## 六、数据质量与口径说明

统计完全基于本仓库 `statement/` 的题面头部元数据，**未访问洛谷站外数据**，以下是使用时必须知道的几件事：

1. **难度取值照抄存档，不做归并**。存档里共存 9 种写法：官方 8 档名称的去加号版本（`提高/省选-` 对应 `提高+/省选−`、`省选/NOI-` 对应 `省选/NOI−`）、`暂未评级`，以及 `NOI+`、`NOI/NOI+`、`Level 8` 三种同时指向最高难度区间的写法——它们很可能来自不同批次的抓取脚本。报告按官方难度序排列，但保留原值以便回溯。
2. **高难度段占比明显偏高，存在系统性偏移风险**。存档中 `NOI+` 占 22.06%，而 `入门` 仅占 3.43%，与洛谷主站以入门/普及题为主体的真实分布不符；`NOI+`（3,586）又远多于 `NOI/NOI+`（552），说明抓取脚本使用的难度名称表与洛谷官方档位并未严格对齐。**引用具体难度前请以洛谷原题页面为准**，本表只适合做相对比较与覆盖度统计。
3. **失效题面**：134 份题面正文为 `Problem not found or unavailable`，已从全部统计中剔除，明细见 CSV 的「题面失效」列。
4. **缺失元数据**：202 份题面缺少 `## Tags`（记为 0 个标签）。
5. **难度与标签会变**：洛谷会不定期调整题目难度、增删标签，本报告只反映抓取时的快照。
6. **标签类别是启发式划分**，仅供聚合参考，逐题精确标签以 CSV 为准。

## 七、如何更新与查询本报告

```bash
# 1) 先校验元数据是否齐全（不写文件）
python3 scripts/gen_statistics.py --check

# 2) 重新生成报告与逐题 CSV
python3 scripts/gen_statistics.py
```

脚本只读取 `statement/`、`solution/`、`appendix/`，不会修改任何题面或题解。
逐题明细的常用查法（`reference/problem-data.csv` 为 UTF-8 BOM，Excel 可直接打开）：

```bash
# 查某道题的难度与标签
grep '^P1004,' reference/problem-data.csv

# 列出所有「线段树」但还没写题解的题
awk -F',' '$5 ~ /线段树/ && $6 == "否" {print $1, $2}' reference/problem-data.csv

# 按难度筛选已写题解的数量
cut -d',' -f3,6 reference/problem-data.csv | sort | uniq -c
```
