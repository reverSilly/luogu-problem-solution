# P2645 斯诺克 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 球的分值 $1\sim7$。小 Ar 打 $n$ 轮、小 Be 打 $m$ 轮（$0\le n,m\le100$，**不保证** $n-1\le m\le n$）。每轮给一个整数 $v\in[0,7]$：

- $v\in[1,7]$：打中了分值为 $v$ 的球，**打球者自己**加 $v$ 分；
- $v=0$：没打中球，**对方**加 $4$ 分。

被打中的球**不**从桌上拿走。输出小 Ar、小 Be 的最终得分。

**第一步：先被背景吓一跳，再发现是幌子。** 题面 Background 里讲了一大堆真实斯诺克规则：21 个球、15 红 6 彩、奇数次必须打红、打完红接彩、红球打完按分值清彩、犯规判罚（打错球按分值给对方加分）……我第一反应是"这不得模拟一整套台球逻辑？"

但紧接着 Description 里明明白白写着：**"小 Ar 和小 Be 记不住斯诺克那么多的规则，所以他们自己发明了一种简单的规则。本题中的打球规则如下……"** 然后给出的就是上面那三条极简规则。这是全题最重要的阅读判断：

> **Background 的真实斯诺克规则全部作废，只按 Description 的简化规则算分。**

没有"必须打红球"、没有"红球拿走"、没有"轮流击球的顺序约束"、没有"打错球按分值判罚"。球不拿走，意味着每一轮都是**独立**的，桌面状态根本不影响后续。我差点就去写红球/彩球状态机了——那是被背景带偏。把这段读清楚，题目瞬间塌缩成"读一堆数、按规则加分"。

**第二步：把每一轮的贡献写清楚。** 对 Ar 的某一轮 $v$：

- $v>0$：`sa += v`（Ar 自己得分）；
- $v=0$：`sb += 4`（Ar 没打中，给**对方** Be 加 4）。

对 Be 的某一轮 $v$ 镜像：$v>0$ 则 `sb += v`，$v=0$ 则 `sa += 4`。注意"对方加 4"是**固定 4 分**，与 $v$ 无关（$v=0$ 就是没打中，没有"错误球分值"那回事——那是被作废的真实规则）。

**第三步：顺序无关，可以分开扫。** 因为每轮贡献只取决于"谁打的、打中没、分值多少"，与桌面状态、与之前之后的轮次都无关（球不拿走），所以总分就是所有轮次贡献的**简单累加**，加法满足交换/结合律，**先扫完 Ar 的 $n$ 轮再扫 Be 的 $m$ 轮**完全正确，不必模拟交替击球。题面特意强调"不保证 $n-1\le m\le n$"，正是在提醒：别假设两人轮流、轮数相近，$n$ 和 $m$ 可以差很多，甚至一个为 $0$。

**第四步：边界——$n=0$ 或 $m=0$。** 若 $n=0$，第二行是空的，Ar 一轮没打，`sa` 不因 Ar 的击球增加（但 Be 若没打中仍会给 Ar 加 4）。用 `for(i=0;i<n;++i)` 读入，$n=0$ 时循环零次，自然跳过空行，无需特判。$m=0$ 同理。`cin>>v` 按空白切分，空行不会被误读。

**第五步：分值范围与类型。** 每轮最多加 $7$（打中）或 $4$（对方没打中），$n,m\le100$，总分上界 $\le 100\times7+100\times4=1100$，`int` 绰绰有余。全局 `sa,sb` 默认 $0$，正好是初始比分。

**手造数据核对**（题面给了样例解释，我据此反推 + 另造犯规/空行数据）：

| 输入 | 分析 | 输出 |
|---|---|---|
| `4 3` / `1 7 1 6` / `1 7 1` | Ar：$1+7+1+6=15$；Be：$1+7+1=9$（样例解释） | `15 9` |
| `2 2` / `0 7` / `0 3` | Ar 打 0→Be+4，打 7→Ar+7；Be 打 0→Ar+4，打 3→Be+3。Ar$=7+4=11$，Be$=4+3=7$ | `11 7` |
| `0 0` / 空 / 空 | 都没打 | `0 0` |
| `1 0` / `0` / 空 | Ar 没打中→Be+4；Be 没打 | `0 4` |

第二组专门打"没打中给对方加 4"，第三、四组专门打 $n/m$ 为 $0$ 的空行边界。

## 二、思维链：完整证明

**记号。** Ar 的击球序列 $u_0,\dots,u_{n-1}$，Be 的 $w_0,\dots,w_{m-1}$，每个值 $\in[0,7]$。`sa`、`sb` 为两人得分，初值 $0$。定义单轮贡献函数：对打球者 $X$（对方 $\bar X$）与值 $v$，
$$\mathrm{contrib}(X,v)=\begin{cases}+v\text{ 给 }X,&v\in[1,7]\\+4\text{ 给 }\bar X,&v=0.\end{cases}$$

---

### 引理 1（只适用简化规则，真实斯诺克规则作废）

本题的计分完全由 Description 的简化规则决定，Background 的红/彩球、击球顺序、犯规判罚等规则不参与计分。

*证明*：Description 显式声明"小 Ar 和小 Be……自己发明了一种简单的规则。**本题中的打球规则如下**"，随后列出的规则是：分值 $1\sim7$；打中则自己加该分值，没打中则对方加 $4$；球不拿走。这是一个**完整且自洽**的计分定义，它没有引用任何红/彩球状态、没有"必须打红"的约束、没有"打错球按分值判罚"。Background 只是情境铺垫，其规则被 Description 的"本题中的打球规则如下"明确取代。故计分只依赖每轮的 $(X,v)$，与桌面球况无关。证毕。

**推论（轮次独立）**：因球不拿走、无桌面状态，第 $t$ 轮的贡献不依赖任何其它轮，$\mathrm{contrib}$ 只是 $(X,v)$ 的函数。

---

### 引理 2（单轮贡献的正确映射）

代码对 Ar 的轮 `if(v)sa+=v; else sb+=4;`、对 Be 的轮 `if(v)sb+=v; else sa+=4;` 恰好实现 $\mathrm{contrib}$。

*证明*：$v\in[0,7]$ 为整数。`if(v)` 即 $v\ne0$，等价于 $v\in[1,7]$（题面保证非负），此时打球者自己加 $v$：Ar 轮 `sa+=v`、Be 轮 `sb+=v`，与 $\mathrm{contrib}$ 第一支一致。`else` 即 $v=0$，对方加 $4$：Ar 轮 `sb+=4`、Be 轮 `sa+=4`，与第二支一致。两支穷尽 $v$ 的所有取值。证毕。

**注**：$v=0$ 时加的是**固定 4**，不是"错误球分值"。后者属于被作废的真实规则（引理 1），本题不存在。

---

### 引理 3（总分 = 各轮贡献之和，顺序无关）

最终 `sa` $=\sum_{t}\mathrm{contrib}(\text{Ar},u_t)$ 中归给 Ar 的部分 $+\sum_{t}\mathrm{contrib}(\text{Be},w_t)$ 中归给 Ar 的部分；`sb` 对称。且先处理全部 Ar 轮再处理全部 Be 轮，与任意交替顺序结果相同。

*证明*：由引理 1 推论，每轮贡献独立、只依赖 $(X,v)$。`sa`、`sb` 的更新都是 `+=`（累加），故最终值是初始 $0$ 加上所有轮次贡献的代数和。整数加法满足交换律与结合律，求和结果与累加顺序无关。代码"先 $n$ 轮 Ar、再 $m$ 轮 Be"是其中一种合法顺序，故与真实交替击球（若存在）结果一致。题面"不保证 $n-1\le m\le n$"不影响此结论——我们从不依赖两人轮数的关系，只各自独立累加。证毕。

---

### 引理 4（空序列边界）

$n=0$ 时 Ar 的击球循环执行零次，`sa` 不因 Ar 击球而变；$m=0$ 时同理。读入不会因空行出错。

*证明*：`for(int i=0,v;i<n;++i)` 在 $n=0$ 时条件 $i<n$ 初始即假，循环体零次执行，不读入任何数，`sa` 保持（仅可能由 Be 的 $v=0$ 轮增加）。$m=0$ 对称。`cin>>v` 以空白（空格/换行）为分隔，$n=0$ 时第二行为空，第三行的 $m$ 个数紧接其后，`cin` 会正确跳过空白读到 Be 的数；不会把空行当成一个 $0$ 误读。故边界安全。证毕。

**注**：$n=0,m=0$ 时两循环都零次，输出 `0 0`；$n=0,m>0$ 时 Ar 仍可能从 Be 的没打中里得分（引理 2 的 `else sa+=4`），这与"Ar 没打球但对手犯规送分"一致。

---

### 引理 5（值域与类型）

$0\le\texttt{sa},\texttt{sb}\le 1100$，`int` 足够，全局默认 $0$ 即正确初值。

*证明*：每轮贡献非负（$+v\ge1$ 或 $+4$）。Ar 的 $n\le100$ 轮每轮至多给 `sa` 加 $7$；Be 的 $m\le100$ 轮每轮至多给 `sa` 加 $4$（当 Be 没打中）。故 $\texttt{sa}\le100\times7+100\times4=1100$，`sb` 对称。下界 $0$（全没打中且……实际上每轮必有正贡献给某人，但单人可能 $0$，如 $n=m=0$）。`int`（$\pm2.1\times10^9$）远够。全局 `int sa,sb` 默认 $0$，正是初始比分，无需显式初始化。证毕。

---

### 引理 6（复杂度）

时间 $O(n+m)$，空间 $O(1)$。

*证明*：读入并处理 $n+m$ 个数，每个 $O(1)$，合计 $O(n+m)$。只用 `sa,sb,n,m,v` 常数个变量，不存序列，空间 $O(1)$。$n,m\le100$，瞬间完成。证毕。

---

### 定理

程序输出的 `sa sb` 恰为按简化规则累计的小 Ar、小 Be 得分；时间 $O(n+m)$，空间 $O(1)$。

*证明*：引理 1 确立只用简化规则、轮次独立；引理 2 保证每轮贡献映射正确；引理 3 保证总分是各轮贡献之和且处理顺序无关；引理 4 保证 $n/m$ 为 $0$ 的空行边界正确；引理 5 保证 `int` 与初值正确；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 读穿背景幌子：Description 的"自己发明的简单规则"取代 Background 的真实斯诺克规则，球不拿走 ⇒ 每轮独立。
- **reduce to easier problem** — 整题塌缩成"读一堆 $(X,v)$、按 $v>0$ 自己加 $v$ / $v=0$ 对方加 $4$ 累加"，无需任何台球状态机。
- **explore its property** — 顺序无关：贡献是纯累加，加法交换/结合 ⇒ 先扫 Ar 再扫 Be 即可，不必模拟交替；"不保证 $n-1\le m\le n$"正提醒别假设轮数关系。
- **discuss by category** — 边界 $n=0$ / $m=0$ 空行：循环零次自然跳过；$v=0$ 加固定 $4$（不是错误球分值）；`int` 足够、全局默认 $0$ 即初值。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 小 Ar 的击球轮数（$0\le n\le100$） | `int`，读入 | 可为 $0$ |
| `m` | 小 Be 的击球轮数（$0\le m\le100$） | `int`，读入 | 可为 $0$，与 $n$ 无大小关系 |
| `sa` | 小 Ar 的得分 | `int`，全局默认 $0$ | "s-a = score Ar" |
| `sb` | 小 Be 的得分 | `int`，全局默认 $0$ | "s-b = score Be" |
| `v` | 当前轮的分值（$0\sim7$） | `int`，循环内读入 | $0$=没打中，$1\sim7$=打中 |

### 算法步骤

1. I/O 加速三行。
2. 读入 `n,m`。
3. 循环 $n$ 次读 `v`：`if(v)sa+=v; else sb+=4;`（Ar 打中自己加，没打中给 Be 加 4）。
4. 循环 $m$ 次读 `v`：`if(v)sb+=v; else sa+=4;`（Be 打中自己加，没打中给 Ar 加 4）。
5. 输出 `sa` 空格 `sb` 换行。

### 复杂度

- 时间：$O(n+m)$，$n,m\le100$。
- 空间：$O(1)$，不存序列。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；4 组手造数据（样例反推 `15 9`、犯规送分 `11 7`、双空 `0 0`、单空 `0 4`）逐条吻合。本题为直接模拟，证明已闭合（引理 1–6），无需对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2645 斯诺克
// 思路：Background 的真实斯诺克规则全部作废，只按 Description 的简化规则：
//       打中分值 v(1~7) → 自己加 v；没打中(0) → 对方加 4；球不拿走 ⇒ 每轮独立。
//       贡献是纯累加，顺序无关，先扫 Ar 的 n 轮再扫 Be 的 m 轮即可。
#include<bits/stdc++.h>
using namespace std;

int n,m,sa,sb;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,v;i<n;++i)
	{
		cin>>v;
		if(v)sa+=v;	// Ar 打中：自己加分
		else sb+=4;	// Ar 没打中：对方(Be)加 4
	}
	for(int i=0,v;i<m;++i)
	{
		cin>>v;
		if(v)sb+=v;	// Be 打中：自己加分
		else sa+=4;	// Be 没打中：对方(Ar)加 4
	}
	cout<<sa<<' '<<sb<<'\n';
	return 0;
}
```

### 代码说明

- **不写任何台球状态机**：没有红/彩球计数、没有"必须打红"、没有击球顺序约束——那些都是被 Description 作废的背景规则（引理 1）。每轮只看 $(谁打的, v)$。
- **`if(v)` 等价 $v\in[1,7]$**：题面保证 $v\ge0$，故 `v!=0` 就是打中；`else` 就是 $v=0$ 没打中，给对方加**固定 4**。
- **两个独立循环**：先 Ar 后 Be，靠加法交换/结合律保证与交替击球同结果（引理 3）；从不假设 $n,m$ 的大小关系。
- **空行自然处理**：$n=0$ 或 $m=0$ 时对应循环零次，`cin` 按空白切分不会误读空行（引理 4）。
- `sa,sb` 全局默认 $0$ 即初始比分；总分 $\le1100$，`int` 足够（引理 5）。
