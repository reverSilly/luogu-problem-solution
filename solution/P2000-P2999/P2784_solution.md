# P2784 化学1（chem1）- 化学合成 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 个化合物、$M$ 个一步反应 $A_i\to B_i$，转化率 $C_i\in(0,1)$：$1$ 单位 $A_i$ 实际生成 $C_i$ 单位 $B_i$。从 $1$ 单位化合物 $S$ 出发，选一条合成路线生成 $T$，求**最高产量**，四舍五入保留 $4$ 位小数；没有可行路线输出 `orz`。

**关于数据范围**：题面的数据范围是一张图片（`pic/2220.png`），本地文本无法读取。这不影响解题——下面会看到，算法是 $O(M\log N)$ 的正权最短路，对任何合理的 $N,M$ 上界都绰绰有余；数组按 $10^5+5$ 开，覆盖到十万级化合物。

**第一步：探性质——路线产量是转化率的乘积。** 沿路线 $S=v_0\to v_1\to\cdots\to v_k=T$，$1$ 单位 $v_0$ 生成 $C_1$ 单位 $v_1$，再生成 $C_1C_2$ 单位 $v_2$……归纳即得最终产量 $\prod_{i=1}^{k}C_i$。所以题目是：**在带权有向图上找一条 $S\to T$ 的路径，最大化边权之积**。

**第二步：警惕——"最长路"不是好东西。** 最大化路径权值和（或积）的一般图问题是 NP 困难的，因为可以绕正权环无限刷。但本题有个救命条件：$0<C<1$。**绕任何环一圈，产量都要乘上一个 $<1$ 的因子，只会越绕越少。** 所以最优路线绝不会含环——它一定是一条简单路径，最大值在有限条简单路径中取得，问题良定义。这个条件是整题的支点：如果允许 $C>1$，存在增益环时产量可以无上界（绕环刷到无穷），题目就崩了。

**第三步：先试直接乘法 DP（能跑，但有暗坑）。** 既然没有增益环，可以直接令 `dis[v]` = 目前已知 $S\to v$ 的最大产量，`dis[S]=1`，沿边松弛 `dis[v]=max(dis[v],dis[u]*C)`，用 SPFA 或 Dijkstra 式堆优化跑。逻辑上正确。但算一笔数值账：产量是**连乘**，$40$ 步 $0.1$ 就是 $10^{-40}$，$320$ 步就是 $10^{-320}$——`double` 的最小正规数约 $2.2\times 10^{-308}$，**直接下溢成 $0$**。一旦两条不同的微小路线都变成 $0$，`max` 就比较不出谁更优，信息永久丢失。虽然本题只输出 $4$ 位小数（微小产量最终都舍入成 `0.0000`），但"中间比较"发生在下溢之后就是错的算法——比如最优路线产量 $10^{-300}$、次优 $10^{-310}$，下溢后两者都是 $0$，若后续还有分支依赖这个比较，结果不可控。**乘法域不安全。**

**第四步：取对数——乘法变加法，连乘变求和。** 对产量取自然对数：

$$\ln\prod_i C_i=\sum_i \ln C_i.$$

$\ln$ 在 $(0,+\infty)$ 上严格递增，所以**最大化乘积 $\iff$ 最大化 $\sum\ln C_i$ $\iff$ 最小化 $\sum(-\ln C_i)$**。令边权 $w_i=-\ln C_i$，由 $0<C_i<1$ 得 $w_i>0$——**所有边权严格为正**！于是问题变成教科书式的"正权单源最短路"，Dijkstra 直接上。对数域里累加的是几十、几百量级的正数，永远不会下溢；最后 `exp(-dis[T])` 一步还原产量。

这就是本题的思维跳跃：**"最大积路径"看着像最长路（难），取 $-\ln$ 后变成正权最短路（易）**。难与易的分界正是 $C<1$ 保证的权值正性。

**第五步：抠边界。**

1. **不可达**：`dis[T]` 保持 INF 时输出 `orz`。注意全局 `long double` 数组默认是 $0$ 不是 INF，**必须显式 `fill_n(dis,n,inf)`**，否则所有点都会被当成"产量 $e^0=1$ 可达"。
2. **$S=T$**：不需要任何反应，$1$ 单位 $S$ 本身就是 $T$，空路线产量为空积 $=1$。代码 `dis[S]=0`，`exp(-0)=1`，输出 `1.0000`，自然覆盖。
3. **重边、自环**：Dijkstra 天然兼容。自环 $w>0$ 永远不会松弛成功（`dis[u]+w>dis[u]`），自动忽略——与"绕环减产"的化学事实一致。
4. **精度**：全程 `long double`（x86 上 80 位），`logl/expl` 配套。输出 `fixed<<setprecision(4)`。
5. **还原时的下溢**：若最优产量本身 $<10^{-4932}$（`long double` 极限），`expl` 返回 $0$——但此时正确答案四舍五入到 $4$ 位小数**本来就是 `0.0000`**，下溢无害。这与第三步"中间比较下溢"有本质区别：一个发生在算法决策处（有害），一个发生在最终输出处（无害）。

**手造数据核对**（题面样例是图片，但"样例说明"给出了全部数字，我据此反推两组，再另造三组打边界）：

第一组，按样例 1 说明反推：反应 $1\to3$（$0.8$）、$1\to2$（$0.9$）、$2\to3$（$0.9$），$S=1,T=3$。两条路线产量 $0.8$ 与 $0.9\times0.9=0.81$，说明明确说答案是 `0.8100`：

```
输入              输出
3 3 1 3           0.8100
1 3 0.8
1 2 0.9
2 3 0.9
```

第二组，按样例 2 说明（"$2$ 只能生成 $3$，$3$ 无法生成别的化合物，故无法生成"）构造不可达：$S=1,T=2$，只有反应 $2\to3$（$0.5$），输出 `orz` ✓。

第三组，专打环：$1\to2$（$0.9$）、$2\to1$（$0.9$）、$1\to3$（$0.5$）。绕环 $1\to2\to1\to3$ 产量 $0.81\times0.5=0.405<0.5$，最优仍是直达，输出 `0.5000` ✓（验证"环只会减产"）。第四组，$S=T=1$，输出 `1.0000` ✓。第五组，专打下溢：$41$ 个化合物链式反应，每步 $0.1$，产量 $10^{-40}$，输出 `0.0000` ✓（对数域里 $\text{dis}=40\ln 10\approx 92.1$，毫无压力；直接乘法版在更长的链上就会失真）。五组全部与手算一致。

## 二、思维链：完整证明

**记号。** 有向图 $G=(V,E)$，$|V|=N$，边 $e=(u\to v)$ 带转化率 $C_e\in(0,1)$。路线指顶点序列 $v_0,v_1,\dots,v_k$（$v_0=S$，$v_k=T$，相邻有边），允许重复顶点时称"途径"（walk），顶点互异时称"简单路径"。边权 $w_e=-\ln C_e$。$\delta(S,v)$ 为 $S\to v$ 的最小权值和（不可达为 $+\infty$）。产量 $Y(P)=\prod_{e\in P}C_e$（空路线 $Y=1$）。

---

### 引理 1（产量 = 转化率之积）

沿路线 $P:v_0\to\cdots\to v_k$，从 $1$ 单位 $v_0$ 出发，到达 $v_i$ 的量为 $\prod_{j=1}^{i}C_{e_j}$（$e_j$ 为第 $j$ 步的边）。特别地最终产量 $Y(P)=\prod_{j=1}^{k}C_{e_j}$。

*证明*：对步数 $i$ 归纳。$i=0$：空积 $=1$，与"起始 $1$ 单位"一致 ✓。设到 $v_{i-1}$ 的量为 $Q_{i-1}=\prod_{j<i}C_{e_j}$。题面规定"$1$ 单位 $A$ 实际生成 $C$ 单位 $B$"，转化是线性比例关系（不存在绝对完全的转化，但比例恒定），故 $Q_{i-1}$ 单位 $v_{i-1}$ 经边 $e_i$ 生成 $Q_{i-1}\cdot C_{e_i}=Q_i$ 单位 $v_i$ ✓。归纳完成。证毕。

---

### 引理 2（最优路线必为简单路径：环只会减产）

设途径 $W$ 含一个环（某顶点重复出现）。删去该环得到途径 $W'$，则 $Y(W')>Y(W)$。因此 $\max_{\text{途径}}Y=\max_{\text{简单路径}}Y$，且最大值存在（简单路径有限条）。

*证明*：设 $W$ 中顶点 $u$ 在第 $a$ 步与第 $b$ 步（$a<b$）重复出现，环段为 $e_{a+1},\dots,e_b$。删去环段后 $W'$ 仍是合法途径（$u$ 处直接衔接），且

$$Y(W)=Y(W')\cdot\prod_{j=a+1}^{b}C_{e_j}.$$

每个 $C_{e_j}\in(0,1)$，故环因子 $\in(0,1)$，$Y(W)<Y(W')$ ✓。任何含环途径都能被严格改进，故最优途径无环，即简单路径。$N$ 个顶点的简单路径至多 $\sum_{k=0}^{N-1}\frac{(N-2)!}{(N-2-k)!}$ 条（有限），有限集上的最大值存在。证毕。

**反面对照（为什么 $C<1$ 是支点）**：若允许某环的因子 $>1$（即环上存在 $C>1$ 的边且乘积 $>1$），则绕环 $t$ 圈产量 $\to\infty$，"最高产量"无上界，题目无解；若环因子恰 $=1$，最优值存在但最优途径可含环，Dijkstra 的正权前提也被破坏。题面 $0<C<1$ 把这两种病态全部排除。

---

### 引理 3（对数归约：最大积 $\iff$ 正权最短路）

对任意两条 $S\to T$ 途径 $P,Q$：$Y(P)>Y(Q)\iff \sum_{e\in P}w_e<\sum_{e\in Q}w_e$。从而

$$\max_P Y(P)=\exp\bigl(-\delta(S,T)\bigr),$$

且 $w_e=-\ln C_e>0$ 对一切边成立。

*证明*：$Y(P),Y(Q)>0$（有限个 $(0,1)$ 数之积）。$\ln$ 在 $(0,+\infty)$ 严格递增，故 $Y(P)>Y(Q)\iff\ln Y(P)>\ln Y(Q)$。由对数乘法公式 $\ln Y(P)=\sum_{e\in P}\ln C_e=-\sum_{e\in P}w_e$，代入得 $\iff\sum_P w<\sum_Q w$ ✓。于是"最大化 $Y$"与"最小化 $\sum w$"在同一路线集合上取到最优（引理 2 保证该集合非空时最大值存在），且 $\ln Y^\*=-\delta(S,T)$，即 $Y^\*=e^{-\delta(S,T)}$。权值正性：$C_e<1\Rightarrow\ln C_e<0\Rightarrow w_e>0$ ✓。证毕。

**推论**：原问题归约为**边权严格为正**的单源最短路——Dijkstra 的适用前提恰好满足。这不是巧合，是 $C<1$ 的化学事实（转化不完全）经 $-\ln$ 翻译后的数学形态。

---

### 引理 4（Dijkstra 不变量：弹出即定稿）

算法：`dis[S]=0`，其余 INF；小根堆存 `(dis估计, 顶点)`；每次弹出堆顶 $(d,u)$，若 `vis[u]` 则跳过（惰性删除），否则置 `vis[u]=true` 并松弛所有出边 `dis[v]=min(dis[v],dis[u]+w)`（成功则入堆）。则**每个顶点 $u$ 第一次被置 `vis` 时，`dis[u]`$=\delta(S,u)$**（不可达顶点永不被置 `vis`）。

*证明*：先证一个辅助事实：**任何时刻 `dis[v]` 都是某条 $S\to v$ 途径的权值和（或 INF）**。归纳：初始 `dis[S]=0` 是空途径；每次松弛 `dis[v]=dis[u]+w` 把 $u$ 的途径接上一条边，仍是途径。故 `dis[v]`$\ge\delta(S,v)$ 恒成立（$\delta$ 是下确界）。

再证弹出时取等。对弹出顺序归纳。设 $u$ 是第一个"置 `vis` 时 `dis[u]`$>\delta(S,u)$"的顶点（反证假设）。取一条 $S\to u$ 的最短途径 $P$（正权 $\Rightarrow$ 可取简单路径，引理 2 的论证同样适用）。$P$ 上从 $S$ 出发第一个未 `vis` 的顶点记为 $y$，其前驱 $x$ 已 `vis`（$S$ 已 `vis`，$x$ 存在；若 $y=S$ 则 $S$ 未 `vis` 与 $S$ 最先弹出矛盾，故 $y\ne S$，$x$ 存在）。由归纳假设，$x$ 置 `vis` 时 `dis[x]`$=\delta(S,x)$，且随后松弛了边 $(x,y)$，故此刻

$$\texttt{dis}[y]\le \delta(S,x)+w(x,y)=\delta(S,y)$$

（$P$ 是最短路，其前缀也是最短：否则换掉前缀得到更短的 $P$，矛盾——这里用到正权保证前缀最短性，实际上任意权值下最短路的前缀都最短，因为若有更短前缀，拼接后总权更小）。结合辅助事实 `dis[y]`$\ge\delta(S,y)$，得 `dis[y]`$=\delta(S,y)$。

$y$ 在 $P$ 上位于 $u$ 之前或就是 $u$。若 $y=u$：`dis[u]`$=\delta(S,u)$，与反证假设矛盾 ✓。若 $y\ne u$：$P$ 上 $y\to u$ 段至少一条边、权值和 $>0$（正权），故 $\delta(S,y)<\delta(S,u)<\texttt{dis}[u]$（反证假设）。于是堆中存在 $y$ 的条目（松弛成功时入堆；即使后来被更小值覆盖，堆里也有 $\le\texttt{dis}[y]$ 的条目），其键 $\le\texttt{dis}[y]=\delta(S,y)<\texttt{dis}[u]=d$。但算法弹出的是**堆顶**（最小键）$u$，键 $d$ 却大于堆中另一条目的键——矛盾 ✓。两情形皆矛盾，故弹出即定稿。

不可达顶点：由辅助事实，`dis` 有限 $\Rightarrow$ 存在途径 $\Rightarrow$ 可达；故不可达顶点 `dis` 恒 INF，永不入堆、永不 `vis` ✓。证毕。

---

### 引理 5（可达性判据：`dis[T]>=inf` $\iff$ 无可行路线）

程序用 `dis[T]>=inf` 判定输出 `orz`，这与"$T$ 从 $S$ 不可达"等价。

*证明*：($\Leftarrow$) 不可达时由引理 4，`dis[T]` 恒为初值 `inf`，判定成立 ✓。($\Rightarrow$) 若可达，取最短路径 $S=v_0\to\cdots\to v_k=T$。对 $i$ 归纳可证每个 $v_i$ 都会被置 `vis` 且 `dis[v_i]`$=\delta(S,v_i)$ 有限：$v_0=S$ 显然；设 $v_{i-1}$ 已定稿，松弛边 $(v_{i-1},v_i)$ 后 `dis[v_i]`$\le\delta(S,v_{i-1})+w<\text{inf}$（有限值，因为 $\delta$ 有限、$w$ 有限），故 $v_i$ 入堆、终将弹出定稿（堆非空时必弹出，有限图有限条目）。于是 `dis[T]` 有限 $<\text{inf}$，判定不成立 ✓。

**数值余量**：有限 $\delta$ 的上界为 $(N-1)\cdot\max_e w_e$。$w_e=-\ln C_e$，即使 $C_e$ 小到 $10^{-300}$，$w_e\approx 691$；$N\le 10^5$ 时 $\delta\le 7\times 10^7\ll\text{inf}=10^{18}$，"有限值"与"INF"之间隔着 $10^{10}$ 倍以上的安全距离，判据不会误判。证毕。

---

### 引理 6（数值安全：对数域为什么优于乘法域）

(a) **乘法域下溢有害**：`double` 最小正规数 $\approx 2.2\times 10^{-308}$。产量 $10^{-320}$ 与 $10^{-330}$ 在 `double` 中都变成 $0$，`max` 比较丢失两条路线的优劣信息；若该比较参与后续松弛决策，算法可能选出次优路线。

(b) **对数域无上溢下溢**：$\text{dis}=\sum w_e$ 是正数累加，量级 $\le(N-1)\max w_e$（引理 5 已估 $\le 7\times 10^7$），`long double` 范围 $\approx[3.4\times 10^{-4932},\,1.2\times 10^{4932}]$，绰绰有余。

(c) **还原误差远低于输出粒度**：`logl`/`expl` 的相对误差 $\le$ 机器精度 $u=2^{-64}\approx 5.4\times 10^{-20}$（x87 80 位）。$\delta$ 的累加误差 $\le N\cdot u\cdot\max\text{dis}\approx 10^5\times 5.4\times 10^{-20}\times 7\times 10^7\approx 3.8\times 10^{-7}$（最坏一阶界），还原产量 $e^{-\delta}$ 的相对误差同量级。产量 $\le 1$，绝对误差 $\le 4\times 10^{-7}$，而四舍五入到 $4$ 位小数的判定阈值是 $5\times 10^{-5}$——误差比阈值小两个数量级以上，安全。

(d) **最终还原的下溢无害**：若 $e^{-\delta}$ 本身 $<10^{-4932}$，`expl` 返回 $0$；但真实产量 $<10^{-4932}\ll 5\times 10^{-5}$，正确答案舍入后本就是 `0.0000`，输出一致。下溢发生在**输出端**而非**决策端**，与 (a) 有本质区别。

*证明*：(a) 由 IEEE754 下溢规则（低于最小正规数逐步丧失精度直至归零）直接得到；构造性反例：两条路线产量 $0.1^{320}$ 与 $0.1^{330}$，`double` 下均为 $0$。(b) 正数和单调增，上界即项数乘最大项；`long double` 指数范围 $\pm 16382$（约 $10^{\pm 4932}$）。(c) 标准浮点误差分析：$n$ 次加法的 worst-case 相对误差界 $n\cdot u/(1-nu)$，代入即得；$\exp$ 的相对误差条件数为 $|\delta|$，但这里直接对 $\delta$ 的绝对误差传播：$|e^{-\hat\delta}-e^{-\delta}|\le e^{-\delta}|\hat\delta-\delta|\le|\hat\delta-\delta|$（$e^{-\delta}\le 1$）。(d) 舍入定义直接验证。证毕。

---

### 引理 7（$S=T$ 与空路线）

$S=T$ 时程序输出 `1.0000`，与"不需要反应、$1$ 单位 $S$ 即 $T$"一致。

*证明*：`dis[S]=0`（空途径权值和 $0$），$T=S$ 故 `dis[T]=0`，`expl(-0)=1`，`fixed<<setprecision(4)` 输出 `1.0000`。空积 $\prod_{\varnothing}=1$ 与引理 1 的 $i=0$ 情形一致。证毕。

---

### 引理 8（复杂度）

时间 $O((N+M)\log N)$，空间 $O(N+M)$。

*证明*：建图 $O(M)$（每条边一次 `logl` 与 `push_back`）。Dijkstra：每个顶点至多定稿一次（`vis` 守卫），每条边至多松弛成功一次并入堆一次，堆中条目 $\le M+1$，每次插入/弹出 $O(\log M)=O(\log N)$（$M\le N^2$ 时 $\log M\le 2\log N$）。总 $O((N+M)\log N)$。空间：邻接表 $O(N+M)$，`dis/vis` $O(N)$，堆 $O(M)$。即使 $N=10^5,M=10^6$，约 $10^6\times 20=2\times 10^7$ 次堆操作，秒级以内。证毕。

---

### 定理

程序输出最佳路线产量（四舍五入 $4$ 位小数），不可达时输出 `orz`，总复杂度 $O((N+M)\log N)$。

*证明*：引理 1 把化学过程化为边权积；引理 2 用 $C<1$ 排除环、保证最优简单路径存在；引理 3 用 $-\ln$ 把最大积归约为正权最短路；引理 4 保证 Dijkstra 定稿值 $=\delta(S,T)$；引理 5 保证 `orz` 判据与可达性等价；引理 6 保证对数域全程数值安全、还原误差远低于输出粒度；引理 7 覆盖 $S=T$；引理 8 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 路线产量 = 转化率连乘（逐步线性比例，归纳即得）。
- explore its property — $0<C<1$ ⇒ 绕环必减产 ⇒ 最优路线是简单路径，"最大积"良定义；若允许 $C>1$ 则增益环使产量无上界，题目崩坏——约束即支点。
- consider easier version — 先试乘法域直接松弛（SPFA/Dijkstra 式 `max(dis[u]*C)`），逻辑可行但发现连乘下溢（$0.1^{320}\to 0$）会污染中间比较。
- reduce to easier problem — 取 $-\ln$：最大积 $\iff$ 最小和，且 $C<1\Rightarrow w=-\ln C>0$，"最长路"塌缩成正权最短路。
- classic problem solution — Dijkstra + 惰性删除小根堆：弹出即定稿（正权不变量），`dis[T]` 有限 $\iff$ 可达。
- explore its property — 对数域累加不下溢；`expl` 还原时的下溢发生在输出端，舍入后本就是 `0.0000`，无害——与决策端下溢严格区分。
- discuss by category — 不可达 → `orz`（INF 必须显式填）；$S=T$ → 空积 $1$ → `1.0000`；重边/自环天然兼容（自环正权永不松弛）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,m,S,T` | 化合物数、反应数、起点、终点 | `int`，读入后 `--S;--T` | 0-based |
| `graph[u]` | $u$ 的出边表，元素 `{v,w}`，$w=-\ln C$ | `vector<pair<int,long double>>[mxn]` | 乘法产量 → 加法正权 |
| `mxn` | $10^5+5$（题面范围是图片，按宽松上界开） | `constexpr int` | |
| `dis[v]` | $S\to v$ 的最小 $\sum(-\ln C)$ 估计 | `long double[mxn]`，**显式 `fill_n(dis,n,inf)`** | 全局默认 $0$ 是陷阱；`dis[S]=0` |
| `inf` | $10^{18}$，不可达哨兵 | `constexpr long double` | 有限 $\delta\le 7\times 10^7$，余量 $10^{10}$ 倍 |
| `vis[v]` | $v$ 是否已定稿 | `bool[mxn]`，默认 `false` | 惰性删除守卫 |
| `Q` | `(dis估计, 顶点)` 小根堆 | `priority_queue<...,greater<>>` | 堆顶最小键先弹出 |
| 答案 | `expl(-dis[T])` | `long double` | `fixed<<setprecision(4)` |

### 算法步骤

1. I/O 加速三行；读 $N,M,S,T$，`--S;--T`。
2. 读 $M$ 条反应 $u\to v$、转化率 $C$，`--u;--v`，加边 `{v,-logl(C)}`。
3. `fill_n(dis,n,inf)`；`dis[S]=0`；`Q.push({0,S})`。
4. 堆非空时：弹出 `(d,u)`；`vis[u]` 则跳过；否则 `vis[u]=true`，遍历出边松弛 `dis[v]=min(dis[v],dis[u]+w)`，成功则入堆。
5. 若 `dis[T]>=inf` 输出 `orz`；否则输出 `fixed<<setprecision(4)<<expl(-dis[T])`。

### 复杂度

- 时间：$O((N+M)\log N)$；空间：$O(N+M)$。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过、无警告；按样例说明反推的两组输出 `0.8100` / `orz` 与说明逐字吻合；另造环减产组（`0.5000`）、$S=T$ 组（`1.0000`）、$40$ 步 $0.1$ 下溢链组（`0.0000`）共五组手算数据全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2784 化学1（chem1）- 化学合成
// 路线产量 = 转化率之积；取 -ln 后变成边权全正的最短路（0<C<1 ⇒ -ln C>0）。
// Dijkstra 求 S→T 最小权值和，答案 expl(-dis[T])；不可达输出 orz。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};
constexpr long double inf{1e18};

int n,m,S,T;
vector<pair<int,long double>>graph[mxn];
long double dis[mxn];
bool vis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>S>>T;--S;--T;
	for(int i=0,u,v;i<m;++i)
	{
		long double c;
		cin>>u>>v>>c;--u;--v;
		graph[u].push_back({v,-logl(c)});	// 乘法产量 ⇒ 加法 -ln C，恒正
	}
	fill_n(dis,n,inf);	// 全局数组默认 0，不可达必须显式填 INF
	dis[S]=0;
	priority_queue<pair<long double,int>,vector<pair<long double,int>>,greater<>>Q;
	Q.push({0,S});
	while(!Q.empty())
	{
		auto[d,u]=Q.top();Q.pop();
		if(vis[u])
			continue;
		vis[u]=true;
		for(auto[v,w]:graph[u])
			if(dis[u]+w<dis[v])
			{
				dis[v]=dis[u]+w;
				Q.push({dis[v],v});
			}
	}
	if(dis[T]>=inf)
		cout<<"orz\n";
	else
		cout<<fixed<<setprecision(4)<<expl(-dis[T])<<'\n';
	return 0;
}
```

### 代码说明

- **`-logl(c)` 是全题的枢纽**：它把"最大积"翻译成"最小和"，同时把 $C<1$ 翻译成 $w>0$——Dijkstra 的正权前提由此而来。读入用 `long double`，配套 `logl/expl`，不要混用 `log/exp`（那是 `double` 版）。
- `fill_n(dis,n,inf)` 不可省：全局 `long double` 默认 $0$，而 $0$ 在本算法里意味着"产量 $1$ 可达"，漏填会让所有点被误判可达（`orz` 永不输出）。
- 惰性删除：同一顶点可能多次入堆，`vis[u]` 守卫保证只定稿一次；弹出的旧条目 `d` 可能大于 `dis[u]`，但松弛用 `dis[u]`（定稿值）而非 `d`，正确性不受影响（引理 4）。
- `dis[T]>=inf` 而非 `==inf`：有限 $\delta$ 与 `inf` 之间余量巨大（引理 5），两种写法等价，`>=` 更防御。
- $S=T$ 时 `dis[T]=0`，`expl(0)=1` → `1.0000`，无需特判；自环 $w>0$ 永不松弛成功，无需特判。
- 输出 `fixed<<setprecision(4)` 完成四舍五入到 $4$ 位小数；产量 $\le 1$，无整数部分溢出之虞。
