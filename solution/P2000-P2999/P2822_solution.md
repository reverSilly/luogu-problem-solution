# P2822 [NOIP 2016 提高组] 组合数问题 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 第一行给 $t,k$（$t$ 组询问，**整份数据共用一个 $k$**），接下来 $t$ 行每行 $n,m$。对每组询问统计满足

$$0\le i\le n,\quad 0\le j\le\min(i,m),\quad k\mid\tbinom{i}{j}$$

的数对 $(i,j)$ 个数。范围：$0\le n,m\le2000$，$1\le t\le10^4$。子任务表里 $k$ 取遍 $2,3,\dots,21$，且 $n,m$ 的上界逐档放大（注意有几档 **$m$ 远大于 $n$**，如 $n\le25,m\le2000$）。

两个信号立刻跳出来：

- $t=10^4$ 而 $n,m\le2000$：**必须预处理，询问 $O(1)$**。每次询问重算一片 $2000\times2000$ 的区域是 $4\times10^6\times10^4=4\times10^{10}$，必死。
- $k$ 在第一行、和 $t$ 一起给：**整份数据 $k$ 不变**，所以预处理只做一次，这是出题人明摆着送的结构。

**一个显式假设**：题面的"全部测试点"那行只给了 $n,m,t$ 的范围，没给 $k$ 的总范围；子任务表里 $k$ 取遍 $2..21$。我按 **$1\le k\le21$** 理解（$k=0$ 时"整除"无定义，不予考虑），并且下面会看到：算法与代码对**任意** $k\ge1$ 都正确，$k\le10^9$ 时连溢出都不会有，所以这个假设不影响实现。

### 第一步：先撞第一堵墙——组合数本身算不出来

最直白的想法：对每个 $(i,j)$ 算 $\binom ij=\frac{i!}{j!(i-j)!}$，再判 `%k==0`。

$\binom{2000}{1000}$ 有多大？由 $\binom{2n}{n}\approx\frac{4^n}{\sqrt{\pi n}}$，$\binom{2000}{1000}\approx\frac{2^{2000}}{\sqrt{1000\pi}}$，约 $600$ 位十进制。`long long` 只有 $19$ 位，`__int128` 只有 $38$ 位。**阶乘路线连数值都存不下**，更别提 $2000!$ 了。

### 第二步：那就在模 $k$ 意义下算——但阶乘公式又撞第二堵墙

"我只关心 $\binom ij\bmod k$，能不能全程取模？"听起来对，但阶乘公式里有**除法**：

$$\binom ij\bmod k=\bigl(i!\cdot(j!)^{-1}\cdot((i-j)!)^{-1}\bigr)\bmod k.$$

逆元存在的条件是 $\gcd(j!,k)=1$。而子任务表里 $k=4,6,8,9,10,12,14,15,16,18,20,21$ **全是合数**！

最小反例：$k=4$，$\binom42=6$。$4!=24\equiv0\pmod4$，$2!=2\equiv2\pmod4$，而 $2$ 在模 $4$ 下**没有逆元**（$2x\bmod4$ 只能是 $0$ 或 $2$，永远不是 $1$）。式子变成"$0$ 除以 $0$"，彻底失效。就算改用"先约分再取模"，也要对每个 $(i,j)$ 做质因数分解，$4\times10^6$ 个格子根本来不及。

**解剖失败原因**：阶乘公式用了除法，而模合数的除法不封闭。要绕开它，就得找一个**只用加法**的组合数递推式。

### 第三步：杨辉三角——只用加法的递推

$$\binom ij=\binom{i-1}{j-1}+\binom{i-1}{j}.$$

组合意义一句话：从 $i$ 个物品里选 $j$ 个，按"第 $i$ 个物品选不选"分类——选了就从剩下 $i-1$ 个里选 $j-1$ 个，没选就从 $i-1$ 个里选 $j$ 个，两类不重不漏。

只有加法，而**模运算对加法封闭**（$(a+b)\bmod k=((a\bmod k)+(b\bmod k))\bmod k$，对任意 $k\ge1$ 成立，不需要 $k$ 是素数）。于是

$$c[i][j]=\bigl(c[i-1][j-1]+c[i-1][j]\bigr)\bmod k,\qquad c[i][0]=c[i][i]=1\bmod k$$

就能把整片 $\binom ij\bmod k$ 递推出来，每个格子的值都 $<k\le21$，`int` 绰绰有余。**两堵墙一次拆掉**：不存大数、不做除法。

（顺带说明为什么不用 Kummer/Lucas：那套理论判"$p\mid\binom ij$"要看 $p$ 进制进位，前提是 $p$ 为素数；本题 $k$ 是合数，而且我们要的是**整片区域的计数**而不是单点判定，直接递推 + 前缀和反而更短更稳。）

### 第四步：再撞第三堵墙——$4\times10^6$ 个格子 $\times10^4$ 次询问

预处理出 $c[i][j]$ 之后，每次询问还是要扫一遍三角形区域数"有多少个 $0$"，$O(nm)$ 每问，总量 $4\times10^{10}$。

这是经典的"区域计数"信号：**二维前缀和**。令

$$b[i][j]=[\,j\le i\ \text{且}\ c[i][j]=0\,],\qquad s[i][j]=\sum_{a<i}\sum_{b<j}b[a][b],$$

则询问答案是 $s$ 在某个右上角的取值，$O(1)$。

### 第五步：计数区域到底是哪个矩形？

题目要的区域是 $\{(i,j):0\le i\le n,\ 0\le j\le\min(i,m)\}$——一个**三角形被水平带截断**的形状，不是矩形。前缀和只会算矩形，怎么办？

关键观察：$j\le\min(i,m)\iff (j\le i)\land(j\le m)$。而 $b[i][j]$ 的定义里已经带了 $j\le i$ 这个因子（三角形外恒为 $0$）。所以

$$\text{答案}=\sum_{i=0}^{n}\sum_{j=0}^{m}b[i][j],$$

即**矩形 $[0,n]\times[0,m]$ 上的前缀和**，三角形外的格子自动贡献 $0$。形状问题被"指示函数带约束"这一招化解了。

进一步，因为 $i\le n$，有 $\min(i,m)=\min(i,\min(n,m))$（下面引理 4 证），所以列上界取 $\min(n,m)$ 与取 $m$ 完全等价，而前者更紧、还在数组范围内。子任务里 $m\le2000$ 而 $n$ 可以只有 $25$，这一档就是专门卡"列上界"的。

### 第六步：第四堵墙——$j>i$ 的"幽灵格子"

这是本题最阴的坑。滚动/全局数组里，$j>i$ 的位置上 $c$ 的值是 $0$（还没被递推写过），而 $0\bmod k=0$，**看起来"被 $k$ 整除"**！如果不加 $j\le i$ 的判断，这些根本不存在的数对会被计入答案。

最小反例：$k=2,n=1,m=1$。真实数对只有 $(0,0),(1,0),(1,1)$，$\binom00=\binom10=\binom11=1$，都不是 $2$ 的倍数，答案 $0$。但格子 $(0,1)$ 上 $c[1]=0$（第 $0$ 行还没递推到第 $1$ 列），若不排除就会多算 $1$，输出 $1$。

所以 $b[i][j]$ 的定义里 **$j\le i$ 这个条件是正确性的一部分，不是优化**。数学上 $\binom ij=0$（$j>i$）确实被任何 $k$ 整除，但题目根本没让这些数对参与计数。

### 第七步：省内存——滚动一行杨辉三角

朴素写法要两个 $2005\times2005$ 的 `int` 数组（$c$ 和 $s$），共 $\approx32$ MB。但 $c$ 只在递推时用，且第 $i$ 行只依赖第 $i-1$ 行——**滚动一维数组**即可：让 `c[j]` 表示当前行的 $\binom ij\bmod k$，每轮执行 `for(j=i;j>=1;--j) c[j]=(c[j]+c[j-1])%k;`。

**为什么必须降序**：更新 $c[j]$ 时要用到"上一行的 $c[j-1]$"，若升序则 $c[j-1]$ 已被本行覆盖，算出来是错的。降序保证读到的 $c[j-1]$ 还是旧值（和 01 背包滚动数组同一个道理）。

**为什么 $c[i]$ 的初值 $0$ 恰好正确**：第 $i$ 行第一次写到第 $i$ 列时，$c[i]$ 还是全局默认的 $0$，而 $\binom{i-1}{i}=0$，正是需要的旧值；于是 $c[i]\leftarrow0+\binom{i-1}{i-1}=1$ ✓。这里的 $0$ 是**数学上正确的 $0$**，与第六步的"幽灵格子"是同一件事的两面：值本身没错，错的是把它当成合法数对去计数。

这样只剩 $s$ 一个二维数组：$2005^2\times4\approx16$ MB，安全。

### 第八步：边界与 $k=1$

- 前缀和用**下标平移**：`s[i+1][j+1]` 表示"前 $i+1$ 行、前 $j+1$ 列"的和，于是第 $0$ 行/第 $0$ 列天然表示"空前缀 $=0$"，全局默认 $0$ 恰好正确，不用写一堆 `i?…:0` 的三目。
- $k=1$：任何整数都被 $1$ 整除，答案就是数对总数 $\sum_{i=0}^n(\min(i,m)+1)$。代码里 `c[0]=1%k=0`，所有 $c[j]$ 恒 $0$，$b$ 在三角形内恒 $1$，自动给出正确结果，**不需要特判**。
- $c[j]<k\le21\Rightarrow c[j]+c[j-1]<42$，`int` 无溢出；$s$ 的最大值不超过数对总数 $\frac{2001\times2002}{2}\approx2\times10^6$，`int` 也够。

## 二、思维链：完整证明

**记号。** $N=2000$。$\binom ij$ 为组合数（$j>i$ 时定义为 $0$，$0!=1$）。$k\ge1$ 为整份数据固定的模数（子任务表给出 $2\le k\le21$；下文所有结论对任意 $k\ge1$ 成立）。$C_{i,j}=\binom ij\bmod k\in[0,k)$。程序的一维数组 `c[j]` 在第 $i$ 轮结束后存 $C_{i,j}$（$j\le i$），$j>i$ 处保持 $0$。指示函数

$$b[i][j]=\begin{cases}1,&j\le i\ \text{且}\ C_{i,j}=0\\0,&\text{否则}\end{cases}\qquad(0\le i,j\le N),$$

前缀和 $s[i+1][j+1]=\sum_{a=0}^{i}\sum_{b=0}^{j}b[a][b]$，且 $s[0][\cdot]=s[\cdot][0]=0$。询问 $(n,m)$ 的答案记 $A(n,m)$。

### 引理 1（Pascal 恒等式）

对 $1\le j\le i-1$：$\binom ij=\binom{i-1}{j-1}+\binom{i-1}{j}$；且 $\binom i0=\binom ii=1$，$j>i$ 时 $\binom ij=0$。

*证明*：设物品集合 $S=\{1,\dots,i\}$。把"$S$ 的 $j$ 元子集"按是否含元素 $i$ 分成两类：

- 含 $i$：去掉 $i$ 后是 $\{1,\dots,i-1\}$ 的 $j-1$ 元子集，且这个对应是双射（逆映射是"添上 $i$"），故有 $\binom{i-1}{j-1}$ 个；
- 不含 $i$：本身就是 $\{1,\dots,i-1\}$ 的 $j$ 元子集，有 $\binom{i-1}{j}$ 个。

两类互斥且穷尽，由加法原理得恒等式。边界：$j=0$ 时只有空集，$\binom i0=1$；$j=i$ 时只有全集，$\binom ii=1$；$j>i$ 时不存在 $j$ 元子集，$\binom ij=0$。证毕。

---

### 引理 2（模 $k$ 递推的正确性；不需要 $k$ 是素数）

定义 $C_{i,j}=\binom ij\bmod k$。则

$$C_{i,0}=C_{i,i}=1\bmod k,\qquad C_{i,j}=(C_{i-1,j-1}+C_{i-1,j})\bmod k\ (1\le j\le i-1).$$

*证明*：先证模运算对加法的同态性：对任意整数 $a,b$ 与 $k\ge1$，写 $a=q_1k+\alpha,b=q_2k+\beta$（$0\le\alpha,\beta<k$），则 $a+b=(q_1+q_2)k+(\alpha+\beta)$，再对 $\alpha+\beta$ 带余除法得 $(a+b)\bmod k=(\alpha+\beta)\bmod k=((a\bmod k)+(b\bmod k))\bmod k$。**这里只用了带余除法，对任意 $k\ge1$ 成立，与 $k$ 是否素数、是否可逆无关。**

对 $i$ 归纳。$i=0$：$\binom00=1$，$C_{0,0}=1\bmod k$ ✓。设第 $i-1$ 行全部正确。第 $i$ 行：$j=0$ 与 $j=i$ 由引理 1 的边界值得 $1\bmod k$ ✓；$1\le j\le i-1$ 时由引理 1，

$$C_{i,j}=\binom ij\bmod k=\bigl(\tbinom{i-1}{j-1}+\tbinom{i-1}{j}\bigr)\bmod k=(C_{i-1,j-1}+C_{i-1,j})\bmod k,$$

最后一步用同态性与归纳假设。证毕。

**对比阶乘路线为何失败**：$\binom ij=i!/(j!(i-j)!)$ 含除法，模 $k$ 下需要 $j!$ 与 $(i-j)!$ 可逆，即 $\gcd(j!,k)=1$。取 $k=4,j=2$：$\gcd(2,4)=2\ne1$，$2$ 在模 $4$ 下无逆元（$2x\bmod4\in\{0,2\}$ 恒不为 $1$），公式不可用。子任务表中 $k$ 取遍 $2..21$，其中合数占多数，故阶乘路线在本题**原则上不可行**，不是"实现麻烦"。

### 引理 3（一维滚动数组降序更新的不变量）

程序第 $i$ 轮执行 `for(j=i;j>=1;--j) c[j]=(c[j]+c[j-1])%k;`（`c[0]` 恒为 $1\bmod k$）。则第 $i$ 轮结束后，对所有 $0\le j\le i$ 有 `c[j]`$=C_{i,j}$；对所有 $j>i$ 有 `c[j]`$=0=C_{i,j}$。

*证明*：对 $i$ 归纳，维护不变量"第 $i-1$ 轮结束后 `c[j]`$=C_{i-1,j}$（$j\le i-1$），`c[j]`$=0$（$j>i-1$）"。

**基础** $i=0$：循环不执行（`j=0` 不满足 `j>=1`），`c[0]=1%k`$=C_{0,0}$ ✓，其余全局默认 $0=C_{0,j}$（$j>0$）✓。

**归纳步**：设第 $i-1$ 轮后不变量成立。第 $i$ 轮按 $j=i,i-1,\dots,1$ 的顺序更新：

- $j=i$：此前 `c[i]` 从未被写过（前 $i-1$ 轮只写 $j\le i-1$），故 `c[i]`$=0=C_{i-1,i}$；`c[i-1]`$=C_{i-1,i-1}$（尚未被本轮更新，因为降序）。于是新 `c[i]`$=(C_{i-1,i}+C_{i-1,i-1})\bmod k=(0+1)\bmod k=C_{i,i}$ ✓（与引理 2 的边界一致）。
- $j<i$：此刻 `c[j]` 与 `c[j-1]` 都**还没被本轮更新**（本轮只写过 $>j$ 的下标），故分别是 $C_{i-1,j}$ 与 $C_{i-1,j-1}$。新 `c[j]`$=(C_{i-1,j}+C_{i-1,j-1})\bmod k=C_{i,j}$ ✓（引理 2）。
- `c[0]` 不更新，恒为 $1\bmod k=C_{i,0}$ ✓。
- $j>i$ 的位置本轮不写，仍为 $0=C_{i,j}$ ✓。

**降序的必要性**：若升序（$j=1..i$），更新 `c[j]` 时 `c[j-1]` 已是本行的 $C_{i,j-1}$，算出的是 $C_{i-1,j}+C_{i,j-1}$，一般 $\ne C_{i,j}$。反例 $k$ 任意、$i=2,j=2$：升序先算 `c[1]`$=C_{1,1}+C_{1,0}=2$，再算 `c[2]`$=C_{1,2}+C_{2,1}=0+2=2$，而真值 $C_{2,2}=1$。故必须降序。证毕。

### 引理 4（计数区域 $=$ 三角形 $\cap$ 矩形；列上界可取 $\min(n,m)$）

对 $0\le n,m\le N$：

$$A(n,m)=\sum_{i=0}^{n}\sum_{j=0}^{\min(n,m)}b[i][j]=\sum_{i=0}^{n}\sum_{j=0}^{m}b[i][j].$$

*证明*：题目定义的计数集合是 $T=\{(i,j):0\le i\le n,\ 0\le j\le\min(i,m),\ k\mid\binom ij\}$。

**第一步：拆解 $\min$。** 对整数 $j\ge0$，$j\le\min(i,m)\iff(j\le i)\land(j\le m)$（$\min$ 的定义：不大于两者且是两者中最大的下界）。故

$$T=\{(i,j):0\le i\le n,\ 0\le j\le m,\ j\le i,\ C_{i,j}=0\}.$$

**第二步：用 $b$ 吸收三角形约束。** 由 $b$ 的定义，$b[i][j]=1$ 当且仅当 $j\le i$ 且 $C_{i,j}=0$。故上式右端的条件恰为"$0\le i\le n,0\le j\le m,b[i][j]=1$"，于是 $|T|=\sum_{i=0}^n\sum_{j=0}^m b[i][j]$。

**第三步：列上界收缩。** 断言：对 $0\le i\le n$，$\min(i,m)=\min(i,\min(n,m))$。分两种情形：

- $m\le n$：$\min(n,m)=m$，两边都是 $\min(i,m)$ ✓。
- $m>n$：$\min(n,m)=n\ge i$，故右边 $=\min(i,n)=i$；左边 $\min(i,m)=i$（因 $i\le n<m$）✓。

因此 $j\le\min(i,m)\iff j\le\min(i,\min(n,m))$，把第二步中的 $m$ 换成 $\min(n,m)$ 得到同样的集合，故两个和式相等。证毕。

**推论**：询问答案就是 $s[n+1][\min(n,m)+1]$。即使直接用 $s[n+1][m+1]$ 也对（$m\le N$ 在数组范围内，且 $j>n\ge i$ 的列上 $b=0$），但 $\min(n,m)$ 更紧、语义更贴合题意。

### 引理 5（二维前缀和递推与边界）

程序 `s[i+1][j+1]=s[i][j+1]+s[i+1][j]-s[i][j]+b[i][j]`，配合全局默认的 $s[0][\cdot]=s[\cdot][0]=0$，则对所有 $0\le i,j\le N$：

$$s[i+1][j+1]=\sum_{a=0}^{i}\sum_{b=0}^{j}b[a][b].$$

*证明*：记 $R(i,j)=\sum_{a=0}^{i}\sum_{b=0}^{j}b[a][b]$（$i,j\ge0$），并约定 $i<0$ 或 $j<0$ 时 $R=0$（空和）。

**容斥恒等式**：矩形 $[0,i]\times[0,j]$ 可写成三块的容斥：

$$R(i,j)=R(i-1,j)+R(i,j-1)-R(i-1,j-1)+b[i][j].$$

理由：$R(i-1,j)$ 覆盖"去掉最后一行"的部分，$R(i,j-1)$ 覆盖"去掉最后一列"的部分，两者之并覆盖了除 $(i,j)$ 外的全部格子，而交集 $[0,i-1]\times[0,j-1]$ 被算了两次，故减去一次 $R(i-1,j-1)$，最后补上角格 $b[i][j]$。逐格核对：对 $(a,b)$ 若 $a<i,b<j$，系数 $1+1-1=1$ ✓；若 $a=i,b<j$，系数 $0+1-0=1$ ✓；若 $a<i,b=j$，系数 $1+0-0=1$ ✓；若 $a=i,b=j$，系数 $0+0-0+1=1$ ✓。每格恰算一次。

**归纳**：对 $i+j$ 归纳。$i+j=0$：$s[1][1]=s[0][1]+s[1][0]-s[0][0]+b[0][0]=b[0][0]=R(0,0)$ ✓（边界 $s[0][\cdot]=s[\cdot][0]=0$ 由全局零初始化提供，语义是"空前缀的和为 $0$"，正确）。设 $i+j-1$ 时成立，则 $s[i][j+1]=R(i-1,j)$、$s[i+1][j]=R(i,j-1)$、$s[i][j]=R(i-1,j-1)$（三者的下标和都是 $i+j-1$），代入容斥恒等式即得 $s[i+1][j+1]=R(i,j)$ ✓。证毕。

**计算顺序的合法性**：程序按 $i$ 升序、$j$ 升序填表，所需的三个格子下标和都更小，已在本轮之前算好，无循环依赖。

---

### 引理 6（$j>i$ 的格子必须排除；否则答案偏大）

若把 $b[i][j]$ 误定义为"$c[j]==0$"（不带 $j\le i$），则存在合法询问使输出错误。

*证明*：由引理 3，第 $i$ 轮时 $j>i$ 处 `c[j]`$=0$。取 $k=2,n=1,m=1$：

- 正确定义：$b[0][0]=[\,C_{0,0}=1\ne0\,]=0$，$b[1][0]=0$，$b[1][1]=[\,C_{1,1}=1\ne0\,]=0$，其余格子在矩形 $[0,1]^2$ 外或 $j>i$。故 $A(1,1)=0$。
- 错误定义：第 $0$ 轮时 `c[1]`$=0$，于是 $b[0][1]$ 被误置 $1$。矩形 $[0,1]\times[0,1]$ 的和变成 $1$，输出 $1\ne0$。

而 $(0,1)$ 这个数对根本不满足题目的 $j\le\min(i,m)=0$，不该被计数。故 $j\le i$ 是正确性条件。证毕。

**注**：这与"全局数组默认 $0$"的移植坑同源但不同质：这里 $0$ 的**数值**是对的（$\binom ij=0$ 当 $j>i$），错的是**把三角形外的格子当成合法数对**。所以修法是加 $j\le i$ 的判断，而不是把数组填成 `inf`。

---

### 引理 7（取值范围、$k=1$ 与溢出）

(a) 全程 `c[j]`$\in[0,k)$，`c[j]+c[j-1]`$<2k\le42$（子任务 $k\le21$），`int` 无溢出；即使 $k$ 放大到 $10^9$，$2k<2^{31}$ 仍安全。
(b) $s$ 的任意格子 $\le$ 数对总数 $\le\frac{(N+1)(N+2)}{2}=2003001<2^{31}$，`int` 足够。
(c) $k=1$ 时程序自动给出"所有数对都计数"的正确结果，无需特判。

*证明*：(a) 由引理 2、3，`c[j]` 是模 $k$ 的余数，故 $0\le$`c[j]`$\le k-1$，两数之和 $\le2k-2$。$k\le21$ 时 $\le40$；$k\le10^9$ 时 $\le2\times10^9-2<2147483647$ ✓。

(b) $b[i][j]\in\{0,1\}$ 且仅在 $j\le i$ 处可能为 $1$，故 $s[i+1][j+1]\le\#\{(a,b):0\le a\le i,\ 0\le b\le\min(a,j)\}\le\sum_{a=0}^{N}(a+1)=\frac{(N+1)(N+2)}2=2003001$ ✓。

(c) $k=1$ 时任何整数 $x$ 都有 $x\bmod1=0$，故 $C_{i,j}=0$ 恒成立，$b[i][j]=[j\le i]$。于是 $A(n,m)=\#\{(i,j):i\le n,j\le\min(i,m)\}=\sum_{i=0}^n(\min(i,m)+1)$，正是"全部数对"。程序中 `c[0]=1%1=0`，递推 `(0+0)%1=0`，与之一致 ✓。证毕。

---

### 引理 8（复杂度）

时间 $O(N^2+t)$，空间 $O(N^2)$，$N=2000$。

*证明*：预处理外层 $i$ 跑 $N+1$ 轮；内层 Pascal 更新第 $i$ 轮 $i$ 次，总 $\sum_{i=0}^{N}i=\frac{N(N+1)}2\approx2\times10^6$ 次加法取模；前缀和每轮 $N+1$ 格，总 $(N+1)^2\approx4\times10^6$ 次常数次整数运算。询问 $t$ 次，每次一次读入、一次 `min`、一次查表、一次输出，$O(t)$。合计 $O(N^2+t)\approx4\times10^6$，远低于 $1$ s 时限。

空间：`s` 为 $(N+5)^2$ 个 `int`$=2005^2\times4\approx16.1$ MB；`c` 为 $N+5$ 个 `int`（$8$ KB）。**只用一个二维数组**（滚动了杨辉三角），比"$c$ 与 $s$ 都二维"的 $32$ MB 省一半。证毕。

---

### 定理

程序对每组询问输出满足 $0\le i\le n,0\le j\le\min(i,m),k\mid\binom ij$ 的数对个数。

*证明*：引理 1、2 保证杨辉三角模 $k$ 递推给出正确的 $C_{i,j}$（且避开合数模下不可逆的除法）；引理 3 保证一维滚动降序实现与二维递推等价；引理 6 保证三角形外的格子被排除；引理 4 保证计数区域等于矩形前缀和、列上界取 $\min(n,m)$；引理 5 保证前缀和递推与边界正确；引理 7 保证无溢出且 $k=1$ 自动正确；引理 8 给出复杂度。故 `s[n+1][min(n,m)+1]` 即答案。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — $t=10^4$ 而 $n,m\le2000$、且 $k$ 整份数据固定 ⇒ 一次预处理 + $O(1)$ 询问是唯一出路。
2. **consider easier version** — 先想"算出 $\binom ij$ 再判整除"：$\binom{2000}{1000}$ 约 $600$ 位，任何整数类型都装不下。
3. **discuss by category** — 改走阶乘公式模 $k$：$k$ 是合数（$4,6,8,9,\dots$），$j!$ 不可逆，$k=4,j=2$ 即反例 ⇒ 除法路线原则性失败。
4. **classic problem solution** — 杨辉三角 $\binom ij=\binom{i-1}{j-1}+\binom{i-1}{j}$：只用加法，模任意 $k$ 封闭，值域 $<k$。
5. **reduce to easier problem** — "$k\mid\binom ij$" $\iff$ "$C_{i,j}=0$"，整除判定塌缩成"数零"。
6. **classic problem solution** — 二维前缀和把区域计数降到 $O(1)$；三角形约束写进指示函数 $b[i][j]=[j\le i\land C_{i,j}=0]$，矩形求和自动忽略三角形外。
7. **explore its property** — $j>i$ 处 $c=0$ 是"幽灵格子"：数值对但数对不合法，必须用 $j\le i$ 排除（$k=2,n=m=1$ 反例）。
8. **classic problem solution** — 滚动一维杨辉三角，降序更新（01 背包同款理由），二维数组只留前缀和，内存 $32\to16$ MB。
9. **discuss by category** — 前缀和下标平移 $+1$ 让零边界天然正确；列上界 $\min(n,m)$；$k=1$ 无需特判。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $t,k$ | 询问组数、模数（整份数据固定） | `int` | 读入；子任务 $2\le k\le21$，代码对任意 $k\ge1$ 正确 |
| $n,m$ | 每组询问的行/列上界 | `int` | 读入；$0\le n,m\le2000$ |
| `mxv` | 预处理上界 $N=2000$ | `constexpr int` | 行、列都递推到 $2000$ |
| `mxn` | 数组尺寸 $2005$ | `constexpr int` | $N+5$ 松弛；前缀和用到下标 $2001$ |
| `c[j]` | 滚动行：当前 $i$ 的 $\binom ij\bmod k$ | `int[mxn]` | `c[0]=1%k`；$j>i$ 处保持 $0$（数学上正确，但**不可计数**） |
| `s[i+1][j+1]` | $\sum_{a\le i}\sum_{b\le j}b[a][b]$，即"前 $i+1$ 行前 $j+1$ 列的合法数对数" | `int[mxn][mxn]` | 第 $0$ 行/列全局默认 $0$ = 空前缀；**下标平移 $+1$** |
| $b[i][j]$ | 指示函数：$j\le i$ 且 $\binom ij\equiv0\pmod k$ | 表达式，不落地 | `(j<=i&&c[j]==0)`，$j\le i$ 是正确性条件 |
| 输出 | $A(n,m)$ | `int` | `s[n+1][min(n,m)+1]`，$\le2003001$ |

### 算法步骤

1. I/O 加速三行；读 `t,k`；`c[0]=1%k`。
2. 对 $i=0..N$：
   - 降序 $j=i..1$：`c[j]=(c[j]+c[j-1])%k`（滚动杨辉三角）；
   - 对 $j=0..N$：`s[i+1][j+1]=s[i][j+1]+s[i+1][j]-s[i][j]+(j<=i&&c[j]==0)`。
3. 每组询问读 `n,m`，输出 `s[n+1][min(n,m)+1]`。

### 复杂度

- 时间：$O(N^2+t)\approx4\times10^6+10^4$，其中 Pascal 更新约 $2\times10^6$ 次、前缀和约 $4\times10^6$ 格。
- 空间：$O(N^2)$，`s` 约 $16.1$ MB（杨辉三角已滚动成一维）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例 1 说明（$k=2,n=m=2$ 只有 $\binom21$）输出 `1` 吻合；$8$ 组手造数据（含幽灵格子反例 $k=2,n=m=1$、$m\gg n$、$k=1$、$n=m=0$、$k=3$）与手算一致；另做两类独立交叉验证：$k=2,3,5$（素数）用 Lucas 定理逐对判定、$k=6,21$（合数）用精确 BigInt 组合数，$n=m=2000$ 全量区域结果完全一致；$k=2..21$ 各 $20$ 组随机询问（共 $400$ 组，$n,m\le60$）与精确 BigInt 杨辉三角 + 独立前缀和 $0$ 处不一致；$t=10^4$ 全极限询问瞬间完成。本题是"杨辉三角 + 二维前缀和"的标准组合，证明已闭合，不建对拍附录。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2822 [NOIP 2016 提高组] 组合数问题
// k 多为合数 ⇒ 阶乘+逆元不可行；杨辉三角只用加法，模任意 k 封闭
// 整份数据 k 固定 ⇒ 一次预处理"是否被 k 整除"的二维前缀和，询问 O(1)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005},mxv{2000};

int t,k,c[mxn],s[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>t>>k;
	c[0]=1%k;					// k=1 时为 0，全部数对都计数，无需特判
	for(int i=0;i<=mxv;++i)
	{
		for(int j=i;j>=1;--j)
			c[j]=(c[j]+c[j-1])%k;		// 必须降序：c[j-1] 要保留上一行的值
		for(int j=0;j<=mxv;++j)
			s[i+1][j+1]=s[i][j+1]+s[i+1][j]-s[i][j]+(j<=i&&c[j]==0);
			// j<=i 不能省！j>i 处 c=0 是"幽灵格子"，不是合法数对
	}
	for(int i=0,n,m;i<t;++i)
	{
		cin>>n>>m;
		cout<<s[n+1][min(n,m)+1]<<'\n';	// 前缀和下标平移 +1，零边界天然正确
	}
	return 0;
}
```

### 代码说明

- **只有一个二维数组**：杨辉三角用一维 `c` 滚动（第 $i$ 行只依赖第 $i-1$ 行），把内存从 $32$ MB 压到 $16$ MB。`s` 必须二维，因为询问的 $(n,m)$ 任意。
- **降序更新**是滚动数组的命门：升序会让 `c[j-1]` 提前变成本行值，算出 $C_{i-1,j}+C_{i,j-1}$ 这种错东西（引理 3 给了 $i=2$ 的反例）。
- **`c[i]` 的初值 $0$ 恰好正确**：第 $i$ 行首次写第 $i$ 列时，`c[i]` 还是全局 $0$，正是 $\binom{i-1}{i}=0$，于是得到 $\binom ii=1$。这里依赖零初始化是**数学正确**的，与"未初始化当 INF 用"的坑不同。
- **`(j<=i&&c[j]==0)`** 里的 `j<=i` 是正确性的一半：$j>i$ 的格子值为 $0$ 但不是合法数对，漏掉这个判断会在 $k=2,n=m=1$ 这种小数据上就输出 $1$ 而非 $0$。
- **下标平移**：`s[i+1][j+1]` 表示前 $i+1$ 行、前 $j+1$ 列，于是 `s[0][*]`、`s[*][0]` 表示空前缀，全局默认 $0$ 正好，省掉所有边界三目。
- **列上界 `min(n,m)`**：$m$ 可以远大于 $n$（子任务有 $n\le25,m\le2000$ 档），取 $\min$ 既贴合题意又保证不越界；由引理 4 它与取 $m$ 等价。
- `c[j]<k\le21`，相加 $<42$；`s` 最大 $\le2003001$，全程 `int` 安全，不需要 `i64`。
- 预处理与询问分离：$k$ 在第一行给出且整份数据不变，所以 $4\times10^6$ 的预处理只做一次，$10^4$ 次询问各 $O(1)$。
