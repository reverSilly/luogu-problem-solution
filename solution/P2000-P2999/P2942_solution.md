# P2942 [USACO09MAR] Moon Mooing G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 给定初始整数 $c$（$1\le c\le 100$）与两个映射

$$f_1(x)=\left\lfloor\frac{a_1x}{d_1}\right\rfloor+b_1,\qquad f_2(x)=\left\lfloor\frac{a_2x}{d_2}\right\rfloor+b_2,$$

其中 $1\le d_i<a_i\le 20$，$0\le b_i\le 20$。从 $\{c\}$ 出发，不断把已有元素代入 $f_1,f_2$ 生成新元素，得到一个集合 $S$（对两个映射封闭、含 $c$ 的最小集合）。把 $S$ 排序、去重，输出**第 $N$ 小**的元素（$1\le N\le 4\times 10^6$）。题目保证所有哞叫时长 $<2^{63}$，内存限制 $64$ MB。

**输入顺序陷阱**：第二、三行是 `a1 b1 d1` 与 `a2 b2 d2`——$b$ 在 $d$ **前面**，和公式里 $a,d,b$ 的书写顺序不同，读入写反就全错。

先把两处题意口径钉死：

1. **"第 $N$ 次哞叫"= 第 $N$ 小的不同时长。** 英文原文说"排序、去重后取前 $N$ 个作为 $N$ 次哞叫的时长，求最长的一次"，中文说"取前 $N$ 个整数……计算第 $N$ 次哞叫的时长"。两种说法一致：答案就是 $S$ 的第 $N$ 小元素。题面样例（$c=3,N=10$，$f_1(x)=\lfloor 4x/3\rfloor+3$，$f_2(x)=\lfloor 17x/2\rfloor+8$）列出前 $10$ 个时长 $3,7,12,19,28,33,40,47,56,65$，答案 $65$，正是第 $10$ 小。
2. **$S$ 至少要有 $N$ 个元素。** 注意 $f_i(x)$ **未必严格大于 $x$**：例如 $a=3,d=2,b=0,x=1$ 时 $f(1)=\lfloor 3/2\rfloor=1$，是"不动点"。极端地，若两个映射把所有可达值都映回自身，$S$ 就是有限集。题目既然要求输出第 $N$ 个时长，就隐含保证 $|S|\ge N$；我按此口径实现（下面引理 4 会说明不动点只可能出现在 $x\le 18$ 的极小值处，但它确实存在，去重逻辑必须处理）。

**数据范围否掉两条朴素路线：**

- **BFS 生成 + 排序**：每个元素分裂出两个后代，生成前 $N$ 个要展开指数级多的候选，不可行。
- **优先队列 + 判重集合**：每次弹出最小、压入两个像，$O(N\log N)$ 看似可行，但 $N=4\times 10^6$ 时堆里常驻百万级 $64$ 位整数，再加一个判重 `set`（红黑树节点开销数倍于裸数组），$64$ MB 内存限制直接爆掉；时间上 $4\times 10^6\times\log$ 次堆调整也悬。

所以必须找 **$O(N)$ 时间、裸数组存储**的做法。

**手造小数据核对**（题面自带一组样例，另造两组打边界）：

第一组（题面样例）：`3 10 / 4 3 3 / 17 8 2`，前 $10$ 个时长 $3,7,12,19,28,33,40,47,56,65$，答案 $65$。注意第 $6$ 个 $33=f_2(3)$ 插进了 $f_1$ 链的 $28$ 与 $40$ 之间——**两条链是交错归并的，不是各跑各的**。

第二组（专打不动点）：`1 5 / 3 0 2 / 2 0 1`，即 $f_1(x)=\lfloor 3x/2\rfloor$，$f_2(x)=2x$，$c=1$。$f_1(1)=1$ 是重复值必须丢弃；$S$ 排序后开头是 $1,2,3,4,6,8,9,12,\dots$（$3=f_1(2)$，$4=f_1(3)=f_2(2)$ 撞值去重），第 $5$ 个是 $6$。

第三组（$N=1$）：`7 1 / 4 3 3 / 17 8 2`，答案就是 $c=7$，一次映射都不用做。

## 二、思维链：完整证明

**记号。** $S$ 是含 $c$、对 $f_1,f_2$ 封闭的最小集合：$S=\{f_w(c):w\text{ 是 }\{1,2\}\text{ 上的有限字}\}$，其中 $f_w$ 表示按字 $w$ 依次复合（空字给出 $c$）。把 $S$ 升序排列为 $s_0<s_1<s_2<\cdots$（去重后严格递增）。目标是 $s_{N-1}$。

### 第一步：探索两个映射的性质

**探索性质。** 归并类算法（丑数、Hamming 数）能成立，靠的是"生成函数单调递增"。先验证本题的 $f_i$ 有没有这个性质——有 floor 和加法，不能想当然。

### 引理 1（单调性与不减性）

对 $i\in\{1,2\}$：

(a) $f_i$ 在整数上**严格递增**：$y>x\ge 0\Rightarrow f_i(y)>f_i(x)$；
(b) $f_i(x)\ge x$ 对所有 $x\ge 0$ 成立。

*证明*：(a) 记 $a=a_i,d=d_i,b=b_i$。$\frac{ay}{d}-\frac{ax}{d}=\frac{a(y-x)}{d}\ge\frac{a}{d}>1$（因 $y-x\ge 1$、$a>d$）。对实数 $u>v+1$，有 $\lfloor u\rfloor\ge\lfloor v\rfloor+1$：因为 $u>v+1\ge\lfloor v\rfloor+1$，而 $\lfloor v\rfloor+1$ 是整数且严格小于 $u$，故不超过 $\lfloor u\rfloor$。于是 $\lfloor ay/d\rfloor\ge\lfloor ax/d\rfloor+1$，加同一个 $b$ 后 $f_i(y)\ge f_i(x)+1>f_i(x)$ ✓。

(b) $a>d\ge 1$ 且 $x\ge 0$，故 $\frac{ax}{d}\ge x$，取 floor 不减到 $x$ 以下（$x$ 是整数）：$\lfloor ax/d\rfloor\ge x$；再加 $b\ge 0$ 得 $f_i(x)\ge x$ ✓。证毕。

**推论**：单映射情形（只有 $f_1$）的 $S=\{c,f_1(c),f_1(f_1(c)),\dots\}$ **迭代一次就天然有序**（由 (a)(b)），根本不用排序。这提示：两个映射的 $S$ 也许是"两条有序流的归并"。

### 第二步：关键结构——每个新元素都有更小的原像

**碰壁。** 想直接归并两条流 $f_1(s_0),f_1(s_1),\dots$ 与 $f_2(s_0),f_2(s_1),\dots$，立刻遇到一个逻辑缺口：归并只能生成"已排好序的前缀的像"，但 $S$ 里会不会有某个元素，它的原像排在很后面、以至于双指针永远追不上？换句话说，**按升序生成时，下一个元素的原像一定已经在已生成的前缀里吗？** 这需要证明，不能靠直觉。

### 引理 2（严格原像引理）

对任意 $v\in S\setminus\{c\}$，存在 $z\in S$，$z<v$，使得 $v=f_1(z)$ 或 $v=f_2(z)$。

*证明*：$v\in S$ 意味着存在有限字 $w=i_k i_{k-1}\cdots i_1$（$i_j\in\{1,2\}$，$k\ge 1$，先作用 $f_{i_1}$）使 $v=f_{i_k}(\cdots f_{i_1}(c)\cdots)$。定义部分复合值 $v_0=c$，$v_j=f_{i_j}(v_{j-1})$（$1\le j\le k$），则 $v_k=v$。由引理 1(b)，$v_0\le v_1\le\cdots\le v_k$。

因 $v\ne c$，有 $v_k>v_0$。取**最小**的 $j^\*$ 使 $v_{j^\*}=v$（序列单调不减且末项为 $v$，这样的 $j^\*$ 存在且 $j^\*\ge 1$）。由最小性，$v_{j^\*-1}\ne v$，结合单调性得 $v_{j^\*-1}<v$。令 $z=v_{j^\*-1}$：它是 $c$ 经有限次映射得到的，故 $z\in S$；且 $v=v_{j^\*}=f_{i_{j^\*}}(z)$，$z<v$。证毕。

**这条引理是双指针归并合法性的地基**：它保证升序枚举时，$s_{t+1}$ 的原像 $z<s_{t+1}$ 必然落在已枚举的前缀 $\{s_0,\dots,s_t\}$ 里（因为 $z\in S$ 且 $z<s_{t+1}$，而前缀恰是 $S$ 中 $\le s_t$ 的全部元素）。于是"下一个元素"一定能从"前缀的像"里找到，不存在追不上的元素。

### 第三步：归约到丑数式双指针归并

**归约。** 把 $S$ 看成两条流的并：$\{f_1(s_j)\}_{j\ge 0}$ 与 $\{f_2(s_j)\}_{j\ge 0}$（由引理 2，$S\setminus\{c\}$ 的每个元素都出现在至少一条流里；反过来流里的值都属于 $S$）。由引理 1(a)，每条流随 $j$ 严格递增——**两条有序流的归并**，正是丑数问题的结构。维护两个指针 $p_1,p_2$ 指向各流"第一个尚未被取用的候选"，每次取较小者 append，并把指针推过所有 $\le$ 新值的候选（去重 + 撞值同步）。

### 引理 3（归并不变量与正确性）

算法：$s[0]\gets c$，$p_1=p_2=0$。对 $i=0,1,\dots,N-1$：

- 若 $i>0$：令 $x=\bigl(p_1<i\bigr)?\,f_1(s[p_1]):\infty$，$y=\bigl(p_2<i\bigr)?\,f_2(s[p_2]):\infty$，置 $s[i]\gets\min(x,y)$；
- 然后对 $k=1,2$：`while(p_k<=i && f_k(s[p_k])<=s[i]) ++p_k;`

则对每个 $t<N$，迭代 $t$ 结束后：

(i) $s[0]<\cdots<s[t]$ 恰为 $S$ 的 $t+1$ 个最小元素（即 $s[j]=s_j$）；
(ii) $p_k$ 是满足 $f_k(s[j])>s[t]$ 的最小下标 $j\in[0,t]$；若不存在则 $p_k=t+1$（"流暂时枯竭"）。

*证明*：对 $t$ 归纳。

**基础 $t=0$**：$c$ 是 $S$ 的最小元——任何 $f_w(c)\ge c$（引理 1(b) 逐次复合），且 $c\in S$。故 (i) 成立。两个 while 把 $p_k$ 推过所有 $f_k(s[j])\le c$ 的下标；因 $f_k(s[j])\ge s[j]$ 且目前只有 $j=0$，循环至多执行一次，结束后 (ii) 成立（$p_k\in\{0,1\}$）。

**归纳步**：设迭代 $t-1$ 后 (i)(ii) 成立（$t\ge 1$）。迭代 $t$ 先取候选：由 (ii)，凡 $p_k<t$ 时候选 $f_k(s[p_k])>s[t-1]$ 且属于 $S$；$p_k=t$ 意味着前缀里没有 $>s[t-1]$ 的像，记 $\infty$。令 $v=\min(x,y)$。

**证 $v=s_t$（$S$ 中第 $t+1$ 小）**，双向夹逼：

- $v\ge s_t$：若 $v=\infty$ 则两条流在前缀里都没有 $>s[t-1]$ 的像，由引理 2，$s_t$ 的原像 $z<s_t$ 必在前缀中且 $f_k(z)=s_t>s[t-1]$，矛盾——故 $S$ 枯竭，与 $|S|\ge N$ 的题设矛盾，$v$ 必为有限值。有限的 $v$ 是 $S$ 中 $>s[t-1]$ 的元素，而 $s_t$ 是其中最小者，故 $v\ge s_t$。
- $v\le s_t$：由引理 2，$s_t=f_k(z)$，$z\in S$，$z<s_t$。于是 $z\le s_{t-1}=s[t-1]$，即 $z=s[j]$ 某个 $j\le t-1$。又 $f_k(s[j])=s_t>s[t-1]$，由 (ii) 得 $p_k\le j\le t-1<t$，候选有限；由引理 1(a) 单调性，$f_k(s[p_k])\le f_k(s[j])=s_t$。故 $v=\min(x,y)\le f_k(s[p_k])\le s_t$。

夹逼得 $v=s_t$ ✓，且 $s[t]=s_t>s_{t-1}=s[t-1]$，(i) 扩展到 $t$。

**while 重建 (ii)**：循环条件 $p_k\le t$ 保证只访问已定义的 $s[0..t]$；每次 $f_k(s[p_k])\le s[t]$ 就前进。终止性：$f_k(s[j])\ge s[j]$，而 $s$ 严格递增，故满足 $s[j]\le s[t]$ 的 $j$ 只有 $0..t$ 有限个，循环必停。停时 $p_k$ 恰是 $[0,t]$ 中第一个 $f_k(s[j])>s[t]$ 的下标，或 $t+1$（不存在）——(ii) 成立。注意 $p_k$ 可能从上轮的 $t$（枯竭态）被重新激活：新 append 的 $s[t]$ 若满足 $f_k(s[t])>s[t]$，while 不动，下轮 $p_k=t<t+1$ 候选恢复有限；若 $f_k(s[t])=s[t]$（不动点），while 再推一格到 $t+1$，继续枯竭态。两种情况都被统一处理。证毕。

**去重与撞值**：若 $x=y$，append 一次后两个 while 都把各自指针推过该值，不会重复 append；若某候选恰好等于 $s[t-1]$（不动点像），它在上一轮已被 while 推过，不会再次成为候选。故输出严格递增、无重复。

### 第四步：不动点到底长什么样？——指针越界守卫的必要性

**碰壁反例。** 若没有 `p_k<i` 守卫与 $\infty$ 哨兵，直接写 `x=f1(s[p1])`：当 $f_1(s[t])=s[t]$（不动点）时 while 会把 $p_1$ 推到 $t+1$，下一轮读到**尚未赋值的** $s[t+1]$（全局默认 $0$），算出 $f_1(0)=b_1$ 这种垃圾候选——程序不崩，答案静默出错。这是"全局数组默认 0 不是 INF"陷阱的又一形态。那么不动点真的会出现吗？

### 引理 4（不动点的范围）

若 $f_i(x)=x$（$x\ge 0$ 整数），则 $b_i=0$ 且 $x(a_i-d_i)<d_i$；特别地 $x\le d_i-1\le 18$。从而 $x\ge 20$ 时恒有 $f_i(x)>x$。

*证明*：$f_i(x)=x$ 即 $\lfloor ax/d\rfloor+b=x$，故 $\lfloor ax/d\rfloor=x-b\le x$，于是 $ax/d<x+1$（否则 floor $\ge x+1$），整理得 $x(a-d)<d$。因 $a-d\ge 1$，$x<d/(a-d)\le d\le 19$，即 $x\le 18$。又 $\lfloor ax/d\rfloor\ge x$（引理 1(b) 的中间结论）且 $b\ge 0$，等号 $f_i(x)=x$ 要求 $b=0$。逆否：$x\ge 20>d-1$ 时 $f_i(x)\ne x$，结合 $f_i(x)\ge x$ 得 $f_i(x)>x$。证毕。

**结论**：枯竭态只可能在值 $\le 18$ 的开局阶段出现（例如 $c=1,a=3,d=2,b=0$），但**确实会出现**，守卫与哨兵不可省。实现取 $\infty=2^{100}$（`i128`），远大于任何真实候选（引理 5），不会与真实值混淆；只要 $|S|\ge N$，$\min(x,y)$ 永远不会真的取到 $\infty$（引理 3 已证）。

### 第五步：值域与内存——两条独立的溢出线

**探索性质。** 题目说"时长 $<2^{63}$"，但**候选值**（指针指向的像）完全可能 $\ge 2^{63}$：答案 $s_{N-1}$ 接近 $2^{63}$ 时，$f_1(s[p_1])$ 可达 $20\times 2^{63}$，用 `long long` 算候选会溢出成负数，`min` 就会选中垃圾。必须把"存储"与"计算"分开对待。

### 引理 5（值域与内存）

(a) 所有被存储的 $s[i]$（$i<N$）满足 $0<s[i]<2^{63}$，`i64` 安全；
(b) 所有候选 $f_k(s[j])\le 20\cdot(2^{63}-1)+20<2^{68}$，用 `__int128` 计算无溢出；哨兵 $2^{100}$ 大于一切真实候选；
(c) 数组 `s` 占 $4000005\times 8$ B $\approx 32$ MB $\le 64$ MB。

*证明*：(a) 题设"没有哞叫时长 $\ge 2^{63}$"，前 $N$ 个时长都是哞叫时长，故 $s[i]<2^{63}$；$c\ge 1$ 且 $f_k$ 保持正性，故 $>0$。`i64` 上限 $2^{63}-1$ 恰好装下。(b) $a_k\le 20,d_k\ge 1,b_k\le 20$，$f_k(x)=\lfloor a_kx/d_k\rfloor+b_k\le 20x+20$；代入 $x\le 2^{63}-1$ 得 $\le 20\cdot 2^{63}-20+20=20\cdot 2^{63}<2^{68}$（$20<2^5$）。`__int128` 上限 $2^{127}-1$，余量 $2^{59}$ 倍。中间乘法 $(i128)a_k\cdot x$ 先转 $128$ 位再乘，杜绝 `i64` 中间量溢出。(c) 直接计算。证毕。

### 引理 6（复杂度）

时间 $O(N)$，空间 $O(N)$。

*证明*：主循环 $N$ 轮，每轮常数次 $f_k$ 求值（`__int128` 乘除是常数时间）；两个指针各自从 $0$ 单调前进到 $\le N$，while 的总执行次数 $\le 2(N+1)$，摊还 $O(1)$ 每轮。故总时间 $O(N)$。空间只有 `s` 数组 $O(N)$（引理 5(c)）。对比优先队列做法的 $O(N\log N)$ 时间与数倍内存，双指针在 $N=4\times 10^6$、$64$ MB 下是唯一稳妥选择。证毕。

### 定理

程序输出 $S$ 的第 $N$ 小元素，时间 $O(N)$、空间 $32$ MB。

*证明*：引理 1 保证两条流有序、迭代不减；引理 2 保证升序枚举无遗漏（每个新元素的原像已在前缀中）；引理 3 的归纳不变量保证每轮 append 的恰是下一个最小元素、去重正确、指针枯竭态被哨兵安全处理；引理 4 说明枯竭态真实存在、守卫必要；引理 5 保证存储与计算全程无溢出、内存达标；引理 6 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — $f_i$ 严格递增（斜率 $a/d>1$ 跨过 floor）且 $f_i(x)\ge x$；输入顺序是 `a b d` 不是 `a d b`。
- consider easier version — 只有一个映射时迭代天然有序；两个映射 = 两条有序流的并。
- explore its property — 严格原像引理：$S\setminus\{c\}$ 的每个元素都有**更小**的原像 ⇒ 升序生成时原像必在已生成前缀里，双指针不会漏。
- reduce to easier problem — 归约到丑数（Hamming 数）式双指针归并：取两候选较小者 append，指针推过所有 $\le$ 新值者。
- classic problem solution — 双指针归并 $O(N)$ 时间、裸数组 $32$ MB，替代 $O(N\log N)$ 且爆内存的堆 + 判重集合。
- discuss by category — 不动点 $f(x)=x$（仅 $x\le 18$）会让指针越界：`p<i` 守卫 + $2^{100}$ 哨兵；两流撞值时双指针同推实现去重。
- explore its property — 两条溢出线分开处理：存储值 $<2^{63}$ 用 `i64`，候选可达 $20\cdot 2^{63}$ 用 `__int128` 计算。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `c` | 初始时长，$1\le c\le 100$ | `i64` | 读入；`s[0]=c` |
| `n` | 哞叫次数，$\le 4\times 10^6$ | `int` | 读入；答案 `s[n-1]` |
| `a1,b1,d1` / `a2,b2,d2` | 两个映射的常数 | `int` | 读入顺序 **a b d** |
| `s[i]` | $S$ 的第 $i+1$ 小元素（0-based） | `i64[mxn]` | `s[0]=c`，其余归并生成；**存储值 $<2^{63}$** |
| `p1,p2` | 两条流的前沿指针 | `int`，初值 $0$ | 指向第一个 $>s[i]$ 的候选下标；可越界到 $i+1$（枯竭态） |
| `f1(x),f2(x)` | 映射，$\lfloor ax/d\rfloor+b$ | `i128(i64)` | **先转 `i128` 再乘**，候选可达 $2^{68}$ |
| `inf` | 候选哨兵 $2^{100}$ | `constexpr i128` | 枯竭态占位，大于一切真实候选 |
| `mxn` | $4000000+5$ | `constexpr int` | `s` 尺寸，$32$ MB |

### 算法步骤

1. I/O 加速三行；读 `c,n` 与两组 `a b d`。
2. `s[0]=c`，`p1=p2=0`。
3. 对 $i=0..n-1$：若 $i>0$，取候选 $x=[p_1<i]\,f_1(s[p_1])$ 否则 $\infty$，$y$ 同理，`s[i]=min(x,y)`（转回 `i64`）。
4. 两个 while：`p_k<=i && f_k(s[p_k])<=s[i]` 时 `++p_k`（去重、撞值同步、不动点推进）。
5. 输出 `s[n-1]`。

### 复杂度

- 时间：$O(N)$（指针总前进 $\le 2N$，摊还常数）。
- 空间：$O(N)$，`s` 数组约 $32$ MB $\le 64$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例输出 $65$；不动点手造组（$c=1,f_1=\lfloor 3x/2\rfloor,f_2=2x,N=5$）输出 $6$、$N=1$ 输出 $c$，均与手算一致；与独立的 BigInt 最小堆枚举器对拍 $200$ 组有效数据（含两式相同、$b=0$ 不动点、$a/d$ 接近 $1$）全部一致；大候选组（$c=1,N=450,f_1=20x,f_2=2x$，候选超过 $2^{63}$）输出 $900719925474099200$ 与堆枚举一致；$N=200000$ 大数据正常运行且前 $300$ 项与堆枚举一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2942 [USACO09MAR] Moon Mooing G
// closure of {c} under f1,f2 = 两条单调流的归并（丑数式双指针）
// f_i(x)>=x 且严格递增；候选可能 >=2^63，用 __int128 算，答案本身 <2^63 用 i64 存
#include<bits/stdc++.h>
using namespace std;
using i64=long long;
using i128=__int128;

constexpr int mxn{4000005};
constexpr i128 inf=(i128)1<<100;	// 候选哨兵：远大于 20*2^63

int n,a1,b1,d1,a2,b2,d2;
i64 c,s[mxn];

i128 f1(i64 x){return (i128)a1*x/d1+b1;}
i128 f2(i64 x){return (i128)a2*x/d2+b2;}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>c>>n;
	cin>>a1>>b1>>d1>>a2>>b2>>d2;
	s[0]=c;
	int p1=0,p2=0;
	for(int i=0;i<n;++i)
	{
		if(i)
		{
			// 不变量：p1/p2 指向各自流中第一个 >s[i-1] 的候选；越界则暂记 inf
			i128 x=p1<i?f1(s[p1]):inf,y=p2<i?f2(s[p2]):inf;
			s[i]=(i64)min(x,y);	// 题目保证前 n 个时长都 <2^63
		}
		// 推进指针越过所有 <=s[i] 的候选（含 f(x)=x 的不动点与两流撞值）
		while(p1<=i&&f1(s[p1])<=s[i])++p1;
		while(p2<=i&&f2(s[p2])<=s[i])++p2;
	}
	cout<<s[n-1]<<'\n';
	return 0;
}
```

### 代码说明

- **读入顺序 `a b d`**：题面第二行是 `a1 b1 d1`，$b$ 在 $d$ 前，照公式顺序读会静默全错。
- `f1/f2` 返回 `i128` 且 `(i128)a1*x` 先转型再乘：候选最大 $20\cdot(2^{63}-1)+20<2^{68}$，`i64` 中间量必溢出；而**存储**的 `s[i]` 由题设 $<2^{63}$，`i64` 恰好装下——计算与存储两条值域线分开处理。
- `p1<i` 守卫 + `inf=2^100` 哨兵处理"流枯竭"：不动点 $f(x)=x$（只可能在 $x\le 18$）会把指针推到 $i+1$，此时直接读 `s[i+1]` 会拿到全局默认的 $0$、算出垃圾候选 $b_1$——不崩但静默错。哨兵保证枯竭流不参与 `min`。
- 两个 while 的条件是 `p<=i`（不是 `p<i`）：append 之后 `s[i]` 已定义，必须检查它自己的像是否 $\le s[i]$（不动点情形），否则下轮守卫会错误地把指针当枯竭。
- 撞值去重不需要额外判断：$x=y$ 时 append 一次，两个 while 各自推过，天然同步。
- `s` 是全局静态 `i64[4000005]`，约 $32$ MB，卡在 $64$ MB 限制内；若用 `priority_queue`+`set` 会数倍于此。
- $N=1$ 时循环只做指针推进、不生成，直接输出 `c`，无需特判。
