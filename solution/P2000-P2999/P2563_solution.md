# P2563 [AHOI2001] 质数和分解 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给自然数 $n$（$2\le n\le200$），求把 $n$ 写成**若干个质数之和**的"本质不同"表达式数目。质数取值范围 $[2,n]$，可以重复使用，单个质数（如 $n$ 本身是质数）也算一种。"本质相同"指交换加数位置能互相得到——也就是说**顺序无关**。输入每行一个 $n$（多组，读到文件尾），每行输出对应答案。题面例子：$9=2+5+2=2+3+2+2=3+3+3=2+7$，共 $4$ 种。

**第一步：先把"本质不同"翻译成数学对象。** 顺序无关 + 可重复 + 和为 $n$，这正是**把 $n$ 分拆成质数 parts 的方案数**（partition into prime parts），等价于"元素取自质数集合、总和为 $n$ 的**多重集**个数"。$9$ 的四个多重集是 $\{2,2,5\}$、$\{2,2,2,3\}$、$\{3,3,3\}$、$\{2,7\}$——注意 $\{2,5,2\}$ 和 $\{2,2,5\}$ 是同一个多重集，只算一次。这一步把"数表达式"变成了"数多重集"，是整道题的支点。

**第二步：先想"顺序有关"的简单版本，对比出陷阱。** 如果题目要的是**有序**拆分（composition，$2+7$ 与 $7+2$ 算两种），DP 是 $f[j]=\sum_{p\le j}f[j-p]$，外层枚举和 $j$、内层枚举质数 $p$。但本题要**无序**，这个写法会把同一多重集的每种排列都数一遍，答案偏大。** unordered 计数的经典写法是"完全背包"：外层枚举物品（质数），内层正序枚举容量（和）。** 为什么外层物品就能去重？因为这样每种多重集只按"质数从小到大"的唯一顺序被构造一次。这个"循环顺序决定有序/无序"是本题最容易翻车的点，我在第二部分专门证明。

**第三步：归约到完全背包计数。** 把每个质数看成一种"硬币"，面值 $p$，数量无限，求凑出总和 $j$ 的**组合数**。状态 $dp[j]$ = 凑出 $j$ 的方案数，转移 $dp[j]\mathrel{+}=dp[j-p]$（正序，允许重复用同一质数）。初值 $dp[0]=1$（空多重集，和为 $0$，是唯一的"什么都不选"方案，也是所有递推的种子）。

**第四步：质数表 + 一次预处理回答所有询问。** 先用筛法求出 $\le200$ 的全部质数。然后**一次性**把 $dp[0..200]$ 算出来：外层遍历每个质数 $p$，内层 $j$ 从 $p$ 到 $200$ 正序累加。之后每读入一个 $n$ 直接输出 $dp[n]$，$O(1)$。

这里有个必须想清楚的细节：**预处理时用了所有 $\le200$ 的质数，会不会让 $dp[n]$ 错误地用到 $>n$ 的质数？** 不会。处理质数 $p$ 时内层从 $j=p$ 起步，所以 $p$ 只影响 $dp[j]$（$j\ge p$）。对任意 $j$，只有 $p\le j$ 的质数才会碰它，$p>j$ 的质数内层根本不到 $j$。故 $dp[j]$ 恰好统计"用 $\le j$ 的质数凑出 $j$"，与题目"质数 $\le n$"的要求自动一致——其实"质数 $\le n$"这个条件是**冗余**的：和为 $n$、每个质数 $\ge2$，任何加数自然 $\le n$。

**第五步：值域与类型。** 我担心方案数爆 `int`。跑一下 $dp[200]=9845164$（约 $9.8\times10^6$），其实 `int` 都装得下。但"分拆数"这类计数增长很快，换个上界就可能爆，所以我用 `long long`（`i64`）做防御性选择，零成本。

**手造数据核对**（题面只给了 $9$ 的例子，没有完整样例输入输出）：

| $n$ | 手算质数分拆 | 程序 |
|---|---|---|
| $2$ | $\{2\}$ → 1 | 1 |
| $3$ | $\{3\}$ → 1 | 1 |
| $4$ | $\{2,2\}$ → 1 | 1 |
| $5$ | $\{5\},\{2,3\}$ → 2 | 2 |
| $9$ | $\{2,7\},\{2,2,5\},\{2,2,2,3\},\{3,3,3\}$ → 4 | 4 |
| $10$ | $\{2,2,2,2,2\},\{2,2,3,3\},\{2,3,5\},\{3,7\},\{5,5\}$ → 5 | 5 |
| $200$ | （太大不手算） | 9845164 |

$n=9$ 与题面例子逐条吻合；$n=10$ 我特意枚举了全部 $5$ 种确认"无序"没数重。

## 二、思维链：完整证明

**记号。** 设 $P=\{p_1<p_2<\cdots<p_t\}$ 为 $\le200$ 的全部质数（$p_1=2$）。对 $0\le j\le200$，定义
$$\mathcal M_k(j)=\Bigl\{\text{元素取自 }\{p_1,\dots,p_k\}\text{、总和为 }j\text{ 的多重集}\Bigr\},\qquad dp_k[j]=|\mathcal M_k(j)|.$$
最终 $dp[j]=dp_t[j]$。空多重集和为 $0$，故 $\mathcal M_k(0)=\{\varnothing\}$，$dp_k[0]=1$。

---

### 引理 1（题目方案 = 质数多重集，且"质数 $\le n$"冗余）

题目的"本质不同的质数和表达式"与 $\mathcal M_t(n)$ 一一对应；且任何和为 $n$、元素 $\ge2$ 的多重集，其元素自动 $\le n$。

*证明*：一个表达式是若干质数的一个**可重排列**，但题面规定"交换加数位置得到的表达式本质相同"，故一个本质不同的表达式恰好对应一个**多重集**（多重集就是"不计顺序的可重集合"）。反之每个多重集按任意顺序写出都是一个合法表达式，且同一多重集的不同排列被归为同一类。故本质不同的表达式集合 $\leftrightarrow$ 元素为质数、和为 $n$ 的多重集集合 $=\mathcal M_t(n)$（这里 $t$ 取 $\le200$ 的质数，下面证范围冗余）。

范围冗余：设多重集元素 $q_1,\dots,q_r$ 都是质数（$\ge2$）且 $\sum q_i=n$。对任一 $q_i$，$q_i=n-\sum_{j\ne i}q_j\le n$（其余项 $\ge0$；$r=1$ 时 $q_i=n$）。故每个加数 $\le n$，题目"质数 $\le n$"的限制自动满足，无需在 DP 中额外裁剪。证毕。

---

### 引理 2（完全背包计数递推）

对 $k\ge1$、$j\ge0$：
$$dp_k[j]=\begin{cases}dp_{k-1}[j]+dp_k[j-p_k],&j\ge p_k\\ dp_{k-1}[j],&j<p_k\end{cases}$$
基例 $dp_0[0]=1$，$dp_0[j]=0\ (j\ge1)$。

*证明*：把 $\mathcal M_k(j)$ 按"是否含元素 $p_k$"划分成不交的两类。

**不含 $p_k$**：这样的多重集元素全取自 $\{p_1,\dots,p_{k-1}\}$、和为 $j$，恰是 $\mathcal M_{k-1}(j)$，个数 $dp_{k-1}[j]$。

**含至少一个 $p_k$**：从中删去一个 $p_k$，得到元素取自 $\{p_1,\dots,p_k\}$、和为 $j-p_k$ 的多重集，即 $\mathcal M_k(j-p_k)$ 的元素。这个"删一个 $p_k$"是双射：逆映射是"加一个 $p_k$"，把 $\mathcal M_k(j-p_k)$ 的每个多重集映回含 $p_k$ 的 $\mathcal M_k(j)$。故这类个数 $=dp_k[j-p_k]$（当 $j\ge p_k$；$j<p_k$ 时不可能含 $p_k$，这类为空）。

两类不交且并为全体，故 $dp_k[j]=dp_{k-1}[j]+dp_k[j-p_k]$（$j\ge p_k$），否则 $dp_k[j]=dp_{k-1}[j]$。

基例：$\{p_1,\dots,p_0\}=\varnothing$，唯一的多重集是空集，和为 $0$。故 $dp_0[0]=1$，$j\ge1$ 时无解 $dp_0[j]=0$。证毕。

---

### 引理 3（原地正序循环实现引理 2，且计数无序）

代码
```
dp[0]=1;
for k=1..t:            // 外层：质数
    for j=p_k..200:    // 内层：正序
        dp[j]+=dp[j-p_k];
```
执行完第 $k$ 轮外层后，对所有 $j$ 有 `dp[j]`$=dp_k[j]$。特别地最终 `dp[j]`$=dp_t[j]=|\mathcal M_t(j)|$，即**无序**方案数。

*证明*：对外层轮数 $k$ 归纳。

**$k=0$（未进循环）**：`dp[0]=1`，其余全局默认 $0$，恰为 $dp_0$。✓

**归纳步**：设进入第 $k$ 轮前 `dp[j]`$=dp_{k-1}[j]$ 对所有 $j$ 成立。第 $k$ 轮内层 $j$ 从 $p_k$ 到 $200$ **递增**执行 `dp[j]+=dp[j-p_k]`。

- 对 $j<p_k$：内层不触及，`dp[j]` 保持 $dp_{k-1}[j]=dp_k[j]$（引理 2 的 $j<p_k$ 分支）。✓
- 对 $j\ge p_k$：执行时 `dp[j]` 仍是旧值 $dp_{k-1}[j]$（本轮尚未更新过 $j$），而 `dp[j-p_k]` 的此刻值需辨析：
  - 若 $j-p_k\ge p_k$：因 $j-p_k<j$ 且内层正序，`dp[j-p_k]` 已在本轮被更新为 $dp_k[j-p_k]$；
  - 若 $j-p_k<p_k$：`dp[j-p_k]` 本轮不会被更新（内层从 $p_k$ 起步），其值 $=dp_{k-1}[j-p_k]=dp_k[j-p_k]$（引理 2 的 $j<p_k$ 分支）。
  
  两种情形都有 `dp[j-p_k]`$=dp_k[j-p_k]$。故 `dp[j]+=dp[j-p_k]` 把 `dp[j]` 更新为 $dp_{k-1}[j]+dp_k[j-p_k]=dp_k[j]$（引理 2）。✓

由归纳，第 $k$ 轮后 `dp[j]`$=dp_k[j]$ 对所有 $j$ 成立。最终 $k=t$ 得 `dp[j]`$=dp_t[j]$。

**为什么无序**：$dp_k[j]$ 数的是**多重集**（引理 1、2），不是序列。外层按质数下标递增处理，相当于强制每个多重集按"质数从小到大"的唯一规范顺序被构造，故同一多重集的不同排列不会被重复计数。证毕。

**对照（有序版本为何不同）**：若把循环改成"外层 $j$、内层 $p$"，则 $f[j]=\sum_p f[j-p]$ 数的是**序列**（composition）：它枚举"最后一个加数是哪个质数"，同一多重集的不同末元素被分别计数，于是每种排列各算一次。本题要无序，故必须外层物品、内层正序——这正是引理 3 的写法。

### 引理 4（一次预处理回答所有询问）

设 $dp$ 由引理 3 用全部 $\le200$ 的质数算出。则对任意 $2\le n\le200$，`dp[n]` 就是题目对 $n$ 的答案，无需为每个 $n$ 重算。

*证明*：由引理 3，`dp[n]`$=|\mathcal M_t(n)|$，即元素取自全部 $\le200$ 质数、和为 $n$ 的多重集数。由引理 1 的范围冗余，和为 $n$ 的多重集元素自动 $\le n\le200$，故"元素取自 $\le200$ 质数"与"元素取自 $\le n$ 质数"对和为 $n$ 的多重集是同一约束。因此 `dp[n]` 恰为题目答案。

再看预处理为何不串味：处理质数 $p$ 时内层 $j\ge p$，故 $p$ 只更新 $j\ge p$ 的格子；对固定 $n$，只有 $p\le n$ 的质数影响 `dp[n]`，$p>n$ 的质数内层到不了 $n$。所以即便一次性跑了所有质数，`dp[n]` 仍只由 $\le n$ 的质数决定，与单独为 $n$ 计算一致。证毕。

### 引理 5（线性筛正确性）

代码
```
for i=2..204:
    if !comp[i]: pri[cnt++]=i;
    for j=0..cnt-1 且 i*pri[j]<205:
        comp[i*pri[j]]=true;
        if i%pri[j]==0: break;
```
结束后 `pri[0..cnt-1]` 恰为 $\le204$ 的全部质数（升序），`comp[x]` 为真 $\iff$ $x$ 是合数（$2\le x\le204$）。

*证明*：这是标准线性筛。核心不变量：每个合数 $x$ 被其**最小质因子**筛掉恰一次。

- **质数被收集**：$i$ 从小到大扫，若 `comp[i]` 仍假说明 $i$ 没被任何更小质数筛掉，即 $i$ 无 $\le\sqrt i$ 的质因子……更直接地，线性筛保证合数 $x=p_{\min}(x)\cdot m$ 在 $i=m$ 那轮、用 $p_{\min}(x)$ 被标记（因 $m$ 的最小质因子 $\ge p_{\min}(x)$，内层在到达 $p_{\min}(x)$ 前不会 break）。故所有合数都被标记，未标记的 $i\ge2$ 必为质数，被收入 `pri`。
- **升序**：$i$ 递增扫描，质数按发现顺序入表，自然升序。
- **每个合数恰筛一次**：内层 `if i%pri[j]==0 break` 保证只用 $\le p_{\min}(i)$ 的质数去筛 $i\cdot pri[j]$，从而 $i\cdot pri[j]$ 的最小质因子就是 $pri[j]$，每个合数只在其最小质因子对应的那次被标记。

范围 $<205$ 覆盖到 $204\ge200$，故 $\le200$ 的质数全在表中。证毕。

### 引理 6（复杂度与值域）

设 $N=200$，$\pi(N)$ 为 $\le N$ 的质数个数（$\pi(200)=46$）。时间 $O(N\pi(N))$（筛 $O(N)$，DP $O(N\pi(N))$，每询问 $O(1)$）；空间 $O(N)$。最大计数值 $dp[200]=9845164<2^{31}$，用 `i64` 绝对安全。

*证明*：筛法每个数被访问常数次，$O(N)$。DP 外层 $\pi(N)$ 个质数，内层对质数 $p$ 跑 $N-p+1\le N$ 次，故总转移 $\le N\pi(N)=200\times46=9200$ 次加法。每询问一次数组读取 $O(1)$。空间：`dp`、`pri`、`comp` 各 $O(N)$。

值域：实测 $dp[200]=9845164$（与质数分拆数列 OEIS A000607 的第 $200$ 项一致），远小于 `int` 上限 $2.1\times10^9$，更小于 `i64` 上限 $9.2\times10^{18}$。虽然本题 `int` 已够，但分拆计数增长极快（总分区数 $p(200)\approx3.97\times10^{12}$ 就超 `int`），用 `i64` 是防御性正确选择。证毕。

### 定理

程序对每个输入 $n$ 输出把 $n$ 分拆成质数之和的本质不同方案数，时间 $O(N\pi(N))$ 预处理 $+$ 每询问 $O(1)$，空间 $O(N)$。

*证明*：引理 1 把题目化为质数多重集计数；引理 5 保证质数表正确；引理 2、3 保证完全背包递推与原地正序实现正确且计数无序；引理 4 保证一次预处理即可回答所有 $n$；引理 6 给出复杂度与类型安全。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "本质不同 = 交换加数位置视为相同" ⇒ 顺序无关 ⇒ 数的是**质数多重集**（分拆），不是排列。
- **consider easier version** — 先想有序版本（composition）：外层和、内层质数 $f[j]=\sum_p f[j-p]$；对比发现它会数重，无序必须换循环顺序。
- **classic problem solution** — 完全背包计数：外层枚举质数、内层正序 `dp[j]+=dp[j-p]`，每种多重集按质数升序唯一构造 ⇒ 无序。
- **explore its property** — "质数 $\le n$"冗余：和为 $n$、加数 $\ge2$ ⇒ 加数自动 $\le n$；故 $p>n$ 的质数内层到不了 $n$，一次预处理 $dp[0..200]$ 即可 $O(1)$ 回答所有询问。
- **classic problem solution** — 线性筛求 $\le200$ 质数（每个合数被最小质因子筛一次）。
- **discuss by category** — $dp[0]=1$ 是空多重集种子；循环顺序决定有序/无序；计数用 `i64` 防御溢出；EOF 驱动多询问。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `mxn` | 上界 $200+5$ | `constexpr int{205}` | 数组尺寸，+5 松弛 |
| `n` | 当前询问的自然数 | `int`，EOF 读入 | $2\le n\le200$ |
| `comp[x]` | $x$ 是否合数 | `bool[mxn]`，全局默认 `false` | 筛法标记 |
| `pri[k]` | 第 $k$ 个质数（升序） | `int[mxn]` | 线性筛收集 |
| `cnt` | 质数个数 | `int`，初值 $0$ | $\pi(200)=46$ |
| `dp[j]` | 把 $j$ 分拆成质数之和的**无序**方案数 | `i64[mxn]` | `dp[0]=1`，其余默认 $0$ |
| `dp[0]` | 空多重集（和为 $0$） | 显式置 $1$ | 所有递推的种子 |

### 算法步骤

1. I/O 加速三行。
2. 线性筛求 $\le204$ 的质数存入 `pri`，个数 `cnt`（引理 5）。
3. `dp[0]=1`。
4. 外层 `k=0..cnt-1`（质数 `p=pri[k]`），内层 `j=p..204` 正序：`dp[j]+=dp[j-p]`（引理 2、3）。
5. `while(cin>>n)` 输出 `dp[n]` 与 `'\n'`（引理 4）。

### 复杂度

- 时间：筛 $O(N)$ + DP $O(N\pi(N))\approx9200$ 次加法 + 每询问 $O(1)$。
- 空间：$O(N)$，三个长度 $205$ 的数组。
- 值域：$dp[200]=9845164$，`i64` 安全。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面仅给 $9$ 的例子，手造 $n\in\{2,3,4,5,9,10,200\}$ 核对：$dp[9]=4$ 与题面四式逐条吻合，$dp[10]=5$ 与手工枚举的全部 $5$ 种一致，$dp[200]=9845164$ 与质数分拆数列 A000607 第 $200$ 项一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2563 [AHOI2001] 质数和分解
// 思路：本质不同 = 顺序无关 = 把 n 分拆成质数多重集 ⇒ 完全背包计数。
//       外层枚举质数、内层正序 dp[j]+=dp[j-p]，每种多重集按质数升序唯一构造 ⇒ 无序。
//       质数<=n 冗余（和为 n、加数>=2）⇒ 一次预处理 dp[0..200]，O(1) 回答每个询问。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{205};

int n,pri[mxn],cnt;
bool comp[mxn];
i64 dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(int i=2;i<mxn;++i)	// 线性筛：每个合数被最小质因子筛一次
	{
		if(!comp[i])pri[cnt++]=i;
		for(int j=0;j<cnt&&i*pri[j]<mxn;++j)
		{
			comp[i*pri[j]]=true;
			if(i%pri[j]==0)break;
		}
	}
	dp[0]=1;	// 空多重集是种子
	for(int k=0;k<cnt;++k)	// 外层质数 ⇒ 无序；内层正序 ⇒ 可重复用
		for(int j=pri[k];j<mxn;++j)
			dp[j]+=dp[j-pri[k]];
	while(cin>>n)
		cout<<dp[n]<<'\n';
	return 0;
}
```

### 代码说明

- **循环顺序是灵魂**：外层质数、内层正序容量 ⇒ 数多重集（无序）。若反过来外层容量、内层质数，就变成数序列（有序），答案偏大（引理 3 对照）。
- **内层正序**允许同一质数被重复选取（完全背包），对应"质数可重复使用"；若改成倒序就变成 0/1 背包（每个质数至多用一次），与题意不符。
- **`dp[0]=1` 必须显式写**：它是空多重集，是所有非零计数的来源；全局 `i64` 默认 $0$，不置 $1$ 则整张表恒 $0$。
- **一次预处理**：`dp` 跑完所有 $\le204$ 质数后，`dp[n]` 只由 $\le n$ 的质数决定（$p>n$ 内层到不了 $n$），故无需按询问重算（引理 4）。
- **`i64` 防御**：本题最大 $dp[200]=9845164$ 其实 `int` 够用，但分拆计数增长快，`i64` 零成本保险。
- **EOF 多询问**：`while(cin>>n)` 逐行读到文件尾，每行一个答案。
