# P2249 【深基13.例1】查找 — 题解

## 一、解题过程：人类思考叙事

先把题意压缩成一句话：给定一个**单调不减**的非负整数序列 $a_1\le a_2\le\cdots\le a_n$（$n\le 10^6$），有 $m\le 10^5$ 次询问，每次给出 $q$，输出 $q$ 在序列中**第一次**出现的位置（从 $1$ 开始编号），不存在输出 $-1$。

最直接的想法是每次询问从头扫一遍，找到第一个等于 $q$ 的位置就停。单次最坏 $O(n)$，总复杂度 $O(nm)$，最坏约 $10^{11}$ 次比较，必然超时。题面特意写了“单调不减”和“输入输出量较大”，前者提示二分，后者提示快读。

于是先回忆最普通的二分：在有序数组里判断 $q$ 是否存在。取 `mid`，若 $a_{mid}=q$ 就返回，若 $a_{mid}<q$ 往右，否则往左。可是这题要的是**第一次出现**，普通二分可能落在中间某个 $q$ 上。

第一个修正方案：先用普通二分找到任意一个 $q$，再向左一路回退，直到前一个数不等于 $q$。这个方案在元素互不相同时没问题，但考虑极端数据

```
5 1
7 7 7 7 7
7
```

二分落在下标 $2$（0-based），向左回退 $2$ 步；如果 $n=10^6$ 且全是 $7$，每次询问都要回退约 $5\times 10^5$ 步，$m=10^5$ 次就退化成 $5\times 10^{10}$，和暴力没有区别。**“找到任意一个再线性扩展”这个思路的症结在于：它把有序性只用了一次，回退时又退回了线性扫描。**

换个角度：不要问“$q$ 在哪”，而问“**从哪里开始，元素不再小于 $q$**”。定义谓词

$$p(i)=[a_i\ge q]\qquad(0\le i<n).$$

因为 $a$ 单调不减，$p$ 一定是“前面一长串 $0$，后面一长串 $1$”的形状。而 $q$ 的第一次出现，恰好就是这个 $0/1$ 分界点（如果分界点上的值真的等于 $q$ 的话）。于是问题从“查找一个值”变成了“**查找第一个满足 $a_i\ge q$ 的位置**”，这是一个标准的 `lower_bound`，二分时**即使 $a_{mid}=q$ 也不能停**，必须继续往左压。

这样每次询问 $O(\log n)$，总复杂度 $O(n+m\log n)$，约 $10^6+2\times 10^6$ 次操作，轻松通过。

最后是几个实现边界：

1. 二分区间用半开的 $[l,r)$，初值 $l=0,r=n$。这样“找不到”时自然得到 $r=n$，不需要特判数组越界。
2. 二分结束后得到的 $l$ 只是“第一个 $\ge q$ 的位置”，它可能指向一个**大于** $q$ 的数，也可能等于 $n$。所以必须再检查 `l<n && a[l]==q`。
3. 不能在 `a[mid]==q` 时提前返回，否则拿到的是“某一个”而不是“第一个”。
4. $a_i,q$ 都可以是 $0$，所以不能拿 $0$ 当“不存在”的哨兵；本题干脆不使用哨兵。
5. 输出是同一行的 $m$ 个整数，用空格分隔；$n=10^6$ 的读入必须关闭同步。

本地题面没有附样例，我手造了三组小数据（见第五节验证状态），其中第一组刻意包含重复元素和不存在元素，第二组覆盖 $n=1$ 与 $q=0$，第三组就是上面那个“全相同”的反例。

## 二、思维链：完整证明

以下下标一律从 $0$ 开始，$a_0\le a_1\le\cdots\le a_{n-1}$。为方便叙述，约定一个虚拟位置 $n$，把“第一个 $\ge q$ 的位置”记作

$$L=\min\bigl(\{i\in[0,n):a_i\ge q\}\cup\{n\}\bigr).$$

也就是说：若存在 $a_i\ge q$，$L$ 是其中最小的下标；若所有 $a_i<q$，则 $L=n$。

**引理 1（谓词单调）**：对固定的 $q$，若 $p(i)$ 为真，则对任意 $j>i$ 都有 $p(j)$ 为真。

*证明*：$p(i)$ 为真即 $a_i\ge q$。由序列单调不减，$a_j\ge a_i\ge q$，故 $p(j)$ 为真。取逆否命题：若 $p(j)$ 为假（$a_j<q$），则对任意 $i<j$ 都有 $p(i)$ 为假。于是全体下标被分成“前段全假、后段全真”两部分，分界点正是 $L$。证毕。

**引理 2（$L$ 的两侧性质）**：对任意 $i<L$ 有 $a_i<q$；对任意 $L\le i<n$ 有 $a_i\ge q$。

*证明*：若 $i<L$ 而 $a_i\ge q$，则 $i$ 属于集合 $\{j:a_j\ge q\}$ 且比 $L$ 小，与 $L$ 取最小值矛盾，故 $a_i<q$。若 $L\le i<n$：当 $L<n$ 时由 $L$ 的定义 $a_L\ge q$，再由单调性 $a_i\ge a_L\ge q$；当 $L=n$ 时区间 $[L,n)$ 为空，命题空洞成立。证毕。

**引理 3（二分不变量）**：在二分循环的任意时刻（循环条件 `l<r` 成立时），都有 $l\le L\le r$。

*证明*：对循环次数归纳。初始 $l=0,r=n$；由 $L$ 的定义 $L\in\{0,1,\dots,n\}$，故 $l\le L\le r$。设某轮开始时 $l\le L\le r$ 且 $l<r$，取 $mid=\lfloor(l+r)/2\rfloor$。由 $l<r$ 得 $l\le mid<r$，特别地 $mid$ 是合法下标（$mid<n$），可以访问 $a_{mid}$。

- 若 $a_{mid}\ge q$：则 $mid$ 属于“真”集合，而 $L$ 是“真”集合的最小下标，故 $L\le mid$。程序令 $r\leftarrow mid$，新区间仍满足 $l\le L\le r$。
- 若 $a_{mid}<q$：由引理 1 的逆否形式，所有 $i\le mid$ 都满足 $a_i<q$，都不可能是 $L$（$L$ 要么是 $n$，要么满足 $a_L\ge q$），故 $L>mid$，即 $L\ge mid+1$。程序令 $l\leftarrow mid+1$，仍有 $l\le L\le r$。

证毕。

**引理 4（二分终止且 $l=L$）**：循环必然终止，终止时 $l=r=L$。

*证明*：每轮中，分支 $r\leftarrow mid$ 使 $r$ 严格减小（$mid<r$），分支 $l\leftarrow mid+1$ 使 $l$ 严格增大（$mid\ge l$），而 $l,r$ 始终是 $[0,n]$ 内的整数，故至多 $n+1$ 轮后必终止；更精确地，区间长度 $r-l$ 每轮至少减半，轮数为 $O(\log n)$。终止时 $l=r$；由引理 3 有 $l\le L\le r=l$，故 $l=L$。证毕。

**引理 5（答案判定正确）**：设二分结束得到 $l=L$，程序按以下规则输出：

- 若 $L<n$ 且 $a_L=q$，输出 $L+1$；
- 否则输出 $-1$。

则该输出等于 $q$ 第一次出现的 $1$-based 位置，或正确地表示不存在。

*证明*：分三种情况。

1. $L<n$ 且 $a_L=q$。由引理 2，所有 $i<L$ 满足 $a_i<q$，故 $q$ 不可能出现在 $L$ 之前；而 $a_L=q$，所以 $L$ 就是第一次出现的位置，输出 $L+1$ 正确。
2. $L=n$。由引理 2（$L=n$ 情形）所有 $i<n$ 满足 $a_i<q$，$q$ 不存在，输出 $-1$ 正确。
3. $L<n$ 且 $a_L>q$。对 $i<L$ 有 $a_i<q$；对 $i\ge L$ 由单调性 $a_i\ge a_L>q$。两侧都没有 $q$，故 $q$ 不存在，输出 $-1$ 正确。

反过来，若 $q$ 在位置 $p$ 出现，则 $p$ 属于“真”集合，故 $L\le p$ 且 $a_L\ge q$。若 $a_L>q$，则由单调性所有 $i\ge L$ 都满足 $a_i>q$，特别地 $a_p>q$，与 $a_p=q$ 矛盾；所以必有 $a_L=q$。又所有 $i<L$ 的 $a_i<q$，故 $L$ 是第一次出现的位置，即 $L=p$。这说明“存在时输出第一次出现的位置”也成立。证毕。

**定理（算法正确性）**：对每个询问，上述二分 + 末尾检查输出的数，恰好是题目要求的答案。

*证明*：由引理 4 二分终止于 $l=L$，由引理 5 末尾检查的输出正确。每个询问相互独立，故所有询问的答案都正确。证毕。

**引理 6（复杂度）**：单次询问时间 $O(\log n)$，总时间 $O(n+m\log n)$，空间 $O(n)$。

*证明*：每轮区间长度至少减半，从 $n$ 降到 $1$ 至多 $\lceil\log_2(n+1)\rceil$ 轮，每轮常数次比较；读入 $n$ 个数 $O(n)$；$m$ 次询问共 $O(m\log n)$。数组 $a$ 占 $O(n)$ 空间，其余为常数。证毕。

**补充说明（为什么“找到任意一个再回退”是错的复杂度）**：设数组全部元素等于 $q$，普通二分返回某个下标 $k$，向左回退需要 $k$ 步；取 $k=\Theta(n)$ 即可让单次询问 $\Theta(n)$，$m$ 次询问 $\Theta(nm)$。这从反面说明必须直接把“第一次”编码进二分谓词，而不能事后再修。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 序列单调不减，因此比较谓词 $[a_i\ge q]$ 是“前假后真”的单调谓词。
- **consider easier version** — 先解决“$q$ 是否存在”的普通二分，确认二分骨架可用。
- **find counterexample** — “二分找到任意一个 $q$ 再向左回退”在全相同数据上退化为 $O(n)$。
- **reduce to easier problem** — “第一次出现”等价于“第一个满足 $a_i\ge q$ 的位置”，把存在性问题化为边界问题。
- **classic problem solution** — 在半开区间 $[l,r)$ 上二分 `lower_bound`，相等时也继续向左压。
- **boundary check** — 二分结果只是第一个 $\ge q$ 的位置，必须再判 `l<n && a[l]==q`。
- **engineering** — $10^6$ 读入 + 关闭同步；输出同一行 $m$ 个用空格分隔的整数。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| $n$ | 序列长度 | `int`，输入 |
| $m$ | 询问次数 | `int`，输入 |
| $a[i]$ | 第 $i$ 个元素（0-based） | `int[mxn]`，输入，全局数组 |
| $q$ | 当前询问的值 | `int`，每次读入 |
| $l,r$ | 二分区间 $[l,r)$ 的左右端点 | `int`，初值 $l=0,\ r=n$ |
| $mid$ | 二分中点 $\lfloor(l+r)/2\rfloor$ | `int`，循环内定义 |
| $L$ | 第一个满足 $a_i\ge q$ 的下标（不存在则为 $n$） | 概念量，终止时 $l=L$ |

`mxn{1000005}` 是 $10^6+5$ 的松弛上界。

### 算法步骤

1. 关闭流同步，读入 $n,m$。
2. 读入 $n$ 个单调不减的整数到 `a[0..n-1]`。
3. 对每个询问 $q$：
   1. 令 $l=0,\ r=n$（半开区间）。
   2. 当 $l<r$：取 $mid=(l+r)/2$；若 `a[mid]>=q` 则 $r=mid$，否则 $l=mid+1$。
   3. 循环结束时 $l$ 是第一个 $\ge q$ 的位置（或 $n$）。
   4. 若 `l<n && a[l]==q` 输出 `l+1`，否则输出 `-1`，后面跟一个空格。
4. 所有询问输出完后补一个换行。

### 复杂度

- 时间复杂度：$O(n+m\log n)$，其中二分约 $\log_2 n\le 20$ 轮/次。
- 空间复杂度：$O(n)$，仅存原数组。

### 验证状态

- 使用 `/d/mingw64/bin/g++.exe -std=c++20 -O2` 编译通过，无错误。
- 本地题面无样例，手造 3 组：`6 4 / 1 2 2 3 3 5 / 2 3 4 6` → `2 4 -1 -1`；`1 2 / 0 / 0 1` → `1 -1`；`5 3 / 7 7 7 7 7 / 7 0 8` → `1 -1 -1`。
- 与线性扫描暴力对拍 300 组随机小数据（含大量重复值），输出完全一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2249 【深基13.例1】查找
// 思路：单调不减 ⇒ 谓词 a[i]>=q 前假后真
//       二分第一个 >=q 的位置（相等也不停），再检查该位置是否真的等于 q
//       n<=1e6，必须关闭流同步
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005};

int n,m,a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0,q;i<m;++i)
	{
		cin>>q;
		int l=0,r=n;
		while(l<r)
		{
			int mid=(l+r)>>1;
			if(a[mid]>=q)
				r=mid;
			else
				l=mid+1;
		}
		// l 是第一个 >=q 的位置（可能是 n）
		if(l<n&&a[l]==q)
			cout<<l+1<<' ';
		else
			cout<<-1<<' ';
	}
	cout<<'\n';
	return 0;
}
```

### 代码说明

- `l=0,r=n` 是半开区间，天然允许“答案等于 $n$（不存在）”，不需要额外的哨兵元素。
- `a[mid]>=q` 时 `r=mid` 而不是 `mid-1`：因为 `mid` 本身可能就是答案，不能丢弃。
- 循环内绝不能在 `a[mid]==q` 时 `break`，否则得到的是任意一次出现。
- 末尾的 `l<n&&a[l]==q` 同时挡住“越界”和“第一个 $\ge q$ 的值严格大于 $q$”两种失败情形。
- 输出用空格分隔，最后补换行；`'\n'` 而非 `endl`。

---

*本题的思维转折只有一个：把“找第一次出现”从“找到再回退”改写成“二分第一个 $\ge q$ 的位置”。一旦谓词选对，边界检查就是全部剩余工作。*
