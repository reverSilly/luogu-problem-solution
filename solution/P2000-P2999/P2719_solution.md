# P2719 搞笑世界杯 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 工作人员准备了 $2n$ 张票：$n$ 张 A（免费）、$n$ 张 B（双倍价），$1\le n\le 1250$。$2n$ 个人排队，每人**必须且只能**买一张。售票规则：对每个人掷一枚公平硬币，正面卖 A、反面卖 B；**若掷到的那一类已经卖完，就改卖另一类**（故事里"剩下两张全是免费票、无需再掷"正是这个机制的体现）。问：**队尾两个人拿到同一类票**（同 A 或同 B）的概率，输出保留 $4$ 位小数。输入给的是 $2n$。

**第一步：把"最后两人同票"翻译成一个状态条件。** 设前 $2n-2$ 个人买完后，已售出 $a$ 张 A、$b$ 张 B，则 $a+b=2n-2$，剩下 $n-a$ 张 A、$n-b$ 张 B，共 $2$ 张。最后两人怎么拿？

- 若 $a=n$（A 卖光），剩 $0$ 张 A、$2$ 张 B：第 $2n-1$ 人无论掷到什么都只能拿 B，第 $2n$ 人也拿 B。**同票**。
- 若 $b=n$（B 卖光），对称，**同票**。
- 若 $a=n-1,b=n-1$（各剩 $1$ 张）：第 $2n-1$ 人掷硬币拿 A 或 B，第 $2n$ 人拿剩下那张。**必不同票**。

而 $a+b=2n-2$、$0\le a,b\le n$ 只可能有三种状态：$(n,n-2)$、$(n-1,n-1)$、$(n-2,n)$。于是

$$\text{最后两人同票}\iff\text{前 }2n-2\text{ 人售完后状态为 }(n,n-2)\text{ 或 }(n-2,n)\iff\text{某类票提前售罄}.$$

它的**反面**恰好是状态 $(n-1,n-1)$。这一步把"概率"问题变成了"到达某个状态的概率"。

**第二步：本能地想上概率 DP，然后碰壁。** 设 $f[i][j]$ 为售票过程中到达状态 $(i,j)$ 的概率。内部状态（$i<n,j<n$，两类都还有）下一步掷硬币，各 $\tfrac12$，所以 $f[i][j]=\tfrac12(f[i-1][j]+f[i][j-1])$。我一开始想把这个式子**统一**用到所有状态，结果在边界翻车：考虑 $f[n][j]$（A 已售罄），从 $(n,j-1)$ 过来时 A 没了，**强制**卖 B，转移概率是 $1$ 而不是 $\tfrac12$！正确写法是 $f[n][j]=\tfrac12 f[n-1][j]+f[n][j-1]$。统一递推在边界少算了一半，直接 DP 必须分类讨论，略显繁琐。

**第三步：关键简化——反面状态根本不会触发"强制"。** 盯着反面状态 $(n-1,n-1)$ 看：要到达它，整个过程中 A 的销量始终 $\le n-1<n$、B 的销量始终 $\le n-1<n$（销量单调不减，终点才 $n-1$）。也就是说，**通往 $(n-1,n-1)$ 的每一条路径上，两类票从头到尾都没卖光过**，每一步都是实打实的公平掷硬币，没有任何强制！于是这 $2n-2$ 步就是 $2n-2$ 次独立公平硬币，要恰好 $n-1$ 次 A、$n-1$ 次 B：

$$P(\text{反面})=\frac{\binom{2n-2}{n-1}}{2^{2n-2}},\qquad \text{答案}=1-\frac{\binom{2n-2}{n-1}}{2^{2n-2}}.$$

边界那堆麻烦的强制转移，**在反面事件里完全不存在**——这就是本题的题眼。$n=1$ 时反面概率 $\binom00/2^0=1$，答案 $0$（只有一 A 一 B，两人必不同），公式自动成立。

**第四步：又碰壁——组合数会爆炸。** $\binom{2n-2}{n-1}$ 在 $n=1250$ 时约 $2^{2498}/\sqrt{\pi n}$，天文数字，`long long`、`double` 都装不下；$2^{2n-2}$ 同样爆炸。但我们要的是**比值**。把它拆成乘积：

$$\frac{\binom{2n-2}{n-1}}{2^{2n-2}}=\frac{(2n-2)!}{(n-1)!\,(n-1)!\,2^{2n-2}}=\prod_{i=1}^{n-1}\frac{2i-1}{2i}.$$

（推导见引理 4。）每个因子 $\frac{2i-1}{2i}\in(0,1)$，乘积单调下降、始终落在 $(0,1]$，**永不溢出**，$O(n)$ 递推即可。

**第五步：精度够不够？** 输出只要 $4$ 位小数（误差阈 $5\times10^{-5}$）。$n-1\le1249$ 次乘法，`double` 单位舍入 $u=2^{-53}\approx1.1\times10^{-16}$，累积相对误差 $\lesssim1249u\approx1.4\times10^{-13}$，绝对误差 $\lesssim10^{-13}$，比阈值小了 $8$ 个数量级。`fixed<<setprecision(4)` 的就近舍入与四舍五入只在"第 $5$ 位起恰为 $5000\dots$"的测度零边界上才可能分歧，而误差 $10^{-13}$ 远不足以把任何真实值推到那种边界上。安全。

**手造数据核对**（题面无样例，按公式与枚举各算一遍）：

| 输入 $2n$ | $n$ | 反面概率 $\binom{2n-2}{n-1}/2^{2n-2}$ | 答案 |
|---|---|---|---|
| 2 | 1 | $1$ | `0.0000` |
| 4 | 2 | $2/4=0.5$ | `0.5000` |
| 6 | 3 | $6/16=0.375$ | `0.6250` |
| 8 | 4 | $20/64=0.3125$ | `0.6875` |
| 2500 | 1250 | $\approx0.01596$ | `0.9840` |

$n=3$ 时我枚举了前 $4$ 人的全部 $16$ 种掷币序列，其中 $10$ 种使某类提前售罄，$10/16=0.625$，与公式吻合。$n$ 越大答案越趋近 $1$（票越多，越容易有一类提前卖光），符合直觉。

## 二、思维链：完整证明

**记号。** 每类票数 $n$（输入 $2n$ 的一半），总人数 $2n$。过程的状态用 $(a,b)$ 表示已售 A、B 张数，$0\le a,b\le n$。第 $t$ 个人（$t=1,\dots,2n$）购票前状态为 $(a_{t-1},b_{t-1})$，$a_0=b_0=0$。掷币结果 $X_t\in\{A,B\}$ 独立且各 $\tfrac12$。购票规则：若 $X_t=A$ 且 $a_{t-1}<n$ 则 $a_t=a_{t-1}+1,b_t=b_{t-1}$；若 $X_t=B$ 且 $b_{t-1}<n$ 则 $b_t=b_{t-1}+1$；否则（掷到的类已售罄）改拿另一类。因 $a_{t-1}+b_{t-1}=t-1<2n$，两类不可能同时售罄，故"另一类"必有余票，规则良定义，且 $a_t+b_t=t$。

---

### 引理 1（同票事件的精确刻画）

最后两人（第 $2n-1,2n$ 人）拿到同一类票，当且仅当前 $2n-2$ 人售完后状态 $(a_{2n-2},b_{2n-2})\in\{(n,n-2),(n-2,n)\}$；其反面等价于状态 $(n-1,n-1)$。

*证明*：记 $(a,b)=(a_{2n-2},b_{2n-2})$，$a+b=2n-2$，$0\le a,b\le n$。剩余 A 票 $n-a$、B 票 $n-b$，$(n-a)+(n-b)=2$。

先穷举 $(a,b)$ 的可能：由 $a+b=2n-2$ 与 $a\le n,b\le n$，若 $a=n$ 则 $b=n-2$；若 $a=n-1$ 则 $b=n-1$；若 $a\le n-2$ 则 $b=2n-2-a\ge n$，结合 $b\le n$ 得 $b=n,a=n-2$。故恰三种：$(n,n-2),(n-1,n-1),(n-2,n)$。

**情形 $(n,n-2)$**：剩 $0$ 张 A、$2$ 张 B。第 $2n-1$ 人：若掷 A，A 已售罄，改拿 B；若掷 B，拿 B。无论如何拿 B，状态变 $(n,n-1)$。第 $2n$ 人：剩 $1$ 张 B，同理必拿 B。两人同 B。✓

**情形 $(n-2,n)$**：对称，两人同 A。✓

**情形 $(n-1,n-1)$**：剩 $1$ 张 A、$1$ 张 B。第 $2n-1$ 人掷币：掷 A 拿 A（A 尚余 $1$），掷 B 拿 B。设其拿了 A，则状态 $(n,n-1)$，第 $2n$ 人只剩 B，拿 B；设其拿了 B，对称第 $2n$ 人拿 A。两人**必不同**。✓

三情形穷尽，故"同票 $\iff(a,b)\in\{(n,n-2),(n-2,n)\}$"，反面"$\iff(a,b)=(n-1,n-1)$"。证毕。

---

### 引理 2（通往反面状态的路径上无强制转移）

若某次售票实现（即掷币序列 $X_1,\dots,X_{2n-2}$ 决定的轨迹）满足 $(a_{2n-2},b_{2n-2})=(n-1,n-1)$，则对一切 $0\le t\le2n-2$ 有 $a_t\le n-1<n$ 且 $b_t\le n-1<n$；从而前 $2n-2$ 步每一步都按掷币结果原样售票（无强制），且 $a_{2n-2}=\#\{t\le2n-2:X_t=A\}$。

*证明*：销量单调不减：$a_0\le a_1\le\dots\le a_{2n-2}=n-1$，故对所有 $t$，$a_t\le n-1<n$；同理 $b_t\le n-1<n$。于是在第 $t$ 步（$t\le2n-2$）购票前，$a_{t-1}\le n-1<n$ 且 $b_{t-1}\le n-1<n$，两类均有余票。按规则，掷 A 则拿 A、掷 B 则拿 B，**不触发强制分支**。故 $a_t=a_{t-1}+[X_t=A]$，累加得 $a_{2n-2}=\sum_{t=1}^{2n-2}[X_t=A]$，即前 $2n-2$ 次掷币中 A 的次数。证毕。

**这条引理是全部简化的支点**：它说明反面事件发生时，过程退化为纯独立公平硬币，边界上那些概率为 $1$ 的强制转移**根本不会出现**，因此无需对它们建模。

---

### 引理 3（反面概率是二项概率）

$$P\big((a_{2n-2},b_{2n-2})=(n-1,n-1)\big)=\frac{\binom{2n-2}{n-1}}{2^{2n-2}}.$$

*证明*：由引理 2，事件 $\{(a_{2n-2},b_{2n-2})=(n-1,n-1)\}$ 等价于 $\{\sum_{t=1}^{2n-2}[X_t=A]=n-1\}$（因为 $a_{2n-2}$ 就是 A 的次数，而 $b_{2n-2}=2n-2-a_{2n-2}$，$a_{2n-2}=n-1\iff b_{2n-2}=n-1$）。

需证两个方向：
- （$\Rightarrow$）若状态为 $(n-1,n-1)$，引理 2 给出 $a_{2n-2}=\#A=n-1$。
- （$\Leftarrow$）若 $\#A=n-1$（从而 $\#B=n-1$），要证状态确为 $(n-1,n-1)$ 且无强制。用反证：假设过程中某步触发了强制，设第一次强制发生在第 $t$ 步，则此前 $a_{t-1}=n$ 或 $b_{t-1}=n$（某类售罄）。但销量单调不减，故 $a_{2n-2}\ge a_{t-1}=n$ 或 $b_{2n-2}\ge n$，与 $a_{2n-2}=b_{2n-2}=n-1<n$ 矛盾。故无强制，每步原样售票，$a_{2n-2}=\#A=n-1$，$b_{2n-2}=n-1$。

因此事件恰好等于"$2n-2$ 次独立公平硬币中恰 $n-1$ 次正面"。$X_t$ 独立同分布、$P(A)=\tfrac12$，这是参数 $(2n-2,\tfrac12)$ 的二项分布取 $n-1$ 的概率：$\binom{2n-2}{n-1}(\tfrac12)^{n-1}(\tfrac12)^{n-1}=\binom{2n-2}{n-1}/2^{2n-2}$。证毕。

---

### 引理 4（比值的乘积形式）

对 $n\ge1$，
$$\frac{\binom{2n-2}{n-1}}{2^{2n-2}}=\prod_{i=1}^{n-1}\frac{2i-1}{2i}.$$
（$n=1$ 时两边均为 $1$，空乘积约定为 $1$。）

*证明*：$n=1$：左 $\binom00/2^0=1$，右空乘积 $=1$。✓

$n\ge2$：把阶乘展开并配对。
$$\binom{2n-2}{n-1}=\frac{(2n-2)!}{((n-1)!)^2}=\frac{\prod_{j=1}^{2n-2}j}{\big(\prod_{i=1}^{n-1}i\big)^2}.$$
分子 $\prod_{j=1}^{2n-2}j$ 按奇偶拆成 $\big(\prod_{i=1}^{n-1}(2i-1)\big)\big(\prod_{i=1}^{n-1}2i\big)$（奇数 $1,3,\dots,2n-3$ 共 $n-1$ 个，偶数 $2,4,\dots,2n-2$ 共 $n-1$ 个）。而 $\prod_{i=1}^{n-1}2i=2^{n-1}(n-1)!$。故
$$\binom{2n-2}{n-1}=\frac{\big(\prod(2i-1)\big)\cdot2^{n-1}(n-1)!}{((n-1)!)^2}=\frac{2^{n-1}\prod_{i=1}^{n-1}(2i-1)}{(n-1)!}=\frac{2^{n-1}\prod(2i-1)}{\prod_{i=1}^{n-1}i}.$$
除以 $2^{2n-2}$：
$$\frac{\binom{2n-2}{n-1}}{2^{2n-2}}=\frac{\prod(2i-1)}{2^{n-1}\prod i}=\prod_{i=1}^{n-1}\frac{2i-1}{2i}.$$
证毕。

**推论（数值可行性）**：每个因子 $\frac{2i-1}{2i}=1-\frac1{2i}\in(0,1)$，故部分积单调递减且落在 $(0,1]$，$n-1\le1249$ 次乘法绝不溢出，也无需大数。

---

### 引理 5（最终答案公式）

$$\text{答案}=1-\prod_{i=1}^{n-1}\frac{2i-1}{2i}.$$

*证明*：由引理 1，同票事件与反面事件（状态 $(n-1,n-1)$）互为补集（三情形中后者唯一对应不同票）。故 $P(\text{同票})=1-P(\text{反面})$。由引理 3，$P(\text{反面})=\binom{2n-2}{n-1}/2^{2n-2}$；由引理 4 化为乘积。代入即得。证毕。

---

### 引理 6（浮点误差远小于输出粒度）

设用 `double`（单位舍入 $u=2^{-53}$）顺序计算 $P_{n-1}=\prod_{i=1}^{n-1}\frac{2i-1}{2i}$，再输出 $1-P_{n-1}$ 保留 $4$ 位小数。则计算值与真值之差的绝对值 $\lesssim10^{-13}$，远小于四舍五入判定阈 $5\times10^{-5}$，输出正确。

*证明*：每个因子 $r_i=\frac{2i-1}{2i}$ 用 `double(2*i-1)/(2*i)` 计算，分子分母 $\le2497$ 可被 `double` 精确表示，除法引入相对误差 $\le u$。顺序乘法的标准误差界：若 $\hat P$ 为计算值、$P$ 为真值，则 $|\hat P-P|\le P\cdot((1+u)^{n-1}-1)\le P\cdot(n-1)u\cdot(1+O(nu))$。这里 $P\le1$、$n-1\le1249$，故 $|\hat P-P|\le1249\times1.11\times10^{-16}\approx1.4\times10^{-13}$。答案 $1-\hat P$ 的误差同量级。

输出保留 $4$ 位小数，判定边界宽度 $10^{-4}$、半阈 $5\times10^{-5}$。误差 $1.4\times10^{-13}$ 比半阈小约 $3.6\times10^8$ 倍，不可能把任何真值推过舍入边界（除非真值本身距边界 $<1.4\times10^{-13}$，而真值是确定的有理数，其第 $5$ 位起恰为 $5000\dots0$ 的情形要求分母整除特定幂次，对 $n\le1250$ 逐一可验证不发生；即便发生，`double` 误差也远小于该有理数与边界的距离）。故 `fixed<<setprecision(4)` 输出正确。证毕。

---

### 引理 7（复杂度）

时间 $O(n)$，空间 $O(1)$。

*证明*：读入 $O(1)$；乘积循环 $n-1$ 次，每次一次乘法一次除法，$O(n)$；输出 $O(1)$。仅用常数个变量（`n`、`prod`、循环变量），空间 $O(1)$。$n\le1250$，瞬间完成。证毕。

### 定理

程序输出"队尾两人拿到同一类票"的概率，保留 $4$ 位小数，复杂度 $O(n)$。

*证明*：引理 1 把事件刻画为状态条件并给出补集；引理 2、3 证明补集概率是无强制的二项概率；引理 4 化为数值可行的乘积；引理 5 给出答案公式；引理 6 保证浮点输出正确；引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 把"最后两人同票"翻译成"前 $2n-2$ 人售完后某类票已售罄"，即状态 $(n,n-2)$ 或 $(n-2,n)$。
- consider easier version — 先想概率 DP $f[i][j]$，发现边界强制转移概率是 $1$ 不是 $\tfrac12$，统一递推翻车。
- reduce to easier problem — 盯住反面状态 $(n-1,n-1)$：通往它的路上两类票永不售罄，强制转移根本不出现，过程退化为纯独立公平硬币。
- classic problem solution — 反面概率即二项概率 $\binom{2n-2}{n-1}/2^{2n-2}$，答案 $=1-$ 它。
- explore its property — 组合数与 $2^{2n-2}$ 都爆炸，但比值可拆成 $\prod_{i=1}^{n-1}\frac{2i-1}{2i}$，因子 $\in(0,1)$ 永不溢出。
- discuss by category — $n=1$ 空乘积 $=1$、答案 $0$ 自动成立；浮点误差 $10^{-13}\ll$ 输出阈 $5\times10^{-5}$，`setprecision(4)` 安全。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 每类票数（输入 $2n$ 的一半） | `int`，读入后 `n/=2` | 输入是 $2n$，先折半 |
| `prod` | 反面概率 $\prod_{i=1}^{n-1}\frac{2i-1}{2i}=\binom{2n-2}{n-1}/2^{2n-2}$ | `double`，初值 $1$ | $n=1$ 时循环不执行，`prod=1`，答案 $0$ |
| `i` | 乘积因子下标 $1\dots n-1$ | `int` | 因子 `(2i-1)/(2i)` |
| `ans` | 同票概率 $1-\texttt{prod}$ | `double` | 输出 `fixed<<setprecision(4)` |

### 算法步骤

1. I/O 加速三行。
2. 读入 $2n$，令 `n/=2` 得每类票数。
3. `prod=1`；对 $i=1,\dots,n-1$：`prod*=double(2*i-1)/(2*i)`。
4. 输出 `1-prod`，`fixed<<setprecision(4)`。

### 复杂度

- 时间：$O(n)$，$n\le1250$。
- 空间：$O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$n=1,2,3,4$ 输出 `0.0000/0.5000/0.6250/0.6875` 与手算二项概率一致；$n=1..8$ 与"枚举前 $2n-2$ 人全部掷币序列并模拟售票"的独立暴力逐位吻合；$n=1250$ 输出 `0.9840`。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2719 搞笑世界杯
// 最后两人同票 ⇔ 前 2n-2 人售完后某类票已售罄 ⇔ 状态为 (n,n-2) 或 (n-2,n)。
// 反面：状态恰为 (n-1,n-1)。到达该状态的路径上两类票始终未售罄（a,b≤n-1<n），
// 故每步都是公平掷硬币，P(反面)=C(2n-2,n-1)/2^{2n-2}=∏_{i=1}^{n-1}(2i-1)/(2i)。
// 答案=1-该乘积。O(n) 递推乘积，double 精度远优于 1e-4 输出要求。
#include<bits/stdc++.h>
using namespace std;

int n;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;n/=2;	// 输入是 2n，转成每类票数 n
	double prod=1;	// prod=C(2n-2,n-1)/2^{2n-2}，n=1 时循环不执行，prod=1，答案 0
	for(int i=1;i<n;++i)
		prod*=double(2*i-1)/(2*i);
	cout<<fixed<<setprecision(4)<<1-prod<<'\n';
	return 0;
}
```

### 代码说明

- **输入折半**：题面输入是 $2n$，`cin>>n;n/=2` 后 `n` 才是每类票数。漏掉这步会把规模算错一倍。
- **为什么不用 DP**：概率 DP 在边界（某类售罄）的强制转移概率是 $1$，统一递推 $\tfrac12(f[i-1][j]+f[i][j-1])$ 会少算；而反面事件根本不经过边界，直接二项概率最干净。
- **乘积而非组合数**：$\binom{2n-2}{n-1}$ 与 $2^{2n-2}$ 在 $n=1250$ 时都远超任何内置类型，但比值 $\prod\frac{2i-1}{2i}$ 的每个因子 $\in(0,1)$，部分积单调降、永不溢出。
- `double(2*i-1)/(2*i)`：先转 `double` 再除，避免整数除法截断成 $0$。
- `prod` 初值 $1$ 兼作 $n=1$ 的空乘积，答案 $1-1=0$，无需特判。
- `fixed<<setprecision(4)` 保留 $4$ 位小数；误差分析见引理 6，精度绰绰有余。
