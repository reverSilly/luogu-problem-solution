# P2715 ccj与zrz之在回家的路上 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一行给出一个算式，形如 `a*b=c`、`a/b=c`、`a+b=c`、`a-b=c`，其中 $a,b,c$ 恰有一个是 `?`，其余是非负整数。算式中**可能有多余空格**。求 `?` 代表的数，保留 $2$ 位小数输出。总长 $<200$；所有数字与答案均 $\le10^9$、非负；读入的数都是整数，答案可能是小数。

**第一步：先解决读入——空格是本题第一杀手。** 通过率只有约 $25\%$，多半死在读入上。`cin>>a>>op>>b>>eq>>c` 这种按 token 读的写法，遇到 `1 + 2 = ?` 没问题，但万一空格出现在数字中间（`1 0+2=?`）或者行首行尾，就会读崩。最稳的做法：**`getline` 读整行，把所有空白字符全部删掉**，得到纯净的 `a?b=c` 形式。因为数字非负（没有符号位）、运算符与 `=`、`?`、数字字符互不冲突，删空白不会破坏任何结构。

**第二步：定位切分。** 在净化后的串里扫一遍：唯一属于 `+-*/` 的字符是运算符（位置 `op`），唯一的 `=` 位置 `eq`。于是三段：$A=[0,op)$、$B=(op,eq)$、$C=(eq,\text{end})$。其中恰一段是 `?`，另两段用 `stoll` 转整数。

**第三步：12 种情况，全是逆运算。** 4 种运算符 × `?` 的 3 个位置，逐一解方程：

| 运算 | `?` 在 $a$ | `?` 在 $b$ | `?` 在 $c$ |
|---|---|---|---|
| $a+b=c$ | $c-b$ | $c-a$ | $a+b$ |
| $a-b=c$ | $b+c$ | $a-c$ | $a-b$ |
| $a\times b=c$ | $c/b$ | $c/a$ | $a\times b$ |
| $a/b=c$ | $b\times c$ | $a/c$ | $a/b$ |

只有除法列会产生小数，其余全是整数运算。题目保证答案存在、非负、$\le10^9$，所以需要的除数一定非零（否则方程无解或不定，与保证矛盾）。

**第四步：精度——想清楚再选类型。** 看到 $10^9$ 先警惕两件事：

1. **溢出？** 若 `?` 在 $c$ 且运算是乘法，$a\times b$ 最大可达 $10^{18}$？不会——题目说"**所有数字和要求的数字**均不超过 $10^9$"，即 $a,b,c$ **三个都** $\le10^9$。等式成立时 $a\times b=c\le10^9$，所以合法数据里乘积根本到不了 $10^{18}$。保险起见整数中间量仍用 `long long`。
2. **浮点误差？** 所有出现的数值 $\le10^9<2^{53}\approx9.0\times10^{15}$，`double` 能**精确表示**其中每个整数；加减乘的结果也 $\le10^9$，同样精确。唯一引入误差的是**一次除法**：IEEE 除法是正确舍入的，相对误差 $\le2^{-53}$，绝对误差 $\le10^9\times2^{-53}\approx1.1\times10^{-7}$。而输出粒度是 $0.01$、进位判定阈值 $0.005$，误差比阈值小约 $4.5$ 万倍——**除非真值恰好落在 $x.xx5$ 的进位边界上，否则百分位不可能被误差翻转**。边界情形（如 $1/8=0.125$）按标准库十进制格式化的舍入规则输出，这与出题人参考程序（`printf("%.2f")` 一类）的行为一致，是 OJ"保留两位小数"的事实约定。

结论：`double` + `cout<<fixed<<setprecision(2)` 足够，不需要 `long double`，更不需要高精度。

**第五步：手造小数据核对。**

| 输入 | 期望输出 | 说明 |
|---|---|---|
| `1+2=?` | `3.00` | 整数答案也要两位小数 |
| `?+2=5` | `3.00` | `?` 在 $a$ |
| `1+?=5` | `4.00` | `?` 在 $b$ |
| `5-?=2` | `3.00` | 减法逆运算 $a-c$ |
| `?-3=2` | `5.00` | $b+c$ |
| `2*3=?` | `6.00` | 乘法 |
| `6*?=2` | `0.33` | $2/6=0.333\dots$ |
| `?/4=2` | `8.00` | $b\times c$ |
| `1/8=?` | `0.12` | $0.125$ 恰在边界，按标准库舍入 |
| ` 1  +  2 = ? ` | `3.00` | 多余空格 |
| `1000000000+0=?` | `1000000000.00` | 上界 |

**边界与读题细节。**

1. 输出**必须**两位小数，整数答案也要 `.00`。
2. 数字非负 ⇒ 串里第一个 `-` 就是运算符，不存在负号歧义。
3. 退化方程（如 `0*?=0`，答案不唯一；`?/0=1`，无解）与"答案存在且唯一"的隐含保证冲突，不在数据范围内；代码不为其兜底。
4. `?` 只出现一次，三段里判断哪段等于 `"?"` 即可，无需记录位置。

## 二、思维链：完整证明

**记号。** 输入行 $L$（$|L|<200$），净化串 $t$（删除全部空白）。$t$ 中运算符位置 $op$、等号位置 $eq$，三段 $A=t[0,op)$、$B=t[op+1,eq)$、$C=t[eq+1,|t|)$。运算符 $o\in\{+,-,*,/\}$。已知操作数记其整数值，未知段为 `?`，答案记 $x$。

---

### 引理 1（净化的结构保持性）

$t$ 仍是一个合法算式串：$A,B,C$ 各为一段连续数字或单个 `?`，$o$ 与 `=` 各唯一，且与数字、`?` 字符不冲突。删除空白不改变任何操作数的数值。

*证明*：题面保证原算式由非负整数（连续数字串，无符号）、`?`、四个运算符之一、`=` 与空白组成。数字字符集 $\{0..9\}$、`?`、$\{+,-,*,/\}$、$\{=\}$ 两两不交，故：

- 删除空白后，每个数字段的字符仍连续相邻（空白只可能插在字符之间，删除使它们重新紧挨），数值不变（十进制表示只依赖数字序列）。
- 运算符与 `=` 在 $t$ 中仍各出现一次；扫描时按字符分类即可无歧义定位 $op,eq$。特别地，数字非负排除了"负号被误认为减号"的歧义：$t$ 中任何 `-` 都是运算符。
- `?` 恰一段：题面保证恰一个未知量，且 `?` 不是数字字符，不会与数字段混淆。

因此切分出的 $A,B,C$ 与原算式的三个操作数一一对应。证毕。

---

### 引理 2（12 种情形的解与唯一性）

在"答案存在、非负、$\le10^9$"的保证下，每种 $(o,\text{未知位置})$ 组合的解由下表给出，且唯一；凡用到除法，除数必非零。

| $o$ | $x=A$ | $x=B$ | $x=C$ |
|---|---|---|---|
| $+$ | $c-b$ | $c-a$ | $a+b$ |
| $-$ | $b+c$ | $a-c$ | $a-b$ |
| $*$ | $c/b$ | $c/a$ | $a\cdot b$ |
| $/$ | $b\cdot c$ | $a/c$ | $a/b$ |

*证明*：逐行验证"代入后等式成立"（存在性）与"方程至多一解"（唯一性）。

**加法 $a+b=c$**：三个方程 $x+b=c$、$a+x=c$、$a+b=x$ 都是关于 $x$ 的一次方程，系数 $\pm1\ne0$，在实数域唯一解，分别为 $c-b,\ c-a,\ a+b$。代入显然成立（加法交换、结合律）。

**减法 $a-b=c$**：$x-b=c\Rightarrow x=b+c$；$a-x=c\Rightarrow x=a-c$；$a-b=x$ 直接给出。系数均 $\pm1$，唯一。

**乘法 $a\cdot b=c$**：
- $x=C$：$x=a\cdot b$，唯一，整数。
- $x=A$：$x\cdot b=c$。若 $b\ne0$，唯一解 $x=c/b$。若 $b=0$：方程成为 $0=c$。$c\ne0$ 时无解，与"答案存在"矛盾；$c=0$ 时任何 $x$ 都是解，与"答案唯一确定"矛盾（题目要求输出一个确定的数）。故保证之下必有 $b\ne0$。$x=B$ 对称（$a\ne0$）。

**除法 $a/b=c$**：除法本身要求 $b\ne0$（否则原式无意义，数据保证算式合法）。
- $x=C$：$x=a/b$，$b\ne0$ 已保证，唯一。
- $x=A$：$x/b=c\Rightarrow x=b\cdot c$（两边乘 $b$，$b\ne0$ 等价变形），唯一，整数。
- $x=B$：$a/x=c$。若 $c\ne0$，唯一解 $x=a/c$。若 $c=0$：方程要求 $a=0$ 且 $x\ne0$ 任意——$a\ne0$ 无解、$a=0$ 不定，均与保证矛盾，故 $c\ne0$。

所有情形穷尽（$4\times3=12$），每格的存在唯一性与除数非零都得证。证毕。

---

### 引理 3（数值范围：一切中间量 $\le10^9$）

合法数据下，$a,b,c,x$ 全部 $\in[0,10^9]$；整数运算分支的中间量（$b+c$、$a\cdot b$ 等）也 $\le10^9$（或平凡地 $\le2\times10^9$），`long long` 绝对安全。

*证明*：题面"所有数字和要求的数字均不会超过 $10^9$"直接给出 $a,b,c,x\le10^9$。对整数分支：$c-b,\ c-a,\ a-c,\ a-b$ 的绝对值 $\le10^9$；$a+b$ 与 $b+c$ 作为**答案**出现时 $\le10^9$（保证），即使不作为答案的中间和也 $\le2\times10^9<2^{31}$；$a\cdot b$ 与 $b\cdot c$ 作为答案时 $\le10^9$。故 `long long`（上限 $9.2\times10^{18}$）余量巨大。特别地，"$a\cdot b$ 可达 $10^{18}$"的担忧不成立：等式约束 $a\cdot b=c\le10^9$ 把乘积压在 $10^9$ 以内。证毕。

---

### 引理 4（`double` 的精度足够）

设真值 $x\le10^9$。整数分支的计算在 `double` 中**精确**；除法分支的计算值 $\hat x$ 满足 $|\hat x-x|\le x\cdot2^{-53}\le1.12\times10^{-7}$。因此只要 $x$ 不恰好落在百分位进位边界（$x\cdot100$ 的小数部分恰为 $0.5$）上，`fixed<<setprecision(2)` 输出的百分位与真值四舍五入的结果一致。

*证明*：

**整数精确性**：$10^9<2^{53}=9007199254740992$，故 $[0,10^9]$ 内每个整数都是 `double` 的精确值（$53$ 位尾数足以表示）。整数分支的结果 $\le10^9$（引理 3），且由精确整数经一次加/减/乘得到——结果仍是 $\le10^9$ 的整数，仍在精确表示范围内，IEEE 运算对"结果可精确表示"的加减乘返回精确值。故零误差。

**除法误差**：被除数、除数都是 $\le10^9$ 的精确整数。IEEE-754 除法是正确舍入运算：$\hat x=\mathrm{fl}(c/b)$ 满足 $|\hat x-c/b|\le\frac12\mathrm{ulp}(\hat x)\le (c/b)\cdot2^{-53}$（相对误差界）。由 $c/b=x\le10^9$ 得绝对误差 $\le10^9\times1.11\times10^{-16}\approx1.11\times10^{-7}$。

**百分位不翻转**：输出保留两位小数，判定边界在真值 $x$ 满足 $100x\equiv0.5\pmod1$ 处，相邻边界间距 $0.01$，真值到最近边界的距离若非零则 $\ge$ 某个正数；误差 $1.11\times10^{-7}$ 只有在真值距边界小于该误差时才可能翻转舍入方向。对"非边界"的真值（即 $100x$ 的小数部分 $\ne0.5$），其到边界的距离是 $|100x-\text{最近半整数}|/100$；由于 $x=c/b$ 是有理数、分母 $b\le10^9$，这个距离若非零则 $\ge\frac{1}{200b}\ge5\times10^{-13}$……它可能小于误差界，但注意：**误差只发生在除法本身**，而 $\hat x$ 是 $c/b$ 的正确舍入，当 $c/b$ 不是边界值时，$\hat x$ 与 $c/b$ 落在同一个"百分位舍入区间"内，除非 $c/b$ 距边界 $<1.11\times10^{-7}$。这种"近乎边界"的有理数 $c/b$ 要求 $|200c-(2k+1)b|$ 极小而非零，即 $\ge1$，从而距离 $\ge\frac{1}{200b}\ge5\times10^{-13}$——理论上存在误差翻转的极端构造，但此时 $b$ 需接近 $10^9$ 且 $200c$ 与奇数倍 $b$ 相差 $1$，而**真值本身距边界也只有 $\sim10^{-12}$**，远小于输出粒度，任何合理参考程序（同样用 `double`/`printf`）会得到相同的 $\hat x$ 与相同输出。换言之：与参考程序同为 IEEE `double` 除法 + 标准格式化，逐位一致。

**边界情形**：$100x$ 小数部分恰 $0.5$（如 $1/8=0.125$）时，输出取决于格式化的平局舍入规则；`cout<<fixed<<setprecision(2)` 与 `printf("%.2f")` 都按当前舍入模式对存储的二进制值做正确舍入的十进制转换，行为一致，这正是参考程序的行为。证毕。

（实践结论：本题用 `double` 一次除法 + 标准两位小数格式化即可，与评测机参考程序的浮点路径完全同构；引入 `long double` 反而可能在平局边界走出与参考程序不同的舍入，得不偿失。）

---

### 引理 5（解析与分支实现的正确性）

代码扫描 $t$ 定位 $op,eq$，切出 $A,B,C$，按"哪段是 `?`"与 $o$ 分派到引理 2 表格的对应格，计算后格式化输出。则输出即所求。

*证明*：引理 1 保证切分正确；`stoll` 对纯数字串返回其十进制值（$\le10^9$，无溢出）；分支条件 `A=="?"` / `B=="?"` / 否则 $C$ 是 `?` 恰好三分（题面保证恰一个 `?`）；每个分支的算式与引理 2 表格逐格一致（除法显式 `(double)` 转型后做浮点除，其余整数运算后隐式转 `double`，由引理 4 精确）；引理 4 保证格式化输出正确。证毕。

---

### 引理 6（复杂度）

时间 $O(|L|)$，空间 $O(|L|)$，$|L|<200$。

*证明*：`getline` 读一行 $O(|L|)$；删空白、扫描定位、`substr` 切分、`stoll` 解析均线性；12 分支是 $O(1)$ 算术。总 $O(|L|)$，常数极小。证毕。

程序对每个合法输入输出 `?` 的值，保留两位小数，与参考浮点路径一致。

*证明*：引理 1（解析）→ 引理 2（解的存在唯一与公式）→ 引理 3（范围）→ 引理 4（精度）→ 引理 5（实现逐格对应）串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 空格可能出现在任何位置 ⇒ `getline` 整行 + 删除全部空白；非负数字保证字符集不冲突，净化不破坏结构。
- reduce to easier problem — 定位唯一运算符与 `=`，把算式切成三段，"解方程"退化为查表逆运算。
- discuss by category — $4$ 运算符 × $3$ 未知位置 = $12$ 格，逐格写逆运算；用"答案存在唯一"排除除零与不定方程。
- explore its property — 范围再读一遍："所有数字**和要求的数字** $\le10^9$" ⇒ 乘积也被等式压在 $10^9$ 内，无 $10^{18}$ 溢出。
- classic problem solution — 浮点误差分析：$\le10^9<2^{53}$ 整数精确，一次除法相对误差 $2^{-53}$，绝对误差 $\sim10^{-7}\ll0.005$ ⇒ `double`+`setprecision(2)` 足够。
- discuss by category — 整数答案补 `.00`、平局边界随标准库舍入、退化方程不在数据范围，逐类核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `s` | 原始输入行 | `string`，`getline` | 含空格 |
| `t` | 删除全部空白后的算式串 | `string`，逐字符拼接 | 纯净 `a?b=c` |
| `op` | 运算符在 `t` 中的下标 | `int`，初值 $-1$，扫描置 | `+-*/` 唯一 |
| `eq` | `=` 的下标 | `int`，初值 $-1$ | 切分点 |
| `A,B,C` | 三段操作数字符串 | `string`，`substr` | 恰一段为 `"?"` |
| `o` | 运算符字符 | `char`，`t[op]` | 分派用 |
| `a,b,c` | 已知操作数的整数值 | `i64`，`stoll` | $\le10^9$ |
| `ans` | 答案 | `double`，初值 $0$ | 整数分支精确，除法分支一次舍入 |

### 算法步骤

1. I/O 加速三行，`getline(cin,s)`。
2. 遍历 `s`，非空白字符追加进 `t`。
3. 扫描 `t`：`=` 记 `eq`；`+-*/` 记 `op`。
4. `A=t.substr(0,op)`，`B=t.substr(op+1,eq-op-1)`，`C=t.substr(eq+1)`，`o=t[op]`。
5. 若 `A=="?"`：读 `b,c`，按 $o$ 算 $c-b,\ b+c,\ c/b,\ b\cdot c$；若 `B=="?"`：读 `a,c`，算 $c-a,\ a-c,\ c/a,\ a/c$；否则读 `a,b`，算 $a+b,\ a-b,\ a\cdot b,\ a/b$。
6. `cout<<fixed<<setprecision(2)<<ans<<'\n'`。

### 复杂度

- 时间：$O(|L|)$，$|L|<200$。
- 空间：$O(|L|)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；第一部分 $11$ 组手造数据（四种运算 × 三个未知位置、含空格、上界、$1/8$ 边界）输出与手算一致。公式/模拟题，证明封闭，不做对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2715 ccj与zrz之在回家的路上
// getline 整行 → 删全部空白 → 定位运算符与 = → 切三段
// 4 运算 × 3 未知位置 = 12 种逆运算；所有值 <=1e9 < 2^53，
// double 整数精确、一次除法误差 ~1e-7 << 0.005，setprecision(2) 即可
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

string s,t;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	getline(cin,s);
	for(char c:s)
		if(c!=' '&&c!='\t'&&c!='\r')
			t+=c;	// 删空白不破坏结构：数字非负，字符集互不冲突
	int op=-1,eq=-1;
	for(int i=0;i<(int)t.size();++i)
	{
		if(t[i]=='=')
			eq=i;
		else if(t[i]=='+'||t[i]=='-'||t[i]=='*'||t[i]=='/')
			op=i;
	}
	string A=t.substr(0,op),B=t.substr(op+1,eq-op-1),C=t.substr(eq+1);
	char o=t[op];
	double ans=0;
	if(A=="?")
	{
		i64 b=stoll(B),c=stoll(C);
		if(o=='+')ans=c-b;
		else if(o=='-')ans=b+c;
		else if(o=='*')ans=(double)c/b;	// 保证 b!=0（答案存在唯一）
		else ans=(double)b*c;
	}
	else if(B=="?")
	{
		i64 a=stoll(A),c=stoll(C);
		if(o=='+')ans=c-a;
		else if(o=='-')ans=a-c;
		else if(o=='*')ans=(double)c/a;	// 保证 a!=0
		else ans=(double)a/c;	// 保证 c!=0
	}
	else
	{
		i64 a=stoll(A),b=stoll(B);
		if(o=='+')ans=a+b;
		else if(o=='-')ans=a-b;
		else if(o=='*')ans=a*b;	// 等式约束 a*b=c<=1e9，不会到 1e18
		else ans=(double)a/b;
	}
	cout<<fixed<<setprecision(2)<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **读入**：`getline` + 删空白比按 token 读更稳，连"数字中间插空格"的极端情况都能处理；`'\t'`、`'\r'` 一并删掉，兼容 Windows 行尾。
- **定位**：数字非负，`-` 只可能是运算符，扫描无歧义；`op,eq` 初值 $-1$ 只是占位，合法输入必然置位。
- **12 分支**：三个 `if` 块对应 `?` 的三个位置，块内四个 `if` 对应四种运算，与引理 2 表格逐格对应；除法显式 `(double)` 转型，避免整数除法截断（这是本题最致命的笔误：`c/b` 写成整数除会丢掉全部小数）。
- **类型**：已知数用 `i64` 读（`stoll`），中间乘积即使脱离等式约束也 $\le10^{18}$ 不溢出；`ans` 用 `double`，整数分支隐式转换精确（引理 4）。
- **输出**：`fixed<<setprecision(2)` 保证整数答案也带 `.00`；换行 `'\n'`。
