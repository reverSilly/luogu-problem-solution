# P2442 分数统计 — 题解

## 一、解题过程：人类思考叙事

题意：有 $n$ 个班，第 $i$ 班的平均评价值是 $a_i\in[1,100]$，人数是 $b_i\in[1,100]$。题目说「大家都假装每个班每个人的评价值就是班级的平均评价值」，也就是说**第 $i$ 班的 $b_i$ 个人，每人的评价值都当作 $a_i$**。$q$ 个询问，每次给一个班级区间 $[u,v]$ 和一个操作号：

1. 这个区间里**所有人**评价值的平均数（保留两位小数，**向下取整**）；
2. 所有人评价值的**众数**（多个众数取最小的）；
3. 所有人评价值的**极差**（最大减最小）。

规模：$n,q\le2\times10^5$，最大测试点时限 $1$s，题面还特意提醒「建议使用较快的读入方式」。标签里有「线段树 / 分块 / ST 表 / **离线处理**」——离线处理这个词很关键，后面会看到它才是本题的钥匙。

**第一步：把「所有人」翻译成一个可计算的多重集。** 区间 $[u,v]$ 里的学生集合，就是「$b_u$ 个 $a_u$、$b_{u+1}$ 个 $a_{u+1}$、……、$b_v$ 个 $a_v$」拼起来。于是三个询问都变成对这个多重集的统计：

- 总分 $S=\sum_{i=u}^{v}a_ib_i$，总人数 $B=\sum_{i=u}^{v}b_i$，平均数 $=S/B$；
- 值 $x$ 的人数 $\mathrm{cnt}_x=\sum_{i=u,\,a_i=x}^{v}b_i$，众数就是让 $\mathrm{cnt}_x$ 最大的最小 $x$；
- 因为 $b_i\ge1$，每个班至少贡献一个人，所以最大/最小评价值就是 $\max a_i/\min a_i$。

**第二步：先挑软柿子。** 平均数用前缀和 $O(1)$；极差用 ST 表 $O(1)$（$O(n\log n)$ 预处理）。这两个都是模板。**众数才是硬骨头**：它不可差分（$\mathrm{mode}[1..v]$ 与 $\mathrm{mode}[1..u-1]$ 推不出 $\mathrm{mode}[u..v]$），线段树合并两个区间的众数也不是 $O(1)$ 能做的。

**第三步：暴力估算，确认必须优化。** 每个询问扫一遍区间、开 $101$ 个桶统计，$O(nq)=4\times10^{10}$，$1$s 内绝无可能。

**第四步：盯住值域。** $a_i\in[1,100]$——**只有 100 种取值**！这是本题最重要的约束。众数不需要「在区间里找出现最多的数」这种一般性难题，只需要**比较 100 个计数器**。于是问题化归为：

> 对每个 $x\in[1,100]$，快速求出 $\mathrm{cnt}_x([u,v])$。

只要这件事能 $O(1)$ 做到，每个询问 $O(100)$，总共 $2\times10^7$，稳过。

**第五步：想法 A——100 套前缀和。** 令 $C[x][i]=\sum_{j\le i,\,a_j=x}b_j$，则 $\mathrm{cnt}_x([u,v])=C[x][v]-C[x][u-1]$，$O(1)$。时间 $O(100(n+q))$ 完美。**但内存**：$100\times2\times10^5$ 个 `int` $=8\times10^7$ 字节 $=80$ MB。这已经贴着常见内存上限了，而且预处理要写 $2\times10^7$ 个格子、访问时跨 $100$ 个大数组跳，缓存极不友好。有没有办法把内存压下来？

**第六步：想法 B——每个值存位置表 + 二分。** 对值 $x$，把所有 $a_i=x$ 的下标排序存起来，再存这些位置上 $b$ 的前缀和。询问时二分出 $[u,v]$ 内的位置区间，$O(\log n)$ 得到 $\mathrm{cnt}_x$。内存降到 $O(n)$，但每询问 $O(100\log n)\approx1800$，总共 $3.6\times10^8$，$1$s 太悬。**二分把复杂度乘上去了，不划算。**

**第七步：想法 C——把「值」这一维搬到最外层离线扫描。** 关键洞察：我们**根本不需要 100 套前缀和同时存在**！询问是离线已知的，那就：

```
for x = 1..100:
    用同一个数组 c[] 建「值为 x 的人数」前缀和      // O(n)
    for 每个询问 j:
        cnt = c[v_j] - c[u_j-1]                    // O(1)
        把 cnt 累进询问 j 的「当前最优众数」与「当前最小/最大出现值」
```

$c[]$ 被**复用 100 次**，内存从 $100n$ 塌缩到 $n$。时间仍是 $O(100(n+q))=4\times10^7$，内存 $O(n+q)\approx11$ MB。这就是标签里「离线处理」的含义：**交换循环顺序，用时间维换空间维**。

**第八步：两个白送的红利。**

- **并列取最小**：因为 $x$ 是**从小到大**扫的，更新最优时只用**严格大于**（`cnt>bc`），那么并列时先来的小 $x$ 不会被后来的大 $x$ 顶掉。不需要任何额外的排序或 tie-break 逻辑。
- **极差也一起做了**：$b_i\ge1$ 保证「$\mathrm{cnt}_x>0\iff$ 值 $x$ 在区间里出现过」。于是升序扫描中**第一个** $\mathrm{cnt}>0$ 的 $x$ 就是最小值，**最后一个**就是最大值。ST 表完全不需要了！同一个扫描顺手解决询问 2 和询问 3。

**第九步：平均数的「向下取整」是个陷阱。** 我一开始想写 `printf("%.2f", (double)S/B)`，但题目说的是**向下取整（截断）**，不是四舍五入。两个具体反例（都在本题数据范围内）：

- $a=[1,2],\ b=[1,7]$：$S=15,B=8$，平均 $=1.875$。截断应为 `1.87`，而 `printf("%.2f",1.875)` 输出 `1.88`。**四舍五入直接错。**
- $a=[1,2],\ b=[85,15]$：$S=115,B=100$，平均 $=1.15$。若改用浮点再 `floor(avg*100)`：`double` 里 $1.15$ 实际是 $1.14999999999999991118$，乘 $100$ 得 $114.999\ldots$，`floor` 后是 $114$，输出 `1.14`。**浮点截断也错。**

结论：**全程整数**。令 $t=\lfloor 100S/B\rfloor$（正整数除法就是下取整），输出 `t/100` `.` `t%100`（后者补足两位）。$100S\le100\times2\times10^9=2\times10^{11}$，必须 `long long`。

**第十步：实现上的坑（都是会真错的）。**

1. **哨兵必须显式初始化**：`mn[j]` 要置 `1145141919`。全局 `int` 数组默认是 **0**，若忘了置 INF，最小值永远是 0，极差全错。
2. **累加器只能在扫描前初始化一次**：`bc[j]=-1, mn[j]=INF, mx[j]=0` 要在读入询问时设好；若放进 `for x` 循环里，每轮都被清空，最后只剩 $x=100$ 的信息。
3. **复用数组的零点**：每轮 `c[0]=0` 必须保证（本实现只写 `c[1..n]`，`c[0]` 天然保持 0，但仍显式写出以免误改）。
4. **$u>v$ 的防御**：题面没明说 $u\le v$，读入后 `if(u>v)swap(u,v)` 一行保险。
5. **输出顺序 = 输入顺序**：离线扫描打乱了处理顺序，答案必须存进 `ans[j]` 按原序号输出。
6. 询问 1 在前缀和阶段就能算完，扫描时 `continue` 跳过，省掉无用功。

**规模核算与实测**：$100\times(2\times10^5+2\times10^5)=4\times10^7$ 次简单运算，$n=q=2\times10^5$ 随机数据实测 **0.26s**，$1$s 时限内很宽裕。

## 二、思维链：完整证明

统一记号：班级下标 $1..n$（实现内部 0-based），$a_i\in[1,100]$，$b_i\in[1,100]$，值域 $V=100$。询问 $j$ 为 $(o_j,u_j,v_j)$，不妨设 $u_j\le v_j$（否则交换，区间集合不变）。定义区间多重集
$$\mathcal{M}(u,v)=\biguplus_{i=u}^{v}\{\underbrace{a_i,\dots,a_i}_{b_i\text{ 个}}\}.$$

### 引理 1（多重集模型与三个统计量的表达式）

对区间 $[u,v]$：
(a) 总人数 $B(u,v)=\sum_{i=u}^{v}b_i$，总分 $S(u,v)=\sum_{i=u}^{v}a_ib_i$，平均数 $=S/B$；
(b) 值 $x$ 的人数 $\mathrm{cnt}_x(u,v)=\sum_{i=u}^{v}[a_i=x]\,b_i$；
(c) 最大评价值 $=\max_{u\le i\le v}a_i$，最小评价值 $=\min_{u\le i\le v}a_i$，极差为二者之差。

*证明*：由题意，第 $i$ 班的 $b_i$ 个人每人评价值都是 $a_i$，故 $\mathcal{M}(u,v)$ 是这些常数值多重集的不交并。
(a) 多重集元素个数 $=\sum b_i$；元素之和 $=\sum (b_i\cdot a_i)$；平均数按定义是和除以个数。因 $b_i\ge1$ 且 $u\le v$，$B\ge1$，除法有意义。
(b) 值 $x$ 的重数等于各段贡献之和：第 $i$ 段贡献 $b_i$ 当且仅当 $a_i=x$，否则 $0$，即 $[a_i=x]b_i$。求和即得。
(c) 多重集的最大元素是各段最大元素的最大值；第 $i$ 段非空（$b_i\ge1$）且所有元素都是 $a_i$，故其最大/最小元素都是 $a_i$。于是整体最大/最小就是 $\max a_i/\min a_i$。**这里 $b_i\ge1$ 是必要条件**：若某班人数为 0，它就不该参与 max/min，结论会失效。证毕。

### 引理 2（前缀和差分）

设 $w_1,\dots,w_n$ 为任意整数权，$P[0]=0,\ P[i]=P[i-1]+w_i$。则对 $1\le u\le v\le n$ 有 $\sum_{i=u}^{v}w_i=P[v]-P[u-1]$。

*证明*：$P[v]=\sum_{i=1}^{v}w_i$，$P[u-1]=\sum_{i=1}^{u-1}w_i$（由递推展开即得，对 $i$ 归纳：$P[0]=0$ 为空和；$P[i]=P[i-1]+w_i=\sum_{j<i}w_j+w_i=\sum_{j\le i}w_j$）。两式相减，$1..u-1$ 的项完全抵消，剩 $\sum_{i=u}^{v}w_i$。证毕。

**应用**：取 $w_i=a_ib_i$ 得 $S$；取 $w_i=b_i$ 得 $B$；对固定 $x$ 取 $w_i=[a_i=x]b_i$ 得 $\mathrm{cnt}_x$。三者都是 $O(1)$ 查询，前提是相应前缀数组已建好。

### 引理 3（平均数的精确截断输出）

设 $S,B$ 为正整数，平均数 $\alpha=S/B$。题目要求输出「$\alpha$ 保留两位小数、向下取整」，即输出 $\dfrac{\lfloor 100\alpha\rfloor}{100}$ 的两位小数十进制串。令 $t=(100\cdot S)/B$（**整数除法**），则 $t=\lfloor100\alpha\rfloor$，且所求字符串为「$t/100$ + `.` + $t\%100$ 补足两位」。

*证明*：
**第一步**：$100\alpha=100S/B$ 是正有理数。对正整数 $p,q$，C++ 的 `p/q` 定义为向零取整，正数时即 $\lfloor p/q\rfloor$。故 $t=\lfloor100S/B\rfloor=\lfloor100\alpha\rfloor$。
**第二步**：$\lfloor100\alpha\rfloor/100$ 是不超过 $\alpha$ 的最大的「两位小数」（即 $0.01$ 的整数倍）：设 $\beta=m/100\le\alpha$（$m$ 整数），则 $m\le100\alpha$，故 $m\le\lfloor100\alpha\rfloor=t$，即 $\beta\le t/100$；而 $t/100\le\alpha$ 显然。所以 $t/100$ 正是所求的截断值。
**第三步**：写 $t=100q+r$，$0\le r<100$（带余除法唯一），则 $t/100=q$、$t\%100=r$，且 $t/100$ 的十进制串接上 `.` 再接 $r$ 的**定长两位**串，其数值为 $q+r/100=t/100$。由于 $r$ 补零到两位，拼接不会错位；$q$ 不带前导零，故整个串是标准表示。
**第四步（范围）**：$S\le100\cdot100\cdot n=2\times10^9$，故 $100S\le2\times10^{11}<2^{63}-1\approx9.2\times10^{18}$，`long long` 安全；$t\le100\cdot100=10^4$。证毕。

**引理 3′（浮点做法为何不可靠）**：存在合法数据使 `floor(100*(double)S/B)` 与 `printf("%.2f",(double)S/B)` 都给出错误答案。

*证明*（构造反例）：
- 取 $a=[1,2],b=[1,7]$：$S=1\cdot1+2\cdot7=15$，$B=8$，$\alpha=1.875$，$t=187$，正确输出 `1.87`。而 `printf("%.2f",1.875)` 按四舍五入输出 `1.88` $\ne$ `1.87`。故「保留两位小数」若用默认 rounding 就违背了题目的「向下取整」。
- 取 $a=[1,2],b=[85,15]$：$S=115,B=100$，$\alpha=1.15$，$t=115$，正确输出 `1.15`。但二进制浮点中 $1.15$ 的最近可表示值是 $1.14999999999999991118\ldots$，乘 $100$ 后仍小于 $115$，`floor` 得 $114$，输出 `1.14` $\ne$ `1.15`。故「先转 double 再截断」也不可靠。
两例的 $a_i,b_i$ 都在 $[1,100]$ 内，是合法输入。证毕。

> 这两个反例是实测确认的，不是理论担忧。整数运算从根本上绕开了它们。

### 引理 4（众数的刻画）

区间众数 $=\min\{x\in[1,100]:\mathrm{cnt}_x=\max_{y\in[1,100]}\mathrm{cnt}_y\}$。

*证明*：按定义，众数是多重集中出现次数最多的值；出现次数即 $\mathrm{cnt}_x$（引理 1(b)）。题目规定多个众数取最小，故取 argmax 集合中的最小元。又因区间非空且 $b_i\ge1$，$\sum_x\mathrm{cnt}_x=B\ge1$，故至少一个 $x$ 的 $\mathrm{cnt}_x\ge1$，最大值 $\ge1$，argmax 集合非空，最小元存在。证毕。

### 引理 5（升序扫描 + 严格大于 ⇒ 最小 argmax）

设 $c_1,\dots,c_V$ 为非负整数。执行：`best=-1; val=0;` 然后对 $x=1..V$，若 $c_x>best$ 则 `best=c_x; val=x;`。结束后 $best=\max_x c_x$ 且 $val=\min\{x:c_x=best\}$。

*证明*：对 $x$ 归纳，证明不变量「处理完 $x$ 后，$best=\max_{y\le x}c_y$，$val=\min\{y\le x:c_y=best\}$」。
$x=0$（未处理）：$best=-1$，而所有 $c_y\ge0>-1$，可视为空集上的约定初值，不变量平凡成立（无 $y\le0$）。
设对 $x-1$ 成立，记 $M=\max_{y<x}c_y$，$w=\min\{y<x:c_y=M\}$。处理 $x$：
- 若 $c_x>M$：更新 $best=c_x,\ val=x$。此时 $\max_{y\le x}c_y=c_x$（严格大于此前所有），且 argmax 集合在 $y\le x$ 中只有 $x$（其余都 $<c_x$），故 $val=x$ 是最小 argmax。不变量成立。
- 若 $c_x\le M$：不更新。$\max_{y\le x}c_y=M$ 不变；argmax 集合要么不变（$c_x<M$），要么新增 $x$（$c_x=M$），但 $w<x$，故最小元仍是 $w$。不变量成立。

取 $x=V$ 即得结论。**严格大于是关键**：若写成 `>=`，则 $c_x=M$ 时会把 $val$ 更新成更大的 $x$，得到的是**最大** argmax，与题目要求相反。证毕。

### 引理 6（出现性判定与极差的免费获取）

对固定 $x$ 与非空区间 $[u,v]$：$\mathrm{cnt}_x(u,v)>0\iff\exists i\in[u,v],a_i=x$。因此在 $x=1..V$ 的升序扫描中，第一个使 $\mathrm{cnt}_x>0$ 的 $x$ 等于 $\min_{u\le i\le v}a_i$，最后一个这样的 $x$ 等于 $\max_{u\le i\le v}a_i$。

*证明*：
($\Leftarrow$) 若存在这样的 $i$，则 $\mathrm{cnt}_x\ge b_i\ge1>0$。
($\Rightarrow$) 若 $\mathrm{cnt}_x=\sum_{i=u}^{v}[a_i=x]b_i>0$，因每项非负，必有某项 $[a_i=x]b_i>0$，即 $a_i=x$（且 $b_i>0$）。
故「$x$ 出现」与「$\mathrm{cnt}_x>0$」等价。设 $A=\{a_i:u\le i\le v\}$，则 $\{x:\mathrm{cnt}_x>0\}=A$。升序扫描第一个命中的 $x$ 是 $A$ 的最小元，最后一个是 $A$ 的最大元（$A$ 非空因区间非空）。由引理 1(c)，极差 $=\max A-\min A$。证毕。

**实现对应**：`mn[j]` 初值 INF，第一次 `cnt>0` 时赋值（此后不再改）；`mx[j]` 每次 `cnt>0` 都覆盖。扫描结束时 `mn[j]=min A`、`mx[j]=max A`。**$b_i\ge1$ 再次是必要条件**。

### 引理 7（离线扫描的等价性与内存塌缩）

设「在线版」为：预处理 $C[x][i]$（$x=1..V$，$i=0..n$），每个询问对每个 $x$ 取 $C[x][v]-C[x][u-1]$。则「离线版」（外层 $x$、内层询问、复用单个 $c[\,]$）对每个询问得到的 $\mathrm{cnt}_x$ 序列与在线版**完全相同**，因而由引理 5、6 得到的众数与极差也相同。

*证明*：离线版第 $x$ 轮开始时执行 `c[0]=0; c[i]=c[i-1]+[a_i=x]b_i`。由引理 2 的归纳，本轮结束后 $c[i]=\sum_{j\le i}[a_j=x]b_j=C[x][i]$，与在线版的第 $x$ 行逐元素相等。本轮内对询问 $j$ 计算的 `c[v_j]-c[u_j-1]` 因此等于 $C[x][v_j]-C[x][u_j-1]=\mathrm{cnt}_x(u_j,v_j)$。每个 $(x,j)$ 对恰好被计算一次，且计算时 $c$ 的内容只依赖 $x$（上一轮的值被完全覆盖：`c[0]` 显式置 0，`c[1..n]` 全部重写），故各轮互不干扰。于是离线版把在线版的二维访问按 $x$ 分层重放，结果一致。

内存方面：在线版需同时保存 $V(n+1)$ 个整数；离线版任一时刻只需 $c[0..n]$ 共 $n+1$ 个整数，加上询问与每询问 $O(1)$ 的累加器，故空间 $O(n+q)$。证毕。

> 这就是「用时间维换空间维」的严格表述：**外层循环变量所对应的那一维数组，可以被复用**。

### 引理 8（累加器初始化时机）

`bc[j]`（当前最大计数）、`mn[j]`（当前最小出现值）、`mx[j]`（当前最大出现值）必须在**整个 $x$ 扫描开始之前**初始化一次；若放在 $x$ 循环内部初始化，结果错误。

*证明*：引理 5、6 的归纳不变量是「处理完 $x$ 后，累加器汇总了 $1..x$ 的全部信息」，其归纳基础是 $x=0$ 时的初值（$best=-1$、$mn=\text{INF}$、$mx=0$）。若每轮重置，则第 $x$ 轮结束时累加器只含 $x$ 这一个值的信息：$bc$ 变成 $\mathrm{cnt}_V$、$val$ 变成 $V$（只要 $\mathrm{cnt}_V>-1$ 恒成立），众数恒为 $100$；$mn$ 变成「$100$ 是否出现」，极差也全错。故必须在扫描外初始化。

另外，`mn[j]` 的初值必须是**大于 100 的哨兵**（如 `1145141919`）。全局 `int` 数组默认值为 $0$，若沿用默认值，则 `if(mn[j]==INF)` 永不成立，`mn[j]` 恒为 $0$，极差变成 $\max a_i-0$，错误。证毕。

### 引理 9（数值范围与类型选择）

(a) $B(u,v)\le100n=2\times10^7<2^{31}-1$；(b) $\mathrm{cnt}_x(u,v)\le B\le2\times10^7$；(c) $S(u,v)\le100\cdot100\cdot n=2\times10^9$；(d) $100S\le2\times10^{11}$。故 `sb,c,bc,mn,mx` 用 `int` 足够，`s` 与类型 1 的答案用 `i64`。

*证明*：(a) 每项 $b_i\le100$，共 $\le n$ 项。(b) $\mathrm{cnt}_x$ 是 $B$ 的一部分（各值人数之和为 $B$），故 $\le B$。(c) 每项 $a_ib_i\le10^4$，共 $\le n=2\times10^5$ 项，积 $\le2\times10^9$。(d) 乘 100 即得。$2\times10^7<2.147\times10^9$，`int` 安全；$2\times10^{11}>2^{31}-1$，必须 64 位。证毕。

> 注意 (c)：$2\times10^9$ 其实**勉强**塞得进 `int`，但 $100S$ 立刻越界，所以 `s` 一律用 `i64`，不要赌边界。

### 定理（算法正确性）

程序对每个询问输出的结果与题目定义一致。

*证明*：
- 类型 1：由引理 1(a)，平均数 $=S/B$；由引理 2，$S,B$ 由前缀差分 $O(1)$ 得到且精确；由引理 3，整数计算 $t=(100S)/B$ 并按 `t/100 . t%100`（补两位）输出，恰为题目要求的向下取整两位小数；由引理 9(d)，无溢出。
- 类型 2：由引理 7，扫描得到的 $\mathrm{cnt}_x$ 与定义一致；由引理 4，众数是最小 argmax；由引理 5，升序 + 严格大于的更新规则恰好给出最小 argmax；由引理 8，累加器初始化正确。
- 类型 3：由引理 6，`mn/mx` 分别是区间内出现的最小/最大值，由引理 1(c) 其差即极差。
- 输出按询问原序号 $j$ 进行，离线处理不打乱顺序。$u>v$ 时交换不改变区间集合（引理 1 的表达式对 $u\le v$ 要求，交换后满足）。
证毕。

### 引理 10（复杂度）

时间 $O(V(n+q))$，空间 $O(n+q)$，其中 $V=100$。

*证明*：前缀和预处理 $O(n)$；读入与类型 1 计算 $O(q)$；扫描共 $V$ 轮，每轮建 $c$ 用 $O(n)$、遍历询问用 $O(q)$（每个询问 $O(1)$：一次减法、常数次比较），合计 $O(V(n+q))=100\times4\times10^5=4\times10^7$。输出 $O(q)$。空间：`a,b,sb,c` 各 $O(n)$，`s` $O(n)$，`Q,ans,bc,mn,mx` 各 $O(q)$，总计 $O(n+q)$，实测约 $11$ MB。证毕。

### 附：其它可行路线为何被放弃

- **100 套前缀和（在线）**：时间同阶，但空间 $80$ MB，且跨 100 个大数组随机访问缓存不友好（引理 7 的对照）。
- **每值位置表 + 二分**：空间 $O(n)$，但时间 $O(Vq\log n)\approx3.6\times10^8$，$1$s 风险大。
- **线段树维护众数**：众数不可合并（两个子区间的众数推不出父区间众数），需要每节点存 100 个计数，空间 $O(100n)$ 且合并 $O(100)$，查询 $O(100\log n)$，全面劣于离线扫描。
- **ST 表求极差**：本身正确（$O(n\log n)$ 预处理、$O(1)$ 查询），但引理 6 表明极差已被同一扫描免费解决，额外 $28$ MB 的 ST 表纯属浪费。
- **莫队**：$O((n+q)\sqrt n)\approx9\times10^7$ 次指针移动，还要额外维护「计数的计数」以支持众数回退，复杂度与实现难度都更高。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 「假装每人等于班级平均」⇒ 区间是「$b_i$ 个 $a_i$」的多重集，三个统计量全部写成 $\sum$ 形式。
- **discuss by category** — 三个询问分开看：平均数（前缀和）、极差（ST 表）都是模板，众数不可差分才是难点。
- **consider easier version** — 先估算暴力 $O(nq)=4\times10^{10}$，确认必须优化。
- **explore its property** — 值域只有 $100$！众数化归为「比较 100 个计数器」，难点转移到「快速求 $\mathrm{cnt}_x([u,v])$」。
- **classic problem solution** — 想法 A：100 套前缀和，$O(1)$ 取计数，但 $80$ MB 内存触顶。
- **classic problem solution** — 想法 B：每值位置表 + 二分，内存降下来但时间乘上 $\log n$，$3.6\times10^8$ 太悬。
- **reduce to easier problem** — 想法 C：询问离线已知 ⇒ 把「值」这一维提到最外层，复用同一个前缀数组，内存从 $100n$ 塌缩到 $n$。
- **explore its property** — 升序扫描 + 严格大于 ⇒ 并列自动取最小值，tie-break 白送。
- **reduce to easier problem** — $b_i\ge1\Rightarrow\mathrm{cnt}_x>0\iff x$ 出现 ⇒ 同一扫描顺手求出极差，ST 表可删。
- **explore its property** — 「向下取整」不是四舍五入：$1.875\to1.87$；浮点截断也会错：$1.15\to1.14$。全程整数 $t=(100S)/B$。
- **discuss by category** — 工程边界：哨兵显式置 INF（全局数组默认 0）、累加器只在扫描外初始化、复用数组零点、$u>v$ 交换、按原序号输出。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| $n,q$ | 班级数、询问数 | `int`，读入 | $\le2\times10^5$ |
| `a[i]` | 第 $i$ 班平均评价值（内部 0-based） | `int[mxn]`，读入 | $[1,100]$ |
| `b[i]` | 第 $i$ 班人数 | `int[mxn]`，读入 | $[1,100]$，**保证 $\ge1$** |
| `s[i]` | 前 $i$ 个班的总分 $\sum a_jb_j$ | `i64[mxn]`，`s[0]=0` | 前缀和，下标 = 个数 |
| `sb[i]` | 前 $i$ 个班的总人数 $\sum b_j$ | `int[mxn]`，`sb[0]=0` | 同上 |
| `c[i]` | **当前值 $x$** 的前 $i$ 个班人数 | `int[mxn]`，每轮 `c[0]=0` 后重建 | 复用 100 次 |
| `Q[j].o/u/v` | 第 $j$ 个询问的操作号与区间（0-based 闭） | `struct{int o,u,v;}[mxn]` | 读入即 `--u;--v`，必要时 swap |
| `ans[j]` | 第 $j$ 个询问的答案 | `i64[mxn]` | 类型 1 存 $t=\lfloor100\alpha\rfloor$；类型 2 存众数 |
| `bc[j]` | 扫描到当前 $x$ 为止的最大 $\mathrm{cnt}$ | `int[mxn]`，**扫描前**置 $-1$ | best count |
| `mn[j]` | 扫描到当前为止最小的出现值 | `int[mxn]`，**扫描前**置 `inf` | 只赋一次 |
| `mx[j]` | 扫描到当前为止最大的出现值 | `int[mxn]`，**扫描前**置 $0$ | 每次覆盖 |
| `x` | 外层枚举的评价值 | `int`，$1\dots100$ | 升序是 tie-break 的关键 |
| `cnt` | 当前询问在当前 $x$ 下的人数 | `int` | `c[v+1]-c[u]` |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 必须 $>100$ |
| `mxn` | $2\times10^5+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速：`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`。
2. 读入 $n,q$，读入 `a[0..n-1]`、`b[0..n-1]`。
3. 建前缀和：`s[i+1]=s[i]+(i64)a[i]*b[i]`，`sb[i+1]=sb[i]+b[i]`。
4. 读入每个询问 `o,u,v`，`--u;--v`，若 `u>v` 则交换；初始化 `mn[j]=inf, mx[j]=0, bc[j]=-1`；若 `o==1`，立即算 `ans[j]=(s[v+1]-s[u])*100/(sb[v+1]-sb[u])`。
5. 对 `x=1..100`：
   1. `c[0]=0`；对 `i=0..n-1` 令 `c[i+1]=c[i]+(a[i]==x?b[i]:0)`。
   2. 对每个询问 `j`：`o==1` 跳过；否则 `cnt=c[v+1]-c[u]`。
      - `o==2`：若 `cnt>bc[j]`，则 `bc[j]=cnt; ans[j]=x`（严格大于 ⇒ 并列保留最小 $x$）。
      - `o==3`：若 `cnt>0`，则「`mn[j]==inf` 时 `mn[j]=x`」且「`mx[j]=x`」。
6. 按 `j=0..q-1` 输出：`o==1` 输出 `ans[j]/100` `.` `ans[j]%100`（不足两位补 `0`）；`o==2` 输出 `ans[j]`；`o==3` 输出 `mx[j]-mn[j]`。

### 复杂度

- 时间：$O(V(n+q))=100\times(n+q)\le4\times10^7$；实测 $n=q=2\times10^5$ 随机数据 $0.26$s。
- 空间：$O(n+q)$，约 $11$ MB（对比「100 套前缀和」的 $80$ MB）。

### 验证状态

编译 `g++ -std=c++20 -O2` 通过；对拍暴力为「每询问直接扫区间 + 101 个桶 + `printf` 独立格式化」：**300 组**随机/定向边界数据（含值域压到 $[1,3]$ 制造大量并列、$b_i\equiv1$、$u=v$、$u>v$、$a_i$ 只取 $1/100$）跑真实可执行文件比对零不一致；另做**穷举**对拍：$n\le4$ 且 $a_i,b_i\in[1,3]$ 的全部数组，以及 $n=2$ 且 $a_i\in[1,100],b_i\in[1,3]$ 的全部数组，对每个数组枚举所有 $(o,u,v)$，共 **1,020,708 个询问**全部一致。手工验证截断格式：$1.875\to$`1.87`、$1.15\to$`1.15`、$6.5\to$`6.50`、$100\to$`100.00`；并列众数取最小、极差为 $0$ 等边界均正确。最大规模 $n=q=2\times10^5$ 实测 $0.26$s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2442 分数统计
// 思路：值域只有 100。把「值」这一维提到最外层离线扫描，
//       复用同一个前缀和数组 c[]，内存从 100n 塌缩到 n。
//       升序 + 严格大于 ⇒ 众数并列自动取最小；
//       cnt>0 ⇔ 该值出现（b_i>=1）⇒ 同一扫描顺手求出极差。
//       平均数全程整数：t=(100*S)/B，输出 t/100 . t%100（截断，非四舍五入）。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{200005},inf{1145141919};

int n,q,a[mxn],b[mxn],sb[mxn],c[mxn];
i64 s[mxn],ans[mxn];
struct{int o,u,v;}Q[mxn];
int bc[mxn],mn[mxn],mx[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>q;
	for(int i=0;i<n;++i)cin>>a[i];
	for(int i=0;i<n;++i)cin>>b[i];
	for(int i=0;i<n;++i)
	{
		s[i+1]=s[i]+(i64)a[i]*b[i];//总分
		sb[i+1]=sb[i]+b[i];//总人数
	}
	for(int i=0;i<q;++i)
	{
		cin>>Q[i].o>>Q[i].u>>Q[i].v;
		--Q[i].u;--Q[i].v;
		if(Q[i].u>Q[i].v)swap(Q[i].u,Q[i].v);
		mn[i]=inf;mx[i]=0;bc[i]=-1;//累加器只能在这里初始化一次
		if(Q[i].o==1)
		{
			i64 tot=s[Q[i].v+1]-s[Q[i].u],num=sb[Q[i].v+1]-sb[Q[i].u];
			ans[i]=tot*100/num;//截断到两位小数后放大 100 倍，全程整数
		}
	}
	//离线：按评价值 x 从小到大扫，c[] 复用为「值为 x 的人数」前缀和
	for(int x=1;x<=100;++x)
	{
		c[0]=0;
		for(int i=0;i<n;++i)c[i+1]=c[i]+(a[i]==x?b[i]:0);
		for(int i=0;i<q;++i)
		{
			if(Q[i].o==1)continue;
			int cnt=c[Q[i].v+1]-c[Q[i].u];
			if(Q[i].o==2)
			{
				if(cnt>bc[i]){bc[i]=cnt;ans[i]=x;}//严格大于 ⇒ 并列时保留最小的 x
			}
			else if(cnt>0)
			{
				if(mn[i]==inf)mn[i]=x;//第一个出现的 x 就是最小值
				mx[i]=x;//最后一个出现的 x 就是最大值
			}
		}
	}
	for(int i=0;i<q;++i)
	{
		if(Q[i].o==1)
		{
			i64 v=ans[i];
			cout<<v/100<<'.'<<(v%100<10?"0":"")<<v%100<<'\n';
		}
		else if(Q[i].o==2)cout<<ans[i]<<'\n';
		else cout<<mx[i]-mn[i]<<'\n';
	}
	return 0;
}
```

### 代码说明

- **`c[]` 复用**是本题的灵魂：它每轮被完整重写（`c[0]=0` 加 `c[1..n]`），所以 100 轮之间互不污染，内存只需一份 $O(n)$。
- **`mn[i]=inf` 不能省**：全局 `int` 数组默认 0，而 0 不是合法评价值也不是「尚未出现」的标记；用 `1145141919` 才能正确识别「第一次出现」。
- **`bc[i]=-1`** 而不是 0：保证 $x=1$ 时即使 $\mathrm{cnt}=0$ 也能进入分支写下初始值，逻辑与引理 5 的归纳基础一致（真正的众数计数 $\ge1$，一定会在后续覆盖它）。
- **`cnt>bc[i]` 的严格性**决定并列取最小；改成 `>=` 就变成取最大，直接 WA。
- **类型 1 的答案存的是 $t=\lfloor100\alpha\rfloor$**（放大 100 倍的整数），输出时才拆成整数部分与两位小数，全程无浮点。`(v%100<10?"0":"")` 负责补前导零，例如 $t=650$ 输出 `6.50`。
- **`(i64)a[i]*b[i]`** 的强制转换写在乘法之前，避免 `int*int` 的中间结果习惯性问题；`tot*100` 最大 $2\times10^{11}$，`i64` 安全。
- 询问 1 在扫描中 `continue` 跳过，因为它已在读入阶段用前缀和算完。
- `u>v` 时交换是防御性写法，不改变区间集合。
