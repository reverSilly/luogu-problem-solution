# P2239 [NOIP 2014 普及组] 螺旋矩阵 — 题解

## 一、解题过程：人类思考叙事

题意复述：一个 $n\times n$ 的矩阵，从左上角 $(1,1)$ 出发向右走，每一步如果前方格子没走过就前进，否则右转；按访问顺序填入 $1,2,\dots,n^2$，形成螺旋矩阵。现在给定 $n,i,j$（$n\le 30000$），只问第 $i$ 行第 $j$ 列的那个数。

第一反应当然是模拟：开一个 $n\times n$ 的 `vis` 和一个答案数组，按方向数组走 $n^2$ 步。可是 $n=30000$ 时 $n^2=9\times10^8$：答案数组按 `int` 算就是 $3.6$ GB，直接爆空间；就算只维护四条边界、不开 `vis`，$9\times10^8$ 次「判前方 + 填写」也远超时限。**模拟只能拿 $n\le 100$ 的 $50\%$**，这条路人走到一半就死了。

于是回头看 $n=4$ 的图：

```
 1  2  3  4
12 13 14  5
11 16 15  6
10  9  8  7
```

一眼能看出它是**一圈一圈套起来的**：最外圈是 $1\sim 12$（边长 $4$ 的方环），里面剩一个 $2\times2$，正好是 $13\sim 16$（边长 $2$ 的方环）。再画 $n=5$ 验证：

```
 1  2  3  4  5
16 17 18 19  6
15 24 25 20  7
14 23 22 21  8
13 12 11 10  9
```

外圈 $1\sim16$（边长 $5$），第二圈是 $3\times3$ 的边界 $17\sim24$（边长 $3$），中心 $25$（边长 $1$）。两次观察给出同一个结论：**螺旋填充是一环填满再填下一环，而且每一环的填法完全一样——从该环左上角出发向右绕一圈。**

只问一个格子，就没必要把整个矩阵造出来。把问题拆成三个小问：

1. **这个格子在第几环？** 把 $(i,j)$ 换成 0-based 的 $(x,y)$，它到上下左右四条边的距离是 $x,\ y,\ n-1-x,\ n-1-y$，取最小值 $k$，就是套在它外面的环数，也就是它所在的环号。例如 $n=4$，0-based 的 $(1,1)$（即第 $2$ 行第 $2$ 列）到四边距离是 $1,1,2,2$，最小 $1$，它确实在第二环（$13$ 那一环）的左上角。
2. **它前面已经填了多少个数？** 把第 $0,1,\dots,k-1$ 环的大小加起来。第 $t$ 环边长 $s=n-2t$，四条边数格子（角只算一次）是 $s+(s-1)+(s-1)+(s-2)=4s-4$。求和化简得 $4k(n-k)$。所以第 $k$ 环左上角 $(k,k)$ 填的数是 $st=1+4k(n-k)$。
3. **它在本环里排第几？** 本环边长 $s=n-2k$，层内相对坐标 $r=x-k,\ c=y-k$。本环的走法是：上边从左到右（$r=0$），右边从上到下（$c=s-1$），下边从右到左（$r=s-1$），左边从下到上（$c=0$）。于是偏移分别是
   - 上边：$c$；
   - 右边：$(s-1)+r$（先走完 $s$ 个上边格子，右边第 $r$ 个格子前面还有 $r-1$ 个）；
   - 下边：$2(s-1)+(s-1-c)$；
   - 左边：$3(s-1)+(s-1-r)$。

   判断顺序按 `r==0 → c==s-1 → r==s-1 → c==0`，因为这恰好是四条边被走到的先后；四个角由先到的那条边认领（比如右上角优先按上边算，得到 $s-1$，与按右边算的结果一样）。这一点第二节会逐一核对。

拿 $n=4$ 的图验算：
- $(1,1)$：$k=0,s=4,st=1,r=c=0$ ⇒ $1$ ✓
- $(1,4)$：$r=0,c=3$ ⇒ $st+3=4$ ✓
- $(2,1)$（0-based $(1,0)$）：$k=0,r=1,c=0$，落到左边分支 ⇒ $1+3\cdot3+(3-1)=12$ ✓
- $(2,2)$（0-based $(1,1)$）：$k=1,s=2,st=13,r=c=0$ ⇒ $13$ ✓
- $(4,1)$（0-based $(3,0)$）：$k=0,r=3=s-1,c=0$，落到下边分支 ⇒ $1+6+3=10$ ✓

到这里算法已经成型：$O(1)$ 算完，不用数组、不用模拟。

实现上踩过的坑：

- **类型**。$n,i,j$ 全读成 `long long`：一开始写成 `int i,j` 混着 `long long n`，`std::min({...})` 的初始化列表要求元素同类型，直接编译不过。统一成 `long long` 最省事。
- **溢出**。$4k(n-k)$ 最大约 $9\times10^8$，加上偏移仍 $<n^2\le9\times10^8<2^{31}$，其实 `int` 也够；但为了不写「刚好不爆」的险棋，全部用 `long long`。
- **边界**。$n=1$ 时 $k=0,s=1,r=c=0$，走第一分支给出 $st+0=1$，正确，不需要特判。$n$ 为偶数时最内环边长 $2$，四个格子分别落在四个分支上，也正确。

## 二、思维链：完整证明

以下坐标一律 0-based。记 $Q_t=[t,\,n-1-t]^2$（一个边长为 $s_t=n-2t$ 的正方形区域），$d(x,y)=\min(x,y,n-1-x,n-1-y)$。

**引理 1（分层刻画）**：$\{(x,y):d(x,y)=t\}$ 恰为 $Q_t$ 的边界；$t=0,1,\dots,\lfloor (n-1)/2\rfloor$ 的这些集合两两不交且覆盖整个矩阵。

*证明*：
(1) 若 $d(x,y)=t$，则 $x\ge t,\ y\ge t,\ x\le n-1-t,\ y\le n-1-t$，即 $(x,y)\in Q_t$；又四个数的最小值等于 $t$，说明四个不等式 $x\ge t,\ y\ge t,\ x\le n-1-t,\ y\le n-1-t$ 中至少有一个取等号，也就是点落在 $Q_t$ 的四条边界线之一上，故在 $Q_t$ 边界上。
(2) 反之，若点在 $Q_t$ 边界上，则它的坐标都在 $[t,n-1-t]$ 内，且 $x=t$ 或 $x=n-1-t$ 或 $y=t$ 或 $y=n-1-t$ 之一成立，于是四个距离的最小值就是 $t$，即 $d(x,y)=t$。
(3) 不交性：$d$ 是单值函数，$d=t$ 与 $d=t'$（$t\ne t'$）不可能同时成立；覆盖性：任何格子的 $d\ge0$，且由 $\min(x,n-1-x)\le\lfloor (n-1)/2\rfloor$ 得 $d\le\lfloor (n-1)/2\rfloor$。证毕。

（直观说法：第 $t$ 环就是 $Q_t$ 的「边框」，把 $Q_t$ 与 $Q_{t+1}$ 相减即可。）

**引理 2（逐环填充，且每环走法固定）**：记第 $k$ 环为 $Q_k$ 的边界。螺旋过程会把第 $0$ 环按「上边左→右、右边上→下、下边右→左、左边下→上」的顺序完整填满；归纳地，若第 $0..k-1$ 环已填满且过程正位于 $(k,k)$ 朝右，则第 $k$ 环也被按同样顺序完整填满；若 $s_k\ge3$，之后过程恰好位于 $(k+1,k+1)$ 朝右（即下一环的起点），若 $s_k\le2$ 则全部格子已填完。

*证明*：对 $k$ 归纳。

**基础**：$k=0$，起点 $(0,0)$ 朝右（题目规定）。沿第 $0$ 行向右时，前方格子 $(0,c)$（$c\ge1$）都还在第 $0$ 行内且未访问，所以会一直走到 $(0,n-1)$；此时前方 $(0,n)$ 出界，右转向下，沿第 $n-1$ 列走到 $(n-1,n-1)$（沿途格子都未访问，故不会提前转弯）；前方 $(n,n-1)$ 出界，右转向左，沿第 $n-1$ 行走回 $(n-1,0)$；前方 $(n-1,-1)$ 出界，右转向上，走到 $(1,0)$；此时前方 $(0,0)$ 已访问。这正是「上边、右边、下边、左边」的顺序，填满 $4n-4$ 个格子；若 $n\ge3$，过程尚未结束，右转向右进入 $(1,1)$（$Q_1$ 的左上角）朝右；若 $n=2$，$4n-4=n^2$，全部格子已填完；若 $n=1$，起点即全部。

**归纳步**：设第 $0..k-1$ 环已填满，过程位于 $(k,k)$ 朝右，且 $s_k\ge1$（否则已结束）。由引理 1，第 $k$ 环上的格子全部不在前 $k$ 环中，故全部未访问；而 $Q_k$ 之外（即前 $k$ 环）的格子全部已填。逐段检查：
- 沿第 $k$ 行向右：前方 $(k,c)$（$k<c\le n-1-k$）都在 $Q_k$ 边界上、未访问，故一路走到 $(k,n-1-k)$；
- 前方 $(k,n-k)$ 的列坐标 $n-k>n-1-k$，在 $Q_k$ 之外、已填，右转向下；沿第 $n-1-k$ 列的格子 $(r,n-1-k)$（$k<r\le n-1-k$）都在 $Q_k$ 边界上、未访问，走到 $(n-1-k,n-1-k)$；
- 前方 $(n-k,n-1-k)$ 在 $Q_k$ 之外、已填，右转向左；沿第 $n-1-k$ 行走到 $(n-1-k,k)$，沿途格子在 $Q_k$ 边界上、未访问；
- 前方 $(n-1-k,k-1)$ 在 $Q_k$ 之外、已填，右转向上；沿第 $k$ 列走到 $(k+1,k)$（$s_k=2$ 时这一列没有中间格，直接停在 $(k+1,k)$），沿途格子在 $Q_k$ 边界上、未访问；
- 前方 $(k,k)$ 已访问（本环起点），右转向右：
  - 若 $s_k\ge3$，$(k+1,k+1)$ 是 $Q_{k+1}$ 的左上角且未访问，过程位于 $(k+1,k+1)$ 朝右；
  - 若 $s_k=2$，本环 $2\times2$ 的四个格子已全部填完，而 $Q_{k+1}$ 边长为 $0$，整个矩阵填完；
  - 若 $s_k=1$，本环只有 $(k,k)$ 一格，填完即整个矩阵填完。

注意每段直行中「前方」要么是本环上未访问的格子（继续），要么在 $Q_k$ 之外已填（右转），不可能出现「前方是本环但已访问」的情形，所以不会提前转弯、也不会漏格。归纳完成。证毕。

**引理 3（前 $k$ 环的格子总数）**：若第 $k$ 环存在（即 $n-2k\ge1$），则第 $0..k-1$ 环共含 $4k(n-k)$ 个格子。

*证明*：对 $t<k$，$s_t=n-2t\ge n-2(k-1)=(n-2k)+2\ge3$，故每一环都能按「四条边去重」数：上边 $s_t$ 个、右边 $s_t-1$ 个（去掉与上边重复的右上角）、下边 $s_t-1$ 个（去掉右下角）、左边 $s_t-2$ 个（去掉左下角和左上角），合计
$$s_t+(s_t-1)+(s_t-1)+(s_t-2)=4s_t-4=4(n-2t-1).$$
求和对 $t=0..k-1$：
$$\sum_{t=0}^{k-1}4(n-2t-1)=4\Big(kn-2\cdot\frac{k(k-1)}2-k\Big)=4(kn-k^2)=4k(n-k).$$
$k=0$ 时和为 $0$，公式同样给 $0$。证毕。

（这一步隐含了一个边界事实：被查询格所在环号 $k=d(x,y)$ 总满足 $n-2k\ge1$，否则它不可能落在任何环上；由引理 1 的覆盖性直接得到。因此「前 $k$ 环」全是完整的环，不存在最内层只有一格却用 $4s-4$ 去数的情况。）

**引理 4（环内偏移）**：设查询格在 0-based 下为 $(x,y)$，环号 $k=d(x,y)$，$s=n-2k$，$r=x-k$，$c=y-k$，$st=1+4k(n-k)$。按如下顺序分派
$$\begin{cases}
r=0 &\Rightarrow \text{偏移}=c,\\
r\ne0,\ c=s-1 &\Rightarrow \text{偏移}=(s-1)+r,\\
r\ne0,\ c\ne s-1,\ r=s-1 &\Rightarrow \text{偏移}=2(s-1)+(s-1-c),\\
\text{其余} &\Rightarrow \text{偏移}=3(s-1)+(s-1-r),
\end{cases}$$
则每个格子恰被分派一次，且偏移等于它在本环遍历序列中的 0-based 下标；于是答案为 $st+\text{偏移}$。

*证明*：
(1) **每条分支上的坐标范围**。由引理 1，$(x,y)$ 在 $Q_k$ 边界上，故 $0\le r,c\le s-1$，且 $r=0$ 或 $c=0$ 或 $r=s-1$ 或 $c=s-1$ 至少一个成立。
(2) **恰一次**。若 $r=0$ 走第一支；否则 $r\ne0$，若 $c=s-1$ 走第二支；否则 $c\ne s-1$，若 $r=s-1$ 走第三支；剩下的情形由 (1) 只能是 $c=0$（因为 $r\ne0$ 排除 $r=0$，$c\ne s-1$ 排除 $c=s-1$，$r\ne s-1$ 排除 $r=s-1$，只剩 $c=0$）。分支互斥且穷尽，故恰一次。
(3) **偏移正确**。记本环遍历序列（由引理 2）为：上边 $(k,k),(k,k+1),\dots,(k,n-1-k)$；右边 $(k+1,n-1-k),\dots,(n-1-k,n-1-k)$；下边 $(n-1-k,n-2-k),\dots,(n-1-k,k)$；左边 $(n-2-k,k),\dots,(k+1,k)$。
- 第一支的格子 $(k,k+c)$ 位于上边，前面恰有 $c$ 个格子，偏移 $c$。
- 第二支的格子 $(k+r,n-1-k)$ 位于右边，前面有上边的 $s$ 个格子和右边的 $r-1$ 个格子，偏移 $s+(r-1)=(s-1)+r$。
- 第三支的格子 $(n-1-k,k+c)$ 位于下边，前面有上边 $s$ 个、右边 $s-1$ 个、下边从 $c'=s-2$ 到 $c+1$ 共 $s-2-c$ 个，偏移 $s+(s-1)+(s-2-c)=2(s-1)+(s-1-c)$。
- 第四支的格子 $(k+r,k)$ 位于左边，前面有上边 $s$ 个、右边 $s-1$ 个、下边 $s-1$ 个、左边从 $r'=s-2$ 到 $r+1$ 共 $s-2-r$ 个，偏移 $s+2(s-1)+(s-2-r)=3(s-1)+(s-1-r)$。

四个角点逐一核对（它们是唯一可能同时满足两条边条件的格子）：左上角 $r=c=0$ 由第一支给出 $0$，它是本环第一个，正确；右上角 $r=0,c=s-1$ 由第一支给出 $s-1$，也是上边最后一个，正确；右下角 $r=c=s-1$ 因 $r\ne0$ 由第二支给出 $2(s-1)$，是右边最后一个，正确；左下角 $r=s-1,c=0$ 因 $r\ne0,c\ne s-1$ 由第三支给出 $2(s-1)+(s-1)=3(s-1)$，是下边最后一个，正确。$s=1$ 时唯一的格子 $r=c=0$ 由第一支给出 $0$，正确。
(4) 由引理 2，本环第 $p$ 个被填的格子（$p$ 从 $0$ 计）填的数是 $st+p$；结合 (3) 得答案 $st+\text{偏移}$。证毕。

**引理 4′（编号连续、不重不漏的自检）**：若 $s\ge2$，第 $k$ 环填的恰是 $st,st+1,\dots,st+4s-5$ 这 $4s-4$ 个数，且下一环（若存在）的起点恰为 $st+4s-4$；若 $s=1$，该环只有一个格子，填的数是 $st=n^2$。因此所有环的编号恰好拼成 $1,2,\dots,n^2$，任何查询的答案都落在 $[1,n^2]$。

*证明*：$s\ge2$ 时由引理 4 的偏移公式，偏移取值集合为 $\{0,\dots,4s-5\}$：第一支给 $0..s-1$，第二支给 $s..2s-2$，第三支给 $2s-1..3s-3$，第四支给 $3s-2..4s-5$，四段首尾相接、总长 $(4s-5)+1=4s-4$。故本环编号为 $st..st+4s-5$。下一环起点为
$$st'=1+4(k+1)(n-k-1)=4kn-4k^2+4n-8k-3,$$
而
$$st+4s-4=1+4k(n-k)+4(n-2k)-4=4kn-4k^2+4n-8k-3,$$
两者相等，故相邻两环的编号首尾相接（差 $1$）。
$s=1$ 时 $n=2k+1$，$st=1+4k(n-k)=1+4k(k+1)=(2k+1)^2=n^2$，唯一的格子填 $n^2$，正确。
由第 $0$ 环起点 $st=1$（引理 3 中 $k=0$）与上面「相邻环首尾相接」的递推，逐环累加即知全部编号恰为 $1,2,\dots,n^2$。证毕。

**定理**：对任意合法 $(i,j)$，上述 $O(1)$ 公式输出螺旋矩阵第 $i$ 行第 $j$ 列的正确数值。

*证明*：由引理 1 得到正确的环号 $k$；由引理 3 得到环前总数 $4k(n-k)$，即本环起点值 $st$；由引理 4 得到环内偏移；三者相加即该格被填入的顺序编号。证毕。

**引理 5（复杂度）**：时间 $O(1)$，空间 $O(1)$。

*证明*：程序只做常数次整数比较、加减乘，没有循环与数组；使用了 $n,i,j,k,s,st,r,c,ans$ 共 $9$ 个标量。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 螺旋矩阵是同心方环，一环填满再填下一环，每环走法相同
- **consider easier version** — 直接模拟是 $O(n^2)$ 时间 + $O(n^2)$ 空间，$n=30000$ 时双双爆掉，只能过 $n\le100$
- **explore its property** — 用「到四条边距离的最小值」定位所在环号
- **classic problem solution** — 环大小 $4s-4$ 求和，得环前缀 $4k(n-k)$
- **reduce to easier problem** — 答案 = 前 $k$ 环总数 + 本环内偏移，问题降成一维编号
- **discuss by category** — 按格子在环的上/右/下/左边分类给偏移，角点按遍历先后归属

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 矩阵边长 | 输入（`long long`） |
| $i,j$ | 查询坐标，读入后立即 `--` 转 0-based | 输入 |
| $k$ | 所在环号 = $d(x,y)=\min(x,y,n-1-x,n-1-y)$ | 由坐标算出 |
| $s$ | 本环边长 $s=n-2k$ | 偶数 $n$ 最内层 $s=2$，奇数 $n$ 最内层 $s=1$ |
| $st$ | 本环左上角填的数 $1+4k(n-k)$ | 由引理 3 |
| $r,c$ | 环内相对坐标 $r=x-k,\ c=y-k$ | $0\le r,c\le s-1$，至少一个触边 |
| `ans` | 答案 $st+$ 环内偏移 | 由四条边分支算出 |

### 算法步骤

1. 读入 $n,i,j$，执行 `--i; --j;` 转成 0-based。
2. 计算环号 $k=\min(i,\ j,\ n-1-i,\ n-1-j)$。
3. 计算本环边长 $s=n-2k$、环起点值 $st=1+4k(n-k)$、相对坐标 $r=i-k,\ c=j-k$。
4. 按 `r==0`（上边）→ `c==s-1`（右边）→ `r==s-1`（下边）→ 否则（左边）的顺序，加上对应偏移得到 `ans`。
5. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(1)$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2239 [NOIP 2014 普及组] 螺旋矩阵
// 思路：螺旋矩阵是同心方环；第 k 环左上角为 1+4k(n-k)，再按四条边算环内偏移，O(1)
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 n,i,j;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>i>>j;
	--i;--j;
	i64 k=min({i,j,n-1-i,n-1-j});   // 到四条边距离的最小值 = 层号
	i64 s=n-2*k;                    // 本层边长
	i64 st=1+4*k*(n-k);             // 本层左上角 (k,k) 填的数
	i64 r=i-k,c=j-k;                // 层内相对坐标
	i64 ans;
	if(r==0)                        // 上边：左 -> 右
		ans=st+c;
	else if(c==s-1)                 // 右边：上 -> 下
		ans=st+(s-1)+r;
	else if(r==s-1)                 // 下边：右 -> 左
		ans=st+2*(s-1)+(s-1-c);
	else                            // 左边：下 -> 上
		ans=st+3*(s-1)+(s-1-r);
	cout<<ans<<'\n';
	return 0;
}
```
