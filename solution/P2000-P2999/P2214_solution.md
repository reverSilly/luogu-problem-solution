# P2214 [USACO14MAR] Mooo Moo S — 题解

## 一、解题过程：人类思考叙事

先重述题意。$N$ 个牧场排成一条直线，$B$ 个奶牛品种，第 $i$ 种的叫声音量为 $V_i$。牛叫声顺着风往右传，**每经过一个牧场音量减 1**。FJ 在第 $i$ 个牧场架麦克风，测到的总音量是 $h_i$。每个牧场里"由该牧场所有奶牛发出的总音量"最多为 $10^5$。求 FJ 最少养了多少头牛；若不存在任何配置能产生这串 $h$，输出 $-1$。

第一件事是把"传播"写成式子。设 $own_i$ 为第 $i$ 个牧场自己产出的音量，则第 $i$ 个牧场听到的总音量是"自产 + 从左边传过来的"：

$$h_i=own_i+\text{carry}_{i-1},\qquad \text{carry}_{i-1}=h_{i-1}-1 .$$

但这里立刻有一个坑：如果 $h_{i-1}=0$，那"减 1"之后就是负数，而音量不可能是负的，此时左边什么也没传过来。所以正确的写法是

$$h_i=own_i+\max(0,\,h_{i-1}-1),$$

第一个牧场没有左边，$\text{carry}_0=0$。

这个 $\max(0,\cdot)$ 不是可选项，用题面 Hint 就能验证：Hint 的数据是 $h=(0,17,16,20,19)$，品种音量 $5,7$。如果硬套 $h_i=own_i+h_{i-1}-1$，则第二个牧场需要 $own_2=17-(-1)=18$，而 $18$ 用 $5,7$ 怎么都凑不出来（$18-7=11,18-14=4$ 都不是 $5$ 的倍数），程序会输出 $-1$。但 Hint 明确说答案是 $4$ 头牛，所以必须夹到 $0$：$own_2=17$，用 $2\times 5+7$ 恰好 $3$ 头；$own_3=16-(17-1)=0$；$own_4=20-(16-1)=5$，$1$ 头；$own_5=19-(20-1)=0$。合计 $3+1=4$ 头，和 Hint 完全吻合。**这就是本题模型里唯一需要"猜"的地方，而 Hint 帮我们确认了它。**

接下来是关键的观察：**一旦听到的音量序列 $h$ 给定，每个牧场的自产音量 $own_i$ 就完全确定了，没有任何选择余地。** 因为 $own_i=h_i-\max(0,h_{i-1}-1)$，右边全是已知量。也就是说，这题没有"整体调度"的自由度：我们能做的只有"用品种音量把每个 $own_i$ 分别凑出来"，而各牧场互不影响。

于是问题退化为一个非常经典的子问题：**给定硬币面额 $V_1,\dots,V_B$（每种无限多枚），凑出金额 $own_i$，最少要几枚硬币？** 这是完全背包（最小硬币数）。因为各牧场独立，总牛数的最小值就是各牧场最小硬币数之和；只要有一个 $own_i$ 凑不出来（或 $own_i<0$），就无解，输出 $-1$。

实现上：$own_i\le 10^5$（题面保证），所以背包只需算到 $10^5$。$dp[x]$ 表示凑出 $x$ 的最少头数，$dp[0]=0$，其余先置无穷，然后对 $x$ 从小到大、对每个品种做 $dp[x]=\min(dp[x],dp[x-V]+1)$。复杂度 $10^5\times 20=2\times 10^6$，非常轻松。

几个边界：

- **$B$ 个品种可能有重复**，不影响完全背包。
- **$h_i$ 全为 $0$** 时，每个 $own_i=0$，答案是 $0$（FJ 一头牛也没有），程序自然输出 $0$。
- **全局 int 数组默认是 $0$ 不是无穷**，所以 $dp$ 必须显式 `fill_n(dp, mxv, inf)`，否则"不可达"会被当成 $0$ 头牛，答案偏小。
- $own_i<0$ 说明这串 $h$ 物理上不可能（比如左边传来的比听到的还多），直接 $-1$。

## 二、思维链：完整证明

为叙述方便，约定一个虚拟的第 $0$ 个牧场，$h_0=1$（它向右传 $0$ 音量），于是公式对所有 $i\ge 1$ 统一写成 $h_i=own_i+\max(0,h_{i-1}-1)$。

**引理 1（传播公式）**：第 $i$ 个牧场听到的总音量满足
$$h_i=own_i+\max(0,h_{i-1}-1).$$

*证明*：对 $i$ 归纳。$i=1$ 时左边没有任何牧场，听到的只有自产，而 $\max(0,h_0-1)=\max(0,0)=0$，公式成立。设 $i-1$ 成立。第 $i$ 个牧场听到的 = 自产 + 从 $i-1$ 传过来的音量。由题面，$i-1$ 传出的音量是"它的总音量减 $1$"，即 $h_{i-1}-1$；而音量是非负量，当 $h_{i-1}=0$ 时没有声音可传，传出为 $0$。两种情况合并正是 $\max(0,h_{i-1}-1)$。又 $own_i\ge0$，故 $h_i\ge0$，归纳可继续。证毕。

（关于"$h_{i-1}=0$ 时传 $0$"：这是由"音量非负"这一物理事实决定的；第一节已用 Hint 反证：若传 $-1$，Hint 的数据会得出 $-1$ 的错误答案，而正确答案是 $4$。）

**引理 2（自产音量的唯一性）**：给定 $h_1,\dots,h_N$，每个 $own_i$ 被唯一确定为
$$own_i=h_i-\max(0,h_{i-1}-1)\qquad(h_0=1).$$

*证明*：由引理 1，$h_i=own_i+\max(0,h_{i-1}-1)$，移项即得。右边只含 $h$，故 $own_i$ 的值唯一，不存在第二种选择。证毕。

**引理 3（配置 ↔ 逐站拆分）**：设第 $i$ 个牧场养了 $c_{i,1},\dots,c_{i,B}$ 头各品种的牛。该配置能产生给定的 $h$，当且仅当对每个 $i$ 都有
$$\sum_{j=1}^{B}c_{i,j}V_j=own_i .$$
（其中 $own_i$ 由引理 2 算出。）

*证明*：
（必要性）若配置产生 $h$，则第 $i$ 个牧场自产的音量按定义就是 $\sum_j c_{i,j}V_j$；由引理 2，它必须等于 $own_i$。
（充分性）设每站的加权和都等于 $own_i$。定义 $h'_0=1$，$h'_i=own_i+\max(0,h'_{i-1}-1)$。对 $i$ 归纳证明 $h'_i=h_i$：$i=1$ 时 $h'_1=own_1=h_1$；设 $h'_{i-1}=h_{i-1}$，则 $h'_i=own_i+\max(0,h_{i-1}-1)=h_i$（引理 2）。而 $h'$ 正是该配置按引理 1 产生的音量序列，故配置产生 $h$。证毕。

**引理 4（按牧场分解最小值）**：记 $m(x)$ 为"用品种音量凑出 $x$ 所需的最少头数"（凑不出记 $+\infty$），则全体合法配置的最少总牛数为 $\sum_{i=1}^{N}m(own_i)$（只要有一项为 $+\infty$，则不存在合法配置）。

*证明*：任一合法配置的总牛数 $=\sum_i\sum_j c_{i,j}=\sum_i(\text{第 }i\text{ 站的头数})$。由引理 3，第 $i$ 站的头数是"凑出 $own_i$ 的一个方案"，故 $\ge m(own_i)$；于是总牛数 $\ge\sum_i m(own_i)$。反之，若所有 $m(own_i)$ 有限，对每站取达到 $m(own_i)$ 的方案拼起来，由引理 3 它是合法配置，总牛数恰为 $\sum_i m(own_i)$。故下界可达，且有一项无穷时不存在合法配置。证毕。

**引理 5（完全背包递推正确）**：定义 $dp[0]=0$，
$$dp[x]=1+\min_{\substack{1\le j\le B\\ V_j\le x}}dp[x-V_j]\qquad(x\ge1),$$
则 $dp[x]=m(x)$（无可行 $j$ 或右侧全为 $+\infty$ 时 $dp[x]=+\infty$）。

*证明*：对 $x$ 归纳。
（$dp[x]\ge m(x)$）设 $dp[x]$ 有限，取达到最小值的 $j$，则 $dp[x]=dp[x-V_j]+1$。由归纳假设 $dp[x-V_j]=m(x-V_j)$，即存在凑出 $x-V_j$ 的 $m(x-V_j)$ 枚方案；再加一枚 $V_j$ 就凑出 $x$，共 $m(x-V_j)+1$ 枚，故 $m(x)\le dp[x]$。若 $dp[x]=+\infty$，说明没有任何 $j$ 使 $dp[x-V_j]$ 有限，归纳可知任何 $x-V_j$ 都凑不出；而任何凑出 $x$ 的方案去掉最后一枚 $V_j$ 就凑出 $x-V_j$，矛盾，故 $m(x)=+\infty$。
（$dp[x]\le m(x)$）若 $m(x)$ 有限，取一个最优方案，它至少含一枚硬币，设其中一枚面额 $V_j$；去掉它得到凑出 $x-V_j$ 的方案，用 $m(x-V_j)$ 枚，故 $m(x)\ge m(x-V_j)+1=dp[x-V_j]+1\ge dp[x]$（最后一步因为 $dp[x]$ 取遍所有 $j$ 的最小值）。
两方向合起来 $dp[x]=m(x)$。归纳基础 $x=0$ 显然。由于所有 $V_j\ge1$，$x-V_j<x$，按 $x$ 递增计算时所需状态都已是最终值。证毕。

**引理 6（$-1$ 判定正确）**：算法输出 $-1$ 当且仅当不存在合法配置。

*证明*：
（输出 $-1$ ⇒ 无解）算法输出 $-1$ 只可能因为三种情况：
① $own_i<0$：由引理 1，$own_i=h_i-\max(0,h_{i-1}-1)\ge0$ 对任何真实配置成立，故无配置能产生该 $h$；
② $dp[own_i]=+\infty$：由引理 5，$own_i$ 无法用品种音量凑出，由引理 3 无合法配置；
③ $own_i\ge mxv$：题面保证每个牧场的自产音量不超过 $10^5$，而 $own_i$ 是唯一确定的（引理 2），故这种情况在合法输入下不会发生；若发生，同样说明不存在满足保证的配置。
（无解 ⇒ 输出 $-1$）若无合法配置，由引理 3 必有某站 $own_i$ 无法拆成品种音量的非负整数组合；这样的 $own_i$ 要么为负（情况①），要么 $dp[own_i]=+\infty$（引理 5），要么超出预处理范围（情况③中的越界判断），三种都会让程序输出 $-1$。证毕。

**定理**：程序输出的数就是最少奶牛数（或正确的 $-1$）。

*证明*：由引理 3、4，最少奶牛数等于 $\sum_i m(own_i)$（无解时为无穷）；由引理 5，$dp$ 正确算出 $m$；由引理 6，$-1$ 的判定正确。故输出正确。证毕。

**引理 7（复杂度）**：时间 $O(mxv\cdot B+N)$，空间 $O(mxv)$，其中 $mxv=10^5+5$。

*证明*：背包两层循环共 $(mxv-1)\cdot B\le 10^5\times20=2\times10^6$ 次；逐站求 $own_i$ 与累加 $O(N)$。空间只有一个长度 $mxv$ 的数组。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 把"风声传播"写成逐站递推 $h_i=own_i+\max(0,h_{i-1}-1)$。
- consider easier version — 先不管"最少牛数"，只问"这串 $h$ 合不合法"：发现 $own_i$ 被 $h$ 唯一确定，没有调度自由。
- sanity check by sample — 用 Hint 的 $0,17,16,20,19$ 反推，确认必须把"传 $-1$"夹成 $0$（否则第 $2$ 站要 $18$，$5/7$ 凑不出，与答案 $4$ 矛盾）。
- reduce to easier problem — 全局最少牛数 = 各站独立的"凑出 $own_i$ 的最少头数"之和。
- classic problem solution — 完全背包（最小硬币数）$dp[x]=1+\min_j dp[x-V_j]$。
- discuss by category — $own_i<0$ / $own_i$ 凑不出 ⇒ 输出 $-1$；否则累加。
- engineering pitfall — 全局数组默认 $0$，必须 `fill_n(dp, mxv, inf)`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 牧场数 | 输入 |
| $b$ | 品种数 | 输入 |
| $V_j$ | 第 $j$ 种牛的音量 | 输入，$1\le V_j\le100$ |
| $h_i$ | 第 $i$ 个牧场听到的总音量 | 输入，$0$-based |
| $own$ | 第 $i$ 个牧场自产音量（局部变量） | $h_i-\max(0,h_{i-1}-1)$，$i=0$ 时减 $0$ |
| $dp[x]$ | 凑出音量 $x$ 的最少牛数 | $dp[0]=0$，其余 `inf` |
| $mxv$ | 背包上界 $=100005$ | 题面保证 $own\le10^5$，$+5$ 松弛 |
| $inf$ | 无穷哨兵 `1145141919` | 表示"凑不出" |
| $ans$ | 总牛数 | 初值 $0$，逐站加 $dp[own]$ |

### 算法步骤

1. I/O 加速三连。
2. 读入 $n,b$，再读 $b$ 个 $V_j$，再读 $n$ 个 $h_i$。
3. `fill_n(dp,mxv,inf); dp[0]=0;`
4. 对 $x=1\dots mxv-1$，对每个品种 $j$：若 $V_j\le x$ 且 $dp[x-V_j]+1<dp[x]$，则更新 $dp[x]=dp[x-V_j]+1$。
5. 对 $i=0\dots n-1$：
   1. $own=h_i-\big(i>0\ ?\ \max(0,h_{i-1}-1)\ :\ 0\big)$；
   2. 若 $own<0$ 或 $own\ge mxv$ 或 $dp[own]\ge inf$，输出 $-1$ 并结束；
   3. 否则 $ans\mathrel{+}=dp[own]$。
6. 输出 $ans$。

### 复杂度

- 时间：$O(10^5\cdot B+N)\le 2\times10^6$。
- 空间：$O(10^5)$。

### 一句话验证状态

Hint 数据输出 $4$；与"枚举每站不超过 12 头牛的全部配置再模拟"的暴力在 200 组随机数据（含 49 组无解）上完全一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2214 [USACO14MAR] Mooo Moo S
// own[i] = h[i] - max(0, h[i-1]-1) 唯一确定；再对每个 own 做完全背包求最少头数
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105},mxv{100005},inf{1145141919};

int n,b,v[mxn],h[mxn],dp[mxv];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>b;
	for(int i=0;i<b;++i)
		cin>>v[i];
	for(int i=0;i<n;++i)
		cin>>h[i];
	// 全局数组默认 0，必须显式填无穷
	fill_n(dp,mxv,inf);
	dp[0]=0;
	for(int x=1;x<mxv;++x)
		for(int i=0;i<b;++i)
			if(v[i]<=x&&dp[x-v[i]]+1<dp[x])
				dp[x]=dp[x-v[i]]+1;
	int ans=0;
	for(int i=0;i<n;++i)
	{
		int own=h[i]-(i?max(0,h[i-1]-1):0);
		if(own<0||own>=mxv||dp[own]>=inf)
		{
			cout<<-1<<'\n';
			return 0;
		}
		ans+=dp[own];
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 第 $0$ 个牧场没有左边来音，用三目 `i?max(0,h[i-1]-1):0` 处理，避免访问 `h[-1]`。
- 背包用"对 $x$ 递增、对每种面额试一次"的写法，正是完全背包（每种无限多）的滚动数组形式；因为 $V_j\ge1$，不会出现用同一轮刚更新的状态自我迭代的时序问题（$x-V_j<x$ 已算完）。
- `dp[x-v[i]]+1<dp[x]` 当 `dp[x-v[i]]=inf` 时是 `inf+1`，不会溢出（`inf` 取 $1145141919$，加 $1$ 仍远小于 `INT_MAX`）。
- 若 `own>=mxv` 也判 $-1$：题面保证不会出现，但保留判断以防数组越界。
- 输出只需一行，`'\n'` 结尾。

### 验证状态

- 编译：`g++ -std=c++20 -O2 -Wall -Wextra` 无错误、无警告。
- Hint 数据（$N=5,B=2,V=\{5,7\},h=\{0,17,16,20,19\}$）输出 $4$，与题面解释一致。
- 对拍：暴力枚举每个牧场 $0\sim12$ 头牛的所有品种组合，模拟风声后与 $h$ 比对取最小总头数；在 $N\le3$、$B\le3$、$h\le10$ 的 $200$ 组随机数据上与本代码输出完全一致，其中 $49$ 组为无解（双方都输出 $-1$）。
