# P2622 关灯问题 II — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n\le10$ 盏灯初始全开，$m\le100$ 个按钮。按钮 $i$ 对灯 $j$ 的效果 $a_{i,j}\in\{1,-1,0\}$：$1$ 表示"开着就关掉，关着不管"；$-1$ 表示"关着就打开，开着不管"；$0$ 表示不管。求把所有灯关掉的最少按键次数，无解输出 $-1$。

**第一反应：贪心。** "每次按能关掉最多灯的按钮"——听起来合理，但按钮有**副作用**（$-1$ 会把别的灯打开），局部最优拼不出全局最优。手造一个反例（$n=3,m=3$，初始 $111$）：

| 按钮 | 效果 $(a_{i,1},a_{i,2},a_{i,3})$ | 从 $111$ 按下的净关灯数 |
|---|---|---|
| A | $(1,1,-1)$ | $-2$（关 1、2；灯 3 已开，$-1$ 无效） |
| B | $(1,-1,1)$ | $-1$（关 1、3；灯 2 已开） |
| C | $(0,1,0)$ | $-1$（关 2） |

贪心选净收益最大的 A，得到"只剩灯 3 亮"。此后：A 对灯 3 是 $-1$（开着不管），C 只管灯 2，都动不了灯 3；只有 B 能关灯 3，但副作用把灯 2 打开，还得再按 C 关灯 2。共 $3$ 下。而最优是 **B → 只剩灯 2 亮 → C → 全关，$2$ 下**。贪心卒。

**第二反应：枚举按钮集合 / 按压顺序？** $m=100$，按钮子集有 $2^{100}$ 个，爆炸；而且顺序显然重要（先 B 后 C 与先 C 后 B 结果不同），同一按钮还可能需要在不相邻的位置按多次。这条路也堵死。

**第三步：抓状态的本质。** 一个按钮的效果**只取决于每盏灯当前的开关**，与"之前按过什么"毫无关系——系统无后效性。于是描述局面只需要"哪些灯亮着"，即灯集合的一个子集：$2^n\le2^{10}=1024$ 种状态！每个按钮是一个**确定的状态转移**。"最少按几下"就是：在这张 $1024$ 个点、每点 $m$ 条出边的有向图上，从"全亮"走到"全灭"的**边权全为 $1$ 的最短路**——BFS 的标准领地。$n\le10$ 这个范围就是状压搜索的请柬。

**第四步：把转移写成 $O(1)$ 位运算。** 预处理两个掩码：`off[i]` = 按钮 $i$ 中 $a=1$ 的位（强制关），`on[i]` = $a=-1$ 的位（强制开）。按按钮 $i$：

$$s\ \longmapsto\ (s\ \&\ \sim\mathrm{off}[i])\ |\ \mathrm{on}[i].$$

先清后置；两个掩码不相交（每个 $a_{i,j}$ 只有一个值），顺序无关。每次转移 $O(1)$，BFS 总量 $O(2^n\cdot m)\approx10^5$。

**第五步：实现上唯一要命的坑。** `dis` 数组必须**显式填 INF**：全局 `int` 默认 $0$，而 $0$ 是合法距离——不填的话所有状态开局就被当成"已访问、距离 $0$"，BFS 一步都走不动，直接输出错误答案。起点 `(1<<n)-1` 置 `dis=0` 入队；结束后 `dis[0]==INF` 则输出 $-1$。

**附赠观察：按钮是幂等的。** 同一按钮**连续**按两次等于按一次（$1$ 清两次还是清，$-1$ 置两次还是置），所以最优序列绝不会相邻重复按同一按钮。但这**不排除不相邻的重复**，因此不能把状态压缩成"按过哪些按钮"——状态必须是灯的局面，BFS 天然正确处理重复与顺序。

**手造数据核对。** 题面无样例，自造四组：上面的贪心反例（答案 $2$）；$n=1,m=1,a=(-1)$（灯已开，按钮只会开灯，永远关不掉，答案 $-1$）；$n=2,m=1,a=(1,1)$（一下全关，答案 $1$）；$n=2,m=2$，按钮 $(1,-1),(-1,1)$（状态在 $11,10,01$ 三个掩码间打转，$00$ 不可达，答案 $-1$）。四组程序输出全部与手算一致。

## 二、思维链：完整证明

**记号。** 灯 $j$（$1\le j\le n$）对应位 $j-1$；状态 $s\in[0,2^n)$ 的位 $j-1$ 为 $1$ 表示灯 $j$ 亮。初始状态 $s_0=2^n-1$（全亮），目标 $0$（全灭）。$\mathrm{off}_i=\sum_{j:a_{i,j}=1}2^{j-1}$，$\mathrm{on}_i=\sum_{j:a_{i,j}=-1}2^{j-1}$。转移函数 $f_i(s)=(s\ \&\ \sim\mathrm{off}_i)\ |\ \mathrm{on}_i$。图 $G$：点集 $[0,2^n)$，对每个 $i$ 连边 $s\to f_i(s)$（允许自环与重边）。$\delta(s)$：$s_0\to s$ 的最短游走长度（不可达为 $\infty$）。`dis[s]`：BFS 维护的距离标号，初值 INF。

---

### 引理 1（状态充分性：按压序列 $\leftrightarrow$ 图上行走）

设依次按下按钮 $i_1,\dots,i_t$，则实际灯局面恰为 $s_t=f_{i_t}(f_{i_{t-1}}(\cdots f_{i_1}(s_0)\cdots))$。特别地，"存在 $t$ 次按压全关" $\iff$ "$G$ 中存在 $s_0\to0$ 的长度 $t$ 游走"，故答案 $=\delta(0)$（$\infty$ 时无解）。

*证明*：对 $t$ 归纳。$t=0$：局面 $s_0$ ✓。设 $t-1$ 步后局面为 $s_{t-1}$。按按钮 $i_t$ 时，每盏灯 $j$ 的新状态按题面逐字翻译：$a_{i_t,j}=1$：亮则灭、灭则灭，即新位 $=0$；$a=-1$：灭则亮、亮则亮，即新位 $=1$；$a=0$：新位 $=$ 旧位。**每盏灯的新位只依赖它自己的旧位**，不依赖其它灯、也不依赖历史，故整个新局面是 $s_{t-1}$ 的确定函数（引理 2 给出其闭式），归纳成立。

于是长度 $t$ 的按压序列与 $G$ 中从 $s_0$ 出发的长度 $t$ 游走一一对应（序列决定游走；游走每步的边标号给出按钮序列），"全关"即游走终点为 $0$。最少按压次数 $=\min\{t:\exists\text{ 长度 }t\text{ 的 }s_0\to0\text{ 游走}\}=\delta(0)$。证毕。

---

### 引理 2（转移闭式）

$f_i(s)=(s\ \&\ \sim\mathrm{off}_i)\ |\ \mathrm{on}_i$，且 $\mathrm{off}_i\cap\mathrm{on}_i=\varnothing$。

*证明*：逐位核对。位 $j-1$：若 $a_{i,j}=1$，该位在 $\mathrm{off}_i$ 中，`s&~off` 将其清 $0$，`|on` 不影响（该位不在 $\mathrm{on}_i$），新位 $0$ ✓（引理 1 的翻译）。若 $a_{i,j}=-1$，该位在 $\mathrm{on}_i$ 中，清操作不动它，置操作将其设 $1$ ✓。若 $a_{i,j}=0$，两掩码都不含该位，保留旧值 ✓。不相交性：每个 $a_{i,j}$ 是单值，$1$ 与 $-1$ 互斥，故两掩码无公共位；从而"先清后置"与"先置后清"结果相同，闭式良定义。证毕。

---

### 引理 3（幂等性：最优序列无相邻重复）

$f_i(f_i(s))=f_i(s)$。从而任何最优按压序列都不含相邻的同一按钮。

*证明*：逐位：$a=1$ 的位两次都清 $0$；$a=-1$ 的位两次都置 $1$；$a=0$ 的位两次都不动。故 $f_i\circ f_i=f_i$。

设最优序列在位置 $t,t+1$ 连按两次 $i$。由幂等性，按完这两次后的状态与只按一次相同；又后续每步转移是状态的确定函数（引理 1），删去其中一次后**所有后续状态逐一不变**，终局仍全关，而长度减 $1$，与最优矛盾。证毕。

**注**：本引理只排除**相邻**重复，不排除不相邻重复（状态不同处按同一按钮完全可能必要），故不能把搜索状态改成"已按按钮集合"。BFS 的正确性不依赖本引理，它只是解释"为什么按钮子集 DP 是错误的模型"。

---

### 引理 4（BFS 标号即最短距离）

BFS 结束后，对每个状态 $s$：可达则 $\mathrm{dis}[s]=\delta(s)$，不可达则 $\mathrm{dis}[s]=\mathrm{INF}$。

*证明*：分四步。

**(a) 标号可实现（$\mathrm{dis}[v]\ge\delta(v)$ 恒成立）。** 对赋值次数归纳：$\mathrm{dis}[s_0]=0=\delta(s_0)$；每次赋值 $\mathrm{dis}[t]=\mathrm{dis}[s]+1$ 发生在弹出 $s$ 且存在边 $s\to t$ 时，由归纳假设 $\mathrm{dis}[s]$ 是某条 $s_0\to s$ 游走的长度，接上该边得 $s_0\to t$ 的 $\mathrm{dis}[s]+1$ 长游走，故 $\mathrm{dis}[t]\ge\delta(t)$（$\delta$ 是最小值）。

**(b) 队列单调性。** 任何时刻队列中 $\mathrm{dis}$ 值从队首到队尾单调不减，且最大减最小 $\le1$；从而弹出值随时间单调不减。对操作归纳：初始队列仅 $s_0$（值 $0$）✓。弹出只删队首（最小值），不破坏单调与跨度。新入队元素值为 $\mathrm{dis}[s]+1$，$s$ 是刚弹出的队首：弹出前队列值 $\in\{d,d+1\}$（$d=\mathrm{dis}[s]$），弹出后仍 $\in\{d,d+1\}$，追加 $d+1$ 到队尾保持单调不减、跨度 $\le1$ ✓。

**(c) 按层归纳：$\delta(v)=d\Rightarrow\mathrm{dis}[v]=d$，且第 $d$ 层全部弹出先于任何 $d+1$ 值弹出。** 先备事实：**最短游走的前缀仍是最短游走**——若到前缀终点有更短游走，拼接后缀即得更短的到 $v$ 游走，矛盾。

$d=0$：$\delta(v)=0\iff v=s_0$，初始赋值 $0$ ✓；$s_0$ 是首个弹出，而任何 $1$ 值标号只能在某次弹出时产生，故 $0$ 层弹出先于一切 $1$ 值弹出 ✓。

设结论对 $\le d$ 层成立。取 $\delta(v)=d+1$，其最短游走上 $v$ 的前驱 $u$ 满足 $\delta(u)=d$。由归纳假设 $\mathrm{dis}[u]=d$ 且 $u$ 被弹出。考察 $u$ 弹出、松弛边 $u\to v$ 的时刻：

- 若 $v$ 未赋值：$\mathrm{dis}[v]=\mathrm{dis}[u]+1=d+1$ ✓。
- 若 $v$ 已赋值：设赋值发生在弹出 $w$ 时，$\mathrm{dis}[v]=\mathrm{dis}[w]+1$。$w$ 先于 $u$ 弹出，由 (b) 弹出值单调不减，$\mathrm{dis}[w]\le\mathrm{dis}[u]=d$，故 $\mathrm{dis}[v]\le d+1$；结合 (a) $\mathrm{dis}[v]\ge\delta(v)=d+1$，得 $\mathrm{dis}[v]=d+1$ ✓。

故第 $d+1$ 层每个点都被赋值为 $d+1$（赋值即入队，恰一次）。这些赋值都发生在弹出值 $\le d$ 的点时；由 (b)，队列中 $d$ 值元素全部排在 $d+1$ 值元素之前，故第 $d+1$ 层的弹出全部晚于第 $d$ 层（及更前）的弹出。归纳完成。

**(d) 收尾。** 每个可达点 $\delta$ 有限，由 (c) 被赋值为 $\delta$ 并入队、弹出；不可达点永远不会被赋值（赋值必对应一条真实游走，(a)），保持 INF。证毕。

---

### 引理 5（终止性与 $-1$ 的正确性）

BFS 循环至多弹出 $2^n$ 次后终止；结束时 $\mathrm{dis}[0]=\mathrm{INF}\iff$ 无解，输出 $-1$ 正确。

*证明*：`dis[t]==inf` 守卫保证每点至多赋值一次、入队一次，点数 $2^n$，故弹出 $\le2^n$ 次，每次枚举 $m$ 条边，循环必然终止。由引理 4(d)，$\mathrm{dis}[0]=\mathrm{INF}\iff0$ 不可达 $\iff G$ 中无 $s_0\to0$ 游走 $\iff$（引理 1）不存在任何全关的按压序列，即无解，按题面输出 $-1$；否则 $\mathrm{dis}[0]=\delta(0)$ 即最少次数。另 $n\ge1\Rightarrow s_0=2^n-1\ne0$，故有解时答案 $\ge1$，不会与"初始即全关"混淆。证毕。

---

### 引理 6（复杂度）

时间 $O(mn+2^n\cdot m)$，空间 $O(2^n+m)$。

*证明*：读入并构造 $\mathrm{off}/\mathrm{on}$：$O(mn)$。BFS：$\le2^n$ 次弹出，每次 $m$ 次 $O(1)$ 位运算转移与比较，$O(2^n m)$。代入 $n=10,m=100$：$1000+1024\times100\approx1.03\times10^5$ 次基本操作。空间：`dis` 长 $2^n$、`off/on` 各长 $m$、队列 $\le2^n$。证毕。

---

### 定理

程序输出最少按键次数，无解时输出 $-1$。

*证明*：引理 1 把问题化为 $G$ 上 $s_0\to0$ 的无权最短路；引理 2 保证代码的 $O(1)$ 转移与题面效果逐位一致；引理 4 保证 BFS 标号等于 $\delta$；引理 5 保证终止与 $-1$ 分支正确；引理 6 给出复杂度。证毕。

---

### 附注：为什么别的模型不行

- **贪心**：第一节的 $3$ 灯反例，净收益最大的首按导致 $3$ 下 $>2$ 下最优；副作用使局部收益不可叠加。
- **按钮子集 DP**：$m=100\Rightarrow2^{100}$ 状态爆炸；且引理 3 只排除相邻重复，顺序与不相邻重复都影响结果，"按过哪些按钮"不是充分状态。
- **子任务视角**：$n\le5$ 时状态仅 $32$ 个（可手玩验证）；$m\le20$ 不改变算法——状态数只依赖 $n$，$m$ 只是每点的出边数；"输出无解"的 $20\%$ 数据要求 INF 判定必须写对。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 按钮效果只依赖当前灯状态（无后效性）⇒ 局面 = 亮灯子集，$2^n\le1024$ 个状态。
- **consider easier version** — 手造 $3$ 灯反例否决"最大化即时净关灯数"贪心：$-1$ 副作用让局部最优不可拼接。
- **reduce to easier problem** — 最少按键 = 状态图上全亮掩码到 $0$ 的无权最短路；按压序列与游走一一对应。
- **classic problem solution** — BFS + `dis` 数组；预处理 `off/on` 掩码把转移压成 $O(1)$：`(s&~off[i])|on[i]`。
- **explore its property** — 按钮幂等 ⇒ 最优序列无相邻重复；但不排除不相邻重复，状态不能压成"按钮集合"。
- **discuss by category** — `dis` 显式填 INF（全局默认 $0$ 是合法距离，最致命的坑）；不可达输出 $-1$；$n=1$、全 $0$ 按钮等边界。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n,m` | 灯数 $\le10$ / 按钮数 $\le100$ | `int`，读入 | 题面分两行给，`cin>>n>>m` 通吃 |
| `off[i]` | 按钮 $i$ 强制关的灯掩码（$a=1$ 的位） | `int[mxm]`，全局默认 $0$ | "1 → 清位" |
| `on[i]` | 按钮 $i$ 强制开的灯掩码（$a=-1$ 的位） | `int[mxm]`，全局默认 $0$ | "-1 → 置位"；与 `off` 不相交 |
| `dis[s]` | 全亮态到状态 $s$ 的最少按键数 | `int[mxs]`，**显式 `fill_n(...,1<<n,inf)`** | 全局默认 $0$ 是陷阱；INF=未访问 |
| `st` | 初始全亮掩码 $(1<<n)-1$ | `int` | `dis[st]=0`，唯一初始 $0$ |
| `Q` | BFS 队列 | `queue<int>` | 存状态掩码 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 远大于任何可能答案（$\le2^n-1$） |
| `mxn,mxm,mxs` | $15,105,1030$ | `constexpr int` | $n+5$、$m+5$、$2^{10}+6$ 松弛 |

### 算法步骤

1. I/O 加速三行；读 `n,m`。
2. 读 $m\times n$ 的效果矩阵：$a=1$ 则 `off[i]|=1<<j`；$a=-1$ 则 `on[i]|=1<<j`；$0$ 跳过。
3. `fill_n(dis,1<<n,inf)`；`st=(1<<n)-1`；`dis[st]=0`；`st` 入队。
4. 队非空时弹出 `s`，对每个按钮 $i$：`t=(s&~off[i])|on[i]`；若 `dis[t]==inf` 则 `dis[t]=dis[s]+1` 并入队。
5. 输出 `dis[0]==inf ? -1 : dis[0]`。

### 复杂度

- 时间 $O(mn+2^n m)\approx1.03\times10^5$；空间 $O(2^n+m)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；四组手造数据（贪心反例 $2$、单灯 $-1$ 按钮 $-1$、双灯全关按钮 $1$、双按钮循环 $-1$）输出全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2622 关灯问题 II
// 思路：按钮效果只依赖当前灯状态 ⇒ 状态 = 灯的子集（2^n ≤ 1024）。
//       预处理 off[i]/on[i] 位掩码，按按钮 i 的转移是 O(1)：s → (s&~off[i])|on[i]。
//       全亮掩码到 0 的无权最短路 ⇒ BFS；dis 必须显式填 INF（全局默认 0 是陷阱）。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{15},mxm{105},mxs{1030},inf{1145141919};

int n,m,off[mxm],on[mxm],dis[mxs];
queue<int>Q;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<m;++i)
		for(int j=0,x;j<n;++j)
		{
			cin>>x;
			if(x==1)
				off[i]|=1<<j;		// 1：开 → 关（强制清位）
			else if(x==-1)
				on[i]|=1<<j;		// -1：关 → 开（强制置位）
		}
	fill_n(dis,1<<n,inf);
	int st=(1<<n)-1;			// 初始全亮
	dis[st]=0;
	Q.push(st);
	while(!Q.empty())
	{
		int s=Q.front();Q.pop();
		for(int i=0;i<m;++i)
		{
			int t=(s&~off[i])|on[i];
			if(dis[t]==inf)
			{
				dis[t]=dis[s]+1;
				Q.push(t);
			}
		}
	}
	cout<<(dis[0]==inf?-1:dis[0])<<'\n';
	return 0;
}
```

### 代码说明

- **`fill_n(dis,1<<n,inf)` 是全题最不能省的一行**：全局 `int` 默认 $0$，而 $0$ 是合法距离；不填 INF 则所有状态被视为"已访问"，BFS 直接瘫痪。只填前 `1<<n` 个即可，`mxs{1030}` 是 $2^{10}+6$ 松弛。
- **转移 `(s&~off[i])|on[i]`**：先清后置，两掩码不相交故顺序无关（引理 2）；自环（$t=s$）被 `dis[t]==inf` 守卫自然跳过，无需特判。
- **灯 $j$ 用位 $j-1$**：读入循环 `j` 从 $0$ 起，`1<<j` 直接对应，内部全程 0-based，无需换算。
- **`off/on` 用 `|=` 累积**：同一按钮对多盏灯的效果合并进一个掩码，$O(mn)$ 预处理换来 BFS 中 $O(1)$ 转移。
- **不需要 visited 数组**：`dis[t]==inf` 兼任"未访问"判定，一数组两用。
- 答案三目输出 `(dis[0]==inf?-1:dis[0])`，覆盖无解分支；有解时 `dis[0]` 即最少按键数（引理 4、5）。
