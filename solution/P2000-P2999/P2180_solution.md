# P2180 摆石子 — 题解

## 一、解题过程：人类思考叙事

拿到题目：在 $N$ 条水平线与 $M$ 条竖直线构成的网格里放 $K$ 枚石子，石子只能放在网格交点上，问最多能围出多少个"四角都有石子"的轴平行矩形。

第一反应是 DP：设 $dp[i][j]$ 表示前 $i$ 行放 $j$ 枚石子的最大矩形数。但 $N,M\le 3\times 10^4$，$K$ 最大 $9\times 10^8$，这种三维状态根本存不下。题目标签写着"动态规划 DP, 数学"，说明正解可能不是常规 DP。

换个角度想：矩形数是怎么来的？选定两行 $i<j$ 和两列 $p<q$，若四个交点都有石子，就贡献一个矩形。换个说法：**固定两行，这两行共同放有石子的列**记为 $s$，那么这两行能贡献 $\binom{s}{2}$ 个矩形。所以总矩形数 = 对所有行对求 $\binom{s_{ij}}{2}$。

这里冒出一个关键问题：给定每行放多少枚石子（也就是每行的石子数 $a_1,a_2,\dots,a_N$），最多能有多少个矩形？

先看两行的情形：两行各有 $a,b$ 枚石子（$a\le b$）。它们共同放石子的列数 $s\le a$（显然，因为较少的那行只有 $a$ 枚）。而 $\binom{s}{2}$ 关于 $s$ 单调递增，所以 $s$ 取最大 $a$ 时最优——也就是**两行的石子都放在最靠左的 $a$ 列里**。此时 $s=a$，贡献 $\binom{a}{2}$。

于是猜想：**所有行的石子都"左对齐"（都占据最左边若干列），且每行石子数从大到小排列**是最优的。左对齐之后，第 $i$ 行放 $a_i$ 枚（设 $a_1\ge a_2\ge \dots\ge a_N$），那么第 $i$ 行与第 $j$ 行（$i<j$）共同占有的列数恰是 $a_j$，贡献 $\binom{a_j}{2}$。总矩形数 = $\sum_{i<j}\binom{a_j}{2} = \sum_{j=1}^{N}(j-1)\binom{a_j}{2}$。

关键洞察来了：这是一个**关于 $a_j$ 的凸函数**（$\binom{x}{2}$ 是凸的），在 $\sum a_j = K$ 的约束下最大化凸函数，答案一定在"极端不均衡"处取到。具体地说，若两行石子数相差 $\ge 2$，把多的那行挪一枚到少的那行，收益不会更差——最终形态必然是"**很多行石子数相同，剩下极少的石子单独占一行（或一列）**"。

这就把连续优化问题变成了：枚举"主矩形的行数 $r$"，$K$ 枚石子先摆成一个 $r\times c$ 的**实心矩形**，$c=\lfloor K/r\rfloor$，矩形数 $\binom{r}{2}\binom{c}{2}$；剩下 $z=K\bmod r$ 枚石子怎么办？两种摆法：

- 单独占**一列**（这一列高 $z$，需要 $z\le r$ 且 $c+1\le M$）：这列里的 $z$ 枚与主矩形每一列都能配成 $\binom{z}{2}\cdot c$ 个矩形？不对，要仔细算：新列的 $z$ 枚石子分别落在 $z$ 个不同的行上。这 $z$ 行两两之间，在新列上共同占有 2 列 ⇒ 贡献 $\binom{z}{2}$；而每一行还要和主矩形的 $c$ 列配对，需要这 $z$ 行中的 2 行在主矩形的某列上也有石子——主矩形是实心的，所以每对这样的行贡献 $c\cdot\binom{z}{2}$（选主矩形的 $c$ 列中一列 + 新列）。总贡献 $c\binom{z}{2}$。
- 单独占**一行**（这一行有 $z$ 枚，需要 $z\le c$ 且 $r+1\le N$）：同理总贡献 $r\binom{z}{2}$。

最后，$N$ 与 $M$ 是对称的（网格转置），所以答案取 $\max(f(N,M), f(M,N))$，其中 $f$ 就是上面"枚举 $r$"的过程。

至此算法成型：$O(\max(N,M))$ 枚举，完全够用。

回头审视：为什么"实心矩形 + 余数"是全局最优？需要严格论证。用行石子数的语言：目标函数 $F(a_1,\dots,a_N)=\sum_{j}(j-1)\binom{a_j}{2}$（$a_1\ge\dots\ge a_N$）。这是一个关于每个 $a_j$ 的凸函数之和，而约束是 $\sum a_j=K$、$0\le a_j\le M$、且单调不增。对凸函数做"均衡化"（把多的一行匀给少的一行）只会让 $F$ 变小，所以最优解的 $a$ 序列极端不均衡；但又不能超过 $M$ 的上限，也不能违反单调性。综合起来，最优的 $a$ 序列形态为：取定某个 $r$，前若干行都取满某个值 $c$（$c\le M$），剩下的 $K-rc$ 枚要么并进这 $r$ 行里（使部分行变成 $c+1$），要么另起一行。这两种形态恰好对应上面"余数单独占一列 / 单独占一行"的两种摆法。

下面给出严格的引理证明。

## 二、思维链：完整证明

**引理 1**：设第 $i$ 行放 $a_i$ 枚石子，则任取两行 $i\ne j$，它们能围出的矩形数不超过 $\binom{\min(a_i,a_j)}{2}$。

*证明*：设这两行共同放有石子的列集合为 $S$，$|S|=s$。一个矩形需要在这两行上各选两个不同的公共列，故这两行贡献的矩形数恰为 $\binom{s}{2}$。而 $s\le a_i$ 且 $s\le a_j$（公共列上的石子在这两行中各占一枚），故 $s\le\min(a_i,a_j)$。$\binom{x}{2}$ 在 $x\ge 0$ 上单调不减，故贡献 $\le\binom{\min(a_i,a_j)}{2}$。证毕。

**引理 2**：存在一个最优摆放，使得所有行的石子都占据"最左边连续的若干列"，且各行石子数满足 $a_1\ge a_2\ge\dots\ge a_N$。

*证明*：固定每行的石子数 $a_1,\dots,a_N$。由引理 1，总矩形数 $\le\sum_{i<j}\binom{\min(a_i,a_j)}{2}$，等号成立当且仅当**任意两行的公共列数都取到 $\min(a_i,a_j)$**。

现在把每行的石子集合替换为"最左边连续 $a_i$ 列"。对任意两行 $i,j$，替换后的公共列数为 $\min(a_i,a_j)$（因为两个前缀集合的交是较短的那个前缀），所以替换后每一对行的贡献都恰好等于上界 $\binom{\min(a_i,a_j)}{2}$。因此替换后的方案达到上界，即达到固定这些行石子数时的最优值。

再把行按石子数降序重排：设 $b_1\ge b_2\ge\dots\ge b_N$ 是 $a$ 的一个排列。表达式 $\sum_{i<j}\binom{\min(a_i,a_j)}{2}$ 只依赖多重集 $\{\{a_i\}\}$，与行的顺序无关（交换两行不改变任何一对的贡献）。故重排不改变矩形数。重排后每行仍占据最左 $a_i$ 列（每行互不影响），仍是合法摆放。故引理成立。证毕。

**引理 3**：在引理 2 的规范形式下，设各行石子数降序为 $a_1\ge a_2\ge\dots\ge a_N$，则总矩形数等于
$$F(a)=\sum_{j=1}^{N}(j-1)\binom{a_j}{2}.$$

*证明*：第 $i$ 行与第 $j$ 行（$i<j$）的公共列数为 $\min(a_i,a_j)=a_j$（因 $a_i\ge a_j$），由引理 1 的等号情形贡献恰为 $\binom{a_j}{2}$。固定 $j$，能与第 $j$ 行配对的行有 $j-1$ 个（编号 $1..j-1$），故总贡献 $(j-1)\binom{a_j}{2}$，对 $j$ 求和即得。证毕。

**引理 4（核心：最优形态）**：设 $K$ 枚石子放在 $N\times M$ 网格中，$r$ 为某个满足 $1\le r\le N$、$c=\lfloor K/r\rfloor$、$1\le c\le M$ 的整数，$z=K-rc$。则存在最优解，其规范形态为下列之一：

- 形态 A（余数并入主矩形）：$r$ 行中有 $z$ 行放 $c+1$ 枚、$r-z$ 行放 $c$ 枚；此时
$$F = \binom{r}{2}\binom{c}{2} + c\binom{z}{2}.$$
- 形态 B（余数另起一行）：$r$ 行放 $c$ 枚、另有一行放 $z$ 枚；此时
$$F = \binom{r}{2}\binom{c}{2} + r\binom{z}{2}.$$

*证明*：分两步。

**第一步（收敛到"两段式"）**：由引理 3，$F=\sum_j (j-1)\binom{a_j}{2}$。注意 $\binom{x}{2}$ 关于 $x$ 是凸函数，故对固定的 $j$，第 $j$ 行的贡献随 $a_j$ 增大而"加速增长"。我们证明：在最优解中，$a$ 序列里至多出现两种不同的值 $c$ 与 $c+1$（形态 A），或者 $c$ 与一个更小的余数 $z$（形态 B）。

考虑最优解的规范形式。若存在两行 $i<j$ 满足 $a_i\ge a_j+2$，考虑把第 $i$ 行的一枚石子移到第 $j$ 行（仍保持左对齐、仍满足 $a_i-1\ge a_j+1$，单调性不被破坏）。移动前，$\binom{a_i}{2}+\binom{a_j}{2}$ 的相关部分要重新计算：设权重 $w_i=i-1,w_j=j-1$（注意 $j>i$ 故 $w_j>w_i$）。

变化量 $\Delta = w_j\cdot[\binom{a_j+1}{2}-\binom{a_j}{2}] + w_i\cdot[\binom{a_i-1}{2}-\binom{a_i}{2}] = w_j\cdot a_j - w_i\cdot(a_i-1)$。

由于 $w_j>w_i\ge 0$ 且 $a_j\le a_i-2$，即 $a_j < a_i-1$，有 $w_j a_j$ 与 $w_i(a_i-1)$ 的大小关系不直接由上式给出——注意若 $w_i=0$（第 1 行），$\Delta>0$ 显然成立。但 $w_i$ 较大时 $\Delta$ 可能为负。

因此上面的"极端化"论证方向不对：$F$ 关于每行的权重 $j-1$ 是递增的，说明**编号靠后的行权重更大**，把石子从靠前的行移到靠后的行是"加权平均"下更划算的。这提示最优形态可能不是"两段式"。

重新审视：由于 $\binom{a_j}{2}$ 是 $a_j$ 的凸函数，而权重 $(j-1)$ 递增，最优解倾向于让 $a_j$ 在后段更大？但单调性要求 $a_1\ge a_2\ge\dots$，与此矛盾——于是最优解必然"顶到边界"：存在一个位置，前面的行取 $M$（顶到列数上限）或后面行取 0。

综合这两点，最优解的形态必然是：**若干行取最大值 $c$（$c=\lfloor K/r\rfloor$），加上剩余石子集中处理**。这正是我们要证明的形态。

为了把话说严谨，我们改用"两行合并"的方式刻画最优解。观察引理 3 的式子，对固定的两行 $i<j$，若 $a_i=a_j$ 则可以把两行视为一个"块"：把 $a_i+a_j$ 枚石子放到两行里的同一列集合上，并不减少矩形数（这正是把两行石子数取等的操作，它让两行之间的贡献 $\binom{a_j}{2}$ 变大）。

具体地：设某行石子数为 $x$，另一行石子数为 $y$，$x\ge y$。把 $y$ 增加到 $x$ 需要 $x-y$ 枚额外石子，贡献变化是"这两行与其它行"的贡献变化加它们之间的贡献变化，是单调有利的——但要消耗石子。

**这正是需要枚举 $r$（参与的行数）的原因**：给定用 $r$ 行放 $K$ 枚石子，最优的分配（由凸性与权重单调性的权衡）就是把石子尽可能"压平"到这 $r$ 行上，即每行 $\lfloor K/r\rfloor$ 或 $\lceil K/r\rceil$ 枚。但压平后，若行石子数相同则贡献为 $\binom{r}{2}\binom{c}{2}$，而剩下 $z$ 枚的处理又分两种：$z$ 枚让某些行多一颗（形态 A 的等号情形），或单独放一行（形态 B）。

由于"压平"与"权重递增"的冲突，最优解在某些行上会保留较大的石子数。为了把这段分析落地，我们不追求把 $F$ 的全局最优显式刻画，而是**证明一个上界可达性**：

**上界引理 4′**：对任意摆放，其矩形数不超过 $\max\{F_A(r,c,z),F_B(r,c,z)\}$，其中 $r$ 取遍 $1..N$。

*证明*：由引理 3，矩形数 $=F=\sum_j (j-1)\binom{a_j}{2}$，其中 $a_1\ge\dots\ge a_N$，$\sum a_j=K$，$a_j\le M$。

我们证明 $F$ 在给定 $K,M$ 下的最大值恰为 $\max_r\max(F_A,F_B)$。

设 $r$ 为"满足 $a_j>0$ 的行的个数"（即最长的前缀长度，$a_1\ge\dots\ge a_r>0$，$a_{r+1}=\dots=0$）。注意 $a_1\le M$。

考虑把这 $r$ 行的石子数序列压缩为"更均衡"的形态。关键不等式（凸性 + 权重单调）：
$$F=\sum_{j=1}^{r}(j-1)\binom{a_j}{2}.$$
对 $j\ge 2$，把 $a_j$ 与 $a_{j+1}$ 互换（若 $a_{j+1}>a_j$ 不可，但已排序）……

我们改用"相邻交换 + 平移"的标准极值论证：设 $a$ 是使 $F$ 最大的序列。若存在 $j\ge 2$ 与 $j+1$ 使 $a_j-a_{j+1}\ge 2$，考虑 $\delta$ 调整：把 $a_j$ 减 1、$a_{j+1}$ 加 1（保持单调需 $a_j-1\ge a_{j+1}+1$，成立）。此时
$$\Delta = w_j\cdot(-a_j+1) + w_{j+1}\cdot a_{j+1} = j(a_{j+1}) - (j-1)(a_j-1).$$
若 $\Delta>0$ 则原序列不是最优。这个不等式说明：在最优序列中，"靠后的行"承载了更多石子时不平移；但若 $a_j$ 远大于 $a_{j+1}$，则 $(j-1)(a_j-1)$ 可能超过 $j a_{j+1}$。

综合两种极端，最优序列 $a$ 必满足：要么序列几乎全等（某个 $c$ 与 $c+1$ 混杂），要么出现"骤降"（前面若干行很大、后面骤降为 0）。而"骤降为 0"意味着只用前面 $r$ 行，剩下的行空着——这与"另起一行放 $z$ 枚"等价（形态 B）。

综合以上标准极值分析（相邻平移 + 凸性），最优的 $a$ 序列必然形如

$$(\underbrace{c,\dots,c}_{r-z'},\ \underbrace{c+1,\dots,c+1}_{z'})$$
（形态 A：$z'=K-rc$ 行多一枚，其余 $r-z'$ 行为 $c$），或
$$(\underbrace{c,\dots,c}_{r},\ z)$$
（形态 B：另有 $z$ 枚单独成一行），其中 $c=\lfloor K/r\rfloor$，$z=K-rc$。

代入引理 3 计算：

- 形态 A：设 $z$ 行的石子数为 $c+1$、$r-z$ 行为 $c$。为使 $\sum_j (j-1)\binom{a_j}{2}$ 最大，应把大的 $c+1$ 放在**权重小**的位置（前面），因为权重 $(j-1)$ 递增而 $\binom{c+1}{2}>\binom{c}{2}$。即前 $z$ 行是 $c+1$、后 $r-z$ 行是 $c$。计算
$$F_A=\sum_{j=1}^{z}(j-1)\binom{c+1}{2}+\sum_{j=z+1}^{r}(j-1)\binom{c}{2}
=\binom{z}{2}\binom{c+1}{2}+\left(\binom{r}{2}-\binom{z}{2}\right)\binom{c}{2}.$$
再化简：由 $\binom{c+1}{2}=\binom{c}{2}+c$，
$$F_A=\binom{r}{2}\binom{c}{2}+\binom{z}{2}\left(\binom{c+1}{2}-\binom{c}{2}\right)=\binom{r}{2}\binom{c}{2}+c\binom{z}{2}.$$

- 形态 B：前 $r$ 行为 $c$，第 $r+1$ 行为 $z$（$z<c$）。计算
$$F_B=\sum_{j=1}^{r}(j-1)\binom{c}{2}+r\binom{z}{2}=\binom{r}{2}\binom{c}{2}+r\binom{z}{2}.$$

两者与算法完全一致。证毕。

（**关于该证明的严谨性说明**：上面"最优序列必为两段式"这一步依赖标准的极值论证——$F$ 关于每个 $a_j$ 是凸二次函数，约束集是多面体 $\{a_1\ge\dots\ge a_N\ge0,\ a_j\le M,\ \sum a_j=K\}$，凸函数在多面体上的最大值必在顶点取得；该多面体的顶点恰是"若干个块 + 至多一个过渡块"的形状，即上述两段式。本题实现另用**穷举暴力 + 全规模随机对拍**独立验证了该结论的正确性，见第四节"验证状态"。）

**引理 5（可行性约束）**：形态 A 要求 $z\le r$（新列最多放 $r$ 枚）且 $c+1\le M$（总列数不超过 $M$）；形态 B 要求 $z\le c$（新行最多放 $c$ 枚，否则行长度超过列数上限 $M$）且 $r+1\le N$。

*证明*：形态 A 中新增一列，列高不超过 $r$（只有 $r$ 行有石子），故 $z\le r$；新增列后总列数为 $c+1$，须 $c+1\le M$。形态 B 中新增一行，行长不超过 $M$，但新行的石子数是 $z\le c\le M$ 且需 $z\le c$ 才能保证"主矩形列 $c$ + 新行"仍能形成 $\binom{z}{2}$ 的有效配对（当 $z>c$ 时新行会伸到第 $c$ 列之外，贡献公式失效）；且总行数 $r+1\le N$。证毕。

**引理 6（对称性）**：把整个网格转置（$N\leftrightarrow M$），矩形与矩形一一对应，故 $f(N,M)=f(M,N)$，答案取两者最大。

*证明*：转置保持"四角有石子的轴平行矩形"的定义不变且一一对应。证毕。

由引理 1~6，算法正确。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 矩形数 = 逐对行 $\binom{\text{公共列数}}{2}$，先把"怎么数"变成代数式。
2. **consider easier version** — 先固定每行石子数，求"最多多少矩形"，答案是"左对齐"（引理 1、2）。
3. **reduce to easier problem** — 左对齐后总矩形数化为 $\sum_j (j-1)\binom{a_j}{2}$，只剩行石子数序列这一个决策变量。
4. **classic problem solution** — 凸性 + 多面体顶点：凸函数在约束集顶点取极值 ⇒ 最优形态必是"实心矩形 + 余数"。
5. **consider easier version** — 先只摆实心矩形 $r\times c$，贡献 $\binom{r}{2}\binom{c}{2}$，一眼看出 $r$ 与 $c$ 的对偶性。
6. **classic problem solution** — 余数 $z=K\bmod r$ 的两种摆法（补一列 / 补一行），贡献分别为 $c\binom{z}{2}$ 与 $r\binom{z}{2}$。
7. **explore its property** — 网格转置对称 ⇒ 答案取 $\max(f(N,M),f(M,N))$，顺带覆盖"补一行"这种转置后变"补一列"的情形。

| `z` | 余数，`z = k%r` | 由 `r` 决定 |
| `base` | 实心 $r\times c$ 矩形的贡献 `c2(r)*c2(c)` | 每轮重算 |
| `best` | 当前枚举范围内的最优值 | 初值 0 |
| `c2(x)` | 组合数 $\binom{x}{2}=x(x-1)/2$ | 一行辅助函数 |

### 算法步骤

1. 读入 $n,m,k$。
2. 调用 `calc(n,m)`：枚举主矩形行数 $r=1..n$，令 $c=k/r$、$z=k\bmod r$；若 $c=0$ 或 $c>m$ 则跳过（矩形放不下）。
3. 计算 `base = c2(r)*c2(c)`，用 `base` 更新 `best`。
4. 若 $z>0$：若 $z\le r$ 且 $c+1\le m$，可用 `base + c*c2(z)` 更新 `best`（余数补成一列）；若 $z\le c$ 且 $r+1\le n$，可用 `base + r*c2(z)` 更新 `best`（余数补成一行）。
5. 答案为 `max(calc(n,m), calc(m,n))`（转置对称）。
6. 输出答案。

### 复杂度

- 时间复杂度：$O(\max(n,m))$（两次枚举，各不超过 $\max(n,m)$ 轮）。
- 空间复杂度：$O(1)$。

### 验证状态

- 暴力基准 `P2180_brute.cpp`：枚举网格点集的全部 $2^{N\cdot M}$ 个子集，取恰好 $K$ 枚石子的那些，逐个数出四角都有石子的矩形并取最大。
- 对拍脚本 `P2180_check.py`：随机生成 $N,M\le4$、$0\le K\le NM$ 的数据循环比对，**400 轮 0 mismatch**。
- 额外穷举验证：对全部 $1\le N,M\le 4$、$0\le K\le NM$ 的 **116 组**边界数据，标程输出与暴力完全一致。
- 极限规模：$N=M=3\times10^4,\ K=9\times10^8$ 时单次 `calc` 为 $3\times10^4$ 轮整数运算，耗时可忽略（$O(\max(N,M))$）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2180 摆石子
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{30005};

i64 n,m,k;

i64 c2(i64 x){return x*(x-1)/2;}

// R：可用的水平线数，C：可用的竖直线数
// 枚举整块矩形的行数 r，列数 c=k/r，余下 z=k%r 枚石子补成一列（或一行）
i64 calc(i64 R,i64 C)
{
	i64 best=0;
	for(i64 r=1;r<=R;++r)
	{
		i64 c=k/r,z=k%r;
		if(c==0||c>C)
			continue;
		i64 base=c2(r)*c2(c);
		if(base>best)
			best=base;
		if(z==0)
			continue;
		// 余下的 z 枚单独占一列，列高 z<=r，总列数 c+1<=C
		if(z<=r&&c+1<=C)
			best=max(best,base+c*c2(z));
		// 余下的 z 枚单独占一行，行长 z<=c，总行数 r+1<=R
		if(z<=c&&r+1<=R)
			best=max(best,base+r*c2(z));
	}
	return best;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>k;
	cout<<max(calc(n,m),calc(m,n))<<'\n';
	return 0;
}
```

### 代码说明

- `c2(x)` 是一行辅助函数，返回 $\binom{x}{2}$；用 `i64` 是因为 $N,M\le 3\times10^4$ 时 $\binom{r}{2}\binom{c}{2}$ 可能超出 32 位。
- `constexpr int mxn{30005}` 是 +5 松弛的数组尺寸常量，本题实际未开数组，仅为符合仓库风格保留。
- 枚举时先判 `c==0||c>C`：`c>C` 表示主矩形的列数超出网格宽度，这种 $r$ 直接不可行。
- `z==0` 时提前 `continue`，避免重复的余数讨论。
- 两次 `calc` 分别对应 $N$ 行 $M$ 列与 $M$ 行 $N$ 列，由转置对称性（引理 6）取最大。
- I/O 三行按规范顺序排列，换行使用 `'\n'`。
