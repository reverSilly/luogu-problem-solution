# P2834 纸币问题 3 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $n$ 种面额**互不相同**的纸币，第 $i$ 种面额 $a_i$，每种**无限张**。要恰好凑出金额 $w$，问有多少种**纸币组合**，答案对 $10^9+7$ 取模。范围：$1\le n\le 10^3$，$1\le a_i,w\le 10^4$；$40\%$ 的数据 $n\le10,w\le100$。

关键词是"**组合**"。组合意味着**不计顺序**：先付 $1$ 元再付 $2$ 元，和先付 $2$ 元再付 $1$ 元，是**同一种**组合 $\{1,2\}$。这一点是整道题的分水岭——它的孪生题 P2840（纸币问题 2）把顺序算作不同方式，两题代码只差**循环次序**。所以我必须先想清楚"组合"到底在数什么。

**第一步：把"组合"翻译成数学对象。** 既然不计顺序，一种组合完全由"每种面额各用了几张"决定。设第 $i$ 种用了 $c_i$ 张（$c_i\ge0$ 的整数），那么一种组合就是一个向量 $(c_1,\dots,c_n)$，满足

$$\sum_{i=1}^{n} c_i\,a_i = w.$$

于是题目等价于：**数这个方程的非负整数解的个数**。因为面额互不相同，不同的解向量一定对应不同的组合（不会重复），相同的解向量就是同一种组合。这一步把模糊的"组合"落地成了一个干净的计数对象。

**第二步：先想暴力，确认必须 DP。** 最直接的想法是枚举每种面额用几张：$c_1$ 从 $0$ 到 $\lfloor w/a_1\rfloor$，$c_2$ 从 $0$ 到 $\lfloor (w-c_1a_1)/a_2\rfloor$……递归下去。但解的个数本身可以是天文数字（例如 $a=\{1,2,\dots\}$、$w=10^4$ 时组合数极大），逐个枚举解会超时；而且 $n=10^3$ 层递归也不现实。$40\%$ 子任务 $n\le10,w\le100$ 正是在暗示"小规模可以搜索/朴素 DP，大规模要线性递推"。方向明确：**背包计数 DP**。

**第三步：定义状态，写出递推。** 令 $f_i[j]$ = "只允许使用前 $i$ 种面额（$a_0,\dots,a_{i-1}$，0-based），恰好凑出 $j$ 元的组合数"。考虑第 $i$ 种面额 $a_{i-1}$ 用不用：

- **一张都不用**：方案数就是 $f_{i-1}[j]$（退回只使用前 $i-1$ 种）。
- **至少用一张**：先拿出一张 $a_{i-1}$，剩下的金额 $j-a_{i-1}$ 仍然**允许继续使用第 $i$ 种**（因为无限张），方案数是 $f_i[j-a_{i-1}]$。

两类不重不漏（按"第 $i$ 种是否出现"划分），所以

$$f_i[j]=f_{i-1}[j]+f_i[j-a_{i-1}]\quad(j\ge a_{i-1}),\qquad f_i[j]=f_{i-1}[j]\quad(j<a_{i-1}).$$

边界 $f_0[0]=1$（什么都不选，凑出 $0$ 元，算一种"空组合"），$f_0[j>0]=0$。注意第二项是 $f_i$ 而不是 $f_{i-1}$——这正是"完全背包"（无限张）区别于"01 背包"（每张最多一次）的地方。

**第四步：压成一维，循环次序是灵魂。** 把 $i$ 这一维滚掉，只留 `dp[j]`。外层枚举面额 $i$，内层枚举金额 $j$ **从小到大**：

```
dp[0]=1
for i in 0..n-1:
    for j = a[i] .. w:        // 升序！
        dp[j] += dp[j-a[i]]
```

为什么升序就对？因为算 `dp[j]` 时要用到 `dp[j-a[i]]`，而 $j-a[i]<j$，升序保证它**已经在本轮（第 $i$ 种）被更新过**，存的是 $f_i[j-a[i]]$（允许再用第 $i$ 种）——恰好对应"至少用一张"那一支。若改成降序，`dp[j-a[i]]` 还是上一轮的 $f_{i-1}$，就变成"第 $i$ 种最多用一张"的 01 背包，答案偏小。

**第五步：用最小反例钉死"组合 vs 排列"。** 我特意拿 $a=\{1,2\},w=3$ 验证两种循环次序：

- 组合（本题，面额外层）：$\{1,1,1\}$、$\{1,2\}$，共 **2** 种。
- 排列（P2840，金额外层）：$1+1+1$、$1+2$、$2+1$，共 **3** 种。

如果本题误写成"金额外层、面额内层"，就会输出 $3$ 而不是 $2$。这个 $2\ne3$ 的最小反例让我彻底确认：**本题必须面额外层**。它的本质是——面额外层时，每种组合里的纸币是按"面额种类编号递增"的顺序被逐步加入的，因此每种组合只被生成**一次**（详见引理 2 的双射证明）。

**第六步：取模与溢出。** 答案对 $p=10^9+7$ 取模。`dp[j]` 与 `dp[j-a[i]]` 都已是 $[0,p)$ 内的数，相加 $<2p=2\,000\,000\,014<2^{31}-1=2\,147\,483\,647$，所以用 `int` 相加**不会溢出**，加完若 $\ge p$ 就减一次 $p$ 即可，无需 `%`（更快）。这是个容易忽略但必须验证的细节：如果模数更大或累加项更多，`int` 就可能溢出，得换 `long long`。

**手造数据核对**（题面无样例，按规则自造）：

| 输入 | 组合 | 输出 |
|---|---|---|
| `2 3` / `1 2` | $\{1,1,1\},\{1,2\}$ | `2` |
| `1 3` / `2` | 无（$3$ 是奇数，$2$ 凑不出） | `0` |
| `3 5` / `1 2 5` | $\{1\times5\},\{1\times3,2\},\{1,2\times2\},\{5\}$ | `4` |

另外跑了一组极限规模 $n=1000,w=10000,a_i=i$，约 $10^7$ 次转移，实测 $0.06$ 秒，远在时限内。

## 二、思维链：完整证明

**记号。** 面额 $a_0,\dots,a_{n-1}$ 互不相同，$a_i\ge1$。目标金额 $w$。模数 $p=10^9+7$。一种**组合**定义为非负整数向量 $\mathbf c=(c_0,\dots,c_{n-1})$ 满足 $\sum_i c_i a_i=w$；因面额互异，组合与解向量一一对应。设答案为 $N(w)=\#\{\mathbf c\ge0:\sum c_i a_i=w\}\bmod p$。

定义 $f_i[j]=\#\{\mathbf c:\ c_k=0\ (k\ge i),\ \sum_{k<i}c_k a_k=j\}$，即"只用前 $i$ 种面额凑出 $j$"的组合数（未取模的真实值）。则 $N(w)=f_n[w]\bmod p$。

---

### 引理 1（递推式的正确性）

对 $i\ge1$ 与任意 $j\ge0$：
$$f_i[j]=f_{i-1}[j]+[\,j\ge a_{i-1}\,]\cdot f_i[j-a_{i-1}].$$
且边界 $f_0[0]=1$，$f_0[j]=0\ (j>0)$。

*证明*：把"只用前 $i$ 种凑出 $j$"的所有组合按**第 $i-1$ 种面额的张数 $c_{i-1}$ 是否为 $0$**划分成两类，二者不交且并为全体。

**类 A（$c_{i-1}=0$）**：这些组合实际只用前 $i-1$ 种，与"只用前 $i-1$ 种凑出 $j$"的组合一一对应，故数目为 $f_{i-1}[j]$。

**类 B（$c_{i-1}\ge1$）**：仅当 $j\ge a_{i-1}$ 时非空（否则 $c_{i-1}a_{i-1}\ge a_{i-1}>j$，不可能）。对类 B 中每个组合，把 $c_{i-1}$ 减 $1$，得到一个新组合 $\mathbf c'$，它仍只用前 $i$ 种（$c'_{i-1}=c_{i-1}-1\ge0$），且总额变为 $j-a_{i-1}$。反之，任何"只用前 $i$ 种凑出 $j-a_{i-1}$"的组合，把 $c_{i-1}$ 加 $1$ 就回到类 B。这两个操作互逆，故类 B 与"只用前 $i$ 种凑出 $j-a_{i-1}$"的组合一一对应，数目为 $f_i[j-a_{i-1}]$。**注意这里仍是 $f_i$ 而非 $f_{i-1}$**：减一张后第 $i-1$ 种仍可能出现，所以"前 $i$ 种"的限制不变。

两类相加即得递推式。

边界：$i=0$ 表示"一种面额都不用"，唯一可能的总额是 $0$（空组合 $\mathbf c=\mathbf0$），故 $f_0[0]=1$；$j>0$ 时无解，$f_0[j]=0$。证毕。

---

### 引理 2（一维升序滚动恰好实现 $f_i$，且每种组合只计一次）

设算法维护数组 `dp[0..w]`，初始 `dp[0]=1`、其余 $0$。外层对 $i=0,\dots,n-1$，内层对 $j=a_i,a_i+1,\dots,w$ **升序**执行 `dp[j]=(dp[j]+dp[j-a_i]) mod p`。则外层第 $i$ 轮结束后，对所有 $j$ 有 `dp[j]`$=f_{i+1}[j]\bmod p$。特别地，全部结束后 `dp[w]`$=f_n[w]\bmod p=N(w)$。

*证明*：对外层轮数归纳。

**归纳基础**：第 $0$ 轮开始前，`dp[j]`$=[j=0]=f_0[j]$，与引理 1 边界一致。

**归纳步骤**：设第 $i$ 轮开始前 `dp[j]`$=f_i[j]\bmod p$ 对所有 $j$ 成立。本轮内层按 $j$ 升序处理。对当前 $j$：

- `dp[j]` 尚未在本轮被改过（升序，$j$ 第一次被访问），故其值是 $f_i[j]$。
- `dp[j-a_i]`：因 $j-a_i<j$ 且 $j-a_i\ge0$（内层从 $a_i$ 起），它**已在本轮被处理过**（若 $j-a_i\ge a_i$）或**本轮根本不会处理**（若 $0\le j-a_i<a_i$，此时它保持 $f_i[j-a_i]$，因为内层不碰 $<a_i$ 的下标）。两种情况下它都等于 $f_{i+1}[j-a_i]$：前者由本轮升序归纳（更小的下标已更新成 $f_{i+1}$），后者因 $f_{i+1}[t]=f_i[t]$ 对 $t<a_i$ 成立（引理 1 中 $j<a_i$ 分支）。

于是执行后 `dp[j]`$=f_i[j]+f_{i+1}[j-a_i]=f_{i+1}[j]$（引理 1，把 $i$ 换成 $i+1$、面额 $a_{(i+1)-1}=a_i$）。对 $j<a_i$ 的下标本轮不动，而 $f_{i+1}[j]=f_i[j]$，仍正确。故第 $i$ 轮结束后 `dp[j]`$=f_{i+1}[j]\bmod p$ 对所有 $j$ 成立。

归纳完成，得 `dp[w]`$=f_n[w]\bmod p$。

**"每种组合只计一次"的组合解释**：上述递推按"面额种类编号从小到大"逐种决定张数。任一组合 $\mathbf c$ 在 DP 中对应唯一的生成路径——先决定 $c_0$（用若干次 $a_0$），再 $c_1$，……，最后 $c_{n-1}$。因为外层固定了种类顺序，同一种组合不会被"换个顺序再加一遍"，故不重不漏。这正是"组合（无序）"与"排列（有序）"的区别：若改成金额外层、面额内层，则同一组合的不同纸币排列会被分别计数（见 P2840）。证毕。

---

### 引理 3（降序会退化成 01 背包——为什么必须升序）

若内层改为**降序** $j=w,w-1,\dots,a_i$，则第 $i$ 轮结束后 `dp[j]` 等于"每种面额**至多用一张**凑出 $j$"的方案数，而非本题的无限张。

*证明*：降序时，算 `dp[j]` 用到的 `dp[j-a_i]`（$j-a_i<j$）**尚未在本轮被处理**，仍是上一轮的值 $f_{i-1}[j-a_i]$。于是递推变成 `dp[j]=f_{i-1}[j]+f_{i-1}[j-a_i]`，即"第 $i$ 种要么不用、要么恰用一张（用一张后退回前 $i-1$ 种）"。这正是 01 背包的递推。对 $a=\{1,2\},w=3$：升序得 $f_2[3]=2$（$\{1,1,1\},\{1,2\}$），降序得 $1$（只有 $\{1,2\}$，因为 $1$ 最多用一张，凑不出 $3$）。故降序错误。证毕。

---

### 引理 4（取模与 `int` 不溢出）

算法中每次加法前，`dp[j]` 与 `dp[j-a_i]` 均在 $[0,p)$ 内。其和 $s$ 满足 $0\le s\le 2(p-1)=2\,000\,000\,012<2^{31}-1$，故 `int` 加法不溢出；且 $s\bmod p$ 等于"若 $s\ge p$ 则 $s-p$，否则 $s$"（因 $s<2p$，至多减一次）。算法正是这样做的，故每步结果都正确落在 $[0,p)$ 且等于真实值模 $p$。

*证明*：$p=1\,000\,000\,007$，$2(p-1)=2\,000\,000\,012$。`int` 上限 $2\,147\,483\,647>2\,000\,000\,012$，不溢出。又 $0\le s<2p$，故 $s\bmod p=s$（当 $s<p$）或 $s-p$（当 $p\le s<2p$），与"加完若 $\ge p$ 减一次 $p$"一致。由归纳，所有 `dp` 值始终是正确的模 $p$ 余数。证毕。

---

### 引理 5（复杂度）

时间 $O(nw)$，空间 $O(n+w)$。

*证明*：外层 $n$ 轮，第 $i$ 轮内层至多 $w-a_i+1\le w$ 次，每次 $O(1)$（一次加法、一次比较、可能一次减法），故时间 $O(nw)$。代入 $n=10^3,w=10^4$ 得 $10^7$ 次基本操作，实测约 $0.06$ 秒。空间：面额数组 $a$ 占 $O(n)$，`dp` 占 $O(w)$，合计 $O(n+w)$。证毕。

---

### 定理

算法输出 $N(w)=\#\{\mathbf c\ge0:\sum c_i a_i=w\}\bmod(10^9+7)$，即恰好凑出 $w$ 元的纸币组合数（不计顺序），时间 $O(nw)$。

*证明*：引理 1 给出正确递推与边界；引理 2 证明一维升序滚动精确实现该递推、且每种组合计一次；引理 3 排除降序的错误退化；引理 4 保证取模与整型运算无误；引理 5 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "组合"= 不计顺序 = 数方程 $\sum c_i a_i=w$ 的非负整数解；面额互异保证解与组合一一对应。
2. **consider easier version** — 先想枚举每种张数的暴力，发现解数可达天文数字、$n=10^3$ 层递归不可行，确认要背包计数 DP。
3. **classic problem solution** — 完全背包计数：$f_i[j]=f_{i-1}[j]+f_i[j-a_i]$，"至少用一张"那支仍是 $f_i$（无限张）。
4. **reduce to easier problem** — 滚掉一维成 `dp[j]`；面额外层 + 金额**升序**内层，恰好让 `dp[j-a_i]` 取到本轮已更新值。
5. **discuss by category** — 用最小反例 $a=\{1,2\},w=3$ 区分组合(2)/排列(3)/01背包(1)，钉死"必须面额外层 + 升序"。
6. **explore its property** — 模 $10^9+7$ 下两数之和 $<2p<2^{31}$，`int` 安全，加完减一次 $p$ 代替 `%`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 纸币种数，$\le10^3$ | `int` | 读入 |
| `w` | 目标金额，$\le10^4$ | `int` | 读入 |
| `a[i]` | 第 $i$ 种面额（0-based），互异，$\ge1$ | `int[mxn]` | 读入；`mxn=1005` |
| `dp[j]` | 只用"已处理过的面额"凑出 $j$ 元的**组合数** $\bmod p$ | `int[mxw]` | `dp[0]=1`，其余 $0$（全局默认）；`mxw=10005` |
| `p` | 模数 $10^9+7$ | `constexpr int` | `1'000'000'007` |
| `i` | 外层面额下标 | `int` | $0..n-1$ |
| `j` | 内层金额，**升序** | `int` | $a_i..w$ |

### 算法步骤

1. I/O 加速三行（`cin.tie` → `cout.tie` → `sync_with_stdio`）。
2. 读 `n,w`；读 `a[0..n-1]`。
3. `dp[0]=1`（空组合凑 $0$ 元），其余靠全局零初始化。
4. 对 `i=0..n-1`：对 `j=a[i]..w`（升序）执行 `dp[j]+=dp[j-a[i]]; if(dp[j]>=p)dp[j]-=p;`。
5. 输出 `dp[w]`。

### 复杂度

- 时间：$O(nw)\le10^7$，实测极限数据约 $0.06$ 秒。
- 空间：$O(n+w)$（`a` 与 `dp` 两个一维数组）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 $\{1,2\}/w=3\to2$、$\{2\}/w=3\to0$ 与手算一致；极限 $n=1000,w=10000$ 正常运行。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2834 纸币问题 3
// 组合(无序)计数 ⇒ 完全背包：面额外层 + 金额升序内层。
// dp[j] = 只用已处理面额凑出 j 的组合数；dp[0]=1(空组合)。
// 升序保证 dp[j-a[i]] 是本轮已更新值(允许再用第 i 种) ⇒ 无限张。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},mxw{10005};
constexpr int p{1'000'000'007};

int n,w,a[mxn],dp[mxw];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>w;
	for(int i=0;i<n;++i)
		cin>>a[i];
	dp[0]=1;					// 凑 0 元：一张都不选，唯一组合
	for(int i=0;i<n;++i)		// 外层枚举纸币种类 ⇒ 组合（无序）
		for(int j=a[i];j<=w;++j)
		{
			dp[j]+=dp[j-a[i]];	// 两个 <p 的数相加 <2p<2^31，int 安全
			if(dp[j]>=p)
				dp[j]-=p;
		}
	cout<<dp[w]<<'\n';
	return 0;
}
```

### 代码说明

- **循环次序是本题唯一的核心**：面额外层、金额升序内层。换成金额外层就变成 P2840 的排列计数；换成降序就退化成 01 背包（引理 3）。
- `dp[0]=1` 是所有递推的种子，表示"空组合"。其余 `dp[j]` 依赖全局零初始化，恰好正确（凑不出时为 $0$）。
- 取模用"加完若 $\ge p$ 减一次 $p$"，因为两加数都 $<p$、和 $<2p$，`int` 不溢出（引理 4），比 `%` 快。
- 面额互异这一条件保证了"解向量 ↔ 组合"是一一对应，DP 不会把同一种组合重复计数。
