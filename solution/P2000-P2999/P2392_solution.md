# P2392 kkksc03 考前临时抱佛脚 — 题解

## 一、解题过程：人类思考叙事

题目：kkksc03 要复习 $4$ 科，第 $i$ 科有 $s_i$ 道题（$1\le s_i\le 20$），第 $j$ 道题耗时 $a_{i,j}$ 分钟（$1\le a_{i,j}\le 60$）。他有左右两个大脑，**同一科内**可以同时算两道不同的题（一脑一道），但**必须一科一科地复习**，不能跨科并行。求复习完全部题目的最短总时间。

先把"时间"这件事算清楚。一科内部，左脑拿到一个题目集合 $L$、右脑拿到补集 $R$，两个脑各自按顺序做自己那堆题，互不干扰。于是这一科的用时是

$$T=\max\Big(\sum_{j\in L}a_j,\ \sum_{j\in R}a_j\Big).$$

而四科是**串行**的，总时间就是 $T_1+T_2+T_3+T_4$。四科之间没有任何共享资源（脑在科与科之间是复用的，但既然串行，就不存在冲突），所以四个 $T_i$ 可以**各自独立地最小化**，再相加。问题立刻被拆成 $4$ 个完全一样的子问题：

> 给定 $s\le 20$ 个正整数，把它们分成两堆，使**较大那堆的和**最小。

第一个念头是贪心：把题目按耗时从大到小排序，每次塞给当前较轻的那个脑（LPT 调度）。写起来很短，但马上能构造反例。取 $a=(3,3,2,2,2)$，总和 $S=12$：

- LPT：$3\to L(3)$，$3\to R(3)$，$2\to L(5)$，$2\to R(5)$，$2\to L(7)$，得 $\max(7,5)=7$；
- 但 $\{3,3\}$ 与 $\{2,2,2\}$ 两边都是 $6$，答案是 $6$。

贪心差了整整 $1$ 分钟。**为什么会差？** 因为 LPT 只看"当前哪边轻"，它不知道后面还有几个 $2$ 可以填平缺口；这是一个**全局配平**问题，局部决策看不见未来。既然贪心不行，就得精确求"最接近半和的子集"。

于是问题变成：设 $S=\sum a_j$，一堆的和为 $t$，另一堆就是 $S-t$，用时 $f(t)=\max(t,S-t)$。这个函数在 $t=S/2$ 处取最小值 $S/2$，向两边线性增大。所以我们要找**可达的子集和中最接近 $S/2$ 的那个**。

这里有一个很舒服的对称性：$t$ 可达 $\iff$ $S-t$ 可达（取补集就行）。所以只需在 $t\le\lfloor S/2\rfloor$ 的一侧找**最大**的可达 $t$，答案就是 $S-t$。不必两侧都找。

那"可达的子集和"怎么求？$S\le 20\times 60=1200$，值域小得离谱——这就是一个**布尔 01 背包**：`dp[j]` 表示"能否选出若干道题恰好凑出 $j$ 分钟"，对每道题 $a$ 做 `for j=half..a: dp[j]|=dp[j-a]`。单科复杂度 $O(s\cdot S/2)\le 20\times 600=12000$，四科不到 $5$ 万次运算。

为什么不用 $2^{20}$ 枚举子集？$4\times 2^{20}\times 20\approx 8\times 10^7$，理论上能过但没必要；背包把指数级降成了线性级，而且代码更短。

实现上有两个必须记住的坑：

**坑一：`dp` 数组跨科复用必须清空。** 全局 `bool dp[]` 默认是 `false`，但第一科跑完后里面留着一堆 `true`；如果第二科不 `fill`，那些"上一科能凑出的时长"会被当成本科的可达状态，直接算出偏小的答案。这不是"默认 0 还是 INF"的问题，而是**多阶段状态残留**的问题。

**坑二：`half` 要取 $\lfloor S/2\rfloor$，且背包上界就是 `half`。** 当 $S$ 是奇数时，$\lfloor S/2\rfloor$ 与 $\lceil S/2\rceil$ 差 $1$，取错了会漏掉最优解或者多算。另外单题科目（$s=1$）时 $S=a$，`half`$=\lfloor a/2\rfloor<a$，唯一可达的是 $t=0$，于是 $T=a$——一个脑干活、另一个脑闲着，完全正确，不需要特判。

自己造两组小数据核对（题面没有给样例）：

**例 1**：$s=(1,1,1,1)$，四科各一道题，耗时都是 $1$。每科 $S=1$、`half`$=0$、`best`$=0$、$T=1$，总答案 $4$。含义：每科只有一道题，两个脑没法并行，只能一科一分钟地串行做完。

**例 2**：$s=(2,2,2,2)$，$A=(1,2)$，$B=(3,4)$，$C=(5,6)$，$D=(7,8)$。

| 科 | $S$ | `half` | 可达且 $\le$`half` 的最大 $t$ | $T=S-t$ |
|---|---|---|---|---|
| A | $3$ | $1$ | $1$（选 $\{1\}$） | $2$ |
| B | $7$ | $3$ | $3$（选 $\{3\}$） | $4$ |
| C | $11$ | $5$ | $5$（选 $\{5\}$） | $6$ |
| D | $15$ | $7$ | $7$（选 $\{7\}$） | $8$ |

总答案 $2+4+6+8=20$。以 B 科为例验证：$\{3\}$ 给左脑、$\{4\}$ 给右脑，$\max(3,4)=4$，确实是最优（$3+4=7$ 是奇数，不可能两边都 $\le 3$）。

## 二、思维链：完整证明

下面把整条链条补全。约定：一科内每道题**整体**由某一个脑完成（题面"同时计算 $2$ 道不同的题目"即一脑一道、题目不可拆分、不可中途换脑），两个脑并行工作，科与科之间串行。

### 引理 1（可分解性）

设第 $i$ 科在最优安排下的用时为 $T_i^\*$，则全局最优总时间为 $\sum_{i=1}^{4}T_i^\*$，且各科可以独立取到自己的最优。

*证明*：由"必须一科一科复习"，四科在时间轴上依次排列、互不重叠，故总时间 $=\sum_i T_i$，其中 $T_i$ 只依赖第 $i$ 科内部的题目分配方案 $\pi_i$。四科的决策变量 $\pi_1,\dots,\pi_4$ 之间没有任何耦合约束（脑在科间串行复用，不构成资源竞争），可行域是笛卡尔积 $\Pi_1\times\Pi_2\times\Pi_3\times\Pi_4$。对可分离目标函数在笛卡尔积上求最小值，有
$$\min_{(\pi_1,\dots,\pi_4)}\sum_i T_i(\pi_i)=\sum_i\min_{\pi_i\in\Pi_i}T_i(\pi_i),$$
因为对任意 $(\pi_i)$ 有 $\sum_i T_i(\pi_i)\ge\sum_i T_i^\*$（逐项不等式相加），而取 $\pi_i$ 为各自最优时等号成立。证毕。

### 引理 2（调度 $\iff$ 划分）

固定一科，题目耗时为 $a_1,\dots,a_s$，$S=\sum_j a_j$。在引理 1 的模型下，该科的最短完成时间等于
$$\min_{L\subseteq\{1..s\}}\max\Big(\sum_{j\in L}a_j,\ S-\sum_{j\in L}a_j\Big).$$

*证明*：分两个方向。

**（可达性 / 上界）** 任取划分 $(L,R)$，令左脑按任意顺序连续做 $L$ 中的题、右脑连续做 $R$ 中的题，两脑同时开工、中途不休息。左脑在时刻 $\sum_{j\in L}a_j$ 完工，右脑在时刻 $\sum_{j\in R}a_j$ 完工，整科在 $\max$ 时刻完工。故最优值 $\le$ 右式。

**（下界）** 考察任意一个合法安排。由于每道题整体由一个脑完成，每道题 $j$ 都有唯一归属脑 $b(j)\in\{L,R\}$，这就诱导了一个划分 $(L,R)$。脑 $b$ 必须串行做完属于它的所有题，其忙碌总时长恰为 $\sum_{j:b(j)=b}a_j$，因此整科完成时刻 $\ge\max(\sum_L,\sum_R)$。这对**每一个**合法安排都成立，故最优值 $\ge\min_{(L,R)}\max(\sum_L,\sum_R)=$ 右式。

两个方向夹逼得等号。注意下界论证不依赖"脑是否中途休息""题目顺序如何"——它只用了"每道题的耗时必须被某个脑完整承担"这一条，所以任何交错、任何空闲都不可能比最优划分更好。证毕。

### 引理 3（对称化：只需找半和以下的最大子集和）

设 $\mathcal A=\{\sum_{j\in L}a_j: L\subseteq\{1..s\}\}$ 为全部可达子集和，$H=\lfloor S/2\rfloor$，$t^\*=\max\{t\in\mathcal A: t\le H\}$。则引理 2 的最小值等于 $S-t^\*$。

*证明*：先注意 $0\in\mathcal A$（空集）且 $0\le H$，故 $t^\*$ 存在。

**第一步：$\mathcal A$ 关于 $S/2$ 对称。** 映射 $L\mapsto \{1..s\}\setminus L$ 是子集族上的对合，且 $\sum_{j\in L^c}a_j=S-\sum_{j\in L}a_j$。故 $t\in\mathcal A\iff S-t\in\mathcal A$。

**第二步：$f(t)=\max(t,S-t)$ 的单调性。** 当 $t\le S/2$ 时 $f(t)=S-t$，关于 $t$ 单调不增；当 $t\ge S/2$ 时 $f(t)=t$，单调不减。且 $f(t)=f(S-t)$ 恒成立。

**第三步：把 $>H$ 的可达值折回 $\le H$。** 设 $t\in\mathcal A$ 且 $t>H$。由第一步 $S-t\in\mathcal A$。断言 $S-t\le H$：
- 若 $S=2H$（偶），$t\ge H+1\Rightarrow S-t\le H-1\le H$；
- 若 $S=2H+1$（奇），$t\ge H+1\Rightarrow S-t\le H$。

两种情况都成立。又 $f(S-t)=f(t)$，所以
$$\min_{t\in\mathcal A}f(t)=\min_{t\in\mathcal A,\ t\le H}f(t).$$

**第四步：在 $[0,H]$ 上 $f(t)=S-t$。** 因为 $t\le H\le S/2$，由第二步 $f(t)=S-t$，它关于 $t$ 单调不增，故在 $t=t^\*$（该区间内最大可达值）处取最小，最小值为 $S-t^\*$。

综合得引理 2 的最小值 $=S-t^\*$。证毕。

**推论（算法只需算到 $H$）**：背包上界取 $H=\lfloor S/2\rfloor$ 即可，不必算到 $S$；这既省一半时间，也直接给出 $t^\*$。

### 引理 4（布尔 01 背包的状态含义与转移正确性）

设物品为 $a_1,\dots,a_s$，容量上界 $H$。定义
$$dp_i[j]=\big[\exists\,T\subseteq\{1..i\},\ \textstyle\sum_{k\in T}a_k=j\big],\quad 0\le j\le H.$$
则 $dp_0[0]=\text{true}$、$dp_0[j>0]=\text{false}$，且
$$dp_i[j]=dp_{i-1}[j]\ \lor\ \big(j\ge a_i\ \land\ dp_{i-1}[j-a_i]\big).$$
用一维数组、$j$ **从 $H$ 递减到 $a_i$** 就地更新，可正确算出 $dp_s$。

*证明*：

**（状态转移）** 对含 $a_i$ 的子集 $T\subseteq\{1..i\}$ 分两类：$i\notin T$ 时 $T\subseteq\{1..i-1\}$，其和为 $j$ 当且仅当 $dp_{i-1}[j]$；$i\in T$ 时 $T\setminus\{i\}\subseteq\{1..i-1\}$ 且和为 $j-a_i$（要求 $j\ge a_i$），当且仅当 $dp_{i-1}[j-a_i]$。两类互斥且穷尽，故取或。边界 $dp_0$ 由"空集和为 $0$、非空子集不存在"直接得到。

**（降序就地更新的正确性）** 用一维数组 $dp[\cdot]$ 表示"当前已处理物品"的状态。处理第 $i$ 件时，按 $j=H,H-1,\dots,a_i$ 的顺序执行 $dp[j]\mathrel{|}=dp[j-a_i]$。断言：在更新下标 $j$ 的时刻，$dp[j-a_i]$ 仍保存的是 $dp_{i-1}[j-a_i]$。理由：$j-a_i<j$（因 $a_i\ge 1$），而本轮只更新了 $\ge j$ 的下标（降序），故下标 $j-a_i$ 尚未被本轮触碰，其值就是上一轮结束时的 $dp_{i-1}[j-a_i]$。同时 $dp[j]$ 在被更新前也仍是 $dp_{i-1}[j]$（同理，$j$ 是本轮第一个被碰到的 $\le j$ 的下标）。于是这次就地或运算恰好实现了上面的转移式，且**每件物品最多被用一次**——这正是 01 背包而非完全背包的关键。若改成升序，$dp[j-a_i]$ 可能已被本轮更新过（含了第 $i$ 件），会导致同一道题被重复选入，语义变成完全背包，答案偏小。

**（每科必须清零）** 一维数组是跨科复用的全局存储。第 $i$ 科开始前若不把 $dp[0..H]$ 全部置 `false` 再令 $dp[0]=\text{true}$，则残留的 `true` 会被当作"本科已可达"，由转移式它们会污染后续所有状态。举一个具体的失败例：第一科 $a=(1,2)$、$S=3$、$H=1$，结束后 $dp[0]=dp[1]=\text{true}$；第二科只有一道题 $a=(5)$、$S=5$、$H=2$，若不清零，$dp[1]=\text{true}$ 会被误认为"第二科能凑出 $1$ 分钟"，于是 $t^\*=1$、$T=5-1=4$，而正确答案是 $5$。故清零是正确性的一部分，不是可选优化。证毕。

### 引理 5（值域与复杂度）

$S\le 20\times 60=1200$，故 $H\le 600$；单科时间 $O(s\cdot H)\le 20\times 600=1.2\times 10^4$，四科合计 $\le 4.8\times 10^4$ 次布尔运算；空间 $O(H_{\max})=O(1205)$。

*证明*：$s\le 20$、$a_j\le 60$ 直接给出 $S\le 1200$。背包双重循环外层 $s$ 次、内层至多 $H+1$ 次，每次 $O(1)$。数组只需开到 $\max H+1\le 601$，取 $1205$（$1200+5$ 松弛）足够且宽裕。证毕。

### 引理 6（边界情形）

- $s=1$：$\mathcal A=\{0,a_1\}$，$H=\lfloor a_1/2\rfloor<a_1$（因 $a_1\ge 1$），故 $t^\*=0$，$T=a_1$。
- $a_j$ 全为 $1$、$s=20$：$S=20$、$H=10$，$t^\*=10$，$T=10$（两脑各做 $10$ 道）。
- $S$ 为奇数：$t^\*\le H=(S-1)/2$，$T=S-t^\*\ge (S+1)/2=\lceil S/2\rceil$，与"两堆不可能完全相等"一致。

*证明*：逐条代入引理 3、4 即可。第一条中 $H<a_1$ 是因为 $a_1\ge 1\Rightarrow\lfloor a_1/2\rfloor\le a_1-1$；此时唯一 $\le H$ 的可达值是 $0$。第二条中 $\{1,\dots,1\}$ 的任意 $k$ 元子集和为 $k$，故 $\mathcal A=\{0,1,\dots,20\}$，$t^\*=10$。第三条由 $t^\*\le H$ 与 $T=S-t^\*$ 直接得到。证毕。

### 定理

算法输出的 $\sum_{i=1}^{4}(S_i-t_i^\*)$ 就是最短总复习时间。

*证明*：由引理 1，全局最优 $=\sum_i$（第 $i$ 科最优）；由引理 2，第 $i$ 科最优 $=\min_{L}\max(\sum_L,S_i-\sum_L)$；由引理 3，该最小值 $=S_i-t_i^\*$；由引理 4，背包正确算出 $t_i^\*$（且每科清零保证状态不串）；由引理 6，边界情形无需特判。四者串联即得。证毕。

### 为什么贪心必须被放弃（反例的完整分析）

LPT（最长处理时间优先）在本题失效，反例 $a=(3,3,2,2,2)$ 已在第一部分给出：LPT 得 $7$，最优 $6$。这里补一个**为什么它必然失效**的结构性解释：LPT 的决策只依赖"当前两堆的差"，而目标函数 $\max(t,S-t)$ 依赖"最终两堆的差"。当剩余物品还能改变差值时，当前的局部最优选择可能与最终配平冲突。上例中前两个 $3$ 被分到两侧后差为 $0$，LPT 认为"已经平衡"，于是把三个 $2$ 按 $2,2,2$ 交替塞入，最终差为 $2$；而全局最优是把两个 $3$ 放同一侧、三个 $2$ 放另一侧，差为 $0$。**局部平衡 $\ne$ 全局平衡**，这正是必须用精确 DP 的原因。另一方面，LPT 也不是完全无用：它给出一个上界，但本题要求精确最优，故弃用。

## 三、模式总结（按实际思考顺序）

- explore its property — 两脑并行 ⇒ 单科用时 $=\max(\text{左堆和},\text{右堆和})$；科间串行 ⇒ 总时间 $=$ 四科用时之和。
- reduce to easier problem — 四科决策互不耦合，拆成 $4$ 个同构的"单科配平"子问题，分别求最优再相加。
- consider easier version — 先剥掉"四科"外壳，只问：$s\le 20$ 个数分两堆，使较大堆最小。
- discuss by category — 试贪心 LPT，用 $(3,3,2,2,2)$ 反例证伪（局部平衡 $\ne$ 全局平衡），转向精确算法。
- explore its property — $f(t)=\max(t,S-t)$ 在 $S/2$ 处最小，且可达子集和集合关于 $S/2$ 对称 ⇒ 只需求 $\le\lfloor S/2\rfloor$ 的**最大**可达子集和。
- classic problem solution — 子集和可达性 = 布尔 01 背包；$S\le 1200$ 值域极小，$O(s\cdot S/2)$ 完胜 $2^{s}$ 枚举。
- explore its property — 全局 `dp` 跨科复用必须清零，否则上一科的可达状态污染本科（引理 4 给出了具体失败例）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `mxn` | 背包数组尺寸 $=1200+5$ | `constexpr int{1205}` | 单科总时长上界 $20\times60$ |
| `mxs` | 单科题目数上界 $+5$ | `constexpr int{25}` | $s_i\le 20$ |
| `s[4]` | 四科的题目数 | `int`，读入 | 第一行的四个数 |
| `a[mxs]` | **当前科**各题耗时 | `int`，每科重读 | 复用同一数组，读完即算 |
| `tot` | 当前科总时长 $S=\sum a_j$ | `int`，每科置 $0$ | $S\le 1200$ |
| `half` | $H=\lfloor S/2\rfloor$，背包上界 | `int`，每科重算 | 只搜半和以下 |
| `dp[mxn]` | `dp[j]` = 能否选出若干题恰好凑出 $j$ 分钟 | `bool`，**每科 `fill_n` 清零**后置 `dp[0]=true` | 布尔 01 背包，降序转移 |
| `best` | $t^\*=\max\{j\le H: dp[j]\}$ | `int`，初值 $0$ | 从 `half` 往下扫，首个 `true` 即是 |
| `ans` | 总最短时间 $\sum_i(S_i-t_i^\*)$ | `int`，初值 $0$ | 四科累加 |

### 算法步骤

1. 读入 $s_1,s_2,s_3,s_4$。
2. 对每科 $k=0,1,2,3$：
   1. 读入 $s_k$ 个耗时到 `a[]`，同时累加得 `tot`$=S$。
   2. `half = tot/2`（整数除法即 $\lfloor S/2\rfloor$）。
   3. `fill_n(dp,mxn,false)` 清空，再置 `dp[0]=true`（空集可达）。
   4. 对每道题 `a[i]`，令 `j` 从 `half` **递减**到 `a[i]`：若 `dp[j-a[i]]` 为真则置 `dp[j]=true`。
   5. 从 `half` 递减扫到 $0$，第一个 `dp[j]==true` 的 `j` 即 `best`$=t^\*$。
   6. `ans += tot-best`（由引理 3，$\max(t^\*,S-t^\*)=S-t^\*$）。
3. 输出 `ans`。

### 复杂度

- 时间：$O\!\left(\sum_{k=1}^{4} s_k\cdot\lfloor S_k/2\rfloor\right)\le 4\times 20\times 600=4.8\times 10^4$。
- 空间：$O(\text{mxn})=O(1205)$ 个 `bool`，另有 $O(25)$ 的读入数组。

### 验证状态

编译（`g++ -std=c++20 -O2`）无错误无警告；题面无样例，自造 $2$ 组小数据（答案 $4$ 与 $20$）手算核对一致；另用 $2^{s}$ 子集枚举暴力在 **300 组随机四科数据** + **1364 组穷举单科数据**（$s=1..5$、耗时 $1..4$ 的全部组合）上对拍，全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2392 kkksc03 考前临时抱佛脚
// 每科把题目分成两堆交给左右脑，用时 max(堆和)；01 背包求 <=S/2 的最大子集和
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1205},mxs{25};	// 单科总时长 <=20*60=1200

int s[4],a[mxs],tot,half;
bool dp[mxn];				// dp[j]=能否选出若干道题恰好凑出 j 分钟

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(int i=0;i<4;++i)
		cin>>s[i];
	int ans=0;
	for(int k=0;k<4;++k)
	{
		tot=0;
		for(int i=0;i<s[k];++i)
		{
			cin>>a[i];
			tot+=a[i];
		}
		half=tot/2;
		fill_n(dp,mxn,false);	// 多科之间必须清空，全局 bool 默认 0 不是「上一科的结果」
		dp[0]=true;
		for(int i=0;i<s[k];++i)
			for(int j=half;j>=a[i];--j)
				if(dp[j-a[i]])
					dp[j]=true;
		int best=0;
		for(int j=half;j>=0;--j)
			if(dp[j])
			{
				best=j;
				break;
			}
		ans+=tot-best;		// best<=tot/2 ⇒ max(best,tot-best)=tot-best
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `mxn{1205}` 是 $1200+5$ 松弛；虽然 `half` 最大只有 $600$，开大一点不影响正确性，也符合仓库"+5"约定。
- `fill_n(dp,mxn,false)` 清的是**整个**数组而不只是 `[0,half]`：下一科的 `half` 可能更大，残留区间同样会污染。
- 内层循环 `for(int j=half;j>=a[i];--j)` 天然处理了 `a[i]>half` 的情形（条件一开始就不成立，直接跳过），无需额外 `if`。
- `best` 的扫描是从 `half` **往下**找第一个 `true`，由引理 3 它就是 $t^\*$；找不到任何非零可达值时 `best=0`（`dp[0]` 恒真），对应"一个脑干全部活"。
- `ans+=tot-best` 而不是 `ans+=max(best,tot-best)`：两者等价（`best<=half<=tot/2`），前者少一次比较，也更能体现引理 3 的结论。
- 全程只用 `int`：$S\le 1200$、$ans\le 4800$，远未触及 32 位上限。
