# P2872 [USACO07DEC] Building Roads S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 平面上 $n$ 个点（$1\le n\le1000$，坐标 $1\le x_i,y_i\le10^6$），已经修好了 $m$ 条边（$1\le m\le1000$，连接给定的点对，**已经存在、不再花钱**）。现在要**新修**一些边（任意两点间都可修，代价为欧几里得距离），使所有点连通，求新修边总长的最小值。输出保留两位小数，题面明确要求用 64 位实型计算。

**第一步：已有边意味着什么？** 已有边免费，所以沿着已有边走动不花一分钱。把已有边构成的图的每个**连通块**看成一个"超级点"：块内任意两点已经互通，新修边如果两端落在同一块里，纯属浪费——它没有让任何原本不连通的点对变得连通。于是问题**缩点**：把每个连通块缩成一个点，要在这些超级点之间修边使之连通，代价是两端点间的欧氏距离。这就是**最小生成树（MST）**的形状。

**第二步：为什么最优解一定是一棵树？** 要连通，边集至少包含一棵生成树；反过来，若最优解里有环，删掉环上任意一条边仍连通（环上两点还有另一条路），而边权（距离）非负，删边只会让总长不增。所以最优解可以取成树——**MST 就是答案**。这一步把"选哪些边"从指数级子集搜索拉进了经典多项式算法的射程。

**第三步：选 Kruskal 还是 Prim？** 缩点后的图仍是稠密图（超级点之间两两可连）。两条经典路线：

- **Prim**：$O(n^2)$ 稠密图版，不用存边，但要处理"超级点间距离 = 块间点对最小距离"的维护，代码绕。
- **Kruskal**：把所有候选边排序 + 并查集。$n\le1000$，完全图边数 $n(n-1)/2\le499500$，排序约 $5\times10^5\times19\approx10^7$ 次比较，完全可行；而且**已有边可以提前用并查集合并掉**，之后扫候选边时"同块就跳过"，天然实现了缩点，代码极短。

选 Kruskal。具体流程：读点 → 并查集把 $m$ 条已有边的端点 union（免费边先"修好"）→ 枚举所有点对 $(i,j),i<j$，边权取**距离的平方**（整数！）→ 按权排序 → 扫边，两端不同块就 union 并把 $\sqrt{w}$ 累加进答案。

**第四步：两个数值陷阱，都是会静默出错的那种。**

1. **平方距离必须 64 位整数。** 坐标差最大 $10^6-1$，平方约 $10^{12}$，两项和约 $2\times10^{12}$，远超 `int` 的 $2.1\times10^9$。若用 `int` 存 $dx^2+dy^2$ 会溢出成乱七八糟的负数，排序顺序全错。最小演示：点 $(1,1)$ 与 $(10^6,10^6)$，平方距离 $2\times(999999)^2\approx2\times10^{12}$。用 `long long`。
2. **排序用平方距离，开方只留给选中的边。** $\sqrt{\cdot}$ 在 $[0,\infty)$ 上严格递增，按 $w^2$ 排序与按 $w$ 排序**顺序完全一致**（平方相等 ⟺ 距离相等，并列时选谁对 MST 总权无影响）。这样排序阶段全是精确整数比较，没有浮点误差；只有至多 $n-1$ 条被选中的边各开一次方，误差源被压到最少。

**第五步：精度够吗？** 答案至多 $(n-1)\times\sqrt2\times10^6\approx1.4\times10^9$。`double` 有约 15–16 位有效数字，这个量级下绝对误差约 $10^{-7}$，远小于保留两位小数所需的 $0.005$；每次 `sqrt` 的相对误差 $\le$ 机器精度，累加 $999$ 次也放大不到哪去。题面要求的"64 位实型"就是 `double`，照办。

**手造数据核对**：$n=4,m=1$，点 $(1,1),(3,1),(1,4),(3,4)$，已有边 $1$–$2$。
- 并查集：$\{1,2\},\{3\},\{4\}$ 三块。
- 候选边（平方距离）：$3$–$4$: $4$；$1$–$3$: $9$；$2$–$4$: $9$；$1$–$4$: $13$；$2$–$3$: $13$；$1$–$2$: $4$（同块，跳过）。
- Kruskal：选 $3$–$4$（长 $2$），块变 $\{1,2\},\{3,4\}$；$1$–$2$ 同块跳过；选 $1$–$3$（长 $3$），全连通。总长 $2+3=5$。

输出 `5.00`。直观核对：把右边两点连起来（$2$），再把左右两列连起来（$3$），没有更便宜的连法——左列内部已被免费边打通，右列内部最便宜是 $2$，两列之间最便宜是 $3$。

## 二、思维链：完整证明

**记号。** 点集 $V=\{0,\dots,n-1\}$（0-based）。已有边集 $E_0$（$m$ 条）。完全图 $K_n$ 上定义边权
$$w(u,v)=\begin{cases}0,&(u,v)\in E_0,\\ \mathrm{dist}(u,v)=\sqrt{(x_u-x_v)^2+(y_u-y_v)^2},&\text{否则}.\end{cases}$$
算法：并查集 `f` 先 union 所有 $E_0$ 的端点；枚举所有点对生成边数组 `E`，权存**平方距离**（`i64`）；按权升序排序；扫边，两端根不同则 union 并累加 $\sqrt{w}$ 到 `ans`。

---

### 引理 1（问题等价于带零权边的 MST）

原问题的最优值 $=$ $K_n$ 在权 $w$ 下的 MST 总权。

*证明*：建立双射。原问题的一个可行解是新修边集 $F$，使图 $(V,E_0\cup F)$ 连通，代价 $\sum_{e\in F}\mathrm{len}(e)$。对应到 $K_n$ 的边集 $E_0\cup F$：它连通，且总权 $\sum_{e\in E_0}0+\sum_{e\in F}\mathrm{len}(e)$ 恰为原代价。反之，$K_n$ 的任何连通生成子图 $H$ 对应原问题可行解 $F=H\setminus E_0$（$E_0$ 本来就存在，$H$ 中其余边就是要新修的），代价 $=\sum_{e\in H}w(e)$。两个方向都保持"连通"与"代价"，故两边最优值相等。

再由"非负权图的最优连通生成子图必可取为生成树"：设 $H$ 连通且有环，删去环上一条边 $e$，环上两端点仍可通过环的其余部分互达，其余点对的连通性不受影响（任何用到 $e$ 的路径可改走环的另一侧），故 $H-e$ 仍连通；$w(e)\ge0$ 故总权不增。反复删环直到无环，得到生成树且总权 $\le$ 原值。所以 MST 总权 $\le$ 任何连通子图总权，而 MST 本身连通，最优值就是 MST 总权。证毕。

---

### 引理 2（预合并 = 先处理零权边）

"先把 $E_0$ 全部 union，再对正权边跑 Kruskal"与"在 $K_n$ 上按 $w$ 完整跑 Kruskal（零权边排最前）"选出的正权边集完全相同，故总权相同。

*证明*：完整 Kruskal 按权升序扫边，所有权 $0$ 的边（即 $E_0$，距离为 $0$ 的不同点对不存在——坐标是整数且点对 $u\ne v$ 时若坐标全同则距离为 $0$，见下方注）排在所有正权边之前。扫零权边阶段的行为就是"两端不同块就 union"，与算法开头的预合并逐条等价（并查集状态只取决于 union 的边集，与顺序无关：同一边集诱导的连通划分唯一）。零权边阶段结束后，并查集的块恰为 $(V,E_0)$ 的连通块；此后扫正权边时，"同块跳过、异块选中"的判据在两个版本里面对同一个并查集状态，逐边决策一致。故选中的正权边集相同，累加的 $\sqrt{w}$ 之和相同。

（注：若存在两个不同点坐标完全相同，它们之间的"正权边"权也为 $0$，会被排在零权段。这不影响结论：把这类边也视为"免费段"的一部分，预合并阶段没 union 它们，但排序后它们最先被扫到并 union，等价于把 $E_0$ 扩充为"所有零权边"。算法的正确性论证对扩充后的 $E_0$ 同样成立，因为引理 1 的 $w$ 定义下这些边权确实是 $0$。）证毕。

---

### 引理 3（Kruskal 正确性：交换论证）

按权升序扫边、两端不在同一并查集块就选中的算法，输出 MST。

*证明*：维护不变量：**已选边集 $F$ 是某棵 MST 的子集**。初始 $F=\varnothing$，平凡。

设某步选中边 $e=(u,v)$（$u,v$ 在 $F$ 的不同连通块），取 MST $T\supseteq F$。若 $e\in T$，不变量保持。若 $e\notin T$：$T+e$ 含唯一环 $C$（树上加一条边恰生一个环）。$C$ 由 $e$ 与 $T$ 中 $u\to v$ 的路径 $P$ 组成。$u,v$ 在 $F$ 的不同块，而 $F\subseteq T$，故路径 $P$ 上必有一条边 $e'$ 跨越这两个 $F$-块（从 $u$ 所在块走到 $v$ 所在块至少跨一次）。$e'$ 的两端在 $F$ 的不同块，说明 Kruskal 扫到 $e$ 时 $e'$ 也是"可选"的候选；算法定理选的是当时候选里权最小的（升序扫描，且此前被跳过的边都是同块边，之后也不会变回候选——并查集只合并不分裂），故 $w(e)\le w(e')$。

令 $T'=T-e'+e$：$e'$ 在环 $C$ 上，删 $e'$ 加 $e$ 后仍连通且边数 $n-1$，是生成树；$w(T')=w(T)-w(e')+w(e)\le w(T)$。$T$ 是 MST，故 $T'$ 也是 MST，且 $F+e\subseteq T'$（$e'\notin F$，因为 $e'$ 跨 $F$-块而 $F$ 的边都在块内）。不变量保持。

归纳到扫描结束：$F$ 连通（否则还存在跨块边未被处理，与"扫完所有边"矛盾——任何跨最终块的边在被扫到时两端必不同块，会被选中），故 $F$ 是生成树；$F\subseteq$ 某 MST 且两者边数都是 $n-1$，故 $F$ 就是那棵 MST。证毕。

---

### 引理 4（平方距离排序等价，且必须 64 位）

按平方距离 $q(u,v)=(x_u-x_v)^2+(y_u-y_v)^2$ 升序排序，与按 $\mathrm{dist}$ 升序排序产生相同的可选顺序（并列次序可任意）；$q$ 必须用 `i64` 存储。

*证明*：$\mathrm{dist}=\sqrt q$，$\sqrt{\cdot}$ 在 $[0,\infty)$ 严格递增：$q_1<q_2\iff\sqrt{q_1}<\sqrt{q_2}$，$q_1=q_2\iff\sqrt{q_1}=\sqrt{q_2}$。故两种排序的"严格先后"关系逐对一致；平方并列的边距离也相等，Kruskal 在并列边中任选都不改变 MST 总权（引理 3 的证明只用到 $w(e)\le w(e')$，等号合法）。所以按 $q$ 排序跑 Kruskal 得到的总权与按 $\mathrm{dist}$ 排序相同。

值域：$|x_u-x_v|\le10^6-1$，$q\le2(10^6-1)^2\approx2\times10^{12}$。`int` 上界约 $2.1\times10^9$，存 $q$ 必溢出；`i64` 上界约 $9.2\times10^{18}$，安全。中间量 $dx\cdot dx$ 本身已达 $10^{12}$ 量级，故 $dx,dy$ 也要以 `i64` 参与乘法。证毕。

---

### 引理 5（精度）

用 `double` 累加至多 $n-1$ 个 $\sqrt q$，结果的绝对误差远小于 $0.005$，保留两位小数正确。

*证明*：每项 $\sqrt q\le\sqrt2\times10^6\approx1.414\times10^6$，总和 $S\le999\times1.414\times10^6\approx1.41\times10^9$。IEEE 754 `double` 的机器精度 $\varepsilon\approx2.2\times10^{-16}$：每次 `sqrt` 的相对误差 $\le\varepsilon$（正确舍入），每项绝对误差 $\le1.414\times10^6\varepsilon\approx3.1\times10^{-10}$；$999$ 次累加的舍入误差每步 $\le\varepsilon\times$ 当前部分和 $\le\varepsilon S\approx3.1\times10^{-7}$，总计 $\le999\times3.1\times10^{-7}+999\times3.1\times10^{-10}\approx3.1\times10^{-4}$……这个粗界仍 $<0.005$；更精细地，累加误差实际按 $\sum_k\varepsilon S_k\le\varepsilon\cdot999\cdot S/2$ 量级估计约 $1.6\times10^{-4}$，同样安全。故四舍五入到两位小数与精确值一致（除非精确值恰好落在 $x.xx5$ 的半整数分位上——此时任何浮点实现都有歧义，属题目容差范围，SPJ/常规判题均接受）。证毕。

---

### 引理 6（复杂度）

时间 $O(n^2\log n)$，空间 $O(n^2)$。

*证明*：生成边 $n(n-1)/2\le499500$ 条，$O(n^2)$；排序 $O(n^2\log(n^2))=O(n^2\log n)$，约 $5\times10^5\times19\approx10^7$ 次比较；扫描每条边两次 `getrt`（路径压缩，近似 $O(1)$），共 $O(n^2\alpha(n))$；开方至多 $n-1$ 次。合计 $O(n^2\log n)$。空间：边数组 $500005\times16$ B $\approx8$ MB（`{int,int,i64}`），点数组与并查集 $O(n)$。证毕。

---

### 定理

程序输出新修边的最小总长（两位小数），时间 $O(n^2\log n)$。

*证明*：引理 1 把原问题等价成带零权边的 MST；引理 2 证明预合并并查集实现与完整 Kruskal 一致；引理 3 证明 Kruskal 输出 MST；引理 4 证明平方距离排序不改变结果且值域安全；引理 5 保证浮点输出精度；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 已有边免费 ⇒ 连通块内互通，块内新修边无用，问题缩点到连通块。
2. **reduce to easier problem** — 建模成完全图 MST：已有边权 $0$，其余边权为欧氏距离。
3. **classic problem solution** — 非负权下最优连通子图必可取为生成树（删环边不增代价）。
4. **discuss by category** — 稠密图：Prim $O(n^2)$ 或 Kruskal $O(n^2\log n)$；$n\le1000$ 时后者边数 $\approx5\times10^5$ 可排序，且并查集预合并天然实现缩点，选 Kruskal。
5. **classic problem solution** — Kruskal + 并查集，交换论证证明"选最小跨块边"永远可扩展进某棵 MST。
6. **explore its property** — 排序用 `i64` 平方距离（$\sqrt{\cdot}$ 单调 ⇒ 顺序等价），开方只留给选中的 $\le n-1$ 条边；`int` 存平方会溢出。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,m` | 点数、已有边数，$\le1000$ | `int` | 读入 |
| `x[i],y[i]` | 点 $i$ 坐标（0-based），$\le10^6$ | `int[mxn]` | 读入 |
| `f[i]` | 并查集父亲 | `int[mxn]` | `iota(f,f+n,0)`；先 union 已有边 |
| `E[k]` | 候选边 $\{u,v,w\}$，$w$ 为**平方距离** | `struct edge[mxm]` | 枚举点对生成，按 `w` 升序排序 |
| `cnt` | 候选边条数 | `int` | $0$，生成时自增，终值 $n(n-1)/2$ |
| `ans` | 新修边总长 | `double` | $0$，选中边时累加 `sqrt(w)` |
| `mxn,mxm` | $1000+5$、$500000+5$ | `constexpr int` | 尺寸松弛 |

### 算法步骤

1. I/O 加速三行；读 `n,m` 与坐标；`iota` 初始化 `f`。
2. 读每条已有边 `u,v`（`--u;--v`），`f[getrt(u)]=getrt(v)` 免费合并。
3. 枚举 $i<j$，`E[cnt++]={i,j,dx*dx+dy*dy}`，`dx,dy` 以 `i64` 计算。
4. 按 `w` 升序排序 `E`。
5. 扫边：两端根相同跳过；否则 union，`ans+=sqrt((double)w)`。
6. `fixed<<setprecision(2)` 输出 `ans`。

### 复杂度

- 时间 $O(n^2\log n)\approx10^7$ 次比较。
- 空间 $O(n^2)\approx8$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 $4$ 点 $1$ 免费边数据输出 `5.00`，与手算 MST 一致；$n=1$ 时无候选边，输出 `0.00`。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2872 [USACO07DEC] Building Roads S
// 思路：已有边免费 ⇒ 并查集先缩点；再对完全图跑 Kruskal。
//       边权存平方距离（i64，防溢出），排序等价于按距离排（sqrt 单调）；
//       只有选中的 <=n-1 条边才开方，浮点误差源最少。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005},mxm{500005};

int n,m,x[mxn],y[mxn],f[mxn],cnt;
struct edge{int u,v;i64 w;}E[mxm];
double ans;

int getrt(int u)
{
	if(f[u]==u)
		return u;
	return f[u]=getrt(f[u]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];
	iota(f,f+n,0);
	for(int i=0,u,v;i<m;++i)
	{
		cin>>u>>v;--u;--v;
		f[getrt(u)]=getrt(v);	// 已有边免费，先缩点
	}
	for(int i=0;i<n;++i)
		for(int j=i+1;j<n;++j)
		{
			i64 dx=x[i]-x[j],dy=y[i]-y[j];
			E[cnt++]={i,j,dx*dx+dy*dy};	// 平方距离最大 2e12，int 会炸
		}
	sort(E,E+cnt,[](const edge&a,const edge&b){return a.w<b.w;});
	for(int i=0;i<cnt;++i)
	{
		auto[u,v,w]=E[i];
		u=getrt(u);v=getrt(v);
		if(u==v)
			continue;
		f[u]=v;
		ans+=sqrt((double)w);	// 只对选中边开方
	}
	cout<<fixed<<setprecision(2)<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 预合并已有边后，Kruskal 扫到同块边直接 `continue`——这就是"缩点"的全部实现，不需要显式建超级点。
- `dx,dy` 声明为 `i64`：若写成 `int`，`dx*dx` 在坐标差 $\ge46341$ 时就溢出，排序顺序静默错乱。
- 排序比较的是整数平方，精确无浮点；`sqrt` 只发生在至多 $n-1$ 条选中边上。
- 已有边里的自环、重边对并查集无害（`getrt` 相同则 union 是空操作），无需特判。
- $n=1$ 时候选边为空，`ans=0`，输出 `0.00`，边界自然成立。
