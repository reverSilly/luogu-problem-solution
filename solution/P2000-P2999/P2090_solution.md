# P2090 数字对 — 题解

## 一、解题过程：人类思考叙事

题目：从 $(1,1)$ 出发，操作是 $(a,b)\to(a+b,b)$ 或 $(a,b)\to(a,a+b)$，问最少几步能让数对中至少有一个数等于 $n$。

$n\le 10^6$。正向暴力：从 $(1,1)$ 出发 BFS/DFS，能走到的数对 $(\le n)$ 只有 $O(n^2)$ 个，每个数对的状态是 $(a,b)$，$10^{12}$ 个状态，太大。

换个方向想。正着走是"加"，反着走就是"减"。从 $(1,1)$ 反推：$(a+b,b)$ 的前驱是 $(a,b)$，也就是从 $(x,y)$（$x>y$）可以退回到 $(x-y,y)$。这正是**更相减损术**（减法版欧几里得）。

于是问题变成：从某个数对 $(n,i)$ 出发，用"每次把大数减去小数"的方式退回到 $(1,1)$，最少要退多少步？答案是所有 $i$ 中的最小值。

这里有一个很关键的结构性质：**前驱是唯一的**。给定 $(x,y)$，若 $x>y$，它只能由 $(x-y,y)$ 一步得到；若 $y>x$，只能由 $(x,y-x)$ 得到。所以从 $(1,1)$ 出发到任意数对的路径**唯一**，反向链也唯一。这解释了为什么"最少步数"根本不需要最短路算法 —— 路径只有一条。

但反向链能不能无限退下去？$(x,y)$ 退到 $(x-y,y)$ 会让和严格减小，所以一定终止。终止时两个数相等：$(d,d)$。要能退到 $(1,1)$，必须 $d=1$，也就是 $\gcd(x,y)=1$。所以**可达的数对恰好是互质的那些**，而退化步数就是更相减损术的步数。

现在还剩两个工程问题：

**问题一：$i$ 要枚举到哪里？** 直观上是 $1\le i\le n$。但会不会最优解的另一个数大于 $n$？比如 $n=5$，$(5,7)$ 也是互质的，它的反向链是 $(5,7)\to(5,2)\to(3,2)\to(1,2)\to(1,1)$，共 $4$ 步；而 $(5,2)$ 只要 $3$ 步。所以 $i>n$ 不会更优。严格地说：$i>n$ 时 $(n,i)$ 的前驱是 $(n,i-n)$，即 $D(n,i)=D(n,i-n)+1$，严格大于 $D(n,r)$（$r$ 为 $i$ 模 $n$ 的余数，$1\le r\le n$）。所以最优一定可以在 $1\le i\le n$ 中取到。（$i=n$ 时 $\gcd=n>1$，不可达，忽略。）

**问题二：反向链最长 $10^6$ 步，枚举 $n$ 个 $i$ 会是 $O(n^2)=10^{12}$，太慢。**

这里就要用到**更相减损术的加速**：与其一次减 $1$，不如一次减 $\lfloor x/y\rfloor$ 次。因为当 $x>y$ 时，连续减 $y$ 直到 $x\le y$，一共减了 $\lfloor x/y\rfloor$ 步（除非 $x$ 是 $y$ 的倍数，那就减到相等为止，共 $x/y$ 步）。把这 $\lfloor x/y\rfloor$ 步一次性记到计数器上，然后令 $x \gets x\bmod y$，这就退化成了**辗转相除**，每轮 $O(1)$，总共 $O(\log n)$ 轮。

一轮的形式是：$x\gets x\bmod y$，$y\gets$ 旧的 $x$。一轮代表 $\lfloor x/y\rfloor$ 步。

边界要小心：
- 当 $y=1$ 时，从 $(x,1)$ 退到 $(1,1)$ 只需 $x-1$ 步（每次减 $1$），直接返回"已累计步数 $+$ $x-1$"。
- 当 $y=0$ 时说明 $x$ 是 $y$ 的倍数且 $y>1$（除到 $0$），此时 $\gcd(x,y)=y>1$，永远到不了 $(1,1)$，返回无穷大。

于是每个 $i$ 的计算是 $O(\log n)$，枚举 $n$ 个 $i$ 总共 $O(n\log n)\approx 2\times 10^7$，可以过。

最后，$n=1$ 时一开始就是 $(1,1)$，答案是 $0$，代码自然处理（$i=1$ 时 $\max=\min=1$，$y=1$ 分支返回 $0$）。

样例 $n=5$：枚举 $i=1..5$，$i=2$ 时 $(5,2)\to(3,2)\to(1,2)\to(1,1)$，$3$ 步，最小值 $3$，与样例输出一致，也与样例解释 $(1,1)\to(1,2)\to(3,2)\to(5,2)$ 吻合。

## 二、思维链：完整证明

**引理 1**：对任意 $x\ne y$，数对 $(x,y)$ 的"前驱"（即能一步走到它的数对）唯一：当 $x>y$ 时为 $(x-y,y)$，当 $y>x$ 时为 $(x,y-x)$；当 $x=y$ 时不存在前驱。

*证明*：一步操作只有两种形态：$(a,b)\to(a+b,b)$ 与 $(a,b)\to(a,a+b)$。

- 结果 $(x,y)$ 若由第一种操作得到，则 $b=y$ 且 $a+b=x$，即 $a=x-y$，要求 $x>y$。
- 结果 $(x,y)$ 若由第二种操作得到，则 $a=x$ 且 $a+b=y$，即 $b=y-x$，要求 $y>x$。

两种情形互斥，所以前驱至多一个；且当 $x>y$ 时 $(x-y,y)$ 确实合法（$x-y\ge 1$），当 $y>x$ 时同理；当 $x=y$ 时两种情形都不满足，故无前驱。证毕。

**引理 2**：从 $(1,1)$ 出发的合法操作序列与"互质数对构成的树"上的根到点路径一一对应；特别地，互质数对 $(x,y)$ 可达，且到达它的步数唯一，记为 $D(x,y)$。

*证明*：由引理 1，每个 $x\ne y$ 的数对至多有一个前驱，故从 $(1,1)$ 出发到达某个数对的路径至多一条。反过来，对任意 $\gcd(x,y)=1$ 的数对，用更相减损术反复把大数减小数，$(x+y)$ 的值严格下降，最终必然到达 $(\gcd(x,y),\gcd(x,y))=(1,1)$；把这条反向链倒过来就是一条从 $(1,1)$ 出发的合法正向路径（每一步都是 $(a,b)\to(a+b,b)$ 或 $(a,b)\to(a,a+b)$ 的形式）。

因此可达当且仅当互质，且路径唯一，步数 $D(x,y)$ 良定义。同时 $\gcd$ 在操作下不变（$\gcd(a+b,b)=\gcd(a,b)$，$\gcd(a,a+b)=\gcd(a,b)$），故从 $\gcd=1$ 出发只能到达互质数对，两者一致。证毕。

**引理 3**：若 $x>y$，则 $D(x,y)=D(x-y,y)+1$；若 $y>x$，则 $D(x,y)=D(x,y-x)+1$；若 $x=y$，则仅当 $x=y=1$ 时可达，且 $D(1,1)=0$。

*证明*：由引理 1，$(x,y)$ 的前驱唯一且为 $(x-y,y)$（$x>y$ 时），任何到达 $(x,y)$ 的正向路径的最后一步都来自 $(x-y,y)$，故 $D(x,y)=D(x-y,y)+1$。$y>x$ 的情形对称。$x=y$ 时无前驱（引理 1），故只有 $x=y=1$（起点本身）可达，且无需操作，$D(1,1)=0$。证毕。

**引理 4**：$\gcd(x,y)>1$ 时 $(x,y)$ 不可达。

*证明*：由引理 2 的证明，$(x,y)$ 可达当且仅当 $\gcd(x,y)=1$。证毕。

**引理 5**：存在最优解，使得终点数对为 $(n,i)$，其中 $1\le i\le n$。

*证明*：任意方案的终点是一个至少有一个分量为 $n$ 的数对，记为 $(n,i)$ 或 $(i,n)$；由对称性 $D(x,y)=D(y,x)$（引理 3 的递推对称），二者步数相同，故只需考虑 $(n,i)$。

若 $i>n$，由引理 3，$(n,i)$ 的前驱为 $(n,i-n)$（因 $i>n$），故 $D(n,i)=D(n,i-n)+1>D(n,i-n)$。反复减去 $n$，令 $r$ 为 $i$ 除以 $n$ 的余数（$1\le r\le n$，因 $\gcd(n,i)=1$ 保证 $r\ne 0$，除非 $n=1$），有 $D(n,i)=D(n,r)+q$（$q\ge 1$），故 $D(n,i)>D(n,r)$ 且 $r\le n$。

因此把 $i>n$ 换成 $r\le n$ 不会变差，最优解必可取 $1\le i\le n$。证毕。

**引理 6**：用"整除加速"的更相减损术计算出的步数等于 $D(x,y)$。

*证明*：设当前 $(x,y)$ 满足 $x>y>0$，记 $q=\lfloor x/y\rfloor$、$r=x\bmod y$。

- 若 $r>0$：连续执行 $q$ 次"减去 $y$"后得到 $(r,y)$，期间每一步都是合法的反向移动（由引理 3），共 $q$ 步。所以 $D(x,y)=q+D(r,y)$。由于 $r<y$，交换后变为 $D(y,r)$，与代码中 `tot+=x/y; x=y; y=r;` 的迭代完全对应。
- 若 $r=0$：连续减去 $y$ 共 $q$ 次后到达 $(0,y)$ 之前的最后一格是 $(y,y)$，而 $(y,y)$ 在 $y>1$ 时不可达（引理 3、4），故 $D(x,y)=\infty$；代码在 $y=0$ 时返回无穷大，一致。
- 边界 $y=1$：$(x,1)$ 的前驱为 $(x-1,1)$，共 $x-1$ 步回到 $(1,1)$，故 $D(x,1)=x-1$，代码返回"已累计 $+$ $x-1$"一致。

由于每轮迭代都严格对应引理 3 的一整段递推，且终止条件（三类边界）都被正确处理，累加得到的总步数恰为 $D(x,y)$。证毕。

**定理**：算法输出的答案是最少操作次数。

*证明*：由引理 5，最优解的终点可取为 $(n,i)$，$1\le i\le n$；由引理 6，算法对每个这样的 $i$ 精确算出 $D(n,i)$；由引理 2、4，互质的 $i$ 可达、其余为无穷。对所有 $i$ 取最小即为全局最优。证毕。

## 三、模式总结（按实际思考顺序）

1. **正向状态太多 ⇒ 反向思考** — 状态是 $(a,b)$，有 $O(n^2)$ 个；反过来"找前驱"只有一步。
2. **发现前驱唯一 ⇒ 路径唯一** — 每个数对至多一个前驱，所以"最少步数"退化为"唯一路径的长度"，不需要最短路。
3. **更相减损术（减法版欧几里得）** — 反向移动就是"大数减小数"，终点由 $\gcd$ 决定。
4. **可达性判据：互质** — $\gcd>1$ 则永远退不到 $(1,1)$，返回无穷。
5. **用整除加速相减** — 一轮 $\lfloor x/y\rfloor$ 步合并成一次取模，把 $O(n)$ 步压成 $O(\log n)$ 轮。
6. **枚举范围收敛到 $1\le i\le n$** — $i>n$ 的前驱递推严格变差。
7. **边界三连** — $y=1$ 收尾、$y=0$ 判死、$n=1$ 答案 $0$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 目标数值 | `int`，$\le 10^6$ |
| $i$ | 终点数对的另一个分量 | `int`，$1\le i\le n$ |
| $(x,y)$ | 反向更相减损术的当前数对 | `i64` |
| `tot` | 已累计的反向步数 | `i64` |
| $D(x,y)$ | 从 $(1,1)$ 走到 $(x,y)$ 的步数（不可达为 $\infty$） | `i64` |
| `inf` | 不可达哨兵 | `i64`，$1\ll 60$ |
| `ans` | 最少操作次数 | `i64` |

### 算法步骤

1. 读入 $n$。
2. 初始化 `ans = inf`。
3. 枚举 $i = 1 \dots n$：计算 $D(n,i)$（因对称性取 $\max,\min$），用 `ans` 取最小。
4. 若 `ans == inf` 输出 `-1`（实际不会出现，见下文），否则输出 `ans`。

### `steps(x,y)` 的含义与流程

`steps(x,y)` 返回 $D(x,y)$（假定 $x\ge y\ge 1$，调用时用 `max`/`min` 保证）：

1. 若 $y=1$：返回 `tot + x - 1`（从 $(x,1)$ 连续减 $1$ 共 $x-1$ 步回到 $(1,1)$）。
2. 若 $y=0$：返回 `inf`（说明 $\gcd>1$，不可达）。
3. 否则：`tot += x/y`（这一轮代表 $\lfloor x/y\rfloor$ 步），令 $r=x\bmod y$，然后 $x\gets y$，$y\gets r$，继续。

### 复杂度

- 时间复杂度：$O(n\log n)$。枚举 $n$ 个 $i$，每个 $i$ 的辗转相除轮数为 $O(\log n)$。
- 空间复杂度：$O(1)$。

### 验证状态

- 标程 `P2090.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `5` 输出 `3`，与官方一致（与样例解释的 $(1,1)\to(1,2)\to(3,2)\to(5,2)$ 吻合）。
- 编写暴力 `P2090_brute.cpp`（朴素逐步相减，统计回到 $(1,1)$ 的步数，非互质返回 `inf`）与对拍脚本 `P2090_check.py`，在 $n\le 120$ 的随机数据上对拍 **400 组全部通过**。
- 注：本题 $i=1$ 恒可达（$D(n,1)=n-1$），故答案一定有限，`ans==inf` 的分支实际不会触发。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2090 数字对
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr i64 inf{1LL<<60};

int n;

i64 steps(i64 x,i64 y)
{
	// 反向还原：x>=y 时前驱唯一为 (x-y,y)，用欧几里得整除加速
	i64 tot=0;
	while(true)
	{
		if(y==1)
			return tot+x-1;      // (x,1) 连续减 1 共 x-1 步
		if(y==0)
			return inf;          // gcd>1，永远到不了 (1,1)
		tot+=x/y;
		i64 r=x%y;
		x=y;
		y=r;
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	i64 ans=inf;
	for(int i=1;i<=n;++i)
		ans=min(ans,steps(max((i64)n,(i64)i),min((i64)n,(i64)i)));
	if(ans==inf)
		cout<<-1<<'\n';
	else
		cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `steps` 中 `tot+=x/y; x=y; y=r;` 这一行是本题的核心：用一次取模代替 $\lfloor x/y\rfloor$ 次相减，把单次计算从 $O(n)$ 压到 $O(\log n)$。
- `y==1` 与 `y==0` 两个边界必须放在取模之前判断，否则会在 $y=1$ 时错误地继续除法、或漏掉"除到 $0$ 说明 $\gcd>1$"的信号。
- 枚举时用 `max`/`min` 传入，依赖 $D(x,y)=D(y,x)$ 的对称性（也可理解为把"另一个数"当作较小者处理）。
- `i64` 存储步数：虽然答案不超过 $n-1\le 10^6$，但中间量与哨兵用 `long long` 更统一；哨兵取 $1\ll 60$，与"答案上界 $10^6$"相差极大，不会误判。
