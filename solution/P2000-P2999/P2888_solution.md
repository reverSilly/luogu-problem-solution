# P2888 [USACO07NOV] Cow Hurdles S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 个站台（$N\le300$）、$M$ 条单向路径（$M\le2.5\times10^4$），第 $i$ 条 $S_i\to E_i$ 上最高的栏高 $H_i$（$1\le H_i\le10^6$）。一条路径的"代价"不是边权之和，而是**路径上最高栏的高度**（最大边权）。$T$ 个询问（$T\le4\times10^4$），每个给 $A,B$，求 $A\to B$ 所有路径中"最高栏高度"的**最小值**；不可达输出 `-1`。

这就是经典的**瓶颈路（minimax path / bottleneck shortest path）**：把最短路里的"边权求和"换成"边权取 max"，再对路径取 min。

**口径说明（题意歧义处理）。** 题面没明说 $A=B$ 怎么办。我取最自然的解读：奶牛已在 $B$，无需移动、不跨任何栏，代价为 $0$。代码里 `d[i][i]=0` 正是这个口径。依据：栏高 $\ge1$，空路径没有栏，$\max$ 取 $0$ 合理；且这是瓶颈路问题的标准约定。

**第一步：识别"换了代数"的最短路。** 普通最短路：路径代价 $=\sum w$，松弛 `d[i][j]=min(d[i][j], d[i][k]+d[k][j])`。本题：路径代价 $=\max w$，松弛应是 `d[i][j]=min(d[i][j], max(d[i][k], d[k][j]))`。结构完全一样，只是把加法换成取 max。问题是：**Floyd 的正确性证明依赖加法吗？换成 max 还成立吗？** 这需要验证（引理 2、3），不能想当然。

**第二步：为什么选 Floyd 而不是逐询问 Dijkstra。** 看数据范围说话：

- 逐询问跑一次瓶颈 Dijkstra：单次 $O(M\log N)\approx2.5\times10^4\times8\approx2\times10^5$，$T=4\times10^4$ 个询问就是 $8\times10^9$，**超时**。
- $N=300$ 极小，$T$ 极大 ⇒ **一次性全源预处理**最划算。Floyd $O(N^3)=300^3=2.7\times10^7$，之后每个询问 $O(1)$。总量 $2.7\times10^7+4\times10^4$，轻松通过。

"小 $N$、多询问"是 Floyd 的标志性场景。标签也写着"Floyd 算法"。

**第三步：验证 max 版 Floyd 真的对。** 普通 Floyd 的核心是"经过中转点 $k$ 的最优路 $=$ 两段最优路拼接"。对求和，这显然（$\min$ 对 $+$ 可分配）。对 max，要确认两件事：

1. **拼接代价 $=\max$ 两段代价**：一条路的最高栏 $=$ 前半最高栏与后半最高栏的较大者。✓（max 的定义）
2. **$\min$ 对 $\max$ 可分配**：$\min_{P_1,P_2}\max(c(P_1),c(P_2))=\max(\min_{P_1}c(P_1),\min_{P_2}c(P_2))$。即"两段各自取最优再拼"就是"拼接后的最优"。这需要证明（引理 2），它成立的关键是 max 对每个参数单调。

还要处理"路径含环"：瓶颈路里**删环不会让最高栏变高**（删边只会让 max 不增），所以最优游走 $=$ 最优简单路径，Floyd 允许游走也不影响答案（引理 1）。

**第四步：初始化的三个坑。**

1. **全局数组默认 $0$ 不是 INF！** `d[i][j]` 表示"不可达"必须是 INF，若留 $0$ 会被当成"零代价可达"，全错。必须 `fill_n(&d[0][0],mxn*mxn,inf)`。这是本题最致命的陷阱。
2. **对角线 `d[i][i]=0`**：对应 $A=B$ 口径。
3. **重边取 min**：两条 $u\to v$ 栏高不同，`d[u][v]=min(d[u][v],w)`，留矮的那条。

INF 取 `1145141919`（$>10^6$ 的最大栏高），输出时 `d==inf` 判不可达。

**第五步：原地更新为什么安全。** Floyd 第 $k$ 轮用 `d[i][k]`、`d[k][j]` 更新 `d[i][j]`。会不会 `d[i][k]` 在本轮已被改过？不会：`d[i][k]=min(d[i][k],max(d[i][k],d[k][k]))=min(d[i][k],max(d[i][k],0))=d[i][k]`（因 `d[k][k]=0` 且所有 `d>=0`）。同理 `d[k][j]` 不变。所以"枢轴行列"在第 $k$ 轮恒定，原地滚动安全（引理 5）。

**手造数据核对（题面无样例）。**

第一组，$N=3$，边 $1\to2(5),2\to3(3),1\to3(10)$，询问 $1\to3,1\to2,3\to1,2\to2$：

```
5
5
-1
0
```

$1\to3$：直达最高栏 $10$，绕 $2$ 是 $\max(5,3)=5$，取 $5$；$3\to1$ 不可达 $-1$；$2\to2$ 为 $0$。

第二组，"长而矮胜短而高"：$N=4$，边 $1\to2(100),2\to4(100),1\to3(5),3\to4(5)$，询问 $1\to4$：经 $2$ 瓶颈 $100$，经 $3$ 瓶颈 $5$，答案 $5$。验证瓶颈路不是边数最少。

第三组，重边：$N=2$，边 $1\to2(7),1\to2(3)$，询问 $1\to2$：取 $\min=3$。

## 二、思维链：完整证明

**记号。** 点 $0\le u<N$（0-based）。边权 $w\ge1$。游走 $P$ 的代价 $c(P)=\max_{e\in P}w_e$（空路径 $c=0$）。$D_k[i][j]=$ 所有"内部点 $\subseteq\{0,\dots,k-1\}$"的 $i\to j$ 游走的最小代价（不可达为 $\infty$）。最终 $d[i][j]=D_N[i][j]$。$\mathrm{inf}=1145141919>10^6$。

---

### 引理 1（删环不增瓶颈，最优游走 $=$ 最优简单路径）

对任意 $i\to j$ 游走 $P$，存在简单路径 $P'$ 使 $c(P')\le c(P)$。故 $\min$ 代价在游走上取与在简单路径上取相等。

*证明*：若 $P$ 含环（某点重复出现），删去两个相同点之间的闭合段，得到更短的游走 $P''$，其边集是 $P$ 边集的子集，故 $c(P'')=\max_{e\in P''}w_e\le\max_{e\in P}w_e=c(P)$（子集的 max $\le$ 全集的 max）。反复删环直到无重复点，得简单路径 $P'$，$c(P')\le c(P)$。因此任何游走的最优代价都能被一条简单路径达到，两者 $\min$ 相等。证毕。

**用途**：Floyd 递推允许游走（拼接可能产生重复点），引理 1 保证这不改变最优值。

---

### 引理 2（$\min$ 对 $\max$ 的分配律）

设 $\mathcal A,\mathcal B$ 为非空有限实数集，则
$$\min_{a\in\mathcal A,\,b\in\mathcal B}\max(a,b)=\max\bigl(\min\mathcal A,\ \min\mathcal B\bigr).$$

*证明*：记 $\alpha=\min\mathcal A,\beta=\min\mathcal B$。

**$\ge$**：对任意 $a\in\mathcal A,b\in\mathcal B$，$a\ge\alpha,b\ge\beta$，故 $\max(a,b)\ge\max(\alpha,\beta)$（max 对每参数单调）。左边是对所有 $(a,b)$ 取 min，仍 $\ge\max(\alpha,\beta)$。

**$\le$**：取 $a^\*=\alpha\in\mathcal A,b^\*=\beta\in\mathcal B$（最小值可达），则 $\max(a^\*,b^\*)=\max(\alpha,\beta)$，左边 $\le$ 这个特定配对的值 $=\max(\alpha,\beta)$。

两向夹逼得等式。证毕。

**用途**：它保证"经过 $k$ 的最优拼接 $=$ 两段各自最优再取 max"，即 $\min_{P_1,P_2}\max(c(P_1),c(P_2))=\max(\min c(P_1),\min c(P_2))$。这是 max 版 Floyd 递推成立的代数核心。

---

### 引理 3（Floyd 不变量）

代码第 $k$ 轮（$k=0,\dots,N-1$）结束后，$d[i][j]=D_{k+1}[i][j]$，即内部点 $\subseteq\{0,\dots,k\}$ 的最小瓶颈。

*证明*：对 $k$ 归纳。

**基础 $k=-1$（初始化后）**：$d[i][j]=$ 直接边最小权（无内部点），$d[i][i]=0$（空路径），不可达 $\infty$。这正是 $D_0[i][j]$（内部点 $\subseteq\varnothing$）。✓

**归纳步**：设第 $k-1$ 轮后 $d=D_k$。第 $k$ 轮做 $d[i][j]\gets\min(d[i][j],\max(d[i][k],d[k][j]))$。考察 $D_{k+1}[i][j]$：内部点 $\subseteq\{0,\dots,k\}$ 的最优游走，按"是否以 $k$ 为内部点"分类：

- **不含 $k$**：内部点 $\subseteq\{0,\dots,k-1\}$，最优代价 $D_k[i][j]=d[i][j]$（旧值）。
- **含 $k$**：在 $k$ 处切成 $i\to k$ 与 $k\to j$ 两段（若多次经过 $k$，取首末次出现，中间 $k\to k$ 环由引理 1 删去不增代价）。两段内部点 $\subseteq\{0,\dots,k-1\}$，代价分别 $\ge D_k[i][k],D_k[k][j]$，且各自最优可达。拼接代价 $=\max$ 两段代价（max 定义），由引理 2，所有这类拼接的最小值 $=\max(D_k[i][k],D_k[k][j])=\max(d[i][k],d[k][j])$。

两类取 min：$D_{k+1}[i][j]=\min(D_k[i][j],\max(D_k[i][k],D_k[k][j]))$，恰是代码的更新式。由归纳假设旧 $d=D_k$，更新后 $d=D_{k+1}$。证毕。

---

### 引理 4（初始化正确）

`fill` 全 $\infty$、`d[i][i]=0`、每条边 `d[u][v]=min(d[u][v],w)` 后，$d=D_0$。

*证明*：$D_0[i][j]$ 是"无内部点"的 $i\to j$ 游走最小代价。$i\ne j$ 时只能是单条边 $i\to j$，代价 $=$ 该边权；多条重边取最小权；无边则 $\infty$。代码 `fill` 置 $\infty$、读边取 min，恰好实现。$i=j$ 时空路径代价 $0$（无栏），`d[i][i]=0` ✓。**关键**：若不 `fill`，全局默认 $0$ 会把所有"无边"误成"代价 $0$ 可达"，$D_0$ 全错——故 `fill` 是正确性前提，不是可选优化。证毕。

---

### 引理 5（原地滚动安全）

第 $k$ 轮中，`d[i][k]` 与 `d[k][j]` 保持不变，故用滚动数组原地更新等价于用独立的 $D_k$。

*证明*：第 $k$ 轮对任意 $i$，当 $j=k$ 时更新 `d[i][k]=min(d[i][k],max(d[i][k],d[k][k]))`。由 `d[k][k]=0`（初始 $0$，且每轮 `min(0,max(0,0))=0` 保持）及所有 $d\ge0$，$\max(d[i][k],0)=d[i][k]$，故 `d[i][k]=min(d[i][k],d[i][k])=d[i][k]` 不变。同理 $i=k$ 时 `d[k][j]=min(d[k][j],max(d[k][k],d[k][j]))=min(d[k][j],d[k][j])=d[k][j]` 不变。枢轴行列恒定，其余 `d[i][j]` 的更新用的都是未被本轮污染的值，等价于独立数组。证毕。

---

### 引理 6（输出与复杂度）

$d[a][b]=\infty\iff a\to b$ 不可达（输出 $-1$）；否则 $d[a][b]$ 即最小瓶颈。时间 $O(N^3+M+T)$，空间 $O(N^2)$。

*证明*：由引理 3，$d=D_N$ 是内部点 $\subseteq\{0,\dots,N-1\}$（即全部点）的最小瓶颈，由引理 1 等于简单路径最小瓶颈，正是题目所求。真实瓶颈 $\le\max w\le10^6<\mathrm{inf}$，故 $d=\mathrm{inf}\iff$ 无路径 $\iff$ 不可达，输出 $-1$ 正确；$a=b$ 时 $d=0$ 输出口径一致。

复杂度：`fill` $O(N^2)$，读边 $O(M)$，Floyd 三重循环 $O(N^3)$，回答 $T$ 个询问 $O(T)$。合计 $O(N^3+M+T)$。代入 $N=300$：$N^3=2.7\times10^7$，$M=2.5\times10^4,T=4\times10^4$，总约 $2.7\times10^7$。空间 `d` 为 $N^2=9\times10^4$ 个 `int`，$O(N^2)$。证毕。

---

### 定理

程序对每个询问输出 $A\to B$ 路径上最高栏高度的最小值（不可达 $-1$，$A=B$ 为 $0$），复杂度 $O(N^3+M+T)$。

*证明*：引理 4 保证初始化 $d=D_0$（`fill` 防 $0$ 陷阱）；引理 1 保证游走与简单路径同最优；引理 2 提供 $\min$-$\max$ 分配律；引理 3 用归纳证明 Floyd 不变量 $d=D_k$；引理 5 保证原地滚动安全；引理 6 串联得输出正确与复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 路径代价是"最大边权"而非"边权和"，识别为瓶颈路（minimax path）。
2. **discuss by category** — 小 $N=300$、多询问 $T=4\times10^4$：逐询问 Dijkstra $O(TM\log N)$ 超时，全源 Floyd $O(N^3)$ 划算。
3. **reduce to easier problem** — 把普通 Floyd 的 $(+,\min)$ 代数换成 $(\max,\min)$，结构不变。
4. **explore its property** — 验证换代数仍成立：拼接代价 $=\max$ 两段、$\min$ 对 $\max$ 可分配、删环不增瓶颈。
5. **classic problem solution** — Floyd 三重循环 `d[i][j]=min(d[i][j],max(d[i][k],d[k][j]))`，原地滚动（枢轴行列因 `d[k][k]=0` 恒定）。
6. **discuss by category** — 初始化三坑：`fill` INF（全局默认 $0$ 致命）、对角线 $0$、重边取 min；输出 `inf→-1`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,m,t` | 点数 $\le300$、边数、询问数 | `int` | 读入 |
| `mxn` | $305$ | `constexpr int` | 约束 $+5$ |
| `inf` | $1145141919$（$>10^6$） | `constexpr int` | 不可达哨兵 |
| `d[i][j]` | $i\to j$ 最小瓶颈 | `int[mxn][mxn]` | **先 `fill` inf**，`d[i][i]=0`，重边 min |
| `u,v,w` | 边的起点、终点、栏高 | `int` | 读入 `--u;--v` |
| `a,b` | 询问起终点 | `int` | 读入 `--a;--b` |

### 算法步骤

1. I/O 加速三行；读 $N,M,T$。
2. `fill_n(&d[0][0],mxn*mxn,inf)`；`for i: d[i][i]=0`。
3. 读每条边 `u,v,w`，`--u;--v`，`d[u][v]=min(d[u][v],w)`。
4. Floyd：`for k: for i: for j: d[i][j]=min(d[i][j],max(d[i][k],d[k][j]))`。
5. 每个询问读 `a,b`，`--a;--b`，输出 `d[a][b]==inf?-1:d[a][b]`。

### 复杂度

- 时间：$O(N^3+M+T)$，$N=300$ 时约 $2.7\times10^7$。
- 空间：$O(N^2)$，约 $9\times10^4$ 个 `int`。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造三组（瓶颈 $5$、不可达 $-1$、$A=B$ 为 $0$；长矮胜短高得 $5$；重边取 min 得 $3$；单点自询 $0$）全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2888 [USACO07NOV] Cow Hurdles S
// 瓶颈路（路径上最大边权的最小值）：把 Floyd 的 (+,min) 换成 (max,min)。
// d[i][j]=min(d[i][j],max(d[i][k],d[k][j]))。N<=300 ⇒ O(N^3)=2.7e7 全源预处理，T 个询问 O(1)。
// 陷阱：全局数组默认 0 不是 INF，必须 fill；d[i][i]=0（A==B 不用跨栏）。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{305},inf{1145141919};

int n,m,t,d[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>t;
	fill_n(&d[0][0],mxn*mxn,inf);
	for(int i=0;i<n;++i)
		d[i][i]=0;
	for(int i=0,u,v,w;i<m;++i)
	{
		cin>>u>>v>>w;--u;--v;
		d[u][v]=min(d[u][v],w);	// 重边取最小栏高
	}
	for(int k=0;k<n;++k)
		for(int i=0;i<n;++i)
			for(int j=0;j<n;++j)
				d[i][j]=min(d[i][j],max(d[i][k],d[k][j]));
	for(int i=0,a,b;i<t;++i)
	{
		cin>>a>>b;--a;--b;
		cout<<(d[a][b]==inf?-1:d[a][b])<<'\n';
	}
	return 0;
}
```

### 代码说明

- **`fill_n(&d[0][0],mxn*mxn,inf)` 是命门**：全局 `int` 默认 $0$，不 `fill` 会把所有不可达误成零代价可达，答案全错。`&d[0][0]` 取二维数组首地址，`mxn*mxn` 铺满整个静态数组。
- **`(max,min) 替代 (+,min)`**：松弛式 `max(d[i][k],d[k][j])` 算"经 $k$ 拼接的瓶颈"，外层 `min` 取最优。引理 2 的分配律保证这与求和版 Floyd 同样正确。
- **`d[i][i]=0`**：$A=B$ 口径（不跨栏）；同时它让第 $k$ 轮枢轴行列 `d[i][k]`、`d[k][j]` 恒定，原地滚动安全（引理 5）。
- **重边 `min`**：同向多条路留最矮栏，符合"路径可选边"语义。
- **`inf=1145141919`**：$>10^6$ 最大栏高，`d==inf` 当且仅当不可达；`max`/`min` 运算不会溢出 `int`（无加法）。
- 0-based 读入输出，`'\n'` 换行，三重循环 $k$ 在最外层（Floyd 标准顺序，保证不变量）。
