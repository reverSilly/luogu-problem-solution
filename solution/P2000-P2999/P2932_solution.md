# P2932 [USACO09JAN] Earthquake Damage G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 农场是 $P$ 个牧场（$1\le P\le3\times10^4$）、$C$ 条无向牛道（$1\le C\le10^5$，**允许自环与重边**）构成的图，谷仓在牧场 $1$。地震损坏了一些牧场使其不可通行，牛道都没坏。$N$ 头牛依次报告：牧场 $\textit{report}_j$（$2\le\textit{report}_j\le P$）**未受损**，但那里的牛**找不到一条不经过受损牧场的路回到谷仓**。在所有报告都成立的前提下，求**无法回到谷仓的牧场数量的最小值**（受损的牧场本身也算"无法回到"）。

**口径说明（题意有歧义处）。** 受损集合 $D$ 是未知的，我们要在"与所有报告相容"的 $D$ 里取使不可达牧场数最小的那个。报告点本身**一定未受损**（题面明说），所以不能把报告点当成受损点。谷仓默认未受损；但若谷仓与某报告点直接相邻，会逼出"谷仓必须受损"的矛盾，此时所有牧场都回不去，答案为 $P$（下面引理会覆盖这一退化情形）。"无法回到谷仓的牧场"= 受损牧场 + 未受损但与谷仓失联的牧场。

**第一步：把报告翻译成图论约束。** 报告 $r$ 未受损却回不去，意思是：在删掉受损点后的图 $G-D$ 里，$r$ 与谷仓**不连通**。等价地，$G$ 中每条 $r\to1$ 的路径都至少经过一个受损点。

**第二步：先试一个"想当然"的做法，然后碰壁。** 最直觉的想法：把报告点当成障碍删掉，从谷仓 BFS，数不到的就是答案。**这是错的。** 反例：$P=3$，牛道 $1-2$、$2-3$，报告 $3$。删掉报告点 $3$ 后谷仓能到 $\{1,2\}$，于是"答案 $=3-2=1$"。但实际上 $3$ 未受损，要让它回不去，唯一能拆的是它到谷仓的必经点 $2$——必须损坏 $2$。这样不可达的是 $\{2,3\}$，答案是 $2$，不是 $1$。**漏算了被迫受损的邻居 $2$。**

**第三步： dissect 失败，找到真正的不变量。** 反例暴露的本质：报告点 $r$ 未受损，那么它的**每个邻点** $u$ 都"脱不了干系"——若 $u$ 未受损且能回谷仓，则 $r\to u\to1$ 全程未受损，$r$ 就能回去，与报告矛盾。所以 $u$ 要么受损、要么也回不去，**无论哪种都计入答案**。于是：

> 报告点 $r$ 自身、以及 $r$ 的所有邻点，全都无法回到谷仓。

把这条用到全体报告点：记 $R$ 为报告点集，$N(R)$ 为它们的全部邻点，则 $R\cup N(R)$ 里的牧场**必然**都在答案里。剩下能"争取回来"的只有 $A=V\setminus(R\cup N(R))$ 中的点。

**第四步：归约成连通块。** 能回到谷仓的牧场集合 $S$ 必须满足：含谷仓、在 $G$ 中连通、且 $S\subseteq A$（因为 $R\cup N(R)$ 全被排除）。要让不可达数 $P-|S|$ 最小，就要让 $|S|$ 最大——而 $A$ 中含谷仓的最大连通子集就是 **$G[A]$ 里谷仓所在的连通块** $C^\*$。于是

$$\text{答案}=P-|C^\*|,\qquad C^\*=\text{删去 }R\cup N(R)\text{ 后谷仓的连通块}.$$

**第五步：实现上只需标记邻点。** 把 $N(R)$（报告点的邻点）标记为受损 `bad`，从谷仓 BFS 跳过 `bad`。报告点 $R$ 不用显式删：它们的邻点全被标 `bad` 了，自然成了孤点，BFS 到不了（谷仓编号 $1$ 不是报告点）。数到的可达数就是 $|C^\*|$，答案 $P-\textit{reached}$。若谷仓本身被标 `bad`（与报告点相邻），可达数 $0$，答案 $P$，与口径一致。

**手造数据核对。**

| 图 | 报告 | `bad`=$N(R)$ | 谷仓可达 | 答案 | 说明 |
|---|---|---|---|---|---|
| $1-2,2-3,3-4$ | $3,4$ | $\{2,4,3\}$ | $\{1\}$ | $3$ | 即 Hint"牧场 2 受损，2,3,4 回不去" |
| $1-2,1-3,2-4,3-4,4-5$ | $5$ | $\{4\}$ | $\{1,2,3\}$ | $2$ | 拆 $4$，$5$ 失联 |
| $1-2,2-3$ | $3$ | $\{2\}$ | $\{1\}$ | $2$ | 第二步的反例，正确值 $2$ |
| $1-2,1-3$ | $2$ | $\{1\}$ | $\varnothing$ | $3$ | 谷仓被迫受损，全不可达 |
| $1-2,2-2,2-3,3-3$ | $3$ | $\{2,3\}$ | $\{1\}$ | $2$ | 自环重边无害 |

第一组与题面 Hint 完全吻合（受损 $2$，导致 $2,3,4$ 无法返回，共 $3$ 个）。

## 二、思维链：完整证明

**记号。** 图 $G=(V,E)$，$|V|=P$，谷仓为顶点 $1$（代码 0-based 记 $0$）。受损集合 $D\subseteq V$。报告集 $R=\{r_1,\dots,r_N\}\subseteq V\setminus\{1\}$。$N(R)=\bigcup_{r\in R}N(r)$，$N(r)$ 为 $r$ 的邻点集（含自环时的 $r$ 自身）。$A=V\setminus(R\cup N(R))$。$G[X]$ 表示顶点集 $X$ 的诱导子图。$\text{Reach}(D)$ 为 $G-D$ 中谷仓所在连通块（若谷仓 $\in D$ 则定义为 $\varnothing$）。

**相容性定义。** $D$ 与报告相容 $\iff$ (i) $R\cap D=\varnothing$（报告点未受损）；(ii) 对每个 $r\in R$，$r$ 与谷仓在 $G-D$ 中不连通。

---

### 引理 1（不可达数 = $P-|\text{Reach}(D)|$）

对任意受损集合 $D$，无法回到谷仓的牧场数等于 $P-|\text{Reach}(D)|$。

*证明*：一个牧场 $u$ 能回到谷仓，当且仅当 $u$ 未受损（$u\notin D$）且 $u$ 与谷仓在 $G-D$ 中连通——即 $u\in\text{Reach}(D)$（谷仓受损时 $\text{Reach}=\varnothing$，没有牧场能回到一个不可通行的谷仓，符合"受损牧场也算不可达"）。故可达集恰为 $\text{Reach}(D)$，不可达集为 $V\setminus\text{Reach}(D)$，大小 $P-|\text{Reach}(D)|$。证毕。

由引理 1，**最小化不可达数 $\iff$ 最大化 $|\text{Reach}(D)|$**（$D$ 取遍相容集合）。

---

### 引理 2（报告点及其邻点必不可达）

设 $D$ 相容。则对每个 $r\in R$：$r\notin\text{Reach}(D)$，且对 $r$ 的每个邻点 $u\in N(r)$ 有 $u\notin\text{Reach}(D)$。从而 $\text{Reach}(D)\subseteq A$。

*证明*：
- $r\notin\text{Reach}(D)$：若 $r\in\text{Reach}(D)$，则 $r$ 未受损且与谷仓连通，违反相容性 (ii)。
- 设 $u\in N(r)$（即边 $ru\in E$）。反设 $u\in\text{Reach}(D)$，则 $u$ 未受损且与谷仓在 $G-D$ 中连通。又 $r$ 未受损（相容性 (i)），边 $ru$ 两端都未受损，故该边在 $G-D$ 中存在，于是 $r$ 经 $u$ 与谷仓连通，$r\in\text{Reach}(D)$，与上一矛盾。故 $u\notin\text{Reach}(D)$。

综上 $R\cup N(R)$ 与 $\text{Reach}(D)$ 不交，即 $\text{Reach}(D)\subseteq V\setminus(R\cup N(R))=A$。证毕。

**这条引理是第二步反例的"修正"**： naive 做法只排除 $R$，漏掉了 $N(R)$；引理 2 证明 $N(R)$ 同样必须排除。

---

### 引理 3（可达集的上界）

设 $D$ 相容且 $\text{Reach}(D)\ne\varnothing$。则 $\text{Reach}(D)\subseteq C^\*$，其中 $C^\*$ 是 $G[A]$ 中谷仓所在连通块。故 $|\text{Reach}(D)|\le|C^\*|$。

*证明*：$\text{Reach}(D)$ 在 $G-D$ 中连通且含谷仓。由引理 2，$\text{Reach}(D)\subseteq A$，特别地 $\text{Reach}(D)\cap R=\varnothing$。一个顶点集 $S\subseteq A$ 在 $G-D$ 中的诱导边，两端都在 $S\subseteq A$，故也是 $G[A]$ 的边；因此 $\text{Reach}(D)$ 在 $G[A]$ 中仍连通、仍含谷仓。含谷仓的连通子集必包含于谷仓所在连通块，故 $\text{Reach}(D)\subseteq C^\*$，取基数即得。证毕。

---

### 引理 4（上界可达：构造最优受损集）

令 $D^\*=V\setminus(C^\*\cup R)$。则 $D^\*$ 相容，且 $\text{Reach}(D^\*)=C^\*$，不可达数 $=P-|C^\*|$。

*证明*：
**相容性 (i)**：$D^\*\cap R=\varnothing$（构造里显式并上了 $R$），报告点未受损 ✓。谷仓 $\in C^\*$（$C^\*$ 是谷仓连通块；若谷仓 $\notin A$ 则 $C^\*=\varnothing$，见下），故谷仓 $\notin D^\*$。

**$\text{Reach}(D^\*)=C^\*$**：$G-D^\*$ 的顶点集为 $C^\*\cup R$。
- 先证 $C^\*$ 中任一点到谷仓在 $G-D^\*$ 内连通：$C^\*$ 在 $G[A]$ 中连通，$A\subseteq C^\*\cup R$ 中的 $C^\*$ 部分，且 $C^\*$ 内部的边都在 $G-D^\*$ 中（两端 $\in C^\*$，未删），故 $C^\*\subseteq\text{Reach}(D^\*)$。
- 再证没有 $R$ 中的点能连到谷仓：关键观察——**$C^\*$ 与 $R$ 之间没有边**。因为 $C^\*\subseteq A=V\setminus(R\cup N(R))$，故 $C^\*\cap N(R)=\varnothing$，即 $C^\*$ 中没有任何点是某报告点的邻点，等价地 $R$ 中没有任何点与 $C^\*$ 相邻。于是从 $R$ 出发在 $G-D^\*$ 中走，只能停留在 $R$ 内部（$R$ 点的邻点要么在 $R$、要么在 $N(R)\setminus R\subseteq D^\*$ 被删），永远跨不进 $C^\*$。故 $R\cap\text{Reach}(D^\*)=\varnothing$。
- 合起来 $\text{Reach}(D^\*)=C^\*$。

**相容性 (ii)**：每个 $r\in R$ 不在 $\text{Reach}(D^\*)=C^\*$ 中（$R\cap C^\*=\varnothing$），即与谷仓不连通 ✓。

由引理 1，不可达数 $=P-|C^\*|$。退化情形：若谷仓 $\in N(R)$（与某报告点相邻），则谷仓 $\notin A$，$C^\*=\varnothing$，$D^\*=V\setminus R$ 含谷仓，$\text{Reach}=\varnothing$，不可达数 $=P$，与"谷仓被迫受损"一致。证毕。

---

### 引理 5（BFS 实现恰好算出 $|C^\*|$）

把 $\texttt{bad}[v]$ 对全体 $v\in N(R)$ 置真，从谷仓出发在"跳过 `bad`"的图上 BFS，得到的可达点数 $\textit{reached}=|C^\*|$。

*证明*：BFS  traverses 的图是 $G-\texttt{bad}=G-N(R)$，其顶点集 $V\setminus N(R)=A\cup(R\setminus N(R))$（比 $A$ 多了"不是任何报告点邻点"的那些报告点）。
- 谷仓可达块：$A$ 中谷仓连通块即 $C^\*$，其内部边不含 $N(R)$ 端点（$C^\*\subseteq A$ 与 $N(R)$ 不交），故在 $G-N(R)$ 中完整保留，$C^\*\subseteq\text{Reach}_{\text{BFS}}$。
- 多出来的报告点 $r\in R\setminus N(R)$：$r$ 的所有邻点都在 $N(R)=\texttt{bad}$ 中被删，故 $r$ 在 $G-N(R)$ 中是孤点；$r\ne$ 谷仓（报告 $\ge2$），不可能并入谷仓块。
- $N(R)$ 中的点全被跳过。

故 $\text{Reach}_{\text{BFS}}=C^\*$，$\textit{reached}=|C^\*|$。若谷仓 $\in N(R)$（`bad[0]` 真），BFS 不启动，$\textit{reached}=0=|C^\*|$（此时 $C^\*=\varnothing$）。证毕。

---

### 引理 6（复杂度与鲁棒性）

时间 $O(P+C)$，空间 $O(P+C)$；自环、重边不影响正确性。

*证明*：建邻接表 $O(C)$；标记 `bad` 遍历每个报告点的邻接表，总度数 $\le2C$，$O(C)$；BFS 每点每边至多访问常数次，$O(P+C)$。自环 $rr$：把 $r$ 自己标 `bad`，但 $r$ 本就因邻点全 `bad` 而不可达，多标无害；重边：邻接表里重复出现，`bad` 重复置真、BFS 用 `vis` 去重，均无副作用。证毕。

---

### 定理

最小不可达牧场数 $=P-|C^\*|$，其中 $C^\*$ 是删去 $R\cup N(R)$ 后谷仓的连通块；程序用"标记 $N(R)$ 为 `bad` + 谷仓 BFS + $P-\textit{reached}$"在 $O(P+C)$ 内算出它。

*证明*：引理 1 把目标转成最大化谷仓连通块；引理 2、3 给出上界 $|C^\*|$；引理 4 构造达到上界的相容受损集，证明最小值恰为 $P-|C^\*|$；引理 5 证明 BFS 实现算出的 $\textit{reached}=|C^\*|$；引理 6 给出复杂度与边界鲁棒性。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 报告"未受损却回不去"= 图论约束：$G-D$ 中报告点与谷仓不连通，$D$ 未知待最小化。
2. **consider easier version** — 先试"只把报告点当障碍 BFS"，构造反例 $1-2-3$ 报告 $3$（naive 给 $1$，真值 $2$）发现漏算。
3. **explore its property** —  dissect 反例得关键引理：报告点未受损 ⇒ 它的每个邻点要么受损要么失联，总之全计入答案。
4. **reduce to easier problem** — 最小化不可达 $\iff$ 最大化谷仓连通块 $\iff$ 在删去 $R\cup N(R)$ 的诱导子图上求谷仓连通块 $C^\*$。
5. **classic problem solution** — 标记 $N(R)$ 为障碍后一次 BFS 求连通块，$O(P+C)$；报告点自动成孤点无需显式删。
6. **discuss by category** — 谷仓与报告点相邻 ⇒ 谷仓必受损 ⇒ 答案 $P$；自环、重边无害。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $P,C,N$ | 牧场数、牛道数、报告数 | `int p,c,n` | 读入 |
| `graph[u]` | 牧场 $u$ 的邻接表（无向，存两次） | `vector<int>[mxn]` | 读入建表，0-based |
| `bad[v]` | $v$ 是否被强制封锁（$v\in N(R)$） | `bool[mxn]` | 全局默认 `false`；遍历报告点邻接表置真 |
| `vis[v]` | BFS 是否访问过 $v$ | `bool[mxn]` | 全局默认 `false` |
| `Q` | BFS 队列 | `queue<int>` | 谷仓未 `bad` 时入队 |
| `reached` | 谷仓可达牧场数 $=|C^\*|$ | `int` | 初值 $0$，每出队一个点 $+1$ |
| $R$ | 报告点集 | 读入的 `r` | $r\ge2$，`--r` 转 0-based |
| $A$ | $V\setminus(R\cup N(R))$，可争取回来的点集 | 概念量 | 不需显式存 |

### 算法步骤

1. I/O 加速三行。
2. 读 $P,C,N$；读 $C$ 条边 `u,v`（`--u;--v`），双向加入 `graph`。
3. 读 $N$ 个报告 `r`（`--r`）；对 `graph[r]` 中每个邻点 `v` 置 `bad[v]=true`。
4. 若 `!bad[0]`：`vis[0]=true`，谷仓入队。
5. BFS：出队 `u` 则 `++reached`；对 `graph[u]` 中未 `bad` 未 `vis` 的 `v` 标记并入队。
6. 输出 `p-reached` 与 `'\n'`。

### 复杂度

- 时间：$O(P+C)$。
- 空间：$O(P+C)$（邻接表）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Hint 型数据（$1-2-3-4$ 报告 $3,4$）输出 $3$ 吻合；另造"反例修正""谷仓被迫受损""自环重边"等 $5$ 组手算数据全对。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2932 [USACO09JAN] Earthquake Damage G
// 报告点 r 未受损却回不到谷仓 ⇒ r 的每个邻点要么受损要么也回不去，总之都计入答案
// 把全体报告点的邻点标记为受损(bad)，从谷仓 BFS，答案 = P - 可达数
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{30005};

int p,c,n;
vector<int>graph[mxn];
bool bad[mxn],vis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>p>>c>>n;
	for(int i=0,u,v;i<c;++i)
	{
		cin>>u>>v;--u;--v;
		graph[u].push_back(v);
		graph[v].push_back(u);
	}
	for(int i=0,r;i<n;++i)
	{
		cin>>r;--r;
		for(int v:graph[r])
			bad[v]=true;	// 报告点自身未受损，但其邻点必须被封锁
	}
	queue<int>Q;
	int reached=0;
	if(!bad[0])	// 谷仓若与报告点相邻则必受损，可达数为 0
	{
		vis[0]=true;
		Q.push(0);
	}
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		++reached;
		for(int v:graph[u])
			if(!bad[v]&&!vis[v])
			{
				vis[v]=true;
				Q.push(v);
			}
	}
	cout<<p-reached<<'\n';
	return 0;
}
```

### 代码说明

- **全题的灵魂是 `for(int v:graph[r]) bad[v]=true;`**：封锁的是报告点的**邻点**，不是报告点自己。漏掉这一步就退化成第二步被反例否掉的 naive 做法。
- 报告点不需要显式标 `bad`：它的邻点全被封锁后自然成孤点，BFS 到不了（引理 5）。即便自环把报告点自己标了 `bad` 也无害。
- `if(!bad[0])` 处理谷仓被迫受损的退化情形：此时 `reached=0`，答案 $P$。
- `bad`、`vis` 靠全局零初始化，`false` 恰是正确初值；本题单测无需清空。
- 答案 `p-reached` 把受损点与失联点一并计入（引理 1），不要再额外加报告点数——它们已经不在 `reached` 里了。
