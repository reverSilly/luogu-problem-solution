# P2031 脑力达人之分割字串 — 题解

## 一、解题过程：人类思考叙事

题意：给一个主串 $s$ 和一个字典，把 $s$ 切成若干段，**每一段内部至少包含一个字典词作为子串**，求最多能切几段。切不了就输出 $0$。

先把题目翻译成人话：比如 $s=$ `asdsd`，字典 $\{as, sd, ds\}$。切成 `as|ds|d`？不行，`d` 里没有字典词。切 `as|dsd`？两段都合法（`as` 含 `as`，`dsd` 含 `ds`），答案 2。再切 `asd|sd` 也是 2 段。答案就是 2。

先想想最朴素的 DP 长什么样。设 $f[i]$ 表示"前 $i$ 个字符最多能切几段"，则

$$f[i]=\max_{1\le j\le i,\ s[j..i]\ \text{合法}}\big(f[j-1]+1\big)$$

这是标准的"最后一段从哪来"的枚举。骨架有了，剩下的难点只有一个：**怎么快速判断 $s[j..i]$ 是否包含某个字典词**。

$n\le 300$，$N\le 500$。最直接的办法：对每个字典词 $A_k$，用朴素匹配找出它在 $s$ 中的所有出现位置 $[a,b]$，标记 `has[a][b]=true`。这样一共 $N\cdot n$ 次起点枚举，每次比较 $|A_k|$ 个字符，$500\times 300\times 300 = 4.5\times 10^7$，能过。

标记完之后，怎么从"某个词恰好占据 $[a,b]$"推出"区间 $[j,i]$ 包含这个词"？注意条件是 $j\le a$ 且 $b\le i$，也就是**左端点不超过词的起点、右端点不小于词的终点**。这正是一个二维前缀的"左上闭包"。

我一开始想用二维数组 `ok[l][r]` 表示"$s[l..r]$ 合法"，然后写了个从右往左、从左往右的扩散：`ok[l][r]=true` 时令 `ok[l-1][r]`、`ok[l][r-1]` 也为真。但很快发现这个扩散的**顺序**很微妙——`ok[l-1][r]` 和 `ok[l][r-1]` 的更新会互相依赖，很难保证一遍扫过去就填满整个闭包，容易出错。

换个角度想：**固定左端点 $j$，问"最早的合法右端点"是多少**。记作 $g[j]$ = 使得 $s[j..r]$ 含某个字典词的最小 $r$。因为"包含"是单调的（右端点越靠右，越容易包含），所以

$$s[j..i]\ \text{合法} \iff i \ge g[j]$$

这一下就把二维判断变成了一维阈值判断，而且转移也简单了：

$$f[i]=\max_{1\le j\le i,\ g[j]\le i}\big(f[j-1]+1\big)$$

$g[j]$ 怎么算？先把所有词的出现位置按起点归拢：对每个出现位置 $[a,b]$，记 `best[a] = min(b)`（同一起点只留最早的终点）。那么

$$g[j]=\min_{a\ge j}\ \text{best}[a]$$

也就是对 `best` 数组求**后缀最小值**即可。$O(n)$ 搞定。

这个"后缀最小值"的技巧很关键，因为它把"词出现在哪里"和"区间是否合法"之间的二维关系压成了一维阈值。

还有一个小坑：$f[j-1]$ 可能不可达（前面切不出来），这时不能拿它转移，需要用 $-1$ 之类的标记判掉。还有，题目要求"**每一段都**至少含一个词"，注意是"含"而不是"等于"——一段里可以有多余的字符，比如 `dsd` 含 `ds` 就算合法。

最后处理"输出 $0$"：如果连整个串都切不出来（$f[n]$ 不可达），输出 $0$。

样例验证：$s=$ `asdsd`，字典 `as, sd, ds`。
- `as` 出现在 $[1,2]$；`sd` 出现在 $[2,3]$ 和 $[4,5]$；`ds` 出现在 $[3,4]$。
- `best[1]=2, best[2]=3, best[3]=4, best[4]=5`。
- 后缀最小值：$g[1]=2, g[2]=3, g[3]=4, g[4]=5, g[5]=inf$。
- $f[0]=0$；$f[1]$：需要 $g[1]=2\le 1$，不成立，$f[1]=-1$；$f[2]$：$g[1]=2\le 2$ 成立，$f[2]=f[0]+1=1$；$f[3]$：$g[2]=3\le 3$ 成立且 $f[1]=-1$ 不可用，$g[1]=2\le3$ 成立，$f[3]=f[0]+1=1$；$f[4]$：$g[3]=4\le4$ 且 $f[2]=1$，得 $f[4]=2$；$f[5]$：$g[4]=5\le5$ 且 $f[3]=1$，得 $2$；还有 $g[3]=4\le5$ 且 $f[2]=1$ 也是 2。故 $f[5]=2$ ✓。

## 二、思维链：完整证明

**引理 1**（阈值化）：固定左端点 $j$，设 $g[j]$ 为使 $s[j..r]$ 包含某个字典词的最小 $r$（不存在则记为 $\infty$），则对任意 $r\ge j$，$s[j..r]$ 合法当且仅当 $r\ge g[j]$。

*证明*：由 $g[j]$ 的定义，存在某个词的出现位置 $[a,b]$ 满足 $j\le a<b\le g[j]$ 且 $b$ 是所有这类出现的终点中最小者。若 $r\ge g[j]$，则该词整体落在 $[j,r]$ 内，故 $s[j..r]$ 合法。反之若 $s[j..r]$ 合法，则其中存在某个词的出现位置 $[a,b]$ 满足 $j\le a<b\le r$，由 $g[j]\le b\le r$ 得 $g[j]\le r$，即 $r\ge g[j]$。两个方向都成立。证毕。

**引理 2**（后缀最小值）：设 $\text{best}[a]$ 为所有起点恰为 $a$ 的词出现位置中最小终点（不存在记 $\infty$），则 $g[j]=\min_{a\ge j}\text{best}[a]$。

*证明*：$s[j..r]$ 包含某个词，等价于存在某个出现位置 $[a,b]$ 满足 $j\le a<b\le r$（词的起点不早于 $j$、终点不晚于 $r$）。对所有满足 $j\le a$ 的起点 $a$，取其最小终点并再取最小，就得到使 $s[j..r]$ 合法的最小 $r$：

$$g[j]=\min\Big(\min_{\substack{a\ge j\\ \text{best}[a]<b}} b\Big)=\min_{a\ge j}\text{best}[a]$$

其中括号内用到了：对于固定起点 $a$，取最小终点一定不劣于取更大的终点（更早结束意味着更容易放进任何区间）。而 $\min_{a\ge j}\text{best}[a]$ 恰是 `best` 数组的后缀最小值，可由 $g[j]=\min(\text{best}[j],g[j+1])$ 从右往左 $O(n)$ 求出。证毕。

**引理 3**（DP 正确性）：令 $f[0]=0$，$f[i]$ 表示 $s[1..i]$ 最多能切成的合法段数（不可行时为 $-1$），则

$$f[i]=\max_{\substack{1\le j\le i\\ f[j-1]\ge 0\\ g[j]\le i}}\big(f[j-1]+1\big)$$

正确。

*证明*：对任意把 $s[1..i]$ 切成合法段的方案，设最后一段为 $s[j..i]$。由引理 1，$s[j..i]$ 合法等价于 $g[j]\le i$；前 $j-1$ 个字符必须自己切得出来，即对应方案的前 $j-1$ 段构成一个合法的 $s[1..j-1]$ 的切分，故 $f[j-1]\ge 0$。该方案的总段数 $= (\text{前 } j-1 \text{ 段的段数})+1 \le f[j-1]+1$。

反之，对任意满足条件的 $j$，取一个实现 $f[j-1]$ 的最优切分方案，再接上合法段 $s[j..i]$，就得到一个 $f[j-1]+1$ 段的合法方案，且各段首尾相接不重叠、恰好覆盖 $s[1..i]$。

两个方向合起来说明 $f[i]$ 等于右式的最大值。证毕。

**引理 4**（答案）：若 $f[n]<0$ 则无法分割，输出 $0$；否则输出 $f[n]$。

*证明*：由引理 3，$f[n]\ge 0$ 当且仅当存在把整个 $s$ 切分成合法段的方案。若不存在，按题目"特殊情况"要求输出 $0$；若存在，$f[n]$ 就是最大段数，且段数为 $0$ 是不可能的（$n\ge 1$，至少要切出 1 段），所以不会与"输出 $0$"混淆。证毕。

**定理**：算法输出的段数是可能的最大段数。

*证明*：引理 1、2 保证阈值判断与"区间含词"完全等价，引理 3 保证 DP 求出了每个前缀的最优解，引理 4 给出正确的输出形式。证毕。

## 三、模式总结（按实际思考顺序）

1. **拆解 DP 骨架** — "最后一段从哪开始"枚举，$f[i]=\max(f[j-1]+1)$，难点只在合法性判定。
2. **标记词的出现位置** — 朴素匹配枚举每个字典词的所有出现位置，$O(N\cdot n\cdot |A|)$ 可接受。
3. **把二维判定压成一维阈值** — 固定左端点后"包含"关于右端点单调，故只需记最早的合法右端点 $g[j]$。
4. **后缀最小值求阈值** — 先按起点归拢取最小终点，再对起点维做后缀最小值。
5. **边界处理** — 前缀不可达时跳过转移；整体不可达时按题意输出 $0$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $s$ | 主串 | `string`，$|s|=n\le 300$ |
| $A_k$ | 字典中第 $k$ 个词 | `string`，$1\le|A_k|\le n$ |
| $N$ | 字典词个数 | `int`，$\le 500$ |
| $n$ | 主串长度（内部 1-based） | `int` |
| $\text{best}[a]$ | 起点恰为 $a$ 的词出现位置中的最小终点 | `int`，初值 `inf` |
| $g[j]$ | 使 $s[j..r]$ 合法的最小 $r$（后缀最小值） | `int` |
| $f[i]$ | $s[1..i]$ 最多可切的合法段数，$-1$ 表示不可行 | `int` |
| `inf` | 无穷大哨兵 | `int`，$1145141919$ |

### 算法步骤

1. 读入主串 `s`、字典词数 `N` 与 `N` 个词。
2. 初始化 `minEnd[l] = inf`（$l=1..n+1$），其中 `minEnd` 即 $\text{best}$。
3. 对每个字典词 `wd`（长度 $m$），枚举它在 `s` 中的所有起点 $i$（$1\le i\le n-m+1$），逐字符比较；若完全相同，则 `minEnd[i] = min(minEnd[i], i+m-1)`。
4. 求后缀最小值：`for(l=n-1..1) minEnd[l] = min(minEnd[l], minEnd[l+1]);`，此时 `minEnd[l]` 即 $g[l]$。
5. DP：`f[0]=0`；对 $i=1..n$，对 $j=1..i$，若 `f[j-1]>=0` 且 `minEnd[j]<=i`，则 `f[i]=max(f[i], f[j-1]+1)`。
6. 输出 `f[n] < 0 ? 0 : f[n]`。

### 复杂度

- 时间复杂度：$O\!\left(\sum_k n\cdot|A_k| + n^2\right)$，约 $4.5\times 10^7 + 9\times 10^4$。
- 空间复杂度：$O(n)$。

- 题面样例 `asdsd / 3 / as sd ds` 输出 `2`，与官方一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2031 脑力达人之分割字串
// 思路：先标出字典词在主串中的所有出现位置，再做 DP
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{305};

string s,wd;
int n,N;
// minEnd[l]: 使 s[l..r] 含有某个字典词的最小 r（1-based，闭区间），无解为 inf
int minEnd[mxn];
// f[i]: s[1..i] 最多分成几段，-1 表示无法分割
int f[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	cin>>N;
	n=s.size();
	const int inf=1145141919;
	for(int l=1;l<=n+1;++l) minEnd[l]=inf;
	for(int k=0;k<N;++k)
	{
		cin>>wd;
		int m=wd.size();
		for(int i=1;i+m-1<=n;++i)
		{
			bool same=true;
			for(int j=0;j<m;++j)
				if(s[i-1+j]!=wd[j]){same=false;break;}
			if(same) minEnd[i]=min(minEnd[i],i+m-1);
		}
	}
	// minEnd[l] = 所有起点 >= l 的词出现位置中，最小的结束位置
	for(int l=n-1;l>=1;--l) minEnd[l]=min(minEnd[l],minEnd[l+1]);

	f[0]=0;
	for(int i=1;i<=n;++i)
	{
		f[i]=-1;
		for(int j=1;j<=i;++j)
			if(f[j-1]>=0 && minEnd[j]<=i)
				f[i]=max(f[i],f[j-1]+1);
	}
	if(f[n]<0) cout<<0<<'\n';
	else cout<<f[n]<<'\n';
	return 0;
}
```

### 代码说明

- `minEnd` 一名两用：前半段充当"按起点归拢的最小终点"（即 $\text{best}$），求完后缀最小值后直接充当 $g$，省掉一个数组。
- `minEnd` 在下标 $n+1$ 处也置为 `inf`，保证后缀最小值的边界安全。
- `f` 的不可达标记用 `-1`，因为合法段数 $\ge 0$，不会与合法值冲突。
- 主串按 1-based 思考，`s[i-1+j]` 是第 $j$ 个字符的 0-based 下标，比较时注意别错位。
