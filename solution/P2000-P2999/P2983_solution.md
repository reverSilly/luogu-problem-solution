# P2983 [USACO10FEB] Chocolate Buying S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 商店有 $N$ 种巧克力（$N\le10^5$），第 $i$ 种单价 $P_i$、有 $C_i$ 头牛想要它（$1\le P_i,C_i\le10^{18}$），库存无限。预算 $B$（$1\le B\le10^{18}$）。每头牛只认自己那一种，买一块就能满足一头。问最多满足多少头牛。

**口径说明**：题面说「$C_i$ 头牛想要这种巧克力」，结合样例（买 $3$ 块第 $1$ 种满足 $3$ 头），明确语义是**每头被满足的牛恰好消耗一块它喜欢的巧克力**，即第 $i$ 种至多买 $C_i$ 块、每块花费 $P_i$、贡献 $1$ 头满足数。这是一个「每种物品最多 $C_i$ 件、每件价值 $1$、费用 $P_i$」的有界背包。

**第一步：暴力与 DP 为什么全灭。** 子集枚举不可能；按预算 DP 的状态数是 $B\le10^{18}$，连数组都开不下。值域 $10^{18}$ 直接把一切「按金额/按牛数展开」的伪多项式算法判了死刑——**只能贪心或数学**。

**第二步：贪心直觉。** 每头牛的价值都是 $1$，要让「头数」最多，当然优先买便宜的。这就是分数背包「按单位价值排序」的特例：这里每件价值相同，单位价值排序退化为**按单价升序**。算法：排序后从便宜到贵，每种买 $\min(C_i,\lfloor\text{剩余预算}/P_i\rfloor)$ 块，直到钱花光或买完。

样例验证：$B=50$，按价排序 $(1,1),(5,3),(7,2),(10,4),(60,1)$：买 $1$ 块 $1$ 元剩 $49$；买 $3$ 块 $5$ 元剩 $34$；买 $2$ 块 $7$ 元剩 $20$；买 $2$ 块 $10$ 元剩 $0$；共 $1+3+2+2=8$ ✓，与题面一致。

**第三步：直觉不等于证明。** 「买便宜」会不会有反例？比如「便宜的买太多，挤占了稍贵但需求大的」？不会——因为每头牛价值相同，把一块贵巧克力换成一块便宜的，满足数不变、花钱更少，省下的钱只会多买不会少买。这个「交换不亏」的直觉要写成严格的交换论证（引理 1），再推出「最优解必是前缀买满形」（引理 2），最后证贪心在所有前缀买满解里最大（引理 4）。三步缺一不可：只证「交换不亏」只能说明存在无逆序最优解，还得说明贪心恰好是其中最好的。

**第四步：真正的陷阱——溢出。** 兴冲冲写 `min(C_i, B/P_i)` 之前，先算一笔账：

- $P_i\cdot C_i$ 最大 $10^{36}$，是 `long long` 上限 $9.22\times10^{18}$ 的 $10^{17}$ 倍。**任何「先算这种全买要多少钱」的写法都必然溢出**。正确姿势是**先除后乘**：`t=min(C_i,B/P_i)`，则 `t*P_i<=B<=1e18`，乘法永远安全。
- 答案会不会溢出？$\sum C_i$ 可达 $10^{23}$，但**答案不会**：每满足一头牛至少花 $1$ 元（$P_i\ge1$），故答案 $\le B\le10^{18}$，`long long` 装得下。前提是别去算 $\sum C_i$。
- `B/P_i` 是整数下取整除法，恰好就是「剩余预算最多买几块」，无需浮点。

**第五步：细节核对。**

1. **$B<P_i$ 时**：$\lfloor B/P_i\rfloor=0$，这块买不起，`t=0`，预算不变，继续看下一种——循环条件 `b>0` 只是提前剪枝，`b==0` 后所有 `t` 都是 $0$，跳过等价。
2. **价格并列**：排序只比 `p`，并列顺序任意。交换论证只用到 $P_i\le P_j$（引理 1），并列时交换代价差为 $0$，论证照样成立。
3. **预算恰好花光**：`b==0` 时循环终止，答案已计入之前所有购买，正确。
4. **全买得起**：所有 $C_i$ 买满后 `b` 可能仍 $>0$，循环自然走完，答案 $=\sum C_i$（此时 $\sum C_i\le B\le10^{18}$，不溢出）。

**手造数据核对。** 第一组用题面样例（上表已逐步核对，答案 $8$ ✓）。另造四组打边界：

| 输入 | 手算 | 期望 |
|---|---|---|
| $N=1,B=1$；$(P,C)=(2,5)$ | $1<2$，一块买不起 | `0` |
| $N=1,B=10^{18}$；$(1,10^{18})$ | 全买，答案 $10^{18}$（`i64` 极限） | `1000000000000000000` |
| $N=2,B=9$；$(3,2),(3,2)$ | 价格并列：先买满第一种 $2$ 块剩 $3$，再买 $1$ 块 | `3` |
| $N=1,B=10$；$(6,5)$ | $\lfloor10/6\rfloor=1<5$，只买 $1$ 块剩 $4$ | `1` |

四组程序输出全部吻合。第二组同时验证了 `t*p` 在 $10^{18}$ 量级不溢出、答案用 `i64` 输出正确。

## 二、思维链：完整证明

**记号。** 解为向量 $x=(x_0,\dots,x_{N-1})$，$x_i\in\{0,1,\dots,C_i\}$ 表示第 $i$ 种买的块数。**可行**：$\sum_i x_iP_i\le B$。目标：最大化 $|x|=\sum_i x_i$。把种类按 $P$ 升序排序（并列任意），以下恒设 $P_0\le P_1\le\dots\le P_{N-1}$。贪心：$b_0=B$，$g_i=\min(C_i,\lfloor b_i/P_i\rfloor)$，$b_{i+1}=b_i-g_iP_i$。

---

### 引理 1（交换论证：存在无「逆序」的最优解）

称 $(i,j)$（$i<j$）为解 $x$ 的**逆序对**，若 $x_i<C_i$ 且 $x_j>0$（便宜的没买满，却买了贵的）。则存在一个最优解不含任何逆序对。

*证明*：最优解集合有限非空（$x=0$ 可行，故非空；每个 $x_i$ 有界，故有限）。在其中取使势函数 $\Phi(x)=\sum_i i\cdot x_i$ **最小**的一个 $x^\*$（有限集上最小值存在）。

断言 $x^\*$ 无逆序对。若不然，设 $(i,j)$ 是逆序对：$i<j$，$x^\*_i<C_i$，$x^\*_j>0$。构造 $x'=x^\*+e_i-e_j$（第 $i$ 种多买一块、第 $j$ 种少买一块）：

- **边界合法**：$x'_i=x^\*_i+1\le C_i$，$x'_j=x^\*_j-1\ge0$，其余分量不变。
- **费用不增**：$\mathrm{cost}(x')-\mathrm{cost}(x^\*)=P_i-P_j\le0$（排序保证 $i<j\Rightarrow P_i\le P_j$）。故 $x'$ 可行。
- **满足数不变**：$|x'|=|x^\*|+1-1=|x^\*|$，故 $x'$ 也是最优解。
- **势严格下降**：$\Phi(x')-\Phi(x^\*)=i-j<0$。

这与 $x^\*$ 的 $\Phi$ 最小性矛盾。故 $x^\*$ 无逆序对。证毕。

**注**：价格并列（$P_i=P_j$）时费用差为 $0$，论证不变——这就是「并列顺序任意」的正确性来源。

---

### 引理 2（无逆序解 = 前缀买满形）

设 $x$ 无逆序对。令 $t=\min\{i:x_i<C_i\}$（若所有 $x_i=C_i$ 则记 $t=N$）。则

$$x_i=C_i\ (i<t),\qquad x_t<C_t\ (t<N),\qquad x_j=0\ (j>t).$$

即「前面全买满、中间至多买一部分、后面一块不买」。

*证明*：$i<t$ 时 $x_i=C_i$ 由 $t$ 的最小性直接得到。设 $j>t$ 且 $x_j>0$。因 $t<N$ 时 $x_t<C_t$，$(t,j)$ 构成逆序对（$t<j$），与无逆序矛盾；$t=N$ 时不存在 $j>t$。故 $j>t\Rightarrow x_j=0$。证毕。

**意义**：引理 1+2 把搜索空间从 $\prod(C_i+1)$ 个解压缩到 $N+1$ 个「阈值形」候选——最优解一定藏在里面。剩下只需比较贪心与这些候选。

---

### 引理 3（贪心可行，且自身是前缀买满形）

(a) 贪心 $g$ 可行：$\sum_i g_iP_i=B-b_N\le B$，且 $0\le g_i\le C_i$。
(b) $g$ 是前缀买满形：令 $t_g=\min\{i:g_i<C_i\}$（不存在则 $t_g=N$），则 $g_i=C_i\ (i<t_g)$，$g_j=0\ (j>t_g)$。

*证明*：(a) 对 $i$ 归纳证 $b_i\ge0$：$b_0=B\ge1>0$；设 $b_i\ge0$，则 $\lfloor b_i/P_i\rfloor\ge0$，$g_i=\min(C_i,\lfloor b_i/P_i\rfloor)\in[0,C_i]$，且 $g_iP_i\le\lfloor b_i/P_i\rfloor\cdot P_i\le b_i$，故 $b_{i+1}=b_i-g_iP_i\ge0$。于是 $\sum g_iP_i=\sum(b_i-b_{i+1})=b_0-b_N=B-b_N\le B$（望远镜求和）。

(b) $i<t_g$ 时 $g_i=C_i$ 由最小性。设 $j>t_g$。在 $t_g$ 处 $g_{t_g}<C_{t_g}$，故 $\min$ 取到第二项：$g_{t_g}=\lfloor b_{t_g}/P_{t_g}\rfloor$。于是

$$b_{t_g+1}=b_{t_g}-\Big\lfloor\frac{b_{t_g}}{P_{t_g}}\Big\rfloor P_{t_g}=b_{t_g}\bmod P_{t_g}<P_{t_g}\le P_j.$$

$b$ 序列单调不增（每步减去非负量），故 $b_j\le b_{t_g+1}<P_j$，$\lfloor b_j/P_j\rfloor=0$，$g_j=\min(C_j,0)=0$。证毕。

**推论**：代码里 `b>0` 的循环剪枝不改变结果：$b_i=0$ 之后所有 $g_j=0$（$\lfloor0/P_j\rfloor=0$），提前退出与走完循环等价。

---

### 引理 4（贪心支配一切可行的前缀买满解）

设 $x$ 是任一**可行**的前缀买满形解，阈值 $t_x$（引理 2 的形式）。则 $|x|\le|g|$。

*证明*：若 $t_g=N$（贪心全买满），$|g|=\sum C_i\ge|x|$ 平凡成立。下设 $t_g<N$，分三种情形。记前缀费用 $F_k=\sum_{i<k}C_iP_i$，残量 $r=B-F_{t_g}$（贪心在 $t_g$ 处的剩余预算；由引理 3，$g_{t_g}=\lfloor r/P_{t_g}\rfloor<C_{t_g}$，故 $r<C_{t_g}P_{t_g}$）。

**情形 A：$t_x<t_g$。** 贪心对每个 $i\le t_x$（$<t_g$）都买满 $C_i$，故

$$|g|\ge\sum_{i\le t_x}C_i=\sum_{i<t_x}C_i+C_{t_x}\ge\sum_{i<t_x}C_i+x_{t_x}=|x|.$$

**情形 B：$t_x=t_g$。** 两解在 $i<t_g$ 处都买满 $C_i$，费用同为 $F_{t_g}$，剩余预算同为 $r$。$x$ 可行要求 $x_{t_g}P_{t_g}\le r$，即 $x_{t_g}\le\lfloor r/P_{t_g}\rfloor$；又 $x_{t_g}\le C_{t_g}$。故

$$x_{t_g}\le\min\Big(C_{t_g},\Big\lfloor\frac{r}{P_{t_g}}\Big\rfloor\Big)=g_{t_g},$$

从而 $|x|=F\text{项}+x_{t_g}\le F\text{项}+g_{t_g}=|g|$。

**情形 C：$t_x>t_g$。** 则 $x_{t_g}=C_{t_g}$（$t_g<t_x$ 处买满）。$x$ 的费用

$$\mathrm{cost}(x)\ge F_{t_g}+C_{t_g}P_{t_g}>F_{t_g}+r=B,$$

其中严格不等号用了 $r<C_{t_g}P_{t_g}$。与 $x$ 可行矛盾，故此情形不存在。

三情形穷尽，$|x|\le|g|$ 恒成立。证毕。

---

### 引理 5（溢出分析：先除后乘是唯一安全姿势）

(a) $P_iC_i$ 可达 $10^{36}>2^{63}-1\approx9.22\times10^{18}$，任何直接计算 $P_iC_i$ 的表达式必然可能溢出。
(b) 代码中出现的乘法只有 `t*a[i].p`，其中 $t=\min(C_i,\lfloor b/P_i\rfloor)$，故 $t\cdot P_i\le\lfloor b/P_i\rfloor\cdot P_i\le b\le B\le10^{18}$，安全。
(c) 答案 $\mathrm{ans}=\sum g_i\le\sum g_iP_i\le B\le10^{18}$（$P_i\ge1$），`i64` 可容纳；而 $\sum C_i$ 可达 $10^{23}$，**不可计算也不必计算**。
(d) 减法 `b-=t*p` 两操作数均在 $[0,10^{18}]$ 且结果 $\ge0$（引理 3），无下溢。

*证明*：(a) 取 $P_i=C_i=10^{18}$ 即达 $10^{36}$，超出 `i64` 表示范围，溢出是确定事件而非概率事件。(b) 由 $\min$ 的第二项 $t\le\lfloor b/P_i\rfloor$，两边乘正数 $P_i$ 得 $tP_i\le\lfloor b/P_i\rfloor P_i\le b$；$b\le B$ 由引理 3 的单调性。(c) $g_i\le g_iP_i$ 因 $P_i\ge1$，求和并用引理 3(a)。(d) 引理 3(a) 已证 $b_{i+1}\ge0$。证毕。

---

### 引理 6（复杂度）

时间 $O(N\log N)$，空间 $O(N)$。

*证明*：读入 $O(N)$；排序 $O(N\log N)$；扫描 $O(N)$（每种一次除法、一次 $\min$、一次乘法、一次减法，均为 $O(1)$ 的 $64$ 位运算）。合计 $O(N\log N)\approx10^5\times17=1.7\times10^6$ 次比较。空间：结构体数组 $N\times16$ 字节 $\approx1.6$ MB，$O(N)$。证毕。

---

### 定理

程序输出预算 $B$ 内最多可满足的牛数，总复杂度 $O(N\log N)$，全程无溢出。

*证明*：引理 1 保证存在无逆序最优解；引理 2 把它限定为前缀买满形；引理 3 保证贪心自身可行且是前缀买满形；引理 4 保证贪心支配所有可行的前缀买满形解——三者串联：$\mathrm{OPT}=\max\{|x|:x\text{ 最优}\}=|x^\*|\le|g|\le\mathrm{OPT}$（$x^\*$ 是引理 1 的无逆序最优解，$g$ 可行故 $|g|\le\mathrm{OPT}$），夹逼得 $|g|=\mathrm{OPT}$。引理 5 保证实现中每个算术表达式都在 `i64` 范围内；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 每头牛价值 $1$、费用 $P_i$、每种至多 $C_i$ 件 ⇒ 单位价值的有界背包；$B\le10^{18}$ 判死一切按金额 DP。
2. **consider easier version** — 若 $C_i=\infty$：全买最便宜的一种；若 $C_i=1$：排序取前缀。两个退化版都指向「按单价升序买」。
3. **classic problem solution** — 分数背包式贪心：按单价升序，每种买 $\min(C_i,\lfloor b/P_i\rfloor)$ 块。
4. **explore its property** — 交换论证：「便宜没买满却买了贵的」逆序对可平移，费用不增、数量不变 ⇒ 存在无逆序最优解（势函数 $\sum i\cdot x_i$ 最小者）。
5. **reduce to easier problem** — 无逆序解必为「前缀买满 + 一个部分 + 后缀零」形，候选从 $\prod(C_i+1)$ 塌缩到 $N+1$ 个阈值；按阈值分三类比较，贪心全胜。
6. **discuss by category** — 溢出分类：$P\cdot C\le10^{36}$ 绝不直接乘（先除后乘）；答案 $\le B\le10^{18}$ 安全；$\sum C_i\le10^{23}$ 不可算；$b=0$ 提前退出等价。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 巧克力种数 $N\le10^5$ | `int` | 读入 |
| `mxn` | $100000+5$ | `constexpr int` | 数组尺寸松弛 |
| `a[i].p` | 第 $i$ 种单价 $P_i$，**排序关键字** | `i64` | 读入；$\le10^{18}$ |
| `a[i].c` | 想要第 $i$ 种的牛数 $C_i$（购买上限） | `i64` | 读入；$\le10^{18}$ |
| `b` | 剩余预算（数学记号 $b_i$） | `i64` | 初值 $B$；**单调不增，恒 $\ge0$** |
| `t` | 当前种实际购买块数 $g_i=\min(C_i,\lfloor b/P_i\rfloor)$ | `i64` | 每轮现算；**先除后乘的载体** |
| `ans` | 已满足牛数 $\sum g_i$ | `i64` | 全局默认 $0$；$\le B\le10^{18}$ |

### 算法步骤

1. I/O 加速三行。
2. 读 $N,B$ 与每种 $(P_i,C_i)$。
3. 按 `p` 升序 `sort`（并列任意）。
4. 顺序扫描（`b>0` 时）：`t=min(a[i].c,b/a[i].p)`；`ans+=t`；`b-=t*a[i].p`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(N\log N)$，排序主导；$N=10^5$ 时约 $1.7\times10^6$ 次比较。
- 空间：$O(N)$，结构体数组约 $1.6$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例输出 $8$ 吻合；另造「买不起」「$10^{18}$ 极限」「价格并列」「部分购买」四组手算数据全对。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2983 [USACO10FEB] Chocolate Buying S
// 按单价升序贪心买满；先除后乘防溢出（P*C 可达 1e36）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n;
i64 b,ans;
struct node{i64 p,c;}a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>b;
	for(int i=0;i<n;++i)
		cin>>a[i].p>>a[i].c;
	sort(a,a+n,[](node x,node y){return x.p<y.p;});
	for(int i=0;i<n&&b>0;++i)
	{
		i64 t=min(a[i].c,b/a[i].p);	// 先除后乘：t*p<=b<=1e18，绝不直接算 p*c
		ans+=t;
		b-=t*a[i].p;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`p,c` 必须是 `i64`**：$10^{18}$ 远超 `int`；读入、比较、除法全程 $64$ 位。
- **先除后乘是本题的生死线**：`t=min(c,b/p)` 保证 `t*p<=b<=1e18`；若写成「先算 `p*c` 再与 `b` 比较」，$10^{36}$ 立刻溢出（引理 5(a)）。
- `b/a[i].p` 是整数下取整除法，语义恰为「剩余预算最多买几块」，与 `min(c,...)` 合成「需求与财力的较小者」。
- 循环条件 `b>0` 是剪枝：`b==0` 后所有 `t=0`，提前退出等价（引理 3 推论）。`b<p` 时 `t=0`、预算不变，自然跳过买不起的种类。
- `ans` 用 `i64`：虽然 $\sum C_i$ 可达 $10^{23}$，但实际答案 $\le B\le10^{18}$（每头牛至少花 $1$ 元），`i64` 恰好装下（引理 5(c)）。
- 排序比较器只比 `p`，并列顺序任意：交换论证在 $P_i=P_j$ 时费用差为 $0$，正确性不受影响（引理 1 注）。
