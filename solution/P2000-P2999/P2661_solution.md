# P2661 [NOIP 2015 提高组] 信息传递 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 个人（$n\le 2\times10^5$），每人有固定的传递对象 $T_i$（$T_i\le n$，$T_i\ne i$）。第 $0$ 轮每人只知道自己生日；每一轮所有人**同时**把自己当前知道的全部生日告诉自己的对象。一旦有人**从别人口中**听到自己的生日，游戏结束。问游戏一共进行了几轮。

题面只给了样例 1 的文字解释（图片看不到），我按解释反推出一组数据：$n=5$，$T=(2,4,2,3,1)$，答案 $3$——解释里说"第 $3$ 轮后 $4$ 号听到 $2$ 号告诉他自己的生日"，而 $T_2=4$，正好吻合。下面所有推理都拿这组数据对表。

**第一步：手动模拟一轮，看清"信息怎么走"。** 把上面的例子画成箭头：$1\to2$，$2\to4$，$3\to2$，$4\to3$，$5\to1$。

- 第 $1$ 轮：每人把**自己的**生日告诉对象。$4$ 的生日沿 $4\to3$ 走到 $3$。
- 第 $2$ 轮：$3$ 把已知的 $\{3,4\}$ 告诉 $2$，于是 $4$ 的生日走到 $2$。
- 第 $3$ 轮：$2$ 把已知的 $\{1,2,3,4\}$ 告诉 $4$，$4$ 听到自己的生日，结束。

盯住"$4$ 的生日"这一个信息看：它沿着 $4\to3\to2\to4$ **每轮恰好走一跳**，$3$ 跳回到源头，用了 $3$ 轮。这不是巧合——每人每轮只转发一次，信息不可能一轮走两跳，也不会停留（知道的信息永远保留并继续转发）。

**第二步：把"听到自己生日"翻译成图论语言。** 信息从 $v$ 出发，走的路线是唯一确定的：$v\to T_v\to T_{T_v}\to\cdots$，即迭代 $T^r(v)$。$v$ 在第 $r$ 轮听到自己的生日，当且仅当这条路线在第 $r$ 跳回到 $v$，即 $T^r(v)=v$。

- 若 $v$ 在某个环上，环长为 $\ell$，则第一次回到 $v$ 恰是第 $\ell$ 轮；
- 若 $v$ 不在环上（挂在环外的"尾巴"上），路线一路向前钻进环里再也不回来，$v$ **永远**听不到自己的生日。

游戏在"第一个人听到自己生日"的那轮结束，所以

$$\text{答案}=\min_{v\ \text{在环上}}\ell(v)=\text{图中最小环的环长}.$$

用样例对表：环是 $2\to4\to3\to2$，长 $3$，答案 $3$ ✓。注意轮数与跳数**不差一**：第 $r$ 轮走 $r$ 跳，样例解释里"进行完第 $3$ 轮后结束、输出 $3$"把计数口径钉死了。

**第三步：看清图的结构。** 每个点出度恰好为 $1$——这是**函数图**（内向基环树森林）：每个弱连通分量恰好一个有向环，环上挂着若干棵指向环的内向树。$T_i\ne i$ 排除了自环，所以答案 $\ge2$。尾巴上的点不影响答案，只有环长有关。

**第四步：朴素做法为什么不行。**

- 真的模拟集合传播：每人维护一个"已知生日集合"，最坏 $O(n^2)$ 空间、每轮 $O(n^2)$ 时间，环长可达 $n$，总量 $4\times10^{10}$，爆。
- 对每个 $v$ 沿 $T$ 走到回到自己：单点 $O(n)$，$n$ 个点 $O(n^2)=4\times10^{10}$（一个大环时每个点都要走满 $n$ 步），还是爆。

瓶颈在于**重复走**：大环上 $n$ 个点各走 $n$ 步，同一条环被走了 $n$ 遍。必须让每个点只被处理一次，做到 $O(n)$。

**第五步：$O(n)$ 求最小环的候选工具。** 函数图最小环是经典问题，标签里也提示了：

- Tarjan 强连通分量：环就是大小 $\ge2$ 的 SCC，取最小 SCC 大小。$O(n)$，但代码量大。
- 拓扑排序剥叶子：不断删入度 $0$ 的点，剩下的恰好是环上点，再逐个环走一遍数长度。$O(n)$，两遍。
- 带权并查集：合并时若已连通则成环，用深度差算环长。能做但繁琐。
- **全局时间戳游走**：一遍扫描，每个点只 stamp 一次，走到"本轮 stamp 过的点"就发现一个环。$O(n)$，十几行，而且是**迭代**的——$n=2\times10^5$ 时递归 DFS 有爆栈风险，迭代游走天然免疫。

我选时间戳游走。

**第六步：设计时间戳游走，关键在"怎么区分新环和旧环"。** 沿 $T$ 走一定会撞到访问过的点，但撞到的点有两种：

1. **本轮**刚访问的——说明从它出发又走回了它，中间这段就是一个新环；
2. **以前某轮**访问的——说明当前链汇入了早已处理完的部分，那里的环早就统计过了，本轮没有新环。

怎么区分？给每个点记一个**全局递增**的时间戳 `vis[u]`（$0$ 表示未访问），每轮游走开始前记下当前时钟 `st`。撞到点 $u$ 时：`vis[u]>st` ⇔ $u$ 是本轮 stamp 的 ⇔ 新环，环长 = 当前时钟 $-$ `vis[u]` $+1$；否则是旧点，忽略。因为时间戳全局唯一、每点一生只 stamp 一次，所有游走的总步数 $\le n$，复杂度 $O(n)$。

**第七步：为什么每个环恰好被发现一次？** 考虑某个环 $C$，看**第一个碰到 $C$ 的游走**：它从某个未访问点进入 $C$ 时，$C$ 上所有点都还没被 stamp（否则更早就有游走碰过 $C$），于是它会沿 $C$ 把整圈 stamp 完，回到入口点时发现"本轮 stamp 过"，报告环长 $|C|$。之后的游走再碰到 $C$ 只会撞到旧时间戳，立刻停下，不会重复报告。反过来，报告出来的"环"也一定是真环：游走是沿 $T$ 的确定性路径，路径上重复出现同一点，中间那段必然是首尾相接的有向环。细节在第二部分严格证。

**手造数据核对**（题面没有可复制的样例输入，第一组按样例解释反推，其余专打结构边界）：

| 输入 | 结构 | 答案 |
|---|---|---|
| `5` / `2 4 2 3 1` | 环 $\{2,3,4\}$ 长 $3$，尾巴 $5\to1\to2$ | $3$（与样例解释一致） |

## 二、思维链：完整证明

**记号。** 把 $T$ 看作 $[n]=\{0,\dots,n-1\}$ 上的函数（代码 0-based），$T(i)\ne i$。$T^r$ 表示 $r$ 次迭代，$T^0=\mathrm{id}$。由于每点出度为 $1$，从 $u$ 出发的有向道路唯一，记 $\mathrm{dist}(u,v)=\min\{k\ge0:T^k(u)=v\}$（不可达为 $\infty$）。$K_r(v)$ 表示第 $r$ 轮结束后 $v$ 知道的生日集合（用源头编号标识生日），$K_0(v)=\{v\}$。

### 引理 1（传播规律：$K_r(v)=\{u:\mathrm{dist}(u,v)\le r\}$）

*证明*：对 $r$ 归纳。$r=0$：$K_0(v)=\{v\}$，而 $\mathrm{dist}(u,v)\le0\iff u=v$ ✓。

设 $r$ 时成立。第 $r+1$ 轮，$v$ 收到所有满足 $T(u)=v$ 的 $u$ 在第 $r$ 轮结束时的知识，且自己原有的知识保留（"告诉"不删除记忆），故

$$K_{r+1}(v)=K_r(v)\cup\bigcup_{u:T(u)=v}K_r(u).$$

由归纳假设，右边 $=\{w:\mathrm{dist}(w,v)\le r\}\cup\bigcup_{u:T(u)=v}\{w:\mathrm{dist}(w,u)\le r\}$。

- 若 $\mathrm{dist}(w,v)=d\le r+1$：$d\le r$ 时落入第一项；$d=r+1\ge1$ 时，唯一道路 $w\leadsto v$ 的最后一条边是某个 $u\to v$，且 $\mathrm{dist}(w,u)=d-1=r$，落入第二项。
- 反之，第二项中 $\mathrm{dist}(w,u)\le r$ 且 $T(u)=v$，拼接得 $\mathrm{dist}(w,v)\le\mathrm{dist}(w,u)+1\le r+1$；第一项显然 $\le r+1$。

两边互含，故 $K_{r+1}(v)=\{w:\mathrm{dist}(w,v)\le r+1\}$。证毕。

**推论**：生日 $u$ 的信息在第 $r$ 轮恰好位于 $T^r(u)$（它每轮走一跳），且"知道"是单调累积的。

### 引理 2（回归 ⇔ 在环上，且首次回归 = 环长）

对 $r\ge1$：$T^r(v)=v\iff v$ 在某个有向环上且环长 $\ell(v)\mid r$。特别地，最小的这种 $r$ 就是 $\ell(v)$；不在环上的 $v$ 对任何 $r\ge1$ 都有 $T^r(v)\ne v$。

*证明*：（$\Rightarrow$）设 $T^r(v)=v$。令 $C=\{v,T(v),\dots,T^{r-1}(v)\}$。$T$ 把 $C$ 映到 $C$，且是满射：$C$ 中每个 $T^k(v)$（$k\ge1$）是 $T^{k-1}(v)$ 的像，而 $v=T(T^{r-1}(v))$ 也是像。有限集上的满射是双射。双射下 $v$ 的轨道是纯周期的：存在最小 $\ell\ge1$ 使 $T^\ell(v)=v$（$\ell\le|C|$），且 $v,T(v),\dots,T^{\ell-1}(v)$ 两两不同（否则与 $\ell$ 最小矛盾），它们构成一个有向环，$v$ 在环上，$\ell(v)=\ell$。写 $r=q\ell+s$，$0\le s<\ell$，则 $T^r(v)=T^s(v)$，它等于 $v$ 当且仅当 $s=0$（$\ell$ 的最小性），即 $\ell\mid r$。

（$\Leftarrow$）$v$ 在长 $\ell$ 的环上，则 $T^\ell(v)=v$，且 $T^r(v)=T^{r\bmod\ell}(v)$，等于 $v\iff\ell\mid r$。

不在环上的 $v$：若某 $r\ge1$ 有 $T^r(v)=v$，由（$\Rightarrow$）$v$ 在环上，矛盾。证毕。

### 引理 3（结束轮数 = 最小环长）

$v$ **第一次**从别人口中听到自己的生日是在第 $\ell(v)$ 轮（$v$ 在环上时）；不在环上则永远听不到。游戏结束轮数 $R=\min_{v\text{ 在环上}}\ell(v)$，即全图最小环长。

*证明*：$v$ 在第 $r$ 轮听到自己的生日，当且仅当存在 $u\ne v$，$T(u)=v$ 且 $v\in K_{r-1}(u)$（$u$ 在上一轮结束时已知 $v$ 的生日，本轮告诉 $v$）。由引理 1，即 $\mathrm{dist}(v,u)\le r-1$。

- **$v$ 在环上**（环长 $\ell$）：$v$ 的入邻居中，环上前驱 $u^\*=T^{\ell-1}(v)$ 满足 $\mathrm{dist}(v,u^\*)=\ell-1$（从 $v$ 出发的唯一道路绕环一周才到 $u^\*$）；任何其它入邻居 $u$ 都是挂在 $v$ 上的尾巴点，从 $v$ 出发永远到不了（否则 $T^k(v)=u$、$T(u)=v$ 给出 $T^{k+1}(v)=v$，由引理 2 $v$ 在环上且道路绕环，$u$ 只能是环上前驱，矛盾）。故条件化为 $\ell-1\le r-1\iff r\ge\ell$，首次成立在 $r=\ell$。
- **$v$ 不在环上**：若存在入邻居 $u$ 使 $\mathrm{dist}(v,u)<\infty$，则 $T^{k}(v)=u$、$T(u)=v$ 给出 $T^{k+1}(v)=v$，引理 2 推出 $v$ 在环上，矛盾。故条件永不成立。

游戏在"第一次有人听到自己生日"的轮结束，$R=\min_v(\text{首次轮数})=\min_{v\text{ 在环上}}\ell(v)$。每个环上所有点的 $\ell$ 相同，故这就是最小环长。样例解释"进行完第 $3$ 轮后结束、答案为 $3$"确认了轮数计数口径（结束的那一轮计入）。证毕。

### 引理 4（函数图结构：每个弱连通分量恰一个环；环必存在）

*证明*：取一个弱连通分量，含 $k$ 个点。每点贡献恰好一条出边且指向分量内，故分量恰有 $k$ 条有向边。看成无向多重图（$2$-环 $i\leftrightarrow j$ 算两条平行边），它连通、$k$ 点 $k$ 边，圈秩 $=k-k+1=1$，故**恰有一个**无向环（计重数）。这个无向环必为有向环：环上每点在全图出度为 $1$，环的每条边都是其某个端点的出边，环有 $m$ 条边、$m$ 个点，而环上点的出边总共 $m$ 条，故这 $m$ 条出边恰好就是环边，每点出度在环内为 $1$，方向沿环一致。

存在性：从任一点出发迭代 $T$，有限个点必出现重复 $T^a(v)=T^b(v)$（$a<b$），则 $T^a(v)$ 在环上（引理 2 的论证）。故至少一个环，答案良定义。又 $T_i\ne i$ 排除自环，$2\le\text{答案}\le n$。证毕。

### 引理 5（时间戳游走的正确性）

算法：`clk` 全局时钟初值 $0$；`vis[u]` 初值 $0$。按 $i=0..n-1$ 扫描，`vis[i]` 非零则跳过；否则记 `st=clk`，令 $u=i$，当 `vis[u]==0` 时置 `vis[u]=++clk` 并 $u\leftarrow T(u)$；停下后若 `vis[u]>st` 则用 `clk-vis[u]+1` 更新答案最小值。

(a) 每点恰好被 stamp 一次，总步数 $O(n)$；(b) 每次报告对应一个真实简单环，长度公式正确；(c) 每个环恰好被报告一次。

*证明*：

(a) stamp 只在 `vis[u]==0` 时发生且永不重置，故每点至多一次。外层扫到 $i$ 时若 $i$ 未 stamp 就启动游走，游走沿 $T$ 把沿途未 stamp 的点全部 stamp，故归纳可知所有点终被 stamp，总 stamp 数 $=n$，while 总迭代 $=n$，外层 $n$ 次，合计 $O(n)$。每次游走必停：每步要么 stamp 一个新点（至多 $n$ 次）要么遇到已 stamp 点停下。

(b) 设某轮游走 stamp 序列 $w_0=i,w_1=T(w_0),\dots,w_{m-1}$，时间戳依次为 $st+1,\dots,st+m=clk$，停在 $u=w_m$（已 stamp）。若 `vis[u]>st`，则 $u$ 的时间戳落在 $(st,clk]$ 内，必是本轮某个 $w_j$（$j<m$）。于是 $w_j\to w_{j+1}\to\cdots\to w_{m-1}\to w_m=w_j$ 是沿 $T$ 的闭合道路，且 $w_j,\dots,w_{m-1}$ 时间戳互异故点互异——这是一个简单有向环，长度 $m-j=clk-(st+j+1)+1=clk-\texttt{vis}[u]+1$ ✓。若 `vis[u]≤st`，$u$ 是旧点，不报告。

(c) 取定环 $C$，设 $W$ 是第一个 stamp 到 $C$ 中任何点的游走（由 (a) 所有点终被 stamp，$W$ 存在）。$W$ 进入 $C$ 时（起点在 $C$ 上或经尾巴到达 $C$ 的入口 $v$），$C$ 上所有点都未 stamp（否则与"第一个"矛盾）。$T$ 把 $C$ 映到 $C$，故 $W$ 从 $v$ 出发沿 $C$ 前进，沿途 $C$ 的点全是新点，不会提前停，直到把 $C$ 的 $|C|$ 个点连续 stamp 完、回到 $v$。此时 $v$ 是本轮 stamp（`vis[v]>st`），$W$ 停下并报告 $clk-\texttt{vis}[v]+1=|C|$（连续时间戳）✓。$W$ 在第一个已 stamp 点就停，故只报告这一个环。此后任何游走遇到 $C$ 的点都是旧时间戳（$\le st$），立即停下且不报告——$C$ 不会被第二次报告。不同环点集不交，各自被自己的"首触游走"报告。综上每个环恰报告一次、值正确。

由 (b)(c)，答案 $=\min$ 环长；由引理 4 至少一个环，`ans` 必被更新，不会输出哨兵。证毕。

### 引理 6（复杂度与实现安全）

时间 $O(n)$、空间 $O(n)$；`clk`$\le n\le2\times10^5$，`ans`$\le n$，`int` 足够；游走是迭代而非递归，$n=2\times10^5$ 的长链不会爆栈。

*证明*：引理 5(a) 给出 $O(n)$ 步；数组 `t,vis` 各 $O(n)$。每步 $O(1)$。时间戳与环长均 $\le n$，`int`（$\pm2.1\times10^9$）安全。递归 DFS 在长链上深度可达 $n$，默认栈约 $1$–$8$ MB 会溢出；本算法用 while 迭代，深度 $O(1)$。证毕。

### 定理

程序输出函数图最小环长，即游戏结束轮数；时间 $O(n)$、空间 $O(n)$。

*证明*：引理 1–3 把游戏归约为最小环长（含轮数口径）；引理 4 保证环存在、答案良定义；引理 5 保证游走恰好报告每个环一次且长度正确；引理 6 给出复杂度与安全性。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 手动模拟样例发现：信息每轮沿 $i\to T_i$ 恰好走一跳，"听到自己生日"= 信息绕回源头。
- **reduce to easier problem** — 游戏轮数 = 函数图最小环长；尾巴点永不回归，只有环长有关；样例钉死"不差一"的轮数口径。
- **explore its property** — 出度全 $1$ ⇒ 基环树森林：每分量恰一个环 + 内向树；$T_i\ne i$ ⇒ 无自环、答案 $\ge2$。
- **consider easier version** — 集合模拟与逐点走环都是 $O(n^2)=4\times10^{10}$，瓶颈是"同一条环被重复走"，必须每点只处理一次。
- **classic problem solution** — 函数图最小环的经典工具：Tarjan SCC / 拓扑剥叶 / 带权并查集 / 时间戳游走，均 $O(n)$；选最短且迭代的时间戳游走（规避 $2\times10^5$ 递归爆栈）。
- **explore its property** — 全局时间戳 + `vis[u]>st` 区分"本轮新环"与"汇入旧分量"；首触游走必绕完整环，故每环恰报告一次。
- **discuss by category** — 迭代而非递归；`int` 值域安全；哨兵 `inf` 必被更新（环必存在）。

| `n` | 人数，$\le2\times10^5$ | `int`，读入 | 内部 0-based |
| `t[i]` | $i$ 的传递对象（读入后 `--t[i]`） | `int[mxn]` | 函数图的唯一出边 |
| `vis[u]` | $u$ 被 stamp 的**全局时间戳**；$0$=未访问 | `int[mxn]`，全局默认 $0$ | 每点一生只 stamp 一次 |
| `clk` | 全局时钟，已 stamp 总数 | `int`，初值 $0$ | 单调递增，$\le n$ |
| `st` | 本轮游走开始前的时钟快照 | `int`，每轮现取 | `vis[u]>st` ⇔ 本轮新环 |
| `ans` | 最小环长 | `int`，初值 `inf` | 环必存在，必被更新 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 显著大于 $n$ |
| `mxn` | $200000+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行（固定顺序）。
2. 读 $n$ 与 $T_{1..n}$，`--t[i]` 转 0-based。
3. 按 $i=0..n-1$ 扫描：`vis[i]` 非零跳过；否则记 `st=clk`，$u=i$，while `vis[u]==0`：`vis[u]=++clk`，$u=$`t[u]`。
4. 停下后若 `vis[u]>st`，`ans=min(ans,clk-vis[u]+1)`（引理 5）。
5. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间 $O(n)$：每点恰 stamp 一次，总步数 $\le2n$。
- 空间 $O(n)$：`t`、`vis` 各约 $0.8$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$5$ 组手造数据（含按样例解释反推的 $n=5$ 组）全对；`appendix/P2661/check.cpp` 用逐轮集合传播的独立模拟对拍，穷举 $n=2..6$ 全部 $16739$ 组 + $500$ 组随机 $n\le150$，$0$ mismatch；$n=200000$ 的大环 / 全 $2$-环 / 长尾三组极限数据答案正确，运行约 $0.02$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2661 [NOIP 2015 提高组] 信息传递
// 思路：信息每轮沿 i→T_i 走一跳，v 在第 r 轮听到自己的生日 ⇔ T^r(v)=v。
//       答案 = 函数图（基环树森林）的最小环长。
//       全局时间戳游走：每个点只 stamp 一次；撞到本轮 stamp 的点 ⇒ 新环，
//       环长 = clk-vis[u]+1；撞到旧点 ⇒ 汇入已处理部分，无新环。O(n)。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{200005},inf{1145141919};

int n,t[mxn],vis[mxn],clk,ans=inf;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>t[i];--t[i];
	}
	for(int i=0;i<n;++i)
	{
		if(vis[i])
			continue;
		int st=clk,u=i;
		while(!vis[u])
		{
			vis[u]=++clk;	// 全局时间戳：每个点一生只被 stamp 一次
			u=t[u];
		}
		if(vis[u]>st)		// 撞到本轮的点 ⇒ 新环；旧点 ⇒ 环早已统计
			ans=min(ans,clk-vis[u]+1);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`vis` 存的是全局时间戳而非 bool**：这是区分"新环 / 旧环"的全部机关。`vis[u]>st` 当且仅当 $u$ 在本轮被 stamp，此时 `clk-vis[u]+1` 恰是环上点数（时间戳连续）。若只用 bool，就无法区分撞到的点是本轮的还是以前的，会把"汇入旧环"误判成新环。
- **每个点只 stamp 一次**是 $O(n)$ 的来源：所有游走的 while 迭代总数恰为 $n$，不会重复走环。
- **迭代而非递归**：$n=2\times10^5$ 的长链下递归 DFS 会爆栈，while 游走深度 $O(1)$。
- `ans` 初值 `inf` 必被更新：函数图至少一个环（引理 4），无需特判无解。
- 读入 `--t[i]` 转 0-based；答案就是环长，无需再加回下标。
