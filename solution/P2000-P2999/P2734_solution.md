# P2734 [IOI 1996 / USACO3.3] 游戏 A Game — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 个正整数排成一行（$2\le N\le100$，每个 $1\sim200$）。先手开始，两人轮流从**当前序列的左端或右端**取走一个数累加到自己得分，取完为止。双方都执行**最优策略**（让自己在对抗最强对手时得分尽量高）。输出先手、后手的最终得分。

标签「区间 DP、博弈论」已经点名方向。但我想先弄清一件事：**贪心行不行？**

**第一步：贪心「每次取较大的端点」是错的。** 直觉上每次拿大的似乎不亏，但取数会**改变剩下的序列**，可能把一个大数「暴露」给对手。手造反例 $[3,9,1,2]$：

- 贪心：端点 $3$ 和 $2$，先手拿 $3$ → 剩 $[9,1,2]$；对手拿 $9$ → 剩 $[1,2]$；先手拿 $2$，对手拿 $1$。先手 $=3+2=5$，后手 $=9+1=10$。
- 最优：先手**故意拿小的** $2$ → 剩 $[3,9,1]$；此时无论对手怎么拿，先手都能拿到 $9$。具体：对手拿 $1$ → 剩 $[3,9]$，先手拿 $9$，对手拿 $3$。先手 $=2+9=11$，后手 $=1+3=4$。

贪心给先手 $5$，最优给 $11$，差了一倍多。**结论：必须考虑「我取之后对手会怎么取」，这是博弈，不是贪心。**

**第二步：抓住「总分固定」这个零和结构。** 所有数最终都被取走，故**先手得分 + 后手得分 = 总和 $S$（常数）**。于是「让我自己得分最大」等价于「让对手得分最小」——这是一个**零和博弈**。这个观察是后面状态设计的支点：我不需要同时记录两人的分数，只要知道「轮到的人能拿多少」，另一个人的就是「剩下的」。

**第三步：设计区间状态。** 取数总是从两端取，所以任何时刻剩下的都是原序列的一个**连续区间** $[i,j]$。定义

$$dp[i][j]=\text{轮到取数的人，从区间 }[i,j]\text{ 出发、双方最优时能拿到的最大总分}.$$

注意这是「**当前行动者**」的得分，不区分他是先手还是后手——因为规则对两人对称，谁轮到谁就是「当前行动者」。

**第四步：推转移——「我拿一个端点，对手在剩下的里最优」。** 设区间和为 $\mathrm{sum}(i,j)$。当前行动者有两种选择：

- **拿左端 $a_i$**：剩下 $[i+1,j]$，轮到**对手**行动。对手最优能拿 $dp[i+1][j]$，而 $[i+1,j]$ 的总和是 $\mathrm{sum}(i,j)-a_i$，所以**我**在剩下的里拿到 $(\mathrm{sum}(i,j)-a_i)-dp[i+1][j]$，加上刚拿的 $a_i$，共 $\mathrm{sum}(i,j)-dp[i+1][j]$。
- **拿右端 $a_j$**：同理我共拿到 $\mathrm{sum}(i,j)-dp[i][j-1]$。

我选对我更有利的：

$$dp[i][j]=\max\bigl(\mathrm{sum}(i,j)-dp[i+1][j],\ \mathrm{sum}(i,j)-dp[i][j-1]\bigr)=\mathrm{sum}(i,j)-\min\bigl(dp[i+1][j],\ dp[i][j-1]\bigr).$$

「$\mathrm{sum}$ 减去对手的最优」正是零和结构的体现：**我拿走的 = 区间总和 − 对手在剩余里拿走的**。边界 $dp[i][i]=a_i$（只剩一个数，轮到的人直接拿走）。

**第五步：计算顺序与答案。** $dp[i][j]$ 依赖 $dp[i+1][j]$ 和 $dp[i][j-1]$，都是**更短**的区间，所以按**区间长度从小到大**递推。最终先手就是整个区间上的当前行动者：$\text{先手}=dp[0][N-1]$，$\text{后手}=S-\text{先手}$。

**手造数据核对**（题面无样例）：

| 输入序列 | 期望（先手 后手） | 说明 |
|---|---|---|
| `3 9 1 2` | `11 4` | 上面的贪心反例，最优先手 $11$ |
| `1 2` | `2 1` | 先手直接拿大的 $2$ |
| `5 5` | `5 5` | 对称，平局 |
| `1 2 3 4` | `6 4` | 先手拿 $4$，最终 $6:4$ |

以 `1 2 3 4` 为例手算 $dp$：长度 $1$ 为 $1,2,3,4$；长度 $2$：$dp_{01}=3-\min(2,1)=2$，$dp_{12}=5-\min(3,2)=3$，$dp_{23}=7-\min(4,3)=4$；长度 $3$：$dp_{02}=6-\min(3,2)=4$，$dp_{13}=9-\min(4,3)=6$；长度 $4$：$dp_{03}=10-\min(6,4)=6$。先手 $6$、后手 $4$，与程序一致。四组全部吻合。

## 二、思维链：完整证明

**记号。** 序列 $a_0,\dots,a_{N-1}$（$1\le a_i\le200$）。前缀和 $s_k=\sum_{t<k}a_t$，区间和 $\mathrm{sum}(i,j)=s_{j+1}-s_i=\sum_{t=i}^{j}a_t$，总和 $S=s_N$。定义 $dp[i][j]$（$0\le i\le j<N$）为「轮到取数的人从区间 $[i,j]$ 出发、双方均最优时能获得的总分」。

---

### 引理 1（零和 / 总分固定）

无论双方如何取数，游戏结束时先手得分 $+$ 后手得分 $=S$。因此在任何子区间上，「当前行动者得分」与「另一人得分」之和等于该区间和；最大化自己得分等价于最小化对手得分。

*证明*：每个数恰好被取走一次（取后从序列移除），且只累加到取它的人的得分。所有数都被取完，故两人得分之和 $=\sum_{t=0}^{N-1}a_t=S$，与取法无关。对子区间 $[i,j]$ 同理：从它开始把数取完，两人（在子游戏里）得分之和 $=\mathrm{sum}(i,j)$。于是「行动者得分 $=\mathrm{sum}(i,j)-$ 另一人得分」，行动者要最大化自己就要最小化另一人。证毕。

---

### 引理 2（博弈值存在且由递推唯一确定）

$dp[i][j]$ 良定义（有限、完全信息、零和博弈必有确定的最优值），且满足
$$dp[i][i]=a_i,\qquad dp[i][j]=\mathrm{sum}(i,j)-\min\bigl(dp[i+1][j],\ dp[i][j-1]\bigr)\ (i<j).$$

*证明*：对区间长度 $L=j-i+1$ 归纳。

**基础 $L=1$**：区间 $[i,i]$ 只剩一个数 $a_i$，轮到的人必须取它（只能取端点，两端是同一个），得 $a_i$，无后续。故 $dp[i][i]=a_i$。

**归纳 $L\ge2$**：设所有长度 $<L$ 的区间的 $dp$ 已良定义且等于其博弈值。考虑 $[i,j]$（长度 $L$），当前行动者（记为 P）只有两种合法动作：取左端 $a_i$ 或取右端 $a_j$。

- **P 取左端 $a_i$**：剩余区间 $[i+1,j]$（长度 $L-1$），轮到对手 Q 行动。由归纳假设，子游戏 $[i+1,j]$ 的博弈值为 $dp[i+1][j]$，即双方最优时**行动者 Q** 获得 $dp[i+1][j]$。由引理 1（零和），P 在该子游戏里获得 $\mathrm{sum}(i+1,j)-dp[i+1][j]$。加上 P 刚取的 $a_i$，P 的总分为
$$a_i+\mathrm{sum}(i+1,j)-dp[i+1][j]=\mathrm{sum}(i,j)-dp[i+1][j].$$
- **P 取右端 $a_j$**：对称地，P 总分 $=\mathrm{sum}(i,j)-dp[i][j-1]$。

P 最优 ⇒ 在两个动作里选使自己总分最大的；Q 在子游戏里也最优 ⇒ 子游戏值正是 $dp[i+1][j]$（或 $dp[i][j-1]$），这已被归纳假设保证。故
$$dp[i][j]=\max\bigl(\mathrm{sum}(i,j)-dp[i+1][j],\ \mathrm{sum}(i,j)-dp[i][j-1]\bigr)=\mathrm{sum}(i,j)-\min\bigl(dp[i+1][j],dp[i][j-1]\bigr).$$

良定义性：游戏有限（每步序列长度减 $1$，至多 $N$ 步结束）、完全信息（双方都知道序列与历史）、零和（引理 1），由 backward induction（Zermelo 定理的有限情形）知最优值存在且唯一，上述归纳正是构造它。证毕。

**注（为什么「$\mathrm{sum}-$ 对手最优」是对的）**：关键是引理 1 的零和——剩余区间的总和固定，对手作为剩余区间的行动者拿到 $dp[\text{剩余}]$，我就拿到「剩余总和 $-dp[\text{剩余}]$」，再加上我先取的那个数，恰好合并成「整个区间和 $-dp[\text{剩余}]$」。若不是零和（比如取数还有额外代价），这个简洁形式就不成立。

---

### 引理 3（计算顺序 / 无后效性）

按区间长度 $L=1,2,\dots,N$ 递增、同长度内左端点 $i$ 递增的顺序计算，所有依赖均已就绪。

*证明*：$dp[i][j]$（长度 $L$）依赖 $dp[i+1][j]$ 与 $dp[i][j-1]$，二者长度均为 $L-1<L$，在上一轮外层循环已全部算出。长度 $1$ 的 $dp[i][i]=a_i$ 直接初始化。故按长度递增是合法的拓扑序，对 $L$ 归纳即得整表正确。证毕。

---

### 引理 4（答案提取）

先手最终得分 $=dp[0][N-1]$，后手最终得分 $=S-dp[0][N-1]$。

*证明*：游戏从整个区间 $[0,N-1]$ 开始，先手是第一个行动者。由 $dp$ 的定义，双方最优时先手获得 $dp[0][N-1]$。由引理 1，后手获得 $S-dp[0][N-1]$。证毕。

---

### 引理 5（值域与复杂度）

所有 $dp$ 值与中间量在 `int` 范围内；时间 $O(N^2)$，空间 $O(N^2)$。

*证明*：$0\le dp[i][j]\le\mathrm{sum}(i,j)\le S\le100\times200=20000$，前缀和 $s_k\le20000$，均远小于 `int` 上限，无溢出（本题全为正整数，$dp$ 非负，无需哨兵）。状态数 $\frac{N(N+1)}2=O(N^2)$，每个 $O(1)$ 转移（一次减法、一次 $\min$、一次前缀和差），故时间 $O(N^2)$；$N=100$ 时约 $5050$ 个状态，极快。空间：$dp$ 为 $N^2$ 个 `int`，$a,s$ 各 $N$ 个，共 $O(N^2)$，约 $105^2\times4\approx44$ KB。证毕。

---

### 定理

程序输出双方最优策略下先手与后手的最终得分。

*证明*：引理 1 确立零和结构；引理 2 证明 $dp$ 良定义且递推正确（含基础与归纳两步）；引理 3 保证按长度递增求值合法；引理 4 把整区间博弈值映射到先手/后手得分；引理 5 保证不溢出且在时限内。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 取数只从两端 ⇒ 任何时刻剩余都是连续区间，天然适合区间 DP。
- **consider easier version** — 先试贪心「取较大端点」，用 $[3,9,1,2]$ 反例（贪心 $5$ vs 最优 $11$）证明它错：取数会暴露大数给对手。
- **explore its property** — 总分固定 ⇒ 零和博弈，「我最大」=「对手最小」，只需记录行动者得分。
- **classic problem solution** — 区间 DP / minimax：$dp[i][j]=\mathrm{sum}(i,j)-\min(dp[i+1][j],dp[i][j-1])$，「我拿一个端点，对手在剩余里最优」。
- **reduce to easier problem** — 用前缀和把区间和 $O(1)$ 化；答案 $=dp[0][N-1]$ 与 $S-dp[0][N-1]$，无需记录两人分数。
- **discuss by category** — 按区间长度递增递推保证无后效；全正整数 ⇒ $dp$ 非负、`int` 足够、无需哨兵。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 序列长度 $N$（$\le100$） | `int`，读入 | |
| `a[i]` | 第 $i$ 个数（$0$-based，$1..200$） | `int[mxn]`，读入 | |
| `s[k]` | 前缀和 $\sum_{t<k}a_t$ | `int[mxn]`，`s[0]=0` | $\mathrm{sum}(i,j)=s[j+1]-s[i]$ |
| `dp[i][j]` | 行动者从 $[i,j]$ 双方最优能拿的总分 | `int[mxn][mxn]` | 「轮到的人」的得分，非先手专属 |
| `len` | 当前枚举的区间长度 | `int`，$2..n$ | 外层递增保证无后效 |
| `first` | 先手得分 $=dp[0][n-1]$ | `int` | 后手 $=s[n]-first$ |
| `mxn` | $100+5$ | `constexpr int{105}` | +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 `n` 与 `a[0..n-1]`，同时递推前缀和 `s[i+1]=s[i]+a[i]`。
3. 初始化 `dp[i][i]=a[i]`。
4. 外层 `len=2..n`，内层枚举左端 `i`（右端 `j=i+len-1<n`）：`dp[i][j]=s[j+1]-s[i]-min(dp[i+1][j],dp[i][j-1])`。
5. `first=dp[0][n-1]`，输出 `first` 与 `s[n]-first`。

### 复杂度

- 时间：$O(N^2)$，$N=100$ 时约 $5050$ 个状态。
- 空间：$O(N^2)$，$dp$ 约 $44$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；贪心反例 `3 9 1 2` 输出 `11 4`；`1 2 → 2 1`、`5 5 → 5 5`、`1 2 3 4 → 6 4`（手算 $dp$ 表核对）全对。本题为经典区间 DP，未写暴力对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2734 [IOI 1996 / USACO3.3] 游戏 A Game
// 思路：区间 DP。dp[i][j] = 轮到取数的人从区间 [i,j] 能拿到的最大总分（双方最优）。
//       取左端 a[i] 后对手在 [i+1,j] 拿 dp[i+1][j]，我得 sum-dp[i+1][j]；取右端同理。
//       dp[i][j]=sum(i,j)-min(dp[i+1][j],dp[i][j-1])，按区间长度递增递推。
//       先手=dp[0][n-1]，后手=总和-先手。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n,a[mxn],s[mxn],dp[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		s[i+1]=s[i]+a[i];	// 前缀和，sum(i,j)=s[j+1]-s[i]
	}
	for(int i=0;i<n;++i)
		dp[i][i]=a[i];
	for(int len=2;len<=n;++len)
		for(int i=0,j;(j=i+len-1)<n;++i)
			dp[i][j]=s[j+1]-s[i]-min(dp[i+1][j],dp[i][j-1]);
	int first=dp[0][n-1];
	cout<<first<<' '<<s[n]-first<<'\n';
	return 0;
}
```

### 代码说明

- **`dp[i][j]` 是「行动者」得分，不是「先手」得分**：规则对两人对称，谁轮到谁就是行动者。这个视角让转移只需一个数组——取走端点后，对手变成剩余区间的行动者，我拿「区间和 − 对手最优」。
- **`s[j+1]-s[i]` 是区间和**：前缀和 $O(1)$ 求 $\mathrm{sum}(i,j)$，避免每次转移重新累加。
- **`for(int i=0,j;(j=i+len-1)<n;++i)`**：把右端 `j` 的赋值写进循环条件，`i` 递增时 `j` 同步右移，条件 `j<n` 自动界定合法左端范围，省去内层再写 `j` 的边界。
- **按 `len` 递增**：`dp[i+1][j]`、`dp[i][j-1]` 都是长度 `len-1` 的区间，上一轮已算好，无后效（引理 3）。
- **全正整数 ⇒ 无需哨兵**：$dp$ 恒非负且 $\le20000$，`int` 足够；这与「不可达状态要填 INF」的题不同，这里所有状态都可达。
- 下标 $0$-based：读入 `a[0..n-1]`，答案 `dp[0][n-1]`，输出得分本身无需 $\pm1$。
