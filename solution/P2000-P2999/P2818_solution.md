# P2818 天使的起誓 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 个宝盒顺时针围成一圈，编号 $1,2,\dots,n$。天使手上的数字是 $m$，她的发言稿在"从 $1$ 号盒子开始按顺时针方向数的第 $m$ 个"盒子里。求这个盒子的编号。范围：$2\le n\le 10^8$，$2\le m\le 10^{1000}$。标签只有"高精度"三个字。

也就是说：$n$ 是个普通 `int`，$m$ 是个**最多 $1001$ 位**的十进制 giant。整道题的难点全部集中在"$m$ 太大"这一件事上。

### 第一步：先把"数盒子"翻译成算式，顺便排掉一个读题陷阱

题面花了不少笔墨写"一开始天使们站在编号为 $n$ 的宝盒旁"。这句话非常容易被读成"数数的起点是 $n$ 号盒"。于是有两种候选解读：

- **解读 A**：$1$ 号盒是第 $1$ 个，$2$ 号盒是第 $2$ 个，……，$n$ 号盒是第 $n$ 个，$n+1$ 个又回到 $1$ 号盒。即第 $m$ 个是 $((m-1)\bmod n)+1$。
- **解读 B**：站在 $n$ 号盒旁，所以 $n$ 号盒是第 $1$ 个，$1$ 号盒是第 $2$ 个，……。即第 $m$ 个是 $((m-2)\bmod n)+1$（$m\ge 2$ 时）。

哪个对？**题面自带的例子就是裁判**：$n=7$、$m=9$ 时答案是 $2$。

- 解读 A：$((9-1)\bmod 7)+1=(8\bmod 7)+1=1+1=2$ ✓。
- 解读 B：序列是 $7,1,2,3,4,5,6,7,1,\dots$，第 $9$ 个是 $1$ ✗。

一个例子就把 B 打死了。而且回头看原文，"代表她们自己的发言稿所在的盒子是**从 $1$ 号盒子开始**按顺时针方向的第几个"这半句本来就明说了起点是 $1$ 号盒；"站在 $n$ 号盒旁"只是场景描写（顺便解释了为什么 Tenshi 手上的数字小就"一下子就找到了"）。**这是本题第一个必须显式确认的口径**，我按解读 A 实现。

于是问题变成：算 $((m-1)\bmod n)+1$。

### 第二步：$m$ 装不下，怎么办

$10^{1000}$ 有 $1001$ 位。`long long` 只有约 $19$ 位，`__int128` 也只有约 $38$ 位，差着几十个数量级。所以 $m$ **必须以字符串读入**，这一点没有商量余地。

接下来是本题真正的思维跳跃：**我要的从来不是 $m$ 本身，而是 $m\bmod n$。**

如果傻乎乎地写一套高精度：先把 $m$ 存成数组，再高精度减 $1$，再高精度除以 $n$ 取余——那是几百行的除法竖式，而这题只问一个余数。既然只要余数，就可以**边读边取模**，把 $1001$ 位的大数在手里"压缩"成一个 $\le n-1$ 的小余数：

$$r\leftarrow 0,\qquad \text{每读到一个数位 } d:\quad r\leftarrow (10r+d)\bmod n.$$

这就是秦九韶（Horner）求值套上模运算。它的合法性来自"模运算对加法、乘法都是同态"：一个数在模 $n$ 意义下的值，可以在只保留余数的情况下逐位算出来，**不需要知道这个数本身**。于是"高精度"标签被降级成了"高精度取模"这一条最轻量的运算，全程只用一个 `long long`。

### 第三步：余数是 $0$ 的时候，答案不是 $0$

盒子编号是 $1..n$，不是 $0..n-1$。这是第二个坑，而且是最容易 WA 的一个。

最小反例：$n=7$、$m=7$。数 $7$ 个盒子恰好走完一整圈，落在 $7$ 号盒；但 $7\bmod 7=0$，如果直接输出余数就会输出 $0$——一个不存在的盒子。

正确的映射是：

$$\text{答案}=\begin{cases}n,& m\bmod n=0\\ m\bmod n,&\text{否则}\end{cases}$$

它和 $((m-1)\bmod n)+1$ 完全等价（下面引理 4 会证），但写成 `r?r:n` 只有一个三目运算符，连"$m-1$"这次高精度减法都省掉了——**这也是"只要余数"思路的额外红利**：如果按 $((m-1)\bmod n)+1$ 字面实现，还得先对 $1001$ 位的串做减 $1$（要处理借位、前导零），而按 $m\bmod n$ 分类讨论就完全绕开了它。

### 第四步：中间量会不会溢出

$n\le 10^8$，所以任意时刻 $r\le n-1\le 99999999$，于是

$$10r+d\le 10\times 99999999+9=999999999<2^{31}-1=2147483647.$$

`int` 其实就够。但我还是用 `i64`：一来 $10^9$ 距离 `int` 上限只剩 $2$ 倍余量，二来 `r*10` 这种写法一旦把 $n$ 的上界看错一位就会静默溢出，用 $64$ 位是零成本的保险（$10^{10}$ 量级对 `i64` 来说毫无压力）。

### 第五步：读入的健壮性

`cin>>m` 按空白切分，所以 $m$ 单独一行、和 $n$ 同一行、行末有 `\r`（Windows 数据）都能正确读到。循环里我只处理 `'0'..'9'` 的字符，其他字符（万一有前导 `+`、或者数据里混进了什么分隔符）直接跳过，不影响结果。前导零也无害：$r$ 从 $0$ 开始，多乘几次 $10$ 加 $0$ 仍然是 $0$。

### 手造数据核对（题面没有给样例输入输出，只有那句 $n=7,m=9\to 2$ 的说明）

| $n$ | $m$ | $m\bmod n$ | 输出 | 手算理由 |
|---|---|---|---|---|
| $7$ | $9$ | $2$ | `2` | 题面例子，第 $8$ 个回到 $1$ 号、第 $9$ 个是 $2$ 号 |
| $7$ | $7$ | $0$ | `7` | 恰好一整圈，落在 $n$ 号盒（余数 $0$ 的坑） |
| $7$ | $8$ | $1$ | `1` | 一圈多一个 |
| $2$ | $2$ | $0$ | `2` | 最小规模 |
| $3$ | $\underbrace{10\cdots0}_{1001\text{ 位}}$ | $1$ | `1` | $10\equiv1\pmod 3\Rightarrow 10^{1000}\equiv1$，极限位数 |
| $10^8$ | $10^{1000}$ | $0$ | `100000000` | $10^{1000}$ 被 $10^8$ 整除，极限 $n$ + 极限位数 |

最后两行专门打"$1001$ 位"和"$n=10^8$"两个上界，手算就能验证，不需要任何对拍程序。

## 二、思维链：完整证明

**记号。** 盒子编号集合 $\{1,\dots,n\}$，$n\ge 2$。$m$ 的十进制表示为数字串 $d_0d_1\cdots d_{L-1}$（$d_0$ 是最高位，$L\le 1001$），其值 $M=\sum_{i=0}^{L-1}d_i\cdot 10^{L-1-i}$。定义前缀值

$$M_i=\sum_{j=0}^{i}d_j\cdot 10^{i-j}\quad(0\le i\le L-1),\qquad M_{-1}=0,$$

即前 $i+1$ 位组成的整数，显然 $M_{L-1}=M$。程序维护的余数记为 $r_i$，初值 $r_{-1}=0$，递推 $r_i=(10r_{i-1}+d_i)\bmod n$。

---

### 引理 1（数盒子的公式；并排除"从 $n$ 号盒起数"的解读）

按题面"从 $1$ 号盒子开始按顺时针方向的第 $m$ 个"，第 $m$ 个盒子的编号为

$$B(m)=((m-1)\bmod n)+1.$$

*证明*：顺时针数盒子得到的序列是 $a_1,a_2,a_3,\dots$，其中 $a_k$ 表示第 $k$ 个盒子的编号。由"从 $1$ 号开始、顺时针、编号递增到 $n$ 后回到 $1$"得

$$a_k=\begin{cases}k,&1\le k\le n\\ a_{k-n},&k>n\end{cases}$$

即序列以 $n$ 为周期，且一个周期内 $a_1..a_n=1..n$。对任意 $m\ge 1$，由带余除法写 $m-1=qn+s$，$q\ge 0$，$0\le s<n$，则 $m=qn+s+1$。反复用周期性 $a_{k}=a_{k-n}$ 共 $q$ 次得 $a_m=a_{s+1}$；而 $1\le s+1\le n$，故 $a_{s+1}=s+1=((m-1)\bmod n)+1$。证毕。

**排除另一种解读**：若把"站在 $n$ 号盒旁"误读成起点，则序列为 $a'_1=n,a'_2=1,\dots$，即 $a'_k=((k-2)\bmod n)+1$（$k\ge1$，模运算取非负余数）。代入题面例子 $n=7,m=9$：$a'_9=((9-2)\bmod 7)+1=(7\bmod 7)+1=0+1=1\ne 2$。而题面明确说答案是 $2$，故该解读与题面矛盾，必须舍弃。解读 A 代入得 $((9-1)\bmod 7)+1=2$，与题面一致。证毕。

---

### 引理 2（模运算对加法、乘法的同态性）

对任意整数 $a,b$ 与正整数 $n$：

(a) $(a+b)\bmod n=\bigl((a\bmod n)+(b\bmod n)\bigr)\bmod n$；
(b) $(a\cdot b)\bmod n=\bigl((a\bmod n)\cdot(b\bmod n)\bigr)\bmod n$。

这里 $x\bmod n$ 指非负最小余数（$0\le x\bmod n<n$）。

*证明*：由带余除法写 $a=q_1n+\alpha$、$b=q_2n+\beta$，其中 $\alpha=a\bmod n$、$\beta=b\bmod n$，$0\le\alpha,\beta<n$。

(a) $a+b=(q_1+q_2)n+(\alpha+\beta)$。再对 $\alpha+\beta$ 做带余除法：$\alpha+\beta=q_3n+\gamma$，$0\le\gamma<n$，则 $a+b=(q_1+q_2+q_3)n+\gamma$。由余数的唯一性，$(a+b)\bmod n=\gamma=(\alpha+\beta)\bmod n$，即 (a)。

(b) $a\cdot b=(q_1n+\alpha)(q_2n+\beta)=n(q_1q_2n+q_1\beta+q_2\alpha)+\alpha\beta$。同理 $\alpha\beta=q_4n+\delta$，$0\le\delta<n$，故 $a\cdot b=n(\cdots)+\delta$，得 $(a\cdot b)\bmod n=\delta=(\alpha\beta)\bmod n$，即 (b)。证毕。

**这条引理是"边读边取模"的全部合法性来源**：它说明"先取余再运算"与"先运算再取余"结果相同，因此我们可以在每一步都把中间值压回 $[0,n)$，而不会改变最终余数。

---

### 引理 3（逐位 Horner 取模的不变量）

对所有 $-1\le i\le L-1$，程序执行完第 $i$ 位的处理后有 $r_i=M_i\bmod n$。特别地，读完全部数位后 $r_{L-1}=M\bmod n$。

*证明*：对 $i$ 归纳。

**基础** $i=-1$：$r_{-1}=0$，$M_{-1}=0$，$0\bmod n=0$ ✓。

**归纳步**：设 $r_{i-1}=M_{i-1}\bmod n$。由前缀值的定义，

$$M_i=\sum_{j=0}^{i}d_j10^{i-j}=10\sum_{j=0}^{i-1}d_j10^{(i-1)-j}+d_i=10M_{i-1}+d_i.$$

（$i=0$ 时求和为空，$M_0=d_0=10\cdot 0+d_0$，式子仍成立。）于是由引理 2(a) 与 (b)：

$$M_i\bmod n=(10M_{i-1}+d_i)\bmod n=\bigl((10\bmod n)(M_{i-1}\bmod n)+(d_i\bmod n)\bigr)\bmod n.$$

程序算的是 $r_i=(10r_{i-1}+d_i)\bmod n$。对它同样用引理 2(a)(b) 展开：

$$r_i=\bigl((10\bmod n)\cdot(r_{i-1}\bmod n)+(d_i\bmod n)\bigr)\bmod n.$$

由循环不变量 $0\le r_{i-1}<n$ 得 $r_{i-1}\bmod n=r_{i-1}$；再代入归纳假设 $r_{i-1}=M_{i-1}\bmod n$，上式右端与 $M_i\bmod n$ 的展开式**逐项相同**，故

$$r_i=(10r_{i-1}+d_i)\bmod n=M_i\bmod n.$$

归纳完成。取 $i=L-1$ 即得 $r_{L-1}=M\bmod n$。证毕。

**注（$n$ 很小时也正确）**：上面刻意没有假设 $d_i<n$。程序做的是"整数乘加之后整体 `%n`"，引理 2 对任意整数都成立，所以 $n=2$、$d_i=9$ 这类情形自动正确，不需要任何特判。

**注（前导零 / 非数字字符）**：若串首有若干 `'0'`，则对应的 $M_i$ 前缀值不变（$10\cdot 0+0=0$），余数也不变，故前导零无害。程序跳过非数字字符，等价于把它们从串中删除，而删除非数字字符不改变 $M$ 的十进制值（题面保证 $m$ 是正整数的十进制表示）。

---

### 引理 4（余数到盒子编号的映射）

设 $r=M\bmod n$。则

$$B(M)=\begin{cases}n,&r=0\\ r,&r\ne 0\end{cases}$$

即程序的 `cout<<(r?r:n)` 正确。

*证明*：由引理 1，$B(M)=((M-1)\bmod n)+1$。写 $M=qn+r$，$0\le r<n$。

**情形 A：$r\ge 1$。** 则 $M-1=qn+(r-1)$，且 $0\le r-1<n$，由余数唯一性 $(M-1)\bmod n=r-1$，故 $B(M)=(r-1)+1=r$ ✓。

**情形 B：$r=0$。** 则 $M=qn$。因 $M\ge 2>0$ 故 $q\ge 1$，于是 $M-1=(q-1)n+(n-1)$，且 $0\le n-1<n$（$n\ge2$），故 $(M-1)\bmod n=n-1$，$B(M)=(n-1)+1=n$ ✓。

两情形穷尽（$r$ 要么为 $0$ 要么在 $[1,n-1]$）。证毕。

**推论**：不需要对 $1001$ 位的串做"减 $1$"的高精度减法。字面公式 $((m-1)\bmod n)+1$ 与分类公式 `r?r:n` 等价，后者只用到 $m\bmod n$。

---

### 引理 5（中间量不溢出，位数上界足够）

程序全程 $0\le r<n\le 10^8$，故每次计算的 $10r+d\le 10(10^8-1)+9=999999999<2^{31}-1$；用 `i64` 存储时上界为 $2^{63}-1\approx9.22\times10^{18}$，余量约 $9.2\times10^9$ 倍。字符串长度 $L\le 1001$，`int` 型的下标与 `size()` 均无溢出风险。

*证明*：由引理 3 的递推，$r_i$ 是模 $n$ 的余数，故 $0\le r_i\le n-1$ 恒成立（这是循环不变量）。代入 $n\le10^8$、$d\le9$ 即得 $10r+d\le 999999999$。与 $2^{31}-1=2147483647$ 比较知 `int` 亦不溢出；`i64` 更宽。$m\le 10^{1000}$ 意味着 $m$ 最多 $1001$ 位（$10^{1000}$ 本身是 $1$ 后面 $1000$ 个 $0$），`std::string` 存 $1001$ 个字符毫无压力。证毕。

---

### 引理 6（复杂度）

时间 $O(L)$，空间 $O(L)$，其中 $L\le 1001$ 是 $m$ 的位数。

*证明*：读入 $n$ 是 $O(1)$；读入 $m$ 是 $O(L)$；循环恰好遍历字符串一次，每次做常数次 $64$ 位乘法、加法、取模（$n$ 固定，硬件除法常数时间），故 $O(L)$。空间只有字符串本身 $O(L)$ 与常数个变量。代入 $L=1001$：约一千次运算，远远低于任何时限。证毕。

---

### 定理

程序输出天使想找的宝盒编号，且对 $2\le n\le10^8$、$2\le m\le10^{1000}$ 的全部数据正确。

*证明*：引理 1 把题意（并用题面例子排除了歧义解读）化为 $((m-1)\bmod n)+1$；引理 2、3 保证逐位 Horner 得到的 $r$ 恰为 $m\bmod n$，与 $m$ 的位数无关；引理 4 保证 `r?r:n` 与 $((m-1)\bmod n)+1$ 等价；引理 5 保证全程无溢出；引理 6 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 圆上顺时针数第 $m$ 个 $=((m-1)\bmod n)+1$：周期为 $n$ 的编号序列，本质是一次取模。
2. **discuss by category** — "站在 $n$ 号盒旁"是场景描写还是数数起点？用题面例子 $n=7,m=9\to2$ 判别，排除起点为 $n$ 的解读。
3. **consider easier version** — 若 $m$ 装得进整数，一行 `(m-1)%n+1` 就完事；困难只来自 $m$ 有 $1001$ 位。
4. **reduce to easier problem** — 要的是 $m\bmod n$ 而不是 $m$ ⇒ 高精度四则运算全套降级为"逐位取模"，且连"减 $1$"都省掉。
5. **classic problem solution** — 大数取模（Horner/秦九韶）：`r=(r*10+d)%n`，合法性来自模运算对加乘的同态性。
6. **discuss by category** — 余数 $0$ 对应 $n$ 号盒而不是 $0$ 号盒：`r?r:n`，$1$-based 编号的经典坑。
7. **explore its property** — 中间量上界 $10(n-1)+9<10^9$，`int` 勉强够、`i64` 零成本保险。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $n$ | 宝盒个数，$2\le n\le10^8$ | `int n` | 读入；也是模数 |
| $m$ | 天使手上的数字，$\le10^{1000}$（$1001$ 位） | `string m` | **必须字符串读入**，任何整数类型都装不下 |
| $L$ | $m$ 的位数 | `m.size()` | $\le1001$ |
| $d_i$ | 第 $i$ 位数字（$0$-based，左高右低） | `char ch` | 只处理 `'0'..'9'`，其余字符跳过 |
| $M_i$ | 前 $i+1$ 位组成的整数值 | 数学量，不落地 | $M_i=10M_{i-1}+d_i$ |
| `r` | 当前前缀的余数 $M_i\bmod n$ | `i64` | 初值 $0$；**循环不变量 $0\le r<n$** |
| 输出 | 盒子编号 $B(m)\in[1,n]$ | `i64` | `r?r:n`：余数 $0$ 表示整圈，落在 $n$ 号盒 |

### 算法步骤

1. I/O 加速三行（`cin.tie` → `cout.tie` → `sync_with_stdio`）。
2. 读 `n`，读字符串 `m`。
3. `r=0`；从左到右遍历 `m` 的每个字符 `ch`：若是数字，`r=(r*10+ch-'0')%n`。
4. 输出 `r?r:n` 与 `'\n'`。

### 复杂度

- 时间：$O(L)$，$L\le1001$，约一千次 $64$ 位乘加取模。
- 空间：$O(L)$，只有输入字符串；额外工作空间 $O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子 $n=7,m=9$ 输出 `2` 与说明一致；另跑 $9$ 组手造/边界数据（余数 $0$、最小 $n=2$、$1001$ 位极限、$n=10^8$ 极限、$1001$ 个 $9$），其中大数用例与独立 BigInt 逐位取模结果一致。本题是"一条公式 + 大数取模"的入门题，逻辑一目了然，不建对拍附录。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2818 天使的起誓
// 第 m 个盒子 = ((m-1) mod n)+1，等价于 r=m mod n 后输出 (r?r:n)
// m 最多 1001 位 ⇒ 字符串读入；只要余数 ⇒ 逐位 Horner 取模，不需要高精度除法
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int n;
string m;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	i64 r=0;
	for(char ch:m)
		if(ch>='0'&&ch<='9')
			r=(r*10+ch-'0')%n;	// 不变量 0<=r<n；中间量 <=10(n-1)+9<1e9
	cout<<(r?r:n)<<'\n';		// 余数 0 = 恰好整圈，落在 n 号盒而非 0 号盒
	return 0;
}
```

### 代码说明

- **没有高精度数组**：只要 $m\bmod n$，一个 `i64 r` 就把 $1001$ 位大数"在线压缩"掉了。这是本题唯一需要的技巧。
- `r=(r*10+ch-'0')%n` 是**先乘加再整体取模**，由引理 2 它与"每步都取模"等价，所以 $n\le 9$、数位 $d\ge n$ 的情形也自动正确，无需特判。
- `r?r:n` 而不是 `r`：盒子编号 $1$-based，$m$ 是 $n$ 的倍数时余数为 $0$，答案是 $n$。这是本题最常见的 WA 点。
- 也没有做 $m-1$：引理 4 证明了分类映射与 $((m-1)\bmod n)+1$ 等价，省掉一次 $1001$ 位的高精度减法（借位、前导零都是坑）。
- `for(char ch:m)` 里只认数字字符，前导零与意外空白都不影响结果。
- 用 `i64` 而非 `int`：$10(n-1)+9$ 最大 $999999999$，`int` 只剩 $2$ 倍余量，$64$ 位是零成本保险。
- 输出 `'\n'`，不用 `endl`。
