# P2426 删数 — 题解

## 一、解题过程：人类思考叙事

题目：$N$ 个**互不相同**的正整数 $x_1,\dots,x_N$ 排成一排。每次操作从当前序列的**最左或最右**删去连续的 $i$ 个数，删去位置 $i..k$ 这一段的价值是 $|x_i-x_k|\times(k-i+1)$；若只删一个数，价值就是那个数本身。反复操作直到删空，求**总价值的最大值**。$3\le N\le100$，$1\le x_i\le1000$。

**第一眼的错觉：这是个"过程题"。** 删左边还是删右边、先删哪段，似乎都会影响后续能删什么，像个要搜索/贪心的交互过程。我试着想"每次删价值最大的一段"的贪心，但很快发现不对：删掉一段会改变剩下的序列，局部最大未必全局最大，而且"价值"还依赖删除顺序……等等，**真的依赖顺序吗？**

**关键观察一：剩下的永远是原序列的一个连续子段。** 初始是 $[1,N]$。每次只从两端删，删完剩下 $[l+i,r]$ 或 $[l,r-i]$，仍是连续子段。归纳可知整个过程中"当前序列"始终是原数组的某个连续区间。

**关键观察二：每次删掉的块，价值只由它自己决定。** 既然当前序列是连续子段，从它左端或右端删去的连续块，对应原数组的一段 $[a,b]$。这一段的值是 $|x_a-x_b|\times(b-a+1)$（单元素时为 $x_a$）——**只跟这段的首尾值和长度有关，跟它什么时候被删、邻居是谁完全无关**。

**于是整个过程被"拍扁"了：** 所有被删的块两两不交、并起来是 $[1,N]$，即它们构成原数组的一个**连续段划分**。总价值 = 各段价值之和，**与删除顺序无关**！题目从"动态删数过程"变成了"静态地把数组切成若干连续段，使段价值和最大"。

**用样例验证这个理解。** 样例序列 $54,29,196,21,133,118$，最优是切成 $[54,29,196]$、$[21,133]$、$[118]$ 三段：
- $[54,29,196]$：$|54-196|\times3=426$；
- $[21,133]$：$|21-133|\times2=224$；
- $[118]$：单元素，$118$。
合计 $426+224+118=768$，与样例说明一致。注意这三段在原数组里就是连续划分的三块，删除时先删左块、再删右块、再删中间即可——顺序不影响总和。

**还要确认：任何连续划分都"删得出来"吗？** 能。把划分的最左段先从左边删掉，它正是当前序列的前缀；再删下一段……每段都是当时序列的前缀，合法。所以"最大总价值"恰好等于"所有连续划分中段价值和的最大值"，不多不少。

**怎么求最大划分？区间 DP。** 设 $f[l][r]$ 为把子段 $[l,r]$ 划分成若干连续段的最大价值和。枚举**最左段** $[l,k]$，剩下 $[k+1,r]$ 递归：
$$f[l][r]=\max_{l\le k\le r}\big(\text{val}(l,k)+f[k+1][r]\big),\quad f[r+1][r]=0.$$
按区间长度从小到大递推，$O(N^3)$，$N=100$ 时约 $1.7\times10^5$ 次转移，绰绰有余。（其实还能写成前缀 DP $O(N^2)$，但区间 DP 更贴合"删数"的结构，且本题规模完全够用。）

**一个必须特判的坑：单元素段。** 价值公式 $|x_l-x_r|\times(r-l+1)$ 在 $l=r$ 时给 $0$，但题目规定"只删一个数时价值是这个数本身"，即 $x_l$。所以 $\text{val}(l,l)=x_l$，绝不能套通用公式。

## 二、思维链：完整证明

**引理 1（连续子段不变量）**：任何时刻，当前剩余序列都是原数组的一个连续子段 $[l,r]$。

*证明*：对操作次数归纳。初始 $[1,N]$ 是连续子段。设某次操作前为 $[l,r]$，从左边删 $i$ 个得 $[l+i,r]$，从右边删 $i$ 个得 $[l,r-i]$（删空则为空段），都仍是连续子段。故归纳成立。证毕。

**引理 2（删除块构成连续划分，且总价值与顺序无关）**：一次完整删除过程产生的各块 $B_1,\dots,B_k$ 是原数组的一个连续段划分；总价值等于 $\sum_{j}\text{val}(B_j)$，与删除顺序无关。

*证明*：由引理 1，每块都是当时连续子段的一个前缀或后缀，故对应原数组的连续区间。各块按删除时刻两两不交（删过的不再出现），且最终删空，故并集为 $[1,N]$——即一个连续段划分。每块 $B_j=[a,b]$ 的价值 $\text{val}(B_j)$ 按题意只由 $x_a,x_b$ 与长度 $b-a+1$ 决定（单元素时为 $x_a$），这些都是原数组的固定量，与该块何时被删、其它块是谁无关。因此总价值 $=\sum_j\text{val}(B_j)$，只是划分本身的函数，与删除顺序无关。证毕。

**引理 3（任何连续划分都可实现）**：设 $[1,N]$ 被划分为连续段 $S_1,\dots,S_k$（从左到右），则存在合法删除过程恰好依次删去这些段。

*证明*：构造：第 $j$ 步从当前序列**左端**删去 $S_j$。由引理 1 的逆过程，删去 $S_1,\dots,S_{j-1}$ 后剩余恰为 $S_j\cup\dots\cup S_k$，而 $S_j$ 是它的最左连续段，即一个前缀，符合"从左边删连续 $|S_j|$ 个数"。故每步合法，$k$ 步删空。证毕。

**引理 4（问题等价于最大权连续划分）**：答案 $=\max\big\{\sum_j\text{val}(S_j): \{S_j\}\text{ 是 }[1,N]\text{ 的连续段划分}\big\}$。

*证明*：由引理 2，任何删除过程的总价值等于其对应划分的段价值和，故答案 $\le$ 右式（每个过程对应一个划分）。由引理 3，任何划分都能被某过程实现，且由引理 2 该过程总价值恰为该划分的段价值和，故答案 $\ge$ 右式。两边夹逼得等号。证毕。

**引理 5（单元素价值）**：$\text{val}(l,r)=\begin{cases}x_l,&l=r,\\|x_l-x_r|\cdot(r-l+1),&l<r.\end{cases}$

*证明*：$l<r$ 时删去 $[l,r]$ 共 $r-l+1\ge2$ 个数，按题意价值为两端值之差的绝对值乘长度。$l=r$ 时只删一个数，题意明确规定价值为该数本身 $x_l$（而非 $|x_l-x_l|\cdot1=0$）。证毕。

**引理 6（区间 DP 正确性）**：定义 $f[l][r]$ 为 $[l,r]$ 的最大段价值和（$f[r+1][r]=0$ 表示空段），则
$$f[l][r]=\max_{l\le k\le r}\big(\text{val}(l,k)+f[k+1][r]\big)$$
且按区间长度递增计算可得 $f[1][N]$ 即答案。

*证明*：对区间长度 $\text{len}=r-l+1$ 归纳。$\text{len}=1$：唯一划分是单段 $[l,l]$，$f[l][l]=\text{val}(l,l)=x_l$，递推中 $k=l=r$ 给 $\text{val}(l,l)+f[l+1][l]=x_l+0$，正确。设长度 $<\text{len}$ 的区间都已正确。对长度 $\text{len}$ 的 $[l,r]$，任一连续划分的最左段必为 $[l,k]$（某个 $l\le k\le r$），其余是 $[k+1,r]$ 的一个连续划分。故
$$f[l][r]=\max_{k}\big(\text{val}(l,k)+\underbrace{f[k+1][r]}_{\text{剩余最优}}\big).$$
其中 $[k+1,r]$ 长度 $r-k<\text{len}$，由归纳假设 $f[k+1][r]$ 已是其最优，且按长度递增已先算好。取遍 $k$ 即枚举了所有可能的最左段，故 $f[l][r]$ 正确。最终 $f[1][N]$ 由引理 4 即答案。证毕。

**引理 7（复杂度与数值范围）**：时间 $O(N^3)$，空间 $O(N^2)$；答案可用 `int` 存储。

*证明*：状态数 $O(N^2)$，每个状态枚举 $O(N)$ 个 $k$，故 $O(N^3)$；$N=100$ 时约 $\sum_{\text{len}}(N-\text{len}+1)\cdot\text{len}\approx N^3/6\approx1.7\times10^5$ 次转移。空间为二维表 $O(N^2)$。数值上，每段价值 $\le 999\times\text{段长}$（差 $\le999$）或单元素 $\le1000$，各段长之和为 $N$，故总价值 $\le 999N+1000N<2\times10^5$，远小于 `int` 上限。证毕。

**定理**：算法输出 $f[1][N]$ 即最大总价值。

*证明*：由引理 4 答案等于最大段价值和；由引理 6 区间 DP 正确算出该最大值；引理 5 保证单元素段不被误算为 0。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 只从两端删 ⇒ 剩余永远是连续子段，删掉的块构成原数组的连续划分。
2. **explore its property** — 块价值只由自身首尾与长度决定 ⇒ 总价值与删除顺序无关，"过程题"塌缩成"静态划分题"。
3. **reduce to easier problem** — 顺序删数 → 最大权连续段划分（任何划分都可"从左到右逐段剥"实现）。
4. **classic problem solution** — 区间 DP：枚举最左段 $[l,k]$，$f[l][r]=\max_k(\text{val}(l,k)+f[k+1][r])$。
5. **discuss by category** — 单元素段价值是 $x_l$ 而非 $0$，必须与多元素段分开处理。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|----------------|
| $n$ | 数的个数 | `int` | 输入 |
| $x[i]$ | 第 $i$ 个数（1-based） | `int[]` | 输入 |
| $f[l][r]$ | 把 $[l,r]$ 划分成连续段的最大价值和 | `int[][]` | 按长度递增递推；空段 $f[r+1][r]=0$ |
| $\text{val}(l,r)$ | 删去段 $[l,r]$ 的价值 | 函数 | $l=r$ 返回 $x_l$，否则 $|x_l-x_r|(r-l+1)$ |
| 答案 | $f[1][n]$ | `int` | 全段最优划分 |

### 算法步骤

1. I/O 加速；读 $n$ 与 $x[1..n]$。
2. 按区间长度 $\text{len}=1..n$ 递增：对每个左端 $l$，令 $r=l+\text{len}-1$，置 $f[l][r]=0$；枚举最左段右端 $k=l..r$，用 $\text{val}(l,k)+(k<r?f[k+1][r]:0)$ 更新 $f[l][r]$ 取最大。
3. 输出 $f[1][n]$。

### 复杂度

- 时间 $O(N^3)$（$N\le100$，约 $1.7\times10^5$ 次转移）；空间 $O(N^2)$。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过。
- 题面 Hint 给出的样例 `6 / 54 29 196 21 133 118` → `768`，与说明一致；另手造 `[1,2,3]→6`、`[10,1,10]→28`、`n=1 [7]→7`，均与手算一致。
- 对拍：暴力（递归枚举 $[1,n]$ 的**全部**连续划分取最大段价值和，独立于区间 DP）与标程在 **300 组**随机数据（$N\le8$、$x_i\in[1,1000]$）上比对，全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2426 删数
// 思路：只从两端删 ⇒ 删掉的块是原数组的连续划分，总价值与顺序无关
//       区间 DP：f[l][r]=max_k( val(l,k)+f[k+1][r] )，val 单元素时为 x[l]
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n,x[mxn],f[mxn][mxn];

int val(int l,int r){return l==r?x[l]:abs(x[l]-x[r])*(r-l+1);}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)cin>>x[i];
	// f[l][r]=max total value of partitioning [l,r] into end-removable segments
	for(int len=1;len<=n;++len)
		for(int l=1;l+len-1<=n;++l)
		{
			int r=l+len-1;
			f[l][r]=0;
			for(int k=l;k<=r;++k)
				f[l][r]=max(f[l][r],val(l,k)+(k<r?f[k+1][r]:0));
		}
	cout<<f[1][n]<<'\n';
	return 0;
}
```

### 代码说明

- `val(l,r)` 用三目区分单元素（返回 `x[l]`）与多元素（`abs(x[l]-x[r])*(r-l+1)`），这是本题最易错的一处：单元素套通用公式会得 0。
- 区间 DP 按 `len` 从小到大，保证转移用到的 `f[k+1][r]`（长度 `r-k<len`）已算好；`k==r` 时剩余为空段，贡献 0。
- `f` 是全局 `int` 数组，每个状态先置 0 再取 max；本题单测，无需多测清空。
- 下标 1-based（`x[1..n]`、`f[1..n][1..n]`），与"第 $i$ 个数"的题意一致；`mxn{105}` 为 $N\le100$ 的 +5 松弛。
- 答案 `f[1][n]`，换行 `'\n'`。
