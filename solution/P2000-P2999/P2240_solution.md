# P2240 【深基12.例1】部分背包问题 — 题解

## 一、解题过程：人类思考叙事

题意复述：有 $N$ 堆金币，第 $i$ 堆重 $m_i$、价值 $v_i$；背包承重 $T$。金币**可以任意分割**，分割后单位价值不变。问最多能带走多少价值（保留两位小数）。数据范围 $N\le100$，$m_i,v_i\le100$，$T\le1000$。

看到「背包」两个字，第一反应是 0/1 背包：$dp[c]$ 表示容量 $c$ 能装的最大价值，每堆要么全拿要么不拿。$T\le1000$ 跑起来飞快。但把题面再读一遍：**金币可以任意分割**——0/1 背包「要么整堆拿、要么不拿」的前提根本不存在。用 0/1 背包不仅慢一点，而是**答案会错**。

举个能说明问题的例子：$T=10$，两堆金币 $(m,v)=(10,100)$ 和 $(6,66)$。0/1 背包只能二选一，取 $100$；但允许分割时可以拿第二堆 $6$ 千克（价值 $66$），再从第一堆切 $4$ 千克（价值 $40$），共 $106>100$。所以模型必须换成「可以拿任意实数重量」。

允许分割之后，一堆金币就退化成一条「单价为 $v_i/m_i$ 的线段」：拿走 $x$ 千克（$0\le x\le m_i$）就得到 $x\cdot v_i/m_i$ 的价值。目标对拿取量是**线性**的，直觉立刻变成：**先拿单位价值最高的，拿完再拿次高的**。这就是分数背包。

试着手算验证：$T=50$，三堆 $(10,60),(20,100),(30,120)$，单价分别是 $6,5,4$。先拿第一堆（$60$）、第二堆（$100$），剩 $20$ 容量，从第三堆拿 $20/30$，得 $80$，总价值 $240$。若改成先拿第三堆再拿第一堆，$30$ 容量换 $120$、$10$ 容量换 $60$、剩 $10$ 只能拿第二堆的一半 $50$，合计 $230<240$。贪心看起来对。

但「看起来对」不够，得回答两个问题：

1. **会不会出现「不拿满某一堆、却去拿后面更差的堆」的最优解？** 交换论证：如果存在更优解里拿了单价低的堆的一部分，而单价高的堆没拿满，就把质量从低单价挪到高单价，价值不减。所以总存在一个「前缀全拿 + 至多一堆拿一部分」的最优解。
2. **为什么按单价排序之后「能拿多少拿多少」就是最优？** 用一个上界：任何方案的价值不超过「前 $k-1$ 堆拿满 + 剩余容量全部按第 $k$ 堆的单价折算」，而这个上界恰好被贪心取到。这两个论断合起来就是正确性证明（第二节）。

实现上有三个具体的坑：

- **排序不能按总价值**，要按单价 $v_i/m_i$。比较时用交叉相乘 `x.v*y.m > y.v*x.m`，避免浮点误差（$m_i,v_i\le100$，乘积最大 $10^4$，不会溢出）。
- **最后一部分必须转成浮点再乘**：写成 `rem*a[i].v/a[i].m` 会先做整数除法（`rem*v/m` 在 `int` 下截断），答案直接错。要写 `(double)rem*a[i].v/a[i].m`。
- **输出**：`cout<<fixed<<setprecision(2)<<ans`，即保留两位小数。

还有一个容易忽略的边界：如果所有金币总重不超过 $T$，循环里永远不会走到「拿一部分」的分支，答案就是所有 $v_i$ 之和；如果 $T$ 比任何一堆都小，则只会拿单价最高的那一堆的一部分。这两种情况代码都不需要特判。

## 二、思维链：完整证明

记第 $i$ 堆的单价 $p_i=v_i/m_i$，总价值函数对拿取量线性。把堆按 $p_1\ge p_2\ge\dots\ge p_N$ 排序（相等时任意）。

**引理 0（为什么不能套 0/1 背包）**：若强制每堆「整堆拿或不拿」，最优值可能严格小于允许分割时的最优值。

*证明*：取 $T=10$，两堆 $(m_1,v_1)=(10,100)$、$(m_2,v_2)=(6,66)$。整堆方案只有「不拿」「拿第 1 堆」「拿第 2 堆」三种（两堆同取重 $16>T$），价值分别为 $0,100,66$，最大 $100$。而分数方案 $x_2=6,\ x_1=4$ 总重 $10\le T$，价值 $66+4\cdot\frac{100}{10}=106>100$。所以 0/1 背包（或任何只按整堆决策的贪心）会给出错误答案，必须按「可分割」建模。证毕。

**引理 1（方案的数学形式）**：一个方案等价于给每堆选一个实数 $x_i\in[0,m_i]$（拿走的重量），满足 $\sum_i x_i\le T$，其价值为
$$\sum_{i=1}^{N}x_i\,p_i=\sum_{i=1}^{N}x_i\cdot\frac{v_i}{m_i}.$$

*证明*：题目允许把一堆金币任意分割且分割后单位价值不变，所以从第 $i$ 堆拿走 $x_i$ 千克（$0\le x_i\le m_i$）获得的价值就是 $x_i\cdot(v_i/m_i)$，与分割方式无关；背包容量限制就是总重量不超过 $T$。不同堆之间互不影响，故总价值是各堆之和。反之任意满足这些约束的 $x$ 都对应一个合法拿法。证毕。

**引理 1′（并列单价的处理）**：若 $p_i=p_j$，交换这两堆在排序中的位置不改变贪心的输出值。

*证明*：记这两堆为 $A,B$，单价都是 $p$。交换只影响它们的处理顺序。设处理到这两堆时剩余容量为 $R$。
- 若 $R\ge m_A+m_B$，两堆都被整堆拿走，价值增量 $v_A+v_B$，与顺序无关。
- 否则设先处理者为 $X$、后处理者为 $Y$，则增量为
$$I=p\cdot\min(m_X,R)+p\cdot\min\big(m_Y,\max(R-m_X,0)\big).$$
若 $R\le m_X$，则 $\min(m_X,R)=R$ 且后一项为 $0$；若 $R>m_X$，则第一项为 $m_X$、第二项为 $\min(m_Y,R-m_X)$。两种情形都给出
$$\min(m_X,R)+\min\big(m_Y,\max(R-m_X,0)\big)=\min(R,\ m_X+m_Y).$$
右边关于 $X,Y$ 对称，故交换顺序后同一个式子仍等于 $\min(R,m_X+m_Y)$，增量都是 $p\cdot\min(R,m_X+m_Y)$。结合 $v_A=m_Ap,\ v_B=m_Bp$，两种顺序的输出值相同。证毕。

**引理 2（交换引理）**：设两份方案只在第 $A,B$ 两堆上不同，且 $p_A\ge p_B$。若在当前方案中 $x_A<m_A$ 且 $x_B>0$，令 $\delta=\min(m_A-x_A,\ x_B)>0$，执行
$$x_A\leftarrow x_A+\delta,\qquad x_B\leftarrow x_B-\delta,$$
则新方案仍可行，且价值变化为 $\delta(p_A-p_B)\ge0$。

*证明*：$\delta\le m_A-x_A$ 保证 $x_A+\delta\le m_A$，$\delta\le x_B$ 保证 $x_B-\delta\ge0$；两者的和 $x_A+x_B$ 不变，故总重量不变、容量约束仍满足。价值变化为 $\delta p_A-\delta p_B=\delta(p_A-p_B)\ge0$。证毕。

**引理 3（最优解的标准形）**：存在一个最优方案，形如
$$x_1=m_1,\ \dots,\ x_{k-1}=m_{k-1},\quad 0\le x_k\le m_k,\quad x_{k+1}=\dots=x_N=0$$
（其中 $k\in[1,N]$；若全部拿完则视为 $k=N+1$ 且所有 $x_i=m_i$）。并且此时 $\sum_i x_i=\min(T,\sum_i m_i)$。

*证明*：可行域 $\{x:0\le x_i\le m_i,\ \sum x_i\le T\}$ 是闭有界多面体，价值函数连续，故最优方案存在；在所有最优方案中取字典序 $(x_1,x_2,\dots,x_N)$ 最大者（有限个坐标上界，字典序最大值必存在）。先证它不可能含「逆序对」：若存在 $i<j$ 使 $x_i<m_i$ 且 $x_j>0$，由 $p_i\ge p_j$ 与引理 2，把质量从 $j$ 挪到 $i$ 后价值不减，仍是**最优**方案；但 $x_i$ 严格变大而 $x_1..x_{i-1}$ 不变，字典序更大，与「字典序最大」矛盾。因此对一切 $i<j$，$\lnot(x_i<m_i\wedge x_j>0)$。
令 $k=\min\{i:x_i<m_i\}$（若不存在则 $k=N+1$，所有堆已拿满）。由 $k$ 的定义，$i<k$ 时 $x_i=m_i$；而对 $j>k$，因 $x_k<m_k$，若 $x_j>0$ 就构成逆序对，故 $x_j=0$。这正是标准形。
再证总拿取量：若某 $x_i<m_i$ 且 $\sum_t x_t<T$，取 $\varepsilon=\min(m_i-x_i,\ T-\sum_t x_t)>0$，令 $x_i\leftarrow x_i+\varepsilon$ 仍可行，价值增加 $\varepsilon p_i>0$（$v_i>0\Rightarrow p_i>0$），与最优性矛盾。所以要么所有堆都拿满（此时 $\sum x_i=\sum m_i\le T$），要么 $\sum x_i=T$。两种情形都给出 $\sum_i x_i=\min(T,\sum_i m_i)$。证毕。

**引理 4（上界引理）**：设 $k$ 是第一个使前缀重量超过容量的下标，即
$$S_{k-1}:=\sum_{i<k}m_i\le T<S_k:=\sum_{i\le k}m_i,$$
记 $R=T-S_{k-1}$（若所有堆总重不超过 $T$，即 $S_N\le T$，约定 $k=N+1$）。则任意可行方案的价值不超过
$$G=\begin{cases}\displaystyle\sum_{i<k}v_i+R\cdot p_k,& k\le N,\\[4pt] \displaystyle\sum_{i=1}^{N}v_i,& k=N+1.\end{cases}$$

*证明*：先处理 $k=N+1$（$S_N\le T$）：由 $x_i\le m_i$ 与 $p_i\ge0$，$\sum_i x_ip_i\le\sum_i m_ip_i=\sum_i v_i=G$。
再处理 $k\le N$。任取可行方案 $x$。因为 $T\ge\sum_i x_i$，有
$$\sum_{i\ge k}x_i\le T-\sum_{i<k}x_i=(T-S_{k-1})+\Big(S_{k-1}-\sum_{i<k}x_i\Big)=R+D,$$
其中 $D=\sum_{i<k}(m_i-x_i)\ge0$（用到 $x_i\le m_i$）。于是
$$
\begin{aligned}
\sum_i x_ip_i
&=\sum_{i<k}x_ip_i+\sum_{i\ge k}x_ip_i\\
&\le\sum_{i<k}x_ip_i+(R+D)\,p_k &&(\text{右侧每堆单价}\le p_k)\\
&=\sum_{i<k}x_ip_i+Rp_k+\sum_{i<k}(m_i-x_i)p_k\\
&=Tp_k+\sum_{i<k}x_i(p_i-p_k) &&(S_{k-1}p_k+Rp_k=Tp_k)\\
&\le Tp_k+\sum_{i<k}m_i(p_i-p_k) &&(x_i\le m_i,\ p_i\ge p_k)\\
&=S_{k-1}p_k+Rp_k+\sum_{i<k}m_i(p_i-p_k)\\
&=\sum_{i<k}m_ip_i+Rp_k=\sum_{i<k}v_i+Rp_k=G. &&\square
\end{aligned}
$$
证毕。

**上界的数值检验**：对 $T=50$、三堆 $(10,60),(20,100),(30,120)$（单价 $6,5,4$），有 $S_2=30\le50<S_3=60$，$R=20$，引理 4 给出的上界是 $G=60+100+20\cdot4=240$，正好是贪心的输出；而「先拿第三堆再拿第一堆」的方案价值为 $120+60+(50-30-10)/20\cdot100=230<240$，与上界方向一致。这说明上界不是空话，它确实卡住了所有方案。

**引理 5（贪心恰好达到上界）**：按单价降序扫描、能整堆拿就整堆拿、装不下就把剩余容量全部用于当前堆的贪心算法，其输出恰为引理 4 中的 $G$。

*证明*：贪心按顺序处理 $1,2,\dots$。对 $i<k$，$S_i\le S_{k-1}\le T$，故第 $i$ 堆能整堆拿，拿走 $m_i$；处理到第 $k$ 堆时剩余容量 $R=T-S_{k-1}$，由 $T<S_k$ 得 $0\le R<m_k$（$R\ge0$ 因 $S_{k-1}\le T$），于是拿走 $R$ 千克、得 $R\cdot p_k$，容量用尽，循环结束。总价值 $=\sum_{i<k}v_i+Rp_k=G$。若 $S_N\le T$，则所有堆都整堆拿完，总价值 $\sum_iv_i=G$。两种情形贪心输出都是 $G$。证毕。

**定理**：贪心算法输出全局最优值。

*证明*：贪心输出 $G$（引理 5），而任意可行方案价值 $\le G$（引理 4），故 $G$ 就是最大值。证毕。

**引理 6（数值精度）**：用 `double` 累加并按两位小数输出，足以得到正确结果。

*证明*：答案不超过 $\sum_i v_i\le100\times100=10^4$，`double` 有约 $15\sim16$ 位十进制有效数字，相对误差约 $10^{-16}$，绝对误差远小于 $10^{-11}$，离 $0.005$ 的舍入粒度还有九个数量级的余量，因此除「精确值恰好落在 $x.xx5$ 这种二义性边界」外，舍入结果唯一确定，与算法正确性无关。此外比较单价用交叉相乘的整数运算（$m_i,v_i\le100$，乘积 $\le10^4$），排序阶段没有任何浮点误差。证毕。

**引理 7（复杂度）**：时间 $O(N\log N)$，空间 $O(N)$。

*证明*：一次排序 $O(N\log N)$，随后一次线性扫描 $O(N)$；数组 `a[N]` 占 $O(N)$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 金币可任意分割 ⇒ 拿走 $x$ 千克得 $x\cdot v/m$，目标对拿取量线性
- **consider easier version** — 先套 0/1 背包，发现「不可分割」这个前提被题目删掉了，构造反例说明模型错了
- **classic problem solution** — 识别为分数背包：按单位价值 $v/m$ 降序贪心
- **exchange argument** — 把质量从低单价堆挪到未满的高单价堆，价值不减 ⇒ 存在「前缀拿满 + 至多一堆拿部分」的最优解
- **explore its property** — 用「前缀拿满 + 剩余容量按下一堆单价折算」给出任何方案的价值上界
- **classic problem solution** — 贪心恰好取到该上界，于是最优
- **classic problem solution** — 用交叉相乘比较比值、用 `double` 只在最后折算，规避浮点比较误差与整数除法截断

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $N$ | 金币堆数 | 输入 |
| $T$ | 背包承重 | 输入 |
| `a[i].m` | 第 $i$ 堆重量 $m_i$ | 输入 |
| `a[i].v` | 第 $i$ 堆价值 $v_i$ | 输入 |
| 单价 $p_i$ | $v_i/m_i$ | 不显式存储，用交叉相乘比较 |
| `rem` | 当前剩余容量 | 初值 $T$ |
| `ans` | 已获得价值（浮点） | 初值 $0$ |

### 算法步骤

1. 读入 $N,T$ 和每堆的 $(m_i,v_i)$。
2. 按 $v_i/m_i$ 降序排序，比较器写成 `1LL*x.v*y.m>1LL*y.v*x.m`（交叉相乘，避免浮点）。
3. 令 `rem=T`、`ans=0`，按排序后的顺序扫描：
   1. 若 `a[i].m<=rem`：整堆拿走，`ans+=a[i].v`，`rem-=a[i].m`；
   2. 否则：拿走剩余容量对应的部分，`ans+=(double)rem*a[i].v/a[i].m`，令 `rem=0` 并结束扫描。
4. 以 `fixed<<setprecision(2)` 输出 `ans`。

### 复杂度

- 时间复杂度：$O(N\log N)$（排序为主），扫描 $O(N)$。
- 空间复杂度：$O(N)$（存 $N$ 堆）。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过，无错误。
- 题面无样例，手造数据核对：`1 5 / 10 3` → `1.50`；`3 50 / 10 60 / 20 100 / 30 120` → `240.00`；`2 3 / 2 3 / 2 3` → `4.50`；`2 1 / 100 1 / 100 100` → `1.00`；`2 100 / 1 1 / 1 1` → `2.00`（全部装下）。
- 对拍：另写「把每堆拆成 $m_i$ 个单位重量、在容量 $T$ 上做有界背包 DP」的暴力（$O(NTm)$，与贪心完全不同的机制），随机 $300$ 组 $N\le8,\ T\le20,\ m_i,v_i\le10$。暴力输出 $10$ 位小数，标程输出两位小数，按半个最小单位（$0.005$）的容差比较，全部一致；另用不截断的小数版本在同样数据上做过 $10^{-6}$ 精度的比对，也全部一致。
- 边界：总重小于容量、容量小于最小堆、比值相等、$N=1$ 均覆盖。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2240 【深基12.例1】部分背包问题
// 思路：按单位价值 v/m 降序，能整堆拿就整堆拿，最后一堆按剩余容量取一部分
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n,T;
struct pile{int m,v;};
pile a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>T;
	for(int i=0;i<n;++i)
		cin>>a[i].m>>a[i].v;
	// 交叉相乘比较 v/m，避免浮点误差
	sort(a,a+n,[](auto x,auto y){return 1LL*x.v*y.m>1LL*y.v*x.m;});

	double ans=0;
	int rem=T;
	for(int i=0;i<n;++i)
	{
		if(a[i].m<=rem)
		{
			ans+=a[i].v;
			rem-=a[i].m;
		}
		else
		{
			// 注意先转 double，否则是整数除法
			ans+=(double)rem*a[i].v/a[i].m;
			rem=0;
			break;
		}
	}
	cout<<fixed<<setprecision(2)<<ans<<'\n';
	return 0;
}
```
