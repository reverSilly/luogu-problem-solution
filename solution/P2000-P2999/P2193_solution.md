# P2193 HXY和序列 — 题解

## 一、解题过程：人类思考叙事

题目要求数一数：长度为 $p$、每个元素都在 $[1,n]$ 内、相邻两项满足"后一项是前一项的倍数"的序列有多少个。

第一反应是暴力枚举，但 $n, p$ 都到 $2000$，序列总数是 $n^p$，枚举不动。

自然的思路是**按最后一项做 DP**。设 $f[j][i]$ 表示"长度为 $j$ 且最后一项是 $i$"的合法序列个数。考虑转移：长度为 $j$、末项是 $i$ 的序列，删掉最后的 $i$，剩下一个长度为 $j-1$ 的合法序列，其末项记作 $d$。原序列合法当且仅当 $i$ 是 $d$ 的倍数，即 $d \mid i$。所以

$$f[j][i] = \sum_{d \mid i} f[j-1][d].$$

初始条件：长度为 1 时，序列就是 $(i)$ 自己，所以 $f[1][i] = 1$。

答案就是 $\sum_{i=1}^{n} f[p][i]$（末项可以是任意值）。

现在看复杂度。直接实现上述转移，就是对每个 $i$ 枚举它的所有因子，单层复杂度是 $\sum_{i=1}^{n} d(i) = O(n \log n)$（因子个数函数的平均是调和级数），总复杂度 $O(p \cdot n \log n)$。

$n = p = 2000$ 时，$2000 \times 2000 \times \log 2000 \approx 4 \times 10^7$，完全跑得动。而且我们可以更聪明一点：**不要"枚举 $i$ 的因子"，改成"枚举 $d$，把 $f[j-1][d]$ 加到 $d$ 的所有倍数上"**。这样内层循环就是标准的枚举倍数写法：

```
for d in 1..n:
    for m in d, 2d, 3d, ... <= n:
        g[m] += f[d]
```

内层总次数是 $\sum_{d=1}^{n} \lfloor n/d \rfloor = O(n \log n)$，与枚举因子等价，但写法更短、缓存更友好。

再优化一步：第 $j$ 层只依赖第 $j-1$ 层，用**滚动数组**即可，空间 $O(n)$。

还有一个细节：$f[j][i]$ 的值可能很大（长度 2000 的序列数量是天文数字），所以每一步都要对 $10^9+7$ 取模。取模时用 `if(g[m]>=p) g[m]-=p;` 即可（因为两个加数都已经在 $[0,p)$ 内，和最多是 $2p-2$，减一次就够），比 `%` 更快。

顺便注意，$f[j][i]$ 关于 $i$ 是单调不减的（$i$ 的因子集合随 $i$ 增大而"至少不减"？其实不然，但 $f[j][i]$ 至少不小于 $f[j][i-1]$ 的趋势在数值上是 f[j][i] ≥ f[j-1][i] 之类，这里用不上，跳过）。另外 $f[1][i]=1$ 而 $f[2][i] = d(i)$，样例 `3 2` 得到 $1+2+2 = 5$ 正好吻合。

整题是纯粹的 DP + 因子枚举。

## 二、思维链：完整证明

**引理 1**：对任意 $j \ge 2$ 与 $1 \le i \le n$，$f[j][i] = \sum_{d \mid i} f[j-1][d]$。

*证明*：设 $S$ 为所有长度为 $j$、末项为 $i$ 的合法序列构成的集合，$|S| = f[j][i]$。
对 $S$ 中每个序列 $(a_1, \dots, a_j)$，把末项删去得到 $T = (a_1, \dots, a_{j-1})$。由题意，$T$ 仍是一个合法序列（相邻整除关系不受影响），长度为 $j-1$，且其末项 $d = a_{j-1}$ 满足 $d \mid a_j = i$，即 $d$ 是 $i$ 的因子。
反过来，任取一个长度为 $j-1$、末项为 $d$ 的合法序列（$d \mid i$），在末尾添上 $i$：新序列相邻整除关系在前 $j-2$ 项上由原序列保证，第 $j-1$ 项与第 $j$ 项之间由 $d \mid i$ 保证，故新序列合法，且末项为 $i$。
这两个操作互为逆映射，构成 $S$ 与所有"长度为 $j-1$ 且末项 $d \mid i$ 的合法序列"的并集之间的一一对应。按 $d$ 分类计数即得 $f[j][i] = \sum_{d \mid i} f[j-1][d]$。证毕。

**引理 2**：算法中的"枚举 $d$ 及其倍数"的累加过程，得到的 $g[i]$ 等于 $\sum_{d \mid i} f[d]$。

*证明*：算法对每个 $d \in [1,n]$ 遍历所有满足 $d \mid m$ 的 $m \in [1,n]$（即 $m = d, 2d, 3d, \dots$），执行 $g[m] \mathrel{+}= f[d]$。因此 $g[m]$ 的最终值是所有满足 $d \mid m$ 的 $d$ 对应的 $f[d]$ 之和，恰好等于引理 1 中的 $\sum_{d \mid i} f[j-1][d]$。此外每个 $(d, m)$ 满足 $d \mid m$ 的组合被访问恰好一次，不会重复计数也不会遗漏。证毕。

**引理 3**：算法计算出的 $f[j][i]$ 正确表示长度为 $j$、末项为 $i$ 的合法序列数（模 $10^9+7$）。

*证明*：对 $j$ 归纳。$j = 1$ 时，算法初始化 $f[i] = 1$；长度为 1 且末项为 $i$ 的序列只有 $(i)$ 一个，正确。$j \ge 2$ 时，归纳假设第 $j-1$ 层的 $f$ 正确，由引理 2 可知本层计算的 $g[i] = \sum_{d \mid i} f[j-1][d]$ 正确，再由引理 1 该式正是 $f[j][i]$。取模运算与加法相容（模运算是同态），故取模后的结果仍是正确答案。证毕。

**引理 4**：最终答案 $\sum_{i=1}^{n} f[p][i]$ 等于所有满足条件的序列总数（模 $10^9+7$）。

*证明*：任意一个合法序列有唯一的末项 $i \in [1,n]$，因此所有合法序列被划分成 $n$ 个互不相交的集合"末项为 $i$ 的合法序列"，第 $i$ 个集合大小为 $f[p][i]$。由并集的可加性，总数为 $\sum_{i=1}^n f[p][i]$。证毕。

**引理 5**：本算法的时间复杂度为 $O(p \cdot n \log n)$，空间复杂度为 $O(n)$。

*证明*：单层中，外层循环 $n$ 次，内层循环次数为 $\sum_{d=1}^{n} \lfloor n/d \rfloor$。由调和级数 $\sum_{d=1}^{n} 1/d = O(\log n)$，故内层次数为 $O(n \log n)$。共 $p$ 层，总时间 $O(p n \log n)$。程序仅使用两个长度为 $O(n)$ 的数组 $f, g$，空间 $O(n)$。证毕。

**定理**：本算法输出的即为题目所求的合法序列数量对 $10^9+7$ 取模的值。

*证明*：由引理 3 滚动数组在 $p$ 轮后保存的就是正确的 $f[p][\cdot]$，由引理 4 将其求和即得答案。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别题型** → 数数 + 相邻关系是整除 ⇒ 典型的"按末项分类"的线性 DP
2. **定义状态** → $f[j][i]$ = 长度为 $j$ 且末项为 $i$ 的方案数；思考"删掉末项"这个逆操作
3. **写转移** → $f[j][i] = \sum_{d \mid i} f[j-1][d]$，其中"删末项"与"添末项"构成一一对应
4. **定初值与答案** → $f[1][i] = 1$；答案 $\sum_i f[p][i]$
5. **优化枚举方向** → "枚举 $i$ 的因子"改为"枚举 $d$ 及其倍数"，写成倍数循环，复杂度 $O(n \log n)$/层
6. **空间优化** → 滚动数组，只留相邻两层
7. **取模细节** → 模数 $10^9+7$，加法后用比较减法代替 `%`
8. **写代码** → 初始化 → 层循环 → 求和输出

## 四、解法说明

### 算法

滚动数组两层 DP。

### 符号表

| 符号 | 含义 | 类型 | 初始化 / 记忆点 |
|------|------|------|----------------|
| $n$ | 序列元素的取值上界 | `int` | 输入 |
| $p$ | 序列长度 | `int` | 输入（代码中变量名为 `len`） |
| $f[i]$ | 当前层的方案数：长度为当前长度、末项为 $i$ 的合法序列数 | `int[]` | $f[1][i]=1$（全部置 1） |
| $g[i]$ | 下一层（暂存） | `int[]` | 每层开始时清零 |
| $M$ | 模数 $10^9+7$ | `constexpr int` | 代码中命名为 `p`（与长度区分） |

### 算法步骤

1. 初始化 I/O 加速（`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`）。
2. 读入 $n, p$。
3. 令 $f[i] = 1$（$1 \le i \le n$），表示长度为 1 的方案。
4. 对长度 $j = 2, 3, \dots, p$：
   1. 把 $g$ 全清零；
   2. 对 $d = 1, \dots, n$：若 $f[d] = 0$ 跳过（该末项无方案）；否则对 $m = d, 2d, 3d, \dots \le n$，执行 $g[m] \mathrel{+}= f[d]$，若 $g[m] \ge M$ 则 $g[m] \mathrel{-}= M$；
   3. 把 $g$ 整体拷回 $f$。
5. 累加 $f[1..n]$，累加时同样对 $M$ 取模，输出。

### 复杂度

- 时间复杂度：$O(p \cdot n \log n)$，其中单层为 $\sum_{d=1}^{n}\lfloor n/d \rfloor = O(n\log n)$。
- 空间复杂度：$O(n)$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2193 HXY和序列
// 思路：f[j][i] = 长度为 j 且末项为 i 的方案数
//       f[1][i] = 1，f[j][i] = sum_{d|i} f[j-1][d]
//       用「枚举 d 的倍数」代替「枚举 i 的因子」，把每层压到 O(n log n)
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005};
constexpr int p{1000000007};

int n,len;
int f[mxn],g[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>len;
	for(int i=1;i<=n;++i)f[i]=1;
	for(int j=2;j<=len;++j)
	{
		memset(g,0,sizeof(g));
		for(int d=1;d<=n;++d)
		{
			if(!f[d])continue;
			for(int m=d;m<=n;m+=d)
			{
				g[m]+=f[d];
				if(g[m]>=p)g[m]-=p;
			}
		}
		for(int i=1;i<=n;++i)f[i]=g[i];
	}
	int ans=0;
	for(int i=1;i<=n;++i)
	{
		ans+=f[i];
		if(ans>=p)ans-=p;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 代码中用 `len` 保存序列长度 $p$，把 `p` 这个名字留给模数常量，避免混淆。
- 模数 `1000000007` 用 `constexpr int p{...}` 定义；由于两个加数均已小于 `p`，一次减法即可完成取模，比 `%` 更快。
- `f`、`g` 为全局数组，`mxn{2005}` 相对约束 $2000$ 有 $5$ 的松弛。
- `if(!f[d])continue;` 是一个有效的剪枝：$f[d]=0$ 时对所有倍数的贡献都是 0。
- 换行使用 `'\n'`，`main` 正常结束 `return 0`。

### 验证状态

- 编译：`g++ -O2 -std=c++17` 通过，无警告。
- 官方样例两组全部通过：`3 2` → `5`；`6 4` → `39`。
- 对拍：使用 `P2193_brute.cpp` 暴力 DFS 枚举所有合法序列计数（$n, p \le 8$），与标程在 2000 组随机数据上比对，全部一致。
