# P2459 [SDOI2007] 立体分割 — 题解

## 一、解题过程：人类思考叙事

题目：一个长方体蛋糕，顶点在原点 $(0,0,0)$，对角顶点在 $(x,y,z)$，$x,y,z$ 是 $1\sim 1000$ 的整数。要把它分成 $n$ 个**大小和形状都相等（全等）**的小长方体，$1\le n\le 1000$。输出 $n$ 行，每行 $6$ 个**实数**，是某个小蛋糕的一对相对顶点坐标，误差不超过 $10^{-9}$。Special Judge，小蛋糕的输出顺序任意，相对顶点任取一组。

**第一反应：整数网格切割。** 最自然的分法是"切豆腐"：沿 $x$ 轴切 $a-1$ 刀、$y$ 轴切 $b-1$ 刀、$z$ 轴切 $c-1$ 刀，得到 $a\times b\times c$ 个小长方体。要恰好 $n$ 块，就要 $a\cdot b\cdot c=n$。如果刀口必须落在整数坐标上，还需要 $a\mid x$、$b\mid y$、$c\mid z$。于是问题看起来是个枚举题：枚举 $n$ 的三因子分解，检查整除性——这也解释了题目标签里的"枚举"。

**碰壁：整除约束可能无解。** 拿最小的数据试一下：$x=y=z=1$，$n=2$。要 $a\cdot b\cdot c=2$ 且 $a,b,c$ 都整除 $1$，只能 $a=b=c=1$，乘积是 $1\ne 2$，无解！再如 $x=2,y=z=1,n=3$：$a\mid 2$ 只能取 $1,2$，$b=c=1$，乘积最多 $2<3$，也无解。

可是题面**根本没有定义"无解"时输出什么**，而且数据范围明确允许 $x=y=z=1,n=1000$。这说明**每一组输入都必须有解**——整数刀口的假设一定是我们自己强加的，不是题目要求的。

**回头重读输出格式，找到钥匙。** 题面写的是"每行 $6$ 个**实数**……误差不超过 $10^{-9}$"。实数！刀口完全可以落在 $x/n$ 这种有理数坐标上，根本不需要整除。整除约束一消失，枚举也就坍缩了：**任意**满足 $a\cdot b\cdot c=n$ 的正整数三元组都给出合法分割——把 $x$ 轴均分成 $a$ 段（每段长 $x/a$）、$y$ 轴均分 $b$ 段、$z$ 轴均分 $c$ 段，网格状排列，每块尺寸都是 $\frac{x}{a}\times\frac{y}{b}\times\frac{z}{c}$，全等，恰好 $abc=n$ 块，不重不漏铺满蛋糕。

既然任意分解都行，何必枚举？取最简单的 $(a,b,c)=(n,1,1)$：**只沿 $x$ 轴切 $n-1$ 刀**，把蛋糕切成 $n$ 片等厚薄板。第 $i$ 片（$i$ 从 $0$ 数）就是

$$\Big[\tfrac{i\cdot x}{n},\ \tfrac{(i+1)\cdot x}{n}\Big]\times[0,y]\times[0,z].$$

输出它的两个相对顶点 $(i x/n,0,0)$ 与 $((i+1)x/n,y,z)$ 即可。$n=1$ 时就是整个蛋糕，$x<n$ 时薄板厚度小于 $1$ 也完全合法——实数坐标嘛。

**剩下唯一要担心的是精度。** 坐标 $i x/n$ 用 `double` 计算：分子 $i\cdot x\le 10^6$ 是精确整数，除法误差不超过半个 ulp（$\le 10^{-13}$ 量级），再用 `fixed<<setprecision(12)` 输出，舍入误差 $\le 5\times 10^{-13}$，合计远小于 $10^{-9}$，有四个数量级的安全余量。还有一个隐蔽的好处：第 $i$ 片的右端面与第 $i+1$ 片的左端面是**同一个表达式** `(double)(i+1)*x/n` 算出来的，两个 `double` 逐位相同、打印出的字符串也相同，所以相邻薄板共享的面严丝合缝，不会因为两次独立舍入产生缝隙或重叠。

至此算法成型：读入四个数，循环 $n$ 次输出薄板坐标，$O(n)$ 结束。下面把"网格分割为什么全等、为什么不重不漏、为什么精度够"全部严格证明。

## 二、思维链：完整证明

**引理 1（网格分割引理）**：设 $a,b,c$ 为正整数且 $a b c=n$。对 $0\le i<a$、$0\le j<b$、$0\le k<c$，定义闭长方体

$$B_{i,j,k}=\Big[\tfrac{i x}{a},\tfrac{(i+1)x}{a}\Big]\times\Big[\tfrac{j y}{b},\tfrac{(j+1)y}{b}\Big]\times\Big[\tfrac{k z}{c},\tfrac{(k+1)z}{c}\Big].$$

则这族长方体满足：(1) 恰好 $n$ 个；(2) 两两全等且非退化；(3) 内部两两不交；(4) 并集恰好是整个蛋糕 $[0,x]\times[0,y]\times[0,z]$。

*证明*：

(1) 三元组 $(i,j,k)$ 的取值个数是 $a\cdot b\cdot c=n$，每个三元组对应一个长方体，且不同三元组对应的长方体不同（由 (3) 它们内部不交，而每个长方体内部非空）。

(2) 记 $T_{i,j,k}=(i x/a,\ j y/b,\ k z/c)$，则 $B_{i,j,k}=B_{0,0,0}+T_{i,j,k}$，即每个 $B_{i,j,k}$ 都是 $B_{0,0,0}$ 的平移。平移是等距变换，保持形状与大小，故所有长方体全等（这比"全等允许旋转"更强：它们连方向都一致）。每个长方体的三边长为 $x/a,y/b,z/c$；因 $x,y,z\ge 1$ 且 $a,b,c$ 为有限正整数，三边长均严格大于 $0$，非退化。

(3) 设两个不同的长方体 $B_{i,j,k}\ne B_{i',j',k'}$ 有公共内点 $p=(p_1,p_2,p_3)$。不同意味着至少一个下标不同，不妨 $i\ne i'$。$p$ 是两者的内点，故 $p_1$ 同时属于开区间 $(i x/a,(i+1)x/a)$ 与 $(i' x/a,(i'+1)x/a)$。但这两个开区间是 $x$ 轴上等分划分的相邻（或相隔）段：若 $i<i'$，则 $(i+1)x/a\le i' x/a$，两开区间不相交；$i>i'$ 同理。矛盾。故内部两两不交。

(4) 先证每个 $B_{i,j,k}\subseteq[0,x]\times[0,y]\times[0,z]$：由 $0\le i<a$ 得 $0\le i x/a$ 且 $(i+1)x/a\le x$，另两维同理。再证蛋糕中任一点 $p=(p_1,p_2,p_3)$（$0\le p_1\le x$ 等）都被覆盖：取 $i=\min(\lfloor p_1 a/x\rfloor,\ a-1)$（$x>0$ 故除法合法）。若 $p_1<x$，则 $\lfloor p_1 a/x\rfloor\le a-1$，由下取整定义 $i\le p_1 a/x<i+1$，即 $i x/a\le p_1<(i+1)x/a$；若 $p_1=x$，则 $i=a-1$，$p_1=x=(i+1)x/a$ 且 $i x/a\le x$。两种情况都有 $p_1\in[i x/a,(i+1)x/a]$。同理取 $j,k$ 覆盖 $p_2,p_3$。于是 $p\in B_{i,j,k}$。并集等于蛋糕。

附带一个体积核对：$n\cdot\frac{x}{a}\cdot\frac{y}{b}\cdot\frac{z}{c}=\frac{abc\cdot xyz}{abc}=xyz$，与蛋糕体积一致——这是 (3)(4) 的必然推论，也可用作独立校验。证毕。

**引理 2（可行性坍缩）**：对任意满足题面范围的输入 $(x,y,z,n)$，取 $(a,b,c)=(n,1,1)$ 即满足引理 1 的前提，故合法分割**永远存在**；特别地，不需要任何整除条件，也不需要枚举因子分解。

*证明*：$n\ge 1$ 是正整数，$n\cdot 1\cdot 1=n$，直接代入引理 1。此时 $B_{i,0,0}=[i x/n,(i+1)x/n]\times[0,y]\times[0,z]$，即 $n$ 片等厚薄板。这也反过来解释了题面为何没有"无解"输出分支：在实数坐标的输出约定下确实无解是不可能的。第一节中 $x=y=z=1,n=2$ 的"无解"只在我们强加整数刀口时才出现；取 $(2,1,1)$ 得两片 $[0,0.5]\times[0,1]^2$ 与 $[0.5,1]\times[0,1]^2$，合法。证毕。

**引理 3（输出格式合法性）**：算法第 $i$ 行输出的两点 $P_i=(i x/n,0,0)$ 与 $Q_i=((i+1)x/n,y,z)$ 是薄板 $B_i$ 的一对相对顶点（体对角线端点），且每行恰 $6$ 个实数、共 $n$ 行。

*证明*：$B_i$ 的 $8$ 个顶点中，$P_i$ 是三个坐标都取区间左端点的顶点，$Q_i$ 是三个坐标都取右端点的顶点，二者恰为体对角线的两端，是一对相对顶点。三个坐标差分别为 $x/n>0$、$y\ge 1>0$、$z\ge 1>0$，全部非零，故这不是面对角线或棱，确实是"相对"顶点（即使薄板很薄也不退化）。题面允许"相对顶点任取一组输出"、小蛋糕顺序任意，故按 $i=0..n-1$ 顺序输出这组顶点对完全符合要求。循环恰执行 $n$ 次，每行输出 $6$ 个数。证毕。

**引理 4（精度与共享面一致性）**：设精确坐标为有理数 $q$，算法打印的十进制串解析回实数后为 $\hat q$，则 $|\hat q-q|\le 5.6\times 10^{-13}<10^{-9}$；且相邻薄板共享面的两侧坐标打印值**完全相等**。

*证明*：分三个误差源逐一界定。

其一，分子精确。$x$ 坐标的分子是 $i\cdot x$ 或 $(i+1)\cdot x$，为不超过 $1000\times 1000=10^6<2^{53}$ 的整数。IEEE-754 双精度浮点能精确表示绝对值不超过 $2^{53}$ 的所有整数，代码中 `(double)i*x` 先把 $i$ 转为 `double` 再乘 $x$，乘积是精确值，无舍入。

其二，除法舍入。IEEE-754 要求基本运算正确舍入：$\mathrm{fl}(q)$ 与精确商 $q$ 的差不超过结果处半个 ulp。所有坐标值落在 $[0,1000]$，而 $1000<2^{10}$，该量级处 $\mathrm{ulp}\le 2^{9-52}=2^{-43}\approx 1.14\times 10^{-13}$，故除法误差 $\le 2^{-44}\approx 5.7\times 10^{-14}$。

其三，打印舍入。`fixed<<setprecision(12)` 把浮点值四舍五入到小数点后 $12$ 位，引入误差 $\le 0.5\times 10^{-12}=5\times 10^{-13}$。

三者相加 $\le 5.7\times 10^{-14}+5\times 10^{-13}<5.6\times 10^{-13}<10^{-9}$。其余坐标 $0,y,z$ 以整数形式打印，是精确值，误差 $0$。

共享面：第 $i$ 片的右端面横坐标由表达式 `(double)(i+1)*x/n` 计算，第 $i+1$ 片的左端面横坐标由表达式 `(double)((i+1))*x/n`（循环变量取 $i+1$ 时的 `(double)i*x/n`）计算——两者是同一整数分子经同一除法得到的同一个 `double` 值（浮点运算是确定性函数），再经同一格式化输出得到同一字符串。故共享面两侧坐标逐字符相等，缝隙与重叠均为 $0$，远优于 $10^{-9}$ 容差。证毕。

**定理（算法正确性）**：算法对任意合法输入输出满足题面全部要求的分割方案。

*证明*：由引理 2，$(n,1,1)$ 网格分割存在；由引理 1，这 $n$ 个薄板全等、非退化、内部不交、铺满蛋糕；由引理 3，输出的 $n$ 行各 $6$ 个实数确为各薄板的一对相对顶点；由引理 4，每个打印坐标与精确值偏差 $<10^{-9}$。题面所有条件（块数、全等、格式、顺序自由、精度）逐条满足。证毕。

**引理 5（复杂度）**：算法时间复杂度 $O(n)$，额外空间复杂度 $O(1)$。

*证明*：读入 $4$ 个整数 $O(1)$；循环 $n$ 次，每次做常数次浮点乘除与 $6$ 个数的输出，输出总长度 $O(n)$（每个数至多常数个字符）。没有数组、没有递归，只用 $4$ 个全局整型变量与循环变量，额外空间 $O(1)$。证毕。

**关于"枚举"标签的说明**：若坚持整数刀口，才需要枚举 $n$ 的因子分解并检查 $a\mid x,b\mid y,c\mid z$，且如第一节所示会遭遇无解；题面的实数输出约定把整除约束整个移除，于是"枚举三因子分解"退化为"任取一个分解"，最简即 $(n,1,1)$。追求形状均衡的分解（比如让 $x/a,y/b,z/c$ 尽量接近）同样合法，但对正确性毫无必要——SPJ 只查全等与铺满，不查美观。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 全等小长方体 + 输出是"实数、误差 $10^{-9}$"⇒ 刀口不必落在整数格点。
2. **consider easier version** — 先解整数切割版：枚举 $a\mid x,b\mid y,c\mid z$ 且 $abc=n$ 的网格。
3. **explore its property** — 反例 $x=y=z=1,n=2$：整数版无解，但题面没有无解分支 ⇒ 整除约束是自己强加的，必须抛弃。
4. **reduce to easier problem** — 实数刀口下任意 $abc=n$ 都合法 ⇒ 枚举坍缩为固定取 $(n,1,1)$，沿单轴均分。
5. **classic problem solution** — 一维等分切片构造；用"平移全等 + 区间划分不交 + 逐点取整覆盖"证明铺满。
6. **explore its property** — 误差预算：分子精确、除法半 ulp、打印 $12$ 位舍入，合计 $\ll 10^{-9}$；相邻块共享面用同一表达式保证逐位一致。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|----------------|
| $x,y,z$ | 蛋糕的长、宽、高（对角顶点坐标） | `int` | 读入，$1\sim 1000$ |
| $n$ | 要分成的小蛋糕数 | `int` | 读入，$1\sim 1000$ |
| $i$ | 薄板编号，$0\le i<n$ | `int` | 循环变量，**内部 0-based** |
| $i x/n$ | 第 $i$ 片左端面横坐标（精确有理数） | `double` | `(double)i*x/n`，分子先转浮点保证整乘精确 |
| $(i+1)x/n$ | 第 $i$ 片右端面横坐标 | `double` | 与第 $i+1$ 片左端面是同一表达式 ⇒ 共享面逐位一致 |
| $0,y,z$ | 薄板在 $y,z$ 方向占满整个蛋糕 | `int` | 直接以整数打印，是精确实数 |

### 算法步骤

1. 初始化 I/O 加速（`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`）。
2. 读入 $x,y,z,n$；设置 `fixed<<setprecision(12)`（$12$ 位小数的舍入误差 $5\times10^{-13}$，加上浮点除法误差仍 $\ll 10^{-9}$）。
3. 对 $i=0..n-1$：输出一行 $6$ 个数 `i*x/n 0 0 (i+1)*x/n y z`，即第 $i$ 片薄板的一对相对顶点。
4. 结束。无解分支不存在（引理 2）。

### 复杂度

- 时间复杂度：$O(n)$（$n$ 行输出，每行常数次运算）。
- 空间复杂度：$O(1)$（仅几个标量，无数组）。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；题面无样例输入输出，手造 $10$ 组边界数据（含 $n=1$、$x=y=z=1,n=1000$、$1000^3,n=1000$ 等）与 $250$ 组随机数据，全部通过独立校验器（块数/非退化/包含于蛋糕/排序尺寸全等/内部两两不交/体积和 $=xyz$）与逐坐标 $10^{-9}$ 精度直检，$0$ 失败。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2459 [SDOI2007] 立体分割
// 输出允许实数坐标（误差 1e-9），切割不必落在整点：
// 沿 x 轴切成 n 片等厚薄板，第 i 片为 [i*x/n,(i+1)*x/n]×[0,y]×[0,z]
#include<bits/stdc++.h>
using namespace std;

int x,y,z,n;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>x>>y>>z>>n;
	cout<<fixed<<setprecision(12);
	for(int i=0;i<n;++i)
		cout<<(double)i*x/n<<' '<<0<<' '<<0<<' '<<(double)(i+1)*x/n<<' '<<y<<' '<<z<<'\n';
	return 0;
}
```

### 代码说明

- **没有枚举、没有数组**：引理 2 证明任意输入都有解，$(n,1,1)$ 分解直接构造，代码只剩一个输出循环。
- `(double)i*x/n`：先把 $i$ 转成 `double` 再乘 $x$，分子 $i x\le 10^6$ 在浮点中精确，整个表达式只含一次正确舍入的除法（引理 4）。
- `setprecision(12)`：打印舍入 $5\times10^{-13}$，与除法误差合计 $<5.6\times10^{-13}$，比 $10^{-9}$ 容差小四个数量级；不必也不应输出更少位数。
- 第 $i$ 行的右端面与第 $i+1$ 行的左端面来自同一表达式 `(i+1)*x/n`，打印字符串完全相同，共享面零缝隙。
- $0,y,z$ 以整数形式输出，它们是精确值，SPJ 按实数解析没有问题。
- 本题不需要哨兵与 `mxn` 常量（无状态数组），全局标量 + `'\n'` + Tab 缩进 + 紧凑运算符遵循仓库风格。
