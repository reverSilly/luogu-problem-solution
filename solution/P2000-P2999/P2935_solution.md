# P2935 [USACO09JAN] Best Spot S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** $P$ 个牧场（$1\le P\le500$），贝茜喜欢其中 $F$ 个（$1\le F\le P$）。$C$ 条双向路（$1<C\le8000$），第 $i$ 条连接 $a_i,b_i$，通过时间 $T_i$（$1\le T_i<892$）。要选一个牧场睡觉，使得**从它出发到所有 $F$ 个喜欢牧场的最短用时的平均值最小**；若多个牧场并列最优，输出**编号最小**的。

**口径说明。** "到某牧场的用时"指图上的**最短路**距离（无向，故对称）。平均值 $=\frac1F\sum_{f}d(i,f)$。若某候选牧场到某个喜欢牧场**不可达**，则它根本"到不了所有 $F$ 个"，平均值无定义，应排除该候选。题面保证存在最佳牧场（隐含至少有一个牧场能到达全部喜欢牧场，例如图连通）；实现上跳过含不可达距离的候选即可。

**第一步：平均最小 $\iff$ 和最小。** $F$ 是固定的正整数，$\frac1F$ 是正常数，乘以它不改变大小关系。所以"平均距离最小"完全等价于"距离之和 $\sum_f d(i,f)$ 最小"。这一步把"平均"这个看似要除法的目标，塌缩成一个纯整数求和——既避免浮点，又方便比较。

**第二步：需要什么距离？** 要对**每个**候选牧场 $i$ 求它到**每个**喜欢牧场 $f$ 的最短路。这是"多对多"的最短路查询。两条路：
- 对每个喜欢牧场跑一次 Dijkstra（$F$ 次单源），累加到各候选；
- 直接 Floyd-Warshall 求**全源最短路**，然后查表求和。

$P\le500$ 是个强烈信号：$P^3=1.25\times10^8$，Floyd 三重循环在 O2 下零点几秒就能跑完，而且代码只有几行、不用堆、不用邻接表。$F$ 最大也是 $500$，Dijkstra 路线 $F\cdot C\log P\approx500\times8000\times9\approx3.6\times10^7$ 也不慢，但实现更繁。这里选 **Floyd**：简单、稳、契合 $P\le500$ 的量级。

**第三步：Floyd 的几个坑。**
1. **初始化必须是 INF，不是 0。** 全局 `int` 数组默认 $0$，若直接把"没有边"当成距离 $0$，最短路会全错。要 `fill` 成 INF，再令对角线 $d[i][i]=0$。
2. **重边取最小。** 读入 $u,v,w$ 时 `dist[u][v]=min(dist[u][v],w)`，不能直接赋值覆盖。
3. **$k$ 在最外层。** Floyd 的中间点 $k$ 必须是第一重循环，这是 DP 阶段顺序，写错顺序结果不对。
4. **INF 不参与加法。** 松弛前判 `dist[i][k]!=inf && dist[k][j]!=inf`，否则 INF+INF 可能溢出或把不可达误判成可达。

**第四步：平局取小编号。** 从小到大枚举候选 $i$，用**严格小于** `s<best` 更新。第一个达到最小和的 $i$ 被记下，后面即使有相同的和也不会替换（不满足严格小于），自然保留最小编号。

**手造数据核对。**

第一组（纯平局）：$P=3,F=2$，喜欢 $\{1,3\}$，路 $1-2(1),2-3(1)$。三个候选到 $\{1,3\}$ 的距离和都是 $2$（$1:0+2$，$2:1+1$，$3:2+0$），并列最优取编号最小 $\Rightarrow$ 输出 `1`。

第二组（有重边/捷径）：$P=4,F=2$，喜欢 $\{1,4\}$，路 $1-2(1),2-3(1),3-4(1),2-4(1)$。$d(1,4)=\min(1+1+1,\,1+1)=2$。各候选和：$1:0+2=2$，$2:1+1=2$，$3:2+1=3$，$4:2+0=2$。最小和 $2$ 在 $\{1,2,4\}$，取最小编号 $\Rightarrow$ 输出 `1`。

第三组直接用题面示意图（$P=13,F=6$，喜欢 $\{1,8,10,11,12,13\}$，$15$ 条边）。按表格牧场 $10$ 与 $11$ 的距离和都是 $36$（平均 $6.00$）并列最小，取编号小的 $10$。程序输出 `10`，与题面"牧场 10 是最佳"吻合；其中 $d(10,1)=12,d(10,8)=11,d(10,10)=0,d(10,11)=1,d(10,12)=4,d(10,13)=8$，和 $36$，逐项与表格一致。

## 二、思维链：完整证明

**记号。** 顶点 $0\le i<P$（0-based）。喜欢集 $\textit{Fav}\subseteq V$，$|\textit{Fav}|=F\ge1$。边权 $w\in[1,891]$ 为正。$d(i,j)$ 为最短路距离（不可达记 $+\infty$）。$\texttt{dist}[i][j]$ 为 Floyd 算出的距离。候选 $i$ 的距离和 $S_i=\sum_{f\in\textit{Fav}}d(i,f)$。

---

### 引理 1（平均最小 $\iff$ 和最小）

$\arg\min_i \frac1F S_i=\arg\min_i S_i$（在可达候选上），且平局集合相同。

*证明*：$F\ge1$ 为固定正常数。对任意两候选 $i,j$，$\frac1F S_i<\frac1F S_j\iff S_i<S_j$（两边同乘正数 $F$ 保序），$\frac1F S_i=\frac1F S_j\iff S_i=S_j$。故按平均值排序与按和排序给出完全相同的顺序与平局类，最小值点集一致。证毕。

**推论**：只需比较整数和 $S_i$，全程无浮点、无除法。

---

### 引理 2（Floyd 的 DP 不变量与正确性）

设 $\texttt{dist}$ 初值为：$\texttt{dist}[i][i]=0$，有边则 $\texttt{dist}[i][j]=\min$ 边权，否则 $\texttt{inf}$。执行 `for k: for i: for j: dist[i][j]=min(dist[i][j],dist[i][k]+dist[k][j])`（跳过 INF）后，$\texttt{dist}[i][j]=d(i,j)$。

*证明*：定义 $d_k(i,j)$ 为"只允许用 $\{0,\dots,k-1\}$ 中的顶点作中间点"的 $i\to j$ 最短路长度。

**基**：$d_0(i,j)$ 不允许任何中间点，即直达边：$i=j$ 为 $0$，有边为最小边权，无边为 $+\infty$。这正是初值（`inf` 代表 $+\infty$）。

**递推**：$d_{k}(i,j)=\min\bigl(d_{k-1}(i,j),\,d_{k-1}(i,k)+d_{k-1}(k,j)\bigr)$。理由：一条中间点 $\subseteq\{0,\dots,k-1\}$ 的最短路，要么不经过 $k$（即 $d_{k-1}(i,j)$），要么经过 $k$；因边权非负，最短路是简单路，$k$ 至多出现一次，于是拆成 $i\to k$ 与 $k\to j$ 两段，两段中间点 $\subseteq\{0,\dots,k-2\}$，长度 $\ge d_{k-1}(i,k)+d_{k-1}(k,j)$，且该下界可达。取 min 即得。

**原地更新的合法性**：第 $k$ 轮用的是 $\texttt{dist}[i][k]$ 与 $\texttt{dist}[k][j]$。需证它们在第 $k$ 轮内不变。$\texttt{dist}[k][k]=0$（非负权下经 $k$ 绕回 $k$ 不会更短），故 $\texttt{dist}[i][k]\leftarrow\min(\texttt{dist}[i][k],\texttt{dist}[i][k]+0)$ 不变；同理 $\texttt{dist}[k][j]$ 不变。于是第 $k$ 轮所有更新等价于用第 $k-1$ 轮的值，原地与滚动数组一致。

归纳到 $k=P$：$d_P(i,j)$ 允许全部顶点作中间点 $=d(i,j)$。故 $\texttt{dist}[i][j]=d(i,j)$。INF 跳过保证 $+\infty$ 不参与有限加法，不可达对保持 `inf`。证毕。

---

### 引理 3（平局取最小编号）

按 $i=0,1,\dots,P-1$ 顺序、用严格不等式 `s<best` 更新最优，最终 `ans` 是距离和最小的候选中编号最小者。

*证明*：设最小和为 $S^\*$，取到它的候选下标集 $T=\{i:S_i=S^\*\}$（在可达候选中），$t=\min T$。扫描到 $t$ 之前，所有 $i<t$ 有 $S_i>S^\*$（否则 $i\in T$ 与 $t$ 最小矛盾），故 `best` 在 $t$ 之前 $>S^\*$；扫描到 $t$ 时 $S_t=S^\*<\texttt{best}$，更新 `ans`$=t$、`best`$=S^\*$。此后对任意 $i>t$：若 $S_i>S^\*$ 不更新；若 $S_i=S^\*$，`s<best` 即 $S^\*<S^\*$ 为假，不更新。故 `ans` 保持 $t=\min T$。证毕。

---

### 引理 4（不可达候选的排除）

若存在 $f\in\textit{Fav}$ 使 $d(i,f)=+\infty$，则候选 $i$ 不参与最优比较。

*证明*：题面要求"到达**所有** $F$ 个喜欢牧场"。若 $i$ 到某 $f$ 不可达，则无法到达该 $f$，平均值无定义（形式上为 $+\infty$），不可能是有限最优解。代码用 `ok=false; break` 跳过此类 $i$，等价于把 $S_i$ 视为 $+\infty$ 排除。题面保证存在最佳牧场，故至少一个候选 `ok` 为真，`ans` 会被合法赋值。证毕。

---

### 引理 5（数值范围与溢出防护）

真实距离 $d(i,j)\le(P-1)\cdot891\le444609$；距离和 $S_i\le F\cdot444609\le2.223\times10^8<2^{31}-1$。Floyd 中两个有限距离之和 $\le889218$，`int` 安全；INF 对被跳过，不做 `inf+inf`。

*证明*：边权 $\le891$、顶点数 $P$，简单路至多 $P-1$ 条边，故 $d\le(P-1)\cdot891$。$P\le500$ 时 $\le499\times891=444609$。$S_i$ 是 $F\le500$ 个这样的距离之和 $\le500\times444609=222304500<2147483647$。Floyd 松弛 `dist[i][k]+dist[k][j]` 仅在两者均 $\ne$ `inf` 时执行，和 $\le2\times444609=889218$，远小于 `int` 上限。`inf=1145141919` 仅作哨兵比较，不参与加法，故无 `inf+inf` 溢出。求和与哨兵 `best` 用 `i64` 进一步留余量。证毕。

---

### 引理 6（复杂度）

时间 $O(P^3+P\cdot F)$，空间 $O(P^2)$。

*证明*：Floyd 三重循环各 $P$ 次，$O(P^3)$；枚举候选 $P$ 个、每个求和至多 $F$ 项，$O(PF)$；读入 $O(C)$。$P=500$ 时 $P^3=1.25\times10^8$ 次内层比较。空间主项为 $\texttt{dist}[P][P]$ 个 `int`，$500\times500\times4\approx1$ MB。证毕。

---

### 定理

程序输出距离和最小（即平均最短用时最小）的牧场编号，平局取最小编号；时间 $O(P^3+PF)$，空间 $O(P^2)$。

*证明*：引理 1 把平均目标转成整数和；引理 2 保证 Floyd 算出正确的全源最短路；引理 4 排除不可达候选；引理 3 保证平局取最小编号；引理 5 保证无溢出；引理 6 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 平均最小 $\iff$ 距离和最小（$F$ 固定正常数）；无向图距离对称，全程整数无浮点。
2. **consider easier version** — 单源最短路是子问题；$F$ 个喜欢点各跑 Dijkstra 可行，但 $P\le500$ 更提示全源。
3. **classic problem solution** — Floyd-Warshall 全源最短路 $O(P^3)$，$k$ 在最外层，原地更新因非负权而合法。
4. **discuss by category** — 重边取 min、对角线置 0、不可达候选跳过、平局用严格小于取小编号。
5. **explore its property** — 值域估计防溢出：INF 不参与加法，距离和用 `i64`，全局数组必须显式 `fill` 成 INF。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $P,F,C$ | 牧场数、喜欢数、路数 | `int p,f,c` | 读入 |
| `fav[j]` | 第 $j$ 个喜欢牧场（0-based） | `int[mxn]` | 读入 `--fav[i]` |
| `dist[i][j]` | $i\to j$ 最短路距离 | `int[mxn][mxn]` | **`fill` 成 `inf`**，对角线 $0$，重边取 min |
| `inf` | 不可达哨兵 $1145141919$ | `constexpr int` | 只比较、不参与加法 |
| `s` | 候选 $i$ 到全部喜欢点的距离和 $S_i$ | `i64` | 每候选重置 $0$ |
| `ok` | 候选 $i$ 是否可达全部喜欢点 | `bool` | 遇 `inf` 置假并 break |
| `best` | 当前最小距离和 | `i64` | 初值大哨兵 $1145141919810$ |
| `ans` | 最优牧场下标（0-based） | `int` | 严格小于更新，平局留最小 |

### 算法步骤

1. I/O 加速三行。
2. 读 $P,F,C$；读 $F$ 个喜欢点存 `fav`（转 0-based）。
3. `fill_n(&dist[0][0],mxn*mxn,inf)`；对 $i<P$ 置 `dist[i][i]=0`。
4. 读 $C$ 条边 `u,v,w`（`--u;--v`），`dist[u][v]=dist[v][u]=min(原值,w)`。
5. Floyd：$k$ 外、$i$ 中、$j$ 内；`dist[i][k]==inf` 跳过；否则 `dist[k][j]!=inf` 时松弛。
6. 枚举候选 $i=0..P-1$：累加 `dist[i][fav[j]]`，遇 `inf` 则 `ok=false` 跳出；`ok && s<best` 时更新 `best,ans`。
7. 输出 `ans+1` 与 `'\n'`。

### 复杂度

- 时间：$O(P^3+PF)$，$P=500$ 时约 $1.25\times10^8$ 次内层操作。
- 空间：$O(P^2)\approx1$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面示意图数据输出 `10`（与表格逐项吻合）；另造"纯平局""带捷径"两组手算数据全对；$P=500,F=500,C=8000$ 极限数据正常跑完。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2935 [USACO09JAN] Best Spot S
// P<=500 ⇒ Floyd 求全源最短路 O(P^3)；平均距离最小 ⇔ 距离和最小（F 固定）
// 顺序枚举候选点 + 严格小于更新 ⇒ 平局自动取编号最小
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{505},inf{1145141919};

int p,f,c,dist[mxn][mxn],fav[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>p>>f>>c;
	for(int i=0;i<f;++i)
	{
		cin>>fav[i];--fav[i];
	}
	fill_n(&dist[0][0],mxn*mxn,inf);	// 全局默认 0 不是 INF，必须显式填
	for(int i=0;i<p;++i)
		dist[i][i]=0;
	for(int i=0,u,v,w;i<c;++i)
	{
		cin>>u>>v>>w;--u;--v;
		dist[u][v]=min(dist[u][v],w);	// 重边取最小
		dist[v][u]=min(dist[v][u],w);
	}
	for(int k=0;k<p;++k)
		for(int i=0;i<p;++i)
		{
			if(dist[i][k]==inf)continue;
			for(int j=0;j<p;++j)
				if(dist[k][j]!=inf&&dist[i][k]+dist[k][j]<dist[i][j])
					dist[i][j]=dist[i][k]+dist[k][j];
		}
	i64 best{1145141919810};
	int ans=0;
	for(int i=0;i<p;++i)
	{
		i64 s=0;
		bool ok=true;
		for(int j=0;j<f;++j)
			if(dist[i][fav[j]]==inf){ok=false;break;}
			else s+=dist[i][fav[j]];
		if(ok&&s<best){best=s;ans=i;}
	}
	cout<<ans+1<<'\n';
	return 0;
}
```

### 代码说明

- **`fill_n(&dist[0][0],mxn*mxn,inf)` 是生死线**：全局 `int` 默认 $0$，不显式填 INF 会把"无边"当成零距，最短路全盘皆错（风格规范里专门强调的陷阱）。
- Floyd 的 `k` 必须在最外层；`if(dist[i][k]==inf)continue` 与内层 `dist[k][j]!=inf` 双重防护，确保 INF 不做加法（引理 5）。
- 重边用 `min` 合并而非覆盖；对角线 `dist[i][i]=0` 在填 INF 之后单独置。
- 平局靠"升序枚举 + 严格 `<`"自动取最小编号（引理 3），不要写成 `<=`。
- `s`、`best` 用 `i64`：虽然本题 `int` 也够（引理 5），但求和与哨兵留 64 位余量更稳。
- 输出 `ans+1` 把 0-based 还原成题面 1-based 编号。
