# P2871 [USACO07DEC] Charm Bracelet S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 裸的 0/1 背包：$N$ 件物品（$1\le N\le 3402$），背包容量 $M$（$1\le M\le 12880$），第 $i$ 件重 $W_i\le400$、价值 $D_i\le100$，每件**至多选一次**，求总重 $\le M$ 时的最大总价值。

**第一步：先试最便宜的两条路，都堵死。**

- **枚举子集**：$2^{3402}$ 种选法，宇宙毁灭也算不完。
- **贪心（按性价比 $D_i/W_i$ 排序能装就装）**：听起来很合理，但造一组最小反例就碎了——容量 $M=10$，物品 $(W,D)=(6,7),(5,5),(5,5)$。性价比 $7/6\approx1.17>1$，贪心先拿 $(6,7)$，剩容量 $4$ 装不下任何物品，得 $7$；而最优是两件 $(5,5)$，得 $10$。**贪心失败的根源**：背包的"剩余容量"是离散资源，拿一件高性价比物品可能把容量切成装不下任何东西的碎片，局部最优不等于全局最优。

两条路都堵死，说明必须**精确记录"容量换价值"的所有可能**——这正是 DP 的地盘。

**第二步：定义状态。** 选物品有"选/不选"两种决策，且决策只关心"还剩多少容量"，不关心之前具体选了谁（无后效性）。于是设
$$f[i][j]=\text{只考虑前 }i\text{ 件物品、总重}\le j\text{ 时的最大总价值}.$$
注意口径是"**不超过** $j$"而不是"恰好 $j$"——这个选择马上会带来一个初始化上的大便利（见第五步）。

**第三步：转移。** 对第 $i$ 件物品分两类：不选，则问题退回 $f[i-1][j]$；选（前提 $j\ge W_i$），则它贡献 $D_i$，其余物品在容量 $j-W_i$ 里随便选，即 $f[i-1][j-W_i]+D_i$。两类取 max：
$$f[i][j]=\max\bigl(f[i-1][j],\;f[i-1][j-W_i]+D_i\bigr)\quad(j\ge W_i).$$
边界 $f[0][j]=0$（一件不选，价值 $0$，合法）。答案 $f[N][M]$。这个转移为什么对？因为任何合法方案要么含第 $i$ 件要么不含，两类各自的最优就是上面两项——完整证明见第二部分。

**第四步：内存墙，以及滚动数组。** 二维数组 $3407\times12885$ 个 `int` 约 $175$ MB，大概率爆内存。盯着转移看：$f[i][\cdot]$ 只依赖 $f[i-1][\cdot]$，**更早的行全是废物**。于是只留一行 `dp[j]`，逐件物品原地刷新。但"原地"立刻埋了个雷：算 `dp[j]` 要用 `dp[j-W_i]`，如果这一轮已经把它刷新成"含第 $i$ 件"的值，第 $i$ 件就被**用了两次**——0/1 背包悄悄变成了完全背包。

**第五步：撞墙与最小反例。** 把 $j$ **从小到大**刷会怎样？造最小组：一件物品 $(W,D)=(2,3)$，$M=4$。升序：`dp[2]=max(0,dp[0]+3)=3`；接着 `dp[4]=max(0,dp[2]+3)=6`——物品被拿了两份！正确答案是 $3$。失败模式看得清清楚楚：升序时 `dp[j-W_i]` 已是**本层**值，转移变成了"在已经选过第 $i$ 件的方案上再选一次"。

**修复**：$j$ **从大到小**刷。这样算 `dp[j]` 时，$j-W_i<j$ 还没被本轮碰过，`dp[j-W_i]` 仍是**上一层**的值，恰好就是转移需要的 $f[i-1][j-W_i]$。一行数组、倒序循环，0/1 背包的标准形态。

**第六步：初始化的口径红利。** 因为状态是"总重 $\le j$"，空集对任何 $j$ 都合法、价值 $0$，所以 `dp` 全 $0$ 初始化**恰好正确**。这里要特别对照一个常见坑：若题目要求"恰好装满"，$0$ 就不是合法值，必须把不可达状态填成 $-\infty$；而全局 `int` 数组默认是 $0$ 不是 INF，那种题直接全局开数组会静默出错。本题是"不超过"口径，$0$ 是真实可达的值，默认零初始化反而是对的——**先想清楚口径，再决定要不要 `fill`**。

**手造数据核对**：$N=3,M=5$，物品 $(2,3),(3,4),(4,5)$。最优：选前两件，重 $5$ 价值 $7$。倒序滚动过程（只列非零变化）：
- 物品 $(2,3)$：`dp[5]=dp[4]=dp[3]=dp[2]=3`；
- 物品 $(3,4)$：`dp[5]=max(3,dp[2]+4)=7`，`dp[4]=max(3,dp[1]+4)=4`，`dp[3]=max(3,dp[0]+4)=4`；
- 物品 $(4,5)$：`dp[5]=max(7,dp[1]+5)=7`，`dp[4]=max(4,dp[0]+5)=5`。

输出 `dp[5]=7` ✓。注意第二件刷新 `dp[5]` 时用到的 `dp[2]=3` 还是第一件层的值（倒序保证），若升序就会错拿本层的 `dp[2]`。

## 二、思维链：完整证明

**记号。** 物品 $1..N$，重 $W_i$、值 $D_i$。$f[i][j]=\max\{\sum_{k\in S}D_k:S\subseteq\{1..i\},\sum_{k\in S}W_k\le j\}$，其中 $0\le j\le M$；空集合法，故 $f$ 处处有定义且 $\ge0$。滚动数组 `dp[0..M]`，处理第 $i$ 件时 $j$ 从 $M$ 递减到 $W_i$ 执行 `dp[j]=max(dp[j],dp[j-W_i]+D_i)`。

---

### 引理 1（性价比贪心不正确）

存在实例使"按 $D_i/W_i$ 降序能装就装"的贪心严格劣于最优。

*证明*：取 $M=10$，物品 $(6,7),(5,5),(5,5)$。性价比 $7/6>5/5=1$，贪心先选 $(6,7)$，剩余容量 $4<5$，后两件都装不下，贪心值 $7$。而选后两件总重 $10\le10$、总值 $10>7$。故贪心不最优。证毕。（这说明必须用能穷尽"容量分配"所有可能的算法，即 DP。）

---

### 引理 2（二维转移正确）

$f[0][j]=0$；对 $i\ge1$：$j<W_i$ 时 $f[i][j]=f[i-1][j]$；$j\ge W_i$ 时 $f[i][j]=\max(f[i-1][j],\,f[i-1][j-W_i]+D_i)$。

*证明*：$i=0$ 时可选集只有空集，价值 $0$，故 $f[0][j]=0$ ✓。

设 $i\ge1$，记 $\mathcal{S}$ 为 $\{1..i\}$ 中总重 $\le j$ 的子集族，按"是否含 $i$"划分成 $\mathcal{S}_0,\mathcal{S}_1$。

$\mathcal{S}_0$ 中的方案就是 $\{1..i-1\}$ 中总重 $\le j$ 的方案，其最大价值为 $f[i-1][j]$。

若 $j<W_i$：任何含 $i$ 的方案总重 $\ge W_i>j$，$\mathcal{S}_1=\varnothing$，故 $f[i][j]=f[i-1][j]$ ✓。

若 $j\ge W_i$：映射 $S\mapsto S\setminus\{i\}$ 是 $\mathcal{S}_1$ 到"$\{1..i-1\}$ 中总重 $\le j-W_i$ 的子集族"的**双射**（逆映射 $T\mapsto T\cup\{i\}$；重量条件 $\sum_{k\in S}W_k\le j\iff\sum_{k\in T}W_k\le j-W_i$），且价值差恒为 $D_i$。故 $\mathcal{S}_1$ 的最大价值 $=f[i-1][j-W_i]+D_i$。

$\mathcal{S}=\mathcal{S}_0\sqcup\mathcal{S}_1$ 且 $\mathcal{S}_0$ 非空（含空集），有限集的最大值等于两部分最大值的 max，得转移式。证毕。

---

### 引理 3（倒序滚动 = 二维 DP）

处理完第 $i$ 件后，对所有 $0\le j\le M$ 有 $\texttt{dp}[j]=f[i][j]$。

*证明*：对 $i$ 归纳。$i=0$：`dp` 全 $0$（全局零初始化），$=f[0][j]$ ✓。

设处理第 $i$ 件前 $\texttt{dp}[j]=f[i-1][j]$ 对所有 $j$ 成立（**层间归纳假设**）。本轮 $j$ 从 $M$ 递减到 $W_i$。考察执行到某个 $j$ 的瞬间，断言：

- 下标 $>j$ 的格子已被本轮刷新；下标 $\le j$ 的格子**尚未被本轮触碰**，仍等于 $f[i-1][\cdot]$（**层内不变量**，由"递减"直接保证：本轮只处理过 $M,M-1,\dots,j+1$）。

于是 `dp[j-W_i]`（$j-W_i<j$）$=f[i-1][j-W_i]$，`dp[j]` 旧值 $=f[i-1][j]$，赋值后
$$\texttt{dp}[j]=\max(f[i-1][j],f[i-1][j-W_i]+D_i)=f[i][j]$$
（最后一步用引理 2）。赋值只改下标 $j$，层内不变量对下一个 $j-1$ 保持。

循环结束后：$j\ge W_i$ 的格子都已被赋成 $f[i][j]$；$j<W_i$ 的格子没被碰过，值仍是 $f[i-1][j]$，而引理 2 说此时 $f[i][j]=f[i-1][j]$，同样吻合。故整行 $=f[i][\cdot]$，归纳完成。证毕。

---

### 引理 4（升序滚动错误：一件物品被重复选）

若把循环改成 $j$ 从 $W_i$ 递增到 $M$，则存在实例输出错误答案；且升序版本实际计算的是"每件可选无限次"的完全背包。

*证明*：反例：$N=1,M=4,(W_1,D_1)=(2,3)$。升序：$j=2$ 时 `dp[2]=max(0,dp[0]+3)=3`；$j=3$ 时 `dp[3]=max(0,dp[1]+3)=3`；$j=4$ 时 `dp[4]=max(0,dp[2]+3)=6`。输出 $6$，而唯一物品只能选一次，正确答案 $3$。错误机理：$j=4$ 用到的 `dp[2]` 已含第 $1$ 件，再加一次等于选了两份。

一般地，升序时 `dp[j-W_i]` 是本轮已刷新的值，归纳可证它等于"前 $i$ 件、第 $i$ 件**不限次数**、容量 $\le j-W_i$"的最优值，故升序转移恰是完全背包的转移。本题要求 0/1，升序必错（只要某件物品能被装 $\ge2$ 份就能构造出偏差）。证毕。

---

### 引理 5（零初始化的合法性与答案）

`dp` 全 $0$ 初始化正确，答案为 `dp[M]`；全程 `int` 不会溢出。

*证明*：由引理 2，$f[0][j]=0$ 对所有 $j$ 成立——因为口径是"总重 $\le j$"，空集永远合法。这与"恰好装满"型背包（不可达状态需 $-\infty$，全局默认 $0$ 会出错）形成对照：本题 $0$ 是真实可达值，零初始化恰好是边界本身。

答案：$f[N][M]$ 按定义就是全物品、容量 $M$ 的最优值，引理 3 保证 `dp[M]`$=f[N][M]$。

值域：任何方案价值 $\le\sum D_i\le N\cdot100=340200<2^{31}-1$，中间量 `dp[j-W]+D` 同样 $\le340200$，`int` 安全。证毕。

---

### 引理 6（复杂度）

时间 $O(NM)$，空间 $O(M)$。

*证明*：每件物品刷至多 $M$ 个格子，每格 $O(1)$，共 $O(NM)\le3402\times12880\approx4.4\times10^7$ 次基本操作，时限内轻松。空间只有一个长度 $M+1$ 的 `int` 数组（约 $51$ KB）加常数。证毕。

---

### 定理

程序输出 0/1 背包最优值，时间 $O(NM)$、空间 $O(M)$。

*证明*：引理 1 排除贪心、确立 DP 必要性；引理 2 给出正确的二维转移；引理 3 证明倒序滚动逐层等于二维 DP；引理 4 说明倒序不可替换为升序；引理 5 保证初始化与答案口径、值域；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **consider easier version** — 先试枚举 $2^N$ 与性价比贪心；贪心被 $(6,7),(5,5),(5,5),M=10$ 的最小反例击碎。
2. **classic problem solution** — 0/1 背包二维 DP：$f[i][j]=\max(f[i-1][j],f[i-1][j-W_i]+D_i)$，按"含不含第 $i$ 件"分类。
3. **reduce to easier problem** — 行依赖只有上一层 ⇒ 滚动成一维 `dp[j]`，内存 $175$ MB → $51$ KB。
4. **explore its property** — 升序刷新会复用本层 `dp[j-W]`，物品被选两次；单物品 $(2,3),M=4$ 反例输出 $6\ne3$。
5. **classic problem solution** — 倒序循环 $j=M..W_i$：$j-W_i<j$ 未被触碰，天然保持上一层语义。
6. **discuss by category** — "不超过容量"口径 ⇒ 全 $0$ 初始化合法（对照"恰好装满"必须填 $-\infty$ 的坑）；价值上界 $340200$，`int` 足够。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 物品数，$\le3402$ | `int` | 读入 |
| `m` | 背包容量，$\le12880$ | `int` | 读入 |
| `w,d` | 当前物品的重量、价值（逐件读入的临时量） | `int` | 每件读入，不留数组 |
| `dp[j]` | 处理完已读物品后，总重 $\le j$ 的最大价值 | `int[mxm]` | 全 $0$（空集合法，**不是**哨兵） |
| `mxm` | $12880+5$ | `constexpr int` | 数组尺寸松弛 |

### 算法步骤

1. I/O 加速三行；读 `n,m`。
2. 逐件读 `w,d`；对 $j=m,m-1,\dots,w$ 执行 `dp[j]=max(dp[j],dp[j-w]+d)`（**倒序**）。
3. 输出 `dp[m]`。

### 复杂度

- 时间 $O(NM)\approx4.4\times10^7$。
- 空间 $O(M)$，约 $51$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 $(2,3),(3,4),(4,5),M=5$ 输出 $7$，与枚举全部 $8$ 个子集的最优一致；升序反例 $(2,3),M=4$ 手算确认倒序输出 $3$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2871 [USACO07DEC] Charm Bracelet S
// 思路：0/1 背包滚动数组。倒序刷 j，保证 dp[j-w] 还是上一层（不含当前物品）。
//       口径是"总重 <= j"，空集合法 ⇒ 全 0 初始化恰好正确，无需 INF。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxm{12885};

int n,m,dp[mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,w,d;i<n;++i)
	{
		cin>>w>>d;
		for(int j=m;j>=w;--j)	// 倒序！升序会把当前物品选两次（变完全背包）
			dp[j]=max(dp[j],dp[j-w]+d);
	}
	cout<<dp[m]<<'\n';
	return 0;
}
```

### 代码说明

- 物品**边读边处理**，连 `w[],d[]` 数组都省了：转移只依赖当前这一件。
- `for(int j=m;j>=w;--j)` 的倒序是 0/1 背包的灵魂：`j-w<j` 尚未被本轮刷新，`dp[j-w]` 保持上一层语义（引理 3 的层内不变量）。
- `dp` 全 $0$ 不是偷懒：口径"不超过 $j$"使空集对每个 $j$ 合法，$f[0][j]=0$ 就是边界。若换成"恰好装满"题，这里必须 `fill` 成 $-\infty$，否则全局默认的 $0$ 会被当成可达状态静默出错。
- 价值上界 $3402\times100=340200$，`int` 足够，无需 `i64`。
