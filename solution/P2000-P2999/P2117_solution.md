# P2117 小Z的矩阵 — 题解

## 一、解题过程：人类思考叙事

题目给一个 $N\times N$ 的 0/1 矩阵 $A$，定义特征值

$$G(A)=\left(\sum_{i=1}^{n}\sum_{j=1}^{n} A_{i,j}\cdot A_{j,i}\right)\bmod 2,$$

然后给 $Q$ 个操作：翻转第 $x$ 行、翻转第 $x$ 列、询问当前的 $G$。$N\le 1000$，$Q\le 5\times 10^5$。

先看这个双重求和里有什么。把求和拆成"对角线"和"非对角线"两部分：

- **对角线部分**（$i=j$）：$A_{i,i}\cdot A_{i,i}=A_{i,i}$，因为 $A_{i,i}\in\{0,1\}$，它的平方就是它自己。
- **非对角线部分**：$i\ne j$ 时，$(i,j)$ 这一项是 $A_{i,j}A_{j,i}$，而 $(j,i)$ 那一项是 $A_{j,i}A_{i,j}$——**完全相同**！两项相加是 $2A_{i,j}A_{j,i}$，是偶数，模 2 后为 0。

于是所有的非对角线项**两两抵消**，只剩下对角线：

$$G(A)\equiv \sum_{i=1}^{n}A_{i,i}\pmod 2.$$

也就是说，$G$ 就是**对角线上 1 的个数的奇偶性**。这是一个巨大的简化：整张 $N\times N$ 的矩阵，只需要留 $N$ 个对角线元素。

再看操作 1：翻转第 $x$ 行。哪些对角线元素受影响？只有 $A_{x,x}$（第 $x$ 行里，只有第 $x$ 列的元素在对角线上）。所以翻转第 $x$ 行，**恰好翻转 $A_{x,x}$ 这一个对角线元素**。

操作 2 同理：翻转第 $x$ 列，恰好翻转 $A_{x,x}$。

翻转一个 0/1 元素会使其奇偶性取反（0→1 或 1→0），所以：

- 每次操作 1 或操作 2，$G$ 的值**取反**（$g \leftarrow g \oplus 1$）。
- 操作 3 直接输出当前的 $g$。

而**翻哪一行、哪一列完全不重要**！不管 $x$ 是多少，效果都是"对角线 1 的个数的奇偶性翻转一次"。所以 $x$ 这个参数读进来丢掉即可（但必须读掉，否则后续输入会错位——这是个很容易踩的坑）。

至此算法变得极其简单：

1. 读矩阵时只累计对角线：`g ^= A[i][i]`（其余元素读进来直接丢）。
2. 逐个读操作：`op==3` 就把 `g` 的字符追加到输出串；否则读掉 $x$，然后 `g ^= 1`。
3. 输出所有询问结果拼成的串（**中间没有空格**）。

复杂度：读矩阵 $O(N^2)$，处理操作 $O(Q)$，共 $O(N^2+Q)$。空间 $O(N+Q)$（输出串最长 $Q$ 个字符；也可以边读边用 `cout` 输出，但题面要求"一行若干个数，中间没有空格"，用 `cout.put` 边读边输出更省空间，这里用字符串收集更直观）。

样例验证：官方样例给出 $3\times 3$ 矩阵

$$\begin{pmatrix}1&1&1\\0&1&1\\1&0&0\end{pmatrix},$$

对角线是 $1,1,0$，奇偶性 $=0$，即初始 $G=0$。样例 12 个操作输出 `01001`。

## 二、思维链：完整证明

**记号约定**：$A$ 为当前 $N\times N$ 的 0/1 矩阵，$A_{i,j}\in\{0,1\}$；$g=\left(\sum_i\sum_j A_{i,j}A_{j,i}\right)\bmod 2$。

**引理 1**：$g=\left(\sum_{i=1}^{N}A_{i,i}\right)\bmod 2$。

*证明*：把双重求和按下标是否相等拆成两部分：

$$\sum_{i=1}^{N}\sum_{j=1}^{N}A_{i,j}A_{j,i}=\sum_{i=1}^{N}A_{i,i}A_{i,i}+\sum_{\substack{1\le i,j\le N\\ i\ne j}}A_{i,j}A_{j,i}.$$

对角线部分：由 $A_{i,i}\in\{0,1\}$ 得 $A_{i,i}^2=A_{i,i}$，故为 $\sum_i A_{i,i}$。

非对角线部分：把下标对 $\{i,j\}$ 与 $\{j,i\}$ 配对（$i\ne j$，故二者不同）。每一对的贡献为

$$A_{i,j}A_{j,i}+A_{j,i}A_{i,j}=2A_{i,j}A_{j,i},$$

是偶数。所有非对角线项恰好被这样两两配对（因为 $\{i,j\}$ 与 $\{j,i\}$ 是不同的无序对，$\{i,j\}$ 中 $i<j$ 的恰有一半），故该部分之和是偶数，模 2 为 0。

于是整个和模 2 等于 $\sum_i A_{i,i}\bmod 2$。证毕。

**引理 2**：翻转第 $x$ 行后，$g$ 的值取反；翻转第 $x$ 列后，$g$ 的值同样取反。

*证明*：翻转第 $x$ 行即把 $A_{x,j}\leftarrow 1-A_{x,j}$ 对所有 $j$ 成立，矩阵其余元素不变。由引理 1，$g$ 只依赖对角线元素 $\sum_i A_{i,i}$。第 $x$ 行中被改动的元素里，只有 $A_{x,x}$ 在对角线上（其余 $A_{x,j}$ 的 $j\ne x$ 不在对角线上，且 $A_{j,x}$ 属于第 $j$ 行，$j\ne x$ 不被改）。故对角线和恰好变化 $A_{x,x}\to 1-A_{x,x}$，即变化量为 $1-2A_{x,x}$，是奇数（$A_{x,x}\in\{0,1\}$），模 2 后 $g$ 改变 1，$g\leftarrow g\oplus 1$。

翻转第 $x$ 列完全对称：只有 $A_{x,x}$ 是对角线元素且被改动，结论相同。证毕。

**引理 3**：经过任意操作序列后，算法维护的 `g` 变量等于当前矩阵的 $G$ 值。

*证明*：对操作数做归纳。

初始时算法读入矩阵并令 `g ^= A[i][i]` 对所有 $i$ 累积，结束时 `g` 等于 $\left(\sum_i A_{i,i}\right)\bmod 2$，由引理 1 等于初始 $G$。

设前 $t$ 个操作后 `g` 等于当前 $G$ 值。考察第 $t+1$ 个操作：
- 若为操作 1 或操作 2，由引理 2，当前 $G$ 变为 $g\oplus 1$；算法执行 `g ^= 1`，故等式保持。
- 若为操作 3，矩阵未变，$G$ 不变；算法不修改 `g`（只把它输出），故等式保持。

归纳完成。证毕。

**定理**：算法输出的所有询问结果都等于对应时刻矩阵的 $G$ 值。

*证明*：由引理 3，每次操作 3 时 `g` 恰为当前 $G$ 值，算法把它作为字符追加到输出串中。所有询问结果按顺序拼接且中间无空格，符合输出格式要求。证毕。

## 三、模式总结（按实际思考顺序）

1. **盯着式子看** — $\sum_i\sum_j A_{i,j}A_{j,i}$ 里，(i,j) 项和 (j,i) 项长得一模一样，而 $A_{i,j}^2=A_{i,j}$。
2. **发现抵消** — 非对角线项两两成对相加是 $2\times$ 整数，模 2 归零；只剩对角线。
3. **性质立刻降维** — $G$ = 对角线 1 的个数的奇偶性，于是整张矩阵只需记 $N$ 个对角线元素。
4. **分析操作的影响** — 翻第 $x$ 行，只有对角线上的 $A_{x,x}$ 被改；所以每次翻转都让奇偶性取反。
5. **发现操作参数无关紧要** — 不管 $x$ 是几，效果一样，$x$ 读进来丢掉即可。但**必须读掉**，否则输入错位。
6. **输出格式** — 所有询问结果拼成一个字符串输出，中间不能有空格。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $N$ | 矩阵阶数 | `int`，$\le 1000$ |
| $Q$ | 操作个数 | `int`，$\le 5\times 10^5$ |
| $A_{i,j}$ | 矩阵元素 | `int`，$\in\{0,1\}$ |
| `g` | 当前 $G$ 值（对角线 1 的个数的奇偶性） | `int`，$\in\{0,1\}$ |
| `out` | 收集的询问结果字符串 | `string` |

### 算法步骤

1. 读入 $N,Q$。
2. 读入矩阵：双层循环读 $N^2$ 个数，只有当 $i==j$ 时执行 `g ^= v`；其余元素读入即丢。
3. 循环 $Q$ 次读操作：
   - `op==3`：`out += char('0'+g)`。
   - 否则（`op==1` 或 `op==2`）：读掉参数 $x$（丢弃不用），然后 `g ^= 1`。
4. 输出 `out`。

### 复杂度

- 时间复杂度：$O(N^2+Q)$。读矩阵 $O(N^2)$，每个操作 $O(1)$。
- 空间复杂度：$O(Q)$，用于存放输出字符串（若边读边输出可降到 $O(1)$）。

### 验证状态

- 标程 `P2117.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例（$3\times 3$ 矩阵 + 12 个操作）输出 `01001`，与官方一致。
- 编写暴力 `P2117_brute.cpp`（真实维护矩阵，操作 1/2 真的翻转，查询按定义遍历求和）与对拍脚本 `P2117_check.py`，在随机小矩阵上对拍 **2000 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2117 小Z的矩阵
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,q;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>q;
	// G(A) mod 2 等于对角线元素之和 mod 2, 只需留对角线
	int g=0;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
		{
			int v;
			cin>>v;
			if(i==j) g^=v;
		}

	// 每次翻转行/列都恰好翻转一个对角元素, 即奇偶性取反
	string out;
	for(int k=0;k<q;++k)
	{
		int op;
		cin>>op;
		if(op==3) out+=char('0'+g);
		else
		{
			int x;
			cin>>x;	// 翻哪一行/列不影响结论, 但必须读掉
			g^=1;
		}
	}
	cout<<out<<'\n';
	return 0;
}
```

### 代码说明

- 只用 `g ^= v` 累计对角线，矩阵本体完全不存，空间从 $O(N^2)$ 降到 $O(Q)$。
- `g` 始终是 0 或 1，`g^=1` 就是取反，正好对应"翻转一个对角线元素使奇偶性改变"。
- 操作 1/2 的参数 `x` 必须读入：输入是流式的，漏读会导致后面所有操作错位。读进来后直接丢弃即可。
- 输出用字符串收集再一次性输出，符合"一行若干个数，中间没有空格"的要求；`char('0'+g)` 把 0/1 转成字符。
