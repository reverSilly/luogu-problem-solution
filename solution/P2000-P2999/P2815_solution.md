# P2815 IPv6地址压缩 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 输入一个**完全展开**的 IPv6 地址：$39$ 个字符，$8$ 组、每组 $4$ 位十六进制、组间用单个 `:` 隔开（形如 `2001:0db8:0000:0000:0123:4567:89ab:cdef`）。要求按规则压缩后输出：

1. 每组去掉前导 `0`（全 `0` 组保留一个 `0`）；
2. 用**一次** `::` 替换**最长**的连续全 `0` 组段；
3. 若最长段有多个，取**最靠前**的那段；
4. 若没有全 `0` 组（无法用 `::`），按规则 1 去前导零后正常输出。

题面特别强调这是 **Darwin（macOS）风格**：哪怕只有一个全 `0` 组，也要用 `::` 压缩（Windows/Linux 则不压单个 `0`）。

**第一步：先把输入拆开。** $39=8\times4+7$ 个冒号，结构完全固定：第 $i$ 组（$0$-based）就是子串 `s.substr(i*5,4)`。不需要任何字符串分割算法，按下标切即可。拆出 $8$ 个长度为 $4$ 的串。

**第二步：去前导零。** 对每组找到第一个非 `0` 字符的位置 $j$，取 `substr(j)`。若整组都是 `0`（$j$ 走到末尾），保留一个 `"0"`。实现上只要 `while(j<3&&t[j]=='0')++j;`——注意 `j<3` 而不是 `j<4`：这样即使前 $3$ 位都是 `0`，第 $4$ 位无论是不是 `0` 都至少保留一位，全 `0` 组自然得到 `"0"`，非全 `0` 组得到去零后的串。这一步把"全 `0` 组"统一表示成字符串 `"0"`，后面判断段就只需比较 `g[i]=="0"`。

**第三步：找最长、最靠前的全 `0` 段。** 这是全题唯一的"算法"。我从左到右扫 $8$ 组，维护"当前正在延伸的全 `0` 段 `[cl,cr]`"：

- 遇到 `"0"`：若当前无段（`cl==-1`）则 `cl=i`；更新 `cr=i`；
- 遇到非 `"0"`：当前段结束，若它比历史最优段**更长**就更新最优；然后清空当前段。

扫完后别忘了**收尾**：最后一段可能一直延伸到第 $7$ 组，循环里没机会触发"遇到非 `0`"的结算，要在循环外再结算一次。

**平局取最靠前**怎么保证？更新条件用**严格大于** `len>bst`。从左往右扫，先遇到的段先被记录；后面长度相同的段因为 `len>bst` 不成立而**不覆盖**，于是最优段始终是最早出现的那个最长段。这正是规则 3。

**这里我踩了一个坑**：最初把最优长度初始化为 `0`、用 `cr-cl>br-bl` 比较，结果**长度为 $1$ 的段**（`cr-cl=0`）永远不大于初始的 `0`，单个全 `0` 组就不会被压缩——直接违反 Darwin 规则。修正：用 `bst=0` 记录最优**长度**（而非下标差），段长算 `cr-cl+1`，单 `0` 段长 $1>0$ 就能被选中。

**第四步：拼输出。** 设最优段为 `[bl,br]`。输出 = 前缀组 `[0,bl)` 用单冒号连接 + `"::"` + 后缀组 `(br,7]` 用单冒号连接。边界全部自然处理：

- 段在开头（`bl=0`）：前缀为空，输出以 `::` 开头，如 `::1`；
- 段在结尾（`br=7`）：后缀为空，输出以 `::` 结尾，如 `1::`；
- 全 `0`（`bl=0,br=7`）：前后缀都空，输出 `::`；
- 段在中间：`a::b`。

连接时的冒号控制：前缀里第 $i$ 组前加 `:` 当且仅当 `i>0`；后缀里第 $i$ 组前加 `:` 当且仅当 `i>br+1`（即不是后缀第一组）。这样 `::` 与前后缀之间**不会多出冒号**。

**第五步：没有全 `0` 组的情况。** 若扫完 `bl==-1`，说明一组 `0` 都没有，无法用 `::`。此时按规则 1 去前导零后，把 $8$ 组用单冒号连接输出。

**关于规则 4"照原样输出"的解读（显式标注假设）**：题面规则 4 说"无法被压缩，此时请照原样输出"。我把它理解为"**无法使用 `::` 压缩**（不存在全 `0` 组），此时按规则 1 去前导零后正常输出 $8$ 组"。理由：规则 1（去前导零）是对**所有组**恒适用的基本格式化，题面例子 `2001:0db8:...:0123:...` 里非零组 `0123→123` 也去了零；若规则 4 要求保留前导零，会与规则 1 矛盾。在"恒去前导零"的解读下，当输入本就无前导零且无全 `0` 组时，输出恰好等于输入，规则 4 的"照原样"自动满足——这是让所有规则同时自洽的唯一读法。

**另一个假设**：题面样例的十六进制数字全为小写（`0db8`、`89ab`、`cdef`）。我**按原字符输出**，不做大小写转换；若输入含大写 `A-F` 也原样保留。

**手造数据核对**（题面给了压缩例子，直接用作检验）：

| 输入 | 去零后 $8$ 组 | 最长最前全 `0` 段 | 输出 |
|---|---|---|---|
| `2001:0db8:0000:0000:0123:4567:89ab:cdef` | `2001 db8 0 0 123 4567 89ab cdef` | `[2,3]` 长 $2$ | `2001:db8::123:4567:89ab:cdef` |
| `2001:0db8:0000:0000:0001:0000:0000:0000` | `2001 db8 0 0 1 0 0 0` | `[5,7]` 长 $3$ | `2001:db8:0:0:1::` |
| `2001:0db8:0000:0000:ffff:0000:0000:0001` | `2001 db8 0 0 ffff 0 0 1` | `[2,3]` 与 `[5,6]` 同长 $2$，取前 | `2001:db8::ffff:0:0:1` |
| `2001:0db8:ffff:0000:0123:4567:89ab:cdef` | `2001 db8 ffff 0 123 4567 89ab cdef` | `[3,3]` 长 $1$（Darwin 压单个） | `2001:db8:ffff::123:4567:89ab:cdef` |

## 二、思维链：完整证明

**记号。** 输入串 $s$ 长 $39$。第 $i$ 组原始串 $t_i=s[5i..5i+3]$（$0$-based，长 $4$）。去零后 $g_i$。全 `0` 段指极大的连续下标区间 $[l,r]$ 使 $g_l=\cdots=g_r=$`"0"`。

---

### 引理 1（按下标切组正确）

对 $0\le i<8$，`s.substr(i*5,4)` 恰为第 $i$ 组的 $4$ 位十六进制串，且 $8$ 组不重不漏覆盖全部 $32$ 个数字字符。

*证明*：完全展开地址的字符布局为：组 $0$ 占 $[0,3]$，冒号占 $4$；组 $1$ 占 $[5,8]$，冒号占 $9$；……组 $i$ 占 $[5i,5i+3]$，冒号占 $5i+4$（$i<7$）。总长 $5\times7+4+4=39$ ✓。故 `substr(i*5,4)` 取到的正是组 $i$ 的 $4$ 个数字字符，不含冒号。$i$ 从 $0$ 到 $7$ 覆盖 $[0,38]$ 中所有非冒号位。证毕。

---

### 引理 2（去前导零的实现正确）

`j=0; while(j<3&&t[j]=='0')++j; g=t.substr(j);` 得到的 $g$ 是 $t$ 去掉前导零后的结果，且全 `0` 组得 `"0"`、非全 `0` 组得至少一位的有效串。

*证明*：设 $t$ 的前导零个数为 $z$（$0\le z\le4$）。

- 若 $z\le3$：循环在 `j=z` 时因 `t[z]!='0'` 停止（$z<3$ 时）或 `j<3` 失败停止（$z=3$ 时 `j` 增到 $3$）。两种情况都有 `j=z`，`substr(z)` 去掉恰好 $z$ 个前导零，保留从第一个非零位起的串。$z=3$ 时保留最后一位（非零），正确。
- 若 $z=4$（全 `0`）：循环 `j` 从 $0$ 增到 $3$ 后 `j<3` 失败停止，`j=3`，`substr(3)` 保留最后一位 `"0"`。故全 `0` 组得 `"0"` ✓。

综上 $g$ 是"去前导零、至少留一位"的标准结果。特别地 $g=$`"0"` 当且仅当 $t$ 全 `0`（非全 `0` 组去零后首位非零，不可能等于 `"0"`）。证毕。

**推论**：判断"第 $i$ 组是否全 `0`"等价于判断 `g[i]=="0"`。

---

### 引理 3（扫描选出最长、最靠前的全 `0` 段）

从左到右扫描，用严格大于 `len>bst` 更新最优段，并在循环外结算末段。则最终 `[bl,br]` 是**长度最大**的全 `0` 段中**起始下标最小**的那个；若无全 `0` 组则 `bl==-1`。

*证明*：先证扫描枚举了**所有**极大全 `0` 段。当前段 `[cl,cr]` 在遇到 `"0"` 时延伸、遇到非 `"0"` 时结算并清空。每个极大全 `0` 段要么其后紧跟一个非 `"0"` 组（在循环内被结算），要么延伸到第 $7$ 组（在循环外被结算）。两种情况都恰好结算一次，不重不漏。

再证选出的段最长。`bst` 初始 $0$，每次结算用 `len=cr-cl+1>bst` 才更新，故 `bst` 单调不减且始终等于已结算段的最大长度。全部段结算完后 `bst` 为全局最大长度，`[bl,br]` 是某个达到该长度的段。

最后证最靠前。设 $S_1,S_2,\dots$ 为按起始下标递增枚举的段。第一个达到最大长度的段 $S_j$ 被记录（此前 `bst` 小于最大长度）。其后任何段 $S_{j'}$（$j'>j$）若长度等于最大长度，则 `len>bst` 为假（`bst` 已等于最大长度），不覆盖；若更短也不覆盖。故 `[bl,br]` 始终是 $S_j$，即最长段中最靠前者。

若无全 `0` 组，没有任何段被结算，`bl` 保持 $-1$。证毕。

**坑点复盘**：若用下标差 `cr-cl` 与初始 `br-bl=0` 比较，长度 $1$ 的段差为 $0$ 不大于 $0$，会漏掉单 `0` 段。改用真实长度 `cr-cl+1` 与 `bst=0` 比较即修复（长度 $1>0$）。

---

### 引理 4（输出拼接正确，含所有边界）

设最优段 `[bl,br]`（`bl!=-1`）。输出 = 前缀组 $g_0..g_{bl-1}$ 单冒号连接 + `"::"` + 后缀组 $g_{br+1}..g_7$ 单冒号连接。则该串是合法压缩地址，且展开后还原为原地址。

*证明*：分四部分核对。

(a) **前缀**：`for i in [0,bl): cout<<(i?":":"")<<g[i];`。$i=0$ 前不加冒号，$i>0$ 前加一个冒号，故前缀是 $g_0:g_1:\cdots:g_{bl-1}$（`bl=0` 时为空）。

(b) **`::`**：紧接前缀输出。它代表被压缩的全 `0` 段 $[bl,br]$。

(c) **后缀**：`for i in (br,7]: cout<<(i>br+1?":":"")<<g[i];`。后缀第一组 $i=br+1$ 前不加冒号（`i>br+1` 假），其余前加一个。故后缀是 $g_{br+1}:\cdots:g_7$（`br=7` 时为空）。

(d) **无多余冒号**：前缀末尾是 $g_{bl-1}$（无尾冒号），接 `::`；`::` 后接后缀首组（无前导冒号）。所以 `::` 两侧不会多出 `:`。边界：`bl=0` 前缀空 → 串以 `::` 开头；`br=7` 后缀空 → 串以 `::` 结尾；`bl=0,br=7` → 恰为 `::`。

**还原性**：把 `::` 展开为 $(br-bl+1)$ 个 `"0"` 组、其余组照抄，得到 $g_0..g_7$；再给每组补前导零至 $4$ 位即还原 $t_0..t_7$（引理 2 的去零是可逆的：补零恢复原 $4$ 位串）。故压缩串与原地址表示同一个 IPv6 地址。证毕。

---

### 引理 5（无全 `0` 组时的输出）

若 `bl==-1`，输出 $g_0:g_1:\cdots:g_7$（$8$ 组单冒号连接）。这是规则 1 去前导零后的标准形式；当输入无前导零时它等于输入本身。

*证明*：无全 `0` 组意味着无法使用 `::`（规则 2 要求至少一组 `0`）。规则 1 仍适用，故输出 $8$ 个去零组用单冒号连接。若每组原本就无前导零（$t_i=g_i$），则输出 $=t_0:\cdots:t_7=s$，即"照原样"。这与规则 4 自洽（见第一部分解读）。证毕。

---

### 引理 6（复杂度）

时间 $O(1)$（输入恒 $39$ 字符，$8$ 组），空间 $O(1)$。

*证明*：切组 $8$ 次、去零每组 $\le4$ 步、扫描 $8$ 组、拼接 $\le8$ 组，全部常数次操作。`g[8]`、`s` 为常数空间。证毕。

---

### 定理

程序输出题面规则（Darwin 风格：去前导零 + 最长最前全 `0` 段压成一次 `::`）下的压缩地址。

*证明*：引理 1 保证切组正确；引理 2 保证去零正确且 `"0"` 判据等价；引理 3 保证选出最长最前段（含单 `0` 段）；引理 4 保证拼接合法且可还原；引理 5 处理无 `0` 情形；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 完全展开地址结构固定（$8$ 组 $\times4$ 位 $+7$ 冒号 $=39$），按下标 `substr(i*5,4)` 切组，无需分割算法。
2. **reduce to easier problem** — 去前导零后全 `0` 组统一成 `"0"`，"找全 `0` 段"变成"找最长连续 `"0"` 段"。
3. **classic problem solution** — 线性扫描维护当前段 + 历史最优段，严格大于更新 ⇒ 最长且最靠前；循环外结算末段。
4. **explore its property** — 单 `0` 段也要压（Darwin）：用真实段长 `cr-cl+1` 与 `bst=0` 比较，避免下标差比较漏掉长度 $1$。
5. **discuss by category** — 段在首 / 尾 / 全 `0` / 中间 / 无 `0` 五类，靠前缀后缀的冒号控制统一拼接，`::` 两侧不多加冒号。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `s` | 输入的 $39$ 字符完全展开地址 | `string` | 读入 |
| `g[i]` | 第 $i$ 组去前导零后的串（全 `0` 组为 `"0"`） | `string[8]` | 由 `s.substr(i*5,4)` 去零得到 |
| `cl,cr` | 当前正在延伸的全 `0` 段左右端点 | `int` | $-1$ 表示无当前段 |
| `bl,br` | 历史最优（最长最前）全 `0` 段左右端点 | `int` | $-1$ 表示尚无全 `0` 段 |
| `bst` | 历史最优段长度 | `int` | $0$；用真实长度比较，单 `0` 段长 $1$ 可入选 |
| `i,j` | 循环变量 / 去零时的首个非零位 | `int` | 局部 |

### 算法步骤

1. I/O 加速三行；读入 `s`。
2. 对 $i=0..7$：取 `t=s.substr(i*5,4)`，`j=0; while(j<3&&t[j]=='0')++j;`，`g[i]=t.substr(j)`。
3. 初始化 `bl=br=-1,bst=0,cl=cr=-1`。
4. 扫 $i=0..7$：若 `g[i]=="0"` 则延伸当前段（`cl==-1` 时 `cl=i`，`cr=i`）；否则结算当前段（`cl!=-1&&cr-cl+1>bst` 时更新 `bst,bl,br`）并清空 `cl=cr=-1`。
5. 循环外再结算一次末段。
6. 若 `bl==-1`：输出 $g_0..g_7$ 单冒号连接，结束。
7. 否则：输出前缀 `[0,bl)` 单冒号连接 + `"::"` + 后缀 `(br,7]` 单冒号连接。

### 复杂度

- 时间：$O(1)$（$39$ 字符、$8$ 组，常数次操作）。
- 空间：$O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面 $4$ 个压缩例子逐字吻合，另造"全 `0` / 段在首 / 段在尾 / 无 `0`"四组边界手算全对。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2815 IPv6地址压缩
// 完全展开地址结构固定：substr(i*5,4) 切 8 组，去前导零（全 0 组留 "0"）。
// 线性扫描选最长、最靠前的连续 "0" 段（严格大于更新），压成一次 ::（Darwin：单个 0 也压）。
#include<bits/stdc++.h>
using namespace std;

string s,g[8];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	for(int i=0;i<8;++i)
	{
		string t=s.substr(i*5,4);
		int j=0;
		while(j<3&&t[j]=='0')
			++j;
		g[i]=t.substr(j);	// j<3 保证全 0 组也保留一个 "0"
	}
	int bl=-1,br=-1,bst=0,cl=-1,cr=-1;
	for(int i=0;i<8;++i)
	{
		if(g[i]=="0")
		{
			if(cl==-1)
				cl=i;
			cr=i;
		}
		else
		{
			if(cl!=-1&&cr-cl+1>bst)	// 严格大于 ⇒ 平局取最靠前
				bst=cr-cl+1,bl=cl,br=cr;
			cl=cr=-1;
		}
	}
	if(cl!=-1&&cr-cl+1>bst)	// 末段可能延伸到第 7 组，循环外结算
		bst=cr-cl+1,bl=cl,br=cr;
	if(bl==-1)	// 无全 0 组：去前导零后正常输出 8 组
	{
		for(int i=0;i<8;++i)
			cout<<(i?":":"")<<g[i];
		cout<<'\n';
		return 0;
	}
	for(int i=0;i<bl;++i)
		cout<<(i?":":"")<<g[i];
	cout<<"::";
	for(int i=br+1;i<8;++i)
		cout<<(i>br+1?":":"")<<g[i];	// 后缀首组前不加冒号，避免 :::
	cout<<'\n';
	return 0;
}
```

### 代码说明

- `while(j<3&&t[j]=='0')` 的 `j<3` 是关键：它让全 `0` 组停在 `j=3`、保留最后一位 `"0"`，而非删成空串。
- `bst` 记录**真实长度**、初值 $0$，配合 `cr-cl+1>bst`：单 `0` 段长 $1>0$ 能被选中（Darwin 规则），且严格大于保证平局取最靠前。
- 循环外的末段结算不可省：延伸到第 $7$ 组的段在循环内遇不到非 `"0"` 组来触发结算。
- 拼接时前缀用 `i?":":""`、后缀用 `i>br+1?":":""` 控制冒号，确保 `::` 两侧不出现多余冒号；段在首/尾/全 `0` 时前后缀自然为空。
- 按原字符输出，不做大小写转换（题面样例全小写）；规则 4 解读为"无全 `0` 组时去前导零后正常输出"，已在第一部分显式标注。
