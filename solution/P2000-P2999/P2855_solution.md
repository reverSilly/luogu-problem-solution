# P2855 [USACO06DEC] River Hopscotch S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一维河道，起点石头在 $0$，终点石头在 $L\le 10^9$，中间有 $N\le 5\times10^4$ 块石头，位置是 $(0,L)$ 内**互不相同**的整数。最多移走 $M\le N$ 块中间石头（起点终点不能动），最大化"相邻剩余石头间距的最小值"（奶牛只能从一块跳到下一块，所以最短跳跃 = 最小相邻间距）。输出这个最大值。

**第一步：先玩弄"移走一块石头"这个操作。** 移走位置 $x$ 的石头，等于把它左右两个间距 $a,b$ **合并**成 $a+b$。因为 $a+b\ge\min(a,b)$，合并只会让最小间距**不减**。两个直接推论：

- 移得越多越不吃亏：任何"移走 $\le M$ 块"的方案，再随便多移几块凑满 $M$ 块，最小间距不会变差。所以"**最多** $M$ 块"与"**恰好** $M$ 块"答案相同，后面只管"$\le M$"。
- 答案至少是 $1$（位置是互异整数，不移任何石头最小间距也 $\ge1$），至多是 $L$（全移走）。

**第二步：直接贪心选石头，撞墙。** 自然的贪心是"每次移走制造最小间距的那块石头"。但"移哪块"牵一发动全身：移走一块会同时改变两个间距，局部最优的移除未必给全局留好余地，$M$ 步之间的相互影响没法用简单交换论证收拾。组合优化直接做，$N=5\times10^4$ 规模下看不到多项式贪心的影子。

**第三步：换视角——"最大化最小值"是二分答案的招牌。** 不问"怎么移"，先问判定题：**给定 $d$，能否移走 $\le M$ 块石头，让所有相邻间距 $\ge d$？** 记为 `check(d)`。它显然单调：$d$ 可行则更小的 $d'$ 用同一套剩余石头也可行。于是答案 = 最大的可行 $d$，在 $[1,L]$ 上二分，$\lceil\log_2 L\rceil\approx30$ 次判定。

**第四步：判定题里的贪心——"能留就留"。** 固定 $d$ 后，从左往右扫石头，维护上一块**保留**石头的位置 `lst`（初始为起点 $0$）：当前石头与 `lst` 的距离 $<d$ 就移走它（计数 `cnt++`），否则保留并更新 `lst`。直觉：保留一块石头总是"免费"的（不耗移除额度），而且尽早保留让 `lst` 尽量靠左，给后面留的空间最大。

但这个直觉有个隐患要正视：**保留石头会把参照点 `lst` 右移，会不会反而逼后面移更多？** 比如间距序列 $[d-1,\,d-1,\,2d]$：第一块太近移走，第二块距起点 $2d-2\ge d$（$d\ge2$）保留……看起来"能留就留"没吃亏。要严格放心，得证"贪心保留的石头数 $\ge$ 任何合法方案"。证明的钥匙是一个**左端点归纳**：设贪心保留的第 $i$ 块位置为 $g_i$，任何合法方案保留的第 $i$ 块为 $s_i$，则 $g_i\le s_i$——贪心的保留位置永远最靠左，于是"贪心已经没石头可留"时任何方案也不可能有更多。完整证明见引理 3、4。

**第五步：终点锚是个坑。** 扫完 $N$ 块中间石头后，还要检查最后一段 `L-lst`：若 $<d$，终点不能移，只能**回头移走最后一块保留的中间石头**。这一移就够了吗？够：设倒数第二块保留石头在 $p$，则 `lst`$-p\ge d$（它当初被保留的条件），合并后 $L-p=(L-\texttt{lst})+(\texttt{lst}-p)>d$，一段达标，且只多花 $1$ 次移除。会不会 `lst` 就是起点（没有中间石头可移）？不会：那要求 $L<d$，而二分范围 $d\le L$。所以 `check` 末尾一句 `if(L-lst<d)++cnt;` 恰好补上这一刀。

**第六步：二分写法。** 求最大可行值，用偏上界模板：`l=1,r=L`，`mid=(l+r+1)>>1`，可行则 `l=mid` 否则 `r=mid-1`，终值 `l` 即答案。$N=0$ 时 `check` 恒真（$d\le L$），答案 $L$，模板自动覆盖。

**手造数据核对**（题面提示给了移除前后的间距信息，我据此反推一组，再补两组边界）：

第一组，按提示反推：$L=25,N=5,M=2$，石头 $2,11,14,17,21$。

```
25 5 2
2
11
14
17
21
```

提示说移走 $2$ 和 $14$ 后最短跳跃为 $4$（$17\to21$、$21\to25$）。手算 `check(4)`：$2$ 太近移走（cnt=1），$11$ 保留，$14$ 距 $11$ 为 $3<4$ 移走（cnt=2），$17,21$ 保留，末段 $25-21=4\ge4$，cnt=2 $\le M$ ✓。`check(5)`：移 $2$、移 $14$、$21$ 距 $17$ 为 $4<5$ 移走，cnt=3 $>M$ ✗。故答案 $4$，与提示吻合。

第二组，$N=0$：`10 0 0` → 答案 $10$（只有起点终点）。

第三组，专打"末段补刀"：$L=10,N=2,M=1$，石头 $4,9$。`check(5)`：$4<5$ 移走（cnt=1），$9$ 保留，末段 $10-9=1<5$ → 补移 $9$（cnt=2）$>1$ ✗；`check(4)`：$4$ 保留，$9$ 距 $4$ 为 $5\ge4$ 保留，末段 $1<4$ 补移 $9$（cnt=1）$\le1$ ✓，剩余 $0,4,10$ 间距 $4,6$，答案 $4$。若漏了末段补刀会误判 `check(5)` 可行，输出 $5$——正是这个坑的抓法。

## 二、思维链：完整证明

**记号。** 石头位置排序后 $0<d_0<d_1<\dots<d_{N-1}<L$，锚点 $0$ 与 $L$ 不可移。一个方案是保留集 $S\subseteq\{0,\dots,N-1\}$，移除数 $N-|S|$；其最小间距 $\mathrm{gap}(S)$ 为序列 $0,(d_i)_{i\in S},L$ 的相邻差的最小值。`check(d)` 返回"是否存在移除数 $\le M$ 且 $\mathrm{gap}\ge d$ 的方案"。

---

### 引理 1（移除单调性；"最多 $M$" = "恰好 $M$"）

移走一块中间石头不会使最小间距减小。因此"移走 $\le M$ 块的最优答案"等于"移走恰好 $M$ 块的最优答案"。

*证明*：设当前相邻间距序列含 $\dots,a,b,\dots$（$a,b$ 是被移石头两侧的间距）。移走后变为 $\dots,a+b,\dots$，其余间距不变。新序列的最小值 $=\min(\text{其余间距},a+b)\ge\min(\text{其余间距},a,b)=$ 旧最小值（因 $a+b\ge a,\ a+b\ge b$）。故每移一块最小间距不减。

于是任何移除数 $t<M$ 的方案可再任移 $M-t$ 块（$M\le N$ 保证够移），最小间距不减，得到移除数恰 $M$ 的不劣方案；反向，恰好 $M$ 的方案类是 $\le M$ 方案类的子集。两边最优值相等。证毕。

---

### 引理 2（`check` 的单调性）

若 `check(d)` 为真且 $1\le d'\le d$，则 `check(d')` 为真。

*证明*：`check(d)` 为真给出保留集 $S$，移除数 $\le M$ 且所有相邻间距 $\ge d\ge d'$，同一 $S$ 即见证 `check(d')`。证毕。

**推论**：可行 $d$ 构成前缀区间 $[1,d^\*]$，二分求最大可行值合法。

---

### 引理 3（贪心保留位置最靠左）

固定 $d$。贪心从左到右扫描，`lst` 初始 $0$，遇到 $d_i-\texttt{lst}\ge d$ 就保留并令 `lst`$=d_i$，否则移走。设贪心保留的位置依次为 $g_1<g_2<\dots<g_k$；设 $S$ 是**任何**满足"相邻间距 $\ge d$（暂不含末段到 $L$）"的保留集，位置 $s_1<s_2<\dots<s_j$。则对一切 $i\le\min(k,j)$ 有 $g_i\le s_i$，且 $k\ge j$。

*证明*：先证 $g_i\le s_i$，对 $i$ 归纳。

$i=1$：$s_1$ 合法要求 $s_1-0\ge d$。贪心取的是**第一个**满足 $d_i\ge d$ 的石头，故 $g_1\le s_1$。

设 $g_{i-1}\le s_{i-1}$。$s_i$ 合法要求 $s_i-s_{i-1}\ge d$，于是 $s_i-g_{i-1}\ge s_i-s_{i-1}\ge d$，且 $s_i>s_{i-1}\ge g_{i-1}$，即 $s_i$ 是贪心在 $g_{i-1}$ 之后的一个候选。贪心取 $g_{i-1}$ 之后**第一个**与 $g_{i-1}$ 距离 $\ge d$ 的石头，故 $g_i$ 存在且 $g_i\le s_i$。

再证 $k\ge j$：若 $j>k$，则 $s_{k+1}$ 存在；由上段论证（取 $i=k+1$）贪心必能保留第 $k+1$ 块，与贪心只保留 $k$ 块矛盾。证毕。

---

### 引理 4（含末段修正的贪心移除数最少）

固定 $d\le L$。贪心扫完 $N$ 块石头后，若 $L-\texttt{lst}<d$ 则再移走最后一块保留石头（`cnt++`）。修正后的移除数 `cnt` 是所有"相邻间距全 $\ge d$（**含**末段到 $L$）"方案中的最小移除数。

*证明*：设贪心扫完保留 $g_1<\dots<g_k$（$k=0$ 时 `lst`$=0$）。分两种情形。

**情形 A：$L-g_k\ge d$**（或 $k=0$ 且 $L\ge d$）。贪心保留集本身合法，移除数 $N-k$。任取合法方案 $S$（$j$ 块），由引理 3，$k\ge j$，故 $N-k\le N-j$，贪心移除数最少。

**情形 B：$L-g_k<d$**。此时必有 $k\ge1$：若 $k=0$ 则 $L-0=L<d$，与 $d\le L$ 矛盾。贪心移走 $g_k$，保留 $g_1,\dots,g_{k-1}$，移除数 $N-k+1$。先验证修正后合法：前 $k-1$ 块之间间距 $\ge d$ 不变；末段变为 $L-g_{k-1}$（$k=1$ 时为 $L-0=L\ge d$）。$k\ge2$ 时 $L-g_{k-1}=(L-g_k)+(g_k-g_{k-1})>0+d\ge d$（因 $g_k$ 被保留要求 $g_k-g_{k-1}\ge d$，且 $L>g_k$）。故合法。

再证最少：任取合法方案 $S$（$j$ 块，含末段 $L-s_j\ge d$）。若 $j\ge k$，则 $s_k$ 存在，由引理 3 $g_k\le s_k$，于是 $L-s_k\le L-g_k<d$，与 $S$ 末段合法矛盾。故 $j\le k-1$，移除数 $N-j\ge N-k+1=$ 贪心移除数。证毕。

---

### 引理 5（`check` 正确）

`check(d)`（即 `cnt<=m`）$\iff$ 存在移除 $\le M$ 块使最小间距 $\ge d$ 的方案。

*证明*：由引理 4，`cnt` 是达到"全间距 $\ge d$"的最小移除数。存在移除 $\le M$ 的合法方案 $\iff$ 最小移除数 $\le M\iff$ `cnt<=m`。证毕。

---

### 引理 6（二分返回答案）

二分 `l=1,r=L`，`mid=(l+r+1)>>1`，`check(mid)` 真则 `l=mid` 否则 `r=mid-1`，终止时 `l` 等于最优答案 $d^\*$。

*证明*：先证答案 $\in[1,L]$：不移石头时位置互异整数 $\Rightarrow$ 最小间距 $\ge1$，故 $d^\*\ge1$；全移走得间距 $L$，且任何方案最小间距 $\le L$（总长 $L$ 被至少一段覆盖），故 $d^\*\le L$。

循环不变量：$d^\*\in[l,r]$。初始成立。每步：若 `check(mid)` 真，由引理 2 的单调性 $d^\*\ge$ `mid`，令 `l=mid` 保持；否则 $d^\*<$ `mid`，即 $d^\*\le$ `mid`$-1$，令 `r=mid-1` 保持。区间长度每步严格缩小（`mid` 偏上界保证 `l=mid` 时 `l` 增大、`r=mid-1` 时 `r` 减小），终态 `l==r`，由不变量 `l`$=d^\*$。证毕。

---

### 引理 7（复杂度）

时间 $O(N\log N+N\log L)$，空间 $O(N)$。

*证明*：排序 $O(N\log N)$。每次 `check` 线性扫 $N$ 块石头 $O(N)$；二分次数 $\lceil\log_2 L\rceil\le30$。合计 $O(N\log N+N\log L)\le 5\times10^4\times(16+30)\approx2.3\times10^6$。空间：位置数组 $O(N)$。数值：位置与间距 $\le L\le10^9$，`int` 够用（$10^9<2.1\times10^9$）；`mid=(l+r+1)>>1` 中 $l+r+1\le 2\times10^9+1<2^{31}$，不溢出。证毕。

---

### 定理

程序输出移走 $\le M$ 块石头后最小跳跃距离的最大值，时间 $O(N\log N+N\log L)$。

*证明*：引理 1 把"最多 $M$"化归为移除数约束；引理 2、5 保证判定单调且正确（其核心是引理 3 的左端点归纳与引理 4 的末段修正）；引理 6 保证二分收敛到最优；引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 移走石头 = 合并相邻间距，$a+b\ge\min(a,b)$ ⇒ 最小间距随移除不减 ⇒ "最多 $M$" = "恰好 $M$"。
2. **consider easier version** — 直接贪心选移除对象牵一发动全身，撞墙；改问判定题"间距全 $\ge d$ 能否 $\le M$ 次移除"。
3. **classic problem solution** — "最大化最小值" ⇒ 二分答案，单调性显然（同一方案见证更小 $d$），范围 $[1,L]$。
4. **classic problem solution** — 判定内贪心"能留就留"：左端点归纳 $g_i\le s_i$ 证保留数最多 ⇒ 移除数最少。
5. **discuss by category** — 末段 $L-\texttt{lst}<d$ 时补移最后一块保留石（一段合并即达标，恰 $+1$ 次）；$d\le L$ 保证有石可移。
6. **classic problem solution** — 偏上界二分 `mid=(l+r+1)>>1` 求最大可行值；$N=0$ 自动得 $L$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $L,N,M$ | 河长 / 中间石头数 / 移除额度 | `int L,n,m` | 读入 |
| `d[i]` | 第 $i$ 块中间石头位置（0-based，排序后） | `int[mxn]` | 读入后 `sort(d,d+n)` |
| `lst` | `check` 中上一块保留石头的位置 | `int`（局部） | 每次 `check` 置 $0$（起点锚） |
| `cnt` | `check` 中已移走的石头数 | `int`（局部） | 每次 `check` 置 $0$ |
| `check(x)` | 最小间距 $\ge x$ 的最少移除数是否 $\le M$ | `bool(int)` | 贪心扫描 + 末段补刀 |
| `l,r,mid` | 二分边界（闭区间，偏上界） | `int` | `l=1,r=L` |
| `mxn` | $50000+5$ | `constexpr int` | 石头数组尺寸 |

### 算法步骤

1. I/O 加速三行；读 $L,N,M$；读 $N$ 个位置到 `d[0..N)`，排序。
2. 二分：`l=1,r=L`；`mid=(l+r+1)>>1`；`check(mid)` 真则 `l=mid`，否则 `r=mid-1`。
3. `check(x)`：`lst=0,cnt=0`；扫每块石头，`d[i]-lst<x` 则 `++cnt`，否则 `lst=d[i]`；扫完若 `L-lst<x` 则 `++cnt`；返回 `cnt<=m`。
4. 输出 `l`。

### 复杂度

- 时间：$O(N\log N+N\log L)\approx2.3\times10^6$。
- 空间：$O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；按提示反推的 $L=25$ 数据答案 $4$ 吻合；$N=0$ 与"末段补刀"两组边界数据手算核对无误。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2855 [USACO06DEC] River Hopscotch S
// 思路：最大化最小值 ⇒ 二分答案 d；判定用贪心「能留就留」：
//       与上一块保留石距离 <d 就移走，否则保留。左端点归纳可证移除数最少。
//       末段 L-lst<d 时补移最后一块保留石（合并后必 >=d），恰 +1 次。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005};

int L,n,m,d[mxn];

bool check(int x)	// 全间距 >=x 的最少移除数是否 <=m
{
	int lst=0,cnt=0;	// lst=上一块保留石头的位置，起点锚 0
	for(int i=0;i<n;++i)
		if(d[i]-lst<x)
			++cnt;	// 太近，移走
		else
			lst=d[i];	// 能留就留：保留位置最靠左，给后面留最大余地
	if(L-lst<x)
		++cnt;	// 末段不够：移走最后一块保留石（x<=L 保证 lst>0，有石可移）
	return cnt<=m;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>L>>n>>m;
	for(int i=0;i<n;++i)
		cin>>d[i];
	sort(d,d+n);
	int l=1,r=L;	// 答案 ∈[1,L]；N=0 时恒可行，自动得 L
	for(;l<r;)
	{
		int mid=(l+r+1)>>1;	// 求最大可行值，偏上界取 mid
		if(check(mid))
			l=mid;
		else
			r=mid-1;
	}
	cout<<l<<'\n';
	return 0;
}
```

### 代码说明

- `check` 里 `lst` 存**位置**而非下标，起点锚 $0$ 与石头位置统一量纲，末段判断 `L-lst` 直接可写。
- 末段补刀 `++cnt` 的合法性：被补移的石头与它前一块保留石的间距 $\ge x$（当初保留的条件），合并后 $>x$，一刀够；且 $x\le L$ 排除"无石可移"的情形（引理 4）。
- 二分偏上界 `(l+r+1)>>1`：求最大可行值必须这样取，否则 `l=mid` 分支在 `l+1==r` 时死循环。
- `int` 够用：$L\le10^9$，`l+r+1`$\le2\times10^9+1<2^{31}$（引理 7）。
