# P2989 [USACO10MAR] Need For Speed S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 赛车基础力 $F$、基础质量 $M$。$N$ 个零件（$N\le 10^4$），第 $i$ 个提供力 $F_i$、增加质量 $M_i$（$1\le M,M_i\le 1000$，$1\le F,F_i\le 10^6$）。选一个零件子集 $S$，**第一目标**最大化比值

$$r(S)=\frac{F+\sum_{i\in S}F_i}{M+\sum_{i\in S}M_i};$$

**第二目标**在比值最大的前提下最小化总质量 $M+\sum_{i\in S}M_i$。输出选中零件的**原下标**，递增、每行一个；一个都不选则输出 `NONE`。题目保证最优解唯一。注意输入第一行顺序是 $F,M,N$。

**第一步：认出分数规划，先想二分。** 最大化 $\frac{\sum a}{\sum b}$ 是 0-1 分数规划的标准形状。经典做法：二分比值 $\lambda$，判定"是否存在 $S$ 使 $r(S)\ge\lambda$"，即 $\max_S\big[(F-\lambda M)+\sum_{i\in S}(F_i-\lambda M_i)\big]\ge 0$——每个零件独立决策，$F_i-\lambda M_i>0$ 就选。判定 $O(N)$，二分几十轮，复杂度没问题。

**第二步：精度墙。** 但本题要输出**精确的集合**，不是近似比值。两个不同的可达比值都是分母 $\le M+\sum M_i\le 1000+10^4\times1000\approx 10^7$ 的有理数，它们的最小差距可小到 $\frac{1}{10^7\times10^7}=10^{-14}$；而比值本身可达 $10^6$ 量级，`double` 在这个量级的 ulp 约 $10^{-10}$，**比最小差距大一万倍**。二分出的 $\lambda$ 用浮点比较 $F_i-\lambda M_i$ 的正负，完全可能把"恰好相等"（该不选，选了违反第二目标）判成"略大"（选）。浮点路线在本题不可靠。

**第三步：转而研究最优集合长什么样。** 设 $S^\*$ 是"比值最大且质量最小"的最优集，比值 $r^\*$。逐个零件考察：

- **$S^\*$ 里的零件**：把它拆掉，比值不能变大（否则 $S^\*$ 不是最优）。用"拆掉后比值 $\le r^\*$"交叉相乘化简，得到 $F_i\ge r^\* M_i$；若取等号，拆掉它比值**不变**而质量**变小**，违反第二目标——所以必须**严格** $F_i>r^\* M_i$。
- **$S^\*$ 外的零件**：把它装上，比值不能变大，同理得 $F_i\le r^\* M_i$。

两条合起来是一个惊人的刻画：

$$S^\*=\{\,i:\ F_i/M_i>r^\*\,\}.$$

**最优集不是"挑挑拣拣"，而是一个阈值切割**：零件自身比值严格高于最终比值的，全要；否则全不要。第二目标（最小质量）恰好把"等于阈值"的零件全部排除——这解释了题目为什么敢承诺解唯一。

**第四步：阈值切割 = 排序前缀，二分可以扔掉。** 把零件按 $F_i/M_i$ **降序**排序，则 $\{i:F_i/M_i>r^\*\}$ 恰是排序后的一个**前缀**！于是只需在 $N+1$ 个前缀里找最优。再看前缀比值 $R_k$（基础车 + 前 $k$ 个零件）的变化规律：加入第 $k+1$ 个零件使比值变大 $\iff$ 该零件自身比值 $>R_k$（加权平均的基本性质）。而零件比值随 $k$ 递减，所以 $R_k$ **先严格上升、一旦不升就永远不升**（单峰）。贪心呼之欲出：

> 按自身比值降序扫，只要装上能**严格**提高总比值就装，第一次不能提高就停。

停止时的前缀就是 $S^\*$（Part 2 引理 5 严格证明 greedy 前缀长度恰等于阈值切割的长度）。全程只用**交叉相乘的整数比较**，零浮点、零二分。

**第五步：范围核对。** 排序比较 $F_iM_j\le 10^6\times1000=10^9$；扫描比较 $F_i\cdot M_{\text{cur}}\le 10^6\times10^7=10^{13}$、$F_{\text{cur}}\cdot M_i\le 10^{10}\times1000=10^{13}$——**超 `int`，必须 `long long`**。这是本题第二个硬坑（第一个是浮点精度）。

**手造数据核对。** 题面无样例，造四组：

1. $F=15,M=5$，零件 $(F_i,M_i)=(10,2),(3,1),(8,4)$。自身比值 $5,3,2$，已降序。装 $1$：$10\times5=50>15\times2=30$ ✓，$F=25,M=7$；装 $2$：$3\times7=21\le25\times1=25$，停。输出 `1`。验证：$25/7\approx3.571$ 优于基础 $3$、优于 $\{1,2\}$ 的 $28/8=3.5$ ✓。
2. $F=10,M=1$，零件 $(5,1)$：$5\times1=5\le10\times1$，不装，输出 `NONE`。
3. **平局打第二目标**：$F=10,M=2$，零件 $(5,1)$：自身比值恰等于基础比值 $5$，$5\times2=10\le10\times1$ 取等，不装（装了比值不变质量变大），输出 `NONE` ✓——严格不等号在这里救了一命。
4. **乱序 + 多件**：$F=2,M=4$，零件 $(100,1),(1,1),(50,1)$，比值 $100,1,50$，排序后顺序为原下标 $1,3,2$。装 $1$：$100\times4>2$ ✓；装 $3$：$50\times5=250>102$ ✓；装 $2$：$1\times6=6\le152$，停。选中 $\{1,3\}$，按原下标升序输出 `1 / 3` ✓。

程序四组输出均与手算一致。

## 二、思维链：完整证明

**记号。** 基础 $(F,M)$，$M\ge1$；零件 $(F_i,M_i)$，$M_i\ge1$。对集合 $S$：$F_S=F+\sum_{i\in S}F_i$，$M_S=M+\sum_{i\in S}M_i\ge1$，$r(S)=F_S/M_S$。最优集 $S^\*$：在所有子集中 $r$ 最大，且其中 $M_S$ 最小。$r^\*=r(S^\*)$。零件自身比值 $\rho_i=F_i/M_i$。前缀比值 $R_k=r(\{\text{降序前 }k\text{ 个}\})$，$R_0=F/M$。

---

### 引理 1（加权平均比较律）

设 $B,b>0$。则 $\dfrac{A+a}{B+b}>\dfrac AB\iff\dfrac ab>\dfrac AB\iff aB>Ab$；把 $>$ 换成 $=$ 或 $<$ 结论同样成立。

*证明*：$\frac{A+a}{B+b}-\frac AB=\frac{B(A+a)-A(B+b)}{B(B+b)}=\frac{aB-Ab}{B(B+b)}$。分母 $>0$，故差的符号由 $aB-Ab$ 决定。而 $\frac ab-\frac AB=\frac{aB-Ab}{bB}$ 符号相同。三个关系同真同假。证毕。

**推论**：往车上装零件 $i$ 使总比值严格上升 $\iff F_iM_{\text{cur}}>F_{\text{cur}}M_i$；拆掉零件 $i$ 使比值不升 $\iff F_i\ge r^\*M_i$（对 $A=F_S-F_i,B=M_S-M_i,a=F_i,b=M_i$ 用等号/不等号版）。

---

### 引理 2（阈值刻画）

$S^\*=\{i:\rho_i>r^\*\}$，即：$i\in S^\*\Rightarrow F_i>r^\*M_i$（严格）；$i\notin S^\*\Rightarrow F_i\le r^\*M_i$。

*证明*：**内部零件**。设 $i\in S^\*$，考察 $S^\*\setminus\{i\}$（质量 $M_{S^\*}-M_i\ge M\ge1>0$，合法）。由 $r^\*$ 的最大性，$r(S^\*\setminus\{i\})\le r^\*$，即 $\frac{F_{S^\*}-F_i}{M_{S^\*}-M_i}\le\frac{F_{S^\*}}{M_{S^\*}}$。交叉相乘（分母均正）：$(F_{S^\*}-F_i)M_{S^\*}\le F_{S^\*}(M_{S^\*}-M_i)$，化简得 $F_iM_{S^\*}\ge F_{S^\*}M_i$，即 $F_i\ge r^\*M_i$。若取等号，则上式取等，$r(S^\*\setminus\{i\})=r^\*$ 仍最优，而质量少了 $M_i\ge1$，与 $S^\*$ 的**质量最小性**矛盾。故 $F_i>r^\*M_i$。

**外部零件**。设 $i\notin S^\*$，考察 $S^\*\cup\{i\}$。由最大性 $r(S^\*\cup\{i\})\le r^\*$，由引理 1（$A=F_{S^\*},B=M_{S^\*},a=F_i,b=M_i$）得 $F_iM_{S^\*}\le F_{S^\*}M_i$，即 $F_i\le r^\*M_i$。

两方向合起来：$i\in S^\*\iff F_i>r^\*M_i\iff\rho_i>r^\*$。证毕。

**推论（唯一性）**：满足"比值最大 + 质量最小"的集合被阈值 $r^\*$ 唯一确定，与题面"解决方案将是唯一的"承诺一致。

---

### 引理 3（最优集是降序前缀）

把零件按 $\rho_i$ 降序排序（相等任意序）。设 $k^\*=\#\{i:\rho_i>r^\*\}$。则 $S^\*$ 恰为排序后的前 $k^\*$ 个，且 $\max_{S}r(S)=\max_{0\le k\le N}R_k$。

*证明*：降序排列中，所有 $\rho>r^\*$ 的零件排在所有 $\rho\le r^\*$ 的零件之前（相等比值的零件同进同出：要么都 $>r^\*$ 要么都 $\le r^\*$，故并列顺序不影响前缀集合）。由引理 2，$S^\*$ 就是前 $k^\*$ 个。于是子集最优值 $r^\*=R_{k^\*}$ 在前缀中取到，前缀最大值 $\le$ 子集最大值又 $\ge R_{k^\*}=r^\*$，两者相等。证毕。

---

### 引理 4（前缀比值单峰）

$R_{k+1}>R_k\iff\rho_{k+1}>R_k$（$\rho_{k+1}$ 为第 $k+1$ 个零件的自身比值）。且一旦 $R_{k+1}\le R_k$，则对所有 $j\ge k$ 有 $R_{j+1}\le R_j$。

*证明*：第一句是引理 1 取 $A=F_{\text{前 }k},B=M_{\text{前 }k},a=F_{k+1},b=M_{k+1}$。

第二句：设 $R_{k+1}\le R_k$，则 $\rho_{k+1}\le R_k$。加权平均介于两者之间：$R_{k+1}\ge\min(R_k,\rho_{k+1})=\rho_{k+1}$（由引理 1 的等号/不等号版，$\rho_{k+1}\le R_k\Rightarrow R_{k+1}\ge\rho_{k+1}$）。而排序降序给出 $\rho_{k+2}\le\rho_{k+1}\le R_{k+1}$，再用第一句得 $R_{k+2}\le R_{k+1}$。对 $j$ 归纳即得"永不回升"。证毕。

---

### 引理 5（贪心恰取到 $S^\*$）

贪心算法"按降序扫，$F_iM_{\text{cur}}>F_{\text{cur}}M_i$ 则装，否则停"输出的集合恰为 $S^\*$。

*证明*：设贪心装了前 $g$ 个后停止（$g=0$ 表示第一个就不装）。证 $g=k^\*$。

**贪心不会提前停**（$g\ge k^\*$）：对每个 $j<k^\*$，第 $j+1$ 个零件满足 $\rho_{j+1}>r^\*$（引理 3），而 $R_j\le\max_k R_k=r^\*$（引理 3），故 $\rho_{j+1}>r^\*\ge R_j$，由引理 4 严格改进，贪心必装。归纳得前 $k^\*$ 个全被装上。

**贪心不会多装**（$g\le k^\*$）：若 $k^\*<N$，第 $k^\*+1$ 个零件满足 $\rho_{k^\*+1}\le r^\*=R_{k^\*}$，由引理 4 不严格改进，贪心在装完 $k^\*$ 个后停下。若 $k^\*=N$ 则无零件可多装。

故 $g=k^\*$，贪心集合 $=$ 前 $k^\*$ 个 $=S^\*$（引理 3）。特别地 $k^\*=0$ 时贪心输出空集，对应 `NONE`。证毕。

**注**：证明只用了"严格改进"与降序两条性质，不需要知道 $r^\*$ 的值——这正是算法能绕开二分与浮点的原因。

---

### 引理 6（精确整数运算与溢出边界）

所有比较用交叉相乘的 `long long` 整数完成，零误差；中间量上界 $\approx10^{13}$，`int` 必然不够，`long long` 余量充足。浮点路线不可靠。

*证明*：**范围**：$F_{\text{cur}}\le 10^6+10^4\times10^6=1.0001\times10^{10}$，$M_{\text{cur}}\le 1000+10^4\times1000=1.0001\times10^7$。扫描比较的两个乘积：$F_iM_{\text{cur}}\le 10^6\times1.0001\times10^7\approx10^{13}$，$F_{\text{cur}}M_i\le 1.0001\times10^{10}\times1000\approx10^{13}$，均超 $2^{31}\approx2.1\times10^9$ 而远小于 $2^{63}\approx9.2\times10^{18}$ ✓。排序比较 $F_iM_j\le10^9$ 虽在 `int` 边缘内，统一转 `i64` 更稳。整数乘法与比较无舍入，判定精确。

**浮点不可靠**：两个不同可达比值 $p/q\ne p'/q'$（$q,q'\le1.0001\times10^7$）满足 $|p/q-p'/q'|=\frac{|pq'-p'q|}{qq'}\ge\frac1{qq'}\ge 10^{-14}$，且该下界可达（相邻 Farey 分数）。比值最大可达 $\max(F/M,\rho_i)\le10^6$，`double` 在 $10^6$ 量级 ulp $\approx2^{20-52}\approx1.2\times10^{-10}\gg10^{-14}$。故存在合法数据使两个不同比值被 `double` 判等、或"恰好相等"被判成严格大——前者可能错排前缀，后者直接违反第二目标。整数路线不存在此问题。证毕。

---

### 引理 7（输出与复杂度）

选中零件按原下标升序输出、每行一个；空集输出 `NONE`。时间 $O(N\log N)$，空间 $O(N)$。

*证明*：贪心收集的是排序后的位置，存原下标 `a[i].i`，最后对 `ans` 排序即升序（题目要求）。排序 $O(N\log N)$（比较器 $O(1)$ 整数乘法），扫描 $O(N)$，输出排序 $O(N\log N)$。空间：零件数组与答案各 $O(N)$。证毕。

---

### 定理

程序输出的零件集合是"比值最大、其中总质量最小"的唯一最优集，全程精确整数运算，总复杂度 $O(N\log N)$。

*证明*：引理 1 提供加权平均比较律；引理 2 用最优性与质量最小性推出阈值刻画；引理 3 把阈值切割翻译成降序前缀，子集最优归约为前缀最优；引理 4 证明前缀比值单峰；引理 5 证明严格改进贪心恰取到阈值前缀即 $S^\*$；引理 6 保证整数比较精确且不溢出；引理 7 保证输出格式与复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **classic problem solution** — 认出 0-1 分数规划：二分 $\lambda$ + 逐项判 $F_i-\lambda M_i>0$，复杂度可行。
2. **explore its property** — 精度墙：可达比值最小间隙 $\sim10^{-14}$，而比值达 $10^6$ 时 `double` ulp $\sim10^{-10}$，浮点判定不可靠，必须精确算术。
3. **explore its property** — 研究最优集结构：拆件不升比值 + 装件不升比值 + 质量最小 ⇒ $S^\*=\{i:\rho_i>r^\*\}$，阈值切割。
4. **reduce to easier problem** — 阈值切割 = 按 $\rho_i$ 降序的前缀；$2^N$ 个子集归约为 $N+1$ 个前缀，二分整个扔掉。
5. **explore its property** — 前缀比值单峰（加权平均介于两者之间 + 零件比值降序）⇒ "严格改进才装，首次不改进即停"的贪心恰为最优。
6. **classic problem solution** — 交叉相乘代替除法：排序与扫描全部 `i64` 整数比较，乘积 $\le10^{13}$ 超 `int`。
7. **discuss by category** — 空集输出 `NONE`；比值相等不装（第二目标）；输出按原下标升序。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $F,M$ | 当前总力 / 总质量（含基础车） | `i64 F,M` | 读入 $F,M,N$；$F\le10^{10},M\le10^7$ |
| $N$ | 零件数 | `int n` | $\le10^4$ |
| `a[i]` | 排序后第 $i$ 个零件 `{f,m,i}` | `part[mxn]` | `i` 是 0-based 原下标，输出 `+1` |
| `mxn` | $10000+5$ | `constexpr int` | 零件数组尺寸 |
| `ans` | 选中零件的原下标（0-based） | `vector<int>` | 贪心收集，最后升序排序 |
| 比较器 | $\rho_x>\rho_y\iff x.f\cdot y.m>y.f\cdot x.m$ | `i64` 乘法 | 降序；相等返回 false，严格弱序合法 |
| 改进判据 | $F_iM_{\text{cur}}>F_{\text{cur}}M_i$ | `i64` 乘法 | **严格**大于，取等不装 |

### 算法步骤

1. I/O 加速三行；读 $F,M,N$ 与每个零件的 $F_i,M_i$，记录原下标。
2. 按 $F_i/M_i$ 降序排序（交叉相乘，`i64`）。
3. 顺序扫：若 `(i64)a[i].f*M>F*(i64)a[i].m` 则装上（`F+=f; M+=m;` 下标入 `ans`），否则 `break`。
4. `ans` 空则输出 `NONE`；否则升序排序后逐行输出 `x+1`。

### 复杂度

- 时间：$O(N\log N)$。
- 空间：$O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造四组（单件改进、`NONE`、比值相等打第二目标、乱序多件）与手算逐条一致；另验证 $F=1,M=1$ 四零件 $(10,1),(9,1),(8,1),(1,1)$ 输出 $\{1,2,3\}$（比值 $7$ 为前缀峰值）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2989 [USACO10MAR] Need For Speed S
// 最优集合恰为按 F_i/M_i 降序排列后、使总比值严格增大的前缀；交叉相乘精确比较
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};

struct part{int f,m,i;};

int n;
i64 F,M;	// 当前总力/总质量：F 可达 1e10，乘积可达 1e13，必须 i64
part a[mxn];
vector<int>ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>F>>M>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i].f>>a[i].m;
		a[i].i=i;
	}
	sort(a,a+n,[](const part&x,const part&y){return (i64)x.f*y.m>(i64)y.f*x.m;});
	for(int i=0;i<n;++i)
	{
		if((i64)a[i].f*M>F*(i64)a[i].m)	// 严格改进才装；相等会增质量不增比值
		{
			F+=a[i].f;M+=a[i].m;
			ans.push_back(a[i].i);
		}
		else break;	// 前缀比值单峰，一旦不改进后面永远不改进
	}
	if(ans.empty())
	{
		cout<<"NONE\n";
		return 0;
	}
	sort(ans.begin(),ans.end());
	for(int x:ans)
		cout<<x+1<<'\n';
	return 0;
}
```

### 代码说明

- **两处 `i64` 转换缺一不可**：比较器里 `(i64)x.f*y.m`（虽然 $\le10^9$ 勉强在 `int` 内，统一转更稳）；扫描里 `(i64)a[i].f*M` 与 `F*(i64)a[i].m`（$\le10^{13}$，`int` 必炸）。`F,M` 本身也声明为 `i64`。
- **严格大于号承载第二目标**：取等时零件比值恰等于当前比值，装了比值不变、质量变大，违反"质量最小"，所以 `>` 不能写成 `>=`。
- `break` 的合法性由单峰性（引理 4）保证：第一次不改进之后永远不改进，不需要扫完全部零件。
- 比较器对相等比值返回 `false`（两个方向都 false），是合法的严格弱序；相等零件同进同出，内部顺序不影响答案。
- 存的是**原下标** `a[i].i`，排序会打乱位置，最后必须对 `ans` 再排一次升序并 `+1` 输出。
- 输入顺序是 $F,M,N$（不是 $N$ 在前），读错顺序会全盘皆错。
