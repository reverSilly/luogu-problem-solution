# P2021 faebdc玩扑克 — 题解

## 一、解题过程：人类思考叙事

题面描述的操作其实很简单：

zky 有 $n$ 张牌，编号 $1 \sim n$，排成一个序列。然后重复做这个动作：

1. 把**最上方**（序列最前面）的牌放到**牌堆底**（序列最后面）；
2. 把**下一张**牌（此时的最上方）拿出来**输出**。

「最终输出的序列恰好是从 $1$ 到 $n$」，问原序列是什么。

翻译成数据结构语言：维护一个队列，每轮「队首移到队尾」，然后「弹出队首并输出它」。

那么反过来看：**输出的第 $v$ 个数是 $v$**，也就是说第 $v$ 轮被取走的那张牌，编号就是 $v$。于是我们不需要正着模拟再记录，而是可以**倒推**：

从「所有牌都还在」的状态出发，模拟 $n$ 轮，**第 $v$ 轮被拿走的那张牌**就是原序列中的第 $v$ 个位置上的牌……不对，注意是「原序列的哪个位置」。因为牌在序列里只会整体旋转和移除，**牌在原序列中的相对位置下标是不变的**。

关键洞察：整个过程中，牌堆始终是原序列的一个**子序列**（顺序不变），只是被"切"成两段（前面被移到末尾的那部分 + 剩余部分），并且随着取牌不断变短。所以只要维护牌的**原始下标**，就能知道每张牌在原序列中的位置。

那么怎么高效地模拟「队首移到队尾 + 弹出队首」？

朴素做法是用 `deque` 或数组 + 头尾指针。每次「队首移到底」在 `deque` 上是 $O(1)$ 的 `rotate`/`push_back`+`pop_front`，总共 $n$ 轮，$O(n)$。但本题要求用**数组**（洛谷不支持 `deque` 的话倒是无所谓，标准库有 `deque`；不过风格指南要求全局静态数组），而且输出要求的是**原序列**，即按原始下标从小到大输出每张牌的编号。

用数组模拟：维护 `que[0..len-1]` 表示当前牌堆顺序（用原始下标），队首是 `que[head]`。

- 「队首移到底」：`que[(head+len-1)%len] = que[head]`？不对，这样会覆盖末尾。
- 更简单：因为「队首移到底」等价于「把队首从数组里删掉，再追加到末尾」，所以就是循环左移一位：`que[0..len-2] = que[1..len-1]`，`que[len-1] = 原来的队首`，然后 `len--`，`que[0]` 就是取出的牌。

每次操作代价 $O(len)$，总代价 $O(n^2)$。$n \le 10^6$，$O(n^2) = 10^{12}$，**超时**。

所以必须做到 $O(n)$。怎么办？

观察「把队首移到队尾」这个操作在**循环意义下**的表现：想象牌围成一个圈，队首指向环上的某个位置。「队首移到底」= 队首指针沿环前进一格。然后「弹出队首」= 把这个位置从环上删掉，指针停在下一个位置。

于是整个过程就是：
- 一个环，初始 $n$ 个结点按原序列顺序排好；
- 一个指针 `cur` 指向环上的某个结点；
- 每轮：指针前进一格（`cur = nxt[cur]`），这个结点被"输出"，然后从环上删掉它，指针停在其后继。

用**数组模拟循环双向链表**即可：
- `nxt[i]`、`prv[i]` 表示结点 $i$ 在环上的后继与前驱；
- 删除结点 $i$：`nxt[prv[i]] = nxt[i]; prv[nxt[i]] = prv[i];`
- 全部 $O(1)$，总复杂度 $O(n)$。

关于「输出顺序」：题目要输出的是**原序列**（即每个原始位置上放的是哪张牌）。所以我记录 `ans[被取走的结点的原始下标] = v`，最后按 `ans[0], ans[1], ..., ans[n-1]` 输出。

等等，这里要再确认一遍语义。题目说「zky 把它排成一个序列，每次把最上方的扑克牌放在牌堆底，然后把下一张扑克牌拿出来输出，最终输出的序列恰好是从 1 到 n，faebdc 问你原序列是什么」。

所以：原序列 = 输入需要输出的那个序列。我们要求的是「原始位置 $i$ 上放的是编号几的牌」。所以 `ans[i]` = 原序列第 $i+1$ 个位置的编号。而 `ans[i]` 应该是「第 $i$ 个被取出的牌（按取出顺序）」，因为取出顺序就是 $1,2,\dots,n$。

也就是说：**第 $i$ 个被取走的牌（在环上的原始位置）就是原序列的第 $i+1$ 个元素**。

再理一遍：设环上结点 $i$ 的原始下标为 $i$（结点编号即原始位置）。取出顺序为 $v=1,2,\dots,n$。第 $v$ 轮取出的结点记作 $pos_v$，它的编号是 $v$。原序列第 $i+1$ 个位置的牌，其编号是多少？如果结点 $i$ 在第 $v$ 轮被取出，则它的编号是 $v$，而它在原序列中的位置是 $i$。所以 `ans[i] = v`。✓ 就是我代码里写的 `ans[cur] = v`。

## 二、思维链：完整证明

**定义**：把原序列的位置 $0,1,\dots,n-1$ 称为结点编号（结点编号即位置，与牌上印刷的编号无关）。牌上印刷的编号按取出顺序为 $1,2,\dots,n$。

**引理 1**：在操作过程中，牌堆中牌的顺序始终是原序列的一个子序列（保持原有相对顺序）。

*证明*：初始时牌堆就是原序列，结论成立。一次操作包含两个动作：（a）把队首移到队尾；（b）弹出队首。动作 (b) 从序列中删除一个元素，不改变其余元素的相对顺序。动作 (a) 把第一个元素移到最后，相对顺序是 $(x, a_2,\dots,a_t) \to (a_2,\dots,a_t,x)$，即 $x$ 从最前面移到了最后面，其余元素的相对顺序不变，仍是原序列的一个子序列。归纳即得。证毕。

**引理 2**：可以用「环 + 指针」精确刻画操作：设环上按顺时针排列着当前牌堆的顺序，环被切成两段——从指针处顺时针到某个断点为前半段（这段的元素在原序列中靠后），从断点顺时针回到指针为后半段（靠前）。则「队首是前半段的第一项，队尾是后半段的最后一项」，即环从指针处开始的线性展开恰好等于当前牌堆顺序。

*证明*：初始时环为 $0\to1\to\dots\to n-1\to0$，指针在 0，无断点（整圈），展开为 $0,1,\dots,n-1$，与初始牌堆一致。设某时刻成立，指针在 $p$。动作 (a)「队首移到底」使队首变为原第二项，等价于把指针从 $p$ 移到 $p$ 的后继：此时从新指针展开，序列为「原第二项, …, 队尾, 原队首」，正是操作后的牌堆，且断点位置不变（仍是一个线性展开，只是起点右移一位，且当指针走过断点时展开自然接上）。动作 (b)「弹出队首」即删除当前指针所指的结点，删除后指针停在其后继；从新指针展开，被删的是原来展开序列的第一项，剩余为展开序列去掉首项，正是弹出后的牌堆。归纳即得。证毕。

**引理 3**：删除环上结点 $i$ 的正确操作为 `nxt[prv[i]] = nxt[i]; prv[nxt[i]] = prv[i];`，且删除后其余结点的相对环序不变。

*证明*：在循环双向链表中，结点 $i$ 的前驱为 `prv[i]`、后继为 `nxt[i]`。把前驱的后继指向 $i$ 的后继、后驱的前驱指向 $i$ 的前驱，就把 $i$ 从链上摘除，其余结点的前驱后继关系全部保持不变，故环序不变。证毕。

**引理 4**：算法记录的 `ans[i]` 等于原序列第 $i+1$ 个位置上那张牌的印刷编号。

*证明*：第 $v$ 轮取出的是印刷编号为 $v$ 的牌（题目规定输出序列恰为 $1,\dots,n$）。由引理 2、3，算法用环与指针精确模拟了每轮的「队首移到底」与「弹出队首」，因此算法在第 $v$ 轮弹出的结点 `cur` 就是真实操作在该轮取出的那张牌所在的原始位置。算法令 `ans[cur] = v`，即在该原始位置上记录了印刷编号 $v$。由引理 1，取出过程不改变牌的相对顺序，故原始位置与取出的对应关系正确。证毕。

**引理 5**：算法的时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

*证明*：建环 $O(n)$；每轮只做常数次指针操作（前进一格、删除结点），共 $n$ 轮，$O(n)$；输出 $n$ 个数，$O(n)$。空间上使用三个长度为 $n+5$ 的整型数组（`ans`、`nxt`、`prv`），$O(n)$。证毕。

**定理**：算法输出的序列即为满足题意的原序列。

*证明*：由引理 4，`ans[i]` 恰为原序列第 $i+1$ 个位置的印刷编号；由引理 2、3，模拟过程与真实操作完全一致，故算法输出的序列正是一次真实操作的输入。由引理 5，复杂度满足 $n\le 10^6$ 的限制。证毕。

## 三、模式总结（按实际思考顺序）

1. **翻译操作** — 「队首移到底 + 弹出队首」，本质是一个队列的循环左移与出队。
2. **发现可倒推** — 输出序列固定为 $1,\dots,n$，第 $v$ 轮取出的牌编号就是 $v$，所以只需记录"哪张牌在第几轮被取走"。
3. **识别朴素模拟的瓶颈** — 数组循环左移是 $O(n^2)$，$n=10^6$ 不可行。
4. **结构升级：环 + 指针** — 「队首移到底」在环上就是指针前进一格；「弹出」就是删结点（引理 2）。
5. **用数组模拟循环双向链表** — `nxt` / `prv` 两个数组，删除结点 $O(1)$（引理 3）。
6. **输出顺序的坑** — 要的是**原序列**，不是取出顺序，所以必须按原始下标记录 `ans[cur] = v`。
7. **$O(n)$** — 满足 $10^6$ 的数据范围。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 牌的总数 | `int`，$\le 10^6$ |
| 结点编号 $i$ | 原始位置 $i$（0-based） | `int`，$[0,n-1]$ |
| `nxt[i]` | 结点 $i$ 在环上的后继 | `int` |
| `prv[i]` | 结点 $i$ 在环上的前驱 | `int` |
| `ans[i]` | 原始位置 $i$ 上那张牌的印刷编号 | `int`，$[1,n]$ |
| `cur` | 当前牌堆顶（队首）所在结点 | `int` |

### 算法步骤

1. 读入 $n$。
2. 建立环：`nxt[i] = (i+1==n) ? 0 : i+1`，`prv[i] = (i==0) ? n-1 : i-1`。
3. 令 `cur = 0`（初始队首是原始位置 0）。
4. 对 $v = 1,2,\dots,n$：
   1. `cur = nxt[cur]`——「最上方的牌移到底部」，队首变为原第二张。
   2. `ans[cur] = v`——这一张被取出来输出，编号为 $v$。
   3. 把结点 `cur` 从环上摘除：`nxt[prv[cur]] = nxt[cur]; prv[nxt[cur]] = prv[cur];`。
   4. `cur = nxt[cur]`——摘除之后的新牌堆顶。
5. 按 `ans[0], ans[1], …, ans[n-1]` 的顺序输出。

### 复杂度

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$，三个 `int` 数组，约 $12\,\text{MB}$（$n=10^6$）。

### 验证状态

- 标程 `P2021.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面样例 `n = 13` 输出 `7 1 12 2 8 3 11 4 9 5 13 6 10`，与官方一致。
- 编写暴力 `P2021_brute.cpp`（用数组模拟队列的「循环左移 + 出队」，$O(n^2)$，$n\le 2000$）与对拍脚本 `P2021_check.py`，在 $n\in[1,59]$ 各一次并附加 60 组随机 $n\le 600$ 的数据上对拍 **119 组全部通过**。
- 语义另用 Python `collections.deque` 独立实现一次双向验证：由 $1,\dots,n$ 正向模拟得到的输出序列恰为 $1,\dots,n$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2021 faebdc玩扑克
// 用循环双向链表模拟「牌堆」，位置 1..n 组成环
// 每步：把最上方的牌移到牌堆底（等价于队首后移），再把下一张牌取出并输出
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1000005};

int n;
int ans[mxn];
int nxt[mxn],prv[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		nxt[i]=(i+1==n)?0:i+1;
		prv[i]=(i==0)?n-1:i-1;
	}
	int cur=0;//cur 指向当前最上方的牌
	for(int v=1;v<=n;++v)
	{
		cur=nxt[cur];//最上方的牌移到底部，新的牌堆顶是原第二张
		ans[cur]=v;//这一张被取出来输出 v
		nxt[prv[cur]]=nxt[cur];//从环上摘掉 cur
		prv[nxt[cur]]=prv[cur];
		cur=nxt[cur];//摘掉之后的新牌堆顶
	}
	for(int i=0;i<n;++i)
	{
		if(i)
			cout<<' ';
		cout<<ans[i];
	}
	cout<<'\n';
	return 0;
}
```

### 代码说明

- 结点编号即原始位置（0-based），牌面印刷编号在取出时才写入 `ans[cur]`，两套编号不要混淆。
- `cur = nxt[cur]` 出现在循环体开头，这就是「最上方的牌放到牌堆底」；随后再次 `cur = nxt[cur]` 是因为要跳过被摘除的结点，指向新的牌堆顶。
- 摘除结点的两行必须顺序无关地都基于**旧**的 `nxt[cur]`/`prv[cur]`：第一行把 `prv[cur]` 的后继指向 `nxt[cur]`，第二行把 `nxt[cur]` 的前驱指向 `prv[cur]`，两者不冲突。
- `mxn` 取 $10^6+5$，三个数组共约 $12$ MB，在常见内存限制（128 MB / 256 MB）内安全。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
