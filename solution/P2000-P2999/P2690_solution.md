# P2690 [USACO04NOV] Apple Catching G — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 两棵苹果树，编号 $1,2$。共 $T\le1000$ 分钟，第 $i$ 分钟恰好有一个苹果从树 $a_i\in\{1,2\}$ 掉下。贝茜**开始时站在 1 号树下**，每分钟她必定站在某棵树下（移动耗时远小于 $1$ 分钟），站在哪棵树下就接住哪棵树的苹果。她**最多愿意移动 $W\le30$ 次**。求最多接住多少苹果。

**第一步：先做两个简化版，摸清"资源"是什么。**

- $W=0$：一步都不能动，答案就是 $a_i=1$ 的分钟数。
- $W\ge T$：每分钟之前都能自由换树，答案就是 $T$（全接住）。

两个极端之间，答案随 $W$ 单调不减。这说明本题的**稀缺资源是"移动次数"**，而进程是"分钟"。一个资源 + 一条时间轴 ⇒ 二维 DP 的强烈信号：状态里必须同时记"到第几分钟"和"用了几次移动"。

**第二步：试贪心，然后被反例打脸。** 最自然的贪心是"每分钟都跑到苹果掉的那棵树下"。反例：$T=4,W=1,a=[2,1,1,1]$。

- 贪心：第 $1$ 分钟移到 2 号树接住（用掉唯一的 $1$ 次移动），此后被困在 2 号树，第 $2,3,4$ 分钟全错过 ⇒ **1** 个。
- 最优：第 $1$ 分钟不动（放弃这个苹果），留在 1 号树接住第 $2,3,4$ 分钟 ⇒ **3** 个。

失败模式很清楚：**一次移动有"未来代价"**——它把你送到另一棵树，而想回来还要再花一次移动。局部收益 $1$ 个苹果，换来的是后面 $3$ 个苹果全丢。贪心看不见未来，所以必须 DP。

**第三步：状态设计的第一个跳跃——位置不用记！** 我一开始想写 $dp[i][j][k]$：第 $i$ 分钟、用了 $j$ 次移动、当前在树 $k$。但只有**两棵**树，而且**每次移动必然换树**（在两棵树之间移动，从 1 到 2 或从 2 到 1），起点固定是 1 号树。于是：

$$\text{用了 }j\text{ 次移动后所在的树}=\begin{cases}1,&j\text{ 为偶数}\\2,&j\text{ 为奇数}\end{cases}$$

**位置是 $j$ 的函数，不是独立自由度！** 第三维塌缩掉了，状态只剩 $(i,j)$，规模 $1000\times31\approx3.1\times10^4$，小得离谱。这是本题真正的"aha"。

**第四步：第二个跳跃——同一间隙移动两次等于没动。** 转移时我犹豫：两分钟之间她能不能移动 $2$ 次、$3$ 次？题目说移动很快，似乎可以。但**移动两次就回到原树**，净效果为零，还白白消耗 $2$ 次配额。把同一间隙里的移动成对删掉，位置序列**逐分钟完全不变**（每次删 $2$ 个，所有前缀和的奇偶性不变），接到的苹果一个不少，移动次数只减不增。所以**不妨设每个间隙至多移动一次**，转移就只有两条：这一分钟之前"不动"或"动一次"。

**第五步：写出转移。** 设 $dp[i][j]$ = 前 $i$ 分钟、**恰好**用了 $j$ 次移动时接到的最多苹果数。第 $i$ 分钟她站在 $\mathrm{pos}(j)=1+(j\bmod 2)$ 号树下，接到苹果当且仅当 $a_i=\mathrm{pos}(j)$。而这个位置在第 $i$ 分钟之前就确定了，所以：

$$dp[i][j]=\max\bigl(dp[i-1][j],\ dp[i-1][j-1]\bigr)+[\,a_i=\mathrm{pos}(j)\,].$$

两项分别对应"第 $i$ 分钟前不动"（移动数不变）与"动一次"（移动数从 $j-1$ 变 $j$）。**注意加的是 $\mathrm{pos}(j)$ 而不是 $\mathrm{pos}(j-1)$**：无论走哪条转移，第 $i$ 分钟时的累计移动数都是 $j$。

边界：$dp[0][0]=0$，$dp[0][j>0]=-\infty$（第 $1$ 分钟之前还没有任何间隙，不可能已用掉移动；"开局先换树"这件事被算作第 $1$ 个间隙的移动，由 $dp[1][1]$ 承接）。

**第六步：答案为什么不是 $dp[T][W]$？** 因为状态是"**恰好** $j$ 次"，不是"至多 $j$ 次"。多用的移动会强制改变位置奇偶，可能反而少接。反例：$T=3,W=2,a=[1,1,1]$。$dp[3][0]=3$（一直不动全接），而 $dp[3][2]=2$（被迫动两次，中间那分钟站在 2 号树错过）。更极端：$T=1,W=2$ 时 $dp[1][2]=-\infty$（一分钟只有一个间隙，用不掉 $2$ 次移动）。所以答案是

$$\max_{0\le j\le W}dp[T][j].$$

那能不能改成"至多 $j$ 次"的语义省掉这个 max？**不能**：至多 $j$ 次时，位置不再由 $j$ 决定（可能用了 $j$ 次也可能 $j-1$ 次），$\mathrm{pos}$ 就写不出来了，第三维又回来了。**"恰好 $j$ 次 + 最后取 max"才是与奇偶性质兼容的语义。**

**第七步：实现上唯一要命的坑——$-\infty$ 必须显式填。** 全局 `int dp[][]` 默认是 $0$，而 $0$ 在本题是**合法值**（"用了 $j$ 次移动、接到 $0$ 个苹果"）。不填 $-\infty$ 的话，$dp[0][5]=0$ 会被当成"开局就能瞬移 $5$ 次"，贝茜等于免费获得了任意多次移动，答案直接错成 $T$。所以 `fill_n(&dp[0][0],mxt*mxw,-inf)` 是必须的，然后再把 `dp[0][0]` 置 $0$。

配套的安全性检查：$-\infty$ 取 `-1145141919`，不可达状态每轮最多加 $1$，$T\le1000$ 轮后仍 $\le-1145140919<0$，而任何可达状态 $\ge0$，所以脏值永远抢不到答案；且 $-1145141919-1$ 之类也不会溢出 `int`（下界 $-2147483648$）。

**手造数据核对。** 题面没给样例输入输出，我自己造了 $9$ 组（含经典 USACO 场景的手算版）：

| 输入 | 手算 | 程序 |
|---|---|---|
| $T=7,W=2$，$a=[2,1,1,2,2,1,1]$ | $6$（放弃第 1 分钟，接 2,3；移到 2 接 4,5；移回 1 接 6,7） | 6 |

## 二、思维链：完整证明

**记号。** 分钟 $i=1,\dots,T$，$a_i\in\{1,2\}$。**间隙** $i$ 指第 $i$ 分钟**之前**的空档（间隙 $1$ 在第 $1$ 分钟之前，即"开局"；间隙 $i$ 在分钟 $i-1$ 与 $i$ 之间，$i\ge2$）。一个**策略**是 $m=(m_1,\dots,m_T)\in\mathbb Z_{\ge0}^T$，$m_i$ = 间隙 $i$ 里的移动次数，约束 $\sum_i m_i\le W$。

记前缀和 $S_i=\sum_{k\le i}m_k$（$S_0=0$），**第 $i$ 分钟所在的树** $\mathrm{tree}_i$，**收获** $\mathrm{gain}(m)=\#\{i:a_i=\mathrm{tree}_i\}$。目标 $\mathrm{OPT}=\max\{\mathrm{gain}(m):\sum m_i\le W\}$。

定义 $\mathrm{pos}(j)=1$ 若 $j$ 偶，$=2$ 若 $j$ 奇（即 $\mathrm{pos}(j)=1+(j\bmod2)$）。

---

### 引理 1（位置 = 累计移动次数的奇偶）

对任意策略 $m$ 与任意 $i$，$\mathrm{tree}_i=\mathrm{pos}(S_i)$。

*证明*：对 $i$ 归纳。$i=1$：开局在 1 号树，间隙 $1$ 里每移动一次就在两棵树之间换一次，故 $\mathrm{tree}_1=1$ 若 $m_1$ 偶、$=2$ 若 $m_1$ 奇，即 $\mathrm{pos}(m_1)=\mathrm{pos}(S_1)$ ✓。

设 $\mathrm{tree}_{i-1}=\mathrm{pos}(S_{i-1})$。间隙 $i$ 里移动 $m_i$ 次，每次换树，故 $\mathrm{tree}_i$ 由 $\mathrm{tree}_{i-1}$ 翻转 $m_i$ 次得到：$\mathrm{tree}_i=\mathrm{tree}_{i-1}$ 若 $m_i$ 偶，否则取另一棵。而 $\mathrm{pos}$ 恰有同样的性质：$\mathrm{pos}(S_{i-1}+m_i)=\mathrm{pos}(S_{i-1})$ 当 $m_i$ 偶，否则取另一值（因为 $\mathrm{pos}$ 只依赖奇偶，且两棵树只有两个取值）。故 $\mathrm{tree}_i=\mathrm{pos}(S_i)$ ✓。证毕。

**推论（状态压缩）**：策略在分钟 $i$ 的收获只依赖 $S_i$ 的奇偶，**不需要把"当前在哪棵树"作为独立状态维度**。这是 $dp$ 只有两维的根据。

---

### 引理 2（规范形：每个间隙至多移动一次）

对任意策略 $m$（$\sum m_i\le W$），存在策略 $m'$ 满足：$m'_i\in\{0,1\}$ 对所有 $i$；$\sum m'_i\le\sum m_i\le W$；且 $\mathrm{gain}(m')=\mathrm{gain}(m)$。

*证明*：构造性证明 + 终止性。若存在 $k$ 使 $m_k\ge2$，令 $m^{(1)}$ 为把 $m_k$ 减 $2$、其余不变所得。

**(a) 配额不增**：$\sum m^{(1)}=\sum m-2\le W$，且各项仍非负。

**(b) 所有前缀和的奇偶不变**：$S^{(1)}_i=S_i$ 对 $i<k$（未改动）；$S^{(1)}_i=S_i-2$ 对 $i\ge k$。减 $2$ 不改变奇偶，故 $S^{(1)}_i\equiv S_i\pmod 2$ 对**所有** $i$ 成立。

**(c) 收获不变**：由引理 1，$\mathrm{tree}_i=\mathrm{pos}(S_i)$ 只依赖奇偶，故每分钟的树逐一不变，$\mathrm{gain}$ 不变。

每做一次这样的删除，总移动数严格减 $2$，而非负整数不能无限递减，故有限步后所有 $m_i\le1$，得到 $m'$。由 (a)(c) 它满足全部要求。证毕。

**推论**：$\mathrm{OPT}=\max\{\mathrm{gain}(m):m\in\{0,1\}^T,\ \sum m_i\le W\}$。**把搜索空间从"每间隙任意多次"压成"每间隙 0/1"，转移才只有两条。** 注意这条引理**不是**说"最优策略不会连续移动两次"这种直觉口号，而是给出了保持收获不变的显式变换。

---

### 引理 3（DP 状态的语义与最优子结构）

定义 $dp[i][j]$（$0\le i\le T$，$0\le j\le W$）为

$$dp[i][j]=\max\Bigl\{\#\{k\le i:a_k=\mathrm{pos}(S_k)\}\ :\ m\in\{0,1\}^T,\ \sum_{k\le i}m_k=j\Bigr\},$$

即"前 $i$ 分钟、前 $i$ 个间隙里**恰好**用掉 $j$ 次移动"的最大收获（集合为空时定义为 $-\infty$）。则

$$dp[0][0]=0,\qquad dp[0][j]=-\infty\ (j\ge1),$$
$$dp[i][j]=\max\bigl(dp[i-1][j],\ dp[i-1][j-1]\bigr)+[\,a_i=\mathrm{pos}(j)\,]\quad(i\ge1),$$

其中 $j=0$ 时第二项视为 $-\infty$。

*证明*：

**边界**：$i=0$ 时没有分钟，收获为 $0$；前 $0$ 个间隙的移动数必为 $0$，故 $j=0$ 可行且值 $0$，$j\ge1$ 的可行集为空，值 $-\infty$ ✓。

**递推（$\ge$ 方向：构造）**：设 $j\ge1$。取达到 $dp[i-1][j]$ 的规范策略 $m^{(0)}$（前 $i-1$ 个间隙用 $j$ 次），令 $m_i=0$，则前 $i$ 个间隙共用 $j$ 次，且由引理 1，第 $i$ 分钟的树为 $\mathrm{pos}(j)$，收获 $=dp[i-1][j]+[a_i=\mathrm{pos}(j)]$。故 $dp[i][j]\ge dp[i-1][j]+[\cdot]$。同理取达到 $dp[i-1][j-1]$ 的策略、令 $m_i=1$，前 $i$ 个间隙共用 $j$ 次，第 $i$ 分钟的树仍是 $\mathrm{pos}(j)$（**关键：位置只看累计 $j$，与"最后一步动没动"无关**），得 $dp[i][j]\ge dp[i-1][j-1]+[\cdot]$。两式取 max 即 $\ge$。$j=0$ 时只有 $m_i=0$ 一条，同理。

**递推（$\le$ 方向：分解）**：任取一个计入 $dp[i][j]$ 的规范策略 $m$。因 $m_i\in\{0,1\}$，只有两种可能：
- $m_i=0$：则 $\sum_{k\le i-1}m_k=j$，其前 $i-1$ 分钟的收获 $\le dp[i-1][j]$（$dp$ 是最大值）；第 $i$ 分钟收获 $=[a_i=\mathrm{pos}(S_i)]=[a_i=\mathrm{pos}(j)]$。故总收获 $\le dp[i-1][j]+[\cdot]$。
- $m_i=1$：则 $\sum_{k\le i-1}m_k=j-1$（要求 $j\ge1$），前 $i-1$ 分钟收获 $\le dp[i-1][j-1]$，第 $i$ 分钟收获仍是 $[a_i=\mathrm{pos}(j)]$。故总收获 $\le dp[i-1][j-1]+[\cdot]$。

两种情形穷尽，故 $dp[i][j]\le\max(\dots)+[\cdot]$。

**这里用到了"无后效性"**：前 $i-1$ 分钟的收获只依赖前 $i-1$ 个间隙的选择，而第 $i$ 分钟的收获只依赖 $j$（引理 1），**两部分互不牵制**，所以可以分别取最优再拼接。若位置不是 $j$ 的函数（例如三棵树），拼接时就必须保证"前段结束位置"与"后段开始位置"一致，最优子结构会失效——这正是引理 1 的价值。

双向夹逼得等式。证毕。

---

### 引理 4（答案 $=\max_{j\le W}dp[T][j]$）

$\mathrm{OPT}=\max_{0\le j\le W}dp[T][j]$。

*证明*：由引理 2 的推论，$\mathrm{OPT}$ 等于规范策略（$m\in\{0,1\}^T$，$\sum m\le W$）上的最大收获。把规范策略按总移动数 $j=\sum_{k\le T}m_k\in[0,W]$ 分类，各类互不相交且并为全体，故

$$\mathrm{OPT}=\max_{0\le j\le W}\ \max\{\mathrm{gain}(m):m\text{ 规范},\textstyle\sum m=j\}=\max_{0\le j\le W}dp[T][j],$$

最后一步正是引理 3 中 $dp[T][j]$ 的定义（$i=T$ 时前 $T$ 个间隙就是全部间隙）。

**两边都要核对**：(i) 每个 $dp[T][j]$ 都由一个真实可行策略达到（引理 3 的构造方向），故 $\max_j dp[T][j]\le\mathrm{OPT}$ 不会高估；(ii) 每个可行策略都被某个 $j$ 类覆盖（引理 2 保证规范化不损失收获、不超配额），故不会低估。证毕。

---

### 引理 5（为什么不能只取 $dp[T][W]$，也不能改成"至多 $j$ 次"）

(a) $dp[T][j]$ 关于 $j$ **不单调**，故 $\max_{j\le W}$ 不可省。
(b) 若把状态语义改成"至多 $j$ 次移动"，则第 $i$ 分钟的位置无法由 $(i,j)$ 确定，引理 3 的转移不成立。

*证明*：

(a) 反例：$T=3,W=2,a=(1,1,1)$。逐格计算（$\mathrm{pos}(0)=1,\mathrm{pos}(1)=2,\mathrm{pos}(2)=1$）：

| $i\backslash j$ | 0 | 1 | 2 |
|---|---|---|---|
| 0 | $0$ | $-\infty$ | $-\infty$ |
| 1 | $1$ | $0$ | $-\infty$ |
| 2 | $2$ | $1$ | $1$ |
| 3 | $3$ | $2$ | $2$ |

$dp[3][0]=3>dp[3][2]=2$。原因：恰好 $2$ 次移动强制她在某分钟站在 2 号树，而苹果全在 1 号树。更极端地 $T=1,W=2$ 时 $dp[1][2]=-\infty$（一个间隙放不下 $2$ 次规范移动），若只取 $dp[T][W]$ 会输出一个哨兵值。故必须对 $j$ 取 max。

(b) 设 $\widetilde{dp}[i][j]$ = 前 $i$ 分钟、移动次数 $\le j$ 的最大收获。此时对应的策略其 $S_i$ 可以是 $j,j-1,j-2,\dots$ 中任意值，$\mathrm{pos}(S_i)$ 不唯一，"第 $i$ 分钟是否接到"就不是 $(i,j)$ 的函数。要恢复无后效性必须再记位置（或记 $S_i$ 的奇偶），状态回到三维。故"恰好 $j$ 次 + 末端取 max"是与引理 1 兼容的唯一简洁语义。证毕。

---

### 引理 6（哨兵安全性：不可达状态永不污染答案）

取 $\mathrm{INF}=1145141919$，不可达初值 $-\mathrm{INF}$。则算法全程所有 $dp$ 值落在 $[-\mathrm{INF},\,T]$ 内；任何不可达状态的值 $\le-\mathrm{INF}+T<0$；而 $dp[T][0]\ge0$ 恒可达。故 $\max_j dp[T][j]$ 必由可达状态取得，且无 `int` 溢出。

*证明*：

**值域**：对 $i$ 归纳。$i=0$：值为 $0$ 或 $-\mathrm{INF}$，都在 $[-\mathrm{INF},T]$ 内。设第 $i-1$ 行成立，则 $b=\max(dp[i-1][j],dp[i-1][j-1])\in[-\mathrm{INF},T]$，$dp[i][j]=b+[\cdot]\in[-\mathrm{INF},T+1]$；但可达状态的收获 $\le i\le T$，不可达状态的值 $\le-\mathrm{INF}+i$，故整行 $\subseteq[-\mathrm{INF},T]$ ✓。

**不可达状态的上界**：若 $(i,j)$ 的可行集为空，则 $j>i$（$i$ 个间隙每个至多 $1$ 次移动，故 $j\le i$ 是可达的必要条件；反之 $j\le i$ 时取前 $j$ 个间隙各移动一次即可达，故可达 $\iff j\le i$）。此时递推中两个前驱都不可达或不存在，值 $\le-\mathrm{INF}+i\le-\mathrm{INF}+T=-1145140919<0$。

**可达状态非负**：$dp[i][0]=dp[i-1][0]+[a_i=1]\ge dp[i-1][0]\ge\dots\ge dp[0][0]=0$（$j=0$ 对应"全程不动"，永远可行）。故 $dp[T][0]\ge0$，$\max_j$ 至少为 $0$，严格大于任何不可达值。

**溢出**：`int` 范围 $[-2147483648,2147483647]$，而 $-\mathrm{INF}=-1145141919$ 远在其内，加 $1$ 最多 $T\le1000$ 次，仍远离下界；上界方面可达值 $\le T\le1000$，同样远离上界。故全程无溢出。证毕。

**为什么必须显式 `fill`**：全局 `int` 数组零初始化，$0$ 会被当作"用了 $j$ 次移动、收获 $0$"的**合法可达状态**，于是 $dp[0][j]=0$ 让贝茜开局免费获得任意多次移动，答案会被抬到 $T$。这是本题最隐蔽的实现陷阱（也是风格规范里反复强调的"不可达数组必须显式填 INF"）。

---

### 引理 7（复杂度）

时间 $O(TW)$，空间 $O(TW)$（可滚动到 $O(W)$）。代入 $T\le1000,W\le30$：状态数 $\le1000\times31=31000$，每个状态 $O(1)$ 转移。

*证明*：双重循环 $i=1..T$、$j=0..W$，每格一次 max、一次相等判断、一次加法，$O(1)$。末尾对 $j$ 取 max 是 $O(W)$。总计 $O(TW+W)=O(TW)$。空间：`dp` 为 $1005\times35$ 个 `int` $\approx140$ KB；`a` 为 $1005$ 个 `int`。若只保留相邻两行（$dp[i]$ 只依赖 $dp[i-1]$），可降到 $O(W)$，但会失去回溯方案的能力；本题只问数量，$140$ KB 也毫无压力，故保留全表以便调试。证毕。

---

### 定理

程序输出 $\mathrm{OPT}$，即最多能接住的苹果数。

*证明*：引理 1 把位置化为移动数的奇偶；引理 2 把策略规范化为每间隙 $0/1$ 而不损失收获、不超配额；引理 3 在此规范空间上建立无后效性的递推并证明其正确；引理 4 把原问题的最优值等于 $\max_{j\le W}dp[T][j]$；引理 5 说明末端取 max 不可省；引理 6 说明哨兵实现不会污染答案；引理 7 给出复杂度。程序逐字实现引理 3 的递推与引理 4 的取 max，故输出 $\mathrm{OPT}$。证毕。

## 三、模式总结（按实际思考顺序）

- **consider easier version** — 先做 $W=0$（数 1 的个数）与 $W\ge T$（全接）两个极端，确认"移动次数"是稀缺资源、"分钟"是时间轴 ⇒ 二维 DP。
- **explore its property** — 贪心"每分钟追苹果"的反例（$T=4,W=1,a=[2,1,1,1]$：贪心 1、最优 3）暴露"移动有未来代价"，局部最优不可拼接。
- **explore its property** — 只有两棵树 + 起点固定 ⇒ 位置 $=\mathrm{pos}(j)=1+(j\bmod2)$，第三维（当前树）被奇偶性吃掉，状态压成 $(i,j)$。
- **reduce to easier problem** — 同一间隙移动两次抵消：成对删除保持所有前缀和奇偶 ⇒ 收获不变、配额不增，WLOG 每间隙至多一次移动，转移只剩两条。
- **classic problem solution** — 资源型二维 DP：$dp[i][j]=\max(dp[i-1][j],dp[i-1][j-1])+[a_i=\mathrm{pos}(j)]$，无后效性由"位置只依赖 $j$"保证。
- **discuss by category** — "恰好 $j$ 次" vs "至多 $j$ 次"：前者与奇偶性质兼容但末端必须 $\max_j$（$dp[T][j]$ 不单调，$T=3,W=2,a=111$ 时 $dp[3][2]=2<3$）；后者会让位置不可确定。
- **explore its property** — 全局数组默认 $0$ 是合法收获值 ⇒ 不可达状态必须显式填 $-\mathrm{INF}$；再证哨兵加 $T$ 次 $1$ 仍 $<0\le$ 可达值，不污染答案也不溢出。
- **classic problem solution** — 滚动数组可把空间降到 $O(W)$（只问数量时不需要回溯方案）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `t` | 分钟数 $T\le1000$ | `int`，读入 | 时间轴 |
| `w` | 移动配额 $W\le30$ | `int`，读入 | 资源轴 |
| `mxt,mxw` | $1000+5$、$30+5$ | `constexpr int{1005},{35}` | `dp` 两维尺寸（+5 松弛） |
| `inf` | $1145141919$ | `constexpr int` | 哨兵；不可达用 `-inf` |
| `a[i]` | 第 $i+1$ 分钟掉苹果的树号（$1$ 或 $2$），**0-based 存** | `int[mxt]`，读入 | 转移里用 `a[i-1]` |
| `dp[i][j]` | 前 $i$ 分钟、**恰好** $j$ 次移动的最大收获 | `int[mxt][mxw]`，**全表填 `-inf`** 后 `dp[0][0]=0` | 行=分钟，列=移动数；$j>i$ 不可达 |
| `pos(j)` | 用了 $j$ 次移动后所在的树 | 表达式 `j&1?2:1` | **偶 1 奇 2**（起点是 1 号树） |
| `b` | 本轮两条转移的前驱最大值 | `int`，每格现算 | `max(dp[i-1][j],dp[i-1][j-1])` |
| `ans` | $\max_{0\le j\le W}dp[T][j]$ | `int`，全局默认 $0$ | $dp[T][0]\ge0$ 保证 `ans` 不会是哨兵 |
| `upd(x,v)` | `x=max(x,v)` | 一行辅助函数 | 松弛最大值 |

### 算法步骤

1. I/O 加速三行。
2. 读 `t,w`；读 $T$ 个树号到 `a[0..t-1]`。
3. `fill_n(&dp[0][0],mxt*mxw,-inf)`，再 `dp[0][0]=0`（**顺序不能反**）。
4. 对 $i=1\dots T$、$j=0\dots W$：
   1. `b=dp[i-1][j]`（第 $i$ 分钟前不动）；
   2. 若 $j>0$，`upd(b,dp[i-1][j-1])`（第 $i$ 分钟前动一次）；
   3. `dp[i][j]=b+(a[i-1]==(j&1?2:1))`（第 $i$ 分钟站在 $\mathrm{pos}(j)$ 号树下）。
5. `ans=0`；对 $j=0\dots W$ 执行 `upd(ans,dp[t][j])`。
6. 输出 `ans`。

### 复杂度

- 时间：$O(TW)\le1000\times31=31000$ 次 $O(1)$ 转移。
- 空间：$O(TW)\approx140$ KB（可滚动到 $O(W)$）。
- 验证状态：`/d/mingw64/bin/g++.exe -std=c++20 -O2 -Wall -Wextra` 编译零警告；题面无样例输入输出，自造 $9$ 组小数据（$W=0$、$W\ge T$、贪心反例、$dp[T][W]$ 非最优的反例、单分钟多配额）全部与手算 DP 表一致；另跑 $T=1000,W=30$ 交替序列，输出 $515=500+15$ 与手算吻合，$0.05$ s。最优性由引理 2–4 严格证明，未写暴力对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2690 [USACO04NOV] Apple Catching G
// 只有两棵树 + 起点在 1 号树 ⇒ 位置 = 移动次数的奇偶（偶 1 奇 2），状态只需 (分钟, 移动数)
// 同一间隙移动两次抵消 ⇒ WLOG 每间隙至多动一次，转移只有"动/不动"两条
// dp[i][j] = 前 i 分钟恰好用 j 次移动的最大收获；答案 max_{j<=w} dp[t][j]
#include<bits/stdc++.h>
using namespace std;

constexpr int mxt{1005},mxw{35};
constexpr int inf{1145141919};

int t,w,a[mxt],dp[mxt][mxw],ans;

void upd(int&x,int v){x=max(x,v);}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>t>>w;
	for(int i=0;i<t;++i)
		cin>>a[i];
	fill_n(&dp[0][0],mxt*mxw,-inf);	// 全局默认 0 是合法收获值，必须显式填 -inf
	dp[0][0]=0;	// 第 1 分钟之前没有间隙，只能用 0 次移动
	for(int i=1;i<=t;++i)
		for(int j=0;j<=w;++j)
		{
			int b=dp[i-1][j];	// 第 i 分钟前不动
			if(j)
				upd(b,dp[i-1][j-1]);	// 第 i 分钟前动一次
			dp[i][j]=b+(a[i-1]==(j&1?2:1));	// 累计 j 次 ⇒ 偶在 1 号树、奇在 2 号树
		}
	for(int j=0;j<=w;++j)
		upd(ans,dp[t][j]);	// "恰好 j 次"不单调，必须对 j 取 max
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`fill_n(&dp[0][0],mxt*mxw,-inf)` 是本题生死线**：二维全局数组在内存里连续，取首元素地址一次性铺满全表。不填的话 `dp[0][j]=0` 意味着"开局免费移动 $j$ 次"，答案会被抬到 $T$。填完再把 `dp[0][0]` 置 $0$，顺序不能反。
- **`j&1?2:1`**：$\mathrm{pos}(j)$，偶数在 1 号树、奇数在 2 号树。**不是 `j-1` 的奇偶**——两条转移走到第 $i$ 分钟时累计移动数都是 $j$。
- **`b` 的初值是 `dp[i-1][j]`，`j==0` 时不访问 `dp[i-1][-1]`**：`if(j)` 守卫既避免负下标，也正确表达"没有移动可省"。
- **不可达状态无需特判**：$-\mathrm{INF}$ 每轮最多加 $1$，$T\le1000$ 后仍 $\le-1145140919<0\le dp[T][0]$，永远抢不到 `ans`，也不会溢出 `int`（引理 6）。
- **末端 `for(j=0..w) upd(ans,dp[t][j])` 不可写成 `ans=dp[t][w]`**：$T=3,W=2,a=[1,1,1]$ 时 `dp[3][2]=2` 而正确答案是 $3$；$T=1,W=2$ 时 `dp[1][2]` 还是哨兵。
- `a` 用 0-based 存、`dp` 行用 $1\dots T$（$dp[0]$ 是边界行），转移里写 `a[i-1]` 对齐；`mxt{1005}` 同时容纳 $a[0..999]$ 与 $dp[0..1000]$。
- 若卡空间，可把 `dp` 滚成两行 $O(W)$；本题 $140$ KB 无压力，保留全表方便打印 DP 表调试。
