# P2889 [USACO07NOV] Milking Time S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 时间轴上有 $M$ 个候选区间（$M\le 10^3$），第 $i$ 个是 $[Start_i,End_i]$，选它可以获得 $Eff_i$ 的价值（$1\le Eff_i\le 10^6$）。限制是：**选完一个区间后必须休息 $R$ 小时才能开始下一个**，即若选了 $i$ 之后紧接着选 $j$，必须满足 $Start_j\ge End_i+R$。要选出总价值最大的可行子集。$N\le 10^6$ 只是时间轴总长，所有区间都落在 $[0,N]$ 内。

**口径说明。** 题面背景里有一条警告：真实数据满足 $0\le Start_i<End_i\le N$（而不是 Hint 里写的 $\le N-1$）。这对解法毫无影响——我们只需要区间之间的相对关系，$N$ 本身不参与任何计算。另外两处自然解读：休息只发生在**两次挤奶之间**（最后一次之后不需要休息，因为之后不再挤奶）；"休息 $R$ 小时"理解为下一次开始时刻 $\ge$ 上一次结束时刻 $+R$（恰好取等合法）。样例缺失，我按这个口径手造数据核对。

**第一眼：这不是"背包"吗？** 标签写着背包 DP，但 $N\le 10^6$、每小时一维的 DP 会退化成 $O(NM)=10^9$，太险。先看 $M$：**$M\le 1000$ 小得可疑**。这强烈暗示复杂度应该只和 $M$ 有关——也就是说，应该把"区间"当物品，而不是把"小时"当阶段。

**试探 1：暴力枚举子集。** $2^{1000}$，不用想。

**试探 2：贪心。** 两个最自然的贪心都能被小手造数据打死：

- *按价值从大到小选*：$R=1$，区间 $(0,5,10),(0,2,6),(3,5,6)$。贪心先拿 $10$，剩下两个都与它重叠，答案 $10$；但选后两个：$End=2$，休息 $1$ 小时，$Start=3\ge 2+1$ ✓，得 $12$。贪心错。
- *按结束时间从早到晚选*：$(0,1,1),(2,10,100)$，$R=0$。贪心先拿 $(0,1)$，$1+0\le 2$ 其实还能拿第二个……换一个：$(0,9,1),(0,1,1),(2,9,100)$ 排序后先拿 $(0,1,1)$ 再拿 $(0,9,1)$？结束早优先会拿 $(0,1,1)$，然后 $(0,9,1)$ 开始 $0<1$ 不兼容跳过，再拿 $(2,9,100)$，得 $101$，这恰好是对的。真正打死它的是"结束早但价值极低、且挡住两个中等价值区间"的构造：$(0,4,1),(0,2,5),(3,5,5)$，$R=1$：结束最早的是 $(0,2,5)$，选它后 $(3,5,5)$ 兼容（$3\ge 2+1$），得 $10$，也对……好吧，无权重时"结束早优先"确实是对的（经典活动选择），**但带权重后**：$(0,2,1),(0,3,100)$，$R=0$：结束早优先拿 $(0,2,1)$，$(0,3,100)$ 开始 $0<2$ 被挡，答案 $1$；最优是 $100$。贪心错。

结论：**价值让"局部最优"不可靠，必须 DP**。

**试探 3：经典模型——加权区间调度。** 去掉休息 $R$（令 $R=0$），这就是教科书上的 weighted interval scheduling：按**结束时间**排序，$f_i=\max(f_{i-1},\,w_i+f_{p(i)})$，其中 $p(i)$ 是最后一个与 $i$ 兼容的区间。休息 $R$ 只是把兼容条件从 $End_j\le Start_i$ 改成 $End_j\le Start_i-R$，**模型完全不变**。这一步是"consider easier version"的标准用法：先剥掉增量（休息），认出经典骨架，再把增量加回去，发现它只改了一个不等式。

**关键观察：兼容集恰好是一个前缀。** 按结束时间排序后，能接在区间 $i$ 前面的区间，是那些 $End_j\le Start_i-R$ 的 $j$。因为数组按 $End$ 升序，这些 $j$ **恰好构成前缀 $[0..j^\*]$**——不多不少。于是"在前面的兼容区间里取最优"就是"取前缀最优值 $f_{j^\*}$"，一个数组值就查完了。而 $j^\*=$ 最后一个 $End\le Start_i-R$ 的位置，在有序的 $End$ 数组上二分即得。

**为什么 $f$ 要定义成"前缀最优"而不是"必选 $i$"？** 若定义 $g_i=$ 必选 $i$ 的最优值，转移要扫所有兼容 $j$ 取 $\max g_j$，是 $O(M^2)$（$M=1000$ 其实也能过）。但"前缀最优"$f_i=\max(f_{i-1},\,w_i+f_{j^\*})$ 把"扫最大值"这一步用 $f_{i-1}$ 与 $f_{j^\*}$ 的递推**免费**维护了——因为兼容集是前缀，前缀里的最优值恰好就是 $f_{j^\*}$。这是本题最漂亮的一步。

**边界核对。** $j^\*=-1$（没有兼容前驱）时转移是 $w_i+0$；$i=0$ 时 $f_{i-1}$ 不存在，按 $0$ 处理（什么都不选价值 $0$，合法）。答案上界 $M\cdot\max Eff=10^9$，`int` 装得下但贴着边，用 `long long` 零成本保险。$f$ 数组**不需要 INF 初始化**：每个前缀都至少可以什么都不选，$0$ 是合法值而非"不可达"。

**手造数据核对**（题面无样例，全部手造并手算）：

| 输入（$N\ M\ R$ + 区间） | 手算 | 程序输出 |
|---|---|---|
| `10 3 2` + $(0,2,5),(4,6,7),(3,5,100)$ | $(3,5)$ 与谁都不兼容（$5+2>6$ 且 $2+2>3$），单选 $100$ | `100` ✓ |
| `10 2 2` + $(0,2,5),(4,6,7)$ | $4=2+2$ 恰好取等，链起来 $12$ | `12` ✓ |
| `10 2 2` + $(0,2,5),(3,6,7)$ | $3<2+2$ 不能链，取 $\max(5,7)=7$ | `7` ✓ |
| `10 2 0` + $(0,3,5),(3,6,7)$ | $R=0$ 首尾相接合法，$12$ | `12` ✓ |
| `10 3 2` + $(0,3,10),(4,6,5),(2,5,20)$ | $3+2>4$ 不能链，单选 $20$ | `20` ✓ |
| `1 1 0` + $(0,1,10^6)$ | 只有一个区间 | `1000000` ✓ |

第 2、3 组专门打"休息恰好取等 / 差一小时"的边界，第 4 组打 $R=0$。

## 二、思维链：完整证明

**记号。** 区间下标排序后为 $0..M-1$，第 $i$ 个为 $(s_i,e_i,w_i)$，满足 $s_i<e_i$、$w_i\ge 1$，且 $e_0\le e_1\le\dots\le e_{M-1}$（按 $e$ 升序排序， ties 任意）。休息 $R\ge 0$。称 $j$ **可接在** $i$ **前**当且仅当 $e_j+R\le s_i$。一个**可行方案**是下标集合 $S$，其元素按时间先后排列后相邻两个都满足"前可接后"。价值 $W(S)=\sum_{i\in S}w_i$。$f_i$ 表示只允许使用下标 $\{0,\dots,i\}$ 时的最大可行价值（允许空集，价值 $0$）。

---

### 引理 1（相邻兼容 $\Rightarrow$ 两两不冲突，方案良定义）

设 $S=\{i_1,\dots,i_k\}$ 按开始时间升序排列（$s_{i_1}<\dots<s_{i_k}$，开始时间互不相同是因为兼容条件强制分离），且每对相邻元素满足 $e_{i_t}+R\le s_{i_{t+1}}$。则对任意 $t<u$ 有 $e_{i_t}+R\le s_{i_u}$，且各区间在时间轴上互不重叠。

*证明*：先证链式不等式。对 $u-t$ 归纳。$u=t+1$ 是假设。设 $e_{i_t}+R\le s_{i_{u-1}}$，则
$$e_{i_t}+R\le s_{i_{u-1}}<e_{i_{u-1}}\le e_{i_{u-1}}+R\le s_{i_u},$$
其中 $s<e$ 是题面保证、$R\ge 0$、最后一步是相邻兼容假设。故 $e_{i_t}+R\le s_{i_u}$。特别地 $R\ge0$ 给出 $e_{i_t}\le s_{i_u}$，区间不重叠。这说明"可行"只需检查时间序上的相邻对，方案与排列顺序无关（时间序唯一）。证毕。

**意义**：把"选一个子集"这件事从"排列 + 检查所有对"简化成"排序后检查相邻"，从而可以按结束时间做一维 DP。

---

### 引理 2（两个贪心的反例，说明必须 DP）

(a) "价值大者优先"不最优；(b) "结束早者优先"不最优。

*证明*：(a) $R=1$，区间 $(0,5,10),(0,2,6),(3,5,6)$。贪心先选 $10$；$(0,2)$ 与 $(0,5)$ 重叠（$0<5$）、$(3,5)$ 与 $(0,5)$ 重叠，都不可再选，贪心得 $10$。而 $\{(0,2,6),(3,5,6)\}$ 可行（$2+1=3\le 3$），价值 $12>10$。

(b) $R=0$，区间 $(0,2,1),(0,3,100)$。结束早优先选 $(0,2,1)$；$(0,3)$ 的开始 $0<2$ 不可接，贪心得 $1$。最优 $\{(0,3,100)\}$ 价值 $100>1$。证毕。

两个反例分别击中"只看价值"与"只看结构"，说明最优决策依赖**价值与位置的耦合**——这正是 DP 的信号。

---

### 引理 3（兼容集恰为前缀）

固定 $i$。令 $j^\*=\max\{j: e_j\le s_i-R\}$（集合为空时 $j^\*=-1$）。则：

(a) $\{j: j\text{ 可接在 }i\text{ 前}\}=\{0,1,\dots,j^\*\}$；
(b) $j^\*<i$，即兼容前驱全部落在排序后的前缀 $[0,i)$ 内；
(c) $j^\*$ 可用 `upper_bound(e,e+i,s_i-R)-e-1` 求出。

*证明*：(a) "可接在 $i$ 前"按定义就是 $e_j\le s_i-R$。由 $e$ 升序：若 $j\le j^\*$ 则 $e_j\le e_{j^\*}\le s_i-R$，可接；若 $j>j^\*$，由 $j^\*$ 的最大性 $e_j>s_i-R$，不可接。故兼容集恰为前缀。

(b) 对任意 $k\ge i$：$e_k\ge e_i>s_i\ge s_i-R$（用 $s_i<e_i$ 与 $R\ge0$），故 $k$ 不满足 $e_k\le s_i-R$，从而 $j^\*<i$。**这一步保证二分只需在 $[0,i)$ 里做，且 DP 无后效性**（$f_i$ 只依赖更小的下标）。

(c) `upper_bound` 在有序数组 `e[0..i)` 中返回第一个 $>s_i-R$ 的位置 $p$；则 $p-1$ 是最后一个 $\le s_i-R$ 的位置（若 $p=0$ 则不存在，$j^\*=-1$）。由 (b)，$[0,i)$ 之外没有满足条件者，故前缀内找到的就是全局 $j^\*$。证毕。

---

### 引理 4（DP 转移的正确性）

定义 $f_{-1}=0$（空前缀只能空选）。则对 $i\ge 0$：
$$f_i=\max\bigl(f_{i-1},\; w_i+f_{j^\*(i)}\bigr),$$
其中 $j^\*(i)$ 由引理 3 给出（$j^\*=-1$ 时 $f_{j^\*}=0$）。

*证明*：对 $i$ 归纳，证明 $f_i$ 等于"只用下标 $\{0..i\}$ 的最大可行价值"。

$i=0$：可行方案只有 $\varnothing$ 与 $\{0\}$（$j^\*(0)=-1$ 由引理 3(b)），价值 $0$ 与 $w_0$；公式给 $\max(0,w_0+0)=w_0$（$w_0\ge1>0$）✓。

设 $f_{i-1}$ 正确。把 $\{0..i\}$ 上的可行方案分成两类：

**不含 $i$**：就是 $\{0..i-1\}$ 上的可行方案，最优值 $f_{i-1}$（归纳假设）。

**含 $i$**：设方案为 $S\cup\{i\}$。$i$ 的开始时间 $s_i$ 大于所有兼容前驱的结束时间，而任何与 $i$ 不兼容的 $j<i$ 都不能共存于可行方案（引理 1 的两两不重叠：若 $e_j>s_i-R\ge s_i$……更直接地，$j$ 与 $i$ 要么重叠要么休息不足，违反引理 1 的 $e_j+R\le s_i$ 或 $e_i+R\le s_j$；后者不可能因为 $e_i>s_i\ge s_j$ 且 $R\ge0$ 时 $e_i+R>s_j$ 恒成立当 $s_j\le s_i$——总之 $j$ 必须可接在 $i$ 前）。由引理 3(a)，$S\subseteq\{0..j^\*\}$。反之，**任何** $\{0..j^\*\}$ 上的可行方案 $S$ 加上 $i$ 都可行：$S$ 中每个 $j$ 满足 $e_j+R\le s_i$，把 $i$ 排在时间序末尾，相邻条件只需检查 $S$ 的最后一个元素与 $i$，成立；其余相邻对由 $S$ 自身可行性保证（引理 1）。故含 $i$ 的最优值 $=w_i+\bigl(\{0..j^\*\}\text{ 上的最优值}\bigr)=w_i+f_{j^\*}$（$j^\*\le i-1$，归纳假设适用；$j^\*=-1$ 时为 $w_i+0$）。

两类取 $\max$ 即公式。证毕。

**注**：这里"前缀最优"的定义是点睛之笔——若定义"必选 $i$"的 $g_i$，含 $i$ 类要算 $\max_{j\le j^\*}g_j$，需要额外扫描；而 $f_{j^\*}$ 按定义已经把这个 $\max$ 维护好了（$f_{j^\*}=\max(\varnothing,\max_{j\le j^\*}g_j)$，空集价值 $0$ 恰好对应"没有前驱"）。

---

### 引理 5（答案与数值范围）

答案为 $f_{M-1}$，且 $0\le f_{M-1}\le M\cdot\max w\le 10^3\times10^6=10^9$。

*证明*：任何可行方案都是 $\{0..M-1\}$ 的子集，反之亦然，故最优值就是 $f_{M-1}$（引理 4 取 $i=M-1$）。上界：可行方案至多 $M$ 个区间，每个价值 $\le10^6$。$10^9<2^{31}-1\approx2.147\times10^9$，`int` 可容纳；但中间量 $w_i+f_{j^\*}$ 同样 $\le10^9$，用 `long long` 存 $f$ 是零成本保险。$M\ge1$ 保证 $f_{M-1}$ 存在。证毕。

---

### 引理 6（复杂度）

时间 $O(M\log M)$，空间 $O(M)$。

*证明*：排序 $O(M\log M)$；复制 $e$ 数组 $O(M)$；每轮 DP 一次 `upper_bound`（$O(\log M)$）加 $O(1)$ 合并，共 $O(M\log M)$。数组 $a,e,f$ 各 $O(M)$。$N$ 只被读入不参与计算，复杂度与 $N$ 无关——这正是"$M\le1000$ 小得可疑"的回报：$M=1000$ 时约 $10^4$ 次基本操作。证毕。

---

### 定理

程序输出最大可行产奶量，时间 $O(M\log M)$、空间 $O(M)$。

*证明*：引理 1 把可行性化为时间序相邻检查；引理 3 证明兼容集恰为前缀且落在 $[0,i)$（无后效性）；引理 4 归纳证明 $f_i$ 是前缀最优值；引理 5 说明 $f_{M-1}$ 即答案且不溢出；引理 6 给出复杂度。引理 2 的反例说明贪心不可行、DP 是必要的。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "休息 $R$ 小时"翻译成不等式 $Start_j\ge End_i+R$；$N$ 只是背景板，$M\le10^3$ 才是真正的复杂度信号。
2. **consider easier version** — 暴力 $2^M$ 不可行；两个贪心（价值优先 / 结束早优先）各造一个反例打死，确认需要 DP。
3. **consider easier version** — 令 $R=0$，剥出经典骨架：加权区间调度（weighted interval scheduling）。
4. **classic problem solution** — 按结束时间排序 + 前缀最优 DP：$f_i=\max(f_{i-1},w_i+f_{j^\*})$。
5. **reduce to easier problem** — 关键结构：排序后"与 $i$ 兼容的区间"恰为前缀 $[0..j^\*]$，于是"兼容集里取最优"塌缩成一次数组取值 $f_{j^\*}$。
6. **classic problem solution** — $j^\*$ 用 `upper_bound` 在有序结束时间数组上二分，$O(\log M)$。
7. **discuss by category** — 边界分类：$j^\*=-1$（无前驱，$+0$）、$i=0$（$f_{-1}=0$）、$R=0$（取等合法）、答案上界 $10^9$ 用 `long long` 保险。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n,m,r` | 时间轴长 / 区间数 / 休息时长 | `int` | 读入；`n` 之后不再使用 |
| `a[i]` | 第 $i$ 个区间 `{s,e,w}`，按 `e` 升序排序 | `struct node{int s,e,w;}[mxn]` | 读入后 `sort` |
| `e[i]` | `a[i].e` 的副本，供二分 | `int[mxn]` | 排序后复制，天然有序 |
| `f[i]` | 只用前 $i+1$ 个区间的最大价值（允许空选） | `i64[mxn]` | 递推；**无需 INF**：空选价值 $0$ 合法 |
| `j` | $j^\*(i)$：最后一个 $e_j\le s_i-r$ 的下标，可为 $-1$ | `int` | `upper_bound(e,e+i,a[i].s-r)-e-1` |
| `take` | 选第 $i$ 个区间的最优值 $w_i+f_j$ | `i64` | `j<0` 时 $f_j$ 按 $0$ |
| `mxn` | $1000+5$ | `constexpr int` | 只与 $M$ 有关 |

### 算法步骤

1. I/O 加速三行；读入 $N,M,R$ 与 $M$ 个区间。
2. 按结束时间 `e` 升序排序；复制出有序数组 `e[]`。
3. 对 $i=0..M-1$：二分求 `j=upper_bound(e,e+i,a[i].s-r)-e-1`；`take=a[i].w+(j>=0?f[j]:0)`；`f[i]=max(i?f[i-1]:0, take)`。
4. 输出 `f[m-1]`。

### 复杂度

- 时间 $O(M\log M)$（排序 + 每区间一次二分），$M\le10^3$；与 $N$ 无关。
- 空间 $O(M)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；6 组手造数据（休息恰好取等 / 差一小时不能链 / $R=0$ 首尾相接 / 大价值孤立区间 / 单区间极值）全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2889 Milking Time S
// 带休息间隔的加权区间调度：按结束时间排序，f[i]=只考虑前 i+1 段时的最优产奶量
// f[i]=max(f[i-1], w[i]+f[j])，j 是最后一段满足 e[j]+R<=s[i] 的区间（二分）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};

struct node{int s,e,w;}a[mxn];
int n,m,r,e[mxn];
i64 f[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>r;
	for(int i=0;i<m;++i)
		cin>>a[i].s>>a[i].e>>a[i].w;
	sort(a,a+m,[](node x,node y){return x.e<y.e;});
	for(int i=0;i<m;++i)
		e[i]=a[i].e;
	for(int i=0;i<m;++i)
	{
		// e[j]<=s[i]-r<e[i]，故兼容区间恰为前缀 [0,j]，二分只查 [0,i)
		int j=upper_bound(e,e+i,a[i].s-r)-e-1;
		i64 take=a[i].w+(j>=0?f[j]:0);
		f[i]=max(i?f[i-1]:0LL,take);	// 不选第 i 段 / 选第 i 段
	}
	cout<<f[m-1]<<'\n';
	return 0;
}
```

### 代码说明

- **排序键是结束时间**，不是开始时间：只有按 $e$ 升序，"兼容集 = 前缀"（引理 3）才成立，二分与前缀 DP 都建立在这上面。
- `upper_bound(e,e+i,...)` 的第二参是 `e+i` 而不是 `e+m`：引理 3(b) 保证 $j^\*<i$，只查前缀既正确又强调无后效性；`a[i].s-r` 可为负，`upper_bound` 返回首位置、`j=-1`，分支 `j>=0?f[j]:0` 接住。
- `f` 是**前缀最优**（可以不选任何区间），所以全局默认 $0$ 恰好是合法初值，**不需要** fill INF——本题没有"不可达状态"，这与最短路类问题相反，别惯性填 INF。
- `i?f[i-1]:0LL` 处理 $i=0$ 时 $f_{-1}$ 不存在；`0LL` 保证 `max` 两参同为 `i64`。
- 答案上界 $10^9$ 在 `int` 范围内，但 `f` 用 `i64` 是零成本保险（引理 5）。
- `n` 读入后再未出现：它只是时间轴背景，真实数据 $End\le N$ 的口径差异不影响任何计算。
