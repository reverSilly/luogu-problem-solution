# P2677 [USACO07DEC] Bookshelf 2 B — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 头奶牛（$1\le N\le 20$），第 $i$ 头身高 $H_i$（$1\le H_i\le 10^6$）。记 $S=\sum H_i$，书架高 $B$，保证 $1\le B\le S$。选若干头奶牛叠成塔（塔高 = 被选奶牛身高之和），要求塔高 $\ge B$，在此前提下塔高尽可能小。输出**最小的"塔高 $-$ 书架高"**（一个非负整数）。

题面只给了输出说明（"选奶牛 $1,3,4,5$，总高 $3+3+5+6=17$，任何方案都叠不出 $16$，于是答案为 $1$"），没有给输入样例，下面的数据都是我自己造并手算核对的。

**第一步：先把"叠塔"这件事翻译成数学。** 奶牛叠在一起，塔高就是身高求和；加法满足交换律与结合律，所以**叠放顺序完全不影响塔高**。于是"一种叠塔方案"就等价于"选一个奶牛子集"，没有任何排列、顺序、相邻关系的信息。问题瞬间干净了：

$$\text{ans}=\min\Bigl\{\textstyle\sum_{i\in T}H_i-B\ :\ T\subseteq\{1..N\},\ \sum_{i\in T}H_i\ge B\Bigr\}.$$

这就是经典的**子集和（subset sum）**问题的一个变体：不是问"能否恰好凑出 $B$"，而是问"$\ge B$ 的最小可达和是多少"。

顺手确认两件事：$B\le S$ 保证**全取**一定合法，所以最小值一定存在（有限非空整数集必有最小元）；答案显然 $\ge 0$。这两点后面写代码时会用到（哨兵一定会被更新）。

**第二步：贪心行不行？** 最自然的想法：把奶牛按身高从大到小排序，一头一头往塔上放，放到总高 $\ge B$ 就停。这样"用最少的奶牛、每头都尽量高"，直觉上超出量应该最小。

立刻找到反例：$H=[6,5,5]$，$B=10$。贪心取 $6$（$6<10$），再取 $5$ 得 $11\ge 10$，停，答案 $1$。但取两头 $5$ 恰好 $10$，答案 $0$。再来一个：$H=[5,4,3]$，$B=7$，贪心 $5+4=9$ 给出 $2$，而 $4+3=7$ 给出 $0$。

**为什么会错？** 贪心的选择准则是"当前这一步增量最大"，而目标是"最终超出量最小"。这两个准则根本不同：超出量 $\sigma(T)-B$ 由**整个子集的和**决定，不由任何单个元素决定。贪心一旦把 $6$ 放进塔里，就再也不会考虑"放弃 $6$、改用两个 $5$"这种**回头路**。

我试着用交换论证救它：如果贪心解 $G$ 不是最优，能不能通过"删掉一个元素"或"把一个已选元素换成一个未选元素"改进一步？如果能，那至少说明贪心解是某种局部最优，也许再加几条规则就对了。结果发现**连局部最优都救不了**：

> $H=[7,6,5,3,2,1]$，$B=17$。贪心取 $7,6$（$13<17$），再取 $5$ 得 $18\ge 17$，停，$G=\{7,6,5\}$，超出量 $1$。
> - 删任何一个：$18-7=11$、$18-6=12$、$18-5=13$，全都 $<17$，不合法；
> - 换任何一个：未选的是 $\{3,2,1\}$，最大才 $3$。换掉 $5$ 得 $7+6+3=16<17$；换掉 $6$ 得 $7+5+3=15<17$；换掉 $7$ 得 $6+5+3=14<17$。全都不合法。
>
> 所以 $G$ 在"删除 / 单元素替换"意义下**已经是局部最优**。但全局最优是 $\{7,6,3,1\}$，和恰好 $17$，超出量 $0$——它需要**同时换掉两个元素**，任何单步交换都到不了。

这个反例彻底断了我"给贪心打补丁"的念头：必须做**全局搜索**（枚举 / DP），而不是局部调整。

**第三步：看数据范围决定搜索方式。** $N\le 20$。这个数字非常刺眼——$2^{20}=1\,048\,576\approx 10^6$，一百万次运算对 C++ 来说是**毫秒级**。所以"枚举全部子集"本身就是正解，不需要任何高级技巧。这就是 OI 里最常用的一条经验：**$N\le 20$ 想指数枚举，$N\le 40$ 想折半搜索，值域小才想背包。**

另一条经典路线是子集和 DP：$f[v]$ 表示"能否凑出高度 $v$"，$f[0]=\text{true}$，每头牛做一次 $f[v]\mathrel{|}=f[v-H_i]$。但值域是 $S\le 20\times 10^6=2\times 10^7$，朴素复杂度 $O(NS)=4\times 10^8$，太慢；用 `bitset` 压位变成 $O(NS/64)\approx 6.3\times 10^6$ 次字操作、$2.5$ MB 内存，才勉强可行。两条路线一对比：

| 路线 | 时间 | 空间 | 适用 |
|---|---|---|---|
| 枚举 $2^N$ 个子集 | $O(2^N)\approx 10^6$ | $O(2^N)\approx 4$ MB | $N$ 小、值域大（**本题**） |
| `bitset` 子集和 DP | $O(NS/64)\approx 6.3\times 10^6$ | $O(S/8)\approx 2.5$ MB | $N$ 大、$S$ 小 |

本题 $N$ 小而 $S$ 大，枚举胜出。我在第二部分把两条路线的正确性都证了，代码用枚举。

**第四步：枚举也要写得聪明。** 最朴素的枚举是对每个 mask 扫 $N$ 位求和，$O(N\cdot 2^N)=2\times 10^7$，其实也能过。但子集和有一个漂亮的递推：设 $\text{low}=s\ \&\ (-s)$ 是 $s$ 的最低位 $1$（对应奶牛 $j=\texttt{ctz}(s)$），$s'=s\oplus\text{low}$ 是"去掉这头奶牛"的子集，则

$$\texttt{sum}[s]=\texttt{sum}[s'] + H_j,\qquad s'<s.$$

因为 $s'<s$，按 $s$ 从小到大循环时 $\texttt{sum}[s']$ **一定已经算好了**。于是每个子集只花 $O(1)$，总共 $O(2^N)$。这正是"子集 DP"的最简形态（SOS DP 的思想雏形）。

**第五步：一个意外好用的性质——答案的上界。** 设最优子集 $T^\*$ 的和为 $\Sigma^\*$。若 $\Sigma^\*>B$，那么对 $T^\*$ 中**任意**一头奶牛 $i$，$\Sigma^\*-H_i$ 也是一个可达和，而且比 $\Sigma^\*$ 小；由 $\Sigma^\*$ 的最小性，它必须 $<B$（否则就找到更优解了）。于是

$$H_i>\Sigma^\*-B=\text{ans}\quad(\forall i\in T^\*)\ \Longrightarrow\ \text{ans}<\min_{i\in T^\*}H_i\le \max_i H_i-1\le 999999.$$

**答案一定小于塔中最矮那头奶牛的身高**，因此不超过 $10^6-1$。这条性质有三个用处：(1) 确认 `int` 绝对够用；(2) 若写 DFS，可以用它剪枝；(3) 若写背包 DP，只需在 $[B,\ B+\max H)$ 这段值域里找答案，不必扫到 $S$。

**第六步：手造数据核对。** 题面没有输入样例，我按输出说明反推了一组，又造了几组专打边界的：

| 输入 | 手算 | 程序 |
|---|---|---|
| `5 16` / `3 1 3 5 6`（按说明反推） | $3+3+5+6=17$，凑不出 $16$ ⇒ $1$ | $1$ ✓ |
| `3 10` / `6 5 5`（贪心反例） | $5+5=10$ ⇒ $0$ | $0$ ✓ |
| `6 17` / `7 6 5 3 2 1`（局部最优反例） | $7+6+3+1=17$ ⇒ $0$ | $0$ ✓ |
| `1 7` / `7`（只有一头） | $7-7=0$ | $0$ ✓ |
| `2 5` / `1 1000000` | 只能取 $10^6$ ⇒ $999995$ | $999995$ ✓ |
| `20 1000000` / `1 2 4 ... 524288`（二进制权值） | 每个和唯一可达，$B$ 本身可达 ⇒ $0$ | $0$ ✓ |
| `20 1` / $20$ 个 `1000000` | 最矮也是 $10^6$ ⇒ $999999$（触到上界） | $999999$ ✓ |
| `20 20000000` / $20$ 个 `1000000` | $B=S$，全取 ⇒ $0$ | $0$ ✓ |

最后一组同时是极限规模测试（$N=20$，$S=2\times 10^7$），实测 $0.06$ 秒内结束（含进程启动）。

## 二、思维链：完整证明

### 记号

- 奶牛下标 $0\le i<N$（内部 0-based），身高 $H_i\in[1,10^6]$，$S=\sum_{i=0}^{N-1}H_i$，$B\in[1,S]$。
- 对掩码 $s\in[0,2^N)$，记 $T(s)=\{i:\lfloor s/2^i\rfloor\bmod 2=1\}$，$\sigma(s)=\sum_{i\in T(s)}H_i$（约定 $\sigma(0)=0$）。
- 可行掩码集 $\mathcal F=\{s\in[1,2^N):\sigma(s)\ge B\}$。
- 目标 $\mathrm{Ans}=\min_{s\in\mathcal F}\bigl(\sigma(s)-B\bigr)$。
- $\mathrm{low}(s)=s\ \&\ (-s)$，$\mathrm{ctz}(s)$ 为 $s$ 的二进制末尾 $0$ 的个数。

---

### 引理 1（方案与子集一一对应，问题等价刻画）

一座合法的塔 $\iff$ 一个非空奶牛子集 $T$ 且 $\sum_{i\in T}H_i\ge B$；塔高只由 $T$ 决定，与叠放顺序无关。因此题目所求 $=\mathrm{Ans}$。

*证明*：塔由"哪些奶牛参与"以及"它们的叠放顺序"共同描述。塔高定义为塔中所有奶牛身高之和，而整数加法满足交换律与结合律，故任意排列 $\pi$ 都有 $\sum_{k}H_{\pi(k)}=\sum_{i\in T}H_i$：**顺序对塔高无影响**，方案的效果完全由 $T$ 决定。

（$\Rightarrow$）任给一座合法塔，取其参与者集合 $T$。塔非空故 $T\ne\varnothing$；题面要求"身高和不小于书架高度"即 $\sum_{i\in T}H_i\ge B$；塔高 $-B=\sigma(s)-B$，其中 $s$ 是 $T$ 的掩码。故该方案的目标值属于 $\{\sigma(s)-B:s\in\mathcal F\}$。

（$\Leftarrow$）任给 $s\in\mathcal F$，把 $T(s)$ 中的奶牛按任意顺序叠起来，就得到一座塔高 $\sigma(s)\ge B$ 的合法塔，其目标值为 $\sigma(s)-B$。

两个方向说明"合法方案的目标值集合"与 $\{\sigma(s)-B:s\in\mathcal F\}$ **完全相同**，故两者的最小值相等，即题目所求 $=\mathrm{Ans}$。证毕。

---

### 引理 2（可行性、非负性与哨兵必然被更新）

$\mathcal F\ne\varnothing$，$\mathrm{Ans}$ 存在且 $0\le\mathrm{Ans}\le S-B\le 2\times 10^7-1$。特别地，程序把 `ans` 初始化为 $1145141919$ 后，循环结束时 `ans` 一定已被某个真实值替换。

*证明*：取 $s_{\text{all}}=2^N-1$，则 $T(s_{\text{all}})$ 是全体奶牛，$\sigma(s_{\text{all}})=S\ge B$（题面保证），且 $s_{\text{all}}\ge 1$（$N\ge 1$），故 $s_{\text{all}}\in\mathcal F$，$\mathcal F$ 非空。$\mathcal F$ 是有限集，$\{\sigma(s)-B:s\in\mathcal F\}$ 是有限非空整数集，必有最小元，$\mathrm{Ans}$ 存在。

对任意 $s\in\mathcal F$：$\sigma(s)\ge B\Rightarrow\sigma(s)-B\ge 0$；又 $\sigma(s)\le S\Rightarrow\sigma(s)-B\le S-B$。取最小值后不等式保持，故 $0\le\mathrm{Ans}\le S-B$。

$S\le 20\times 10^6=2\times 10^7$，故 $\mathrm{Ans}\le 2\times 10^7-1<1145141919$。程序枚举了**所有** $s\in[1,2^N)$，其中包含 $s_{\text{all}}$，且在该处执行 `ans=min(ans,sum[s]-b)`，故 `ans` 至少被更新一次，最终值 $\le S-B<$ 哨兵。证毕。

**注**：$s=0$（空集）被循环跳过是安全的：$\sigma(0)=0<B$（因 $B\ge 1$），空集本来就不可行，跳过不改变最小值。

---

### 引理 3（降序贪心不正确：反例与失败机理）

设贪心 $G$：把 $H$ 降序排列，依次累加直到前缀和 $\ge B$ 停止，取该前缀对应的子集。则存在输入使 $\sigma(G)-B>\mathrm{Ans}$。进一步，存在输入使 $G$ 在"删除一个元素"与"替换一个元素"两种单步操作下都无法改进，但 $G$ 仍非全局最优。

*证明*：

**(a) 简单反例。** $H=[6,5,5]$，$B=10$。降序前缀：$6<10$，$6+5=11\ge 10$，故 $G=\{6,5\}$，$\sigma(G)-B=1$。而 $T=\{5,5\}$ 给出 $\sigma=10\ge B$，目标值 $0$。故 $\mathrm{Ans}=0<1$，贪心错。

**(b) 局部最优仍非全局最优的反例。** $H=[7,6,5,3,2,1]$，$B=17$（$S=24\ge B$，合法）。降序前缀：$7<17$，$7+6=13<17$，$7+6+5=18\ge 17$，故 $G=\{7,6,5\}$，$\sigma(G)=18$，超出量 $1$。

- *删除不可行*：$\sigma(G)-7=11<17$，$\sigma(G)-6=12<17$，$\sigma(G)-5=13<17$。三种删除都破坏 $\ge B$。
- *替换不可行*：未选元素集为 $\{3,2,1\}$，最大 $3$。替换 $5\to h$ 得 $13+h\le 16<17$；替换 $6\to h$ 得 $12+h\le 15<17$；替换 $7\to h$ 得 $11+h\le 14<17$。九种替换全部不合法。

故 $G$ 在这两种单步操作下是局部最优。但 $T=\{7,6,3,1\}$ 满足 $\sigma(T)=17\ge B$，目标值 $0<1$，所以 $\mathrm{Ans}=0$，$G$ 非全局最优。

**(c) 失败机理（为什么交换论证救不回来）。** 交换论证要成立，需要"任何非最优解都能通过一步局部操作变好"。本例中从 $G$ 到 $T$ 需要**同时**去掉 $5$、加入 $3$ 和 $1$（两步以上的组合变动），单步邻域里根本没有更优解。更本质地说：贪心的评价函数是"当前增量最大"，目标函数是"最终和与 $B$ 的差最小"，二者之间**不存在拟阵（matroid）结构**——子集和的可行性约束 $\sigma\ge B$ 是**向上封闭**的（加元素只会更容易可行），而不是拟阵要求的"独立集向下封闭"，贪心最优性的结构前提根本不成立。故只能全局枚举 / DP。证毕。

### 引理 4（lowbit 子集和递推的正确性）

定义数组 $\texttt{sum}[0]=0$，对 $s\ge 1$ 令 $\text{low}=s\ \&\ (-s)$、$j=\mathrm{ctz}(\text{low})$、$s'=s\oplus\text{low}$，并置 $\texttt{sum}[s]=\texttt{sum}[s']+H_j$。若按 $s=1,2,\dots,2^N-1$ 的升序计算，则对所有 $s$ 有 $\texttt{sum}[s]=\sigma(s)$。

*证明*：先证三条位运算事实。设 $s\ge 1$，其二进制最低位的 $1$ 在第 $j$ 位。

1. **$s\ \&\ (-s)=2^j$。** 补码定义 $-s=\sim s+1$。设 $s$ 的低 $j$ 位全为 $0$、第 $j$ 位为 $1$，则 $\sim s$ 的低 $j$ 位全为 $1$、第 $j$ 位为 $0$；加 $1$ 后低 $j$ 位进位归 $0$、第 $j$ 位变 $1$，更高位与 $\sim s$ 相同（即与 $s$ 相反）。故 $s$ 与 $-s$ 只在第 $j$ 位同时为 $1$，按位与得 $2^j$。
2. **$\mathrm{ctz}(2^j)=j$**，故 $H_j$ 正是最低位对应奶牛的身高（内部 0-based，第 $j$ 位 $\leftrightarrow$ 奶牛 $j$）。
3. **$s'=s\oplus 2^j=s-2^j<s$，且 $T(s')=T(s)\setminus\{j\}$。** 异或把第 $j$ 位从 $1$ 翻成 $0$，其余位不变；因该位原为 $1$，数值减少 $2^j$。

于是 $\sigma(s)=\sum_{i\in T(s)}H_i=H_j+\sum_{i\in T(s)\setminus\{j\}}H_i=H_j+\sigma(s')$（有限和的可加性，$j\in T(s)$ 保证拆分不重不漏）。

再对 $s$ 升序归纳：$s=0$ 时 $\texttt{sum}[0]=0=\sigma(0)$（全局数组零初始化，且空集和为 $0$）✓。设所有 $s'<s$ 已满足 $\texttt{sum}[s']=\sigma(s')$。由事实 3，$s'<s$，故计算 $\texttt{sum}[s]$ 时 $\texttt{sum}[s']$ 已就绪且等于 $\sigma(s')$；代入递推得 $\texttt{sum}[s]=\sigma(s')+H_j=\sigma(s)$ ✓。证毕。

**推论**：每个掩码只花 $O(1)$（一次与、一次异或、一次 `ctz`、一次加法），总时间 $O(2^N)$，优于逐位求和的 $O(N\cdot 2^N)$。

### 引理 5（枚举取 min 就是答案）

程序输出 $\min\{\texttt{sum}[s]-B:\ 1\le s<2^N,\ \texttt{sum}[s]\ge B\}$（若集合为空则输出哨兵）。该值等于 $\mathrm{Ans}$。

*证明*：由引理 4，$\texttt{sum}[s]=\sigma(s)$，故程序计算的集合与 $\{\sigma(s)-B:s\in\mathcal F\}$ 逐项相同（$\mathcal F$ 的定义正是 $s\ge 1\land\sigma(s)\ge B$）。由引理 2，该集合非空，哨兵必被替换，`min` 的累积结果就是集合最小元 $=\mathrm{Ans}$。再由引理 1，$\mathrm{Ans}$ 就是题目所求。证毕。

---

### 引理 6（超出量的紧上界：$\mathrm{Ans}<\min_{i\in T^\*}H_i$）

设 $s^\*\in\mathcal F$ 使 $\sigma(s^\*)-B=\mathrm{Ans}$，$T^\*=T(s^\*)$。则对每个 $i\in T^\*$ 都有 $H_i>\mathrm{Ans}$。从而 $\mathrm{Ans}\le\max_i H_i-1\le 999999$。

*证明*：若 $\mathrm{Ans}=0$，则 $H_i\ge 1>0$ 对一切 $i$ 成立，结论显然。

设 $\mathrm{Ans}>0$，即 $\sigma(s^\*)>B$。任取 $i\in T^\*$，令 $s_i=s^\*\oplus 2^i$（把奶牛 $i$ 移出塔）。则 $\sigma(s_i)=\sigma(s^\*)-H_i<\sigma(s^\*)$。

**断言**：$\sigma(s_i)<B$。反证：若 $\sigma(s_i)\ge B$，则 $s_i\in\mathcal F$（$s_i\ge 1$？若 $T^\*=\{i\}$ 则 $s_i=0$、$\sigma(s_i)=0<B$，与假设矛盾，故此时断言自动成立；否则 $s_i\ge 1$），于是 $\sigma(s_i)-B$ 是目标集合中的一个元素且 $\sigma(s_i)-B<\sigma(s^\*)-B=\mathrm{Ans}$，与 $\mathrm{Ans}$ 是最小值矛盾。断言成立。

由 $\sigma(s^\*)-H_i<B$ 得 $H_i>\sigma(s^\*)-B=\mathrm{Ans}$。对 $i\in T^\*$ 全部成立，故 $\mathrm{Ans}<\min_{i\in T^\*}H_i\le\max_{0\le i<N}H_i\le 10^6$。整数不等式给出 $\mathrm{Ans}\le 10^6-1=999999$。证毕。

**用途**：(1) `int` 足够（其实引理 2 已给更弱的 $2\times 10^7$ 界，这里是紧界）；(2) DFS 剪枝：一旦当前超出量 $\ge$ 已选最矮身高就不可能更优；(3) 背包路线只需在 $[B,B+\max H)$ 内找第一个可达值。

---

### 引理 7（值域与溢出安全）

所有 $\sigma(s)\le S\le 2\times 10^7$，$\texttt{sum}$ 数组与 `ans` 用 `int` 安全；$\texttt{sum}[s']+H_j$ 的中间量也不超过 $2\times 10^7$。

*证明*：$H_i\ge 1>0$，故 $\sigma(s)=\sum_{i\in T(s)}H_i\le\sum_{i=0}^{N-1}H_i=S\le 20\times 10^6=2\times 10^7$。递推中的加法结果就是某个 $\sigma(s)$，同样 $\le 2\times 10^7$。`int` 上限 $2^{31}-1=2147483647\approx 2.1\times 10^9$，余量约 $100$ 倍。`ans` 的哨兵 $1145141919<2^{31}-1$ ✓，真实答案 $\le 2\times 10^7$ ✓。掩码 $s<2^{20}$，`1<<n` 最大 $2^{20}$，`int` 安全。证毕。

### 引理 8（另一条路线：`bitset` 子集和 DP 的正确性与代价）

设 $f$ 是长度 $S+1$ 的位串，初值 $f[0]=1$、其余 $0$。依次对每头奶牛 $i$ 执行 $f\mathrel{|}=f\ll H_i$（右侧用移位前的快照）。则处理完全部奶牛后 $f[v]=1\iff\exists T,\ \sum_{i\in T}H_i=v$。于是 $\mathrm{Ans}=\min\{v\ge B:f[v]=1\}-B$，且由引理 6 只需扫描 $v\in[B,\ B+\max H)$。

*证明*：对已处理的奶牛数 $t$ 归纳，命题 $P(t)$：$f[v]=1\iff v$ 是"前 $t$ 头奶牛的某个子集"的和。

$t=0$：只有空集，和为 $0$，$f[0]=1$、其余 $0$ ✓。

设 $P(t-1)$ 成立。第 $t$ 头奶牛身高 $h=H_{t-1}$。新子集分两类：不含第 $t$ 头（和集合不变，对应旧 $f$），含第 $t$ 头（和 $=$ 旧某个可达和 $+h$，对应 $f\ll h$）。`f |= f<<h` 中右侧 `f<<h` 先按旧 $f$ 求值（C++ 复合赋值的语义：先算右操作数再合并），故恰好把这两类并起来，且**不会把第 $t$ 头奶牛用两次**（那需要 $f\ll 2h$，不存在）。故 $P(t)$ 成立。

$t=N$ 时即得结论。最小可达 $v\ge B$ 存在（$v=S$ 可达，引理 2），故 $\mathrm{Ans}$ 的表达式正确。扫描范围：由引理 6，$\mathrm{Ans}\le\max H-1$，故最优 $v=B+\mathrm{Ans}\le B+\max H-1$，只需扫 $[B,B+\max H)$。

代价：`bitset` 每次移位 + 或运算处理 $\lceil (S+1)/64\rceil$ 个机器字，$N$ 次共 $O(NS/64)\approx 20\times 2\times 10^7/64=6.25\times 10^6$ 次字操作；空间 $S/8\approx 2.5$ MB。与枚举路线的 $O(2^N)\approx 10^6$ 相比，本题枚举更快。证毕。

**这条引理的意义是"讨论范围选算法"**：若把 $N$ 放大到 $100$、$H_i$ 缩小到 $10^3$（$S\le 10^5$），枚举 $2^{100}$ 立刻不可行，而 `bitset` DP 只需 $100\times 10^5/64\approx 1.6\times 10^5$ 次字操作，成为唯一选择。

### 引理 9（复杂度）

时间 $O(2^N+N)$，空间 $O(2^N+N)$。$N=20$ 时约 $1.05\times 10^6$ 次 $O(1)$ 递推，数组 $(2^{20}+5)$ 个 `int` $\approx 4.2$ MB。

*证明*：读入 $O(N)$。主循环执行 $2^N-1$ 次，每次由引理 4 的推论为 $O(1)$（`__builtin_ctz` 编译为单条 `tzcnt`/`bsf` 指令），加上一次比较与可能的 `min`，仍 $O(1)$。故时间 $O(2^N+N)$。空间：`sum` 数组 $2^N+5$ 个 `int`，`h` 数组 $N+5$ 个 `int`，其余 $O(1)$，故 $O(2^N+N)$。代入 $N=20$：$2^{20}=1048576$ 次迭代，$1048581\times 4\ \text{B}\approx 4.19$ MB。证毕。

### 定理

程序输出题目所求的最小超出量，时间 $O(2^N)$，空间 $O(2^N)$。

*证明*：引理 1 把叠塔问题等价化为子集和目标 $\mathrm{Ans}$；引理 2 保证 $\mathrm{Ans}$ 存在、非负、哨兵必被更新；引理 3 说明贪心不可用（必须全局枚举）；引理 4 保证 $\texttt{sum}[s]=\sigma(s)$；引理 5 保证枚举取 min 就是 $\mathrm{Ans}$；引理 6、7 保证值域与 `int` 安全；引理 9 给出复杂度；引理 8 给出另一条路线的等价性与选择依据。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 塔高 = 身高求和，加法交换/结合 ⇒ 叠放顺序无关，方案塌缩成一个**子集**；问题 = "$\ge B$ 的最小子集和减 $B$"。
- **explore its property** — $B\le S$ ⇒ 全取可行 ⇒ 最优值存在、答案非负、哨兵必被更新。
- **consider easier version** — 先试最朴素的降序贪心（取到 $\ge B$ 就停），两个反例（$[6,5,5],B=10$；$[5,4,3],B=7$）打掉。
- **explore its property** — 交换论证找失败条件：贪心解在"删除 / 单替换"下局部最优仍可能非全局最优（$[7,6,5,3,2,1],B=17$），说明子集和没有拟阵结构，必须全局搜索。
- **discuss by category** — 看范围选算法：$N\le 20\Rightarrow 2^N\approx 10^6$ 枚举可行；$S\le 2\times 10^7\Rightarrow$ 朴素背包 $O(NS)=4\times 10^8$ 太慢，`bitset` 压位才可行；本题选枚举。
- **classic problem solution** — lowbit 子集和递推 $\texttt{sum}[s]=\texttt{sum}[s\oplus\mathrm{low}(s)]+H_{\mathrm{ctz}(s)}$，把 $O(N2^N)$ 压到 $O(2^N)$。
- **explore its property** — 最优超出量 $<$ 塔中最矮身高 ⇒ $\mathrm{Ans}\le\max H-1\le 999999$，可作剪枝 / 值域裁剪 / 溢出核算。
- **classic problem solution** — 备选路线：0/1 背包可行性 DP（`bitset` 的 $f\mathrel{|}=f\ll H_i$），$N$ 大而值域小时改用它。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 奶牛数 $N\le 20$ | `int`，读入 | 掩码位数 |
| `b` | 书架高 $B\in[1,S]$ | `int`，读入 | 可行性下界 |
| `h[i]` | 第 $i$ 头奶牛身高（0-based） | `int[mxn]`，读入 | `mxn{25}` = $20+5$ |
| `sum[s]` | 掩码 $s$ 对应子集的身高和 $\sigma(s)$ | `int[mxs]`，全局默认 $0$ | `sum[0]=0` 恰好正确；其余由 lowbit 递推 |
| `mxs` | $(1\ll 20)+5$ | `constexpr int` | 子集数组尺寸，$\approx 4.2$ MB |
| `low` | $s\ \&\ (-s)$，最低位的 $1$ | `int`，每轮现算 | `s^low` 是去掉该位的子掩码，且 $<s$ |
| `ans` | 最小超出量 | `int`，初值 $1145141919$ | 引理 2 保证必被更新 |
| `s` | 当前枚举的子集掩码 | `int`，$1..2^N-1$ | 跳过 $0$（空集，$0<B$ 不可行） |

### 算法步骤

1. I/O 加速三行（固定顺序）。
2. 读入 `n,b` 与 `h[0..n-1]`。
3. `ans=1145141919`。
4. 对 `s=1..(1<<n)-1` 升序：
   1. `low=s&-s`；
   2. `sum[s]=sum[s^low]+h[__builtin_ctz(low)]`（引理 4：子问题已算过）；
   3. 若 `sum[s]>=b`，`ans=min(ans,sum[s]-b)`。
5. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(2^N+N)$，$N=20$ 时约 $1.05\times 10^6$ 次 $O(1)$ 递推。
- 空间：$O(2^N+N)$，`sum` 数组约 $4.2$ MB。
- 值域：$\sigma\le 2\times 10^7$，$\mathrm{Ans}\le 999999$，`int` 安全（引理 6、7）。

### 验证状态

`g++ -std=c++20 -O2 -Wall -Wextra` 编译通过、无警告。题面无输入样例，按输出说明反推 $1$ 组 + 自造 $7$ 组（贪心反例、局部最优反例、单头奶牛、$B=S$、二进制权值、全 $10^6$ 触上界、$N=20$ 极限）全部与手算一致；$N=20,S=2\times 10^7$ 极限数据 $0.06$ s 内跑完。本题为入门级枚举，按规范不做暴力对拍、不建 appendix。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2677 [USACO07DEC] Bookshelf 2 B
// 思路：塔高 = 某个非空子集的身高和；求 >=B 的最小子集和，答案 = 该和 - B。
//       N<=20 ⇒ 直接递推出全部 2^N 个子集和：sum[s]=sum[s^lowbit(s)]+h[ctz(s)]。
//       B<=S 保证全取可行，答案一定存在；且答案 < 塔中最矮奶牛的身高 <= maxH-1。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25},mxs{(1<<20)+5};

int n,b,h[mxn],sum[mxs];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>b;
	for(int i=0;i<n;++i)
		cin>>h[i];
	int ans=1145141919;
	for(int s=1;s<(1<<n);++s)	// s=0 是空集，身高和 0<B，不用考虑
	{
		int low=s&-s;
		sum[s]=sum[s^low]+h[__builtin_ctz(low)];	// 去掉最低位的 1，子问题已算过
		if(sum[s]>=b)
			ans=min(ans,sum[s]-b);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`sum[s^low]` 一定已算好**：`s^low == s-low < s`，而循环按 `s` 升序，这是整份代码唯一的依赖顺序，不能改成降序或随机序。
- **`sum[0]=0` 靠全局零初始化**：空集和为 $0$，恰好正确，不需要显式赋值；但**这不是"不可达"数组**，所以不涉及"全局默认 0 被误当合法值"的陷阱（本题 $0$ 就是合法的空集和）。
- **跳过 `s=0`**：$B\ge 1$ 使空集不可行，跳过不影响答案；若 $B$ 可以为 $0$ 则必须把 `s=0` 也纳入。
- **`__builtin_ctz(low)`**：`low` 是 $2$ 的幂，`ctz` 直接给出奶牛下标（0-based），与读入顺序一致，无需 `--`。
- **哨兵 `1145141919`**：由引理 2，全集可行且 $S-B< $ 哨兵，所以 `ans` 必被更新，不需要额外判"无解"。
- **`mxs{(1<<20)+5}`**：$+5$ 松弛；`1<<n` 最大 $2^{20}$，循环上界取不到 `mxs`，无越界。
- 若改成 DFS 写法，可用引理 6 剪枝（当前超出量 $\ge$ 已选最矮身高即可回溯），但 $N\le 20$ 时递推枚举已经足够快且无递归开销。
