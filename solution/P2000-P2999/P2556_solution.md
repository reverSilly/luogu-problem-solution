# P2556 [AHOI2002] 黑白图像压缩 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一幅黑白图像有 $n$ 个像素（$n$ 是 $8$ 的倍数，$1\le n\le 8\times10^4$），用"位图法"存成 $n/8$ 个字节：每个字节 $8$ 位，**从高位到低位**依次对应 $8$ 个像素，$0$ 白 $1$ 黑。现在要改用"像素片段法"（游程编码）：把连续同色像素合并成一段，每段用一个字节表示——**最高位是颜色，低 $7$ 位是长度**。题目保证每段长度 $<128$。输入位图字节序列，输出片段法的十进制字节序列。

**第一步：先把"字节→像素"的展开方向搞清楚。** 题面例子：字节 $210$ 的二进制是 `11010010`，对应像素"黑黑白黑白白黑白"。注意顺序：**最高位（最左边的 $1$）对应第一个像素**。所以字节 $b$ 的第 $j$ 位（$j=7$ 是最高位）对应第 $7-j$ 个像素。展开时我要从高位往低位读：

$$a[8i+(7-j)]=(b\gg j)\ \&\ 1,\qquad j=7,6,\dots,0.$$

这里最容易错的就是方向——如果误把最低位当第一个像素，整幅图就左右镜像了。我用例子核对：$210=(11010010)_2$，从高位读是 $1,1,0,1,0,0,1,0$，正是"黑黑白黑白白黑白" ✓。

**第二步：游程编码就是"扫一遍，数连续同色"。** 展开成像素数组 $a[0..n-1]$ 后，从左到右扫描：遇到一段连续的相同颜色，就数出它的长度 $len$，输出一个字节 $(\text{颜色}\ll7)\mid len$，然后跳到下一段。例如像素 `11 0 1 00 1 000000000 11111111` 分成 $7$ 段，长度分别是 $2,1,1,2,1,9,8$，颜色 $1,0,1,0,1,0,1$，编码成 $130,1,129,2,129,9,136$。

实现上我用双指针：`i` 指向段首，`j` 从 `i` 往后走到第一个颜色不同的位置，`j-i` 就是段长。这样每段只扫一次，总共 $O(n)$。

**第三步：为什么长度能塞进 $7$ 位？——题目那句保证是关键。** 一个字节 $8$ 位，最高位给了颜色，剩下 $7$ 位给长度，能表示 $0\sim127$。题目明确说"**每个片段的最大长度小于 $128$**"，也就是每段长度 $\le127$，恰好塞得下，**不需要把长段拆成多段**。我特意确认了这一点：如果题目没这个保证，遇到长度 $\ge128$ 的段就得拆分（一段拆成若干个 $\le127$ 的同色段），但本题保证了不会发生，所以直接编码即可。

这一步还顺带解决了"颜色位和长度位会不会打架"的疑虑：颜色占第 $7$ 位（值 $0$ 或 $128$），长度占第 $0\sim6$ 位（值 $0\sim127$），两者**位段不重叠**，按位或 `|` 拼起来就是一个 $0\sim255$ 的合法字节，且能唯一拆回 (颜色, 长度)。

**第四步：段会跨字节边界，必须先整体展开。** 一个连续同色段可能横跨好几个字节（比如例子里那段 $9$ 个白像素，跨了第 $2$、第 $3$ 个字节）。所以我不能"逐字节独立编码"，必须先把所有字节展开成完整的像素序列，再在像素序列上做游程编码。这也是我选择开一个 $a[80005]$ 数组整体展开的原因——逻辑最直白，不会在字节边界处把一段错误地切成两段。

**手造数据核对**（题面给了一个完整例子，我把它当主测试，再补两个边界）：

主测试，$n=24$，字节 `210 0 255`：展开成 `11010010 00000000 11111111`，游程分成 $7$ 段，输出 `130 1 129 2 129 9 136`，与题面完全一致。

边界一，$n=128$，前 $127$ 个像素黑、最后 $1$ 个白（字节 `255`×$15$ + `254`）：第一段长 $127$（恰好是 $7$ 位上限），编码 $(1\ll7)\mid127=255$；第二段长 $1$ 白，编码 $1$。输出 `255 1`，验证了"长度 $127$ 不溢出"。

边界二，$n=8$，字节 `170`（`10101010`，黑白交替）：$8$ 段各长 $1$，输出 `129 1 129 1 129 1 129 1`，验证了"每段长 $1$"和"颜色交替"。

## 二、思维链：完整证明

**记号。** 输入字节序列 $b_0,\dots,b_{n/8-1}$，每个 $b_i\in[0,255]$。展开后像素序列 $a[0..n-1]\in\{0,1\}$。游程编码输出字节序列 $v_0,\dots,v_{R-1}$。

---

### 引理 1（字节展开的方向与正确性）

对第 $i$ 个字节 $b_i$，其 $8$ 个像素按"高位在前"展开为
$$a[8i+k]=(b_i\gg(7-k))\ \&\ 1,\qquad k=0,1,\dots,7.$$
即 $a[8i]$ 是最高位（bit $7$），$a[8i+7]$ 是最低位（bit $0$）。

*证明*：题面规定"八个像素从前向后依次对应于字节从高位到低位的八个位"。字节 $b_i$ 的第 $j$ 位（$j=7$ 最高，$j=0$ 最低）的值为 $(b_i\gg j)\&1$。"从前向后"的第 $k$ 个像素（$k=0$ 最前）对应"从高位到低位"的第 $k$ 个位，即 bit $7-k$。故 $a[8i+k]=(b_i\gg(7-k))\&1$。

代码用等价写法 `for(j=7;j>=0;--j) a[i*8+(7-j)]=(b>>j)&1`：令 $k=7-j$，当 $j$ 从 $7$ 递减到 $0$，$k$ 从 $0$ 递增到 $7$，与上式逐项一致。

**方向反证**：若误用 $a[8i+k]=(b_i\gg k)\&1$（低位在前），则 $a[8i]$ 变成 bit $0$，整幅图每个字节内部左右镜像。用题面例子 $b=210=(11010010)_2$ 检验：正确展开首位是 bit $7=1$（黑），镜像展开首位是 bit $0=0$（白），与题面"第一个像素黑"矛盾。故必须高位在前。证毕。

---

### 引理 2（游程划分的良定义与双射）

像素序列 $a[0..n-1]$ 被唯一划分为若干**极大同色连续段**（游程）$[l_0,r_0),[l_1,r_1),\dots$，满足 $l_0=0$、$r_{s}=l_{s+1}$、$r_{R-1}=n$，且每段内颜色恒定、相邻段颜色不同。该划分与像素序列一一对应（给定序列划分唯一，给定各段 (颜色,长度) 可唯一还原序列）。

*证明*：**存在唯一**：从 $l_0=0$ 起，令 $r_0$ 为最大的使 $a[0..r_0-1]$ 同色的右端点（即第一个与 $a[0]$ 不同色的位置，或 $n$）；再令 $l_1=r_0$ 重复。每步右端点由"极大同色"唯一确定，故划分唯一。相邻段颜色必不同（否则可合并，与"极大"矛盾）。

**双射**：正向，序列 $\to$ 各段 (颜色 $c_s=a[l_s]$, 长度 $len_s=r_s-l_s$)。逆向，给定 $(c_s,len_s)$ 序列，依次铺 $len_s$ 个颜色 $c_s$ 的像素即还原 $a$（因 $\sum len_s=n$ 且相邻 $c_s$ 不同，铺出的序列恰以这些位置为极大同色段边界）。两方向互逆，故双射。证毕。

---

### 引理 3（编码字节合法且唯一可拆）

设某段颜色 $c\in\{0,1\}$、长度 $len$。题目保证 $1\le len<128$（段非空且长度 $<128$）。则编码字节 $v=(c\ll7)\mid len$ 满足 $v\in[0,255]$，且 $c=v\gg7$、$len=v\ \&\ 127$ 唯一恢复。

*证明*：$c\ll7\in\{0,128\}$，占 bit $7$；$len\in[1,127]$，占 bit $0\sim6$（因 $len<128=2^7$）。两个位段不重叠，故按位或等于相加：$v=(c\ll7)+len\in[0,128+127]=[0,255]$，是合法字节。

可拆性：$v\gg7$ 取出 bit $7$ 即 $c$（因 $len<128$ 不污染 bit $7$）；$v\&127$ 取出低 $7$ 位即 $len$（因 $c\ll7$ 只占 bit $7$，被 $\&127$ 屏蔽）。故 $(c,len)$ 唯一恢复。

**长度保证的必要性（反证）**：若 $len\ge128$，则 $len$ 的第 $7$ 位为 $1$，与颜色位 $c\ll7$ 重叠，$v=(c\ll7)\mid len$ 会把长度的进位混入颜色位，解码 $v\gg7$ 不再等于 $c$，编码失效。题目"每段长度 $<128$"正好排除此情形，故无需拆分长段。证毕。

---

### 引理 4（压缩无损：解码还原原图）

把输出字节序列 $v_0,\dots,v_{R-1}$ 逐个解码为 $(c_s,len_s)$（引理 3），再依次铺 $len_s$ 个颜色 $c_s$ 的像素，得到的序列恰为原像素序列 $a[0..n-1]$。

*证明*：由引理 2，原序列唯一划分为游程 $(c_s,len_s)$；由引理 3，每个 $v_s$ 唯一编码 $(c_s,len_s)$ 且可唯一拆回。解码后铺像素正是引理 2 的逆向操作，故还原 $a$。又 $\sum_s len_s=n$（游程划分覆盖整个序列），铺出的像素总数为 $n$，与原图一致。故压缩无损。证毕。

---

### 引理 5（双指针扫描正确且 $O(n)$）

代码 `for(i=0;i<n;){ j=i; while(j<n&&a[j]==a[i])++j; 输出(a[i]<<7)|(j-i); i=j; }` 恰好按引理 2 的游程划分逐段输出，总时间 $O(n)$。

*证明*：**正确**：外层 `i` 是当前段首。内层 `while` 把 `j` 推到第一个 $a[j]\ne a[i]$ 的位置（或 $n$），故 $[i,j)$ 是以 $i$ 开头的极大同色段，$j-i=len$。输出 $(a[i]\ll7)\mid(j-i)$ 即该段编码（引理 3）。然后 `i=j` 跳到下一段首。由归纳，每次外层迭代处理一个完整游程，直到 $i=n$，恰好遍历引理 2 的全部游程。

**复杂度**：内层 `j` 在整个算法中单调不减（每段 `j` 从 `i` 走到段尾，下一段 `i=j` 接着走），故 `while` 的总执行次数 $\le n$。外层段数 $R\le n$。总时间 $O(n)$。展开字节 $O(n)$，输出 $O(R)=O(n)$。空间 $O(n)$（像素数组）。证毕。

---

### 定理

程序输出的十进制字节序列是输入位图的像素片段法表示，且可无损还原原图；时间 $O(n)$，空间 $O(n)$。

*证明*：引理 1 保证字节按"高位在前"正确展开为像素；引理 2 保证游程划分良定义；引理 5 保证双指针逐段输出正确编码；引理 3 保证每段编码合法（长度 $<128$ 塞进 $7$ 位）；引理 4 保证无损。复杂度由引理 5 给出。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 字节→像素是"高位在前"：$a[8i+k]=(b\gg(7-k))\&1$；方向反了整幅图镜像。
- **reduce to easier problem** — 像素片段法 = 游程编码（RLE）：扫一遍，把连续同色合并成段，每段输出 $(c\ll7)\mid len$。
- **explore its property** — 题目保证段长 $<128$ ⇒ 长度恰塞进低 $7$ 位、颜色占第 $7$ 位，位段不重叠，无需拆分长段。
- **classic problem solution** — 双指针求极大同色段：`j` 单调推进，总扫描 $O(n)$；段可跨字节，故先整体展开再编码。
- **discuss by category** — 边界：段长 $1$、段长 $127$（上限）、跨字节长段、全同色单段，逐类核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 像素总数（$8$ 的倍数，$\le8\times10^4$） | `int`，读入 | 字节数 $=n/8$ |
| `a[i]` | 第 $i$ 个像素颜色（$0$ 白 / $1$ 黑） | `int[mxn]`，展开填入 | $0$-based，高位在前 |
| `mxn` | $80000+5$ | `constexpr int{80005}` | $+5$ 松弛 |
| `b` | 读入的一个位图字节 | `int` | $0\sim255$ |
| `i,j` | 游程双指针：`i` 段首，`j` 段尾（开） | `int` | `j-i`=段长 |
| `first` | 是否第一段（控制输出空格） | `bool`，初值 `true` | 段间空格分隔 |

### 算法步骤

1. I/O 加速三行；读 `n`。
2. 读 $n/8$ 个字节，每个按 `for(j=7..0) a[i*8+(7-j)]=(b>>j)&1` 展开（高位在前）。
3. 双指针扫描：`i=0`；每轮 `j=i`，`while(j<n&&a[j]==a[i])++j`；输出 `(a[i]<<7)|(j-i)`（段间空格）；`i=j`。
4. 末尾换行。

### 复杂度

- 时间：$O(n)$（展开 $O(n)$ + 扫描 $O(n)$），$n\le8\times10^4$。
- 空间：$O(n)$（像素数组 `int[80005]` $\approx320$ KB）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子 `210 0 255`→`130 1 129 2 129 9 136` 吻合；另测段长 $127$ 上限（输出 `255 1`）、黑白交替（`129 1 ...`）两组边界全对。普及-级直接模拟，证明已闭合，无需对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2556 [AHOI2002] 黑白图像压缩
// 字节展开成像素（高位在前），再按颜色做游程编码：每段输出 (颜色<<7)|长度
// 题目保证每段长度 < 128，恰好塞进低 7 位
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{80005};

int n,a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n/8;++i)
	{
		int b;
		cin>>b;
		for(int j=7;j>=0;--j)
			a[i*8+(7-j)]=(b>>j)&1;	// 高位对应前面的像素
	}
	bool first=true;
	for(int i=0;i<n;)
	{
		int j=i;
		while(j<n&&a[j]==a[i])
			++j;
		if(!first)
			cout<<' ';
		first=false;
		cout<<((a[i]<<7)|(j-i));	// 颜色占最高位，长度占低 7 位
		i=j;
	}
	cout<<'\n';
	return 0;
}
```

### 代码说明

- **`a[i*8+(7-j)]=(b>>j)&1`**：$j$ 从 $7$（最高位）递减到 $0$，$7-j$ 从 $0$ 递增到 $7$，实现"高位在前"展开（引理 1）。写反成 `(b>>(7-j))` 配 `a[i*8+j]` 也行，但方向必须一致，否则镜像。
- **先整体展开再编码**：游程可跨字节边界（如 $9$ 个白像素跨两个字节），逐字节独立编码会把一段错切成多段，故必须先展开成完整像素序列（引理 2、第四步叙事）。
- **`(a[i]<<7)|(j-i)`**：颜色 $a[i]\in\{0,1\}$ 左移 $7$ 位占最高位，长度 $j-i<128$ 占低 $7$ 位，位段不重叠（引理 3）。题目保证长度 $<128$，故无需拆分。
- **双指针 `j` 单调推进**：每段 `j` 从 `i` 走到段尾，`i=j` 接续，总扫描 $O(n)$（引理 5）。
- **`first` 控制空格**：题面要求"相邻数之间用一个空白字符隔开"，故段间输出空格、首段前不输出，末尾补换行。
- **`mxn{80005}`**：$n\le8\times10^4$，$+5$ 松弛；`int` 数组存 $0/1$ 像素，约 $320$ KB，远低于限制。
