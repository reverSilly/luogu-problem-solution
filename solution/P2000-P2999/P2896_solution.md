# P2896 [USACO08FEB] Eating Together S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 给一个长度 $N\le 3\times10^4$ 的序列，每个元素 $\in\{1,2,3\}$。每次操作可以把一个位置的数改成 $\{1,2,3\}$ 中任意一个（不能移动位置）。求最少修改次数，使整个序列变成**不降**（如 `111222333`）或**不升**（如 `333222111`）。

**口径说明。** 题面说"升序或降序"，但给出的例子 `111222333` 含大量重复，所以这里的"序"是**非严格**的（允许相邻相等）。两种方向都合法，答案取两者较小。$N\ge1$，单元素序列两种方向都天然满足，答案 $0$。

**试探 1：枚举目标序列。** 每个位置 $3$ 种取值，$3^{30000}$ 个候选，天文数字。但枚举的视角透露了一个信息：**目标序列的约束只有"相邻两个值的大小关系"**——不降就是 $b_1\le b_2\le\dots\le b_N$，一条链式局部约束。

**试探 2：贪心"哪里逆序改哪里"。** 序列 `2 3 1 3 2`：看到 `3 1` 逆序，改 $1\to3$？得 `2 3 3 3 2`，还有 `3 2` 逆序，再改……改法之间互相影响，局部修补没有全局观，很难保证最少。放弃。

**关键观察：代价按位置独立，约束只连接相邻。** 修改代价是 $\sum_i[a_i\ne b_i]$，每个位置贡献 $0$ 或 $1$，互不纠缠；而合法性只要求 $b_{i-1}\le b_i$。这正是**线性 DP 的标准形状**：从左到右决定每个 $b_i$，只需要记住"上一个值是多少"。值域只有 $3$，状态就是
$$f[i][j]=\text{前缀 }a_1..a_i\text{ 改成不降、且 }b_i=j\text{ 的最少修改数}.$$
转移：$b_{i-1}$ 可以是任何 $k\le j$，所以
$$f[i][j]=[a_i\ne j]+\min_{k\le j}f[i-1][k].$$
状态数 $3N$，每个状态转移看 $\le3$ 个前驱，$O(9N)$ 已经稳过。再进一步：$\min_{k\le j}f[i-1][k]$ 是**前缀最小值**，$j$ 从小到大扫一遍、维护滚动 $\mathrm{mn}$ 即可，$O(3N)$。

**不升怎么办？再写一份对称 DP？不用。** 把每个值 $v$ 映成 $4-v$（$1\leftrightarrow3$，$2$ 不动），这是一个**翻转大小关系的对合**：原序列的不升目标翻转后恰是不降目标，而且"改没改"这件事在翻转下不变（$a_i\ne b_i\iff 4-a_i\ne 4-b_i$）。所以**同一份 DP 跑两遍**：一遍原值，一遍翻转值，取 $\min$。代码里内部用 $0$-based 值 $0,1,2$，翻转就是 $v\mapsto 2-v$。

**换个视角验算：答案 $=N-\max(\text{最长不降子序列},\text{最长不升子序列})$。** 不改的位置构成原序列的一个不降子序列，所以改的次数 $\ge N-\mathrm{LNDS}$；反过来，保留一个最长不降子序列、把其余位置"填"成它左边最近的保留值，就得到一个合法的不降目标（下面引理 4 严格证）。这给了 DP 一个独立的交叉验证：手算小数据时我用 LNDS/LNIS 数长度，和 DP 输出对上了才放心。

**实现细节。**

1. **$f$ 不需要 INF 初始化**：第一个位置取任何结尾值 $j$ 都合法，$f[0][j]=[a_0\ne j]$ 直接赋值，三个状态全部可达。这和"最短路里不可达状态"完全不同，别惯性填 INF。
2. 滚动数组：$f[3]$ 与临时 $g[3]$，每轮先算完 $g$ 再整体拷回 $f$——**不能边算边覆盖 $f$**，否则 $j$ 大的转移会用到本轮已更新的 $f[j']$（$j'<j$），把"前缀 min"污染成"允许 $b_i$ 取多个值"的错误语义。
3. 每轮 $\mathrm{mn}$ 重置为 INF，再随 $j$ 递增累积 $\min$。
4. 读入即 `--a[i]` 转 $0$-based，比较 `v!=j` 直接给出 $0/1$ 代价。

**手造数据核对**（题面无样例，全部手造，用 LNDS/LNIS 视角独立手算）：

| 输入序列 | 手算 | 输出 |
|---|---|---|
| `1 3 2 2 1` | LNIS $=3,2,2,1$ 长 $4$，改 $1$ 处（$1\to3$） | `1` ✓ |
| `2`（$N=1$） | 天然有序 | `0` ✓ |
| `2 1 3` | LNDS $=2,3$ 长 $2$；LNIS $=2,1$ 长 $2$；改 $1$ | `1` ✓ |
| `3 1 2 3` | LNDS $=1,2,3$ 长 $3$，改 $1$（$3\to1$） | `1` ✓ |
| `1 2 3 1 2 3` | LNDS $=1,1,2,3$ 长 $4$，改 $2$ | `2` ✓ |
| `2 2 1 1` | 已不升 | `0` ✓ |
| `3 2 1` | 已不升 | `0` ✓ |
| `2 3 1 3 2` | LNDS $=2,3,3$ 长 $3$；LNIS $=3,3,2$ 长 $3$；改 $2$ | `2` ✓ |

第 2 组打 $N=1$，第 6、7 组打"已有序（含重复）"，第 8 组打"两个方向打平"。

## 二、思维链：完整证明

**记号。** 原序列 $a_0..a_{N-1}\in\{0,1,2\}$（内部 $0$-based）。目标序列 $b_0..b_{N-1}\in\{0,1,2\}$。**不降**指 $b_0\le b_1\le\dots\le b_{N-1}$；**不升**指反向。代价 $C(b)=\sum_i[a_i\ne b_i]$（$[\cdot]$ 为艾弗森括号）。$\mathrm{ans}=\min\{C(b):b\text{ 不降或不升}\}$。翻转映射 $\varphi(v)=2-v$。$f_i(j)$ 表示"前缀 $a_0..a_i$ 改成不降且 $b_i=j$"的最小代价。

---

### 引理 1（约束的局部性：相邻 $\iff$ 全局）

序列 $b$ 不降当且仅当对所有 $i\ge1$ 有 $b_{i-1}\le b_i$。

*证明*：必要性显然（全局定义包含相邻对）。充分性：对任意 $p<q$，链式应用 $b_p\le b_{p+1}\le\dots\le b_q$（整数 $\le$ 的传递性，对 $q-p$ 归纳即得），故全局不降。证毕。

**意义**：合法性可以逐位检查，DP 只需携带"上一个值"这一个比特的历史——这是状态能压到 $3$ 维的根本原因。

---

### 引理 2（不降方向的 DP 正确）

定义 $f_0(j)=[a_0\ne j]$，且对 $i\ge1$：
$$f_i(j)=[a_i\ne j]+\min_{0\le k\le j}f_{i-1}(k).$$
则 $f_i(j)$ 等于"前缀 $a_0..a_i$ 改成不降且末位为 $j$"的最小代价；不降方向的最优值为 $\min_j f_{N-1}(j)$。

*证明*：对 $i$ 归纳。

$i=0$：前缀只有一个位置，$b_0=j$ 无相邻约束，代价恰 $[a_0\ne j]$ ✓。

设 $f_{i-1}$ 正确。考察任一合法前缀赋值 $b_0..b_i$，$b_i=j$。由引理 1，合法性等价于"$b_0..b_{i-1}$ 不降且 $b_{i-1}\le j$"。代价可拆分：
$$C(b_0..b_i)=C(b_0..b_{i-1})+[a_i\ne j],$$
两项分别只依赖前缀与末位。固定 $b_{i-1}=k\le j$ 时，前缀部分的最小值由归纳假设为 $f_{i-1}(k)$；反之，任何达到 $f_{i-1}(k)$ 的前缀赋值接上 $b_i=j$ 都合法（$k\le j$ 满足相邻约束）。故
$$f_i(j)=[a_i\ne j]+\min_{k\le j}f_{i-1}(k).$$
三个 $j$ 都可达（第一个位置起就没有不可达状态），$\min$ 在有限非空集上取得。最后，任何不降目标必有某个末位 $j$，故全局最优 $=\min_j f_{N-1}(j)$。证毕。

---

### 引理 3（翻转归约：不升方向复用同一 DP）

$\varphi(v)=2-v$ 是 $\{0,1,2\}$ 上的对合双射，且：
(a) $b$ 不升 $\iff$ $\varphi(b)$（逐位作用）不降；
(b) $[a_i\ne b_i]=[\varphi(a_i)\ne\varphi(b_i)]$。
因此"序列 $a$ 改成不升的最小代价" $=$ "序列 $\varphi(a)$ 改成不降的最小代价"。

*证明*：$\varphi(\varphi(v))=2-(2-v)=v$，对合；$\varphi$ 把 $\{0,1,2\}$ 映到自身且单射（$2-v=2-w\Rightarrow v=w$），故双射。

(a) $b_{i-1}\ge b_i\iff 2-b_{i-1}\le 2-b_i\iff\varphi(b)_{i-1}\le\varphi(b)_i$，逐对等价，由引理 1 得全局等价。

(b) 双射保持不等：$a_i\ne b_i\iff\varphi(a_i)\ne\varphi(b_i)$。

于是 $b\mapsto\varphi(b)$ 是"$a$ 的不升目标"与"$\varphi(a)$ 的不降目标"之间的**保代价双射**（代价逐位相等），两边最小值相等。证毕。

**意义**：不用写第二份对称 DP，`calc(1)` 只是把读入值翻转后跑 `calc(0)` 的同一套转移。

---

### 引理 4（交叉验证视角：$\mathrm{ans}_{\text{不降}}=N-\mathrm{LNDS}$）

设 $L$ 为 $a$ 的最长不降子序列长度。则不降方向的最小代价为 $N-L$。

*证明*：**下界**：设最优目标 $b$ 改了 $c$ 处，保留位置集 $K=\{i:a_i=b_i\}$，$|K|=N-c$。$K$ 中位置按原序取值 $a_i=b_i$，而 $b$ 不降，故 $(a_i)_{i\in K}$ 是 $a$ 的不降子序列，$N-c\le L$，即 $c\ge N-L$。

**上界（构造）**：取一个长为 $L$ 的不降子序列，位置 $p_1<\dots<p_L$。定义
$$b_i=\begin{cases}a_{p_1},&i<p_1\\ a_{p_t},&p_t\le i<p_{t+1}\\ a_{p_L},&i\ge p_L\end{cases}$$
即"每段填左边最近的保留值，开头填第一个保留值"。$b$ 不降：同段内值相同；跨段时段的值按 $a_{p_1}\le\dots\le a_{p_L}$ 递增（子序列不降）。且 $b_{p_t}=a_{p_t}$，保留 $\ge L$ 处，代价 $\le N-L$。

两边夹得最小代价 $=N-L$。对不升方向同理（引理 3 翻转后应用）。证毕。

**用途**：手算小数据时用"数最长不降/不升子序列"独立验算 DP 输出，两套逻辑互为对照。

---

### 引理 5（前缀 min 滚动与实现不变量）

代码用 `mn` 随 $j=0,1,2$ 递增累积 $\min(f[0..j])$，并写入临时数组 $g$ 后整体拷回 $f$。则每轮结束后 $f[j]=f_i(j)$。

*证明*：内层循环第 $j$ 步执行 `mn=min(mn,f[j])` 后，$\mathrm{mn}=\min_{k\le j}f_{i-1}(k)$（对 $j$ 归纳：$j=0$ 时 $\mathrm{mn}=\min(\mathrm{INF},f[0])=f[0]$，$\mathrm{INF}>$ 任何合法代价故不干扰；$j$ 步由 $j-1$ 步的 $\min_{k\le j-1}$ 并入 $f[j]$ 得 $\min_{k\le j}$）。于是 `g[j]=mn+(v!=j)` 恰为引理 2 的转移。**必须用 $g$ 中转**：若直接写 `f[j]=mn+(v!=j)`，则第 $j$ 步的 `mn` 会混入本轮已更新的 $f[j']$（$j'<j$，属于第 $i$ 层而非 $i-1$ 层），破坏归纳假设。整体拷回后 $f$ 即第 $i$ 层。

初始化：$f[j]=[a_0\ne j]$ 三态全可达，无需 INF；$\mathrm{mn}$ 每轮重置 INF 只是"空前缀 min"的中性元，立即被 $f[0]$ 覆盖。证毕。

---

### 引理 6（复杂度）

时间 $O(N)$（常数 $6$：两方向 $\times$ 每位置 $3$ 个状态），空间 $O(N)$（存 $a$；DP 本身 $O(1)$）。

*证明*：每方向每位置做 $3$ 次 $\min$ 与 $3$ 次赋值，$O(6N)$；读入 $O(N)$。$N=3\times10^4$ 时约 $2\times10^5$ 次基本操作。空间：$a$ 数组 $30005$ 个 `int` 约 $120$ KB，$f,g$ 各 $3$ 个。若改成流式读入两遍可省 $a$，但本题无此必要。证毕。

---

### 定理

程序输出最少修改次数，时间 $O(N)$、空间 $O(N)$。

*证明*：引理 1 把合法性化为相邻约束；引理 2 归纳证明不降 DP 的每个状态与最优值；引理 3 证明翻转归约保代价，不升方向复用同一 DP；引理 5 保证滚动实现与转移语义一致；答案取两方向 $\min$ 恰覆盖题面"升序或降序"；引理 4 提供独立视角交叉验证；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 代价按位置独立（$0/1$ 可拆分），合法性只连接相邻（$\le$ 的传递性）：线性 DP 的标准形状。
2. **consider easier version** — 枚举 $3^N$ 目标不可行；贪心局部修补互相干扰；先只做"不降"这一个方向。
3. **classic problem solution** — 末位值 DP：$f[i][j]=[a_i\ne j]+\min_{k\le j}f[i-1][k]$，值域 $3$ 状态极小。
4. **reduce to easier problem** — 不升 $\xrightarrow{v\mapsto 2-v}$ 不降：翻转是保代价的对合双射，同一份 DP 跑两遍取 $\min$。
5. **classic problem solution** — 前缀最小值滚动：$\mathrm{mn}$ 随 $j$ 递增累积，$O(9N)\to O(3N)$；$g$ 中转防止层内污染。
6. **explore its property** — 独立视角：答案 $=N-\max(\mathrm{LNDS},\mathrm{LNIS})$（保留位成子序列 + 填谷构造），用于手算交叉验证。
7. **discuss by category** — 边界：$N=1$ 答案 $0$；已有序（含重复）答案 $0$；$f$ 三态全可达**无需 INF**，$\mathrm{mn}$ 每轮重置 INF 只是中性元。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 序列长度 $\le3\times10^4$ | `int` | 读入 |
| `a[i]` | 第 $i$ 头牛的组号，内部 $0,1,2$ | `int[mxn]` | 读入即 `--a[i]` |
| `f[j]` | 当前前缀以值 $j$ 结尾的最小修改数 | `int[3]` | 首位置 $[a_0\ne j]$；**无需 INF**（三态全可达） |
| `g[j]` | 本轮转移的临时层 | `int[3]` | 每轮算完整体拷回 `f`，防层内污染 |
| `mn` | $\min_{k\le j}f[k]$ 的滚动前缀 min | `int` | 每轮重置 `inf`，随 $j$ 累积 |
| `dir` | 方向：$0$ 原值不降；$1$ 翻转值不降（=原不升） | `int` | `calc` 参数 |
| `v` | 当前 cow 在本方向下的值：`dir?2-a[i]:a[i]` | `int` | 每位置现算 |
| `mxn` | $30000+5$ | `constexpr int` | 数组尺寸 |
| `inf` | $1145141919$ | `constexpr int` | 只用作 $\min$ 的中性元 |

### 算法步骤

1. I/O 加速三行；读 $N$ 与序列，读入即转 $0$-based。
2. `calc(dir)`：首位置 $f[j]=[v_0\ne j]$；对 $i=1..N-1$：$\mathrm{mn}\leftarrow\mathrm{INF}$，$j=0..2$ 依次 $\mathrm{mn}\leftarrow\min(\mathrm{mn},f[j])$、$g[j]\leftarrow\mathrm{mn}+[v_i\ne j]$；拷回 $f$；返回 $\min_j f[j]$。
3. 输出 $\min(\texttt{calc}(0),\texttt{calc}(1))$。

### 复杂度

- 时间 $O(6N)=O(N)$，$N=3\times10^4$；空间 $O(N)$（DP 本身 $O(1)$）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；8 组手造数据（$N=1$、已不升含重复、两方向打平、需改 $2$ 处等）全部与 LNDS/LNIS 独立手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2896 Eating Together S
// 最少修改使序列不降或不升；值域只有 1..3
// f[j]=前缀以值 j 结尾的最小修改数，f'[j]=(a[i]!=j)+min_{k<=j}f[k]（前缀 min 滚动）
// 不升 = 把值 v 映成 2-v（0-based）后再跑同一份不降 DP
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{30005},inf{1145141919};

int n,a[mxn],f[3],g[3];

int calc(int dir)	// dir=0 不降；dir=1 值翻转后不降 = 原序列不升
{
	int v=dir?2-a[0]:a[0];
	for(int j=0;j<3;++j)
		f[j]=(v!=j);	// 第一头牛：任何结尾值都可达，无需 INF
	for(int i=1,mn;i<n;++i)
	{
		v=dir?2-a[i]:a[i];
		mn=inf;
		for(int j=0;j<3;++j)
		{
			mn=min(mn,f[j]);	// mn=min_{k<=j}f[k]
			g[j]=mn+(v!=j);
		}
		for(int j=0;j<3;++j)
			f[j]=g[j];
	}
	return min({f[0],f[1],f[2]});
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];--a[i];	// 内部 0-based：值 0,1,2
	}
	cout<<min(calc(0),calc(1))<<'\n';
	return 0;
}
```

### 代码说明

- **`g` 中转是硬要求**：`mn` 累积的必须是**上一层**的 $f$；若边算边写 `f[j]`，$j$ 大的状态会吃到本轮新值，转移语义就错了（引理 5）。
- `f` 首层直接赋 $[v_0\ne j]$，三态全可达——本题**没有不可达状态**，不需要 fill INF；`inf` 只当每轮 `mn` 的中性元，第一次 `min` 立即被真实值覆盖。
- 翻转用 `2-a[i]`（$0$-based 的 $v\mapsto 2-v$），与 $1$-based 的 $4-v$ 等价；它保代价、反序（引理 3），所以两个方向共用 `calc`。
- `(v!=j)` 是 `bool`，参与加法自动提升为 $0/1$，正是单位修改代价。
- `min({f[0],f[1],f[2]})` 用初始化列表一次取三值最小；答案 $\le N\le3\times10^4$，`int` 足够。
- 两方向各扫一遍 $a$，所以序列要存下来；`calc` 之间 `f` 被首层重新赋值，无残留状态。
