# P2678 [NOIP 2015 提高组] 跳石头 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 河道起点在 $0$、终点在 $L$（$1\le L\le 10^9$），中间有 $N$ 块岩石（$0\le N\le 5\times 10^4$），位置 $D_i$ 满足 $0<D_i<L$、**严格递增且互不相同**。选手从起点出发，每次跳向**下一块没被移走的岩石**，直到终点。组委会至多移走 $M$ 块中间岩石（$0\le M\le N$，起点终点不能动）。要最大化"整个过程中最短的那一跳"，输出这个最大值。

题面的样例说明写着"移走距离为 $2$ 和 $14$ 的岩石后，最短跳跃距离为 $4$（从 $17$ 跳到 $21$，或从 $21$ 跳到终点）"。据此可以反推出样例是 $L=25,N=5,M=2,D=[2,11,14,17,21]$，答案 $4$。我把它当作第一组核对数据。

**第一步：把"移走岩石"翻译成序列操作。** 把起点和终点也看成位置，得到递增序列

$$0=p_0<p_1=D_1<p_2=D_2<\dots<p_N=D_N<p_{N+1}=L.$$

移走 $M$ 块岩石 = 从内部点 $\{p_1,\dots,p_N\}$ 里删掉至多 $M$ 个；剩下的序列（首尾固定是 $0$ 和 $L$）的**相邻差的最小值**就是选手的最短一跳。目标：

$$\text{ans}=\max_{\text{删至多 }M\text{ 个内部点}}\ \min_i\ (q_{i+1}-q_i).$$

**"最大化最小值"**——这六个字是二分答案的经典信号。直接优化很难（删一个点会**合并**两个间距，影响是全局的、非局部的），但"给定一个阈值 $x$，问能不能做到所有间距 $\ge x$"看起来容易得多。

先确认"直接贪心删最小的间距"为什么不行：$L=10,D=[2,4,6,8]$，原始间距全是 $2$。$M=1$ 时删任何一块都还剩 $2$，答案 $2$；$M=2$ 时答案仍是 $2$；但 $M=3$ 时删掉 $2,4,8$ 得到序列 $0,6,10$，间距 $6,4$，答案 $4$。**删哪几块不是由"原始间距谁最小"决定的**，因为删除会改变后续所有间距。局部贪心没有出路。

**第二步：二分 + 判定。** 定义

$$\texttt{check}(x)=\bigl[\text{存在删法，删不超过 }M\text{ 块，使所有相邻间距}\ge x\bigr].$$

它单调：若 $x$ 可行，则任何 $x'<x$ 也可行（**同一套删法**，间距 $\ge x>x'$）。所以可行的 $x$ 构成一个前缀区间 $[1,\text{ans}]$，二分找右端点即可。

答案的范围也要先定下来：一块都不删时，所有间距是**互不相同的整数之差**，故 $\ge 1$，于是 $\text{ans}\ge 1$；任何方案至少有一跳，其长度 $\le L$，故 $\text{ans}\le L$。二分区间取 $[1,L]$。

**第三步：判定里的贪心。** 从左往右扫，维护 `last` = 上一块**留下**的位置（初始 $0$）。看到 $p_i$：

- 若 $p_i-\texttt{last}<x$：这块**必须移走**（留着它，这一跳就 $<x$），`cnt++`；
- 否则：**留下**，`last=p_i`。

直觉是"能留就留，留得越多删得越少"。但这里我卡了一下：**留下当前这块会让 `last` 变大，后面岩石与 `last` 的差就变小，不是更难留吗？** 所以"能留就留"并不是显然正确的，它需要一个交换论证：贪心留下的第 $i$ 块位置，总是**不晚于**任何合法方案留下的第 $i$ 块位置（因为贪心每次都挑"最靠左的可行位置"），于是贪心永远不会比别人先"用完"岩石。归纳可证贪心留下的块数最多，即删除数最少。这条证明我放在第二部分引理 3。

**第四步：本题真正的坑——终点不能移走。** 扫完 $N$ 块岩石后，还要检查最后一跳 $L-\texttt{last}$。如果它 $<x$ 怎么办？终点是**不能删**的，所以只能回头删掉 `last` 那块岩石；删掉之后新的最后一块是 `prev`，还要再检查 $L-\texttt{prev}$……看起来可能连锁回退，写起来很烦。

于是我想到一个偷懒写法：**把终点 $L$ 也当成一块岩石放进数组一起扫**，间距不够就 `cnt++`（相当于"把终点移走"）。这明显违反题意，我一开始认定它是错的。但仔细一想又觉得不对：

> 贪心留下的相邻两块间距**一定 $\ge x$**（这是贪心的规则）。所以如果 $L-\texttt{last}<x$，把 `last` 删掉换成"删终点"的计数，新的最后一跳是
> $$L-\texttt{prev}=(L-\texttt{last})+(\texttt{last}-\texttt{prev})\ge 0+x=x,$$
> **一次就够，绝不会连锁回退！**

也就是说，"删终点"这个非法操作，可以**一对一地换成"删最后一块留下的岩石"**，删除总数不变，结果却完全合法。反过来，任何合法方案也是"终点可删"这个松弛问题的方案，所以松弛问题的最优值不会比原问题更差。两边一夹，**两个问题的最小删除数完全相等**，偷懒写法是对的。

这是全题最漂亮的一步：先把约束**松弛**掉得到一个更好写的问题，再证明松弛不改变最优值。第二部分引理 4、5 给完整证明。

**第五步：二分的写法细节。** 找"最大可行值"要用**偏上界**的 mid：`mid=(l+r+1)>>1`，可行则 `l=mid`，否则 `r=mid-1`。若写成 `mid=(l+r)>>1` 配 `l=mid`，在 `l+1==r` 时会死循环。另外核算溢出：$l+r+1\le 2\times 10^9+1=2000000001<2^{31}-1=2147483647$，`int` 安全（这是本题唯一一个"差一点就溢出"的地方）。

**第六步：复杂度。** 每次 `check` 扫 $N+1$ 个位置，$O(N)$；二分 $O(\log L)\approx 30$ 次；总 $O(N\log L)\approx 1.5\times 10^6$，远低于限制。空间 $O(N)$。

**手造 / 反推数据核对：**

| 输入 | 手算 | 程序 |
|---|---|---|
| `25 5 2` / `2 11 14 17 21`（按说明反推） | 留 $11,17,21$：间距 $11,6,4,4$ ⇒ $4$ | $4$ ✓ |
| `10 0 0`（没有岩石） | 一跳 $10$ | $10$ ✓ |
| `10 2 2` / `3 7`（全删） | 一跳 $10$ | $10$ ✓ |
| `10 2 0` / `3 7`（不能删） | $\min(3,4,3)=3$ | $3$ ✓ |
| `10 2 1` / `6 7` | 删 $7$：$6,4$ ⇒ $4$ | $4$ ✓ |
| `20 2 1` / `5 16`（**终点回退案例**） | 删 $16$：$5,15$ ⇒ $5$ | $5$ ✓ |
| `10 3 2` / `4 5 6` | 删 $4,6$：$5,5$ ⇒ $5$ | $5$ ✓ |
| `1 0 0` | $L=1$ | $1$ ✓ |
| `1000000000 0 0` | $L=10^9$ | $10^9$ ✓ |
| `10 4 1/2/3` / `2 4 6 8` | $2,2,4$（打掉"删最小间距"贪心） | $2,2,4$ ✓ |

第六组专门打第四步那个引理：$x=5$ 时贪心留下 $5$ 和 $16$，最后一跳 $20-16=4<5$，"删终点"计 $1$；真实做法是删 $16$，也计 $1$，剩下 $0\to5\to20$ 间距 $5,15$，完全合法。

## 二、思维链：完整证明

### 记号

- 位置序列 $p_0=0<p_1<\dots<p_N<p_{N+1}=L$，其中 $p_i=D_i\ (1\le i\le N)$，全部为互不相同的整数。
- 内部点集 $R=\{p_1,\dots,p_N\}$，$|R|=N$；**松弛点集** $P=R\cup\{L\}$，$|P|=N+1$。
- 对 $T\subseteq P$，把 $\{0\}\cup T$ 升序排列得 $0=u_0<u_1<\dots<u_k$。称 $T$ 为 **$x$-可行**，若所有相邻差 $u_{i+1}-u_i\ge x$（$i=0..k-1$）。注意松弛定义**不要求 $L\in T$**。
- 原问题的最小删除数 $r(x)=\min\{|R\setminus T|:\ T\subseteq P,\ L\in T,\ T\text{ 是 }x\text{-可行}\}$。
- 松弛问题的最小删除数 $r'(x)=\min\{|P\setminus T|:\ T\subseteq P,\ T\text{ 是 }x\text{-可行}\}$。
- 贪心保留集 $G$：`last=0`，按升序扫 $P$，若 $p-\texttt{last}\ge x$ 则保留并令 $\texttt{last}=p$，否则丢弃。$\texttt{cnt}=|P\setminus G|$。

---

### 引理 1（问题等价刻画与判定单调性）

题目所求 $\text{ans}=\max\{x\in\mathbb Z_{\ge 1}:\ r(x)\le M\}$，且谓词 $[r(x)\le M]$ 关于 $x$ 单调不增（$x$ 可行 $\Rightarrow$ 任何 $x'\le x$ 可行）。

*证明*：**等价刻画。** 一个比赛方案由"移走哪些内部岩石"唯一决定，即一个删集 $A\subseteq R$，$|A|\le M$；剩余序列是 $\{0\}\cup(R\setminus A)\cup\{L\}$，最短一跳 $g(A)=\min$ 相邻差。令 $T=(R\setminus A)\cup\{L\}\subseteq P$，则 $L\in T$、$|P\setminus T|=|R\setminus(R\setminus A)|=|A|$，且 $T$ 的相邻差就是剩余序列的相邻差。故

$$g(A)\ge x\iff T\text{ 是 }x\text{-可行},\qquad |A|\le M\iff |P\setminus T|\le M.$$

于是"$\exists A,|A|\le M,g(A)\ge x$" $\iff$ "$\exists T\subseteq P,L\in T,|P\setminus T|\le M,T$ 是 $x$-可行" $\iff r(x)\le M$。因此 $\text{ans}=\max_A g(A)=\max\{x:r(x)\le M\}$（$g(A)$ 是正整数，最大值存在）。

**单调性。** 设 $r(x)\le M$，取达到最小的 $T$。对 $x'\le x$，$T$ 的所有相邻差 $\ge x\ge x'$，故 $T$ 也是 $x'$-可行，$r(x')\le|P\setminus T|=r(x)\le M$。证毕。

**推论**：可行 $x$ 的集合是 $\{1,2,\dots,\text{ans}\}$ 这样一个前缀区间（引理 2 保证 $\text{ans}\ge1$），二分答案合法。

---

### 引理 2（答案范围：$1\le\text{ans}\le L$）

*证明*：**下界。** 取 $A=\varnothing$（$M\ge 0$ 允许）。剩余序列就是 $p_0<p_1<\dots<p_{N+1}$，每个相邻差是两个**互不相同的整数**之差，故 $\ge 1$。于是 $g(\varnothing)\ge 1$，$\text{ans}\ge 1$。（$N=0$ 时序列只有 $0,L$，差为 $L\ge 1$，同样成立。）

**上界。** 任何方案的剩余序列至少含一跳（起点 $\ne$ 终点，$L\ge 1$），所有跳长度为正整数且总和为 $L$，故每一跳 $\le L$，最小跳 $\le L$。取最大值得 $\text{ans}\le L$。证毕。

**推论**：二分区间 $[1,L]$ 一定包含答案；特别地 `check(1)` 恒真、`check(L)` 可能真（$M=N$ 时全删，一跳 $L$）。

---

### 引理 3（贪心最大化保留数：$\texttt{cnt}=r'(x)$）

设 $G$ 为贪心保留集，$k=|G|$。则对任意 $x$-可行的 $T\subseteq P$ 有 $|T|\le k$。因此 $k=\max\{|T|:T\text{ 是 }x\text{-可行}\}$，$\texttt{cnt}=|P|-k=r'(x)$。

*证明*：设 $G=\{g_1<g_2<\dots<g_k\}$，$T=\{t_1<t_2<\dots<t_m\}$ 是任意 $x$-可行集。

**断言**：对每个 $i\le\min(k,m)$ 有 $g_i\le t_i$；并且若 $m>k$ 则贪心还会保留第 $k+1$ 个元素（与 $|G|=k$ 矛盾）。

对 $i$ 归纳。

*$i=1$*：贪心初始 `last=0`，保留的第一个位置是 $P$ 中满足 $p-0\ge x$ 的**最小**者，即 $g_1=\min\{p\in P:p\ge x\}$（若该集合为空则 $k=0$，此时任何 $T$ 也必须为空，因为 $t_1\ge x$ 且 $t_1\in P$，矛盾，故 $m=0$，结论平凡）。由 $T$ 的 $x$-可行性，$t_1-0\ge x$，即 $t_1\in\{p\in P:p\ge x\}$，故 $g_1\le t_1$ ✓。

*归纳步*：设 $g_i\le t_i$ 且 $i<m$。贪心保留 $g_i$ 后 `last`$=g_i$，继续向后扫，保留的下一个位置是
$$g_{i+1}=\min\{p\in P:\ p>g_i,\ p-g_i\ge x\}=\min\{p\in P:\ p\ge g_i+x\}$$
（$p\ge g_i+x>g_i$ 自动保证 $p>g_i$；若集合为空则贪心停止，$k=i$）。另一方面，由 $T$ 的可行性 $t_{i+1}-t_i\ge x$，结合归纳假设：
$$t_{i+1}\ge t_i+x\ge g_i+x,$$
且 $t_{i+1}\in P$。故 $\{p\in P:p\ge g_i+x\}$ **非空**（含 $t_{i+1}$），贪心必然会保留某个 $g_{i+1}\le t_{i+1}$ ✓，且 $k\ge i+1$。

由归纳，只要 $i<m$ 就有 $k\ge i+1$；取 $i=m-1$ 得 $k\ge m$。故 $|T|=m\le k=|G|$。

既然 $G$ 本身是 $x$-可行的（贪心规则直接保证：每次保留时 $p-\texttt{last}\ge x$，而 `last` 正是上一个保留位置；首个保留位置与 $0$ 的差也 $\ge x$），$k$ 就是最大保留数。于是最小删除数 $r'(x)=|P|-k=\texttt{cnt}$。证毕。

**注（为什么"能留就留"不是显然的）**：留下当前岩石会使 `last` 变大，让**紧邻的下一块**更难留。上面的归纳绕开了这个局部困难：它比较的不是"下一步好不好走"，而是"第 $i$ 个保留位置的绝对坐标"。贪心把每个保留位置都压到最左，从而在**全局**上不劣于任何方案。这正是交换论证的标准形态。

---

### 引理 4（终点松弛不改变最优值：$r(x)=r'(x)$，$1\le x\le L$）

*证明*：分两个方向。

**（$r'\le r$）** 任何满足"$L\in T$ 且 $x$-可行"的 $T$ 也是松弛问题的可行解（松弛只去掉了 $L\in T$ 的要求）。在更大集合上取最小值不会更大，故 $r'(x)\le r(x)$。

**（$r\le r'$）** 取贪心保留集 $G$，由引理 3，$|G|=|P|-r'(x)$。分两种情形。

*情形 A：$L\in G$。* 则 $G$ 本身就是原问题的可行解（含 $L$、$x$-可行），故
$$r(x)\le|P\setminus G|=r'(x).$$

*情形 B：$L\notin G$。* 首先 $G\ne\varnothing$：若 $G=\varnothing$，则 `last` 始终为 $0$，扫到 $L$ 时 $L-0=L\ge x$（因 $x\le L$），贪心会保留 $L$，与 $L\notin G$ 矛盾。故可令 $\texttt{last}=\max G>0$，$\texttt{prev}=\max\bigl((G\setminus\{\texttt{last}\})\cup\{0\}\bigr)$。

由贪心规则，保留 `last` 时必有 $\texttt{last}-\texttt{prev}\ge x$。由 $L\notin G$ 且 $L$ 是 $P$ 的最大元（最后被扫到），必有 $L-\texttt{last}<x$。

构造 $G'=(G\setminus\{\texttt{last}\})\cup\{L\}$。则：
1. $|G'|=|G|$（删一个加一个，且 $L\notin G$ 保证不重复）；
2. $L\in G'$；
3. $G'$ 是 $x$-可行的：$G\setminus\{\texttt{last}\}$ 内部的相邻差与 $G$ 中一样（删掉最大元不影响前面的差），全部 $\ge x$；新增的最后一跳为
$$L-\texttt{prev}=(L-\texttt{last})+(\texttt{last}-\texttt{prev})>0+x\ge x$$
（$L>\texttt{last}$ 因位置互异，$\texttt{last}-\texttt{prev}\ge x$ 由贪心规则）；若 $G\setminus\{\texttt{last}\}=\varnothing$ 则 $\texttt{prev}=0$，最后一跳为 $L\ge x$ ✓。

故 $G'$ 是原问题的可行解，$r(x)\le|P\setminus G'|=|P\setminus G|=r'(x)$。

两情形都得 $r\le r'$，与第一方向合并得 $r(x)=r'(x)$。证毕。

**这条引理的实际含义**：代码里"把终点当成可移走的岩石一起扫"是**合法的实现技巧**，不是 bug。它计的那一次"删终点"，总能一对一地换成"删最后一块保留的岩石"，而且**只需要换一次**（不会连锁回退），因为贪心保证 $\texttt{last}-\texttt{prev}\ge x$。

### 引理 5（`check(x)` 的返回值就是可行性）

代码 `check(x)` 返回 `true` $\iff r(x)\le M\iff x$ 可行（引理 1 意义下）。

*证明*：代码把 $d[0..n-1]$ 存 $N$ 块岩石、$d[n]=L$，按升序扫 $i=0..n$，正是引理 3 的贪心（`last` 初值 $0$，间距 $<x$ 则 `++cnt`，否则 `last=d[i]`）。故循环正常结束时 $\texttt{cnt}=|P\setminus G|=r'(x)$，由引理 4 等于 $r(x)$。

代码在 `++cnt>m` 时立即 `return false`。由于 `cnt` 单调不减，提前退出时的 `cnt` 已 $>M$，完整扫描的 `cnt` 也 $>M$，故提前退出不改变返回值：返回 `false` $\iff r(x)>M$，返回 `true` $\iff r(x)\le M$。再由引理 1，这就是"$x$ 可行"。证毕。

---

### 引理 6（二分的循环不变量与终止）

代码 `l=1,r=L`；当 `l<r` 时取 `mid=(l+r+1)>>1`，`check(mid)` 真则 `l=mid`，否则 `r=mid-1`。循环结束时 `l==r==ans`。

*证明*：**不变量** $l\le\text{ans}\le r$。初始由引理 2 成立。

设某轮开始时不变量成立且 $l<r$。则 $l+r+1\le 2r$，$\text{mid}=\lfloor(l+r+1)/2\rfloor$ 满足 $l<\text{mid}\le r$（因 $l<r\Rightarrow l+r+1\ge 2l+2\Rightarrow\text{mid}\ge l+1$；$l+r+1\le 2r\Rightarrow\text{mid}\le r$）。

- 若 `check(mid)` 真：由引理 5 与引理 1 的单调性，$\text{ans}\ge\text{mid}$，令 $l=\text{mid}$ 后 $l\le\text{ans}$ 仍成立，$r$ 不变故 $\text{ans}\le r$ ✓。新区间长度 $r-\text{mid}<r-l$（因 $\text{mid}>l$）。
- 若假：$\text{ans}<\text{mid}$，整数故 $\text{ans}\le\text{mid}-1$，令 $r=\text{mid}-1$ 后不变量保持 ✓。新区间长度 $\text{mid}-1-l<r-l$（因 $\text{mid}\le r$）。

每轮区间长度严格减小且非负，故有限步内终止于 $l=r$；由不变量 $l\le\text{ans}\le r=l$，得 $\text{ans}=l$。证毕。

**为什么必须偏上界取 mid**：若用 $\text{mid}=\lfloor(l+r)/2\rfloor$ 配 `l=mid`，当 $r=l+1$ 时 $\text{mid}=l$，`check` 真则 `l=mid=l`，区间不变，**死循环**。偏上界保证 $\text{mid}>l$，区间必然收缩。

---

### 引理 7（值域与溢出）

所有位置差 $\le L\le 10^9$，`cnt` $\le N+1\le 50001$，二分中 $l+r+1\le 2\times 10^9+1<2^{31}-1$，故全程 `int` 安全。

*证明*：$0\le d[i]\le L\le 10^9$，`last` 也是某个 $d[i]$ 或 $0$，故 $d[i]-\texttt{last}\in[0,10^9]$（升序保证非负），`int` 上限 $2.147\times 10^9$ 足够。`cnt` 每轮至多加 $1$，共 $N+1\le 50001$ 轮 ✓。$l,r\in[1,L]$，故 $l+r+1\le 2L+1=2000000001<2147483647$ ✓（**这是本题唯一逼近 `int` 上限的表达式**，若 $L$ 再大一点就必须换 `long long` 或写成 `l+(r-l+1)/2`）。数组 `d` 需要 $N+1\le 50001$ 个 `int`，`mxn{50005}` 足够。证毕。

---

### 引理 8（复杂度）

时间 $O(N\log L)$，空间 $O(N)$。

*证明*：`check` 扫 $N+1$ 个位置，每个 $O(1)$，故 $O(N)$（提前退出只会更快）。二分区间 $[1,L]$ 每轮长度至少减半（$\text{mid}$ 取中点附近），故轮数 $\le\lceil\log_2 L\rceil+1\le 31$。总时间 $O(N\log L)$，代入 $N=5\times 10^4,L=10^9$ 得约 $1.55\times 10^6$ 次基本操作。空间：`d` 数组 $50005$ 个 `int` $\approx 200$ KB，其余 $O(1)$。证毕。

---

### 定理

程序输出"至多移走 $M$ 块岩石后最短跳跃距离的最大值"，时间 $O(N\log L)$，空间 $O(N)$。

*证明*：引理 1 把题目化为 $\max\{x:r(x)\le M\}$ 并给出单调性；引理 2 给出二分区间 $[1,L]$；引理 3 证明贪心计数 $=r'(x)$；引理 4 证明 $r'(x)=r(x)$（终点松弛合法）；引理 5 证明 `check` 正确；引理 6 证明二分收敛到 $\text{ans}$；引理 7 保证 `int` 不溢出；引理 8 给出复杂度。证毕。

### 附：一个等价但更啰嗦的写法（对照用）

如果不愿意用"终点可删"的松弛，可以显式处理最后一跳：扫完 $N$ 块后若 $L-\texttt{last}<x$，则 `cnt++` 并把 `last` 回退到上一块保留的岩石。引理 4 情形 B 的计算表明**回退一次就够**（$L-\texttt{prev}\ge x$），所以这个写法与松弛写法的 `cnt` 完全相同。但它需要额外记录"上一块保留位置"，代码更长、更容易写错——这正是"先松弛再证等价"的价值。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 移走岩石 = 从递增位置序列里删内部点；目标 = 最大化相邻差的最小值；删一个点会**合并**两个间距，影响全局。
- **consider easier version** — 先试"删掉最小的 $M$ 个间距"这种局部贪心，$L=10,D=[2,4,6,8]$ 时 $M=1,2,3$ 的答案 $2,2,4$ 说明它不成立。
- **classic problem solution** — "最大化最小值" ⇒ 二分答案，把最优化问题转成判定问题 $\texttt{check}(x)$。
- **explore its property** — 判定单调性：$x$ 可行 ⇒ 更小 $x$ 可行（同一套删法），可行集是前缀区间。
- **classic problem solution** — 判定用贪心：从左扫，间距 $<x$ 就删当前，否则留下（能留就留）。
- **explore its property** — 贪心正确性不显然（留下当前会让 `last` 变大），靠"第 $i$ 个保留位置尽量靠左"的归纳交换论证证明保留数最多。
- **reduce to easier problem** — 终点不可删的约束先**松弛**成"终点也可删"，再证两者最小删除数相等：把最后一块保留岩石换成终点，基数不变且一次就够（$\texttt{last}-\texttt{prev}\ge x$）。
- **discuss by category** — 二分边界 $[1,L]$、偏上界 mid 防死循环、$l+r+1\le 2\times 10^9+1$ 的溢出核算；$N=0/M=0/M=N$ 退化情形。
- **classic problem solution** — 总复杂度 $O(N\log L)\approx 1.5\times 10^6$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `L` | 起点到终点距离（$\le 10^9$） | `int`，读入 | 也是二分右端点 |
| `n` | 中间岩石数（$\le 5\times 10^4$） | `int`，读入 | 可为 $0$ |
| `m` | 至多移走块数（$\le n$） | `int`，读入 | 判定的预算 |
| `d[i]` | 第 $i$ 个位置（0-based） | `int[mxn]`，读入 | **`d[n]=L`**：终点一起扫 |
| `mxn` | $50000+5$ | `constexpr int` | 要装下 $N+1$ 个位置 |
| `check(x)` | 阈值 $x$ 是否可行 | `bool(int)` | 返回 `cnt<=m` |
| `last` | 上一块**留下**的位置 | `int`，初值 $0$（起点） | 起点不能删，永远是第一个 `last` |
| `cnt` | 贪心计数（松弛问题的删除数） | `int`，初值 $0$ | 由引理 4 等于真实删除数 |
| `l,r` | 二分区间（闭） | `int`，初值 $1,L$ | 不变量 `l<=ans<=r` |
| `mid` | 偏上界中点 `(l+r+1)>>1` | `int` | 找最大可行值必须偏上 |

### 算法步骤

1. I/O 加速三行（固定顺序）。
2. 读 `L,n,m`；读 `d[0..n-1]`；令 `d[n]=L`。
3. 二分：`l=1,r=L`；当 `l<r`：`mid=(l+r+1)>>1`；`check(mid)` 真则 `l=mid`，否则 `r=mid-1`。
4. `check(x)`：`cnt=0,last=0`；对 `i=0..n`：若 `d[i]-last<x` 则 `++cnt`（超过 `m` 立即返回 `false`），否则 `last=d[i]`；扫完返回 `true`。
5. 输出 `l` 与 `'\n'`。

### 复杂度

- 时间：$O(N\log L)$，$N=5\times 10^4,L=10^9$ 时约 $1.5\times 10^6$ 次操作。
- 空间：$O(N)$，`d` 数组约 $200$ KB。
- 值域：位置差 $\le 10^9$；$l+r+1\le 2000000001<$ `INT_MAX`（引理 7）。

### 验证状态

`g++ -std=c++20 -O2 -Wall -Wextra` 编译通过、无警告。按样例说明反推的 $L=25,N=5,M=2$ 数据输出 $4$，与说明逐条吻合；另造 $9$ 组手工数据（$N=0$、$M=0$、$M=N$、$L=1$、$L=10^9$、终点回退案例 `20 2 1 / 5 16`、局部贪心反例 `10 4 M / 2 4 6 8`）全部与手算一致。因"终点可删松弛"这条性质较隐蔽，另做了一轮**轻量验证**：$400$ 组随机小数据（$N\le 8$，$L\le N+25$，$M$ 随机）与"枚举全部 $2^N$ 种删法、逐一算最小间距取最大"的暴力端到端比对，$0$ mismatch（脚本为临时文件，未建 appendix）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2678 [NOIP 2015 提高组] 跳石头
// 思路：二分最短跳跃距离 x，贪心判定：从起点扫，间距 <x 的岩石移走，否则留下。
//       终点 L 也放进数组一起扫（当作可移走），可以证明这与"终点不可移走"等价：
//       若终点被"移走"，改成移走最后一块留下的岩石即可，前一块留下的岩石距它 >=x。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005};

int L,n,m,d[mxn];

bool check(int x)	// 至多移走 m 块，能否让所有相邻间距都 >=x
{
	int cnt=0,last=0;
	for(int i=0;i<=n;++i)	// d[n]=L，终点一起扫
	{
		if(d[i]-last<x)
		{
			if(++cnt>m)
				return false;
		}
		else
			last=d[i];
	}
	return true;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>L>>n>>m;
	for(int i=0;i<n;++i)
		cin>>d[i];
	d[n]=L;
	int l=1,r=L;	// 位置互不相同的整数 ⇒ 不移走任何岩石时最短间距 >=1，故答案 >=1
	for(;l<r;)
	{
		int mid=(l+r+1)>>1;	// 偏上界取 mid，找最大可行值；l+r+1<=2e9+1 不溢出
		if(check(mid))
			l=mid;
		else
			r=mid-1;
	}
	cout<<l<<'\n';
	return 0;
}
```

### 代码说明

- **`d[n]=L` 是全题的关键一行**：把终点纳入扫描，`check` 就不需要任何"最后一跳"的特判。它的合法性由引理 4 保证（"删终点"可一对一换成"删最后一块保留岩石"，且只换一次）。
- **`i<=n` 而不是 `i<n`**：循环必须扫到终点，否则最后一跳没人检查，答案会偏大。
- **`last` 初值 $0$**：起点是不能删的，它永远是第一个参照点；`cnt` 只统计 $P$ 中被丢弃的元素，起点不在 $P$ 里，不会被误计。
- **`++cnt>m` 立即返回**：`cnt` 单调不减，提前退出不影响正确性，还能在不可行时省时间。
- **偏上界 `mid=(l+r+1)>>1`**：找"最大可行值"必须让 `mid>l`，否则 `l=mid` 会死循环。
- **`int` 够用但很紧**：$l+r+1\le 2\times 10^9+1$，距 `INT_MAX` 只剩 $1.47\times 10^8$；若题目把 $L$ 放大到 $2\times 10^9$ 就必须改 `l+(r-l+1)/2` 或用 `i64`。
- **`mxn{50005}`**：要装 $N+1=50001$ 个位置，$+5$ 松弛后足够；`d[n]` 不越界。
- 全程无递归、无额外数据结构，$O(N\log L)$ 时间、$O(N)$ 空间。
