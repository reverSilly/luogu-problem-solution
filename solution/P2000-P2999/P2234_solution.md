# P2234 [HNOI2002] 营业额统计 — 题解

## 一、解题过程：人类思考叙事

先重述题意。给出 $n$ 天的营业额 $a_1,\dots,a_n$（$n\le32767$，$|a_i|\le10^6$，可为负）。定义第 $i$ 天的"最小波动值"为

$$\min_{1\le j<i}|a_i-a_j|,$$

特别地，第一天的最小波动值是 $a_1$ 本身（不是 $|a_1|$）。求所有天的最小波动值之和。

最直接的做法是两层循环：对每天 $i$，扫一遍前面所有天算最小差。复杂度 $O(n^2)$，$n=32767$ 时约 $5.4\times10^8$ 次比较，很悬。需要把"在前 $i-1$ 个数里找离 $a_i$ 最近的那个"这件事做快。

问题抽象出来是：**维护一个动态集合 $S$（前 $i-1$ 天的营业额），每次询问 $\min_{v\in S}|x-v|$。**

先想清楚这个最小值会落在哪里。把 $S$ 里的数排好序，$x$ 落在数轴的某个位置：

- 所有小于等于 $x$ 的数里，越靠近 $x$ 的差越小，所以最优的是**小于等于 $x$ 的最大值**，也就是 $x$ 的**前驱**；
- 所有大于等于 $x$ 的数里，越靠近 $x$ 的差越小，所以最优的是**大于等于 $x$ 的最小值**，也就是 $x$ 的**后继**。

不在前驱和后继里的数，要么比前驱更小（离 $x$ 更远），要么比后继更大（也离 $x$ 更远）。所以答案只能是"前驱距离"或"后继距离"中的一个。这个观察把"在 $i-1$ 个数里找最小"压缩成了"在有序集合里定位 $x$ 的左右邻居"。

于是自然想到用 `std::set`：它天然有序，支持插入和 `lower_bound`（第一个 $\ge x$ 的位置，即后继），前驱用 `prev` 拿（迭代器前移一位就是小于 $x$ 的最大值）。每天先查询、再把 $a_i$ 插入集合。

几个必须注意的细节：

1. **先查后插**。如果把 $a_i$ 先插进去再查，`lower_bound` 会直接命中自己，答案永远是 $0$，完全错误。
2. **第一天特判**。集合是空的，直接把 $a_1$ 计入答案并插入，不做查询。
3. **迭代器边界**。`lower_bound` 可能返回 `end()`（没有后继），此时只能看前驱；如果它恰好是 `begin()`（没有前驱），只能看后继。两边都比较时要先判存在。
4. **重复值**。`set` 会去重。这不影响正确性：若之前出现过 $a_i$，`lower_bound` 命中相等的值，距离 $0$，就是正确答案；去重只是少存了几个副本。
5. **答案可能为负**。第一天的贡献是 $a_1$ 本身，$a_1$ 可以是负数，所以累加器不能从 $0$ 开始"只加非负数"，也不能把中间结果夹到 $0$。用 64 位整数累加即可（题面保证最终结果小于 $2^{31}$，但用 `long long` 更稳）。

用题面 Hint 自检：营业额 $5,1,2,5,4,6$。

- 第 1 天：$+5$，集合 $\{5\}$；
- 第 2 天 $1$：前驱无、后继 $5$，$|1-5|=4$；
- 第 3 天 $2$：前驱 $1$、后继 $5$，取 $1$；
- 第 4 天 $5$：命中 $5$，取 $0$；
- 第 5 天 $4$：前驱 $2$、后继 $5$，取 $1$；
- 第 6 天 $6$：前驱 $5$，取 $1$。

总和 $5+4+1+0+1+1=12$，与 Hint 一致。

## 二、思维链：完整证明

**引理 1（最近邻必是前驱或后继）**：设 $S$ 是非空有限整数集，$x$ 为整数。令
$$p=\max\{v\in S: v\le x\},\qquad q=\min\{v\in S: v\ge x\},$$
（若相应集合为空则记 $p$ 或 $q$ 不存在）。则
$$\min_{v\in S}|x-v|=\min\big(\{|x-p|:p\text{ 存在}\}\cup\{|x-q|:q\text{ 存在}\}\big).$$

*证明*：任取 $v\in S$。
若 $v<x$：则 $v\le x$，故 $v\le p$（$p$ 是这类数的最大值），于是 $|x-v|=x-v\ge x-p=|x-p|$。
若 $v>x$：则 $v\ge x$，故 $v\ge q$，于是 $|x-v|=v-x\ge q-x=|x-q|$。
若 $v=x$：则 $v$ 同时属于两类，$p=q=x$，$|x-v|=0=|x-p|$。
所以每个 $v$ 的距离都不小于 $p$ 或 $q$ 中某个候选的距离；而 $p,q\in S$（若存在）本身是合法候选。故最小值等于候选集的最小值。证毕。

**引理 2（去重不改变最小值）**：设 $S'$ 是把 $S$ 中重复元素删到只剩一个后得到的集合（即 $S$ 的支撑集），则对任意 $x$，
$$\min_{v\in S}|x-v|=\min_{v\in S'}|x-v| .$$

*证明*：$S'\subseteq S$，对更大的集合取最小只会更小，故 $\min_S\le\min_{S'}$。另一方面，任取 $v\in S$，由于 $S'$ 保留了 $S$ 中每一个出现过的取值，必存在 $v'\in S'$ 使 $v'=v$，于是 $|x-v|=|x-v'|\ge\min_{S'}$。对 $v$ 取最小得 $\min_S\ge\min_{S'}$。两方向合起来相等。证毕。

**引理 3（集合不变式）**：设处理完第 $i$ 天后集合为 $S_i$，则 $S_i=\{a_1,\dots,a_i\}$（作为集合，忽略重复）。

*证明*：对 $i$ 归纳。$i=1$ 时程序把 $a_1$ 插入空集，$S_1=\{a_1\}$。设 $S_{i-1}=\{a_1,\dots,a_{i-1}\}$，第 $i$ 天查询后插入 $a_i$，得 $S_i=\{a_1,\dots,a_{i-1}\}\cup\{a_i\}=\{a_1,\dots,a_i\}$。证毕。

**引理 4（第 $i$ 天的计算值等于定义值，$i\ge2$）**：设第 $i$ 天查询时 `lower_bound(a_i)` 得到迭代器 `it`。则
- 若 `it!=end()`，则 `*it` 是 $a_i$ 的后继 $q$；
- 若 `it!=begin()`，则 `*prev(it)` 是 $a_i$ 的前驱 $p$；
程序取的 $\min(\texttt{*it}-a_i,\ a_i-\texttt{*prev(it)})$（缺项则只取存在项）恰为 $\min_{j<i}|a_i-a_j|$。

*证明*：`std::set` 的迭代器按升序排列，`lower_bound(x)` 返回第一个 $\ge x$ 的元素，正是 $q$；若它等于 `begin()`，说明没有元素 $<x$，即前驱不存在，否则 `prev` 给出 $<x$ 的最大元素，正是 $p$。第 $i$ 天查询前集合为 $S_{i-1}=\{a_1,\dots,a_{i-1}\}$（引理 3），非空（$i\ge2$ 时至少含 $a_1$），故至少存在一个候选。由引理 1，取两者最小即得 $\min_{j<i}|a_i-a_j|$。证毕。

**引理 5（第一天）**：第一天的贡献按题目规定为 $a_1$，程序在 $i=0$ 时直接执行 `ans+=a`，正确。

*证明*：直接对应题面"第一天的最小波动值为第一天的营业额"。证毕。

**引理 6（总和正确）**：程序最终输出的 `ans` 等于 $\sum_{i=1}^{n}\text{fluc}_i$，其中 $\text{fluc}_1=a_1$，$\text{fluc}_i=\min_{j<i}|a_i-a_j|$。

*证明*：程序在第 1 天加 $a_1$（引理 5），在第 $i\ge2$ 天加引理 4 算出的 $\text{fluc}_i$，逐日累加即得。证毕。

**定理**：程序输出题面所求的答案。

*证明*：由引理 6，输出等于定义的和；题面保证该和小于 $2^{31}$，程序用 `long long` 累加不会溢出。证毕。

**引理 7（复杂度）**：时间 $O(n\log n)$，空间 $O(n)$。

*证明*：每天一次 `lower_bound` 与至多一次 `prev` 及一次 `insert`，`std::set` 的每次操作 $O(\log n)$，共 $O(n\log n)$。集合最多存 $n$ 个不同值，空间 $O(n)$。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 一维最近邻问题：最小值必在有序集合的前驱或后继处取得。
- consider easier version — 若已有前 $i-1$ 天的有序表，单次查询只需 $O(\log n)$，问题变成"增量维护有序表"。
- classic problem solution — `std::set` + `lower_bound` 取后继、`prev` 取前驱。
- discuss by category — 第一天特判加 $a_1$；迭代器到 `end()` 只看前驱、到 `begin()` 只看后继；重复值命中得 $0$。
- engineering pitfall — 必须先查询再插入，否则命中自己恒为 $0$；答案可为负，累加器用 64 位且不夹零。
- complexity check — $O(n\log n)$，$n\le32767$ 轻松通过。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 天数 | 输入 |
| $a$ | 当天的营业额（边读边处理） | 读入 |
| `s` | 已出现过的营业额集合（有序、去重） | 空 |
| `it` | `s.lower_bound(a)`，指向后继 | 每次查询重算 |
| `best` | 当天的最小波动值 | 每天置 `1145141919` |
| $ans$ | 波动值总和 | 初值 $0$，类型 `long long` |

### 算法步骤

1. I/O 加速三连；读入 $n$。
2. 对 $i=0\dots n-1$：
   1. 读入 $a$；
   2. 若 $i=0$：$ans\mathrel{+}=a$，`s.insert(a)`，进入下一天；
   3. `it=s.lower_bound(a)`，`best=1145141919`；
   4. 若 `it!=s.end()`，`best=*it-a`；
   5. 若 `it!=s.begin()`，`best=min(best,a-*prev(it))`；
   6. $ans\mathrel{+}=best$；`s.insert(a)`。
3. 输出 $ans$。

### 复杂度

- 时间：$O(n\log n)$。
- 空间：$O(n)$。

### 一句话验证状态

Hint 数据 $5,1,2,5,4,6$ 输出 $12$；与 $O(n^2)$ 暴力在 500 组随机小数据（含负数、重复值）上完全一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2234 [HNOI2002] 营业额统计
// 每天在有序集合里找 a 的前驱/后继，取较近者；第一天直接加 a
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int n;
set<int>s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	i64 ans=0;
	for(int i=0,a,best;i<n;++i)
	{
		cin>>a;
		if(i==0)
		{
			ans+=a;   // 第一天的最小波动值就是当天的营业额（可为负）
			s.insert(a);
			continue;
		}
		auto it=s.lower_bound(a);   // 第一个 >= a，即后继
		best=1145141919;
		if(it!=s.end())
			best=*it-a;
		if(it!=s.begin())
			best=min(best,a-*prev(it));   // 前驱
		ans+=best;
		s.insert(a);   // 先查后插
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `lower_bound(a)` 给出后继（$\ge a$），`prev(it)` 给出前驱（$<a$）；两边取距离最小，正是引理 1。
- 先计算 `best` 再 `insert(a)`，避免"命中自己"。
- `best` 的初值用 `1145141919` 表示"暂时没有候选"；由于 $i\ge2$ 时集合非空，至少有一边存在，`best` 一定被更新。
- `ans` 用 `long long`：单日波动可达 $2\times10^6$，$n$ 项和可能超过 `int`（虽然题面保证小于 $2^{31}$，但不依赖它）；且第一天可能为负，不能初始化为"负无穷"再取 max 之类的写法。
- `set` 去重不影响答案：若存在相等的旧值，`lower_bound` 直接命中，距离 $0$。

### 验证状态

- 编译：`g++ -std=c++20 -O2 -Wall -Wextra` 无错误、无警告。
- Hint 数据 $n=6,a=\{5,1,2,5,4,6\}$ 输出 $12$，与题面一致；$n=1,a=\{-5\}$ 输出 $-5$。
- 对拍：$n\le10$、$a_i\in[-10,10]$（大量重复值）的 500 组随机数据，与 $O(n^2)$ 暴力完全一致。
