# P2659 美丽的序列 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给定长度 $n$ 的序列 $a_1,\dots,a_n$（$1\le n\le2\times10^6$，$0\le a_i\le2\times10^6$）。一个区间 $[l,r]$ 的"美丽度" $=$ 区间长度 $\times$ 区间最小值 $=(r-l+1)\cdot\min_{l\le t\le r}a_t$。求所有区间美丽度的最大值（"美丽系数"）。题面样例解释里"选 $[2,3]$ 得 $2\times2=4$"提示序列含重复元素。

**第一反应：枚举区间。** 固定 $l$，右移 $r$ 并维护 running min，$O(n^2)$。但 $n=2\times10^6$，$n^2=4\times10^{12}$，远超时限。$60\%$ 数据 $n\le2\times10^5$ 时 $O(n^2)$ 也才 $4\times10^{10}$，同样不行。必须 $O(n)$ 或 $O(n\log n)$。题面还专门提示"你可能需要一个读入优化"——$2\times10^6$ 个数的读入本身就是瓶颈之一。

**第二步：换个枚举对象——不枚举区间，枚举"谁是最小值"。** 这是本题的思维跳跃。一个区间的美丽度由它的**最小值**和**长度**决定。与其枚举区间再求最小值，不如反过来：**固定某个位置 $i$，让 $a_i$ 当最小值，问它能"管"多宽的区间**。

具体地，从 $i$ 向左右扩展，只要遇到的元素都 $\ge a_i$，$a_i$ 就仍是最小值；一旦遇到**严格小于** $a_i$ 的元素就停。设左边界 $L_i$（左边第一个 $<a_i$ 的位置，没有则 $-1$）、右边界 $R_i$（右边第一个 $<a_i$ 的位置，没有则 $n$），那么 $a_i$ 能管的最大区间是开区间 $(L_i,R_i)$，长度 $R_i-L_i-1$，美丽度候选 $a_i\cdot(R_i-L_i-1)$。

**为什么最优解一定在这些候选里？** 设最优区间是 $[l,r]$，最小值 $m=a_i$（某个 $i\in[l,r]$）。因为 $[l,r]$ 里所有元素 $\ge a_i$，所以 $a_i$ 的"势力范围" $(L_i,R_i)$ **至少覆盖** $[l,r]$；而 $(L_i,R_i)$ 里的元素也都 $\ge a_i$ 且含 $a_i$，最小值仍是 $a_i$。于是
$$a_i\cdot(R_i-L_i-1)\ \ge\ a_i\cdot(r-l+1)=\text{最优值}.$$
左边又是一个合法区间的美丽度，所以它**恰好等于**最优值。因此 $\text{答案}=\max_i a_i(R_i-L_i-1)$。枚举对象从 $O(n^2)$ 个区间降到 $n$ 个位置。

**第三步：识别经典模型。** "对每个位置求左右第一个严格更小者，再算 $a_i\times$ 跨度"——这正是**直方图最大矩形**（largest rectangle in histogram）！把 $a_i$ 看成宽度 $1$、高度 $a_i$ 的柱子，区间美丽度 $=$ 长 $\times$ 最小高 $=$ 以该区间为底、以最小柱高为高的矩形面积。答案就是直方图里能勾出的最大矩形面积。经典解法：**单调栈**，$O(n)$ 求出每个位置的左右边界。

**第四步：单调栈怎么写 + 重复元素的坑。** 维护一个下标栈，栈内对应的高度**单调不降**。扫描到 $i$ 时，只要栈顶高度 $>a_i$ 就弹栈：被弹出的 $j$ 找到了右边界 $i$（右边第一个严格更小），而弹完后的新栈顶就是 $j$ 的左边界（左边第一个 $\le a_j$ 的仍在栈中的位置）。于是候选 $a_j\times(i-\text{新栈顶}-1)$。

重复元素要小心：弹栈条件用**严格** $>$，相等不弹。这样一段相等元素里，**最左边那个**会一直留到真正更小的元素出现才弹出，它的左边界是段外第一个严格更小者、右边界也是段外第一个严格更小者，恰好拿到**整段的完整跨度**；段里其它元素虽然跨度被左边的相等元素截断，但最大值已经被最左那个取到了。所以"严格 $>$ 弹栈"不会漏掉最优解（第二部分引理 3 严格证明）。

**第五步：收尾的两个工程细节。**

1. **哨兵**：在末尾补一个 $a_n=-1$（比所有 $a_i\ge0$ 都小），扫描到它时把栈里剩余元素全部逼出来，省去循环后再单独清栈。
2. **溢出**：$a_i\le2\times10^6$，跨度 $\le2\times10^6$，乘积 $\le4\times10^{12}$，**超 `int`**，必须 `i64`。
3. **快读**：$n=2\times10^6$，用 `fread` 缓冲快读（题面明示需要读入优化），输出用 `printf`，全程 C stdio，避开 `ifstream` 在本地 non-static 链接下的段错误坑。

**手造数据核对**（题面只给了样例解释"选 $[2,3]$ 得 $4$"，没有完整样例输入，我按解释反推并另造几组）：

- $a=[1,2,2]$：区间 $[2,3]$（1-based）最小 $2$、长 $2$ ⇒ $4$；$[1,3]$ 最小 $1$ 长 $3$ ⇒ $3$；单点最大 $2$。答案 $4$，与样例解释吻合。
- $a=[3,1,2,2,4]$：$[3,5]$ 最小 $2$ 长 $3$ ⇒ $6$；$[2,5]$ 最小 $1$ 长 $4$ ⇒ $4$；$[1,5]$ 最小 $1$ 长 $5$ ⇒ $5$。答案 $6$。
- $a=[2,2,2,2]$：整段最小 $2$ 长 $4$ ⇒ $8$。
- $a=[0,0,0]$：全 $0$ ⇒ $0$；$a=[5]$ ⇒ $5$；$a=[1,2,3,4,5]$ ⇒ $[3,4,5]$ 最小 $3$ 长 $3$ ⇒ $9$。

程序输出与手算逐条吻合；另与"枚举所有区间 running min"的 $O(n^2)$ 独立暴力在 $400$ 组随机小数据（$n\le60$，$a_i\in[0,10]$，刻意制造大量重复与 $0$）上对拍，$0$ mismatch。

## 二、思维链：完整证明

**记号。** 序列 $a_0,\dots,a_{n-1}$（内部 $0$-based），$a_i\in[0,2\times10^6]$。区间 $[l,r]$（$0\le l\le r<n$）的美丽度 $B(l,r)=(r-l+1)\cdot\min_{l\le t\le r}a_t$。答案 $\mathrm{OPT}=\max_{0\le l\le r<n}B(l,r)$。对每个 $i$，定义
$$L_i=\max\{j<i:a_j<a_i\}\ (\text{无则 }-1),\qquad R_i=\min\{j>i:a_j<a_i\}\ (\text{无则 }n).$$
候选 $C_i=a_i\cdot(R_i-L_i-1)$。

---

### 引理 1（候选区间的最小值恰为 $a_i$）

对每个 $i$，开区间 $(L_i,R_i)$ 非空（含 $i$），且 $\min_{t\in(L_i,R_i)}a_t=a_i$。

*证明*：$L_i<i<R_i$ 故 $i\in(L_i,R_i)$，非空。对任意 $t\in(L_i,R_i)$：若 $t<i$，由 $L_i$ 是左边**第一个** $<a_i$ 的位置，$t>L_i$ 意味着 $a_t\ge a_i$（否则 $t$ 会是更靠右的 $<a_i$ 者，与 $L_i$ 的最大性矛盾）；若 $t>i$，同理由 $R_i$ 的最小性得 $a_t\ge a_i$；$t=i$ 时 $a_t=a_i$。故区间内所有元素 $\ge a_i$ 且 $a_i$ 在其中，最小值 $=a_i$。证毕。

**推论**：$C_i=a_i\cdot(R_i-L_i-1)=B(L_i+1,R_i-1)$ 是一个**合法区间**的美丽度，故 $C_i\le\mathrm{OPT}$，从而 $\max_i C_i\le\mathrm{OPT}$。

---

### 引理 2（最优解必是某个候选：$\mathrm{OPT}=\max_i C_i$）

$\mathrm{OPT}=\max_{0\le i<n}C_i$。

*证明*：由引理 1 推论已有 $\max_i C_i\le\mathrm{OPT}$。下证 $\mathrm{OPT}\le\max_i C_i$。

取最优区间 $[l,r]$ 使 $B(l,r)=\mathrm{OPT}$，设其最小值 $m=\min_{[l,r]}a_t$，取 $i\in[l,r]$ 使 $a_i=m$。因 $[l,r]$ 内所有元素 $\ge a_i$，故左边第一个 $<a_i$ 的位置 $L_i<l$（$[l,i)$ 内无 $<a_i$ 者，$L_i$ 只能在 $l$ 左侧或不存在），即 $L_i\le l-1$；同理 $R_i\ge r+1$。于是
$$R_i-L_i-1\ge(r+1)-(l-1)-1=r-l+1.$$
又由引理 1，$(L_i,R_i)$ 的最小值是 $a_i=m$，所以
$$C_i=a_i(R_i-L_i-1)\ge m(r-l+1)=B(l,r)=\mathrm{OPT}.$$
故 $\max_i C_i\ge C_i\ge\mathrm{OPT}$。双向夹逼得等式。证毕。

**这条引理是"枚举最小值"归约的合法性核心**：它证明了把 $O(n^2)$ 个区间换成 $n$ 个"最大跨度候选"不丢最优解。

---

### 引理 3（单调栈单趟扫描正确计算 $\max_i C_i$，含重复元素）

算法：栈 `st` 存下标，栈内高度单调不降。令 $a_n=-1$（哨兵）。对 $i=0..n$：当栈非空且 $a_{\text{st.top}}>a_i$ 时，弹出 $j=\text{st.top}$，记新栈顶为 $k$（栈空则 $k=-1$），用 $V(j)=a_j\cdot(i-k-1)$ 更新答案；然后把 $i$ 入栈。则 $\max_j V(j)=\max_i C_i=\mathrm{OPT}$。

*证明*：分两步。

**(A) 每个 $V(j)\le\mathrm{OPT}$（弹出的都是合法候选）。** 设 $j$ 被 $i$ 弹出，新栈顶 $k$。断言：区间 $(k,i)$ 内所有元素 $\ge a_j$，从而 $\min_{(k,i)}a=a_j$（$j\in(k,i)$），$V(j)=B(k+1,i-1)\le\mathrm{OPT}$。

- 右半 $[j,i-1]$：这些位置在 $j$ 之后、$i$ 之前被扫描。它们都没能弹出 $j$（$j$ 直到 $i$ 才弹），故其高度都 $\ge a_j$（若某个 $<a_j$，扫描到它时就会因严格 $>$ 弹出 $j$）。
- 左半 $(k,j)$：$k$ 是弹出 $j$ 后的新栈顶，即栈中 $j$ 正下方的下标。栈内高度单调不降，故 $a_k\le a_j$。若存在 $t\in(k,j)$ 使 $a_t<a_j$，则 $t$ 是比 $k$ 更靠近 $j$ 的、高度 $\le a_j$ 的位置；但 $t$ 若在栈中应位于 $k,j$ 之间（与 $k$ 是 $j$ 正下方矛盾），若不在栈中则它早被弹出——而它被弹出时 $j$ 尚未入栈或已在栈中：若 $j$ 已在栈中且 $a_t<a_j$，$t$ 入栈扫描会弹出 $j$（矛盾，$j$ 现在才弹）。故 $t$ 不可能在 $j$ 之前以 $<a_j$ 的高度留存于 $(k,j)$。综上 $(k,j)$ 内元素 $\ge a_j$。

故 $(k,i)$ 内全 $\ge a_j$ 且含 $a_j$，$V(j)$ 是合法美丽度，$\le\mathrm{OPT}$。所以 $\max_j V(j)\le\mathrm{OPT}$。

**(B) 每个 $C_i$ 都被某个 $V(j)$ 取到（不漏最优）。** 把序列按"极大相等连续段"划分。设某段为 $[p,q]$（$a_p=\dots=a_q=v$，且 $a_{p-1}\ne v$ 或 $p=0$，$a_{q+1}\ne v$ 或 $q=n-1$）。段内所有位置的 $L,R$ 相同：$L_p=\dots=L_q=$ 段左第一个 $<v$ 者，$R_p=\dots=R_q=$ 段右第一个 $<v$ 者（相等元素不构成"严格更小"，边界跳过整段）。故 $C_p=\dots=C_q=v(R_p-L_p-1)$。

考察段最左位置 $p$。扫描时 $p$ 入栈；段内后续相等元素因"严格 $>$ 才弹"不会弹出 $p$（相等不弹），它们压在 $p$ 上方。直到扫描到段右第一个 $<v$ 的位置 $R_p$（或哨兵 $n$，若段延伸到末尾），才开始弹栈：先弹出 $p$ 上方的相等元素，最后弹出 $p$。弹出 $p$ 时：
- 右边界 $i=R_p$（右边第一个严格更小，正是触发弹出的位置）；
- 新栈顶 $k$：$p$ 下方的栈元素。$p$ 入栈时曾弹出所有 $>a_p=v$ 的栈顶，留下的栈顶高度 $\le v$；又 $p$ 是段最左，其左侧最近的高度 $\le v$ 者就是 $L_p$（左边第一个 $<v$，因为 $a_{p-1}\ne v$ 且若 $a_{p-1}>v$ 则更左的 $\le v$ 者必 $<v$）。故 $k=L_p$。

于是 $V(p)=a_p(R_p-L_p-1)=v(R_p-L_p-1)=C_p$。即每段的完整候选都被段最左位置取到。结合引理 2，$\max_j V(j)\ge\max_{\text{段}}C_p=\max_i C_i=\mathrm{OPT}$。

(A)(B) 夹逼得 $\max_j V(j)=\mathrm{OPT}$。证毕。

**注**：若弹栈条件误用 $\ge$（相等也弹），则段最左位置会被段内第二个相等元素提前弹出，右边界停在段内，拿不到完整跨度——虽然此时**段最右**位置反而拿到完整跨度，最大值仍对，但左右边界的语义会变。本文用严格 $>$，由 (B) 保证段最左取到完整跨度，逻辑最清晰。

---

### 引理 4（哨兵 $a_n=-1$ 逼空栈）

设 $a_n=-1$。扫描到 $i=n$ 时，栈中所有剩余元素都会被弹出，且每个弹出的右边界取 $n$。

*证明*：所有真实元素 $a_j\ge0>-1=a_n$，故弹栈条件 $a_{\text{st.top}}>a_n$ 对栈中每个元素都成立，循环一直弹到栈空。弹出 $j$ 时右边界 $i=n$，对应"右边没有严格更小者"（$R_j=n$），与定义一致。哨兵自身最后入栈，但循环已结束，不影响答案。证毕。

---

### 引理 5（值域与溢出）

$\mathrm{OPT}\le4\times10^{12}$，必须用 `i64`；候选乘积 `(i64)a[j]*(i-k-1)` 先转 `i64` 再乘，避免 `int` 中间溢出。

*证明*：$a_i\le2\times10^6$，跨度 $R_i-L_i-1\le n\le2\times10^6$，故 $C_i\le2\times10^6\times2\times10^6=4\times10^{12}$。`int` 上限 $2.147\times10^9$，远小于 $4\times10^{12}$，会溢出；`i64` 上限 $9.22\times10^{18}$，安全。代码 `(i64)a[j]*(i-k-1)` 把左操作数先提升为 `i64`，乘法在 `i64` 下进行，杜绝 `int*int` 的中间溢出。答案 `ans` 为 `i64`，初值 $0$（全 $0$ 序列时 $\mathrm{OPT}=0$，正确）。证毕。

---

### 引理 6（`fread` 快读正确性）

`rd()` 对输入流中的非负整数 token 返回其值；`gc()` 用 `fread` 缓冲逐字符供给。

*证明*：`gc()` 维护缓冲 `ibuf`、位置 `ipos`、长度 `ilen`；缓冲耗尽时 `fread`  refill，读到 $0$ 字节返回 `EOF`。`rd()` 先跳过所有非数字字符（空白等），再按 Horner `x=x*10+(c-'0')` 累加数字直到非数字。题面保证 $n\ge1$、$a_i\ge0$ 均为非负整数，无符号位，故解析正确。$a_i\le2\times10^6$、$n\le2\times10^6$ 均在 `int` 内，Horner 中间值 $\le2\times10^6$ 不溢出。输入恰含 $n+1$ 个 token，`rd` 调用 $n+1$ 次后不再读，`EOF` 不会引发死循环。证毕。

---

### 引理 7（复杂度）

时间 $O(n)$，空间 $O(n)$。

*证明*：每个下标 $0..n$ 恰好入栈一次、至多弹栈一次，故弹栈循环总执行 $\le n+1$ 次，扫描 $O(n)$。快读 $O(\text{输入字符数})=O(n)$（每数 $\le7$ 位）。空间：`a[mxn]`、`st[mxn]` 各 $2\times10^6$ 个 `int` $\approx8$ MB，缓冲 $1$ MB，合计 $O(n)$，约 $17$ MB。证毕。

---

### 定理

程序输出 $\max_i a_i(R_i-L_i-1)=\mathrm{OPT}$，即序列的美丽系数；时间 $O(n)$，空间 $O(n)$。

*证明*：引理 1、2 把"枚举区间"归约为"枚举最小值的最大跨度候选"；引理 3 证明单调栈单趟扫描（严格 $>$ 弹栈）正确算出 $\max_i C_i$，含重复元素；引理 4 保证哨兵逼空栈；引理 5 保证 `i64` 不溢出；引理 6 保证快读正确；引理 7 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 美丽度 $=$ 长 $\times$ 最小值，由"最小值"和"跨度"两个量决定。
- **consider easier version** — 枚举区间 $O(n^2)$，$n=2\times10^6$ 时 $4\times10^{12}$ 超时，确认要 $O(n)$。
- **reduce to easier problem** — 不枚举区间改枚举最小值：最优区间必是其最小值元素的"最大跨度"，答案 $=\max_i a_i(R_i-L_i-1)$。
- **classic problem solution** — 左右第一个严格更小者 = 单调栈；整体即"直方图最大矩形"，$O(n)$。
- **explore its property** — 重复元素：严格 $>$ 弹栈，相等段最左位置拿到完整跨度；哨兵 $-1$ 逼空栈。
- **discuss by category** — 乘积 $\le4\times10^{12}$ 用 `i64`；$n=2\times10^6$ 用 `fread` 快读；全 $0$ 答案为 $0$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 序列长度 $\le2\times10^6$ | `int`，快读 | 内部 $0$-based |
| `a[i]` | 第 $i$ 个元素 $\in[0,2\times10^6]$ | `int[mxn]`，快读 | `a[n]=-1` 是哨兵 |
| `st[]` | 单调栈（存下标），栈内高度单调不降 | `int[mxn]` | `tp` 为栈顶指针（元素个数） |
| `tp` | 栈中元素个数 | `int`，初值 $0$ | `st[tp-1]` 是栈顶 |
| `ans` | 美丽系数 $\max_i C_i$ | `i64`，初值 $0$ | 乘积先转 `i64` |
| `j` | 被弹出的下标（当前候选的最小值位置） | `int` | `a[j]` 是矩形高 |
| `k`/`l` | 弹出 $j$ 后的新栈顶（左边界，栈空则 $-1$） | `int` | 跨度 $=i-l-1$ |
| `i` | 扫描位置，也是弹出时的右边界 | `int` | $0..n$，$n$ 是哨兵 |
| `ibuf,ipos,ilen` | `fread` 缓冲 / 位置 / 长度 | `char[1<<20]`,`int` | 快读三件套 |
| `mxn` | $2\times10^6+5$ | `constexpr int` | 数组尺寸 $+5$ 松弛 |

### 算法步骤

1. 快读 `n`，快读 `a[0..n-1]`；置 `a[n]=-1`（哨兵）。
2. `tp=0,ans=0`。对 `i=0..n`：
   1. 当 `tp>0 && a[st[tp-1]]>a[i]`：弹出 `j=st[--tp]`；左边界 `l=tp?st[tp-1]:-1`；`ans=max(ans,(i64)a[j]*(i-l-1))`。
   2. `st[tp++]=i`（$i$ 入栈）。
3. `printf("%lld\n",ans)`。

### 复杂度

- 时间：$O(n)$（每下标至多入栈 / 弹栈各一次）$+$ 快读 $O(n)$。
- 空间：$O(n)$，`a`、`st` 各约 $8$ MB，缓冲 $1$ MB，合计约 $17$ MB。
- 值域：$\mathrm{OPT}\le4\times10^{12}$，`i64` 安全。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；按样例解释反推 $a=[1,2,2]\to4$ 吻合；手算 $[3,1,2,2,4]\to6$、$[2,2,2,2]\to8$、$[0,0,0]\to0$、$[5]\to5$、$[1,2,3,4,5]\to9$ 全对；另与 $O(n^2)$ 枚举区间暴力在 $400$ 组随机小数据（$n\le60$，$a_i\in[0,10]$，大量重复与 $0$）对拍，$0$ mismatch。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2659 美丽的序列
// 思路：美丽度=长*最小值 ⇒ 枚举"谁当最小值"，答案=max_i a[i]*(左右第一个严格更小者之间的跨度)。
//       这就是直方图最大矩形，单调栈 O(n)。
//       严格 > 弹栈：相等段最左位置拿到完整跨度；哨兵 a[n]=-1 逼空栈。
//       乘积<=4e12 用 i64；n=2e6 用 fread 快读（题面提示需要读入优化）。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2000005};

int n,a[mxn],st[mxn],tp;
i64 ans;

// fread 快读：n 达 2e6，cin 可能吃紧
char ibuf[1<<20];int ipos,ilen;
inline int gc()
{
	if(ipos==ilen)
	{
		ilen=fread(ibuf,1,sizeof ibuf,stdin);
		ipos=0;
		if(!ilen)
			return EOF;
	}
	return ibuf[ipos++];
}
inline int rd()
{
	int x=0,c=gc();
	while(c<'0'||c>'9')
		c=gc();
	while(c>='0'&&c<='9')
	{
		x=x*10+(c-'0');
		c=gc();
	}
	return x;
}

int main()
{
	n=rd();
	for(int i=0;i<n;++i)
		a[i]=rd();
	a[n]=-1;	// 哨兵：比所有 a_i(>=0) 都小，逼出栈中全部元素
	for(int i=0;i<=n;++i)
	{
		while(tp&&a[st[tp-1]]>a[i])	// 严格 > 才弹，相等留在栈里
		{
			int j=st[--tp];
			int l=tp?st[tp-1]:-1;	// 左边第一个 <=a[j] 的仍在栈者
			ans=max(ans,(i64)a[j]*(i-l-1));	// 高 a[j]，宽 i-l-1
		}
		st[tp++]=i;
	}
	printf("%lld\n",ans);
	return 0;
}
```

### 代码说明

- **单调栈语义**：栈内下标对应高度单调不降。弹栈条件 `a[st[tp-1]]>a[i]` 用**严格** $>$，相等不弹——这保证相等段最左位置留到段外更小者出现才弹，拿到完整跨度（引理 3B）。
- **左边界 `l=tp?st[tp-1]:-1`**：弹出 $j$ 后的新栈顶即 $j$ 左边第一个 $\le a_j$ 的仍在栈位置；栈空说明左边没有更小者，$l=-1$。跨度 `i-l-1` 是开区间 $(l,i)$ 的长度。
- **哨兵 `a[n]=-1`**：所有 $a_i\ge0$，扫描到 $i=n$ 时把栈逼空，每个剩余元素的右边界取 $n$，无需循环后单独清栈。
- **`(i64)a[j]*(i-l-1)`**：先把高转 `i64` 再乘宽，避免 `int*int` 在 $4\times10^{12}$ 量级溢出；`ans` 为 `i64`。
- **`fread` 快读 + `printf` 输出**：纯 C stdio，$2\times10^6$ 个数读入快，且避开本地 `ifstream` 段错误坑。`rd` 只处理非负整数（题面保证），无符号分支。
- 下标内部 $0$-based；`tp` 是栈元素个数，`st[tp-1]` 为栈顶；全局数组默认 $0$，`ans` 初值 $0$ 恰好对应全 $0$ 序列的答案。
