# P2693 [USACO1.3] 号码锁 Combination Lock — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 锁有三个转盘，每个刻着 $1\sim n$（$n\le 100$），转盘是**圆环**，$1$ 与 $n$ 相邻。有两把"钥匙"：农夫的 $(x,y,z)$ 和锁匠的 $(a,b,c)$。锁有容错：只要某个转盘的数字与**某一把钥匙**对应转盘的数字在圆环上**相距不超过 2 个位置**，且三个转盘都满足（对同一把钥匙），锁就开。问有多少个**不同的有序组合** $(p,q,r)$ 能开锁。注意 $(1,2,3)$ 与 $(3,2,1)$ 算不同组合。

题面样例说明给的是 $n=50$、农夫 $(1,2,3)$、锁匠 $(5,6,7)$，但没给输出。下面所有例子都是我自己手算再用程序核对的。

**第一步：把"相距 2 以内"翻译成数学。** 转盘是圆环，所以"距离"不是 $|v-c|$，而是**圆环距离**
$$\mathrm{dist}(v,c)=\min\bigl(|v-c|,\ n-|v-c|\bigr).$$
比如 $n=50$ 时 $1$ 与 $49$ 的直线差是 $48$，但绕一圈只要 $2$ 步，所以 $\mathrm{dist}(1,49)=2$，是"够得着"的。开锁条件就是：存在一把钥匙，使得 $\mathrm{dist}(p,x)\le2$、$\mathrm{dist}(q,y)\le2$、$\mathrm{dist}(r,z)\le2$（或对锁匠那把）。**这一步是全题的地基**——把"圆环""容错 2"两个词精确化，后面才不会在 $1$ 与 $n$ 相邻处翻车。

**第二步：最朴素的想法——暴力枚举。** 组合总数 $n^3\le 100^3=10^6$，对每个组合检查两把钥匙，每次 $O(1)$。$10^6$ 次判断完全能过。这是"模拟/枚举"标签最直接的解法。但我停下来想了想：真的需要扫 $10^6$ 个组合吗？

**第三步：发现每把钥匙只开一个很小的"容差盒"。** 固定一把钥匙 $(x,y,z)$，第一个转盘能取的合法值恰好是
$$S(x)=\{x-2,\ x-1,\ x,\ x+1,\ x+2\}\pmod n,$$
即圆环上以 $x$ 为中心、半径 $2$ 的 $5$ 个连续位置（$n<5$ 时会绕圈重叠，见下）。三个转盘独立，所以这把钥匙能开的组合集合是一个**笛卡尔积盒**
$$A=S(x)\times S(y)\times S(z),\qquad |A|=|S(x)|\cdot|S(y)|\cdot|S(z)|.$$
而 $|S(c)|=\min(n,5)$：$n\ge5$ 时 $5$ 个连续余数互不相同，$n<5$ 时 $5$ 个连续余数绕圈铺满整个圆环（只剩 $n$ 个不同值）。于是 $|A|=\min(n,5)^3\le 125$。**两把钥匙加起来至多 $250$ 个组合**——比 $10^6$ 小了四个数量级！

**第四步：答案就是两个盒子的并，去重即可。** 能开锁的组合 $=A\cup B$（$B$ 是锁匠的盒）。我只要把 $A$ 的 $\le125$ 个组合和 $B$ 的 $\le125$ 个组合都枚举出来，扔进一个三维标记数组 `vis[p][q][r]`，最后数有多少个被标记的格子。重复的组合（两盒相交、或 $n<5$ 时盒内自身重叠）会被 `vis` 自动去重。**不需要任何分类讨论**，$n$ 多小都对。

这里有两个必须想清楚的坑：

1. **两盒会相交。** 若两把钥匙很近（比如样例里每位只差 $4$），$A\cap B\ne\varnothing$，直接 $|A|+|B|$ 会重复计数。`vis` 去重正好解决。
2. **$n\le5$ 时所有组合都能开。** 圆环上任意两值的最大距离是 $\lfloor n/2\rfloor$，$n\le5$ 时 $\lfloor n/2\rfloor\le2$，于是**每个转盘都够得着每把钥匙的每个值**，$A=B=$ 全空间，答案 $n^3$。我的枚举里 $S(c)$ 铺满圆环、$125$ 个偏移大量重复，`vis` 去重后恰好得到 $n^3$，无需特判。

**第五步：用容斥做闭式交叉验证。** 既然 $|A|=|B|=\min(n,5)^3$，由容斥
$$\text{ans}=|A\cup B|=2\min(n,5)^3-|A\cap B|,\qquad |A\cap B|=I(x,a)\,I(y,b)\,I(z,c),$$
其中 $I(u,v)=|S(u)\cap S(v)|$ 是单个转盘上两个容差弧的交集大小。$n\ge5$ 时 $I(u,v)=\max(0,5-d)+\max(0,5-(n-d))$，$d=\mathrm{dist}(u,v)$；$n<5$ 时 $I=n$。这个公式我在第二部分严格证明，并用它手算样例：$n=50$ 时每位 $d=4$，$I=\max(0,1)+\max(0,5-46)=1$，故 $\text{ans}=250-1=249$，与枚举程序一致。**最终代码用枚举**（更短、更不易错），容斥只作为验证手段。

**手造数据核对**（题面只给样例说明、没给输出，我按说明算出 $249$ 并另造四组打边界）：

| 输入 | 手算 | 程序 |
|---|---|---|
| $n=50$，$(1,2,3)/(5,6,7)$ | $250-1^3=249$ | $249$ |
| $n=1$，$(1,1,1)/(1,1,1)$ | $1$（全空间只有 $1$ 个） | $1$ |
| $n=6$，$(1,1,1)/(4,4,4)$ | $250-4^3=186$ | $186$ |
| $n=5$，$(1,2,3)/(4,5,1)$ | $5^3=125$（全开） | $125$ |
| $n=2$，$(1,1,1)/(2,2,2)$ | $2^3=8$（全开） | $8$ |

第三组专门打"两盒相交但 $n>5$"：$S(1)=\{5,6,1,2,3\}$、$S(4)=\{2,3,4,5,6\}$（$1$-based），交 $\{2,3,5,6\}$ 大小 $4$，三位独立故 $|A\cap B|=64$。第四、五组打 $n\le5$ 全开。全部吻合。

## 二、思维链：完整证明

**记号。** 转盘值取 $0$-based（读入后 `--`），即 $\{0,1,\dots,n-1\}$，圆环距离 $\mathrm{dist}(u,v)=\min(|u-v|,\,n-|u-v|)$。对钥匙值 $c$ 定义容差集 $S(c)=\{(c+j)\bmod n: j\in\{-2,-1,0,1,2\}\}$。农夫盒 $A=S(x)\times S(y)\times S(z)$，锁匠盒 $B=S(a)\times S(b)\times S(c)$。答案 $=|A\cup B|$。

---

### 引理 1（圆环距离刻画"相距 2 以内"）

转盘值 $v$ 与钥匙值 $c$ "相距不超过 2 个位置" $\iff\mathrm{dist}(v,c)\le2$。

*证明*：把 $n$ 个位置看作圆环 $\mathbb Z_n$。从 $v$ 走到 $c$ 有两条弧：顺时针 $|v-c|$ 步、逆时针 $n-|v-c|$ 步（这里 $|v-c|$ 取直线差，绕圈即 $n-|v-c|$）。"相距几个位置"定义为较短弧的步数，即 $\min(|v-c|,n-|v-c|)=\mathrm{dist}(v,c)$。"不超过 2"就是 $\mathrm{dist}(v,c)\le2$。

需验证这个定义与"圆环上 $1$ 与 $n$ 相邻"一致：$v=0,c=n-1$（即 $1$ 与 $n$）时 $|v-c|=n-1$，$n-|v-c|=1$，$\mathrm{dist}=1$，确实相邻 ✓。若误用直线距离 $|v-c|=n-1$，就会把相邻判成相距很远——这正是本题最容易翻车的点。证毕。

**推论**：$v\in S(c)\iff\mathrm{dist}(v,c)\le2$。因为 $S(c)$ 恰是圆环上到 $c$ 距离 $\le2$ 的全部位置（$c$ 自身及左右各 $2$ 个）。

---

### 引理 2（容差集大小 $|S(c)|=\min(n,5)$）

对任意 $c$，$S(c)$ 是 $5$ 个连续余数 $\{c-2,c-1,c,c+1,c+2\}\bmod n$，且 $|S(c)|=\min(n,5)$。

*证明*：$S(c)$ 由 $5$ 个连续整数 $c-2,\dots,c+2$ 模 $n$ 得到。

- **$n\ge5$**：$5$ 个连续整数模 $n$ 互不相同（若 $(c+i)\equiv(c+j)\pmod n$ 且 $0\le i<j\le4$，则 $n\mid(j-i)$，但 $0<j-i\le4<n$，矛盾）。故 $|S(c)|=5$。
- **$n<5$**：任意 $n$ 个连续整数模 $n$ 恰好铺满全部 $n$ 个余数（这是 $\mathbb Z_n$ 的基本性质：连续 $n$ 个整数构成完全剩余系）。这里 $5>n$，$5$ 个连续整数包含某 $n$ 个连续整数，故模 $n$ 后覆盖全部 $n$ 个余数，$|S(c)|=n$。

两情形合并即 $|S(c)|=\min(n,5)$。注意 $n<5$ 时 $S(c)$ 与 $c$ 无关（都是整个圆环），这一点在引理 5 用到。证毕。

---

### 引理 3（单钥匙开锁集是笛卡尔积盒）

钥匙 $(x,y,z)$ 能开的组合集合恰为 $A=S(x)\times S(y)\times S(z)$，$|A|=\min(n,5)^3$。

*证明*：组合 $(p,q,r)$ 被这把钥匙打开 $\iff$ 三个转盘各自够得着对应钥匙值（引理 1 推论）$\iff p\in S(x)\land q\in S(y)\land r\in S(z)\iff(p,q,r)\in S(x)\times S(y)\times S(z)$。三个条件独立，故是笛卡尔积。大小由乘法原理 $|A|=|S(x)||S(y)||S(z)|=\min(n,5)^3$（引理 2）。证毕。

---

### 引理 4（答案 $=|A\cup B|$，枚举去重恰好计算它）

能开锁的组合集合 $=A\cup B$；算法用 `vis` 标记 $A$ 与 $B$ 的全部元素并计数不同格子，输出 $|A\cup B|$。

*证明*：**集合相等**：组合能开锁 $\iff$ 它被农夫钥匙或锁匠钥匙打开（题面"两种组合之一"）$\iff$ 它 $\in A$ 或 $\in B$ $\iff\in A\cup B$。

**算法正确**：外层 `t=0,1` 分别取农夫、锁匠钥匙；三重循环 `dx,dy,dz∈[-2,2]` 枚举 $S(\cdot)$ 的 $5$ 个偏移，`wrap` 取模归一化（引理 7），得到该钥匙盒的一个元素并标记 `vis`。由引理 3，$t=0$ 标记遍 $A$ 的全部 $\min(n,5)^3$ 个元素（$n<5$ 时有重复标记，但 `vis` 幂等），$t=1$ 标记遍 $B$。`if(!vis)++ans` 保证每个不同组合只计一次。故 `ans` $=|A\cup B|$。证毕。

---

### 引理 5（$n\le5$ 时全空间开锁，答案 $n^3$）

若 $n\le5$，则每个组合都能开锁，答案 $=n^3$。

*证明*：圆环 $\mathbb Z_n$ 上任意两值的最大距离为 $\lfloor n/2\rfloor$（最远的一对是直径两端）。$n\le5\Rightarrow\lfloor n/2\rfloor\le2$。故对任意转盘值 $v$ 与任意钥匙值 $c$，$\mathrm{dist}(v,c)\le\lfloor n/2\rfloor\le2$，即 $v\in S(c)$。于是 $S(c)=$ 全圆环（与引理 2 的 $n<5$ 情形一致；$n=5$ 时 $|S(c)|=5=n$ 也是全圆环），$A=B=\{0,\dots,n-1\}^3$，$|A\cup B|=n^3$。

算法层面：$n\le5$ 时 $\min(n,5)=n$，每盒 $n^3$ 个元素，两盒都是全空间，`vis` 去重后 `ans`$=n^3$，无需特判。证毕。

---

### 引理 6（容斥闭式与逐位交集公式）

$$\text{ans}=2\min(n,5)^3-I(x,a)\,I(y,b)\,I(z,c),\qquad I(u,v)=|S(u)\cap S(v)|.$$
其中
$$I(u,v)=\begin{cases}n,&n<5,\\[2pt]\max(0,5-d)+\max(0,5-(n-d)),&n\ge5,\ d=\mathrm{dist}(u,v).\end{cases}$$

*证明*：**容斥**：$|A\cup B|=|A|+|B|-|A\cap B|$。由引理 3，$|A|=|B|=\min(n,5)^3$。$A\cap B=(S(x)\cap S(a))\times(S(y)\cap S(b))\times(S(z)\cap S(c))$（笛卡尔积的交逐位取交），故 $|A\cap B|=I(x,a)I(y,b)I(z,c)$。代入即得闭式。

**$n<5$**：由引理 2，$S(u)=S(v)=$ 全圆环，$I=n$。

**$n\ge5$ 的交集公式**：$S(u),S(v)$ 是圆环上两段长 $5$ 的连续弧，中心圆环距离 $d$。把圆环在 $u$ 处剪开展成直线，$S(u)$ 占 $[-2,2]$，$S(v)$ 的中心在 $d$（顺时针）或等价地 $-(n-d)$（逆时针）。两弧的交由**两段不相交的连续run**组成：

- 顺时针侧：$S(u)$ 的右端 $2$ 与 $S(v)$ 的左端 $d-2$ 重叠，重叠长度 $\max(0,\,2-(d-2)+1)=\max(0,5-d)$（$d>4$ 时不重叠）。
- 逆时针侧：$S(u)$ 的左端 $-2\equiv n-2$ 与 $S(v)$ 绕过来的右端重叠，等价于把距离换成 $n-d$，重叠长度 $\max(0,5-(n-d))$。

$n\ge5$ 保证这两段 run 落在圆的两侧、互不相交（否则需 $5-d>0$ 且 $5-(n-d)>0$ 且两段相接，即 $n<5$，矛盾）。故 $I=\max(0,5-d)+\max(0,5-(n-d))$。

**验证**：$n=50,d=4$：$\max(0,1)+\max(0,5-46)=1$，直接数 $S(1)\cap S(5)=\{3\}$ 大小 $1$ ✓。$n=6,d=3$：$2+2=4$，$S(0)=\{4,5,0,1,2\},S(3)=\{1,2,3,4,5\}$，交 $\{1,2,4,5\}$ 大小 $4$ ✓。$n=5,d=2$：$3+2=5$，两弧都是全圆环，交 $5$ ✓。证毕。

**注**：此闭式与枚举程序对同一输入给出相同答案（手算五组全部吻合），互为交叉验证。最终代码采用枚举，因为它把 $n<5$、两盒相交等情形统一交给 `vis` 去重，无需分情况写公式，更不易错。

---

### 引理 7（`wrap` 归一化正确）

`wrap(v)=(v%n+n)%n` 把任意整数 $v$ 映到 $[0,n)$，且对 $v=c+\mathrm{d}x$（$c\in[0,n)$，$\mathrm{d}x\in[-2,2]$）给出正确的圆环余数。

*证明*：C++ 的 `%` 对负数向零截断，`v%n∈(-n,n)`。加 $n$ 后 $\in(0,2n)$，再 `%n` 落到 $[0,n)$，且与数学模 $n$ 同余（因为 $(v\bmod n+n)\bmod n\equiv v\pmod n$）。对 $v\in[-2,n+1]$（$c\le n-1,\mathrm{d}x\le2$ 给出 $v\le n+1$；$c\ge0,\mathrm{d}x\ge-2$ 给出 $v\ge-2$），两次取模消除负数与越界，结果正是 $S(c)$ 中对应偏移的余数。$n=1$ 时 `wrap` 恒为 $0$，与引理 5 的"全空间只有一个值"一致。证毕。

---

### 定理（正确性与复杂度）

程序输出能开锁的不同组合数 $|A\cup B|$；时间 $O(1)$（至多 $2\times125=250$ 次标记），空间 $O(n^3)$（`vis` 数组 $105^3$ 个 `bool`）。

*证明*：引理 1 把题意精确化为圆环距离；引理 2、3 给出盒结构与大小；引理 4 证明枚举去重恰好计算 $|A\cup B|$；引理 5 保证 $n\le5$ 边界自动正确；引理 7 保证取模归一化无误；引理 6 提供独立闭式交叉验证。复杂度：三重循环各 $5$ 次、两把钥匙，共 $250$ 次 $O(1)$ 标记，故时间 $O(1)$；`vis` 为 $105^3\approx1.16\times10^6$ 个 `bool`（约 $1.1$ MB），空间 $O(n^3)$ 但被常数上界 $105^3$ 限制。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "相距 2 以内"是圆环距离 $\min(|v-c|,n-|v-c|)\le2$，不是直线距离；$1$ 与 $n$ 相邻是最大坑点。
- **consider easier version** — 先想暴力：枚举 $n^3\le10^6$ 个组合逐个判两把钥匙，能过但笨。
- **explore its property** — 每把钥匙只开一个容差盒 $S(x)\times S(y)\times S(z)$，$|S(c)|=\min(n,5)$，至多 $125$ 个组合。
- **reduce to easier problem** — 答案 $=$ 两盒之并 $|A\cup B|$，枚举 $\le250$ 个组合用 `vis` 去重即可，不必扫 $n^3$。
- **discuss by category** — $n<5$ 盒收缩/自重叠、$n\le5$ 全开、两盒相交：全部交给 `vis` 去重自动处理，无需分类特判。
- **classic problem solution** — 容斥 $|A\cup B|=|A|+|B|-|A\cap B|$ 配逐位弧交公式，作为闭式交叉验证（代码仍用枚举）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 转盘数字个数，$\le100$ | `int`，读入 | 圆环大小 |
| `f[3]` | 农夫钥匙 $(x,y,z)$，读入后 `--` 转 0-based | `int[3]` | "f = farmer" |
| `g[3]` | 锁匠钥匙 $(a,b,c)$，0-based | `int[3]` | "g = 预设/锁匠" |
| `vis[a][b][c]` | 组合 $(a,b,c)$ 是否已被某把钥匙覆盖 | `bool[mxn][mxn][mxn]`，全局默认 `false` | 去重标记，幂等 |
| `mxn` | $100+5=105$ | `constexpr int` | +5 松弛，覆盖 $0..n-1\le99$ |
| `wrap(v)` | $(v\bmod n+n)\bmod n$，归一化到 $[0,n)$ | `int(int)` | 处理负偏移与绕圈 |
| `ans` | 被标记的不同组合数 $=|A\cup B|$ | `int`，初值 $0$ | 每新标记一格 `++ans` |
| `dx,dy,dz` | 三个转盘的容差偏移，$\in[-2,2]$ | `int` | 三重循环各 $5$ 次 |

### 算法步骤

1. I/O 加速三行（`cin.tie` → `cout.tie` → `sync_with_stdio`）。
2. 读 `n`；读农夫钥匙入 `f[0..2]`、锁匠钥匙入 `g[0..2]`，每个 `--` 转 0-based。
3. 对 `t=0,1`（`t?g:f` 选钥匙）：三重循环 `dx,dy,dz∈[-2,2]`，算 `a=wrap(c[0]+dx)`、`b=wrap(c[1]+dy)`、`d=wrap(c[2]+dz)`；若 `!vis[a][b][d]` 则置真并 `++ans`。
4. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(1)$，至多 $2\times5^3=250$ 次标记（远小于暴力 $n^3=10^6$）。
- 空间：$O(n^3)$，`vis` 为 $105^3$ 个 `bool` $\approx1.1$ MB。
- 验证状态：`g++ -std=c++20 -O2 -Wall -Wextra` 编译通过；题面样例说明（$n=50$）手算 $249$ 与程序一致；另造 $n=1,6,5,2$ 四组边界（全开 / 两盒相交 / 单值圆环）手算与程序逐一吻合；容斥闭式（引理 6）对同五组独立给出相同答案。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2693 [USACO1.3] 号码锁 Combination Lock
// 思路：每把钥匙开一个容差盒 S(x)×S(y)×S(z)，|S(c)|=min(n,5)，至多 125 个组合。
//       答案 = 两盒之并，枚举 ≤250 个组合用 vis 去重，自动处理 n<5 与两盒相交。
//       圆环距离 ⇒ 偏移 dx∈[-2,2] 后 wrap 归一化；n≤5 时全空间开锁。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n,f[3],g[3];
bool vis[mxn][mxn][mxn];

int wrap(int v){return (v%n+n)%n;}	// 归一化到 [0,n)，处理负偏移与绕圈

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<3;++i){cin>>f[i];--f[i];}
	for(int i=0;i<3;++i){cin>>g[i];--g[i];}
	int ans=0;
	for(int t=0;t<2;++t)
	{
		int*c=t?g:f;	// t=0 农夫，t=1 锁匠
		for(int dx=-2;dx<=2;++dx)
			for(int dy=-2;dy<=2;++dy)
				for(int dz=-2;dz<=2;++dz)
				{
					int a=wrap(c[0]+dx),b=wrap(c[1]+dy),d=wrap(c[2]+dz);
					if(!vis[a][b][d])
					{
						vis[a][b][d]=true;
						++ans;	// 每个不同组合只计一次
					}
				}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`vis` 去重是核心**：两盒相交、$n<5$ 时盒内偏移重复，都被 `if(!vis)` 统一吸收，无需任何分类讨论。全局 `bool` 默认 `false`，恰好是"未覆盖"初值。
- **`wrap` 两次取模**：`(v%n+n)%n` 先把负数抬正再归一化。$n=1$ 时恒返回 $0$，与"全空间只有一个组合"一致；偏移 $-2$ 在 $n$ 小时会绕圈，`wrap` 自动处理。
- **0-based**：读入立刻 `--f[i]`，内部全程 $0..n-1$，输出是计数无需加回。
- **$5^3$ 而非 $n^3$**：每把钥匙只枚举 $125$ 个偏移，两把共 $250$ 次，比暴力扫 $10^6$ 快四个数量级，且 $n$ 多小都对。
- `mxn{105}` 是 $100+5$ 松弛；`vis` 约 $1.1$ MB，远低于限制。
