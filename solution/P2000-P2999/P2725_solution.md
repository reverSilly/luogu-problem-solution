# P2725 [USACO3.1] 邮票 Stamps — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $n$ 种邮票（$1\le n\le50$），面值 $a_i$（$1\le a_i\le10^4$），每种**张数不限**。信封上最多贴 $k$ 张（$1\le k\le200$）。求最大的正整数 $m$，使得 $1,2,\dots,m$ 每一个面值都能用**不超过 $k$ 张**邮票凑出。若连 $1$ 都凑不出（即没有面值 $1$ 的邮票），输出 $0$。

样例：$k=5$，面值 $\{1,3\}$。$1\sim5$ 全用 $1$ 分贴；$6=3+3$，$7=3+3+1$，……，$13=3\times4+1$ 都能 $\le5$ 张贴出；但 $14$ 不行（$3\times4+1\times2$ 要 $6$ 张，$3\times3+1\times5$ 要 $8$ 张……最少 $6$ 张 $>5$）。答案 $13$。

**第一步：把"连续可达"翻译成"最少张数"。** 直接对每个面值枚举"用哪些邮票、各几张"是多重组合爆炸。换个角度：对每个面值 $v$，定义

$$dp[v]=\text{凑出 }v\text{ 所需的最少邮票张数}.$$

那么"$v$ 能用 $\le k$ 张贴出" $\iff dp[v]\le k$。题目要的 $m$ 就是**从 $1$ 开始连续满足 $dp[v]\le k$ 的最长前缀的右端点**，即第一个 $dp[v]>k$ 的 $v$ 减 $1$。

**第二步：为什么"第一个断点"就是答案，后面不用看？** 这里有个容易含糊的地方：会不会 $v$ 凑不出、但 $v+1$ 反而凑得出，导致"连续前缀"提前结束却错过了后面更大的连续段？题目要的是 **$1$ 到 $m$ 全部**可达，所以一旦某个 $v$ 断了，无论后面如何，$m$ 都不可能 $\ge v$。因此答案**恰好**是第一个断点减 $1$，找到即可停，不必算完所有面值。这一步把"求最大 $m$"变成了"找最小不可达面值"。

**第三步：$dp$ 怎么算——完全背包求最小件数。** 凑 $v$ 的最后一步必然是贴上某张面值 $a_i$ 的邮票，此前凑的是 $v-a_i$。于是

$$dp[v]=\min_{a_i\le v}\big(dp[v-a_i]+1\big),\qquad dp[0]=0.$$

每种邮票无限张，所以这是**完全背包**（不是 $0/1$ 背包）；求的是最小件数，所以是 $\min$ 而非 $\max$。按 $v$ 从小到大递推：算 $dp[v]$ 时所有 $dp[v-a_i]$（$v-a_i<v$）都已算好，无后效性。

**第四步：算到多大为止？** $k$ 张邮票能凑出的最大面值是 $k\cdot a_{\max}$（全贴最大的）。所以任何 $v>k\cdot a_{\max}$ 必不可达，第一个断点 $\le k\cdot a_{\max}+1$。只需递推到 $k\cdot a_{\max}+1$。代入上界 $200\times10^4+1=2\,000\,001$，数组开 $2\times10^6+5$ 即可。

**第五步：两个必须抠的细节。**

1. **INF 初始化。** 全局 `int` 数组默认是 $0$，而 $dp[v]=0$ 会被误读成"$v$ 用 $0$ 张就能凑出"。必须把整个 $dp$ 显式填成一个大哨兵（`1145141919`），只留 $dp[0]=0$。否则所有面值都会被当成"可达"，答案直接冲到上界。
2. **没有面值 $1$。** 若 $1\notin\{a_i\}$，则 $dp[1]=\text{INF}>k$，第一个断点就是 $1$，答案 $1-1=0$，与题面"若 $m$ 不存在输出 $0$"一致，无需特判。

**手造数据核对**（题面给了样例解释，另造三组打卡片边界）：

| 输入 | 分析 | 输出 |
|---|---|---|
| `5 2` / `1 3` | 样例，$14$ 需 $6$ 张 $>5$ | `13` |
| `1 1` / `1` | 只能贴 $1$ 张，$1$ 可达、$2$ 需 $2$ 张 | `1` |
| `3 2` / `2 3` | 没有 $1$，$dp[1]=\infty$ | `0` |
| `2 2` / `1 3` | $1,2(1+1),3,4(3+1)$ 可达；$5$ 需 $3$ 张 $>2$ | `4` |

四组与程序输出逐一吻合。

## 二、思维链：完整证明

**记号。** 面值集合 $A=\{a_1,\dots,a_n\}$，$a_i\ge1$，$a_{\max}=\max A$。上限 $k$。$dp[0]=0$，对 $v\ge1$，$dp[v]=\min_{a_i\le v}(dp[v-a_i]+1)$，无可行项时 $dp[v]=+\infty$。实现中 $+\infty$ 用哨兵 $\text{INF}=1145141919$ 代替。

---

### 引理 1（$dp[v]$ 确为凑出 $v$ 的最少张数）

对每个整数 $v\ge0$，$dp[v]$ 等于"用 $A$ 中邮票（每种无限张）凑出总面值 $v$ 所需的最少张数"；若无法凑出则为 $+\infty$。

*证明*：对 $v$ 强归纳。

**基例 $v=0$**：凑 $0$ 用 $0$ 张，$dp[0]=0$。✓

**归纳步**：设对所有 $0\le u<v$ 结论成立。考察凑 $v$ 的任一方案（$v\ge1$，故至少一张）。设其最后一张面值为 $a_i$（必 $a_i\le v$），去掉这张后剩余邮票凑出 $v-a_i$，张数为"总张数 $-1$"。由归纳假设，凑 $v-a_i$ 的最少张数是 $dp[v-a_i]$，故该方案总张数 $\ge dp[v-a_i]+1\ge\min_{a_j\le v}(dp[v-a_j]+1)=dp[v]$。这说明**任何方案张数 $\ge dp[v]$**（下界）。

反向：取使 $dp[v-a_i]+1$ 最小的 $a_i$。由归纳假设，存在凑 $v-a_i$ 的方案恰用 $dp[v-a_i]$ 张（若 $dp[v-a_i]=\infty$ 则该项不参与 $\min$）；再添一张 $a_i$ 即凑出 $v$，张数 $dp[v-a_i]+1=dp[v]$。这说明**存在方案恰用 $dp[v]$ 张**（可达）。

上下界夹逼，$dp[v]$ 就是最少张数。若所有 $a_i>v$ 或所有 $dp[v-a_i]=\infty$，则 $\min$ 为空，$dp[v]=\infty$，对应"无法凑出"。证毕。

**推论**：$v$ 能用 $\le k$ 张凑出 $\iff dp[v]\le k$。

---

### 引理 2（答案 = 第一个断点减 $1$）

设 $v^\*=\min\{v\ge1:dp[v]>k\}$（若集合非空）。则题目所求 $m=v^\*-1$；特别地 $v^\*=1$ 时 $m=0$。

*证明*：题目要求最大的 $m$ 使 $\forall v\in[1,m],dp[v]\le k$。

先证 $m=v^\*-1$ 可行：对 $1\le v\le v^\*-1$，由 $v^\*$ 的最小性，$v\notin\{u\ge1:dp[u]>k\}$，故 $dp[v]\le k$。所以 $[1,v^\*-1]$ 全可达。

再证 $m\ge v^\*$ 不可行：$dp[v^\*]>k$，即 $v^\*$ 不可达，故任何 $m\ge v^\*$ 都使 $[1,m]$ 含不可达的 $v^\*$，违反要求。

综上最大可行 $m=v^\*-1$。$v^\*=1$ 时 $m=0$，对应"没有面值 $1$、连 $1$ 都凑不出"。证毕。

**关于"后面会不会又有连续段"的澄清**：题目要的是**从 $1$ 起**的连续可达前缀，不是"任意最长连续段"。即便 $v^\*$ 之后某些面值可达，也无关紧要——前缀已在 $v^\*$ 处断裂。故找到第一个断点即可停止，无需扫描全部面值。

---

### 引理 3（断点必在 $k\cdot a_{\max}+1$ 之前出现）

$v^\*\le k\cdot a_{\max}+1$，即递推只需算到 $v=k\cdot a_{\max}+1$ 必能遇到断点。

*证明*：$k$ 张邮票的总面值 $\le k\cdot a_{\max}$（每张 $\le a_{\max}$）。故任何 $v>k\cdot a_{\max}$ 都无法用 $\le k$ 张凑出，即 $dp[v]>k$（含 $dp[v]=\infty$ 的情形）。取 $v=k\cdot a_{\max}+1>k\cdot a_{\max}$，有 $dp[v]>k$，所以集合 $\{v\ge1:dp[v]>k\}$ 非空且其最小元 $v^\*\le k\cdot a_{\max}+1$。证毕。

**推论（数组尺寸与循环上界）**：$dp$ 数组开到 $k\cdot a_{\max}+2$（含下标 $k\cdot a_{\max}+1$）即够；主循环 `for(v=1;v<=k*a_max+1;++v)` 必在范围内 `break`。代入 $k\le200,a_{\max}\le10^4$，上界 $2\,000\,001$。

---

### 引理 4（递推的无后效性与计算顺序）

按 $v=1,2,\dots$ 递增顺序计算，每次 $dp[v]=\min_{a_i\le v}(dp[v-a_i]+1)$ 引用的 $dp[v-a_i]$ 均已正确算出。

*证明*：$a_i\ge1$，故 $v-a_i\le v-1<v$。在算 $dp[v]$ 之前，循环已处理完 $1,\dots,v-1$，由引理 1 的归纳，这些 $dp$ 值都是正确的最少张数。$dp[0]=0$ 预先设好。故所有引用项就绪，计算良定义且正确。证毕。

---

### 引理 5（INF 哨兵不会污染答案）

取 $\text{INF}=1145141919$。在 $v\le k\cdot a_{\max}+1\le2\,000\,001$ 的整个递推中，凡用到 $\text{INF}$ 的中间量都不溢出 `int`，且 $\text{INF}$ 始终 $>k$，不会把不可达面值误判为可达。

*证明*：转移中出现的最大中间量是 $\text{INF}+1=1145141920<2^{31}-1=2147483647$，不溢出。$\min$ 运算只会保留 $\le$ 当前值的项，$\text{INF}$ 作为"不可达"标记参与 $\min$ 时，要么被更小的有限值取代，要么保持 $\text{INF}$；无论哪种，结果 $\ge$ 真实最少张数（$\text{INF}$ 代表 $+\infty$）。判定 $dp[v]>k$：因 $k\le200\ll\text{INF}$，任何含 $\text{INF}$ 的项都 $>k$，不可达面值必被判为断点；而真实可达面值 $dp[v]\le k$（张数非负整数），不会被误判。故哨兵语义与 $+\infty$ 一致。证毕。

**初始化必要性**：全局 `int dp[]` 默认全 $0$。若不显式 `fill_n(dp,...,INF)`，则 $dp[v]=0$ 会被读成"$0$ 张可达"，引理 1 的基例被破坏（除 $dp[0]$ 外全错），所有面值误判可达，答案冲到上界。故**必须**先填 INF 再置 $dp[0]=0$。

---

### 引理 6（复杂度）

时间 $O(k\cdot a_{\max}\cdot n)$，空间 $O(k\cdot a_{\max})$。

*证明*：主循环最多 $k\cdot a_{\max}+1$ 次（引理 3），每次内层枚举 $n$ 种面值，做常数次比较与加法，故时间 $O((k\cdot a_{\max})\cdot n)$。代入 $200\times10^4\times50=10^8$ 量级；但实际常在远早于上界处遇到断点而 `break`（如含面值 $1$ 时断点通常 $\le k\cdot a_{\text{次大}}$ 量级），实测极限数据 $0.04$ s。空间为 $dp$ 数组 $O(k\cdot a_{\max})\approx2\times10^6$ 个 `int` $\approx8$ MB，加 $O(n)$ 的面值数组。证毕。

---

### 定理

程序输出题目所求的最大 $m$（不存在时输出 $0$），复杂度 $O(k\cdot a_{\max}\cdot n)$。

*证明*：引理 1 保证 $dp[v]$ 是最少张数、$dp[v]\le k\iff v$ 可达；引理 2 保证答案是第一个断点减 $1$；引理 3 保证断点在循环上界内必出现；引理 4 保证递推顺序正确；引理 5 保证 INF 哨兵语义正确且必须初始化；引理 6 给出复杂度。证毕。

---

## 三、模式总结（按实际思考顺序）

- explore its property — "连续 $1..m$ 可达" $\iff$ 最少张数 $dp[v]\le k$ 的最长前缀；把存在性判定转成最优化量。
- reduce to easier problem — 答案 = 第一个 $dp[v]>k$ 的 $v$ 减 $1$；找到断点即停，后面不必算（题目要从 $1$ 起的连续前缀）。
- classic problem solution — 完全背包求最小件数：$dp[v]=\min_{a_i\le v}(dp[v-a_i]+1)$，$dp[0]=0$，按 $v$ 递增递推。
- explore its property — $k$ 张最大凑 $k\cdot a_{\max}$，故断点 $\le k\cdot a_{\max}+1$，据此定数组尺寸与循环上界。
- discuss by category — 无面值 $1$ 时 $dp[1]=\infty$、答案 $0$ 自动成立；全局数组默认 $0$ 必须显式填 INF，否则"不可达"被当成"$0$ 张可达"。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `k` | 信封最多贴的张数 | `int`，读入 | $\le200$ |
| `n` | 面值种数 | `int`，读入 | $\le50$ |
| `a[i]` | 第 $i$ 种面值 | `int[mxn]`，读入 | 每种无限张 |
| `mx` | $a_{\max}$ | `int`，读入时取 $\max$ | 定上界用 |
| `mxv` | $dp$ 数组尺寸 $2\,000\,005$ | `constexpr int` | $k\cdot a_{\max}+1=2\,000\,001$，$+5$ 松弛 |
| `inf` | 不可达哨兵 $1145141919$ | `constexpr int` | $\text{INF}+1$ 不溢出 `int` |
| `dp[v]` | 凑出面值 $v$ 的最少张数 | `int[mxv]` | **先全填 INF**，再置 `dp[0]=0` |
| `ans` | 第一个断点减 $1$ | `int`，初值 $0$ | 断点处 `ans=v-1;break` |

### 算法步骤

1. I/O 加速三行。
2. 读 `k,n`；读 $n$ 个面值，同时求 `mx`。
3. `fill_n(dp,k*mx+2,inf)`；`dp[0]=0`。
4. 对 $v=1,\dots,k\cdot mx+1$：内层枚举面值 $a_i\le v$，`dp[v]=min(dp[v],dp[v-a[i]]+1)`。
5. 若 `dp[v]>k`：`ans=v-1`，`break`。
6. 输出 `ans`。

### 复杂度

- 时间：$O(k\cdot a_{\max}\cdot n)$，上界 $10^8$ 量级，实际常提前 `break`，实测极限 $0.04$ s。
- 空间：$O(k\cdot a_{\max})\approx8$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例 `5 2 / 1 3` 输出 `13`；另造 `1 1 / 1`→`1`、`3 2 / 2 3`→`0`、`2 2 / 1 3`→`4` 均手算吻合；$300$ 组随机小数据（$k\le5,n\le4,a_i\le8$）与"枚举各面值张数向量标记可达集"的独立暴力逐一一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2725 [USACO3.1] 邮票 Stamps
// dp[v]=凑出面值 v 所需的最少邮票张数（每种面值无限张，完全背包求最小件数）。
// 答案=第一个 dp[v]>k 的 v 减 1；若 dp[1]>k 则输出 0。
// 上界：k 张邮票最大和为 k*max(a)，故只需算到 k*max(a)+1。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{55},mxv{2000005};	// mxv=k*a_max+1=200*10000+1，+5 松弛
constexpr int inf{1145141919};

int k,n,a[mxn],dp[mxv];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>k>>n;
	int mx=0;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		mx=max(mx,a[i]);
	}
	fill_n(dp,k*mx+2,inf);	// 全局默认 0 会被当成「0 张可达」，必须显式填 INF
	dp[0]=0;
	int ans=0;
	for(int v=1;v<=k*mx+1;++v)
	{
		for(int i=0;i<n;++i)
			if(a[i]<=v)
				dp[v]=min(dp[v],dp[v-a[i]]+1);
		if(dp[v]>k)	// 第一个断点：v 不可达，答案 v-1
		{
			ans=v-1;
			break;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **完全背包求最小件数**：内层 `dp[v]=min(dp[v],dp[v-a[i]]+1)`，按 $v$ 递增、面值任意顺序都对（引用项 $v-a_i<v$ 已算好）。求 $\min$ 不是 $\max$，因为要的是"最少张数"。
- **INF 初始化是命门**：`fill_n(dp,k*mx+2,inf)` 把用到的格子全填哨兵，再 `dp[0]=0`。漏掉这步，全局默认 $0$ 会让所有面值被误判"0 张可达"。
- **提前 break**：题目要从 $1$ 起的连续可达前缀，第一个 `dp[v]>k` 就是断点，答案 `v-1`，后面不必算。
- **上界 `k*mx+1`**：$k$ 张最大凑 $k\cdot a_{\max}$，故 $k\cdot a_{\max}+1$ 必不可达，循环必在此前 `break`，数组不会越界。
- **无面值 $1$ 自动输出 $0$**：$dp[1]$ 保持 INF $>k$，第一轮就 `ans=0;break`，无需特判。
- `inf+1=1145141920` 仍在 `int` 范围内，转移不溢出。
