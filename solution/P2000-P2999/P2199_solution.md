# P2199 最后的迷宫 — 题解

## 一、解题过程：人类思考叙事

题目：在一个 $N \times M$ 的迷宫里（`O` 空地，`X` 墙），给定奖杯位置和哈利位置。哈利只能**上下左右**移动，每步 $1$ 秒；但哈利视力很好，能沿**八个方向**（含斜向）直视，只要视线中没有墙就能看到奖杯。求哈利最少要多少秒才能**看到一个能看见奖杯的位置**（站到那个位置就能用飞来咒拿到奖杯）。如果奖杯被墙完全围住，输出 `Poor Harry`。

先把问题拆成两半：

**第一半：哪些位置"看得见奖杯"？**

这与哈利当前在哪无关，只取决于奖杯在哪一格。从奖杯格出发，向 8 个方向各投出一条射线，射线经过的所有非墙格子都能看到奖杯。再加上奖杯自己所在的格子（原地就能看到）。这一步的复杂度是 $O(N+M)$（8 条射线，每条最长 $\max(N,M)$）。

**第二半：哈利怎样最快到达其中之一？**

哈利只能四方向移动，每步代价相同 ⇒ 这是**无权图最短路**，用 BFS。从哈利位置 BFS，第一次取出的"能看见奖杯"的格子，其距离就是答案。BFS 的复杂度是 $O(NM)$。

把两半合起来：**每次询问先 O(N+M) 标记可见格，再 O(NM) 做一次 BFS**。

$BFS$ 只能进行一次吗？不行——每次询问的奖杯位置不同，可见格集合也不同，所以每次询问都要重新做。但**标记可见格**这一步很便宜，真正的开销是 BFS。总询问数不超过 $512$，$NM \le 16384$，$512 \times 16384 \approx 8.4 \times 10^6$，完全跑得动。

几个实现上的坑：

**坑一：坐标顺序。** 题面说"左上角为 $(1,1)$，右下角为 $(N,M)$"，且"$N$ 为高，$M$ 为宽"，所以 **$x$ 是行（范围 $1..N$），$y$ 是列（范围 $1..M$）**。也就是"先行后列"。

**坑二：每行四个数的顺序。** 题面写"分别是奖杯坐标及哈利的坐标"，即 `ex ey sx sy`——**奖杯在前，哈利在后**。这一条只能靠样例反推确认（见下文验证部分）。

**坑三：存储。** $NM \le 16384$，但 $N$ 或 $M$ 单独可以到 $16384$（例如 $N=16384, M=1$）。用二维数组 `char g[16384][16384]` 是 256 MB，会爆内存。所以必须**一维存储**：`g[i*M+j]` 表示格子 $(i,j)$，总大小 $16384$。

**坑四：多测清空。** 每次询问的 `see` 标记必须清空；`vis`、`dis` 也必须每次清空，否则会串数据。

顺便说，"奖杯被墙包围"其实不用特判：如果 8 条射线一步都走不出去，那么可见格集合只有奖杯自己这一格（而奖杯格一定不是墙），哈利要走到奖杯格才行——如果奖杯四周全是墙，那奖杯格是孤立的，BFS 根本到不了，此时 BFS 找不到可见格，输出 `Poor Harry`；如果奖杯没被围住但四周的墙很多，哈利可能仍然走不到任何可见格（比如哈利在另一个封闭区域），同样输出 `Poor Harry`。**统一用"BFS 没找到可见格 ⇒ Poor Harry"即可**，不需要额外特判。

样例理解：

样例 1 的迷宫是
```
O X X O
X X O O
X O O O
```
询问 `3 2 2 4`：奖杯在 $(3,2)$，哈利在 $(2,4)$。哈利从 $(2,4)$ 走到 $(2,3)$，$(2,3)$ 位于奖杯 $(3,2)$ 的**东北方向**（$x$ 减一、$y$ 减一），中间没有墙（$(2,3)$ 本身就是空地，且紧邻），所以一步就能看到奖杯 ⇒ 答案 `1`。

样例 2 的询问 `3 3 1 1`：按"奖杯在前"理解，奖杯在 $(3,3)$，哈利在 $(1,1)$。哈利所在的 $(1,1)$ 是个空地，但它的两个邻居 $(1,2)$ 与 $(2,1)$ 都是墙，**哈利被完全围住，一步也走不出去**，自然看不到奖杯 ⇒ `Poor Harry` ✓。

顺带把输入顺序确认下来。如果把每行四个数理解成"哈利在前、奖杯在后"，那么样例 1 的询问 `3 2 2 4` 就变成哈利在 $(3,2)$、奖杯在 $(2,4)$。此时 $(2,4)$ 的 8 个方向里只有 $(1,4)$ 是空地可见，而哈利从 $(3,2)$ 出发要绕道 $(3,3)\to(2,3)\to(2,4)\to(1,4)$，共 4 步，与样例输出 `1` 不符。而按"奖杯在前"理解时哈利只需一步就看到奖杯，与样例吻合。**结论：每行四个数是 `ex ey sx sy`，即奖杯坐标在前、哈利坐标在后。**

## 二、思维链：完整证明

**引理 1**：设奖杯在格 $c$。一个格子 $v$ 能看到奖杯，当且仅当 $v = c$，或者 $v$ 与 $c$ 在同一行 / 同一列 / 同一条 45° 对角线上，且 $v$ 与 $c$ 之间的所有格子都不是墙。

*证明*：哈利只能沿八个方向直视。若 $v$ 与 $c$ 不在上述四类直线上，则视线方向不在八个方向之列，哈利看不到 $c$。若 $v=c$，则原地可见。若 $v$ 与 $c$ 在同一直线上但中间存在墙，则墙不透光（题面"迷宫是不透光的"），必然挡住视线。若同一直线上且中间无墙，则视线畅通，$v$ 可见。反之，四个条件之一成立时按上面的推理都可见。证毕。

**引理 2**：从奖杯格沿 8 个方向投射射线所标记的格子集合，恰好等于所有能看见奖杯的格子。

*证明*：由引理 1，能看见奖杯的格子必然与奖杯在同一行 / 列 / 对角线上，且中间无墙。算法从奖杯出发沿 8 个方向逐格前进，只要遇到非墙格子就标记并继续，遇到墙或出界就停止，恰好标记了"该方向上与奖杯同行/列/对角线且中间无墙"的全部格子，再加上奖杯自身。反过来，射线标记的格子都满足引理 1 的条件，故都能看见奖杯。两个方向合起来得证。证毕。

**引理 3**：哈利从起点出发走 $t$ 步所能到达的格子集合，恰为无权图中起点距离不超过 $t$ 的顶点集合。

*证明*：把每个空地看作顶点、上下左右相邻的空地之间连一条权为 $1$ 的边，墙不参与建图。哈利的一次移动就是沿一条边走一步，$t$ 步就是沿 $t$ 条边的游走，其终点到起点的最短路长度不超过 $t$。反之，若某点到起点的最短路长度为 $d \le t$，沿最短路走 $d$ 步再原地不动 $t-d$ 步即可到达（题目只要求"尽早看到"，多走无意义）。故两集合相同。证毕。

**引理 4**：BFS 第一次取出的"能看见奖杯"的格子的距离，就是哈利最早能看到奖杯的时间。

*证明*：BFS 按距离从小到大的顺序逐层展开，节点出队时其 `dis` 值就是它到起点的最短路长度（无权图 BFS 的标准性质）。设首次出队的可见格为 $v$，$dis[v]=d$。由引理 3，哈利走 $d$ 步可以到达 $v$ 并看到奖杯；而任何走少于 $d$ 步能到达的格子都已先于 $v$ 出队且都不是可见格（否则 $v$ 就不是第一个），故哈利不可能在少于 $d$ 秒时看到奖杯。所以 $d$ 即最短时间。证毕。

**引理 5**：若 BFS 结束仍未找到任何可见格，则哈利无法看到奖杯。

*证明*：BFS 会访问起点所在连通块中的全部顶点。若其中存在可见格，它一定会被弹出（由引理 4 的论证），与"未找到"矛盾。因此哈利所在的连通块中不存在可见格。而哈利无法离开自己的连通块，故无论怎么走都看不到奖杯，输出 `Poor Harry` 正确。反之，若存在可见格但与哈利不连通（如奖杯被墙围住时只有奖杯格可见），哈利也到不了，结论同样成立。证毕。

**定理**：算法对每次询问输出的答案正确。

*证明*：由引理 2，标记的可见格集合完全正确；由引理 4，BFS 找到的最小距离就是最短时间；由引理 5，找不到时输出 `Poor Harry` 正确。证毕。

**引理 6**：本算法单次询问的时间复杂度为 $O(NM + N + M) = O(NM)$，空间复杂度为 $O(NM)$。

*证明*：8 条射线每条最多走 $\max(N,M)$ 步，共 $O(N+M)$；BFS 每个格子最多入队一次、每次考察 4 个邻居，共 $O(NM)$。两阶段合计 $O(NM)$。程序使用长度为 $NM$ 的 `g`、`see`、`vis`、`dis`、`Q` 五个数组，空间 $O(NM)$。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别题型** → "能看见的位置集合"（几何/射线）+ "最近能到达"（BFS）
2. **拆成两个子问题** → ①哪些格子能看见奖杯？②哈利最快到其中哪个？
3. **解决子问题 ①** → 从奖杯向 8 个方向投射射线，遇墙/出界停止 ⇒ 标记可见格；奖杯自身也算可见
4. **解决子问题 ②** → 无权图最短路 ⇒ BFS（只能上下左右，每步 1s ⇒ BFS 而非 Dijkstra）
5. **统一处理无解** → BFS 没找到可见格 ⇒ `Poor Harry`（奖杯被围住是其中一种情形）
6. **工程坑点** → ①坐标先行后列 ($x$ 为行 $1..N$，$y$ 为列 $1..M$)；②每行是 `ex ey sx sy`，奖杯在前；③$NM\le16384$ 但单边可达 16384 ⇒ **必须一维存储**；④多测要清空 `see`/`vis`/`dis`
7. **写代码** → 一维地图 → 每次询问：8 射线标记 → BFS → 输出

## 四、解法说明

### 算法

每次询问：射线标记可见格 + BFS 求最近可见格距离。

### 符号表

| 符号 | 含义 | 类型 | 初始化 / 记忆点 |
|------|------|------|----------------|
| $N$ | 迷宫的“行”数（高） | `int` | 输入 |
| $M$ | 迷宫的“列”数（宽） | `int` | 输入 |
| $g[i\cdot M+j]$ | 格子 $(i,j)$ 的内容，`'O'` 空地 / `'X'` 墙 | `char[]` | 一维存储，长度 $NM$ |
| $ex,ey$ | 奖杯坐标（行、列，1-based） | `int` | 每组询问输入 |
| $sx,sy$ | 哈利坐标（行、列，1-based） | `int` | 每组询问输入 |
| $see[u]$ | 格子 $u$ 是否能看见奖杯 | `bool[]` | 每次询问清零 |
| $vis[u]$ | 格子 $u$ 是否已被 BFS 访问 | `bool[]` | 每次询问清零 |
| $dis[u]$ | 哈利到格子 $u$ 的最短步数 | `int[]` | 每次询问置 $-1$ |
| $Q$ | BFS 队列 | `int[]` | 数组模拟队列 |
| $dx[8],dy[8]$ | 8 个方向的位移 | `int[]` | 视线方向 |
| $mx[4],my[4]$ | 4 个移动方向的位移 | `int[]` | 行走方向 |
| $ans$ | 答案 | `int` | 初始 $-1$，找不到时输出 `Poor Harry` |

### 算法步骤

1. 初始化 I/O 加速（`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`）。
2. 读入 $N, M$，再读入 $N\times M$ 个字符，存进一维数组 `g`（第 $i$ 行第 $j$ 列的字符是 `g[i*M+j]`，$i,j$ 从 $0$ 开始）。
3. 循环读入 `ex, ey, sx, sy`：
   1. 若 `ex == 0`，结束。
   2. 四个坐标全部减一，转成 0-based。
   3. 清空 `see`；置 `see[ex*M+ey] = true`（奖杯自身可见）。
   4. 对 8 个方向 $(dx[k],dy[k])$：从奖杯的相邻格出发，只要在界内且不是墙，就标记 `see` 并沿该方向再走一步；遇墙或出界则停止该方向。
   5. 清空 `vis`，把 `dis` 全部置 $-1$；哈利位置入队，`dis = 0`。
   6. BFS：取队首 $u$；若 `see[u]` 为真，记 `ans = dis[u]` 并结束 BFS；否则把四个方向的合法邻居（界内、非墙、未访问）入队，`dis` 加一。
   7. 若 `ans == -1` 输出 `Poor Harry`，否则输出 `ans`。
4. 每次询问独立处理，状态互不影响。

### 复杂度

- 单次询问时间复杂度：$O(NM)$（射线标记 $O(N+M)$，BFS $O(NM)$）。
- 总时间复杂度：$O(Q \cdot NM)$，其中 $Q \le 512$ 是询问数。
- 空间复杂度：$O(NM)$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2199 最后的迷宫
// 思路：对每次询问，先从奖杯向 8 个方向投射射线，标出所有能看见奖杯的格子
//       再从哈利的位置 BFS（只能上下左右走），取最近的「能看见奖杯」的格子
//       走不到任何这样的格子就输出 Poor Harry
//       N*M<=16384，用一维数组存地图
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{16389};

int n,m;
char g[mxn];
bool see[mxn],vis[mxn];
int dis[mxn],Q[mxn];

const int dx[8]={-1,-1,-1,0,0,1,1,1};
const int dy[8]={-1,0,1,-1,1,-1,0,1};
const int mx[4]={-1,1,0,0};
const int my[4]={0,0,-1,1};

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			cin>>g[i*m+j];

	int ex,ey,sx,sy;
	while(cin>>ex>>ey>>sx>>sy)
	{
		if(ex==0)break;
		--ex;--ey;--sx;--sy;
		// 奖杯所在的格子当然算「看得见」
		memset(see,0,sizeof(see));
		see[ex*m+ey]=1;
		for(int k=0;k<8;++k)
		{
			int x=ex+dx[k],y=ey+dy[k];
			while(x>=0&&x<n&&y>=0&&y<m&&g[x*m+y]!='X')
			{
				see[x*m+y]=1;
				x+=dx[k];
				y+=dy[k];
			}
		}
		memset(vis,0,sizeof(vis));
		memset(dis,-1,sizeof(dis));
		int hd=0,tl=0;
		Q[tl++]=sx*m+sy;
		vis[sx*m+sy]=1;
		dis[sx*m+sy]=0;
		int ans=-1;
		while(hd<tl)
		{
			int u=Q[hd++];
			if(see[u])
			{
				ans=dis[u];
				break;
			}
			int x=u/m,y=u%m;
			for(int k=0;k<4;++k)
			{
				int tx=x+mx[k],ty=y+my[k];
				if(tx<0||tx>=n||ty<0||ty>=m)continue;
				int v=tx*m+ty;
				if(vis[v]||g[v]=='X')continue;
				vis[v]=1;
				dis[v]=dis[u]+1;
				Q[tl++]=v;
			}
		}
		if(ans<0)cout<<"Poor Harry\n";
		else cout<<ans<<'\n';
	}
	return 0;
}
```

### 代码说明

- **一维存储**是本题的硬约束：`mxn{16389}` 对应 $NM \le 16384$。用 `g[i*m+j]` 表示第 $i$ 行第 $j$ 列（$i,j$ 均为 0-based），反解用 `x=u/m, y=u%m`。若用二维数组，`16384 × 16384` 的 `char` 也要 256 MB，直接 MLE。
- **两组方向数组**：`dx/dy` 是 8 个视线方向（用于射线标记），`mx/my` 是 4 个移动方向（用于 BFS）。这两者不能混用——哈利能斜着**看**，但只能直着**走**。
- **坐标顺序**：输入是 `ex ey sx sy`（奖杯在前、哈利在后），且 $x$ 为行（$1..N$）、$y$ 为列（$1..M$）。
- 射线循环中，`g[x*m+y]!='X'` 同时处理了"遇墙停止"和"空地继续"，出界条件写在 `while` 里。
- `see` 每次询问必须 `memset` 清零（可见格随奖杯位置变化），`vis`/`dis` 同样每次清空，避免多测串数据。
- `dis` 初始化为 $-1$ 兼作"未访问"标记，与 `vis` 配合使用。
- BFS 找到可见格时**立刻 break**，因为 BFS 出队顺序按距离递增，第一次命中就是最短距离。
- 换行使用 `'\n'`，`main` 正常结束 `return 0`。

### 验证状态

- 编译：`g++ -O2 -std=c++17` 通过，无警告。
- 官方样例两组全部通过：`3 4 / OXXO / XXOO / XOOO / 3 2 2 4 / 3 3 1 1 / 0 0 0 0` → 第一组 `1`，第二组 `Poor Harry`。
- 对拍：使用 `P2199_brute.cpp` 暴力做法（对每个格子独立判断是否与奖杯同行/列/对角且中间无墙，再对哈利的位置做一次 BFS 求最近可见格的最短步数），与标程在 2000 组随机数据上比对，全部一致。
