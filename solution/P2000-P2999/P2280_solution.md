# P2280 [HNOI2003] 激光炸弹 — 题解

## 一、解题过程：人类思考叙事

题意重述：地图上有 $n$ 个目标，第 $i$ 个在整点 $(x_i,y_i)$，价值 $v_i$（同一位置可能有多个目标，价值相加）。炸弹的爆破范围是一个**边长为 $m$、边与坐标轴平行**的正方形，**位于正方形边上的目标不会被摧毁**。问怎样投放能炸掉的总价值最大。数据范围 $n\le 10^4$，$0\le x_i,y_i\le 5000$，$1\le m\le 5000$，$v_i<100$，答案不超过 $32767$。

第一反应是枚举正方形的位置。但正方形的位置是**连续的**，左下角可以取任意实数，候选无穷多，直接枚举不可能。必须先把"连续"这个问题离散化。

关键问题是：一个边长为 $m$ 的开正方形，在一条坐标轴上到底能"框住"哪些整数坐标？先从一维想起。

- 取 $m=1$，目标在 $(0,0)$。单位正方形放在 $(-0.5,0.5)\times(-0.5,0.5)$ 就能把原点包在内部，所以边长 $1$ 能覆盖**一个**整数坐标，而不是零个。如果误以为"边长 $m$ 的格子覆盖 $m-1$ 个整点"，答案会直接错。
- 取 $m=1$，目标在 $0$ 和 $1$。任何长度为 $1$ 的开区间都不可能同时包含 $0$ 和 $1$（那需要右端点严格大于 $1$、左端点严格小于 $0$，长度就大于 $1$ 了）。所以一条边只能覆盖**连续的**若干整数坐标，个数不超过 $m$。
- 取 $m=2$，目标在 $(0,0)$ 与 $(1,1)$。正方形 $(-0.5,1.5)^2$ 把两个点都包住，所以 $m=2$ 确实能覆盖每条轴上连续 $2$ 个整数坐标。

于是猜想：**一维上，爆破区间摧毁的整数坐标集合，恰好可以是任意一段长度为 $m$ 的连续整数；而任何实际投放摧毁的集合，都含于某一段长度为 $m$ 的连续整数中。** 因为所有价值都是正的，把集合扩大只会让答案变大，所以最优投放一定对应"每条轴上恰好连续 $m$ 个整数坐标"。

这样问题就变成了：在 $0..5000$ 的坐标网格上，选一个 $m\times m$ 的**整点窗口**（横坐标连续 $m$ 个值、纵坐标连续 $m$ 个值），最大化窗口内目标价值之和。这是经典的二维前缀和问题：

1. 把坐标整体加 $1$，存进 $a[1..5001][1..5001]$，同一位置直接 `+=`；
2. 原地做二维前缀和；
3. 枚举所有右下角 $(i,j)$（$i,j\ge m$），用容斥取 $m\times m$ 窗口和，取最大值。

过程中踩过/需要提防的坑：

- **边界语义**：不是 $m-1$ 个点，也不是 $m+1$ 个点。开区间长度 $m$ 最多含 $m$ 个整数，而任意 $m$ 个连续整数都能通过把边界放在半整数处取到。
- **坐标平移**：目标坐标从 $0$ 开始，直接做前缀和会用到下标 $-1$；统一加 $1$ 后空出第 $0$ 行/列。
- **$m$ 很大**：$m=5000$ 时窗口只能从坐标 $0$ 或 $1$ 开始，并不是整张图；循环 $i=m..5001$ 正好只枚举这两个合法起点。若 $m>5001$（本题不会出现，但写成通用代码更稳），整个坐标范围都能被覆盖，把 $m$ 截到 $5001$ 即可。
- **内存**：$5001^2$ 个 `int` 约 $100$ MB。开两个这样的数组会翻倍，所以必须原地做前缀和。
- **重复目标**：同一位置用 `+=` 累加，不能赋值。

手工验证一组：$m=2$，目标 $(0,0,5),(1,0,7),(5,5,10)$。窗口 $x\in\{0,1\},y\in\{0,1\}$ 覆盖前两个，和 $12$；另外两个窗口都只能覆盖一个目标，故答案 $12$。程序输出 $12$，符合预期。

## 二、思维链：完整证明

### 引理 1（一维摧毁集合的形状）

设爆破正方形在 $x$ 轴上的投影是开区间 $(a,a+m)$。定义
$$S(a)=\{\,k\in\mathbb Z: a<k<a+m\,\}.$$
则 $S(a)$ 是若干连续整数（可以为空），且 $|S(a)|\le m$。

**证明**：若 $k_1,k_2\in S(a)$ 且 $k_1<k_2$，任取整数 $k$ 满足 $k_1<k<k_2$，则
$$a<k_1<k<k_2<a+m,$$
故 $k\in S(a)$。这说明 $S(a)$ 中任意两数之间的整数都在 $S(a)$ 中，即 $S(a)$ 是连续的一段整数（空集也视为连续）。

若 $S(a)\ne\varnothing$，令 $p=\min S(a)$，$q=\max S(a)$。由定义 $p>a$、$q<a+m$，两式相减得
$$q-p<(a+m)-a=m.$$
由于 $q-p$ 是整数，故 $q-p\le m-1$，从而 $|S(a)|=q-p+1\le m$。$\square$

### 引理 2（任意连续 $m$ 个整数都可取到）

对任意整数 $x_0$，令 $B_{x_0}=\{x_0,x_0+1,\dots,x_0+m-1\}$。则存在实数 $a$ 使 $S(a)=B_{x_0}$。

**证明**：取 $a=x_0-\tfrac12$，则区间为 $\left(x_0-\tfrac12,\ x_0+m-\tfrac12\right)$。

- 对 $k\in B_{x_0}$，有 $x_0-\tfrac12<k<x_0+m-\tfrac12$，故 $k\in S(a)$；
- 对 $k\le x_0-1$，有 $k<x_0-\tfrac12=a$，不在区间内；
- 对 $k\ge x_0+m$，有 $k>x_0+m-\tfrac12=a+m$，不在区间内。

所以 $S(a)=B_{x_0}$。$\square$

### 引理 3（一维问题化归为窗口最大值）

固定纵坐标上的摧毁集合，则横坐标方向的最优投放可以取成某个完整窗口 $B_{x_0}$，且最优值等于
$$\max_{x_0\in\mathbb Z}\ \sum_{i:\ x_i\in B_{x_0}} v_i.$$

**证明**：任取一个投放，其横坐标摧毁集合为 $S$。由引理 1，$S$ 是连续的且 $|S|\le m$。若 $S=\varnothing$，任取一个窗口 $B$，它覆盖的目标价值不少于 $0$，不劣于当前投放。

若 $S\ne\varnothing$，令 $p=\min S$、$q=\max S$，则 $q-p\le m-1$。取 $x_0=q-m+1$，则
$$x_0=q-m+1\le p,\qquad x_0+m-1=q,$$
故 $S\subseteq B_{x_0}$。由引理 2，$B_{x_0}$ 可以被某个真实投放取到。把横坐标集合从 $S$ 扩大到 $B_{x_0}$，只可能增加被摧毁的目标（所有 $v_i>0$），因此该投放不劣于原投放。所以最优值一定能在完整窗口上取到；反过来每个窗口都能被真实投放取到，故最大值公式成立。$\square$

### 引理 4（二维化归）

设一次投放的横、纵摧毁集合分别为 $S_x,S_y$，摧毁的目标集合为 $\{(x_i,y_i):x_i\in S_x,\ y_i\in S_y\}$。则存在完整窗口 $B_x,B_y$（各含 $m$ 个连续整数）使得
$$\sum_{x_i\in S_x,y_i\in S_y}v_i\le \sum_{x_i\in B_x,y_i\in B_y}v_i,$$
且每个完整窗口都能被真实投放取到。因此二维最优值等于所有 $m\times m$ 整点窗口和的最大值。

**证明**：由引理 3 的构造，存在完整窗口 $B_x\supseteq S_x$ 与完整窗口 $B_y\supseteq S_y$。目标集合从 $S_x\times S_y$ 扩大到 $B_x\times B_y$ 只会增加元素，且所有价值为正，故价值和不变小。两个方向的正方形边界可以独立选取（横纵投影互不影响），由引理 2 可同时取到 $B_x,B_y$，因此每个完整窗口都对应一次真实投放，其价值和可以被实际取到。$\square$

### 引理 5（只需枚举有限的窗口起点）

当 $1\le m\le 5001$ 时，所有目标坐标都在 $[0,5000]$，只需枚举 $x_0,y_0\in[0,5000-m+1]$。

**证明**：任取整数 $x_0$。记窗口 $B_{x_0}$ 与 $[0,5000]$ 的交集为 $T$。

- 若 $T=\varnothing$，窗口不覆盖任何目标，价值和为 $0$，不会优于任何覆盖了正价值目标的窗口（$n\ge1$，$v_i>0$）。
- 若 $x_0<0$，则 $T\subseteq\{0,1,\dots,m-1\}=B_0$，且 $0$ 在枚举范围内（因 $m\le5001$）。
- 若 $x_0>5000-m+1$，则 $T\subseteq\{5000-m+1,\dots,5000\}=B_{5000-m+1}$，该起点也在枚举范围内。
- 否则 $0\le x_0\le5000-m+1$，本身就在枚举范围内。

由于目标价值均为正，把 $T$ 替换为包含它的那个枚举窗口不会减小价值和。纵坐标同理。故最大值必在枚举范围内取到。若 $m\ge5001$，窗口 $B_0=\{0,\dots,m-1\}$ 包含全部坐标 $0..5000$，把 $m$ 截为 $5001$ 后枚举 $B_0$ 即可得到全部目标之和。$\square$

### 引理 6（二维前缀和与容斥）

把坐标平移后，令 $P[i][j]$ 表示矩形 $[1,i]\times[1,j]$ 内所有目标价值之和。则
$$P[i][j]=a[i][j]+P[i-1][j]+P[i][j-1]-P[i-1][j-1],$$
且窗口 $[i-m+1,i]\times[j-m+1,j]$ 的价值和为
$$P[i][j]-P[i-m][j]-P[i][j-m]+P[i-m][j-m].$$

**证明**：第一个式子按 $a[i][j]$ 是否被计入分类：$P[i-1][j]$ 覆盖 $[1,i-1]\times[1,j]$，$P[i][j-1]$ 覆盖 $[1,i]\times[1,j-1]$，二者并集是 $[1,i]\times[1,j]$ 去掉单点 $(i,j)$，交集是 $[1,i-1]\times[1,j-1]$，由容斥即得。

第二个式子：$P[i][j]$ 是左下角为 $(1,1)$、右上角为 $(i,j)$ 的大矩形。减去上方 $[1,i-m]\times[1,j]$ 与左方 $[1,i]\times[1,j-m]$ 后，左上角 $[1,i-m]\times[1,j-m]$ 被减了两次，加回一次，剩下的正是目标窗口。$\square$

### 定理（算法正确性）

算法枚举了所有可能的完整 $m\times m$ 整点窗口并取最大前缀和。由引理 1–4，任一真实投放的收益都不超过某个完整窗口的收益，而每个完整窗口都能由真实投放实现；由引理 5，最优窗口的起点必在枚举范围内；由引理 6，前缀和容斥算出的正是窗口价值。故输出即为答案。$\square$

### 复杂度

坐标范围为 $5001\times5001$。前缀和 $O(5001^2)$，枚举窗口 $O(5001^2)$，读入 $O(n)$。总时间 $O(5001^2+n)$，空间 $O(5001^2)$，约 $100$ MB。$\square$

## 三、模式总结（按实际思考顺序）

- explore its property — 边长 $m$ 的开正方形在一条轴上摧毁的整数集合是连续的一段，且长度不超过 $m$。
- consider easier version — 先做一维：把连续投放化归为"连续 $m$ 个整数坐标"的窗口。
- explore its property — 任意连续 $m$ 个整数都能通过把边界放在半整数处实现，故窗口集合与可行投放等价。
- reduce to easier problem — 二维的横纵投影互相独立，分别取完整窗口，问题化为 $m\times m$ 整点窗口最大值。
- classic problem solution — 二维前缀和 + 容斥，枚举所有窗口右下角。
- discuss by category — 窗口起点越界时向 $[0,5000]$ 内收缩不劣；$m\ge5001$ 时退化为全图。
- handle implementation details — 坐标 $+1$ 平移、同点价值累加、原地前缀和控内存。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 说明 |
|------|------|-------------|
| $n$ | 目标个数 | 输入，$n\le10^4$ |
| $m$ | 爆破正方形边长 | 输入；若大于 $5001$ 截为 $5001$ |
| $a[i][j]$ | 坐标 $(i-1,j-1)$ 上的目标总价值；做完前缀和后变为 $P[i][j]$ | 全局 `int`，初值 $0$，同点 `+=` |
| $P[i][j]$ | 平移后矩形 $[1,i]\times[1,j]$ 的价值和 | 由 $a$ 原地递推 |
| $ans$ | 所有 $m\times m$ 窗口和的最大值 | 初值 $0$ |
| $i,j$ | 窗口右下角坐标（平移后） | $m\le i,j\le5001$ |

### 算法步骤

1. 读入 $n,m$；对每个目标读入 $x,y,v$，执行 `a[x+1][y+1]+=v`。
2. 对 $i=1..5001$、$j=1..5001$，原地计算二维前缀和 `a[i][j]+=a[i-1][j]+a[i][j-1]-a[i-1][j-1]`。
3. 若 $m>5001$，令 $m=5001$（覆盖全部坐标）。
4. 枚举 $i=m..5001$、$j=m..5001$，用容斥计算窗口和并更新 `ans`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(5001^2+n)$，约 $2.5\times10^7$ 次整数运算。
- 空间：$O(5001^2)$，约 $100$ MB。

### 验证状态

已用 `g++ -std=c++20 -O2` 编译通过；与枚举所有窗口起点的暴力在 $120$ 组随机小数据上完全一致，并手工验证了 $m=1$ 边界、同点重复、$m=5000$ 跨全图等 $5$ 组用例。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{5005};

int n,m,a[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,x,y,v;i<n;++i)
	{
		cin>>x>>y>>v;
		a[x+1][y+1]+=v;
	}
	for(int i=1;i<=5001;++i)
		for(int j=1;j<=5001;++j)
			a[i][j]+=a[i-1][j]+a[i][j-1]-a[i-1][j-1];
	if(m>5001)
		m=5001;
	int ans=0;
	for(int i=m;i<=5001;++i)
		for(int j=m;j<=5001;++j)
			ans=max(ans,a[i][j]-a[i-m][j]-a[i][j-m]+a[i-m][j-m]);
	cout<<ans<<'\n';
	return 0;
}
```
