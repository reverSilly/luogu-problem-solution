# P2298 Mzc和男家丁的游戏 — 题解

## 一、解题过程：人类思考叙事

先把题面翻译成一句人话：给一张 $n\times m$ 的格子图（$3\le n,m\le 2000$），`m` 是 mzc 的位置，`d` 是男家丁的位置，`#` 是不能走的墙，`.` 是空地。mzc 每一步只能走到**上下左右相邻**的非墙格子里；走一步算一次移动。问从 `m` 走到 `d` 最少要移动多少次；走不到就输出 `No Way!`。

**第一反应：搜。** 从 `m` 出发 DFS，枚举所有路径，到 `d` 时更新最小值。写之前先估一下规模：格子最多 $2000\times 2000=4\times 10^6$ 个。DFS 的两条死路立刻暴露：

1. 路径数量是**指数级**的。只要图里有环（空地上到处都是环），同一个格子可以被不同路径反复经过，枚举不完。
2. 即使数据很争气地只有少量路径，**递归深度**也可能到 $4\times 10^6$，系统栈根本撑不住，直接 RE。

所以 DFS 这条路既超时又爆栈，必须放弃。

**换个角度：这其实是一张图。** 把每个非墙格子看成一个点，上下左右相邻的两个非墙格子之间连一条边。mzc 移动一次 = 在图上走一条边。「最少移动次数」= 从 `m` 对应的点走到 `d` 对应的点的**最短路边数**。

关键观察：**每条边的代价都是 $1$**（走一步就是一步，没有权重差异）。这种「边权全为 1」的图叫无权图，它的单源最短路不需要 Dijkstra，用 **BFS** 就够：BFS 按「离起点几层」由近到远地扩展，第一次碰到目标时走过的层数就是最短距离。

而且 BFS 的每个格子**最多入队一次**，天然满足「每个格子只处理一次」的要求，正好补上 DFS 的两个洞。到这里算法就定了：从 `m` 出发做 BFS，第一次弹出 `d` 时输出它的层数。

**工程上的坑，逐个排掉。**

坑一：**队列要自己开数组。** 用全局数组 `int Q[mxn*mxn]`（`mxn=2005`）加头尾指针 `hd/tl` 模拟队列，比 `queue<int>` 常数更小，也避免 `pair` 拆包的开销；$4\times 10^6$ 个 `int` 是 16 MB，可以接受。

坑二（最阴的一个）：**全局 `int` 数组的初值是 $0$，不是 $-1$。** 如果我用 `dis[x][y] != -1` 判断「是否访问过」，而 `dis` 没有初始化，那么所有格子的 `dis` 都是 $0$，看起来全都「访问过」。于是起点一入队，四个邻居全被判成已访问，队列立刻空掉，程序永远输出 `No Way!`。所以必须显式 `fill_n(..., -1)`。同时 `dis = -1` 也顺便充当了访问标记，不必再开一个 `vis` 数组。

坑三：**答案的量级**。最长最短路径不超过格子总数 $4\times 10^6$，`int` 足够，不需要 64 位。

坑四：**多个 `d` 怎么办？** 题面说「一次只需要找一个男家丁」，输入正常只有一个 `d`。不过代码写成「第一个弹出的 `d` 就返回」之后，即使有多个 `d`，拿到的也是最近的那个，不需要额外处理。

坑五：**无解判定**。BFS 会把起点所在的整个连通块都访问一遍。如果队列空了都没见到 `d`，说明 `d` 不在起点连通块里，怎么走都到不了，输出 `No Way!` 即可，不需要单独判断「被墙围住」。

**自己造两组数据验证思路。** 题面没有样例，手造：

```
3 3
m.#
...
##d
```
起点 $(1,1)$，目标 $(3,3)$。可走的路线有 $(1,1)\to(1,2)\to(2,2)\to(2,3)\to(3,3)$ 与 $(1,1)\to(2,1)\to(2,2)\to(2,3)\to(3,3)$，都是 $4$ 步，程序应输出 `4`。

```
3 3
m#.
#.#
#.d
```
$(1,1)$ 的右邻 $(1,2)$ 与下邻 $(2,1)$ 都是墙，起点被彻底封死，程序应输出 `No Way!`。

两个手造例子的实际运行结果分别是 `4` 与 `No Way!`，与推理一致。

## 二、思维链：完整证明

先固定记号。设 $V$ 为所有满足 $g\ne$ `#` 的格子，$s$ 为 `m` 所在格子，$t$ 为 `d` 所在格子。构造无向图 $G=(V,E)$，其中
$$E=\bigl\{\{u,v\}: u,v\in V,\ u,v\ \text{上下左右相邻}\bigr\}.$$
记 $\delta(v)$ 为 $G$ 中 $s$ 到 $v$ 的最短路边数（不可达时为 $+\infty$）。

**引理 1（图模型等价）**：mzc 的任意一个合法移动序列，与 $G$ 中从 $s$ 出发的一条 walk（允许重复经过点的路径）一一对应；「用 $k$ 步从 $s$ 走到 $x$」当且仅当 $G$ 中存在一条长度为 $k$ 的 $s\to x$ walk。特别地，最少移动次数 $=\delta(t)$。

*证明*：mzc 每一步从格子 $u$ 走到上下左右相邻的格子 $v$。由 $V$ 的定义，走过的格子都非墙，所以 $u,v\in V$ 且 $\{u,v\}\in E$，这一步就是沿边 $(u,v)$ 走一次。反过来，$G$ 中每条边都连接两个上下左右相邻的非墙格，沿这条边走一步就是一次合法移动。于是长度为 $k$ 的移动序列与长度为 $k$ 的 walk 逐个对应，两者集合相同。对 $k$ 取下确界即得最少移动次数 $=\delta(t)$。证毕。

**引理 2（赋值的下界性）**：BFS 在任意时刻给某点 $v$ 赋的值 $dis[v]$，都满足 $\delta(v)\le dis[v]$。

*证明*：对赋值发生的先后顺序做归纳。第一次赋值是 $dis[s]=0$，对应长度为 $0$ 的空 walk，$\delta(s)=0$，成立。之后每次赋值形如 $dis[v]=dis[u]+1$，其中 $u$ 是当前弹出的点。由归纳假设，存在长度 $dis[u]$ 的 $s\to u$ walk，在它末尾接上边 $(u,v)$，得到长度 $dis[u]+1$ 的 $s\to v$ walk，故 $\delta(v)\le dis[u]+1=dis[v]$。证毕。

**引理 3（队列按距离不降）**：BFS 运行过程中，任意时刻队列里的 `dis` 值按入队顺序单调不减，并且队尾的值不超过队首的值加 $1$。

*证明*：记队列为 $q_1,\dots,q_r$，证明不变量
$$\mathrm{(I)}\quad dis[q_1]\le dis[q_2]\le\cdots\le dis[q_r]\le dis[q_1]+1 .$$
初始时队列只有 $s$，$dis[s]=0$，不变量成立。设某时刻不变量成立，执行一次「弹出队首 $q_1$，并把若干新点接到队尾」：

- 弹出后剩下 $q_2,\dots,q_r$，它们内部的单调性来自 (I)。新的队首是 $q_2$（若队列非空）。由 (I)，$dis[q_2]\in\{dis[q_1],dis[q_1]+1\}$（整数且不小于 $dis[q_1]$）。若 $dis[q_2]=dis[q_1]+1$，则 $dis[q_r]\le dis[q_1]+1=dis[q_2]\le dis[q_2]+1$；若 $dis[q_2]=dis[q_1]$，则 $dis[q_r]\le dis[q_1]+1=dis[q_2]+1$。两种情况都有 $dis[q_r]\le dis[q_2]+1$，而 $q_2,\dots,q_r$ 的单调性未变，故 (I) 对剩余队列成立。
- 新入队的点都由 $q_1$ 扩展而来，值全为 $dis[q_1]+1$，它们彼此相等；且 $dis[q_r]\le dis[q_1]+1$，故接在队尾后仍然单调；新队尾的值 $dis[q_1]+1$ 与新队首 $dis[q_2]$ 之差不超过 $1$（上面已算过 $dis[q_2]\in\{dis[q_1],dis[q_1]+1\}$）。

于是 (I) 在每次操作后保持。而 (I) 直接蕴含「弹出顺序的 `dis` 值单调不减」：被弹出的永远是当前队首，弹出后新队首的值不小于旧队首的值。证毕。

**引理 4（分层不变量）**：对每个 $d\ge 0$，在「第一个 `dis` 值为 $d+1$ 的点被弹出」这一时刻之前，下列两件事已经成立：

1. 所有满足 $\delta\le d$ 的点都已被弹出；
2. 所有满足 $\delta=d+1$ 的点都已入队，且入队时的值是 $d+1$。

*证明*：对 $d$ 归纳。

$d=0$：$s$ 是唯一 $\delta=0$ 的点，它第一个被弹出，弹出时扫描四邻居，把所有未访问的邻居以值 $1$ 入队。这些邻居恰是 $\delta=1$ 的全部点（它们与 $s$ 相邻，且由引理 2 入队值 $\ge\delta=1$，而实际赋的是 $1$），且 $s$ 弹完后队首的值若存在即为 $1$。故结论成立。

设结论对 $d-1$ 成立。由归纳假设，在第一个值为 $d$ 的点弹出前，所有 $\delta\le d-1$ 的点已弹出、所有 $\delta=d$ 的点已入队且值为 $d$。注意此时队列里不存在值 $<d$ 的点（值 $<d$ 的点都已弹出），所以接下来弹出的全是值为 $d$ 的点，直到它们耗尽——这正是由引理 3 的单调性保证的：值 $d$ 的点全排在值 $d+1$ 的点前面。

考察任意一个 $\delta=d$ 的点 $u$ 被弹出时的扫描。设 $v$ 是 $u$ 的未访问邻居。一方面 $v$ 与 $u$ 相邻，$\delta(v)\le d+1$；另一方面，在扫描 $u$ 的时刻，所有 $\delta\le d$ 的点要么已弹出、要么已入队（$\delta<d$ 的已弹出，$\delta=d$ 的此刻正在被弹出、之前已入队），因此「未访问」迫使 $\delta(v)\ge d+1$。两式合并得 $\delta(v)=d+1$。于是 $v$ 以值 $dis[u]+1=d+1$ 入队，由引理 2 这个值恰为 $\delta(v)$。

再证所有 $\delta=d+1$ 的点都会入队：任取这样的点 $v$，取一条最短路 $s=w_0,\dots,w_{d+1}=v$，则 $\delta(w_d)=d$，$w_d$ 会在本层被弹出（上面已说明值 $d$ 的点会全部弹出），弹出时 $v$ 若未访问则以值 $d+1$ 入队，若已访问则它更早已经以值 $d+1$ 入队。故结论 2 成立，结论 1 也随 $d$ 的推进成立。证毕。

**推论 1（`dis` 精确）**：任何入队的点 $v$ 都满足 $dis[v]=\delta(v)$。

*证明*：$v=s$ 时 $dis[s]=0=\delta(s)$，成立。否则 $v$ 是在某个值 $d$ 的点 $u$ 被弹出时入队的，由引理 4 的论证，$v$ 未访问 $\Rightarrow\delta(v)=d+1$，且 $dis[v]=d+1$。证毕。

**推论 2（首次弹出 `d` 即最优）**：BFS 第一次弹出的 `d` 格子，其 `dis` 就是 $\delta(t)$。

*证明*：由引理 3，弹出顺序的 `dis` 单调不减；由推论 1，每个点的 `dis` 都等于其真实最短距离。因此第一个被弹出的 `d` 格子在所有 `d` 格子中 $\delta$ 最小，而 $\delta(t)=\min\{\delta(x): g[x]=\texttt{d}\}$。证毕。

**引理 5（无解判定）**：若 BFS 队列为空时仍未弹出任何 `d`，则 $t\notin$ 起点所在连通块，即 $\delta(t)=+\infty$。

*证明*：先证「BFS 恰好访问起点连通块」。一方面，任何入队的点都是从一个已入队的点沿边扩展来的，由归纳法它到 $s$ 存在一条 walk，故与 $s$ 连通；另一方面，任取与 $s$ 连通的点 $v$，取一条 $s\to v$ 的 walk，对 walk 上位置归纳：$s$ 已入队，若第 $i$ 个点已入队，它终将被弹出（队列先进先出，元素不会丢失），弹出时若第 $i+1$ 个点未访问则把它入队，故第 $i+1$ 个点也会入队，归纳得 $v$ 入队。两边合起来即「访问集合 = 连通块」。因此若某个 `d` 格子与 $s$ 连通，它必然入队并被弹出（推论 1 的论证），与「队列空仍无 `d`」矛盾。故不存在与 $s$ 连通的 `d` 格子，mzc 无论怎么走都碰不到男家丁，输出 `No Way!` 正确。证毕。

**定理**：程序输出正确。

*证明*：若 $t$ 可达，由推论 2 输出的 `dis` 等于 $\delta(t)$，再由引理 1 它就是最少移动次数；若 $t$ 不可达，由引理 5 输出 `No Way!`。证毕。

**引理 6（复杂度）**：时间 $O(nm)$，空间 $O(nm)$。

*证明*：每个格子至多入队一次（入队时立刻把 `dis` 置为非 $-1$，此后不会再被放入），每次弹出只考察 $4$ 个邻居，故总操作数是 $O(nm)$。空间上 `g`、`dis`、`Q` 各占 $O(nm)$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 移动只能在上下左右相邻的非墙格之间进行，且每步代价恒为 $1$，把网格抽象成「点 = 非墙格、边 = 相邻关系」的无权图。
- **consider easier version** — 去掉「找 `d`」的目标，先问「从 `m` 出发走 $k$ 步能到哪些格子」，这就是无权图的按层扩展。
- **识别 DFS 的死因** — 路径数指数级 + 递归深度 $4\times 10^6$ 会爆栈，因此必须「每格只处理一次」且迭代实现。
- **classic problem solution** — 无权图单源最短路用 BFS，配数组模拟队列，$O(nm)$。
- **explore its property** — BFS 弹出顺序的 `dis` 单调不减，所以第一次弹出 `d` 就可以立刻停，不必跑完全图。
- **reduce to easier problem** — 无解判定退化为「起点连通块里有没有 `d`」，队列跑空即无解，不需要单独判「被墙围住」。
- **排查实现坑** — 全局 `int dis` 初值是 $0$，必须 `fill_n(..., -1)`，否则所有格子都像「已访问」，队列一步也走不出去。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 行数 | 读入 |
| $m$ | 列数 | 读入 |
| `g[i][j]` | 第 $i$ 行第 $j$ 列的字符（`m`/`d`/`.`/`#`） | 读入，0-based |
| `dis[i][j]` | 从 `m` 到 $(i,j)$ 的最短步数，兼作访问标记 | 全置 $-1$；起点为 $0$ |
| `Q[]` | 数组模拟的 BFS 队列，存一维编号 $x\cdot m+y$ | `hd=tl=0` |
| `sx,sy` | `m` 的坐标 | 读入时顺带记录 |
| `ans` | 第一次弹出的 `d` 的距离 | $-1$ 表示没找到 |
| `dx[4],dy[4]` | 上下左右四个方向 | 常量 |

### 算法步骤

1. 读入 $n,m$，逐字符读入网格，记录 `m` 的位置 $(sx,sy)$。
2. 把 `dis` 全部置 $-1$；`Q[0]=sx*m+sy`，`tl=1`，`dis[sx][sy]=0`。
3. 当 `hd<tl` 时循环：
   1. 取出队首 $u$，反解 $x=u/m,\;y=u\bmod m$。
   2. 若 `g[x][y]=='d'`，令 `ans=dis[x][y]` 并跳出循环。
   3. 否则枚举四个方向 $(tx,ty)$；若在界内、不是 `#`、且 `dis[tx][ty]==-1`，则置 `dis[tx][ty]=dis[x][y]+1` 并把 $tx\cdot m+ty$ 入队。
4. 若 `ans<0` 输出 `No Way!`，否则输出 `ans`。

### 复杂度

- 时间复杂度：$O(nm)$（每格至多入队、出队一次，每次检查 $4$ 个邻居）。
- 空间复杂度：$O(nm)$（`g`、`dis`、`Q` 三个大小为 $nm$ 量级的数组）。
- 极限数据 $2000\times2000$ 全空地图上实测约 $0.15$ s，远低于 $1$ s。

### 验证状态

- 编译：`g++ -std=c++20 -O2 -Wall` 无错误无警告。
- 题面无样例，手造 2 组（可走 4 步、被墙封死）分别输出 `4` 与 `No Way!`，与手算一致。
- 对拍：另写 Bellman-Ford 式松弛暴力（完全不复用 BFS 分层思想），在 $3\le n,m\le 8$、随机墙密度的 $300$ 组数据上与标程逐个比对，**0 mismatch**（含大量无解数据）。
- 极限规模 $2000\times2000$ 空白地图（答案 $3998$）运行 $0.15$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2298 Mzc和男家丁的游戏
// 思路：把非墙格子看成无权图的点，mzc 每次上下左右走一步 = 走一条边
//       从 'm' 出发 BFS，第一次弹出 'd' 时的距离就是最短移动次数
//       弹完队列仍没见到 'd' => 不连通 => No Way!
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005};

int n,m,sx,sy;
char g[mxn][mxn];
int dis[mxn][mxn];      // 全局 int 默认 0，必须手动置 -1
int Q[mxn*mxn];         // 4e6 个格子，递归会爆栈，用数组模拟队列

const int dx[4]={-1,1,0,0};
const int dy[4]={0,0,-1,1};

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
		{
			cin>>g[i][j];
			if(g[i][j]=='m')
			{
				sx=i;
				sy=j;
			}
		}

	fill_n(&dis[0][0],mxn*mxn,-1);
	int hd=0,tl=0,ans=-1;
	Q[tl++]=sx*m+sy;
	dis[sx][sy]=0;
	while(hd<tl)
	{
		int u=Q[hd++];
		int x=u/m,y=u%m;
		if(g[x][y]=='d')
		{
			ans=dis[x][y];
			break;
		}
		for(int k=0;k<4;++k)
		{
			int tx=x+dx[k],ty=y+dy[k];
			if(tx<0||tx>=n||ty<0||ty>=m)
				continue;
			if(g[tx][ty]=='#'||dis[tx][ty]!=-1)
				continue;
			dis[tx][ty]=dis[x][y]+1;
			Q[tl++]=tx*m+ty;
		}
	}
	if(ans<0)
		cout<<"No Way!\n";
	else
		cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `dis` 既存距离又当访问标记：`-1` 表示未访问。**不要**省略 `fill_n`——全局数组默认全 $0$，会把所有格子误判成已访问。
- 队列用一维数组 `Q` 存 `x*m+y`，出队时用 `u/m, u%m` 反解坐标，省掉一个 `pair` 队列的开销。
- 弹出时先判 `d` 再扩展：因为 BFS 的弹出顺序按距离非降，第一次命中就是最优，可以直接 `break`（引理 3 + 推论 2）。
- 若 `ans` 仍为 $-1$，说明 `d` 与 `m` 不连通，输出 `No Way!`。
- 方向数组只有 $4$ 个：只能上下左右走，不能走斜线；八方向是「视线」类题目的设定，和本题无关。
