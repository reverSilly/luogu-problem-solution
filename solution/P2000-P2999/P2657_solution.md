# P2657 [SCOI2009] windy 数 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一个正整数叫 windy 数，当且仅当它**不含前导零**且**相邻两个数字之差的绝对值至少为 $2$**。给定 $1\le a\le b\le 2\times10^9$，求 $[a,b]$ 里 windy 数的个数。注意"差至少为 $2$"是**绝对值**差：$13$ 合法（$|1-3|=2$），$12$ 不合法（$|1-2|=1$），$20$ 合法（$|2-0|=2$），$11$ 不合法（差 $0$）。单个数字 $1\sim9$ 没有"相邻对"，约束空成立，所以它们都是 windy 数。

**第一反应：暴力枚举。** 从 $a$ 到 $b$ 逐个判断。但 $b-a$ 最大接近 $2\times10^9$，每个数还要拆位，妥妥超时。数据范围 $2\times10^9$ 只有 $10$ 位，这是在明示：**按数位结构计数**，而不是按数值枚举。标签里的"数位 DP / 记忆化搜索"也印证了方向。

**第二步：区间转前缀。** 计数问题里"求 $[a,b]$"几乎总是先拆成两个前缀：
$$\text{ans}=\mathrm{count}(b)-\mathrm{count}(a-1),$$
其中 $\mathrm{count}(x)$ 表示 $[1,x]$ 里 windy 数的个数。这一步把"任意区间"归约成"从 $1$ 开始的前缀"，后者才能用数位 DP 逐位卡上界。因为 $a\ge1$，所以 $a-1\ge0$；约定 $\mathrm{count}(0)=0$（$0$ 不是正整数，更不是 windy 数），边界就闭合了。

**第三步：$\mathrm{count}(x)$ 怎么逐位填。** 把 $x$ 写成十进制位 $d_{L-1}d_{L-2}\dots d_0$（高位在前，$L\le10$）。我们从最高位往最低位一位一位地填数字，填出来的数必须 $\le x$。填的过程中要维护两件事：

1. **是否贴着上界（tight）**：如果前面填的每一位都恰好等于 $x$ 对应位，那么当前位最多只能填到 $d_{pos}$；一旦某位填得比 $d_{pos}$ 小，后面就彻底自由（$0\sim9$ 随便填）。
2. **上一位填了什么（pre）**：windy 的约束是"相邻两位差 $\ge2$"，所以只要知道**上一位**就能判断当前位合不合法——这是一个**只耦合相邻位**的局部约束，不需要记住更早的历史。

**第四步：本题真正的坑——前导零。** windy 数"不含前导零"，但我们逐位填的时候，位数比 $x$ 少的数（比如 $x=100$ 时的 $5$、$13$）必须靠"前面填 $0$"来表示：$5$ 写成 $005$，$13$ 写成 $013$。这些 $0$ 是**占位的前导零，不是数字本身的位**。于是：

- 在还没遇到第一个非零位之前（记状态 `lead=true`），填 $0$ 只是继续占位，**不能**拿它去和后面算"相邻差"——否则 $005$ 会被误判成"$0$ 和 $0$ 差 $0<2$"而错杀。
- 一旦填了第一个非零位 $d$，数字才真正开始，`lead` 变 `false`，`pre=d`，从这一刻起才启用"差 $\ge2$"约束。
- 如果一路填到底全是 $0$（`lead` 始终 `true`），那代表数字 $0$，**不是** windy 数，要排除。

我把"前导零阶段"和"正式数字阶段"用一个布尔 `lead` 分开，前导零阶段把 `pre` 统一记成哨兵 $10$（一个不可能与任何真实数字 $0\sim9$ 混淆的值），这样记忆化时 `lead=true` 的状态能正确合并——因为此阶段 `pre` 根本不参与判断。

**第五步：记忆化。** 当 `tight=false` 时，"从第 `pos` 位往后、上一位是 `pre`、是否仍在前导零 `lead`"这三元组就**完全决定**了后续合法填法的数量，与更前面具体填了什么无关。于是开 `f[pos][pre][lead]` 记忆化，每个状态只算一次。状态数约 $L\times11\times2$，每个状态枚举 $10$ 个数字，总量小到可以忽略。

**手造数据核对**（题面没有给样例，我按定义手算了几组，再用程序核对）：

- $[1,10]$：$1\sim9$ 都是 windy（$9$ 个），$10$ 的差是 $1$ 不合法 ⇒ 答案 $9$。
- $[1,25]$：一位数 $9$ 个；两位数里 $13,14,15,16,17,18,19$（$7$ 个，$12$ 差 $1$ 不行、$10/11$ 不行），$20$（差 $2$）、$24$（差 $2$）、$25$（差 $3$）合法，$21/22/23$ 不行 ⇒ 两位共 $10$ 个；合计 $19$。
- $[13,13]$：$13$ 差 $2$ 合法 ⇒ $1$；$[12,12]$：差 $1$ ⇒ $0$；$[20,20]$：差 $2$ ⇒ $1$。
- $[1,1]$：只有 $1$ ⇒ $1$。

程序输出与这些手算逐条吻合。另外用"逐个判断"的独立暴力在 $300$ 组随机区间（$b\le2\times10^4$）上对拍，$0$ mismatch，重点覆盖了前导零与多位边界。

## 二、思维链：完整证明

**记号。** 对正整数 $n$，其**规范十进制表示**为 $n=\overline{c_{k-1}c_{k-2}\dots c_0}$，其中 $c_{k-1}\ne0$（无前导零），$k\ge1$ 是位数。定义谓词
$$\mathrm{Windy}(n)\iff \forall\,1\le i\le k-1:\ |c_i-c_{i-1}|\ge2.$$
当 $k=1$ 时全称量词范围为空，$\mathrm{Windy}(n)$ 恒真。$\mathrm{count}(x)=\#\{n:1\le n\le x,\ \mathrm{Windy}(n)\}$，约定 $\mathrm{count}(0)=0$。$x$ 的位数组为 $d_{L-1}\dots d_0$（高位在前，$d_{L-1}\ne0$ 当 $x\ge1$）。

---

### 引理 1（前缀差分）

对 $1\le a\le b$，$[a,b]$ 内 windy 数个数 $=\mathrm{count}(b)-\mathrm{count}(a-1)$。

*证明*：设 $S(t)=\{n:1\le n\le t,\mathrm{Windy}(n)\}$。因 $a\ge1$，有 $a-1\ge0$。集合 $\{n:a\le n\le b\}=\{n:1\le n\le b\}\setminus\{n:1\le n\le a-1\}$，且后者是前者的子集（$a-1<b$）。windy 是正整数的性质，故交上 $\mathrm{Windy}$ 后仍有 $S(b)\setminus S(a-1)=\{n:a\le n\le b,\mathrm{Windy}(n)\}$，且 $S(a-1)\subseteq S(b)$。有限集合差的基数等于基数差：$|S(b)\setminus S(a-1)|=|S(b)|-|S(a-1)|=\mathrm{count}(b)-\mathrm{count}(a-1)$。当 $a=1$ 时 $S(0)=\varnothing$，$\mathrm{count}(0)=0$，公式仍成立。证毕。

---

### 引理 2（windy 约束的局部性）

一个填数过程从高位到低位逐位确定数字。设已填好的**有效数字**（去掉前导零后）最高位到当前位的前一位为 $c_{k-1},\dots,c_{i+1}$，当前要填 $c_i$。则"填 $c_i$ 后至今为止是否仍可能成为 windy 数"只取决于 $c_{i+1}$（上一位有效数字）与 $c_i$，与 $c_{k-1},\dots,c_{i+2}$ 无关。

*证明*：$\mathrm{Windy}$ 的定义是相邻位差 $\ge2$ 的合取。已填部分对应的约束是 $\{|c_{k-1}-c_{k-2}|\ge2,\dots,|c_{i+2}-c_{i+1}|\ge2\}$，这些在填 $c_i$ 之前就已确定真假，且不含 $c_i$。新引入的约束只有 $|c_{i+1}-c_i|\ge2$ 一条，它只涉及 $c_{i+1}$ 与 $c_i$。故"至今合法"当且仅当"之前合法"且"$|c_{i+1}-c_i|\ge2$"，前者是填 $c_i$ 前的既定事实，后者只依赖上一位。因此判断当前位只需上一位。证毕。

**推论**：DP 状态里保存"上一位有效数字 `pre`"即足够，无需保存整段历史。这正是数位 DP 能把指数级枚举压成多项式状态的原因。

---

### 引理 3（前导零与规范表示的一一对应）

考虑所有长度为 $L$ 的数字串 $s=s_{L-1}\dots s_0$（允许前导零），其数值 $\mathrm{val}(s)=\sum s_i10^i$。则：

(a) 每个正整数 $n<10^L$ 恰对应一个这样的串（左侧补零到 $L$ 位）；
(b) 串 $s$ 去掉前导零后得到的规范表示，其相邻差约束**等价于**：在填数过程中，从第一个非零位开始，相邻有效位差 $\ge2$；前导零之间、以及前导零与第一个非零位之间**不施加**约束。

*证明*：(a) 十进制表示唯一，补零不改变数值，故 $n\leftrightarrow s$ 是双射（$n=0$ 对应全零串）。

(b) 设 $s$ 的前导零占据高位 $s_{L-1}=\dots=s_{t+1}=0$，$s_t\ne0$（若全零则 $n=0$，单独处理）。规范表示就是 $s_t s_{t-1}\dots s_0$，位数 $k=t+1$。$\mathrm{Windy}(n)$ 要求 $|s_{i}-s_{i-1}|\ge2$ 对 $1\le i\le t$。这些恰好是"从第一个非零位 $s_t$ 起，相邻位"的约束。前导零 $s_{L-1},\dots,s_{t+1}$ 不在规范表示里，它们之间以及与 $s_t$ 之间不构成 windy 的相邻对，故不施加约束。

反过来，若填数时"前导零阶段不检查、第一个非零位起检查相邻差 $\ge2$"，则被接受的串去掉前导零后恰满足 $\mathrm{Windy}$。两个方向一致。特别地，全零串（`lead` 始终真）对应 $n=0$，不是正整数，应排除。证毕。

**这条引理是 `lead` 标志的全部依据**：它保证了"占位零"与"数字位"被正确区分，既不会错杀 $005$ 这类短数，也不会把 $0$ 算进去。

---

### 引理 4（DP 状态与转移的完备性）

定义状态 $(pos,pre,lead,lim)$：已填完高位的 $pos$ 位（$0\le pos\le L$），`pre` 是上一位**有效**数字（`lead=true` 时记哨兵 $10$），`lead` 表示是否仍全为前导零，`lim` 表示已填前缀是否恰好等于 $x$ 的前 $pos$ 位。设 $F(pos,pre,lead,lim)$ 为从该状态出发、填完剩余 $L-pos$ 位所能得到的 windy 数个数。则：

**边界**：$F(L,pre,lead,lim)=[\,lead=\text{false}\,]$（填完了，非全零即是一个合法 windy 数）。

**转移**：令 $up=lim\,?\,d_{pos}:9$。对每个 $d\in[0,up]$，令 $lim'=lim\land(d=d_{pos})$：
- 若 $lead\land(d=0)$：贡献 $F(pos+1,10,\text{true},lim')$（继续占位）；
- 否则若 $\neg lead\land|d-pre|<2$：贡献 $0$（违反相邻差）；
- 否则：贡献 $F(pos+1,d,\text{false},lim')$（$d$ 成为新的有效位）。

$F$ 等于所有 $d$ 的贡献之和。

*证明*：对剩余位数 $L-pos$ 归纳。

$L-pos=0$（$pos=L$）：填数结束。由引理 3，全零串代表 $0$ 应排除（`lead=true` ⇒ $0$），否则该串的规范表示满足 windy（填数过程已逐位保证），计 $1$。边界成立。

设剩余位数 $>0$。当前位可填 $d\in[0,up]$：`lim=true` 时前缀贴着 $x$，当前位不能超过 $d_{pos}$，故 $up=d_{pos}$；`lim=false` 时前缀已严格小于 $x$，当前位任意，$up=9$。不同 $d$ 导出的后续填法互不相交（当前位不同），故总数是各 $d$ 贡献之和。

对固定 $d$，新状态的正确性：
- `lim'`：新前缀贴着 $x$ 当且仅当旧前缀贴着（`lim`）且当前位也取到上界（$d=d_{pos}$）。若 `lim=false`，则 $lim'$ 必 false（前缀已严格小）。与 $lim'=lim\land(d=d_{pos})$ 一致。
- 若 `lead=true` 且 $d=0$：仍是前导零，`pre` 保持哨兵 $10$，`lead'=true`。由引理 3，此位不施加约束，正确。
- 若 `lead=true` 且 $d\ne0$：这是第一个有效位，无前驱，不检查差；`pre'=d`，`lead'=false`。落入"否则"分支（因 $\neg lead$ 为假，跳过差检查），正确。
- 若 `lead=false`：$d$ 是有效位，前驱为 `pre`，须 $|d-pre|\ge2$，否则该分支贡献 $0$；合法时 `pre'=d`，`lead'=false`。由引理 2，只需 `pre` 即可判断，正确。

各分支的子问题剩余位数减 $1$，由归纳假设其 $F$ 值正确，故当前 $F$ 正确。证毕。

---

### 引理 5（记忆化的合法性：无后效性）

当 `lim=false` 时，$F(pos,pre,lead,lim)$ 的值与"具体是哪条前缀到达该状态"无关，只由 $(pos,pre,lead)$ 决定。因此可用 `f[pos][pre][lead]` 记忆化。

*证明*：`lim=false` 意味着已填前缀严格小于 $x$ 的对应前缀，故剩余每一位的上界都是 $9$（不再受 $x$ 约束）。由引理 4 的转移，剩余填法的计数只通过 $(pos,pre,lead)$ 影响：`pos` 决定剩余位数，`pre` 决定第一位有效数字的差约束（引理 2），`lead` 决定是否仍在前导零阶段（引理 3）。转移中不再引用任何更早的历史或 $x$ 的具体位（因 $up=9$ 恒定）。故两个不同前缀若到达同一 $(pos,pre,lead)$ 且 `lim=false`，其后续计数完全相同。记忆化合法。

`lim=true` 的状态**不记忆化**：它依赖 $x$ 的具体位 $d_{pos}$，且每条贴着上界的路径唯一（至多一条），记忆化无收益反而可能污染。代码用 `if(!lim)` 守卫读写 `f`，正确。证毕。

**哨兵归一化**：`lead=true` 时 `pre` 恒为 $10$，使所有前导零状态共享同一 `pre` 维度，记忆化才能正确合并（否则不同占位历史会散落到不同 `pre`，虽不影响正确性但浪费状态）。$10$ 不与真实数字 $0\sim9$ 冲突，且 `lead=true` 时差检查被跳过，哨兵值不会被误用。

---

### 引理 6（$\mathrm{count}(x)$ 的实现正确性）

代码 `count(x)`：$x\le0$ 返回 $0$；否则把 $x$ 拆成高位在前的 `dig[0..L-1]`，`memset(f,-1)`，返回 `dfs(0,10,true,true)`。则返回值 $=\mathrm{count}(x)$。

*证明*：$x\le0$ 时 $[1,x]=\varnothing$，$\mathrm{count}(x)=0$，正确（覆盖 $a=1$ 时的 $\mathrm{count}(0)$）。

$x\ge1$：拆位循环 `for(t=x;t;t/=10)dig[len++]=t%10` 得到低位在前，再反转成高位在前，故 `dig[0]=d_{L-1},...,dig[L-1]=d_0`，与记号一致。初始状态 $(0,10,\text{true},\text{true})$ 表示"还没填任何位、处于前导零阶段、贴着 $x$ 上界"，正是 $\mathrm{count}(x)$ 的根。由引理 4，`dfs` 计算 $F(0,10,\text{true},\text{true})$；由引理 5，记忆化不改变其值。而 $F(0,10,\text{true},\text{true})$ 枚举了所有 $\le x$ 的 $L$ 位串（含前导零），由引理 3 恰对应 $[0,x]$ 的整数，排除 $0$ 后即 $[1,x]$ 的 windy 数，故等于 $\mathrm{count}(x)$。

`memset(f,-1,sizeof f)`：`f` 是 `i64`，$-1$ 的补码是全 $1$ 字节，`memset` 按字节填 $0xFF$ 恰好使每个 `i64` 为 $-1$，作为"未计算"标记正确（合法计数 $\ge0$，不会与 $-1$ 混淆）。每次 `count` 前重置，避免 $b$ 与 $a-1$ 两次调用间串味。证毕。

---

### 引理 7（值域与复杂度）

答案与所有 DP 值均可用 `i64` 安全存储；单次 $\mathrm{count}$ 时间 $O(L\cdot11\cdot2\cdot10)$，空间 $O(L\cdot11\cdot2)$，$L\le10$。

*证明*：答案 $\le b\le2\times10^9<2^{31}$，但 DP 中间值 $F(pos,\dots)$ 在 `lim=false` 时统计的是"剩余 $L-pos$ 位自由填"的 windy 串数，其上界为 $9\cdot8^{L-pos-1}$ 量级（首位 $9$ 选、后续每位约 $7\sim8$ 选），$L=10$ 时约 $10^9$ 量级，仍在 `i64`（$\pm9.2\times10^{18}$）内绰绰有余；用 `i64` 杜绝任何溢出疑虑。

状态数：$pos\in[0,L]$，$pre\in[0,10]$（$11$ 个），$lead\in\{0,1\}$，共 $O(11\cdot2\cdot L)$。每个状态枚举 $d\in[0,9]$ 至多 $10$ 个转移，每个转移 $O(1)$。`lim=true` 的状态每条上界路径至多一个、不记忆化但总数 $O(L\cdot10)$。故单次 $\mathrm{count}$ 时间 $O(L\cdot11\cdot2\cdot10)=O(1)$（$L\le10$ 为常数）。两次 $\mathrm{count}$ 合计仍 $O(1)$。空间为 `f[15][11][2]` 个 `i64` $\approx2.6$ KB。证毕。

---

### 定理

程序输出 $\mathrm{count}(b)-\mathrm{count}(a-1)$，等于 $[a,b]$ 内 windy 数的个数，复杂度 $O(\log b)$（视位数为常数则 $O(1)$）。

*证明*：引理 1 把区间计数化为前缀差；引理 2、3 论证了"上一位 + 前导零标志"是充分状态且前导零处理正确；引理 4 给出完备转移与边界；引理 5 保证记忆化无后效；引理 6 保证 `count` 实现与定义一致；引理 7 保证值域与复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — windy 约束是"相邻位绝对差 $\ge2$"，只耦合相邻位 ⇒ 状态只需记上一位。
- **consider easier version** — 先想暴力枚举 $[a,b]$，$2\times10^9$ 超时，确认要按数位计数。
- **reduce to easier problem** — 区间计数拆前缀差 $\mathrm{count}(b)-\mathrm{count}(a-1)$，把任意区间归约成"从 $1$ 卡上界"。
- **classic problem solution** — 数位 DP：状态 $(pos,pre,lead,lim)$，逐位填、记忆化 `lim=false` 的子问题。
- **explore its property** — 前导零是占位不是数字位：`lead` 阶段不查差、`pre` 归一化成哨兵 $10$、全零串代表 $0$ 要排除。
- **discuss by category** — 边界 $\mathrm{count}(0)=0$、单位数 $1\sim9$ 恒合法、`memset(f,-1)` 对 `i64` 正确、`lim=true` 不记忆化。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `a,b` | 询问区间端点，$1\le a\le b\le2\times10^9$ | `i64`，读入 | 答案 `count(b)-count(a-1)` |
| `len` | 当前 $x$ 的位数 $L\le10$ | `int` | 每次 `count` 重算 |
| `dig[i]` | $x$ 的第 $i$ 位（**高位在前**，`dig[0]` 是最高位） | `int[mxn]` | 拆位后反转 |
| `f[pos][pre][lead]` | `lim=false` 时状态 $(pos,pre,lead)$ 的合法后缀数 | `i64[mxn][11][2]`，初值 $-1$ | $-1$=未算；`memset` 按字节填 $0xFF$ |
| `pos` | 已填位数（$0\le pos\le L$） | `int` | `pos==len` 到达边界 |
| `pre` | 上一位**有效**数字；前导零阶段为哨兵 $10$ | `int` | 差约束只依赖它 |
| `lead` | 是否仍全为前导零 | `bool` | 真⇒不查差、`pre=10` |
| `lim` | 已填前缀是否贴着 $x$ 上界 | `bool` | 真⇒当前位 $\le d_{pos}$，且不记忆化 |
| `mxn` | $10+5=15$ | `constexpr int` | 位数上界 $+5$ 松弛 |

### 算法步骤

1. I/O 加速三行；读入 `a,b`（`i64`）。
2. 定义 `count(x)`：$x\le0$ 返回 $0$；否则拆位到 `dig`（低位在前）并反转成高位在前，`memset(f,-1,sizeof f)`，返回 `dfs(0,10,true,true)`。
3. `dfs(pos,pre,lead,lim)`：
   1. `pos==len`：返回 `lead?0:1`。
   2. `!lim && f[pos][pre][lead]!=-1`：直接返回记忆值。
   3. `up=lim?dig[pos]:9`；枚举 `d=0..up`，`nlim=lim&&d==dig[pos]`：
      - `lead&&d==0`：累加 `dfs(pos+1,10,true,nlim)`；
      - 否则 `!lead&&abs(d-pre)<2`：跳过；
      - 否则：累加 `dfs(pos+1,d,false,nlim)`。
   4. `!lim` 时写回 `f[pos][pre][lead]`；返回累加和。
4. 输出 `count(b)-count(a-1)` 与 `'\n'`。

### 复杂度

- 时间：$O(L\cdot11\cdot2\cdot10)$，$L\le10$，两次 `count` 合计常数级（约数千次基本运算）。
- 空间：$O(L\cdot11\cdot2)$，`f[15][11][2]` 约 $2.6$ KB。
- 值域：答案 $\le2\times10^9$，DP 中间值 $\lesssim10^9$，`i64` 安全。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；题面无样例，手算 $[1,10]=9$、$[1,25]=19$、$[13,13]=1$、$[12,12]=0$、$[20,20]=1$、$[1,1]=1$ 全部吻合；另与"逐个判断 windy"的独立暴力在 $300$ 组随机区间（$1\le a\le b\le2\times10^4$）对拍，$0$ mismatch，覆盖前导零、单位数、多位边界。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2657 [SCOI2009] windy 数
// 思路：区间计数拆前缀差 count(b)-count(a-1)。
//       count(x) 用数位 DP：状态 (pos,pre,lead,lim)。
//       windy 约束只耦合相邻位 ⇒ 记上一位 pre 即可。
//       前导零是占位：lead 阶段不查差、pre 归一化成哨兵 10、全零串代表 0 要排除。
//       lim=false 的子问题无后效 ⇒ 记忆化 f[pos][pre][lead]。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{15};	// 2e9 最多 10 位，+5 松弛

int len,dig[mxn];
i64 f[mxn][11][2];	// f[pos][pre][lead]，pre=10 表示仍在前导零

i64 dfs(int pos,int pre,bool lead,bool lim)
{
	if(pos==len)
		return lead?0:1;	// 全前导零代表 0，不是 windy 数
	if(!lim&&f[pos][pre][lead]!=-1)
		return f[pos][pre][lead];
	int up=lim?dig[pos]:9;
	i64 res=0;
	for(int d=0;d<=up;++d)
	{
		bool nlim=lim&&d==dig[pos];
		if(lead&&d==0)
			res+=dfs(pos+1,10,true,nlim);	// 继续占位，不查差
		else
		{
			if(!lead&&abs(d-pre)<2)
				continue;	// 相邻差 <2，非法
			res+=dfs(pos+1,d,false,nlim);
		}
	}
	if(!lim)
		f[pos][pre][lead]=res;	// 只记忆自由状态
	return res;
}

i64 count(i64 x)
{
	if(x<=0)
		return 0;
	len=0;
	for(i64 t=x;t;t/=10)
		dig[len++]=t%10;
	for(int i=0;i<len/2;++i)
		swap(dig[i],dig[len-1-i]);	// 翻成高位在前
	memset(f,-1,sizeof f);	// i64 全 0xFF = -1，作"未计算"标记
	return dfs(0,10,true,true);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	i64 a,b;
	cin>>a>>b;
	cout<<count(b)-count(a-1)<<'\n';
	return 0;
}
```

### 代码说明

- **`lead` 与 `pre=10` 哨兵**：前导零阶段 `pre` 统一记 $10$，既让记忆化状态正确合并，又保证 `abs(d-pre)` 永远不会在 `lead=true` 时被执行（差检查有 `!lead` 守卫）。
- **`nlim=lim&&d==dig[pos]`**：只有"原来贴着上界且当前位取到上界"才继续贴着；一旦填小就彻底自由。这是数位 DP 卡上界的标准写法。
- **`pos==len` 返回 `lead?0:1`**：填完时若仍全零代表数字 $0$，排除；否则是一个合法 windy 数，计 $1$。单位数 $1\sim9$ 走"第一个非零位即末位"的路径，差检查从未触发，自然全部计入。
- **`memset(f,-1,sizeof f)` 对 `i64` 正确**：$-1$ 的补码是全 $1$ 字节，按字节填充恰好得到 `i64` 的 $-1$；合法计数非负，不会与标记混淆。每次 `count` 前重置，隔离 $b$ 与 $a-1$ 两次调用。
- **`lim=true` 不记忆化**：贴着上界的路径依赖 $x$ 的具体位且至多一条，记忆化无收益；用 `if(!lim)` 守卫读写，避免污染自由状态。
- 全程 `i64`，答案与中间值都远离溢出；`'\n'` 换行；下标内部 $0$-based（`dig[0]` 为最高位）。
