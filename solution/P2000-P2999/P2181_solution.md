# P2181 对角线 — 题解

## 一、解题过程：人类思考叙事

题意翻译：给定一个 $n$ 个顶点的凸多边形，任意三条对角线都不交于同一点，问图形中对角线交点的个数。

看到"凸多边形"和"对角线交点"，第一反应是组合计数。经典结论是 $\binom{n}{4}$，但我不能只凭"经典结论"就动手写，先自己推一遍。

**第一步：两个交点对应几组四点？**

考虑一个具体的交点 $P$，它是两条对角线 $AC$ 和 $BD$ 的交点，其中 $A,B,C,D$ 是四个不同的顶点（按圆周顺序）。反过来，任意选定四个顶点 $A,B,C,D$（按圆周顺序排列），它们构成一个凸四边形，这个四边形的两条对角线 $AC$ 与 $BD$ 必然在内部相交，产生一个交点。

所以"交点"和"四元组 $\{\text{4 个顶点}\}$"之间看起来是一一对应的。但是！这里有一个坑：**如果三个对角线共点，一个交点就对应了 $\binom{3}{2}=3$ 组四点**（三对线两两组合共 3 种）。题目明确说了"任何三条对角线都不会交于一点"，就是为了排除这个退化情形。

所以在题目的保证下，每个交点恰好由 2 条对角线产生，而这 2 条对角线的 4 个端点唯一确定一个四点集合；反之每个四点集合恰好产生 1 个交点。因此

$$\text{交点数} = \binom{n}{4}.$$

**第二步：为什么"任意四点产生的交点互不相同"？**

这是上面论证里唯一还需要确认的一环，我把它拆开看。

- 方向一（四点 → 交点）：任取 4 个顶点，按圆周顺序记为 $A,B,C,D$。由于多边形是**凸**的，$A,B,C,D$ 构成一个凸四边形，其对角线 $AC$、$BD$ 在四边形内部相交，产生一个交点 $P$。这个交点是多边形对角线的交点（$AC$、$BD$ 都是 $n$ 边形的对角线，因为 $A\ne C$ 且 $B\ne D$ 且四点不重复）。
- 方向二（交点 → 四点唯一）：设交点 $P$ 由对角线 $AC$ 与 $BD$ 产生。因为"任意三条对角线不共点"，所以**过 $P$ 的对角线恰好只有这两条**。于是由 $P$ 唯一确定了 $\{A,B,C,D\}$ 这个集合。
- 两点合一：由方向二，四点集合与交点之间是单射；由方向一，每个四点集合都被某个交点命中（满射）。故为双射，个数为 $\binom n4$。

补充一点严谨性：$AC$ 与 $BD$ 是"对角线"而非"边"，因为 $A,B,C,D$ 是四个不同的顶点，$AC$ 至少隔着一个顶点 $B$（在圆周顺序上），$BD$ 同理。

**第三步：数值范围与溢出。**

$n\le 10^5$，$\binom{10^5}{4} \approx 4.166\times 10^{18}$。这已经接近 `long long` 的上限 $9.22\times 10^{18}$，最终答案是能存下的。但**中间乘积** $n(n-1)(n-2)(n-3) \approx 10^{20}$ 远超 `long long`，会溢出。

两种处理：
1. 依次做除法：$\binom n4 = \frac{n(n-1)(n-2)(n-3)}{24}$，注意 $24 = 4\cdot 3\cdot 2\cdot 1$，可以一边乘一边约掉因子，但因子要"配对"处理，代码写起来容易出错。
2. 用 `__int128` 算中间值，最后转回 `long long` 输出。

我选第二种，简单可靠。`__int128` 最大约 $1.7\times 10^{38}$，绰绰有余。

顺带确认几个小值：$n=4$ 时四边形只有 1 个交点（两条对角线），$\binom 44=1$ ✓。$n=6$ 时 $\binom 64 = 15$，这正是题面那张六边形图的答案 ✓。

**第四步：$n<4$ 怎么办？** 题面保证 $n\ge 3$。$n=3$ 时是三角形，没有对角线，交点数为 $0$；公式 $\binom 34 = 0$ 恰好也对（乘积里含一个 $0$ 因子）。所以不必特判。

## 二、思维链：完整证明

**记号约定**：$n$ 为顶点数；顶点按逆时针顺序编号 $1,2,\dots,n$；对角线指连接两个**不相邻**顶点的线段；记 $\binom n4 = \frac{n(n-1)(n-2)(n-3)}{24}$。

**引理 1**：任取 4 个不同的顶点，按圆周顺序记为 $A,B,C,D$，则线段 $AC$ 与 $BD$ 都在多边形内部相交于一点 $P$。

*证明*：由多边形凸性，四点 $A,B,C,D$ 在圆周上的顺序即为 $A,B,C,D$，它们构成一个凸四边形。凸四边形的两条对角线 $AC$、$BD$ 在四边形内部相交（这是凸四边形的基本性质：两条对角线把四边形分成两个三角形，两个三角形 $ABC$、$ACD$ 被对角线 $BD$ 分处两侧，故 $BD$ 穿过 $AC$；同理 $AC$ 穿过 $BD$）。而 $A,C$ 之间在圆周上至少隔着顶点 $B$，故 $A,C$ 不相邻，$AC$ 是多边形的对角线；同理 $BD$ 也是对角线。证毕。

**引理 2**（每个交点恰好来自两条对角线）：题设"任何三条对角线都不会交于一点"，因此对任一对角线的交点 $P$，过 $P$ 的对角线恰有两条。

*证明*：过 $P$ 的对角线至少有两条（否则 $P$ 不是交点）。若存在三条对角线过 $P$，则违反题设"任何三条对角线不会交于一点"。故过 $P$ 的对角线恰有两条。证毕。

**引理 3**（双射）：设 $\mathcal S$ 是所有 4 元顶点子集构成的集合，$\mathcal P$ 是所有对角线交点构成的集合。则映射

$$\varphi:\mathcal S\to\mathcal P,\quad \{A,B,C,D\}\mapsto (AC\cap BD)$$

（$A,B,C,D$ 按圆周顺序）是双射。

*证明*：
- **良定义**：由引理 1，$AC$ 与 $BD$ 确实相交于某点 $P$，且 $AC,BD$ 都是对角线，故 $P\in\mathcal P$。
- **单射**：设 $\varphi(S_1)=\varphi(S_2)=P$。由引理 2，过 $P$ 的对角线恰有两条，记为 $AC$ 与 $BD$。则 $S_1$ 必然是 $\{A,B,C,D\}$（因为 $\varphi(S_1)=P$ 意味着 $S_1$ 产生的两条对角线就是 $AC,BD$，其端点集就是 $\{A,B,C,D\}$），同理 $S_2=\{A,B,C,D\}$。故 $S_1=S_2$，单射成立。
- **满射**：任取 $P\in\mathcal P$。由定义，存在两条相交的对角线 $AC$、$BD$，其交点为 $P$；四个端点互不相同（否则两条对角线共享端点，不会在内部相交）。于是 $S=\{A,B,C,D\}$ 按圆周顺序排列，由引理 1，$AC$ 与 $BD$ 的交点正是 $P$，即 $\varphi(S)=P$。满射成立。证毕。

**引理 4**：交点数等于 $\binom n4$。

*证明*：由引理 3，交点集 $\mathcal P$ 与 4 元顶点子集集 $\mathcal S$ 等势，而 $|S|=\binom n4$。故 $|\mathcal P|=\binom n4$。证毕。

**定理**：算法输出的值就是对角线交点数。

*证明*：算法计算 $\binom n4 = n(n-1)(n-2)(n-3)/24$，用 `__int128` 承载中间乘积（$n\le10^5$ 时中间值 $\le 10^{20}$，`long long` 会溢出而 `__int128` 不会），最后除以 $24$ 并转回 `long long` 输出（$\binom{10^5}4 = 4166416671249975000 < 2^{63}-1$，能存下）。由引理 4 该值即答案。证毕。

## 三、模式总结（按实际思考顺序）

1. **认出"凸多边形 + 任意三条对角线不共点"的标准信号** — 后半句是为了排除共点退化，让计数变简单。
2. **找对应关系** — 每个交点 ↔ 每个四点集合，想到了 $\binom n4$。
3. **但要证，不能只背结论** — 于是拆成两问：四点必产生交点（凸性）、交点必唯一确定四点（不共点保证）。
4. **发现唯一性论证里的"共点"坑** — 一个交点对应多组四点，所以题设那句"任意三条不共点"是必需条件。
5. **数值范围** — 最终答案能进 `long long`，中间乘积不能，改用 `__int128`。
6. **小值自检** — $n=3\to0$、$n=4\to1$、$n=6\to15$（与题面示意图一致）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 多边形顶点数 | `i64`，$[3,10^5]$ |
| `res` | 交点数 $\binom n4$ | `i128` 中间量 |

### 算法步骤

1. 读入 $n$。
2. 计算 `res = (__int128)n*(n-1)*(n-2)*(n-3)/24`。
3. 输出 `(long long)res`。

### 复杂度

- 时间复杂度：$O(1)$。
- 空间复杂度：$O(1)$。

### 验证状态

- 标程 `P2181.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 编写暴力 `P2181_brute.cpp`（枚举多边形的所有对角线，两两配对，按"两条对角线的 4 个端点在圆周上是否交替出现"判定是否在内部相交，统计相交的线对数——在"任意三条不共点"的题设下，相交线对数即交点数）与对拍脚本 `P2181_check.py`，在 $3\le n\le 14$ 的随机数据上对拍 **2000 组全部通过**。
- 手工验证：$n=6\to15$（与题面六边形图一致）、$n=4\to1$、$n=100000\to4166416671249975000$、$n=3\to0$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2181 对角线
#include<bits/stdc++.h>
using namespace std;
using i64=long long;
using i128=__int128_t;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	i64 n;
	cin>>n;
	// 交点数等于 C(n,4)：任取 4 个顶点恰确定一个交点
	// n<=1e5 时 C(n,4) 约 4.17e18，超过 int64 中间乘积，故用 __int128
	i128 res=(i128)n*(n-1)*(n-2)*(n-3)/24;
	cout<<(i64)res<<'\n';
	return 0;
}
```

### 代码说明

- `(i128)n` 这个强制转换是关键：必须**在乘法发生之前**就把 `n` 提升到 128 位，否则 `n*(n-1)` 会先按 `long long` 算出溢出值再转换（转换发生在乘法之后已经晚了）。
- 除以 $24$ 在 128 位下进行，结果精确（$n(n-1)(n-2)(n-3)$ 必被 $24$ 整除，因为它是 $4$ 个连续整数的乘积，必含因子 $4$、$3$、$2$、$1$）。
- 最后 `(i64)res` 安全：$\binom{10^5}4 \approx 4.17\times10^{18} < 2^{63}-1 \approx 9.22\times10^{18}$。
- `using i128=__int128_t;` 是 GCC/Clang 提供的类型，题目环境（GNU C++17）支持。
