# P2803 学校选址 II — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一条直线上有 $n$ 栋楼（$n\le 100$），第 $i$ 栋有 $a_i$ 个学生（$0<a_i\le100$），相邻楼距 $d_i$（$1\le d_i\le100$）。要在路上任选 $k$ 个点（$k\le100$，可与楼重合也可不重合）建小学，每个学生走**到最近学校**的距离，求总距离和的最小值。

先把坐标落地：令 $x_0=0$，$x_i=x_{i-1}+d_{i-1}$，则楼 $i$ 在 $x_i$，学生上学路程就是 $a_i\cdot|x_i-p|$（$p$ 为其所属学校位置）。$x$ 最大 $99\times100=9900$，总费用上界约 $100\times100\times9900=9.9\times10^7$，`int` 勉强装得下，但我全程用 `i64` 保险。

**第一步：先做 $k=1$ 的简单版本。** 一所学校，最小化 $f(p)=\sum_i a_i|x_i-p|$。第一反应是"加权平均数"？不对——平均数最小化的是**平方**距离和，不是绝对值距离和。构造反例：楼在 $0,1,10$，学生数 $100,1,1$。加权平均 $\approx0.18$，费用 $\approx100\times0.18+1\times0.82+1\times9.82\approx28.6$；而把学校放在 $0$ 号楼，费用 $=1\times1+1\times10=11$，远更小。正确答案是**加权中位数**：把学生按位置排开，取"累计人数首次达到总人数一半"的那栋楼。直觉：$f$ 是分段线性凸函数，学校每向右移动 $\mathrm dp$，左边所有学生各多走 $\mathrm dp$、右边所有学生各少走 $\mathrm dp$，所以斜率 = 左侧人数 $-$ 右侧人数；斜率由负转正的折点就是最小值点，而折点只在楼的位置出现——**学校建在楼上永远不劣**，"可以不与楼重合"这句话是烟雾弹。

**第二步：$k>1$ 时学校怎么分工？** 关键观察：学校都在直线上，每栋楼去**最近**的学校。把学校按位置排序 $p_1<\dots<p_k$，则"楼的最近学校编号"随楼的位置**单调不减**：若楼 $A$ 在楼 $B$ 左边，$A$ 却去了更靠右的学校，交换一下必然更优（严格证明见引理 3，用中点一刀切）。于是**每所学校服务的楼构成一段连续区间**，问题变成：

> 把序列 $0..n-1$ 切成至多 $k$ 段，每段费用 = 该段的加权中位数费用 $w(i,j)$，最小化段费用和。

这就是经典的**邮局问题**（post office DP）。

**第三步：段费用 $w(i,j)$ 怎么算？** 对区间 $[i,j]$，总权重 $W=\sum_{t=i}^j a_t$，加权中位数 $m$ = 最小的下标使 $2\sum_{t=i}^m a_t\ge W$。费用拆成左右两半：

$$w(i,j)=\underbrace{x_m\sum_{t=i}^m a_t-\sum_{t=i}^m a_tx_t}_{\text{左半}}+\underbrace{\sum_{t=m+1}^j a_tx_t-x_m\sum_{t=m+1}^j a_t}_{\text{右半}}.$$

预处理前缀和 $pa[i]=\sum_{t<i}a_t$、$px[i]=\sum_{t<i}a_tx_t$，每对 $(i,j)$ 都 $O(1)$ 算费用。中位数 $m$ 随 $j$ 增大**只右移不左移**（$W$ 单调增，条件 $2\cdot\text{前缀}\ge W$ 越来越难满足），所以对每个 $i$ 用一根单调指针扫 $j$，全部 $w$ 只要 $O(n^2)$。

**第四步：DP。** $f[j][i]$ = 前 $i$ 栋楼用 $j$ 所学校的最小费用。枚举最后一段 $[t,i-1]$：

$$f[j][i]=\min_{j-1\le t<i}\bigl(f[j-1][t]+w(t,i-1)\bigr),\qquad f[0][0]=0,\ f[0][i>0]=+\infty.$$

答案 $f[k][n]$。两个边界：$k\ge n$ 时每栋楼门口建一所，答案 $0$（代码里 `k=min(k,n)`，DP 自然给出 $0$）；**$f$ 必须显式填 INF**——全局数组默认 $0$，若 $f[0][i]$ 留 $0$，就等于宣称"$0$ 所学校免费覆盖 $i$ 栋楼"，DP 会一路错到底。这是本题最容易静默翻车的坑。

**第五步：为什么"至多 $k$ 段"和"恰好 $k$ 段"等价？** 段数不足 $k$ 时，把某段再切一刀不会更差：两段各自的中位数费用之和 $\le$ 整段费用（整段最优学校同时服务两段时的费用就是整段费用，而各段用自己的最优只会更小，引理 4 严格证）。所以 $k\le n$ 时不妨设每段非空、恰好 $k$ 段，DP 的 $t\ge j-1$ 限制合法。

**手造数据核对**（题面无样例）：

| 输入 | 手算 | 考点 |
|---|---|---|
| `3 1` / `1 1 1` / `1 1` | $2$ | 楼在 $0,1,2$，中位数 $1$，费用 $1+0+1$ |
| `3 2` / `1 1 1` / `1 1` | $1$ | 切 $\{0\},\{1,2\}$，费用 $0+1$ |
| `2 1` / `1 100` / `10` | $10$ | 加权中位数被 $100$ 人拉到 $1$ 号楼，费用 $1\times10$ |
| `3 1` / `100 1 1` / `1 9` | $11$ | 打"加权平均"错误思路：楼 $0,1,10$，中位数 $0$ |
| `1 1` / `5` /（无第三行） | $0$ | $n=1$，$n-1=0$ 个距离 |
| `2 5` / `3 4` / `7` | $0$ | $k>n$，每楼一所 |

## 二、思维链：完整证明

**记号.** 楼 $0..n-1$，坐标 $x_0=0<x_1<\dots<x_{n-1}$（$d_i\ge1$ 保证严格递增），权重 $a_i\ge1$。前缀和 $pa[i]=\sum_{t<i}a_t$，$px[i]=\sum_{t<i}a_tx_t$（$pa[0]=px[0]=0$）。区间 $[i,j]$ 的总权重 $W_{i,j}=pa[j+1]-pa[i]$。学校位置 $p\in\mathbb R$。

### 引理 1（加权中位数最小化绝对偏差和）

固定区间 $[i,j]$，令 $F(p)=\sum_{t=i}^j a_t|x_t-p|$。设 $m$ 为满足 $2(pa[m+1]-pa[i])\ge W_{i,j}$ 的**最小**下标（$i\le m\le j$）。则 $F$ 在 $p=x_m$ 处取全局最小值，且

$$F(x_m)=x_m(pa[m+1]-pa[i])-(px[m+1]-px[i])+(px[j+1]-px[m+1])-x_m(pa[j+1]-pa[m+1]).$$

*证明*：$m$ 存在：$m=j$ 时 $2W_{i,j}\ge W_{i,j}$ 成立（$W_{i,j}>0$）。

$F$ 是分段线性函数，折点只在 $x_i,\dots,x_j$。在不含折点的开区间上，$F$ 可导且

$$F'(p)=\sum_{x_t<p}a_t-\sum_{x_t>p}a_t.$$

（每项 $a_t|x_t-p|$ 在 $p>x_t$ 时导数 $+a_t$，$p<x_t$ 时导数 $-a_t$。）

- 当 $p<x_i$：$F'(p)=-W_{i,j}<0$。
- 当 $p\in(x_{r},x_{r+1})$（$i\le r<j$）：$F'(p)=2(pa[r+1]-pa[i])-W_{i,j}$。由 $m$ 的最小性，$r<m$ 时 $2(pa[r+1]-pa[i])<W_{i,j}$，斜率 $<0$；$r\ge m$ 时 $2(pa[r+1]-pa[i])\ge2(pa[m+1]-pa[i])\ge W_{i,j}$（前缀和单调），斜率 $\ge0$。
- 当 $p>x_j$：$F'(p)=W_{i,j}>0$。

所以 $F$ 在 $(-\infty,x_m)$ 上严格递减（各段斜率 $<0$，折点处连续），在 $(x_m,+\infty)$ 上不减（各段斜率 $\ge0$）。故 $x_m$ 是全局最小点。特别地，若 $2(pa[m+1]-pa[i])=W_{i,j}$，则 $(x_m,x_{m+1})$ 上斜率为 $0$，整段平台都是最小点，$x_m$ 仍是其中之一——**最小值总能在某栋楼处取到**，学校位置无需离开楼。

费用公式：在 $p=x_m$ 处，$t\le m$ 的项 $|x_t-x_m|=x_m-x_t$，$t>m$ 的项 $=x_t-x_m$，拆开求和并用前缀和代换即得上式。证毕。

**推论（$k=1$ 的答案）**：$w(0,n-1)=F(x_m)$ 即一所学校的最优费用；"加权平均"思路被第一部分 $100,1,1$ 反例否定（平均最小化平方和，与本题目标函数不同）。

### 引理 2（区间费用公式与中位数指针的单调性）

对固定 $i$，令 $m(j)$ 为区间 $[i,j]$ 的加权中位数下标（引理 1 定义）。则 $m(j)$ 关于 $j$ 单调不减，且 $m(j)\le j$。从而以一根指针 `m` 从 $i$ 开始、随 $j$ 递增只向右推进，即可在 $O(n^2)$ 总时间内求出所有 $w(i,j)$。

*证明*：$m(j)\le j$：$m=j$ 满足条件，最小满足者 $\le j$。单调性：设 $j'>j$，则 $W_{i,j'}=W_{i,j}+pa[j'+1]-pa[j+1]>W_{i,j}$（$a_t\ge1$）。若 $m(j')<m(j)$，由 $m(j)$ 的最小性，$2(pa[m(j')+1]-pa[i])<W_{i,j}<W_{i,j'}$，与 $m(j')$ 满足 $[i,j']$ 的条件矛盾。故 $m(j')\ge m(j)$。指针每步右移一格、对每个 $i$ 至多移 $n$ 格，总移动 $O(n^2)$；每对 $(i,j)$ 的费用用前缀和 $O(1)$ 计算。证毕。

### 引理 3（最近学校划分是连续段）

设学校位置 $p_1<\dots<p_s$（互异；重合的学校可合并，不影响任何距离）。对楼位置 $x$，记 $\nu(x)=\arg\min_r|x-p_r|$（平局任取一个固定规则，如取编号最小）。则 $x<x'\Rightarrow\nu(x)\le\nu(x')$。从而按 $\nu$ 值分组，每组是楼的连续区间。

*证明*：反设 $x<x'$ 但 $\nu(x)=u>v=\nu(x')$。则 $p_v<p_u$。由 $\nu(x)=u$：$|x-p_u|\le|x-p_v|$。对 $p_v<p_u$，$|x-p_u|\le|x-p_v|\iff x\ge\frac{p_v+p_u}{2}$（数轴上到右点更近 $\iff$ 在中点右侧；平方展开 $(x-p_u)^2\le(x-p_v)^2\iff 2x(p_u-p_v)\ge p_u^2-p_v^2\iff x\ge\frac{p_v+p_u}{2}$，$p_u-p_v>0$ 保证除法等号方向）。同理由 $\nu(x')=v$：$|x'-p_v|\le|x'-p_u|\iff x'\le\frac{p_v+p_u}{2}$。于是 $x\ge\text{中点}\ge x'$，与 $x<x'$ 矛盾。故 $\nu$ 单调不减。楼按坐标排序后，$\nu$ 值序列单调不减，相同 $\nu$ 值的楼必连续成段。证毕。

### 引理 4（切段不增费用）

对 $i\le t<j$：$w(i,t)+w(t+1,j)\le w(i,j)$。

*证明*：设 $p^*$ 是 $[i,j]$ 的最优学校位置（引理 1 保证存在）。则

$$w(i,j)=\sum_{r=i}^j a_r|x_r-p^*|=\sum_{r=i}^t a_r|x_r-p^*|+\sum_{r=t+1}^j a_r|x_r-p^*|\ge w(i,t)+w(t+1,j),$$

最后一步因为 $w(i,t)$ 是左半段在**所有**位置上的最小值，$\le$ 它在特定位置 $p^*$ 的费用；右半同理。证毕。

### 引理 5（原问题 = 连续分段 DP）

设 $\mathrm{OPT}$ 为原题最优值，$\mathrm{DP}$ 为"把 $0..n-1$ 切成恰好 $k'$ 个非空连续段（$k'=\min(k,n)$），费用和 $\sum w$ 的最小值"。则 $\mathrm{OPT}=\mathrm{DP}$。

*证明*：先证 $\mathrm{OPT}\le\mathrm{DP}$：取最优分段，在每段的中位数楼处建学校（共 $k'\le k$ 所；若 $k'<k$ 多余学校随便放，不增加费用）。每栋楼的学生走到**本段**学校的费用恰为段费用，而走到**最近**学校只会更近，故实际总费用 $\le\sum w=\mathrm{DP}$。所以 $\mathrm{OPT}\le\mathrm{DP}$。

再证 $\mathrm{OPT}\ge\mathrm{DP}$：取最优学校布局（位置互异化后 $s\le k$ 所），按引理 3 把楼分成 $s$ 个连续段，每段学生去同一所学校 $p_r$，总费用 $=\sum_{\text{段}}\sum a|x-p_r|\ge\sum_{\text{段}}w(\text{段})$（$w$ 是段内最小值）。若 $s=k'\le k$ 且各段非空，这已是一个合法分段，$\ge\mathrm{DP}$。若 $s<k'$：由引理 4，把任一段切开后费用和不增；反复切直到恰有 $k'$ 段（$k'\le n$ 保证切得动：段数 $<n$ 时必有长度 $\ge2$ 的段），得到 $\mathrm{OPT}\ge\sum w(\text{新段})\ge\mathrm{DP}$。若 $s$ 段中有空段（某学校没服务任何楼），删掉它费用不变，归入前一情形。综上 $\mathrm{OPT}\ge\mathrm{DP}$。两向夹逼得等号。证毕。

### 引理 6（DP 递推正确）

定义 $f[j][i]$：前 $i$ 栋楼（$0..i-1$）切成恰好 $j$ 个非空连续段的最小费用和；无合法切法时为 $+\infty$。则 $f[0][0]=0$，$f[0][i]=+\infty$（$i\ge1$），且对 $1\le j\le i$：

$$f[j][i]=\min_{j-1\le t<i}\bigl(f[j-1][t]+w(t,i-1)\bigr).$$

*证明*：对 $j$ 归纳。$j=0$：$0$ 段覆盖 $0$ 栋楼费用 $0$；覆盖 $\ge1$ 栋不可能，$+\infty$，与初始化一致。设 $j-1$ 时 $f[j-1][\cdot]$ 全部正确。前 $i$ 栋切 $j$ 段的任一切法，其最后一段形如 $[t,i-1]$，前 $t$ 栋被切成 $j-1$ 段；非空性要求最后一段 $t\le i-1$、前 $t$ 栋 $\ge j-1$ 栋即 $t\ge j-1$。该切法费用 $=$（前 $t$ 栋的 $j-1$ 段费用）$+w(t,i-1)\ge f[j-1][t]+w(t,i-1)$。反之，对任一 $t\in[j-1,i-1]$，取前 $t$ 栋的最优 $j-1$ 段切法（若 $f[j-1][t]=\infty$ 则不存在，跳过）接上段 $[t,i-1]$，得到合法 $j$ 段切法，费用恰为 $f[j-1][t]+w(t,i-1)$。两向取最小即得递推。$i<j$ 时 $t$ 的范围为空，$f[j][i]=\infty$，正确（$j$ 段装不进 $i<j$ 栋楼）。证毕。

**推论**：答案 $=f[k'][n]$（引理 5 + 本引理）。$k\ge n$ 时 $k'=n$，唯一合法切法是每栋一段，$w(i,i)=0$，答案 $0$。

### 引理 7（复杂度与数值范围）

时间 $O(n^2+kn^2)$，空间 $O(n^2)$；所有代数量在 `i64` 内无溢出。

*证明*：前缀和 $O(n)$；$w$ 预处理由引理 2 为 $O(n^2)$；DP 状态 $O(kn)$，每个状态枚举 $O(n)$ 个 $t$，共 $O(kn^2)\le100\times100\times100=10^6$。空间：$w,f$ 各 $105\times105$ 个 `i64`，约 $176$ KB。数值：$x_i\le9900$，$pa\le10^4$，$px\le10^4\times9900=9.9\times10^7$；$w$ 与 $f$ 的最大可能值 $\le\sum a_t\cdot(x_{n-1}-x_0)\le10^4\times9900=9.9\times10^7$；INF 取 $1145141919810\approx1.1\times10^{12}$，INF 加有限值 $\le1.2\times10^{12}$ 仍远小于 `i64` 上限 $9.2\times10^{18}$，且 INF 永远大于任何真实费用，不会污染 min。证毕。

### 定理

程序输出原题最优总距离。

*证明*：引理 1 给出单段最优费用与"学校建在楼上不劣"；引理 2 保证 $w$ 表正确且 $O(n^2)$ 可求；引理 3 保证最优布局诱导出连续分段；引理 4、5 把原题等价成恰好 $k'$ 段的分段最小化；引理 6 保证 DP 递推与边界正确（含 INF 初始化）；引理 7 给出复杂度与无溢出。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 坐标前缀和化；目标函数 $\sum a_i|x_i-p|$ 是分段线性凸函数，"可建在任意点"不增加自由度。
2. **consider easier version** — $k=1$：加权中位数最优；用 $100,1,1$ 反例排除"加权平均"（那是平方距离的答案）。
3. **explore its property** — 直线上"最近学校"编号随位置单调不减（中点论证）⇒ 每所学校服务连续一段楼。
4. **reduce to easier problem** — 原题塌缩成经典邮局问题：序列切 $k$ 段，段费用 = 段加权中位数费用。
5. **classic problem solution** — 前缀和 $pa,px$ + 单调中位数指针，$O(n^2)$ 预处理全部 $w(i,j)$。
6. **classic problem solution** — 划分 DP $f[j][i]=\min_t f[j-1][t]+w(t,i-1)$；切段不增费用保证"恰好 $k$ 段"与"至多 $k$ 段"等价。
7. **discuss by category** — $k\ge n$ 答案 $0$；$n=1$ 无距离行；$f$ 必须显式填 INF（默认 $0$ 会被当成"$0$ 校免费覆盖"）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n,k` | 楼数、学校数，$\le100$ | `int` | 读入；`k=min(k,n)` |
| `a[i]` | 楼 $i$ 的学生数 | `i64[mxn]` | 读入，$1..100$ |
| `x[i]` | 楼 $i$ 的坐标 | `i64[mxn]` | `x[0]=0`（全局默认），`x[i]=x[i-1]+d` |
| `pa[i]` | $\sum_{t<i}a_t$ | `i64[mxn]` | `pa[0]=0`，递推 |
| `px[i]` | $\sum_{t<i}a_tx_t$ | `i64[mxn]` | `px[0]=0`，递推；"权重×坐标"前缀和 |
| `w[i][j]` | 区间 $[i,j]$ 建一所学校的最小费用 | `i64[mxn][mxn]` | 中位数公式 $O(1)$ 算 |
| `m` | 当前区间 $[i,j]$ 的加权中位数下标 | `int` | 每个 $i$ 从 $i$ 起，随 $j$ 单调右移 |
| `f[j][i]` | 前 $i$ 栋楼用 $j$ 所学校的最小费用 | `i64[mxn][mxn]` | **`fill_n` 全填 `inf`**，`f[0][0]=0` |
| `inf` | $1145141919810$ | `constexpr i64` | 大于一切真实费用（$\le9.9\times10^7$） |
| `mxn` | $100+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行；读 `n,k`、`a[0..n-1]`、$n-1$ 个距离并递推 `x`；`k=min(k,n)`。
2. 递推 `pa,px`。
3. 对每个 $i$：指针 `m=i`；对 $j=i..n-1$：`W=pa[j+1]-pa[i]`，`while(2*(pa[m+1]-pa[i])<W)++m`；用引理 1 公式算 `w[i][j]`。
4. `fill_n(&f[0][0],mxn*mxn,inf)`；`f[0][0]=0`。
5. 对 $j=1..k$、$i=j..n$：`f[j][i]=min(f[j][i],f[j-1][t]+w[t][i-1])`，$t=j-1..i-1$。
6. 输出 `f[k][n]`。

### 复杂度

- 时间 $O(n^2+kn^2)\le10^6$；空间 $O(n^2)$，约 $176$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；六组手造数据（含加权中位数、$k>n$、$n=1$、平均数反例）与手算一致；另用"枚举所有连续分段 + 每段枚举所有楼坐标取最小"的独立暴力（不依赖中位数结论）对 $300$ 组随机小数据（$n\le7,k\le8$）逐组一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2803 学校选址 II（经典邮局问题）
// 直线上最近学校划分必为连续段 ⇒ 划分 DP；段费用 = 加权中位数费用
// w 用前缀和 + 单调中位数指针 O(n^2)；f 必须显式填 INF（默认 0 是合法费用！）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};
constexpr i64 inf{1145141919810};

int n,k;
i64 a[mxn],x[mxn],pa[mxn],px[mxn],w[mxn][mxn],f[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=1,d;i<n;++i)
	{
		cin>>d;
		x[i]=x[i-1]+d;
	}
	k=min(k,n);
	for(int i=0;i<n;++i)
	{
		pa[i+1]=pa[i]+a[i];
		px[i+1]=px[i]+a[i]*x[i];
	}
	for(int i=0;i<n;++i)
	{
		int m=i;
		for(int j=i;j<n;++j)
		{
			i64 W=pa[j+1]-pa[i];
			while(2*(pa[m+1]-pa[i])<W)
				++m;	// 加权中位数：左半权重首次 >= 总权重一半；m 随 j 单调右移
			w[i][j]=x[m]*(pa[m+1]-pa[i])-(px[m+1]-px[i])
				+(px[j+1]-px[m+1])-x[m]*(pa[j+1]-pa[m+1]);
		}
	}
	fill_n(&f[0][0],mxn*mxn,inf);	// 0 所学校覆盖不了任何楼，必须 INF 而非默认 0
	f[0][0]=0;
	for(int j=1;j<=k;++j)
		for(int i=j;i<=n;++i)
			for(int t=j-1;t<i;++t)
				f[j][i]=min(f[j][i],f[j-1][t]+w[t][i-1]);
	cout<<f[k][n]<<'\n';
	return 0;
}
```

### 代码说明

- `w[i][j]` 的两项分别是中位数左半（含 $m$）与右半的费用，全部用 `pa,px` 前缀和 $O(1)$ 拼出；`m` 指针只右移，正确性由引理 2 保证。
- `2*(pa[m+1]-pa[i])<W` 用乘法避免浮点除法；平局（恰好一半）时取**左**中位数，引理 1 证明平台段上任何点都最优，取左端点合法。
- `f` 的 INF 预填是本题头号坑：`f[0][i>0]` 若留默认 $0$，递推会认为"$0$ 所学校免费覆盖前 $i$ 栋"，答案恒 $0$。
- `k=min(k,n)` 之后 `f[k][n]` 必有合法切法（每栋一段），不会输出 INF；$k\ge n$ 时答案自然为 $0$。
- 全程 `i64`：虽然真实费用上界 $9.9\times10^7$ 在 `int` 内，INF 与中间量用 `i64` 更稳，也符合"哨兵显著大于答案"的原则。
