# P2449 [SDOI2005] 矩形 — 题解

## 一、解题过程：人类思考叙事

题意：平面上 $n$ 个轴平行矩形，顶点坐标都是 $\le10000$ 的非负整数，$n\le7000$。定义「块」：每个矩形自己是一个块；**如果两个块有一段公共的部分，它们就合成一个新块**。问最终有多少个不同的块。题面 Hint 里有一句极关键的话：**「注意：角重合不算同一个块。」** 还有一句：「橙色加粗的**线段**表示这里有重合的部分」。

**第一步：把「一段公共的部分」抠清楚。** 这是全题唯一的语义难点。「一段」意味着**有长度的线段**，一个点不算一段。于是：

- 两个矩形**面积重叠** ⇒ 公共部分含线段 ⇒ 合并；
- 两个矩形**只共用一条边（或边的一部分）**，面积交为 0 但交是一条正长度线段 ⇒ **合并**；
- 两个矩形**只在一个角上碰一下**，交是一个点 ⇒ **不合并**。

Hint 特意只把「角重合」排除出去，反过来说明「边重合」是要算的；配图用**加粗线段**而不是加粗区域来标注重合部分，也印证了这一点。如果误写成「必须面积重叠」（判定里全用严格 `<`），贴边的矩形会被错拆成两块；如果误写成「只要接触就算」（全用 `<=`），贴角的矩形会被错并成一块。**两种写法都错，正确条件夹在中间。**

**第二步：认出这是连通性问题。** 「合并」具有传递性（A 与 B 合、B 与 C 合 ⇒ A、B、C 同块），而且合并只取决于「有没有公共部分」，与合并顺序无关。这就是**无向图连通分量**：顶点是矩形，边是「两矩形交含正长度线段」，答案 = 连通分量数 ⇒ **并查集**。

**第三步：矩形级判定够不够？——一个必须回答的疑问。** 题目说的是「两个**块**有一段公共部分」，块是矩形的并集。会不会出现这种情况：块 A 与块 B 整体共享一条线段，但 A 里任何一个矩形与 B 里任何一个矩形都不共享线段？如果会，那只做两两矩形判定就漏合并了。

想清楚后发现**不会**：一条正长度线段被有限个闭矩形覆盖，必有某个矩形覆盖它的一个正长度子段（有限个点盖不住一条线段）。对 A 用一次、再对 B 用一次，就能抽出一对真正共享正长度线段的矩形。所以**块级合并 $\iff$ 矩形级合并**，两两判定 + 并查集是完备的。（这一步在第二节有完整证明，不能跳过。）

**第四步：几何判定写成两个整数。** 两个闭轴平行矩形的交仍是闭轴平行矩形：
$$[\max(x_1,x_1'),\ \min(x_2,x_2')]\times[\max(y_1,y_1'),\ \min(y_2,y_2')].$$
令 $dx=\min(x_2,x_2')-\max(x_1,x_1')$，$dy$ 同理。则：$dx<0$ 或 $dy<0$ ⇒ 空交；$dx=dy=0$ ⇒ 单点；否则（$dx\ge0,dy\ge0$ 且至少一个 $>0$）⇒ 含正长度线段。**坐标是整数，$dx,dy$ 也是整数，不需要任何 eps**，这是本题比一般计算几何舒服的地方。

**第五步：复杂度够不够？要不要扫描线？** $n\le7000$，两两配对 $\binom{7000}{2}\approx2.45\times10^7$，每次判定是几个 `min/max` 与比较，$O(1)$。总量 $2.45\times10^7$ 次基本运算——**完全跑得动**，实测最坏数据（7000 个完全相同的大矩形，剪枝失效）只要 **0.11s**。所以不需要扫描线 + 线段树那套重武器；并查集 $O(n^2\alpha(n))$ 就是本题的正解规模。

**第六步：另一条路，以及它为什么被放弃。** 坐标是 $\le10000$ 的整数，很自然想到「单位格子网格 + 洪水填充」：把每个矩形覆盖的单位格标记，然后数 **4-连通**块数。4-连通恰好对应「贴边算、贴角不算」（贴角的两格是斜对角，不 4-相邻）——这个视角反过来印证了第一步的语义判断，非常好用。但规模上：$10000\times10000=10^8$ 个格子，`char` 存储 100 MB、BFS 要考察 $4\times10^8$ 次邻居，$1$s 内不可能；若改成坐标离散化，每维最多 $2n=14000$ 个不同坐标，格子数反而涨到 $1.96\times10^8$，更糟。**所以网格法只适合当小规模验证器，不适合当正解。**（我真的用它做了独立对拍，见第四节。）

**第七步：一个便宜的剪枝。** 把矩形按 $x_1$ 升序排序。固定 $i$，内层枚举 $j>i$；一旦 $x_1^{(j)}>x_2^{(i)}$，则 $dx<0$ 不可能相交，而且**后面的 $j$ 的 $x_1$ 只会更大**，所以可以直接 `break`。最坏复杂度不变，但实际数据（矩形散布在 $10000\times10000$ 平面）上快很多。

**第八步：实现细节。**

1. 答案 = $n-$ 成功合并次数（每次成功合并把两个不同连通块并成一个，块数减一）。
2. 输入顺序是「左下 $x$、左下 $y$、右上 $x$、右上 $y$」，即 `x1 y1 x2 y2`。
3. 洛谷上**用标准输入输出**，不要 `freopen("PRO.IN")`（Background 明确说明）。
4. 并查集路径压缩即可，$n=7000$ 不需要按秩合并。
5. 排序后矩形编号变了，但并查集是在**排序后的下标**上建的，答案只关心块数，不关心编号，所以无需记录原序号。

手造小例子逐个验证：单个矩形 → 1；贴角 `[0,0,1,1]` 与 `[1,1,2,2]` → 2；贴边 `[0,0,1,1]` 与 `[1,0,2,1]` → 1；分离 → 2；面积重叠 → 1；三个矩形两两贴角 → 3；再加一个「桥」矩形同时贴到前两个 → 1。全部与预期一致。

## 二、思维链：完整证明

记矩形 $R_i=[x_1^{(i)},x_2^{(i)}]\times[y_1^{(i)},y_2^{(i)}]$ 为**闭**矩形（含边界），坐标为整数，$x_1\le x_2,\ y_1\le y_2$（正常矩形为严格小于）。

### 引理 1（交的代数形式）

两个闭轴平行矩形 $R=[x_1,x_2]\times[y_1,y_2]$、$R'=[x_1',x_2']\times[y_1',y_2']$ 的交为
$$R\cap R'=[X_1,X_2]\times[Y_1,Y_2],\quad X_1=\max(x_1,x_1'),\ X_2=\min(x_2,x_2'),\ Y_1=\max(y_1,y_1'),\ Y_2=\min(y_2,y_2').$$
记 $dx=X_2-X_1,\ dy=Y_2-Y_1$。则 $R\cap R'=\varnothing\iff dx<0$ 或 $dy<0$。

*证明*：点 $(p,q)\in R\cap R'$ 当且仅当 $x_1\le p\le x_2$ 且 $x_1'\le p\le x_2'$ 且 $y_1\le q\le y_2$ 且 $y_1'\le q\le y_2'$。前两条等价于 $\max(x_1,x_1')\le p\le\min(x_2,x_2')$，即 $X_1\le p\le X_2$；后两条同理等价于 $Y_1\le q\le Y_2$。故交恰为所述闭矩形（当 $X_1\le X_2$ 且 $Y_1\le Y_2$ 时非空）。若 $dx<0$ 即 $X_2<X_1$，则不存在满足 $X_1\le p\le X_2$ 的 $p$，交为空；$dy<0$ 同理。反之若 $dx\ge0$ 且 $dy\ge0$，点 $(X_1,Y_1)$ 同时满足四个不等式，属于交，故交非空。证毕。

### 引理 2（「含正长度线段」的判据）

设 $Q=[X_1,X_2]\times[Y_1,Y_2]$ 非空（$dx\ge0,dy\ge0$）。则 $Q$ 含有一条长度 $>0$ 的线段 $\iff$ $dx>0$ 或 $dy>0$（即 $Q$ 不是单点）。

*证明*：
($\Leftarrow$) 若 $dx>0$，取水平线段 $S=[X_1,X_2]\times\{Y_1\}$。对任意 $(p,Y_1)\in S$ 有 $X_1\le p\le X_2$、$Y_1\le Y_1\le Y_2$（因 $dy\ge0$），故 $S\subseteq Q$，且 $S$ 的长度为 $dx>0$。若 $dy>0$，对称地取竖直线段 $\{X_1\}\times[Y_1,Y_2]$，长度 $dy>0$。
($\Rightarrow$) 若 $dx=dy=0$，则 $X_1=X_2,\ Y_1=Y_2$，$Q=\{(X_1,Y_1)\}$ 是单点集。它的子集只有 $\varnothing$ 与自身，都不含长度 $>0$ 的线段（线段含无穷多点）。故逆否命题成立。证毕。

### 引理 3（矩形级合并判据）

两个矩形应被合并 $\iff dx\ge0\ \wedge\ dy\ge0\ \wedge\ (dx>0\vee dy>0)$。等价地，代码写成「若 $dx<0$ 或 $dy<0$ 或 $(dx=0\wedge dy=0)$ 则跳过」。

*证明*：由题意，合并的条件是公共部分含「一段」即正长度线段。由引理 1，公共部分是 $Q$（或空）；空集不含线段。由引理 2，非空 $Q$ 含正长度线段当且仅当 $dx>0$ 或 $dy>0$。合起来即所述判据。

**三类情形对照**：$dx>0,dy>0$（面积重叠）合并；$dx=0,dy>0$ 或 $dx>0,dy=0$（贴边/贴部分边）合并；$dx=dy=0$（贴角）不合并；$dx<0$ 或 $dy<0$（分离）不合并。证毕。

> **两个常见错误写法的反例**：
> - 全用严格不等号（要求 $dx>0\wedge dy>0$）：$R=[0,1]\times[0,1]$、$R'=[1,2]\times[0,1]$ 有 $dx=0,dy=1$，被错判为不合并，但它们的并是 $[0,2]\times[0,1]$ 一整块。
> - 全用非严格不等号（只判 $dx\ge0\wedge dy\ge0$）：$R=[0,1]\times[0,1]$、$R'=[1,2]\times[1,2]$ 有 $dx=dy=0$，被错判为合并，但 Hint 明确说角重合不算。

### 引理 4（块级合并 $\iff$ 矩形级合并：有限覆盖引理）

设块 $A=\bigcup_{i\in I}R_i$、块 $B=\bigcup_{j\in J}R_j$（有限个闭矩形之并）。则 $A\cap B$ 含正长度线段 $\iff$ 存在 $i\in I,j\in J$ 使 $R_i\cap R_j$ 含正长度线段。

*证明*：
($\Leftarrow$) $R_i\subseteq A,\ R_j\subseteq B$，故 $R_i\cap R_j\subseteq A\cap B$，其中的正长度线段也在 $A\cap B$ 中。

($\Rightarrow$) 设 $S\subseteq A\cap B$ 是一条长度 $L>0$ 的线段。把 $S$ 参数化为 $\{P(t):t\in[0,L]\}$（$P$ 为弧长参数，连续单射）。

**第一步**：$S\subseteq A=\bigcup_{i\in I}R_i$，故 $S=\bigcup_{i\in I}(R_i\cap S)$。每个 $R_i$ 是闭凸集，凸集与线段的交是线段（可能退化为点或空），且闭性保证它是**闭**子线段，对应参数区间 $[a_i,b_i]\subseteq[0,L]$（或空）。这些闭区间覆盖 $[0,L]$：$\bigcup_i[a_i,b_i]=[0,L]$。若所有 $i$ 都有 $a_i=b_i$（退化），则并集是有限点集，而 $[0,L]$（$L>0$）含无穷多点，矛盾。故存在 $i_0$ 使 $b_{i_0}>a_{i_0}$，即 $S'=R_{i_0}\cap S$ 是正长度闭子线段。

**第二步**：$S'\subseteq S\subseteq B=\bigcup_{j\in J}R_j$。对 $S'$ 重复第一步的论证（$S'$ 也是正长度线段，$J$ 有限），得 $j_0$ 使 $S''=R_{j_0}\cap S'$ 是正长度线段。

于是 $S''\subseteq R_{i_0}\cap R_{j_0}$，即这一对矩形的交含正长度线段。证毕。

> **这条引理是「两两矩形判定 + 并查集」合法性的根据**。没有它，我们无权把题目中「块与块」的合并规则替换成「矩形与矩形」的判定。注意证明只用到「有限个闭凸集」，与线段方向无关，因此即使公共线段是斜的也成立。

### 引理 5（块 = 连通分量）

建图 $G$：顶点为 $n$ 个矩形，$(i,j)$ 是边当且仅当 $R_i\cap R_j$ 含正长度线段（引理 3 的判据）。则题目定义的最终块划分恰为 $G$ 的连通分量划分。

*证明*：把「块」看作顶点集合的一个划分，初始为 $n$ 个单点集，每步把两个有公共线段的块并起来，直到不能合并。

**（块 $\subseteq$ 分量）** 对合并步数归纳：初始每个单点集当然含于某分量。若块 $A,B$ 合并，由引理 4 存在 $i\in A,j\in B$ 使 $(i,j)\in E(G)$。由归纳假设 $A$ 含于分量 $C_A$、$B$ 含于分量 $C_B$；边 $(i,j)$ 说明 $C_A=C_B$，故 $A\cup B$ 仍含于同一分量。不变量保持。

**（分量 $\subseteq$ 块）** 过程终止时，任意两个不同块之间都没有公共线段，由引理 4，**任意两个不同块之间都没有 $G$ 的边**。反设某分量 $C$ 被拆到 $\ge2$ 个块里，取 $u,v\in C$ 属于不同块。因 $C$ 连通，存在 $G$ 中路径 $u=w_0,w_1,\dots,w_t=v$。沿路径必存在相邻一对 $w_{s},w_{s+1}$ 属于不同块（否则所有 $w$ 同块，与 $u,v$ 不同块矛盾），但它们是 $G$ 的边，跨块——与「终止时无跨块边」矛盾。故每个分量完整落在一个块内。

两个包含关系合起来：块划分 = 分量划分。证毕。

### 引理 6（计数公式）

设并查集初始为 $n$ 个单点集，每处理一条边 $(i,j)$ 时若两端属于不同集合则合并。则最终集合数 $=n-(\text{成功合并次数})$，且等于 $G$ 的连通分量数。

*证明*：每次成功合并把两个**不同**集合变成一个，集合数恰减 $1$；失败（同集合）不改变集合数。初始 $n$，故最终集合数 $=n-\#\text{成功合并}$。

再证最终集合就是分量：由引理 5 的论证，合并只沿边进行，故每个集合含于某分量；反之若某分量被拆成两个集合，则该分量内存在跨集合的边（取分量内路径），而算法枚举了**所有**满足判据的对（即所有边），这条边被处理时两端必已同集合或触发合并——严格地说，对分量内任意两点，沿路径归纳可知它们最终同集合（路径上每条边被处理时，要么两端已同集合，要么合并使之同集合；集合只增不减）。故分量内所有点同集合，即分量 $\subseteq$ 集合。结合前者得相等。证毕。

### 引理 7（排序 + break 剪枝的正确性）

把矩形按 $x_1$ 升序排序（记排序后仍为 $R_0,\dots,R_{n-1}$）。固定 $i$，内层从 $j=i+1$ 递增枚举，条件为 $x_1^{(j)}\le x_2^{(i)}$；一旦不满足即终止内层循环。则被跳过的所有对 $(i,k)$（$k\ge j$）都不可能是边。

*证明*：排序保证 $k\ge j\Rightarrow x_1^{(k)}\ge x_1^{(j)}$。若 $x_1^{(j)}>x_2^{(i)}$，则 $x_1^{(k)}>x_2^{(i)}$。于是
$$dx=\min(x_2^{(i)},x_2^{(k)})-\max(x_1^{(i)},x_1^{(k)})\le x_2^{(i)}-x_1^{(k)}<0,$$
由引理 1 交为空，由引理 3 不是边。故跳过它们不丢任何合并。又每对 $(i,k)$（$i<k$）要么被内层枚举到，要么被本引理证明为非边，故所有边都被处理，引理 6 的前提成立。证毕。

### 引理 8（并查集操作正确性）

`getrt(x)`（`if(f[x]==x)return x; return f[x]=getrt(f[x]);`）返回 $x$ 所在集合的代表元，且路径压缩不改变划分；`f[u]=v`（$u\ne v$ 为两个代表元）把两集合并为一。

*证明*：把 `f` 看作父指针森林，每个集合是一棵树，代表元是根（`f[r]==r`）。
**查找**：对树高归纳。若 `f[x]==x`，$x$ 是根，返回自身，正确。否则 `getrt(f[x])` 由归纳假设返回 $x$ 所在树的根 $r$；赋值 `f[x]=r` 后返回 $r$。$x$ 与 $r$ 本就在同一棵树，改父指针只是把 $x$ 直接挂到根上，**树的顶点集合不变**，故划分不变，返回值正确。
**合并**：$u,v$ 是不同树的根，令 `f[u]=v` 把 $u$ 树挂到 $v$ 根下，两树合成一棵，顶点集恰为两集合之并；其余树不受影响。故实现的是集合并。证毕。

### 引理 9（单位格 4-连通视角：语义的独立佐证）

设所有矩形都是**正常**整数矩形（$x_1<x_2,\ y_1<y_2$）。把平面切成单位格 $C_{i,j}=[i,i+1]\times[j,j+1]$，令 $\mathrm{Cells}(R)=\{(i,j):C_{i,j}\subseteq R\}$，$\mathcal{C}=\bigcup_i\mathrm{Cells}(R_i)$。则
(a) $R_i\cap R_j$ 含正长度线段 $\iff$ $\mathrm{Cells}(R_i)$ 与 $\mathrm{Cells}(R_j)$ 相交或存在 4-相邻的格对；
(b) 块数 $=\mathcal{C}$ 的 4-连通分量数。

*证明*：
(a) ($\Rightarrow$) 由引理 1、2，交 $Q=[X_1,X_2]\times[Y_1,Y_2]$ 非空非单点，坐标皆整数。
- 若 $dx>0,dy>0$：$X_1+1\le X_2,\ Y_1+1\le Y_2$，故 $C_{X_1,Y_1}\subseteq Q\subseteq R_i\cap R_j$，两格集相交。
- 若 $dx=0,dy>0$：设 $R_i$ 是右边界为 $X_1$ 的那个（$x_2^{(i)}=X_1$），$R_j$ 是左边界为 $X_1$ 的那个。因 $R_i$ 正常，$x_1^{(i)}<x_2^{(i)}=X_1$ 且为整数 ⇒ $x_1^{(i)}\le X_1-1$；又 $[Y_1,Y_2]\subseteq[y_1^{(i)},y_2^{(i)}]$ 且 $Y_1+1\le Y_2$ ⇒ $C_{X_1-1,Y_1}\subseteq R_i$。同理 $C_{X_1,Y_1}\subseteq R_j$。这两格水平相邻（4-相邻）。
- $dx>0,dy=0$ 对称。

($\Leftarrow$) 若两格集相交，取公共格 $C\subseteq R_i\cap R_j$，则交含面积 $>0$，由引理 2 含正长度线段。若存在 4-相邻格对 $C_{p,q}\subseteq R_i$、$C_{p+1,q}\subseteq R_j$（水平情形），则 $R_i\supseteq[p,p+1]\times[q,q+1]$、$R_j\supseteq[p+1,p+2]\times[q,q+1]$，两者都含竖直线段 $\{p+1\}\times[q,q+1]$，长度 $1>0$，故交含正长度线段。竖直相邻对称。

(b) 每个正常整数矩形的 $\mathrm{Cells}(R_i)$ 非空且本身 4-连通（它是一个实心格矩形，任意两格可沿行/列折线到达）。由 (a)，矩形图的边恰对应格集的「相交或 4-相邻」。于是：矩形在同一连通分量 $\iff$ 它们的格集在 $\mathcal{C}$ 的同一 4-连通分量。严格地说，把每个矩形映到其格集所在的 4-连通分量，(a) 保证相邻矩形映到同一分量，故该映射在矩形连通分量上是常值；反之若两个矩形格集 4-连通，取格路径，路径上每格属于某矩形，相邻格要么同矩形要么由 (a) 给出矩形边，故两矩形在矩形图中连通。因此两边分量一一对应，数目相等。证毕。

> **这条引理的价值**：它把「贴边算、贴角不算」翻译成「4-连通而非 8-连通」，与 Hint 完全吻合，是对引理 3 语义判断的**独立佐证**；同时它给出了一个与并查集毫无关系的算法，可作小规模对拍基准。但 $10^8$ 量级的格子数使它在 $n=7000$、坐标 $\le10000$ 时不可行（见第一节第六步）。

### 定理（算法正确性）

程序输出的整数等于题目所求块数。

*证明*：程序读入 $n$ 个矩形，按 $x_1$ 排序（引理 7 保证排序 + 剪枝后仍枚举了所有可能成为边的对），对每对用引理 3 的判据判定，判据由引理 1、2 保证与「交含正长度线段」等价；由引理 4，这与题目「块有公共一段」的合并规则等价；由引理 5，最终块划分 = 图 $G$ 的连通分量划分；并查集操作由引理 8 正确维护划分，由引理 6 最终集合数 = 分量数 = $n-$ 成功合并次数，正是程序维护的 `ans`。故输出正确。证毕。

### 引理 10（复杂度）

时间 $O(n\log n+n^2\alpha(n))$，空间 $O(n)$。

*证明*：排序 $O(n\log n)$。双重循环至多 $\binom{n}{2}=n(n-1)/2$ 对，每对 $O(1)$ 的 `min/max` 与比较；判定为边时至多两次 `getrt` 与一次合并，路径压缩并查集单次均摊 $O(\alpha(n))$。故总时间 $O(n^2\alpha(n))$，$n=7000$ 时 $\binom{n}{2}=2.4495\times10^7$。剪枝（引理 7）只会减少枚举对数，不改变最坏界。空间：矩形数组 $O(n)$、父数组 $O(n)$。证毕。

**实测**：$n=7000$ 个完全相同的 $[0,10000]^2$ 矩形（剪枝完全失效的最坏形态）耗时 $0.11$s；$n=7000$ 随机矩形耗时 $0.056$s。

### 附：为什么不用扫描线

扫描线 + 线段树维护「当前活跃矩形」可以在 $O(n\log n)$ 内找出所有相交对，理论上更优。但本题 $n\le7000$，$O(n^2)$ 的常数极小（几个整数比较），实测 $0.1$s 级别，远低于时限；而扫描线要处理「贴边算、贴角不算」的退化事件排序（同一 $x$ 上进出事件的先后、$y$ 区间端点重合的判定），实现复杂度与出错概率都高得多。**按数据规模选择算法**：$n\le7000$ 时 $O(n^2)$ 并查集是性价比最高的正解；若 $n$ 到 $10^5$ 才必须上扫描线。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 抠「一段公共的部分」：正长度线段才算，点不算；由 Hint 反推「贴边算、贴角不算」。
- **reduce to easier problem** — 合并有传递性且与顺序无关 ⇒ 无向图连通分量 ⇒ 并查集，答案 = 分量数。
- **consider easier version** — 先怀疑「块级合并」是否强于「矩形级两两合并」，用有限覆盖引理证明二者等价，才敢只判矩形对。
- **explore its property** — 闭轴平行矩形的交仍是闭轴平行矩形，$dx,dy$ 两个整数就把「空 / 点 / 线段 / 面积」四类分完，无需 eps。
- **classic problem solution** — 并查集 + $O(n^2)$ 两两判定；$n\le7000\Rightarrow2.45\times10^7$ 次常数判定，规模允许，不必上扫描线。
- **reduce to easier problem** — 单位格 4-连通洪水填充：既佐证语义（4-连通而非 8-连通），又提供完全独立的验证器；但 $10^8$ 格子在全规模不可行。
- **classic problem solution** — 按 $x_1$ 排序 + 内层 `x1_j>x2_i` 即 break 的剪枝，最坏界不变、实际大幅加速。
- **discuss by category** — 面积重叠 / 贴边 / 贴角 / 分离四类分别对应合并、合并、不合并、不合并；答案用 $n-$ 成功合并次数维护。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| $n$ | 矩形数 | `int`，读入 | $\le7000$ |
| `r[i].x1/y1/x2/y2` | 第 $i$ 个矩形的左下、右上坐标 | `struct rect[mxn]`，读入后按 `x1` 升序排序 | 排序后下标即并查集下标 |
| `f[i]` | 并查集父指针 | `int[mxn]`，`iota(f,f+n,0)` | 根满足 `f[i]==i` |
| `getrt(x)` | 找代表元 + 路径压缩 | `int` 函数 | 不改变划分（引理 8） |
| `dx` | $\min(x_2^{(i)},x_2^{(j)})-\max(x_1^{(i)},x_1^{(j)})$ | `int`，每对重算 | $<0$ 分离，$=0$ 贴边/贴角 |
| `dy` | $y$ 方向同理 | `int`，每对重算 | 与 `dx` 联合分类 |
| `ans` | 当前块数 | `int`，初值 $n$ | 每成功合并 `--ans` |
| `u,v` | 两端代表元 | `int` | `u!=v` 才合并 |
| `mxn` | $7000+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速：`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`。
2. 读入 $n$ 与 $n$ 行 `x1 y1 x2 y2` 存入 `r`。
3. 按 `x1` 升序排序 `r`；`iota(f,f+n,0)` 初始化并查集；`ans=n`。
4. 对 $i=0\dots n-1$，内层 $j=i+1$ 起、条件 `j<n && r[j].x1<=r[i].x2`：
   1. 算 `dx`、`dy`；
   2. 若 `dx<0 || dy<0 || (dx==0&&dy==0)` 则 `continue`（分离或贴角）；
   3. 否则求 `u=getrt(i), v=getrt(j)`；若 `u!=v` 则 `f[u]=v; --ans;`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(n\log n+n^2\alpha(n))$，最坏 $\binom{7000}{2}\approx2.45\times10^7$ 对判定；实测最坏形态 $0.11$s。
- 空间：$O(n)$，两个长度 $7005$ 的数组。

### 验证状态

编译 `g++ -std=c++20 -O2` 通过。手造 7 组几何边界（单矩形 / 贴角 / 贴边 / 分离 / 面积重叠 / 两两贴角三连 / 加桥矩形）全部符合预期。**独立对拍**采用「单位格二维差分 + 4-连通洪水填充」（引理 9 保证其等价）：穷举坐标 $\in[0,3]$ 的全部 36 个正常矩形的**所有有序对（1296）与有序三元组（46656）**，共 **47952 组**零不一致；另跑 **300 组**随机数据（$n\le15$，坐标域 $4$ 或 $10$，密集贴边贴角）零不一致；再做 **8 组中等规模**独立比对（$n=500\sim3000$，坐标 $\le100$，含全部 $1\times1$ 单位矩形的极端贴角形态）全部一致。$n=7000$ 的三种形态（全同 / 散布 / 随机）另与「不排序不剪枝、判定式独立改写、最后数根」的第二份实现交叉验证一致，最坏耗时 $0.11$s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2449 [SDOI2005] 矩形
// 思路：块 = 连通分量。两矩形交为 [max x1,min x2]x[max y1,min y2]，
//       dx<0||dy<0 分离；dx==0&&dy==0 贴角（不算）；其余（含贴边）合并。
//       n<=7000，O(n^2) 并查集足够；按 x1 排序后内层可 break 剪枝。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{7005};

int n,f[mxn];
struct rect{int x1,y1,x2,y2;}r[mxn];

int getrt(int x)
{
	if(f[x]==x)return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)cin>>r[i].x1>>r[i].y1>>r[i].x2>>r[i].y2;
	sort(r,r+n,[](const rect&a,const rect&b){return a.x1<b.x1;});
	iota(f,f+n,0);
	int ans=n;
	for(int i=0;i<n;++i)
		for(int j=i+1;j<n&&r[j].x1<=r[i].x2;++j)//x1 升序，越过右边界即可 break
		{
			int dx=min(r[i].x2,r[j].x2)-max(r[i].x1,r[j].x1);
			int dy=min(r[i].y2,r[j].y2)-max(r[i].y1,r[j].y1);
			if(dx<0||dy<0||(dx==0&&dy==0))continue;//不相交，或只交于一个角
			int u=getrt(i),v=getrt(j);
			if(u!=v){f[u]=v;--ans;}
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **判定式是全题的核心**：`dx<0||dy<0` 排除分离，`(dx==0&&dy==0)` 排除贴角，剩下的（含 $dx=0,dy>0$ 这类贴边）一律合并。少写任何一半都会 WA。
- **排序 + 循环条件即剪枝**：`j<n&&r[j].x1<=r[i].x2` 写在 `for` 的条件里，等价于「一旦越过就 break」，由引理 7 保证不丢边。
- `ans` 初值 $n$，每次成功合并减一，省去最后再数一遍根。
- 排序打乱了原编号，但并查集建在排序后的下标上、答案只关心块数，因此不需要保存原序号。
- 坐标为整数，`dx/dy` 用 `int` 精确计算，**不要引入浮点或 eps**。
- 洛谷评测用标准输入输出，代码中不出现 `freopen`。
- `getrt` 是标准路径压缩一行式；$n=7000$ 下无需按秩合并。
