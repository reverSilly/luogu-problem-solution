# P2956 [USACO09OCT] The Robot Plow G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 一块 $X\times Y$ 的方格田（$1\le X,Y\le240$），给出 $I$ 个矩形（$1\le I\le200$），每个矩形由左下角 $(Xll,Yll)$ 与右上角 $(Xur,Yur)$ 描述（$1\le Xll\le Xur\le X$，$1\le Yll\le Yur\le Y$）。矩形之间可能重叠。求**至少被一个矩形覆盖的方格总数**。

**第一个必须抠清楚的点：坐标含不含端点？** 题面特意提醒"这个区间可能比初始设想的多一行或一列"。用题面给的例子裁决：$6\times4$ 的田，指令 $(1,1)(2,4)$ 与 $(1,3)(5,4)$，答案 $14$。

- 若坐标**含两端**：第一个矩形宽 $2-1+1=2$、高 $4-1+1=4$，共 $8$ 格；第二个宽 $5-1+1=5$、高 $4-3+1=2$，共 $10$ 格；重叠部分是列 $1..2$、行 $3..4$ 共 $4$ 格。并 $=8+10-4=14$ ✓。
- 若按半开理解（宽 $Xur-Xll$）：第一个 $1\times3=3$ 格，第二个 $4\times1=4$ 格，重叠 $1\times1=1$ 格，并 $=6\ne14$ ✗。

所以口径确定：**矩形覆盖闭区间 $[Xll,Xur]\times[Yll,Yur]$ 内的所有整格**，共 $(Xur-Xll+1)(Yur-Yll+1)$ 格。题面图示里 `**....` 占两列、`#####.` 占五列也印证了这一点。这是本题最容易 WA 的地方，必须先用例子钉死。

**第二步：能不能把各矩形面积加起来？** 不能。上面的例子已经给出反例：$8+10=18\ne14$，重叠的 $4$ 格被算了两次。题目问的是**并集的大小**，不是面积之和。

**第三步：容斥原理行不行？** 两个矩形有公式 $|A\cup B|=|A|+|B|-|A\cap B|$，但 $I$ 个矩形的容斥要枚举所有非空子集：

$$\Bigl|\bigcup_{i=1}^{I}R_i\Bigr|=\sum_{\emptyset\ne T\subseteq[I]}(-1)^{|T|+1}\Bigl|\bigcap_{i\in T}R_i\Bigr|,$$

共 $2^{200}-1$ 项，天文数字，直接淘汰。（矩形交仍是矩形、好算，但项数救不回来。）

**第四步：回到格子的视角。** 田只有 $240\times240=57600$ 格——**值域极小**。与其对矩形做集合运算，不如对每一格回答一个是非题："你被犁过吗？"一格被犁过 $\iff$ 它落在至少一个矩形里。于是开一个 `bool g[245][245]`，对每条指令把矩形内的格子全部置 `true`，最后数 `true` 的个数。

这个写法的妙处在于：**`bool` 标记天然去重**。同一格被置十次 `true` 还是 `true`，重叠问题在赋值语义层面自动消失，根本不需要容斥。

**第五步：算复杂度，确认不需要更花哨的东西。** 每条指令最多标记 $X\cdot Y=57600$ 格，$I=200$ 条共 $\le200\times57600\approx1.15\times10^7$ 次赋值，加一遍 $57600$ 的计数扫描。C++ 每秒轻松做 $10^8$ 次这种简单操作，$1.15\times10^7$ 毫无压力。

顺带想一步"如果值域更大怎么办"：若 $X,Y$ 到 $10^4$、$I$ 到 $10^5$，逐格标记就爆了，那时才需要**二维差分**（每个矩形四角 $O(1)$ 打差分标记，最后二维前缀和还原，$O(I+XY)$）或扫描线 + 线段树（$O(I\log I)$，与值域无关）。但本题 $1.15\times10^7$ 的上界摆在这里，直接标记就是最简单、最不易写错的正解。**先算账再选工具，不为用不上的规模付代码复杂度。**

**手造数据核对。** 第一组用题面例子：

```
输入：        输出：
6 4 2         14
1 1 2 4
1 3 5 4
```

手算 $8+10-4=14$ ✓（这组同时钉死了"含端点"口径）。

第二组打最小边界：`1 1 1 / 1 1 1 1`——$1\times1$ 的田、一个单格矩形，输出 $1$。若误按半开理解会输出 $0$，立刻暴露。

第三组打去重：`3 3 2 / 1 1 3 3 / 1 1 3 3`——同一矩形犁两遍，输出 $9$ 而不是 $18$。

第四、五组打上限：`240 240 1 / 1 1 240 240` 输出 $57600$；以及 $200$ 条满田指令的最坏标记量数据，输出仍 $57600$。五组全部与手算一致。

## 二、思维链：完整证明

**记号。** 格子用整数坐标 $(x,y)$（$1\le x\le X,1\le y\le Y$）标识。第 $i$ 条指令的矩形为格集 $R_i=\{(x,y):Xll_i\le x\le Xur_i,\ Yll_i\le y\le Yur_i\}$。目标是 $\bigl|\bigcup_{i=1}^{I}R_i\bigr|$。程序内部转 0-based：读入后四个坐标各减 $1$，标记 `g[x][y]`（$0\le x<X,0\le y<Y$）。

---

### 引理 1（坐标口径：闭区间，含两端）

第 $i$ 条指令覆盖的格集恰为 $R_i$（闭区间定义），其大小为 $(Xur_i-Xll_i+1)(Yur_i-Yll_i+1)$。

*证明*：题意解读论证。题面明文写"机器人会犁耕区间 $(Xll\dots Xur,\ Yll\dots Yur)$ 内的所有田地方格"，省略号记法表示含两端；又特意警告可能"多一行或一列"，提示读者不要按半开理解。用题面例子裁决：两条指令 $(1,1)(2,4)$、$(1,3)(5,4)$ 答案为 $14$。闭区间口径下 $|R_1|=2\times4=8$，$|R_2|=5\times2=10$，$R_1\cap R_2=[1,2]\times[3,4]$ 共 $4$ 格，由两集合容斥 $|R_1\cup R_2|=8+10-4=14$，与题面一致；半开口径下得 $3+4-1=6\ne14$，矛盾。题面图示（`**` 两列、`#####` 五列）亦与闭区间吻合。故口径为闭区间。

大小公式：$x$ 可取 $Xll,Xll+1,\dots,Xur$ 共 $Xur-Xll+1$ 个整数，$y$ 同理 $Yur-Yll+1$ 个，格集是两坐标区间的笛卡尔积，大小为两长度之积。证毕。

### 引理 2（目标是并集，面积和与容斥都不可行）

(a) 一般地 $\bigl|\bigcup R_i\bigr|\ne\sum|R_i|$；(b) 容斥公式正确但需 $2^I-1$ 项，$I=200$ 时不可计算。

*证明*：(a) 反例即题面例子：$\sum|R_i|=18$ 而并集为 $14$（引理 1 已算）。一般地，当两矩形相交非空时，交内每格在 $\sum|R_i|$ 中被计至少两次而在并集中恰一次，故和严格偏大。

(b) 容斥原理（标准集合恒等式）：对任意有限集族，$\bigl|\bigcup_{i\in[I]}R_i\bigr|=\sum_{\emptyset\ne T\subseteq[I]}(-1)^{|T|+1}\bigl|\bigcap_{i\in T}R_i\bigr|$。其正确性可由"每格被计的净次数"验证：设某格恰属于 $k\ge1$ 个矩形，则它在含于这 $k$ 个矩形的每个非空子集 $T$ 的交项中各被计一次，净系数 $\sum_{t=1}^{k}\binom{k}{t}(-1)^{t+1}=1-(1-1)^k=1$（二项式定理），恰计一次；不属于任何矩形的格净系数 $0$。故公式正确。但非空子集数为 $2^I-1\ge2^{200}-1>10^{60}$，任何计算机都无法枚举，路线不可行。证毕。

### 引理 3（打标记的正确性：bool 赋值天然去重）

处理完前 $t$ 条指令后，对任意格 $(x,y)$：`g[x][y]==true` $\iff(x,y)\in\bigcup_{i=1}^{t}R_i$（坐标已转 0-based）。

*证明*：对 $t$ 归纳。

**基础** $t=0$：`g` 为全局 `bool` 数组，零初始化即全 `false`；空并集为空，等价成立 ✓。（注意这里依赖的是"全 false = 全未覆盖"，与"int 数组默认 0 不是 INF"的陷阱方向相反——本题 $0$ 恰好就是正确的初值。）

**归纳步**：设 $t-1$ 时成立。第 $t$ 条指令把满足 $x1_t\le x\le x2_t,\ y1_t\le y\le y2_t$ 的格子置 `true`（0-based 闭区间，引理 1 的口径），其余格子不动。分两类：

- 格 $(x,y)\in R_t$：被置 `true`；且 $(x,y)\in\bigcup_{i\le t}R_i$，等价式两边同真 ✓。
- 格 $(x,y)\notin R_t$：`g` 值不变，由归纳假设等于"$\in\bigcup_{i\le t-1}R_i$"；而 $(x,y)\notin R_t$ 时 "$\in\bigcup_{i\le t}R_i$" $\iff$ "$\in\bigcup_{i\le t-1}R_i$"，等价式保持 ✓。

关键点是 `true` 的**幂等性**：已在并集中的格再次被置 `true` 不变，所以重叠矩形不会造成任何重复计数——计数阶段每格只贡献 $0$ 或 $1$。归纳完成。证毕。

### 引理 4（计数即答案）

最终 `ans=`$\sum_{x=0}^{X-1}\sum_{y=0}^{Y-1}$`g[x][y]` 恰为 $\bigl|\bigcup_{i=1}^{I}R_i\bigr|$。

*证明*：由引理 3（$t=I$），`g[x][y]` 为 `true` 当且仅当该格属于并集。`bool` 参与加法时 `true` 计 $1$、`false` 计 $0$，故 `ans` 等于并集中格子的个数。又所有 $R_i\subseteq[1,X]\times[1,Y]$（题面保证坐标不越界），转 0-based 后落在扫描范围 $[0,X)\times[0,Y)$ 内，无遗漏；扫描范围外的格子不存在。故 `ans` 恰为并集大小。证毕。

### 引理 5（下标安全）

全程对 `g` 的访问满足 $0\le x\le X-1\le239$、$0\le y\le Y-1\le239$，不越界。

*证明*：题面保证 $1\le Xll\le Xur\le X\le240$，减 $1$ 后 $0\le x1\le x2\le X-1\le239$；标记循环 `x` 从 $x1$ 到 $x2$、`y` 从 $y1$ 到 $y2$，均在此范围内。计数循环 `x<X,y<Y` 同理。数组尺寸 $\texttt{mxn}=245>240$，最大合法下标 $244\ge239$ ✓。证毕。

### 引理 6（复杂度）

时间 $O(I\cdot X\cdot Y+X\cdot Y)$，空间 $O(X\cdot Y)$。

*证明*：第 $i$ 条指令的标记次数为 $|R_i|\le X\cdot Y$，故标记总量 $\le I\cdot X\cdot Y=200\times240\times240=1.152\times10^7$；计数扫描 $X\cdot Y=57600$ 次。每次操作是常数时间的数组赋值 / 加法，总时间 $O(IXY+XY)$，代入约 $1.16\times10^7$ 次基本操作，远低于常见时限对应的 $\sim10^8$ 量级。空间：`bool g[245][245]` $\approx60$ KB，加常数变量。证毕。

**对比二维差分**：差分做法每指令 $O(1)$（四角加减）、还原 $O(XY)$，总 $O(I+XY)$，渐近更优；但本题 $I\cdot XY$ 的常数积已经足够小，差分的前缀和还原反而多一层下标细节（边界补零、累加方向），直接标记是复杂度与出错率的更好平衡。若 $X,Y\ge10^4$ 则必须换差分或扫描线——这是"按值域选工具"的分界。

### 定理

程序输出恰为被犁过的方格总数，时间 $O(IXY)$、空间 $O(XY)$。

*证明*：引理 1 钉死坐标口径与矩形格集；引理 2 排除面积和与容斥两条歧路，确认目标是并集；引理 3 保证标记数组精确刻画并集（幂等赋值去重）；引理 4 保证计数即并集大小；引理 5 保证无越界；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 用题面例子（答案 14）裁决坐标口径：闭区间含两端，矩形有 $(Xur-Xll+1)(Yur-Yll+1)$ 格；半开理解得 6，立刻排除。
2. **consider easier version** — 先想"面积直接相加"：重叠反例 $8+10=18\ne14$ 否掉；目标是并集不是和。
3. **classic problem solution** — 容斥原理公式正确但 $2^{200}$ 项不可枚举，排除。
4. **reduce to easier problem** — 值域极小（$57600$ 格）⇒ 把"矩形集合运算"翻转为"逐格是非题"：bool 数组打标记，幂等赋值天然去重，重叠问题在语义层面消失。
5. **discuss by category** — 按值域选工具：本题 $I\cdot XY\approx1.15\times10^7$ 直接标记即可；值域再大才升级二维差分 $O(I+XY)$ 或扫描线 $O(I\log I)$。
6. **explore its property** — 全局 bool 数组默认 false 恰好是"未覆盖"的正确初值（与 int 数组默认 0 不是 INF 的陷阱方向相反，无需 fill）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `X,Y` | 田的宽、高（格数），$\le240$ | `int` | 读入 |
| `I` | 指令条数，$\le200$ | `int` | 读入 |
| `mxn` | 数组尺寸 $240+5$ | `constexpr int` | 两个维度共用 |
| `g[x][y]` | 格 $(x,y)$（0-based）是否被犁过 | `bool[][]` | 全局默认 `false`=未覆盖，恰好正确 |
| `x1,y1,x2,y2` | 当前矩形的左下、右上坐标 | `int` | 读入后各 `--` 转 0-based，**循环含两端** |
| `ans` | 被犁过的格子总数 | `int` | $0$，计数阶段累加 `g[x][y]` |

### 算法步骤

1. I/O 加速三行；读 $X,Y,I$。
2. 每条指令读 $x1,y1,x2,y2$，四个坐标各减 $1$。
3. 双重循环 $x\in[x1,x2]$、$y\in[y1,y2]$（闭区间），置 `g[x][y]=true`。
4. 全部指令处理后，扫 $x\in[0,X)$、$y\in[0,Y)$，`ans+=g[x][y]`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(I\cdot X\cdot Y)\le1.152\times10^7$ 次赋值 + $57600$ 次计数。
- 空间：$O(XY)\approx60$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子输出 14；单格田、重复矩形、满田、200 条满田指令最坏数据共五组全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2956 [USACO09OCT] The Robot Plow G
// 矩形并的格子数：直接打标记。bool 标记天然去重，重叠不会重复计数
// 坐标含两端：矩形覆盖 (x2-x1+1)*(y2-y1+1) 格，读入后转 0-based
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{245};

int X,Y,I,ans;
bool g[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>X>>Y>>I;
	for(int i=0,x1,y1,x2,y2;i<I;++i)
	{
		cin>>x1>>y1>>x2>>y2;--x1;--y1;--x2;--y2;
		for(int x=x1;x<=x2;++x)
			for(int y=y1;y<=y2;++y)
				g[x][y]=true;
	}
	for(int x=0;x<X;++x)
		for(int y=0;y<Y;++y)
			ans+=g[x][y];
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`x<=x2` 而不是 `x<x2`**：坐标含两端是本题第一易错点（引理 1 用题面例子钉死）。四个坐标都要 `--`，漏减任何一个都会整体平移一格。
- `g` 是 `bool`：全局零初始化 = 全 `false` = 全未覆盖，初值恰好正确，不需要 `fill`；重复置 `true` 幂等，重叠自动去重（引理 3）。
- 计数用 `ans+=g[x][y]`，`bool` 隐式转 $0/1$；也可写 `if(g[x][y])++ans;`，等价。
- 答案上界 $X\cdot Y=57600$，`int` 绰绰有余，不需要 `long long`。
- 若把标记循环写成"先差分再前缀和"，本题同样能过但下标细节更多；在 $1.15\times10^7$ 的运算量面前，直接标记是更稳的选择。
