# P2969 [USACO09DEC] Music Notes S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一首歌由 $N$ 个音符顺序演奏（$N\le 5\times10^4$），第 $i$ 个音符持续 $B_i$ 个节拍（$1\le B_i\le 10^4$），从时刻 $0$ 开始：第 $1$ 个音符占据时间区间 $[0,B_1)$，第 $2$ 个占据 $[B_1,B_1+B_2)$，依此类推。注意题面的措辞是「在时间 $T$ 到时间 $T+1$ **之前**」，即每个音符占据的是**左闭右开**区间，整拍时刻 $T$ 恰好落在某个音符的开头时算新音符。有 $Q$ 个询问（$Q\le 5\times10^4$），每个给一个时刻 $T_i$（$0\le T_i\le \text{end\_of\_song}$），问区间 $[T_i,T_i+1)$ 里在演奏第几个音符，输出音符编号（$1$ 到 $N$）。

**边界口径（题面有一处含糊，先说清楚）。** 题面写 $T_i\le \text{end\_of\_song}$，但当 $T_i$ 恰好等于整首歌的总长 $S=B_1+\dots+B_N$ 时，区间 $[S,S+1)$ 里**没有任何音符在演奏**——题目没有定义这种情况的答案。我采用的口径是：答案统一为「**第一个满足前缀和 $>T$ 的音符下标**」，即 `upper_bound` 的自然语义。这个公式对所有 $T<S$ 都精确给出覆盖 $[T,T+1)$ 的音符；对 $T=S$ 它自然延拓为 $N+1$（「第 $N$ 个音符之后的虚拟位置」）。依据：这是前缀和二分最标准、最无分支的写法，也是本题作为「前缀和 + 二分」模板题的自然语义；若数据真的包含 $T=S$ 且期望别的值，任何统一公式都无法同时满足，只能赌出题人按标准语义造数据。下文引理 4 会把这个边界单独列出来。

**第一步：把「音符」翻译成「区间」。** 设前缀和 $s_i=B_1+\dots+B_i$（$s_0=0$）。第 $i$ 个音符占据 $[s_{i-1},s_i)$。于是问题变成：**给定 $T$，找唯一的 $i$ 使 $s_{i-1}\le T<s_i$**。这些区间首尾相接、互不重叠，把 $[0,s_N)$ 完整铺满——「唯一」是有保证的，不是碰运气。

**第二步：暴力为什么不行。** 每个询问从头扫前缀和，找到第一个 $s_i>T$ 就停。单次 $O(N)$，总量 $NQ=2.5\times10^9$，稳稳超时。但暴力的「找第一个 $s_i>T$」这个动作本身透露了关键信息。

**第三步：抓住 $B_i\ge 1$ 这个条件。** 它保证前缀和**严格递增**：$s_0<s_1<\dots<s_N$。于是谓词 $P(i)=[s_i>T]$ 长这样：

$$\underbrace{\text{false},\dots,\text{false}}_{s_i\le T},\underbrace{\text{true},\dots,\text{true}}_{s_i>T}$$

一旦变 true 就永远 true——**单调谓词**。找「第一个 true」正是二分查找的标准场景，`std::upper_bound` 一行搞定，单次 $O(\log N)$。总量 $N+Q\log N\approx 8.5\times10^5$，轻松通过。

这一步是本题唯一的思维跳跃：**「找包含 $T$ 的区间」归约成「在严格递增序列里找第一个大于 $T$ 的元素」**。之所以能归约，靠的就是「区间左闭右开 + 前缀和严格递增」这两条性质合力给出的单调性。

**第四步：几个必须抠清楚的细节。**

1. **`upper_bound` 还是 `lower_bound`？** 区间是左闭右开 $[s_{i-1},s_i)$，$T=s_{i-1}$ 时答案已经是第 $i$ 个音符，所以要找**严格大于** $T$ 的第一个前缀和，即 `upper_bound`。用 `lower_bound`（第一个 $\ge T$）会在每个整拍边界上把答案错成前一个音符。
2. **输出 $+1$。** 内部 0-based：`upper_bound(s,s+n,t)-s` 是 0-based 下标，题目要 1-based 编号，输出时 $+1$。
3. **值域。** $s_N\le 5\times10^4\times10^4=5\times10^8<2^{31}$，`int` 其实装得下；我仍用 `long long` 存前缀和与 $T$，零成本的保险（也避免读入 $T$ 时的类型不一致）。
4. **$T=0$。** $B_1\ge1$ 保证 $s_0=0\le T<s_1$，`upper_bound` 返回下标 $0$，输出 $1$，正确。

**手造数据核对。** 题面自带一组样例（音符时长 $2,1,3$，询问 $2,3,4,0,1$），直接用它，再补两组打边界：

第一组（题面样例）：前缀和 $s=[2,3,6]$。

| $T$ | 第一个 $s_i>T$ | 输出 | 题面期望 |
|---|---|---|---|
| 2 | $s_1=3$（下标 1） | 2 | 2 ✓ |
| 3 | $s_2=6$（下标 2） | 3 | 3 ✓ |
| 4 | $s_2=6$ | 3 | 3 ✓ |
| 0 | $s_0=2$ | 1 | 1 ✓ |
| 1 | $s_0=2$ | 1 | 1 ✓ |

第二组（单音符 + 总长边界）：$N=1,B=[5]$，询问 $0,4,5$ → 输出 `1 1 2`。前两个是「音符内部」与「最后一拍」，第三个就是上面声明的 $T=S$ 口径（公式延拓为 $N+1=2$）。

第三组（连续整拍切换）：$N=2,B=[1,1]$，询问 $0,1$ → 输出 `1 2`。专打「$T$ 恰好等于前缀和」时 `upper_bound` 与 `lower_bound` 的分歧：$T=1=s_1$ 必须答第 $2$ 个音符。

## 二、思维链：完整证明

**记号。** 音符下标内部用 $0\le i<N$。前缀和数组 $s[i]=\sum_{j=0}^{i}B_j$（代码语义），数学上另记 $S_i=\sum_{j=1}^{i}B_j$（$1$-based，$S_0=0$），两者关系 $s[i]=S_{i+1}$。总长 $S_N\le 5\times10^8$。询问时刻 $T\in[0,S_N]$。

---

### 引理 1（音符区间构成 $[0,S_N)$ 的一个划分）

第 $i$ 个音符（$1\le i\le N$）占据区间 $I_i=[S_{i-1},S_i)$。则：

(a) 两两不交：$i\ne j\Rightarrow I_i\cap I_j=\varnothing$；
(b) 完整覆盖：$\bigcup_{i=1}^{N}I_i=[0,S_N)$。

*证明*：不妨 $i<j$。则 $S_i\le S_{j-1}$（前缀和单调不减，引理 2 会证严格递增，这里只用单调不减：$S_{j-1}-S_i=\sum_{k=i+1}^{j-1}B_k\ge0$，空和为 $0$）。$I_i$ 中每个点 $x<S_i\le S_{j-1}$，而 $I_j$ 中每个点 $x\ge S_{j-1}$，故不交，(a) 成立。

(b) 对 $N$ 归纳。$N=1$：$I_1=[0,B_1)=[0,S_1)$ ✓。设 $N-1$ 成立：$\bigcup_{i=1}^{N-1}I_i=[0,S_{N-1})$。而 $I_N=[S_{N-1},S_N)$ 与之首尾相接（左端点恰为前一段的右端点，左闭右开保证无缝且不重叠），并集为 $[0,S_N)$ ✓。证毕。

**推论**：对任意 $T\in[0,S_N)$，存在**唯一**的 $i$ 使 $T\in I_i$，即 $S_{i-1}\le T<S_i$。存在性由 (b)，唯一性由 (a)。这保证题目对合法询问的答案良定义。

---

### 引理 2（前缀和严格递增）

$S_0<S_1<\dots<S_N$。

*证明*：$S_i-S_{i-1}=B_i\ge1>0$（题面约束 $B_i\ge1$）。逐项相加即得严格递增链。证毕。

**这条引理是二分的命根子**：若允许 $B_i=0$，前缀和会出现平台，谓词 $[s_i>T]$ 仍单调但「第一个 true」对应的音符可能时长为 $0$（不占据任何时刻），答案语义就崩了。$B_i\ge1$ 同时保证了「严格递增」与「每个音符真实占据至少一拍」。

---

### 引理 3（答案 = 第一个大于 $T$ 的前缀和的下标）

设 $T\in[0,S_N)$。令 $i^\*=\min\{i\in[1,N]:S_i>T\}$（$1$-based）。则 $T\in I_{i^\*}$，即答案就是 $i^\*$。用代码的 0-based 前缀和数组表述：`upper_bound(s,s+n,T)-s` 等于 $i^\*-1$，输出再加 $1$ 即 $i^\*$。

*证明*：集合 $\{i:S_i>T\}$ 非空，因为 $S_N>T$（$T<S_N$ 是前提）。有限非空整数集有最小元，$i^\*$ 良定义。

证 $S_{i^\*-1}\le T$：若 $i^\*=1$，$S_0=0\le T$（$T\ge0$）✓。若 $i^\*>1$，由最小性，$i^\*-1$ 不在集合中，即 $S_{i^\*-1}\le T$ ✓。又由定义 $S_{i^\*}>T$，故 $S_{i^\*-1}\le T<S_{i^\*}$，即 $T\in I_{i^\*}$。由引理 1 推论的唯一性，答案就是 $i^\*$。

代码对应：$s[i]=S_{i+1}$ 严格递增（引理 2），`upper_bound(s,s+n,T)` 按定义返回第一个满足 $s[i]>T$ 的位置 $i_0$，则 $i_0=i^\*-1$，输出 $i_0+1=i^\*$ ✓。证毕。

---

### 引理 4（边界行为）

(a) $T=0$ 时答案为 $1$。
(b) $T\in[S_{N-1},S_N)$（最后一拍区间）时答案为 $N$。
(c) $T=S_N$ 时 `upper_bound` 返回 `s+n`，程序输出 $N+1$；这是第一部分声明的口径：题面未定义该点的答案，程序按「第一个前缀和 $>T$」的统一公式自然延拓。

*证明*：(a) $S_1=B_1\ge1>0=T$，且 $S_0=0\le T$，由引理 3 答案 $i^\*=1$。(b) $S_N>T$ 而对 $i<N$ 有 $S_i\le S_{N-1}\le T$，故 $i^\*=N$。(c) 所有 $s[i]=S_{i+1}\le S_N=T$，没有元素 $>T$，`upper_bound` 按标准库定义返回尾后位置 $n$，输出 $n+1=N+1$。程序不会越界访问（`upper_bound` 只比较不 deref 尾后位置），行为确定。证毕。

---

### 引理 5（单调谓词上二分的正确性：`upper_bound` 的循环不变量）

设数组 $s[0..N)$ 严格递增，$T$ 为任意值。谓词 $P(i)=[s[i]>T]$ 单调：$P(i)$ 真 $\Rightarrow$ 对所有 $j>i$，$P(j)$ 真。二分查找「第一个 true」（不存在则返回 $N$）的算法维护区间 $[l,r]$，不变量为：

$$\text{所有 }i<l:\neg P(i);\qquad \text{所有 }i\ge r:P(i)\text{（}r=N\text{ 时视为空约束）}.$$

初始 $l=0,r=N$ 不变量空真。每步取 $mid=\lfloor(l+r)/2\rfloor$：若 $P(mid)$ 真，令 $r=mid$——由单调性，所有 $i\ge mid$ 皆真，右半约束保持；若 $P(mid)$ 假，令 $l=mid+1$——由单调性的逆否（$P(mid)$ 假 $\Rightarrow$ 所有 $i\le mid$ 皆假），左半约束保持。区间长度每步至少减半，终将 $l=r$。此时不变量给出：$i<l$ 皆假、$i\ge l$ 皆真，故 $l$ 恰为第一个 true 的位置（全假时 $l=N$）。`std::upper_bound` 实现的正是这一过程。

*证明*：单调性：$j>i\Rightarrow s[j]>s[i]$（引理 2 的严格递增），故 $s[i]>T\Rightarrow s[j]>T$；逆否命题给出「$P(mid)$ 假 $\Rightarrow$ 所有 $i\le mid$ 假」（对 $i\le mid$，若 $P(i)$ 真则由单调性 $P(mid)$ 真，矛盾）。其余逐句已在上面论证：初始空真、两分支各自保持对应半边的约束、长度 $\lceil(r-l)/2\rceil$ 严格递减保证终止、终止时不变量恰好刻画「第一个 true」。证毕。

---

### 引理 6（复杂度与值域）

时间 $O(N+Q\log N)$，空间 $O(N)$。所有数值 $\le5\times10^8$，`int` 可容纳；实现用 `i64` 留余量。

*证明*：读入与递推前缀和 $O(N)$（每音符一次加法）。每询问一次 `upper_bound`，由引理 5 区间长度每步减半，至多 $\lceil\log_2(N+1)\rceil\le16$ 次比较，共 $O(Q\log N)$。输出 $O(Q)$。合计 $O(N+Q\log N)\approx5\times10^4+5\times10^4\times16=8.5\times10^5$ 次基本操作。空间只有一个长度 $N$ 的前缀和数组，$O(N)$。值域：$S_N=\sum B_i\le5\times10^4\times10^4=5\times10^8<2^{31}-1\approx2.147\times10^9$；$T\le S_N$ 同界。证毕。

---

### 定理

对每个询问 $T\in[0,S_N)$，程序输出覆盖 $[T,T+1)$ 的音符的 1-based 编号；$T=S_N$ 时按统一公式输出 $N+1$（口径见第一部分）。总复杂度 $O(N+Q\log N)$。

*证明*：引理 1 保证答案良定义（区间划分）；引理 2 保证前缀和严格递增；引理 3 把「覆盖 $T$ 的音符」等价转化为「第一个 $>T$ 的前缀和下标 $+1$」；引理 5 保证 `upper_bound` 恰好求出该下标；引理 4 逐一核对 $T=0$、最后一拍、$T=S_N$ 三个边界；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 音符 = 前缀和切出的左闭右开区间 $[S_{i-1},S_i)$；$B_i\ge1$ ⇒ 前缀和严格递增、区间无缝铺满。
2. **consider easier version** — 单询问暴力扫前缀和 $O(N)$，总量 $NQ=2.5\times10^9$ 超时，确认需要更快的定位。
3. **reduce to easier problem** — 「找覆盖 $T$ 的区间」= 「找第一个 $>T$ 的前缀和」：谓词 $[s_i>T]$ 单调，问题塌缩成有序序列二分。
4. **classic problem solution** — `upper_bound` 二分，单查 $O(\log N)$；左闭右开语义决定必须用「严格大于」而非「大于等于」。
5. **discuss by category** — 边界三类：$T=0$、$T$ 恰为某前缀和（整拍切换）、$T=S_N$（题面未定义，按公式延拓为 $N+1$ 并显式声明口径）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 音符个数 $N\le5\times10^4$ | `int` | 读入 |
| `q` | 询问个数 $Q\le5\times10^4$ | `int` | 读入 |
| `mxn` | $50000+5$ | `constexpr int` | 数组尺寸松弛 |
| `s[i]` | 前 $i+1$ 个音符的总节拍 $S_{i+1}$，严格递增 | `i64[mxn]` | `s[i]=b+(i?s[i-1]:0)`；**音符 $i$ 覆盖 $[s[i-1],s[i])$，$s[-1]$ 视为 $0$** |
| `b` | 当前读入的音符时长 $B_i$ | `int`（循环内临时） | 每音符读入 |
| `t` | 当前询问时刻 $T$ | `i64` | 每询问读入 |
| 答案 | `upper_bound(s,s+n,t)-s+1` | `int` 表达式 | 第一个 $>t$ 的前缀和下标（0-based）$+1$ |

### 算法步骤

1. I/O 加速三行（`cin.tie` → `cout.tie` → `sync_with_stdio`）。
2. 读 $N,Q$；顺序读入 $B_i$，递推前缀和 `s[i]=b+(i?s[i-1]:0)`。
3. 每个询问读 `t`，输出 `upper_bound(s,s+n,t)-s+1` 与 `'\n'`。

### 复杂度

- 时间：$O(N+Q\log N)\approx8.5\times10^5$ 次基本操作。
- 空间：$O(N)$，一个 `i64` 前缀和数组约 $0.4$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例（$2,1,3$；询问 $2,3,4,0,1$）输出 `2 3 3 1 1` 逐条吻合；另造「单音符 + $T=S$ 边界」「连续整拍切换」两组手算数据全对。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2969 [USACO09DEC] Music Notes S
// 前缀和严格递增 ⇒ 「s[i]>T」是单调谓词 ⇒ upper_bound 二分
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{50005};

int n,q;
i64 s[mxn];	// s[i]=前 i+1 个音符的总节拍数；音符 i 覆盖 [s[i-1],s[i])，s[-1] 视为 0

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>q;
	for(int i=0,b;i<n;++i)
	{
		cin>>b;
		s[i]=b+(i?s[i-1]:0);
	}
	for(int i=0;i<q;++i)
	{
		i64 t;
		cin>>t;
		// 第一个 s[i]>t 的位置就是覆盖时刻 t 的音符（0-based），输出 +1
		cout<<upper_bound(s,s+n,t)-s+1<<'\n';
	}
	return 0;
}
```

### 代码说明

- **`upper_bound` 不能换成 `lower_bound`**：区间左闭右开，$T$ 恰等于某前缀和时属于**后一个**音符，必须找「严格大于」。这是本题唯一能写错的核心点。
- `s[i]=b+(i?s[i-1]:0)` 用三目处理 $i=0$ 的边界，避免访问 `s[-1]`；也可以先 `s[0]=b` 再循环，等价。
- 前缀和与 $T$ 用 `i64`：$5\times10^8$ 其实在 `int` 内，但 `long long` 是零成本保险，且 `upper_bound` 的比较类型与数组一致，不会有隐式转换惊喜。
- 输出 `-s+1`：指针差是 0-based 下标，题目要 1-based 编号。$T=S_N$ 时差为 $n$，输出 $N+1$，即第一部分声明的口径，程序不越界。
- 全局数组默认 $0$ 在本题**无害**：`s` 的每个格子都会被读入循环赋值，`upper_bound` 只访问 $[0,n)$，不存在「未初始化格子被当成合法值」的陷阱。
