# P2364 [CHCI 2001 Final Exam #2] 胖男孩 — 题解

## 一、解题过程：人类思考叙事

**重述题意。** 输入三行字符串（只含小写字母，每行不超过 $100$ 个字符），它们是麦克同一封信的三个版本。麦克打字时会误打：对**每一个想打的字符**，最多多打出 $3$ 个多余字符，多余字符可能在正确字符之前或之后（但不会把顺序搞乱、也不会漏掉想打的字）。要求还原出麦克**可能写出的最长的那封信**。题目保证有解，答案不唯一（SPJ）。

**第一步：把故事抹掉，只留结构。** "误打"只做了两件事：在正确字符之间**插入**多余字符，不会改动相对顺序、不会删除。所以：

> 正确信件一定是三封信的**公共子序列**（按顺序出现在每一版里）。

反过来，只要一个串是三版的公共子序列，把各版中没被用到的字符统统当成"误打"，就得到一种自洽的解释。于是问题变成经典的**三串最长公共子序列（3-LCS）**，并且要输出这个子序列本身（不是长度）。

一句必要的说明：题面"每个字符最多带 $3$ 个误打字符"是在描述**数据的生成方式**（保证三版都来自同一封真信），它不会把答案变得更长——任何可能的真信都必须是公共子序列，而上界就是这个上界；对给定的三串，求最长公共子序列就是本题所定义的标准答案（SPJ 也是按"是否为公共子序列 + 长度是否最大"判的）。

**第二步：两串 LCS 的直接推广。** 两串时 $dp_{i,j}$ 表示前缀 $a[1..i],b[1..j]$ 的 LCS 长度；三串就再加一维：
$$dp_{i,j,k}=\text{（}a\text{ 前 }i\text{ 个、}b\text{ 前 }j\text{ 个、}c\text{ 前 }k\text{ 个字符的 LCS 长度）}.$$
规模 $101^3\approx10^6$，每个状态 $O(1)$ 转移，完全可以。内存 $101^3\times4\,\mathrm{B}\approx4.1\,\mathrm{MB}$，也够。

**第三步：转移怎么写才不出错。** 最自然的想法是"枚举 $2^3-1=7$ 种下标组合取最大"，但有个更清爽的写法：

- 若三个末字符相等（$a_i=b_j=c_k$），**一定取它**：$dp_{i,j,k}=dp_{i-1,j-1,k-1}+1$。
- 否则，$dp_{i,j,k}=\max\{dp_{i-1,j,k},\,dp_{i,j-1,k},\,dp_{i,j,k-1}\}$。

我一开始不敢用第一条，觉得"末字符相等但可能有更优的不取它的方案"。后来想通了：相等时可以**把最优解里最后一个公共字符对齐到这三个位置的末尾**（不亏），所以一定存在取它的最优解。这一步是整道题第二个必须严格论证的地方，见引理 3。

**第四步：怎么把字符串还原出来。** 只有长度显然不够，要在 DP 表上倒着走：从 $(n,m,l)$ 出发，若三个当前末字符相等就直接收下这个字符并把三个指针各退一格；否则哪一维的前驱 `dp` 值等于当前 `dp` 就退哪一维。关键点是：**退的时候必须退到"值不变"的方向**，随便退一格会丢掉最优性。

**第五步：坑与细节。**

- 三处不同的字母不能用 `a[i-1]==b[j-1]&&b[j-1]==c[k-1]` 写错成 `a==b&&a==c` 之外的形式——一定要三个两两相等（写成 `a==b&&a==c` 最稳）。
- 回溯的 `else` 分支只要写"第一个 `dp` 值相等的方向"，因为"三者中最大者必被取到"保证了三个分支里至少有一个成立；顺序无所谓。
- 数组大小：字符串长 $100$，写下标 $1..100$，数组开 $105$ 留余量。
- 输出的是字符串，末尾换行；答案若为空（本题保证有解，实际不会发生）就输出一个空行。

**自造数据检验（题面无样例）。**

| 输入 | 输出 | 说明 |
| --- | --- | --- |
| `abcbdab` / `bdcaba` / `bacdbd` | `bcb` | 长度 $3$；另一条长度 $3$ 的是 `bdb`，SPJ 均可 |
| `abc` / `ac` / `abd` | `a` | `ab` 不在 `c` 版里 |
| `banana` / `bandana` / `banjo` | `ban` | `bana` 不是 `banjo` 的子序列 |
| `a` / `b` / `c` | 空行 | 公共子序列为空 |

再把"枚举 $a$ 的全部子序列、逐个检查是否为 $b,c$ 的子序列、取最长"当基准，在 $300$ 组随机小数据（长度 $\le10$，字母表大小 $2\sim3$，故意制造大量重复与大量空解）上对拍：长度全部一致，且用额外的校验器确认输出确实是三串的公共子序列。

## 二、思维链：完整证明

### 2.0 记号

记三串为 $a,b,c$，长度为 $n,m,l$。用 $(i,j,k)$ 表示"$a$ 的前 $i$ 个字符、$b$ 的前 $j$ 个、$c$ 的前 $k$ 个"这三个前缀，$dp_{i,j,k}$ 为其公共子序列的最大长度。约定 $i=0$ 或 $j=0$ 或 $k=0$ 时 $dp=0$。

### 引理 1：建模（必要性与答案刻画）

**引理 1**：设真信为 $L$。则 $L$ 是 $a,b,c$ 的公共子序列；从而 $|L|\le dp_{n,m,l}$。

*证明*：麦克按顺序打出 $L$ 的字符 $L_1,L_2,\dots,L_{|L|}$，其间只可能插入多余字符。因此在任意一版中，$L_1,\dots,L_{|L|}$ 的出现位置严格递增，即 $L$ 是该版的子序列。三版同时成立，故 $L$ 是公共子序列，长度不超过最大值 $dp_{n,m,l}$。证毕。

**（建模说明）** 反过来，给定任意公共子序列 $S$，把各版中未参与匹配的字符视为误打字符，就构成一种"麦克想写 $S$"的自洽解释。故本题要求的最长信件即三串的 LCS；题面里"至多 $3$ 个误打"只是保证数据确实由某封真信生成（题目保证有解），并不改变"答案是 LCS"这一结论（它只会影响某些**非最长**的公共子序列能否被某个具体打字过程实现，而不影响最大值的位置——这也是本题 SPJ 的判法）。

### 引理 2：删尾引理

**引理 2**：若 $T$ 是 $(i,j,k)$ 的非空公共子序列，则 $T$ 去掉末字符后是 $(i-1,j-1,k-1)$ 的公共子序列。

*证明*：设 $T$ 在三个前缀中的匹配位置分别为 $p_1<\dots<p_{|T|}\le i$、$q_1<\dots<q_{|T|}\le j$、$r_1<\dots<r_{|T|}\le k$。去掉末字符后剩下前 $|T|-1$ 个字符，它们的位置都 $<p_{|T|}\le i$，即 $\le i-1$，落在 $a$ 的前 $i-1$ 个字符内；同理落在 $b$ 的前 $j-1$、$c$ 的前 $k-1$ 个字符内。证毕。

**推论 2′（单调性）**：$dp$ 关于每个下标单调不降。特别地 $dp_{i-1,j,k}\le dp_{i,j,k}$。

*证明*：$(i-1,j,k)$ 的任一公共子序列也是 $(i,j,k)$ 的公共子序列（前缀包含关系），故最大值不超过。证毕。

### 引理 3：末字符相等时一定取

**引理 3**：若 $a_i=b_j=c_k=\sigma$（$i,j,k\ge1$），则
$$dp_{i,j,k}=dp_{i-1,j-1,k-1}+1.$$

*证明*：

（$\ge$）取 $(i-1,j-1,k-1)$ 的一个最长公共子序列 $S$，在后面接上 $\sigma$：它在三个前缀中都出现在原有匹配位置之后（因为原匹配都在前 $i-1/j-1/k-1$ 个字符内），且末字符 $\sigma$ 分别取第 $i,j,k$ 个字符，合法。长度为 $dp_{i-1,j-1,k-1}+1$。

（$\le$）取 $(i,j,k)$ 的一个最长公共子序列 $T$，$L=|T|$。若 $T$ 为空则 $L=0$，平凡。否则设 $T$ 的末字符为 $\tau$，它在三个前缀中的最后匹配位置为 $p\le i,\ q\le j,\ r\le k$。

- 若 $\tau=\sigma$：由引理 2，$T$ 去掉末字符是 $(i-1,j-1,k-1)$ 的公共子序列，故 $L-1\le dp_{i-1,j-1,k-1}$。
- 若 $\tau\ne\sigma$：因为第 $i$ 个字符是 $\sigma\ne\tau$，末字符不可能匹配到位置 $i$，故 $p\le i-1$；又 $T$ 的全部匹配位置 $\le p$，所以 $T$ 是 $a$ 的前 $i-1$ 个字符的子序列。同理对 $b$ 是前 $j-1$ 个、对 $c$ 是前 $k-1$ 个的子序列。故 $L\le dp_{i-1,j-1,k-1}$。

两种情形都有 $L\le dp_{i-1,j-1,k-1}+1$。证毕。

### 引理 4：末字符不全相等时的转移

**引理 4**：若 $a_i,b_j,c_k$ 不全相等（$i,j,k\ge1$），则
$$dp_{i,j,k}=\max\{dp_{i-1,j,k},\ dp_{i,j-1,k},\ dp_{i,j,k-1}\}.$$

*证明*：

（$\ge$）三个前驱各自的公共子序列都是 $(i,j,k)$ 的公共子序列，取最长者即得。

（$\le$）取 $(i,j,k)$ 的最长公共子序列 $T$（$L=|T|$）。若 $T$ 为空则 $L=0$ 平凡。否则设其末字符在三个前缀中的最后匹配位置为 $(p,q,r)$。由于 $a_i,b_j,c_k$ 不全相等，$(p,q,r)\ne(i,j,k)$：否则三个末字符都等于 $T$ 的末字符，与"不全相等"矛盾。于是 $p<i$、$q<j$、$r<k$ 中至少一个成立。

- 若 $p<i$：$T$ 的全部匹配位置在 $a$ 中 $\le p\le i-1$，在 $b,c$ 中 $\le j,k$，故 $T$ 是 $(i-1,j,k)$ 的公共子序列，$L\le dp_{i-1,j,k}$。
- 若 $q<j$：同理 $L\le dp_{i,j-1,k}$。
- 若 $r<k$：同理 $L\le dp_{i,j,k-1}$。

三种情形至少一种成立，故 $L\le\max\{\dots\}$。证毕。

**由引理 3、4 得到完整递推**：
$$dp_{i,j,k}=\begin{cases}dp_{i-1,j-1,k-1}+1,& a_i=b_j=c_k,\\[2pt] \max\{dp_{i-1,j,k},dp_{i,j-1,k},dp_{i,j,k-1}\},&\text{否则}.\end{cases}$$
边界 $dp_{0,\cdot,\cdot}=dp_{\cdot,0,\cdot}=dp_{\cdot,\cdot,0}=0$。按 $i,j,k$ 递增顺序填表（每个状态只依赖三个下标都不更大的状态），填表合法。

### 引理 5：回溯（还原字符串）正确

设回溯过程从 $(i,j,k)=(n,m,l)$ 开始，维护不变量

$$\textbf{(Inv)}\qquad \text{已收集字符数}+dp_{i,j,k}=dp_{n,m,l},\ \text{且已收集字符（逆序）是三个相应后缀的公共子序列}.$$

**引理 5**：每次迭代都保持 (Inv)，且迭代终止时已收集 $dp_{n,m,l}$ 个字符；把收集的字符逆序输出即一个长度最优的公共子序列。

*证明*：

*保持 (Inv)*：
- 若 $a_i=b_j=c_k$：由引理 3，$dp_{i,j,k}=dp_{i-1,j-1,k-1}+1$，收下该字符（计数 $+1$）并令 $(i,j,k)\gets(i-1,j-1,k-1)$，等式两边同增 $1$，成立；收下的字符同时等于三者的第 $i,j,k$ 个字符，逆序拼在已收集串前面仍是公共子序列。
- 否则：由引理 4，$dp_{i,j,k}$ 等于三个前驱 `dp` 值中的最大者，故至少存在一个方向 $d\in\{i-1,j-1,k-1\}$ 使该方向的 `dp` 值恰等于 $dp_{i,j,k}$。代码按"$i-1$、$j-1$、$k-1$"的顺序检查，命中即移动，等式不变；已收集串不动，仍是公共子序列。

*终止*：每轮至少一个下标减 $1$，故至多 $n+m+l$ 轮后某个下标变成 $0$，循环结束；此时 $dp_{i,j,k}=0$，由 (Inv) 得已收集数 $=dp_{n,m,l}$。

*最优性*：已收集的是一个公共子序列（由不变量第二部分），长度等于 $dp_{n,m,l}$，即最大长度。证毕。

### 引理 6：复杂度

**引理 6**：时间 $O(nml)$，空间 $O(nml)$，取 $n,m,l\le100$ 时约 $10^6$ 个状态、$4.1\,\mathrm{MB}$。

*证明*：三层循环每状态 $O(1)$；回溯至多 $n+m+l$ 步。数组 $105^3$ 个 `int`，$105^3\times4\approx4.6\,\mathrm{MB}$，在常规 $128\,\mathrm{MB}$ 限制内。证毕。

**定理**：程序输出的字符串是三串的公共子序列，且长度等于三串 LCS 的长度。

*证明*：由引理 3、4 递推正确（每一步都用了完整的上下界论证），填表得到正确的 $dp$；由引理 5 回溯输出的是长度 $dp_{n,m,l}$ 的公共子序列；由引理 1，任何"可能的信件"长度不超过 $dp_{n,m,l}$，故这是最长信件。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 误打只会"插入"字符、不改顺序 ⇒ 真信必是三版的公共子序列，"最长真信"就是最长公共子序列。
2. **reduce to easier problem** — 把打字故事完全抹掉，问题化为标准 3-LCS，并要求输出串本身而非长度。
3. **classic problem solution** — 二维 LCS 加一维：$dp_{i,j,k}$ 表示三个前缀的 LCS 长度，$O(nml)$ 状态。
4. **explore its property** — 末字符三者相等时"取它"一定不亏（对齐论证），否则只需看三个"退一格"的前驱。
5. **classic problem solution** — 用深搜式的倒推在 DP 表上还原答案：相等就收字符，否则沿着 `dp` 值不变的方向退。
6. **check the bound** — $100^3$ 状态 $\times4\mathrm{B}\approx4.1\,\mathrm{MB}$，必须保留整张表（回溯要用），不能只滚两维。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
| --- | --- | --- |
| `a,b,c` | 三封信（`string`） | 读入，长度 $\le100$ |
| $n,m,l$ | 三串长度 | `a.size()` 等 |
| `dp[i][j][k]` | $a$ 前 $i$、$b$ 前 $j$、$c$ 前 $k$ 个字符的 LCS 长度 | 全局数组，默认 $0$（边界正好是 $0$） |
| `i,j,k` | 回溯时的当前位置，从 $(n,m,l)$ 退到 $0$ | 循环变量 |
| `ans` | 倒序收集的答案串 | 空串，最后 `reverse` |

### 算法步骤

1. 读入 `a,b,c`，取 $n=|a|,m=|b|,l=|c|$。
2. 三重循环 $i=1..n$、$j=1..m$、$k=1..l$：
   - 若 `a[i-1]==b[j-1] && a[i-1]==c[k-1]`：`dp[i][j][k]=dp[i-1][j-1][k-1]+1`；
   - 否则 `dp[i][j][k]=max({dp[i-1][j][k],dp[i][j-1][k],dp[i][j][k-1]})`。
3. 令 `i=n,j=m,k=l`；当三者都 $>0$ 时循环：
   - 若三个当前末字符相等：`ans+=a[i-1]`，`--i,--j,--k`；
   - 否则若 `dp[i][j][k]==dp[i-1][j][k]`：`--i`；
   - 否则若 `dp[i][j][k]==dp[i][j-1][k]`：`--j`；
   - 否则 `--k`。
4. `reverse(ans)` 后输出 `ans` 并换行。

### 复杂度

- 时间 $O(nml)$（$\le10^6$ 个状态，回溯 $O(n+m+l)$）。
- 空间 $O(nml)$，约 $4.6\,\mathrm{MB}$。

### 验证状态

- `g++ -std=c++20 -O2` 编译通过。
- 题面无样例，自造四组数据与手算一致：`abcbdab/bdcaba/bacdbd → bcb`、`abc/ac/abd → a`、`banana/bandana/banjo → ban`、`a/b/c → 空行`。
- 与"枚举 $a$ 的全部子序列 + 子序列判定"的暴力对拍 $300$ 组随机小数据（长度 $\le10$，字母表 $\{a,b\}$ 或 $\{a,b,c\}$）：长度全部相同；再用独立校验器确认输出真的是三串的公共子序列（呼应 SPJ）。
- 极限规模（三个长度 $100$、字母表 $\{a,b\}$）运行 $0.06$ 秒。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2364 胖男孩
// 三串最长公共子序列 + 回溯还原
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int dp[mxn][mxn][mxn];
string a,b,c;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b>>c;
	int n=a.size(),m=b.size(),l=c.size();
	for(int i=1;i<=n;++i)
		for(int j=1;j<=m;++j)
			for(int k=1;k<=l;++k)
				if(a[i-1]==b[j-1]&&a[i-1]==c[k-1])
					dp[i][j][k]=dp[i-1][j-1][k-1]+1;   // 三者相等一定取
				else
					dp[i][j][k]=max({dp[i-1][j][k],dp[i][j-1][k],dp[i][j][k-1]});
	string ans;
	int i=n,j=m,k=l;
	while(i&&j&&k)
	{
		if(a[i-1]==b[j-1]&&a[i-1]==c[k-1])
		{
			ans+=a[i-1];
			--i;--j;--k;
		}
		else if(dp[i][j][k]==dp[i-1][j][k])
			--i;
		else if(dp[i][j][k]==dp[i][j-1][k])
			--j;
		else
			--k;
	}
	reverse(ans.begin(),ans.end());
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 三个字符相等的判断写成 `a[i-1]==b[j-1]&&a[i-1]==c[k-1]`（两两相等即三者相等），避免漏判。
- `dp` 是全局 `int` 数组，默认全 $0$，恰好就是"某一维为 $0$ 时 LCS 为 $0$"的边界，所以不需要额外初始化。
- 回溯的 `else` 分支一定落在 `--k` 上时是安全的：由引理 4，三个前驱中必有一个等于当前 `dp` 值，前两个都不等时第三个必然相等。
- 必须保留整张三维表（回溯要查任意位置的值），所以不能像"只求长度"那样滚动数组。
- 输出字符串后换行；本题 SPJ，任意一个最长公共子序列都算对。
