# P2203 [USACO13OPEN] Blink B — 题解

## 一、解题过程：人类思考叙事

题面：$N$ 盏灯围成一圈（$3\le N\le16$），每秒同时更新一次——第 $i$ 盏灯在时刻 $T$ 的状态，等于它在 $T-1$ 时刻的状态异或"它左边那盏灯在 $T-1$ 时刻的状态"（第 $1$ 盏的左边是第 $N$ 盏）。给定初态，求 $B$ 秒后每盏灯的状态，$B\le10^{15}$。

**最直接的想法**：模拟 $B$ 秒。但 $B$ 有 $10^{15}$，每秒还要扫 $N$ 盏灯，必然超时。题目特意提醒"$B$ 可能超过 32 位整数范围"，说明正解一定不是按时间线性做的。

**盯住数据范围**：$N\le16$。这说明"状态"本身非常小——每盏灯只有开/关两种，整个吊灯的状态可以用一个不超过 $2^{16}=65536$ 的整数表示。而每一秒的更新规则是**确定的**：只要知道这一秒的完整状态，下一 秒的完整状态就唯一确定，与更早的历史无关。

**于是产生关键直觉**：把状态看成有向图上的点，每个点只有一条出边（指向下一秒的状态）。从初始状态出发沿着唯一的出边走，一共只有 $2^N$ 个点，由抽屉原理，走不超过 $2^N+1$ 步必然踩到一个之前走过的点。一旦重复，之后就会沿着同一个环无限循环。也就是说，**序列最终是周期的**（可能先有一段"预周期"，因为不同的状态可能走到同一个状态，映射未必是双射）。

**算法雏形**：一秒一秒模拟，同时用数组 `seen[s]` 记录状态 `s` 第一次出现的时刻。当当前状态已经出现过（设第一次出现在 $t_0$，现在是 $t$），就找到了环：周期 $p=t-t_0$。此后任意时刻 $B$ 的状态，只需把 $B$ 对周期取模，落回环上的对应位置即可。为了处理 $B$ 小于首次重复时刻的情况，把每一步的状态按时间顺序存进 `hist[t]`，直接查表。

**把状态压缩成整数**：用第 $i$ 个二进制位表示第 $i+1$ 盏灯（0-based）。第 $i$ 位的新值 = 旧第 $i$ 位 异或 旧第 $i-1$ 位（下标模 $N$，因为第 $1$ 盏的左边是第 $N$ 盏）。"旧第 $i-1$ 位"整体左移一位就得到了：`(s<<1)` 的第 $i$ 位正是旧第 $i-1$ 位；但第 $0$ 位需要旧第 $N-1$ 位，由 `(s>>(n-1))` 补上。两者按位或得到"左邻居状态"掩码，再与 `s` 异或，最后用 `(1<<n)-1` 截断。

**这里踩过一个坑**：一开始把左邻居写成了右移 `(s>>1)`，相当于让第 $i$ 盏灯去看**右边**的灯。用题面样例解释的轨迹核对时第一秒就不对：初态是 `1 0 0 0 0`，按题面规则（左边的灯亮才翻转）第一秒应变成 `1 1 0 0 0`，而右移版本得到的是 `1 0 0 0 1`——正好把方向搞反了。改成左移后，程序逐时刻复现了题面给出的 $T=0$ 到 $T=6$ 的全部状态，这才确认方向正确。

**边界与实现细节**：

- 更新必须是"同时"的：新状态完全由旧状态算出，不能一边改一边用新值，所以先算整个邻居掩码再异或。
- `B` 用 64 位整数读入。
- `seen` 初值 $-1$；`hist` 要开到 $2^N+5$，因为首次重复最晚发生在第 $2^N$ 步。
- 输出时从低位到高位逐位输出，对应第 $1$ 到第 $N$ 盏灯。

这样时间与空间都和 $B$ 无关，只与 $2^N$ 有关，$N=16$ 时约 $6.5\times10^4$，轻松通过。

## 二、思维链：完整证明

记一个状态为 $s\in\{0,1\}^N$，第 $i$ 位（$0\le i<N$）表示第 $i+1$ 盏灯。定义一步变换 $T:\{0,1\}^N\to\{0,1\}^N$：
$$(T(s))_i=s_i\oplus s_{(i-1)\bmod N}.$$
用 $x_t$ 表示时刻 $t$ 的状态，则 $x_0$ 为初态，$x_{t+1}=T(x_t)$。

**引理 1（位运算实现与题面规则一致）**：令 `nb=(s<<1)|(s>>(n-1))`，`mask=(1<<n)-1`，则 `(s^nb)&mask` 的第 $i$ 位等于 $s_i\oplus s_{(i-1)\bmod N}$。

*证明*：分两种下标。

- 当 $1\le i\le N-1$ 时，`s<<1` 的第 $i$ 位等于 $s$ 的第 $i-1$ 位；`s>>(N-1)` 只有第 $0$ 位可能为 $1$（等于 $s_{N-1}$），在第 $i\ge1$ 位上恒为 $0$。故 `nb` 的第 $i$ 位为 $s_{i-1}=s_{(i-1)\bmod N}$，异或后得到 $s_i\oplus s_{i-1}$。
- 当 $i=0$ 时，`s<<1` 的第 $0$ 位恒为 $0$；`s>>(N-1)` 的第 $0$ 位等于 $s_{N-1}=s_{(0-1)\bmod N}$。故 `nb` 的第 $0$ 位为 $s_{N-1}$，异或后得到 $s_0\oplus s_{N-1}$。

其余高位在 `&mask` 后被清除。两种情形都符合题面"第 $i$ 盏灯看左边邻居"的规则。证毕。

**引理 2（确定性）**：若 $x_t=y_t$，则对任意 $j\ge0$，$x_{t+j}=y_{t+j}$。

*证明*：对 $j$ 归纳。$j=0$ 是假设。若 $x_{t+j}=y_{t+j}$，则 $x_{t+j+1}=T(x_{t+j})=T(y_{t+j})=y_{t+j+1}$，因为 $T$ 是函数，相同输入给出相同输出。证毕。

**引理 3（必然重复）**：存在 $0\le t_0<t\le 2^N$，使得 $x_{t_0}=x_t$。因此第一段模拟循环在至多 $2^N+1$ 次迭代内终止。

*证明*：考虑 $2^N+1$ 个状态 $x_0,x_1,\dots,x_{2^N}$。状态总数只有 $2^N$ 个，由抽屉原理必有两个相等，即存在 $t_0<t$ 使 $x_{t_0}=x_t$，且可取 $t\le2^N$。程序每迭代一次就把一个新状态写入 `seen`，所以写入次数不超过 $2^N$，循环必然终止。证毕。

**引理 4（周期性）**：若 $x_p=x_q$ 且 $p<q$，令 $d=q-p$，则对一切 $j\ge0$ 有 $x_{p+j}=x_{q+j}=x_{p+j+d}$；进而对一切 $u\ge p$ 有 $x_{u+d}=x_u$。

*证明*：对 $j$ 归纳证明 $x_{p+j}=x_{q+j}$。$j=0$ 即 $x_p=x_q$。若 $x_{p+j}=x_{q+j}$，由引理 2（确定性）两边再走一步得 $x_{p+j+1}=x_{q+j+1}$。于是对所有 $j\ge0$ 成立。又 $q+j=(p+j)+d$，故 $x_{p+j+d}=x_{p+j}$。对任意 $u\ge p$ 取 $j=u-p$ 即得 $x_{u+d}=x_u$。证毕。

**引理 5（模周期归约）**：设 $x_{t_0}=x_t$，$p=t-t_0>0$。则对任意 $B\ge t_0$，若 $B-t_0=qp+r$（$q\ge0$，$0\le r<p$），有 $x_B=x_{t_0+r}$。

*证明*：对 $q$ 归纳证明 $x_{t_0+r+kp}=x_{t_0+r}$。$k=0$ 时等式两边都是 $x_{t_0+r}$，成立。若对 $k$ 成立，由引理 4（取 $u=t_0+r+kp\ge t_0$）得 $x_{t_0+r+(k+1)p}=x_{t_0+r+kp}=x_{t_0+r}$。故 $x_B=x_{t_0+qp+r}=x_{t_0+r}$。证毕。

**引理 6（算法正确性）**：程序找到首次重复状态时，设当前时刻为 $t$、该状态第一次出现于 $t_0$、$p=t-t_0$。若 $B<t$，程序输出 `hist[B]=x_B`；若 $B\ge t$，程序输出 `hist[t_0+(B-t_0)\bmod p]=x_B$。两种情形都正确。

*证明*：

- 若 $B<t$：循环在时刻 $0,1,\dots,t-1$ 都把当时状态写入了 `hist`（第 $t$ 步在写入前就发现重复并退出），所以 `hist[B]` 确实是 $x_B$。
- 若 $B\ge t$：因为 $t>t_0$，所以 $B\ge t_0$。由引理 5，$x_B=x_{t_0+((B-t_0)\bmod p)}$。而 $t_0+((B-t_0)\bmod p)\le t_0+p-1=t-1$，该下标已在 `hist` 中存过，故输出正确。

证毕。

**引理 7（时空复杂度）**：时间复杂度 $O(2^N)$，空间复杂度 $O(2^N)$。

*证明*：由引理 3，循环至多迭代 $2^N+1$ 次，每次只做常数次位运算，故时间 $O(2^N)$。`seen` 与 `hist` 的长度均为 $2^N+O(1)$，空间 $O(2^N)$。与 $B$ 无关。证毕。

**定理**：程序对任意 $B\ge0$ 输出时刻 $B$ 的完整灯状态，且顺序与题面编号一致。

*证明*：正确性由引理 1（更新规则）、引理 6（时间归约）得到；输出时第 $i$ 位对应第 $i+1$ 盏灯，与编码约定一致。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 更新是"同时、局部、确定性"的，整个吊灯只需 $N$ 位二进制描述。
- **consider easier version** — 若 $B$ 很小则直接逐秒模拟；瓶颈只在 $B$ 过大。
- **classic problem solution** — 有限状态 + 确定性映射 ⇒ 用抽屉原理证明序列必然进入周期。
- **classic problem solution** — `seen` 数组记录每个状态首次出现时刻，`hist` 按时间保存状态，首次重复即定位预周期与循环节。
- **reduce to easier problem** — 把 $B$ 对周期取模，把 $10^{15}$ 的时间归约到 $O(2^N)$。
- **discuss by category** — $B$ 在预周期内直接查 `hist`；$B$ 在环上则用 $t_0+((B-t_0)\bmod p)$。
- **boundary check** — 位方向必须是"左邻居"（左移补最高位），并用题面轨迹逐时刻核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $N$ | 灯的数量 | 输入，$3\le N\le16$ |
| $B$ | 经过的时间 | 输入，`i64`，可达 $10^{15}$ |
| `s` | 当前状态，第 $i$ 位表示第 $i+1$ 盏灯 | 由输入按低位到高位拼成 |
| `mask` | `(1<<n)-1`，保留低 $N$ 位 | 构造 |
| `step(s)` | 走一秒后的状态 | 返回 `(s^nb)&mask`，`nb=(s<<1)|(s>>(n-1))` |
| `seen[s]` | 状态 `s` 第一次出现的时刻 | 全部置 $-1$ |
| `hist[t]` | 时刻 $t$ 的状态 | 循环中依次写入 |
| `t` | 当前模拟到的时刻 | 从 $0$ 开始 |
| `t0` | 首次重复状态第一次出现的时刻 | `seen[s]` |
| `p` | 循环节长度 | `t-t0` |
| `ans` | 时刻 $B$ 的状态 | 按分支取 `hist` 中的值 |

### 算法步骤

1. 读入 $N,B$；读入 $N$ 个 $0/1$，第 $i$ 个放在 `s` 的第 $i$ 位（0-based）。
2. 令 `mask=(1<<n)-1`，`seen` 全部置 $-1$，`t=0`。
3. 当 `seen[s]==-1` 时循环：
   1. `seen[s]=t`，`hist[t]=s`；
   2. `s=step(s)`，`t=t+1`。
4. 退出时当前 `s` 在时刻 `t` 重复了时刻 `t0=seen[s]` 的状态，周期 `p=t-t0`。
5. 若 $B<t$，`ans=hist[B]`；否则 `ans=hist[t0+(B-t0)%p]`。
6. 对 $i=0..N-1$ 输出 `ans` 的第 $i$ 位，每行一个。

### 复杂度

- 时间复杂度：$O(2^N)$，与 $B$ 无关；$N=16$ 时约 $6.6\times10^4$ 次迭代。
- 空间复杂度：$O(2^N)$，`seen` 与 `hist` 各约 $65536$ 个 `int`。

### 验证状态

编译通过；用题面样例解释给出的 $T=0\sim6$ 轨迹（初态 `1 0 0 0 0`）逐时刻核对，输出完全一致；另做两组随机对拍：2000 组 $N\in[3,16]$、$B<3000$ 与逐秒暴力模拟比对，300 组 $N\in[3,16]$、$B$ 达 $10^{18}$ 量级与独立的 GF(2) 矩阵快速幂实现比对，全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxst{1<<16};

int n,mask;
i64 B;
int seen[mxst];     // seen[s]=状态s第一次出现的时刻
int hist[mxst+5];   // hist[t]=时刻t的状态

int step(int s)
{
	int nb=(s<<1)|(s>>(n-1));     // 第i位取左边邻居(即i-1位,环形)
	return (s^nb)&mask;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>B;
	int s=0;
	for(int i=0;i<n;++i)
	{
		int x;
		cin>>x;
		s|=x<<i;
	}
	mask=(1<<n)-1;
	fill_n(seen,mxst,-1);
	int t=0;
	while(seen[s]==-1)
	{
		seen[s]=t;
		hist[t]=s;
		s=step(s);
		++t;
	}
	// 当前时刻t的状态等于时刻t0=seen[s]的状态，周期p=t-t0
	int t0=seen[s],p=t-t0;
	int ans;
	if(B<t)
		ans=hist[B];
	else
		ans=hist[t0+(B-t0)%p];
	for(int i=0;i<n;++i)
		cout<<((ans>>i)&1)<<'\n';
	return 0;
}
```

### 代码说明

- `step` 中的 `(s<<1)|(s>>(n-1))` 是"每个位置取左邻居"：左移把第 $i-1$ 位送到第 $i$ 位，右移 $N-1$ 位把第 $N-1$ 位补到第 $0$ 位；最后 `&mask` 截掉溢出位。
- 循环退出时没有把当前状态写入 `hist[t]`，所以 `hist` 的有效下标是 $0\sim t-1$；`B<t` 的分支刚好覆盖预周期与环的前半段。
- `B` 用 `i64`，取模时 `(B-t0)%p` 也自动是 64 位运算。
- 输出按低位到高位，正好对应第 $1$ 到第 $N$ 盏灯。
