# P2793 Facer的工厂 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N\le10^5$ 根钢管**按顺序**加工，长度 $a_i\le h\le10^9$。机器每秒加工长度 $k$；只能在整数秒时刻塞入钢管；任何时刻"已塞入但还没加工完"的剩余长度（等待长度）不能超过 $h$。求加工完所有钢管的最短总秒数。

**第一步：把时间线语义钉死。** 样例 2 的逐秒解释给出了精确模型：

> 每一秒 = **先塞入**（塞完等待长度 $\le h$），**后加工**（这一秒内机器加工 $\min(k,\text{等待长度})$）。

等待长度按**剩余未加工长度**算：样例里塞入 $5$、加工 $3$ 后等待是 $2$，说明被加工了一半的钢管只算剩下一半。钢管按顺序塞入（机器按塞入顺序加工，而加工必须按钢管顺序，所以塞入顺序就是钢管顺序——任何时刻已塞入的恰是一个前缀）。

**第二步：先想"没有 $h$ 约束"的简化版。** 若等待长度无上限，开局全塞进去，机器一秒不停地干，答案就是 $\lceil S/k\rceil$（$S=\sum a_i$）。样例 2 恰好 $S=15,k=3$，答案 $5=\lceil15/3\rceil$，很容易让人以为这就是通解。**但这是错的**，手造一个反例：

$h=5,k=4,a=[5,5]$。$\lceil10/4\rceil=3$，然而逐秒推演：第 1 秒塞 $5$ 加工 $4$ 剩 $1$；第 2 秒 $1+5>5$ 塞不进，只能加工 $1$（机器空转 $3$）；第 3 秒塞第二根 $5$ 加工 $4$ 剩 $1$；第 4 秒加工 $1$。**答案 $4>3$**。$h$ 太小会逼机器空转，$\lceil S/k\rceil$ 只是下界。必须真的调度。

**第三步：贪心假设——每秒开头能塞多少塞多少。** 直觉：料进机器越早越好，机器有活干就不会空转；$h$ 只限制"塞入"，而贪心按顺序塞，"已经塞得更多"永远不会挡住后面某根钢管——它早就塞进去了。反过来找失败模式：会不会"现在塞太多，占着 $h$，导致后面塞不进"？不会，因为后面的钢管在贪心方案里**已经塞过了**，不需要再塞。这个直觉可以严格化成"双单调支配"归纳（第二部分引理 2）：贪心在每一秒的"已塞入根数"和"已加工总量"都 $\ge$ 任何合法方案，关键一步是 $p'=\min(p+k,\ S(i))$ 对两个参数都单调。于是贪心最优。

**第四步：逐秒模拟会炸，压缩成事件。** 贪心策略定了，但答案可达 $S/k\approx10^{14}$ 秒（$a_i=10^9,k=1$），逐秒循环必死。观察：**两次塞入之间，世界唯一的变化就是 $w\mathrel{-}=k$**。设当前等待 $w$，下一根 $a_i$ 塞不进（$w>h-a_i$），那么"第一次能塞进"发生在恰好 $d=\lceil(w-(h-a_i))/k\rceil$ 秒之后——中间这些秒塞入条件一直不满足，可以直接快进。全部塞完后同理快进 $\lceil w/k\rceil$ 秒收尾。每次快进之后必然塞入至少一根（或结束），所以事件数 $O(n)$，总复杂度 $O(n)$。

**第五步：抠快进的取整边界。** 这是全题最容易错的地方：

- 快进条件成立时 $w-(h-a_i)\ge1$（整数严格大于），故 $d\ge1$，不会死循环；
- $h-a_i\ge0$ 保证 $d\le\lceil w/k\rceil$，即"能塞入"不晚于"排空"，快进秒数不会多算；
- $w-dk$ 可能为负（最后一秒机器把料干完后空转了半秒），要 clamp 到 $0$。这**不是**误差：塞入只发生在秒首，而第 $d$ 秒的秒首等待仍 $>h-a_i$（$d$ 的最小性），那一秒确实塞不进，空转合法；
- $w\le h\le10^9$，但 $t$ 可达 $10^{14}$，$d\cdot k$ 可达 $2\times10^9$，全程 `i64`。

**手造数据核对**（题面只有文字解释，无样例输入输出文件）：

| 输入 | 手算 | 程序 |
|---|---|---|
| $n=1,h=5,k=3,a=[5]$（样例 1） | $\lceil5/3\rceil=2$ | `2` ✓ |
| $n=5,h=6,k=3,a=[5,4,3,1,2]$（样例 2） | 逐秒推演 $5$ 秒 | `5` ✓ |
| $n=2,h=5,k=4,a=[5,5]$（反例） | $4$（见上） | `4` ✓ |
| $n=3,h=10,k=3,a=[10,10,10]$ | 每根占 $4$ 秒（$3$ 秒加工+$1$ 秒空转等位），共 $12$ | `12` ✓ |
| $n=1,h=10^9,k=1,a=[10^9]$ | $10^9$ | `1000000000` ✓ |

另外写了轻量自检（`appendix/P2793/check.cpp`）：事件式快进 vs 逐秒暴力，$2\times10^5$ 组随机小数据（$n\le12,h\le20,k\le7$）全部一致——快进的 ceil 边界值得这个验证。

## 二、思维链：完整证明

**记号与模型。** 秒编号 $t=1,2,\dots$。第 $t$ 秒开头先塞入（塞入后等待 $\le h$），随后机器加工 $\min(k,w)$。前缀和 $S(i)=\sum_{j\le i}a_j$，$S(0)=0$，$S=S(n)$。一个**方案** $X$ 由每秒塞入的根数决定；由于塞入按钢管顺序，第 $t$ 秒塞入阶段结束后已塞入根数记为 $i_X(t)$（关于 $t$ 不减），第 $t$ 秒结束时累计加工量记为 $p_X(t)$。令 $p_X(0)=0,i_X(0)=0$。则

- 第 $t$ 秒塞入后的等待 $w_X(t)=S(i_X(t))-p_X(t-1)$，**可行性**要求 $w_X(t)\le h$；
- 加工递推 $p_X(t)=p_X(t-1)+\min\bigl(k,\ w_X(t)\bigr)=\min\bigl(p_X(t-1)+k,\ S(i_X(t))\bigr)$；
- 完成时刻 $T_X=\min\{t:p_X(t)=S\}$。

题目要求 $\min_X T_X$。以下设 $k\ge1$（机器速度为正，题意隐含），$1\le a_i\le h$。

---

### 引理 1（贪心良定义、可行、不死锁）

定义贪心方案 $G$：第 $t$ 秒开头，从 $i_G(t-1)$ 起按顺序塞入，直到下一根塞不下为止，即
$$i_G(t)=\max\{j\ge i_G(t-1):S(j)-p_G(t-1)\le h\}.$$
则 $G$ 每秒可行（$w_G(t)\le h$），且只要还有未塞入的钢管，$G$ 永远不会"既塞不进又永远等不到"：等待排空到 $0$ 时下一根必能塞入。

*证明*：可行性由定义直接成立（只塞到满足上限的最大前缀；$S$ 单调不减，故"前缀中每个中间状态都 $\le h$"与"末端 $\le h$"等价）。集合非空：$j=i_G(t-1)$ 时 $S(j)-p_G(t-1)=w_G(t-1)-\text{已加工}\le h$（上一秒可行且加工只减等待）。不死锁：若 $i_G(t)<n$ 且当前等待为 $0$，则 $a_{i+1}\le h$ 保证至少能塞一根；而等待每秒至少减 $\min(k,w)$，有限秒内必到 $0$（或更早塞入）。故 $G$ 在有限秒内塞完并加工完所有钢管，$T_G$ 存在。证毕。

### 引理 2（双单调支配：贪心最优的核心）

对任意可行方案 $X$ 与任意 $t\ge0$：
$$i_G(t)\ge i_X(t)\quad\text{且}\quad p_G(t)\ge p_X(t).$$

*证明*：对 $t$ 归纳。$t=0$ 两边都是 $0$ ✓。设 $t-1$ 成立，证第 $t$ 秒的两个阶段。

**塞入阶段**：记 $j=i_X(t)$。若 $j\le i_G(t-1)$，则 $j\le i_G(t-1)\le i_G(t)$，成立。否则 $j>i_G(t-1)\ge i_X(t-1)$，$X$ 在第 $t$ 秒确实塞入了新钢管，其可行性给出
$$S(j)-p_X(t-1)\le h.$$
由归纳假设 $p_G(t-1)\ge p_X(t-1)$，故
$$S(j)-p_G(t-1)\le S(j)-p_X(t-1)\le h,$$
即 $j$ 属于 $G$ 的可塞集合；又 $S$ 单调，$i_G(t-1)$ 到 $j$ 之间的每个前缀都满足上限，所以 $G$ 的最大前缀 $i_G(t)\ge j=i_X(t)$ ✓。**这一步就是"塞得多不会吃亏"的严格版**：$X$ 想塞的任何前缀，$G$ 因为加工得更多、等待更短，一定也塞得下。

**加工阶段**：$p(t)=\min\bigl(p(t-1)+k,\ S(i(t))\bigr)$。$\min$ 对两个参数都单调不减：$a\ge a',b\ge b'\Rightarrow\min(a,b)\ge\min(a',b')$（$\min(a',b')$ 等于 $a'$ 或 $b'$，两者都 $\le$ 对应的 $a,b$，故 $\le\min(a,b)$）。由归纳假设 $p_G(t-1)+k\ge p_X(t-1)+k$，由塞入阶段 $S(i_G(t))\ge S(i_X(t))$，故 $p_G(t)\ge p_X(t)$ ✓。证毕。

### 定理 1（贪心最优）

$T_G\le T_X$ 对一切可行方案 $X$ 成立，故答案 $=T_G$。

*证明*：取 $t=T_X$，则 $p_X(t)=S$。由引理 2，$p_G(t)\ge S$；又 $p_G(t)\le S$（加工总量不超过总长），故 $p_G(t)=S$，即 $G$ 在 $T_X$ 秒内已完成，$T_G\le T_X$。引理 1 保证 $G$ 本身可行。证毕。

**注**：$\lceil S/k\rceil$ 是任何方案的下界（每秒至多加工 $k$），当 $h$ 足够大（例如 $h\ge S$）时贪心第一秒全塞入，达到下界；反例 $h=5,k=4,a=[5,5]$ 说明下界一般不可达。

### 引理 3（纯加工段的快进公式）

设某秒开头塞入阶段结束后状态为：已塞入 $i$ 根、等待 $w$（即已过了 $t$ 秒，正准备进入第 $t+1$ 秒）。

(a) 若 $i<n$ 且 $w+a_{i+1}>h$（下一根塞不进），则从第 $t+1$ 秒起连续 $d=\Bigl\lceil\dfrac{w-(h-a_{i+1})}{k}\Bigr\rceil$ 秒内都无法塞入，且第 $t+d+1$ 秒开头恰能塞入；这 $d$ 秒后的等待为 $\max(0,\ w-dk)$。

(b) 若 $i=n$，则再过 $d=\lceil w/k\rceil$ 秒全部加工完，等待归 $0$。

*证明*：纯加工段里等待按 $w_s=\max(0,\ w-sk)$ 演化（$s$ 为已经过的纯加工秒数）。

(a) 第 $t+s+1$ 秒**开头**的等待是 $w_s$（上一秒结束后的值），塞入条件为 $w_s\le h-a_{i+1}$。因 $h-a_{i+1}\ge0$，$\max(0,w-sk)\le h-a_{i+1}\iff w-sk\le h-a_{i+1}\iff s\ge\frac{w-(h-a_{i+1})}{k}$。最小整数解即 $d=\lceil(w-(h-a_{i+1}))/k\rceil$。对 $0\le s<d$ 有 $w-sk>h-a_{i+1}\ge0$，故这些秒的开头既塞不进、等待又为正（机器每秒都有活干，演化式里 clamp 不生效）；特别地第 $t+d$ 秒开头等待 $w-(d-1)k>h-a_{i+1}$，那一秒仍塞不进，即使该秒内等待被加工到 $0$ 也不影响"秒首才能塞入"的语义。$d$ 秒后等待 $\max(0,w-dk)\le h-a_{i+1}$，下一根可塞 ✓。

(b) 完成条件 $w-sk\le0\iff s\ge w/k$，最小整数解 $\lceil w/k\rceil$ ✓。证毕。

### 引理 4（事件循环 = 贪心时间线的无损压缩）

代码循环维护不变量：**$(t,w,i)$ 恰为贪心方案过了 $t$ 秒后的状态**（$i$ 根已塞入、等待 $w$，下一秒是第 $t+1$ 秒）。每轮：先执行最大前缀塞入；若 $i=n$ 且 $w=0$ 则终止；否则按引理 3 快进 $d$ 秒（`t+=d; w=max(0,w-d*k)`）。则循环终止时 $t=T_G$。

*证明*：初始 $(0,0,0)$ ✓。塞入阶段与引理 1 的 $i_G$ 定义逐字相同（`while(i<n&&w+a[i]<=h)` 就是最大前缀）。快进阶段：进入时若 $i<n$，塞入阶段已极大，故 $w+a_{i+1}>h$，引理 3(a) 适用，跳过的 $d$ 秒与贪心逐秒走完全一致（那些秒贪心也塞不进任何钢管）；若 $i=n$，引理 3(b) 适用。故不变量保持，且 $t$ 累计的秒数一秒不多一秒不少。

**终止性与迭代次数**：$i<n$ 的快进结束后 $w\le h-a_{i+1}$，下一轮塞入阶段必塞入至少一根；所以"快进且 $i<n$"的轮次 $\le n$，加上塞完后的收尾轮 $\le1$，总轮次 $\le n+1$。每轮内层塞入循环全程合计恰 $n$ 次自增。故时间 $O(n)$。终止时 $i=n,w=0$，即全部加工完，$t=T_G$。证毕。

### 引理 5（算术安全：取整、clamp 与溢出）

全程：$0\le w\le h\le10^9$；快进时 $d\ge1$ 且 $d\le\lceil w/k\rceil$；$d\cdot k\le w+k-1\le2\times10^9$；$t\le S/k+n+1\le10^{14}+10^5+1$。所有量用 `i64` 无溢出，`ceildiv(x,y)=(x+y-1)/y` 的调用处均有 $x\ge0,y>0$。

*证明*：$w\le h$：塞入阶段只塞到上限，加工只减。$d\ge1$：$i<n$ 时快进条件 $w>h-a_{i+1}$ 是整数严格不等式，分子 $w-(h-a_{i+1})\ge1$；$i=n$ 时 $w\ge1$（否则已 break），分子 $\ge1$。$d\le\lceil w/k\rceil$：$h-a_{i+1}\ge0\Rightarrow w-(h-a_{i+1})\le w$，ceil 单调。于是 $w-dk\ge w-\lceil w/k\rceil k> -k$，clamp 至 $0$ 合法（引理 3 已论证语义无损）；$d\cdot k\le\lceil w/k\rceil k\le w+k-1\le h+k-1\le2\times10^9<2^{63}$。$t$ 的界：每个快进段至多最后一秒加工量不足 $k$（其余秒等待为正、满负荷），段数 $\le n+1$，故 $tk\le S+(n+1)(k-1)$，$t\le S/k+n+1$；$S\le n\cdot10^9=10^{14}$。`ceildiv` 分子非负已由 $d\ge1$ 的论证覆盖，分母 $k\ge1$。证毕。

### 引理 6（复杂度）

时间 $O(n)$，空间 $O(n)$。

*证明*：引理 4 已证轮次 $\le n+1$、塞入自增合计 $n$，每轮其余操作 $O(1)$。空间只有长度 $n$ 的 `a[]` 与常数个标量。证毕。

### 定理

程序输出最短完成时间 $T_G$，时间 $O(n)$。

*证明*：引理 1 保证贪心可行，引理 2＋定理 1 保证贪心最优，引理 3、4 保证事件循环精确复现贪心时间线，引理 5 保证算术无误，引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 钉死时间线：每秒"先塞入后加工"，等待长度按剩余未加工长度计，塞入必为前缀。
- consider easier version — 去掉 $h$ 约束：答案 $\lceil S/k\rceil$，机器永不空转；这是通用下界。
- explore its property — 手造反例 $h=5,k=4,a=[5,5]$：答案 $4>3$，$h$ 会逼机器空转，公式路线破产，必须调度。
- classic problem solution — 贪心"每秒能塞尽塞"；用 $(i,p)$ 双单调支配归纳证最优，核心是 $\min(p+k,S(i))$ 对两参单调。
- reduce to easier problem — 两次塞入之间只有 $w\mathrel{-}=k$ ⇒ 逐秒模拟压缩为事件快进 $d=\lceil(w-(h-a_i))/k\rceil$，$O(\text{答案})\to O(n)$。
- discuss by category — 塞完后收尾 $\lceil w/k\rceil$；$w-dk<0$ clamp；$d\ge1$ 防死循环；$t$ 达 $10^{14}$ 用 `i64`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,h,k` | 根数、等待上限、每秒加工量 | `int/i64`，读入 | $a_i\le h$，$k\ge1$ |
| `a[i]` | 第 $i$ 根长度（0-based） | `i64[mxn]`，读入 | 按顺序塞入 |
| `i` | 已塞入根数（下一根下标） | `int`，$0$ | 塞入阶段自增 |
| `w` | 当前等待长度（剩余未加工） | `i64`，$0$ | 恒 $\le h$；加工后 clamp 到 $0$ |
| `t` | 已经过的秒数 = 答案 | `i64`，$0$ | 可达 $10^{14}$ |
| `d` | 本次快进的秒数 | `i64` | $\lceil(w-(h-a_i))/k\rceil$ 或 $\lceil w/k\rceil$ |
| `ceildiv(x,y)` | $\lceil x/y\rceil$，$x\ge0,y>0$ | `i64(i64,i64)` | `(x+y-1)/y` |

### 算法步骤

1. 读 `n,h,k` 与 `a[0..n-1]`。
2. 循环（`i<n||w>0`）：
   1. 塞入：`while(i<n&&w+a[i]<=h) w+=a[i++];`
   2. 若 `i==n&&w==0` 跳出；
   3. 快进：`d = i<n ? ceildiv(w-(h-a[i]),k) : ceildiv(w,k)`；`t+=d; w=max(0,w-d*k);`
3. 输出 `t`。

### 复杂度

- 时间：$O(n)$（轮次 $\le n+1$，塞入合计 $n$ 次）。
- 空间：$O(n)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例 1/2 文字解释复现（$2$、$5$）、反例 $4$、$[10,10,10]$ 得 $12$、$10^9$ 极限均与手算一致；`appendix/P2793/check.cpp` 以逐秒暴力为基准，$2\times10^5$ 组随机小数据全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2793 Facer的工厂
// 贪心：每秒开头把能塞的前缀钢管全塞进去（等待长度<=h），然后机器加工 k。
// 逐秒模拟会到 1e14 秒，改成事件式快进：塞不进下一根时，
// 直接跳过 d=ceil((w-(h-a[i]))/k) 秒到"恰好能塞入"的那一秒；全部塞完则快进 ceil(w/k) 秒收尾。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n;
i64 h,k,a[mxn],w,t;

i64 ceildiv(i64 x,i64 y){return (x+y-1)/y;}	// 要求 x>=0,y>0

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>h>>k;
	for(int i=0;i<n;++i)
		cin>>a[i];
	int i=0;
	while(i<n||w>0)
	{
		while(i<n&&w+a[i]<=h)	// 本秒开头：按顺序塞到塞不下为止
			w+=a[i++];
		if(i==n&&w==0)
			break;
		i64 d=i<n?ceildiv(w-(h-a[i]),k):ceildiv(w,k);
		// i<n 时必有 w>h-a[i]>=0，故 d>=1；h-a[i]>=0 保证 d<=ceil(w/k)，w 不会减成负数以下
		t+=d;
		w=max(0ll,w-d*k);
	}
	cout<<t<<'\n';
	return 0;
}
```

### 代码说明

- 内层 `while` 是"最大前缀塞入"，与引理 1 的 $i_G$ 定义一一对应；外层每轮要么塞入至少一根、要么是最后的排空收尾，故 $O(n)$。
- `d` 的两个分支分别对应引理 3 的 (a)(b)；`i<n` 分支的分子 $w-(h-a_i)\ge1$ 由"塞入阶段已极大"保证，`ceildiv` 不会收到负数。
- `w=max(0ll,w-d*k)` 的 clamp 对应"最后一秒机器提前干完、空转半秒"，语义上合法（引理 3(a) 证明了那一秒秒首确实塞不进）。
- `t` 与 `d*k` 都可能超 `int`（$10^{14}$、$2\times10^9$），全程 `i64`；`0ll` 保证 `max` 两参同型。
- 全局 `w,t` 默认 $0$ 恰是初始状态；本题单测，无需重置。
