# P2840 纸币问题 2 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 种面额互不相同的纸币，第 $i$ 种面额 $a_i$、无限张，要恰好支付 $w$ 元。问有多少种**支付方式**，对 $10^9+7$ 取模。题面特意强调：**同样的纸币组合，支付顺序不同算不同方式**——付 $3$ 元时 $1+2$ 和 $2+1$ 是两种方式。范围：$1\le n\le10^3$，$1\le a_i,w\le10^4$；$40\%$ 数据 $n\le10,w\le100$。

这题和 P2834（纸币问题 3）是孪生题：那边数**组合**（无序），这边数**排列**（有序）。两题的状态都是"凑出某个金额的方案数"，但**循环次序恰好相反**。所以我先想清楚"有序"在数什么，再决定 DP 的枚举顺序。

**第一步：把"支付方式"翻译成数学对象。** 一次支付是一个**纸币序列** $(b_1,b_2,\dots,b_k)$，每个 $b_t$ 是某种面额（可重复），满足 $\sum_t b_t=w$。序列有序：$(1,2)$ 与 $(2,1)$ 是不同序列。空序列只在 $w=0$ 时合法（本题 $w\ge1$，但递推需要它作种子）。于是题目等价于：**数用给定面额（可重复）拼出 $w$ 的有序序列个数**——组合数学里这叫"受限组成（composition）"。

**第二步：先想暴力，确认要 DP。** 朴素想法是 DFS：每一步枚举下一张付哪种面额，累计到 $w$ 就计一种。但方式数本身可以是天文数字（$a$ 含 $1$、$w=10^4$ 时序列数极大），逐个枚举必然超时。$40\%$ 子任务 $n\le10,w\le100$ 暗示小规模可搜索、大规模要递推。方向：**线性 DP**。

**第三步：找递推——按"最后一张"分类。** 令 $g[j]$ = "恰好支付 $j$ 元的有序方式数"。任何一个支付 $j$ 元的非空序列都有**最后一张**纸币。按最后一张是哪种面额分类：

- 最后一张是 $a_i$（要求 $a_i\le j$）：去掉它，前面是一个支付 $j-a_i$ 元的任意有序序列，有 $g[j-a_i]$ 种；反过来，任何支付 $j-a_i$ 的序列后面接一张 $a_i$，都唯一得到一个"最后一张是 $a_i$"的支付 $j$ 的序列。

各类按"最后一张的面额"划分，不重不漏（一个序列的最后一张是唯一确定的），所以

$$g[j]=\sum_{i:\,a_i\le j} g[j-a_i],\qquad g[0]=1\ (\text{空序列}).$$

这就是"爬楼梯/完全排列"型递推：金额外层、面额内层。

**第四步：循环次序——为什么金额必须在外层。** 把递推写成代码：

```
dp[0]=1
for j = 1 .. w:            // 金额外层
    for i = 0 .. n-1:      // 面额内层
        if a[i]<=j: dp[j] += dp[j-a[i]]
```

算 `dp[j]` 时，所有 `dp[j-a[i]]`（$j-a[i]<j$）都已在之前的金额轮算好，是完整的 $g[j-a[i]]$（**所有面额都可用**）。这正对应"最后一张是 $a_i$、前面任意序列"。

反过来，如果误写成 P2834 的"面额外层、金额升序内层"，会怎样？那时 `dp[j]` 是"只用前若干种面额"的方案数，每种组合里的纸币被强制按面额种类编号递增的顺序加入，于是**同一组合的不同排列被合并成一种**——数出来的是组合而非排列。

**第五步：最小反例钉死次序。** 取 $a=\{1,2\},w=3$：

- 本题（排列，金额外层）：$1+1+1$、$1+2$、$2+1$，共 **3**。
- 若误用面额外层（组合）：$\{1,1,1\},\{1,2\}$，只有 **2**。

$3\ne2$，这个反例让我确认本题**必须金额外层**。手算递推核对：$g[0]=1$；$g[1]=g[0]=1$（只有 $1$）；$g[2]=g[1]+g[0]=2$（$1+1$、$2$）；$g[3]=g[2]+g[1]=3$（$1+1+1$、$2+1$、$1+2$）。与枚举一致。

**第六步：取模与溢出。** 与 P2834 同理：`dp[j]` 累加过程中，每次加法前两个加数都在 $[0,p)$，和 $<2p<2^{31}$，`int` 不溢出；每加一项就"若 $\ge p$ 减 $p$"，保证 `dp[j]` 始终落在 $[0,p)$。注意这里是**内层循环里逐项取模**（因为要对 $n$ 个面额累加），而不是加完所有项再取一次模——后者中间和可能高达 $n\cdot p$ 溢出 `int`。逐项减 $p$ 既正确又快。

**手造数据核对**（题面无样例，按规则自造）：

| 输入 | 有序方式 | 输出 |
|---|---|---|
| `2 3` / `1 2` | $1{+}1{+}1,\ 1{+}2,\ 2{+}1$ | `3` |
| `1 4` / `2` | $2{+}2$ | `1` |
| `3 10000` / `10000 9999 1` | $10000$；$9999{+}1$；$1{+}9999$；$1\times10^4$ | `4` |

第三组专门打"大面额 + 顺序"：$9999+1$ 与 $1+9999$ 算两种，加上整张 $10000$ 和全 $1$，共 $4$。另外跑极限规模 $n=1000,w=10000,a_i=i$，约 $10^7$ 次转移，实测 $0.06$ 秒。

## 二、思维链：完整证明

**记号。** 面额 $a_0,\dots,a_{n-1}$ 互异、$\ge1$，目标 $w\ge1$，模数 $p=10^9+7$。一种**支付方式**定义为有限序列 $(b_1,\dots,b_k)$（$k\ge0$），每个 $b_t\in\{a_0,\dots,a_{n-1}\}$，$\sum_t b_t=w$。序列有序、面额可重复。设 $g[j]$ 为支付 $j$ 元的有序方式数（真实值），答案 $=g[w]\bmod p$。

---

### 引理 1（按最后一张分类的递推）

$g[0]=1$；对 $j\ge1$，
$$g[j]=\sum_{i:\,a_i\le j} g[j-a_i].$$

*证明*：$j=0$ 时只有空序列 $(\,)$ 满足总额 $0$（任何非空序列总额 $\ge\min a_i\ge1>0$），故 $g[0]=1$。

$j\ge1$ 时，任何支付 $j$ 的序列必非空（空序列总额 $0\ne j$），故有唯一的最后一张 $b_k$。按 $b_k$ 等于哪个面额 $a_i$ 把所有序列划分成若干类，各类不交（最后一张唯一）且并为全体。

固定 $i$ 且 $a_i\le j$。考察"最后一张是 $a_i$"的序列集合 $S_i$。定义映射 $\varphi:S_i\to\{\text{支付 }j-a_i\text{ 的序列}\}$，$\varphi(b_1,\dots,b_k)=(b_1,\dots,b_{k-1})$（去掉最后一张）。因 $b_k=a_i$，去掉后总额 $=j-a_i\ge0$，故像合法。$\varphi$ 是双射：逆映射为"在任意支付 $j-a_i$ 的序列末尾接一张 $a_i$"，二者互逆显然。故 $|S_i|=g[j-a_i]$。

若 $a_i>j$，则 $S_i=\varnothing$（最后一张 $a_i>j$ 使总额 $>j$），贡献 $0$，与求和条件 $a_i\le j$ 一致。

各类相加：$g[j]=\sum_{i:a_i\le j}|S_i|=\sum_{i:a_i\le j}g[j-a_i]$。证毕。

---

### 引理 2（金额外层、面额内层的滚动实现正确）

算法：`dp[0]=1`，其余初始 $0$；对 $j=1,\dots,w$（升序），对 $i=0,\dots,n-1$，若 $a_i\le j$ 则 `dp[j]=(dp[j]+dp[j-a_i]) mod p`。则每个 $j$ 轮结束后 `dp[j]`$=g[j]\bmod p$，最终 `dp[w]`$=g[w]\bmod p$。

*证明*：对 $j$ 归纳。

**基础**：$j=0$，`dp[0]=1`$=g[0]$。

**步骤**：设对所有 $t<j$ 已有 `dp[t]`$=g[t]\bmod p$。进入第 $j$ 轮时 `dp[j]` 仍是初始 $0$（此前各轮只更新各自的下标，且 $j$ 未被碰过；注意 $j-a_i<j$，之前轮更新的是更小下标）。本轮内层依次对每个满足 $a_i\le j$ 的 $i$ 执行 `dp[j]+=dp[j-a_i]`。因 $j-a_i<j$，由归纳假设 `dp[j-a_i]`$=g[j-a_i]\bmod p$，且本轮不会修改它（内层只改 `dp[j]`）。故内层结束后
$$\texttt{dp[j]}=\Big(\sum_{i:a_i\le j}g[j-a_i]\Big)\bmod p=g[j]\bmod p$$
（引理 1）。逐项取模的正确性见引理 3。归纳完成。证毕。

---

### 引理 3（逐项取模不溢出且正确）

内层每次加法前，`dp[j]` 与 `dp[j-a_i]` 都在 $[0,p)$。其和 $s<2p=2\,000\,000\,014<2^{31}-1$，`int` 不溢出；执行"若 $s\ge p$ 则 $s-p$"后结果 $=s\bmod p\in[0,p)$。因此无论内层累加多少项，`dp[j]` 始终保持在 $[0,p)$ 且等于"已累加项之和 $\bmod p$"。内层全部结束后即 $g[j]\bmod p$。

*证明*：$2(p-1)=2\,000\,000\,012<2\,147\,483\,647$，不溢出。$0\le s<2p\Rightarrow s\bmod p=s-[s\ge p]\cdot p$，与代码一致。对累加项数归纳即得"始终等于部分和模 $p$"。**关键**：必须逐项取模；若把 $n$ 项先全加进一个 `int` 再取模，中间和可达 $n(p-1)\approx10^{12}$，远超 `int`，会溢出。证毕。

---

### 引理 4（面额外层会数成组合——为什么本题必须金额外层）

若改用"面额外层 $i$、金额升序内层 $j$"（即 P2834 的写法），则得到的 `dp[w]` 是**组合数**（无序），一般严格小于本题的排列数。

*证明*：面额外层时，第 $i$ 轮只允许使用面额 $a_0,\dots,a_i$，且递推 `dp[j]+=dp[j-a_i]` 中 `dp[j-a_i]` 是"只用前 $i+1$ 种"的方案。归纳可知最终 `dp[j]` 数的是"非递减面额序列"——因为纸币只能按种类编号从小到大的顺序被加入，任何组合被唯一地表示成"先若干 $a_0$、再若干 $a_1$、……"的规范序列。这与"有序序列"不同：后者把同一组合的不同排列分别计数。

最小反例：$a=\{1,2\},w=3$。金额外层得 $g[3]=3$（$111,12,21$）；面额外层得组合数 $2$（$\{1,1,1\},\{1,2\}$）。$3>2$，故面额外层对本题错误。证毕。

---

### 引理 5（复杂度）

时间 $O(nw)$，空间 $O(n+w)$。

*证明*：外层 $w$ 轮，每轮内层 $n$ 次，每次 $O(1)$（比较 + 可能的加法/减法），故 $O(nw)\le10^7$，实测约 $0.06$ 秒。空间：`a` 占 $O(n)$，`dp` 占 $O(w)$。证毕。

---

### 定理

算法输出支付 $w$ 元的**有序**方式数 $\bmod(10^9+7)$，时间 $O(nw)$。

*证明*：引理 1 建立按最后一张分类的正确递推；引理 2 证明金额外层、面额内层的滚动精确实现它；引理 3 保证逐项取模正确且不溢出；引理 4 排除面额外层的错误（那会数成组合）；引理 5 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "顺序不同算不同方式"= 数有序序列（受限组成），而非组合；空序列是 $w=0$ 的种子。
2. **consider easier version** — DFS 枚举下一张的暴力会因方式数爆炸而超时，确认要线性递推。
3. **classic problem solution** — 按"最后一张面额"分类：$g[j]=\sum_{a_i\le j}g[j-a_i]$，$g[0]=1$（爬楼梯型完全排列）。
4. **reduce to easier problem** — 金额外层升序、面额内层滚动；`dp[j-a_i]` 恒为已算好的完整 $g$ 值。
5. **discuss by category** — 最小反例 $a=\{1,2\},w=3$：排列 $3$ vs 组合 $2$，钉死"金额外层"，与孪生题 P2834 恰好相反。
6. **explore its property** — 内层对 $n$ 项累加必须**逐项**取模（否则中间和 $\sim np$ 溢出 `int`）；单项和 $<2p<2^{31}$ 安全。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 纸币种数，$\le10^3$ | `int` | 读入 |
| `w` | 目标金额，$\le10^4$ | `int` | 读入 |
| `a[i]` | 第 $i$ 种面额（0-based），互异，$\ge1$ | `int[mxn]` | 读入；`mxn=1005` |
| `dp[j]` | 支付 $j$ 元的**有序**方式数 $\bmod p$ | `int[mxw]` | `dp[0]=1`（空序列），其余 $0$；`mxw=10005` |
| `p` | 模数 $10^9+7$ | `constexpr int` | `1'000'000'007` |
| `j` | 外层金额，**升序** | `int` | $1..w$ |
| `i` | 内层面额下标 | `int` | $0..n-1$ |

### 算法步骤

1. I/O 加速三行。
2. 读 `n,w`；读 `a[0..n-1]`。
3. `dp[0]=1`（空序列支付 $0$ 元），其余靠全局零初始化。
4. 对 `j=1..w`（升序）：对 `i=0..n-1`，若 `a[i]<=j` 则 `dp[j]+=dp[j-a[i]]; if(dp[j]>=p)dp[j]-=p;`（逐项取模）。
5. 输出 `dp[w]`。

### 复杂度

- 时间：$O(nw)\le10^7$，实测极限数据约 $0.06$ 秒。
- 空间：$O(n+w)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 $\{1,2\}/w=3\to3$、$\{2\}/w=4\to1$、$\{10000,9999,1\}/w=10000\to4$ 均与手算一致；极限 $n=1000,w=10000$ 正常运行。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2840 纸币问题 2
// 排列(有序)计数 ⇒ 金额外层 + 面额内层：dp[j]=Σ dp[j-a[i]]。
// 按"最后一张是 a[i]"分类；dp[0]=1(空序列)。
// 与 P2834(组合,面额外层)恰为孪生，循环次序相反。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},mxw{10005};
constexpr int p{1'000'000'007};

int n,w,a[mxn],dp[mxw];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>w;
	for(int i=0;i<n;++i)
		cin>>a[i];
	dp[0]=1;					// 支付 0 元：空序列，唯一方式
	for(int j=1;j<=w;++j)		// 外层枚举金额 ⇒ 排列（有序）
		for(int i=0;i<n;++i)
			if(a[i]<=j)
			{
				dp[j]+=dp[j-a[i]];	// 最后一张是 a[i]
				if(dp[j]>=p)
					dp[j]-=p;
			}
	cout<<dp[w]<<'\n';
	return 0;
}
```

### 代码说明

- **金额外层、面额内层**是本题核心，与 P2834 恰好相反。它实现"按最后一张分类"的递推 $g[j]=\sum g[j-a_i]$。
- `dp[0]=1` 是空序列种子；其余 `dp[j]` 依赖全局零初始化（凑不出时为 $0$）。
- 内层对 $n$ 个面额累加，**每加一项就取一次模**（引理 3）：单项和 $<2p<2^{31}$ 用 `int` 安全；若攒完再取模会溢出。
- `if(a[i]<=j)` 跳过过大面额，避免负下标。
- 面额互异保证"按最后一张面额分类"各类不交；若面额可重复则需先去重，否则同一序列会被重复计数（本题保证互异，无需处理）。
