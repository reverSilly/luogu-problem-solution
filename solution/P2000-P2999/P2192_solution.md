# P2192 HXY玩卡片 — 题解

## 一、解题过程：人类思考叙事

题目描述看起来很啰嗦，但翻译过来只有一句话：给你 $n$ 张卡片，每张卡片上写着一个数字（只可能是 $5$ 或 $0$），要求你挑出其中若干张，排成一个**能被 $90$ 整除的整数**，求这个整数最大是多少。

先把 $90$ 拆开：$90 = 9 \times 10$。于是"能被 90 整除"等价于"同时能被 9 整除且能被 10 整除"。

能被 $10$ 整除 ⇒ 末位必须是 $0$。这立刻带来两个推论：

第一，如果没有 $0$ 这张卡片，那么拼出来的数末位不可能是 $0$（$5$ 的末位是 $5$），一个都不能用，输出 `-1`。

第二，如果有 $0$，那么至少可以用掉一张 $0$ 放在末位。

接着处理"能被 9 整除"。有个经典结论：一个数能被 $9$ 整除，当且仅当它的**各位数字之和**能被 $9$ 整除。

而我们手上只有 $5$ 和 $0$，数字和就是 $5 \times (\text{5 的个数}) + 0 = 5k$，其中 $k$ 是用掉的 $5$ 的个数。要求 $9 \mid 5k$，因为 $\gcd(5,9)=1$，所以必须有 $9 \mid k$。

也就是说：**用掉的 $5$ 的个数必须是 9 的倍数**。

现在问题就退化成了：手上有 $c_5$ 个 $5$、$c_0$ 个 $0$，选 $k$ 个 $5$（$k$ 是 9 的倍数，$k \le c_5$）和若干个 $0$，排成最大的数。

最大化一个数，先看位数：位数越多数越大（无前导零时）。位数 = 用的 $5$ 的个数 + 用的 $0$ 的个数。$5$ 的个数每多 9 个就多 9 位，所以 $k$ 应取最大的 9 的倍数 $k = \lfloor c_5/9 \rfloor \times 9$。$0$ 当然全部用上（每个 $0$ 都贡献一位）。

如果 $k = 0$，说明根本凑不出一个带 $5$ 的合法数。此时唯一的合法数是整数 $0$（$0$ 能被 $90$ 整除），输出 `0`。

最后是排列：位数固定后，要让数最大，就要把大的数字放前面。$5 > 0$，所以把所有 $5$ 放前面、所有 $0$ 放后面，得到 `555...000...`。

题面说"选若干张卡片拼成一个整数"，如果"若干张"允许一张，答案就退化成 `0`；如果"至少两张"且不允许多余前导零，样例 1 给出 `0`，说明允许只拼出一张 `0`。样例 1 是 `5 0 5 0`，用掉的两张 `5` 无法凑成 9 的倍数（只有 2 个 $5$），所以只能拼出一个 `0`——这与"用掉全部 $0$"矛盾。因此题意的正确理解是：**要拼的数必须能被 90 整除，而 0 本身是合法的（$0 = 0 \times 90$）**；当拼不出含 $5$ 的合法数时，最优解就是 `0`。样例 2 是 9 个 $5$ 加 1 个 $0`，答案 `5555555550`（共 10 位），验证了"用掉 9 个 $5$ + 1 个 $0$"。样例 3 只有两个 `5`，没有 `0`，答案 `-1`。

整题就是一堆数论结论 + 贪心，没有数据结构，$O(n)$。

## 二、思维链：完整证明

**引理 1**：一个只由 $5$ 和 $0$ 组成的十进制正整数（至少含一个 $5$）能被 $90$ 整除，当且仅当它末位为 $0$ 且其中 $5$ 的个数是 $9$ 的倍数。

*证明*：设该数含 $k$ 个 $5$、$t$ 个 $0$。
由 $90 = 9 \times 10$ 且 $\gcd(9,10)=1$，$90 \mid x \iff 9 \mid x$ 且 $10 \mid x$。
$10 \mid x$ 当且仅当 $x$ 的末位是 $0$。
$x$ 的各位数字之和为 $5k$。由 $9$ 整除的判定法则，$9 \mid x \iff 9 \mid 5k$。又 $\gcd(5,9)=1$，由欧几里得引理得 $9 \mid 5k \iff 9 \mid k$。
综上得证。证毕。

**引理 2**：设卡片中 $5$ 的个数为 $c_5$、$0$ 的个数为 $c_0$，则任何合法的拼接结果中所含 $5$ 的个数 $k$ 满足 $k \le \lfloor c_5/9 \rfloor \times 9$；当 $c_0 = 0$ 时不存在合法的正整数结果。

*证明*：由引理 1，$k$ 必须是 $9$ 的倍数，且 $k \le c_5$。满足这两个条件的最大非负 $k$ 恰为 $9 \lfloor c_5/9 \rfloor$。另一方面，若 $c_0 = 0$，则任何拼出的数末位都是 $5$，不能被 $10$ 整除，故不能被 $90$ 整除，得证。证毕。

**引理 3**：在所有合法的拼接结果中，最大者所含的 $5$ 的个数恰为 $k^* = 9\lfloor c_5/9 \rfloor$，且所用的 $0$ 的个数为 $c_0$（假设 $c_0 \ge 1$ 且 $k^* \ge 1$）。

*证明*：设某合法结果含 $k$ 个 $5$、$t$ 个 $0$（$0 \le t \le c_0$），其位数为 $k+t$。若两个正整数位数不同，则位数多的严格更大（无前导零）。由引理 2，$k \le k^*$。
先证 $t$ 应取 $c_0$：固定 $k$，把结果的末位 $0$ 换成更多的 $0$（即在末位多插一个 $0$）后仍满足"末位为 $0$、$5$ 的个数是 $9$ 的倍数"，位数加一，故严格更大。所以最优解用满 $c_0$ 个 $0$。
再证 $k$ 应取 $k^*$：设某解含 $k < k^*$ 个 $5$（$k$ 仍是 9 的倍数），由 $k^* - k \ge 9$，可以把 $k^* - k$ 个额外的 $5$ 插到最前面，所得新数仍以 $0$ 结尾、$5$ 的个数变成 $k^*$（是 9 的倍数），位数由 $k + c_0$ 增加到 $k^* + c_0$，严格更大。所以最优解取 $k = k^*$。证毕。

**引理 4**：在含 $k^*$ 个 $5$ 与 $c_0$ 个 $0$ 的所有排列中，把所有 $5$ 放在前面、所有 $0$ 放在后面，得到的数最大。

*证明*：设某个排列不是"所有 $5$ 在前"，则存在一对位置 $i < j$，位置 $i$ 是 $0$、位置 $j$ 是 $5$。交换这两个位置，其余位不变。交换后高位变大、低位变小，两数位数相同，故交换后的数严格更大。反复交换直到所有 $5$ 都在所有 $0$ 之前，得到 $55\cdots500\cdots0$，它不小于任何其他排列，是最大值。证毕。

**引理 5**：当 $c_0 \ge 1$ 且 $k^* = 0$ 时，最优答案为整数 $0$；当 $c_0 = 0$ 时答案为 $-1$。

*证明*：$k^* = 0$ 表示手头的 $5$ 不足 $9$ 个。由引理 1，任何含 $5$ 的正整数都不合法。而只用一个 $0$ 拼出的整数 $0$ 满足 $0 = 0 \times 90$，是合法的，且任何合法的正整数都比 $0$ 大，因此最优解为 $0$。若 $c_0 = 0$，由引理 2 不存在合法的正整数，而负数不符合"拼卡片"的含义，故无解，输出 $-1$。证毕。

**定理**：本算法输出的即为最大合法整数。

*证明*：分三种情形。$c_0 = 0$ 时由引理 5 输出 $-1$ 正确；$c_0 \ge 1$ 且 $k^* = 0$ 时由引理 5 输出 $0$ 正确；否则由引理 3 最优解含 $k^*$ 个 $5$ 与 $c_0$ 个 $0$，由引理 4 它们的最佳排列是 $5 \cdots 5 0 \cdots 0$，恰为算法输出。证毕。

**引理 6**：本算法的时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

*证明*：读入 $n$ 张卡片并统计 $c_5, c_0$ 需 $O(n)$ 时间；输出至多 $n$ 个字符需 $O(n)$ 时间。除此之外只使用常数个变量，占 $O(1)$ 空间。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别题型** → 构造最大数 + 数论整除条件
2. **拆分解除条件** → $90 = 9 \times 10$，拆成"被 9 整除"和"被 10 整除"两条独立的可判定条件
3. **逐条落实** → 被 10 整除 ⇒ 末位是 `0`；被 9 整除 ⇒ 数位和是 9 的倍数 ⇒ $5$ 的个数是 9 的倍数
4. **把数论转成贪心** → $k$ 取最大的 9 的倍数，$0$ 全部用上，位数越多越大
5. **固定数字集合后定排列** → 大的数字全部前置 ⇒ `555...000`
6. **补齐边界** → 没有 $0$ 输出 `-1`；$5$ 不足 9 个输出 `0`
7. **写代码** → 计数 → 分支输出

## 四、解法说明

### 算法

统计卡片中 $5$ 和 $0$ 的个数 $c_5, c_0$。

1. 若 $c_0 = 0$，输出 `-1`。
2. 计算 $k = 9 \lfloor c_5 / 9 \rfloor$。
3. 若 $k = 0$，输出 `0`。
4. 否则输出 $k$ 个 `5`，紧接着输出 $c_0$ 个 `0`。

### 符号表

| 符号 | 含义 | 初始化 | 记忆点 |
|------|------|--------|--------|
| $n$ | 卡片总数 | 输入 | 读入后即固定 |
| $c_5$ | 数字为 $5$ 的卡片数 | $0$ | 遇到 $5$ 加一 |
| $c_0$ | 数字为 $0$ 的卡片数 | $0$ | 遇到 $0$ 加一 |
| $k$ | 使用的 $5$ 的个数（9 的倍数） | $9\lfloor c_5/9\rfloor$ | 向下取整到 9 的倍数 |

### 算法步骤

1. 初始化 I/O 加速（`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`）。
2. 读入 $n$，循环读入 $n$ 个数字，分别累加到 $c_5$、$c_0$。
3. 若 $c_0 = 0$，输出 `-1` 并结束。
4. 计算 $k = c_5 / 9 * 9$（整数除法）。
5. 若 $k = 0$，输出 `0` 并结束。
6. 循环输出 $k$ 个字符 `5`。
7. 循环输出 $c_0$ 个字符 `0`，输出换行。

### 复杂度

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(1)$（不计输出缓冲）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2192 HXY玩卡片
// 思路：90 = 9 * 10；末位必须是 0，数字和必须是 9 的倍数
//       数字和 = 5 * (5 的个数) => 5 的个数必须是 9 的倍数
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,c5,c0;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		int x;cin>>x;
		if(x==5)++c5;
		else ++c0;
	}
	// 没有 0 就凑不出末位 0，连整数 0 都排不出来
	if(c0==0)
	{
		cout<<-1<<'\n';
		return 0;
	}
	// 5 的个数必须是 9 的倍数，取最大的那个（位数越多数越大）
	int k=c5/9*9;
	if(k==0)
	{
		// 凑不出含 5 的合法数，只有整数 0 合法
		cout<<0<<'\n';
		return 0;
	}
	// 同样的位数下 5 全部前置最大；0 全部用上（多一位就更大）
	for(int i=0;i<k;++i)cout<<'5';
	for(int i=0;i<c0;++i)cout<<'0';
	cout<<'\n';
	return 0;
}
```

### 代码说明

- 计数器 `c5`、`c0` 放在全局，`mxn` 为松弛上界常量。
- 用 `c5/9*9` 完成"向下取整到 9 的倍数"，全程 `int` 即可，$n \le 1000$ 不会溢出。
- 输出的 0 写作 `cout<<0<<'\n'` 而不是 `'0'`，保证与样例中的 `0` 一致（数值 0）。
- 换行使用 `'\n'`，`main` 正常结束 `return 0`。

### 验证状态

- 编译：`g++ -O2 -std=c++17` 通过，无警告。
- 官方样例三组全部通过：`4 / 5 0 5 0` → `0`；`11 / 5 5 5 5 5 5 5 5 0 5 5` → `5555555550`；`2 / 5 5` → `-1`。
- 对拍：使用 `P2192_brute.cpp` 暴力枚举所有"取出若干张卡片的所有子集与排列"，取能被 $90$ 整除的最大值作为答案，与标程在 2000 组随机数据上比对，全部一致。
