# P2618 数字工程 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 多组数据（每行一个 $n$，读到 EOF），$1\le n\le10^6$。每次操作可以"减 $1$"或"除以 $n$ 的任意一个素因子"，各耗 $1$ 单位能量，求把 $n$ 变成 $1$ 的最少能量。

**第一反应：贪心。** "除以最大素因子缩小得最快"听起来很对。手算 $n=8$ 检验：贪心走 $8\to4\to2\to1$，$3$ 步；但 $8\to7\to1$ 只要 $2$ 步——$7$ 是素数，一步除尽！**贪心第一步就死了**。失败根源：状态的"好坏"不由大小决定，素数是"一步到 $1$"的好状态，减 $1$ 可能恰好跳进好状态；"能除就除"这类短视规则看不见这一步之外的世界。

**第二步：手算小表找规律。** $f[1..10]=0,1,1,2,1,2,1,2,2,2$。规律：$f[\text{素数}]=1$；$f[8]=2$ 来自 $8\to7$；$f[9]=2$ 来自 $9\to3$。每个状态的答案似乎都由"更小的状态"决定——确实如此：

**最优子结构。** 从 $i$ 出发的第一步只有两种可能：到 $i-1$，或到 $i/p$（$p$ 是 $i$ 的素因子）。剩下的步骤必须是目标状态的最优解（否则换更优的，总步数更少，矛盾）。而 $i-1<i$、$i/p\le i/2<i$，**所有依赖都严格更小**，于是得到无后效性的正推 DP：

$$f[1]=0,\qquad f[i]=1+\min\Bigl(f[i-1],\ \min_{p\mid i,\ p\text{ 素}}f[i/p]\Bigr).$$

**第三步：实现瓶颈——素因子从哪来？** 对每个 $i$ 试除到 $\sqrt i$：$\sum_{i\le10^6}\sqrt i\approx6.7\times10^8$ 次取模，太慢。正确工具是**线性筛预处理最小素因子 `spf`**，然后对每个 $i$ 沿 `spf` 链剥素数幂：`x=i`，取 `p=spf[x]`，用 $f[i/p]$ 松弛，把 $x$ 中 $p$ 的幂全部剥掉，重复直到 $x=1$。这样每个 $i$ 的代价是 $\Omega(i)$（计重数的素因子个数），总量 $\sum\Omega(i)=O(N\log\log N)$，宽松上界 $O(N\log N)\approx2\times10^7$（因 $\Omega(i)\le\log_2 i$），都远低于时限。

**第四步：多组数据。** 询问个数未知（EOF 驱动），但 $n\le10^6$ 固定：**预处理一次** $f[1..10^6]$（筛 + DP 合计几百万次操作），每问 $O(1)$ 输出。`while(cin>>n)` 即可。

**第五步：边界与哨兵。** $n=1$ 时已是 $1$，答案 $0$。注意本题**不需要 INF**：任何 $i$ 都能沿"减 $1$"链走到 $1$，故 $f[i]\le i-1$ 恒有限，`f[i]=f[i-1]+1` 是永远可行的保底转移——这与"不可达数组必须显式填 INF"的惯例不冲突，因为这里根本没有不可达状态。值域上 $f[i]\le2\lfloor\log_2 i\rfloor+1\le41$（奇减偶除策略），`int` 绰绰有余。

**手造数据核对。** 题面无样例，我手算了 $f[1..30]$ 全表：

$$0,1,1,2,1,2,1,2,2,2,1,2,1,2,2,3,1,2,1,2,2,2,1,2,2,2,3,3,1,2$$

（例如 $f[12]=2$：$12\to11\to1$；$f[16]=3$：$16\to15\to5\to1$；$f[27]=3$：$27\to9\to3\to1$。）程序输出逐项一致。另测：$f[97]=f[7919]=f[999983]=1$（素数）；$f[10^6]=3$，手工验证路径 $1000000\xrightarrow{\div5}200000\xrightarrow{-1}199999\xrightarrow{\div199999}1$（$199999$ 是素数），且 $2$ 步不可能：一步要求 $10^6$ 是素数（否）；两步要求 $999999,500000,200000$ 之一是素数（$999999=3\times333333$，后两个是偶数，全否）。

## 二、思维链：完整证明

**记号。** $N=10^6$。$f[i]$：把 $i$ 变成 $1$ 的最少操作数。$\mathrm{spf}[x]$：$x$ 的最小素因子（素数处 $\mathrm{spf}[p]=p$）。$\Omega(i)$：$i$ 的计重数素因子个数（$\Omega(12)=\Omega(2^2\cdot3)=3$）。$\omega(i)$：互异素因子个数。

---

### 引理 1（最优子结构与递推）

$f[1]=0$；对 $i\ge2$，
$$f[i]=1+\min\Bigl(f[i-1],\ \min_{p\mid i,\ p\text{ 素}}f[i/p]\Bigr).$$

*证明*：记 $R=1+\min(\cdots)$。

**（$f[i]\le R$，构造可达）** 对每个候选目标 $j\in\{i-1\}\cup\{i/p:p\mid i\text{ 素}\}$：先做一步合法操作到 $j$，再接 $j$ 的最优序列（$f[j]$ 步），得到 $i\to1$ 的 $1+f[j]$ 步方案。故 $f[i]\le1+f[j]$ 对所有候选成立，取 min 得 $f[i]\le R$。

**（$f[i]\ge R$，最优分解）** 取 $i$ 的最优操作序列，其第一步必为"减 $1$"（到 $i-1$）或"除以某素因子 $p$"（到 $i/p$）——题面只允许这两种操作。设到 $j$，则剩余部分是 $j\to1$ 的 $f[i]-1$ 步方案，故 $f[j]\le f[i]-1$，即 $f[i]\ge1+f[j]\ge R$。

双向夹逼得等式。**良基性**：$i-1<i$，$i/p\le i/2<i$（$p\ge2$），依赖严格递减，对 $i$ 强归纳无循环，$f[1]=0$ 为基（$1$ 已是目标，$0$ 步；任何操作都使数变小，不可能"操作后再回 $1$"更优）。证毕。

---

### 引理 2（线性筛正确性：$\mathrm{spf}$ 与线性复杂度）

筛结束后，对所有 $2\le x\le N$：$\mathrm{spf}[x]$ 等于 $x$ 的最小素因子；每个合数恰被标记一次；总操作数 $O(N)$。

*证明*：对 $i$ 强归纳（$i=2..N$），归纳假设：所有 $2\le x<i$ 的 $\mathrm{spf}[x]$ 已正确，且合数 $x$ 恰被标记一次。处理 $i$ 时：

**(a) 若 $\mathrm{spf}[i]=0$，则 $i$ 是素数。** 反证：设 $i$ 合，$p=\mathrm{spf}[i]$（真实最小素因子），$m=i/p<i$。$m$ 的每个素因子都是 $i$ 的素因子，故 $\mathrm{spf}[m]\ge p$。由归纳假设 $m$ 已被正确处理，其内层循环按升序枚举素数表 $pr$，直到 $pr[j]=\mathrm{spf}[m]$ 才 `break`（`i%pr[j]==0` 首次成立恰在 $pr[j]=\mathrm{spf}[m]$），故所有 $\le\mathrm{spf}[m]$ 的素数都被枚举到；$p\le\mathrm{spf}[m]$ 且 $m\cdot p=i\le N$ 未越界，于是 $i$ 在 $m$ 那一轮已被标记为非 $0$，矛盾。故 $i$ 素，置 $\mathrm{spf}[i]=i$ 并加入 $pr$；素数按升序发现，$pr$ 始终升序 ✓。

**(b) 内层标记的值正确。** 内层枚举到的 $pr[j]$ 满足 $pr[j]\le\mathrm{spf}[i]$（$i$ 素时 $\mathrm{spf}[i]=i$，`break` 发生在 $pr[j]=i$；$i$ 合时发生在 $pr[j]=\mathrm{spf}[i]$）。令 $x=i\cdot pr[j]\le N$：$i$ 的每个素因子 $\ge\mathrm{spf}[i]\ge pr[j]$，故 $x$ 的最小素因子就是 $pr[j]$，赋值 $\mathrm{spf}[x]=pr[j]$ 正确。又 $x\ge2i>i$，标记不触碰已处理条目，归纳假设不被破坏。

**(c) 每个合数都被标记。** 设 $i$ 合，$p=\mathrm{spf}[i]$，$m=i/p<i$。同 (a) 的论证：$\mathrm{spf}[m]\ge p$，$m$ 的内层循环必枚举到 $p$（乘积界 $m\cdot p=i\le N$ 不提前拦截），$i$ 被标记且值为 $p$ ✓。

**(d) 唯一性与线性。** 若 $i$ 被两次标记：$i=u\cdot q=u'\cdot q'$，两次都满足 $q\le\mathrm{spf}[u]$、$q'\le\mathrm{spf}[u']$。由 (b)，$q$ 与 $q'$ 都等于 $i$ 的最小素因子，故 $q=q'$，进而 $u=u'=i/q$：两次标记来自同一轮同一 $j$，矛盾。故每个合数恰标记一次。内层总迭代次数 $=$ 合数个数 $\le N$，外层 $N$ 轮，总 $O(N)$。归纳完成。证毕。

---

### 引理 3（`spf` 链恰好枚举互异素因子，DP 实现正确）

对固定 $i$，循环 `x=i; while(x>1){ p=spf[x]; 用 f[i/p] 松弛; 剥尽 x 中 p 的幂; }` 中，$p$ 恰好取遍 $i$ 的每个互异素因子各一次；且每次松弛引用的 $f[i/p]$ 均已算好。故正推得到的 $f[i]$ 满足引理 1 的递推。

*证明*：**枚举不重不漏**：维护不变量"$i$ 的素因子集合 $=$ 已访问的 $p$ 之集 $\sqcup$ $x$ 的素因子之集，且 $x\mid i$"。初始 $x=i$、已访问为空 ✓。每轮：$p=\mathrm{spf}[x]$ 是 $x$ 的素因子从而是 $i$ 的素因子；$p$ 未访问过（否则上轮已把 $p$ 的幂剥尽，$p\nmid x$，与 $p=\mathrm{spf}[x]$ 矛盾）；剥幂后 $x'=x/p^{v_p(x)}$ 仍整除 $i$，其素因子集恰为 $x$ 的素因子集去掉 $p$，不变量保持。$x\ge2$ 时每轮 $x'\le x/2$，严格递减，有限轮到 $1$；此时 $x$ 无素因子，不变量给出"已访问 $=i$ 的全部互异素因子" ✓。

**依赖已就绪**：$p\ge2\Rightarrow i/p\le i/2<i$，外层按 $i$ 升序计算，$f[i/p]$ 与 $f[i-1]$ 都已定值 ✓。

**递推一致**：代码先 `f[i]=f[i-1]+1`，再对每个互异素因子 $p$ 取 `min(f[i],f[i/p]+1)`，恰为引理 1 的 $1+\min(f[i-1],\min_p f[i/p])$ ✓。对 $i$ 归纳即得全表正确。证毕。

---

### 引理 4（复杂度）

预处理时间 $O(N\log N)$（宽松初等界；精细为 $O(N\log\log N)$），每次询问 $O(1)$；空间 $O(N)$。

*证明*：筛 $O(N)$（引理 2(d)）。DP 对每个 $i$：`x` 循环轮数 $=\omega(i)$，剥幂除法总次数 $=\Omega(i)$，松弛 $\omega(i)\le\Omega(i)$ 次，故单点代价 $O(\Omega(i))$。总量
$$\sum_{i\le N}\Omega(i)=\sum_{p^k\le N}\Bigl\lfloor\frac N{p^k}\Bigr\rfloor\le N\sum_{p\le N}\frac1{p-1}=O(N\log\log N)$$
（第一个等号：$\Omega(i)=\sum_{p^k\mid i}1$，交换求和；最后一步是 Mertens 定理 $\sum_{p\le x}1/p=\ln\ln x+O(1)$ 与收敛级数 $\sum_p\frac1{p(p-1)}$）。若不想引用 Mertens，用初等界 $\Omega(i)\le\log_2 i$（每个素因子 $\ge2$）得 $\sum\Omega(i)\le N\log_2 N\approx2\times10^7$，同样远低于时限。询问只做一次数组访问。空间：`f`、`spf`、`pr` 三个长 $10^6+5$ 的 `int` 数组 $\approx12$ MB。证毕。

---

### 引理 5（值域、有限性与边界）

$f[1]=0$；对所有 $i$，$f[i]\le i-1$（恒有限，无需 INF）；更紧地 $f[i]\le2\lfloor\log_2 i\rfloor+1\le41$。

*证明*：$f[1]=0$：已是目标。有限性：`f[i]=f[i-1]+1` 保底，归纳得 $f[i]\le i-1$；组合解释是"连减 $i-1$ 次"总可行，故**不存在不可达状态**，本题不需要 INF 哨兵。紧界：采用策略"偶数除以 $2$（$1$ 步）；奇数减 $1$ 再除以 $2$（$2$ 步）"，每轮至多 $2$ 步且数值至少减半（奇数 $x\to(x-1)/2<x/2$），$\lfloor\log_2 i\rfloor$ 轮后 $\le i/2^{\lfloor\log_2 i\rfloor}<2$ 即到达 $1$，故 $f[i]\le2\lfloor\log_2 i\rfloor\le2\times19=38$（$i\le10^6<2^{20}$），$+1$ 松弛写 $41$ 亦安全。`int` 足够。$n=1$ 输出 $0$ ✓。证毕。

---

### 定理

程序对每个询问 $n$ 输出把 $n$ 变成 $1$ 的最少能量 $f[n]$；预处理 $O(N\log N)$，单问 $O(1)$。

*证明*：引理 2 保证 $\mathrm{spf}$ 正确；引理 3 保证 DP 枚举的松弛集合恰为 $\{i/p:p\mid i\text{ 素}\}$ 且依赖就绪，从而 $f$ 表满足引理 1 的最优子结构递推，即 $f[n]$ 为最少操作数；引理 5 保证值域与 $n=1$ 边界；引理 4 给出复杂度。EOF 驱动循环对每组数据独立输出，互不干扰（$f$ 表只读）。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 两种操作都严格减小数值 ⇒ 状态依赖天然无环，最优子结构直接可写。
- **consider easier version** — 手算 $f[1..10]$：$f[\text{素数}]=1$、$f[8]=2$（经 $7$），看清"好状态"结构。
- **classic problem solution** — 试贪心"除最大素因子"，$n=8$ 反例（$8\to7\to1$ 优于 $8\to4\to2\to1$）否决，转向 DP。
- **classic problem solution** — 递推 $f[i]=1+\min(f[i-1],\min_{p\mid i}f[i/p])$，依赖全 $<i$，正推一遍。
- **classic problem solution** — 线性筛最小素因子 $\mathrm{spf}$：每个合数恰被最小素因子筛一次，$O(N)$。
- **reduce to easier problem** — 沿 $\mathrm{spf}$ 链剥素数幂枚举互异素因子，把"分解每个 $i$"的总代价压到 $\sum\Omega(i)=O(N\log\log N)$。
- **discuss by category** — 多组数据：预处理一次 + $O(1)$ 回答；$n=1$ 边界；全状态可达故无需 INF（与"不可达必填 INF"惯例的适用条件对照）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `mxn` | $10^6+5$ | `constexpr int{1000005}` | +5 松弛 |
| `f[i]` | $i\to1$ 的最少操作数 | `int[mxn]`，`f[1]=0` | 全局默认 $0$ 恰好只对 $i=1$ 正确，其余全部正推覆盖 |
| `spf[i]` | $i$ 的最小素因子（素数处 $=i$） | `int[mxn]`，$0$ 表示未筛 | 线性筛填充 |
| `pr[cnt]` | 升序素数表 | `int[mxn]`，`cnt=0` | $\pi(10^6)=78498$，开 `mxn` 富余 |
| `x,p` | 剥因子游标 / 当前素因子 | `int`，每个 $i$ 现算 | `x` 每轮至少减半 |
| `n` | 当前询问 | `int` | EOF 驱动 `while(cin>>n)` |

### 算法步骤

1. I/O 加速三行。
2. 线性筛：`i=2..mxn-1`，`spf[i]==0` 则 `spf[i]=i,pr[cnt++]=i`；内层枚举 `pr[j]` 至 `i*pr[j]>=mxn`，标记 `spf[i*pr[j]]=pr[j]`，`i%pr[j]==0` 则 `break`（乘积用 `i64` 防溢出）。
3. 正推 DP：`f[1]=0`；`i=2..mxn-1`：`f[i]=f[i-1]+1`；`x=i`，当 `x>1`：`p=spf[x]`，`f[i]=min(f[i],f[i/p]+1)`，剥尽 `x` 中 `p` 的幂。
4. `while(cin>>n)` 输出 `f[n]`。

### 复杂度

- 时间：预处理 $O(N\log N)$ 宽松界（精细 $O(N\log\log N)$，$N=10^6$），单问 $O(1)$。
- 空间：$O(N)$，三个 `int` 数组约 $12$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$f[1..30]$ 与手算全表逐项一致；$f[97]=f[7919]=f[999983]=1$（素数）；$f[10^6]=3$ 与手工路径 $10^6\xrightarrow{\div5}2\times10^5\xrightarrow{-1}199999\xrightarrow{\div199999}1$ 及"两步不可能"论证吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2618 数字工程
// 思路：两种操作都严格减小 n ⇒ 最优子结构：f[i]=1+min(f[i-1], min_{p|i} f[i/p])。
//       线性筛预处理最小质因子 spf，正推 f[2..1e6]；对每个 i 沿 spf 链枚举互异质因子。
//       多组数据（EOF 驱动）：预处理一次，每问 O(1)。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1000005};

int f[mxn],spf[mxn],pr[mxn],cnt;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	// 线性筛：spf[x] = x 的最小质因子（质数处 spf[p]=p）
	for(int i=2;i<mxn;++i)
	{
		if(!spf[i])
			spf[i]=i,pr[cnt++]=i;
		for(int j=0;j<cnt&&(i64)i*pr[j]<mxn;++j)
		{
			spf[i*pr[j]]=pr[j];
			if(i%pr[j]==0)
				break;			// 保证每个合数只被最小质因子筛一次
		}
	}
	f[1]=0;
	for(int i=2;i<mxn;++i)
	{
		f[i]=f[i-1]+1;			// 操作 1：减 1
		for(int x=i;x>1;)
		{
			int p=spf[x];
			f[i]=min(f[i],f[i/p]+1);	// 操作 2：除以质因子 p，i/p<i 已算好
			for(;x%p==0;x/=p);		// 剥掉 p 的幂，只枚举互异质因子
		}
	}
	int n;
	while(cin>>n)
		cout<<f[n]<<'\n';
	return 0;
}
```

### 代码说明

- **`(i64)i*pr[j]` 先转型再乘**：$i$ 与 $pr[j]$ 都可接近 $10^6$，`int` 乘积可达 $10^{12}$ 必溢出；转型后比较安全，而真正执行标记时 $i\cdot pr[j]<10^6$ 回落 `int` 下标无虞。
- **`break` 位置**：先标记再判 `i%pr[j]==0`，保证 $pr[j]=\mathrm{spf}[i]$ 这一次标记不被跳过——这是线性筛"每个合数恰筛一次"的关键（引理 2）。
- **剥幂循环 `for(;x%p==0;x/=p);`**：$x$ 减到 $1$ 时 $1\bmod p=1\ne0$ 自动停；外层 `x>1` 保证不访问 `spf[1]`。
- **不需要 INF**：`f[i]=f[i-1]+1` 是永远可行的保底（连减链），所有状态可达；全局默认 $0$ 只对 `f[1]` 正确，其余格子都在使用前被正推覆盖。
- **预处理上界写死 `mxn`**：询问个数未知，一次筛满 $10^6$ 比"读全询问再按最大值筛"更简单，代价仅几十毫秒。
- EOF 驱动 `while(cin>>n)`：题面"本题有多组数据"且未给组数，按读到文件尾处理。
