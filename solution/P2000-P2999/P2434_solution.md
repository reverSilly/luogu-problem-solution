# P2434 [SDOI2005] 区间 — 题解

## 一、解题过程：人类思考叙事

题目重述：给 $n$ 个**闭区间** $[a_i,b_i]$（$3\le n\le5\times10^4$，$1\le a_i\le b_i\le10^6$）。它们的并集可以写成若干个**互不相交**的闭区间之并，要求写出**区间个数最少**的那种表示，并按升序输出（升序的定义是 $a\le b<c\le d$，注意中间是**严格**小于）。

**第一反应：答案就是"并集的连通块"。** 把区间画在数轴上，重叠或首尾相接的会粘成一段，中间有空隙的就断开。每一段极大连续区间就是一个连通块，把它们输出即可。直觉上这既最少又唯一。但"直觉"不够，得先想清楚怎么算，再证它确实最少。

**尝试一：涂数轴。** 值域只有 $10^6$，开一个 `bool cov[1000001]`，把每个区间覆盖的位置涂黑，再从左到右扫描极大连续黑段，每段输出一个区间。朴素涂色是 $O(\sum(b_i-a_i+1))$，最坏 $5\times10^4\times10^6=5\times10^{10}$，超时；改用**差分数组** `diff[a]++, diff[b+1]--` 再前缀和，就是 $O(n+V)$，$V=10^6$，完全可行。看起来问题已经解决了。

**然后撞上一个致命反例。** 取 $[1,2]$ 与 $[3,4]$。按整点涂色，$1,2,3,4$ 全黑且连续，扫出一个段 $[1,4]$，于是输出一个区间。可是 $[1,2]\cup[3,4]$ 作为**实数集合**并不等于 $[1,4]$——中间的 $(2,3)$ 是空的！题目要求输出的并**恰好等于**原并集，$[1,4]$ 多覆盖了 $(2,3)$，是错的。再看题面给的升序定义 $a\le b<c\le d$：$[1,2]$ 与 $[3,4]$ 满足 $2<3$，本来就是两个合法的、应当分开输出的区间。**整点涂色把"相邻但不相交"误判成了"相交"。**

**修正：双倍坐标。** 错误的根源是"整点 $2$ 与整点 $3$ 之间没有缝隙"。把每个区间 $[a,b]$ 映射成整点段 $[2a,2b]$，则 $[1,2]\to[2,4]$、$[3,4]\to[6,8]$，中间的 $5$ 没被涂黑，扫描时自然断开；而 $[1,2]$ 与 $[2,3]$ 映射成 $[2,4]$ 与 $[4,6]$，在 $4$ 处相接，仍然合并。这样"整点连续段"就与"实数闭区间的连通块"一一对应了。差分改成 `diff[2a]++, diff[2b+1]--`，值域翻倍到 $2\times10^6$，依旧 $O(n+V)$。

**再退一步：其实根本不需要数轴。** 涂色法依赖值域 $V$，而本题真正的结构只有 $n$ 个区间。把区间**按左端点排序**，从左到右扫描，维护当前连通块 $[L,R]$：

- 若下一个区间的左端点 $a\le R$，说明它与当前块**有公共点**（闭区间！$a=R$ 时恰好共享端点 $R$），并入，$R\leftarrow\max(R,b)$；
- 若 $a>R$，说明中间有空隙，当前块结束，输出 $[L,R]$，另起新块。

这就是经典的**区间合并**模板，$O(n\log n)$，与值域无关，也不用开 $2\times10^6$ 的数组。排序保证输出的块天然升序。

**关键边界：相接到底并不并？** 并。因为闭区间 $[1,2]$ 与 $[2,3]$ 共享点 $2$，并集是 $[1,3]$，是一个连通块。判据必须是 $a\le R$（**带等号**），写成 $a<R$ 就会把相接的两段错误拆开。反过来 $[1,2]$ 与 $[3,4]$ 满足 $3>2$，必须拆开，判据的等号方向恰好把这两种情况分清。

**最后证"最少"。** 任何合法表示里的每个区间都是连通的，故只能落在某一个连通块内；而每个连通块又必须被覆盖，所以至少需要"连通块个数"个区间。另一方面连通块本身就是合法表示，个数恰好等于连通块数。故最少 = 连通块数，且表示唯一（一个闭区间不能拆成两个以上互不相交的非空闭区间之并，否则中间会留缝）。扫描法算出的正是连通块，得证。

自造样例验证（题面无样例）：
```
5
1 3
2 6
8 10
15 18
17 20
```
排序后扫描：$[1,3]$ 与 $[2,6]$ 相接（$2\le3$）并成 $[1,6]$；$8>6$ 断开输出 $[1,6]$，新块 $[8,10]$；$15>10$ 断开输出 $[8,10]$，新块 $[15,18]$；$17\le18$ 并成 $[15,20]$；结束输出 $[15,20]$。共 $3$ 行，与"涂双倍坐标"暴力一致。再造相接例 $[1,2],[2,3],[3,4]\to[1,4]$（一行）、相离例 $[1,2],[3,4],[5,6]\to$ 三行，均正确。

## 二、思维链：完整证明

记 $U=\bigcup_{i=1}^n[a_i,b_i]\subseteq\mathbb R$。

### 引理 1（两个闭区间相交的判据）

设 $[a,b],[c,d]$ 为闭区间且 $a\le c$。则 $[a,b]\cap[c,d]\ne\varnothing\iff c\le b$。

*证明*：
- ($\Leftarrow$) 若 $c\le b$，则 $a\le c\le b$ 且 $c\le d$，故 $c\in[a,b]$ 且 $c\in[c,d]$，交集非空。
- ($\Rightarrow$) 若 $c>b$，则 $[a,b]$ 中每点 $\le b<c\le$ $[c,d]$ 中每点，两集合无公共元素，交集为空。逆否即得：交集非空 $\Rightarrow c\le b$。

证毕。

> 这条引理说明合并判据必须带等号：$c=b$ 时两区间共享端点 $b$，仍相交。

### 引理 2（排序后扫描的不变量）

把区间按 $(a,b)$ 字典序排序得 $[a_1,b_1],\dots,[a_n,b_n]$（$a_1\le a_2\le\dots$）。扫描维护当前块 $[L,R]$，初值 $L=a_1,R=b_1$；对 $i=2..n$：若 $a_i\le R$ 则 $R\leftarrow\max(R,b_i)$，否则输出 $[L,R]$ 并令 $L=a_i,R=b_i$。则**每次输出时**，$[L,R]$ 恰是已处理区间中"包含第 $1$ 个未输出区间的那一极大相交链"的并，且 $L=\min a$、$R=\max b$（对该链而言）。

*证明*：对扫描过程归纳。

**不变量**：在处理第 $i$ 个区间之前，当前块 $[L,R]$ 等于某个下标集合 $G=\{j_1<\dots<j_k\}$（$j_k<i$）对应区间的并，且这些区间按左端点排序后**相邻两个都相交**（即 $a_{j_{t+1}}\le\max_{s\le t}b_{j_s}$），并且 $[L,R]=[\,a_{j_1},\max_t b_{j_t}\,]$ 是一个闭区间（连通）。

- **初始**：$G=\{1\}$，$[L,R]=[a_1,b_1]$，显然成立。
- **并入**（$a_i\le R$）：由引理 1，$[a_i,b_i]$ 与 $[L,R]$ 相交（因 $a_i\le R$ 且 $a_i\ge L$——排序保证 $a_i\ge a_{j_1}=L$）。两个相交闭区间之并仍是闭区间 $[\min(L,a_i),\max(R,b_i)]=[L,\max(R,b_i)]$（$a_i\ge L$）。故新块仍连通，$G$ 加入 $i$ 后相邻仍相交，不变量保持。
- **断开**（$a_i>R$）：由引理 1，$[a_i,b_i]$ 与 $[L,R]$ 不相交；又因排序，后续所有 $a_j\ge a_i>R$，故后续区间都不与 $[L,R]$ 相交。所以 $[L,R]$ 已经是一个**极大**连通块，输出它正确。新块从 $i$ 重新开始，不变量保持。

扫描结束时最后一个块同样极大（没有后续区间），输出。证毕。

### 引理 3（扫描结果 = 并集的连通分量）

引理 2 输出的所有闭区间，恰是 $U$ 的全部连通分量（极大 connected 子集），且互不相交、按升序排列。

*证明*：
- **每个输出块 $\subseteq U$ 且连通**：由引理 2，块是若干原区间之并，且这些区间两两链式相交，故并是连通闭区间，$\subseteq U$。
- **极大性**：由引理 2 的"断开"论证，块外的任何原区间都不与该块相交，故不存在更大的连通子集包含它。所以它是连通分量。
- **覆盖**：每个原区间都被并入某个块（扫描不遗漏），故所有块之并 $=U$。
- **互不相交**：不同块之间由"断开"条件 $a_i>R$ 保证有空隙，故不相交。
- **升序**：按左端点排序扫描，块的左端点递增；又互不相交，故前块右端点 $<$ 后块左端点，满足题面 $a\le b<c\le d$。

证毕。

### 引理 4（最少区间数 = 连通分量数）

设 $U$ 有 $k$ 个连通分量。则任何"互不相交闭区间之并 $=U$"的表示至少含 $k$ 个区间；且存在恰含 $k$ 个的表示（即分量本身）。故最少为 $k$。

*证明*：
- **下界**：设表示为 $U=\bigcup_{j=1}^m I_j$，$I_j$ 为互不相交的非空闭区间。每个 $I_j$ 连通，故含于 $U$ 的某一个连通分量（连通子集必落在唯一分量内）。每个分量 $C$ 非空，须被某些 $I_j$ 覆盖；而覆盖 $C$ 的 $I_j$ 都 $\subseteq C$，故至少有一个 $I_j$ 落在 $C$ 内。不同分量内的 $I_j$ 互不相同，所以 $m\ge k$。
- **可达**：由引理 3，$k$ 个分量本身就是互不相交闭区间且并为 $U$，故 $m=k$ 可达。

综上最少为 $k$。证毕。

### 引理 5（最少表示唯一，且就是分量）

含 $k$ 个区间的合法表示唯一，即 $U$ 的 $k$ 个连通分量。

*证明*：设 $U=\bigcup_{j=1}^k I_j$ 是含 $k$ 个区间的合法表示。由引理 4 的下界论证，每个分量恰含一个 $I_j$（否则某分量含 $\ge2$ 个，另一分量含 $0$ 个，与"每分量至少一个"矛盾）。设分量 $C=[L,R]$，含它的 $I_j=[c,d]\subseteq C$ 且 $C\subseteq I_j$（因 $I_j$ 要覆盖整个 $C$，而 $C$ 内只有这一个 $I_j$）。故 $[c,d]=[L,R]=C$。所以每个 $I_j$ 恰等于一个分量，表示唯一。

**补充：一个闭区间不能拆成 $\ge2$ 个互不相交非空闭区间之并。** 设 $[L,R]=\bigcup_{t=1}^m J_t$，$m\ge2$，$J_t$ 互不相交非空闭区间。按左端点排序 $J_1=[c_1,d_1],J_2=[c_2,d_2],\dots$，互不相交 $\Rightarrow d_1<c_2$。取 $x=(d_1+c_2)/2$，则 $L\le d_1<x<c_2\le R$，故 $x\in[L,R]$，但 $x\notin J_1$（$x>d_1$）且 $x\notin J_2$（$x<c_2$），也不在更后的 $J_t$（左端点 $\ge c_2>x$）。矛盾。故 $m=1$。这保证了"分量不可再拆"，与引理 4 的下界一致。证毕。

### 引理 6（边界：相接 vs 相离）

- $[1,2]$ 与 $[2,3]$：$2\le2$，由引理 1 相交，并为 $[1,3]$，**合并**。
- $[1,2]$ 与 $[3,4]$：$3>2$，由引理 1 不相交，**不合并**，输出两段。

*证明*：直接代入引理 1。前者共享点 $2$，后者中间有空隙 $(2,3)$。证毕。

> 这正是"整点涂色"会出错的地方：整点 $2,3$ 相邻无隙，但实数区间 $(2,3)$ 是空的。双倍坐标或排序扫描都能正确区分。

### 定理（算法正确性与复杂度）

排序 + 扫描合并（判据 $a_i\le R$）输出的区间列，是 $U$ 的连通分量，即最少且唯一的合法表示，按升序排列。时间 $O(n\log n)$，空间 $O(n)$。

*证明*：正确性由引理 2、3、4、5、6 合起来即得。复杂度：排序 $O(n\log n)$，扫描 $O(n)$，合计 $O(n\log n)$；存 $n$ 个区间 $O(n)$。$n\le5\times10^4$，$n\log n\approx8\times10^5$，远小于时限。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 答案 = 并集的连通分量，先把它看成数轴上的"粘段"。
- consider easier version — 先想"涂数轴 + 扫连续段"，差分 $O(n+V)$ 似乎可行。
- explore its property — 反例 $[1,2],[3,4]$ 暴露整点涂色把"相邻不相交"误并；闭区间是实数集。
- reduce to easier problem — 双倍坐标 $[2a,2b]$ 修正涂色；再进一步发现排序扫描可完全摆脱值域。
- classic problem solution — 区间合并模板：按左端点排序，$a_i\le R$ 则并否则输出。
- classic problem solution — 连通分量 + "闭区间不可拆"证明最少且唯一。
- discuss by category — 端点相接（$a=R$，并）与严格相离（$a>R$，拆）的边界，判据必须带等号。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| `n` | 区间个数，$3\le n\le5\times10^4$ | `int`，读入 |
| `s[i].a, s[i].b` | 第 $i$ 个闭区间左右端点 | `struct seg`，读入 |
| `L, R` | 当前连通块的左右端点 | `int`，初值 `s[0].a, s[0].b` |
| `mxn` | 数组尺寸 $50000+5$ | `constexpr int{50005}` |

本题无需求无穷大，哨兵 `1145141919` 不使用；无多测，无需清空。

### 算法步骤

1. 读入 $n$ 与 $n$ 个区间存进 `s`。
2. 按 $(a,b)$ 字典序排序 `s`。
3. 令 `L=s[0].a, R=s[0].b`。
4. 对 $i=1..n-1$：
   - 若 `s[i].a<=R`：`R=max(R,s[i].b)`（并入当前块）；
   - 否则：输出 `L R`，令 `L=s[i].a, R=s[i].b`（断开，新块）。
5. 输出最后一块 `L R`。

### 复杂度

- 时间：$O(n\log n)$（排序主导）。
- 空间：$O(n)$。

### 验证状态

编译通过；自造样例 `1 3 / 2 6 / 8 10 / 15 18 / 17 20` 输出 `1 6 / 8 10 / 15 20`，与双倍坐标暴力一致；相接例 $[1,2],[2,3],[3,4]\to[1,4]$、相离例 $[1,2],[3,4],[5,6]\to$ 三行均正确；对拍 $1406$ 组（$400$ 组随机 + $1000$ 组 $n=3$ 坐标 $\le4$ 全穷举 + $6$ 组边界）全部一致；$n=5\times10^4$ 极限数据运行约 $0.09$ 秒。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2434 [SDOI2005] 区间
// 闭区间并的最少不相交表示 = 连通分量；排序后扫描合并，判据 a<=R（带等号）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005};

int n;
struct seg{int a,b;}s[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>s[i].a>>s[i].b;
	sort(s,s+n,[](seg x,seg y){return x.a!=y.a?x.a<y.a:x.b<y.b;});
	int L=s[0].a,R=s[0].b;
	for(int i=1;i<n;++i)
	{
		if(s[i].a<=R)			// 闭区间：端点相接也算相交，必须带等号
			R=max(R,s[i].b);
		else
		{
			cout<<L<<' '<<R<<'\n';
			L=s[i].a;R=s[i].b;
		}
	}
	cout<<L<<' '<<R<<'\n';
	return 0;
}
```

### 代码说明

- **判据 `s[i].a<=R` 的等号是本题灵魂**：闭区间端点相接（如 $[1,2]$ 与 $[2,3]$）共享端点，必须合并；写成 `<` 会错误拆开。而 $[1,2]$ 与 $[3,4]$ 因 $3>2$ 自然断开，不会误并。
- 排序用 $(a,b)$ 字典序，保证扫描时左端点不减，输出天然升序，满足题面 $a\le b<c\le d$。
- `R=max(R,s[i].b)` 处理"包含"情形（如 $[1,10]$ 与 $[2,3]$），右端点取较大者。
- 循环结束后**必须再输出最后一块**，否则漏掉末尾区间。
- 全局数组 `s[mxn]`，`mxn=50005` 为 $n\le50000$ 的 $+5$ 松弛；无多测，无需清空。
- 换行用 `'\n'`，I/O 三行按规范顺序。
