# P2721 小 Q 的赚钱计划 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 年初（非闰年，共 $365$ 天）小 Q 有 $10^5$ 元。有 $N$ 个理财产品（$0\le N\le 10^4$），每个产品三个参数：发行/购买日期 $A$（格式 `MMDD`）、投资天数 $B\in[10,300]$、年利息率 $C\in[3,30]$（百分之几，最多 $2$ 位小数）。**每个时刻最多持有一件产品**。求一年后最多能拿到多少钱，保留两位小数。

**第一步：先把"钱什么时候变"搞清楚。** 现金只在两个时刻变化：买入产品时现金变成产品（锁定），产品到期时连本带利变回现金。持有期间现金不动，闲置期间现金也不动（题面没有给活期利息）。所以整条时间轴上，"现金"是一个**分段常数、只在到期日跳增**的量。这提示我按"天"做 DP：只要知道每个时刻手里最多有多少现金，就能往后推。

**第二步：一个必须先定的建模问题——能不能只投一部分钱？** 题面只说"最多持有一件产品"，没说必须全仓。但利息是本金的**线性正比例**函数（利率 $>0$），闲钱又不生息，所以"同一套购买时间表下，每次把全部可用现金投进去"一定不劣：投 $P\le \text{cash}$ 元，到期拿回 $P\cdot\text{factor}$，加上没投的 $\text{cash}-P$，总共 $\text{cash}+P(\text{factor}-1)\le \text{cash}\cdot\text{factor}$（因为 $\text{factor}>1$）。全仓永远 $\ge$ 部分仓，而且现金更多只会让后续选择更宽。于是**只需记录"每个时刻的最大现金"一个数**，不必记"现金+产品市值"两个量。这一步把状态压成了一维。

**第三步：把日期翻译成时间轴上的点。** 非闰年每月天数 `31,28,31,30,31,30,31,31,30,31,30,31`。我建立一条 $0..365$ 的时间轴：时刻 $t$ 表示"第 $t+1$ 天的清晨"，于是 $t=0$ 是 1 月 1 日清晨（年初），$t=365$ 是 12 月 31 日结束（年底）。发行日 `MMDD` 先算出它是当年第几天 $\text{doy}$（用月份前缀和），再令 $s=\text{doy}-1$，就是它在时间轴上的起点。

**第四步：产品占多长、利息多少。** 投资 $B$ 天，从第 $s$ 天清晨开始，占用 $B$ 个整天，即半开区间 $[s,\,s+B)$，在时刻 $s+B$ 到期。年利息率 $C\%$ 按"实际天数/365"单利计息，$B$ 天的利息是 $\text{本金}\times\frac{C}{100}\times\frac{B}{365}$，所以到期因子是
$$\text{factor}=1+\frac{C\cdot B}{36500}.$$
为了避开浮点解析噪声，我把 $C$ 读成字符串、化成"百分之几的 $100$ 倍"的整数 $c$（例如 $3.65\%\to c=365$），于是 $\text{factor}=1+\frac{c\cdot B}{3650000}$，分子分母都是整数，只在最后除一次。

**第五步：为什么是半开区间、为什么到期当天能再买。** "每个时刻最多一件"意味着两件产品的时间区间不能相交。产品甲占 $[s,s+B)$，产品乙若恰在 $s+B$ 发行，占 $[s+B,\dots)$，两者**端点相接但内部不交**，任何时刻都不冲突——所以到期当天可以立刻买入下一件。这正是"复利滚存"能成立的关键。反过来，若把区间写成闭区间 $[s,s+B]$，就会凭空多占一天、禁止当天续买，与"投资 $B$ 天"的字面不符。年底截断同理：产品必须在 $s+B\le 365$ 时到期，钱才能在年底前拿回；$s+B>365$ 的产品等于把钱锁到明年，对"年底现金"毫无贡献，直接忽略（不买它、让钱闲置即可，严格不劣）。

**第六步：写出 DP。** 设 $f[t]$ 为时刻 $t$ 手里最多的现金。$f[0]=10^5$。两类转移：
- **闲置**：$f[t]=\max(f[t],\,f[t-1])$（今天什么都不买，把昨天的钱带过来）；
- **产品**：对每个起点为 $t$、天数 $b$、利率整数 $c$ 的产品，若 $t+b\le 365$，则 $f[t+b]=\max\bigl(f[t+b],\,f[t]\cdot(1+\frac{cb}{3650000})\bigr)$。

因为 $b\ge 10>0$，产品转移永远指向未来，按 $t$ 从小到大扫一遍即可，无后效。答案就是 $f[365]$。

**第七步：精度与范围。** 一年最多滚 $\lfloor 365/10\rfloor=36$ 次，每次因子 $\le 1+\frac{30\times 300}{36500}\approx 1.247$，但短周期复利的实际上限是连续复利 $e^{0.3}\approx 1.35$，所以答案 $\le 1.35\times 10^5$。`double` 在 $10^5$ 量级的 ulp 约 $10^{-11}$，$36$ 次乘法累积相对误差 $\le 36\times 2^{-53}\approx 4\times 10^{-15}$，绝对误差 $\le 10^{-9}$，远小于 $0.005$ 的进位阈值——`double` 足够，不必上定点。我用 BigInt 精确算过 $36$ 连滚的极限值，与 `double` 输出逐位一致。

**手造数据核对**（题面无样例，下面都是我按规则手算、再用程序核对的）：

| 输入 | 手算 | 输出 |

## 二、思维链：完整证明

**记号。** 时间轴 $T=\{0,1,\dots,365\}$，时刻 $t$ 表示第 $t+1$ 天清晨，$t=365$ 为年底。产品 $i$ 有起点 $s_i\in[0,364]$、天数 $b_i\in[10,300]$、利率整数 $c_i\in[300,3000]$（$c_i=100\times C_i$，$C_i$ 是百分之几）。到期因子 $\varphi_i=1+\frac{c_i b_i}{3650000}>1$。一个**策略**是若干产品的购买序列，满足任意时刻至多持有一件；现金按"买入锁定、到期连本带利收回"演化。$f[t]$ 定义为时刻 $t$ 的最大现金。

---

### 引理 1（全仓不劣：状态可压成一维现金）

存在一个最优策略，每次买入都把当时全部可用现金投入。因此只需记录每个时刻的最大现金 $f[t]$，无需记录"现金 + 产品市值"。

*证明*：任取一个策略 $\sigma$（允许部分仓），构造 $\sigma'$：购买时间表与 $\sigma$ 完全相同，但每次买入投入全部可用现金。对时间归纳证明 $\sigma'$ 在每个时刻的现金 $\ge\sigma$。

设某次买入发生在时刻 $s$，买入前两者现金分别为 $X'\ge X$（归纳假设）。$\sigma$ 投入 $P\le X$，$\sigma'$ 投入 $X'$。该产品在 $s+b$ 到期，期间无其他事件（至多一件产品）。到期时：
$$\sigma:\ (X-P)+P\varphi=X+P(\varphi-1),\qquad \sigma':\ X'\varphi.$$
由 $\varphi>1$、$P\le X\le X'$，得 $X+P(\varphi-1)\le X+X(\varphi-1)=X\varphi\le X'\varphi$。故到期后 $\sigma'$ 现金仍 $\ge\sigma$。闲置区间现金不变，不等式保持。归纳到年底，$\sigma'$ 的年底现金 $\ge\sigma$。所以最优值必可由某个全仓策略达到，状态只需一维现金。证毕。

**注**：部分仓并不能换来"同时多持产品"（件数上限与金额无关），故全仓没有任何副作用。

---

### 引理 2（日期 ↔ 时间点的 bijection）

设月份天数 $d_1..d_{12}$（非闰年），前缀和 $P_m=\sum_{j<m}d_j$（$P_1=0$）。合法日期 `MMDD`（月 $m$、日 $a$，$1\le a\le d_m$）对应当年第 $\text{doy}=P_m+a$ 天，时间点 $s=\text{doy}-1=P_m+a-1$。该映射是合法日期集合到 $\{0,\dots,364\}$ 的双射。

*证明*：非闰年 $\sum d_j=365$。对固定 $m$，$a$ 取遍 $1..d_m$ 时 $\text{doy}$ 取遍 $P_m+1..P_m+d_m=P_{m+1}$，相邻月份首尾相接（$P_{m+1}$ 恰是下一月起点的前一天），故 $\text{doy}$ 取遍 $1..365$ 且不重不漏。减 $1$ 后 $s$ 取遍 $0..364$。代码用 `pre[mo-1]+da-1` 计算，与 $P_m+a-1$ 一致。证毕。

---

### 引理 3（到期因子的精确表达）

产品 $i$ 投入本金 $X$，$b_i$ 天后连本带利为 $X\varphi_i$，其中 $\varphi_i=1+\frac{c_i b_i}{3650000}$，$c_i$ 是"年利率百分数 $\times100$"的整数。

*证明*：年利率为 $C_i\%=\frac{C_i}{100}=\frac{c_i}{10000}$（小数）。按实际天数/365 单利，$b_i$ 天利息 $=X\cdot\frac{c_i}{10000}\cdot\frac{b_i}{365}=X\cdot\frac{c_i b_i}{3650000}$。本利和 $=X+X\cdot\frac{c_i b_i}{3650000}=X\varphi_i$。把 $C_i$ 解析成整数 $c_i$（整数部分 $\times100$ 加小数部分右补零至 $2$ 位）是精确的十进制放大，无舍入；唯一的浮点运算是最后一次除法，误差见引理 8。证毕。

---

### 引理 4（策略 = 不交半开区间；年底现金 = 本金 × 因子积；越界产品可删）

(a) 全仓策略等价于选取若干产品，其占用区间 $[s_i,s_i+b_i)$ 两两不交且都含于 $[0,365)$；年底现金 $=10^5\prod\varphi_i$（按时间顺序）。
(b) 任何用到 $s_i+b_i>365$ 产品的策略，删去该产品（改为闲置）后年底现金不减。故可只考虑 $s_i+b_i\le 365$ 的产品。

*证明*：(a) 全仓时，买入把全部现金锁进产品，到期收回，故两件产品的时间区间不能相交（否则某时刻持有两件，违反约束）；半开区间端点相接不算相交（引理见第五步叙事）。现金演化：年初 $10^5$，每经过一件产品乘 $\varphi_i$，闲置不改变，故年底现金 $=10^5\prod\varphi_i$。反之任何两两不交、含于 $[0,365)$ 的区间组，按起点顺序购买即构成合法全仓策略。

(b) 设策略用了产品 $i$ 且 $s_i+b_i>365$。它在年底尚未到期，对年底现金的贡献是 $0$（钱被锁住）；又因区间不交，任何后续产品起点 $\ge s_i+b_i>365$，也在年底之外，同样无贡献。删去 $i$ 及其后所有产品、改为闲置，年底现金 $=$ 买入 $i$ 之前的现金 $\ge$ 原策略年底现金（原策略年底现金正是这笔被锁住的本金，闲置则原样保留）。故删去不劣。证毕。

---

### 引理 5（DP 转移的正确性，双向夹逼）

$f[0]=10^5$；对 $t\ge 1$，
$$f[t]=\max\Bigl(f[t-1],\ \max_{i:\,s_i+b_i=t} f[s_i]\varphi_i\Bigr).$$

*证明*：由引理 1、4，$f[t]$ 是"限制在 $[0,t]$ 内的全仓策略"在时刻 $t$ 的最大现金。

**（$\ge$，构造可达）**
- 闲置：取达到 $f[t-1]$ 的策略，在 $[t-1,t)$ 不持产品，现金原样带到 $t$，得 $f[t-1]$。
- 产品：对任一 $s_i+b_i=t$，取达到 $f[s_i]$ 的策略（其所有区间含于 $[0,s_i]$），在 $s_i$ 买入产品 $i$，占 $[s_i,t)$，与之前区间不交，时刻 $t$ 到期得 $f[s_i]\varphi_i$。
两者都合法，故 $f[t]\ge$ 右端。

**（$\le$，最优子结构）** 取达到 $f[t]$ 的策略 $\sigma$。看时刻 $t$ 是否有产品到期：
- **有**（至多一件，设为 $i$，$s_i+b_i=t$）：$\sigma$ 在 $s_i$ 之前的部分是一个限制在 $[0,s_i]$ 的策略，其时刻 $s_i$ 现金 $\le f[s_i]$；产品 $i$ 把这笔现金乘 $\varphi_i$ 带到 $t$，故 $f[t]\le f[s_i]\varphi_i$。
- **无**：则 $[t-1,t)$ 内无到期事件，现金不变，$f[t]=\sigma$ 在 $t-1$ 的现金 $\le f[t-1]$。
两种情形都 $\le$ 右端。双向夹逼得等式。证毕。

---

### 引理 6（求值顺序合法、无后效）

按 $t=0,1,\dots,365$ 递增处理：先做闲置转移 $f[t]\gets\max(f[t],f[t-1])$，再对起点为 $t$ 的产品做前向转移。处理到 $t$ 时 $f[t]$ 已是最终值，且所有写入 $f[t]$ 的产品转移都已完成。

*证明*：产品转移从 $s$ 写入 $s+b$，$b\ge 10>0$ 故 $s+b>s$，是严格前向边。对 $t$ 归纳：处理 $t$ 之前，所有 $s<t$ 已处理，凡 $s+b=t$ 的产品都已把 $f[s]\varphi$ 写入 $f[t]$；而 $s\ge t$ 的产品只会写入 $>t$ 的位置，不会再改 $f[t]$。故此时 $f[t]$ 已集齐所有"到期于 $t$"的贡献，再与 $f[t-1]$（已 finalized）取 max 即得引理 5 的右端。依赖图是 DAG（边严格递增），递增序是合法拓扑序。证毕。

**实现对应**：代码把产品按起点桶排 `g[s]`，外层 `for t`，内层遍历 `g[t]`，正是上述顺序。

---

### 引理 7（答案 = $f[365]$；$0$ 初始化安全）

年底最大现金为 $f[365]$。数组 $f$ 除 $f[0]=10^5$ 外初值为 $0$ 不会导致错误。

*证明*：年底即时刻 $365$，由 $f$ 的定义答案就是 $f[365]$。

$0$ 初始化安全性：闲置转移形成链 $f[t]\ge f[t-1]\ge\dots\ge f[0]=10^5>0$，故每个 $f[t]$ 最终 $\ge 10^5$，初值 $0$ 永远会被闲置链或某个 $\ge 10^5$ 的产品贡献覆盖，不会作为最终值残留。即使某 $f[t]$ 暂无产品到期，闲置 max 也会把它抬到 $f[t-1]\ge 10^5$。故 $0$ 是安全的下界初值（本题所有状态都可达，不存在"不可达被误当 $0$"的陷阱）。证毕。

### 引理 8（精度与复杂度）

答案 $\le 1.35\times 10^5$；`double` 累积误差 $\le 10^{-9}$，远小于 $0.005$ 进位阈值，两位小数输出正确。时间 $O(N+365)$，空间 $O(N+365)$。

*证明*：范围：一年至多 $\lfloor 365/10\rfloor=36$ 件产品，每件 $\varphi\le 1+\frac{3000\times 300}{3650000}\approx 1.2466$；更紧地，短周期复利 $\bigl(1+\frac{0.3\,b}{365}\bigr)^{365/b}$ 关于 $b$ 递减，上确界为连续复利 $e^{0.3}\approx 1.3499$，故答案 $\le 1.35\times 10^5$。

精度：`double` 单位舍入 $u=2^{-53}\approx 1.11\times 10^{-16}$。至多 $36$ 次乘法，相对误差 $\le 36u\approx 4\times 10^{-15}$，绝对误差 $\le 1.35\times 10^5\times 4\times 10^{-15}\approx 5.4\times 10^{-10}<0.005$。除非真值恰落在半分钱边界 $5\times 10^{-3}$ 的 $10^{-9}$ 邻域内（测度极小，且单产品情形可证不可能：$\frac{2c b}{73}$ 的小数部分无法恰为 $0.005$，因 $400cb/73$ 为奇数要求 $200m\equiv-1\pmod{400}$ 无解），输出必正确。已用 BigInt 精确核算 $36$ 连滚极限值 $134269.80$，与 `double` 输出逐位一致。

复杂度：解析 $N$ 个产品 $O(N)$（利率串长 $\le 5$）；桶排 $O(N)$；DP 外层 $366$ 次、内层每个产品恰被遍历一次，共 $O(N+365)$。空间：$f$ 为 $366$ 个 `double`，桶 `g` 共存 $N$ 个 `pair`，$O(N+365)$。证毕。

---

### 定理

程序输出 $f[365]$，即年底最大现金的两位小数表示；时间 $O(N+365)$，空间 $O(N+365)$。

*证明*：引理 1 把状态压成一维现金；引理 2、3 保证日期与因子的精确翻译；引理 4 把策略刻画为不交半开区间并排除越界产品；引理 5 给出 DP 转移的双向正确性；引理 6 保证递增求值合法；引理 7 保证答案与初值；引理 8 保证精度与复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 现金只在到期日跳增、持有/闲置期间不变 ⇒ 按天做 DP，状态是"每个时刻的最大现金"。
- **reduce to easier problem** — 利息线性且为正、闲钱不生息 ⇒ 全仓不劣，状态从"现金+市值"压成一维现金。
- **explore its property** — 日期 `MMDD` 用月份前缀和映成 $0..364$ 的时间点；产品占半开区间 $[s,s+b)$，到期当天可续买。
- **discuss by category** — 年底截断：$s+b\le 365$ 才计入，越界产品锁钱到明年、直接忽略；$N=0$ 输出本金。
- **classic problem solution** — 时间轴上的加权区间调度 / DAG 最长路：闲置转移 $f[t]\gets\max(f[t],f[t-1])$ + 产品前向转移 $f[s+b]\gets\max(f[s+b],f[s]\varphi)$。
- **explore its property** — $b\ge 10>0$ ⇒ 转移严格前向，递增扫一遍即合法拓扑序，无后效。
- **discuss by category** — 利率化成整数百分之一避开解析噪声；估范围 $e^{0.3}$ 上界确认 `double` 精度足够，两位小数输出。

| `s` | 产品起点时间点 | `int` | `pre[mo-1]+da-1`，$0..364$ |
| `c` | 利率整数（百分之几 $\times100$） | `int` | $3.65\%\to365$；因子 $1+\frac{cb}{3650000}$ |
| `mxd` | $366$（时间点 $0..365$） | `constexpr int` | 时间轴尺寸 |

### 算法步骤

1. I/O 加速三行。
2. 预处理月份前缀和 `pre`。
3. 读 $N$；每个产品读 `A,b,C`：解析 `MMDD` 得 $s$；把 `C` 解析成整数 $c$（整数部分 $\times100$ + 小数右补零至 $2$ 位）；`g[s].push_back({b,c})`。
4. `f[0]=1e5`。
5. 外层 `t=0..365`：若 `t>0` 则 `f[t]=max(f[t],f[t-1])`（闲置）；遍历 `g[t]` 的每个 `(b,c)`，若 `t+b<=365` 则 `f[t+b]=max(f[t+b],f[t]*(1+c*b/3650000.0))`（产品）。
6. 输出 `fixed<<setprecision(2)<<f[365]`。

### 复杂度

- 时间：$O(N+365)$，$N\le 10^4$ 时约 $10^4$ 次解析 + $366$ 次扫描。
- 空间：$O(N+365)$，`f` 约 $3$ KB，桶共存 $N$ 个 `pair`。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译无警告；$7$ 组手造样例（无产品 / 单产品 / 到期续买链 / 年底恰好到期 / 越界忽略 / 重叠取舍 / 利率三种写法）全部与手算一致；$36$ 连滚极限值与 BigInt 精确核算逐位吻合（`134269.80`）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2721 小 Q 的赚钱计划
// 时间轴 0..365：t 表示第 t+1 天清晨（t=365 即年底）。
// 产品占用半开区间 [s,s+b)，s+b 时刻连本带利到账，因子 1+C*b/3650000。
// f[t]=t 时刻最多现金；闲钱向后传，产品向前跳。答案 f[365]。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxd{366};

int n,pre[13];
double f[mxd];
vector<pair<int,int>>g[mxd];	// g[s]：(投资天数 b, 年利率百分数×100 的整数 C)

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	constexpr int md[12]{31,28,31,30,31,30,31,31,30,31,30,31};
	for(int i=1;i<=12;++i)
		pre[i]=pre[i-1]+md[i-1];
	cin>>n;
	for(int i=0;i<n;++i)
	{
		string A,C;int b;
		cin>>A>>b>>C;
		int mo=(A[0]-'0')*10+(A[1]-'0'),da=(A[2]-'0')*10+(A[3]-'0');
		int s=pre[mo-1]+da-1;	// 发行日 MMDD → 0-based 时间点
		int c=0,j=0;
		for(;j<(int)C.size()&&C[j]!='.';++j)
			c=c*10+(C[j]-'0');
		c*=100;
		if(j<(int)C.size())	// 小数部分：右补零至 2 位，化成整数百分之一
		{
			++j;
			int fp=0,k=0;
			for(;j<(int)C.size()&&k<2;++j,++k)
				fp=fp*10+(C[j]-'0');
			for(;k<2;++k)
				fp*=10;
			c+=fp;
		}
		g[s].push_back({b,c});
	}
	f[0]=1e5;
	for(int t=0;t<=365;++t)
	{
		if(t)
			f[t]=max(f[t],f[t-1]);	// 闲钱：这一天什么都不买
		for(auto[b,c]:g[t])
			if(t+b<=365)	// 年底后才到期的产品等于把钱锁死，直接忽略
				f[t+b]=max(f[t+b],f[t]*(1+c*b/3650000.0));
	}
	cout<<fixed<<setprecision(2)<<f[365]<<'\n';
	return 0;
}
```

### 代码说明

- **半开区间 + 到期续买**：产品占 $[s,s+b)$，写入 `f[s+b]`；下一件若起点恰为 $s+b$ 就能接上，这是复利滚存的关键。若误写成闭区间会少滚一天。
- **年底截断 `t+b<=365`**：越界产品锁钱到明年，对年底现金无贡献，跳过即可（等价于"不买、闲置"，严格不劣）。
- **利率整数化**：`c` 是"百分之几 $\times100$"，因子 `1+c*b/3650000.0` 只在最后除一次，避免 `cin>>double` 的解析噪声；`3`/`3.5`/`30.00` 三种写法统一处理。
- **`f` 的 $0$ 初值安全**：闲置链保证 `f[t]>=f[0]=1e5`，$0$ 永远不会作为最终值残留（所有状态可达，无需填 INF）。
- **桶排 `g[s]`**：把产品按起点挂桶，DP 内层只遍历当天起点的产物，总复杂度 $O(N+365)$，不必每天扫全部 $N$ 个。
- 答案 `f[365]` 用 `fixed<<setprecision(2)` 输出两位小数；`double` 精度经 BigInt 核算足够（引理 8）。
