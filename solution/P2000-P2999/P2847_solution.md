# P2847 [USACO16DEC] Moocast G — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 平面上 $N$ 头奶牛（$N\le1000$），坐标为 $0..25000$ 的整数。花 $X$ 元给每头牛配一个传输半径 $\sqrt X$ 的对讲机：两头牛能直接通信 $\iff$ 它们的**平方距离** $\le X$。消息可以无限次中继。求最小的**整数** $X$，使任意一头牛发出的消息能到达所有牛。

**第一步：探索性质。** 三个观察立刻落地：

1. **不用开方。** 判定条件是 $(x_u-x_v)^2+(y_u-y_v)^2\le X$，全程整数运算，$\sqrt X$ 只是背景故事。坐标差 $\le25000$，平方距离最大 $2\times25000^2=1.25\times10^9$——这个数后面会惹祸，先记住它。
2. **单调性。** $X$ 增大只会增加边、不会删边，所以"图连通"关于 $X$ 单调：若 $X$ 可行则一切 $X'\ge X$ 可行。答案是一个阈值。
3. **"广播可达所有牛" = 无向图连通。** 边是双向的（平方距离对称），消息沿边任意走，从任何点出发能到所有点 $\iff$ 图连通。

**第二步：容易版本——固定 $X$ 判定。** 把平方距离 $\le X$ 的牛对连边，BFS/DFS 判连通，$O(N^2)$（完全图不用真的建边，BFS 时现算距离）。结合单调性，**二分答案**：在 $[0,1.25\times10^9]$ 上二分 $X$，约 $31$ 次判定，总 $O(N^2\log V)\approx3\times10^7$，能过。标签里的"二分"就是这条路。

**第三步：能不能去掉那个 $\log$？** 盯着"阈值"的结构看：$X$ 可行 $\iff$ 存在一棵生成树，其所有边权 $\le X$（连通图必有生成树；反过来生成树连通则图连通）。所以

$$\text{答案}=\min_{\text{生成树 }T}\ \max_{e\in T} w(e),$$

即**最小瓶颈生成树**的瓶颈值。而经典结论：**最小生成树（MST）就是最小瓶颈生成树**——MST 的最大边就是答案（引理 4 完整证明）。于是只需跑一遍 MST，取选中边权的最大值，二分整个被省掉。

**第四步：选 Prim 还是 Kruskal？** 图是隐式完全图，边数 $\binom{N}{2}\approx5\times10^5$。Kruskal 要显式生成、排序这 $5\times10^5$ 条边（$O(N^2\log N)$，内存约 $6$ MB 边数组）；**稠密图 Prim** 只需 `dis[]` 数组，每轮 $O(N)$ 选最小 + $O(N)$ 松弛，共 $O(N^2)=10^6$，不存一条边。$N\le1000$ 正是稠密 Prim 的教科书场景。选 Prim。

**第五步：撞墙——哨兵比真实边权还小。** 我习惯性写下 `constexpr int inf{1145141919}`，然后突然想起第一步记的那个数：最大平方距离 $1.25\times10^9=1250000000$，而 $1145141919\approx1.145\times10^9$ **比它小**！后果不是崩溃而是静默错解：松弛 `dis[v]=min(dis[v],d2(u,v))` 中，若真实边权 $1.25\times10^9>\texttt{inf}$，`min` 会保留 `inf`，真实的大边被哨兵"削顶"，答案输出 $1145141919$。最小反例：$N=2$，两点 $(0,0),(25000,25000)$，正确答案 $1250000000$，带病代码输出 $1145141919$。

修复：哨兵必须**严格大于一切可能的边权**。改用 `i64` 的 $1145141919810\approx1.145\times10^{12}$（仍是 114514 家族），`dis` 数组与答案都用 `i64`，余量近千倍。顺带把 `dis` 显式 `fill_n` 成 INF——全局默认 $0$ 会被 Prim 当成"零代价已连通"，第一轮就把所有点以 $0$ 费用选走，这是另一个静默错解坑。

**第六步：边界。** $N=1$：不需要任何边，答案 $0$。Prim 里 `dis[0]=0`，第一轮选中它，`ans=max(ans,0)=0`，自动正确。重合点距离 $0$，无影响。

**手造数据核对**（题面无样例）：

| 输入 | 手算 | 说明 |
|---|---|---|
| `3` / `(0,0),(3,0),(0,4)` | $16$ | 三边 $9,16,25$；MST 取 $9+16$，瓶颈 $16$。$X=15$ 时点 $(0,4)$ 孤立 |
| `1` / `(5,7)` | $0$ | 单点无边 |
| `2` / `(0,0),(25000,25000)` | $1250000000$ | 专打哨兵削顶的反例 |
| `4` / 单位正方形四顶点 | $1$ | 三条单位边即连通 |

## 二、思维链：完整证明

**记号。** 点集 $V=\{0,\dots,N-1\}$，边权 $w(u,v)=(x_u-x_v)^2+(y_u-y_v)^2\in\mathbb Z_{\ge0}$。$G_X$ 为保留 $w\le X$ 的边的图。$B^\*=\min_{T\text{ 生成树}}\max_{e\in T}w(e)$（$N=1$ 时定义 $B^\*=0$）。$\mathrm{ans}$ 为题目所求最小整数 $X$。

### 引理 1（连通性单调 + 答案 = 最小瓶颈）

$G_X$ 连通 $\iff X\ge B^\*$；故 $\mathrm{ans}=B^\*$，且 $B^\*$ 是某条边的权值（$N\ge2$ 时）或 $0$（$N=1$ 时）。

*证明*：单调性：$X\le X'$ 时 $G_X$ 的边集是 $G_{X'}$ 的子集，连通性只增不减。

($\Leftarrow$)：设 $X\ge B^\*$，取达到 $B^\*$ 的生成树 $T$，其每条边 $w\le B^\*\le X$，故 $T\subseteq G_X$，$G_X$ 含生成树从而连通。

($\Rightarrow$)：设 $G_X$ 连通。连通图必含生成树（反复删去环上的边，连通性保持，有限步后无环且连通），取 $G_X$ 的一棵生成树 $T$，其所有边 $\le X$，故 $B^\*\le\max_{e\in T}w(e)\le X$。

两方向得 $G_X$ 连通 $\iff X\ge B^\*$。最小可行整数 $X$ 即 $B^\*$（$B^\*$ 本身是整数：它是有限个整数边权的最大值的最小值）。$N\ge2$ 时生成树非空，$B^\*$ 是某边权；$N=1$ 时任何 $X\ge0$ 都连通（单点图连通），$\mathrm{ans}=0$。证毕。

### 引理 2（割性质：最小横跨边属于某棵 MST）

设 $(S,V\setminus S)$ 是任一非平凡划分，$e$ 是横跨该割的边中权值最小者（之一）。则存在一棵 MST 包含 $e$。

*证明*：取任一 MST $T$。若 $e\in T$ 完毕。否则把 $e=(u,v)$ 加入 $T$：树加一条边恰好产生一个环 $C$，且 $C$ 经过 $e$。$u\in S,v\notin S$（或反之），环 $C$ 从 $S$ 走到 $V\setminus S$ 再走回来，必含另一条横跨割的边 $f\ne e$。由 $e$ 的最小性 $w(f)\ge w(e)$。令 $T'=T+e-f$：删去环上一条边仍连通且边数 $N-1$，故 $T'$ 是生成树，且 $w(T')=w(T)+w(e)-w(f)\le w(T)$。$T$ 已是 MST（权和最小），故 $w(T')=w(T)$，$T'$ 也是 MST 且含 $e$。证毕。

### 引理 3（Prim 不变量：选出的是 MST）

稠密 Prim 维护已选集合 $S$（`vis`）与 `dis[v]`（$v\notin S$）。每轮选 `dis` 最小的未选点 $u$ 加入 $S$，并用 $w(u,\cdot)$ 松弛。则：(a) 每轮开始时 $\texttt{dis}[v]=\min_{s\in S}w(s,v)$（$S=\varnothing$ 时除起点外为 $+\infty$）；(b) 选中的边是割 $(S,V\setminus S)$ 的最小横跨边；(c) 算法结束时选中边集是一棵 MST，$\mathrm{ans}$ 等于其最大边权。

*证明*：(a) 对轮数归纳。初始 $S=\varnothing$：`dis[0]=0`（起点虚拟零边），其余 `fill_n` 为 INF，与"空集上取 min 为 $+\infty$"一致。设某轮开始时成立；选中 $u$ 后 $S'=S\cup\{u\}$，对每个 $v\notin S'$ 执行 $\texttt{dis}[v]\leftarrow\min(\texttt{dis}[v],w(u,v))$，恰好把 $\min_{s\in S}$ 更新成 $\min_{s\in S'}$；已选点不再被读。不变量保持。

(b) 由 (a)，`dis[u]` 是 $u$ 到 $S$ 的最小边权；选 `dis` 最小的 $u$，则边 $(s^\*,u)$（$s^\*\in S$ 取到该 min）满足：对任何横跨边 $(s,v)$，$w(s,v)\ge\texttt{dis}[v]\ge\texttt{dis}[u]=w(s^\*,u)$。故它是割的最小横跨边。由引理 2，存在包含它的 MST；对轮数归纳（每轮把"存在包含已选边集的 MST"这一性质保持下去：初始空集平凡；每轮在含已选边集的 MST 上对割 $(S,V\setminus S)$ 应用引理 2 的交换论证，可换成含新边的 MST），结束时得到一棵包含全部选中边的 MST。选中边共 $N-1$ 条且每轮连通一个新点，无环，恰为生成树，故它就是 MST。

(c) 代码在选中 $u$ 时执行 `ans=max(ans,dis[u])`，即把每条选中边的权值计入最大值，结束时 $\mathrm{ans}=\max_{e\in T}w(e)$。证毕。

### 引理 4（MST 是 minimum bottleneck：答案 = MST 最大边）

设 $T$ 是任一 MST，$B=\max_{e\in T}w(e)$。则 $B^\*=B$。

*证明*：$B^\*\le B$：$B^\*$ 的定义是对**所有**生成树取瓶颈值的最小值，$T$ 是其中之一，故 $B^\*=\min_{T'}\max_{e\in T'}w(e)\le\max_{e\in T}w(e)=B$。

反向 $B^\*\ge B$：设 $e=(u,v)\in T$ 且 $w(e)=B$。从 $T$ 中删去 $e$，树裂成两个连通分支，点集分别为 $S\ni u$ 与 $V\setminus S\ni v$（树删边恰裂成两块）。**断言：任何横跨割 $(S,V\setminus S)$ 的边 $f$ 都有 $w(f)\ge B$。** 否则若 $w(f)<B=w(e)$，则 $T-e+f$ 是生成树（$f$ 重新连通两块，边数不变）且权和 $w(T)-w(e)+w(f)<w(T)$，与 $T$ 是 MST 矛盾。断言成立。

现在对任意可行 $X$：$G_X$ 连通（引理 1），故 $G_X$ 中必有横跨该割的边 $f$（否则 $S$ 与 $V\setminus S$ 之间无路），于是 $X\ge w(f)\ge B$。特别地 $X=B^\*$ 可行，故 $B^\*\ge B$。

夹逼得 $B^\*=B$。证毕。

**注**：这条引理反过来也说明"最小瓶颈生成树不一定唯一、不一定是 MST"，但**瓶颈值**唯一等于 MST 最大边——我们只需要值，不需要树本身，所以 Prim 顺手取 max 即可。

### 引理 5（哨兵必须压过最大边权；INF 预填充）

最大可能边权 $W_{\max}=2\times25000^2=1250000000$。(a) 若哨兵 $\texttt{inf}\le W_{\max}$，Prim 可能输出错误答案；(b) 取 `i64 inf=1145141919810` 并 `fill_n(dis,n,inf)` 后，算法全程正确且无溢出；(c) 若不预填充（全局默认 $0$），答案恒错（$N\ge2$ 且存在正距离点对时）。

*证明*：(a) 反例：$N=2$，$(0,0),(25000,25000)$，唯一边权 $1250000000$。若 $\texttt{inf}=1145141919<1250000000$，松弛 $\texttt{dis}[1]=\min(\texttt{inf},1250000000)=\texttt{inf}$，第二轮选中 $\texttt{dis}[1]=1145141919$，输出 $1145141919\ne1250000000$。一般地，$\min$ 会把任何 $>\texttt{inf}$ 的真实边权削成 $\texttt{inf}$，破坏引理 3(a) 的不变量。

(b) $\texttt{inf}=1145141919810>1.25\times10^9=W_{\max}$，故真实边权永远小于哨兵，$\min$ 不会误选哨兵；`dis[0]=0` 覆盖起点。所有量 $\le\texttt{inf}<2^{63}-1$，`i64` 无溢出；$w$ 的计算中 $dx^2\le6.25\times10^8$、和 $\le1.25\times10^9$，即便在 `int` 内也不溢出，转 `i64` 只是统一类型。引理 3 的不变量在"哨兵 $=$ 真正的 $+\infty$ 语义"下成立。

(c) 若 `dis` 默认 $0$：第一轮选中点 $0$ 后，所有 $\texttt{dis}[v]=\min(0,w(0,v))=0$，之后每轮都以 $0$ 选中，$\mathrm{ans}=0$。只要存在正距离点对，真实答案 $>0$，故错。$0$ 是合法边权（重合点），这种错误同样静默。证毕。

### 引理 6（复杂度与边界）

时间 $O(N^2)$，空间 $O(N)$；$N=1$ 输出 $0$。

*证明*：$N$ 轮，每轮选最小 $O(N)$、松弛 $O(N)$（每次松弛现算 $w(u,v)$，$O(1)$），合计 $O(N^2)=10^6$。空间：坐标、`dis`、`vis` 各 $O(N)$，不存边。$N=1$：唯一一轮选中 $0$，$\texttt{dis}[0]=0$，$\mathrm{ans}=0$，与引理 1 的 $N=1$ 情形一致。证毕。

### 定理

程序输出最小可行整数 $X$，即 $B^\*$，复杂度 $O(N^2)$。

*证明*：引理 1 把题目化成最小瓶颈 $B^\*$；引理 4 证明 $B^\*$ 等于 MST 最大边；引理 2、3 证明 Prim 选出的边集是 MST 且 `ans` 记录其最大边权；引理 5 保证哨兵与初始化的语义正确（这正是本题最隐蔽的两个坑）；引理 6 给出复杂度与 $N=1$ 边界。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 通信条件就是平方距离 $\le X$，全程整数；连通性关于 $X$ 单调；"广播可达"= 无向图连通。
2. **consider easier version** — 固定 $X$：隐式完全图上 BFS 判连通，$O(N^2)$。
3. **classic problem solution** — 单调性 + 判定 ⇒ 二分答案 $O(N^2\log V)$，能过但带 $\log$。
4. **reduce to easier problem** — 阈值结构 ⇒ 答案 = 最小瓶颈生成树值；经典结论 MST 即最小瓶颈生成树 ⇒ 只需 MST 最大边，$\log$ 消失。
5. **classic problem solution** — 隐式完全图（$5\times10^5$ 边）用稠密 Prim $O(N^2)$，不存边；每轮选最小 `dis` + 松弛，顺手 `ans=max(ans,dis[u])`。
6. **explore its property** — 算值域发现 $W_{\max}=1.25\times10^9>1145141919$：常用哨兵会被真实边权"削顶"，必须换更大的 `i64` 哨兵。
7. **discuss by category** — `dis` 必须 `fill_n` 成 INF（默认 $0$ 是合法边权）；$N=1$ 答案 $0$；重合点距离 $0$ 无害。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 奶牛数 $N\le1000$ | `int` | 读入 |
| `mxn` | $1000+5$ | `constexpr int` | 点数上界 |
| `inf` | 哨兵 $1145141919810$ | `constexpr i64` | **必须 $>W_{\max}=1.25\times10^9$**，故用 `i64` |
| `x[i],y[i]` | 第 $i$ 头牛坐标（0-based） | `int[mxn]` | 读入，$0..25000$ |
| `dis[v]` | 已选集 $S$ 到 $v$ 的最小边权（平方距离） | `i64[mxn]` | **`fill_n(dis,n,inf)`**，`dis[0]=0` |
| `vis[v]` | $v$ 是否已加入 $S$ | `bool[mxn]` | 全局默认 `false` 恰好正确 |
| `ans` | MST 最大边权 = 答案 $X$ | `i64` | $0$；每轮 `max(ans,dis[u])` |
| `d2(u,v)` | 平方距离 $(x_u-x_v)^2+(y_u-y_v)^2$ | `i64(int,int)` | $\le1.25\times10^9$ |

### 算法步骤

1. I/O 加速三行；读 `n` 与坐标。
2. `fill_n(dis,n,inf)`；`dis[0]=0`；`ans=0`。
3. 重复 $N$ 轮：在未选点中找 `dis` 最小的 `u`；`vis[u]=1`；`ans=max(ans,dis[u])`；对所有未选 `v` 执行 `dis[v]=min(dis[v],d2(u,v))`。
4. 输出 `ans`。

### 复杂度

- 时间 $O(N^2)=10^6$；空间 $O(N)$（不存 $5\times10^5$ 条边）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；四组手造数据（$3$ 点 $3\text-4\text-5$ 三角形 $\to16$、单点 $\to0$、对角极限 $\to1250000000$、单位正方形 $\to1$）全部与手算一致；$200$ 组随机小数据（$N\le8$）与"候选 $X$ 排序 + BFS 判连通"的独立暴力逐组一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2847 [USACO16DEC] Moocast G
// 答案 = 平方距离完全图的 MST 最大边（MST 即最小瓶颈生成树）
// 稠密 Prim O(N^2)，不存边；哨兵必须 > 2*25000^2=1.25e9，1145141919 不够大！
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};
constexpr i64 inf{1145141919810};

int n,x[mxn],y[mxn];
i64 dis[mxn];
bool vis[mxn];

i64 d2(int u,int v)
{
	i64 dx=x[u]-x[v],dy=y[u]-y[v];
	return dx*dx+dy*dy;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];
	fill_n(dis,n,inf);	// 全局默认 0 是合法边权，必须显式填 INF
	dis[0]=0;
	i64 ans=0;
	for(int t=0;t<n;++t)
	{
		int u=-1;
		for(int i=0;i<n;++i)
			if(!vis[i]&&(u==-1||dis[i]<dis[u]))
				u=i;
		vis[u]=1;
		ans=max(ans,dis[u]);	// 瓶颈 = MST 最大边
		for(int v=0;v<n;++v)
			if(!vis[v])
				dis[v]=min(dis[v],d2(u,v));
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **哨兵是本题第一坑**：$W_{\max}=1250000000>1145141919$，若用常用 `int` 哨兵，`min` 会把真实大边削成哨兵值，$N=2$ 对角数据即错（引理 5(a)）。换 `i64 inf=1145141919810` 后余量近千倍。
- **`fill_n(dis,n,inf)` 是第二坑**：`dis` 默认 $0$ 会让所有点以零代价被选中，答案恒 $0$。`vis` 默认 `false` 则恰好正确，无需预填。
- `u=-1` 作"尚未找到"的哨兵下标，配合 `u==-1||dis[i]<dis[u]` 短路，避免读 `dis[-1]`。
- 每轮先 `ans=max(ans,dis[u])` 再松弛：`dis[u]` 此刻正是选中边的权值（引理 3(b)），松弛只改未选点，不影响已记录的边。
- $N=1$ 时唯一一轮 `dis[0]=0`，输出 $0$，无需特判；重合点 $w=0$ 同样无害。
