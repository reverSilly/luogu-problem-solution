# P2311 loidc，想想看 — 题解

## 一、解题过程：人类思考叙事

题意重述：$n$ 个时间段，$a_i$ 是第 $i$ 段中国队的金牌数，**保证 $a_i$ 两两不等**。$m$ 个询问，每个给出 $x_i,y_i$，求 $[x_i,y_i]$ 内 $a$ 最大的那个**时间段编号**。关键约束：询问是按顺序提出的，并且严格满足 $x_i\le x_{i+1}$、$y_i\le y_{i+1}$——**两个端点都只增不减**。$n,m\le 10^5$。

**第一反应：区间最值，上结构。** 求区间最大值的位置是标准 RMQ 问题：稀疏表 $O(n\log n)$ 预处理、$O(1)$ 询问，表里存下标，比较时比 $a$ 值就行。$n,m\le10^5$ 完全够，这题"就这？"

但有个地方很扎眼：题面**特意**用一整段话强调"后一个问题总是在前一个问题之后提出""严格有 $x_i\le x_{i+1}$、$y_i\le y_{i+1}$"。如果只是普通 RMQ，这个条件毫无用处——出题人不会平白无故写它。所以我打算先把它用起来看看会走到哪。

**把条件翻译成画面。** $x$ 不减、$y$ 不减，意思是：询问区间是一个**一直向右滑动的窗口**，左边界右移、右边界也右移，从不回退。这正是"滑动窗口最大值"的形状——而滑动窗口最大值的经典解法是**单调队列**：右端点右移时把新元素压进队尾（压之前弹掉队尾所有不可能再成为最大值的元素），左端点右移时把已经出窗口的队头弹掉，队头就是当前窗口最大值。

于是问题变成："这道题是不是就是滑动窗口最大值，只是问的是位置而不是值？"是的。$a$ 两两不等 ⇒ 最大值的位置唯一，队列里存下标、比较时查 $a$，队头下标就是答案。整体 $O(n+m)$，比稀疏表还优，而且用上了题目的特殊条件。

**具体怎么维护。** 队列里存下标，同时保证：
- 下标从队头到队尾严格递增；
- $a$ 从队头到队尾严格递减。

每个询问：先让右端点从上次的位置推进到 $y_i$（每个新下标入队，入队前把队尾所有 $a$ 值比它小的弹掉），再把队头所有下标 $<x_i$ 的弹掉，此时队头就是答案。

**顾虑一：这样弹，凭什么后面不会漏答案？** 队尾被弹掉的元素 $p$ 有一个"替身"：弹它的那个新元素 $q$，满足 $q>p$ 且 $a_q>a_p$。以后任何包含 $p$ 的窗口（右端点 $y\ge q$，因为右端点只增不减）必然也包含 $q$，而 $a_q>a_p$，所以 $p$ 永远不可能是那个窗口的最大值。"被更大的、更靠右的元素支配 ⇒ 此生无用"，这就是弹队的合法性来源。

**顾虑二：队头弹出会不会把答案弹掉？** 队头只在下标 $<x_i$ 时被弹，此时它已经不在窗口里了，弹掉是对的。反过来，窗口右端点 $y_i$ 处的元素刚被压进去且 $y_i\ge x_i$，所以队列永远不会被弹空。

**顾虑三（关键的自我怀疑）：如果询问不单调会怎样？** 我拿 $a=\{1,2,3,4,5\}$ 试：先问 $[1,5]$，再问 $[3,4]$。第一次把下标 $5$（值 $5$）压进了队，第二次右端点缩到 $4$，可是我们**没有任何机制**把它删掉（它既不在队头被 $x$ 弹出，也不会被新元素从队尾顶掉），于是会错答 $5$（正确答案是 $4$）。这说明：**单调条件是算法正确性的前提，不是可选优化**。题目保证了它，算法才能成立；如果不保证，就必须退回 RMQ / 线段树。

**顾虑四：值相等怎么办？** 题面保证 $a_i$ 互不相同，所以"最大值的位置"唯一，用 `<` 弹队尾、用 `<` 弹队头都不会出现"平局怎么选"的歧义。若允许相等，弹队尾时应写 `<=` 以保留最靠左（或最靠右）的那个，否则会留下两个并列最大值而答案不唯一。

到这里算法完全定型：一个下标数组当队列，两个指针当队头队尾，一个 `cur` 记录"已经压到哪"。全部操作都是均摊 $O(1)$。

## 二、思维链：完整证明

约定：下标 $0$-based，$a_0..a_{n-1}$ 两两不等。队列用数组 $Q[hd,tl)$ 模拟，$Q[hd]$ 为队头。

**定义（右起最大值集）**：对区间 $[L,R]$，令
$$\mathrm{RLM}(L,R)=\{\,i\in[L,R] : a_i>\max(a_{i+1},\dots,a_R)\,\},$$
其中约定 $i=R$ 时右端为空集、最大值为 $-\infty$，故 $R\in\mathrm{RLM}(L,R)$。（"右起最大值"= 从右往左看能看到的高度记录。）

**引理 1（答案唯一）**：对任意 $x\le y$，$\arg\max_{i\in[x,y]}a_i$ 唯一。

*证明*：$[x,y]$ 非空；若有两个不同下标都取到最大值，则这两个 $a$ 相等，与"两两不等"矛盾。证毕。

**引理 2（队列的两个形状不变式）**：任意时刻，队列中的下标严格递增，且对应 $a$ 值严格递减。

*证明*：入队时新下标 $cur$ 严格大于队列中的一切下标（$cur$ 单调递增，队内下标都 $<cur$），且总是追加到队尾，故下标递增性质保持；值递减：入队前把队尾所有 $a<a_{cur}$ 的元素弹出，直到队尾满足 $a>a_{cur}$（不能相等，值两两不等），再追加 $cur$，于是新的相邻关系 $a_{\text{队尾-1}}>a_{cur}$ 成立，而原有相邻关系未被改动；出队只删队头（或队尾的连续后缀），删掉首/尾元素不破坏"相邻严格递减"。证毕。

**引理 3（入队正确性：推进入队后队列 = 右起最大值集）**：假设当前队列恰为 $\mathrm{RLM}(L,Y)$（按引理 2 的顺序排列），则对 $Y+1$ 执行"弹掉队尾所有 $a<a_{Y+1}$，再追加 $Y+1$"后，队列恰为 $\mathrm{RLM}(L,Y+1)$。

*证明*：
$$\mathrm{RLM}(L,Y+1)=\{i\in[L,Y]:a_i>\max(a_{i+1..Y})\ \text{且}\ a_i>a_{Y+1}\}\cup\{Y+1\},$$
因为 $a_i>\max(a_{i+1..Y+1})=\max\big(\max(a_{i+1..Y}),a_{Y+1}\big)$ 等价于两个条件同时成立。

由归纳假设，队列（作为集合）$=\{i\in[L,Y]:a_i>\max(a_{i+1..Y})\}$，且它的 $a$ 值沿队列严格递减（引理 2）。于是"队列中满足 $a_i>a_{Y+1}$ 的元素"恰好是队列的一个**前缀**：值严格递减，所以大于 $a_{Y+1}$ 的都在前面，小于 $a_{Y+1}$ 的都在后面（无相等）。算法从队尾依次弹出 $a<a_{Y+1}$ 的元素，弹的正是这个后缀，直到队尾值 $>a_{Y+1}$（或队列空），留下的正是该前缀。再追加 $Y+1$：它的下标最大、值最小，下标递增与值递减都保持。故操作后的队列恰为上式右端，即 $\mathrm{RLM}(L,Y+1)$。证毕。

**引理 4（出队正确性：删掉出窗口的队头）**：设队列为 $\mathrm{RLM}(L,Y)$，且 $L\le x\le Y$。把队头所有下标 $<x$ 弹出后，队列恰为 $\mathrm{RLM}(x,Y)$。

*证明*：由于队列下标递增（引理 2），所有 $<x$ 的元素构成一个前缀，从队头依次弹出恰好删掉它们。而对 $i\ge x$，条件"$a_i>\max(a_{i+1..Y})$"与 $L$ 无关，故
$$\mathrm{RLM}(L,Y)\cap\{i\ge x\}=\mathrm{RLM}(x,Y).$$
证毕。

**引理 5（队头就是最大值的位置）**：设队列为 $\mathrm{RLM}(x,y)$（非空），队头为 $f$。则 $f=\arg\max_{i\in[x,y]}a_i$（唯一，引理 1），即 $a_f=\max(a_x..a_y)$。

*证明*：设 $m=\arg\max_{i\in[x,y]}a_i$。
- $m\in\mathrm{RLM}(x,y)$：右端每个 $i>m$ 都有 $a_i<a_m$（否则与 $m$ 是唯一最大矛盾），故 $a_m>\max(a_{m+1..y})$。
- 于是 $m$ 在队列中。若 $f<m$：由引理 2，队列下标递增，$m$ 排在 $f$ 之后，值严格递减，故 $a_m<a_f$，与 $m$ 是最大值矛盾。若 $f>m$：$m$ 在队列中且比队头下标更小，与 $f$ 是队内最小下标矛盾。
故 $f=m$。证毕。

**引理 6（队列非空）**：处理第 $i$ 个询问时（$x_i\le y_i$），弹队头之后队列非空。

*证明*：考察下标 $y_i$。它在本询问的推进阶段被压入（若它已在队列中则由上一次询问压入，且此后没有更靠右的下标入队会把它从队尾顶掉——顶替只发生在压入新下标时）。压入之后，本询问不再压入任何下标，故它不会被队尾弹出；又 $y_i\ge x_i$，它也不会被队头弹出（队头只弹 $<x_i$）。故 $y_i$ 仍在队列中。证毕。

**引理 7（复杂度）**：总时间 $O(n+m)$，空间 $O(n)$。

*证明*：`cur` 单调递增，每个下标至多被压入一次；每个下标至多被队尾弹出一次、队头弹出一次，故全部队列操作总数 $O(n)$。每个询问另有 $O(1)$ 次比较与一次输出，共 $O(m)$。空间为 $a$ 与 $Q$ 两个长度 $n$ 的数组。证毕。

**定理**：程序对每个询问输出正确的最大金牌数所在时间段。

*证明*：对询问数归纳。基：第一个询问前队列为空（$L=1$，$Y=0$ 时 $\mathrm{RLM}(1,0)=\varnothing$），由引理 3 反复应用，推进到 $Y=y_1$ 后队列 $=\mathrm{RLM}(1,y_1)$；由引理 4，弹出 $<x_1$ 后队列 $=\mathrm{RLM}(x_1,y_1)$；由引理 5 与引理 6，队头即答案。归纳步同理（本询问的 $x_i\ge x_{i-1}$，故引理 4 的前提成立；$y_i\ge y_{i-1}$，故引理 3 只需继续推进）。证毕。

**备注（单调条件的必要性，即"反面教材"）**：若去掉 $x_i\le x_{i+1}$、$y_i\le y_{i+1}$，本算法会出错。取 $a=\{1,2,3,4,5\}$，询问 $[1,5]$ 后询问 $[3,4]$：第一次把下标 $4$（$0$-based，值 $5$）压入且它是队头；第二次右端点缩回，队头仍为 $4$，输出 $5$，而 $[3,4]$ 的最大值是下标 $3$（值 $4$）。原因是引理 3 的推进前提"只增不减"被破坏，且没有任何机制能把"右端点变小时掉出窗口"的元素删掉。这正说明题面那句"后一个问题总是在前一个问题之后提出"是**正确性条件**，不是废话。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 抓住特殊机制：$x$、$y$ 都不减 ⇒ 询问是一个只向右滑的窗口。
2. **consider easier version** — 先忽略这个条件：区间最值 = 稀疏表/线段树，$O(1)/O(\log n)$ 能过，但把题目的条件白扔了。
3. **reduce to easier problem** — 条件用得上的样子正是经典"滑动窗口最大值"，于是问题归约到单调队列原型。
4. **explore its property** — 队尾弹出 = "支配"关系：右边有更大值 ⇒ 任何未来窗口要么不含它、要么含那个更大的 ⇒ 它此生无用。
5. **explore its property（碰壁/自我怀疑）** — 用 $a=\{1,2,3,4,5\}$、先 $[1,5]$ 后 $[3,4]$ 构造反例，验证"单调性是正确性前提"而非优化。
6. **classic problem solution** — 单调队列存下标、值递减、队头即最大值位置；$O(n+m)$。
7. **边界条件** — $y_i\ge x_i$ 保证队列非空；$a_i$ 互异保证答案唯一、`<` 比较无歧义。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| $n$ | 时间段数 | `int`，读入 |
| $m$ | 询问数 | `int`，读入 |
| $a[i]$ | 第 $i$ 个时间段（$0$-based）的金牌数 | `int a[mxn]`，读入，两两不等 |
| $Q[hd..tl)$ | 单调队列，存下标；$a$ 值从队头到队尾严格递减 | `int Q[mxn]`，$hd=tl=0$ 为空 |
| $hd$ | 队头指针（第一个有效元素的下标） | 初值 $0$ |
| $tl$ | 队尾指针（最后一个有效元素的下一位，即半开） | 初值 $0$ |
| $cur$ | 下一个待入队的时间段下标，即已把 $[0,cur)$ 压入过 | 初值 $0$ |
| $x,y$ | 询问区间（读入后减一转 $0$-based） | 循环内局部变量 |

记忆点：$Q$ 里"下标递增、值递减"，队头永远是当前窗口的最大值；$cur$ 只向前走，代表"右端点已经推进到哪"。

### 算法步骤

1. 读入 $n$ 与 $a[0..n-1]$，`hd=tl=cur=0`。
2. 读入 $m$，按输入顺序逐个处理询问（顺序不能乱，状态是复用的）：
   1. 读 $x,y$，`--x;--y;`。
   2. **推进右端点**：`for(;cur<=y;++cur)`：先 `while(hd<tl && a[Q[tl-1]]<a[cur]) --tl;`（弹掉被支配的队尾），再 `Q[tl++]=cur;`。
   3. **弹出出窗口的队头**：`while(hd<tl && Q[hd]<x) ++hd;`。
   4. 输出 `Q[hd]+1`（转回 $1$-based）。
3. 每个询问互不干扰的只有输出，队列状态在询问之间**连续复用**（这正是 $O(n+m)$ 的来源）。

### 复杂度

- 时间：$O(n+m)$。每个下标入队至多一次、出队（队头或队尾）至多一次；每个询问 $O(1)$。
- 空间：$O(n)$（`a`、`Q` 各 $n$；`mxn{100005}` 为 $10^5$ 加松弛）。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过。
- 本题题面无样例，手造三组小数据（$a=\{5,3,9,1,7\}$ 配单调询问 $[1,3],[1,5],[2,5],[4,5]$ 得 `3 3 3 5`；$a=\{1,2,3,4,5\}$ 配 $[1,2],[2,3],[3,4],[4,5],[5,5]$ 得 `2 3 4 5 5`；$a=\{6,5,4,3,2,1\}$ 配 $[1,6],[2,6],[3,6],[4,5],[5,5]$ 得 `1 2 3 4 5`）全部人工核对通过。
- 对拍：与"每询问直接扫区间取最大值"的暴力在 $n\le30,m\le20$ 的**随机单调询问序列**上跑 **300 组**，输出完全一致。
- 另单独验证了"询问不单调时算法确实会错"（输出 $5$ 而非 $4$），与正文备注一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2311 loidc，想想看
// 关键：x、y 都不减 => 询问是只向右滑的窗口 => 单调队列（存下标，值队头到队尾严格递减）
// 队尾弹出：右边有更大的 => 被支配，以后永远不可能当最大值
// 队头弹出：下标 < x => 已经出窗口
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n,m,a[mxn],Q[mxn];	//Q[hd,tl) 存下标，值从队头到队尾严格递减

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	int hd=0,tl=0,cur=0;	//cur=已入队右端点（开），[0,cur)
	cin>>m;
	for(int x,y;m--;)
	{
		cin>>x>>y;--x;--y;
		for(;cur<=y;++cur)	//先推进右端点
		{
			while(hd<tl&&a[Q[tl-1]]<a[cur])
				--tl;
			Q[tl++]=cur;
		}
		while(hd<tl&&Q[hd]<x)	//再弹出出窗口的队头
			++hd;
		cout<<Q[hd]+1<<'\n';	//y>=x 保证队列非空
	}
	return 0;
}
```

### 代码说明

- `Q` 同时当队列和"答案仓库"：队头下标加一就是输出，不需要另外记录。
- 推进右端点用 `cur` 而不是每次从 $y_{i-1}+1$ 重新开始，这正是 $O(n+m)$ 的来源；`cur` 全程只增。
- **两条 `while` 的顺序**：必须先推右端点再弹队头。若先弹队头，队列可能暂时变空（此时 `Q[hd]` 已是旧值），虽然本题 $x\le y$ 下最终结果不变，但"推完再弹"能保证任何时刻读队头都是安全的。
- 比较一律用 `<`：$a_i$ 互不相同，不会出现并列，若数据允许相等应改成 `<=`（否则并列最大值会同时滞留，答案不唯一）。
- `y>=x` 是队列非空的保证（正文引理 6）；若题面允许 $x>y$ 的空区间，这里需要特判。

---

*本题的思维结构是"把题面的单调条件翻译成滑动窗口 ⇒ 认出单调队列原型"；真正的价值在于想清楚"队尾为什么可以弹"（支配关系）和"单调条件为什么不可或缺"（反例）。*
