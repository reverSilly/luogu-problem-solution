# P2813 母舰 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 对方有 $M$ 个防御系统（防御力给定），我方有 $N$ 个攻击系统（攻击力给定），$N,M\le10^5$。每个攻击系统选一个**不同的**防御系统攻击；攻击力**严格大于**防御力才能破坏它。**只有当对方防御系统全部被破坏后**，剩余的攻击才打到母舰本体，伤害 = 这些攻击系统的攻击力之和。求最大伤害。

样例：防御 $1000,2000,1200$，攻击 $2100,2000,1200,1000,1000$。最优：$2100\to2000$、$2000\to1200$、$1200\to1000$，剩下 $1000+1000=2000$ 点伤害。注意 $2000$ 打 $2000$ **不破**（严格大于），样例解释里 $e$ 只能去打 $1200$，印证了这一点。

**第一步：伤害是"全有或全无"的。** 只要有一个防御系统没被破坏，所有攻击都砸在防御上，本体伤害为 $0$。所以策略空间只有两类：(a) 放弃破防，伤害 $0$；(b) 破掉**全部** $M$ 个防御，伤害 = 没用于破防的攻击力之和。若 (b) 可行，其伤害 $\ge0$，永不劣于 (a)。于是问题变成：**判断能否全破；能的话，让"用于破防的攻击力总和"最小**，答案 = 攻击力总和 $-$ 这个最小值。

**第二步：一对一匹配不失一般性。** 题面说"用不同的攻击系统去攻击对面母舰的防御系统"，样例也是每个防御恰好挨一发。就算允许多个攻击系统砸同一个防御，也毫无好处：防御被破坏一次就够了，多砸的攻击不如省下来打本体。所以任何最优方案都能整理成"每个防御恰被一个攻击系统破坏、每个攻击系统至多用一次"的**匹配**，且不损失伤害。

**第三步：贪心怎么贪？先试一个错的。** 直觉"大攻击打大防御"？反例：防御 $[1,10]$，攻击 $[2,11,100]$。大对大：$100\to10$、$11\to1$，剩 $2$，伤害 $2$。但 $11\to10$、$2\to1$，剩 $100$，伤害 $100$。**把大攻击浪费在小防御上是暴殄天物**——小防御应该用"刚好够破"的最小攻击去解决，把大攻击省下来打本体。

于是正确贪心浮现：**防御从小到大处理，每个防御用"剩余攻击中严格大于它的最小者"**。比当前防御还小的攻击永远破不了它（以及后面更大的防御），直接跳过——它们自动成为本体伤害的一部分。

**第四步：为什么这个贪心对？** 交换论证。设最小防御 $d$，最小够用攻击 $a'$。任取一个最优全破匹配：若它给 $d$ 分配的就是 $a'$，无事发生；若分配的是更大的 $a$：
- $a'$ 在匹配里没被用：把 $d$ 的分配换成 $a'$，$a$ 省下来打本体，伤害**不减**（$a\ge a'$）；
- $a'$ 被用在某个防御 $d'$ 上：交换——$d\leftarrow a'$、$d'\leftarrow a$。合法性：$a'>d$（$a'$ 够用）；$a>a'$（$a'$ 是最小够用者而 $a\ne a'$）且 $a'>d'$（$a'$ 原本就能破 $d'$），故 $a>d'$，交换后仍全破，破防总花费**不变**。

两种情形都能把最优解改造成"同意贪心第一步"的最优解；对剩下的防御归纳，贪心全程最优。同时这也证明：**贪心失败（攻击耗尽）$\iff$ 根本不存在全破匹配**——若存在，交换论证会造出一个跟着贪心走的全破匹配，贪心就不会失败。

**第五步：实现与口径。** 双排序 + 双指针：防御升序 `def`，攻击升序 `atk`；指针 `i` 扫攻击，对每个 `def[j]` 先 `while(atk[i]<=def[j])++i` 跳过废物，若耗尽输出 $0$；否则 `used+=atk[i++]`。答案 `tot-used`（被跳过的攻击没进 `used`，自动算进本体伤害）。样例核算：`def=[1000,1200,2000]`，`atk=[1000,1000,1200,2000,2100]`；$1000$ 防：跳过两个 $1000$，用 $1200$；$1200$ 防：用 $2000$；$2000$ 防：用 $2100$；`used=5300`，`tot=7300`，答案 $2000$ ✓。

**口径假设（题面未明说处，按最自洽解读实现）：**
1. 攻击力/防御力数值范围题面未给，按"单个值在 32 位整数内、总和可能超 32 位"处理：数组与累加全用 `i64`（$N\le10^5$，若单值达 $10^9$，总和 $10^{14}$ 必须 64 位）。
2. "大于"取**严格**大于（样例 $2000$ 不破 $2000$ 佐证）。
3. 每个攻击系统至多使用一次、每个防御至多被一个攻击系统攻击（样例一对一佐证；且由第二步，即使允许重复攻击同一防御也不影响最优值）。
4. 未全破时伤害为 $0$（"全部被破坏掉之后……才……本身"的字面义）。

**手造数据核对：**

| 输入（防御 / 攻击） | 手算 | 考点 |
|---|---|---|
| $[1000,2000,1200]$ / $[2100,2000,1200,1000,1000]$ | $2000$ | 样例 |
| $[1,10]$ / $[2,11,100]$ | $100$ | 打"大对大"错误贪心 |
| $[5,5]$ / $[5,6]$ | $0$ | 严格大于 + 攻击不够全破 |
| $[3]$ / $[3]$ | $0$ | 相等不破 |
| $[7]$ / $[2,9]$ | $2$ | 废物攻击 $2$ 计入本体伤害 |
| $[4,4]$ / $[5,5,5]$ | $5$ | 全破后剩一个 $5$ |

## 二、思维链：完整证明

**记号.** 防御力升序 $d_0\le d_1\le\dots\le d_{M-1}$，攻击力升序 $a_0\le a_1\le\dots\le a_{N-1}$，$T=\sum a_i$。**全破匹配**：单射 $\mu:\{0..M-1}\to\{0..N-1\}$ 满足 $a_{\mu(j)}>d_j$ 对所有 $j$。其花费 $C(\mu)=\sum_j a_{\mu(j)}$，伤害 $T-C(\mu)$。

### 引理 1（问题归约：全破 or 零）

最优伤害 $=\begin{cases}T-\min_\mu C(\mu),&\text{全破匹配存在}\\0,&\text{否则}\end{cases}$。且允许"多个攻击砸同一防御"不改变最优值。

*证明*：按题面，防御未全破时本体伤害 $0$。全破时，设方案中用于攻击防御的攻击系统多重集为 $S$（可能重复砸同一防御），本体伤害 $=T-\sum_{s\in S}a_s$。对每个防御，它被破坏说明至少有一个砸它的攻击满足严格大于；只保留其中一个，其余从 $S$ 移除：防御仍全破，$\sum_{s\in S}a_s$ 不增，伤害不减。整理后 $S$ 中每个攻击系统至多出现一次（每个攻击系统只有一发）、每个防御恰好对应一个攻击，即全破匹配 $\mu$，伤害 $=T-C(\mu)$。故最优伤害 $=\max(0,\ T-\min_\mu C(\mu))$（无匹配时取 $0$）。有匹配时 $T-\min C\ge0$（$\min C\le T$，因为匹配用的攻击是全部攻击的子集），故 $\max$ 可去掉，得分段式。证毕。

### 引理 2（废物攻击可跳过）

处理到防御 $d_j$（升序）时，剩余攻击中满足 $a_i\le d_j$ 者不可能破坏 $d_j,d_{j+1},\dots,d_{M-1}$ 中任何一个，可永久跳过；跳过的攻击计入本体伤害。

*证明*：$k\ge j\Rightarrow d_k\ge d_j\ge a_i$，故 $a_i>d_k$ 不成立，$a_i$ 对任何剩余防御都无用。跳过不损失任何全破匹配。又答案公式 $T-C(\mu)$ 中，$C$ 只统计匹配使用的攻击，被跳过者不在 $C$ 内，自动贡献 $a_i$ 到伤害。证毕。

### 引理 3（贪心选择性质：最小防御配最小够用攻击）

设 $d_0$ 为最小防御，$a'$ 为全体攻击中满足 $a'>d_0$ 的最小者（若不存在则无全破匹配）。若存在全破匹配，则存在一个**花费最小**的全破匹配 $\mu^\*$ 满足 $\mu^\*(0)=a'$ 的下标。

*证明*：无 $a'$ 时任何攻击都 $\le d_0$，$d_0$ 不可破，无全破匹配，与前提矛盾，故 $a'$ 存在。取任一花费最小的全破匹配 $\mu$，设 $\mu(0)=a$。由 $a>d_0$ 与 $a'$ 的最小性，$a\ge a'$。

情形 A：$a=a'$，已满足。

情形 B：$a>a'$ 且 $a'$ 未被 $\mu$ 使用。构造 $\mu'$：$\mu'(0)=a'$，其余同 $\mu$。合法性：$a'>d_0$ ✓，其余不变；仍是单射（$a'$ 原本空闲）。$C(\mu')=C(\mu)-a+a'\le C(\mu)$。由 $\mu$ 最小性，$C(\mu')=C(\mu)$，$\mu'$ 也是最小花费匹配且满足要求。

情形 C：$a>a'$ 且 $a'=\mu(j)$（$j\ne0$）。构造 $\mu'$：$\mu'(0)=a'$、$\mu'(j)=a$，其余同。合法性：$a'>d_0$ ✓；$a>a'>d_j$（$a'=\mu(j)$ 合法给出 $a'>d_j$）✓；单射性：$a,a'$ 原本分别占用于 $0,j$，交换后仍各用一次 ✓。$C(\mu')=C(\mu)$（两项互换，和不变），故 $\mu'$ 最小花费且满足要求。

三情形穷尽，均得到所需 $\mu^\*$。证毕。

### 引理 4（贪心算法正确且失败即无解）

算法：`i=0`；对 $j=0..M-1$：跳过所有 $a_i\le d_j$（引理 2）；若 $i=N$ 则宣告失败；否则令 $\mu(j)=i$，`used+=a[i]`，`++i`。则：

(a) 若存在全破匹配，算法不失败，且输出的 $\mu$ 是花费最小的全破匹配；
(b) 若算法失败，则不存在全破匹配；
(c) 算法成功时答案 $T-\texttt{used}$ 即最优伤害。

*证明*：对 $M$ 归纳（在"去掉已处理防御与已用/已跳过攻击"的子问题上）。

$M=0$：空匹配花费 $0$，平凡。

设结论对 $M-1$ 成立。考虑第一步：$d_0$ 最小，算法选的最小够用攻击正是引理 3 的 $a'$（指针跳过所有 $\le d_0$ 者，停在第一个 $>d_0$ 者）。若不存在这样的攻击：$d_0$ 不可破，无全破匹配，算法失败，(b) 成立。若存在：由引理 3，存在最小花费全破匹配 $\mu^\*$ 以 $a'\to d_0$ 开头。剩余子问题：防御 $d_1..d_{M-1}$、攻击为去掉 $a'$ 及所有 $\le d_0$ 的废物后的序列（废物由引理 2 不参与任何匹配）。$\mu^\*$ 限制在子问题上仍是全破匹配；反之子问题的任何全破匹配接上 $a'\to d_0$ 都是原问题全破匹配，且花费差恒为 $a'$。故"原问题最小花费" $=a'+$ "子问题最小花费"。由归纳假设，算法在子问题上成功且给出最小花费匹配（若子问题无匹配则失败）。拼上第一步即得 (a)；子问题失败 $\Rightarrow$ 子问题无匹配 $\Rightarrow$ 原问题无匹配（否则 $\mu^\*$ 的限制就是子问题匹配），(b) 成立。

(c)：成功时 `used`$=C(\mu)$ 为最小花费，由引理 1 最优伤害 $=T-C(\mu)=T-\texttt{used}$；被跳过的攻击不在 `used` 中，已自动计入。失败时由 (b) 无匹配，引理 1 给 $0$，算法输出 $0$。证毕。

### 引理 5（复杂度与数值范围）

时间 $O(M\log M+N\log N)$，空间 $O(N+M)$；`i64` 累加无溢出（在"单值 $\le10^9$"的常规口径下）。

*证明*：两次排序 $O(M\log M+N\log N)$；双指针中 `i` 与 `j` 各单调前进至多 $N,M$ 步，扫描 $O(N+M)$。空间两个 `i64` 数组各 $100005$ 项，约 $1.6$ MB。数值：题面未给单值上界，按 32 位整数口径 $|a_i|\le2^{31}-1$，$T\le10^5\times(2^{31}-1)\approx2.1\times10^{14}<2^{63}-1$，`i64` 安全；即使单值达 $10^9$ 也同样安全。证毕。

### 定理

程序输出最大本体伤害。

*证明*：引理 1 把原题归约为"全破匹配的最小花费"；引理 2 保证跳过废物攻击无损；引理 3 给出贪心选择性质（交换论证，含花费不增的两种情形）；引理 4 归纳证明贪心成功即最优、失败即无解；引理 5 给出复杂度。口径假设（严格大于、一对一、未全破零伤害、64 位累加）已在第一部分显式标注。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 伤害"全有或全无"：未全破 = $0$；全破 = 总攻击力 $-$ 破防花费 ⇒ 目标转成"最小化破防花费"。
2. **reduce to easier problem** — 重复砸同一防御无益 ⇒ 一对一匹配；问题 = 排序数组间的最小花费支配匹配。
3. **consider easier version** — 试"大攻击打大防御"贪心，被 $[1,10]/[2,11,100]$ 反例击穿：大攻击要省着打本体。
4. **classic problem solution** — 双排序 + 双指针贪心：最小防御配"最小够用"攻击，$\le$ 当前防御的攻击永久跳过（它们对更大防御也无用）。
5. **explore its property** — 交换论证两情形（$a'$ 空闲 → 花费降；$a'$ 被占 → 交换花费不变）证明贪心选择性质，归纳得全局最优与"失败即无解"。
6. **discuss by category** — 严格大于（相等不破）；$N<M$ 或攻击耗尽输出 $0$；跳过者自动计入 `tot-used`；单值范围未给 ⇒ `i64` 数组与累加。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `m,n` | 对方防御数、我方攻击数，$\le10^5$ | `int` | 读入顺序先 `m` 后 `n` |
| `def[j]` | 第 $j$ 个防御力，升序 | `i64[mxn]` | 读入后 `sort` |
| `atk[i]` | 第 $i$ 个攻击力，升序 | `i64[mxn]` | 读入后 `sort` |
| `tot` | 攻击力总和 $T$ | `i64` | 读入时累加，全局默认 $0$ |
| `used` | 贪心匹配的花费 $C(\mu)$ | `i64` | $0$ 起，每配一对加 `atk[i]` |
| `i,j` | 攻击指针 / 防御指针 | `int` | 均 $0$ 起单调前进 |
| `mxn` | $10^5+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行；读 `m,n`；读 `def[0..m-1]`；读 `atk[0..n-1]` 并累加 `tot`。
2. `sort(def,def+m)`、`sort(atk,atk+n)`。
3. `i=0`；对 `j=0..m-1`：`while(i<n&&atk[i]<=def[j])++i`；若 `i==n` 输出 `0` 结束；否则 `used+=atk[i++]`。
4. 输出 `tot-used`。

### 复杂度

- 时间 $O(M\log M+N\log N)\approx3.4\times10^6$ 次比较；空间 $O(N+M)\approx1.6$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例与五组手造边界（严格大于、攻击不足、废物计伤、全破剩余）与手算一致；另用"按定义递归枚举所有全破匹配"的独立暴力对 $400$ 组随机小数据（$M\le4,N\le6$，值域 $1..15$ 刻意造大量相等）逐组一致；$M=5\times10^4,N=10^5$、攻击力 $\sim10^9$ 的极限数据答案 $\approx5\times10^{13}$（验证 `i64` 必需），运行约 $0.1$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2813 母舰
// 伤害全有或全无：全破防 ⇒ 伤害 = tot - 破防花费；否则 0
// 贪心：防御升序，每个防御配"剩余攻击中严格大于它的最小者"，大攻击省下来打本体
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n,m;
i64 atk[mxn],def[mxn],tot;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n;
	for(int i=0;i<m;++i)
		cin>>def[i];
	for(int i=0;i<n;++i)
	{
		cin>>atk[i];
		tot+=atk[i];
	}
	sort(def,def+m);
	sort(atk,atk+n);
	i64 used=0;
	for(int j=0,i=0;j<m;++j)
	{
		while(i<n&&atk[i]<=def[j])
			++i;	// 打不穿当前及以后所有防御，留作本体伤害（严格大于！）
		if(i==n)
		{
			cout<<0<<'\n';	// 无法全破 ⇒ 伤害为 0
			return 0;
		}
		used+=atk[i++];
	}
	cout<<tot-used<<'\n';
	return 0;
}
```

### 代码说明

- `atk[i]<=def[j]` 的 `<=` 是题面"严格大于才破坏"的直接翻译：相等不破，样例 $2000$ 打 $2000$ 失败正是此意。
- 被 `while` 跳过的攻击**不进 `used`**，于是 `tot-used` 自动把它们算作本体伤害，不需要第二个累加器。
- 指针 `i` 全程只前进：防御升序保证"对当前防御无用"的攻击对后续防御也无用（引理 2），跳过是永久的。
- `i==n` 即攻击耗尽仍未全破，由引理 4(b) 此时不存在任何全破方案，输出 `0`。
- 数组与 `tot/used` 全 `i64`：题面未给单值上界，$10^5$ 个攻击力求和必须防 32 位溢出。
