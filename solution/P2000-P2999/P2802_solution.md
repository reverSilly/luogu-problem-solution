# P2802 回家 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n\times m$ 的网格（$n,m\le 9$），五种格子：`0` 障碍、`1` 空地、`2` 起点、`3` 家、`4` 鼠标。小 H 初始满血 $6$，每移动一格（上下左右，不能不动、不能出界）耗 $1$ 血；**血量降到 $0$ 立即死亡**——哪怕这一格正好是鼠标（不能先拾取再活过来）或正好是家（不算回家）。走到鼠标格瞬间补满 $6$ 血，且鼠标**无限次**可用（"每次经过这个格子都有鼠标"）。求从起点活着走到家的最少移动次数，做不到输出 `-1`。

$n,m\le 9$ 小到离谱，一看就是搜索题。但"血量"这个机制让最朴素的 BFS 立刻翻车，我按下面的顺序把它想清楚。

**第一步：朴素 BFS 为什么不行？** 网格最短路的标准反应是 BFS + `vis[x][y]`。但本题"能不能继续走"取决于**当前血量**，而同一个格子可以在不同血量下被经过。只按格子判重，会把"第一次低血量经过、之后高血量再经过"的合法路线错杀。构造一个最小反例（$2\times 7$）：

```
2 1 1 1 1 1 3
0 0 4 0 0 0 0
```

起点 $(0,0)$，家 $(0,6)$，唯一鼠标在死胡同 $(1,2)$。沿第 $0$ 行直走要 $6$ 步，第 $6$ 步血尽而亡；所以**必须**先去鼠标补血：$(0,0)\to(0,1)\to(0,2)\to(1,2)$（$3$ 步，血 $6\to3$，拾取补满 $6$），再原路折回 $(0,2)$ 一路向右到家（又 $5$ 步，血 $6\to1$），共 $8$ 步。格子 $(0,2)$ 被经过**两次**：第一次血 $4$、第二次血 $5$。`vis[x][y]` 版 BFS 在第一次经过 $(0,2)$ 后就把它封死，补血回来时进不去，错误输出 `-1`。**结论：判重必须带上血量维度。**（题面特意提到 2021 年加了一组 hack 数据，大概率就是打这种写法的。）

**第二步：状态到底是什么？** 想清楚"未来的合法性只由什么决定"：站在哪一格（决定能往哪走、会不会拾取/到家）+ 当前血量（决定还能走几步）。历史路径、走过哪些鼠标格都**不影响未来**——鼠标无限次可用，不存在"拾取过就没了"的资源消耗。所以状态取 $(x,y,hp)$，$hp\in\{1,\dots,6\}$（$0$ 血是死态，不入队）。状态总数 $\le 9\times9\times6=486$，小得可以随便搜。

**第三步：死亡规则怎么落进转移？** 从 $(x,y,hp)$ 走到邻格 $(nx,ny)$：先扣血 $hp'=hp-1$；**若 $hp'=0$，这条转移直接不存在**（题面两句"就算……才死去"分别堵死了"鼠标格上死里逃生"和"家门口死也算到家"两个漏洞）；活下来之后，若该格是鼠标则 $hp'\gets6$，若该格是家则任务完成。注意顺序：**先判死、再拾取、再判家**，与题面逐句对应。

**第四步：BFS 即最优。** 每次移动耗时 $1$，状态图上所有边权为 $1$，BFS 的层序就是最短移动次数。第一次**生成**家格子状态时，当前出队状态的距离 $+1$ 就是答案；队列耗尽仍没碰到家则输出 `-1`。不需要 Dijkstra，不需要 DFS 爆搜加最优性剪枝。

**第五步：几个细节。**

1. `dis[x][y][hp]` 是"未访问"标记兼距离数组，全局 `int` 默认 $0$ 而 $0$ 是合法距离，**必须显式 `fill_n` 成 INF**，否则所有状态都会被当成"已以 $0$ 步访问过"，BFS 一步都走不动。
2. 起点格 `2` 就是空地，可以反复经过；家格 `3` 一旦活着踏上立即结束，不必入队。
3. 鼠标格的状态永远是 $(x,y,6)$（踏上即满血），所以"重复经过鼠标"天然被状态判重吸收，不会死循环。
4. 有人想优化成"每格只记最大血量"（优势剪枝）：同格高血确实支配低血，但**不同时刻**到达的同格状态不能互相剪——晚到的高血状态可能步数更多。本题状态数 $486$，完全没必要冒这个险，老老实实三维判重。

**手造数据核对**（题面无样例，按规则自造）：

| 输入 | 手算 | 考点 |
|---|---|---|
| `1 2` / `2 3` | $1$ | 最基础 |
| `1 6` / `2 1 1 1 1 3` | $5$ | 走 $5$ 步血剩 $1$，恰好活着到家 |
| `1 7` / `2 1 1 1 1 1 3` | $-1$ | 第 $6$ 步血尽，"家门口死去不算回家" |
| `1 8` / `2 1 1 1 1 1 4 3` | $-1$ | 第 $6$ 步踏上鼠标时血已归零，"鼠标格上死去不能补满" |
| `1 8` / `2 1 1 1 1 4 1 3` | $7$ | 第 $5$ 步血 $1$ 拾取补满，再走 $2$ 步到家 |
| 上文 $2\times7$ 反例 | $8$ | 同格不同血必须允许重访 |

六组把死亡边界、拾取时机、血量维判重全部覆盖。

## 二、思维链：完整证明

**记号。** 格子 $(x,y)$，$0\le x<n,0\le y<m$，类型 $a_{x,y}\in\{0,1,2,3,4\}$。状态 $s=(x,y,h)$，$h\in\{1,\dots,6\}$。起点状态 $s_0=(sx,sy,6)$。定义转移关系 $s\to s'$：存在方向 $d$ 使 $(x',y')$ 是 $(x,y)$ 的四邻格之一、在界内、$a_{x',y'}\ne0$，且 $h-1\ge1$；此时 $h'=6$ 若 $a_{x',y'}=4$，否则 $h'=h-1$。称 $a_{x,y}=3$ 的状态为**终态**。

### 引理 1（合法行走与状态图路径一一对应）

小 H 的一个合法行走（每步不死亡、不出界、不穿障碍）恰好对应状态图中从 $s_0$ 出发的一条路径，且行走步数 = 路径边数；反之亦然。

*证明*：对步数归纳。初始：满血站在起点，对应 $s_0$，$0$ 步。设前 $t$ 步合法且对应状态序列 $s_0,\dots,s_t$，$s_t=(x_t,y_t,h_t)$ 记录真实位置与真实血量。第 $t+1$ 步走到邻格 $(x',y')$：合法 $\iff$ 在界内、非障碍、扣血后 $h_t-1\ge1$（题面"一旦降到 $0$ 将死去"，且死亡判定先于拾取与到家判定）。这正是转移关系的全部条件。转移后的血量：若该格是鼠标，题面"瞬间补满"给出 $h'=6$；否则 $h'=h_t-1$。与 $h'$ 的定义逐字一致。故合法行走 $\iff$ 状态图路径，步数守恒。反过来，任一路径按上述规则还原出的行走每步都满足合法性条件。证毕。

**推论**："能否回家" $\iff$ 从 $s_0$ 可达某终态；"最短时间" $\iff$ $s_0$ 到终态集的最短路长度。历史无关性（鼠标无限次、无其他消耗）保证状态 $(x,y,h)$ 是充分统计量，不需要额外维度。

### 引理 2（死亡规则的转移编码无歧义）

题面三条规则——(i) 血降到 $0$ 即死；(ii) 踏上鼠标格时若已死不能补满；(iii) 在家门口死去不算回家——等价于转移定义中"先要求 $h-1\ge1$，再做拾取/到家判定"。

*证明*：(i) 直接对应 $h-1\ge1$ 的前置条件。(ii) 若某步使 $h-1=0$ 且目标格是鼠标：按题面小 H 已死，行走终止，该步不产生任何后继状态；我们的转移因前置条件失败而不存在，一致。若 $h-1\ge1$，拾取合法，$h'=6$。(iii) 若某步使 $h-1=0$ 且目标格是家：题面不算完成；我们的转移不存在，家状态不可达，一致。若 $h-1\ge1$ 且目标格是家，行走成功完成，对应到达终态。三条规则的所有情形（目标格类型 $\times$ 扣血后是否存活）都被穷尽且逐一对应。证毕。

### 引理 3（BFS 距离不变量）

以 $s_0$ 为源做 BFS（队列初始 $\{s_0\}$，`dis[s0]=0`，其余 INF；出队时向所有未访问后继松弛并入队），则：

(a) 队列中状态的距离值单调不减，且任意时刻队列里最多出现两种相邻的距离值 $D,D+1$；
(b) 每个状态第一次被设置 `dis` 时的值等于 $s_0$ 到它的最短距离 $d^*(s)$；
(c) 状态按距离不减的顺序出队。

*证明*：对操作序列归纳维持不变量 (a)：初始队列只有 $s_0$（距离 $0$），成立。出队一个距离 $D$ 的状态时，由归纳假设它是队首且队列其余元素距离 $\in\{D,D+1\}$；它生成的后继距离 $D+1$ 追加队尾，不破坏单调性；出队后队列元素距离 $\in\{D,D+1\}$ 仍成立。故 (a) 恒成立，(c) 随之成立。

(b)：先证 `dis[s]` $\ge d^*(s)$：每次赋值都对应一条真实存在的 $s_0\to s$ 路径（沿前驱链），长度即赋值，故不小于最短距离。再证每个可达状态都会被赋值为 $d^*(s)$：对 $d^*(s)$ 归纳。$d^*=0$ 只有 $s_0$，初始化正确。设 $d^*(s)=D\ge1$，取最短路上的前驱 $p$，$d^*(p)=D-1$；由归纳假设 $p$ 以 `dis[p]`$=D-1$ 入队并出队；出队时枚举到边 $p\to s$：若 $s$ 未访问则赋 `dis[s]`$=D$，正确；若 $s$ 已访问，由 (a)(c)，$s$ 的赋值发生在某个距离 $\le D-1$ 的状态出队时（因为 $p$ 是距离 $D-1$ 层中出队的，而队列单调），故 `dis[s]`$\le D$，结合 $\ge d^*(s)=D$ 得等于 $D$。证毕。

### 引理 4（首次生成终态即答案；队列耗尽即无解）

BFS 过程中第一次生成终态时，答案 = 当前出队状态的 `dis`$+1$；若队列耗尽仍未生成终态，则无解，输出 `-1`。

*证明*：设首次生成终态 $g$ 时出队状态为 $u$，`dis[u]`$=D$，则 `dis` 候选值 $D+1$。由引理 3，$D=d^*(u)$，故存在长度 $D+1$ 的合法回家行走，答案 $\le D+1$。反设存在更短的回家行走，长度 $L\le D$，其末状态 $g'$ 是终态且 $d^*(g')=L'\le L\le D$。由引理 3(b) 的证明过程，$g'$ 会在某个距离 $\le L'-1\le D-1$ 的状态出队时被生成；而 BFS 按距离不减出队（引理 3(c)），所有距离 $\le D-1$ 的状态都在 $u$（距离 $D$）之前出队完毕，故 $g'$ 的生成早于本次生成，与"首次"矛盾。所以答案 $=D+1$。

无解方向：状态图有限（$\le486$ 个点），BFS 每个状态至多入队一次，必然终止；队列耗尽时所有可达状态都已访问（引理 3(b) 的归纳覆盖全部可达点），其中没有终态 $\iff$ 终态不可达 $\iff$ 由引理 1 不存在合法回家行走。证毕。

### 引理 5（按格子判重的 BFS 是错误的）

存在合法输入，使"只按 $(x,y)$ 判重"的 BFS 输出 `-1` 而正确答案为 $8$。

*证明*：取第一部分的 $2\times7$ 反例。先验证正确答案是 $8$：第 $1$ 行只有 $(1,2)$ 可走，其余全障碍，故任何回家路径在第 $0$ 行上从 $(0,0)$ 走到 $(0,6)$，中途可选是否下探 $(1,2)$。不下探：$6$ 步，第 $6$ 步扣血后 $h=0$，由引理 2 死亡，非法。下探：必须经 $(0,2)\to(1,2)\to(0,2)$，总步数 $6+2=8$；血量序列 $6,5,4,3\xrightarrow{\text{拾取}}6,5,4,3,2,1$，全程 $\ge1$，合法。故最优 $8$。再验证错误算法：它沿第 $0$ 行 BFS，$(0,2)$ 在第 $2$ 步被访问并封死；从 $(1,2)$（第 $3$ 步可达）返回 $(0,2)$ 的转移被判重拦截，而 $(0,3..6)$ 只能从 $(0,2)$ 进入（第 $1$ 行对应列全障碍），于是家不可达，输出 `-1`。两者矛盾，故按格子判重错误。证毕。

### 引理 6（复杂度）

时间 $O(7nm)$，空间 $O(7nm)$（常数 $7$ 为血量维大小，含 $0$ 号空位）。

*证明*：状态数 $\le 6nm$，每个状态至多入队、出队一次（`dis` 判重），每次出队枚举 $4$ 个方向做 $O(1)$ 检查，故时间 $O(24nm)=O(7nm)$。`dis` 与队列各 $O(7nm)$。代入 $n,m\le9$：状态 $\le486$，操作 $\le$ 几千次，远低于任何时限。证毕。

### 定理

程序输出最短合法回家时间，无解时输出 `-1`。

*证明*：引理 1 把问题化为状态图最短路；引理 2 保证转移与题面死亡/拾取规则逐句一致；引理 3 保证 BFS 距离正确；引理 4 保证首次生成终态的时机给出最优值、耗尽给出无解；引理 5 说明血量维不可省略（本实现带血量维）；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 血量机制使"能否继续走"依赖当前 HP；鼠标无限次可用 ⇒ 无资源消耗维度，历史无关。
2. **consider easier version** — 先想裸 BFS（无血量），用 $2\times7$ 死胡同鼠标反例击穿"按格子判重"：同格必须以不同血量重访。
3. **reduce to easier problem** — 把"带血量的行走"等价成状态 $(x,y,hp)$ 图上的路径，问题塌缩成单位边权最短路。
4. **explore its property** — 死亡判定先于拾取/到家判定：转移先要求 $hp-1\ge1$，再补满、再认家，堵死两个题面漏洞。
5. **classic problem solution** — 单位权 BFS：首次生成家状态即最短时间；`dis` 三维数组必须显式填 INF（全局默认 $0$ 是合法距离）。
6. **discuss by category** — 起点可重访、鼠标态恒为满血、家格不入队直接返回；"每格只记最大血"的剪枝跨时刻不安全，状态数极小不值得用。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n,m` | 网格行列数，$\le9$ | `int` | 读入 |
| `a[x][y]` | 格子类型 $0..4$ | `int[mxn][mxn]` | 读入；`2` 起点 `3` 家 `4` 鼠标 |
| `sx,sy` | 起点坐标（0-based） | `int` | 读入时扫描 `a==2` 记录 |
| `dis[x][y][h]` | 状态 $(x,y,h)$ 的最短步数，兼访问标记 | `int[mxn][mxn][7]` | **`fill_n` 全填 `inf`**；`dis[sx][sy][6]=0`；$h$ 用 $1..6$ |
| `inf` | 未访问哨兵 $1145141919$ | `constexpr int` | 显著大于任何可能步数 |
| `Q[qh..qt)` | BFS 队列，元素 `{x,y,hp}` | `node[mxn*mxn*7]` | `qh=qt=0`；每状态至多入队一次 |
| `dx,dy` | 四方向偏移 | `int[4]` | 上下左右 |
| `mxn` | $9+5=14$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行；读 `n,m` 与网格，记录 `sx,sy`。
2. `fill_n(&dis[0][0][0],mxn*mxn*7,inf)`；`dis[sx][sy][6]=0`，起点入队。
3. 队首出队 `(x,y,hp)`，枚举四方向得 `(nx,ny)`：越界或 `a==0` 跳过；`nhp=hp-1`，若 `nhp==0` 跳过（先判死）；若 `a[nx][ny]==4` 则 `nhp=6`（再拾取）。
4. 若 `a[nx][ny]==3`：输出 `dis[x][y][hp]+1` 并结束（再判家）。
5. 否则若 `dis[nx][ny][nhp]==inf`：赋值 `dis[x][y][hp]+1` 并入队。
6. 队列耗尽：输出 `-1`。

### 复杂度

- 时间 $O(7nm)\le$ 几千次操作；空间 $O(7nm)$，约 $14\times14\times7\times4$ B $\approx5.5$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；六组手造数据（含死亡边界、拾取时机、同格重访反例）与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2802 回家
// 状态 (x,y,hp)：同格不同血必须允许重访（死胡同鼠标反例）
// 转移顺序：先判死(hp-1==0 即死) → 再拾取(补满 6) → 再判家
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{14},inf{1145141919};

int n,m,a[mxn][mxn],dis[mxn][mxn][7];
int dx[4]={1,-1,0,0},dy[4]={0,0,1,-1};
struct node{int x,y,hp;}Q[mxn*mxn*7];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	int sx=0,sy=0;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
		{
			cin>>a[i][j];
			if(a[i][j]==2)
				sx=i,sy=j;
		}
	fill_n(&dis[0][0][0],mxn*mxn*7,inf);	// 全局默认 0 是合法距离，必须显式填 INF
	int qh=0,qt=0;
	dis[sx][sy][6]=0;
	Q[qt++]={sx,sy,6};
	while(qh<qt)
	{
		auto[x,y,hp]=Q[qh++];
		for(int d=0;d<4;++d)
		{
			int nx=x+dx[d],ny=y+dy[d];
			if(nx<0||nx>=n||ny<0||ny>=m||a[nx][ny]==0)
				continue;
			int nhp=hp-1;
			if(nhp==0)	// 血尽即死，鼠标和家都救不回来
				continue;
			if(a[nx][ny]==4)
				nhp=6;	// 鼠标无限次，踏上即满血
			if(a[nx][ny]==3)
			{
				cout<<dis[x][y][hp]+1<<'\n';
				return 0;
			}
			if(dis[nx][ny][nhp]==inf)
			{
				dis[nx][ny][nhp]=dis[x][y][hp]+1;
				Q[qt++]={nx,ny,nhp};
			}
		}
	}
	cout<<-1<<'\n';
	return 0;
}
```

### 代码说明

- `dis` 第三维开 $7$：血量只用 $1..6$，$0$ 号位空置；`fill_n` 把整块三维数组按一维铺平填 INF，这是"全局数组默认 $0$"坑点的标准解法。
- 判死 `nhp==0` 写在拾取与判家**之前**，顺序就是题面语义；反过来写会同时放过"鼠标上复活"和"家门口阵亡"两个 hack。
- 家格不写 `dis`、不入队，直接返回——BFS 层序保证这是最短时间（引理 4）。
- 鼠标格的后继状态恒为 $(x,y,6)$，天然判重，不会因"鼠标无限次"而死循环。
- 队列容量 `mxn*mxn*7`$=1372\ge486$（实际状态上界），每个状态至多入队一次，绝不越界。
