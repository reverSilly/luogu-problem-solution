# P2615 [NOIP 2015 提高组] 神奇的幻方 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给定奇数 $N$（$1\le N\le 39$），按四条固定规则把 $1,2,\dots,N^2$ 依次填进 $N\times N$ 矩阵：$1$ 填第一行中间；之后每个 $K$ 根据 $K-1$ 的位置决定去向——第一行非末列则去最后一行右一列；末列非首行则去第一列上一行；右上角则去正下方；其余情况右上方没填就去右上方，填了就去正下方。输出矩阵。

$N^2\le 1521$，四条规则就是算法本身——**这是一道纯模拟题**，不需要任何优化。但"照着写"之前有三件事必须想清楚，写完之后还有一个值得追问的性质。

**第一步：把规则翻译成对 $(r,c)$ 的分类讨论。** 全程只需维护"上一个数 $K-1$ 的位置 $(r,c)$"，每个 $K$ 做一次 $O(1)$ 判断。翻译时抠三个细节：

1. **优先级。** 右上角 $(0,n-1)$ 同时满足"在第一行"和"在最后一列"，规则 1、2 的字面条件都带"但不在……"的排除项，所以四条规则按 $(r=0?,\ c=n-1?)$ 恰好切成互不重叠的四块，右上角单独走规则 3。代码里我按"规则 1 → 规则 2 → 规则 3 → 规则 4"的顺序写 `if-else`，每个分支自带排除条件，不会串。
2. **0-based 换算。** 第一行是 `r==0`，最后一行是 `r==n-1`；"第一行中间"是 `c=n/2`（$n$ 为奇数，`n/2` 下取整恰好等于 $(n-1)/2$，即 0-based 的正中间）；"上一行/右一列"就是 `r-1`/`c+1`。
3. **"还未填数"怎么判。** 全局数组默认 $0$，而填入的数从 $1$ 开始，所以 `a[r-1][c+1]==0` 就是"未填"。规则 4 访问 `a[r-1][c+1]` 时必有 `r>=1 && c<=n-2`（前三个分支已排除其它情况），下标天然安全。

**第二步：手算最小数据确认理解。** 题面没有样例，我自己造：

- $N=1$：只填 $1$，输出 `1`。循环 `k=2..1` 不执行，边界天然正确。
- $N=3$：$1$ 在 $(0,1)$；$2$ 走规则 1 到 $(2,2)$；$3$ 走规则 2 到 $(1,0)$；$4$ 的右上方 $(0,1)$ 已被 $1$ 占，走规则 4 下方到 $(2,0)$；$5$ 到 $(1,1)$；$6$ 到 $(0,2)$；$7$ 的上一数在右上角，走规则 3 到 $(1,2)$；$8$ 走规则 2 到 $(0,0)$；$9$ 走规则 1 到 $(2,1)$。得到

```
8 1 6
3 5 7
4 9 2
```

正是洛书，每行每列每对角线和为 $15$。规则理解无误。

**第三步：追问一个规则没有回答的问题。** 规则 4 说"右上方填了就去正下方"——可它凭什么保证**正下方一定是空的**？规则 1、2 的绕回目标又凭什么没被占过？如果某一步撞进已填格，整个构造就崩了。模拟能跑通不代表良定义，我想把"永不覆盖、永不越界、恰好填满"证出来。

盯着 $N=3$ 和 $N=5$ 的位置表看，把 $k-1$ 写成 $a\cdot n+b$（$0\le b<n$，即"第 $a$ 组、组内第 $b$ 个"），规律浮出水面：

$$r\equiv 2a-b\pmod n,\qquad c\equiv c_0-a+b\pmod n,\qquad c_0=\tfrac{n-1}{2}.$$

也就是说：**每 $n$ 个连续数是一组，组内每步走"右上方"（出界就绕回），组与组之间走"正下方"**。$N=3$ 时 $1,2,3$ 是第 $0$ 组（右上绕回），$4,5,6$ 第 $1$ 组，$7,8,9$ 第 $2$ 组；$N=5$ 时 $6$ 的右上方是 $1$（本组开头，已填）所以 $6$ 下方——完全吻合。

**第四步：这个闭式为什么对？** 两条腿：

- **不撞车**：映射 $(a,b)\mapsto(2a-b,\ c_0-a+b)$ 在模 $n$ 下是**双射**——两个同余式相加立刻得 $a\equiv a'$，再得 $b\equiv b'$，单射；定义域值域都是 $n^2$ 个元素，故双射。$n^2$ 个数占据 $n^2$ 个互异格子，恰好填满，谁也不会覆盖谁。
- **规则确实走出这个闭式**：对 $k$ 归纳。组内（$b\ge1$）时规则 1、2、4 的目标全都等于"模 $n$ 意义的右上方"，而右上角在组内**不可能出现**（它要求 $b=n-1$，见引理 3）；组边界（$b=0$）时右上方格子恰好是**本组第一个数**的位置（早已填），于是走下方，与闭式一致；唯一的右上角出现在第 $\frac{n-1}{2}$ 组末尾，规则 3 的"正下方"也与闭式一致。

至此模拟的良定义性证完，代码可以放心写。

**第五步（附赠）：它为什么"神奇"？** 用闭式算和：行、列、反对角线的和都是 $\frac{n(n^2+1)}2$；主对角线要按 $\gcd(3,n)$ 分两类，结果同样是 $\frac{n(n^2+1)}2$。题目只要求按规则输出，但这条性质解释了"幻方"二字的来历，也让第二部分的内容不只是"翻译规则"。

**手造数据核对。** $N=1,3,5$ 三组输出与手算逐格一致（$N=5$ 得到经典幻方 `17 24 1 8 15 / 23 5 7 14 16 / 4 6 13 20 22 / 10 12 19 21 3 / 11 18 25 2 9`）；另跑 $N=39$，输出的 $1521$ 个数互异（恰为 $1..1521$），所有行、列、两条对角线和均为 $29679=\frac{39\times(39^2+1)}2$，与引理 5、6 吻合。

## 二、思维链：完整证明

**记号。** 全程 0-based：行 $r\in[0,n)$，列 $c\in[0,n)$，$n$ 为奇数，$c_0=\frac{n-1}2$（整数）。数 $k\in[1,n^2]$ 唯一写成 $k=a\cdot n+b+1$，$0\le a,b<n$。定义闭式位置
$$\varphi(a,b)=\bigl((2a-b)\bmod n,\ (c_0-a+b)\bmod n\bigr).$$
程序状态：`a[r][c]` 为已填的数（$0$ 表示未填），$(r,c)$ 为上一个数的位置。

---

### 引理 1（规则分类穷尽、互斥，数组访问合法）

四条规则按 $(r=0?,\ c=n-1?)$ 把 $[0,n)^2$ 划分为四个互不相交的区域，规则 4 再按右上方占用与否二分；规则 1、2、3 的目标坐标都在 $[0,n)^2$ 内，规则 4 对 `a[r-1][c+1]` 的访问下标合法。

*证明*：布尔对 $(r=0,\ c=n-1)$ 只有四种取值：$(真,假)$ 走规则 1，$(假,真)$ 走规则 2，$(真,真)$ 走规则 3，$(假,假)$ 走规则 4。四者穷尽且互斥，`if-else` 链的书写顺序不影响结果（各分支条件已自带排除）。逐一核对：

- 规则 1：目标 $(n-1,\ c+1)$。$c\ne n-1\Rightarrow c+1\le n-1$ ✓。
- 规则 2：目标 $(r-1,\ 0)$。$r\ne0\Rightarrow r-1\ge0$ ✓。
- 规则 3：目标 $(r+1,\ c)=(1,\ n-1)$。$n=1$ 时填数循环为空、规则 3 不会执行；$n\ge3$ 时 $1\le n-1$ ✓。
- 规则 4：进入该分支时 $r\ge1,\ c\le n-2$，故读 `a[r-1][c+1]` 的下标在界内 ✓；"右上方"目标 $(r-1,c+1)$ 同理在界内 ✓。

"正下方"目标 $(r+1,c)$ 的越界问题（$r$ 可能等于 $n-1$）不在本引理处理：引理 3 将证明**每个实际执行步的目标都恰为 $\varphi(a,b)$**，而 $\varphi$ 的值是模 $n$ 代表元、必在 $[0,n)^2$ 内，从而下方目标自动在界内（具体地：组内永不走下方分支；组边界处 $r'\ne n-1$；规则 3 处 $r'=0$）。证毕。

---

### 引理 2（$\varphi$ 是双射：永不撞车的根源）

映射 $\varphi:\mathbb Z_n^2\to\mathbb Z_n^2$，$(a,b)\mapsto(2a-b,\ c_0-a+b)$ 是双射。

*证明*：先证单射。设 $\varphi(a,b)=\varphi(a',b')$，即
$$2a-b\equiv 2a'-b'\pmod n,\qquad c_0-a+b\equiv c_0-a'+b'\pmod n.$$
两式**相加**，$b$ 恰好消去：$a+c_0\equiv a'+c_0\pmod n\Rightarrow a\equiv a'$。代回第一式得 $b\equiv b'$。故 $(a,b)=(a',b')$（都在 $[0,n)^2$ 内），单射成立。

定义域与值域都是恰好 $n^2$ 个元素的有限集，单射必为满射，故双射。证毕。

**注**：这条证明对任意 $n$ 成立（不需要奇数）；$n$ 为奇数用在两处：$c_0=\frac{n-1}2$ 是整数（"第一行中间"存在），以及引理 3 中"$2$ 模 $n$ 可逆"。系数矩阵 $\begin{pmatrix}2&-1\\-1&1\end{pmatrix}$ 行列式为 $1$，是单射的结构性原因。

**推论**：$n^2$ 个数按 $\varphi$ 落位时占据 $n^2$ 个**互异**格子，即 $\{0..n-1\}^2$ 全部格子各被填恰好一次——只要规则确实走出 $\varphi$（引理 3），就永不覆盖、最终填满。

---

### 引理 3（规则实现闭式：对 $k$ 归纳）

设数 $1,2,\dots,k-1$ 已按规则填入，且对每个 $j<k$，$j=a_jn+b_j+1$ 的位置为 $\varphi(a_j,b_j)$。则数 $k=an+b+1$ 按规则填到的位置也是 $\varphi(a,b)$。

*证明*：$k=1$ 时 $a=b=0$，$\varphi(0,0)=(0,c_0)$ 正是"第一行中间" ✓。设 $k\ge2$，记 $k-1=a'n+b'+1$，其位置 $(r',c')=\varphi(a',b')$，即 $r'\equiv 2a'-b'$，$c'\equiv c_0-a'+b'$。分两大情形。

**情形 A：$b'\le n-2$（组内）。** 此时 $a=a'$，$b=b'+1$，目标闭式 $\varphi(a,b)=(r'-1\bmod n,\ c'+1\bmod n)$。

先证 **$k-1$ 不在右上角**。若在，则 $r'=0\wedge c'=n-1$，即
$$2a'-b'\equiv0,\qquad c_0-a'+b'\equiv-1\pmod n.$$
相加得 $a'\equiv-1-c_0=-\frac{n+1}2\equiv\frac{n-1}2\pmod n$，代回第一式得 $b'\equiv 2a'\equiv n-1\pmod n$，与 $b'\le n-2$ 矛盾。故右上角（规则 3）在组内不会触发。

于是只剩规则 1、2、4：

- 若 $r'=0$（则 $c'\ne n-1$）：规则 1 目标 $(n-1,\ c'+1)=(r'-1\bmod n,\ c'+1\bmod n)$ ✓。
- 若 $c'=n-1$（则 $r'\ne0$）：规则 2 目标 $(r'-1,\ 0)=(r'-1\bmod n,\ c'+1\bmod n)$ ✓。
- 否则（$r'\ge1,\ c'\le n-2$）：规则 4 检查右上方 $(r'-1,c'+1)=\varphi(a,b)$。由引理 2，格子 $\varphi(a,b)$ 只对应唯一的 $(a,b)$，而它对应的数 $k$ 尚未填（已填的数都 $<k$，位置互异），故右上方**必为空**，走右上方分支 ✓。

三个子情形的目标都等于 $\varphi(a,b)$，情形 A 成立。

**情形 B：$b'=n-1$（组边界）。** 此时 $k=(a'+1)n+1$，$a=a'+1$，$b=0$。$k-1$ 的位置满足
$$r'\equiv 2a'-(n-1)\equiv 2a'+1,\qquad c'\equiv c_0-a'+(n-1)\equiv c_0-a'-1\pmod n.$$

- **子情形 B1：$a'=\frac{n-1}2$。** 则 $r'\equiv n\equiv0$，$c'\equiv c_0-\frac{n-1}2-1=-1\equiv n-1$：$k-1$ 恰在右上角，规则 3 触发，目标 $(r'+1,c')=(1,n-1)$。而 $\varphi(a'+1,0)=(2a'+2,\ c_0-a'-1)\equiv(1,\ -1)=(1,n-1)$ ✓。
- **子情形 B2：$a'\ne\frac{n-1}2$。** 先排除规则 1、2、3：$r'=0\iff 2a'\equiv-1\iff a'\equiv\frac{n-1}2$（$n$ 奇 ⇒ $2$ 模 $n$ 可逆，$-1\cdot2^{-1}=\frac{n-1}2$），已排除；$c'=n-1\iff c_0-a'-1\equiv-1\iff a'\equiv c_0=\frac{n-1}2$，同样排除。故走规则 4。右上方格子为
$$(r'-1\bmod n,\ c'+1\bmod n)=(2a',\ c_0-a')=\varphi(a',0),$$
它是数 $a'n+1$ 的位置。由 $a'n+1\le a'n+n=k-1$，该数**已填**，右上方被占，走"正下方"分支，目标
$$(r'+1,\ c')=(2a'+2,\ c_0-a'-1)=\varphi(a'+1,0)=\varphi(a,b)\ ✓.$$
（下方不越界：本步执行意味着 $k\le n^2$，即 $(a'+1)n=k-1\le n^2-1$，故 $a'\le n-2$。若 $r'=n-1$，则 $2a'+1\equiv-1\Rightarrow 2a'\equiv-2\Rightarrow a'\equiv-1\equiv n-1$（$2$ 模 $n$ 可逆），与 $a'\le n-2$ 矛盾。故 $r'\le n-2$，$r'+1\le n-1$ ✓。）

两大情形穷尽（$b'\le n-2$ 或 $b'=n-1$），归纳完成。证毕。

### 推论 4（模拟良定义：不覆盖、不越界、恰好填满）

程序对 $k=2..n^2$ 的每一步：目标格子在 $[0,n)^2$ 内、此前未填、填入后 $1..n^2$ 各占一格，最终矩阵是 $1..n^2$ 的一个排列。

*证明*：对 $k$ 归纳，引理 3 给出"第 $k$ 步目标 $=\varphi(a,b)$"。$\varphi(a,b)$ 是模 $n$ 代表元，在界内；由引理 2 的单射性，它与所有 $j<k$ 的位置 $\varphi(a_j,b_j)$ 不同，故未填，赋值 `a[r][c]=k` 不构成覆盖；引理 1 中所有数组访问的下标都由"目标在界内"与分支条件保证合法。$n^2$ 步后由引理 2 的满射性，每格恰被填一次。证毕。

### 引理 5（行和、列和、反对角线和）

每一行、每一列、反对角线（$r+c=n-1$）上的数之和都等于 $M=\frac{n(n^2+1)}2$。

*证明*：数 $k=an+b+1$ 落在 $\varphi(a,b)$。由引理 2，固定行 $r$ 时，满足 $2a-b\equiv r$ 的 $(a,b)$ 恰有 $n$ 对：对每个 $a\in\mathbb Z_n$，$b\equiv 2a-r$ 唯一确定，且 $a$ 跑遍 $\mathbb Z_n$ 时 $b$ 也跑遍 $\mathbb Z_n$（$b=2a-r$ 是 $\mathbb Z_n$ 上的双射，$n$ 奇 ⇒ $2$ 可逆）。于是
$$\text{行和}=\sum_{a=0}^{n-1}(an+1)+\sum_{b=0}^{n-1}b=n\cdot\frac{n(n-1)}2+n+\frac{n(n-1)}2=\frac{n(n^2-1)}2+n=\frac{n(n^2+1)}2.$$

固定列 $c$：$c_0-a+b\equiv c\Rightarrow b\equiv c-c_0+a$，$a$ 跑遍时 $b$ 跑遍（系数 $1$ 可逆），求和与上式逐项相同，列和 $=M$。

反对角线 $r+c\equiv n-1$：两式相加 $(2a-b)+(c_0-a+b)=a+c_0\equiv n-1\Rightarrow a\equiv n-1-c_0=\frac{n-1}2$ **固定**，$b$ 自由跑遍 $\mathbb Z_n$。于是
$$\text{反对角线和}=\sum_{b=0}^{n-1}\Bigl(\frac{n-1}2\cdot n+b+1\Bigr)=n\Bigl(\frac{n(n-1)}2+1\Bigr)+\frac{n(n-1)}2=\frac{n(n^2+1)}2=M.$$
证毕。

### 引理 6（主对角线和：按 $\gcd(3,n)$ 分类）

主对角线（$r=c$）上的数之和也等于 $M=\frac{n(n^2+1)}2$。

*证明*：$r\equiv c\iff 2a-b\equiv c_0-a+b\iff 3a\equiv c_0+2b\pmod n$。

**情形 1：$3\nmid n$。** $3$ 模 $n$ 可逆，对每个 $b$ 有唯一 $a\equiv3^{-1}(c_0+2b)$。$n$ 奇且 $3\nmid n$ ⇒ $2\cdot3^{-1}$ 模 $n$ 可逆 ⇒ $b$ 跑遍 $\mathbb Z_n$ 时 $a$ 也跑遍。与引理 5 的行和完全同构：和 $=n\cdot\frac{n(n-1)}2+n+\frac{n(n-1)}2=M$。

**情形 2：$3\mid n$。** 写 $n=3m$，$n$ 奇 ⇒ $m$ 奇。先算 $c_0\bmod 3$：$c_0=\frac{3m-1}2$，模 $3$ 下 $3m-1\equiv2$，$2^{-1}\equiv2$，故 $c_0\equiv2\cdot2=1\pmod3$。

同余式 $3a\equiv c_0+2b\pmod{3m}$ 有解 $\iff 3\mid(c_0+2b)\iff 1+2b\equiv0\pmod3\iff b\equiv1\pmod3$。故对角线上的数恰对应 $b=1+3j$（$j=0..m-1$），每个这样的 $b$ 给出 $3$ 个 $a$。

固定 $b=1+3j$，令 $t=\frac{c_0+2b}3=\frac{c_0+2}3+2j=\frac{m+1}2+2j$（$\frac{c_0+2}3=\frac{(3m-1)/2+2}3=\frac{m+1}2$，$m$ 奇故为整数）。则 $3a\equiv3t\pmod{3m}\iff a\equiv t\pmod m$，$[0,n)$ 内的三个解为 $a_0,\ a_0+m,\ a_0+2m$，其中 $a_0=t\bmod m$。三个解之和 $=3a_0+3m$。

$j$ 跑遍 $0..m-1$ 时 $2j\bmod m$ 跑遍 $\mathbb Z_m$（$m$ 奇 ⇒ $2$ 可逆），故 $a_0$ 跑遍 $\mathbb Z_m$，$\sum_j a_0=\frac{m(m-1)}2$。对角线总和：
$$\sum_{j=0}^{m-1}\Bigl[n(3a_0+3m)+3(b+1)\Bigr]=3n\cdot\frac{m(m-1)}2+3nm^2+\sum_{j=0}^{m-1}(9j+6).$$
代入 $n=3m$：
$$=\frac{9m^2(m-1)}2+9m^3+\frac{9m(m-1)}2+6m=\frac{9m}2\bigl(m^2-1\bigr)+9m^3+6m=\frac{27m^3+3m}2=\frac{3m(9m^2+1)}2=\frac{n(n^2+1)}2=M.$$
两情形都得 $M$。证毕。

（$n\le39$ 中 $3\mid n$ 的有 $3,9,15,21,27,33,39$，情形 2 不是空谈；$N=3$ 时主对角线 $8+5+2=15=M$ ✓。）

### 引理 7（复杂度）

时间 $O(N^2)$，空间 $O(N^2)$。

*证明*：填数循环执行 $N^2-1$ 次，每次是常数次比较与赋值（引理 1 的分支互斥，无内层循环）；输出 $N^2$ 个数。故时间 $O(N^2)\le1521$ 步。空间为一个 $N\times N$ 的 `int` 矩阵，$45\times45\times4\approx8$ KB。证毕。

---

### 定理

程序输出的矩阵恰为按题面四条规则构造的 $N\times N$ 幻方：它是 $1..N^2$ 的排列，且每行、每列、两条对角线之和均为 $\frac{N(N^2+1)}2$。

*证明*：引理 1 + 引理 3 + 推论 4 保证模拟良定义、每步与规则逐字一致、输出是 $1..N^2$ 的排列；引理 5、6 保证幻方性质；引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 四条规则本质是对 $K-1$ 位置 $(r,c)$ 的 $(r=0?,c=n-1?)$ 四象限分类；右上角是规则 1/2 条件的重叠区，必须单独处理。
- **consider easier version** — 手算 $N=1,3,5$ 确认规则翻译无误（$N=3$ 得洛书）。
- **classic problem solution** — 直接模拟：维护上一个数的位置，$O(N^2)$ 逐数填写，无需任何数据结构。
- **explore its property** — 观察位置表发现闭式：$k=an+b+1\Rightarrow(r,c)\equiv(2a-b,\ c_0-a+b)\pmod n$，组内右上、组间正下。
- **reduce to easier problem** — "永不撞车、恰好填满"归约为模 $n$ 线性映射的单射性：两个同余式相加即得 $a\equiv a'$，双射立现。
- **discuss by category** — 归纳验证规则与闭式一致：组内（右上）/ 组边界（下方）/ 右上角（规则 3）三类位置分别核对。
- **explore its property** — 行/列/反对角线和恒为 $\frac{n(n^2+1)}2$；主对角线按 $\gcd(3,n)=1$ 或 $3$ 分类求和，解释"神奇"。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 幻方阶数，奇数 $\le39$ | `int`，读入 | $N^2\le1521$ |
| `a[r][c]` | 矩阵，$0$ 表示未填 | `int[mxn][mxn]`，全局默认 $0$ | 填 $1..n^2$，$0$ 兼作"未填"哨兵 |
| `r,c` | 上一个数 $K-1$ 的位置 | `int`，初值 `(0,n/2)` | 0-based；`n/2` 即奇数 $n$ 的正中间列 |
| `k` | 当前要填的数 | `int`，$2..n^2$ | 每步 $O(1)$ 分类 |
| `nr,nc` | 本步目标位置 | `int`，每步现算 | 四个规则分支之一 |
| `mxn` | $39+5=44$，取 $45$ | `constexpr int{45}` | +5 松弛 |
| $c_0,\varphi$ | 证明用闭式，代码不出现 | — | $c_0=\frac{n-1}2$，$\varphi(a,b)=(2a-b,c_0-a+b)\bmod n$ |

### 算法步骤

1. I/O 加速三行；读入 `n`。
2. `r=0,c=n/2`，`a[r][c]=1`。
3. 对 `k=2..n*n`：按 `(r==0&&c!=n-1)` / `(c==n-1&&r!=0)` / `(r==0&&c==n-1)` / `a[r-1][c+1]==0` / 否则，五个分支算出 `(nr,nc)`（依次对应规则 1、2、3、4 右上、4 下方）；令 `r=nr,c=nc`，`a[r][c]=k`。
4. 逐行输出，数间单空格，行末 `'\n'`。

### 复杂度

- 时间 $O(N^2)\le1521$ 步；空间 $O(N^2)\approx8$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$N=1,3,5$ 输出与手算逐格一致（$N=3$ 洛书、$N=5$ 经典幻方）；$N=39$ 输出含 $1521$ 个互异的数，全部行、列、两对角线和均为 $29679=\frac{39(39^2+1)}2$，与引理 5、6 吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2615 [NOIP 2015 提高组] 神奇的幻方
// 思路：纯模拟。记录上一个数 K-1 的位置 (r,c)，按四条规则分类讨论填 K。
//       规则 3（右上角）必须先于规则 1/2 判断；规则 4 用 a[r-1][c+1]==0 判空。
//       0-based：第一行 r=0，中间列 c=n/2（n 为奇数），最后一行/列 n-1。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{45};

int n,a[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	int r=0,c=n/2;
	a[r][c]=1;
	for(int k=2;k<=n*n;++k)
	{
		int nr,nc;
		if(r==0&&c!=n-1)
			nr=n-1,nc=c+1;			// 规则 1：第一行非末列 → 最后一行右一列
		else if(c==n-1&&r!=0)
			nr=r-1,nc=0;			// 规则 2：末列非首行 → 第一列上一行
		else if(r==0&&c==n-1)
			nr=r+1,nc=c;			// 规则 3：右上角 → 正下方
		else if(a[r-1][c+1]==0)
			nr=r-1,nc=c+1;			// 规则 4：右上方未填 → 右上方
		else
			nr=r+1,nc=c;			// 规则 4：右上方已填 → 正下方
		r=nr;c=nc;
		a[r][c]=k;
	}
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			cout<<a[i][j]<<(j==n-1?'\n':' ');
	return 0;
}
```

### 代码说明

- **分支顺序即优先级**：规则 1、2 的条件自带"但不在……"排除项，右上角只会落进第三个分支；即使把规则 3 写在最前也等价，但当前写法与题面编号一一对应，最不易错。
- **`a[r-1][c+1]==0` 判空**：全局数组默认 $0$，填入的数 $\ge1$，$0$ 恰好兼作"未填"标记，不需要额外的 `vis` 数组。
- **下标安全**：进入规则 4 时必有 `r>=1 && c<=n-2`，`a[r-1][c+1]` 不越界；"正下方"分支的 `r+1` 不越界由引理 3 保证（组内不走下方，组边界处 $r'\ne n-1$）。
- **$N=1$ 边界**：`k=2..1` 循环为空，直接输出 `1`，无需特判。
- 输出用 `(j==n-1?'\n':' ')` 控制"数间单空格、行末换行"，符合题面格式。
