# P2010 [NOIP 2016 普及组] 回文日期 — 题解

## 一、解题过程：人类思考叙事

题目要求统计区间 $[date_1, date_2]$ 内有多少个**真实存在**的日期，其 8 位数字表示是回文。

最朴素的想法：把区间里的每一天都枚举出来，判断是否回文。但区间可以跨很多年，比如 `20000101` 到 `20101231`，这有 4000 多年、150 万多天——虽然也能枚举，但每天都要做除法取模判断是否回文，$O(\text{天数})$ 的常数不小，而且完全没有利用「回文」这个结构的性质。

换个角度想：8 位数字 `YYYYMMDD` 是回文，意味着第 1 位 = 第 8 位，第 2 位 = 第 7 位，第 3 位 = 第 6 位，第 4 位 = 第 5 位。

把年份的 4 位记作 $a\,b\,c\,d$（千位 $a$、百位 $b$、十位 $c$、个位 $d$），那么整个 8 位串必须是

$$a\ b\ c\ d\ d\ c\ b\ a$$

也就是说：**月 = $d\,c$，日 = $b\,a$**。

这个观察太关键了——年份一旦确定，月和日就被**唯一确定**了！也就是说，一个年份最多对应一个回文日期。

于是枚举的对象从「区间内的每一天」变成了「区间内的每一个年份」，每个年份只需 $O(1)$ 的检查。

而且年份数量也很少：4 位年份最多 10000 个，$10^4$ 相比 $1.5\times 10^6$ 降了两个数量级。

具体做法：枚举年份 $y$，从 $y$ 的十进制表示中取出各位：

- 月 $mo = (y \bmod 10)\times 10 + \lfloor y/10 \rfloor \bmod 10$，即把年份的最后两位**倒过来**；
- 日 $da = \lfloor y/100 \rfloor \bmod 10 \times 10 + \lfloor y/1000 \rfloor$，即把年份的前两位倒过来。

验证一下 $y=2010$：$mo = 0\times 10 + 1 = 1$（月 = 1），$da = 1\times 10 + 2 = 12$？等等，$y=2010$，千位=2，百位=0，十位=1，个位=0。$da$ 应为「百位千位」倒过来 = $b\,a = 0\,2 = 2$，即 2 日。而 `20100102` 确实是回文。✓

再看 $y=2011$：$mo = 1\times 10 + 1 = 11$（11 月），$da = 0\times 10+2 = 2$？但样例说明里说样例 1 的回文日期是 `20111102`。所以 $da$ = 02，即百位 $b=0$，千位 $a=2$ → $da = 02$ = 2 日。对，`20111102` 的末两位是 `02`，前面是 `2011`，回文成立。✓

那么 $mo = 11$（年份后两位倒过来：11 → 11），$da = 02$（年份前两位倒过来：20 → 02）。$y=2011$ → `20111102`。✓ 完全一致。

接下来是合法性检查：

1. $mo$ 必须在 $[1,12]$；
2. $da$ 必须在 $[1, \text{该月天数}]$；
3. 2 月的天数取决于闰年：闰年判据是「被 4 整除但不被 100 整除」或「被 400 整除」。

最后把算出的日期 `y*10000+mo*100+da` 与区间端点比较，落在 $[date_1, date_2]$ 内就计数。

关于比较：直接比整数即可，因为 `YYYYMMDD` 这种 8 位零填充的十进制表示，其整数大小顺序与日期先后顺序一致（前 4 位是年，年相同比月，月相同比日）。而且题面保证年份部分是 4 位且首位不为 0，所以不会出现「位数不同」导致的字典序与数值序不一致问题。

枚举范围：$y$ 从 $date_1$ 的年份到 $date_2$ 的年份。但注意边界年份——年份 $y_1$ 对应的候选回文日期可能**早于** $date_1$（比如 $date_1 = 20100115$，年份 2010 的候选是 `20100102`，早于区间起点），所以不能只看年份是否在区间内，必须算完具体日期再比较整数值。代码里正是这么做的。

样例 1：`20110101` ~ `20111231`。枚举年份 2011 → 候选 `20111102`，落在区间内，答案 1。✓
样例 2：`20000101` ~ `20101231`。年份 2001 → 候选 `20011002`（$mo$=01, $da$=02），在区间内；年份 2010 → 候选 `20100102`，在区间内。答案 2。✓

## 二、思维链：完整证明

**引理 1**：若日期 $y$ 的 8 位数字表示为回文，且年份的 4 位十进制表示为 $a\,b\,c\,d$（$a$ 为千位，$a\ne 0$），则该日期的月为 $10d+c$、日为 $10b+a$。

*证明*：8 位串按位记为 $s_1s_2\cdots s_8$，其中 $s_1=a, s_2=b, s_3=c, s_4=d, s_5=\text{月十位}, s_6=\text{月个位}, s_7=\text{日十位}, s_8=\text{日个位}$。回文的定义是对所有 $1\le i\le 8$ 有 $s_i = s_{9-i}$。取 $i=4$ 得 $s_4=s_5$，即 $d=\text{月十位}$；取 $i=3$ 得 $s_3=s_6$，即 $c=\text{月个位}$。故月 $=10d+c$。取 $i=2$ 得 $s_2=s_7$，即 $b=\text{日十位}$；取 $i=1$ 得 $s_1=s_8$，即 $a=\text{日个位}$。故日 $=10b+a$。证毕。

**引理 2**：每个年份至多对应一个回文日期。

*证明*：由引理 1，给定年份的 4 位数字后，月与日被唯一确定，故候选日期至多一个。证毕。

**引理 3**：日期 $y$（年份为 $y$）是回文日期当且仅当：令 $mo = 10(y\bmod 10)+\lfloor y/10\rfloor \bmod 10$，$da = 10(\lfloor y/100\rfloor \bmod 10)+\lfloor y/1000\rfloor$，则 $1 \le mo \le 12$、$1 \le da \le \text{days}(y,mo)$。

*证明*：

（$\Rightarrow$）若 $y$ 对应的某个日期是回文，则由引理 2，该日期只能是 $mo, da$ 这一个。它既然是真实存在的日期，则其月必在 $[1,12]$，其日必在 $[1,\text{days}(y,mo)]$（2 月的天数由闰年规则给出）。故条件必要。

（$\Leftarrow$）若上述条件成立，则由 $mo,da$ 构成的日期真实存在（月份合法、日不超该月天数），且其 8 位表示为 $a\,b\,c\,d\,d\,c\,b\,a$（回引理 1 的推导），逐位满足 $s_i=s_{9-i}$，故为回文。证毕。

**引理 4**：算法枚举的年份集合覆盖了区间内所有可能的回文日期。

*证明*：设区间内存在一个回文日期 $D$，其年份为 $y$。由于 $D$ 的 8 位表示的前 4 位就是年份，而区间端点 $date_1, date_2$ 的前 4 位分别是它们的年份，由「$date_1 \le D \le date_2$」在「年→月→日」的字典序下可得 $\text{year}(date_1) \le y \le \text{year}(date_2)$。故 $y$ 必在算法枚举的年份区间内，不会被漏掉。证毕。

**引理 5**：用整数比较 $cur = y\times 10^4+mo\times 10^2+da$ 与 $date_1, date_2$ 的大小，等价于比较日期的先后。

*证明*：$cur$ 的十进制展开恰为年份 4 位、月份 2 位、日 2 位的零填充拼接（年份固定 4 位且首位非零，$mo, da \in[1,31]$ 均可写成 2 位零填充）。对两个这样的 8 位数，数值大小由最高的不同位决定，而该位在 8 位串中的位置顺序与「年 → 月 → 日」的比较顺序一致（高位先比年份，年相同比月，月相同比日）。故数值序与日期序一致。证毕。

**引理 6**：算法统计出的数量恰为区间内回文日期的个数。

*证明*：由引理 4，每个区间内的回文日期其年份必被枚举到；由引理 3，在该年份处，算法计算出的 $(mo,da)$ 恰为该回文日期（引理 2 保证唯一），并通过合法性检查，故不会漏计。由引理 5，合法性检查通过后与区间端点的比较等价于日期在区间内的判断，故不会误计区间外的日期。又由引理 2，每个年份最多贡献 1，不会重复计数。故计数正确。证毕。

**定理**：算法输出的答案正确。

*证明*：由引理 6，计数正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别枚举粒度** — 逐日枚举是 $O(\text{天数})$；注意到「回文」这个约束能大幅压缩枚举空间。
2. **关键结构发现** — 8 位回文 ⟹ 后 4 位由前 4 位唯一确定，**年份决定月日**（引理 1、2）。
3. **枚举对象降维** — 从「每一天」降为「每一个年份」，$O(10^4)$ 级别。
4. **合法性校验** — 月份范围、日是否超月天数、闰年 2 月特殊处理。
5. **区间判定用整数值比较** — `YYYYMMDD` 的数值序 = 日期序（引理 5）。
6. **边界坑** — 边界年份的候选日期可能落在区间外，必须算完完整日期再比较，不能只判年份。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $date_1$ | 区间起始日期（8 位整数） | `int`，$10000101 \le date_1$ |
| $date_2$ | 区间结束日期（8 位整数） | `int` |
| $y_1,y_2$ | 起止日期的年份 | `int`，4 位 |
| $y$ | 当前枚举的年份 | `int` |
| $mo$ | 由年份推出的月份 | `int`，$[1,12]$ |
| $da$ | 由年份推出的日 | `int`，$[1,31]$ |
| $cur$ | 候选回文日期的 8 位整数值 | `int` |
| `isleap(y)` | 判断 $y$ 是否为闰年 | `bool` |
| `mdays(y,m)` | $y$ 年 $m$ 月的天数 | `int` |

### 算法步骤

1. 读入 $date_1, date_2$。
2. 取 $y_1 = date_1 / 10000$，$y_2 = date_2 / 10000$。
3. 初始化 `ans = 0`。
4. 对 $y = y_1, y_2, \dots$：
   1. 计算 $mo = (y \bmod 10)\times 10 + (y/10) \bmod 10$（年份后两位倒序）。
   2. 计算 $da = (y/100 \bmod 10)\times 10 + y/1000$（年份前两位倒序）。
   3. 若 $mo \notin [1,12]$，跳过本年。
   4. 若 $da \notin [1, \text{mdays}(y,mo)]$，跳过本年。
   5. 计算 $cur = y\times 10^4 + mo\times 10^2 + da$。
   6. 若 $date_1 \le cur \le date_2$，则 `ans++`。
5. 输出 `ans`。

### 闰年与月天数

- `isleap(y)`：`(y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)`。
- `mdays(y, 2)` 在闰年时为 29，平年为 28；其余月份查表 `md[13] = {0,31,28,31,30,31,30,31,31,30,31,30,31}`。

### 复杂度

- 时间复杂度：$O(y_2-y_1+1)$，年份跨度最多 $10^4$。
- 空间复杂度：$O(1)$（仅一张 13 元素月份表）。

### 验证状态

- 标程 `P2010.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面样例 1（`20110101` / `20111231`）输出 `1`；样例 2（`20000101` / `20101231`）输出 `2`，均与官方一致。
- 编写暴力 `P2010_brute.cpp`（逐日枚举区间内所有真实日期，用独立的 8 位回文判定函数 `ispal()` 统计）与对拍脚本 `P2010_check.py`，在随机日期区间上对拍 **200 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2010 [NOIP 2016 普及组] 回文日期
// 枚举年份：由年份唯一确定候选回文日期 abcd -> dc 月 ba 日
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{5};

int d1,d2;

bool isleap(int y)
{
	return (y%4==0&&y%100!=0)||(y%400==0);
}

int mdays(int y,int m)
{
	static const int md[13]={0,31,28,31,30,31,30,31,31,30,31,30,31};
	if(m==2&&isleap(y))
		return 29;
	return md[m];
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>d1>>d2;
	int y1=d1/10000,y2=d2/10000;
	int ans=0;
	for(int y=y1;y<=y2;++y)
	{
		//回文日期 abcd dc ba
		int mo=(y%10)*10+(y/10)%10;
		int da=(y/100%10)*10+y/1000;
		if(mo<1||mo>12)
			continue;
		if(da<1||da>mdays(y,mo))
			continue;
		int cur=y*10000+mo*100+da;
		if(cur>=d1&&cur<=d2)
			++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `mo` 与 `da` 的计算式直接对应引理 1：月份是年份后两位的倒序，日期是年份前两位的倒序。
- `mdays` 用 `static const int md[13]` 存放平年月天数，只有 2 月需要按闰年特判，其余直接查表。
- 区间判定必须用完整的 `cur`（含月日）而不是只判年份——边界年份的候选回文日期可能落在区间之外。
- `cur` 的最大值为 $99991231 < 2^{31}-1$，`int` 足够。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
