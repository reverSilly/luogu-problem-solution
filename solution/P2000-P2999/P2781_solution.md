# P2781 传教 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一排 $n$ 个人，编号 $1\sim n$，初始信仰值全为 $0$。$m$ 个操作依次给出：操作 `1 l r k` 把 $[l,r]$ 内每个人的信仰值加 $k$；操作 `2 l r` 询问 $[l,r]$ 内信仰值之和。数据范围：$1\le n\le 10^9$，$1\le m\le 10^3$，$1\le l\le r\le n$，$k\le 10$。子任务：$n,m\le 10$；$n,m\le 10^3$；$n,m\le 10^9$ 且**特殊性质 A（没有传教操作）**；最后才是 $n\le 10^9$ 的一般情况。

**第一步：条件反射与立刻碰壁。** "区间加、区间求和"——线段树或树状数组的标准模板题。但看一眼 $n$ 就清醒了：$n\le 10^9$，光是开一个 `long long a[1000000000]` 就要 $8$ GB，线段树 $4$ 倍空间更是天文数字。**下标范围高达 $10^9$，任何"按人开数组"的做法都死了。** 动态开点线段树倒是可行（每次操作只新建 $O(\log n)$ 个节点，$m\le 10^3$ 次操作总共约 $6\times 10^4$ 个节点），标签里的"线段树"大概就是指它。但先别急着写——再看看另一个约束。

**第二步：$m\le 10^3$ 小得反常。** 出题人把 $n$ 放到 $10^9$，却把 $m$ 压到 $10^3$，这个组合在暗示：**复杂度应该只和 $m$ 有关，和 $n$ 无关**。特殊性质 A 更是把话挑明了：没有传教操作时答案恒为 $0$——也就是说，**所有非零的信仰值都来自至多 $m$ 次传教操作**，人群本身只是一块"被涂色的画布"，我们根本不需要逐人维护它。

**第三步：探性质——信仰值是操作的线性叠加。** 盯着"每个人初始为 $0$、每次操作给一段人加 $k$"看：第 $p$ 个人在任意时刻的信仰值，恰好等于**此前所有覆盖他的传教操作的 $k$ 之和**：

$$\text{value}(p)=\sum_{j\text{ 是此前的传教操作}} k_j\cdot[\,l_j\le p\le r_j\,].$$

操作之间互不干扰（加法可交换），这就是叠加原理。于是询问 $[l,r]$ 的答案是

$$\sum_{p=l}^{r}\text{value}(p)=\sum_{p=l}^{r}\ \sum_{j} k_j\cdot[\,p\in[l_j,r_j]\,].$$

**第四步：交换求和号——整道题塌缩成"区间交"。** 上面是有限双重求和，交换顺序完全合法：

$$\sum_{j} k_j\cdot\bigl|[l,r]\cap[l_j,r_j]\bigr|.$$

翻译成人话：**每次询问，把它之前的每次传教操作翻出来，算两个区间的交有多长，乘上 $k$，累加。** 两个整数区间的交就是 $[\max(l,l_j),\min(r,r_j)]$，长度 $\max(0,\min(r,r_j)-\max(l,l_j)+1)$，一行算完。

这就是标签里的"枚举"。每次询问 $O(\text{已有操作数})\le 10^3$，总复杂度 $O(m^2)\le 10^6$，$n=10^9$ 从头到尾没参与运算——它只保证坐标装得下 `int`。**不需要线段树，不需要离散化，不需要任何数据结构**，一个存操作的数组就够了。

回头对比一下离散化思路（把 $\le 2m$ 个端点排序、压成 $\le 2m+1$ 段原子区间，再在压缩数组上差分/线段树）：它同样把复杂度降到只含 $m$，但要多写排序、映射、维护三套东西。既然询问可以直接对操作枚举，离散化就是不必要的中间层。**"先想数据结构，再发现数据规模允许暴力枚举操作本身"，是本题的思维捷径。**

**第五步：抠边界。**

1. **溢出。** 单次贡献 $k\times\text{长度}\le 10\times 10^9=10^{10}$，远超 `int` 上限 $2.1\times 10^9$；总和 $\le m\cdot 10\cdot n=10^{13}$。**必须 `long long`**，而且乘积要先转 `i64` 再乘（`(i64)k*(hi-lo+1)`），否则 `int*int` 在乘法那一步就炸了。
2. **只有"此前"的操作算数。** 询问之后的传教不影响本次答案，所以在线读入、只枚举已存下的操作即可，不用离线。
3. **没有传教操作时** `cnt=0`，循环体不执行，`ans=0`——特殊性质 A 自动成立，不用特判。
4. **$k$ 的下界题面没写**（只写了 $k\le 10$）。叠加原理对任意整数 $k$（含负数、零）都成立，代码不做任何符号假设，天然稳健。
5. **0-based。** 读入 `l,r` 后 `--l;--r`，区间交公式在 0-based 下原样成立（长度仍是 `hi-lo+1`）。

**手造数据核对**（题面没有给样例输入输出，只有样例说明，我按说明反推一组，再另造三组打边界）：

第一组，按样例说明反推。说明说"一开始答案爲 $0$；到第五个操作时五个人的信仰值为 $0,7,7,15,6$，答案为 $7+15=22$"。反推出操作序列：先询问 `2 1 5`（得 $0$），再 `1 2 3 7`、`1 4 5 6`、`1 4 4 9`（此时信仰值恰为 $0,7,7,15,6$），最后询问 `2 3 4`（得 $7+15=22$）：

```
输入                 输出
5 5                  0
2 1 5                22
1 2 3 7
1 4 5 6
1 4 4 9
2 3 4
```

与说明逐条吻合。

第二组，专打 $n=10^9$ 与溢出：`1 1 1000000000 10` 后询问全段，答案 $10^{10}$（`int` 版会在这里翻车）；询问 `5 6` 得 $20$。第三组，特殊性质 A：两次询问都输出 $0$。第四组，专打区间交的边界（相接但不重叠的 $[1,2]$ 与 $[3,5]$）：信仰值 $3,3,4,4,4$，询问 `2 3` 得 $7$、`1 5` 得 $18$。四组全部手算一致。

## 二、思维链：完整证明

**记号。** 操作按输入顺序编号 $1\sim m$。第 $j$ 个传教操作记为 $(l_j,r_j,k_j)$，区间 $I_j=[l_j,r_j]$（整数闭区间，证明中用 1-based，与 0-based 只差一个平移，不影响任何结论）。询问 $q$ 记为 $[l,r]$，其"前缀"指输入顺序在 $q$ 之前的所有操作。$\text{value}_q(p)$ 表示处理完 $q$ 的前缀后第 $p$ 个人的信仰值。$[P]$ 为命题 $P$ 的指示函数（真为 $1$，假为 $0$）。

---

### 引理 1（叠加原理：信仰值 = 覆盖操作的 $k$ 之和）

对任意时刻（任意操作前缀）与任意人 $p$：

$$\text{value}(p)=\sum_{j\in\text{前缀中的传教操作}} k_j\cdot[\,p\in I_j\,].$$

*证明*：对前缀长度 $t$ 归纳。

$t=0$：无人被传教，$\text{value}(p)=0$（题面初始条件），右端是空和 $=0$ ✓。

设前缀长 $t-1$ 时成立。第 $t$ 个操作若是询问，不改变任何信仰值，前缀中的传教操作集合也不变，等式两边都不变 ✓。若是传教 $(l_t,r_t,k_t)$，题面规定"第 $l_t$ 到第 $r_t$ 个人信仰值增加 $k_t$"，即

$$\text{value}'(p)=\text{value}(p)+k_t\cdot[\,p\in I_t\,].$$

由归纳假设代入，右端恰好多出第 $t$ 项，等式对长 $t$ 的前缀成立 ✓。归纳完成。证毕。

**注**：证明只用了"每次操作是加一个常数"这一线性结构，对 $k$ 的符号、大小零假设。这就是"$k$ 下界未给也稳健"的根据。

---

### 引理 2（整数区间交的显式公式）

对整数闭区间 $[a,b]$、$[c,d]$（$a\le b$，$c\le d$）：

$$[a,b]\cap[c,d]=[\max(a,c),\ \min(b,d)],$$

且交中整数个数为 $\max\bigl(0,\ \min(b,d)-\max(a,c)+1\bigr)$。

*证明*：$p\in[a,b]\cap[c,d]\iff (a\le p\le b)\land(c\le p\le d)\iff \max(a,c)\le p\le\min(b,d)$（两个下界取大、两个上界取小，是 $\land$ 的直接改写）。故交是闭区间 $[\max(a,c),\min(b,d)]$；当 $\max(a,c)>\min(b,d)$ 时它是空集。

计数：非空整数区间 $[u,v]$ 中的整数为 $u,u+1,\dots,v$，共 $v-u+1$ 个（对 $v-u$ 归纳即得）；空集为 $0$ 个。合并写即 $\max(0,v-u+1)$。证毕。

**推论**：代码中 `lo=max(l,op[j].l), hi=min(r,op[j].r)`，`if(lo<=hi) ans+=k*(hi-lo+1)` 恰好计算 $k_j\cdot|[l,r]\cap I_j|$（`lo>hi` 时贡献为 $0$，跳过等价）。

---

### 引理 3（交换求和：询问答案 = $\sum_j k_j\cdot$ 交长）

设询问 $q=[l,r]$ 的前缀中有传教操作 $j=1..c$（按输入顺序重编号），则

$$\text{ans}(q)=\sum_{p=l}^{r}\text{value}_q(p)=\sum_{j=1}^{c} k_j\cdot\bigl|[l,r]\cap I_j\bigr|.$$

*证明*：由引理 1，

$$\sum_{p=l}^{r}\text{value}_q(p)=\sum_{p=l}^{r}\sum_{j=1}^{c} k_j\cdot[\,p\in I_j\,].$$

这是**有限**双重求和（$p$ 至多 $n$ 项、$j$ 至多 $c$ 项），有限和可以任意交换次序（加法交换律 + 结合律对项数归纳）。交换后：

$$\sum_{j=1}^{c} k_j\sum_{p=l}^{r}[\,p\in I_j\,]=\sum_{j=1}^{c} k_j\cdot\bigl|\{p\in[l,r]:p\in I_j\}\bigr|=\sum_{j=1}^{c} k_j\cdot\bigl|[l,r]\cap I_j\bigr|.$$

中间一步：指示函数对 $p$ 求和就是计数集合元素个数。最后用引理 2 把交长写成 $\max(0,\min(r,r_j)-\max(l,l_j)+1)$。证毕。

**这条引理是全题的核心**：它把"对 $10^9$ 个人求和"换成了"对 $\le 10^3$ 个操作求和"。$n$ 从此只出现在坐标数值里，不出现在循环次数里。

---

### 引理 4（因果性：只需枚举"此前"的操作）

询问 $q$ 的答案只依赖输入顺序在 $q$ 之前的传教操作；之后的操作不影响 $\text{ans}(q)$。

*证明*：题面规定操作**依次**执行，询问输出的是"当前"信仰值之和。由引理 1，$\text{value}_q(p)$ 的表达式只含 $q$ 前缀中的操作；后续操作改变的是更晚时刻的 $\text{value}$，与 $\text{value}_q$ 无关。故在线算法"读入一个操作就处理一个、询问时只扫已存下的 `op[0..cnt-1]`"与离线重排等价。证毕。

---

### 引理 5（数值范围：`int` 必炸，`i64` 安全）

设 $|k_j|\le 10$（题面给 $k\le 10$；按绝对值同界估计，负数情形结论不变），则

$$|\text{ans}(q)|\le c\cdot 10\cdot n\le 10^3\times 10\times 10^9=10^{13},$$

且单项贡献 $|k_j|\cdot|[l,r]\cap I_j|\le 10\times 10^9=10^{10}$。两者都超出 `int` 上限 $2^{31}-1\approx 2.15\times 10^9$，但远小于 `long long` 上限 $2^{63}-1\approx 9.22\times 10^{18}$。

*证明*：由引理 3，$|\text{ans}|\le\sum_j|k_j|\cdot|[l,r]\cap I_j|\le\sum_j 10\cdot n=c\cdot 10\cdot n$（交长 $\le n$）。代入 $c\le m\le 10^3$、$n\le 10^9$ 得 $10^{13}$。单项同理。$10^{10}>2.15\times 10^9$，故**即使只有一个操作、一次询问**，极限数据（$k=10$、区间长 $10^9$）也会让 `int` 溢出——这不是"可能"，是"一定"。$10^{13}<9.22\times 10^{18}$，余量约 $9\times 10^5$ 倍，`i64` 安全。

**实现推论**：`ans+=(i64)op[j].k*(hi-lo+1)` 中必须先把 `k` 提升为 `i64` 再乘。若写成 `ans+=op[j].k*(hi-lo+1)`，乘法以 `int` 进行，$10^{10}$ 在乘法那一步就溢出，之后转 `i64` 也救不回来。证毕。

---

### 引理 6（复杂度）

时间 $O(m^2)$，空间 $O(m)$，均与 $n$ 无关。

*证明*：每个操作读入 $O(1)$。传教操作存入 `op`，$O(1)$。询问枚举 `cnt` 个已存操作，每个做常数次 `max/min/乘法/加法`，$O(\text{cnt})\le O(m)$。$m$ 个操作总时间 $\le\sum_{\text{询问}}O(m)=O(m^2)$。最坏情形（前 $m/2$ 个全是传教、后 $m/2$ 个全是询问）约 $m^2/4=2.5\times 10^5$ 次枚举，远小于 $1$ 秒时限。空间：`op` 数组 $O(m)$ 个三元组，其余 $O(1)$。$n$ 只作为坐标数值参与 `max/min`，不产生任何循环或数组。证毕。

---

### 定理

程序对每个询问输出正确的信仰值之和，总复杂度 $O(m^2)$、空间 $O(m)$。

*证明*：引理 1 给出信仰值的精确表达式；引理 4 保证只需前缀操作；引理 3 把询问化为对前缀操作的加权交长和；引理 2 保证交长公式正确（代码逐字实现）；引理 5 保证 `i64` 下无溢出；引理 6 给出复杂度。串联即得。证毕。

---

### 附注：为什么动态开点线段树 / 离散化也对，但没必要

- **动态开点线段树**：把 $[1,n]$ 建成隐式满二叉树，只在新访问的路径上开点。每次区间加/求和访问 $O(\log n)$ 个节点，总节点 $O(m\log n)\approx 6\times 10^4$，时间 $O(m\log n)$。正确性依赖懒标记下传的标准线段树不变量。它比 $O(m^2)$ 渐近更快，但 $m\le 10^3$ 时 $10^6$ 与 $3\times 10^4$ 都远低于时限，多写的几十行代码没有收益。
- **离散化**：所有端点 $\le 2m$ 个，排序去重后把数轴压成 $\le 2m+1$ 段原子区间，每段内部信仰值恒等（因为没有任何操作端点落在段内部），在压缩数组上差分即可。它本质上和引理 3 是同一个洞察（"只有 $O(m)$ 个位置重要"）的两种实现，但引理 3 连压缩数组都不用建。

三条路殊途同归，枚举操作是最短的那条。

## 三、模式总结（按实际思考顺序）

- explore its property — $n\le 10^9$ 否掉一切按人开数组的做法；$m\le 10^3$ 才是真正可用的资源上界。
- consider easier version — 特殊性质 A（无传教）答案恒 $0$：信仰值只诞生于 $\le m$ 次操作，人群只是画布。
- explore its property — 叠加原理：$\text{value}(p)=\sum_j k_j[p\in I_j]$，操作之间线性无关。
- reduce to easier problem — 交换有限双重求和号：区间和 $=\sum_j k_j\cdot|[l,r]\cap I_j|$，对 $10^9$ 人的求和塌缩成对 $\le 10^3$ 操作的枚举。
- classic problem solution — 整数区间交公式 $[\max(l,l'),\min(r,r')]$，长度 $\max(0,hi-lo+1)$，一行算完。
- discuss by category — 溢出分类：单项 $10^{10}$、总和 $10^{13}$ 都超 `int`，必须 `i64` 且乘法前先提升；无操作时 `cnt=0` 自动输出 $0$；$k$ 符号不做假设。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 人数，$\le 10^9$ | `int`，读入 | 只当坐标用，从不开数组 |
| `m` | 操作数，$\le 10^3$ | `int`，读入 | 复杂度的唯一来源 |
| `op[j]` | 第 $j$ 个**传教**操作 $\{l,r,k\}$，0-based 闭区间 | 匿名结构体数组 `[mxm]` | 询问不存，只存操作 1 |
| `cnt` | 已存下的传教操作个数 | `int`，全局默认 $0$ | 询问时枚举 `op[0..cnt-1]` |
| `mxm` | $1000+5$ | `constexpr int` | 操作数组尺寸 |
| `t` | 当前操作类型（$1$ 传教 / $2$ 询问） | `int`，每轮读入 | 分流 |
| `l,r` | 当前操作的区间端点，读入后 `--l;--r` | `int` | 0-based |
| `lo,hi` | 询问区间与 `op[j]` 的交的端点 | `int`，每次枚举现算 | `lo=max(l,op[j].l)`，`hi=min(r,op[j].r)` |
| `ans` | 当前询问的答案 | `i64`，每询问清零 | 累加 `(i64)k*(hi-lo+1)` |

### 算法步骤

1. I/O 加速三行；读 $n,m$。
2. 依次读 $m$ 个操作：类型 $1$ 则读 `l,r,k`、转 0-based、存入 `op[cnt++]`；类型 $2$ 则读 `l,r`、转 0-based，进入步骤 3。
3. 对该询问：`ans=0`；枚举 $j=0..cnt-1$，算 `lo=max(l,op[j].l)`、`hi=min(r,op[j].r)`；若 `lo<=hi` 则 `ans+=(i64)op[j].k*(hi-lo+1)`。
4. 输出 `ans` 与 `'\n'`，继续下一个操作。

### 复杂度

- 时间：$O(m^2)\le 10^6$（最坏约 $2.5\times 10^5$ 次枚举），与 $n$ 无关。
- 空间：$O(m)$（`op` 数组约 $12$ KB）。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过、无警告；按样例说明反推的 $5$ 操作组输出 $0,22$ 逐条吻合；另造 $n=10^9$ 溢出组（$10^{10},20$）、特殊性质 A 组（$0,0$）、区间相接边界组（$7,18$）共四组手算数据全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2781 传教
// n 高达 1e9 但 m 只有 1e3 ⇒ 根本不用维护人群数组。
// 每个询问的答案 = 对它之前的每次传教操作，累加 k × 两区间交的长度。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxm{1005};

int n,m,cnt;
struct{int l,r,k;}op[mxm];	// 只存传教操作，0-based 闭区间

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,t,l,r,k;i<m;++i)
	{
		cin>>t;
		if(t==1)
		{
			cin>>l>>r>>k;--l;--r;
			op[cnt++]={l,r,k};
		}
		else
		{
			cin>>l>>r;--l;--r;
			i64 ans=0;
			for(int j=0;j<cnt;++j)
			{
				int lo=max(l,op[j].l),hi=min(r,op[j].r);
				if(lo<=hi)
					ans+=(i64)op[j].k*(hi-lo+1);	// k*长度可达 1e10，必须 i64
			}
			cout<<ans<<'\n';
		}
	}
	return 0;
}
```

### 代码说明

- **没有数据结构**：`op` 只是操作日志。引理 3 证明了"询问 = 对日志的加权枚举"，所以日志就是全部状态。
- `(i64)op[j].k*(hi-lo+1)`：提升必须发生在乘法**之前**（引理 5），`ans` 本身是 `i64` 还不够。
- `lo<=hi` 一个判断同时处理了"相交"与"不相交"（含相接但不重叠）两类情形，空交贡献 $0$，无需特判。
- `cnt=0`（特殊性质 A 或询问早于一切传教）时内层循环不执行，`ans=0` 自动正确。
- 询问不存入 `op`，保证枚举的每一项都是传教操作，`k` 字段永远有意义。
