# P2773 漂亮字串 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 多组询问（读到 EOF），每组给四个数 $a=\text{CountO}$、$b=\text{CountX}$、$p=\text{maxO}$、$q=\text{maxX}$（全部 $0\le\cdot\le10^6$）。要用**至多** $a$ 个 O、$b$ 个 X 拼一个串，使得任意只含 X 的子串长度 $\le q$、任意只含 O 的子串长度 $\le p$，求串的最大长度。

**第一步：把"任意子串"翻译成"连续段"。** "任意只包含 X 的字串长度不超过 maxX"听着吓人，其实等价于：**每个极长 X 连续段长度 $\le q$**（任何全 X 子串都躺在某个极长 X 段里；反过来极长段自己就是全 X 子串）。O 同理。于是整个串的结构就是 **O 块与 X 块交替**：

$$\underbrace{OO\cdots}_{\le p}\underbrace{XX\cdots}_{\le q}\underbrace{O\cdots}_{\le p}\cdots$$

问题变成：怎么分配两种块的数量和大小，让总长度最大。

**第二步：先试一个单边贪心（然后翻车）。** 直觉上，cap 小的字母"单块容量小"，应该把它拆成很多小块当隔板，让 cap 大的字母填满隔板之间的长块。假设 $p\le q$，把 $a$ 个 O **全部**用掉、每个 O 块只放 $1$ 个 O，就有 $a+1$ 个 X 块 slot，答案似乎应该是

$$a+\min\bigl(b,\;(a+1)q\bigr).$$

拿 $a=5,b=1,p=1,q=100$ 一试：公式给 $5+\min(1,600)=6$。但手工拼一下——只有 $1$ 个 X，它最多把 O 分成左右两段，每段 $\le p=1$，所以最多 `OXO`，长度 $3$。**公式错了，而且错得离谱。**

**第三步：解剖失败原因。** 上面的推导只用了"O 块数 $k_O\le a$"，却忘了**隔板自己也要被隔开**：$5$ 个独立的 O 块之间至少要 $4$ 个 X 块，而 X 块数 $k_X\le b=1$。块数是**互相约束**的：交替结构要求 $|k_O-k_X|\le1$，所以 $k_O\le k_X+1\le b+1$，O 最多用 $\min(a,(b+1)p)$ 个，而不是 $a$ 个。对称地，X 最多用 $\min(b,(a+1)q)$ 个。两边互相卡，谁也别想"全部用掉"。

**第四步：写成干净的优化问题。** 设 $k_O,k_X$ 为两种块的个数，可行条件是

$$0\le k_O\le a,\quad 0\le k_X\le b,\quad |k_O-k_X|\le1,$$

给定块数后长度上界是 $\min(a,k_Op)+\min(b,k_Xq)$（每项 = 总量 cap 与块容量 cap 取小）。这个目标对 $k_O,k_X$ **各自单调不减**，而可行域里存在一个**逐分量最大**的点：

$$k_O^\*=\min(a,b+1),\qquad k_X^\*=\min(b,a+1).$$

任何可行点都被它逐分量支配，所以最优点就是它，代进去得到**闭式**：

$$\boxed{\;\text{ans}=\min\bigl(a,(b+1)p\bigr)+\min\bigl(b,(a+1)q\bigr)\;}$$

注意这个式子**对称**，根本不需要假设 $p\le q$——第二步的"谁当隔板"之争被彻底消解了：公式自动让两边互相限制。

**第五步：退化情形与溢出。**

1. **$p=0$**：任何 O 出现都会形成长度 $\ge1>0$ 的全 O 子串，所以 O **一个都不能用**，先令 $a:=0$；$q=0$ 同理令 $b:=0$。之后公式自动退化：$a=0$ 时答案 $=\min(b,q)$（一段 X），正确。
2. **溢出**：$(b+1)p$ 最大约 $10^6\times10^6=10^{12}$，远超 `int`，必须 `long long`。答案本身 $\le a+b\le2\times10^6$。
3. 每组询问 $O(1)$，EOF 驱动读入即可。

**手造数据核对**（题面无样例，按规则自造，覆盖翻车点与退化点）：

```
输入                  输出        解释
5 1 2 1               5           OOXOO：X 当隔板，O 两段各 2
5 1 1 100             3           OXO：第二步错误公式会给 6
0 5 3 2               2           没有 O，只能 XX
3 0 2 5               2           没有 X，只能 OO
1000000 1000000 1 1   2000000     OXOX… 完美交替
0 0 0 0               0           空串
2 2 0 0               0           两个 cap 都是 0，什么也放不了
1 6 1 2               5           XXOXX：1 个 O 最多隔出 2 段 X，各 2
```

八组全部与公式吻合；另外把 $a,b,p,q\in[0,5]$ 的全部 $1296$ 组与"枚举所有长度 $\le a+b$ 的 O/X 串"的穷举结果逐一比对，零差异（穷举只用于自检公式，正解就是 $O(1)$ 闭式）。

## 二、思维链：完整证明

**记号。** 一组询问为 $(a,b,p,q)$：O 的可用个数、X 的可用个数、O 段长上限、X 段长上限。串 $S$ 合法指：O 总数 $\le a$，X 总数 $\le b$，每个全 O 子串长 $\le p$，每个全 X 子串长 $\le q$。目标 $\max|S|$。

---

### 引理 1（子串约束 ⟺ 极长段约束）

$S$ 合法 $\iff$ O 总数 $\le a$、X 总数 $\le b$，且每个**极长** O 连续段长 $\le p$、每个极长 X 连续段长 $\le q$。

*证明*：($\Rightarrow$) 极长 O 段本身是只含 O 的子串，故长 $\le p$；X 同理。总数约束原样保留。

($\Leftarrow$) 任取一个只含 O 的子串 $T$。$T$ 中相邻字符在原串中也相邻且同为 O，故 $T$ 整体落在**同一个**极长 O 段内（若 $T$ 跨越两个极长段，中间必有非 O 字符，与 $T$ 全 O 矛盾）。于是 $|T|\le$ 该段长 $\le p$。X 同理。证毕。

**推论**：合法串恰好是"O 块 / X 块交替拼接"的串，块即极长段。以下均在块模型下讨论。

---

### 引理 2（块模型的完备参数化）

一个合法串等价于如下数据：块数 $k_O,k_X\ge0$，以及每块的长度，满足

1. 块按 O、X 交替排列（相邻块字母不同）；
2. $|k_O-k_X|\le1$；
3. 每个 O 块长 $\in[1,p]$，每个 X 块长 $\in[1,q]$（空串时 $k_O=k_X=0$）；
4. O 块长之和 $\le a$，X 块长之和 $\le b$。

反之，任何满足 1–4 的块序列拼接出的串都合法，且其极长段恰为这些块。

*证明*：正方向：由引理 1，合法串的极长段就是块。相邻极长段字母必不同（否则可合并成更长的同字母段，与"极长"矛盾），故交替；交替序列中两种字母出现次数差 $\le1$，得 2；块非空且受 cap 约束得 3；总数约束得 4。

反方向：给定满足 1–4 的块序列，拼接后相邻块字母不同，故每个块都是极长段（不会被并入邻段），段长 $\le$ cap、总数 $\le$ 计数，由引理 1 串合法。两个方向互逆（极长段分解唯一），故是等价参数化。证毕。

---

### 引理 3（上界：支配论证）

对任意合法串，设其块数为 $k_O,k_X$，则

$$|S|\;\le\;\min(a,k_Op)+\min(b,k_Xq)\;\le\;\min\bigl(a,(b+1)p\bigr)+\min\bigl(b,(a+1)q\bigr).$$

*证明*：第一个不等号：O 的总用量既 $\le a$（计数约束）又 $\le k_Op$（每块 $\le p$），故 $\le\min(a,k_Op)$；X 同理；两者相加即 $|S|$。

第二个不等号：由引理 2，$k_O\le a$（每块至少 $1$ 个 O）且 $k_O\le k_X+1\le b+1$，故 $k_O\le\min(a,b+1)$。函数 $k\mapsto\min(a,kp)$ 单调不减（$p\ge0$），所以 $\min(a,k_Op)\le\min(a,\min(a,b+1)p)=\min(a,(b+1)p)$（最后一步：$\min(a,b+1)\le b+1$ 且 $\min$ 单调；若 $\min(a,b+1)=a$ 则 $\min(a,ap)=a$（$p\ge1$ 时）或 $0$（$p=0$ 时），两种情况都 $=\min(a,(b+1)p)$，因为 $p=0$ 时两边都是 $0$，$p\ge1,a\le b+1$ 时 $(b+1)p\ge a$）。对称地 $\min(b,k_Xq)\le\min(b,(a+1)q)$。相加即得。证毕。

---

### 引理 4（上界可达：构造）

设 $p,q\ge1$（$p=0$ 或 $q=0$ 的情形见引理 5）。令

$$k_O=\min(a,b+1),\quad k_X=\min(b,a+1),\quad u=\min(a,k_Op),\quad v=\min(b,k_Xq).$$

则存在合法串恰用 $u$ 个 O、$v$ 个 X，长度 $u+v$ 达到引理 3 的上界。

*证明*：分三步。

**(i) $(k_O,k_X)$ 可行**，即 $|k_O-k_X|\le1$ 且 $k_O\le a,k_X\le b$。后者由 $\min$ 定义显然。前者分情形：若 $a\le b$，则 $k_O=a$，而 $k_X=\min(b,a+1)\in\{a,a+1\}$（因 $b\ge a$），差 $\le1$；若 $a>b$ 对称。✓

**(ii) 用量能摊进块里**：需 $k_O\le u\le k_Op$（每块 $[1,p]$）且 $k_X\le v\le k_Xq$。右半边由 $u=\min(a,k_Op)\le k_Op$ 自动。左半边：若 $k_O=a$，则 $u=\min(a,ap)=a=k_O$（$p\ge1$）；若 $k_O=b+1<a$，则 $u=\min(a,(b+1)p)\ge b+1=k_O$（$p\ge1$ 且 $a>b+1$）。$k_O=0$ 时 $u=0$，无需摊。X 对称。于是把 $u$ 个 O 任意分成 $k_O$ 个 $[1,p]$ 的块（例如贪心装满前几块）、$v$ 个 X 分成 $k_X$ 个 $[1,q]$ 的块，均存在。✓

**(iii) 拼串**：块数多的字母放首尾，交替拼接（$k_O=k_X$ 时任选开头；$k_O=k_X+1$ 时 O 开头 O 结尾；反之 X 开头 X 结尾）。由引理 2 反方向，串合法，长度 $u+v$。

最后核对 $u+v$ 等于引理 3 上界：$u=\min(a,k_Op)$，而 $k_O=\min(a,b+1)$。若 $a\le b+1$：$k_O=a$，$u=a=\min(a,(b+1)p)$（$(b+1)p\ge a$，因 $p\ge1$）；若 $a>b+1$：$k_O=b+1$，$u=\min(a,(b+1)p)$。两种情况都有 $u=\min(a,(b+1)p)$，对称地 $v=\min(b,(a+1)q)$。证毕。

---

### 引理 5（零 cap 退化）

若 $p=0$，则任何合法串不含 O，且此时答案 $=\min(b,q)$；$q=0$ 对称。实现上先做 $p=0\Rightarrow a:=0$、$q=0\Rightarrow b:=0$，再套引理 3/4 的公式，结果不变且构造仍合法。

*证明*：$p=0$ 时若串含 O，则该 O 自身构成长度 $1>0$ 的全 O 子串，违规；故合法串全 X，只有一个极长 X 段，长 $\le\min(b,q)$，且 $X^{\min(b,q)}$ 可达，答案 $\min(b,q)$。

预处理后 $a=0$：公式给 $\min(0,(b+1)p)+\min(b,(0+1)q)=0+\min(b,q)$ ✓。构造层面 $k_O=0,k_X=\min(b,1)\le1$，引理 4 的 (i)(ii)(iii) 在 $p\ge1$ 或 $a=0$ 时依然逐字成立（$k_O=0$ 时不需要 $p\ge1$）；若 $p=q=0$ 则 $a=b=0$，答案 $0$，空串合法。证毕。

---

### 引理 6（数值范围）

公式中 $(b+1)p\le(10^6+1)\times10^6\approx1.000001\times10^{12}$，$(a+1)q$ 同阶，均超 `int`（$\approx2.1\times10^9$），必须 64 位；最终答案 $\le a+b\le2\times10^6$。每组询问 $O(1)$ 时间、$O(1)$ 额外空间。

*证明*：直接代入约束上界；`long long` 上限 $9.2\times10^{18}$ 绰绰有余。公式只含常数次加法、乘法、$\min$。证毕。

---

### 定理

对每组询问，$\text{ans}=\min(a',(b'+1)p)+\min(b',(a'+1)q)$（其中 $a'=a\cdot[p>0]$，$b'=b\cdot[q>0]$）即最长合法串长度，单组 $O(1)$。

*证明*：引理 1 把子串约束化为段约束；引理 2 给出块模型完备参数化；引理 3 对所有合法串给出上界；引理 4 在 $p,q\ge1$ 时构造出达到上界的串；引理 5 把零 cap 情形归约到同一公式并验证退化正确；引理 6 保证 64 位实现无溢出且复杂度 $O(1)$。证毕。

---

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "任意全 X 子串 $\le q$" ⟺ 极长 X 段 $\le q$ ⇒ 串 = O 块 / X 块交替。
2. **consider easier version** — 先试单边贪心"小 cap 字母全用掉当隔板"：$a+\min(b,(a+1)q)$。
3. **explore its property** — 反例 $a=5,b=1,p=1,q=100$（公式 6，实际 3）暴露漏洞：隔板自己也要被隔开，$|k_O-k_X|\le1$ 让块数互相卡。
4. **reduce to easier problem** — 归约成双变量单调优化：在 $k_O\le a,k_X\le b,|k_O-k_X|\le1$ 下最大化 $\min(a,k_Op)+\min(b,k_Xq)$。
5. **classic problem solution** — 单调目标在可行域的逐分量最大点 $(\min(a,b+1),\min(b,a+1))$ 取最优（支配论证），得对称闭式，无需讨论谁当隔板。
6. **discuss by category** — $\max=0$ 的字母一个不能用，先清零计数；$a=0/b=0$ 自动退化为单段；乘积 $10^{12}$ 量级必须 `long long`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `a` | CountO，O 的可用个数 | `i64` | 每行读入；`p==0` 时置 0 |
| `b` | CountX，X 的可用个数 | `i64` | 每行读入；`q==0` 时置 0 |
| `p` | maxO，O 段长上限 | `i64` | 每行读入 |
| `q` | maxX，X 段长上限 | `i64` | 每行读入 |
| $k_O,k_X$ | （推导量）O/X 块数，最优取 $\min(a,b+1),\min(b,a+1)$ | — | 代码中不显式出现，已代入闭式 |
| `ans` | $\min(a,(b+1)p)+\min(b,(a+1)q)$ | `i64` | 两项 = 两种字母各自的最大可用量 |

### 算法步骤

1. I/O 加速三行。
2. EOF 驱动循环读入 `a,b,p,q`。
3. 若 `p==0` 令 `a=0`；若 `q==0` 令 `b=0`（零 cap 字母不可用）。
4. 输出 `min(a,(b+1)*p)+min(b,(a+1)*q)` 与 `'\n'`。

### 复杂度

- 时间：每组询问 $O(1)$，总计 $O(\text{行数})$。
- 空间：$O(1)$（无数组）。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过；8 组手造数据（含翻车反例与全部退化情形）逐条吻合；$a,b,p,q\in[0,5]$ 共 1296 组与"枚举所有 O/X 串"的穷举自检零差异。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2773 漂亮字串
// 思路：约束只限制"极长同字母连续段" ⇒ 串 = O 块与 X 块交替。
//       设 kO 个 O 块、kX 个 X 块，则 |kO-kX|<=1、kO<=CountO、kX<=CountX，
//       长度 <= min(CountO,kO*maxO)+min(CountX,kX*maxX)，两项对块数单调不减，
//       在逐分量最大的可行点 kO=min(CountO,CountX+1),kX=min(CountX,CountO+1) 取最优。
//       答案 = min(CountO,(CountX+1)*maxO)+min(CountX,(CountO+1)*maxX)。
//       max=0 的字母一个也放不了，先把对应 Count 清零。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(i64 a,b,p,q;cin>>a>>b>>p>>q;)
	{
		if(p==0)
			a=0;			// maxO=0：任何只含 O 的子串长度>=1 都违规
		if(q==0)
			b=0;
		cout<<min(a,(b+1)*p)+min(b,(a+1)*q)<<'\n';
	}
	return 0;
}
```

### 代码说明

- 整份代码就是定理的闭式，没有循环内的算法——所有工作都在第二部分的支配论证与可达性构造里。
- `(b+1)*p` 在 `i64` 下计算（`a,b,p,q` 全部声明为 `i64`），若用 `int` 读入会在 $10^{12}$ 量级静默溢出。
- 清零必须发生在套公式**之前**：$p=0$ 但 $a>0$ 时公式第一项 $\min(a,(b+1)\cdot0)=0$ 恰好也对，但第二项 $\min(b,(a+1)q)$ 会虚增 X 的 slot 数（O 根本不能出现，X 只有 $1$ 段而非 $a+1$ 段），所以显式清零是 correctness 的一部分，不是防御性冗余。
- EOF 驱动用 `for(i64 a,b,p,q;cin>>a>>b>>p>>q;)`，读入失败即退出，符合"输入包含多行，至文件结束为止"。
