# P2340 [USACO03FALL] Cow Exhibition G — 题解

## 一、解题过程：人类思考叙事

题意：有 $N\le400$ 头奶牛，第 $i$ 头有智商 $S_i$、情商 $F_i$，二者都在 $[-1000,1000]$。选一个子集参展，要求

$$\sum S_i\ge0,\qquad \sum F_i\ge0,$$

在这个前提下最大化 $\sum S_i+\sum F_i$。可以一头都不选，此时答案为 $0$。

**第一步：最直接的想法为什么不可行。**

两个约束、两个和，看起来是二维背包：`dp[智商和][情商和]`。但智商和、情商和各自的范围是 $[-4\times10^5,4\times10^5]$，二维状态数是 $(8\times10^5)^2\approx6.4\times10^{11}$，时间和空间都爆炸。必须利用目标函数的特殊结构。

**第二步：目标函数是"两个和相加"，这救了我们。**

如果已经确定了智商和 $s$，那么目标就是 $s+\sum F_i$——$s$ 已经固定，只需让情商和尽量大。换句话说：

> 对每个可能的智商和 $s$，只需要记录"能达到 $s$ 的子集中最大的情商和"。

记 `dp[s]` 为智商和恰为 $s$ 时的最大情商和。这样状态从二维降成一维。为什么可以只留最大值？因为后续再往子集里加奶牛时，加进来的 $S,F$ 与"当前子集具体是哪些奶牛"无关，只与当前和 $s$ 有关；同样智商和下，情商和更大的方案在任何后续扩展中都严格不差。

**第三步：范围与下标偏移。**

$N\le400$，每头 $|S_i|\le1000$，所以智商和一定落在 $[-400000,400000]$。数组下标不能为负，统一加偏移量 $400000$：`dp[s+400000]` 对应智商和 $s$。数组长度 $800001$ 再加一点松弛。

**第四步：负权重的 0/1 背包，循环方向要按符号分开。**

普通 0/1 背包（重量为正）倒序枚举容量，保证用到的是"上一轮"的状态。这里重量 $S_i$ 可能是负数，倒序就不对了。

具体的翻车例子：设当前可达的智商和为 $\{0,1\}$，情商和都是 $0$；来了一头 $S=-1,F=100$ 的奶牛。若仍倒序枚举目标 $j$（从大到小）：

- $j=0$ 时用 $j-S=1$ 转移，`dp[0]` 变成 $100$；
- 接着 $j=-1$ 时用 $j-S=0$ 转移，而 `dp[0]` 刚刚被这头奶牛更新过，于是 `dp[-1]` 变成 $200$——同一头奶牛被用了两次。

正确做法：

- $S_i\ge0$：目标 $j$ 从大到小枚举，源状态 $j-S_i<j$ 还没被本轮更新；
- $S_i<0$：目标 $j$ 从小到大枚举，源状态 $j-S_i>j$ 还没被本轮更新。

这样每头奶牛在每一轮中至多贡献一次。

**第五步：不可达状态必须是负无穷，不能是 0。**

全局 `int` 数组默认全是 $0$。如果把 $0$ 当作"可达且情商和为 $0$"，程序会凭空捏造子集。例如只有一头奶牛 $(1,-1)$，`dp[1]` 本来是"智商和 $1$ 不可达"（选了这头奶牛情商和是 $-1$，不选则智商和是 $0$），却因为默认 $0$ 被当成情商和 $0$ 的可达状态，最后扫 $s\ge0$ 时会错误地输出 $1+0=1$。所以初始化必须 `fill_n(dp, ..., -INF)`，只让 `dp[0+偏移]=0`（空集）。

**第六步：统计答案。**

枚举所有 $s\ge0$，若 `dp[s]` 可达且 $\ge0$，用 $s+\texttt{dp[s]}$ 更新答案。空集对应 $s=0$、情商和 $0$，故答案至少为 $0$，与题面"不选任何奶牛输出 $0$"一致。

## 二、思维链：完整证明

**引理 1（同智商和只留最大情商和）**：设两个子集 $A,B$ 的智商和都等于 $s$，且 $\sum_{A}F\ge\sum_{B}F$。则对任意与 $A\cup B$ 不相交的后续奶牛集合 $C$：

1. $A\cup C$ 与 $B\cup C$ 的智商和相同，且 $A\cup C$ 的目标值不小于 $B\cup C$ 的目标值；
2. 若 $B\cup C$ 可行（两个和均非负），则 $A\cup C$ 也可行。

*证明*：$A\cup C$ 与 $B\cup C$ 的智商和都等于 $s+\sum_C S$，相同；情商和分别为 $\sum_A F+\sum_C F$ 与 $\sum_B F+\sum_C F$，由 $\sum_A F\ge\sum_B F$ 知前者不小于后者。目标值是智商和加情商和，故 1 成立。对于 2：若 $B\cup C$ 可行，则其智商和 $s+\sum_C S\ge0$，情商和 $\sum_B F+\sum_C F\ge0$；$A\cup C$ 的智商和与之相同，情商和 $\sum_A F+\sum_C F\ge\sum_B F+\sum_C F\ge0$，故 $A\cup C$ 也可行。也就是说，同一智商和下情商和更大的方案，在任何后续扩展中都不差。证毕。

**引理 2（二维 DP 的递推）**：设 $g_i(s)$ 表示"只考虑前 $i$ 头奶牛、智商和恰为 $s$ 的子集中最大的情商和"，若不存在这样的子集则为 $-\infty$。则

$$g_i(s)=\max\big(g_{i-1}(s),\ g_{i-1}(s-S_i)+F_i\big),\qquad g_0(0)=0,\ g_0(s)=-\infty\ (s\ne0).$$

*证明*：前 $i$ 头奶牛的子集按"是否包含第 $i$ 头"分成两类，互不重叠且覆盖全部：

- 不含第 $i$ 头：智商和为 $s$ 的最优值就是 $g_{i-1}(s)$；
- 含第 $i$ 头：去掉它得到前 $i-1$ 头的一个子集，智商和为 $s-S_i$，情商和为（原情商和）$-F_i$。要使原情商和最大，等价于使这个子集的情商和最大，即 $g_{i-1}(s-S_i)$，于是该类最优值为 $g_{i-1}(s-S_i)+F_i$（当 $g_{i-1}(s-S_i)=-\infty$ 时表示不存在）。

两类取最大即得递推。基础情形由定义直接给出：空集智商和、情商和都为 $0$，故 $g_0(0)=0$；$s\ne0$ 时不存在智商和为 $s$ 的子集，故 $g_0(s)=-\infty$。证毕。

**引理 3（一维滚动与枚举方向）**：把 $g$ 压成一维数组 `dp`，按奶牛顺序处理。处理第 $i$ 头时，若 $S_i\ge0$ 则目标下标 $j$ 从大到小枚举，若 $S_i<0$ 则从小到大枚举；循环范围覆盖 $[lo+S_i,hi+S_i]$（$lo,hi$ 为处理前的可达最小/最大智商和）。每轮结束后 `dp[j]` 等于 $g_i(j)$。

*证明*：对 $i$ 归纳。设轮开始时 `dp[j]=g_{i-1}(j)`。递推只需把 $g_{i-1}(j-S_i)+F_i$ 与 `dp[j]` 取最大。

- **$S_i\ge0$**：目标 $j$ 递减枚举。源下标 $j-S_i<j$，递减枚举尚未访问到它，故读取的是本轮未修改的 $g_{i-1}(j-S_i)$；而目标 `dp[j]` 在本轮只会被写一次（循环变量等于 $j$ 时），因此不会把第 $i$ 头用两次。
- **$S_i<0$**：目标 $j$ 递增枚举。源下标 $j-S_i>j$，递增枚举尚未访问到它，同理读取的是 $g_{i-1}$，每头奶牛至多使用一次。
- **覆盖性**：包含第 $i$ 头的新状态，其智商和必为"旧智商和 $+S_i$"，落在 $[lo+S_i,hi+S_i]$ 内，循环恰好遍历这些目标；不含第 $i$ 头的状态原样保留在数组中。故轮末 `dp[j]` 取遍两类来源的最大值，等于 $g_i(j)$。
- 循环不会越界：任意可达智商和 $s$ 满足 $|s|\le i\cdot1000\le400000$，偏移后下标在 $[0,800000]$ 内。

归纳完成。证毕。

**引理 4（$-\infty$ 初始化的必要性）**：若把不可达状态初始化为 $0$，算法可能输出不可行的子集对应的值。

*证明（反例）*：$N=1$，奶牛为 $(1,-1)$。若所有 `dp` 初值为 $0$，则 `dp[1+400000]` 被当作"智商和 $1$、情商和 $0$"的可达状态（实际上没有任何子集智商和为 $1$）。最终扫 $s\ge0$ 时，$s=1$ 满足 `dp[1]` $=0\ge0$，答案被更新为 $1$。但唯一非空子集的智商和是 $1$、情商和是 $-1$，不满足情商和非负；空集答案为 $0$，正确答案是 $0$。故必须用 $-\infty$ 标记不可达，且转移时跳过 $-\infty$ 源。证毕。

**引理 5（答案提取）**：$\max\{s+\texttt{dp}[s]\mid s\ge0,\ \texttt{dp}[s]\ge0\}$ 等于题目所求最大值（在 DP 正确的前提下）。

*证明*：DP 枚举了前 $N$ 头奶牛的全部子集；对每个子集，设其智商和为 $s$、情商和为 $f$。若 $s\ge0,f\ge0$，则 `dp[s]≥f`（`dp[s]` 是同一 $s$ 下情商和的最大值），于是 $s+\texttt{dp}[s]\ge s+f$，且 $s+\texttt{dp}[s]$ 本身对应某个可行子集（`dp[s]` 可达且 $\ge0$），故最大值一致。空子集给出 $s=0,\texttt{dp}[0]=0$，保证答案 $\ge0$。证毕。

**定理**：算法输出正确。

*证明*：由引理 2、3，DP 数组在全部奶牛处理后等于 $g_N$；由引理 1，同 $s$ 只保留最大情商和不丢失最优解；由引理 5，扫描 $s\ge0$ 得到的最大值即答案；引理 4 说明初始化方式保证了"可达"语义。证毕。

**复杂度**：设 $R=800001$ 为智商和值域宽度。时间 $O(NR)$（利用 $lo,hi$ 收缩后为 $O\big(\sum_i 2000i\big)=O(N^2\cdot1000)$，最坏约 $1.6\times10^8$ 次转移）；空间 $O(R)$。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 目标是"智商和 + 情商和"，固定智商和后只需最大化情商和 ⇒ 二维状态可压成一维。
- **reduce to easier problem** — 问题化为"以智商和为下标的 0/1 背包，价值为情商"。
- **explore its property** — 智商和值域 $[-4\times10^5,4\times10^5]$，用偏移量 $+400000$ 把下标变成非负。
- **classic problem solution** — 0/1 背包滚动数组，重量为负时枚举方向反转（正数倒序、负数正序）。
- **find counterexample** — 负权重仍倒序会把同一头奶牛用两次（$\{0,1\}$ + 奶牛 $(-1,100)$ 的例子）。
- **explore its property** — 全局数组默认 $0$ 会把不可达状态伪装成"情商和 $0$"，必须用 $-\infty$ 初始化。
- **classic problem solution** — 最后扫描 $s\ge0$ 且 $\texttt{dp}[s]\ge0$，取 $s+\texttt{dp}[s]$ 的最大值；空集保证答案非负。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 说明 |
|------|------|-------------|
| $N$ | 奶牛数 | 输入 |
| $S_i,F_i$ | 第 $i$ 头奶牛的智商、情商 | 读入 |
| `mxv` | 偏移量 $400000$，也是智商和绝对值上界 | 常量 |
| `dp[j]` | 智商和为 $j-\texttt{mxv}$ 时的最大情商和 | 全部 `neg`，仅 `dp[mxv]=0` |
| `neg` | 不可达标记 $-1145141919$ | 常量 |
| `lo,hi` | 当前可达智商和的最小值、最大值 | 初值 $0,0$ |
| `ans` | 答案 | 初值 $0$（空集） |

### 算法步骤

1. 读入 $N$。
2. `fill_n(dp, ..., neg)`；`dp[mxv]=0`；`lo=hi=0`。
3. 对每头奶牛 $(s,f)$：
   1. 若 $s\ge0$：`j` 从 `hi+s` 递减到 `lo+s`，若 `dp[j-s+mxv]` 可达，则用它 $+f$ 更新 `dp[j+mxv]`；然后 `hi+=s`。
   2. 若 $s<0$：`j` 从 `lo+s` 递增到 `hi+s`，同样转移；然后 `lo+=s`。
4. 扫描 $j=0$ 到 `hi`：若 `dp[j+mxv]>=0`，用 $j+\texttt{dp}[j+\texttt{mxv}]$ 更新 `ans`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(NR)$，$R=800001$；$lo,hi$ 收缩后实际转移次数不超过 $\sum_{i}2000i\approx1.6\times10^8$。
- 空间：$O(R)$。

### 验证状态

- 用 `/d/mingw64/bin/g++.exe -std=c++20 -O2 -Wall -Wextra` 编译通过，无警告。
- 手造数据：`1 / -5 7` → `0`；`1 / 5 7` → `12`；`2 / 3 -5 / 2 10` → `12`（只选第二头）；两头都是负情商/负智商 → `0`；四头混合数据 → `11`（全选，智商和 $11$、情商和 $0$）。
- 对拍：随机生成 $N\le15$、$S_i,F_i\in[-1000,1000]$ 的数据（并混入小值域以制造大量同和状态），暴力枚举全部 $2^N$ 个子集统计答案，与标程比对 **1000 组全部一致**。
- 极限性能：$N=400$、全部 $S_i=1000$ 的最坏可达范围数据，单次运行远低于常见时限（$O(1.6\times10^8)$ 次简单转移）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxv{400000},mxn{800005};
constexpr int neg{-1145141919};

int n;
int dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	fill_n(dp,mxn,neg);
	dp[mxv]=0;
	int lo=0,hi=0;
	cin>>n;
	for(int i=0,s,f;i<n;++i)
	{
		cin>>s>>f;
		if(s>=0)
		{
			for(int j=hi+s;j>=lo+s;--j)
				if(dp[j-s+mxv]!=neg)
					dp[j+mxv]=max(dp[j+mxv],dp[j-s+mxv]+f);
			hi+=s;
		}
		else
		{
			for(int j=lo+s;j<=hi+s;++j)
				if(dp[j-s+mxv]!=neg)
					dp[j+mxv]=max(dp[j+mxv],dp[j-s+mxv]+f);
			lo+=s;
		}
	}
	int ans=0;
	for(int j=0;j<=hi;++j)
		if(dp[j+mxv]>=0)
			ans=max(ans,j+dp[j+mxv]);
	cout<<ans<<'\n';
	return 0;
}
```
