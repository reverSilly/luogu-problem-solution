# P2628 冒险岛 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一条由符号组成的路 $s$（$|s|\le10^6$，**可能含空格**），最左是第 $1$ 格、最右是终点。棋子初始在**所有符号之前的第 $0$ 格**。掷 $n$ 次骰子（$n\le10^5$，每次 $1\sim6$），每次前进对应步数，然后可能触发特殊符号：

- **`>`（奖励）**：走完骰子步数后停在 `>` 上，且**后面紧跟着 $2$ 个或以上 `>`**，就沿 `>` 一直前进，直到遇到第一个非 `>` 或到达右边界停下。
- **`*`（惩罚）**：停在 `*` 上且后面紧跟 $2$ 个或以上 `*`，就后退 $k$ 步，$k$ 是从当前 `*` 起连续 `*` 的个数。
- 每次掷骰后**奖励/惩罚至多触发一次**；触发后即便又落在特殊符号上也不再触发。
- 超出右边界停在最后一个符号；超出左边界停在**第一个符号**（不能退回第 $0$ 格起点）。

输出当前符号序号（$1$ 起）与离终点的步数。

**第一步：把"后面紧跟 2 个或以上"翻译成精确条件。** 当前符号是 `>`，它后面还要有 $\ge2$ 个 `>`，意味着**从当前位置起的连续 `>` 段长度 $k\ge3$**（自己 $1$ 个 + 后面 $\ge2$ 个）。`*` 同理。这是第一个易错点：$k=2$ 不触发，必须 $k\ge3$。我专门造了 `ab>>cd`（`>` 段长 $2$）验证不触发。

**第二步：把奖励/惩罚的落点写成公式。** 设当前 $0$-based 下标 `pos`，连续段长 $k$（段占 `pos..pos+k-1`）：

- 奖励：沿 `>` 前进到**第一个非 `>`**，即下标 `pos+k`；若段一直顶到右边界（`pos+k-1=L-1`），就停在最后一个符号 `L-1`。两种情况合起来就是 `pos=min(pos+k, L-1)`。
- 惩罚：后退 $k$ 步到 `pos-k`；若越过左边界就停在第一个符号 `0`（**不是起点 $-1$**）。即 `pos=max(pos-k, 0)`。

**第三步：位置模型与输出。** 我用 $0$-based：字符串 `s[0..L-1]`，棋子位置 `pos`，**起点 `pos=-1`**（所有符号之前）。掷骰 `pos+=d`，超右界 `pos=L-1`。因为 $d\ge1$，第一次掷完 `pos>=0`，之后 `pos` 始终在 $[0,L-1]$。输出序号 `pos+1`、离终点步数 `(L-1)-pos`。核对样例说明：终点第 $25$ 格、棋子第 $20$ 格，步数 $25-20=5$，正是 `(L-1)-pos = 24-19 = 5`。

**第四步：先写朴素版，然后撞上效率墙。** 最直接的写法是每次掷骰后**现扫**连续段：`while(pos+k<L && s[pos+k]==c)++k`。逻辑没错，但复杂度会炸：考虑**整条路全是 `*`** 的极端数据，$L=10^6$。棋子每次被惩罚退回到开头附近，下一次掷骰又落在某个 `*` 上，连续段长 $\approx L$，于是要扫 $\approx10^6$ 个字符；$n=10^5$ 次掷骰就是 $10^{11}$ 次操作，妥妥 TLE。**奖励/惩罚每回合至多一次**并不能救场，因为"一次"本身就要扫 $O(L)$。

**第五步：预处理连续段长度，把每回合降到 $O(1)$。** 关键观察：`run[i]`（从 $i$ 起的同字符连续段长度）**只依赖 $s$，与骰子无关**，可以一次性预处理。从右往左递推：
$$\texttt{run}[L-1]=1,\qquad \texttt{run}[i]=\begin{cases}\texttt{run}[i+1]+1,&s[i]=s[i+1]\\1,&s[i]\ne s[i+1]\end{cases}$$
这样每个 `run[i]` 都 $O(1)$ 算出，总 $O(L)$。之后掷骰时直接查 `k=run[pos]`，每回合 $O(1)$，总复杂度 $O(L+n)$。我用"预处理版 vs 现扫版"在 $20000$ 组随机小数据上交叉验证，落点完全一致（确认预处理没写错），全 `*` 极端数据也不再超时。

**第六步：读入的坑——空格。** 题面明确"字符串中可能存在空格"，所以**不能用 `cin>>s`**（会在空格处截断），必须 `getline(cin,s)` 读整行。空格本身就是普通符号（不是 `>`/`*`，不触发），照常吃进长度。另外防御性地去掉行尾可能的 `'\r'`（CRLF 数据），避免把回车当成一个符号算进 $L$。读完字符串再 `cin>>n` 和骰子即可。

**手造数据核对**（题面只给了样例说明、没给样例输入，我按说明反推出一条 $25$ 格的路并验证）：

按说明"第一次掷 $5$ 走到第一个 `>`、奖励到左起第二个 `f`；第二次掷 $6$ 走到 `*`、退 $3$ 步到 `d`；第三次掷 $6$ 走到左起第四个 `>`、奖励到 `f`；最终第 $20$ 格、离终点 $5$ 步"，我构造路 `faaa>>>faadaa***>>>faaaad`（$L=25$），骰子 `5 6 6`：

- 掷 $5$：`pos=-1+5=4`（第 $5$ 格 `>`），`run[4]=3`，奖励 `pos=min(4+3,24)=7`（第 $8$ 格，第二个 `f`）✓
- 掷 $6$：`pos=7+6=13`（第 $14$ 格 `*`），`run[13]=3`，惩罚 `pos=max(13-3,0)=10`（第 $11$ 格 `d`）✓
- 掷 $6$：`pos=10+6=16`（第 $17$ 格，第四个 `>`），`run[16]=3`，奖励 `pos=min(16+3,24)=19`（第 $20$ 格 `f`）✓
- 输出 `20 5`，与样例说明逐字吻合。

另造三组打边界：`a>>>b` 掷 $2\to$ `5 0`（奖励到终点）；`a***b` 掷 $2\to$ `1 4`（惩罚越过左界停在第一格）；`ab>>cd` 掷 $3\to$ `3 3`（段长 $2$ 不触发）。

## 二、思维链：完整证明

### 记号与位置模型

- 路 $s[0..L-1]$（$0$-based），$L=|s|\ge1$。棋子位置 `pos`$\in[-1,L-1]$，`pos=-1` 表示起点（所有符号之前），`pos=p`（$p\ge0$）表示停在符号 $s[p]$（第 $p+1$ 格）。
- $\texttt{run}[i]$：从 $i$ 起、与 $s[i]$ 相同字符的极大连续段长度。
- 一次掷骰 $d\in[1,6]$ 的处理：`pos+=d`；右界 clamp；按 $s[\texttt{pos}]$ 至多触发一次奖励/惩罚。
- 输出：序号 $\texttt{pos}+1$，离终点步数 $(L-1)-\texttt{pos}$。

---

### 引理 1（触发条件 $k\ge3$ 的精确性）

停在特殊符号 $c\in\{\texttt{>},\texttt{*}\}$ 上时，"后面紧跟着 $2$ 个或以上 $c$" 等价于 $\texttt{run}[\texttt{pos}]\ge3$。

*证明*：$\texttt{run}[\texttt{pos}]$ 是从 `pos` 起连续 $c$ 的个数，包含 `pos` 自身。"后面紧跟 $\ge2$ 个 $c$" 指 $s[\texttt{pos}+1],s[\texttt{pos}+2]$ 都是 $c$（至少这两个），即除自身外还有 $\ge2$ 个，故连续段总长 $\ge1+2=3$。反之若 $\texttt{run}[\texttt{pos}]=k\ge3$，则 $s[\texttt{pos}+1],s[\texttt{pos}+2]$ 在段内、都是 $c$，满足"后面 $\ge2$ 个"。$k=1$（后面 $0$ 个）、$k=2$（后面 $1$ 个）都不满足。故充要条件为 $k\ge3$。证毕。

---

### 引理 2（奖励落点 $=\min(\texttt{pos}+k,\,L-1)$）

触发奖励时（$s[\texttt{pos}]=\texttt{>}$，$k=\texttt{run}[\texttt{pos}]\ge3$），棋子停在"第一个非 `>` 符号"或"右边界最后一个符号"，其下标恰为 $\min(\texttt{pos}+k,L-1)$。

*证明*：连续 `>` 段占据 $[\texttt{pos},\texttt{pos}+k-1]$，由 $\texttt{run}$ 定义，$s[\texttt{pos}+k]\ne\texttt{>}$（若 $\texttt{pos}+k<L$）或 $\texttt{pos}+k=L$（段顶到右边界）。

- **情形 A：$\texttt{pos}+k\le L-1$。** 则 $s[\texttt{pos}+k]$ 存在且非 `>`，是段后第一个非 `>`。"沿 `>` 前进直到遇到非 `>`" 即停在此处，落点 $\texttt{pos}+k=\min(\texttt{pos}+k,L-1)$ ✓。
- **情形 B：$\texttt{pos}+k=L$。** 段为 $[\texttt{pos},L-1]$，一路 `>` 到最后一个符号，再无符号可走。"到达右边界停下"即停在 $L-1$，$\min(L,L-1)=L-1$ ✓。

两情形穷尽（$\texttt{pos}+k$ 要么 $\le L-1$ 要么 $=L$，不可能 $>L$，因段长 $k\le L-\texttt{pos}$）。证毕。

---

### 引理 3（惩罚落点 $=\max(\texttt{pos}-k,\,0)$，且不回起点）

触发惩罚时（$s[\texttt{pos}]=\texttt{*}$，$k=\texttt{run}[\texttt{pos}]\ge3$），后退 $k$ 步，落点为 $\max(\texttt{pos}-k,0)$。

*证明*：题面"退后 $k$ 步，$k$ 为从当前 `*` 起连续 `*` 的数量"，即目标下标 $\texttt{pos}-k$。若 $\texttt{pos}-k\ge0$，落点就是 $\texttt{pos}-k$。若 $\texttt{pos}-k<0$，越过左边界，题面"停在第一个符号上，不能退回起点"——第一个符号下标 $0$（起点是 $-1$），故 clamp 到 $0$。合起来 $\max(\texttt{pos}-k,0)$。注意 clamp 下界是 $0$ 而非 $-1$，正是"不能退回起点"的体现。证毕。

---

### 引理 4（每回合至多触发一次）

一次掷骰后，无论奖励还是惩罚，都只处理一次；移动后即便落在特殊符号上也不再触发。

*证明*：题面明确"每次掷骰子后，奖励或惩罚至多一次……不能再受到奖励或惩罚"。代码结构为：`pos+=d` → 右界 clamp → 一个 `if(s[pos]=='>'){...} else if(s[pos]=='*'){...}`，该分支体内修改 `pos` 后**不再回到符号判断**，本回合结束。故至多一次。这与"先掷骰落点判定一次、移动后不连锁"的规则逐字对应。证毕。

---

### 引理 5（右界 clamp 在判定之前是安全的）

掷骰后若 $\texttt{pos}\ge L$，先令 $\texttt{pos}=L-1$ 再判定特殊符号，不会漏触发也不会误触发。

*证明*：$\texttt{pos}\ge L$ 表示越过右边界，题面令停在最后一个符号 $L-1$。而 $\texttt{run}[L-1]=1$（其后无符号），由引理 1，$1<3$ 不触发任何奖励/惩罚。故 clamp 到 $L-1$ 后判定必然"不触发"，与"停在终点、不再移动"一致。先 clamp 后判定与题意等价。证毕。

---

### 引理 6（$\texttt{run}$ 递推正确）

$\texttt{run}[L-1]=1$，$\texttt{run}[i]=[s[i]=s[i+1]]\,?\,\texttt{run}[i+1]+1:1$，则 $\texttt{run}[i]$ 等于从 $i$ 起与 $s[i]$ 相同的极大连续段长度。

*证明*：对 $i$ 从 $L-1$ 递减归纳。$i=L-1$：其后无字符，段长 $1$ ✓。设 $\texttt{run}[i+1]$ 正确。

- 若 $s[i]\ne s[i+1]$：从 $i$ 起的同字符段只有 $s[i]$ 自己（下一个就不同），段长 $1$ ✓。
- 若 $s[i]=s[i+1]$：从 $i$ 起的段 $=$ $s[i]$ 加上从 $i+1$ 起的同字符段（因 $s[i]=s[i+1]$，两段字符一致、首尾相接），段长 $1+\texttt{run}[i+1]$ ✓。

故递推正确。预处理一遍 $O(L)$。证毕。

---

### 引理 7（朴素现扫的最坏复杂度与预处理的必要性）

朴素"每回合现扫连续段"最坏 $O(nL)$；预处理 $\texttt{run}$ 后为 $O(L+n)$。

*证明*：构造全 `*` 路 $s=\texttt{*}^L$。则 $\texttt{run}[i]=L-i$。棋子起点 $-1$，掷 $d=1$：$\texttt{pos}=0$，$k=L\ge3$，惩罚 $\texttt{pos}=\max(0-L,0)=0$。再掷 $1$：$\texttt{pos}=1$，$k=L-1$，惩罚 $\max(1-(L-1),0)=0$（$L\ge2$）。如此 $\texttt{pos}$ 在 $0/1$ 间徘徊，每回合现扫的段长 $\approx L$。$n$ 回合共 $\approx nL=10^5\times10^6=10^{11}$ 次字符比较，超时。

预处理后 $\texttt{run}$ 一次 $O(L)$ 算好，每回合查表 $O(1)$，$n$ 回合 $O(n)$，合计 $O(L+n)=10^6+10^5$，轻松通过。故预处理是把最坏复杂度从 $O(nL)$ 降到 $O(L+n)$ 的必要步骤。证毕。

---

### 引理 8（模拟的整体正确性与输出映射）

按上述规则逐回合更新 `pos`，最终 `pos` 即棋子所在符号的 $0$-based 下标；输出 `pos+1` 与 $(L-1)-\texttt{pos}$ 正确。

*证明*：对回合数归纳。初始 $\texttt{pos}=-1$ 对应"第 $0$ 格起点"✓。设第 $t-1$ 回合后 `pos` 正确。第 $t$ 回合：`pos+=d` 实现"前进 $d$ 步"；引理 5 处理右界；引理 1 判定是否触发；引理 2/3 给出触发后的正确落点；引理 4 保证至多一次。故第 $t$ 回合后 `pos` 正确。归纳得最终 `pos` 正确。

输出：序号是 $1$-based，故 $\texttt{pos}+1$；终点是最后一个符号（$0$-based $L-1$，序号 $L$），离终点步数 $=$ 序号差 $=L-(\texttt{pos}+1)=(L-1)-\texttt{pos}$。与样例说明"第 $20$ 格、离终点 $5$ 步"（$L=25$）一致。证毕。

---

### 引理 9（读入含空格的路）

用 `getline(cin,s)` 读取第一行，空格作为普通符号计入 $L$；去掉行尾 `'\r'` 不影响合法符号。

*证明*：题面"字符串中可能存在空格"，且空格不是 `>`/`*`，是路的普通一格。`cin>>s` 遇空白即停，会截断路，故必须 `getline` 读整行（保留内部空格）。行尾 `'\r'` 仅出现在 CRLF 换行的数据里，不是题目定义的符号，去掉它使 $L$ 等于真实符号数；若数据是 LF 则无 `'\r'`，不删任何东西。故读入正确。证毕。

---

### 定理

程序在 $O(L+n)$ 时间、$O(L)$ 空间内正确模拟棋子行走，输出所在序号与离终点步数。

*证明*：引理 6 保证 $\texttt{run}$ 预处理正确；引理 1~5 保证每回合的触发判定、落点、clamp、至多一次都与题面规则逐字对应；引理 8 用归纳把逐回合正确性串成整体并给出输出映射；引理 9 保证含空格读入正确；引理 7 给出复杂度 $O(L+n)$、空间 $O(L)$（一个 $\texttt{run}$ 数组）。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "后面紧跟 $2$ 个或以上" $=$ 从当前起的同字符连续段长 $k\ge3$（含自身）。
- **explore its property** — 奖励落点 $=\min(\texttt{pos}+k,L-1)$（第一个非 `>` 或右界）；惩罚落点 $=\max(\texttt{pos}-k,0)$（左界 clamp 到第一格、非起点）。
- **reduce to easier problem** — 位置模型 $0$-based、起点 $\texttt{pos}=-1$；输出序号 $\texttt{pos}+1$、步数 $(L-1)-\texttt{pos}$。
- **consider easier version** — 先写"每回合现扫连续段"的朴素模拟，逻辑正确但最坏 $O(nL)$。
- **explore its property** — 全 `*` 极端数据下每回合扫 $\approx L$，$n$ 回合 $10^{11}$ 超时；连续段长只依赖 $s$、与骰子无关。
- **classic problem solution** — 从右往左预处理 $\texttt{run}[i]$（同字符段长），每回合查表 $O(1)$，总 $O(L+n)$。
- **discuss by category** — 含空格用 `getline`、去行尾 `'\r'`；右界 clamp 在判定前安全（$\texttt{run}[L-1]=1$ 不触发）；每回合至多触发一次。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `s` | 路的符号串（含空格） | `string`，`getline` 读入 | $0$-based，$L=|s|$ |
| `L` | 路长（$\le10^6$） | `int` | 终点下标 $L-1$ |
| `run[i]` | 从 $i$ 起同字符连续段长度 | `int[mxl]`，右→左递推 | 与骰子无关，预处理一次 |
| `n` | 掷骰次数（$\le10^5$） | `int`，读入 | 每回合 $O(1)$ |
| `pos` | 棋子 $0$-based 位置 | `int`，初值 $-1$ | $-1$=起点；输出 `pos+1` |
| `d` | 本回合骰子点数 $1\sim6$ | `int`，读入 | `pos+=d` |
| `k` | 当前连续段长 `run[pos]` | `int` | $k\ge3$ 才触发 |
| `mxl` | $10^6+5$ | `constexpr int{1000005}` | +5 松弛 |

### 算法步骤

1. I/O 加速三行；`getline(cin,s)`，若行尾 `'\r'` 则去掉；`L=s.size()`。
2. 预处理 `run[L-1]=1`；`for i=L-2..0: run[i]=(s[i]==s[i+1])?run[i+1]+1:1`（引理 6）。
3. 读 `n`；`pos=-1`。
4. 每回合读 `d`：`pos+=d`；`if(pos>=L)pos=L-1`（引理 5）；
   - 若 `s[pos]=='>'`：`k=run[pos]`，`if(k>=3)pos=min(pos+k,L-1)`（引理 1、2）；
   - 否则若 `s[pos]=='*'`：`k=run[pos]`，`if(k>=3)pos=max(pos-k,0)`（引理 1、3）；
   - 不再二次判定（引理 4）。
5. 输出 `pos+1`、空格、`L-1-pos`、换行（引理 8）。

### 复杂度

- 时间：$O(L+n)$，$L=10^6,n=10^5$ 实测 121 ms。
- 空间：$O(L)$，`run` 数组约 4 MB + 字符串约 1 MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；按样例说明反推的 $25$ 格路 + 骰子 `5 6 6` 输出 `20 5`，与说明逐字吻合；另造 `a>>>b`/`a***b`/`ab>>cd` 三组边界手算一致；预处理版与"每回合现扫"的独立朴素版在 $20000$ 组随机小数据（含空格、`>`/`*` 段长 $1\sim3$ 边界）上落点完全一致；全 `*` 极端数据不再超时。（模拟题，验证脚本仅临时放在 `.scratch`，不建 appendix。）

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2628 冒险岛
// 模拟棋子行走：连续段长 k>=3 才触发奖励/惩罚，每回合至多一次
// 预处理 run[i]（同字符连续段长）把每回合降到 O(1)，总 O(L+n)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxl{1000005};

int L,n,run[mxl];
string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	getline(cin,s);	// 路可能含空格，必须读整行
	if(!s.empty()&&s.back()=='\r')s.pop_back();	// 防 CRLF
	L=s.size();
	run[L-1]=1;
	for(int i=L-2;i>=0;--i)	// run[i]：从 i 起同字符连续段长度
		run[i]=(s[i]==s[i+1])?run[i+1]+1:1;
	cin>>n;
	int pos=-1;	// 起点：所有符号之前的第 0 格
	for(int i=0,d;i<n;++i)
	{
		cin>>d;
		pos+=d;
		if(pos>=L)pos=L-1;	// 超出右边界停在最后一个符号
		if(s[pos]=='>')
		{
			int k=run[pos];
			if(k>=3)pos=min(pos+k,L-1);	// 前进到第一个非 '>' 或右边界
		}
		else if(s[pos]=='*')
		{
			int k=run[pos];
			if(k>=3)pos=max(pos-k,0);	// 后退 k，超出左边界停在第一个符号
		}
	}
	cout<<pos+1<<' '<<L-1-pos<<'\n';
	return 0;
}
```

### 代码说明

- **`pos=-1` 起点**：$0$-based 下标，$-1$ 表示"所有符号之前"。掷骰 `pos+=d`（$d\ge1$）后 `pos>=0`，故 `s[pos]` 永远合法；输出 `pos+1` 还原成 $1$-based 序号。
- **`run` 预处理是性能命门**：不预处理则全 `*` 数据每回合扫 $O(L)$、总 $O(nL)=10^{11}$ 超时（引理 7）。预处理后查表 $O(1)$。
- **`k>=3` 而非 `k>=2`**：题面"后面紧跟 $2$ 个或以上"含自身共 $\ge3$（引理 1），$k=2$ 不触发。
- **奖励 `min(pos+k,L-1)`、惩罚 `max(pos-k,0)`**：分别处理右界（停在最后符号）与左界（停在第一格、**不是起点 $-1$**）。
- **右界 clamp 在判定前**：`pos>=L` 时先置 `L-1`，而 `run[L-1]=1<3` 必不触发，安全（引理 5）。
- **`if/else if` 只判定一次**：移动后不再连锁触发（引理 4）。
- **`getline` + 去 `'\r'`**：保住路中的空格、去掉 CRLF 的回车，使 $L$ 等于真实符号数。
