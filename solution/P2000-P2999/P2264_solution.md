# P2264 情书 — 题解

## 一、解题过程：人类思考叙事

先把题意压缩成一句话：给了 $n$ 个互不相同的单词（只含英文字母），又给了一段正文（只含英文字母、数字、空格、英文逗号、英文句号、英文引号）。正文按英文句号分句，大小写不敏感。某一句里如果出现了词表中的某个单词，感动值 $+1$；同一个单词在同一句里出现多次只算一次；不同单词互不影响。求总感动值。数据范围是 $n\le 100$、单词长度 $\le 50$、正文长度 $\le 1000$，非常小。

第一反应是"字符串查找"：对每一句话，枚举每个词，看它是不是这句话的子串。但马上就能构造出反例。假如词表里只有 `he`，句子是 `the`。`the` 里确实包含子串 `he`，可 `the` 并不是单词 `he`，按题意不应该加分。再比如词 `a` 与句子 `cat`，子串 `a` 出现了一次，但按题意 `cat` 不是单词 `a`。所以"子串出现"比"单词出现"宽松，直接 `find` 会多算。

那么"一个单词出现"到底该怎么刻画？词表里的词只由字母组成，正文里能组成词的字符也只有字母。把正文中**连续的字母**看成一段，段与段之间被非字母字符隔开。如果某个词作为一个独立的单词出现，它左右两侧要么是正文边界，要么是非字母，因此它自己恰好构成一个完整的"字母段"；反过来，任何一个完整的字母段，取它本身就是一个左右有边界（或者顶到正文两端）的出现。于是"单词出现"等价于"存在一个极大的连续字母段恰好等于这个单词"。

题面里那句"一句话中可能包含英文引号，比如 `you're`"正好在提示这件事：引号会把 `you're` 切成 `you` 和 `re` 两个词，引号不是单词的一部分。既然如此，数字、空格、逗号、句号、引号都应当按分隔符处理。词表里没有数字，所以数字也不可能成为词的一部分，把它当分隔符是自洽的。

接下来处理"每一句话"这个限制。句号既是单词的分隔符，又是句子的边界。扫描正文时维护一个"当前字母段"的缓冲区 `tok`：读到字母就往里加，读到任何非字母就先结算 `tok`，再判断这个非字母是不是句号；如果是句号，就把"本句已经计过分的单词"标记全部清空，进入下一句。这样每个字母段都会被结算一次，而且结算时用的标记正好属于它所在的那一句。

用一个手造的小例子走一遍：

```
2
love
my
I love you, my love. LOVE!
```

第一句的字母段依次是 `i`、`love`、`you`、`my`、`love`。`love` 第一次出现时记 $1$ 分并打标记，第二次出现时标记已存在，不再加分；`my` 记 $1$ 分；`i`、`you` 不在词表里。第一句共 $2$ 分。句号后标记清空，第二句的 `love`（已转小写）再记 $1$ 分。总答案是 $3$。这里的 `LOVE` 验证了大小写不敏感，`you,` 后面的逗号则说明逗号确实起到了分隔作用。

还有一个小边界：正文的最后一句不一定会以句号收尾。循环结束时缓冲区 `tok` 里可能还压着最后一段字母，必须再结算一次；如果正文恰好以句号结尾，此时 `tok` 是空的，补结算不会产生任何影响。

复杂度方面，每个字符只被 $O(1)$ 次处理；每个字母段都要和最多 $100$ 个词逐一比较，单次比较最多 $50$ 个字符。最坏 $1000\times 100\times 50=5\times 10^6$ 次字符比较，完全够用，不需要 Trie 或哈希。

## 二、思维链：完整证明

**定义 1（单词出现）**：设正文串为 $S$，词 $w$ 只含字母。称 $w$ 在 $S$ 中作为单词出现，若存在下标区间 $[l,r]$ 满足：

1. $S[l..r]=w$；
2. $l=0$，或者 $S[l-1]$ 不是字母；
3. $r=|S|-1$，或者 $S[r+1]$ 不是字母。

这个定义把"左右都有词边界"形式化了。下面说明它为什么与题面等价：题面要求的是"特定单词"，而词表里的词只含字母；正文里只有字母能构成词的一部分；引号、空格、逗号、句号、数字都不是字母，因而在词法上起分隔作用。题面专门举出 `you're` 的例子，说明引号确实会切断单词，所以"非字母即边界"是题面明确支持的读法。

**引理 1**：$w$ 在 $S$ 中作为单词出现，当且仅当 $S$ 的某一个极大连续字母段恰好等于 $w$。

*证明*：

（$\Leftarrow$）设 $[l,r]$ 是一个极大字母段且 $S[l..r]=w$。所谓极大，指区间内全是字母，且区间不能再向左右扩展：若 $l>0$，则 $S[l-1]$ 不是字母；若 $r<|S|-1$，则 $S[r+1]$ 不是字母。于是定义 1 的三条全部满足，$w$ 作为单词出现。

（$\Rightarrow$）设 $w$ 在 $[l,r]$ 处作为单词出现。由定义 1 的第 1 条，$S[l..r]=w$，而 $w$ 只含字母，所以区间 $[l,r]$ 全是字母。由第 2、3 条，区间左右紧邻的字符（如果存在）都不是字母，因此这个字母区间无法再扩展，正是包含位置 $l$ 的那个极大字母段。极大字母段由其中任意一个位置唯一确定，所以 $w$ 等于这个极大字母段。

两个方向合起来，引理成立。证毕。

**引理 2**：扫描器（遇到字母就追加进 `tok`，遇到非字母就结算并清空 `tok`，扫描结束后再结算一次）输出的非空 `tok` 序列，恰好是 $S$ 的全部极大字母段，每个恰好一次。

*证明*：设 $[l,r]$ 是任意一个极大字母段。

- 在位置 $l$：若 $l=0$，扫描开始前 `tok` 为空；若 $l>0$，由极大性 $S[l-1]$ 不是字母，扫描到 $S[l-1]$ 时已经结算并清空了 `tok`。因此扫描到 $S[l]$ 时 `tok` 为空，$S[l]$ 被追加，`tok` 从 $S[l]$ 开始。
- 对 $l<k\le r$：$S[k]$ 是字母，扫描器只会追加，不会结算，所以 $S[k]$ 依次进入同一个 `tok`。
- 在位置 $r$：若 $r<|S|-1$，由极大性 $S[r+1]$ 不是字母，扫描到它时结算，输出的正是 $S[l..r]$；若 $r=|S|-1$，循环结束后的补结算输出 $S[l..r]$。

所以每个极大字母段至少被输出一次。另一方面，扫描器输出的每个非空 `tok` 都从某个字母开始，并且这个字母的前一个字符（如果存在）一定是非字母——否则它会被追加到前一个 `tok` 里而不会新开一段；同理 `tok` 结束时后一个字符一定是非字母或已到串尾。因此每个输出都是极大字母段，不会把一段拆成两段，也不会输出非极大的段。不同极大字母段互不重叠，故每个恰好输出一次。证毕。

**引理 3**：扫描器把每个极大字母段归属到唯一的一句话，并且每句话开始时 `got` 数组恰好是全 `false`。

*证明*：句子由句号切分：第 $k$ 句是从上一个句号之后到下一个句号（不含句号）之间的字符；最后一段如果没有句号收尾，也算作一句。极大字母段内不可能含有句号，因此整个字母段落在同一句内。

考虑任意一句。它的第一个字符之前的字符要么是句号（上一句的结尾），要么不存在。扫描器在处理那个句号时，先结算了上一句末尾的字母段，然后执行 `fill_n(got,n,false)`；若该句是全文第一句，则程序开始时 `got` 由全局零初始化，也是全 `false`。在这句内部，不会再遇到句号，所以不会再次清空 `got`。这句里的每个字母段在遇到非字母（包括结尾的句号或正文末尾）时被结算，结算时 `got` 仍是本句的标记。下一句的句号处理完后 `got` 再次被清空。因此每个字母段的结算都发生在它所属句子的标记作用域内。证毕。

**引理 4**：对每一句话，算法使 `ans` 增加的量恰好等于这句中出现的不同词表单词的个数。

*证明*：固定一句。由引理 2，这句里的字母段被逐一结算；由引理 1，词表单词 $w_k$ 在这句中作为单词出现，当且仅当某个字母段恰好等于 $w_k$。

结算一个字母段 $t$ 时，`id(t)` 返回满足 $w_k=t$ 的下标 $k$（词表在输入后已统一转小写，比较的是小写形式），找不到则返回 $-1$。若命中且 `got[k]` 为 `false`，算法把 `got[k]` 置 `true` 并使 `ans` 加一；若 `got[k]` 已为 `true`，说明本句此前已经结算过一个等于 $w_k$ 的字母段，不再加分。

于是对每个 $k$：若 $w_k$ 在本句出现，则第一次遇到对应字母段时加一分，之后不再加，净贡献恰为 $1$；若 $w_k$ 不在本句出现，则 `id` 永远不会返回 $k$，净贡献为 $0$。由引理 3，`got` 在每句开始时全为 `false`，所以不同句子之间互不干扰。对 $k$ 求和，本句贡献恰为"出现的不同词表单词个数"。证毕。

> 说明：词表保证输入不重复。即使出现两个仅大小写不同的词，由于全文不区分大小写，它们本质上是同一个词，`id` 只返回第一个下标，也只会记一次分；这与"同一单词不叠加"一致。

**引理 5（大小写）**：把词表和正文都转成小写后，两个字母相等当且仅当它们在转小写前忽略大小写相等。

*证明*：输入字母是 ASCII 英文字母。ASCII 中 `tolower` 只把 `'A'..'Z'` 映射为 `'a'..'z'`，其余字符不变。对两个字母 $x,y$：若 $x=y$，转小写后当然相等；若 $x\ne y$，则只有 $x,y$ 是同一个字母的大小写两种写法时，转小写后才相等，否则不相等。因此转小写后的相等关系正是"忽略大小写相等"。证毕。

**引理 6（结尾补结算）**：若正文不以句号结尾，循环结束后的补结算恰好把最后一句的最后一个字母段计入；若正文以句号结尾，补结算不产生任何效果。

*证明*：若正文不以句号结尾且最后一个字符是字母，则由引理 2 的证明，最后这个极大字母段一直留在 `tok` 中未被结算；补结算把它取出并按当前句的 `got` 计分，正是它应得的处理。若正文以句号结尾，处理该句号时已经结算并清空了 `tok`（若句号前紧邻字母），或者 `tok` 本来就是空的（若句号前不是字母），补结算看到空串直接返回。若正文为空，`tok` 也为空，补结算直接返回。证毕。

**定理**：算法输出的 `ans` 等于题面定义的感动值。

*证明*：由引理 4，每一句的贡献都等于该句中出现的不同词表单词数；由引理 3 和引理 6，所有字母段都被归属到正确的句子且没有遗漏或重复；由引理 5，大小写处理不改变"是否是同一个词"的判断；由引理 1，用极大字母段判断"单词出现"与题面语义一致。把每句贡献相加，正是题面定义的感动值。证毕。

**引理 7（复杂度）**：设正文长度为 $L$、词表大小为 $n$、单词最大长度为 $K$，则时间复杂度为 $O(L\cdot n\cdot K)$，空间复杂度为 $O(nK+L)$。

*证明*：每个字符被扫描一次，花费 $O(1)$。正文被切成至多 $L$ 个字母段，每个字母段调用一次 `id`，`id` 至多比较 $n$ 个词，每个词至多比较 $K$ 个字符，故比较总代价 $O(LnK)$。空间上保存 $n$ 个长度不超过 $K$ 的词、全文和少量标记，共 $O(nK+L)$。在本题 $L\le 1000,n\le 100,K\le 50$ 下，$LnK\le 5\times 10^6$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "出现单词"必须以极大字母段为单位，子串匹配会被 `the` 里的 `he` 骗过。
- **find counterexample** — 用 `he` / `the`、`a` / `cat` 否定了直接 `find` 的方案，逼出"词边界"的定义。
- **discuss by category** — 正文字符分三类：字母（词内字符）、句号（词边界兼句子边界）、其他非字母（词边界），分别处理。
- **reduce to easier problem** — 先按句号切句，句内问题退化为"哪些不同的词表单词出现过"。
- **classic problem solution** — 线性扫描 + 当前字母段缓冲 + 每句一个 `bool` 标记数组。
- **boundary** — 最后一句可能没有句号，循环结束后要补一次结算。
- **complexity check** — $1000\times 100\times 50$ 的字符比较量可以接受，无需 Trie。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初始化 / 记忆点 |
|------|------|------|----------------|
| $n$ | 词表单词数 | `int` | 输入，$1\le n\le 100$ |
| $w_i$ | 第 $i$ 个词的小写形式 | `string[]` | 读入后逐字符 `tolower` |
| $text$ | 全文（行与行之间补 `'\n'`） | `string` | 读入词表后一直读到 EOF |
| $tok$ | 当前正在累积的字母段 | `string` | 空串 |
| $got_i$ | 当前句中 $w_i$ 是否已经计过分 | `bool[]` | 全 `false`，每遇到 `'.'` 清零 |
| $ans$ | 感动值 | `int` | $0$ |
| $id(t)$ | 返回与 $t$ 相等的词下标，找不到返回 $-1$ | 函数 | 线性比较 $w_0..w_{n-1}$ |

### 算法步骤

1. 读入 $n$，再读入 $n$ 个单词，并把每个单词逐字符转成小写。
2. 用一次 `getline` 吃掉词表最后一行的换行，然后把剩余所有行依次拼进 `text`，每行末尾补一个 `'\n'`（换行是非字母，天然起分隔作用；这样即使正文跨行也不会把两行粘成一个词）。
3. 初始化 `tok` 为空、`got` 全为 `false`、`ans=0`。
4. 从左到右扫描 `text` 的每个字符 $c$：
   1. 若 $c$ 是字母，把 `tolower(c)` 追加到 `tok`。
   2. 否则先结算：若 `tok` 非空，令 $k=id(tok)$；若 $k\ge 0$ 且 `got[k]` 为假，则置 `got[k]=true`、`ans` 加一；随后清空 `tok`。结算完后再判断：若 $c$ 是 `'.'`，执行 `fill_n(got,n,false)` 进入下一句。
5. 扫描结束后再执行一次第 4.2 步的结算部分（不因句号而清空标记），处理没有句号收尾的最后一句。
6. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(L\cdot n\cdot K)$，其中 $L\le 1000$ 是正文长度、$n\le 100$ 是词表大小、$K\le 50$ 是单词最大长度；上界约 $5\times 10^6$ 次字符比较。
- 空间复杂度：$O(nK+L)$。

### 验证状态

编译通过（`g++ -std=c++20 -O2`，无错误）；本题题面无样例，手造 4 组覆盖 `you're`、`the`/`he`、大小写混排、空正文的用例分别得到 $3,2,1,0$，并用"按位置出现 + 左右边界检查"的独立暴力在 300 组随机数据上对拍，结果全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2264 情书
// 把正文切成句号分隔的句子，再把每句切成极大字母段
// 每句用一个 bool 数组去重，统计句内出现的不同词表单词
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n;
string w[mxn],text,tok;
bool got[mxn];

int id(const string&t)
{
	for(int i=0;i<n;++i)
		if(w[i]==t)
			return i;
	return -1;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>w[i];
		for(char&c:w[i])
			c=tolower((unsigned char)c);
	}
	string line;
	getline(cin,line);                 // 吃掉词表最后一行的换行
	while(getline(cin,line))
		text+=line+'\n';               // 换行也是非字母分隔符

	int ans=0;
	auto flush=[&]()
	{
		if(tok.empty())
			return;
		int k=id(tok);
		if(k>=0&&!got[k])              // 同一句同一个词只加一次
		{
			got[k]=1;
			++ans;
		}
		tok.clear();
	};
	for(char c:text)
	{
		if(isalpha((unsigned char)c))
			tok+=tolower((unsigned char)c);
		else
		{
			flush();
			if(c=='.')                 // 句号：进入下一句，标记清零
				fill_n(got,n,false);
		}
	}
	flush();                           // 最后一句可能没有句号
	cout<<ans<<'\n';
	return 0;
}
```
