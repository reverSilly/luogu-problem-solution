# P2080 增进感情 — 题解

## 一、解题过程：人类思考叙事

题目：小明做 $n$ 件事，第 $i$ 件事让"小明对小红的好感"增加 $a_i$，让"小红对小明的好感"增加 $b_i$（可能为负）。他可以任选一些事做。要在"亲密程度"（两人好感之和）$\ge v$ 的前提下，最小化"好感之差的绝对值"。

$n\le30$，$|a_i|,|b_i|\le100$。

先把符号定清楚。设选出的事构成集合 $S$，则：

- 小明对小红的好感 $A=\sum_{i\in S}a_i$，
- 小红对小明的好感 $B=\sum_{i\in S}b_i$，
- 亲密程度 $A+B\ge v$，
- 目标：最小化 $|A-B|$。

**第一反应：直接 DP 状态 $A$？** 那 $A$ 的范围是 $\pm3000$，$B$ 又依赖选择，状态不够。

**换个角度：把目标函数拆开。** 我们要最小化 $|A-B|$，同时要求 $A+B\ge v$。

注意 $A-B = \sum(a_i-b_i)$，$A+B=\sum(a_i+b_i)$。设每件事的"差值贡献" $d_i=a_i-b_i$，"亲密贡献" $s_i=a_i+b_i$。那么问题变成：

> 选一个子集 $S$，使得 $\sum_{i\in S}s_i\ge v$，最小化 $|\sum_{i\in S}d_i|$。

**这是一个"以差值为状态"的 DP。** 关键洞察是：

**对于同一个差值 $D$，我们只关心最大的亲密程度。**

理由：如果两个选法达到同一个差值 $D$，但亲密程度分别是 $S_1$ 和 $S_2$，且 $S_1<S_2$，那么 $S_1$ 这个选法永远不比 $S_2$ 有用——因为 $S_2$ 差值相同（答案一样），亲密程度还更大（更容易满足 $\ge v$）。所以对每个 $D$，只保留 $\max S$。

于是定义：

$$\text{dp}[D] = \text{差值恰好为 } D \text{ 的所有选法中，亲密程度的最大值}.$$

**状态范围**：$D = \sum d_i$，$|d_i|=|a_i-b_i|\le200$，$n\le30$，所以 $|D|\le6000$。用偏移量把负数下标变成正数：`dp[D+6005]`，数组长度 $12010$。

**转移**：处理第 $i$ 件事时，选或不选。

- 不选：`ndp[D] = max(ndp[D], dp[D])`；
- 选：`ndp[D+d_i] = max(ndp[D+d_i], dp[D]+s_i)`。

初始 `dp[0]=0`（什么都不做，差值 0、亲密 0），其余为 $-\infty$（不可达）。

**这一步特别容易漏掉"不选"的转移！** 我第一次写就只写了"选"，结果只能得到"全部都选或全不选"的组合，很多状态丢失。DP 必须允许"保持原状"。

**答案**：从 $D=0$ 开始向上找最小的 $D$，使 `dp[±D] >= v`。如果 $|D|=0$ 就满足（$A=B$），答案是 0。

**关于"负值与无穷小"**：不可达状态必须用一个足够小的值标记。我用 `-1145141919`（这是本仓库风格里常用的哨兵）。用 `int` 存亲密程度总和是可以的（最大 $30\times200=6000$），但为稳妥起见也可以用 `i64`。

**还有一个细节**：$dp$ 数组必须初始化为不可达，不能是 0。因为"差值为 0、亲密程度为 0"和"差值为 0、不可达"是不同的状态，如果不可达被当成 0，可能出现"亲密程度刚好达到 $v$"的假阳性？实际上如果 $v>0$，亲密 0 不会误判。但更严重的是：如果某些状态不可达却被当成 `dp=0`，那么"选"这个状态就会把 `s_i` 加到 0 上，凭空造出状态。所以必须用哨兵填充。

样例验证：`4 15 / 5 6 / -1 8 / 7 2 / 1 0`

$n=4,v=15$。四件事的 $(a,b)$：$(5,6),(-1,8),(7,2),(1,0)$。
$d = a-b$：$-1,-9,5,1$。
$s = a+b$：$11,7,9,1$。

要 $\sum s\ge15$，最小化 $|\sum d|$。

枚举：
- 选 {1,2}: s=18≥15 ✓，d=-10，|d|=10。
- 选 {1,3}: s=20 ✓，d=4，|d|=4。
- 选 {1,4}: s=12 <15 ✗。
- 选 {3,4}: s=10 ✗。
- 选 {1,3,4}: s=21 ✓，d=5，|d|=5。
- 选 {2,3}: s=16 ✓，d=-4，|d|=4。
- 选 {2,3,4}: s=17 ✓，d=-3，|d|=3。✓ 最优是 3。
- 选 {1,2,3}: s=27 ✓，d=-5，|d|=5。
- 全部：s=28 ✓，d=-4，|d|=4。

最小是 3（选第 2、3、4 件：$A=-1+7+1=7$，$B=8+2+0=10$，$A+B=17\ge15$，$|A-B|=3$）✓ 与样例答案 3 一致。

## 二、思维链：完整证明

**引理 1**：对任意选法 $S$，记 $A=\sum_{i\in S}a_i$、$B=\sum_{i\in S}b_i$，则 $|A-B|=\left|\sum_{i\in S}(a_i-b_i)\right|$、$A+B=\sum_{i\in S}(a_i+b_i)$。

*证明*：由有限和的线性性质直接成立。证毕。

**引理 2**：存在最优解，使得对每个差值 $D$，只需保留该差值下亲密程度最大的选法。

*证明*：设两个选法 $S_1,S_2$ 的差值同为 $D$，亲密程度 $s_1<s_2$。若某解 $S$ 用到了 $S_1$，把 $S$ 中 $S_1$ 的部分替换为 $S_2$，则新选法的差值仍为 $D$（因为两者差值相同），亲密程度变为 $s-s_1+s_2>s$，因此仍满足 $\ge v$ 的约束，且目标值 $|D|$ 不变。

严格地说，我们关心的是"每个 $D$ 下的最大亲密程度"这个函数 $f(D)=\max\{\text{亲密程度}:\text{差值为}D\}$。可行集为 $\{D: f(D)\ge v\}$，显然 $f$ 越大越有利，故只保留最大值不影响可行性与最优性。证毕。

**引理 3**：DP 结束后，`dp[D+LIM]` 等于所有差值为 $D$ 的选法中亲密程度的最大值。

*证明*：归纳。设处理完前 $i$ 件事后，命题对前 $i$ 成立（初始 $i=0$ 时只有空集，差值 0、亲密 0，`dp[LIM]=0`，其余不可达，正确）。

处理第 $i+1$ 件事时，任一选法恰为"前 $i$ 件事的某个选法" $\cup$（选或不选第 $i+1$ 件）。由引理 2，只需考虑前 $i$ 件事中每个差值 $D$ 对应的最大亲密程度 `dp[D+LIM]`。

- 不选第 $i+1$ 件：新差值仍为 $D$，亲密程度仍为 `dp[D+LIM]`，由 `ndp[D+LIM]=max(ndp[D+LIM],dp[D+LIM])` 承接。
- 选第 $i+1$ 件：新差值为 $D+d_{i+1}$，亲密程度为 `dp[D+LIM]+s_{i+1}`，由 `ndp[D+d_{i+1}+LIM]=max(...,dp[D+LIM]+s_{i+1})` 承接。

两种情形覆盖所有选法，且每次转移都对应一个真实选法，故 `ndp` 恰好记录了每个新差值下的最大亲密程度。归纳成立。证毕。

**引理 4**：算法输出的答案等于最小的可行 $|D|$。

*证明*：由引理 2、3，存在差值为 $D$ 的选法满足亲密程度 $\ge v$ 当且仅当 `dp[D+LIM] >= v`（因为 `dp` 记录的就是该差值下的最大亲密程度）。算法从 $D=0$ 起递增枚举，取第一个满足条件的 $D$。由于 $|D|$ 的取值关于 $0$ 对称，依次检查 `dp[LIM+D]` 与 `dp[LIM-D]` 即覆盖了所有差值为 $\pm D$ 的可能。第一个满足条件的 $D$ 必然是最小的可行 $|D|$。

若所有 $D$ 都不满足，说明任何选法的亲密程度都 $<v$（否则该差值的 `dp` 会 $\ge v$），即无论如何都无法在一起，输出 $-1$ 正确。证毕。

**定理**：算法输出题目要求的"好感之差最小绝对值"，无法在一起时输出 $-1$。

*证明*：由引理 1、2、3、4 依次成立得证。证毕。

## 三、模式总结（按实际思考顺序）

1. **把目标函数拆成"差值"和"和"** — $|A-B|$ 是差值，$A+B\ge v$ 是和，二者都由选法线性决定，于是可以以差值为状态、以和为权值。
2. **关键判断：同一差值只保留最大亲密程度** — 这是整个 DP 能成立的核心，因为目标是差值的绝对值，与亲密程度的具体数值无关，只与"能否 $\ge v$"有关。
3. **状态用偏移量处理负下标** — $|D|\le n\cdot200=6000$，用 `LIM=6005` 偏移。
4. **DP 必须有"不选"转移** — `ndp[D]=max(ndp[D],dp[D])`，漏了它就只能得到"全选"这一种组合。
5. **不可达状态用哨兵填充** — `fill_n(dp,lim*2,-1145141919)`，`dp[0]` 初始为 0 而非哨兵；全局 int 数组默认 0 的坑在这里表现为"不可达被当成亲密程度 0"。
6. **答案从 0 往上找** — 第一个满足 `dp[±D] >= v` 的 $D$ 即答案；找不到输出 $-1$。
7. **n=30 可以暴力枚举子集** — 但 $2^{30}$ 太大，DP 是正解；暴力版仅用于小数据对拍。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 事情数 | `int`，$\le30$ |
| $v$ | 亲密程度门槛 | `int` |
| $a_i,b_i$ | 第 $i$ 件事对双方好感的增量 | `int`，$|a_i|,|b_i|\le100$ |
| $d_i=a_i-b_i$ | 第 $i$ 件事的差值贡献 | `int`，$|d_i|\le200$ |
| $s_i=a_i+b_i$ | 第 $i$ 件事的亲密贡献 | `int`，$|s_i|\le200$ |
| $D$ | 选中集合的差值之和 $\sum d_i$ | `int`，$|D|\le6000$ |
| `LIM` | 下标偏移量 | `int`，`6005` |
| `dp[D+LIM]` | 差值为 $D$ 时能达到的最大亲密程度 | `int`，$-1145141919$ 表示不可达 |
| `ndp[]` | 转移用的新数组 | 同上 |

**初始化约定**：`dp[]`、`ndp[]` 为全局数组，默认全 0；使用前用 `fill_n(dp,lim*2,-1145141919)` 显式填充为不可达哨兵，并把 `dp[LIM]=0`（空集：差值 0、亲密 0）。**这一步绝不能省略**，否则不可达状态会被误当作亲密程度 0 而凭空造出可行解。

### 算法步骤

1. 读入 $n,v$。
2. `fill_n(dp,lim*2,-1145141919)`，令 `dp[LIM]=0`。
3. 对 $i=1\ldots n$：
   - 读入 $a_i,b_i$，计算 $dd=a_i-b_i$、$ss=a_i+b_i$；
   - `fill_n(ndp,lim*2,-1145141919)`；
   - 遍历所有下标 $j$（$0\le j<lim\cdot2$），若 `dp[j]==-1145141919` 则跳过（不可达）：
     - 不选第 $i$ 件：`ndp[j]=max(ndp[j],dp[j])`；
     - 选第 $i$ 件：令 $t=j+dd$，若 $0\le t<lim\cdot2$ 则 `ndp[t]=max(ndp[t],dp[j]+ss)`；
   - `copy_n(ndp,lim*2,dp)`。
4. 令 `ans=-1`；对 $d=0,1,\ldots,6000$：若 `dp[LIM+d]>=v || dp[LIM-d]>=v` 则 `ans=d` 并 `break`。
5. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(n\cdot K)$，其中 $K=2\cdot6005=12010$ 为状态数，即 $O(n\cdot n\cdot\max|d_i|)$；实际约 $30\times12010\approx3.6\times10^5$ 次状态转移。
- 空间复杂度：$O(K)$，两个长度为 $12010$ 的 `int` 数组。

### 验证状态

- 标程 `P2080.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `4 15 / 5 6 / -1 8 / 7 2 / 1 0` 输出 `3`，与官方一致（最优选法为做第 2、3、4 件事，$A=7,B=10$，亲密程度 $17\ge15$，$|A-B|=3$）。
- 编写独立暴力 `P2080_brute.cpp`（**枚举全部 $2^n$ 个子集**，直接算 $A,B$ 并取最优，完全不使用 DP）与对拍脚本 `P2080_check.py`：随机生成 $1\le n\le12$ 的数据（$a_i,b_i$ 取 $\pm1\sim\pm8$ 且非零），并附加"全正 / 全负 / 恰好差一点 / 完全达不到 $v$ / 官方样例"等极端构造，**对拍 2005 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{35};
constexpr int lim{6005};

int n,v;
//dp[d]：在"好感之差 A-B 等于 d"的选法里，亲密程度 A+B 的最大值
int dp[lim*2],ndp[lim*2];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>v;
	fill_n(dp,lim*2,-1145141919);
	dp[lim]=0;
	for(int i=1;i<=n;++i)
	{
		int a,b;
		cin>>a>>b;
		int dd=a-b,ss=a+b;
		fill_n(ndp,lim*2,-1145141919);
		for(int j=0;j<lim*2;++j)
		{
			if(dp[j]==-1145141919)
				continue;
			//不选第 i 件事
			ndp[j]=max(ndp[j],dp[j]);
			//选第 i 件事
			int t=j+dd;
			if(t>=0&&t<lim*2)
				ndp[t]=max(ndp[t],dp[j]+ss);
		}
		copy_n(ndp,lim*2,dp);
	}
	int ans=-1;
	for(int d=0;d<=6000;++d)
	{
		if(dp[lim+d]>=v||dp[lim-d]>=v)
		{
			ans=d;
			break;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `dp[]`、`ndp[]` 为全局数组，默认全 0；进入循环前用 `fill_n(dp,lim*2,-1145141919)` 把不可达状态显式填成哨兵，再单独设 `dp[lim]=0` 表示空集。这是"全局 int 数组默认 0"最典型的坑。
- 转移循环里 `if(dp[j]==-1145141919) continue;` 跳过不可达状态，防止哨兵参与加法后变成"看似可达"的假状态。
- "不选"转移 `ndp[j]=max(ndp[j],dp[j])` 不可省略：没有它，DP 只能表示"全选"这一种组合。
- 答案枚举同时检查 `dp[lim+d]` 与 `dp[lim-d]`，因为差值可为正也可为负，而目标只看绝对值。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
