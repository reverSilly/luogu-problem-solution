# P2614 计算器弹琴 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给一份"计算器谱"和每分钟拍数 $T$（$50\le T\le200$），求按完谱子需要多少**秒**，小数向下取整。谱子行数 $n\le100$，每行 $\le100$ 字符。规则：

- 每个音高符号（`+ < * / 1 2 3 4 5 6 7 8 9 = % C M` 共 $17$ 个）默认是**四分音符 = 1 拍**；
- 音符后跟 `-` 延长：`1-`=2 拍、`1---`=4 拍，即**每个 `-` 加 1 拍**（`-` 只出现在括号外）；
- 嵌套括号 `( )` 表示更短音符：每深一层时值减半。第 $0$ 层四分（1 拍）、第 $1$ 层八分（$0.5$）、第 $2$ 层十六分（$0.25$）、第 $3$ 层三十二分（$1/8$）。**最多到 $32$ 分音符**（深度 $\le3$）；
- 音符后跟附点 `.` 延长一半：`1.`=$1.5$ 拍、`1-.`=$3$ 拍。附点不连续、全音符无附点；
- 空白（空格、换行）随意添加，**忽略**。

**第一步：先把"一个音符值多少拍"写成公式。** 一个音符的时值由四件事决定：基础 $1$ 拍、括号深度 $d$（除以 $2^d$）、后面 `-` 的个数 $k$（每个加 $1$ 拍，但只在 $d=0$ 出现）、有没有附点（乘 $3/2$）。所以

$$\text{ beats }=\Bigl(\frac{1}{2^d}+k\Bigr)\times\begin{cases}3/2,&\text{有附点}\\1,&\text{无}\end{cases}\qquad(k>0\text{ 仅当 }d=0).$$

总秒数 $=\dfrac{\text{总拍数}\times60}{T}$，向下取整。样例解释里 $32$ 拍、$T=60$ → $32$ 秒，验证公式：$32\times60/60=32$。✓

**第二步：浮点还是整数？——抓住"最小粒度"。** 时值里有 $1/2,1/4,1/8$ 还有附点的 $3/2$ 倍，看起来必须用浮点。但我把所有可能的值列出来：深度 $d\le3$，基础 $1/2^d\in\{1,1/2,1/4,1/8\}$；附点乘 $3/2$ 后 $\in\{3/2,3/4,3/8,3/16\}$；$d=0$ 加 `-` 是整数拍再乘 $3/2$ 得半整数。**所有值都是 $1/16$ 拍的整数倍**（最小的是 $32$ 分附点 $=3/16$ 拍）。

这是本题的支点：**用"1/16 拍"作单位，全程整数运算，零浮点误差**。令 $1$ 拍 $=16$ 单位，则：

- 深度 $d$ 的基础音符 $=16/2^d=$ `16>>d` 单位（$d=0,1,2,3$ → $16,8,4,2$）；
- 每个 `-` 加 $16$ 单位；
- 附点 `val=val*3/2`。

**第三步：附点的整数除法会不会丢精度？** 我停下来验证：`val*3/2` 在 C++ 里是整数除法，若 `val` 是奇数就会向下取整出错。但 `val` 恒为偶数——基础值 $16,8,4,2$ 都是偶数，加 $16k$ 仍是偶数，所以 `val*3` 是偶数、`/2` 精确。最小情形 $d=3$ 附点：`val=2`，`2*3/2=3` 单位 $=3/16$ 拍，正确。**偶数性保证了附点整数运算无损**。

**第四步：先做 40% 子任务（无括号无附点），再增量加回。** 子任务里只有音符和 `-`：扫一遍，遇音符记 $16$ 单位、遇 `-` 加 $16$ 单位即可。加上括号：维护一个深度计数器 `depth`，遇 `(` 加一、遇 `)` 减一，音符基础值改成 `16>>depth`。加上附点：音符（及其 `-`）之后若紧跟 `.` 就 `val=val*3/2`。三件事叠加就是完整解，**不需要栈**——因为括号只影响"当前深度"，一个计数器就够，音符时值只依赖它被读到时的深度。

**第五步：解析的字符流处理。** 把 $n$ 行拼成一个串、**先滤掉所有空白**，再从左到右扫：

- `(` → `++depth`；`)` → `--depth`；
- 音高符号 → `val=16>>depth`，然后**贪心 lookahead**：只要下一个字符是 `-` 就 `val+=16` 并前进；之后若下一个是 `.` 就 `val=val*3/2` 并前进；把 `val` 累加进总单位；
- 其它字符（理论上没有）忽略。

滤空白让"音符 + 修饰符"在流里紧挨着，lookahead 才成立；也顺带处理了"音符在行尾、`-` 在下一行"这种跨行写法（拼接后连续）。

**第六步：最终换算与取整。** 总单位 `units`，总拍数 $=$ `units/16`，秒数 $=\dfrac{\text{units}}{16}\times\dfrac{60}{T}=\dfrac{\text{units}\times15}{4T}$。`units`、$T$ 都是正整数，C++ 整数除法天然向下取整，正好满足"向下取整到整数"。用 `i64` 防中间溢出（`units*15` 最大约 $10^7$，其实 `int` 也够，但 `i64` 零成本）。

**手造数据核对**（题面只给了样例解释的文字、没有样例输入输出，我按规则手算）：

| 输入（$n,T$ + 谱） | 手算拍数 | 秒数 | 程序 |
|---|---|---|---|
| `1 60` / `1111` | $4$ | $4$ | 4 |
| `1 60` / `(1(34(56))2)` | $0.5{+}0.25{+}0.25{+}0.125{+}0.125{+}0.5=1.75$ | $\lfloor1.75\rfloor=1$ | 1 |
| `1 60` / `(3.(45.))` | $0.75{+}0.25{+}0.375=1.375$ | $1$ | 1 |
| `1 60` / `1-.` | $2\times1.5=3$ | $3$ | 3 |
| `2 120` / `1-` `1---` | $2+4=6$ | $6\times60/120=3$ | 3 |
| `1 60` / 28 个`1`+2 个`1-` | $28+4=32$ | $32$ | 32 |
| `1 60` / `(((5.)))` | $3/16$ | $0$ | 0 |
| `1 200` / `1111` | $4$ | $4\times60/200=1.2\to1$ | 1 |

倒数第三行正是样例解释的 $32$ 拍 → $32$ 秒；`(3.(45.))` 与题面给的 $3/4,1/4,3/8$ 拍逐音吻合；深度 $3$ 附点 $3/16$ 拍验证了最小粒度。八组全对。

## 二、思维链：完整证明

**记号。** 音高符号集 $\Sigma=\{$`+`,`<`,`*`,`/`,`1`..`9`,`=`,`%`,`C`,`M`$\}$。把谱子滤去空白后得字符流 $c_0c_1\cdots c_{L-1}$。深度 $d_i$ 为位置 $i$ 处已闭合括号的净层数（遇 `(` 加一、`)` 减一）。一个音符指 $\Sigma$ 中某符号，其后可跟若干 `-`（仅 $d=0$）与至多一个 `.`。定义单位 $u=1/16$ 拍，$1$ 拍 $=16u$。

---

### 引理 1（所有音符时值都是 $1/16$ 拍的整数倍）

任一音符的拍数 $b$ 满足 $16b\in\mathbb Z_{\ge0}$。

*证明*：由规则 $b=\bigl(2^{-d}+k\bigr)\cdot(3/2)^e$，其中 $d\in\{0,1,2,3\}$（最多 $32$ 分音符），$e\in\{0,1\}$（附点至多一个），$k\in\{0,1,2,3\}$ 且 $k>0$ 仅当 $d=0$（括号内无 `-`）。分两类：

**$d=0$**：$b=(1+k)(3/2)^e$。$e=0$ 时 $b=1+k\in\{1,2,3,4\}$，$16b\in\{16,32,48,64\}$ 整数。$e=1$ 时 $b=(1+k)\cdot3/2$，$1+k\in\{1,2,3\}$（全音符 $1+k=4$ 无附点，故排除），$b\in\{1.5,3,4.5\}$，$16b\in\{24,48,72\}$ 整数。

**$d\ge1$**：$k=0$，$b=2^{-d}(3/2)^e$。$16b=16\cdot2^{-d}\cdot(3/2)^e=2^{4-d}\cdot(3/2)^e$。$d=1$：$2^3=8$，$e=1$ 再 $\times3/2=12$；$d=2$：$4$，$e=1$→$6$；$d=3$：$2$，$e=1$→$3$。全为整数。

两类穷尽所有合法音符，故 $16b$ 恒为非负整数。证毕。

**推论**：以 $u=1/16$ 拍为单位，每个音符贡献整数单位，总单位 `units`$=16\times$总拍数，是整数。全程无需浮点。

---

### 引理 2（单位计算的整数正确性，附点无损）

代码对深度 $d$ 的音符取 `val=16>>d`，每个 `-` 执行 `val+=16`，附点执行 `val=val*3/2`。则最终 `val`$=16b$（$b$ 为该音符拍数），且 `val*3/2` 是**精确**整数运算（无截断误差）。

*证明*：`16>>d`$=\lfloor16/2^d\rfloor=16/2^d$（$d\le3$ 时 $2^d\mid16$，整除），即基础单位 $16\cdot2^{-d}$。每个 `-` 加 $16$ 单位 $=1$ 拍，$k$ 个 `-` 后 `val`$=16(2^{-d}+k)$。附点前 `val` 恒为偶数：基础 $16/2^d\in\{16,8,4,2\}$ 皆偶，加 $16k$ 仍偶。故 `val*3` 为偶，`(val*3)/2` 精确等于 $\mathrm{val}\times3/2$，无向下取整损失。附点后 `val`$=16(2^{-d}+k)(3/2)=16b$。无附点时 `val`$=16(2^{-d}+k)=16b$（$e=0$）。两情形都得 `val`$=16b$。证毕。

**注**：偶数性是关键。若某音符基础值为奇数单位，附点 `*3/2` 会截断出错；引理 1 的粒度分析（最小 $2$ 单位）保证了这不会发生。

---

### 引理 3（深度计数器 = 括号嵌套层数）

扫描滤空白后的流，遇 `(` 令 `++depth`、遇 `)` 令 `--depth`，则读到位置 $i$ 的音符时 `depth` 恰等于该音符被多少层括号包围。

*证明*：谱子括号合法嵌套（题面保证）。对扫描位置归纳：`depth` 初值 $0$（根层）。每遇 `(` 进入更深一层，`depth` 加一；每遇 `)` 退出一层，`depth` 减一。由于括号合法配对，任意前缀里 `(` 数 $\ge$ `)` 数，`depth` 恒 $\ge0$，且 `depth`$=$（已读 `(` 数）$-$（已读 `)` 数）$=$ 当前未闭合的括号层数 $=$ 当前位置的嵌套深度。音符的时值只依赖它被读到时的深度（它属于哪几层括号），故 `16>>depth` 正确。证毕。

**为什么不需要栈**：括号只改变"当前深度"这一个标量，音符时值不依赖括号的历史结构（只依赖当前层数），故一个计数器足够，无需记录每层的内容。

---

### 引理 4（滤空白保持语义）

把 $n$ 行拼接并删除所有空白字符后得到的流，与原谱在"忽略空白"意义下等价；每个音符的修饰符（`-`、`.`）在滤后流中紧跟该音符。

*证明*：题面规定空白可随意添加且忽略，故原谱的语义只由非空白字符的**相对顺序**决定。拼接 $n$ 行保持行内顺序与行间顺序，删除空白不改变非空白字符的相对顺序，故滤后流与原谱语义等价。

修饰符紧跟：原谱中 `-`、`.` 总是依附于其前的音符（`1-`、`1.`），中间即便插入空白，滤除后 `-`/`.` 仍紧邻音符。故对音符做 lookahead（连续吃 `-`、再吃至多一个 `.`）能正确归并其修饰符。跨行情形（音符在行尾、`-` 在下一行）拼接后也连续，同样正确。证毕。

---

### 引理 5（贪心 lookahead 与文法一致）

音符的文法为 `note := symbol '-'* '.'?`（`-` 仅 $d=0$、`.` 至多一个、全音符无 `.`）。代码"先吃所有 `-`、再吃至多一个 `.`"恰好解析该文法，每个音符被消费一次。

*证明*：由题面约束：`-` 连续若干（$0..3$）跟在符号后，`.` 至多一个跟在 `-` 之后（`1-.` 合法），不连续两个 `.`。故一个音符的完整形态是 `symbol` + 若干 `-` + 可选 `.`。代码从 `symbol` 起，`while` 吃掉所有紧邻 `-`（每个 `+16`），再 `if` 吃掉紧邻的至多一个 `.`（`*3/2`），与文法逐段对应。消费后指针停在修饰符之后，下一个字符必是新音符、`(`、`)` 或流尾，不会重复消费同一音符。`-` 只在 $d=0$ 出现由题面保证，代码无需额外判断（即便 $d>0$ 误跟 `-` 也不合法，数据不含）。证毕。

---

### 引理 6（总秒数公式与向下取整）

设总单位 `units`，每分钟拍数 $T$。则演奏秒数 $=\dfrac{\text{units}\times15}{4T}$，且 C++ 整数除法 `units*15/(4*T)` 给出其向下取整值。

*证明*：总拍数 $B=\text{units}/16$（引理 1 推论）。每分钟 $T$ 拍 ⇒ 每拍 $60/T$ 秒 ⇒ 总秒数 $=B\times60/T=\dfrac{\text{units}}{16}\times\dfrac{60}{T}=\dfrac{\text{units}\times60}{16T}=\dfrac{\text{units}\times15}{4T}$。

`units`$\ge0$、$T>0$，故 $\dfrac{\text{units}\times15}{4T}\ge0$。对非负整数 $a,b$（$b>0$），C++ 的 `a/b` 等于 $\lfloor a/b\rfloor$。取 $a=\text{units}\times15$、$b=4T$，整数除法即向下取整，符合题意"小数向下取整到整数"。证毕。

---

### 引理 7（复杂度与值域）

设 $L\le n\times100=10^4$ 为总字符数。时间 $O(L)$，空间 $O(L)$。`units`$\le72\times(\text{音符数})\le72\times10^4=7.2\times10^5$，`units*15`$\le1.08\times10^7$，`i64` 安全（`int` 亦够）。

*证明*：拼接 + 滤空白扫一遍 $O(L)$；主扫描每个字符被访问常数次（音符的 lookahead 消费其修饰符，指针单调前进，总步数 $\le L$），$O(L)$。空间：滤后串 `s` 长度 $\le L$，$O(L)$。

值域：单音符最大时值 $=4.5$ 拍（`1--.`，$3$ 拍附点；全音符 $4$ 拍无附点）$=72$ 单位。音符数 $\le L\le10^4$，故 `units`$\le72\times10^4=7.2\times10^5$，`units*15`$\le1.08\times10^7<2^{31}$。$4T\le800$。用 `i64` 计算无溢出。证毕。

---

### 定理

程序输出演奏谱子所需秒数（向下取整），时间 $O(L)$、空间 $O(L)$，全程整数运算零浮点误差。

*证明*：引理 1 保证所有时值是 $1/16$ 拍整数倍 ⇒ 可整数化；引理 2 保证单位计算（含附点）精确；引理 3 保证深度正确；引理 4 保证滤空白与拼接不改语义；引理 5 保证 lookahead 正确解析每个音符；引理 6 保证秒数公式与取整正确；引理 7 给出复杂度与类型安全。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 音符时值 $=(2^{-d}+k)\times(3/2)^e$：深度减半、`-` 加拍、附点乘 $3/2$；秒数 $=$ 总拍 $\times60/T$。
- **explore its property** — 枚举所有合法时值，发现最小粒度是 $1/16$ 拍（$32$ 分附点 $=3/16$）⇒ 可全程整数化。
- **consider easier version** — 40% 子任务无括号无附点：只数音符与 `-`；再增量加回深度计数器与附点。
- **reduce to easier problem** — 以 $1/16$ 拍为单位：基础 `16>>d`、`-` 加 $16$、附点 `*3/2`；`val` 恒偶保证附点整数除法无损，零浮点误差。
- **classic problem solution** — 单遍模拟：滤空白拼接 → 深度计数器（无需栈）→ 音符贪心 lookahead 吃 `-` 与 `.`。
- **discuss by category** — 秒数 `units*15/(4*T)` 整数除法天然向下取整；音高符号集 $17$ 个；跨行音符靠拼接连续处理；`i64` 防溢出。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 谱子行数 $\le100$ | `int`，读入 | 每行 $\le100$ 字符 |
| `T` | 每分钟拍数 $[50,200]$ | `int`，读入 | 秒数 $=$ 拍 $\times60/T$ |
| `isNote[c]` | 字符 $c$ 是否音高符号 | `bool[128]`，默认 `false` | 由 $17$ 符号串置真 |
| `s` | 拼接 $n$ 行并滤去空白后的流 | `string`，初值空 | 只含 meaningful 字符 |
| `depth` | 当前括号嵌套层数 | `int`，初值 $0$ | `(` 加一、`)` 减一，$\le3$ |
| `units` | 总时值，单位 $1/16$ 拍 | `i64`，初值 $0$ | $1$ 拍 $=16$ 单位 |
| `val` | 当前音符的单位时值 | `i64` | 基础 `16>>depth`，`-` 加 $16$，附点 `*3/2` |
| `i` | 扫描指针 | `int` | lookahead 消费修饰符时前进 |

### 算法步骤

1. I/O 加速三行；用串 `"+<*/123456789=%CM"` 置 `isNote`。
2. 读 `n,T`；`getline` 吃掉首行剩余，再读 $n$ 行，逐字符滤去空白追加到 `s`（引理 4）。
3. `units=0,depth=0`；扫 `s`：
   - `(` → `++depth`；`)` → `--depth`（引理 3）；
   - 音高符号 → `val=16>>depth`；`while` 下一字符是 `-` 则 `val+=16,++i`；`if` 下一字符是 `.` 则 `val=val*3/2,++i`；`units+=val`（引理 2、5）。
4. 输出 `units*15/(4*T)` 与 `'\n'`（引理 6）。

### 复杂度

- 时间：$O(L)$，$L\le10^4$ 字符。
- 空间：$O(L)$ 滤后串。
- 值域：`units`$\le7.2\times10^5$，`units*15`$\le1.08\times10^7$，`i64` 安全。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面仅给样例解释文字，手造 $8$ 组核对——`1111`→4、`(1(34(56))2)`→1、`(3.(45.))`→1（与题面 $3/4,1/4,3/8$ 拍吻合）、`1-.`→3、两行 `1-`/`1---` 于 $T=120$→3、$28$ 四分 $+2$ 二分于 $T=60$→32（即样例解释的 $32$ 拍 $32$ 秒）、`(((5.)))`→0（$3/16$ 拍）、`1111` 于 $T=200$→1（$1.2$ 向下取整），全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2614 计算器弹琴
// 思路：所有时值都是 1/16 拍的整数倍（最小 32 分附点=3/16）⇒ 以 1/16 拍为单位全程整数。
//       深度 d 基础 16>>d 单位；每个 - 加 16；附点 val*3/2（val 恒偶，无损）。
//       滤空白拼接 → 深度计数器（无需栈）→ 音符贪心 lookahead 吃 - 与 .。
//       秒数 = units/16 拍 × 60/T = units*15/(4T)，整数除法天然向下取整。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int n,T;
bool isNote[128];
string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(char c:string("+<*/123456789=%CM"))	// 17 个音高符号
		isNote[(unsigned char)c]=true;
	cin>>n>>T;
	string line;
	getline(cin,line);	// 吃掉第一行剩余
	for(int i=0;i<n;++i)
	{
		getline(cin,line);
		for(char c:line)
			if(!isspace((unsigned char)c))
				s+=c;	// 滤空白，跨行音符拼接后连续
	}
	i64 units=0;	// 以 1/16 拍为单位
	int depth=0;
	for(int i=0;i<(int)s.size();++i)
	{
		char c=s[i];
		if(c=='('){++depth;continue;}
		if(c==')'){--depth;continue;}
		if(isNote[(unsigned char)c])
		{
			i64 val=16>>depth;	// 深度 depth 的基础时值
			while(i+1<(int)s.size()&&s[i+1]=='-'){val+=16;++i;}	// 每个 - 加一拍
			if(i+1<(int)s.size()&&s[i+1]=='.'){val=val*3/2;++i;}	// 附点延长 1/2，val 恒偶故精确
			units+=val;
		}
	}
	cout<<units*15/(4*T)<<'\n';	// units/16 拍 × 60/T 秒，向下取整
	return 0;
}
```

### 代码说明

- **整数化是灵魂**：`16>>depth` 把"深度减半"变成移位，`-` 加 $16$、附点 `*3/2` 全是整数运算，彻底避开浮点误差（引理 1、2）。
- **附点无损靠偶数性**：`val` 基础值 $\in\{16,8,4,2\}$ 皆偶，加 $16k$ 仍偶，故 `val*3/2` 精确；最小情形 $d=3$ 附点 `2*3/2=3` 单位 $=3/16$ 拍。
- **深度计数器代替栈**：括号只影响当前层数，音符时值只依赖被读到时的 `depth`，一个 `int` 足够（引理 3）。
- **滤空白 + 拼接**：先删所有空白再扫，保证音符与 `-`/`.` 紧邻，lookahead 成立；跨行音符也被拼接连续处理（引理 4）。
- **lookahead 消费修饰符**：`while` 吃 `-`、`if` 吃 `.` 时 `++i`，指针单调前进，每个字符至多访问一次，$O(L)$（引理 5、7）。
- **取整**：`units*15/(4*T)` 是非负整数除法，天然向下取整，无需 `floor`（引理 6）。
- **音高符号集**：`"+<*/123456789=%CM"` 恰 $17$ 个，注意 `0` 不是音符、`C`/`M` 是大写；`isNote` 用 `unsigned char` 下标避免负值 UB。
