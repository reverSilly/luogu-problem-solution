# P2347 [NOIP 1996 提高组] 砝码称重 — 题解

## 一、解题过程：人类思考叙事

题意：有 $1,2,3,5,10,20$ 克的砝码各若干枚，第 $i$ 种有 $a_i$ 枚，所有砝码总重不超过 $1000$ 克。问这些砝码一共能称出多少种**不同的正整数重量**（一枚砝码都不用的情况不算）。输入六个整数 $a_1,\dots,a_6$，输出 `Total=N`。

第一反应是枚举：每种砝码取 $0\sim a_i$ 枚，把所有取法都试一遍，把得到的重量记下来。写六个循环或者 DFS 都很直接，看起来没有任何思维难度。

但先别急着写。对一组输入，取法总数是 $\prod_{i=1}^{6}(a_i+1)$。题目只限制了总重不超过 $1000$，并没有单独限制每个 $a_i$，所以这个乘积可以很大。构造一组合法输入：

$$(a_1,\dots,a_6)=(100,50,33,20,10,5),$$

总重为

$$100\cdot1+50\cdot2+33\cdot3+20\cdot5+10\cdot10+5\cdot20=599\le1000,$$

而枚举量是

$$101\times51\times34\times21\times11\times6=242\,735\,724,$$

两亿四千万个叶节点。就算每个叶节点只做一次加法，也已经很危险；更关键的是，这其中的绝大多数取法算出来的重量是**重复**的——总重只有 $599$，不同的重量最多也就 $600$ 种，枚举把同一种重量重复计算了几十万次。

**关键转折：答案只关心"哪些重量能被称出来"，而不关心"用哪种取法称出来"。** 于是可以把状态从"取法"压缩成"重量"：开一个布尔数组 `dp[s]` 表示重量 $s$ 能否被称出。重量范围只有 $0\sim1000$，一共 $1001$ 个状态。原来指数级的取法空间，被压成了线性的重量空间。

那怎么在这些状态之间转移？把每一枚砝码看成一个独立的物品：它要么被用上（重量增加 $w$），要么不被用上。这就是标准的 **0/1 子集和**。从 `dp[0]=true` 出发，逐个物品做

$$\texttt{dp}[s]\ \vert=\ \texttt{dp}[s-w],$$

并且 $s$ 必须**从大到小**枚举。

为什么必须倒序？假设现在只有一枚 $2$ 克砝码，正序枚举会先令 `dp[2]=dp[0]=true`，再枚举到 $s=4$ 时又用刚被更新过的 `dp[2]` 把 `dp[4]` 置为真——同一枚砝码被用了两次，凭空称出了 $4$ 克。倒序时，处理到 $s$ 时 $s-w<s$ 还没有被本轮更新过，仍是"前 $t-1$ 枚物品"的旧值，恰好保证每枚砝码至多使用一次。

先排除两个容易想当然的结论（都是错的）：

- **"$0\sim S$ 全都称得出来"**：错。若只有 2 枚 2 克砝码，能称出的只有 $2,4$，答案是 $2$ 而不是 $4$。
- **"有 1 克砝码就能称出 $0\sim S$ 所有重量"**：错。若只有 1 枚 1 克和 1 枚 20 克，能称出 $1,20,21$，答案是 $3$ 而不是 $21$。

所以可达重量集合可以很稀疏、很不连续，必须老老实实做 DP，不能靠"区间"之类的结论偷懒。

再核对复杂度上界。虽然 $a_i$ 本身没有单独限制，但每种砝码至少重 $1$ 克，所以总枚数

$$T=\sum_{i=1}^{6}a_i\le\sum_{i=1}^{6}a_iw_i=S\le1000.$$

物品数不超过 $1000$，重量状态不超过 $1001$，转移总量不超过 $10^6$，非常轻松。这也解释了为什么"总重 $\le1000$"这个条件才是真正的规模控制：它同时限制了物品数和状态数。

手造几组小数据核对：

- `1 0 0 0 0 0`：只有一枚 1 克，能称出 $1$，答案 `Total=1`。
- `2 1 0 0 0 0`：两枚 1 克和一枚 2 克，能称出 $1,2,3,4$，答案 `Total=4`。
- `0 0 0 0 0 0`：一枚砝码都没有，排除 0 之后答案 `Total=0`。
- `1 1 1 1 1 1`：$1,2,3$ 能凑出 $0\sim6$，加 5 克并上 $5\sim11$ 得 $0\sim11$，加 10 克得 $0\sim21$，加 20 克得 $0\sim41$，答案 `Total=41`。

## 二、思维链：完整证明

记六种砝码的重量为 $w=(1,2,3,5,10,20)$，数量为 $a_i$，总重 $S=\sum_{i=1}^{6}a_iw_i\le1000$。把第 $i$ 种砝码拆成 $a_i$ 枚互不相同的"副本"，共 $T=\sum_{i=1}^{6}a_i$ 枚，按任意固定顺序排成一个物品表 $p_1,\dots,p_T$。

**引理 1（取法与物品子集的可达重量一致）**：所有取法 $(c_1,\dots,c_6)$（$0\le c_i\le a_i$）能称出的重量集合，与物品表全部子集能凑出的重量集合完全相同。

*证明*：两个方向。

1. 任给一组取法，取第 $i$ 种的前 $c_i$ 枚副本，得到一个子集，其重量和 $\sum_i c_iw_i$ 与原取法称出的重量相同。所以取法能称出的每个重量都能由某个子集凑出。
2. 任取物品表的一个子集，令 $c_i$ 为该子集中第 $i$ 种副本的枚数，则 $0\le c_i\le a_i$，$(c_1,\dots,c_6)$ 是一组合法取法，且重量和与原集合相同。所以子集能凑出的每个重量都能由某组取法称出。

两个方向合起来，两种方式的可达重量集合相同。证毕。

（注意这里不需要、也不应该声称"取法与子集一一对应"：同一个取法只对应"取前 $c_i$ 枚"这一个规范子集，而子集可以选任意哪几枚副本。我们真正需要的只是**可达重量集合相同**，上面的两个方向已经足够。）

**引理 2（0/1 背包不变量）**：设 $\texttt{dp}_t[s]$ 表示"用前 $t$ 枚物品能否凑出重量 $s$"。则

$$\texttt{dp}_0[0]=\text{true},\quad \texttt{dp}_0[s]=\text{false}\ (s>0),$$

$$\texttt{dp}_t[s]=\texttt{dp}_{t-1}[s]\ \lor\ \bigl(s\ge p_t\land\texttt{dp}_{t-1}[s-p_t]\bigr).$$

*证明*：对 $t$ 归纳。$t=0$ 时只有空集，能凑出的唯一重量是 $0$，初值正确。设 $\texttt{dp}_{t-1}$ 正确，考察前 $t$ 枚物品的任一子集：若它不含 $p_t$，则其重量和 $s$ 由前 $t-1$ 枚凑出，当且仅当 $\texttt{dp}_{t-1}[s]$ 为真；若它含 $p_t$，则其余物品来自前 $t-1$ 枚且重量和为 $s-p_t$，当且仅当 $s\ge p_t$ 且 $\texttt{dp}_{t-1}[s-p_t]$ 为真。两种情形互斥且穷尽所有子集，故并起来恰好是上式右端。证毕。

**引理 3（倒序循环实现的就是引理 2 的转移）**：处理物品 $p_t$ 时，令 $s$ 从 $S$ 递减到 $p_t$ 执行 `dp[s]|=dp[s-p_t]`。全部执行完后，内存中的 `dp` 恰为 $\texttt{dp}_t$。

*证明*：对 $s$ 从大到小归纳，证明在处理完下标 $s$ 之后，所有 $\ge s$ 的位置都等于 $\texttt{dp}_t$，所有 $<s$ 的位置仍等于 $\texttt{dp}_{t-1}$。

初始时 $s=S+1$，所有位置都等于 $\texttt{dp}_{t-1}$，论断成立。设处理下标 $s$ 前论断成立。因为 $p_t\ge1$，有 $s-p_t<s$，所以 `dp[s-p_t]` 仍等于 $\texttt{dp}_{t-1}[s-p_t]$；而 `dp[s]` 尚未被本轮修改，等于 $\texttt{dp}_{t-1}[s]$。一次操作把

$$\texttt{dp}[s]\leftarrow\texttt{dp}_{t-1}[s]\ \lor\ \texttt{dp}_{t-1}[s-p_t],$$

这正是引理 2 的 $\texttt{dp}_t[s]$。处理完后，$\ge s$ 的部分都等于 $\texttt{dp}_t$，$<s$ 的部分仍等于 $\texttt{dp}_{t-1}$，论断对 $s-1$ 继续成立。递减到 $p_t$ 结束后，所有 $\ge p_t$ 的位置等于 $\texttt{dp}_t$；而 $s<p_t$ 时 $s-p_t<0$，不可能由"含 $p_t$"得到，故 $\texttt{dp}_t[s]=\texttt{dp}_{t-1}[s]$，这些位置本来就等于 $\texttt{dp}_t$。于是整个数组等于 $\texttt{dp}_t$。证毕。

（反过来，若正序枚举，处理 $s$ 时 $s-p_t$ 可能已被本轮更新，读到的是 $\texttt{dp}_t[s-p_t]$，相当于物品 $p_t$ 可以重复使用，与"每枚只有一枚"矛盾。上面 2 克砝码称出 4 克的例子就是这种错误。）

**引理 4（最终答案）**：所有物品处理完后，$\texttt{dp}[s]$ 为真当且仅当重量 $s$ 能被这些砝码称出；答案等于 $|\{s\in[1,S]:\texttt{dp}[s]\}|$。

*证明*：由引理 1，取法与物品子集的可达重量集合相同，所以"重量 $s$ 可称出"等价于"存在物品子集重量和为 $s$"；由引理 2、3，后者等价于最终的 $\texttt{dp}[s]$ 为真。题目排除"一枚都不用"的 $s=0$，且所有可达重量不超过总重 $S$，故从 $1$ 数到 $S$ 即可。证毕。

**引理 5（规模上界）**：物品数 $T\le S\le1000$。

*证明*：每种砝码重量 $w_i\ge1$，故 $a_i\le a_iw_i$，对 $i$ 求和得 $T=\sum a_i\le\sum a_iw_i=S\le1000$。证毕。

**引理 6（复杂度）**：时间复杂度 $O(TS)\le10^6$，空间复杂度 $O(S)$。

*证明*：DP 对每枚物品枚举 $s\in[p_t,S]$，共不超过 $T\cdot S\le10^6$ 次操作；数组 `dp` 长 $S+1$，`a` 与 `w` 长为常数。证毕。

**定理**：程序输出 `Total=` 加上正确的可达重量个数。

*证明*：由引理 3，循环结束时 `dp` 恰为全部物品的子集和标记；由引理 4，统计 $1\le s\le S$ 中 `dp[s]` 为真的个数即为答案。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 答案只与"可达重量的集合"有关，与具体取法无关。
2. **consider easier version** — 先写枚举所有取法的 DFS，并估算组合数规模。
3. **碰壁反例** — 合法输入 $(100,50,33,20,10,5)$ 就有 $2.4\times10^8$ 种取法，且大量取法称出同一重量。
4. **reduce to easier problem** — 用布尔状态把"多重集选择"压成"0/1 子集和"。
5. **classic problem solution** — 0/1 背包，重量倒序枚举保证每枚砝码只用一次。
6. **verify boundary** — 排除 $s=0$；全 0 输入输出 `Total=0`；可达集合可以稀疏（如只有 2 克砝码）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| `w[6]` | 六种砝码的重量 $1,2,3,5,10,20$ | 常量 |
| `a[6]` | 每种砝码的枚数 | 输入 |
| `S` | 所有砝码总重 $\sum a_iw_i$ | 读入时累加，$\le1000$ |
| `dp[s]` | 能否用已处理的砝码称出重量 $s$ | 全 `false`，`dp[0]=true` |
| `ans` | 可达的正整数重量个数 | 0 |
| `mxn` | 重量上界 $1000$（+5 松弛） | 常量 |

### 算法步骤

1. 读入 $a_1,\dots,a_6$，同时累加总重 $S=\sum a_iw_i$。
2. 置 `dp[0]=true`，其余为 `false`。
3. 对每种砝码 $i$，把它的 $a_i$ 枚副本逐枚当作物品：对 $s$ 从 $S$ 递减到 $w_i$，执行 `dp[s]|=dp[s-w_i]`。
4. 统计 $s=1,\dots,S$ 中 `dp[s]` 为真的个数，输出 `Total=` 与该个数。

### 复杂度

- 时间复杂度：$O(TS)$，其中 $T=\sum a_i\le S\le1000$，故不超过 $10^6$。
- 空间复杂度：$O(S)$。

### 验证状态

g++ 16.2（`-std=c++20 -O2 -Wall -Wextra`）编译通过且无警告；与"递归枚举全部取法"的暴力在 300 组随机小数据（每种至多 3 枚）上完全一致；手算四组分别得到 `Total=1`、`Total=4`、`Total=0`、`Total=41`；边界输入 `1000 0 0 0 0 0` 输出 `Total=1000`，`0 0 0 0 0 50` 输出 `Total=50`，枚举量达 $2.4\times10^8$ 的混合输入 `100 50 33 20 10 5` 输出 `Total=599`。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2347 [NOIP 1996 提高组] 砝码称重
// 思路：可表示重量只有 0..1000 共 1001 个「状态」，把「枚举组合」换成「按重量去重」。
//       把同一重量的若干枚砝码逐枚看作 0/1 物品，做可行性背包；下标倒序保证每枚只用一次。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};
constexpr int w[6]{1,2,3,5,10,20};

int a[6];
bool dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int S=0;
	for(int i=0;i<6;++i)
	{
		cin>>a[i];
		S+=a[i]*w[i];
	}
	dp[0]=true;
	for(int i=0;i<6;++i)
		for(int k=0;k<a[i];++k)
			for(int s=S;s>=w[i];--s)
				dp[s]|=dp[s-w[i]];
	int ans=0;
	for(int s=1;s<=S;++s)
		if(dp[s])
			++ans;
	cout<<"Total="<<ans<<'\n';
	return 0;
}
```
