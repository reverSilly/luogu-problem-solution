# P2330 [SCOI2005] 繁忙的都市 — 题解

## 一、解题过程：人类思考叙事

先把题意压缩成一句话：给一张 $n$ 个点、$m$ 条带权边的**连通**无向图，选一个边集，要求

1. 选出的边把所有点连通；
2. 在满足 1 的前提下边数最少；
3. 在满足 1、2 的前提下，选出的边中**最大边权**尽量小。

输出选出的边数与最大边权。数据范围 $n\le 300$，$m\le 8000$，$c\le 10^4$，非常小。

**第一步：条件 2 其实没有选择余地。**

要让 $n$ 个点连通，至少需要 $n-1$ 条边——每加一条边，连通块个数最多减少 $1$，而从 $n$ 块减到 $1$ 块至少要减 $n-1$ 次。另一方面，图是连通的，所以一定存在一棵生成树，它恰好有 $n-1$ 条边。两边一夹，**最少边数恒为 $n-1$**，而且任何"用 $n-1$ 条边连通所有点"的方案一定是一棵树（连通且边数达到下界，不可能含环）。于是条件 2 从问题里消失了，只剩下：

> 在所有生成树中，选一棵**最大边权最小**的。

这就是经典的"最小瓶颈生成树"。

**第二步：先试最朴素的贪心，立刻撞反例。**

最直接的想法是"选权值最小的 $n-1$ 条边"。但这样可能选出环、同时漏掉某个点。例如 $n=4$，边为 $(1,2,1),(2,3,1),(1,3,1),(3,4,100)$：最小的三条边正好是三角形 $1\!-\!2\!-\!3$，点 $4$ 完全孤立，方案不可行。失败原因是：**只看边权、不看连通性**，小边可能全挤在同一个连通块里形成环。

**第三步：换个角度——"最小化最大值"通常可以二分。**

把问题改写成判定：给定阈值 $X$，只允许使用权值 $\le X$ 的边，能否把所有点连通？$X$ 变大时可用边只增不减，所以"能连通"这个性质关于 $X$ **单调**，可以二分出最小的可行 $X$。排序一次后，每次判定用并查集把可用边扫一遍，总复杂度 $O(m\log m+m\log 10^4)$，对本题绰绰有余。

**第四步：但二分是绕路，Kruskal 一遍就给出了同一个 $X$。**

把边按权值升序排序，用并查集依次尝试合并；**当成功合并的次数第一次达到 $n-1$ 时，当前这条边的权值就是答案**。原因是：Kruskal 处理完排序后的前若干条边时，并查集的连通分量恰好等于"只保留这些前缀边"的子图的连通分量。因此"第一次连通"发生的时刻，正是最小的可行阈值 $X$：所有更小的边加起来都连不通，而加上权值为 $X$ 的这批边后连通了。二分要找的 $X$ 与 Kruskal 的收尾边权是同一个数。

更妙的是，Kruskal 收下的这 $n-1$ 条边本身就构成一棵生成树，它的最大边权就是收尾边权，所以它不仅给出了最优值，还顺带给出了达到最优值的方案（本题只要求输出值）。

**第五步：实现层面的坑。**

- 输出的边数**恒为** $n-1$，不是 Kruskal 收下的边数之外的任何量；图保证连通，循环一定能收满 $n-1$ 条。
- $n=1$ 时不需要任何道路，按规定输出 `0 0`；把 `ans` 初值设成 $0$、循环条件写成 `cnt<n-1` 即可自然处理。
- 并查集路径压缩足够；无需按秩合并。

## 二、思维链：完整证明

**引理 1（边数下界）**：若一张图有 $n$ 个顶点且连通，则它至少有 $n-1$ 条边。

*证明*：从没有边的状态开始逐条加入边，维护连通块个数 $k$。初始 $k=n$。加入一条边 $(u,v)$ 时：若 $u,v$ 已在同一连通块内，$k$ 不变；否则两个连通块合并，$k$ 恰好减少 $1$。因此每加入一条边，$k$ 至多减少 $1$。最终图连通即 $k=1$，总共减少了 $n-1$，故加入的边数至少为 $n-1$。证毕。

**引理 2（树恰好 $n-1$ 条边）**：一棵有 $n\ge1$ 个顶点的树恰好有 $n-1$ 条边。

*证明*：对 $n$ 归纳。$n=1$ 时没有边，成立。设 $n\ge2$ 且命题对 $n-1$ 成立。取树中最长的一条简单路径 $v_0v_1\cdots v_k$。

- $v_0$ 不可能有路径之外的邻居 $u$：否则 $uv_0v_1\cdots v_k$ 是更长的一条简单路径，与最长性矛盾（$u$ 不在路径上，不会重复）。
- $v_0$ 不可能与 $v_i$（$i\ge2$）相邻：否则 $v_0v_1\cdots v_iv_0$ 构成一个环，与树无环矛盾。

所以 $v_0$ 的度数为 $1$，是叶子。删去 $v_0$ 及其唯一的边，剩下的图仍然连通：任取剩下两个顶点 $a,b$，树中 $a,b$ 之间的唯一路径若经过 $v_0$，则 $v_0$ 在这条路径上要有两个不同的邻居，与度数为 $1$ 矛盾；故路径完全避开 $v_0$，删掉 $v_0$ 后 $a,b$ 仍连通。剩下的图也无环（子图继承无环性），所以是 $n-1$ 个顶点的树，由归纳假设有 $n-2$ 条边。把删掉的边加回，原树有 $n-1$ 条边。证毕。

**引理 3（生成树存在）**：若图连通，则它存在一棵生成树，恰有 $n-1$ 条边。

*证明*：从原图出发，只要还存在环，就删去环上的一条边。删环边不破坏连通性（环上两点之间仍有沿环的另一条路可走），所以整个过程图始终连通且始终包含全部顶点。边数严格减少，过程必然终止；终止时图连通、无环、包含全部顶点，即为一棵生成树。由引理 2，它有 $n-1$ 条边。证毕。

**推论 1**：满足条件 1、2 的方案恰好是全部生成树，边数恒为 $n-1$。

*证明*：由引理 1，边数至少 $n-1$；由引理 3，$n-1$ 条边可以连通，故最少边数为 $n-1$。若一个 $n-1$ 条边的子图连通，它不可能含环——否则删去环上一条边后仍连通，只剩 $n-2$ 条边，违反引理 1。所以它连通无环，是生成树。反之，生成树按定义连通且恰有 $n-1$ 条边，满足条件 1、2。证毕。

于是原问题等价于：**在所有生成树中最小化最大边权**。

**引理 4（Kruskal 前缀 = 前缀子图的连通分量）**：把边按权值升序排成 $e_1,e_2,\dots,e_m$。Kruskal 处理完前 $k$ 条边后，并查集的每个连通块恰好是子图 $G_k=(V,\{e_1,\dots,e_k\})$ 的一个连通分量，且并查集的成功合并次数等于 $n-c_k$，其中 $c_k$ 是 $G_k$ 的连通分量数。

*证明*：对 $k$ 归纳。$k=0$ 时并查集有 $n$ 个单点块，$G_0$ 有 $n$ 个分量，成立。设处理完前 $k-1$ 条边时成立，考虑第 $k$ 条边 $e_k=(u,v)$：

- 若 $u,v$ 在并查集中同块，由归纳假设它们在 $G_{k-1}$ 中连通，故 $G_k$ 只是在同一分量内部多了一条边，分量结构不变；并查集也不做合并。归纳成立。
- 若 $u,v$ 不同块，则 $G_k$ 中这两个分量通过 $e_k$ 合并成一个，其它分量不变（$e_k$ 只涉及 $u,v$ 所在的两个分量）；并查集恰好把这两块合并。归纳成立。

成功合并次数：初始 $n$ 个分量，每次成功合并使分量数减少 $1$，故处理完 $k$ 条边后成功合并次数 $=n-c_k$。证毕。

**引理 5（Kruskal 收尾边权即最小瓶颈）**：设图连通、$n\ge2$。设 Kruskal 在第 $t$ 次成功合并时首次使成功次数达到 $n-1$，记这条边为 $e^{*}$，$c=w(e^{*})$。则

1. Kruskal 收下的 $n-1$ 条边构成一棵生成树，其最大边权为 $c$；
2. 任意生成树的最大边权都至少为 $c$。

因而最小可能的最大边权恰为 $c$。

*证明*：

1. Kruskal 只在两端点不属于同一并查集块时收边，所以收下的边不会成环，是一个森林；收满 $n-1$ 条边后，由引理 4，并查集分量数为 $n-(n-1)=1$，即所有点连通。连通、无环、$n-1$ 条边 ⇒ 生成树。所有被收下的边在处理顺序上不晚于 $e^{*}$，权值都 $\le c$；又 $e^{*}$ 本身被收下，故最大边权恰为 $c$。

2. 记 $P$ 为所有权值 $<c$ 的边组成的集合，$G_P=(V,P)$。先证 $G_P$ 不连通：若 $G_P$ 连通，由引理 4，Kruskal 处理完所有权值 $<c$ 的边后并查集只剩 $1$ 个分量，成功合并次数已达 $n-1$，循环会在处理 $e^{*}$ 之前结束，与"$e^{*}$ 是首次达到 $n-1$ 次合并的边"矛盾。所以 $G_P$ 不连通。

   反设存在一棵生成树 $T$，其所有边权都 $<c$，则 $T$ 的边全部属于 $P$，于是 $T$ 是 $G_P$ 的连通生成子图，$G_P$ 连通，矛盾。因此每棵生成树都含有至少一条权值 $\ge c$ 的边，其最大边权 $\ge c$。

综合 1、2，$c$ 是生成树最大边权的下界，且被 Kruskal 的树取到，故最优值就是 $c$。证毕。

**推论 2（$n=1$）**：只有一个交叉路口时，不需要改造任何道路，边数为 $0$，最大分值按空集约定为 $0$。

*证明*：空边集已经使唯一的点连通，边数 $0$ 不可能更少；空集上没有边，最大分值取 $0$（题目要求输出两个整数，这是唯一合理的约定）。证毕。

**定理**：程序输出 $(n-1,c)$ 是正确的。

*证明*：由推论 1，最少边数为 $n-1$，任何最优方案的边集是生成树；由引理 5，生成树最小可能的最大边权为 $c$，且 Kruskal 的树达到它；$n=1$ 由推论 2 处理。程序在合并次数达到 $n-1$ 时把当前边权记入 `ans`，正是引理 5 中的 $c$；输出边数写死为 $n-1$，与推论 1 一致。证毕。

**复杂度**：排序 $O(m\log m)$；并查集 $m$ 次查询、至多 $n-1$ 次合并，近似 $O((n+m)\alpha(n))$；总时间 $O(m\log m)$，空间 $O(n+m)$。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 条件 2 把边数钉死：连通 $n$ 点至少 $n-1$ 条边，生成树恰好 $n-1$ 条。
- **reduce to easier problem** — 条件 2 消失，问题化为"在所有生成树中最小化最大边权"（最小瓶颈生成树）。
- **consider easier version** — 先想"取最小的 $n-1$ 条边"，用三角形+孤立点的反例否定。
- **consider easier version** — "最小化最大值"改成二分判定：只用 $c\le X$ 的边能否连通，性质关于 $X$ 单调。
- **classic problem solution** — 二分的最小可行 $X$ 正是 Kruskal 第一次连通的时刻，排序+并查集一遍即可。
- **explore its property** — 并查集前缀连通分量 = 排序前缀子图的连通分量，这是"收尾边权即答案"的证明支点。
- **classic problem solution** — 交换论证/反证：任何生成树都必须用到权值 $\ge c$ 的边，而 Kruskal 的树全用 $\le c$ 的边。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 说明 |
|------|------|-------------|
| $n$ | 交叉路口数（顶点数） | 输入 |
| $m$ | 道路数（边数） | 输入 |
| `E[i]` | 第 $i$ 条边，字段 `u,v,w`，内部 0-based | 读入后 `--u,--v` |
| `f[x]` | 并查集父指针 | 初始 `f[i]=i` |
| `getrt(x)` | 路径压缩找根 | 递归一行 |
| `cnt` | 已成功合并（收下）的边数 | 初值 $0$ |
| `ans` | 最后一条被收下边的权值，即最小瓶颈 | 初值 $0$（$n=1$ 时输出 $0$） |

### 算法步骤

1. 读入 $n,m$ 与 $m$ 条边，顶点编号转 0-based。
2. 把边按 `w` 升序排序。
3. 初始化并查集 `f[i]=i`，`cnt=0`，`ans=0`。
4. 按排序顺序枚举边：若两端点根不同，合并并 `++cnt`，令 `ans=E[i].w`；当 `cnt==n-1` 时立刻停止。
5. 输出 `n-1` 与 `ans`。

### 复杂度

- 时间：$O(m\log m)$（排序主导；并查集部分近似线性）。
- 空间：$O(n+m)$。

### 验证状态

- 用 `/d/mingw64/bin/g++.exe -std=c++20 -O2 -Wall -Wextra` 编译通过，无警告。
- 手造 3 组数据：链式 5 点全 1 权（输出 `4 1`）、三角形+桥（输出 `3 100`）、$n=1$（输出 `0 0`），均符合预期。
- 对拍：随机生成 $n\le6$、$m\le9$ 的连通图（先随机树再加少量非重复边），暴力枚举所有恰含 $n-1$ 条边的子集、检查是否为生成树并取最小瓶颈，与标程比对 **2000 组全部一致**。
- 题面无样例，以上手造数据替代。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{305},mxm{8005};

int n,m;
struct edge{int u,v,w;}E[mxm];
int f[mxn];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<m;++i)
	{
		cin>>E[i].u>>E[i].v>>E[i].w;
		--E[i].u;--E[i].v;
	}
	sort(E,E+m,[](auto a,auto b){return a.w<b.w;});
	for(int i=0;i<n;++i)
		f[i]=i;
	int cnt=0,ans=0;
	for(int i=0;i<m&&cnt<n-1;++i)
	{
		int a=getrt(E[i].u),b=getrt(E[i].v);
		if(a==b)
			continue;
		f[a]=b;
		++cnt;
		ans=E[i].w;
	}
	cout<<n-1<<' '<<ans<<'\n';
	return 0;
}
```
