# P2952 [USACO09OPEN] Cow Line S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 维护一个初始为空的双端队列，依次执行 $S$ 条指令（$S\le 10^5$）：

- `A L` / `A R`：一头新奶牛从左侧 / 右侧入队；
- `D L K` / `D R K`：$K$ 头奶牛从左侧 / 右侧出队。

奶牛按入队先后编号 $1,2,\dots,N$（$N$ 就是 `A` 指令的条数，题目不单独给出）。保证每条指令都可执行（出队时队里至少有这么多头），且最终队列非空。要求从左到右逐行输出最终队列里的奶牛编号。

**编号口径。** 题面说"奶牛以 $1\dots N$ 的顺序排队"，结合样例解释逐条核对：第 1 条 `A L` 进来的是 $1$，第 2 条 `A L` 进来的是 $2$……第 8 条 `A` 进来的是 $8$——**编号就是"第几个执行 `A` 指令"**，与从哪端加入无关。这一点样例解释已经完整确认，无歧义。

**第一反应：这就是双端队列的定义。** 入队只发生在两端、出队也只发生在两端，中间元素永远不动。所以不需要任何高级数据结构，`deque` 或者"数组 + 左右指针"就能模拟。真正要想清楚的只有三件事：

1. **编号怎么发？** 用一个计数器 `cnt`，每遇到一条 `A` 就 `++cnt`，把 `cnt` 放进队里。离开的奶牛不再回来，所以编号永不重复、永不回收。
2. **`D L K` 要不要真的弹 $K$ 次？** 用 `deque` 的话就是循环 `pop_front()` $K$ 次。虽然总弹出次数不超过总入队次数（$\le S$），均摊下来也是 $O(S)$，但"数组 + 指针"写法里 `l+=k` 一步到位，单条指令最坏 $O(1)$，更干净。
3. **数组开多大、指针从哪开始？** 左端最多加入 $S$ 头，右端也最多加入 $S$ 头。把初始空队列放在数组正中（下标 $10^5$ 处），左边留 $10^5$ 个空位、右边留 $10^5$ 个空位，就**永远不会越界**。数组开 $2\times10^5+5$。这是"离线知道操作总数上界"时替代动态扩容的经典小技巧。

**为什么不用平衡树 / 链表？** 因为操作只碰两端。任何支持"序列中间插入"的结构都是杀鸡用牛刀；本题连 `deque` 的随机访问都不需要，两个 int 指针足矣。

**手造数据核对。** 题面样例解释给出了完整的 10 条指令与最终队列，直接用作第一组测试：

```
输入：              输出：
10                  7
A L                 2
A L                 5
A R                 6
A L                 8
D R 2
A R
A R
D L 1
A L
A R
```

逐步模拟：$1\to 2,1\to 2,1,3\to 4,2,1,3\to 4,2\to 4,2,5\to 4,2,5,6\to 2,5,6\to 7,2,5,6\to 7,2,5,6,8$，与题面解释逐条吻合。

第二组专打"左端连续入队后批量出队"：`A L / A L / A L / D L 2 / A R`（$S=5$）。队列变化 $1\to 2,1\to 3,2,1\to 1\to 1,4$，输出 `1` `4`。注意第 4 条指令一次弹两头，且第 5 条 `A R` 的编号是 $4$ 而不是 $3$——**被弹出的编号不回收**。

第三组专打"空队列状态"：`A R / D R 1 / A L / A L`（$S=4$）。队列 $1\to$ 空 $\to 2\to 3,2$，输出 `3` `2`。中途 `l==r`（空）时指针不越界、计数器照常递增。

另跑两组极限数据：$10^5$ 条 `A L`（左指针恰好降到 $0$，输出 $10^5,10^5-1,\dots,1$）与 $10^5$ 条 `A R`（右指针恰好升到 $2\times10^5$，输出 $1,\dots,10^5$），均正确，验证了"正中开局"的边界计算。

## 二、思维链：完整证明

**记号。** 指令序列 $c_1,\dots,c_S$。用半开区间 $[l,r)$ 表示数组 `a` 中当前队列占据的格子：$a[l]$ 是最左边的奶牛，$a[r-1]$ 是最右边的。初始 $l=r=10^5$（空队列）。`cnt` 为已发出的最大编号，初始 $0$。记 $A_L,A_R$ 分别为已执行的 `A L`、`A R` 条数。

---

### 引理 1（编号规则）

第 $t$ 条 `A` 指令（无论 `L` 还是 `R`）引入的奶牛编号为 $t$。

*证明*：这是题意解读层面的论证。题面规定奶牛编号 $1\dots N$ 且"一个接一个地站到队伍里"，样例解释中第 $1,2,3,4,5,6,7,8$ 条 `A` 指令引入的奶牛恰为 $1,2,3,4,5,6,7,8$（其中第 5 条 `A` 引入 $5$，尽管此前已有两头离开）。故编号 = `A` 指令的序号，与加入方向、与当前队列内容均无关。程序用 `++cnt` 在每条 `A` 指令处发号，`cnt` 恰等于已执行的 `A` 指令条数（对指令数归纳：初始 $0$；每遇 `A` 加 $1$，`D` 不改），与题意一致。证毕。

### 引理 2（表示不变量）

执行完任意前缀指令 $c_1,\dots,c_i$ 后，数组段 $a[l..r)$ 从左到右恰为当前队列，且其中元素互不相同。

*证明*：对 $i$ 归纳。

**基础** $i=0$：$l=r$，段为空，队列初始为空 ✓。

**归纳步**：设 $c_1,\dots,c_{i-1}$ 后不变量成立，考察 $c_i$ 的四种情形。

1. `A L`：程序执行 `a[--l]=++cnt`。新段为 $a[l-1..r)$，其首元素是新编号 `cnt`，其余部分 $a[l..r)$ 由归纳假设等于旧队列。题意要求新奶牛站到最左边，即新队列 = [新牛] + 旧队列 ✓。新编号 `cnt` 大于此前发出的一切编号（引理 1），故与段内旧元素不同，互异性保持。
2. `A R`：对称，`a[r++]=++cnt` 把新编号接在段尾，新队列 = 旧队列 + [新牛] ✓，互异性同理。
3. `D L K`：题意要求移除最左边的 $K$ 头。由归纳假设旧队列 = $a[l..r)$，其最左 $K$ 头是 $a[l..l+K)$。指令可执行保证 $K\le r-l$，故 $l+K\le r$，程序 `l+=k` 后新段 $a[l+K..r)$ 恰为旧队列去掉最左 $K$ 头 ✓。段是旧段的子段，互异性继承。
4. `D R K`：对称，`r-=k` 后新段 $a[l..r-K)$ 为旧队列去掉最右 $K$ 头 ✓。

四情形穷尽所有指令类型，归纳完成。证毕。

### 引理 3（指针界：数组永不越界）

全程成立 $0\le l\le r\le 2\times10^5<\texttt{mxn}$，因此对 `a` 的每次读写都在合法下标内。

*证明*：分三个不等式。

**$l\ge 0$**：$l$ 只在 `A L` 时减 $1$、在 `D L K` 时加 $K\ge1$（题意 $K$ 为正整数头数），其余指令不变。故任意时刻 $l\ge 10^5-A_L\ge 10^5-S\ge 0$（`A L` 条数不超过指令总数 $S\le10^5$）。

**$r\le 2\times10^5$**：对称地，$r$ 只在 `A R` 时加 $1$、在 `D R K` 时减，故 $r\le 10^5+A_R\le 10^5+S\le 2\times10^5$。数组尺寸 $\texttt{mxn}=200005>2\times10^5$，最大合法下标 $200004$，而写入下标最大为 $r-1\le 199999$ ✓。

**$l\le r$**：对指令归纳。初始 $l=r$ ✓。`A` 使区间变长，保持 $l\le r$。`D L K` 可执行意味着当前队列至少 $K$ 头，即 $K\le r-l$，故 $l+K\le r$；`D R K` 同理 $r-K\ge l$。所以任何时刻段长 $r-l\ge0$，特别地空队列时 $l=r$，后续 `A` 仍从该位置正确扩展（引理 2 的归纳不依赖段非空）。证毕。

**推论**：`a` 中从未被写过的格子不会被读到——输出循环只扫 $[l,r)$，而引理 2 保证该段内每个格子都是某条 `A` 指令写入后尚未被 `D` 移出的。全局数组默认 $0$ 的陷阱在本题不构成威胁，因为"未定义区域"被指针严格隔离。

### 引理 4（输出正确性）

程序输出 $a[l],a[l+1],\dots,a[r-1]$ 各占一行，恰为题目要求的最终队列。

*证明*：全部 $S$ 条指令执行完后，由引理 2（取 $i=S$），$a[l..r)$ 从左到右等于最终队列。题目要求"以从左到右的顺序输出，一个编号占一行"，程序的 `for(int i=l;i<r;++i)cout<<a[i]<<'\n'` 逐字实现该要求。题面保证最终队列非空，故至少输出一行（但即使为空，循环零次也不出错）。证毕。

### 引理 5（复杂度）

时间 $O(S+N)=O(S)$，空间 $O(S)$。

*证明*：每条指令的处理是常数次比较、读写与指针加减：`A` 为 $O(1)$；`D` 为 $O(1)$（**只移指针，不逐头弹出**，与 $K$ 无关）。$S$ 条指令共 $O(S)$。输出 $N$ 行，$N\le S$（每头牛对应一条 `A`），故输出 $O(S)$。总计 $O(S)$。空间：数组 $200005$ 个 `int` $\approx0.8$ MB，加常数个变量，$O(S)$。代入 $S=10^5$：约 $10^5$ 次常数操作加 $10^5$ 行输出，远在时限之内。证毕。

**对比**：若用 `deque` 逐头 `pop`，`D L K` 单条最坏 $O(K)$，但每头牛一生只被弹出一次，总弹出 $\le$ 总入队 $\le S$，均摊仍 $O(S)$——两种写法都正确，指针版胜在单条指令最坏 $O(1)$ 且零分配。

### 定理

程序对任意合法指令序列输出正确的最终队列，时间 $O(S)$、空间 $O(S)$。

*证明*：引理 1 保证编号发放符合题意；引理 2 保证数组段始终精确表示队列；引理 3 保证所有访问合法、无越界；引理 4 保证输出即答案；引理 5 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 操作只碰两端、中间不动 ⇒ 这是双端队列的抽象数据类型定义本身，不需要序列中间插入的任何重武器。
2. **explore its property** — 编号 = 第几条 `A` 指令（样例解释确认）；离开的牛不回来 ⇒ 一个单调递增计数器发号即可，不回收。
3. **classic problem solution** — 双端队列模拟：`deque` 或"数组 + 左右指针"；选后者，`D L K` 用 `l+=k` 一步完成，单条指令最坏 $O(1)$。
4. **reduce to easier problem** — 离线已知 $S\le10^5$ ⇒ 把空队列放在 $2\times10^5$ 数组正中，两端各留 $10^5$ 松弛，动态扩容问题塌缩成静态数组。
5. **discuss by category** — 四种指令逐一核对指针变化方向；空队列（`l==r`）、左指针触底（$l=0$）、右指针触顶（$r=2\times10^5$）三类边界单独造数据验证。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `s` | 指令条数 $S\le10^5$ | `int` | 读入 |
| `mxn` | 数组尺寸 $2\times10^5+5$ | `constexpr int` | 左右各 $10^5$ 松弛 + 5 |
| `a[mxn]` | 队列存储区，段 $[l,r)$ 有效 | `int[]` | 全局默认 $0$，但有效段外永不读取 |
| `l` | 左端指针，指向最左奶牛 | `int` | $10^5$（正中开局）；`A L` 减、`D L` 加 |
| `r` | 右端指针的**后一位**（半开区间） | `int` | $10^5$；`A R` 加、`D R` 减 |
| `cnt` | 已发出的最大编号 = 已执行 `A` 条数 | `int` | $0$，每条 `A` 先 `++cnt` 再入队 |
| `op,side` | 当前指令的类型与方向字符 | `char` | 每条指令读入 |
| `k` | `D` 指令的出队头数 | `int` | 仅 `D` 时读入 |

### 算法步骤

1. I/O 加速三行；读 $S$。
2. 逐条读指令：先读 `op,side`；若 `op=='D'` 再读 `k`。
3. `A L`：`a[--l]=++cnt`；`A R`：`a[r++]=++cnt`。
4. `D L K`：`l+=k`；`D R K`：`r-=k`。
5. 全部指令处理完后，`for(i=l;i<r;++i)` 输出 `a[i]` 与 `'\n'`。

### 复杂度

- 时间：$O(S)$，每条指令 $O(1)$，输出 $O(N)\le O(S)$。
- 空间：$O(S)$，约 $0.8$ MB 静态数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例解释的 10 条指令输出 `7 2 5 6 8` 吻合；另造"批量出队后编号不回收""中途空队列"两组及 $10^5$ 条 `A L` / `A R` 两组极限数据全部正确。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2952 [USACO09OPEN] Cow Line S
// 双端队列模拟：数组 + 左右指针，初始放在正中，两端各留 1e5 松弛
// D 操作只移动指针，O(1)；编号按 A 命令出现顺序递增
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{200005};

int s,cnt,l{100000},r{100000},a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	for(int i=0,k;i<s;++i)
	{
		char op,side;
		cin>>op>>side;
		if(op=='A')
		{
			if(side=='L')
				a[--l]=++cnt;
			else
				a[r++]=++cnt;
		}
		else
		{
			cin>>k;
			if(side=='L')
				l+=k;	// 左端弹出 k 头：指针右移即可
			else
				r-=k;
		}
	}
	for(int i=l;i<r;++i)
		cout<<a[i]<<'\n';
	return 0;
}
```

### 代码说明

- **半开区间 $[l,r)$**：`l` 指向最左元素，`r` 指向最右元素的后一位。空队列即 `l==r`，与初始状态一致，无需特判。
- `a[--l]=++cnt` 与 `a[r++]=++cnt` 的自增 / 自减位置是易错点：左端先减再写，右端先写再加。
- `D` 指令**不逐头弹出**，`l+=k` / `r-=k` 一步完成；被"弹出"的格子仍留在数组里，但已在有效段外，永不读取（引理 3 推论）。
- 编号计数器 `cnt` 只在 `A` 时递增，`D` 不影响——离开的奶牛编号不回收。
- `l,r` 初始 $10^5$ 而非 $0$：左端最多加入 $10^5$ 头，必须预留向左生长的空间；这是"正中开局"技巧的全部理由。
- 输出每头一行（题面要求），不是空格分隔。
