# P2918 [USACO08NOV] Buying Hay S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离干草背景）。** 有 $N$ 种物品（$1\le N\le 100$），第 $i$ 种重量 $P_i$（$1\le P_i\le 5000$）、价格 $C_i$（$1\le C_i\le 5000$），**每种可以买无限多件**。要求买到的总重量 **至少** $H$（$1\le H\le 50000$），最小化总价格。输出最小价格。

约束与边界：

- "至少 $H$"而不是"恰好 $H$"——**允许超重**，这是本题与普通完全背包唯一的区别，也是全部思维量的来源。
- 每件重量 $\ge 1$、价格 $\ge 1$：买 $H$ 件任意物品必然够重，所以**答案一定存在**，且不超过 $H\cdot\max C_i\le 50000\times5000=2.5\times10^8$（`int` 装得下）。
- $H=1$ 时答案就是 $\min C_i$（买最便宜的一包，哪怕它重 5000）。
- 题面 Hint 给了一组可反推的数据："在第二家公司买 3 包，共花费 9 美元"。我据此构造核对数据（见下），不依赖任何外部样例。

**手造极简数据核对：**

第一组（与 Hint 吻合）：$N=2,H=15$，公司 1 卖 $(P,C)=(3,2)$，公司 2 卖 $(5,3)$。

```
输入：
2 15
3 2
5 3

输出：
9
```

手算枚举：全买公司 1 需 5 包（15 磅）花 10；全买公司 2 需 3 包（15 磅）花 9；混买 $2\times5+2\times3=16$ 磅花 $6+4=10$。最优 9，恰是"第二家公司买 3 包花 9 美元"✓。

第二组（必须超重）：$N=1,H=10$，$(3,2)$。3 包只有 9 磅不够，必须买 4 包（12 磅）花 **8**。这组专门检验"至少"语义：恰好 10 磅根本凑不出来。

第三组（超重更便宜）：$N=1,H=7$，$(5,3)$。买 2 包（10 磅）花 **6**。

第四组（$H=1$ 边界）：$N=2,H=1$，$(5,100),(1,1)$，答案 **1**。

## 二、思维链：完整证明

**记号。** 需求 $j\in[0,H]$。$f[j]$ = 买到总重量 $\ge j$ 的最小花费。物品 $i$ 的重量 $P_i\ge1$、价格 $C_i\ge1$，件数不限。

### 第一步：识别模型——classic problem solution 的起点

"每种无限件 + 重量约束 + 最小化价格"，一眼**完全背包**。但标准完全背包回答的是"恰好装满容量 $j$ 的最优值"或"不超过 $j$ 的最优值"，本题是"**至少** $H$"。方向反了，不能直接套模板，得先想清楚怎么处理"超重"。

### 第二步：路线 A——"恰好 $j$"DP + 后缀取 min，需要一个上界

最直接的改法：令 $g[j]$ = 恰好买到 $j$ 磅的最小花费（不可达为 $+\infty$），做标准完全背包，然后答案 $=\min_{j\ge H}g[j]$。问题：$j$ 要枚举到多大？总重量原则上无上界（可以买一万包），必须证明**最优解不会超重太多**。

**引理 1（最优总重量上界）。** 设最优方案总重量为 $W^\*$，则 $W^\*\le H+P_{\max}-1$，其中 $P_{\max}=\max_i P_i\le 5000$。

*证明*：反证。设 $W^\*\ge H+P_{\max}$。最优方案至少含一件物品（$H\ge1$），任取其中一件，设其重量为 $p\le P_{\max}$、价格为 $c\ge1$。删去它后总重量 $W^\*-p\ge H+P_{\max}-P_{\max}=H$，仍然满足需求；而总花费减少了 $c\ge1$，**严格更便宜**，与最优性矛盾。故 $W^\*\le H+P_{\max}-1$。证毕。

于是路线 A 只需把 $g$ 开到 $H+P_{\max}$，答案 $=\min_{j=H}^{H+P_{\max}-1}g[j]$，复杂度 $O(N(H+P_{\max}))$。这条路线正确，但要多开 5000 的数组、多写一段后缀 min，而且"不可达为 $+\infty$"的初始化一不小心就踩全局数组默认 0 的坑。**有没有更干净的写法？**

### 第三步：路线 B——把"超重"直接吸收进状态定义

回到需求本身：我要的是"总重 $\ge j$"。买一件物品 $i$ 之后，**剩余需求**是多少？如果原来要 $\ge j$，这件贡献了 $P_i$，那么剩下的只需 $\ge j-P_i$；特别地，若 $j-P_i\le0$，这一件就已经达标，**剩余需求是 0，剩余花费是 0**。负数需求没有意义，把它**截断到 0**：

$$f[j]=\min_{1\le i\le N}\Bigl(f[\max(0,\,j-P_i)]+C_i\Bigr),\qquad f[0]=0.$$

这就是路线 B：状态空间恰好 $[0,H]$，不需要引理 1 的上界，不需要后缀 min，不需要"不可达"状态（任何 $j$ 都可达）。直觉上它把"所有 $\ge H$ 的总重量"折叠成一个状态，超重部分自动被 $\max(0,\cdot)$ 丢弃。直觉需要证明——下面两条引理分别证"不会漏解"和"不会算出非法解"。

**引理 2（最优子结构，$\ge$ 方向：递推式不会高估）。** 对 $j\ge1$，$f[j]\ge\min_i\bigl(f[\max(0,j-P_i)]+C_i\bigr)$。

*证明*：设 $S$ 是需求 $j$ 的一个最优购买方案（多重集），总重 $W(S)\ge j\ge1$，故 $S$ 非空。任取 $S$ 中一件物品 $i$。剩余方案 $S'=S\setminus\{i\}$ 的总重 $W(S')=W(S)-P_i\ge j-P_i$；又 $W(S')\ge0$，所以 $W(S')\ge\max(0,j-P_i)$，即 $S'$ 是需求 $\max(0,j-P_i)$ 的**可行解**。由 $f$ 的定义（最小花费），$\mathrm{cost}(S')\ge f[\max(0,j-P_i)]$。于是

$$f[j]=\mathrm{cost}(S)=\mathrm{cost}(S')+C_i\ge f[\max(0,j-P_i)]+C_i\ge\min_{i'}\bigl(f[\max(0,j-P_{i'})]+C_{i'}\bigr).$$

对任意最优方案都成立，故不等式成立。证毕。

**引理 3（可行性，$\le$ 方向：递推式不会低估）。** 对 $j\ge1$，$f[j]\le\min_i\bigl(f[\max(0,j-P_i)]+C_i\bigr)$。

*证明*：固定任意 $i$。取需求 $j'=\max(0,j-P_i)$ 的最优方案 $T$（$j'=0$ 时 $T=\varnothing$，花费 0）。给 $T$ 添一件物品 $i$，得方案 $T'=T\cup\{i\}$，总重

$$W(T')=W(T)+P_i\ge j'+P_i=\max(0,j-P_i)+P_i\ge j$$

（最后一步分两种情形：若 $j-P_i\ge0$，则 $j'+P_i=j$；若 $j-P_i<0$，则 $j'=0$，$j'+P_i=P_i>j$。）故 $T'$ 对需求 $j$ 可行，$f[j]\le\mathrm{cost}(T')=f[j']+C_i$。对每个 $i$ 都成立，取 min 即得。证毕。

**推论（递推式成立）**：引理 2、3 夹逼得 $f[j]=\min_i\bigl(f[\max(0,j-P_i)]+C_i\bigr)$，且 $f[0]=0$（什么都不买即满足需求 0，花费 0；花费非负故 0 最小）。

### 第四步：计算顺序的合法性——归纳闭环

递推式右边的下标 $\max(0,j-P_i)$ 会不会 $\ge j$ 导致循环依赖？不会：

**引理 4（无后效性 / 归纳正确性）。** 因 $P_i\ge1$，对 $j\ge1$ 有 $\max(0,j-P_i)\le j-1<j$。故按 $j=1,2,\dots,H$ 升序计算时，右边所有 $f$ 值都已算完且不再改变；对 $j$ 归纳即得每个 $f[j]$ 都等于真实最优值。

*证明*：对 $j$ 归纳。基例 $j=0$：$f[0]=0$ 正确（引理 3 推论）。归纳步：设 $f[0..j-1]$ 全部正确。计算 $f[j]$ 时引用的每个 $f[\max(0,j-P_i)]$ 下标 $\le j-1$，由归纳假设是真实最优值；由引理 2、3 的夹逼，用真实值算出的 $\min_i(\cdot)$ 恰是 $f[j]$ 的真实最优值。证毕。

顺带一提：这个 DP **不需要**完全背包标志性的"正序循环容量"技巧——那个技巧是为了让同一物品被重复选用；这里每件物品的"重复使用"已经体现在状态转移本身（$f[j-P_i]$ 里可以再含物品 $i$），外层枚举 $j$、内层枚举 $i$ 即可，物品顺序无关紧要。

### 第五步：数值范围与初始化——explore its property

**引理 5（值域与 int 安全性）。** 对所有 $j\le H$，$f[j]\le j\cdot C_{\max}\le H\cdot 5000=2.5\times10^8<2^{31}-1$；哨兵取 $\mathrm{inf}=1145141919$ 时，$\mathrm{inf}+C_i\le1145146919<2^{31}-1$，中间加法不溢出。

*证明*：可行性上界：买 $j$ 件最便宜的物品（每件重 $\ge1$）总重 $\ge j$，花费 $\le j\cdot C_{\max}$。代入 $j\le H=50000,C_{\max}\le5000$ 得 $2.5\times10^8$。哨兵加法：$1145141919+5000=1145146919<2147483647$ ✓。故全程 `int` 安全。证毕。

初始化陷阱：$f[1..H]$ 的"未计算"值必须是 $\mathrm{inf}$ 而不是全局默认的 $0$——$0$ 会被 $\min$ 当成"免费达标"，答案直接错成 0。所以 `fill_n(f,h+1,inf)` 后再置 `f[0]=0`。（实际上由引理 5 每个状态都可达，算完后不会有 inf 残留，但计算**过程中** min 的语义要求初值是 inf。）

**引理 6（复杂度）。** 时间 $O(NH)$，空间 $O(H+N)$。

*证明*：外层 $j$ 循环 $H$ 次，内层 $i$ 循环 $N$ 次，每次一个 $\max$、一个加法、一个 $\min$，$O(1)$。合计 $NH\le100\times50000=5\times10^6$ 次基本操作，远低于时限。数组 `f` 长 $H+1$，`p,c` 各长 $N$。证毕。

### 定理

程序输出 $f[H]$，即买到至少 $H$ 磅干草的最小花费。

*证明*：引理 2、3 夹逼证明递推式刻画了真实最优值；引理 4 保证升序计算恰好实现该递推；引理 5 保证 `int` 与哨兵不溢出、初始化语义正确；引理 6 给出复杂度。故输出的 $f[H]$ 正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **classic problem solution** — 识别"无限件 + 重量 + 最小花费"= 完全背包骨架。
2. **explore its property** — 本题约束是"至少 $H$"而非"恰好/不超过"，超重合法，模板不能直接套。
3. **consider easier version** — 路线 A：先做"恰好 $j$"DP，再对 $j\ge H$ 取后缀 min；用交换/删件论证证明最优总重 $\le H+P_{\max}-1$，把无界枚举截成有界。
4. **reduce to easier problem** — 路线 B：把状态重定义为"至少 $j$"，买一件后剩余需求 $\max(0,j-P_i)$，超重被截断吸收，状态空间缩回 $[0,H]$。
5. **classic problem solution** — 双向夹逼证明最优子结构（删一件得可行解 ⇒ 不高估；加一件得可行解 ⇒ 不低估），升序归纳闭环。
6. **discuss by category** — 值域 $2.5\times10^8$ 用 int 安全；$f$ 必须显式 fill 成 inf（默认 0 是"免费达标"的陷阱）；$H=1$、必须超重等边界用手造数据覆盖。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N,H$ | 公司数 $\le100$、需求磅数 $\le50000$ | `int n,h` | 读入 |
| `mxn` | $100+5$ | `constexpr int` | 物品数组尺寸 |
| `mxh` | $50000+5$ | `constexpr int` | DP 数组尺寸 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | "尚未算出"，加 5000 不溢出 |
| `p[i],c[i]` | 第 $i$ 包干草的重量、价格 | `int[mxn]` | 读入，0-based |
| `f[j]` | 买到总重 **至少** $j$ 磅的最小花费 | `int[mxh]` | `fill_n(f,h+1,inf)`；`f[0]=0`；记忆点：**需求截断到 0** |
| `j` | 当前需求（升序枚举） | `int` | $1..H$ |
| `i` | 当前枚举的"最后买的一包" | `int` | $0..N-1$ |

### 算法步骤

1. I/O 加速三行；读 $N,H$ 与所有 $(P_i,C_i)$。
2. `fill_n(f,h+1,inf)`，`f[0]=0`。
3. 对 $j=1..H$：对每个 $i$，`f[j]=min(f[j],f[max(0,j-p[i])]+c[i])`。
4. 输出 `f[h]`。

### 复杂度

- 时间 $O(NH)\le5\times10^6$；空间 $O(H+N)$，约 200 KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；四组手造数据（Hint 反推组=9、必须超重组=8、超重更便宜组=6、$H=1$ 组=1）输出与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2918 [USACO08NOV] Buying Hay S
// f[j]=买到至少 j 磅的最小花费；买一包 i 后剩余需求 max(0,j-p[i])，
// 超重被截断吸收 ⇒ 状态空间恰好 [0,H]，无需"恰好 j + 后缀 min"的上界讨论。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105},mxh{50005},inf{1145141919};

int n,h,p[mxn],c[mxn],f[mxh];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>h;
	for(int i=0;i<n;++i)
		cin>>p[i]>>c[i];
	fill_n(f,h+1,inf);	// 默认 0 会被 min 当成"免费达标"，必须显式置 inf
	f[0]=0;	// 需求 0 磅：什么都不买
	for(int j=1;j<=h;++j)
		for(int i=0;i<n;++i)
			f[j]=min(f[j],f[max(0,j-p[i])]+c[i]);	// 下标 <j，已算完
	cout<<f[h]<<'\n';
	return 0;
}
```

### 代码说明

- 核心一行 `f[j]=min(f[j],f[max(0,j-p[i])]+c[i])`：`max(0,·)` 就是"这一包已经超重达标，剩余需求归零"的数学表达，引理 2、3 证明它不多算也不少算。
- 因 $P_i\ge1$，转移下标 $\le j-1$，升序一遍即可，**不需要**完全背包的"容量正序"技巧——物品的无限次使用已隐含在 $f[j-P_i]$ 自身可再含物品 $i$ 之中。
- `fill_n(f,h+1,inf)` 是必须的：全局默认 0 会让 `min` 误以为所有需求都能免费满足。`inf+5000` 仍在 int 范围内（引理 5）。
- 答案上界 $H\cdot C_{\max}=2.5\times10^8$，`int` 足够，无需 `long long`。
