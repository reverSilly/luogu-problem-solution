# P2850 [USACO06DEC] Wormholes G — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $F\le 5$ 个农场，每个农场有 $N\le 500$ 块田地、$M\le 2500$ 条**双向**路径（耗时 $T\le 10000$ 秒，两点间可能有多条）、$W\le 200$ 个**单向**虫洞（从 $S$ 到 $E$，把时间往回拨 $T\le 10000$ 秒）。问：能否从**某块田地出发**（起点任选），走若干路径与虫洞后，在**出发时刻之前**回到起点。每个农场输出一行 `YES`/`NO`。

**第一步：把"时间回溯"翻译成图论语言。** 给每条边一个"时间增量"权值：走路径花 $+T$ 秒，走虫洞花 $-T$ 秒。那么沿一条途径（walk）走下来，总的时间变化就是**边权之和**——出发时刻加上这个和，就是回到起点时的时刻。"在出发之前回到起点"即：存在一条**起点=终点、边权和严格小于 $0$** 的闭途径。注意是**严格**小于：权值和为 $0$ 的环只能"恰好同时"回来，遇不到过去的自己。

于是问题变成：这张混合图（正权双向边 + 负权单向边）里**是否存在负环**？这就是标签里"负权环"三个字的来历。

**第二步：闭途径可以换成环，起点自由可以去掉。** 两个小归约：

- 任何闭途径都能拆成若干个简单环的并（把途径中重复出现的点之间截段）。若闭途径总权 $<0$，拆出的环里至少一个权 $<0$；反过来，一个负环本身就是合法闭途径。所以"存在负闭途径" $\iff$ "存在负环"。
- 题目允许从**任意**田地出发，所以负环在图的哪个角落都无所谓，不需要"从某指定点可达"这种限制。等价地：建一个虚拟超级源点，向所有点连 $0$ 权边，则"图中任何位置有负环" $\iff$ "超级源点可达负环"。

**第三步：先看简单版本找感觉。** 如果没有虫洞（$W=0$ 的效果），所有边权为正，任何环的权都为正，答案必为 `NO`。这说明本题的全部难度都集中在**负权边**上——而负权边一旦成环，最短路就无下界，这正是 Bellman-Ford 的主场。

**第四步：选算法。** 判负环的三件经典工具：

- Floyd：跑完看 `d[i][i]<0`。$O(N^3)=1.25\times10^8$ 每个农场，$\times 5=6.25\times10^8$，在 $1$ s 时限边缘疯狂试探，不选。
- SPFA：某点入队 $\ge N$ 次判负环，期望快但最坏 $O(N\cdot E)$ 且常被卡。
- Bellman-Ford：把所有边松弛 $N$ 轮，第 $N$ 轮仍能松弛 $\iff$ 有负环。复杂度 $O(N\cdot(2M+W))\le 500\times 5200=2.6\times10^6$ 每个农场，$\times 5\approx1.3\times10^7$，稳过。

选 Bellman-Ford。它通常需要一个源点，但第二步已经说了：**起点自由 $\iff$ 超级源点 $\iff$ 把 `dis` 数组全部初始化成 $0$**（超级源点那圈 $0$ 权边松弛一遍的效果就是全 $0$）。这里有个和平时相反的细节：一般最短路题 `dis` 要填 INF，而本题 **$0$ 恰恰是有意义的初值**，千万别顺手填 INF——填了 INF 就变成"只从 $0$ 号点出发"，会漏掉不与 $0$ 号点连通的负环。

**第五步：判定规则抠严格。** 跑 $N$ 轮松弛：

- 若某一轮**没有任何边被松弛**，说明 `dis` 已满足所有三角不等式 `dis[v]≤dis[u]+w`。把任何一个环上的不等式加起来得 $0\le$ 环权，故不可能有负环 → `NO`，且可以立即提前退出。
- 若 $N$ 轮**轮轮都有松弛**，则有负环 → `YES`。理由（完整证明见引理 4、5）：无负环时最优途径可取简单路（$\le N-1$ 条边），$N-1$ 轮后必然稳定；所以第 $N$ 轮还在动，只能是负环在把距离无限往下拽。

**第六步：实现细节。**

1. 双向路径拆成**两条**方向相反的正权有向边；虫洞是一条负权有向边。边表容量 $2M+W\le 5200$。
2. 重边直接全存，Bellman-Ford 天然支持。
3. 虫洞可能 $S=E$（题面没禁止）：负权自环就是负环，松弛条件 `dis[u]>dis[u]-T` 恒成立，算法自动判 `YES`，无需特判。
4. 数值范围：$k$ 轮后 `dis[v]` 是某条 $\le k$ 边途径的权和，$\ge -500\times10000=-5\times10^6$，`int` 绰绰有余。
5. 多测：每个农场重建边表（`ec=0`）、`fill_n(dis,n,0)`。

## 二、思维链：完整证明

**记号。** 一个农场是有向带权图 $G=(V,E)$，$|V|=N$。每条路径 $\{S,E,T\}$ 贡献两条边 $(S,E,+T),(E,S,+T)$；每个虫洞 $(S,E,T)$ 贡献一条边 $(S,E,-T)$。途径 $W=(v_0,e_1,v_1,\dots,e_k,v_k)$ 的权 $w(W)=\sum_i w(e_i)$，长度（边数）为 $k$。闭途径指 $v_0=v_k$。简单环指除首尾外顶点互异的闭途径。

---

### 引理 1（时间回溯 $\iff$ 负闭途径）

FJ 能"在出发时刻之前回到起点"，当且仅当 $G$ 中存在权 $<0$ 的闭途径。

*证明*：设 FJ 在时刻 $t_0$ 从 $v_0$ 出发，依次经过边 $e_1,\dots,e_k$ 回到 $v_0$。每走一条边，时刻增加该边权（路径 $+T$：时刻前进；虫洞 $-T$：时刻倒退），对 $k$ 归纳即得回到起点的时刻为 $t_0+w(W)$。"在出发之前"即 $t_0+w(W)<t_0\iff w(W)<0$。反之，给定负闭途径，FJ 从其起点出发沿它走一遍即达成目标。两个方向都成立。证毕。

---

### 引理 2（负闭途径 $\iff$ 负简单环；起点自由）

$G$ 存在负闭途径 $\iff$ $G$ 存在负简单环。且由于起点任选，负环位于任何连通块都算数。

*证明*：($\Leftarrow$) 简单环是闭途径的特例，显然。

($\Rightarrow$) 设负闭途径 $W$ 边数最少（在所有负闭途径中取边数最小者）。若 $W$ 除首尾外有重复顶点 $v_i=v_j$（$0\le i<j\le k$，且 $(i,j)\ne(0,k)$），则把 $W$ 拆成两段闭途径 $W_1=(v_i,\dots,v_j)$ 与 $W_2$（去掉中间段后首尾相接），$w(W)=w(W_1)+w(W_2)<0$，故至少一段权 $<0$，且其边数严格小于 $W$（$W_1$ 边数 $j-i<k$；$W_2$ 边数 $k-(j-i)<k$），与 $W$ 的最小性矛盾。故 $W$ 是简单环。

起点自由：题目不指定起点，任何负环上的任一点都可作出发点（引理 1 的构造），故无需可达性条件。证毕。

---

### 引理 3（全 $0$ 初始化的 Bellman-Ford 不变量）

令 `dis` 初值全 $0$，每轮按任意固定顺序对所有边做一次松弛 `dis[v]=min(dis[v],dis[u]+w)`。则第 $k$ 轮结束后：

(a) 每个 `dis[v]` 要么为 $0$（空途径），要么等于某条**以 $v$ 结尾、边数 $\le k$** 的途径的权；
(b) `dis[v]` $\le$ 任何以 $v$ 结尾、边数 $\le k$ 的途径的权。

*证明*：对 $k$ 归纳。$k=0$：`dis[v]=0` 是空途径（$0$ 条边）的权，(a)(b) 平凡成立。

设 $k-1$ 轮后成立。第 $k$ 轮中每次松弛把 `dis[v]` 更新为 `dis[u]+w`：由归纳假设 (a)，`dis[u]` 对应某条 $\le k-1$ 边、以 $u$ 结尾的途径，接上边 $(u,v)$ 得到 $\le k$ 边、以 $v$ 结尾的途径，权恰为 `dis[u]+w`，故 (a) 保持。对 (b)：任取以 $v$ 结尾、边数 $\le k$ 的途径 $W$。若 $W$ 边数 $\le k-1$，由归纳假设 `dis[v]` 在本轮只会减小，仍 $\le w(W)$。若 $W$ 恰 $k$ 条边，设最后一条边为 $(u,v)$，前缀 $W'$ 以 $u$ 结尾、$k-1$ 条边；由归纳假设 (b)，第 $k$ 轮处理边 $(u,v)$ 时 `dis[u]` $\le w(W')$（本轮 `dis[u]` 只减不增），于是该次松弛后 `dis[v]` $\le$ `dis[u]`$+w\le w(W')+w=w(W)$。故 (b) 保持。证毕。

**推论**：`dis[v]` 永远不低于"以 $v$ 结尾的所有途径的权下确界"——它始终对应一条真实途径，不会凭空变小。

---

### 引理 4（无负环 $\Rightarrow$ $N-1$ 轮后稳定）

若 $G$ 无负简单环，则第 $N-1$ 轮结束后，任何边都无法再被松弛（从而第 $N$ 轮无变化）。

*证明*：定义 $\delta(v)=\min\{w(W):W\text{ 以 }v\text{ 结尾}\}$（允许任意起点、空途径）。先证该最小值可由**简单路**达到：任取途径 $W$，若它有重复顶点，截出的环权 $\ge0$（无负环，引理 2 的拆分论证），删去该环不增权、边数减少；反复删环得简单路 $W'$，$w(W')\le w(W)$，边数 $\le N-1$。故 $\delta(v)$ 等于"以 $v$ 结尾、$\le N-1$ 边的途径"的最小权。

由引理 3(b)，第 $N-1$ 轮后 `dis[v]` $\le\delta(v)$；由引理 3(a)，`dis[v]` 是某条真实途径的权 $\ge\delta(v)$。故 `dis[v]` $=\delta(v)$。

再证此时无边可松弛：对任意边 $(u,v,w)$，把达到 $\delta(u)$ 的简单路接上该边，得到以 $v$ 结尾的途径，故 $\delta(v)\le\delta(u)+w$，即 `dis[v]` $\le$ `dis[u]`$+w$，松弛条件不成立。证毕。

---

### 引理 5（有负环 $\Rightarrow$ 每一轮都有松弛）

若 $G$ 有负简单环，则无论已经跑了多少轮，下一轮至少有一条边被松弛。

*证明*：反证。设某轮没有任何边被松弛，则轮末对所有边 $(u,v,w)$ 有 `dis[v]` $\le$ `dis[u]`$+w$。取负环 $C=(v_0,v_1,\dots,v_k=v_0)$，把环上 $k$ 条边的不等式相加：$\sum_i$ `dis[`$v_i$`]` $\le\sum_i$ `dis[`$v_{i-1}$`]`$+\sum_i w_i$。左右两边的 `dis` 项是同一多重集（环上每个点恰出现一次），消去得 $0\le w(C)<0$，矛盾。故每轮必有松弛。证毕。

（注意此论证不依赖初值、不依赖可达性：全 $0$ 初始化下所有点都"可达"，负环 wherever 都逃不掉。）

---

### 引理 6（判定规则正确）

程序跑至多 $N$ 轮：若某轮无变化则提前退出并输出 `NO`；若 $N$ 轮全有变化则输出 `YES`。该规则与"存在负环"等价。

*证明*：无负环时，由引理 4，第 $N$ 轮必无变化，故程序必在第 $N$ 轮或之前提前退出，输出 `NO` ✓。有负环时，由引理 5，每轮都有变化，程序不会提前退出，跑满 $N$ 轮输出 `YES` ✓。两方向穷尽。证毕。

---

### 引理 7（复杂度与数值范围）

单农场时间 $O(N\cdot(2M+W))$，空间 $O(N+M+W)$；全程 `int` 不溢出。

*证明*：每轮扫边表一遍 $O(2M+W)$，至多 $N$ 轮。$F$ 个农场共 $O(F\cdot N\cdot(2M+W))\le 5\times500\times5200=1.3\times10^7$ 次松弛尝试。空间：边表 $5205$ 个三元组 + `dis` $505$ 个 `int`。

数值：由引理 3(a)，$k$ 轮后 `dis[v]` 是 $\le k\le N$ 条边的途径权和，每条边权 $\in[-10000,10000]$，故 `dis[v]` $\in[-5\times10^6,10^7]$，远小于 `int` 上限 $2.1\times10^9$；松弛中间量 `dis[u]+w` 同范围。证毕。

---

### 定理

程序对每个农场输出 `YES` 当且仅当 FJ 能回到出发时刻之前，总时间 $O(F\cdot N\cdot(2M+W))$。

*证明*：引理 1 把目标翻译成负闭途径；引理 2 归约为负简单环且去掉起点限制；引理 3 给出全 $0$ 初始化（超级源点）的合法性；引理 4、5 从两个方向夹出"第 $N$ 轮仍松弛 $\iff$ 负环"；引理 6 说明程序判定规则与之等价；引理 7 给出复杂度与数值安全。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 时间回溯 = 负权边：路径 $+T$ 双向、虫洞 $-T$ 单向，"回到出发前" = 闭途径权和 $<0$（严格）。
2. **reduce to easier problem** — 负闭途径拆环 $\iff$ 负简单环；起点任选 $\iff$ 负环在哪都行。
3. **consider easier version** — 无虫洞则全正权必 `NO`，确认难点只在负环判定。
4. **classic problem solution** — 判负环三选一：Floyd $O(N^3)$ 太肥、SPFA 易被卡，选 Bellman-Ford $O(N(2M+W))$。
5. **classic problem solution** — 起点自由 $\iff$ 虚拟超级源点 $\iff$ `dis` 全 $0$ 初始化（本题 $0$ 是合法初值，别填 INF）。
6. **discuss by category** — 某轮无松弛 $\Rightarrow$ 三角不等式全成立 $\Rightarrow$ 无负环（提前退出）；$N$ 轮轮轮松弛 $\Rightarrow$ 负环；零权环不算、负自环算。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $F$ | 农场数，$\le5$ | `int F` | 读入 |
| $N,M,W$ | 田地 / 双向路径 / 虫洞数 | `int n,m,w` | 每农场读入 |
| `E[i]={u,v,w}` | 第 $i$ 条有向边（0-based 端点） | `edge[mxm]` | 路径拆两条 $+T$，虫洞一条 $-T$ |
| `ec` | 当前农场边数 | `int` | 每农场置 $0$ |
| `dis[v]` | 超级源点意义下 $v$ 的当前最短估计 | `int[mxn]` | **每农场 `fill_n(dis,n,0)`**（$0$ 是合法初值！） |
| `mxn` | $500+5$ | `constexpr int` | 点数上界 |
| `mxm` | $2\times2500+200+5=5205$ | `constexpr int` | 边数上界 |
| `it` | 已完成的松弛轮数 | `int` | 循环变量；`it==n` $\iff$ 轮轮有松弛 |
| `chg` | 本轮是否发生过松弛 | `bool` | 每轮置 `false` |

### 算法步骤

1. I/O 加速三行；读 $F$。
2. 对每个农场：读 $N,M,W$；`ec=0`；读 $M$ 条路径，各加两条 $+T$ 有向边；读 $W$ 个虫洞，各加一条 $-T$ 有向边（端点全部 `--` 转 0-based）。
3. `fill_n(dis,n,0)`（超级源点）。
4. 松弛至多 $N$ 轮：每轮扫 `E[0..ec)`，若 `dis[v]>dis[u]+w` 则更新并置 `chg=true`；本轮 `chg=false` 则 `break`。
5. 循环结束时 `it==n` 输出 `YES`，否则输出 `NO`。

### 复杂度

- 时间：$O(F\cdot N\cdot(2M+W))\le1.3\times10^7$ 次松弛尝试。
- 空间：$O(N+M+W)$，边表约 $62$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造"负环 / 无负环""零权环 / 负自环"两组共 $4$ 个农场逐一核对无误。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2850 [USACO06DEC] Wormholes G
// 思路：路径=正权双向边，虫洞=负权单向边；「回到出发之前」⟺ 存在负环（严格负）。
//       起点自由 ⇒ 虚拟超级源点 ⇒ dis 全 0 起步的 Bellman-Ford；
//       第 n 轮仍能松弛 ⟺ 有负环；某轮无松弛即可提前判 NO。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{505},mxm{5205};	// 2*2500+200+5

struct edge{int u,v,w;}E[mxm];
int n,m,w,ec,dis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int F;
	cin>>F;
	while(F--)
	{
		cin>>n>>m>>w;
		ec=0;
		for(int i=0,u,v,t;i<m;++i)
		{
			cin>>u>>v>>t;--u;--v;
			E[ec++]={u,v,t};	// 双向路径拆成两条正权有向边，重边照存
			E[ec++]={v,u,t};
		}
		for(int i=0,u,v,t;i<w;++i)
		{
			cin>>u>>v>>t;--u;--v;
			E[ec++]={u,v,-t};	// 虫洞：单向负权；S==E 的负自环也能被自动判出
		}
		fill_n(dis,n,0);	// 超级源点向所有点连 0 边 ⟺ 全 0 初始化（这里 0 不是"未访问"！）
		int it=0;
		for(;it<n;++it)
		{
			bool chg=false;
			for(int i=0;i<ec;++i)
				if(dis[E[i].v]>dis[E[i].u]+E[i].w)
				{
					dis[E[i].v]=dis[E[i].u]+E[i].w;
					chg=true;
				}
			if(!chg)
				break;	// 三角不等式全部成立 ⇒ 无负环
		}
		cout<<(it==n?"YES\n":"NO\n");	// 跑满 n 轮仍在松弛 ⇒ 负环
	}
	return 0;
}
```

### 代码说明

- `dis` 全 $0$ 是本题的灵魂：它等价于超级源点，保证任何连通块里的负环都逃不掉。若习惯性地填 INF，就退化成"只从 $0$ 号点出发"，会漏判。
- 判定用"跑满 $N$ 轮"而不是"第 $N$ 轮单独检查"：`it==n` 当且仅当每轮都有松弛，由引理 4、5 这与负环存在等价。
- 边表每农场重建（`ec=0`），`dis` 每农场 `fill_n` 重置，多测互不污染。
- 全程 `int`：`dis` 下界 $-5\times10^6$，无溢出风险（引理 7）。
