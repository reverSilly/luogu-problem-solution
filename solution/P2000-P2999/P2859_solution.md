# P2859 [USACO06FEB] Stall Reservations S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 头奶牛（$1\le N\le 5\times 10^4$），第 $i$ 头的产奶时段是**闭区间** $[A_i,B_i]$（$1\le A_i\le B_i\le 10^6$，两端点都算在内）。同一牛棚里的任意两头牛时段不能有任何公共时刻（连端点相碰都不行）。求最少牛棚数，并输出每头牛分到哪个棚（SPJ，任意一种最优方案均可）。

**第一步：把"牛棚"翻译成数学对象。** 一个牛棚里装的是若干头牛，它们的区间必须**两两不交**。所以题目就是：把 $N$ 个闭区间划分成尽量少的组，每组内两两不交。这是经典的**区间划分（interval partitioning）**问题。先抠一个细节：区间是闭的，$[1,2]$ 和 $[2,3]$ 在时刻 $2$ 相撞，**不能**同棚。这个"端点相碰也算冲突"的口径是本题最容易写挂的地方，后面会专门造数据打它。

**第二步：答案有没有下界？** 找一个"最挤的时刻"。若某个时刻 $t$ 同时落在 $d$ 个区间里，这 $d$ 头牛两两冲突，鸽笼原理告诉我们至少要有 $d$ 个棚。记最大覆盖深度
$$D=\max_{t}\bigl|\{i:A_i\le t\le B_i\}\bigr|,$$
则答案 $\ge D$。这个下界非常便宜：扫一遍端点就能算。于是自然猜想：**答案会不会恰好等于 $D$？** 如果真是这样，我们甚至不需要"算出 $D$ 再构造"，只要找到一个永远只用 $D$ 个棚的构造法就行。

**第三步：什么样的构造法有希望？** 换个视角：按时间从左往右"接待"奶牛。每头牛到来时，给它找一个已经空出来的棚（上一头牛已经结束），找不到就开新棚。为了让"开新棚"尽量少，直觉上应该**按开始时间排序**依次处理——这样处理到第 $i$ 头牛时，所有可能和它抢棚的"早开始的牛"都已经安置好了，决策不会被未来反悔。

那"空出来的棚"有多个时选哪个？选**最后结束时间最早**的那个（小根堆堆顶）。理由很朴素：结束越早的棚越"空闲"，把结束晚的棚留给后面可能更晚开始的牛。不过先别急着相信这个贪心——它真的最优吗？

**第四步：最优性怎么证？交换论证卡住了，换一条路。** 通常贪心最优性用交换论证（"最优解和我选得不一样，把它换过来不变差"）。但这题有个更漂亮的**直接计数**思路，根本不用交换：

> 贪心什么时候开新棚？当且仅当**所有**已开的棚的"最后结束时间"都 $\ge A_i$（堆顶是最小值，堆顶都 $\ge A_i$ 说明全都 $\ge A_i$）。

假设这是开的第 $k$ 个棚。那么已有的 $k-1$ 个棚，每个棚里最后那头牛满足：开始时间 $\le A_i$（按开始排序，先处理），结束时间 $\ge A_i$（刚才的条件）——所以它的区间**包含时刻 $A_i$**！加上当前这头牛自己也包含 $A_i$，我们当场抓到了 $k$ 个两两冲突、共同覆盖 $A_i$ 的区间。于是 $D\ge k$。

这说明：**贪心每开一个新棚，都能出示一个"此刻确实需要这么多棚"的现场证据**。开的棚总数 $\le D$；又第二步证了答案 $\ge D$；而贪心方案本身合法（下面证），所以贪心用的棚数恰好 $=D=$ 最优。猜想成立，而且证明比交换论证干净得多。

**第五步：落地成代码。** 结构体存 $\{A,B,\text{原编号}\}$，按 $A$ 排序（$A$ 相同随意，证明只用到"先处理的开始时间 $\le A_i$"）；小根堆存二元组 $(\text{棚的最后结束时间},\text{棚编号})$。对每头牛：堆非空且堆顶结束时间 $<A_i$（**严格小于**，闭区间！）就弹出复用、压入 $(B_i,\text{同一棚号})$；否则开新棚。答案记到 `ans[原编号]`，最后按输入顺序输出。复杂度 $O(N\log N)$，$5\times10^4$ 轻松通过。

**手造数据核对**（按题面规则自己造，专门打"端点相碰"）：

4 头牛：$[1,3],[2,5],[4,6],[1,2]$。牛1 与牛4 开始时间并列，排序后谁先谁后取决于排序实现（引理 5 会证任意并列定序都最优）。参考实现实际产生的顺序：牛1 $[1,3]$ → 牛4 $[1,2]$ → 牛2 $[2,5]$ → 牛3 $[4,6]$。

- 牛1：无棚，开棚 1，堆 $\{(3,1)\}$。
- 牛4：堆顶结束 $3\ge 1$，开棚 2，堆 $\{(2,2),(3,1)\}$。
- 牛2：堆顶结束 $2\ge 2$（**端点相碰，不能复用！**），开棚 3，堆 $\{(2,2),(3,1),(5,3)\}$。
- 牛3：堆顶结束 $2<4$，复用棚 2，堆 $\{(3,1),(5,3),(6,2)\}$。

输出棚数 $3$；分配：牛1→1，牛2→3，牛3→2，牛4→2。核对下界：时刻 $2$ 被 $[1,3],[2,5],[1,2]$ 三个区间覆盖，$D=3$，吻合。若把复用条件误写成 `<=`，牛2 会复用棚 2，输出 $2$ 个棚且 $[1,2]$ 与 $[2,5]$ 同棚——非法。这组数据把口径错误一击毙命。（若并列定序不同，分配方案会不同，但棚数恒为 $3$；SPJ 接受任意最优方案。）

## 二、思维链：完整证明

**记号。** 区间 $I_i=[A_i,B_i]$（闭），$0\le i<N$。称 $i,j$ **冲突**当且仅当 $I_i\cap I_j\ne\varnothing$。一个**合法方案**是把 $\{0,\dots,N-1\}$ 划分成若干组（棚），每组内任意两头牛不冲突。最优值记 $\mathrm{OPT}$。最大深度 $D=\max_{t\in\mathbb{Z}}|\{i:A_i\le t\le B_i\}|$（$t$ 取遍整数时刻即可，因为端点都是整数，覆盖数只在端点处变化）。

贪心算法：把牛按 $A$ 升序排序（并列任意）得序列 $c_0,\dots,c_{N-1}$；维护小根堆 $Q$，元素为 $(e,s)$：棚 $s$ 已接待的牛中最大的 $B$ 值 $e$。依次处理每头牛 $(A,B)$：若 $Q$ 非空且堆顶 $e<A$，弹出堆顶 $(e,s)$，令该牛入棚 $s$，压入 $(B,s)$；否则开新棚 $s=\text{cnt}$（$\text{cnt}$ 自增），压入 $(B,s)$。

---

### 引理 1（下界：$\mathrm{OPT}\ge D$）

*证明*：设时刻 $t^\*$ 达到最大深度，即有 $D$ 个区间 $I_{i_1},\dots,I_{i_D}$ 都包含 $t^\*$。任取其中两个 $I_{i_p},I_{i_q}$，它们都含 $t^\*$，故交非空，冲突，必须分在不同棚。于是这 $D$ 头牛占据 $D$ 个互不相同的棚（鸽笼原理的逆否：$D$ 个两两不同的对象放进 $<D$ 个盒子必有两个同盒，而同盒非法）。任何合法方案棚数 $\ge D$，取最小即 $\mathrm{OPT}\ge D$。证毕。

---

### 引理 2（贪心方案的合法性）

贪心结束后，每个棚内的区间两两不交，且每头牛恰好被分配一次。

*证明*：每头牛在排序序列中出现一次，处理时恰好执行"复用"或"新开"之一，故恰好分配一次。

对棚内合法性，固定一个棚 $s$，对它接待的牛按处理顺序归纳。设棚 $s$ 已接待的牛区间两两不交，且堆中 $s$ 对应的 $e$ 等于这些区间右端点的最大值（**归纳不变量**）。初始棚 $s$ 只有一头牛，平凡成立。下一次棚 $s$ 被复用，必是因为堆顶 $(e,s)$ 满足 $e<A_{\text{新}}$。棚内每头旧牛的 $B\le e<A_{\text{新}}\le B_{\text{新}}$，故旧区间整体在新左侧、无公共点，新牛与所有旧牛不交；又新区间右端点 $B_{\text{新}}\ge A_{\text{新}}>e$，压入 $(B_{\text{新}},s)$ 后 $e$ 仍为右端点最大值，不变量保持。

还需确认堆操作维护了"每棚恰一个堆元素"：开新棚压入一个新棚号；复用弹出 $(e,s)$ 再压入 $(B,s)$，棚号集合不变。故堆中元素与已开棚一一对应，堆顶 $e$ 确为"所有棚的最后结束时间的最小值"。证毕。

---

### 引理 3（复用判据的正确性）

处理牛 $(A,B)$ 时，"存在可复用的棚" $\iff$ "$Q$ 非空且堆顶 $e<A$"。且复用时选堆顶棚是合法的。

*证明*：由引理 2，堆中每个 $(e,s)$ 的 $e$ 是棚 $s$ 内所有区间右端点的最大值。棚 $s$ 可复用 $\iff$ 新牛与棚内所有牛不交 $\iff$ 所有旧 $B<A$（旧区间都在新左侧才不交；旧 $A\le$ 旧 $B$，若某旧 $B\ge A$ 则旧区间含时刻 $\max(A,\text{旧}A)\le$ 旧$B$ 且 $\ge A$……更直接地：旧区间 $[A',B']$ 与 $[A,B]$ 不交且 $A'\le A$（排序保证旧牛开始不晚于 $A$）$\iff B'<A$）$\iff e<A$。所以存在可复用棚 $\iff\min_s e_s<A\iff$ 堆顶 $e<A$。选堆顶棚满足 $e<A$，由上述等价链合法。证毕。

（注：这里用到了"按 $A$ 排序"保证旧牛 $A'\le A$；若 $A'=A$ 则两区间都含 $A$，必冲突，而 $B'\ge A'=A$ 使 $e<A$ 不成立，判据自动排除，无需特判。）

---

### 引理 4（上界：贪心开的棚数 $\le D$）

*证明*：设贪心处理牛 $c_k=(A,B)$ 时开了第 $t$ 个棚（即开棚前已有 $t-1$ 个棚）。由引理 3 的否定分支，此时所有已开棚的堆值 $e_s\ge A$。

对每个已开棚 $s$，取棚内使右端点达到 $e_s$ 的那头牛 $j_s$（引理 2 保证 $e_s$ 是棚内某牛的 $B$）。牛 $j_s$ 在 $c_k$ 之前被处理，排序保证 $A_{j_s}\le A$；又 $B_{j_s}=e_s\ge A$。故 $A_{j_s}\le A\le B_{j_s}$，即 $I_{j_s}$ 包含时刻 $A$。

这 $t-1$ 头牛分属不同棚，互不相同；再加上 $c_k$ 自己（$A\le A\le B$），共 $t$ 个**互不相同**的区间都包含时刻 $A$。由 $D$ 的定义，$D\ge t$。

贪心最终棚数 $\text{cnt}$ 等于最后一次开棚的序号，故 $\text{cnt}\le D$。证毕。

---

### 引理 5（并列开始时间不需要特殊处理）

排序时 $A$ 相同的牛任意定序，算法仍正确。

*证明*：引理 2、3、4 的证明中，对"先处理的牛"只使用了 $A_{\text{旧}}\le A_{\text{新}}$ 这一条性质（引理 3 括注里说明了 $A'=A$ 时判据自动判冲突）。$A$ 相同的牛无论谁先谁后，该性质都成立；且它们两两冲突（都含公共开始时刻），引理 4 的计数把它们如实计入深度。故任意并列定序下结论不变。证毕。

---

### 定理（贪心最优）

贪心输出的棚数 $\text{cnt}=\mathrm{OPT}=D$，且分配方案合法。

*证明*：引理 2 保证方案合法，故 $\mathrm{OPT}\le\text{cnt}$；引理 4 给出 $\text{cnt}\le D$；引理 1 给出 $D\le\mathrm{OPT}$。三者夹逼：$\mathrm{OPT}\le\text{cnt}\le D\le\mathrm{OPT}$，全部取等。证毕。

---

### 引理 6（复杂度与值域）

时间 $O(N\log N)$，空间 $O(N)$。

*证明*：排序 $O(N\log N)$。每头牛至多一次弹出、一次压入，堆大小 $\le N$，每次堆操作 $O(\log N)$，共 $O(N\log N)$。输出 $O(N)$。空间：牛数组、答案数组、堆均 $O(N)$。值域：$A,B\le10^6$、棚号 $\le N\le5\times10^4$，`int` 足够，无需 64 位。代入 $N=5\times10^4$：约 $5\times10^4\times17\approx8.5\times10^5$ 次堆比较，远低于时限。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 同棚 = 区间两两不交；闭区间端点相碰也算冲突，复用判据必须严格 `<`。
2. **consider easier version** — 先找下界：最大点覆盖深度 $D$，鸽笼原理得 $\mathrm{OPT}\ge D$。
3. **explore its property** — 猜想 $\mathrm{OPT}=D$；按开始时间排序接待，空棚优先复用。
4. **classic problem solution** — 区间划分贪心：按左端点排序 + 以"最后结束时间"为键的小根堆选棚。
5. **reduce to easier problem** — 不用交换论证：开第 $k$ 个棚的瞬间，$k$ 个区间共同覆盖当前开始时刻，直接见证 $D\ge k$。
6. **discuss by category** — SPJ 任意最优方案；记录原编号按输入顺序输出；并列开始时间无需特判。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 奶牛数，$\le5\times10^4$ | `int` | 读入 |
| `c[i]` | 第 $i$ 头牛 $\{a,b,i\}$：开始、结束、**原编号** | `struct cow[mxn]` | 读入；随后按 `a` 排序，原编号留在 `i` 里 |
| `ans[i]` | **原编号** $i$ 的牛分到的棚号（0-based） | `int[mxn]` | 处理时写入，输出时 `+1` |
| `Q` | 小根堆，元素 $(e,s)$：棚 $s$ 的最后结束时间 $e$ | `priority_queue<pair<int,int>,...,greater<>>` | 空；每棚恰一个元素 |
| `cnt` | 已开棚数（= 最终答案第一行） | `int` | $0$，开新棚时自增 |
| `mxn` | $50000+5$ | `constexpr int` | 数组尺寸松弛 |

### 算法步骤

1. I/O 加速三行；读 `n` 与每头牛的 `a,b`，记原编号 `i`。
2. 按 `a` 升序排序 `c`（并列任意，引理 5）。
3. 顺序处理每头牛：若 `Q` 非空且堆顶 `e<a`，弹出堆顶得棚号 `s`，`ans[原编号]=s`，压入 `(b,s)`；否则 `ans[原编号]=cnt`，压入 `(b,cnt)`，`++cnt`。
4. 输出 `cnt`；按原编号 $0..n-1$ 输出 `ans[i]+1`。

### 复杂度

- 时间 $O(N\log N)$（排序 + 每牛常数次堆操作）。
- 空间 $O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 4 牛数据（含端点相碰 $[1,2]$ 与 $[2,5]$）实际运行输出棚数 $3$、分配 $(1,3,2,2)$，与手算一致，深度下界 $D=3$ 吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2859 [USACO06FEB] Stall Reservations S
// 思路：区间划分。按开始时间排序 + 小根堆维护每个棚的最后结束时间。
//       开第 k 个棚时，k 个区间共同覆盖当前开始时刻 ⇒ 棚数 = 最大深度 = 最优。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005};

int n,ans[mxn];
struct cow{int a,b,i;}c[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>c[i].a>>c[i].b;
		c[i].i=i;
	}
	sort(c,c+n,[](const cow&x,const cow&y){return x.a<y.a;});
	priority_queue<pair<int,int>,vector<pair<int,int>>,greater<>>Q;	// (棚的最后结束时间,棚编号)
	int cnt=0;
	for(int k=0;k<n;++k)
	{
		auto[a,b,i]=c[k];
		if(!Q.empty()&&Q.top().first<a)	// 闭区间：end==a 仍冲突，必须严格 <
		{
			auto[e,s]=Q.top();Q.pop();
			ans[i]=s;
			Q.emplace(b,s);
		}
		else
		{
			ans[i]=cnt;
			Q.emplace(b,cnt);
			++cnt;
		}
	}
	cout<<cnt<<'\n';
	for(int i=0;i<n;++i)
		cout<<ans[i]+1<<'\n';
	return 0;
}
```

### 代码说明

- 堆里存的是**每个棚的最后结束时间**，不是牛：复用后弹出旧值压入新值，保证每棚恰一个元素，堆顶即"最早空闲的棚"。
- 复用条件 `Q.top().first<a` 的严格小于号是本题命门：闭区间端点相碰算冲突，写成 `<=` 会产出非法方案（SPJ 直接判错）。
- `ans` 按**原编号**写回，排序打乱的是处理顺序而非输出顺序。
- 棚号内部 0-based，输出 `+1`；`cnt` 即最少棚数，由定理它等于最大覆盖深度。
