# P2310 loidc，看看海 — 题解

## 一、解题过程：人类思考叙事

题意重述：给出 $n$ 个时刻的海浪高度 $a_1,\dots,a_n$（高度**两两不等**）。有 $m$ 个询问 $(x,y,k)$，问在时刻区间 $[x,y]$ 里，高度排第 $k$ 小的那个**时刻**是哪一个。$n,m\le 4000$，$1\le x\le y\le n$，$1\le k\le y-x+1$。

**第一步先把"输出什么"钉死。** 题面写的是"在时间 $[x,y]$ 内海浪高度第 $k$ 小的单位时刻是那个时刻"——它问的是**时刻编号**（$1..n$），不是高度值。这个理解有两点支撑：其一，句子主干是"……的单位时刻是哪个时刻"，问的是时刻；其二，题目特意保证"各个时刻海浪高度均不相同"，这正好让"第 $k$ 小的高度"唯一、从而取得它的时刻也唯一，问"是哪个时刻"才有唯一答案。所以答案是一个下标。

**第二步看预算。** $n,m\le 4000$，最朴素的 $O(nm)$ 量级是 $1.6\times 10^7$，这正是本题的设计容量（$30\%$ 数据给到 $n,m\le 200$，也说明正解就是平方级，而不是 $O((n+m)\log n)$ 的高级结构）。

**想法一：每个询问抄出来排序。** 把 $a_x..a_y$ 抄进临时数组，按高度排序，取第 $k$ 个，再回头找它的时刻。单次 $O(\text{len}\log\text{len})$，最坏 $4000\times 12$ 次比较、乘 $4000$ 个询问约 $1.9\times 10^8$——1 秒内很悬。更让我不安的是：**每个询问都在重复做同一件事**，同一批高度被反复排序，这份重复劳动明显可疑。

**想法二：只求第 $k$ 小，不必全序。** 用 `nth_element`（quickselect）单次 $O(\text{len})$，总共 $1.6\times10^7$，稳过。但把库函数的正确性讲清楚不如自己写一个可证的扫描；而且拿到第 $k$ 小的值之后还要再扫一遍才知道它落在哪个时刻（题目要的是时刻）。所以这条路能过，但不是最省心的。

**想法三（碰壁）：沿"位置轴"做文章。** 我试过另一种思路：区间最值可以用稀疏表 $O(1)$ 求，那"第 $k$ 小"能不能用"反复取最值"拼出来？第一次取最小值没问题；第二次要把最小值**删掉**再取最小——但 RMQ 结构不支持删除，删掉一个点之后"第二小"根本不是任何原区间的信息。换成堆：把区间元素塞进小根堆弹 $k$ 次，单次 $O(\text{len}+k\log \text{len})$，比排序还慢。

这次碰壁给出了一个明确的信号：**"第 $k$ 小"天生是"在值的全序上数数"，硬用位置轴上的区间结构去拆它，方向不对。**

**想法四（换轴，正解）：一次排序，反复过滤。** 既然"第 $k$ 小"依赖高度的全序，那就干脆**把整个数组按高度排一次**，得到 $ord[0..n-1]$，其中 $ord[v]$ 是"高度第 $v+1$ 小的那个时刻"。因为高度两两不等，这个顺序是唯一的。

现在看一个询问 $[x,y]$：从 $v=0$ 开始扫 $ord$，只保留**时刻落在 $[x,y]$ 里**的那些 $ord[v]$。由于 $ord$ 本身是高度升序，"挑子序列"当然还是高度升序——于是我得到的恰好是 $a_x..a_y$ 按高度升序排好的样子（只是少了不相关的时刻），第 $k$ 个就是答案。

这就把"重复排序"换成了"排序一次 + 每次询问线性过滤"：预处理 $O(n\log n)$，单次询问 $O(n)$，总计 $O(n\log n+nm)=1.6\times10^7$ 次比较，代码只有六行。

**顺手检查边界：**
- $k\le y-x+1$ 保证扫描一定能数到第 $k$ 个，不会数不出来；
- 过滤条件是"$x\le ord[v]\le y$"，$O(1)$ 判断，不需要额外空间；
- 内层存的是 $0$-based 时刻，输出时 $+1$。

**再想远一步：** 如果 $n,m$ 变成 $10^5$ 呢？那时"在 $ord$ 上找第 $k$ 个落在 $[x,y]$ 里的下标"就必须做成对数级，这就是经典的**静态区间第 $k$ 小**（主席树 / 值域二分 + 归并树 / 整体二分）。本题不需要，但这个"同一刻画、更高档的结构"的升级路线值得记住——它说明换轴这一步不是投机，而是把问题搬到了它真正的形状上。

## 二、思维链：完整证明

约定：时刻用 $0$-based 下标 $0..n-1$ 讨论，$a_p$ 表示时刻 $p$ 的高度；$ord$ 是把 $0..n-1$ 按 $a$ 升序排列后得到的下标序列。

**引理 1（答案良定义）**：对任意合法询问 $(x,y,k)$，存在唯一的时刻 $t\in[x,y]$，使 $a_t$ 是 $\{a_p:p\in[x,y]\}$ 中第 $k$ 小的数。

*证明*：区间内共有 $y-x+1$ 个时刻，题设 $1\le k\le y-x+1$，故"第 $k$ 小"存在。又 $a$ 两两不等，故区间内不存在两个相等的高度，因而"第 $k$ 小的高度值"唯一确定；取得该值的时刻也唯一（若有两个时刻取到同一高度，则这两个高度相等，矛盾）。证毕。

**引理 2（全局高度序唯一且严格递增）**：按比较器 $a_u<a_v$ 对下标集 $\{0,\dots,n-1\}$ 排序得到的 $ord$ 满足
$$a_{ord[0]}<a_{ord[1]}<\dots<a_{ord[n-1]},$$
且满足该严格递增性质的排列只有 $ord$ 一个。

*证明*：排序输出满足相邻不逆序，即 $a_{ord[v]}\le a_{ord[v+1]}$；若取等则两高度相等，与"两两不等"矛盾，故为严格递增。唯一性：任何满足严格递增的排列，其第一个元素必须是**最小高度**的下标；而最小高度只有一个（两两不等），故第一位被唯一确定；删去它后同理确定第二位……归纳即得整个排列唯一。证毕。

**引理 3（核心：区间第 $k$ 小 = 全局序上的第 $k$ 次命中）**：固定询问 $(x,y)$，令
$$S=\{p:x\le p\le y\},\qquad v_1<v_2<\dots<v_s\ \text{为所有满足 } ord[v]\in S \text{ 的下标 }v .$$
（$s=|S|=y-x+1$。）则 $a_{ord[v_j]}$ 恰是 $\{a_p:p\in S\}$ 中第 $j$ 小的数。

*证明*：分两步。

（1）**多重集相等**：$\{a_{ord[v_j]}:1\le j\le s\}=\{a_p:p\in S\}$。
- "$\subseteq$"：每个 $v_j$ 都满足 $ord[v_j]\in S$，故 $a_{ord[v_j]}$ 属于右端。
- "$\supseteq$"：任取 $p\in S$，由于 $ord$ 是 $0..n-1$ 的排列，存在唯一的 $v$ 使 $ord[v]=p$；该 $v$ 满足 $ord[v]\in S$，故它就是某个 $v_j$。

（2）**次序**：$v_1<\dots<v_s$ 且 $a_{ord[\cdot]}$ 关于其下标严格递增（引理 2），故
$$a_{ord[v_1]}<a_{ord[v_2]}<\dots<a_{ord[v_s]}.$$
于是这是一个把右端多重集严格升序排好的序列，它的第 $j$ 项正是第 $j$ 小。证毕。

**引理 4（扫描实现正确）**：按 $v=0,1,\dots,n-1$ 递增扫描，用 $cnt$ 记录"已遇到的、$ord[v]\in[x,y]$ 的个数"；当 $cnt$ 首次等于 $k$ 时令 $ans=ord[v]$ 并跳出。则 $ans$ 就是引理 1 中唯一的 $t$，输出 $ans+1$（转回 $1$-based）即所求。

*证明*：由引理 3，所有满足 $ord[v]\in S$ 的下标按递增顺序恰为 $v_1<v_2<\dots<v_s$。扫描按 $v$ 递增进行，$cnt$ 就是"已遇到的前若干个 $v_j$ 的个数"，所以 $cnt$ 首次等于 $k$ 的那一刻遇到的正是 $v_k$（这也是第一次，因为 $cnt$ 严格单调增且只在命中时增加）。此时 $ord[v_k]$ 就是第 $k$ 小的时刻（引理 3）。由引理 1 与 $k\le y-x+1=s$，$v_k$ 必然存在，故 $ans$ 一定被赋值，不会输出占位初值。证毕。

**引理 5（复杂度）**：预处理 $O(n\log n)$；每个询问扫描 $n$ 个 $v$，单次 $O(n)$；总时间 $O(n\log n+nm)$，空间 $O(n)$。

*证明*：排序 $n$ 个元素 $O(n\log n)$；单次询问的循环上界为 $n$，循环体是一条范围判断加一次自增（命中时还可能提前跳出），$O(1)$，乘 $m$ 次得 $O(nm)$。空间上只用了 $a$、$ord$ 两个长度 $n$ 的数组与若干标量，$O(n)$。取 $n=m=4000$ 得 $nm=1.6\times10^7$。证毕。

**定理**：对每个询问，程序输出该询问的正确时刻。

*证明*：由引理 1，正确答案存在且唯一；由引理 4，扫描给出的正是它；由引理 5，算法在时限内完成。证毕。

**备注（升级路线，仅作说明，不参与本题实现）**：设 $w$ 为 $\{a_p:p\in[x,y]\}$ 的第 $k$ 小值，则 $w$ 是满足 $\#\{p\in[x,y]:a_p\le v\}\ge k$ 的最小可行高度 $v$。*理由*：若 $v<w$，则区间内 $\le v$ 的高度少于 $k$ 个（它们只能是第 $1..j$ 小，$j<k$）；若 $v=w$，则区间内 $\le w$ 的恰有至少 $k$ 个（前 $k$ 小都 $\le w$）。于是"二分答案 + 区间计数"即可求第 $k$ 小；把计数换成归并树（$O(\log^2 n)$）或主席树/整体二分（$O(\log n)$）就得到 $10^5$ 档的通用解法。本题 $n\le 4000$，直接线性扫更短更稳。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 先钉死输出：要的是**时刻**不是高度；"高度两两不等"正是为了让第 $k$ 小的时刻唯一。
2. **explore its property** — 读预算：$n,m\le 4000$ ⇒ $O(nm)=1.6\times10^7$ 就是设计容量，不必上高级结构。
3. **consider easier version** — 单次询问的最笨做法：抄出区间、排序、取第 $k$ 个、回查时刻，$O(\text{len}\log\text{len})$。
4. **classic problem solution** — 只要第 $k$ 小 ⇒ `nth_element`/quickselect，单次 $O(\text{len})$；能过但正确性不好讲、且还要回查时刻。
5. **explore its property（碰壁）** — 试沿"位置轴"用 RMQ 反复取最小值：取走最小值后求次小无法用 RMQ 表达 ⇒ 证明这条路不通，必须换轴。
6. **reduce to easier problem** — 换到"高度轴"：全局按高度排一次得到 $ord$，询问变成"在 $ord$ 上找第 $k$ 个落在 $[x,y]$ 里的下标"。
7. **explore its property** — 子序列保持升序 ⇒ 线性过滤就够，不需要任何数据结构支撑"第 $k$ 个"。
8. **classic problem solution（拓展）** — 同一刻画把 $n,m$ 放大到 $10^5$ 时升级为"二分高度 + 区间计数"（归并树/主席树/整体二分）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| $n$ | 时刻总数 | `int`，读入 |
| $m$ | 询问数 | `int`，读入 |
| $a[i]$ | 第 $i$ 个时刻（$0$-based）的海浪高度 | `int a[mxn]`，读入，两两不等 |
| $ord[v]$ | 高度第 $v+1$ 小的时刻（$0$-based） | `int ord[mxn]`，先 `iota` 成 $0..n-1$，再按 $a$ 升序 `sort` |
| $x,y$ | 询问的区间端点（读入后减一，转 $0$-based） | 循环内局部变量 |
| $k$ | 询问的排名 | 循环内局部变量 |
| $cnt$ | 扫描中已命中的 $ord[v]\in[x,y]$ 的个数 | 每个询问重置为 $0$ |
| $ans$ | 第 $k$ 次命中的时刻 | 每个询问重置为 $0$，命中后立即赋值并 `break` |

记忆点：`ord` 是"高度序"，扫描它就是在高度升序上数数；`cnt` 数的是"落在询问区间里的高度"。

### 算法步骤

1. 读入 $n$ 与 $a[0..n-1]$。
2. `iota(ord,ord+n,0)`，再 `sort(ord,ord+n,[](u,v){return a[u]<a[v];})`，得到高度升序的时刻序列（引理 2 保证唯一）。
3. 读入 $m$，逐个询问处理：
   1. 读 $x,y,k$，`--x;--y;`。
   2. `cnt=0`，`ans=0`。
   3. 对 $v=0..n-1$：若 $ord[v]<x$ 或 $ord[v]>y$ 则跳过；否则 `++cnt`，若 `cnt==k` 则 `ans=ord[v]` 并跳出。
   4. 输出 `ans+1`。
4. 每个询问互不影响（`cnt`、`ans` 都在询问内重置），无多测清零问题。

### 复杂度

- 时间：$O(n\log n+nm)$，$n=m=4000$ 时约 $5\times10^4$（排序）$+1.6\times10^7$（扫描）次操作。
- 空间：$O(n)$（`a`、`ord` 两个数组；`mxn{4005}` 为 $n$ 上界加松弛）。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过。
- 本题题面无样例，手造两组小数据并人工核对：$n=5$、$a=\{3,1,4,2,5\}$，询问 `1 5 3`/`2 4 1`/`1 3 3` 得 `1 2 3`（程序输出一致）；$n=5$、$a=\{1,2,3,4,5\}$，询问 `1 5 5`/`2 4 2`/`3 5 1` 手算应为 `5 3 3`（此刻 `ord={0,1,2,3,4}`，逐个询问数命中位置即得）。
- 对拍：与"每询问抄出区间排序取第 $k$ 个"的暴力在 $n\le40,m\le20$ 的随机数据上跑 **300 组**，输出完全一致。
- 极限规模 $n=m=4000$（全随机区间）单次运行 $0.09$ s（含读写）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2310 loidc，看看海
// 为什么换轴：区间第 k 小是「在高度全序上数数」，所以先把高度序排出来（ord）
// 询问 [x,y] 的答案 = ord 上第 k 个落在 [x,y] 里的时刻（取子序列仍升序）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{4005};

int n,m,a[mxn],ord[mxn];	//ord[v]=高度第 v 小的时刻

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	iota(ord,ord+n,0);
	sort(ord,ord+n,[](int u,int v){return a[u]<a[v];});	//高度两两不等，序唯一
	cin>>m;
	for(int x,y,k;m--;)
	{
		cin>>x>>y>>k;--x;--y;
		int cnt=0,ans=0;
		for(int v=0;v<n;++v)
		{
			if(ord[v]<x||ord[v]>y)
				continue;
			if(++cnt==k)
			{
				ans=ord[v];
				break;
			}
		}
		cout<<ans+1<<'\n';	//转回 1-based 时刻
	}
	return 0;
}
```

### 代码说明

- `ord` 用 `iota` 初始化成 $0..n-1$，再按高度排序；排序比较器只读 `a`，不改 `a`。
- 内层扫描从 $v=0$ 起（高度最小端），一旦 `cnt==k` 立刻 `break`：更靠后的高度都更大，不可能更优。
- `ans` 初值 $0$ 只是占位：由 $k\le y-x+1$ 一定命中，若真担心可以在 `cnt` 未到 $k$ 时输出 $-1$ 自检，但按题面约束用不到。
- `x`、`y` 减一转 $0$-based，`ord` 里存的也是 $0$-based，输出时统一 $+1$，全程只有一处坐标转换。
- 没有多测，所以不需要清零；若改成多组数据，`cnt`/`ans` 已在询问内重置，只有 `ord` 需要重排。

---

*本题的思维结构是"识别出答案依赖高度的全序 ⇒ 把重复排序换成一次排序 + 反复线性过滤"；真正需要注意的是"输出时刻不是高度"这一读题细节，以及 $O(nm)$ 的容量判断。*
