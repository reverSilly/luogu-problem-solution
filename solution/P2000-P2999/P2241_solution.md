# P2241 统计方形（数据加强版） — 题解

## 一、解题过程：人类思考叙事

题意复述：一个 $n\times m$ 的方格棋盘（$n$ 行 $m$ 列小格），数出其中由格线围成的正方形个数，以及长方形（**不含正方形**）个数。$n,m\le5000$。

最直接的想法是枚举一个矩形的四条边：上边界 $r_1$、下边界 $r_2$（$0\le r_1<r_2\le n$），左边界 $c_1$、右边界 $c_2$（$0\le c_1<c_2\le m$），若 $r_2-r_1=c_2-c_1$ 就是正方形。循环量级是
$$\binom{n+1}{2}\binom{m+1}{2}\approx\frac{n^2m^2}{4}.$$
1997 年的原版数据规模很小，这种四重循环能过；但本题是**数据加强版**，$n=m=5000$ 时约 $1.56\times10^{14}$，完全不可能。必须换计数方式。

先做一个简化问题：**完全不管正方形，所有矩形有多少个？**

矩形由四条格线围成：两条横线、两条竖线。棋盘有 $n+1$ 条横线、$m+1$ 条竖线，任取两条横线、两条竖线就唯一确定一个矩形，反之每个矩形的边界也唯一确定这四条线。所以
$$\text{矩形总数}=\binom{n+1}{2}\binom{m+1}{2}=\frac{n(n+1)}2\cdot\frac{m(m+1)}2.$$
这一步把「枚举四个边界」变成了「枚举两对线」，复杂度直接变成公式。

接着**正方形怎么数？** 正方形是特殊的矩形，按边长分类。边长 $k$ 的正方形，其下边界可以在 $0,1,\dots,n-k$ 这 $n-k+1$ 个位置，左边界可以在 $0,1,\dots,m-k$ 这 $m-k+1$ 个位置，位置一旦定下，整个正方形就定了。所以边长 $k$ 的正方形有 $(n-k+1)(m-k+1)$ 个，$k$ 取 $1..\min(n,m)$。不同边长对应不同正方形，不会重复计数，直接求和即可。

题目要的两个答案就都有了：
$$\text{正方形}=\sum_{k=1}^{\min(n,m)}(n-k+1)(m-k+1),\qquad
\text{长方形}=\text{矩形总数}-\text{正方形}.$$
注意题目明确说「长方形（不包含正方形）」，所以是总数**减去**正方形，不是把总数直接输出。

拿小棋盘自检：
- $n=m=1$：总数 $\binom22\binom22=1$，正方形 $\sum_{k=1}^{1}1\cdot1=1$，长方形 $0$，合理（只有一个小格）。
- $n=2,m=3$：总数 $\binom32\binom42=3\times6=18$；正方形 $2\cdot3+1\cdot2=8$（$6$ 个 $1\times1$ 加 $2$ 个 $2\times2$）；长方形 $10$。用暴力枚举四个边界也得到 $8$ 和 $10$，吻合。
- $n=1,m=5000$：总数 $\binom22\binom{5001}2=12502500$，正方形 $5000$，长方形 $12497500$。一行的棋盘里每个小格都是正方形，剩下全是 $1\times k$（$k\ge2$）的长条，数目对得上。

实现上的坑只有一个但很致命：**溢出**。$n=m=5000$ 时总数约 $1.56\times10^{14}$，`int` 早就爆了，必须开 `long long`（`i64`）。另外 `n*(n+1)/2` 要先乘后除，$5000\cdot5001=2.5\times10^7$ 在 `long long` 里毫无压力。

## 二、思维链：完整证明

**引理 1（矩形与「两横两竖」一一对应）**：棋盘内由格线围成的矩形，与「从 $n+1$ 条横线中选 $2$ 条、从 $m+1$ 条竖线中选 $2$ 条」的选择方案一一对应。因此矩形总数为
$$R=\binom{n+1}{2}\binom{m+1}{2}.$$

*证明*：棋盘只有横、竖两组格线，任何由格线围成的矩形四条边必分别落在两条横线与两条竖线上，因此是轴平行矩形，可以用 $(r_1,r_2,c_1,c_2)$（$0\le r_1<r_2\le n$，$0\le c_1<c_2\le m$）唯一描述。
- **映射**：矩形 $\mapsto$（其下边所在横线 $r_1$ 与上边所在横线 $r_2$，左边竖线 $c_1$ 与右边竖线 $c_2$）。因为矩形边界唯一，这个映射是单射。
- **逆映射**：给定两条横线 $r_1<r_2$ 与两条竖线 $c_1<c_2$，它们围成的区域就是一个合法的轴平行矩形，且其边界正是这四条线。故映射是满射。
于是双射成立。横线对的选法有 $\binom{n+1}{2}$ 种，竖线对有 $\binom{m+1}{2}$ 种，两组选择互相独立（任意组合都给出合法矩形），由乘法原理总数为其乘积。证毕。

**引理 1′（第二条独立计数路径：按左下角双计数）**：对 $0\le x\le m-1,\ 0\le y\le n-1$，以格点 $(x,y)$ 为左下角的矩形有 $(m-x)(n-y)$ 个，且
$$\sum_{x=0}^{m-1}\sum_{y=0}^{n-1}(m-x)(n-y)=\frac{m(m+1)}2\cdot\frac{n(n+1)}2=\binom{m+1}{2}\binom{n+1}{2},$$
与引理 1 一致。

*证明*：以 $(x,y)$ 为左下角时，右边界可选 $x+1,\dots,m$ 共 $m-x$ 条，上边界可选 $y+1,\dots,n$ 共 $n-y$ 条，宽与高独立，故有 $(m-x)(n-y)$ 个矩形。每个矩形有唯一的左下角，所以这种数法不重不漏。求和时把双重和分解为两个单和之积
$$\sum_{x=0}^{m-1}\sum_{y=0}^{n-1}(m-x)(n-y)=\Big(\sum_{x=0}^{m-1}(m-x)\Big)\Big(\sum_{y=0}^{n-1}(n-y)\Big),$$
而 $\sum_{x=0}^{m-1}(m-x)=m+(m-1)+\dots+1=\frac{m(m+1)}2$，$\sum_{y=0}^{n-1}(n-y)=\frac{n(n+1)}2$。乘积即 $\binom{m+1}{2}\binom{n+1}{2}$。证毕。

**引理 2（边长 $k$ 的正方形计数）**：对 $1\le k\le\min(n,m)$，边长为 $k$ 的正方形恰有 $(n-k+1)(m-k+1)$ 个。

*证明*：边长为 $k$ 的轴平行正方形由其左下角格点 $(x,y)$（$0\le x\le m-k$，$0\le y\le n-k$）与 $k$ 唯一确定，且不同的 $(x,y,k)$ 给出不同的正方形（左下角与边长都可从正方形读出）。所以只需数合法的左下角个数：横坐标 $x$ 有 $m-k+1$ 种，纵坐标 $y$ 有 $n-k+1$ 种，二者独立，故为 $(m-k+1)(n-k+1)=(n-k+1)(m-k+1)$。证毕。

**引理 3（按边长分类不重不漏）**：所有正方形恰为「边长为 $1,2,\dots,\min(n,m)$ 的正方形」的不交并，故
$$S=\sum_{k=1}^{\min(n,m)}(n-k+1)(m-k+1).$$

*证明*：每个正方形的边长是唯一确定的正整数 $k$，且 $k\le\min(n,m)$（正方形要放进 $n\times m$ 的棋盘）；反之每个 $k$ 与每个合法左下角给出的都是正方形。因此按 $k$ 分类既不重复（同一正方形只有一个边长）也不遗漏（任何正方形都有自己的边长）。由引理 2 对每类计数再求和即得。证毕。

**引理 3′（正方形计数的闭式，用于交叉验证）**：记 $A=n+1,\ B=m+1,\ r=\min(n,m)$，则
$$S=rAB-(A+B)\frac{r(r+1)}2+\frac{r(r+1)(2r+1)}6.$$
特别地 $n=m$ 时 $S=\sum_{j=1}^{n}j^2=\frac{n(n+1)(2n+1)}6$。

*证明*：把引理 2 的项展开：$(n-k+1)(m-k+1)=(A-k)(B-k)=AB-(A+B)k+k^2$，于是
$$S=rAB-(A+B)\sum_{k=1}^{r}k+\sum_{k=1}^{r}k^2.$$
用归纳法证两个求和公式。
（一）$\sum_{k=1}^{r}k=\frac{r(r+1)}2$：$r=1$ 时两边都是 $1$；若对 $r-1$ 成立，则 $\sum_{k=1}^{r}k=\frac{(r-1)r}2+r=\frac{r(r+1)}2$。
（二）$\sum_{k=1}^{r}k^2=\frac{r(r+1)(2r+1)}6$：$r=1$ 时两边都是 $1$；若对 $r-1$ 成立，则
$$\sum_{k=1}^{r}k^2=\frac{(r-1)r(2r-1)}6+r^2=\frac{r\big((r-1)(2r-1)+6r\big)}6=\frac{r(2r^2+3r+1)}6=\frac{r(r+1)(2r+1)}6.$$
两式代入即得闭式。当 $n=m$ 时 $A=B=n+1,\ r=n$，代入得 $S=\frac{n(n+1)(2n+1)}6$；另一方面作代换 $k\mapsto n+1-k$ 可见 $\sum_{k=1}^{n}(n-k+1)^2=\sum_{j=1}^{n}j^2$，两种写法一致。
这条闭式与引理 2 的循环求和是两条互相独立的计数路径（一条用乘法公式，一条逐个累加），代码用循环、手算可用闭式，二者必须相等——本节所有样例数值都做了这种双向核对。证毕。

**引理 4（两个答案的关系）**：记矩形总数为 $R$、正方形数为 $S$，则题目所求的「长方形（不包含正方形）」个数为 $R-S$，且 $R-S\ge0$。

*证明*：每个矩形要么是正方形、要么不是，二者互斥且穷尽；正方形共 $S$ 个，故非正方形矩形共 $R-S$ 个。又 $S\le R$（正方形是矩形的子集），所以 $R-S\ge0$，不会出现负数。证毕。

**引理 4′（直接数非正方形矩形，独立验证减法）**：宽 $w$、高 $h$ 的矩形有 $(m-w+1)(n-h+1)$ 个，且
$$\sum_{w=1}^{m}\sum_{h=1}^{n}[w\ne h]\,(m-w+1)(n-h+1)=R-S.$$

*证明*：宽为 $w$ 的矩形，其左边界可在 $0,1,\dots,m-w$ 中选，共 $m-w+1$ 种；高为 $h$ 的矩形，下边界可在 $0,\dots,n-h$ 中选，共 $n-h+1$ 种；两者独立，故宽 $w$ 高 $h$ 的矩形有 $(m-w+1)(n-h+1)$ 个，且每组 $(w,h)$ 与每个位置唯一确定一个矩形、不重不漏。
把双重和按 $w=h$ 与 $w\ne h$ 拆开。全和
$$\sum_{w=1}^{m}\sum_{h=1}^{n}(m-w+1)(n-h+1)=\Big(\sum_{w=1}^{m}(m-w+1)\Big)\Big(\sum_{h=1}^{n}(n-h+1)\Big)=R,$$
其中两个单和分别是 $\binom{m+1}2$ 与 $\binom{n+1}2$。而 $w=h$ 的部分是 $\sum_{k=1}^{\min(m,n)}(m-k+1)(n-k+1)=S$（双重和里 $w\le m,\ h\le n$，故 $k\le\min(m,n)$ 自动成立）。所以 $w\ne h$ 的部分为 $R-S$，与引理 4 一致。证毕。

**引理 5（数值范围）**：$n,m\le5000$ 时 $R\le1.6\times10^{14}<2^{63}-1$，而 $R$ 会超过 $2^{31}-1$，故必须用 $64$ 位整数、且 $64$ 位足够。

*证明*：$R=\binom{5001}{2}^2=(12502500)^2=156\,312\,506\,250\,000\approx1.56\times10^{14}$。它大于 $2^{31}-1\approx2.15\times10^9$（`int` 溢出），小于 $2^{63}-1\approx9.22\times10^{18}$（`long long` 安全）。中间量 $n(n+1)=5000\cdot5001=2.5\times10^7$ 与 $\binom{5001}{2}=1.25\times10^7$ 也都远小于 $2^{63}$，先乘后除不会溢出。证毕。

**引理 6（复杂度）**：时间 $O(\min(n,m))$，空间 $O(1)$。

*证明*：只需一次 $k=1..\min(n,m)$ 的循环，循环体是常数次 $64$ 位乘加；除此之外只有常数次算术。证毕。

**定理**：算法输出的两个数分别是棋盘内正方形与非正方形矩形的正确个数。

*证明*：正方形数由引理 2、3 给出（引理 3′ 的闭式与循环求和一致）；矩形总数由引理 1 给出（引理 1′ 用另一条计数路径独立验证）；非正方形矩形数由引理 4 给出为两者之差（引理 4′ 用直接双重计数再次验证）；数值范围由引理 5 保证不溢出。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 棋盘只有横竖两组格线，所以图形都是轴平行的，可由四条边界线唯一描述
- **consider easier version** — 先不管正方形/长方形的区分，只数「所有矩形」
- **classic problem solution** — 矩形 ↔ 两横线 × 两竖线，用组合数 $\binom{n+1}2\binom{m+1}2$ 一次算出
- **discuss by category** — 正方形按边长 $k$ 分类，每类 $(n-k+1)(m-k+1)$ 个
- **reduce to easier problem** — 长方形（不含正方形）= 矩形总数 − 正方形数
- **explore its property** — 估算上界 $1.56\times10^{14}$，确定必须开 `long long`

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n,m$ | 棋盘的行数、列数（小格数） | 输入（`i64`） |
| `sq` | 正方形个数 | 初值 $0$，按边长 $k$ 累加 |
| `tot` | 矩形总数 | $\frac{n(n+1)}2\cdot\frac{m(m+1)}2$ |
| $k$ | 枚举的正方形边长 | $1\le k\le\min(n,m)$ |

### 算法步骤

1. 读入 $n,m$（`long long`）。
2. `sq=0`；对 $k=1,2,\dots,\min(n,m)$ 累加 $(n-k+1)(m-k+1)$。
3. `tot=(n*(n+1)/2)*(m*(m+1)/2)`。
4. 输出 `sq` 与 `tot-sq`，中间一个空格。

### 复杂度

- 时间复杂度：$O(\min(n,m))$。
- 空间复杂度：$O(1)$。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过，无错误。
- 题面无样例，手造数据核对：`1 1` → `1 0`；`2 3` → `8 10`；`5000 1` → `5000 12497500`；`5000 5000` → `41679167500 156270827082500`（与 $\sum_{k=1}^{5000}k^2$、$\binom{5001}{2}^2$ 的手算值一致）。
- 对拍：与「四重循环枚举上下左右边界、逐个数」的暴力在 $1\le n,m\le8$ 的全部 $64$ 组以及随机 $300$ 组 $n,m\le8$ 上比较，共 $364$ 组 $0$ 处不一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2241 统计方形（数据加强版）
// 思路：矩形总数 = C(n+1,2)*C(m+1,2)；正方形按边长 k 统计，每类 (n-k+1)(m-k+1) 个
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 n,m;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	i64 sq=0;
	for(i64 k=1;k<=min(n,m);++k)
		sq+=(n-k+1)*(m-k+1);
	i64 tot=(n*(n+1)/2)*(m*(m+1)/2);
	cout<<sq<<' '<<tot-sq<<'\n';
	return 0;
}
```
