# P2121 拆地毯 — 题解

## 一、解题过程：人类思考叙事

题目给了一张无向图：$n$ 个关键区域、$m$ 条地毯（边），每条地毯有一个美丽度（边权 $w$）。要求保留**至多 $K$ 条**地毯，保留后图中不能有环，问美丽度之和最大是多少。

"不能有环"这个条件一出来，图论味道就非常浓了。想保留尽可能多又不成环的边，那就是一棵**生成树**；但这里又有个 $K$ 的限制，$K$ 可能比 $n-1$ 小，所以目标不是生成树，而是"森林"。

关键观察：边权都是**正整数**。既然 $K$ 之内能选多少条就选多少条（少选一条一定不会更优，因为正权），那么问题等价于：选一个大小为 $\min(K, \text{最大森林边数})$ 的森林，使边权和最大。

这正是**最大生成森林**的加限制版。Kruskal 求最小生成树的流程是"按边权从小到大排序，能加就加"，求最大生成树就是"按边权从大到小排序，能加就加"——把 `sort` 的比较符号反过来，再加一个"选满 $K$ 条就停"的条件即可。

具体实现：
1. 把所有边按 $w$ 从大到小排序；
2. 用并查集维护当前已选边构成的连通块；
3. 依次考察每条边 $(u,v,w)$：若 $u,v$ 已经连通，加入它会成环，跳过；否则合并 $u,v$，答案加上 $w$，已选边数加一；
4. 已选边数达到 $K$ 时立刻停止。

这里有一个小坑：$K$ 可能大于 $n-1$，此时图最多只有 $n-1$ 条不成环的边，多余的 $K$ 不用管，循环自然会因为边遍历完而结束。

复杂度：排序 $O(m\log m)$，并查集 $O(m\alpha(n))$，总复杂度 $O(m\log m)$。

## 二、思维链：完整证明

**引理 1（森林的边数上界）**：$n$ 个点的无环图最多有 $n-1$ 条边。

*证明*：无环图（森林）的每个连通块是一棵树。设森林有 $k$ 个连通块，第 $i$ 个连通块有 $n_i$ 个点，则它有 $n_i - 1$ 条边。森林总边数为 $\sum_{i=1}^{k}(n_i-1) = n - k \le n - 1$。证毕。

**引理 2（正权 ⇒ 最优解边数取满）**：设 $r$ 为图的最大森林边数（$r\le n-1$），则最优解的边数为 $\min(K, r)$，且该边数下取最大边权和。

*证明*：因为所有边权都是正整数，任一不合法（成环）的集合不存在，任一合法的森林若边数少于 $\min(K,r)$，可以在其中加入一条不与已有边成环的边使边数加一（当边数 $<r$ 时，由引理 1 的证明，森林未连通所有点，故存在连接两个不同连通块的边），边权和严格变大。故最优解必取 $\min(K,r)$ 条边。证毕。

**引理 3（交换引理）**：设 $A,B$ 都是森林，且 $|A| < |B|$，则存在 $e\in B\setminus A$，使 $A\cup\{e\}$ 仍是森林。

*证明*：把 $A$ 的连通块记为 $V_1,\dots,V_k$。若存在 $e\in B\setminus A$ 的两个端点落在 $A$ 的不同连通块中，则 $A\cup\{e\}$ 无环，结论成立。否则 $B$ 的每条边的两个端点都在同一个 $V_i$ 内。$B$ 在每个 $V_i$ 内的边构成该顶点集上的森林，最多 $|V_i|-1$ 条，故 $|B|\le \sum_i (|V_i|-1) = n-k = |A|$，与 $|A|<|B|$ 矛盾。所以那种 $e$ 必然存在。证毕。

**引理 4（Kruskal 前 $j$ 条边最优）**：设 $G_j$ 是 Kruskal（按边权从大到小）选出的前 $j$ 条边构成的森林，则对任意含 $j$ 条边的森林 $S$，有 $w(G_j)\ge w(S)$。

*证明*：对 $j$ 归纳。$j=0$ 时显然。设结论对 $j-1$ 成立，令 $e$ 为 Kruskal 第 $j$ 个选中的边，则 $G_j=G_{j-1}\cup\{e\}$。

先说明：$e$ 是所有"加入 $G_{j-1}$ 后不成环"的边中权值最大的。因为边按权值递减处理，任何权值大于 $w(e)$ 的边在轮到它时都被否决了，那时被否决只可能是因为成环；设当时的森林为 $F'\subseteq G_{j-1}$，则 $F'+f$ 有环意味着 $G_{j-1}+f$ 也有环（$G_{j-1}$ 是 $F'$ 的超图），故 $f$ 不可加。而 $e$ 本身可加（它被选入了）。所以 $e$ 是可加边中权值最大的。

现在取任意 $j$ 条边的森林 $S$。由引理 3（$|G_{j-1}|=j-1<|S|=j$），存在 $f\in S\setminus G_{j-1}$ 使 $G_{j-1}\cup\{f\}$ 是森林。由归纳假设，$w(G_{j-1}\cup\{f\})\ge w(S)$。又因 $f$ 可加，$w(f)\le w(e)$，故
$$w(G_j)=w(G_{j-1})+w(e)\ge w(G_{j-1})+w(f)=w(G_{j-1}\cup\{f\})\ge w(S).$$
证毕。

**定理**：算法输出的是满足题意的最大美丽度之和。

*证明*：算法正是按权值递减执行 Kruskal 并在选满 $K$ 条时停止。设最终选出 $j=\min(K,r)$ 条边。由引理 4，$w(G_j)$ 不小于任何 $j$ 条边森林的权值和；由引理 2，任意合法解的边数不超过 $j$，且边数少于 $j$ 的解权值更小。故 $w(G_j)$ 即为最优解。证毕。

## 三、模式总结（按实际思考顺序）

1. 识别题型 → "不成环 + 边数上限 + 边权和最大" ⇒ 拟阵贪心（Kruskal 变体）
2. 读题发现边权全为正 ⇒ 边数能取满就取满（引理 2）
3. 把"最小生成树"的心智模型搬过来：**升序改降序**
4. 加"选满 $K$ 条就停"的计数控制
5. 并查集判环：`getrt(u)==getrt(v)` 就是会成环
6. 数值：$m\le 10^5$、$w$ 无上限，答案用 `long long` 累加（$10^5$ 条边、每条可达 $10^9$ 量级会爆 `int`）

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 |
|------|------|------|
| $n$ | 关键区域个数（点数） | `int` |
| $m$ | 地毯条数（边数） | `int` |
| $K$ | 至多保留的地毯条数 | `int` |
| $E_i=(u_i,v_i,w_i)$ | 第 $i$ 条地毯 | 结构体 |
| $f[x]$ | 并查集父亲 | `int` |
| $cnt$ | 已选边数 | `int` |
| $ans$ | 美丽度之和 | `i64` |

### 算法步骤

1. 读入 $n,m,K$ 与 $m$ 条边 $(u,v,w)$，点编号转为 $0$-based。
2. 按 $w$ 从大到小排序所有边。
3. 初始化并查集：$f[x]=x$。
4. 依次扫描排序后的边：
   - 若 `getrt(u)==getrt(v)`，跳过（会成环）；
   - 否则 `f[getrt(u)]=getrt(v)`，`ans+=w`，`cnt++`；
   - 若 `cnt==K`，跳出循环。
5. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(m\log m + m\alpha(n))$，主要是排序。
- 空间复杂度：$O(n+m)$。

### 代码行为

1. I/O 加速三行固定顺序；
2. 排序后单次扫描 + 并查集判环；
3. `ans` 使用 `i64` 防止溢出；
4. `cnt>=K` 立即停，满足"至多 $K$ 条"。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

struct edge{int u,v,w;};

int f[mxn];
edge E[mxn];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m,K;
	cin>>n>>m>>K;
	for(int i=0;i<m;++i)
	{
		cin>>E[i].u>>E[i].v>>E[i].w;
		--E[i].u;--E[i].v;
	}
	//按美丽度从大到小排序，贪心取不成环的前 K 条
	sort(E,E+m,[](edge a,edge b){return a.w>b.w;});

	iota(f,f+n,0);
	i64 ans=0;
	int cnt=0;
	for(int i=0;i<m&&cnt<K;++i)
	{
		int u=getrt(E[i].u),v=getrt(E[i].v);
		if(u==v)
			continue;//这条边会成环，丢弃
		f[u]=v;
		ans+=E[i].w;
		++cnt;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `mxn` 取 $10^5+5$，遵循"+5 松弛约定"。
- 排序比较器写成 lambda，`a.w>b.w` 即降序，与求最小生成树只差一个比较方向。
- `getrt` 用路径压缩，一行写法。
- `ans` 用 `i64`：$K$ 可达 $10^5$，边权若达 $10^9$ 量级总和会超 `int`。
- 循环条件写成 `i<m&&cnt<K`，"至多 $K$ 条"由 `cnt<K` 保证；当 $K>n-1$ 时边遍历完自然结束。
- 换行用 `'\n'`。
