# P2920 [USACO08NOV] Time Management S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离商人背景）。** 有 $N$ 个工作（$1\le N\le 1000$），第 $i$ 个耗时 $T_i$（$1\le T_i\le 1000$）、必须在时刻 $S_i$ **或之前**完成（$1\le S_i\le 10^6$）。现在是时刻 $0$，工作**不可中断**（一旦开始必须做到完），同一时刻只能做一个工作。求一个**最晚的开始时刻** $s\ge 0$，使得存在一种工作安排让所有工作都按时完成；若连 $s=0$ 都不可行，输出 `-1`。

约束与边界：

- "最晚开始"意味着中间**可以有空闲**（睡懒觉），但空闲只会让完成时间变晚，直觉上最优方案里不该有空闲——这要证明（引理 1）。
- 开始时刻不能为负（"现在是 0 时刻"），所以答案是 $\max(0,\text{理论最晚})$ 吗？**不是**：理论最晚 $<0$ 时说明 $s=0$ 也不可行，按题意输出 `-1` 而不是 0。这是本题最容易写错的分支。
- 答案可以是 $0$（恰好从当前时刻开始才来得及），$0$ 是合法输出，别和 `-1` 混淆。
- 总耗时 $\sum T_i\le 10^6$，$S_i\le10^6$，所有中间量 `int` 足够。
- 题面 Hint 给了样例解释但没有样例输入输出，我按解释反推数据核对（见下）。

**手造极简数据核对：**

第一组（按 Hint 反推）：4 个工作，耗时 $3,8,5,1$，截止 $5,14,20,16$。

```
输入：
4
3 5
8 14
5 20
1 16

输出：
2
```

手算：按截止期升序排为 $(3,5),(8,14),(1,16),(5,20)$，前缀耗时 $3,11,12,17$，各工作的"最晚开始余量" $S_i-\text{前缀}=2,3,4,3$，取 min 得 **2**。与 Hint"约翰必须在时间 2 开始"一致 ✓。

第二组（不可行）：$N=2$，$(5,3),(1,10)$。第一个工作耗时 5 却要求 3 之前完成，$s=0$ 也不行：

```
输入：
2
5 3
1 10

输出：
-1
```

第三组（答案恰为 0）：$N=2$，$(2,2),(3,5)$。前缀 $2,5$，余量 $0,0$，答案 **0**。

第四组（单工作）：$N=1$，$(3,5)$，答案 $5-3=2$。

## 二、思维链：完整证明

**记号。** 工作 $i$ 耗时 $T_i>0$、截止 $S_i$。一个"安排"= 开始时刻 $s\ge0$ + 工作的一个执行顺序（允许中间空闲）。工作 $j$ 的完成时刻记 $F_j$，可行当且仅当所有 $F_j\le S_j$。

### 第一步：空闲有没有用？——explore its property

求"最晚开始"，直觉是"能拖就拖"。但先要确认：**最优安排里需要空闲吗？** 如果空闲永远无益，问题就简化成"从 $s$ 起连续不断地做，选一个顺序"。

**引理 1（左移消空闲）。** 若开始时刻 $s$ 下存在可行安排，则存在一个从 $s$ 起**无空闲连续执行**的可行安排（顺序不变）。

*证明*：取任一可行安排，保持工作顺序不变，把每段空闲删去、让后一个工作紧接前一个工作的完成时刻开始。对第 $k$ 个工作归纳：新完成时刻 $F'_k\le F_k$。$k=1$：$F'_1=s+T_1\le F_1$（原安排第一个工作可能在 $s$ 之后才开始）✓。设 $F'_{k-1}\le F_{k-1}$，则 $F'_k=F'_{k-1}+T_k\le F_{k-1}+T_k\le F_k$（原安排中工作 $k$ 的开始 $\ge F_{k-1}$）✓。于是每个 $F'_k\le F_k\le S_k$，新安排仍可行。证毕。

**推论**：只需考虑"从 $s$ 起连续执行某个排列"的安排。此时若排列为 $\pi_1,\dots,\pi_N$，则 $F_{\pi_k}=s+\sum_{t\le k}T_{\pi_t}$，可行性条件是

$$\forall k:\quad s+\sum_{t\le k}T_{\pi_t}\le S_{\pi_k}. \tag{$\ast$}$$

### 第二步：哪个顺序最好？——试探与碰壁

现在要选排列。两个自然的候选：

- **耗时短的先做（SPT）**？反例：$(T,S)=(1,100),(10,10)$。SPT 先做 1：完成 1、11，第二个工作 $11>10$ 失败；但先做 10 再做 1：完成 10、11，都达标。**SPT 错**。
- **截止早的先做（EDF）**？上例中 EDF 先做 $(10,10)$，恰好正确。直觉：截止紧的工作"容不得等"，应该优先。但直觉不是证明——万一 EDF 也有反例呢？下面用**交换论证**证明 EDF 永远不吃亏。

**引理 2（EDF 交换论证）。** 固定开始时刻 $s$。若存在可行的连续安排，则按 $S$ **升序**（EDF）排列的连续安排也可行。

*证明*：设某可行排列中存在**相邻逆序对**：位置 $k,k+1$ 上是工作 $a,b$，且 $S_a>S_b$（截止晚的反而排在前面）。设这两个工作开始前已耗时 $P$（即 $a$ 从 $s+P$ 开始）。原安排可行给出：

$$s+P+T_a\le S_a,\qquad s+P+T_a+T_b\le S_b.$$

交换 $a,b$ 后：$b$ 完成于 $s+P+T_b\le s+P+T_a+T_b\le S_b$ ✓；$a$ 完成于 $s+P+T_b+T_a=s+P+T_a+T_b\le S_b<S_a$ ✓。其余工作的开始/完成时刻完全不变（这两个工作的总耗时 $T_a+T_b$ 没变，占用的时间区间总长没变）。所以**交换相邻逆序对保持可行性**。

任何排列都能通过有限次相邻交换变成 EDF 排列（冒泡排序：每次交换减少一个逆序对，逆序对数有限非负，必然终止；截止相同的元素间无需交换）。每一步都保持可行性，故 EDF 排列可行。证毕。

### 第三步：EDF 下的可行性刻画——reduce to easier problem

固定 EDF 顺序（把下标重排使 $S_1\le S_2\le\cdots\le S_N$），记前缀耗时 $A_k=\sum_{t\le k}T_t$。

**引理 3（前缀刻画）。** 开始时刻 $s$ 下 EDF 连续安排可行 $\iff$ 对所有 $k$：$s+A_k\le S_k$。

*证明*：EDF 连续安排中工作 $k$ 恰在 $s+A_k$ 完成（无空闲、顺序固定），可行性条件 $(\ast)$ 逐字变成 $s+A_k\le S_k$。必要性、充分性都是同一组不等式，双向成立。证毕。

注意这里用到了 $S$ 升序：每个工作 $k$ 的完成时刻是 $s+A_k$，它只需不超过**自己的**截止 $S_k$；前缀内部更早工作的约束是另一条独立不等式 $s+A_t\le S_t\ (t<k)$，同样包含在 $\forall k$ 之中，一条不多、一条不少。

### 第四步：最晚开始时刻的闭式——答案浮现

把引理 3 的不等式解出 $s$：$s\le S_k-A_k$ 对所有 $k$ 成立。令**余量** $D_k=S_k-A_k$，则

$$s\text{ 可行}\iff s\le\min_k D_k.$$

**引理 4（答案公式）。** 记 $D^\*=\min_{1\le k\le N}(S_k-A_k)$（EDF 序下）。则：

(a) 若 $D^\*\ge0$，最晚开始时刻就是 $D^\*$；
(b) 若 $D^\*<0$，任何 $s\ge0$ 都不可行，输出 `-1`。

*证明*：(a) 由引理 3，$s=D^\*$ 满足全部前缀约束，EDF 安排可行；又任何可行安排经引理 1（消空闲）、引理 2（换成 EDF）后仍可行，故其 $s$ 必满足 $s\le D_k\ \forall k$，即 $s\le D^\*$。所以 $D^\*$ 可行且是上界，恰为最晚。(b) 若某 $s\ge0$ 可行，同理由引理 1、2、3 得 $s\le D^\*<0$，与 $s\ge0$ 矛盾。故无可行 $s$，按题意输出 `-1`。证毕。

**边界核对**：$D^\*=0$ 时输出 0（合法，"现在就得开始"）；$D^\*<0$ 时输出 -1，**不能**输出 $\max(0,D^\*)=0$——那是把"不可行"误报成"恰好可行"。

### 第五步：实现与复杂度——classic problem solution

算法只剩三步：按 $S$ 升序排序；扫一遍累加 $A_k$ 并取 $\min(S_k-A_k)$；按符号输出。

**引理 5（复杂度与值域）。** 时间 $O(N\log N)$，空间 $O(N)$；所有中间量绝对值 $\le 2\times10^6$，`int` 安全。

*证明*：排序 $O(N\log N)$，扫描 $O(N)$。$A_k\le\sum T_i\le1000\times1000=10^6$，$S_k\le10^6$，故 $D_k\in[-10^6,10^6]$，`int` 远够。存储 $N$ 个 `{T,S}` 对。证毕。

### 定理

程序输出：$D^\*\ge0$ 时输出 $D^\*$（最晚开始时刻），否则输出 `-1`。

*证明*：引理 1 把问题归约到连续安排；引理 2 证明 EDF 顺序不失可行性；引理 3 给出 EDF 可行性的前缀不等式组；引理 4 解出最晚开始时刻并处理不可行分支；引理 5 保证实现复杂度与数值安全。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 空闲只会推迟完成：左移论证把"任意安排"归约成"从 $s$ 起连续执行一个排列"。
2. **consider easier version** — 先固定顺序问可行性：前缀耗时 + 截止不等式组；再试探 SPT，构造反例否定。
3. **classic problem solution** — EDF（截止早优先）+ 相邻逆序交换论证：交换后两工作都仍达标、其余不变，冒泡到 EDF 保持可行性。
4. **reduce to easier problem** — EDF 下可行性 $\iff\forall k:s+A_k\le S_k$，解出 $s\le\min_k(S_k-A_k)$，最晚开始有闭式。
5. **discuss by category** — $D^\*\ge0$ 输出 $D^\*$（含 0）；$D^\*<0$ 输出 -1，绝不能 clamp 成 0；排序、前缀和、取 min 一遍扫完。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N$ | 工作数 $\le1000$ | `int n` | 读入 |
| `mxn` | $1000+5$ | `constexpr int` | 数组尺寸 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | `ans` 初值，必被某个 $D_k\le10^6$ 更新 |
| `a[i]` | 第 $i$ 个工作 `{t,s}`：耗时、截止 | `struct job[mxn]` | 读入；按 `s` 升序排序 |
| `cur` | 前缀耗时 $A_k$ | `int`，初值 0 | 每读一个工作 `cur+=t` |
| `ans` | 余量最小值 $D^\*=\min(S_k-A_k)$ | `int`，初值 `inf` | 最终 $\ge0$ 输出它，$<0$ 输出 -1 |

### 算法步骤

1. I/O 加速三行；读 $N$ 与所有 $(T_i,S_i)$。
2. 按 $S$ 升序排序（EDF）。
3. `cur=0`；顺序扫描：`cur+=a[i].t`，`ans=min(ans,a[i].s-cur)`。
4. `ans<0` 输出 `-1`，否则输出 `ans`。

### 复杂度

- 时间 $O(N\log N)$；空间 $O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；四组手造数据（Hint 反推组=2、不可行组=-1、恰为 0 组=0、单工作组=2）输出与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2920 [USACO08NOV] Time Management S
// 空闲无益（左移论证）⇒ 连续执行；EDF（截止升序）最优（相邻交换论证）。
// 可行 ⇔ 每个前缀 s+A_k ≤ S_k ⇒ 最晚开始 = min(S_k-A_k)，负则 -1。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},inf{1145141919};

int n,ans{inf};
struct job{int t,s;}a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i].t>>a[i].s;
	sort(a,a+n,[](job x,job y){return x.s<y.s;});	// EDF：截止早的先做
	int cur=0;
	for(int i=0;i<n;++i)
	{
		cur+=a[i].t;
		ans=min(ans,a[i].s-cur);	// 前缀约束：s ≤ S_i - 前缀耗时
	}
	cout<<(ans<0?-1:ans)<<'\n';	// 负余量 = 连 0 时刻开始都不可行，不能 clamp 成 0
	return 0;
}
```

### 代码说明

- 排序比较器只看 `s`（截止）；截止相同的工作任意先后都行——交换论证对 $S_a=S_b$ 的"逆序"同样成立（交换后两者完成时刻集合不变）。
- `ans` 初值 `inf` 是"尚未取 min"的哨兵；第一个工作就会把它更新成 $\le10^6$ 的真实余量，不存在残留。
- 最后一行三目是本题**唯一的语义陷阱**：`ans<0` 必须输出 `-1`。写成 `max(0,ans)` 会把不可行数据误判成"0 时刻开始可行"。
- 全程 `int`：前缀耗时与截止都 $\le10^6$，余量 $\ge-10^6$，无溢出。
