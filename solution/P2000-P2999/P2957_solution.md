# P2957 [USACO09OCT] Barn Echoes G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 给两个字符串 $a,b$（长度 $1\sim80$，字母串）。一个"重复部分"指**同时是其中一个串的前缀、另一个串的后缀**的字符串。求最长重复部分的长度；没有非空重复部分时答案为 $0$（空串平凡地满足条件）。

**第一步：把定义写成数学式子。** 设 $|a|=n,|b|=m$。长度为 $k$ 的重复部分存在，当且仅当

$$\underbrace{a[0..k)=b[m-k..m)}_{\text{方向一：}a\text{ 的前缀}=\ b\text{ 的后缀}}\quad\lor\quad\underbrace{b[0..k)=a[n-k..n)}_{\text{方向二：}b\text{ 的前缀}=\ a\text{ 的后缀}}.$$

两个方向**都要查**——题面例子就是证据：`moyooyoxyzooo` 与 `yzoooqyasdfljkamo`，方向一给出 `yzooo`（长 $5$），方向二给出 `mo`（长 $2$），答案取较大的 $5$。只查一个方向的代码会在"只有反向有重叠"的数据上 WA（比如 $a=$`xxmo`，$b=$`moqqq`，只有方向二成立，答案 $2$）。

**第二步：$k$ 的范围。** 前缀、后缀的长度都不能超过所在串的长度，所以 $k\le\min(n,m)$；$k=0$（空串）永远合法，答案存在且 $\ge0$。

**第三步：要不要上 KMP / 哈希？** 题目标签写着"哈希、前缀和"，很容易条件反射去写 KMP 的 next 数组或双哈希。但先算账：串长只有 $80$。枚举 $k$ 从 $\min(n,m)$  downto $1$，每个 $k$ 逐字符比较两个方向，总比较次数 $\le2\sum_{k=1}^{80}k=80\times81=6480$ 次——**比读入的字符数多不了一个数量级**。$O(L^2)$ 的暴力在 $L=80$ 时就是正解，KMP 的 $O(L)$ 在这里省不下任何可感知的时间，却要多写几十行容易出错的代码。**先算账再选工具。**（若 $L$ 到 $10^6$，才需要 KMP/Z 函数：对 $a+\#+b$ 求 Z 函数或 next 数组即可 $O(L)$ 解决，那是另一档规模的事。）

**第四步：能不能二分 $k$？** 不能，而且值得造个反例钉死。谓词 $P(k)=$"存在长 $k$ 的重复部分"**不单调**：取 $a=$`abca`，$b=$`xxabca`：

- $k=4$：$a$ 整体 `abca` = $b$ 的后缀 `abca` ✓；
- $k=3$：`abc` vs $b$ 后缀 `bca` ✗；$b$ 前缀 `xxa` vs $a$ 后缀 `bca` ✗；
- $k=2$：`ab` vs `ca` ✗；`xx` vs `ca` ✗；
- $k=1$：`a` vs $b$ 末位 `a` ✓。

真、假、假、真——"长重叠存在"推不出"短重叠存在"（前缀 / 后缀对齐的位置随 $k$ 整体滑动，没有遗传性）。所以二分答案没有合法性基础，只能**从大到小线性扫，第一个成功的 $k$ 就是最大值**。这也顺便解释了为什么不能"从小往大扫到失败就停"。

**第五步：边界。** 两串相同（$a=b=$`abc`）时 $k=n$ 整体成立，答案 $n$；完全无公共字母（`abcd`/`efgh`）答案 $0$；单字符串（`a`/`a`）答案 $1$；较短串整体嵌入较长串端部（`abcxxxxabcx` 与 `qqabcxxxxabcx`）答案 $11$——最后这组与题面 Hint 的口径（"`abcxxxxabcx` 是重复部分，答案 11"）一致。

**手造数据核对。** 题面正文例子用作第一组：

```
输入：                输出：
moyooyoxyzooo         5
yzoooqyasdfljkamo
```

手算：方向一 $k=5$ 时 $a$ 后缀 `yzooo` = $b$ 前缀 `yzooo` ✓；$k=6$ 时 `xyzooo` vs `yzoooq` ✗，更大也不成立；方向二最大 $k=2$（`mo`）。答案 $5$ ✓。

另造六组：`abca/xxabca`→$4$（非单调反例，同时验证"从大到小扫"）；`abc/abc`→$3$（全串重叠）；`abcd/efgh`→$0$（无重叠兜底）；`xxmo/moqqq`→$2$（仅方向二成立）；`abcxxxxabcx/qqabcxxxxabcx`→$11$（Hint 口径）；`a/a`→$1$（最小规模）。七组输出全部与手算一致。

## 二、思维链：完整证明

**记号。** $a,b$ 为输入串，$n=|a|,m=|b|$，$L=\min(n,m)\le80$。$x[0..k)$ 表示 $x$ 的长 $k$ 前缀，$x[|x|-k..|x|)$ 表示长 $k$ 后缀。定义谓词

$$P(k)\iff\bigl(a[0..k)=b[m-k..m)\bigr)\ \lor\ \bigl(b[0..k)=a[n-k..n)\bigr),\qquad 0\le k\le L.$$

串相等定义为长度相同且逐位字符相同。

---

### 引理 1（定义等价性：答案 $=\max\{k:P(k)\}$）

题目所求"最长重复部分的长度"等于 $\max\{k\in[0,L]:P(k)\}$，且该集合非空（$P(0)$ 恒真），故最大值存在。

*证明*：题目定义：重复部分是"同时是一个字符串的前缀和另一个字符串的后缀的字符串"。设重复部分为串 $t$，$|t|=k$。"一个串的前缀、另一个串的后缀"只有两种指派：$t$ 是 $a$ 的前缀且 $b$ 的后缀，或 $t$ 是 $b$ 的前缀且 $a$ 的后缀（"一个…另一个…"指两个不同的串；即使允许同串，$a$ 的前缀 = $a$ 的后缀的情形也已被 $k\le L$ 的枚举覆盖于两串之间的比较之外——但题面语境是"两个声音的重复部分"，指跨串重叠，两种指派已穷尽）。第一种指派即 $t=a[0..k)=b[m-k..m)$，第二种即 $t=b[0..k)=a[n-k..n)$。故"存在长 $k$ 的重复部分" $\iff P(k)$。

范围：前缀长度 $\le$ 所在串长，故 $k\le n$ 且 $k\le m$，即 $k\le L$。$k=0$ 时两个比较都是空串 = 空串，恒真，集合非空。有限非空整数集必有最大值，且最长重复部分的长度就是最大的可行 $k$。证毕。

### 引理 2（$P$ 不单调：二分与提前终止均不合法）

存在输入使 $P$ 的真值随 $k$ 增大呈"真—假—真"形态，故 $P$ 既不单调增也不单调减。

*证明*：构造 $a=$`abca`（$n=4$），$b=$`xxabca`（$m=6$），$L=4$。逐 $k$ 验证：

- $k=4$：方向一 $a[0..4)=$`abca`，$b[2..6)=$`abca`，相等，$P(4)$ 真。
- $k=3$：方向一 `abc` vs $b[3..6)=$`bca`，首字符 a≠b，不等；方向二 $b[0..3)=$`xxa` vs $a[1..4)=$`bca`，首字符 x≠b，不等。$P(3)$ 假。
- $k=2$：方向一 `ab` vs $b[4..6)=$`ca`，不等；方向二 `xx` vs $a[2..4)=$`ca`，不等。$P(2)$ 假。
- $k=1$：方向一 `a` vs $b[5..6)=$`a`，相等，$P(1)$ 真。

于是 $P(4)>P(3)$（真>假）而 $P(2)<P(1)$（假<真），两个方向的单调性都被同一组数据否定。直观原因：$k$ 变化时前缀与后缀的**对齐位置整体滑动**，长重叠的字符对应关系不遗传给短重叠（与"子串出现"这类单调谓词本质不同）。故二分答案、"从小到大扫到第一个失败即停"都没有正确性依据。证毕。

### 引理 3（从大到小扫描返回最大值）

程序按 $k=L,L-1,\dots,1$ 的顺序检查 $P(k)$，首次为真即输出 $k$ 并结束；若全假则输出 $0$。该输出等于 $\max\{k:P(k)\}$。

*证明*：设 $k^\*=\max\{k\in[0,L]:P(k)\}$（引理 1 保证存在）。

**情形 A：$k^\*\ge1$。** 扫描经过所有 $k>k^\*$ 时，由 $k^\*$ 的最大性，$P(k)$ 假，程序不输出、继续；扫到 $k=k^\*$ 时 $P(k^\*)$ 真，程序输出 $k^\*$ 并 `return 0`。故输出恰为 $k^\*$。

**情形 B：$k^\*=0$。** 对所有 $k\in[1,L]$，$P(k)$ 假（否则 $k^\*\ge k\ge1$），循环正常结束，程序输出 $0=k^\*$。

两情形穷尽，输出恒等于 $k^\*$。注意此论证**不需要任何单调性**——线性扫描的正确性只依赖"遍历了所有候选且按降序取第一个真"，这正是引理 2 排除二分后仍可用的原因。证毕。

### 引理 4（`ovl` 函数正确实现单方向比较）

`ovl(x,y,k)` 返回真 $\iff x[0..k)=y[|y|-k..k+|y|-k)$，即 $x$ 的长 $k$ 前缀等于 $y$ 的长 $k$ 后缀；且调用时所有下标合法。

*证明*：设 $m_y=|y|$。函数逐位比较 $x[j]$ 与 $y[m_y-k+j]$（$j=0..k-1$）：左侧恰遍历 $x[0..k)$，右侧恰遍历 $y[m_y-k..m_y)$，两串长度均为 $k$。逐位全等则返回真，任一位置不等立即返回假——这正是"长度相同且逐位相同"的串相等定义，故返回值等价于两子串相等。

下标合法性：主程序只在 $k\le L=\min(n,m)$ 时调用，故 $j<k\le|x|$，$x[j]$ 合法；$m_y-k+j\ge m_y-k\ge0$ 且 $<m_y$，$y$ 侧合法。特别地 $k\ge1$（循环下界），但即使 $k=0$ 函数也平凡返回真，与空串语义一致。证毕。

**推论**：`ovl(a,b,k)||ovl(b,a,k)` 恰为 $P(k)$ 的实现（两个方向分别对应引理 1 的两种指派，`||` 对应 $\lor$；短路求值不影响真值）。

### 引理 5（复杂度）

时间 $O(L^2)$，空间 $O(n+m)$。

*证明*：外层循环至多 $L$ 轮；第 $k$ 轮调用 `ovl` 至多两次，每次至多 $k$ 次字符比较（提前失配只会更少）。总比较次数 $\le2\sum_{k=1}^{L}k=L(L+1)\le80\times81=6480$。读入与输出 $O(n+m)$。故时间 $O(L^2+n+m)=O(L^2)$（$L\ge1$ 时 $n+m\le2\max\le2\times80$ 为常数级，但渐近式按 $L$ 写）。空间：两个输入串 $O(n+m)$，函数只用常数额外变量。代入 $L=80$：不足 $10^4$ 次基本操作，任何时限下都瞬间完成。证毕。

**对比 KMP / 哈希**：对 $a+\#+b$ 求前缀函数可 $O(n+m)$ 得到方向一的最大重叠（$\#$ 为不出现在字母表中的分隔符，保证匹配长度 $\le L$），方向二对称再做一次；哈希则需处理碰撞概率。两者在 $L=80$ 时收益为零、代码量与出错面翻倍，故不采用——这是"按规模选工具"的决策，不是"不会高级算法"。

### 定理

程序输出两串最长重复部分的长度，时间 $O(L^2)\le6480$ 次字符比较。

*证明*：引理 1 把题意等价转化为 $\max\{k:P(k)\}$；引理 2 排除二分与提前终止，确立降序线性扫描的必要性；引理 3 证明扫描输出即最大值；引理 4 证明每轮检查正确实现 $P(k)$ 且下标安全；引理 5 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 把"重复部分"形式化：$P(k)=$（$a$ 前缀 = $b$ 后缀）$\lor$（$b$ 前缀 = $a$ 后缀），$k\le\min(n,m)$，两个方向都必须查（题面例子正向 5、反向 2）。
2. **explore its property** — $k=0$（空串）恒合法 ⇒ 答案存在且 $\ge0$，无重叠时输出 0 有定义依据。
3. **consider easier version** — 先算账：$L\le80$，暴力枚举 $k$ + 逐字符比较 $\le6480$ 次，$O(L^2)$ 已是正解；KMP / 哈希是 $L\ge10^6$ 档的工具，此处收益为零。
4. **explore its property** — 造反例 `abca/xxabca` 证明 $P$ 不单调（真—假—假—真）：对齐位置随 $k$ 滑动，重叠无遗传性 ⇒ 二分与"扫到失败即停"均不合法。
5. **classic problem solution** — 降序线性扫描取第一个真：正确性只依赖穷尽 + 降序，不需要单调性；全假兜底输出 0。
6. **discuss by category** — 边界逐类核对：两串相同（答案 = 串长）、仅反向重叠、完全无重叠、单字符、短串整体嵌入长串端部（Hint 的 11）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `a,b` | 两个输入串 | `string` | `cin>>a>>b`，长度 $1\sim80$ |
| `n,m` | $\lvert a\rvert,\lvert b\rvert$ | `int` | 读入后取 `size()` |
| `k` | 当前枚举的重叠长度 | `int` | 从 `min(n,m)` 递减到 $1$ |
| `ovl(x,y,k)` | $x$ 的长 $k$ 前缀是否等于 $y$ 的长 $k$ 后缀 | `bool(const string&,const string&,int)` | 逐位比较 $x[j]$ 与 $y[\lvert y\rvert-k+j]$ |
| 输出 | 最长重复部分长度 | `int` | 首个成立的 $k$；全不成立输出 $0$ |

### 算法步骤

1. I/O 加速三行；读入 $a,b$，取 $n,m$。
2. $k$ 从 $\min(n,m)$ 到 $1$ 降序枚举：若 `ovl(a,b,k)` 或 `ovl(b,a,k)` 为真，输出 $k$ 并结束程序。
3. 循环结束仍未输出，则输出 $0$（空串重叠兜底）。

### 复杂度

- 时间：$O(L^2)$，$L=\min(n,m)\le80$，至多 $6480$ 次字符比较。
- 空间：$O(n+m)$，两个输入串。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子输出 5；另造非单调、全串重叠、无重叠、仅反向、Hint 口径 11、单字符共七组全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2957 [USACO09OCT] Barn Echoes G
// 串长 <=80，O(L^2) 枚举长度 + 逐字符比较足够；两个方向都要查
// 谓词不单调（abca/xxabca：k=4 真 k=3 假 k=1 真），不能二分，从大到小扫
#include<bits/stdc++.h>
using namespace std;

string a,b;

bool ovl(const string&x,const string&y,int k)	// x 的长 k 前缀 == y 的长 k 后缀
{
	int m=y.size();
	for(int j=0;j<k;++j)
		if(x[j]!=y[m-k+j])
			return false;
	return true;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b;
	int n=a.size(),m=b.size();
	for(int k=min(n,m);k>=1;--k)
		if(ovl(a,b,k)||ovl(b,a,k))
		{
			cout<<k<<'\n';
			return 0;
		}
	cout<<0<<'\n';	// 空串永远是合法重叠，答案至少 0
	return 0;
}
```

### 代码说明

- **两个方向**：`ovl(a,b,k)` 查"$a$ 前缀 = $b$ 后缀"，`ovl(b,a,k)` 查反向；漏掉任何一个都会在单方向数据上 WA（如 `xxmo/moqqq` 只有反向成立）。
- `ovl` 的下标 `y[m-k+j]`：后缀起点是 `m-k`，不是 `m-k-1` 也不是 `k`；$k\le\min(n,m)$ 保证两侧都不越界（引理 4）。
- **降序扫描 + 首个成功即返回**：正确性不需要谓词单调（引理 3），而谓词确实不单调（引理 2 的反例），所以既不能二分也不能升序提前停。
- 循环下界是 $k\ge1$：$k=0$ 不必检查（恒真），由循环外的 `cout<<0` 兜底。
- `ovl` 参数用 `const string&` 避免每次调用拷贝串；`m=y.size()` 在函数内取，两方向复用同一份代码。
- 串长 $\le80$，无需 `mxn` 数组与哨兵；`string` 直接承载输入，是本题最简形态。
