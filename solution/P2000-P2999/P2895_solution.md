# P2895 [USACO08FEB] Meteor Shower S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 第一象限的整数格点图（$x,y\ge 0$），贝茜时刻 $0$ 在 $(0,0)$，每单位时间沿坐标轴走到相邻格。$M\le 5\times10^4$ 颗流星，第 $i$ 颗在时刻 $T_i\le 1000$ 砸中 $(X_i,Y_i)$（$0\le X_i,Y_i\le 300$），把**该格与四邻格**共 $5$ 格永久烧毁。格子在时刻 $t$ 被毁后，贝茜只能在**严格早于** $t$ 的时刻出现在该格。求走到一个**永不被毁**的格子的最早时刻；走不到输出 $-1$。

**口径说明。** 题面"如果一个格子在时刻 $t$ 被撞击或烧焦，贝茜只能在 $t$ 之前的时刻在这个格子里出现"给出的是**严格不等式**：到达时刻 $\tau$ 合法当且仅当 $\tau<\text{烧毁时刻}$。移动模型按离散时刻理解：时刻 $\tau$ 在 $u$、时刻 $\tau+1$ 在相邻格 $v$，只要求两个"出现时刻"各自合法（出发格在离开瞬间被毁不影响，这是本题的标准模型）。原点若时刻 $0$ 即被毁（$T=0$ 砸原点或其邻格），贝茜连出发都不行，直接 $-1$。

**第一步：把"流星"翻译成"每格的死线"。** 流星是事件，格子是状态——先把事件摊到格子上：令
$$D(x,y)=\min\{T_i:\text{第 }i\text{ 颗流星砸中 }(x,y)\text{ 或其四邻}\},$$
没有流星波及则 $D=\infty$（安全格）。这样"贝茜时刻 $\tau$ 能否在 $(x,y)$"就是一个纯局部判断 $\tau<D(x,y)$，$M$ 颗流星的信息被压缩进一张 $305\times305$ 的表。预处理 $O(5M)$。**这一步把"带时间的动态障碍"变成了"每格一个静态死线"**，后面所有推理都只面对 $D$。

**第二步：能不能原地等待？** 题目没禁止等，但等待**永远无益**：格子的可停留性随时间单调变差（$D$ 固定，$\tau$ 越大越容易 $\ge D$），等待不会解锁任何新格子。把任何含等待的走法里的等待删掉，每格到达时刻只会提前，仍然合法，且更早到安全格。所以最优解一定是"每时刻走一步"的路径，**到达时刻 = 步数**。

**第三步：于是就是 BFS——但带一条剪枝。** 无权图最短路 = BFS。唯一增量是扩展时的合法性检查：从 $(x,y)$（时刻 $t$）走到邻格 $(nx,ny)$，要求 $t+1<D(nx,ny)$。还有一个隐患：**BFS 每格只访问一次（最早到达时刻），会不会漏掉"晚点到反而能走通"的解？** 不会——约束是 $\tau<D$，**越早到越宽松**：若晚到时刻 $\tau'$ 能继续走通，早到时刻 $\tau\le\tau'$ 沿同一后续走法每个时刻都更早，处处仍合法。所以"最早到达"支配一切晚到达，普通 BFS 的"访问一次"规则原封不动成立。这是本题 correctness 的核心，下面引理 3 严格证。

**第四步：图是无限的，BFS 在哪停？** 第一象限无限大，但流星坐标 $\le300$，波及范围 $\le301$，所以**坐标 $\ge302$ 的格子全是安全格**。任何一条通往安全格的路径，取它**第一次**踏上安全格的位置：前一格不安全（坐标 $\le301$），走一步坐标至多 $+1$，故首个安全格坐标 $\le302$。于是把搜索框限制在 $[0,302]^2$ 不会丢掉任何最优解——出了这个框的格子根本不需要走。BFS 队列里**第一个弹出的安全格**就是答案（BFS 按时刻不减出队）。

**第五步：实现细节与坑。**

1. **`dgr` 必须显式 fill 成 INF**：全局 `int` 数组默认 $0$，而 $0$ 是"时刻 0 就被毁"的合法值——不填 INF 会把全图当成焦土，直接输出 $-1$。这是本题第一大坑。
2. `dis` 也 fill INF，兼作"未访问"标记（合法到达时刻 $\le$ 搜索框直径 $\ll$ INF，不会混淆）。
3. 流星在边界（如 $x=0$）时四邻有负坐标，跳过即可（贝茜也走不出第一象限）。
4. 同一格被多颗流星波及时取 $\min$——死线由**最早**的那颗决定。
5. 起点特判：$D(0,0)=0\Rightarrow -1$；$D(0,0)=\infty\Rightarrow$ 答案 $0$（BFS 第一轮弹出即返回，代码自然覆盖）。

**手造数据核对**（题面无样例，全部手造手算）：

|---|---|---|
| `1` + $(0,0,2)$ | 原点及 $(1,0),(0,1)$ 时刻 $2$ 毁；$(1,1)$ 是对角**不**被波及，$2$ 步到达 | `2` ✓ |

## 二、思维链：完整证明

**记号。** 格点集 $V=\{(x,y):x,y\ge0\}$。死线函数 $D:V\to\mathbb Z_{\ge0}\cup\{\infty\}$，$D(v)=\min\{T_i:v\in\mathrm{blast}_i\}$，其中 $\mathrm{blast}_i$ 是第 $i$ 颗流星的砸点及四邻（空集取 $\infty$）。称 $v$ **安全**当 $D(v)=\infty$。**合法行走**是序列 $v_0=(0,0),v_1,\dots,v_L$，相邻格曼哈顿距离 $1$、坐标非负，且对每个 $\tau$ 有 $\tau<D(v_\tau)$（含 $\tau=0$ 的原点检查）。目标：最小的 $L$ 使 $v_L$ 安全；不存在则 $-1$。$\mathrm{dis}(v)$ 表示 BFS 算出的到达时刻（未访问为 $\infty$）。搜索框 $B=[0,302]^2$。

---

### 引理 1（死线预处理正确）

对每格 $v$，程序算出的 `dgr[v]` 等于 $D(v)$；且 $v$ 在时刻 $\tau$ 可出现当且仅当 $\tau<\texttt{dgr}[v]$。

*证明*：程序对每颗流星把砸点与四个非负邻格的 `dgr` 与 $T_i$ 取 $\min$。格 $v$ 被第 $i$ 颗流星更新当且仅当 $v\in\mathrm{blast}_i$（砸点自身 + 四邻，负坐标邻格不在 $V$ 中、跳过不损失），故 `dgr[v]`$=\min\{T_i:v\in\mathrm{blast}_i\}=D(v)$；无流星波及时保持初值 INF$=\infty$。"可出现"的判据 $\tau<D(v)$ 是题面原文（"只能在 $t$ 之前的时刻出现"）的直接翻译，安全格 $D=\infty$ 时恒成立。证毕。

**推论**：$D$ 有限的格子坐标 $\le301$（流星坐标 $\le300$，波及半径 $1$）；坐标 $\ge302$ 的格子必安全。

---

### 引理 2（等待无益：最优解是每时刻一步的行走）

若存在合法行走（允许在原地停留，即 $v_{\tau+1}=v_\tau$ 也允许，同样要求 $\tau+1<D(v_\tau)$）在时刻 $L$ 到达安全格，则存在**不含停留**的合法行走在时刻 $L'\le L$ 到达安全格。

*证明*：把行走中所有停留步删除，得到序列 $w_0,w_1,\dots,w_{L'}$（$L'\le L$），相邻格仍距离 $1$。$w_k$ 在原行走中的出现时刻 $\tau_k\ge k$（每删一步，时刻与下标的差增大），且 $\tau_k<D(w_k)$。新行走中 $w_k$ 的出现时刻是 $k\le\tau_k<D(w_k)$，合法性保持（死线判据对时刻**单调**：越早越合法）。终点不变仍安全，$L'\le L$。证毕。

**意义**：只需搜索"到达时刻 = 步数"的路径，BFS 的层数就是时刻。

---

### 引理 3（最早到达支配晚到达；BFS 的 dis 正确）

(a) 若存在合法行走在时刻 $\tau'$ 到达 $v$，且从 $v$ 出发某后续走法在时刻序列 $\tau',\tau'+1,\dots$ 下合法，则对任何 $\tau\le\tau'$（$v$ 在 $\tau$ 可出现），同一后续走法从时刻 $\tau$ 出发也合法。
(b) 在搜索框 $B$ 上运行"BFS + 剪枝 $t+1<D$"，对每个 $B$ 内可达格 $v$，$\mathrm{dis}(v)$ 等于 $B$ 内合法行走到达 $v$ 的最早时刻。

*证明*：(a) 后续走法第 $k$ 格原出现时刻 $\tau'+k<D$，改为 $\tau+k\le\tau'+k<D$，逐格合法。故"晚到能走通 $\Rightarrow$ 早到能走通"，每格只需记录最早到达时刻，**访问一次**不丢解。

(b) 对 BFS 出队顺序归纳，证不变量：出队的 $\mathrm{dis}$ 值不减，且每个出队格 $v$ 的 $\mathrm{dis}(v)$ 是 $B$ 内最早合法到达时刻。

- 起点：$\mathrm{dis}(0,0)=0$，任何行走 $0$ 时刻在起点，最早即 $0$（若 $D(0,0)=0$ 已提前判 $-1$，否则 $0<D$ 合法）。
- 设已出队格的断言成立。队列中元素的 $\mathrm{dis}$ 值不减（BFS 每次扩展 $+1$，标准性质）。取出队首 $u$，$\mathrm{dis}(u)=t$。对邻格 $v$：若 $v$ 已访问，$\mathrm{dis}(v)\le t+1$（更早出队或同层先入队），无需更新。若未访问且 $t+1<D(v)$，置 $\mathrm{dis}(v)=t+1$。要证这是最早：任何到达 $v$ 的合法行走倒数第二格 $u'$ 满足"到达 $u'$ 的时刻 $+1<D(v)$"，且 $u'$ 的最早到达 $\mathrm{dis}(u')\le$ 该行走到达 $u'$ 的时刻；由 (a)，从 $\mathrm{dis}(u')$ 出发走最后一步仍合法，故最早到达 $v$ 的时刻 $=\min_{u'\sim v}\mathrm{dis}(u')+1$（只取满足 $<D(v)$ 者）。所有 $\mathrm{dis}(u')<t+1$ 的 $u'$ 已出队并扩展过（出队值不减），它们的扩展若合法早已把 $v$ 入队；现在 $v$ 仍未访问，说明这些 $u'$ 要么不合法要么 $\mathrm{dis}(u')+1\ge t+1$，故 $t+1$ 就是最小值。
- 剪枝掉的 $v$（$t+1\ge D(v)$ 且未访问）：任何更晚的到达时刻 $\ge t+1\ge D(v)$ 都不合法，$v$ 确实不可达，不丢解。

归纳成立。证毕。

---

### 引理 4（搜索框 $[0,302]^2$ 不丢最优解）

设存在 $V$ 上的合法行走到达某安全格。则存在 $B=[0,302]^2$ 内的合法行走，在**不晚于**原时刻到达某安全格。

*证明*：取原行走**第一次**到达安全格的前缀 $v_0,\dots,v_L$（$v_L$ 安全，$v_0..v_{L-1}$ 均不安全）。由引理 1 推论，不安全格坐标 $\le301$；$v_L$ 与 $v_{L-1}$ 曼哈顿距离 $1$，故 $v_L$ 坐标 $\le302$。于是整条前缀落在 $B$ 内，长度 $L$ 不超过原行走长度。反之 $B\subseteq V$，$B$ 内的行走本来就是合法行走。两边取最小值相等。证毕。

---

### 引理 5（首个出队的安全格即答案；起点特判）

(a) 若 $D(0,0)=0$，无合法行走，答案 $-1$。
(b) 否则 BFS 在 $B$ 上运行，**第一个出队的安全格**的 $\mathrm{dis}$ 值就是全局答案；队列空则答案 $-1$。

*证明*：(a) 合法行走要求 $0<D(v_0)=0$，矛盾，故不存在。

(b) 由引理 3(b)，出队时刻值不减。设第一个出队的安全格为 $s$，$\mathrm{dis}(s)=t^\*$。一方面存在长度 $t^\*$ 的合法行走到安全格（BFS 路径），答案 $\le t^\*$。另一方面设最优答案为 $t_{\mathrm{opt}}$，由引理 4 存在 $B$ 内长度 $t_{\mathrm{opt}}$ 的合法行走到某安全格 $s'$；由引理 3(b) $\mathrm{dis}(s')\le t_{\mathrm{opt}}$，且 $s'$ 必被入队出队（其路径上每格都被松弛）。出队值不减 $\Rightarrow$ 首个安全格出队值 $t^\*\le\mathrm{dis}(s')\le t_{\mathrm{opt}}$。故 $t^\*=t_{\mathrm{opt}}$。

队列空：$B$ 内无合法可达的安全格；由引理 4，$V$ 内也没有，答案 $-1$。特别地 $D(0,0)=\infty$ 时起点自身安全，第一轮出队即输出 $0$。证毕。

---

### 引理 6（复杂度）

时间 $O(M+|B|)=O(M+303^2)$，空间 $O(|B|)$。

*证明*：预处理每颗流星更新 $5$ 格，$O(5M)$。BFS 每格至多入队一次、每次扩展 $4$ 邻，$O(4|B|)$，$|B|=303^2\approx9.2\times10^4$。合计 $O(M+|B|)\approx2.5\times10^5+9.2\times10^4$ 次基本操作。空间两张 $305^2$ 的 `int` 表约 $0.74$ MB。证毕。

---

### 定理

程序输出贝茜到达安全格的最短时刻（不可达输出 $-1$），时间 $O(M+303^2)$。

*证明*：引理 1 保证死线表正确、判据 $\tau<D$ 与题意一致；引理 2 把问题化为无停留行走；引理 3 保证"最早到达支配晚到达"，带剪枝的 BFS 算出的 $\mathrm{dis}$ 恰为最早合法到达时刻；引理 4 保证有限搜索框不丢最优解；引理 5 保证首个出队安全格即答案、起点特判与 $-1$ 分支正确；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 把 $M$ 个"流星事件"摊成每格一个静态死线 $D(x,y)=\min T$（砸点 + 四邻取 min），动态障碍变静态判据 $\tau<D$。
2. **explore its property** — 可停留性随时间单调变差 $\Rightarrow$ 等待永远无益，最优解是"到达时刻 = 步数"的路径。
3. **consider easier version** — 去掉流星就是网格无权最短路 = 裸 BFS；增量就一条剪枝 $t+1<D$。
4. **explore its property** — 约束 $\tau<D$ 对时刻单调 $\Rightarrow$ 最早到达支配晚到达，BFS"每格访问一次"不丢解（这是带时间约束仍能裸 BFS 的充要结构）。
5. **reduce to easier problem** — 流星坐标 $\le300\Rightarrow$ 焦土 $\le301\Rightarrow$ 首个安全格坐标 $\le302$，无限图截成 $303^2$ 有限框。
6. **classic problem solution** — BFS 按时刻不减出队，首个出队的安全格即答案；队空输出 $-1$。
7. **discuss by category** — 边界分类：$D(0,0)=0$ 直接 $-1$；$D(0,0)=\infty$ 答案 $0$；流星贴边时负坐标邻格跳过；`dgr`/`dis` 必须显式 fill INF（全局默认 $0$ 是合法死线值，不是无穷）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `m` | 流星数 $\le5\times10^4$ | `int` | 读入 |
| `dgr[x][y]` | 格 $(x,y)$ 被烧毁的最早时刻 $D$ | `int[mxn][mxn]` | **fill INF**；INF=永远安全；$0$ 是合法死线，绝不能靠默认 |
| `dis[x][y]` | BFS 最早合法到达时刻 | `int[mxn][mxn]` | **fill INF**，兼作"未访问"标记 |
| `mxn` | $305$（坐标上界 $302+5$ 松弛） | `constexpr int` | 表尺寸 |
| `lim` | $302$：搜索框 $[0,\texttt{lim}]^2$ | `constexpr int` | 焦土 $\le301$，$302$ 必安全 |
| `inf` | $1145141919$ | `constexpr int` | 远大于任何合法时刻（$\le$ 框直径 $\approx600$） |
| `dx,dy` | 四方向 | `int[4]` | 读流星与 BFS 共用 |
| `Q` | BFS 队列，存坐标对 | `queue<pair<int,int>>` | 时刻从 `dis` 现查，不存三元组 |

### 算法步骤

1. I/O 加速三行；`dgr`、`dis` 整表 fill INF。
2. 读 $M$；每颗流星 $(x,y,t)$：`dgr[x][y]` 与四个非负邻格各对 $t$ 取 $\min$。
3. 若 `dgr[0][0]==0`：输出 $-1$，结束。
4. `dis[0][0]=0`，起点入队。
5. 循环出队 $(x,y)$，$t=$`dis[x][y]`：若 `dgr[x][y]==inf`，输出 $t$ 结束；否则扩展四邻 $(nx,ny)$：越界（$<0$ 或 $>\texttt{lim}$）、已访问、或 $t+1\ge$`dgr[nx][ny]` 则跳过，否则 `dis=t+1` 入队。
6. 队空输出 $-1$。

### 复杂度

- 时间 $O(M+303^2)\approx3.4\times10^5$；空间 $O(305^2)\approx0.74$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；9 组手造数据（严格小于边界、困死、原点时刻 0 被毁、原点安全、同格多流星取 min、对角不波及、穿过稍后烧毁格）全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2895 Meteor Shower S
// dgr[x][y]=该格被烧毁的最早时刻（流星砸自己+四邻），inf=永远安全
// BFS：到达时刻 t 必须严格 <dgr；每格只在最早到达时刻入队一次
// 流星坐标<=300 ⇒ 焦土<=301 ⇒ 坐标 302 必安全，搜索框 [0,302] 足够
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{305},lim{302},inf{1145141919};

int m,dgr[mxn][mxn],dis[mxn][mxn];
int dx[4]={1,-1,0,0},dy[4]={0,0,1,-1};
queue<pair<int,int>>Q;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	fill_n(&dgr[0][0],mxn*mxn,inf);	// 全局默认 0 不是 inf！
	fill_n(&dis[0][0],mxn*mxn,inf);	// dis=inf 兼作"未访问"
	cin>>m;
	for(int i=0,x,y,t;i<m;++i)
	{
		cin>>x>>y>>t;
		dgr[x][y]=min(dgr[x][y],t);
		for(int k=0;k<4;++k)
		{
			int nx=x+dx[k],ny=y+dy[k];
			if(nx>=0&&ny>=0)
				dgr[nx][ny]=min(dgr[nx][ny],t);
		}
	}
	if(dgr[0][0]==0)	// 时刻 0 原点已毁，贝茜无法出发
	{
		cout<<-1<<'\n';
		return 0;
	}
	dis[0][0]=0;
	Q.push({0,0});
	while(!Q.empty())
	{
		auto[x,y]=Q.front();Q.pop();
		int t=dis[x][y];
		if(dgr[x][y]==inf)	// BFS 按时间出队，首个安全格即答案
		{
			cout<<t<<'\n';
			return 0;
		}
		for(int k=0;k<4;++k)
		{
			int nx=x+dx[k],ny=y+dy[k];
			if(nx<0||ny<0||nx>lim||ny>lim)
				continue;
			if(dis[nx][ny]!=inf||t+1>=dgr[nx][ny])
				continue;	// 必须严格早于烧毁时刻
			dis[nx][ny]=t+1;
			Q.push({nx,ny});
		}
	}
	cout<<-1<<'\n';
	return 0;
}
```

### 代码说明

- **两张表都必须 fill INF**：`dgr` 的 $0$ 是"时刻 0 被毁"的合法值，靠全局默认零初始化会把全图当焦土；`dis` 的 INF 兼作未访问标记，合法时刻最大不过几百，与 INF 无混淆。
- 判据是 `t+1>=dgr` 则**跳过**——题面要求严格早于烧毁时刻，写成 `>` 会在"恰好同刻"的数据上 WA（手造第 2、6 组专打这个）。
- 流星更新只挡负坐标（`nx>=0&&ny>=0`），上界不用挡：$300+1=301<305$。
- 搜索框上界 `lim=302` 由引理 4 保证不丢最优解；`mxn=305` 是 $+5$ 松弛，框外格子永远不访问。
- 安全判定放在**出队时**而非入队时：起点安全（答案 $0$）与中途安全走同一段代码，无需特判。
- 队列只存坐标，时刻从 `dis` 现查——每格只入队一次，`dis` 即该格唯一正确的时刻，省一个字段。
