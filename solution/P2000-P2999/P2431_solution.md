# P2431 正妹吃月饼 — 题解

## 一、解题过程：人类思考叙事

题目重述：月饼的重量是 $1,2,4,8,16,\dots$ 克，即 $2^0,2^1,2^2,\dots$，**每种恰好一个**。正妹要挑一个子集吃掉，设总重量为 $S$，要求 $A\le S\le B$，在此前提下**最大化月饼的个数**（不是重量）。$1\le A\le B\le 2^{63}-1$。

**第一反应：背包。** 物品是 $2^0,2^1,\dots$，容量 $B$，求"重量落在 $[A,B]$ 内时最多选几件"。但 $B$ 高达 $2^{63}-1$，重量维度的 DP 根本开不下；物品虽然有无穷多种，可真正能用的只有 $2^0\sim 2^{62}$ 这 $63$ 种（再大就超过 $B$ 了），$2^{63}$ 种子集也枚举不动。背包这条路直接堵死。

**第二反应：贪心。** 要个数最多，当然优先拿小的：$1+2+4+\dots+2^{k-1}=2^k-1$。于是"拿最轻的 $k$ 个"是重量最省的 $k$ 件方案。可是还有个下界 $A$：如果 $2^k-1<A$，就得把某些小月饼换成大的，个数不变但重量上升。换哪几个？换多少？一旦开始讨论"换法"，情况就爆炸了——我试着写了几个小例子，发现"贪心拿最小的 $k$ 个再往上补"根本无法直接给出最大的 $k$。贪心卡住。

**卡住之后回头看物品本身。** 这些重量是 $2$ 的幂，而且**每种只有一个**。这句话太眼熟了：一个由互不相同的 $2$ 的幂组成的集合，它的和……不就是**二进制表示**吗？

- 选 $\{1,2,4,16\}$，和是 $23$，而 $23=(10111)_2$，恰好 $4$ 个 $1$；
- 选 $\{1,2,4,8\}$，和是 $15=(1111)_2$，$4$ 个 $1$；
- 选 $\{2,8\}$，和是 $10=(1010)_2$，$2$ 个 $1$。

反过来，任何一个数 $x$ 的二进制里哪些位是 $1$，就唯一决定了"吃哪几个月饼"。**子集与数是一一对应的，子集大小就是 $\operatorname{popcount}(x)$。** 于是原题被彻底改写：

> 在 $[A,B]$ 中找一个整数 $x$，使 $\operatorname{popcount}(x)$ 最大，输出这个最大值。

背包、贪心、换法讨论全部消失，只剩一个"区间内最多 $1$ 位数"的问题。这就是本题真正的样子（题目标签里的"进制"正是指这一步）。

**先做简化版：去掉下界 $A$。** 在 $[0,B]$ 里最多能有多少个 $1$？这里有个一眼能看出的事实：**含 $k$ 个 $1$ 的最小正整数是 $\underbrace{11\cdots1}_{k}=2^k-1$**。所以

- 若 $2^{k+1}-1>B$，则 $[0,B]$ 里不可能有 $k+1$ 个 $1$ 的数（任何这样的数都 $\ge 2^{k+1}-1$）；
- 而 $2^k-1\le B$ 时，$2^k-1$ 本身就有 $k$ 个 $1$，取到上界。

于是 $\max_{x\le B}\operatorname{popcount}(x)=\lfloor\log_2(B+1)\rfloor$。漂亮，但**这只是简化版**。

**把下界加回来，立刻碰壁。** 反例：$A=B=8$。公式给 $\lfloor\log_2 9\rfloor=3$，可 $8=(1000)_2$ 只有 $1$ 个 $1$，正确答案是 $1$。原因是 $7=(111)_2$ 虽然 $1$ 多，却小于 $A$，被下界挡掉了。所以"全 $1$ 数"不一定落在区间里，必须同时照顾两端。

**再试一个更朴素的贪心：从高位往低位尽量填 $1$。** 写出来后发现它会漏解：$A=8,B=9$ 时，最高位（第 $3$ 位）$A,B$ 都是 $1$，填 $1$；第 $2,1$ 位 $A,B$ 都是 $0$，只能填 $0$；第 $0$ 位 $A=0,B=1$，填 $1$ 得 $9=(1001)_2$，$2$ 个 $1$，这次对了。但换成 $A=10,B=12$：公共高位是 $1$（第 $3$ 位），第 $2$ 位 $A=0,B=1$，贪心填 $1$ 就得 $\ge 12$，低位只能全 $0$，得 $12=(1100)_2$，$2$ 个 $1$；而实际最优是 $11=(1011)_2$，$3$ 个 $1$——**第 $2$ 位填 $0$、把低位全填 $1$ 反而更好**。逐位贪心失败，失败原因是"某一位填 $1$ 会挤掉后面一整串 $1$"。

**从失败里提炼结构。** 上面两个例子提示：真正起决定作用的是 $A$ 与 $B$ **最高的那个不同位**。设它是第 $p$ 位。比 $p$ 高的位上 $A,B$ 完全一样，那么区间里的任何数在这些位上也**必须**和它们一样（否则要么 $<A$ 要么 $>B$，第二节引理 3 会严格证明）。所以高位的 $1$ 的个数是**白送的定值**，记作 $\mathrm{cnt}$。

第 $p$ 位上 $A$ 是 $0$、$B$ 是 $1$（因为 $A\le B$ 且这是最高不同位）。于是区间里的数只有两类：

- **第 $p$ 位填 $0$**：这个数已经 $<B$ 了，上界自动满足；只要低位 $\ge A$ 的低位即可。低位一共 $p$ 位，全填 $1$ 就是最大（$p$ 个 $1$），而且 $2^p-1$ 一定 $\ge A$ 的低位。所以这一支稳拿 $\mathrm{cnt}+p$。
- **第 $p$ 位填 $1$**：这个数已经 $>A$ 了，下界自动满足；只要低位 $\le B$ 的低位 $B_{\text{low}}$。这就退回刚才的简化版：低位最多 $\lfloor\log_2(B_{\text{low}}+1)\rfloor$ 个 $1$，加上第 $p$ 位自己那 $1$ 个，共 $\mathrm{cnt}+1+\lfloor\log_2(B_{\text{low}}+1)\rfloor$。

两支取最大即可。**再化简一步**：$B_{\text{low}}\le 2^p-1$，所以 $\lfloor\log_2(B_{\text{low}}+1)\rfloor\le p$，第二支 $\le \mathrm{cnt}+p+1$；而它等于 $\mathrm{cnt}+p+1$ 当且仅当 $B_{\text{low}}=2^p-1$（$B$ 的低 $p$ 位全 $1$），否则 $\le \mathrm{cnt}+p$，被第一支盖住。于是最终答案只剩一个漂亮的式子：

$$\text{ans}=\mathrm{cnt}+p+[\,B\text{ 的低 }p+1\text{ 位全是 }1\,].$$

**边界**：$A=B$ 时不存在"不同位"，区间只有一个数，答案就是 $\operatorname{popcount}(A)$，必须单独处理（否则 $p$ 无定义）。

**用题面 Hint 自查。** Hint 说"可以吃 $1,2,4,16$ 这 $4$ 个"，$1+2+4+16=23=(10111)_2$，$4$ 个 $1$。题面没给样例输入输出，我自己造一组与之相容的：$A=2,B=23$。此时 $A\oplus B=21=(10101)_2$，$p=4$，公共高位为空 $\mathrm{cnt}=0$，$B$ 的低 $5$ 位是 $10111\ne 11111$，故答案 $0+4+0=4$，与 Hint 吻合。再造 $A=B=8\to1$、$A=1,B=10\to3$（吃 $1,2,4$，共 $7$ 克）、$A=B=2^{63}-1\to63$，全部手算可验证。

## 二、思维链：完整证明

下面把整条推理链补成严格证明。记 $v_2$ 无关，只用二进制位运算：$x$ 的第 $i$ 位记 $x_i$，$\operatorname{pc}(x)$ 为 $x$ 的二进制中 $1$ 的个数。

### 引理 1（可行方案与区间整数的一一对应）

设月饼重量集合为 $W=\{2^0,2^1,2^2,\dots\}$，每种一个。则

$$\max\{|S|:S\subseteq W,\ A\le\textstyle\sum_{w\in S}w\le B\}=\max\{\operatorname{pc}(x):x\in\mathbb Z,\ A\le x\le B\}.$$

*证明*：分三步。

**(a) 能用的月饼只有 $2^0,\dots,2^{62}$。** 若 $S$ 含某个 $2^k$ 且 $k\ge63$，则 $\sum S\ge 2^{63}>2^{63}-1\ge B$，违反上界。故任何可行方案都是 $\{2^0,\dots,2^{62}\}$ 的子集。反之该集合的任意子集的和 $\le\sum_{i=0}^{62}2^i=2^{63}-1$，不会"越界到无法表示"。

**(b) 子集 $\leftrightarrow$ 整数是双射，且 $|S|=\operatorname{pc}(x)$。** 定义 $\varphi(S)=\sum_{i\in I}2^i$，其中 $S=\{2^i:i\in I\}$，$I\subseteq\{0,\dots,62\}$。由二进制表示的**存在唯一性**：每个 $x\in[0,2^{63}-1]$ 有唯一的位集合 $I(x)=\{i:x_i=1\}$ 使 $x=\sum_{i\in I(x)}2^i$；反之每个 $I$ 给出唯一的 $x$。故 $\varphi$ 是 $\{0,\dots,62\}$ 的子集族到 $[0,2^{63}-1]$ 的双射，且 $|S|=|I|=\operatorname{pc}(\varphi(S))$（$I$ 中每个元素贡献一个互不相同的二进制位 $1$，无进位）。

**(c) 约束等价。** 由 (b)，"$S$ 可行"等价于"$A\le\varphi(S)\le B$"，而目标 $|S|$ 等于 $\operatorname{pc}(\varphi(S))$。双射保证两边的最大值相等。证毕。

> 这条引理是整题的地基：它把"选物品"变成"选数"，把"个数"变成"popcount"。后面所有讨论都在整数区间上进行。

### 引理 2（前缀最大值：$[0,M]$ 内最多多少个 $1$）

对整数 $M\ge0$，$\displaystyle\max_{0\le x\le M}\operatorname{pc}(x)=\lfloor\log_2(M+1)\rfloor$。记 $f(M)=\lfloor\log_2(M+1)\rfloor$。

*证明*：设 $k=f(M)$，即 $2^k\le M+1<2^{k+1}$，等价于 $2^k-1\le M<2^{k+1}-1$。

**上界**：若 $\operatorname{pc}(x)\ge k+1$，则 $x$ 至少有 $k+1$ 个互不相同的二进制位为 $1$，故 $x\ge 2^0+2^1+\dots+2^{k}=2^{k+1}-1>M$，与 $x\le M$ 矛盾。所以 $\operatorname{pc}(x)\le k$。

**可达**：取 $x^\*=2^k-1=(\underbrace{1\cdots1}_{k})_2$。由 $k$ 的定义 $x^\*\le M$，且 $x^\*\ge0$，$\operatorname{pc}(x^\*)=k$。

上下界相等，故最大值为 $k$。证毕。

> 注意这里"含 $t$ 个 $1$ 的最小数是 $2^t-1$"是**唯一**用到的经典事实，它的证明就是上面上界那一句：$t$ 个不同的位权最小取 $2^0,\dots,2^{t-1}$。

### 引理 3（高位被强制）

设 $A<B$，$p$ 为 $A\oplus B$ 的最高位（即 $A,B$ 最高的不同位）。则任意 $x\in[A,B]$ 与 $A$（也与 $B$）在所有 $i>p$ 的位上完全相同。

*证明*：反证。设存在 $i>p$ 使 $x_i\ne A_i$，取其中最大的一个记为 $q$。于是对所有 $i>q$ 有 $x_i=A_i$；又因 $q>p$ 而 $A,B$ 在所有 $>p$ 的位上相同，故对所有 $i>q$ 也有 $x_i=B_i$。即 $x,A,B$ 三者在 $q$ 以上完全一致，胜负只由第 $q$ 位决定。

- 若 $x_q=1,A_q=0$：则 $x>A$；又 $B_q=A_q=0$（$q>p$），故 $x>B$，与 $x\le B$ 矛盾。
- 若 $x_q=0,A_q=1$：则 $x<A$，与 $x\ge A$ 矛盾。

两种情况都矛盾，故不存在这样的 $q$。证毕。

**推论 3.1**：$A_p=0$，$B_p=1$。
*证明*：$p$ 是最高不同位，故 $A_p\ne B_p$。若 $A_p=1,B_p=0$，由引理 3 的同样论证（更高全同）得 $A>B$，与 $A<B$ 矛盾。故 $A_p=0,B_p=1$。证毕。

记公共高位构成的数为 $\mathrm{pre}=\lfloor A/2^{p+1}\rfloor=\lfloor B/2^{p+1}\rfloor$，$\mathrm{cnt}=\operatorname{pc}(\mathrm{pre})$。由引理 3，任何可行 $x$ 的高位贡献恒为 $\mathrm{cnt}$，与低位选择无关。于是只需最大化低 $p+1$ 位的 $1$ 的个数。

### 引理 4（第 $p$ 位取 $0$ 的一支）

设 $A<B$，$p,\mathrm{cnt}$ 如上，$A_{\text{low}}=A\bmod 2^p$。则

$$\max\{\operatorname{pc}(x):x\in[A,B],\ x_p=0\}=\mathrm{cnt}+p,$$

且由 $x^{(0)}=\mathrm{pre}\cdot2^{p+1}+(2^p-1)$ 取到。

*证明*：**可达性**：$x^{(0)}$ 的高位是 $\mathrm{pre}$，第 $p$ 位是 $0$，低 $p$ 位全 $1$。
- $x^{(0)}\ge A$：两者高位相同、第 $p$ 位都是 $0$（$A_p=0$），只需比较低 $p$ 位：$2^p-1\ge A_{\text{low}}$，因为 $A_{\text{low}}=A\bmod 2^p\in[0,2^p-1]$。成立。
- $x^{(0)}\le B$：两者高位相同，而 $x^{(0)}_p=0<1=B_p$，故 $x^{(0)}<B$。成立。
- $\operatorname{pc}(x^{(0)})=\mathrm{cnt}+0+p$。

**上界**：任何 $x_p=0$ 的可行 $x$，其低 $p+1$ 位中第 $p$ 位为 $0$，剩下 $p$ 位最多 $p$ 个 $1$，加上固定的 $\mathrm{cnt}$，总数 $\le\mathrm{cnt}+p$。

上下界相等。证毕。

### 引理 5（第 $p$ 位取 $1$ 的一支）

设 $B_{\text{low}}=B\bmod 2^p$。则

$$\max\{\operatorname{pc}(x):x\in[A,B],\ x_p=1\}=\mathrm{cnt}+1+f(B_{\text{low}}),$$

其中 $f$ 由引理 2 给出；取到最大值的数是 $x^{(1)}=\mathrm{pre}\cdot2^{p+1}+2^p+(2^{f(B_{\text{low}})}-1)$。

*证明*：先刻画这一支的可行低位集合。$x$ 高位为 $\mathrm{pre}$、$x_p=1$，写 $x=\mathrm{pre}\cdot2^{p+1}+2^p+y$，$0\le y<2^p$。
- $x\ge A$：高位相同而 $x_p=1>0=A_p$，故 $x>A$ **恒成立**，与 $y$ 无关。
- $x\le B$：高位相同、第 $p$ 位相同（都是 $1$），故等价于 $y\le B_{\text{low}}$。

所以这一支等价于"在 $[0,B_{\text{low}}]$ 中选 $y$ 最大化 $\operatorname{pc}(y)$"，再加上第 $p$ 位的 $1$ 个与高位的 $\mathrm{cnt}$ 个。由引理 2，$\max\operatorname{pc}(y)=f(B_{\text{low}})$，在 $y^\*=2^{f(B_{\text{low}})}-1$ 处取到；由引理 2 的证明 $y^\*\le B_{\text{low}}$，故 $x^{(1)}$ 可行。总数 $\mathrm{cnt}+1+f(B_{\text{low}})$。证毕。

### 引理 6（两支合并与化简）

设 $A<B$。则

$$\max_{x\in[A,B]}\operatorname{pc}(x)=\mathrm{cnt}+\max\bigl(p,\ 1+f(B_{\text{low}})\bigr)=\mathrm{cnt}+p+[\,B_{\text{low}}=2^p-1\,].$$

*证明*：由推论 3.1，$x_p$ 只能是 $0$ 或 $1$，两支覆盖了全部可行 $x$，故由引理 4、5，最大值是 $\mathrm{cnt}+\max(p,1+f(B_{\text{low}}))$。

再化简。因 $0\le B_{\text{low}}\le 2^p-1$，有 $1\le B_{\text{low}}+1\le 2^p$，故 $f(B_{\text{low}})=\lfloor\log_2(B_{\text{low}}+1)\rfloor\le p$，从而 $1+f(B_{\text{low}})\le p+1$。

- 若 $B_{\text{low}}=2^p-1$：$B_{\text{low}}+1=2^p$，$f=p$，第二支 $=p+1>p$，最大值 $=p+1$。
- 若 $B_{\text{low}}<2^p-1$：$B_{\text{low}}+1\le 2^p-1<2^p$，故 $f\le p-1$，第二支 $\le p$，最大值 $=p$。

两种情况合起来正是 $p+[\,B_{\text{low}}=2^p-1\,]$。证毕。

**推论 6.1（位运算判据）**：$B_{\text{low}}=2^p-1\iff B$ 的第 $0\sim p-1$ 位全为 $1$。又 $B_p=1$（推论 3.1），故等价于 $B$ 的第 $0\sim p$ 位全为 $1$，即
$$\bigl(B\ \&\ (2^{p+1}-1)\bigr)=2^{p+1}-1.$$
*证明*：$B_{\text{low}}=B\bmod 2^p$ 就是 $B$ 的低 $p$ 位，它等于 $2^p-1$ 当且仅当这 $p$ 位全 $1$。与 $B_p=1$ 合并即得低 $p+1$ 位全 $1$。证毕。

### 引理 7（$A=B$ 的退化情形）

若 $A=B$，则答案为 $\operatorname{pc}(A)$。

*证明*：由引理 1，可行 $x$ 只有 $x=A$ 一个，故最大值 $=\operatorname{pc}(A)$。此时 $A\oplus B=0$，$p$ 不存在，引理 3–6 的前提 $A<B$ 不成立，必须单独处理。证毕。

### 定理（算法正确性）

程序输出
$$\begin{cases}\operatorname{pc}(A),&A=B,\\[2pt]\operatorname{pc}\bigl(A\gg(p+1)\bigr)+p+\bigl[(B\ \&\ (2^{p+1}-1))=2^{p+1}-1\bigr],&A<B,\end{cases}\qquad p=\lfloor\log_2(A\oplus B)\rfloor$$
即为原题答案。

*证明*：$A=B$ 时由引理 7。$A<B$ 时：$A\gg(p+1)=\mathrm{pre}$，故 $\operatorname{pc}(A\gg(p+1))=\mathrm{cnt}$；由推论 6.1，方括号里的判据就是 $[\,B_{\text{low}}=2^p-1\,]$。代入引理 6 即得 $\max_{x\in[A,B]}\operatorname{pc}(x)$，再由引理 1 这就是最多月饼数。证毕。

### 引理 8（复杂度与数值范围）

算法时间 $O(1)$（常数次 $64$ 位运算），空间 $O(1)$；所有中间量不超过 $2^{63}-1$，用 `unsigned long long` 无溢出。

*证明*：$B\le 2^{63}-1$ 且 $A\le B$，故 $A\oplus B<2^{63}$，$p\le62$，$p+1\le63$。于是 `1ULL<<(p+1)` 最大为 $2^{63}$，在 `unsigned long long`（$64$ 位）内合法；掩码 $2^{p+1}-1\le2^{63}-1$ 亦合法。$A\gg(p+1)$ 是普通右移。$\operatorname{pc}$ 与 $\lfloor\log_2\rfloor$ 分别用 `__builtin_popcountll` 与 `63-__builtin_clzll` 实现，均为常数时间。证毕。

> **实现坑点提醒**：$p$ 必须用 $A\oplus B$ 的**最高位**而不是最低位；$A=B$ 时 `__builtin_clzll(0)` 是未定义行为，所以必须先判等再求 $p$。另外 $B\le2^{63}-1$ 恰好卡在 `long long` 上界，用无符号类型读入更稳妥。

## 三、模式总结（按实际思考顺序）

- explore its property — 重量是互不相同的 $2$ 的幂且每种一个 ⇒ 子集和就是二进制数，个数就是 popcount，背包/贪心全部作废。
- consider easier version — 先扔掉下界 $A$，只问 $[0,B]$ 内最多几个 $1$。
- classic problem solution — "含 $k$ 个 $1$ 的最小数是 $2^k-1$" ⇒ $f(M)=\lfloor\log_2(M+1)\rfloor$，一行闭式。
- reduce to easier problem — 把下界加回来后发现 $f(B)$ 会高估（$A=B=8$ 反例），改为按"$A,B$ 最高不同位 $p$"切分区间。
- explore its property — 高于 $p$ 的位被区间强制锁死，贡献是常数 $\mathrm{cnt}$；第 $p$ 位上 $A=0,B=1$。
- discuss by category — 第 $p$ 位取 $0$（上界松、下界紧）与取 $1$（下界松、上界紧）两支分别求最优，取 max。
- classic problem solution — 取 $1$ 的那支退化回引理 2 的 $f(B_{\text{low}})$，复用简化版结论。
- reduce to easier problem — 比较两支发现只在"$B$ 低 $p+1$ 位全 $1$"时差 $1$，答案压成 $\mathrm{cnt}+p+[\cdots]$ 一个判据。
- discuss by category — $A=B$ 退化单独处理，避免 $\operatorname{clz}(0)$ 未定义。

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| $A,B$ | 总重量下界、上界，$1\le A\le B\le2^{63}-1$ | `u64`，读入 |

| $\operatorname{pc}(x)$ | $x$ 的二进制中 $1$ 的个数 = 月饼个数 | `__builtin_popcountll` |
| $p$ | $A\oplus B$ 的最高位下标（$A,B$ 最高不同位） | `int`，`63-__builtin_clzll(A^B)` |
| $\mathrm{pre}$ | $A,B$ 高于 $p$ 的公共前缀，$=A\gg(p+1)$ | `u64` |
| $\mathrm{cnt}$ | $\operatorname{pc}(\mathrm{pre})$，被强制锁定的高位 $1$ 数 | `int` |
| $B_{\text{low}}$ | $B\bmod 2^p$，$B$ 的低 $p$ 位 | 推导量 |
| $f(M)$ | $\lfloor\log_2(M+1)\rfloor$，$[0,M]$ 内最大 popcount | 引理 2 |
| `mask` | $2^{p+1}-1$，用于判"$B$ 低 $p+1$ 位全 $1$" | `u64`，`(1ULL<<(p+1))-1` |
| `ans` | 最多月饼数 | `int`，输出 |

本题不需要数组，故无 `mxn`；哨兵 `1145141919` 亦无用武之地（答案恒非负且 $\le63$）。

### 算法步骤

1. 读入 $A,B$（`unsigned long long`）。
2. 若 $A=B$，输出 $\operatorname{pc}(A)$，结束（引理 7）。
3. 令 $x=A\oplus B$，$p=63-\operatorname{clz}(x)$（$x\ne0$，合法）。
4. $\mathrm{cnt}=\operatorname{pc}(A\gg(p+1))$。
5. $\texttt{mask}=2^{p+1}-1$；判 $(B\ \&\ \texttt{mask})=\texttt{mask}$，成立记 $1$ 否则 $0$。
6. 输出 $\mathrm{cnt}+p+$ 第 5 步的判据值（引理 6、推论 6.1）。

### 复杂度

- 时间：$O(1)$（常数次 $64$ 位位运算与内建函数）。
- 空间：$O(1)$。

### 验证状态

编译通过；自造样例 `2 23 → 4`（与题面 Hint 的 $1+2+4+16$ 一致）、`1 1 → 1`、`5 5 → 2`、`1 10 → 3`、`8 9 → 2`、`9223372036854775807 9223372036854775807 → 63`、`1 9223372036854775807 → 63` 全部正确；另用"逐数枚举 popcount"与"独立数位 DP"两种暴力对拍 $85200$ 组（含 $80200$ 组小范围全穷举、$3000$ 组 $64$ 位随机大数、$2000$ 组中等范围随机）全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2431 正妹吃月饼
// 子集和 <-> 二进制数，个数 <-> popcount
// 答案 = [A,B] 内最大 popcount；按 A^B 的最高位 p 分两支
#include<bits/stdc++.h>
using namespace std;
using u64=unsigned long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	u64 A,B;
	cin>>A>>B;
	if(A==B)						// 退化：区间只有一个数
	{
		cout<<__builtin_popcountll(A)<<'\n';
		return 0;
	}
	u64 x=A^B;
	int p=63-__builtin_clzll(x);			// A,B 最高的不同位
	int cnt=__builtin_popcountll(A>>(p+1));	// 被锁死的公共高位里 1 的个数
	u64 mask=(1ULL<<(p+1))-1;
	// 第 p 位取 0 稳拿 p 个；取 1 只有在 B 低 p+1 位全 1 时才多拿 1 个
	cout<<cnt+p+((B&mask)==mask)<<'\n';
	return 0;
}
```

### 代码说明

- `A==B` 必须先判：否则 `x=0`，`__builtin_clzll(0)` 未定义。
- `p+1<=63`（因 $B\le2^{63}-1$），`1ULL<<(p+1)` 不会移出 $64$ 位；用 `u64` 而非 `i64` 是为了让 $2^{63}$ 这个中间量合法。
- `(B&mask)==mask` 是 `bool`，与 `int` 相加时自动提升为 $0/1$，正好实现引理 6 的方括号判据。
- 全程无循环、无数组，$O(1)$。
