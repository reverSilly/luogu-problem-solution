# P2820 局域网 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 台计算机（$1\le n\le100$）、$k$ 条网线，每条网线有畅通程度 $f(i,j)\in[1,1000]$（越小越通畅，$0$ 表示无网线）。要**删掉一些网线**，使得：

1. 剩下的网络**没有回路**；
2. **不改变原图节点的连通性**（原来能互达的还能互达，原来不能的也不能）；
3. 被删网线的 $\sum f$ **最大**。

输出这个最大值。注意范围里**只给了 $n$ 和 $f$ 的上界，$k$ 没有上界**——这个缺口后面会变成一个真实的设计约束。

### 第一步：把"删得最多"翻译成"留得最少"

删边权和最大，看起来要在"删哪些"上做组合优化。但所有网线的权和是个**常数**：

$$\sum_{\text{删}}f=\underbrace{\sum_{\text{全部}}f}_{\text{tot，读入时累加}}-\sum_{\text{留}}f.$$

于是"删得最多" $\iff$ "留得最少"。这一步补集转化把目标从"最大化"翻成"最小化"，而**最小化**恰好是生成树理论的主场。

### 第二步：刻画"合法的保留集"到底是什么

条件 1（无回路）+ 条件 2（连通性不变）合起来是什么意思？

- 无回路 $\Rightarrow$ 保留集是**森林**；
- 连通性不变 $\Rightarrow$ 原图每个连通块里的点，在保留集里仍然连通 $\Rightarrow$ 每块至少是一棵**生成树**。

森林的每个连通块都是树，而它又必须覆盖原连通块的全部点——所以**保留集恰好是原图的一棵生成森林**（每个连通块一棵生成树），边数恰为 $n-c$（$c$ 为原图连通块数）。不多一条（多一条就成环），不少一条（少一条就断开）。

所以题目就是：**总权和 $-$ 最小生成森林（MSF）的权和**。图连通时就是熟悉的 MST；不连通时是 MSF。Kruskal 天生处理森林——它从不强求把所有点并成一棵树。

### 第三步：撞墙——$k$ 没有上界

标准写法是"读入 $k$ 条边 $\to$ 排序 $\to$ Kruskal"。但题面没给 $k$ 的范围：如果 $k=10^7$，边数组就要 $120$ MB，排序也要好几秒。$n\le100$ 这么小，$k$ 却可以任意大，说明**大量边是冗余的**。冗余在哪？

$n\le100$ 意味着无序点对最多 $\binom{100}{2}=4950$ 个。$k$ 超出这个数，就必然有**平行边**（同一对计算机之间多条网线）或**自环**（$i=j$）。

### 第四步：平行边和自环能不能先处理掉？

**自环**：一条 $i\to i$ 的网线自己就是一个回路，条件 1 直接判它死刑，**必删**。它的权和全额计入答案。

**平行边**：$u,v$ 之间两条网线，走"去一条、回另一条"就是一个回路（多重图里的 $2$-环）。所以**至多保留一条**。那保留哪条？直觉是"留最便宜的"，但直觉要证：

> 交换论证：若某个最优保留集用了 $u,v$ 之间权为 $7$ 的边，而存在权为 $5$ 的平行边，把 $7$ 换成 $5$——连通性不变（还是连接 $u,v$），无环性不变（$u,v$ 之间的连接关系没变，任何环的结构同构），权和却变小了。与"最优"矛盾。故最优解一定用每对点之间最便宜的那条。

于是可以**在读入阶段就把边集压缩**：矩阵 `mn[u][v]` 只记每对点的最小权，`tot` 累加所有读入的权。压缩后待排序的边不超过 $4950$ 条，**内存与 $k$ 无关**，时间只有 $O(k)$ 的读入加 $O(n^2\log n)$ 的排序。墙拆掉了。

这一步还顺带把"平行边算不算回路"的口径问题解决了：无论出题人怎么想，标准 Kruskal 逐边处理时第二条平行边必然因为"两端已连通"被拒，与"先压成最小边"的结果**逐边一致**（引理 3 会证等价）。

### 第五步：Kruskal 为什么对

按权从小到大扫边，两端不在同一连通块就保留（并查集合并），否则丢弃。丢弃的边权和就是答案。

正确性有两半，都要证：

- **可行性**：结果无环（每次只在不同块之间连边），且连通性与原图一致（原图任意路径上的每条边，要么被保留，要么被拒时两端已在保留集里连通——所以路径的连通性被逐边继承）。
- **最优性**：交换论证。设 Kruskal 结果为 $F$，任取一棵最小生成森林 $T$，逐条把 $F$ 的边"换进" $T$：加入 $f_i$ 会形成唯一环，环上必有一条不在 $F$ 里的边 $e'$，且 $w(e')\ge w(f_i)$（否则 $e'$ 更早被 Kruskal 处理时就会被拒，而拒它的那些边都在 $F$ 的前缀里，会与 $T$ 无环矛盾）。换掉 $e'$ 后仍是生成森林且权和不增。归纳到底得 $F$ 本身就是最小生成森林。

### 第六步：两个实现层面的坑

**坑一：矩阵初值。** 我要用 `mn[u][v]=min(mn[u][v],c)` 维护每对点的最小权。全局 `int` 数组默认 $0$，而 $c\ge1$，于是 `c<mn[u][v]` 恒假——**所有边都被当成"已有更便宜的边"而丢弃**，最后输出 `tot`（等价于把网线全删了）。必须显式 `fill_n(&mn[0][0],mxn*mxn,inf)`。

（题面说 $f=0$ 表示"无网线"，看起来可以用 $0$ 当哨兵；但 $0$ 哨兵只能配"存在性判断"，配 `min` 更新就反了。用 `inf` 才与 `min` 语义一致。）

**坑二：答案的类型。** $k$ 无上界 $\Rightarrow$ `tot` 无上界。$k=10^7$、$f=1000$ 时 `tot`$=10^{10}$，`int` 直接溢出。`tot`、`kept`、答案全用 `i64`。（`kept` 其实很小：$\le(n-1)\times1000=99000$，但统一 $64$ 位省心。）

## 二、思维链：完整证明

**记号。** 原图 $G=(V,E)$ 是**多重图**（允许平行边与自环），$|V|=n\le100$，边权 $w_e\in[1,1000]$。$c$ 为 $G$ 的连通块数（自环不影响连通性）。$\text{tot}=\sum_{e\in E}w_e$。保留集 $S\subseteq E$ 称为**可行**，当且仅当 $(V,S)$ 无环且与 $G$ 有相同的连通块划分。$G'$ 表示"去自环、每对点只留最小权边"得到的简单图，边权记 $\mathrm{mn}[u][v]$。

---

### 引理 0（树的基本事实）

一个连通无环图（树）若有 $t$ 个顶点，则恰有 $t-1$ 条边。

*证明*：对 $t$ 归纳。$t=1$：无环 $\Rightarrow$ 无自环，边数 $0=t-1$ ✓。

设 $t\ge2$ 且结论对 $t-1$ 成立。先证**存在度为 $1$ 的顶点（叶子）**：取一条极长的简单路径 $v_0v_1\cdots v_\ell$（顶点数有限，极长路径存在；连通且 $t\ge2$ 保证至少有一条边，故 $\ell\ge1$）。若 $\deg(v_0)\ge2$，则 $v_0$ 有邻居 $x\ne v_1$：若 $x$ 在路径上（$x=v_j,j\ge2$），则 $v_0v_1\cdots v_jv_0$ 是环，矛盾；若 $x$ 不在路径上，则路径可延长，与极长矛盾。故 $\deg(v_0)=1$。

删去 $v_0$ 及其唯一边：剩下 $t-1$ 个点仍连通（任意两点间的路径若经过 $v_0$，则必须"进来又出去"，但 $v_0$ 度为 $1$ 不可能，故路径不经过 $v_0$），仍无环（子图）。由归纳假设有 $t-2$ 条边，加回 $1$ 条得 $t-1$ ✓。证毕。

### 引理 1（可行集 $=$ 生成森林）

$S\subseteq E$ 可行 $\iff$ $S$ 是 $G$ 的生成森林（即 $G$ 的每个连通块在 $S$ 中恰为一棵生成树）。此时 $|S|=n-c$。

*证明*：

**（$\Leftarrow$）** 生成森林无环 ✓；每块的生成树覆盖该块全部顶点且连通，故连通块划分与 $G$ 相同 ✓。

**（$\Rightarrow$）** 设 $S$ 可行。$(V,S)$ 无环，故其每个连通块是树。由"连通性不变"，$(V,S)$ 的每个连通块的顶点集恰为 $G$ 的某个连通块的顶点集（划分相同）。于是每块是覆盖该块全部顶点的树，即生成树。所以 $S$ 是生成森林。

边数：设各块顶点数 $t_1,\dots,t_c$，$\sum t_i=n$。由引理 0，第 $i$ 块贡献 $t_i-1$ 条边，故 $|S|=\sum(t_i-1)=n-c$。证毕。

**推论**：可行集的边数是**定值** $n-c$，所以"删边最多"不是"删的条数最多"，而是"删的权和最大"——条数由可行性锁死，自由度只在"选哪些边"。

### 引理 2（补集转化）

$$\max_{S\text{ 可行}}\sum_{e\notin S}w_e=\text{tot}-\min_{S\text{ 可行}}\sum_{e\in S}w_e=\text{tot}-\text{MSF}(G).$$

*证明*：对任意 $S\subseteq E$，$\sum_{e\notin S}w_e+\sum_{e\in S}w_e=\sum_{e\in E}w_e=\text{tot}$（每条边恰属一侧）。故 $\sum_{e\notin S}w_e=\text{tot}-\sum_{e\in S}w_e$。$\text{tot}$ 是常数，最大化左式等价于最小化 $\sum_{e\in S}w_e$；由引理 1，可行集恰为生成森林，故最小值就是最小生成森林的权和 $\text{MSF}(G)$。证毕。

---

### 引理 3（平行边与自环的压缩等价性）

设 $G'$ 为"删去所有自环、每对点 $\{u,v\}$ 只保留权最小的一条边"得到的简单图。则

(a) $G$ 与 $G'$ 的连通块划分相同；
(b) $\text{MSF}(G)=\text{MSF}(G')$；
(c) 任何可行集都不含自环，且每对点之间至多含一条边。

*证明*：

(c) 自环 $(u,u)$ 本身是长度 $1$ 的环，含它的集合有环，不可行。$u,v$ 之间两条平行边构成长度 $2$ 的环（多重图意义下：$u\xrightarrow{e_1}v\xrightarrow{e_2}u$ 是闭迹且边不重复），含它们的集合有环，不可行。故可行集在每对点之间至多一条边、无自环。

(a) 删自环不改变任何两点间的可达性（自环不提供新可达关系）。平行边中删去非最小者也不改变可达性（$u,v$ 之间仍有一条边）。故划分相同。

(b) 记 $\mathcal F,\mathcal F'$ 分别为 $G,G'$ 的可行集族。

- **$\mathcal F\to\mathcal F'$ 的映射**：由 (c)，$S\in\mathcal F$ 无自环、每对点至多一条边，故可把 $S$ 的每条边映到 $G'$ 中同点对的那条唯一边，得 $S'\subseteq E(G')$。$S'$ 与 $S$ 有相同的点对集合，故连通块划分相同（由 (a) 等于 $G$ 的划分），且无环（环结构只依赖点对序列）。所以 $S'\in\mathcal F'$。权和：$G'$ 中该点对的边是**最小权**，故 $w(S')\le w(S)$。
- **$\mathcal F'\to\mathcal F$ 的提升**：$S'\in\mathcal F'$ 的每条边在 $G$ 中都有对应边（就是被保留的那条最小权平行边），取这些边得 $S\in\mathcal F$（点对集合相同 $\Rightarrow$ 无环性与连通性相同），且 $w(S)=w(S')$。

于是 $\min_{S'\in\mathcal F'}w(S')\le\min_{S\in\mathcal F}w(S)$（第一映射把 $G$ 的最优解映成 $G'$ 的一个可行解，权和只减不增），同时 $\min_{S\in\mathcal F}w(S)\le\min_{S'\in\mathcal F'}w(S')$（提升把 $G'$ 的最优解搬回 $G$，权和相等）。两式夹逼得相等。证毕。

**推论**：可以先压缩再跑 Kruskal，答案不变；压缩后边数 $\le\binom{n}{2}=4950$，与 $k$ 无关。自环的权全额留在 tot 里、不进 MSF，故自动被"删除"。

### 引理 4（Kruskal 的输出是生成森林）

设 $F$ 为 Kruskal 在 $G'$ 上保留的边集（按权升序扫，两端不同块则保留并合并）。则 $F$ 无环，且与 $G'$ 连通块划分相同，即 $F$ 是生成森林。

*证明*：

**无环**：归纳。初始 $F=\varnothing$ 无环。每次加入边 $(u,v)$ 时，$u,v$ 属于当前 $F$ 的**不同**连通块（并查集判定），故加入后不可能产生环（环要求新边两端已在同一块）。归纳得 $F$ 始终无环。

**连通性保持**：任取 $G'$ 中一条路径 $u=x_0,x_1,\dots,x_\ell=v$。对路径上每条边 $e=(x_{i-1},x_i)$：Kruskal 处理它时，要么保留（此后两端在 $F$ 中连通，且连通性只增不减），要么拒绝——拒绝的**唯一原因**是当时两端已在 $F$ 中连通。两种情况都得到"处理完 $e$ 之后 $x_{i-1},x_i$ 在 $F$ 中连通"。所有边处理完后，路径上相邻点两两 $F$-连通，由连通性的传递性得 $u,v$ $F$-连通。故 $G'$ 中连通的点在 $F$ 中也连通；反向包含显然（$F\subseteq E(G')$）。划分相同。

结合无环与引理 1，$F$ 是生成森林。证毕。

### 引理 5（Kruskal 的最优性：交换论证）

引理 4 的 $F$ 是 $G'$ 的**最小**生成森林。

*证明*：设 $F=\{f_1,\dots,f_r\}$ 按 Kruskal 保留的先后排序（故 $w(f_1)\le\cdots\le w(f_r)$，$r=n-c$）。任取一棵最小生成森林 $T$。我们归纳构造一列最小生成森林 $T_0,T_1,\dots,T_r$，使 $T_i\supseteq\{f_1,\dots,f_i\}$。

**基础**：$T_0=T$ ✓。

**归纳步**：设 $T_{i-1}$ 是最小生成森林且含 $\{f_1,\dots,f_{i-1}\}$。若 $f_i\in T_{i-1}$，取 $T_i=T_{i-1}$ 即可。否则：

1. **$f_i$ 的两端在 $T_{i-1}$ 中连通**：$T_{i-1}$ 是生成森林，其连通块划分与 $G'$ 相同；$f_i\in E(G')$ 的两端当然在同一块。故 $T_{i-1}+f_i$ 恰含**一个**环 $C$（生成森林加一条块内边产生唯一环：块内两点间路径唯一，加新边成环；任何环必含新边，否则 $T_{i-1}$ 有环）。
2. **$C$ 上存在 $e'\in T_{i-1}\setminus\{f_1,\dots,f_i\}$**：因为 $\{f_1,\dots,f_i\}$ 无环（Kruskal 不变量），而 $C$ 是环，故 $C\not\subseteq\{f_1,\dots,f_i\}$；$C$ 的边除 $f_i$ 外都来自 $T_{i-1}$，所以存在 $e'\in C\cap T_{i-1}$ 且 $e'\notin\{f_1,\dots,f_i\}$。
3. **$w(e')\ge w(f_i)$**：反证。设 $w(e')<w(f_i)$。$e'\notin F$（因 $e'\notin\{f_1,\dots,f_i\}$ 且 $e'$ 的权更小，若被保留必排在 $f_i$ 之前，矛盾），故 Kruskal 处理 $e'$ 时**拒绝**了它，即当时 $e'$ 的两端已被"此前保留的边"连通。此前保留的边权都 $\le w(e')<w(f_i)$，故都属于 $\{f_1,\dots,f_{i-1}\}\subseteq T_{i-1}$。于是 $e'$ 的两端在 $T_{i-1}$ 中经由一条**不含 $e'$** 的路径连通，该路径加 $e'$ 构成 $T_{i-1}$ 中的环，与 $T_{i-1}$ 无环矛盾。故 $w(e')\ge w(f_i)$。
4. **交换**：令 $T_i=T_{i-1}+f_i-e'$。删去环 $C$ 上一条边 $e'$ 后，$C$ 上其余点仍通过 $C$ 的剩余部分连通，故连通块划分不变；边数不变（$n-c$）；无环（唯一环 $C$ 被打破，且不含 $e'$ 的环在 $T_{i-1}$ 中本就不存在）。所以 $T_i$ 是生成森林，且 $w(T_i)=w(T_{i-1})+w(f_i)-w(e')\le w(T_{i-1})$。由 $T_{i-1}$ 已是最小，得 $w(T_i)=w(T_{i-1})$，$T_i$ 也是最小生成森林，且含 $\{f_1,\dots,f_i\}$ ✓。

归纳到 $i=r$：$T_r$ 是最小生成森林且 $F\subseteq T_r$。但 $|F|=r=n-c=|T_r|$（引理 1），故 $F=T_r$，即 $F$ 是最小生成森林。证毕。

### 引理 6（并查集正确性）

`f[]` 初值 `iota`（每点自成一树）；`getrt` 带路径压缩；合并写作 `f[a]=b`（$a,b$ 为两根）。则任意时刻"`getrt(u)==getrt(v)`" $\iff$ "$u,v$ 在已保留边集 $F$ 中连通"。

*证明*：不变量：`f[]` 构成一片森林，其每棵树的顶点集恰为 $F$ 的一个连通块，根是该块的代表。

初始 $F=\varnothing$，每点一块，`f[x]=x` ✓。

**合并**：处理边 $(u,v)$ 时取 $a=\texttt{getrt}(u),b=\texttt{getrt}(v)$。若 $a=b$，两点已同块，不加入边，划分不变 ✓。若 $a\ne b$，加入边后两块合并为一块；令 `f[a]=b` 把 $a$ 所在树挂到 $b$ 所在树的根下，两棵树合成一棵，顶点集恰为并块 ✓。

**路径压缩**：`getrt(x)` 把 $x$ 到根路径上的点直接挂到根。这不改变任何点所属的树（根不变），故不变量保持，且后续查询仍返回同一代表 ✓。

由不变量，"同根" $\iff$ "同树" $\iff$ "$F$ 中连通"。证毕。

### 引理 7（哨兵、溢出与复杂度）

(a) `mn` 必须以 `inf` 初始化；用全局默认 $0$ 会丢失所有边。
(b) `tot`、`kept`、答案用 `i64` 必要且充分。
(c) 时间 $O(k+n^2\log n)$，空间 $O(n^2)$，均与 $k$ 的大小无关（除读入的线性项）。

*证明*：

(a) 更新条件是 `c<mn[u][v]`，$c\ge1$。若初值 $0$，则 $c<0$ 恒假，矩阵永不更新，所有点对都被视为"无边"，$F=\varnothing$、`kept`$=0$，输出 `tot`——等价于宣称"所有网线都能删"，显然错（例如三角形 $1,2,3$ 会输出 $6$ 而非 $3$）。取 `inf`$=1145141919>1000\ge c$，首条边必满足 $c<\text{inf}$，之后 `min` 语义正确。

(b) $\text{tot}=\sum_{e}w_e\le 1000k$，而 $k$ **无上界**，故 `tot` 可超 $2^{31}-1$（$k\ge2.15\times10^6$ 即溢出），必须 $64$ 位。$\text{kept}\le(n-1)\cdot1000\le99000$（引理 1：至多 $n-c\le n-1$ 条边），`int` 够，但答案 $\text{tot}-\text{kept}$ 与 `tot` 同量级，故统一 `i64`。又 $\text{kept}\le\text{tot}$（$F$ 的边是原边集的子集，压缩后权只减不增，引理 3），故答案 $\ge0$，不会输出负数。

(c) 读入 $k$ 条边、每条常数次矩阵操作：$O(k)$。枚举点对建边表：$O(n^2)$，边数 $\le\binom n2$。排序 $O(n^2\log n^2)=O(n^2\log n)$。Kruskal：$O(n^2\alpha(n))$ 次并查集操作（路径压缩，近似常数）。合计 $O(k+n^2\log n)$。空间：矩阵 $n^2$ 个 `int`（$\approx44$ KB）、边表 $\le11025$ 个 `edge`、并查集 $O(n)$，即 $O(n^2)$，**与 $k$ 无关**。代入 $n=100$：排序至多 $4950$ 条边，瞬间完成。证毕。

### 定理

程序输出"无回路、连通性不变"前提下被删网线权和的最大值。

*证明*：引理 1 把可行性刻画为生成森林；引理 2 把目标转化为 $\text{tot}-\text{MSF}$；引理 3 保证"去自环 + 平行边取最小"的压缩不改变 MSF，从而不改变答案；引理 4、5 保证 Kruskal 输出的正是最小生成森林；引理 6 保证并查集判定连通性的正确性；引理 7 保证哨兵、类型与复杂度。故 `tot-kept` 即答案。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "无回路 + 连通性不变"恰好刻画生成森林：边数被锁死为 $n-c$，自由度只在选边。
2. **reduce to easier problem** — 补集转化：删边权和最大 $=$ 总权和 $-$ 保留边权和最小，最大化翻成最小化。
3. **classic problem solution** — 最小生成森林（Kruskal + 并查集）；图不连通时是森林不是树，模板不能强求 $n-1$ 条边。
4. **consider easier version** — 发现 $k$ 无上界而 $n\le100$：先问"哪些边一定冗余"，把规模压到 $\binom n2$。
5. **explore its property** — 自环是 $1$-环必删；平行边是 $2$-环至多留一条，且留最便宜的（交换论证）。
6. **classic problem solution** — Kruskal 最优性的交换论证：加入 $f_i$ 成唯一环，环上必有不在 $F$ 的 $e'$ 且 $w(e')\ge w(f_i)$。
7. **discuss by category** — `mn` 矩阵必须 `fill_n(...,inf)`（默认 $0$ 配 `min` 更新会丢光所有边）；`tot` 用 `i64`（$k$ 无上界）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $n,k$ | 计算机数、网线数 | `int` | 读入；$n\le100$，**$k$ 无上界** |
| `tot` | 所有网线权和 $\sum f$ | `i64` | 全局默认 $0$，读入时累加；**$k$ 无上界故必须 $64$ 位** |
| `kept` | 保留边（MSF）权和 | `i64` | 全局默认 $0$；$\le(n-1)\times1000$ |
| `mn[u][v]` | 点对 $\{u,v\}$ 间最小权（压缩后的简单图） | `int[mxn][mxn]` | **`fill_n(...,inf)`**；`inf` 表示无网线；自环不写入 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 远大于权上界 $1000$，配 `min` 更新 |
| `E[i]` | 压缩后的第 $i$ 条边 $\{u,v,w\}$ | `struct edge[mxn*mxn]` | 至多 $\binom n2=4950$ 条；按 `w` 升序排序 |
| `cnt` | `E` 中边数 | `int` | 全局默认 $0$ |
| `f[x]` | 并查集父亲 | `int[mxn]` | `iota(f,f+n,0)`；`getrt` 路径压缩 |
| 输出 | 被删网线权和最大值 | `i64` | `tot-kept` |

### 算法步骤

1. I/O 加速三行；`fill_n(&mn[0][0],mxn*mxn,inf)`。
2. 读 `n,k`；逐条读 `u,v,c`，`--u;--v`；`tot+=c`；若 `u!=v&&c<mn[u][v]` 则 `mn[u][v]=mn[v][u]=c`（自环只计入 `tot`，必删）。
3. 枚举 $u<v$，把 `mn[u][v]<inf` 的点对装入 `E[cnt++]`。
4. 按权升序 `sort(E,E+cnt,...)`；`iota(f,f+n,0)`。
5. 顺序扫 `E`：`a=getrt(u),b=getrt(v)`；若 `a==b` 跳过（这条边被删）；否则 `f[a]=b;kept+=w`。
6. 输出 `tot-kept`。

### 复杂度

- 时间：$O(k+n^2\log n)$；$n\le100$ 时排序规模 $\le4950$，读入是唯一与 $k$ 成正比的项。
- 空间：$O(n^2)\approx$ 几十 KB，**与 $k$ 无关**。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$6$ 组手造数据（三角形、平行边、不连通、自环、四边形带对角线、等权平行边）与手算逐一吻合；另用 $300$ 组随机多重图（$n\le8$，刻意含自环与平行边）与**独立实现的 Prim**（直接在多重图上跑，不经压缩）交叉验证，$0$ 处不一致；$k=495000$ 的极限数据（$n=100$ 完全图、每对点 $100$ 条平行边）也正确且瞬间完成，验证"内存与 $k$ 无关"。本题是 Kruskal 模板 + 一次等价压缩，证明已闭合，不建对拍附录。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2820 局域网
// 删边权和最大 = tot - 保留边权和最小；"无环+连通性不变" ⟺ 保留集是生成森林 ⇒ Kruskal
// k 无上界而 n<=100 ⇒ 自环必删、平行边只留最便宜的一条，先把边集压到 <=4950 条
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105},inf{1145141919};

int n,k,cnt,mn[mxn][mxn],f[mxn];
i64 tot,kept;
struct edge{int u,v,w;}E[mxn*mxn];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	fill_n(&mn[0][0],mxn*mxn,inf);	// 默认 0 配 min 更新会丢光所有边！
	cin>>n>>k;
	for(int i=0,u,v,c;i<k;++i)
	{
		cin>>u>>v>>c;--u;--v;
		tot+=c;
		if(u!=v&&c<mn[u][v])
			mn[u][v]=mn[v][u]=c;	// 自环不进矩阵：必删，权已计入 tot
	}
	for(int u=0;u<n;++u)
		for(int v=u+1;v<n;++v)
			if(mn[u][v]<inf)
				E[cnt++]={u,v,mn[u][v]};
	sort(E,E+cnt,[](edge a,edge b){return a.w<b.w;});
	iota(f,f+n,0);
	for(int i=0;i<cnt;++i)
	{
		int a=getrt(E[i].u),b=getrt(E[i].v);
		if(a==b)
			continue;		// 两端已连通 ⇒ 这条边成环，被删除
		f[a]=b;
		kept+=E[i].w;
	}
	cout<<tot-kept<<'\n';	// 不连通时是生成森林，Kruskal 天然支持
	return 0;
}
```

### 代码说明

- **没有 `ans` 变量**：答案就是 `tot-kept`。被拒的边不需要逐条累加——补集转化让它们自动落在差值里，少一处出错机会。
- `mn` 矩阵承担三件事：平行边取最小、去重、$O(1)$ 判"这对点有没有边"。它把"$k$ 无上界"这个题面缺口彻底堵死：内存只与 $n^2$ 有关。
- `fill_n(&mn[0][0],mxn*mxn,inf)` 是**必须**的一行：全局 `int` 默认 $0$，而更新条件是 `c<mn[u][v]`（$c\ge1$），初值 $0$ 会让所有边被静默丢弃，输出 `tot`（相当于把网线全删）。
- 自环 `u==v` 只累加 `tot`、不写矩阵：它是 $1$-环，任何可行集都不能含它，故全额计入被删权和。
- `if(a==b)continue;` 就是"这条边被删"的判定点；`f[a]=b` 是根挂根，配合路径压缩即标准并查集。
- 不连通的数据无需特判：Kruskal 从不要求凑满 $n-1$ 条边，扫完所有边自然得到生成森林（引理 4）。
- `tot`/`kept` 用 `i64`：$k$ 无上界，$1000k$ 可超 `int`；`kept` 本身很小但统一 $64$ 位省心。
- `E` 开到 `mxn*mxn`$=11025$，远大于实际上界 $\binom{100}{2}=4950$，符合 $+5$ 松弛习惯。
