# P2695 骑士的工作 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 恶龙有 $n$ 个头（$n\le2\times10^4$），第 $i$ 个大小 $a_i\in[1,10^5]$。来了 $m$ 位骑士（$m\le2\times10^4$），第 $j$ 位能砍掉**至多一个**大小不超过 $z_j$ 的头，报酬 $z_j$ 金币（$z_j\in[1,10^5]$）。每个头必须被砍掉，每位骑士至多砍一个头。求砍掉所有头的**最小总报酬**；若砍不完，输出 `you died!`。题面无样例，下面的例子都是我手算的。

**第一步：把它写成匹配问题。** 一个方案就是给每个头 $i$ 指派一位**互不相同**的骑士 $\varphi(i)$，满足 $z_{\varphi(i)}\ge a_i$（砍得动），总花费 $\sum_i z_{\varphi(i)}$。要最小化这个和；若不存在这样的单射，就 `you died!`。这本质是**带权二分匹配**，但 $n,m\le2\times10^4$，跑最小费用流太重，而且结构特殊，应该有更简单的贪心。

**第二步：贪心的直觉——便宜的骑士留给小的头。** 大头难砍（只有大 $z$ 的骑士砍得动），小头好砍（几乎所有骑士都行）。所以应该**让便宜的骑士去砍小头**，把贵的大骑士留给大头。反过来想：如果先处理**最小的头**，给它派**最便宜的、砍得动它的**骑士，会不会最优？

**第三步：发现"先小后大"能让弱骑士被永久淘汰。** 把 heads 升序 $a_1\le\dots\le a_n$、knights 升序 $z_1\le\dots\le z_m$。处理最小的头 $a_1$ 时，所有 $z<a_1$ 的骑士不仅砍不动 $a_1$，也砍不动后面**所有更大的头**——它们从此再也用不上，可以**永久丢弃**。于是用一个指针 $j$ 扫骑士：跳过 $z_j<a_i$ 的（丢弃），第一个 $z_j\ge a_i$ 的就是"最便宜的可用骑士"，派给 $a_i$，$j$ 前进。这就是**双指针**，$O(n+m)$。

**第四步：为什么"最小头配最便宜可用骑士"一定最优？交换论证。** 设 $a_1$ 最小，$k$ 是最便宜且 $z_k\ge a_1$ 的骑士。任取一个最优方案：若它没把 $k$ 给 $a_1$，而是给了 $k'$（$z_{k'}\ge z_k$），把 $k$ 给了某个头 $a_j$（$j\ge2$，故 $a_j\ge a_1$）或干脆没用 $k$。我们**交换**：让 $a_1$ 用 $k$（$z_k\ge a_1$ ✓），让 $a_j$ 用 $k'$（$z_{k'}\ge z_k\ge a_j$ ✓，因为 $k$ 原本砍得动 $a_j$）。用的骑士集合不变 ⇒ 花费不变，仍最优。若 $k$ 原本闲置，直接把 $a_1$ 的 $k'$ 换成 $k$，花费不增（$z_k\le z_{k'}$），仍最优。**所以总存在一个最优方案把 $k$ 给 $a_1$**——贪心的第一步不会错。去掉 $a_1$ 和 $k$，剩下的子问题同理递归，贪心全程最优。

**第五步：无解怎么判？** 双指针在处理某个头 $a_i$ 时若 $j$ 已到 $m$（没有可用骑士了），说明砍不完。可以证明：**贪心失败 $\iff$ 原问题无解**（第四步的交换论证还保证：若原问题有解，则把最便宜可用骑士给最小头后，剩余子问题仍有解，归纳得贪心必成功）。所以一旦失败就输出 `you died!`，不必另做可行性判定。

**几个边界：** $m<n$ 时骑士不够，指针必然提前耗尽 ⇒ `you died!`；某个头比所有骑士都大（$a_i>\max z$）⇒ 指针跳过全部骑士 ⇒ `you died!`；花费上界 $n\cdot\max z=2\times10^4\times10^5=2\times10^9$，逼近 `int` 上限，用 `long long` 稳妥。

**手造数据核对：**

| 输入 | 手算 | 程序 |
|---|---|---|
| $n=2,m=3$，$a=[5,1]$，$z=[1,5,5]$ | 头 $1\to z1$、头 $5\to z5$，$1+5=6$ | $6$ |
| $n=1,m=2$，$a=[5]$，$z=[3,4]$ | 无人砍得动 $5$ | `you died!` |
| $n=2,m=1$，$a=[1,1]$，$z=[1]$ | 骑士不够 | `you died!` |
| $n=2,m=3$，$a=[2,2]$，$z=[2,3,5]$ | $2+3=5$（$5$ 闲置） | $5$ |

第一组打"便宜骑士配小头"：排序后 $a=[1,5]$，$1$ 配 $z1$、$5$ 配 $z5$，而不是 $5$ 配 $z5$、$1$ 配 $z5$（那样要 $10$）。第四组打"弱骑士被丢弃"：第二个头 $2$ 时 $z=2$ 已用，$z=3$ 是下一个可用，$z=5$ 太贵闲置。全部吻合。

## 二、思维链：完整证明

**记号。** 头升序 $a_1\le\dots\le a_n$，骑士升序 $z_1\le\dots\le z_m$。**可行方案** $=$ 单射 $\varphi:\{1..n\}\to\{1..m\}$ 满足 $z_{\varphi(i)}\ge a_i$；花费 $\mathrm{cost}(\varphi)=\sum_i z_{\varphi(i)}$。最优花费 $=\min_{\varphi\text{ 可行}}\mathrm{cost}(\varphi)$，无可行方案则无解。贪心：对 $i=1..n$，把**最便宜的未用且 $z\ge a_i$** 的骑士派给 $a_i$。

---

### 引理 1（贪心选择保持可行性与最优性）

设 $a_1$ 为最小头，$k$ 为最便宜且 $z_k\ge a_1$ 的骑士。若原实例可行，则：
(a) 存在可行方案把 $k$ 派给 $a_1$；
(b) 存在**最优**方案把 $k$ 派给 $a_1$；
(c) 去掉 $a_1$ 与 $k$ 后的剩余实例仍可行。

*证明*：任取可行方案 $\varphi$。若 $\varphi(a_1)=k$，(a) 已成立。否则 $\varphi(a_1)=k'$，$z_{k'}\ge a_1$，由 $k$ 的最便宜性 $z_{k'}\ge z_k$。分两种情形：

- **$k$ 在 $\varphi$ 中闲置**：把 $a_1$ 改派 $k$。$z_k\ge a_1$ ✓，仍可行，得 (a)。若 $\varphi$ 最优，花费变化 $z_k-z_{k'}\le0$；若 $<0$ 与最优矛盾，故 $=0$，新方案也最优且用 $k$，得 (b)。（若 $\varphi$ 非最优，改取最优 $\varphi^\*$ 重复此论证。）
- **$k$ 被派给某头 $a_j$（$j\ge2$）**：则 $a_j\ge a_1$（$a_1$ 最小）且 $z_k\ge a_j$。**交换**：$a_1\to k$（$z_k\ge a_1$ ✓），$a_j\to k'$（$z_{k'}\ge z_k\ge a_j$ ✓）。其余头不变。用的骑士集合不变 ⇒ 花费不变，故若 $\varphi$ 最优则新方案也最优，得 (a)(b)。

(c)：由 (a) 存在用 $k$ 砍 $a_1$ 的可行方案，删去 $a_1$ 与 $k$，剩下的指派仍是剩余实例的可行方案。证毕。

**注**：交换合法的关键是 $z_{k'}\ge z_k\ge a_j$——$k'$ 比 $k$ 贵（更强），$k$ 原本砍得动 $a_j$，所以 $k'$ 更砍得动。这正是"便宜骑士配小头不会饿死大头"的严格版。

---

### 引理 2（双指针恰好实现贪心）

升序排序后，指针 $j$ 从 $0$ 起；对每个 $a_i$：`while(j<m && z[j]<a[i]) ++j;` 若 `j==m` 失败，否则用 $z_j$、`++j`。则每次派给 $a_i$ 的恰是"最便宜的未用且 $z\ge a_i$"的骑士。

*证明*：归纳不变量：处理 $a_i$ 前，下标 $<j$ 的骑士要么**已用**（派给了 $a_1..a_{i-1}$），要么**已丢弃**（在某个 $a_{i'}\le a_i$ 处因 $z<a_{i'}$ 被跳过）。已丢弃者 $z<a_{i'}\le a_i$，故对当前及以后所有头都太弱（引理 4）。下标 $\ge j$ 的骑士未用且升序。`while` 跳过 $z_j<a_i$（这些对 $a_i$ 太弱，丢弃安全），停在第一个 $z_j\ge a_i$——它正是未用骑士中 $z$ 最小且 $\ge a_i$ 者，即最便宜可用骑士。派给它后 `++j`，不变量保持。证毕。

---

### 引理 3（贪心成功 $\iff$ 可行，且成功时最优）

对 $n$ 归纳。$n=0$ 平凡（花费 $0$，可行）。设原实例可行：由引理 1(c)，贪心第一步（$k$ 配 $a_1$）后剩余实例可行；由归纳假设贪心在剩余实例上成功且最优，故整体成功。反之贪心成功则产出一个可行方案。最优性：引理 1(b) 保证存在用贪心第一步的最优方案，归纳假设剩余最优，拼接即整体最优。

**推论（无解判定）**：贪心失败 $\Rightarrow$ 不可行（逆否：可行 $\Rightarrow$ 成功）。故双指针一旦 `j==m` 即可断言 `you died!`，无需另判。证毕。

---

### 引理 4（丢弃弱骑士安全）

若 $z<a_i$，则该骑士砍不动 $a_i,a_{i+1},\dots,a_n$（全部 $\ge a_i>z$），在任何可行方案中都不会被派给这些头；又因头已升序处理，它也不会被派给已处理的头。故永久丢弃不影响可行性与最优性。

*证明*：砍得动头 $a$ 要求 $z\ge a$。对 $j\ge i$，$a_j\ge a_i>z$，故 $z<a_j$，砍不动。已处理的头 $a_1..a_{i-1}$ 在贪心中已被指派，不会回头用新骑士。所以该骑士在剩余问题里完全无用，丢弃安全。证毕。

---

### 定理（正确性与复杂度）

程序输出最小总报酬，或当且仅当无可行方案时输出 `you died!`；时间 $O((n+m)\log(n+m))$，空间 $O(n+m)$。

*证明*：引理 2 保证双指针实现"最小头配最便宜可用骑士"的贪心；引理 1、3 保证该贪心成功当且仅当可行、且成功时花费最优；引理 4 保证丢弃弱骑士不丢解。复杂度：两次排序 $O(n\log n+m\log m)$，双指针扫描 $O(n+m)$（$j$ 单调前进至多 $m$ 步，$i$ 至多 $n$ 步），合计 $O((n+m)\log(n+m))$；两个数组 $O(n+m)$。花费上界 $2\times10^9$ 用 `i64` 安全。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 方案 $=$ 头到骑士的单射，$z\ge a$ 才砍得动，目标 $\min\sum z$；是带权匹配但结构特殊。
- **consider easier version** — 先想"便宜骑士配小头"的贪心直觉，再问"先小后大"还是"先大后小"。
- **explore its property** — 先处理最小头时，$z<a_i$ 的骑士对**所有更大头**都太弱 ⇒ 可永久丢弃，双指针成立。
- **classic problem solution** — 交换论证：最便宜可用骑士配最小头必属某最优解（$z_{k'}\ge z_k\ge a_j$ 保证交换合法），归纳得全程最优。
- **reduce to easier problem** — 无解判定归约为贪心失败：可行 $\Rightarrow$ 贪心成功（引理 1c 归纳），故 `j==m` 即 `you died!`。
- **discuss by category** — $m<n$ / 头大于所有骑士 / 花费逼近 `int` 上限，逐类核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,m` | 头数 / 骑士数，$\le2\times10^4$ | `int`，读入 | 两个规模 |
| `a[i]` | 第 $i$ 个头大小，升序排序 | `int[mxn]` | "a = 头" |
| `z[j]` | 第 $j$ 位骑士能力=报酬，升序排序 | `int[mxn]` | "z = 骑士" |
| `mxn` | $20000+5=20005$ | `constexpr int` | +5 松弛 |
| `j` | 骑士指针：最便宜未用可用骑士的下标 | `int`，初值 $0$ | 单调前进，跳过弱骑士 |
| `ans` | 已派骑士的报酬和 | `i64`，初值 $0$ | 上界 $2\times10^9$，用 64 位 |

### 算法步骤

1. I/O 加速三行；读 `n,m`、`a[0..n-1]`、`z[0..m-1]`。
2. `sort(a,a+n)`、`sort(z,z+m)`（均升序）。
3. `j=0, ans=0`；对 `i=0..n-1`：`while(j<m && z[j]<a[i]) ++j;`（丢弃弱骑士）；若 `j==m` 输出 `you died!` 并结束；否则 `ans+=z[j]; ++j;`。
4. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O((n+m)\log(n+m))$，排序主导；双指针 $O(n+m)$。
- 空间：$O(n+m)$，两个 `int[20005]`。
- 验证状态：`g++ -std=c++20 -O2 -Wall -Wextra` 编译通过；题面无样例，手造 $4$ 组（正常 / 头过大 / 骑士不足 / 弱骑士丢弃）与手算逐一吻合；交换论证（引理 1）与归纳（引理 3）闭合最优性与无解判定。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2695 骑士的工作
// 思路：头与骑士都升序。先处理最小头，z<a_i 的骑士对所有更大头都太弱⇒永久丢弃。
//       双指针：每个头配最便宜可用骑士（交换论证证最优），j==m 即无解。
//       花费上界 n*maxz=2e9 逼近 int 上限，用 i64。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{20005};

int n,m,a[mxn],z[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0;i<m;++i)
		cin>>z[i];
	sort(a,a+n);
	sort(z,z+m);
	i64 ans=0;
	int j=0;
	for(int i=0;i<n;++i)
	{
		while(j<m&&z[j]<a[i])	// 弱骑士对当前及以后所有头都无用，丢弃
			++j;
		if(j==m)
		{
			cout<<"you died!\n";
			return 0;
		}
		ans+=z[j];	// 最便宜可用骑士配当前最小头
		++j;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **双升序 + 双指针**：头升序保证"被丢弃的弱骑士对后续头仍太弱"，指针 $j$ 单调前进、绝不回头，$O(n+m)$。
- **`while(z[j]<a[i]) ++j`**：跳过砍不动当前头的骑士。它们 $z<a_i\le a_{i+1}\le\dots$，永远用不上，丢弃安全（引理 4）。
- **`j==m` 即无解**：由引理 3，可行 $\Rightarrow$ 贪心成功，故失败必无解，直接 `you died!`，无需另判 $m<n$ 或 $\max a>\max z$（都被指针耗尽覆盖）。
- **`i64 ans`**：$n\cdot\max z=2\times10^9$ 逼近 `int` 上限 $2.147\times10^9$，用 64 位杜绝溢出。
- **0-based**：读入即 $0..n-1$，排序、指针、输出均 0-based，无需转换。
- `mxn{20005}` 是 $2\times10^4+5$ 松弛；两个数组约 $160$ KB。
