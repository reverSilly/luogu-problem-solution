# P2370 yyy2015c01 的 U 盘 — 题解

## 一、解题过程：人类思考叙事

**先把题意翻译成一句人话。** 有 $n$ 个文件，第 $i$ 个大小 $W_i$、价值 $V_i$。我们要买一个大小为 $L$ 的接口（只有大小 $\le L$ 的文件才传得进去），再从这 $n$ 个文件里挑一部分放进容量为 $S$ 的 U 盘（被挑文件的大小之和 $\le S$），要求被挑文件价值之和 $\ge p$。求最小的 $L$；怎么挑都达不到 $p$ 就输出 `No Solution!`。

约束：$n,W_i,S \le 10^3$，$V_i \le 10^6$，$p \le 10^9$。注意 $V_i$ 最大 $10^6$、$n$ 最大 $10^3$，所以"价值总和"最大恰好是 $10^9$，处于 `int` 的边界（$2^{31}-1\approx 2.147\times10^9$），用 `int` 存是够的，但这提醒我们 $p$ 也可以取到 $10^9$，判断要严格用 `>=`。

**第一步：这是个"最小化所选元素的最大值"的结构。** 目标是 $\min L$，而 $L$ 只通过"哪些文件被允许"影响可行性。于是很自然地把问题拆成两半：

1. 给定 $L$，能不能做到价值 $\ge p$？
2. 在所有可行的 $L$ 里找最小的那个。

**第二步：给定 $L$ 之后是什么问题？** 允许的文件集合确定了：$\{i : W_i \le L\}$。要在其中挑一个子集，使"总大小 $\le S$"且"总价值尽量大"。这就是最经典的 **0/1 背包**：把大小看成重量、价值看成价值、容量就是 $S$，求容量 $S$ 内的最大价值，再看它是否 $\ge p$。$S \le 10^3$，一次背包 $O(nS) = 10^6$。

**第三步：可行的 $L$ 长什么样？** 直觉上"接口越大越好用"：$L$ 变大只会让**更多**文件被允许，原本的合法方案仍然合法。所以可行的 $L$ 一定是"从某个阈值往后全都可行"的形状——一段后缀。这种单调性立刻让人想到**二分答案**：把 $W_i$ 排序去重，在文件大小上二分，每次 $O(nS)$ 判一次，总 $O(nS\log n) \approx 10^7$，完全能过。

**第四步：先确认二分是合法的（这一步很容易被跳过）。** 二分要求答案落在候选集合里。答案会不会是一个"不是任何文件大小"的数？不会：若某个 $L$ 可行，取那个最优子集 $T$，把接口缩小到 $L'=\max_{i\in T}W_i$ 仍然可行（$T$ 里所有文件都不超过 $L'$），而 $L'$ 就是一个文件大小。所以最小可行 $L$ 一定等于某个 $W_i$。二分在排序后的 $W$ 上做是有依据的。

**第五步：能不能不二分？** 二分的问题是"每次都要把背包从头做一遍"，而相邻两次判定用的文件集合几乎是包含关系。观察背包的一条基本性质：**0/1 背包的最终结果只取决于被处理的物品多重集，与处理顺序无关**（每个物品要么选要么不选，选择是集合意义下的）。既然如此，就按 $W$ 从小到大**逐个把文件塞进背包**：塞完所有大小 $\le L$ 的文件时，`dp` 就是"接口大小为 $L$"时的背包。于是只要一边加一边检查 `dp[S] >= p`，第一个成立的位置就是答案；每个文件只被加入一次，总复杂度 $O(nS)$，比二分少一个 $\log$。

这个"加一个查一次"的写法在边界上要想清楚：同一大小的文件可能有好几个，检查发生在"加到一半"时会不会错答成更小的 $L$？不会（后面会严格证明）：加到一半就达标，说明用"大小 $\le$ 当前值"的文件已经够了，答案不可能更大；而所有更小的候选值在前面都已经失败过，答案也不可能更小。

**手造一个小例子走一遍**（题面没有给出样例数据，这里自己造一组）：

```
3 5 4
1 2
2 3
3 4
```
排序后仍是 $(1,2),(2,3),(3,4)$，$S=4$，$p=5$。

- 加入 $(1,2)$：`dp` 最大是 2，$2<5$，失败（说明 $L=1$ 不行）。
- 加入 $(2,3)$：能选 $(1,2)+(2,3)$，总大小 $3\le4$，价值 $5\ge5$，成功 ⇒ 答案 $L=2$。

再手造一组无解的：

```
2 10 3
2 3
2 4
```
无论怎么挑都只有 $4<10$（容量 $3$ 只放得下一个），输出 `No Solution!`。

**几个实现上的坑：**

- **坑一：0/1 背包的容量维必须倒序枚举。** 正序枚举会让同一个文件被重复使用（变成完全背包），答案会偏大。后面引理里会说明倒序为什么恰好对应"每个文件至多用一次"。
- **坑二：`dp` 初值就是 0，不需要 INF。** `dp[j]` 的语义是"容量 $j$ 以内能取到的最大价值"，空集（价值 0）永远合法，所以全局 `int` 数组默认的 0 恰好是对的初值。这和"最短路求最小"那类题要 `fill` 成 INF 是完全相反的情形，别条件反射地 memset。
- **坑三：`No Solution!` 的判定不要用 `ans = 0` 当哨兵**，因为 $W_i\ge1$ 时 0 虽然不会与合法答案冲突，但语义不清；用一个明显不可能的哨兵（$1145141919$）更稳妥。
- **坑四：比较用 `>= p`**，题面说的是"不小于 $p$"。

## 二、思维链：完整证明

以下把"接口大小为 $L$"的可行性记作 $\mathrm{ok}(L)$，把大小 $\le L$ 的文件集合记作 $A(L)=\{i: W_i\le L\}$。

**引理 1（可行性的背包刻画）**：$\mathrm{ok}(L)$ 成立，当且仅当
$$\max\Big\{\textstyle\sum_{i\in T}V_i \;:\; T\subseteq A(L),\ \sum_{i\in T}W_i\le S\Big\}\ \ge\ p .$$

*证明*：
（$\Rightarrow$）若存在合法方案，取它挑出的文件集合 $T$。由"接口为 $L$"知每个 $i\in T$ 满足 $W_i\le L$，即 $T\subseteq A(L)$；由 U 盘容量知 $\sum_{i\in T}W_i\le S$。所以 $T$ 是右式取 max 的那个族里的一个元素，故右式 $\ge\sum_{i\in T}V_i\ge p$。
（$\Leftarrow$）若右式 $=M\ge p$，由于 $A(L)$ 是有限集，其子集族有限，max 一定被某个 $T^*$ 取到（不是上确界而是真最大值）。这个 $T^*$ 满足 $\subseteq A(L)$（所有文件都传得进去）与总大小 $\le S$，价值 $M\ge p$，于是它就是一个合法方案，$\mathrm{ok}(L)$ 成立。证毕。

**引理 2（0/1 背包的滚动数组不变量）**：设当前的物品序列是 $(W_1,V_1),\dots,(W_m,V_m)$（顺序任意）。用倒序容量循环依次处理这些物品后，
$$\texttt{dp}[j]=\max\Big\{\textstyle\sum_{i\in T}V_i\;:\;T\subseteq\{1..m\},\ \sum_{i\in T}W_i\le j\Big\}\qquad(0\le j\le S),$$
即"容量 $j$ 以内、只考虑前 $m$ 个物品时的最大价值"。

*证明*：对处理过的物品个数 $m$ 归纳。

$m=0$：唯一的子集是空集，价值 0，而所有 $V_i>0$ 使非空子集价值为正、但此时没有物品，故 $\texttt{dp}[j]=0$ 正确。这与全局数组默认 0 一致。

归纳步：设处理完前 $m$ 个物品后 `dp` 满足不变量，现在处理第 $m+1$ 个物品 $(W,V)$。任取 $T\subseteq\{1..m+1\}$：
- 若 $m+1\notin T$，则 $T\subseteq\{1..m\}$，其价值和 $\le\texttt{dp}[j]$（归纳假设）。
- 若 $m+1\in T$，令 $T'=T\setminus\{m+1\}$，则 $\sum_{T'}W\le j-W$，于是 $\sum_T V=V+\sum_{T'}V\le V+\texttt{dp}[j-W]$（归纳假设，注意 $j-W<j$）。
反之，$\texttt{dp}[j]$ 与 $V+\texttt{dp}[j-W]$ 这两个值都被某个具体子集取到（前者由归纳假设的取到者，后者由 $T'$ 的取到者并上 $\{m+1\}$，可行性由 $\sum_{T'}W\le j-W$ 保证）。因此
$$\texttt{dp}_{\text{new}}[j]=\max\big(\texttt{dp}_{\text{old}}[j],\ V+\texttt{dp}_{\text{old}}[j-W]\big)$$
（$j<W$ 时只有第一项，代码中循环下界正是 $W$，故这些位置不被改动）。

最后说明**为什么必须倒序**：代码是原地更新。计算 $\texttt{dp}[j]$ 时若 $j-W<j$ 尚未被本轮更新过，读到的是 $\texttt{dp}_{\text{old}}[j-W]$，正好符合上式；而倒序枚举保证"比 $j$ 小的下标都还没更新"，所以原地数组等价于"两层滚动"。若正序枚举，$\texttt{dp}[j-W]$ 已经是本轮（含第 $m+1$ 个物品）的值，$\texttt{dp}[j]$ 就会把第 $m+1$ 个物品用两次、三次……，那是不合法方案的价值，会高估，结论就错了。证毕。

**引理 3（可行性关于 $L$ 单调）**：若 $\mathrm{ok}(L)$ 成立，则对任意 $L'\ge L$ 也有 $\mathrm{ok}(L')$。

*证明*：$L'\ge L\Rightarrow A(L)\subseteq A(L')$。引理 1 中的可行方案 $T$ 满足 $T\subseteq A(L)\subseteq A(L')$，其总大小与总价值不变，仍是 $L'$ 下的合法方案。故 $\mathrm{ok}(L')$ 成立。证毕。

**引理 4（答案必是某个 $W_i$，且等于"最小化的最大文件大小"）**：若存在可行的 $L$，则
$$\min\{L:\mathrm{ok}(L)\}=\min\Big\{\max_{i\in T}W_i\;:\;T\ \text{满足}\ \sum_{i\in T}W_i\le S,\ \sum_{i\in T}V_i\ge p\Big\},$$
并且这个最小值属于 $\{W_1,\dots,W_n\}$。

*证明*：记右边的集合族为 $\mathcal F$（满足容量与价值要求的子集族），右式记作 $M$。
先证 $\min\{L:\mathrm{ok}(L)\}\ge M$：设 $\mathrm{ok}(L)$ 成立，由引理 1，存在 $T\in\mathcal F$ 且 $T\subseteq A(L)$，后者意味着 $\max_{i\in T}W_i\le L$。于是 $M\le\max_{i\in T}W_i\le L$。因为对每个可行的 $L$ 都有 $M\le L$，取最小得 $\min\{L:\mathrm{ok}(L)\}\ge M$。
再证 $\ge$ 反向：设 $T^*\in\mathcal F$ 取到 $M=\max_{i\in T^*}W_i$。注意 $p\ge1$ 且 $V_i\ge1$，故 $T^*\ne\varnothing$，$M$ 是一个实实在在的文件大小（$M\ge1$）。取 $L=M$：$T^*$ 中每个文件的大小都 $\le M=L$，且总大小 $\le S$、总价值 $\ge p$，所以 $\mathrm{ok}(M)$ 成立，于是 $\min\{L:\mathrm{ok}(L)\}\le M$。
两个方向合并得等号；又 $M$ 是 $T^*$ 中若干 $W_i$ 的最大值，必是某个 $W_i$。证毕。

引理 4 说明"在文件大小里找答案"不是碰巧，而是问题本身的结构，二分的候选集因此合法。

**引理 5（按 $W$ 升序逐个加入时"第一次达标"的位置就是答案）**：把文件按 $W$ 升序排序为 $a_0,a_1,\dots,a_{n-1}$（`a[i].w` 非降）。设 `dp_i` 表示处理完 $a_0..a_i$ 后的背包。若扫描在第 $k$ 个文件处首次出现 $\texttt{dp}_k[S]\ge p$，则答案为 `a[k].w`；若扫描到结尾都没有出现，则无解。

*证明*：分三点。

(1) **前缀背包是"某个更小接口"的真实背包。** 由引理 2，$\texttt{dp}_i[S]$ 是"只允许 $a_0..a_i$ 这些文件"时的最大价值。由于排序非降，$\{a_0..a_i\}\subseteq A(\texttt{a}[i].\texttt{w})$。由引理 1 的（$\Leftarrow$）方向（族更大，max 只会更大），$\texttt{dp}_i[S]\le$ 真实接口 `a[i].w` 下的最大值。所以 $\texttt{dp}_k[S]\ge p$ 推出 $\mathrm{ok}(\texttt{a}[k].\texttt{w})$ 成立，即**答案 $\le$ `a[k].w`**。

(2) **答案不会更小。** 反设答案 $=\texttt{a}[j].\texttt{w}<\texttt{a}[k].\texttt{w}$。取 $m=\max\{i:\texttt{a}[i].\texttt{w}=\texttt{a}[j].\texttt{w}\}$，即"该大小"的最后一个文件。由于数组按 `w` 非降排序且 $\texttt{a}[m].\texttt{w}<\texttt{a}[k].\texttt{w}$，必有 $m<k$；又 $k$ 是**首次**达标的位置，所以在位置 $m$ 处 $\texttt{dp}_m[S]<p$。但前缀 $0..m$ 恰好就是 $A(\texttt{a}[j].\texttt{w})$ 的全部（排序把同大小的文件连续排在一起，$m$ 是该大小的最后一个），于是由引理 2，$\texttt{dp}_m[S]$ 正是 $\mathrm{ok}(\texttt{a}[j].\texttt{w})$ 判定中所用的那个最大值，它 $<p$，与引理 1 矛盾。故答案 $\ge\texttt{a}[k].\texttt{w}$。

(3) **"从未达标"等价于无解。** 若无解，则对每个 $L$ 都有引理 1 的 max $<p$，特别地 $L=\max_i W_i$ 时（允许全部文件）也 $<p$；而 $\texttt{dp}_{n-1}[S]$ 正是全部文件的背包值，故扫描不会达标。反之若扫描到结尾仍未达标，则用全部文件也达不到 $p$，任何更小的接口更不可能，无解。

由 (1)(2) 得答案 $=$ `a[k].w`；由 (3) 得"没有 $k$"时输出 `No Solution!` 正确。证毕。

**定理**：程序输出正确。

*证明*：由引理 5，若存在首次达标位置则输出恰为最小可行接口大小；否则由引理 5(3) 问题无解，输出 `No Solution!`。引理 2 保证 `dp` 的原地滚动确实等于背包真值（这是引理 5 的前提），引理 3、4 说明"答案是一段后缀的最小值、且必为某个文件大小"，与实现一致。证毕。

**复杂度**：排序 $O(n\log n)$；每个文件一次倒序容量循环 $O(S)$，共 $O(nS)$。总时间 $O(n\log n+nS)$，空间 $O(n+S)$。$n,S\le10^3$ 时约 $10^6$ 次运算。

## 三、模式总结（按实际思考顺序）

- explore its property — 目标是最小化"所选文件大小的最大值"，而 $L$ 只通过"允许哪些文件"起作用，于是拆成"判定 + 找最小"
- consider easier version — 固定 $L$ 后退化为 0/1 背包：容量 $S$ 内最大价值是否 $\ge p$
- explore its property — 可行性关于 $L$ 单调（接口变大只会多允许文件），可行 $L$ 是一段后缀
- reduce to easier problem — 最小可行 $L$ 必等于某个 $W_i$（把接口收缩到所选集合的最大文件大小），故候选集只有 $n$ 个
- classic problem solution — 二分答案 + 每次重做背包（$O(nS\log n)$，可行但多一个 $\log$）
- avoid repeated work — 0/1 背包只依赖物品多重集，故按 $W$ 升序逐个加入即可复用同一份 `dp`，$O(nS)$
- classic problem solution — 滚动数组 0/1 背包，容量维倒序枚举防重复使用
- handle boundaries — `No Solution!` 用 114514 家族哨兵、`dp` 初值 0 的正确语义、价值上界 $10^9$ 用 `int` 恰好安全、比较用 `>= p`

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|----------------|
| $n$ | 文件个数 | `int` | 输入 |
| $p$ | 要求的最小总价值 | `int` | 输入，$\le10^9$ |
| $S$ | U 盘容量（总大小上限） | `int` | 输入 |
| `a[i].w` | 第 $i$ 个文件的大小 $W_i$ | `int` | 输入后按 `w` 升序排序 |
| `a[i].v` | 第 $i$ 个文件的价值 $V_i$ | `int` | 输入 |
| `dp[j]` | 只考虑"已加入的文件"、总大小 $\le j$ 时的最大价值 | `int[]` | 全局默认 0；语义是"至多"，空集 0 合法，**不要填 INF** |
| `ans` | 最小接口大小 | `int` | $1145141919$ 表"没找到" |

### 算法步骤

1. 读入 $n,p,S$ 与全部 $(W_i,V_i)$。
2. 把文件按 $W_i$ 升序排序。
3. 令 `ans` $=1145141919$，`dp` 全 0。
4. 依次取排序后的第 $i$ 个文件：对 $j$ 从 $S$ 倒序枚举到 `a[i].w`，做 `dp[j]=max(dp[j],dp[j-a[i].w]+a[i].v)`。
5. 紧接着判 `dp[S]>=p`：成立则 `ans=a[i].w` 并跳出循环（由引理 5，这个位置就是首次达标处）。
6. 若 `ans` 仍是哨兵值，输出 `No Solution!`；否则输出 `ans`。

### 复杂度

- 时间：$O(n\log n+nS)$。
- 空间：$O(n+S)$。

### 状态的一句话验证

`dp` 的下标语义（容量"至多"）、倒序枚举（每件至多一次）、以及"第一个达标的文件大小即答案"（引理 5）三者对应代码中的四处关键点：`dp[j-a[i].w]`、`j--`、`dp[S]>=p` 的即时判定、和 `ans==1145141919` 的无解出口。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2370 yyy2015c01 的 U 盘
// 把文件按大小升序依次塞进 0/1 背包：塞完第 i 个后 dp[S] 就是「接口大小 = a[i].w」时的最大价值
// 第一个满足 dp[S]>=p 的文件大小就是答案，全程不满足就是 No Solution!
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,p,S;
struct{int w,v;}a[mxn];
int dp[mxn];   //dp[j]=容量 j 以内能取到的最大价值

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>p>>S;
	for(int i=0;i<n;++i)
		cin>>a[i].w>>a[i].v;
	sort(a,a+n,[](auto x,auto y){return x.w<y.w;});
	int ans{1145141919};       //114514 家族哨兵：表示「没找到」
	for(int i=0;i<n;++i)
	{
		for(int j=S;j>=a[i].w;--j)
			dp[j]=max(dp[j],dp[j-a[i].w]+a[i].v);
		//此时 dp 恰好是「接口大小 = a[i].w」时的 0/1 背包
		if(dp[S]>=p)
		{
			ans=a[i].w;
			break;
		}
	}
	if(ans==1145141919)
		cout<<"No Solution!\n";
	else
		cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `sort` 只按 `w` 排序，同大小的顺序任意：引理 5 的证明只用到"同大小的文件连续排列"，不要求组内有序。
- 内层循环下界是 `a[i].w`：大小超过 $S$ 的文件循环体一次都不执行，等价于"这个文件永远选不进去"，无需特判。
- `dp[S]` 是"容量 $\le S$"的最大价值（不是恰好 $S$），因为 `dp` 的初值与转移都是"至多"语义。
- `ans` 用 `1145141919` 当"没找到"，因为合法答案 $\le 10^3$，不可能撞上。
- 价值总和最大 $10^3\times10^6=10^9<2^{31}-1$，故 `int` 安全；若 $n$ 或 $V$ 更大则应换 `long long`。
