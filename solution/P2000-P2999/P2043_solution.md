# P2043 质因子分解 — 题解

## 一、解题过程：人类思考叙事

题目要求把 $N!$ 分解成质因数的乘积，并按质数从小到大输出每个质数及其指数。$N\le 10000$。

$N!$ 本身极大（$10000!$ 有 $35660$ 位），显然不能先算出阶乘再分解。但题目问的其实是"**$N!$ 里每个质数出现了多少次**"，这是个可以绕开大整数的计数问题。

最朴素的思路是：把 $1,2,\dots,N$ 每个数都试除分解，统计每个质因子被除掉的次数，累加起来就是答案。这个做法在 $N=10000$ 时复杂度是 $O(N\cdot\text{试除次数})$，大约 $10^5$ 级别，完全能过。所以本题的"暴力"版本非常容易写，我也确实写了它来做对拍。

但更漂亮的做法是 **Legendre 公式**。它回答的问题是：$N! = 1\cdot2\cdot3\cdots N$ 中，质数 $p$ 一共出现了多少次？

换一个角度数。$N!$ 中的每个因子 $i$ 都贡献若干个 $p$。如果只看"至少含一个 $p$"的因子有哪些——它们是 $p, 2p, 3p, \dots, \lfloor N/p\rfloor p$，共 $\lfloor N/p\rfloor$ 个，每个先贡献 $1$ 个 $p$。然后看"至少含两个 $p$"的因子，它们是 $p^2$ 的倍数，共 $\lfloor N/p^2\rfloor$ 个，每个再多贡献 $1$ 个 $p$。以此类推：

$$v_p(N!)=\sum_{k\ge1}\left\lfloor\frac{N}{p^k}\right\rfloor$$

这个式子每项都只需要不断除以 $p$ 就能算出来，代码极短：

```cpp
int a=0,x=n;
while(x){ x/=p; a+=x; }
```

注意 `while(x)` 条件配合"先除后加"：当 $x$ 除到 $0$ 时最后一次迭代只是把 $x$ 变成 $0$ 并加 $0$，不影响结果，但多一次无害的循环；写成 `while(x){x/=p;a+=x;}` 已经是安全的（不会死循环，因为 $x$ 每次至少减半或变 $0$）。

还有一件事：**哪些质数要输出？** 答案里出现的质数恰好是所有不超过 $N$ 的质数——因为 $N!$ 的因子都不超过 $N$。所以需要先把 $[2,N]$ 内的质数筛出来。用**埃氏筛**：从小到大枚举 $i$，若 $i$ 未被标记为合数则它是质数，把它加入答案数组，并把它的所有倍数 $i^2, i^2+i, \dots$ 标记为合数。注意内层从 $i^2$ 开始，而不是从 $2i$：因为小于 $i^2$ 的 $i$ 的倍数已经被更小的质因子筛掉了，重复标记是浪费。

样例 $N=10$：质数有 $2,3,5,7$。
- $v_2(10!)=\lfloor10/2\rfloor+\lfloor10/4\rfloor+\lfloor10/8\rfloor=5+2+1=8$；
- $v_3=3+1=4$；
- $v_5=2$；
- $v_7=1$。

输出 `2 8 / 3 4 / 5 2 / 7 1`，与题面 Hint 中的 $10!=(2^8)(3^4)(5^2)\cdot7$ 完全一致。

## 二、思维链：完整证明

**引理 1**（筛法正确性）：埃氏筛标记的合数集合恰好是 $[2,N]$ 中所有非质数。

*证明*：对任意 $x\in[2,N]$。

若 $x$ 是合数，设其最小质因子为 $p\le\sqrt{x}$。当枚举到 $i=p$ 时，$p$ 尚未被标记（$p$ 是质数），故 $p$ 被收进质数数组，且内层循环从 $p^2$ 开始。由于 $x\ge p^2$ 且 $p\mid x$，$x$ 必被标记。

若 $x$ 是质数，假设它被标记，则存在某个 $i<p$（因为 $i^2\le x$ 且 $i\mid x$，$i<x$）使 $x$ 是 $i$ 的倍数且 $x\ge i^2$，此时 $i\mid x$ 且 $1<i<x$，与 $x$ 是质数矛盾。故质数不会被标记。

综上，被标记的恰是合数。证毕。

**引理 2**（答案中的质数集合）：$N!$ 的质因子恰为所有满足 $p\le N$ 的质数 $p$。

*证明*：$N!=1\cdot2\cdots N$ 的每个因子都不超过 $N$，故 $N!$ 的任何质因子都不超过 $N$。反之，任一质数 $p\le N$ 本身就是因子之一，故 $p\mid N!$。证毕。

**引理 3**（Legendre 公式）：对质数 $p$ 与正整数 $N$，$N!$ 中质因子 $p$ 的指数为 $v_p(N!)=\sum_{k\ge1}\lfloor N/p^k\rfloor$。

*证明*：记 $N!$ 中质因子 $p$ 的指数为 $v_p(N!)$。由 $N!=\prod_{i=1}^{N}i$ 及指数的可加性，$v_p(N!)=\sum_{i=1}^{N}v_p(i)$。

把 $1,\dots,N$ 中每个数按其含有的 $p$ 的个数分组：对每个 $k\ge1$，令 $A_k=\{i\in[1,N]: p^k\mid i\}$，则 $v_p(i)\ge k$ 当且仅当 $i\in A_k$。由分层计数原理，$\sum_{i=1}^N v_p(i)=\sum_{k\ge1}|A_k|$。

而 $|A_k|=\lfloor N/p^k\rfloor$（$1$ 到 $N$ 中 $p^k$ 的倍数个数）。当 $p^k>N$ 时该项为 $0$，故求和有限。于是 $v_p(N!)=\sum_{k\ge1}\lfloor N/p^k\rfloor$。证毕。

**定理**：算法输出的每一行 $(p,a)$ 都正确，且按 $p$ 升序、不重不漏。

*证明*：由引理 1，筛法得到的质数数组恰好是不超过 $N$ 的所有质数，且按枚举顺序天然递增。由引理 2，这些正是需要输出的质数集合。对每个这样的 $p$，程序用 `while(x){x/=p;a+=x;}` 计算，迭代序列恰为 $x=\lfloor N/p\rfloor,\lfloor N/p^2\rfloor,\dots$ 直至为 $0$，由引理 3 其和即 $v_p(N!)$。因此输出正确、升序、不重不漏。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别题型** — 求阶乘的质因子指数，核心是"不要真去算阶乘"。
2. **分层计数** — 按"含至少 $k$ 个 $p$"给因子分层，得到 Legendre 公式。
3. **公式的代码形态** — 不断除以 $p$ 累加即可，$O(\log_p N)$。
4. **筛出质数** — 埃氏筛，内层从 $i^2$ 开始。
5. **边界** — $N=1$ 时 $1!=1$，无质因子，输出为空（程序自然什么都不输出）。
6. **验证方式** — 题面 Hint 的 $10!$ 分解可手算核对；另写"逐数试除累加"的暴力做对拍。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $N$ | 输入的整数 | `int`，$1\le N\le 10000$ |
| `vis[i]` | $i$ 是否为合数 | `bool[]`，长度 $N+5$ |
| `pri[i]` | 第 $i$ 个质数（升序） | `int[]` |
| `cnt` | 已找到的质数个数 | `int` |
| $p$ | 当前处理的质数 | `int` |
| $a$ | $v_p(N!)$，即 $p$ 的指数 | `int`，$\le N-1\le 9999$ |
| `x` | Legendre 求和中的当前项，初始为 $N$ | `int` |

### 算法步骤

1. 读入 $N$。
2. **埃氏筛**：对 $i=2..N$，若 `vis[i]` 为假则 `pri[++cnt]=i`，并把 $i^2,i^2+i,\dots\le N$ 标记为真。
3. 对每个质数 $p=\text{pri}[i]$（$i=1..cnt$）：
   - 令 $a=0,x=N$；
   - 反复执行 $x\leftarrow\lfloor x/p\rfloor$、$a\leftarrow a+x$，直到 $x=0$；
   - 输出 $p$ 与 $a$。
4. 结束。

### 复杂度

- 筛法：$O(N\log\log N)$。
- 求指数：每个质数 $O(\log_p N)$，总复杂度 $O(\pi(N)\log N)$，远小于筛法。
- 总时间复杂度：$O(N\log\log N)$；空间复杂度：$O(N)$。

- 题面 Hint 样例 $N=10$ 输出
  ```

  ```
  与 Hint 的 $10!=(2^8)(3^4)(5^2)\cdot7$ 一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2043 质因子分解
// 思路：先筛出不超过 N 的所有质数，再用 Legendre 公式求每个质数在 N! 中的指数
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

bool vis[mxn];
int pri[mxn],cnt;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	// 埃氏筛：标出合数，同时收集质数
	for(int i=2;i<=n;++i)
	{
		if(vis[i]) continue;
		pri[++cnt]=i;
		for(int j=i*i;j<=n;j+=i) vis[j]=true;
	}
	for(int i=1;i<=cnt;++i)
	{
		int p=pri[i],a=0,x=n;
		// Legendre: v_p(N!)=N/p+N/p^2+...
		while(x)
		{
			x/=p;
			a+=x;
		}
		cout<<p<<' '<<a<<'\n';
	}
	return 0;
}
```

### 代码说明

- 筛的内层从 `i*i` 开始：小于 $i^2$ 的 $i$ 的倍数已被更小的质因子标记过，重复标记纯属浪费。
- `pri` 按 `i` 从小到大枚举时依次追加，天然升序，无需额外排序。
- `while(x){x/=p;a+=x;}`：每轮把 `x` 整除 $p$ 一次并累加，恰好依次得到 $\lfloor N/p\rfloor,\lfloor N/p^2\rfloor,\dots$；当 `x` 变为 $0$ 时循环结束，最后一轮多加的 $0$ 不影响结果。
- `i*i` 在 $N\le10000$ 时最大 $10^8$，`int` 不会溢出（`int` 上限约 $2.1\times10^9$）。
- 指数 $a\le N-1$（Legendre 公式各项之和不超过 $N/(p-1)$ 对 $p=2$ 成立时约 $N$），`int` 足够。
