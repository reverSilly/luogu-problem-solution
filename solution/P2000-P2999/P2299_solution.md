# P2299 Mzc和体委的争夺战 — 题解

## 一、解题过程：人类思考叙事

题意：$n$ 个停留站、$m$ 条**双向**道路，第 $i$ 条连接 $a_i,b_i$，两个方向耗时都是 $c_i$（$1\le c_i\le 10^6$）。求从 $1$ 号站到 $n$ 号站的最短时间。数据范围 $n\le 2500$，$m\le 2\times 10^5$，时限 $1$ s。

**第一反应：BFS？** 不行。BFS 只对「边权全相同」的图正确——它按边数分层，而这里边的代价是 $1$ 到 $10^6$ 不等，走两条便宜的路可能比走一条贵的路更快，BFS 会给出错误答案。必须换成真正的最短路算法。

**候选算法盘点。**

- **Bellman-Ford**：$O(nm)=2500\times 2\times 10^5=5\times 10^8$ 次松弛。虽然不至于爆炸，但在 $1$ s 的限制下非常悬，而且它完全没利用「边权为正」这个条件。
- **SPFA**：看起来很美，入队才松弛。但它的最坏复杂度就是 $O(nm)$，而且有大量针对它的构造数据（网格状分层图能把每个点反复入队），$1$ s 的题不敢赌。
- **Dijkstra**：要求边权非负——本题 $c_i\ge 1>0$，完美符合。堆优化后 $O((n+m)\log m)$，稳。

还有一个细节值得注意：$n\le 2500$ 意味着 $n^2=6.25\times 10^6$，**朴素 $O(n^2)$ Dijkstra 也能过**（每次线性扫最小值，$6.25\times 10^6$ 次比较），代价是要开 $2500\times 2500$ 的邻接矩阵（约 $25$ MB）。两种写法都可行，堆优化版对「点多边少」更稳，也更容易复用，所以选堆优化。这个权衡说明了一件事：本题的难度不在算法选择，而在**把 Dijkstra 的正确性和边界写对**。

**两个必须想清楚的实现问题。**

问题一：**距离会超 `int`。** 直觉上「$n\le 2500$、边权 $\le 10^6$，乘积 $2.5\times 10^9$」——这正好越过了 `int` 的上界 $2147483647$。要严格说明：在最短路里不会绕圈（正权图里绕一圈只会更远），所以最短路至多含 $n-1=2499$ 条边，长度至多 $2499\times 10^6=2.499\times 10^9$。虽然真实数据未必取到，但**合法输入就能让 `int` 溢出成负数**，进而被当成「更短的路」继续松弛，答案彻底错乱。所以 `dis` 必须开 `long long`，松弛时的 `dis[u]+w` 也必须在 64 位下计算。

问题二：**重边与自环。** 题面没有禁止 $a_i=b_i$ 或多条路连接同一对站点。自环对最短路毫无贡献（走它只会更长），重边则取最小者即可——而把边全部塞进邻接表、让 Dijkstra 自己挑，这两种情况都天然被正确处理，不需要预处理去重。这也解释了为什么用邻接表而不是邻接矩阵：矩阵会把重边覆盖成「最后一条」，虽不影响最短路正确性，但邻接表更省心。

另外记录一下无解的边界：题目没有明说 $1$ 与 $n$ 一定连通，若真的不连通，`dis[n-1]` 会停在哨兵值。按题面「输出 1 到 n 最短时间」的约定，测试数据应保证连通；代码不做额外特判，但心里要清楚这一点。

**手造数据核对思路。** 题面无样例，手造两组：

```
4 4
1 2 5
2 4 5
1 3 1
3 4 1
```
最短路是 $1\to3\to4$，$1+1=2$，比 $1\to2\to4$ 的 $10$ 短，应输出 `2`。

```
3 3
1 2 1000000
2 3 1000000
1 3 1500000
```
直走 $1\to3$ 花费 $1.5\times10^6$，绕行 $2\times10^6$，应输出 `1500000`。两组程序实际输出与手算一致。

## 二、思维链：完整证明

记号：$G=(V,E)$ 为双向图，$|V|=n$，边 $e$ 的权 $c_e\ge 1$。$\delta(v)$ 表示 $1$ 号点到 $v$ 的最短距离，$\delta(v)=+\infty$ 表示不可达。程序中 `dis[v]` 是「当前已知的最好上界」（tentative distance），`vis[v]` 表示 $v$ 是否已被「定型」（弹出并确认）。

**引理 1（`dis` 始终是真实路径长度）**：程序运行过程中任何时刻，若 `dis[v]=c<+\infty`，则图中存在一条从 $1$ 到 $v$、长度为 $c$ 的路径。因此恒有 $\delta(v)\le$ `dis[v]`。

*证明*：对 `dis` 被修改的次数归纳。初始 `dis[1]=0`，对应长度 $0$ 的空路径；其余为 $+\infty$，命题空洞成立。每次修改来自对边 $(u,v,w)$ 的松弛，把 `dis[v]` 改成 `dis[u]+w`。由归纳假设存在长度 `dis[u]` 的 $1\to u$ 路径，接上边 $(u,v)$ 即得长度 `dis[u]+w` 的 $1\to v$ 路径。于是任何有限 `dis[v]` 都是某条真实路径的长度，而 $\delta(v)$ 是所有这些长度的最小值，故 $\delta(v)\le$ `dis[v]`。证毕。

**引理 2（最短路是简单路，长度上界）**：若 $\delta(v)<+\infty$，则存在一条不含重复顶点的最短路，其边数不超过 $n-1$，长度不超过 $(n-1)\cdot 10^6$。

*证明*：取一条最短路 $P$。若 $P$ 上某个顶点 $x$ 出现两次，设两次出现之间的子路径为 $C$（一个环）。$C$ 至少含一条边，且每条边权 $\ge 1>0$，故 $C$ 的长度 $\ge 1$。从 $P$ 中删去 $C$ 得到一条更短的 $1\to v$ 路径，与 $P$ 最短矛盾。故 $P$ 无重复顶点，边数 $\le n-1$，长度 $\le (n-1)\cdot\max c_e=2499\times10^6<2.5\times10^9$。证毕。

> 这条引理有两个用处：一是给出 `dis` 的取值上界，从而算出必须用 64 位；二是说明「最短路不会绕圈」，为引理 3 的「路径前缀也是最短路」提供依据。

**引理 3（最短路的前缀仍是最短路）**：设 $1=w_0,w_1,\dots,w_k=v$ 是一条最短路，则对每个 $0\le i\le k$，$w_0,\dots,w_i$ 是 $1$ 到 $w_i$ 的最短路。

*证明*：若存在更短的 $1\to w_i$ 路径 $P'$，则把 $P'$ 接上原路径的后半段 $w_i\to v$，得到一条严格短于原最短路的 $1\to v$ 路径，矛盾。证毕。

**引理 4（弹出的点距离精确）**：设 $u$ 是某次被弹出且 `vis[u]` 尚为 false 的点，则 `dis[u]`$=\delta(u)$。

*证明*：由引理 1 已有 `dis[u]`$\ge\delta(u)$。反设 `dis[u]`$>\delta(u)$，并取 $u$ 为**第一个**违反该等式的弹出点，于是此前弹出的所有点 $x$ 都满足 `dis[x]`$=\delta(x)$。

设 $1=w_0,w_1,\dots,w_k=u$ 是一条最短路（$k=\delta(u)<$ `dis[u]`）。令 $i$ 为「在 $u$ 被弹出的这一刻之前已经定型（`vis` 为 true）的最大下标」。这个 $i$ 一定存在：$w_0=1$ 的 `dis` 为 $0$，是所有值中的最小值，堆每次弹出最小值，故 $1$ 号点先于 $u$ 被弹出（即使 $u=1$ 也不可能，因为 `dis[1]`$=0=\delta(1)$ 不违反等式）。又 $u=w_k$ 此刻尚未定型，所以 $i\le k-1$。

考察 $w_i$ 被弹出的时刻。由 $i$ 的定义与「第一个违反者」的选取，`dis[w_i]`$=\delta(w_i)$。此时算法扫描 $w_i$ 的邻边，对边 $(w_i,w_{i+1})$ 做松弛，使得
$$\texttt{dis}[w_{i+1}]\le \texttt{dis}[w_i]+c(w_i,w_{i+1})=\delta(w_i)+c(w_i,w_{i+1})=\delta(w_{i+1}),$$
最后一步用了引理 3（最短路的子段 $w_0\dots w_{i+1}$ 也是最短路）。`dis` 只会减小、不会增大，所以到 $u$ 被弹出时仍有 `dis[w_{i+1}]`$\le\delta(w_{i+1})$。

由 $i$ 的最大性，$w_{i+1}$ 在 $u$ 弹出前**没有**定型。它在某次松弛中得到了当前值 `dis[w_{i+1}]`，并且那次松弛同时把它以该值压入了堆。一条堆记录消失只有两种方式：还在堆里，或者被弹出；而它一旦被弹出，若当时 `vis` 为 false 就会被定型，与「没定型」矛盾（若当时 `vis` 已为 true，则它更早就定型了，同样矛盾）。所以那条记录此刻**仍在堆中**。

又因 $w_{i+1}$ 落在 $1\to u$ 的最短路前缀上，有 $\delta(w_{i+1})\le\delta(u)=k<$ `dis[u]`。于是堆顶的值 $\le$ `dis[w_{i+1}]`$\le\delta(w_{i+1})\le k<$ `dis[u]`，与「本次弹出的是最小值 `dis[u]`」矛盾。证毕。

**引理 5（可达点都会被定型）**：若 $\delta(v)<+\infty$，则 $v$ 最终会被弹出且 `vis[v]` 变为 true。

*证明*：取最短路 $1=w_0,\dots,w_k=v$，对 $i$ 归纳证明 $w_i$ 最终定型。$w_0=1$ 一开始就在堆中，且 `dis[1]`$=0$ 是最小可能值，故它必被弹出并定型。设 $w_i$ 已定型。它被弹出时对边 $(w_i,w_{i+1})$ 做了松弛，由引理 3 与引理 1 得 `dis[w_{i+1}]`$=\delta(w_{i+1})$，并且一条值为 $\delta(w_{i+1})$ 的堆记录被压入。$w_{i+1}$ 若在别处已被定型则已证完；否则这条记录一直留在堆中直到被弹出（堆不会丢弃元素），弹出时 `vis` 仍为 false，于是被定型。归纳完成。证毕。

> 注：堆里可能有同一个点的多条记录（每次成功松弛都压一条），弹出时若 `vis` 已 true 就跳过，这叫惰性删除；引理 5 说明「至少有一条正确值的记录会留下并被处理」，所以惰性删除不会漏点。

**定理（答案正确）**：程序输出的 `dis[n-1]` 等于 $\delta(n-1)$（在 $n$ 可达时）。

*证明*：若 $n$ 可达，由引理 5 它会被定型，定型那一刻由引理 4 有 `dis[n-1]`$=\delta(n-1)$；定型之后 `dis` 不会被改小（引理 1 保证任何候选值都 $\ge\delta$），所以最终输出仍是 $\delta(n-1)$。若 $n$ 不可达，`dis[n-1]` 保持哨兵值，属于题面之外的约定情形。证毕。

**引理 6（复杂度）**：时间 $O((n+m)\log m)$，空间 $O(n+m)$。

*证明*：每条**有向**边只在其起点被弹出定型时被扫描一次（每个点只定型一次），故扫描总数恰为 $2m$；每次扫描至多触发一次成功松弛、至多压入一条堆记录，所以整局压堆次数不超过 $2m+1$（含初始的 `{0,0}`）。于是每一轮循环取出、判 `vis` 的代价合计 $O(m)$，每次堆操作为 $O(\log m)$，总计 $O((n+m)\log m)$。空间为邻接表 $O(n+m)$ 加堆 $O(m)$，即 $O(n+m)$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 边权不是 1 而是 $1\sim10^6$，BFS 的分层思想失效，必须用真正的最短路。
- **classic problem solution** — 排除 Bellman-Ford（$O(nm)=5\times10^8$ 太悬）与 SPFA（最坏 $O(nm)$，易被网格数据卡），锁定 Dijkstra：唯一的前提「边权非负」由 $c_i\ge1$ 满足。
- **consider easier version** — 注意到 $n\le2500$ 时朴素 $O(n^2)$ Dijkstra 只需 $6.25\times10^6$ 次比较，说明本题真正的难点不在选算法，而在正确性与边界。
- **explore its property** — 正权图的最短路不含环 ⇒ 边数 $\le n-1$ ⇒ 距离上界 $2.5\times10^9$ 超过 `int`，必须 64 位。
- **classic problem solution** — 堆优化 Dijkstra：惰性删除 + `greater<>` 小根堆，$O((n+m)\log m)$。
- **处理输入噪声** — 重边、自环不预处理，直接进邻接表，Dijkstra 自动处理。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 停留站数 | 读入 |
| $m$ | 道路数 | 读入 |
| `graph[u]` | $u$ 的出边表，元素为 `{v,w}` | 双向边各插一次 |
| `dis[v]` | 当前已知的 $1\to v$ 最短距离上界 | 全部 `inf`，`dis[0]=0` |
| `vis[v]` | $v$ 是否已定型 | 全 false |
| `Q` | 小根堆 `pair<i64,int>`，存放 `{距离, 点}` | 初始压入 `{0,0}` |
| `inf` | 哨兵 `1145141919810` | 比 $2.5\times10^9$ 大，且远离真实值 |

### 算法步骤

1. 读入 $n,m$；对每条边读 $a,b,c$，转成 0-based 后向 `graph[a]`、`graph[b]` 各插入 `{对端, c}`。
2. 把 `dis[0..n-1]` 置为 `inf`，`dis[0]=0`；把 `{0,0}` 压入小根堆。
3. 循环直到堆空：
   1. 弹出堆顶 `{d,u}`；若 `vis[u]` 为 true 则跳过（惰性删除）。
   2. 置 `vis[u]=true`（此刻 `dis[u]` 已成为最终值，引理 4）。
   3. 枚举 $u$ 的每条出边 `{v,w}`；若 `dis[u]+w<dis[v]`，更新 `dis[v]` 并把 `{dis[v],v}` 压堆。
4. 输出 `dis[n-1]`。

### 复杂度

- 时间复杂度：$O((n+m)\log m)$，其中堆中记录数不超过 $2m+1$。
- 空间复杂度：$O(n+m)$。
- 极限数据 $n=2500,\ m=2\times10^5$ 实测约 $0.13$ s。

### 验证状态

- 编译：`g++ -std=c++20 -O2 -Wall` 无错误无警告。
- 题面无样例，手造 2 组（菱形图 / 直连更优）输出 `2` 与 `1500000`，与手算一致。
- 对拍：另写 Bellman-Ford（$n$ 轮全边松弛）作为暴力，在 $2\le n\le 9$、随机生成树保证连通的 $300$ 组随机图上比对，**0 mismatch**。
- 极限规模 $n=2500,m=2\times10^5$、边权 $10^6$ 内随机，运行 $0.13$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2299 Mzc和体委的争夺战
// 思路：双向正权图，求 1 到 n 的最短路 => Dijkstra + 小根堆（惰性删除）
//       最短路最多 n-1 条边、每条 1e6，长度会超 int，距离必须 64 位
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2505};
constexpr i64 inf{1145141919810};

struct edge{int v,w;};

int n,m;
vector<edge>graph[mxn];
i64 dis[mxn];
bool vis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,a,b,c;i<m;++i)
	{
		cin>>a>>b>>c;
		--a;--b;
		graph[a].push_back({b,c});
		graph[b].push_back({a,c});
	}

	fill_n(dis,mxn,inf);
	priority_queue<pair<i64,int>,vector<pair<i64,int>>,greater<>>Q;
	dis[0]=0;
	Q.emplace(0,0);
	while(!Q.empty())
	{
		auto[d,u]=Q.top();
		Q.pop();
		if(vis[u])
			continue;      // 惰性删除：过期的堆记录直接丢
		vis[u]=true;
		for(auto[v,w]:graph[u])
			if(dis[u]+w<dis[v])
			{
				dis[v]=dis[u]+w;
				Q.emplace(dis[v],v);
			}
	}
	cout<<dis[n-1]<<'\n';
	return 0;
}
```

### 代码说明

- `dis` 是 `i64`：单条最短路可达 $2499\times10^6>2^{31}-1$，用 `int` 会溢出成负数并破坏松弛的正确性（反例就是「绕远反而更短」）。
- 双向边各插一次，重边、自环都不做预处理：重边会被 Dijkstra 自动取小，自环松弛必然失败。
- `greater<>` 让 `pair` 按第一关键字（距离）升序，实现小根堆；`{d,u}` 的结构化绑定让代码更短。
- `if(vis[u]) continue;` 是惰性删除：一个点可能被压入多次，第一次弹出即定型，之后的都是过期记录。
- 松弛条件写成 `dis[u]+w<dis[v]`，等号不更新，避免无意义的重复压堆。
- 题目保证 $1$ 与 $n$ 连通；若数据不连通，`dis[n-1]` 会保持哨兵值，这只是防御性的默认行为，不是本题的标准输出。
