# P2884 [USACO07MAR] Monthly Expense S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给定 $n$ 个正整数 $a_1,\dots,a_n$（$n\le10^5$，$1\le a_i\le10^4$），要把它们**按原顺序**切成**恰好 $m$ 段**（$1\le m\le n$，每段非空、连续）。设第 $j$ 段的元素和为 $s_j$，一种划分的"代价"是 $\max_j s_j$。求所有合法划分中代价的**最小值** $S$。

这就是经典的"**最小化最大段和**"（split array largest sum / 书本分配 / 月度开销）问题。背景（FJ 把 $n$ 天的开销分成 $m$ 个月报销，最小化最贵那个月）剥掉后，核心是：**连续、保序、恰好 $m$ 段、最小化最大段和**。

**第一步：直接 DP 为什么不行。** 最自然的 DP：$dp[i][j]=$ 把前 $i$ 个数分成 $j$ 段的最小最大段和，转移枚举最后一段的起点 $k$：$dp[i][j]=\min_k\max(dp[k][j-1],\ \text{sum}(k{+}1..i))$。状态 $O(nm)$、转移 $O(n)$，总 $O(n^2m)$。$n=m=10^5$ 时是 $10^{15}$，彻底超时。光是 $O(nm)$ 个状态都存不下。**必须换思路。**

**第二步：把"求最优"改成"判定可行"。** 直接求最小的 $S$ 很难，但反过来问一个判定问题就简单了：

> 给定上限 $S$，能否把序列切成**不超过 $m$ 段**，使每段和都 $\le S$？

记这个判定为 $\text{check}(S)$。它和原问题的关系是：原答案 $=\min\{S:\text{check}(S)=\text{true}\}$。为什么？若某 $S$ 可行，则存在一种 $\le m$ 段、每段 $\le S$ 的划分，其代价 $\le S$，故答案 $\le S$；反之答案 $S^\*$ 对应的划分每段 $\le S^\*$，故 $\text{check}(S^\*)$ 真。两者夹逼得答案就是最小可行 $S$。

**第三步：可行性有单调性 ⇒ 二分答案。** 若 $S$ 可行，则 $S+1$ 也可行（同一种划分，每段和 $\le S<S+1$）。所以 $\text{check}$ 关于 $S$ 单调：一段 false 之后全是 true。于是可以**二分**找第一个 true 的位置。这把"求最优"降成了 $O(\log(\text{值域}))$ 次判定。

**第四步：判定用贪心——每段尽量塞满。** 给定 $S$，怎么判 $\le m$ 段够不够？贪心：从左到右扫，维护当前段的和 `cur`；能塞下下一个数（`cur+a[i]<=S`）就塞，塞不下就**封口**、开新段。最后数段数 `cnt`，`cnt<=m` 即可行。

直觉上"每段塞得越满，用的段越少"。但这需要**严格证明**贪心确实给出最少段数（第四步的引理 2 用"逐步领先"归纳证）。有了它，$\text{check}(S)$ 就等价于"最少段数 $\le m$"。

**第五步：两个必须抠清的细节。**

1. **"不超过 $m$ 段" vs "恰好 $m$ 段"。** 题目要恰好 $m$ 段，但贪心判的是 $\le m$。这两者等价吗？等价，关键在 $a_i>0$ 且 $m\le n$：若贪心只用了 $k<m$ 段，因 $k<m\le n$，必有某段含 $\ge2$ 个元素（鸽笼），把它从中间劈成两段，**每半段的和 $\le$ 原段和 $\le S$**（正数保证子段和不超过整段），段数 $+1$ 仍合法。反复劈到 $m$ 段即可。所以 $\le m$ 可行 $\iff$ 恰好 $m$ 可行。（若允许 $a_i=0$ 结论仍成立；但若 $m>n$ 就无法恰好 $m$ 段，题目用 $m\le n$ 排除了。）
2. **二分的上下界。** 下界 $L=\max a_i$：含最大元素的那段，和至少是 $\max a_i$，故 $S\ge\max a_i$；这也保证贪心里"单个元素永远塞得下"，不会死循环。上界 $R=\sum a_i$：一整段装下全部，$m\ge1$ 必可行。答案落在 $[L,R]$，且 $\text{check}(R)$ 恒真，二分良定义。

**第六步：复杂度。** 每次 $\text{check}$ 扫一遍 $O(n)$，二分 $O(\log R)=O(\log(n\cdot\max a_i))\approx\log 10^9\approx30$ 次，总 $O(n\log R)\approx3\times10^6$，轻松通过。值域 $\sum a_i\le10^9$ 超 `int` 一点点（$10^9<2^{31}$ 其实没超，但用 `long long` 更稳，避免 `cur+a[i]` 中间量越界）。

**手造数据核对。** 题面样例解释给出划分 $\{100,400\},\{300,100\},\{500\},\{101\},\{400\}$，反推序列 $100,400,300,100,500,101,400$，$m=5$：

```
500
```

各段和 $500,400,500,101,400$，最大 $500$；而 $\max a_i=500$ 是下界，故答案恰 $500$，吻合。

另造边界：$m=n$（每数一段，答案 $=\max a_i$）；$m=1$（一整段，答案 $=\sum a_i$）；$n=1$；以及 $a=[1,2,3,4,5],m=2$（答案 $9$，划分 $[1,2,3],[4,5]$）。全部与手算一致。

## 二、思维链：完整证明

**记号。** 序列 $a_0,\dots,a_{n-1}$（0-based），$a_i\ge1$。前缀和 $\text{sum}(l..r)=\sum_{i=l}^r a_i$。一种"段数 $\le m$、上限 $S$"的划分指把序列切成 $k\le m$ 个非空连续段，每段和 $\le S$。$\text{check}(S)$ 返回是否存在的这样的划分。$\mathrm{Ans}$ 为原题答案（恰好 $m$ 段的最小最大段和）。$L=\max_i a_i$，$R=\sum_i a_i$。

---

### 引理 1（可行性单调）

若 $\text{check}(S)$ 真，则对任意 $S'\ge S$，$\text{check}(S')$ 真。

*证明*：$\text{check}(S)$ 真给出一个 $k\le m$ 段、每段和 $\le S$ 的划分。同一种划分每段和 $\le S\le S'$，故对 $S'$ 仍合法，$\text{check}(S')$ 真。证毕。

**推论**：$\text{check}$ 在整数轴上是"先 false 后 true"的单调谓词，可二分找首个 true。

---

### 引理 2（贪心给出最少段数）

设 $S\ge L=\max a_i$。贪心（当前段能塞下就塞，塞不下封口开新段）产生的段数 $k_g$ 是"每段和 $\le S$"的所有划分中**最少**的段数。

*证明*：先确认贪心良定义：因 $S\ge\max a_i$，每个单独元素都 $\le S$，故"开新段后第一个元素必塞得下"，不会卡死；贪心确实产出一个每段和 $\le S$ 的合法划分。

设任意合法划分 $P$ 有 $k$ 段，第 $i$ 段末尾下标为 $o_i$（$o_k=n-1$）；贪心第 $i$ 段末尾下标为 $g_i$。**断言：对所有 $i\le\min(k_g,k)$，$g_i\ge o_i$**（贪心的第 $i$ 个切口不落后于 $P$）。对 $i$ 归纳：

- **$i=1$**：贪心第一段从 $0$ 起尽量右延，直到再加一个就超 $S$。$P$ 的第一段 $[0,o_1]$ 和 $\le S$，是"从 $0$ 起、和 $\le S$"的一个前缀，贪心取的是**最长**的这类前缀，故 $g_1\ge o_1$。
- **归纳步**：设 $g_{i-1}\ge o_{i-1}$。贪心第 $i$ 段起点 $g_{i-1}+1\ge o_{i-1}+1$（$P$ 第 $i$ 段起点）。考虑区间 $[g_{i-1}+1,\ o_i]$：它是 $P$ 第 $i$ 段 $[o_{i-1}+1,o_i]$ 去掉一个前缀（因 $g_{i-1}+1\ge o_{i-1}+1$），由 $a_i\ge1>0$，去前缀只会让和变小，故 $\text{sum}(g_{i-1}+1..o_i)\le\text{sum}(o_{i-1}+1..o_i)\le S$。这说明贪心第 $i$ 段从 $g_{i-1}+1$ 起**至少能延到 $o_i$** 而不超 $S$，而贪心取最长，故 $g_i\ge o_i$。（若 $g_{i-1}+1>o_i$，则贪心第 $i$ 段起点已在 $o_i$ 右侧，$g_i\ge g_{i-1}+1>o_i$ 更成立。）

由断言，贪心第 $k$ 段末尾 $g_k\ge o_k=n-1$，即贪心至多 $k$ 段就扫完整个序列，$k_g\le k$。这对任意合法 $P$ 成立，故 $k_g\le$ 最少段数；又贪心本身合法，$k_g\ge$ 最少段数。故 $k_g=$ 最少段数。证毕。

**推论**：$\text{check}(S)\iff k_g(S)\le m$。代码里 `cnt` 就是 $k_g$，`cnt>m` 时提前返回 false 不影响结论（段数只会继续增）。

---

### 引理 3（"$\le m$ 段" 与 "恰好 $m$ 段" 等价）

设 $1\le m\le n$，$a_i\ge1$。存在"$\le m$ 段、每段 $\le S$"的划分 $\iff$ 存在"恰好 $m$ 段、每段 $\le S$"的划分。

*证明*：($\Leftarrow$) 恰好 $m$ 段显然 $\le m$ 段。

($\Rightarrow$) 设合法划分有 $k\le m$ 段。若 $k=m$ 已证。若 $k<m$：因 $k<m\le n$，有 $k<n$，$n$ 个元素分进 $k$ 段，由鸽笼原理必有一段含 $\ge2$ 个元素。把该段在任意内部位置劈成两个非空连续子段，两子段各自是原段的连续子区间，由 $a_i>0$，子段和 $\le$ 原段和 $\le S$，仍合法，段数变 $k+1$。重复此操作，段数每次 $+1$，直到 $k=m$（因 $m\le n$，最多劈到 $n$ 段即每元素一段，必能到达 $m$）。故恰好 $m$ 段可行。证毕。

**用途**：原题要"恰好 $m$ 段"，引理 3 把它等价转成"$\le m$ 段"，于是引理 2 的贪心判据直接适用。**正数性 $a_i>0$ 与 $m\le n$ 是这条等价的两条腿，缺一不可。**

---

### 引理 4（答案的上下界）

$L\le\mathrm{Ans}\le R$，且 $\text{check}(R)$ 恒真、$\text{check}(S)$ 对 $S<L$ 恒假。

*证明*：**下界**：任何划分中，含最大元素 $a_{i^\*}=L$ 的那段，其和 $\ge a_{i^\*}=L$（正数），故该划分代价 $\ge L$，取 min 得 $\mathrm{Ans}\ge L$。对 $S<L$，含 $a_{i^\*}$ 的段和 $\ge L>S$，不可能每段 $\le S$，$\text{check}(S)$ 假。

**上界**：把整个序列作为 $1$ 段（$m\ge1$），和 $=R$，由引理 3 可细分到 $m$ 段且每段 $\le R$，故 $\mathrm{Ans}\le R$，$\text{check}(R)$ 真。证毕。

---

### 引理 5（二分正确）

在 $[L,R]$ 上对单调谓词 $\text{check}$ 二分（`check(mid)` 真则 `r=mid` 否则 `l=mid+1`），终止时 `l==r` 即最小可行 $S$，等于 $\mathrm{Ans}$。

*证明*：由引理 1，$\text{check}$ 单调；由引理 4，$\text{check}(L-1)$ 假、$\text{check}(R)$ 真，故首个 true 的位置 $S^\*\in[L,R]$ 存在。二分维护不变量"$S^\*\in[l,r]$"：初始 $[L,R]$ 含 $S^\*$；`check(mid)` 真说明 $S^\*\le mid$，置 $r=mid$ 保持；假说明 $S^\*>mid$ 即 $S^\*\ge mid+1$，置 $l=mid+1$ 保持。每轮区间减半，终态 $l=r=S^\*$。

再由第二步的夹逼：$\mathrm{Ans}=\min\{S:\text{check}(S)\}=S^\*$（引理 3 保证"$\le m$ 段可行"与原题"恰好 $m$ 段"同义）。故输出 $l$ 即 $\mathrm{Ans}$。证毕。

---

### 引理 6（复杂度与数值范围）

时间 $O(n\log R)$，空间 $O(n)$；所有累加量 $\le R\le10^9$，用 `long long` 无溢出。

*证明*：二分轮数 $O(\log(R-L+1))=O(\log R)$；每轮 $\text{check}$ 扫 $n$ 个元素 $O(n)$；读入 $O(n)$。合计 $O(n\log R)$。$R=\sum a_i\le n\cdot\max a_i=10^5\times10^4=10^9$。`cur+a[i]` 最大 $\le R+\max a_i\approx10^9$，虽未超 `int`（$2^{31}\approx2.1\times10^9$），但用 `i64` 彻底杜绝边界溢出。空间：数组 $a$ 为 $O(n)$，其余 $O(1)$。证毕。

---

### 定理

程序输出把序列切成恰好 $m$ 段的最小最大段和，复杂度 $O(n\log R)$。

*证明*：引理 3 把"恰好 $m$ 段"等价转为"$\le m$ 段"；引理 2 保证贪心 $\text{check}$ 正确判定最少段数 $\le m$；引理 1 保证可行性单调可二分；引理 4 给出合法二分区间；引理 5 保证二分收敛到最小可行 $S=\mathrm{Ans}$；引理 6 给出复杂度与数值安全。证毕。

## 三、模式总结（按实际思考顺序）

1. **consider easier version** — 先想 DP $dp[i][j]$，$O(n^2m)$ 超时，确认要换框架。
2. **reduce to easier problem** — "求最小 $S$" 转成判定 "给定 $S$ 能否 $\le m$ 段每段 $\le S$"，答案 $=$ 最小可行 $S$。
3. **explore its property** — 可行性关于 $S$ 单调（$S$ 可行 $\Rightarrow S+1$ 可行）⇒ 二分答案。
4. **classic problem solution** — 判定用贪心"每段尽量塞满"，逐步领先归纳证明它给出最少段数。
5. **explore its property** — $a_i>0$ 且 $m\le n$ ⇒ "$\le m$ 段" 与 "恰好 $m$ 段" 等价（可继续细分，子段和 $\le$ 整段）。
6. **discuss by category** — 二分下界 $\max a_i$（含最大元素的段）、上界 $\sum a_i$（一整段）；`long long` 防中间量溢出。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,m` | 元素个数、段数，$m\le n\le10^5$ | `int` | 读入 |
| `a[i]` | 第 $i$ 个正整数 | `int[mxn]` | 读入，0-based |
| `mxn` | $100005$ | `constexpr int` | 约束 $+5$ |
| `l,r` | 二分下界 $\max a_i$、上界 $\sum a_i$ | `i64` | 读入时顺带求出 |
| `s` | 当前判定的段和上限 | `i64`（check 参数） | 二分 mid |
| `cur` | 贪心当前段的累加和 | `i64`，每次 check 重置 $0$ | 塞不下就封口 |
| `cnt` | 贪心已用段数 | `int`，每次 check 重置 $1$ | `cnt>m` 即 false |

### 算法步骤

1. I/O 加速三行。
2. 读 $n,m$；读每个 $a_i$，同时 `l=max(l,a[i])`、`r+=a[i]`。
3. 二分：`while(l<r)`，`mid=(l+r)>>1`；`check(mid)` 真则 `r=mid`，否则 `l=mid+1`。
4. `check(s)`：`cnt=1,cur=0`；扫每个 $a_i$，若 `cur+a[i]>s` 则 `++cnt,cur=a[i]`（`cnt>m` 返回 false），否则 `cur+=a[i]`；扫完返回 true。
5. 输出 `l`。

### 复杂度

- 时间：$O(n\log R)$，$R\le10^9$，约 $3\times10^6$ 次操作。
- 空间：$O(n)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例解释反推序列输出 $500$；$m=n$ 输出 $\max$、$m=1$ 输出 $\sum$、$n=1$、$[1,2,3,4,5]/m=2$ 输出 $9$ 均与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2884 [USACO07MAR] Monthly Expense S
// 二分答案 S∈[max a_i, sum a_i]；check：贪心从左到右尽量塞满一段，段数 ≤ m 即可行。
// a_i>0 保证"子段和 ≤ 整段和"，于是"≤m 段"与"恰好 m 段"等价（m≤n 可继续细分）。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n,m,a[mxn];

bool check(i64 s)	// 前提 s>=max a_i；返回最少段数是否 <=m
{
	int cnt=1;
	i64 cur=0;
	for(int i=0;i<n;++i)
	{
		if(cur+a[i]>s)
		{
			++cnt;
			cur=a[i];
			if(cnt>m)
				return false;
		}
		else
			cur+=a[i];
	}
	return true;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	i64 l=0,r=0;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		l=max(l,(i64)a[i]);	// 下界：含最大元素的那段至少这么大
		r+=a[i];			// 上界：一整段装下全部
	}
	while(l<r)
	{
		i64 mid=(l+r)>>1;
		if(check(mid))
			r=mid;
		else
			l=mid+1;
	}
	cout<<l<<'\n';
	return 0;
}
```

### 代码说明

- **二分框架**：`l=max a_i`、`r=sum`，`check(mid)` 真收右界、假抬左界，终态 `l` 即最小可行上限。下界取 $\max$ 而非 $0$，既剪枝又保证贪心里单元素恒塞得下。
- **贪心 check**：`cur+a[i]>s` 就封口开新段（`cur=a[i]`），否则累加。`cnt` 初值 $1$（第一段已开）。`cnt>m` 提前返回，省掉无谓扫描。
- **`i64` 的必要性**：$R\le10^9$ 虽未超 `int`，但 `cur+a[i]`、`l+r` 等中间量用 `i64` 彻底免溢出；`(l+r)>>1` 在 `i64` 下安全。
- **没有显式处理"恰好 $m$ 段"**：引理 3 已证 $\le m$ 与恰好 $m$ 等价，贪心判 $\le m$ 即可，代码无需真的劈段。
- 0-based 读入，`'\n'` 换行，全局静态数组。
