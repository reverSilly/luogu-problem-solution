# P2807 三角形计数 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 把一个大（等边）三角形的每条边 $n$ 等分，过对应等分点作平行于三条边的连线，形成一张三角形网格。问图里**一共**有多少个三角形（各种大小、各种朝向都算）。$t\le100$ 组询问，每组 $n\le500$。

**第一步：先手画小情况，别急着找公式。**

- $n=1$：就一个大三角形，$1$ 个。
- $n=2$：每边中点连线，把大三角形切成 $4$ 个小三角形——$3$ 个朝上、$1$ 个朝下（倒扣在中心）；再加上大三角形本身（朝上、边长 $2$）。共 $3+1+1=5$ 个。
- $n=3$：朝上的单位小三角形 $6$ 个、朝下的 $3$ 个；边长 $2$ 朝上的 $3$ 个；边长 $3$ 朝上的 $1$ 个（大三角形）。共 $6+3+3+1=13$ 个。

得到序列 $1,5,13,\dots$。差分 $4,8,\dots$ 不算整齐，硬凑递推容易翻车。但我注意到一个**结构性事实**：所有三角形要么"朝上"（与大三角形同向），要么"朝下"（倒扣）。**按朝向分类**，分别数，应该各自有规律。

**第二步：抓住"线只有三个方向"。** 图里所有直线都平行于大三角形的某条边，所以只有三个方向。任何一个三角形由三条两两不平行的线围成，于是**恰好每个方向各取一条**。这样的三角形必然与大三角形相似（等边），朝向只有上/下两种，边长是正整数（线间距都是 $1$ 个单位）。这就把"数三角形"拆成了两个干净的子问题：数边长为 $k$ 的朝上三角形、数边长为 $k$ 的朝下三角形。

**第三步：用坐标把"朝上、边长 $k$"数清楚。** 沿大三角形两条边建斜坐标：格点 $(a,b)$，$a,b\ge0$、$a+b\le n$（$a$ 是沿一条边走的步数，$b$ 是沿另一条边的步数）。三族网格线就是 $a=\text{常数}$、$b=\text{常数}$、$a+b=\text{常数}$。一个朝上、边长 $k$ 的三角形，顶点（最上方的角）在 $(a,b)$，另两个顶点是 $(a+k,b)$ 与 $(a,b+k)$。三个顶点都要落在网格内，最紧的约束是 $a+b+k\le n$。令行号 $r=a+b$，则 $r\le n-k$；第 $r$ 行有 $r+1$ 个格点（$a=0..r$）。所以朝上边长 $k$ 的个数 $=\sum_{r=0}^{n-k}(r+1)=1+2+\dots+(n-k+1)=T(n-k+1)$，其中 $T(m)=\frac{m(m+1)}2$ 是三角形数。验证 $n=3,k=1$：$T(3)=6$ ✓。

**第四步：朝下的三角形要"缩得更狠"。** 朝下、边长 $k$ 的三角形，上面一条水平边、下面一个尖角，三顶点是 $(a,b)$、$(a-k,b+k)$、$(a,b+k)$。约束里最紧的是尖角 $(a,b+k)$ 要求 $a+b+k\le n$，同时左上角要求 $a\ge k$。令 $a'=a-k\ge0$，则 $a'+b\le n-2k$。于是个数 $=\sum_{r=0}^{n-2k}(r+1)=T(n-2k+1)$，**前提是 $n-2k\ge0$**（即 $2k\le n$），否则一个都没有。这解释了为什么朝下三角形又少又小：$n=3$ 时只有 $k=1$（$T(2)=3$ 个），$k=2$ 需要 $n\ge4$ 才出现。验证 $n=4,k=2$：$T(1)=1$ ✓（正中心那个倒扣的边长 $2$ 三角形）。

**第五步：求和、化简。** 朝上总数 $\sum_{k=1}^n T(n-k+1)=\sum_{j=1}^n T(j)=\frac{n(n+1)(n+2)}6$。朝下总数 $\sum_{k=1}^{\lfloor n/2\rfloor}T(n-2k+1)$。两者相加，按 $n$ 奇偶分别展开（下面引理 5 完整算），结果惊人地统一：

$$\text{答案}=\left\lfloor\frac{n(n+2)(2n+1)}8\right\rfloor.$$

$n$ 偶时整除；$n$ 奇时乘积 $\equiv1\pmod8$，下取整恰好减掉 $\frac18$。回代 $n=1,2,3,4,5$：$\lfloor9/8\rfloor=1$、$40/8=5$、$\lfloor105/8\rfloor=13$、$216/8=27$、$\lfloor385/8\rfloor=48$，与手画/手算逐一吻合。

**第六步：落地。** C++ 正整数除法就是下取整，所以一行 `n*(n+2)*(2*n+1)/8` 搞定。$n\le500$ 时乘积 $\le500\times502\times1001=251251000<2^{31}$，`int` 都装得下，但我用 `i64` 更稳。$t$ 组循环输出即可。这是基本公式题，无需对拍。

## 二、思维链：完整证明

**记号.** 斜坐标格点 $(a,b)$，$a,b\in\mathbb Z_{\ge0}$，$a+b\le n$。三族线：$a=c$、$b=c$、$a+b=c$（$c$ 整数）。三角形数 $T(m)=\frac{m(m+1)}2$（$m\ge0$，$T(0)=0$）。

### 引理 1（图中三角形的结构）

图中每个三角形恰好由三族线各一条围成，与大三角形相似，朝向为上或下，边长为正整数。

*证明*：三角形的三条边两两不平行（否则围不成三角形）。图中所有线只属于三个平行族，故三条边必分属三个不同族，每族恰一条。三族线两两夹角固定（等于大三角形的内角 $60^\circ$），故围成的三角形三个内角都是 $60^\circ$，是等边三角形，与大三角形相似。其边要么平行于大三角形的边且同向（朝上），要么反向（朝下），只有这两种朝向。相邻平行线间距为 $1$ 单位，三角形每条边跨越整数个间距，故边长 $k\in\mathbb Z_{\ge1}$。证毕。

### 引理 2（朝上、边长 $k$ 的个数）

朝上边长 $k$（$1\le k\le n$）的三角形个数为 $T(n-k+1)=\frac{(n-k+1)(n-k+2)}2$。

*证明*：朝上三角形顶点（上角）在格点 $(a,b)$，两底角为 $(a+k,b)$、$(a,b+k)$（沿两族线各走 $k$ 步）。三顶点均在网格内 $\iff$ 各坐标 $\ge0$ 且各坐标和 $\le n$。$(a,b)$：$a+b\le n$；$(a+k,b)$：$a+b+k\le n$；$(a,b+k)$：$a+b+k\le n$。最紧约束为 $a+b+k\le n$，且 $a,b\ge0$。令 $r=a+b$，则 $0\le r\le n-k$；对固定 $r$，$a$ 可取 $0,1,\dots,r$（$b=r-a\ge0$），共 $r+1$ 个。故总数 $=\sum_{r=0}^{n-k}(r+1)=\sum_{s=1}^{n-k+1}s=T(n-k+1)$。每个合法 $(a,b)$ 唯一确定一个三角形，反之每个朝上边长 $k$ 三角形有唯一上角 $(a,b)$，故为双射，计数无重无漏。证毕。

### 引理 3（朝下、边长 $k$ 的个数）

朝下边长 $k$ 的三角形个数为：若 $2k\le n$ 则 $T(n-2k+1)=\frac{(n-2k+1)(n-2k+2)}2$，否则 $0$。

*证明*：朝下三角形上边水平、下为尖角，三顶点为左上 $(a,b)$、右上 $(a-k,b+k)$、下尖 $(a,b+k)$（验证：左上沿 $b$ 族线走 $k$ 步到下尖 $(a,b+k)$；右上沿 $a$ 族线走 $k$ 步到 $(a-k+k,b+k)=(a,b+k)$，重合，确为三角形）。三顶点在网格内的约束：
- 左上 $(a,b)$：$a,b\ge0$，$a+b\le n$；
- 右上 $(a-k,b+k)$：$a-k\ge0\Rightarrow a\ge k$，$b+k\ge0$ 自动，和 $a+b\le n$；
- 下尖 $(a,b+k)$：$a\ge0$，$b+k\ge0$，和 $a+b+k\le n$。

合并最紧约束：$a\ge k$、$b\ge0$、$a+b+k\le n$。令 $a'=a-k\ge0$，则 $a'+b\le n-2k$。当 $n-2k<0$ 时无解，个数 $0$。当 $n-2k\ge0$：令 $r=a'+b\in[0,n-2k]$，每行 $r+1$ 个，总数 $=\sum_{r=0}^{n-2k}(r+1)=T(n-2k+1)$。$(a',b)\leftrightarrow(a,b)$ 是双射，每个朝下三角形有唯一左上角，计数无重无漏。证毕。

### 引理 4（朝上总数）

$\sum_{k=1}^n T(n-k+1)=\frac{n(n+1)(n+2)}6$。

*证明*：令 $j=n-k+1$，$k$ 从 $1$ 到 $n$ 时 $j$ 从 $n$ 到 $1$，故和 $=\sum_{j=1}^n T(j)=\frac12\sum_{j=1}^n(j^2+j)=\frac12\bigl[\frac{n(n+1)(2n+1)}6+\frac{n(n+1)}2\bigr]=\frac{n(n+1)}2\cdot\frac{(2n+1)+3}{6}=\frac{n(n+1)(2n+4)}{12}=\frac{n(n+1)(n+2)}6$。证毕。

### 引理 5（总数 closed form）

朝上总数加朝下总数 $=\left\lfloor\frac{n(n+2)(2n+1)}8\right\rfloor$。

*证明*：分奇偶。

**$n=2m$ 偶。** 朝上 $=\frac{2m(2m+1)(2m+2)}6=\frac{2m(m+1)(2m+1)}3$。朝下：$k=1..m$，令 $j=m-k$（$j=0..m-1$），$n-2k+1=2j+1$，$T(2j+1)=\frac{(2j+1)(2j+2)}2=(2j+1)(j+1)=2j^2+3j+1$。求和 $\sum_{j=0}^{m-1}(2j^2+3j+1)=2\frac{(m-1)m(2m-1)}6+3\frac{(m-1)m}2+m=\frac{m(4m-1)(m+1)}6$（通分合并，见下）。于是总数 $=\frac{2m(m+1)(2m+1)}3+\frac{m(m+1)(4m-1)}6=\frac{m(m+1)}6[4(2m+1)+(4m-1)]=\frac{m(m+1)(12m+3)}6=\frac{m(m+1)(4m+1)}2$。而 $\frac{n(n+2)(2n+1)}8=\frac{2m(2m+2)(4m+1)}8=\frac{m(m+1)(4m+1)}2$，相等且为整数（$m(m+1)$ 必偶）。

（朝下合并细节：$2\frac{(m-1)m(2m-1)}6+3\frac{(m-1)m}2+m=\frac{2(m-1)m(2m-1)+9(m-1)m+6m}6=\frac{m[2(m-1)(2m-1)+9(m-1)+6]}6=\frac{m[(m-1)(4m+7)+6]}6=\frac{m(4m^2+3m-1)}6=\frac{m(4m-1)(m+1)}6$。）

**$n=2m+1$ 奇。** 朝上 $=\frac{(2m+1)(2m+2)(2m+3)}6=\frac{(2m+1)(m+1)(2m+3)}3$。朝下：$k=1..m$，令 $j=m+1-k$（$j=1..m$），$n-2k+1=2j$，$T(2j)=\frac{2j(2j+1)}2=j(2j+1)=2j^2+j$。求和 $\sum_{j=1}^m(2j^2+j)=2\frac{m(m+1)(2m+1)}6+\frac{m(m+1)}2=\frac{m(m+1)(4m+5)}6$。总数 $=\frac{(2m+1)(m+1)(2m+3)}3+\frac{m(m+1)(4m+5)}6=\frac{m+1}6[2(2m+1)(2m+3)+m(4m+5)]=\frac{m+1}6[8m^2+16m+6+4m^2+5m]=\frac{(m+1)(12m^2+21m+6)}6=\frac{(m+1)(4m^2+7m+2)}2$。

另一方面 $P=n(n+2)(2n+1)=(2m+1)(2m+3)(4m+3)=16m^3+44m^2+36m+9$。$\frac{P-1}8=\frac{16m^3+44m^2+36m+8}8=2m^3+\frac{11}2m^2+\frac92m+1=\frac{4m^3+11m^2+9m+2}2=\frac{(m+1)(4m^2+7m+2)}2$，恰等于总数。又 $n$ 奇时 $n,n+2,2n+1$ 全奇，$P$ 奇；逐余数验证 $n\equiv1,3,5,7\pmod8$ 时 $P\equiv1\pmod8$（$1\cdot3\cdot3=9$、$3\cdot5\cdot7=105$、$5\cdot7\cdot3=105$、$7\cdot1\cdot7=49$，均 $\equiv1$），故 $\lfloor P/8\rfloor=(P-1)/8=$ 总数。

两情形都得总数 $=\lfloor n(n+2)(2n+1)/8\rfloor$。证毕。

### 引理 6（整数除法与范围）

C++ 中 `n*(n+2)*(2*n+1)/8`（正整数）等于 $\lfloor n(n+2)(2n+1)/8\rfloor$；$n\le500$ 时乘积 $\le251251000$，`i64` 无溢出。

*证明*：C++ 整数除法向零截断，被除数与除数均正，故等于下取整。乘积关于 $n$ 单调增，$n=500$ 时 $500\times502\times1001=251251000<2^{31}-1<2^{63}-1$，`i64` 安全（实际 `int` 也够，用 `i64` 留余量）。证毕。

### 定理

程序对每个 $n$ 输出图中三角形总数 $\lfloor n(n+2)(2n+1)/8\rfloor$。

*证明*：引理 1 把三角形按朝向与边长分类；引理 2、3 给出各类个数；引理 4、5 求和化简为 closed form；引理 6 保证一行整数除法正确且无溢出。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 手画 $n=1,2,3$ 得 $1,5,13$；发现三角形只有"朝上/朝下"两种朝向。
2. **explore its property** — 线只有三个方向 ⇒ 每个三角形三族线各取一条 ⇒ 等边、整数边长、上/下两类。
3. **discuss by category** — 按朝向拆分：朝上边长 $k$ 与朝下边长 $k$ 分别计数。
4. **classic problem solution** — 斜坐标格点 $(a,b)$，$a+b\le n$；朝上个数 $T(n-k+1)$，朝下个数 $T(n-2k+1)$（需 $2k\le n$），都是三角形数。
5. **reduce to easier problem** — 两类各自求和：朝上 $\frac{n(n+1)(n+2)}6$，朝下按奇偶展开，合并化简。
6. **classic problem solution** — 统一 closed form $\lfloor n(n+2)(2n+1)/8\rfloor$；正整数除法即下取整，一行输出。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `t` | 询问组数，$\le100$ | `int` | 读入 |
| `n` | 每边等分数，$\le500$ | `i64` | 每组读入；用 `i64` 防乘积溢出 |
| `T(m)` | 三角形数 $\frac{m(m+1)}2$ | 数学记号 | 计数基本块，代码不显式出现 |
| 答案 | $\lfloor n(n+2)(2n+1)/8\rfloor$ | `i64` | 一行整数除法 |

（本题无数组状态，纯公式。）

### 算法步骤

1. I/O 加速三行；读 `t`。
2. 每组读 `n`，输出 `n*(n+2)*(2*n+1)/8` 与 `'\n'`。

### 复杂度

- 时间 $O(t)$，每组 $O(1)$；空间 $O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$n=1..5$ 输出 $1,5,13,27,48$，与手画/手算及引理 5 逐一吻合（基本公式题，按规范不做对拍）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2807 三角形计数
// 朝上边长 k：T(n-k+1)；朝下边长 k：T(n-2k+1)(需 2k<=n)
// 两类求和化简 = floor(n(n+2)(2n+1)/8)，正整数除法即下取整
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int t;
	cin>>t;
	while(t--)
	{
		i64 n;
		cin>>n;
		cout<<n*(n+2)*(2*n+1)/8<<'\n';	// n 奇时乘积 ≡1(mod 8)，截断恰好减 1/8
	}
	return 0;
}
```

### 代码说明

- 核心就一行公式，正确性由引理 2–5 的完整计数与代数化简保证，不是"凑出来的"。
- `n` 用 `i64`：虽然 $n\le500$ 时乘积 $2.5\times10^8$ 在 `int` 内，`i64` 留足余量、杜绝中间溢出。
- 正整数 `/8` 向零截断 = 下取整，自动处理 $n$ 奇偶两种情况，无需 `if` 分支。
- 无数组、无递归、无哨兵，$O(1)$ 每组；`'\n'` 换行。
