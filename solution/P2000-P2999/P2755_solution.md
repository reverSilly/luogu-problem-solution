# P2755 洗牌问题 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $2n$ 张牌，初始顺序 $1,2,\dots,n,n+1,\dots,2n$。一次洗牌把序列变成
$$n+1,\,1,\,n+2,\,2,\,n+3,\,3,\,\dots,\,2n,\,n,$$
也就是把后半段依次插到前半段每张牌前面。给定 $n\le 10^8$，求**最少**多少次洗牌后第一次回到初始顺序 $m$。题面没有样例，下面的例子都是我手算并用程序核对过的。

**第一反应：直接模拟整副牌。** 开一个 $2n$ 的数组，每次按规则重排，数到回到 $1..2n$ 为止。但 $2n$ 最大 $2\times10^8$，光数组就 $800$ MB；而且 $m$ 本身可能很大，每轮还要 $O(n)$ 重排——时间和空间都爆。这条路一眼死。

**第二步：把"整副牌"缩成"一张牌"。** 洗牌规则对每张牌是**一视同仁**的：它只跟牌当前所在的**位置**有关，跟牌面数字无关。换句话说，洗牌是位置集合 $\{1,\dots,2n\}$ 上的一个**固定置换** $f$——"原来在位置 $i$ 的牌，洗一次后跑到位置 $f(i)$"。既然所有牌都按同一个 $f$ 移动，我只要盯住**一张牌**（比如 1 号牌）的位置怎么变就够了。这是本题第一个关键简化：$2n$ 张牌 $\to$ 一个位置置换。

**第三步：把 $f$ 写出来，发现它是"乘 2 取模"。** 设当前序列为 $a$，洗后为 $b$，规则是 $b_{2k-1}=a_{n+k}$、$b_{2k}=a_k$（$k=1..n$）。于是：

- 原来在位置 $k\le n$ 的牌（前半段），洗后落在位置 $2k$，即 $f(k)=2k$；
- 原来在位置 $n+k$ 的牌（后半段），洗后落在位置 $2k-1$，即 $f(n+k)=2k-1=2(n+k)-2n-1$。

两段合起来看：令 $M=2n+1$，则
$$f(i)\equiv 2i\pmod M,\qquad f(i)\in\{1,\dots,2n\}.$$
验证：$i\le n$ 时 $2i\le 2n<M$，取模就是 $2i$；$i>n$ 时 $2n<2i\le 4n<2M$，取模是 $2i-M=2i-2n-1$。**这个 interleaving 恰好就是模 $2n+1$ 的乘 2！** 这是全题的支点。

**第四步：回到初始顺序 $\iff 2^m\equiv 1$。** 洗 $m$ 次就是 $f$ 复合 $m$ 次：$f^m(i)\equiv 2^m i\pmod M$。整副牌回到初始 $\iff$ 每张牌都回到原位 $\iff f^m(i)=i$ 对所有 $i$。取 $i=1$ 得必要条件 $2^m\equiv 1\pmod M$；反过来若 $2^m\equiv 1$，则 $f^m(i)\equiv i$，而两边都落在 $\{1,\dots,2n\}$（模 $M$ 的非零剩余），只能相等，故充分。于是
$$m=\operatorname{ord}_M(2)\quad(\text{2 模 }2n+1\text{ 的乘法阶}).$$
$M=2n+1$ 是奇数，$\gcd(2,M)=1$，阶一定存在，且整除 $\varphi(M)\le M-1=2n$。问题从"模拟 $2n$ 张牌"彻底塌缩成"求一个数的乘法阶"。

**第五步：怎么求阶，以及一个卡常细节。** 最朴素：$x=2$，$m=1$，不断 $x\leftarrow 2x\bmod M$、$m{+}{+}$，直到 $x=1$。循环次数 $=\operatorname{ord}_M(2)\le 2n\le 2\times10^8$。如果每次都用 `long long` 的 `%`，硬件除法有几十周期延迟、又是循环携带依赖，$2\times10^8$ 次可能要一两秒。但注意 $x<M\le 2\times10^8+1$，所以 $2x<4\times10^8+2<2^{31}$，**`int` 装得下**，取模可以换成"翻倍后若 $\ge M$ 就减 $M$"——两三条指令搞定。实测 $n=10^8$ 仅 $0.14$ s。

**手算校验：**

- $n=1$：$M=3$，$2^1=2,2^2=4\equiv1$ → $m=2$。直接洗：$[1,2]\to[2,1]\to[1,2]$，$2$ 次 ✓。
- $n=2$：$M=5$，$2,4,3,1$ → $m=4$。$[1,2,3,4]\to[3,1,4,2]\to[4,3,2,1]\to[2,4,1,3]\to[1,2,3,4]$，$4$ 次 ✓。
- $n=3$：$M=7$，$2,4,1$ → $m=3$。$[1..6]\to[4,1,5,2,6,3]\to[2,4,6,1,3,5]\to[1..6]$，$3$ 次 ✓。

## 二、思维链：完整证明

**记号。** 位置集合 $P=\{1,2,\dots,2n\}$，$M=2n+1$（奇数，$M\ge3$）。洗牌置换 $f:P\to P$ 定义为"原位置 $i$ 的牌洗一次后的新位置"。$\operatorname{ord}_M(2)$ 表示满足 $2^m\equiv1\pmod M$ 的最小正整数 $m$。

### 引理 1（洗牌置换的显式与"乘 2"刻画）

$$f(i)=\begin{cases}2i,&1\le i\le n,\\ 2i-2n-1,&n<i\le 2n,\end{cases}$$
且 $f(i)$ 恰为 $2i\bmod M$ 落在 $\{1,\dots,2n\}$ 中的唯一剩余；$f$ 是 $P$ 上的双射。

*证明*：由洗牌规则 $b_{2k-1}=a_{n+k}$、$b_{2k}=a_k$：原位置 $k\le n$ 的牌出现在 $b$ 的第 $2k$ 位，故 $f(k)=2k$；原位置 $n+k$ 的牌出现在第 $2k-1$ 位，故 $f(n+k)=2k-1$，代入 $i=n+k$ 得 $f(i)=2(i-n)-1=2i-2n-1$。

模刻画：$i\le n$ 时 $2\le 2i\le 2n<M$，故 $2i\bmod M=2i=f(i)$。$n<i\le 2n$ 时 $2n<2i\le 4n$，而 $M=2n+1$、$2M=4n+2$，故 $2i<2M$ 且 $2i>M$（因 $2i\ge 2n+2>M$），于是 $2i\bmod M=2i-M=2i-2n-1=f(i)$，且其范围 $i=n+1\mapsto1$、$i=2n\mapsto 2n-1$，落在 $\{1,\dots,2n\}$。两段都等于"$2i$ 模 $M$ 的非零剩余"。

双射：$i\mapsto 2i\bmod M$ 在 $\{1,\dots,M-1\}$ 上是单射（$2$ 与 $M$ 互素，$2i\equiv2j\Rightarrow i\equiv j$，而 $i,j\in\{1..2n\}$ 模 $M$ 不同余），定义域陪域都是 $P=\{1..M-1\}$，有限集单射即双射。证毕。

### 引理 2（$m$ 次洗牌 = 乘 $2^m$）

对任意 $m\ge1$、$i\in P$，$f^m(i)$ 等于 $2^m i\bmod M$ 落在 $\{1,\dots,2n\}$ 的剩余。

*证明*：对 $m$ 归纳。$m=1$ 即引理 1。设 $m-1$ 成立，$f^{m-1}(i)\equiv 2^{m-1}i\pmod M$。则 $f^m(i)=f(f^{m-1}(i))\equiv 2\cdot f^{m-1}(i)\equiv 2\cdot 2^{m-1}i=2^m i\pmod M$（引理 1 对任意自变量成立）。又 $f^m(i)\in P$，故它就是该剩余。证毕。

### 引理 3（回到初始 $\iff 2^m\equiv1\pmod M$）

洗 $m$ 次后整副牌恢复初始顺序 $\iff 2^m\equiv1\pmod M$。

*证明*：初始时位置 $i$ 上是牌 $i$；洗 $m$ 次后位置 $f^m(i)$ 上是牌 $i$。恢复初始 $\iff$ 每张牌 $i$ 都在位置 $i$ $\iff f^m(i)=i$ 对所有 $i\in P$。

（$\Rightarrow$）取 $i=1$：$f^m(1)=1$，由引理 2，$2^m\cdot1\bmod M=1$，即 $2^m\equiv1\pmod M$。

（$\Leftarrow$）若 $2^m\equiv1$，则对任意 $i$，$f^m(i)\equiv 2^m i\equiv i\pmod M$。而 $f^m(i)\in P=\{1..M-1\}$、$i\in P$，两者模 $M$ 同余且都在 $\{1,\dots,M-1\}$ 内，故相等。于是 $f^m(i)=i$ 对所有 $i$，恢复初始。证毕。

### 引理 4（最小 $m$ 就是乘法阶，且存在、$\le 2n$）

满足引理 3 条件的最小正整数 $m=\operatorname{ord}_M(2)$；它存在且整除 $\varphi(M)$，从而 $\le\varphi(M)\le M-1=2n$。

*证明*：$M$ 奇 $\Rightarrow\gcd(2,M)=1\Rightarrow 2$ 是模 $M$ 既约剩余系 $(\mathbb Z/M)^\times$ 的元素。该群有限（阶 $\varphi(M)$），由拉格朗日定理，元素 $2$ 的阶 $\operatorname{ord}_M(2)$ 存在且整除 $\varphi(M)$。集合 $\{m\ge1:2^m\equiv1\}$ 恰为 $\operatorname{ord}_M(2)$ 的正倍数集（带余除法：$m=q\cdot\operatorname{ord}+r$，$2^m\equiv(2^{\operatorname{ord}})^q 2^r\equiv 2^r$，故 $2^m\equiv1\iff 2^r\equiv1\iff r=0$），最小元即 $\operatorname{ord}_M(2)$。又 $\varphi(M)\le M-1=2n$。证毕。

### 引理 5（模拟循环正确且终止）

程序令 $x=2$、$ans=1$，循环体 $x\leftarrow 2x\bmod M$、$ans{+}{+}$，直到 $x=1$。则循环不变量为 $x=2^{ans}\bmod M$（取 $\{1..M-1\}$ 剩余），退出时 $ans=\operatorname{ord}_M(2)$。

*证明*：初始 $x=2=2^1\bmod M$（$M\ge3$），$ans=1$，不变量成立。每轮 $x\leftarrow 2x\bmod M=2\cdot2^{ans}\bmod M=2^{ans+1}\bmod M$，$ans\leftarrow ans+1$，不变量保持。$x$ 始终非零（$2$ 是单位，其幂也是单位，$\not\equiv0$），故 $x\in\{1..M-1\}$。由引理 4，存在 $ans=\operatorname{ord}_M(2)$ 使 $x=1$，循环必在此退出；而退出条件是 $x=1$ 即 $2^{ans}\equiv1$，第一次满足的最小 $ans$ 正是阶。证毕。

### 引理 6（`int` 与条件减法的安全性）

$M=2n+1\le 200000001<2^{31}$；循环中 $x\in[1,M-1]$，故 $2x\le 2M-2\le 400000000<2^{31}-1$，`x+=x` 不溢出；且 $2x<2M$，故"$2x\ge M$ 则减 $M$"恰给出 $2x\bmod M$。$ans\le 2n\le 2\times10^8<2^{31}$，`int` 足够。

*证明*：$n\le10^8\Rightarrow M\le200000001$。$x\le M-1\Rightarrow 2x\le 2M-2=400000000<2147483647$，加法安全。$0\le 2x<2M$，故 $2x\bmod M$ 等于 $2x$（若 $2x<M$）或 $2x-M$（若 $M\le 2x<2M$），正是条件减法。阶 $\le2n$（引理 4）故 $ans$ 不溢出。证毕。

### 定理

程序输出 $\operatorname{ord}_{2n+1}(2)$，即题目所求最小洗牌次数 $m$；时间 $O(m)\le O(n)$，空间 $O(1)$。

*证明*：引理 1–3 把"恢复初始"等价于 $2^m\equiv1\pmod{2n+1}$；引理 4 给出最小 $m$ 为乘法阶且 $\le2n$；引理 5 保证模拟循环算出的正是阶；引理 6 保证 `int` 与条件减法无溢出、取模等价。每轮 $O(1)$、共 $m\le2n$ 轮，故 $O(n)$ 时间；只用常数个变量，$O(1)$ 空间。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 洗牌对每张牌一视同仁，是位置集合上的固定置换 $f$，与牌面数字无关。
- consider easier version — 放弃模拟 $2n$ 张牌，改为只盯一张牌的位置（盯住置换即可）。
- explore its property — 写出 $f$：前半 $f(i)=2i$、后半 $f(i)=2i-2n-1$，统一为 $f(i)\equiv2i\pmod{2n+1}$。
- reduce to easier problem — "整副恢复初始" $\iff 2^m\equiv1\pmod{2n+1}$ $\iff m=\operatorname{ord}_{2n+1}(2)$（乘法阶）。
- classic problem solution — 反复翻倍取模求阶；$M$ 奇保证阶存在且 $\le\varphi(M)\le2n$。
- discuss by category — 卡常：$x<M\le2\times10^8+1\Rightarrow 2x<2^{31}$，用 `int` 条件减法代替慢速 `%`，极限 $0.14$ s。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 半副牌数，$1\le n\le10^8$ | `int`，读入 | 总牌数 $2n$ |
| `M` | 模数 $2n+1$（奇数） | `int`，`2*n+1` | "乘 2 取模"的模 |
| `x` | 当前 $2^{ans}\bmod M$ 的剩余 | `int`，初值 $2$ | 始终 $\in[1,M-1]$，永不为 $0$ |
| `ans` | 已洗次数，即当前指数 | `int`，初值 $1$ | 退出时 $=\operatorname{ord}_M(2)$ |

### 算法步骤

1. I/O 加速三行。
2. 读 `n`，令 `M=2*n+1`、`x=2`、`ans=1`（$M\ge3$ 故 $2\bmod M=2$）。
3. 当 `x!=1`：`x+=x`；若 `x>=M` 则 `x-=M`（等价 $x\leftarrow 2x\bmod M$）；`++ans`。
4. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(\operatorname{ord}_{2n+1}(2))\le O(2n)=O(n)$；每轮常数条指令，$n=10^8$ 实测 $0.14$ s。
- 空间：$O(1)$。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；题面无样例，手造 $n=1,2,3,4,5$ 五组（期望 $2,4,3,6,10$）逐条吻合，其中 $n=1,2,3$ 另用整副牌手工洗牌核对；$n=10^8$ 极限数据输出 $22222222$、运行 $0.14$ s。本题为公式/数论题，证明已闭合，未写暴力对拍脚本。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2755 洗牌问题
// 洗牌是位置置换 f(i)≡2i (mod 2n+1)；整副恢复初始 ⟺ 2^m≡1 (mod 2n+1)
// 故 m = 2 模 (2n+1) 的乘法阶，反复翻倍取模即可
// x<M<=2e8+1 ⇒ 2x<2^31，用 int 条件减法代替慢速 %，极限 0.14s
#include<bits/stdc++.h>
using namespace std;

int n,ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	int M=2*n+1;		// 模数，奇数 ⇒ gcd(2,M)=1，阶存在
	int x=2;			// M>=3 ⇒ 2%M=2，即 2^1
	ans=1;
	while(x!=1)			// 第一次 2^ans≡1 即乘法阶
	{
		x+=x;			// 2x<4e8+2<int 上限，条件减法 = 取模
		if(x>=M)
			x-=M;
		++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **只追踪一个剩余 `x`**：由引理 3，整副牌恢复初始等价于 $2^m\equiv1$，所以根本不需要牌数组，$O(1)$ 空间。
- `x=2` 而非 `2%M`：$M=2n+1\ge3$，$2\bmod M=2$ 恒成立，省一次取模，也避免误用未初始化的变量。
- **条件减法代替 `%`**：$x<M\le2\times10^8+1\Rightarrow 2x<2^{31}$（引理 6），`x+=x; if(x>=M)x-=M;` 与 `x=x*2%M` 完全等价，但避开硬件除法延迟，这是极限数据能 $0.14$ s 的关键。
- `x` 永不为 $0$（$2$ 是模奇数 $M$ 的单位），循环一定在 $x=1$ 处终止，不会死循环。
- `ans` 上界 $2n\le2\times10^8$，`int` 安全；全程无 `long long`、无浮点。
