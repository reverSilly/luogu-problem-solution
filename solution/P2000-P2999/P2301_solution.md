# P2301 就是干！ — 题解

## 一、解题过程：人类思考叙事

题意：有 $m$ 根木棍，长度已知；有 $n$ 个人，每人要拿**两根**木棍（一根投掷、一根近战）。第 $i$ 个人的不舒服指数是 $(L_1-L_2)^2$，总矛盾指数是所有人的不舒服指数之和。求最小的总矛盾指数。数据范围 $m\le 2000$，$n\le 500$，且「肯定有解」，意味着 $m\ge 2n$——也就是**从 $m$ 根里挑出 $2n$ 根，再两两配对**。

**先看暴力能做多大。** 枚举「挑哪 $2n$ 根」有 $\binom{m}{2n}$ 种，再枚举「怎么配对」有 $(2n-1)!!$ 种。$m=2000,n=500$ 时这是天文数字，毫无希望。必须找结构。

**结构从哪来？看代价函数。** $(L_1-L_2)^2$ 对「长度差」是**平方级惩罚**：两根差 $10$ 贡献 $100$，差 $20$ 贡献 $400$。这强烈暗示：**长度相近的应该配在一起**。于是第一步自然是对长度排序——排序不改变答案（配对只与长度多重集有关），但让「相近」变成「相邻」。

**先试贪心，立刻翻车。** 最自然的贪心是「每次取出当前距离最近的两根配成一对」。用长度 $1,2,3,4$（$n=2$）试一试：距离最近的有三对 $(1,2),(2,3),(3,4)$，贪心若随手挑了 $(2,3)$，代价 $1$；剩下 $(1,4)$，代价 $9$；总共 $10$。可是最优却是 $(1,2)+(3,4)=1+1=2$。贪心差了 $5$ 倍。

翻车的原因很清楚：「当前最近」是**局部**最优，而挑走中间两根会把两端的「孤儿」逼到一起，产生一个巨大的平方代价。这提示我们：正确的结构不是「任意相近」，而是**排序后按顺序两两相邻**。但这只是猜测，必须证明，否则换个数据又可能翻车。

**把问题拆成两层。** 完整问题有两个决策：① 挑哪些木棍；② 怎么配对。为了不被两件事同时干扰，先解**简化版**：假如恰好只有 $2n$ 根木棍、必须全部用上，最优配对是什么？猜想是「排序后第 $1$ 与第 $2$、第 $3$ 与第 $4$……」。用交换论证可以证明：若最小的两根没有配在一起，把它们的搭档互换，代价不会变大（证明见引理 1）。于是简化版的答案确定：相邻配对。

**回到原题：多出来的木棍怎么办？** 有了引理 1，任意一个「已选出的 $2n$ 根」内部都按相邻配对最优。接下来证明：可以假定**每一对在全局排序数组里也是相邻的**。理由是「压缩」：若某一对是 $(x,y)$ 而中间还夹着一根没被选中的木棍 $z$（$x\le z\le y$），那么把 $y$ 换成 $z$，这一对的代价 $(z-x)^2\le(y-x)^2$ 不会变大，其余各对原封不动。反复替换，直到每对都贴着。这一步把「选哪些」和「怎么配」两件事合并成了同一件事：**在排序数组上挑一些互不重叠的相邻对**。

**最后一层：DP。** 既然最优解可以写成「排序数组上一堆互不重叠的相邻对 $(i-1,i)$」，那就从左往右扫，决定「第 $i$ 根要不要和第 $i-1$ 根配」。状态 $dp[i][j]$：前 $i$ 根里配出 $j$ 对的最小代价。转移只有两种：不用第 $i$ 根（$dp[i-1][j]$），或让第 $i$ 根与第 $i-1$ 根成对（$dp[i-2][j-1]+(a_i-a_{i-1})^2$）。复杂度 $O(mn)=10^6$，轻松。

**手造数据核对。** 题面无样例，手造：

- `4 2 / 1 2 3 4`：最优 $(1,2)+(3,4)=1+1=2$。
- `3 1 / 1 5 10`：只能挑两根，$(1,5)$ 代价 $16$，$(5,10)$ 代价 $25$，$(1,10)$ 代价 $81$，最小 $16$。

两组程序输出 `2` 与 `16`，与手算一致。另外用 `5 2 / 1 2 100 101 200` 检查「允许丢弃木棍」的情形：最优 $(1,2)+(100,101)=2$，程序也输出 `2`。

## 二、思维链：完整证明

约定：把 $m$ 根木棍的长度排序为 $a_1\le a_2\le\dots\le a_m$。一个「方案」由两部分组成：选出的下标集合 $S\subseteq\{1,\dots,m\}$，$|S|=2n$；以及 $S$ 上的一个完美匹配 $M$（$n$ 条边）。方案的代价为 $\mathrm{cost}(M)=\sum_{(i,j)\in M}(a_i-a_j)^2$。记全局最优值为 $\mathrm{OPT}$。

**引理 1（定集合的最优配对是相邻配对）**：设 $b_1\le b_2\le\dots\le b_{2n}$ 是任意 $2n$ 个已选长度排好序的结果，则在所有完美匹配中，代价最小的是
$$(b_1,b_2),(b_3,b_4),\dots,(b_{2n-1},b_{2n}),$$
其代价为 $\sum_{t=1}^{n}(b_{2t}-b_{2t-1})^2$。

*证明*：对 $n$ 归纳。$n=1$ 时 $b_1,b_2$ 是仅有的两个元素，只能配成 $(b_1,b_2)$，唯一且最优。设 $n\ge2$，取任意一个最优匹配 $M$。设 $b_1$ 在 $M$ 中的搭档是 $b_c$，$b_2$ 的搭档是 $b_d$（$c,d\ge2$，$c\ne d$；若 $b_2$ 的搭档就是 $b_1$，即 $c=2$，则这一对已经是 $(b_1,b_2)$，直接进入归纳）。

若 $c\ne2$，则 $b_1,b_2,b_c,b_d$ 是四个互不相同的元素，且由排序有 $b_1\le b_2$、$b_c\ge b_2$、$b_d\ge b_2\ge b_1$。把原有的两条边 $(b_1,b_c)$、$(b_2,b_d)$ 换成 $(b_1,b_2)$ 与 $(b_c,b_d)$，其余边不变，得到同集合上的另一个完美匹配 $M'$。代价差为
$$
\begin{aligned}
&\ \bigl[(b_c-b_1)^2+(b_d-b_2)^2\bigr]-\bigl[(b_2-b_1)^2+(b_d-b_c)^2\bigr]\\
=&\ \bigl[(b_c-b_1)^2-(b_2-b_1)^2\bigr]+\bigl[(b_d-b_2)^2-(b_d-b_c)^2\bigr]\\
=&\ (b_c-b_2)(b_c+b_2-2b_1)+(b_c-b_2)(2b_d-b_2-b_c)\\
=&\ (b_c-b_2)\bigl[(b_c+b_2-2b_1)+(2b_d-b_2-b_c)\bigr]\\
=&\ 2(b_c-b_2)(b_d-b_1).
\end{aligned}
$$
因为 $b_c\ge b_2$、$b_d\ge b_1$，所以差值 $\ge0$，即 $\mathrm{cost}(M')\le\mathrm{cost}(M)$。$M'$ 含边 $(b_1,b_2)$，且仍是最优匹配。再看 $M'$ 在剩下 $b_3,\dots,b_{2n}$ 上的部分：若这剩下的 $2n-2$ 个元素存在更便宜的匹配，把它与 $(b_1,b_2)$ 拼起来就会比 $M'$ 更便宜，与 $M'$ 最优矛盾。故它在剩余部分上也是最优的，由归纳假设可化为 $(b_3,b_4),\dots,(b_{2n-1},b_{2n})$。证毕。

> 这段代数也解释了贪心为什么错：贪心挑的是「全局最近的一对」，它在式子里相当于让 $(b_c-b_2)(b_d-b_1)$ 的**符号**没法保证——挑走中间的一对会把两个远端元素留在一起，此时 $b_d-b_1$ 很大，差值就变成负的（新匹配更差）。

**引理 2（可以压缩到相邻下标）**：存在一个最优方案，其中每条匹配边的两个端点在原数组中的下标相邻。

*证明*：取一个最优方案 $(S,M)$，由引理 1 可设 $M$ 是 $S$ 内按长度排序后的相邻配对。当长度有并列时，排序用 $(\text{长度},\text{下标})$ 字典序打破并列——这不影响代价，因为长度相同的位置互换不改变任何一项 $(b_{2t}-b_{2t-1})^2$。

定义该方案的「跨度」为
$$\Phi=\sum_{(i,j)\in M}|i-j| .$$
若某条边 $(i,j)\in M$（$i<j$）在数组中不相邻，即 $j\ge i+2$，则下标 $i+1$ 的木棍**不在** $S$ 中：否则它的键 $(a_{i+1},i+1)$ 在字典序下严格位于 $(a_i,i)$ 与 $(a_j,j)$ 之间，$i$ 与 $j$ 就不可能成为 $S$ 排序后的相邻位置，与 $M$ 是相邻配对矛盾。令
$$S'=(S\setminus\{j\})\cup\{i+1\},\qquad M'=(M\setminus\{(i,j)\})\cup\{(i,i+1)\}.$$
$S'$ 仍是 $2n$ 根木棍，$M'$ 仍是 $S'$ 上的完美匹配（其余边端点都在 $S'$ 中）。由 $a_i\le a_{i+1}\le a_j$ 得 $(a_{i+1}-a_i)^2\le(a_j-a_i)^2$，故
$$\mathrm{cost}(M')=\mathrm{cost}(M)-(a_j-a_i)^2+(a_{i+1}-a_i)^2\le\mathrm{cost}(M)=\mathrm{OPT}.$$
而 $\mathrm{OPT}$ 是所有方案的最小值，所以 $\mathrm{cost}(M')=\mathrm{OPT}$，新方案仍最优。同时新方案的跨度
$$\Phi'=\Phi-|i-j|+|i-(i+1)|=\Phi-(j-i)+1<\Phi .$$
跨度是非负整数，故反复执行上述替换必然在有限步后停止。停止时不存在满足 $j\ge i+2$ 的匹配边，即每条匹配边的两个端点下标相邻。证毕。

> 注意：替换之后 $M'$ 未必仍是「$S'$ 内相邻配对」，但这不影响结论——我们只需要「存在一个最优方案，它的每条边都是相邻下标对」，而 DP 恰好枚举了所有这样的方案。

**引理 3（DP 状态的含义）**：记 $f(i,j)$ 为「在 $a_1,\dots,a_i$ 中选出 $j$ 条互不相交的相邻下标对（形如 $(t-1,t)$）的最小总代价」，不可行时为 $+\infty$。则 $dp[i][j]=f(i,j)$。

*证明*：对 $i$ 归纳。$i=0$ 时 $dp[0][0]=0=f(0,0)$，$dp[0][j]=+\infty=f(0,j)$（$j>0$）。

设 $i\ge1$。任取 $f(i,j)$ 的一个最优解（若 $f(i,j)=+\infty$ 则两种转移都取不到有限值，等式成立）。看下标 $i$ 是否被使用：

- 若 $i$ 未被使用，则该解完全落在 $a_1,\dots,a_{i-1}$ 内，代价 $\ge f(i-1,j)$；反之 $f(i-1,j)$ 的任一解也是 $f(i,j)$ 的可行解。故这一类的最小值就是 $f(i-1,j)=dp[i-1][j]$（归纳假设）。
- 若 $i$ 被使用，由于相邻对只能是 $(i-1,i)$，这条边唯一确定；去掉它剩下 $j-1$ 条互不相交的相邻对，全部落在 $a_1,\dots,a_{i-2}$ 内，代价为 $(a_i-a_{i-1})^2+f(i-2,j-1)$。反之任取 $f(i-2,j-1)$ 的解并添上边 $(i-1,i)$ 也是可行解。故这一类的最小值为 $(a_i-a_{i-1})^2+dp[i-2][j-1]$（归纳假设）。

两类互斥且穷尽，故 $f(i,j)=\min\{dp[i-1][j],\,(a_i-a_{i-1})^2+dp[i-2][j-1]\}=dp[i][j]$。证毕。

**定理（答案正确）**：$dp[m][n]=\mathrm{OPT}$。

*证明*：一方面，DP 的每一个取值都对应一个真实方案（$n$ 条相邻下标对即 $n$ 对木棍，恰好分给 $n$ 个人），所以 $dp[m][n]\ge\mathrm{OPT}$。另一方面，由引理 2 存在最优方案，其每条匹配边都是相邻下标对；这 $n$ 条边互不相交，是 $f(m,n)$ 的可行解，故 $f(m,n)\le\mathrm{OPT}$。由引理 3，$dp[m][n]=f(m,n)$。两式合并得 $dp[m][n]=\mathrm{OPT}$。证毕。

**引理 4（复杂度）**：时间 $O(mn)$，空间 $O(mn)$。

*证明*：状态数 $(m+1)(n+1)$，每个状态 $O(1)$ 转移。空间即 DP 表大小。证毕。

**关于 64 位**：单次代价 $(a_i-a_{i-1})^2$ 在长度达到 $10^9$ 量级时可达 $10^{18}$，若用 `int` 计算平方会直接溢出；因此差值、平方、DP 表统一用 `i64`（`long long`）。题面没有给出木棍长度的上界，若长度真能达到 $10^9$ 且 $n=500$，累加上限约 $5\times10^{20}$ 会超出 64 位，那种极端数据需要 `__int128`；按常规数据规模 `i64` 足够。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 代价是长度差的平方，对「配得远」有平方级惩罚，所以先排序，让「相近」变成「相邻」。
- **碰壁反例** — 「每次取当前最近的一对」的贪心在 $1,2,3,4$ 上给出 $10$，最优是 $2$：局部最近会把两个远端元素逼成一对。
- **consider easier version** — 先假设恰好 $2n$ 根、全部用上，猜「排序后相邻配对」。
- **classic problem solution** — 交换论证（四条边重连，代价差 $2(b_c-b_2)(b_d-b_1)\ge0$）证明引理 1：定集合时相邻配对最优。
- **reduce to easier problem** — 「压缩」：把某对里较远的那根换成夹在中间没被选的木棍，代价不增、跨度严格减，于是只需考虑「全局相邻下标对」。
- **classic problem solution** — 在排序数组上做线性 DP：$dp[i][j]=\min(dp[i-1][j],\,dp[i-2][j-1]+(a_i-a_{i-1})^2)$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $m$ | 木棍根数 | 读入 |
| $n$ | 人数（需要 $n$ 对） | 读入，题设保证 $m\ge2n$ |
| `a[1..m]` | 排序后的木棍长度 | 读入后 `sort(a+1,a+m+1)` |
| `dp[i][j]` | 前 $i$ 根木棍中凑出 $j$ 对的最小不舒服指数和 | 全置 `inf`，`dp[0][0]=0` |
| `inf` | 不可行哨兵 `1145141919810` | 注意全局数组默认 $0$，必须显式填 |
| 答案 | `dp[m][n]` | 直接输出 |

### 算法步骤

1. 读入 $m,n$，再读入 $m$ 个长度到 `a[1..m]`，升序排序。
2. 把整个 DP 表填成 `inf`（`fill_n(&dp[0][0], mxn*mxk, inf)`），令 `dp[0][0]=0`。
3. 对 $i=1..m$、$j=0..n$：
   1. 先继承「不用第 $i$ 根」：`dp[i][j]=dp[i-1][j]`。
   2. 若 $j\ge1$ 且 $i\ge2$ 且 `dp[i-2][j-1]` 有限，则用 `dp[i-2][j-1]+(a[i]-a[i-1])*(a[i]-a[i-1])` 更新 `dp[i][j]`。
4. 输出 `dp[m][n]`。

### 复杂度

- 时间复杂度：$O(mn)\le 2000\times500=10^6$。
- 空间复杂度：$O(mn)$，即 $2005\times505\times8$ B $\approx 8$ MB。
- 极限数据 $m=2000,n=500$ 实测约 $0.04$ s。

### 验证状态

- 编译：`g++ -std=c++20 -O2 -Wall` 无错误无警告。
- 题面无样例，手造 4 组：`4 2 / 1 2 3 4 → 2`、`3 1 / 1 5 10 → 16`、`5 2 / 1 2 100 101 200 → 2`、`6 2 / 1 2 3 100 101 102 → 2`，全部与手算一致。
- 对拍：暴力程序**枚举所有 $\binom{m}{2n}$ 个子集，并对每个子集递归枚举全部配对方式**（不复用任何「相邻」结论），在 $2\le m\le 8$、$n\le m/2$ 的 $300$ 组随机数据上与标程比对，**0 mismatch**。
- 极限规模 $m=2000,n=500$ 运行 $0.04$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2301 就是干！
// 思路：排序后，最优方案里每对木棍一定是排序数组中相邻的两根
//       dp[i][j] = 前 i 根木棍里配出 j 对的最小不舒服指数
//       转移：丢掉第 i 根 / 第 i 根与第 i-1 根配成一对
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005},mxk{505};
constexpr i64 inf{1145141919810};

int m,n;
i64 a[mxn];
i64 dp[mxn][mxk];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n;
	for(int i=1;i<=m;++i)
		cin>>a[i];
	sort(a+1,a+m+1);

	fill_n(&dp[0][0],mxn*mxk,inf);
	dp[0][0]=0;
	for(int i=1;i<=m;++i)
		for(int j=0;j<=n;++j)
		{
			dp[i][j]=dp[i-1][j];
			if(j>0&&i>=2&&dp[i-2][j-1]<inf)
				dp[i][j]=min(dp[i][j],dp[i-2][j-1]+(a[i]-a[i-1])*(a[i]-a[i-1]));
		}
	cout<<dp[m][n]<<'\n';
	return 0;
}
```

### 代码说明

- `a[1..m]` 用 1-based，`dp[i]` 就对应「前 $i$ 根」，转移里的 `(a[i]-a[i-1])` 正是排序后相邻两根。
- `dp` 必须整体 `fill_n` 成 `inf`：全局 `i64` 数组默认是 $0$，而 $0$ 是「合法的最小代价」，不初始化会让不可行状态伪装成最优解。
- `dp[i-2][j-1]<inf` 用于剪掉 `inf + 代价` 的溢出/无意义更新；本题 `inf` 足够大，但保留这个判断更稳。
- 平方用 `i64` 计算：`(a[i]-a[i-1])*(a[i]-a[i-1])` 中两个因子都是 `i64`，不会按 `int` 溢出。
- 转移顺序是「先继承、再尝试配对」，因此 `j=0` 也能正确处理；`i=1` 时 `i>=2` 不成立，只有继承。
- 输出 `dp[m][n]` 即前 $m$ 根里配出 $n$ 对的最小代价；题设「肯定有解」，故它一定有限。
