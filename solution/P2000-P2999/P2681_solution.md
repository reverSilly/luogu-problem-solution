# P2681 众数 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 序列 $a_1..a_n$（$n\le 1000$），$m$ 个操作（$m\le 1000$），任意时刻 $0<a_i\le 10^9$：

- `0 x y`：询问区间 $[x,y]$ 的**众数**（出现次数最多的值），**若有多个输出较小的那个**；保证 $x\le y$。
- `1 x y`：把 $a_x$ 改成 $y$（注意这里的 $y$ 是**值**，不是下标）。

每个询问输出一行。题面没有样例，下面的数据都是我手造并手算核对的。

**第一步：把"众数 + 并列取小"写成一个明确的目标。** 设 $\mathrm{cnt}(v)=|\{i\in[x,y]:a_i=v\}|$。题目要的是

$$\arg\max_v\ \bigl(\mathrm{cnt}(v),\ -v\bigr)\quad\text{（二元组字典序）}.$$

即：先比出现次数（大者优先），次数相同比值本身（**小**者优先）。因为不同值的 $-v$ 互不相同，这个二元组序是**严格全序**，最优值唯一，不存在"输出哪个都行"的歧义。这一步看着琐碎，但它决定了后面代码里那个 `>` 到底该不该带等号。

**第二步：看数据范围，先别急着上高级数据结构。** 一看到"区间众数 + 单点修改"，条件反射是莫队（带修莫队 $O(n^{5/3})$）或者分块预处理。但本题 $n,m\le 1000$：

$$m\times n\log n\approx 1000\times 1000\times 10=10^7,$$

**每次询问把整个区间重新统计一遍都绰绰有余**。这就是"范围决定算法"：高级数据结构是为了摊掉重复计算，而当总量本来就只有 $10^7$ 时，重复计算根本不是问题，写莫队反而是自找麻烦（离线排序、指针移动、修改回滚，一堆易错细节）。

所以我决定：**不维护任何动态结构**，每次询问现场重算。修改操作就是一次朴素赋值 `a[x]=y`。

**第三步：唯一的障碍是值域。** 统计频数最自然的写法是桶计数 `cnt[a[i]]++`，但 $a_i\le 10^9$，开 $10^9$ 的数组要 $4$ GB，直接爆炸。两条出路：

1. **离散化**：把所有出现过的值（初始 $n$ 个 + 每次修改的 $y$，共 $\le n+m\le 2000$ 个）收集起来排序去重，映射到 $0..V-1$，然后开 `cnt[2000]` 计数。优点：每次询问 $O(len+V)$，总量约 $2\times 10^6$，更快。缺点：**必须离线**读完所有操作才能建映射，代码多一层。
2. **比较排序**：把区间拷进临时数组 `b`，`sort(b,b+len)`，相同值自然聚成连续段，扫一遍段就能计频。优点：**在线**、不需要存操作、代码极短、完全不依赖值域。缺点：多一个 $\log$。

本题 $10^7$ 与 $2\times 10^6$ 都远低于限制，我选**方案 2**（在线 + 短）。方案 1 的正确性与代价我在第二部分引理 6 里一并交代，作为"范围再大一点该怎么改"的备选。

**第四步：排序之后怎么扫，以及"并列取小"怎么自动实现。** 排序后 `b` 升序，相同的值挤在一起形成若干**段**，段的值严格递增。扫描时维护 `cnt` = 当前段的长度：

```
cnt = (b[i]==b[i-1] ? cnt+1 : 1);
if(cnt>mx) mx=cnt, ans=b[i];
```

关键是那个**严格大于**。因为段是按值**升序**出现的，第一次达到最大频数的段一定是值最小的那个；后面频数相同的段不会触发 `cnt>mx`，`ans` 就保留住了较小值。如果写成 `cnt>=mx`，并列时会被后面的**较大**值覆盖，恰好与题意相反。

这个"排序 + 严格大于"的组合把"并列取小"这条规则**免费**实现了，不需要额外比较值的大小——这是本题最舒服的一点。但它需要证明（引理 4），因为 `mx` 是边扫边涨的，`ans` 也是边扫边换的，直觉上容易怀疑"最后 `ans` 会不会指向一个频数不是最大的值"。

**第五步：几个必须抠清楚的细节。**

1. **修改的 `y` 不能 `--`**。`0 x y` 里 $x,y$ 都是下标，`1 x y` 里只有 $x$ 是下标。统一在读入后 `--x`，然后**只在询问分支里** `--y`。这是本题最容易写错的一行。
2. **`len=1`**：`ans=b[0], mx=1, cnt=1`，循环不执行，直接输出唯一元素 ✓。
3. **`b` 数组复用不清空**：每次只用前 `len` 个，`sort(b,b+len)` 也只排前 `len` 个，后面的脏数据永远读不到。
4. **值域 $10^9<$ `INT_MAX`**：`int` 存得下，不需要 `long long`。
5. **内部 0-based**：读入 `--x`（询问再 `--y`），`a[x+i]` 直接对应区间。

**手造数据核对：**

第一组（打"并列取小"和"修改后重算"）：
```
5 4
1 2 2 3 3
0 1 5      → 1:1, 2:2, 3:2，并列取小 ⇒ 2
1 3 3      → a = [1,2,3,3,3]
0 1 5      → 3 出现 3 次 ⇒ 3
0 2 4      → [2,3,3] ⇒ 3
```
输出 `2 / 3 / 3`，程序一致。

第二组（打"较小值出现在区间后面"）：`4 1` / `3 3 1 1` / `0 1 4` → 频数 $3:2,1:2$，并列取小 ⇒ **1**（不是先出现的 3）。程序输出 `1` ✓。这一组专门验证"并列取小"是按**值**而不是按**位置**。

第三组（打大值与单点区间）：
```
3 3
5 5 5
0 2 2      → 5
1 1 1      → a = [1,5,5]
0 1 3      → 5（2 次）
```
输出 `5 / 5` ✓。

第四组（全不相同）：`4 1` / `9 7 3 1` / `0 1 4` → 每个值都 1 次，取最小 ⇒ `1` ✓。

第五组（值域上界）：`3 2` / `1 1000000000 1000000000` / `0 1 3` → `1000000000` ✓；随后 `1 1 999999999` 不越界。

第六组（修改成全新值）：`2 3` / `1 2` / `1 2 42` / `0 2 2` / `0 1 1` → `42 / 1` ✓。

## 二、思维链：完整证明

### 记号

- 序列 $a_0..a_{n-1}$（内部 0-based），任意时刻 $a_i\in[1,10^9]$。
- 询问区间 $[x,y]$（0-based 闭），$len=y-x+1\ge 1$。
- $\mathrm{cnt}(v)=|\{i\in[x,y]:a_i=v\}|$，$V=\{a_i:i\in[x,y]\}$（区间内出现过的值集，非空）。
- 二元组序：$(c_1,w_1)\prec(c_2,w_2)\iff c_1<c_2\ \lor\ (c_1=c_2\land w_1>w_2)$（次数大者优先，次数同则值小者优先）。
- `b[0..len-1]`：区间副本升序排序后的数组。

---

### 引理 1（题目目标的精确刻画与唯一性）

询问答案 $=\arg\max_{v\in V}\bigl(\mathrm{cnt}(v),-v\bigr)$（普通字典序），且该最大值唯一。

*证明*：题面"众数"= 区间内出现次数最多的值，即 $v$ 使 $\mathrm{cnt}(v)=\max_{u\in V}\mathrm{cnt}(u)=:C$。设 $T=\{v\in V:\mathrm{cnt}(v)=C\}$，$T$ 非空（有限非空集必有最大值）。题面"如果有多个输出较小的"即在 $T$ 中取 $\min$。

另一方面，按字典序最大化 $(\mathrm{cnt}(v),-v)$：第一分量最大者为 $C$，故最优者必在 $T$ 中；在 $T$ 内第一分量相同，比较第二分量 $-v$，最大者对应 $v$ 最小，即 $\min T$。两者一致。

唯一性：若 $v_1\ne v_2$ 都在 $V$ 中，则 $-v_1\ne-v_2$，故 $(\mathrm{cnt}(v_1),-v_1)\ne(\mathrm{cnt}(v_2),-v_2)$；字典序是严格全序，有限非空集的最大元唯一。证毕。

**注**：$V$ 非空因为 $len\ge 1$（题面保证 $x\le y$ 且下标合法）。这排除了"空区间众数"的未定义情形。

---

### 引理 2（单点修改的语义与"不维护结构"的合法性）

操作 `1 x y` 的效果是把 $a_x$ 置为 $y$，其余位置不变；此后所有询问都基于最新序列。程序用一次赋值实现，且每次询问重新统计，故结果与"维护某个动态数据结构"完全一致。

*证明*：题面定义的修改就是单点赋值，`a[x]=y`（`x` 已 `--` 转 0-based）逐字实现它，$y$ 是值不做下标转换 ✓。

设第 $t$ 个操作前的序列为 $a^{(t)}$。对询问操作，程序读取的是**当前**的 `a` 数组，即 $a^{(t)}$；统计过程（引理 3、4）只依赖 $a^{(t)}$ 在 $[x,y]$ 上的取值，与历史无关。对修改操作，程序把 $a^{(t)}$ 变为 $a^{(t+1)}$，与题面一致。对操作数归纳即得：程序在任意时刻的 `a` 数组都等于题面定义的当前序列，故每个询问的答案都正确。

**关键观察**：因为每次询问都**从头统计**，历史信息的正确性完全由 `a` 数组承载，不需要任何"增量维护"的结构，也就不存在"结构与实际序列不同步"这类 bug。这是"范围小到可以重算"带来的**正确性红利**，不只是性能上的取舍。证毕。

---

### 引理 3（排序把频数统计变成段扫描）

设 `b` 是 $\{a_i:i\in[x,y]\}$ 的升序排序结果（可重集）。则：

(a) 相同的值在 `b` 中占据一段连续下标，不同段对应的值严格递增；
(b) 扫描时 `cnt=(b[i]==b[i-1]?cnt+1:1)`（初值 `cnt=1`）给出的 `cnt` 恰为"以 $i$ 结尾的极大相等段"的长度；
(c) 每个值 $v\in V$ 恰对应一段，段长 $=\mathrm{cnt}(v)$。

*证明*：(a) 排序的定义给出 $b_0\le b_1\le\dots\le b_{len-1}$。设 $b_i=b_j=v$ 且 $i<j$，则对任意 $i\le k\le j$ 有 $v=b_i\le b_k\le b_j=v$，故 $b_k=v$：**相等值必连续**。于是可把 $[0,len)$ 划分成若干极大相等段；相邻段的值不能相等（否则可合并成更大的相等段，与极大性矛盾），又因整体非降，故段值严格递增。

(b) 对 $i$ 归纳。$i=0$：`cnt=1`，以 $0$ 结尾的极大相等段至少含 $b_0$，长度为 $1$ 当且仅当它是段首——初始化时我们正处在第一段开头，故 `cnt=1` 正确。设 $i-1$ 时 `cnt` 等于以 $i-1$ 结尾的段长。若 $b_i=b_{i-1}$，则 $i$ 与 $i-1$ 同段（由 (a) 的连续性），段长加 $1$，代码 `cnt+1` ✓；若 $b_i\ne b_{i-1}$，则 $i$ 是新段的第一元素，段长 $1$，代码置 `1` ✓。

(c) 由 (a)，每个 $v\in V$ 对应唯一一段；段中每个元素都等于 $v$，且区间内所有等于 $v$ 的元素都在这一段里（否则与连续性矛盾），故段长 $=|\{i\in[x,y]:a_i=v\}|=\mathrm{cnt}(v)$（排序是可重集的双射，不改变重数）。证毕。

---

### 引理 4（"严格大于"更新实现"并列取小"，核心）

代码令 `ans=b[0], mx=1, cnt=1`，随后对 $i=1..len-1$ 执行引理 3(b) 的 `cnt` 更新，并在 `cnt>mx` 时置 `mx=cnt, ans=b[i]`。则循环结束时

$$\texttt{mx}=\max_{v\in V}\mathrm{cnt}(v)=C,\qquad \texttt{ans}=\min\{v\in V:\mathrm{cnt}(v)=C\},$$

即引理 1 所求的答案。

*证明*：分三步。

**第一步：`mx` 单调不减，且每次增大都同时改写 `ans`。** 代码里 `mx` 只在 `cnt>mx` 分支被赋值为 `cnt`（此时新值 $>$ 旧值），其余时候不变，故 `mx` 单调不减；且该分支同时执行 `ans=b[i]`，所以 **`mx` 的每一次增大都伴随 `ans` 的一次改写**，不存在"只涨 `mx` 不换 `ans`"的情形。

**第二步：结束时 `mx`$=C$。** 由引理 3(b)(c)，扫描过程中 `cnt` 会取到每个段的**每一个前缀长度**，特别地会取到每个段的完整长度 $\mathrm{cnt}(v)$。设 $v^\*$ 使 $\mathrm{cnt}(v^\*)=C$，其段为 $[l,r]$。当 $i=r$ 时 `cnt`$=\mathrm{cnt}(v^\*)=C$。若此时 `mx`$<C$，则触发更新使 `mx`$=C$；若 `mx`$\ge C$，由 `mx` 始终 $\le$ 已见过的最大段长 $\le C$（`mx` 的每个值都是某个 `cnt`，而 `cnt` $\le$ 所在段的完整长 $\le C$），得 `mx`$=C$。故结束时 `mx`$=C$。

**第三步：结束时 `ans`$=\min T$，其中 $T=\{v:\mathrm{cnt}(v)=C\}$。** 由第一步，`ans` 的最后一次改写发生在 `mx` 的最后一次增大时，而那次增大把 `mx` 置为最终值 $C$（`mx` 单调不减且终值为 $C$）。设那次改写发生在下标 $i_0$，则 `ans`$=b_{i_0}$ 且当时 `cnt`$=C$。

- $b_{i_0}$ 所在段的完整长 $\ge$ 当时的 `cnt`$=C$，又 $\le C$，故**恰为 $C$**，即 $b_{i_0}\in T$。
- 反证 $b_{i_0}\ne\min T$：设 $v_0=\min T<b_{i_0}$。由引理 3(a)，值小的段在前，故 $v_0$ 的段 $[l_0,r_0]$ 满足 $r_0<i_0$。当 $i=r_0$ 时 `cnt`$=\mathrm{cnt}(v_0)=C$；此时 `mx`$\le C$。若 `mx`$<C$ 则触发更新，`mx` 变成 $C$ 且 `ans` 变成 $v_0$——但 `mx` 一旦到 $C$ 就不会再增大（第二步），故 $i_0$ 处不可能再有"`mx` 的最后一次增大"，矛盾。若当时 `mx` 已 $=C$，则 `mx` 在 $r_0<i_0$ 之前就已达终值，$i_0$ 处同样不是最后一次增大，矛盾。

故 `ans`$=\min T$。结合第一、二步与引理 1，程序输出正是题目答案。证毕。

**反例对照（为什么不能写 `>=`）**：`b=[1,1,3,3]`。用 `>`：$i=1$ 时 `cnt=2>mx=1` ⇒ `mx=2,ans=1`；$i=3$ 时 `cnt=2>2` 假 ⇒ `ans` 保持 $1$ ✓。用 `>=`：$i=3$ 时 `cnt=2>=2` 真 ⇒ `ans=3` ✗（题目要较小的 $1$）。

### 引理 5（初始化与边界）

`ans=b[0], mx=1, cnt=1` 是正确的初始状态；$len=1$ 时直接输出 `b[0]`；`b` 数组跨询问复用不需要清空。

*证明*：$len\ge 1$ 保证 `b[0]` 存在。初始时扫描位置为 $0$，以 $0$ 结尾的段长为 $1$（引理 3(b) 的基例），故 `cnt=1`；已见过的最大段长为 $1$，故 `mx=1`；对应的值为 `b[0]`，故 `ans=b[0]`。这与"扫描前的状态"完全一致，循环从 $i=1$ 开始不重不漏。

$len=1$：循环体不执行，输出 `ans=b[0]`，而区间只有一个元素，其频数为 $1$，众数就是它 ✓（引理 1 中 $V$ 只含一个值）。

复用：每次询问先把 `a[x..y]` 拷入 `b[0..len-1]`（覆盖旧值），再 `sort(b,b+len)`（只触碰前 $len$ 个），扫描也只读前 $len$ 个。下标 $\ge len$ 的残留数据**从不被读取**，故无需清空。证毕。

### 引理 6（备选路线：离线离散化 + 桶计数）

若先把所有出现过的值（初始 $n$ 个 + 所有修改的 $y$）收集、排序、去重得到 $V_{\text{all}}$（$|V_{\text{all}}|\le n+m\le 2000$），把每个值映射到其排名，则可用 `cnt[2000]` 桶计数：每次询问对区间内每个元素 `++cnt[id]`，再扫 $V_{\text{all}}$ 找最优，最后把 `cnt` 减回去复原。该路线与排序路线答案一致，时间 $O\bigl((n+m)\log(n+m)+m(n+|V_{\text{all}}|)\bigr)\approx 2\times 10^6$。

*证明*：**离散化保序且保相等**：排名映射 $\mathrm{id}$ 是 $V_{\text{all}}\to[0,|V_{\text{all}}|)$ 的双射，且 $v<w\iff\mathrm{id}(v)<\mathrm{id}(w)$（排序去重后按下标定序）。故"值相等"关系不变 ⇒ 频数统计不变；"值较小"关系不变 ⇒ 并列取小的结果不变。任何时刻 $a_i\in V_{\text{all}}$（初始值与所有修改值都被收集），故映射总有定义。

**计数正确**：`++cnt[id(a_i)]` 对区间内每个元素累加一次，故 `cnt[id(v)]`$=\mathrm{cnt}(v)$。扫描 $V_{\text{all}}$ 时按**值升序**（排名升序）遍历，用严格 `>` 更新 `(mx,ans)`，由引理 4 完全相同的论证得 `ans`$=\min T$。

**复原正确**：询问结束后对区间内每个元素 `--cnt[id(a_i)]`，把本次加过的全部减回，`cnt` 恢复全 $0$；修改操作只改 `a[x]`，不影响 `cnt`（因为 `cnt` 在询问之间恒为 $0$）。故各询问互不干扰。

**代价**：收集 + 排序去重 $O((n+m)\log(n+m))$；每次询问 $O(len+|V_{\text{all}}|)\le O(n+n+m)$，共 $O(m(n+m))\approx 2\times 10^6$。比排序路线的 $O(mn\log n)\approx 10^7$ 快约 $5$ 倍，但需要离线存下全部操作。**本题两者都远超够用，故选在线的排序路线。** 若 $n,m$ 放大到 $10^5$，两者都不够，才需要分块 / 带修莫队。证毕。

### 引理 7（值域、下标与复杂度）

`int` 足以存所有值与下标；时间 $O(n+m\cdot n\log n)$，空间 $O(n)$。

*证明*：$a_i\le 10^9<2^{31}-1=2147483647$ ✓；修改的 $y$ 同界 ✓；下标 $\le n\le 1000$ ✓；`cnt`、`mx` $\le len\le 1000$ ✓。全程无乘法、无求和，不存在溢出。

时间：读入 $O(n)$；每个修改 $O(1)$；每个询问拷贝 $O(len)$、排序 $O(len\log len)$、扫描 $O(len)$，合计 $O(len\log len)\le O(n\log n)$。$m$ 个操作共 $O(n+m\,n\log n)$。代入 $n=m=1000$：$1000\times 1000\times\log_2 1000\approx 10^7$ 次比较。

空间：`a`、`b` 各 $1005$ 个 `int`，约 $8$ KB，$O(n)$。证毕。

---

### 定理

程序对每个 `0 x y` 输出区间 $[x,y]$ 内出现次数最多、并列时值最小的那个数；对每个 `1 x y` 正确执行单点赋值。时间 $O(n+m\,n\log n)$，空间 $O(n)$。

*证明*：引理 1 把题目目标刻画为二元组字典序最大；引理 2 保证"每次重算 + 朴素赋值"与题面的动态语义一致；引理 3 保证排序后段扫描得到的就是频数；引理 4 保证严格 `>` 更新选出"频数最大且值最小"；引理 5 保证初始化、$len=1$、数组复用都正确；引理 7 保证值域与复杂度；引理 6 给出备选路线的等价性。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "众数 + 并列取小" $=$ 二元组 $(\mathrm{cnt}(v),-v)$ 的字典序最大；严格全序 ⇒ 答案唯一。
- **discuss by category** — 先看范围：$n,m\le 1000\Rightarrow m\,n\log n\approx 10^7$，每次询问重算就够，**不需要**莫队 / 分块 / 线段树。
- **reduce to easier problem** — 既然每次重算，单点修改就退化成一次朴素赋值，动态问题塌缩成"静态区间众数"，不必维护任何结构。
- **explore its property** — 值域 $10^9$ ⇒ 桶计数不可行；出路只有离散化或比较排序。
- **discuss by category** — 离散化（离线、$O(m(n+V))$）vs 排序（在线、$O(mn\log n)$）；本题选在线的排序路线。
- **classic problem solution** — 拷区间 + `sort` + 扫极大相等段计频。
- **explore its property** — 段按值升序出现 + **严格** `>` 更新 ⇒ "并列取小"免费实现；写 `>=` 就恰好反了。
- **discuss by category** — 修改的 `y` 是值不是下标（不能 `--y`）；$len=1$；`b` 复用不清空。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,m` | 序列长度、操作数（$\le 1000$） | `int`，读入 | 范围决定"可以重算" |
| `a[i]` | 当前序列（0-based） | `int[mxn]`，读入 | 唯一的"真实状态"，修改直接赋值 |
| `b[i]` | 询问区间的副本，排序后扫段 | `int[mxn]`，每次询问前 $len$ 个重写 | **复用不清空**，只读前 $len$ 个 |
| `mxn` | $1000+5$ | `constexpr int` | $+5$ 松弛 |
| `flag` | 操作类型：$0$ 询问 / $1$ 修改 | `int`，每操作读入 | 决定 `y` 是下标还是值 |
| `x,y` | 操作参数 | `int`，读入后 `--x` | **只有询问分支再 `--y`** |
| `len` | 区间长度 $y-x+1$ | `int` | $\ge 1$（题面保证 $x\le y$） |
| `cnt` | 以当前下标结尾的相等段长度 | `int`，初值 $1$ | 段内 `+1`，换段置 `1` |
| `mx` | 已见过的最大段长（$=$ 最大频数） | `int`，初值 $1$ | 单调不减 |
| `ans` | 当前最优值 | `int`，初值 `b[0]` | 只在 `cnt>mx` 时改写 ⇒ 并列取小 |

### 算法步骤

1. I/O 加速三行（固定顺序）。
2. 读 `n,m` 与 `a[0..n-1]`。
3. 对每个操作读 `flag,x,y`，`--x`：
   - `flag==1`：`a[x]=y`（`y` 是值，不转换）。
   - `flag==0`：`--y`；`len=y-x+1`；把 `a[x..y]` 拷入 `b[0..len-1]`；`sort(b,b+len)`；令 `ans=b[0],mx=1,cnt=1`；对 `i=1..len-1` 更新 `cnt`，若 `cnt>mx` 则 `mx=cnt,ans=b[i]`；输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(n+m\,n\log n)\approx 10^7$（$n=m=1000$）。
- 空间：$O(n)$，两个 $1005$ 的 `int` 数组约 $8$ KB。
- 值域：$a_i\le 10^9<$ `INT_MAX`，全程 `int`。

### 验证状态

`g++ -std=c++20 -O2 -Wall -Wextra` 编译通过、无警告。题面无样例，自造 $6$ 组手工数据（并列取小、较小值出现在区间后段、修改后重算、单点区间、全不相同、值域上界 $10^9$、修改成全新值）全部与手算一致。本题为直接模拟，按规范不做暴力对拍、不建 appendix。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2681 众数
// 思路：n,m<=1000 ⇒ 每次询问把区间拷出来排序，扫相等段计频，O(m*n log n) 足够。
//       值域 1e9 不能开桶；排序天然把相同值聚成段，且段按值升序出现，
//       计频时用严格 > 更新答案，就自动实现"众数并列取较小值"。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,m,a[mxn],b[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int q=0,flag,x,y;q<m;++q)
	{
		cin>>flag>>x>>y;--x;
		if(flag)
			a[x]=y;	// 修改：y 是值，不是下标，不能 --
		else
		{
			--y;
			int len=y-x+1;
			for(int i=0;i<len;++i)
				b[i]=a[x+i];
			sort(b,b+len);
			int ans=b[0],mx=1,cnt=1;
			for(int i=1;i<len;++i)
			{
				cnt=(b[i]==b[i-1]?cnt+1:1);
				if(cnt>mx)	// 严格大于：并列时保留先出现的（更小的）值
					mx=cnt,ans=b[i];
			}
			cout<<ans<<'\n';
		}
	}
	return 0;
}
```

### 代码说明

- **`--x` 放在分支外、`--y` 放在询问分支内**：这是本题最容易错的一行。修改操作的 `y` 是新值（可达 $10^9$），若误 `--y` 会把值改小 $1$；询问的 `y` 是下标，若不 `--` 会越界或算错区间。
- **`cnt>mx` 的严格性**：段按值升序出现，第一次达到最大频数的段值最小；严格 `>` 让后续同频段不覆盖 `ans`。改成 `>=` 会输出并列中**较大**的值（引理 4 的反例）。
- **`ans=b[0],mx=1,cnt=1` 的初始化**：对应"扫描位置 $0$、当前段长 $1$"，使 $len=1$ 时循环不执行也能输出正确答案。
- **`b` 不清空**：每次只写、只排、只读前 `len` 个，残留数据不可达。
- **不维护任何数据结构**：`a` 就是唯一真实状态，修改是 $O(1)$ 赋值，询问是 $O(len\log len)$ 重算。范围小带来的正确性红利（引理 2）。
- **值域**：$10^9$ 在 `int` 内，不需要 `i64`；也不需要离散化（那是 $n,m$ 更大时的备选，见引理 6）。
