# P2072 宗教问题 — 题解

## 一、解题过程：人类思考叙事

题目：$N$ 个教徒按**顺序**分成若干连续段（集体），每段的"危险值"是这段里不同宗教的种数，且每段宗教数不能超过 $K$（超过就是"无限危险"，不允许）。问：(1) 至少分几段；(2) 危险值总和最少是多少。

$N\le1000$，$M\le20$，$K<M$。

**第一问：贪心。** 段要尽量长才能段数最少。当前段从左往右加教徒，只要加进去之后宗教种数不超过 $K$ 就继续加；一旦要超了，就必须开新段。这是经典的最少分段贪心（与"每段最多装 $K$ 种颜色"类似），交换论证可证。

注意这里的贪心对象是"宗教种数"而不是"人数"，但原理一样：段可以无限长，限制是种数。所以只要当前段的种数还能容纳，就多塞一个人进去，段数不会变多；只有在塞不下时才开新段——而开新段必然增加段数，所以能塞就塞是最优的。

**第二问：DP，但状态里不能记段数。** 直觉是 `dp[i][j]` 表示前 $i$ 个人分 $j$ 段的最小危险值，但段数这一维会让状态数变成 $O(N^2)$，转移再枚举段起点就是 $O(N^3)$，$N=1000$ 跑不动。

而且更重要的是：**第二问和第一问的"最少段数"没有必然关系**。第二问要的是危险值总和最小，段数可以多也可以少。比如样例的最优划分是 `[1,2,3] / [4,3,4,3,2] / [1,2]`，3 段，危险值 $3+2+2=7$？但样例答案是 6。等等，让我核对一下样例。

样例输入：
```
10 4 3
1 2 3 4 3 4 3 2 1 2
```
宗教序列：$1,2,3,4,3,4,3,2,1,2$。

样例提示给的划分 $[1,2,3]/[4,3,4,3,2]/[1,2]$：
- 第 1 段 `1,2,3` → 3 种宗教 → 危险值 3
- 第 2 段 `4,3,4,3,2` → 宗教 {4,3,2} → 3 种 → 危险值 3
- 第 3 段 `1,2` → 2 种 → 危险值 2
总和 $3+3+2=8$。但答案是 6。

嗯，那说明还有更优的划分。试试贪心分段：
- 段1：$1,2,3$（3种）→ 再加 4 就是 4 种 > $K=3$，停。所以段1 = $1,2,3$，危险值 3。
- 段2：从 $4$ 开始：$4,3$（2种），加 $4$（还是2种），加 $3$（2种），加 $2$（3种）→ 段2 = $4,3,4,3,2$，危险值 3。再加 $1$ 就是 4 种，停。
- 段3：$1,2$ → 危险值 2。

共 3 段，总危险值 $3+3+2=8$。但答案是 6！说明第二问的最优划分不是贪心划分。

那第二问的最优是什么？$N=10$ 个元素，要总危险值 6。每段危险值至少 1（段非空），所以段数最多 6 段。危险值总和 6 意味着段数 ≤6，且每段宗教数少。

试试：$[1,2]/[3,4,3]/[4,3,2]/[1,2]$？危险值 $2+1+2+2=7$。

再试 5 段且每段尽量同宗教：
- $[1]/[2]/[3,4,3,4,3]/[2]/[1,2]$ → $1+1+2+1+2=7$。
- $[1,2]/[3]/[4,3,4,3]/[2]/[1,2]$ → $2+1+2+1+2=8$。

试 4 段：
- $[1,2,3]/[4,3,4,3,2]/[1,2]$ → 8。
- $[1,2]/[3,4,3]/[4,3,2]/[1,2]$ → $2+2+2+2=8$。

试 5 段：
$[1]/[2,3,4,3,4,3,2]/[1]/[2]$ → $1+3+1+1=6$！段2 = 2,3,4,3,4,3,2 宗教 {2,3,4}=3 种 ✓。总 = 1+3+1+1 = 6 ✓。

还有 5 段的其它划法，比如 $[1,2]/[3]/[4,3,4,3]/[2,1]/[2]$ → 2+1+2+2+1=8。

再看 6 段：$[1]/[2]/[3]/[4,3,4,3]/[2]/[1,2]$ → 1+1+1+2+1+2=8。
或者 $[1,2,3,4,3,4,3,2,1,2]$ 整段宗教 4 种 > 3 不行。

所以 6 是对的，段数 5，划分 $[1]/[2,3,4,3,4,3,2]/[1]/[2]$。危险值 1+3+1+1=6 ✓。

**关键发现：第二问最优解的段数（5）比第一问最少段数（3）还多！** 而且划分完全不同。这说明第二问必须独立做 DP，绝不能复用第一问的贪心划分。

那么 DP 怎么做？

**关键在于：$K<M\le20$，段内宗教种数 $\le K$，所以每段的"种类"是受限的小值。** 而且 $M$ 只有 20，宗教种数最多 20 种。

于是想到：**dp[i] = 前 $i$ 个人分段的最小危险值总和**，转移
$$dp[i] = \min_{1\le j\le i}\bigl(dp[j-1] + \text{types}(j,i)\bigr),$$
其中 $\text{types}(j,i)$ 是区间 $[j,i]$ 内不同宗教数，且要求 $\text{types}(j,i)\le K$（否则这一段非法）。

这个转移是 $O(N^2)$ 枚举 $j$，总共 $O(N^2)$ 次转移。但每次算 $\text{types}(j,i)$ 需要 $O(M)$（用计数桶），总体 $O(N^2M)=2\times10^7$，其实也能过。不过我们可以更快。

**优化：倒序枚举左端点 $j$。** 对固定的 $i$，从 $j=i$ 开始往前扫，用一个大小为 $M$ 的计数桶 `cnt[宗教]` 维护区间 $[j,i]$ 里各宗教的出现次数。每次 $j$ 减一，若 $cnt[a[j]]$ 从 0 变成 1，则 `types` 加一。当 `types > K` 时，后面的 $j$ 更小、types 只会更大，可以直接 `break`。这样每个 $i$ 的转移是 $O(MK)$（因为最多往前扫 $K$ 个"新宗教"就 break，实际扫的长度不超过区间内宗教种数限制所允许的长度，最坏 $O(n)$ 但实际上 types 超过 K 就停，最坏情况是全同宗教区间很长——$K\ge1$ 时 types 恒为 1，能扫到 $j=1$，所以最坏还是 $O(n)$）。总共 $O(N^2)$。

**一个重要细节**：$M$ 可能大于 $N$ 吗？$M$ 是宗教种数（1..M），$N$ 是人数，$N$ 可以小于 $M$。桶开 $M$ 大小没问题。

**第一问和第二问要分开算**，第二问的 DP 数组 `dp` 要初始化为无穷大（`inf`），因为 `dp[i]` 是从 `dp[j-1]+types` 转移来的，不可达时不能取 0。`dp[0]=0`。

**桶要清空**：第二问里每次换 $i$ 时要清空 `cnt[]`。第一问里当前组换新组时也要清空 `cnt[]`（或者用一个"组编号"来避免清空，但 $M\le20$ 直接清空更简单，代价 $O(M)$ 每组，总共 $O(NM)$）。

**顺便验证一下第一问的贪心在样例上**：序列 $1,2,3,4,3,4,3,2,1,2$，$K=3$：
- 段1：1,2,3 → 3 种；加 4 → 4 种超 → 段1 = $1,2,3$。
- 段2：4,3,4,3,2 → 3 种；加 1 → 4 种超 → 段2 = $4,3,4,3,2$。
- 段3：1,2 → 2 种。
共 3 段 ✓ 与样例答案一致。

好，两问的算法都定了。

## 二、思维链：完整证明

**引理 1**（第一问贪心最优）：若存在一个划分，使得某一段在"还能容纳新教徒"的情况下提前结束（后面的人被放到了下一段），那么把后面这一段的第一个教徒挪到当前段，不会增加段数且不会违反约束。

*证明*：设当前段是 $[l,r]$，且 $r$ 后面紧跟的段非空。记当前段的宗教种数为 $t\le K$。考虑下一段的第一个教徒 $x$（宗教 $a_x$）。若 $a_x$ 不在当前段的宗教集合里，则把 $x$ 挪入当前段后种数变为 $t+1$；否则仍为 $t$。由于原划分合法，下一段里含 $x$ 的那一段宗教数 $\le K$。若挪入后当前段种数变为 $t+1>K$，即 $t=K$ 且 $a_x$ 是新宗教，那么下一段必须包含 $a_x$，其宗教数 $\le K$；但下一段去掉 $x$ 后剩余部分仍合法，而把 $x$ 挪来使当前段变成 $K+1$ 种——这说明原划分中 $x$ 的宗教是新出现的且下一段用了它……

更简洁地表述：设当前段的宗教集合为 $S$，$|S|=t\le K$。下一段 $[r+1,s]$ 的宗教集合 $T$ 满足 $|T|\le K$。把 $x=a_{r+1}$ 挪到当前段：
- 若 $a_x\in S$，当前段种数仍为 $t\le K$，合法，段数不变。
- 若 $a_x\notin S$，则 $a_x\in T$，即 $T$ 中至少含 $a_x$ 这一种不在 $S$ 里的宗教，故 $T\setminus S\ne\emptyset$。此时下一段去掉 $x$ 后变成 $[r+2,s]$，宗教数 $\le |T|\le K$，仍合法；当前段变成 $t+1$ 种。为保证 $t+1\le K$，需要 $t\le K-1$。若 $t=K$ 且 $a_x\notin S$，则 $|S\cup T|\ge K+1$，但这并不矛盾。

因此"提前结束且下一段有新宗教"时，直接挪动可能破坏当前段合法性。

改用标准的"最远可行前缀"论证：设贪心切出的第一段是 $[1,r]$，即 $[1,r]$ 的宗教数 $\le K$ 而 $[1,r+1]$ 的宗教数 $>K$（若 $r=N$ 则无此问题）。任何合法划分的第一段终点 $r'\le r$，因为 $r$ 已经是满足约束的最远位置。设某个最优划分的第一段为 $[1,r']$，$r'\le r$。

递归地，把最优划分中后续段依次与贪心的对应段比较，可以证明贪心每一段的终点都不早于最优划分对应段的终点，从而贪心总段数最少。

这是"贪心段数最少"的标准证明：更长的第一段永远不会让后面的分段变难——因为限制只与"段内宗教种数"有关，段的前缀更长意味着后面要分的元素更少。

具体地：设贪心第 $t$ 段覆盖到 $g_t$，任意合法划分第 $t$ 段覆盖到 $o_t$。归纳证明 $g_t\ge o_t$。基例：$g_1$ 是满足约束的最远前缀，$o_1\le g_1$。归纳：假设 $g_{t-1}\ge o_{t-1}$。若 $g_{t-1}\ge o_t$，则 $g_t\ge g_{t-1}\ge o_t$ 显然。否则 $g_{t-1}\in[o_{t-1},o_t)$，贪心从 $g_{t-1}+1$ 开始的最长可行段至少覆盖到 $o_t$——因为区间 $[g_{t-1}+1,o_t]$ 是 $[o_{t-1}+1,o_t]$ 的子区间，宗教种数不超过后者的种数 $\le K$。故 $g_t\ge o_t$。

于是贪心用 $T$ 段覆盖了 $N$ 个人，任何合法划分至少要 $T$ 段（因为 $o_T\le g_T$ 且 $o_{T+1}$ 必须存在才能覆盖完）。贪心最优。证毕。

**引理 2**（DP 转移的正确性）：$dp[i] = \min_{j\le i,\ \text{types}(j,i)\le K}\bigl(dp[j-1]+\text{types}(j,i)\bigr)$ 得到的是前 $i$ 人分段的最小危险值总和。

*证明*：任何把前 $i$ 人分成若干段的合法划分，其最后一段必为某个 $[j,i]$，且 $\text{types}(j,i)\le K$；前面 $j-1$ 人的划分贡献至少为 $dp[j-1]$，总危险值至少为 $dp[j-1]+\text{types}(j,i)$。故任何合法划分的危险值 $\ge$ 该转移式右端的最小值。

反之，对每个合法的 $j$，取 $dp[j-1]$ 对应的最优划分并接上段 $[j,i]$，得到一个合法的划分，危险值恰为 $dp[j-1]+\text{types}(j,i)$。故转移式右端的最小值可达到。

两者结合，$dp[i]$ 恰为所求。$dp[0]=0$ 作为初值正确。证毕。

**引理 3**（桶维护区间宗教种数的正确性）：在固定 $i$、从 $j=i$ 向下枚举的过程中，`cnt[c]` 恒为宗教 $c$ 在区间 $[j,i]$ 中的出现次数，`types` 恒为该区间不同宗教数。

*证明*：初始 $j=i$ 时清空桶，`types=0`，区间 $[i,i]$ 只有一个元素，处理后 `cnt[a[i]]=1`、`types=1`，正确。每次 $j$ 减一，只多纳入元素 $a_j$：若 `cnt[a[j]]` 由 $0$ 变 $1$，则宗教种数加一，否则不变。归纳成立。证毕。

**引理 4**（`types > K` 时 `break` 不遗漏更优解）：倒序枚举 $j$ 时，一旦当前区间 $[j,i]$ 的宗教种数超过 $K$，则对所有 $j'<j$，区间 $[j',i]\supseteq[j,i]$，宗教种数 $\ge$ 当前值 $>K$，全部非法。

*证明*：区间包含关系保证元素只增不减，宗教种数单调不减。证毕。

**定理**：算法输出的最少集体数与最小危险值均正确。

*证明*：第一问由引理 1 得证；第二问由引理 2 得证，其中转移的高效实现由引理 3、4 保证正确性与完备性。证毕。

## 三、模式总结（按实际思考顺序）

1. **两问先分开看** — 样例告诉我们第二问的最优划分段数（5）比第一问的最少段数（3）还多，第二问**绝不能**在第一问的贪心划分上做优化。
2. **第一问：能塞就塞的贪心** — 段无长度上限、限制只在宗教种数，所以尽量往当前段塞，塞不下才开新段。
3. **第二问：按"前缀最优"设计 DP** — `dp[i]` 只记前 $i$ 人的最小危险值，段起点 $j$ 作为转移枚举量，不引入段数维度。
4. **利用小值域做优化** — $M\le20$ 用计数桶 O(1) 维护区间宗教种数；倒序枚举 $j$ 时宗教种数单调不减，超 $K$ 立即 `break`。
5. **桶必须每次清空** — 两问各自换组/换 $i$ 时都要重置 `cnt[]`，否则计数串味。
6. **DP 初值用无穷大** — `dp[]` 初始化为 `inf`、`dp[0]=0`，不能默认 0，否则不可达状态会被当成合法。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $N$ | 教徒人数 | `int`，$\le1000$ |
| $M$ | 宗教种数 | `int`，$\le20$ |
| $K$ | 单个集体允许的最大宗教种数 | `int`，$1\le K<M$ |
| `a[i]` | 第 $i$ 个教徒的宗教编号 | `int`，$1\sim M$ |
| `cnt[c]` | 当前区间内宗教 $c$ 的出现次数 | `int`，$0\sim N$ |
| `typ` | 当前区间内的不同宗教数 | `int`，$0\sim K$ |
| `grp` | 已开启的集体数（第一问） | `int` |
| `dp[i]` | 前 $i$ 人划分后的最小危险值总和 | `int`，$\le N\cdot K$ |
| `inf` | 不可达标记 | `int`，`1145141919` |

**初始化约定**：`a[]`、`cnt[]`、`dp[]` 均为全局数组，默认全 0；`dp[]` 在使用前用 `fill_n(dp,mxn,inf)` 显式填充为不可达，`dp[0]=0`。

### 算法步骤

**第一问（贪心）**
1. `grp=0`、`typ=0`、`cnt[]` 全 0。
2. 对 $i=1\ldots N$：
   - 若 `cnt[a[i]]==0`（新宗教）：若 `typ==K` 则说明当前组已满，`++grp`、清空 `cnt[]`、`typ=0`；然后 `++typ`。
   - `++cnt[a[i]]`。
3. 循环结束后 `++grp`（最后一段还没计），输出 `grp`。

**第二问（DP）**
4. `fill_n(dp,mxn,inf)`，`dp[0]=0`。
5. 对 $i=1\ldots N$：
   - 清空 `cnt[]`，`typ=0`；
   - 倒序枚举 $j=i,i-1,\ldots,1$：
     - 若 `cnt[a[j]]==0` 则 `++typ`；`++cnt[a[j]]`；
     - 若 `typ>K` 则 `break`（由引理 4）；
     - `dp[i]=min(dp[i], dp[j-1]+typ)`。
6. 输出 `dp[N]`。

### 复杂度

- 时间复杂度：$O(N^2+NM)$。第二问的 DP 转移共 $O(N^2)$ 次，每次 O(1)；第一问清空桶共 $O(\text{grp}\cdot M)\le O(NM)$。$N=1000$ 时约 $10^6$ 次转移。
- 空间复杂度：$O(N+M)$，存储宗教序列、`dp[]` 与计数桶。

### 验证状态

- 标程 `P2072.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `10 4 3 / 1 2 3 4 3 4 3 2 1 2` 输出 `3` 与 `6`，与官方一致（第二问的最优划分是 `[1]/[2,3,4,3,4,3,2]/[1]/[2]`，危险值 $1+3+1+1=6$）。
- 编写独立暴力 `P2072_brute.cpp`（枚举 $2^{N-1}$ 种连续划分，直接求段数与危险值总和的最小值，完全不使用贪心与 DP）与对拍脚本 `P2072_check.py`：随机生成 $1\le N\le12$、$2\le M\le6$、$1\le K<M$ 的数据，并附加"全同宗教 / 全不同宗教 / $K=1$ / 官方样例"等极端构造，**对拍 2004 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};
constexpr int inf{1145141919};

int n,m,k;
//a[i]：第 i 个教徒的宗教
int a[mxn];
//cnt[]：当前区间内各宗教出现次数
int cnt[mxn];
//dp[i]：前 i 人分组后危险值总和的最小值
int dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>k;
	for(int i=1;i<=n;++i)
		cin>>a[i];

	//第一问：贪心，每组尽量长（不同宗教数不超过 k）
	int grp=0,typ=0;
	for(int i=1;i<=n;++i)
	{
		if(cnt[a[i]]==0)
		{
			if(typ==k)
			{
				//当前组已满，另开一组
				++grp;
				for(int j=1;j<=m;++j)
					cnt[j]=0;
				typ=0;
			}
			++typ;
		}
		++cnt[a[i]];
	}
	++grp;

	//第二问：dp[i] = min(dp[j-1] + 区间 [j,i] 的不同宗教数)
	fill_n(dp,mxn,inf);
	dp[0]=0;
	for(int i=1;i<=n;++i)
	{
		for(int j=1;j<=m;++j)
			cnt[j]=0;
		int typ=0;
		for(int j=i;j>=1;--j)
		{
			if(cnt[a[j]]==0)
				++typ;
			++cnt[a[j]];
			if(typ>k)
				break;
			dp[i]=min(dp[i],dp[j-1]+typ);
		}
	}

	cout<<grp<<'\n';
	cout<<dp[n]<<'\n';
	return 0;
}
```

### 代码说明

- 三问共用的 `cnt[]` 桶在每次"换组 / 换 i"时都要清空，代码中用 `for(int j=1;j<=m;++j) cnt[j]=0;` 显式清零。
- `dp[]` 用 `fill_n(dp,mxn,inf)` 填充为不可达，只让 `dp[0]=0` 可达；这是"全局 int 数组默认 0"最容易踩的坑——默认 0 会让所有状态都"可达"。
- 第二问内层的 `typ` 用了局部变量，与第一问的 `typ` 作用域不同，避免互相干扰。
- `if(typ>k) break;` 依赖区间宗教种数的单调性，是本题 DP 的关键剪枝。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
