# P2949 [USACO09OPEN] Work Scheduling G — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 时间从 $0$ 开始，每个整数时刻是一个长度为 $1$ 的时段，每个时段至多做一件工作。有 $N$ 件工作（$1\le N\le10^5$），第 $i$ 件耗时恰 $1$ 个时段，若放在时刻 $t$ 做必须满足 $t<D_i$（$1\le D_i\le10^9$），做完获得利润 $P_i$（$1\le P_i\le10^9$）。选一个工作子集并安排时刻，最大化总利润。只输出最大总利润（可能超 32 位）。

换算成"格子"语言：工作 $i$ 可以放进编号 $0,1,\dots,D_i-1$ 的任意一个格子，每格至多一件。**截止时间 $D_i$ 就是"前 $D_i$ 个格子可用"**。题面提示里"在时间 $1$ 完成 $(1,7)$"是 1-based 的说法，对应 0-based 的格子 $0$，与 $t<D_i$ 一致。

**第一反应：枚举子集。** $2^N$ 死路。但注意一个分离结构：**一个子集能不能排下，与利润无关**；利润只决定"在能排下的子集里挑哪个"。于是先解决一个更干净的问题——

**第二步：哪些子集是可行的？** 手玩几组：两件工作截止都是 $1$，只能留一件；截止 $1,2,2$ 的三件可以全留（时刻 $0,1$ 放两件截止 $2$ 的？不行，只有两个格子 $0,1$，三件放不下）。规律浮出水面：把子集按截止时间升序排，第 $k$ 件必须满足 $D_{(k)}\ge k$——等价地，**对每个 $t$，截止 $\le t$ 的工作数不超过 $t$**（它们只能挤在前 $t$ 个格子里）。必要性显然；充分性也不难：按截止升序把第 $k$ 件放格子 $k-1$ 即可。这是全题的地基（引理 1）。

**第三步：贪心试探。** 最自然的贪心：按利润从大到小，能塞就塞（塞进截止前最晚的空格子）。它是对的，但"找最晚空格子"要并查集或线段树，而且正确性证明并不平凡。换一个更顺的扫描顺序试试：**按截止时间升序**处理工作，手里维护"已选工作的利润小根堆"。为什么这个顺序好？因为处理到工作 $i$ 时，**之前所有工作的截止都 $\le D_i$**，于是"前 $t$ 格容量"这无穷多条约束里，真正可能卡住新工作的只有 $t=D_i$ 这一条——已选数量 $\le D_i$。约束塌缩成一个数！

**第四步：反悔。** 新工作 $(d,p)$ 到来：

- 堆大小 $<d$：还有空位，直接收（堆大小 $+1$ 仍 $\le d$，可行）。
- 堆大小 $=d$（注意不可能 $>d$，见上）：塞不下了。但"塞不下"不等于"不该要"——如果 $p$ 比堆里**最小**的利润 $m$ 大，就把那件最不值钱的踢掉、换上 $i$：数量不变仍可行，总利润净增 $p-m>0$。这就是**反悔贪心**：先做局部最优决策，允许后来者用"换人"的方式推翻旧决策，而小根堆让"被推翻的总是最弱的那个"只需 $O(\log N)$。
- $p\le m$：不换，丢弃 $i$。

直觉上"每次换人都让总利润变大、且始终保持可行"，但**局部变大不等于全局最优**——会不会早些时候踢掉的人其实是后面某步的关键？会不会存在一个完全不同的子集更赚？这必须严格证明，不能靠"感觉贪心是对的"。

**第五步：证明的骨架。** 用归纳法证明强不变量："处理完前 $i$ 件（按截止升序）后，堆恰好是前 $i$ 件中**利润最大的可行子集**"。归纳步要比较"任意可行子集 $S$"与堆 $H$，分"$S$ 含不含新工作 $e$"讨论。含 $e$ 时把 $e$ 拿掉，剩下 $S-e$ 是前 $i-1$ 件里的可行子集且比 $H$ 小——这时需要一件武器：**扩充引理**（两个可行集，小的总能从大的里借一个元素保持可行）。它让我们把 $S-e$ 一步步扩充到 $H$ 的大小，从而压出上界 $w(S-e)\le w(H)-\min(H)$。这条引理本身用"最紧容量时刻"的反证法证（引理 2），是整篇证明里最精彩的一步。

**第六步：实现细节。** $D_i,P_i\le10^9$ 都在 `int` 内；堆大小 $\le N\le10^5$，与 $D_i$ 比较安全。总利润 $\le10^5\times10^9=10^{14}$，**必须 `long long`**（题面也明说了）。不需要输出方案，可行性引理保证"堆里的集合一定排得下"，我们只管加利润。

**手造数据核对**（题面提示给了一个 $17$ 的例子，补全成完整输入；另造三组）：

| 输入 $(D_i,P_i)$ | 手算 | 输出 |
|---|---|---|
| `(2,10),(1,5),(1,7)` | 格子 $0$ 放 $(1,7)$，格子 $1$ 放 $(2,10)$，$7+10=17$（与提示一致） | `17` |
| `(1,10),(1,20),(1,30),(1,40)` | 截止全 $1$，只有一个格子，取最大 $40$ | `40` |
| `(2,5),(2,6),(1,1),(1,2),(3,100)` | 格子 $0$ 放 $(1,2)$，格子 $1$ 放 $(2,6)$？更优：格子 $0$ 放 $(2,5)$ 不行——$(2,5)$ 可放格子 $0$ 或 $1$；最优 $\{5,6,100\}$：$5$ 放格子 $0$，$6$ 放格子 $1$，$100$ 放格子 $2$，共 $111$ | `111` |
| `(1e9,1e9),(1e9,1e9)` | 两件都做，$2\times10^9$ 超 `int` | `2000000000` |

四组全部与程序输出一致。第三组里 $(1,1),(1,2)$ 先后被反悔踢掉，正是"换人"机制的体现。

## 二、思维链：完整证明

**记号。** 工作 $i$ 为 $(D_i,P_i)$，$P_i\ge1$。子集 $S$ **可行**指存在单射把 $S$ 中每件工作放到一个互不相同的整数时刻 $t\in[0,D_i)$。记 $c_S(t)=|\{i\in S:D_i\le t\}|$，$w(S)=\sum_{i\in S}P_i$。把工作按 $D$ 升序排序后依次处理，$H_i$ 表示处理完前 $i$ 件后堆中的集合（$H_0=\varnothing$）。算法：处理 $e=(d,p)$ 时，若 $|H|<d$ 则 $H\leftarrow H\cup\{e\}$；否则（$|H|=d$）若 $p>\min(H)$ 则 $H\leftarrow H\setminus\{\arg\min\}\cup\{e\}$，否则不变。

---

### 引理 1（可行性的容量判据）

$S$ 可行 $\iff$ 对所有整数 $t\ge1$，$c_S(t)\le t$。

*证明*：**必要性**：截止 $\le t$ 的工作只能放在时刻 $0..t-1$ 这 $t$ 个格子里，且互不重叠，故件数 $\le t$。

**充分性**：把 $S$ 按截止升序排成 $s_1,\dots,s_k$（$D_{s_1}\le\dots\le D_{s_k}$），令第 $j$ 件放时刻 $j-1$。各时刻互异，只需验证 $j-1<D_{s_j}$，即 $D_{s_j}\ge j$。注意到 $s_1,\dots,s_j$ 的截止都 $\le D_{s_j}$，故 $c_S(D_{s_j})\ge j$；由条件 $c_S(D_{s_j})\le D_{s_j}$，得 $D_{s_j}\ge j$ ✓。于是该安排合法，$S$ 可行。证毕。

**推论**：若 $S$ 中所有工作的截止都 $\le d$，则 $S$ 可行 $\Rightarrow|S|=c_S(d)\le d$。特别地，按截止升序扫描时，处理到截止为 $d$ 的工作，已选堆 $H$ 必满足 $|H|\le d$——"堆大小 $>d$"永远不会发生，分支只有 $<d$ 与 $=d$ 两种。

---

### 引理 2（扩充引理 / 交换性质）

设 $A,B$ 都可行且 $|A|<|B|$，则存在 $b\in B\setminus A$ 使 $A\cup\{b\}$ 可行。

*证明*：由引理 1，只需找 $b$ 使对所有 $t$，$c_{A+b}(t)\le t$。注意 $c_{A+b}(t)=c_A(t)+[D_b\le t]$，即只有 $t\ge D_b$ 处计数 $+1$。称满足 $c_A(t)=t$ 的 $t$ 为**紧时刻**。

**情形一：$A$ 无紧时刻。** 则对所有 $t\ge1$ 有 $c_A(t)\le t-1$，任取 $b\in B\setminus A$（非空，因 $|B|>|A|$），$t\ge D_b$ 处 $c_{A+b}(t)=c_A(t)+1\le t$ ✓，$t<D_b$ 处不变 ✓。可行。

**情形二：$A$ 有紧时刻。** 紧时刻有界：$t>\max_{i\in A}D_i$ 时 $c_A(t)=|A|<t$（$|A|<|B|$ 且 $B$ 可行给出 $|A|\le|B|-1$，而 $c_B(t)\le t$ 对大 $t$ 平凡；直接地，$t>|A|$ 时 $c_A(t)\le|A|<t$），故紧时刻都 $\le|A|$，取**最大**紧时刻 $T$。

先证：**任何 $D_b>T$ 的 $b$ 都可行**——$t<D_b$ 处计数不变；$t\ge D_b>T$ 处由 $T$ 的最大性 $c_A(t)<t$，即 $c_A(t)\le t-1$，$+1$ 后 $\le t$ ✓。

再证 $B\setminus A$ 中**必有** $D_b>T$ 者。反设所有 $b\in B\setminus A$ 都满足 $D_b\le T$。则
$$c_B(T)\ \ge\ c_{A\cap B}(T)+|B\setminus A|\ \ge\ \bigl(c_A(T)-|A\setminus B|\bigr)+|B\setminus A|\ =\ T-|A\setminus B|+|B\setminus A|\ =\ T+|B|-|A|\ >\ T,$$
其中第一个 $\ge$ 是因为 $A\cap B$ 与 $B\setminus A$ 不交且都在 $B$ 中、截止都 $\le T$（后者由反设）；第二个 $\ge$ 是因为 $c_{A\cap B}(T)=c_A(T)-|\{i\in A\setminus B:D_i\le T\}|\ge c_A(T)-|A\setminus B|$；而 $c_A(T)=T$ 由紧时刻定义。这与 $B$ 可行（$c_B(T)\le T$）矛盾。故存在 $D_b>T$ 的 $b\in B\setminus A$，可行。证毕。

---

### 推论 2.1（小可行集的利润上界）

设 $H$ 是某工作全集 $U$ 中利润最大的可行子集（$w(H)=\max\{w(T):T\subseteq U\text{ 可行}\}$），$m=\min_{i\in H}P_i$。则对 $U$ 的任意可行子集 $S$ 满足 $|S|\le|H|-1$，有 $w(S)\le w(H)-m$。

*证明*：若 $|S|<|H|-1$，反复用引理 2（$A=S$ 逐步扩充，$B=H$）：只要 $|S|<|H|$ 就能从 $H\setminus S$ 借一个元素保持可行。因所有利润 $\ge1>0$，扩充只增利润，故可先把 $S$ 扩充到恰好 $|H|-1$ 个元素而不减小 $w$，仍记为 $S$。

再用一次引理 2：存在 $h\in H\setminus S$ 使 $S+h$ 可行。$S+h\subseteq U$ 可行，由 $H$ 的最优性 $w(S)+P_h=w(S+h)\le w(H)$，故 $w(S)\le w(H)-P_h\le w(H)-m$（$P_h\ge m$）。证毕。

（注意 $H$ 最优 $\Rightarrow$ $H$ 是**极大**可行集：任何能加进 $H$ 的正利润元素都会让 $w$ 更大，矛盾；这保证引理 2 里 $|S|<|H|$ 时 $H\setminus S$ 借得出元素——引理 2 本身已保证存在性，无需额外条件。）

---

### 引理 3（单步可行性）

按截止升序处理到 $e=(d,p)$，当前堆 $H$ 可行且其中所有截止 $\le d$。则：

(a) 若 $|H|<d$，$H+e$ 可行；
(b) 若 $|H|=d$，$H+e$ 不可行；且对任意 $m\in H$，$H-m+e$ 可行。

*证明*：(a) $t<d$ 处 $c_{H+e}(t)=c_H(t)\le t$；$t\ge d$ 处 $c_{H+e}(t)=|H|+1\le d\le t$ ✓（用了 $H$ 中截止全 $\le d$）。

(b) $c_{H+e}(d)=|H|+1=d+1>d$，违反引理 1，不可行。对 $H-m+e$：$t<d$ 处，删 $m$ 只减计数、加 $e$ 无影响，故 $c_{H-m+e}(t)\le c_H(t)\le t$；$t\ge d$ 处 $c_{H-m+e}(t)=|H|-1+1=|H|=d\le t$ ✓。可行。证毕。

---

### 引理 4（主不变量：堆始终是前缀的最优可行子集）

对每个 $i=0..N$，$H_i$ 是前 $i$ 件工作（按截止升序）中利润最大的可行子集。

*证明*：对 $i$ 归纳。$i=0$：$H_0=\varnothing$，唯一可行子集，平凡。

设 $H=H_{i-1}$ 是前 $i-1$ 件的最优可行子集，处理第 $i$ 件 $e=(d,p)$。由引理 1 推论 $|H|\le d$。任取前 $i$ 件中的可行子集 $S$，要证 $w(S)\le w(H_i)$。按 $e\in S$ 与否分类：

**类一：$e\notin S$。** $S$ 是前 $i-1$ 件的可行子集，由归纳假设 $w(S)\le w(H)$。

**类二：$e\in S$。** $S-e$ 是前 $i-1$ 件的可行子集（可行性对删元素封闭，引理 1 计数只减）。又因前 $i$ 件截止全 $\le d$，引理 1 给 $|S|\le d$，故 $|S-e|\le d-1$。

- **分支 A：$|H|<d$（算法收下 $e$，$H_i=H+e$）。** 由归纳假设直接 $w(S-e)\le w(H)$，故 $w(S)=w(S-e)+p\le w(H)+p=w(H_i)$。结合类一（$w(S)\le w(H)<w(H_i)$，利润为正），$H_i$ 最优；可行性由引理 3(a) ✓。
- **分支 B：$|H|=d$。** 此时 $|S-e|\le d-1=|H|-1$，由推论 2.1（取 $U$ 为前 $i-1$ 件）得 $w(S-e)\le w(H)-m$，其中 $m=\min(H)$。故
$$w(S)\ \le\ w(H)-m+p.$$
  - 若 $p\le m$（算法不动，$H_i=H$）：$w(S)\le w(H)=w(H_i)$，结合类一得 $H_i$ 最优 ✓。
  - 若 $p>m$（算法换人，$H_i=H-m^\*+e$，$m^\*$ 是取到最小利润的元素）：$w(S)\le w(H)-m+p=w(H_i)$；而类一的 $w(S)\le w(H)<w(H)-m+p=w(H_i)$。故 $H_i$ 最优；可行性由引理 3(b) ✓。

所有分支穷尽，归纳完成。证毕。

**这条引理直接终结了"局部反悔会不会损害全局"的疑虑**：不是"每步变大所以最后最大"这种非法推理，而是每步都**严格等于前缀全局最优**，最后一步的前缀就是全集。

---

### 引理 5（复杂度与数值范围）

时间 $O(N\log N)$，空间 $O(N)$；总利润须用 64 位。

*证明*：排序 $O(N\log N)$。每件工作至多一次 `push`、一次 `pop`、一次 `top`，堆大小 $\le N$，单次 $O(\log N)$，合计 $O(N\log N)$。空间：工作数组 $O(N)$、堆 $O(N)$。

数值：$D_i,P_i\le10^9<2^{31}$，`int` 安全；堆大小 $\le N\le10^5$，`(int)Q.size()<d` 比较安全。总利润 $\le N\cdot\max P_i=10^5\times10^9=10^{14}$，超 `int`（约 $2.1\times10^9$）但在 `long long`（约 $9.2\times10^{18}$）内，故 `ans` 用 `i64`。证毕。

---

### 定理

程序输出最大总利润，时间 $O(N\log N)$、空间 $O(N)$。

*证明*：引理 1 把"能否排下"翻译成纯计数判据，并给出按截止升序扫描时 $|H|\le d$ 的关键事实；引理 3 保证算法的两种操作（直收 / 换人）都维持可行性；引理 2 与推论 2.1 提供比较任意可行子集所需的交换武器；引理 4 归纳证明堆在每个前缀上都是最优可行子集，取 $i=N$ 即全集最优——其利润就是答案（最优子集一定可行，可行子集的最优利润就是最大总利润，安排的存在性由引理 1 充分性保证，无需构造）。引理 5 给出复杂度与 `i64` 的必要性。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 把"时刻 $t<D_i$"翻译成"前 $D_i$ 个格子可用"；可行性与利润分离，先研究"哪些子集排得下"。
2. **reduce to easier problem** — 可行性判据：子集可行 $\iff$ 每个 $t$ 满足"截止 $\le t$ 的件数 $\le t$" $\iff$ 按截止升序第 $k$ 件 $D_{(k)}\ge k$。
3. **consider easier version** — 先想"按利润降序 + 找空位"的贪心（正确但要并查集维护空位）；换扫描顺序寻找更轻的实现。
4. **explore its property** — 按截止升序扫描时，已选集合的截止全 $\le$ 当前 $d$，无穷多条容量约束塌缩成一条 $|H|\le d$。
5. **classic problem solution** — 反悔贪心 + 小根堆：没满直收；满了且新利润 $>$ 堆顶则换人，$O(\log N)$ 找到"最该被推翻的决策"。
6. **classic problem solution** — 交换论证（扩充引理）：小可行集总能从大可行集借元素保持可行，用"最大紧时刻"反证构造。
7. **explore its property** — 归纳证明强不变量"堆 = 前缀最优可行子集"，而非"每步局部变大"；推论 2.1 把任意对手 $S$ 压到 $w(H)-m+p$ 之下。
8. **discuss by category** — 总利润 $10^{14}$ 超 `int` 用 `i64`；$D_i\le10^9$ 但堆大小 $\le10^5$，比较安全；只求利润不构造方案。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 工作数 $N\le10^5$ | `int` | 读入 |
| `mxn` | $10^5+5$ | `constexpr int` | 约束 $+5$ |
| `a[i].d` | 第 $i$ 件工作截止 $D_i\le10^9$ | `int` | 读入；排序后升序 |
| `a[i].p` | 第 $i$ 件工作利润 $P_i\le10^9$ | `int` | 读入 |
| `Q` | **已选工作利润的小根堆**（只存利润，不存编号——不构造方案） | `priority_queue<int,vector<int>,greater<>>` | 空；堆顶 = 已选中最小利润 = 反悔时的牺牲者 |
| `ans` | 已选利润总和 | `i64` | $0$；入堆加、出堆减，与堆同步 |

### 算法步骤

1. I/O 加速三行；读 `n` 与全部 $(D_i,P_i)$。
2. 按 `d` 升序排序。
3. 顺序扫描每件 $(d,p)$：若 `(int)Q.size()<d`，`push(p)`、`ans+=p`；否则若 `p>Q.top()`，`ans-=Q.top();pop();push(p);ans+=p`；否则跳过。
4. 输出 `ans`。

### 复杂度

- 时间：$O(N\log N)$（排序 + 每件至多常数次堆操作）。
- 空间：$O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面提示例（答案 $17$）与三组手造数据（全截止 $1$ 取最大、连续反悔换人、$2\times10^9$ 超 `int` 边界）全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2949 [USACO09OPEN] Work Scheduling G
// 按截止时间升序 + 小根堆反悔贪心：没满就直收；满了且新工作更赚，就换掉堆里最不赚的
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n;
struct job{int d,p;}a[mxn];
priority_queue<int,vector<int>,greater<>>Q;
i64 ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i].d>>a[i].p;
	sort(a,a+n,[](job x,job y){return x.d<y.d;});
	for(int i=0;i<n;++i)
	{
		if((int)Q.size()<a[i].d)	// 截止前还有空时段：直接做
		{
			Q.push(a[i].p);
			ans+=a[i].p;
		}
		else if(a[i].p>Q.top())	// 满了：反悔，踢掉已选里利润最小的
		{
			ans-=Q.top();Q.pop();
			Q.push(a[i].p);
			ans+=a[i].p;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **堆里只存利润**：题目只要最大总利润，不需要方案，省掉编号与回溯；`ans` 与堆同步增减，最后就是堆内元素和。
- **`else` 分支隐含 `Q.size()==a[i].d`**：按截止升序扫描保证已选截止全 $\le d$，可行性给出 $|H|\le d$（引理 1 推论），所以"没满"只有 $<d$ 一种，"满了"恰好 $=d$，换人后数量不变仍可行（引理 3）。
- **`p>Q.top()` 用严格大于**：相等时换不换利润一样，不换省两次堆操作；正确性证明里 $p\le m$ 归入"不动"分支，两种写法都对。
- `(int)Q.size()`：`size()` 返回无符号类型，直接与 `int` 比较会触发符号转换警告/隐患，显式转 `int`（堆大小 $\le10^5$ 安全）。
- `ans` 必须 `i64`：$10^5\times10^9=10^{14}$，`int` 会在极限数据静默溢出。
- 排序比较器只比 `d`，相等截止的相对顺序任意——引理 4 的证明对同截止工作的处理顺序没有要求（它们互相之间谁先谁后，容量约束都是同一个 $d$）。
