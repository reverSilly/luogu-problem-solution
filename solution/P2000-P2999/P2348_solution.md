# P2348 三国杀I（洗牌&发牌） — 题解

## 一、解题过程：人类思考叙事

题意：$n$ 个玩家，每人要发 $4$ 张牌；牌库共 $k$ 张牌，从上到下给出，每张牌用两个字符串描述（第一个是花色+点数，第二个是类型）。先把整副牌洗 $m$ 次，再从第 $1$ 张开始依次发给第 $1,2,\dots,n,1,2,\dots$ 号玩家（第 $i$ 张给第 $(i-1)\bmod n+1$ 号）。问第 $p$ 位玩家拿到的 $4$ 张牌；牌不够则输出 `Error:cards not enough`。数据范围 $n\le1000$，$k\le10^5$，$m\le80$。

这道题没有复杂的算法，全部难点都在**把两段文字规则翻译成下标公式**。先拆成两个独立的小问题：发牌、洗牌。

**发牌**最简单。第 $i$ 张牌给第 $(i-1)\bmod n+1$ 号玩家，反过来解：第 $p$ 位玩家拿到的牌满足 $(i-1)\bmod n=p-1$，即 $i\equiv p\pmod n$。在 $1\le i\le k$ 中，满足条件的位置从 $p$ 开始，依次加 $n$：

$$i=p,\ p+n,\ p+2n,\ p+3n,\ \dots$$

每人只需要 $4$ 张，所以只取前四个。

**"牌不够"怎么判？** 每人要 $4$ 张，所以只发 $4$ 轮、共 $4n$ 张，第 $4$ 轮结束后停止，剩下的牌不再使用。按上面的公式，第 $n$ 位玩家的第 $4$ 张是第 $n+3n=4n$ 张，所以 $k\ge4n$ 时人人都够（第 $p$ 位玩家的第 $4$ 张 $p+3n\le n+3n=4n\le k$）；$k<4n$ 时第 $n$ 位玩家一定拿不满 $4$ 张，这一局发不起来，输出错误信息。判据就是 $k<4n$。

**洗牌**是重头戏。题面给出的不是"第 $x$ 张移到哪里"，而是"洗完之后，从上到下依次是原来的第 $\lfloor k/2\rfloor+1,1,\lfloor k/2\rfloor+2,2,\dots,k,\lfloor k/2\rfloor$ 张"。记 $h=\lfloor k/2\rfloor$。把牌分成上半叠 $1..h$ 与下半叠 $h+1..k$，这段话说的就是：**下半叠与上半叠交替叠放，且下半叠先放**。写成公式（$1$-based，$1\le t\le h$）：

$$\text{new}[2t-1]=\text{old}[h+t],\qquad \text{new}[2t]=\text{old}[t].$$

若 $k$ 为奇数，下半叠比上半叠多一张（旧的第 $k$ 张），它没有配对对象，按题面括号"直接忽略掉"——不是把牌扔掉，而是不参与交替，留在新牌堆的最底下。$0$-based 下统一写成

$$\text{src}(d)=\begin{cases}h+d/2,&d\text{ 为偶数},\\ d/2,&d\text{ 为奇数}.\end{cases}$$

这里有一个必须停下来想清楚的细节：**$k$ 为奇数时题面序列末尾会多写一项**。比如 $k=5,h=2$，按规律写出来是

$$3,1,4,2,5,2,$$

一共 $6$ 项，但牌只有 $5$ 张。括号里说"最后一张牌直接忽略掉"——洗牌不可能把牌弄丢，所以被忽略的是**序列里多写的那一项**，而不是物理上的最后一张牌：取前 $5$ 项得到 $3,1,4,2,5$，原来的第 $5$ 张仍然在牌堆里，只是落到了最底下。如果理解反了（以为每次洗牌要丢掉一张牌），牌数会越洗越少，后面的发牌会全错。

还有一个方向问题：题面描述的是"洗完之后从上到下是哪些旧位置"，所以是 $\text{new}[d]=\text{old}[\text{src}(d)]$；如果实现成"旧的第 $d$ 张移到新位置 $\text{src}(d)$"，得到的是逆置换。用 $k=4$ 手算就能区分：正置换给出 $3,1,4,2$，逆置换给出 $2,4,1,3$，两者不同。

**为什么这个映射一定是合法的洗牌？** 它把新牌堆的奇数位全部取自旧牌堆的下半叠、偶数位全部取自旧牌堆的上半叠，两段下标不重不漏地覆盖了 $1..k$，所以每张牌恰好出现一次。下面会严格证明它是双射。

**要洗 $m$ 次**：每次都是同一个置换作用在当前牌堆上。$m\le80$，$k\le10^5$，直接模拟 $mk\le8\times10^6$ 次搬运即可，连置换快速幂都不用。

实现时还有一个选择：是搬整张牌（两个字符串），还是只搬下标？后者更省：读入时把牌面存在 `suit[]`、`typ[]` 里，洗牌只对下标数组做置换，最后按最终下标取牌面。这样每轮只搬运 `int`，代码也更清爽。

手算核对。取 $n=2,k=8,m=1,p=1$，牌用 $1..8$ 标记：

- 一次洗牌（$h=4$）：$5,1,6,2,7,3,8,4$；
- 第 $1$ 位玩家拿第 $1,3,5,7$ 张，即 $5,6,7,8$。

再洗一次：对 $5,1,6,2,7,3,8,4$ 再作用同一置换，得 $7,5,3,1,8,6,4,2$；第 $1$ 位玩家拿第 $1,3,5,7$ 张，即 $7,3,8,4$。

奇数张：$n=1,k=5,m=1,p=1$，洗一次得 $3,1,4,2,5$，玩家 $1$ 拿走前 $4$ 张 $3,1,4,2$。

## 二、思维链：完整证明

约定：牌的位置从 $1$ 开始编号，初始时第 $i$ 张就是输入的第 $i$ 行；记 $h=\lfloor k/2\rfloor$。

**引理 1（发牌位置）**：按"第 $i$ 张给第 $(i-1)\bmod n+1$ 号"的规则，会发给第 $p$ 位玩家（$1\le p\le n$）的位置恰为

$$\{i\in[1,k]:i\equiv p\pmod n\},$$

其中前四个（若存在）是 $p,\ p+n,\ p+2n,\ p+3n$；实际发牌只取前四个。

*证明*：第 $i$ 张牌发给第 $(i-1)\bmod n+1$ 号玩家，它等于 $p$ 当且仅当 $(i-1)\bmod n=p-1$，即 $i\equiv p\pmod n$。在 $[1,k]$ 中，同余类 $p$ 的最小正整数代表是 $p$（因为 $1\le p\le n$），其余依次加 $n$，所以集合正是 $p,p+n,\dots$ 中不超过 $k$ 的那些，前四个即所述。证毕。

**引理 2（牌够的充要条件）**：每位玩家都能拿到 $4$ 张牌，当且仅当 $k\ge4n$。

*证明*：充分性：若 $k\ge4n$，对任意 $p\le n$ 有 $p+3n\le n+3n=4n\le k$，由引理 1 该玩家的前四个位置都在牌堆内，恰有 $4$ 张。必要性：若 $k<4n$，取 $p=n$，其第四个位置 $n+3n=4n>k$，故该玩家至多有 $3$ 张牌，不满足"每人 $4$ 张"。证毕。

**引理 3（洗牌的下标公式）**：一次洗牌后，新牌堆第 $d$ 张（$1$-based，$1\le d\le k$）是旧牌堆的第

$$\mathrm{src}(d)=\begin{cases}h+\dfrac{d+1}{2},&d\text{ 为奇数},\\[4pt]\dfrac{d}{2},&d\text{ 为偶数}\end{cases}$$

张。

*证明*：题面给出的新牌堆顺序是 $h+1,1,h+2,2,\dots$。对 $1\le t\le h$，第 $2t-1$ 项是 $h+t$、第 $2t$ 项是 $t$，这一点直接由"下半叠第 $t$ 张、上半叠第 $t$ 张交替"得到。

- 若 $d=2t-1$ 为奇数且 $d\le 2h$，则 $t=(d+1)/2\le h$，$\mathrm{src}(d)=h+t=h+(d+1)/2$；
- 若 $d=2t$ 为偶数，则 $t=d/2\le h$，$\mathrm{src}(d)=t=d/2$；
- 剩下唯一的可能是 $k$ 为奇数且 $d=k=2h+1$。此时下半叠的第 $h+1$ 张（旧的第 $k$ 张）没有配对对象，按题面括号"直接忽略掉"——它不参与交替，留在新牌堆最底下，即 $\mathrm{src}(k)=k$。代入公式也有 $h+(k+1)/2=h+h+1=k$。

题面把序列写成"$\dots,k,\lfloor k/2\rfloor$"，在 $k$ 为奇数时末尾会多出一项（重复了一个上半叠下标）；这一项对应的新位置 $k+1$ 不存在，直接忽略。物理上的第 $k$ 张牌没有消失，只是留在最底下。证毕。

**引理 4（洗牌是双射）**：映射 $d\mapsto\mathrm{src}(d)$ 是 $\{1,\dots,k\}$ 到自身的双射；等价地，新牌堆是旧牌堆的一个排列，不重不漏。

*证明*：分奇偶讨论取值集合。

- 奇数 $d=2t-1$：$t$ 取遍 $1,\dots,h$，取值为 $h+1,h+2,\dots,2h$，共 $h$ 个，且随 $t$ 严格递增，互不相同。
- 偶数 $d=2t$：$t$ 取遍 $1,\dots,h$，取值为 $1,2,\dots,h$，共 $h$ 个，也严格递增。
- 若 $k$ 为奇数，还剩 $d=k=2h+1$，取值为 $k$。

两段区间 $[h+1,2h]$ 与 $[1,h]$ 不交；$k$ 为偶数时 $2h=k$，两者并起来恰为 $[1,k]$；$k$ 为奇数时再并上单点 $\{2h+1=k\}$，也恰为 $[1,k]$。无论哪种情形都恰好覆盖 $[1,k]$ 中的每个位置一次。因此每个旧位置恰好被一个新位置取到一次。证毕。

**引理 5（$0$-based 公式）**：令 $d_0=d-1\in[0,k-1]$，则

$$\mathrm{src}(d)-1=\begin{cases}h+d_0/2,&d_0\text{ 为偶数},\\ d_0/2,&d_0\text{ 为奇数},\end{cases}$$

这正是代码中的 `src=(d&1)?d/2:h+d/2`（此处 `d` 为 $0$-based）。

*证明*：$d$ 为奇数时 $d_0$ 为偶数，$\mathrm{src}(d)-1=h+(d+1)/2-1=h+(d-1)/2=h+d_0/2$；$d$ 为偶数时 $d_0$ 为奇数，$\mathrm{src}(d)-1=d/2-1=(d-2)/2=d_0/2$（整数除法）。证毕。

**引理 6（多次洗牌）**：记 $P$ 为引理 3 的置换，初始牌堆为 $D_0$，洗 $t$ 次后的牌堆为 $D_t$，则

$$D_t[d]=D_0[P^t(d)],$$

其中 $P^t$ 表示 $P$ 迭代 $t$ 次。

*证明*：对 $t$ 归纳。$t=0$ 时 $D_0[d]=D_0[P^0(d)]$。设 $D_t[d]=D_0[P^t(d)]$，则洗一次后

$$D_{t+1}[d]=D_t[P(d)]=D_0[P^t(P(d))]=D_0[P^{t+1}(d)].$$

证毕。由于 $P$ 只与 $k$ 有关、与牌面内容无关，代码每轮对当前下标数组施加同一个映射，正是计算 $D_m$。

**引理 7（输出位置）**：若 $k\ge4n$，第 $p$ 位玩家的第 $t+1$ 张牌（$t=0,1,2,3$）位于洗牌后牌堆的第 $p+tn$ 个位置（$1$-based），即代码中的 $0$-based 下标 `(p-1)+t*n`。

*证明*：由引理 1，四个位置是 $p+tn$（$t=0..3$），转成 $0$-based 即 $(p-1)+tn$。由引理 6，洗 $m$ 次后的牌堆就是代码循环结束后的数组。证毕。

**定理（正确性）**：若 $k<4n$，输出 `Error:cards not enough` 正确；否则输出的四行恰为第 $p$ 位玩家按发牌顺序拿到的四张牌。

*证明*：第一种情形由引理 2 的必要性即"牌不够"成立。第二种情形由引理 2 可知每人都有 $4$ 张；由引理 3、4，每轮洗牌实现的是题面规定的双射；由引理 6，$m$ 轮后得到正确牌堆；由引理 7，取的四个位置与顺序都正确；每行按输入格式输出"花色+点数 类型"两个字符串，与题面"格式同输入"一致。证毕。

**引理 8（复杂度）**：时间复杂度 $O(mk+k)$，空间复杂度 $O(k)$。

*证明*：每轮洗牌恰好搬运 $k$ 个下标，共 $m$ 轮；读入 $k$ 张牌与输出 $4$ 行是 $O(k)$。下标数组 `cur,nxt` 各长 $k$，牌面数组各长 $k$，空间 $O(k)$。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 把洗牌看成"旧下标 → 新下标"的置换，把发牌看成"位置模 $n$ 同余"。
2. **consider easier version** — 先解决发牌：第 $p$ 位玩家的位置是 $p,p+n,p+2n,p+3n$。
3. **discuss by category** — 按 $k\ge4n$ 与 $k<4n$ 分成"正常发牌"和"输出错误"两类。
4. **explore its property** — 奇偶位置分别对应下半叠与上半叠，写出 `new[d]=old[...]` 的分段公式。
5. **碰壁 / 澄清歧义** — 奇数张时题面序列末尾多一项；洗牌不丢牌，忽略的是多余下标，用 $k=5$ 验证。
6. **classic problem solution** — 同一置换迭代 $m$ 次（$m\le80$，$k\le10^5$，$8\times10^6$ 次搬运）。
7. **实现细节** — 只洗下标不洗字符串；双缓冲避免原地覆盖。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| `n` | 玩家数 | 输入 |
| `k` | 牌数 | 输入 |
| `m` | 洗牌次数 | 输入 |
| `p` | 询问的玩家编号（$1$-based） | 输入 |
| `suit[i]` | 初始第 $i$ 张牌的花色+点数（$0$-based） | 读入后不再改变 |
| `typ[i]` | 初始第 $i$ 张牌的类型 | 读入后不再改变 |
| `cur[d]` | 当前洗牌后第 $d$ 位放的是初始第几张牌 | 初始 `cur[d]=d` |
| `nxt[d]` | 本轮洗牌的新牌堆缓冲 | 每轮覆盖 |
| `h` | $\lfloor k/2\rfloor$，上半叠大小 | 一次算好 |
| `d` | 新牌堆位置（$0$-based） | 循环变量 |
| `src` | 该位置对应的旧牌堆位置 | `(d&1)?d/2:h+d/2` |
| `id` | 第 $p$ 位玩家第 $t$ 张牌在初始牌堆中的编号 | `cur[(p-1)+t*n]` |

### 算法步骤

1. 读入 $n,k,m,p$，再读入 $k$ 张牌的两个字符串；初始化 `cur[i]=i`。
2. 若 $k<4n$，输出 `Error:cards not enough` 并结束。
3. 令 $h=k/2$，重复 $m$ 次：
   1. 对每个新位置 $d\in[0,k-1]$，按 `src=(d&1)?d/2:h+d/2` 令 `nxt[d]=cur[src]`；
   2. 把 `nxt` 复制回 `cur`。
4. 对 $t=0,1,2,3$，取 `id=cur[(p-1)+t*n]`，输出 `suit[id]` 与 `typ[id]`（空格分隔）。

### 复杂度

- 时间复杂度：$O(mk+k)$，最坏 $80\times10^5=8\times10^6$ 次下标搬运。
- 空间复杂度：$O(k)$。

### 验证状态

g++ 16.2（`-std=c++20 -O2 -Wall -Wextra`）编译通过且无警告；与"显式拆分上/下半叠交替合并"的独立暴力在 300 组随机数据（$n\le5$，$k\le30$，$m\le6$，含牌不够分支）上完全一致；手算 $k=8,m=1$ 得 `5,6,7,8`，$k=8,m=2$ 得 `7,3,8,4`，$k=5$ 得 `3,1,4,2`，$n=3,k=10$ 输出错误信息，均吻合；最大规模 $n=1000,k=10^5,m=80$ 实测约 $0.08$ 秒。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2348 三国杀I（洗牌&发牌）
// 思路：洗牌是「下半叠与上半叠交替」的固定置换，奇偶位置分别对应两段下标；
//       只对下标数组模拟 m 次洗牌，再按 (p-1)+t*n 取第 p 位玩家的 4 张牌。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n,k,m,p;
string suit[mxn],typ[mxn];
int cur[mxn],nxt[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k>>m>>p;
	for(int i=0;i<k;++i)
	{
		cin>>suit[i]>>typ[i];
		cur[i]=i;
	}
	if(k<4*n)
	{
		cout<<"Error:cards not enough\n";
		return 0;
	}
	int h=k/2;
	for(int t=0;t<m;++t)
	{
		for(int d=0;d<k;++d)
			nxt[d]=(d&1)?cur[d/2]:cur[h+d/2];	//0-based：偶数下标取下半叠，奇数下标取上半叠
		for(int d=0;d<k;++d)
			cur[d]=nxt[d];
	}
	for(int t=0;t<4;++t)
	{
		int id=cur[(p-1)+t*n];
		cout<<suit[id]<<' '<<typ[id]<<'\n';
	}
	return 0;
}
```
