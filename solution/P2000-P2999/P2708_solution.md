# P2708 硬币翻转 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一行 $n$ 个硬币（$n\le10^6$），状态是 $0/1$ 字符串，$1$ 为正面。每次操作可以选一个 $k\ge1$，把**前 $k$ 个**硬币同时翻面。求把所有硬币变成 $1$ 的最少操作次数。

**第一步：玩小例子，找操作的感觉。** 题面样例解释给了 `10` → `00` → `11`，答案 $2$。我再手算几个：

- `0`：翻前 $1$ 个，$1$ 次。
- `1`：不用动，$0$ 次。
- `00`：翻前 $2$ 个，$1$ 次。
- `01`：翻前 $1$ 个，`11`，$1$ 次。
- `010`：翻前 $1$ 个 → `110`；翻前 $2$ 个 → `000`；翻前 $3$ 个 → `111`，共 $3$ 次。能不能 $2$ 次？两次前缀翻翻的净效果是翻一个**连续区间**（先翻 $a$ 再翻 $b$，重叠部分翻两次抵消），而 `010` 需要翻位置 $1$ 和 $3$ 两个不相连的点，$2$ 次做不到。所以 $3$ 次是最优。
- `1001`：翻前 $3$ 个 → `0111`；翻前 $1$ 个 → `1111`，$2$ 次。
- `000`：翻前 $3$ 个，$1$ 次。

**第二步：发现一个自然的贪心——从右往左修。** 上面的操作序列有个共同点：**每次翻转都以"最右边的 $0$"为右端点**。为什么这样想？因为最右边的硬币只被"翻全部 $n$ 个"这一种操作影响，越靠右的硬币越"难伺候"；而翻前缀 $[1..p]$ 不会碰位置 $>p$ 的硬币。所以：

> 找到最右边的 $0$（设位置 $p$），翻前 $p$ 个。位置 $p$ 变 $1$，它右边本来就是全 $1$ 且不再被碰；新的 $0$ 只可能出现在 $p$ 左边。

于是"最右边的 $0$"严格左移，至多 $n$ 步必然全 $1$。这个贪心一定可行，但**它最优吗**？数一数上面例子的贪心步数：`10`→$2$，`010`→$3$，`1001`→$2$，`000`→$1$，`01`→$1$。

**第三步：找步数的公式。** 把答案和字符串的形状对照：

| 串 | 相邻不同对数 | 末位是 $0$？ | 答案 |
|---|---|---|---|
| `10` | $1$ | 是 | $2$ |
| `010` | $2$ | 是 | $3$ |
| `1001` | $2$ | 否 | $2$ |
| `000` | $0$ | 是 | $1$ |
| `01` | $1$ | 否 | $1$ |
| `1` | $0$ | 否 | $0$ |

规律呼之欲出：**答案 = 相邻字符不同的对数 +（末位是 $0$ 则 $1$，否则 $0$）**。等价地，在串尾补一个虚拟的 `1`，答案就是整个串（含虚拟尾）相邻不同的对数。

**第四步：为什么恰好是这个数？——每次操作只动一个"交界"。** 这是本题真正的思维跳跃。把相邻两位不同的地方叫**交界**。翻前缀 $[1..k]$ 时：

- 前缀**内部**的相邻对：两个一起翻，相同仍相同、不同仍不同，交界状态不变；
- 前缀**外部**：根本没碰；
- **唯一**受影响的是切口处那一对（第 $k$ 位与第 $k+1$ 位；$k=n$ 时是第 $n$ 位与虚拟尾 `1`）：一个翻了一个没翻，交界状态**恰好翻转**。

所以每次操作，交界总数 $\Phi$ 恰好 $+1$ 或 $-1$。目标全 $1$（含虚拟尾）没有任何交界，$\Phi=0$。从 $\Phi_0$ 走到 $0$，每步最多变 $1$，**至少要 $\Phi_0$ 步**；而第二步的贪心每步恰好把切口处的交界消掉（$\Phi$ 减 $1$），**恰好 $\Phi_0$ 步**。下界与构造吻合，贪心最优，公式得证。

**第五步：实现。** 根本不用真的模拟翻转：读入字符串，扫一遍数相邻不同对，再看末位是不是 `0`，加起来输出。$O(n)$，$n=10^6$ 轻松。

**边界核对。**

1. 全 $1$：$0$ 对交界、末位非 $0$，答案 $0$ ✓（一次都不用翻）。
2. 全 $0$：$0$ 对交界、末位是 $0$，答案 $1$ ✓（翻全部）。
3. $n=1$：`0`→$1$，`1`→$0$ ✓。
4. 操作要求"前若干个"，$k\ge1$；贪心用的 $k=p\ge1$，合法。$k=n$ 也允许（样例第 $2$ 步就是翻全部）。
5. 答案最大 $n$（交替串 `0101...0` 之类），`int` 足够。

## 二、思维链：完整证明

**记号。** 硬币串 $s_1s_2\dots s_n\in\{0,1\}^n$。操作 $\mathrm{flip}(k)$（$1\le k\le n$）：把 $s_1..s_k$ 逐位取反。补虚拟尾 $s_{n+1}=1$（**永不参与翻转**）。定义交界数

$$\Phi(s)=\bigl|\{\,i\in[1,n]:s_i\ne s_{i+1}\,\}\bigr|.$$

注意 $i=n$ 这一对就是"末位与虚拟尾 $1$"，故 $\Phi(s)=\bigl(\text{原串相邻不同对数}\bigr)+[s_n=0]$。

---

### 引理 1（目标态刻画）

$\Phi(s)=0\iff s$ 全为 $1$。

*证明*：$\Phi(s)=0$ 意味着 $s_1=s_2=\dots=s_n=s_{n+1}=1$（每一对都相同，链条传递到虚拟尾），故全 $1$。反之全 $1$ 时每对都相同，$\Phi=0$。证毕。

---

### 引理 2（单次操作对 $\Phi$ 的影响：恰好 $\pm1$）

对任意 $s$ 与 $1\le k\le n$，$\Phi(\mathrm{flip}(k)(s))=\Phi(s)\pm1$。具体地：只有第 $k$ 对交界（$s_k$ 与 $s_{k+1}$ 之间）的状态翻转，其余 $n-1$ 对不变。

*证明*：逐对检查第 $i$ 对（$s_i,s_{i+1}$），$i=1..n$：

- $i<k$：两位都在前缀内，都被取反。取反是双射且保持"相等/不等"：$\bar a=\bar b\iff a=b$。故该对交界状态不变。
- $i>k$：两位都在前缀外（$i\ge k+1$），都没被碰，状态不变。
- $i=k$：$s_k$ 被取反、$s_{k+1}$ 不变（$k=n$ 时 $s_{n+1}$ 是虚拟尾，按定义不翻）。于是 $s_k\ne s_{k+1}$ 变成 $\bar s_k=s_{k+1}$ 或反之——**恰好翻转**。

综上恰有一对状态翻转，$\Phi$ 变化 $\pm1$。证毕。

---

### 引理 3（下界）

任何把 $s$ 变成全 $1$ 的操作序列，长度 $\ge\Phi(s)$。

*证明*：设序列长 $t$，状态列 $s^{(0)}=s,s^{(1)},\dots,s^{(t)}$ 全 $1$。由引理 2，$|\Phi(s^{(j)})-\Phi(s^{(j-1)})|=1$，故由三角不等式
$$\Phi(s)=|\Phi(s^{(0)})-\Phi(s^{(t)})|\le\sum_{j=1}^{t}|\Phi(s^{(j)})-\Phi(s^{(j-1)})|=t.$$
（其中 $\Phi(s^{(t)})=0$ 由引理 1。）证毕。

---

### 引理 4（贪心构造：每步 $\Phi$ 减 $1$，且必然终止）

策略：若 $s$ 不全 $1$，取最右边的 $0$ 的位置 $p$（即 $s_p=0$ 且 $s_{p+1}=\dots=s_n=1$），执行 $\mathrm{flip}(p)$。则：

(a) 该步使 $\Phi$ 恰好减 $1$；
(b) 步后最右边的 $0$ 的位置严格小于 $p$（若还有 $0$）；
(c) 至多 $\Phi(s)$ 步后全 $1$。

*证明*：

(a) 由 $p$ 的定义，$s_p=0$ 而 $s_{p+1}=1$（$p<n$ 时由"最右 $0$"保证；$p=n$ 时 $s_{n+1}=1$ 是虚拟尾），故第 $p$ 对是交界。由引理 2，$\mathrm{flip}(p)$ 只翻转第 $p$ 对：交界变非交界，$\Phi$ 减 $1$。

(b) $\mathrm{flip}(p)$ 后 $s_p=1$，位置 $>p$ 的硬币未被触碰仍全 $1$，故位置 $\ge p$ 不再有 $0$；新的 $0$ 只可能在 $<p$ 处（前缀内部翻出来的）。

(c) 由 (b)，"最右 $0$ 位置"这个非负整数每步严格减小，故至多 $n$ 步内不存在 $0$，即全 $1$。更紧地：由 (a) 每步 $\Phi$ 减 $1$ 且 $\Phi\ge0$，至多 $\Phi(s)$ 步后 $\Phi=0$，由引理 1 即全 $1$。证毕。

---

### 定理（答案公式）

最少操作次数 $=\Phi(s)=\bigl|\{i\in[1,n-1]:s_i\ne s_{i+1}\}\bigr|+[s_n=0]$。

*证明*：引理 3 给出下界 $\Phi(s)$；引理 4 给出达到 $\Phi(s)$ 步的构造。上下界吻合，故最优值恰为 $\Phi(s)$。展开定义即公式。证毕。

**推论（贪心最优性）**：引理 4 的"翻到最右 $0$"贪心就是最优策略之一——它每步都踩在下界要求的 $-1$ 上。任何"浪费步"（$\Phi$ 加 $1$ 的操作）都会让总步数严格超过下界。

---

### 引理 5（复杂度）

时间 $O(n)$，空间 $O(n)$（存字符串；若逐字符流式读入可降到 $O(1)$ 额外空间）。

*证明*：读入 $n$ 个字符 $O(n)$；一遍扫描做 $n-1$ 次相邻比较与一次末位判断，$O(n)$。答案 $\le n\le10^6$，`int` 安全。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 手玩 `10`、`010`、`1001` 等小例子，确认操作是前缀翻转、$k$ 可取 $1..n$。
- consider easier version — 两次操作的净效果 = 翻一个连续区间（重叠抵消），由此判定 `010` 两步不可行。
- explore its property — 发现"从右往左修"贪心：翻到最右 $0$，右侧成果永不破坏，最右 $0$ 严格左移 ⇒ 必然终止。
- explore its property — 数小例子答案，猜出公式：相邻不同对数 + 末位 $0$ 指示。
- reduce to easier problem — 补虚拟尾 `1`，把公式统一成"交界总数 $\Phi$"。
- classic problem solution — 势函数（potential）论证：每次前缀翻转只翻转切口处一个交界 ⇒ $\Delta\Phi=\pm1$ ⇒ 下界 $\Phi_0$；贪心每步 $-1$ 达到下界。
- discuss by category — 全 $1$、全 $0$、$n=1$、$k=n$ 合法性、答案上界 $n$，逐类核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `s` | 硬币串，$s_i\in\{0,1\}$ | `string`，读入 | 内部 0-based：`s[i]` 是第 $i+1$ 个硬币 |
| `n` | 硬币数 $\le10^6$ | `int`，`s.size()` | |
| `ans` | 最少操作次数 $=\Phi(s)$ | `int`，初值 `(s.back()=='0')` | 先记"末位与虚拟尾 1"的那对交界 |
| $\Phi$ | 交界总数（含虚拟尾 `1`） | 数学量 | 每次操作恰好 $\pm1$；全 $1\iff\Phi=0$ |

### 算法步骤

1. I/O 加速三行，读入字符串 `s`。
2. `ans=(s.back()=='0')`（末位与虚拟尾的交界）。
3. 对 $i=0..n-2$：若 `s[i]!=s[i+1]` 则 `++ans`。
4. 输出 `ans`。

### 复杂度

- 时间：$O(n)$，$n\le10^6$，一遍扫描。
- 空间：$O(n)$ 存串（约 $1$ MB）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；`10`→$2$（与题面样例解释一致）、`010`→$3$、`1001`→$2$、`0`→$1$、`1`→$0$、`000`→$1$、`01`→$1$、`111`→$0$ 全部与手算一致。公式已由势函数上下界封闭证明，不做对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2708 硬币翻转
// 补虚拟尾 1，答案 = 交界总数 Φ：相邻不同对数 + [末位为 0]
// 每次前缀翻转只翻转切口处一个交界（ΔΦ=±1）⇒ 下界 Φ；
// "翻到最右 0"贪心每步 -1 ⇒ 恰好 Φ 步，最优。无需真的模拟翻转。
#include<bits/stdc++.h>
using namespace std;

string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	int n=s.size();
	int ans=(s[n-1]=='0');	// 末位与虚拟尾 1 的交界
	for(int i=0;i+1<n;++i)
		if(s[i]!=s[i+1])
			++ans;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `ans` 初值就是"末位是否为 $0$"：把虚拟尾 `1` 的那对交界先计入，循环只数原串内部的 $n-1$ 对，两者合起来恰是 $\Phi$。
- 全局 `string` 默认空，但本题读入后立即使用，无初始化陷阱；答案数组不存在，也就没有"全局默认 0 误当可达"的问题。
- 不模拟翻转：模拟是 $O(n\cdot\text{答案})$ 最坏 $O(n^2)$，$n=10^6$ 会超时；公式扫描 $O(n)$ 才是正解。
- $n=1$ 时循环不执行，`ans` 就是末位判断，正确覆盖最小数据。
