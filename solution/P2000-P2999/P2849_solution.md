# P2849 [USACO14DEC] Marathon S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 个检查点（$3\le N\le500$）必须**按编号顺序**访问，坐标 $[-1000,1000]$，两点间距离是曼哈顿距离 $|x_1-x_2|+|y_1-y_2|$。Bessie 要跳过 $K$ 个检查点（$K<N$），但**第 $1$ 个和第 $N$ 个不能跳**。求跳过后的最短总路程。可能有检查点重合，跳过重合点中的一个仍算跳过一个。

**口径说明（题面歧义的处理）。** 题面说"跳过 $K$ 个"，字面是**恰好** $K$ 个；但端点不可跳，实际可跳上限是 $N-2$，而题目只保证 $K<N$。下面会证明：由曼哈顿三角不等式，**多跳一个点绝不会让最短路程变长**，所以"恰好 $K$"与"至多 $K$"在 $K\le N-2$ 时答案完全相同；若数据出现 $K=N-1$，唯一自洽的解读是"至多 $K$"，答案等于跳 $N-2$ 个。我按 $\texttt{dp}[N-1][\min(K,N-2)]$ 实现，两种口径统一覆盖，并在此显式标注该假设。

**第一步：暴力有多暴力？** 路线就是"保留端点的一个子序列"，方案数 $\binom{N-2}{K}$。$N=500,K=249$ 时约 $10^{148}$，宇宙原子数级别，彻底没戏。必须找结构。

**第二步：从 $K=0,1$ 的容易版本入手。**

- $K=0$：答案就是 $\sum_{i=1}^{N-1} d(i,i+1)$，一遍扫描。
- $K=1$：跳掉中间点 $b$（前后保留点为 $a,c$），路程变化量是"收益" $g(b)=d(a,b)+d(b,c)-d(a,c)$。由三角不等式 $g(b)\ge0$——**跳点永远不亏**。枚举每个中间点取最大收益，$O(N)$。

这里收获两条关键性质：(1) 跳点不亏（三角不等式）；(2) 收益只取决于**被跳点及其前后两个保留点**，与更远的路线无关。

**第三步：$K\ge2$ 先试贪心，然后撞墙。** 既然每次跳点都有非负收益，自然想"重复 $K$ 次：跳掉当前收益最大的点"。但收益是**耦合**的：跳掉一个点后，它的邻居们的"前后保留点"变了，收益全部要重算；两个单独看收益为 $0$ 的相邻点，一起跳可能收益巨大。

构造最小反例（$N=6,K=2$）：检查点依次为
$$(0,0),\ (1,1),\ (2,0),\ (4,0),\ (4,2),\ (2,2).$$
相邻距离全为 $2$，原路程 $10$。单点收益：跳 $(1,1)$ 得 $g=2+2-2=2$；其余三个中间点的 $g$ 全是 $0$（路径在那些点处恰好"顺路"）。贪心第一步跳 $(1,1)$，之后所有收益归零，总路程 $8$。但最优是**同时跳 $(4,0),(4,2)$**：路线变成 $(0,0)\to(1,1)\to(2,0)\to(2,2)$，路程 $2+2+2=6$。这两个点单独跳收益都是 $0$，合跳却省 $4$——因为它们构成一个"绕出去的方形弯"，只有把弯的两个角一起剪掉，弦才拉得直。贪心 $8>$ 最优 $6$，淘汰。

**第四步：失败的教训指向状态设计。** 贪心错在"局部收益"不等于"全局贡献"。要全局最优，就得让 DP 替我们枚举所有子序列——但不能指数级枚举。观察：一条路线的后续代价只取决于**最后一个保留点是谁**（决定下一段距离从哪量起）和**已经跳了几个**（决定还剩多少跳点额度）。历史路径怎么绕的，只要这两项相同就完全等价。于是状态：

$$\texttt{dp}[i][j]=\text{从点 }0\text{ 走到点 }i\text{（}i\text{ 必须保留）、在 }1..i-1\text{ 中恰好跳了 }j\text{ 个的最短路程}.$$

转移枚举**上一个保留点** $p<i$：那么 $p+1..i-1$ 全部被跳，共 $i-p-1$ 个，前缀路程就是 $\texttt{dp}[p][j-(i-p-1)]$：

$$\texttt{dp}[i][j]=\min_{\substack{0\le p<i\\ i-p-1\le j}}\bigl(\texttt{dp}[p][j-(i-p-1)]+d(p,i)\bigr).$$

为什么枚举"上一个保留点"而不是"上一个点跳没跳"？因为若只记 $i-1$ 跳没跳，跳了之后还得知道再上一个保留点是谁才能算距离——信息不够，状态就得再加维。直接枚举 $p$ 把"连续跳一段"一次性打包，状态二维就封闭了。这是本题真正的思维跳跃。

**第五步：单调性把口径问题顺手解决。** 引理 2 证明 $\mathrm{OPT}(j+1)\le\mathrm{OPT}(j)$（只要还能再跳）：在最优路线里任取一个被保留的中间点剪掉，三角不等式保证路程不增。所以"恰好 $K$"的最优值就是"至多 $K$"的最优值（$K\le N-2$），答案取 $\texttt{dp}[N-1][\min(K,N-2)]$。

**第六步：实现坑。**

1. **INF 预填充**：`dp` 是全局数组默认 $0$，而 $0$ 是合法路程。不可达状态（如 $\texttt{dp}[0][j>0]$、$\texttt{dp}[p][p]$）必须显式 `fill_n(&dp[0][0],mxn*mxn,inf)`，否则 $0$ 会被当成"零代价可达"静默传播。
2. **INF 算术**：单段距离 $\le4000$，$\texttt{inf}+4000=1145145919<2^{31}-1$ 不溢出；$\min(\texttt{inf},\texttt{inf}+4000)=\texttt{inf}$，脏值不会污染答案。
3. **循环边界**：$j\le\min(K,i-1)$（$1..i-1$ 只有 $i-1$ 个可跳）；$p$ 从 $i-1$ 递减到 $i-1-j$（再往前跳的个数就超 $j$ 了）。$p=0$ 时只有 $j=i-1$ 才合法，对应 $\texttt{dp}[0][0]=0$。
4. **重合点**：检查点按**下标**区分，重合只是距离为 $0$，DP 天然正确，无需去重。

**手造数据核对**（题面无样例）：

| 输入 | 手算 | 说明 |
|---|---|---|
| `6 2` / 上文反例六点 | $6$ | 贪心给 $8$，DP 必须给 $6$ |
| `3 1` / `(0,0),(1,1),(2,0)` | $2$ | 跳中间，$d=2$ |
| `3 0` / 同上 | $4$ | $K=0$ 直接求和 |
| `4 2` / `(0,0),(1,0),(2,0),(3,0)` | $3$ | 共线，跳两个中间点 |
| `3 2` / `(0,0),(1,1),(2,0)` | $2$ | $K=N-1$ 口径测试：按"至多"落到跳 $1$ 个 |

## 二、思维链：完整证明

**记号。** 点下标 $0..N-1$（输入第 $i$ 个转为 $i-1$）。$d(u,v)=|x_u-x_v|+|y_u-y_v|$。"路线"指下标严格递增的子序列 $0=i_0<i_1<\dots<i_m=N-1$，代价 $\sum_{t=1}^{m}d(i_{t-1},i_t)$；跳过的点数 $=(N-2)-(m-1)$（中间点共 $N-2$ 个，保留 $m-1$ 个）。$\mathrm{OPT}(j)$ 为恰好跳 $j$ 个中间点的最小代价。$\texttt{dp}[i][j]$ 如正文定义（$i$ 保留，$1..i-1$ 中恰跳 $j$ 个）。

### 引理 1（曼哈顿距离满足三角不等式）

对任意三点 $a,b,c$：$d(a,c)\le d(a,b)+d(b,c)$。

*证明*：先证实数绝对值不等式 $|u+v|\le|u|+|v|$：由 $u\le|u|,\ v\le|v|$ 得 $u+v\le|u|+|v|$；由 $-u\le|u|,\ -v\le|v|$ 得 $-(u+v)\le|u|+|v|$。而 $|u+v|=\max(u+v,-(u+v))$，故 $|u+v|\le|u|+|v|$。

取 $u=x_a-x_b,\ v=x_b-x_c$，则 $u+v=x_a-x_c$，得 $|x_a-x_c|\le|x_a-x_b|+|x_b-x_c|$；对 $y$ 坐标同理。两式相加即 $d(a,c)\le d(a,b)+d(b,c)$。证毕。

**推论**：单点收益 $g(b)=d(a,b)+d(b,c)-d(a,c)\ge0$；连续跳一段 $p+1..i-1$ 的收益 $d(p,p+1)+\dots+d(i-1,i)-d(p,i)\ge0$（反复用引理 1 归纳）。

### 引理 2（单调性：$\mathrm{OPT}(j+1)\le\mathrm{OPT}(j)$，"恰好"与"至多"同值）

对 $0\le j<N-2$，$\mathrm{OPT}(j+1)\le\mathrm{OPT}(j)$。从而当 $K\le N-2$ 时 $\min_{j\le K}\mathrm{OPT}(j)=\mathrm{OPT}(K)$；"至多跳 $K$ 个"的最优值也是 $\mathrm{OPT}(K)$。

*证明*：取达到 $\mathrm{OPT}(j)$ 的路线。它保留了 $(N-2)-j\ge1$ 个中间点（因 $j<N-2$），任取其中一个 $b$，设其在路线中的前后保留点为 $a,c$（端点 $0,N-1$ 恒保留，故 $a,c$ 存在）。把 $b$ 从路线中删除：新路线仍严格递增、仍含两端点，跳过数变为 $j+1$，合法。代价变化为 $d(a,c)-d(a,b)-d(b,c)\le0$（引理 1）。故 $\mathrm{OPT}(j+1)\le$ 新路线代价 $\le\mathrm{OPT}(j)$。

反复应用得 $\mathrm{OPT}(0)\ge\mathrm{OPT}(1)\ge\dots\ge\mathrm{OPT}(N-2)$，所以 $\min_{j\le K}\mathrm{OPT}(j)=\mathrm{OPT}(\min(K,N-2))$。"恰好 $K$"（$K\le N-2$）与"至多 $K$"都等于它；$K=N-1$ 时"恰好"无合法方案，按"至多"口径取 $\mathrm{OPT}(N-2)$。证毕。

### 引理 3（DP 转移的正确性）

$\texttt{dp}[0][0]=0$；$\texttt{dp}[0][j]=+\infty\ (j\ge1)$。对 $i\ge1$、$0\le j\le i-1$：
$$\texttt{dp}[i][j]=\min_{\substack{0\le p<i\\ i-p-1\le j}}\bigl(\texttt{dp}[p][j-(i-p-1)]+d(p,i)\bigr),$$
且 $\texttt{dp}[i][j]$ 恰为"从 $0$ 到 $i$、$i$ 保留、$1..i-1$ 中恰跳 $j$ 个"的最小代价；$j>i-1$ 时不可达，值为 $+\infty$。

*证明*：对 $i$ 归纳。$i=0$：路线只有点 $0$，跳 $0$ 个，代价 $0$；$j\ge1$ 无方案（$1..-1$ 为空），$+\infty$。成立。

设 $i\ge1$，且所有 $p<i$ 的行已正确。记 $S=j-(i-p-1)$。

**($\ge$)**：取达到 $\texttt{dp}[i][j]$ 的最优路线，设最后一个保留点之前的保留点为 $p$（$p<i$；$m\ge1$ 因 $i\ge1$ 且 $0$ 恒保留，若路线只有 $0,i$ 则 $p=0$）。则 $p+1..i-1$ 全被跳，共 $i-p-1$ 个，故 $j\ge i-p-1$，即 $p$ 在 $\min$ 的枚举范围内。路线去掉最后一段 $p\to i$，剩下是"从 $0$ 到 $p$、$p$ 保留、$1..p-1$ 中恰跳 $S$ 个"的合法路线（跳过的点集不变，只是不再含 $p+1..i-1$ 这段），其代价 $\ge\texttt{dp}[p][S]$（归纳假设）。故 $\texttt{dp}[i][j]\ge\texttt{dp}[p][S]+d(p,i)\ge\min$ 右端。

**($\le$)**：对任一合法 $p$，取达到 $\texttt{dp}[p][S]$ 的路线（若为 $+\infty$ 则该项为 $+\infty$，不等式平凡），追加边 $p\to i$：新路线严格递增、含 $0$ 与 $i$，在 $1..i-1$ 中跳过的恰是"前缀跳的 $S$ 个"加上 $p+1..i-1$ 共 $S+(i-p-1)=j$ 个，合法，代价 $\texttt{dp}[p][S]+d(p,i)$。故 $\texttt{dp}[i][j]\le$ 右端每一项，$\le\min$。

夹逼得等式。可达性：$j\le i-1$ 时任选 $j$ 个中间点跳掉即得合法路线，故有限；$j>i-1$ 时方案不存在，$+\infty$。归纳完成。

**良基性**：转移只引用 $p<i$ 的行，按 $i$ 升序计算时所有引用均已就绪，无循环依赖。证毕。

### 引理 4（代码循环恰好实现引理 3，且 INF 语义全程保持）

代码：`fill_n(&dp[0][0],mxn*mxn,inf); dp[0][0]=0;` 然后 `for i=1..n-1, for j=0..min(k,i-1), for p=i-1 downto 0 while i-p-1<=j: dp[i][j]=min(dp[i][j],dp[p][j-(i-p-1)]+dis(p,i))`。则：(a) 每个被计算的 $\texttt{dp}[i][j]$ 等于引理 3 的值；(b) 未被计算的状态保持 `inf`，且恰为不可达状态；(c) 全程无溢出、无脏值传播。

*证明*：(a) 外层 $i$ 升序保证引理 3 的良基性。内层 $j$ 枚举 $0..\min(k,i-1)$：对每个 $j$，$p$ 从 $i-1$ 递减，条件 $i-p-1\le j\iff p\ge i-1-j$，恰好枚举引理 3 中 $\max(0,i-1-j)\le p\le i-1$ 的全部合法 $p$（$p<0$ 时循环终止）。$\texttt{dp}[i][j]$ 初值 `inf` 相当于 $\min$ 从 $+\infty$ 开始累积。故计算结果与引理 3 一致。

(b) 被跳过的状态分两类：$j>i-1$（不可达，引理 3）；$j>k$（可达但本题用不到——任何转移引用的第二维 $S=j-(i-p-1)\le j\le k$，答案第二维 $\min(k,n-2)\le k$，故 $j>k$ 的格子永不被读）。两类都保持 `inf`，语义安全。特别地 $\texttt{dp}[p][p]$（$p\ge1$）属于 $j>i-1$ 类，保持 `inf`；当 $j=i-1$ 且 $p$ 使 $S=p$ 时引用它，候选值 $\texttt{inf}+d>\texttt{inf}$，$\min$ 不选，正确排除"在 $1..p-1$ 中跳 $p$ 个"的不可能方案。

(c) 值域：有限 $\texttt{dp}$ 值 $\le(N-1)\cdot4000\le1.996\times10^6$（每段 $d\le|{\pm}2000|+|{\pm}2000|=4000$，至多 $N-1$ 段）；出现的最大算术值 $\texttt{inf}+4000=1145145919<2^{31}-1$，无溢出。$\min(\texttt{inf},\texttt{inf}+4000)=\texttt{inf}$，不可达不会传播出 $\texttt{inf}+4000$ 之类的脏值；有限值只会与有限值或 $\texttt{inf}+d$ 比较，$\min$ 结果要么保持要么变小，不变量"$\texttt{dp}\in\{\text{真实值}\}\cup\{\texttt{inf}\}$"由对操作次数的归纳保持。证毕。

### 引理 5（答案与复杂度）

答案为 $\texttt{dp}[N-1][\min(K,N-2)]$。时间 $O(N\cdot K^2)$（最坏约 $6.3\times10^7$），空间 $O(N^2)$。

*证明*：答案正确性：$\texttt{dp}[N-1][j]$ 是"全程、终点保留、恰跳 $j$ 个"的最优值即 $\mathrm{OPT}(j)$（引理 3 取 $i=N-1$）；由引理 2，"至多 $K$"与"恰好 $K$（$K\le N-2$）"的最优值都是 $\mathrm{OPT}(\min(K,N-2))$，即该格子。

时间：对固定 $i$，$j$ 跑 $0..m$（$m=\min(k,i-1)$），每个 $j$ 的 $p$ 循环恰 $j+1$ 次，共 $\sum_{j=0}^{m}(j+1)=(m+1)(m+2)/2$ 次 $O(1)$ 转移。对 $i$ 求和 $\le N\cdot(K+1)(K+2)/2\le500\times499\times500/2=62\,375\,000$。空间：`dp` 为 $505\times505$ 个 `int` $\approx1$ MB，坐标 $O(N)$。证毕。

### 定理

程序输出按题面口径（"恰好 $K$"，$K\le N-2$；或等价的"至多 $K$"）跳过检查点后的最短曼哈顿路程，复杂度 $O(NK^2)$。

*证明*：引理 1 提供三角不等式这一几何地基；引理 2 用它证明单调性，统一两种口径并给出 $K=N-1$ 的自洽落点；引理 3 证明二维状态 + 枚举上一保留点的转移正确；引理 4 证明代码循环、INF 预填充与算术安全逐条落实引理 3；引理 5 给出答案格子与复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **consider easier version** — $K=0$ 直接求和；$K=1$ 枚举单点收益 $g(b)=d(a,b)+d(b,c)-d(a,c)$，$O(N)$。
2. **explore its property** — 曼哈顿三角不等式 ⇒ 收益恒 $\ge0$，跳点永远不亏；收益只依赖被跳点与前后保留点。
3. **classic problem solution** — 试贪心"重复取最大收益"，$N=6$ 反例否定：相邻两点单独收益 $0$、合跳收益 $4$，收益耦合不可局部决策。
4. **reduce to easier problem** — 路线 = 保端子序列；后续代价只依赖（最后保留点，已跳数）⇒ 二维 DP，转移枚举上一保留点 $p$，把"连续跳一段"打包。
5. **explore its property** — 单调性 $\mathrm{OPT}(j+1)\le\mathrm{OPT}(j)$ ⇒ "恰好 $K$"="至多 $K$"，$K=N-1$ 落到 $N-2$，口径歧义被数学消解。
6. **discuss by category** — `dp` 必须 `fill_n` 成 INF（$0$ 是合法路程）；$\texttt{inf}+4000$ 不溢出；$j\le\min(K,i-1)$、$p\ge i-1-j$ 的边界；重合点按下标区分无需去重。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 检查点数 $N\le500$ | `int` | 读入 |
| `k` | 要跳的个数 $K<N$ | `int` | 读入；实际用 $\min(K,N-2)$ |
| `mxn` | $500+5$ | `constexpr int` | 两维共用 |
| `inf` | 不可达哨兵 $1145141919$ | `constexpr int` | $+4000$ 仍不溢出 `int` |
| `x[i],y[i]` | 第 $i$ 个检查点坐标（0-based） | `int[mxn]` | 读入，$\pm1000$ |
| `dp[i][j]` | 到达 $i$（保留）、$1..i-1$ 中恰跳 $j$ 个的最短路程 | `int[mxn][mxn]` | **`fill_n(&dp[0][0],mxn*mxn,inf)`**，`dp[0][0]=0` |
| `dis(u,v)` | 曼哈顿距离 $|x_u-x_v|+|y_u-y_v|$ | `int(int,int)` | $\le4000$ |
| `i,j,p` | 当前点 / 已跳数 / 上一保留点 | `int` | $p$ 递减至 $i-1-j$ |

### 算法步骤

1. I/O 加速三行；读 `n,k` 与坐标。
2. `fill_n(&dp[0][0],mxn*mxn,inf)`；`dp[0][0]=0`。
3. 对 `i=1..n-1`、`j=0..min(k,i-1)`：对 `p=i-1` 递减且 `i-p-1<=j`，执行 `dp[i][j]=min(dp[i][j],dp[p][j-(i-p-1)]+dis(p,i))`。
4. 输出 `dp[n-1][min(k,n-2)]`。

### 复杂度

- 时间 $O(NK^2)\le6.3\times10^7$ 次 $O(1)$ 转移；空间 $O(N^2)\approx1$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；五组手造数据（贪心反例 $\to6$、$K=1\to2$、$K=0\to4$、共线 $\to3$、$K=N-1$ 口径 $\to2$）全部与手算一致；$300$ 组随机小数据（$N\le9$，含 $K=N-1$）与位掩码枚举跳过集合的独立暴力逐组一致。

```cpp
// 题目：P2849 [USACO14DEC] Marathon S
// dp[i][j]=到点 i（保留）、1..i-1 中恰跳 j 个的最短曼哈顿路程
// 枚举上一保留点 p：p+1..i-1 全跳（i-p-1 个），dp[i][j]=min(dp[p][j-(i-p-1)]+d(p,i))
// 三角不等式 ⇒ 多跳不亏 ⇒ "恰好 K"="至多 K"，答案 dp[n-1][min(k,n-2)]
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{505};
constexpr int inf{1145141919};

int n,k,x[mxn],y[mxn],dp[mxn][mxn];

int dis(int u,int v)
{
	return abs(x[u]-x[v])+abs(y[u]-y[v]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];
	fill_n(&dp[0][0],mxn*mxn,inf);	// 全局默认 0 是合法路程，必须显式填 INF
	dp[0][0]=0;
	for(int i=1;i<n;++i)
		for(int j=0;j<=k&&j<=i-1;++j)
			for(int p=i-1;p>=0&&i-p-1<=j;--p)	// p+1..i-1 全跳，共 i-p-1 个
				dp[i][j]=min(dp[i][j],dp[p][j-(i-p-1)]+dis(p,i));
	cout<<dp[n-1][min(k,n-2)]<<'\n';
	return 0;
}
```

### 代码说明

- 转移的核心是"上一保留点 $p$"：$p$ 与 $i$ 之间的点**整段被跳**，个数 $i-p-1$ 直接从 $j$ 里扣。若只记"$i-1$ 跳没跳"，距离就没法算——状态必须记住最后保留点，这正是贪心失败后补上的信息。
- `p` 循环条件 `i-p-1<=j` 随 `p` 递减单调变紧，一旦不满足后面全不满足，直接终止即可；`j<=i-1` 保证第二维不越可达域，`dp[p][p]` 这类不可达格子保持 `inf`，候选值 `inf+dis>inf` 被 `min` 自动排除（引理 4）。
- `fill_n(&dp[0][0],mxn*mxn,inf)` 一次填平整个二维数组；只填 `dp[0][0]=0` 一个可达初值。
- 答案 `min(k,n-2)`：端点不可跳，可跳上限 $N-2$；由单调性（引理 2），这也正是"至多 $K$"口径的答案，$K=N-1$ 的数据不会越界也不会无解。
- 全程 `int`：路程 $\le4000\times499<2\times10^6$，`inf+4000` 不溢出，无需 `i64`。
