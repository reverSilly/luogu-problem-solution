# P2988 [USACO10MAR] Test Taking S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 道判断题（$N\le 10^6$）。可靠消息：正确答案为 true 的题数 $t$ 一定属于给定集合 $\{t_1,\dots,t_K\}$（$0\le t_i\le N$，$0\le K\le 10^4$），但**不知道具体哪几题是 true**。约翰要交一张确定的答卷，求他**保证**能拿到的最高分——即"约翰先选答卷，对手再选最坏的 $t$ 与最坏的 true 分布"这个 maximin 博弈的值。输出一行一个整数。

**口径说明（一处）。** $K$ 可以为 $0$。此时没有任何消息，合理的解读是 $t$ 可以是 $[0,N]$ 中任意值，对手取 $t$ 等于约翰答 true 的题数即可让"最坏得分"压到 $0$（下文引理 2 的公式对任意 $t$ 成立，取 $t=N-x$ 得 $0$），故 $K=0$ 输出 $0$。依据：消息集合为空 = 无约束，而不是"不存在合法考试"。

**第一步：答卷的"形状"重要吗？** 约翰答 $x$ 个 true、$N-x$ 个 false。对手知道约翰的答卷，要选 $t\in T$ 和"哪 $t$ 题为 true"来最小化得分。由于所有题在对手眼里地位对称（消息只约束数量），**具体哪几题答 true 不影响最坏得分**——对手总能把 true 尽量安排在约翰答 false 的题上。所以答卷只需优化一个数 $x\in[0,N]$。这一步把 $2^N$ 种答卷压成 $N+1$ 种。

**第二步：算最坏得分。** 设约翰答 true 的题里实际有 $a$ 题为 true。则答对题数 = （true 中答对的 $a$）+（false 中答对的：约翰答 false 共 $N-x$ 题，其中实际 true 的有 $t-a$ 题，故答对 $N-x-(t-a)$ 题）：

$$\text{score}=a+(N-x-t+a)=N-x-t+2a.$$

对手要最小化 $a$。$a$ 能多小？true 共 $t$ 个，约翰答 false 的"坑位"有 $N-x$ 个：若 $t\le N-x$，true 全塞进坑位，$a=0$；否则塞满坑位后还剩 $t-(N-x)$ 个 true 必须落在约翰答 true 的题上，$a=t-(N-x)$。合起来 $a_{\min}=\max(0,\,x+t-N)$，且这个下界**可以取到**（构造如上）。代入：

$$\text{worst}(x,t)=N-x-t+2\max(0,x+t-N)=\begin{cases}N-x-t,&x+t\le N\\ x+t-N,&x+t>N\end{cases}=\bigl|N-x-t\bigr|.$$

绝对值冒出来的那一刻，题目结构就清楚了。

**第三步：换元，归约成数轴问题。** 令 $y=N-x$（约翰答 false 的题数），$x\in[0,N]\iff y\in[0,N]$。要求

$$\max_{y\in[0,N]\cap\mathbb Z}\ \min_{t\in T}\ |y-t|.$$

这是经典问题：**在数轴区间 $[0,N]$ 里找一个整点，使它到给定点集的最近距离最大**。直觉：最远点要么在区间端点，要么在两个相邻给定点的正中间。

**第四步：候选点枚举。** 把 $T$ 排序。距离函数 $g(y)=\min_i|y-t_i|$ 是分段线性的"锯齿"：

- $y\le t_{\min}$：$g(y)=t_{\min}-y$，递减，最优在左端点 $y=0$，值 $t_{\min}$；
- $y\ge t_{\max}$：$g(y)=y-t_{\max}$，递增，最优在右端点 $y=N$，值 $N-t_{\max}$；
- $y$ 在相邻两点 $t_i\le t_{i+1}$ 之间：最近的给定点必是这两个邻居之一，$g(y)=\min(y-t_i,\ t_{i+1}-y)$，在中点取最大；整点限制下最大值是 $\lfloor(t_{i+1}-t_i)/2\rfloor$（取 $y=t_i+\lfloor\text{gap}/2\rfloor$）。

三类候选取 max 即答案。重复的 $t_i$ 产生 gap$=0$，贡献 $0$，无害。

**第五步：复杂度与范围。** 排序 $O(K\log K)$，$K\le 10^4$；$N\le 10^6$，答案 $\le N$，`int` 足够。注意 $N$ 很大但**不需要**开 $O(N)$ 数组——算法只跟 $K$ 个点有关。

**用题面例子核对。** $N=6$，$T=\{0,3\}$：端点候选 $t_{\min}=0$、$N-t_{\max}=3$；间隙候选 $\lfloor3/2\rfloor=1$。答案 $3$，对应 $y=6$ 即 $x=0$ 全答 false——与题面"全答 false 至少对 $3$ 题"一致 ✓。

**手造数据。** $N=10$，$T=\{0,10\}$：端点候选都是 $0$，间隙 $\lfloor10/2\rfloor=5$，答案 $5$（$y=5$：$t=0$ 时对 $5$ 题、$t=10$ 时也对 $5$ 题）。$N=5$，$T=\{2,2,3,3\}$：端点 $\max(2,2)=2$，间隙 $0$ 与 $0$，答案 $2$（$y=0$：最近点距离 $2$）。$K=0$：输出 $0$。程序输出均与手算一致。

## 二、思维链：完整证明

**记号。** 答卷由"答 true 的题集"决定，$x$ 为其大小，$y=N-x$。真实答案由"true 题集"决定，大小 $t\in T$。得分 = 两集合的一致位数。博弈：约翰先定答卷，对手后选 $t\in T$ 与 true 题集最小化得分；若 $T=\varnothing$ 则对手可选任意 $t\in[0,N]$（口径）。

---

### 引理 1（对称性：只有数量 $x$ 重要，且 $a$ 的可行域是整区间）

固定 $x,t$。设 $a$ = 约翰答 true 且实际 true 的题数。则得分 $=N-x-t+2a$；对手可实现的 $a$ 恰为整数区间 $[\max(0,x+t-N),\ \min(x,t)]$ 中的每个值。

*证明*：得分公式：true 侧答对 $a$；false 侧约翰答了 $N-x$ 题，其中实际 true 的有 $t-a$ 个（true 总共 $t$，落在 true 侧 $a$ 个），故 false 侧答对 $(N-x)-(t-a)$。相加得 $N-x-t+2a$。

$a$ 的范围：$a\le x$（true 侧只有 $x$ 题）、$a\le t$（true 只有 $t$ 个）；又 false 侧至多容纳 $N-x$ 个 true，故 $t-a\le N-x\Rightarrow a\ge x+t-N$；且 $a\ge0$。合起来 $\max(0,x+t-N)\le a\le\min(x,t)$。

可达性（构造）：先把 $\min(t,\,N-x)$ 个 true 放进约翰答 false 的题，剩余 $\max(0,t-(N-x))=\max(0,x+t-N)$ 个 true 放进约翰答 true 的题——这恰好实现 $a_{\min}$（需验证容量：剩余 true 数 $\le x\iff t\le N$ ✓）。要得到更大的 $a$，把 false 侧的 true 逐个挪到 true 侧的空位（true 侧空位 $x-a_{\min}\ge0$，false 侧 true 数足够挪），每挪一个 $a$ 加 $1$，直到 $a=\min(x,t)$（此时 true 全在 true 侧或 true 侧已满）。区间内每个整数都被构造到。证毕。

**推论**：最坏得分只依赖 $(x,t)$，与答卷的具体形状无关。

---

### 引理 2（最坏得分 $=|N-x-t|$）

固定 $x,t$，对手最小化后的得分为 $|N-x-t|$。

*证明*：得分关于 $a$ 严格递增（系数 $2>0$），故对手取 $a_{\min}=\max(0,x+t-N)$（引理 1 保证可达）。代入：

- 若 $x+t\le N$：$a_{\min}=0$，得分 $=N-x-t\ge0$，等于 $|N-x-t|$。
- 若 $x+t>N$：$a_{\min}=x+t-N$，得分 $=N-x-t+2(x+t-N)=x+t-N>0$，等于 $|N-x-t|$。

两情形穷尽。证毕。

---

### 引理 3（归约：数轴最远点）

博弈值 $=\displaystyle\max_{y\in[0,N]\cap\mathbb Z}g(y)$，其中 $g(y)=\min_{t\in T}|y-t|$（$T=\varnothing$ 时 $g\equiv0$，见引理 6）。

*证明*：由引理 1、2，约翰选 $x$ 的保证得分是 $\min_{t\in T}|N-x-t|$。映射 $x\mapsto y=N-x$ 是 $[0,N]$ 整点到自身的双射，故 $\max_x\min_t|N-x-t|=\max_y\min_t|y-t|$。证毕。

---

### 引理 4（锯齿函数的分段结构）

设 $T$ 排序去重后为 $u_1<u_2<\dots<u_m$（$m\ge1$）。则：

(a) $y\le u_1$ 时 $g(y)=u_1-y$；$y\ge u_m$ 时 $g(y)=y-u_m$；
(b) $u_i\le y\le u_{i+1}$ 时 $g(y)=\min(y-u_i,\ u_{i+1}-y)$。

*证明*：(a) 对 $y\le u_1$，每个 $|y-u_j|=u_j-y\ge u_1-y$，最小值在 $j=1$ 取到。右侧对称。

(b) 对 $j\le i$：$|y-u_j|=y-u_j\ge y-u_i$（$u_j\le u_i$）；对 $j\ge i+1$：$|y-u_j|=u_j-y\ge u_{i+1}-y$。故所有距离都 $\ge\min(y-u_i,u_{i+1}-y)$，而 $j=i$ 与 $j=i+1$ 恰好取到这两个值，最小值就是它们中较小者。证毕。

---

### 引理 5（三类候选点取尽最优）

$\max_{y\in[0,N]\cap\mathbb Z}g(y)=\max\Big(u_1,\ N-u_m,\ \max_{1\le i<m}\big\lfloor\tfrac{u_{i+1}-u_i}{2}\big\rfloor\Big)$。

*证明*：把 $[0,N]$ 切成 $[0,u_1]$、各 $[u_i,u_{i+1}]$、$[u_m,N]$（$u_j\in[0,N]$ 保证覆盖），逐段求整点最大值。

**左段** $[0,u_1]$：$g=u_1-y$ 关于 $y$ 递减，最大在 $y=0$，值 $u_1$。

**右段** $[u_m,N]$：$g=y-u_m$ 递增，最大在 $y=N$，值 $N-u_m$。

**中段** $[u_i,u_{i+1}]$：记 $L=u_i,R=u_{i+1},G=R-L$。对任意整点 $y$，$(y-L)+(R-y)=G$，两非负整数之和为 $G$，较小者 $\le\lfloor G/2\rfloor$（若两者都 $\ge\lfloor G/2\rfloor+1$，和 $\ge2\lfloor G/2\rfloor+2>G$，矛盾）。故 $g(y)\le\lfloor G/2\rfloor$。取 $y^\*=L+\lfloor G/2\rfloor$（整点且在段内）：$g(y^\*)=\min(\lfloor G/2\rfloor,\lceil G/2\rceil)=\lfloor G/2\rfloor$，上界取到。

三段最大值取 max 即全局最大。重复点去重不影响 $g$（$\min$ 对重复元素幂等）；不去重时重复产生 $G=0$ 的段，贡献 $0$，同样无害。证毕。

---

### 引理 6（$K=0$ 的边界）

$T=\varnothing$ 时博弈值为 $0$。

*证明*：按口径，对手可选任意 $t\in[0,N]$。对约翰的任何 $x$，对手取 $t=N-x\in[0,N]$，由引理 2 得分 $=|N-x-(N-x)|=0$。故任何答卷保证得分为 $0$；又得分非负，博弈值恰为 $0$。证毕。

---

### 引理 7（复杂度与范围）

时间 $O(K\log K)$，空间 $O(K)$；所有量 $\le N\le10^6$，`int` 安全。

*证明*：读入 $O(K)$，排序 $O(K\log K)$，扫描相邻间隙 $O(K)$。$t_i\in[0,N]$，$u_1\le10^6$，$N-u_m\le10^6$，$\lfloor G/2\rfloor\le5\times10^5$，答案 $\le10^6<2^{31}$。$N$ 本身不产生数组开销。证毕。

---

### 定理

程序输出约翰保证能获得的最高分 $\max_x\min_{t\in T}|N-x-t|$，总复杂度 $O(K\log K)$。

*证明*：引理 1 证明答卷只需优化数量 $x$ 并给出对手的最优应对；引理 2 把最坏得分化简为绝对值；引理 3 换元归约成数轴最远点；引理 4、5 证明端点 + 间隙中点三类候选取尽最优；引理 6 处理 $K=0$；引理 7 给出复杂度与数值安全。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 消息只约束 true 的**数量**，题目地位对称 ⇒ 答卷只需优化"答几个 true"，$2^N$ 压成 $N+1$。
2. **explore its property** — 得分 $=N-x-t+2a$，对手最小化 $a$；$a_{\min}=\max(0,x+t-N)$ 可达（坑位构造）。
3. **reduce to easier problem** — 最坏得分 $=|N-x-t|$；换元 $y=N-x$，归约为"数轴 $[0,N]$ 上离点集最近的距离最大化"。
4. **classic problem solution** — 锯齿距离函数分段线性：最优候选 = 两端点 + 相邻点间隙中点（整点下取整 $\lfloor\text{gap}/2\rfloor$）。
5. **discuss by category** — $K=0$ 无消息 ⇒ 对手取 $t=y$ 压成 $0$；重复 $t_i$ 产生零间隙，无害。
6. **explore its property** — 复杂度只跟 $K$ 走（$O(K\log K)$），$N\le10^6$ 只是数值范围，不开 $O(N)$ 数组。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N$ | 题数，$\le10^6$ | `int n` | 只参与 $N-t_{\max}$ |
| $K$ | 消息个数，$\le10^4$，可为 $0$ | `int k` | $K=0$ 直接输出 $0$ |
| `t[i]` | 可能的 true 题数 | `int[mxn]` | 读入后排序；重复无害 |
| `mxn` | $10000+5$ | `constexpr int` | 按 $K$ 开，不按 $N$ |
| `ans` | 博弈值 | `int` | $\max(t_1,\ N-t_K,\ \max\lfloor\text{gap}/2\rfloor)$ |
| $y$ | 隐式变量 $N-x$（答 false 的题数） | 不出现在代码 | 三类候选对应 $y=0,N,$ 间隙中点 |

### 算法步骤

1. I/O 加速三行；读 $N,K$。
2. 若 $K=0$：输出 $0$，结束。
3. 读 $K$ 个 $t_i$，升序排序。
4. `ans=max(t[0], n-t[k-1])`（两端点候选）。
5. 扫 $i=1..K-1$：`ans=max(ans,(t[i]-t[i-1])/2)`（间隙中点候选，整除自动下取整）。
6. 输出 `ans`。

### 复杂度

- 时间：$O(K\log K)$，$K\le10^4$。
- 空间：$O(K)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子 $N=6,T=\{0,3\}$ 输出 $3$ ✓；手造 $N=10,T=\{0,10\}\to5$、$N=5,T=\{2,2,3,3\}\to2$、$K=0\to0$ 均与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2988 [USACO10MAR] Test Taking S
// 答 x 个 true 时最坏得分 = |N-x-t|；令 y=N-x，即数轴 [0,N] 上离点集 {t_i} 最远的整点
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int n,k,t[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	if(k==0)	// 没有任何消息：t 任意，对手取 t=y 使答案为 0
	{
		cout<<0<<'\n';
		return 0;
	}
	for(int i=0;i<k;++i)
		cin>>t[i];
	sort(t,t+k);
	int ans=max(t[0],n-t[k-1]);	// 两端候选 y=0 与 y=N
	for(int i=1;i<k;++i)
		ans=max(ans,(t[i]-t[i-1])/2);	// 相邻间隙中点，下取整
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 全部推导浓缩成三行：排序、端点取 max、间隙除以 $2$ 取 max。C++ 非负整数除法天然下取整，正是引理 5 要的 $\lfloor\text{gap}/2\rfloor$。
- `mxn` 按 $K\le10^4$ 开而不是按 $N\le10^6$ 开——算法根本不枚举题目。
- $K=0$ 必须特判：否则 `t[0]`、`t[k-1]` 越界访问未定义值。
- 不需要去重：重复 $t_i$ 的间隙为 $0$，`max` 自动忽略。
- 答案与所有中间量 $\le10^6$，`int` 足够；`t[i]-t[i-1]` 排序后非负，无符号陷阱。
