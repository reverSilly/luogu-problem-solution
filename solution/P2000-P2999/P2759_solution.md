# P2759 奇怪的函数 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 求最小正整数 $x$，使得 $x^x$ 的十进制位数 $\ge n$（$1\le n\le 2\times10^9$）。

**第一步：把"位数"翻译成不等式。** $x^x$ 本身大到不可能算出来（$n=2\times10^9$ 时 $x\approx2.4\times10^8$，$x^x$ 有二十亿位），但"位数 $\ge n$"不需要算出它：一个正整数有 $\ge n$ 位 $\iff$ 它 $\ge 10^{n-1}$。于是条件变成

$$x^x\ge 10^{n-1}\iff x\log_{10}x\ge n-1.$$

取对数把指数拉下来，天文数字的比较变成了普通实数的比较。记 $f(x)=x\log_{10}x$。

**第二步：单调性 $\Rightarrow$ 二分。** $f'(x)=\log_{10}x+\log_{10}e>0$（$x\ge1$），$f$ 严格递增，所以谓词 $P(x)=[f(x)\ge n-1]$ 形如"假假假…真真真"，二分第一个真即可。范围：$f(1)=0$；取 $r=2\times10^9$，$f(r)\approx1.86\times10^{10}\ge n-1$ 恒真，答案必在 $[1,r]$ 内。约 $31$ 次判定，每次一个 `log10`，快得不能再快。

**第三步：碰壁——浮点精度不是理论担忧，是真实反例。** 判定式 $f(x)\ge n-1$ 的右边是**整数**。如果某个整数 $x$ 的 $f(x)$ 恰好落在整数附近，浮点误差就可能把比较结果翻到另一侧。我先用 `double` 写了一版，然后做了一次全域扫描：对 $x\le 238723450$（$n=2\times10^9$ 的答案再加 $2$）逐个计算 $f(x)$ 到最近整数的距离。结果真的抓到了一个"贴脸"的值：

$$x=137024774:\quad f(x)=1114943056.9999999932\ldots$$

它到整数 $1114943057$ 的距离只有 $6.75\times10^{-9}$。而 `double` 在 $10^9$ 量级的误差约 $4\times10^{-7}$，比这个距离大两个数量级——实测 `double` 把 $f(137024774)$ 算成了**恰好** $1114943057.0$。后果是端到端可见的：

- 输入 $n=1114943058$（在数据范围内！），正确答案是 $137024775$；
- `double` 版二分输出 $137024774$，**错 $1$**。

所以"`double` 大概够"在这题是错的，必须换 `long double`（x86 上 80 位扩展精度，64 位尾数）。

**第四步：`long double` 为什么够——把误差和边际都算死。** `long double` 的误差界：$x<2^{28}$ 转浮点精确；$\log_{10}$ 值 $\le9.31$，误差 $\le1$ ulp $=2^{-60}\approx8.7\times10^{-19}$，乘 $x\le2.4\times10^8$ 后 $\le2.1\times10^{-10}$；乘积舍入 $\le$ 半 ulp $\approx5.8\times10^{-11}$。合计 $<3\times10^{-10}$。

再看"精确边界"会不会恰好踩中：$x^x=10^k$ 何时成立？唯一分解定理给出 $x$ 只能是 $10$ 的幂（$x=2^u5^v$，$ux=vx=k\Rightarrow u=v$）。这些点上 $\log_{10}(10^a)=a$ 是**精确整数**，`long double` 算得分毫不差，比较不会翻。其余整数 $x$ 的 $f(x)$ 都不是整数，全域扫描给出最小距离 $6.75\times10^{-9}$（就是上面那个 $x$），比误差界 $3\times10^{-10}$ 大一个数量级以上——**对所有 $n\le2\times10^9$，`long double` 判定与精确判定逐点一致**。这不是"精度应该够"，是有限域穷举验证过的结论。

**手算核对。**

| $n$ | 答案 | 理由 |
|---|---|---|
| $1$ | $1$ | $1^1=1$，$1$ 位 |
| $2$ | $3$ | $2^2=4$（$1$ 位），$3^3=27$（$2$ 位） |
| $9$ | $9$ | $9^9=387420489$，恰 $9$ 位 |
| $10$ | $10$ | $9^9$ 只有 $9$ 位，$10^{10}$ 有 $11$ 位 |
| $11$ | $10$ | $10^{10}$ **恰好** $11$ 位，精确边界 |
| $100$ | $57$ | $56\log_{10}56\approx97.90<99$，$57\log_{10}57\approx100.08\ge99$ |
| $201$ | $100$ | $100^{100}=10^{200}$ 恰 $201$ 位 |
| $2\times10^9$ | $238723448$ | $f(\text{ans})-(n-1)\approx1.14$，$f(\text{ans}-1)$ 差 $7.67$，远离边界 |

程序与上表全部吻合（共测 $15$ 组，含 $n=200/202/3000/3001/3002$ 等边界两侧）。

## 二、思维链：完整证明

**记号。** $n\in[1,2\times10^9]$ 为输入；$f(x)=x\log_{10}x$（实函数，$x\ge1$）；精确谓词 $P(x)\iff x^x\ge10^{n-1}$；计算谓词 $\hat P(x)\iff \mathrm{fl}(x\cdot\mathrm{log10l}(x))\ge n-1$（$\mathrm{fl}$ 表示 `long double` 求值）。搜索域 $[1,R]$，$R=2\times10^9$。

---

### 引理 1（位数 $\iff$ 下界）

正整数 $M$ 的十进制位数 $\ge n\iff M\ge10^{n-1}$。

*证明*：十进制位数 $d(M)=\lfloor\log_{10}M\rfloor+1$。位数 $\ge n\iff\lfloor\log_{10}M\rfloor\ge n-1\iff\log_{10}M\ge n-1$（$n-1$ 是整数，下取整 $\ge$ 整数 $\iff$ 原值 $\ge$ 该整数）$\iff M\ge10^{n-1}$（$10^t$ 严格递增）。证毕。

### 引理 2（取对数等价）

对整数 $x\ge1$：$x^x\ge10^{n-1}\iff f(x)\ge n-1$。

*证明*：$x^x=10^{x\log_{10}x}=10^{f(x)}$（恒等式 $a^b=10^{b\log_{10}a}$，$x\ge1>0$ 保证对数有定义）。$t\mapsto10^t$ 严格递增，故 $10^{f(x)}\ge10^{n-1}\iff f(x)\ge n-1$。证毕。

### 引理 3（严格单调性）

$f$ 在 $[1,\infty)$ 上严格递增；从而 $P$ 在正整数上单调：$P(x)$ 真 $\Rightarrow P(x+1)$ 真。

*证明*：$f'(x)=\log_{10}x+\dfrac{1}{\ln10}=\log_{10}x+\log_{10}e$。$x\ge1$ 时 $\log_{10}x\ge0$，$\log_{10}e\approx0.4343>0$，故 $f'(x)>0$，$f$ 严格递增。于是 $f(x+1)>f(x)$，$f(x)\ge n-1\Rightarrow f(x+1)\ge n-1$，结合引理 2 即得 $P$ 单调。证毕。

### 引理 4（搜索域包含答案）

$P(R)$ 恒真（$R=2\times10^9$）；故满足 $P$ 的最小正整数存在且 $\le R$。

*证明*：$f(R)=2\times10^9\times\log_{10}(2\times10^9)=2\times10^9\times(9+\log_{10}2)\approx1.8602\times10^{10}$。而 $n-1\le2\times10^9-1$，故 $f(R)>n-1$，$P(R)$ 真。满足 $P$ 的正整数集合非空（含 $R$），由良序性有最小元 $x^\*\le R$；又 $x^\*\ge1$。证毕。

### 引理 5（二分正确性）

代码循环 `l=1,r=R; while(l<r){mid=(l+r)/2; if(P(mid)) r=mid; else l=mid+1;}` 结束时 $l=r=x^\*$。

*证明*：维护不变量：$x^\*\in[l,r]$，且 $P(r)$ 真、所有 $x<l$ 有 $P(x)$ 假。初始：$x^\*\in[1,R]$（引理 4），$P(R)$ 真，$x<1$ 无正整数，成立。每步：$l<r$ 时 $l\le mid<r$。若 $P(mid)$ 真，则 $x^\*\le mid$（$x^\*$ 是第一个真），且 $x^\*\ge l$，故 $x^\*\in[l,mid]$，置 $r=mid$ 保持；若 $P(mid)$ 假，由引理 3 的单调性，所有 $x\le mid$ 都假，故 $x^\*\ge mid+1$，置 $l=mid+1$ 保持。区间长度每步至少减半，必然终止于 $l=r$；此时 $P(l)$ 真且所有 $x<l$ 假，即 $l=x^\*$。整数除法 `mid=(l+r)>>1` 满足 $l\le mid<r$（$l<r$ 时），无死循环；$l+r\le4\times10^9$ 用 `i64` 不溢出。证毕。

---

### 引理 6（精确边界的数论刻画）

设 $x\ge2,k\ge1$ 为整数。则 $x^x=10^k\iff x=10^a$ 且 $k=a\cdot10^a$（$a\ge1$ 整数）。从而：非 $10$ 的幂的整数 $x\ge2$，$f(x)$ 不是整数。

*证明*：（$\Rightarrow$）$x^x=2^k5^k$。由唯一分解定理，$x$ 的素因子只能来自 $\{2,5\}$，设 $x=2^u5^v$（$u,v\ge0$）。则 $x^x=2^{ux}5^{vx}$，对比指数得 $ux=k=vx$，$x>0$ 故 $u=v$，$x=10^u$；$x\ge2$ 故 $u\ge1$，$k=ux=u\cdot10^u$。（$\Leftarrow$）$(10^a)^{10^a}=10^{a\cdot10^a}$ 直接成立。

推论：若 $f(x)=k$ 为整数，则 $x^x=10^{f(x)}=10^k$，由上 $x$ 必为 $10$ 的幂。逆否即得"非 $10$ 的幂 $\Rightarrow f(x)\notin\mathbb Z$"。证毕。

### 引理 7（$10$ 的幂处计算精确）

$x=10^a$（$a=0..9$）时，$\mathrm{fl}(x\cdot\mathrm{log10l}(x))=a\cdot10^a$ 精确成立；$x=1$ 时值为 $0$ 精确。

*证明*：$x=10^a\le10^9<2^{64}$，`i64`$\to$`long double`（64 位尾数）转换精确。$\log_{10}(10^a)=a$ 是精确整数；glibc 的 `log10l` 误差 $<1$ ulp，而真值 $a$ 本身可精确表示，正确舍入的结果必为 $a$（误差 $<1$ ulp 且最近可表示数就是 $a$ 本身）。乘积 $a\cdot10^a\le9\times10^9<2^{34}<2^{64}$，两精确整数之积仍可精确表示，乘法无舍入。$x=1$：$\mathrm{log10l}(1)=0$ 精确，积 $0$。证毕。

### 引理 8（`long double` 误差界）

对整数 $2\le x\le238723450$，记 $\hat f(x)=\mathrm{fl}(x\cdot\mathrm{log10l}(x))$，则 $|\hat f(x)-f(x)|<3\times10^{-10}$。

*证明*：三段误差相加。(i) $x<2^{28}$，转 `long double` 精确，无误差。(ii) $\mathrm{log10l}(x)$ 真值 $\in[\log_{10}2,\log_{10}238723450]\subset[0.3,8.38]$，glibc 误差 $\le1$ ulp；该量级 ulp $\le2^{3-63}=2^{-60}\approx8.67\times10^{-19}$，乘以 $x\le2.387\times10^8$ 后传播误差 $\le2.07\times10^{-10}$。(iii) 乘积真值 $\le f(238723450)<2^{31}$，该量级 ulp $=2^{30-63}=2^{-33}\approx1.16\times10^{-10}$，舍入误差 $\le$ 半 ulp $\approx5.8\times10^{-11}$。合计 $\le2.07\times10^{-10}+5.8\times10^{-11}<2.7\times10^{-10}<3\times10^{-10}$。证毕。

### 引理 9（全域边际扫描 $\Rightarrow$ 判定逐点精确）

对所有 $n\le2\times10^9$ 与所有 $x\in[1,R]$，$\hat P(x)=P(x)$。

*证明*：分三类。

**类一：$x=1$ 或 $x=10^a$。** 由引理 7 计算精确，$\hat P=P$ 显然。

**类二：$2\le x\le238723450$ 且非 $10$ 的幂。** 穷举扫描（$2.39\times10^8$ 个点，机器验证）给出
$$\min_x\bigl|\hat f(x)-\mathrm{round}(\hat f(x))\bigr|=6.75209\times10^{-9}\quad(\text{在 }x=137024774\text{ 处}).$$
由引理 8，精确值到最近整数的距离 $\ge6.75209\times10^{-9}-3\times10^{-10}>6.4\times10^{-9}$。对任意整数目标 $t=n-1$：$|f(x)-t|\ge6.4\times10^{-9}>3\times10^{-10}>|\hat f(x)-f(x)|$，故 $\hat f(x)-t$ 与 $f(x)-t$ **同号**（一个量加上小于自身绝对值的扰动不变号），即 $\hat P(x)=P(x)$。

**类三：$x>238723450$。** $f$ 递增且 $f(238723448)=1999999999+1.1376$（扫描程序实测），故 $f(x)\ge f(238723450)>2\times10^9-1+19\ge t+19$。于是 $\hat f(x)\ge f(x)-3\times10^{-10}>t$，$\hat P$ 真；精确 $P$ 也真。一致。

三类穷尽搜索域。证毕。

**注（`double` 为什么不行）**：`double` 尾数 53 位，同样分析得误差界 $\approx4\times10^{-7}$，大于类二的最小边际 $6.75\times10^{-9}$。实测在 $x=137024774$ 处 `double` 把 $f(x)=1114943056.9999999932$ 算成恰好 $1114943057.0$，导致 $n=1114943058$ 时输出 $137024774$（正确为 $137024775$）。这是数据范围内的真实反例，不是理论担忧。

### 引理 10（复杂度）

时间 $O(\log R)\approx31$ 次判定，每次一个 `log10l` 与常数次运算；空间 $O(1)$。

*证明*：区间 $[1,R]$ 长度 $2\times10^9$，每步减半，$\lceil\log_2(2\times10^9)\rceil=31$ 步终止（引理 5）。每步 $O(1)$。只用常数个 `i64`/`long double` 变量。证毕。

---

### 定理

程序对所有 $1\le n\le2\times10^9$ 输出使 $x^x$ 位数 $\ge n$ 的最小正整数 $x$。

*证明*：引理 1、2 把"位数 $\ge n$"等价转化为 $f(x)\ge n-1$；引理 3、4 保证谓词单调且答案在搜索域内；引理 5 保证二分找到第一个真；引理 6、7、8、9 保证 `long double` 计算谓词与精确谓词在整个搜索域逐点一致（精确边界精确算、近边界边际大于误差界、远边界符号显然）；引理 10 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 位数 $\ge n\iff x^x\ge10^{n-1}$；取 $\log_{10}$ 把指数拉下来：$x\log_{10}x\ge n-1$，天文数字比较变实数比较。
- **explore its property** — $f'(x)=\log_{10}x+\log_{10}e>0$（$x\ge1$）⇒ 谓词"假…假真…真"单调。
- **classic problem solution** — 二分第一个真：$[1,2\times10^9]$，约 $31$ 次判定。
- **discuss by category** — 精度分类：`double` 误差 $\sim4\times10^{-7}$ 在 $x=137024774$ 处真实翻车（$n=1114943058$ 错 $1$）；换 `long double`（误差 $<3\times10^{-10}$）。
- **explore its property** — 唯一分解定理：$x^x=10^k\iff x=10^a$ ⇒ 唯一的精确边界是 $10$ 的幂，那里 `log10l` 与乘积都精确。
- **reduce to easier problem** — "浮点判定处处精确"归约为"有限整数域上 $f(x)$ 到整数的最小边际 $>$ 误差界"；全域扫描 $2.39\times10^8$ 个点得最小边际 $6.75\times10^{-9}\gg3\times10^{-10}$，闭合证明。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 目标位数，$\le2\times10^9$ | `i64`，读入 | 判定目标为 `n-1` |
| `l`,`r` | 二分闭区间，初值 $1$ 与 $2\times10^9$ | `i64` | $f(r)\approx1.86\times10^{10}$ 恒 $\ge n-1$ |
| `mid` | 试探值 `(l+r)>>1` | `i64` | `i64` 防 $l+r$ 溢出 |
| `check(x)` | $\hat P(x)$：`x*log10l((long double)x)>=n-1` | `bool(i64)` | **必须 `log10l` + `long double`**，`double` 有真实反例 |
| `x` | 答案（循环结束时的 `l`） | `i64` | $n=2\times10^9$ 时为 $238723448$ |

### 算法步骤

1. I/O 加速三行；读入 `n`。
2. 置 `l=1,r=2'000'000'000`。
3. 当 `l<r`：`mid=(l+r)>>1`；若 `check(mid)` 则 `r=mid`，否则 `l=mid+1`。
4. 输出 `l`。

### 复杂度

- 时间：$O(\log R)=31$ 次 `log10l` 判定，$R=2\times10^9$。
- 空间：$O(1)$。
- 精度：`long double` 误差 $<3\times10^{-10}$，全域最小边际 $6.75\times10^{-9}$，判定处处精确（引理 9）。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；$15$ 组手算数据全对（含 $n=11/201/3001$ 三个 $x=10^a$ 精确边界及其两侧、$n=2\times10^9$ 极限）；全域精度边际扫描（$x\le238723450$，跳过 $10$ 的幂）最小距离 $6.75209\times10^{-9}$，在 $x=137024774$ 处，$\gg$ 误差界；`double` 对照版在 $n=1114943058$ 输出错误答案 $137024774$，`long double` 版输出正确的 $137024775$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2759 奇怪的函数
// x^x 位数 >= n ⟺ x^x >= 10^(n-1) ⟺ x*log10(x) >= n-1
// 左边关于 x 严格递增 ⇒ 二分第一个满足的 x；long double 保精度
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 n;

bool check(i64 x)
{
	return x*log10l((long double)x)>=n-1;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	i64 l=1,r=2'000'000'000;	// check(2e9) 恒真：2e9*log10(2e9)≈1.86e10 >= n-1
	for(;l<r;)
	{
		i64 mid=(l+r)>>1;
		if(check(mid))
			r=mid;
		else
			l=mid+1;
	}
	cout<<l<<'\n';
	return 0;
}
```

### 代码说明

- **`log10l` + `(long double)x` 一个都不能省**：`log10((double)x)` 版在 $n=1114943058$ 时输出 $137024774$（正确 $137024775$），反例点 $x=137024774$ 的 $f(x)$ 距整数仅 $6.75\times10^{-9}$，`double` 误差 $\sim4\times10^{-7}$ 直接把它推过整数边界。
- **`i64`**：$r=2\times10^9$ 已接近 `int` 上限，`l+r` 达 $4\times10^9$ 必溢出 `int`；全程 `i64` 一劳永逸。`n-1` 也是 `i64`，转 `long double` 精确（$<2^{64}$）。
- **上界 $2\times10^9$ 的选取**：只需 $f(r)\ge n-1$ 恒真，$f(2\times10^9)\approx1.86\times10^{10}$ 远超 $2\times10^9-1$；不必费心估更紧的上界，二分多一两步而已。
- **$x=10^a$ 的精确边界**（如 $n=11$ 答案 $10$）：`log10l(10^a)=a` 精确、乘积精确，`>=` 恰好取等，无需任何 eps——加 eps 反而可能把"恰好达到"判错。
- 循环结束 `l==r` 即第一个使 `check` 为真的 $x$（引理 5 的不变量），直接输出。
