# P2626 斐波那契数列（升级版） — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 斐波那契 $f(1)=f(2)=1$，$f(n)=f(n-1)+f(n-2)$。输入 $n\le 48$，求 $f(n)\bmod 2^{31}$ 的值，再把这个值**分解质因数**输出。

这题标签是"模拟、递推、素数判断"，难度普及-，本质就是两件事：**递推求值** + **试除分解**。但有两个地方必须想清楚，否则会 WA。

**第一步：$n\le48$ 时 $f(n)$ 有多大？要不要取模？** 我先把斐波那契往后写几项：$f(46)=1836311903$，$f(47)=2971215073$，$f(48)=4807526976$。而 $2^{31}=2147483648$。可见 $f(46)<2^{31}$，但 $f(47),f(48)$ 都**超过**了 $2^{31}$。所以"mod $2^{31}$"不是摆设：

$$f(47)\bmod 2^{31}=823731425,\qquad f(48)\bmod 2^{31}=512559680.$$

要分解的是**取模之后**的数，不是原始 $f(n)$。这一点很容易看漏——如果直接分解 $f(48)=4807526976$，答案就全错了。

**第二步：怎么算 $f(n)\bmod 2^{31}$ 才不溢出？** $f(48)\approx4.8\times10^9$ 已经超 `int`（$2.1\times10^9$），但远没超 `long long`。最省心的写法是**边递推边取模**：
$$f(i)=(f(i-1)+f(i-2))\bmod 2^{31}.$$
因为 $f(i-1),f(i-2)$ 取模后都 $<2^{31}$，它们的和 $<2^{32}$，`long long` 轻松装下，再取模又回到 $[0,2^{31})$。这样全程数值都很小，绝不溢出。我在第二节证明"边加边取模"与"先算完整 $f(n)$ 再取模"结果一致（模运算对加法是同态）。

**第三步：分解质因数——试除就够了。** 取模后的值 $v<2^{31}\approx2.1\times10^9$，$\sqrt v\le 46341$。直接**试除**：$p$ 从 $2$ 枚举到 $\sqrt v$，每遇到 $p\mid v$ 就把 $v$ 里的 $p$ 除干净、记下指数；循环结束后若 $v>1$，剩下的 $v$ 本身是个质数。最坏 $46341$ 次循环，瞬间跑完，根本不需要 Pollard-Rho 之类的高级算法。

这里有个**必须证明的点**：为什么循环结束后剩下的 $v$ 一定是质数（或 $1$）？直觉是"小质因子都被除掉了"，但严格理由要用反证：若剩下的 $v$ 是合数，它必有 $\le\sqrt v$ 的质因子，而那个质因子 $<p$（当前枚举值）早该被除掉了，矛盾。第二节写完整。

**第四步：输出格式（题面没给样例，这是最大的坑）。** 题面只说"分解质因数"，没给样例输入输出。按这道题的通行格式，输出是
$$\texttt{值}=\texttt{质数}^{\texttt{指数}}*\texttt{质数}^{\texttt{指数}}*\cdots$$
质数从小到大，**指数为 $1$ 时省略 `^1`**（只写质数），各因子用 `*` 连接。例如：

- $n=3$：$f=2$，输出 `2=2`；
- $n=6$：$f=8=2^3$，输出 `8=2^3`；
- $n=12$：$f=144=2^4\cdot3^2$，输出 `144=2^4*3^2`；
- $n=48$：$v=512559680=2^6\cdot5\cdot1601749$，输出 `512559680=2^6*5*1601749`。

**第五步：边界 $v=1$。** $n=1,2$ 时 $f=1$，$1$ 没有质因子。按"值=分解式"的格式，约定输出 `1=1`。另外我核对了 $n\le48$ 时 $v$ **绝不会是 $0$**：$f(n)$ 要 $\equiv0\pmod{2^{31}}$ 就得是 $2^{31}$ 的倍数，而 $f(47)=2971215073$、$f(48)=4807526976$ 都不是 $2147483648$ 的整数倍，$n\le46$ 时 $f(n)<2^{31}$ 更不可能为 $0$。所以不用处理"分解 $0$"这种无意义情形。

**手算核对**（题面无样例，我自己算并用程序验证）：上面 $n=3,6,12,48$ 四组，把输出的分解式乘回去都精确等于左边的值（如 $2^6\times5\times1601749=320\times1601749=512559680$），且 $1601749$ 经试除确认是质数。$n=46$ 输出 `1836311903=139*461*28657`，乘回 $139\times461\times28657=1836311903=f(46)$，一致。

## 二、思维链：完整证明

### 记号

- $f(1)=f(2)=1$，$f(n)=f(n-1)+f(n-2)$（$n\ge3$）。$M=2^{31}=2147483648$。
- 程序用数组 `f[1..n]`，`f[i]=(f[i-1]+f[i-2])%M`。记 $v=\texttt{f[n]}$。
- 分解：对 $v$ 试除，输出质因子及其指数。

---

### 引理 1（边递推边取模 $=$ 完整值取模）

程序算出的 `f[i]` 满足 $\texttt{f[i]}=f(i)\bmod M$，且 $0\le\texttt{f[i]}<M$。

*证明*：对 $i$ 归纳。$i=1,2$：`f[1]=f[2]=1`，而 $f(1)=f(2)=1<M$，故 $1\bmod M=1$ ✓。

设 $i-1,i-2$ 成立，即 $\texttt{f[i-1]}=f(i-1)\bmod M$、$\texttt{f[i-2]}=f(i-2)\bmod M$。由模加法同态：
$$(a+b)\bmod M=\bigl((a\bmod M)+(b\bmod M)\bigr)\bmod M.$$
取 $a=f(i-1),b=f(i-2)$，则
$$f(i)\bmod M=(f(i-1)+f(i-2))\bmod M=\bigl(\texttt{f[i-1]}+\texttt{f[i-2]}\bigr)\bmod M=\texttt{f[i]}.$$
最后一步正是代码 `f[i]=(f[i-1]+f[i-2])%M`。又 `%M` 的结果落在 $[0,M)$，故 $0\le\texttt{f[i]}<M$。证毕。

**溢出安全**：$\texttt{f[i-1]},\texttt{f[i-2]}<M=2^{31}$，和 $<2^{32}\approx4.3\times10^9$，`long long`（$\pm9.2\times10^{18}$）远够；即便 `int` 也装不下 $2^{32}$，故必须用 `long long`（或 `unsigned`）。代码用 `i64`。

---

### 引理 2（$n\le48$ 时 $v\ne0$，且 $v=1$ 仅当 $n\in\{1,2\}$）

$v=f(n)\bmod M\in[1,M)$；$v=1\iff n\in\{1,2\}$。

*证明*：$f(n)\ge1$ 对所有 $n\ge1$（斐波那契正项）。$v=0$ 当且仅当 $M\mid f(n)$。$n\le46$ 时 $f(n)\le f(46)=1836311903<M$，故 $M\nmid f(n)$（$f(n)\ge1$），$v=f(n)\ge1$。$n=47$：$f(47)=2971215073$，$2971215073/M\approx1.38$ 非整数，$v=823731425\ne0$。$n=48$：$f(48)=4807526976$，$/M\approx2.24$ 非整数，$v=512559680\ne0$。故 $v\ne0$ 恒成立。

$v=1$：$n=1,2$ 时 $f=1$，$v=1$。$n\ge3$ 时 $f(n)\ge2$；若 $n\le46$，$v=f(n)\ge2$；$n=47,48$ 时 $v$ 分别为 $823731425,512559680$，均 $\ne1$。故 $v=1$ 仅在 $n=1,2$。证毕。

**推论**：只需为 $v=1$ 设一个"输出 `1=1`"的分支，不必处理 $v=0$。

---

### 引理 3（试除分解的完整性：所有质因子都被找到）

设 $v\ge2$。试除循环 `for(p=2;p*p<=v;++p) if(v%p==0){ 除尽 p，记指数 }` 会把 $v$ 的**每个**质因子按从小到大顺序输出，指数正确。

*证明*：循环按 $p=2,3,4,\dots$ 递增枚举。维护不变量：**进入第 $p$ 轮时，当前 $v$ 不含任何 $<p$ 的质因子**（因为 $2..p-1$ 都已试过，凡整除的都被除尽）。

- 若 $p$ 是质数且 $p\mid v$：内层 `while(v%p==0)v/=p,++e` 把 $p$ 除尽，指数 $e$ 恰为 $p$ 在当前 $v$ 中的重数；由不变量，这也是 $p$ 在**原始** $v$ 中的重数（更小的质因子已除尽，不影响 $p$ 的重数）。输出 $p^e$ 正确。
- 若 $p$ 是合数：$p$ 的质因子都 $<p$，已被除尽，故 $p\nmid v$，`if` 不触发，跳过合数不影响结果。

设原始 $v$ 的某质因子为 $q$。当 $p$ 递增到 $q$ 时，若此时 $q^2\le v_{\text{当前}}$，循环会执行到 $p=q$ 并除尽 $q$（输出）；若 $q^2>v_{\text{当前}}$，则循环在 $p\le q$ 前就因 `p*p>v` 终止，此时 $q$ 作为剩余 $v$ 被引理 4 处理。两种情形 $q$ 都被输出。故所有质因子无遗漏，且因 $p$ 递增而有序。证毕。

---

### 引理 4（循环结束后剩余的 $v$ 是 $1$ 或质数）

试除循环终止（即首次 $p^2>v$）后，若 $v>1$，则 $v$ 是质数。

*证明*：反证。设终止时 $v>1$ 且 $v$ 是合数。则 $v$ 有最小质因子 $q\le\sqrt v$。由终止条件 $p^2>v$ 得 $p>\sqrt v\ge q$，即 $q<p$。由引理 3 的不变量，进入第 $p$ 轮时 $v$ 不含任何 $<p$ 的质因子，而 $q<p$ 且 $q\mid v$，矛盾。故 $v$ 不可能是合数；$v>1$ 时只能是质数。证毕。

**推论**：代码末尾 `if(v>1) 输出 v`（指数 $1$，省略 `^1`）正确补上最后一个大质因子。例如 $v=512559680$ 除尽 $2^6,5$ 后剩 $1601749$，$p$ 枚举到 $1266$ 时 $1266^2>1601749$ 终止，$1601749>1$ 作为质数输出。

---

### 引理 5（输出格式与数值一致）

程序输出 `v=` 后接各质因子（升序、`*` 连接、指数 $>1$ 才写 `^e`），$v=1$ 时输出 `1=1`。该串表示的乘积恰等于 $v$。

*证明*：由引理 3、4，输出的质因子集合 $\{p_i\}$ 与指数 $\{e_i\}$ 满足 $v=\prod p_i^{e_i}$（算术基本定理保证唯一）。代码对每个因子：`first` 控制是否前置 `*`（第一个不前置），`cout<<p`，`if(e>1)cout<<'^'<<e`。故输出串解析回来正是 $\prod p_i^{e_i}=v$。$v=1$ 时无质因子，单独输出 `1=1`，乘积 $1=v$ ✓。左边的 `v` 由引理 1 等于 $f(n)\bmod M$，故整串表示"$f(n)\bmod M$ 的质因数分解"。证毕。

---

### 引理 6（复杂度）

时间 $O(n+\sqrt v)$，空间 $O(n)$。

*证明*：递推 $n-2$ 次加法取模，$O(n)$，$n\le48$。试除 $p$ 从 $2$ 到 $\sqrt v\le\sqrt{2^{31}}\approx46341$，每轮一次取模，$O(\sqrt v)$。合计 $O(n+\sqrt v)\le48+46341$，瞬间完成。空间 `f[55]` 为 $O(n)$。证毕。

---

### 定理

程序输出 $f(n)\bmod 2^{31}$ 的质因数分解串，格式为 `值=质数^指数*...`（指数 $1$ 省略、$1$ 输出 `1=1`），正确且高效。

*证明*：引理 1 保证 $v=f(n)\bmod M$；引理 2 保证只需处理 $v=1$ 边界；引理 3、4 保证试除分解完整且剩余为质数；引理 5 保证输出串与 $v$ 的分解一致；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — $n\le48$ 时 $f(47),f(48)$ 已超 $2^{31}$，要分解的是**取模后**的值，不是原始 $f(n)$。
- **classic problem solution** — 边递推边取模 `f[i]=(f[i-1]+f[i-2])%M`，模加法同态保证等价，`long long` 防溢出。
- **classic problem solution** — 试除分解质因数：$p$ 从 $2$ 到 $\sqrt v$，除尽记指数，剩余 $>1$ 即大质数。
- **explore its property** — 反证"剩余 $v$ 必为质数"：若合数则有 $\le\sqrt v<p$ 的质因子，早该被除掉。
- **discuss by category** — 边界 $v=1$（$n=1,2$）输出 `1=1`；核对 $v$ 恒 $\ne0$；指数 $1$ 省略 `^1`、因子升序 `*` 连接。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 项数（$\le48$） | `int`，读入 | $f(1)=f(2)=1$ |
| `mod` | $M=2^{31}$ | `constexpr i64{1LL<<31}` | 取模基数 |
| `f[i]` | $f(i)\bmod M$ | `i64[55]`，`f[1]=f[2]=1` | 边递推边取模 |
| `v` | 待分解的值 $=f[n]$ | `i64` | $v\in[1,M)$，恒 $\ne0$ |
| `p` | 试除的当前除数 | `i64`，从 $2$ 递增 | `p*p<=v` 为循环条件 |
| `e` | 质因子 $p$ 的指数 | `int`，每轮清 $0$ | $e>1$ 才输出 `^e` |
| `first` | 是否还没输出过因子 | `bool`，初值 `true` | 控制 `*` 前置 |

### 算法步骤

1. I/O 加速三行；读 `n`。
2. `f[1]=f[2]=1`；`for i=3..n: f[i]=(f[i-1]+f[i-2])%mod`（引理 1）。
3. `v=f[n]`；先输出 `v<<'='`。
4. 若 `v==1`：输出 `1` 与换行，结束（引理 2）。
5. `for p=2; p*p<=v; ++p`：若 `v%p==0`，`while(v%p==0)v/=p,++e`；非首个因子先输出 `*`；输出 `p`，`e>1` 再输出 `^e`（引理 3）。
6. 循环后若 `v>1`：非首个先输出 `*`，再输出 `v`（引理 4）。
7. 输出换行。

### 复杂度

- 时间：$O(n+\sqrt v)\le48+46341$，可忽略。
- 空间：$O(n)$，`f[55]`。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面无样例，手算 $n=3,6,12,46,47,48$ 六组，输出分解式乘回均精确等于左边值（如 $2^6\cdot5\cdot1601749=512559680=f(48)\bmod2^{31}$，$139\cdot461\cdot28657=1836311903=f(46)$），$1601749$ 经试除确认为质数；$n=1,2$ 输出 `1=1`。**格式说明**：题面未给样例，按本题通行格式 `值=质数^指数*...`（指数 $1$ 省略、$1$ 记为 `1=1`）实现。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2626 斐波那契数列（升级版）
// 边递推边 mod 2^31，再对结果试除分解质因数
// 输出格式：值=质数^指数*质数^指数...（指数 1 省略；值为 1 时输出 1=1）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr i64 mod{1LL<<31};

int n;
i64 f[55];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	f[1]=f[2]=1;
	for(int i=3;i<=n;++i)
		f[i]=(f[i-1]+f[i-2])%mod;	// 模加法同态：等价于完整 f(n) 再取模
	i64 v=f[n];
	cout<<v<<'=';
	if(v==1)	// 1 没有质因子，约定输出 1=1
	{
		cout<<1<<'\n';
		return 0;
	}
	bool first=true;
	for(i64 p=2;p*p<=v;++p)
		if(v%p==0)
		{
			int e=0;
			while(v%p==0)v/=p,++e;
			if(!first)cout<<'*';
			first=false;
			cout<<p;
			if(e>1)cout<<'^'<<e;	// 指数 1 省略 ^1
		}
	if(v>1)	// 剩下的 v 是质数（引理 4）
	{
		if(!first)cout<<'*';
		cout<<v;
	}
	cout<<'\n';
	return 0;
}
```

### 代码说明

- **`%mod` 每步都做**：保证 `f[i-1]+f[i-2]<2^{32}`，`long long` 不溢出；由引理 1 与"先算完整值再取模"等价。
- **分解的是 `v=f[n]`（已取模）**，不是原始斐波那契数——这是本题最容易看漏的地方。
- **`p*p<=v` 用 `i64`**：$p\le46341$，$p^2\le2.1\times10^9$，`i64` 安全；`v` 在循环中不断变小，上界随之收缩，效率更高。
- **`while(v%p==0)v/=p,++e`**：一次除尽同一个质因子，`e` 即重数；合数 `p` 因其质因子已除尽而不会整除 `v`，自动跳过。
- **`first` 控制 `*`**：第一个因子前不加 `*`，其余前置；末尾大质数同样处理。
- **`v==1` 提前返回**：$n=1,2$ 的唯一边界，输出 `1=1`；由引理 2，$v$ 不会是 $0$，无需处理。
