# P2790 ccj与zrz之积木问题 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n<25$ 个位置，初始位置 $i$ 上放着积木 $i$（编号 $0\sim n-1$，**天然 0-based**）。四种指令：`move a onto b`、`move a over b`、`pile a onto b`、`pile a over b`，语义是"把 $a$（单个 / 连同上方整摞）放到 $b$（清掉 $b$ 上方之后直接摞在 $b$ 上 / $b$ 所在堆的顶部）"，放之前 `move` 还要先把 $a$ 上方归位。$a,b$ 在同一堆的指令非法，直接忽略。`quit` 结束，输出每个位置从底到顶的积木。这就是经典的 UVa101 The Blocks Problem。

**第一步：把四条指令拆成两个原语。** 四条指令看着多，其实是两个独立开关的 $2\times2$ 组合：

| | onto（先清 $b$ 上方） | over（不清） |
|---|---|---|
| **move**（先清 $a$ 上方，只搬 $a$） | `back(a); back(b);` 搬单个 | `back(a);` 搬单个 |
| **pile**（$a$ 连同上方整摞搬） | `back(b);` 整摞搬 | 整摞搬 |

于是只需要实现两个原语：`back(x)`＝把 $x$ 上方的积木逐个归位；`carry(a,b)`＝把 $a$ 及其上方整摞搬到 $b$ 所在堆顶。"搬单个"就是 `back(a)` 之后 $a$ 成了堆顶，pop 出来 push 过去——它是 `carry` 的退化情形。四条指令各是一行组合，不用写四份逻辑。

**第二步：数据结构。** 每个位置一个 `vector<int> pile[i]`（底$\to$顶）。指令给的是积木编号，要 $O(1)$ 知道它在哪个堆，再维护一个反向索引 `loc[x]`。$n<25$，其实每次线性找也能过，但 `loc` 让"同堆非法"的判断变成一句 `loc[a]==loc[b]`，干净得多。

**第三步：本题真正隐蔽的性质——归位时，家一定是空的。** 写 `back` 时会犹豫：把积木 $t$ 归位到位置 $t$，如果位置 $t$ 上还堆着别的积木怎么办？直接 push 会不会把 $t$ 压在别人上面、顺序就乱了？动手画几步就会发现一个不变量：

> **非空堆 $i$ 的堆底永远是积木 $i$。**

初始显然。之后所有操作要么"从某堆顶部拿走若干"（不动堆底），要么"往某堆顶部追加若干"（不动堆底），要么"把 $t$ 归位到位置 $t$"——而由不变量立刻推出：**$t$ 不在位置 $t$ 时，位置 $t$ 必空**（否则堆底是 $t$，$t$ 就在家了）。所以归位就是 push 进一个空堆，顺序问题根本不存在。这个性质不证清楚，`back` 写起来心里是没底的；证清楚之后它反而是全题最让人安心的一步。（完整归纳证明见第二部分引理 2。）

**第四步：几个必须抠住的实现细节。**

1. **非法判断必须在任何修改之前**：`loc[a]==loc[b]` 时整条指令跳过。注意 $a=b$ 也满足同堆，自动被覆盖。
2. **`carry` 里先捕获 `pa=loc[a], pb=loc[b]` 再动手**：搬运过程中 `loc[a]` 会被改成 `pb`，如果循环里现取 `loc[a]` 定位源堆就会错；目标堆用捕获的 `pb`。合法性保证 `pa!=pb`，两个 vector 不是同一个，边读边 push 安全。
3. **`back(a)` 与 `back(b)` 的顺序无关**：$a,b$ 不同堆，两次归位动的是不相交的积木集合（引理 4 会证连"归位目的地"都不会撞进对方的堆），先清谁都行。
4. **输出格式**：`i:` 后每个积木前缀一个空格（`i: 2 1 3`）；空堆只输出 `i:`，不带尾随空格。

**第五步：手造数据逐条推演**（题面无样例）。

第一组，$n=4$：`move 1 onto 2` → 堆2=`[2,1]`；`pile 3 over 1` → 把 `[3]` 搬到堆2顶 → `[2,1,3]`；`move 0 onto 3` → $0$ 上方无物、$3$ 是堆2顶，$0$ 摞上 → `[2,1,3,0]`。输出：

```
0:
1:
2: 2 1 3 0
3:
```

第二组，$n=5$，专打"归位"与"非法指令"：`pile 1 onto 2`→`[2,1]`；`pile 3 over 2`→`[2,1,3]`；`move 1 onto 4`→先把 $1$ 上方的 $3$ 归位（堆3=`[3]`），再搬 $1$ →堆4=`[4,1]`；`pile 2 over 1`→`[2]` 搬到堆4 →`[4,1,2]`；`move 3 onto 2`→$2$ 是堆4顶，$3$ 摞上 →`[4,1,2,3]`；`move 1 over 1`→同堆，忽略。输出：

```
0: 0
1:
2:
3:
4: 4 1 2 3
```

两组都与程序输出逐字节一致。

## 二、思维链：完整证明

**记号。** 积木集合 $\{0..n-1\}$，位置集合同。**格局**＝每个积木所在位置的指派 $\mathrm{pos}:\text{积木}\to\text{位置}$，加上每个位置内从底到顶的一个有序列表。代码用 `pile[i]`（列表）与 `loc[x]`（指派）表示格局。指令序列中合法指令按序作用，非法指令是恒等变换。

---

### 引理 1（表示一致性）

任何时刻：每个积木恰出现在一个 `pile` 中一次，且 `loc[x]` 等于含 $x$ 的那个堆的下标。

*证明*：初始 `pile[i]=[i]`、`loc[i]=i`，成立。只需证每个原语保持：

- `back(x)`：每轮从堆 $j$ pop 出 $t$ 再 push 进堆 $t$，$t$ 的出现次数不变、所在堆从 $j$ 变 $t$，同步写 `loc[t]=t` ✓；其余积木不动 ✓。
- `carry(a,b)`：把源堆中 $a$ 及其上方的每个积木 $y$ 依次 push 进目标堆并写 `loc[y]=pb`，最后 `resize` 从源堆删去它们。每个 $y$ 仍是"恰在一个堆、`loc` 同步" ✓；$b$ 及目标堆原有积木、源堆 $a$ 下方的积木都不动 ✓。
- 搬单个：pop＋push＋改 `loc`，同上 ✓。

非法指令直接 `continue`，格局不变 ✓。归纳得证。证毕。

### 引理 2（堆底不变量与"家必空"）

**不变量 I1：任何非空堆 $i$ 的堆底元素是积木 $i$。** 从而 **I2：积木 $t$ 不在位置 $t$ $\Rightarrow$ 堆 $t$ 为空**。

*证明*：I2 是 I1 的逆否：若堆 $t$ 非空，由 I1 堆底是 $t$，故 $t$ 在位置 $t$。下面对指令条数归纳证 I1。

初始：堆 $i=[i]$，堆底 $i$ ✓。设某指令前 I1 成立，逐原语检查：

- `back(x)` 中的一轮归位：设 $t$ 从堆 $j=\texttt{loc}[x]$ 顶部被弹出，要 push 进堆 $t$。先证 $j\ne t$：若 $j=t$，则 $t$ 在堆 $t$ 中且位于 $x$ 上方（$t\ne x$，因为循环条件是堆顶 $\ne x$），但 I1 说堆 $t$ 的堆底是 $t$，$t$ 不可能既在堆底又在 $x$ 上方，矛盾。故 $t$ 不在位置 $t$，由 I2 **堆 $t$ 为空**，push 后堆 $t=[t]$，堆底 $t$ ✓。源堆 $j$：只弹顶部，且循环在 $x$ 处停止，$x$ 始终留在堆 $j$，堆 $j$ 非空、堆底不变 ✓。
- `carry(a,b)`：目标堆 $pb$ 含 $b$，非空，追加不改变堆底 ✓。源堆 $pa$：删去从 $a$ 开始的顶部后缀。若 $a$ 是堆底（由 I1 即 $a=pa$），源堆变空，I1 对空堆无要求 ✓；否则堆底 $pa$ 留在源堆 ✓。
- 搬单个：`back(a)` 后 $a$ 是堆顶，pop 使源堆要么变空（$a$ 是堆底）要么堆底不动；push 进含 $b$ 的非空目标堆，堆底不动 ✓。

所有原语保持 I1，归纳成立。证毕。

**这条引理是 `back` 的正确性地基**：归位永远是"push 进空堆"，不存在"压到别人上面"的情形，归位后的顺序（只有一个元素）平凡正确。

### 引理 3（`back(x)` 的后置条件）

`back(x)` 终止时：$x$ 是其所在堆的堆顶；原先在 $x$ 上方的每个积木 $t$ 都单独位于堆 $t$；$x$ 下方的积木与其余堆不受影响。

*证明*：循环每轮弹出当前堆顶。由引理 1，$x$ 在堆 $\texttt{loc}[x]$ 中；堆是有限列表，从顶向下逐个弹出，必然在有限步内到达 $x$（循环条件 `v.back()!=x` 恰在 $x$ 成为堆顶时退出）。被弹出的恰是"初始时 $x$ 上方的那些积木"（它们按从顶到底的顺序离开），每个由引理 2 的论证进入空堆 $t$ 且 `loc[t]=t`。$x$ 下方元素从未被触碰；其他堆只可能作为归位目的地被 push，而目的地堆 $t$ 为空（引理 2），push 不影响任何已有积木。证毕。

### 引理 4（两次归位互不干扰）

合法指令中 $a,b$ 不同堆。`back(a)` 与 `back(b)` 作用的积木集合不相交，且各自的归位目的地堆也不会是对方的工作堆；故两者可交换，先后顺序不影响结果。

*证明*：`back(a)` 只弹出堆 $pa$ 中 $a$ 上方的积木，`back(b)` 只弹出堆 $pb$ 中 $b$ 上方的积木，$pa\ne pb$，两个被弹集合不相交。再看目的地：`back(a)` 归位的积木 $t$ 满足"$t$ 在堆 $pa$ 中且 $t\ne pa$"（引理 2 已证 $j\ne t$），其目的地是堆 $t$。堆 $t$ 会等于 $pb$ 吗？若 $t=pb$，则积木 $pb$ 在堆 $pa$ 中；但 $b$ 在堆 $pb$ 中，若堆 $pb$ 非空则堆底是 $pb$（I1），即积木 $pb$ 应在堆 $pb$，与引理 1 的"恰在一个堆"矛盾。故目的地 $\ne pb$；对称地 `back(b)` 的目的地 $\ne pa$。于是两次归位读写的堆完全不相交，操作可交换。证毕。

### 引理 5（四条指令 = 原语组合，逐条对照语义）

对合法指令（$\texttt{loc}[a]\ne\texttt{loc}[b]$）：

1. `move a onto b` ≡ `back(a); back(b);` 搬单个；
2. `move a over b` ≡ `back(a);` 搬单个到堆 $\texttt{loc}[b]$ 顶；
3. `pile a onto b` ≡ `back(b); carry(a,b)`；
4. `pile a over b` ≡ `carry(a,b)`。

*证明*：逐条对照题面语义。

1. 题面：把 $a$ 和 $b$ 上方的木块全部归位，然后把 $a$ 摞在 $b$ 上面。由引理 3，`back(a)` 后 $a$ 是堆顶、`back(b)` 后 $b$ 是堆顶（引理 4 保证两步互不干扰且都执行到位）。搬单个：pop $a$、push 到堆 $\texttt{loc}[b]$——此时 $b$ 是该堆顶，故 $a$ 恰好直接摞在 $b$ 上 ✓。
2. 题面：把 $a$ 上方归位，把 $a$ 放在 $b$ 所在堆的顶部。`back(a)` 后搬单个到堆 $\texttt{loc}[b]$ 顶；$b$ 上方若有积木则保留，$a$ 压在它们上面，正是"堆顶"而非"$b$ 上" ✓。
3. 题面：把 $b$ 上方归位，把 $a$ 及上面整摞摞在 $b$ 上。`back(b)` 后 $b$ 是堆顶；`carry(a,b)` 把 $a$ 起的后缀按原序追加到堆 $\texttt{loc}[b]$，$a$ 落在 $b$ 正上方，整摞内部顺序不变 ✓。注意 `carry` 前**不需要** `back(a)`：$a$ 上方的积木正是要一起搬的。
4. 题面：整摞搬到 $b$ 所在堆顶。`carry(a,b)` 直接实现 ✓。

代码的分支结构 `if(op=="move")back(a); if(md=="onto")back(b);` 恰好枚举上表四格；`move` 分支的搬单个与 `pile` 分支的 `carry` 分别对应"只搬 $a$"与"搬整摞"。证毕。

### 引理 6（`carry` 的实现细节正确）

先捕获 `pa=loc[a], pb=loc[b]`，`pos=find(...)` 定位 $a$，循环 `i=pos..size-1` 逐个 `loc[va[i]]=pb; pile[pb].push_back(va[i]);`，最后 `va.resize(pos)`。则整摞按原序转移、`loc` 全部同步、源堆恰好截断。

*证明*：合法性保证 $pa\ne pb$，故 `va` 与 `pile[pb]` 是不同 vector，对 `pile[pb]` 的 push 不会使 `va` 的引用/迭代器失效。循环中修改的是 `loc[va[i]]`，而 `va[i]` 都属于源堆、$b$ 属于目标堆，故 `loc[b]` 全程不变（用捕获的 `pb` 更保险）。`find` 一定成功（引理 1：$a$ 在堆 `pa` 中）。追加顺序即源堆中从 $a$ 到顶的顺序，保持整摞内部相对顺序；`resize(pos)` 删去的恰是已搬走的后缀。每个被搬积木的 `loc` 在 push 的同时更新为 `pb`，引理 1 的一致性保持。证毕。

### 引理 7（非法指令与输出格式）

`loc[a]==loc[b]`（含 $a=b$）时跳过，格局不变，符合"非法指令应当忽略"。输出第 $i$ 行为 `i:` 后跟每个积木的 `' '+编号`，即从底到顶；空堆输出 `i:`。

*证明*：同堆判断在 `back/carry` 之前执行，`continue` 不触碰任何状态 ✓。$a=b$ 时 $\texttt{loc}[a]=\texttt{loc}[b]$ 恒成立，被同一判断覆盖 ✓。输出循环 `for(int v:pile[i])` 按 vector 下标序即底$\to$顶序打印，与题面"按照从底部到顶部的顺序"一致；格式沿用 UVa101 原题（冒号后每个积木前一个空格，空堆无尾随空格）。证毕。

### 引理 8（复杂度）

每条指令 $O(n)$，$q$ 条指令共 $O(qn)$；空间 $O(n)$。

*证明*：`back` 每轮弹一个积木，至多 $n$ 轮；`carry` 的 `find` 与搬运各 $\le n$；搬单个 $O(1)$ 均摊（vector 尾操作）。$n<25$，常数极小。空间：$n$ 个 vector 共 $n$ 个元素＋`loc` 数组。证毕。

### 定理

程序输出的格局恰为初始格局按序施加所有合法指令后的结果。

*证明*：引理 1 保证表示始终一致；引理 2、3 保证归位原语正确（家必空、$x$ 成堆顶）；引理 4 保证两次归位可交换；引理 5 保证四条指令的语义逐条落实；引理 6 保证整摞搬运的顺序与索引同步；引理 7 保证非法指令被忽略、输出格式正确。对指令条数归纳即得。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 四条指令 = "搬单个/搬整摞" × "清目标顶/不清" 的 $2\times2$ 组合，先拆开关再写代码。
- reduce to easier problem — 归约成两个原语 `back(x)` 与 `carry(a,b)`，每条指令只是它们的组合；搬单个是 `back(a)` 后的退化搬运。
- explore its property — 堆底不变量：非空堆 $i$ 堆底必为 $i$ ⇒ 积木不在家时家必空 ⇒ 归位 = push 进空堆，顺序无忧。
- classic problem solution — vector 堆模拟 + `loc[]` 反向索引，$O(1)$ 定位与同堆判断。
- discuss by category — 同堆非法（含 $a=b$）先判再动；`carry` 前捕获 `pa/pb`；空堆输出 `i:` 无尾随空格。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 位置/积木数，$<25$ | `int`，读入 | 编号天然 0-based，不做 `--` |
| `pile[i]` | 位置 $i$ 从底到顶的积木列表 | `vector<int>[mxn]`，初始 `[i]` | 堆底不变量：非空则底为 $i$ |
| `loc[x]` | 积木 $x$ 所在堆下标 | `int[mxn]`，初始 `loc[i]=i` | 与 `pile` 同步维护 |
| `back(x)` | 把 $x$ 上方积木逐个归位 | `void` | 归位 = push 进空堆 |
| `carry(a,b)` | $a$ 及上方整摞搬到 $b$ 堆顶 | `void` | 先捕获 `pa,pb` 再动手 |
| `op,md` | 指令动词 move/pile 与介词 onto/over | `string` | 两个开关 |

### 算法步骤

1. 读 $n$；初始化 `pile[i]=[i]`、`loc[i]=i`。
2. 循环读 `op`，遇 `quit` 停；读 `a md b`。
3. 若 `loc[a]==loc[b]` 跳过（非法）。
4. `op=="move"` 则 `back(a)`；`md=="onto"` 则 `back(b)`。
5. `move`：pop 堆顶 $a$，改 `loc[a]=loc[b]`，push 进目标堆；`pile`：`carry(a,b)`。
6. 对每个位置输出 `i:` 及 `' '+积木` 序列，换行。

### 复杂度

- 时间：$O(qn)$，$q$ 为指令数，$n<25$。
- 空间：$O(n)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；两组手造指令序列（含归位、整摞搬运、同堆非法指令、$n=1$ 边界）逐字节吻合手推结果。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2790 ccj与zrz之积木问题（UVa101 The Blocks Problem）
// pile[i]=第 i 个位置从底到顶的积木；loc[x]=积木 x 现在哪个位置。
// 关键不变量：非空堆 i 的堆底必是 i ⇒ x 不在位置 x 时位置 x 必空 ⇒ 归位就是 push 进空堆。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{30};

int n,loc[mxn];
vector<int>pile[mxn];

void back(int x)	// 把 x 上方的积木全部归位
{
	auto&v=pile[loc[x]];
	while(v.back()!=x)
	{
		int t=v.back();
		v.pop_back();
		pile[t].push_back(t);	// 位置 t 此时必空（堆底不变量）
		loc[t]=t;
	}
}
void carry(int a,int b)	// 把 a 及其上方整摞搬到 b 所在堆顶
{
	int pa=loc[a],pb=loc[b];
	auto&va=pile[pa];
	int pos=find(va.begin(),va.end(),a)-va.begin();
	for(int i=pos;i<(int)va.size();++i)
	{
		loc[va[i]]=pb;
		pile[pb].push_back(va[i]);
	}
	va.resize(pos);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		pile[i].push_back(i);
		loc[i]=i;
	}
	for(string op,md;cin>>op&&op!="quit";)
	{
		int a,b;
		cin>>a>>md>>b;	// 编号本来就是 0-based，不需要 --
		if(loc[a]==loc[b])
			continue;	// 同一堆（含 a==b）：非法指令，忽略
		if(op=="move")
			back(a);
		if(md=="onto")
			back(b);
		if(op=="move")
		{
			pile[loc[a]].pop_back();	// back(a) 后 a 必是堆顶
			loc[a]=loc[b];
			pile[loc[a]].push_back(a);
		}
		else
			carry(a,b);
	}
	for(int i=0;i<n;++i)
	{
		cout<<i<<':';
		for(int v:pile[i])
			cout<<' '<<v;
		cout<<'\n';
	}
	return 0;
}
```

### 代码说明

- `back` 里 `pile[t].push_back(t)` 之所以敢直接 push，全靠堆底不变量（引理 2）：$t$ 不在家 ⇒ 家必空。这是本题最值得记住的一条性质。
- `carry` 先捕获 `pa/pb`：循环会改 `loc[a]`，现取 `loc[a]` 定位源堆是经典错误；`pa!=pb` 由合法性检查保证，两个 vector 互不干扰。
- 搬单个的三行顺序：先 pop（此时 `loc[a]` 还是旧堆），再改 `loc[a]`，再 push 进 `pile[loc[a]]`（已是新堆）。
- 非法判断 `loc[a]==loc[b]` 放在一切修改之前，$a=b$ 自动被覆盖。
- 输出 `i:` 后每个积木前缀一个空格；空堆只有 `i:`，与 UVa101 格式一致。
