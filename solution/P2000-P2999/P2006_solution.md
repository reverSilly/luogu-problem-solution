# P2006 赵神牛的游戏 — 题解

## 一、解题过程：人类思考叙事

题目背景是 DNF，赵神牛有 $k$ 点法力，$m$ 个技能，boss 血量 $n$。

关键句在题面最后：「他**一局只放一个技能**，不过每个技能都可以放无数次」。

这就把问题简化成了一个纯粹的单技能判定：对每个技能 $i$，问「只放这一个技能，能不能打死 boss」。

再看技能参数：耗蓝 $a_i$，造成伤害 $b_i$，法力一共 $k$ 点。

放一次消耗 $a_i$ 点法力，那么最多能放 $\lfloor k/a_i \rfloor$ 次，总伤害就是 $\lfloor k/a_i \rfloor \cdot b_i$。只要这个值 $\ge n$，这个技能就能打死 boss。

到这里基本上就是一遍循环了。但是有两个坑：

**坑一：$a_i = 0$。** 数据范围明确写 $0 \le a_i, b_i \le 2147483647$。当 $a_i = 0$ 时，$\lfloor k/a_i \rfloor$ 是**除零**，程序会直接崩。而且此时语义是"不耗蓝，可以无限放"，伤害无穷大，只要 $b_i > 0$ 就能打死 boss。所以 $a_i=0$ 要**单独处理**。

那如果 $a_i = 0$ 且 $b_i = 0$ 呢？每放一次伤害 0，放一万次也是 0，打不死 boss。这种技能要判为不可行。

**坑二：溢出。** $b_i$ 最大 $2147483647 \approx 2.1\times 10^9$，已经超了 `int` 的最大值 $2147483647$？不，正好等于上限，但 $\lfloor k/a_i \rfloor \cdot b_i$ 的乘积可以轻松到 $3\times 10^4 \times 2.1\times 10^9 \approx 6.4\times 10^{13}$，远超 `int`。必须用 `long long`。

同理 $k, n$ 虽然都 $\le 3\times 10^4$，但统一用 `long long` 更省心。

再看输出格式：「可以杀死 boss 的技能序号，如果有多个，按从小到大的顺序输出，中间用一个空格隔开；如果没有技能能杀死 boss，输出 `-1`」。所以遍历 $i = 1 \dots m$ 顺序判定，天然就是升序。用一个 `first` 标志控制空格，避免输出多余的空格。

样例 1：`k=100, m=3, n=5000`，技能 `(20,1000), (90,1), (110,10000)`。
- 技能 1：$100/20 = 5$ 次，伤害 $5\times 1000 = 5000 \ge 5000$，可行。
- 技能 2：$100/90 = 1$ 次，伤害 $1$，不够。
- 技能 3：$100/110 = 0$ 次（法力不够放一次），伤害 0，不够。

输出 `1`。✓

样例 2：`k=50, m=4, n=10`，技能 `(60,100), (70,1000), (80,1000), (90,0)`。
- 技能 1：$50/60 = 0$ 次，伤害 0，不行。
- 技能 2、3 同理。
- 技能 4：$50/90=0$ 次，伤害 0（就算能放，$b_i=0$ 也没用），不行。

输出 `-1`。✓

这是一道纯模拟题，唯一值得写一写的就是 $a_i=0$ 的分类讨论和溢出防护。

## 二、思维链：完整证明

**引理 1**：当 $a_i > 0$ 时，只放技能 $i$ 能造成的最大总伤害为 $\lfloor k/a_i \rfloor \cdot b_i$。

*证明*：施放一次技能 $i$ 消耗 $a_i$ 点法力。施放 $t$ 次共消耗 $t\cdot a_i$ 点法力，法力有限的充要条件是 $t\cdot a_i \le k$，即 $t \le \lfloor k/a_i \rfloor$。故施放次数的最大值为 $t_{\max} = \lfloor k/a_i \rfloor$。每次施放造成 $b_i$ 点伤害且伤害可累加，故最大总伤害为 $t_{\max}\cdot b_i = \lfloor k/a_i \rfloor\cdot b_i$。证毕。

**引理 2**：当 $a_i = 0$ 时，只放技能 $i$ 能打死 boss 当且仅当 $b_i > 0$。

*证明*：$a_i=0$ 意味着施放该技能不消耗法力，因此施放次数不受 $k$ 限制，可以施放任意多次。若 $b_i > 0$，则每次施放造成 $b_i$ 点正伤害，总伤害随次数无上界增长，必然能达到 $\ge n$，可以打死 boss。若 $b_i = 0$，则每次施放伤害为 0，无论施放多少次总伤害恒为 0，而 $n > 0$，故永远打不死。证毕。

**引理 3**：只放技能 $i$ 能打死 boss 当且仅当 $a_i=0$ 时 $b_i>0$，或 $a_i>0$ 时 $\lfloor k/a_i\rfloor\cdot b_i \ge n$。

*证明*：分 $a_i=0$ 与 $a_i>0$ 两种情形，由引理 1 与引理 2 分别得到。两种情形覆盖了所有可能的 $a_i$（数据范围保证 $a_i\ge 0$），故结论成立。证毕。

**引理 4**：算法输出的技能序号集合恰好是所有能打死 boss 的技能序号集合，且按升序排列。

*证明*：算法按 $i=1,2,\dots,m$ 的顺序遍历，对每个 $i$ 依据引理 3 判定其可行性，判定条件与"能否打死 boss"完全等价，故被输出的技能恰好是可行技能，不多不少。由于遍历顺序本身是升序，输出的序号自然升序。证毕。

**引理 5**：若不存在可行技能，算法输出 `-1`；否则输出的第一行恰为所有可行序号，格式符合题面要求。

*证明*：算法用 `first` 标志记录是否已经输出过内容。若全部技能都不可行，`first` 始终为真，输出 `-1`；否则在输出第一个可行序号前 `first` 为真，不加空格，之后每输出一个前先加一个空格，因此整行恰为升序、逗号分隔（空格分隔）的序号序列，符合题面「中间用一个空格隔开」的要求。证毕。

**引理 6**：算法中所有算术运算不发生溢出。

*证明*：$\lfloor k/a_i\rfloor \le k \le 3\times 10^4$（因 $a_i \ge 1$）。故乘积 $\lfloor k/a_i\rfloor \cdot b_i \le 3\times 10^4 \times 2147483647 \approx 6.44\times 10^{13}$。`long long` 的范围是 $\pm 9.22\times 10^{18}$，远大于该上界，故不溢出。证毕。

**定理**：算法输出的结果正确。

*证明*：由引理 3，每个技能的可行性判定正确；由引理 4、5，输出集合与格式正确；由引理 6，判定过程本身可靠。故算法正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **抓题面关键句** — "一局只放一个技能，但每个技能可以放无数次" → 不是背包，是对每个技能独立判定。
2. **写出判定公式** — 施放次数 $\lfloor k/a_i\rfloor$，总伤害 $\lfloor k/a_i\rfloor\cdot b_i$，与 $n$ 比较。
3. **发现除零边界** — $a_i=0$ 必须单独分类，否则程序崩溃。
4. **补齐 $a_i=0,b_i=0$ 的语义** — 无消耗但零伤害，仍打不死。
5. **检查溢出** — 乘积可达 $6.4\times 10^{13}$，必须 `long long`。
6. **输出格式** — 升序、空格分隔、无解输出 `-1`，用 `first` 标志控制空格。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $k$ | 法力值总量 | `i64`，$[0,3\times 10^4]$ |
| $m$ | 技能个数 | `int`，$(0,3\times 10^4]$ |
| $n$ | boss 体力值 | `i64`，$(0,3\times 10^4]$ |
| $a_i$ | 第 $i$ 个技能的耗蓝量 | `i64`，$[0,2147483647]$ |
| $b_i$ | 第 $i$ 个技能的单次伤害 | `i64`，$[0,2147483647]$ |
| $cnt$ | 技能 $i$ 的最多施放次数 | `i64` |
| $dmg$ | 技能 $i$ 的最大总伤害 | `i64` |
| `first` | 是否已经输出过技能序号 | `bool` |

### 算法步骤

1. 读入 $k, m, n$。
2. 读入 $m$ 组 $(a_i, b_i)$。
3. 初始化 `first = true`。
4. 对 $i=1,2,\dots,m$：
   1. 若 $a_i = 0$：该技能不耗蓝可无限施放，可行当且仅当 $b_i > 0$。
   2. 否则：`cnt = k / a_i`，`dmg = cnt * b_i`，可行当且仅当 `dmg >= n`。
   3. 若可行：若 `first` 为真则不输出空格，否则先输出一个空格；输出 $i$；置 `first = false`。
5. 若 `first` 仍为真（无任何可行技能），输出 `-1`。
6. 输出换行。

### 复杂度

- 时间复杂度：$O(m)$。
- 空间复杂度：$O(m)$（存储各技能的 $(a_i,b_i)$）。

### 验证状态

- 标程 `P2006.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面样例 1（`100 3 5000` / `20 1000` / `90 1` / `110 10000`）输出 `1`；样例 2（`50 4 10` / `60 100` / `70 1000` / `80 1000` / `90 0`）输出 `-1`，均与官方一致。
- 编写暴力 `P2006_brute.cpp`（逐次施放模拟伤害累加，上限 100000 次）与对拍脚本 `P2006_check.py`，在 $k\in[0,30000]$、$a_i,b_i$ 含 $0$ 与 $2147483647$ 边界值的随机数据上对拍 **400 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2006 赵神牛的游戏
// 模拟：每个技能可施放 k/a_i 次，总伤害 (k/a_i)*b_i
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{30005};

int m;
i64 k,n;
i64 a[mxn],b[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>k>>m>>n;
	for(int i=0;i<m;++i)
		cin>>a[i]>>b[i];
	bool first=true;
	for(int i=0;i<m;++i)
	{
		bool ok=false;
		if(a[i]==0)
		{
			//不耗蓝，理论上可无限施放：只有伤害大于 0 才能打死 boss
			ok=(b[i]>0);
		}
		else
		{
			i64 cnt=k/a[i];//最多施放次数
			i64 dmg=cnt*b[i];//总伤害，64 位防止溢出
			ok=(dmg>=n);
		}
		if(ok)
		{
			if(!first)
				cout<<' ';
			first=false;
			cout<<i+1;
		}
	}
	if(first)
		cout<<-1;
	cout<<'\n';
	return 0;
}
```

### 代码说明

- `a[i]==0` 的分支必须放在除法之前，否则 `k/a[i]` 会触发整数除零（程序直接 UB 崩溃）。
- `cnt * b[i]` 中 `cnt` 与 `b[i]` 都是 `i64`，乘积在 `long long` 范围内（引理 6）。
- `a` / `b` 用 1-based 语义（`a[i]` 对应第 $i+1$ 个技能），输出时用 `i+1` 直接得到技能序号。
- `first` 标志保证空格只在两个序号之间出现，且空结果时能正确输出 `-1`。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
