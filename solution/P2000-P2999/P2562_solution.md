# P2562 [AHOI2002] Kitty猫基因编码 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给一个 $01$ 串，长度 $Len\le 256$ 且是 $2$ 的正整数次幂。按 ABC 编码规则把它改写成只含 `A`、`B`、`C` 的符号串：

- 若整段**全是 `0`**，编码为 `A`；
- 若整段**全是 `1`**，编码为 `B`；
- 否则（既有 `0` 又有 `1`），编码为 `C`，后面接**左半段**的编码、再接**右半段**的编码。

题面用两张图给出规则，但规则本身是这道经典题的标准定义，上面三条就是它的全部内容。输入一行 $01$ 串，输出一行编码。

**第一步：先探规则的结构——它是"自相似"的。** 盯着第三条看：一个混合串的编码 = `C` + 左半编码 + 右半编码，而"左半编码""右半编码"又是**同一个问题**在更短串上的实例。这不是循环、不是递推数列，而是**分治递归**：把串劈成两半，分别解决，再拼起来。前两条（全 `0`→`A`、全 `1`→`B`）就是递归的**终止情形**——遇到"纯串"就不再往下劈。

**第二步：先做最小版本，确认终止。** 长度 $1$ 的串：`0` 全 `0` → `A`，`1` 全 `1` → `B`，都直接命中终止情形。长度 $2$：`00`→`A`、`11`→`B`、`01` 与 `10` 是混合 → `C` + 左半(`0`或`1`) + 右半 = `CAB` 或 `CBA`。到这里我确信：**只要串非空，递归一定能停**，因为每次劈半长度严格变小，最终落到长度 $1$ 的纯串。题目保证长度是 $2$ 的幂，所以"劈半"永远整除、两半等长，不会出现奇数长度劈不开的尴尬。

**第三步：会不会有更聪明的做法？** 我 briefly 想过"是不是要记忆化/DP"。但每个子串只会被它的父串调用一次（劈半得到的是**不重叠**的两段），没有重复子问题，记忆化毫无收益。也想过"能不能不递归、用栈模拟"——可以，但没必要：递归深度最多 $\log_2 256=8$ 层，栈空间微乎其微，直接写递归最清晰。**结论：这就是一道裸的分治递归题，不需要任何数据结构。**

**第四步：落地成代码的几个决定。**

1. **怎么判"纯串"？** 扫一遍 $[l,r)$，用两个布尔 `all0`、`all1`：遇到非 `0` 就把 `all0` 置假，遇到非 `1` 就把 `all1` 置假。扫完若 `all0` 真 → `A`，否则若 `all1` 真 → `B`，否则混合。注意长度 $1$ 时 `all0`、`all1` 恰有一个为真，不会误判。
2. **区间用半开 $[l,r)$。** 根调用 `sth(0,n)`，混合时 `mid=(l+r)>>1`，递归 `sth(l,mid)` 与 `sth(mid,r)`。半开区间让"两半不重不漏"一目了然，也避免 $\pm1$ 错误。
3. **输出边递归边追加。** 用一个全局 `string ans`，命中 `A`/`B` 就 `ans+=`，混合就先 `ans+='C'` 再递归左右——**先序遍历**的顺序恰好就是编码的拼接顺序（`C` 在前，左半编码居中，右半编码在后）。
4. **递归写法用自递归 lambda `sth`。** 这是本仓库的签名风格，`function<void(int,int)>sth{[&](int l,int r){...}}`，捕获 `s`、`ans` 与自身。

**手造数据核对**（题面只给规则图、没有样例输入输出，我按规则手算再用程序核对）：

| 输入 | 手算编码 | 程序输出 |
|---|---|---|
| `00000000` | 全 `0` → `A` | `A` |
| `11111111` | 全 `1` → `B` | `B` |
| `0011` | 混合 → `C`+enc(`00`)+enc(`11`)=`C`+`A`+`B` | `CAB` |
| `00001111` | 混合 → `C`+enc(`0000`)+enc(`1111`)=`C`+`A`+`B` | `CAB` |
| `01` | 混合 → `C`+`A`+`B` | `CAB` |
| `0101` | 混合 → `C`+enc(`01`)+enc(`01`)=`C`+`CAB`+`CAB` | `CCABCAB` |

最后一行最能体现递归：`0101` 的两半都是 `01`，各自又展开成 `CAB`，于是 `C`+`CAB`+`CAB`=`CCABCAB`。六组全部吻合。

## 二、思维链：完整证明

**记号。** 输入串 $s=s_0s_1\cdots s_{n-1}$，$n=2^k$（$k\ge0$，$n\le256$）。对半开区间 $[l,r)\subseteq[0,n)$，记子串 $s[l..r)=s_l\cdots s_{r-1}$，长度 $len=r-l$。定义编码函数 $E$：

$$E(s[l..r))=\begin{cases}\texttt{A},&\text{若 }s[l..r)\text{ 全为 }0\\ \texttt{B},&\text{若 }s[l..r)\text{ 全为 }1\\ \texttt{C}\,\Vert\,E(s[l..m))\,\Vert\,E(s[m..r)),&\text{否则}\end{cases}$$

其中 $m=\lfloor(l+r)/2\rfloor$，$\Vert$ 表示字符串拼接。程序用全局 `ans` 按先序追加字符实现 $E(s[0..n))$。

---

### 引理 1（"纯串"判定的正确性）

代码扫描 $[l,r)$ 后，`all0` 为真 $\iff$ 子串全为 `0`；`all1` 为真 $\iff$ 子串全为 `1`。且当 $len\ge1$ 时，`all0` 与 `all1` 不可能同时为真。

*证明*：`all0` 初值真，循环中"遇到 $s_i\ne$`0` 就置假"。故循环结束后 `all0` 为真 $\iff$ 不存在 $i\in[l,r)$ 使 $s_i\ne$`0` $\iff$ 所有 $s_i=$`0`。`all1` 同理。若两者同时为真，则所有 $s_i$ 既是 `0` 又是 `1`，矛盾（`0`$\ne$`1`）；当 $len\ge1$ 时至少有一个字符，故不可能同真。特别地 $len=1$ 时，该字符是 `0` 则 `all0` 真 `all1` 假，是 `1` 则反之，恰有一个为真。证毕。

**推论**：代码"先判 `all0` 输出 `A`，再判 `all1` 输出 `B`，否则混合"的三分支与定义 $E$ 的三分支逐字对应，且互斥不遗漏。

---

### 引理 2（劈半的整除性与不重不漏）

设 $len=r-l$ 是 $2$ 的幂且 $len\ge2$，$m=(l+r)>>1$。则 $m-l=r-m=len/2$，且 $[l,m)$ 与 $[m,r)$ 不交、并为 $[l,r)$，两半长度都是 $len/2$（仍是 $2$ 的幂）。

*证明*：$l+r=l+(l+len)=2l+len$。因 $len$ 是偶数（$len\ge2$ 且为 $2$ 的幂），$2l+len$ 是偶数，故 $m=(2l+len)/2=l+len/2$ 精确整除，无下取整误差。于是 $m-l=len/2$，$r-m=(l+len)-(l+len/2)=len/2$。两半 $[l,l+len/2)$ 与 $[l+len/2,l+len)$ 首尾相接、不重叠，并为 $[l,l+len)=[l,r)$。$len/2=2^{k-1}$ 仍是 $2$ 的幂。证毕。

**注**：题目保证 $n$ 是 $2$ 的幂，由本引理归纳可知递归中**每一层**的子串长度都是 $2$ 的幂，故"劈半"永远整除。即便不保证（一般串），$m=\lfloor(l+r)/2\rfloor$ 也能劈成两半（长度差至多 $1$），算法依然正确——$2$ 的幂只是让两半严格等长。

---

### 引理 3（递归良定义与终止性）

对任意非空子串 $s[l..r)$，$E(s[l..r))$ 是唯一确定的有限字符串，且递归在有限步内终止。

*证明*：对长度 $len$ 做**强归纳**。

**基例 $len=1$**：由引理 1，子串是纯串（全 `0` 或全 `1`），$E$ 直接返回 `A` 或 `B`，有限且唯一，不递归。

**归纳步 $len\ge2$**：假设对所有长度 $<len$ 的非空子串结论成立。若 $s[l..r)$ 纯，则 $E$ 返回单字符，成立。若混合，由引理 2 两半长度均为 $len/2<len$（因 $len\ge2$），且非空。由归纳假设 $E(s[l..m))$、$E(s[m..r))$ 都是唯一确定的有限串，故 $E(s[l..r))=\texttt{C}\Vert E(\text{左})\Vert E(\text{右})$ 也唯一确定且有限。递归调用的是更短的子串，长度严格递减且有下界 $1$，故有限步终止。证毕。

---

### 引理 4（先序追加 = 编码拼接）

程序对 `sth(l,r)` 的执行，恰好把 $E(s[l..r))$ 的字符**按顺序**追加到 `ans` 末尾。

*证明*：对 $len$ 强归纳。

$len=1$（或一般纯串）：代码 `ans+='A'`（或 `'B'`）后 `return`，追加的正是 $E=\texttt{A}$（或 `B`）。✓

混合串：代码先 `ans+='C'`，再 `sth(l,mid)`，再 `sth(mid,r)`。由归纳假设，`sth(l,mid)` 把 $E(\text{左})$ 按序追加，`sth(mid,r)` 把 $E(\text{右})$ 按序追加。三次追加的顺序是 `C`、$E(\text{左})$、$E(\text{右})$，拼接结果恰为 $\texttt{C}\Vert E(\text{左})\Vert E(\text{右})=E(s[l..r))$。✓

根调用 `sth(0,n)` 执行前 `ans` 为空，执行后 `ans`$=E(s[0..n))$，即整串编码。证毕。

**这条引理是"边递归边输出"合法性的核心**：它保证不需要先递归拿到子串再拼接（那样会反复拷贝字符串），直接往全局 `ans` 追加即可，顺序天然正确。

---

### 引理 5（复杂度）

设 $n\le256$。时间 $O(n\log n)$，空间 $O(n)$（输出串）$+O(\log n)$（递归栈）。

*证明*：把递归展开成一棵**劈分树**：每个混合串是一个内部节点（产生 `C` 并劈成两半），每个纯串是一个叶子（产生 `A`/`B`）。最坏情形是直到长度 $1$ 才出现纯串，此时树是满二叉树，叶子数 $n$，内部节点数 $n-1$，总节点数 $2n-1$，深度 $\log_2 n+1$。

每个节点执行一次"纯串判定"，扫描其子串，代价 $O(\text{子串长度})$。第 $d$ 层（根为 $d=0$）至多 $2^d$ 个节点，每个子串长度 $n/2^d$，故该层总扫描量 $\le 2^d\cdot(n/2^d)=n$。层数 $\le\log_2 n+1$，故总扫描量 $O(n\log n)$。追加字符总数 $=$ 编码长度 $\le 2n-1=O(n)$。合计时间 $O(n\log n)$。

代入 $n=256$：$256\times9\approx2304$ 次字符检查，瞬间完成。

空间：`ans` 长度 $\le2n-1=O(n)$；递归深度 $\le\log_2 n+1=O(\log n)$，每层栈帧常数大小。证毕。

---

### 定理

程序输出输入 $01$ 串的 ABC 编码，时间 $O(n\log n)$、空间 $O(n)$。

*证明*：引理 1 保证三分支判定与定义一致；引理 2 保证劈半整除、不重不漏；引理 3 保证递归良定义且终止；引理 4 保证先序追加得到的正是 $E(s[0..n))$；引理 5 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — ABC 规则第三条"混合 → C + 左半编码 + 右半编码"是自相似结构，前两条纯串是终止情形 ⇒ 天然分治递归。
- **consider easier version** — 先做长度 $1$、$2$ 的最小游戏：`0`→A、`1`→B、`01`→CAB，确认递归一定停（长度严格递减到纯串）。
- **reduce to easier problem** — 子串不重叠、无重复子问题 ⇒ 记忆化/DP 无收益；劈半递归就是最简形态，不需要任何数据结构。
- **classic problem solution** — 自递归 lambda `sth` 在半开区间 $[l,r)$ 上分治：判纯串输出 A/B，否则 `ans+='C'` 后递归左右两半。
- **explore its property** — 先序追加全局 `ans` 的顺序恰是 `C`+左+右的拼接顺序，省去子串返回与拷贝。
- **discuss by category** — 长度为 $2$ 的幂保证劈半整除；纯串判定用 `all0`/`all1` 双标志，长度 $1$ 时恰一为真。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `s` | 输入 $01$ 串 | `string`，读入 | 下标 $0..n-1$ |
| `n` | 串长，$2$ 的幂，$\le256$ | `int`，`s.size()` | 递归总区间 $[0,n)$ |
| `ans` | 编码结果，边递归边追加 | `string`，初值空 | 先序追加 = 拼接顺序 |
| `sth(l,r)` | 把 $E(s[l..r))$ 追加到 `ans` | 自递归 lambda | **半开区间 $[l,r)$** |
| `all0` | 当前子串是否全 `0` | `bool`，每次调用初值 `true` | 遇非 `0` 置假 |
| `all1` | 当前子串是否全 `1` | `bool`，每次调用初值 `true` | 遇非 `1` 置假 |
| `mid` | 劈半中点 $(l+r)>>1$ | `int` | 左 $[l,mid)$、右 $[mid,r)$ |
| `mxn` | 串缓冲尺寸 $256+5$ | `constexpr int{260}` | +5 松弛（本解用 `string`，常量留作习惯） |

### 算法步骤

1. I/O 加速三行。
2. 读入 `s`，`n=s.size()`。
3. 定义自递归 lambda `sth(l,r)`：
   1. 扫 $[l,r)$ 求 `all0`、`all1`（引理 1）；
   2. 若 `all0` → `ans+='A'`，返回；若 `all1` → `ans+='B'`，返回；
   3. 否则 `ans+='C'`，`mid=(l+r)>>1`，`sth(l,mid)`，`sth(mid,r)`（引理 2、4）。
4. 调用 `sth(0,n)`。
5. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(n\log n)$，$n=256$ 时约 $2300$ 次字符检查。
- 空间：$O(n)$ 输出串 $+O(\log n)$ 递归栈（深度 $\le9$）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面无样例输入输出，手造 $6$ 组（全 `0`、全 `1`、`0011`、`00001111`、`01`、`0101`）与按规则手算的编码逐字符吻合，覆盖纯串终止、混合劈半、双层递归三种情形。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2562 [AHOI2002] Kitty猫基因编码
// 思路：ABC 编码是分治递归——全 0→A，全 1→B，混合→C+左半编码+右半编码。
//       半开区间 [l,r)，先序往全局 ans 追加，顺序恰是 C+左+右。
//       长度是 2 的幂 ⇒ 劈半整除；单字符必为纯串 ⇒ 递归一定终止。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{260};

string s,ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	int n=s.size();
	function<void(int,int)>sth{[&](int l,int r){	// [l,r) 半开区间
		bool all0=true,all1=true;
		for(int i=l;i<r;++i)
		{
			if(s[i]!='0')all0=false;
			if(s[i]!='1')all1=false;
		}
		if(all0){ans+='A';return;}
		if(all1){ans+='B';return;}
		ans+='C';
		int mid=(l+r)>>1;
		sth(l,mid);
		sth(mid,r);
	}};
	sth(0,n);
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **三分支互斥**：`all0`、`all1` 由引理 1 保证不同时为真，故"先 A 再 B 否则 C"不会误判；长度 $1$ 的纯串直接命中 A/B，是递归的落点。
- **先序追加**：混合时先 `ans+='C'` 再递归左右，追加顺序天然是 `C`+左编码+右编码（引理 4），无需返回子串再拼接，省去反复拷贝。
- **半开区间**：`mid=(l+r)>>1`，左 $[l,mid)$、右 $[mid,r)$ 不重不漏；长度为 $2$ 的幂保证 `mid` 精确整除（引理 2）。
- **自递归 lambda `sth`**：`[&]` 捕获 `s`、`ans` 与自身，`std::function` 提供递归穿透；深度 $\le\log_2 256+1=9$，栈安全。
- `mxn{260}` 是 $+5$ 松弛的习惯常量；本解用 `string` 存串，无需手动开字符数组。
