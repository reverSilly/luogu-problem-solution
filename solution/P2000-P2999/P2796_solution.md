# P2796 Facer的程序 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 个程序（$N\le 10^5$），给出 $N-1$ 条"联系"，且任意两个程序之间**恰好存在一条**联系链——这等于明说：整张图是一棵**树**。要数出有多少个非空程序子集 $S$，使得 $S$ 内部也满足"任意两个程序恰好由一条链相连"，答案对 $10^9+7$ 取模。题面没有给样例输入输出，只给了样例解释：$3$ 个程序连成链时，合法子集是 $\{1\},\{2\},\{3\},\{1,2\},\{2,3\},\{1,2,3\}$ 共 $6$ 个。注意解释里**单点算、空集不算**（否则是 $7$ 个），这两个边界先记下来。

**第一步：把"S 也满足条件"翻译成人话。** 条件里的链 $a,x_1,\dots,x_n,b$ 必须全部由 $S$ 里的程序组成（否则"子程序块"就名不副实了）。在树里，$a,b$ 之间的简单路径**本来就唯一**，所以"恰好一条"的"至多一条"半边是自动成立的，真正有约束力的是"至少一条"：

$$S\text{ 合法}\iff \forall a,b\in S,\ a\to b\text{ 的树上路径整条落在 }S\text{ 里}\iff S\text{ 的诱导子图连通}.$$

（链默认不重复经过顶点——否则来回走就有无穷多条链，"恰好一条"无从谈起。）于是题目变成：**数树上非空连通子集的个数**。这是一个纯计数问题，和"链"的唯一性再无关系。

**第二步：先看简单版本找感觉。**

- **链（路径图）**：连通子集就是连续区间，共 $\frac{n(n+1)}2$ 个。$n=3$ 时 $6$ 个，和样例解释吻合——这确认了"单点算、空集不算"的读法。
- **菊花（星图）**：中心为 $c$，任何含 $c$ 的子集都连通（共 $2^{n-1}$ 个），不含 $c$ 的连通子集只有单点（$n-1$ 个）。$n=4$ 时 $8+3=11$ 个。

两个特例都暗示同一件事：**连通子集的结构由"最靠近某个根的点"决定**。链上它是区间左端点，菊花上它是中心。

**第三步：给树定根，按"最浅点"分类。** 任选根（比如 $0$ 号）。一个连通子集 $S$ 里深度最小的点——我叫它 $S$ 的**顶点**——是唯一的：如果有两个最浅点 $a,b$，它们之间的路径必须经过 $\mathrm{lca}(a,b)$，而 $\mathrm{lca}$ 的深度严格更小，路径又必须整条在 $S$ 里，矛盾。于是：

$$\text{答案}=\sum_{u}\bigl(\text{以 }u\text{ 为顶点的连通子集数}\bigr).$$

"以 $u$ 为顶点"意味着 $S$ 整个落在 $\mathrm{subtree}(u)$ 里（否则 $u$ 到某个外部点的路径会爬过 $u$ 的父亲，出现更浅的点）。所以只要定义

$$f[u]=\text{在 }\mathrm{subtree}(u)\text{ 内、包含 }u\text{ 的连通子集个数},$$

答案就是 $\sum_u f[u]$，每个子集恰好在自己的顶点处被数一次，**不重不漏**。

**第四步：$f[u]$ 的乘积转移。** $S$ 含 $u$ 且连通，那么对 $u$ 的每个孩子 $v$，$S$ 在 $\mathrm{subtree}(v)$ 里的部分只有两种可能：

- **空**：这个孩子子树一个点都不取；
- **一个包含 $v$ 的连通子集**：只要取了子树里任何一个点 $x$，$u\to x$ 的路径第一步就是 $u\to v$，所以 $v$ 必须被取；而取出来的部分自身也必须连通（两点间路径仍留在该子树内）。

反过来，各孩子子树里独立地选"空 / 含 $v$ 的连通块"，再并上 $\{u\}$，一定连通（任何两点都能借道 $u$ 相连）。这是一个**双射**，于是

$$\boxed{f[u]=\prod_{v\text{ 是 }u\text{ 的孩子}}\bigl(1+f[v]\bigr)}$$

那个 $+1$ 就是"这棵子树不取"的选项。叶子 $f=1$（只有 $\{u\}$ 自己）。这是最经典的树形计数 DP 之一。

**第五步：实现上的三个坑。**

1. **递归深度。** $N=10^5$ 的链会让递归 DFS 深度达到 $10^5$，Windows 默认栈下大概率爆栈。改用 **BFS 求出层序与父亲，再倒着扫层序**做 DP：处理 $u$ 时它的孩子一定已经算完。迭代写法零栈风险。
2. **取模与溢出。** $f$ 值模后 $<p=10^9+7$，乘积 $f[u]\cdot(f[v]+1)\le(p-1)\cdot p\approx10^{18}$，`long long` 装得下，`int` 装不下——乘法必须用 `i64`。
3. **空集与 $N=1$。** $f[u]$ 数的是"含 $u$"的子集，天然非空，空集自动被排除；$N=1$ 时没有边，$f[0]=1$，答案 $1$，代码无需特判。

**手造数据核对**（题面只有样例解释，我按解释反推链形输入，另造三组手算）：

| 输入 | 手算 | 程序 |
|---|---|---|
| $3$ 链：`1-2,2-3` | $6$（样例解释逐条列出） | $6$ ✓ |
| $4$ 菊花：中心 $1$ | $2^3+3=11$ | $11$ ✓ |
| $4$ 链 | $\frac{4\cdot5}2=10$ | $10$ ✓ |
| $5$ 树：`1-2,2-3,3-4,2-5` | 按大小枚举：$5$ 单点 $+4$ 边 $+4$ 三点 $+3$ 四点 $+1$ 五点 $=17$ | $17$ ✓ |
| $N=1$ | $1$ | $1$ ✓ |

其中 $5$ 树那组我逐个子集数过：三点连通块是 $\{1,2,3\},\{1,2,5\},\{2,3,5\},\{2,3,4\}$，四点连通块是 $\{1,2,3,4\},\{1,2,3,5\},\{2,3,4,5\}$（$\{1,2,4,5\}$ 里 $4$ 够不着，不连通）。DP 给出 $f=[7,6,2,1,1]$，和 $17$，与枚举一致。

## 二、思维链：完整证明

**记号。** 树 $T=(V,E)$，$|V|=N$，根为 $0$。$\mathrm{dep}(u)$ 为深度，$\mathrm{fa}(u)$ 为父亲，$\mathrm{subtree}(u)$ 为 $u$ 及其后代组成的点集。对点集 $S$，"诱导子图连通"指只保留两端都在 $S$ 中的边后图连通。$p=10^9+7$。树上任意两点 $a,b$ 间的简单路径记 $P(a,b)$，由树的定义它存在且唯一。

---

### 引理 0（路径封闭性：子树对路径封闭）

若 $x,y\in\mathrm{subtree}(v)$，则 $P(x,y)$ 上所有点都在 $\mathrm{subtree}(v)$ 内。

*证明*：$v$ 是 $x$ 与 $y$ 的公共祖先，故 $v$ 是 $\mathrm{lca}(x,y)$ 的祖先（$\mathrm{lca}$ 是**最深**公共祖先，$v$ 作为公共祖先必在其祖先链上），即 $\mathrm{lca}(x,y)\in\mathrm{subtree}(v)$。树上路径 $P(x,y)=P(x,\mathrm{lca})\cup P(\mathrm{lca},y)$。$P(x,\mathrm{lca})$ 上的点都是 $x$ 的祖先且是 $\mathrm{lca}$ 的后代；$\mathrm{lca}$ 是 $v$ 的后代，故这些点也都是 $v$ 的后代，属于 $\mathrm{subtree}(v)$。另一半同理。证毕。

这条引理后面要用两次（引理 1 的连通性、引理 3 的分解），先单独证掉。

---

### 引理 1（题意刻画：合法子集 = 非空连通子集）

非空子集 $S\subseteq V$ 满足题面条件（$S$ 内任意两程序恰好由一条 $S$ 内的链相连），当且仅当 $S$ 的诱导子图连通。空集按样例解释不计入。

*证明*：先明确"链"是顶点不重复的序列（若允许重复，任何有边的图里两点间都有无穷多条链，与题设"恰好一条"矛盾，故题意只能是简单路径）。

**唯一性半边自动成立**：$S$ 内的任何链都是 $T$ 中一条简单路径；$T$ 中 $a,b$ 间简单路径唯一，故 $S$ 内至多一条。于是题面条件等价于"存在性"：$\forall a,b\in S$，$P(a,b)\subseteq S$。

**（$\Rightarrow$）** 若 $\forall a,b\in S$ 有 $P(a,b)\subseteq S$，则 $P(a,b)$ 本身就是诱导子图里 $a$ 到 $b$ 的一条路径，故诱导子图连通。

**（$\Leftarrow$）** 若诱导子图连通，则存在一条完全在 $S$ 内的 $a\to b$ 路径 $Q$。$Q$ 也是 $T$ 中的简单路径，由唯一性 $Q=P(a,b)$，故 $P(a,b)\subseteq S$。

单点集 $\{u\}$：条件对 $a=b$ 平凡成立（长度为 $0$ 的链），诱导子图连通，合法——与样例解释计入 $\{1\},\{2\},\{3\}$ 一致。空集：逻辑上空真，但样例解释 $3$ 链答案为 $6$ 而非 $7$，说明出题人不计空集；本文按此处理（实现上 $f[u]$ 只数含 $u$ 的集合，天然排除空集）。证毕。

---

### 引理 2（顶点存在且唯一）

每个非空连通子集 $S$ 恰有一个深度最小的点，称为 $\mathrm{top}(S)$。

*证明*：存在性：$S$ 有限非空，深度取最小值必可达。唯一性：反设 $a,b\in S$，$a\ne b$，$\mathrm{dep}(a)=\mathrm{dep}(b)=\min_{x\in S}\mathrm{dep}(x)=d$。由引理 1，$P(a,b)\subseteq S$。树上 $P(a,b)$ 经过 $l=\mathrm{lca}(a,b)$。若 $a$ 是 $b$ 的祖先，则 $\mathrm{dep}(a)<\mathrm{dep}(b)$（$a\ne b$），与深度相等矛盾；故 $a,b$ 互不为祖先，$\mathrm{dep}(l)<\min(\mathrm{dep}(a),\mathrm{dep}(b))=d$。但 $l\in P(a,b)\subseteq S$，与 $d$ 是最小深度矛盾。证毕。

---

### 引理 3（分解引理：含 $u$ 的连通块按孩子子树独立分解）

固定 $u$，记 $\mathcal C(u)=\{S\subseteq\mathrm{subtree}(u):u\in S,\ S\text{ 诱导连通}\}$。对 $S\in\mathcal C(u)$ 与 $u$ 的每个孩子 $v$，令 $S_v=S\cap\mathrm{subtree}(v)$。则

$$S\in\mathcal C(u)\iff \text{对每个孩子 }v,\ S_v=\varnothing\ \text{或}\ S_v\in\mathcal C(v).$$

且映射 $S\mapsto(S_v)_v$ 是 $\mathcal C(u)$ 到 $\prod_v\bigl(\{\varnothing\}\cup\mathcal C(v)\bigr)$ 的**双射**，逆映射为 $(S_v)_v\mapsto\{u\}\cup\bigcup_v S_v$。

*证明*：

**（$\Rightarrow$）** 设 $S\in\mathcal C(u)$，$v$ 是孩子。若 $S_v\ne\varnothing$，取 $x\in S_v$。$P(u,x)\subseteq S$（引理 1）。$x$ 在 $v$ 的子树里而 $u$ 不在，故 $P(u,x)$ 的第一步是边 $u\to v$，于是 $v\in P(u,x)\subseteq S$，即 $v\in S_v$。再证 $S_v$ 连通：任取 $x,y\in S_v$，由引理 0，$P(x,y)\subseteq\mathrm{subtree}(v)$；又 $P(x,y)\subseteq S$，故 $P(x,y)\subseteq S_v$，由引理 1 的逻辑（路径都在集合内 ⇒ 连通）得 $S_v$ 连通。所以 $S_v\in\mathcal C(v)$。

**（$\Leftarrow$）** 设各 $S_v$ 为空或属于 $\mathcal C(v)$，令 $S=\{u\}\cup\bigcup_v S_v$。显然 $u\in S\subseteq\mathrm{subtree}(u)$。证连通：任取 $x,y\in S$。若 $x=u$ 或 $y=u$，设 $x\in S_v$，则 $v\in S_v$ 且 $S_v$ 连通给出 $S$ 内 $x\to v$ 的路径，再接边 $v\to u$。若 $x\in S_{v_1},y\in S_{v_2}$：$v_1=v_2$ 时由 $S_{v_1}$ 连通直接相连；$v_1\ne v_2$ 时走 $x\to v_1\to u\to v_2\to y$，各段都在 $S$ 内。故 $S$ 连通，$S\in\mathcal C(u)$。

**双射**：两个映射互逆是显然的集合运算（$\mathrm{subtree}(v)$ 两两不交、都不含 $u$，并集分解唯一）；上面两个方向恰好说明它们互相落在对方的定义域里。故为双射。证毕。

---

### 引理 4（乘积公式）

定义 $f[u]=|\mathcal C(u)|$（真实个数，未取模）。则

$$f[u]=\prod_{v\text{ 是 }u\text{ 的孩子}}\bigl(1+f[v]\bigr).$$

*证明*：对 $\mathrm{subtree}(u)$ 的大小归纳。叶子：没有孩子，$\mathcal C(u)=\{\{u\}\}$，$f[u]=1=$ 空积 ✓。一般地，由引理 3 的双射与乘法原理：

$$f[u]=\Bigl|\prod_v\bigl(\{\varnothing\}\cup\mathcal C(v)\bigr)\Bigr|=\prod_v\bigl(1+|\mathcal C(v)|\bigr)=\prod_v(1+f[v]),$$

其中 $|\mathcal C(v)|=f[v]$ 由归纳假设（孩子子树更小）保证定义一致。证毕。

**注**：$+1$ 对应"该孩子子树取空"，$f[v]$ 对应"取一个含 $v$ 的连通块"。各孩子之间**独立**——这是引理 3 双射的全部内容，也是"为什么可以直接乘"的根据。

---

### 引理 5（答案 = $\sum_u f[u]$，不重不漏）

记 $\mathcal A$ 为全体合法子集（引理 1 意义下）。则

$$|\mathcal A|=\sum_{u\in V}f[u].$$

*证明*：按 $\mathrm{top}(S)$（引理 2，存在唯一）把 $\mathcal A$ 划分成不交类 $\mathcal A_u=\{S\in\mathcal A:\mathrm{top}(S)=u\}$。证 $\mathcal A_u=\mathcal C(u)$：

**（$\subseteq$）** 设 $S\in\mathcal A_u$。先证 $S\subseteq\mathrm{subtree}(u)$：反设存在 $x\in S\setminus\mathrm{subtree}(u)$，则 $P(u,x)$ 从 $u$ 出发必须先爬到 $\mathrm{fa}(u)$（因为 $\mathrm{lca}(u,x)$ 是 $u$ 的真祖先），于是 $\mathrm{fa}(u)\in P(u,x)\subseteq S$，深度比 $u$ 小，与 $\mathrm{top}(S)=u$ 矛盾。故 $S\subseteq\mathrm{subtree}(u)$，又 $u\in S$、$S$ 连通，得 $S\in\mathcal C(u)$。

**（$\supseteq$）** 设 $S\in\mathcal C(u)$。$\mathrm{subtree}(u)$ 中所有点深度 $\ge\mathrm{dep}(u)$，而 $u\in S$，故 $u$ 是 $S$ 的最浅点，$\mathrm{top}(S)=u$，$S\in\mathcal A_u$。

于是 $|\mathcal A|=\sum_u|\mathcal A_u|=\sum_u f[u]$。每个 $S$ 恰属于一个类（顶点唯一），不重；每个类都被求和覆盖，不漏。证毕。

---

### 引理 6（取模合法性与溢出界）

把引理 4、5 中的所有加法、乘法换成模 $p$ 意义下的运算，最终结果等于 $|\mathcal A|\bmod p$；且每次乘法中间值 $\le(p-1)\cdot p<2^{63}-1$，`i64` 安全。

*证明*：模映射 $\varphi:\mathbb Z\to\mathbb Z_p$ 是环同态：$\varphi(a+b)=\varphi(a)+\varphi(b)$，$\varphi(ab)=\varphi(a)\varphi(b)$。$f[u]$ 与答案都是由 $1$ 出发经有限次加法、乘法得到的整数表达式，故逐项取模与最后取模结果相同（对表达式结构归纳即得）。

溢出界：归纳保持 $0\le f[u]<p$。$f[u]\cdot(f[v]+1)\le(p-1)\cdot p=10^{18}+6\times10^9+\dots$，精确地 $(10^9+6)(10^9+7)=10^{18}+13\times10^9+42<9.22\times10^{18}=2^{63}-1$ ✓。`ans+f[u]` $<2p$ 更是远小于上界。故全程 `i64` 无溢出；若用 `int`（$\approx2.1\times10^9$）则乘积必然溢出——这是本题最直接的实现陷阱。证毕。

---

### 引理 7（BFS 倒序的计算顺序正确）

以 $0$ 为根 BFS 得到序列 $\mathrm{ord}[0..N)$（$\mathrm{ord}[0]=0$，父亲先于孩子入队）。按 $i=N-1\dots0$ 处理 $u=\mathrm{ord}[i]$，执行 $f[u]\leftarrow f[u]\cdot(f[v]+1)\bmod p$（$v$ 遍历孩子）时，所有 $f[v]$ 已是最终值。

*证明*：BFS 的性质：$\mathrm{dep}$ 沿 $\mathrm{ord}$ 不减，且 $\mathrm{fa}(v)$ 在 $\mathrm{ord}$ 中的位置严格先于 $v$（孩子由父亲出队时才入队）。故倒序扫描时，$v$ 的位置在 $u=\mathrm{fa}(v)$ 之后 ⇒ 倒序中 $v$ 先被处理。对子树大小归纳：处理 $u$ 时其所有孩子 $v$ 已处理完，而 $v$ 处理完时 $f[v]$ 已乘入其全部孩子的贡献（归纳假设），即 $f[v]$ 为引理 4 的最终值。于是 $f[u]$ 按公式更新后也正确。最后 $\mathrm{ans}=\sum f[u]\bmod p$ 由引理 5、6 正确。

树无环，BFS 中用 `v!=fa[u]` 判重即可（每个点只会被其父亲入队一次：若 $v$ 已入队且不是 $u$ 的孩子关系，则树中存在环，矛盾），无需 `vis` 数组。证毕。

**为什么不用递归 DFS**：$N=10^5$ 的链使递归深度 $10^5$，每帧含迭代器/返回地址等数十字节，远超 Windows 默认 $1$ MB 栈，会栈溢出崩溃。BFS 倒序是纯迭代，零栈风险，复杂度相同。

---

### 引理 8（复杂度）

时间 $O(N)$，空间 $O(N)$。

*证明*：读入建图 $O(N)$；BFS 每点入队出队各一次、每条边被两端各扫一次，$O(N)$；DP 倒序扫描同样每条边被扫常数次，每次一个 `i64` 乘法取模 $O(1)$，共 $O(N)$。空间：邻接表 $2(N-1)$ 个 `int`、`fa/ord` 各 $N$、`f` 为 $N$ 个 `i64`，合计 $O(N)$，约 $4$ MB 量级。证毕。

---

### 定理

程序输出树上非空连通子集个数模 $10^9+7$，时间 $O(N)$，空间 $O(N)$。

*证明*：引理 1 把题意化为数非空连通子集；引理 2 给出按顶点划分；引理 3、4 给出 $f[u]$ 的乘积公式；引理 5 保证答案 $=\sum f[u]$ 不重不漏；引理 6 保证取模与 `i64` 安全；引理 7 保证 BFS 倒序求值正确；引理 8 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "任意两点恰好一条链"= 树；"$S$ 也满足条件"= 诱导子图连通（唯一性自动成立，存在性才是约束）。
- **consider easier version** — 链上连通子集 = 区间 $n(n+1)/2$；菊花上 = 含中心的任意子集 + 单点；两者都指向"按最浅点分类"。
- **explore its property** — 定根后每个连通子集有唯一最浅点（反证：两个最浅点的路径经过更浅的 lca）。
- **reduce to easier problem** — 按最浅点划分 ⇒ 只需数"子树内包含 $u$ 的连通块"$f[u]$，答案 $\sum f[u]$。
- **classic problem solution** — 树形计数 DP 乘积公式 $f[u]=\prod(1+f[v])$：每个孩子子树独立选"不取 / 取含 $v$ 的连通块"，双射 + 乘法原理。
- **discuss by category** — 实现边界：$10^5$ 深链用 BFS 倒序代替递归防爆栈；乘法必须 `i64`；$f$ 天然排除空集；$N=1$ 无需特判。

| `graph[u]` | 邻接表 | `vector<int>[mxn]` | 读入 `--u;--v`，双向加边 |
| `fa[u]` | 以 $0$ 为根的父亲 | `int[mxn]` | `fa[0]=-1`，其余 BFS 时赋值 |
| `ord[i]` | BFS 层序第 $i$ 个点 | `int[mxn]` | `ord[0]=0`；父亲先于孩子 |
| `f[u]` | 子树内**含 $u$** 的连通子集数 $\bmod p$ | `i64[mxn]`，全置 $1$ | 初值 $1$ = 只有 $\{u\}$；"$+1$ = 不取该子树" |
| `ans` | $\sum_u f[u]\bmod p$ | `i64`，初值 $0$ | 每个子集在唯一最浅点处计数 |
| `p` | $1\,000\,000\,007$ | `constexpr i64` | 乘积 $\le(p-1)p<2^{63}$，必须 `i64` |
| `mxn` | $100000+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 $n$ 与 $n-1$ 条边，`--u;--v` 后双向建 `graph`。
3. BFS：`fa[0]=-1`，`ord` 当队列用（`head/tail` 双指针）；出队 $u$ 时把满足 `v!=fa[u]` 的邻居 $v$ 入队并令 `fa[v]=u`（树无环，此判重足够）。
4. `f[0..n)` 全置 $1$。
5. 倒序 `i=n-1..0`：取 `u=ord[i]`，对每个孩子 `v` 执行 `f[u]=f[u]*(f[v]+1)%p`；然后 `ans=(ans+f[u])%p`。
6. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(n)$，$n=10^5$ 时实测 $0.07$ s 量级。
- 空间：$O(n)$，邻接表 + 三个 `int` 数组 + 一个 `i64` 数组，约 $4$ MB。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过；$3$ 链 $=6$ 与题面样例解释逐条吻合；$4$ 菊花 $=11$、$5$ 菊花 $=20$、$4$ 链 $=10$、$5$ 节点树 $=17$（逐子集手工枚举核对）、$N=1=1$ 全对；$10^5$ 深链输出 $49965=\frac{n(n+1)}2\bmod p$，与闭式一致且无爆栈。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2796 Facer的程序
// 题意 = 数树上非空连通子集（mod 1e9+7）
// 定根后每个连通子集有唯一最浅点 ⇒ 答案 = sum f[u]
// f[u] = prod(1+f[v])：每个孩子子树「不取 / 取含 v 的连通块」，双射 + 乘法原理
// BFS 层序倒推，避免 1e5 深链递归爆栈
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};
constexpr i64 p{1'000'000'007};

int n,fa[mxn],ord[mxn];
i64 f[mxn],ans;
vector<int>graph[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1,u,v;i<n;++i)
	{
		cin>>u>>v;--u;--v;
		graph[u].push_back(v);
		graph[v].push_back(u);
	}
	// BFS 求出以 0 为根的父节点与层序
	fa[0]=-1;
	int head=0,tail=0;
	ord[tail++]=0;
	while(head<tail)
	{
		int u=ord[head++];
		for(int v:graph[u])
			if(v!=fa[u])
			{
				fa[v]=u;
				ord[tail++]=v;
			}
	}
	for(int i=0;i<n;++i)
		f[i]=1;
	for(int i=n-1;i>=0;--i)	// 倒层序：处理 u 时其子树已全部算完
	{
		int u=ord[i];
		for(int v:graph[u])
			if(v!=fa[u])
				f[u]=f[u]*(f[v]+1)%p;	// 每个孩子子树：不取 / 取含 v 的连通块
		ans=(ans+f[u])%p;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`f` 用 `i64`**：`f[u]*(f[v]+1)` 最大约 $10^{18}$，`int` 必炸；`ans` 同理。这是本题唯一的数值陷阱。
- **BFS 判重只靠 `v!=fa[u]`**：树无环，每个点只会被父亲入队一次，不需要 `vis`。`fa[0]=-1` 是"根无父亲"的哨兵：树无自环，根的邻居编号都 $\ne0$，所以即使误留全局默认 `fa[0]=0` 也碰巧不出错，但 $-1$ 让"根没有父亲"的语义显式成立，不依赖巧合。
- **倒序扫描时 `f[v]` 已是终值**：BFS 保证父亲先于孩子入队，倒序则孩子先于父亲被处理（引理 7）。`f` 初值全 $1$ 对应"只含自己"，乘入每个孩子时该孩子的贡献已完整。
- **空集自动排除**：每个 $f[u]$ 数的集合都含 $u$，非空；答案对 $u$ 求和时每个连通子集恰在其最浅点被数一次。
- **$N=1$**：没有边，BFS 只入队根，`f[0]=1`，输出 $1$，无需特判。
