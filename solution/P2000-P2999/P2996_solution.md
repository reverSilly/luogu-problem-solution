# P2996 [USACO10NOV] Visiting Cows G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 给一棵 $N$ 个点的树（$1\le N\le 50000$，$N-1$ 条边，任意两点间通路唯一——这就是树的定义）。要选出一个尽量大的点集，使得**任何一条边的两个端点不能同时被选**。输出这个点集的最大大小。这正是图论里的经典对象：**最大独立集**。

一般图的最大独立集是 NP-hard 的，但树上有 $O(N)$ 的动态规划——这是本题的题眼。约束 $N\le 5\times10^4$ 也暗示了线性或线性对数算法。

**边界先抠清楚：**

- $N=1$：没有边，直接拜访这头牛，答案 $1$。
- 输入编号 $1..N$，内部转 0-based。
- 树可能退化成一条链（深度 $5\times10^4$）——这对实现方式有实质影响，后面会讲。

**第一步：试探贪心。** 独立集问题第一反应往往是各种贪心，我试了两个：

1. **"隔层选"（按深度奇偶二染色，取较大的一类）**。二染色的每一类都是独立集，所以答案至少是 $\max(|黑|,|白|)$。但它不一定最优。反例：**双星树**——两个中心 $c_1,c_2$ 相邻，各挂 $3$ 片叶子。二染色把 $c_1$ 与 $c_2$ 的叶子染同色，两类大小都是 $1+3=4$；而**全选 $6$ 片叶子**是合法独立集，大小 $6>4$。贪心失败，且失败模式很清楚：最优解在树的不同分支里**混用了两种颜色**，全局二染色强迫所有分支同相位，做不到。
2. **"一次选完所有叶子"**。叶子互不相邻（$N\ge3$ 时），看似安全。反例：链 $1-2-3-4$，叶子 $\{1,4\}$；删掉它们和邻居后剩 $2-3$ 一条边，再选 $2$——但 $2$ 与已选的 $1$ 相邻，非法。若改成"选叶子→删叶子及其邻居→重复"的**迭代**版本，其实可以证明是对的（叶子贪心），但证明并不比 DP 短，而且实现要维护度数与队列，得不偿失。

贪心碰壁的共性：**选不选一个点，影响的是它的邻居，而邻居的邻居又反过来影响邻居**——这种局部耦合恰好是树形 DP 的舒适区：把"父亲选/不选"作为状态传给子树，子树内部就解耦了。

**第二步：定状态。** 任选根（取 $0$ 号点）。设 $dp[u][0]$ = 在 $u$ 的子树内、**不选 $u$** 时的最大独立集大小；$dp[u][1]$ = **选 $u$** 时的最大独立集大小。转移：

$$dp[u][1]=1+\sum_{v\in son(u)}dp[v][0],\qquad dp[u][0]=\sum_{v\in son(u)}\max(dp[v][0],dp[v][1]).$$

理由：选了 $u$，每个儿子都被边 $(u,v)$ 禁止；不选 $u$，每个儿子自由选择。不同儿子的子树之间**没有边**（树！），所以各自的最优可以直接相加。答案 $=\max(dp[root][0],dp[root][1])$。

**第三步：实现方式——递归还是迭代？** 教科书代码是一个 DFS。但链状数据下递归深度 $5\times10^4$，在栈空间紧张的评测环境有爆栈风险。注意到转移只依赖"儿子先算完"，而 **BFS 序的逆序**天然满足这一点（BFS 中父亲一定先于儿子入队）。于是：先一遍 BFS 求出父亲数组 `par` 与访问序 `ord`，再倒着扫 `ord` 递推。零递归，栈安全，复杂度不变。

**手造数据核对。**

第一组，题面 Hint 里的图（边 $1-2,2-3,3-4,2-6,6-5,6-7$）：

```
输入：            7
                  1 2 / 2 3 / 3 4 / 2 6 / 6 5 / 6 7
```

以 $2$ 为根看：儿子 $1$（叶）、$3$（带叶 $4$）、$6$（带叶 $5,7$）。$dp[1]=(0,1)$，$dp[4]=dp[5]=dp[7]=(0,1)$；$dp[3]=(1,1)$，$dp[6]=(2,1)$；$dp[2][1]=1+0+1+2=4$，$dp[2][0]=1+1+2=4$。答案 $4$，与题面"Bessie 能拜访 4 头奶牛"一致（例如 $\{1,4,5,7\}$）。

第二组，专打贪心反例的双星树（$N=8$：中心 $1-2$ 相邻，$1$ 挂叶 $3,4,5$，$2$ 挂叶 $6,7,8$）：答案应为 $6$（全选叶子）。DP：$dp[1][1]=1+dp[2][0]=1+3=4$，$dp[1][0]=\max(dp[2])+\sum\max(叶)=3+3=6$ ✓。

第三组，$N=1$：无边，$dp[0]=(0,1)$，答案 $1$ ✓。

## 二、思维链：完整证明

**记号。** 树 $T=(V,E)$，$|V|=N$。以 $0$ 为根，$son(u)$ 为儿子集合，$T_u$ 为 $u$ 的子树（点集）。独立集：$S\subseteq V$ 且 $\forall (a,b)\in E,\ \{a,b\}\not\subseteq S$。$\alpha(U)$ 表示导出子图 $T[U]$ 的最大独立集大小。$dp$ 定义如上。

---

### 引理 1（贪心下界与它的失败：为什么必须 DP）

二染色两类各自是独立集，故 $\alpha(V)\ge\max(|黑|,|白|)$；但存在树使不等号严格。

*证明*：树是二分图（无奇环），二染色合法：每条边两端异色，故同色类内无边，是独立集，下界成立。反例双星树：中心 $c_1,c_2$ 相邻必异色，设 $c_1$ 黑。$c_1$ 的 $3$ 片叶子全白，$c_2$ 的 $3$ 片叶子全黑。$|黑|=|\{c_1\}\cup leaves(c_2)|=4$，$|白|=4$。而 $leaves(c_1)\cup leaves(c_2)$ 共 $6$ 点：叶子只与自己的中心相邻，中心都不在集合里，故独立，$\alpha\ge6>4$。证毕。

这条引理说明"全局相位一致"的方案类不够大，必须允许每个分支独立决定选法——这正是 DP 状态里"选/不选"逐点分支的意义。

---

### 引理 2（子树解耦：跨子树无边）

设 $v_1\ne v_2$ 是 $u$ 的两个儿子。则 $T_{v_1}$ 与 $T_{v_2}$ 的点集不交，且**不存在**一端在 $T_{v_1}$、另一端在 $T_{v_2}$ 的边。进一步，$T_u$ 中所有边恰为：$\{(u,v):v\in son(u)\}$ 与各 $T_v$ 内部的边。

*证明*：不交性：若 $x\in T_{v_1}\cap T_{v_2}$，则根到 $x$ 的树上路径既经过 $v_1$ 又经过 $v_2$；但树上路径唯一，且 $v_1,v_2$ 互不为祖先（同为 $u$ 的儿子），矛盾。跨子树无边：若存在边 $(a,b)$，$a\in T_{v_1},b\in T_{v_2}$，则根$\to v_1\to a\to b\to v_2\to u\to$根 构成一个环（各段拼接，$a\ne b$ 且两子树不交保证不退化），与树无环矛盾。边的分类：$T_u$ 内任一边 $(a,b)$，若 $a=u$ 则 $b$ 必为儿子（父亲不在 $T_u$ 内）；否则 $a,b$ 同属某个 $T_v$（若分属两个儿子子树则违反刚才的结论；若其一为 $u$ 已讨论）。证毕。

**推论**：给定"选/不选 $u$"后，各儿子子树内的选择**互相独立**，约束只剩边 $(u,v)$。

---

### 引理 3（转移的正确性）

对每个点 $u$：
$$dp[u][1]=1+\sum_{v\in son(u)}dp[v][0],\qquad dp[u][0]=\sum_{v\in son(u)}\max(dp[v][0],dp[v][1]),$$
其中 $dp[u][1]$ 是 $T_u$ 内**含 $u$** 的最大独立集大小，$dp[u][0]$ 是**不含 $u$** 的最大独立集大小。

*证明*：对子树高度归纳。

**基**：$u$ 是叶子，$son(u)=\varnothing$。含 $u$ 的最优是 $\{u\}$，大小 $1=1+0$ ✓；不含 $u$ 的只能是 $\varnothing$，大小 $0$ ✓。

**归纳**：设所有儿子的 $dp$ 正确。

先证 $dp[u][1]$。设 $S$ 是 $T_u$ 内含 $u$ 的任一独立集。对每个儿子 $v$：边 $(u,v)$ 迫使 $v\notin S$，故 $S\cap T_v$ 是 $T_v$ 内不含 $v$ 的独立集，$|S\cap T_v|\le dp[v][0]$（归纳假设）。由引理 2 的分拆，$|S|=1+\sum_v|S\cap T_v|\le 1+\sum_v dp[v][0]$。反向构造：对每个 $v$ 取达到 $dp[v][0]$ 的不含 $v$ 的独立集 $S_v$，令 $S=\{u\}\cup\bigcup_v S_v$。合法性逐边检查：$(u,v)$ 边——$v\notin S_v$ ✓；$T_v$ 内部边——$S_v$ 独立 ✓；无其他边（引理 2）✓。故上界可达，$dp[u][1]$ 公式成立。

再证 $dp[u][0]$。不含 $u$ 的独立集 $S$ 在每个 $T_v$ 上的限制是 $T_v$ 的任意独立集（$v$ 选不选都行，因为 $u\notin S$，边 $(u,v)$ 自动满足），故 $|S|\le\sum_v\max(dp[v][0],dp[v][1])$。反向：各 $T_v$ 取各自最优（含 $v$ 或不含 $v$ 中较大者），并起来仍独立（跨子树无边、$u$ 不在集合中）。上界可达 ✓。证毕。

---

### 引理 4（根上取 max 即全局答案）

$\alpha(V)=\max(dp[0][0],dp[0][1])$。

*证明*：$T_0=V$（根的子树是全树）。任何独立集要么含根要么不含根，两类的最优分别是 $dp[0][1]$ 与 $dp[0][0]$（引理 3），全体最优是两类较大者。证毕。

---

### 引理 5（BFS 逆序是合法的递推顺序）

设 `ord[0..N-1]` 是从根出发的 BFS 访问序，`par[u]` 是 BFS 树上的父亲。则 (a) `par` 就是原树的父亲关系；(b) 对每个非根 $u$，`par[u]` 在 `ord` 中的位置严格靠前；(c) 倒序扫描 `ord` 时，每个点的所有儿子都已递推完毕。

*证明*：(a) BFS 中 `v` 经由边 `(u,v)` 首次入队时置 `par[v]=u`。树上根到 `v` 的路径唯一，BFS 沿最短路扩展，首次到达 `v` 的前驱必是这条唯一路径上 `v` 的父亲（任何别的邻居要么更深要么就是儿子，儿子不可能先于 `v` 出队——它们只能经 `v` 或更深处到达，而那条路更长）。严格地说：若 `par[v]=w` 不是树父亲，则根$\to w$ 的 BFS 路径加边 $(w,v)$ 给出另一条根到 $v$ 的路径，与树路径唯一矛盾（BFS 路径是图中真实路径）。

(b) `par[u]` 出队时 `u` 才入队，入队序即 `ord`，故父亲位置靠前。

(c) 由 (b)，儿子在 `ord` 中位置严格靠后；倒序扫描时位置靠后的先处理，故处理 $u$ 时其全部儿子的 $dp$ 已就绪。又 `dp[u]` 只读儿子的 `dp`（引理 3），无其他依赖。证毕。

**实现注意**：全局 `dp` 默认 $0$，而本题 $dp$ 是**计数**而非距离，$0$ 恰好是"空集"的合法值；转移用 `+=` 从 $0$ 累加、`dp[u][1]=1` 显式置底，所以**不需要**填 INF——这与最短路类问题相反，务必分清。

---

### 引理 6（复杂度）

时间 $O(N)$，空间 $O(N)$。

*证明*：读入 $O(N)$。BFS：每点入队一次，每条边被两个端点各扫一次，$O(N)$。递推：同样每条边贡献常数次加法/取 max，$O(N)$。空间：邻接表 $2(N-1)$ 个 `int`，`dp` $2N$、`par`/`ord` 各 $N$ 个 `int`，均 $O(N)$；无递归栈。$N=5\times10^4$ 时总操作数约 $10^6$ 量级，远低于时限。证毕。

---

### 定理

程序输出树的最大独立集大小，时间 $O(N)$，且对链状数据无爆栈风险。

*证明*：引理 1 说明贪心不足、需要逐点分支的 DP；引理 2 给出子树解耦这一 DP 可行性的结构基础；引理 3 归纳证明两条转移；引理 4 把子树答案拼成全树答案；引理 5 保证迭代实现（BFS 逆序）与递归版计算完全相同的值；引理 6 给出复杂度与栈安全。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "每条边两端至多选一个" = 独立集；"通路唯一" = 树。一般图 NP-hard，树上多项式可解。
2. **consider easier version** — 试贪心：二染色取大类（双星树反例 $4<6$）、一次选完叶子（链 $1-2-3-4$ 反例），确认贪心相位/顺序不够灵活。
3. **reduce to easier problem** — 贪心失败模式 = 分支间需要独立决策 ⇒ 以"选/不选 $u$"为状态把耦合切断，归约为树形 DP。
4. **classic problem solution** — 树上最大独立集（"没有上司的舞会"模型）：$dp[u][1]=1+\sum dp[v][0]$，$dp[u][0]=\sum\max(dp[v][0],dp[v][1])$。
5. **classic problem solution** — 用 BFS 序 + 逆序递推替代递归 DFS，儿子先于父亲被计算，链深 $5\times10^4$ 也零爆栈风险。
6. **discuss by category** — $N=1$ 无边直接答案 $1$；`dp` 是计数数组，全局零初始化恰好合法，不需要 INF。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 点数 $N\le5\times10^4$ | `int` | 读入 |
| `graph[u]` | 无向邻接表 | `vector<int>[mxn]` | 读入建双向边 |
| `par[u]` | BFS 树父亲（= 原树父亲） | `int[mxn]` | `par[0]=-1`，其余入队时赋值 |
| `ord[i]` | BFS 访问序第 $i$ 个点 | `int[mxn]` | `ord[0]=0`（根） |
| `dp[u][0]` | $T_u$ 内**不选** $u$ 的最大独立集 | `int[mxn][2]` | 全局默认 $0$，倒序扫描时累加 |
| `dp[u][1]` | $T_u$ 内**选** $u$ 的最大独立集 | 同上 | 处理 $u$ 时先置 $1$（$u$ 自己） |
| `mxn` | $50000+5$ | `constexpr int` | 数组尺寸 |

记忆点：**0 = 不选、1 = 选**；选了父亲儿子只能取 $0$，不选父亲儿子取 $\max$。

### 算法步骤

1. I/O 加速三行；读 $N$ 与 $N-1$ 条边（`--u;--v`），建无向邻接表。
2. 从 $0$ 号点 BFS（用 `ord` 数组本身当队列）：填 `par` 与 `ord`。
3. 倒序 `i=N-1..0`，令 `u=ord[i]`：`dp[u][1]=1`；对每个 `v!=par[u]` 的邻居：`dp[u][0]+=max(dp[v][0],dp[v][1])`，`dp[u][1]+=dp[v][0]`。
4. 输出 `max(dp[0][0],dp[0][1])`。

### 复杂度

- 时间 $O(N)$；空间 $O(N)$（邻接表 + 四个 $O(N)$ 数组），无递归栈。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面 Hint 图手算答案 $4$ 吻合；双星树（$6$）、单点（$1$）、链 $1-2-3-4$（$2$）等手造数据全部正确。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2996 [USACO10NOV] Visiting Cows G
// 树上最大独立集：dp[u][0/1] = 不选/选 u 时子树内最多拜访数
// 链状数据深度可达 5e4，用 BFS 序倒序递推代替递归，杜绝爆栈
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005};

int n,dp[mxn][2],par[mxn],ord[mxn];
vector<int>graph[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1,u,v;i<n;++i)
	{
		cin>>u>>v;--u;--v;
		graph[u].push_back(v);
		graph[v].push_back(u);
	}
	int tail=0;
	ord[tail++]=0;par[0]=-1;
	for(int head=0;head<tail;++head)	// ord 数组本身当 BFS 队列
	{
		int u=ord[head];
		for(int v:graph[u])
			if(v!=par[u])
			{
				par[v]=u;
				ord[tail++]=v;
			}
	}
	for(int i=n-1;i>=0;--i)	// 逆 BFS 序：儿子一定先于父亲被递推
	{
		int u=ord[i];
		dp[u][1]=1;	// dp 是计数不是距离，全局 0 初值恰好合法
		for(int v:graph[u])
			if(v!=par[u])
			{
				dp[u][0]+=max(dp[v][0],dp[v][1]);
				dp[u][1]+=dp[v][0];
			}
	}
	cout<<max(dp[0][0],dp[0][1])<<'\n';
	return 0;
}
```

### 代码说明

- **状态语义**：第二维 $0$=不选、$1$=选。选 $u$ 时儿子全被迫取 $0$；不选 $u$ 时儿子各取 $\max$。跨子树无边（引理 2）是"直接求和"的合法性来源。
- **BFS 队列复用 `ord`**：`head<tail` 即队列非空；树上 `v!=par[u]` 足以防止回头，不需要 `vis` 数组。
- **倒序递推**（引理 5）：父亲在 `ord` 中位置靠前 ⇒ 倒序时儿子先算完。等价于递归 DFS 的后序，但零栈深度。
- `dp[u][1]=1` 必须在累加前显式赋值；`dp[u][0]` 依赖全局零初值（计数语义下 $0$ 合法，**不要**画蛇添足填 INF）。
- $N=1$ 时读边循环不执行，BFS 只含根，`dp[0]=(0,1)`，输出 $1$，边界自动覆盖。
