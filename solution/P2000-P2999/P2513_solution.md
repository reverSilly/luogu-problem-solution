# P2513 [HAOI2009] 逆序对数列 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 求 $1\sim n$ 的排列中**恰好有 $k$ 个逆序对**的排列个数，答案对 $10000$ 取模。$n,k\le 1000$。题面样例说明给出：$n=4,k=1$ 时答案为 $3$（$\{1,2,4,3\},\{1,3,2,4\},\{2,1,3,4\}$），可反推样例输入 `4 1`、输出 `3`。

**第一反应：暴力枚举排列。** $n!$ 增长极快，$n=1000$ 时天文数字，不可行。但注意子任务"30% 的数据 $n\le 12$"——$12!\approx 4.8\times 10^8$，枚举已经吃力；这个子任务在暗示：**正解是与 $n!$ 无关的多项式算法**，几乎必然是 DP。

**第二步：找增量结构——排列怎么"长大"？** 直接对"前 $i$ 个位置填什么"做 DP 很难，因为逆序对依赖具体数值的大小关系，状态要记"用过哪些数"，指数级。换一个生长方式：**不按位置生长，按数值生长**——把最大元素 $i$ **插入**一个 $1..i-1$ 的排列里。

关键观察：$i$ 比所有已有元素都大，所以
- 不含 $i$ 的数对，相对顺序在插入前后**完全不变**，旧逆序对原样保留；
- 含 $i$ 的数对 $(i,x)$ 是逆序对 $\iff$ $x$ 排在 $i$ **后面**。

于是：**把 $i$ 插到"后面恰好有 $t$ 个元素"的位置，新增逆序对恰好 $t$ 个**，$t$ 可以取 $0,1,\dots,i-1$（插最末 $t=0$，插最前 $t=i-1$），每个位置对应唯一的 $t$。这个对应还是**双射**：任何长度 $i$ 的排列，删掉 $i$ 就唯一还原出"长度 $i-1$ 的排列 + 插入位置"。

**第三步：列出 DP。** 设 $f[i][j]$ = 长度 $i$、恰好 $j$ 个逆序对的排列数。按"最大元素 $i$ 后面有几个元素"分类：

$$f[i][j]=\sum_{t=0}^{\min(j,\,i-1)}f[i-1][j-t].$$

边界 $f[0][0]=1$（空排列，$0$ 个逆序对），$f[0][j>0]=0$。复杂度 $O(n^2k)$：$n=k=1000$ 时约 $\frac{1}{2}n^2k=5\times10^8$ 次加法——说实话 C++ 未必超时，但式子里那个"上一行的一段连续区间求和"太扎眼了，**必须优化**。

**第四步：认出滑动窗口。** 把求和变量换元 $s=j-t$：

$$f[i][j]=\sum_{s=\max(0,\,j-i+1)}^{j}f[i-1][s].$$

这是上一行 $f[i-1][\cdot]$ 上一个**右端点为 $j$、宽度至多 $i$ 的窗口和**。$j$ 增加 $1$ 时，窗口右端进一个 $f[i-1][j]$，左端出一个 $f[i-1][j-i]$（仅当 $j\ge i$，否则左端还卡在 $0$ 出不去）。于是：

$$\boxed{f[i][j]=f[i][j-1]+f[i-1][j]-[j\ge i]\cdot f[i-1][j-i]}$$

每个状态 $O(1)$，总复杂度 $O(nk)=10^6$，轻松通过。这就是"前缀和"标签的由来：滑动窗口和 = 两个前缀和之差，这里直接写成了差分递推。

**第五步：取模的坑——减法会出负数。** 模数 $10000$ 不是质数，但本题只有加减、没有除法，不需要逆元，逐项取模完全合法。唯一陷阱：$f[i][j-1]+f[i-1][j]-f[i-1][j-i]$ 可能为负（例如 $f[i][j-1]=0,f[i-1][j]=0,f[i-1][j-i]=1$），C++ 的 `%` 对负数返回负余数，必须写 `(x%p+p)%p`。中间量范围 $[-9999,19998]$，`int` 安全。

**第六步：边界自查。**
- $k=0$：只有升序排列，答案应为 $1$。递推里 $f[i][0]=f[i-1][0]=\dots=f[0][0]=1$ ✓。
- $k>\frac{n(n-1)}2$（逆序对上限，倒序排列达到）：答案应为 $0$，DP 自动给出（引理 7）。
- $n=1$：$f[1][0]=1$，$f[1][j\ge1]=0$ ✓。
- **行和不变量**：$\sum_j f[i][j]=i!$（每个排列恰好被数一次）。这是免费的对拍器：手算 $n=5$ 一行，看是否加出 $120$。

**手造数据核对**（程序输出全部吻合）：

| 输入 | 期望 | 依据 |
|---|---|---|
| `4 1` | $3$ | 题面样例说明 |
| `3 0/1/2/3/4` | $1,2,2,1,0$ | 手工枚举 $6$ 个排列：123(0),132(1),213(1),231(2),312(2),321(3) |
| `4 2` | $5$ | 1342,1423,2143,2314,3124 |
| `4 3` / `4 6` / `4 7` | $6$ / $1$ / $0$ | 分布 $1,3,5,6,5,3,1$，和 $=24=4!$ |
| `5 0..10` | $1,4,9,15,20,22,20,15,9,4,1$ | 行和 $=120=5!$ ✓ |
| `1 0` / `1 1` | $1$ / $0$ | 只有一个排列 |
| `1000 0` | $1$ | 升序唯一 |
| `1000 1000` | $3760$ | 极限规模，$0.08$ s |

$n=4,5$ 的整行与组合数学中著名的 Mahonian 数（逆序对分布）一致，行和恰为 $n!$，递推的加减两支（尤其 $j\ge i$ 的减法支，从 $f[4][4]=f[4][3]+f[3][4]-f[3][0]=6+0-1=5$ 开始被触发）都被覆盖。

## 二、思维链：完整证明

**记号。** $[n]=\{1,\dots,n\}$，$S_n$ 为其全体排列。对 $\pi\in S_n$，$\mathrm{inv}(\pi)=\#\{(p,q):p<q,\pi_p>\pi_q\}$。$f[i][j]$ 定义为 $\#\{\pi\in S_i:\mathrm{inv}(\pi)=j\}$（$i\ge 0$，$S_0$ 只含空排列）。模数 $p=10000$。约定 $f[i][j]=0$ 当 $j<0$。

---

### 引理 1（插入映射是双射）

固定 $i\ge 1$。定义映射
$$\Phi:S_{i-1}\times\{0,1,\dots,i-1\}\to S_i,\qquad \Phi(\pi,t)=\text{把 }i\text{ 插入 }\pi\text{ 使其后恰有 }t\text{ 个元素}.$$
则 $\Phi$ 是双射，其逆为"删去元素 $i$，记 $t$ 为 $i$ 后面的元素个数"。

*证明*：**良定义**：长度 $i-1$ 的序列有 $i$ 个可插空隙（首前、元素间、尾后），从尾往前数第 $t$ 个空隙后面恰有 $t$ 个元素，$t\in[0,i-1]$ 各对应唯一空隙；插入后是 $1..i$ 的排列。

**单射**：设 $\Phi(\pi,t)=\Phi(\pi',t')=\sigma$。$\sigma$ 中元素 $i$ 的位置唯一，其后元素个数唯一，故 $t=t'$；删去 $i$ 后剩余序列唯一，故 $\pi=\pi'$。

**满射**：任取 $\sigma\in S_i$，删去 $i$ 得 $\pi\in S_{i-1}$，设 $i$ 后有 $t$ 个元素，则 $t\in[0,i-1]$ 且 $\Phi(\pi,t)=\sigma$。

故 $\Phi$ 双射。证毕。

### 引理 2（插入恰好新增 $t$ 个逆序对）

$\mathrm{inv}(\Phi(\pi,t))=\mathrm{inv}(\pi)+t$。

*证明*：把 $\sigma=\Phi(\pi,t)$ 的数对分成两类。

**不含 $i$ 的数对**：$\sigma$ 删去 $i$ 后就是 $\pi$，且删除不改变其余元素的相对先后。故 $(\sigma_p,\sigma_q)$（均 $\ne i$，$p<q$）是逆序对 $\iff$ 它们在 $\pi$ 中对应的元素构成逆序对。这类贡献恰为 $\mathrm{inv}(\pi)$。

**含 $i$ 的数对**：$i$ 是 $[i]$ 的最大元。若 $i$ 在前（$\sigma_p=i,\sigma_q=x$），则 $i>x$ 恒成立，是逆序对；若 $i$ 在后（$\sigma_p=x,\sigma_q=i$），则 $x<i$，不是逆序对。故含 $i$ 的逆序对恰为"$i$ 与它后面每个元素"组成的对，共 $t$ 个。

两类不重不漏，相加得 $\mathrm{inv}(\sigma)=\mathrm{inv}(\pi)+t$。证毕。

### 引理 3（DP 递推与边界）

对 $i\ge 1,j\ge 0$：
$$f[i][j]=\sum_{t=0}^{\min(j,\,i-1)}f[i-1][j-t].$$
边界：$f[0][0]=1$，$f[0][j]=0\ (j\ge 1)$。

*证明*：把集合 $A=\{\sigma\in S_i:\mathrm{inv}(\sigma)=j\}$ 按"$i$ 后面的元素个数 $t$"划分。由引理 1，每个 $\sigma$ 唯一对应 $(\pi,t)$，$t\in[0,i-1]$；由引理 2，$\mathrm{inv}(\sigma)=j\iff\mathrm{inv}(\pi)=j-t$。故
$$|A|=\sum_{t=0}^{i-1}\#\{\pi\in S_{i-1}:\mathrm{inv}(\pi)=j-t\}=\sum_{t=0}^{i-1}f[i-1][j-t].$$
$j-t<0$ 的项按约定为 $0$（逆序对数非负，不可能为负），故求和上限可截到 $t\le j$，即 $\min(j,i-1)$。

边界：$S_0$ 只含空排列，逆序对数 $0$，故 $f[0][0]=1$、$f[0][j\ge1]=0$。证毕。

### 引理 4（滑动窗口恒等式：$O(n^2k)\to O(nk)$ 的合法性）

对 $i\ge 1$：
$$f[i][0]=f[i-1][0];\qquad f[i][j]=f[i][j-1]+f[i-1][j]-[j\ge i]\cdot f[i-1][j-i]\ \ (j\ge 1),$$
其中 $[\cdot]$ 为 Iverson 括号。

*证明*：由引理 3 换元 $s=j-t$，
$$f[i][j]=\sum_{s=L(j)}^{j}f[i-1][s],\qquad L(j)=\max(0,\,j-i+1).$$
（$t$ 从 $0$ 到 $\min(j,i-1)$ ⇔ $s$ 从 $j-\min(j,i-1)=\max(0,j-i+1)$ 到 $j$。）

$j=0$：窗口 $[L(0),0]=[0,0]$，$f[i][0]=f[i-1][0]$ ✓。

$j\ge 1$：比较相邻两个窗口 $[L(j-1),j-1]$ 与 $[L(j),j]$。右端新增项 $f[i-1][j]$。左端：
- **情形 A：$j<i$**。则 $j-i+1\le 0$ 且 $(j-1)-i+1<0$，故 $L(j)=L(j-1)=0$，左端无项被移出。于是 $f[i][j]=f[i][j-1]+f[i-1][j]$，与 $[j\ge i]=0$ 的公式一致。
- **情形 B：$j\ge i$**。则 $L(j)=j-i+1\ge 1$，$L(j-1)=\max(0,j-i)=j-i$（因 $j-i\ge 0$）。左端从 $j-i$ 前进到 $j-i+1$，恰移出一项 $f[i-1][j-i]$。于是 $f[i][j]=f[i][j-1]+f[i-1][j]-f[i-1][j-i]$，与 $[j\ge i]=1$ 一致。

（$j=i$ 时 $L(j-1)=0$、移出项为 $f[i-1][0]$，公式同样成立，因为 $j-i=0$。）两情形穷尽，恒等式得证。证毕。

**注**：这就是"前缀和"视角——令 $P[j]=\sum_{s\le j}f[i-1][s]$，则 $f[i][j]=P[j]-P[L(j)-1]$；递推式只是把两个前缀和的差**增量**维护，省掉显式前缀和数组。

### 引理 5（逐项取模的正确性与负数处理）

把递推中每个 $f$ 值都替换为其模 $p=10000$ 的余数（代表元取 $[0,p-1]$），并用 `(x%p+p)%p` 归一化，所得结果与"先算精确整数再取模"一致；中间量不溢出 `int`。

*证明*：映射 $\varphi:\mathbb Z\to\mathbb Z_p$，$\varphi(x)=x\bmod p$ 是环同态：$\varphi(a+b)=\varphi(a)+\varphi(b)$，$\varphi(a-b)=\varphi(a)-\varphi(b)$。递推只含加减与常数 $0/1$ 系数，故对 $i,j$ 双重归纳：若上一行与本行左侧的值都已 $\equiv$ 精确值 $\pmod p$，则本步算出的值也 $\equiv$ 精确值 $\pmod p$。基例 $f[0][0]=1,f[0][j>0]=0$ 精确成立。

C++ 的 `%` 对负被除数返回负余数（向零截断），而 $f[i][j-1]+f[i-1][j]-f[i-1][j-i]$ 可能为负；`(x%p+p)%p` 把 $(-p,p)$ 内的余数平移回 $[0,p)$，与数学模一致。

范围：三个操作数都在 $[0,9999]$，故中间量 $\in[-9999,19998]$，远小于 `int` 上限；`%` 后仍在 $[-9999,9999]$，加 $p$ 后 $\in[1,19999]$，再 `%` 得 $[0,9999]$。无溢出。证毕。

### 引理 6（计算顺序与无后效性）

按 $i=1..n$ 外层、$j=0..k$ 内层递增计算，所有依赖均已就绪。

*证明*：$f[i][j]$ 依赖 $f[i][j-1]$（本行左侧，$j$ 递增已算）、$f[i-1][j]$ 与 $f[i-1][j-i]$（上一行，$i$ 递增已算；$j-i<j$ 且 $\ge0$ 时才引用，均在上一行的 $[0,k]$ 范围内）。第 $0$ 行由引理 3 的边界显式给出（$f[0][0]=1$，其余全局默认 $0$ 恰好正确）。对 $i$ 归纳即得整表 $\equiv$ 精确值 $\pmod p$。证毕。

### 引理 7（值域性质：上限、行和、$k$ 过大自动为 $0$）

(a) $\max_{\pi\in S_n}\mathrm{inv}(\pi)=\frac{n(n-1)}2$，由倒序排列达到；故 $k>\frac{n(n-1)}2$ 时答案为 $0$，DP 自动给出。
(b) $\sum_{j\ge 0}f[n][j]=n!$（行和不变量）。

*证明*：(a) 逆序对是"位置对"的子集，位置对共 $\binom n2=\frac{n(n-1)}2$ 个，故 $\mathrm{inv}\le\binom n2$；倒序排列 $(n,n-1,\dots,1)$ 中每个位置对都是逆序对，取到上界。于是 $k>\binom n2$ 时目标集合为空，$f[n][k]=0$；递推无需特判——归纳可证 $f[i][j]=0$ 对所有 $j>\binom i2$：$i=0$ 显然；若上一行在 $>\binom{i-1}2$ 处全 $0$，则窗口 $[\max(0,j-i+1),j]$ 内 $s\ge j-i+1>\binom i2-i+1=\binom{i-1}2$，全为 $0$，故 $f[i][j]=0$。

(b) 每个 $\pi\in S_n$ 有唯一的 $\mathrm{inv}(\pi)$，故按逆序对数分类是对 $S_n$ 的划分，各类大小之和 $=|S_n|=n!$。用递推验证：$\sum_j f[i][j]=\sum_j\sum_{t=0}^{i-1}f[i-1][j-t]=\sum_{t=0}^{i-1}\sum_j f[i-1][j-t]=i\cdot(i-1)!=i!$（交换求和次序，内层对 $j$ 遍历所有整数即遍历上一行全部）。证毕。

**用途**：(b) 是免费校验——手算 $n=5$ 一行得 $1,4,9,15,20,22,20,15,9,4,1$，和为 $120=5!$，与程序逐项一致。

### 引理 8（复杂度）

时间 $O(nk)$，空间 $O(nk)$。

*证明*：状态数 $(n+1)(k+1)\le 1001^2\approx 10^6$，每个状态常数次加减与取模（引理 4、6）。空间为 `int f[1005][1005]`$\approx 4.04$ MB。代入 $n=k=1000$：约 $10^6$ 次转移，实测 $0.08$ s。证毕。

### 定理

程序输出 $f[n][k]\bmod 10000$，等于恰好 $k$ 个逆序对的 $n$ 元排列数模 $10000$；时间 $O(nk)$，空间 $O(nk)$。

*证明*：引理 1、2 建立"插入最大元"的双射与逆序对增量；引理 3 给出精确计数递推；引理 4 证明 $O(1)$ 滑动窗口递推与之逐项相等；引理 5 保证逐项取模（含负数归一化）不改变结果；引理 6 保证求值顺序合法；引理 7 保证边界情形（$k=0$、$k$ 超上限）自动正确；引理 8 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **consider easier version** — 暴力枚举 $n!$ 不可行；子任务 $n\le 12$ 暗示正解是多项式 DP。
- **explore its property** — 按数值生长：把最大元 $i$ 插入长度 $i-1$ 的排列，"后面有 $t$ 个元素" $\iff$ 新增恰好 $t$ 个逆序对，旧逆序对不变；插入位置 $\leftrightarrow t$ 是双射。
- **classic problem solution** — 插入型 DP：$f[i][j]=\sum_{t=0}^{\min(j,i-1)}f[i-1][j-t]$，$O(n^2k)\approx 5\times10^8$。
- **reduce to easier problem** — 内层和是上一行的定宽滑动窗口 $\Rightarrow$ 前缀和差分：$f[i][j]=f[i][j-1]+f[i-1][j]-[j\ge i]f[i-1][j-i]$，$O(nk)$。
- **discuss by category** — 模 $10000$ 只有加减：逐项取模合法，但减法出负必须 `(x%p+p)%p`；$f[0][0]=1$；$k>\binom n2$ 自动 $0$。
- **explore its property** — 行和不变量 $\sum_j f[n][j]=n!$：免费的手算校验器（$n=5$ 行和 $120$）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 排列长度（$\le 1000$） | `int`，读入 | |
| `k` | 目标逆序对数（$\le 1000$） | `int`，读入 | 可超 $\binom n2$，答案自动 $0$ |
| `p` | 模数 $10000$ | `constexpr int` | 非质数，但只用加减，无需求逆 |
| `f[i][j]` | 长度 $i$、恰好 $j$ 个逆序对的排列数 $\bmod\ p$ | `int[mxn][mxn]`，全局默认 $0$ | "i 是最大元也是长度" |
| `f[0][0]` | 空排列 | 显式置 $1$ | 唯一的非零边界 |
| `mxn` | $1000+5$ | `constexpr int{1005}` | +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 `n,k`；`f[0][0]=1`（其余全局默认 $0$ 恰好是正确边界）。
3. 外层 `i=1..n`，内层 `j=0..k`：
   1. `f[i][j]=f[i-1][j]`（窗口右端新进项）；
   2. `j>0` 时 `f[i][j]+=f[i][j-1]`（接上前一个窗口和）；
   3. `j>=i` 时 `f[i][j]-=f[i-1][j-i]`（窗口左端移出项）；
   4. `f[i][j]=(f[i][j]%p+p)%p`（负数归一化）。
4. 输出 `f[n][k]`。

### 复杂度

- 时间：$O(nk)\le 10^6$ 次转移，实测极限数据 $0.08$ s。
- 空间：$O(nk)$，`1005×1005` 的 `int` 数组约 $4$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例说明反推的 `4 1 → 3` 吻合；手算 $n=3,4$ 全分布（含手工枚举核对 $n=4,k=2$ 的 $5$ 个排列）、$n=5$ 整行 Mahonian 数且行和 $=120=5!$、$k=0$、$k$ 超上限、$n=1$ 等 $20$ 余组边界全部一致；$n=k=1000$ 极限规模 $0.08$ s。经典插入 DP + 前缀和优化，证明已闭合（引理 4 窗口恒等式），未写对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2513 [HAOI2009] 逆序对数列
// 思路：f[i][j]=长度 i 恰好 j 个逆序对的排列数
//       把最大元素 i 插入长度 i-1 的排列，放到"后面恰有 t 个元素"的位置新增 t 个逆序对
//       f[i][j]=Σ_{t=0..min(j,i-1)} f[i-1][j-t]，是上一行的滑动窗口和
//       前缀和差分：f[i][j]=f[i][j-1]+f[i-1][j]-(j>=i?f[i-1][j-i]:0)，O(nk)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},p{10000};

int n,k,f[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	f[0][0]=1;	// 空排列 0 个逆序对
	for(int i=1;i<=n;++i)
		for(int j=0;j<=k;++j)
		{
			f[i][j]=f[i-1][j];
			if(j>0)
				f[i][j]+=f[i][j-1];
			if(j>=i)
				f[i][j]-=f[i-1][j-i];
			f[i][j]=(f[i][j]%p+p)%p;	// 减法可能出负数
		}
	cout<<f[n][k]<<'\n';
	return 0;
}
```

### 代码说明

- **三行转移就是窗口滑动**：`+f[i-1][j]` 是右端进窗，`+f[i][j-1]` 是继承上一个窗口和，`-f[i-1][j-i]` 是左端出窗（仅当窗口宽度已满 $i$，即 `j>=i`）。`j=0` 时窗口只有一格，直接 `f[i][0]=f[i-1][0]`，两个 `if` 都不触发。
- **`(x%p+p)%p` 不可省**：三个操作数都在 $[0,9999]$，差可能到 $-9999$；C++ 负数 `%` 返回负余数，直接输出会 WA。中间量 $\in[-9999,19998]$，`int` 无溢出。
- **边界只有一处非零**：`f[0][0]=1`。第 $0$ 行其余、以及所有 $j>\binom i2$ 的格子都应是 $0$，全局数组默认值恰好正确——但这是"恰好"，不是"理所当然"，引理 7(a) 证明了递推不会在这些格子凭空造出非零值。
- **下标 1-based**：状态天然按"长度 $i$"定义，$i=0$ 表示空排列，与 P2389 同款处理，不做 `--i`。
- 空间 $4$ MB 用满表而非滚动数组：$n,k\le 1000$ 完全装得下，且与证明中的 $f[i][j]$ 记号一一对应，调试时可直接打表核对 Mahonian 行。
