# P2069 松鼠吃果子 — 题解

## 一、解题过程：人类思考叙事

题目描述有点绕，我们把它翻译成人话：

有 $n$ 个果子竖着排成一列，编号 $1\sim n$，$1$ 在最下面。松鼠一开始站在最下面那个果子上。第 $i$ 次跳，它要跳过 $(i^3\bmod 5+1)$ 个果子，然后吃掉脚下的那个果子。吃完之后上面的果子整体掉一格。**如果它跳出了最前面（跳过了所有剩余的果子），它就回到最下面，重做第 $i$ 次跳**。问第 $m$ 次吃到的果子编号。

$n,m\le200$，数据保证能跳到第 $m$ 次。

先手算一下，感受一下这个过程。$n=10,m=4$：

- 第 1 跳：$1^3\bmod5+1=2$，从 1 号往上跳 2 个，落在 3 号，吃掉 3。剩下 $1,2,4,5,6,7,8,9,10$，松鼠站在 4 号（原来 4 号掉到了 3 的位置）。
- 第 2 跳：$2^3\bmod5+1=9\bmod5+1=5$。从 4 号往上跳 5 个，落在 8 号，吃掉 8。剩 $1,2,4,5,6,7,9,10$。
- 第 3 跳：$3^3\bmod5+1=27\bmod5+1=2+1=3$。从 5 号（吃掉 8 后 6 号掉上来）往上跳 3 个……跳出了最前面！回到最下面重做第 3 跳：从 1 号往上跳 3 个，落在 5 号，吃掉 5。
- 第 4 跳：$4^3\bmod5+1=64\bmod5+1=4+1=5$，同样跳出，回到最下面重做：从 1 号跳 5 个，落在 9 号，吃掉 9。

答案 9。和题目提示里给的"吃掉的果子依次为 3、8、5、9"完全对得上。好，模型建立正确。

现在想怎么实现。

**第一个想法：用链表。** 果子是一个序列，每次删除一个元素、并在序列里往下走若干步。`std::list` 正好支持"迭代器往前走 $k$ 步"和"删除当前迭代器指向的元素"，且删除后其他元素的相对顺序不变（这正是"上面的果子整体下移一格"的语义）。$O(m \cdot n)$，$n\le200$，$4\times10^4$ 次操作，绰绰有余。

**第二个想法：用数组。** 因为 $n\le200$，直接用一个数组存剩余果子的编号，每次"下移一格"就是 `a[j]=a[j+1]` 整体搬一次，$O(n)$。$m$ 次跳就是 $O(nm)$，同样轻松。

我选数组，理由是：数组版不需要处理迭代器失效，而且"删除后松鼠脚下位置不变"这个关键点在数组里表达得非常直白。

**关键细节：删除果子之后，松鼠站在哪里？**

这是本题最容易出错的地方。我们来看：松鼠跳到了第 $q$ 个位置（数组下标），吃掉了 `a[q]`。上面的果子全部下移一格，也就是说原来 `a[q+1]` 现在占据了 `a[q]` 的位置。松鼠是"跳到第 $q$ 个果子并吃掉它"，那么下一跳它应该从哪出发？

从物理角度想：松鼠踩着的那颗果子被吃掉了，它现在站在的是"上面掉下来的那颗果子"所在的位置，也就是新数组里的下标 $q$（因为删除后 `a[q]` 就是原来的 `a[q+1]`）。

再验证一下第 1 跳：初始 `a = [1,2,...,10]`，$p=0$（站在 1 号），第 1 跳 $k=2$，$q=p+k=2$，吃掉 `a[2]=3`。删除后数组变成 `[1,2,4,5,...,10]`，下标 2 现在是 4 号。松鼠下一跳应该从 4 号出发，即 $p=2$。✓ 与手算一致。

所以：**$p \gets q$，删除后下标不变**。

**"跳出最前面"的处理。** 若 $q=p+k \ge sz$（$sz$ 是剩余果子数），说明跳过头了。按题意"它回到最下面的果子上，重做它的第 $k$ 次跳"。

注意题意说的是"重做它的第 $k$ 次跳"——这里的 $k$ 指的是**跳的次数编号**（题面用 $k$ 泛指"第几次"，即当前是第 $i$ 次跳就重做第 $i$ 次跳），而不是跳跃长度。题面原文"设为每 $k$ 次，它吃不到任何果子了。这时它回到最下面的果子上，重做它的第 $k$ 次跳"，结合上下文，$k$ 是"第 $k$ 次跳"。

所以重做的方式是：从最下面（下标 0）出发，跳同样的距离 $i^3\bmod5+1$，即令 $p=0,\ q=k$。

手算验证：第 3 跳时 $p$ 在 5 号（下标 3），$k=3$，$q=3+3=6 \ge sz=8$？不对，等一下。让我重算。第 2 跳吃掉 8 后剩 8 个果子 $[1,2,4,5,6,7,9,10]$，松鼠 $p=3$（对应 6 号）。

嗯，我前面手算说"从 5 号往上跳 3 个"，让我重新对一下。吃掉 8 之前，数组是 $[1,2,4,5,6,7,8,9,10]$，$p=3$（对应 5 号）。第 2 跳 $k=2^3\bmod5+1=8\bmod5+1=3+1=4$，$q=3+4=7$，吃掉 `a[7]=9`？

这和提示的"8"对不上。让我重新检查 $2^3\bmod5$：$2^3=8$，$8\bmod5=3$，$3+1=4$。所以第 2 跳跳 4 个。

第 1 跳 $1^3\bmod5+1=1+1=2$，$p=0$，$q=2$，吃掉 `a[2]=3` ✓ 与提示一致。删除后 $[1,2,4,5,6,7,8,9,10]$，$p=2$（现在是 4 号）。

第 2 跳 $k=4$，$q=2+4=6$，吃掉 `a[6]=8` ✓ 与提示一致！删除后 $[1,2,4,5,6,7,9,10]$，$p=6$（现在是 9 号）。

第 3 跳 $k=3^3\bmod5+1=27\bmod5+1=2+1=3$，$q=6+3=9 \ge sz=8$，跳出了！回到最下面重做：$p=0$，$q=k=3$，吃掉 `a[3]=5` ✓ 与提示一致！删除后 $[1,2,4,6,7,9,10]$，$p=3$（现在是 6 号）。

第 4 跳 $k=4^3\bmod5+1=64\bmod5+1=4+1=5$，$q=3+5=8\ge sz=7$，跳出！重做：$p=0$，$q=5$，吃掉 `a[5]=9` ✓ 与提示一致！

答案 9，完美吻合。模型彻底验证正确。

于是算法就非常清晰了：模拟 $m$ 次跳，维护数组 `a`（剩余果子编号，自下而上）、剩余个数 `sz`、松鼠所在下标 `p`。每一步算出 $k=i^3\bmod5+1$、$q=p+k$；若 $q\ge sz$ 则 $p=0,\ q=k$ 重做；吃掉 `a[q]`，前移数组，`sz--`，`p=q$。

最后一跳吃到的果子就是答案。

## 二、思维链：完整证明

**引理 1**：设当前剩余果子按自下而上顺序存于数组 `a[0..sz-1]`，松鼠脚下是 `a[p]`。则第 $i$ 跳若不跳出，目标是 `a[p+k]`，其中 $k=i^3\bmod5+1$。

*证明*：题目规定第 $i$ 次跳"跳过 $(i^3\bmod5+1)$ 个果子，并把脚下的果子吃了"。跳过的果子数就是 $k$ 个，从 `a[p]`（脚下）往上数，跨过 $k$ 个果子后落脚的下一个果子是 `a[p+k]`（下标从 $p$ 出发前进 $k$ 格）。证毕。

**引理 2**：吃掉 `a[q]` 并让上方果子下移一格后，剩余序列为 `a[0..q-1]` 接到 `a[q+1..sz-1]`，且松鼠脚下变为新数组的 `a[q]`。

*证明*：吃掉的是下标 $q$ 处的果子，它上方（即下标大于 $q$）的每颗果子都下移一格，即新下标 = 旧下标 $-1$。于是旧 `a[q+1]` 移到新 `a[q]`，旧 `a[q+2]` 移到新 `a[q+1]`，依此类推；`q` 以下的果子不动。所以新数组就是把旧 `a[q+1..sz-1]` 整体前移一格接到 `a[0..q-1]` 之后。松鼠吃掉的是它落脚的那颗，它现在站着的位置就是那颗果子原来的位置对应的地面，即新数组中原来上方那颗果子的位置，也就是新 `a[q]`（当 $q<sz-1$ 时）；当 $q=sz-1$（吃的是最上面那颗）时上方没有果子，松鼠脚下无对应果子，此后必然跳出最前面（由引理 3 的边界分析），这与题意一致。证毕。

**引理 3**：若 $p+k\ge sz$，则应令 $p=0,\ q=k$ 重新定位。

*证明*：$p+k\ge sz$ 意味着从 `a[p]` 往上跳 $k$ 个之后已经越过最上面那颗果子（最上面的下标是 $sz-1$），即"跳出了这串果子的最前面"。按题意，此时松鼠"回到最下面的果子上，重做它的第 $i$ 次跳"。最下面的果子是 `a[0]`，故松鼠脚下变为 $p=0$；重做的是同一次跳，跳跃长度仍是 $k=i^3\bmod5+1$，由引理 1，目标是新下标 $0+k=k$，即 $q=k$。证毕。

**引理 4**：模拟过程中 `a[]`、`sz`、`p` 始终与真实过程的"剩余果子序列、松鼠脚下位置"一致。

*证明*：归纳。初始时 `a` 为 $1\sim n$、$sz=n$、$p=0$，与"松鼠从最下面果子开始"一致（$p=0$ 即最下面）。

假设某次跳之前一致。由引理 1 与引理 3，本次跳的目标下标 $q$ 计算正确（两种情形分别对应不跳出与跳出重做）。本次吃掉的果子编号为 `a[q]`，与真实一致。由引理 2，吃掉并下移后的数组与松鼠脚下位置也与真实一致，即 `a` 更新、`sz--`、`p=q` 之后状态仍一致。归纳成立。证毕。

**定理**：算法输出的编号就是松鼠第 $m$ 次跳吃到的果子编号。

*证明*：由引理 4，第 $m$ 次跳时记录下的 `a[q]` 与真实吃到的果子编号相同；算法最后输出该值，故正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **先把题意翻译成"维护一个序列 + 一个游标"** — 删元素、游标停在原地、上方元素前移，这三个动作就是全部。
2. **手算几组数据验证模型** — 题目提示给了"3、8、5、9"这条关键序列，拿它当"标准答案"逐步核对，比读十遍题面有用。
3. **确定"吃掉后游标不动"这个不变量** — 删除元素后游标下标保持不变，这是本题唯一的思维难点，必须靠手算确认。
4. **"跳出最前面"= 回到底部重做同一次跳** — 注意重做的是"第 $i$ 次跳"（跳跃长度不变），起点变成最下面。
5. **数组 vs 链表** — $n\le200$，数组 + 手动前移即可，$O(nm)$ 完全够；链表的迭代器版更"正统"但要处理删除后的迭代器位置，两者等价。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 果子总数 | `int`，$\le 200$ |
| $m$ | 要吃第 $m$ 只果子 | `int`，$\le n$ |
| `a[i]` | 第 $i$ 个位置上的剩余果子编号（**自下而上**排列，0-based） | `int`，$1\sim n$ |
| `sz` | 剩余果子个数 | `int`，$0\sim n$ |
| `p` | 松鼠脚下位置的数组下标 | `int`，$0\sim sz-1$ |
| $k$ | 第 $i$ 跳跳过的果子数 $i^3\bmod5+1$ | `int`，$1\sim5$ |
| $q$ | 本次吃掉的位置下标 | `int` |
| `ans` | 记录本次吃掉的果子编号 | `int` |

**初始化约定**：`a[]` 为全局数组，默认全 0；使用前显式填入 `a[i]=i+1`。`sz`、`p`、`ans` 在 `main` 内显式赋初值。

### 算法步骤

1. 读入 $n,m$；填 `a[i]=i+1`（$i=0\ldots n-1$），令 `sz=n`、`p=0`。
2. 令 `ans=0`。
3. 对 $i=1\ldots m$：
   - 计算 $k=i\cdot i\cdot i\bmod 5+1$，令 $q=p+k$；
   - 若 $q\ge sz$（跳出最前面）：令 $p=0$、$q=k$，重做本次跳；
   - 令 `ans=a[q]`；
   - 删除该果子：把 `a[q+1..sz-1]` 整体前移一格（`for(j=q;j+1<sz;++j) a[j]=a[j+1];`），并令 `sz--`；
   - 令 `p=q`（松鼠脚下位置不变，下标仍为 $q$）。
4. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(nm)$。共 $m$ 次跳，每次删除最多搬移 $n$ 个元素。
- 空间复杂度：$O(n)$，存储剩余果子序列。

### 验证状态

- 标程 `P2069.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `10 4` 输出 `9`，与题目提示给出的吃果序列 `3、8、5、9` 完全一致。
- 编写独立暴力 `P2069_brute.cpp`（用 `std::list` + 迭代器逐步上爬，与标程的数组模拟是两种完全不同的数据结构实现）与对拍脚本 `P2069_check.py`：随机生成 $3\le n\le40$、$1\le m\le n$ 的数据，并且用与标程相同的模拟规则预先筛掉"跳不到第 $m$ 次"的非法数据（题目保证能跳到第 $m$ 次），再穷举所有 $3\le n\le12$ 的合法 $(n,m)$ 组合以及官方样例，**对拍 3041 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{205};

int n,m;
//a[]：还没被吃掉的果子的编号，自下而上排列
int a[mxn];
//sz：剩余果子个数；p：松鼠当前所在位置（a 中的下标，0-based）
int sz,p;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		a[i]=i+1;
	sz=n;
	p=0;
	int ans=0;
	for(int i=1;i<=m;++i)
	{
		int k=i*i*i%5+1;
		int q=p+k;
		if(q>=sz)
		{
			//跳出最前面：回到最下面的果子，重做第 i 跳
			p=0;
			q=k;
		}
		ans=a[q];
		for(int j=q;j+1<sz;++j)
			a[j]=a[j+1];
		--sz;
		p=q;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `a[]` 是全局数组，默认全 0；进入循环前用 `a[i]=i+1` 显式填入编号，不依赖默认初始化。
- `p` 与 `q` 严格区分：`q` 是"本次要吃的位置"，`p` 是"松鼠脚下"；删除后令 `p=q`，因为上方果子下移一格后正好补在 `q` 这个位置。
- `k=i*i*i%5+1` 用 `int` 即可，$i\le200$ 时 $i^3\le8\times10^6$ 不会溢出。
- 数组前移用 `for(int j=q;j+1<sz;++j) a[j]=a[j+1];`，写 `j+1<sz` 而不是 `j<sz`，避免读到 `a[sz]`。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
