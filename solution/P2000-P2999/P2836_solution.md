# P2836 [ICPC 1993 WF] 加油问题 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 开车从出发地到目的地，距离 $D$ 英里。油箱容量 $C$ 加仑，每加仑跑 $M$ 英里，出发地加满油花费 $c_0$ 元。路上有 $n\le51$ 个加油站，按距出发地距离递增给出，第 $i$ 个在 $x_i$ 英里处、油价 $p_i$ **分**/加仑。驾驶员行为受下列规则约束：

1. **停车限制**：油箱里油**不少于半箱**（$\ge C/2$）时**从不**在加油站停，**除非**用当前油到不了下一个加油站（或目的地）。
2. 每次停下都**加满**油箱。
3. 每停一次，额外花 $2.00$ 元买零食。
4. **无安全余量**：到下一站/目的地只需"刚好够"的油，不必多带。
5. 出发时油箱**总是满的**。
6. 每个加油站的付款**四舍五入到分**。

求旅程上汽油 + 食品**至少**花多少钱（元，保留两位小数）。题目保证加油站安排得让车能从出发地开到目的地。

**先把"至少"和规则读透（关键解读）。** 规则 1 是一条**禁令**而非强制：它只说"油 $\ge$ 半箱且能到下一站时**不准停**"，并没有说"油 $<$ 半箱时**必须停**"。所以在"油 $<$ 半箱"或"到不了下一站"这两种情形下，停不停是**有选择余地的**；题目问"至少花多少"，就是要我们在**所有遵守规则的策略里取最小花费**。这一点决定了本题是**最优化 DP**，而不是"模拟一个确定行为"。我把它作为显式假设记下（见第二部分末尾）。

**第一步：探索性质——油量到底由什么决定？** 规则 2"每次加满" + 规则 5"出发满油"意味着：**任何时刻的油量，只取决于上一次加油是在哪个点**。设上次加油在点 $j$（加满到 $C$），之后一路开到点 $i$ 没再加油，消耗 $=(x_i-x_j)/M$ 加仑，于是

$$\text{fuel}(i,j)=C-\frac{x_i-x_j}{M}.$$

这是个**决定性**的观察：油量本来是连续量，看似要离散化或开浮点状态，但它被"上次加油点 $j$"完全确定！所以状态不需要记油量，只需记 **(当前点 $i$, 上次加油点 $j$)**。$n\le51$，点数 $n+2\le53$，状态数 $O(n^2)\approx2800$——小到可以随便 DP。

**第二步：考虑简化版，看清增量。** 假如**没有**半箱禁令（想在哪个站停就在哪个站停），这就是经典"加油站最小费用"DP：状态同样是 $(i,j)$，在每个站自由选择停/不停。半箱禁令只是给"停"这个动作加了一个**合法性闸门**：只有 $\text{fuel}<C/2$ 或到不了下一站时才允许停。于是简化版的框架完全复用，只需在"停"的转移前判一下合法性。增量很小，框架不变。

**第三步：撞墙——"停"的合法性会不会依赖更早的历史？** 我一度担心：判断"能不能停"要看当前油量，而油量会不会受"更早以前在哪加过油"影响？由第一步，$\text{fuel}(i,j)$ 只依赖 $(i,j)$，与 $j$ 之前的历史**无关**。再看"到不了下一站"：下一站距离 $x_{i+1}-x_i$ 是固定的，能否到达 $=\big(x_{i+1}-x_i>\text{fuel}(i,j)\cdot M\big)$，也只依赖 $(i,j)$。所以**合法性是 $(i,j)$ 的函数**，状态 $(i,j)$ 是**充分**的（马尔可夫性），DP 无后效性成立。墙拆了。

**第四步：写出转移。** 把出发地记为点 $0$（$x_0=0$），加油站为点 $1..n$，目的地为点 $n+1$（$x_{n+1}=D$）。令满油续航 $R=C\cdot M$。状态 $dp[i][j]$ = "到达点 $i$、上次加油在点 $j$"的最小花费（**分**，不含出发地加油费）。在点 $i$（加油站）有两种决策：

- **不停**，直接开到点 $i+1$：要求从 $j$ 满油能到 $i+1$，即 $x_{i+1}-x_j\le R$。花费不变，$dp[i+1][j]\leftarrow dp[i][j]$。
- **停**（加满 + 零食）：合法性 $=\big(\text{fuel}(i,j)<C/2\big)\ \lor\ \big(x_{i+1}-x_i>\text{fuel}(i,j)\cdot M\big)$；且加满后要能到下一站 $x_{i+1}-x_i\le R$。买入 $C-\text{fuel}(i,j)=\frac{x_i-x_j}{M}$ 加仑，油钱四舍五入到分 $=\mathrm{round}\big(\frac{x_i-x_j}{M}\cdot p_i\big)$，再加 $200$ 分零食。$dp[i+1][i]\leftarrow dp[i][j]+\text{add}$（上次加油点变成 $i$）。

注意"到不了下一站"时**必须停**（不停就开不到），此时"不停"转移的可达条件自动失败，只剩"停"，逻辑自洽。

**第五步：边界与答案。** 出发满油，$dp[1][0]=0$（能到第一个点，题目保证）。目的地 $n+1$ 不需要加油，答案 $=\min_j dp[n+1][j]+\mathrm{round}(c_0\times100)$（加上出发地加满油的费用，元转分）。全程用**整数分**累加，最后拆成"元.分"输出，避免浮点输出误差。

**第六步：浮点边界与四舍五入的坑。** 距离/容量/油耗是实数，$\text{fuel}$ 由除法得到，比较"是否 $<$ 半箱""能否到达"时要用 $\varepsilon$ 容差。我取 $\varepsilon=10^{-9}$：

- "不少于半箱"是 $\ge C/2$ **禁停**，所以"允许停"的半箱条件写成 $\text{fuel}<C/2-\varepsilon$——把"恰好半箱"以及浮点噪声下落在半箱附近的值都判为"不少于半箱"（禁停），严格遵守禁令。
- 可达用 $\le R+\varepsilon$（"无安全余量"⇒ 恰好够也算能到）。
- 四舍五入到分用 `llround(v+1e-9)`：`llround` 对正数就是"四舍五入"（half-away-from-zero），加 $10^{-9}$ 是为了补偿二进制表示误差把真实的 $.5$ 压成 $.4999999999$ 的情形。

这些是**数值实现层面的显式假设**，题面未给精度/边界细则，我选最自洽的口径。

**手造数据核对**（题面无样例，按规则自造，$C=10,M=10\Rightarrow R=100$，$c_0=20.00$）：

| 场景 | 推理 | 输出 |
|---|---|---|
| $D=100$，站 $50$@$100$ 分 | 到站油 $=5=$ 半箱，能到终点（$50\le50$）⇒ 禁停；直接开到终点 | `20.00` |
| $D=150$，站 $60$@$100$、$95$@$200$ | 站 $60$ 油 $4<5$ 可停（便宜）；停它后到 $95$ 油 $6.5\ge5$ 且能到终点 ⇒ 跳过贵站。买 $6$ 加仑@$100$+$200$=$800$ 分 | `28.00` |
| $D=120$，站 $90$@$150$ | 到站油 $1$，到终点需要 $3>1$ ⇒ 被迫停；买 $9$ 加仑@$150$+$200$=$1550$ 分 | `35.50` |
| $D=120$，站 $50$@$100$ | 到站油 $=5=$ 半箱，但到终点 $70>50$ ⇒ "除非到不了"例外，允许停；买 $5$@$100$+$200$=$700$ | `27.00` |
| $D=120$，站 $55$@$101$ | 买 $5.5$ 加仑@$101=555.5$ 分 → 四舍五入 $556$，+$200$=$756$ | `27.56` |
| $D=50$，$n=0$ | 满油直达，无站 | `20.00` |

第二组专门验证"自愿在便宜站停、以跳过后面贵站"确实更优（$800<2100$），说明 DP 必须允许"油 $<$ 半箱时自愿停"，而不是只在被迫时停。第五组专门打四舍五入到分的 $.5$ 边界。全部与程序输出一致。

## 二、思维链：完整证明

**记号。** 点 $0,1,\dots,n+1$：$x_0=0$，$x_1<\dots<x_n$ 为加油站位置，$x_{n+1}=D$；$0<x_i\le D$。油价 $p_i>0$（分/加仑，$i=1..n$）。容量 $C>0$，油耗 $M>0$，满油续航 $R=CM$。出发加油费 $c_0>0$（元）。题目保证相邻点间距 $\le R$（"任何汽车都能从出发地开到目的地"）。$\varepsilon=10^{-9}$。

$\text{fuel}(i,j)=C-\dfrac{x_i-x_j}{M}$（$j<i$）。$dp[i][j]$ = 到达点 $i$、上次加油在点 $j$ 的最小花费（分，不含 $c_0$），不可达为 $+\infty$。

**解读假设（显式标注）**：
- (A1) 规则 1 是禁令：油 $\ge C/2$ 且能到下一点时禁停；其余情形停/不停可选，目标是在所有合法策略中最小化总花费。
- (A2) 出发地加满油费 $c_0$ 计入总花费。
- (A3) "无安全余量"⇒ 可达判据为 $\text{fuel}\cdot M\ge\text{距离}$（取等允许）。
- (A4) 每站付款 = 四舍五入到分的油钱 + $200$ 分零食；$c_0$ 也四舍五入到分后计入。
- (A5) 浮点比较用 $\varepsilon$ 容差，"恰好半箱"按禁停处理（$\text{fuel}<C/2-\varepsilon$ 才允许自愿停）。

---

### 引理 1（油量由上次加油点唯一确定）

若上次加油在点 $j$（加满至 $C$），此后未加油一路到达点 $i$（$j<i$），则到达时油量恰为 $\text{fuel}(i,j)=C-\frac{x_i-x_j}{M}$，且 $\text{fuel}(i,j)\ge0\iff x_i-x_j\le R$。

*证明*：从 $j$ 到 $i$ 行驶 $x_i-x_j$ 英里，每加仑跑 $M$ 英里，故消耗 $\frac{x_i-x_j}{M}$ 加仑。出发时（在 $j$ 加满）油量 $C$，途中无加油，故到达油量 $=C-\frac{x_i-x_j}{M}$。非负 $\iff C\ge\frac{x_i-x_j}{M}\iff CM\ge x_i-x_j\iff R\ge x_i-x_j$。证毕。

**推论**：油量不是独立自由变量，而是 $(i,j)$ 的函数。状态记 $(i,j)$ 即隐含了油量，无需离散化连续油量。

---

### 引理 2（状态充分性 / 无后效性）

从点 $i$ 出发的一切未来决策的合法性与花费，只依赖 $(i,j)$（$j$ 为上次加油点），与 $j$ 之前的历史无关。因此 $dp[i][j]$ 良定义，且满足最优子结构。

*证明*：未来在点 $i$ 是否允许停，由 $\text{fuel}(i,j)$ 与下一点间距决定（引理 3），二者都是 $(i,j)$ 的函数（$\text{fuel}$ 由引理 1）。未来"不停"能到多远，由 $x_{\text{next}}-x_j\le R$ 决定，也只依赖 $(i,j)$。未来每次停的花费由当时 $(i',j')$ 决定。已发生的花费是沉没成本，不影响未来决策的合法性或单价。故给定 $(i,j)$，未来子问题与历史无关（马尔可夫性）。

最优子结构：设某最优策略到达 $(i,j)$ 的前缀花费为 $P$，若存在另一合法前缀以更小花费 $P'<P$ 到达同一 $(i,j)$，则把原策略的前缀换成它、后缀不变（后缀合法性只依赖 $(i,j)$，不变），得到总花费更小的合法策略，矛盾。故最优策略的前缀必是到达 $(i,j)$ 的最优前缀，即 $dp[i][j]$。证毕。

---

### 引理 3（停车合法性判据）

在加油站 $i$（上次加油 $j$）**允许停** $\iff$ $\text{fuel}(i,j)<C/2$ **或** $x_{i+1}-x_i>\text{fuel}(i,j)\cdot M$（到不了下一点）。后者等价于 $x_{i+1}-x_j>R$。

*证明*：规则 1（A1）：油 $\ge C/2$ 且能到下一点时**禁停**；其否定即"允许停" $=$（油 $<C/2$）$\lor$（到不了下一点）。"到不了下一点" $=$ 当前油不够开到 $i+1$ $=$ $x_{i+1}-x_i>\text{fuel}(i,j)\cdot M$。又
$$x_{i+1}-x_i>\text{fuel}(i,j)\cdot M=\Big(C-\frac{x_i-x_j}{M}\Big)M=R-(x_i-x_j)\iff x_{i+1}-x_j>R.$$
故两表述等价。证毕。

**推论**：当 $x_{i+1}-x_j>R$（到不了下一点）时，"不停"转移的可达条件失败，只剩"停"，即**被迫停**，与规则一致。

---

### 引理 4（两条转移的正确性）

从状态 $(i,j)$（$dp[i][j]<\infty$，$1\le i\le n$）：

**(a) 不停**：若 $x_{i+1}-x_j\le R$，则 $dp[i+1][j]\le dp[i][j]$（花费不变，上次加油点仍 $j$）。
**(b) 停**：若（$\text{fuel}(i,j)<C/2$ 或 $x_{i+1}-x_i>\text{fuel}(i,j)M$）且 $x_{i+1}-x_i\le R$，则
$$dp[i+1][i]\le dp[i][j]+\underbrace{\mathrm{round}\Big(\frac{x_i-x_j}{M}\cdot p_i\Big)}_{\text{油钱(分)}}+200.$$

*证明*：

(a) 不停意味着从 $i$ 继续开到 $i+1$，上次加油仍是 $j$。由引理 1，能到 $i+1$ $\iff x_{i+1}-x_j\le R$。此过程不加油、不买零食，花费增量 $0$，新状态 $(i+1,j)$。故 $dp[i+1][j]\le dp[i][j]+0$。

(b) 停的合法性由引理 3。停下后加满：买入 $C-\text{fuel}(i,j)=\frac{x_i-x_j}{M}$ 加仑（引理 1），单价 $p_i$ 分/加仑，油钱 $=\frac{x_i-x_j}{M}p_i$ 分，四舍五入到分（A4）得 $\mathrm{round}(\cdot)$；零食 $200$ 分。加满后油量 $C$，上次加油点变为 $i$，要能开到 $i+1$ 需 $x_{i+1}-x_i\le R$（题目保证相邻间距 $\le R$，故恒成立，代码仍显式判以保稳健）。新状态 $(i+1,i)$，花费增量 $=\mathrm{round}(\cdot)+200$。故不等式成立。证毕。

---

### 引理 5（DP 归纳正确性）

按 $i=1,\dots,n$ 顺序、对每个 $j<i$ 施加引理 4 的两条转移（取 min）后，$dp[i+1][\cdot]$ 恰为"到达点 $i+1$、各上次加油点"的最小花费。初始 $dp[1][0]=0$（若 $x_1\le R$）。最终 $\min_j dp[n+1][j]$ 为到达目的地的最小花费（不含 $c_0$）。

*证明*：对 $i$ 归纳。

**基础**：出发满油（上次加油点 $0$），能到点 $1$ $\iff x_1-x_0=x_1\le R$（题目保证），花费 $0$，故 $dp[1][0]=0$；其余 $dp[1][j>0]$ 无意义（$j<i=1$ 只有 $j=0$）。

**归纳步骤**：设 $dp[i][\cdot]$ 已正确（到达点 $i$ 各状态的最优前缀花费）。任何到达点 $i+1$、上次加油点为 $j'$ 的合法策略，其在点 $i$ 的决策只有两种：
- 若 $j'=j$（在 $i$ 没停）：它由某个到达 $(i,j)$ 的策略经"不停"而来，要求 $x_{i+1}-x_j\le R$，花费 $=dp[i][j]$（引理 4a）。
- 若 $j'=i$（在 $i$ 停了）：它由某个到达 $(i,j)$（$j<i$）的策略经"停"而来，合法性与花费见引理 4b。

这两种情形穷尽了在点 $i$ 的所有合法决策（停或不停），且每条转移的花费增量精确。由归纳假设 $dp[i][j]$ 是最优前缀，取 min 后 $dp[i+1][j']$ 即到达 $(i+1,j')$ 的最优花费。不可达状态保持 $+\infty$。

**终点**：目的地 $n+1$ 不是加油站，无需停；到达它的最小花费 $=\min_{j}dp[n+1][j]$（$j$ 可为 $0..n$，即最后一次加油可能在出发地或任一加油站）。证毕。

---

### 引理 6（总花费与输出）

答案（分）$=\min_j dp[n+1][j]+\mathrm{round}(c_0\times100)$。以"元.分"两位小数输出即所求。

*证明*：总花费 = 出发地加满油费（A2，$c_0$ 元 $=\mathrm{round}(c_0\times100)$ 分）+ 途中各站油钱与零食（已含在 $dp$ 里，单位分）。由引理 5，途中最小花费 $=\min_j dp[n+1][j]$。相加得总花费（分）。设总分为 $T$，则元 $=\lfloor T/100\rfloor$、分 $=T\bmod100$（补零两位），数值 $=T/100$ 元，保留两位小数。全程整数分累加，无浮点累积误差。证毕。

---

### 引理 7（四舍五入到分的实现）

对正实数 $v$（某站油钱，单位分），`llround(v+1e-9)` 给出 $v$ 四舍五入到整数的值（half-up），其中 $+10^{-9}$ 补偿二进制表示误差。

*证明*：四舍五入到分 $=\lfloor v+0.5\rfloor$（$v\ge0$）。C 的 `llround` 对正数返回 $\lfloor v+0.5\rfloor$（half-away-from-zero，正数即 half-up），故 `llround(v)` 在 $v$ 精确时正确。但 $v=\frac{x_i-x_j}{M}p_i$ 由浮点乘除得到，真实值恰为 $k+0.5$ 时可能被表示成 $k+0.4999999999$，使 `llround` 误舍为 $k$。加 $10^{-9}$ 把这种"略低于 $.5$"的表示误差推回 $.5$ 以上，恢复正确进位；对真实值远离 $.5$（$\ge10^{-6}$ 量级）的情形，$10^{-9}$ 不改变舍入结果。故 `llround(v+1e-9)` 在题面数据精度下实现四舍五入。证毕。

（这是数值实现假设 A4/A5 的一部分：题面未规定 $.5$ 边界的浮点细则，取最自洽的"四舍五入 + 微小正容差"。）

---

### 引理 8（复杂度）

时间 $O(n^2)$，空间 $O(n^2)$。

*证明*：状态 $(i,j)$ 共 $\sum_{i=1}^{n+1}i=O(n^2)$ 个（$i\le n+1\le52$，$j<i$）。每个状态两条 $O(1)$ 转移（常数次浮点比较 + 一次 `llround`）。故时间 $O(n^2)\le52^2\approx2700$ 次操作，极快。空间：$dp$ 为 $O(n^2)$ 的 `i64` 数组（$60\times60$），$x,p$ 各 $O(n)$。合计 $O(n^2)$。证毕。

### 定理

程序输出驾驶员在遵守全部规则的前提下，旅程汽油 + 食品的最小总花费（元，两位小数），时间 $O(n^2)$。

*证明*：引理 1 把连续油量塌缩为 $(i,j)$ 的函数；引理 2 确立状态充分性与最优子结构；引理 3 给出停车合法性判据；引理 4 给出两条精确转移；引理 5 归纳证明 DP 求出到达各状态的最优花费；引理 6 加出发费并以整数分输出；引理 7 保证四舍五入正确；引理 8 给出复杂度。在假设 A1–A5 下串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 读透规则：半箱条款是**禁令**非强制，"至少花多少"⇒ 在合法策略里最优化；每站加满 + 出发满油。
2. **explore its property** — 决定性观察：油量 $=C-(x_i-x_j)/M$ 由**上次加油点 $j$** 唯一确定 ⇒ 连续油量塌缩成离散状态 $(i,j)$。
3. **consider easier version** — 先去掉半箱禁令 = 经典加油站费用 DP；禁令只是给"停"加一道合法性闸门，框架复用。
4. **reduce to easier problem** — 合法性（半箱 / 到不了下一站）也只依赖 $(i,j)$ ⇒ 无后效性，$O(n^2)$ 状态 DP。
5. **classic problem solution** — 逐点 DP：不停（可达则花费不变）/ 停（合法则加满油钱四舍五入 + 200 分），$dp[i+1][j]$ 与 $dp[i+1][i]$ 取 min。
6. **discuss by category** — 被迫停（到不了下一站）自动只剩"停"；自愿停（油 < 半箱）可跳过后面贵站；终点取 $\min_j$ 再加出发费。
7. **explore its property** — 全程整数分累加 + `llround(v+1e-9)` 四舍五入 + $\varepsilon$ 容差比较，最后拆"元.分"输出，规避浮点误差。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `D` | 出发地到目的地距离（英里） | `double` | 读入 |
| `C` | 油箱容量（加仑） | `double` | 读入 |
| `M` | 每加仑行驶英里数 | `double` | 读入 |
| `c0` | 出发地加满油费用（元） | `double` | 读入；计入总花费 |
| `n` | 加油站数，$\le51$ | `int` | 读入 |
| `R` | 满油续航 $=C\cdot M$（英里） | `double` | 算出 |
| `x[i]` | 点 $i$ 距出发地距离；`x[0]=0`,`x[n+1]=D` | `double[mxn]` | 读入/赋值；`mxn=60` |
| `pr[i]` | 站 $i$ 油价（**分**/加仑） | `double[mxn]` | 读入（$i=1..n$） |
| `dp[i][j]` | 到点 $i$、上次加油在点 $j$ 的最小花费（**分**，不含 $c_0$） | `i64[mxn][mxn]` | **显式填 `inf`**；`dp[1][0]=0` |
| `inf` | 不可达哨兵 | `constexpr i64` | `1145141919810` |
| `eps` | 浮点比较容差 | `constexpr double` | `1e-9` |
| `fuel` | 到点 $i$ 时剩油 $=C-(x_i-x_j)/M$ | `double` | 每状态现算 |
| `half` | 是否不足半箱（允许自愿停） | `bool` | `fuel<C/2-eps` |
| `forced` | 是否到不了下一点（被迫停） | `bool` | `x[i+1]-x[i]>fuel*M+eps` |
| `add` | 停一次的花费增量（分） | `i64` | `llround((C-fuel)*pr[i]+1e-9)+200` |
| `best` | 到目的地最小花费（分） | `i64` | `min_j dp[n+1][j]` |
| `tot` | 总花费（分） | `i64` | `best+llround(c0*100+1e-9)` |

### 算法步骤

1. I/O 加速三行。
2. 读 `D,C,M,c0,n`；算 `R=C*M`；置 `x[0]=0,x[n+1]=D`；读各站 `x[i],pr[i]`。
3. `fill_n(&dp[0][0],mxn*mxn,inf)`（**全局默认 0 会被当成可达 0 花费，必须显式填 inf**）；若 `x[1]<=R+eps` 则 `dp[1][0]=0`。
4. 对 `i=1..n`、`j=0..i-1`，跳过 `dp[i][j]>=inf`：算 `fuel`；
   - 不停：若 `x[i+1]-x[j]<=R+eps`，`dp[i+1][j]=min(dp[i+1][j],dp[i][j])`；
   - 停：若 `(half||forced)&&x[i+1]-x[i]<=R+eps`，`add=llround((C-fuel)*pr[i]+1e-9)+200`，`dp[i+1][i]=min(dp[i+1][i],dp[i][j]+add)`。
5. `best=min_{j=0..n} dp[n+1][j]`；`tot=best+llround(c0*100+1e-9)`。
6. 输出 `tot/100 << '.' << setw(2) << setfill('0') << tot%100`。

### 复杂度

- 时间：$O(n^2)\le52^2\approx2700$ 次转移，极快。
- 空间：$O(n^2)$（`dp` 约 $60\times60$ 个 `i64`）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 6 组（半箱禁停、自愿停便宜站跳过贵站、被迫停、恰好半箱但被迫、$.5$ 四舍五入、$n=0$）输出 `20.00/28.00/35.50/27.00/27.56/20.00` 均与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2836 [ICPC 1993 WF] 加油问题
// 每站加满 + 出发满油 ⇒ 油量 = C-(x_i-x_j)/M 由"上次加油点 j"唯一确定。
// 状态 (i,j)：到点 i、上次加油在 j 的最小花费(分)。O(n^2) DP。
// 停的合法性：油<半箱 或 到不了下一点(被迫)；停则加满油钱四舍五入到分 +200 分零食。
// 半箱条款是禁令非强制 ⇒ 在所有合法策略里取最小花费。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{60};				// 点数 n+2<=53
constexpr i64 inf{1145141919810};
constexpr double eps{1e-9};

int n;
double D,C,M,R,c0,x[mxn],pr[mxn];
i64 dp[mxn][mxn];					// dp[i][j]=到点 i、上次加油在点 j 的最小花费(分)

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>D>>C>>M>>c0>>n;
	R=C*M;							// 满油续航(英里)
	x[0]=0;x[n+1]=D;
	for(int i=1;i<=n;++i)
		cin>>x[i]>>pr[i];			// pr 单位：分/加仑
	fill_n(&dp[0][0],mxn*mxn,inf);	// 全局默认 0 会被当成可达，必须显式填 inf
	if(x[1]<=R+eps)
		dp[1][0]=0;					// 出发满油，能到第一个点
	for(int i=1;i<=n;++i)
		for(int j=0;j<i;++j)
		{
			if(dp[i][j]>=inf)
				continue;
			double fuel=C-(x[i]-x[j])/M;	// 到 i 时的剩油(加仑)
			if(x[i+1]-x[j]<=R+eps)			// 不停：直接开到下一点
				dp[i+1][j]=min(dp[i+1][j],dp[i][j]);
			bool half=fuel<C/2-eps;			// 不足半箱才允许停
			bool forced=x[i+1]-x[i]>fuel*M+eps;	// 到不了下一点 ⇒ 被迫停
			if((half||forced)&&x[i+1]-x[i]<=R+eps)
			{
				i64 add=(i64)llround((C-fuel)*pr[i]+1e-9)+200;	// 加满的油钱(四舍五入到分)+2 元零食
				dp[i+1][i]=min(dp[i+1][i],dp[i][j]+add);
			}
		}
	i64 best=inf;
	for(int j=0;j<=n;++j)
		best=min(best,dp[n+1][j]);
	i64 tot=best+(i64)llround(c0*100+1e-9);	// 加上出发地加满油的费用
	cout<<tot/100<<'.'<<setw(2)<<setfill('0')<<tot%100<<'\n';
	return 0;
}
```

### 代码说明

- **状态塌缩是全题支点**：油量连续，但"每次加满"使它只由上次加油点 $j$ 决定，于是 $(i,j)$ 两个整数下标就够，$O(n^2)$ 而非浮点状态。
- `dp` **必须 `fill_n(...,inf)`**：全局 `i64` 默认 $0$，若不填 inf，未可达状态会被当成"0 花费可达"，min 转移会静默污染答案（移植坑点）。
- `half=fuel<C/2-eps`：把"恰好半箱"判为禁停（规则"不少于半箱"含等号）；`forced` 用 `>fuel*M+eps`，恰好够算能到（无安全余量）。
- "不停"转移的可达条件 `x[i+1]-x[j]<=R+eps` 失败时自动只剩"停"，即被迫停，无需特判。
- `add` 里 `(C-fuel)` 就是买入加仑数 $=\frac{x_i-x_j}{M}$；`llround(...+1e-9)` 四舍五入到分并补偿 $.5$ 表示误差；`+200` 是零食（分）。
- 全程整数分累加，最后 `tot/100` 与 `tot%100` 拆元/分，`setw(2)<<setfill('0')` 补零，避免浮点输出误差。
- 出发费 `c0` 元转分计入 `tot`（假设 A2）；$n=0$ 时 `dp[1][0]=0` 即目的地，循环不执行，答案 $=c_0$。
