# P2378 因式分解II — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 输入只有一行：一个关于 $x$ 的多项式。它的最高次数不超过 $2$，最高次项系数是 $1$；项数不超过 $3$；按降幂排列；每个系数的绝对值不超过 `maxlongint`（$2^{31}-1$）。输入按"日常写法"给出：系数为 $0$ 的项整个省略，系数为 $1$ 时把 $1$ 省掉，系数为 $-1$ 时写成 `-x`。题面保证这个多项式一定能分解，且分解出来的系数都是整数。

要求输出它的因式分解，同样按日常写法：

- 若写成 $(x+a)(x+b)$，必须有 $a>b$；
- $(x+0)$ 简写成 $x$；
- $(x+a)(x+a)$ 写成 $(x+a)^2$；
- 允许 $(x-3)$，但不允许 $(x+-3)$。

**第一反应：这题的数学只有一行。** 首一整系数二次式若能分解成整数系数的一次因式，一定可以写成
$$x^2+bx+c=(x+p)(x+q),\qquad p+q=b,\ pq=c .$$
找两个整数，和是 $b$、积是 $c$——这就是初中的十字相乘。求它们的标准手段是判别式：把因式乘开得 $b^2-4c=(p-q)^2$，所以 $D=b^2-4c$ 必须是完全平方数，且 $p,q=\dfrac{b\pm\sqrt D}{2}$。数学部分就这样结束了。

**真正的麻烦在两头：解析和输出。** 题目给的不是三个整数，而是一个字符串。日常写法意味着：

- `x^2` 单独出现时，$b=c=0$（**只有一项**，题面温馨提示里专门点了这种情况）；
- `x^2+6` 只有两项，$b=0$；
- `x^2+5x` 只有两项，$c=0$；
- `x^2+x+1` 里 `x` 的系数是 $1$，但那个 $1$ 被省掉了；
- 负号紧贴系数，`-5x`、`-4`。

所以第一步必须写一个**按项扫描**的解析器：先读符号，再读数字（没有数字就是系数 $1$），再看后面跟的是 `x`（可能带 `^2`）还是什么都没有（常数项）。因为项按降幂排列，读到 `x^2` 就填 $a$，读到 `x` 就填 $b$，读到数字就填 $c$，不会错位。

**接着想输出。** 输出规则里最要命的是 $a>b$：它其实是在规定一个**规范序**——两个常数从大到小排。于是：

- $x^2+5x+6=(x+3)(x+2)$，写 `(x+3)(x+2)`（$3>2$）；
- $x^2-5x+6=(x-2)(x-3)$，写 `(x-2)(x-3)`（$-2>-3$）；
- $x^2+5x=x(x+5)$，常数是 $5$ 和 $0$，按 $a>b$ 应写成 `(x+5)x`；
- $x^2-5x=x(x-5)$，常数是 $0$ 和 $-5$，$0>-5$，写成 `x(x-5)`。

后两个例子很有教育意义：同是"缺常数项"，输出里裸 `x` 的位置却不同，完全由 $a>b$ 决定。

**重根怎么办？** $x^2+2x+1=(x+1)^2$，此时 $a=b$，$a>b$ 写不出来，正好由规则 2（$(x+a)(x+a)$ 写成 $(x+a)^2$）接管。极端情形 $x^2=(x+0)^2$：规则 1 把 $(x+0)$ 变成 $x$，规则 2 补上平方，得到 `x^2`，与输入一致——自洽。

**数值上的坑。** 题面特意提示"中间过程会不会超 maxlongint"。哪里会超？$b\le 2^{31}-1$ 时 $b^2\approx4.6\times10^{18}$，已经超出 32 位，所以判别式必须用 64 位算；而 $4c$ 只有 $8.6\times10^9$，反而是小头。$-b$ 也要小心：若 $b=-2^{31}+1$，$-b$ 在 64 位里毫无问题。另外开方要用整数开方并做 $\pm1$ 修正，不能直接信 `sqrt` 的浮点结果。

**退化输入怎么办？** 题面保证最高次系数是 $1$，但"最高次"到底是几次并没写死：如果输入里根本没有 $x^2$ 项（比如 `x+3`、甚至一个常数），那它本身就已经"分解完了"。我的处理是把这种退化情形按日常写法原样输出（代码里的 `poly()`），这样解析器不会崩，也不会输出空行。同理，万一（违反保证地）遇到不可分解的二次式，也回退成原样输出。这两条只是保险丝，正常数据不会触发。

**手造数据核对**（题面无样例，以下均为自造）：

| 输入 | 输出 | 说明 |
|------|------|------|
| `x^2+5x+6` | `(x+3)(x+2)` | 两根 $3,2$，$a>b$ |
| `x^2-5x+6` | `(x-2)(x-3)` | 两根 $-2,-3$，$-2>-3$ |
| `x^2+2x+1` | `(x+1)^2` | 重根 |
| `x^2-4` | `(x+2)(x-2)` | 缺一次项 |
| `x^2` | `x^2` | 只有一项，重根 $0$ |
| `x^2+5x` | `(x+5)x` | 常数 $5>0$ |
| `x^2-5x` | `x(x-5)` | 常数 $0>-5$ |
| `x^2-1` | `(x+1)(x-1)` | 差平方 |
| `x^2+4x+3` | `(x+3)(x+1)` | 两根 $3,1$ |

## 二、思维链：完整证明

下面把"解析正确、求根正确、输出正确"三件事逐条证明。记号约定：输入多项式写成
$$f(x)=a x^2+b x+c\quad(a=1),$$
解析结果存在全局变量 $a,b,c$ 里；求根时记 $D=b^2-4c$，$s=\lfloor\sqrt D\rfloor$（若 $D\ge0$），$p=\dfrac{b+s}{2}$，$q=\dfrac{b-s}{2}$。

**引理 1（解析的语法前提）。** 题目给出的输入串满足：不含空白与括号；由若干个"带符号项"首尾相连组成，符号只出现在两项之间；每个项要么是 $\pm[\text{系数}]x^2$、要么是 $\pm[\text{系数}]x$、要么是 $\pm[\text{系数}]$，其中系数可省略（省略即为 $1$）；各项按 $x^2,x,1$ 的顺序至多各出现一次。

*证明：* 题面明确规定"按降序排列""项数不高于三项""$x$ 的系数为 $1$（或 $-1$）时把 $1$ 省去""系数为 $0$ 的项整个省略"。因此串就是 $0\sim3$ 个合法项按降幂拼接，且形如 $x^2$、$x$ 的项各自最多一个，剩下的只能是常数项。串中不出现空格（题面是标准数学写法）——即便出现，程序的预处理也会先删掉所有空白，不影响下述论证。证毕。

**引理 2（解析器正确）。** 对满足引理 1 的输入串，程序的 `parse` 结束后 $a,b,c$ 恰好等于该多项式的三个系数。

*证明：* 对项的个数归纳。

- 归纳假设：进入某个循环体时，已经处理完前 $j$ 个项，且这 $j$ 个项的贡献已经加到了对应的系数上，当前位置 $i$ 指向下一个项的符号（或串尾）。
- 归纳步：设当前符号位为 $sg$（初始为 $+$）。程序先读连续数字；若一个数字也没读到，按引理 1 的"系数可省略"约定取 $\text{coef}=1$，否则 $\text{coef}$ 就是那串十进制数字的值（注意 $\text{coef}$ 用 64 位累加，位数不超过 $10$ 位，不会溢出）。接着看 $i$ 处字符：
  - 若是 `x`，说明这一项含 $x$。吃掉 `x` 后再看是否紧跟 `^`：若有 `^`，读出指数 $e$，由引理 1 只可能是 $2$，于是把 $\text{coef}\cdot sg$ 加进 $a$；若无 `^`，指数是 $1$，加进 $b$。
  - 否则这一项不含 $x$，把 $\text{coef}\cdot sg$ 加进 $c$。
  然后吃掉分隔符号（`+` 记为 $+1$，`-` 记为 $-1$，若已是串尾则结束）。
- 关键的不错位论证：由引理 1，$x^2$ 项、$x$ 项、常数项在串中最多各出现一次，且按此顺序出现；解析器判定的类别只由"数字后面是否紧跟 `x`（以及 `x` 后面是否紧跟 `^2`）"决定，与位置无关。所以"`x^2` 项 $\to a$、`x` 项 $\to b$、无 $x$ 项 $\to c$"这一映射与真实类别一致，不会把 $x$ 项误记成常数项。
- 再加一层保险：代码用 `a+=`、`b+=`、`c+=` 而不是赋值，即使（违反引理 1）出现同类项重复，结果依然是系数之和，仍然正确。

由归纳，处理完全部项后 $a,b,c$ 即为真实系数。此外，三个系数的初值都是 $0$，恰好对应"该项被省略"的情形，与引理 1 的省略约定一致。证毕。

**引理 3（分解的充要条件）。** 设 $a=1$。存在整数 $p\ge q$ 使 $x^2+bx+c=(x+p)(x+q)$，当且仅当 $D=b^2-4c$ 是完全平方数 $s^2$（$s\ge0$ 为整数）；此时
$$p=\frac{b+s}{2},\qquad q=\frac{b-s}{2}.$$

*证明：*

- 必要性：若 $(x+p)(x+q)=x^2+(p+q)x+pq$ 与 $x^2+bx+c$ 恒等，则 $p+q=b$、$pq=c$，于是 $D=b^2-4c=(p+q)^2-4pq=(p-q)^2$，是完全平方数。
- 充分性：设 $D=s^2$。先证 $b$ 与 $s$ 同奇偶：$b^2-s^2=4c$ 是 $4$ 的倍数，故 $b^2\equiv s^2\pmod 4$；平方数模 $4$ 只能是 $0$ 或 $1$，所以 $b$ 与 $s$ 要么同为偶数、要么同为奇数，即 $b\equiv s\pmod 2$。于是
$$p=\frac{b+s}{2},\quad q=\frac{b-s}{2}$$
都是整数，$p\ge q$，且
$$p+q=b,\qquad pq=\frac{(b+s)(b-s)}{4}=\frac{b^2-s^2}{4}=\frac{4c}{4}=c,$$
即 $x^2+bx+c=x^2+(p+q)x+pq=(x+p)(x+q)$。证毕。

（约定说明：全文与代码统一采用"因式写成 $(x+p)$"的符号约定，$p,q$ 就带上了符号，所以 $x^2-5x+6$ 对应 $p=-2,q=-3$ 而不是 $2,3$。题面里 $a>b$ 的 $a,b$ 就是这里的 $p,q$。）

**引理 4（唯一性）。** 满足 $p+q=b$、$pq=c$ 的整数对 $\{p,q\}$ 若存在则唯一（作为无序对）。

*证明：* 若 $p+q=b,pq=c$，则对 $t\in\{p,q\}$ 有 $t^2-bt+c=t^2-(p+q)t+pq=(t-p)(t-q)=0$，即 $p,q$ 都是 $t^2-bt+c=0$ 的根。二次方程在整数范围内的根集（计重数）唯一：若 $p\ne q$，则它恰有两个不同的根 $p,q$，任何另一对整数解也只能是这两个；若 $p=q$，则 $t^2-bt+c=(t-p)^2$，唯二重根为 $p$。故无序对唯一。证毕。

由引理 3、4，程序的求根算法（算 $D$、判完全平方、取 $p,q$）既不漏解也不错解，且输出的常数集合是唯一确定的。

**引理 5（整数开方正确）。** 设 $D\ge0$，且 $D< 2^{63}$。函数 `isqrt` 返回 $\lfloor\sqrt D\rfloor$。

*证明：* 记 $s_0=\lfloor\sqrt D\rfloor$，$s_1$ 为 `sqrtl` 给出的浮点值取整。`long double` 在 x86 上有 64 位有效位，$\sqrt D\le 2^{32}$，其相对误差不超过 $2^{-63}$，故 $|s_1-s_0|\le1$（若浮点值恰好落在整数边界下方，向下取整后可能比 $s_0$ 小 1；落在上方则可能大 1）。第一个 `while` 用条件 $s^2>D$ 把 $s$ 一路减到 $s\le s_0$；第二个 `while` 用条件 $(s+1)^2\le D$ 把 $s$ 一路增到 $(s+1)^2>D$。两个循环的判定都是精确的整数比较（引理 6 保证 $b$ 与 $D$ 的量级使 $(s+1)^2<2^{63}$），最终停在"$s^2\le D<(s+1)^2$"，即 $s=\lfloor\sqrt D\rfloor$。由于初值与真值相差不超过 $1$，循环至多执行常数次。证毕。

**引理 6（数值范围安全）。** 设 $|b|,|c|\le2^{31}-1$。则 $D=b^2-4c$ 落在 $[-2^{33},\,4.63\times10^{18}]$ 内，$|p|,|q|<2^{32}$，全部可用带符号 64 位整数表示。

*证明：* $b^2\le(2^{31}-1)^2<4.612\times10^{18}$，$|4c|\le2^{33}\approx8.59\times10^9$，故 $D<4.6121\times10^{18}<2^{63}-1\approx9.22\times10^{18}$，下界为 $-2^{33}$。又 $s=\sqrt D<\sqrt{4.6121\times10^{18}}<2.148\times10^9$，$|b|<2.148\times10^9$，故 $|p|,|q|=\left|\frac{b\pm s}{2}\right|<2.148\times10^9<2^{32}$。中间量 $s^2$、$(s+1)^2$、$b^2$ 都不超过 $4.7\times10^{18}<2^{63}$。证毕。

**引理 7（单个因式的打印正确）。** 记 `term(k)` 的输出为 $T(k)$。则 $T(0)=$ `x`，$T(k)=$ `(x+k)`（$k>0$），$T(k)=$ `(x-k)`（$k<0$），并且把 $T(k)$ 看作数学表达式时恒等于 $x+k$。

*证明：* 三种情形分别展开：$k=0$ 时 $x+0=x$；$k>0$ 时 `(x+k)` 就是 $x+k$；$k<0$ 时 `to_string(-k)` 输出的是 $|k|$ 的十进制，故 `(x-k)` 表示 $x-|k|=x+k$。另外由引理 6，$|k|<2^{32}$，`-k` 不会溢出。证毕。这里顺带满足了"不能出现 $(x+-3)$"：负数一律走 $k<0$ 分支，符号只出现一次。

**引理 8（整体输出正确）。** 对任意合法的、可整数分解的输入，程序输出串所表示的数学表达式恰为输入多项式，且满足题面的排版规范。

*证明：* 分情形。

1. $p\ne q$：输出 `term(p)+term(q)`。由引理 7，其值为 $(x+p)(x+q)=x^2+bx+c$，等于输入多项式（引理 3 的充分性方向）。排序：由引理 3，$p\ge q$，故第一个因式的常数不小于第二个，满足 $a>b$。若 $q=0$（此时必有 $p>0$），第二个因式打印成裸 `x`，输出形如 `(x+5)x`，常数序列 $(5,0)$ 仍是降序，满足规则 1；若 $p=0$（此时必有 $q<0$），第一个因式是裸 `x`，输出形如 `x(x-5)`，常数序列 $(0,-5)$ 也是降序。中间不可能出现 `(x+0)`。
2. $p=q$：输出 `term(p)+"^2"`。由引理 7，值为 $(x+p)^2=x^2+2px+p^2$，而 $b=2p,c=p^2$，等于输入多项式；排版上满足规则 2。$p=0$ 时输出 `x^2`，即 $(x+0)^2$ 按规则 1、2 化简的结果，值为 $x^2$，与输入 $x^2$ 一致。
3. $a=0$ 或 $D$ 非完全平方（违反题面保证的退化情形）：输出 `poly()`，逐项按日常写法拼出 $a x^2+b x+c$，值与输入相同（同引理 2 的对应关系反向拼装），排版亦合法。

三种情形下输出都不是空串（`poly()` 在 $a=b=c=0$ 时输出 `0`），且都不含 `+-`、`(x+0)`。证毕。

**定理（正确性）。** 对题面保证范围内的输入，程序输出唯一正确且合规的分解式。

*证明：* 由引理 2，$a,b,c$ 解析正确；由引理 3、4，$p,q$ 存在且唯一，程序求出它们；由引理 5、6，求根在数值上精确无溢出；由引理 8，输出表达式等于输入多项式且排版合规；由引理 4 的唯一性，任何正确分解式的常数无序对都等于 $\{p,q\}$，再结合 $a>b$ 的规范序（重根时用 `^2`），正确输出串是唯一的。证毕。

**引理 9（复杂度）。** 设输入串长度为 $L$（本题 $L\le40$）。时间复杂度 $O(L)$，空间复杂度 $O(L)$。

*证明：* 预处理扫一遍串、解析再扫一遍，每步 $O(1)$，共 $O(L)$；开方是常数次整数运算。空间只有串本身与几个 64 位变量。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 题目给的是"日常写法"的表达式串而不是系数三元组，解析本身就是一半的工作量。
2. **reduce to easier problem** — 首一整系数二次式分解 $\iff$ 找两个整数 $p+q=b,\ pq=c$（十字相乘/Vieta）。
3. **classic problem solution** — 用判别式 $D=b^2-4c$ 判完全平方求出 $p,q$，这是"整数根"问题的标准判定。
4. **explore its property** — 输出规则 $a>b$ 实际上规定了"常数从大到小"的规范序，连缺项时裸 `x` 的位置也被它决定。
5. **discuss by category** — 按 $p=q$（写 `^2`）、$q=0$（写裸 `x`）、常数正负、次数退化分类讨论输出。
6. **classic problem solution** — 中间量 $b^2$ 会超 32 位，必须 64 位 + 整数开方修正，呼应题面"会不会超 maxlongint"的提示。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `a` | $x^2$ 的系数（题面保证为 $1$） | `i64` | 每个串清 $0$；解析时 `+=` |
| `b` | $x$ 的系数 | `i64` | 清 $0$；解析时 `+=` |
| `c` | 常数项 | `i64` | 清 $0$；解析时 `+=` |
| `str` | 去掉空白后的输入串 | `string` | 由 `getline` 后的整行删除 `isspace` 得到 |
| `d` | 判别式 $b^2-4c$ | `i64` | 由 `b,c` 现算 |
| `rt` | $\lfloor\sqrt{\max(d,0)}\rfloor$ | `i64` | 由 `isqrt` 得出 |
| `p,q` | 两个因式的常数，约定 $(x+p)(x+q)$，$p\ge q$ | `i64` | `p=(b+rt)/2`，`q=(b-rt)/2` |
| `term(k)` | 返回因式 `(x+k)` 的日常写法，$k=0$ 返回裸 `x` | 函数 | 负数走 `-` 分支，杜绝 `+-` |
| `poly()` | 把当前 $ax^2+bx+c$ 按日常写法拼回原式 | 函数 | 只作退化情形的兜底 |

### 算法步骤

1. I/O 加速三行（`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`）。
2. `while(getline(cin,line))` 读入一行；把其中所有空白字符删掉得到 `str`；`str` 为空则跳过（防止行尾空行）。
3. 置 `a=b=c=0`，调用 `parse(str)`：反复读"符号 + 可选数字 + 可选 `x`/`x^2`"，把系数累加到 `a`（`x^2` 项）、`b`（`x` 项）、`c`（常数项）。
4. 若 `a==0`：输出 `poly()`，处理下一个串（退化情形，正常数据不触发）。
5. 算 `d=b*b-4*c`；若 `d<0`，输出 `poly()`。
6. `rt=isqrt(d)`；若 `rt*rt!=d`，输出 `poly()`。
7. `p=(b+rt)/2`，`q=(b-rt)/2`。
8. 若 `p==q` 输出 `term(p)` 后接 `^2`，否则输出 `term(p)` 接 `term(q)`；换行。
9. 若输入还有下一行，回到步骤 2（题面只给一个多项式，本循环只用于容错）。

### 复杂度

- 时间：$O(L)$，$L$ 为输入串长度（$\le40$），$L$ 的量级下常数可忽略。
- 空间：$O(L)$，只有输入串与若干 64 位标量。

### 验证状态

- 编译：`g++ -std=c++20 -O2 -Wall` 无警告无错误。
- 题面无样例，自造 9 组小数据（见第一节表格）全部得到预期输出，含 `x^2`、`x^2±5x`、`x^2±5x+6`、`x^2-4`、`x^2±2x+1`。
- 对拍：随机生成 $p,q\in[-200,200]$，用四种书写风格（全项 / 省略零项 / 显式 `+0x` / 带空格）拼出输入，把程序输出用独立解析器拆回常数多重集，要求与 $\{p,q\}$ 相同且按非增序排列，**400 组全部一致**。
- 额外手工核对 64 位边界：`x^2±2147483647x` 输出 `(x+2147483647)x` / `x(x-2147483647)`，未溢出。
- 疑虑：题面无样例，缺常数项时 `(x+5)x` 与 `x(x+5)` 谁是被判定的标准答案无法从题面以外的渠道确认；本实现严格按"若写成 $(x+a)(x+b)$ 则 $a>b$"取常数降序。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2378 因式分解II
// 思路：把"日常写法"的串解析成 a*x^2+b*x+c（题面保证 a=1），
//       再用判别式 D=b^2-4c 找整数根 p>=q，使 x^2+bx+c=(x+p)(x+q)；
//       输出按题面规范：常数从大到小，(x+0) 写成 x，重根写成 ^2。
//       中间量 b^2 会超 32 位，必须 64 位 + 整数开方修正。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 a,b,c;			// a*x^2+b*x+c，题面保证 a=1

// 把 "(x+k)" 写成日常形式：k=0 时就是 "x"
string term(i64 k)
{
	if(k==0)
		return "x";
	if(k>0)
		return "(x+"+to_string(k)+")";
	return "(x-"+to_string(-k)+")";
}

// 把当前多项式按日常写法拼回去（用于理论上不会出现的退化输入）
string poly()
{
	string r;
	if(a!=0)
	{
		if(a==1)
			r+="x^2";
		else if(a==-1)
			r+="-x^2";
		else
			r+=to_string(a)+"x^2";
	}
	if(b!=0)
	{
		if(!r.empty()&&b>0)
			r+="+";
		if(b==1)
			r+="x";
		else if(b==-1)
			r+="-x";
		else
			r+=to_string(b)+"x";
	}
	if(c!=0)
	{
		if(!r.empty()&&c>0)
			r+="+";
		r+=to_string(c);
	}
	if(r.empty())
		r="0";
	return r;
}

i64 isqrt(i64 x)
{
	i64 s=(i64)sqrtl((long double)x);
	while(s>0&&s*s>x)
		--s;
	while((s+1)*(s+1)<=x)
		++s;
	return s;
}

// 逐项扫描：符号 + 可选数字 + 可选 x[^2]
void parse(const string&s)
{
	int n=s.size(),i=0,sg=1;
	if(i<n&&(s[i]=='-'||s[i]=='+'))
	{
		if(s[i]=='-')
			sg=-1;
		++i;
	}
	while(i<n)
	{
		i64 coef=0;
		bool hn=false;
		while(i<n&&isdigit((unsigned char)s[i]))
		{
			coef=coef*10+(s[i]-'0');
			hn=true;
			++i;
		}
		if(!hn)					// 系数省略 ⇒ 1
			coef=1;
		if(i<n&&s[i]=='x')
		{
			++i;
			int e=1;
			if(i<n&&s[i]=='^')
			{
				++i;e=0;
				while(i<n&&isdigit((unsigned char)s[i]))
				{
					e=e*10+(s[i]-'0');
					++i;
				}
			}
			if(e==2)
				a+=coef*sg;
			else if(e==1)
				b+=coef*sg;
		}
		else
			c+=coef*sg;
		if(i<n)
		{
			if(s[i]=='-')
				sg=-1;
			else
				sg=1;
			++i;
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	string line;
	while(getline(cin,line))
	{
		string str;
		for(char ch:line)
			if(!isspace((unsigned char)ch))
				str+=ch;
		if(str.empty())
			continue;
		a=b=c=0;
		parse(str);
		if(a==0)				// 退化：本来就不到二次
		{
			cout<<poly()<<'\n';
			continue;
		}
		i64 d=b*b-4*c;			// 必须 64 位
		i64 rt=isqrt(d<0?0:d);
		if(d<0||rt*rt!=d)		// 题面保证可分解，这里只是保险丝
		{
			cout<<poly()<<'\n';
			continue;
		}
		i64 p=(b+rt)/2,q=(b-rt)/2;	// p>=q，天然满足题面 a>b 的规范序
		if(p==q)
			cout<<term(p)<<"^2\n";
		else
			cout<<term(p)<<term(q)<<'\n';
	}
	return 0;
}
```

### 代码说明

- `parse` 按引理 1、2 的语法扫描：系数可省略（取 $1$），`x` 后可带 `^2`；用 `+=` 累加使重复项不至于出错。
- 三个系数的"归属"只取决于该数字后面是否紧跟 `x`，与位置无关，这是解析不会错位的根本原因。
- `d=b*b-4*c` 用 `i64`：$b=2^{31}-1$ 时 $b^2\approx4.6\times10^{18}$，32 位会溢出，题面的提示正指此处。
- `isqrt` 用 `sqrtl` 起步再加 $\pm1$ 修正，保证精确（引理 5）。
- `term` 把三种符号情形分开写，负数用 `(x-3)` 而不是 `(x+-3)`；`k=0` 直接返回裸 `x`，对应"$(x+0)$ 写成 $x$"。
- `p>=q` 由 $rt\ge0$ 保证，所以输出顺序天然满足 $a>b$；重根走 `^2` 分支，`p==0` 时 `term(0)` 是 `x`，输出 `x^2`。
- `poly()` 只服务于两类题面保证不会出现的输入（次数 $<2$、不可整数分解），保证程序不会输出空行或崩溃。
- 用 `while(getline(...))` 逐行处理，既能在正常单行输入下只输出一行，也能容忍多余的空行。
