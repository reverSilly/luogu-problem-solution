# P2752 [USACO4.3] 街道赛跑Street Race — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一张有向图描述"良好跑道"：路口编号 $0..N$（最多 $50$ 个路口、$100$ 条单行道），满足 (1) 每个路口都能从起点 $0$ 到达；(2) 从每个路口都能到达终点 $N$；(3) $N$ 没有出边。求两个集合（都不含 $0$ 和 $N$，升序输出）：

- **不可避免路口**：任何从 $0$ 到 $N$ 的路线都必须经过的路口；
- **中间路口**：能把整张跑道**划分**成两条良好跑道的路口 $S$——第一天 $0\to S$，第二天 $S\to N$，两半**没有公共街道**、**唯一公共路口是 $S$**，且 $S$ 是第一半的终点、第二半的起点。

**输入有个小机关**：不直接给 $N$。共 $N+2$ 行：前 $N+1$ 行依次是路口 $0..N$ 的出边表，每行以 `-2` 结尾；最后一行只有 `-1`。所以按 token 读入，数 `-2` 的个数就能定出 $N$（`-2` 出现 $N+1$ 次）。

**第一问几乎是定义的直接翻译。** "每条 $0\to N$ 路线都经过 $S$" 的反面是"存在一条避开 $S$ 的路线"。于是：**删掉 $S$，从 $0$ 做 BFS，若 $N$ 不再可达，$S$ 就是不可避免路口**。$N\le50$，对每个候选删点跑一次 BFS，总共 $O(N(N+M))\approx7500$ 次操作，随便过。

**第二问的第一直觉是错的。** 我最初猜："中间路口 = 不可避免 + 每条路线**恰好经过一次** $S$"。毕竟要分成两天，经过两次听起来就没法分。但构造一个反例就推翻了它：

$$0\to1,\quad 1\to2,\quad 2\to1,\quad 1\to3\qquad(N=3,\ S=1)$$

路线 $0\to1\to2\to1\to3$ 经过 $1$ 两次。但划分完全合法：第一天 $\{0\to1\}$；第二天 $\{1\to2,\ 2\to1,\ 1\to3\}$——环 $1\to2\to1$ **整个归第二天**，第二天里 $2$ 从起点 $1$ 可达、也能到终点 $3$（$2\to1\to3$），三条良好条件全满足。所以"经过两次"根本不是障碍，障碍在别处。

**回到定义，抓住"划分"这个词。** 划分意味着：每条街道恰好归一天，每个路口（除 $S$）恰好归一天。第一个关键观察：**一条街道的两个端点必须在同一半（或其中一个是 $S$）**——否则这条街道连接了两个不同半的路口，它既不能算第一半的街道（端点不在第一半），也不能算第二半的，无处安放。即：**不存在跨越两半的边**。

**第二个关键观察：划分其实是被迫唯一的。** 记 $A$ 为"删掉 $S$ 后从 $0$ 可达的点集"。

- $A$ 里的点**必须**归第一半：从 $0$ 到 $v\in A$ 有条避开 $S$ 的路，路上没有 $S$ 可以"换半"，又没有跨越边，所以整条路都在第一半，$v$ 跑不掉。
- 第一半**只能**有 $A$ 里的点：第一半是良好跑道，每个点需要从 $0$ 在第一半内部可达；而 $S$ 是第一半的**终点，不许有出边**，所以这条可达路径不可能途经 $S$ 再出来——它是一条避开 $S$ 的路，终点自然在 $A$ 里。

于是第一半的点集恰好是 $A\cup\{S\}$，第二半是其余所有点；街道归属也随之唯一（端点都在 $A\cup\{S\}$ 的边只能归第一半，其余归第二半）。**"存在划分吗"被归约成了"这个唯一候选划分良好吗"**——不用搜索任何方案！

**最后一步：逐项检查唯一候选的良好性。** 大部分条件自动成立（下面引理 2 会证：$A$ 中每个点都能在 $A\cup\{S\}$ 内部走到 $S$；$S$ 能在第二半内部走到每个点）。真正可能出问题的只有：

1. **有边从 $A$ 外面指进 $A$**（包括 $S\to A$ 的"回头边"）：这种边是跨越边，两半都放不下。反例：$0\to1\to2\to3$ 加一条 $2\to1$，$S=2$ 时 $A=\{0,1\}$，边 $2\to1$ 指进 $A$——第一半若收下它，终点 $2$ 就有了出边，违反良好条件 (3)。
2. **$S$ 有自环**：自环两端都是 $S$，会被迫归第一半，同样让终点有出边。

再加上"$S$ 不可避免"（$N\notin A$），就是完整刻画。顺带一提，题目图例里 $6$ 是不可避免路口却不是中间路口，正是这类"回头边/指进 $A$ 的边"在作怪。

**手造数据核对**（题面只有图没有样例输入输出，我按图例描述重构了一张图，另造五组打各种边界）：

## 二、思维链：完整证明

**记号。** $G=(V,E)$，$V=\{0,1,\dots,N\}$，$N\le49$，$|E|\le100$。良好跑道三条件：(G1) $0$ 可达每个点；(G2) 每个点可达 $N$；(G3) $N$ 出度为 $0$。对 $S\in V\setminus\{0,N\}$，$G-S$ 表示删去 $S$ 及其关联边后的图，$A=A(S)=\{v:0\text{ 在 }G-S\text{ 中可达 }v\}$（含 $0$，不含 $S$）。

**定义（划分）。** $S$ 的一个**合法划分**是 $(V_1,E_1),(V_2,E_2)$，满足：$V_1\sqcup V_2=V\setminus\{S\}$，$0\in V_1$，$N\in V_2$；$E_1\sqcup E_2=E$；$E_1$ 的边端点都在 $V_1\cup\{S\}$ 内、$E_2$ 的边端点都在 $V_2\cup\{S\}$ 内；$C_1=G[V_1\cup\{S\}]$ 是以 $0$ 为起点、$S$ 为终点的良好跑道，$C_2=G[V_2\cup\{S\}]$ 是以 $S$ 为起点、$N$ 为终点的良好跑道。（"良好"即 G1–G3 对各自起终点成立。）$S$ 是**中间路口** $\iff$ 存在合法划分。

**定义（不可避免）。** $S$ 不可避免 $\iff$ 每条 $0\to N$ 的路线都经过 $S$。路线允许重复经过路口（walk）；由于任何 walk 可删环成 path、任何 path 也是 walk，"存在避开 $S$ 的 walk" $\iff$ "存在避开 $S$ 的 path"，下文统一用 path。

---

### 引理 1（不可避免 $\iff$ 删点断连）

对 $S\ne0,N$：$S$ 不可避免 $\iff$ $G-S$ 中 $0$ 不可达 $N$ $\iff N\notin A(S)$。

*证明*：$S$ 不避免 $\iff$ 存在一条 $0\to N$ 的路线不经过 $S$ $\iff$ 该路线是 $G-S$ 中的一条 $0\to N$ path $\iff$ $G-S$ 中 $0$ 可达 $N$。第一个等价是定义取反；第二个等价因为"不经过 $S$"的路线恰好就是 $G-S$ 中的路线（walk/path 等价见上）；第三个是可达性定义。而 $G-S$ 中 $0$ 可达 $N$ 即 $N\in A(S)$。证毕。

（$0$ 与 $N$ 本身平凡地不可避免——每条路线都含起终点——但题目要求输出时排除，故只枚举 $1..N-1$。）

---

### 引理 2（$A$ 的四条结构性质）

设 $S$ 不可避免（$N\notin A$）。则：

(a) **出边封闭**：$A$ 中点的出边只指向 $A\cup\{S\}$；
(b) **$A$ 内部可达 $S$**：每个 $v\in A$ 在 $G[A\cup\{S\}]$ 中可达 $S$；
(c) **$S$ 在第二半内部可达一切**：每个 $v\notin A$（$v\ne S$）在 $G[V\setminus A]$ 中从 $S$ 可达；
(d) $0\in A$，$S\notin A$，$N\notin A$。

*证明*：(d) 由定义与引理 1 直接成立。

(a) 设 $u\in A$，边 $u\to w$，$w\ne S$。$0$ 在 $G-S$ 中可达 $u$，接上边 $u\to w$（$w\ne S$，边在 $G-S$ 中）得 $0$ 在 $G-S$ 中可达 $w$，故 $w\in A$。

(b) 取 $v\in A$。由 G2，$G$ 中有 $v\to N$ 的 path；$S$ 不可避免，该 path 必经过 $S$。取**第一次**到达 $S$ 的前缀：$v\to\cdots\to S$，内部点都不是 $S$。对任一内部点 $u$：$0$ 在 $G-S$ 中可达 $v$（$v\in A$），接上 $v\to\cdots\to u$（避开 $S$）得 $u\in A$。故整条前缀落在 $G[A\cup\{S\}]$ 内，$v$ 在其中可达 $S$。

(c) 取 $v\notin A$，$v\ne S$。由 G1，$G$ 中有 $0\to v$ 的 path；$v\notin A$ 说明它必经过 $S$（否则 $v\in A$）。取**最后一次**离开 $S$ 的后缀：$S\to\cdots\to v$，内部点都不是 $S$。对任一内部点 $u$：若 $u\in A$，则 $u$ 在 $G-S$ 中从 $0$ 可达，接上 $u\to\cdots\to v$（避开 $S$）得 $v\in A$，矛盾。故内部点全在 $V\setminus A$，整条后缀落在 $G[V\setminus A]$ 内。证毕。

---

### 引理 3（中间 $\Rightarrow$ 不可避免）

若 $S$ 是中间路口，则 $S$ 不可避免。

*证明*：取任一合法划分。$G$ 中任一条 $0\to N$ path：起点 $0\in V_1$，终点 $N\in V_2$。沿 path 走，点的归属从 $V_1$ 变到 $V_2$；相邻两点由一条边连接，而**跨越边不存在**（端点分属 $V_1,V_2$ 的边既不能进 $E_1$ 也不能进 $E_2$，与 $E_1\sqcup E_2=E$ 矛盾），所以归属不可能在相邻两点间直接切换；唯一同时属于两半的点是 $S$。故 path 必经过 $S$。证毕。

---

### 引理 4（划分被迫唯一，核心）

设 $S$ 不可避免且存在合法划分 $(V_1,E_1),(V_2,E_2)$。则必有
$$V_1=A,\quad V_2=V\setminus(A\cup\{S\}),\quad E_1=E\bigl(G[A\cup\{S\}]\bigr),\quad E_2=E\setminus E_1.$$

*证明*：分四步。

**第一步：无跨越边。** 若边 $u\to w$ 满足 $u\in V_1,w\in V_2$（或反向），则它进 $E_1$ 要求 $w\in V_1\cup\{S\}$（假），进 $E_2$ 要求 $u\in V_2\cup\{S\}$（假），与每条边恰归一半矛盾。故任何边的两端点同属 $V_1\cup\{S\}$ 或同属 $V_2\cup\{S\}$。

**第二步：$A\subseteq V_1$。** 取 $v\in A$，$G-S$ 中有 $0\to v$ path。沿该 path 归纳：$0\in V_1$；若当前点在 $V_1$，下一条边的终点不能是 $V_2$ 的点（第一步，且 path 避开 $S$），故仍在 $V_1$。于是 $v\in V_1$。

**第三步：$V_1\subseteq A$。** 取 $v\in V_1$。$C_1$ 良好（G1），$C_1$ 中有 $0\to v$ path。$S$ 是 $C_1$ 的终点，由 G3 在 $C_1$ 中出度为 $0$，故该 path 一旦到达 $S$ 就无法继续；$v\ne S$（$S\notin V_1$），所以 path 全程避开 $S$。它是 $G-S$ 中的 $0\to v$ path，故 $v\in A$。

结合第二、三步 $V_1=A$，$V_2=V\setminus(A\cup\{S\})$。

**第四步：边归属唯一。** 两端都在 $A$ 内的边：端点属 $V_1$，进 $E_2$ 要求端点属 $V_2\cup\{S\}$（不交，假），故必进 $E_1$。$u\in A\to S$ 的边同理必进 $E_1$。$S\to w$（$w\in A$）的边与 $S$ 自环：若存在，它们端点在 $A\cup\{S\}$ 内只能进 $E_1$，使 $S$ 在 $C_1$ 中有出边，违反 G3——故合法划分存在时这两种边**不存在**。于是 $E_1$ 恰为 $G[A\cup\{S\}]$ 的全部边，$E_2$ 为其余边。证毕。

---

### 引理 5（障碍的必要条件）

若 $S$ 是中间路口，则：(i) 不存在边 $u\to v$ 满足 $u\notin A,v\in A$；(ii) $S$ 无自环。

*证明*：设存在合法划分，由引理 4，$V_1=A,V_2=V\setminus(A\cup\{S\})$。

(i) 边 $u\to v$，$u\notin A,v\in A$：若 $u=S$，则该边端点在 $A\cup\{S\}$ 内，被迫归 $E_1$，$S$ 在 $C_1$ 中有出边，违反 G3；若 $u\ne S$，则 $u\in V_2,v\in V_1$，是跨越边，违反引理 4 第一步。两种情形都矛盾。

(ii) $S$ 自环两端都是 $S$，归 $E_1$ 则 $S$ 在 $C_1$ 有出边（违反 G3）；归 $E_2$ 则它是 $C_2$ 的边，但 $C_1=G[A\cup\{S\}]$ 也含它（端点在 $A\cup\{S\}$ 内），成为公共街道，违反"无公共街道"。矛盾。证毕。

---

### 引理 6（充分性：无障碍则唯一候选合法）

设 $S$ 不可避免（$N\notin A$），且 (i) 无边 $u\to v$ 满足 $u\notin A,v\in A$，(ii) $S$ 无自环。则取
$$C_1=G[A\cup\{S\}],\qquad C_2=G[V\setminus A]$$
（各取诱导子图的全部边）构成合法划分。

*证明*：逐项验证定义中的每个条件。

**点划分**：$(A)\sqcup(V\setminus(A\cup\{S\}))=V\setminus\{S\}$ ✓；$0\in A=V_1$ ✓；$N\notin A\Rightarrow N\in V_2$ ✓；两半公共点恰 $\{S\}$ ✓。

**边划分**：$E_1=E(G[A\cup\{S\}])$，$E_2=E(G[V\setminus A])$。不交：公共边需两端点同时在 $A\cup\{S\}$ 与 $V\setminus A$ 内，即两端都是 $S$——$S$ 自环，已被 (ii) 排除 ✓。覆盖：任取边 $u\to v$。若 $u\in A$，由引理 2(a)，$v\in A\cup\{S\}$，边在 $E_1$ ✓。若 $u\notin A$：$v\in A$ 被 (i) 排除，故 $v\notin A$，边在 $E_2$ ✓。每条边恰归一半 ✓。

**$C_1$ 良好**（起 $0$ 终 $S$）：
- G1：对 $v\in A$，$G-S$ 中的 $0\to v$ path 全程在 $A$ 内（路上每点都在 $G-S$ 中从 $0$ 可达），即在 $C_1$ 内 ✓；$0\to S$：$G$ 中存在（G1），取简单 path，它避开 $S$ 的内部（简单性），内部点在 $A$ 内，故在 $C_1$ 内 ✓。
- G2：引理 2(b)，每个 $v\in A$ 在 $C_1$ 内可达 $S$ ✓（$S$ 自身平凡）。
- G3：$S$ 在 $C_1$ 中的出边只能是 $S\to w,w\in A$（自环已排除），被 (i)（$u=S\notin A$）排除，故出度 $0$ ✓。

**$C_2$ 良好**（起 $S$ 终 $N$）：
- G1：引理 2(c)，每个 $v\notin A$ 在 $C_2$ 内从 $S$ 可达 ✓。
- G2：取 $v\notin A$，$G$ 中有 $v\to N$ path（G2）。该 path 从 $A$ 外出发，而 (i) 禁止任何边从 $A$ 外指进 $A$，故 path **永远进不了 $A$**，全程在 $V\setminus A$ 内，即在 $C_2$ 内 ✓。
- G3：$N$ 在 $G$ 中出度 $0$（原图 G3），在子图中更是 $0$ ✓。

**$S$ 的角色**：$C_1$ 终点、$C_2$ 起点 ✓。全部条件满足，是合法划分。证毕。

---

### 定理（中间路口的刻画）

对 $S\in\{1,\dots,N-1\}$，记 $A$ 为 $G-S$ 中 $0$ 的可达集。则
$$S\text{ 是中间路口}\iff N\notin A\ \land\ \bigl[\nexists\,u\to v\in E:u\notin A,v\in A\bigr]\ \land\ S\text{ 无自环}.$$

*证明*：（$\Rightarrow$）中间 $\Rightarrow$ 不可避免（引理 3）$\Rightarrow N\notin A$（引理 1）；障碍条件由引理 5。（$\Leftarrow$）引理 6 直接构造合法划分。证毕。

**注（并行边与它点自环）**：重边不影响任何论证（每条边独立归属，条件按边逐条检查）；非 $S$ 点的自环落在自己所属半内，不违反 G1–G3，无需特判。程序对 $S$ 自环显式设防，其余情形定理已覆盖。

---

### 引理 7（输入解析）

按 token 读入，遇 `-2` 计数加一、遇 `-1` 停止，则停止时计数值 $=N+1$，且第 $k$ 个 `-2` 之前读入的正整数恰为路口 $k-1$ 的出边终点。

*证明*：题面保证前 $N+1$ 行依次是路口 $0..N$ 的出边表、每行以 `-2` 结尾，最后一行仅 `-1`。token 流即：$[\text{路口 }0\text{ 的终点}]\,{-2}\,[\text{路口 }1\text{ 的终点}]\,{-2}\,\cdots\,[\text{路口 }N\text{ 的终点（空）}]\,{-2}\,{-1}$。故 `-2` 恰出现 $N+1$ 次；已读入的 `-2` 个数就是"当前正在读哪个路口"的编号（$0$-based）。程序用 `cur` 维护该计数，读到的终点 $x$ 挂到 `graph[cur]`，停止时 `n=cur-1=N`。空白与换行被 `cin>>` 自动跳过，行结构无关。证毕。

### 引理 8（复杂度）

时间 $O(N(N+M))$，空间 $O(N+M)$。

*证明*：候选 $S$ 共 $N-1$ 个。每个：一次 BFS $O(N+M)$；一次全边扫描 $O(M)$（$S$ 自环检查 $O(\deg S)\subseteq O(M)$）。合计 $O(N(N+M))\le50\times(50+100)=7500$ 量级。存图 $O(N+M)$，`vis` $O(N)$，输出列表 $O(N)$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 输入不显式给 $N$：数 `-2` 的个数定出 $N$，token 式读入与行结构无关。
- **reduce to easier problem** — 不可避免 $\iff$ 删掉 $S$ 后 $0$ 不可达 $N$：把"所有路线都经过"翻译成一次可达性判定。
- **classic problem solution** — BFS 可达性，每个候选 $O(N+M)$，总 $O(N(N+M))$。
- **explore its property** — 反例推翻直觉"恰好经过一次 $S$"：环 $S\to w\to S$ 可整体归第二半，经过两次不妨碍划分。
- **explore its property** — 划分要求每条街道恰归一半 ⇒ 街道两端点必须同半（$\cup\{S\}$）⇒ 无跨越边。
- **reduce to easier problem** — 划分被迫唯一：$A\subseteq V_1$（避 $S$ 的路无法换半）且 $V_1\subseteq A$（$C_1$ 中 $S$ 无出边，可达路不能途经 $S$）⇒ 存在性归约为唯一候选划分的良好性检查。
- **discuss by category** — 逐项检查两半良好性：多数由结构性质自动成立；障碍仅剩"从 $A$ 外指进 $A$ 的边"与 $S$ 自环。
- **classic problem solution** — BFS 求 $A$ + 全边扫描查障碍，$O(N(N+M))$ 收工。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 终点编号 $N$ | `int` | 由 `-2` 计数减 $1$ 得到，非读入 |
| `graph[u]` | 路口 $u$ 的出边终点表 | `vector<int>[mxn]` | 读入时 `cur` 即当前路口 |
| `vis[v]` | BFS 后：$v$ 是否属于 $A$（$G-S$ 中 $0$ 可达） | `bool[mxn]` | 每次 BFS 前 `fill_n` 清零；`vis[s]` 恒假 |
| `bfs(s,ban)` | 从 `s` 出发、避开 `ban` 的可达集写入 `vis` | `void` | `ban=-1` 表示无禁点 |
| `unav` | 不可避免路口列表 | `vector<int>` | 升序（按 `s=1..n-1` 枚举） |
| `mid` | 中间路口列表 | `vector<int>` | 先过不可避免关，再查障碍 |
| `mxn` | $50+5$ | `constexpr int{55}` | 路口数上界 $50$ |

### 算法步骤

1. I/O 加速三行；token 循环读入：`-2` 则 `++cur`，`-1` 则停，否则 `graph[cur].push_back(x)`；`n=cur-1`。
2. 对 `s=1..n-1`：`bfs(0,s)` 得 $A$（`vis`）。
3. 若 `vis[n]` 真：$S$ 可避免，跳过。否则记入 `unav`。
4. 障碍检查：$S$ 自环 ⇒ 否；存在边 `u→v` 使 `!vis[u]&&vis[v]` ⇒ 否（$S\to A$ 的回头边也在此被捕获，因 `vis[s]` 恒假）。
5. 无障碍则记入 `mid`。
6. 第一行输出 `unav.size()` 及元素（空格分隔），第二行同法输出 `mid`。

### 复杂度

- 时间：$O(N(N+M))\le50\times150=7500$ 量级。
- 空间：$O(N+M)$。
- 正确性：定理（引理 1–6）给出中间路口的充要刻画；引理 7 保证解析正确。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；$6$ 组手造数据全对（含按图例描述重构的 $10$ 路口图：不可避免 $3,6$、中间仅 $3$，与题面"只有路口 $3$ 是中间路口"吻合；另覆盖链、菱形、$S\to w\to S$ 环、$S\to A$ 回头边、它点指进 $A$ 五类边界）；刻画与"枚举全部点划分 + 逐半验证良好性"的独立暴力在 $2000$ 张随机良好跑道（路口数 $\le7$）上逐点一致，$0$ mismatch（`appendix/P2752/verify.cpp`）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2752 [USACO4.3] 街道赛跑Street Race
// 不可避免点：删去 S 后 0 不再能到达 N。
// 中间路口：S 不可避免，且记 A 为 G-S 中 0 可达点集，
//           不存在 u∉A → v∈A 的边（这种边无法划分给任何一半），且 S 无自环。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{55};

int n;
vector<int>graph[mxn];
bool vis[mxn];

void bfs(int s,int ban)	// vis = 从 s 出发、不经过 ban 的可达点集；ban=-1 表示无禁点
{
	fill_n(vis,n+1,false);
	queue<int>Q;
	vis[s]=true;Q.push(s);
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		for(int v:graph[u])
			if(v!=ban&&!vis[v])
			{
				vis[v]=true;
				Q.push(v);
			}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int x,cur=0;
	while(cin>>x&&x!=-1)
	{
		if(x==-2)
			++cur;	// 一个邻接表结束；cur 即当前路口编号
		else
			graph[cur].push_back(x);
	}
	n=cur-1;	// 共 N+1 张邻接表（路口 0..N），最后一行是 -1
	vector<int>unav,mid;
	for(int s=1;s<n;++s)
	{
		bfs(0,s);
		if(vis[n])
			continue;	// 删 s 后 0 仍可达 N ⇒ 不是不可避免点
		unav.push_back(s);
		bool ok=true;
		for(int v:graph[s])
			if(v==s)
				ok=false;	// S 自环只能归第一半，但终点不许有出边
		for(int u=0;u<=n&&ok;++u)
			for(int v:graph[u])
				if(!vis[u]&&vis[v])
					ok=false;	// 从 A 外指进 A 的边：两半都放不下
		if(ok)
			mid.push_back(s);
	}
	cout<<unav.size();
	for(int v:unav)
		cout<<' '<<v;
	cout<<'\n'<<mid.size();
	for(int v:mid)
		cout<<' '<<v;
	cout<<'\n';
	return 0;
}
```

### 代码说明

- **`vis` 的双重身份**：BFS 后它就是集合 $A$ 的指示数组。`vis[n]` 判不可避免；`!vis[u]&&vis[v]` 判"指进 $A$ 的边"。因为 `ban=s` 永不入队，`vis[s]` 恒假，所以 $S\to A$ 的回头边自动被同一条判据捕获，不必单列。
- **$S$ 自环必须单独查**：自环 $S\to S$ 满足 `!vis[u]&&!vis[v]`，逃过边扫描判据，但它被迫归第一半、让终点有出边，是独立障碍（引理 5(ii)）。
- **读入机关**：`cur` 数 `-2`，既是"当前路口编号"又是最终的 $N+1$；`while(cin>>x&&x!=-1)` 对 EOF 也稳健。终点 $N$ 的邻接表是空行（只有 `-2`），自然处理。
- **输出格式**：数量在前、元素升序空格分隔；数量为 $0$ 时只输出 `0`。枚举顺序 `s=1..n-1` 天然升序，无需排序。
- 本题路口编号本来就是 $0..N$ 的语义编号，不做 `--u` 转换（转换反而会错位）。
- 复杂度 $O(N(N+M))$，$50$ 个路口 $100$ 条边下约几千次操作，远低于限制。
