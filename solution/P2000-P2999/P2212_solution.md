# P2212 [USACO14MAR] Watering the Fields S — 题解

## 一、解题过程：人类思考叙事

题面：平面上 $n$ 个点 $(x_i,y_i)$，连接点 $i,j$ 的代价是欧几里得距离的平方 $(x_i-x_j)^2+(y_i-y_j)^2$。但代价**小于 $c$** 的两点无法连通。求让所有点两两连通的最小总代价；做不到输出 `-1`。$n\le2000$，$0\le x_i,y_i\le1000$，$c\le10^6$。

**第一步：翻译成图论。** 把每个点看成顶点。对每一对点，如果平方距离 $w\ge c$，就在它们之间连一条权为 $w$ 的边；如果 $w<c$，这条边根本不存在（不允许使用）。问题问的是：在这个图上，用最小的总边权把所有顶点连成一个连通块；若图不连通则无解。

**第二步：认出最小生成树。** 任何合法方案选出的边必须让全图连通，即构成一个连通生成子图。如果方案里有环，随便删掉环上一条边，连通性不变而总代价不增（边权都是非负的，实际上都 $\ge c\ge1$），所以最优方案一定是一棵生成树。于是答案就是这张"可用边图"的**最小生成树（MST）**权值；图不连通则 `-1`。

**第三步：选 Kruskal 还是 Prim？** 完全图有 $\binom{2000}{2}\approx2\times10^6$ 条边。Kruskal 要把边全部存下来再排序，$2\times10^6$ 条边、每条 $12$ 字节左右，内存和时间都还算能过，但没必要。Prim 的朴素实现只需要一个 `dis` 数组：每轮从未访问点中选 `dis` 最小的，然后扫描所有点松弛。由于图是"完全图挖掉一些边"，每轮扫描全部 $n$ 个点即可，总复杂度 $O(n^2)=4\times10^6$，连边都不用存。所以选 Prim。

**第四步：处理禁边与无解。** 松弛时只有 $w\ge c$ 才更新 `dis[v]`。如果某一轮所有未访问点的 `dis` 都是无穷大，说明当前生成树与外界在可用边图里没有任何边相连，图不连通，直接输出 `-1`。注意 $w=c$ 是允许的（题面说"小于 $c$"才无法连通），所以判断要写 `w>=c`。

**第五步：防溢出。** 单条边最大 $(1000)^2+(1000)^2=2\times10^6$，生成树最多 $n-1=1999$ 条边，总代价上界约 $4\times10^9$，超过 `int` 上限 $2.147\times10^9$，必须用 `long long` 存 `dis` 和答案。`dis` 的无穷大也要用 64 位哨兵。

**边界情况**：

- $n=1$：不需要任何边，答案是 $0$。Prim 第一轮取起点、加入代价 $0$，自然得到 $0$。
- 两个点重合：平方距离 $0<c$，无边，可能无解。
- $c$ 很大（如 $10^6$）而点很密：大量边被禁，很可能无解。

手工小例（自己造）：

- `n=1,c=5,(0,0)` → `0`；
- `n=3,c=1,(0,0),(0,1),(1,0)`：三条边权 $1,1,2$ 都可用，MST 取两条权 $1$ 的边 → `2`；
- 同样的点但 $c=100$：所有边权都小于 $100$，没有可用边 → `-1`；
- `n=2,c=2,(0,0),(0,1)`：唯一一条边权 $1<2$，被禁 → `-1`。

四个结果都与程序一致。

## 二、思维链：完整证明

**建模**：构造无向图 $G=(V,E)$，$V=\{1,\dots,n\}$，对每对 $i\ne j$，
$$w(i,j)=(x_i-x_j)^2+(y_i-y_j)^2,\qquad (i,j)\in E\iff w(i,j)\ge c,$$
边权取 $w(i,j)$。

**引理 1（问题等价于 MST）**：设所有点可以用合法连接连通。则最小总代价等于 $G$ 的最小生成树权值；若 $G$ 不连通，则无解。

*证明*：

- 任一合法方案选出的边集 $F$ 使 $G[F]$ 连通且包含全部顶点，否则存在两点不连通。取 $G[F]$ 的一棵生成树 $T\subseteq F$，则 $w(T)=\sum_{e\in T}w(e)\le\sum_{e\in F}w(e)$（边权非负，且 $T$ 的边都来自 $F$）。所以最优方案可以取成一棵生成树，其代价不小于 MST 的权值。
- 反之，MST 本身就是合法的连通方案，代价等于 MST 权值。
- 若 $G$ 不连通，任何方案只能用 $G$ 的边，不可能把不同连通块的点连起来，故无解。

证毕。

**引理 2（割性质）**：设 $S\subset V$ 非空且 $S\ne V$，$e=(u,v)$ 是所有一个端点在 $S$、另一个端点在 $V\setminus S$ 的边中权值最小的一条。则存在一棵 MST 包含 $e$。

*证明*：取一棵 MST $T$。若 $e\in T$，结论成立。否则把 $e$ 加入 $T$，得到唯一一个环 $C$（树上加一条边恰有一个环）。沿环走一圈，从 $S$ 出发最终回到 $S$，穿过割 $(S,V\setminus S)$ 的次数是偶数；$e$ 穿了一次，所以环上还存在另一条跨越割的边 $f\ne e$。由 $e$ 的最小性，$w(f)\ge w(e)$。令 $T'=T+e-f$：从环上删去一条边仍连通且边数为 $n-1$，故 $T'$ 是生成树；其权值 $w(T')=w(T)+w(e)-w(f)\le w(T)$。$T$ 是最小生成树，故 $w(T')\ge w(T)$，结合得 $w(T')=w(T)$，$T'$ 也是 MST 且包含 $e$。证毕。

**引理 3（Prim 不变式）**：把算法执行中的点分为已访问集 $S$ 与未访问集 $U=V\setminus S$。每轮开始前满足：

1. 已选出的边集 $T_0$ 构成 $S$ 上的一棵生成树（$|S|=1$ 时为空树）；
2. $T_0$ 包含于某棵 MST；
3. 对每个 $v\in U$，`dis[v]` 等于 $\min\{w(u,v):u\in S,\ (u,v)\in E\}$，若没有这样的边则为 $+\infty$。

*证明*：对轮数归纳。初始 $S=\{0\}$，空树是生成树，空集包含于任意一棵 MST；`dis[0]=0`，其余为 $+\infty$，与"$S$ 到 $v$ 没有边"一致（$S$ 只有一个点且没有自环）。

设某轮开始前不变式成立。算法选出 $u\in U$ 使 `dis[u]` 最小。

- 若 `dis[u]=+\infty`：由不变式 3，$S$ 与 $U$ 之间没有任何 $G$ 中的边。
- 若 `dis[u]` 有限：由不变式 3，存在 $u_0\in S$ 使 $w(u_0,u)=\text{dis}[u]$，即存在横跨割的边 $e=(u_0,u)$。对任意横跨割的边 $(a,v)$（$a\in S$，$v\in U$），不变式 3 给出 $\text{dis}[v]\le w(a,v)$，而 $u$ 是所有未访问点中 `dis` 最小的，故 $\text{dis}[u]\le\text{dis}[v]\le w(a,v)$。因此 $e$ 是横跨割 $(S,U)$ 的最小边。取包含 $T_0$ 的 MST $T^*$。若 $e\in T^*$，则 $T_0+e\subseteq T^*$。否则把 $e$ 加入 $T^*$ 得到唯一环 $C$；沿 $C$ 绕一圈，从 $S$ 出发最终回到 $S$，跨越割的次数为偶数，$e$ 已跨越一次，故环上还有另一条跨越割的边 $f\ne e$，且 $f\notin T_0$（$T_0$ 的边两端都在 $S$ 内，不可能跨越割）。由 $e$ 的最小性 $w(f)\ge w(e)$，于是 $T'=T^*-f+e$ 仍是生成树且权值不增，从而是 MST，并且 $T_0+e\subseteq T'$。所以加入 $u$ 与 $e$ 后不变式 2 仍成立。
- 加入 $u$ 后，对每个 $v\in U\setminus\{u\}$，新的 `dis[v]` 应为 $\min(\text{旧 dis}[v],w(u,v))$（若 $(u,v)\in E$）。这正是算法的松弛；若 $w(u,v)<c$ 则边不存在，不更新。$S$ 变为 $S\cup\{u\}$，树增加一条边，仍连通且无环，故不变式 1 成立。

证毕。

**引理 4（无解判定正确）**：若某轮所有未访问点的 `dis` 均为 $+\infty$，则 $G$ 不连通。

*证明*：由引理 3，此时 $S$ 与 $U$ 之间没有 $G$ 的边。$S$ 非空（至少含起点），$U$ 也非空（还有未访问点）。取 $s\in S$、$t\in U$，$G$ 中任何 $s$ 到 $t$ 的路径都必须某一步从 $S$ 跨到 $U$，这需要一条 $S$ 与 $U$ 之间的边，矛盾。故 $G$ 不连通。证毕。

**引理 5（Prim 输出正确）**：若 $G$ 连通，Prim 选出的 $n-1$ 条边构成 MST，输出其权值；若 $G$ 不连通，算法在某一轮遇到 `dis[u]=+\infty` 并输出 `-1`。

*证明*：若 $G$ 连通，由引理 4 的反面，每轮都存在横跨割的边，`dis` 的最小值有限，算法完整执行 $n$ 轮，加入 $n-1$ 条边。由引理 3 的不变式 2，最终边集 $T_0$ 包含于某棵 MST $T^*$；而 $T_0$ 是 $n$ 个点上的生成树，已有 $n-1$ 条边，$T^*$ 也只有 $n-1$ 条边，故 $T_0=T^*$，即 $T_0$ 就是 MST，其权值即最小总代价。若 $G$ 不连通，由引理 4 算法输出 `-1` 正确。证毕。

**引理 6（复杂度与溢出）**：时间复杂度 $O(n^2)$，额外空间 $O(n)$；总代价可能超过 32 位整数，必须用 64 位。

*证明*：每轮选最小值扫描 $n$ 个点，松弛再扫描 $n$ 个点，共 $n$ 轮，$O(n^2)$。除输入坐标外只需 `dis`、`vis` 两个长度 $n$ 的数组，空间 $O(n)$。单条边权最大 $1000^2+1000^2=2\times10^6$，生成树至多 $n-1\le1999$ 条边，总代价至多约 $3.998\times10^9>2^{31}-1$，故 `dis` 与答案用 `i64`。证毕。

**定理**：程序输出即题目所求的最小总代价，无解时输出 `-1`。

*证明*：由引理 1 问题等价于 MST；由引理 5 Prim 正确求得 MST 或判定无解；由引理 6 实现不会溢出且复杂度达标。证毕。

## 三、模式总结（按实际思考顺序）

- **reduce to easier problem** — 把"连接点"抽象成带权无向图，代价小于 $c$ 的边直接不存在。
- **explore its property** — 合法方案是连通生成子图，去掉环不增代价 ⇒ 最优是一棵生成树。
- **classic problem solution** — 问题化为最小生成树；不连通则无解。
- **classic problem solution** — 完全图用朴素 Prim：`dis` 维护树到各点的最小合法边权，$O(n^2)$，不必存 $2\times10^6$ 条边。
- **prove greedy by cut** — 割性质保证每轮选出的最小横跨边属于某棵 MST。
- **discuss by category** — 连通时输出 MST 权值；出现 `dis=INF` 时输出 `-1`；$n=1$ 自然为 $0$。
- **boundary check** — 边权阈值是"小于 $c$ 禁用"，故用 `w>=c`；总代价用 64 位。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 点数 | 输入 |
| $c$ | 允许连通的最小代价（平方距离） | 输入 |
| `x[i],y[i]` | 第 $i$ 个点的坐标 | 输入 |
| `dis[v]` | 当前生成树到未访问点 $v$ 的最小合法边权 | 全部 `inf`，`dis[0]=0` |
| `vis[v]` | 点 $v$ 是否已加入生成树 | `false` |
| `u` | 本轮选中的未访问点 | `dis` 最小者 |
| `w` | 两点平方距离 | 松弛时现算 |
| `ans` | MST 总权值 | $0$，累加 `dis[u]` |
| `inf` | 64 位无穷哨兵 | $1145141919810$ |

### 算法步骤

1. 读入 $n,c$ 与 $n$ 个点。
2. `dis` 全部置 `inf`，`dis[0]=0`；`ans=0`。
3. 重复 $n$ 轮：
   1. 在未访问点中找 `dis` 最小的 $u$（若并列任取）；
   2. 若 `dis[u]>=inf`，说明图不连通，输出 `-1` 并结束；
   3. `vis[u]=1`，`ans+=dis[u]`；
   4. 对每个未访问的 $v$，计算 $w=(x_u-x_v)^2+(y_u-y_v)^2$；若 $w\ge c$ 且 $w<dis[v]$，令 `dis[v]=w`。
4. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(n^2)$。$n=2000$ 时约 $4\times10^6$ 次距离计算。
- 空间复杂度：$O(n)$（`dis`、`vis` 与坐标数组），不存边。

### 验证状态

编译通过；4 组手造数据（$n=1$、可行三角形、全禁边、单边被禁）输出分别为 `0 2 -1 -1`，与手算一致；另在 3000 组随机小数据（$n\le9$，坐标 $0\sim11$，$c\le100$，含重合点）上与"枚举所有 $w\ge c$ 的边 + Kruskal 并查集"的独立实现比对，全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005};
constexpr i64 inf{1145141919810};

int n,c;
i64 x[mxn],y[mxn];
i64 dis[mxn];       // dis[v]=当前生成树到v的最短合法边权
bool vis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>c;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];

	fill_n(dis,mxn,inf);
	dis[0]=0;
	i64 ans=0;
	for(int it=0;it<n;++it)
	{
		int u=-1;
		for(int i=0;i<n;++i)
			if(!vis[i]&&(u==-1||dis[i]<dis[u]))
				u=i;
		if(dis[u]>=inf)
		{
			cout<<-1<<'\n';
			return 0;
		}
		vis[u]=1;
		ans+=dis[u];
		for(int v=0;v<n;++v)
			if(!vis[v])
			{
				i64 w=(x[u]-x[v])*(x[u]-x[v])+(y[u]-y[v])*(y[u]-y[v]);
				if(w>=c&&w<dis[v])
					dis[v]=w;
			}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `dis` 与 `ans` 用 `i64`：最大的生成树总代价接近 $4\times10^9$，`int` 会溢出。
- 松弛条件 `w>=c` 对应"代价小于 $c$ 无法连通"；取等号是合法的。
- 选点用 `u==-1||dis[i]<dis[u]`，避免把 `u` 初值设成 $0$ 后对已访问点做错误比较。
- 若最小的 `dis` 仍是 `inf`，说明当前树与剩余点之间没有任何可用边，图不连通。
- $n=1$ 时第一轮取点 $0$、累加 $0$，随后退出，输出 `0`，无需特判。
