# P2089 烤鸡 — 题解

## 一、解题过程：人类思考叙事

题目很活泼：Hanke 有 $10$ 种配料，每种可以放 $1\sim 3$ 克，美味程度是总和。给定 $n$，输出所有总质量为 $n$ 的搭配方案，**按字典序**排列，第一行输出方案总数。

先算一下方案空间有多大。每种配料 $3$ 种选择，一共 $3^{10}=59049$ 种组合。这个数量非常小，直接暴力枚举完全可行 —— 这是一道纯枚举题，关键不在算法而在**怎么枚举才能天然满足字典序**。

最笨的办法是写 $10$ 层循环，每层 `for(v=1;v<=3;++v)`。功能上没问题，但 $10$ 层嵌套写出来又长又容易写错。自然的改进是用 **DFS（递归）**：第 $d$ 层枚举第 $d$ 种配料的克数，$d$ 从 $1$ 到 $10$，选满 $10$ 层就检查总和。

字典序怎么保证？这里有个漂亮的性质：**如果每一层的枚举顺序都是从小到大，那么整棵 DFS 树的叶子遍历顺序天然就是字典序**。

为什么？字典序比较两个方案，是从左往右逐位比较，第一个不同的位置小的方案字典序小。DFS 在第 $1$ 层先枚举完 $v=1$ 的所有分支，再枚举 $v=2$ 的分支 —— 也就是"第一位为 $1$"的方案全部排在"第一位为 $2$"的方案前面。而第一位相同时，递归进入第二层，第二位小的又先出。层层递推，恰好就是字典序的定义。

所以：**DFS + 每层从小到大枚举**，输出顺序直接满足要求，连排序都不用做。这是本题最值得记住的一点。

再说搜索空间的大小优化。$3^{10}=59049$ 次叶子调用，每次 $O(1)$，总共不到 $2\times 10^5$ 次操作，随便跑。

那么能不能剪枝？$n\le 10000$，但 $10$ 种配料每种最多 $3$ 克，总质量最大 $30$，最小 $10$。所以：
- 若 $n<10$ 或 $n>30$，**无解**，只需输出第一行 `0`。
- 若 $10\le n\le 30$，一定有解。

有趣的是，题目数据范围写的是 $n\le 10000$，但由于总和最多 $30$，$n>30$ 时其实一个方案都没有。有同学会在这上面卡住：$n=10000$ 时 DFS 跑完 $59049$ 个叶子，发现一个都不满足，输出方案数 $0$，效果是对的，只是白跑了一趟（而且完全不会超时）。所以剪枝是"锦上添花"，不是必需。

我用了一个更省事的写法：DFS 时维护当前已选质量和 `sum`，选满 $10$ 种时判断 `sum==n` 就记录。不需要额外的剪枝，$59049$ 次递归在 $1$ 秒时限里绰绰有余。

另外注意输出格式：**第一行是方案总数**，然后每行一个方案（$10$ 个数，空格分隔）。如果一个方案都没有，就只输出第一行的 `0`，后面没有别的行。

还有一点：$3^{10}=59049$ 种组合里，$n=20$（全 $2$）恰好一个解；$n=11$ 有 $10$ 个解（一个 $2$ 其余 $1$）。方案总数最多是多少？总质量 $20$ 时解最多 —— 组合数 $\binom{20}{10}$ 量级（把 $x_i\in[1,3]$ 令 $y_i=x_i-1\in[0,2]$，$\sum y_i=10$，每 $y_i$ 至少被 $5$ 个…… 实际最大值约 $8953$）。总方案数最多 $3^{10}=59049$，所以方案总数用一个 `int` 存毫无压力。

## 二、思维链：完整证明

**引理 1**：$n<10$ 或 $n>30$ 时不存在合法方案。

*证明*：$10$ 种配料，每种质量在 $\{1,2,3\}$ 中。总质量最小为 $10\times 1=10$，最大为 $10\times 3=30$。故 $n\notin[10,30]$ 时无解。证毕。

**引理 2**：DFS 恰好枚举每一个长度为 $10$、每位取自 $\{1,2,3\}$ 的序列，且每个序列恰好被枚举一次。

*证明*：递归的第 $d$ 层枚举第 $d$ 位的取值 $v\in\{1,2,3\}$，共 $3$ 个分支，深度为 $10$。深度为 $10$ 时，路径上的 $10$ 次选择唯一确定一个序列。由归纳可知深度 $d$ 的调用点与长度为 $d$ 的前缀序列一一对应；深度 $10$ 的调用点与长度为 $10$ 的完整序列一一对应。因此每个序列被枚举恰好一次，且没有遗漏。证毕。

**引理 3**：DFS 输出方案序列的顺序是字典序非降的。

*证明*：设两个不同的方案 $u=(u_1,\dots,u_{10})$ 与 $v=(v_1,\dots,v_{10})$，设 $k$ 是它们第一个不同的位置，即 $u_1=v_1,\dots,u_{k-1}=v_{k-1}$ 而 $u_k\ne v_k$。不妨设 $u_k<v_k$（否则交换 $u,v$ 同理）。

由引理 2 的枚举结构，DFS 在第 $k$ 层先完整遍历 $u_k$ 对应的整个子树，之后才遍历 $v_k$ 对应的子树。而 $u$ 位于前一个子树中，$v$ 位于后一个子树中。由于第 $k$ 层之前的所有层取值都相同，两者在第 $k$ 层分道扬镳的那个分支的枚举先后，正好由第 $k$ 层"从小到大枚举"决定，即 $u$ 先于 $v$ 被输出。

而字典序的定义正是：第一个不同的位置上取值小的方案在前。故输出顺序为字典序非降。证毕。

**引理 4**：算法输出的方案总数与方案列表自洽。

*证明*：由引理 2，DFS 遍历了全部 $3^{10}$ 个序列；算法在深度 $10$ 处检查 `sum==n`，只把满足条件的序列加入 `sol`。因此 `sol` 中恰好包含全部且仅包含合法方案，每个方案出现一次（无重复无遗漏）。于是 `sol.size()` 就是方案总数，`sol` 的内容就是方案列表。证毕。

**引理 5**：当无解时，算法只输出第一行的 `0`。

*证明*：由引理 1，$n\notin[10,30]$ 时 `sol` 为空（引理 4），此时循环 `for(auto&s:sol)` 一次都不执行，输出内容仅有 `cout<<sol.size()<<'\n';` 即 `0`。证毕。

**定理**：算法输出满足题目要求（方案总数正确、方案列表完整且按字典序排列）。

*证明*：由引理 4，总数与列表正确；由引理 3，顺序为字典序；由引理 5，无解时输出格式也正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **估一下搜索空间** — $3^{10}=59049$，直接暴力枚举绰绰有余，本题是纯枚举题。
2. **用 DFS 代替 $10$ 层循环** — 同层循环的重复代码用递归消掉。
3. **发现"逐层从小到大枚举 ⇒ 天然字典序"** — 不需要额外排序，这是本题的关键性质。
4. **顺手看总质量的取值范围** — $[10,30]$，超界直接无解（可选剪枝）。
5. **输出格式别漏** — 先方案总数，再每行一个方案；无解时只有一行 `0`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 目标美味程度 | `int`，$\le 10^4$ |
| $d$ | 递归深度，当前要决定第 $d$ 种配料 | `int`，$1..10$ |
| `cur[d]` | 第 $d$ 种配料放的克数 | `int`，$\in\{1,2,3\}$ |
| `sum` | 已经确定的配料总质量 | `int`，$0..30$ |
| `sol` | 所有合法方案的容器 | `vector<array<int,10>>` |
| `mxs` | `cur` 数组长度（$10+1$） | `constexpr int` |

### 算法步骤

1. 读入 $n$。
2. 调用 `dfs(1,0)`：从第 $1$ 种配料开始，当前总和 $0$。
3. `dfs(d,sum)` 的行为：
   - 若 $d>10$：说明 $10$ 种配料都已确定，若 `sum==n` 则把 `cur[1..10]` 存入 `sol`；返回。
   - 否则对 $v=1,2,3$（**从小到大**）：令 `cur[d]=v`，递归 `dfs(d+1,sum+v)`。
4. 输出 `sol.size()`。
5. 遍历 `sol`，每行输出 $10$ 个数，空格分隔。

### 复杂度

- 时间复杂度：$O(3^{10}\cdot 10)$，即约 $6\times 10^5$ 次常数操作。$3^{10}$ 是与 $n$ 无关的常数，实际就是 $O(1)$ 级别的固定开销。
- 空间复杂度：$O(\text{方案数}\cdot 10)$，最坏情形下存下全部合法方案。

### 验证状态

- 标程 `P2089.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `11` 输出 $10$ 组方案，且顺序为 `1 1 1 1 1 1 1 1 1 2` 开头（即字典序），与官方一致。
- 编写暴力 `P2089_brute.cpp`（三进制枚举 $0..3^{10}-1$，高位对应靠前配料，枚举顺序本身即字典序）与对拍脚本 `P2089_check.py`，在 $n\in[1,30]$ 的随机数据及 $n=1,10,11,20,29,30,31,100$ 等边界上对拍 **2008 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2089 烤鸡
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{59055};
constexpr int mxs{11};

int n;
int cur[mxs];
vector<array<int,10>> sol;

void dfs(int dep,int sum)
{
	if(dep>10)
	{
		if(sum==n)
			sol.push_back({cur[1],cur[2],cur[3],cur[4],cur[5],cur[6],cur[7],cur[8],cur[9],cur[10]});
		return;
	}
	// 每种配料 1~3 克，按字典序从小到大枚举
	for(int v=1;v<=3;++v)
	{
		cur[dep]=v;
		dfs(dep+1,sum+v);
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	dfs(1,0);
	cout<<sol.size()<<'\n';
	for(auto&s:sol)
	{
		for(int i=0;i<10;++i)
			cout<<s[i]<<(i==9?'\n':' ');
	}
	return 0;
}
```

### 代码说明

- `cur` 用 1-based 下标（`cur[1..10]` 对应 $10$ 种配料），与题目"第几种配料"的自然顺序一致；数组长度 `mxs{11}` 留一位余量。
- `dfs` 里 `for(int v=1;v<=3;++v)` 的**升序**是字典序输出的充分条件，不要改成降序或乱序。
- 用 `sum` 增量维护已选总和，避免每层重新累加。
- `sol` 用 `vector<array<int,10>>`，一次 `push_back` 拷贝整个方案，`cur` 后续被覆盖也不影响已存方案。
- 无解时 `sol` 为空，循环体不执行，只输出首行 `0`，符合题面"如果没有符合要求的方法，就只要在第一行输出一个 0"。
