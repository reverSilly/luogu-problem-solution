# P2077 红绿灯 — 题解

## 一、解题过程：人类思考叙事

题目：一条笔直公路上有 $N$ 个十字路口，相邻路口距离 $A_i$ 千米。每个路口红灯 $R_i$ 分钟、绿灯 $G_i$ 分钟。一辆车从距离 1 号路口 $M$ 千米处出发，**出发时所有路口的红绿灯刚好从红灯跳到绿灯**。车速 1 千米/分钟，不能闯红灯。问通过每个路口的最早时间。

$N\le10^5$，$M,A_i\le10$，$R_i,G_i\le5$。

**第一步：把"时间"变成"相位"。**

关键在题面那句"此时所有路口的红灯刚好从红灯跳到绿灯"——出发时刻 $t=0$ 时，所有灯都是**刚刚变绿**。

对一个路口 $i$，周期长度 $per_i=R_i+G_i$。第 $t$ 分钟它处于周期内的第 $t\bmod per_i$ 分钟。而因为 $t=0$ 时刚好变绿，所以：

- 相位 $t\bmod per_i < G_i$ → 绿灯，可以通过；
- 相位 $t\bmod per_i \ge G_i$ → 红灯，要等。

这就完全没有模拟的必要了：直接看相位就行。

**第二步：处理"等待"。**

假设车在时刻 $t$ 到达路口 $i$。令 $ph=t\bmod per_i$。

- 若 $ph<G_i$：直接通过，$t$ 不变。
- 否则（红灯）：需要等到下一个绿灯开始。下一个周期起点是 $t+(per_i-ph)$，那里恰好是绿灯的第一分钟。所以令
$$t \gets t + (per_i - ph).$$

这里要注意一个细节：等的时候，是等到"下一个整周期的起点"，而不是等到"当前红灯段的末尾再补一段绿灯"。因为绿灯段是从周期起点开始的 $[0,G_i)$，红灯段是 $[G_i, per_i)$。$ph\ge G_i$ 说明已经在红灯里，红灯还要持续 $per_i-ph$ 分钟才结束，届时进入下一周期的绿灯段。所以 $t+(per_i-ph)$ 正是下一个绿灯的起点。✓

**第三步：时间怎么往前走。**

车从距离 1 号路口 $M$ 千米处出发，速度 1 千米/分钟，所以到达 1 号路口的时刻是 $t=M$。

到达路口 $i$ 的时刻 = 上一个路口的通过时刻 + 路程 $A_{i-1}$（注意 $A_i$ 是第 $i$ 与第 $i+1$ 个路口之间的距离，所以从 $i$ 到 $i+1$ 走的是 $A_i$）。

于是：

```
t = M
for i = 1..N:
    if i > 1: t += A[i-1]
    per = R[i] + G[i]
    ph = t % per
    if ph >= G[i]: t += per - ph
    输出 t
```

样例：`5 3 / 2 4 3 2 / 3 4 3 4 3 / 2 3 2 3 1`。

$N=5,M=3$，$A=(2,4,3,2)$，$R=(3,4,3,4,3)$，$G=(2,3,2,3,1)$。

- 路口 1：$t=3$，$per=3+2=5$，$ph=3\bmod5=3\ge G_1=2$ → 红灯，等 $5-3=2$，$t=5$。输出 5 ✓
- 路口 2：$t=5+A_1=5+2=7$，$per=4+3=7$，$ph=0<3$ → 绿灯，$t=7$。输出 7 ✓
- 路口 3：$t=7+4=11$，$per=3+2=5$，$ph=1<2$ → 绿灯，$t=11$。输出 11 ✓
- 路口 4：$t=11+3=14$，$per=4+3=7$，$ph=0<3$ → 绿灯，$t=14$。输出 14 ✓
- 路口 5：$t=14+2=16$，$per=3+1=4$，$ph=0<1$ → 绿灯，$t=16$。输出 16 ✓

全对。

**一个容易忽略的点**：$t$ 可能超过 `int` 吗？$N\le10^5$，每个路口最多等 $per\le10$ 分钟，加上路程 $A_i\le10$，总时间不超过 $10^5\times20=2\times10^6$，`int` 够。但用 `i64` 更稳妥，而且 `%` 和 `/` 对 `i64` 没额外开销。

**另一个细节**：题目说"输出一行一个正整数"，但 $N$ 个路口要输出 $N$ 行——题面 Output Format 写的是"共 $N$ 行，每行一个正整数"。按 $N$ 行输出。

思路到此为止，$O(N)$。

## 二、思维链：完整证明

**引理 1**：在时刻 $t$，路口 $i$ 是绿灯当且仅当 $t\bmod (R_i+G_i) < G_i$。

*证明*：路口 $i$ 的灯周期为 $per_i=R_i+G_i$，一个周期内前 $G_i$ 分钟绿灯、后 $R_i$ 分钟红灯。题面说明出发时刻 $t=0$ 时所有灯"刚好从红灯跳到绿灯"，即 $t=0$ 是第 $0$ 个周期的起点（且此刻为绿灯的第一分钟）。因此时刻 $t$ 落在第 $\lfloor t/per_i\rfloor$ 个周期的相位 $t\bmod per_i$ 处，相位 $<G_i$ 恰为该周期的绿灯段。证毕。

**引理 2**：若在时刻 $t$ 到达路口 $i$ 且 $ph=t\bmod per_i\ge G_i$，则最早可通过的时刻是 $t+(per_i-ph)$。

*证明*：由引理 1，时刻 $t$ 处为红灯，最少还需 $per_i-ph$ 分钟红灯才结束（当前周期在 $t+(per_i-ph)$ 时刻进入下一周期）。而在 $t+(per_i-ph)$ 时刻，相位为 $0<G_i$，由引理 1 为绿灯，可以通过。故该时刻既是最早的（更早仍在红灯），又确实可通过。证毕。

**引理 3**：算法在第 $i$ 个路口输出的时刻，是车通过该路口的最早时刻。

*证明*：归纳。设车离开第 $i-1$ 个路口的最早时刻为 $t_{i-1}$（$i=1$ 时取出发时刻 $t_0=M$）。

对 $i=1$：车从距离 1 号路口 $M$ 千米处出发，车速 1 千米/分钟，故到达时刻恰为 $M$，算法初始化 $t=M$ 正确。

对 $i>1$：通过第 $i-1$ 个路口后，车到第 $i$ 个路口还需行驶 $A_{i-1}$ 千米，故最早到达时刻为 $t_{i-1}+A_{i-1}$。算法令 $t\gets t+A_{i-1}$ 得到最早到达时刻。再由引理 2，算法把 $t$ 调整到最早可通过时刻。反过来，任何更早的方案都不可能更早到达（行驶时间固定），也不可能更早通过（更早到达时仍在红灯，见引理 2），故算法给出的时刻即最早通过时刻。证毕。

**定理**：算法输出的 $N$ 个时刻依次是车通过各路口的最早时刻。

*证明*：由引理 3 对每个 $i$ 成立，且算法按 $i=1\ldots N$ 顺序输出，故结论成立。证毕。

## 三、模式总结（按实际思考顺序）

1. **读题时抓住"所有灯同时由红转绿"** — 这一句把"相位"直接锚定为从 $t=0$ 开始，否则 $t\bmod per$ 的含义就没了。
2. **周期问题先看相位，再考虑模拟** — 有周期就直接用 `%`，不用逐分钟模拟。
3. **等红灯的时长要想清楚** — 等到"下一个周期的起点"而不是"红灯结束"，因为绿灯段贴着周期开头。等价说法：$t\gets t+(per-ph)$。
4. **区分"到达时刻"和"通过时刻"** — 通过时刻 $\ge$ 到达时刻，输出的是后者。
5. **路程累加要对应正确的下标** — 从第 $i$ 个路口到第 $i+1$ 个是 $A_i$，所以到第 $i$ 个路口加的是 $A_{i-1}$，第一个路口加的是 $M$。
6. **时间用 `i64`** — 累加量大，`long long` 免心烦。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $N$ | 十字路口数 | `int`，$\le10^5$ |
| $M$ | 出发点到 1 号路口的距离（千米） | `int`，$\le10$ |
| `a[i]` | 第 $i$ 与第 $i+1$ 个路口之间的距离（$i<N$） | `int`，$\le10$ |
| `r[i]` | 第 $i$ 个路口的红灯时间（分钟） | `int`，$\le5$ |
| `g[i]` | 第 $i$ 个路口的绿灯时间（分钟） | `int`，$\le5$ |
| $per_i$ | 第 $i$ 个路口的周期 $r_i+g_i$ | `i64`，$2\le\cdot\le10$ |
| $t$ | 当前时刻 | `i64` |
| $ph$ | 当前时刻在路口 $i$ 周期内的相位 $t\bmod per_i$ | `i64`，$0\le ph<per_i$ |

**初始化约定**：`a[]`、`r[]`、`g[]` 为全局数组，默认全 0，读入时逐个覆盖；`t` 在 `main` 内显式初始化为 `M`。

### 算法步骤

1. 读入 $N,M$。
2. 读入 $A_1\ldots A_{N-1}$ 到 `a[]`。
3. 读入 $R_1\ldots R_N$ 到 `r[]`。
4. 读入 $G_1\ldots G_N$ 到 `g[]`。
5. 初始化 `t = M`。
6. 对 $i=1\ldots N$：
   - 若 $i>1$，令 `t += a[i-1]`（从上一个路口驶来）；
   - 令 `per = r[i]+g[i]`、`ph = t % per`；
   - 若 `ph >= g[i]`（红灯），令 `t += per - ph`（等到下一周期起点）；
   - 输出 `t`。
7. 结束。

### 复杂度

- 时间复杂度：$O(N)$，每个路口一次取模、一次比较。
- 空间复杂度：$O(N)$，存储距离与红绿灯时长。

### 验证状态

- 标程 `P2077.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `5 3 / 2 4 3 2 / 3 4 3 4 3 / 2 3 2 3 1` 输出 `5 7 11 14 16`（分行），与官方一致。
- 编写独立暴力 `P2077_brute.cpp`（**逐分钟模拟灯色**：对每个路口单独维护"当前还剩多少分钟绿灯 / 红灯"，用 `while` 循环一分钟一分钟地把时间推到下一个绿灯时刻，与标程的取模相位法完全不同）与对拍脚本 `P2077_check.py`：随机生成 $1\le N\le6$ 的数据（保证暴力能在可接受时间内跑完），并附加"$N=1$ / 全红 / 全绿 / 官方样例"等极端构造，**对拍 2004 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n,m;
//a[i]：第 i 个路口与第 i+1 个路口的距离
int a[mxn];
//r[i],g[i]：红灯、绿灯时间
int r[mxn],g[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=1;i<n;++i)
		cin>>a[i];
	for(int i=1;i<=n;++i)
		cin>>r[i];
	for(int i=1;i<=n;++i)
		cin>>g[i];

	//t=0 时所有路口刚由红转绿，故一个周期内前 g[i] 分钟是绿灯
	i64 t=m;
	for(int i=1;i<=n;++i)
	{
		if(i>1)
			t+=a[i-1];
		i64 per=r[i]+g[i];
		i64 ph=t%per;
		if(ph>=g[i])
			t+=per-ph;
		cout<<t<<'\n';
	}
	return 0;
}
```

### 代码说明

- `a[]`、`r[]`、`g[]` 为全局数组，默认 0，读入时逐个覆盖，不需要额外 `fill`。
- `t`、`per`、`ph` 一律用 `i64`：累加量大，且 `t%per` 的类型与 `per` 保持一致，避免隐式转换警告。
- `if(i>1) t+=a[i-1];` 放在循环体开头，把"行驶时间"和"等灯时间"两件事分开，逻辑清晰。
- 等灯条件是 `ph>=g[i]`（注意是 `>=`，相位恰好等于 $G_i$ 时已是红灯的最后一分钟）。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
