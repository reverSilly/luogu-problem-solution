# P2666 [USACO07OCT] Bessie's Secret Pasture S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 选 $4$ 块正方形草皮（边长为**非负整数**，可以为 $0$，每种边长供应无限），边长平方和恰为 $N$（$1\le N\le10000$），问有多少种选法。即数有序四元组 $(a,b,c,d)\in\mathbb Z_{\ge0}^4$ 使 $a^2+b^2+c^2+d^2=N$。

**第一步：先把题面那句自相矛盾的话掰清楚——到底计不计顺序？** 题面写"注意这里不讲究顺序"，紧接着却说"如 $(1,2,3,4)$ 与 $(4,3,2,1)$ 是**两种不同方法**"。后半句明摆着把排列算作不同方案。再看它给的 $N=4$ 例子：$5$ 种 $=(1,1,1,1),(2,0,0,0),(0,2,0,0),(0,0,2,0),(0,0,0,2)$。

- 若**计顺序**（有序四元组）：$(1,1,1,1)$ 算 $1$ 种，$(2,0,0,0)$ 的 $4$ 个排列各算 $1$ 种，共 $1+4=5$ ✓。
- 若**不计顺序**（只看边长多重集）：只有 $\{1,1,1,1\}$ 与 $\{2,0,0,0\}$ 两类，共 $2\ne5$ ✗。

例子是硬证据：**计顺序**。"不讲究顺序"是翻译失误，以它自己的举例和 $N=4\to5$ 为准。这一步必须钉死，否则整道题数错对象。

**第二步：确定搜索范围。** 边长非负且 $a^2\le N\le10000$，故 $a\le\lfloor\sqrt N\rfloor\le100$。四个变量都在 $[0,100]$。供应无限 ⇒ 允许重复；边长 $0$ 合法 ⇒ 允许 $0$。

**第三步：暴力到折半的演进。**

- **四重循环** $a,b,c,d\in[0,100]$：$101^4\approx1.04\times10^8$，加剪枝（$a^2+b^2+c^2+d^2\le N$）能砍掉大半，但写法笨、量级偏大。
- **三重循环 + 完全平方判定**：枚举 $a,b,c$，看 $N-a^2-b^2-c^2$ 是否完全平方（预处理 `isSq[]`）。约 $10^6$ 量级，能过，但还能更好。
- **2+2 折半（meet in the middle）**：把 $4$ 个平方拆成"前两个 + 后两个"。先预处理

$$\texttt{cnt}[s]=\#\{(a,b)\in\mathbb Z_{\ge0}^2:a^2+b^2=s\}\quad(0\le s\le N),$$

  则答案 $=\sum_{s=0}^{N}\texttt{cnt}[s]\cdot\texttt{cnt}[N-s]$：前两块面积和为 $s$、后两块面积和为 $N-s$，两边独立选取、乘法原理。预处理双重循环约 $\frac{\pi N}{4}\approx7854$ 次，卷积 $N+1$ 次，总 $O(N)$，一万的数据量瞬间出解。

折半为什么对？因为四元组 $(a,b,c,d)$ 与"有序对 $((a,b),(c,d))$"一一对应，按 $s=a^2+b^2$ 分类后，每一类恰是 $P_s\times P_{N-s}$ 的笛卡尔积（$P_t$ 是平方和为 $t$ 的有序对集合），大小 $\texttt{cnt}[s]\cdot\texttt{cnt}[N-s]$，各类不交，求和即总数。第二部分严格证。

**第四步：手算对表。** 先算小 $N$ 的 `cnt`：$\texttt{cnt}[0]=1$（$(0,0)$），$\texttt{cnt}[1]=2$（$(0,1),(1,0)$），$\texttt{cnt}[2]=1$（$(1,1)$），$\texttt{cnt}[4]=2$（$(0,2),(2,0)$），$\texttt{cnt}[3]=0$。

$$N=4:\ \texttt{cnt}[0]\texttt{cnt}[4]+\texttt{cnt}[1]\texttt{cnt}[3]+\texttt{cnt}[2]\texttt{cnt}[2]+\texttt{cnt}[3]\texttt{cnt}[1]+\texttt{cnt}[4]\texttt{cnt}[0]=2+0+1+0+2=5\ ✓.$$

再手工枚举 $N=1..10$ 的全部方案（按边长多重集分类、数排列）：

| $N$ | 方案（边长多重集 → 排列数） | 答案 |
|---|---|---|
| $1$ | $(1,0,0,0)\to4$ | $4$ |
| $2$ | $(1,1,0,0)\to6$ | $6$ |
| $3$ | $(1,1,1,0)\to4$ | $4$ |
| $4$ | $(1,1,1,1)\to1$；$(2,0,0,0)\to4$ | $5$ |
| $5$ | $(2,1,0,0)\to12$ | $12$ |
| $6$ | $(2,1,1,0)\to12$ | $12$ |
| $7$ | $(2,1,1,1)\to4$ | $4$ |
| $8$ | $(2,2,0,0)\to6$ | $6$ |
| $9$ | $(3,0,0,0)\to4$；$(2,2,1,0)\to12$ | $16$ |
| $10$ | $(3,1,0,0)\to12$；$(2,2,1,1)\to6$ | $18$ |

程序输出 `4 6 4 5 12 12 4 6 16 18`，逐位吻合。又手算 $N=25$：$(5,0,0,0)\to4$、$(4,3,0,0)\to12$、$(4,2,2,1)\to12$，共 $28$；$N=100$：$(10,0,0,0)\to4$、$(9,3,3,1)\to12$、$(8,6,0,0)\to12$、$(8,4,4,2)\to12$、$(7,5,5,1)\to12$、$(7,7,1,1)\to6$、$(5,5,5,5)\to1$，共 $59$——程序均一致。

**第五步：值域与实现。** $\texttt{cnt}[s]\le101$（固定 $a$ 至多一个 $b\ge0$ 使 $b^2=s-a^2$），$\sum_s\texttt{cnt}[s]\le101^2=10201$，故答案 $\le101\times10201\approx1.03\times10^6$，`int` 都够；代码用 `i64` 累加只是零成本保险。$N=10000$ 时程序输出 $1217$。

**文化注脚**（不影响算法）：本题计的是"非负有序"四平方表示数；数论里 Jacobi 四平方和定理给的是"带符号有序"表示数 $r_4(N)=8\sum_{d\mid N,4\nmid d}d$，两者差一个符号权重 $2^{\#\text{非零}}$，不能直接混用。Lagrange 四平方和定理保证每个 $N$ 至少一种表示（答案 $\ge1$），但本题 $N\le10000$ 直接枚举即可，无需搬这些重定理。

## 二、思维链：完整证明

**记号。** $P_t=\{(x,y)\in\mathbb Z_{\ge0}^2:x^2+y^2=t\}$，$\texttt{cnt}[t]=|P_t|$。$Q=\{(a,b,c,d)\in\mathbb Z_{\ge0}^4:a^2+b^2+c^2+d^2=N\}$ 为所求方案集（有序，见引理 1）。$Q_s=\{(a,b,c,d)\in Q:a^2+b^2=s\}$。

### 引理 1（计顺序：题意判定）

题目所求为**有序**四元组个数 $|Q|$。

*证明*：题面举例 $(1,2,3,4)$ 与 $(4,3,2,1)$ 是"两种不同方法"，明确把不同排列计为不同方案。$N=4$ 的样例列出 $5$ 种：$(1,1,1,1)$ 与 $(2,0,0,0)$ 的 $4$ 个排列。有序计数 $=1+4=5$，与样例一致；无序计数 $=2$（仅两个多重集），与样例矛盾。故"不讲究顺序"一句与举例及样例冲突，以举例和样例为准，计顺序。证毕。

### 引理 2（搜索范围：边长 $\le\lfloor\sqrt N\rfloor\le100$）

任何解的每个边长 $\le\lfloor\sqrt N\rfloor\le100$；双重循环 `a=0..⌊√N⌋, b=0..⌊√(N-a²)⌋` 恰好遍历所有平方和 $\le N$ 的有序对，不重不漏。

*证明*：边长非负，$a^2\le a^2+b^2+c^2+d^2=N$，故 $a\le\sqrt N$，整数即 $a\le\lfloor\sqrt N\rfloor\le\lfloor\sqrt{10000}\rfloor=100$。循环条件 `a*a<=n` 与 `a*a+b*b<=n` 正是 $a\le\sqrt N$、$b\le\sqrt{N-a^2}$ 的整数写法，遍历的恰是 $\{(a,b)\ge0:a^2+b^2\le N\}=\bigcup_{s\le N}P_s$，每个有序对访问一次。证毕。

### 引理 3（`cnt` 正确）

预处理后 $\texttt{cnt}[s]=|P_s|$（$0\le s\le N$）。

*证明*：由引理 2，双重循环把每个满足 $a^2+b^2\le N$ 的有序对 $(a,b)$ 恰好访问一次，每次 `++cnt[a*a+b*b]`。故 $\texttt{cnt}[s]$ 累计的恰是平方和为 $s$ 的有序对个数 $=|P_s|$。$s>N$ 的格子不会被用到（卷积只取 $s,N-s\in[0,N]$）。证毕。

### 引理 4（折半卷积公式）

$|Q|=\sum_{s=0}^{N}\texttt{cnt}[s]\cdot\texttt{cnt}[N-s]$。

*证明*：按 $s=a^2+b^2$ 把 $Q$ 划分：$Q=\bigsqcup_{s=0}^{N}Q_s$（每个四元组的 $a^2+b^2$ 唯一确定一个 $s\in[0,N]$，各类不交且并为全体）。

固定 $s$，映射 $(a,b,c,d)\mapsto\bigl((a,b),(c,d)\bigr)$ 是 $Q_s$ 到 $P_s\times P_{N-s}$ 的双射：

- 良定义：$(a,b)\in P_s$（$a^2+b^2=s$），$(c,d)\in P_{N-s}$（$c^2+d^2=N-s$）。
- 单射：四元组由两个有序对唯一拼回。
- 满射：任给 $(a,b)\in P_s$、$(c,d)\in P_{N-s}$，拼成的四元组平方和 $=s+(N-s)=N$ 且 $a^2+b^2=s$，属于 $Q_s$。

故 $|Q_s|=|P_s|\cdot|P_{N-s}|=\texttt{cnt}[s]\cdot\texttt{cnt}[N-s]$（乘法原理）。对 $s$ 求和即得 $|Q|$。证毕。

### 引理 5（值域与复杂度）

$\texttt{cnt}[s]\le\lfloor\sqrt N\rfloor+1\le101$；$\sum_{s=0}^N\texttt{cnt}[s]\le(\lfloor\sqrt N\rfloor+1)^2\le10201$；答案 $\le101\times10201=1030301<2^{31}$，`int` 安全（代码用 `i64` 更稳）。时间 $O(N)$、空间 $O(N)$。

*证明*：固定 $a$，方程 $b^2=s-a^2$ 在 $b\ge0$ 中至多一个解（平方函数在 $\ge0$ 单射），故 $|P_s|\le\#\{a:0\le a\le\sqrt N\}=\lfloor\sqrt N\rfloor+1\le101$。$\sum_s\texttt{cnt}[s]=|\bigcup_{s\le N}P_s|\le(\lfloor\sqrt N\rfloor+1)^2\le10201$（引理 2 的遍历范围）。于是

$$|Q|=\sum_s\texttt{cnt}[s]\texttt{cnt}[N-s]\le\bigl(\max_s\texttt{cnt}[s]\bigr)\sum_s\texttt{cnt}[N-s]\le101\times10201=1030301<2^{31},$$

`int` 足够，`i64` 累加零成本保险。

时间：预处理迭代次数 $=|\bigcup_{s\le N}P_s|=\#\{(a,b)\ge0:a^2+b^2\le N\}\approx\frac{\pi N}{4}+O(\sqrt N)\le10201$；卷积 $N+1\le10001$ 次乘加；合计 $O(N)$。空间：`cnt` 数组 $N+1\le10001$ 个 `int`，$O(N)$。证毕。

### 定理

程序输出有序四元组个数 $|Q|$，即题目方案总数；时间 $O(N)$、空间 $O(N)$。

*证明*：引理 1 确定计数对象为有序四元组；引理 2、3 保证 `cnt` 正确且遍历不重不漏；引理 4 把 $|Q|$ 化为卷积 $\sum_s\texttt{cnt}[s]\texttt{cnt}[N-s]$，正是代码所算；引理 5 给出值域安全与 $O(N)$ 复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 题面"不讲究顺序"与举例自相矛盾，用 $N=4\to5$（有序 $5$、无序 $2$）判定**计顺序**。
- **explore its property** — 边长非负、平方和 $=N$ ⇒ 每边 $\le\lfloor\sqrt N\rfloor\le100$；供应无限可重复、$0$ 合法。
- **consider easier version** — 四重循环 $101^4\approx10^8$ 偏大 → 三重 + 完全平方判定 $\approx10^6$ 可过但非最优。
- **reduce to easier problem** — $4$ 平方拆 $2+2$：四元组 ↔ 有序对之对，按前半面积和 $s$ 分类。
- **classic problem solution** — meet in the middle：预处理 $\texttt{cnt}[s]$（平方和为 $s$ 的有序对数），答案 $=\sum_s\texttt{cnt}[s]\texttt{cnt}[N-s]$，$O(N)$。
- **discuss by category** — 值域：$\texttt{cnt}\le101$、答案 $\le10^6$，`int` 安全；Jacobi/Lagrange 是带符号/存在性定理，本题直接枚举即可，不混用。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 目标面积 $N$（$1\le N\le10000$） | `int`，读入 | |
| `cnt[s]` | 平方和恰为 $s$ 的**有序非负整数对** $(a,b)$ 个数 | `int[mxn]`，全局默认 $0$ | "cnt = 两平方表示数" |
| `ans` | 有序四元组总数 $\sum_s\texttt{cnt}[s]\texttt{cnt}[n-s]$ | `i64`，初值 $0$ | 折半卷积 |
| `a,b` | 预处理枚举的两个边长 | `int` | $a^2+b^2\le n$ |
| `s` | 卷积枚举的前半面积和 | `int` | $0\le s\le n$ |
| `mxn` | $10000+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 $n$。
3. 预处理：`for a=0; a*a<=n; ++a`，`for b=0; a*a+b*b<=n; ++b`，`++cnt[a*a+b*b]`（引理 2、3）。
4. 卷积：`for s=0..n`，`ans += (i64)cnt[s]*cnt[n-s]`（引理 4）。
5. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间 $O(N)$：预处理约 $\frac{\pi N}{4}\le10201$ 次自增，卷积 $N+1$ 次乘加。
- 空间 $O(N)$：`cnt` 约 $40$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$N=1..10$ 与手工枚举逐位一致（`4 6 4 5 12 12 4 6 16 18`）；$N=4\to5$ 吻合题面样例；$N=25\to28$、$N=100\to59$ 经手工按多重集数排列核实；$N=10000\to1217$，运行瞬时。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2666 [USACO07OCT] Bessie's Secret Pasture S
// 思路：数有序四元组 (a,b,c,d)≥0 使 a²+b²+c²+d²=N（样例 N=4→5 说明计顺序）。
//       2+2 折半：cnt[s]=平方和为 s 的有序非负整数对数，
//       答案 = Σ cnt[s]·cnt[N-s]。边长 ≤100，总复杂度 O(N)。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};

int n,cnt[mxn];
i64 ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int a=0;a*a<=n;++a)
		for(int b=0;a*a+b*b<=n;++b)
			++cnt[a*a+b*b];			// 每个有序对 (a,b) 恰好计一次
	for(int s=0;s<=n;++s)
		ans+=1ll*cnt[s]*cnt[n-s];	// 前两块面积和 s，后两块面积和 n-s
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **计顺序是题意判定**：`cnt` 数的是**有序**对（$(0,1)$ 与 $(1,0)$ 各算一个），卷积自然给出有序四元组，与 $N=4\to5$ 一致。若误改成无序（强制 $a\le b$）会数错。
- **折半卷积**：`ans += cnt[s]*cnt[n-s]` 把"四平方"拆成两个"两平方"独立选取，$O(N)$ 取代 $O(N^2)$ 的四重循环。
- **循环边界 `a*a<=n`、`a*a+b*b<=n`**：恰好遍历平方和 $\le n$ 的有序对，不重不漏（引理 2）；边长上界 $100$ 自动满足。
- **`1ll*` 防溢出**：虽然已证答案 $\le10^6$、`int` 足够，`i64` 累加是零成本保险。
- `cnt` 全局默认 $0$，无需显式初始化；$s>n$ 的格子不会被访问。
