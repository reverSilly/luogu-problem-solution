# P2941 [USACO09FEB] Surround the Islands S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 有 $N$ 个顶点（$3\le N\le 500$，编号 $1..N$）和 $N$ 条边，每条边给出的一对顶点属于**同一个岛屿**且相邻；每个岛是一个多边形（环），但**顶点属于哪个岛不直接给出**。任意两顶点间有航线，费用由对称矩阵 $c_{ij}\le 1000$ 给出。FJ 的行动规则：

- 可以从**任何顶点**开始装篱笆（装篱笆本身不花钱，只有坐船花钱）；
- 装完一个岛后，可以坐船到另一个岛的某个顶点，把那个岛**整个**装完，然后**马上坐船原路返回**；
- 目标：装完所有岛，最小化总船费。

先把规则里三个决定建模的口径钉死：

1. **"马上原路返回"是硬约束**：每次外出必须回到出发顶点，不能"装完 A 岛直接去 B 岛"。这意味着行动轨迹是以某个"母岛"为中心的**星形往返**，而不是链式巡游。这是全题的题眼。
2. **岛上走动免费**：题面只给船费矩阵，且说"可以从任何一个顶点坐船"。所以回到母岛后，他可以自由走到母岛的任何顶点再出发；同理到达目标岛后从哪个顶点开始装都行。依据：若岛上移动也要钱，题目必须给出岛上移动的费用模型，而它没有。
3. **每个岛恰好外出访问一次**：费用非负，重复访问只会多花钱；母岛自己不用坐船（起点任选）。

**手造小数据核对**（题面无样例）：

第一组：$N=3$，边 $(1,2),(2,3),(3,1)$——只有一个三角形岛。不用坐船，答案 $0$。

第二组：$N=6$，两个三角形岛 $\{1,2,3\},\{4,5,6\}$，跨岛最小船费在 $(2,5)$ 处取 $7$，其余跨岛费用 $8,9$。无论母岛选谁，都要往返另一个岛一次：$2\times 7=14$。

第三组（专打"母岛选择"）：$N=9$，三个三角形岛 $A=\{1,2,3\},B=\{4,5,6\},C=\{7,8,9\}$，岛间最小船费 $d(A,B)=3$（顶点对 $(1,4)$）、$d(A,C)=5$（$(2,7)$）、$d(B,C)=4$（$(5,8)$）。三种母岛方案的单程和：选 $A$ 为 $3+5=8$，选 $B$ 为 $3+4=7$，选 $C$ 为 $5+4=9$。最优母岛是 $B$，答案 $2\times 7=14$。**若程序不枚举母岛、固定选第一个岛，会输出 $16$**——这组数据专门否掉那种写法。

三组程序输出 $0,14,14$，与手算一致。

## 二、思维链：完整证明

### 第一步：读懂"马上原路返回"到底锁死了什么

**探索性质。** 第一反应是"这不是 TSP 吗？"——访问所有岛、最小化路费。但 TSP 允许 $A\to B\to C$ 链式移动，本题却规定每次装完新岛**必须立刻原路返回**。把一次"外出"定义成：从当前所在顶点 $u$ 坐船到另一岛顶点 $v$，装完该岛，坐船回 $u$。注意装岛是沿多边形走一整圈，**起点 $v$ 装完一圈后回到 $v$**，所以返程确实是 $v\to u$，与去程互为反向。于是每次外出结束后，FJ 的位置**不变**（还在 $u$）。位置不变 ⇒ 下一次外出仍从同一个岛出发 ⇒ 所有外出共享同一个母岛。星形结构是被规则**强制**的，不是我们选出来的。

### 引理 1（最优策略的星形结构）

存在最优策略形如：选定一个母岛 $H$，先装好 $H$（免费），然后对其余每个岛 $C$ 恰做一次往返外出；总费用 $=\sum_{C\ne H}(\text{该次往返费用})$，且外出顺序不影响总费用。

*证明*：由题面规则，任何合法策略都是"装母岛 + 若干次外出"的序列（第一次装岛免费，因为起点任选；此后每装一个新岛必须伴随一次外出并返回）。由上面的位置不变论证，所有外出都从母岛 $H$ 的某顶点出发、回到该顶点。

**每个非母岛至少外出一次**：否则它的篱笆没装完。**恰一次最优**：费用矩阵非负，若某岛被外出访问 $k\ge 2$ 次，删掉其中 $k-1$ 次（及其装篱笆动作，第一次已装完）仍合法且费用不增。故存在最优策略每个非母岛恰访问一次。

**顺序无关**：每次外出的费用只取决于（出发顶点，到达顶点）这对选择，与之前做过什么外出无关（位置始终回到原处，船费矩阵静态）。故总费用是各项之和，顺序任意。证毕。

### 第二步：岛在哪里？——并查集

**探索性质。** 输入不告诉我们顶点属于哪个岛，只给"同岛相邻"的边。但"同岛"恰好就是这些边的**连通关系**：一个岛是多边形，其顶点沿边连成一圈；不同岛之间没有边。所以：

### 引理 2（岛 = 连通块）

以 $N$ 条给定边建无向图，则每个连通块恰为一个岛的全部顶点。

*证明*：($\subseteq$) 同一岛的顶点沿多边形边界两两相邻成环，环上任意两点沿环可达，故同岛 ⇒ 同连通块。($\supseteq$) 每条边的两端同岛（题面），故连通路径上相邻顶点同岛，由传递性整条路径同岛，故同连通块 ⇒ 同岛。两者互含，连通块 = 岛。证毕。

于是用并查集（DSU）合并 $N$ 条边即得所有岛，$O(N\,\alpha(N))$。

### 第三步：缩点——把岛压成超级点

**归约。** 引理 1 说总费用是"母岛到各岛往返费"之和。一次外出可以任选母岛顶点 $u$ 与目标岛顶点 $v$（口径 2：岛上走动免费），所以该次外出的最优费用只依赖两个岛，不依赖具体顶点。定义

$$d(H,C)=\min_{u\in H,\ v\in C} c_{uv}.$$

### 引理 3（单次外出的最优费用）

从母岛 $H$ 出发装完岛 $C\ne H$ 并返回，最小费用为 $2\,d(H,C)$。

*证明*：**下界**：任一次外出选某对 $(u,v)$，去程 $c_{uv}$；装完一圈回到 $v$；返程"原路"即 $v\to u$，由矩阵对称 $c_{vu}=c_{uv}$。费用 $2c_{uv}\ge 2d(H,C)$。**可达**：取达到最小值的 $(u^\*,v^\*)$，从 $u^\*$ 出发到 $v^\*$ 装完返回，费用恰 $2d(H,C)$。上下界夹逼。证毕。

（注意这里用到了对称性保证；题面明确"两个岛屿间两个方向的旅行费用相等"。即使矩阵不对称，原路返回也意味着返程走同一条航线，费用仍按同一矩阵元计，结论不变。）

### 引理 4（总费用公式与母岛枚举）

最优答案 $=2\cdot\min_{H}\sum_{C\ne H} d(H,C)$，$H,C$ 取遍所有岛。

*证明*：由引理 1，最优策略是星形且每岛恰访问一次；由引理 3，各次外出独立地取到 $2d(H,C)$（各次外出的顶点对选择互不干扰——回到母岛后可自由换出发顶点）；母岛 $H$ 本身免费且可任选（起点任选）。对 $H$ 取 min 即得。反过来，任何 $H$ 对应的星形策略都合法，故 min 可达。证毕。

**特例**：只有一个岛时求和为空，答案 $0$——公式自动覆盖，无需特判。

### 第四步：实现层面的两个不变量

### 引理 5（岛间最小费表的正确计算）

对每对顶点 $u<v$，若其所属连通块代表元 $r_u\ne r_v$，用 $c_{uv}$ 同时松弛 $best[r_u][r_v]$ 与 $best[r_v][r_u]$（取 min）。全部处理完后，对任意两个不同连通块 $A,B$，$best[A][B]=d(A,B)$。

*证明*：跨块顶点对 $(u,v)$（$u\ne v$）在枚举 $u<v$ 时恰被扫到一次；每次扫描把 $c_{uv}$ 计入它所属的块对。故 $best[A][B]$ 恰为 $\min\{c_{uv}:u\in A,v\in B\}$（对称性保证两个方向枚举到的是同一个值集）。**初值必须显式填 INF**：$best$ 是 min 表，全局默认 $0$ 会把所有岛间距离静默变成 $0$，答案错成 $0$ 而不报错——这是"全局数组默认 0 不是 INF"陷阱的标准形态。本题任意两顶点有航线且费用 $\le 1000$，故最终每个用到的 $best[A][B]\le 1000$，INF 不会残留在答案里。证毕。

### 引理 6（复杂度与值域）

时间 $O(N^2+N\,\alpha(N))$，空间 $O(N^2)$；答案 $\le 2\times(\lceil N/3\rceil-1)\times 1000<3.4\times 10^5$，int 安全。

*证明*：DSU 合并 $N$ 次 $O(N\alpha(N))$；读矩阵与枚举顶点对 $O(N^2)$；枚举母岛 $O(N)$ 个、每个求和 $O(N)$ 个块，共 $O(N^2)$。$N=500$ 时约 $2.5\times 10^5$ 次基本操作。空间：两个 $505\times 505$ 的 int 矩阵约 $2$ MB。值域：每个岛是多边形至少 $3$ 顶点，岛数 $\le N/3$；每项 $d\le 1000$，故单程和 $\le (N/3)\times 1000\approx 1.67\times 10^5$，翻倍后仍远小于 int 上限。证毕。

### 定理

程序输出装完所有岛的最小总船费 $2\cdot\min_H\sum_{C\ne H}d(H,C)$，复杂度 $O(N^2)$。

*证明*：引理 2 保证 DSU 分块即分岛；引理 5 保证 $best$ 表即 $d$；引理 1、3、4 保证星形公式就是最优值；程序对每个代表元求和取 min 再乘 $2$，正是引理 4 的公式；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — "马上原路返回"锁死位置：每次外出回到出发顶点 ⇒ 所有外出共享母岛，星形结构是被强制的，不是 TSP。
- explore its property — 岛不直接给出，但"同岛相邻"边的连通块恰是岛 ⇒ 并查集分块。
- reduce to easier problem — 岛上走动免费 ⇒ 每个岛缩成一个超级点，点间边权 = 跨岛顶点对的最小船费 $d(H,C)$。
- consider easier version — 两个岛时答案显然 $2d$；多个岛时母岛免费，问题变成"选一个中心使到其余点距离和最小"。
- classic problem solution — 枚举所有顶点对建块间 min 表（$O(N^2)$），再枚举母岛求和取 min（$O(N^2)$）。
- discuss by category — 单岛答案 $0$（空和自动覆盖）；min 表必须显式填 INF，全局默认 $0$ 会静默错成答案 $0$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 顶点数 = 边数，$\le 500$ | `int` | 读入 |
| `f[x]` | DSU 父亲 | `int[mxn]` | `iota` 自环；`getrt` 路径压缩 |
| `c[i][j]` | 顶点 $i\to j$ 船费，对称 $\le 1000$ | `int[mxn][mxn]` | 读入，0-based |
| `best[A][B]` | 块 $A,B$ 间最小船费 $d(A,B)$ | `int[mxn][mxn]` | **`fill_n` 全表 INF**；min 表 |
| `mxn` | $500+5$ | `constexpr int` | |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 远大于 $1000$ |
| `ru,rv` | 顶点所属块代表元 | `int` | `getrt` 现查 |
| `s` | 当前母岛到其余各岛的单程费之和 | `int`，每岛清零 | |
| `ans` | 最优单程和 | `int` | 初值 `inf` |

### 算法步骤

1. I/O 加速三行；读 $N$；`iota(f,f+n,0)`。
2. 读 $N$ 条边，`--u;--v`，`f[getrt(u)]=getrt(v)` 合并。
3. 读 $N\times N$ 船费矩阵。
4. `best` 全表填 `inf`；枚举 $u<v$，跨块则用 `c[u][v]` 双向松弛 `best`。
5. 枚举每个代表元 $i$（`getrt(i)==i`）作母岛：对其余代表元 $j$ 累加 `best[i][j]` 得 `s`，`ans=min(ans,s)`。
6. 输出 `2*ans`。

### 复杂度

- 时间：$O(N^2+N\,\alpha(N))$，$N=500$ 时约 $2.5\times 10^5$ 次操作。
- 空间：$O(N^2)$，约 $2$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；三组手造数据（单岛 $0$、双岛 $14$、三岛选最优母岛 $14$，后者能区分"固定母岛"的错误写法输出 $16$）全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2941 [USACO09FEB] Surround the Islands S
// 并查集缩出岛屿；岛间最小船费 best[A][B]；枚举母岛，答案 = 2*min(到其余各岛最小费之和)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{505};
constexpr int inf{1145141919};

int n,f[mxn],c[mxn][mxn],best[mxn][mxn];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	iota(f,f+n,0);
	for(int i=0,u,v;i<n;++i)
	{
		cin>>u>>v;--u;--v;
		f[getrt(u)]=getrt(v);
	}
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			cin>>c[i][j];
	fill_n(&best[0][0],mxn*mxn,inf);	// best 是 min 表，必须显式填 INF
	for(int u=0;u<n;++u)
		for(int v=u+1;v<n;++v)
		{
			int ru=getrt(u),rv=getrt(v);
			if(ru!=rv)
			{
				best[ru][rv]=min(best[ru][rv],c[u][v]);
				best[rv][ru]=min(best[rv][ru],c[u][v]);
			}
		}
	int ans=inf;
	for(int i=0;i<n;++i)
		if(getrt(i)==i)	// 枚举母岛（每个连通块的代表元）
		{
			int s=0;
			for(int j=0;j<n;++j)
				if(j!=i&&getrt(j)==j)
					s+=best[i][j];
			ans=min(ans,s);
		}
	cout<<2*ans<<'\n';	// 每次外出必须原路返回，费用翻倍
	return 0;
}
```

### 代码说明

- **`fill_n(&best[0][0],mxn*mxn,inf)` 是本题最容易丢的一行**：`best` 是 min 表，全局默认 $0$ 会让所有岛间距离变成 $0$，程序不崩、答案静默错成 $0$。
- 母岛枚举用"代表元"判据 `getrt(i)==i`：路径压缩后非根节点的 `f[i]!=i`，每个块恰一个代表元被枚举，不重不漏。
- 枚举顶点对只扫 $u<v$：矩阵对称，每对跨块顶点贡献一次即可，双向写 `best` 是为了后面按任意顺序查表。
- 单岛时内层求和为空、`s=0`，`ans=0`，输出 $0$，无需特判。
- 乘 $2$ 放在最后：星形结构下每次外出都是往返，统一翻倍比逐项乘更不易漏。
- 值域 $\le 3.4\times 10^5$，全程 `int` 足够；哨兵用 114514 家族。
