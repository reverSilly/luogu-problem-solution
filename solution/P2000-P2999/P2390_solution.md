# P2390 地标访问 — 题解

## 一、解题过程：人类思考叙事

题目：把道路看成数轴，贝西从原点 $0$ 出发，每分钟走 $1$ 单位距离。有 $n$ 个地标（$1\le n\le 5\times10^4$），坐标 $x_i$ 互不相同、$|x_i|\le 10^5$。$t$ 分钟后日落（$1\le t\le 10^9$），**日落时不用回到原点**。问最多能访问多少个地标（路过就算访问）。题面没有样例，下面的例子都是我手算并程序核对的。

**第一个念头：按时间模拟。** $t\le10^9$，一分钟一分钟走根本不行，光循环就超时。而且"往哪走"本身就是决策，模拟还得配贪心。

**第二个念头：贪心——每次去最近的未访问地标。** 听起来很自然，但我构造了一个反例：

地标 $\{-2,\ 1,\ 5\}$，$t=9$。

- 贪心：从 $0$ 出发最近的是 $1$（距离 $1$），走到 $1$，用时 $1$；此时未访问的有 $-2$（距离 $3$）和 $5$（距离 $4$），选 $-2$，用时 $4$；再去 $5$ 要 $7$ 分钟，总用时 $11>9$。**只访问了 $2$ 个。**
- 更优：先向左走到 $-2$（用时 $2$），再掉头一路向右走到 $5$（用时 $7$，途中经过 $1$），总共 $2+7=9\le 9$。**访问了 $3$ 个。**

贪心错在哪？它只看"下一步最近"，完全没考虑**折返代价**：先向右 $1$ 再回头向左 $2$，等于把 $0\to1$ 这段路走了两遍还多。而"先左后右"虽然第一步远一点，却是一条不折返的长路。

**第三个念头：访问过的地标有什么结构？** 这是本题的突破口。贝西的位置是时间的**连续函数** $p(\tau)$，$p(0)=0$。设她这段时间内到达的最左位置为 $L$、最右为 $R$，则 $L\le0\le R$，而且由连续性（介值定理），$[L,R]$ 里的**每一个点都被她踩过**。所以：

$$\text{访问的地标集合}=\{i:L\le x_i\le R\}.$$

把坐标排序后，这个集合就是**一段连续的下标区间**！而且这段区间必须"跨过原点"（$L\le0\le R$）。于是问题从"规划一条路线"变成了"**选一个跨过 $0$ 的区间 $[L,R]$，在时间预算内让它包含尽量多的地标**"。

**第四个念头：覆盖 $[L,R]$ 最少要多久？** 她必须到达 $L$ 和 $R$ 两个端点，只有两种顺序：

- 先左后右：$0\to L\to R$，路程 $|L|+(R-L)=R-2L$；
- 先右后左：$0\to R\to L$，路程 $R+(R-L)=2R-L$。

取较小者：$\min(R-2L,\ 2R-L)=(R-L)+\min(-L,R)$。也就是"**总跨度 + 较短的那一半**"——先把近的那端吃掉，再一路走到远的那端，绝不回头。这个式子既给出了构造（上界），也能用"首次到达 $L$ / 首次到达 $R$ 谁先谁后"证明是最优（下界），后面严格写。

**第五个念头：端点可以规范化。** $L,R$ 本来可以是任意实数，但注意到代价 $(R-L)+\min(-L,R)$ 关于 $R$ 单调增、关于 $-L$ 单调增，而区间里的地标数在"收缩到不丢失任何地标"时不变。所以可以把 $L$ 往右收到"$0$ 或最左边那个被访问的地标"，把 $R$ 往左收到"$0$ 或最右边那个被访问的地标"，代价只减不增、计数不变。**候选端点只剩 $O(n)$ 个：$0$ 和各地标坐标。**

**第六个念头：怎么枚举才不超时？** 两端各 $O(n)$ 个候选，暴力配对是 $O(n^2)=2.5\times10^9$，太慢。但固定一端后，另一端的最优值是**单调**的：

设我向左访问最靠近原点的 $a$ 个负坐标地标（它们必然是 $x$ 排序后负数段的最后 $a$ 个），最左到达 $L=-d$，$d\ge0$。由覆盖公式，可行的 $R\ge0$ 满足
$$\min(R+2d,\ 2R+d)\le t\iff R\le t-2d\ \ \text{或}\ \ R\le\frac{t-d}2.$$
所以 $R$ 的上界就是 $R_{\max}=\max\!\left(t-2d,\ \left\lfloor\frac{t-d}2\right\rfloor\right)$（坐标是整数，故下取整）。**固定 $a$ 后，右侧能取到的地标数就是"正坐标中 $\le R_{\max}$ 的个数"，一次 `upper_bound` 搞定。**

于是算法：排序 → 枚举 $a=0..p$（$p$ 是负坐标个数）→ 每次二分 → 取最大。$O(n\log n)$。

**为什么只枚举左侧就够了？不用对称地再枚举右侧？** 因为任何一个最优解都有"它访问了 $a^\*$ 个负地标"这件事，我的循环一定会枚举到 $a=a^\*$；在那一轮里 $R_{\max}\ge R^\*$（$R^\*$ 是那个最优解的右端），所以算出的计数 $\ge$ 最优解的计数。而我算出的每个计数又都真实可达，于是最大值恰好等于最优。**一侧枚举 + 两种顺序取 max，已经覆盖了"先左后右"和"先右后左"全部情形。**

**坑点清单（都是我真踩过的）：**

1. **$t\le10^9$**：$t-2d$、$(t-d)/2$ 都要用 `long long` 算，虽然本题数值上 `int` 也够（$10^9+2\times10^5<2^{31}$），但混用容易在别处翻车，统一 `i64` 最稳。
2. **下取整**：$(t-d)/2$ 必须是**下取整**。因为 $R$ 是整数坐标，$R\le\frac{t-d}2$ 等价于 $R\le\lfloor\frac{t-d}2\rfloor$；C++ 的正数除法天然下取整，但如果 $t-d$ 可能为负就要小心——好在我们先判了 $d\le t$。
3. **$d>t$ 时直接 `break`**：$d(a)=-x[p-a]$ 随 $a$ **严格递增**（坐标互不相同），一旦超预算，后面所有 $a$ 都超，可以整段剪掉。写成 `continue` 也对但白跑。
4. **原点上的地标白送**：$x_i=0$ 的地标在 $\tau=0$ 就访问了，不占任何时间。要单独计数（代码里的 `z`），否则 `upper_bound` 在正数段里数不到它。
5. **$R_{\max}$ 要 $\ge0$**：若两个上界都是负数，说明只能不去右边（$R=0$），此时计数为 $a+z$。实际上 $d\le t$ 时 $\lfloor(t-d)/2\rfloor\ge0$ 自动成立，`max(...,0LL)` 是防御性写法。
6. **不用加回程**：题面 Hint 明说"日落时不用回到原点"，所以覆盖公式里**没有** $+|L|$ 或 $+R$ 的回程项。如果误加回程，就变成 $\min(2R-2L,\dots)$ 之类，答案会偏小。
7. **$t=0$**：只能访问原点处的地标（若有），答案 $0$ 或 $1$。代码里 $a=0,d=0,R_{\max}=0$，正数段一个也数不到，恰好正确。

**手算校验：**

- $\{-3,4\}$，$t=9$：覆盖两端需 $\min(4+6,\ 8+3)=10>9$，只能选一个 ⇒ $1$。$t=10$ ⇒ $2$。
- $\{-2,-1,1,2\}$，$t=5$：$a=1$（$d=1$）时 $R_{\max}=\max(5-2,\lfloor4/2\rfloor)=3$，右侧 $\le3$ 的有 $1,2$ 两个 ⇒ $1+2=3$；$a=2$（$d=2$）时 $R_{\max}=\max(1,1)=1$ ⇒ $2+1=3$。全取 $4$ 个需 $(2+2)+2=6>5$ ⇒ 答案 $3$。$t=6$ 时 $a=2$ 给 $R_{\max}=2$ ⇒ $4$ ✓。
- $\{-2,1,5\}$，$t=9$：$a=1$（$d=2$）时 $R_{\max}=\max(9-4,\lfloor7/2\rfloor)=5$ ⇒ 右侧 $1,5$ 两个 ⇒ $1+2=3$ ✓（正是贪心反例的正确答案）。
- $\{-5,0,5\}$，$t=0$ ⇒ $1$（原点那个）✓。

## 二、思维链：完整证明

### 模型形式化

贝西的运动是连续函数 $p:[0,t]\to\mathbb R$，$p(0)=0$，且满足 Lipschitz 条件 $|p(\tau)-p(\tau')|\le|\tau-\tau'|$（速度不超过 $1$）。**路径长度** $\ell(p)=\sup$  over 所有分划 $\sum|p(\tau_{i+1})-p(\tau_i)|$；由 Lipschitz 条件，$\ell(p)\le t$，且"以速度 $1$ 沿折线走"时 $\ell(p)$ 恰等于所用时间。地标 $i$ 被访问 $\iff\exists\tau\in[0,t],p(\tau)=x_i$。目标：最大化被访问地标数。

### 引理 1（访问集合是跨 $0$ 的连续区间）

设 $L=\min_{\tau\in[0,t]}p(\tau)$，$R=\max_{\tau\in[0,t]}p(\tau)$（连续函数在紧区间上取到最值）。则 $L\le0\le R$，且地标 $i$ 被访问 $\iff L\le x_i\le R$。因此把 $x$ 升序排序后，被访问地标恰为一段连续下标区间。

*证明*：$p(0)=0$ 故 $L\le0\le R$。

（$\Rightarrow$）若 $p(\tau)=x_i$，由最值定义 $L\le x_i\le R$。

（$\Leftarrow$）设 $L\le x_i\le R$。取 $\tau_L,\tau_R$ 使 $p(\tau_L)=L$、$p(\tau_R)=R$。$p$ 在 $[\min(\tau_L,\tau_R),\max(\tau_L,\tau_R)]$ 上连续，由介值定理，$x_i$ 介于 $L,R$ 之间必被取到，即存在 $\tau$ 使 $p(\tau)=x_i$，且 $\tau\in[0,t]$。故被访问。

排序后 $\{i:L\le x_i\le R\}$ 是一段连续下标：设 $i<j<k$ 且 $i,k$ 都属于该集合，由 $x$ 升序得 $L\le x_i\le x_j\le x_k\le R$，故 $j$ 也属于该集合——这正是"下标区间"的定义。证毕。

### 引理 2（覆盖区间的最短时间）

设 $L\le0\le R$。从 $0$ 出发、访问 $[L,R]$ 中所有点所需的最短时间（$=$ 最短路径长度）为
$$C(L,R)=\min(R-2L,\ 2R-L)=(R-L)+\min(-L,\ R).$$

*证明*：

**下界。** 若 $L=R=0$，则 $p$ 恒为 $0$（最值都是 $0$），原地不动即覆盖 $[0,0]$，用时 $0=C(0,0)=\min(0,0)$，结论成立。否则 $L\ne R$（$L<0<R$ 或其中之一为 $0$）。设 $\tau_L=\inf\{\tau:p(\tau)=L\}$、$\tau_R=\inf\{\tau:p(\tau)=R\}$，由连续性与最值可达性，二者都存在且 $p(\tau_L)=L$、$p(\tau_R)=R$，且 $\tau_L\ne\tau_R$（因 $L\ne R$）。

路径长度对区间可加且不小于位移绝对值：$\ell(p)\ge|p(\tau_L)-p(0)|+|p(\tau_R)-p(\tau_L)|$ 若 $\tau_L<\tau_R$（把路径按 $0,\tau_L,\tau_R$ 分段，每段长度 $\ge$ 该段位移绝对值，丢掉其余非负段）。即 $\ell(p)\ge|L|+(R-L)=R-2L$。同理若 $\tau_R<\tau_L$，$\ell(p)\ge R+(R-L)=2R-L$。两种情形必有其一，故
$$\ell(p)\ge\min(R-2L,\ 2R-L).$$

**上界（构造）。** 走折线 $0\to L\to R$：长度 $|L-0|+|R-L|=(-L)+(R-L)=R-2L$，以速度 $1$ 走恰用时 $R-2L$，且由介值定理覆盖 $[L,R]$ 全部点。走折线 $0\to R\to L$：长度 $R+(R-L)=2R-L$，同样覆盖 $[L,R]$。取两者中较短者即达到下界。

**化简。** $R-2L\le 2R-L\iff -2L\le R-L\iff -L\le R$。故 $\min(R-2L,2R-L)=(R-L)+\min(-L,R)$（当 $-L\le R$ 时取 $R-2L=(R-L)+(-L)$，否则取 $2R-L=(R-L)+R$）。证毕。

**注**：式中没有"回到原点"的项，正对应 Hint 1。若要求回到 $0$，最短时间会变成 $2(R-L)$，本题不是。

### 引理 3（端点规范化）

存在最优解，其 $L\in\{0\}\cup\{x_i:x_i<0\}$、$R\in\{0\}\cup\{x_i:x_i>0\}$。即端点只需在"$0$ 或地标坐标"中取。

*证明*：取任一最优解，其极值为 $L\le0\le R$，访问集合 $V=\{i:L\le x_i\le R\}$（引理 1）。若 $V=\varnothing$，则答案 $0$，取 $L=R=0$ 即可（$C(0,0)=0\le t$）。

否则令 $L'=\min(\{0\}\cup\{x_i:i\in V\})$，$R'=\max(\{0\}\cup\{x_i:i\in V\})$。则 $L\le L'\le0\le R'\le R$，且 $L'$ 要么是 $0$、要么是 $V$ 中最小的地标坐标（负数或 $0$）；$R'$ 同理。

**计数不变**：$[L',R']\subseteq[L,R]$，且 $[L,L')$ 与 $(R',R]$ 中不含任何地标（否则该地标属于 $V$，与 $L',R'$ 的定义矛盾）。故 $\{i:L'\le x_i\le R'\}=V$。

**代价不增**：$C(L',R')=(R'-L')+\min(-L',R')$。因 $R'\le R$、$-L'\le -L$，两项都单调不减于各自变量，故 $C(L',R')\le C(L,R)\le t$。

于是 $(L',R')$ 是可行的、访问数相同的最优解，且端点取自所述候选集。证毕。

**推论（左侧枚举的参数化）**：规范化后，被访问的负地标恰是"最靠近 $0$ 的 $a$ 个负坐标"（$a\ge0$），因为它们是 $\{x_i<0\}$ 中 $\ge L'$ 的那些，而 $L'$ 本身是其中一个（或 $0$）。记 $d=-L'\ge0$，则 $d=0$（$a=0$）或 $d=-x_{(a)}$，其中 $x_{(a)}$ 是第 $a$ 靠近 $0$ 的负坐标。

### 引理 4（固定左侧后右侧的可行域）

设向左最远到达 $-d$（$d\ge0$）。则存在合法的 $R\ge0$ 当且仅当 $d\le t$；此时可行的整数 $R$ 恰为
$$0\le R\le R_{\max}(d):=\max\left(t-2d,\ \left\lfloor\frac{t-d}2\right\rfloor\right).$$

*证明*：由引理 2，需 $C(-d,R)=\min(R+2d,\ 2R+d)\le t$。

**必要性 $d\le t$**：$R\ge0$ 故 $R+2d\ge2d$、$2R+d\ge d$，于是 $\min(R+2d,2R+d)\ge d$，要 $\le t$ 必须 $d\le t$。

**可行域刻画**：$\min(A,B)\le t\iff A\le t\ \text{或}\ B\le t$。故
$$\min(R+2d,2R+d)\le t\iff R\le t-2d\ \text{或}\ R\le\frac{t-d}2.$$
两个条件都是"$R$ 不超过某上界"，其并集就是"$R$ 不超过两上界的较大者"：
$$R\le\max\left(t-2d,\ \frac{t-d}2\right).$$
因 $R$ 取整数（地标坐标为整数，且由引理 3 可设 $R$ 为 $0$ 或某正地标坐标），$R\le\frac{t-d}2\iff R\le\lfloor\frac{t-d}2\rfloor$；又 $d\le t$ 保证 $t-d\ge0$，整数除法即下取整。故整数可行域为 $R\le R_{\max}(d)$。

**非空性**：$d\le t$ 时 $\lfloor(t-d)/2\rfloor\ge0$，故 $R_{\max}\ge0$，$R=0$ 总是可行（此时 $C(-d,0)=\min(2d,d)=d\le t$）。代码里的 `max(...,0LL)` 只是防御性写法。

**充分性（可达）**：对任意整数 $0\le R\le R_{\max}$，$R$ 必不超过两个上界之一，对应引理 2 的两种走法之一，用时 $\le t$，覆盖 $[-d,R]$。证毕。

### 引理 5（只枚举左侧即覆盖最优）

设最优答案为 $\mathrm{OPT}$。算法枚举 $a=0..p$、每轮计数 $\mathrm{cnt}(a)=a+z+\#\{x_i>0:x_i\le R_{\max}(d(a))\}$（$z$ 为原点地标数，$0$ 或 $1$），则 $\max_a\mathrm{cnt}(a)=\mathrm{OPT}$。

*证明*：

**（$\le$，每个计数都可达）** 对任一 $a$ 且 $d(a)\le t$：取 $L=-d(a)$、$R=R_{\max}(d(a))$。由引理 4，$C(L,R)\le t$，走法存在；由引理 1，访问集合为 $[L,R]$ 内全部地标，即"最靠近 $0$ 的 $a$ 个负地标" $+$ "原点地标（若有）" $+$ "$\le R$ 的全部正地标"，三部分互不相交，个数恰为 $\mathrm{cnt}(a)$。故 $\mathrm{cnt}(a)\le\mathrm{OPT}$。

**（$\ge$，最优解被枚举到）** 由引理 3 及其推论，存在最优解访问了某个 $a^\*\in[0,p]$ 个负地标，左端 $L^\*=-d(a^\*)$，右端 $R^\*\ge0$，且 $C(L^\*,R^\*)\le t$。由引理 4 的必要条件，$d(a^\*)\le t$（故算法不会在这一轮 `break`），且 $R^\*\le R_{\max}(d(a^\*))$。于是
$$\mathrm{OPT}=a^\*+z+\#\{x_i>0:x_i\le R^\*\}\le a^\*+z+\#\{x_i>0:x_i\le R_{\max}(d(a^\*))\}=\mathrm{cnt}(a^\*)\le\max_a\mathrm{cnt}(a).$$

双向夹逼得等式。证毕。

**注**：这里**不需要**对称地再枚举右侧。原因是引理 4 的 $R_{\max}$ 已经把"先左后右"（$R\le t-2d$）与"先右后左"（$R\le(t-d)/2$）两种顺序**同时**纳入并取了 max；枚举左侧 $a$ 只是固定了区间的一个端点，另一个端点的最优值由可行域直接给出。

### 引理 6（$d(a)$ 严格递增与 `break` 的合法性）

设升序数组中负坐标为 $x[0..p-1]$（$x[0]<x[1]<\dots<x[p-1]<0$）。定义 $d(0)=0$、$d(a)=-x[p-a]$（$1\le a\le p$）。则 $d(0)<d(1)<\dots<d(p)$，故一旦 $d(a)>t$，对所有 $a'>a$ 都有 $d(a')>t$，可以 `break`。

*证明*：$a\ge1$ 时 $d(a)=-x[p-a]>0=d(0)$。对 $1\le a<p$，$p-(a+1)=p-a-1<p-a$，由严格升序 $x[p-a-1]<x[p-a]$，取负号反向得 $d(a+1)>d(a)$。故序列严格递增；递增序列一旦超过 $t$，后面全部超过 $t$，由引理 4 这些 $a$ 全不可行，跳过不影响答案。证毕。

（题面保证坐标互不相同，故"严格"成立；即使有重复，也只是变成非严格递增，`break` 依然正确。）

### 引理 7（计数的实现正确性）

设 $p=\#\{x_i<0\}$，$z=[\exists x_i=0]$，排序后正坐标段为 $x[p+z..n-1]$。则对给定 $R\ge0$，$\#\{x_i>0:x_i\le R\}=\texttt{upper\_bound}(x+p+z,\ x+n,\ R)-(x+p+z)$，且总访问数 $=a+z+\text{该计数}$。

*证明*：排序后 $x[0..p-1]<0$，$x[p]=0$（若 $z=1$），$x[p+z..n-1]>0$ 且升序。`upper_bound` 返回首个 $>R$ 的位置，故 $[p+z,\text{该位置})$ 内的元素恰为 $\le R$ 的正坐标，个数即差值。三部分（$a$ 个负地标、原点地标、$\le R$ 的正地标）符号不同或位置不同，互不相交；由引理 1，它们都落在 $[-d,R]$ 内且被访问，而 $[-d,R]$ 内也没有别的地标（负地标中 $<-d$ 的不在区间内，正地标中 $>R$ 的不在区间内）。故总数为三者之和。证毕。

### 引理 8（单调性：可选的 $O(n)$ 双指针）

$R_{\max}(d)$ 关于 $d$ 单调不增，故 $\mathrm{cnt}(a)$ 中的右侧计数关于 $a$ 单调不增。因此排序后可用双指针把总复杂度降到 $O(n)$。

*证明*：$d_1<d_2\Rightarrow t-2d_1>t-2d_2$ 且 $\lfloor(t-d_1)/2\rfloor\ge\lfloor(t-d_2)/2\rfloor$，两个上界都不增，故其 max 不增。正坐标段升序，$\#\{x\le R\}$ 关于 $R$ 单调不减，复合后关于 $a$ 单调不增。于是随着 $a$ 递增，右指针只需单调左移，总移动 $O(n)$。证毕。

（本文实现用二分，$O(n\log n)$ 已远低于限制，且与题面"二分"标签一致；双指针作为可选优化记录在此。）

### 引理 9（复杂度与值域）

时间 $O(n\log n)$，空间 $O(n)$；所有中间量在 `i64` 下安全。

*证明*：排序 $O(n\log n)$；枚举 $a$ 至多 $p+1\le n+1$ 轮，每轮一次 `upper_bound` 为 $O(\log n)$，合计 $O(n\log n)$。空间为一个长度 $n$ 的数组加常数个标量，$O(n)$。

值域：$t\le10^9$，$d\le10^5$，故 $t-2d\in[-2\times10^5,10^9]$，$\lfloor(t-d)/2\rfloor\in[0,5\times10^8]$，$R_{\max}\le10^9$；`upper_bound` 的比较是 `int < i64`，安全。答案 $\le n\le5\times10^4$。全部远小于 `i64` 上界。证毕。

### 定理（算法正确性）

程序输出的 `ans` 等于贝西在 $t$ 分钟内能访问的最多地标数。

*证明*：引理 1 把"路线规划"等价于"选跨 $0$ 区间 $[L,R]$"；引理 2 给出覆盖该区间的充要时间条件；引理 3 把端点候选缩到 $0$ 与地标坐标，并推出"左侧必是最靠近 $0$ 的 $a$ 个"；引理 4 给出固定 $a$ 后 $R$ 的完整可行域；引理 5 证明单侧枚举取 max 恰为最优；引理 6 保证 `break` 剪枝不丢解；引理 7 保证每轮计数正确；引理 9 保证无溢出。故输出正确。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — $t\le10^9$ ⇒ 按时间模拟不可行；必须找结构。
- **consider easier version** — 先试"每次去最近未访问地标"的贪心，用 $\{-2,1,5\},t=9$ 打出反例（贪心 $2$，最优 $3$），定位失败原因是忽略了折返代价。
- **explore its property** — 位置是时间的连续函数 ⇒ 访问集合 $=[L,R]$ 内全部地标，排序后是**一段连续区间**且跨过 $0$。
- **classic problem solution** — 数轴上覆盖区间的最短折返路程：$\min(R-2L,2R-L)=(R-L)+\min(-L,R)$，"先近端后远端"，用首次到达顺序证下界、用两条折线证上界。
- **reduce to easier problem** — 代价对 $R$、$-L$ 单调 ⇒ 端点可收缩到 $0$ 或地标坐标，候选从连续变成 $O(n)$ 个。
- **discuss by category** — 固定左侧 $a$ 个（最靠近 $0$ 的负地标），右侧可行域是两条线性约束的并 ⇒ $R_{\max}=\max(t-2d,\lfloor(t-d)/2\rfloor)$。
- **classic problem solution** — 排序 + `upper_bound` 数右侧个数，$O(n\log n)$；只枚举一侧即覆盖最优（两种行走顺序已在 $R_{\max}$ 里取过 max）。
- **explore its property** — $d(a)$ 严格递增 ⇒ $d>t$ 时 `break`；$R_{\max}$ 单调不增 ⇒ 可选双指针降到 $O(n)$。
- **discuss by category** — 边界：原点地标白送（`z`）、$t=0$、$R_{\max}$ 夹到 $\ge0$、下取整、`i64`、不加回程。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `t` | 日落前的分钟数（$\le10^9$） | `i64`，读入 | 时间预算 = 路程预算 |
| `n` | 地标数（$\le5\times10^4$） | `int`，读入 | 注意输入顺序是 **t 在前** |
| `x[i]` | 地标坐标，读入后升序排序 | `int[mxn]` | 0-based，互不相同 |
| `p` | 负坐标个数 $=\#\{x_i<0\}$ | `int`，`lower_bound(x,x+n,0)-x` | `x[0..p-1]<0` |
| `z` | 原点是否有地标（$0/1$） | `int`，`p<n&&x[p]==0` | 白送的一个 |
| `a` | 枚举量：访问最靠近 $0$ 的 $a$ 个负地标 | `int`，$0..p$ | 左侧决策 |
| `d` | 向左最远距离 $=-L$ | `i64`，`a?-x[p-a]:0` | 随 `a` 严格递增 |
| `R` | 该 `d` 下向右可达的最远整数坐标 | `i64`，`max({t-2*d,(t-d)/2,0LL})` | 两种走法取 max |
| `cnt` | 正坐标中 $\le R$ 的个数 | `int`，`upper_bound` 差值 | 右侧计数 |
| `ans` | 最多访问地标数 | `int`，初值 $0$ | `max(ans,a+z+cnt)` |
| `mxn` | $5\times10^4+5$ | `constexpr int mxn{50005}` | +5 松弛 |

### 算法步骤

1. I/O 加速：`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`。
2. 读入 `t,n`（**t 在前**），读入 `x[0..n-1]`，`sort(x,x+n)`。
3. 求 `p=lower_bound(x,x+n,0)-x`（负坐标个数）与 `z=(p<n&&x[p]==0)`（原点地标）。
4. `ans=0`。枚举 `a=0..p`：
   1. `d = a ? -x[p-a] : 0`；
   2. 若 `d>t` 则 `break`（引理 6：后面全不可行）；
   3. `R = max({t-2*d,(t-d)/2,0LL})`（引理 4：先左后右 / 先右后左）；
   4. `cnt = upper_bound(x+p+z,x+n,R)-(x+p+z)`（引理 7）；
   5. `ans = max(ans,a+z+cnt)`。
5. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(n\log n)$（排序 + 至多 $n+1$ 次二分）。$n=5\times10^4$ 时实测约 $0.1$ s（含读入）。
- 空间：$O(n)$，一个 `int[50005]`，约 $200$ KB。
- 值域：中间量 $\le10^9$ 量级，`i64` 全程安全（引理 9）。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；题面无样例，改为与**完全独立的状压 TSP 暴力**（$dp[mask][i]$ = 从 $0$ 出发恰好访问 $mask$、停在 $i$ 的最短路程，答案 = 满足 $\min_i dp\le t$ 的最大 $|mask|$，不使用任何区间/折返公式）**端到端对拍 362 组**（$n\le11$，含 22 组手工边界 + 300 组随机小坐标 + 40 组大坐标/大 $t$），$0$ mismatch；另在 $n=3000$ 的 10 组数据上与 $O(n^2)$ 端点对枚举法一致，并在 $n=5\times10^4$ 上通过规模测试。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2390 地标访问
// 思路：连续行走 ⇒ 访问集合 = 排序后一段跨 0 的区间 [L,R]
//       覆盖 [L,R] 的最短路程 = min(R-2L,2R-L) = (R-L)+min(-L,R)
//       端点可收缩到 0 或地标坐标；枚举左侧访问 a 个负地标（最靠近 0 的 a 个）
//       d=-L 固定后，R 的可行上界 = max(t-2d, (t-d)/2)，upper_bound 数右侧个数
//       只枚举左侧即覆盖最优（两种行走顺序已在 max 里）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{50005};

int n,x[mxn];
i64 t;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>t>>n;                       // 注意：t 在前，n 在后
	for(int i=0;i<n;++i)
		cin>>x[i];
	sort(x,x+n);

	int p=lower_bound(x,x+n,0)-x;    // x[0..p-1] 为负坐标
	int z=(p<n&&x[p]==0);            // 原点处的地标白送
	int ans=0;
	for(int a=0;a<=p;++a)            // 枚举访问最靠近原点的 a 个负坐标地标
	{
		i64 d=a?-x[p-a]:0;           // 向左走的最远距离
		if(d>t)
			break;                   // d 随 a 严格递增，后面全不可行
		// 先左后右：R+2d<=t；先右后左：2R+d<=t
		i64 R=max({t-2*d,(t-d)/2,0LL});
		int cnt=upper_bound(x+p+z,x+n,R)-(x+p+z);
		ans=max(ans,a+z+cnt);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **输入顺序是 `t n`**，不是 `n t`。题面第一行写的是"两个整数 $t,n$"，读反了会全盘皆错。
- **`p` 与 `z` 把数组切成三段**：`x[0..p-1]` 负、`x[p]` 可能为 $0$、`x[p+z..n-1]` 正。二分只在正数段做，原点地标用 `z` 单独加，负地标用 `a` 单独加，三者不重不漏。
- **`d=a?-x[p-a]:0`**：`a` 个最靠近 $0$ 的负坐标是 `x[p-1],x[p-2],...,x[p-a]`，其中最远的是 `x[p-a]`，取负号得距离。`a=0` 时不向左走，`d=0`。
- **`break` 而不是 `continue`**：`d` 严格递增（引理 6），超预算后无需再看。
- **`max({t-2*d,(t-d)/2,0LL})`**：三项都是 `i64`（`0LL` 保证初始化列表类型一致）。`t-2*d` 对应"先左后右"，`(t-d)/2` 对应"先右后左"，整数除法在 `t>=d` 时就是下取整。`0LL` 是防御性夹紧。
- **`upper_bound` 的比较是 `int < i64`**：标准库模板按 `value` 的类型推导，`int` 会提升为 `i64`，不会截断。
- **没有回程项**：Hint 1 明确"日落时不用回到原点"，所以覆盖公式是 $(R-L)+\min(-L,R)$ 而不是 $2(R-L)$。
- 全程 `i64` 参与时间运算，`x` 用 `int` 存（$|x_i|\le10^5$），`mxn{50005}` 是 $5\times10^4+5$ 的松弛。
