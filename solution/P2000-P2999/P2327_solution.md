# P2327 [SCOI2005] 扫雷 — 题解

## 一、解题过程：人类思考叙事

题意重述：棋盘是 $n$ 行 $2$ 列。**第一列**的某些格子是雷，**第二列没有雷**。第二列每个格子里写着"它 $8$ 邻域内的雷数"（因为它自己不是雷，所以数字总是显示出来的）。现在给出第二列 $n$ 个数字，问第一列的雷有多少种摆法（即方案数，$n\le 10000$）。

**第一步：把图形信息翻译成下标方程。** 这是本题唯一需要"建模"的地方，值得慢一点数。第二列第 $i$ 格记为 $(i,2)$，它的 $8$ 邻域（不含自己）是 5 个格子：

$$(i-1,1),\ (i,1),\ (i+1,1),\ (i-1,2),\ (i+1,2).$$

其中后两个在第二列，而第二列没有雷 ⇒ 贡献为 $0$。于是

$$a_i=b_{i-1}+b_i+b_{i+1},$$

这里 $b_j=1$ 表示第一列第 $j$ 格有雷、$0$ 表示没有；棋盘外的格子不存在，视为 $0$，即 $b_0=b_{n+1}=0$。这一条式子是全题的骨架：**第二列的数字只"看得见"第一列相邻的三格**。

顺带澄清一个常见误会：第一列的格子自己也会显示数字（如果它不是雷），但那些数字**没有给**，所以它们不构成任何约束，不需要检查。我们只需要让给定的 $n$ 个 $a_i$ 全部被满足。

**第二步：局部约束 ⇒ 想到 DP。** 每个方程只牵连相邻三个格子，这是典型的"轮廓线 DP"形状：从左往右扫，状态只需要记住"上一格和当前格是否有雷"，即 $(b_{i-1},b_i)$ 四种状态，转移由 $a_i$ 决定 $b_{i+1}$。$n\le10^4$、状态 $4$ 个，$O(n)$ 的 DP 是一个可行方向。到这一步题目已经有解了。

**第三步：再挤一下——其实根本没有 DP 的余地。** 盯着 $a_i=b_{i-1}+b_i+b_{i+1}$ 看：$b_{i+1}$ 的系数是 $1$，所以

$$b_{i+1}=a_i-b_{i-1}-b_i$$

是**被唯一解出来**的，不是"可能取 0 也可能取 1"。也就是说：只要 $b_0=0$（棋盘外）与 $b_1$ 定了，$b_2$ 由方程 $1$ 定死，$b_3$ 由方程 $2$ 定死……整条序列没有任何选择余地。而 $b_1$ 只能取 $0$ 或 $1$，**总共只有两个候选**。

于是"计方案数"退化成"枚举两个初值、各模拟一遍、看谁活得下来"。这也解释了为什么答案总是 $0/1/2$：候选只有两条。

**第四步：把"活得下来"的条件写清楚。** 递推中可能出现 $b_{i+1}=2$ 或 $-1$——那不是合法的雷（雷的数量只能是 $0$ 或 $1$），说明这条候选链从某处开始就不可能对应任何布局，整条判死。递推到 $i=n$ 时算出的其实是 $b_{n+1}$，它必须恰为 $0$（棋盘外无雷），这一步**不能漏**。

**碰壁记录（都是我自己先写错再改对的）：**

- **碰壁一：$2^n$ 枚举。** $n\le10^4$，$2^{10000}$ 远超任何时限；它只能用来对拍（$n\le10$ 时很合适，我就这么干了）。
- **碰壁二：以为"中途算出 $2$ 后面还能补救"。** 不能。方程是逐条必须成立的硬约束，$b_{i+1}$ 没有第二个取值可用；一旦越界，后面所有方程都建立在错误的值上，补不回来。
- **碰壁三：漏掉最后一条方程。** 比如 $n=2,a=\{0,1\}$：$b_1=b_2=0$ 满足第一条方程 $a_1=b_0+b_1+b_2=0$，但 $a_2=b_1+b_2+b_3=0\ne1$，实际方案数是 $0$。若不检查"最后算出的 $b_{n+1}=0$"，程序会错答 $1$。
- **碰壁四：以为还要检查第一列自己的数字。** 不用，那些数字没给（见第一步末尾）。

**手造小例子核对（本题题面无样例）：**
- $n=1,a=\{1\}$：$b_1=1$ 一种（$a_1=b_1=1$），答案 $1$。
- $n=2,a=\{1,1\}$：两条方程都化为 $b_1+b_2=1$，故 $(b_1,b_2)=(1,0)$ 或 $(0,1)$，答案 $2$。
- $n=4,a=\{1,2,2,1\}$：由 $b_1+b_2=1$ 与 $b_1+b_2+b_3=2$ 得 $b_3=1$，再由 $b_3+b_4=1$ 得 $b_4=0$，回代得 $b_2=1,b_1=0$，唯一方案 $(0,1,1,0)$，答案 $1$。
- $n=5,a=\{3,3,3,3,3\}$：无论 $b_1$ 取什么都立刻越界，答案 $0$。

## 二、思维链：完整证明

记号：$b_j\in\{0,1\}$ 表示第一列第 $j$ 格是否有雷（$1\le j\le n$），并约定 $b_0=b_{n+1}=0$；$a_i$ 为第二列第 $i$ 格的数字（$1\le i\le n$）。

**引理 1（核心方程）**：任一合法布局都满足，且只需满足
$$a_i=b_{i-1}+b_i+b_{i+1}\qquad(1\le i\le n).$$

*证明*：$a_i$ 是 $(i,2)$ 的 $8$ 邻域内雷数。$(i,2)$ 的 $8$ 邻域（不含自身）为
$$(i-1,1),(i,1),(i+1,1),(i-1,2),(i+1,2).$$
第二列无雷，故其中后两格的雷数恒为 $0$；前三个落在第一列，雷数分别是 $b_{i-1},b_i,b_{i+1}$（越界的 $j$ 视为 $b_j=0$）。求和即得方程。"只需满足"是因为：布局的全部信息就是 $b_1..b_n$，而题面只给了第二列的数字作为约束，第一列的数字不在输入中，故除此 $n$ 条方程外没有别的约束。证毕。

**引理 2（布局与 0/1 向量一一对应）**：第一列的布雷方案与向量 $(b_1,\dots,b_n)\in\{0,1\}^n$ 一一对应。

*证明*：定义映射 $\varphi$：把布局送到向量 $b$，其中 $b_j=1$ 当且仅当第一列第 $j$ 格有雷。$\varphi$ 是单射：两个布局若向量相同，则每一格的"有雷/无雷"都相同，这两个布局就是同一个布局。$\varphi$ 是满射：任给 $b\in\{0,1\}^n$，按 $b_j$ 决定第 $j$ 格是否放雷，得到一个布局，它的 $\varphi$ 值正是 $b$。既单又满，故为一一对应。证毕。

**引理 3（唯一延拓）**：固定 $b_1=t\in\{0,1\}$。若向量 $(b_1,\dots,b_n)$ 满足引理 1 的全部方程，则对每个 $i=1..n$ 有
$$b_{i+1}=a_i-b_{i-1}-b_i,$$
从而整个向量（连同 $b_{n+1}$）被 $t$ 唯一确定。

*证明*：对 $i$ 归纳。方程 $i$ 中 $b_{i+1}$ 的系数为 $1$，故解唯一：$b_{i+1}=a_i-b_{i-1}-b_i$。$b_1=t$ 给定、$b_0=0$ 给定 ⇒ $b_2$ 唯一；设 $b_1..b_i$ 唯一，则 $b_{i+1}$ 由上式唯一。归纳得全序列唯一。证毕。

**推论 3′**：满足引理 1 方程的解至多 $2$ 个（按 $b_1\in\{0,1\}$ 分类，每类至多一个）。

**引理 4（候选合法性判定）**：设从 $t$ 出发按引理 3 递推得到 $c_0=0,\ c_1=t,\ c_{i+1}=a_i-c_{i-1}-c_i\ (1\le i\le n)$。则 $t$ 对应一个合法布局 $\iff$
$$c_i\in\{0,1\}\ (1\le i\le n)\qquad\text{且}\qquad c_{n+1}=0 .$$

*证明*：
（$\Rightarrow$）设合法布局的向量为 $b$，$b_1=t$。由引理 3 的唯一性，$b_i=c_i$（$1\le i\le n$）且 $b_{n+1}=c_{n+1}$。由 $b_i\in\{0,1\}$ 得第一组条件；由棋盘外无雷 $b_{n+1}=0$ 得 $c_{n+1}=0$。

（$\Leftarrow$）设两组条件成立，令 $b_j=c_j$（$1\le j\le n$），$b_0=b_{n+1}=0$。则对 $1\le i\le n-1$：
$$b_{i-1}+b_i+b_{i+1}=c_{i-1}+c_i+c_{i+1}=a_i$$
（等号来自递推式的移项 $c_{i+1}=a_i-c_{i-1}-c_i$）；对 $i=n$：
$$b_{n-1}+b_n+b_{n+1}=c_{n-1}+c_n+0=a_n-c_{n+1}+0=a_n$$
（用 $c_{n+1}=0$）。故引理 1 的全部方程成立，$b$ 是合法布局。证毕。

**引理 5（不重不漏）**：方案数 = $\#\{t\in\{0,1\}: t\text{ 满足引理 4 的条件}\}$，取值 $0,1,2$。

*证明*：不重：$t=0$ 与 $t=1$ 给出的布局 $b_1$ 不同，故是两个不同布局（引理 2 的对应是单射）。不漏：任一合法布局的 $b_1$ 只能是 $0$ 或 $1$，且由引理 3 它就等于对应 $t$ 的递推结果，故被枚举到。于是方案数等于合法 $t$ 的个数；$t$ 只有两个取值，故答案为 $0,1,2$ 之一。证毕。

**引理 6（复杂度）**：时间 $O(n)$，空间 $O(n)$。

*证明*：两个候选各做一次长度 $n$ 的线性递推，$O(n)$；存储 $a_{1..n}$ 需要 $O(n)$。证毕。

**定理**：程序输出正确的方案数。

*证明*：由引理 5，答案等于合法初值个数；程序的循环正是对两个 $t$ 分别实现引理 3 的递推（`prv=b_{i-1}`、`cur=b_i`、`nxt=b_{i+1}`），并用"$nxt\notin\{0,1\}$ 立即判死 + 结束时要求 `cur==0`"精确实现了引理 4 的两组条件（结束时 `cur` 正是 $c_{n+1}$；中途的 $c_i$ 都在 `cur`/`prv` 里被检查过）。故计数正确。证毕。

**备注（与"DP 题"的关系）**：常规写法是 $dp[i][b_{i-1}][b_i]$，$4$ 个状态，转移由 $a_i$ 唯一确定 $b_{i+1}$。注意每个状态**至多有一个后继**（$b_{i+1}$ 被 $a_i$ 唯一确定，还可能因越界而无后继），所以这张 DP 图是若干条互不相交的链而非一般的 DAG：从 $(b_0,b_1)=(0,0)$ 与 $(0,1)$ 出发只有两条链，链的条数就是方案数。既然每条链都只有唯一走法，"枚举初值 + 模拟"与"$4$ 状态 DP"完全等价，而前者更短、更不容易写错转移。这也是本题被标成 DP 却可以用两行递推解决的原因。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 把"$8$ 邻域"数清楚：第二列第 $i$ 格只看得到第一列的 $i-1,i,i+1$ 三格，于是得到方程 $a_i=b_{i-1}+b_i+b_{i+1}$。
2. **explore its property** — 约束是"局部的"（只连相邻三格）⇒ 自然想到沿列扫的轮廓线 DP，状态 $(b_{i-1},b_i)$。
3. **reduce to easier problem** — 关键一步：$b_{i+1}$ 的系数是 $1$ ⇒ 它被 $a_i$ 唯一解出 ⇒ 自由度只剩 $b_1$ 一个。
4. **discuss by category** — 按 $b_1=0$ 与 $b_1=1$ 分两类，各跑一遍"确定化模拟"，合法者计数，答案 $\in\{0,1,2\}$。
5. **explore its property（碰壁/反例）** — $2^n$ 枚举不可行；"中途越界后面能补救"是错的（方程是硬约束）；漏查 $b_{n+1}=0$ 会多算（反例 $n=2,a=\{0,1\}$）。
6. **classic problem solution** — 4 状态 DP 的转移唯一 ⇒ DP 图退化成两条链 ⇒ "枚举初态 + 递推"即最优写法。
7. **边界条件** — $b_0=b_{n+1}=0$；中途值必须落在 $\{0,1\}$；$n=1$ 被同一套逻辑自然覆盖。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| $n$ | 列数（行数为 $2$） | `int`，读入 |
| `a[i]` | 第二列第 $i$ 格的数字（$1$-based，与题面下标一致） | `int a[mxn]`，读入 |
| `b1` | 枚举的初值 $b_1\in\{0,1\}$ | 循环变量 |
| `prv` | 递推中的 $b_{i-1}$ | 每轮初值 $0$（即 $b_0$） |
| `cur` | 递推中的 $b_i$ | 每轮初值 `b1`（即 $b_1$）；结束时它是 $b_{n+1}$ |
| `nxt` | 由方程解出的 $b_{i+1}$ | 每轮由 $a_i-prv-cur$ 计算 |
| `ok` | 本候选链是否还没越界 | 每轮初值 `true` |
| `ans` | 合法候选个数（答案） | 初值 $0$ |

记忆点：`prv`/`cur` 就是滑动窗口 $(b_{i-1},b_i)$；循环结束后 `cur` 变成 $b_{n+1}$，必须为 $0$。

### 算法步骤

1. 读入 $n$ 与 $a_1..a_n$。
2. `ans=0`。
3. 对 `b1=0,1`：
   1. `prv=0`，`cur=b1`，`ok=true`。
   2. 对 $i=1..n$：`nxt=a[i]-prv-cur`；若 `nxt<0||nxt>1` 则 `ok=false` 并跳出；否则 `prv=cur; cur=nxt;`。
   3. 若 `ok && cur==0` 则 `++ans`。
4. 输出 `ans`。

### 复杂度

- 时间：$O(n)$（两个候选各扫一遍）。
- 空间：$O(n)$（`a`；`mxn{10005}` 为 $10000$ 加松弛）。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过。
- 本题题面无样例，手造六组小数据并同时用 $2^n$ 暴力核对：$(n,a)\to$ 答案分别是 $(1,[1])\to1$、$(1,[0])\to1$、$(2,[1,1])\to2$、$(4,[1,2,2,1])\to1$、$(5,[3,3,3,3,3])\to0$、$(3,[0,0,0])\to1$，标程与暴力一致。
- 对拍：与"枚举第一列 $2^n$ 种方案逐格验证"的暴力在 $n\le10$ 上跑 **400 组**（一半由真实布局生成、一半完全随机），输出完全一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2327 [SCOI2005] 扫雷
// 第二列第 i 格的 8 邻域里只有第一列的 i-1,i,i+1 有雷 => a_i = b_{i-1}+b_i+b_{i+1}
// b_{i+1} 的系数是 1 => 由 b_1 唯一确定整列 => 只枚举 b_1 的两种取值
// 中途算出非 0/1 即整条链判死；最后算出的 b_{n+1} 必须为 0
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int n,a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)
		cin>>a[i];
	int ans=0;
	for(int b1=0;b1<2;++b1)
	{
		int prv=0,cur=b1;	//b_0=0（棋盘外无雷），b_1=b1
		bool ok=1;
		for(int i=1;i<=n;++i)
		{
			int nxt=a[i]-prv-cur;	//a_i=b_{i-1}+b_i+b_{i+1}
			if(nxt<0||nxt>1)
			{
				ok=0;
				break;
			}
			prv=cur;
			cur=nxt;
		}
		if(ok&&cur==0)		//最后算出的是 b_{n+1}，必须是 0
			++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 循环体就是一条"滚动两格"的递推：`prv`、`cur` 装着 $(b_{i-1},b_i)$，`nxt` 是解出的 $b_{i+1}$；不需要开 $4$ 状态的 DP 表。
- `if(nxt<0||nxt>1)` 是整条候选链的死刑判决：雷数只能是 $0/1$，越界说明这条链不对应任何布局，必须整条丢弃（不能"跳过去继续"）。
- 循环结束后 `cur` 恰为 $b_{n+1}$，`cur==0` 就是最后一条方程 $a_n=b_{n-1}+b_n+b_{n+1}$ 的检查；漏掉它会把 $n=2,a=\{0,1\}$ 这类数据多算成 $1$。
- `a` 用 $1$-based 存（`a[1..n]`），与递推里 $b_0,b_{n+1}$ 的边界约定对齐，省掉下标偏移的心算。
- 答案范围是 $0..2$，用 `int` 足够；不需要多测清空。

*本题的思维结构是"把网格的 8 邻域翻译成三格线性方程 ⇒ 发现方程给出的是唯一递推 ⇒ 自由度只剩一个初值"；真正的坑是"越界必须整条判死"和"最后那条方程不能漏"。*
