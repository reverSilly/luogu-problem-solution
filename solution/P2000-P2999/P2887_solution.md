# P2887 [USACO07NOV] Sunscreen G — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $C$ 头牛（$C\le2500$），第 $i$ 头能接受的阳光强度是一个**闭区间** $[\text{minSPF}_i,\text{maxSPF}_i]$（$1\le\text{min}\le\text{max}\le1000$）。有 $L$ 种防晒霜（$L\le2500$），第 $j$ 种把强度固定为 $\text{SPF}_j$，共有 $\text{cover}_j$ 瓶（$\le2500$）。每头牛至多涂一瓶，涂了第 $j$ 种就接收强度 $\text{SPF}_j$；只有 $\text{SPF}_j\in[\text{min}_i,\text{max}_i]$ 才算满足。求**最多能满足多少头牛**。

剥掉背景：这是一个**二分图最大匹配**——左边牛、右边"瓶"（第 $j$ 种拆成 $\text{cover}_j$ 个相同的瓶），牛 $i$ 与瓶 $j$ 有边当且仅当 $\text{SPF}_j\in[\text{min}_i,\text{max}_i]$。但边有极强的结构：**每头牛的邻居是 SPF 轴上一段连续区间**。这种"区间匹配"不需要一般图匹配算法，贪心即可。

**第一步：一般匹配为什么是大炮打蚊子。** 瓶总数最多 $\sum\text{cover}_j\le2500\times2500=6.25\times10^6$，跑匈牙利/Dinic 既慢又没必要。区间结构提示我们：**按 SPF 从小到大扫描**，用贪心决定每瓶给谁。

**第二步：扫描框架。** 把防晒霜按 $\text{SPF}$ 升序排。扫到强度 $s$ 时，"有资格"的牛是 $\text{min}_i\le s\le\text{max}_i$ 的那些。其中 $\text{min}_i\le s$ 的牛可以**预先入候选池**（因为 $s$ 递增，一旦 $\text{min}_i\le s$ 就永远 $\le$ 后续 $s$）；而 $\text{max}_i<s$ 的牛**已经过期**——后续 SPF 只会更大，再也救不活，可以永久丢弃。于是候选池里真正可用的，是 $\text{min}_i\le s\le\text{max}_i$ 且尚未被服务的牛。

**第三步：核心贪心——上限紧的牛先救。** 同一强度 $s$ 下有多头合格牛、却只有 $\text{cover}$ 瓶时，给谁？答案是：**$\text{max}_i$ 最小的牛优先**。

直觉：$\text{max}$ 小的牛"窗口窄"，后面强度一大就过期了；$\text{max}$ 大的牛"窗口宽"，留到后面还有救。把稀缺的当前瓶让给最紧迫的牛，选择余地大的牛往后放。

这不是拍脑袋——它需要**交换论证**严格证明（引理 2）：若最优解把当前瓶给了 $\text{max}$ 较大的牛 $X$、而贪心给 $\text{max}$ 较小的 $Y$，总能把两者交换（或把 $Y$ 换进来）而不减少满足数。关键不等式是 $\text{max}_Y\le\text{max}_X$，它保证 $X$ 接手 $Y$ 原来那瓶（强度 $\ge s$）时仍不超上限。

**第四步：数据结构落地。** 候选池要支持"插入 $\text{max}$""删最小 $\text{max}$""弹掉所有 $<s$ 的过期值"——**小根堆**（按 $\text{max}$）正合适：

- 牛按 $\text{min}$ 升序排，指针 $j$ 把 $\text{min}\le s$ 的牛的 $\text{max}$ 依次入堆；
- 弹堆顶直到堆顶 $\ge s$（弹掉的都是过期牛）；
- 弹 $\text{cover}$ 次堆顶（每次 $\text{ans}{+}{+}$），堆空则停。堆顶 $\ge s$ 且其 $\text{min}\le s$，恰好合格。

**第五步：细节。**

1. **过期牛为什么能永久丢**：$s$ 单调递增，$\text{max}_i<s\le s'$ 对所有后续 $s'$ 成立，这头牛再也匹配不上任何剩余瓶。丢弃不影响最优。
2. **同 SPF 多种防晒霜**：排序后顺序处理，候选池跨瓶保留，合格集相同，逻辑不变。
3. **堆里只存 $\text{max}$**：牛一旦入堆就不需要再认身份（只计数），存 $\text{max}$ 一个 `int` 即可。
4. **每头牛只服务一次**：服务即弹堆，不会重复计数。

**手造数据核对。** 题面样例解释"第一头牛涂第一种、第二头牛涂第二种"，据此反推一组（$C=3,L=2$；牛 $[3,10],[2,5],[1,5]$；霜 $(\text{SPF}6,\text{cover}2),(\text{SPF}4,\text{cover}1)$）：

```
2
```

扫描：$s=4$时候选 $\{5,5,10\}$，给 $\text{max}=5$ 的牛一瓶（$\text{ans}=1$）；$s=6$时弹掉过期的 $5$，给 $\text{max}=10$ 的牛一瓶（$\text{ans}=2$）。第三头牛 $[1,5]$ 无霜可用，共 $2$，与解释吻合。

另造三组：

- **贪心选择关键例**：牛 $[1,3],[2,5]$，霜 $(3,1),(5,1)$。$s=3$给 $\text{max}=3$ 的牛，$s=5$给 $\text{max}=5$ 的牛，答案 $2$。若错误地"先给 $\text{max}$ 大的"，$s=3$给了 $[2,5]$，则 $[1,3]$ 在 $s=5$ 过期，只得 $1$。验证"上限紧先救"。
- **过期例**：牛 $[1,2],[5,6]$，霜 $(3,5)$。$[1,2]$ 在 $s=3$ 过期，$[5,6]$ 的 $\text{min}=5>3$ 不入池，答案 $0$。
- **全不合格**：牛 $[1,2],[3,4]$，霜 $(10,5)$，全部过期，答案 $0$。

## 二、思维链：完整证明

**记号。** 牛 $i$ 的区间 $[\ell_i,h_i]$（$\ell=\text{minSPF},h=\text{maxSPF}$）。瓶按 SPF 升序处理，第 $t$ 瓶强度 $s_t$（同种霜的 $\text{cover}$ 瓶强度相同，排序后连续）。贪心：扫到 $s$ 时，把所有 $\ell_i\le s$ 且未入池的牛入小根堆（键 $h_i$）；弹掉堆顶 $<s$ 者；再弹至多 $\text{cover}$ 个堆顶计入答案。称 $\ell_i\le s\le h_i$ 的牛在强度 $s$ **合格**；$h_i<s$ 为**过期**。$\mathrm{Opt}$ 为最大满足数。

---

### 引理 1（过期牛不可逆）

若牛 $i$ 在强度 $s$ 过期（$h_i<s$），则它对任何后续瓶 $s'\ge s$ 都不合格，永久丢弃不改变 $\mathrm{Opt}$。

*证明*：后续瓶强度 $s'\ge s>h_i$，故 $s'\notin[\ell_i,h_i]$，牛 $i$ 与任何剩余瓶都无边。它在任何"只用剩余瓶"的匹配里都是孤立点，删去不影响最大匹配数。贪心弹掉堆顶 $<s$ 正是删去这些孤立点。证毕。

---

### 引理 2（最小上限优先的交换论证）

设当前瓶强度 $s$，贪心把它给合格且未服务的牛 $Y$（$h_Y$ 在候选中最小）。则存在一个最优解，它把这一瓶也给 $Y$（其余分配相应调整），即贪心的这一步不损失最优性。

*证明*：取任一最优解 $O$。若 $O$ 已把当前瓶给 $Y$，无需调整。否则 $O$ 把当前瓶给了某牛 $X\ne Y$（或闲置），分两种情形把 $O$ 改造成"当前瓶给 $Y$"且满足数不减：

**情形 A：$Y$ 在 $O$ 中未被服务。** 把当前瓶从 $X$ 改给 $Y$（$Y$ 合格，合法），$X$ 变为未服务。满足数不变（一换一）。若当前瓶在 $O$ 中本就闲置，则直接给 $Y$，满足数 $+1$，与 $O$ 最优矛盾——故最优解里闲置瓶必无合格未服务牛，此分支不会发生。

**情形 B：$Y$ 在 $O$ 中被某个后续瓶 $s'\ge s$ 服务。** 交换 $X,Y$ 的瓶：$Y$ 拿当前瓶 $s$（合格 ✓），$X$ 拿 $s'$。需验 $X$ 对 $s'$ 合格：
- 下界：$X$ 对当前 $s$ 合格 $\Rightarrow\ell_X\le s\le s'$，故 $\ell_X\le s'$ ✓。
- 上界：$Y$ 在 $O$ 中对 $s'$ 合格 $\Rightarrow s'\le h_Y$；贪心选 $Y$ 因其上限最小 $\Rightarrow h_Y\le h_X$。故 $s'\le h_Y\le h_X$ ✓。

交换后两牛仍各自合格，满足数不变，且当前瓶给了 $Y$。

两种情形都把 $O$ 改成"当前瓶给 $Y$"的最优解。证毕。

**关键不等式**：$s'\le h_Y\le h_X$。正是"$h_Y$ 最小"让 $X$ 能接手 $Y$ 的后续瓶而不超上限——这是整条贪心的命脉。

---

### 引理 3（尽量用满 cover 瓶不浪费）

在强度 $s$，只要还有合格未服务牛，贪心就继续用瓶（直到 $\text{cover}$ 用尽或候选空），这不会损失最优性。

*证明*：对每一瓶重复套用引理 2：第一瓶给当前最小上限牛 $Y_1$，存在最优解与之对齐；在该最优解基础上处理第二瓶，候选里去掉 $Y_1$，再给最小上限牛 $Y_2$，引理 2 的交换论证同样适用（$Y_2$ 的上限 $\le$ 任何被换牛）。逐瓶归纳，贪心用满 $\min(\text{cover},\text{合格牛数})$ 瓶后，仍存在与贪心前缀完全一致的最优解。故"能用就用"不损失最优。证毕。

---

### 引理 4（堆不变量）

处理强度 $s$ 的瓶之前、弹掉过期堆顶之后，小根堆恰含"所有 $\ell_i\le s$、尚未被服务、且 $h_i\ge s$ 的牛"的 $h_i$，即恰好是合格未服务牛集合。

*证明*：对扫描过程归纳。入池：牛按 $\ell$ 升序，指针 $j$ 把所有 $\ell_i\le s$ 的牛入堆一次；因 $s$ 递增，之前入池的牛 $\ell\le$ 旧 $s\le s$ 仍满足，新入池的 $\ell\le s$，故堆中（弹过期前）含所有 $\ell_i\le s$ 且未服务的牛。弹过期：反复弹堆顶 $<s$，由引理 1 这些牛永久无用；弹完后堆顶 $\ge s$，堆内全部 $\ge s$（小根堆性质）。服务：弹堆顶即把该牛标记服务并移出堆。故"弹过期后、服务前"堆恰为 $\{\ell_i\le s,\ h_i\ge s,\ \text{未服务}\}$，正是合格未服务集。证毕。

**推论**：服务时弹的堆顶 $h\ge s$ 且对应牛 $\ell\le s$，确实合格；贪心每步都合法。

---

### 引理 5（贪心全局最优）

贪心满足的牛数 $=\mathrm{Opt}$。

*证明*：对已处理的瓶数归纳，维持不变量"存在一个最优解，与贪心在前 $t$ 瓶上的分配完全一致"。$t=0$ 平凡。设前 $t$ 瓶一致的最优解 $O_t$ 存在；处理第 $t+1$ 瓶（强度 $s$）时，由引理 4 堆给出合格未服务集，由引理 2、3 贪心这 $\text{cover}$ 瓶的每一步都能把 $O_t$ 改造成与贪心前 $t+1$ 瓶一致的最优解 $O_{t+1}$（过期牛由引理 1 本就不在 $O_t$ 的剩余匹配里）。归纳到所有瓶处理完，$O_{\text{末}}$ 与贪心完全一致，故贪心满足数 $=|O_{\text{末}}|=\mathrm{Opt}$。证毕。

---

### 引理 6（复杂度）

时间 $O((C+L)\log C)$，空间 $O(C+L)$。

*证明*：排序牛 $O(C\log C)$、排序霜 $O(L\log L)$。扫描中每头牛至多入堆一次、出堆一次（服务或过期），堆操作 $O(\log C)$，共 $O(C\log C)$；每瓶常数次堆判断，$O(L)$。合计 $O(C\log C+L\log L+C\log C)=O((C+L)\log C)$（$L\le C$ 量级）。空间：牛、霜数组 $O(C+L)$，堆 $O(C)$。代入 $C,L\le2500$，约 $2500\times12\times2\approx6\times10^4$ 次操作，极快。证毕。

---

### 定理

程序输出最多能满足的奶牛数，等于二分图最大匹配 $\mathrm{Opt}$，复杂度 $O((C+L)\log C)$。

*证明*：引理 1 保证过期牛可弃；引理 4 保证堆恰维护合格未服务集；引理 2 的最小上限交换论证 $+$ 引理 3 的逐瓶归纳保证每步贪心不损失最优；引理 5 串联得全局最优；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **reduce to easier problem** — 剥背景成二分图最大匹配（牛 ↔ 瓶），但边是 SPF 轴上的区间，结构特殊。
2. **consider easier version** — 一般匹配 $O(VE)$ 太重（瓶可达 $6\times10^6$），区间结构提示贪心扫描。
3. **explore its property** — SPF 升序扫：$\ell\le s$ 的牛永久入候选，$h<s$ 的牛永久过期（$s$ 单调）。
4. **classic problem solution** — "上限紧的牛先救"：合格牛中 $h$ 最小者优先，交换论证 $s'\le h_Y\le h_X$ 证明最优。
5. **classic problem solution** — 小根堆维护候选 $h$：入池、弹过期、弹顶服务，$O(\log C)$ 每操作。
6. **discuss by category** — 同 SPF 多瓶顺序处理、堆只存 $h$、服务即弹堆防重复、cover 用满或候选空即停。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `c,l` | 牛数、霜种数，$\le2500$ | `int` | 读入 |
| `cow[i]={lo,hi}` | 第 $i$ 头牛区间 | `struct[mxn]` | 按 `lo` 升序排 |
| `bot[i]={spf,cov}` | 第 $i$ 种霜强度与瓶数 | `struct[mxn]` | 按 `spf` 升序排 |
| `mxn` | $2505$ | `constexpr int` | 约束 $+5$ |
| `Q` | 候选牛 `hi` 的小根堆 | `priority_queue<int,vector<int>,greater<>>` | 堆顶 $=$ 最小上限 |
| `j` | 入池指针（按 `lo` 序） | `int`，初值 $0$ | `lo<=s` 就入堆 |
| `s` | 当前瓶强度 | `int` | `bot[i].spf` |
| `ans` | 已满足牛数 | `int`，初值 $0$ | 每服务一头 $+1$ |

### 算法步骤

1. I/O 加速三行；读 $C,L$、牛区间、霜 $(\text{spf},\text{cover})$。
2. 牛按 `lo` 升序排，霜按 `spf` 升序排。
3. `j=0,ans=0`；对每种霜 $i$（强度 $s$）：
   - 入池：`while(j<c && cow[j].lo<=s) Q.push(cow[j++].hi)`。
   - 弹过期：`while(!Q.empty() && Q.top()<s) Q.pop()`。
   - 服务：`for(k=0;k<bot[i].cov && !Q.empty();++k){ Q.pop(); ++ans; }`。
4. 输出 `ans`。

### 复杂度

- 时间：$O((C+L)\log C)$，$C,L\le2500$ 时约 $6\times10^4$ 次操作。
- 空间：$O(C+L)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例解释反推组输出 $2$；"上限紧先救"关键例输出 $2$（错误贪心会得 $1$）、过期例与全不合格例输出 $0$，均与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2887 [USACO07NOV] Sunscreen G
// 防晒霜按 SPF 从小到大扫；lo<=SPF 的牛入小根堆（键 hi）。
// 先弹掉 hi<SPF 的过期牛（之后 SPF 只会更大，永远没救），
// 再把 cover 瓶分给堆顶（hi 最小）的牛：上限紧的牛先救，选择余地大的牛留给后面。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2505};

int c,l;
struct{int lo,hi;}cow[mxn];
struct{int spf,cov;}bot[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>c>>l;
	for(int i=0;i<c;++i)
		cin>>cow[i].lo>>cow[i].hi;
	for(int i=0;i<l;++i)
		cin>>bot[i].spf>>bot[i].cov;
	sort(cow,cow+c,[](auto a,auto b){return a.lo<b.lo;});
	sort(bot,bot+l,[](auto a,auto b){return a.spf<b.spf;});
	priority_queue<int,vector<int>,greater<>>Q;	// 未分配且 lo 已过界的牛，按 hi 小根堆
	int j=0,ans=0;
	for(int i=0;i<l;++i)
	{
		int s=bot[i].spf;
		while(j<c&&cow[j].lo<=s)
			Q.push(cow[j++].hi);
		while(!Q.empty()&&Q.top()<s)	// 过期牛：任何剩余防晒霜都救不了
			Q.pop();
		for(int k=0;k<bot[i].cov&&!Q.empty();++k)
		{
			Q.pop();	// 堆顶 hi>=s 且 lo<=s，恰好可用
			++ans;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **两个排序方向不同**：牛按 `lo` 排（为了指针入池），霜按 `spf` 排（为了扫描）。别排反。
- **小根堆 `greater<>`**：堆顶是最小 `hi`，正是"上限最紧"的牛，贪心核心。
- **三段循环各司其职**：入池（`lo<=s`）、弹过期（`hi<s`）、服务（弹顶 `cover` 次）。弹过期保证服务时堆顶一定 `hi>=s`，加上入池保证 `lo<=s`，故弹顶必合格。
- **堆只存 `hi`**：牛入堆后只需计数，不需身份，一个 `int` 足矣；服务即弹堆，天然防重复。
- **过期牛永久丢弃**（引理 1）：$s$ 单调递增，`hi<s` 的牛对后续所有瓶都无效，弹掉无害。
- 0-based，`'\n'` 换行，全局静态数组，`mxn=2505`。
