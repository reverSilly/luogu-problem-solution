# P2058 [NOIP 2016 普及组] 海港 — 题解

## 一、解题过程：人类思考叙事

题目的形式化描述很清楚：对第 $i$ 条信息，统计满足

$$t_i-86400 < t_p \le t_i$$

的船只 $p$ 的所有乘客中，有多少个**不同的国籍**。

注意这个区间是**左开右闭**的：$t_p = t_i-86400$ 的船**不在**窗口内。这个边界细节是本题最容易踩的坑。

数据范围：$n\le 10^5$，$\sum k_i\le 3\times10^5$，$t_i$ **递增**（不降），$x_{i,j}\le 10^5$。

由于 $t_i$ 递增，第 $i$ 个窗口的右端点 $t_i$ 是单调右移的，而左端点 $t_i-86400$ 也单调右移。所以窗口里的船只集合是一个"整体向右滑动的区间"——这就是**双指针 / 滑动窗口**的标准模型。

具体做法：维护一个队列，里面存着当前还在窗口内的船只编号。

- **右指针**：处理第 $i$ 艘船时，先把队首所有 $t_p\le t_i-86400$ 的船**踢出**窗口；
- **左指针**：再把第 $i$ 艘船**加进**窗口；
- 然后输出当前窗口内不同国籍的个数。

"不同国籍的个数"怎么维护？用计数数组 `cnty[x]` 表示窗口内国籍为 $x$ 的乘客人数，再用一个变量 `diff` 维护"计数非零的国籍种类数"：

- 加入一个国籍为 $x$ 的乘客：若 `cnty[x]` 原来为 $0$，说明是新出现的国籍，`diff++`；然后 `cnty[x]++`；
- 移除一个国籍为 $x$ 的乘客：先 `cnty[x]--`，若变成 $0$，说明这个国籍已经不在窗口里了，`diff--`。

这样每次增删都是 $O(1)$。

一个实现上的选择：**扁平存储所有乘客**。因为输入是一条船一条船给的，如果想"踢掉某条船的所有乘客"，就需要知道这条船的乘客在数组里的位置。两种做法：

1. 用 `vector<int> nat[n]` 存每条船的乘客列表；
2. 把所有乘客**拍平**进一个一维数组 `nat[]`，另用 `st[i]` 记录第 $i$ 艘船的乘客在 `nat[]` 中的起始下标，乘客个数为 `kc[i]`，那么第 $i$ 艘船的乘客就是 `nat[st[i] .. st[i]+kc[i]-1]`。

我选了第二种。它的好处是所有乘客数据在内存里连续，排除了 `10^5` 个 `vector` 的堆分配开销，遍历更快；坏处是要多维护一个 `st[]` 数组。

这里有个**顺序问题**值得强调：题目要求"读入并处理"，但如果边读边处理就无法回头踢船（因为还不知道后面有哪些船）。不过实际上，因为 $t_i$ 递增，处理第 $i$ 艘船时只需要知道 $t_1..t_i$ 的信息——已经读过的船里，只有可能过期的才需要踢掉，而这些船的乘客信息在读入时就已经拿到了。所以两种做法都行。

但"边读边处理"有个隐患：踢船时需要访问**之前**那条船的乘客列表。如果用 `vector<int> nat[n]` 存法就没问题；如果用扁平数组，就必须先读完所有船才能知道 `st[]`。我的标程选择**先读完所有船**（一次性读入 `t[]`、`kc[]` 和扁平的 `nat[]`），然后再统一滑动窗口——这样数据结构最简单，也不会出现"读到一半就要回头删除"的问题。

样例 2：
```
4
1 4 1 2 2 3
3 2 2 3
86401 2 3 4
86402 1 5
```
- 第 1 艘船，窗口是 $(-86399,1]$，只有第 1 艘船，国籍 $\{1,2,3\}$，答案 $3$；
- 第 2 艘船，$t=3$，窗口 $(-86397,3]$，船 1、2，国籍 $\{1,2,3\}$，答案 $3$；
- 第 3 艘船，$t=86401$，窗口 $(1,86401]$，**船 1 的 $t=1$ 不满足 $t>1$，被踢掉**，只剩船 2、3，国籍 $\{2,3,4\}$，答案 $3$；
- 第 4 艘船，$t=86402$，窗口 $(2,86402]$，船 2、3、4，国籍 $\{2,3,4,5\}$，答案 $4$。

输出 `3 3 3 4`，与题面一致。

## 二、思维链：完整证明

**引理 1**（窗口内船只的正确性）：处理第 $i$ 艘船并完成过期删除后，队列中存放的恰好是所有满足 $t_i-86400<t_p\le t_i$ 的船只。

*证明*：分两步说明。

**加入**：算法把第 $i$ 艘船加入队列。由 $t_i\le t_i$，它满足右端点条件。

**删除**：由于 $t_p$ 递增，队列中的船只按 $t_p$ 非降排列，因此"满足 $t_p\le t_i-86400$"的船必然是队列的一个前缀。算法用 `while` 循环不断弹出队首，直到队首的 $t_p>t_i-86400$（或队列为空），故被弹出的恰好是所有 $t_p\le t_i-86400$ 的船。

再看不变量：处理完第 $i-1$ 艘船后，队列恰为满足 $t_{i-1}-86400<t_p\le t_{i-1}$ 的船。处理第 $i$ 艘船时，窗口左端点从 $t_{i-1}-86400$ 右移到 $t_i-86400$（因 $t_i\ge t_{i-1}$，左端点不减），右端点从 $t_{i-1}$ 右移到 $t_i$。

于是 $\{p: t_i-86400<t_p\le t_i\} = \{p: t_{i-1}-86400<t_p\le t_{i-1}\}\cup\{i\}\setminus\{p: t_p\le t_i-86400\}$。这正是算法的"删除 + 加入"两步。由归纳法，结论对所有 $i$ 成立。证毕。

**引理 2**（`diff` 的正确性）：任意时刻，`diff` 等于当前窗口内出现过的不同国籍数。

*证明*：维护不变量"窗口内国籍 $x$ 的乘客数等于 `cnty[x]`，且 `diff` 等于满足 `cnty[x]>0` 的 $x$ 的个数"。

初始时窗口为空，所有 `cnty[x]=0`，`diff=0`，不变量成立。

**加入**一个国籍为 $x$ 的乘客：若 `cnty[x]` 原来为 $0$，则执行 `cnty[x]++` 后变为 $1$，使"计数为正"的国籍多了 $x$ 这一个，故 `diff++`；否则 `cnty[x]` 仍为正，$x$ 本来就被计入，`diff` 不变。算法用 `if(!cnty[x]++) ++diff;` 恰好实现这一逻辑。

**移除**一个国籍为 $x$ 的乘客：算法先执行 `--cnty[x]`。若结果为 $0$，说明 $x$ 不再出现在窗口中，应从"计数为正"的集合里划掉，故 `diff--`；否则 $x$ 仍在窗口中，`diff` 不变。算法用 `if(!--cnty[x]) --diff;` 恰好实现这一逻辑。

两种操作都保持不变量，故 `diff` 始终等于窗口内不同国籍数。证毕。

**定理**：算法输出的第 $i$ 行恰为第 $i$ 条信息的正确答案。

*证明*：由引理 1，窗口内的船只恰为题目要求统计的船只；由引理 2，输出时 `diff` 等于这些船上乘客的不同国籍数；由引理 2 的定义，`cnty` 又精确统计了每个国籍的人数，故 `diff` 就是题目所求。证毕。

## 三、模式总结（按实际思考顺序）

1. **把文字翻译成区间** — "$24$ 小时内"对应 $t_i-86400<t_p\le t_i$，**左开右闭**。
2. **发现单调性** — $t_i$ 递增 ⇒ 窗口两端都单调右移 ⇒ 双指针。
3. **维护集合而非逐个重算** — 每次输出都重扫窗口会退化到 $O(n\sum k)$，必须增量维护。
4. **用"计数 + 不同数"两个量** — `cnty[x]` 记录人数，`diff` 记录种类数，增删都是 $O(1)$。
5. **左开边界的处理** — 过期条件写成 `t_p <= t_i-86400`（含等号地踢掉），而不是 `<`。
6. **数据结构的取舍** — 扁平数组存乘客 + `st[]` 记起始下标，避免 $10^5$ 个 `vector` 的分配开销。
7. **验证方式** — 题面两组样例手算核对；另写"每艘船重建 `set`"的暴力做对拍。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 船只数 | `int`，$\le 10^5$ |
| $t_i$ | 第 $i$ 艘船的到达时间 | `int[]`，$\le 10^9$ |
| $k_i$ | 第 $i$ 艘船的乘客数 | `int[]` |
| $x_{i,j}$ | 第 $i$ 艘船第 $j$ 名乘客的国籍 | `int`，$\le 10^5$ |
| `nat[]` | 扁平存储的所有乘客国籍 | `int[300005]` |
| `st[i]` | 第 $i$ 艘船的乘客在 `nat[]` 中的起始下标 | `int[]` |
| `cnty[x]` | 当前窗口内国籍为 $x$ 的乘客数 | `int[100005]` |
| `diff` | 当前窗口内不同国籍数 | `int`，$\le 10^5$ |
| `q[]` | 队列，存窗口内船只编号 | `int[]` |
| `head`/`tail` | 队列头尾 | `int` |

### 算法步骤

1. 读入 $n$；对每艘船读入 $t_i,k_i$，记录 `st[i]`，并把 $k_i$ 个国籍依次读入扁平数组 `nat[]`。
2. 初始化队列（空）、`diff=0`、所有 `cnty[x]=0`。
3. 依次处理第 $i$ 艘船（$i=1..n$）：
   - **踢出过期船**：`while(head<tail && t[q[head]]<=t[i]-86400)`，对被踢船的每名乘客执行 `if(!--cnty[nat[j]]) --diff;`；
   - **加入当前船**：对每名乘客执行 `if(!cnty[nat[j]]++) ++diff;`，并把 $i$ 入队；
   - 输出 `diff`。

### 复杂度

- 时间复杂度：$O(n+\sum k_i)$。每艘船入队一次、出队至多一次，每名乘客被加入一次、被移除至多一次。
- 空间复杂度：$O(n+\sum k_i+\max x)$，即 $O(n+\sum k_i+10^5)$。

### 验证状态

- 标程 `P2058.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 题面样例 1（`1 4 4 1 2 2 / 2 2 2 3 / 10 1 3`）输出 `3 4 4`；样例 2（`1 4 1 2 2 3 / 3 2 2 3 / 86401 2 3 4 / 86402 1 5`）输出 `3 3 3 4`，均与题面一致。
- 另写暴力 `P2058_brute.cpp`：对每艘船，把窗口内所有乘客的国籍塞进 `set<int>`，输出 `set.size()`。
- 对拍脚本 `P2058_check.py`：**303 组**用例（300 组随机：$n\le8$、时间非递减、含 $k_i=0$ 的船 + 3 组 $86400$ 边界极端：恰好差 $86400$、恰好差 $86401$、同一时刻多船），标程与暴力输出 **0 处不一致**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2058 [NOIP 2016 普及组] 海港
// 思路：时间递增，用队列维护 (t_i-86400, t_i] 这段窗口里的船，
//       再用国籍计数数组维护「出现过的不同国籍数」
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};
constexpr int mxk{300005};

int t[mxn],kc[mxn],st[mxn];
int nat[mxk];			// 扁平存储所有乘客的国籍
int cnty[100005];		// cnty[x]: 当前窗口里国籍 x 的人数
int q[mxn];				// 队列存船的编号

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	int tot=0;
	for(int i=0;i<n;++i)
	{
		cin>>t[i]>>kc[i];
		st[i]=tot;
		for(int j=0;j<kc[i];++j) cin>>nat[tot++];
	}
	int head=0,tail=0;
	int diff=0;				// 当前窗口内不同国籍数
	for(int i=0;i<n;++i)
	{
		// 踢掉过期船：窗口左端开，t_p <= t_i-86400 的都不在窗口内
		while(head<tail&&t[q[head]]<=t[i]-86400)
		{
			int s=q[head++];
			for(int j=st[s];j<st[s]+kc[s];++j)
			{
				if(!--cnty[nat[j]]) --diff;
			}
		}
		// 加入当前船
		for(int j=st[i];j<st[i]+kc[i];++j)
		{
			if(!cnty[nat[j]]++) ++diff;
		}
		q[tail++]=i;
		cout<<diff<<'\n';
	}
	return 0;
}
```

### 代码说明

- **过期条件是 `<=`**：窗口左端是开区间，$t_p=t_i-86400$ 的船刚好在窗口外，必须被踢掉。这里写成 `<` 就会多算一艘船——样例 2 的第三艘船正是这个边界。
- `if(!cnty[nat[j]]++) ++diff;` 与 `if(!--cnty[nat[j]]) --diff;` 是"自增/自减的结果作为条件"的惯用法：前者的 `cnty[x]++` 先把计数加一、后置求值为旧值（是否为 $0$），后者先减一再看是否变成 $0$。两处都在计数跨越 $0$ 时才动 `diff`。
- `nat[]` 扁平存储 + `st[i]` 记起始下标：第 $i$ 艘船的乘客区间是 $[st[i], st[i]+kc[i])$，踢船时按这个区间遍历。
- 队列用数组 `q[]` 配 `head`/`tail` 实现，避免 `std::queue` 的额外开销；`head` 只增不减，总共入队 $n$ 次。
- `t[i]-86400` 用 `int` 计算即可：$t_i\le10^9$，减 $86400$ 不会溢出；即使为负也被 `t[q[head]]<=负数` 正确地判为"全过期"。
