# P2701 [USACO5.3] 巨大的牛棚 Big Barn — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n\times n$ 的农场（$1\le n\le1000$），有 $t$ 棵果树（$1\le t\le10000$），每棵占一个格子，坐标 $(x,y)$（$1\le x,y\le n$）。要找一个**不含任何树**、边与坐标轴平行的正方形区域建牛棚，输出最大边长。题面给了一个 $8\times8$ 的例子：树在 $(2,2),(2,6),(6,3)$，答案 $5$（右下角有两处可放）。

**第一反应：暴力枚举所有正方形。** 边长 $k$ 的正方形有 $(n-k+1)^2$ 个位置，总数 $\sum_{k=1}^{n}(n-k+1)^2\approx n^3/3\approx3.3\times10^8$。每个正方形还要检查内部有没有树，朴素检查 $O(k^2)$，总量天文数字。就算预处理二维前缀和把"区域内树数"降到 $O(1)$ 查询，$3.3\times10^8$ 次查询在 $1$ 秒量级时限下也非常悬。暴力路线不踏实。

**第二步：探性质——可行性对边长单调。** 如果一个 $k\times k$ 的空正方形存在，那么它的任意 $k'\times k'$ 子正方形（$k'\le k$，比如贴着同一个右下角取）也是空的——空区域的子区域还是空区域。所以谓词"$\exists$ 边长 $k$ 的空正方形"关于 $k$ **单调不增**：大边长可行 $\Rightarrow$ 小边长可行。这正是二分答案的前提！于是有一条稳妥的路线：二分边长 $k$，每次用二维前缀和 $O(n^2)$ 扫所有位置检查，总复杂度 $O(n^2\log n)\approx10^7$，能过。这也是题面"前缀和"标签暗示的解法。

**第三步：还能不能把 $\log$ 去掉？** 二分是"全局判定"视角：每次问"边长 $k$ 行不行"。换一个**逐格**视角：对每个格子 $(i,j)$，问"以它为右下角的空正方形最大边长是多少"，记作 $dp[i][j]$。全局答案就是 $\max dp$——因为任何正方形都有唯一的右下角。这是经典"最大正方形"DP 的格局，关键在转移怎么写。

**第四步：猜转移，然后找反例验证。** 一个以 $(i,j)$ 为右下角的 $k$ 正方形，去掉最下面一行、最右边一列、或两者都去掉，就得到以 $(i-1,j)$、$(i,j-1)$、$(i-1,j-1)$ 为右下角的 $k-1$ 正方形。直觉：三个邻居都能撑起 $k-1$，我就能撑起 $k$。于是猜

$$dp[i][j]=\min\bigl(dp[i-1][j],\ dp[i][j-1],\ dp[i-1][j-1]\bigr)+1\quad(\text{格子 }(i,j)\text{ 无树}).$$

**为什么是 $\min$ 而不是 $\max$？为什么对角项不能省？** 拿一个 $2\times2$ 农场、树在左上角 $(1,1)$ 来试：$dp$ 表第一行是 $[0,1]$（树格 $0$，空格 $1$），第二行第一个是 $1$。算右下角时，上 $=1$、左 $=1$，若漏掉对角项写成 $\min(\text{上},\text{左})+1=2$，就宣称整个 $2\times2$ 是空的——可左上角明明有树！对角项 $dp[i-1][j-1]=0$ 恰好把这个洞堵死：$\min(1,1,0)+1=1$，正确。**短板原理**：$k$ 正方形要求三个方向**同时**撑得起 $k-1$，任何一个方向撑不起，整体就撑不起，所以取 $\min$。

反过来，三个邻居都 $\ge m$ 时，三个 $m$ 正方形加上空格 $(i,j)$ 是不是**恰好铺满** $(m+1)$ 正方形、不留缝也不越界？这一步不能靠直觉，我在第二部分逐格分区严格验证（引理 2 的构造方向）。

**第五步：边界与答案。** 第 $0$ 行、第 $0$ 列没有"上方/左方邻居"，越界方向按 $0$ 处理（相当于农场外是宽度 $0$ 的空正方形）；树格 $dp=0$（任何含它的正方形都不空，连 $1\times1$ 都不行）。答案 $=\max_{i,j}dp[i][j]$；全被树占满时（$n=1,t=1$）答案 $0$。复杂度 $O(n^2)=10^6$，比二分路线还少一个 $\log$，而且不用写前缀和。

**坐标的一个小安心点**：输入 $(x,y)$ 哪个是行哪个是列不影响答案——把农场转置，正方形还是正方形，树集合跟着转置，最大边长不变。所以直接 `tr[x][y]=true`（转 0-based）即可。

**手造数据核对**：

| 输入 | 答案 | 打的点 |
|---|---|---|
| 题面 $8\times8$ 例：`8 3` + 树 $(2,2),(2,6),(6,3)$ | $5$ | 与题面文字一致 |
| `2 1` + 树 $(1,1)$ | $1$ | 对角项反例：漏对角会错输出 $2$ |
| `3 1` + 树 $(2,2)$ | $1$ | 中心树卡死所有 $2\times2$ |
| `3 1` + 树 $(1,1)$ | $2$ | 角落树，右下 $2\times2$ 空 |
| `5 5` + 第 $3$ 行整行是树 | $2$ | 横贯障碍，上下各剩 $2$ 行 |
| `1 1` + 树 $(1,1)$ | $0$ | 全占满，答案 $0$ |
| `1000 1` + 树 $(500,500)$ | $500$ | 大规模：任何 $501$ 正方形必含第 $500$ 行与第 $500$ 列，从而必含中心树 |
| `1000 1` + 树 $(1,1)$ | $999$ | 大规模：去掉一角 |

程序输出与手算全部一致，$n=1000$ 单组约 $0.04$ 秒。

## 二、思维链：完整证明

**记号。** 网格格子 $(i,j)$，$0\le i,j<n$（内部 0-based；输入的 $(x,y)$ 读入后 `--x;--y`）。树集合 $T\subseteq[0,n)^2$，$|T|=t$。以 $(i,j)$ 为**右下角**、边长 $k\ge1$ 的正方形定义为
$$S(i,j,k)=\{(i',j'):i-k+1\le i'\le i,\ j-k+1\le j'\le j\}.$$
称 $S(i,j,k)$ **合法**，若它含于网格（即 $i-k+1\ge0$ 且 $j-k+1\ge0$；$i,j<n$ 已给定）；称其**空**，若 $S(i,j,k)\cap T=\varnothing$。定义
$$dp[i][j]=\max\{k\ge1:S(i,j,k)\text{ 合法且空}\},$$
集合为空时 $dp[i][j]=0$。目标 $\mathrm{OPT}=\max\{k:\exists(i,j),\ S(i,j,k)\text{ 合法且空}\}$（不存在时 $0$）。越界邻居的 $dp$ 值一律按 $0$ 参与运算。

---

### 引理 1（可行性向下封闭 / 单调性）

若存在合法且空的 $k$ 正方形，则对每个 $1\le k'\le k$ 都存在合法且空的 $k'$ 正方形。从而谓词 $F(k)=[\exists\text{ 合法且空的 }k\text{ 正方形}]$ 关于 $k$ 单调不增，二分答案合法。

*证明*：设 $S(i,j,k)$ 合法且空。取 $S(i,j,k')$（同一右下角）：其行范围 $[i-k'+1,i]\subseteq[i-k+1,i]$（因 $k'\le k$），列范围同理，故 $S(i,j,k')\subseteq S(i,j,k)$。子集继承合法性（含于网格）与空性（$S(i,j,k)\cap T=\varnothing\Rightarrow$ 子集交 $T$ 亦空）。$k'\ge1$ 时正方形非空、定义有效。故 $F(k)=\text{真}\Rightarrow F(k')=\text{真}$，单调性成立；在单调谓词上二分"最大可行 $k$"是标准且正确的。证毕。

**注**：这条引理支撑第一节里 $O(n^2\log n)$ 的二分 + 前缀和中间解法；最终 DP 解法不需要它，但它解释了"为什么答案这个概念是良定的"——可行边长构成 $\{0,1,\dots,\mathrm{OPT}\}$ 的一个前缀段。

---

### 引理 2（DP 转移，核心）

对树格 $(i,j)\in T$：$dp[i][j]=0$。对空格 $(i,j)\notin T$：
$$dp[i][j]=\min(u,v,d)+1,\quad u=\begin{cases}dp[i-1][j]&i>0\\0&i=0\end{cases},\ v=\begin{cases}dp[i][j-1]&j>0\\0&j=0\end{cases},\ d=\begin{cases}dp[i-1][j-1]&i>0\land j>0\\0&\text{否则}\end{cases}.$$

*证明*：树格情形：任何含 $(i,j)$ 的正方形都与 $T$ 相交，连 $k=1$ 都不可行，定义集合为空，$dp=0$ ✓。

空格情形记 $k=dp[i][j]\ge1$（$k=1$ 总可行：单格 $(i,j)$ 合法且空），$m=\min(u,v,d)$。双向夹逼。

**方向一（$m+1\ge k$，即"最优正方形压迫三个邻居"）**：若 $k=1$，则 $m\ge0$ 给出 $m+1\ge1=k$ ✓。设 $k\ge2$，最优正方形 $S=S(i,j,k)$ 合法且空。考察三个子正方形：

- $S(i-1,j,k-1)$：行范围 $[i-k+1,i-1]\subseteq[i-k+1,i]$，列范围 $[j-k+2,j]\subseteq[j-k+1,j]$，故 $\subseteq S$，继承合法与空；右下角 $(i-1,j)$ 在网格内（$i\ge k-1\ge1$）。由 $dp$ 定义（最大值 $\ge$ 任何可行值），$u=dp[i-1][j]\ge k-1$。
- $S(i,j-1,k-1)$：行 $[i-k+2,i]$、列 $[j-k+1,j-1]$，同理 $\subseteq S$，得 $v\ge k-1$。
- $S(i-1,j-1,k-1)$：行 $[i-k+1,i-1]$、列 $[j-k+1,j-1]$，同理 $\subseteq S$，得 $d\ge k-1$。

三者都 $\ge k-1$，故 $m\ge k-1$，$m+1\ge k$ ✓。

**方向二（$k\ge m+1$，即"三个邻居撑起的正方形真实存在"）**：若 $m=0$：单格 $(i,j)$ 空，$k\ge1=m+1$ ✓。设 $m\ge1$。由 $u\ge m$ 及 $dp$ 定义，$A=S(i-1,j,m)$ 合法且空；同理 $B=S(i,j-1,m)$、$C=S(i-1,j-1,m)$ 合法且空。合法性给出 $i-1-m+1=i-m\ge0$、$j-m\ge0$，故目标 $S^\*=S(i,j,m+1)$（行 $[i-m,i]$、列 $[j-m,j]$）在网格内。下证
$$S^\*=A\cup B\cup C\cup\{(i,j)\},$$
逐格分区验证。任取 $(i',j')\in S^\*$，即 $i-m\le i'\le i$，$j-m\le j'\le j$：

1. $(i',j')=(i,j)$：由第四项覆盖（$(i,j)$ 空是前提）。
2. $i'\le i-1$ 且 $j'\ge j-m+1$：属于 $A$（$A$ 的行 $[i-m,i-1]$、列 $[j-m+1,j]$）✓。
3. $i'\ge i-m+1$ 且 $j'\le j-1$：属于 $B$（$B$ 的行 $[i-m+1,i]$、列 $[j-m,j-1]$）✓。
4. 其余：即 $i'\le i-1$ 且 $j'\le j-1$（不满足 2 的列条件且不满足 3 的列条件时 $j'\le j-1$；不满足 2、3 的行条件时 $i'\le i-1$），结合 $S^\*$ 的范围得 $i'\in[i-m,i-1]$、$j'\in[j-m,j-1]$，属于 $C$ ✓。

四种情形穷尽 $S^\*$ 的所有格子（情形 2、3 可重叠，重叠无害——并集只要求覆盖）。于是 $S^\*$ 的每个格子要么在空的 $A/B/C$ 中、要么是空格 $(i,j)$，故 $S^\*$ 空；又已证合法，所以 $k=dp[i][j]\ge m+1$ ✓。

双向夹逼得 $k=m+1$。证毕。

**反例复盘（为什么对角项不可省）**：$n=2$、$T=\{(0,0)\}$。$dp[0][0]=0$（树），$dp[0][1]=dp[1][0]=1$。若转移写成 $\min(u,v)+1$，则 $dp[1][1]=2$，宣称 $S(1,1,2)$ 空；但 $(0,0)\in S(1,1,2)\cap T$，矛盾。漏洞出在方向二的构造：只有 $A$（行 $[0,0]$、列 $[1,1]$）与 $B$（行 $[1,1]$、列 $[0,0]$）时，格子 $(0,0)$ 不在 $A\cup B\cup\{(1,1)\}$ 里——**左上角缺了一块**，恰好由 $C=S(0,0,m)$ 负责覆盖，而 $C$ 的可行性正是 $d$ 项。$\min$ 取短板则保证三个方向同时成立，构造才无缝。

---

### 引理 3（答案 $=\max dp$）

$\mathrm{OPT}=\max_{0\le i,j<n}dp[i][j]$。

*证明*：双向。

（$\le$）对每个 $(i,j)$，若 $dp[i][j]=k\ge1$，由定义存在合法且空的 $S(i,j,k)$，故 $\mathrm{OPT}\ge k$；$dp=0$ 时平凡。取 max 得 $\mathrm{OPT}\ge\max dp$。

（$\ge$）若 $\mathrm{OPT}=0$ 平凡。否则设最优正方形为 $S(i^\*,j^\*,\mathrm{OPT})$，它合法且空，由 $dp$ 定义 $dp[i^\*][j^\*]\ge\mathrm{OPT}$，故 $\max dp\ge\mathrm{OPT}$。

夹逼得等式。证毕。

**这条引理说明"逐格视角"没有丢失任何方案**：每个正方形都有唯一右下角，枚举右下角 = 枚举所有正方形，只是把"对每个正方形检查空性"重组成了"对每个格子递推最大边长"。

---

### 引理 4（计算顺序与无后效性）

按行优先（$i=0..n-1$ 外层，$j=0..n-1$ 内层）计算，每个 $dp[i][j]$ 依赖的 $u,v,d$ 都已就绪；整表正确。

*证明*：$dp[i][j]$ 依赖 $dp[i-1][j]$（上一行，整行已算完）、$dp[i][j-1]$（本行前一列，已算）、$dp[i-1][j-1]$（上一行，已算）；$i=0$ 或 $j=0$ 时相应依赖按 $0$ 处理，无需读取。依赖图是 DAG 且行优先序是其拓扑序。对行优先序做归纳：基础（$(0,0)$）只依赖边界 $0$ 与树标记，由引理 2 正确；归纳步引用引理 2 的转移与已正确的更早格子。故整表每个值都等于定义值。证毕。

**初始化陷阱排查**：本题 $dp$ 的"不可达"值是 $0$（树格、边界外），而全局 `int` 数组默认恰是 $0$——**不需要**显式填哨兵；树格用 `continue` 跳过、保持默认 $0$，语义正确。这与"不可达必须填 INF"的通则不冲突：通则针对的是"默认 $0$ 会被误当成合法值"的场景，本题 $0$ 本身就是合法语义。

---

### 引理 5（复杂度与值域）

时间 $O(n^2+t)$，空间 $O(n^2)$；$dp$ 值 $\le n\le1000$，`int` 安全。

*证明*：读入 $t$ 个树坐标 $O(t)$；双重循环 $n^2$ 格，每格常数次比较、一次 $\min$、一次 $\max$，$O(n^2)$。$n=1000$ 时 $10^6$ 格，实测约 $0.04$ 秒。空间：`dp` 为 $1005^2$ 个 `int` $\approx4$ MB，`tr` 为 $1005^2$ 个 `bool` $\approx1$ MB，合计 $O(n^2)\approx5$ MB。值域：$S(i,j,k)$ 合法要求 $k\le i+1\le n$ 且 $k\le j+1\le n$，故 $dp\le n\le1000$，$\min+1\le1001$，远在 `int` 内。证毕。

---

### 定理

程序输出不需要砍树就能修建的最大正方形牛棚边长，时间 $O(n^2+t)$、空间 $O(n^2)$。

*证明*：引理 2 给出每格 $dp$ 的正确转移（含树格与边界），引理 4 保证按行优先序计算整表正确，引理 3 保证 $\max dp$ 就是全局最优边长，引理 5 给出复杂度与值域安全；引理 1 额外说明答案概念的良定性与二分中间解法的合法性。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **consider easier version** — 暴力枚举全部正方形 $\approx n^3/3$ 个；二维前缀和把空性检查降到 $O(1)$，仍有 $3.3\times10^8$ 次查询，不踏实。
- **explore its property** — 空正方形的子正方形仍空 ⇒ 可行性对边长单调 ⇒ 二分答案 + 前缀和检查，$O(n^2\log n)$ 可过（中间解法）。
- **reduce to easier problem** — 全局最优 $\to$ 逐格最优：每个正方形有唯一右下角，$\mathrm{OPT}=\max_{i,j}dp[i][j]$，把"枚举正方形"重组为"递推每格"。
- **classic problem solution** — 最大正方形 DP：$dp[i][j]=\min(\text{上},\text{左},\text{左上})+1$，$O(n^2)$ 去掉 $\log$。
- **explore its property** — $2\times2$ 左上树反例证明对角项不可省：$\min$ 是短板原理，三个 $(k-1)$ 正方形 $+$ 本格恰好铺满 $k$ 正方形（逐格分区验证）。
- **discuss by category** — 边界逐类处理：第 $0$ 行/列的越界邻居按 $0$；树格 $dp=0$（全局默认值恰好正确，无需填哨兵）；全占满输出 $0$；$(x,y)$ 行列语义不影响答案（转置对称）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 农场边长，$\le1000$ | `int`，读入 | 格子 0-based：$0..n-1$ |
| `t` | 果树数，$\le10000$ | `int`，读入 | 每棵占一格 |
| `tr[i][j]` | 格子 $(i,j)$ 是否有树 | `bool[mxn][mxn]`，全局默认 `false` | 读入 `--x;--y` 后置 `true` |
| `dp[i][j]` | 以 $(i,j)$ 为**右下角**的最大空正方形边长 | `int[mxn][mxn]`，全局默认 $0$ | 树格/边界外恰为 $0$，默认值即正确语义 |
| `u,v,d` | 上 / 左 / 左上邻居的 $dp$ 值（越界按 $0$） | `int`，每格现算 | "up, left, diagonal"；$\min$ 取短板 |
| `ans` | 最大边长 $=\max dp$ | `int`，全局默认 $0$ | 全占满时就是 $0$ |
| `mxn` | $1000+5$ | `constexpr int{1005}` | +5 松弛 |

### 算法步骤

1. I/O 加速三行；读入 `n,t`。
2. 读 $t$ 个树坐标 `(x,y)`，`--x;--y`，`tr[x][y]=true`。
3. 行优先双重循环 `i=0..n-1`、`j=0..n-1`：
   1. 树格 `continue`（$dp$ 保持 $0$，引理 2）；
   2. 取 `u=i?dp[i-1][j]:0`、`v=j?dp[i][j-1]:0`、`d=(i&&j)?dp[i-1][j-1]:0`；
   3. `dp[i][j]=min({u,v,d})+1`（引理 2）；
   4. `ans=max(ans,dp[i][j])`（引理 3）。
4. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(n^2+t)$，$n=1000$ 时 $10^6$ 格、每格 $O(1)$，实测约 $0.04$ 秒。
- 空间：$O(n^2)$，`dp` 约 $4$ MB + `tr` 约 $1$ MB。
- 验证状态：`g++ -std=c++20 -O2 -Wall -Wextra` 编译零警告；题面 $8\times8$ 例输出 $5$ 与文字一致；$6$ 组手造小数据（含"漏对角项"反例 $2\times2$、中心树、整行树、$n=1$ 全占满）与手算一致；$n=1000$ 中心树 / 角落树两组大规模输出 $500/999$，与理论值一致。

```cpp
// 题目：P2701 [USACO5.3] 巨大的牛棚 Big Barn
// dp[i][j]=以 (i,j) 为右下角的最大空正方形边长
// 空位 min(上,左,左上)+1；树格 0；答案=max dp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,t,dp[mxn][mxn],ans;
bool tr[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>t;
	for(int i=0,x,y;i<t;++i)
	{
		cin>>x>>y;--x;--y;
		tr[x][y]=true;
	}
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
		{
			if(tr[i][j])continue;	// 树格 dp=0，全局默认值正好
			int u=i?dp[i-1][j]:0,v=j?dp[i][j-1]:0,d=(i&&j)?dp[i-1][j-1]:0;
			dp[i][j]=min({u,v,d})+1;
			ans=max(ans,dp[i][j]);
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **三个邻居一个都不能少**：`min({u,v,d})` 的对角项 `d` 负责覆盖目标正方形的左上区域；漏掉它，$2\times2$ 左上树的数据就会错输出 $2$（引理 2 的反例）。
- **越界按 $0$**：`i?dp[i-1][j]:0` 等三目把"农场外"视为边长 $0$，等价于给网格垫一圈 $0$ 哨兵行/列，但不用真的多开边界、也不用分支写两套转移。
- **全局默认 $0$ 恰好正确**：树格 `continue` 后保持 $0$，`ans` 初值 $0$ 覆盖"全占满"情形。本题**不需要**填 INF——$0$ 就是"不可达"的合法语义，与"默认 $0$ 会被误当可达"的陷阱场景相反。
- **0-based**：读入立刻 `--x;--y`；输出是边长不是坐标，无需加回。
- **行列语义无关**：把输入第一维当行、第二维当列（或反过来）答案相同——转置不改变正方形集合的空性与边长，所以不必纠结题面 $(x,y)$ 的朝向。
- `min({u,v,d})` 用 initializer_list 版本，三项一次取最小；每格 $O(1)$，总 $10^6$ 格，远低于时限。
