# P2251 质量检测 — 题解

## 一、解题过程：人类思考叙事

题意：给出长度为 $N$ 的序列 $A_1,\dots,A_N$（$N\le 10^5$，$A_i\le 10^6$）和窗口长度 $M\le N$，对每个长度为 $M$ 的连续段 $[i,i+M-1]$（$i=1,\dots,N-M+1$）求出段内最小值，按 $i$ 递增每行输出一个。

最直接的做法是对每个窗口扫一遍，复杂度 $O(NM)$，最坏 $10^{10}$，超时。$30\%$ 的数据 $N\le 1000$ 可以用这个暴力，但满分必须更快。

观察窗口的移动方式：从 $[i,i+M-1]$ 滑到 $[i+1,i+M]$，**只有一个元素离开、一个元素进入**。直觉上最小值也应该能“增量”更新：新最小值 = $\min(\text{旧最小值},A_{i+M})$。但这个式子只在“离开的元素不是最小值”时成立。反例：

$$A=[1,2,3],\ M=2.$$

第一个窗口 $[1,2]$ 的最小值是 $1$，它离开了；第二个窗口 $[2,3]$ 的最小值是 $2$，无法由“旧最小值 $1$ 和新元素 $3$”得到。**问题在于：最小值离开后，我们需要的是“第二小值”，而一个变量存不下这个信息。**

于是至少需要维护一个候选集合。最朴素的想法是用 `multiset` 或“堆 + 懒删除”维护窗口内所有元素，每次插入、删除、取最小值，复杂度 $O(N\log N)$，对 $10^5$ 完全够。但还能不能做到 $O(N)$？

关键的第二层观察是**支配关系**。设当前窗口里有两个下标 $j<i$，且 $A_j\ge A_i$。那么 $j$ 还有可能在未来某个窗口里成为最小值吗？

考虑任意一个“未来”的窗口（右端点 $\ge i$）。只要它还包含 $j$，由于窗口是长度 $M$ 的连续段、而 $i-j\le M-1<M$，它一定也包含 $i$；又因为 $A_i\le A_j$，窗口里已经有一个不比 $j$ 大的 $i$，所以 $j$ **永远不会是严格更优的候选**。换句话说：**后来的、值不大于它的元素，会把前面的元素彻底“支配”掉。**

这条性质提示我们只保留“从右往左看仍然可能成为最小值”的元素，也就是窗口的**后缀最小值**序列。这样的元素从左到右值严格递增：越靠右的元素值越大。新元素进来时，它比队尾元素小（或相等），队尾就被支配，可以永久删除；于是用一个双端队列维护这个序列：

- 队尾：不断弹出 $A_{\text{back}}\ge A_i$ 的下标，再压入 $i$；
- 队头：弹出已经滑出窗口（下标 $\le i-M$）的元素；
- 此时队头就是当前窗口的最小值。

每个下标最多进队一次、出队一次，总复杂度 $O(N)$。

实现细节与坑：

1. **队列存下标而不是值**，否则无法判断过期。
2. 弹出队尾用 `>=` 而不是 `>`：值相等的两个元素，靠右的那个存活得更久，靠左的可以安全丢弃；这样队列里的值严格递增，不变量最干净。
3. **先处理队头过期，再弹队尾**。这样弹队尾时所有剩余下标都满足 $i-j\le M-1<M$，支配引理的条件始终成立；如果先弹队尾，可能把下标 $i-M$（已经不属于新窗口）也按支配关系弹掉，虽然结果仍然正确，但证明要多讨论一个边界。
4. $M=1$ 时每个元素自己就是一个窗口，此时过期操作会把前一个元素弹掉，输出当前元素，逻辑自然成立。
5. $N=M$ 时只输出一个数；循环中 `i>=M-1` 的条件保证不会提前输出。
6. 输出是 $N-M+1$ 行，每行一个数。

本地题面没有样例，我手造了四组小数据（见第五节），覆盖了“最小值滑出”“$M=1$”“$M=N$”“重复值”四种情形。

## 二、思维链：完整证明

设序列下标 $0$-based，$A_0,\dots,A_{N-1}$。对 $i\ge M-1$，记窗口

$$W_i=[i-M+1,\ i].$$

算法在 $i=0,1,\dots,N-1$ 上依次执行：

1. 当队头下标 $\le i-M$ 时弹出队头；
2. 当队尾下标 $j$ 满足 $A_j\ge A_i$ 时弹出队尾；
3. 把 $i$ 压入队尾；
4. 若 $i\ge M-1$，输出 $A_{\text{front}}$。

下面证明第 4 步输出的确实是 $\min W_i$。

**引理 1（支配引理）**：设 $j<i$ 且 $i-j<M$，$A_j\ge A_i$。则对任意 $k\ge i$，若窗口 $W_k$ 包含 $j$，则 $W_k$ 也包含 $i$，并且 $\min W_k$ 与是否考虑 $j$ 无关（即去掉 $j$ 不改变该窗口的最小值）。

*证明*：$W_k=[k-M+1,k]$ 包含 $j$ 意味着 $k-M+1\le j\le k$。由于 $i>j$，立刻有

$$i\ge j+1\ge(k-M+1)+1=k-M+2>k-M+1;$$

又因为 $k\ge i$，所以 $k-M+1\le i\le k$，即 $i\in W_k$。于是窗口 $W_k$ 同时包含 $i$ 与 $j$，且 $A_i\le A_j$。因为 $i\in W_k\setminus\{j\}$，有 $\min(W_k\setminus\{j\})\le A_i\le A_j$，所以

$$\min W_k=\min\bigl(\min(W_k\setminus\{j\}),\ A_j\bigr)=\min(W_k\setminus\{j\}).$$

即去掉 $j$ 后窗口最小值不变。证毕。

**引理 2（不变量：队列 = 后缀最小值）**：在第 $i$ 步执行完毕（弹出过期、弹出被支配的队尾、压入 $i$）后，队列中的下标集合恰为

$$S_i=\{\,j\in W_i:\ A_j<A_k\ \text{对一切}\ j<k\le i\,\},$$

即窗口 $W_i$ 内“从右往左看严格更小”的那些位置（后缀严格最小值）。并且队列中下标严格递增、对应的值严格递增。

*证明*：对 $i$ 归纳。

**基始 $i=0$**：队列中只有 $0$，$W_0=[0,0]$，条件空洞成立；下标与值都只有一个，递增性成立。

**归纳步**：设第 $i-1$ 步后队列满足 $S_{i-1}$。第 $i$ 步分三小步。

(a) 弹出队头 $\le i-M$。这些下标不属于 $W_i$；队列下标递增，所以过期元素恰好是队列的一个前缀，弹完后剩下的正是 $S_{i-1}\cap W_i$（因为 $W_{i-1}\cap W_i=[i-M+1,i-1]$，而 $S_{i-1}$ 中属于该区间的元素就是 $S_{i-1}\cap W_i$）。

(b) 弹出队尾满足 $A_j\ge A_i$ 的元素。由于队列的值严格递增，满足 $A_j\ge A_i$ 的元素构成队列的一个后缀，弹完后剩下的是 $S_{i-1}\cap W_i$ 中满足 $A_j<A_i$ 的那些 $j$。对 $j\in W_i$，$j<i$，有

$$j\in S_i\iff A_j<A_i\ \text{且}\ A_j<A_k\ (\forall j<k\le i-1)\iff A_j<A_i\ \text{且}\ j\in S_{i-1}.$$

所以弹完后留下的恰好是 $S_i$ 中所有 $<i$ 的元素。

(c) 压入 $i$。$i\in W_i$，且不存在 $k$ 满足 $i<k\le i$，故 $i\in S_i$。于是队列集合恰为 $S_i$。

递增性：下标递增是因为只在尾部加入更大的 $i$；值递增是因为旧队列值严格递增，弹完后队尾值 $<A_i$（或队列为空），加入 $A_i$ 后仍严格递增。证毕。

**引理 3（队头是窗口最小值）**：对任意 $i\ge M-1$，若 $q_1$ 是第 $i$ 步后队列的队头，则 $A_{q_1}=\min W_i$。

*证明*：由引理 2，队列恰为 $S_i$，且值从左到右严格递增，所以 $q_1$ 是 $S_i$ 中值最小的元素，即对任意 $j\in S_i$ 有 $A_{q_1}\le A_j$。

任取 $j\in W_i$。若 $j\in S_i$，已得 $A_{q_1}\le A_j$。若 $j\notin S_i$，由 $S_i$ 的定义，存在 $k_1$ 满足 $j<k_1\le i$ 且 $A_{k_1}\le A_j$。若 $k_1\in S_i$，则 $A_{q_1}\le A_{k_1}\le A_j$。若 $k_1\notin S_i$，再取 $k_2>k_1$ 使 $A_{k_2}\le A_{k_1}$，如此继续。下标严格递增且始终不超过 $i$，所以这个过程必然终止；终止时得到某个 $k_t\in S_i$，并且沿链有 $A_{k_t}\le\cdots\le A_{k_1}\le A_j$。于是 $A_{q_1}\le A_{k_t}\le A_j$。

由 $j$ 的任意性，$A_{q_1}$ 是窗口最小值。又 $q_1\in W_i$（引理 2 中 $S_i\subseteq W_i$），故 $A_{q_1}=\min W_i$。证毕。

**定理（输出正确）**：算法对每个 $i\ge M-1$ 输出 $\min W_i$，且恰好输出 $N-M+1$ 个数。

*证明*：由引理 3，第 4 步输出的 $A_{\text{front}}=\min W_i$。循环对 $i=0,\dots,N-1$ 各执行一次，条件 $i\ge M-1$ 恰在 $i=M-1,\dots,N-1$ 成立，共 $N-M+1$ 次，与题目要求的窗口一一对应。证毕。

**引理 4（复杂度）**：总时间复杂度 $O(N)$，空间复杂度 $O(N)$。

*证明*：每个下标 $i$ 在第 3 步被压入队列恰好一次。每次第 1 步或第 2 步的弹出都会永久删除一个下标，而每个下标最多被删除一次；因此所有 `while` 循环的弹出总次数不超过 $N$。循环体其余部分为常数时间，总时间 $O(N)$。队列与数组各占 $O(N)$ 空间。证毕。

**补充（为什么 `>=` 而不是 `>`）**：若 $A_j=A_i$ 且 $j<i$，由引理 1（$i-j<M$）可知任何同时包含 $j$ 的未来窗口都包含 $i$，且两者值相等，保留 $j$ 不会得到更小的值，反而会让 $j$ 更早过期、需要额外维护。用 `>=` 弹出可以保证队列值严格递增，使引理 2、3 的表述统一。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 窗口每次只滑一格，只有一个元素离开、一个进入。
- **consider easier version** — 先想“新最小值 = min(旧最小值, 新元素)”的增量更新。
- **find counterexample** — 最小值恰好离开时该式失效，必须知道第二小值，一个变量不够。
- **explore its property** — 支配关系：更靠右且值不大于旧元素的元素，会让旧元素在未来所有窗口中都不再必要。
- **classic problem solution** — 单调队列维护窗口的后缀严格最小值，队头即窗口最小值。
- **amortized analysis** — 每个下标至多入队一次、出队一次，总操作 $O(N)$。
- **boundary discipline** — 先弹过期队头再弹队尾；只在 $i\ge M-1$ 时输出；`>=` 保证严格递增。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| $N$ | 产品总数（序列长度） | `int`，输入 |
| $M$ | 窗口长度 | `int`，输入 |
| $A[i]$ | 第 $i$ 件产品的分数（0-based） | `int[mxn]`，输入 |
| $Q$ | 单调队列，存下标 | `int[mxn]`，空队列 |
| $hd$ | 队头指针（指向第一个元素） | `int`，初值 $0$ |
| $tl$ | 队尾指针（指向最后一个元素的下一个位置） | `int`，初值 $0$ |
| $i$ | 当前处理的下标 | 循环变量 |

队列中始终满足：下标递增、$A[Q[hd]]<A[Q[hd+1]]<\cdots<A[Q[tl-1]]$，且所有下标都在窗口 $W_i$ 内。

### 算法步骤

1. 关闭流同步，读入 $N,M$ 与序列 $A_0,\dots,A_{N-1}$。
2. 初始化 $hd=tl=0$。
3. 对 $i=0,1,\dots,N-1$：
   1. 当 $hd<tl$ 且 $Q[hd]\le i-M$ 时，$hd$ 自增（弹出滑出窗口的队头）。
   2. 当 $hd<tl$ 且 $A[Q[tl-1]]\ge A[i]$ 时，$tl$ 自减（弹出被 $A[i]$ 支配的队尾）。
   3. 令 $Q[tl]=i$，$tl$ 自增。
   4. 若 $i\ge M-1$，输出 $A[Q[hd]]$ 并换行。
4. 结束。

### 复杂度

- 时间复杂度：$O(N)$（均摊）。
- 空间复杂度：$O(N)$（数组与队列）。

### 验证状态

- 使用 `/d/mingw64/bin/g++.exe -std=c++20 -O2` 编译通过，无错误。
- 本地题面无样例，手造并跑通 4 组：
  - `5 3 / 5 3 4 1 2` → `3 1 1`；
  - `1 1 / 7` → `7`；
  - `6 6 / 2 2 2 2 2 2` → `2`；
  - `6 2 / 1 5 3 4 2 6` → `1 3 3 2 2`。
- 与 $O(NM)$ 暴力对拍 300 组随机数据，输出完全一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2251 质量检测
// 思路：单调队列维护每个窗口的后缀严格最小值
//       先弹过期队头，再弹被 a[i] 支配的队尾，压入 i
//       队头就是当前窗口的最小值；每个下标进出各一次，O(N)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n,m,a[mxn],Q[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	int hd=0,tl=0;
	for(int i=0;i<n;++i)
	{
		// 先让滑出窗口 [i-m+1,i] 的索引出队
		while(hd<tl&&Q[hd]<=i-m)
			++hd;
		// 队尾值 >=a[i] 的索引被 a[i] 支配，永远不可能再当最小值
		while(hd<tl&&a[Q[tl-1]]>=a[i])
			--tl;
		Q[tl++]=i;
		if(i>=m-1)
			cout<<a[Q[hd]]<<'\n';
	}
	return 0;
}
```

### 代码说明

- `Q` 存的是**下标**，通过 `a[Q[...]]` 取值；这样既能比较值，也能判断是否过期。
- 过期条件写成 `Q[hd]<=i-m`：窗口左端是 $i-m+1$，所以下标 $\le i-m$ 全部离开。
- 弹队尾用 `>=`：相等时靠右的元素活得更久，保留它即可，同时保证队列值严格递增。
- 先过期再弹队尾，使支配引理的条件 $i-j<M$ 对所有还在队列中的 $j$ 都成立。
- `if(i>=m-1)` 才输出：前 $M-1$ 个位置还没有形成完整窗口。
- 每个下标最多入队一次、被弹出一次，`while` 的总执行次数是 $O(N)$，不是 $O(NM)$。

---

*本题的核心不是“会写单调队列模板”，而是想清楚为什么旧元素可以被新元素永久支配：窗口连续滑动 $M$ 格才会丢掉一个位置，而支配者的下标更靠右、值又更小，所以它一定比被支配者活得更久。*
