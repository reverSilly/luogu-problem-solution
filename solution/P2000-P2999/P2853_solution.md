# P2853 [USACO06DEC] Cow Picnic S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $K\le 100$ 头奶牛分布在 $N\le 1000$ 个牧场上（多头牛可以同在一个牧场），牧场间有 $M\le 10000$ 条**有向**路径（无自环）。求有多少个牧场是**每头牛都能到达**的。输入第一行是 $K,N,M$——**注意顺序不是 $N,M,K$**，这是第一个坑。

**第一步：把"所有牛都能到"翻译成集合语言。** 设第 $i$ 头牛的起点是 $c_i$，它在有向图上能到达的点集为 $R(c_i)$（含自身：走 $0$ 步也算"在"）。答案就是

$$\Bigl|\bigcap_{i=1}^{K} R(c_i)\Bigr|.$$

于是问题拆成两半：怎么求单源的可达集 $R(s)$？怎么把 $K$ 个集合交起来？

**第二步：求可达集——BFS/DFS 一遍就行。** 有向图单源可达性是搜索的看家本领：从 $s$ 出发沿有向边遍历，标记到的点恰是 $R(s)$。一次 $O(N+M)$。$K$ 头牛各跑一遍，$O(K(N+M))\le 100\times 11000=1.1\times10^6$，轻松通过。

这里我对比过另一条路：Floyd 传递闭包，$O(N^3)=10^9$，在 $1$ s 时限下太肥；而且我们只需要 $K\le100$ 个源点的可达性，根本不需要全源点对，Floyd 是杀鸡用牛刀还杀不动。**"源点少、图稀疏"时，逐源 BFS 优于传递闭包**——这是本题规模给出的明确暗示。

**第三步：交集怎么算？先撞一次墙。** 我第一反应是"反图多源 BFS"：把所有牛的位置一起塞进队列，在反图上跑一遍，能标记到的点就是"某头牛能到"的点……等等，这是**并集**不是交集！最小反例：$N=3$，牛在 $1$ 和 $2$，边只有 $1\to3$。点 $3$ 被牛 $1$ 可达、牛 $2$ 不可达，多源 BFS 却会标记它。并集 $\ne$ 交集，此路不通。

**第四步：撞墙后的修正——给每个点计数。** 交集的本质是"被**所有** $K$ 个集合覆盖"。那就逐源 BFS，每头牛把它的可达集里每个点的计数器 `cnt[v]` 加 $1$；最后 `cnt[v]==K` 的点恰好在交集里。这一步把"集合交"归约成了"逐源搜索 + 计数"，不需要任何高级数据结构。

多头牛同起点怎么办？不用管：起点相同的牛可达集完全相同，每头各贡献一次，`cnt` 照样准确——按牛计数天然兼容重复起点（若按"不同起点"去重，阈值就要改成不同起点数，反而多一步）。

**第五步：实现细节。**

1. 每头牛 BFS 前 `fill_n(vis,n,0)` 重置访问标记；`cnt` 全程累计、不清零。
2. 起点自身需要 `++cnt[s]`：牛"已经在"那个牧场，题意允许原地集合（提示里"奶牛可以在 3 或 4 号牧场相遇"也印证可达含自身）。
3. BFS 用全局数组当队列（每点至多入队一次，容量 $N$ 足够），避免 `queue` 的开销；`vis` 在入队时置位，保证不重复计数。
4. 读入顺序 $K,N,M$；牛位置与边端点全部 `--` 转 0-based。

**手造数据核对**（题面只有一句提示，没有样例输入输出，自造两组）：

第一组：$K=2,N=4,M=4$，牛在 $1,2$；边 $1\to3,\ 2\to3,\ 3\to4,\ 1\to2$。

```
2 4 4
1
2
1 3
2 3
3 4
1 2
```

$R(1)=\{1,2,3,4\}$，$R(2)=\{2,3,4\}$，交集 $\{2,3,4\}$，答案 $3$。注意 $2$ 号牧场：牛 $1$ 经 $1\to2$ 到达、牛 $2$ 原地，所以算——专打"含自身 + 有向"两个点。

第二组：$K=3,N=3,M=1$，牛在 $1,1,3$；边 $1\to2$。

```

```

$R(1)=\{1,2\}$（两头牛各贡献一次），$R(3)=\{3\}$，交集为空，答案 $0$。专打"重复起点"与"孤立点只能原地"。

## 二、思维链：完整证明

**记号。** 有向图 $G=(V,E)$，$|V|=N$。牛 $i$ 起点 $c_i$。$R(s)=\{v:$ 存在 $s\to v$ 的有向途径（含长度 $0$）$\}$。`cnt[v]` 为处理完全部 $K$ 头牛后的计数器。

---

### 引理 1（BFS 标记集恰为可达集）

从 $s$ 出发、沿有向边、入队时置 `vis` 的 BFS 结束后，`vis[v]=1` $\iff v\in R(s)$。

*证明*：两个方向。

($\Rightarrow$) 对入队顺序归纳：$s$ 首个入队，对应长度 $0$ 的途径。之后每个入队的 $v$ 都是被某个已入队的 $u$ 经边 $(u,v)$ 发现的；由归纳假设存在 $s\to u$ 途径，接上 $(u,v)$ 得 $s\to v$ 途径。故每个被标记的点都可达。

($\Leftarrow$) 设 $v\in R(s)$，取最短途径 $s=v_0,v_1,\dots,v_k=v$。对 $j$ 归纳证 $v_j$ 必入队：$v_0=s$ 入队 ✓。设 $v_{j-1}$ 入队，则它必出队（队列有限、每点到多入队一次，BFS 循环把所有入队点都出队）；出队时扫描边 $(v_{j-1},v_j)$：若 $v_j$ 未标记则立即标记入队，若已标记则结论已成立。故 $v_k=v$ 被标记。证毕。

**推论**：每点至多入队一次（`vis` 在入队时置位），故队列容量 $N$ 足够，且 `cnt[v]` 在单次 BFS 中至多被加 $1$。

---

### 引理 2（计数器 = 覆盖数）

处理完全部 $K$ 头牛后，`cnt[v]` $=\#\{i:v\in R(c_i)\}$。

*证明*：第 $i$ 次 BFS 中，`cnt[v]` 被加 $1$ 当且仅当 $v$ 被标记（起点在入队前显式 `++cnt[s]`，其余点在标记时 `++cnt[v]`，由引理 1 推论每点恰至多一次）。由引理 1，被标记 $\iff v\in R(c_i)$。故第 $i$ 次 BFS 对 `cnt[v]` 的贡献恰为指示函数 $[v\in R(c_i)]$。`cnt` 跨 BFS 累计不清零，求和即得覆盖数。重复起点无需特判：$c_i=c_j$ 时两次 BFS 标记集相同，各贡献 $1$，与"两头牛"的语义一致。证毕。

---

### 引理 3（答案 = `cnt==K` 的点数）

程序输出 $\#\{v:$ `cnt[v]` $=K\}$，等于题目所求。

*证明*：题目要求"所有奶牛都可到达"的牧场数，即 $\bigl|\bigcap_i R(c_i)\bigr|$。而 $v\in\bigcap_i R(c_i)\iff$ 对所有 $i$ 有 $v\in R(c_i)\iff$ 覆盖数 $=K\iff$ `cnt[v]` $=K$（引理 2）。又覆盖数 $\le K$ 恒成立，故 `cnt[v]==K` 与 `cnt[v]>=K` 等价，判等号无遗漏。证毕。

---

### 引理 4（可达含自身的合理性）

$R(s)$ 包含 $s$ 本身（长度 $0$ 的途径），且这与题意一致。

*证明*：题意要求"所有奶牛都可到达的地方"作为进餐点。已在牧场 $s$ 的牛不需要移动即可"在" $s$ 进餐，故 $s$ 对它可达；若把 $s$ 排除，则"所有牛恰好同在一个牧场"的合法情形会被误判为 $0$。题面提示"奶牛可以在 $3$ 或 $4$ 号牧场相遇"描述的正是普通可达语义。故含自身是唯一自洽的解读。证毕。

---

### 引理 5（反图多源 BFS 求的是并集，不是交集）

把所有 $c_i$ 作为源点在反图上做多源 BFS，标记集为 $\bigcup_i R(c_i)$，一般不等于 $\bigcap_i R(c_i)$。

*证明*：反图中 $v$ 被源点 $c_i$ 标记 $\iff$ 原图存在 $c_i\to v$ 途径 $\iff v\in R(c_i)$。多源 BFS 的标记集是各源点标记集的并（引理 1 对每个源点成立，标记只增不减），即 $\bigcup_i R(c_i)$。反例：$V=\{1,2,3\}$，$c=(1,2)$，$E=\{(1,3)\}$：$R(1)=\{1,3\}$，$R(2)=\{2\}$，并集含 $3$ 而交集 $\{1,3\}\cap\{2\}=\varnothing$ 不含 $3$。故并集做法错误，必须逐源计数。证毕。

---

### 引理 6（复杂度）

时间 $O(K(N+M)+N)$，空间 $O(N+M)$。

*证明*：每次 BFS 中每点至多入队一次（引理 1 推论），每条边至多被扫描一次（其尾出队时），故单次 $O(N+M)$；`fill_n(vis,n,0)` 也是 $O(N)$。$K$ 次共 $O(K(N+M))$；最后统计 $O(N)$。代入 $K=100,N=1000,M=10000$：约 $1.1\times10^6$ 次基本操作。空间：邻接表 $O(N+M)$，`cnt/vis/q` 各 $O(N)$。证毕。

---

### 定理

程序输出所有奶牛都可到达的牧场数，时间 $O(K(N+M))$。

*证明*：引理 1 保证单次 BFS 的标记集正确；引理 2 把计数器与覆盖数等同；引理 3 把覆盖数 $=K$ 与题意交集等同；引理 4 确认含自身语义；引理 5 排除了并集歧路；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "所有牛都能到" = $K$ 个单源可达集的**交集**；可达含自身（走 $0$ 步）。
2. **consider easier version** — 单源可达性 = 一次 BFS/DFS，$O(N+M)$；$K$ 个源点就跑 $K$ 次。
3. **discuss by category** — 源点少（$K\le100$）图稀疏：逐源 BFS $O(K(N+M))$ 优于 Floyd 闭包 $O(N^3)=10^9$。
4. **reduce to easier problem** — 反图多源 BFS 是**并集**（最小反例：$1\to3$、牛在 $1,2$），撞墙后改为逐源 BFS + 每点计数。
5. **classic problem solution** — `cnt[v]` 累计覆盖数，答案 = `cnt[v]==K` 的点数；重复起点天然兼容。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $K,N,M$ | 牛数 / 牧场数 / 有向边数 | `int k,n,m` | 读入，**顺序 K,N,M** |
| `c[i]` | 第 $i$ 头牛的起点（0-based） | `int[105]` | 读入后 `--` |
| `graph[u]` | $u$ 的出边邻接表 | `vector<int>[mxn]` | 读入建表 |
| `vis[v]` | 本次 BFS 中 $v$ 是否已标记 | `int[mxn]` | **每次 BFS 前 `fill_n(vis,n,0)`** |
| `cnt[v]` | 能到达 $v$ 的牛数（覆盖数） | `int[mxn]` | 全局 $0$，跨 BFS 累计不清零 |
| `q[hd..tl)` | BFS 队列（数组模拟） | `int[mxn]` | 每次 BFS `hd=tl=0` |
| `ans` | `cnt[v]==k` 的点数 | `int` | $0$ 起统计 |
| `mxn` | $1000+5$ | `constexpr int` | 点数上界 |

### 算法步骤

1. I/O 加速三行；读 $K,N,M$；读 $K$ 个牛位置（`--`）；读 $M$ 条有向边建 `graph`（`--`）。
2. 对每头牛 $i$：`bfs(c[i])`——重置 `vis`，起点标记并 `++cnt`，入队；循环出队扫描出边，未标记的点标记、`++cnt`、入队。
3. 统计 `cnt[i]==k` 的个数输出。

### 复杂度

- 时间：$O(K(N+M))\le1.1\times10^6$。
- 空间：$O(N+M)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造"有向 + 含自身""重复起点 + 孤立点"两组数据核对无误。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2853 [USACO06DEC] Cow Picnic S
// 思路：答案 = K 个单源可达集的交集大小。
//       逐源 BFS，每头牛给可达点 cnt++；cnt[v]==K 即在交集里。
//       反图多源 BFS 求的是并集，不能用！
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int k,n,m,c[105],cnt[mxn],vis[mxn],q[mxn];
vector<int>graph[mxn];

void bfs(int s)
{
	fill_n(vis,n,0);	// vis 每次重置；cnt 全程累计
	int hd=0,tl=0;
	vis[s]=1;++cnt[s];q[tl++]=s;	// 自己所在牧场也算可达（走 0 步）
	while(hd<tl)
	{
		int u=q[hd++];
		for(int v:graph[u])
			if(!vis[v])
			{
				vis[v]=1;++cnt[v];	// 入队时置位 ⇒ 每点恰计一次
				q[tl++]=v;
			}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>k>>n>>m;	// 注意顺序是 K,N,M，不是 N,M,K
	for(int i=0;i<k;++i)
	{
		cin>>c[i];--c[i];
	}
	for(int i=0,u,v;i<m;++i)
	{
		cin>>u>>v;--u;--v;
		graph[u].push_back(v);	// 有向边，只加 u→v
	}
	for(int i=0;i<k;++i)
		bfs(c[i]);	// 重复起点照跑：两头牛各贡献一次，天然正确
	int ans=0;
	for(int i=0;i<n;++i)
		if(cnt[i]==k)
			++ans;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `cnt` 与 `vis` 的生命周期不同：`vis` 是"本次 BFS 的临时标记"，每次清零；`cnt` 是"跨所有牛的累计覆盖数"，绝不清零。把两者一起清零是本题最常见的挂法。
- 起点显式 `++cnt[s]`：BFS 循环只统计"被边发现的点"，起点自己不会经过那条分支，漏掉就错。
- 数组队列容量 `mxn`：每点至多入队一次（`vis` 入队时置位），不会溢出。
- 有向边只加 `u→v`；加成双向会把"能到"算多。
