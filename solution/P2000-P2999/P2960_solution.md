# P2960 [USACO09OCT] Invasion of the Milkweed G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** $X$ 列 $Y$ 行的网格（$1\le X,Y\le 100$），$(1,1)$ 在**左下角**，坐标是常规数学坐标系（$x$ 向右、$y$ 向上）。格子只有两种：草 `.` 与巨石 `*`。第 $0$ 周乳草占据 $(M_x,M_y)$；此后**每周**，所有已被占据格子的**八邻域**（上下左右 + 四个对角）中的非巨石格全部被占据。题目保证所有草地最终都会被占据。求**最后一块草地被占据的周数**。

**输入格式要抠细**：第 $y+1$ 行描述的是网格第 $Y+1-y$ 行——即输入**自上而下**给出网格（第一行输入是最上面一行 $y=Y$）。起点 $(M_x,M_y)$ 的 $M_y$ 是自下而上数的。这两套方向必须在读入时统一，否则起点放错行，样例都过不了。

**手造/样例核对。** 题面自带样例：$X=4,Y=3$，起点 $(1,1)$，地图

```
....
..*.
.**.
```

按周演化（题面给出）：第 $1$ 周占 $(1,2),(2,2)$（左下格的八邻里只有这两格是草），第 $2$ 周占顶行前三格，第 $3$ 周占 $(4,3),(4,2)$，第 $4$ 周占 $(4,1)$——答案 $4$。注意第 $4$ 周那格 $(4,1)$ 与 $(4,2)$ 是**竖直相邻**、与 $(3,2)$ 巨石相邻：没有对角传播的话它永远到不了（$(3,1)$ 是巨石），这组样例专门验证"八方向"。

再造三组极简数据：$1\times1$ 全草、起点即全图，答案 $0$（第 $0$ 周就完成）；$3\times1$ 一条行 `...`、起点 $(2,1)$，答案 $1$；$3\times3$ 强制绕路：

```
...
**.
...
```

起点 $(1,1)$（左下角）。$(1,2),(2,2)$ 是巨石，只能沿底行右移再绕上去：$(2,1)$ 第 $1$ 周，$(3,1),(3,2)$ 第 $2$ 周，$(3,3),(2,3)$ 第 $3$ 周，$(1,3)$ 第 $4$ 周。答案 $4$。这组验证"巨石挡路时距离要绕"。四组全部与程序一致。

**思路是怎么来的。** 第一反应是逐周模拟：每周扫全图，把已占格的八邻标记为占，直到没有新格。这是对的，但每周 $O(XY)$、最多 $O(XY)$ 周，最坏 $O((XY)^2)=10^8$，能过但不优雅。再盯着规则看一句话：

> 每周，乳草传播到已占据格子周围的所有非岩石格；**仅仅一周后**它就准备好继续传播。

"每格被占后下一周才继续传"+"每次传播耗时一周"——这正是**边权为 $1$ 的图上的层序扩张**。把草地当顶点、八相邻当边，第 $t$ 周被占的格子集合就是"距起点图上距离 $\le t$ 的顶点集"。于是"最后一块草地被占的周数"= **起点到所有草地的最短距离的最大值**。一次 BFS 就完事，$O(XY)$。这就是把"时间过程"归约成"静态距离"的标准手法。

## 二、思维链：完整证明

**记号。** 内部网格 0-based、自上而下存储：`g[r][c]`，$0\le r<Y$，$0\le c<X$。建图 $G$：顶点集 $V=\{(r,c):g_{r,c}=\texttt{'.'}\}$，两顶点间有边当且仅当切比雪夫距离为 $1$（即 $|\Delta r|\le 1,|\Delta c|\le 1$ 且不同格）——八邻域。源点 $s$ 为起点格。$\mathrm{dist}(v)$ 为 $G$ 中 $s$ 到 $v$ 的最短路长度（边数）；题目保证所有 $v\in V$ 可达，故 $\mathrm{dist}$ 均有限。$S_t$ 为第 $t$ 周结束时被占据的格子集合。

---

### 引理 1（坐标换算）

输入第 $i$ 行（$1\le i\le Y$）对应内部行 $r=i-1$；坐标行 $y$（自下而上，$1\le y\le Y$）对应内部行 $r=Y-y$。起点 $(M_x,M_y)$ 的内部坐标为 $(r,c)=(Y-M_y,\;M_x-1)$。

*证明*：题面说输入第 $y+1$ 行（$y=1\dots Y$）描述坐标行 $Y+1-y$。令地图行序号 $i=y$（即第 $i$ 行地图，$1\le i\le Y$），则它描述坐标行 $Y+1-i$：$i=1$ 时是坐标行 $Y$（最上行），$i=Y$ 时是坐标行 $1$（最下行），与"输入自上而下"一致。内部数组自上而下 0-based 存储，第 $i$ 行地图存 `g[i-1]`，故"坐标行 $y\mapsto$ 内部行 $r$"满足 $r=i-1=(Y+1-y)-1=Y-y$。起点：$r=Y-M_y$，$c=M_x-1$（列自左向右，常规 0-based）。样例核对：$Y=3,M_y=1\Rightarrow r=2$（`g[2]=".**."` 的最下行），$M_x=1\Rightarrow c=0$，正是左下草格 ✓。证毕。

---

### 引理 2（第 $t$ 周被占 $\iff$ 图上距离 $\le t$）

对所有 $t\ge 0$：$S_t=\{v\in V:\mathrm{dist}(v)\le t\}$。

*证明*：先把传播规则写成集合递推。第 $0$ 周 $S_0=\{s\}$；第 $t+1$ 周，"已占据格子周围的所有非岩石格"被占，且已占的保持被占（乳草不会消失），故

$$S_{t+1}=S_t\cup\{v\in V:\exists u\in S_t,\ u\sim v\},$$

其中 $u\sim v$ 表示 $G$ 中有边（八相邻且都非巨石——巨石不在 $V$ 中，自动被排除）。

对 $t$ 归纳。**基础** $t=0$：$\mathrm{dist}(v)\le 0\iff v=s$，故 $S_0=\{s\}$ ✓。

**归纳步**：设 $S_t=\{v:\mathrm{dist}(v)\le t\}$。

($\subseteq$) 任取 $v\in S_{t+1}$。若 $v\in S_t$，则 $\mathrm{dist}(v)\le t\le t+1$。否则存在 $u\in S_t$ 与 $v$ 相邻，$\mathrm{dist}(v)\le\mathrm{dist}(u)+1\le t+1$（三角不等式：$s\to u$ 最短路接边 $u\to v$ 是一条合法路径）。

($\supseteq$) 任取 $v$ 满足 $\mathrm{dist}(v)=k\le t+1$。若 $k\le t$，由归纳假设 $v\in S_t\subseteq S_{t+1}$。若 $k=t+1$，取 $s\to v$ 最短路上的倒数第二个顶点 $w$：$\mathrm{dist}(w)=k-1=t$（最短路的子路径仍最短），由归纳假设 $w\in S_t$，而 $w\sim v$，故 $v\in S_{t+1}$。

两向包含即得等式。证毕。

**这条引理是全题的支点**：它把"逐周的时间过程"完全刻画成"静态的最短距离"，此后不再需要模拟时间。

---

### 引理 3（答案 = 最大距离）

牧场被完全占领的周数 $T=\max_{v\in V}\mathrm{dist}(v)$。

*证明*："完全占领"即 $S_T=V$。由引理 2，$S_T=V\iff$ 所有 $v$ 满足 $\mathrm{dist}(v)\le T\iff T\ge\max_v\mathrm{dist}(v)$。题目保证所有草地可达（$\mathrm{dist}$ 有限），故满足条件的最小整数 $T$ 就是 $\max_v\mathrm{dist}(v)$。又"最后一块草地被占据的周数"：取 $v^\*=\arg\max\mathrm{dist}$，由引理 2，$v^\*\notin S_{T-1}$（$\mathrm{dist}(v^\*)=T>T-1$）而 $v^\*\in S_T$，即它恰在第 $T$ 周首次被占，且没有更晚被占的格。故输出 $T$。证毕。

---

### 引理 4（BFS 正确性：`dis[v]` = $\mathrm{dist}(v)$，每点恰入队一次）

程序以 `dis` 初始化为 $\infty$、`dis[s]=0`、$s$ 入队开始；每次出队 $u$，对八邻中满足"在界内、非巨石、`dis`$=\infty$"的 $v$ 置 `dis[v]=dis[u]+1` 并入队。则算法结束时对所有 $v\in V$ 有 `dis[v]`$=\mathrm{dist}(v)$，且每点恰入队一次。

*证明*：分四条。

**(i) 每点至多入队一次**：入队的前提是 `dis[v]`$=\infty$，入队同时置为有限值，此后 `dis` 只会被读取不再修改（有限值不满足入队条件），故不会二次入队。

**(ii) `dis[v]` $\ge\mathrm{dist}(v)$（上界性质）**：对入队顺序归纳。$s$：`dis[s]=0=dist(s)`。若 $v$ 由 $u$ 发现，则 `dis[v]=dis[u]+1`；由归纳假设 `dis[u]`$\ge\mathrm{dist}(u)$，且 $u\sim v$ 给出 $\mathrm{dist}(v)\le\mathrm{dist}(u)+1$，故 `dis[v]`$\ge\mathrm{dist}(u)+1\ge\mathrm{dist}(v)$。同时这也说明 `dis[v]` 对应一条真实路径（$s\to u$ 的见证路径接边 $u\to v$）。

**(iii) 队列中 `dis` 值单调不减，且最大最小之差 $\le 1$**：对操作序列归纳。初始队列只有 $s$（值 $0$），成立。出队不破坏单调性。$u$ 出队时新入队的值都是 `dis[u]+1`；由归纳假设，此刻队列剩余元素的值 $\in\{\texttt{dis}[u],\texttt{dis}[u]+1\}$（队头是 $u$，值最小；极差 $\le 1$），新元素追加在队尾且值为 `dis[u]+1` $\ge$ 队尾值，单调性与极差 $\le 1$ 保持。

**(iv) `dis[v]` $\le\mathrm{dist}(v)$（下界性质）**：对 $\mathrm{dist}(v)=k$ 归纳。$k=0$：$v=s$，`dis[s]=0` ✓。设 $k\ge 1$，取最短路前驱 $w$（$\mathrm{dist}(w)=k-1$，$w\sim v$）。由归纳假设 `dis[w]=k-1`，故 $w$ 会入队并出队。考察 $w$ 出队的时刻：若 $v$ 尚未入队，则此刻 `dis[v]`$=\infty$，$w$ 的扫描会发现 $v$ 并置 `dis[v]=dis[w]+1=k`；若 $v$ 已入队，设它由 $u'$ 发现，由 (iii)，出队顺序按 `dis` 不减，而 $u'$ 在 $w$ 之前或同时出队意味着 `dis[u']`$\le$`dis[w]`$=k-1$，故 `dis[v]=dis[u']+1`$\le k$。（$u'$ 不可能比 $w$ 晚出队：$v$ 在 $w$ 出队前已入队，而队列 FIFO，发现者必先出队。）两种情况都有 `dis[v]`$\le k=\mathrm{dist}(v)$。

(ii)(iv) 夹逼得 `dis[v]=dist(v)`；可达性保证每个 $v$ 都会被发现（否则取未入队中 $\mathrm{dist}$ 最小者，其最短路前驱已入队出队、必发现它，矛盾），结合 (i) 恰一次。证毕。

---

### 引理 5（出队时取 max 即答案；复杂度）

程序在每次出队时 `ans=max(ans,dis[u])`，结束时 `ans`$=\max_{v\in V}\mathrm{dist}(v)$。时间 $O(XY)$，空间 $O(XY)$。

*证明*：由引理 4，每个草地顶点恰出队一次且 `dis` 值正确，巨石从不入队，故 `ans` 恰遍历了所有 $\mathrm{dist}(v)$ 取最大，即引理 3 的 $T$。复杂度：读入 $O(XY)$；`fill` $O(\text{mxn}^2)$ 为常数量级（$105^2$）；每点入队一次、出队一次、每次出队扫 $8$ 个方向，总操作 $\le 8XY+O(XY)=O(XY)\le 8\times10^4$。空间：`g` 与 `dis` 各 $105\times105$，$O(XY)$。证毕。

---

### 定理

程序输出的整数恰为乳草占领最后一块非巨石格的周数。

*证明*：引理 1 保证起点与地图在内部坐标系下摆放正确；引理 2 把逐周传播刻画为距离层；引理 3 把"完成入侵的周数"化归为最大距离；引理 4 保证 BFS 算出的 `dis` 就是真实距离；引理 5 保证出队取 max 得到最大距离且复杂度线性。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "每格被占一周后才继续传、传播到八邻"= 边权 $1$ 的层序扩张；第 $t$ 周被占 $\iff$ 图上距离 $\le t$。
2. **consider easier version** — 先想逐周模拟（每周扫全图），最坏 $O((XY)^2)$；确认"时间"可以消掉。
3. **reduce to easier problem** — "完成入侵的周数"= 源点到所有草地的最短距离的最大值，一次单源 BFS。
4. **classic problem solution** — 队列 BFS：`dis` 显式填 INF、入队即定值、出队扫八方向；出队时顺手取 max。
5. **discuss by category** — 坐标系换算：$(1,1)$ 在左下角、输入自上而下 ⇒ 起点内部行 $r=Y-M_y$；巨石不是图顶点，自动被排除。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `x,y` | 列数 $X$、行数 $Y$，$\le 100$ | `int` | 读入；注意 $x$ 是宽、$y$ 是高 |
| `mx,my` | 起点坐标（$(1,1)$ 左下） | `int` | 读入 |
| `g[r][c]` | 内部地图，0-based 自上而下 | `char[mxn][mxn]` | 第 $i$ 行输入存 `g[i-1]` |
| `dis[r][c]` | 起点到该格的图上最短距离（周数） | `int[mxn][mxn]` | **显式 fill 成 INF**；默认 $0$ 会被当成"已访问" |
| `inf` | $1145141919$ | `constexpr int` | 哨兵 |
| `sr,sc` | 起点内部坐标 $(Y-M_y,\ M_x-1)$ | `int` | 换算一次 |
| `dx,dy` | 八方向偏移 | `constexpr int[8]` | 含四个对角 |
| `Q` | BFS 队列，存编码 $r\cdot\text{mxn}+c$ | `queue<int>` | 解码 `u/mxn`、`u%mxn` |
| `ans` | 出队距离的最大值 = 答案 | `int` | 全局默认 $0$；起点第 $0$ 周，恰为下界 |

### 算法步骤

1. I/O 加速三行；读 $X,Y,M_x,M_y$；逐行读入 `g[0..Y-1]`。
2. `fill` `dis` 为 INF；算起点 $(sr,sc)=(Y-M_y,M_x-1)$；`dis[sr][sc]=0`，入队。
3. BFS：出队 $u$，`ans=max(ans,dis[u])`；扫 $8$ 方向，界内、非 `*`、`dis==inf` 的格置 `dis+1` 入队。
4. 队空后输出 `ans`。

### 复杂度

- 时间 $O(XY)\le 10^4$ 格、每格 $8$ 次检查。
- 空间 $O(XY)$，两个 $105\times105$ 数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例（$4\times3$，起点左下）输出 $4$；手造 $1\times1$（$0$）、$3\times1$ 居中起点（$1$）、$2\times2$ 全草（$1$）、$3\times3$ 巨石绕路（$4$）四组与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2960 [USACO09OCT] Invasion of the Milkweed G
// 八方向 BFS：第 t 周被占领 <=> 距源点图上距离 <= t；答案 = 最大距离
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105},inf{1145141919};
constexpr int dx[8]{-1,-1,-1,0,0,1,1,1},dy[8]{-1,0,1,-1,1,-1,0,1};

int x,y,mx,my,dis[mxn][mxn],ans;
char g[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>x>>y>>mx>>my;
	for(int i=0;i<y;++i)
		cin>>g[i];
	fill_n(&dis[0][0],mxn*mxn,inf);	// 全局默认 0 会被当成"已访问"，必须置 INF
	int sr=y-my,sc=mx-1;	// (1,1) 在左下角：坐标行 my = 自上而下第 y-my 行（0-based）
	queue<int>Q;
	dis[sr][sc]=0;
	Q.push(sr*mxn+sc);
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		int ux=u/mxn,uy=u%mxn;
		ans=max(ans,dis[ux][uy]);
		for(int d=0;d<8;++d)
		{
			int nx=ux+dx[d],ny=uy+dy[d];
			if(nx<0||nx>=y||ny<0||ny>=x||g[nx][ny]=='*'||dis[nx][ny]!=inf)
				continue;
			dis[nx][ny]=dis[ux][uy]+1;
			Q.push(nx*mxn+ny);
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`dis` 必须显式 fill INF**：全局 `int` 默认 $0$，而 $0$ 是起点的合法距离；不 fill 的话所有格子都被当成"已访问"，BFS 一步都走不出去。这是本题最容易静默出错的一行。
- **坐标换算只有一处**：`sr=y-my,sc=mx-1`。输入行序与内部行序一致（都自上而下），所以地图本身不用翻转，只有起点要换。
- 边界判断用 `nx>=y`（行）与 `ny>=x`（列）：$y$ 是高、$x$ 是宽，写反会在非方形数据上越界或漏格。
- 队列存 `r*mxn+c` 的编码，解码用 `/mxn`、`%mxn`；`mxn` 是编译期常量，编解码都是常数时间。
- `ans` 在出队时取 max：每个草地恰出队一次（引理 4），巨石不入队，故无需最后再扫全图；全部草地可达由题目保证，`ans` 不会漏格。
- 八方向数组含对角——题面样例的最后一格 $(4,1)$ 正是靠"先对角绕到 $(3,2)$ 上方再下来"才占领的，四方向会错。
