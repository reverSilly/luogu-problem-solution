# P2539 [AHOI2005] 矿藏编码 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 矿藏区是 $2^K\times 2^K$ 的格子（$1<K<50$，即 $K\le 49$），黑格是山峰、白格是平地。它用一种**递归编码**记录：

- 整块全是平地 → 编码 `0`；
- 整块全是山峰 → 编码 `1`；
- 否则把这块**均匀切成 4 份**，依次编码得 $S_1,S_2,S_3,S_4$，整块编码为 `2`$S_1S_2S_3S_4$。

给一个长度 $\le 200$ 的编码串，问整片矿藏区有多少格是平地。（题面"输入格式"里写"由 `0`、`1` 组成"是笔误——它自己给的例子 `2021010210001` 就含 `2`，`2` 是"四分"标记，必须处理。）

**第一步：认出这是一棵四叉树。** 编码规则就是四叉树的先序遍历：`0`/`1` 是叶子（一块纯色区域），`2` 是内部结点（后面紧跟 4 棵子树，对应四个象限）。根是整片 $2^K\times2^K$，深度 $d$ 的结点代表一个 $2^{K-d}\times 2^{K-d}$ 的正方形。于是"统计平地格子数"变成"**递归解析这棵树，把每个 `0` 叶子代表的面积加起来**"。我不需要真的把格子画出来——一个 `0` 叶子一次性贡献它那块的全部格子数。

**第二步：一个 `0` 叶子贡献多少格？** 深度 $d$ 的块边长 $2^{K-d}$，面积 $(2^{K-d})^2=4^{K-d}$。所以解析到深度 $d$ 遇到 `0`，答案就加 $4^{K-d}$；遇到 `1` 加 $0$；遇到 `2` 就递归四个孩子（深度 $d+1$）再把它们的贡献相加。预处理 $4^0,4^1,\dots,4^K$ 即可 $O(1)$ 取面积。象限的先后顺序（题面图里那四种切法）**完全不影响答案**——我们只求总和，加法交换律保证怎么排都一样，所以不必纠结图里到底是左上还是右上先。

**第三步：真正的坑——答案会爆 `long long`。** 兴冲冲写完递归，我算了一下上界：整片全平地时答案 $=4^K$。$K$ 最大 $49$，$4^{49}=2^{98}\approx 3.17\times10^{29}$。而 `long long` 上限才 $9.2\times10^{18}$——**超了 11 个数量级**。哪怕编码只有一个字符 `0`，$K=49$ 时答案就是 $2^{98}$，`long long` 直接溢出成负数。这不是"可能溢出"，是"极限数据必然溢出"。

那 `unsigned long long` 呢？上限 $1.8\times10^{19}$，还是远小于 $2^{98}$，照样爆。必须上 `__int128`（上限约 $1.7\times10^{38}$，装 $2^{98}$ 绰绰有余）。而且 `cout` 不认识 `__int128`，得**手工逐位输出**。这一步是本题的分水岭：算法本身是小学递归，范围处理才是省选级别的陷阱。

**第四步：递归会不会太深？** 编码串长 $\le 200$，每个 `2` 至少消耗一个字符并让深度 $+1$，所以深度 $\le$ `2` 的个数 $\le 200$；又叶子只能出现在深度 $\le K\le 49$（深度 $K$ 时块已是 $1\times1$，必为 `0`/`1`），故实际深度 $\le 49$。栈深几十层，毫无压力。

**手造数据核对**（题面只给了编码例子没给输出，我手算它，另造四组打边界与溢出）：

题面例子 $K=2$、`2021010210001`：根 `2` 分四块（每块 $2\times2=4$ 格）——第一块 `0` 贡献 $4$；第二块 `2` 再分四个 $1\times1$：`1,0,1,0` 贡献 $0+1+0+1=2$；第三块 `2`：`1,0,0,0` 贡献 $0+1+1+1=3$；第四块 `1` 贡献 $0$。合计 $4+2+3+0=9$。程序输出 $9$ ✓。

另造：$K=2$、`0` → $16$（全平地）；$K=2$、`1` → $0$（全山峰）；$K=2$、`21000` → 根 `2` 四块 `1,0,0,0` 贡献 $0+4+4+4=12$；$K=49$、`0` → $2^{98}=316912650057057350374175801344$（专打 `__int128` 溢出边界，`long long` 版本在这里必翻车）。

## 二、思维链：完整证明

**记号。** 编码串 $s$（字符集 $\{0,1,2\}$），根深度 $0$。深度 $d$ 的结点代表边长 $2^{K-d}$ 的正方形，面积 $\mathrm{area}(d)=4^{K-d}$。`pw[d]`$=4^d$。解析函数 $\mathrm{dfs}(d)$ 消耗 $s$ 中描述该结点子树的一段字符，返回该块内平地格子数。全局指针 `pos` 指向下一个待读字符。

---

### 引理 1（编码与四叉树一一对应）

合法编码串恰好是一棵四叉树的先序遍历：`0`/`1` 为叶子，`2` 为内部结点且其后紧跟恰好 4 棵子树的编码。深度 $d$ 的结点代表 $2^{K-d}\times2^{K-d}$ 的块，且叶子只出现在深度 $\le K$。

*证明*：对编码规则归纳。根代表整片 $2^K\times2^K$（深度 $0$，边长 $2^{K-0}$ ✓）。若某深度 $d$ 的块编码为 `2`，规则说"均匀划分成 4 份"，每份边长减半为 $2^{K-d-1}=2^{K-(d+1)}$，即 4 个深度 $d+1$ 的孩子，编码依次为 $S_1S_2S_3S_4$——这正是先序遍历中"内部结点 + 4 棵子树"。若编码为 `0`/`1`，该块纯色，是叶子。深度 $K$ 时边长 $2^0=1$，块是单格，必纯色（`0` 或 `1`），不可能再分（`2` 要求"否则"即非纯色，单格必纯色），故叶子深度 $\le K$。反过来，任何这样的四叉树按规则展开都得到唯一编码串。证毕。

**推论（解析无歧义）**：先序遍历中，读到 `0`/`1` 即知一个叶子结束；读到 `2` 即知要再读 4 棵子树。故用一个全局指针顺序扫描即可唯一还原整棵树，无需回溯或分隔符。

---

### 引理 2（深度 $d$ 的块面积）

$\mathrm{area}(d)=4^{K-d}$，且 `pw[K-d]` 恰为其值。

*证明*：深度 $d$ 的块边长 $2^{K-d}$（引理 1），正方形面积 $=(2^{K-d})^2=2^{2(K-d)}=4^{K-d}$。代码预处理 `pw[0]=1`、`pw[i]=pw[i-1]*4`，由归纳 `pw[i]`$=4^i$，故 `pw[K-d]`$=4^{K-d}=\mathrm{area}(d)$。证毕。

---

### 引理 3（$\mathrm{dfs}$ 返回正确的平地数）

对任意深度 $d\le K$ 的结点，$\mathrm{dfs}(d)$ 返回该块内平地格子数，且恰好消耗描述该子树的字符段。

*证明*：对子树结构归纳。

**叶子 `0`**：该块全平地，平地数 $=\mathrm{area}(d)=4^{K-d}$，代码返回 `pw[K-d]` ✓（引理 2）。消耗 1 字符 ✓。

**叶子 `1`**：该块全山峰，平地数 $0$，代码返回 $0$ ✓。消耗 1 字符 ✓。

**内部 `2`**：该块被 4 个深度 $d+1$ 的孩子**不交**地铺满（四象限划分）。平地数 = 四个孩子平地数之和。代码读掉 `2` 后依次 $\mathrm{dfs}(d+1)$ 四次并累加。由归纳假设每个孩子返回其平地数、消耗其字符段，故累加值 = 本块平地数 ✓，消耗 = `2` + 四段子树 ✓。

**边界**：由引理 1，叶子深度 $\le K$，故 `pw[K-d]` 的下标 $K-d\ge 0$；又 $d\ge 0$ 故 $K-d\le K$，`pw` 预处理到 $K$ 足够，不越界。内部结点 $d<K$（深度 $K$ 必为叶子），递归 $d+1\le K$ 合法。证毕。

---

### 引理 4（象限顺序不影响答案）

无论四个象限按何种顺序编码，$\mathrm{dfs}(0)$ 的返回值相同。

*证明*：由引理 3，答案 $=\sum_{\text{叶子 }v,\ \mathrm{type}(v)=0}\mathrm{area}(\mathrm{depth}(v))$。这是一个对**叶子集合**求和的式子，每个叶子的贡献只取决于它的类型与深度，与它在兄弟中的排列顺序无关。加法满足交换律与结合律，故重排象限（即重排子树遍历顺序）不改变总和。因此题面图中未明示的象限先后顺序对答案无影响，无需确定。证毕。

---

### 引理 5（值域：必须 `__int128`，`long long` 必溢出）

答案 $\in[0,4^K]$，上界 $4^K\le 4^{49}=2^{98}\approx 3.17\times10^{29}$。该值超出 `long long` 上限 $2^{63}-1\approx 9.22\times10^{18}$，也超出 `unsigned long long` 上限 $2^{64}-1\approx 1.84\times10^{19}$，但远小于 `__int128` 上限 $2^{127}-1\approx 1.70\times10^{38}$。

*证明*：答案是非负整数，最大当整片全平地（编码 `0`），为 $4^K$。$K\le 49$ 故 $4^K\le 4^{49}=2^{98}$。比较：$2^{98}>2^{64}-1$（因 $98>64$），故 `long long` 与 `unsigned long long` 都表示不下，极限数据**必然**溢出（不是"可能"）。而 $2^{98}<2^{127}-1$，`__int128` 安全，余量约 $2^{29}$ 倍。中间量 `pw[i]`$=4^i\le 4^{49}=2^{98}$ 同样在 `__int128` 内；递归累加 $\le 4^K\le 2^{98}$ 不溢出。证毕。

**推论（输出须手工）**：`std::ostream` 无 `__int128` 重载，`cout<<ans` 编译失败。须递归 `wr(x)`：先 `wr(x/10)` 再 `putchar(x%10+'0')`，逐位输出。因答案 $\ge 0$，无需处理负号。

---

### 引理 6（递归深度与复杂度）

递归深度 $\le\min(K,\ \text{串长})\le 49$；时间 $O(|s|+K)$，空间 $O(K)$。

*证明*：每深入一层消耗至少一个 `2` 字符，故深度 $\le$ `2` 的个数 $\le|s|\le 200$；又由引理 1 深度 $\le K\le 49$，取小者 $\le 49$，栈安全。每个字符恰被 `pos++` 读一次，故解析 $O(|s|)$；预处理 `pw` 为 $O(K)$；合计 $O(|s|+K)$。空间：`pw` 数组 $K+1$ 个 `__int128`，递归栈 $O(K)$ 层，$O(K)$。证毕。

---

### 定理

程序输出矿藏区平地格子总数，全程 `__int128` 无溢出，复杂度 $O(|s|+K)$。

*证明*：引理 1 保证编码可无歧义解析为四叉树；引理 2、3 保证每个 `0` 叶子贡献正确面积、$\mathrm{dfs}(0)$ 返回总平地数；引理 4 保证象限顺序无关；引理 5 保证 `__int128` 既精确又不溢出、手工输出正确；引理 6 给复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 编码规则就是四叉树先序遍历：`0`/`1` 叶子、`2` 内部结点带 4 棵子树；深度 $d$ 的块面积 $4^{K-d}$。
- **reduce to easier problem** — "数平地格子"化归为"递归解析四叉树，把每个 `0` 叶子的面积累加"，不必真的展开 $2^K\times2^K$ 的网格。
- **explore its property** — 只求总和，加法交换律使象限顺序无关，绕开题面图未明示的切分方向。
- **discuss by category** — 算值域：$4^{49}=2^{98}$ 远超 `long long`/`unsigned long long`，必须 `__int128`；这是本题真正的陷阱。
- **classic problem solution** — `__int128` 手工逐位输出（`wr` 递归 + `putchar`），绕开 `cout` 无重载的问题。
- **explore its property** — 递归深度 $\le\min(K,|s|)\le 49$，栈安全；每字符读一次，$O(|s|+K)$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `k` | 规模指数，网格 $2^k\times2^k$（$1<k<50$） | `int`，读入 | 根深度 0，叶子深度 $\le k$ |
| `s` | 编码串（含 `0`/`1`/`2`） | `string`，读入 | 长度 $\le 200$ |
| `pos` | 下一个待读字符下标 | `int`，初值 0（全局默认） | 先序扫描指针 |
| `pw[d]` | $4^d$ | `i128[mxk]` | `pw[0]=1`，`pw[i]=pw[i-1]*4` |
| `dfs(d)` | 解析深度 $d$ 的块，返回平地数 | `i128(int)` | `0`→`pw[k-d]`，`1`→0，`2`→四子和 |
| `wr(x)` | 手工输出非负 `__int128` | `void(i128)` | 递归 `wr(x/10)` + `putchar` |
| `mxn` | 串长上界 $200+5$ | `constexpr int{205}` | 本题串用 `string`，此常量备用 |
| `mxk` | $K$ 上界 $49+5$ | `constexpr int{55}` | `pw` 尺寸 |

### 算法步骤

1. I/O 加速三行。
2. 读 `k` 与 `s`。
3. 预处理 `pw[0]=1`，`pw[i]=pw[i-1]*4`（$i=1..k$），全程 `__int128`。
4. `wr(dfs(0))`：从根先序解析，`0` 叶子加 `pw[k-d]`、`1` 叶子加 0、`2` 递归四子求和；手工逐位输出结果，`putchar('\n')`。

### 复杂度

- 时间：$O(|s|+K)$，$|s|\le 200,K\le 49$，极小。
- 空间：$O(K)$（`pw` 数组 + 递归栈 $\le 49$ 层）。
- 值域：答案 $\le 2^{98}$，`__int128` 安全（引理 5）。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；题面例子 $K=2$、`2021010210001` 手算得 $9$，程序输出 $9$；另造全平地（$16$）、全山峰（$0$）、混合（$12$）、$K=49$ 全平地（$2^{98}=316912650057057350374175801344$）四组手算数据全对，最后一组专验 `__int128` 溢出边界。本题为四叉树直接递归 + 大整数输出，性质清晰，未写对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2539 [AHOI2005] 矿藏编码
// 思路：编码是四叉树先序遍历。深度 d 的块面积 4^(k-d)。
//       dfs 解析：'0' 叶子加整块面积，'1' 加 0，'2' 递归四子求和。
//       答案最大 4^49=2^98 远超 long long ⇒ 全程 __int128，手工逐位输出。
//       只求总和，象限顺序无关（加法交换律）。
#include<bits/stdc++.h>
using namespace std;
using i128=__int128;

constexpr int mxn{205},mxk{55};

int k,pos;
string s;
i128 pw[mxk];	// pw[d]=4^d，深度 d 的块含 4^(k-d) 个格子

i128 dfs(int d)	// 解析深度 d 的一个块，返回其中平地格子数
{
	char c=s[pos++];
	if(c=='0')
		return pw[k-d];	// 整块平地
	if(c=='1')
		return 0;	// 整块山峰
	i128 res=0;
	for(int i=0;i<4;++i)
		res+=dfs(d+1);	// '2'：四份依次编码
	return res;
}

void wr(i128 x)	// __int128 手工输出（答案非负，无需负号）
{
	if(x>9)
		wr(x/10);
	putchar((int)(x%10)+'0');
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>k>>s;
	pw[0]=1;
	for(int i=1;i<=k;++i)
		pw[i]=pw[i-1]*4;
	wr(dfs(0));
	putchar('\n');
	return 0;
}
```

### 代码说明

- **`using i128=__int128;`** 是仓库允许的裸用别名。本题**必须**用它：$K=49$ 全平地时答案 $2^{98}$，`long long` 一定溢出（引理 5）。`pw` 与累加器都用 `i128`。
- **`dfs` 的三种字符**：`0`/`1` 是叶子直接返回面积或 0；`2` 读掉自身后递归四个深度 $d+1$ 的孩子。`pos` 全局递增，先序扫描无歧义（引理 1 推论）。
- **面积查表**：`pw[k-d]`$=4^{k-d}$ 即深度 $d$ 块的格子数，$O(1)$ 取得，避免每次现算幂。
- **`wr` 递归输出**：`cout` 无 `__int128` 重载，故先递归高位 `wr(x/10)` 再 `putchar` 低位。答案 $\ge 0$，不需负号分支。
- **象限顺序无关**：只求总和，`for(i=0;i<4;++i)` 按编码顺序累加即可，不必知道题面图里的切分方向（引理 4）。
- 递归深度 $\le\min(k,|s|)\le 49$，栈安全；`mxk{55}` 是 $49+5$ 松弛。
