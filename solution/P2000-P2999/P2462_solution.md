# P2462 [SDOI2007] 游戏 — 题解

## 一、解题过程：人类思考叙事

题目：给一张全小写英语单词表（$n\le 10000$ 行，每行一个长度不超过 $100$ 的单词；题面没有显式给出 $n$ 这个数，只说有 $n$ 行，按 EOF 读入）。词语接龙规则：

1. 前一个单词拥有的所有字母，在后一个单词里必须出现，且出现次数不少于前一个单词；
2. 后一个单词的长度比前一个恰好**多 $1$**。

求最长接龙，输出长度和任意一组最优方案（Special Judge，不要求字典序）。

**先把两条规则拧成一句话。** 设单词 $w$ 的字母计数向量为 $\mathrm{sig}(w)\in\mathbb{Z}_{\ge0}^{26}$。规则 1 说 $\mathrm{sig}$ 逐维不减，规则 2 说向量各维之和恰好加 $1$。逐维不减的整数向量、总和恰增 $1$——那只能是**某一维恰好 $+1$，其余维不变**。所以接龙规则等价于：

$$\text{后词签名}=\text{前词签名}+e_c\quad(\text{恰添加一个字母 }c).$$

字母的**排列顺序完全无关紧要**，`bar`、`bra`、`abr` 在接龙里是同一个东西。

**第一版想法：建图跑 DAG 最长路。** 把每个单词看成点，$v\to w$ 连边当且仅当满足接龙规则。边只从短词指向长词（长度恰 $+1$），图是 DAG，按长度排序后 DP 即可。但判边要逐对检查：$O(n^2\cdot 26)$，最坏 $10^8$ 对再乘 $26$ 维 $\approx 2.6\times10^9$ 次操作，太慢。瓶颈在"给每个词找前驱要扫描所有词"。

**关键观察：前驱其实只有至多 $26$ 种可能。** 由等价规则，词 $w$ 的前驱签名必然是 $\mathrm{sig}(w)-e_c$，其中 $c$ 取遍 $w$ 中出现的字母——至多 $26$ 个候选向量！不需要扫描词表，只要把"签名 $\to$ 单词"存进哈希表，每个词做 $\le 26$ 次哈希查找就能找齐所有前驱。查找一个 $26$ 字节串的哈希是 $O(26)$，总复杂度降到 $O(26^2 n)\approx 6.8\times 10^6$ 次字符操作，绰绰有余。

**顺手去重。** 签名相同的词（重复词、字母异位词）接龙能力完全相同：长度一样、与任何词的相容性一样。而一条接龙里长度严格递增，同长度的词至多出现一个，所以每个签名只保留一个代表词即可，答案不变，方案输出代表词也一定是词表里的词。

**DP 骨架。** 签名的各维之和就是词长，所以按词长 $l=1..100$ 分层处理：$f[u]=1+\max f[v]$，$v$ 取遍存在的 $\mathrm{sig}(u)-e_c$。长度 $l-1$ 的层先处理完，转移引用的 $f[v]$ 都已定型。记录 $\mathrm{prv}[u]$ 为取到最大值的前驱，最后从全局最优端点沿 $\mathrm{prv}$ 回溯、反转，就得到方案。

**几个实现坑，逐一排掉：**

- **输入没有显式 $n$**：`while(cin>>s)` 读到 EOF。为稳妥起见，跳过含数字的 token（单词保证全小写字母，数字串只可能是某些数据版本首行给出的 $n$），两种输入形态都兼容。
- **计数字节编码**：词长 $\le 100$，每维计数 $\le 100<127$，塞进 `char` 不会溢出；`std::string` 按长度管理内容，内嵌 `'\0'` 不影响哈希与比较。签名 $26$ 字节定长，可以直接当 `unordered_map` 的键。
- **签名决定长度**：$\mathrm{sig}$ 各维之和 $=$ 词长，所以"签名减一维"查到的词长度必然恰减 $1$，一张全局哈希表就够，不需要按长度分表，也不会跨层误匹配。
- **答案上界**：长度从 $\ge1$ 严格递增到 $\le100$，接龙至多 $100$ 个词，回溯路径很短。
- **全局数组初值**：`f[u]` 注册时置 $1$、`prv[u]` 置 $-1$，不能依赖全局 $0$（$0$ 是合法编号）。

**用题面给的词表走一遍。** `ab, arc, arco, bar, bran, carbon, carbons, cobra, crab, crayon, narc`。一条 $6$ 词接龙：`ab → bar → crab → cobra → carbon → carbons`，每步恰好加一个字母（r, c, o, n, s）。它为什么最优？词表里没有长度 $1$ 的词，最短是长度 $2$ 的 `ab`，最长是长度 $7$ 的 `carbons`，长度严格递增 ⇒ 接龙至多 $7-2+1=6$ 个词。上界可达，答案就是 $6$。程序输出与这条链完全一致。

## 二、思维链：完整证明

以下记输入词表为 $W$（可含重复），$\mathrm{sig}(w)[c]$ 为字母 $c$ 在 $w$ 中的出现次数，$|w|$ 为词长。注意恒等式 $\sum_c \mathrm{sig}(w)[c]=|w|$。

**引理 1（规则等价刻画）**：对词 $v,w$，"$v$ 可接 $w$"（满足题面两条规则）当且仅当存在字母 $c$ 使 $\mathrm{sig}(w)=\mathrm{sig}(v)+e_c$。

*证明*：必要性：规则 1 给出 $\forall c,\ \mathrm{sig}(w)[c]\ge\mathrm{sig}(v)[c]$，即差向量 $d=\mathrm{sig}(w)-\mathrm{sig}(v)$ 各维为非负整数；规则 2 给出 $\sum_c d[c]=|w|-|v|=1$。非负整数之和为 $1$，必有恰好一维等于 $1$、其余全为 $0$，即 $d=e_c$。充分性：若 $\mathrm{sig}(w)=\mathrm{sig}(v)+e_c$，则逐维不减（规则 1 成立），且 $|w|=\sum\mathrm{sig}(w)=\sum\mathrm{sig}(v)+1=|v|+1$（规则 2 成立）。证毕。

**引理 2（签名充分性与去重保最优）**：(a) 一个词序列是否构成合法接龙，只取决于其签名序列；(b) 设 $S$ 为输入中出现的不同签名之集，每个签名保留一个代表词（算法保留首个），则"只用代表词的最长接龙长度"等于"用全部输入词的最长接龙长度"。

*证明*：(a) 由引理 1，相邻两词的合法性等价于签名相差一个 $e_c$，与词的字母排列无关；整个序列合法当且仅当每对相邻签名满足该条件，故只依赖签名序列。

(b) 记全词表最优值为 $\mathrm{OPT}_W$，代表词表最优值为 $\mathrm{OPT}_S$。一方面代表词都是输入词，代表词表上的任何接龙也是 $W$ 上的接龙，故 $\mathrm{OPT}_S\le\mathrm{OPT}_W$。另一方面，取 $W$ 上一条最优接龙 $w_1,\dots,w_m$，把每个 $w_t$ 换成其签名的代表词 $w'_t$：由 (a)，签名序列未变，新序列仍合法；每个 $w'_t$ 都在输入中；长度仍为 $m$。故 $\mathrm{OPT}_S\ge m=\mathrm{OPT}_W$。两向夹逼得相等。

附带说明：接龙中词长严格递增（每步 $+1$），故同长度的词至多出现一次，替换代表词不会造成"同一个词被用两次"的冲突；且接龙中的词两两不同（长度不同）。证毕。

**引理 3（前驱枚举完备且无冗余）**：对签名 $s\in S$，其在 $S$ 中的全部可能前驱恰为集合 $\{s-e_c:\ s[c]\ge1\}\cap S$；算法对每个 $c$ 做一次哈希查找，恰好不重不漏地考察了这个集合。

*证明*：由引理 1，$v$ 是 $s$ 的前驱当且仅当 $\mathrm{sig}(v)=s-e_c$ 对某个 $c$ 成立。$s-e_c$ 要是合法签名必须 $s[c]\ge1$（否则该维为负，不对应任何词）。反之对每个满足 $s[c]\ge1$ 的 $c$，$s-e_c$ 是非负整数向量，若它属于 $S$ 则对应词是合法前驱。故可能前驱集合恰为 $\{s-e_c:s[c]\ge1\}\cap S$。不同的 $c$ 给出不同的向量（差在不同维），枚举无重复；算法循环 $c=0..25$、跳过 $s[c]=0$、查表命中才转移，与该集合一一对应。证毕。

**引理 4（分层处理的拓扑性）**：设 $u$ 的词长为 $l$。算法按 $l=1,2,\dots$ 逐层处理，处理 $u$ 时引用的任何 $f[v]$（$v$ 为 $u$ 的前驱）都已计算完毕且此后不再改变。

*证明*：由引理 3，前驱签名 $s-e_c$ 的各维之和为 $l-1$，故前驱词长恰为 $l-1$，被分在更早的层。层内转移只引用长度小 $1$ 的层，同层之间无引用，故层内处理顺序任意。对 $l$ 归纳：$l=1$ 层无前驱（前驱需长度 $0$，而 `cin>>s` 读入的词非空，词表中不存在长度 $0$ 的词），$f$ 保持初值 $1$，处理后不再被修改（后续层只读不写它）；假设 $<l$ 的层处理完后 $f$ 值定型，则第 $l$ 层处理时引用的都是定型值，且第 $l$ 层只写本层的 $f$，归纳成立。证毕。

**引理 5（DP 正确性）**：对每个注册词 $u$，处理完其所在层后，$f[u]$ 等于"以 $u$ 的签名结尾的最长接龙长度" $L(u)$；$\mathrm{prv}[u]$ 要么为 $-1$（$L(u)=1$），要么为满足 $f[\mathrm{prv}[u]]+1=f[u]$ 的前驱编号。

*证明*：对词长 $l$ 归纳。$l=1$：无前驱（引理 4），任何以 $u$ 结尾的接龙只有 $u$ 自己，$L(u)=1=f[u]$，$\mathrm{prv}[u]=-1$ 保持初值。

设结论对一切长度 $<l$ 成立。取长度 $l$ 的 $u$。任何以 $u$ 结尾、长度 $\ge2$ 的接龙，其倒数第二个词 $v$ 必是 $u$ 的前驱（引理 1），且去掉 $u$ 后是以 $v$ 结尾的接龙，长度 $\le L(v)$；由引理 2，把整条链换成代表词不改变长度与合法性，故可设 $v$ 是注册词。于是

$$L(u)=1+\max\{L(v):\ v\text{ 是 }u\text{ 的注册前驱}\},$$

前驱集为空时 $L(u)=1$。由引理 3，算法枚举的恰是这个前驱集；由引理 4 与归纳假设，枚举时 $f[v]=L(v)$ 已定型。算法执行 $f[u]\leftarrow\max(f[u],f[v]+1)$（初值 $1$ 对应空前驱集），故处理完后 $f[u]=L(u)$；$\mathrm{prv}[u]$ 在严格变优时更新为当前 $v$，最终要么保持 $-1$（无改进，$f[u]=1$），要么指向取到最大值的前驱，满足 $f[\mathrm{prv}[u]]+1=f[u]$。证毕。

**引理 6（回溯重构合法且最优）**：设 $\mathrm{best}$ 为算法结束时 $f$ 最大的编号。从 $\mathrm{best}$ 沿 $\mathrm{prv}$ 走到 $-1$、反转得到的词序列是一条合法接龙，长度恰为 $f[\mathrm{best}]=\max_u L(u)$，即全局最优。

*证明*：先证终止与长度：每步 $u\to\mathrm{prv}[u]$ 词长减 $1$（引理 3），长度非负故至多 $100$ 步必到 $-1$；由引理 5，非 $-1$ 的每步满足 $f$ 值减 $1$，故路径点数恰为 $f[\mathrm{best}]$。再证合法：路径上相邻两点 $v=\mathrm{prv}[u]$ 满足 $\mathrm{sig}(v)=\mathrm{sig}(u)-e_c$，由引理 1 反转后 $v$ 可接 $u$；所有点都是注册词即输入词（引理 2 保证代表词合法）。最后证最优：$\mathrm{best}$ 的维护方式是每处理完一个 $u$ 就比较 $f[u]>f[\mathrm{best}]$，而每个 $f[u]$ 在其所在层处理完后定型（引理 4、5），故结束时 $f[\mathrm{best}]=\max_u f[u]=\max_u L(u)$；由引理 2，这就是全词表的最长接龙长度。证毕。

**引理 7（编码与边界）**：(a) 用 $26$ 字节 `string` 存签名是单射编码，哈希查找不会把不同签名混同；(b) 每维计数 $\le100$，`char` 运算不溢出；(c) 答案 $\in[1,100]$。

*证明*：(a) 签名到 $26$ 字节串按维一一对应；`std::string` 的相等与哈希都基于完整字节序列（含内嵌 `'\0'`，长度固定 $26$），故键相等当且仅当签名相等。又因各维之和等于词长，"签名减一维"得到的键只可能命中长度恰减 $1$ 的词，全局一张表不会跨长度误匹配。(b) 词长 $\le100$，任一字母计数 $\le100$；`char` 在该平台为 $8$ 位有符号，范围 $[-128,127]$，$100$ 及其减一运算均在范围内。(c) 词表非空（$n\ge1$）故答案 $\ge1$；接龙词长严格递增、最小 $\ge1$、最大 $\le100$，故词数 $\le100$。证毕。

**定理（算法正确性）**：算法输出的第一行是最长接龙长度，随后各行构成一条达到该长度的合法接龙。

*证明*：引理 5 保证 $f$ 值正确，引理 6 保证 $\mathrm{best}$ 取到全局最大且回溯链合法、长度等于 $f[\mathrm{best}]$，引理 2 保证去重不损失最优、代表词属于输入，引理 7 保证编码与数值边界无误。合起来即定理。证毕。

**引理 8（复杂度）**：设输入总字符数 $\Sigma=\sum|s|\le 10^6$，不同签名数 $T\le n$。时间复杂度 $O(\Sigma+26^2\cdot T)$（哈希均摊），空间复杂度 $O(T\cdot(100+26))$。

*证明*：读入与建签名 $O(\Sigma+26T)$；每次哈希插入/查找对 $26$ 字节键是 $O(26)$ 均摊。DP 阶段每个注册词至多 $26$ 轮，每轮一次 $26$ 字节拷贝、一次 $O(26)$ 查找，共 $O(26^2 T)\approx 6.8\times10^6$ 次字符级操作。分桶 $O(T)$，回溯与输出 $O(100)$。空间：`wrd` 存词（$\le100$ 字节）、`key` 存签名（$26$ 字节）、哈希表 $T$ 项、`f/prv/bylen` 共 $O(T+100)$。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 两条规则合并：后词签名 = 前词签名 + 恰一个 $e_c$，字母顺序无关。
2. **consider easier version** — 先想朴素建图 + DAG 最长路，$O(26n^2)$ 在最坏数据下碰壁。
3. **reduce to easier problem** — 相容性只依赖 $26$ 维计数签名 ⇒ 重复词/异位词去重，每签名留一个代表。
4. **classic problem solution** — 前驱 = 签名减一个字母，至多 $26$ 个候选 ⇒ 哈希表查找代替全表扫描。
5. **classic problem solution** — 按词长分层的 DAG 最长路 DP + 前驱指针回溯输出方案。
6. **explore its property** — 签名各维之和 = 词长 ⇒ 全局一张哈希表天然分层；计数 $\le100$ 可压进字节；EOF 读入兼容显式 $n$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|----------------|
| `tot` | 不同签名的个数（注册词数 $T$） | `int` | $0$ |
| `id` | 签名（$26$ 字节串）$\to$ 编号 | `unordered_map<string,int>` | 空；签名各维之和=词长，天然防跨层误匹配 |
| `wrd[u]` | 编号 $u$ 的代表词（该签名首个输入词） | `string[mxn]` | 注册时赋值；输出方案用它 |
| `key[u]` | 编号 $u$ 的签名，`key[u][c]`=字母 $c$ 计数 | `string[mxn]` | 注册时赋值；计数 $\le100$ 存 `char` |
| `f[u]` | 以 $u$ 结尾的最长接龙长度 | `int[mxn]` | 注册时置 $1$（不是 $0$！） |
| `prv[u]` | 最优链上 $u$ 的前驱编号 | `int[mxn]` | 注册时置 $-1$（$0$ 是合法编号，不能当哨兵） |
| `bylen[l]` | 词长为 $l$ 的编号列表 | `vector<int>[mxl]` | 空；$l\le100<105$ |
| `best` | 全局最优链尾编号 | `int` | $0$（词表非空，编号 $0$ 必存在） |
| `path` | 回溯出的编号路径（逆序） | `vector<int>` | 临时；反转后输出 |

### 算法步骤

1. 初始化 I/O 加速（`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`）。
2. `while(cin>>s)` 读到 EOF：跳过含数字的 token（兼容首行显式给出 $n$ 的数据形态）；构造 $26$ 字节签名；已注册则跳过（去重），否则分配编号 `u=tot++`，写入 `id/wrd/key`，置 `f[u]=1,prv[u]=-1`，把 `u` 挂进 `bylen[|s|]`。
3. 对 $l=1..104$、对 `bylen[l]` 中每个 $u$：枚举字母 $c$，若 `key[u][c]>0` 则拷贝签名并将第 $c$ 维减一得到前驱键，查 `id`；命中 $v$ 且 `f[v]+1>f[u]` 时更新 `f[u]` 与 `prv[u]`；处理完 $u$ 后用 `f[u]` 更新 `best`。
4. 从 `best` 沿 `prv` 收集编号直到 $-1$，反转得 `path`。
5. 输出 `path.size()`，再逐行输出 `wrd[path[t]]`。

### 复杂度

- 时间复杂度：$O(\Sigma+26^2\cdot T)$，$\Sigma\le10^6$ 为输入总长，$T\le n\le10^4$；约 $10^7$ 量级字符操作。
- 空间复杂度：$O(T\cdot(100+26))$，约几 MB。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；题面 $11$ 词示例输出 $6$ 且链与题面一致；$300$ 组随机小数据（含异位词、重复词、随机长链偏置）与 $O(26n^2)$ 暴力答案一致且方案全部通过合法性校验；单词/全重复/全异位词/长度 $100$ 链等边界正确；$10000$ 词满规模数据 $0.1$ 秒跑完，答案 $100$ 达理论上界且方案合法。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2462 [SDOI2007] 游戏
// 接龙规则等价于：后词字母计数向量 = 前词计数向量 + 恰一个字母
// 把单词压成 26 维签名（每维一个字节），同签名（重复词/异位词）只留一个代表
// 按长度分层 DP：f[u]=以 u 结尾的最长接龙；前驱 = 签名减去一个字母，哈希查找
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005},mxc{26},mxl{105};

int tot,f[mxn],prv[mxn];
string wrd[mxn],key[mxn];
unordered_map<string,int>id;
vector<int>bylen[mxl];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	string s;
	while(cin>>s)
	{
		if(s.find_first_of("0123456789")!=string::npos)
			continue;   // 题面只说有 n 行单词；若数据首行给了数字 n 则跳过（单词保证全小写）
		string k(mxc,'\0');
		for(char ch:s)
			++k[ch-'a'];
		if(id.count(k))
			continue;   // 同签名接龙能力完全相同，留一个代表即可
		int u=tot++;
		id[k]=u;
		wrd[u]=s;
		key[u]=k;
		f[u]=1;
		prv[u]=-1;
		bylen[s.size()].push_back(u);
	}
	int best=0;
	for(int l=1;l<mxl;++l)
		for(int u:bylen[l])
		{
			for(int c=0;c<mxc;++c)
			{
				if(key[u][c]==0)
					continue;
				string k=key[u];
				--k[c];   // 前驱签名：第 c 种字母少一个，长度恰减 1
				auto it=id.find(k);
				if(it==id.end())
					continue;
				int v=it->second;
				if(f[v]+1>f[u])
				{
					f[u]=f[v]+1;
					prv[u]=v;
				}
			}
			if(f[u]>f[best])
				best=u;
		}
	vector<int>path;
	for(int u=best;u!=-1;u=prv[u])
		path.push_back(u);
	reverse(path.begin(),path.end());
	cout<<path.size()<<'\n';
	for(int u:path)
		cout<<wrd[u]<<'\n';
	return 0;
}
```

### 代码说明

- **签名即键**：`string k(26,'\0')` 的每个字节是一种字母的计数；`std::string` 按长度管理字节，内嵌 `'\0'` 不影响 `unordered_map` 的哈希与相等比较。
- **去重在注册时完成**：`id.count(k)` 命中即跳过，保证每个签名只有一个代表词，`f/prv` 也只对代表词计算。
- **`f[u]=1,prv[u]=-1` 显式初始化**：全局 `int` 数组默认 $0$，而 $0$ 是合法编号、$1$ 才是"只有自己"的链长，不能靠默认值。
- **分层循环 `l=1..104`**：词长 $\le100$，前驱长度恰减一，处理第 $l$ 层时第 $l-1$ 层的 `f` 已定型；同层互不引用，顺序任意。
- **回溯**：`prv` 链每步词长减一，至多 $100$ 步；`reverse` 后即为从短到长的接龙。
- **数字 token 跳过**：题面输入是 $n$ 行单词、无显式 $n$；若某些数据首行带 $n$，该行是纯数字，跳过后两种形态都正确（单词保证全小写，不会误伤）。
- SPJ 只要求最长与合法，不要求字典序，故代表词任取首个即可。
