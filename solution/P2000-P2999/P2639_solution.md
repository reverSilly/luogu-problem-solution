# P2639 [USACO09OCT] Bessie's Weight Problem G — 题解

## 一、解题过程：人类思考叙事

**题意重述。** Bessie 每天最多吃 $H$ 公斤干草（$5\le H\le45000$）。有 $N$ 捆干草（$1\le N\le500$），第 $i$ 捆重 $S_i$（$1\le S_i\le H$）。每捆**要么整捆吃完、要么不吃**，且**每捆最多吃一次**（即使有两捆重量相同，也是两捆独立的草）。求不超过 $H$ 的前提下能吃到的**最大总重量**。

**第一反应：这就是 0/1 背包，而且"价值 = 重量"。** 每捆草是一个物品，重量 $S_i$，只能选一次，背包容量 $H$。普通背包要最大化"总价值"，而这题价值就是重量本身——所以目标是**不超过 $H$ 的最大子集和**。一下子认出经典模型，方向就定了。

**第二步：否掉暴力。** 枚举每捆吃不吃，共 $2^N$ 种方案，$N=500$ 时 $2^{500}$ 是天文数字，彻底不可行。必须 DP。

**第三步：列状态与转移。** 设 $dp_i[j]$ 为"只考虑前 $i$ 捆草、总重量不超过 $j$ 时能吃到的最大重量"。考虑第 $i$ 捆（重 $w=S_i$）吃不吃：

- **不吃**：问题退化成前 $i-1$ 捆、容量 $j$，即 $dp_{i-1}[j]$；
- **吃**：先给它腾出 $w$ 的空间，剩下容量 $j-w$ 交给前 $i-1$ 捆，即 $dp_{i-1}[j-w]+w$（要求 $j\ge w$）。

于是
$$dp_i[j]=\begin{cases}\max\bigl(dp_{i-1}[j],\ dp_{i-1}[j-w]+w\bigr),&j\ge w,\\ dp_{i-1}[j],&j<w.\end{cases}$$
答案就是 $dp_N[H]$。状态数 $N\times H$，每个 $O(1)$ 转移，$O(NH)=500\times45000=2.25\times10^7$，能过。

**第四步：滚成一维，以及那个"必须倒序"的坑。** $dp_i$ 只依赖 $dp_{i-1}$，可以滚成一维数组 `dp[j]`。但**内层循环必须从 $H$ 倒着扫到 $w$**，这是 0/1 背包的命门。我特意想了为什么：

转移要用的是**上一层**的 `dp[j-w]`。倒序时，算 `dp[j]` 用到 `dp[j-w]`，而 $j-w<j$，倒序意味着 `dp[j-w]` **还没被本物品更新过**，存的正是上一层的值——正确。若**正序**，算 `dp[j]` 时 `dp[j-w]` 可能已经被本物品更新过（成了 $dp_i[j-w]$），于是同一捆草被算了两次，变成"完全背包"（每捆可吃无限次），错。

我造了个反例确认：$H=4$，只有一捆 $w=2$。正序：`dp[2]=dp[0]+2=2`，接着 `dp[4]=dp[2]+2=4`——可明明只有一捆 $2$ 公斤的草，最多吃 $2$，正序却给出 $4$（把同一捆吃了两次）。倒序：`dp[4]=dp[2]+2=0+2=2`（此时 `dp[2]` 还是 $0$），正确。这个反例把"倒序"的必要性钉死了。

**第五步：初始化与答案。** `dp` 全 $0$ 即可：$dp_0[j]=0$（一捆都不吃，重量 $0$，且 $0\le j$ 合法）。因为允许"吃不饱"（子集和可以 $<j$），$dp[j]\ge0$ 恒成立，不需要 $-\infty$ 哨兵。最后输出 `dp[H]`：由单调性它就是"不超过 $H$ 的最大子集和"。

**手算核对**（题面样例）：$H=56$，四捆 $15,19,20,21$。能吃 $15+20+21=56$，恰好顶到上限；其它组合如 $19+20+21=60>56$ 超限，$15+19+21=55<56$。故答案 $56$，程序输出一致。

## 二、思维链：完整证明

**记号。** 物品（草捆）重量 $w_1,\dots,w_N$（$w_i=S_i\in[1,H]$），容量 $H$。对子集 $T\subseteq\{1..i\}$，记 $w(T)=\sum_{t\in T}w_t$。定义
$$dp_i[j]=\max\{\,w(T):T\subseteq\{1..i\},\ w(T)\le j\,\},\qquad 0\le i\le N,\ 0\le j\le H.$$
因空集 $w(\varnothing)=0\le j$，集合非空，最大值存在且 $\ge0$。

---

### 引理 1（题目即 $dp_N[H]$）

题目所求"不超过 $H$ 的最大总重量"等于 $dp_N[H]$。

*证明*：一个合法吃法就是选一个草捆子集 $T\subseteq\{1..N\}$（每捆至多一次对应子集元素不重复），总重量 $w(T)$，约束 $w(T)\le H$。目标是最大化 $w(T)$。按定义 $dp_N[H]=\max\{w(T):T\subseteq\{1..N\},w(T)\le H\}$，正是所求。证毕。

---

### 引理 2（二维转移）

对 $i\ge1$：若 $j\ge w_i$，$dp_i[j]=\max(dp_{i-1}[j],\ dp_{i-1}[j-w_i]+w_i)$；若 $j<w_i$，$dp_i[j]=dp_{i-1}[j]$。

*证明*：把可行子集族 $\{T\subseteq\{1..i\}:w(T)\le j\}$ 按"是否含 $i$"划分。

**不含 $i$**：$T\subseteq\{1..i-1\}$，$w(T)\le j$，其最大重量 $=dp_{i-1}[j]$。

**含 $i$**（仅当 $j\ge w_i$ 可能）：写 $T=T'\cup\{i\}$，$T'\subseteq\{1..i-1\}$。约束 $w(T)=w(T')+w_i\le j\iff w(T')\le j-w_i$。故这类 $T$ 的最大重量 $=\max\{w(T')+w_i:T'\subseteq\{1..i-1\},w(T')\le j-w_i\}=dp_{i-1}[j-w_i]+w_i$。

两族不交且并为全体，故最大值是两族最大值的较大者，即 $\max(dp_{i-1}[j],dp_{i-1}[j-w_i]+w_i)$。若 $j<w_i$，含 $i$ 的族为空（$w(T)\ge w_i>j$），只剩不含 $i$ 的族，$dp_i[j]=dp_{i-1}[j]$。证毕。

---

### 引理 3（一维滚动 + 倒序的正确性，核心）

用一维数组 `dp[0..H]`，初始全 $0$。对 $i=1..N$，令 `for j=H downto w_i: dp[j]=max(dp[j],dp[j-w_i]+w_i)`。则处理完第 $i$ 个物品后，对所有 $j$ 有 `dp[j]`$=dp_i[j]$。

*证明*：对 $i$ 归纳。$i=0$：`dp` 全 $0=dp_0[j]$（引理 4）。设处理第 $i$ 个物品前 `dp[j]`$=dp_{i-1}[j]$ 对所有 $j$。考察本物品的倒序循环，按 $j$ 从 $H$ 递减到 $w_i$ 依次更新。

**关键不变量**：在更新 `dp[j]` 的那一刻，对所有 $k\ge j$，`dp[k]` 已被本物品更新为 $dp_i[k]$；对所有 $k<j$，`dp[k]` 仍是 $dp_{i-1}[k]$（尚未访问）。这是因为倒序：比 $j$ 大的下标先被更新，比 $j$ 小的还没轮到。

于是更新 `dp[j]`（$j\ge w_i$）时：右端 `dp[j]` 此刻 $=dp_{i-1}[j]$（$j$ 本身首次被本物品更新）；`dp[j-w_i]` 因 $j-w_i<j$，此刻 $=dp_{i-1}[j-w_i]$。故
$$\texttt{dp}[j]\leftarrow\max(dp_{i-1}[j],\ dp_{i-1}[j-w_i]+w_i)=dp_i[j]\quad(\text{引理 2}).$$
对 $j<w_i$：循环不触及，`dp[j]` 保持 $dp_{i-1}[j]=dp_i[j]$（引理 2 的 $j<w_i$ 分支）。故循环结束后所有 `dp[j]`$=dp_i[j]$。归纳成立。证毕。

**反例（正序为何错）**：若正序 `for j=w_i to H`，更新 `dp[j]` 时 `dp[j-w_i]`（$j-w_i<j$）可能已被本物品更新为 $dp_i[j-w_i]$，转移变成 $\max(dp_{i-1}[j],dp_i[j-w_i]+w_i)$，允许物品 $i$ 被重复计入。具体：$H=4$、单个物品 $w=2$，正序得 `dp[2]=2`、`dp[4]=dp[2]+2=4`，但真实 $dp_1[4]=2$（只有一捆 $2$）。倒序得 `dp[4]=dp[2]+2=0+2=2`，正确。故倒序是 0/1（每物品一次）约束的实现关键。

---

### 引理 4（初始化）

$dp_0[j]=0$ 对所有 $j\ge0$。故全局 `int dp[]` 默认 $0$ 恰好正确，无需显式填充。

*证明*：前 $0$ 个物品的子集只有 $\varnothing$，$w(\varnothing)=0\le j$，故 $dp_0[j]=0$。全局数组零初始化与之吻合。又因空集始终可行，$dp_i[j]\ge0$ 恒成立，转移中不会出现"不可达"状态，无需 $-\infty$ 哨兵。证毕。

---

### 引理 5（单调性与答案）

$dp_i[j]$ 关于 $j$ 单调不减；特别地 $dp_N[H]$ 即答案，无需再对 $j$ 取 max。

*证明*：$j_1\le j_2\Rightarrow\{T:w(T)\le j_1\}\subseteq\{T:w(T)\le j_2\}$，更大集合上取最大值不会更小，故 $dp_i[j_1]\le dp_i[j_2]$。由引理 1，答案 $=dp_N[H]$，直接输出即可。证毕。

---

### 引理 6（复杂度与值域）

时间 $O(NH)$，空间 $O(H)$；所有 `dp` 值 $\le H\le45000$，`int` 安全。

*证明*：$N$ 个物品，每个内层循环至多 $H$ 次 $O(1)$ 转移，时间 $O(NH)=500\times45000=2.25\times10^7$。一维数组 `dp[0..H]`，空间 $O(H)$。任何 $dp_i[j]\le j\le H\le45000$（子集和不超过容量），`int`（$\pm2.1\times10^9$）绰绰有余；转移 `dp[j-w]+w`$\le(j-w)+w=j\le H$，无溢出。证毕。

---

### 定理

程序输出不超过 $H$ 的最大可吃重量，复杂度 $O(NH)$、空间 $O(H)$。

*证明*：引理 1 把题目化为 $dp_N[H]$；引理 2 给出转移；引理 3 证明一维倒序滚动逐项等于二维 DP（含正序反例）；引理 4 保证初始化；引理 5 保证答案即 `dp[H]`；引理 6 给出复杂度与值域。证毕。

## 三、模式总结（按实际思考顺序）

- **classic problem solution** — 认出 0/1 背包，且"价值 $=$ 重量"⇒ 求不超过 $H$ 的最大子集和。
- **consider easier version** — 暴力 $2^N$ 不可行（$N=500$），确认必须 DP。
- **classic problem solution** — 背包 DP：$dp_i[j]=\max(dp_{i-1}[j],dp_{i-1}[j-w_i]+w_i)$，按"第 $i$ 捆吃不吃"划分。
- **reduce to easier problem** — 二维滚成一维 `dp[j]`，空间 $O(H)$。
- **explore its property** — 0/1 约束的命门：内层**倒序**保证用到上一层 `dp[j-w]`；正序会重复计入（$H=4,w=2$ 反例）。
- **discuss by category** — 初始化全 $0$（空集合法，$dp\ge0$，无需 $-\infty$）；答案直接 `dp[H]`（单调性）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `H` | 容量上限（$\le45000$） | `int`，读入 | 也是答案下标 |
| `n` | 草捆数（$\le500$） | `int`，读入 | 物品个数 |
| `w` | 当前草捆重量 $S_i$ | `int`，逐个读入 | 重量即价值 |
| `dp[j]` | 处理过的草捆中，总重 $\le j$ 的最大重量 | `int[mxh]`，全 $0$ | 滚动数组，答案 `dp[H]` |
| `mxh` | $45000+5$ | `constexpr int{45005}` | +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 `H,n`；`dp` 全局默认全 $0$（引理 4）。
3. 对每捆草：读 `w`；`for j=H downto w`：`dp[j]=max(dp[j],dp[j-w]+w)`（倒序，引理 3）。
4. 输出 `dp[H]`。

### 复杂度

- 时间：$O(NH)=2.25\times10^7$。
- 空间：$O(H)$，约 $180$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例（$H=56$，$15/19/20/21$）输出 $56$ 吻合；倒序必要性已用 $H=4,w=2$ 反例确认（引理 3）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2639 Bessie's Weight Problem G
// 思路：0/1 背包，价值=重量 ⇒ 求不超过 H 的最大子集和。
//       dp[j]=max(dp[j],dp[j-w]+w)，内层倒序保证每捆只吃一次。
//       dp 全 0 初始化（空集合法），答案 dp[H]。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxh{45005};

int H,n,dp[mxh];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>H>>n;
	for(int i=0,w;i<n;++i)
	{
		cin>>w;
		for(int j=H;j>=w;--j)		// 必须倒序：用到上一层 dp[j-w]
			dp[j]=max(dp[j],dp[j-w]+w);
	}
	cout<<dp[H]<<'\n';
	return 0;
}
```

### 代码说明

- **倒序是 0/1 背包的命门**：`for(j=H;j>=w;--j)` 保证更新 `dp[j]` 时 `dp[j-w]` 仍是上一层值（引理 3）；写成正序就退化成完全背包（每捆可重复吃），$H=4,w=2$ 会错出 $4$。
- **`dp` 全 $0$ 即可**：空集重量 $0$ 始终合法，$dp[j]\ge0$，不需要 $-\infty$；全局数组默认 $0$ 恰好正确（引理 4）。
- **价值 $=$ 重量**：转移 `dp[j-w]+w` 里加的 `w` 既是占用也是价值，故 `dp[H]` 直接就是最大可吃重量。
- **`w` 在循环头读入**：`for(int i=0,w;...)` 是风格允许的临时变量声明；每捆读完立即做背包，无需存全部重量。
- 时间 $2.25\times10^7$、空间约 $180$ KB，远低于限制。
