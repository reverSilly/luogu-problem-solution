# P2213 [USACO14MAR] The Lazy Cow S — 题解

## 一、解题过程：人类思考叙事

先重述题意。有一个 $N\times N$ 的草地矩阵（$N\le 400$），第 $r$ 行第 $c$ 列有 $G(r,c)$ 单位青草（$0\le G\le 1000$）。贝茜要选一个格子住下，从居住点出发**最多走 $K$ 步**（$0\le K\le 2N$），每步走到上下左右相邻的格子。问她最多能吃到多少青草。

第一件要弄清楚的事：**"最多走 $K$ 步"到底能吃到哪些格子？** 没有障碍，从 $(r,c)$ 走到 $(x,y)$ 的最短步数就是曼哈顿距离 $|x-r|+|y-c|$：一方面每走一步 $|x-r|+|y-c|$ 这个量最多减少 $1$，所以至少要走这么多步；另一方面先竖着走再横着走就能恰好走这么多步。于是"能走到的格子"就是所有满足 $|x-r|+|y-c|\le K$ 的格子，也就是一个**菱形**（旋转 $45^\circ$ 的正方形）。题面的 Hint 恰好把菱形内的格子都打了星号，这也确认了"能吃到"指的是这个区域里所有格子的青草之和，而不是"沿着一条长度 $K$ 的路径依次吃"。

于是问题变成：**在 $N\times N$ 个格子里找一个菱形（曼哈顿半径 $K$），使覆盖的权值和最大。**

最直接的做法是枚举中心 $(r,c)$，再枚举所有格子判断是否落在菱形内，复杂度 $O(N^4)$。$N=400$ 时是 $2.56\times 10^{10}$，必然超时。

退一步想：固定中心后，枚举"行偏移" $dx$，这一行被覆盖的列恰好是区间 $[c-(K-|dx|),\ c+(K-|dx|)]$，用每行的前缀和 $O(1)$ 求出这段的和。每个中心要看 $2K+1$ 行，于是总复杂度 $O(N^2\cdot \min(N,2K+1))=O(N^3)$，$N=400$ 时约 $6.4\times 10^7$。这个复杂度已经能过题了，但它让我注意到一件事：**菱形是斜着的，所以按行拆区间时每个中心的形状都不一样**；如果能把菱形"摆正"，就能用二维前缀和 $O(1)$ 求一个中心，整体降到 $O(N^2)$。

摆正的办法是坐标旋转 $45^\circ$。令

$$u=r+c,\qquad v=r-c .$$

这个变换把"横平竖直"的格子转成了斜的网格。直觉上，曼哈顿距离 $|a|+|b|$ 在旋转后应该变成"切比雪夫距离" $\max(|a+b|,|a-b|)$。随手验证：$a=3,b=1$ 时 $|a|+|b|=4$，而 $\max(4,2)=4$；$a=3,b=-1$ 时也是 $4$ 与 $\max(2,4)=4$；$a=2,b=-2$ 时 $|a|+|b|=4$，$\max(0,4)=4$。全都吻合。下面的引理 2 会给出严格证明。

既然

$$|x-r|+|y-c|\le K \iff |u-u_0|\le K\ \text{且}\ |v-v_0|\le K,$$

菱形就变成了 $(u,v)$ 坐标系里一个**边长为 $2K$ 的轴平行正方形**！这正是我想要的"摆正"。

接下来落地：

1. 开一个 $(2N-1)\times(2N-1)$ 的矩阵 $S$，把每个格子的草量放到 $S[r+c][r-c+N-1]$（$v$ 可能为负，整体平移 $N-1$）。
2. 对 $S$ 做二维前缀和。
3. 枚举每个中心 $(r,c)$，算出对应的 $(u_0,v_0)$，查询正方形 $[u_0-K,u_0+K]\times[v_0-K,v_0+K]$ 的和（越界部分裁掉），取最大值。

这里有一个必须想清楚的问题：**旋转后的矩阵里大部分位置是空的（只有一半的奇偶性格子有值），正方形查询会不会把不该算的格子算进来？** 不会。因为 $u+v=2r$ 恒为偶数，每个格子的像都落在"偶奇偶性"的位置上；反过来说，一个 $(u,v)$ 若 $u+v$ 为奇数，它根本不可能是任何格子的像，我们在那里放的就是 $0$，加进来等于没加。而正方形里的每个偶奇偶性位置都唯一对应一个格子（$r=(u+v)/2,\ c=(u-v)/2$），所以正方形恰好框住了菱形里的全部格子，一个不多一个不少。这一点在引理 5 里严格说明。

还有两个边界细节：

- **裁剪**：正方形可能超出旋转矩阵的范围。超出的部分不可能包含任何格子的像（因为所有格子的 $u,v$ 都在 $[0,2N-2]$ 内），所以直接裁到 $[0,2N-2]$ 不丢信息。
- **$K$ 很大**：$K\ge 2N-2$ 时整个棋盘都在菱形内，旋转法的裁剪会自动让正方形覆盖全矩阵，答案就是总和，无需特判。$K=0$ 时正方形退化成单点，答案就是最大单格，也无需特判。

最后用题面 Hint 自检：Hint 里星号格子是第 $3$ 行第 $3$ 列为中心的菱形（半径 $2$），把星号格子的数加起来是 $342$，与题面给的答案一致，说明"菱形内全部格子求和"这个理解是对的。我的程序读入这组数据也输出 $342$（见第五节验证状态）。

## 二、思维链：完整证明

**引理 1（可达区域 = 曼哈顿球）**：从 $(r,c)$ 出发，用不超过 $K$ 步能到达的格子集合恰为 $\{(x,y): |x-r|+|y-c|\le K\}$。

*证明*：记 $d(x,y)=|x-r|+|y-c|$。
（下界）每走一步只改变一个坐标 $1$，故 $d$ 每次最多减少 $1$。走 $t$ 步后到达的点满足 $d\ge d_0-t$，其中 $d_0=d(r,c)=0$，即 $d\ge -t$；更准确地说，从起点 $d=0$ 出发走 $t$ 步，终点 $d\le t$（三角不等式 $d(\text{终点})\le d(\text{起点})+t$）。所以 $t$ 步内到达的格子必满足 $d\le t\le K$。
（上界）若 $d(x,y)\le K$，先沿行方向走 $|x-r|$ 步、再沿列方向走 $|y-c|$ 步，共 $d\le K$ 步到达，途中不越界（因为终点在棋盘内且路径是单调的，行、列坐标都在两端之间）。故该格子可达。
两方向合起来，可达集合恰为 $d\le K$。又题面 Hint 把该集合内的格子全部标星并以其权值和为答案，故"能吃到"的正是这些格子。证毕。

**引理 2（旋转恒等式）**：对任意整数 $a,b$，有 $\max(|a+b|,|a-b|)=|a|+|b|$。

*证明*：两边都非负，故可比较平方。
$$|a+b|^2=a^2+2ab+b^2,\qquad |a-b|^2=a^2-2ab+b^2,$$
于是
$$\max(|a+b|^2,|a-b|^2)=a^2+b^2+2|ab|=(|a|+|b|)^2 .$$
这里用到 $\max(2ab,-2ab)=2|ab|$。对非负数开平方即得 $\max(|a+b|,|a-b|)=|a|+|b|$。证毕。

**引理 3（菱形 ↔ 正方形）**：令 $u=x+y,\ v=x-y$，$u_0=r+c,\ v_0=r-c$。则
$$|x-r|+|y-c|\le K \iff |u-u_0|\le K\ \text{且}\ |v-v_0|\le K .$$

*证明*：取 $a=x-r,\ b=y-c$，则 $u-u_0=a+b,\ v-v_0=a-b$。由引理 2，
$$\max(|u-u_0|,|v-v_0|)=|a|+|b|=|x-r|+|y-c| .$$
所以"两者都 $\le K$"（即 $\max\le K$）与"$|x-r|+|y-c|\le K$"等价。证毕。

**引理 4（旋转映射是单射，且像的奇偶性固定）**：映射 $\varphi(r,c)=(r+c,\ r-c)$ 在格子集合上是单射；并且对任何格子，$u+v=2r$ 为偶数。反之，若 $(u,v)$ 满足 $u+v$ 为偶数且 $0\le u+v\le 2N-2$、$0\le u-v\le 2N-2$，则它恰是唯一格子 $\big((u+v)/2,(u-v)/2\big)$ 的像。

*证明*：若 $\varphi(r,c)=\varphi(r',c')$，则两式相加得 $2r=2r'$，两式相减得 $2c=2c'$，故 $r=r',c=c'$，单射成立。$u+v=(r+c)+(r-c)=2r$ 为偶数。反解公式由 $u=r+c,\ v=r-c$ 直接解出 $r=(u+v)/2,\ c=(u-v)/2$；当 $u+v$ 为偶数时 $r,c$ 为整数，再由 $0\le u+v,u-v\le 2N-2$ 得 $0\le r,c\le N-1$，即合法格子，且由单射性唯一。证毕。

**引理 5（旋转矩阵上的窗口和 = 菱形权和）**：记旋转矩阵 $S$ 满足：若 $(u,v)=\varphi(r,c)$ 且 $r,c\in[0,N-1]$，则 $S[u][v+N-1]=G(r,c)$；其余位置为 $0$。则对任意中心 $(r,c)$ 与其像 $(u_0,v_0)$，
$$\sum_{\substack{u,v\\ |u-u_0|\le K,\ |v-v_0|\le K}} S[u][v+N-1]=\sum_{\substack{x,y\\ |x-r|+|y-c|\le K}} G(x,y).$$

*证明*：把左边窗口内（且索引合法）的位置分成两类。
第一类：存在格子 $(x,y)$ 使 $\varphi(x,y)=(u,v)$。由引理 4，这样的格子存在当且仅当 $u+v$ 为偶数（且反解落在棋盘内），并且唯一；此时 $S$ 在该位置的值恰为 $G(x,y)$。
第二类：不存在这样的格子，则 $S$ 在该位置为 $0$（构造如此），对求和无贡献。
于是左边等于"像落在窗口内的所有格子的 $G$ 之和"。由引理 3，格子的像落在窗口内 $\iff$ 该格子满足 $|x-r|+|y-c|\le K$。故左边等于菱形权和。证毕。

**引理 6（裁剪的安全性）**：把窗口 $[u_0-K,u_0+K]\times[v_0-K,v_0+K]$ 裁剪到索引范围 $[0,2N-2]\times[0,2N-2]$ 后再求和，结果不变。

*证明*：任何格子的像都满足 $u=r+c\in[0,2N-2]$、$v=r-c\in[-(N-1),N-1]$，即其（平移后的）索引必在 $[0,2N-2]$ 内。所以被裁掉的窗口位置没有第一类位置（它们不可能是任何格子的像），只可能是第二类位置（值为 $0$）。由引理 5 的论证，去掉这些位置不改变和。证毕。

**引理 7（二维前缀和查询正确）**：设 $P[i][j]$ 为 $S$ 在矩形 $[1,i]\times[1,j]$（$1$-based）内的元素和。则矩形 $[u_1,u_2]\times[v_1,v_2]$ 的和为
$$P[u_2][v_2]-P[u_1-1][v_2]-P[u_2][v_1-1]+P[u_1-1][v_1-1].$$

*证明*：把前缀和矩形拆成三个互不相交的部分：$[1,u_1-1]\times[1,v_2]$、$[u_1,u_2]\times[1,v_1-1]$、$[u_1,u_2]\times[v_1,v_2]$，三者并为 $[1,u_2]\times[1,v_2]$。于是
$$P[u_2][v_2]=P[u_1-1][v_2]+\big(P[u_2][v_1-1]-P[u_1-1][v_1-1]\big)+\text{目标矩形和},$$
移项即得公式。证毕。

**引理 8（枚举所有中心即得最优）**：设 $F(r,c)$ 为以 $(r,c)$ 为居住点的青草总量，则答案为 $\max_{r,c}F(r,c)$。

*证明*：居住点必是某个格子（题面"在她的地盘内找到一点"指矩阵中的格子，Hint 的最优解也是格子 $(3,3)$）。对每个可能的居住点，引理 1 给出可达格子集合，引理 5 说明程序算出的正是该集合的权和，故程序对每个居住点都算出了精确的 $F(r,c)$，取最大值即为答案。证毕。

**定理**：算法输出的值等于题目所求的最大青草量。

*证明*：由引理 5、6、7，程序对每个中心计算的值等于 $F(r,c)$（引理 8 的记号）；由引理 8，取最大即答案。证毕。

**引理 9（复杂度）**：时间 $O(N^2)$，空间 $O(N^2)$。

*证明*：旋转矩阵边长为 $2N-1$，建表 $O(N^2)$，前缀和 $O((2N-1)^2)=O(N^2)$，枚举 $N^2$ 个中心、每个 $O(1)$ 查询，合计 $O(N^2)$。空间为两个 $O(N^2)$ 的矩阵（原地做前缀和只需一个），即 $O(N^2)$。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 无阻碍网格里"$K$ 步内可达"就是曼哈顿距离 $\le K$，可达区域是菱形；Hint 的星号图确认了求和口径。
- consider easier version — 枚举中心 + 枚举行，用行前缀和把单中心从 $O(N^2)$ 降到 $O(N)$，整体 $O(N^3)$ 已经可过。
- explore its property — 旋转 $45^\circ$ 后曼哈顿距离变成切比雪夫距离 $\max(|u-u_0|,|v-v_0|)$，菱形变轴平行正方形。
- reduce to easier problem — 菱形区域求和 ⇒ 旋转坐标系下的矩形区域求和。
- classic problem solution — 二维前缀和做到 $O(1)$ 矩形查询，总复杂度 $O(N^2)$。
- discuss by category — 窗口越界裁剪、奇偶性空格为 $0$、$K=0$ 与 $K\ge 2N-2$ 的极端情形，统一由同一套下标与裁剪处理，无需特判。
- sanity check by hint — 用 Hint 的星号菱形（$K=2$）手算 $342$，反推并确认模型。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 棋盘边长 | 输入 |
| $k$ | 最多步数（曼哈顿半径） | 输入 |
| $G(r,c)$ | 格子 $(r,c)$ 的青草量，$0$-based | 读入后立即放入旋转矩阵，不单独存 |
| $S[i][j]$ | 旋转矩阵，$1$-based；$S[r+c+1][r-c+n]=G(r,c)$ | 全 $0$，随后原地变前缀和 |
| $mx$ | 旋转矩阵有效边长 $=2n-1$ | $u,v$ 的取值个数 |
| $u,v$ | 旋转坐标（$1$-based 下标）：$u=r+c+1$，$v=r-c+n$ | 中心与窗口都用它 |
| $u_1,u_2,v_1,v_2$ | 裁剪后的窗口边界 | $u_1=\max(1,u-k)$ 等 |
| `rect(u1,v1,u2,v2)` | 二维前缀和的矩形查询 | 返回 $[u_1,u_2]\times[v_1,v_2]$ 的和 |
| $ans$ | 最大青草量 | 初值 $0$（草量非负） |

### 算法步骤

1. I/O 加速三连。
2. 读入 $n,k$；对每个格子读入 $g$，执行 `S[r+c+1][r-c+n]=g`（把格子搬到旋转坐标系）。
3. 令 `mx=2*n-1`，对 $S$ 做原地二维前缀和：`S[i][j]+=S[i-1][j]+S[i][j-1]-S[i-1][j-1]`（$1\le i,j\le mx$）。
4. 枚举中心 $(r,c)$（$0$-based）：
   1. 算 $u=r+c+1,\ v=r-c+n$；
   2. 窗口裁剪：$u_1=\max(1,u-k),\ u_2=\min(mx,u+k)$，$v_1=\max(1,v-k),\ v_2=\min(mx,v+k)$；
   3. `ans=max(ans,rect(u1,v1,u2,v2))`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(n^2)$（建表 $O(n^2)$ + 前缀和 $O(n^2)$ + $n^2$ 次 $O(1)$ 查询）。
- 空间：$O(n^2)$，旋转矩阵 $(2n-1)^2\le 799^2\approx 6.4\times 10^5$ 个 `long long`，约 $5$ MB。

### 一句话验证状态

Hint 数据（$K=2$，最优中心 $(3,3)$）输出 $342$；与 $O(n^4)$ 暴力在 $500$ 组随机小数据上完全一致；$n=400,K=800$ 的最大规模实测约 $0.05$ 秒。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2213 [USACO14MAR] The Lazy Cow S
// 曼哈顿菱形旋转 45 度变成轴平行正方形，再用二维前缀和 O(1) 查询
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{405},mxx{810};

int n,k;
i64 s[mxx][mxx];

// 1-based 的矩形和，闭区间 [u1,u2] x [v1,v2]
i64 rect(int u1,int v1,int u2,int v2)
{
	return s[u2][v2]-s[u1-1][v2]-s[u2][v1-1]+s[u1-1][v1-1];
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int r=0,g;r<n;++r)
		for(int c=0;c<n;++c)
		{
			cin>>g;
			s[r+c+1][r-c+n]=g;   // (r,c) -> (u,v)=(r+c,r-c)，下标各 +1 / +n
		}
	int mx=2*n-1;
	for(int i=1;i<=mx;++i)
		for(int j=1;j<=mx;++j)
			s[i][j]+=s[i-1][j]+s[i][j-1]-s[i-1][j-1];
	i64 ans=0;
	for(int r=0;r<n;++r)
		for(int c=0;c<n;++c)
		{
			int u=r+c+1,v=r-c+n;
			int u1=max(1,u-k),u2=min(mx,u+k);
			int v1=max(1,v-k),v2=min(mx,v+k);
			ans=max(ans,rect(u1,v1,u2,v2));
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 关键在下标换算：$u=r+c$、$v=r-c$ 的原始范围是 $[0,2n-2]$ 与 $[-(n-1),n-1]$。数组下标统一 $+1$ 后，$u$ 侧写作 `r+c+1`，$v$ 侧写作 `r-c+n`，两者都落在 $[1,2n-1]$。
- 旋转矩阵里只有 $u+v$ 为偶数的位置有值，其余为 $0$；正方形查询把这些 $0$ 一起加进来不影响答案（引理 5）。
- 窗口裁剪用 `max(1,·)` 与 `min(mx,·)`，天然兼容 $k=0$ 和 $k\ge 2n-2$，不需要任何特判。
- `s` 用 `i64`：虽然最大总和只有 $400^2\times 1000=1.6\times 10^8$，但前缀和与乘法习惯上留 64 位余量，避免手误。
- 数组尺寸 `mxx{810}` 对应 $2\times 400-1=799$ 的边长，留了松弛。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 无错误、无警告。
- Hint 给出的 $5\times 5$、$K=2$ 数据（最优解在 $(3,3)$，答案 $342$）程序输出 $342$，与题面一致。
- 对拍：$O(n^4)$ 暴力（枚举中心 + 枚举全部格子判曼哈顿距离）与本代码在 $n\le 8$、随机 $K\in[0,2n]$、随机权值的 $500$ 组数据上输出完全一致。
