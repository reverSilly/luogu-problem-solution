# P2427 Wave — 题解

## 一、解题过程：人类思考叙事

题目：$N\times M$ 的格子矩阵，每格一个小写字母表示介质，**不同字母介质不同、波速不同**。$Q$ 次询问，每次给波源 $(X,Y)$（行、列均 0-based），问波能以**不变的波速**延伸到的、**以波源为中心**的最大轴平行正方形的**边长**。$N,M\le1000$，$Q\le10^4$。

**先把物理语言翻译成格子语言。** "波速不变"意味着波经过的介质必须一样——不同字母波速不同，一旦跨介质波速就变了。所以这个正方形里的**每一格都必须和波源同字母**。又因为正方形"以波源为中心"、边平行坐标轴，中心是一个格子，故边长必为**奇数** $2k+1$，覆盖行 $[X-k,X+k]$、列 $[Y-k,Y+k]$。于是每次询问变成：

> 求最大的 $k$，使正方形 $[X-k,X+k]\times[Y-k,Y+k]$ 不越界、且其中所有格子都等于 $c=\text{grid}[X][Y]$。答案 $2k+1$。

**朴素做法：从 $k=0$ 往外扩，逐格检查。** 每次检查 $O(k^2)$，最坏扩到 $R\approx500$，单询问 $O(R^2)$，$Q=10^4$ 时约 $10^{10}$，超时。

**发现单调性 → 二分。** 若半径 $k$ 的正方形全是 $c$，则更小的正方形（它的子集）也全是 $c$；若半径 $k$ 里混进了别的字母，则更大的正方形（含它）也必然混进。所以"可行"关于 $k$ 是**前缀单调**的：存在阈值 $K$，$k\le K$ 可行、$k>K$ 不可行。可以**二分**最大的可行 $k$。但二分要求每次判定 $O(1)$ 或很快——"整个正方形是否全为 $c$"怎么快速判？

**经典工具：二维前缀和。** 对字母 $c$ 建前缀和 $s[i][j]=$ 左上角矩形里 $c$ 的个数，则任意子矩形里 $c$ 的个数可 $O(1)$ 容斥求出。正方形全为 $c$ $\iff$ 其中 $c$ 的个数 $=$ 面积 $(2k+1)^2$。于是每次判定 $O(1)$，单询问 $O(\log\min(N,M))$。

**一个内存坑。** 最直接的写法是给 26 个字母各建一张 $1001\times1001$ 的 `int` 前缀表，约 $26\times10^6\times4\approx105$ MB，可能撞内存上限。换个角度：**询问可以按波源字母离线分组**。对每个出现过的字母 $c$，只建**一张**前缀表（复用同一块内存），回答所有源字母为 $c$ 的询问，再换下一个字母。这样内存降到 $O(NM)$（一张表 + 网格），时间 $O(26\cdot NM + Q\log)$，完全可接受。

**边界。** $k$ 的上界是 $\text{lim}=\min(X,\,Y,\,N-1-X,\,M-1-Y)$（保证正方形不越界）；$k=0$ 永远可行（波源自己那一格就是 $c$），所以答案至少为 1。二分在 $[0,\text{lim}]$ 上找最大可行 $k$，输出 $2k+1$。

## 二、思维链：完整证明

**引理 1（波速不变 $\iff$ 正方形全为源字母）**：波能以不变波速充满以 $(X,Y)$ 为中心的正方形，当且仅当正方形内每格字母都等于 $c=\text{grid}[X][Y]$。

*证明*：题设"不同字母表示不同介质，不同介质波速不同"，故每种字母对应一个确定的波速，且字母不同则波速不同。波从源出发，源格字母为 $c$，波速即 $c$ 的波速。若正方形内存在字母 $\ne c$ 的格，波传到该格时介质改变、波速改变，与"不变波速"矛盾。反之，若全为 $c$，则整块介质均匀，波速恒为 $c$ 的波速，可以不变波速延伸。故条件恰为"全格 $=c$"。证毕。

**引理 2（中心正方形的形状）**：以格子 $(X,Y)$ 为中心、边平行坐标轴、由整格构成的正方形，边长必为奇数 $2k+1$（$k\ge0$），覆盖行 $[X-k,X+k]$、列 $[Y-k,Y+k]$。

*证明*：中心是单个格子 $(X,Y)$，正方形关于该格中心对称，故向上下左右各延伸相同的整数格数 $k$，行、列跨度均为 $2k+1$。边长即 $2k+1$。证毕。

**引理 3（越界阈值）**：正方形 $[X-k,X+k]\times[Y-k,Y+k]$ 完全落在 $[0,N-1]\times[0,M-1]$ 内，当且仅当 $k\le\text{lim}:=\min(X,Y,N-1-X,M-1-Y)$。

*证明*：行不越界 $\iff X-k\ge0$ 且 $X+k\le N-1\iff k\le X$ 且 $k\le N-1-X$。列同理 $\iff k\le Y$ 且 $k\le M-1-Y$。四者同时成立 $\iff k\le\min(X,Y,N-1-X,M-1-Y)=\text{lim}$。证毕。

**引理 4（前缀和判定）**：设 $s[i][j]$ 为字母 $c$ 在行 $[0,i-1]$、列 $[0,j-1]$ 矩形中的个数，则正方形 $[r_1,r_2]\times[c_1,c_2]$ 中 $c$ 的个数为
$$\text{cnt}=s[r_2+1][c_2+1]-s[r_1][c_2+1]-s[r_2+1][c_1]+s[r_1][c_1],$$
且"正方形全为 $c$" $\iff\text{cnt}=(r_2-r_1+1)(c_2-c_1+1)$。

*证明*：第一式是二维前缀和的标准容斥：大矩形 $[0,r_2]\times[0,c_2]$ 减去上方 $[0,r_1-1]\times[0,c_2]$ 与左方 $[0,r_2]\times[0,c_1-1]$，再加回被减两次的左上角 $[0,r_1-1]\times[0,c_1-1]$，恰得目标矩形计数。第二式：矩形共 $\text{area}$ 格，每格要么是 $c$ 要么不是，故 $\text{cnt}\le\text{area}$，等号成立当且仅当每格都是 $c$。证毕。

**引理 5（可行性单调）**：固定询问 $(X,Y)$ 与 $c$，定义 $\text{ok}(k)=$"半径 $k$ 正方形不越界且全为 $c$"。则 $\text{ok}$ 关于 $k$ 单调不增：$\text{ok}(k)\Rightarrow\text{ok}(k-1)$（$k\ge1$）。

*证明*：不越界部分由引理 3，$k\le\text{lim}\Rightarrow k-1\le\text{lim}$。全为 $c$ 部分：半径 $k-1$ 的正方形是半径 $k$ 正方形的子集，后者全为 $c$ 则前者也全为 $c$。两部分都保持，故 $\text{ok}(k)\Rightarrow\text{ok}(k-1)$。证毕。

**引理 6（二分正确）**：$\text{ok}(0)$ 恒真，且由引理 5 可行集是前缀 $\{0,1,\dots,K\}$（$K\le\text{lim}$）。在 $[0,\text{lim}]$ 上二分"最大可行 $k$"得到的 $K$ 即最优半径，答案 $2K+1$。

*证明*：$\text{ok}(0)$：半径 0 正方形只含源格 $(X,Y)$，其字母为 $c$，且 $0\le\text{lim}$（源在界内），故真。由引理 5，若 $\text{ok}(k)$ 假则对所有 $k'>k$ 也假（逆否），故可行集形如 $[0,K]$。二分维护"lo 可行、hi+1 不可行"的不变量：取 $mid=\lceil(lo+hi)/2\rceil$，若 $\text{ok}(mid)$ 则 $lo=mid$（可行域右扩），否则 $hi=mid-1$。终止 $lo=hi=K$。由引理 1、2，最大全 $c$ 中心正方形边长 $2K+1$。证毕。

**引理 7（复杂度）**：时间 $O(26\cdot NM + Q\log\min(N,M))$，空间 $O(NM+Q)$。

*证明*：至多 26 个字母各建一次前缀表，每次 $O(NM)$，共 $O(26NM)$；每询问二分 $O(\log\text{lim})=O(\log\min(N,M))$ 次、每次判定 $O(1)$，共 $O(Q\log\min(N,M))$。空间为网格 $O(NM)$、单张前缀表 $O(NM)$、询问与答案 $O(Q)$。证毕。

**定理**：算法对每个询问输出正确的最大边长。

*证明*：由引理 1 把物理条件化为"全格 $=c$"；由引理 2、3 确定正方形形状与半径上界；由引理 4 前缀和 $O(1)$ 判定；由引理 5、6 二分求得最大可行半径 $K$，输出 $2K+1$ 即最大边长。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "波速不变" $\iff$ 正方形全为源字母；中心在格子上 $\Rightarrow$ 边长为奇数 $2k+1$。
2. **consider easier version** — 单询问 = 最大全 $c$ 中心正方形；可行性关于半径单调 $\Rightarrow$ 可二分。
3. **classic problem solution** — 二维前缀和：$O(1)$ 判"正方形是否全为 $c$"（计数 $=$ 面积）。
4. **explore its property** — 26 张前缀表 $\approx105$ MB 太大 $\Rightarrow$ 按源字母离线分组、复用一张表，内存降到 $O(NM)$。
5. **classic problem solution** — 在 $[0,\text{lim}]$ 上二分最大可行半径，答案 $2k+1$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|----------------|
| $n,m,q$ | 行数、列数、询问数 | `int` | 输入 |
| `g[i][j]` | 格子 $(i,j)$ 的介质字母 | `char[][]` | 输入，0-based |
| `s[i][j]` | 当前字母在 $[0,i-1]\times[0,j-1]$ 的个数 | `int[][]` | 每个字母 `memset` 清零后递推 |
| `qs[c]` | 源字母为 `c` 的询问列表 `{x,y,id}` | `vector<query>[]` | 读入时按 `g[x][y]` 分组 |
| `ans[id]` | 第 `id` 个询问的答案边长 | `int[]` | $2k+1$ |
| `ok(x,y,k)` | 半径 $k$ 正方形是否全为当前字母 | 函数 | 前缀和容斥计数 $=(2k+1)^2$ |
| `lim` | 半径上界 $\min(x,y,n-1-x,m-1-y)$ | `int` | 保证不越界 |

### 算法步骤

1. I/O 加速；读 $n,m,q$ 与网格 `g`。
2. 读 $q$ 个询问 $(x,y)$，按 `g[x][y]-'a'` 压入 `qs[c]`，记下原序号 `id`。
3. 对每个有询问的字母 $c$：`memset(s,0,...)`，递推 $s[i][j]=s[i-1][j]+s[i][j-1]-s[i-1][j-1]+[g[i-1][j-1]=c]$。
4. 对该组每个询问：`lim=min(x,y,n-1-x,m-1-y)`；在 $[0,\text{lim}]$ 二分最大 $k$ 使 `ok(x,y,k)`；`ans[id]=2k+1`。
5. 按原序号输出 `ans[0..q-1]`。

### 复杂度

- 时间 $O(26\cdot NM + Q\log\min(N,M))$；空间 $O(NM+Q)$（单张前缀表复用）。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过。
- 题面无样例，手造 4 组：① $5\times5$ 全 `a`，询问 `(2,2),(1,1),(0,0)` → `5,3,1`；② $3\times3$ 中心 `b` 其余 `a`，询问 `(1,1)` → `1`；③ $1\times1$ → `1`；④ 全 `a` 边界受限 `(0,2),(1,2)` → `1,3`。均与手算一致。
- 对拍：暴力（对每询问从 $k=0$ 逐半径扩、逐格检查全 $c$，独立于前缀和 + 二分）与标程在 **300 组**随机数据（$N,M\le8$、字母表 $\{a,b,c\}$、随机询问）上比对，全部一致。
- 极限规模：$N=M=1000,\ Q=10^4$ 全 `a` 网格，运行约 $0.07$ s，内存约 $5$ MB。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2427 Wave
// 思路：波速不变 ⇔ 正方形全为源字母；中心正方形边长 2k+1
//       可行性关于半径单调 ⇒ 二分；二维前缀和 O(1) 判"全为 c"
//       按源字母离线分组、复用一张前缀表，避免 26 张表爆内存
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},mxq{10005};

int n,m,q;
char g[mxn][mxn];
int s[mxn][mxn];
int ans[mxq];
struct query{int x,y,id;};
vector<query>qs[26];

// is the whole square [x-k,x+k]x[y-k,y+k] made of letter c ?
bool ok(int x,int y,int k)
{
	int r1=x-k,r2=x+k,c1=y-k,c2=y+k;
	int cnt=s[r2+1][c2+1]-s[r1][c2+1]-s[r2+1][c1]+s[r1][c1];
	int side=2*k+1;
	return cnt==side*side;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>q;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			cin>>g[i][j];
	for(int i=0,x,y;i<q;++i)
	{
		cin>>x>>y;
		qs[g[x][y]-'a'].push_back({x,y,i});
	}
	// answer queries grouped by source letter; one prefix table reused per letter
	for(int c=0;c<26;++c)
	{
		if(qs[c].empty())continue;
		memset(s,0,sizeof(s));
		for(int i=1;i<=n;++i)
			for(int j=1;j<=m;++j)
				s[i][j]=s[i-1][j]+s[i][j-1]-s[i-1][j-1]+(g[i-1][j-1]-'a'==c);
		for(auto[x,y,id]:qs[c])
		{
			int lim=min({x,y,n-1-x,m-1-y});
			int lo=0,hi=lim;
			while(lo<hi)
			{
				int mid=(lo+hi+1)>>1;
				if(ok(x,y,mid))lo=mid;
				else hi=mid-1;
			}
			ans[id]=2*lo+1;
		}
	}
	for(int i=0;i<q;++i)cout<<ans[i]<<'\n';
	return 0;
}
```

### 代码说明

- **离线分组**是内存关键：`qs[c]` 按源字母收集询问，外层对每个字母只建一张前缀表 `s`（`memset` 复用），回答完该组再换下一个字母。这样任意时刻只有一张 $1001\times1001$ 的 `int` 表（约 4 MB）加网格，而非 26 张。
- `ok` 用二维前缀和容斥求正方形内 $c$ 的个数，与面积 $(2k+1)^2$ 比较；相等即全为 $c$（引理 4）。
- 二分用"偏上界"写法 `mid=(lo+hi+1)>>1`，求**最大**可行半径；`ok(0)` 恒真保证 `lo` 有下界。
- `lim=min({x,y,n-1-x,m-1-y})` 同时约束四个方向不越界（引理 3）。
- 下标 0-based（行列均 $0..N-1$），与题面一致；前缀表 `s` 用 1-based 递推（`s[i][j]` 对应网格 `[0,i-1]×[0,j-1]`），容斥时 `r2+1` 等不越界（$r_2\le N-1$）。
- 答案 `ans[id]=2*lo+1`，按原序号输出，换行 `'\n'`。
