# P2035 [USACO08JAN] iCow B — 题解

## 一、解题过程：人类思考叙事

题目描述的是一个"贪心 + 分摊"的模拟过程，规则四条：

1. 每首曲子有权值 $R_i$；
2. 下一首播放的是**权值最大**的曲子，权值相同时选**编号最小**的；
3. 播放完后，这首曲子的权值被**平均分给其他 $N-1$ 首**，它自己清零；
4. 若不能整除，余数按曲目 $1,2,3,\dots$ 的顺序（跳过刚播过的那首）依次多给 $1$。

$T\le 1000$，$N\le 1000$，所以 $N\cdot T \le 10^6$ 次基本操作，**直接模拟**毫无压力。真正需要小心的是细节。

先把每一步拆开：

**第一步：选谁播。** 遍历所有曲子，找权值最大的；如果有多个，取编号最小的。实现上写成 `if(r[i]>r[best]) best=i;`——注意这里用的是严格大于 `>`，那么遍历时**编号小的先出现且不会被替换**，自动实现了"并列取最小编号"。这是一个很容易写错的地方：如果写成 `>=`，并列时会取到编号最大的。

**第二步：怎么分。** 权值 $w$ 分给 $N-1$ 首，每首先得 $q=\lfloor w/(N-1)\rfloor$，余数 $r'=w\bmod (N-1)$ 依次多给 $1$。余数的分配顺序是"曲目 1、2、3……依次下去，跳过刚播过的那首"。所以实现是：从编号 1 开始遍历，遇到 `best` 就跳过（它已经清零了），其余每首先加 $q$，再从前 $N-1$ 首中的前 $r'$ 首额外加 $1$。

这里有个细节要抠：**余数是分给"排在最前面的"曲子**。也就是说，第一个该拿余数的曲子是编号最小的那首（如果它不是刚播过的那首）。我的实现里 `rem` 是一个计数器，遇到一个该分的曲子就 `rem--`，所以前 `rem` 首（按编号升序、跳过 best）各多得 1。这正好符合题意。

**第三步：清零。** 刚播过的那首曲子的权值设为 $0$。注意顺序：应该先把 $w$ 存下来，再清零，否则分出去的量就错了。

还有个边界情况值得注意：**$N=1$** 时"分给其他 $N-1$ 首"就是除以 $0$。数据范围写的是 $1\le N\le 1000$，所以 $N=1$ 是合法输入。此时只有一首曲子，播完权值清零，没有别人可分，下一轮仍然只能播它（权值 0，编号 1）。我的代码里对 $N=1$ 单独处理，避免除零。

样例：$N=3,T=4,R=[10,8,11]$。
- 权值最大的是 #3（11）。$11/2=5$ 余 $1$。#1 得 $5+1=6$（余数给它，因为编号最小），#2 得 $5$。得 $[16,13,0]$。
- 权值最大的是 #1（16）。$16/2=8$ 余 $0$。#2 得 $13+8=21$，#3 得 $0+8=8$。得 $[0,21,8]$。
- 权值最大的是 #2（21）。$21/2=10$ 余 $1$。跳过 #2，#1 得 $10+1=11$，#3 得 $8+10=18$。得 $[11,0,18]$。
- 权值最大的是 #3（18）。

输出 `3 1 2 3`，与样例一致。题面 Hint 里给的权值变化序列 `[10,8,11] → [16,13,0] → [0,21,8] → [11,0,18]` 也完全对上，说明我对余数分配顺序的理解是对的。

## 二、思维链：完整证明

**引理 1**（选曲规则）：每次播放的都是当前权值最大的曲子；若多首并列，取其中编号最小的。

*证明*：算法维护 `best=1`，随后按 $i=2,3,\dots,N$ 顺序扫描，仅当 $r[i]>r[\text{best}]$ 时更新 `best`。

扫描结束后，对任意 $i\ne \text{best}$ 都有 $r[i]\le r[\text{best}]$，故 `best` 的权值是全局最大的。而由于更新条件是严格大于，一个编号更小且权值相等的曲子**不会**替换掉 `best`（第一次遇到最大权值时就已确定，之后只有严格更大的才能替换）；因此在所有权值最大的曲子中，`best` 的编号最小。证毕。

**引理 2**（分配的正确性）：设本轮被播曲子的权值为 $w$，$N>1$，则算法结束后每首曲子 $i\ne \text{best}$ 的权值增量为 $q=\lfloor w/(N-1)\rfloor$ 加上（当且仅当它在"按编号升序、跳过 best"的序列中排在前 $r'=w\bmod(N-1)$ 位时）$1$。

*证明*：算法先令 $q=w/(N-1)$、$rem=w\bmod(N-1)$，再以 $i=1,2,\dots,N$ 的升序遍历，对每个 $i\ne\text{best}$ 先执行 $r[i] \mathrel{+}= q$，然后当 $rem>0$ 时执行 $r[i]\mathrel{+}=1$ 且 $rem--$。

遍历顺序恰为"编号升序且跳过 best"，因此额外加 $1$ 的正是该序列的前 $r'$ 首，其余曲子只加 $q$。又由带余除法的定义，$w=(N-1)q+r'$，即分出去的总权值为 $(N-1)q+r'=w$，与被播曲子的原权值相等，符合"平均分给其他 $N-1$ 首"。证毕。

**引理 3**（权值守恒与清零）：每轮结束后，被播曲子的权值为 $0$，其余曲子的权值之和增加了原权值 $w$。

*证明*：算法在分配前先执行 $r[\text{best}]=0$（清零），再执行引理 2 的分配（把 $w$ 分出去）。注意 $w$ 是在清零之前保存到局部变量中的，因此分出去的确是原权值 $w$ 而非 $0$。总权值守恒。证毕。

**引理 4**（模拟的归纳正确性）：算法输出的第 $k$ 首曲子，正是按 FJ 算法第 $k$ 次应播放的曲子。

*证明*：对 $k$ 归纳。

$k=1$：初始权值即输入的 $R_i$，由引理 1，算法选出的曲子正是权值最大、编号最小的那首，与规则一致。

归纳步：假设前 $k-1$ 轮结束后，算法维护的权值数组与 FJ 算法的真实权值数组逐项相同。第 $k$ 轮中，由引理 1，算法选出的曲子与 FJ 规则选出的一致；由引理 2、3，分配与清零的结果也与规则完全一致，因此第 $k$ 轮结束后两个权值数组仍逐项相同。

由归纳法，算法每一轮输出的曲子编号都正确。证毕。

**定理**：算法输出的前 $T$ 个编号即为所求。

*证明*：直接由引理 4，算法恰好模拟了 $T$ 轮并输出了每轮所选的曲子编号。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别题型** — 规则明确的机械过程，且 $N\cdot T\le 10^6$，模拟足够。
2. **把规则拆成"选 / 分 / 清零"三步** — 顺序不能乱，先存权值再清零。
3. **并列取最小编号的技巧** — 用严格大于 `>` 而不是 `>=`，靠遍历顺序自然实现。
4. **平均分配的余数顺序** — "编号升序、跳过刚播过的那首"，前 $rem$ 首多得 $1$。
5. **边界情况：$N=1$** — 除以 $N-1$ 会除零，必须特判。
6. **验证方式** — 拿 Hint 给的权值变化序列逐步比对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $N$ | 曲子总数 | `int`，$1\le N\le 1000$ |
| $T$ | 要输出的曲子数量 | `int`，$\le 1000$ |
| $R_i$ | 第 $i$ 首曲子的权值 | `int`，初始 $1\le R_i\le 10^4$ |
| `r[i]` | 当前第 $i$ 首曲子的权值（被逐步修改） | `int[]`，长度 $N$ |
| `best` | 本轮选中播放的曲子编号 | `int` |
| `w` | 本轮被播曲子的原权值（分配前保存） | `int` |
| `q` | 每首曲子分到的基本份额 $\lfloor w/(N-1)\rfloor$ | `int` |
| `rem` | 待分配的余数个数，初始为 $w\bmod(N-1)$ | `int` |

### 算法步骤

1. 读入 $N,T$ 与 $N$ 个初始权值到 `r[1..N]`。
2. 重复 $T$ 轮：
   - **选**：令 `best=1`，扫描 $i=2..N$，若 `r[i] > r[best]` 则 `best=i`。
   - **输出** `best`。
   - **分**：保存 `w = r[best]`，令 `r[best]=0`；若 $N>1$，令 `q=w/(N-1)`、`rem=w%(N-1)`，按 $i=1..N$ 升序遍历，跳过 `best`，每首 `r[i]+=q`，若 `rem>0` 则再 `r[i]++` 且 `rem--`。
3. 结束。

### 复杂度

- 时间复杂度：$O(N\cdot T)$，最多 $10^6$ 轮内操作。
- 空间复杂度：$O(N)$。

### 验证状态

- 标程 `P2035.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面样例 `3 4 / 10 8 11` 输出 `3 1 2 3`，与官方一致；题面 Hint 给出的四组权值变化 `[10,8,11] → [16,13,0] → [0,21,8] → [11,0,18]` 也与模拟逐步吻合。
- 额外构造边界数据验证：$N=1$（`1 3 / 5` 输出 `1 1 1`，不崩溃）、$N=2$ 且权值相等（`2 5 / 4 4` 输出 `1 2 1 2 1`，并列取最小编号正确）。
- 本题规则完全确定、暴力即正解本身（不存在独立的更朴素算法可作对照），故未生成对拍脚本。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2035 [USACO08JAN] iCow B
// 逐轮模拟：选最大权值（并列取最小编号），再把它的权值平均分给其他曲子
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,T;
int r[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>T;
	for(int i=1;i<=n;++i) cin>>r[i];

	for(int step=0;step<T;++step)
	{
		// 选权值最大的曲子，并列时取编号最小的
		int best=1;
		for(int i=2;i<=n;++i)
			if(r[i]>r[best]) best=i;
		cout<<best<<'\n';
		// 把 best 的权值分给其余 N-1 首曲子
		int w=r[best];
		r[best]=0;
		if(n>1)	// N=1 时没有别的曲子可分，避免除以 0
		{
			int q=w/(n-1),rem=w%(n-1);
			for(int i=1;i<=n;++i)
			{
				if(i==best) continue;
				r[i]+=q;
				if(rem>0) { r[i]++; rem--; }	// 余数按编号从小到大依次多给 1
			}
		}
	}
	return 0;
}
```

### 代码说明

- `if(r[i]>r[best])` 用严格大于：并列时保留先遇到的（编号更小的）那个，这是题目要求的"编号最小优先"。
- `int w=r[best];` 必须在 `r[best]=0;` **之前**保存，否则分出去的是 0。
- 余数分配用 `rem` 递减实现"排名靠前的曲子先拿"，遍历顺序 `i=1..n` 且 `continue` 跳过 `best`，恰好等价于题面的"顺序为曲目 1、2……，刚播放过的那首需要被跳过"。
- `n>1` 的特判是为了避免 `w/(n-1)` 在 $N=1$ 时除以 0。
- 权值总和守恒，最大不超过 $N\times 10^4=10^7$，`int` 足够。
