# P2190 小Z的车厢 — 题解

## 一、解题过程：人类思考叙事

题意翻译：环形铁轨上有 $n$ 个站（$1..n$ 顺时针排列）。有 $m$ 条订票记录 $(x,y,z)$：有 $z$ 个人从 $x$ 站**顺时针**坐到 $y$ 站。每节车厢坐 $36$ 人。求最少需要几节车厢。

第一步：把"区间加"转成"求某段的最大载客量"。

一条订票 $(x,y,z)$ 覆盖的是：从 $x$ 出发顺时针走到 $y$ 的这段路上经过的所有"区间"。注意题目说"当火车停靠到 $x$ 站时，所有要在 $x$ 站上车的人都会上车，所有要在 $y$ 站下车的人都会下车"——也就是**在 $y$ 站下车的人不占用 $y$ 站之后的路段**。

第二步：定义"段"。

把环切成 $n$ 段：第 $i$ 段是从站 $i$ 顺时针走到站 $i+1$ 的那一段（$i=n$ 时是 $n\to 1$ 那一段，即跨越 $1\to n$ 的那一段）。

一条订票 $(x,y,z)$：
- 若 $x<y$：经过第 $x,x+1,\dots,y-1$ 段。
- 若 $x>y$（顺时针要绕过 $1$）：经过第 $x,x+1,\dots,n$ 段 **和** 第 $1,2,\dots,y-1$ 段。

注意 $x\ne y$（题面保证），所以不会出现 $x=y$ 的整圈情形。

第三步：差分。

对每一段求"载客量"，本质是 $n$ 个位置上做区间加、然后求最大值。$n,m\le 10^6$，区间加用差分 $O(1)$ 每条，总共 $O(n+m)$。

差分数组 `diff[]`，区间 $[l,r]$ 加 $z$ 就是 `diff[l]+=z; diff[r+1]-=z;`。最后做前缀和就得到每段的载客量，取最大值。

- $x<y$：`diff[x]+=z; diff[y]-=z;`（覆盖段 $x..y-1$）。
- $x>y$：`diff[x]+=z; diff[n+1]-=z;`（覆盖段 $x..n$）以及 `diff[1]+=z; diff[y]-=z;`（覆盖段 $1..y-1$）。

这里有个细节要注意：**跨越 $1\to n$ 的那一段**是第 $n$ 段（从站 $n$ 顺时针到站 $1$）。我把它放在 `diff[n+1]` 处截断，即第 $n$ 段的载客量被正确计入，前缀和扫到 $n$ 时会把它加上；`diff[n+1]` 只是用来终止这一段，不会被扫描到，正确。

第四步：答案。

设最大载客量为 $mx$，需要 $\lceil mx/36\rceil$ 节车厢，即 `(mx+35)/36`（整数除法）。

数据范围：$z\le 100$，$m\le 10^6$，所以总人数最多 $10^8$，前缀和值最大 $10^8$——`int` 放得下 $10^8$（$<2.1\times10^9$），但差分数组我仍然用 `long long`，稳妥。

第五步：验证。

我写一个暴力：直接对每条订票，逐段累加（$O(mn)$），和差分版本对比。

样例自造一个：$n=4$，订票 $(1,3,10),(2,4,20),(3,1,5)$。
- $(1,3,10)$：段 1,2 各 +10。
- $(2,4,20)$：段 2,3 各 +20。
- $(3,1,5)$：$x>y$，段 3,4 各 +5，段 $1..y-1=1..0$ 为空。
- 各段载客：段1 = 10+5 = 15；段2 = 10+20 = 30；段3 = 20+5 = 25；段4 = 5。
- 最大 30，$\lceil 30/36\rceil = 1$。

等等，段 1 应该是 10 + 5 = 15？$(3,1,5)$ 覆盖段 3,4（从站 3 顺时针：3→4 段、4→1 段），到达站 1 下车，所以段 1 不含它。所以段1 = 10。段4 = 5。段2 = 10+20 = 30，段3 = 20+5 = 25。最大 30，答案 1。

我的差分实现：$(3,1,5)$ → `diff[3]+=5; diff[4]-=5; diff[1]+=5; diff[1]-=5;` → `diff[1]+=5-5=0` 抵消了，正确（因为 $y=1$ 时段 $1..y-1$ 为空）。

那 `diff[1]+=z; diff[y]-=z;` 当 $y=1$ 时正好抵消，代码天然正确，不需要特判。

## 二、思维链：完整证明

**记号约定**：站编号 $1..n$ 顺时针排列；**第 $i$ 段**指从站 $i$ 顺时针走到站 $(i\bmod n)+1$ 的那一段路（$i=n$ 时是 $n\to1$）；$\mathrm{load}[i]$ 为第 $i$ 段的载客人数；订票 $(x,y,z)$ 表示 $z$ 人从站 $x$ 上车、顺时针坐到站 $y$ 下车。

**引理 1**（覆盖区间）：订票 $(x,y,z)$ 占用的路段恰为
- $x<y$：段集合 $\{x,x+1,\dots,y-1\}$；
- $x>y$：段集合 $\{x,x+1,\dots,n\}\cup\{1,2,\dots,y-1\}$。

*证明*：由站编号顺时针排列，"从站 $x$ 顺时针到站 $y$"沿途经过的段依次是 $x,x+1,\dots$，直到 $y$ 之前的一段为止（因为乘客在站 $y$ 下车，段 $y$ 及其之后不再有这批乘客）。若 $x<y$，不绕回，段集合为 $\{x,\dots,y-1\}$；若 $x>y$，必须绕过编号 $1$ 继续到 $y$，段集合为 $\{x,\dots,n\}\cup\{1,\dots,y-1\}$。$x=y$ 被题面排除。证毕。

**引理 2**（差分正确性）：算法求出的前缀和 $S[i]=\sum_{t=1}^{i}\mathrm{diff}[t]$ 等于第 $i$ 段的载客人数 $\mathrm{load}[i]$。

*证明*：对单条订票 $(x,y,z)$ 考察它对差分数组的贡献。
- 若 $x<y$：贡献为 `diff[x]+=z, diff[y]-=z`。对任一段 $i$ 计算前缀和：$z$ 被计入当且仅当 $x\le i<y$，即恰是引理 1 中该订票占用的段集合。证毕。
- 若 $x>y$：贡献为 `diff[x]+=z, diff[n+1]-=z, diff[1]+=z, diff[y]-=z`。前缀和在 $i\in[1,y-1]$ 时包含 `diff[1]` 的 $+z$ 而不含 `diff[y]` 的 $-z$，故贡献 $z$；在 $i\in[y,x-1]$ 时贡献为 $z-z=0$（`diff[1]` 的 $+z$ 与 `diff[y]` 的 $-z$ 相消）；在 $i\in[x,n]$ 时贡献为 $z$（`diff[1]`、$\mathrm{diff}[y]$ 抵消，`diff[x]` 生效）；在 $i\ge n+1$ 时贡献为 $z+z-z-z=0$。综合得贡献 $z$ 当且仅当 $i\in\{x,\dots,n\}\cup\{1,\dots,y-1\}$，与引理 1 一致。证毕。

由线性性（差分数组的贡献可相加），所有订票叠加后，算法算出的 $S[i]$ 恰为第 $i$ 段的真实载客人数。证毕。

**引理 3**（最大值与车厢数）：令 $\mathrm{mx}=\max_i \mathrm{load}[i]$。所需车厢数至少为 $\lceil \mathrm{mx}/36\rceil$，且这个下界可以达到。

*证明*：**下界**：第 $i$ 段上同时有 $\mathrm{load}[i]$ 人，每节车厢容量 $36$，故总容量必须 $\ge \mathrm{load}[i]\ge\mathrm{mx}$，即车厢数 $\ge\lceil\mathrm{mx}/36\rceil$。
**可达性**：设共安排 $T=\lceil\mathrm{mx}/36\rceil$ 节车厢，共 $36T\ge\mathrm{mx}$ 个座位。按顺时针顺序逐站处理：在某站上车的乘客任选空座位入座（站点上下车不区分座位，故任意选择都合法）。在第 $i$ 段上，车上的乘客恰是"在站 $1..i$ 上车、在站 $i+1..n$（含绕回）下车"的那批人，其人数为 $\mathrm{load}[i]$。由于任意时刻车上人数 $\le \max_i \mathrm{load}[i] = \mathrm{mx} \le 36T$，座位数永远够用，不会出现某段乘客无座可坐的情况。故 $T$ 节车厢可行。
综上，最少车厢数为 $\lceil\mathrm{mx}/36\rceil$。证毕。

**引理 4**（整除计算）：`(mx+35)/36` 等于 $\lceil\mathrm{mx}/36\rceil$。

*证明*：记 $\mathrm{mx}=36q+r$，$0\le r<36$。若 $r=0$，则 `(mx+35)/36 = (36q+35)/36 = q$（整除取下整，因为 $36q+35 < 36(q+1)$），等于 $\lceil \mathrm{mx}/36\rceil = q$。若 $r>0$，则 `(mx+35)/36 = (36q+r+35)/36`，而 $r+35\in[36,70]$，故商为 $q+1$，等于 $\lceil\mathrm{mx}/36\rceil=q+1$。证毕。

**定理**：算法输出的车厢数是最少需要的车厢数。

*证明*：由引理 2，算法算出的 $\mathrm{mx}$ 是真实的各段最大载客人数；由引理 3、4，输出值 $\lceil\mathrm{mx}/36\rceil$ 恰为最少车厢数。证毕。

## 三、模式总结（按实际思考顺序）

1. **把"环形"翻译成"段"** — 定义第 $i$ 段为 $i\to i+1$，共 $n$ 段，跨越 $1\to n$ 的那段就是第 $n$ 段。
2. **把订票翻译成区间加** — $(x,y,z)$ 是若干段的区间加 $z$。
3. **差分** — $O(1)$ 处理一条订票，最后一次前缀和拿全局最大。
4. **跨界的两段拆成两个普通区间** — $x>y$ 时拆成 $[x,n]$ 与 $[1,y-1]$。
5. **注意 $y=1$ 时空区间** — `diff[1]+=z; diff[y]-=z;` 天然抵消，不用特判。
6. **向上取整** — `(mx+35)/36`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 站点数 | `int`，$\le 10^6$ |
| $m$ | 订票记录数 | `int`，$\le 10^6$ |
| $x,y,z$ | 一条订票：起点站、终点站、人数 | `int`，$x\ne y$，$1\le z\le 100$ |
| `diff_[i]` | 差分数组 | `i64[]`，下标 $1..n+1$ |
| `cur` | 当前前缀和（某段载客量） | `i64`，$\le 10^8$ |
| `mx` | 各段载客量最大值 | `i64` |

### 算法步骤

1. 读入 $n,m$。
2. 对第 $i=1..m$ 条订票 $(x,y,z)$：
   - 若 $x<y$：`diff_[x]+=z; diff_[y]-=z;`
   - 若 $x>y$：`diff_[x]+=z; diff_[n+1]-=z; diff_[1]+=z; diff_[y]-=z;`
3. `cur=0, mx=0`；对 $i=1..n$：`cur+=diff_[i]; mx=max(mx,cur);`
4. 输出 `(mx+35)/36`。

### 复杂度

- 时间复杂度：$O(n+m)$。
- 空间复杂度：$O(n)$。

### 验证状态

- 标程 `P2190.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 编写暴力 `P2190_brute.cpp`（对每条订票逐段累加载客量，再取最大值，$O(mn)$）与对拍脚本 `P2190_check.py`，在 $n,m\le 60$ 的随机数据上对拍 **2000 组全部通过**。
- 手工验证：$n=4$，订票 `(1,3,10) (2,4,20) (3,1,5)` 输出 `1`（各段载客 10 / 30 / 25 / 5，最大 30，$\lceil30/36\rceil=1$）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2190 小Z的车厢
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1000005};

i64 diff_[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m;
	cin>>n>>m;
	// 站点 i 的出站方向（顺时针）记为第 i 段（i=n 时为 n->1 那一段）
	for(int i=1;i<=m;++i)
	{
		int x,y,z;
		cin>>x>>y>>z;
		if(x<y)
		{
			// 经过第 x,x+1,...,y-1 段
			diff_[x]+=z;
			diff_[y]-=z;
		}
		else
		{
			// 经过第 x,...,n 段与第 1,...,y-1 段，跨越 1->n
			diff_[x]+=z;
			diff_[n+1]-=z;
			diff_[1]+=z;
			diff_[y]-=z;
		}
	}
	i64 mx=0,cur=0;
	for(int i=1;i<=n;++i)
	{
		cur+=diff_[i];
		mx=max(mx,cur);
	}
	// 每节车厢 36 人
	cout<<(mx+35)/36<<'\n';
	return 0;
}
```

### 代码说明

- `diff_` 用 `i64`：总人数上限 $m\cdot z \le 10^8$，`int` 也够，但用 `i64` 更稳，也方便 `(mx+35)` 不溢出。
- `mxn` 取 $10^6+5$；`diff_[n+1]` 需要被写入（作为区间的右端哨兵），所以数组要开到 $n+1$。
- 跨越 $1\to n$ 的那段是**第 $n$ 段**，不是"第 $n+1$ 段"；`diff_[n+1]-=z` 只是给区间 $[x,n]$ 打结束标记，前缀和只扫到 $n$，因此第 $n$ 段的载客量被完整计入，正确。
- $y=1$ 时 `diff_[1]+=z` 与 `diff_[y]-=z` 相消，自动处理了"段 $1..y-1$ 为空"的情形，无需特判。
- 向上取整用 `(mx+35)/36`，等价于 $\lceil\mathrm{mx}/36\rceil$。
