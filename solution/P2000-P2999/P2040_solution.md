# P2040 打开所有的灯 — 题解

## 一、解题过程：人类思考叙事

题目描述的是一个 $3\times3$ 的灯阵：点一下某个格子，这个格子以及它上下左右的邻格（如果存在）的开关状态全部**取反**。目标是用最少的点击次数把九盏灯全部点亮。

第一反应是暴力枚举。但枚举什么呢？枚举"点了哪些格子"?九宫格只有 $9$ 个位置，如果规定每个位置至多点一次，那么所有点击方案的子集数是 $2^9=512$，非常小。所以最朴素的思路是：枚举 $512$ 个子集，判断每一种点击方案能否点亮所有灯，取其中点击次数最少且可行的方案。这确实能做出答案。

不过更值得琢磨的问题是：**为什么可以规定每个位置至多点一次？** 因为在异或语义下，点同一个格子两次等于没点，任何方案都可以把重复的点击两两消掉，得到一个点击次数不更多、结果完全相同的子集。所以最优解一定是子集。

既然状态数只有 $2^9=512$，那么"当前灯阵状态"本身也可以压成一个 $9$ 位二进制数：第 $i$ 位表示第 $i$ 个格子亮不亮。这样一来，整个问题就变成了一个**状态图上的最短路**问题：

- 图的节点：$512$ 个灯阵状态；
- 图的边：对任意状态 $s$ 和任意位置 $i$，连一条 $s \to s\mathbin{\mathrm{xor}} tg[i]$ 的边，其中 $tg[i]$ 是"点击位置 $i$ 会翻转的位集合"（$i$ 自己加上存在的上下左右）；
- 边权：$1$（点一次）；
- 起点：输入状态；终点：全 $1$ 的状态 $511$。

状态图是无向的（异或是可逆的），且规模小到可怜，所以最直接的做法就是 **BFS** 求最短路。BFS 第一次到达终点时的层数就是最少点击次数。这个做法的好处是它把"枚举所有方案再取最优"变成了"一次 BFS 走完全图"，代码短且几乎没有出错空间。

具体实现上要注意几件事：

1. **翻转用异或**。状态是位掩码，点一下等价于把状态与翻转掩码异或：`v = u ^ tg[i]`。这比"逐位取反"清爽得多。
2. **翻转掩码要预处理边界**。角落的格子只有 3 个邻格（含自己），边上的有 4 个，中心有 5 个。如果不判边界，`i-3`、`i+3`、`i-1`、`i+1` 会越界或串行。用 `r=i/3, c=i%3` 判断行列即可。
3. **"全亮"的编码**。若用第 $i$ 位表示第 $i$ 个格子，则全亮就是 `(1<<9)-1 = 511`。
4. **无解情况**。BFS 跑完后若终点距离仍是哨兵 `1145141919`，说明打不到全亮状态（虽然本题的初始状态范围内实际都可达，但写上更稳妥），输出 `-1`。

样例：初始
```
0 1 1
1 0 0
1 0 1
```
按行优先编号为 $0\sim8$，初态掩码 = 第 $1,2,3,6,8$ 位为 $1$，即 $2+4+8+64+256=334$。题目说点中间 $(2,2)$（编号 $4$）再点左上角 $(1,1)$（编号 $0$）共 2 步。手算核对：$tg[4]$ 覆盖编号 $1,3,4,5,7$，$334\oplus tg[4]=500$；$tg[0]$ 覆盖编号 $0,1,3$，$500\oplus tg[0]=511$，恰为全亮。程序输出 `2`，与题面一致。

## 二、思维链：完整证明

**引理 1**（点击可去重）：若某个点击方案中位置 $i$ 被点击了至少两次，则存在一个点击次数更少（或相等）且最终状态相同的方案。

*证明*：点击是"翻转固定掩码 $tg[i]$"这一操作的复合。点击 $i$ 两次等价于把状态与 $tg[i]\oplus tg[i]=0$ 异或，即状态不变。若点击次数为 $c_i\ge2$，则 $c_i\bmod 2$ 次点击与 $c_i$ 次点击效果相同；把 $c_i$ 降为 $c_i\bmod 2$ 只减少点击次数而不改变最终状态。特别地，当 $c_i$ 为偶数时该位置可以完全删去，为奇数时保留一次。所以最优解中每个位置至多被点击一次。证毕。

**引理 2**（状态图正确刻画点击过程）：从状态 $s$ 出发点击位置 $i$，得到的灯阵状态恰为 $s\oplus tg[i]$。

*证明*：由 $tg[i]$ 的定义，它的第 $j$ 位为 $1$ 当且仅当格子 $j$ 是位置 $i$ 本身或 $i$ 的上下左右邻格（越界的不计入）。而一次点击的效果正是"把这些格子的亮灭取反"。在位掩码表示下，"把若干指定位取反"等价于"与这些位组成的掩码异或"，因为：$s$ 的第 $j$ 位与 $tg[i]$ 的第 $j$ 位异或，若 $tg[i]$ 该位为 $0$ 则结果等于原位（不变），为 $1$ 则结果等于原位的反（取反）。这恰好与点击效果逐位一致。证毕。

**引理 3**（BFS 得到的距离是最少点击次数）：设 $\mathrm{dis}[s]$ 为 BFS 从初态出发到状态 $s$ 的最短距离，则 $\mathrm{dis}[s]$ 等于从初态到 $s$ 的最少点击次数。

*证明*：把"从初态到 $s$ 的点击序列"与"状态图中的路径"一一对应：给定一个长为 $L$ 的点击序列，由引理 2，每一步对应状态图上一条边，故得到一条长为 $L$ 的路径；反之，状态图中的每条边都对应一次合法点击，故一条长为 $L$ 的路径对应一个长为 $L$ 的点击序列。两者一一对应且长度相同。

状态图每条边权为 $1$，BFS 在无权图上求得的就是最少边数路径长度，因此 $\mathrm{dis}[s]$ 恰为最少点击次数。证毕。

**定理**：算法输出的值就是打开所有灯所需的最少步数。

*证明*：全部点亮对应状态 $T=511$。由引理 3，$\mathrm{dis}[T]$ 是到达 $T$ 的最少点击次数，即所求最少步数。若 $\mathrm{dis}[T]$ 为哨兵值，说明状态图中不存在从初态到 $T$ 的路径，由一一对应性知不存在能点亮所有灯的点击序列，输出 `-1` 亦正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别题型** — 九宫格翻转，状态空间小到可以枚举。
2. **先想清楚"点两次等于没点"** — 这一步把"点击次数"变成"子集大小"，从而确定搜索空间是 $2^9$。
3. **把灯阵压成位掩码** — 让"翻转"变成一次异或，让"两个状态是否相同"变成一次整数比较。
4. **建模成最短路** — 节点是灯阵状态、边是点击、边权为 1，BFS 一次搞定，还天然给出最少步数。
5. **边界处理** — 角落格子邻格不足，预处理翻转掩码时必须判行列，否则会算到别的格子头上。
6. **兜底无解** — BFS 后检查终点距离是否为哨兵。
7. **验证方式** — 用题面样例（输出 2）核对，并另写枚举全部 $2^9$ 个子集的暴力做对拍。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| 灯阵规模 | 固定 $3\times3=9$ 个格子 | — |
| `st` | 初始状态位掩码，第 $i$ 位表示格子 $i$ 是否亮 | `int`，$0\sim511$ |
| `tg[i]` | 点击位置 $i$ 会翻转的格子集合的掩码 | `int[9]` |
| `dis[s]` | 从初态到状态 $s$ 的最少点击次数 | `int[512]` |
| `inf` | 不可达哨兵 | `constexpr int inf{1145141919}` |
| 目标状态 $T$ | 九盏灯全亮，`(1<<9)-1` | `int`，$511$ |

### 算法步骤

1. 读入 9 个数字，按行优先压成初态 `st`（第 $i$ 位为 1 表示亮）。
2. 预处理 9 个翻转掩码 `tg[i]`：起点是格子 $i$ 自身，再按 `r=i/3, c=i%3` 判断上下左右是否存在，存在就把对应位也置 1。
3. 在 $2^9=512$ 个状态上 BFS：
   - 起点 `dis[st]=0`，其余置 `inf`；
   - 每次取出状态 $u$，枚举 9 个位置 $i$，令 $v=u\mathbin{\mathrm{xor}}tg[i]$，若 `dis[v]` 仍为 `inf` 则令 `dis[v]=dis[u]+1` 并入队。
4. 若 `dis[(1<<9)-1]` 仍为 `inf`，输出 `-1`；否则输出 `dis[(1<<9)-1]`。

### 复杂度

- 时间复杂度：$O(2^9\cdot 9)$，即最多 $512\times9=4608$ 次转移，可忽略不计。
- 空间复杂度：$O(2^9)$。

### 验证状态

- 标程 `P2040.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 题面样例（`0 1 1 / 1 0 0 / 1 0 1`）输出 `2`，与题面"最少需要 2 步"一致。
- 另写暴力 `P2040_brute.cpp`：枚举全部 $2^9=512$ 个点击子集，判断能否点亮并取最小基数。
- 对拍脚本 `P2040_check.py`：**304 组**随机与极端用例（随机初态 + 全 0 / 全 1 / 样例初态等边界），标程与暴力输出 **0 处不一致**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2040 打开所有的灯
// 思路：把 9 盏灯压成 9 位状态，状态图上 BFS 求最短路
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{520};
constexpr int inf{1145141919};

int tg[9];				// tg[i]: 点击第 i 个位置会翻转的位掩码
int dis[1<<9];			// dis[state]: 从初始状态到 state 的最少点击数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int st=0;
	for(int i=0;i<9;++i)
	{
		int x;
		cin>>x;
		if(x) st|=1<<i;		// 1 表示亮
	}
	// 预处理每个位置自身的翻转掩码：自己 + 上下左右
	for(int i=0;i<9;++i)
	{
		int r=i/3,c=i%3,mask=1<<i;
		if(r>0) mask|=1<<(i-3);
		if(r<2) mask|=1<<(i+3);
		if(c>0) mask|=1<<(i-1);
		if(c<2) mask|=1<<(i+1);
		tg[i]=mask;
	}
	fill_n(dis,1<<9,inf);
	dis[st]=0;
	queue<int>q;
	q.push(st);
	while(!q.empty())
	{
		int u=q.front();
		q.pop();
		for(int i=0;i<9;++i)
		{
			int v=u^tg[i];		// 点击等价于异或翻转
			if(dis[v]==inf)
			{
				dis[v]=dis[u]+1;
				q.push(v);
			}
		}
	}
	// 全部点亮对应 9 位全 1
	if(dis[(1<<9)-1]==inf)
		cout<<-1<<'\n';
	else
		cout<<dis[(1<<9)-1]<<'\n';
	return 0;
}
```

### 代码说明

- `u^tg[i]` 一步完成"翻转指定若干格"，见引理 2。
- `tg[i]` 的构造用 `r=i/3, c=i%3` 判断四周是否存在，避免角落格子越界访问到相邻行的格子。
- `fill_n(dis,1<<9,inf)` 把所有距离初始化为哨兵 `1145141919`，兼作"未访问"标记。
- 队列用 `std::queue`，BFS 出队顺序即距离递增顺序，因此第一次给 `dis[v]` 赋值就是最短距离，不需要额外松弛。
- 目标状态写成 `(1<<9)-1`，避免手算常数出错。
