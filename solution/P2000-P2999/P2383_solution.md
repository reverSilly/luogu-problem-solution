# P2383 狗哥玩木棒 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 第一行 $n\le10$ 表示测试组数。每组给出 $m\le20$ 根木棒的长度 $a_i\le2000$。问能否把**全部**木棒首尾相接摆成一个正方形（四条边等长）。输出 `yes`/`no`。

**先做没有争议的化简。** 正方形四边等长，所以边长只能是
$$\text{side}=\frac{\sum a_i}{4}.$$
两个必要条件立刻到手：$\sum a_i$ 必须被 $4$ 整除；最长的木棒不能超过 side（否则它放不进任何一条边）。这两条能筛掉一大半的 `no`，而且证明只需一句话（见第二节引理 1）。

**剩下的问题是什么形状？** 等价于：把 $m$ 根木棒分成 $4$ 组，每组之和恰为 side。这是经典的"划分成 $k$ 个等和子集"，本质是 bin packing，$m\le20$ 时最裸的 $4^m$（每根棒子选一个桶）是 $4^{20}\approx10^{12}$，不行。于是想到搜索 + 剪枝——题目标签也正是"搜索, 剪枝"。

**搜索框架怎么选？** 有两种常见写法：

1. **一次装一条边**：枚举一个和为 side 的子集作为第一条边，删掉后递归。优点是"边"的概念清晰。
2. **四桶逐个放**：开四个容量为 side 的桶，按顺序把每根木棒放进某个桶，桶不能超容量。优点是每步只看四个桶，剪枝容易写。

我选第 2 种：状态就是 `cap[0..3]` 四个桶的当前高度，`dfs(idx)` 表示"前 `idx` 根已经放好，现在放第 `idx` 根"。

**排序是个免费的加速。** 把木棒**从大到小**排序再放。理由：大棒子能去的地方少，先放它等于先把搜索树的分叉掐掉；而且"存在合法划分"这件事与放置顺序无关（任何划分都可以按降序依次执行），所以排序不丢解。

**第一个剪枝：容量。** `cap[k]+a[idx]>side` 的桶直接跳过。这是显然的——桶高只会增不会减，超过 side 就永远补不回来。

**第二个剪枝：等高桶等价。** 四个桶只是"标签"不同，如果两个桶当前高度相同，那么把当前木棒放进哪一个，后续能走到的局面完全一样（把两个桶的标签互换即可）。所以：**同一高度只试一次**。实现上用一个 `last` 记住"刚刚试过并已失败的那个桶的高度"，遇到等高的桶就跳过。

**第三个剪枝（这里差点翻车）：空桶失败即整体失败。** 教科书上写着"如果木棒放进一个空桶会导致失败，那么整个分支失败"。我一开始觉得它显然：所有空桶都一样，这个空桶失败，别的空桶不也一样失败吗？

写完才发现这个理由**不完整**：它只说明了"别的空桶也失败"，可没说"放进**不空**的桶也失败"。真正的隐患是：万一当前木棒放进一个已经装了东西的桶里反而能成呢？那时 `break` 就成了错误剪枝。

**修补：需要一个不变量。** 关键观察是——**任何时刻，非空的桶总是前 $p$ 个桶 $\{0,1,\dots,p-1\}$，空的桶总是后 $4-p$ 个**。为什么？因为循环按 $k=0,1,2,3$ 的顺序试桶，而"往空桶里放"永远不会因为容量被拒（空桶容量是满的 side，而 $a_{idx}\le\text{side}$），所以**遇到的第一个空桶一定会被真的尝试**；一旦尝试并递归下去，前缀就延长一位。于是"第一个空桶"后面的桶必然都还是空的。

有了这个不变量，`break` 就只跳过"下标更大、且确实为空"的桶——它们与刚失败的那个空桶完全等价。所有**非空**的桶都在它之前被尝试过（或作为等高副本被安全跳过）。所以 `break` 是纯粹的对称性剪枝，不丢解。这条不变量是整个剪枝正确性的支柱，必须写进证明里。

**第四个剪枝：缺口填不满。** 若某个桶的剩余容量 $r=\text{side}-\text{cap}[k]$ 满足 $0<r<\text{最短剩余木棒}$，那这个桶永远填不满（任何一根剩余木棒都比缺口长），直接失败。这条既便宜又有效：加上它，满规模随机数据的最坏用时大约降了一半。

**还有什么会错？** 三个易错点：

- 多组数据：每组的 `cap` 必须清零，`side` 重新算。
- `m` 根木棒全部要用，所以 $\sum a_i=4\,\text{side}$ 是硬约束，不能"剩下几根不用"。
- 剪枝的正确性各自独立，但**空桶剪枝依赖前缀不变量**，两者必须一起证明，不能分开"显然"。

**手造数据核对**（题面无样例）：

| 输入 | 输出 | 说明 |
|------|------|------|
| `4: 1 1 1 1` | `yes` | 边长 $1$，每根自成一边 |
| `4: 1 1 1 2` | `no` | 总和 $5$ 不被 $4$ 整除 |
| `5: 1 1 1 1 4` | `no` | 边长 $2$，最长棒 $4>2$ |
| `7: 1 1 1 1 1 1 2` | `yes` | 边长 $2$：$2\mid1+1\mid1+1\mid1+1$ |
| `8: 2×8` | `yes` | 边长 $4$，两两成边 |
| `4: 2000 2000 2000 2000` | `yes` | 边长 $2000$，每根自成一边 |
| `20: 2000×20` | `yes` | 边长 $10000$，五根一边 |
| `20: 1×20` | `yes` | 边长 $5$，五根一边 |
| `6: 1 1 1 1 1 3` | `no` | 边长 $2$，最长棒 $3>2$ |

## 二、思维链：完整证明

**约定。** 木棒按非增序排列为 $a_0\ge a_1\ge\dots\ge a_{m-1}$；记 $\text{side}=T/4$，$T=\sum a_i$（仅当 $4\mid T$ 时才讨论）。四个桶的当前高度记为 $c_0,c_1,c_2,c_3$，初始全 $0$。`dfs(idx)` 负责把 $a_{idx},a_{idx+1},\dots,a_{m-1}$ 全部放入桶中。"可解"（solvable）指：存在一种放法，使四个桶最终高度都恰为 side。

**引理 1（必要条件）。** 若 $4\nmid T$ 或 $\max_i a_i>\text{side}$，则不可能组成正方形，输出 `no` 是对的。

*证明：* 正方形的四条边等长，设边长为 $L$，则四边上的木棒长度之和为 $4L$；木棒全用且不重叠，故 $4L=T$，于是 $L=T/4$ 必须是整数，即 $4\mid T$。又任一根木棒整体落在某条边上，其长度不超过该边长 $L=\text{side}$，故 $\max a_i\le\text{side}$。两条任一被违反即无解。证毕。

以下假设两条必要条件都通过，于是 $\text{side}$ 是整数且 $a_i\le\text{side}$ 对一切 $i$ 成立。

**引理 2（不变量）。** 在 `dfs` 的任意一次调用中：

- (I1) 对一切 $k$，$0\le c_k\le\text{side}$；
- (I2) $\sum_k c_k+\sum_{t\ge idx}a_t=4\,\text{side}$。

进一步，当 $idx=m$ 时 (I2) 化为 $\sum_k c_k=4\,\text{side}$，结合 (I1) 得 $c_0=c_1=c_2=c_3=\text{side}$。

*证明：* 初始时 $c_k=0$、$idx=0$，(I1) 成立，(I2) 化为 $\sum_t a_t=T=4\,\text{side}$ ✓。归纳：设当前满足两条不变量，程序把 $a_{idx}$ 放进桶 $k$（仅当 $c_k+a_{idx}\le\text{side}$，这正是 (I1) 的保持条件），然后 $idx$ 加一。此时 $\sum_k c_k$ 增加 $a_{idx}$，而 $\sum_{t\ge idx}a_t$ 减少 $a_{idx}$，(I2) 不变 ✓；(I1) 由容量检查保证 ✓。回溯时把 $c_k$ 减回去，两个不变量同时复原 ✓。最后一段由 $\sum_kc_k=4\,\text{side}$ 与每个 $c_k\le\text{side}$ 得每个都等于 side。证毕。

**引理 3（搜索空间完备）。** 把三个剪枝（等高、空桶、缺口）删掉、只保留容量检查与"到叶子返回 true"的结构，`dfs(0)` 返回 true 当且仅当可解。

*证明：* 搜索树把"每根木棒选一个桶"的 $4^m$ 种指派逐一枚举，到 $idx=m$ 时每种指派恰对应一条根到叶的路径。

- 若可解，取一份合法划分，沿"每根木棒放进它所属的桶"这条路径下降：任一前缀时刻桶高不超过该桶的最终值 side，故容量检查全部通过，最终到达叶子并返回 true。
- 若返回 true，说明存在一条全程通过容量检查的路径到达叶子；由引理 2，此时四桶恰满 side，于是该路径就是一种合法划分。

两个方向合起来得证。证毕。

**引理 4（容量剪枝安全）。** 跳过满足 $c_k+a_{idx}>\text{side}$ 的桶不丢解。

*证明：* 在引理 3 的枚举中，任何最终四桶恰满的指派都满足"任意时刻任意桶高度不超过 side"（高度单调不减，且终点等于 side）。所以"放进超容量桶"的指派全都不可能成为解，跳过它们不改变"是否存在解"。证毕。

**引理 5（降序排序不丢解）。** 设 $\pi$ 是任意排列，"按 $\pi$ 顺序存在合法划分"$\iff$"按降序存在合法划分"。

*证明：* 划分是一个集合划分（每根木棒属于哪条边），与"先处理谁"无关：给定一个合法划分，按降序依次把木棒放进它所属的桶，每一时刻桶高不超过最终值 side，因此这条放置序列合法。所以只要存在划分，降序搜索就能走通；反之降序走通给出的也是一份合法划分。证毕。

**引理 6（等高剪枝安全）。** 若在某次调用中 $c_{k_1}=c_{k_2}$，且程序只在 $k_1,k_2$ 中尝试了 $k_1$ 就跳过了 $k_2$，则不丢解。

*证明：* 设把 $a_{idx}$ 放进 $k_2$ 之后存在一个完成的划分 $\sigma$。考虑把 $\sigma$ 中桶 $k_1$ 与 $k_2$ 的角色整体互换：由于两者当前高度相同，互换后每个时刻两桶高度仍不超过 side（互换只是把"往 $k_1$ 加的东西"改加到 $k_2$、反之亦然），且终点仍都是 side；其余桶不动。于是得到一个合法完成，其中 $a_{idx}$ 落在 $k_1$。也就是说"放进 $k_2$ 可解"蕴含"放进 $k_1$ 可解"，跳过 $k_2$ 安全。证毕。

**引理 7（前缀不变量与空桶剪枝安全）。** 在任意一次 `dfs` 调用中，存在 $p\in[0,4]$ 使 $c_0,\dots,c_{p-1}>0$ 而 $c_p=\dots=c_3=0$。并且：若把 $a_{idx}$ 放进第一个空桶（桶 $p$）后的递归失败，则"把 $a_{idx}$ 放进任何桶"都失败，函数可以立即返回 false。

*证明：* 分两部分。

**(a) 前缀不变量。** 对递归深度归纳。初始 $p=0$ ✓。设当前前缀为 $p$。循环按 $k=0,1,2,3$ 顺序试桶：

- 对 $k<p$：桶非空，可能被尝试，或作为等高副本跳过（引理 6）。
- 对 $k=p$（第一个空桶）：容量检查必过（$c_p=0$，$a_{idx}\le\text{side}$，引理 1 已保证）；等高检查也必不跳过它——`last` 记录的是"最近一次真正尝试过的桶的高度"，而此前真正尝试过的桶都非空（高度 $>0$），所以 `last` 要么是 $-1$（尚未尝试任何桶，此时 $p=0$）要么 $>0$，都不会等于 $c_p=0$。因此空桶 $p$ 一定被真正尝试。

于是每次成功递归都使前缀延长一位（桶 $p$ 变非空），回溯后复原；若在 $k=p$ 处失败，函数直接返回、不再尝试 $k>p$ 的桶，此时那三个桶本来就都是空的。故"非空桶是前缀、空桶是后缀"在整棵搜索树中恒成立。

**(b) 空桶剪枝安全。** 设放进桶 $p$ 的分支失败。桶 $p+1,\dots,3$ 全空（(a)），由引理 6 它们与桶 $p$ 等价，放进它们同样失败。而桶 $0,\dots,p-1$ 都已在本轮循环里被处理：要么真被尝试（若成功就已经返回 true，与"当前要返回 false"矛盾），要么作为某个"已尝试且等高"的桶的副本被跳过（引理 6），其结局与那个被尝试的桶相同——也失败。所以四种放法全部失败，返回 false 正确。证毕。

**引理 8（缺口剪枝安全）。** 若存在桶 $k$ 使 $0<\text{side}-c_k<\min_{t\ge idx}a_t$，则当前局面不可解，返回 false 正确。

*证明：* 桶 $k$ 的剩余容量 $r>0$，说明还必须有木棒进入它（否则最终高度 $<$ side）。任何一根剩余木棒的长度 $\ge\min_{t\ge idx}a_t>r$，放进去就会超过 side，违反 (I1) 所刻画的可行性。因此不存在合法完成。证毕。

**引理 9（主定理：函数返回值正确）。** 对搜索树中任意被到达的节点，"`dfs` 返回 true" $\iff$"该节点可解"。

*证明：* 对剩余木棒数 $m-idx$ 做强归纳。

- $idx=m$：由引理 2，可解 $\iff$ 四个桶全等于 side $\iff\sum_kc_k=4\,\text{side}$（因 (I1)(I2) 恒成立），而函数此时直接返回 true，故等价 ✓。（此分支在缺口剪枝之前返回，不会被误判。）
- $idx<m$，归纳假设对所有 $idx'>idx$ 成立。
  - 若缺口剪枝触发：由引理 8，不可解，函数返回 false ✓。
  - 否则设 $s=a_{idx}$。
    - **可靠性**：函数返回 true 只可能来自某个被尝试的桶 $k$（容量检查通过）的递归返回 true。由归纳假设，那个子节点可解，把 $s$ 加进桶 $k$ 即得本节点的一个合法完成，故本节点可解 ✓。
    - **完备性**：设本节点可解，取一份完成 $\sigma$，令 $b$ 为 $\sigma$ 中 $s$ 所在的桶。$\sigma$ 合法 $\Rightarrow c_b+s\le\text{side}$，故容量检查不会排除 $b$。分三种情形：
      1. 桶 $b$ 被真正尝试：把 $\sigma$ 限制到子节点即得其完成，由归纳假设该子调用返回 true，于是本函数返回 true ✓。
      2. 桶 $b$ 因等高被跳过：跳过时存在一个**先被真正尝试**的桶 $k^\*$ 满足 $c_{k^\*}=c_b$。由引理 6，把 $\sigma$ 中 $b,k^\*$ 两个桶互换得到另一个完成 $\sigma'$，其中 $s$ 落在 $k^\*$；于是情形 1 适用，返回 true ✓。
      3. 循环在第一个空桶 $p$ 处 `break` 并返回 false（即桶 $b$ 未被尝试）。由引理 7(a) 的前缀不变量，非空桶恰为 $0,\dots,p-1$。若 $b<p$，则桶 $b$ 非空，在本轮循环中它必被真正尝试或作为某个等高桶的副本被处理：若是真正尝试，把 $\sigma$ 限制到该子节点得其可解，由归纳假设该子调用返回 true，本函数就不会走到 `break`；若被跳过，则由引理 6 存在经其等高副本的完成，同样使该子调用返回 true。两种都与"走到 $p$ 才 `break`"矛盾。故 $b\ge p$，由前缀不变量得 $c_b=0$：$s$ 在 $\sigma$ 中落在一个空桶里。再由引理 6（空桶之间等高），把 $\sigma$ 中桶 $b$ 与桶 $p$ 互换，得到一份 $s$ 落在 $p$ 的完成；那么"放进桶 $p$"的子调用可解，由归纳假设应返回 true——与"该分支失败并 `break`"矛盾。故此情形不可能发生 ✓。

    综上，可解时函数必返回 true。
- 归纳完成。再由引理 3（搜索空间完备）与引理 5（排序不丢解），`dfs(0)` 返回 true $\iff$ 原问题可解。证毕。

**引理 10（复杂度）。** 最坏时间复杂度 $O(4^m\cdot m)$，空间 $O(m)$；实际运行远小于此上界。

*证明：* 搜索树叶层至多 $4^m$ 个节点、深度 $m$，每层 $O(1)$ 工作（四个桶的检查），故上界 $O(4^m m)$；三个剪枝只减少节点数，不增加渐进上界。空间是递归栈与两个长度 $m$ 的数组（`a`、`cap`），$O(m)$。$m\le20$、$n\le10$ 下，剪枝把实际节点数压到极小（实测 10 组满规模随机数据最坏约 $0.3$ 秒）。证毕。

**定理。** 对每组数据，程序输出 `yes` 当且仅当所有木棒能拼成正方形。

*证明：* 引理 1 处理必要条件不满足的情形（此时确实无解）；其余情形由引理 9 的等价性得出。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 问题等价于"把木棒划分成 4 个和为 $T/4$ 的组"，边长被唯一确定为 $T/4$。
2. **consider easier version** — 先做两个 $O(m)$ 的必要条件（$4\mid T$、$\max a\le\text{side}$），筛掉大量 `no`。
3. **classic problem solution** — bin packing 式 DFS：四个容量为 side 的桶，逐根放，超容量即跳过。
4. **explore its property** — "存在划分"与放置顺序无关，故可降序排序，先放最受约束的大棒。
5. **explore its property** — 桶只是标签，等高桶等价 $\Rightarrow$ 同一高度只试一次（对称性剪枝）。
6. **explore its property** — 循环按序试桶 + 空桶必被尝试 $\Rightarrow$ 非空桶恒为前缀、空桶恒为后缀 $\Rightarrow$ 空桶失败即可整体失败。
7. **explore its property** — 剩余容量小于最短剩余木棒的桶永远填不满 $\Rightarrow$ 缺口剪枝。
8. **classic problem solution** — 以"剩余木棒数"为规模做归纳，逐条证明剪枝不丢解，得到函数返回值与可解性的等价。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $n$ | 测试组数 | `int` | 输入，$\le10$ |
| $m$ | 当前组木棒根数 | `int` | 输入，$\le20$ |
| $a_i$ | 木棒长度，**降序**存放 | `int[]` | 读入后 `sort(...,greater<int>())` |
| `tot` | $\sum a_i$ | `int` | 读入时累加（$\le40000$） |
| `mx` | $\max a_i$ | `int` | 读入时取最大 |
| `side` | 边长 $=tot/4$ | `int` | 只在 $4\mid tot$ 时计算 |
| `cap[4]` | 四个桶的当前高度 | `int[]` | **每组必须清零** |
| `idx` | 当前要放的木棒下标 | `int` | 递归参数，$0\to m$ |
| `last` | 本轮最近一次真正尝试过的桶高度 | `int` | 每层初值 $-1$，用于等高剪枝 |
| `mn` | 剩余木棒中最短的一根 $=a_{m-1}$ | `int` | 降序后恒为末元素 |

### 算法步骤

1. I/O 加速三行。
2. 读 $n$，循环 $n$ 次处理每组。
3. 读 $m$ 与 $a_0..a_{m-1}$，同时求 `tot`、`mx`。
4. 若 `tot%4!=0` 或 `mx>tot/4`，输出 `no`，进入下一组。
5. `side=tot/4`；`sort(a,a+m,greater<int>())`；`cap[0..3]=0`。
6. 调用 `dfs(0)`，按其返回值输出 `yes`/`no`。
7. `dfs(idx)`：
   1. `idx==m` 返回 true。
   2. `mn=a[m-1]`；对 $k=0..3$：若 $0<\text{side}-\text{cap}[k]<mn$ 返回 false（缺口剪枝）。
   3. `s=a[idx]`，`last=-1`。
   4. 对 $k=0..3$：
      1. `cap[k]==last` 则跳过（等高剪枝）；
      2. `cap[k]+s>side` 则跳过（容量剪枝）；
      3. `last=cap[k]`；`cap[k]+=s`；若 `dfs(idx+1)` 为真则返回 true；`cap[k]-=s`；
      4. 若 `cap[k]==0`（还原后为空，即这个空桶失败）返回 false（空桶剪枝）。
   5. 四个桶都试完仍未成功，返回 false。

### 复杂度

- 时间：最坏 $O(4^m)$ 次递归，每次 $O(1)$ 检查；$m\le20$、$n\le10$，三个剪枝把实际规模压到远小于上界（实测满规模随机数据 10 组最坏约 $0.3$ 秒）。
- 空间：$O(m)$（递归栈 + 两个长度 $m$ 的数组 + 四个桶）。
- 验证状态：编译通过；9 组手造边界（整除、超长棒、全等棒、$m=4$ 最小规模）全对；300 组 $m\le11$ 随机数据与"无剪枝 $4^m$ 全枚举"暴力一致；300 组 $m=20$ 随机数据与"$2^m$ 位掩码 DP"完全一致；对 60 个随机种子做满规模计时，最坏约 $0.3$ 秒/10 组。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2383 狗哥玩木棒
// 思路：能被 4 整除且最长棒不超过 tot/4 后，问题变成"把木棒分成 4 组、每组和恰为 side"。
//       降序排序后 DFS 往四个桶里放，配合三个剪枝：
//       ① 容量剪枝 ② 等高桶等价（last）③ 空桶失败即整体失败（依赖"非空桶恒为前缀"）
//       另有缺口剪枝：剩余容量比最短剩余木棒还小，永远填不满。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};

int m,side,a[mxn],cap[4];

// 木棒已按长度降序排列，从第 idx 根开始往下放
bool dfs(int idx)
{
	if(idx==m)						// 全部放完且从未超限 ⇒ 四桶都恰好装满 side
		return true;
	int mn=a[m-1];					// 剩余木棒中最短的一根
	for(int k=0;k<4;++k)
	{
		int r=side-cap[k];
		if(r>0&&r<mn)				// 这个缺口剩下的木棒都填不满
			return false;
	}
	int s=a[idx],last=-1;			// last：刚试过并失败的桶高度，相同高度不再重试
	for(int k=0;k<4;++k)
	{
		if(cap[k]==last)			// 等高桶等价，跳过
			continue;
		if(cap[k]+s>side)
			continue;
		last=cap[k];
		cap[k]+=s;
		if(dfs(idx+1))
			return true;
		cap[k]-=s;
		if(cap[k]==0)				// 放进空桶都失败：其余空桶与它等价
			return false;
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	while(n--)
	{
		cin>>m;
		int tot=0,mx=0;
		for(int i=0;i<m;++i)
		{
			cin>>a[i];
			tot+=a[i];
			mx=max(mx,a[i]);
		}
		if(tot%4!=0)				// 边长不是整数
		{
			cout<<"no\n";
			continue;
		}
		side=tot/4;
		if(mx>side)					// 最长棒放不进任何一边
		{
			cout<<"no\n";
			continue;
		}
		sort(a,a+m,greater<int>());	// 先放最受约束的大棒
		cap[0]=cap[1]=cap[2]=cap[3]=0;
		cout<<(dfs(0)?"yes\n":"no\n");
	}
	return 0;
}
```

### 代码说明

- `cap` 是四个桶的当前高度，每组数据必须清零——多测最容易踩的坑。
- `if(cap[k]==last)continue;` 是等高剪枝：`last` 只记录"最近一次真正递归过的桶"，因此永远只跳过与已尝试桶等高的副本，不会误跳（引理 6）。
- `if(cap[k]==0)return false;` 是空桶剪枝，它的正确性依赖"非空桶恒为前缀"这一不变量（引理 7(a)）：循环按序试桶、空桶必被尝试，所以此刻下标更大的桶全空，与失败的这个空桶完全等价。
- 缺口剪枝放在进入循环之前：一次扫描四个桶，$O(1)$，能砍掉大量"看似能填、其实填不满"的死路。
- `mn` 恒等于 `a[m-1]`（降序排序），不必每层重算最小值。
- `idx==m` 的 true 返回在缺口剪枝之前，避免在"已全部放完"时被剩余容量的检查误伤。
- 全部木棒必须使用：由不变量 $\sum c_k+\sum_{t\ge idx}a_t=4\,\text{side}$ 保证，放完就必然四桶各为 side。
