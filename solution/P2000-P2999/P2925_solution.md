# P2925 [USACO08DEC] Hay For Sale S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离蟑螂背景）。** 马车容量 $C$（$1\le C\le 5\times10^4$）。有 $H$ 捆稻草（$1\le H\le 5000$），第 $i$ 捆体积 $V_i$（$1\le V_i\le C$），**每捆要么整捆买、要么不买，不能拆分、不能重复买**。选一个子集，使总体积不超过 $C$ 且尽量大。输出这个最大总体积。

约束与边界：

- 这是**价值 = 重量**的 0/1 背包：买第 $i$ 捆既消耗 $V_i$ 容量又贡献 $V_i$ 价值。等价于"**子集和**：不超过 $C$ 的最大可达子集和"。
- $V_i\le C$ 保证每捆单独都装得下；答案 $\ge \max V_i \ge 1$，不会是 0（除非……不会，$H\ge1$）。
- $H=1$ 时答案就是 $V_1$。
- 全部体积都 $\le C$ 且总和 $\le C$ 时答案是总和（全买）。
- 规模 $C\cdot H=5\times10^4\times5000=2.5\times10^8$，一维 0/1 背包在 `-O2` 下完全可行（内层循环无循环携带依赖，编译器可向量化）；下文还会给出一个 $O(CH/64)$ 的 bitset 视角作为可选加速。
- 题面无样例输入输出，手造数据核对（见下）。

**手造极简数据核对：**

第一组：$C=10,H=3$，体积 $3,4,5$。

```
输入：
10 3
3
4
5

输出：
9
```

手算枚举子集：$\{3\}=3,\{4\}=4,\{5\}=5,\{3,4\}=7,\{3,5\}=8,\{4,5\}=9,\{3,4,5\}=12>10$ 舍。最大 **9**。

第二组（0/1 与完全背包的分水岭）：$C=12,H=1$，体积 $6$。只有一捆，答案 **6**；若误用完全背包（正序循环）会算出 12。

第三组（全装得下）：$C=6,H=3$，体积 $2,2,2$，答案 **6**。

第四组（$H=1$ 边界）：$C=5,H=1$，体积 $5$，答案 **5**。

## 二、思维链：完整证明

**记号。** 物品（稻草捆）$i=1..H$，体积 $V_i$。容量 $j\in[0,C]$。目标：$\max\bigl\{\sum_{i\in S}V_i:\ S\subseteq\{1..H\},\ \sum_{i\in S}V_i\le C\bigr\}$。

### 第一步：识别模型——explore its property

"每捆至多买一次 + 容量上限 + 最大化总体积"，就是 **0/1 背包**，而且价值恰好等于重量。这个特殊性意味着：DP 值本身就是一个"可达的子集和"，答案 = 不超过 $C$ 的最大可达子集和。先按标准 0/1 背包推，最后再看这个特殊性还能榨出什么。

### 第二步：二维 DP 与最优子结构——classic problem solution

令 $g[i][j]$ = 只考虑前 $i$ 捆、总体积不超过 $j$ 时的最大总体积。

**引理 1（二维递推）。** $g[0][j]=0$；对 $i\ge1$：

$$g[i][j]=\begin{cases}g[i-1][j],&j<V_i\\ \max\bigl(g[i-1][j],\ g[i-1][j-V_i]+V_i\bigr),&j\ge V_i.\end{cases}$$

*证明*：$i=0$：空集是唯一选择，体积 0，故 $g[0][j]=0$ ✓。

$i\ge1$：设 $S^\*$ 是前 $i$ 捆中容量 $j$ 下的最优子集。按"第 $i$ 捆是否入选"分类，两类穷尽：

- **不选 $i$**：$S^\*\subseteq\{1..i-1\}$ 且 $\sum_{S^\*}V\le j$，故 $\mathrm{val}(S^\*)\le g[i-1][j]$；反之任何前 $i-1$ 捆的容量 $j$ 可行子集也是前 $i$ 捆的可行子集，故这一类的最大值**恰为** $g[i-1][j]$。
- **选 $i$**（仅当 $j\ge V_i$ 才可能）：$S^\*\setminus\{i\}$ 的体积 $\le j-V_i$，是前 $i-1$ 捆容量 $j-V_i$ 的可行子集，故 $\mathrm{val}(S^\*)\le g[i-1][j-V_i]+V_i$；反之任何前 $i-1$ 捆容量 $j-V_i$ 的最优子集添上第 $i$ 捆，体积 $\le j$、价值 $+V_i$，故这一类的最大值**恰为** $g[i-1][j-V_i]+V_i$。

两类取 max 即得递推式；$j<V_i$ 时第二类为空，只剩第一类。证毕。

答案显然是 $g[H][C]$（定义逐字对应题目要求）。但二维数组 $5000\times50000$ 个 int 约 1 GB，必须滚动掉第一维。

### 第三步：一维滚动为什么必须倒序——本题真正的坑

滚动数组写法：只留 `dp[j]`，对每个物品 $i$，让 $j$ **从 $C$ 递减到 $V_i$**，执行 `dp[j]=max(dp[j],dp[j-V_i]+V_i)`。为什么必须倒序？正序会发生什么？

**引理 2（倒序不变量）。** 设第 $i$ 轮开始前 `dp[j]`$=g[i-1][j]$ 对所有 $j$ 成立。若本轮 $j$ 从 $C$ **递减**到 $V_i$ 更新，则本轮结束后 `dp[j]`$=g[i][j]$ 对所有 $j$ 成立。

*证明*：考察本轮中更新位置 $j$ 的时刻。此时：

- `dp[j]` 尚未被本轮碰过（每个位置只更新一次），仍等于 $g[i-1][j]$；
- `dp[j-V_i]` 的下标 $j-V_i<j$，而本轮是**从大到小**扫的，比 $j$ 小的位置都还没更新，故 `dp[j-V_i]` 也仍等于 $g[i-1][j-V_i]$。

于是赋值 `dp[j]=max(dp[j],dp[j-V_i]+V_i)` 恰好计算 $\max(g[i-1][j],g[i-1][j-V_i]+V_i)=g[i][j]$（引理 1）。对 $j<V_i$ 的位置，本轮不写，而 $g[i][j]=g[i-1][j]$（引理 1 的第一分支），值不变也正确。所有位置逐一成立，本轮结束即得 $g[i][\cdot]$。对 $i$ 归纳（基例 $i=0$：`dp` 全 0 $=g[0][\cdot]$），$H$ 轮后 `dp[j]`$=g[H][j]$。证毕。

**引理 3（正序的错误：具体反例）。** 若 $j$ 从 $V_i$ **递增**到 $C$，同一物品可能被重复计入。反例：$C=12$，只有一捆 $V_1=6$。正序先算 `dp[6]=max(dp[6],dp[0]+6)=6`，再算 `dp[12]=max(dp[12],dp[6]+6)=12`——但 `dp[6]` 已经是"买了这捆"的状态，再加一次等于买了两捆。正确答案是 6，正序给出 12。

*证明（一般机理）*：正序更新 $j$ 时，$j-V_i<j$ 已被本轮更新过，`dp[j-V_i]` 可能已含物品 $i$，于是 `dp[j-V_i]+V_i` 含两份 $i$，违反 0/1 约束。倒序则保证读取的永远是"上一轮"的值（引理 2），每件物品至多被计入一次。证毕。

（顺带看清了 0/1 与完全背包的唯一区别：完全背包**允许**重复，所以故意正序，让 `dp[j-V_i]` 用本轮新值；0/1 禁止重复，所以倒序。本题每捆只有一捆，必须倒序。）

### 第四步：初始化的陷阱反转——discuss by category

风格指南反复强调"全局 int 数组默认 0 不是 INF，必须显式 fill"。但本题**恰好相反**：`dp[j]` 的语义是"最大体积"，**空集体积 0 是每个容量的合法下界**，$g[0][j]=0$ 正是我们要的初值！全局零初始化在这里**天然正确**，不需要也不应该 fill 成 INF（fill 成 INF 反而会把"不可达"的语义强加给一个永远可达的状态——任何容量都至少能装空集）。

**教训**：哨兵初始化与否取决于状态语义。"最小化 + 不可达"要 INF；"最大化 + 空方案合法"要 0。本题属于后者，代码里用注释标明，防止 review 时被"好心"改成 INF。

### 第五步：价值 = 重量的特殊性——可选的 bitset 加速

回到第一步的观察：`dp[j]` 其实只关心"$j$ 以内哪些子集和可达"。令布尔数组 $b[s]$ = 存在子集和恰为 $s$，则每读一捆 $v$：$b \mathrel{|}= b\ll v$（每个旧可达和 $s$ 派生新可达和 $s+v$），最后答案是 $\le C$ 的最大可达 $s$。用 `bitset<50005>` 实现，每捆只需 $C/64\approx782$ 次字操作，总量 $O(CH/64)\approx4\times10^6$，比朴素 DP 快约两个数量级。

**引理 4（bitset 递推与答案）。** 设 $b_i[s]=1\iff$ 前 $i$ 捆存在子集和恰为 $s$。则 $b_0[0]=1$、其余 0；$b_i[s]=b_{i-1}[s]\lor b_{i-1}[s-V_i]$（$s\ge V_i$ 时，否则第二项为 0），恰为 `b|=b<<v` 的逐位语义。答案 $=\max\{s\le C:b_H[s]=1\}$。

*证明*：子集按是否含第 $i$ 捆分类：不含 ⇒ 和 $s$ 由前 $i-1$ 捆达成（$b_{i-1}[s]$）；含 ⇒ 其余部分和为 $s-V_i$（$b_{i-1}[s-V_i]$）。两类穷尽且互不干扰（这里 $b_{i-1}$ 是**上一轮**的快照，`bitset` 的 `b|=b<<v` 右侧先整体求值再或回去，天然避免引理 3 的重复计入问题）。答案：题目要求 $\le C$ 的最大子集和，正是 $\le C$ 的最大可达 $s$；又 $g[H][C]=\max\{s\le C:b_H[s]=1\}$（最大体积方案的体积本身就是一个可达和，且任何 $\le C$ 的可达和都是可行方案），两种算法答案一致。证毕。

朴素 0/1 背包 $2.5\times10^8$ 次 `max` 在 `-O2` 下可通过（内层倒序循环读写不冲突、可向量化），且是本题标签所指的标准解法，故参考实现采用它；bitset 版作为极限卡常时的备选，思路已在引理 4 中证明。

**引理 5（复杂度与值域）。** 朴素版时间 $O(CH)$，空间 $O(C)$；所有值 $\le C\le5\times10^4$，`int` 安全。

*证明*：$H$ 轮、每轮至多 $C$ 次 $O(1)$ 更新，合计 $\le CH=2.5\times10^8$。`dp` 值是不超过 $j\le C$ 的子集和，$\le5\times10^4$；`dp[j-v]+v` 中间量 $\le C$（只在 $j\ge v$ 时计算，`dp[j-v]`$\le j-v$），无溢出。空间一个长 $C+1$ 的 int 数组，约 200 KB。证毕。

### 定理

程序输出不超过 $C$ 的最大可达子集和，即能买到的最大稻草体积。

*证明*：引理 1 建立二维最优子结构；引理 2 证明倒序一维滚动逐轮精确复现二维递推；引理 3 排除正序（重复计入）的错误写法；第四步确认零初始化合法；引理 5 给出复杂度与值域。故 `dp[C]`$=g[H][C]$ 就是答案。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 价值 = 重量的 0/1 背包，等价于"不超过 $C$ 的最大可达子集和"。
2. **classic problem solution** — 二维 0/1 背包递推：按"第 $i$ 捆选/不选"分类，两类各自取到最优，夹出 max 递推式。
3. **reduce to easier problem** — 滚动掉第一维；倒序循环保证读到的 `dp[j-v]` 是上一轮值，每捆至多计一次（归纳证明不变量）。
4. **consider easier version** — 用单捆反例（$C=12,V=6$）暴露正序 = 完全背包的重复计入错误，确认倒序是 0/1 的命门。
5. **discuss by category** — 初始化语义反转：最大化 + 空集合法 ⇒ 全局默认 0 恰好正确，不能 fill INF。
6. **classic problem solution** — 子集和视角的 bitset 加速：`b|=b<<v`，$O(CH/64)$，答案取 $\le C$ 的最高置位（可选卡常）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $C,H$ | 容量 $\le5\times10^4$、捆数 $\le5000$ | `int c,h` | 读入（注意顺序：先 $C$ 后 $H$） |
| `mxc` | $50000+5$ | `constexpr int` | DP 数组尺寸 |
| `dp[j]` | 已读捆中、总体积 $\le j$ 的最大总体积 | `int[mxc]` | **全局默认 0 即正确初值**（空集），不 fill INF |
| `v` | 当前捆体积 | `int` | 每捆读入后立即做一轮 DP，无需存全部体积 |
| `j` | 容量下标 | `int` | **从 `c` 递减到 `v`**（倒序是 0/1 的命门） |

### 算法步骤

1. I/O 加速三行；读 $C,H$。
2. 对每捆：读 $v$；`for(j=c;j>=v;--j) dp[j]=max(dp[j],dp[j-v]+v)`。
3. 输出 `dp[c]`。

### 复杂度

- 时间 $O(CH)\le2.5\times10^8$（`-O2` 下内层循环可向量化，极限规模实测远低于时限）；空间 $O(C)$，约 200 KB。
- 可选 bitset 版 $O(CH/64)\approx4\times10^6$（引理 4）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；四组手造数据（枚举组=9、单捆防重复组=6、全装组=6、$H=1$ 组=5）输出与手算一致；$C=50000,H=5000$ 极限规模随机数据运行通过。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2925 [USACO08DEC] Hay For Sale S
// 价值=重量的 0/1 背包：dp[j]=容量 j 内最大可达子集和。
// 倒序循环 ⇒ dp[j-v] 是上一轮的值 ⇒ 每捆至多买一次。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxc{50005};

int c,h,dp[mxc];	// 最大化+空集合法 ⇒ 全局默认 0 恰好是正确初值，别 fill INF

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>c>>h;
	for(int i=0,v;i<h;++i)
	{
		cin>>v;
		for(int j=c;j>=v;--j)
			dp[j]=max(dp[j],dp[j-v]+v);	// 倒序！正序会重复买同一捆
	}
	cout<<dp[c]<<'\n';
	return 0;
}
```

### 代码说明

- **倒序是本题唯一的算法命门**：引理 2 证明倒序时 `dp[j-v]` 尚未被本轮更新，读到的恰是"前 $i-1$ 捆"的状态；引理 3 的单捆反例（$C=12,V=6$ 正序得 12）说明正序就是完全背包。
- `dp` 零初始化**合法且必须**：任何容量都能装空集（体积 0），这是最大化问题的天然下界。与"最小化 + 不可达要 fill INF"的陷阱正好相反，注释里写明防止误改。
- 边读边 DP：每捆读入后立即更新一轮，不需要存下全部 $V_i$，空间只有 `dp` 一个数组。
- `j>=v` 的循环下界同时处理了"$j<V_i$ 时物品装不下、`dp[j]` 保持原值"的分支（引理 1 第一分支），无需额外 if。
- 若评测机极卡常，可换 bitset 子集和写法（引理 4）：`bitset<50005>b; b[0]=1;` 每捆 `b|=b<<v;`，最后从 $C$ 向下找第一个置位。
