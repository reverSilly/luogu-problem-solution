# P2335 [SDOI2005] 位图 — 题解

## 一、解题过程：人类思考叙事

题意很直白：给一个 $n\times m$ 的 0/1 矩阵，至少有一个 $1$（白点）。对每个格子 $(i,j)$，求它到**最近的**白点的曼哈顿距离

$$d\big((i_1,j_1),(i_2,j_2)\big)=|i_1-i_2|+|j_1-j_2|,$$

并把整张表输出。$n,m\le150$。

**第一步：最笨的做法与它的代价。**

对每个格子，枚举所有白点，取距离最小值。设白点有 $W$ 个，复杂度 $O(nmW)\le O(n^2m^2)$。当 $n=m=150$ 时是 $150^4\approx5.06\times10^8$ 次绝对值运算——常数很小，也许能卡过去，但它显然在做大量重复劳动：相邻两个格子到同一个白点的距离只差 $1$，没必要各自从头枚举。

**第二步：把"到最近白点的距离"翻译成图论语言。**

把每个格子看成顶点，上下左右相邻的格子之间连一条长度 $1$ 的边。因为网格没有障碍（每个格子都存在），从白点 $w$ 走到格子 $v$ 的最少步数恰好是曼哈顿距离。于是

$$f(v)=\min_{w\text{ 为白点}} \operatorname{dist}(v,w),$$

也就是**从"所有白点"这个集合出发到 $v$ 的最短路**。

**第三步：多源 BFS。**

单源最短路用 BFS；多源怎么办？把所有白点**同时**作为起点：初始时把每个白点的 `dis` 置 $0$ 并全部入队，然后做普通 BFS。直观上相当于在网格外再加一个虚拟源点 $S$，$S$ 到每个白点连一条权为 $0$ 的边；$S$ 到 $v$ 的最短路就是 $f(v)$。我们不真的建 $S$，而是把"$S$ 的邻点已经全部以距离 $0$ 入队"这件事直接写进初始化。

**第四步：为什么不用 Dijkstra、也不用两遍扫描 DP？**

- 所有网格边权都是 $1$，BFS 的"按层扩展"天然给出最短路，Dijkstra 是杀鸡用牛刀。
- 确实存在 $O(nm)$ 的两遍扫描做法（从上到下、从下到上各做一次距离递推），但多源 BFS 更直接，也不依赖"距离是曼哈顿距离"这一具体形式；本题标签也正是 BFS。

**第五步：实现坑点。**

- `dis` 要初始化为 $-1$ 表示未访问；白点先置 $0$，这样白点不会被重复赋值。
- 至少有一个白点由题面保证；若没有，全图都不可达，但无需处理这种情况。
- 输出是 $n$ 行、每行 $m$ 个数，数之间用空格分隔。
- 队列里存一维编号 $i\cdot m+j$，出队时用 `/m`、`%m` 还原行列，避免存 `pair`。

## 二、思维链：完整证明

**引理 1（网格最短路 = 曼哈顿距离）**：在 $n\times m$ 的完整网格图上（四邻接、每边长度 $1$），任意两格 $p=(i_1,j_1)$、$q=(i_2,j_2)$ 之间的最短路长度等于 $|i_1-i_2|+|j_1-j_2|$。

*证明*：分两个方向。

- **下界**：每走一步，行坐标或列坐标恰有一个改变 $1$，因此 $|i-i_2|+|j-j_2|$ 这个量每一步最多减少 $1$。从 $p$ 出发它等于 $|i_1-i_2|+|j_1-j_2|$，到达 $q$ 时它等于 $0$，所以至少要走 $|i_1-i_2|+|j_1-j_2|$ 步。
- **上界**：先沿行方向走 $|i_1-i_2|$ 步到 $(i_2,j_1)$，再沿列方向走 $|j_1-j_2|$ 步到 $(i_2,j_2)$。网格中每一格都存在，路径不会出界，总步数恰为 $|i_1-i_2|+|j_1-j_2|$。

上下界相同，引理得证。证毕。

**引理 2（BFS 出队顺序单调）**：多源 BFS 中，任意时刻队列内的 `dis` 值单调不减，且至多取两个相邻的整数值；因此顶点出队的 `dis` 值单调不减。

*证明*：对操作次数归纳。初始时队列里全是 $0$，成立。设当前不变式成立，队首 `dis` 为 $d$。

- 由"至多两个相邻值"知队列中其余元素的 `dis` 只能是 $d$ 或 $d+1$。
- 弹出队首后，把它所有未访问的邻居以 $d+1$ 入队并放到队尾；这些新元素的 `dis` 都是 $d+1$，接在原有（$\ge d$ 且 $\le d+1$）元素之后，队列仍单调不减且只有 $d,d+1$ 两种值（若原队列还有 $d$，则新队列是 $d,\dots,d,d+1,\dots,d+1$；否则全是 $d+1$）。

不变式保持，故出队顺序的 `dis` 单调不减。证毕。

**引理 3（多源 BFS 赋值的下界）**：BFS 给任意格子 $v$ 赋的值 `dis[v]` 满足 `dis[v]` $\ge f(v)$。

*证明*：BFS 赋值的来源是一条从某个白点出发、逐格相邻的行走路径：白点初始 `dis=0`，此后每次赋值都是"已赋值格子 $u$ 的邻居 $v$ 赋值 `dis[u]+1`"，对应在 $u$ 的路径末尾接上一步。因此赋值 $d$ 意味着存在一条从某白点到 $v$、长度为 $d$ 的网格路径，故 $f(v)\le d$。证毕。

**引理 4（多源 BFS 赋值的上界）**：对每个整数 $k\ge0$，所有满足 $f(v)\le k$ 的格子最终都会被赋值，且 `dis[v]` $\le k$。

*证明*：对 $k$ 归纳。

- $k=0$：$f(v)=0$ 当且仅当 $v$ 本身是白点，初始化时已置 `dis=0`。
- 设命题对 $k-1$ 成立，考虑 $f(v)=k$（$f(v)<k$ 的格子由归纳假设已被赋值且 $\le k-1\le k$）。取一条从某白点到 $v$ 的最短路径，设 $u$ 是路径上 $v$ 的前一个格子，则该路径前段是到 $u$ 的长度 $k-1$ 的路径，故 $f(u)\le k-1$；又若 $f(u)<k-1$，在这条路径后接一步就得到到 $v$ 的长度 $<k$ 的路径，与 $f(v)=k$ 矛盾，所以 $f(u)=k-1$。由归纳假设，$u$ 最终被赋值且 `dis[u]` $\le k-1$，从而 $u$ 会入队并被弹出。

  考察 $u$ 被弹出的时刻：
  - 若此时 $v$ 尚未被赋值，则 $v$ 作为 $u$ 的未访问邻居被赋 `dis[u]+1` $\le k$；
  - 若 $v$ 已被赋值，设赋值它的是格子 $u'$，则 `dis[v]=dis[u']+1`。$u'$ 先于 $u$ 出队，由引理 2 的出队单调性，`dis[u']` $\le$ `dis[u]` $\le k-1$，故 `dis[v]` $\le k$。

  两种情形都得到 `dis[v]` $\le k$，归纳完成。证毕。

**定理（BFS 输出正确）**：BFS 结束后，对每个格子 $v$ 都有 `dis[v]` $=f(v)$。

*证明*：取 $k=f(v)$。由引理 4，`dis[v]` $\le f(v)$；由引理 3，`dis[v]` $\ge f(v)$。两者夹逼得等号。证毕。

**引理 5（终止与全覆盖）**：BFS 一定终止，且由于题面保证至少有一个白点，每个格子最终都会被赋值。

*证明*：每个格子最多入队一次（入队前必然从 $-1$ 被改成非负），队列长度有限，故 BFS 终止。矩形网格作为四邻接图是连通的：任意两格可按引理 1 的构造沿网格走通，因此从某个白点出发可以到达所有格子；结合引理 4（取 $k=f(v)$，它是有限数），每个格子都会被赋值。证毕。

**复杂度**：每个格子入队、出队各一次，每次考察 $4$ 个邻居，时间 $O(nm)$；`g`、`dis`、`Q` 都是 $O(nm)$ 规模，空间 $O(nm)$。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "到最近白点的距离" = 以所有白点为起点的多源最短路。
- **consider easier version** — 先想逐格枚举所有白点，$O(n^2m^2)$ 太重复。
- **reduce to easier problem** — 把网格建成四邻接、边权全为 $1$ 的图，距离化为最短路。
- **classic problem solution** — 多源 BFS：所有白点 `dis=0` 同时入队，按层扩展。
- **explore its property** — 虚拟超级源 + 0 权边，说明"全部白点入队"为什么正确。
- **classic problem solution** — 用出队单调性 + 归纳证明 BFS 赋的值恰为最近距离。
- **explore its property** — 完整网格无阻碍，图距离就是题面给的曼哈顿距离。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 说明 |
|------|------|-------------|
| $n,m$ | 行数、列数 | 输入 |
| `g[i][j]` | 格子字符，`'1'` 白、`'0'` 黑 | 逐字符读入 |
| `dis[i][j]` | 到最近白点的距离；$-1$ 表示未访问 | `memset` 为 $-1$，白点置 $0$ |
| `Q[ ]` | 手写队列，存一维编号 $i\cdot m+j$ | 头 `hd`、尾 `tl`，初值 $0$ |
| `dx[4],dy[4]` | 上下左右四个方向 | 常量 |
| `hd,tl` | 队头、队尾指针 | 初值 $0$ |

### 算法步骤

1. 读入 $n,m$ 与 $n\times m$ 个字符。
2. `dis` 全部置 $-1$。
3. 扫描全图，把所有 `'1'` 格子的 `dis` 置 $0$ 并入队。
4. 当队列非空：弹出队首 $u$，还原行列 $(x,y)$；对四个邻居，若在界内且 `dis` 仍为 $-1$，置 `dis=dis[x][y]+1` 并入队。
5. 按行输出 `dis`，同一行数字间用空格分隔，行末换行。

### 复杂度

- 时间：$O(nm)$。
- 空间：$O(nm)$。

### 验证状态

- 用 `/d/mingw64/bin/g++.exe -std=c++20 -O2 -Wall -Wextra` 编译通过，无警告。
- 手造数据：`1 1 / 1` → `0`；`2 2 / 10 / 00` → `0 1 / 1 2`；单白点在角上的 $3\times3$ 全黑图，输出距离场符合预期。
- 对拍：随机生成 $n,m\le8$ 且至少一个白点的位图，暴力对每个格子扫描所有白点取曼哈顿距离最小值，与标程逐格比对 **2000 组全部一致**（同时校验了输出解析与格式）。
- 题面无样例，以上手造数据替代。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{155};

int n,m;
char g[mxn][mxn];
int dis[mxn][mxn],Q[mxn*mxn];
const int dx[4]={-1,1,0,0};
const int dy[4]={0,0,-1,1};

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			cin>>g[i][j];
	memset(dis,-1,sizeof(dis));
	int hd=0,tl=0;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			if(g[i][j]=='1')
			{
				dis[i][j]=0;
				Q[tl++]=i*m+j;
			}
	while(hd<tl)
	{
		int u=Q[hd++],x=u/m,y=u%m;
		for(int k=0;k<4;++k)
		{
			int tx=x+dx[k],ty=y+dy[k];
			if(tx<0||tx>=n||ty<0||ty>=m)
				continue;
			if(dis[tx][ty]!=-1)
				continue;
			dis[tx][ty]=dis[x][y]+1;
			Q[tl++]=tx*m+ty;
		}
	}
	for(int i=0;i<n;++i)
	{
		for(int j=0;j<m;++j)
			cout<<dis[i][j]<<' ';
		cout<<'\n';
	}
	return 0;
}
```
