# P2883 [USACO07MAR] Cow Traffic S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 个路口（$N\le 5\times10^3$）、$M$ 条单向道路（$M\le 5\times10^4$），每条边 $U_i\to V_i$ 满足 $U_i<V_i$（所以图是 DAG，且**编号本身就是一个拓扑序**），可能有重边。入度为 $0$ 的点是"放牧点"（源点），牛圈固定在 $N$ 号点。每头牛从某个源点出发，沿有向边走到 $N$。对每条边，统计"所有源点→$N$ 的路径中，经过这条边的路径条数"，输出这个计数的**最大值**。题目保证答案 $\le 2^{31}-1$（32 位有符号整数范围）。

剥掉背景，这就是一道 **DAG 上"边流量"计数**题：把"路径数"当成流量，源点注入、$N$ 号点吸收，求流量最大的那条边。

**第一步：暴力为什么不行。** 最直接的想法是 DFS 枚举每一条源点→$N$ 的路径，给路径上的每条边计数 $+1$。但 DAG 的路径条数可以是指数级甚至 $3^{N/3}$ 级（后面引理 7 会构造），枚举路径必然超时。标签写着"DP、递推、拓扑排序"，提示我们要**按拓扑序递推计数**，而不是枚举路径。

**第二步：一条边上的路径数怎么拆。** 考虑一条固定的边 $e=(u,v)$。任何经过 $e$ 的源点→$N$ 路径，都唯一地分成三段：

$$\underbrace{\text{源点}\rightsquigarrow u}_{\text{前缀}}\ \xrightarrow{\ e=(u,v)\ }\ \underbrace{v\rightsquigarrow N}_{\text{后缀}}.$$

因为是 DAG（无环），前缀里不会含 $v$、后缀里不会含 $u$，两段**互不干扰**：任选一条"源点→$u$"的路径、再任选一条"$v$→$N$"的路径，拼上 $e$ 就得到一条合法的源点→$N$ 路径，且不同选择给出不同路径。于是

$$\text{flow}(u,v)=\bigl(\text{源点}\to u\text{ 的路径数}\bigr)\times\bigl(v\to N\text{ 的路径数}\bigr).$$

记 $f[u]=$ 源点→$u$ 的路径数，$g[v]=v\to N$ 的路径数，则 $\text{flow}(u,v)=f[u]\cdot g[v]$。**这一步是全题的支点**：把"经过某边的路径数"这个看似要枚举的量，拆成两个独立计数的乘积。

**第三步：$f$ 和 $g$ 都是经典 DAG 路径计数。**

- $f$ 顺着拓扑序推：源点 $f=1$（空路径，就地出发）；非源点 $f[u]=\sum_{(w,u)}f[w]$（按"最后一步从哪来"分类）。因为边恒 $w<u$，**按编号从小到大**扫就是拓扑序，不用真的建队列。
- $g$ 逆着拓扑序推：$g[N]=1$（空路径，就地到达）；$g[u]=\sum_{(u,v)}g[v]$（按"第一步往哪去"分类）。**按编号从大到小**扫即可。

两者都是 $O(N+M)$。答案就是 $\max_{(u,v)\in E}f[u]\cdot g[v]$。

**第四步：真正的陷阱——溢出，而且保证只保答案。** 兴冲冲用 `long long` 写完，要停下来问：题目保证的是**答案**（最大边流量）$\le 2^{31}-1$，**没有**保证 $f[u]$、$g[v]$ 各自不溢出。这两个量会不会爆？

分两类点看：

- **能到 $N$ 的点（"活点"，$g>0$）**：对活点 $u\ne N$，它至少有一条出边 $(u,v)$ 使 $g[v]\ge1$，于是 $\text{flow}(u,v)=f[u]\cdot g[v]\ge f[u]$。而 $\text{flow}\le$ 答案 $\le 2^{31}-1$，所以 $f[u]\le 2^{31}-1$，**活点的 $f$ 被答案死死压住**。$f[N]$ 稍大（是所有入边流量之和），但 $\le M\cdot(2^{31}-1)\approx10^{14}$，仍在 `long long` 内。
- **到不了 $N$ 的点（"死点"，$g=0$）**：这些点上的路径**永远走不到牛圈**，对任何边的流量贡献都是 $f[u]\cdot 0=0$。但死点自己的 $f[u]$（源点→它的路径数）可以是天文数字——DAG 路径数上界约 $3^{N/3}$，$N=5000$ 时约 $10^{794}$，**远超 `long long`**。如果傻乎乎地给死点也递推 $f$，累加过程就会溢出（有符号溢出是 UB）。

破局点：**死点的 $f$ 根本不需要算**。在正序推 $f$ 时加一句 `if(!g[u]) continue;`，跳过所有死点。这样 $f$ 只在活点上递推，而活点的 $f$ 已被证明 $\le M\cdot(2^{31}-1)$，`long long` 绰绰有余。

为什么跳过死点不影响活点的 $f$？因为若 $v$ 是活点、$(u,v)$ 是边，则 $u$ 经 $v$ 能到 $N$，$u$ 也是活点。**活点的所有入边都来自活点**，死点从不给活点贡献，跳过它们完全无害。

至于 $g$，可以**不加守卫**地对所有点算：因为 DAG 里**每个点都能从某个源点到达**（沿入边回溯必到入度 $0$ 点），所以每个点都"源点可达"，对称地可证 $g[u]\le M\cdot(2^{31}-1)$，不会爆（引理 6）。

**第五步：几个细节。**

1. **重边要保留**：两条 $u\to v$ 是两条不同的路，邻接表里存两次，递推时自然各贡献一次。用 `set` 去重会错。
2. **源点判定**：读入时统计 `indeg`，`indeg[u]==0` 即源点，$f[u]$ 初始化为 $1$。
3. **$N$ 号点**：$g[N]=1$ 是递推起点；$f[N]$ 会被算出来（$N$ 是活点），但答案只看边流量，$f[N]$ 本身不直接输出。
4. **0-based**：读入 `--u;--v`，$N$ 号点对应下标 `n-1`。
5. **答案初值**：`ans=0`。若所有边都是死边（流量 $0$），答案就是 $0$，合法。

**手造数据核对。** 题面"样例解释"给了四条经过 $6\to7$ 的路径，据此反推图（$N=7$，边 $1\to3,2\to3,3\to4,3\to5,4\to6,5\to6,6\to7$）：

```
4
```

手算：$f[6]=4$（$1,2$ 各经 $4,5$ 两条到 $6$），$g[7]=1$，$\text{flow}(6,7)=4$，其余边流量 $\le2$，最大 $4$，与解释吻合。

另造三组打边界：

- 重边：$N=4$，边 $1\to2,1\to2,2\to4,3\to4$。$f[2]=2$（两条重边），$\text{flow}(2,4)=2\cdot1=2$，答案 $2$。验证重边各算一次。
- 死区：$N=6$，边 $1\to2,1\to3,2\to4,3\to4,5\to6$。点 $1,2,3,4$ 到不了 $6$（死区），只有 $5\to6$ 是活边，答案 $1$。验证死区被正确忽略。
- 溢出压测：构造 $69$ 层"梯子"死区（$140$ 个点，约 $2^{69}$ 条路径，远超 `long long`）$+$ 一条活边 $141\to142$。答案仍为 $1$，证明守卫 `if(!g[u])continue` 真的挡住了死区溢出。

## 二、思维链：完整证明

**记号。** 点下标 $0\le u<N$（读入已转 0-based，牛圈是 $N-1$）。边集 $E$（含重边，按重数计）。$f[u]=$ 从**任意源点**（入度 $0$ 点）到 $u$ 的有向路径条数（含源点到自身的空路径，计 $1$）；$g[u]=$ 从 $u$ 到牛圈 $N-1$ 的有向路径条数（含空路径，计 $1$）。$\text{flow}(u,v)=f[u]\cdot g[v]$。答案 $\mathrm{Ans}=\max_{(u,v)\in E}\text{flow}(u,v)$，题设 $\mathrm{Ans}\le 2^{31}-1$。称 $g[u]>0$ 的点为**活点**（能到牛圈），$g[u]=0$ 为**死点**。

---

### 引理 1（边流量的乘积公式）

对任意边 $e=(u,v)\in E$，经过 $e$ 的"源点→牛圈"路径条数恰为 $f[u]\cdot g[v]$。

*证明*：构造双射。设 $\mathcal P_e$ 为经过 $e$ 的源点→牛圈路径集合，$\mathcal A$ 为源点→$u$ 路径集合（$|\mathcal A|=f[u]$），$\mathcal B$ 为 $v$→牛圈路径集合（$|\mathcal B|=g[v]$）。

**映射 $\Phi:\mathcal A\times\mathcal B\to\mathcal P_e$**：把 $\alpha\in\mathcal A$、边 $e$、$\beta\in\mathcal B$ 首尾拼接。需证拼接结果是合法路径（无重复点）。$\alpha$ 的点都 $\le u$（边恒低→高，$\alpha$ 终点是 $u$，故 $\alpha$ 上点编号 $\le u$）；$\beta$ 的点都 $\ge v>u$。两段点集不相交，且 $\alpha$ 不含 $v$、$\beta$ 不含 $u$，拼接后仍严格递增、无环，是合法 DAG 路径，且经过 $e$。故 $\Phi$ 良定义。

**单射**：若 $\Phi(\alpha_1,\beta_1)=\Phi(\alpha_2,\beta_2)$，这条路径在 $e$ 处唯一地切成前缀（到 $u$）与后缀（从 $v$），故 $\alpha_1=\alpha_2$、$\beta_1=\beta_2$。

**满射**：任取 $P\in\mathcal P_e$，$P$ 经过 $e$，在 $e$ 处切开得前缀 $\alpha$（源点→$u$）与后缀 $\beta$（$v$→牛圈），$\Phi(\alpha,\beta)=P$。

双射成立，故 $|\mathcal P_e|=|\mathcal A|\cdot|\mathcal B|=f[u]\cdot g[v]$。证毕。

**推论**：$\mathrm{Ans}=\max_{(u,v)\in E}f[u]\cdot g[v]$，只需求出所有 $f,g$ 再扫一遍边。

---

### 引理 2（$f$ 的正序递推正确）

按编号 $u=0,1,\dots,N-1$ 顺序，令源点 $f[u]=1$、非源点 $f[u]=\sum_{(w,u)\in E}f[w]$，则结果等于真实 $f[u]$。

*证明*：先证**编号序是拓扑序**：每条边 $(w,u)$ 满足 $w<u$，故处理 $u$ 时所有入邻居 $w<u$ 已处理完毕，$f[w]$ 已是最终值。

再对 $u$ 归纳证明 $f[u]$ 等于真实路径数。源点（入度 $0$）：到它的路径只有空路径，计 $1$，代码置 $f[u]=1$ ✓。非源点 $u$：任何源点→$u$ 路径必有最后一条边 $(w,u)$，按这条边分类，各类路径数 $=$（源点→$w$ 路径数）$=f[w]$（去掉最后一步是双射，同引理 1 的切分论证）。各类不重不漏（最后一条边唯一），故 $f[u]=\sum_{(w,u)}f[w]$。由归纳假设各 $f[w]$ 正确，故 $f[u]$ 正确。重边在邻接表里出现多次，求和时按重数各计一次，与"不同边是不同路径"一致。证毕。

---

### 引理 3（$g$ 的逆序递推正确）

令 $g[N-1]=1$，按编号 $u=N-2,\dots,0$ 顺序置 $g[u]=\sum_{(u,v)\in E}g[v]$，则结果等于真实 $g[u]$。

*证明*：边 $(u,v)$ 满足 $v>u$，逆序处理 $u$ 时所有出邻居 $v>u$ 已处理，$g[v]$ 已定。对 $u$ 从大到小归纳。牛圈 $N-1$：到自身的路径只有空路径，$g=1$ ✓。其余 $u$：任何 $u$→牛圈路径必有第一条边 $(u,v)$，按它分类，各类路径数 $=g[v]$（去掉第一步是双射）。故 $g[u]=\sum_{(u,v)}g[v]$。特别地，若 $u$ 无出边或所有出邻居都是死点，则 $g[u]=0$（到不了牛圈），与定义一致。证毕。

---

### 引理 4（每个点都源点可达）

DAG 中任意点 $u$ 都存在某个源点 $s$ 使 $s\rightsquigarrow u$，即真实 $f[u]\ge1$。

*证明*：从 $u$ 出发沿入边回溯：若当前点入度 $0$ 则它是源点，停止；否则任取一条入边 $(w,\cdot)$ 走到 $w$。因边恒低→高，回溯严格递减编号，不可能无限进行，必在有限步内停在某个入度 $0$ 点 $s$。反转这条回溯链即得 $s\rightsquigarrow u$ 的路径，故 $f[u]\ge1$。证毕。

**用途**：这条引理保证 $g$ 的界（引理 6）对**所有**点成立，无需守卫。

---

### 引理 5（活点的 $f$ 被答案压住）

对活点 $u$（$g[u]>0$）：若 $u\ne N-1$ 则 $f[u]\le\mathrm{Ans}\le 2^{31}-1$；$f[N-1]\le M\cdot\mathrm{Ans}$。

*证明*：**情形 $u\ne N-1$**：$g[u]=\sum_{(u,v)}g[v]>0$，故存在出边 $(u,v)$ 使 $g[v]\ge1$。由引理 1，$\text{flow}(u,v)=f[u]\cdot g[v]\ge f[u]\cdot1=f[u]$。又 $\text{flow}(u,v)\le\mathrm{Ans}$，故 $f[u]\le\mathrm{Ans}\le2^{31}-1$。

**情形 $u=N-1$**：$g[N-1]=1$，故 $f[N-1]=\sum_{(w,N-1)}f[w]=\sum_{(w,N-1)}f[w]\cdot g[N-1]=\sum_{(w,N-1)}\text{flow}(w,N-1)$。每条入边流量 $\le\mathrm{Ans}$，入边数（含重边）$\le M$，故 $f[N-1]\le M\cdot\mathrm{Ans}\le 5\times10^4\times(2^{31}-1)\approx1.07\times10^{14}$。证毕。

---

### 引理 6（所有点的 $g$ 都不溢出）

对任意点 $u$，$g[u]\le M\cdot\mathrm{Ans}\le1.07\times10^{14}$，故用 `long long` 计算 $g$ 永不溢出。

*证明*：死点 $g[u]=0$，平凡。**活点 $u$**：由引理 4，$f[u]\ge1$。

- 若 $u$ 有入边 $(w,u)$：$\text{flow}(w,u)=f[w]\cdot g[u]\ge1\cdot g[u]=g[u]$（$f[w]\ge1$ 由引理 4），故 $g[u]\le\text{flow}(w,u)\le\mathrm{Ans}$。
- 若 $u$ 是源点（无入边）：$f[u]=1$，$g[u]=\sum_{(u,v)}g[v]=\sum_{(u,v)}f[u]\cdot g[v]=\sum_{(u,v)}\text{flow}(u,v)\le M\cdot\mathrm{Ans}$。

两种情形都 $\le M\cdot\mathrm{Ans}\approx1.07\times10^{14}<9.22\times10^{18}$（`long long` 上限）。故 $g$ 全程无溢出，**不需要守卫**。证毕。

---

### 引理 7（死点的 $f$ 可超 `long long`，守卫必要且无害）

(a) 存在合法输入使某死点 $u$ 的真实 $f[u]>2^{63}-1$；(b) 跳过死点不改变任何活点的 $f$；(c) 跳过死点后所有被计算的 $f$ 值 $\le M\cdot\mathrm{Ans}$，无溢出。

*证明*：**(a) 构造**：取"梯子"图——$2k$ 个点分成 $k$ 层，每层 $2$ 点，相邻层之间 $4$ 条边（完全二部）。从第 $1$ 层到第 $k$ 层的路径数为 $2^{k-1}\cdot2=2^k$ 量级（每层 $2$ 种选择）。取 $k=69$，$138$ 个点（$\le N=5000$），路径数 $\approx2^{69}>2^{63}-1$。把这套梯子放在编号 $1..138$，再放一条独立活边 $139\to140$（牛圈 $=140$）。梯子所有点到不了牛圈，是死点，其 $f$ 达 $2^{69}$，超 `long long`。故不加守卫地递推死点 $f$ 会溢出（有符号溢出是 UB）。

**(b) 无害**：设 $v$ 是活点（$g[v]>0$），$(u,v)$ 是边。则 $u$ 经 $v$ 可达牛圈，$g[u]\ge g[v]>0$，$u$ 也是活点。故活点的入邻居全是活点，死点从不向活点推送 $f$。跳过死点（`if(!g[u])continue`）不影响任何活点 $f$ 的累加。

**(c) 界**：被计算的只有活点 $f$，由引理 5，$\le M\cdot\mathrm{Ans}\approx1.07\times10^{14}$，`long long` 安全。证毕。

---

### 引理 8（答案正确与复杂度）

代码输出 $\max_{(u,v)\in E}f[u]\cdot g[v]$（活点 $f$ 已算、死点 $f=0$），等于真实 $\mathrm{Ans}$；时间 $O(N+M)$，空间 $O(N+M)$。

*证明*：**正确性**：对活边 $(u,v)$（$g[v]>0$），$u,v$ 皆活，$f[u],g[v]$ 由引理 2、3、7(b) 正确，乘积 $=$ 真实流量（引理 1）。对死边 $(u,v)$（$g[v]=0$），真实流量 $=f[u]\cdot0=0$；代码里 $u$ 也是死点（$u\to v$ 死⇒$u$ 死），$f[u]=0$（被跳过未赋值，全局默认 $0$），乘积 $0\cdot0=0$，一致。故每条边的乘积都等于真实流量，取 max 即 $\mathrm{Ans}$。

**乘积无溢出**：活边乘积 $=$ 真实流量 $\le\mathrm{Ans}\le2^{31}-1$；死边乘积 $0$。都在 `long long` 内（虽然 $f[u],g[v]$ 各自的界较松，但其乘积被答案压住）。

**复杂度**：读入建图 $O(M)$；$g$ 递推扫每条边一次 $O(N+M)$；$f$ 递推同理 $O(N+M)$；扫边求 max $O(M)$。合计 $O(N+M)$。空间：邻接表 $O(N+M)$，$f,g,\text{indeg}$ 各 $O(N)$，边数组 $O(M)$，合计 $O(N+M)$。代入 $N=5000,M=5\times10^4$，约 $10^5$ 级操作，极快。证毕。

---

### 定理

程序输出所有源点→牛圈路径中、经过某条边的路径数的最大值，全程 `long long` 无溢出，复杂度 $O(N+M)$。

*证明*：引理 1 把边流量化为 $f[u]\cdot g[v]$；引理 2、3 保证 $f,g$ 递推正确；引理 4 保证每点源点可达；引理 5、6 分别压住活点 $f$ 与所有 $g$ 的范围；引理 7 证明死点 $f$ 会溢出但守卫必要且无害；引理 8 串联得答案正确、乘积无溢出、复杂度 $O(N+M)$。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 边恒低→高 ⇒ 图是 DAG，且**编号即拓扑序**，递推不用真建拓扑队列。
2. **consider easier version** — 先想暴力枚举路径，发现路径数可达 $3^{N/3}$ 指数级，确认必须 DP 计数。
3. **reduce to easier problem** — 经过边 $(u,v)$ 的路径 $=$（源点→$u$）$\times$（$v$→牛圈），DAG 无环保证前后缀独立，边流量 $=f[u]\cdot g[v]$。
4. **classic problem solution** — DAG 路径计数：$f$ 正序推（按最后一步分类）、$g$ 逆序推（按第一步分类），各 $O(N+M)$。
5. **explore its property** — 题目只保证**答案**不溢出，不保证 $f,g$ 各自不溢出；活点 $f\le$ 答案，死点 $f$ 可达 $3^{N/3}$。
6. **discuss by category** — 活点 / 死点分类：死点 $g=0$，其 $f$ 用守卫 `if(!g[u])continue` 跳过，既防溢出又不影响活点。
7. **explore its property** — 每点都源点可达（入边回溯）⇒ $g$ 对所有点都有界，无需守卫；重边保留各计一次。

| `mxn,mxm` | $5005,50005$ | `constexpr int` | 约束 $+5$ |
| `E[i]={u,v}` | 第 $i$ 条边（0-based，含重边） | `struct{int u,v;}[mxm]` | 最后扫边求 max 用 |
| `graph[u]` | $u$ 的出邻居列表（重边存多次） | `vector<int>[mxn]` | 邻接表 |
| `indeg[u]` | $u$ 的入度 | `int[mxn]`，默认 $0$ | 读入时 `++indeg[v]`；判源点 |
| `f[u]` | 源点→$u$ 路径数 | `i64[mxn]`，默认 $0$ | **只在活点递推**；源点置 $1$ |
| `g[u]` | $u$→牛圈路径数 | `i64[mxn]`，默认 $0$ | `g[n-1]=1`，逆序推；所有点都算 |
| `ans` | 最大边流量 | `i64`，初值 $0$ | $\max f[u]\cdot g[v]$ |

### 算法步骤

1. I/O 加速三行。
2. 读 $N,M$；每条边读 `u,v`，`--u;--v`，存 `E[i]`、`graph[u].push_back(v)`、`++indeg[v]`。
3. `g[n-1]=1`；$u$ 从 $N-2$ 递减到 $0$：`for v in graph[u]: g[u]+=g[v]`。
4. $u$ 从 $0$ 到 $N-1$：若 `g[u]==0` 则 `continue`（跳过死点）；若 `indeg[u]==0` 则 `f[u]=1`；`for v in graph[u]: if(g[v]) f[v]+=f[u]`。
5. `ans=0`；扫每条边 `E[i]`：`ans=max(ans,f[u]*g[v])`。
6. 输出 `ans`。

### 复杂度

- 时间：$O(N+M)$，$N=5000,M=5\times10^4$ 时约 $10^5$ 级操作。
- 空间：$O(N+M)$，邻接表 $+$ 边数组 $+$ 三个 $O(N)$ 数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例解释反推图输出 $4$；重边组输出 $2$、死区组输出 $1$、孤立牛圈组输出 $0$ 均与手算一致；$69$ 层梯子死区（$2^{69}$ 路径，超 `long long`）$+$ 活边压测输出 $1$，证明守卫挡住溢出。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2883 [USACO07MAR] Cow Traffic S
// 边恒 u<v ⇒ 编号就是拓扑序。g[u]=u→N 的路径数（倒序递推），f[u]=源点→u 的路径数（正序递推）。
// 边 (u,v) 的流量 = f[u]*g[v]。只给 g>0 的"活点"算 f：死胡同分量的路径数可以是天文数字，
// 而活点上的 f、g 都被答案（≤2^31-1）约束住，i64 可证不溢出。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{5005},mxm{50005};

int n,m,indeg[mxn];
i64 f[mxn],g[mxn];
vector<int>graph[mxn];
struct{int u,v;}E[mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<m;++i)
	{
		cin>>E[i].u>>E[i].v;--E[i].u;--E[i].v;
		graph[E[i].u].push_back(E[i].v);	// 重边保留：每条边是独立的路径选择
		++indeg[E[i].v];
	}
	g[n-1]=1;
	for(int u=n-2;u>=0;--u)
		for(int v:graph[u])
			g[u]+=g[v];
	for(int u=0;u<n;++u)
	{
		if(!g[u])	// 死点不算 f，防止死胡同分量路径数爆炸
			continue;
		if(!indeg[u])
			f[u]=1;
		for(int v:graph[u])
			if(g[v])
				f[v]+=f[u];
	}
	i64 ans=0;
	for(int i=0;i<m;++i)
		ans=max(ans,f[E[i].u]*g[E[i].v]);
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **两个方向两遍递推**：$g$ 逆序（$u$ 从大到小，出邻居已算）、$f$ 正序（$u$ 从小到大，入邻居已算）。编号即拓扑序，省掉拓扑排序。
- **守卫 `if(!g[u])continue` 是正确性关键，不是优化**：死点路径数可达 $3^{N/3}$，超 `long long`；跳过它们防溢出，且活点入邻居全是活点，跳过无害（引理 7）。
- **$f$ 用前向推送**：`f[v]+=f[u]` 等价于"按入边求和"，但只需出邻接表，不必再建反向图。`if(g[v])` 保证只给活点推送（其实死点 $u$ 已被外层跳过，这里再保险一层）。
- **$g$ 不加守卫**：每点都源点可达（引理 4），$g$ 对所有点有界（引理 6），直接算即可。
- **重边**：`graph` 与 `E` 都按重数存，递推与求 max 自然各计一次；用 `set` 去重会错。
- **乘积用 `i64`**：活边乘积 $=$ 真实流量 $\le2^{31}-1$，但 $f,g$ 各自可达 $10^{14}$，中间量必须 `i64`。
- `ans` 初值 $0$：全死边时答案 $0$ 合法。`'\n'` 换行，0-based 内部处理。
