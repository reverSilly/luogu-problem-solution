# P2066 机器分配 — 题解

## 一、解题过程：人类思考叙事

总公司有 $M$ 台设备，分给 $N$ 个分公司。第 $i$ 个公司分到 $j$ 台设备时盈利为 $v_{i,j}$。要求：**总台数不超过 $M$**，使总盈利最大；盈利相同时，**编号小的公司分得设备尽可能少**。$M\le15$，$N\le10$。

这题的骨架一眼就能看出来是**分组背包**：每个公司是一组，组内选一个"选几台"的数量 $j$，各组选的数量之和不超过 $M$。$N\le10,M\le15$，直接 $O(NM^2)$ 的 DP 就够。

麻烦的是**平局时的方案还原**。先把 DP 想清楚。

**DP 的方向选择。** 如果按"前缀"定义 $f[i][j]$ = 前 $i$ 个公司用**恰好** $j$ 台设备的最大盈利，转移是 $f[i][j]=\max_k\{v[i][k]+f[i-1][j-k]\}$。但题目说"总台数不超过 $M$"，答案应当允许设备有剩余（比如所有公司盈利都随台数递增时才用得满）。用"恰好 $j$ 台"定义，答案就得再取 $\max_j f[N][j]$，稍显别扭。

所以我改用**后缀型**定义：

$$f[i][j]=\text{公司 } i,i+1,\dots,N \text{ 总共使用不超过 } j \text{ 台设备时的最大盈利}$$

转移：给公司 $i$ 分 $k$ 台，剩下 $j-k$ 台交给后面的公司：

$$f[i][j]=\max_{0\le k\le j}\{\,v[i][k]+f[i+1][j-k]\,\}$$

边界：$f[N+1][j]=0$（没有公司了，盈利为 $0$，且设备可以剩下不用）。$v[i][0]=0$（分 $0$ 台没盈利）。这样 $f[1][M]$ 就是答案。注意这个定义下"不超过 $j$ 台"是自然包含在转移里的——$k$ 可以小于 $j$，剩余的留给后缀。

**方案还原。** 有了 $f$ 之后，从公司 $1$ 开始依次确定每个公司分几台。设当前还剩 `rest` 台要给公司 $i..N$，且目标盈利是 $f[i][rest]$。我们要在所有满足

$$v[i][k]+f[i+1][rest-k]=f[i][rest]$$

的 $k$ 中选**最小的**。

为什么选最小就满足"编号小的公司分得设备尽可能少"？因为这题的要求是字典序意义下的：先让公司 1 尽量少，如果公司 1 的数量确定了再让公司 2 尽量少，以此类推。所以从前往后贪心，每次取最小的可行 $k$，正是标准的字典序最小贪心。

那"可行"怎么判定？$k$ 可行当且仅当 $v[i][k]+f[i+1][rest-k]$ **等于** $f[i][rest]$——因为 $f[i][rest]$ 就是最大值，等于就说明选它还能达到最优；小于就说明浪费了（这个 $k$ 拿不到最优值）。所以只要从小到大扫 $k$，找到第一个让等式成立的即可。

如果从头到尾都没有 $k$ 让等式成立怎么办？按递推式，$f[i][rest]$ 就是这些项的最大值，必然存在某个 $k$ 达到它，所以一定找得到。

样例：
```
3 3
30 40 50
20 30 50
20 25 30
```
输出 `70 / 1 1 / 2 1 / 3 1`。核对：$30+20+20=70$，共 $3$ 台。另一种方案公司 1 分 $0$、公司 2 分 $3$ 台得 $50$，只有 $50$，更差；公司 1 分 $2$ 台得 $40$、公司 2 分 $1$ 台得 $20$，共 $60$。所以 $70$ 确实最大。而分配 $(1,1,1)$ 也是达到 $70$ 的方案里公司 1 拿得最少的（公司 1 拿 $0$ 台则后面最多也只能凑到更小的值），符合平局规则。

**实现细节。** $v$ 用 `i64`（盈利值题面没给上限，稳妥起见用 `long long`）；`f` 同样用 `i64`。$N\le10,M\le15$，数组开小一点即可。

## 二、思维链：完整证明

**引理 1**（DP 的正确性）：$f[i][j]$ 等于把不超过 $j$ 台设备分配给公司 $i,i+1,\dots,N$ 能得到的最大总盈利。

*证明*：对 $i$ 从 $N+1$ 倒序归纳。

**边界**：$i=N+1$ 时没有公司，盈利必为 $0$，而 $f[N+1][j]=0$ 正确。

**归纳步**：设对公司 $i+1,\dots,N$ 的结论成立。考虑给公司 $i..N$ 分配不超过 $j$ 台设备的任意方案。设公司 $i$ 分到 $k$ 台，则 $0\le k\le j$，公司 $i$ 贡献 $v[i][k]$，其余公司共用不超过 $j-k$ 台设备，由归纳假设它们的最大盈利是 $f[i+1][j-k]$。

故任何方案的总盈利不超过 $\max_{0\le k\le j}\{v[i][k]+f[i+1][j-k]\}$。反之，对任一 $k$，取"公司 $i$ 分 $k$ 台 + 公司 $i+1..N$ 达到 $f[i+1][j-k]$ 的方案"，就构造出一个盈利恰为该项、总台数不超过 $k+(j-k)=j$ 的合法方案。所以最大值可达。

综上 $f[i][j]=\max_{0\le k\le j}\{v[i][k]+f[i+1][j-k]\}$，且该值就是最优值。证毕。

**引理 2**（贪心还原的可行性与最优性）：在还原过程中，若当前还剩 `rest` 台、公司 $i$ 待定，且最优总盈利为 $f[i][rest]$，则存在 $k$ 使 $v[i][k]+f[i+1][rest-k]=f[i][rest]$。

*证明*：由引理 1 的递推式，$f[i][rest]$ 恰是集合 $\{v[i][k]+f[i+1][rest-k]\mid 0\le k\le rest\}$ 的最大值，故集合中至少有一项取到该最大值，即存在这样的 $k$。证毕。

**引理 3**（还原方案的盈利最优）：还原算法输出的方案，其总盈利等于 $f[1][M]$。

*证明*：设还原过程中公司 $i$ 取到 $k_i$，剩余量 `rest` 从 $M$ 递减为 $M-\sum_{p<i}k_p$。

由引理 2，等式 $v[i][k_i]+f[i+1][rest-k_i]=f[i][rest]$ 成立。把这些等式沿 $i=1,2,\dots,N$ 累加，相邻项的 $f$ 消去，得

$$\sum_{i=1}^{N}v[i][k_i]+f[N+1][0]=f[1][M].$$

而 $f[N+1][0]=0$，故方案总盈利恰为 $f[1][M]$，即最大盈利。证毕。

**引理 4**（字典序最小）：在所有总盈利等于 $f[1][M]$ 的方案中，还原算法输出的方案使编号小的公司分得的设备尽可能少。

*证明*：设算法输出为 $x=(x_1,x_2,\dots,x_N)$，另一最优方案为 $y=(y_1,\dots,y_N)$。设 $i$ 是第一个使 $x_i\ne y_i$ 的位置，则对所有 $p<i$ 有 $x_p=y_p$，且 $\sum_{p<i}x_p=\sum_{p<i}y_p$。

由于 $y$ 也是最优方案，在前 $i-1$ 个公司分得相同台数的前提下，$y_i$ 必满足 $v[i][y_i]+f[i+1][rest-y_i]=f[i][rest]$（否则 $y$ 的总盈利会小于最优值），即 $y_i$ 是算法在第 $i$ 步扫描时遇到的候选之一。

而算法取的是候选中**最小**的 $k$，故 $x_i\le y_i$。若 $x_i\ne y_i$ 则 $x_i<y_i$，即在第一个不同的位置上算法给出的台数更少。

对任意另一个最优方案 $y$ 都有此结论，故算法输出的方案在"编号小的公司优先少分"这一字典序规则下最优。证毕。

**定理**：算法输出的最大盈利值与设备分配方案均满足题目要求。

*证明*：由引理 1，最大盈利为 $f[1][M]$；由引理 3，输出方案确实达到该盈利；由引理 4，方案在平局规则下最优。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别分组背包** — 每公司一组，组内选数量，组间求和。
2. **DP 方向的选择** — 用"后缀 + 不超过 $j$ 台"定义，天然处理"设备可以剩余"，答案直接是 $f[1][M]$。
3. **平局还原是独立的贪心** — DP 只负责最优值，方案要另想办法。
4. **字典序最小的标准套路** — 从前向后，每次取"仍能达到最优"的最小值。
5. **可行性的判定式** — $v[i][k]+f[i+1][rest-k]=f[i][rest]$（等号成立才算可行）。
6. **数值类型** — 盈利题面没给上限，用 `i64` 稳妥。
7. **验证方式** — 题面样例核对；另写 DFS 枚举所有分配并按字典序比较的暴力对拍。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $N$ | 分公司数 | `int`，$1\le N\le10$ |
| $M$ | 设备台数 | `int`，$1\le M\le15$ |
| $v_{i,j}$ | 第 $i$ 个公司分 $j$ 台设备的盈利，$v_{i,0}=0$ | `i64[12][17]` |
| $f[i][j]$ | 公司 $i..N$ 使用不超过 $j$ 台设备的最大盈利 | `i64[12][17]` |
| `rest` | 还原过程中剩余待分配的设备数 | `int`，$0\le rest\le M$ |

### 算法步骤

1. 读入 $N,M$ 与 $N\times M$ 的盈利矩阵（$v_{i,0}$ 保持为 $0$）。
2. **DP**（$i$ 从 $N$ 到 $1$）：
   - $f[N+1][j]=0$（$0\le j\le M$）；
   - 对每个 $i$：$f[i][0]=0$；对 $j=1..M$：$f[i][j]=\max_{0\le k\le j}\big(v[i][k]+f[i+1][j-k]\big)$。
3. 输出 `f[1][M]`。
4. **还原**：令 `rest=M`；对 $i=1..N$：从小到大扫 $k=0..rest$，找到第一个满足 $v[i][k]+f[i+1][rest-k]==f[i][rest]$ 的 $k$，输出 `i k`，令 `rest-=k`。

### 复杂度

- 时间复杂度：$O(NM^2)$，最大 $10\times225=2250$ 次运算；还原 $O(NM)$。
- 空间复杂度：$O(NM)$。

### 验证状态

- 标程 `P2066.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 题面样例 `3 3 / 30 40 50 / 20 30 50 / 20 25 30` 输出
  ```
  70
  1 1
  2 1
  3 1
  ```
  与官方一致。
- 另写暴力 `P2066_brute.cpp`：DFS 枚举所有满足"总台数 $\le M$"的分配方案，比较总盈利取最大；盈利相同时用 `lexLess()` 逐位比较取字典序最小者。
- 对拍脚本 `P2066_check.py`：**203 组**用例（200 组随机：$N\le3,M\le5$ + 3 组极端：全 $0$ 盈利、单调递增、题面样例），标程与暴力输出 **0 处不一致**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2066 机器分配
// 思路：后缀型分组背包，f[i][j]: 公司 i..n 最多使用 j 台设备时的最大盈利
//       还原时从公司 1 开始贪心取最小的 k，保证编号小的公司分得设备尽可能少
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{12};
constexpr int mxm{17};

int n,m;
i64 v[mxn][mxm];			// v[i][j]: 第 i 个公司分 j 台设备的盈利
i64 f[mxn][mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=1;i<=n;++i)
		for(int j=1;j<=m;++j) cin>>v[i][j];
	// 没有公司时盈利为 0（设备可以剩下不用）
	for(int j=0;j<=m;++j) f[n+1][j]=0;
	for(int i=n;i>=1;--i)
	{
		f[i][0]=0;
		for(int j=1;j<=m;++j)
		{
			f[i][j]=0;
			for(int k=0;k<=j;++k)
				f[i][j]=max(f[i][j],v[i][k]+f[i+1][j-k]);
		}
	}
	cout<<f[1][m]<<'\n';
	int rest=m;
	for(int i=1;i<=n;++i)
	{
		int k=0;
		// 取最小的 k，使后缀仍能达到最优值
		while(k<rest&&v[i][k]+f[i+1][rest-k]!=f[i][rest]) ++k;
		cout<<i<<' '<<k<<'\n';
		rest-=k;
	}
	return 0;
}
```

### 代码说明

- `v[i][0]` 没有读入，保持全局数组初值 $0$，正好对应"分 $0$ 台无盈利"，转移里 $k=0$ 的项就是"这家公司不要设备"。
- `f[N+1][j]=0` 是"没有公司"的边界；`f[i][0]=0` 是"没设备可用"的边界，两者一起保证转移在 $j=0$ 时也自洽。
- 还原时的判定条件写成 `!=` 跳出，即"第一个让等式成立的 $k$"，对应字典序最小的贪心（引理 4）。
- `while(k<rest&&...)` 中的 `k<rest` 是必要的上界保护：$k$ 不能超过剩余台数，否则 `f[i+1][rest-k]` 会索引到负数。当 $k$ 扫到 `rest` 时循环自然结束，此时 `rest-k=0`，而由引理 2 必有 $k=rest$ 可行。
- `i64` 用于 `v` 与 `f`：题面未给盈利上限，且求和可能溢出 `int`。
