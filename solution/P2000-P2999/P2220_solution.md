# P2220 [HAOI2012] 容易题 — 题解

## 一、解题过程：人类思考叙事

先重述题意。有一个长度为 $m$ 的数列 $A$，每个 $A_i$ 取 $[1,n]$ 中的正整数。给出 $k$ 条形如 $A_x\ne y$ 的限制。求所有满足限制的数列的**积之和**

$$\sum_{T\in S}\prod_{i=1}^{m}T_i \pmod{10^9+7},$$

若一个合法数列都没有则输出 $0$。数据范围 $n,m\le10^9$，$k\le10^5$。

第一反应：数列总数是 $n^m$，$m$ 最大 $10^9$，枚举是不可能的；就算每个位置取值范围很小，也无法逐位 DP（$m$ 太大）。必须找封闭形式。

先退到最简单的情形：**$m=2$，没有任何限制**。要算

$$\sum_{a=1}^{n}\sum_{b=1}^{n}ab .$$

盯着这个式子看：$ab$ 对 $a$、$b$ 是"乘法"，而外面是"求和"。把内层求和拆开：

$$\sum_{a=1}^{n}a\left(\sum_{b=1}^{n}b\right)=\left(\sum_{a=1}^{n}a\right)\left(\sum_{b=1}^{n}b\right).$$

**积的和竟然等于和的积。** 这不是巧合，而是乘法对加法的分配律：每个 $a$ 都要和每一个 $b$ 配对相乘，把 $b$ 的和先算出来当公因子即可。

那有限制呢？比如第二个位置不能取 $2,3$。那么 $b$ 的求和范围变成 $S_2=\{1\}\cup\{4,\dots,n\}$，上面的推导一字不改：

$$\sum_{a\in S_1}\sum_{b\in S_2}ab=\left(\sum_{a\in S_1}a\right)\left(\sum_{b\in S_2}b\right).$$

顺着这个思路推广到 $m$ 个位置：**答案是每个位置"允许取值之和"的乘积**。归纳证明放在第二节（引理 1、3），直觉就是"每个位置独立出一个因子"。

于是问题变成：对每个位置 $i$，算出它的允许值之和 $f_i$。

- 没有被任何限制涉及的位置：允许值是 $[1,n]$ 全部，$f_i=T:=\frac{n(n+1)}{2}$。
- 被限制的位置 $x$：允许值是 $[1,n]$ 去掉所有"$A_x\ne y$"里的 $y$，所以 $f_x=T-\sum_{y\in B_x}y$，其中 $B_x$ 是位置 $x$ 被禁的**不同** $y$ 的集合。

这里立刻出现第一个坑：**同一条限制可能重复给出**（比如两次输入 `2 3`）。如果不去重，就会把 $3$ 扣两次，因子算小。解决办法是把所有 $(x,y)$ 排序，同组内跳过相邻重复的 $y$。

第二个坑：$m$ 最大 $10^9$，但被限制的位置最多只有 $k\le10^5$ 个。设不同被限制位置数为 $d$，剩下 $m-d$ 个位置的因子都是 $T$，用快速幂算 $T^{m-d}$ 即可。

第三个坑：**除以 2 不能直接取模**。$T=\frac{n(n+1)}{2}$，正确做法是用 $2$ 在模 $10^9+7$ 下的逆元 $500000004$，即 $T\equiv n(n+1)\cdot 500000004\pmod p$。

第四个坑（容易误判）：如果某个位置的因子模 $p$ 恰好为 $0$，答案就是 $0$，这是正确的模结果，不需要也不应该当成"无解"。而"无解"（某位置所有值都被禁）算出来的因子本来就是整数 $0$，同样输出 $0$，两者自然统一。

最后用题面 Hint 自检。Hint 的表格对应 $n=3,m=4$，限制是 $A_1\ne1,\ A_2\ne2,3,\ A_4\ne3$。于是 $T=6$，$f_1=5,\ f_2=1,\ f_3=6,\ f_4=3$，乘积 $5\cdot1\cdot6\cdot3=90$。表格里 $12$ 个数列的积逐个相加也恰好是 $90$（$2+4+4+8+6+12+3+6+6+12+9+18=90$），与因子乘积一致。这就是本题的样例。

## 二、思维链：完整证明

**引理 1（有限和的乘积分解）**：设 $S_1,\dots,S_m$ 是有限整数集，则
$$\sum_{(a_1,\dots,a_m)\in S_1\times\cdots\times S_m}\ \prod_{i=1}^{m}a_i=\prod_{i=1}^{m}\left(\sum_{a\in S_i}a\right).$$

*证明*：对 $m$ 归纳。
$m=1$ 时两边都是 $\sum_{a\in S_1}a$。
设对 $m-1$ 成立。把 $m$ 元组按前 $m-1$ 个分量分组：
$$\sum_{(a_1,\dots,a_m)}\prod_{i=1}^{m}a_i
=\sum_{(a_1,\dots,a_{m-1})}\left[\left(\prod_{i=1}^{m-1}a_i\right)\sum_{a_m\in S_m}a_m\right].$$
内层对 $a_m$ 的求和与 $a_1,\dots,a_{m-1}$ 无关，可提到外层：
$$=\left(\sum_{(a_1,\dots,a_{m-1})}\prod_{i=1}^{m-1}a_i\right)\cdot\left(\sum_{a_m\in S_m}a_m\right)
=\left(\prod_{i=1}^{m-1}\sum_{a\in S_i}a\right)\left(\sum_{a\in S_m}a\right),$$
最后一步用了归纳假设。证毕。

**引理 2（每个位置的允许集合）**：位置 $i$ 的允许取值集合为
$$S_i=[1,n]\setminus B_i,\qquad B_i=\{y:(i,y)\text{ 是某条限制}\}.$$

*证明*：数列合法当且仅当对每条限制 $(x,y)$ 都有 $A_x\ne y$。把所有 $x=i$ 的限制收集起来，就是"$A_i$ 不能属于 $B_i$"；其余 $x\ne i$ 的限制与 $A_i$ 无关。故 $A_i$ 可以取 $[1,n]$ 中任意不属于 $B_i$ 的值，即 $S_i$。证毕。

**引理 3（答案 = 各位置允许值之和的乘积）**：记 $f_i=\sum_{a\in S_i}a$，则所求答案为 $\prod_{i=1}^{m}f_i$。

*证明*：所有合法数列恰为 $S_1\times\cdots\times S_m$ 中的元素（引理 2：每个位置独立取值，且合法性就是各位置取值合法）。对每个数列取积再求和，正是引理 1 的左端，故等于右端 $\prod_i f_i$。证毕。

**引理 4（$f_i$ 的计算）**：
$$f_i=\begin{cases}T,&B_i=\varnothing,\\ T-\sum_{y\in B_i}y,&B_i\ne\varnothing,\end{cases}\qquad T=\frac{n(n+1)}{2}.$$

*证明*：$[1,n]$ 的元素之和为 $T$。$S_i$ 是从 $[1,n]$ 中删去集合 $B_i$ 的元素，故其和等于 $T$ 减去 $B_i$ 中所有元素之和。注意 $B_i$ 是**集合**，同一个 $y$ 只删一次；这正是必须去重的原因。证毕。

**引理 5（去重与分组扫描的正确性）**：把所有限制对 $(x,y)$ 按字典序排序后，顺序扫描；对每个 $x$ 的连续段，仅当当前 $y$ 与段内前一个 $y$ 不同时累加 $y$。这样得到的 $\sigma_x$ 恰为 $\sum_{y\in B_x}y$。

*证明*：排序后，$x$ 相同的对连续排列，构成若干段；同一段内 $y$ 非降，故相等的 $y$ 相邻。逐段扫描时，段内第一个 $y$ 一定被累加，此后每个 $y$ 被累加当且仅当它与前一个不同，即每个不同的 $y$ 恰好被累加一次。段内所有不同 $y$ 的集合正是 $B_x$（由 $B_x$ 的定义），故 $\sigma_x=\sum_{y\in B_x}y$。证毕。

**引理 6（模运算合法性）**：
(i) $T\bmod p$ 可用 $n(n+1)\bmod p$ 乘 $2^{-1}\bmod p=500000004$ 得到；
(ii) 在计算 $\prod f_i$ 时对每步取模，结果等于真实答案模 $p$。

*证明*：(i) $p=10^9+7$ 是奇素数，故 $2$ 在 $\mathbb{Z}_p$ 中可逆，$2\cdot500000004=1000000008\equiv1\pmod p$。又 $n(n+1)$ 是偶数，$T$ 是整数；在 $\mathbb{Z}_p$ 中 $T\equiv n(n+1)\cdot2^{-1}$，因为两边乘 $2$ 都等于 $n(n+1)$。(ii) 取模映射 $\mathbb{Z}\to\mathbb{Z}_p$ 是环同态，保持加法与乘法，故先乘后模与先模后乘结果相同；有限个因子连乘亦然。证毕。

**引理 7（快速幂与指数非负）**：设 $d$ 为 $B_x\ne\varnothing$ 的位置个数，则 $0\le m-d\le m$，且 $T^{m-d}\bmod p$ 可在 $O(\log m)$ 内算出。

*证明*：每个被限制的位置必是某个 $x\in[1,m]$，不同位置数 $d\le m$，故指数非负。二进制快速幂的不变式为"$res\cdot base^{e}=T^{m-d}$"（初值 $res=1,base=T,e=m-d$，每步把 $e$ 折半、$base$ 平方，$e$ 为奇数时把 $base$ 乘进 $res$），循环 $\lceil\log_2(m-d+1)\rceil$ 次后 $e=0$，$res=T^{m-d}$。证毕。

**定理**：程序输出等于题目所求答案模 $10^9+7$；当不存在合法数列时输出 $0$。

*证明*：由引理 2、3，答案为 $\prod_i f_i$。程序对每个被限制位置用引理 5 的方式算出 $\sigma_x$，用引理 4 得到 $f_x$；对未被限制的 $m-d$ 个位置用 $T^{m-d}$ 一次乘上（引理 7），由引理 6 所有模运算合法。故输出为答案模 $p$。若无合法数列，则某位置 $B_x=[1,n]$，此时 $f_x=T-\sum_{y=1}^{n}y=0$，乘积为 $0$，与题目要求的输出一致。证毕。

**引理 8（复杂度）**：时间 $O(k\log k+\log m)$，空间 $O(k)$。

*证明*：读入与排序 $O(k\log k)$；扫描 $O(k)$；快速幂 $O(\log m)$。存 $k$ 个限制对，空间 $O(k)$。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 求和对象是"积"，乘法对加法可分配，暗示整体可以因式分解。
- consider easier version — 先做 $m=2$ 且无限制：得到两个"和"的乘积。
- reduce to easier problem — 归纳到一般 $m$：答案 = 每个位置允许值之和的乘积，每个位置独立贡献一个因子。
- explore its property — 未受限位置的因子恒为 $T=n(n+1)/2$，只有被限制的位置需要单独计算。
- classic problem solution — 排序去重（同 $(x,y)$ 重复只扣一次）+ 快速幂处理 $m-d$ 个相同因子。
- discuss by category — 某位置被禁光 ⇒ 因子为 $0$；$k=0$ ⇒ $T^m$；指数 $m-d$ 可能为 $0$。
- modular arithmetic — 除以 $2$ 用逆元 $500000004$，全程取模。
- sanity check by hint — 用 Hint 表格反推 $n=3,m=4$ 与四条限制，手算 $90$ 与表格逐项求和对照。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 每个位置的取值范围上界 $[1,n]$ | 输入 |
| $m$ | 数列长度 | 输入 |
| $k$ | 限制条数 | 输入 |
| $c[\,]$ | 存 $(x,y)$ 限制对 | 读入后排序 |
| $T$ | $n(n+1)/2 \bmod p$，即无限制位置的因子 | 用逆元计算 |
| $d$ | 不同被限制位置数 | 扫描时计数 |
| $\sigma$ | 当前位置所有不同禁值之和（模 $p$） | 每组清零 |
| $ans$ | 答案 | 初值 $1$ |
| `qpow(a,b)` | 快速幂 $a^b\bmod p$ | 二进制拆分 |
| $p$ | $10^9+7$ | 模数 |

### 算法步骤

1. I/O 加速三连；读入 $n,m,k$ 与 $k$ 个 $(x,y)$。
2. 对限制对按 $(x,y)$ 字典序排序。
3. $T\gets n(n+1)\bmod p\cdot500000004\bmod p$。
4. $ans\gets1,\ d\gets0$；按 $x$ 分组扫描：
   1. 组内依次看 $y$，若与组内前一个 $y$ 不同，则 $\sigma\gets(\sigma+y)\bmod p$；
   2. 该组结束后 $ans\gets ans\cdot\big((T-\sigma)\bmod p\big)\bmod p$，$d\gets d+1$。
5. $ans\gets ans\cdot T^{\,m-d}\bmod p$。
6. 输出 $ans$。

### 复杂度

- 时间：$O(k\log k+\log m)$。
- 空间：$O(k)$。

### 一句话验证状态

Hint 对应的 $n=3,m=4$ 四条限制输出 $90$（与表格逐项求和一致）；与 $O(n^m)$ 枚举暴力在 500 组随机小数据上完全一致；$n=m=10^9,k=10^5$ 实测约 $0.06$ 秒。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2220 [HAOI2012] 容易题
// 答案 = 每个位置「允许取值之和」的乘积；未受限位置因子为 n(n+1)/2
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxk{100005};
constexpr i64 p{1'000'000'007};

i64 n,m;
int k;
pair<i64,i64>c[mxk];

i64 qpow(i64 a,i64 b)
{
	i64 r=1;
	for(;b;b>>=1,a=a*a%p)
		if(b&1)
			r=r*a%p;
	return r;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>k;
	for(int i=0;i<k;++i)
		cin>>c[i].first>>c[i].second;
	sort(c,c+k);
	i64 S=(n%p)*((n+1)%p)%p*500000004%p;   // n(n+1)/2 mod p，2 的逆元
	i64 ans=1;
	int d=0;
	for(int i=0;i<k;)
	{
		int j=i;
		i64 sum=0;
		while(j<k&&c[j].first==c[i].first)
		{
			// 同组内相同的 y 只扣一次
			if(j==i||c[j].second!=c[j-1].second)
				sum=(sum+c[j].second)%p;
			++j;
		}
		ans=ans*((S-sum+p)%p)%p;
		++d;
		i=j;
	}
	ans=ans*qpow(S,m-d)%p;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `sort(c,c+k)` 同时完成"按位置分组"和"同组内 $y$ 升序"，于是相同 $(x,y)$ 必然相邻，`c[j].second!=c[j-1].second` 就是去重判据。
- `500000004` 是 $2$ 在模 $10^9+7$ 下的逆元；直接写 `n*(n+1)/2` 会先溢出（$n$ 到 $10^9$ 时 $n(n+1)$ 到 $10^{18}$ 量级，`long long` 虽能存，但取模后再除会错），必须用逆元。
- `(S-sum+p)%p`：`sum` 已取模，`S-sum` 可能为负但绝对值小于 $p$，加一次 $p$ 即可归正。
- 指数 `m-d` 用 `i64`：`m` 达 $10^9$，`d` 为 `int` 时相减仍正确，但统一按 64 位处理更稳。
- $k=0$ 时循环不执行，`d=0`，答案就是 $S^m$，符合"无限制"的情形。

### 验证状态

- 编译：`g++ -std=c++20 -O2 -Wall -Wextra` 无错误、无警告。
- 样例：由 Hint 表格反推的 $n=3,m=4$、限制 $(1,1),(2,2),(2,3),(4,3)$，输出 $90$，与表格 $12$ 个积之和一致；另构造含重复限制的数据，与暴力一致。
- 对拍：$n,m\le4$、$k\le6$（允许重复限制）的 500 组随机数据，与枚举全部数列求积之和的暴力完全一致。
- 极限：$n=m=10^9,\ k=10^5$ 随机限制，实测 $0.06$ 秒。
