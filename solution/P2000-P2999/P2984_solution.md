# P2984 [USACO10FEB] Chocolate Giving S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一张 $N$ 个点、$M$ 条边的**无向带权图**（$N\le 5\times10^4$，$M\le 10^5$，边权 $1\le L_i\le 2000$）。$B$ 个询问（$B\le 25000$ 且 $2B\le N$），每个询问给出 $P_i,Q_i$：奶牛要从 $P_i$ 出发，**必须先到 $1$ 号点**取礼物，再到 $Q_i$ 送礼物，问最短路程。每询问输出一行一个整数。

**一个口径说明。** 题面没有明说图连通，但给了 $M\ge N-1$ 的下界，且要求每个询问都输出一个整数答案——若 $P_i$ 或 $Q_i$ 与 $1$ 不连通，"最短路程"就没有定义。因此我按**图连通（所有农场都能从 $1$ 到达）**的口径处理，这也是此类 USACO 最短路题的默认约定。代码里 `dis` 填 INF，若真出现不连通数据会输出天文数字而不是静默输出 $0$，便于发现问题。

**第一步：剥掉故事，盯住"必经点"。** 路线被 $1$ 号点切成两段：$P\to 1$ 和 $1\to Q$。这两段互不干扰——第一段怎么走不影响第二段的可选走法（图是静态的，走重复点、重复边都允许）。所以直觉上：

$$\text{答案}(P,Q)=d(P,1)+d(1,Q).$$

这个式子需要证明两个方向：任何合法路线都**不短于**它（下界），以及存在恰好这么长的合法路线（可达）。两边都成立才算数，Part 2 引理 1 会完整证。

**第二步：无向图把两段拧成一段。** 图是无向的，把 $P\to 1$ 的路线倒过来走就是 $1\to P$ 的路线，长度不变，于是 $d(P,1)=d(1,P)$。答案变成

$$d(1,P)+d(1,Q),$$

**两项都只跟"从 $1$ 出发的单源距离"有关**。这是全题的思维跳跃：$B$ 个看起来是"两点间最短路"的询问，塌缩成了**一次单源最短路 + 每询问一次加法**。

**第三步：算账，选算法。** 如果每个询问跑一次 Dijkstra，是 $O(B(N+M)\log N)\approx 25000\times1.5\times10^5\times16\approx 6\times10^{10}$，必死。而单源一次 Dijkstra 只要 $O((N+M)\log M)\approx 2.4\times10^6$，加上 $B$ 次 $O(1)$ 回答，轻松通过。边权全为正，Dijkstra 适用（没有负权，不用 Bellman-Ford / SPFA）。

**第四步：范围核对，两个易错点。**

1. **距离上界**：最短路上每条边至多走一次（正权图去掉环只会更短），故 $d(1,v)\le (N-1)\times 2000\approx 10^8$，两项相加 $\le 2\times10^8<2^{31}-1\approx 2.1\times10^9$，**`int` 装得下**，不必开 `long long`。
2. **INF 陷阱**：`dis` 是全局 `int` 数组，默认值是 $0$ 不是无穷！不显式 `fill` 成 INF 的话，所有点开局就是"距离 $0$"，Dijkstra 一步都不会松弛，输出全 $0$。必须 `fill_n(dis,n,inf)`，且 `inf` 要显著大于真实距离上界 $10^8$——取 `1145141919`（约 $1.1\times10^9$）恰好：比 $10^8$ 大一个量级，又不会在 `dis[u]+w` 时溢出 `int`。

**手造数据核对。** 题面没有样例，造一组小图：

```
输入：
4 4 3
1 2 3
2 3 4
1 3 10
3 4 1
2 4
4 2
1 1
```

手算单源距离：$d(1,1)=0$；$d(1,2)=3$（直连）；$d(1,3)=\min(10,\ 3+4)=7$（借道 $2$ 比直连 $10$ 短——专门造来打"只看直连边"的错误）；$d(1,4)=7+1=8$。三个询问：$d(1,2)+d(1,4)=3+8=11$；$d(1,4)+d(1,2)=11$（对称）；$d(1,1)+d(1,1)=0$（$P=Q=1$ 的退化情形）。程序输出 `11 / 11 / 0`，逐条吻合。

## 二、思维链：完整证明

**记号。** 图 $G=(V,E)$ 无向，边权 $w(e)\ge 1$。$d(u,v)$ 为 $u$ 到 $v$ 的最短路长度（ walk 长度的下确界；不连通时为 $+\infty$，按口径不出现）。询问 $(P,Q)$ 的合法路线是**任何从 $P$ 出发、中途至少经过点 $1$ 一次、最终停在 $Q$ 的 walk**（允许重复点边——题目只说"走多远"，没有禁止重复）。

---

### 引理 1（必经点分解：答案 $=d(P,1)+d(1,Q)$）

对任意询问 $(P,Q)$，合法路线的最短长度恰为 $d(P,1)+d(1,Q)$。

*证明*：分下界与可达两半。

**下界**：设 $W$ 是任一合法路线。$W$ 经过点 $1$，取它**第一次**到达 $1$ 的时刻，把 $W$ 切成 $W_1$（$P\to 1$ 的 walk）与 $W_2$（$1\to Q$ 的 walk）。则 $\mathrm{len}(W)=\mathrm{len}(W_1)+\mathrm{len}(W_2)$。由最短路定义，$d(P,1)$ 是所有 $P\to 1$ walk 长度的最小值（正权保证最小值存在：任何 walk 删去其中的环得到简单路径，长度不增，而简单路径只有有限条），故 $\mathrm{len}(W_1)\ge d(P,1)$；同理 $\mathrm{len}(W_2)\ge d(1,Q)$。相加得 $\mathrm{len}(W)\ge d(P,1)+d(1,Q)$。

**可达**：取一条 $P\to 1$ 的最短路 $W_1^\*$ 与一条 $1\to Q$ 的最短路 $W_2^\*$，首尾拼接成 walk $W^\*$。它在点 $1$ 处经过 $1$，是合法路线（拼接处即使重复点边也无妨，walk 允许），长度恰为 $d(P,1)+d(1,Q)$。

两半合起来，最小值就是 $d(P,1)+d(1,Q)$。证毕。

**注**：这里"允许重复点边"是本质的——两段最短路可能共用边，若题目要求简单路径则分解不成立。题面只限制总路程，没有限制重复，故 walk 模型正确。

---

### 引理 2（无向对称：$d(P,1)=d(1,P)$）

无向图中 $d(u,v)=d(v,u)$。

*证明*：设 $W=(u=v_0,e_1,v_1,\dots,e_k,v_k=v)$ 是 $u\to v$ 的 walk。因为每条边无向，倒序序列 $(v_k,e_k,\dots,e_1,v_0)$ 是合法的 $v\to u$ walk，且边权多重集相同，长度相等。于是 $u\to v$ 的 walk 集合与 $v\to u$ 的 walk 集合之间存在保长度的双射（逆映射就是再倒一次），两集合的长度最小值相等。证毕。

**推论**：答案 $=d(1,P)+d(1,Q)$，只依赖从 $1$ 出发的单源距离数组。

---

### 引理 3（Dijkstra 的正确性）

在边权非负的图上，从源点 $s=1$（内部 $0$）运行"小根堆 + 惰性删除"的 Dijkstra：每个点 $u$ 第一次被弹出并标记 `vis[u]=true` 时，`dis[u]`$=d(s,u)$。

*证明*：先立两条恒成立的不变量。

**(i) `dis[v]` 永远是某条真实 $s\to v$ walk 的长度（或 INF）**。初始 `dis[s]=0`（空 walk）、其余 INF；每次松弛 `dis[v]=dis[u]+w` 对应"到 $u$ 的 walk 接一条边"，仍是真实 walk。故 `dis[v]`$\ge d(s,v)$ 恒成立。

**(ii) `dis` 只减不增**，且每次减小都伴随一个键值等于新 `dis` 的堆元素入堆。

对**出队定居的顺序**归纳。设此前所有定居点 $x$ 都满足 `dis[x]`$=d(s,x)$（第一个定居点是 $s$ 本身：堆中初始只有键 $0$ 的 $s$，而由 (i) 任何点键值 $\ge d\ge 0$，故 $s$ 最先弹出，`dis[s]`$=0=d(s,s)$，基例成立）。

现在弹出键值最小的未定居点 $u$，键为 `dis[u]`。反设 `dis[u]`$>d(s,u)$。取一条 $s\to u$ 的最短路 $\pi$。$\pi$ 从已定居的 $s$ 出发、终于未定居的 $u$，故沿 $\pi$ 存在**第一个未定居点** $y$，其前驱 $x$ 已定居（$y$ 可能就是 $u$）。由归纳假设 `dis[x]`$=d(s,x)$，且 $x$ 定居时松弛过边 $(x,y)$，故彼时 `dis[y]`$\le d(s,x)+w(x,y)$；由 (ii)，此后 `dis[y]` 只减不增，现在仍有

$$\texttt{dis}[y]\le d(s,x)+w(x,y)=d(s,y)\le d(s,u)<\texttt{dis}[u].$$

第一个等号是最短路 $\pi$ 的子路径最优性（最短路的前缀也是最短路），第二个不等号因为 $y$ 在 $\pi$ 上且边权非负（$y$ 到 $u$ 的剩余段长度 $\ge 0$）。由 (i) 又有 `dis[y]`$\ge d(s,y)$，故 `dis[y]`$=d(s,y)$ 且堆中存在键为 `dis[y]`$<$`dis[u]` 的 $y$ 元素（$y$ 未定居，其最新键元素还没被弹出；即使有更大的过期键也无妨，最小键的那个仍在堆里）。这与"$u$ 是当前堆中键最小的未定居点"矛盾。故 `dis[u]`$=d(s,u)$。归纳完成。

最后，连通图中每个点都会被定居：只要还有点未定居，由连通性存在从已定居集合出发的边，其终点 `dis` 有限、在堆中，算法不会提前空堆。证毕。

---

### 引理 4（数值范围：`int` 与 INF 的选取安全）

真实距离 $d(1,v)\le (N-1)\cdot 2000<10^8$；询问答案 $\le 2\times 10^8<2^{31}-1$；取 `inf`$=1145141919$，则松弛运算 `dis[u]+w` 不溢出，且 INF 不会被误当成真实距离。

*证明*：正权图中最短路可取为简单路径（任何 walk 删环不增长度，引理 1 已述），至多 $N-1$ 条边，每条 $\le 2000$，故 $d\le 49999\times 2000=9.9998\times 10^7<10^8$。答案两项相加 $\le 1.99996\times 10^8<2147483647$ ✓。

松弛只对已定居的 $u$ 做（`dis[u]`$=d\le 10^8$），`dis[u]+w`$\le 10^8+2000\ll 2^{31}$ ✓；堆里 INF 键的点不会被弹出松弛（连通图中任何点在 INF 键弹出前必然已被有限键更新并定居——由引理 3 末段），即使弹出，`inf+2000`$\approx 1.145\times 10^9<2^{31}$ 也不溢出 ✓。INF$=1.145\times 10^9>10^8$，比任何真实距离大一个量级，`dis[u]+w<dis[v]` 的比较不会把"不可达"误判成"可达" ✓。证毕。

---

### 引理 5（复杂度）

时间 $O((N+M)\log M+B)$，空间 $O(N+M)$。

*证明*：每条边至多在其一端定居时触发一次成功松弛（每端各一次，共 $\le 2M$ 次入堆），加上初始 $1$ 次，堆操作 $\le 2M+1$ 次，每次 $O(\log M)$；弹出总次数同阶。读入 $O(N+M+B)$，回答 $B$ 次 $O(1)$。合计 $O((N+M)\log M+B)$。代入 $M=10^5$：约 $2\times10^5\times17\approx 3.4\times10^6$ 次堆基本操作，远低于时限。空间：邻接表 $2M$ 个 `pair<int,int>` 约 $1.6$ MB，`dis`/`vis` 各 $O(N)$，堆 $O(M)$。证毕。

---

### 定理

程序对每个询问输出 $d(1,P_i)+d(1,Q_i)$，即经过 $1$ 号点的最短路线长度，总复杂度 $O((N+M)\log M+B)$。

*证明*：引理 1 把"必经点路线"分解为两段最短路之和；引理 2 把两段都归到从 $1$ 出发的单源距离；引理 3 保证 Dijkstra 算出的 `dis` 正是单源距离；引理 4 保证 `int` 与 INF 全程安全；引理 5 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "必须先到 $1$"把路线切成互不干扰的两段：$P\to 1$ 与 $1\to Q$，答案 $=d(P,1)+d(1,Q)$（下界 + 拼接可达）。
2. **consider easier version** — 若只有一个询问，就是两次单源最短路；$B$ 个询问逐个跑是 $6\times10^{10}$ 量级，必须共享预处理。
3. **reduce to easier problem** — 无向图 $d(P,1)=d(1,P)$，$B$ 个"两点最短路"询问塌缩成**一次**从 $1$ 出发的单源最短路 + 每询问一次加法。
4. **classic problem solution** — 正权单源最短路 ⇒ 堆优化 Dijkstra（惰性删除 + `greater<>`），$O((N+M)\log M)$。
5. **explore its property** — 范围核对：$d\le 10^8$、答案 $\le 2\times10^8$，`int` 够用；INF 取 $1145141919$ 既大于真实距离又不溢出。
6. **discuss by category** — 全局 `dis` 默认 $0$ 不是 INF，必须显式 `fill`；$P=Q=1$ 输出 $0$ 自然成立。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N,M,B$ | 点数 / 边数 / 询问数 | `int n,m,b` | 读入顺序 $N,M,B$ |
| `mxn` | $50000+5$ | `constexpr int` | 点数组尺寸 |
| `inf` | 距离哨兵 $1145141919$ | `constexpr int` | $>10^8$（真实距离上界），$+2000$ 不溢出 |
| `graph[u]` | $u$ 的邻接表，元素 `(v,w)` | `vector<pair<int,int>>[mxn]` | 无向图双向加边 |
| `dis[v]` | $d(1,v)$ 的当前上界，定居后为精确值 | `int[mxn]` | **必须 `fill_n(dis,n,inf)`**，`dis[0]=0` |
| `vis[v]` | $v$ 是否已定居（弹出过） | `bool[mxn]` | 全局默认 `false`，恰好正确 |
| `Q` | 小根堆，元素 `(键,u)` | `priority_queue<...,greater<>>` | 惰性删除：弹出时 `vis[u]` 为真则丢弃 |
| `p,q` | 询问端点，读入后 `--p;--q` | `int` | 输出 `dis[p]+dis[q]` |

### 算法步骤

1. I/O 加速三行；读 $N,M,B$。
2. 读 $M$ 条边，`--u;--v`，双向加入 `graph`。
3. Dijkstra：`dis` 填 INF，`dis[0]=0` 入堆；每次弹出最小键，过期（`vis`）则丢；否则定居并松弛所有出边，成功松弛则入堆。
4. 每个询问读 `p,q` 转 0-based，输出 `dis[p]+dis[q]` 与 `'\n'`。

### 复杂度

- 时间：$O((N+M)\log M+B)$，极限约 $3.4\times10^6$ 次堆操作。
- 空间：$O(N+M)$，约 $2$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 $4$ 点 $4$ 边 $3$ 询问（含借道更短、对称询问、$P=Q=1$）与手算逐条一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2984 [USACO10FEB] Chocolate Giving S
// 必经点 1 的最短路 = d(1,P)+d(1,Q)，一次 Dijkstra 预处理，O(1) 回答每个询问
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005},inf{1145141919};

int n,m,b,dis[mxn];
bool vis[mxn];
vector<pair<int,int>>graph[mxn];

void dij()
{
	fill_n(dis,n,inf);	// 全局数组默认 0，必须显式填 INF
	priority_queue<pair<int,int>,vector<pair<int,int>>,greater<>>Q;
	dis[0]=0;Q.emplace(0,0);
	while(!Q.empty())
	{
		auto[d,u]=Q.top();Q.pop();
		if(vis[u])continue;	// 惰性删除：过期堆元素直接丢
		vis[u]=true;
		for(auto[v,w]:graph[u])
			if(dis[u]+w<dis[v])
			{
				dis[v]=dis[u]+w;
				Q.emplace(dis[v],v);
			}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>b;
	for(int i=0,u,v,w;i<m;++i)
	{
		cin>>u>>v>>w;--u;--v;
		graph[u].emplace_back(v,w);
		graph[v].emplace_back(u,w);
	}
	dij();
	for(int i=0,p,q;i<b;++i)
	{
		cin>>p>>q;--p;--q;
		cout<<dis[p]+dis[q]<<'\n';	// 最大 2*(N-1)*2000 < 2^31，int 安全
	}
	return 0;
}
```

### 代码说明

- `dij` 只跑一次，源点是内部 $0$ 号（原题 $1$ 号农场）；所有询问共享 `dis`。
- **`fill_n(dis,n,inf)` 是生死线**：全局 `int` 默认 $0$，不填 INF 则所有点开局"距离 $0$"，一次松弛都不会发生，输出全 $0$。
- 惰性删除写法：同一个点可能以多个不同键入堆，弹出时若已定居直接 `continue`，不用手写 `decrease_key`。
- `dis[p]+dis[q]` 用 `int` 即可（引理 4）；若边权或点数放大，这里与 `inf` 都要换 `i64`。
- 无向图记得双向加边；读入立刻 `--` 转 0-based，输出的是距离不是编号，无需 `+1`。
