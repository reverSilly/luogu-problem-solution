# P2001 硬币的面值 — 题解

## 一、解题过程：人类思考叙事

题面这句话读起来别扭得很：「最少需要多少硬币就能组合成所有可能的价格？」——「组合成所有可能的价格」，也就是从 $1$ 到 $m$ 的每一个价格都要能**恰好**凑出来，不是「凑出 $m$ 就完事」。而且硬币可以重复使用。

第一反应：这不就是凑硬币问题吗？排序 + 贪心。

但直接想「每次拿面值最大的硬币凑剩下的钱」又觉得哪里不对：题目不是要凑出 $m$，而是要**同时**凑出 $1,2,3,\dots,m$ 里的每一个数，且总共用的硬币数最少。这是"覆盖"而不是"找零"。

换个角度想。既然面值可以重复使用，那我实际上是在选一个**多重集合**（每种面值选多少枚），使得用这个多重集合能凑出 $[1,m]$ 的所有整数，并且 $|多重集合|$ 最小。

这里立刻有一个关键洞察：如果某个多重集合能凑出 $[0,c]$ 里的所有数，并且我手里有一枚面值为 $v$ 的硬币且 $v \le c+1$，那么加上这枚硬币后，能凑出的范围变成 $[0, c+v]$。为什么？

- 原来能凑出 $[0,c]$；
- 加上 $v$ 之后，用上这枚 $v$ 就能凑出 $[v, c+v]$；
- 只要 $v \le c+1$，两个区间 $[0,c]$ 和 $[v,c+v]$ 之间没有空隙，合起来就是 $[0,c+v]$。

这就是经典的"连续覆盖"递推。设 `cov` 是当前能连续凑出的最大端点（初始 $0$），那么只要手上有面值 $v \le cov+1$，加入它就让 `cov` 变成 `cov+v`。

反过来，**必须**满足 $v \le cov+1$，否则中间会缺一截：假如 $v > cov+1$，那么 $cov+1$ 这个数就永远凑不出来（小的硬币加起来最多到 $cov$，大的硬币一旦用就超过 $cov+1$）。

于是问题变成：给定 $n$ 个面值，每个面值可无限次取，要求用最少的枚数把 `cov` 从 $0$ 推到至少 $m$，且每次取的面值要满足 $v \le cov+1$。

贪心直觉：**始终取当前能用的最大面值**。因为面值越大，同样一枚硬币贡献的 `cov` 增量越大，"性价比"越高，而且大面值不会像小面值那样很快就把 `cov+1` 的门槛跨过去浪费掉。

不过贪心要证明严谨一点：设当前可用的最大面值为 $v_{\max}$，任何可行方案的下一枚都 $\le v_{\max}$。如果换一枚更小的 $v' < v_{\max}$，那么两枚的增量分别是 $v'$ 和 $v_{\max}$，显然后者更大。但要小心：贪心选了大面值后，可能"跳过"了一些本来用小面值可以更精细调节的机会？不需要，因为最终目标只是 `cov ≥ m`，多出来的覆盖是浪费的。所以只要证明"用等量硬币时，贪心序列的 `cov` 不小于任何其他序列"，贪心就成立。

这个证明可以用交换论证：设某个最优方案中第一枚硬币是 $v'$，而当前可用的最大面值是 $v_{\max} \ge v'$。把第一枚换成 $v_{\max}$——但这可能破坏"后续硬币都要 $\le cov+1$"的限制，因为 `cov` 变大了，后续的门槛只会更宽松，不会更严（门槛是上界 `cov+1`，`cov` 变大 → 门槛变大 → 限制更松）。所以替换后依然可行，且覆盖范围只会更大，硬币数不变。这就完成了交换论证。

**但真正卡人的是数据范围。** $m \le 2^{63}$！这意味着 `cov` 可能涨到远超 64 位。如果一枚枚硬币地加，答案可能是 $2^{63}$ 量级（面值全是 $1$ 的极端情况），时间上完全不可接受。

好在贪心序列是**分段常数**的：使用面值 $v$ 时，只要 $v \le cov+1$，我们就一直可以用 $v$，直到 `cov+1` 大到让下一个更大的面值变得可用。这中间可以用乘法一步算完。

具体地：把面值排序去重为 $a_1 < a_2 < \dots < a_k$。贪心会用 $a_1$ 直到 `cov ≥ a_2 - 1`（这样 $a_2$ 才"可用"），然后用 $a_2$ 直到 `cov ≥ a_3 - 1`，……最后用 $a_k$ 直到 `cov ≥ m`。每一段需要的枚数就是 $\lceil (target - cov)/v \rceil$，直接除法算出来。

于是复杂度变成 $O(n \log n)$（排序）+ $O(n)$（扫描），与 $m$ 的大小完全无关。

还有一个边界：如果最小面值不是 $1$，那 $1$ 就永远凑不出来，直接输出 `No answer!!!`。

再想想 $m$ 的边界：$m \le 2^{63}$，而 `u64` 最大是 $2^{64}-1$，`cov` 累加后可能超过 $2^{64}$？`cov` 最大只会到「第一次 ≥ m 时」的位置，此时 `cov < m + max_face ≤ 2^63 + 2^63 = 2^64`。嗯，这确实可能溢出 `u64` 的边界——严格说 `2^64` 本身超了。所以我用 `__uint128_t` 存 `cov`，稳妥。答案（硬币枚数）最大是 $m$（全用面值 1），也就是 $2^{63}$，`u64` 装得下。

答案验证：`5 31`，面值 `1 2 8 4 16`，排序去重为 `1 2 4 8 16`。
- 用面值 1 到 `cov ≥ 2-1=1`：需要 1 枚，`cov=1`，枚数 1。
- 用面值 2 到 `cov ≥ 4-1=3`：需要 1 枚，`cov=3`，枚数 2。
- 用面值 4 到 `cov ≥ 8-1=7`：需要 1 枚，`cov=7`，枚数 3。
- 用面值 8 到 `cov ≥ 16-1=15`：需要 1 枚，`cov=15`，枚数 4。
- 用面值 16 到 `cov ≥ 31`：需要 1 枚，`cov=31`，枚数 5。

答案 5，和样例一致。

## 二、思维链：完整证明

**引理 1（覆盖引理）**：若当前所选硬币能凑出 $[0,c]$ 中的每个整数，且再加入一枚面值为 $v$ 的硬币，则能凑出的范围是 $[0,c]$ 与 $[v,c+v]$ 的并集；当且仅当 $v \le c+1$ 时，该并集恰为 $[0,c+v]$，否则存在缺口。

*证明*：设加入前的集合为 $S$，$S$ 包含 $[0,c]$ 的所有整数（可能还包含更大的数，但那些数 $\ge c+1$，对连续性无益）。加入面值 $v$ 的硬币后，新可凑出的集合为 $S' = S \cup (S+v)$，其中 $S+v = \{s+v : s \in S\}$。

- 若 $v \le c+1$：$S$ 覆盖 $[0,c]$，$S+v$ 覆盖 $[v,c+v]$。因为 $v \le c+1$，区间 $[0,c]$ 与 $[v,c+v]$ 相交或相邻（$[v,c+v]$ 的左端点 $v \le c+1$ 即 $[0,c]$ 的右端点加一），所以并集连续地覆盖 $[0,c+v]$。
- 若 $v > c+1$：$c+1 \in [0,c]$ 不成立，$c+1 \notin S$（因 $S$ 中所有 $\le c$ 的数都在 $[0,c]$ 里被覆盖，且 $S$ 中不存在值 $c+1$，否则 $S$ 就已覆盖 $[0,c+1]$，与 $c$ 是"最大连续端点"矛盾）；同理 $c+1 \notin S+v$（因 $S+v$ 中最小元素 $\ge v > c+1$）。所以 $c+1$ 永远凑不出来，存在缺口。证毕。

**引理 2（可行性刻画）**：一个多重集合能凑出 $[1,m]$ 的所有整数，当且仅当按某种顺序排列其面值 $v_1, v_2, \dots, v_t$ 满足：令 $c_0 = 0$，$c_j = c_{j-1} + v_j$，则对所有 $j$ 有 $v_j \le c_{j-1}+1$，且 $c_t \ge m$。

*证明*：

（$\Leftarrow$）由引理 1，$v_1 \le c_0+1 = 1$ 意味着 $v_1=1$（否则 $1$ 凑不出），随后每次加入都使连续覆盖区间扩展到 $[0,c_j]$。$c_t \ge m$ 时 $[1,m]$ 全被覆盖。

（$\Rightarrow$）设该多重集合能凑出 $[1,m]$。取其中任意一个面值 $v$。若 $v > 1$，则把 $v$ 去掉后剩余集合必须能凑出 $1$（因为 $v$ 本身 $>1$，凑出 $1$ 不可能用到 $v$），于是剩余集合能凑出 $[0,c]$（$c \ge 1$，取连续端点）。此时 $v$ 若 $\le c+1$ 则可加入扩展区间。递归地，从剩余集合开始每次取一个"可加入"的面值。这里需说明：总能找到一个满足 $v \le c+1$ 的剩余面值——否则所有剩余面值都 $> c+1$，则 $c+1$ 无法由任何面值凑出（都 $> c+1$），与剩余集合能凑出 $[0,c]$ 矛盾（注意 $c+1 \le m$ 需成立：若 $c \ge m$ 则结论平凡，见下）。

补充边界情形：若剩余集合的连续端点 $c \ge m$，则"能凑出 $[1,m]$"已经成立，无须再讨论。故整个过程在 $c < m$ 时进行，而此时 $c+1 \le m$，必有某个面值 $\le c+1$，可被取出并加入。归纳到底，得到满足条件的排列顺序。证毕。

**引理 3（贪心最优性）**：在每一步都取"当前可用（$\le cov+1$）的最大面值"的策略，得到的硬币枚数最少。

*证明*：设当前连续覆盖端点为 $c$，可用面值集合为 $V(c) = \{v : v \le c+1\}$，其最大值为 $V_{\max}$。设某个最优解的下一步取了 $v' \in V(c)$，则 $v' \le V_{\max}$。

构造一个新方案：把该最优解的**第一枚**硬币换成 $V_{\max}$。

- 可行性：新方案的第一枚满足 $V_{\max} \le c+1$，由引理 1，它把覆盖区间扩展为 $[0, c+V_{\max}]$。
- 后续硬币：原方案第 2 枚要求 $v_2 \le c+v'+1$。新方案覆盖端点为 $c+V_{\max} \ge c+v'$，所以 $c+V_{\max}+1 \ge c+v'+1 \ge v_2$，即原方案的第 2 枚在新方案里仍然可用。归纳地，第 $j$ 枚要求 $v_j \le c+\sum_{i<j}v_i + 1$，而新方案的前 $j-1$ 枚之和 $\ge$ 原方案，故新方案的门槛只会更高更宽松，所有后续硬币都仍然合法。
- 枚数不变，覆盖范围不小于原方案。

因此存在一个最优解，其第一步取的是 $V_{\max}$。对剩余问题重复该论证（归纳），即得贪心最优。证毕。

**引理 4（分段批量等价于逐枚贪心）**：当连续使用面值 $v$ 且 $v \le cov+1$ 始终成立时，一次性使用 $\lceil (target-cov)/v \rceil$ 枚 $v$ 与逐枚使用直到 `cov` 达到 `target` 完全等价。

*证明*：逐枚使用面值 $v$ 时，每用一枚 `cov` 增加 $v$，且只要使用前 $v \le cov+1$ 就合法。使用 $t$ 枚后 `cov = cov_0 + t·v`。要用尽可能少的枚数使 `cov ≥ target`，需 $t \ge (target-cov_0)/v`，最小整数解为 $t = \lceil (target-cov_0)/v \rceil$。使用这 $t$ 枚的过程中，最后一枚使用前 `cov = cov_0+(t-1)v`。合法性要求 $v \le cov_0+(t-1)v+1$，即 $cov_0 + (t-1)v \ge v-1$。当 $t=1$ 时要求 $cov_0 \ge v-1$，即 $v \le cov_0+1$，这正是我们按面值排序保证的"该面值可用"条件；当 $t \ge 2$ 时 $cov_0+(t-1)v \ge v \ge v-1$，自动满足。故批量使用与逐枚使用完全等价且合法。证毕。

**引理 5（无解判定）**：若排序去重后的最小面值 $\ne 1$，则无解。

*证明*：$1$ 只能由面值 $1$ 的硬币凑出（所有面值都是正整数）。若不存在面值 $1$，则价格 $1$ 无法凑出，题目要求的"所有可能价格"（含 $1$，因 $m \ge 1$）无法覆盖，故无解。反之若存在面值 $1$，则按引理 1 依次取面值 $1$ 可把覆盖扩展到 $[0,\text{该面值 1 的总枚数}]$，只要枚数足够多就能覆盖 $[0,m]$，且每一步 $1 \le cov+1$ 恒成立，故总有解。证毕。

**定理**：算法输出的是最少硬币枚数，无解时输出 `No answer!!!`。

*证明*：无解判定由引理 5 给出。算法按面值升序扫描，在每一段内用引理 4 的批量方式取尽量少的枚数把 `cov` 推到达标位置，这段所用面值正是贪心策略会选择的面值（引理 3），且每段结束时恰好达到"下一面值变为可用"或"覆盖到 $m$"的边界，与逐枚贪心完全一致。因此最终枚数即贪心最优解。证毕。

## 三、模式总结（按实际思考顺序）

1. **抠题面语义** — "组合成所有可能的价格" = 覆盖 $[1,m]$ 的每个整数，不是凑出 $m$；硬币可重复使用。
2. **识别核心结构** — 维护"当前能连续凑出的区间 $[0,cov]$"，这是这类"完全背包覆盖"问题的通用状态。
3. **推出单枚条件** — 面值 $v \le cov+1$ 才能无缝扩展，否则出现缺口（引理 1、2）。
4. **选定贪心** — 恒取当前可用最大面值；交换论证证明最优（引理 3）。
5. **发现卡点：$m \le 2^{63}$** — 逐枚模拟会超时，转向"分段常量"结构。
6. **乘法批量** — 每种面值只用一段，用除法一次算出这段的枚数（引理 4）。
7. **处理边界** — 最小面值不是 1 则无解；`cov` 用 `__uint128_t` 防溢出，枚数用 `unsigned long long`。
8. **实现要点** — 排序去重、丢弃 $>m$ 的面值（永远用不上）、目标点取 `a[i+1]-1`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 硬币面值种数 | `int`，$\le 2\times 10^5$ |
| $m$ | 需要覆盖的价格上界 | `unsigned long long`，$\le 2^{63}$ |
| $a_1<\dots<a_k$ | 排序去重后的面值，$a_1$ 为最小面值 | `unsigned long long[]` |
| $cov$ | 当前能连续凑出的区间右端点，即 $[0,cov]$ 全可凑出 | `__uint128_t` |
| $cnt$ | 已选硬币枚数 | `unsigned long long`，$\le m$ |
| $target$ | 本段需要把 $cov$ 推到的位置 | `__uint128_t` |
| $times$ | 本段所用面值的枚数 | `__uint128_t` |

### 算法步骤

1. 读入 $n, m$ 与 $n$ 个面值。
2. 升序排序；去重；丢弃所有 $> m$ 的面值（面值超过 $m$ 的硬币永远用不上），得到 $a_1<\dots<a_k$。
3. 若 $k=0$ 或 $a_1 \ne 1$，输出 `No answer!!!` 并结束。
4. 初始化 $cov=0$，$cnt=0$。
5. 对 $i=1,2,\dots,k$：
   1. 令 $v=a_i$。
   2. 令 $target = a_{i+1}-1$（若 $i=k$ 则令 $target=m$）——即"下一枚面值变为可用"的门槛。
   3. 若 $cov \ge target$，说明 $a_{i+1}$ 已经可用，直接进入下一段（`continue`）。
   4. 计算 $times = \lceil (target-cov)/v \rceil$；若当前 $cov < m$，再用 $times' = \lceil (m-cov)/v \rceil$ 收紧（取较小者），避免多拿硬币。
   5. 累加：$cov \mathrel{+}= times\cdot v$，$cnt \mathrel{+}= times$。
   6. 若 $cov \ge m$，跳出循环。
6. 输出 $cnt$。

### 复杂度

- 时间复杂度：$O(n\log n)$（排序）+ $O(n)$（扫描），**与 $m$ 的大小无关**。
- 空间复杂度：$O(n)$。

### 验证状态

- 标程 `P2001.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面样例 `5 31` / `1 2 8 4 16` 输出 `5`，与官方一致。
- 编写暴力 `P2001_brute.cpp`（定义 `dp[c]` = 覆盖连续区间 $[0,c]$ 的最少硬币数，转移 `dp[c+v]=min(dp[c+v],dp[c]+1)`，要求 $v \le c+1$）与对拍脚本 `P2001_check.py`，在 $n\le 12$、$m\le 2000$、面值 $\in[1,60]$ 的随机数据上对拍 **400 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2001 硬币的面值
// 贪心：始终使用「当前能用的最大面值」，可用乘法批量统计次数
#include<bits/stdc++.h>
using namespace std;
using i64=long long;
using u64=unsigned long long;
using u128=__uint128_t;

constexpr int mxn{200005};

int n;
u64 m;
u64 a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	sort(a,a+n);
	//去重，并丢弃大于 m 的面值（面值 > m 的硬币永远用不上）
	int k=0;
	for(int i=0;i<n;++i)
	{
		if(a[i]>m)
			break;
		if(k==0||a[k-1]!=a[i])
			a[k++]=a[i];
	}
	//拼不出 1 就无解
	if(k==0||a[0]!=1)
	{
		cout<<"No answer!!!\n";
		return 0;
	}
	u128 cov=0;//当前能连续拼出的区间 [0,cov]
	u64 cnt=0;//已选的硬币数
	for(int i=0;i<k;++i)
	{
		u64 v=a[i];
		//下一个面值变成「可用」的门槛：cov >= a[i+1]-1
		u128 target=(i+1<k)?(u128)(a[i+1]-1):(u128)m;
		if(cov>=target)
			continue;//a[i+1] 已经可用，贪心直接换更大的面值
		u128 need=target-cov;
		u128 times=(need+v-1)/v;
		//一旦拼满 m 就停手
		if(cov<(u128)m)
		{
			u128 tm=((u128)m-cov+v-1)/v;
			if(tm<times)
				times=tm;
		}
		cov+=(u128)times*v;
		cnt+=(u64)times;
		if(cov>=(u128)m)
			break;
	}
	cout<<cnt<<'\n';
	return 0;
}
```

### 代码说明

- `cov` 用 `__uint128_t`：$m$ 可达 $2^{63}$，累计覆盖量可能超出 `unsigned long long` 的安全范围，用 128 位整数彻底规避溢出。
- `cnt` 用 `unsigned long long`：答案（枚数）最大为 $m \le 2^{63}$，`u64` 足够。
- 上取整写成 `(need+v-1)/v`，全程整数运算，不引入浮点误差。
- `target` 取 `a[i+1]-1` 而不是 `a[i+1]`：只要 `cov ≥ a[i+1]-1` 就有 `a[i+1] ≤ cov+1`，即该面值"可用"，这是引理 1 的直接结论。
- 丢弃 $>m$ 的面值是安全的：任何面值超过 $m$ 的硬币都无法参与凑出 $[1,m]$ 中的数。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
