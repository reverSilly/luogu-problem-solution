# P2902 [USACO08MAR] Pearl Pairing G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** $N$ 颗珍珠（$2\le N\le 10^5$，$N$ 为偶数），$C$ 种颜色（$1\le C\le N$），第 $i$ 种颜色有 $C_i$ 颗，$\sum C_i=N$。要把**全部**珍珠分成 $N/2$ 对，每对两颗颜色**不同**。数据保证有解；输出任意一组方案，每行一对的颜色编号（Special Judge）。

**口径说明。** 输出的是**颜色编号** $a_i,b_i$，不是珍珠的个体编号——题面原文"表示 Bessie 可以将各自颜色为 $a_i$ 和 $b_i$ 的两个珍珠配对"，且输入根本没有给珍珠编号。SPJ 只检查：每行两色不同、每种颜色被使用的总次数恰为 $C_i$。另外"数据保证存在答案"意味着我们**不用处理无解**，但这个"保证"本身藏着解题钥匙（见下）。

**试探 1：动态贪心。** 最自然的想法：每次取剩余数量**最多**的两种颜色各一颗配对，用堆维护，$O(N\log C)$。直觉上"先消耗大户"不会错，但要严格证明"任何时刻都不会把自己逼进只剩一种颜色的死局"，需要一番交换论证；而且 $\log$ 因子和堆的代码量都不小。先放着，找找有没有更静态的结构。

**试探 2：什么时候有解？** 反过来想无解的情形：某种颜色 $c$ 的珍珠**超过一半**（$C_c>N/2$）。每对至多装一颗颜色 $c$，总共只有 $N/2$ 对，装不下——**鸽笼原理直接判死**。所以
$$\text{有解}\Rightarrow \max_i C_i\le N/2.$$
题目保证有解，就是保证 $\max C_i\le N/2$。这个条件会不会也是充分的？如果是，证明充分性的构造过程本身就应该是算法。

**关键构造：排成一排，对折配对。** 把所有珍珠**按颜色排序**摊成一行：颜色 $1$ 的 $C_1$ 颗、颜色 $2$ 的 $C_2$ 颗……同色珍珠在行内是**连续块**，块长 $C_i\le N/2$。现在把行**从中间对折**：第 $i$ 颗（$0\le i<N/2$）与第 $i+N/2$ 颗配对。

为什么一定异色？反证：若第 $i$ 与第 $i+N/2$ 颗同色 $c$，由排序的单调性，**它们之间的所有珍珠**（含两端，共 $N/2+1$ 颗）全是颜色 $c$，于是 $C_c\ge N/2+1>N/2$，与可行性条件矛盾！块长 $\le N/2$ 的连续块，**盖不住相距 $N/2$ 的两个位置**——这就是全部秘密。

再核对"不重不漏"：左半 $[0,N/2)$ 与右半 $[N/2,N)$ 恰好各用一次，$N/2$ 对覆盖全部 $N$ 颗；每颗珍珠的颜色被输出一次，各颜色使用次数自动等于 $C_i$。构造完备。

**实现：连排序都不用。** 颜色编号本来就是 $1..C$ 顺序读入的，按读入顺序把每种颜色展开 $C_i$ 次写进数组，得到的就是有序行——**计数排序的展开步**，$O(N)$。然后一遍循环输出 `a[i]+1` 与 `a[i+N/2]+1`。总复杂度 $O(N+C)$，比堆贪心更快更短。

**边界核对。** $N=2,C=2$（各 $1$ 颗）：行 `1 2`，对 $(1,2)$ ✓。某颜色数量为 $0$（题面未明说 $C_i\ge1$，但"一共 $C$ 种颜色"通常蕴含存在；即便出现 $0$）：展开循环零次，代码天然 robust。$C=1$ 时 $C_1=N>N/2$ 无解，被"保证有解"排除，不用管。

**手造数据核对**（题面只有文字说明没有样例输入输出，第一组按说明构造，其余手造）：

| 输入 | 展开行 | 输出配对 | 核对 |
|---|---|---|---|
| `8 3` + $C=(2,2,4)$ | `1 1 2 2 3 3 3 3` | $(1,3),(1,3),(2,3),(2,3)$ | 与题面说明"每颗颜色 3 与颜色 1、2 配对"一致 ✓ |
| `4 2` + $(2,2)$ | `1 1 2 2` | $(1,2),(1,2)$ | ✓ |
| `2 2` + $(1,1)$ | `1 2` | $(1,2)$ | 最小规模 ✓ |
| `6 3` + $(3,2,1)$ | `1 1 1 2 2 3` | $(1,2),(1,2),(1,3)$ | 颜色 1 恰好用 $3$ 次，块长 $3=N/2$ 贴边 ✓ |
| `10 4` + $(1,2,3,4)$ | `1 2 2 3 3 3 4 4 4 4` | $(1,3),(2,4),(2,4),(3,4),(3,4)$ | 各颜色用量 $1,2,3,4$ 逐一吻合 ✓ |

第 4 组专打"最大块恰好 $N/2$"的贴边情形：此时同色块两端相距 $N/2-1$，仍盖不住相距 $N/2$ 的配对位，构造依然成立。

## 二、思维链：完整证明

**记号。** 颜色集合 $\{0,\dots,C-1\}$（内部 $0$-based），数量 $C_c\ge0$，$\sum_c C_c=N$（偶数）。**方案**是 $N/2$ 个无序对 $(a_k,b_k)$，满足每对 $a_k\ne b_k$，且每种颜色 $c$ 在全部 $2\cdot(N/2)=N$ 个输出位中恰出现 $C_c$ 次。展开数组 $a[0..N)$：按颜色升序把颜色 $c$ 重复写 $C_c$ 次。配对规则：对 $i\in[0,N/2)$，输出 $(a[i],a[i+N/2])$。

---

### 引理 1（可行性的必要条件：$\max C_c\le N/2$）

若存在合法方案，则对所有颜色 $c$ 有 $C_c\le N/2$。

*证明*：固定颜色 $c$。每对 $(a_k,b_k)$ 中 $a_k\ne b_k$，故**至多一个**位置是颜色 $c$。方案共 $N/2$ 对，颜色 $c$ 的总出现次数 $\le N/2$。而合法性要求该次数恰为 $C_c$，故 $C_c\le N/2$。对所有 $c$ 成立。证毕。

**推论**：题面"数据保证存在答案" $\Rightarrow$ 输入必满足 $\max_c C_c\le N/2$。下文直接把这个不等式当已知条件用。

---

### 引理 2（展开行的结构：同色连续块）

数组 $a$ 单调不减；颜色 $c$ 占据的位置恰为连续区间
$$\Bigl[\,\sum_{d<c}C_d,\ \sum_{d\le c}C_d\,\Bigr),$$
长度 $C_c$；且 $\sum_c C_c=N$ 保证展开恰好填满 $a[0..N)$。

*证明*：构造过程按 $c=0,1,\dots,C-1$ 顺序、每个 $c$ 连续写 $C_c$ 次，故位置指针从 $0$ 单调推进，颜色 $c$ 的写入区间首尾相接、起点为 $\sum_{d<c}C_d$、长度为 $C_c$，单调不减显然。总写入数 $\sum_c C_c=N$，无越界无空洞（$C_c=0$ 时区间为空，同样成立）。证毕。

---

### 引理 3（错位半周期配对必异色）

对所有 $i\in[0,N/2)$，$a[i]\ne a[i+N/2]$。

*证明*：反证。设某个 $i$ 使 $a[i]=a[i+N/2]=c$。由引理 2，$a$ 单调不减，故对每个 $j\in[i,\,i+N/2]$ 有
$$c=a[i]\le a[j]\le a[i+N/2]=c,$$
即 $a[j]=c$。这给出颜色 $c$ 的 $N/2+1$ 个**互不相同**的位置，故 $C_c\ge N/2+1>N/2$，与引理 1 推论（$\max C_c\le N/2$）矛盾。证毕。

**直观**：同色块是长度 $\le N/2$ 的连续段，而配对两位置相距 $N/2$（跨度 $N/2+1$ 个格子），短块盖不住长跨度。贴边情形 $C_c=N/2$ 时块跨度恰 $N/2$ 个格子，仍差一格，构造不失效。

---

### 引理 4（不重不漏：输出是合法方案）

配对规则产生的 $N/2$ 行输出满足：每行两色不同；每种颜色 $c$ 恰出现 $C_c$ 次。

*证明*：位置使用：左半 $\{i:i\in[0,N/2)\}=[0,N/2)$，右半 $\{i+N/2:i\in[0,N/2)\}=[N/2,N)$，两集合不交、并为 $[0,N)$，故**每个位置恰被输出一次**。每行两色不同由引理 3。颜色计数：位置 $j$ 输出颜色 $a[j]$，每个位置一次，故颜色 $c$ 的输出次数 $=|\{j:a[j]=c\}|=C_c$（引理 2 的块长）。证毕。

---

### 引理 5（复杂度）

时间 $O(N+C)$，空间 $O(N)$。

*证明*：读入 $C$ 个数量 $O(C)$；展开循环总写入 $\sum C_c=N$ 次，$O(N)$（**无需比较排序**：颜色按读入顺序天然升序，这是计数排序的展开步）；输出 $N/2$ 行，$O(N)$。空间：数组 $a$ 共 $N\le10^5$ 个 `int`，约 $400$ KB。对比堆贪心的 $O(N\log C)$，本构造去掉了对数因子且代码只有两个循环。证毕。

---

### 定理

程序对任何满足"保证有解"的输入输出一组合法配对方案，时间 $O(N+C)$、空间 $O(N)$。

*证明*：引理 1 把"保证有解"翻译成 $\max C_c\le N/2$；引理 2 保证展开行有序且同色成块、块长 $=C_c$；引理 3 用反证 + 单调性证明错位半周期的每对异色；引理 4 证明位置不重不漏、颜色计数恰为 $C_c$，即输出是合法方案；引理 5 给出复杂度。证毕。

**附注（为什么不需要验证有解）**：若输入无解（$\max C_c>N/2$），引理 3 的反证不再成立，构造可能输出同色对；但题面保证有解，此分支不存在。若想 robust，可在读入时检查 $\max C_c\le N/2$，本题不需要。

## 三、模式总结（按实际思考顺序）

1. **consider easier version** — 先放下构造，问"什么时候有解"：可行性判定往往比构造简单，而且判定条件就是构造的钥匙。
2. **explore its property** — 每对至多装一颗某色 + 只有 $N/2$ 对 $\Rightarrow$ 鸽笼给出必要条件 $\max C_i\le N/2$；"保证有解"即保证此不等式。
3. **consider easier version** — 堆贪心"每次取最多的两色"可行但要交换论证 + $O(N\log C)$；寻找一次性静态构造。
4. **reduce to easier problem** — 按颜色展开成有序行（读入顺序即颜色顺序，计数排序展开步 $O(N)$），配对问题变成行上的位置匹配。
5. **explore its property** — 有序行中同色是连续块，块长 $=C_i\le N/2$；"块短"是可用结构。
6. **classic problem solution** — 对折 / 错位半周期配对：$i\leftrightarrow i+N/2$；同色对会迫使块长 $\ge N/2+1$，反证矛盾。
7. **discuss by category** — 边界：$N=2$ 最小规模；块长贴边 $N/2$ 仍成立；$C_i=0$ 天然 robust；输出颜色编号而非珍珠编号（SPJ 只查异色与计数）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n,c` | 珍珠总数（偶）/ 颜色数 | `int` | 读入 |
| `k` | 当前颜色的数量 $C_i$ | `int` | 每颜色读入 |
| `cnt` | 展开指针，已写入的珍珠数 | `int`，初值 $0$ | 循环头声明，随展开推进到 $N$ |
| `a[j]` | 有序行第 $j$ 颗珍珠的颜色（$0$-based） | `int[mxn]` | 按颜色顺序展开，天然单调不减 |
| `mxn` | $10^5+5$ | `constexpr int` | 数组尺寸 |
| 输出 | 第 $i$ 行 `a[i]+1 a[i+n/2]+1` | — | 左半 $[0,N/2)$ 配右半 $[N/2,N)$ |

### 算法步骤

1. I/O 加速三行；读 $N,C$。
2. 对颜色 $i=0..C-1$：读 $C_i$，把 $i$ 连续写入 `a[cnt..cnt+C_i)`（展开即排序）。
3. 对 $i=0..N/2-1$：输出 `a[i]+1` 与 `a[i+n/2]+1`（转回 $1$-based 颜色编号）。

### 复杂度

- 时间 $O(N+C)$；空间 $O(N)\approx400$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；5 组手造数据（题面说明的 $8$ 颗 $3$ 色、最小规模 $N=2$、最大块贴边 $N/2$、四色混合）逐行核对：每对异色、各颜色用量恰为 $C_i$，全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2902 Pearl Pairing G
// 按颜色展开成有序序列（计数排序，O(N)），第 i 颗与第 i+N/2 颗配对
// 可行性保证 max C_i<=N/2 ⇒ 同色块长<=N/2 ⇒ 错位半周期必异色
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n,c,a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>c;
	for(int i=0,k,cnt=0;i<c;++i)
	{
		cin>>k;
		while(k--)
			a[cnt++]=i;	// 按颜色顺序展开，天然有序
	}
	for(int i=0;i<n/2;++i)
		cout<<a[i]+1<<' '<<a[i+n/2]+1<<'\n';
	return 0;
}
```

### 代码说明

- **没有 `sort`**：颜色编号按 $0..C-1$ 顺序读入，展开写入天然单调不减——这是计数排序的"展开"步，$O(N)$ 完成排序效果。
- `cnt` 声明在 `for` 初始化里、跨迭代存活，展开结束时恰为 $N$（$\sum C_i=N$）；`k` 每轮读入后 `while(k--)` 消耗到 $-1$，下轮重新读入，无残留。
- 配对循环只跑 $N/2$ 次：左半 $[0,N/2)$ 每颗配右半对应颗，位置不重不漏（引理 4），**不需要**记录"用过没用"。
- 异色性完全由数学保证（引理 3），代码里**没有任何检查或回退**——这正是"证明先行"的红利：构造的正确性在写代码前已经关闭。
- 输出 `+1` 转回 $1$-based 颜色编号；本题无 INF、无不可达状态，数组默认零值不参与任何语义。
- 若把配对写成 `i` 与 `(i+n/2)%n` 的"旋转"视角也一样：本质是环上相距半周期的完美匹配，左半右半只是它的无环写法。
