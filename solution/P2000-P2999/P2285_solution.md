# P2285 [HNOI2004] 打鼹鼠 — 题解

## 一、解题过程：人类思考叙事

题意重述：有一个 $n\times n$ 的网格（$n\le10^3$），接下来有 $m$ 条记录 $(t_i,x_i,y_i)$（$m\le10^4$，$t_i$ 不降），表示 $t_i$ 时刻在 $(x_i,y_i)$ 出现一只鼹鼠。机器人初始位置可以任意选定；每个单位时间只能走到上下左右相邻格或停在原地。机器人只有在某时刻恰好和鼹鼠同格才能打到它。问最多能打多少只。

最直接的想法是按时间做 DP：设 $f(t,x,y)$ 表示 $t$ 时刻在 $(x,y)$ 最多打了多少只。但 $t$ 最大 $2.5\times10^7$，状态数是 $2.5\times10^7\times n^2$，完全不可能。必须换视角。

注意到：**没有鼹鼠出现的时刻和位置其实无关紧要**，机器人只可能在"某只鼹鼠出现的时刻、在该鼹鼠的格子"完成一次有效击杀。于是把每只鼹鼠看成一个事件节点，问的是：最多能按顺序访问多少个事件？

两个事件 $j\to i$（$t_j\le t_i$）能否被同一个机器人依次打到？机器人从 $(x_j,y_j)$ 到 $(x_i,y_i)$，中间有 $\Delta t=t_i-t_j$ 个单位时间。在网格上每步最多让曼哈顿距离减少 $1$，所以必要条件是两个格子的曼哈顿距离不超过 $\Delta t$。反过来，如果距离不超过 $\Delta t$，机器人沿最短路走过去，剩下的时间原地等待即可。因此：

$$j\text{ 能接到 }i\iff |x_i-x_j|+|y_i-y_j|\le t_i-t_j.$$

于是所有事件构成一张 DAG（按时间定向），要求最长链。设 $dp[i]$ 表示"以事件 $i$ 结尾的最长链长度"，则
$$dp[i]=1+\max_{\substack{j<i\\ |x_i-x_j|+|y_i-y_j|\le t_i-t_j}} dp[j],$$
若没有合法的 $j$，则 $dp[i]=1$——因为机器人初始位置自由，可以直接从事件 $i$ 的格子开始等它出现。答案是 $\max_i dp[i]$。

$m\le10^4$，$O(m^2)$ 约 $5\times10^7$ 次比较，完全跑得动，不需要更复杂的数据结构。

几个容易错的点：

- **$dp$ 初值必须是 $1$**，不是 $0$：任意一只鼹鼠都能作为第一条。
- **同一时刻的多只鼹鼠最多打一只**。如果两只鼹鼠时刻相同但格子不同，曼哈顿距离至少为 $1$，而时间差为 $0$，转移条件不成立，所以 DP 不会把它们接在一起；题目又保证"同一时刻同一地点只出现一只"，因此不会漏掉合法的同刻转移。
- **输入时间不降**，所以下标顺序就是时间顺序，直接 $j<i$ 枚举即可；若题目不保证，则需要先按 $t$ 排序。
- 曼哈顿距离用 `abs` 计算，$t$ 的差最大 $2.5\times10^7$，`int` 足够。

手工验证：$n=3$，事件 $(1,1,1),(2,1,2),(3,1,3)$。相邻事件距离都是 $1$、时间差都是 $1$，可以连成 $3$ 条，答案 $3$。另一组：$(1,1,1)$ 与 $(1,2,2)$ 同刻异格，只能打一只，答案 $1$。程序输出与预期一致。

## 二、思维链：完整证明

### 引理 1（两点间的可达判定）

设机器人在 $t_1$ 时刻位于 $(x_1,y_1)$，在 $t_2\ge t_1$ 时刻位于 $(x_2,y_2)$。这可行，当且仅当
$$|x_1-x_2|+|y_1-y_2|\le t_2-t_1.$$

**证明**：

**必要性。** 机器人每经过一个单位时间，要么原地不动，要么走到上下左右相邻格。一次移动使横坐标或纵坐标改变 $1$，所以曼哈顿距离 $d(P,Q)=|P_x-Q_x|+|P_y-Q_y|$ 在一次移动后相对原位置至多增加 $1$（三角不等式：$d(P',Q)\le d(P',P)+d(P,Q)=1+d(P,Q)$）。经过 $t_2-t_1$ 个单位时间，总位移的曼哈顿距离不超过步数，即 $d\le t_2-t_1$。

**充分性。** 设 $d=|x_1-x_2|+|y_1-y_2|\le t_2-t_1$。机器人先沿横向从 $x_1$ 单调走到 $x_2$（用 $|x_1-x_2|$ 步），再沿纵向从 $y_1$ 单调走到 $y_2$（用 $|y_1-y_2|$ 步），共 $d$ 步。由于起点、终点都在网格内，单调行走过程中横纵坐标始终介于两端点之间，不会走出 $n\times n$ 网格。剩余 $t_2-t_1-d\ge0$ 个单位时间原地等待。等待是题目允许的操作。故可行。$\square$

### 引理 2（任意合法链都可实现）

设事件序列 $i_1,i_2,\dots,i_k$ 满足 $t_{i_1}\le t_{i_2}\le\cdots\le t_{i_k}$，且对每个相邻对都有 $|x_{i_{r+1}}-x_{i_r}|+|y_{i_{r+1}}-y_{i_r}|\le t_{i_{r+1}}-t_{i_r}$。则存在一种机器人策略，依次在这些事件发生的时刻打到它们。

**证明**：对 $r$ 归纳构造机器人轨迹。

- 初始时（时刻 $0$）把机器人放在事件 $i_1$ 的格子并等待到 $t_{i_1}$，打到第一只。
- 假设已在 $t_{i_r}$ 时刻位于事件 $i_r$ 的格子。由引理 1，可在 $t_{i_{r+1}}$ 之前从该格走到事件 $i_{r+1}$ 的格子；按引理 1 的构造行走并等待，正好在 $t_{i_{r+1}}$ 时刻到达并打到第 $r+1$ 只。

每一段轨迹都在规定的时间区间内完成，段与段只在端点时刻衔接，故整体是一个合法策略。$\square$

### 引理 3（最优策略与最长链等价）

设一次机器人策略实际打到的事件集合为 $H$，按时间排序为 $i_1,\dots,i_k$。则对任意相邻两项有 $t_{i_r}\le t_{i_{r+1}}$ 且曼哈顿距离不超过时间差。因此 $H$ 是 DAG 中的一条链，$k$ 不超过最长链长度。反之，由引理 2，任意一条链都能被某个策略全部打到。故"最多打到的鼹鼠数"等于"事件 DAG 的最长链长度"。

**证明**：

先证 $H$ 是链。机器人同一时刻只能在一个格子，而同一时刻同一地点最多一只鼹鼠，所以 $H$ 中同一时刻至多一个事件（若同一时刻有两个不同格子的事件，机器人不可能同时在两处）。按时间排序后，相邻两次击杀之间机器人从 $i_r$ 的格子移动到了 $i_{r+1}$ 的格子，用时 $t_{i_{r+1}}-t_{i_r}$，由引理 1 的必要性得距离不超过时间差。

再证反向。引理 2 给出了实现任意链的策略，该策略至少打到链上的所有事件，所以最优击杀数不小于最长链长度。两个方向合起来即得相等。$\square$

### 引理 4（DP 状态与转移的正确性）

设 $dp[i]$ 表示以事件 $i$ 为最后一个事件的最长链长度。则
$$dp[i]=1+\max\Bigl(\{0\}\cup\{dp[j]:j<i,\ |x_i-x_j|+|y_i-y_j|\le t_i-t_j\}\Bigr).$$
特别地，当集合为空时 $dp[i]=1$。

**证明**：对 $i$ 归纳（按输入下标，$t$ 不降）。

- **下界**：任取合法的 $j$，由归纳假设存在一条长度为 $dp[j]$ 的链以 $j$ 结尾。由转移条件，$j$ 可以接到 $i$ 后面，得到长度 $dp[j]+1$ 的链；空链接上 $i$ 得到长度 $1$ 的链。故 $dp[i]$ 不小于右端。
- **上界**：任取一条以 $i$ 结尾的链。若链只有 $i$，长度为 $1$。否则设 $i$ 的前驱为 $j$。由于 $t$ 不降且 $j\ne i$，有 $j<i$；链的合法性给出转移条件。删去 $i$ 后得到以 $j$ 结尾的链，长度不超过 $dp[j]$，故原链长度不超过 $dp[j]+1$，也就不能超过右端。

两方向合起来得到等式。$\square$

**关于"前驱一定在 $i$ 之前"的说明**：输入保证 $t$ 不降，所以 $t_j\le t_i$。若 $t_j=t_i$，两个不同事件必须位于不同格子（同刻同格最多一只），曼哈顿距离至少 $1>0=t_i-t_j$，不满足转移条件；因此真正合法的前驱必满足 $t_j<t_i$，从而在输入中位于 $i$ 之前。枚举 $j<i$ 不会漏解。$\square$

### 定理（答案正确）

由引理 3，答案是事件 DAG 的最长链长度；由引理 4，$dp[i]$ 正确计算了以 $i$ 结尾的最长链长度；最长链必以某个事件结尾，故 $\max_i dp[i]$ 就是答案。$\square$

### 复杂度

外层枚举 $i$ 共 $m$ 次，内层枚举 $j<i$，总转移次数 $m(m-1)/2$，时间 $O(m^2)$；存储 $t,x,y,dp$ 四个长度 $m$ 的数组，空间 $O(m)$。$\square$

## 三、模式总结（按实际思考顺序）

- explore its property — 两个事件能否连续打到，只取决于曼哈顿距离与时间差的大小关系。
- reduce to easier problem — 忽略没有鼹鼠的时刻，把每只鼹鼠抽象成 DAG 节点。
- classic problem solution — 按时间定向后在 DAG 上做最长路 DP。
- discuss by category — 同刻异格不可转移；初始位置自由使每个点都可以作为链首。
- explore its property — 合法链与真实机器人轨迹一一对应（最短路 + 等待）。
- handle implementation details — $dp$ 初值 $1$、输入已按时间排序、距离用 `abs`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 说明 |
|------|------|-------------|
| $n$ | 网格边长 | 输入，仅用于理解，不参与计算 |
| $m$ | 鼹鼠事件数 | 输入 |
| $t[i]$ | 第 $i$ 只鼹鼠出现时刻 | 输入，不降 |
| $x[i],y[i]$ | 第 $i$ 只鼹鼠的格子 | 输入 |
| $dp[i]$ | 以事件 $i$ 结尾的最长合法链长度 | 计算时先置 $1$ |
| $ans$ | 所有 $dp[i]$ 的最大值 | 初值 $0$ |

### 算法步骤

1. 读入 $n,m$ 与所有事件 $(t_i,x_i,y_i)$。
2. 对 $i=0..m-1$：
   1. 置 $dp[i]=1$（机器人可从该格开始等待）。
   2. 对每个 $j<i$，若 $t_i-t_j\ge|x_i-x_j|+|y_i-y_j|$，用 $dp[j]+1$ 更新 $dp[i]$。
   3. 用 $dp[i]$ 更新 `ans`。
3. 输出 `ans`。

### 复杂度

- 时间：$O(m^2)$，$m\le10^4$ 时约 $5\times10^7$ 次转移。
- 空间：$O(m)$。

### 验证状态

已用 `g++ -std=c++20 -O2` 编译通过；与"按时间逐刻、逐格做 DP"的独立暴力在 $300$ 组随机小数据（含同刻多鼹鼠、原地等待、长间隔）上完全一致，并手工验证了 $5$ 组边界用例。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int n,m,t[mxn],x[mxn],y[mxn],dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<m;++i)
		cin>>t[i]>>x[i]>>y[i];
	int ans=0;
	for(int i=0;i<m;++i)
	{
		dp[i]=1;
		for(int j=0;j<i;++j)
			if(t[i]-t[j]>=abs(x[i]-x[j])+abs(y[i]-y[j]))
				dp[i]=max(dp[i],dp[j]+1);
		ans=max(ans,dp[i]);
	}
	cout<<ans<<'\n';
	return 0;
}
```
