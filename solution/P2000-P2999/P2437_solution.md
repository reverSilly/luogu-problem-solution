# P2437 蜜蜂路线 — 题解

## 一、解题过程：人类思考叙事

先把题目读薄：一条编号为 $1,2,3,\dots$ 的蜂房带子，蜜蜂只能**从标号小的蜂房爬到标号大的相邻蜂房**，问从 $m$ 爬到 $n$（$m<n$）有多少条不同路线。数据范围 $1\le m,n\le 1000$，标签是「高精度 / 递推 / Fibonacci 数列」。

**第一步：把「相邻」翻译成数学。** 题图是一条锯齿状排列的六边形蜂房带：第 $i$ 个蜂房与第 $i+1$ 个共用一条边，同时因为错位排列，它还与第 $i+2$ 个共用一条边；再往后（$i+3$ 及以后）就不再有公共边了。题目备注「右上角应为 $n-1$」也在提示：图上画的就是 $m,m+1,\dots,n-1,n$ 这样一条连续编号的带子。于是移动规则被精确刻画为：

$$i \longrightarrow i+1 \quad\text{或}\quad i \longrightarrow i+2 .$$

方向只能变大，所以**不会走回头路，也不会绕圈**，一条路线就是一个严格递增的蜂房序列。

**第二步：先手玩小数据。** 令 $d=n-m$。

- $d=1$：只能 $m\to m+1$，$1$ 种。
- $d=2$：$m\to m+1\to m+2$，或 $m\to m+2$，$2$ 种。
- $d=3$：$1{+}1{+}1$、$1{+}2$、$2{+}1$，$3$ 种。
- $d=4$：$1111,112,121,211,22$，$5$ 种。

$1,1,2,3,5$——Fibonacci 的味道扑面而来。而且注意到：把整条路线的标号都减去 $m-1$，就得到一条从 $1$ 到 $d+1$ 的路线，相邻关系只跟标号差有关，所以**答案只依赖 $d=n-m$，与 $m$ 具体是多少无关**。这一步把两个变量压成了一个。

**第三步：为什么是 Fibonacci？** 盯住**最后一步**：要落到 $n$，上一步只能站在 $n-1$（走 $+1$）或 $n-2$（走 $+2$）。这两类路线互不重叠、又穷尽所有可能，于是

$$g(d)=g(d-1)+g(d-2),\qquad g(0)=1,\ g(1)=1 .$$

$g(0)=1$ 是「原地不动」这一条空路线，它不是凑数：$d=2$ 时 $g(2)=g(1)+g(0)=2$，正好把手算结果对上。若把 $g(0)$ 设成 $0$，整条数列就全错了。

到这里算法已经出来了：递推 $d$ 次。但**真正的坑在数值规模**。

**第四步：碰壁——整数装不下。** $d$ 最大 $999$，答案是 $F_{1000}$。它有多大？Fibonacci 增长率是 $\varphi\approx1.618$，$F_{1000}\approx 4.3\times10^{208}$，**209 位十进制数**。而 `long long` 只有 19 位（$F_{93}=12200160415121876738$ 就已经超过 $2^{63}-1$，即 $d\ge 92$ 就爆），`__int128` 也只有 38 位（$d\ge185$ 就爆）。用 `double`/`long double` 更不行：它们只有 15～19 位有效数字，而题目要输出**精确的整数**，后面一百多位全是垃圾。标签里的「高精度」不是装饰。

**第五步：好消息——只需要加法。** 一般高精度题要写加、减、乘、除，这里递推式只有 $+$。所以只要实现「大数 $+$ 大数」，而且可以**压位**：把十进制数按每 $9$ 位切成一段存进 `int`（$10^9$ 进制），一次加法处理 9 位十进制，$209$ 位只需 $24$ 段。两数相加每段最大 $2\times(10^9-1)+1<2^{31}$，`int` 不会溢出。

**第六步：位数上界要算清楚，不能拍脑袋开数组。** 严格地：$F_k<2^k$（归纳即得），故 $F_{1000}<2^{1000}=(2^{10})^{100}< (10^4)^{100}=10^{400}$，即最多 $400$ 位十进制、最多 $\lceil 400/9\rceil=45$ 段。开 `mxl{64}`（容量 $576$ 位）绰绰有余。

**第七步：几个实现细节。**

1. 递推时 $g(i-1)$ 的段数不少于 $g(i-2)$ 的段数（数列单调不减），所以循环按 `len[i-1]` 走，对 $j\ge len[i-2]$ 的段显式跳过而不是依赖「全局数组默认为 0」。
2. 最高段加完可能还有进位，要额外补一段；进位只可能是 $1$。
3. 输出时**最高段正常打印**（不能带前导零），**其余每段必须补足 9 位**（`setw(9)<<setfill('0')`），否则中间那些「000000012」会被打印成「12」，整个数就错了。
4. $m=n$ 虽然题目保证不会出现，但 $g(0)=1$ 的初始化天然覆盖了它，不需要特判。

手算验证：$m=1,n=4\Rightarrow 3$；$m=1,n=10\Rightarrow F_{10}=55$；$m=1,n=1000\Rightarrow$ 209 位的 $F_{1000}$，与独立实现一致。

## 二、思维链：完整证明

下面把每一步都钉死。记 $B=10^9$（压位进制），$F_1=F_2=1,\ F_k=F_{k-1}+F_{k-2}$ 为标准 Fibonacci 数列，$g(d)$ 为「从某个蜂房出发、跨越标号差 $d$」的路线数。

### 引理 1（移动集合的刻画）

在题图的蜂房带上，从蜂房 $i$ 出发一步能到达的蜂房恰为 $i+1$ 与 $i+2$。

*证明*：题图中蜂房排成一条锯齿带，相邻编号的蜂房共用一条边；由于错位排列，第 $i$ 个蜂房还与第 $i+2$ 个蜂房共用一条边，而与编号差 $\ge 3$ 的蜂房没有公共边（中间隔着别的蜂房）。题目规定只能爬向**标号大的相邻**蜂房，故候选只有 $i+1,i+2$，且两者都合法（标号更大且相邻）。反之任何一步都必须落在这两者之一。证毕。

> 这条引理是「读图」得到的建模前提；后续所有结论都以它为唯一几何输入。若把移动集合换成别的（例如只允许 $+1$），下面的递推会相应退化，方法论不变。

### 引理 2（平移不变性：答案只依赖 $d=n-m$）

从 $m$ 到 $n$ 的路线数等于从 $1$ 到 $n-m+1$ 的路线数。

*证明*：设一条路线为蜂房序列 $m=c_0<c_1<\dots<c_k=n$，由引理 1 有 $c_{t+1}-c_t\in\{1,2\}$。定义映射 $\Phi$：把每个标号减去 $m-1$，得到 $1=c_0-m+1<c_1-m+1<\dots<c_k-m+1=n-m+1$。差分不变，故像序列的每一步仍属于 $\{1,2\}$，由引理 1 它是一条合法路线。$\Phi$ 的逆映射是「每个标号加 $m-1$」，同理合法，故 $\Phi$ 是双射。两个集合等势，路线数相等。证毕。

因此下文只研究 $g(d):=$ 从 $1$ 到 $d+1$ 的路线数，$d=n-m\in[0,999]$。

### 引理 3（路线 $\leftrightarrow$ 有序拆分的双射）

$g(d)$ 等于把整数 $d$ 写成**有序**的 $1,2$ 之和的方案数（即 $d$ 的、部分只取 $1$ 或 $2$ 的组成/composition 数），其中 $d=0$ 对应空和，计 $1$ 种。

*证明*：
**（路线 $\to$ 拆分）** 给定路线 $1=c_0<c_1<\dots<c_k=d+1$，令 $s_t=c_t-c_{t-1}\in\{1,2\}$，则 $\sum_{t=1}^{k}s_t=c_k-c_0=d$，得到一个合法拆分。
**（拆分 $\to$ 路线）** 给定 $(s_1,\dots,s_k)$，$s_t\in\{1,2\}$，$\sum s_t=d$，令 $c_t=1+\sum_{u\le t}s_u$。则 $c_0=1$，$c_k=d+1$，序列严格递增，且所有 $c_t\in[1,d+1]$（部分和单调），相邻差为 $s_t\in\{1,2\}$，由引理 1 每一步合法，故是一条路线。
两个映射互逆（差分与前缀和互为逆运算），故为双射。$d=0$ 时只有 $k=0$ 的空序列，对应「原地不动」，计 $1$。证毕。

### 引理 4（递推式与初值）

$g(0)=1,\ g(1)=1$，且对 $d\ge2$ 有 $g(d)=g(d-1)+g(d-2)$。

*证明*：由引理 3，只需对拆分数。$d=0$：空拆分唯一，$g(0)=1$。$d=1$：只能是 $(1)$，$g(1)=1$。

设 $d\ge2$，把全部拆分按**最后一个部分** $s_k$ 分成两类：
- $s_k=1$：去掉末项得到 $d-1$ 的一个拆分；反之给 $d-1$ 的任一拆分末尾添 $1$ 得到本类的一个拆分。两操作互逆，故本类数目 $=g(d-1)$。
- $s_k=2$：同理本类数目 $=g(d-2)$（$d\ge2$ 保证 $d-2\ge0$，$g(d-2)$ 有定义）。

两类不交（末项不同）且穷尽（末项只能是 $1$ 或 $2$），由加法原理 $g(d)=g(d-1)+g(d-2)$。证毕。

**边界为何必须是 $g(0)=1$**：若误设 $g(0)=0$，则 $g(2)=g(1)+g(0)=1$，与手算的 $2$ 矛盾；错误会沿递推传播到所有 $d$。$g(0)=1$ 的组合意义就是引理 3 中的空拆分。

### 引理 5（闭式对应）

$g(d)=F_{d+1}$，其中 $F_1=F_2=1$。

*证明*：对 $d$ 归纳。$d=0$：$g(0)=1=F_1$；$d=1$：$g(1)=1=F_2$。设对 $d-1,d-2$ 成立（$d\ge2$），则 $g(d)=g(d-1)+g(d-2)=F_d+F_{d-1}=F_{d+1}$。证毕。

于是本题答案为 $F_{n-m+1}$。特别地 $m=1,n=4$ 时 $F_4=3$，$m=1,n=10$ 时 $F_{10}=55$，与手算一致。

### 引理 6（为什么必须高精度：位数的上下界）

(a) 对 $k\ge1$ 有 $F_k<2^k$；从而 $d\le999$ 时答案 $F_{d+1}\le F_{1000}<2^{1000}<10^{400}$，即十进制位数 $\le400$，$B=10^9$ 进制段数 $\le\lceil400/9\rceil=45$。

(b) $F_{93}=12200160415121876738>2^{63}-1$，故 $d\ge92$ 时 `long long` 溢出；$F_{186}\approx3.33\times10^{38}>2^{127}-1\approx1.70\times10^{38}$，故 $d\ge185$ 时 `__int128` 也溢出。

*证明*：
(a) 归纳：$F_1=1<2$，$F_2=1<4$；设 $F_{k-1}<2^{k-1},F_{k-2}<2^{k-2}$，则 $F_k<2^{k-1}+2^{k-2}=3\cdot2^{k-2}<4\cdot2^{k-2}=2^k$。于是 $F_{1000}<2^{1000}=(2^{10})^{100}=1024^{100}<(10^4)^{100}=10^{400}$。一个小于 $10^{400}$ 的正整数至多 $400$ 位十进制；每段装 $9$ 位，故至多 $\lceil400/9\rceil=45$ 段。取 `mxl=64`（容量 $576$ 位）安全。
(b) 直接计算（可由递推逐项验证）：$F_{92}=7540113804746346429<2^{63}-1=9223372036854775807$，而 $F_{93}=12200160415121876738>2^{63}-1$；$F_{186}=332825110087067562321196029789634457848>2^{127}-1$。由引理 5，$d=92$ 对应 $F_{93}$、$d=185$ 对应 $F_{186}$。证毕。

**推论**：任何定长整数类型都不够；浮点类型只有 $\le19$ 位有效数字，无法给出精确的 209 位整数。必须用任意精度表示。又因递推只含加法，**只需实现高精度加法**。

### 引理 7（压位表示与加法正确性）

设大数 $X$ 用段数组 $x_0,\dots,x_{l-1}$ 表示，$X=\sum_{j=0}^{l-1}x_jB^j$，$0\le x_j<B$，$x_{l-1}\ne0$（$X>0$）。算法

```
carry=0
for j=0..l-1:
    s = x[j] + y[j] + carry      // y 的缺失段视为 0
    z[j] = s % B ; carry = s / B
if carry: z[l++] = carry
```

（其中 $l=\max(l_x,l_y)$）得到的 $z$ 恰表示 $X+Y$，且每段仍 $<B$。

*证明*：先证**段值合法**：$x_j,y_j\le B-1$，且归纳假设 $carry\le1$，故 $s\le 2B-1$，于是 $s/B\le1$（进位仍 $\le1$，归纳成立），$s\%B<B$。初始 $carry=0\le1$。末尾若 $carry=1$，新段值为 $1<B$，合法。

再证**数值正确**。断言：对每个 $k\in[0,l]$，
$$\sum_{j<k}z_jB^j+carry_k\cdot B^k=\sum_{j<k}(x_j+y_j)B^j,$$
其中 $carry_k$ 是处理完第 $k-1$ 段后的进位（$carry_0=0$），缺失段按 $0$ 计。

对 $k$ 归纳。$k=0$：两边都是 $0$。设对 $k$ 成立，则
$$\sum_{j<k+1}z_jB^j+carry_{k+1}B^{k+1}
=\sum_{j<k}z_jB^j+(s_k\bmod B)B^k+\lfloor s_k/B\rfloor B^{k+1}
=\sum_{j<k}z_jB^j+s_kB^k.$$
由归纳假设 $\sum_{j<k}z_jB^j=\sum_{j<k}(x_j+y_j)B^j-carry_kB^k$，代入并用 $s_k=x_k+y_k+carry_k$：
$$=\sum_{j<k}(x_j+y_j)B^j-carry_kB^k+(x_k+y_k+carry_k)B^k=\sum_{j<k+1}(x_j+y_j)B^j.$$
断言对 $k+1$ 成立。取 $k=l$：若 $carry_l=0$，则 $\sum_{j<l}z_jB^j=X+Y$；若 $carry_l=1$，算法把它写成第 $l$ 段，于是 $\sum_{j<l+1}z_jB^j=X+Y$。两种情形都表示 $X+Y$。证毕。

**关于「缺失段」**：本实现中 $l=len[i-1]\ge len[i-2]$（引理 8），对 $j\ge len[i-2]$ 显式不加 $y_j$，等价于把缺失段当 $0$，与引理 7 的前提一致。这里**不依赖全局数组的零初始化**，逻辑自洽。

### 引理 8（段数单调不减）

对 $i\ge1$ 有 $len[i]\ge len[i-1]$，其中 $len[i]$ 是 $g(i)$ 的段数。

*证明*：由引理 4，$g(i)=g(i-1)+g(i-2)\ge g(i-1)$（$g\ge0$）。对正整数 $X\ge Y>0$，$X$ 的十进制位数不少于 $Y$ 的位数（否则 $X<10^{t}\le Y$，矛盾，$t$ 为 $Y$ 的位数）；段数 $=\lceil\text{位数}/9\rceil$ 是位数的单调不减函数，故 $len[i]\ge len[i-1]$。证毕。

这保证递推循环只需按 `len[i-1]` 遍历，不会漏掉 $g(i-2)$ 的任何非零段。

### 引理 9（输出格式正确性）

设 $z_0,\dots,z_{l-1}$ 是 $X>0$ 的合法压位表示（$z_{l-1}\ne0$）。则「先正常输出 $z_{l-1}$，再依次把 $z_{l-2},\dots,z_0$ 各补足 9 位输出」得到的字符串恰为 $X$ 的十进制表示（无前导零）。

*证明*：$X=\sum_{j<l}z_jB^j$，$B=10^9$。把每个 $z_j$（$j<l-1$）写成定长 9 位十进制串 $S_j$（不足补前导零，因 $z_j<10^9$ 故恰好 9 位够用），$z_{l-1}$ 写成不含前导零的串 $S_{l-1}$（非空，因 $z_{l-1}\ge1$）。则拼接串 $S_{l-1}S_{l-2}\cdots S_0$ 的数值为
$$z_{l-1}\cdot10^{9(l-1)}+\sum_{j<l-1}z_j\cdot10^{9j}=X,$$
因为每段定长 9 位，低段整体占据 $9(l-1)$ 位。该串首位非零，故它就是 $X$ 的标准十进制表示（十进制表示唯一）。证毕。

**反例说明为何必须补零**：若某低段为 $12$ 而不补零，拼接后相当于把该段的权重从 $10^{9j}$ 降为 $10^{9j-7}$，数值改变。例如 $X=10^9+12$ 的两段为 $(12,1)$，不补零会输出 `112` 而非 `1000000012`。

### 定理（算法正确性）

程序输出等于从 $m$ 到 $n$ 的路线数。

*证明*：由引理 2，答案 $=g(n-m)$；由引理 4、5，$g$ 由 $g(0)=g(1)=1$ 与 $g(i)=g(i-1)+g(i-2)$ 唯一确定。程序正是按此递推，每一步的加法由引理 7 保证数值正确、段值合法，遍历范围由引理 8 保证完整，故 $f[d]$ 表示 $g(d)$。由引理 6(a)，段数不超过 $45<64$，数组不越界。最后由引理 9，输出的字符串是 $g(d)$ 的十进制表示。$d=0,1$ 时循环不执行，直接输出初始化的 $1$，同样正确。证毕。

### 引理 10（复杂度）

时间 $O(d\cdot L)$，空间 $O(d\cdot L)$，其中 $L\le45$ 是最大段数。代入 $d\le999$ 得时间 $\le 999\times45\approx4.5\times10^4$ 次段运算，空间 $\le1005\times64$ 个 `int`（约 $257$ KB）。

*证明*：递推共 $d-1$ 轮，第 $i$ 轮遍历 $len[i-1]\le L$ 段，每段 $O(1)$（一次加、一次取模、一次除法）；输出 $O(L)$。故时间 $O(dL)$。数组 `f[mxn][mxl]` 与 `len[mxn]` 占用 $O(dL)$ 空间（按上界开）。证毕。

> 若只保留滚动的前两项，空间可降到 $O(L)$；本题 $d\le999$，整表存储更直观且便于调试，故保留整表。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 读蜂房图，把「相邻」精确翻译成移动集合 $\{+1,+2\}$，方向单调递增故无环。
- **reduce to easier problem** — 平移不变性：答案只依赖 $d=n-m$，两个变量压成一个。
- **consider easier version** — 手算 $d=1,2,3,4$ 得 $1,2,3,5$，先认出 Fibonacci 形状。
- **classic problem solution** — 按「最后一步是 $+1$ 还是 $+2$」分类，得到 $g(d)=g(d-1)+g(d-2)$，$g(0)=g(1)=1$。
- **explore its property** — 估规模：$F_{1000}$ 有 209 位，`long long`（$d\ge92$）与 `__int128`（$d\ge185$）先后爆掉，浮点精度不够。
- **classic problem solution** — 高精度加法；因为递推只含 $+$，不必写乘法；用 $10^9$ 压位把 209 位压成 24 段。
- **explore its property** — 严格位数上界 $F_k<2^k\Rightarrow F_{1000}<10^{400}\Rightarrow\le45$ 段，据此定 `mxl`。
- **discuss by category** — 边界 $d=0,1$ 由初值覆盖；输出时最高段不补零、其余段补足 9 位。

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| $m,n$ | 起点、终点蜂房编号 | `int`，读入 | $m<n$ |
| $d$ | 标号差 $n-m$ | `int` | 答案只依赖它 |
| `base` | 压位进制 $10^9$ | `constexpr int` | 一段 = 9 位十进制 |
| `mxn` | $d$ 的上界 $+5$，即 $1005$ | `constexpr int` | 距离维 |
| `mxl` | 段数上界 $64$（$\ge45$ 即安全） | `constexpr int` | 位数维 |
| `f[i][j]` | $g(i)$ 的第 $j$ 段（低位在前，$0\le f<B$） | `int[mxn][mxl]`，全局零初始化 | `f[0][0]=f[1][0]=1` |
| `len[i]` | $g(i)$ 的段数（最高非零段下标 $+1$） | `int[mxn]`，`len[0]=len[1]=1` | 单调不减（引理 8） |
| `carry` | 当前段加法进位，只能是 $0$ 或 $1$ | `int`，每轮置 $0$ | $s\le2B-1$ |
| `l` | 本轮结果段数 | `int`，初值 `len[i-1]` | 有进位则 `++l` |

### 算法步骤

1. I/O 加速：`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`。
2. 读入 $m,n$，令 $d=n-m$。
3. 初始化 $g(0)=g(1)=1$：`f[0][0]=f[1][0]=1`，`len[0]=len[1]=1`。
4. 对 $i=2\dots d$：令 `l=len[i-1]`、`carry=0`；对 $j=0\dots l-1$，`cur=f[i-1][j]+carry`，若 `j<len[i-2]` 再加 `f[i-2][j]`；`f[i][j]=cur%base`，`carry=cur/base`。循环结束后若 `carry` 非零则 `f[i][l++]=carry`；`len[i]=l`。
5. 输出 `f[d][len[d]-1]`（不补零），再对 $j=len[d]-2\dots0$ 输出 `setw(9)<<setfill('0')<<f[d][j]`，最后换行。

### 复杂度

- 时间：$O(d\cdot L)$，$L\le45$，最坏约 $4.5\times10^4$ 次段运算。
- 空间：$O(\text{mxn}\cdot\text{mxl})=1005\times64$ 个 `int`，约 $257$ KB。

### 验证状态

编译 `g++ -std=c++20 -O2` 通过；手造样例 $ (1,3)\to2$、$(1,4)\to3$、$(2,5)\to3$、$(1,10)\to55$、$(1,1)\to1$ 全部正确；另用**完全独立的十进制逐位字符串大数**实现做对拍，穷举 $d=0\dots999$（覆盖全部可能输入，因为答案只依赖 $d$）零不一致，并额外跑 300 组随机 $(m,n)$ 的真实可执行文件比对，零不一致；$F_{1000}$ 输出 209 位，与独立实现逐字符相同。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2437 蜜蜂路线
// 思路：蜂房 i 只能爬到 i+1 / i+2，答案只依赖 d=n-m，
//       g(d)=g(d-1)+g(d-2)，g(0)=g(1)=1，即 F_{d+1}。
//       F_1000 有 209 位，必须高精度；递推只含加法，用 1e9 压位。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},mxl{64};
constexpr int base{1'000'000'000};

int m,n,d,len[mxn];
int f[mxn][mxl];//f[i]=距离为 i 时的路线数，base 进制，低位在前

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n;
	d=n-m;
	f[0][0]=1;len[0]=1;//原地不动算一条路线
	f[1][0]=1;len[1]=1;
	for(int i=2;i<=d;++i)
	{
		int l=len[i-1],carry=0;
		for(int j=0;j<l;++j)
		{
			int cur=f[i-1][j]+carry;
			if(j<len[i-2])cur+=f[i-2][j];
			f[i][j]=cur%base;
			carry=cur/base;
		}
		if(carry)f[i][l++]=carry;//最高位进位
		len[i]=l;
	}
	cout<<f[d][len[d]-1];
	for(int j=len[d]-2;j>=0;--j)
		cout<<setw(9)<<setfill('0')<<f[d][j];
	cout<<'\n';
	return 0;
}
```

### 代码说明

- `mxl{64}` 不是随手写的：引理 6 给出 $\le45$ 段的严格上界，$64$ 段容量 $576$ 位十进制，留足松弛。
- `if(j<len[i-2])` 显式处理「较短加数的高位缺失」，不依赖全局数组的零初始化，逻辑与引理 7 的前提一一对应。
- `cur` 最大 $2\times(10^9-1)+1=1999999999<2^{31}-1$，`int` 安全；进位只能是 $0/1$。
- 输出最高段用普通 `cout`，其余段 `setw(9)<<setfill('0')`；`setfill` 是粘性的，但此处只在同一段循环里使用，无副作用。
- $d=0$ 或 $1$ 时递推循环不执行，直接输出初始化的 $1$，无需特判。
