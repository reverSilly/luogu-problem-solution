# P2786 英语1（eng1）- 英语作文 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 词汇表有 $N\le 10^5$ 个高级单词 $A_i$（只含数字与大小写字母，长度 $\le 50$），每个含金量 $B_i\le 10^5$。接下来到输入结束是一篇作文，共 $M\le 3\times 10^4$ 个单词，单词之间由 `,` `.` `!` `?` 以及空白（空格、换行）分隔。作文里每出现一次某个高级单词，总含金量就加 $B_i$，最后输出总含金量对 $P\le 10^9$ 的模。**大小写敏感**，且**一切以单词为最小单位**：`yyyy` 是一个单词，不能算作 `yyy` 出现两次。

**第一步：先否掉两个错误方向。**

方向一：对作文里每个单词，扫一遍词汇表找相等。复杂度 $O(M\cdot N\cdot L)=3\times10^4\times10^5\times50=1.5\times10^{11}$ 次字符比较，必死。这说明需要"字典"：把词汇表预处理成 单词 $\to$ 含金量 的映射，作文单词一次查表。

方向二：看到标签里有"树形数据结构、哈希"，联想到 Trie / AC 自动机做**子串匹配**。但题面样例 2 专门强调 `yyyy` 不算 `yyy` 出现两次——**子串匹配是错误模型**。本题要的是"整词相等"，不是"包含"。一旦想通这一点，问题反而变简单了：整词相等就是字典查找，连 Trie 都不用，`unordered_map<string,i64>` 足够（`map` 的 $O(\log N)$ 查找也完全能过，$3\times10^4\times17\times50\approx2.5\times10^7$ 次字符比较）。

**第二步：作文怎么切成单词？** 输入不是一行一个单词，而是带分隔符的原始文本，一直读到 EOF（输入格式里根本没有 $M$，$M$ 只出现在数据范围里）。关键观察：

> 词汇单词只含 $[0\text{-}9A\text{-}Za\text{-}z]$；而作文里除了单词字符，其余全是分隔符（`,` `.` `!` `?` 与空白）。

所以**任何非字母数字字符都是分隔符**，单词就是文本中的**极长字母数字连续段**。逐字符扫描：是字母数字就攒进当前 token，否则把非空 token 结算掉并清空。这个判据是题面分隔符集合的超集，但超集是安全的——多切的地方本来就不可能是单词内部。连续分隔符产生空 token，跳过即可。

两个必须记住的边界：**大小写敏感**，千万不要顺手 fold 成小写（那是另一道题 P2412 的规则）；**EOF 时最后一个 token 可能没有后继分隔符**，循环结束后要再结算一次。

**第三步：词汇表侧的两个细节。**

1. 同一个单词可能在词汇表里出现多行（题面没保证互异）。用 `mp[a]+=b` 累加：若数据保证互异，累加与赋值等价；若不互异，"每行都是一个已知高级词汇"的自然语义就是贡献叠加。
2. 溢出与取模。单条词值 $\le 10^5$，累加后一个单词的总词值 $\le N\cdot10^5=10^{10}$，超 `int`。答案侧每次累加前 `ans<P≤1e9`，故 `ans+词值<1.1e10`，`long long` 安全；**每加一次就模一次**，`ans` 永远落在 $[0,P)$。$P=1$ 时答案恒 $0$，代码自然覆盖。

**第四步：手造数据核对。** 题面只保留了样例说明、没有附样例输入输出（且说明里的算式 $1\times2+2\times4+3\times1+4\times1+100\times1$ 实际等于 $117$ 而非 $115$，与文字叙述对不上），所以不猜原样例，直接按规则自造：

| 输入（词汇表 + 作文） | 手算 | 程序输出 |
|---|---|---|
| `hansbug 1 / absi2011 2 / yyy 3 / kkksc03 4 / lzn 100`，$P=99$；作文 `hansbug,absi2011!yyy?kkksc03.lzn hansbug,absi2011` | $1\cdot2+2\cdot2+3+4+100=113$，$113\bmod99=14$ | `14` ✓ |
| 同上，但把 `yyy` 换成 `yyyy` | $113-3=110$，$110\bmod99=11$ | `11` ✓（整词匹配生效） |
| `Abc 5 / abc 7 / a1 9 / zz 20`，$P=100$；作文 `Abc,abc!a1?Abc. ABc zz` | $5+7+9+5+20=46$（`ABc` 不计） | `46` ✓（大小写敏感生效） |
| `x 100000 / y 100000`，$P=10^9$；作文 10 个 `x`、10 个 `y` | $2\times10^6$ | `2000000` ✓ |

四组分别覆盖：基本计数、整词边界、大小写、大数值与取模。

## 二、思维链：完整证明

**记号。** 字母表 $\Sigma=\{0..9,A..Z,a..z\}$（$62$ 个字符），分隔符集 $\Delta=\{',','.','!','?'\}\cup\{\text{空白}\}$。作文是 $\Sigma\cup\Delta$ 上的字符串 $T$（读到 EOF 为止）。词汇表为 $(A_i,B_i)_{i=1}^N$，$A_i\in\Sigma^+$。定义单词 $w$ 的**聚合词值**
$$V(w)=\sum_{i:\,A_i=w}B_i,$$
以及作文中 $w$ 的出现次数 $\mathrm{cnt}(w)$。题目要求的总含金量为 $\mathrm{Total}=\sum_{w}\mathrm{cnt}(w)\cdot V(w)$，输出 $\mathrm{Total}\bmod P$。

---

### 引理 1（单词 = 极长 $\Sigma$-段，切分唯一）

把 $T$ 在每次遇到 $\Delta$ 字符处切开，得到的非空片段恰为作文的全部单词（按出现顺序，含重复）；等价地，单词就是 $T$ 的极长 $\Sigma$-连续段。

*证明*：先证"单词内部不含 $\Delta$ 字符"：单词由 $\Sigma$ 字符构成（题面：词汇含数字、大小写字母；作文单词与词汇同一字符集，否则永远匹配不上，不影响答案），故单词内部每个字符都属于 $\Sigma$。再证"单词之间必有 $\Delta$ 字符"：题面说作文由 $M$ 个单词与若干分隔符组成，分隔符包含且仅包含 `,` `.` `!` `?`（空白是排版的天然分隔），两个相邻单词之间至少有一个分隔符或空白。于是每个单词都是 $\Sigma$-连续段；又因为它两侧（若存在）都是 $\Delta$ 字符或文本端点，它是**极长**的。

反过来，任一极长 $\Sigma$-段 $T[l..r]$：其内部无 $\Delta$ 字符，故不跨越任何切分点；其左端 $l$ 要么是文本开头、要么 $T[l-1]\in\Delta$，右端同理，故它恰好是一个完整片段，不会被切得更碎也不会与邻段合并。两个方向合起来给出"单词集合（含重数、按序）= 非空片段集合"的双射。

**推论（整词语义）**：`yyyy` 是一个极长段，作为整体查表；它不等于 `yyy`，也不包含两次 `yyy` 的**单词出现**。子串匹配会把 `yyyy` 里的 `yyy` 数出来，违反本引理刻画的双射，故错误。证毕。

### 引理 2（扫描器恰好实现引理 1 的切分）

代码的字符循环维护不变量：**`tok` 等于"自上一个 $\Delta$ 字符（或文本开头）以来、到当前字符之前为止的极长 $\Sigma$-后缀"**；每遇到 $\Delta$ 字符就结算非空 `tok` 并清空；EOF 后再结算一次。则被结算的 token 序列恰为作文单词序列。

*证明*：对已读字符数归纳。初始 `tok` 为空，对应"文本开头、尚未读入"，不变量成立。

- 读到 $c\in\Sigma$：`tok+=c`。由归纳假设 `tok` 是上一个 $\Delta$ 之后的全部 $\Sigma$ 字符，追加 $c$ 后仍是"到当前为止"的极长 $\Sigma$-后缀 ✓。
- 读到 $c\in\Delta$：此时 `tok` 恰是从上一个切分点到 $c$ 之前的完整片段。若非空，它就是一个极长 $\Sigma$-段（两侧都是 $\Delta$ 或端点），结算之；若为空，说明两个 $\Delta$ 相邻，中间没有单词，跳过。清空后不变量对"下一个位置"重新成立 ✓。
- EOF：最后一段 $\Sigma$-后缀没有后继 $\Delta$ 字符来触发结算，循环外的 `if(!tok.empty())add(tok);` 补上这最后一次。若文本以 $\Delta$ 结尾，`tok` 已空，不重复结算 ✓。

由引理 1，结算序列 = 单词序列。每个单词恰被结算一次（它只在右端点处触发一次 flush）。证毕。

### 引理 3（查表累加 = 总含金量）

设哈希表 `mp` 满足 $\texttt{mp}[w]=V(w)$（对词汇表中出现过的 $w$），其余单词查不到。则程序累加的量恰为 $\mathrm{Total}$。

*证明*：建表循环执行 `mp[A_i]+=B_i`。对每个不同的 $w$，所有满足 $A_i=w$ 的行各贡献一次 $B_i$，故表项终值 $=\sum_{i:A_i=w}B_i=V(w)$（全局 `unordered_map` 下标访问把不存在的键值初始化为 $0$，首行即 $0+B_i$）。若词汇互异，$V(w)=B_i$，与"赋值"写法等价；若不互异，累加正是"每行词汇各自贡献"的语义。

由引理 2，作文每个单词 $u$ 恰被查表一次：查到则加 $V(u)$，查不到加 $0$。故程序累加总量
$$\sum_{\text{作文单词 }u}V(u)=\sum_w\mathrm{cnt}(w)\cdot V(w)=\mathrm{Total},$$
中间等号是有限和的交换求和次序（把按"出现"求和改成按"单词种类"分组），严格成立。证毕。

### 引理 4（逐次取模的正确性与溢出界）

代码每次命中执行 `ans=(ans+mp值)%p`。则全程 `ans` 非负且 $<P$，终值 $=\mathrm{Total}\bmod P$；且每次加法在 `long long` 内不溢出。

*证明*：取模正确性：模运算对加法同态，$(x+y)\bmod P=\bigl((x\bmod P)+y\bigr)\bmod P$。对命中次数归纳：第 $0$ 次后 `ans`$=0=\text{空和}\bmod P$；设第 $k$ 次后 `ans`$\equiv$ 前 $k$ 项和 $\pmod P$，第 $k+1$ 次 `(ans+v)%p` $\equiv$ 前 $k$ 项和 $+v$ $\pmod P$ ✓。未命中的单词贡献 $0$，跳过不改变同余式。终值即 $\mathrm{Total}\bmod P$，且 `%` 对非负被除数给出 $[0,P)$ 的结果（$P\ge1$；$P=1$ 时恒 $0$）。

溢出界：归纳可得每次加法前 $0\le\texttt{ans}<P\le10^9$；词值 $V(w)\le\sum_iB_i\le N\cdot10^5=10^{10}$。故 `ans+V` $<1.1\times10^{10}<2^{63}-1\approx9.2\times10^{18}$，`i64` 安全。**注意词值本身可达 $10^{10}$，超 `int`，所以表值与 `ans` 都必须是 `i64`**——这是本题最实际的坑。证毕。

### 引理 5（大小写敏感 = 字节相等，不做任何规范化）

查表用 `string` 的精确相等（哈希 + `operator==`），不 fold 大小写。这与题面"此题目中大小写敏感"一致。

*证明*：题面明文"大小写敏感"，即 `Abc` 与 `abc` 是两个不同的单词。`std::string` 相等是逐字节相等，`'A'`(65) $\ne$ `'a'`(97)，故 `Abc` 只会命中键 `Abc`。若错误地 fold，`ABc` 会命中 `abc` 的词值，手造第三组数据（`ABc` 不应计入）立刻暴露。证毕。

### 引理 6（复杂度）

设词汇总字符数 $S_A=\sum L_i\le N\cdot50=5\times10^6$，作文总字符数 $S_T\le M\cdot(L_{\max}+1)+\text{分隔符}\approx1.5\times10^6$ 量级。时间期望 $O(S_A+S_T)$，空间 $O(S_A)$。

*证明*：建表：$N$ 次插入，每次哈希 + 拷贝 $O(L_i)$，合计 $O(S_A)$（`unordered_map` 期望 $O(1)$ 次桶探测，`reserve(2N)` 把装载因子压到 $0.5$ 以下，避免 rehash）。扫描：每个作文字符恰被 `cin.get` 读一次、做 $O(1)$ 分类；每个 token 恰被哈希查找一次，代价 $O(|tok|)$，所有 token 长度和 $\le S_T$。故总时间期望 $O(S_A+S_T)\approx6.5\times10^6$ 字符级操作，远低于时限。空间：表里存 $N$ 个键串与 `i64` 值，$O(S_A)$；`tok` 最长 $50$。若改用 `map`，时间 $O((S_A+S_T)\log N)$ 亦可通过，且是最坏情形保证；哈希版在本题数据下没有构造性卡哈希风险（键是自然英文单词）。证毕。

### 定理

程序输出 $\mathrm{Total}\bmod P$，其中 $\mathrm{Total}$ 是作文中所有高级单词**整词出现**的含金量之和（大小写敏感）。

*证明*：引理 1 刻画单词切分，引理 2 保证扫描器恰好产出这些单词，引理 3 保证查表累加等于 $\mathrm{Total}$，引理 5 保证相等语义正确，引理 4 保证逐次取模后终值正确且不溢出，引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — "一切以单词为最小单位" ⇒ 整词相等而非子串匹配，`yyyy`≠两次 `yyy`；AC 自动机方向直接排除。
- consider easier version — 若作文已是单词列表，问题退化为"字典查值求和"；剩下的全部工作只是把原始文本切成单词。
- reduce to easier problem — 词汇只含字母数字 ⇒ 任何非字母数字字符都是分隔符 ⇒ 单词 = 极长字母数字段，一遍字符扫描完成切分。
- classic problem solution — 哈希字典 `unordered_map<string,i64>`：词→聚合词值，期望 $O(1)$ 查找；重复词条 `+=` 累加。
- explore its property — 大小写敏感，不 fold；词值可达 $10^{10}$ 超 `int`，表值与答案都用 `i64` 且逐次取模。
- discuss by category — EOF 末尾单词补结算、连续分隔符空 token 跳过、$P=1$ 恒 $0$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 词汇条数 $N\le10^5$ | `int`，读入 | |
| `p` | 模数 $P\le10^9$ | `i64`，读入 | $P=1$ 时答案恒 $0$ |
| `mp` | 单词 $\to$ 聚合词值 $V(w)$ | `unordered_map<string,i64>`，空 | 重复词条 `+=`；`reserve(2n)` |
| `tok` | 当前正在攒的极长字母数字段 | `string`，空 | 遇分隔符结算并清空 |
| `ans` | 已结算含金量 $\bmod P$ | `i64`，$0$ | 恒在 $[0,P)$ |
| `isword(c)` | $c$ 是否属于 $[0\text{-}9A\text{-}Za\text{-}z]$ | `bool(char)` | 其余一律当分隔符 |
| `add(tok)` | 查表，命中则 `ans=(ans+V)%p` | `void` | EOF 后还要调一次 |

### 算法步骤

1. I/O 加速三行；读 `n,p`。
2. 读 $N$ 行 `(a,b)`，`mp[a]+=b`。
3. `cin.get(c)` 逐字符读到 EOF：`isword(c)` 则 `tok+=c`；否则若 `tok` 非空则 `add(tok)` 并清空。
4. EOF 后若 `tok` 非空再 `add(tok)`。
5. 输出 `ans`。

### 复杂度

- 时间：期望 $O(S_A+S_T)$，约 $6.5\times10^6$ 字符级操作（$S_A\le5\times10^6$，$S_T\approx1.5\times10^6$）。
- 空间：$O(S_A)$，哈希表存 $N$ 个词串。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；四组手造数据（基本计数 $113\bmod99=14$、`yyyy` 整词边界 $110\bmod99=11$、大小写敏感 $46$、大数值 $2\times10^6$）全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2786 英语1（eng1）- 英语作文
// 词汇表塞进哈希表（同词多行则含金量累加），作文逐字符扫描，
// 非字母数字字符一律当分隔符，切出的极大字母数字段就是"单词"，整词查表累加，最后模 P。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int n;
i64 p,ans;
unordered_map<string,i64>mp;

bool isword(char c)
{
	return (c>='0'&&c<='9')||(c>='a'&&c<='z')||(c>='A'&&c<='Z');
}
void add(const string&tok)
{
	auto it=mp.find(tok);
	if(it!=mp.end())
		ans=(ans+it->second)%p;	// ans<p<=1e9，词值<=1e10，i64 不溢出
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>p;
	mp.reserve(n*2);
	for(int i=0,b;i<n;++i)
	{
		string a;
		cin>>a>>b;
		mp[a]+=b;
	}
	string tok;
	for(char c;cin.get(c);)
	{
		if(isword(c))
			tok+=c;
		else if(!tok.empty())
		{
			add(tok);
			tok.clear();
		}
	}
	if(!tok.empty())
		add(tok);	// 作文末尾没有分隔符时最后一个单词在这里结算
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `mp[a]+=b` 而不是 `mp[a]=b`：词条可能重复，聚合词值才是"每行词汇各自贡献"的语义；互异时两者等价。
- 表值与 `ans` 都是 `i64`：词值上界 $10^{10}$ 超 `int`，这是本题最实际的溢出坑。
- `for(char c;cin.get(c);)` 读到 EOF：输入格式里作文没有单词数前缀，只能读到底；`cin.get` 不跳空白，换行也被当作分隔符，正好。
- 循环外那次 `add` 不可省：作文可能以单词结尾（无尾随分隔符/换行）。
- 大小写敏感：没有任何 fold 操作，`ABc` 不会命中 `abc`。
