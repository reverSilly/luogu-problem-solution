# P2296 [NOIP 2014 提高组] 寻找道路 — 题解

## 一、解题过程：人类思考叙事

题意重述：有向图 $G$ 有 $n$ 个点、$m$ 条边（$n\le10^4$，$m\le2\times10^5$），每条边长 $1$。给定起点 $s$、终点 $t$，要求找一条 $s\to t$ 的路径，满足：

1. 路径上**每个点**的所有出边所指的点，都能直接或间接到达 $t$；
2. 在满足条件 1 的前提下路径最短。

输出最短长度，不存在输出 $-1$。图可能有重边、自环，题目保证 $t$ 没有出边。

第一反应是直接从 $s$ 跑 BFS 求最短路，但马上发现不行：BFS 每步只关心"下一步走哪条边"，而条件 1 关心的是**当前点的所有出边**。一个点即使能通过某条出边走到 $t$，只要它还有另一条出边通向"死路"，这个点就根本不能出现在答案路径上。因此必须先把"哪些点有资格出现在路径上"预处理出来。

条件里反复出现"能到达 $t$"。在有向图里，"$u$ 能到达 $t$"等价于"在反图上从 $t$ 出发能到达 $u$"。于是第一步：**建反图，从 $t$ 做一次 BFS/DFS，标记所有能到达 $t$ 的点**，记为集合 $R$。

有了 $R$，一个点 $v$ 能出现在合法路径上，当且仅当它的**每一条**出边都指向 $R$ 中的点。这是一个只和 $v$ 的邻接表有关的局部判定，可以 $O(m)$ 扫一遍求出所有合法点，记为集合 $V$。

接下来只需要在**只含 $V$ 中点的诱导子图**上从 $s$ 做 BFS，求到 $t$ 的最短距离。因为路径上每个点都合法，条件 1 自然满足；反过来任何合法路径的点也都在 $V$ 中，一条都不会漏。

这里有一个非常经典的易错点：**"能到达 $t$"和"合法"不是一回事**。例如 $v$ 有两条出边，一条通向能到达 $t$ 的点，另一条通向死路。$v$ 本身能到达 $t$（走第一条边），但 $v$ 不合法（第二条边指向的点到不了 $t$）。如果只做了反图 BFS、忘了检查"所有出边"，就会把这种点放进 BFS，得到偏小的错误答案。

另一个边界：起点 $s$ 也必须是合法点，否则直接输出 $-1$；终点 $t$ 题目保证没有出边，所以它合法（条件对空出边集真）。如果 $t$ 有出边，同样要检查它是否合法。

手工例子：$6$ 个点，边 $1\to2$、$2\to5$、$1\to3$、$3\to4$、$4\to5$、$2\to6$，$s=1,t=5$。

- 反图从 $5$ 出发能到达 $4,3,2,1$，所以 $R=\{1,2,3,4,5\}$，$6\notin R$。
- 点 $2$ 的出边有 $5$ 和 $6$，其中 $6\notin R$，故 $2$ 不合法；点 $1$ 的出边指向 $2,3$，二者都在 $R$，故 $1$ 合法；$3,4,5$ 也都合法。
- 在合法点构成的子图上，$2$ 被删掉，只能走 $1\to3\to4\to5$，长度 $3$。虽然 $1\to2\to5$ 长度只有 $2$，但 $2$ 不合法，不能用。

程序输出 $3$，与推理一致。

## 二、思维链：完整证明

### 引理 1（反图 BFS 恰好标记能到达 $t$ 的点）

设 $R=\{v\in V: v\text{ 在 }G\text{ 中存在一条到 }t\text{ 的有向路径}\}$。在反图 $G^R$ 上从 $t$ 出发做 BFS，被访问到的点集恰好是 $R$。

**证明**：

记反图 $G^R=(V,E^R)$，其中 $(v,u)\in E^R\iff(u,v)\in E$。

**先证 BFS 访问到的点都属于 $R$。** 若 BFS 访问到 $u$，则 $G^R$ 中存在路径 $t=v_0\to v_1\to\cdots\to v_k=u$。把每条反边翻转，得到 $G$ 中的路径 $u=v_k\to v_{k-1}\to\cdots\to v_0=t$，故 $u$ 能到达 $t$，即 $u\in R$。

**再证 $R$ 中的点都会被访问。** 设 $u\in R$，取 $G$ 中一条路径 $u=w_0\to w_1\to\cdots\to w_k=t$。翻转后得到 $G^R$ 中的路径 $t=w_k\to w_{k-1}\to\cdots\to w_0=u$。BFS 从 $t$ 出发会遍历 $t$ 在 $G^R$ 中能到达的所有点，因此必定访问 $u$。

两个方向合起来，访问点集 $=R$。$\square$

特别地，$t\in R$，因为长度为 $0$ 的路径从 $t$ 到 $t$。

### 引理 2（条件 1 等价于路径上所有点合法）

定义合法点集
$$V_{\mathrm{good}}=\{\,v\in V:\ \forall (v,u)\in E,\ u\in R\,\}.$$
对任意一条 $s\to t$ 的路径 $P=(v_0=s,v_1,\dots,v_k=t)$，$P$ 满足条件 1 当且仅当 $v_0,v_1,\dots,v_k\in V_{\mathrm{good}}$。

**证明**：条件 1 的原话是"路径上的所有点的出边所指向的点都直接或间接与终点连通"，即
$$\forall r\in\{0,\dots,k\},\ \forall (v_r,u)\in E:\ u\in R.$$
把量词按点拆开，这恰好是"对每个 $r$，$v_r$ 的所有出边终点都在 $R$ 中"，也就是每个 $v_r\in V_{\mathrm{good}}$。两边是同一个命题的两种写法，故等价。$\square$

**注意**：这里 $R$ 与 $V_{\mathrm{good}}$ 不能混用。$v\in R$ 只说明**存在**一条出边通向能到达 $t$ 的点；$v\in V_{\mathrm{good}}$ 要求**所有**出边都通向能到达 $t$ 的点。后者更强。

### 引理 3（化归为诱导子图上的最短路）

设 $G[V_{\mathrm{good}}]$ 为只保留 $V_{\mathrm{good}}$ 中顶点及其间原有边得到的诱导子图。则 $G$ 中满足条件 1 的 $s\to t$ 路径集合，恰好等于 $G[V_{\mathrm{good}}]$ 中所有 $s\to t$ 路径的集合。

**证明**：

- 任取 $G$ 中满足条件 1 的路径 $P$。由引理 2，$P$ 的所有顶点都在 $V_{\mathrm{good}}$ 中，且 $P$ 的边都是 $G$ 的边，所以 $P$ 是 $G[V_{\mathrm{good}}]$ 中的路径。
- 任取 $G[V_{\mathrm{good}}]$ 中的 $s\to t$ 路径 $P$。它的所有顶点都在 $V_{\mathrm{good}}$ 中，由引理 2，$P$ 满足条件 1。

故两族路径相同，它们的最短长度也相同。若 $s\notin V_{\mathrm{good}}$ 或 $t\notin V_{\mathrm{good}}$，则不存在这样的路径（因为路径必须包含起点和终点）。$\square$

### 引理 4（单位权 BFS 求最短路）

在边权均为 $1$ 的有向图 $G[V_{\mathrm{good}}]$ 上，从 $s$ 出发的 BFS 第一次给顶点 $v$ 赋的距离 $dis[v]$，等于 $s$ 到 $v$ 的最短路径长度；未被赋值的点不可达。

**证明**：BFS 用队列逐层扩展，先发现的点距离不大于后发现的点。形式化地对距离 $d$ 归纳证明：所有到 $s$ 最短路长度为 $d$ 的点，都会在 BFS 的第 $d$ 层被首次发现，且 $dis=d$。

- $d=0$：只有 $s$，初始 $dis[s]=0$。
- 设对 $d-1$ 成立。任取最短路长度为 $d$ 的点 $v$，取一条最短路 $s=w_0\to\cdots\to w_{d-1}\to w_d=v$。由归纳，$dis[w_{d-1}]=d-1$。当 $w_{d-1}$ 出队时，若 $v$ 尚未被访问，则会被赋 $dis=d$；若 $v$ 已被访问，则它首次被访问时的距离不超过 $d$。另一方面，任何首次访问 $v$ 的路径都对应一条长度等于该距离的 $s\to v$ 路径，故距离不可能小于最短路的 $d$。因此 $dis[v]=d$。

同时，BFS 只沿真实边扩展，任何被赋值的距离都对应一条真实路径，所以不会把不可达点标成可达。$\square$

### 引理 5（无解判定）

若 $s\notin V_{\mathrm{good}}$ 或 $t\notin V_{\mathrm{good}}$，或 BFS 结束后 $dis[t]=-1$，则不存在满足条件的路径；否则 BFS 得到的 $dis[t]$ 就是答案。

**证明**：

- 若 $s$ 或 $t$ 不合法，由引理 3，合法路径集合为空，输出 $-1$ 正确。
- 若二者都合法，但 $G[V_{\mathrm{good}}]$ 中 $s$ 到 $t$ 不可达，由引理 3，$G$ 中也不存在合法路径，输出 $-1$ 正确。
- 若可达，由引理 3 与引理 4，$dis[t]$ 是最短合法路径长度，输出正确。$\square$

题目保证 $t$ 没有出边，所以 $t$ 的出边集合为空，"所有出边终点都在 $R$"对空集真，故 $t\in V_{\mathrm{good}}$。代码仍然显式检查 $t$，这样即使条件变化也正确。

### 定理（整体正确性）

反图 BFS 由引理 1 正确求出 $R$；扫描出边由引理 2 正确求出 $V_{\mathrm{good}}$；引理 3 把原问题等价化为诱导子图最短路；引理 4 保证 BFS 求出最短距离；引理 5 保证无解时输出 $-1$。故算法输出正确。$\square$

### 复杂度

反图 BFS 每个点至多入队一次、每条反边至多被检查一次：$O(n+m)$。合法性扫描检查每条原边一次：$O(n+m)$。正向 BFS 同样 $O(n+m)$。总时间 $O(n+m)$。存储两张邻接表共 $2m$ 条边、若干长度 $n$ 的数组，空间 $O(n+m)$。$\square$

## 三、模式总结（按实际思考顺序）

- explore its property — 条件 1 是"每个路径点的全部出边"都要能到 $t$，不是"选的下一步"能到 $t$。
- reduce to easier problem — "能到达 $t$"通过反图从 $t$ 遍历求出。
- explore its property — 区分"自身能到 $t$"（$R$）与"所有出边都能到 $t$"（$V_{\mathrm{good}}$）。
- reduce to easier problem — 合法路径集合等于诱导子图 $G[V_{\mathrm{good}}]$ 中的路径集合。
- classic problem solution — 单位权有向图最短路用 BFS。
- discuss by category — 起点不合法 / 终点不合法 / 诱导子图中不可达，均输出 $-1$。
- handle implementation details — 正反两张邻接表、重边自环无影响、距离数组初始化为 $-1$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 说明 |
|------|------|-------------|
| $n,m$ | 点数、边数 | 输入 |
| `graph[u]` | 原图 $u$ 的所有出边终点 | 读边时 `push_back` |
| `rg[u]` | 反图 $u$ 的所有出边终点（即原图中指向 $u$ 的点） | 读边时同步建 |
| `can[u]` | $u$ 是否能到达 $t$（$u\in R$） | 全局 `bool`，初值 `false`；`can[t]=true` |
| `ok[u]` | $u$ 是否合法（所有出边终点都 `can`） | 全局 `bool`，扫描出边计算 |
| `dis[u]` | 诱导子图中 $s$ 到 $u$ 的最短距离 | `fill_n(dis,n,-1)`，`dis[s]=0` |
| `Q` | BFS 队列 | 数组模拟，正反两次复用 |
| $s,t$ | 起点、终点 | 输入后转 0-based |

### 算法步骤

1. 读入 $n,m$，建原图 `graph` 与反图 `rg`（每条边 $u\to v$ 同时加入 `graph[u]` 和 `rg[v]`）。
2. 读入 $s,t$ 并减一。
3. 反图 BFS：`can[t]=true`，$t$ 入队；每次取出 $u$，把 `rg[u]` 中未标记的点标记并入队。结束后 `can` 即集合 $R$。
4. 对每个 $u$，令 `ok[u]=true`，遍历 `graph[u]`：只要有一个终点 `can` 为假，就令 `ok[u]=false` 并停止。
5. 若 `!ok[s]||!ok[t]`，输出 $-1$ 并结束。
6. 正向 BFS：`dis[s]=0`，$s$ 入队；取出 $u$ 后若 $u=t$ 立即停止；否则把 `ok` 为真且未访问的出边终点入队，距离加一。
7. 输出 `dis[t]`（不可达时仍为 $-1$）。

### 复杂度

- 时间：$O(n+m)$。
- 空间：$O(n+m)$。

### 验证状态

已用 `g++ -std=c++20 -O2` 编译通过；与"枚举所有简单路径并逐点检查条件"的暴力在 $300$ 组随机小图（含自环、重边、终点出边）上完全一致，并手工验证了 $5$ 组用例，包括"能到 $t$ 但不合法"的关键反例。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int n,m;
vector<int>graph[mxn],rg[mxn];
bool can[mxn],ok[mxn];
int dis[mxn],Q[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,u,v;i<m;++i)
	{
		cin>>u>>v;--u;--v;
		graph[u].push_back(v);
		rg[v].push_back(u);
	}
	int s,t;
	cin>>s>>t;--s;--t;

	int hd=0,tl=0;
	can[t]=true;
	Q[tl++]=t;
	while(hd<tl)
	{
		int u=Q[hd++];
		for(int v:rg[u])
			if(!can[v])
			{
				can[v]=true;
				Q[tl++]=v;
			}
	}
	for(int u=0;u<n;++u)
	{
		ok[u]=true;
		for(int v:graph[u])
			if(!can[v])
			{
				ok[u]=false;
				break;
			}
	}
	if(!ok[s]||!ok[t])
	{
		cout<<-1<<'\n';
		return 0;
	}
	fill_n(dis,n,-1);
	hd=tl=0;
	dis[s]=0;
	Q[tl++]=s;
	while(hd<tl)
	{
		int u=Q[hd++];
		if(u==t)
			break;
		for(int v:graph[u])
			if(ok[v]&&dis[v]==-1)
			{
				dis[v]=dis[u]+1;
				Q[tl++]=v;
			}
	}
	cout<<dis[t]<<'\n';
	return 0;
}
```
