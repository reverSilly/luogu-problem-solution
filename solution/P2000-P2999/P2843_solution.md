# P2843 暗杀 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 个人排成一列（$N\le10^5$），每人有一个 $K$ 位二进制特性值 $a_i$（$K\le30$，十进制输入），第 $b$ 位为 $1$ 表示有第 $b$ 种特性。要找一段**连续**的 $M$ 个人，使得这 $M$ 个人里 **$K$ 种特性各自出现的总次数全部相等**（都等于某个 $t$，$t$ 是多少无所谓），最大化 $M$。只能攻击一次，输出最大的 $M$；若不存在这样的非空段，输出 $0$。

子任务：$30\%$ 有 $N\le100$，$50\%$ 有 $N\le1000$——这暗示 $O(N^2)$ 甚至 $O(N^2K)$ 能拿一半分，满分需要近线性。

**第一步：把"次数相等"翻译成数学。** 设段为第 $l+1$ 到第 $r$ 个人。特性 $b$ 在段内的出现次数就是 $\sum_{i=l+1}^{r}\mathrm{bit}_b(a_i)$。条件"所有 $K$ 个次数相等"是 $K-1$ 个等式：$\mathrm{cnt}_1=\mathrm{cnt}_2=\dots=\mathrm{cnt}_K$。

先排除一个诱人的假捷径：**"总次数能被 $K$ 整除"行不行？** 不行。反例：$K=3$，段内特性值为 $1,1,1,2,4,4$（二进制 $001,001,001,010,100,100$），三个计数是 $(3,1,2)$，总和 $6$ 能被 $3$ 整除，但三个数互不相等。整除只是必要条件，不是充分条件——必须逐维比较。

**第二步：从最简单的 $K$入手找结构。**

- $K=1$：只有一种特性，"所有次数相等"对**任何段**都成立（只有一个数，没有比较对象），答案直接是 $N$。
- $K=2$：条件变成 $\mathrm{cnt}_1=\mathrm{cnt}_2$。给每个人一个权值 $b_i=\mathrm{bit}_1(a_i)-\mathrm{bit}_2(a_i)\in\{-1,0,1\}$，则段合法 $\iff\sum b_i=0$。这是经典题"**最长零和子段**"：做前缀和 $s_i$，段 $(l,r]$ 零和 $\iff s_l=s_r$，答案就是"相同前缀和的最远两次出现"的下标差，用一张"值 $\to$ 最早下标"的表 $O(N)$ 扫完。

$K=2$ 的解法给了关键洞察：**把"段内条件"改写成"两个端点的前缀状态相等"**。

**第三步：推广到一般 $K$。** 设 $c_b(i)$ 为前 $i$ 个人中特性 $b$ 的出现次数（前缀计数）。段 $(l,r]$ 内特性 $b$ 的次数是 $c_b(r)-c_b(l)$。条件"全相等"即

$$c_1(r)-c_1(l)=c_2(r)-c_2(l)=\dots=c_K(r)-c_K(l).$$

把参考维定为第 $K$ 维，移项得：对每个 $b<K$，$c_b(r)-c_K(r)=c_b(l)-c_K(l)$。也就是说，定义 $K-1$ 维**差向量**

$$v(i)=\bigl(c_1(i)-c_K(i),\;c_2(i)-c_K(i),\;\dots,\;c_{K-1}(i)-c_K(i)\bigr),$$

则**段 $(l,r]$ 合法 $\iff v(l)=v(r)$**（引理 2 给出双向严格证明）。为什么减 $c_K$ 而不是别的？因为"全相等"等价于"每一维与某一固定参考维的差都相等"，减掉参考维恰好把"$K$ 个数相等"压缩成"$K-1$ 个差分为 $0$"，而且这个压缩是**可逆的**（不丢信息）：差向量相等能反推出所有计数相等。$K=2$ 时 $v(i)$ 退化成标量 $c_1(i)-c_2(i)$，正是第二步的前缀和——两条思路在这里汇合。

**第四步：问题变成"相同向量的最远出现"。** 现在要对 $N+1$ 个前缀位置 $i=0..N$（$v(0)$ 是全零向量）求 $\max\{r-l: v(l)=v(r),\,l<r\}$。这和"最长零和子段"一模一样，只是键从整数变成了 $K-1$ 维向量。撞墙点：$N=10^5$ 时不能 $O(N^2)$ 两两比较（$10^{10}$ 次，每次还要比 $29$ 维）。需要把"按向量分组"做快。

两条路：

1. **哈希表**：把向量哈希成一个数，`unordered_map` 存"向量 $\to$ 最早下标"。期望 $O(NK)$，但要自己写哈希函数；若只存哈希值不存原向量，还有碰撞误判的理论风险（本题计数差范围 $\pm10^5$、$29$ 维，无法无损压进 $64$ 位）。
2. **排序分组**：把 $N+1$ 个向量按字典序排序，相等的向量必然排成连续段；每段内取原始下标的最大值减最小值，就是该等价类贡献的答案。排序 $O(N\log N\cdot K)$，比较的是**完整向量**，**零碰撞、完全精确**，而且全程只用全局静态数组，不需要任何哈希技巧。

$N\log N\cdot K\approx10^5\times17\times29\approx5\times10^7$ 次整数比较，完全可行。我选排序：正确性证明最干净（不依赖哈希函数的任何概率性质），代码也短。

**第五步：实现细节抠一遍。**

1. **差向量可以原地做**：先照常递推 $K$ 维前缀计数 $c_b(i)$，再对每个 $i$ 把前 $K-1$ 维各减去第 $K$ 维。注意第 $K$ 维自身不修改，所以减法顺序无关。
2. **$K=1$ 的退化**：差向量是 $0$ 维，所有 $v(i)$ 相等，排序后一整组，答案 $N$——代码不需要特判，空区间的 `lexicographical_compare` 恒返回 `false`（全等价），`equal` 恒 `true`，逻辑自动覆盖。
3. **$v(0)$ 必须有**：空前缀是合法左端点（段从第 $1$ 个人开始），全局数组默认 $0$ 恰好就是全零向量，但这是"恰好正确"，我在证明里显式确认它。
4. **值域**：$a_i<2^{30}$ 用 `int` 装得下；计数 $\le10^5$，差分 $\in[-10^5,10^5]$，`int` 安全。
5. **答案是 $0$ 的情形**：没有任何两个前缀向量相等时，每组只有一个下标，$\max-\min=0$，输出 $0$，与"不存在合法非空段"一致。

**手造数据核对**（题面无样例）：

| 输入 | 手算 | 说明 |
|---|---|---|
| `6 3` / `1 2 4 1 2 4` | $6$ | 全段计数 $(2,2,2)$ |
| `5 2` / `1 1 2 1 2` | $4$ | 全段 $(3,2)$ 不行；第 $2\sim5$ 人 $(2,2)$ 行 |
| `3 1` / `5 3 7` | $3$ | $K=1$ 退化，任意段都行 |
| `4 3` / `1 1 2 4` | $3$ | 全段 $(2,1,1)$ 不行；第 $2\sim4$ 人 $(1,2,4)$ 计数 $(1,1,1)$ 行 |
| `4 3` / `1 1 1 1` | $0$ | 特性 2、3 计数恒 $0$ 而特性 1 恒正，任何非空段都不平衡 |

第二组手推差向量（$c_1-c_2$）：$0,1,2,1,2,1$，值 $1$ 最早出现在 $i=1$、最晚 $i=5$，差 $4$，与答案吻合。

## 二、思维链：完整证明

**记号。** 人下标 $1..N$，前缀位置 $i\in\{0,\dots,N\}$。$\mathrm{bit}_b(a)\in\{0,1\}$ 为 $a$ 的第 $b$ 位（$b=1..K$）。$c_b(i)=\sum_{t=1}^{i}\mathrm{bit}_b(a_t)$，$c_b(0)=0$。差向量 $v(i)\in\mathbb Z^{K-1}$，第 $b$ 个分量为 $c_b(i)-c_K(i)$。段 $(l,r]$ 指第 $l+1..r$ 个人，长度 $r-l$。"平衡段"指 $K$ 种特性出现次数全相等的段。

### 引理 1（前缀计数表示段计数）

段 $(l,r]$ 内特性 $b$ 的出现次数 $\mathrm{cnt}_b(l,r)=c_b(r)-c_b(l)$。

*证明*：$\mathrm{cnt}_b(l,r)=\sum_{t=l+1}^{r}\mathrm{bit}_b(a_t)$。而 $c_b(r)=\sum_{t=1}^{r}\mathrm{bit}_b(a_t)=\sum_{t=1}^{l}\mathrm{bit}_b(a_t)+\sum_{t=l+1}^{r}\mathrm{bit}_b(a_t)=c_b(l)+\mathrm{cnt}_b(l,r)$（求和区间可加性，$0\le l<r\le N$）。移项即得。$l=r$ 时两边均为 $0$，公式仍成立。证毕。

### 引理 2（平衡段 $\iff$ 端点差向量相等）

对 $0\le l<r\le N$：段 $(l,r]$ 是平衡段 $\iff v(l)=v(r)$。

*证明*：由引理 1，平衡即存在整数 $t\ge0$ 使对所有 $b\in\{1..K\}$ 有 $c_b(r)-c_b(l)=t$。

**($\Rightarrow$)**：设平衡。对任意 $b<K$，$c_b(r)-c_b(l)=t=c_K(r)-c_K(l)$。移项：$c_b(r)-c_K(r)=c_b(l)-c_K(l)$，即 $v(r)$ 与 $v(l)$ 的第 $b$ 个分量相等。$b$ 遍历 $1..K-1$，故 $v(l)=v(r)$。

**($\Leftarrow$)**：设 $v(l)=v(r)$，即对每个 $b<K$ 有 $c_b(r)-c_K(r)=c_b(l)-c_K(l)$，移项得 $c_b(r)-c_b(l)=c_K(r)-c_K(l)$。令 $t=c_K(r)-c_K(l)$，则所有 $K$ 个段计数都等于 $t$（第 $K$ 维平凡）。又段计数是非负整数之和，$t\ge0$ 自动成立。故段平衡。

两个方向都只用了移项，等价严格成立。特别地，"减去参考维 $c_K$"不丢信息：$K$ 个计数相等这一性质完全由 $K-1$ 个差分刻画。证毕。

### 引理 3（答案 = 等价类内最远下标差）

设 $\mathrm{ans}$ 为最长平衡段长度（不存在则为 $0$）。把前缀位置按 $v$ 值相等划分成等价类，则
$$\mathrm{ans}=\max_{\text{等价类 }C}\bigl(\max C-\min C\bigr).$$

*证明*：由引理 2，平衡段与"同类且 $l<r$ 的前缀位置对 $(l,r)$"一一对应，长度为 $r-l$。

对任一等价类 $C$（$|C|\ge1$），其中任意两元素 $l<r$ 都构成平衡段，长度 $r-l\le\max C-\min C$；而 $(\min C,\max C)$ 本身（若 $|C|\ge2$）就是合法对，取到上界。故类 $C$ 贡献的最大长度恰为 $\max C-\min C$（$|C|=1$ 时为 $0$，对应"无段"）。所有平衡段都属于某个等价类，故全局最大值就是各类贡献的最大值。若所有类都是单点，$\mathrm{ans}=0$，与"不存在非空平衡段"一致。证毕。

### 引理 4（排序分组正确枚举等价类）

把下标数组 $\texttt{id}[0..N]$（初始 $\texttt{id}[i]=i$）按"对应差向量的字典序"排序后，$v$ 值相等的下标必然占据一段连续区间；顺序扫描极大相等段即可枚举全部等价类。

*证明*：字典序 $\le_{\mathrm{lex}}$ 是 $\mathbb Z^{K-1}$ 上的全预序：自反、传递、完全（任意两向量可比），且 $x\le_{\mathrm{lex}}y\le_{\mathrm{lex}}x\iff x=y$（逐分量反对称）。排序后序列满足 $v(\texttt{id}[0])\le_{\mathrm{lex}}v(\texttt{id}[1])\le_{\mathrm{lex}}\dots$

设某等价类含下标 $p,q$（$v(p)=v(q)$），且排序后位置 $i_p<i_q$。对任何夹在中间的位置 $t$（$i_p<i_t<i_q$），有 $v(p)\le_{\mathrm{lex}}v(\texttt{id}[t])\le_{\mathrm{lex}}v(q)=v(p)$，由反对称得 $v(\texttt{id}[t])=v(p)$，即 $t$ 也属于该类。故等价类在排序后是连续区间，不同类之间以严格 $<$ 分隔。

代码的分组扫描 `for(i=0,j;i<=n;i=j)` 内层用 `equal` 逐分量比较（$K-1$ 个 `int` 全等），恰好把每个极大连续相等段切成一组；组内维护原始下标的 $\min,\max$，由引理 3 取差更新答案。$K=1$ 时向量为 $0$ 维：`lexicographical_compare` 对空区间恒 `false`（严格弱序成立，全部等价），`equal` 对空区间恒 `true`，整个序列是一组，$\max-\min=N-0=N$，与"$K=1$ 任意段平衡"一致。证毕。

### 引理 5（差向量的递推与值域）

代码先算 $c_b(i)=c_b(i-1)+\mathrm{bit}_b(a_i)$（$b=1..K$），再令 $v_b(i)=c_b(i)-c_K(i)$（$b<K$，原地减、不改第 $K$ 维）。则结果正确，且所有中间量在 `int` 范围内。

*证明*：递推正确性对 $i$ 归纳：$i=0$ 时全局数组默认 $0$，恰为 $c_b(0)=0$（$v(0)$ 是全零向量，引理 3 需要它）；$i\ge1$ 时 $c_b(i)=c_b(i-1)+\mathrm{bit}_b(a_i)$ 就是前缀和定义。原地减法阶段：第 $K$ 维从未被写入，故对 $b<K$ 执行 `d[i][b]-=d[i][K-1]` 时读到的是原始 $c_K(i)$，各维减法互不干扰，结果即 $v(i)$。

值域：$K\le30\Rightarrow a_i\le2^{30}-1=1073741823<2^{31}-1$，`int` 可存；$\mathrm{bit}$ 提取 `(a>>b)&1` 对非负 `int` 良定义。$0\le c_b(i)\le N\le10^5$，故 $v_b(i)\in[-10^5,10^5]$，比较与存储均无溢出。证毕。

### 引理 6（复杂度）

时间 $O(NK+N\log N\cdot K)$，空间 $O(NK)$。

*证明*：读入 $O(N)$；前缀计数递推 $NK\le3\times10^6$；原地差分 $N(K-1)$；排序 $N+1$ 个元素，每次比较是 $O(K)$ 的字典序比较（多数比较在前几个分量就分出大小，最坏 $K$），共 $O(N\log N\cdot K)\approx10^5\times17\times29\approx5\times10^7$ 次整数比较；分组扫描中每个位置恰被 `equal` 检查一次（作为组的成员或组边界），$O(NK)$。合计 $O(NK\log N)$。

空间：`d` 为 $(10^5+5)\times35$ 个 `int` $\approx14$ MB，`id`、`a` 各 $0.4$ MB，在常见 $128/256$ MB 限制内。证毕。

### 定理

程序输出最长平衡段长度（不存在则 $0$），复杂度 $O(NK\log N)$。

*证明*：引理 5 保证 `d[i]` 存的是正确的 $v(i)$（含 $v(0)=0$）；引理 1、2 把"段平衡"严格等价成"端点向量相等"；引理 3 把答案化成等价类的最远下标差；引理 4 保证排序 + 扫描精确枚举等价类并算出每类的 $\max-\min$；引理 6 给出复杂度。全程精确整数比较，无哈希碰撞、无浮点误差。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "K 种次数全相等"是 $K-1$ 个等式；"总和被 $K$ 整除"只是必要条件，反例 $(3,1,2)$ 否定捷径。
2. **consider easier version** — $K=1$ 答案恒 $N$；$K=2$ 化为 $\pm1$ 权值的最长零和子段。
3. **classic problem solution** — 最长零和子段的标准解：前缀和 + "相同值最远出现"，把段条件改写成端点状态相等。
4. **reduce to easier problem** — 一般 $K$：段平衡 $\iff$ 差向量 $v(i)=(c_1-c_K,\dots,c_{K-1}-c_K)$ 在两端点相等，$K=2$ 的标量前缀和是它的特例。
5. **classic problem solution** — "相同键最远出现"的键是向量：排序 + 极大相等段分组，组内 $\max-\min$；精确无碰撞，替代哈希表。
6. **discuss by category** — $K=1$ 时 $0$ 维向量自动全等价；$v(0)$ 全零必须参与；无解时输出 $0$；值域 $\pm10^5$ 用 `int` 足够。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 人数 $N\le10^5$ | `int` | 读入 |
| `k` | 特性数 $K\le30$ | `int` | 读入 |
| `mxn` | $100000+5$ | `constexpr int` | 前缀位置 $0..N$ 共 $N+1$ 个 |
| `mxk` | $30+5$ | `constexpr int` | 向量维数上界 |
| `a[i]` | 第 $i+1$ 个人的特性值（0-based 存） | `int[mxn]` | 读入，$<2^{30}$ |
| `d[i][b]` | 先存 $c_{b+1}(i)$，差分后存 $v(i)$ 第 $b$ 分量（$b<K-1$）；第 $K-1$ 列始终是 $c_K(i)$ | `int[mxn][mxk]` | 全局默认 $0$ 恰为 $v(0)$；递推 + 原地减 |
| `id[i]` | 排序用的前缀位置下标 | `int[mxn]` | `id[i]=i`，按 `d` 行字典序排序 |
| `ans` | 最长平衡段长度 | `int` | $0$；每组 $\max-\min$ 更新 |
| `mn,mx` | 当前等价类内原始下标的最小 / 最大值 | `int` | 每组重置为组首下标 |

### 算法步骤

1. I/O 加速三行；读 `n,k` 与 `a[0..n-1]`。
2. 递推前缀计数：`d[i][b]=d[i-1][b]+((a[i-1]>>b)&1)`，$i=1..N$，$b=0..K-1$。
3. 原地差分：对 $b=0..K-2$、$i=0..N$，`d[i][b]-=d[i][k-1]`（第 $K-1$ 列不动）。
4. `id[i]=i`；按 `d` 行的字典序 `sort(id,id+n+1,...)`（`lexicographical_compare`，长度 $K-1$）。
5. 顺序扫描极大相等段（`equal` 判组边界），组内求原始下标 `mn,mx`，`ans=max(ans,mx-mn)`。
6. 输出 `ans`。

### 复杂度

- 时间 $O(NK\log N)\approx5\times10^7$ 次整数比较；空间 $O(NK)\approx14$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；五组手造数据（全段平衡 $\to6$、$K=2$ 差向量手推 $\to4$、$K=1$ 退化 $\to3$、子段平衡 $\to3$、无解 $\to0$）全部与手算一致；$300$ 组随机小数据（$N\le14,K\le5$）与独立 $O(N^2K)$ 枚举暴力逐组一致；$N=99990,K=30$ 的已知答案极限数据输出正确，运行 $0.16$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2843 暗杀
// 段内 K 种特性次数全相等 ⇔ 两端点的差向量 v(i)=(c_1-c_K,...,c_{K-1}-c_K) 相等
// 把 N+1 个向量排序分组，组内最远下标差即答案；精确比较，零哈希碰撞
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005},mxk{35};

int n,k,a[mxn],d[mxn][mxk],id[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int i=0;i<n;++i)
		cin>>a[i];
	// d[0] 全 0：空前缀是合法左端点，全局默认恰好正确
	for(int i=1;i<=n;++i)
		for(int b=0;b<k;++b)
			d[i][b]=d[i-1][b]+((a[i-1]>>b)&1);
	for(int b=0;b<k-1;++b)
		for(int i=0;i<=n;++i)
			d[i][b]-=d[i][k-1];	// 第 k-1 列保持 c_K，减法互不干扰
	for(int i=0;i<=n;++i)
		id[i]=i;
	sort(id,id+n+1,[](int x,int y){
		return lexicographical_compare(d[x],d[x]+k-1,d[y],d[y]+k-1);
	});
	int ans=0;
	for(int i=0,j;i<=n;i=j)	// 极大相等段分组；k=1 时 0 维向量全等价，自动得 n
	{
		int mn=id[i],mx=id[i];
		for(j=i+1;j<=n&&equal(d[id[i]],d[id[i]]+k-1,d[id[j]]);++j)
		{
			mn=min(mn,id[j]);
			mx=max(mx,id[j]);
		}
		ans=max(ans,mx-mn);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `d` 一物两用：先当 $K$ 维前缀计数，再原地减成 $K-1$ 维差向量（第 $K-1$ 列保留 $c_K$ 不参与比较）。比较与分组都只看前 `k-1` 列，`lexicographical_compare`/`equal` 的区间长度都是 `k-1`。
- 排序的是**下标** `id` 而不是 `d` 的行本身：组内要还原"原始前缀位置"求 $\max-\min$，搬动 $29$ 维的行既慢又会丢失下标信息。
- 分组循环 `for(int i=0,j;i<=n;i=j)`：内层 `j` 走到第一个不等位置，外层直接跳到 `j`，每个位置恰被访问一次；`i=n` 时内层立即终止（`j=n+1`），无越界。
- $K=1$ 不需要特判：空区间的字典序比较恒 `false`、`equal` 恒 `true`，全部下标一组，答案 $N$（引理 4）。
- 全程 `int`：$a_i<2^{30}$、差分 $\in[-10^5,10^5]$，无溢出（引理 5）；无哈希、无浮点，正确性是确定性的。
