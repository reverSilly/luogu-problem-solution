# P2712 摄像头 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 个摄像头（$n\le100$），第 $i$ 个位于位置 $x_i$，能监视 $m_i$ 个位置（$0\le m_i\le100$，位置编号 $0..500$）。一个摄像头能被砸毁，当且仅当它所在的位置**不被其他（还活着的）摄像头监视**；砸毁后它的监视能力消失。问能否砸掉全部：能输出 `YES`，不能输出剩余个数。

**第一步：把"砸"的顺序依赖画出来。** 摄像头 $j$ 现在能不能砸，取决于"有没有别的活摄像头监视着 $x_j$"。反过来写：**若摄像头 $i$ 监视位置 $x_j$，则 $j$ 必须等 $i$ 先被砸掉**。这是一条依赖边 $i\to j$。于是：

- 可砸 = 入度为 $0$（没有活的前驱监视它）；
- 砸掉 $u$ = 删除 $u$ 的所有出边，被它监视的摄像头入度减 $1$，减到 $0$ 就变成新的可砸点。

**这就是拓扑排序（Kahn 剥皮）**，标签也明示了。模型本身不难，真正的坑全在建模细节里，我逐个抠：

**坑 1：自己监视自己算不算？** 题面写的是"不被**其他**摄像头监视"。所以即使摄像头 $i$ 的监视列表里含 $x_i$，也不构成对自己的依赖——**建边时必须排除 $i=j$**。不排除的话，一个自监视的无辜摄像头会被判成"砸不掉"。

**坑 2：同一位置重复列了多次怎么算？** 入度的语义是"**有几个不同的摄像头**监视我"，不是"被监视了几次"。若 $i$ 的列表里 $x_j$ 出现两次，依赖边 $i\to j$ 仍然只有一条。用 `bool mon[i][y]` 记录监视关系天然去重；如果直接对每个读入的 $y$ 累加入度，就会把入度虚增，导致本可砸的摄像头永远等不到入度归零。

**坑 3：两个摄像头在同一位置？** 题面没说位置互异。若 $i,j$ 都在位置 $p$，且 $i$ 监视 $p$，则边 $i\to j$ 存在（$i$ 监视了 $j$ 的位置）；若两者都监视 $p$，则互相依赖，谁也砸不了——模型自动处理，不需要特判。

**坑 4：监视列表里没有摄像头的位置？** 那些位置与本题无关，建边时只关心 $y$ 是否等于某个 $x_j$，其余忽略。

**第二步：剥完之后剩的是什么？** Kahn 算法结束后，剩下的每个摄像头入度都 $\ge1$，且这些入度全部来自剩下的摄像头——**剩余子图里每个点都有前驱**，沿前驱走必然走进环。所以砸不掉的本质是"依赖环（及被环挡住的部分）"。还要确认一件事：**剩下的个数与剥的顺序无关**（否则答案就不唯一了）。直觉上，任何合法砸法能砸掉的，剥皮也都能砸掉——下面用"第一个反例"论证严格证明。

**第三步：手造小数据核对模型。**

1. $n=1$，位置 $0$，不监视任何位置 → 入度 $0$，砸掉，`YES`。
2. $n=1$，位置 $5$，监视 $\{5\}$（自监视）→ 排除自环后入度 $0$，`YES`（坑 1）。
3. $n=2$：$1$ 号在位置 $1$ 监视 $\{2\}$，$2$ 号在位置 $2$ 监视 $\{\}$ → 边 $1\to2$；先砸 $1$ 再砸 $2$，`YES`。
4. $n=2$：互相监视对方位置 → 环，输出 $2$。
5. $n=2$：$1$ 号在位置 $1$ 监视 $\{2,2\}$（重复），$2$ 号不监视 → 去重后入度 $1$，`YES`（坑 2；不去重会错输出 $1$）。
6. $n=3$：$0,1$ 号互监视，$2$ 号独立 → 砸掉 $2$ 号，剩 $2$ 个，输出 $2$。

**第四步：实现选型。** $n\le100$、位置 $\le500$，直接 `bool mon[105][505]` 存监视关系，$O(n^2)$ 枚举建边 + 邻接矩阵，Kahn 用队列。总复杂度 $O(n^2+\sum m_i)$，规模极小，不需要任何高级数据结构。

## 二、思维链：完整证明

**记号。** 摄像头集合 $V=\{0,\dots,n-1\}$（内部 0-based），位置 $x_i\in[0,500]$。$\mathrm{mon}(i,y)$ 表示 $i$ 的监视列表含位置 $y$（重复列出视为一次）。建边：$i\to j\iff i\ne j\land\mathrm{mon}(i,x_j)$。入度 $\mathrm{in}(j)=|\{i:i\to j\}|$。"活着"指尚未被砸。

---

### 引理 1（可砸条件的图论刻画）

在活摄像头集合 $S$ 下，$j\in S$ 可砸 $\iff$ $j$ 在导出子图 $G[S]$ 中入度为 $0$。

*证明*：按题意，$j$ 可砸 $\iff$ 不存在**其他**活摄像头监视 $x_j$，即 $\nexists i\in S\setminus\{j\}:\mathrm{mon}(i,x_j)$。由建边定义（$i\ne j$ 已排除自监视），这恰好是"$G[S]$ 中没有指向 $j$ 的边"，即入度为 $0$。两个方向逐字等价。证毕。

（这条引理同时确认了坑 1 与坑 2 的处理：自监视因 $i\ne j$ 被排除；重复监视因 $\mathrm{mon}$ 是布尔关系、入度数的是**前驱个数**而只计一次。）

---

### 引理 2（砸毁 = 删点删边，模型自洽）

砸掉 $u$ 后，其余摄像头的可砸状态恰等于 $G[S\setminus\{u\}]$ 中的入度为 $0$ 判定。

*证明*：题面明确"砸了这些摄像头之后自然这些位置就监视不到了"，即 $u$ 的所有监视关系失效。活集合变为 $S\setminus\{u\}$，由引理 1 直接得到。算法上维护 $\mathrm{in}[\cdot]$：删 $u$ 时对每条 $u\to v$ 执行 `--in[v]`，正是导出子图入度的增量维护。证毕。

---

### 引理 3（Kahn 剥出的集合 = 一切合法砸法能砸掉的集合；剩余个数唯一）

设 $R$ 为 Kahn 算法（反复取当前入度 $0$ 的点删除，直到没有）删掉的点集。则：

(a) $R$ 中的点存在一个合法砸毁顺序（即算法的删除顺序）；
(b) 任何合法砸毁顺序砸掉的点都属于 $R$；
(c) 剩余个数 $n-|R|$ 与剥皮顺序无关。

*证明*：

(a) 算法每步删除的点在当前活子图中入度为 $0$（队列里只放入度减到 $0$ 的点，初始放入度 $0$ 的点），由引理 1 该步合法。故删除序列本身是合法砸法。

(b) 反证。设某合法序列砸掉了 $R$ 之外的点，取其中**第一个** $R$ 外的点 $v$。合法性要求砸 $v$ 时它的所有前驱（监视 $x_v$ 的其他摄像头）都已被砸掉。另一方面，算法终止时 $v\notin R$ 活着且 $\mathrm{in}(v)\ge1$，而这些残余入度只能来自同样未被删的点（来自 $R$ 的边在删点时已被扣掉），故存在前驱 $u\notin R$。$u$ 必须在 $v$ 之前被砸（否则 $v$ 不可砸），但 $u\notin R$ 且在序列中先于 $v$——与"$v$ 是第一个 $R$ 外的点"矛盾。

(c) 由 (a)(b)，"可砸掉的点集"被唯一确定为 $R$：任何合法砸法最多砸掉 $R$，而剥皮顺序能砸掉全部 $R$。故无论队列以什么顺序出队，$|R|$ 相同，剩余 $n-|R|$ 相同。证毕。

**推论（剩余子图的结构）**：终止时每个剩余点入度 $\ge1$ 且前驱都在剩余集内，从任一点沿前驱无限回溯，点数有限必重复，故剩余子图含环；剩余点正是"环上及被环挡住"的摄像头。这解释了为什么答案是"个数"而不是别的：它们一个都砸不了。

---

### 引理 4（建边实现的正确性）

代码用 `mon[i][y]` 布尔矩阵读入监视列表，再枚举 $i\ne j$ 判 `mon[i][x[j]]` 建边、累加 $\mathrm{in}[j]$。则建出的图与引理 1 的定义一致。

*证明*：读入时 `mon[i][y]=true` 对重复的 $y$ 幂等，故 $\mathrm{mon}(i,y)$ 恰为"列表含 $y$"。枚举所有有序对 $(i,j),i\ne j$，条件 `mon[i][x[j]]` 即 $\mathrm{mon}(i,x_j)$，与边定义逐字一致；每对至多建一条边、$\mathrm{in}[j]$ 至多因 $i$ 加 $1$，故入度 = 不同前驱个数。位置范围 $0..500$ 落在 `mxv=505` 内，无越界。证毕。

---

### 引理 5（复杂度）

时间 $O(n^2+\sum_i m_i)$，空间 $O(n\cdot 505+n^2)$。

*证明*：读入 $\sum m_i$ 个位置，每次 $O(1)$ 置位。建边双重循环 $n(n-1)$ 次 $O(1)$ 判断。Kahn：每点入队出队各一次，出队时扫一行邻接矩阵 $O(n)$，共 $O(n^2)$。合计 $O(n^2+\sum m_i)$。代入 $n=100,m_i\le100$：约 $10^4+10^4=2\times10^4$ 次基本操作，远低于时限。空间：`mon` 约 $105\times505$ 字节 $\approx53$ KB，`e` 约 $105^2$ 字节 $\approx11$ KB。证毕。

---

### 定理

程序输出 `YES` 当且仅当所有摄像头可被某合法顺序砸毁；否则输出砸不掉的摄像头个数，且该个数唯一确定。

*证明*：引理 1、2、4 保证算法维护的入度始终等于真实可砸判定；引理 3 保证剥皮删掉的恰为全部可砸点、剩余个数与顺序无关；$|R|=n$ 时输出 `YES`，否则输出 $n-|R|$。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 把"可砸"翻译成"没有活的前驱监视我的位置"，依赖边 $i\to j$：$j$ 等 $i$ 先死。
- classic problem solution — 入度 $0$ 可砸、删点减入度 ⇒ 拓扑排序（Kahn 剥皮）。
- discuss by category — 建模四坑逐一处理：自监视排除（"其他"）、重复监视去重（入度数前驱个数）、同位置摄像头、非摄像头位置忽略。
- explore its property — 剩余子图每点入度 $\ge1$ ⇒ 必含环；用"第一个反例"论证证明剩余集合与剥皮顺序无关，答案唯一。
- discuss by category — 手造 $6$ 组小数据（独立、自监视、链、环、重复列表、环+独立点）核对模型与输出格式。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 摄像头数 $\le100$ | `int`，读入 | |
| `x[i]` | 第 $i$ 个摄像头的位置 $\in[0,500]$ | `int[mxn]`，读入 | 内部 0-based 摄像头编号 |
| `mon[i][y]` | 摄像头 $i$ 是否监视位置 $y$ | `bool[mxn][mxv]`，全局默认 `false` | 布尔矩阵天然去重 |
| `e[i][j]` | 依赖边 $i\to j$（$i$ 监视 $x_j$，$i\ne j$） | `bool[mxn][mxn]`，默认 `false` | 邻接矩阵 |
| `in[j]` | $j$ 的当前入度 = 活前驱个数 | `int[mxn]`，建边时累加 | 减到 $0$ 即可砸 |
| `Q` | 入度 $0$ 的待砸队列 | `queue<int>` | Kahn |
| `cnt` | 已砸个数 | `int`，初值 $0$ | 答案：`cnt==n`→`YES`，否则 `n-cnt` |
| `mxn,mxv` | $105,505$ | `constexpr int` | 约束 $+5$ 松弛 |

### 算法步骤

1. I/O 加速三行，读 $n$。
2. 每个摄像头读 $x_i,m$，再读 $m$ 个位置 $y$，置 `mon[i][y]=true`。
3. 枚举 $i\ne j$：若 `mon[i][x[j]]` 则 `e[i][j]=true; ++in[j]`。
4. 所有 `in[i]==0` 的 $i$ 入队。
5. 队不空：出队 $u$，`++cnt`；对每个 $v$ 若 `e[u][v]` 则 `--in[v]`，减到 $0$ 入队。
6. `cnt==n` 输出 `YES`，否则输出 `n-cnt`。

### 复杂度

- 时间：$O(n^2+\sum m_i)\le$ 约 $2\times10^4$ 次操作。
- 空间：$O(n\cdot505+n^2)\approx64$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；第一部分 $6$ 组手造数据（含自监视、重复列表、同位置、环）输出全部与手算一致。标准拓扑排序模型，证明封闭，不做对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2712 摄像头
// i 监视 x_j ⇒ 依赖边 i→j（j 要等 i 先被砸）；入度 0 可砸 ⇒ Kahn 拓扑剥皮
// 坑：自监视不算（"其他"摄像头）；重复监视只算一个前驱（bool 去重）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105},mxv{505};

int n,x[mxn],in[mxn];
bool mon[mxn][mxv],e[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0,m;i<n;++i)
	{
		cin>>x[i]>>m;
		for(int j=0,y;j<m;++j)
		{
			cin>>y;
			mon[i][y]=true;	// 重复列出幂等，天然去重
		}
	}
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			if(i!=j&&mon[i][x[j]])	// i!=j：自监视不构成依赖
				e[i][j]=true,++in[j];
	queue<int>Q;
	for(int i=0;i<n;++i)
		if(!in[i])
			Q.push(i);
	int cnt=0;
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		++cnt;
		for(int v=0;v<n;++v)
			if(e[u][v]&&--in[v]==0)
				Q.push(v);
	}
	if(cnt==n)
		cout<<"YES\n";
	else
		cout<<n-cnt<<'\n';
	return 0;
}
```

### 代码说明

- `mon` 是"摄像头 × 位置"布尔矩阵：读入去重 $O(1)$，建边查询 $O(1)$；位置 $0..500$ 需要 `mxv=505`（含 $0$，共 $501$ 个值，$+5$ 松弛）。
- `i!=j` 一行排除自环，对应题面"其他摄像头"；漏掉它会把自监视摄像头误判为砸不掉。
- `--in[v]==0` 才入队，保证每个点恰好入队一次（入度单调递减，只会穿过 $0$ 一次），`cnt` 即剥皮总数。
- 剩余点不需要显式找出：引理 3 保证个数唯一，直接输出 `n-cnt`。
- 全局 `bool`/`int` 默认 $0$/`false` 在本题恰好都是正确初值（无边、无监视、入度 $0$ 起算），不存在"不可达数组要填 INF"的场景。
