# P2201 数列编辑器 — 题解

## 一、解题过程：人类思考叙事

题面：一开始数列为空，只有一个光标。要支持五种操作：`I x` 在光标前插入 $x$；`D` 删除光标前的数；`L` / `R` 光标左/右移一格；`Q k` 询问"光标之前"的数列 $\{a_1,\dots,a_m\}$ 中，前 $k$ 个位置里最大的前缀和（$1\le k\le m$）。操作数 $N\le 10^6$，插入的数绝对值不超过 $1000$。保证不会在空数列上 `D`。

**第一反应**：开一个数组，记录光标的排名，插入/删除时把后面元素整体挪动。问题立刻暴露：`I` 和 `D` 都是 $O(N)$ 的，$10^6$ 次操作最坏 $10^{12}$，完全不行。换成链表能让插入删除 $O(1)$，但 `Q k` 还是要从头累加 $k$ 个数，最坏 $O(N)$。

**关键观察一：所有修改都发生在光标处。** 光标左边的数，彼此的相对顺序永远不会改变；光标右边的数也一样。于是整个数列可以看成一左一右两段，每次操作只做三件事之一：

- 往左段末尾塞一个数（`I`）；
- 从左段末尾拿走一个数（`D`）；
- 把左段末尾的数搬到右段开头（`L`），或者反过来（`R`）。

"只在末尾进出、且只和另一端交换末尾元素"的结构，正是**栈**。所以用两个栈 `a`（光标左侧，栈顶是光标前最后一个数）和 `b`（光标右侧，栈顶是光标后第一个数）来模拟光标。

**关键观察二：`Q k` 只跟左段有关。** 题面说光标之前是 $\{a_1,\dots,a_m\}$，而 $k\le m$；前 $k$ 个数一定全在光标左边，也就是全在栈 `a` 里。右栈只用来"记住"被光标越过的数，方便 `R` 时还原，不需要维护任何统计信息。

**关键观察三：前缀最大值可以在压栈时顺便维护。** 设 `sum` 为左栈元素之和，`f[i]` 为左栈前 $i$ 个数的最大前缀和。压入一个 $x$ 时：

- 新的 `sum` 变成 `sum + x`；
- 前 $i-1$ 个前缀没变，新增的前缀只有"前 $i$ 个之和"即新 `sum`；
- 所以 `f[i] = max(f[i-1], sum)`。

弹栈时，被删掉的是最后一个前缀，前 $i-1$ 个前缀和全都没变，所以 `f` **什么都不用改**。把元素从 `a` 搬到 `b` 时，左段只是弹栈，同样不用改；把元素从 `b` 搬回 `a` 时，等价于一次压栈，重新算一格即可。这样每种操作都是 $O(1)$。

**一个必须注意的边界**：`f[0]` 不能初始化为 $0$。题目里的前缀和是 $a_1+\dots+a_j$（$j\ge 1$），不包含空前缀。如果 `f[0]=0`，那么插入第一个负数 $x$ 时会得到 `f[1]=max(0,x)=0`，而正确答案应是 $x$。所以 `f[0]` 要设成负无穷。

手工小例（自己造）：依次执行

```
I 5, I -2, Q 2, I 3, Q 3, L, D, Q 1, R, I 4, Q 3
```

- `I 5`、`I -2` 后左段是 $[5,-2]$，前缀和 $5,3$，`Q 2` 答 $5$；
- `I 3` 后 $[5,-2,3]$，前缀和 $5,3,6$，`Q 3` 答 $6$；
- `L` 后光标在 $3$ 前，左段 $[5,-2]$；`D` 删掉 $-2$，左段 $[5]$，`Q 1` 答 $5$；
- `R` 把 $3$ 放回，左段 $[5,3]$；`I 4` 后 $[5,3,4]$，前缀和 $5,8,12$，`Q 3` 答 $12$。

与程序输出一致，说明"弹栈不改 `f`、回搬才重算"的维护方式是对的。

## 二、思维链：完整证明

先把状态精确化。设在任意时刻，整个数列为 $b_1,b_2,\dots,b_m$，光标位于位置 $c$，即光标左边恰有 $b_1,\dots,b_c$（$0\le c\le m$）。定义：

- 栈 $L$ 自底向顶存放 $b_1,\dots,b_c$，栈顶为 $b_c$；
- 栈 $R$ 自底向顶存放 $b_m,b_{m-1},\dots,b_{c+1}$，栈顶为 $b_{c+1}$；
- $S=\sum_{i=1}^{c}b_i$（左段之和）；
- 对 $0\le i\le c$，$f[i]=\max_{1\le j\le i}\sum_{t=1}^{j}b_t$，并约定 $f[0]=-\infty$。

**引理 1（双栈不变式）**：初始时 $m=c=0$，$L,R$ 为空，不变式成立。五种操作各自保持上述不变式。

*证明*：逐条检查。

1. `I x`：数列变为 $b_1,\dots,b_c,x,b_{c+1},\dots,b_m$，光标位置变为 $c+1$。新左段是 $b_1,\dots,b_c,x$，恰为 $L$ 压入 $x$；新右段仍是 $b_{c+1},\dots,b_m$，$R$ 不变。不变式成立。
2. `D`：题目保证 $c\ge1$，删除的是 $b_c$。新数列 $b_1,\dots,b_{c-1},b_{c+1},\dots,b_m$，光标位置 $c-1$。新左段是 $L$ 弹出栈顶后的内容；新右段不变。不变式成立。
3. `L`：若 $c=0$，光标已经在最左端，数列与光标位置都不变，$L,R$ 也不变，故不变式保持。若 $c\ge1$，新光标位置为 $c-1$，新左段为 $b_1,\dots,b_{c-1}$，即 $L$ 弹出栈顶 $b_c$；新右段为 $b_c,b_{c+1},\dots,b_m$，其自底向顶恰为 $b_m,\dots,b_{c+1},b_c$，也就是把 $b_c$ 压入 $R$ 后的内容。不变式成立。
4. `R`：若 $c=m$ 则程序不做事。否则新光标位置 $c+1$，左段变为 $b_1,\dots,b_c,b_{c+1}$，即从 $R$ 弹出栈顶 $b_{c+1}$ 压入 $L$；右段变为 $b_{c+2},\dots,b_m$，恰为 $R$ 弹出栈顶后的内容。不变式成立。
5. `Q k`：只读不写，不变式当然保持。

证毕。

**引理 2（$f$ 的正确性）**：在上述不变式下，对每个时刻的每个 $1\le i\le c$，都有 $f[i]=\max_{1\le j\le i}\sum_{t=1}^{j}b_t$；同时 $S=\sum_{t=1}^{c}b_t$。

*证明*：对操作序列归纳。初始 $c=0$，$S=0$ 正确，$f$ 没有需要验证的下标。

- `I x`：旧左段前缀（长度 $1..c$）与新数列的前缀完全一致，$f[1..c]$ 不变仍正确；新前缀只有长度 $c+1$，其和为旧 $S+x=$ 新 $S$，程序置 $f[c+1]=\max(f[c],S_{\text{新}})$，正是所有前缀和（前 $c$ 个的最大值 $f[c]$ 与第 $c+1$ 个前缀和）的最大值。$S$ 也同步加上 $x$。
- `D`：删除 $b_c$ 后，长度 $1..c-1$ 的前缀一个都没变，所以 $f[1..c-1]$ 仍正确；$S$ 减去了 $b_c$，正确。
- `L`：左段缩短为前 $c-1$ 个，前缀 $1..c-1$ 不变，$f$ 不变；$S$ 减去被搬走的 $b_c$，正确。
- `R`：左段长度变为 $c+1$，前 $c$ 个前缀不变；新前缀和等于旧 $S+b_{c+1}=$ 新 $S$，程序令 $f[c+1]=\max(f[c],S_{\text{新}})$，与 `I` 同理正确。
- `Q k`：不改变任何状态。

由归纳法，任意时刻结论成立。证毕。

**引理 3（查询正确）**：一次 `Q k` 输出 $f[k]$，就是题目所问的"光标之前数列前 $k$ 位的最大前缀和"。

*证明*：由题面保证 $k\le m$，其中 $m$ 是光标之前数列的长度，也就是当前的 $c$。由引理 1，光标之前的数列恰为 $b_1,\dots,b_c$，它的前 $k$ 位就是整个数列的前 $k$ 位 $b_1,\dots,b_k$。由引理 2，$f[k]=\max_{1\le j\le k}\sum_{t=1}^{j}b_t$，正是这 $k$ 个前缀和的最大值。证毕。

**引理 4（$f[0]=-\infty$ 的必要性）**：若令 $f[0]=0$，则当第一个插入的数为负数时，$f[1]$ 会被算成 $0$，与真实最大前缀和 $x<0$ 不符。

*证明*：插入 $x<0$ 时，程序计算 $f[1]=\max(f[0],S)=max(0,x)=0$；而长度 $1$ 的前缀和集合只有 $\{x\}$，最大值为 $x<0$。故必须取 $f[0]$ 小于任何可能的前缀和，本题取 $-1145141919810$ 即可（前缀和绝对值不超过 $10^6\times1000=10^9$）。证毕。

**引理 5（复杂度）**：总时间复杂度 $O(N)$，空间复杂度 $O(N)$。

*证明*：`I` 与 `R` 各做一次常数次赋值并可能更新一格 $f$；`D` 与 `L` 各做一次弹栈；`Q` 直接输出一格。五种操作都是 $O(1)$，共 $N$ 次，故时间 $O(N)$。两个栈最多各存 $N$ 个数，$f$ 长度 $N+1$，空间 $O(N)$。证毕。

**定理**：按上述双栈 + 前缀最大值维护的算法，对每次 `Q k` 都输出正确答案。

*证明*：由引理 1 状态表示始终正确，由引理 2 $f$ 始终是真实前缀最大值，由引理 3 查询取到的就是答案，由引理 4 哨兵设置不破坏负数情形。故算法正确。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 插入/删除只发生在光标边界，光标左右两段的内部顺序永不改变。
- **reduce to easier problem** — `Q k` 只涉及光标左侧的前 $k$ 个数，右段只需保存数值，不需要任何统计。
- **classic problem solution** — 用两个栈模拟光标：压栈 = 右移/插入，弹栈 = 左移/删除，栈间搬运 = 光标跨过一个数。
- **explore its property** — 前缀最大值是"可增量维护"的：压栈时多出一个前缀，弹栈时前缀集合只少最后一个。
- **discuss by category** — 分别考察 `I/D/L/R` 对 `sum` 与 `f` 的影响，得到"只有压栈需要重算一格"。
- **boundary check** — `f[0]` 必须为 $-\infty$，因为前缀不允许为空；空栈上的 `L/R` 要判边界。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $N$ | 操作总数 | 输入 |
| `a[0..lt-1]` | 光标左侧的栈，栈顶 `a[lt-1]` | `lt=0`，空 |
| `b[0..rt-1]` | 光标右侧的栈，栈顶 `b[rt-1]` 是光标后第一个数 | `rt=0`，空 |
| `lt` | 左栈元素个数，等于光标之前的数字个数 | $0$ |
| `rt` | 右栈元素个数 | $0$ |
| `sum` | 左栈所有元素之和 | $0$ |
| `f[0..lt]` | `f[i]` = 左栈前 $i$ 个数的最大前缀和 | `f[0]=-1145141919810`，其余随压栈计算 |
| `x` | 一次插入的数 | 读入 |
| `k` | 一次询问的前缀长度 | 读入，$1\le k\le lt$ |
| `op` | 当前命令字符 | 读入 |

### 算法步骤

1. 读入 $N$；初始化 `lt=rt=0`、`sum=0`、`f[0]=-1145141919810`。
2. 对每条命令：
   1. 读入命令字符 `op`。
   2. 若 `op=='I'`：读入 $x$，`a[lt++]=x`，`sum+=x`，`f[lt]=max(f[lt-1],sum)`。
   3. 若 `op=='D'`：`sum-=a[--lt]`（题目保证非空）。
   4. 若 `op=='L'`：若 `lt>0`，把 `a[lt-1]` 搬到 `b` 栈顶（`b[rt++]=a[--lt]`），并令 `sum-=b[rt-1]`；否则不动。
   5. 若 `op=='R'`：若 `rt>0`，把 `b[rt-1]` 搬回 `a` 栈顶（`a[lt++]=b[--rt]`），`sum+=a[lt-1]`，`f[lt]=max(f[lt-1],sum)`；否则不动。
   6. 若 `op=='Q'`：读入 $k$，输出 `f[k]`。
3. 全部操作结束后程序自然结束。

### 复杂度

- 时间复杂度：$O(N)$，每次操作 $O(1)$。
- 空间复杂度：$O(N)$，两个栈与 `f` 数组。

### 验证状态

编译通过；手造 11 条命令的用例输出 `5 6 5 12`，与手算一致；并在 2000 组随机操作序列（长度不超过 60，含边界 `L/R` 与负数插入）上与"vector + 光标下标"的暴力实现逐条输出比对，全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1000005};
constexpr i64 ninf{-1145141919810};

int a[mxn],b[mxn];   // a:光标左侧的栈(下标0..lt-1)  b:光标右侧的栈(栈顶是光标后第一个数)
i64 f[mxn];          // f[i]=光标左侧前i个数的最大前缀和
i64 sum;             // 光标左侧所有数之和

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	int lt=0,rt=0;
	f[0]=ninf;
	for(int i=0;i<n;++i)
	{
		char op;
		cin>>op;
		if(op=='I')
		{
			int x;
			cin>>x;
			a[lt++]=x;
			sum+=x;
			f[lt]=max(f[lt-1],sum);
		}
		else if(op=='D')
		{
			sum-=a[--lt];
		}
		else if(op=='L')
		{
			if(lt)
			{
				b[rt++]=a[--lt];
				sum-=b[rt-1];
			}
		}
		else if(op=='R')
		{
			if(rt)
			{
				a[lt++]=b[--rt];
				sum+=a[lt-1];
				f[lt]=max(f[lt-1],sum);
			}
		}
		else
		{
			int k;
			cin>>k;
			cout<<f[k]<<'\n';
		}
	}
	return 0;
}
```

### 代码说明

- 下标从 $0$ 开始读写更方便：`a[lt++]` 写入后 `lt` 恰好是新长度，`f[lt]` 对应前 `lt` 个数。
- `L` 里先做 `b[rt++]=a[--lt]`，此时 `b[rt-1]` 就是刚搬走的数，直接用它更新 `sum`，避免再用临时变量。
- `D` 与 `L` 都只弹栈，不触碰 `f`：被删除的只是最后一个前缀，其余前缀和没变。
- `R` 是唯一需要"重算前缀最大值"的搬运方向，因为左段增长了一个数。
- `f[0]=ninf` 防止第一个数为负时把空前缀当成合法答案。
