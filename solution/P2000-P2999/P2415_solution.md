# P2415 集合求和 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给一个集合 $s$（$1\le|s|\le 30$，元素 $1\le s_i\le 1000$），求**它所有子集的元素之和的总和**。空集也算子集（贡献 $0$）。题面保证答案 $\le 10^{18}$。

输入格式有个坑：**只给元素，不给个数**（"集合中的元素"），所以必须读到 EOF 为止，不能先读一个 $n$。

**第一步：先估规模，判断能不能暴力。** $n$ 个元素的集合有 $2^n$ 个子集。$n=30$ 时 $2^{30}\approx1.07\times10^9$，每个子集还要扫一遍元素求和，总量 $\sim3\times10^{10}$——枚举子集这条路直接死掉。答案保证 $\le10^{18}$ 也在暗示：**要用 64 位整数，而且要有闭式**。

**第二步：手算最小的样例，找规律。** 题面 Hint 给了 $s=\{2,3\}$：子集是 $\varnothing,\{2\},\{3\},\{2,3\}$，总和 $0+2+3+5=10$。

我换个角度数这 $10$：不看子集，看**每个元素被加了几次**。

- $2$ 出现在 $\{2\}$ 和 $\{2,3\}$ 里，共 $2$ 次；
- $3$ 出现在 $\{3\}$ 和 $\{2,3\}$ 里，共 $2$ 次。

所以总和 $=2\times2+2\times3=2\times(2+3)=10$。**$2$ 恰好是子集总数 $4$ 的一半。**

再试 $s=\{1,2,3\}$：$8$ 个子集，每个元素应该出现 $4$ 次，总和 $=4\times(1+2+3)=24$。手工列一遍：$\varnothing(0),\{1\}(1),\{2\}(2),\{3\}(3),\{1,2\}(3),\{1,3\}(4),\{2,3\}(5),\{1,2,3\}(6)$，加起来 $0+1+2+3+3+4+5+6=24$ ✓。

**第三步：为什么每个元素恰好出现在一半子集里？** 直觉是"选它 / 不选它"对称。严格一点：固定元素 $a_i$，把"含 $a_i$ 的子集"里的 $a_i$ 删掉，就得到一个 $s\setminus\{a_i\}$ 的子集；反过来给 $s\setminus\{a_i\}$ 的任意子集添上 $a_i$，就得到一个含 $a_i$ 的子集。这两个操作互逆，是**双射**，所以含 $a_i$ 的子集个数 $=|P(s\setminus\{a_i\})|=2^{n-1}$。

于是答案 $=2^{n-1}\sum_i s_i$。整个算法就是"读一遍求和 + 乘一个 $2$ 的幂"，$O(n)$。

**第四步：换个推导交叉验证。** 万一"一半"这个直觉在边界上翻车呢？我用递推再推一遍：设 $F_k$ 为前 $k$ 个元素的所有子集的元素和之总和。加入第 $k+1$ 个元素 $a_k$ 后，子集分成两类——不含 $a_k$ 的（总和仍是 $F_k$）与含 $a_k$ 的（每个都是"前 $k$ 个的某子集 $+a_k$"，总和 $F_k+a_k\cdot 2^k$）。所以
$$F_{k+1}=2F_k+a_k\cdot 2^k,\qquad F_0=0.$$
展开：$F_1=a_0$，$F_2=2a_0+a_1\cdot2=2(a_0+a_1)$，$F_3=4(a_0+a_1)+4a_2=4(a_0+a_1+a_2)$……归纳可得 $F_n=2^{n-1}\sum a_i$，与双射法完全一致。这条递推我后来直接写成暴力程序，用来在 $n=30$ 的极限数据上核对闭式（$2^{30}$ 枚举跑不动，但递推是 $O(n)$ 的）。

**第五步：几个实现上的坑，逐个排掉。**

1. **读入到 EOF。** 元素个数不给，`while(cin>>a[n]){sum+=a[n];++n;}` 一路读到流失败。这样写还顺带兼容"一行给完"和"分多行给"两种排版。
2. **必须 `long long`。** 极限是 $n=30$、全 $1000$：$2^{29}\times30000=16106127360000\approx1.6\times10^{13}$，远超 `int` 的 $2.1\times10^9$。事实上 $n=20$ 全 $1000$ 时就已经 $2^{19}\times20000\approx1.05\times10^{10}$ 爆 `int` 了。求和变量、幂变量、答案变量**全部**用 `i64`。
3. **$2^{n-1}$ 怎么算。** 写 `1LL<<(n-1)` 可以，但 $n=0$ 时移位数为 $-1$ 是未定义行为。虽然题目保证 $|s|\ge1$，我改用循环 `for(int i=1;i<n;++i)pw*=2;`：$n\ge1$ 时得到 $2^{n-1}$，$n=0$ 时 `pw=1`、`sum=0`，答案 $0$，**天然避开负数移位**，也不依赖任何边界特判。
4. **空集要不要减掉？** 不用。空集贡献 $0$，去掉它不改变总和；而且它不含任何元素，所以"每个元素出现 $2^{n-1}$ 次"这个计数也不受影响（$2^{n-1}$ 是在全部 $2^n$ 个子集里数出来的）。**千万不要因为"非空子集有 $2^n-1$ 个"就把系数写成 $2^{n-1}-1$**，那是把"子集个数"和"含某元素的子集个数"搞混了。
5. **重复元素。** 题面说是集合，元素互异；即便数据里出现重复值，按"位置"区分子集时公式照样成立（双射论证只用到"某个固定位置"，与值是否相同无关）。

**手造数据核对**（题面没有给样例输入输出，只有 Hint 里的 $\{2,3\}$ 解释）：

| 输入 | 手算 | 程序 |
|------|------|------|
| `2 3` | $2^1\times5=10$ | `10` ✓ |
| `1 2 3` | $2^2\times6=24$ | `24` ✓ |
| `1000` | $2^0\times1000=1000$ | `1000` ✓ |
| $30$ 个 `1000` | $2^{29}\times30000=16106127360000$ | `16106127360000` ✓ |

最后一组同时验证了"不溢出"和"$2^{n-1}$ 的幂次没算错一位"。

## 二、思维链：完整证明

**记号。** 设集合元素按读入顺序记为 $a_0,a_1,\dots,a_{n-1}$（$1\le n\le30$，$1\le a_i\le1000$）。对子集 $T\subseteq\{0,\dots,n-1\}$（用下标集合表示子集），定义其权 $w(T)=\sum_{i\in T}a_i$，$w(\varnothing)=0$。要求的答案是
$$A=\sum_{T\subseteq\{0,\dots,n-1\}}w(T).$$
记 $S=\sum_{i=0}^{n-1}a_i$。

---

### 引理 1（子集总数为 $2^n$）

$n$ 元集合的子集个数是 $2^n$，且子集与 $\{0,1\}^n$ 中的向量一一对应。

*证明*：定义映射 $\chi$：子集 $T\mapsto(\mathbf 1_{0\in T},\dots,\mathbf 1_{n-1\in T})\in\{0,1\}^n$（特征向量）。

- **单射**：若 $\chi(T)=\chi(T')$，则对每个 $i$，$i\in T\iff i\in T'$，故 $T=T'$。
- **满射**：任给 $v\in\{0,1\}^n$，取 $T=\{i:v_i=1\}$，则 $\chi(T)=v$。

故 $\chi$ 是双射，子集个数 $=|\{0,1\}^n|=2^n$（每个分量独立取 $2$ 种值，乘法原理）。证毕。

---

### 引理 2（每个元素恰出现在 $2^{n-1}$ 个子集中）

固定 $i$。含 $i$ 的子集个数 $=2^{n-1}$。

*证明*：记 $\mathcal A=\{T\subseteq\{0,\dots,n-1\}:i\in T\}$，$\mathcal B=\{U:U\subseteq\{0,\dots,n-1\}\setminus\{i\}\}$。

定义 $f:\mathcal A\to\mathcal B$，$f(T)=T\setminus\{i\}$；$g:\mathcal B\to\mathcal A$，$g(U)=U\cup\{i\}$。

- **良定义**：$T\in\mathcal A$ 时 $T\setminus\{i\}$ 不含 $i$，故属于 $\mathcal B$；$U\in\mathcal B$ 时 $U\cup\{i\}$ 含 $i$，故属于 $\mathcal A$。
- **互逆**：$g(f(T))=(T\setminus\{i\})\cup\{i\}=T$（因 $i\in T$）；$f(g(U))=(U\cup\{i\})\setminus\{i\}=U$（因 $i\notin U$）。

故 $f$ 是双射，$|\mathcal A|=|\mathcal B|$。而 $\{0,\dots,n-1\}\setminus\{i\}$ 有 $n-1$ 个元素，由引理 1，$|\mathcal B|=2^{n-1}$。证毕。

**等价的对合视角**：映射 $\tau(T)=T\triangle\{i\}$（含 $i$ 则删、不含则加）是 $\mathcal P$ 上的对合（$\tau\circ\tau=\mathrm{id}$）且无不动点（$\tau(T)\ne T$），它把全部 $2^n$ 个子集两两配对，每对恰有一个含 $i$，故含 $i$ 的占一半。这与上面的双射是同一件事的两种写法。

---

### 引理 3（交换求和顺序：双计数）

$$A=\sum_{i=0}^{n-1}a_i\cdot\bigl|\{T:i\in T\}\bigr|=2^{n-1}\cdot S.$$

*证明*：把 $w(T)$ 写成带指示函数的和：$w(T)=\sum_{i=0}^{n-1}a_i\mathbf 1_{i\in T}$（$i\notin T$ 的项为 $0$，不影响）。于是
$$A=\sum_{T}\sum_{i}a_i\mathbf 1_{i\in T}.$$
这是**有限**双重求和，指标集为有限集 $P=\{(T,i):i\in T\}$，被加项为 $a_i$。有限和可以任意重排（加法交换律 + 结合律），按 $T$ 分组或按 $i$ 分组都是对同一多重集 $\{a_i:(T,i)\in P\}$ 求和：
$$\sum_{T}\sum_{i}a_i\mathbf 1_{i\in T}=\sum_{(T,i)\in P}a_i=\sum_{i}a_i\cdot|\{T:(T,i)\in P\}|=\sum_i a_i\cdot|\{T:i\in T\}|.$$
由引理 2，$|\{T:i\in T\}|=2^{n-1}$ 对每个 $i$ 都成立，提出公因子得 $A=2^{n-1}\sum_i a_i=2^{n-1}S$。证毕。

**这一步是本题的核心转化**：从"对子集求和"（$2^n$ 项，不可枚举）变成"对元素求和"（$n$ 项），代价只是要知道每个元素的出现次数——而引理 2 用一个双射就给出了。

---

### 引理 4（递推推导，独立复核）

设 $F_k=\sum_{T\subseteq\{0,\dots,k-1\}}w(T)$（前 $k$ 个元素的答案），则 $F_0=0$ 且
$$F_{k+1}=2F_k+a_k\cdot 2^k\quad(0\le k<n).$$
由此可归纳证明 $F_n=2^{n-1}S$（$n\ge1$）。

*证明*：**递推式**：前 $k+1$ 个元素的子集分成不交的两类：
- 不含下标 $k$ 的：它们就是前 $k$ 个元素的子集，权和总和为 $F_k$；
- 含下标 $k$ 的：由引理 2 的双射，它们与"前 $k$ 个元素的子集 $U$"一一对应（$U\mapsto U\cup\{k\}$），每个的权为 $w(U)+a_k$，故这类总和为 $\sum_U(w(U)+a_k)=F_k+a_k\cdot|\{U\}|=F_k+a_k2^k$（引理 1）。

两类相加得 $F_{k+1}=2F_k+a_k2^k$。$F_0$ 对应只有空集，$w(\varnothing)=0$，故 $F_0=0$。

**闭式归纳**：命题 $P(k)$：$F_k=2^{k-1}\sum_{j<k}a_j$（$k\ge1$）。
- $k=1$：$F_1=2F_0+a_0\cdot2^0=a_0=2^0\sum_{j<1}a_j$ ✓。
- 设 $P(k)$ 成立，则
$$F_{k+1}=2\cdot2^{k-1}\sum_{j<k}a_j+a_k2^k=2^k\Bigl(\sum_{j<k}a_j+a_k\Bigr)=2^k\sum_{j<k+1}a_j,$$
即 $P(k+1)$ ✓。

故 $F_n=2^{n-1}S$，与引理 3 一致。证毕。

---

### 引理 5（空集不影响答案，也不影响系数）

$A$ 等于"所有**非空**子集的权和之和"；同时每个元素在非空子集中的出现次数仍是 $2^{n-1}$。

*证明*：$w(\varnothing)=0$，故从求和中去掉 $\varnothing$ 这一项不改变 $A$。又 $\varnothing$ 不含任何元素，故对每个 $i$，$\{T:i\in T\}$ 中本来就没有 $\varnothing$，去掉它不改变该集合的大小，仍为 $2^{n-1}$（引理 2）。证毕。

**推论（常见错误）**：把系数写成 $2^{n-1}-1$ 或 $\frac{2^n-1}{2}$ 都是错的——非空子集有 $2^n-1$ 个（奇数），但"含某元素的子集"个数与是否允许空集无关。

---

### 引理 6（读入到 EOF 的正确性）

题面不给出元素个数。`while(cin>>a[n]){sum+=a[n];++n;}` 能且仅能读入输入流中全部整数，读完后 `n` 等于元素个数、`sum` 等于 $S$。

*证明*：`operator>>(int&)` 先跳过前导空白（空格、换行、制表符），再解析一个整数；成功时流保持 good，表达式转换为 `true`，恰好消耗一个整数；到达文件尾或解析失败时流置 fail/eof，转换为 `false`，循环结束。因此循环体执行次数 = 输入中整数的个数 = $n$，且第 $t$ 次执行把第 $t$ 个整数存入 `a[t]`（此时 `n==t`）并累加进 `sum`。由加法交换律，`sum` $=\sum_t a_t=S$，与排版（一行或多行）无关。

数组越界：题面保证 $n\le30$，`mxn=35`，写入下标 $0..29$ 均在界内；循环条件在写入前判断流状态，不会多写。证毕。

---

### 引理 7（数值范围与 64 位必要性）

在 $1\le n\le30$、$1\le a_i\le1000$ 下，
$$A\le 2^{29}\times 30000=16\,106\,127\,360\,000\approx1.61\times10^{13},$$
且该上界可达；$A$ 可能超过 `int` 上限 $2^{31}-1=2\,147\,483\,647$，故必须用 64 位整数。中间量 `pw`$\le2^{29}$、`sum`$\le30000$ 也都在 64 位内。

*证明*：$A=2^{n-1}S$ 关于 $n$ 与每个 $a_i$ 都单调不减（$n$ 增大时因子 $2^{n-1}$ 增大且 $S$ 不减；$a_i$ 增大时 $S$ 增大），故最大值在 $n=30$、所有 $a_i=1000$ 处取到，此时 $S=30000$、$2^{29}=536870912$，乘积 $=16106127360000$。

它 $<2^{63}-1=9223372036854775807$，故 `long long` 足够（也与题面"答案 $\le10^{18}$"相容）。

超 `int` 的实例：$n=20$、全 $1000$ 时 $A=2^{19}\times20000=10485760000>2^{31}-1$。故 32 位会溢出。

中间量：`pw` 最终为 $2^{n-1}\le2^{29}$，`sum`$\le30000$，两者相乘即 $A$，全程无超过 $A$ 的量。证毕。

---

### 引理 8（幂的循环计算与 $n=0$ 安全）

代码 `i64 pw=1; for(int i=1;i<n;++i)pw*=2;` 结束后：$n\ge1$ 时 `pw`$=2^{n-1}$；$n=0$ 时 `pw`$=1$。因此 `ans=sum*pw` 在 $n\ge1$ 时等于 $A$，在 $n=0$ 时等于 $0$，且**全程没有移位运算**，不存在负数移位或移位数 $\ge$ 位宽的未定义行为。

*证明*：循环执行次数为 $\max(n-1,0)$（$n\ge1$ 时 $i$ 取 $1..n-1$ 共 $n-1$ 次；$n\le1$ 时 $0$ 次）。每次 `pw` 乘 $2$，初值 $1$，故 `pw`$=2^{\max(n-1,0)}$。$n\ge1$ 时即 $2^{n-1}$，由引理 3 得 `ans`$=A$。$n=0$ 时输入无元素，引理 6 给出 `sum`$=0$，故 `ans`$=0$，与"空集合只有空集一个子集、权和为 $0$"一致。乘法在 64 位内进行，由引理 7 不溢出。证毕。

---

### 引理 9（复杂度）

时间 $O(n)$，空间 $O(n)$（若边读边累加、不存 `a[]`，可降到 $O(1)$ 额外空间）。

*证明*：读入 $n$ 个整数并累加：$O(n)$；幂循环 $n-1$ 次乘法：$O(n)$；一次乘法与输出：$O(1)$。合计 $O(n)$，$n\le30$。空间：`a[mxn]` 为常数大小数组（$35$ 个 `int`），按输入规模计为 $O(n)$；只保留 `sum`、`pw`、`n` 的话是 $O(1)$。证毕。

---

### 定理

程序对任意合法输入输出 $A=2^{n-1}\sum_i a_i$，即集合所有子集的元素之和的总和，且不会溢出。

*证明*：引理 6 保证 $n$ 与 $S$ 读对；引理 1、2 给出子集计数与每元素出现次数；引理 3 把答案化为闭式；引理 4 用独立递推复核同一闭式；引理 5 说明空集的处理不影响结果；引理 8 保证幂次计算正确且无未定义行为；引理 7 保证 64 位足够；引理 9 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 子集共 $2^n$ 个，$n=30$ 时 $\approx10^9$，枚举子集不可行；答案 $\le10^{18}$ 暗示 64 位 + 闭式。
2. **consider easier version** — 手算 $\{2,3\}$ 与 $\{1,2,3\}$，改成"数每个元素被加了几次"，发现次数恰是子集总数的一半。
3. **reduce to easier problem** — 交换求和顺序（双计数）：$\sum_T\sum_{i\in T}a_i=\sum_i a_i\cdot\#\{T\ni i\}$，把 $2^n$ 项压成 $n$ 项。
4. **classic problem solution** — 用"删掉 / 添上 $a_i$"的双射（或无不动点对合）证明每个元素恰出现在 $2^{n-1}$ 个子集中。
5. **classic problem solution** — 独立递推 $F_{k+1}=2F_k+a_k2^k$ 复核闭式，并作为大规模对拍基准。
6. **discuss by category** — 输入不给个数 ⇒ 读到 EOF；答案 $1.6\times10^{13}$ ⇒ 全程 `long long`；用乘法循环算 $2^{n-1}$ 顺手避开 $n=0$ 的负数移位。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $n$ | 集合元素个数（**不读入，靠 EOF 数出来**） | `int` | 全局默认 $0$，每读到一个元素 `++n` |
| `a[i]` | 第 $i$ 个元素（0-based） | `int[mxn]` | 读入；其实只用来暂存，可省 |
| `mxn` | $30+5=35$ | `constexpr int` | 数组尺寸 |
| `sum` | $S=\sum_i a_i$ | `i64` | 初值 $0$，边读边累加 |
| `pw` | $2^{n-1}$（$n=0$ 时为 $1$） | `i64` | **初值 $1$**，循环乘 $2$ 共 $n-1$ 次 |
| `ans` | 答案 $S\cdot 2^{n-1}$ | `i64` | 由 `sum*pw` 得到 |
| `i64` | `long long` 别名 | — | 答案可达 $1.6\times10^{13}$，必须 64 位 |

### 算法步骤

1. I/O 加速三行。
2. `while(cin>>a[n])`：把元素读进 `a[n]`，`sum+=a[n]`，`++n`；直到 EOF。
3. `pw=1`；`for(int i=1;i<n;++i)pw*=2;` 得到 $2^{n-1}$。
4. `ans=sum*pw`。
5. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(n)$，$n\le30$（读入 $n$ 个数 + $n-1$ 次乘法）。
- 空间：$O(n)$（`a[35]`；若边读边累加可做到 $O(1)$ 额外空间）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Hint 的 $\{2,3\}\to10$ 以及手造 $\{1,2,3\}\to24$、$\{1000\}\to1000$、$30$ 个 $1000\to16106127360000$ 全部正确；$366$ 组数据（$6$ 组手造 + $300$ 组 $n\le14$ 随机与"$2^n$ 子集全枚举"暴力比对 + $60$ 组 $15\le n\le30$ 随机与 `__int128` 递推 $F_{k+1}=2F_k+a_k2^k$ 比对，含 $n=30$ 全 $1000$ 极限）全部一致，$0$ mismatch。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2415 集合求和
// 思路：每个元素恰出现在 2^(n-1) 个子集中（删/添该元素的双射），
//       所以答案 = 2^(n-1) * 所有元素之和。O(n)。
//       输入不给元素个数 ⇒ 读到 EOF；答案可达 1.6e13 ⇒ 全程 long long。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{35};

int n,a[mxn];
i64 sum,pw{1},ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	while(cin>>a[n])			// 元素个数不给出，读到 EOF 为止
	{
		sum+=a[n];
		++n;
	}
	for(int i=1;i<n;++i)		// pw=2^(n-1)；n==0 时 pw=1、sum=0，不会负数移位
		pw*=2;
	ans=sum*pw;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`while(cin>>a[n])`** 是本题输入格式的唯一正确姿势：题面只给元素、不给个数。写成"先读 $n$ 再读 $n$ 个数"会把第一个元素当成个数，全盘皆错。
- `sum`、`pw`、`ans` 全为 `i64`。`pw{1}` 用花括号初始化（风格规范），**不能初始化为 $0$**，否则答案恒为 $0$。
- 幂用循环乘 $2$ 而不是 `1LL<<(n-1)`：结果一样，但顺手规避了 $n=0$ 时负数移位的未定义行为，也不需要额外特判。
- `a[]` 只是暂存，真正用到的只有 `sum` 与 `n`；保留数组是为了符合"全局静态数组"的仓库风格，也方便调试时回看输入。
- 空集不需要任何特判：它贡献 $0$，且不含任何元素，系数 $2^{n-1}$ 不受影响（引理 5）。
- 换行用 `'\n'`。
