# P2946 [USACO09MAR] Cow Frisbee Team S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 头奶牛（$1\le N\le 2000$），第 $i$ 头能力为整数 $R_i$（$1\le R_i\le 10^5$）。要选出**至少 $1$ 头、至多 $N$ 头**组成队伍（即选一个**非空子集**），要求队员能力之和是 $F$ 的倍数（$1\le F\le 1000$）。问方案数，对 $10^8$ 取模输出。注意：方案按"选了哪些牛"区分，与顺序无关；两头能力相同的牛也是不同的个体。

**第一反应：枚举子集。** 每头牛选或不选，共 $2^N$ 种，$N=2000$ 时 $2^{2000}$ 是天文数字，直接死路。但"每头牛选/不选、对全局和有一个约束"这个形状，就是**0/1 背包计数**的标准脸。

**第二步：背包的"体积维"开多大？** 经典计数背包 $f[s]$ 表示"和恰为 $s$ 的子集数"，这里 $s$ 最大 $2000\times10^5=2\times10^8$，数组开不下，时间 $O(N\sum R)$ 也爆炸。卡住之后回头读题：题目**根本不关心和的具体值**，只关心"是不是 $F$ 的倍数"，即只关心 $\text{和}\bmod F$。而模运算对加法是"透明"的：

$$(a+b)\bmod F=\bigl((a\bmod F)+(b\bmod F)\bigr)\bmod F.$$

也就是说，往队伍里加一头能力为 $R_i$ 的牛，对余数的影响只取决于 $r_i=R_i\bmod F$，与 $R_i$ 本身无关。**于是 $2\times10^8$ 的"和"维度塌缩成 $F\le1000$ 的"余数"维度**——这一步是本题的全部灵魂。

**第三步：写出转移。** 设 $f[j]$ = 只考虑前 $i$ 头牛、选出子集的能力和 $\equiv j\pmod F$ 的方案数。加入第 $i+1$ 头牛（余数 $r$）时，每个旧子集 $S$ 分裂成两个新子集：

- 不选它：$S$ 保留，余数不变，贡献到 $f'[j]$；
- 选它：$S\cup\{i+1\}$，余数变成 $(j+r)\bmod F$，贡献到 $f'[(j+r)\bmod F]$。

所以 $f'=f$（继承），再对每个 $j$ 做 $f'[(j+r)\bmod F]\mathrel{+}=f[j]$。初始 $f[0]=1$（空集，和为 $0$），其余为 $0$。答案要求非空，而空集恰好被计入 $f[0]$ 一次，故输出 $f[0]-1$（取模意义下）。

**第四步：一个诱人的陷阱——能不能像普通 0/1 背包那样"原地倒序"省掉一层数组？** 普通 0/1 背包把体积维倒着扫，保证读到的 $f[j-w]$ 还是旧层的值。但这里下标是**环形的**：$(j+r)\bmod F$ 在 $j+r\ge F$ 时回绕到比 $j$ 小的位置。倒序扫描时，回绕目标会在**之后**被当作源读取——读到的是本轮已污染的值，同一头牛被用了两次。我在草稿纸上试了 $F=5$、两头牛余数都是 $3$ 的例子，倒序原地版真的算错了（完整推演见引理 3）。**结论：必须复制整层**，$f$ 与 $g$ 两个数组倒手，每头牛 $O(F)$ 复制 + $O(F)$ 转移，总量 $O(NF)=2\times10^6$，毫无压力。

**第五步：取模细节。** 模数 $10^8$ 不是质数，但全程只有加法，不需要逆元，是不是质数无所谓。两个 `int` 相加最大 $(10^8-1)\times2<2^{31}$，不溢出。最后 $f[0]$ 是取模后的值，可能恰好为 $0$，直接 `f[0]-1` 会得 $-1$，要写 `(f[0]-1+p)%p`。

**手造数据核对**（题面无样例输入输出，全部自造并手算）：

| 输入 | 手算 | 输出 |
|---|---|---|
| `4 5` / `1 2 3 4` | 和为 $5$ 倍数的子集：$\{1,4\},\{2,3\},\{1,2,3,4\}$（和 $10$），共 $3$ | `3` |
| `1 1` / `7` | $F=1$ 时任何非空子集都行，$2^1-1=1$ | `1` |
| `2 3` / `1 1` | 子集和为 $1,1,2$，无 $3$ 的倍数 | `0` |
| `2 5` / `3 3` | 子集和为 $3,3,6$，无 $5$ 的倍数（这正是打原地滚动陷阱的数据） | `0` |
| `3 1` / `5 5 5` | $2^3-1=7$ | `7` |
| `4 5` / `1 2 8 2` | $\{2,8\},\{8,2\},\{1,2,2\}$（和 $5$），共 $3$ | `3` |

六组全部与程序输出一致；另造 $N=2000,F=1$、全 $R_i=10^5$ 的极限数据，答案应为 $2^{2000}-1\bmod 10^8$，用大整数精确算得 `49029375`，程序输出一致。

## 二、思维链：完整证明

**记号。** 牛编号 $1..N$，$r_i=R_i\bmod F$。对子集 $S\subseteq\{1..N\}$ 记 $\sigma(S)=\sum_{i\in S}R_i$（$\sigma(\varnothing)=0$）。目标是求 $\bigl|\{S\ne\varnothing:\sigma(S)\equiv0\pmod F\}\bigr|\bmod 10^8$。记 $p=10^8$。

---

### 引理 1（余数是充分统计量）

对任意整数 $a,b$ 与正整数 $F$：$(a+b)\bmod F=\bigl((a\bmod F)+(b\bmod F)\bigr)\bmod F$。从而对任意子集 $S$，$\sigma(S)\bmod F=\bigl(\sum_{i\in S}r_i\bigr)\bmod F$。

*证明*：带余除法写 $a=q_1F+\alpha$、$b=q_2F+\beta$，$0\le\alpha,\beta<F$，则 $a\bmod F=\alpha$、$b\bmod F=\beta$。于是 $a+b=(q_1+q_2)F+(\alpha+\beta)$，两边取 $\bmod F$，整数倍 $F$ 的部分消失，得 $(a+b)\bmod F=(\alpha+\beta)\bmod F$，即所证。

对 $|S|$ 归纳：$S=\varnothing$ 时两边都是 $0$；设 $S'=S\cup\{i\}$（$i\notin S$），则 $\sigma(S')\bmod F=(\sigma(S)+R_i)\bmod F$，由上式与归纳假设 $=\bigl((\sum_{j\in S}r_j)+r_i\bigr)\bmod F=\bigl(\sum_{j\in S'}r_j\bigr)\bmod F$。证毕。

**推论**：判断"和是 $F$ 的倍数"只需要知道余数；每头牛可以先压缩成 $r_i\in[0,F)$，DP 状态只需 $F$ 个余数，与 $R_i$ 的大小无关。

---

### 引理 2（DP 不变量与转移正确性）

设处理完前 $i$ 头牛后，数组 $f$ 满足
$$f[j]\equiv\bigl|\{S\subseteq\{1..i\}:\sigma(S)\equiv j\pmod F\}\bigr|\pmod p,\qquad 0\le j<F.$$
初始（$i=0$）$f[0]=1$、其余 $0$ 满足该式。若第 $i+1$ 头牛余数为 $r$，则按"先令 $g=f$，再对每个 $j$ 做 $g[(j+r)\bmod F]\mathrel{+}=f[j]\pmod p$"得到的 $g$，对前 $i+1$ 头牛满足同一不变量。

*证明*：初始时子集只有 $\varnothing$，$\sigma(\varnothing)=0$，故余数 $0$ 计 $1$、其余计 $0$ ✓。

归纳步：把 $\{1..i+1\}$ 的子集按"是否含 $i+1$"划分成两类：

- **不含**：就是 $\{1..i\}$ 的子集，余数分布即 $f$。$g$ 初始化为 $f$ 的副本，恰好承接这一类。
- **含**：映射 $S\mapsto S\cup\{i+1\}$ 是 $\{1..i\}$ 的子集到这一类的**双射**（逆映射是删去 $i+1$）。由引理 1，$\sigma(S\cup\{i+1\})\bmod F=(\sigma(S)+r)\bmod F$，即余数 $j$ 的旧子集一一对应到余数 $(j+r)\bmod F$ 的新子集。故这一类在余数 $k$ 上的数量 $=\sum_{j:(j+r)\bmod F=k}f_{\text{真}}[j]$。由于 $j\mapsto(j+r)\bmod F$ 是 $[0,F)$ 上的**置换**（平移模 $F$，逆为减 $r$），每个 $k$ 恰有一个原像 $j=(k-r)\bmod F$，所以转移循环对每个 $j$ 恰好执行一次加法，把 $f[j]$ 加到唯一的 $g[(j+r)\bmod F]$ 上，不多不少。

两类相加即得 $g[k]\equiv f_{\text{真}}[k]+f_{\text{真}}[(k-r)\bmod F]\pmod p$，正是前 $i+1$ 头牛的真实计数。全程只有加法，逐次取模与最后取模结果相同（模运算对加法的同态性，引理 1 把 $F$ 换成 $p$ 即得）。证毕。

---

### 引理 3（原地滚动不可行：回绕反例）

试图省掉 $g$、直接在 $f$ 上按 $j=F-1,F-2,\dots,0$ 的顺序执行 $f[(j+r)\bmod F]\mathrel{+}=f[j]$，是**错误**的。

*证明*（构造反例）：取 $F=5$，两头牛余数均为 $r=3$。第一头牛处理后正确状态为 $f[0]=1,f[3]=1$，其余 $0$（子集 $\varnothing$ 与 $\{1\}$）。

第二头牛若原地倒序：

| 步骤 $j$ | 目标 $(j+3)\bmod5$ | 操作 | 结果 |
|---|---|---|---|
| $4$ | $2$ | $f[2]\mathrel{+}=f[4]=0$ | 不变 |
| $3$ | $1$ | $f[1]\mathrel{+}=f[3]=1$ | $f[1]=1$ |
| $2$ | $0$ | $f[0]\mathrel{+}=f[2]=0$ | 不变 |
| $1$ | $4$ | $f[4]\mathrel{+}=f[1]=\mathbf{1}$ | $f[4]=1$ ← **读到本轮刚写入的值** |
| $0$ | $3$ | $f[3]\mathrel{+}=f[0]=1$ | $f[3]=2$ |

得到 $f[4]=1$。但真实答案是：四个子集的和余数为 $0,3,3,1$，$f[4]$ 应为 $0$。错误根源：$j=3$ 时回绕写入 $f[1]$，而 $j=1$ 在倒序中**晚于** $j=3$ 被处理，把"已经选过第二头牛"的状态又当作源再选一次，同一头牛被用了两次。

一般地，只要 $r\ne0$，倒序中所有满足 $j+r\ge F$ 的 $j$ 都会回绕写到更小的下标，而那些下标随后还要当源读——污染不可避免（正序则反过来，未回绕的 $j+r<F$ 部分写到更大下标、随后被读，同样污染）。唯一安全做法是**源与目标分离**：读旧层 $f$、写新层 $g$。证毕。

（$r=0$ 时原地也不安全：$f[j]\mathrel{+}=f[j]$ 会把每个计数翻倍，这恰好是对的——但那是"每头 $r=0$ 的牛让方案数翻倍"的巧合，不能依赖；统一复制最稳。）

---

### 引理 4（空集修正与防负取模）

设真实答案 $A=\bigl|\{S\ne\varnothing:\sigma(S)\equiv0\pmod F\}\bigr|$，处理完全部 $N$ 头牛后的 $f[0]$ 满足 $f[0]\equiv A+1\pmod p$。则 `(f[0]-1+p)%p` 等于 $A\bmod p$。

*证明*：由引理 2，$f[0]\equiv|\{S:\sigma(S)\equiv0\}|\pmod p$。满足 $\sigma(S)\equiv0$ 的子集中，$\varnothing$ 恰好一个（$\sigma(\varnothing)=0$ 是 $F$ 的倍数），其余都非空，故该计数 $=A+1$，即 $f[0]\equiv A+1\pmod p$。

于是 $A\equiv f[0]-1\pmod p$。C++ 的 `%` 对负被除数给出负余数，而 $f[0]\in[0,p)$ 可能为 $0$（真实计数是 $p$ 的倍数时），此时 `f[0]-1=-1`。先加 $p$：$f[0]-1+p\in[p-1,2p-1)$ 恒为正，再 `%p` 得到 $[0,p)$ 内与 $A$ 同余的唯一值，即 $A\bmod p$。证毕。

---

### 引理 5（数值安全：int 不溢出、合数模无害）

全程 $f[j],g[j]\in[0,p)$，单次加法 $g[(j+r)\bmod F]+f[j]\le 2(p-1)=199999998<2^{31}-1$，`int` 不溢出。模数 $p=10^8$ 为合数，但算法只用加法与取模，不涉及除法/逆元，故不需要 $p$ 是质数。

*证明*：每次写入后立即 `%p`，故任意时刻数组元素 $\in[0,p)$；两个这样的数相加 $\le2p-2<2^{31}-1=2147483647$，`int` 加法精确。正确性只依赖"$(a+b)\bmod p=((a\bmod p)+(b\bmod p))\bmod p$"（引理 1 对 $p$ 同样成立），与 $p$ 的因子结构无关。证毕。

---

### 引理 6（复杂度）

时间 $O(NF)$，空间 $O(F)$。

*证明*：每头牛执行一次 `copy_n`（$F$ 次赋值）、一个 $F$ 次循环（每次一个加法、一个取模、一次下标计算，均 $O(1)$）、再一次 `copy_n`，合计 $O(F)$；共 $N$ 头，$O(NF)$。读入 $O(N)$ 被吸收。空间只有两个长度 $F$ 的数组与常数个变量，$O(F)$。代入 $N=2000,F=1000$：约 $2\times10^6$ 次基本操作，远低于时限。证毕。

---

### 定理

程序输出恰为"能力和是 $F$ 倍数的非空子集数"对 $10^8$ 取模的值，时间 $O(NF)$、空间 $O(F)$。

*证明*：引理 1 保证把每头牛压缩成 $r_i=R_i\bmod F$ 不丢失任何与整除性有关的信息；引理 2 用归纳法保证每处理一头牛后 $f$ 都是正确的余数计数（模 $p$），其中"复制整层"的写法由引理 3 说明是不可省略的；处理完 $N$ 头后由引理 4，`(f[0]-1+p)%p` 即非空子集答案的模 $p$ 值；引理 5 保证所有中间量在 `int` 内精确、合数模不影响加法同态；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **consider easier version** — 先想暴力枚举 $2^{2000}$ 个子集，确认死路；"每头选/不选 + 全局和约束"认出 0/1 背包计数。
2. **explore its property** — 题目只问"是否 $F$ 的倍数"，模对加法透明 ⇒ 每头牛压缩成 $R_i\bmod F$，$2\times10^8$ 的和维度塌缩成 $F$ 个余数。
3. **classic problem solution** — 余数维 0/1 背包计数：$f[j]$ 继承 + $f'[(j+r)\bmod F]\mathrel{+}=f[j]$，初始 $f[0]=1$（空集）。
4. **explore its property** — 余数下标是环形的，$(j+r)\bmod F$ 会回绕 ⇒ 经典"原地倒序"失效（$F=5,r=3$ 反例），必须双数组复制整层。
5. **reduce to easier problem** — "非空"约束不另设状态：空集是唯一和为 $0$ 的空子集，答案 $=f[0]-1$。
6. **discuss by category** — 取模后 $f[0]$ 可能为 $0$，写 `(f[0]-1+p)%p` 防负；模数 $10^8$ 是合数但只用加法，无逆元需求；两数之和 $<2^{31}$，`int` 足够。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 牛数 $N\le2000$ | `int` | 读入 |
| `F` | 幸运数字 $F\le1000$，余数维长度 | `int` | 读入 |
| `p` | 模数 $10^8$（合数，只加不除） | `constexpr int` | — |
| `mxn` | $1000+5$，余数数组尺寸 | `constexpr int` | 约束 $+5$ |
| `f[j]` | 已处理的牛中，子集和 $\equiv j\pmod F$ 的方案数（模 $p$） | `int[mxn]` | `f[0]=1`（空集），其余 $0$（全局默认恰好正确） |
| `g[j]` | 新一轮的 $f$：先复制旧层（不选），再叠加平移（选） | `int[mxn]` | 每头牛开始时 `copy_n(f,F,g)` |
| `r` | 当前牛的能力余数 $R_i\bmod F$ | `int` | 读入后立即 `r%=F`，牛本身不存 |

### 算法步骤

1. I/O 加速三行；读 `n,F`；`f[0]=1`。
2. 对每头牛：读 `r` 并 `r%=F`；`copy_n(f,F,g)` 继承"不选"；对 $j=0..F-1$ 执行 `g[(j+r)%F]=(g[(j+r)%F]+f[j])%p` 叠加"选"；`copy_n(g,F,f)` 倒手回 $f$。
3. 输出 `(f[0]-1+p)%p`（扣空集、防负）。

### 复杂度

- 时间：$O(NF)\le2\times10^6$ 次基本操作。
- 空间：$O(F)$，两个长度 $1005$ 的 `int` 数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$6$ 组手造小数据（含 $F=1$、无解、原地滚动陷阱数据）全部与手算一致；$N=2000,F=1$ 极限数据输出 `49029375`，与大整数精确计算的 $2^{2000}-1\bmod10^8$ 一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2946 [USACO09MAR] Cow Frisbee Team S
// 子集和模 F 计数：f[j]=已处理的牛中选出子集、能力和 ≡j (mod F) 的方案数（模 1e8）
// 每头牛只有 选/不选 两种决策 ⇒ 0/1 背包；余数会回绕，不能原地倒序，必须复制一份
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},p{100000000};

int n,F,f[mxn],g[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>F;
	f[0]=1;	// 空集：和为 0，余数 0，恰好贡献 1
	for(int i=0,r;i<n;++i)
	{
		cin>>r;r%=F;
		copy_n(f,F,g);	// g 先继承「不选第 i 头」
		for(int j=0;j<F;++j)
			g[(j+r)%F]=(g[(j+r)%F]+f[j])%p;	// 「选第 i 头」：余数整体平移 r
		copy_n(g,F,f);
	}
	cout<<(f[0]-1+p)%p<<'\n';	// 扣掉空集；f[0] 取模后可能为 0，先 +p 防负
	return 0;
}
```

### 代码说明

- **牛不落地存**：读入即 `r%=F`，之后只与余数打交道（引理 1），省掉 $N$ 大小的数组。
- **双数组倒手**是本题最容易写错的地方：`g` 必须先整体复制 `f`（承接"不选"），转移循环的**源永远是旧层 `f`、目标永远是新层 `g`**，这样每个旧子集恰好被"选/不选"各用一次。任何原地写法都会被回绕污染（引理 3 的反例）。
- `f[0]=1` 是把空集当种子；它最后在答案里被 `-1` 扣掉。其余 `f[j]` 依赖全局零初始化，恰好正确——这里 $0$ 就是"没有方案"，不是 INF 语义，无需 fill。
- `(f[0]-1+p)%p`：$f[0]$ 是模 $p$ 后的值，可能为 $0$，先 $+p$ 保证被除数为正（引理 4）。
- 加法中间量 $\le2\times10^8-2$，`int` 安全；模数 $10^8$ 是合数但全程无除法，不受影响（引理 5）。
