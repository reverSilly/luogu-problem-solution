# P2268 [HNOI2002] DNA 分子的最佳比对 — 题解

## 一、解题过程：人类思考叙事

题意重述：给两条 DNA 序列 $T_1,T_2$（长度不超过 $1000$，字母可能是大写或小写）。所谓比对，就是在两条序列里插入若干空白 `-`，使两行等长、逐列对齐，并且每一个位置至少有一个核苷酸（不能两行同时是空白）。每一列的得分规则是：

- 两个相同的核苷酸：$+1$；
- 两个不同的核苷酸：$0$；
- 一个核苷酸对一个空白：$-2$。

求所有比对方式中的最大得分。

最直接的想法是枚举所有比对：在第一条序列的每个缝隙决定插几个空白、在第二条序列的每个缝隙决定插几个空白，再配对。这个数量是指数级的，长度 $1000$ 完全不可能。必须找结构。

先盯着"一列"看。一列只有三种形态：$(T_1[i],T_2[j])$、$(T_1[i],-)$、$(-,T_2[j])$。并且从左往右读，第一条序列的字符是按原顺序被消耗的，第二条也是按原顺序被消耗的。也就是说，一个比对等价于一个从左到右的决策序列：每一步要么同时消耗两条序列的一个字符，要么只消耗第一条、要么只消耗第二条。既然只关心"各自消耗到哪了"，状态自然就是两个前缀长度 $(i,j)$。这就是二维 DP 的雏形。

在写 DP 之前，先试试贪心，看看"能配对相同字符就配对"行不行。取 $T_1=\text{AB}$、$T_2=\text{BA}$。唯一的相同字符对是 $T_1$ 的 A 与 $T_2$ 的 A。如果贪心把它们配上，由于 $T_2$ 的 B 在 A 前面、$T_1$ 的 B 在 A 后面，比对只能是
$$\text{A}\text{与空白},\quad \text{空白}\text{与B},\quad \text{A}\text{与A},\quad \text{B}\text{与空白},$$
得分为 $-2-2+1-2=-3$。可如果老老实实按位置对齐：A 对 B（$0$ 分）、B 对 A（$0$ 分），总分是 $0$，比 $-3$ 好得多。原因是：配对一对相同字符只赚 $1$ 分，却可能把两侧的字符各挤出一个空位、亏掉 $4$ 分。局部最优的配对并不等于全局最优，必须把"配对/插空"的决策放到一起比较，这正是 DP 要解决的问题。

把比对画成网格上的路径会更清楚：从 $(0,0)$ 出发，同时消耗两个字符就是向右下走一格（对角步），只消耗 $T_1$ 的字符就是向下走一格（竖直步），只消耗 $T_2$ 的字符就是向右走一格（水平步）。终点是 $(n,m)$。对角步的权值是"两个字符是否相同"（$1$ 或 $0$），竖直步和水平步的权值都是 $-2$。问题变成求一条从 $(0,0)$ 到 $(n,m)$ 的最大权路径。

于是设 $dp[i][j]$ 表示 $T_1$ 的前 $i$ 个字符与 $T_2$ 的前 $j$ 个字符的最大得分。转移考虑最后一列：

$$dp[i][j]=\max\begin{cases}
dp[i-1][j-1]+[T_1[i]=T_2[j]],\\
dp[i-1][j]-2,\\
dp[i][j-1]-2.
\end{cases}$$

边界是 $dp[i][0]=-2i$（第一条序列的 $i$ 个字符全部对空白），$dp[0][j]=-2j$（第二条序列全部对空白），$dp[0][0]=0$。答案是 $dp[n][m]$。

实现上有两个细节。第一，题面说序列中的字母可能是小写或大写，而得分取决于"是否是同一个核苷酸"，大小写只是书写方式，所以读入后统一转成大写再比较。第二，答案可能是负数（两条序列没有公共字符且长度不等时），DP 的初值必须严格按边界设置，不能依赖全局数组的 $0$。

长度 $1000$ 时状态数是 $10^6$，每个状态 $O(1)$ 转移，时间和空间都绰绰有余。下面把每一步的合法性补成完整证明。

## 二、思维链：完整证明

**定义 1（比对）**：把两条序列 $T_1$（长度 $n$）与 $T_2$（长度 $m$）写成两行，每行由原字符和若干空白 `-` 组成，满足：

1. 两行长度相同，设为 $L$；
2. 每一列至少有一个非空白字符；
3. 第一行删去所有空白后恰为 $T_1$，第二行删去所有空白后恰为 $T_2$。

一列的得分 $w$ 定义为：两个非空白字符相同则 $w=1$，不同则 $w=0$，恰有一个空白则 $w=-2$。比对的总得分是各列得分之和。

第 2 条排除了"两个空白"的列。即使允许这种列，它不为任何字符配对、按题意也没有定义得分；把它删除后两行仍然等长，其余各列的字符配对关系完全不变，总得分不变。所以限制"每列至少一个核苷酸"不会损失最优解，下面的所有论证都在这个规范下进行。

**引理 1（比对与路径的双射）**：所有 $T_1,T_2$ 的比对，与所有从 $(0,0)$ 到 $(n,m)$ 的、由对角步、竖直步、水平步组成的路径一一对应；并且对应前后总得分相同。

*证明*：先定义"比对 → 路径"。从左到右扫描比对的每一列，维护两个计数器 $i,j$，分别表示 $T_1,T_2$ 已经消耗的字符数。

- 若该列是 $(T_1[i+1],T_2[j+1])$，则 $i,j$ 各加 $1$，在路径上记为对角步，权值取该列的得分；
- 若该列是 $(T_1[i+1],-)$，则 $i$ 加 $1$、$j$ 不变，记为竖直步，权值 $-2$；
- 若该列是 $(-,T_2[j+1])$，则 $j$ 加 $1$、$i$ 不变，记为水平步，权值 $-2$。

由定义 1 的第 2 条，每列恰好属于这三种之一，所以每一步都有定义。由第 3 条，第一行删去空白后是 $T_1$，说明每次取出的 $T_1$ 字符依次是 $T_1[1],T_1[2],\dots$，因此 $i$ 恰好从 $0$ 增加到 $n$；同理 $j$ 从 $0$ 增加到 $m$。所以扫描完所有列后到达 $(n,m)$，得到一条合法路径，且路径权值和等于比对总得分（逐列对应）。

再定义"路径 → 比对"。从 $(0,0)$ 出发沿路径走：

- 对角步从 $(i-1,j-1)$ 到 $(i,j)$ 时，输出一列 $(T_1[i],T_2[j])$；
- 竖直步从 $(i-1,j)$ 到 $(i,j)$ 时，输出一列 $(T_1[i],-)$；
- 水平步从 $(i,j-1)$ 到 $(i,j)$ 时，输出一列 $(-,T_2[j])$。

路径的每一步都使 $i+j$ 增加 $1$，最终到达 $(n,m)$，因此输出的列数有限且两行等长；每列恰有一个或两个核苷酸，满足定义 1 的第 2 条；$T_1$ 的字符按 $i=1,2,\dots,n$ 的顺序各出现一次，$T_2$ 同理，满足第 3 条。所以得到一个合法比对，得分等于路径权值和。

最后看两个映射是否互逆。从比对出发得到路径，再从路径按上述规则输出列：原比对的第一列若是 $(T_1[1],T_2[1])$，路径第一步就是对角步，反推输出同一列；若是 $(T_1[1],-)$，反推输出 $(T_1[1],-)$；其余类型同理。对后续每一列归纳，输出序列与原比对逐列相同。反过来，从路径出发得到比对，再扫描比对恢复路径，每一步的方向与权值也逐列相同。故两映射互逆，是双射。证毕。

**引理 2（子结构可加性）**：固定 $i,j$。任取 $T_1$ 前 $i$ 个字符与 $T_2$ 前 $j$ 个字符的一个比对 $A$，以及任意一个"从 $(i,j)$ 继续到 $(n,m)$"的路径所对应的列序列 $C$。把 $A$ 的列与 $C$ 的列首尾相接，得到 $(n,m)$ 的一个合法比对，且
$$\text{score}(A+C)=\text{score}(A)+\text{score}(C).$$
此外，$C$ 的得分只由 $i,j$ 与两条序列的剩余后缀决定，与 $A$ 的内部结构无关。

*证明*：$A$ 消耗完 $T_1[1..i]$ 与 $T_2[1..j]$，$C$ 从第 $i+1$ 个、第 $j+1$ 个字符开始继续消耗；拼接后第一行的非空白字符依次是 $T_1[1..i]$ 再接 $T_1[i+1..n]$，即整个 $T_1$，第二行同理。每列至少一个核苷酸，两行等长，所以拼接结果是合法比对。总得分是各列得分之和，而列被分成互不相交的两段，故等于两段得分相加。$C$ 的每一列只涉及 $T_1[i+1..n]$ 与 $T_2[j+1..m]$，其可行性（字符是否还剩）与 $A$ 无关，所以 $C$ 的可选集合与得分都只依赖 $i,j$ 和后缀。证毕。

引理 2 说明：如果某个前缀比对 $A$ 的得分低于同一 $(i,j)$ 下的最优前缀比对 $A^\ast$，那么对任意 $C$，$A+C$ 的得分都低于 $A^\ast+C$；因此要求全局最优，前缀部分一定可以取到该子问题的最优值。这就是最优子结构。

**引理 3（转移方程）**：设 $F(i,j)$ 为 $T_1$ 前 $i$ 个字符与 $T_2$ 前 $j$ 个字符的最大比对得分。对 $i\ge1,j\ge1$，有
$$F(i,j)=\max\Big(F(i-1,j-1)+[T_1[i]=T_2[j]],\ F(i-1,j)-2,\ F(i,j-1)-2\Big).$$

*证明*：分上界与可达性两边。

（上界）取 $(i,j)$ 的一个最优比对 $A$。因为 $i,j\ge1$，两条序列都还有字符，$A$ 至少有一列，考虑它的最后一列。由定义 1，最后一列属于且仅属于以下三种情况：

- 最后一列是 $(T_1[i],T_2[j])$。删掉这一列，剩下的列对齐的是 $T_1[1..i-1]$ 与 $T_2[1..j-1]$，是一个合法比对（两行仍等长，每列仍至少一个核苷酸，删去后各行剩余字符仍是相应前缀）。它的得分是 $F(i,j)-[T_1[i]=T_2[j]]$，而 $F(i-1,j-1)$ 是该子问题的最优值，故 $F(i-1,j-1)\ge F(i,j)-[T_1[i]=T_2[j]]$，即
  $$F(i,j)\le F(i-1,j-1)+[T_1[i]=T_2[j]].$$
- 最后一列是 $(T_1[i],-)$。删掉它，剩下的是 $T_1[1..i-1]$ 与 $T_2[1..j]$ 的比对，得分 $F(i,j)+2$，故 $F(i-1,j)\ge F(i,j)+2$，即 $F(i,j)\le F(i-1,j)-2$。
- 最后一列是 $(-,T_2[j])$。同理 $F(i,j)\le F(i,j-1)-2$。

最后一列必然是三者之一，所以 $F(i,j)$ 不超过三个候选值的最大值。

（可达性）对三个候选分别构造：

- 取 $(i-1,j-1)$ 的最优比对，在末尾追加一列 $(T_1[i],T_2[j])$。追加后第一行多消耗 $T_1[i]$、第二行多消耗 $T_2[j]$，正好对齐两个前缀，列数增加一，合法；得分增加 $[T_1[i]=T_2[j]]$。所以 $F(i,j)\ge F(i-1,j-1)+[T_1[i]=T_2[j]]$。
- 取 $(i-1,j)$ 的最优比对，在末尾追加 $(T_1[i],-)$，合法且得分减 $2$，所以 $F(i,j)\ge F(i-1,j)-2$。
- 取 $(i,j-1)$ 的最优比对，在末尾追加 $(-,T_2[j])$，合法且得分减 $2$，所以 $F(i,j)\ge F(i,j-1)-2$。

上下界相同，转移方程成立。证毕。

**引理 4（边界）**：$F(0,0)=0$；对 $i\ge1$，$F(i,0)=-2i$；对 $j\ge1$，$F(0,j)=-2j$。

*证明*：对齐 $T_1$ 的前 $i$ 个字符与空序列时，$T_2$ 没有任何字符可以配对，每一列只能是 $(T_1[k],-)$，共 $i$ 列，每列 $-2$，总分 $-2i$；且这是唯一可能的比对，所以它也是最大值。$j$ 方向对称。$i=j=0$ 时没有任何列，得分 $0$。证毕。

**引理 5（DP 正确性）**：按 $i$ 从小到大、$j$ 从小到大填表，程序算出的 $dp[i][j]$ 满足 $dp[i][j]=F(i,j)$，因此 $dp[n][m]$ 是所求最大得分。

*证明*：对 $i+j$ 做归纳。

- 基础：$i=0$ 或 $j=0$ 时，程序按引理 4 显式赋值，等于 $F(i,j)$。
- 归纳步：设 $i\ge1,j\ge1$，且所有 $i'+j'<i+j$ 的状态都已正确。引理 3 给出了 $F(i,j)$ 只依赖 $F(i-1,j-1),F(i-1,j),F(i,j-1)$ 的等式，这三个下标的和都是 $i+j-2$ 或 $i+j-1$，小于 $i+j$，由归纳假设它们在程序中已经等于对应的 $F$ 值。程序对这三个值取最大值再加/减相应权值，得到的正是 $F(i,j)$。

由归纳原理，所有状态都正确，答案 $dp[n][m]=F(n,m)$ 正确。证毕。

**引理 6（大小写处理）**：读入后把两条序列都转成大写再比较，不改变"两个字符是否表示同一个核苷酸"这一判断。

*证明*：题面说明序列中的字母可能是英文小写或大写，而 DNA 的核苷酸只有 A、T、C、G 四种，大小写只是书写方式。对英文字母 $x,y$，`toupper(x)=toupper(y)` 当且仅当 $x=y$ 或 $x,y$ 是同一个字母的两种大小写写法。因此转大写后的相等关系正是"同一个核苷酸"。证毕。

**定理**：程序输出 $T_1,T_2$ 的最大比对得分。

*证明*：由引理 1，比对与三类步路径一一对应且得分相同，所以最大比对得分等于最大权路径的权值；由引理 5，DP 求出的 $dp[n][m]$ 正是最大权路径的权值；由引理 6，大小写归一不改变字符相等的判断。三者结合，输出即所求。证毕。

**引理 7（复杂度）**：时间复杂度 $O(nm)$，空间复杂度 $O(nm)$。

*证明*：状态数为 $(n+1)(m+1)$，每个状态做常数次加法、比较与取最大值，故时间 $O(nm)$。程序使用 $(n+1)\times(m+1)$ 的 `int` 表，故空间 $O(nm)$。在 $n,m\le1000$ 时状态数不超过 $10^6$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 比对的每一列只有"配一对 / 第一条对空 / 第二条对空"三种形态，字符按原顺序被消耗。
- **find counterexample** — 贪心优先配对相同字符在 `AB` 与 `BA` 上得到 $-3$，而按位置对齐得 $0$，否定了局部贪心。
- **reduce to easier problem** — 比对 ↔ 从 $(0,0)$ 到 $(n,m)$ 的三类步最大权路径。
- **classic problem solution** — 前缀二维 DP（序列比对 / 编辑距离骨架），状态只记两条序列各消耗了多少前缀。
- **discuss by category** — 最后一列分三类，分别从三个子状态转移，取最大值。
- **boundary** — 第一行、第一列只能一路加空位，初值为 $-2i$、$-2j$，不能用全局零初始化冒充。
- **prove optimal substructure** — 拼接的列序列得分可加，且后续可选集合只依赖剩余后缀，所以前缀可以取最优。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初始化 / 记忆点 |
|------|------|------|----------------|
| $T_1,T_2$ | 两条 DNA 序列，已统一转大写 | `string` | 输入后逐字符 `toupper` |
| $n,m$ | 两条序列的长度 | `int` | $n=T_1.\text{size}()$，$m=T_2.\text{size}()$ |
| $dp[i][j]$ | $T_1$ 前 $i$ 个字符与 $T_2$ 前 $j$ 个字符的最大得分 | `int[1005][1005]` | $dp[0][0]=0$；$dp[i][0]=-2i$；$dp[0][j]=-2j$；内部按转移式填 |
| $[P]$ | 艾弗森括号，条件真为 $1$、假为 $0$ | 记号 | 用于"相同 $+1$、不同 $+0$" |

### 算法步骤

1. 读入两行字符串 $T_1,T_2$，逐字符转成大写。
2. 令 $n=|T_1|$、$m=|T_2|$，把 $dp[0][0]$ 置 $0$。
3. 对 $i=1..n$：置 $dp[i][0]=dp[i-1][0]-2$；对 $j=1..m$：置 $dp[0][j]=dp[0][j-1]-2$。
4. 对 $i=1..n$，对 $j=1..m$：
   1. $v_1=dp[i-1][j-1]+(T_1[i-1]=T_2[j-1]\ ?\ 1:0)$；
   2. $v_2=dp[i-1][j]-2$；
   3. $v_3=dp[i][j-1]-2$；
   4. $dp[i][j]=\max(v_1,v_2,v_3)$。
5. 输出 $dp[n][m]$。

### 复杂度

- 时间复杂度：$O(nm)$，$n,m\le1000$，状态数不超过 $10^6$。
- 空间复杂度：$O(nm)$，即 $1005\times1005$ 的 `int` 表（约 $4$ MB）。

### 验证状态

编译通过（`g++ -std=c++20 -O2`）；题面示例 $T_1=\text{ATCAG},T_2=\text{ACTAG}$ 输出 $3$（与题面"比对二得 $3$ 分"一致），`AB`/`BA` 输出 $0$、两条相同长度 $1000$ 的序列输出 $1000$；另与"枚举两条序列所有插空排列、逐列计分"的独立暴力在 $200$ 组长度不超过 $5$ 的随机数据上对拍，结果全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2268 [HNOI2002] DNA 分子的最佳比对
// dp[i][j]：T1 前 i 个字符与 T2 前 j 个字符的最大得分
// 最后一列三种情况：配对 / T1 对空 / T2 对空
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

string t1,t2;
int dp[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>t1>>t2;
	for(char&c:t1)
		c=toupper((unsigned char)c);
	for(char&c:t2)
		c=toupper((unsigned char)c);
	int n=t1.size(),m=t2.size();
	for(int i=1;i<=n;++i)              // 只能一路对空位
		dp[i][0]=dp[i-1][0]-2;
	for(int j=1;j<=m;++j)
		dp[0][j]=dp[0][j-1]-2;
	for(int i=1;i<=n;++i)
		for(int j=1;j<=m;++j)
		{
			int best=max(dp[i-1][j],dp[i][j-1])-2;
			best=max(best,dp[i-1][j-1]+(t1[i-1]==t2[j-1]?1:0));
			dp[i][j]=best;
		}
	cout<<dp[n][m]<<'\n';
	return 0;
}
```
