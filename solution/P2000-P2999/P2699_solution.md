# P2699 【数学 1】小浩的幂次运算 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一行三个整数 $l,r,w$（$1\le l\le r\le 10^{18}$，$1\le w\le 10^9$）。输出所有满足 $l\le w^i\le r$ 的数 $w^i$，空格分开；一个都没有则输出 $-1$。题面没有样例，下面的例子全部手造手算。

**第零步：先把 $i$ 的范围定下来。** 题面只写"所有 $w^i$"，没有限定 $i$。按幂次运算的自然约定，$i$ 取**非负整数**：$w^0=1,w^1=w,w^2,\dots$（负指数产生分数，不在"整数数字"的输出语境里）。这个约定有一个可观测的后果：$l=1$ 时 $1$ 必须被输出。本文按 $i\ge0$ 处理。

**第一反应：直接枚举。** $i=0,1,2,\dots$ 逐个算 $w^i$，落在 $[l,r]$ 里就输出。要枚举多少项？$w\ge2$ 时幂次至少翻倍增长，而 $2^{60}=1152921504606846976>10^{18}\ge r$，所以不超过 $60$ 项——规模小到可以忽略。这题的难点完全不在算法，而在**两个会让程序直接炸掉的坑**。

**坑一：$w=1$，死循环。** $1^i$ 永远是 $1$。如果 $l\le1\le r$，枚举循环会无限输出 $1$；即使 $1\notin[l,r]$，`cur*=w` 也永远不增长，循环条件永真，照样死循环。必须特判：$w=1$ 时幂的**值集**只有 $\{1\}$，若 $1\in[l,r]$ 输出一个 `1`，否则输出 `-1`。（输出的是"满足条件的数字"，无穷多个相同的 $1$ 作为数字只有一个。）由于 $l\ge1$，"$1\in[l,r]$"其实就是 $l=1$。

**坑二：乘法溢出。** 兴冲冲写下 `cur*=w` 之后算一下上界：`cur` 最大 $10^{18}$，$w$ 最大 $10^9$，乘积最大 $10^{27}$，而 `long long` 上限是 $9.22\times10^{18}$——**超了八个数量级**。具体反例：$l=1,r=10^{18},w=10^9$，幂序列是 $1,10^9,10^{18},10^{27},\dots$，第四项一乘就溢出。有符号溢出是未定义行为：实测中它通常回绕成负数，于是 `cur<=r` 永真，程序开始输出负数垃圾甚至死循环。**必须在乘之前判断"再乘会不会超过 $r$"**。

**怎么判？把乘法换成除法。** 我要的条件是 $cur\cdot w\le r$。两边除以 $w$（正数，不等号方向不变）得 $cur\le r/w$；但 C++ 的 `r/w` 是**向下取整**的整数除法，而 $cur$ 是整数，所以

$$cur\cdot w\le r\iff cur\le\lfloor r/w\rfloor\iff\texttt{cur<=r/w}.$$

（这个等价性下面引理 3 严格证。）于是循环体末尾写 `if(cur>r/w)break; cur*=w;`：一旦下一个幂会超过 $r$ 就停，**每次真正执行的乘法都保证结果 $\le r\le10^{18}$**，全程不碰溢出。另一条路是用 `__int128` 存 `cur`（中间量 $\le10^{27}<1.7\times10^{38}$，也安全），但除法守卫连 128 位都不需要，更干净。

**第三个容易漏的点：$w^0=1$。** 循环必须从 `cur=1` 起步而不是 `cur=w`，否则 $l=1$ 的数据会漏掉 $1$。还有输出格式：数字之间空格分开（我用"输出过一个数之后，再输出前先打空格"的写法，避免行尾多余空格）；一个都没输出过就补 `-1`。

**顺序需要排序吗？** 不需要。$w\ge2$ 时 $w^{i+1}=w\cdot w^i\ge2w^i>w^i$，幂序列严格递增，枚举顺序天然就是升序，且无重复。$w=1$ 已特判。

**手造数据核对**（全部手算）：

| 输入 `l r w` | 输出 | 打的点 |
|---|---|---|
| `1 100 2` | `1 2 4 8 16 32 64` | 常规；含 $w^0=1$ |
| `10 100 3` | `27 81` | 两端都过滤 |
| `5 5 2` | `-1` | 无解 |
| `1 1 1` | `1` | $w=1$ 且命中 |
| `2 100 1` | `-1` | $w=1$ 不命中（死循环坑） |
| `1 1000000000000000000 1000000000` | `1 1000000000 1000000000000000000` | $10^{27}$ 溢出坑：第四项必须被守卫拦下 |
| `1000000000000000000 1000000000000000000 1000000000` | `1000000000000000000` | $l=r$ 恰好命中幂 |
| `999999999999999999 1000000000000000000 2` | `-1` | $2^{59}\approx5.76\times10^{17}<l$，$2^{60}\approx1.15\times10^{18}>r$，夹缝无解 |
| `1 5 10` | `1` | $w>r$：只有 $w^0$ 合法 |
| `1 1000000000000000000 2` | $60$ 个数，末项 `576460752303423488` | $2^0..2^{59}$ 全枚举，项数上界 |

程序输出与手算逐条一致。

## 二、思维链：完整证明

**记号。** 输入整数 $l,r,w$ 满足 $1\le l\le r\le10^{18}$，$1\le w\le10^9$。幂序列 $p_i=w^i$（$i\in\mathbb Z_{\ge0}$，$p_0=1$）。目标值集 $P=\{p_i:i\ge0\}\cap[l,r]$，按升序输出，$P=\varnothing$ 时输出 $-1$。`i64` 为 64 位有符号整数，上限 $2^{63}-1=9223372036854775807\approx9.22\times10^{18}$。

---

### 引理 1（$w=1$ 的完全刻画）

$w=1$ 时：$P=\{1\}$ 当且仅当 $l\le1\le r$，否则 $P=\varnothing$。程序输出 `1` 或 `-1` 后终止。

*证明*：对一切 $i\ge0$，$1^i=1$（归纳：$1^0=1$；$1^{i+1}=1\cdot1^i=1$）。故 $\{p_i\}$ 作为值集是 $\{1\}$，$P=\{1\}\cap[l,r]$，非空当且仅当 $l\le1\le r$。又 $l\ge1$，故 $l\le1\iff l=1$；此时 $r\ge l=1$ 自动成立，条件简化为 $l=1$。程序的特判分支 `cout<<(l<=1&&1<=r?"1":"-1")` 与此逐字对应，且不含循环，必然终止。证毕。

**为什么必须特判而不能靠循环自然结束**：$w=1$ 时 `cur*=w` 不改变 `cur`，守卫 `cur>r/w` 即 `cur>r` 与循环条件 `cur<=r` 互补——若 $1\le r$ 则守卫永假、循环永真，死循环。引理 1 把这个退化情形从枚举中剥离，是算法终止性的前提。

---

### 引理 2（$w\ge2$：项数上界与终止性）

$w\ge2$ 时 $p_i\ge2^i$；满足 $p_i\le r$ 的 $i$ 至多 $59$，即合法幂至多 $60$ 个。枚举循环至多执行 $60$ 次。

*证明*：$p_i=w^i\ge2^i$（底数越大幂越大，对 $i$ 归纳：$i=0$ 两边都是 $1$；$w^{i+1}=w\cdot w^i\ge2\cdot2^i=2^{i+1}$）。而 $2^{60}=(2^{10})^6=1024^6>1000^6=10^{18}\ge r$，故 $p_i\le r\Rightarrow2^i<2^{60}\Rightarrow i\le59$。

循环终止性：每次迭代末尾要么 `break`，要么执行 `cur*=w`；后者使 `cur` 至少翻倍（$w\ge2$，$cur\ge1$），严格递增。`cur` 是整数且守卫保证 `cur`$\le r$（引理 3），严格递增的有界整数序列必在有限步内触发守卫 `cur>r/w` 而 `break`。迭代次数等于枚举到的幂个数 $\le60$。证毕。

---

### 引理 3（除法守卫 $\iff$ 乘法不越界，核心）

对正整数 $cur,r,w$：
$$cur\cdot w\le r\iff cur\le\lfloor r/w\rfloor.$$
因此代码 `if(cur>r/w)break; cur*=w;` 保证：(a) 每次执行的乘法结果 $\le r$，绝不溢出；(b) 恰好枚举完所有 $\le r$ 的幂，不漏不多。

*证明*：等价性双向证。

（$\Leftarrow$）设 $cur\le\lfloor r/w\rfloor$。两边乘正数 $w$：$cur\cdot w\le\lfloor r/w\rfloor\cdot w$。又由向下取整定义 $\lfloor r/w\rfloor\le r/w$，乘 $w$ 得 $\lfloor r/w\rfloor\cdot w\le r$。传递得 $cur\cdot w\le r$。

（$\Rightarrow$）设 $cur\cdot w\le r$。除以正数 $w$：$cur\le r/w$。$cur$ 是整数，不超过实数 $r/w$ 的最大整数就是 $\lfloor r/w\rfloor$，故 $cur\le\lfloor r/w\rfloor$。

C++ 中 `r/w` 对正整数恰好计算 $\lfloor r/w\rfloor$，所以 `cur>r/w` 为真 $\iff cur\cdot w>r$。

(a) 乘法只在 `cur<=r/w` 时执行，由等价性结果 $\le r\le10^{18}<2^{63}-1$，`i64` 表示精确，无溢出、无未定义行为。

(b) 循环不变量：第 $i$ 次迭代开始时 `cur`$=p_i$（初始 `cur=1`$=p_0$ ✓；每轮末尾 `cur*=w` 使 $p_i\to p_{i+1}$ ✓）。循环在 `cur`$=p_i$ 时检查守卫：若 $p_{i+1}=p_i\cdot w>r$ 则 `break`，此后所有幂 $p_{i+1},p_{i+2},\dots$ 都 $>r$（引理 2 的严格递增性：$w\ge2$ 时幂序列递增，一旦超过 $r$ 不会再回来），停止不漏；若 $p_{i+1}\le r$ 则继续，不多停。又进入循环体时 `cur`$\le r$ 恒成立（初始 $1\le r$；乘法后 $\le r$），故循环条件 `cur<=r` 与守卫一致，枚举的恰是 $\{p_i:p_i\le r\}$ 全体。证毕。

**对比 `__int128` 路线**：直接用 128 位存 `cur`，乘积上界 $r\cdot w\le10^{27}<2^{127}-1\approx1.7\times10^{38}$，也安全，且不需要守卫等价性。两条路线都正确；本文选除法守卫，因为它把全部运算留在 `i64` 内，代价只是每轮一次除法（$\le60$ 次，可忽略）。

---

### 引理 4（过滤、升序、无重复）

$w\ge2$ 时幂序列严格递增：$p_{i+1}>p_i$。因此算法输出的数恰为 $P$ 中元素按升序排列，无重复。

*证明*：$p_{i+1}=w\cdot p_i\ge2p_i=p_i+p_i>p_i$（$p_i\ge1>0$）。严格递增 $\Rightarrow$ 各幂互不相同 $\Rightarrow$ 枚举顺序即数值升序。算法对每个枚举到的 $p_i\le r$ 检查 `cur>=l`，通过才输出，故输出集合 $=\{p_i:p_i\le r\}\cap[l,+\infty)=P$，顺序保持升序。证毕。

---

### 引理 5（输出格式与 $-1$ 判定）

设算法输出过的数字依次为 $q_1<q_2<\dots<q_k$。则打印的字节串为：$k\ge1$ 时 `q1 q2 ... qk`（单个空格分隔，无行尾空格）加换行；$k=0$ 时 `-1` 加换行。且 $k=0\iff P=\varnothing$。

*证明*：`any` 初值 `false`；每次输出前若 `any` 为真先打一个空格，输出后置 `any=true`。故第一个数前无空格，之后每个数前恰一个空格，行尾无空格。循环结束后 `any` 为假当且仅当一次都没输出，此时补打 `-1`。由引理 3(b)、引理 4，输出过的数恰为 $P$ 的全部元素，故 $k=|P|$，$k=0\iff P=\varnothing$。$w=1$ 分支由引理 1 直接给出 `1` 或 `-1`，格式一致。证毕。

---

### 引理 6（值域安全清单）

算法中所有 `i64` 中间量均不超过 $10^{18}$（或为合法的小整数），无溢出。

*证明*：逐项清点。输入 $l,r\le10^{18}$、$w\le10^9$：读入即在范围内。`cur`：由引理 3(a) 恒 $\le r\le10^{18}$。`r/w`：$\le r\le10^{18}$，且 $w\ge1$ 除法合法（$w=1$ 已特判，实际进入循环时 $w\ge2$）。`cur*w`：仅在 $\le r$ 时计算。比较与输出：均为范围内整数的直接操作。唯一可能越界的量 $10^{27}$ 被守卫**在计算之前**排除，从未真正出现。证毕。

---

### 定理

程序按升序输出所有满足 $l\le w^i\le r$（$i\ge0$）的数，无解输出 $-1$；时间 $O(\log_w r+1)\le61$ 次迭代，空间 $O(1)$。

*证明*：$w=1$ 由引理 1 完全刻画；$w\ge2$ 时引理 2 保证枚举有限且终止，引理 3 保证枚举恰好覆盖所有 $\le r$ 的幂且全程无溢出，引理 4 保证过滤后升序无重复，引理 5 保证输出格式与 $-1$ 语义，引理 6 保证值域安全。迭代次数 $\le60$（引理 2），每次 $O(1)$ 次算术与至多一次输出，输出总字符数 $\le60\times19$；空间只有常数个 `i64` 与一个 `bool`。证毕。

---

## 三、模式总结（按实际思考顺序）

- **explore its property** — 幂序列指数增长：$w\ge2$ 时 $\le r\le10^{18}$ 的幂至多 $60$ 个 ⇒ 直接枚举，算法本身是平凡的。
- **discuss by category** — $w=1$ 退化为常数列：不特判就死循环；值集只有 $\{1\}$，命中输出一个 `1`，否则 `-1`。
- **explore its property** — 溢出上界计算：$cur\cdot w\le10^{18}\times10^9=10^{27}\gg$ `i64` 上限，`cur*=w` 必须在乘之前拦截。
- **reduce to easier problem** — "乘积会不会越界"归约成整数除法比较：$cur\cdot w\le r\iff cur\le\lfloor r/w\rfloor$，一行守卫解决。
- **classic problem solution** — 循环不变量枚举（`cur`$=w^i$）+ 区间过滤输出；严格递增保证升序无重复，`any` 标记处理分隔符与 `-1`。
- **discuss by category** — 边界逐类核对：$w^0=1$ 要不要输出（$i\ge0$ 约定）、$w>r$ 只剩 $1$、$l=r$ 恰命中、$2^{59}$ 与 $2^{60}$ 夹缝无解。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `l,r` | 目标区间端点，$1\le l\le r\le10^{18}$ | `i64`，读入 | 全程 `long long` |
| `w` | 底数，$1\le w\le10^9$ | `i64`，读入 | $w=1$ 必须特判 |
| `cur` | 当前枚举到的幂 $w^i$ | `i64`，初值 $1$ | 从 $w^0=1$ 起步；恒 $\le r$ |
| `any` | 是否已经输出过至少一个数 | `bool`，初值 `false` | 控制分隔空格与末尾 `-1` |
| `r/w` | 守卫阈值 $\lfloor r/w\rfloor$ | 每轮现算 | `cur>r/w` $\iff$ 下一幂 $>r$ |

### 算法步骤

1. I/O 加速三行；读入 `l,r,w`。
2. 若 `w==1`：输出 `l<=1&&1<=r?"1":"-1"`，结束（引理 1）。
3. `any=false`；循环 `cur=1` 起：
   1. 若 `cur>=l`：按需打空格，输出 `cur`，`any=true`（此时 `cur<=r` 由不变量保证）；
   2. 若 `cur>r/w`：`break`（下一个幂越界，引理 3）；
   3. `cur*=w`（结果保证 $\le r$，无溢出）。
4. 若 `!any` 输出 `-1`；输出换行。

### 复杂度

- 时间：$O(\log_w r+1)$，最坏 $w=2$ 时 $60$ 次迭代，每次 $O(1)$。
- 空间：$O(1)$，常数个 64 位变量。
- 验证状态：`g++ -std=c++20 -O2 -Wall -Wextra` 编译零警告；$13$ 组手造数据（含 $w=1$ 两态、$10^{27}$ 溢出边界、$l=r$、$2^{59}/2^{60}$ 夹缝、$w>r$）与手算逐条一致；$w=2,r=10^{18}$ 全枚举恰 $60$ 项、末项 $2^{59}=576460752303423488$，$w=3$ 恰 $38$ 项，均核对无误。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2699 【数学 1】小浩的幂次运算
// 枚举 w^0,w^1,...；w=1 特判（否则死循环）；乘法前用 cur>r/w 防溢出
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 l,r,w;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>l>>r>>w;
	if(w==1)	// 1 的任何次幂都是 1，枚举循环永不终止
	{
		cout<<(l<=1&&1<=r?"1":"-1")<<'\n';
		return 0;
	}
	bool any=false;
	for(i64 cur=1;cur<=r;)
	{
		if(cur>=l)
		{
			if(any)cout<<' ';
			cout<<cur;
			any=true;
		}
		if(cur>r/w)break;	// 等价于 cur*w>r：下一个幂越界，且再乘会溢出
		cur*=w;
	}
	if(!any)cout<<-1;
	cout<<'\n';
	return 0;
}
```

### 代码说明

- **`cur` 从 $1$ 起步**：$w^0=1$ 是合法幂，$l=1$ 时必须输出它；从 `cur=w` 起步是本题最常见的漏项错误。
- **守卫在乘法之前**：`if(cur>r/w)break;` 利用引理 3 的等价性，把"乘积是否越界"变成不溢出的除法比较。若写成先 `cur*=w` 再判断，溢出已经发生（有符号溢出是 UB），判断本身都不可靠。
- **循环条件 `cur<=r` 是双保险**：守卫已保证乘法后 `cur<=r`，条件永真，终止完全靠 `break`；保留它让"只枚举 $\le r$ 的幂"这一不变量在代码上自明。
- **`w==1` 分支里 `l<=1&&1<=r`**：按题面 $l\ge1$ 其实等价于 `l==1`，写成区间判断更贴合题意、也不依赖下界约定。
- **`any` 标记**：第一个数前不打空格、之后每个数前打一个，行尾无多余空格；全程没输出过则补 `-1`（引理 5）。
- 全程 `i64`：$10^{18}$ 远超 `int`；唯一的 $10^{27}$ 级中间量被守卫在计算前排除，不需要 `__int128`。
