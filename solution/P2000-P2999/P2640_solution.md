# P2640 神秘磁石 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给一个长度不超过 $n$ 的一维坐标系（坐标是 $1\sim n$ 的整数），两条规则：

1. 磁石只有放在**素数坐标**上磁力才最大（且所有素数坐标的磁力一样大，与坐标数值无关）；
2. 两块磁石**相距恰好 $k$** 时，破坏力达到当前磁力的峰值。

问：哪些坐标对的破坏力最大？输出所有 $\le n$ 的"素数对"，每对一行、空格隔开；一对都没有就输出 `empty`。数据范围 $1\le k\le n\le 10^4$。

**第一步：把"破坏力最大"翻译成数学条件。** 题面说"最大破坏力取决于磁力大小和磁石间距"。要让破坏力最大，就得让两个因子都取到最大：

- 磁力最大 $\Rightarrow$ 两块磁石**都**在素数坐标上（规则 1）；
- 间距取到峰值条件 $\Rightarrow$ 两坐标之差**恰好**为 $k$（规则 2）。

所以答案就是：所有满足 $p<q\le n$、$p$ 与 $q$ 都是素数、$q-p=k$ 的坐标对 $(p,q)$。换句话说，枚举较小的素数 $p$，检查 $p$ 和 $p+k$ 是否都是素数且 $p+k\le n$。这一步是整题的支点——题目背景很花哨，但落到数学上就是"差为 $k$ 的素数对"。

**第二步：先想暴力，再确认范围。** 最朴素的写法是：对每个 $p$ 用试除法判 $p$ 和 $p+k$ 是否素数，$O(n\sqrt n)$。$n=10^4$ 时约 $10^4\times100=10^6$ 次取模，其实也能过。但既然要判 $n$ 以内所有数的素性，**埃氏筛**一次 $O(n\log\log n)$ 把整张素数表打出来，之后每次查询 $O(1)$，更干净也更快。标签里写着"模拟、搜索、数学"，筛法正是那个"数学"。

**第三步：一个能帮我验算的隐蔽性质——奇偶性。** 我停下来想：$k$ 是奇数会怎样？若 $k$ 为奇数，则 $p$ 与 $p+k$ **奇偶性相反**，两个都是素数就必须有一个是偶素数。唯一的偶素数是 $2$。因为 $p<p+k$ 且 $p\ge2$，偶的那个只能是 $p=2$（$p+k=2$ 不可能，$k\ge1$）。于是：

> **$k$ 为奇数时，唯一可能的素数对是 $(2,\,2+k)$，且仅当 $2+k$ 也是素数才成立。**

比如 $k=1$：只有 $(2,3)$；$k=3$：$(2,5)$；$k=5$：$(2,7)$；$k=7$：$(2,9)$，$9$ 不是素数 $\Rightarrow$ `empty`。这条性质不是算法必需的（筛法自动处理了），但它给了我一个**独立的手算校验**：跑 $k$ 为奇数的数据时，答案要么空、要么只有一行 `2 (2+k)`。若程序输出了别的，立刻知道错了。

$k$ 为偶数时就是"孪生素数"那类（$k=2$ 是孪生素数，$k=4$ 是表兄弟素数……），可能有多个 pair，按 $p$ 升序输出。

**第四步：输出顺序与去重。** 题面没明说顺序，但"所有素数对"最自然的呈现是**按较小元素 $p$ 升序**，每对写成 `p p+k`（小的在前）。我让 $p$ 从 $2$ 递增枚举，每个合法 pair 恰好被输出一次——因为 pair 由它的较小元素 $p$ 唯一确定，不会重复也不会遗漏。

**第五步：`empty` 的判定。** 用一个 `found` 标志，枚举过程中只要输出过任何一对就置真；循环结束仍为假就输出 `empty`。注意 $n$ 很小（如 $n=1,2$）或 $k$ 很大时经常一对都没有，这条分支必须写对。

**手造数据核对**（题面无样例，我按规则自己造）：

| 输入 | 分析 | 输出 |
|---|---|---|
| `10 2` | 差 2 的素数对：$(3,5),(5,7)$；$(2,4)$ 中 4 非素数 | `3 5` / `5 7` |
| `5 2` | 只有 $(3,5)$ | `3 5` |
| `10 1` | $k$ 奇，只有 $(2,3)$ | `2 3` |
| `20 4` | $(3,7),(7,11),(13,17)$ | `3 7` / `7 11` / `13 17` |
| `2 1` | $\le2$ 只有素数 2，凑不成对 | `empty` |
| `1 1` | 没有素数 | `empty` |

这些把"偶数 $k$ 多对""奇数 $k$ 单对""无解 empty""极小 $n$"全覆盖了。

## 二、思维链：完整证明

**记号。** 坐标取值 $1\le x\le n$。$\mathbb P$ 为素数集合。`np[x]` 为筛法的标记数组，`np[x]=true` 表示 $x$ **不是**素数。称 $(p,q)$ 为**合法对**当且仅当 $p,q\in\mathbb P$、$p<q\le n$、$q-p=k$。

---

### 引理 1（"破坏力最大" $\iff$ 差为 $k$ 的素数对）

坐标对 $(p,q)$（$p<q\le n$）使破坏力最大，当且仅当 $p,q$ 都是素数且 $q-p=k$。

*证明*：题面给出破坏力由两个因子决定：磁力大小、磁石间距。

- 由规则 1，单块磁石的磁力在素数坐标取最大值，在非素数坐标严格更小；且所有素数坐标磁力相等。故"两块磁石的磁力都最大" $\iff$ $p\in\mathbb P$ 且 $q\in\mathbb P$。
- 由规则 2，间距为 $k$ 时破坏力达到"当前磁力的峰值"，即间距因子取到最大。故间距条件为 $q-p=k$。

两因子相互独立且都要取最大，合起来即 $p,q\in\mathbb P\land q-p=k$。反之，满足此条件的对，两因子都最大，破坏力最大。证毕。

**推论**：答案集合 $=\{(p,p+k):p\in\mathbb P,\ p+k\in\mathbb P,\ p+k\le n\}$，每个 pair 由较小元素 $p$ 唯一确定。

---

### 引理 2（埃氏筛正确性）

执行 `np[0]=np[1]=true`；对 $i=2,3,\dots$ 直到 $i^2>n$，若 `!np[i]` 则把所有 $j=i^2,i^2+i,\dots\le n$ 标记 `np[j]=true`。则结束后对任意 $2\le x\le n$：`np[x]=false` $\iff$ $x$ 是素数。

*证明*：分两个方向。

**（合数必被标记）** 设 $x\le n$ 是合数，令 $r$ 为 $x$ 的**最小素因子**，则 $r\le\sqrt x\le\sqrt n$，且 $x=r\cdot(x/r)$ 其中 $x/r\ge r$。外层循环会枚举到 $i=r$（因 $r\le\sqrt n$ 即 $r^2\le n$）。此时 `np[r]` 是否为假？$r$ 是素数，它不会被任何更小的 $i'$ 标记（$r$ 没有 $\le\sqrt r$ 的素因子），故轮到 $i=r$ 时 `np[r]=false`，进入内层。内层从 $r^2$ 开始、步长 $r$ 标记所有 $r$ 的倍数；$x=r\cdot(x/r)$ 是 $r$ 的倍数且 $x\ge r^2$（因 $x/r\ge r$），故 $x$ 落在内层标记范围内，被置 `np[x]=true`。

**（素数永不被标记）** 设 $x$ 是素数。内层只标记形如 $i\cdot t$（$t\ge i\ge2$）的合数，素数 $x$ 不能写成两个 $\ge2$ 整数之积，故永远不会被任何内层循环标记。`np[x]` 保持初值 `false`。

**（边界 0,1）** 显式置 `np[0]=np[1]=true`，与"$0,1$ 非素数"一致；枚举从 $p=2$ 起，不会用到它们。证毕。

**注（为何从 $i^2$ 起标）**：$i$ 的倍数 $i\cdot t$（$t<i$）已被更小的素因子在 earlier 轮次标记过，从 $i^2$ 起标避免重复，是埃氏筛 $O(n\log\log n)$ 复杂度的关键，但不影响正确性（引理 2 的"合数必被标记"只用到 $x\ge r^2$）。

---

### 引理 3（枚举的完整性、唯一性、有序性）

代码 `for(int p=2;p+k<=n;++p) if(!np[p]&&!np[p+k]) 输出 p,p+k` 恰好把每个合法对输出一次，且按 $p$ 升序。

*证明*：

- **完整性**：任取合法对 $(p,q)$，由引理 1 有 $q=p+k$、$p\ge2$、$q=p+k\le n$。故循环变量 $p$ 满足 $2\le p$ 且 $p+k\le n$，一定被枚举到；由引理 2，`!np[p]&&!np[p+k]` 为真，于是输出。无遗漏。
- **唯一性**：循环对每个 $p$ 至多执行一次输出；而合法对与其较小元素 $p$ 一一对应（引理 1 推论），故每个合法对恰输出一次。无重复。
- **有序性**：$p$ 严格递增枚举，输出的 pair 按较小元素升序排列。
- **范围安全**：条件 $p+k\le n$ 保证 $p+k$ 不越界（`np` 尺寸 $n+1$ 足够），且 $p<p+k\le n$ 保证两坐标都 $\le n$。证毕。

---

### 引理 4（奇偶性：奇数 $k$ 时至多一对）

若 $k$ 为奇数，则合法对至多一个，且若存在必为 $(2,2+k)$，存在当且仅当 $2+k\in\mathbb P$。

*证明*：设 $(p,p+k)$ 合法，$p,p+k$ 均素数。$k$ 奇 $\Rightarrow$ $p$ 与 $p+k$ 奇偶性相反 $\Rightarrow$ 其中恰一个为偶数。偶素数只有 $2$。

- 若 $p+k=2$：则 $p=2-k\le1$（$k\ge1$），与 $p\ge2$ 矛盾，不可能。
- 故只能 $p=2$，此时 $p+k=2+k$，合法当且仅当 $2+k$ 是素数（且 $2+k\le n$，由枚举条件保证）。

因此奇数 $k$ 时合法对唯一确定为 $(2,2+k)$（若 $2+k$ 素数且 $\le n$），否则为空。证毕。

**用途**：这是一条独立于筛法的校验性质。程序中筛法 + 枚举对奇偶 $k$ 一视同仁，引理 4 保证奇数 $k$ 的输出必为空或单行 `2 (2+k)`，可用于手算核对（见第一节表格 `10 1`）。

---

### 引理 5（`empty` 判定正确）

`found` 初值 `false`，每次输出置 `true`；循环后 `!found` 则输出 `empty`。则程序输出 `empty` 当且仅当不存在合法对。

*证明*：由引理 3，"输出过至少一对" $\iff$ "存在合法对"。`found` 恰记录"是否输出过至少一对"，故 `found=true` $\iff$ 存在合法对，`found=false` $\iff$ 不存在。后者输出 `empty`，与题面"若没有找到任何素数对，输出 empty"一致。证毕。

---

### 引理 6（复杂度）

时间 $O(n\log\log n)$，空间 $O(n)$。

*证明*：筛法：外层 $i$ 到 $\sqrt n$，内层对每个素数 $i$ 标记约 $n/i$ 个数，总标记次数 $\sum_{i\le\sqrt n,\,i\in\mathbb P}n/i=n\sum_{i\le\sqrt n,\,i\in\mathbb P}1/i=O(n\log\log n)$（素数倒数和的经典估计）。枚举：$p$ 从 $2$ 到 $n-k$，每步 $O(1)$ 查表，$O(n)$。合计 $O(n\log\log n)$。空间：`np` 为 $n+1$ 个 `bool`，$O(n)$；$n\le10^4$ 时约 $10$ KB。证毕。

---

### 定理

程序按较小元素升序输出所有差为 $k$、两端均为 $\le n$ 素数的坐标对，无解时输出 `empty`；时间 $O(n\log\log n)$，空间 $O(n)$。

*证明*：引理 1 把题意化为合法对集合；引理 2 保证素性判定正确；引理 3 保证枚举完整、唯一、有序；引理 5 保证 `empty` 分支正确；引理 4 提供奇数 $k$ 的独立校验；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 把花哨背景翻译成数学条件："破坏力最大" $\iff$ 两坐标都是素数且差恰好为 $k$。
- **consider easier version** — 先想试除法暴力 $O(n\sqrt n)$（$n=10^4$ 其实能过），确认需要素性判定。
- **classic problem solution** — 埃氏筛 $O(n\log\log n)$ 预处理 $n$ 以内素数表，查询 $O(1)$。
- **explore its property** — 奇偶性：$k$ 奇 $\Rightarrow$ 唯一候选 $(2,2+k)$；作为独立手算校验，而非算法分支。
- **reduce to easier problem** — 枚举较小素数 $p$，判 $p$ 与 $p+k$ 是否都素数且 $p+k\le n$；pair 由 $p$ 唯一确定，天然去重 + 升序。
- **discuss by category** — 无解时输出 `empty`（`found` 标志）；极小 $n$、奇/偶 $k$ 分类核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 坐标系长度上界（$\le10^4$） | `int`，读入 | 坐标 $1\sim n$ |
| `k` | 要求的磁石间距（$1\le k\le n$） | `int`，读入 | 差恰好为 $k$ |
| `mxn` | $10^4+5$ | `constexpr int{10005}` | +5 松弛 |
| `np[x]` | $x$ **不是**素数的标记 | `bool[mxn]`，全局默认 `false` | "np = not prime"；`np[0]=np[1]=true` |
| `p` | 枚举的较小素数坐标 | `int`，从 $2$ 递增 | 循环变量 |
| `found` | 是否输出过至少一对 | `bool`，初值 `false` | 决定结尾是否 `empty` |

### 算法步骤

1. I/O 加速三行。
2. 读入 `n,k`。
3. 埃氏筛：`np[0]=np[1]=true`；对 $i=2\dots\lfloor\sqrt n\rfloor$，若 `!np[i]` 则标记 $i^2,i^2+i,\dots\le n$ 为 `true`。
4. `found=false`；对 $p=2$ 到 $n-k$：若 `!np[p]&&!np[p+k]`，输出 `p` 空格 `p+k` 换行，并置 `found=true`。
5. 若 `!found`，输出 `empty` 换行。

### 复杂度

- 时间：$O(n\log\log n)$（筛）$+O(n)$（枚举），$n\le10^4$ 时极快。
- 空间：$O(n)$，`np` 约 $10$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；6 组手造数据（偶/奇 $k$、多对/单对/empty、极小 $n$）逐条吻合；另与独立试除法判素 + 枚举的暴力对拍 $20000$ 组随机 $(n,k)$（$n\le200$，含大量奇数 $k$ 与无解情形），$0$ mismatch。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2640 神秘磁石
// 思路：破坏力最大 ⇔ 两坐标都是素数且差恰好为 k。
//       埃氏筛打出 n 以内素数表，枚举较小素数 p，判 p 与 p+k 是否都素数且 p+k<=n。
//       按 p 升序输出，每对一行；一对都没有输出 empty。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int n,k;
bool np[mxn];	// np[i]=true 表示 i 不是素数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	np[0]=np[1]=true;
	for(int i=2;i*i<=n;++i)
		if(!np[i])
			for(int j=i*i;j<=n;j+=i)
				np[j]=true;
	bool found=false;
	for(int p=2;p+k<=n;++p)	// p 是较小坐标，p+k<=n 保证两端都不越界
		if(!np[p]&&!np[p+k])
		{
			cout<<p<<' '<<p+k<<'\n';
			found=true;
		}
	if(!found)
		cout<<"empty\n";
	return 0;
}
```

### 代码说明

- `np` 是"非素数"标记，全局 `bool` 默认 `false`（即默认都当素数），筛法把合数置 `true`；`np[0]=np[1]=true` 必须显式写，因为 $0,1$ 不是素数但默认值是 `false`。
- 内层从 `j=i*i` 起标：$i$ 的更小倍数已被前面的素数标记过，这是埃氏筛的标准优化，不影响正确性（引理 2）。
- 枚举条件 `p+k<=n` 一举保证两件事：$p+k$ 不越界、两坐标都 $\le n$；`p` 从 $2$ 升序天然给出去重 + 有序输出。
- 奇数 $k$ 时无需特判——筛法 + 枚举自动只会留下 $(2,2+k)$（引理 4），代码对奇偶 $k$ 统一处理。
- `found` 标志把"是否输出过"与"结尾是否 empty"解耦，避免重复扫描。
