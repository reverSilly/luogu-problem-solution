# P2185 公路通行税 — 题解

## 一、解题过程：人类思考叙事

题意翻译：$N$ 个城市由 $M$ 条双向公路连成一个连通图。收税员按"经过的公路条数"收费，而政府改推"公路印花"：印花一年的价值 = 在两个最远城市之间做 100 次旅行的费用。一次旅行的费用 = 从一个城市到另一个城市所需经过的**最少公路数**。

所以：**印花价值 = 图的直径（边数）× 100**。

数据范围：$N\le 1000$，$M\le 25000$，**多组数据**，以 `0 0` 结束。

问题就是求无向连通图的直径（以边数计）。

**第一步：为什么不能用 Floyd？**

Floyd 求所有点对最短路是 $O(N^3)$，$N=1000$ 就是 $10^9$ 次运算，多组数据直接超时。

**第二步：BFS 求单源最短路。**

无权图中 BFS 就是最短路算法。从某个点 $s$ 出发 BFS，得到的 `dist[i]` 是 $s$ 到 $i$ 的最少公路数。$s$ 的"最远距离"是 $\max_i \mathrm{dist}[i]$。

**第三步：直径 = 所有点的最远距离的最大值。**

这看起来是废话，但它其实是本题的**关键**：$\mathrm{diam}(G)=\max_s \max_i \mathrm{dist}[s][i]$。这里的"$\max_s$"看起来要多跑 $N$ 次 BFS，但直觉上 BFS 很贵，能不能只跑两次？

对于一般图，"两次 BFS 求直径"的技巧只在**树**上成立（树上从任意点出发两次 BFS 就能找到直径）。本题的图是任意连通图（有环），这个技巧不适用！例如三角形加长尾巴，从任意点出发最远点未必是直径端点。所以老老实实跑 $N$ 次 BFS。

**第四步：复杂度够吗？**

$N$ 次 BFS，每次 $O(N+M)$，总共 $O(N(N+M)) = 1000\times(1000+25000) = 2.6\times 10^7$。对无向图，每条边在邻接表里出现两次，BFS 里是 $2M$ 次松弛，加起来 $N\cdot 2M = 1000\times50000 = 5\times10^7$。完全可以接受。

多组数据也没有总次数限制，按题目给的规模走就行。

**第五步：细节。**

- 输入到 `0 0` 结束。注意 `0 0` 是"两个 0"，要同时为 0 才 break。
- 图连通，所以 BFS 能访问到所有点，`dist[i]` 不会是 -1。（其实即使不连通，取 max 也会把 -1 忽略掉，因为初值最大是 0……不过题目保证连通，无需担心。）
- 自环：`1 1` 表示城市 1 和城市 1 之间有一条公路。加进邻接表也无妨（BFS 里 `dist[1]` 已经设过，不会重复入队），只是边数统计上多一条但不影响最短路。
- 答案上界：直径 $\le N-1 \le 999$，答案 $\le 99900$，`int` 够用。不过为了稳妥我用 `i64` 乘。

**第六步：数据结构选型。**

$N\le 1000$，$M\le 25000$。用邻接表（链式前向星）最省事：静态数组 `head/nxt/to`，`mxn = 1005`、`mxm = 50005`（每条无向边存两次，$2\times25000=50000$）。

BFS 用数组模拟队列，队列长度最多 $N$，`mxn` 足够。

## 二、思维链：完整证明

**记号约定**：$N$ 为城市数，$M$ 为公路数；城市编号 $1..N$；$G$ 为对应的无向图；$d(u,v)$ 为 $u$ 到 $v$ 经过的最少公路数（无向图上 $d(u,v)=d(v,u)$）。

**引理 1**（BFS 求最短路）：对任意起点 $s$，算法结束后 $\mathrm{dist}[i]$ 等于 $d(s,i)$。

*证明*：BFS 按"距离层"访问顶点：先访问距离 0 的 $s$，再访问所有距离 1 的顶点……具体地，若顶点 $u$ 首次被访问时 $\mathrm{dist}[u]=t$，则存在一条长度为 $t$ 的从 $s$ 到 $u$ 的路径（由 $u$ 是从某个距离 $t-1$ 的顶点首次发现的）。另一方面，若存在更短的路径（长度 $t'<t$），则沿该路径 $s=v_0,v_1,\dots,v_{t'}=u$，每个 $v_{i+1}$ 都会在 $v_i$ 被访问后的那一层被发现，于是 $u$ 会在第 $t'$ 层（更早）被访问，与"首次访问时距离为 $t$"矛盾。故 $\mathrm{dist}[i]=d(s,i)$。证毕。

**引理 2**（单点的最远距离）：对起点 $s$，令 $f(s)=\max_i \mathrm{dist}[i]$。则 $f(s)$ 是从 $s$ 出发到任意城市所需经过的最少公路数的最大值。

*证明*：由引理 1，$\mathrm{dist}[i]=d(s,i)$，取最大值得 $f(s)=\max_i d(s,i)$，正是题面"从 $s$ 到最远城市的最少公路数"。证毕。

**引理 3**（直径等于最大 $f$）：算法输出的 `diam` 等于 $\max_{u,v} d(u,v)$。

*证明*：算法对每个 $s\in\{1..N\}$ 做一次 BFS 并用 `max(diam, dist[i])` 更新，故最终 `diam = \max_s\max_i \mathrm{dist}[s][i] = \max_s f(s) = \max_s\max_i d(s,i)`。因为 $\max$ 可交换，这恰是所有点对最短距离的最大值，即图的直径。证毕。

**引理 4**（答案正确）：算法输出的是公路印花价值。

*证明*：由引理 3，输出的 `diam` 是两个最远城市之间的最少公路数。题面规定"一年的公路印花的价值相当于在两个最远城市之间进行 100 次旅行所需的费用"，而一次旅行的费用等于经过的最少公路数（每条公路收 1 PC），故印花价值 $= \mathrm{diam}\times 100$。算法输出 `diam*100`，正确。证毕。

**定理**：算法对每组数据输出的值即为该组的公路印花价值。

*证明*：由引理 1、3、4 逐层成立。证毕。

**补充说明（为什么不能用"两次 BFS"）**：树上"任取一点两次 BFS 求直径"的经典结论依赖于树上路径的唯一性。本题的图含环，$f(s)$ 的最大值未必由任意 $s$ 达到，因此必须枚举所有起点。举例说明：取一个三角形 $a,b,c$ 并在 $c$ 上挂一条长链 $c-d-e-f$，图中最长路为 $a$ 到 $f$（长 3+1=… ），而从 $b$ 出发的最远点是 $f$；从链的中点出发最远点是 $a$ 或 $b$。取最坏起点时两次 BFS 会得到小于直径的值。因此本解采用 $N$ 次 BFS 的稳妥做法。

## 三、模式总结（按实际思考顺序）

1. **翻译题意** — 求无向连通图的直径（边数），乘以 100。
2. **先想 Floyd** — $O(N^3)$ 太慢，否决。
3. **BFS 求单源最短路** — 无权图的标准工具。
4. **关键判断：两次 BFS 的技巧在一般图上不成立** — 只对树有效，本题图含环，必须枚举所有起点。
5. **算复杂度确认可行** — $O(N(N+M))\approx 5\times10^7$。
6. **工程细节** — 多组数据到 `0 0` 结束；链式前向星存图；数组模拟 BFS 队列。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $N$ | 城市数 | `int`，$[1,1000]$ |
| $M$ | 公路数 | `int`，$[1,25000]$ |
| `head[u]` | 城市 $u$ 的邻接表头 | `int[]`，$1..N$ |
| `nxt[e]`,`to[e]` | 前向星：下一条边、终点 | `int[]`，$1..2M$ |
| `ecnt` | 已加入的边数计数 | `int`，$\le 2M$ |
| `dist_[i]` | 起点到 $i$ 的最少公路数 | `int[]`，$[-1,N-1]$ |
| `que[]` | BFS 队列 | `int[]`，长度 $\le N$ |
| `diam` | 图的直径（边数） | `int`，$[0,N-1]$ |

### 算法步骤

1. 循环读入 $N,M$；若 $N=M=0$ 则结束。
2. 清空 `head[1..N]`、`ecnt=0`。
3. 读入 $M$ 条公路 $(u,v)$，双向各加一条边（`adde(u,v)`、`adde(v,u)`）。
4. `diam=0`；对每个起点 $s=1..N$：
   - BFS：把所有 `dist_[i]` 置 $-1$（表示未访问），`dist_[s]=0`，$s$ 入队；不断出队 $u$，对每条邻边 $u\to v$，若 `dist_[v]==-1` 则 `dist_[v]=dist_[u]+1` 并入队。
   - 用 $\max_i \mathrm{dist}[i]$ 更新 `diam`。
5. 输出 `diam * 100`。

### 复杂度

- 单组时间复杂度：$O\bigl(N\cdot(N+M)\bigr)$，约 $5\times10^7$ 次基本操作。
- 空间复杂度：$O(N+M)$。

### 验证状态

- 标程 `P2185.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 编写暴力 `P2185_brute.cpp`（Floyd 求所有点对最短路，取最大值作为直径；自环 `u==v` 时不写入邻接矩阵以免破坏对角线的 $0$）与对拍脚本 `P2185_check.py`，在 $n\le 40$ 的随机连通图上对拍 **300 组全部通过**。
- 手工验证：`4 3 / 1 2 / 2 3 / 3 4` 输出 `300`（链，直径 3）；`5 5 / 1 2 / 2 3 / 3 4 / 4 5 / 5 1` 输出 `200`（五元环，直径 2，含环时"两次 BFS"技巧失效，此处直径只能靠枚举起点得到）；把两组数据接在一起输入（末尾以 `0 0` 结束）输出两行 `300`、`200`，验证了多组数据的读入与状态重置。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2185 公路通行税
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};
constexpr int mxm{50005};

int head[mxn],nxt[mxm],to[mxm],ecnt;
int dist_[mxn],que[mxn];

void adde(int u,int v)
{
	++ecnt;
	to[ecnt]=v;
	nxt[ecnt]=head[u];
	head[u]=ecnt;
}

void bfs(int s,int n)
{
	for(int i=1;i<=n;++i)
		dist_[i]=-1;
	int l=0,r=0;
	que[r++]=s;
	dist_[s]=0;
	while(l<r)
	{
		int u=que[l++];
		for(int e=head[u];e;e=nxt[e])
		{
			int v=to[e];
			if(dist_[v]!=-1)
				continue;
			dist_[v]=dist_[u]+1;
			que[r++]=v;
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m;
	while(cin>>n>>m)
	{
		if(!n&&!m)
			break;
		for(int i=1;i<=n;++i)
			head[i]=0;
		ecnt=0;
		for(int i=1;i<=m;++i)
		{
			int u,v;
			cin>>u>>v;
			adde(u,v),adde(v,u);
		}
		// 图连通，从每个点出发 BFS，最远距离的最大值即为直径（边数）
		int diam=0;
		for(int s=1;s<=n;++s)
		{
			bfs(s,n);
			for(int i=1;i<=n;++i)
				diam=max(diam,dist_[i]);
		}
		// 印花价值 = 直径条公路 × 100 次旅行 × 每次 1 PC
		cout<<(i64)diam*100<<'\n';
	}
	return 0;
}
```

### 代码说明

- 链式前向星存图：`head[u]` 是 $u$ 的第一条出边编号，`nxt[e]` 是同起点的下一条边，`to[e]` 是终点。每条无向边调用两次 `adde`，因此边数组要开到 $2M+5$。
- 每组数据要重置 `head[]` 和 `ecnt`，否则上一组的边会残留。
- `bfs` 用 `-1` 表示"未访问"，这样重置只需一次线性赋值，不必另开 `vis` 数组。
- 队列用数组 `que` 模拟，队列长度最多 $N$（每个点最多入队一次），`mxn` 足够。
- 直径用 `int` 存（$\le N-1$），乘 100 时先转 `i64` 避免潜在的整型溢出习惯问题。
- `if(!n&&!m) break;` 必须两个都为零才退出，只判一个会误伤合法数据。
