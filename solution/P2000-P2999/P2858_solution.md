# P2858 [USACO06FEB] Treats for the Cows G/S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N\le 2000$ 份零食排成一列，初始价值 $V_i\le 1000$。每天从**最左或最右**取一份卖掉，第 $a$ 天卖出的零食售价 $V_i\times a$。卖完全部 $N$ 份，求最大总收益。

**第一步：看清操作的结构。** 每天只能动两端，所以任何时刻**剩下的零食一定是原序列的一段连续区间** $[l,r]$；而且已经卖了多少天完全由区间长度决定：剩 $len=r-l+1$ 份时，已卖 $N-len$ 天，**今天是第 $N-len+1$ 天**。这两个观察是整道题的地基——"状态"不需要记录卖出的顺序，只需要记录剩下的区间。

**第二步：先试贪心，撞墙。** 倍数随天数递增，直觉是"便宜的先卖、贵的留到后面"，即每天卖两端中较小者。手造一个反例打脸：$V=[1,10,12,2,11]$。

- 贪心：两端 $1,11$ 卖 $1$（$+1$）；两端 $10,11$ 卖 $10$（$+20$）；两端 $12,11$ 卖 $11$（$+33$）；两端 $12,2$ 卖 $2$（$+8$）；最后 $12$（$+60$）。合计 $122$。
- 更优：卖 $1$（$+1$）；卖右端 $11$（$+22$）；卖右端 $2$（$+6$）；卖左端 $10$（$+40$）；最后 $12$（$+60$）。合计 $129>122$。

复盘失败原因：贪心只比较**两端当下**的价值，但卖端的真正代价是**暴露出它身后的东西**。上例中贪心第 $2$ 天卖掉 $10$，是因为它只看到 $10<11$；而最优方案宁可第 $2$ 天卖更贵的 $11$，把 $10$ 留到第 $4$ 天（$10\times4=40$ 远胜 $10\times2=20$），同时让最大的 $12$ 稳坐第 $5$ 天。**局部比较两端无法预见"身后"的结构**，贪心没救，必须枚举决策。

**第三步：贪心撞墙 → 区间 DP。** 第一步已经说了状态就是剩余区间 $[l,r]$，而今天的倍数 $day=N-(r-l+1)+1$ 由区间唯一确定。于是定义

$$dp[l][r]=\text{把区间 }[l,r]\text{ 全部卖完（从第 }day\text{ 天开始卖）的最大收益}.$$

今天只有两种决策：卖左端 $l$，得 $V_l\times day$，剩下 $[l+1,r]$ 从明天继续；或卖右端 $r$，得 $V_r\times day$，剩下 $[l,r-1]$。两者取 max：

$$dp[l][r]=\max\bigl(V_l\times day+dp[l+1][r],\ \ V_r\times day+dp[l][r-1]\bigr),\qquad day=N-(r-l).$$

边界：$len=1$ 时它是最后一份，第 $N$ 天卖，$dp[i][i]=V_i\times N$。答案 $dp[0][N-1]$。按区间长度从小到大递推即可，$O(N^2)$ 个状态、每个 $O(1)$ 转移，$N=2000$ 时约 $4\times10^6$，稳过。

**为什么这个 DP 没有后效性？** 因为"未来怎么卖"只依赖两件事：剩下哪些零食（区间 $[l,r]$）、今天第几天（由长度定）。历史卖出顺序对这两件事毫无影响——这正是第一步两个观察的价值，完整证明见引理 2。

**第四步：空间还能压。** $2005\times2005$ 的 `long long` 表约 $32$ MB，能过但肥。注意到长度 $len$ 的转移只依赖长度 $len-1$，可以滚动成一维：`f[l]` 表示当前长度下 $dp[l][l+len-1]$。关键是**覆盖顺序**：$len$ 轮里让 $l$ **从小到大**扫，算 `f[l]` 时 `f[l+1]` 还没被本轮覆盖（仍是 $len-1$ 的值，恰是 $dp[l+1][r]$），`f[l]` 自己也还是旧值（$dp[l][r-1]$），两个依赖都拿得到。于是空间 $O(N)$。

**第五步：数值范围。** 总收益上界：把最大的 $V$ 配最大的天数，$\le 1000\times\sum_{a=1}^{2000}a=1000\times2001000=2.001\times10^9$。这比 `int` 上限 $2.147\times10^9$ 只小 $7\%$——理论上装得下，但贴脸飞行，任何中间量手滑就炸。用 `long long`（`i64`）一劳永逸。

## 二、思维链：完整证明

**记号。** 零食价值 $V_0,\dots,V_{N-1}$（0-based）。一个卖法是每天取当前序列左端或右端，共 $N$ 天；第 $a$ 天卖出的零食贡献 $V\times a$。$dp[l][r]$ 定义见下。

---

### 引理 1（剩余集是区间；天数由长度定）

任何合法卖法进行 $t$ 天后，剩余零食恰为原序列的某个连续区间 $[l,r]$，且 $r-l+1=N-t$；第 $t+1$ 天的倍数是 $t+1=N-(r-l)$。

*证明*：对 $t$ 归纳。$t=0$：剩余 $[0,N-1]$，长度 $N$ ✓。设 $t$ 天时剩余 $[l,r]$，长度 $N-t$。第 $t+1$ 天只能取左端 $l$ 或右端 $r$：取 $l$ 剩 $[l+1,r]$，取 $r$ 剩 $[l,r-1]$，都是连续区间，长度 $N-t-1=N-(t+1)$ ✓。倍数即天数 $t+1=N-(r-l+1)+1=N-(r-l)$。证毕。

---

### 引理 2（DP 递推正确：无后效性 + 最优子结构）

定义 $dp[l][r]$ 为"剩余区间 $[l,r]$、从第 $day=N-(r-l)$ 天起卖完"的最大收益。则

$$dp[i][i]=V_i\times N;\qquad dp[l][r]=\max\bigl(V_l\times day+dp[l+1][r],\ V_r\times day+dp[l][r-1]\bigr)\ (l<r).$$

且原问题答案 $=dp[0][N-1]$。

*证明*：对区间长度 $len=r-l+1$ 归纳。

**良定义（无后效性）**：由引理 1，任何到达"剩余 $[l,r]$"的历史都恰卖了 $N-len$ 天，故"接下来第几天"唯一确定为 $day=N-len+1$；未来合法操作只取决于剩余序列本身。因此"从该状态出发的最大未来收益"与历史无关，$dp[l][r]$ 良定义。

**基础 $len=1$**：只剩一份，它是第 $N$ 天（最后一天）卖出，收益 $V_i\times N$，别无选择，故 $dp[i][i]=V_i\times N$ ✓。

**归纳步**：设长度 $<len$ 的区间递推正确。状态 $[l,r]$（$len\ge2$）的第一天只有两种互斥决策：

- 卖左端 $l$：立即收益 $V_l\times day$，剩余 $[l+1,r]$（长度 $len-1$），从第 $day+1$ 天继续。注意 $[l+1,r]$ 对应的天数参数 $N-((r)-(l+1))=N-(r-l)+1=day+1$，与 $dp[l+1][r]$ 的定义**恰好衔接**。由归纳假设，后续最大收益 $=dp[l+1][r]$，该分支总收益 $V_l\times day+dp[l+1][r]$。
- 卖右端 $r$：同理总收益 $V_r\times day+dp[l][r-1]$。

任何合法卖法必属其一，故 $dp[l][r]\le\max(\cdots)$；反之两个分支各自拼接"立即卖出 + 子区间最优卖法"都是合法卖法，故 $dp[l][r]\ge\max(\cdots)$。两边夹得等号。

**答案**：初始状态剩余 $[0,N-1]$、第 $1$ 天，$day=N-(N-1)=1$ 与定义一致，故答案 $=dp[0][N-1]$。证毕。

---

### 引理 3（"卖较小端"贪心错误）

存在实例使"每天卖两端中价值较小者"的收益严格小于最优。

*证明*：取 $V=[1,10,12,2,11]$，$N=5$。贪心卖序唯一确定（每步两端价值均不等）：$1,10,11,2,12$，收益 $1\cdot1+10\cdot2+11\cdot3+2\cdot4+12\cdot5=1+20+33+8+60=122$。另一合法卖序 $1,11,2,10,12$（左、右、右、左、最后）收益 $1\cdot1+11\cdot2+2\cdot3+10\cdot4+12\cdot5=1+22+6+40+60=129>122$。故贪心非最优。证毕。

（失败机理：贪心第 $2$ 天卖 $10$ 只因其 $<11$，却放弃了把 $10$ 留到第 $4$ 天的 $40$ 收益；端点比较看不见"身后"的结构。）

---

### 引理 4（一维滚动的覆盖顺序正确）

令 `f[l]` 滚动存储当前长度 $len$ 的 $dp[l][l+len-1]$。初始化 `f[i]=V[i]*N`（$len=1$）。对 $len=2,\dots,N$，令 $day=N-len+1$，**$l$ 从小到大**执行

$$\texttt{f}[l]\leftarrow\max\bigl(\texttt{f}[l+1]+V_l\times day,\ \texttt{f}[l]+V_{l+len-1}\times day\bigr),\quad l=0,\dots,N-len.$$

则每轮结束后 `f[l]` $=dp[l][l+len-1]$，最终 `f[0]` $=dp[0][N-1]$。

*证明*：对 $len$ 归纳。$len=1$ 即引理 2 基础 ✓。设 $len-1$ 轮结束后 `f[l]` $=dp[l][l+len-2]$ 对所有合法 $l$ 成立。进入 $len$ 轮，断言：计算 `f[l]` 的那一刻，`f[l]` 与 `f[l+1]` 都仍是 $len-1$ 轮的旧值。因为本轮按 $l$ 递增覆盖，下标 $<l$ 的已被覆盖、下标 $\ge l$ 的尚未被动过，而 $l,l+1\ge l$ ✓。于是

- 旧 `f[l+1]` $=dp[l+1][l+len-1]$（长度 $len-1$，起点 $l+1$），正是引理 2 递推中的 $dp[l+1][r]$；
- 旧 `f[l]` $=dp[l][l+len-2]$，正是 $dp[l][r-1]$。

代入引理 2 的递推即得新 `f[l]` $=dp[l][l+len-1]$。下标范围：$l\le N-len$ 时 $l+1\le N-len+1\le N-1$（$len\ge2$），不越界。归纳完成，$len=N$ 轮只算 `f[0]` $=dp[0][N-1]$。证毕。

---

### 引理 5（数值范围）

任何卖法的总收益 $\le 1000\times N(N+1)/2\le 2.001\times10^9$；用 `i64` 存储绝对安全，`int` 则余量不足 $7\%$。

*证明*：总收益 $=\sum_{a=1}^{N}a\times V_{p_a}$，其中 $p$ 是排列。由排序不等式，最大值在"大价值配大天数"时取得，$\le\sum_{a=1}^{N}a\times1000=1000\times N(N+1)/2$。$N=2000$ 时为 $2\,001\,000\,000<2^{31}-1=2\,147\,483\,647$，但仅余 $6.8\%$；中间量 `f[l+1]+V*day` 同样被该上界控制（它是某合法卖法的收益）。`i64` 上限 $9.2\times10^{18}$，余量 $4.6\times10^9$ 倍。证毕。

---

### 引理 6（复杂度）

时间 $O(N^2)$，空间 $O(N)$。

*证明*：状态数 $\sum_{len=1}^{N}(N-len+1)=N(N+1)/2\approx2\times10^6$，每个状态一次 $O(1)$ 的 max 转移。空间：`v` 与 `f` 各 $N$ 个元素。证毕。

---

### 定理

程序输出卖完全部零食的最大收益，时间 $O(N^2)$、空间 $O(N)$。

*证明*：引理 1 确立"剩余区间 + 长度定天数"的状态结构；引理 2 证明区间 DP 递推与无后效性；引理 3 排除贪心歧路；引理 4 证明一维滚动的覆盖顺序正确；引理 5 保证数值安全；引理 6 给出复杂度。证毕。

---

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 只能动两端 ⇒ 剩余集恒为连续区间 $[l,r]$；已卖天数 $=N-len$，今天倍数由长度唯一确定。
2. **consider easier version** — 试贪心"卖较小端"：反例 $[1,10,12,2,11]$ 得 $122<129$，端点比较看不见"身后"结构，贪心死。
3. **classic problem solution** — 区间 DP：$dp[l][r]=\max(V_l\cdot day+dp[l+1][r],\ V_r\cdot day+dp[l][r-1])$，按长度递增，$O(N^2)$。
4. **reduce to easier problem** — 转移只依赖 $len-1$ 层 ⇒ 一维滚动；$l$ 递增覆盖保证 `f[l+1]` 与 `f[l]` 都还是旧值，空间 $O(N)$。
5. **discuss by category** — 收益上界 $2.001\times10^9$ 贴着 `int` 上限，用 `i64`；$len=1$ 边界是第 $N$ 天而非第 $1$ 天。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N$ | 零食数，$\le2000$ | `int n` | 读入 |
| `v[i]` | 第 $i$ 份零食初始价值（0-based） | `int[mxn]` | 读入 |
| `f[l]` | 滚动 DP：当前长度 $len$ 下 $dp[l][l+len-1]$ | `i64[mxn]` | $len=1$ 时 `f[i]=v[i]*n`（最后一天卖） |
| $len$ | 当前枚举的区间长度 | `int` | $2\to N$ 递增 |
| $day$ | 当前长度对应的"今天"倍数，$N-len+1$ | `int` | 每轮现算 |
| `mxn` | $2000+5$ | `constexpr int` | 数组尺寸 |

### 算法步骤

1. I/O 加速三行；读 $N$ 与 `v[0..N)`。
2. 初始化 `f[i]=(i64)v[i]*n`（$len=1$：最后一份第 $N$ 天卖）。
3. 对 $len=2,\dots,N$：$day=N-len+1$；$l$ 从 $0$ 到 $N-len$ **递增**执行 `f[l]=max(f[l+1]+v[l]*day, f[l]+v[l+len-1]*day)`。
4. 输出 `f[0]`。

### 复杂度

- 时间：$O(N^2)\approx2\times10^6$ 次转移。
- 空间：$O(N)$（一维滚动）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；按提示反推的 $V=[1,3,1,5,2]$ 手算 DP 逐层核对得 $43$ 吻合；$N=1$、$N=2$ 边界手算无误。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2858 [USACO06FEB] Treats for the Cows G/S
// 思路：剩余零食恒为区间 [l,r]，今天倍数 day=N-(r-l) 由长度定 ⇒ 区间 DP。
//       dp[l][r]=max(v[l]*day+dp[l+1][r], v[r]*day+dp[l][r-1])。
//       只依赖 len-1 层 ⇒ 一维滚动；l 递增覆盖，f[l+1] 与 f[l] 都还是旧值。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005};

int n,v[mxn];
i64 f[mxn];	// 滚动：f[l]=dp[l][l+len-1]；收益上界 2e9 贴 int 上限，用 i64

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>v[i];
	for(int i=0;i<n;++i)
		f[i]=(i64)v[i]*n;	// len=1：只剩它自己，第 n 天卖
	for(int len=2;len<=n;++len)
	{
		int day=n-len+1;
		for(int l=0;l+len<=n;++l)	// l 递增：f[l+1] 尚未被本轮覆盖，仍是 len-1 的值
			f[l]=max(f[l+1]+(i64)v[l]*day,f[l]+(i64)v[l+len-1]*day);
	}
	cout<<f[0]<<'\n';
	return 0;
}
```

### 代码说明

- 一维滚动的命门是 **$l$ 递增**：算 `f[l]` 时 `f[l+1]`（对应 $dp[l+1][r]$）与 `f[l]`（对应 $dp[l][r-1]$）都必须是上一轮的旧值；若 $l$ 递减，`f[l+1]` 已被本轮覆盖，转移就错了（引理 4）。
- 初始化是 `v[i]*n` 不是 `v[i]*1`：长度 $1$ 的区间是**最后**一天卖，倍数 $N$。这是本题最容易写反的边界。
- `day=n-len+1`：剩 $len$ 份说明已卖 $N-len$ 天，今天第 $N-len+1$ 天。
- 乘法前显式转 `i64`：`v[l]*day` 最大 $1000\times2000=2\times10^6$ 本身不溢出，但累加进 `f` 后总量可达 $2.001\times10^9$，全程 `i64` 最稳。
