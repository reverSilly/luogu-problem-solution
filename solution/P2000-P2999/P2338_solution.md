# P2338 [USACO14JAN] Bessie Slows Down S — 题解

## 一、解题过程：人类思考叙事

题意：贝西从位置 $x=0$、时间 $t=0$、速度 $v=1$ 出发，向 $1000$ 米外的终点滑行。她一共有 $N$ 条失误记录：

- `T S`：比赛开始后第 $S$ 秒整发生一次失误；
- `D X`：滑到距起点 $X$ 米处时发生一次失误。

第 $k$ 次失误后速度变成 $\dfrac{1}{k+1}$（第一次后 $1/2$，第二次后 $1/3$，……）。同一时刻、同一位置上的多条记录算作**不同的**失误，各自让速度下降一档。求滑过终点所需时间，非整数时四舍五入。

**第一步：先把"速度"这件事想清楚。**

速度只与"到目前为止一共失误了几次"有关，与失误是 `T` 还是 `D`、发生顺序如何都无关。设已经失误 $k$ 次，则

$$v=\frac{1}{k+1}.$$

于是整条运动轨迹是**分段匀速**的：两个相邻事件之间速度不变，位置关于时间是一条线段。要求终点时间，只需把所有"拐点"（事件）按真实发生顺序走一遍。

**第二步：事件的发生顺序有很强的结构。**

- `T` 事件发生在**绝对时间**上，把所有 `T` 按时间排序，它们被遇到的顺序就是排序顺序。
- `D` 事件发生在**固定位置**上。贝西一直向前滑，位置单调不减，所以位置小的 `D` 一定先被遇到；把 `D` 按距离排序即可。
- 于是问题变成"归并两个有序表"：任意时刻，下一个事件要么是"还没到的下一个 `T` 时刻"，要么是"到达下一个 `D` 位置"。

在当前速度 $v=1/(k+1)$ 下，从 $x$ 滑到 $D$ 需要

$$\Delta t=\frac{D-x}{v}=(D-x)(k+1).$$

比较 $T_{\text{next}}$ 与 $t+(D_{\text{next}}-x)(k+1)$，谁小谁先发生。

**第三步：一个很容易踩的坑——终点本身也是"位置事件"。**

如果只比较"下一个 `T`"与"下一个 `D`"，在没有 `D` 可比较时就会把未来的 `T` 当成下一个事件。反例：$N=1$，唯一记录是 `T 5000`。正确过程是 $1000$ 秒时已经滑过终点，失误根本没发生，答案 $1000$；而错误做法会先处理 $t=5000$ 的失误，把位置推到 $5000$，输出 $5000$。

修正：把"到达 $1000$ 米终点"也看成一个位置事件——当没有剩余 `D` 时，下一个位置事件就是终点；当还有 `D` 时，因为 $D\le1000$，到达 $D$ 不会晚于到达终点，所以只需比较下一个 `D`。

**第四步：同时发生的多个事件怎么办？**

题面明确说同一时刻、同一位置的记录算不同失误。例如 `T 10` 和 `D 10`：第 $10$ 秒时贝西恰好位于 $10$ 米，两条记录同时触发，失误数一次加 $2$，之后速度是 $1/3$，总时间为 $10+990\times3=2980$。若只算一次失误会得到 $10+990\times2=1990$，差距巨大。

处理方式：由于同时发生的事件之间**没有时间流逝、没有位移**，它们的先后顺序不影响处理完这一批之后的状态（位置相同、时间相同、失误总数相同），所以可以任意排序，只要**一个都不漏**。代码里先处理 `T`：若某个 `D` 的到达时刻与 `T` 相同，处理完 `T` 后位置恰好等于该 `D`，下一轮以新的（更大的）失误数重算到达时间，得到 $\Delta t=0$，随即把它也处理掉；多个同刻 `T`、同位置 `D` 同理，逐个消耗。

**第五步：四舍五入与精度。**

精确时间可能是半整数，例如 `T 1`、`T 2`：$1$ 秒时位置 $1$，速度变 $1/2$；$2$ 秒时位置 $1.5$，速度变 $1/3$；剩余 $998.5$ 米用时 $2995.5$ 秒，总时间 $2997.5$，输出 $2998$。对非负时间，"四舍五入"就是 $\lfloor t+\tfrac12\rfloor$，直接 `(long long)(t+0.5L)`。

时间规模：`T` 最大 $10^7$，失误最多 $10^4$ 次，最后一段最多 $1000\times10001\approx10^7$ 秒，总时间不超过约 $2.1\times10^7$。用 `long double` 累加，误差远小于 $0.5$，不会影响取整（对拍时用精确分数实现验证了这一点）。

## 二、思维链：完整证明

**引理 1（速度公式）**：若贝西已经历 $k$ 次失误，则当前速度为 $\dfrac{1}{k+1}$。

*证明*：对 $k$ 归纳。$k=0$ 时题面给出速度为 $1=1/(0+1)$。设 $k$ 次失误后速度为 $1/(k+1)$，第 $k+1$ 次失误后题面规定速度降为 $\dfrac{1}{(k+1)+1}=\dfrac{1}{k+2}$，归纳成立。证毕。

**引理 2（下一个事件时刻）**：设当前时刻 $t$、位置 $x$、已失误 $k$ 次，剩余事件中最近的 `T` 时刻为 $T_{\text{next}}$，最近的 `D` 位置为 $D_{\text{next}}$（若不存在则视为 $+\infty$），并令

$$\tau_D=t+(D_{\text{next}}-x)(k+1),\qquad \tau_{\text{end}}=t+(1000-x)(k+1).$$

则在 $t$ 之后，下一个使状态发生变化的时刻为

$$\min\big(T_{\text{next}},\ \tau_D,\ \tau_{\text{end}}\big).$$

*证明*：由引理 1，在下一个事件之前速度恒为 $1/(k+1)$，位置随时间线性变化 $x(s)=x+(s-t)/(k+1)$。

- `T` 事件在时刻 $T_{\text{next}}$ 发生，与位置无关。
- 到达 $D_{\text{next}}$ 的时刻是方程 $x(s)=D_{\text{next}}$ 的解，即 $s=t+(D_{\text{next}}-x)(k+1)=\tau_D$。
- 到达终点的时刻同理为 $\tau_{\text{end}}$。

在 $\min$ 之前，没有任何 `T` 触发、没有到达任何 `D`、也没有到达终点，速度保持不变，故状态不变；在 $\min$ 处首次发生变化。证毕。

**引理 3（`D` 事件按距离递增被遇到，且不会被跳过）**：把 `D` 值升序排列为 $D_1\le D_2\le\cdots$。在模拟过程中，位置 $x$ 单调不减，且始终有 $x\le D_j$，其中 $D_j$ 是当前最小的未处理 `D`；因此 `D` 一定按 $D_1,D_2,\dots$ 的顺序被处理，不会漏掉。

*证明*：速度为正，位置单调不减。初始 $x=0\le D_1$（题面 $X\ge1$）。设某时刻不变式 $x\le D_j$ 成立：

- 若下一个事件是 `T` 且在到达 $D_j$ 之前发生，由引理 2 有 $T_{\text{next}}<\tau_D$，在该时刻位置 $x'=x+(T_{\text{next}}-t)/(k+1)<D_j$，不变式保持。
- 若下一个事件是到达 $D_j$（时刻 $\tau_D$），处理时把 $x$ 置为 $D_j$，然后 $j$ 后移，新的未处理 `D` 满足 $D_{j+1}\ge D_j=x$，不变式保持。
- 若下一个事件是到达终点，过程结束（终点 $1000\ge$ 所有 `D`，此时不可能还有 `D` 未处理：若存在则 $\tau_D\le\tau_{\text{end}}$，由引理 2 会先处理 `D`）。

三种情形都不跳过任何 `D`，且顺序与排序一致。证毕。

**引理 4（同刻事件可任意排序）**：若若干事件发生在同一时刻 $\tau$，则按任意顺序处理它们，处理完全部事件后的状态（时刻、位置、失误总数）相同。

*证明*：这些事件都发生在时刻 $\tau$，而贝西在时刻 $\tau$ 的位置唯一确定，记作 $x(\tau)$；每个 `T` 事件是否触发只取决于 $\tau$ 是否等于其记录时刻，每个 `D` 事件是否触发只取决于 $x(\tau)$ 是否等于其记录位置，都与处理顺序无关。处理过程中不消耗时间、不移动位置，故位置始终是 $x(\tau)$、时刻始终是 $\tau$；失误总数等于触发的记录条数，也与顺序无关。因此处理完这一批后状态唯一。证毕。

**引理 5（模拟的正确性）**：设模拟开始前状态与真实过程一致。每次按引理 2 选出最早事件、按引理 3 与引理 4 处理，则处理完后状态仍与真实过程一致；因此最终输出的时刻就是真实到达终点的时刻（在精确算术下）。

*证明*：对事件个数归纳。基础情形：初始 $(t,x,k)=(0,0,0)$ 与真实一致。归纳步：由引理 2，下一个真实事件正是被选中的那个，且其发生时刻由公式精确给出；处理该事件时位置/时间按匀速直线运动更新，与实际轨迹相同；失误数加 $1$（或按引理 4 一次加若干）。若选中终点，则由引理 2，终点是下一个状态变化点，在此之前没有事件，到达时刻 $\tau_{\text{end}}$ 就是答案。故每一步状态都与真实一致，过程结束时输出真实时间。证毕。

**引理 6（终止性）**：模拟至多进行 $N+1$ 轮。

*证明*：每轮要么消耗一个 `T`（$i$ 增加），要么消耗一个 `D`（$j$ 增加），要么进入终点分支后令 $x=1000$ 使循环条件 `x<1000` 失败而退出。`T`、`D` 各至多被消耗 $N$ 次，加上最后的终点轮，轮数不超过 $N+1$。证毕。

**引理 7（取整）**：对非负实数 $t$，$\lfloor t+\tfrac12\rfloor$ 等于"四舍五入到最近整数"（恰好半整数时向上取整）。

*证明*：设 $t=n+r$，$n=\lfloor t\rfloor$ 为非负整数，$r\in[0,1)$。若 $r<\tfrac12$，则 $t+\tfrac12<n+1$，下取整为 $n$；若 $r\ge\tfrac12$，则 $t+\tfrac12\ge n+1$ 且 $<n+2$，下取整为 $n+1$。这正是四舍五入（$r=\tfrac12$ 时进位）。证毕。

**定理**：程序输出的整数等于真实终点时间四舍五入后的结果（浮点误差远小于 $0.5$ 的前提下）。

*证明*：由引理 5，模拟得到的 $t$ 是真实终点时间；由引理 7，`(long long)(t+0.5L)` 实现四舍五入。浮点误差分析见第四节的复杂度与验证说明。证毕。

**复杂度**：排序 $O(N\log N)$，模拟 $O(N)$，总时间 $O(N\log N)$；空间 $O(N)$。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 速度只由"已失误次数"决定：第 $k$ 次后为 $1/(k+1)$，轨迹分段匀速。
- **explore its property** — `T` 按时间排序、`D` 按位置排序；位置单调 ⇒ `D` 的遭遇顺序就是距离顺序。
- **reduce to easier problem** — 问题化为归并两个有序事件表，逐个计算下一拐点。
- **try naive idea and find counterexample** — 只比较 `T` 与下一个 `D`、忘记终点，会被"终点前还有很晚的 `T`"反例击败（`T 5000` 应输出 $1000$）。
- **explore its property** — 把终点当作虚拟位置事件；同刻同位置的多条记录各算一次失误。
- **consider easier version** — 同刻事件之间无时间、无位移 ⇒ 顺序无关，只需保证一条不漏。
- **classic problem solution** — 分段匀速模拟 + 每段用 $(D-x)(k+1)$ 算时间；最后 $\lfloor t+\tfrac12\rfloor$ 取整。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 说明 |
|------|------|-------------|
| $N$ | 失误记录条数 | 输入 |
| `T[ ]` | 所有 `T` 记录的时间，升序 | 读入后 `sort`；`nt` 为个数 |
| `D[ ]` | 所有 `D` 记录的位置，升序 | 读入后 `sort`；`nd` 为个数 |
| `nt,nd` | `T`、`D` 的记录数 | 初值 $0$ |
| `t` | 当前时刻 | `long double`，初值 $0$ |
| `x` | 当前位置（米） | `long double`，初值 $0$ |
| `cnt` | 已发生的失误次数 $k$ | 初值 $0$ |
| `i` | 下一条未处理的 `T` 下标 | 初值 $0$ |
| `j` | 下一条未处理的 `D` 下标 | 初值 $0$ |
| `arr` | 下一个位置事件（下一个 `D` 或终点）的到达时刻 | 每轮按当前速度重算 |

### 算法步骤

1. 读入 $N$ 与每条记录，按类型分别放入 `T`、`D`。
2. 对 `T`、`D` 分别升序排序。
3. 初始化 `t=x=0`，`cnt=i=j=0`。
4. 当 `x<1000` 循环：
   1. 计算 `arr`：若还有 `D`，`arr=t+(D[j]-x)*(cnt+1)`；否则 `arr=t+(1000-x)*(cnt+1)`。
   2. 若还有 `T` 且 `T[i]<=arr`：`x+=(T[i]-t)/(cnt+1)`，`t=T[i]`，`++i`，`++cnt`。
   3. 否则若还有 `D`：`t=arr`，`x=D[j]`，`++j`，`++cnt`。
   4. 否则（终点）：`t=arr`，`x=1000`。
5. 输出 `(long long)(t+0.5L)`。

### 复杂度

- 时间：$O(N\log N)$（排序），模拟 $O(N)$。
- 空间：$O(N)$。

### 精度说明

总时间上界约 $2.1\times10^7$，`long double`（64 位有效位）每次运算相对误差约 $10^{-19}$；$O(N)$ 次累加后的绝对误差保守估计在 $10^{-7}$ 量级，远小于取整所需的 $0.5$。代码对同刻事件先处理 `T`、下一轮以 $\Delta t=0$ 补处理 `D`，不会漏计。

### 验证状态

- 用 `/d/mingw64/bin/g++.exe -std=c++20 -O2 -Wall -Wextra` 编译通过，无警告。
- 题面 Hint 反推的数据 `2 / T 10 / D 20`：输出 `2970`，与 Hint 的 $10+20+2940$ 一致。
- 手造数据：`T 5000` → `1000`（终点先到）；`T 10` 与 `D 10` 同刻 → `2980`（两次失误）；`T 1`、`T 2` → `2998`（精确值 $2997.5$ 四舍五入）；`D 1000` → `1000`。
- 对拍：随机生成 $N\le8$ 的 `T`/`D` 混合数据（包含大量同刻/同位置与半整数边界），用 `__int128` 精确分数独立模拟并按 $\lfloor t+\frac12\rfloor$ 取整，与标程比对 **3000 组全部一致**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};

int n,nt,nd;
int T[mxn],D[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0,val;i<n;++i)
	{
		char op;
		cin>>op>>val;
		if(op=='T')
			T[nt++]=val;
		else
			D[nd++]=val;
	}
	sort(T,T+nt);
	sort(D,D+nd);
	long double t=0,x=0;
	int cnt=0,i=0,j=0;
	while(x<1000)
	{
		// 下一个事件：要么是到下一个 D 点，要么是到终点
		long double arr=j<nd?t+(D[j]-x)*(cnt+1):t+(1000-x)*(cnt+1);
		if(i<nt&&(long double)T[i]<=arr)
		{
			x+=(T[i]-t)/(cnt+1);
			t=T[i];
			++i;++cnt;
		}
		else if(j<nd)
		{
			t=arr;
			x=D[j];
			++j;++cnt;
		}
		else
		{
			t=arr;
			x=1000;
		}
	}
	cout<<(i64)(t+0.5L)<<'\n';
	return 0;
}
```
