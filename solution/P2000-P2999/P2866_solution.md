# P2866 [USACO06NOV] Bad Hair Day S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 头牛排成一排面朝右（$1\le N\le 8\times10^4$，$1\le h_i\le 10^9$）。第 $i$ 头牛能看到它右边**连续**的一段牛：$i+1,i+2,\dots,j$，要求这段里每一头都**严格矮于** $h_i$；一旦遇到第一头身高 $\ge h_i$ 的牛，视线就被挡住（那头牛本身也看不到）。$C_i$ 是能看到的数量，求 $\sum C_i$。

**第一步：把"看到"刻画成一个位置。** 定义 $\mathrm{nge}(i)=\min\{j>i:h_j\ge h_i\}$（右边第一头"不低于"它的牛），若不存在记 $\mathrm{nge}(i)=N+1$。那么第 $i$ 头牛能看到的恰好是 $i+1,\dots,\mathrm{nge}(i)-1$ 这段连续前缀——因为定义保证这段里所有牛都 $<h_i$，而 $\mathrm{nge}(i)$ 处挡住。于是
$$C_i=\mathrm{nge}(i)-i-1,\qquad \sum_i C_i=\sum_i\bigl(\mathrm{nge}(i)-i-1\bigr).$$
问题被**归约**成：对每个位置求"右边第一个 $\ge$ 自己的元素"（next greater-or-equal，简称 NGE）。注意是 $\ge$ 不是 $>$：题面要求严格矮才可见，所以**等高的牛也挡视线**。这是第一个口径陷阱，手造 $[3,3]$：第一头牛 $C_1=0$（第二头不严格矮），若误用 $>$ 会算成 $1$。

**第二步：暴力为什么不行，范围暗示什么。** 对每个 $i$ 向右扫到第一个 $\ge$，最坏 $O(N^2)=6.4\times10^9$（例如严格递减的身高序列，每头牛都要扫到底）。$N\le8\times10^4$ 这个规模暗示 $O(N\log N)$ 甚至 $O(N)$。NGE 是单调栈的招牌应用，方向基本定了。

**第三步：单调栈怎么摆？两种视角。** 视角 A：从右往左扫，栈里维护"候选阻挡者"，对每个 $i$ 弹掉所有 $<h_i$ 的栈顶，剩下的栈顶就是 $\mathrm{nge}(i)$。视角 B（本题经典写法）：**从左往右扫，在"出栈"的瞬间结算答案**。维护一个身高**严格递减**的栈（存下标）。新牛 $i$ 到来时，把栈顶所有身高 $\le h_i$ 的牛依次弹出——对每头被弹出的牛 $j$，$i$ 就是它的第一个阻挡者，当场累加 $C_j=i-j-1$。扫完后栈里剩下的牛右边再无阻挡者，各累加 $N-j-1$（0-based 即 $n-j-1$）。

为什么视角 B 是对的？关键要证：**牛 $j$ 在时刻 $i$ 被弹出 $\iff i=\mathrm{nge}(j)$**，即弹出时刻恰好是第一个阻挡者，不早不晚。"不早"容易（弹出条件就是 $h_i\ge h_j$）；"不晚"需要一条不变量：$j$ 还留在栈里时，$j$ 与当前位置之间的所有牛都严格矮于 $h_j$——否则 $j$ 早该被某个中间牛弹掉了。这条不变量正是单调栈"严格递减"结构的副产品，下面完整证明。

**第四步：值域陷阱。** $\sum C_i$ 最大能到多少？严格递减序列 $[N,N-1,\dots,1]$ 里 $C_i=N-i$，总和 $N(N-1)/2\approx3.2\times10^9$，**超过 32 位 `int`**（约 $2.1\times10^9$）。必须用 `long long` 累加。身高本身 $\le10^9$，`int` 够用。

**手造数据核对**（按题面规则手算）：

第一组 $h=[5,3,4,2,6]$（$N=5$）：
- $C_1$：$5$ 右边 $3,4,2$ 都 $<5$，到 $6$ 被挡 → $3$；
- $C_2$：$3$ 右边第一个是 $4\ge3$ → $0$；
- $C_3$：$4$ 看到 $2$，被 $6$ 挡 → $1$；
- $C_4$：$2$ 被 $6$ 挡 → $0$；$C_5=0$。总和 $4$。

用视角 B 走一遍（下标 0-based）：压 $0$；$h_1=3<5$ 压 $1$；$h_2=4$：弹 $1$（$3\le4$）加 $2-1-1=0$，压 $2$；$h_3=2$ 压 $3$；$h_4=6$：弹 $3$ 加 $4-3-1=0$，弹 $2$ 加 $4-2-1=1$，弹 $0$ 加 $4-0-1=3$，压 $4$；结束弹 $4$ 加 $5-4-1=0$。总和 $0+0+1+3+0=4$ ✓。

第二组专打等高：$h=[3,3,2]$：$C_1=0$（等高处挡住），$C_2=1$，$C_3=0$，总和 $1$。算法：压 $0$；$h_1=3$：弹 $0$（$3\le3$，**等号必须取到**）加 $1-0-1=0$，压 $1$；$h_2=2$ 压 $2$；结束弹 $2$ 加 $0$、弹 $1$ 加 $3-1-1=1$。总和 $1$ ✓。

## 二、思维链：完整证明

**记号。** 下标 0-based，$0\le i<n$。$\mathrm{nge}(i)=\min\{j>i:h_j\ge h_i\}$，不存在时记 $n$。算法：栈 `stk`（存下标，`top` 为元素个数），从左到右处理 $i$：当栈非空且 $h_{\texttt{stk[top-1]}}\le h_i$ 时弹出栈顶 $j$ 并累加 $i-j-1$；然后把 $i$ 压栈。全部处理完后，依次弹出剩余 $j$ 并累加 $n-j-1$。

---

### 引理 1（可见集是连续前缀，$C_i=\mathrm{nge}(i)-i-1$）

*证明*：按题面，$i$ 能看到 $j>i$ 当且仅当 $h_i>h_k$ 对所有 $i<k\le j$ 成立。设 $p=\mathrm{nge}(i)$。

若 $i<j<p$：由 $p$ 的最小性，任何 $i<k\le j<p$ 都不满足 $h_k\ge h_i$，即 $h_k<h_i$，故 $j$ 可见。若 $j\ge p$：取 $k=p\le j$，有 $h_p\ge h_i$，条件破坏，$j$ 不可见。故可见集恰为 $\{i+1,\dots,p-1\}$，大小 $p-i-1$。$p=n$（无阻挡者）时可见集为 $\{i+1,\dots,n-1\}$，大小 $n-i-1$，公式统一成立。证毕。

---

### 引理 2（栈的结构不变量）

处理完前缀 $[0..i]$（即 $i$ 已压栈）后，设栈内下标自底向顶为 $j_1<j_2<\dots<j_k$，则：

(a) $h_{j_1}>h_{j_2}>\dots>h_{j_k}$（严格递减）；

(b) 对每个 $t$，区间 $(j_t,j_{t+1})$ 内的所有下标 $u$（$j_t<u<j_{t+1}$）满足 $h_u<h_{j_t}$；对栈顶 $j_k$，$(j_k,i]$ 内所有 $u$ 满足 $h_u<h_{j_k}$；

(c) 每个下标至多入栈一次、出栈一次。

*证明*：对处理步数归纳。初始栈空，平凡。

设处理 $i$ 之前不变量成立（前缀 $[0..i-1]$）。处理 $i$ 时先执行若干次弹出，再压入 $i$。

**弹出阶段**：每次弹出栈顶的条件是 $h_{\text{顶}}\le h_i$，故**所有被弹元素的身高都 $\le h_i$**。弹出只删栈顶，剩余元素间的相邻关系不变，(a) 保持。设弹出停止时的栈顶为 $j^\*$（若弹空则压入阶段单独处理），停止条件给出 $h_{j^\*}>h_i$。需证 (b) 对 $j^\*$ 的新约束区间 $(j^\*,i]$ 成立。任取 $j^\*<u\le i$：

- $u=i$：$h_i<h_{j^\*}$ ✓。
- $u<i$ 且 $u$ 在**本步**被弹出：弹出条件给出 $h_u\le h_i<h_{j^\*}$ ✓。
- $u<i$ 且 $u$ 在**更早的步** $p<i$ 被弹出：$j^\*$ 活到了步 $i$，故步 $p$ 时 $j^\*$ 已在栈中且位于 $u$ 下方（栈内下标递增）；由当时的 (a)，$h_u<h_{j^\*}$ ✓。
- $u<i$ 且 $u$ 从未入栈：由归纳假设（处理 $i$ 之前），$u$ 落在当时 $u$ 下方最近的栈元素 $j_t$ 的约束区间里，$h_u<h_{j_t}$。因 $j^\*$ 在栈中且 $j^\*<u$，有 $j_t\ge j^\*$：若 $j_t=j^\*$ 则 $h_u<h_{j^\*}$ ✓；若 $j_t>j^\*$ 则 $j_t$ 在本步被弹出（否则它会挡在 $j^\*$ 上面），$h_u<h_{j_t}\le h_i<h_{j^\*}$ ✓。

其余未被弹出、也不相邻于被弹元素的栈元素，其约束区间不变，(b) 自动保持。

**压入阶段**：若栈被弹空，压入 $i$ 后 (a)(b) 都平凡。否则压入 $i$ 后，(a) 需要 $h_{j^\*}>h_i$，正是弹出停止条件 ✓。新栈顶 $i$ 的约束区间 $(i,i]=\varnothing$，平凡 ✓。旧栈顶 $j^\*$ 的约束区间从弹出阶段证好的 $(j^\*,i]$ 收缩为 $(j^\*,i)$（$i$ 自己入栈了），子集当然仍满足 ✓。其余栈元素的约束区间不变。(c)：每步只压入 $i$ 一次，弹出删除的元素不再回来。证毕。

---

### 引理 3（弹出时刻 = 第一个阻挡者）

下标 $j$ 在处理步 $i$ 被弹出 $\iff i=\mathrm{nge}(j)$。

*证明*：

($\Rightarrow$) 设 $j$ 在步 $i$ 被弹出。弹出条件给出 $h_i\ge h_j$。又由引理 2(b)，$j$ 被弹前是栈顶，$(j,i-1]$ 内所有 $u$ 满足 $h_u<h_j$；而 $j$ 在步 $i$ 之前一直在栈里（每下标只入栈一次），说明步 $j+1,\dots,i-1$ 都没有把它弹出。综合：$j<u<i$ 时 $h_u<h_j$，且 $h_i\ge h_j$，故 $i$ 是 $j$ 右边第一个 $\ge h_j$ 的位置，即 $i=\mathrm{nge}(j)$。

($\Leftarrow$) 设 $i=\mathrm{nge}(j)$，即 $h_i\ge h_j$ 且 $j<u<i$ 时 $h_u<h_j$。先证步 $i$ 之前 $j$ 仍在栈中：若 $j$ 曾在步 $p<i$ 被弹出，由 ($\Rightarrow$) 方向（该方向只用了弹出条件与不变量，不依赖本方向）得 $p=\mathrm{nge}(j)=i$，矛盾；$j$ 在步 $j$ 入栈后只可能因弹出离栈，故步 $i$ 开始时 $j$ 在栈中。再证步 $i$ 的弹出会一直弹到 $j$：$j$ 上方的栈元素 $u$ 满足 $u>j$（栈内下标递增）且由引理 2(a) $h_u<h_j\le h_i$，故都满足弹出条件 $\le h_i$，会被逐个弹掉；轮到 $j$ 时 $h_j\le h_i$ 同样满足，$j$ 被弹出。证毕。

---

### 引理 4（结算值正确，总和 = $\sum C_i$）

算法累加的总和恰为 $\sum_{i}C_i$。

*证明*：由引理 3，每个在步 $i<n$ 被弹出的 $j$ 满足 $i=\mathrm{nge}(j)$，累加值 $i-j-1=\mathrm{nge}(j)-j-1=C_j$（引理 1）。扫描结束后仍在栈中的 $j$：它没被任何步弹出，由引理 3 的 ($\Leftarrow$) 逆否，$\mathrm{nge}(j)$ 不存在（否则会在步 $\mathrm{nge}(j)<n$ 被弹），即 $\mathrm{nge}(j)=n$，收尾累加 $n-j-1=C_j$ ✓。由引理 2(c)，每个下标恰好被结算一次（弹出时或收尾时），无重复无遗漏。故总和 $=\sum_j C_j$。证毕。

---

### 引理 5（复杂度与值域）

时间 $O(N)$，空间 $O(N)$；答案必须用 64 位整数。

*证明*：每个下标至多入栈一次、出栈一次（引理 2(c)），每次入/出栈 $O(1)$，外层循环 $N$ 步，总时间 $O(N)$。栈与身高数组各 $O(N)$。

值域：$C_i\le n-1-i$，故 $\sum C_i\le\sum_{i=0}^{n-1}(n-1-i)=n(n-1)/2$。$n=8\times10^4$ 时约 $3.2\times10^9>2^{31}-1\approx2.15\times10^9$，`int` 溢出；且该上界可达（严格递减序列取等），所以 64 位是**必需**而非保险。身高 $\le10^9<2^{31}$，`int` 足够。证毕。

---

### 定理

算法输出 $\sum_{i=1}^{N}C_i$，时间 $O(N)$。

*证明*：引理 1 把答案写成 NGE 距离和；引理 2 建立栈不变量；引理 3 证明弹出时刻恰为 NGE；引理 4 证明每头牛恰好结算一次且结算值正确；引理 5 给出复杂度与值域。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 可见集 = 右边连续前缀，止于第一个 $\ge h_i$ 的牛；等高也挡（严格矮才可见）。
2. **reduce to easier problem** — $\sum C_i=\sum(\mathrm{nge}(i)-i-1)$，归约为"下一个 $\ge$ 元素"（NGE）问题。
3. **consider easier version** — 暴力每头牛向右扫 $O(N^2)=6.4\times10^9$ 超时；$N\le8\times10^4$ 暗示线性/对数级。
4. **classic problem solution** — 单调栈（严格递减），从左往右扫，**出栈瞬间结算**被弹牛的贡献 $i-j-1$。
5. **explore its property** — 栈不变量：栈内相邻下标之间的牛都严格更矮 ⇒ 弹出时刻不早不晚恰为 NGE。
6. **discuss by category** — 收尾 flush 剩余栈（贡献 $n-j-1$）；答案上界 $n(n-1)/2\approx3.2\times10^9$ 必须 `long long`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 牛数，$\le8\times10^4$ | `int` | 读入 |
| `h[i]` | 第 $i$ 头牛身高（0-based），$\le10^9$ | `int[mxn]` | 读入 |
| `stk` | 单调栈，存下标，身高自底向顶严格递减 | `int[mxn]` | 空 |
| `top` | 栈内元素个数 | `int` | $0$；`stk[top-1]` 是栈顶 |
| `ans` | $\sum C_i$，上界 $\approx3.2\times10^9$ | `i64` | $0$，**必须 64 位** |
| `mxn` | $80000+5$ | `constexpr int` | 数组尺寸松弛 |

### 算法步骤

1. I/O 加速三行；读 `n` 与 `h[0..n-1]`。
2. 对 $i=0..n-1$：当 `top>0` 且 `h[stk[top-1]]<=h[i]` 时，弹出 $j$，`ans+=i-j-1`；然后把 $i$ 压栈。
3. 收尾：栈非空就弹出 $j$，`ans+=n-j-1`。
4. 输出 `ans`。

### 复杂度

- 时间 $O(N)$：每下标至多一进一出。
- 空间 $O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 $[5,3,4,2,6]$ 输出 $4$、等高数据 $[3,3,2]$ 输出 $1$，均与逐头手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2866 [USACO06NOV] Bad Hair Day S
// 思路：C_i = nge(i)-i-1（右边第一个 >= h_i 的位置）。
//       单调栈从左往右扫，出栈瞬间结算：被弹出的 j 的第一个阻挡者就是当前 i。
//       等高也挡视线 ⇒ 弹出条件是 <=；答案可达 n(n-1)/2 ≈ 3.2e9 ⇒ i64。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{80005};

int n,h[mxn],stk[mxn],top;
i64 ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>h[i];
	for(int i=0;i<n;++i)
	{
		while(top&&h[stk[top-1]]<=h[i])	// 等高也挡：<= 的等号不能丢
		{
			int j=stk[--top];
			ans+=i-j-1;	// j 的可见数在出栈瞬间定格
		}
		stk[top++]=i;
	}
	while(top)	// 右边再无阻挡者：看到队尾
	{
		int j=stk[--top];
		ans+=n-j-1;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 栈存**下标**不存身高：结算贡献需要位置差 $i-j-1$，身高现查 `h[]`。
- 弹出条件 `<=`：题面要求严格矮才可见，等高的牛既看不到也挡视线，等号丢了会把 $[3,3]$ 算错。
- 两个 `while` 分工明确：第一个在扫描中结算"有阻挡者"的牛，第二个收尾结算"看到队尾"的牛；每头牛恰好结算一次。
- `ans` 用 `i64`：$n(n-1)/2$ 在 $n=8\times10^4$ 时约 $3.2\times10^9$，`int` 会静默溢出成负数。
