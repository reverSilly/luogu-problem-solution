# P2313 [HNOI2005] 汤姆的游戏 — 题解

## 一、解题过程：人类思考叙事

题意重述：平面上有 $N$ 个图形，两类：`r` 轴平行矩形，给出的是**一对对角顶点** $(x_1,y_1),(x_2,y_2)$（谁是左下谁是右上完全没说）；`c` 圆，给出圆心 $(x,y)$ 与半径 $r$。另有 $M$ 个点。对每个点，数它落在多少个图形**内部**。落在边界上不算内部。所有坐标是实数，$N,M\le 500$。

**先看预算，这一步很关键。** $N,M\le 500$，所以"每个点 $\times$ 每个图形"的暴力是 $500\times500=2.5\times10^5$ 次判定。这个数字小到可以忽略常数——本题**没有任何算法设计空间**：不需要扫描线、不需要 KD 树、不需要容斥。既然复杂度不构成问题，题目的全部难度就落在"如何把一个点是否在图形内部**判对**"上。这也解释了为什么它被标成"计算几何 + 枚举"：几何是判定的细节，枚举是整体的骨架。

于是我把注意力全部转向三个判定细节。

**细节一：矩形的四个数怎么配。** 输入是 `r x1 y1 x2 y2`，而 $(x_1,y_1)$ 与 $(x_2,y_2)$ 是**一对对角顶点**。这意味着：
- 两个 $x$ 坐标是 $x_1,x_2$（第 1、3 个数），两个 $y$ 坐标是 $y_1,y_2$（第 2、4 个数）——**不是**"前两个是 $x$、后两个是 $y$"；
- 而且这两个对角顶点谁在左下、谁在右上都没有保证，$x_1>x_2$ 或 $y_1>y_2$ 完全可能。

所以我必须先把 $x$ 归一到 $[\min(x_1,x_2),\max(x_1,x_2)]$、$y$ 归一到 $[\min(y_1,y_2),\max(y_1,y_2)]$，再判定。这是这题最容易写错的地方（我第一次写对拍暴力时就是把四个数按输入顺序存成 `x1,y1,x2,y2` 再用，立刻在随机数据上炸了——见第四节的验证记录）。

另一个等价写法是符号法：$x$ 严格在 $x_1,x_2$ 之间 $\iff (x-x_1)(x-x_2)<0$，不需要 $\min/\max$，也不怕顺序。两种写法都对，我最终用 $\min/\max$（更好读），并在对拍里用符号法当独立实现。

**细节二："边界不算内部"必须用严格不等号，而且绝不能加 eps。** 题面写得很明确："当某点在一个图形的边界上时，我们认为该点不在这个图形的内部"。所以矩形要写 $\min x<x<\max x$ 且 $\min y<y<\max y$；圆要写严格小于。如果为了"浮点安全"加一个 $\varepsilon$，把"$|d-r|<\varepsilon$ 视作在圆上"甚至把"$d<r+\varepsilon$"判进去，方向就**反了**：那等于把边界点算成内部，正好与题意冲突。eps 在这里不是保护，是 bug 源。

**细节三：圆用平方距离，不开方。** $d^2=dx^2+dy^2<r^2$ 与 $\sqrt{dx^2+dy^2}<r$ 等价（两边都非负），省一次开方，也避免了开方的额外舍入。

**精度用什么？** 只做乘法与比较，`double` 的 53 位尾数在很多数据下够用；但既然要判"恰好相等"的边界，用 `long double`（x86 上是 80 位、64 位尾数）更稳，代价为零，所以我用了 `long double`。

**输入的小坑。** 每行先是一个字母（`cin >> char` 会跳过空白，正合适），然后是 4 个或 3 个实数；点的坐标是两个实数。读数时不要用 `getline` 折腾，直接 `cin` 流式读最省事。

**整理成算法：** 读入 $N$ 个图形（矩形归一化），然后对每个点遍历所有图形累加"是否严格在内部"的 0/1 判定，输出计数。

## 二、思维链：完整证明

**引理 1（矩形 = 两个区间的乘积）**：设矩形的对角顶点为 $(x_1,y_1)$、$(x_2,y_2)$，则矩形（含边界的闭区域）恰为
$$R=\{(x,y):\ \min(x_1,x_2)\le x\le\max(x_1,x_2),\ \min(y_1,y_2)\le y\le\max(y_1,y_2)\}.$$

*证明*：轴平行矩形的四条边分别落在 $x=x_1$、$x=x_2$、$y=y_1$、$y=y_2$ 四条直线上（因为顶点就是这些直线两两的交点）。已知 $(x_1,y_1)$、$(x_2,y_2)$ 是对角，则另外两个顶点必为 $(x_1,y_2)$ 与 $(x_2,y_1)$：它们必须同时落在一条竖边（$x=x_1$ 或 $x=x_2$）和一条横边（$y=y_1$ 或 $y=y_2$）上。于是矩形就是"$x$ 落在两条竖边之间"与"$y$ 落在两条横边之间"的交，即上式。把 $\min/\max$ 写成区间形式只是为了不依赖两个顶点谁大。证毕。

**引理 2（严格不等式 ⟺ 内部，边界被排除）**：点在矩形内部（不含边界）$\iff$
$$\min(x_1,x_2)<x<\max(x_1,x_2)\quad\text{且}\quad\min(y_1,y_2)<y<\max(y_1,y_2).$$

*证明*：由引理 1，点在闭矩形内 $\iff$ 四个非严格不等式成立。闭矩形 = 内部 $\cup$ 边界，而点在边界上 $\iff$ 它满足四个非严格不等式且至少有一个取等号（取等即落在某条边上；反之落在边上则对应坐标等于边所在直线的坐标）。于是"在内部"= "四个非严格都成立且没有等号" = 四个严格不等式成立。证毕。

（顺带说明退化情形：若 $x_1=x_2$，则 $\min=\max$，严格不等式无解，判定的结果恒为"不在内部"，与"零宽矩形没有内部"一致。）

**引理 3（符号法等价）**：对任意实数 $x,x_1,x_2$，$(x-x_1)(x-x_2)<0\iff x$ 严格介于 $x_1,x_2$ 之间。

*证明*：两数之积为负 $\iff$ 两因子异号 $\iff$（不妨 $x_1<x_2$）$x-x_1>0$ 且 $x-x_2<0$，或 $x-x_1<0$ 且 $x-x_2>0$；后一种与 $x_1<x_2$ 矛盾，前一种即 $x_1<x<x_2$。$x_1>x_2$ 时对称。若 $x=x_1$ 或 $x=x_2$ 则积为 $0$，不满足严格小于。证毕。

（这条引理说明"符号法"与"$\min/\max$ 法"给出同一判定，只是前者不需要归一化；我在对拍里用它作为独立实现。）

**引理 4（圆内部 = 平方距离小于半径平方）**：点 $P$ 在以 $O$ 为心、$r>0$ 为半径的圆内部（不含圆周）$\iff |PO|^2<r^2$。且 $|PO|^2=(P_x-O_x)^2+(P_y-O_y)^2$ 只含乘法。

*证明*：$\sqrt{\cdot}$ 在 $[0,+\infty)$ 上严格递增，故 $|PO|^2<r^2\iff\sqrt{|PO|^2}<\sqrt{r^2}\iff|PO|<r$（这里用了 $|PO|\ge0$、$r\ge0$）。而 $|PO|<r$ 按定义就是"在开圆盘内"。平方距离由勾股定理给出，仅需两次乘法与一次加法。证毕。

（$r=0$ 时右边为 $0$，条件变成 $|PO|^2<0$，恒假，与"半径为零的圆没有内部"一致，无需特判。）

**引理 5（累加即计数）**：设 $I_j(P)=\mathbf{1}[P\text{ 在图形 }j\text{ 内部}]$，则 $\sum_{j=1}^{N}I_j(P)$ 恰为"包含 $P$ 的图形个数"。

*证明*：题目要的是"点 $P$ 在多少个图形内部"，即集合 $\{j:P\in\text{内部}(G_j)\}$ 的基数；指示变量之和正是该集合的基数（每个满足条件的 $j$ 贡献 $1$，否则贡献 $0$）。证毕。

**引理 6（复杂度）**：时间 $O(NM)$，空间 $O(N)$。

*证明*：每个点遍历 $N$ 个图形，每个图形 $O(1)$ 次比较/乘法，共 $O(NM)$；存储 $N$ 个图形的类型与参数，$O(N)$。取 $N=M=500$ 得 $2.5\times10^5$ 次判定。证毕。

**定理**：程序对每个点输出的计数正确。

*证明*：由引理 1、2（矩形）与引理 4（圆），每个 $I_j(P)$ 的取值与"$P$ 严格在图形 $j$ 内部"完全一致（边界的处理由引理 2 的严格不等号与引理 4 的严格小于保证，与题面"边界不算内部"一致）；由引理 5，求和即为所求计数；由引理 6，算法在时限内完成。证毕。

**备注（精度）**：判定只用 $+,-,\times$ 与比较。`long double` 有 64 位尾数，相对误差约 $10^{-19}$；坐标是有限位小数，平方运算的绝对误差量级为 $|坐标|^2\cdot10^{-19}$。要误判一个点，必须让 $|PO|^2-r^2$ 落在这个量级内，即点几乎精确贴在边界上——而有限位小数的输入几乎不会制造这种"恰好差 $10^{-18}$"的样例；若真的输入了边界点，同样的十进制字面量解析成同样的浮点数，$(x-x_1)(x-x_2)$ 或 $dx^2+dy^2-r^2$ 通常也精确抵消。因此用严格比较、不加 eps 是正确做法（加 eps 反而会把边界点算进内部，违反题意）。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 先算预算：$N,M\le500\Rightarrow 2.5\times10^5$ 次判定 ⇒ 本题是"纯判定 + 枚举"，没有算法空间。
2. **explore its property** — 矩形给的是一对**对角**顶点且顺序任意 ⇒ 必须先把 $x$、$y$ 各自归一到 $\min/\max$（$x$ 取第 1、3 个数，$y$ 取第 2、4 个数）。
3. **explore its property** — "边界不算内部" ⇒ 一切用严格不等式；**禁止 eps**（加 eps 会把边界算进去，方向正好反了）。
4. **reduce to easier problem** — 圆判定化为平方距离比较 $\Rightarrow$ 去掉 `sqrt`，只留乘法。
5. **discuss by category** — 按图形类型分两支：矩形（两个区间）与圆（一个开圆盘）。
6. **classic problem solution** — 符号法 $(x-x_1)(x-x_2)<0$ 作为"免归一化"的等价判定，用作对拍的独立实现。
7. **工程细节** — `cin >> char` 读类型再流式读实数；用 `long double` 提升边界判定的稳健性。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| $N$ | 图形个数 | `int`，读入 |
| $M$ | 点数 | `int`，读入 |
| `ty[i]` | 第 $i$ 个图形的类型，`'r'` 或 `'c'` | `char ty[mxn]`，读入 |
| `g[i][0],g[i][1]` | 矩形：$x$ 的下界与上界（已归一化）；圆：圆心的横坐标与纵坐标 | `long double g[mxn][4]`，读入时算好 |
| `g[i][2],g[i][3]` | 矩形：$y$ 的下界与上界；圆：半径 $r$（`g[i][3]` 空闲） | 同上 |
| $x,y$ | 当前点的坐标 | `long double`，循环内局部 |
| $ans$ | 当前点被多少个图形严格包含 | `int`，每个点重置为 $0$ |

记忆点：矩形存在 `g[i][0..3]` 里当"两个闭区间"用；圆存在 `g[i][0..2]` 里当"圆心 + 半径"用，两者共用同一张表但语义按 `ty[i]` 分派。

### 算法步骤

1. 读入 $N,M$。
2. 对 $i=0..N-1$：读类型字符；若为 `'r'`，读 $x_1,y_1,x_2,y_2$，存 `g[i][0]=min(x1,x2)`、`g[i][1]=max(x1,x2)`、`g[i][2]=min(y1,y2)`、`g[i][3]=max(y1,y2)`；若为 `'c'`，读 $x,y,r$ 存进 `g[i][0..2]`。
3. 对每个点：读 $x,y$，`ans=0`；遍历 $i=0..N-1$：
   - `'r'`：若 `g[i][0]<x && x<g[i][1] && g[i][2]<y && y<g[i][3]` 则 `++ans`；
   - `'c'`：令 $dx=x-g[i][0]$、$dy=y-g[i][1]$，若 $dx^2+dy^2<g[i][2]^2$ 则 `++ans`。
4. 输出 `ans`，处理下一个点。

### 复杂度

- 时间：$O(NM)$，最坏 $2.5\times10^5$ 次 O(1) 判定。
- 空间：$O(N)$（`ty`、`g` 各 $N$；`mxn{505}` 为 $500$ 加松弛）。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过。
- 本题题面无样例，手造两组小数据人工核对通过：
  - 组一：`3 4`，图形 `r 0 0 2 2`、`c 1 1 1`、`r 2 2 0 0`（第三个故意把对角顶点反序），点 `(0,0)`（矩形角点）、`(1,1)`（圆心）、`(1,1.5)`、`(2,1)`（恰在圆上、也在矩形边上）⇒ 输出 `0 3 3 0`；
  - 组二：`2 4`，图形 `r 0 0 1 2`、`r 2 0 1 3`（第二个 $x$ 反序），点 `(0.5,1)`、`(1.5,1)`、`(1,1)`（落在两矩形公共边上）、`(0.5,2)`（矩形上边）⇒ 输出 `1 1 0 0`。
- 对拍：写了一份**独立实现**的暴力——坐标统一放大 4 倍变整数（生成器保证所有坐标是 $0.25$ 的整数倍，故判定全程精确），矩形用符号法 $(x-x_1)(x-x_2)<0$、圆用开方比较；随机 $N\le8$、$M\le10$，其中一半的点**故意放在边界上**（边、角、圆周），跑 **300 组**，与标程输出完全一致。（这份暴力的第一版把四个数按输入顺序当成 $x_1,y_1,x_2,y_2$ 直接配对，随机数据第一组就炸了——正好印证"对角顶点的配对与顺序"是真坑。）（这份暴力的第一版把四个数按输入顺序当成 $x_1,y_1,x_2,y_2$ 直接配对，随机数据第一组就炸了——正好印证"对角顶点的配对与顺序"是真坑。）

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2313 [HNOI2005] 汤姆的游戏
// N,M<=500 => 每个点枚举每个图形，2.5e5 次判定，难点全在判定本身：
//   矩形：给的是一对「对角」顶点，顺序任意 => 先归一成 min/max 两个区间
//   圆  ：平方距离比较，不开方
//   边界不算内部 => 一律严格不等号，禁止 eps（加 eps 会把边界算进去，方向反了）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{505};

int n,m;
char ty[mxn];			//'r' 矩形 / 'c' 圆
long double g[mxn][4];	//矩形：g[0],g[1] 是 x 的下界/上界，g[2],g[3] 是 y 的下界/上界；圆：g[0],g[1] 圆心，g[2] 半径

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
	{
		cin>>ty[i];
		if(ty[i]=='r')
		{
			long double x1,y1,x2,y2;
			cin>>x1>>y1>>x2>>y2;
			g[i][0]=min(x1,x2);g[i][1]=max(x1,x2);
			g[i][2]=min(y1,y2);g[i][3]=max(y1,y2);
		}
		else
			cin>>g[i][0]>>g[i][1]>>g[i][2];
	}
	for(int j=0;j<m;++j)
	{
		long double x,y;
		cin>>x>>y;
		int ans=0;
		for(int i=0;i<n;++i)
		{
			if(ty[i]=='r')
				ans+=g[i][0]<x&&x<g[i][1]&&g[i][2]<y&&y<g[i][3];
			else
			{
				long double dx=x-g[i][0],dy=y-g[i][1];
				ans+=dx*dx+dy*dy<g[i][2]*g[i][2];	//严格小于：落在圆周上不算内部
			}
		}
		cout<<ans<<'\n';
	}
	return 0;
}
```

### 代码说明

- 矩形归一化只用一次 `min/max`，之后判定就是两个开区间的交集判断；写成 `g[i][0]<x&&x<g[i][1]` 时**两个方向都要严格**，漏掉一个方向就会把两条边算漏/多算。
- 所有比较都不加 eps：题面明确"边界不算内部"，严格不等号正是这个语义。
- 圆用 $dx^2+dy^2<r^2$，`long double` 下既省掉开方也保留更多尾数（坐标量级正常时不会溢出）。
- `ans += bool` 依赖 `bool` 转 `int` 得 0/1，等价于指示变量求和（引理 5）。
- `mxn{505}` 按 $N,M\le500$ 加松弛；`g[i][3]` 对圆不用，读入时不会碰它，无脏值问题。

---

*本题的思维结构是"先确认暴力就是正解，再把全部注意力压到判定的精度与边界语义上"；三个雷点是：对角顶点的配对与顺序、边界必须用严格不等式、以及"为了安全加 eps"其实会把答案判错。*
