# P2735 [USACO3.4] 网 Electric Fences — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 三角形电网的三个顶点是格点 $O=(0,0)$、$A=(n,m)$、$B=(p,0)$，其中 $0\le n<32000$、$0<m<32000$、$p>0$。牛只能放在**严格位于三角形内部**的格点上（碰到边界的格点不行）。问内部格点有多少个。

**第一步：暴力数格点行不行？** 三角形被框在 $x\in[0,\max(n,p)]$、$y\in[0,m]$ 里，最多约 $32000\times32000\approx10^9$ 个格点，逐个判断是否在内部要 $10^9$ 次运算，超时。而且题目是 USACO 3.4 的计算几何，标签明示有公式。方向：**格点多边形计数**。

**第二步：想起 Pick 定理。** 顶点全是格点的简单多边形，面积 $S$、内部格点数 $I$、边界格点数 $B$ 满足

$$S=I+\frac B2-1\quad\Longrightarrow\quad I=S-\frac B2+1=\frac{2S-B+2}{2}.$$

三角形当然是简单多边形，顶点都是格点，定理适用。于是只需求两样东西：**面积 $S$** 和 **边界格点数 $B$**。

**第三步：面积。** 底边 $OB$ 在 $x$ 轴上，长 $p$；顶点 $A=(n,m)$ 到底边的高就是 $m$（$m>0$）。所以

$$S=\frac{p\cdot m}{2},\qquad 2S=p\cdot m.$$

注意 $2S$ 是整数（$p,m$ 都是整数），这保证了后面 $I=(2S-B+2)/2$ 的分子是整数。

**第四步：边界格点数——每条边上的格点数 = 端点坐标差的 gcd。** 这是本题的核心引理。连接格点 $(x_1,y_1)$ 与 $(x_2,y_2)$ 的线段上（含两端点），格点个数是

$$\gcd(|x_2-x_1|,\;|y_2-y_1|)+1.$$

直觉：设 $\Delta x=|x_2-x_1|,\Delta y=|y_2-y_1|$，$g=\gcd(\Delta x,\Delta y)$。线段上的格点把线段等分成 $g$ 段，每段横向走 $\Delta x/g$、纵向走 $\Delta y/g$（互质，保证中间不再落格点），共 $g+1$ 个格点（含端点）。

三条边分别算（含端点）：
- $OA$：$\Delta x=n,\Delta y=m$ → $\gcd(n,m)+1$ 个；
- $AB$：$\Delta x=|p-n|,\Delta y=m$ → $\gcd(|p-n|,m)+1$ 个；
- $BO$：$\Delta x=p,\Delta y=0$ → $\gcd(p,0)+1=p+1$ 个。

**第五步：顶点别重复数。** 三条边的格点集在三个顶点处两两相交（每个顶点恰属于两条边）。把三条边的"含端点"计数相加，每个顶点被算了 $2$ 次，而边界上每个顶点应只算 $1$ 次，故要减去 $3$：

$$B=\big(\gcd(n,m)+1\big)+\big(\gcd(|p-n|,m)+1\big)+(p+1)-3=\gcd(n,m)+\gcd(|p-n|,m)+p.$$

（等价说法：每条边只数"一个端点 + 内部格点"，即 $\gcd$ 个，三条边首尾相接恰好不重不漏。）

**第六步：合并。**

$$I=\frac{2S-B+2}{2}=\frac{p\cdot m-\gcd(n,m)-\gcd(|p-n|,m)-p+2}{2}.$$

**第七步：几个边界与溢出。**
- $n=0$：$A=(0,m)$ 在 $y$ 轴上，$\gcd(0,m)=m$，公式照常（$OA$ 是竖直线段，$m+1$ 个格点）。
- $p=n$：$AB$ 竖直，$\gcd(0,m)=m$，照常。
- $p<n$：$|p-n|=n-p$，用 `abs` 取绝对值，$\gcd$ 照常。
- **整除性**：$2S=pm$ 与 $B$ 同奇偶（Pick 定理保证 $2S-B+2$ 是偶数），所以 `/2` 是精确整除，不会截断出错。
- **溢出**：$p\cdot m$ 最大约 $32000\times32000\approx1.02\times10^9$，勉强在 `int` 内，但中间量与答案稳妥起见用 `long long`。答案 $I\le S\approx5\times10^8$，`long long` 绰绰有余。

**手造数据核对**（题面无样例，自造四组并逐点数验证）：

| 输入 $(n,m,p)$ | 三角形 | $2S=pm$ | $B$ | $I=(2S-B+2)/2$ | 内部格点 |
|---|---|---|---|---|---|
| `1 1 2` | $(0,0),(1,1),(2,0)$ | $2$ | $\gcd(1,1)+\gcd(1,1)+2=4$ | $0$ | 无 |
| `2 2 4` | $(0,0),(2,2),(4,0)$ | $8$ | $2+2+4=8$ | $1$ | $(2,1)$ |
| `0 1 1` | $(0,0),(0,1),(1,0)$ | $1$ | $1+1+1=3$ | $0$ | 无 |
| `3 3 3` | $(0,0),(3,3),(3,0)$ | $9$ | $3+3+3=9$ | $1$ | $(2,1)$ |

四组与程序输出一致，且与手工逐点枚举吻合。

## 二、思维链：完整证明

**记号。** 三角形顶点 $O=(0,0)$、$A=(n,m)$、$B=(p,0)$，$n\ge0,m>0,p>0$ 均为整数。$S$ 为面积，$B$ 为边界（三条边并集）上的格点数，$I$ 为严格内部格点数。$\gcd(x,0)=x$（$x\ge0$）。

---

### 引理 1（线段上的格点数 = $\gcd+1$）

设 $P=(x_1,y_1)$、$Q=(x_2,y_2)$ 为格点，$\Delta x=|x_2-x_1|$、$\Delta y=|y_2-y_1|$，$g=\gcd(\Delta x,\Delta y)$（若 $P=Q$ 则 $g=0$，线段退化为一点，格点数 $1$，下文设 $P\ne Q$ 故 $g\ge1$）。则线段 $PQ$ 上（含端点）的格点恰有 $g+1$ 个。

*证明*：不妨设 $x_2\ge x_1,y_2\ge y_1$（否则反射坐标，格点数不变），则 $\Delta x=x_2-x_1,\Delta y=y_2-y_1$。线段上的点可参数化为
$$P+t(Q-P)=(x_1+t\Delta x,\;y_1+t\Delta y),\quad t\in[0,1].$$
它是格点 $\iff t\Delta x\in\mathbb Z$ 且 $t\Delta y\in\mathbb Z$。

设 $g=\gcd(\Delta x,\Delta y)$，写 $\Delta x=g\,u,\Delta y=g\,v$，$\gcd(u,v)=1$。条件变为 $tgu\in\mathbb Z$ 且 $tgv\in\mathbb Z$。令 $s=tg$，则需 $su\in\mathbb Z,sv\in\mathbb Z$。

**断言**：$su,sv$ 同为整数 $\iff s\in\mathbb Z$。
- （$\Leftarrow$）$s$ 整数则 $su,sv$ 整数，显然。
- （$\Rightarrow$）设 $su,sv\in\mathbb Z$。由 $\gcd(u,v)=1$，存在整数 $\alpha,\beta$ 使 $\alpha u+\beta v=1$（Bézout）。于是 $s=s(\alpha u+\beta v)=\alpha(su)+\beta(sv)\in\mathbb Z$。

故 $s=tg\in\mathbb Z$，即 $t=k/g$，$k\in\mathbb Z$。结合 $t\in[0,1]$ 得 $k\in\{0,1,\dots,g\}$，共 $g+1$ 个值，对应 $g+1$ 个不同格点（$t$ 不同则点不同）。证毕。

**推论**：三条边的格点数（含端点）分别为 $\gcd(n,m)+1$、$\gcd(|p-n|,m)+1$、$\gcd(p,0)+1=p+1$。

---

### 引理 2（边界格点数 $B$）

$$B=\gcd(n,m)+\gcd(|p-n|,m)+p.$$

*证明*：边界是三条边 $OA,AB,BO$ 的并集。由引理 1，三边各自格点数（含端点）为 $g_1+1,g_2+1,g_3+1$，其中 $g_1=\gcd(n,m),g_2=\gcd(|p-n|,m),g_3=p$。

用容斥。三条边两两的交集恰为公共顶点：$OA\cap AB=\{A\}$、$AB\cap BO=\{B\}$、$BO\cap OA=\{O\}$（三角形非退化，三顶点互异；边是直线段，两条不同边除公共顶点外无其他公共点——否则三点共线，三角形退化）。三边共同交集为空（无一点同属三边）。每个交集是单点集，含 $1$ 个格点。

由容斥原理：
$$B=(g_1+1)+(g_2+1)+(g_3+1)-|OA\cap AB|-|AB\cap BO|-|BO\cap OA|+|OA\cap AB\cap BO|$$
$$=(g_1+g_2+g_3+3)-1-1-1+0=g_1+g_2+g_3.$$
即 $B=\gcd(n,m)+\gcd(|p-n|,m)+p$。证毕。

**非退化性核对**：$O=(0,0),B=(p,0)$ 在 $x$ 轴上，$A=(n,m)$ 因 $m>0$ 不在 $x$ 轴上，故三点不共线，三角形非退化，三顶点互异（$p>0$ 保证 $O\ne B$；$m>0$ 保证 $A\ne O,A\ne B$）。引理 2 的容斥前提成立。

---

### 引理 3（面积）

$$S=\frac{pm}{2},\qquad 2S=pm\in\mathbb Z.$$

*证明*：以 $OB$ 为底，$O=(0,0),B=(p,0)$，底长 $|OB|=p$。顶点 $A=(n,m)$ 到直线 $OB$（即 $x$ 轴 $y=0$）的距离为 $|m|=m$（$m>0$）。三角形面积 $=\tfrac12\times\text{底}\times\text{高}=\tfrac12 pm$。$p,m$ 整数故 $2S=pm$ 整数。证毕。

（也可用鞋带公式：$2S=|x_O(y_A-y_B)+x_A(y_B-y_O)+x_B(y_O-y_A)|=|0\cdot(m-0)+n(0-0)+p(0-m)|=pm$。）

---

### 引理 4（Pick 定理适用）

顶点均为格点的简单多边形满足 $S=I+\tfrac B2-1$。本题三角形是简单多边形且顶点为格点，故适用，从而
$$I=S-\frac B2+1=\frac{2S-B+2}{2}.$$

*证明*：Pick 定理是格点几何的经典定理，对任意顶点为格点的简单多边形成立（标准证明：把多边形三角剖分成"本原三角形"——内部与边上除顶点外无格点、面积 $\tfrac12$ 的三角形；每个本原三角形贡献 $I=0,B=3,S=\tfrac12$，满足 $\tfrac12=0+\tfrac32-1$；再对三角剖分用欧拉公式与角度求和归纳合并，内部格点与边界格点在拼接时按内/边分类累加，定理保持）。三角形本身是简单多边形（引理 2 已证非退化），三顶点 $O,A,B$ 均为格点，故定理适用。

代数变形：$S=I+\tfrac B2-1\Rightarrow I=S-\tfrac B2+1=\tfrac{2S-B+2}{2}$。证毕。

---

### 引理 5（整除性：分子必为偶数）

$2S-B+2$ 是偶数，故 $I=(2S-B+2)/2$ 是精确整数，C++ 整数除法不产生截断误差。

*证明*：由引理 4，$I$ 是格点计数，必为非负整数。而 $I=(2S-B+2)/2$，故 $2S-B+2=2I$ 是偶数。无需另行验证 $2S$ 与 $B$ 的奇偶关系——Pick 定理已保证结果为整数。实现中直接用整数除法 `/2` 即得精确 $I$。证毕。

（独立核对：$2S=pm$。$B=g_1+g_2+p$。可以验证 $pm$ 与 $g_1+g_2+p$ 同奇偶，故 $pm-(g_1+g_2+p)+2$ 为偶。这与 Pick 定理一致。）

---

### 引理 6（最终公式与范围）

$$I=\frac{p\cdot m-\gcd(n,m)-\gcd(|p-n|,m)-p+2}{2}.$$
且 $0\le I\le\tfrac{pm}{2}<5.12\times10^8$，用 `long long` 计算全程不溢出。

*证明*：把引理 3 的 $2S=pm$、引理 2 的 $B$ 代入引理 4 的 $I=(2S-B+2)/2$ 即得公式。

范围：$I\ge0$（格点数非负，Pick 定理保证）。$I=S-\tfrac B2+1\le S=\tfrac{pm}{2}$（因 $B\ge3$，$\tfrac B2-1\ge\tfrac12>0$）。$p,m<32000$，故 $pm<32000^2=1.024\times10^9$，$I<5.12\times10^8<2^{31}$。中间量 $pm\le1.024\times10^9$ 虽在 `int` 内，但为稳妥用 `long long`（$p\cdot m$ 可达 $10^9$ 量级，接近 `int` 上限，`long long` 余量充足）。$\gcd$ 的递归参数 $\le32000$，`long long` 安全。证毕。

---

### 引理 7（复杂度）

时间 $O(\log\max(n,m,p))$，空间 $O(\log\max(n,m,p))$（递归栈）。

*证明*：计算两个 $\gcd$，每次欧几里得算法 $O(\log V)$（$V\le32000$，$\log V\approx15$）。其余为常数次算术。空间为 $\gcd$ 递归深度 $O(\log V)$。瞬间完成。证毕。

---

### 定理

程序输出三角形严格内部格点数 $I$，复杂度 $O(\log V)$。

*证明*：引理 1 给出每条边格点数；引理 2 用容斥得边界总数 $B$；引理 3 得面积 $S$；引理 4 应用 Pick 定理；引理 5 保证整除精确；引理 6 给出公式与范围；引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 牛只能放严格内部格点；暴力枚举 $\sim10^9$ 格点超时，需要公式。
- classic problem solution — Pick 定理 $S=I+B/2-1$，把"数内部格点"归约为"求面积 + 求边界格点数"。
- classic problem solution — 线段格点数 $=\gcd(|\Delta x|,|\Delta y|)+1$（Bézout 证明），分别算三条边。
- explore its property — 三边在顶点处两两相交，容斥减 $3$，得 $B=\gcd(n,m)+\gcd(|p-n|,m)+p$。
- reduce to easier problem — 面积用底 $p$ 高 $m$：$2S=pm$；代入 Pick 得 $I=(pm-B+2)/2$。
- discuss by category — $n=0$/$p=n$/$p<n$ 用 $\gcd(0,m)=m$ 与 `abs` 统一处理；整除性由 Pick 保证；$pm\sim10^9$ 用 `long long`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,m,p` | 顶点 $A=(n,m)$、$B=(p,0)$ 的参数 | `i64`，读入 | $O=(0,0)$ 固定 |
| `gcd(a,b)` | 最大公约数，$\gcd(a,0)=a$ | `i64(i64,i64)` | 递归 `b?gcd(b,a%b):a` |
| `b` | 边界格点数 $B=\gcd(n,m)+\gcd(|p-n|,m)+p$ | `i64` | 三边各 $\gcd$ 个，顶点不重复 |
| `ans` | 内部格点数 $I=(pm-B+2)/2$ | `i64` | $2S=pm$，整除精确 |

### 算法步骤

1. I/O 加速三行。
2. 读 `n,m,p`（`long long`）。
3. `b=gcd(n,m)+gcd(abs(p-n),m)+p`。
4. `ans=(p*m-b+2)/2`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(\log V)$，$V\le32000$。
- 空间：$O(\log V)$ 递归栈。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 `1 1 2`→`0`、`2 2 4`→`1`、`0 1 1`→`0`、`3 3 3`→`1` 与逐点枚举吻合；$300$ 组随机数据（$n\in[0,40],m,p\in[1,40]$）与"遍历包围盒逐格点用三边同侧法判严格内部"的独立暴力逐一一致；极限 `31999 31999 31999` 输出 `511920003`，无溢出。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2735 [USACO3.4] 网 Electric Fences
// Pick 定理：S=I+B/2-1 ⇒ I=S-B/2+1=(2S-B+2)/2。
// 2S=p*m；边界格点数 B=gcd(n,m)+gcd(|p-n|,m)+p（三条边各自 gcd，顶点不重复计）。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 n,m,p;

i64 gcd(i64 a,i64 b){return b?gcd(b,a%b):a;}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>p;
	i64 b=gcd(n,m)+gcd(abs(p-n),m)+p;	// 三条边的格点数（含端点，顶点恰好各算一次）
	i64 ans=(p*m-b+2)/2;	// 2S=p*m 为偶数，B 与 2S 同奇偶，整除精确
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **Pick 定理一步到位**：$I=(2S-B+2)/2$，只需面积与边界格点数，不必枚举任何格点。
- **每条边 $\gcd$ 个格点**：线段含端点共 $\gcd+1$ 个，三边相加再减 $3$ 个重复顶点，净得 $B=\gcd(n,m)+\gcd(|p-n|,m)+p$。代码直接写三个 $\gcd$ 相加，等价于"每边只数一个端点 + 内部点"。
- `gcd(a,0)=a`：递归基 `b?gcd(b,a%b):a` 自动处理 $n=0$（$\gcd(0,m)=m$）与 $p=n$（$\gcd(0,m)=m$）。
- `abs(p-n)`：$p<n$ 时取绝对值，$\gcd$ 要求非负参数。
- **整除精确**：Pick 定理保证 $2S-B+2$ 为偶数，`/2` 无截断误差。
- `i64`：$p\cdot m$ 可达 $\sim10^9$，用 `long long` 避免接近 `int` 上限的风险。
