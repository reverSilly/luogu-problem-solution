# P2660 zzc 种田 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一块 $x\times y$ 的矩形田地（$1\le x,y\le10^{16}$），每次种一个**正方形**，体力消耗等于该正方形的**周长**，种过的地方不能再种。要用若干正方形**恰好铺满**整块田，求最小总体力。

总体力 $=\sum 4s_i=4\sum s_i$（$s_i$ 是各正方形边长）。所以问题等价于：**把 $x\times y$ 矩形剖分成若干正方形，最小化边长之和 $S=\sum s_i$**，答案再乘 $4$。

**第一反应：贪心切最大正方形。** 矩形里能放的最大正方形边长是短边 $\min(x,y)$。设 $x\ge y$，先从左边切一个 $y\times y$，剩下 $(x-y)\times y$；继续切……这正是**辗转相除**（欧几里得算法）的几何版！而且一次可以切 $\lfloor x/y\rfloor$ 个 $y\times y$（它们并排占满 $x$ 方向的前 $y\lfloor x/y\rfloor$ 长度），剩下 $(x\bmod y)\times y$，再交换长宽递归。

**第二步：算算贪心的边长和，发现惊人规律。** 手算几组：

- $5\times3$：切 $3$（剩 $2\times3$）→ 切 $2$（剩 $2\times1$）→ 切两个 $1$。$S=3+2+1+1=7$。而 $x+y-\gcd=5+3-1=7$。
- $6\times4$：切 $4$（剩 $2\times4$）→ 切两个 $2$。$S=4+2+2=8$。$x+y-\gcd=6+4-2=8$。
- $13\times11$：$S=11+2\cdot? $……辗转相除 $13=1\cdot11+2,\ 11=5\cdot2+1,\ 2=2\cdot1$，$S=11+5\cdot2+2\cdot1=11+10+2=23$。$x+y-\gcd=13+11-1=23$。
- $x\times x$：一个正方形，$S=x$；$x+y-\gcd=2x-x=x$。

全都吻合！于是猜想：**贪心边长和 $S=x+y-\gcd(x,y)$**，答案 $=4(x+y-\gcd(x,y))$。这个闭式可以用归纳严格证明（第二部分引理 2）：辗转相除每步 $x=qy+r$ 贡献 $qy$，而 $\gcd(y,r)=\gcd(x,y)$， telescoping 后恰好剩 $x+y-\gcd$。

**第三步：贪心真的最优吗？这是本题唯一需要小心的地方。** 公式漂亮，但"每次切最大正方形"凭什么最优？会不会有一种"不切最大、巧妙拼接"的铺法边长和更小？我需要一个**下界**证明：任何铺法都有 $S\ge x+y-\gcd(x,y)$。

设 $x\ge y$，$g=\gcd(x,y)$。分两种情况：

- **情况 A：存在边长恰为 $y$ 的正方形。** 它占满整个高度，把矩形切成左右两条独立的全高矩形。于是 $S=y+S_{\text{左}}+S_{\text{右}}$，左右两条拼起来是 $(x-y)\times y$ 的一个铺法，由归纳 $S_{\text{左}}+S_{\text{右}}\ge(x-y)+y-\gcd(x-y,y)=x-g$。故 $S\ge y+x-g=x+y-g$。
- **情况 B：所有正方形边长都 $<y$。** 这时没有正方形能"占满高度"或"占满宽度"，所以**每个正方形至多贴着矩形的两条边，且贴两条当且仅当它在某个角上**。把四条边各自被贴的正方形边长加起来：底边 $=x$、顶边 $=x$、左边 $=y$、右边 $=y$，合计 $2x+2y$。另一方面这个合计 $=\sum_i s_i\cdot(\text{正方形 }i\text{ 贴的边数})=2C+E$，其中 $C$ 是四个角正方形边长和、$E$ 是贴一条边的正方形边长和。而 $S=C+E+I\ge C+E$（$I$ 是内部正方形），所以 $2x+2y=2C+E=C+(C+E)\le C+S$，即 $S\ge2x+2y-C$。又左上角 $+$ 左下角 $\le y$（左边总长），右上角 $+$ 右下角 $\le y$，故 $C\le2y$，得 $S\ge2x$。因 $x\ge y$，$2x\ge x+y\ge x+y-g$。

两种情况都给出 $S\ge x+y-g$，而贪心恰好取到等号 ⇒ **贪心最优，公式成立**。情况 B 的"边计数"是本题最漂亮的一步：它把"所有正方形都偏小"这种看似灵活的情形，用四条边的总长一举卡死。

**第四步：实现与溢出。** 有了闭式，代码就是一行 `4*(x+y-gcd(x,y))`。$x,y\le10^{16}$，$x+y\le2\times10^{16}$，乘 $4$ 得 $8\times10^{16}$，远小于 `long long` 上限 $9.22\times10^{18}$，`i64` 安全。`gcd` 用辗转相除 $O(\log)$。

**手造数据核对**（题面无样例）：

- $5\times3\to4\cdot7=28$；$1\times1\to4$；$2\times1\to4\cdot2=8$；$6\times4\to4\cdot8=32$；$13\times11\to4\cdot23=92$。
- 极限 $10^{16}\times10^{16}\to4\cdot(2\times10^{16}-10^{16})=4\times10^{16}$。

程序输出与手算逐条吻合。另外，因为"贪心最优"是本题性质最隐蔽的一环，我写了一个**穷举所有正方形铺法**的独立暴力（记忆化 + 分支限界），对 $1\le x,y\le8$ 的**全部 $64$ 组矩形**验证最小边长和恰为 $x+y-\gcd$，$0$ mismatch——这为下界证明提供了坚实的实证支撑。

## 二、思维链：完整证明

**记号与模型。** 田地是 $x\times y$ 矩形（$x,y$ 正整数）。铺法 $=$ 把矩形剖分成有限个**轴对齐**正方形（矩形的直角强迫角上正方形轴对齐，进而传播到全体），边长 $s_1,\dots,s_k>0$，$\sum s_i^2=xy$（面积），体力 $=4S$，$S=\sum s_i$。记 $\mathrm{OPT}(x,y)=\min S$，$g=\gcd(x,y)$。不妨设 $x\ge y$（对称）。

---

### 引理 1（目标归约）

最小体力 $=4\cdot\mathrm{OPT}(x,y)$，其中 $\mathrm{OPT}(x,y)$ 是正方形剖分的最小边长和。

*证明*：每个正方形周长 $4s_i$，总体力 $\sum4s_i=4\sum s_i=4S$。铺法合法当且仅当正方形恰好铺满矩形（不重不漏），即 $\sum s_i^2=xy$ 且几何上无重叠无空隙。最小化 $4S$ 等价于最小化 $S$。证毕。

---

### 引理 2（贪心可达：$S_{\text{greedy}}=x+y-\gcd(x,y)$）

定义贪心：$x\ge y>0$ 时切 $\lfloor x/y\rfloor$ 个边长 $y$ 的正方形，余 $(x\bmod y)\times y$ 递归；$G(x,0)=0$。即
$$G(x,y)=y\Big\lfloor\frac{x}{y}\Big\rfloor+G(y,\ x\bmod y)\quad(x\ge y>0).$$
则对 $x,y>0$，$G(x,y)=x+y-\gcd(x,y)$；且 $G(x,0)=0$。

*证明*：对 $x+y$ 强归纳。不妨 $x\ge y$。设 $x=qy+r$，$0\le r<y$。

**$r=0$**：$G(x,y)=qy+G(y,0)=qy=x$。而 $\gcd(x,y)=y$（因 $y\mid x$），$x+y-\gcd=x+y-y=x$。相等 ✓。

**$r>0$**：$G(x,y)=qy+G(y,r)$。因 $y+r\le y+(y-1)=2y-1<x+y$（$x>y$ 因 $r>0$ 且 $x\ge y$，若 $x=y$ 则 $r=0$），归纳假设适用：$G(y,r)=y+r-\gcd(y,r)$。由欧几里得 $\gcd(y,r)=\gcd(y,x\bmod y)=\gcd(x,y)=g$。故
$$G(x,y)=qy+y+r-g=(q+1)y+r-g.$$
而 $x+y-g=qy+r+y-g=(q+1)y+r-g$。相等 ✓。

**边界** $G(x,0)=0=x+0-\gcd(x,0)=x-x=0$ ✓。证毕。

**推论**：$\mathrm{OPT}(x,y)\le x+y-g$（贪心是一个合法铺法）。

---

### 引理 3（边计数下界：所有正方形边长 $<y$ 时 $S\ge2x$）

设 $x\ge y$，某铺法的所有正方形边长 $<y$。则 $S\ge2x$。

*证明*：因每个 $s_i<y\le x$，没有正方形能占满高度 $y$（需 $s_i=y$）或宽度 $x$（需 $s_i=x$）。故每个正方形**至多贴一条水平边（底或顶）和至多一条竖直边（左或右）**，即至多贴 $2$ 条边；贴 $2$ 条当且仅当它位于某个角（同时贴一水平一竖直）。四个角各由一个正方形覆盖，且因 $s_i<x,y$，四个角正方形互不相同。

记 $C=$ 四个角正方形边长和，$E=$ 恰贴一条边的正方形边长和，$I=$ 不贴边（内部）正方形边长和。则 $S=C+E+I$。

**按边求和**：底边被贴它的正方形的底边不重不漏地划分，故这些正方形边长和 $=x$；顶边同理 $=x$；左边 $=y$；右边 $=y$。四边合计 $2x+2y$。

**按正方形求和**：每个正方形被计入它所贴的每条边，故四边合计 $=\sum_i s_i\cdot(\text{贴边数})=2C+1\cdot E+0\cdot I=2C+E$。

两式相等：$2x+2y=2C+E$。又 $2C+E=C+(C+E)\le C+(C+E+I)=C+S$（因 $I\ge0$）。故
$$S\ge2x+2y-C.$$
左边总长 $y$ 被左上角、左下角及其它左边正方形划分，故左上 $+$ 左下 $\le y$；同理右上 $+$ 右下 $\le y$。于是 $C\le2y$，代入得 $S\ge2x+2y-2y=2x$。证毕。

**注**：此论证对实数边长也成立，不依赖整数性。

---

### 引理 4（全高正方形分解）

设 $x\ge y$，某铺法含一个边长 $y$ 的正方形。则 $S\ge y+\mathrm{OPT}(x-y,y)$。

*证明*：边长 $y$ 的正方形占满高度 $[0,y]$，设其水平位置 $[t,t+y]$。它把矩形分成左条 $[0,t]\times[0,y]$（$t\times y$）与右条 $[t+y,x]\times[0,y]$（$(x-t-y)\times y$）。因该正方形占满高度，任何其它正方形不能跨越它的左右竖直边（否则会与它重叠或超出矩形），故左条、右条各自被独立铺满。于是 $S=y+S_{\text{左}}+S_{\text{右}}$。

左条与右条都是全高 $y$ 的矩形，把它们并排拼接得到 $(t+(x-t-y))\times y=(x-y)\times y$ 的一个合法铺法，其边长和 $=S_{\text{左}}+S_{\text{右}}$。由 $\mathrm{OPT}$ 的最小性，$S_{\text{左}}+S_{\text{右}}\ge\mathrm{OPT}(x-y,y)$。故 $S\ge y+\mathrm{OPT}(x-y,y)$。证毕。

---

### 引理 5（下界：$\mathrm{OPT}(x,y)\ge x+y-\gcd(x,y)$）

对任意正整数 $x,y$，$\mathrm{OPT}(x,y)\ge x+y-\gcd(x,y)$。

*证明*：对面积 $xy$ 强归纳，不妨 $x\ge y$，$g=\gcd(x,y)$。

**基例 $x=y$**：面积约束 $\sum s_i^2=x^2$，每个 $s_i\le x$，故 $S=\sum s_i\ge\sum s_i^2/x=x^2/x=x$。而 $x+y-g=2x-x=x$。$S\ge x$ ✓。

**归纳步 $x>y$**：任取一铺法，分两种情况。
- **含边长 $y$ 的正方形**：由引理 4，$S\ge y+\mathrm{OPT}(x-y,y)$。因 $(x-y)y<xy$（$y>0$），归纳假设给出 $\mathrm{OPT}(x-y,y)\ge(x-y)+y-\gcd(x-y,y)=x-g$（$\gcd(x-y,y)=\gcd(x,y)=g$）。故 $S\ge y+x-g=x+y-g$ ✓。
- **所有正方形边长 $<y$**：由引理 3，$S\ge2x$。因 $x\ge y$ 且 $g\ge1>0$，$2x=x+x\ge x+y> x+y-g$，故 $S\ge x+y-g$ ✓。

两情况穷尽（要么有边长 $y$ 者，要么全部 $<y$；不可能有 $>y$ 者因短边为 $y$）。故对该铺法 $S\ge x+y-g$，对最小值亦然。证毕。

---

### 引理 6（闭式、`gcd` 与溢出）

$\mathrm{OPT}(x,y)=x+y-\gcd(x,y)$，答案 $=4(x+y-\gcd(x,y))$；`i64` 存储安全，`gcd` 辗转相除正确且 $O(\log\min(x,y))$。

*证明*：引理 2 给 $\mathrm{OPT}\le x+y-g$，引理 5 给 $\mathrm{OPT}\ge x+y-g$，夹逼得等式。答案 $=4\mathrm{OPT}$（引理 1）。

溢出：$x,y\le10^{16}$，$x+y\le2\times10^{16}$，$g\ge1$，故 $x+y-g<2\times10^{16}$，$4(x+y-g)<8\times10^{16}$。`i64` 上限 $9.22\times10^{18}$，余量约 $115$ 倍，安全。中间量 $x+y$ 亦 $<2^{63}$。

`gcd`：辗转相除 $\gcd(a,b)=\gcd(b,a\bmod b)$，$\gcd(a,0)=a$，由欧几里得算法正确性，每两步至少减半，$O(\log\min(x,y))$。证毕。

---

### 定理

程序输出 $4(x+y-\gcd(x,y))$，等于铺满 $x\times y$ 田地的最小体力；时间 $O(\log\min(x,y))$，空间 $O(1)$（递归栈 $O(\log)$）。

*证明*：引理 1 归约到最小边长和；引理 2 证贪心可达 $x+y-g$；引理 3、4、5 证下界 $x+y-g$；引理 6 得闭式与值域安全。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 体力 $=$ 周长和 $=4\times$ 边长和，问题归约为"正方形剖分最小化 $\sum s_i$"。
- **classic problem solution** — 贪心切最大正方形（边长 $=$ 短边）$=$ 辗转相除的几何版，一次切 $\lfloor x/y\rfloor$ 个。
- **explore its property** — 手算多组发现贪心边长和 $=x+y-\gcd(x,y)$，归纳 telescoping 证明（$\gcd(y,x\bmod y)=\gcd(x,y)$）。
- **discuss by category** — 下界分两类：含短边正方形 ⇒ 全高分解 $+$ 归纳；全部偏小 ⇒ 边计数 $S\ge2x\ge x+y-g$。
- **reduce to easier problem** — 闭式 $4(x+y-\gcd)$ 把几何剖分塌缩成一行 `gcd`，$O(\log)$。
- **explore its property** — 溢出核算：$4\times2\times10^{16}=8\times10^{16}\ll9.2\times10^{18}$，`i64` 安全。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `x,y` | 田地长宽 $\le10^{16}$ | `i64`，读入 | 对称，无需排序 |
| `gcd(x,y)` | 最大公约数 | `i64(i64,i64)` 递归 | 辗转相除，$\gcd(a,0)=a$ |
| `x+y-gcd(x,y)` | 最小边长和 $\mathrm{OPT}$ | `i64` | 贪心可达且为下界 |
| `4*(x+y-gcd)` | 最小体力（答案） | `i64` | 周长 $=4\times$ 边长 |

### 算法步骤

1. I/O 加速三行；读入 `x,y`（`i64`）。
2. 计算 `g=gcd(x,y)`（辗转相除）。
3. 输出 `4*(x+y-g)` 与 `'\n'`。

### 复杂度

- 时间：$O(\log\min(x,y))$（`gcd`），其余 $O(1)$。
- 空间：$O(1)$（`gcd` 递归栈 $O(\log)$，可改迭代为 $O(1)$）。
- 值域：答案 $<8\times10^{16}$，`i64` 安全。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；题面无样例，手算 $5\times3\to28$、$1\times1\to4$、$2\times1\to8$、$6\times4\to32$、$13\times11\to92$、$10^{16}\times10^{16}\to4\times10^{16}$ 全部吻合；因"贪心最优"性质隐蔽，另写穷举所有正方形铺法的独立暴力（记忆化 $+$ 分支限界），对 $1\le x,y\le8$ 全部 $64$ 组矩形验证 $\mathrm{OPT}=x+y-\gcd$，$0$ mismatch。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2660 zzc 种田
// 思路：体力=周长和=4*边长和。贪心切最大正方形=辗转相除，边长和=x+y-gcd(x,y)。
//       下界：含短边正方形⇒全高分解+归纳；全部偏小⇒四边计数 S>=2x>=x+y-gcd。
//       故答案=4*(x+y-gcd(x,y))。x,y<=1e16，4*(x+y)<=8e16，i64 安全。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 gcd(i64 a,i64 b){return b?gcd(b,a%b):a;}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	i64 x,y;
	cin>>x>>y;
	// 最小边长和 = x+y-gcd(x,y)，体力 = 4 倍边长和
	cout<<4*(x+y-gcd(x,y))<<'\n';
	return 0;
}
```

### 代码说明

- **一行闭式**：`4*(x+y-gcd(x,y))`。无需模拟辗转相除切正方形——引理 2 已证贪心边长和 telescoping 成 $x+y-\gcd$，直接算 `gcd` 即可。
- **`gcd` 手写辗转相除**：`b?gcd(b,a%b):a`，$\gcd(a,0)=a$，$O(\log)$；`i64` 参数避免 $10^{16}$ 溢出 `int`。
- **`i64` 全程**：$x,y\le10^{16}$，$x+y\le2\times10^{16}$，$4(x+y)\le8\times10^{16}<9.22\times10^{18}$，安全（引理 6）。若用 `int` 会立刻溢出。
- **对称性**：公式对 $x,y$ 对称，无需 `swap` 保证 $x\ge y$；`gcd` 本身也对称。
- `'\n'` 换行；I/O 三行固定顺序；无全局数组（$O(1)$ 空间）。
