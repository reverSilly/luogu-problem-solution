# P2722 [USACO3.1] 总分 Score Inflation — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 竞赛总时长 $m$（$1\le m\le 10^4$），有 $n$ 类题目（$1\le n\le 10^4$）。第 $i$ 类题每道得分 $p_i$、耗时 $t_i$（$1\le p_i,t_i\le 10^4$）。**同一类题可以重复选任意多道**。求总耗时不超过 $m$ 时的最大总分。

**第一步：抓住"可以重复选择"这句话。** 这是全题的题眼。每类题不是"选或不选"，而是"选 $0,1,2,\dots$ 道"，数量无上界（只受总时间约束）。这正是**完全背包**（unbounded knapsack）的标准模型：物品体积 $t_i$、价值 $p_i$、背包容量 $m$、每件物品无限个。如果误当成 0/1 背包（每类至多一道），就会少算很多分。

**第二步：先回忆 0/1 背包，再看它为什么在这里会错。** 0/1 背包的一维写法是
```
for i: for j=m down to t[i]: dp[j]=max(dp[j],dp[j-t[i]]+p[i]);
```
**倒序**枚举 $j$ 是为了保证 `dp[j-t[i]]` 还是"上一轮（不含物品 $i$）"的值，从而每件物品至多用一次。但本题要重复用，倒序恰恰把这条路堵死了。

举个最小反例：$m=10$，只有一类题 $(p=5,t=3)$。正确答案是选 $3$ 道（耗时 $9\le 10$），得 $15$ 分。若用倒序：`dp[10]=max(dp[10],dp[7]+5)`，而 `dp[7]` 此时还是 $0$（倒序先算大的），于是 `dp[10]=5`——只选了一道，错了。**倒序 = 每类至多一道 = 0/1 背包**，与题意不符。

**第三步：把倒序改成正序，就是完全背包。** 完全背包的一维写法：
```
for i: for j=t[i] to m: dp[j]=max(dp[j],dp[j-t[i]]+p[i]);
```
**正序**枚举 $j$ 时，`dp[j-t[i]]` 已经在同一轮里被更新过（因为 $j-t_i<j$），它**可能已经含有若干道第 $i$ 类题**，于是 `dp[j-t[i]]+p[i]` 就表示"在已含第 $i$ 类的基础上再加一道"，自然允许重复选。这就是 0/1 与完全背包唯一的一行之差：**倒序 vs 正序**。

**第四步：状态语义与初始化。** 我定义 `dp[j]` = 总耗时**不超过** $j$ 的最大得分（"至多"语义，不是"恰好"）。初始 `dp[0..m]=0`：一道题都不选，耗时 $0$、得分 $0$，对任何 $j$ 都合法。因为 $p_i>0$，"至多 $j$"的最优值就是 `dp[j]`，且 `dp` 关于 $j$ 单调不减，最终答案直接是 `dp[m]`，不必再对 $j$ 取 max。全局 `int` 数组默认 $0$，恰好就是合法初值，不用显式填。

**第五步：范围与复杂度。** $n,m\le 10^4$，$O(nm)=10^8$ 次 `max` 转移，C++ `-O2` 下约 $0.1$ 秒，能过。答案上界：全用耗时最小（$t\ge 1$）、得分最大（$p\le 10^4$）的题，至多 $m$ 道，总分 $\le m\times 10^4=10^8<2^{31}$，`int` 安全。$t_i>m$ 的题内层循环 `j=t[i]..m` 直接不执行，自动忽略。

**手造数据核对**（题面无样例）：

| 输入 | 手算 | 输出 |
|---|---|---|
| `10 1` / `5 3` | 选 $3$ 道耗时 $9$，$3\times5=15$ | `15` |
| `9 2` / `6 5` / `5 4` | $5+4=9$ 耗时，$6+5=11$；优于两道 $5$ 分题（$8$ 耗时 $10$ 分） | `11` |
| `10 2` / `5 3` / `4 4` | 三道 $3$ 耗时题 $9\le10$，$15$ 分；混选 $3+3+4=10$ 得 $14$ | `15` |
| `2 1` / `100 5` | $t=5>m=2$，一道都选不了 | `0` |

第二组专门说明"重复选同一类"与"混选不同类"都要考虑，第三组说明重复选可能优于混选。

## 二、思维链：完整证明

**记号。** 容量 $m$，物品（题目类）$i=1..n$，体积 $t_i\ge 1$、价值 $p_i\ge 1$，每件无限个。一个方案是多重集 $\{x_i\ge 0\}$（$x_i$ 为第 $i$ 类选的道的），耗时 $\sum x_i t_i$，得分 $\sum x_i p_i$。定义二维状态
$$D_i[j]=\max\Bigl\{\sum_{k\le i}x_k p_k:\ \sum_{k\le i}x_k t_k\le j,\ x_k\ge 0\Bigr\},$$
即"只用前 $i$ 类、总耗时 $\le j$"的最大得分。一维数组 `dp` 是它的滚动实现。

---

### 引理 1（模型等价）

题目所求 $=D_n[m]$。

*证明*：题目方案 = 每类选若干道（$x_i\ge 0$，无上界），约束总耗时 $\le m$，目标最大化总分。这与 $D_n[m]$ 的定义逐字一致（"可以重复选择" $\Leftrightarrow$ $x_i$ 无上界；"总耗时在规定时间里" $\Leftrightarrow$ $\sum x_i t_i\le m$）。证毕。

---

### 引理 2（完全背包转移，双向夹逼）

$D_0[j]=0$；对 $i\ge 1$，
$$D_i[j]=\begin{cases}D_{i-1}[j],&j<t_i,\\[2pt]\max\bigl(D_{i-1}[j],\ D_i[j-t_i]+p_i\bigr),&j\ge t_i.\end{cases}$$

*证明*：$D_0[j]$：不用任何类，只能 $x=0$，得分 $0$。

$j<t_i$：第 $i$ 类一道都放不下（$x_i\ge 1$ 会使耗时 $\ge t_i>j$），故 $x_i=0$，退化为 $D_{i-1}[j]$。

$j\ge t_i$：按 $x_i=0$ 与 $x_i\ge 1$ 划分方案集合。
- **$x_i=0$**：即只用前 $i-1$ 类、耗时 $\le j$，最大得分 $D_{i-1}[j]$。
- **$x_i\ge 1$**：从方案里拿出一道第 $i$ 类题，剩下仍是"前 $i$ 类、耗时 $\le j-t_i$"的合法方案（第 $i$ 类还可继续出现），其得分 $\le D_i[j-t_i]$；加回这道题得 $D_i[j-t_i]+p_i$。反之，任何"前 $i$ 类、耗时 $\le j-t_i$"的方案加一道第 $i$ 类题，耗时 $\le j$、得分 $+p_i$，合法。故这一支的最大值恰为 $D_i[j-t_i]+p_i$。

两支不交且并为全体，取 max 即得。注意右端是 $D_i$（**同一行**）而非 $D_{i-1}$，这正是"无限个"的体现：拿出/加回一道第 $i$ 类题后，子问题里第 $i$ 类依然可用。证毕。

---

### 引理 3（一维正序滚动实现 $D_i$）

外层 `for i=1..n`、内层 `for j=t[i]..m` **正序**执行 `dp[j]=max(dp[j],dp[j-t[i]]+p[i])`，则第 $i$ 轮结束后 `dp[j]`$=D_i[j]$（$0\le j\le m$）。

*证明*：对 $i$ 归纳。$i=0$：`dp` 全 $0=D_0$ ✓。

设第 $i-1$ 轮后 `dp[j]`$=D_{i-1}[j]$。第 $i$ 轮内层对 $j$ 正序归纳：
- $j<t_i$：不更新，`dp[j]` 保持 $D_{i-1}[j]=D_i[j]$（引理 2 的 $j<t_i$ 分支）✓。
- $j\ge t_i$：执行前，`dp[j]` 尚未在本轮更新，仍是 $D_{i-1}[j]$；而 `dp[j-t[i]]` 因 $j-t_i<j$ **已在本轮更新**，由内层归纳假设等于 $D_i[j-t_i]$。于是 `dp[j]=max(D_{i-1}[j],D_i[j-t_i]+p_i)=D_i[j]`（引理 2）✓。

故第 $i$ 轮结束 `dp[j]`$=D_i[j]$。由外层归纳，第 $n$ 轮后 `dp[m]`$=D_n[m]$。证毕。

**关键对比**：若内层**倒序**，则执行 `dp[j]` 时 `dp[j-t[i]]` 尚未更新，仍是 $D_{i-1}[j-t_i]$，转移变成 $\max(D_{i-1}[j],D_{i-1}[j-t_i]+p_i)$——这是 0/1 背包（每类至多一道），与引理 2 的 $D_i[j-t_i]$ 不同。反例：$m=10,(p,t)=(5,3)$，倒序得 $5$，正序得 $15$（引理 2 要求 $D_i[7]=10$，倒序却用 $D_{i-1}[7]=0$）。

---

### 引理 4（"至多"语义：$0$ 初始化合法、答案 = `dp[m]`）

`dp` 全 $0$ 初始化合法；$D_i[j]$ 关于 $j$ 单调不减；答案 $D_n[m]$ 无需再对 $j$ 取 max。

*证明*：$0$ 初始化：空方案（所有 $x_i=0$）耗时 $0\le j$、得分 $0$，对任何 $j$ 合法，故 $D_i[j]\ge 0$，全 $0$ 是合法下界且 $D_0[j]=0$ 精确。

单调性：$j_1\le j_2$ 时，"耗时 $\le j_1$"的方案集合 $\subseteq$"耗时 $\le j_2$"，在更大集合上取 max 不减，故 $D_i[j_1]\le D_i[j_2]$。

答案：题目要求耗时 $\le m$ 的最大得分 $=D_n[m]$（引理 1），由单调性它已是 $j\le m$ 中最大，不必再扫一遍。证毕。

---

### 引理 5（值域与复杂度）

答案 $\le m\cdot\max p_i\le 10^8$，`int` 安全。时间 $O(nm)$，空间 $O(m)$。

*证明*：值域：每道题耗时 $\ge 1$，故总道数 $\le m$；每道得分 $\le 10^4$，总分 $\le m\times 10^4\le 10^4\times 10^4=10^8<2^{31}-1\approx 2.1\times 10^9$，`int` 不溢出。中间量 `dp[j-t]+p` $\le 10^8+10^4$ 仍安全。

时间：外层 $n$ 轮，第 $i$ 轮内层至多 $m-t_i+1\le m$ 次，每次 $O(1)$，共 $O(nm)\le 10^8$。$t_i>m$ 的轮内层为空，自动忽略。空间：一维 `dp[m+1]`，$O(m)$。证毕。

---

### 定理

程序输出 `dp[m]`$=D_n[m]$，即总耗时 $\le m$ 的最大总分；时间 $O(nm)$，空间 $O(m)$。

*证明*：引理 1 把题目化为 $D_n[m]$；引理 2 给出完全背包转移；引理 3 证明一维正序滚动逐项实现 $D_i$；引理 4 保证 $0$ 初始化与答案位置；引理 5 保证 `int` 与复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "可以重复选择" $\Rightarrow$ 每类数量无上界 $\Rightarrow$ 完全背包（不是 0/1）。
- **consider easier version** — 先回忆 0/1 背包倒序写法，用 $m=10,(5,3)$ 反例确认倒序会少算（只得 $5$ 而非 $15$）。
- **classic problem solution** — 完全背包一维正序：`for j=t[i]..m: dp[j]=max(dp[j],dp[j-t[i]]+p[i])`，正序使 `dp[j-t]` 已含本类、允许重复。
- **explore its property** — "至多 $j$"语义 + $p_i>0$ ⇒ 全 $0$ 初始化合法、`dp` 单调、答案直接 `dp[m]`。
- **discuss by category** — 值域 $m\cdot p_{\max}\le 10^8$ 用 `int`；$t_i>m$ 内层为空自动忽略；$O(nm)=10^8$ 可过。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `m` | 竞赛总时长（容量，$\le 10^4$） | `int`，读入 | 第一行第一个数 |
| `n` | 题目类数（$\le 10^4$） | `int`，读入 | 第一行第二个数 |
| `p,t` | 当前类的得分 / 耗时 | `int`，每轮读入 | 输入顺序是先 $p$ 后 $t$ |
| `dp[j]` | 总耗时 $\le j$ 的最大得分 | `int[mxm]`，全 $0$ | "至多"语义；答案 `dp[m]` |
| `mxm` | $10^4+5$ | `constexpr int` | 容量数组尺寸 |

### 算法步骤

1. I/O 加速三行。
2. 读 `m,n`（注意顺序：先时长后类数）。
3. 对每类 $i$：读 `p,t`；内层 `for j=t..m` **正序**：`dp[j]=max(dp[j],dp[j-t]+p)`。
4. 输出 `dp[m]`。

### 复杂度

- 时间：$O(nm)\le 10^8$，实测极限数据（$n=m=10^4$）约 $0.14$ 秒。
- 空间：$O(m)$，`dp` 约 $40$ KB。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译无警告；$5$ 组手造样例（重复选 / 混选 / 重复优于混选 / $t>m$ / 边界 $m=1$）全部与手算一致；$n=m=10^4$ 极限数据输出 $10^8$ 且 $0.14$ 秒。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2722 [USACO3.1] 总分 Score Inflation
// 完全背包：每类题可选无限次，dp[j]=总耗时不超过 j 的最大得分。
// 正序枚举 j，dp[j-t] 已含本类题 ⇒ 允许重复选（0/1 背包才倒序）。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxm{10005};

int m,n,dp[mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n;
	for(int i=0,p,t;i<n;++i)
	{
		cin>>p>>t;
		for(int j=t;j<=m;++j)
			dp[j]=max(dp[j],dp[j-t]+p);
	}
	cout<<dp[m]<<'\n';
	return 0;
}
```

### 代码说明

- **正序是完全背包的灵魂**：`for(int j=t;j<=m;++j)` 正序，使 `dp[j-t]` 已含本类题，从而允许重复选。改成倒序就退化为 0/1 背包（每类至多一道），本题会错。
- **输入顺序**：第一行先 `m`（时长）后 `n`（类数）；每行先 `p`（得分）后 `t`（耗时），别读反。
- **全 $0$ 初始化**：`dp` 是全局 `int` 数组默认 $0$，恰是"至多 $j$"语义的合法初值（空方案），无需显式填；答案 `dp[m]` 由单调性即最优。
- **$t_i>m$ 自动忽略**：内层 `j=t..m` 当 `t>m` 时为空循环，不必特判。
- **`int` 足够**：答案 $\le m\cdot p_{\max}=10^8<2^{31}$，无需 `long long`。
- 一维滚动数组空间 $O(m)$，时间 $O(nm)$，是本题的标准最优写法。
