# P2433 【深基1-2】小学数学 N 合一 — 题解

## 一、解题过程：人类思考叙事

题目重述：这是一道"提交答案"式的 $14$ 合 $1$。输入一个题号 $T\in[1,14]$，输出对应小题的答案。$14$ 个小题从输出字符串、苹果分配、火车相遇，一直到牛吃草、解一元二次方程，跨度很大。程序本身只是一个 `if/switch` 分发器，**真正的难度全在"每个答案到底是多少、以什么格式输出"**。

我先把 $14$ 题按"需要什么"分成三类：

1. **纯算术/字符串**（1、2、3、7、12）：直接算，几乎没有陷阱。
2. **需要建数学模型**（5、9、10、13、14）：相遇问题、逆推、牛吃草、体积守恒、二次方程。这几题如果模型建错，答案就全错。
3. **需要控制输出精度**（4、6、8、11）：题面反复强调"保留 $6$ 位有效数字""直接使用 `cout` 输出"。这是最容易翻车的一类。

**先踩精度这个坑。** 我一开始想当然地写 `cout<<fixed<<setprecision(6)`，因为"保留 6 位"听起来像 6 位小数。但题面第 4 题写的是"**6 位有效数字**"，第 6、8、11 题写的是"**直接使用 `cout` 输出**"。这两句话含义完全不同：

- `cout` 的默认浮点格式是 `defaultfloat` + 精度 $6$，意思是**6 位有效数字**，不是 6 位小数；
- `fixed<<setprecision(6)` 是**6 位小数**。

拿第 6 题试：对角线 $\sqrt{117}=10.8166538\ldots$。默认 `cout` 给 `10.8167`（6 位有效数字），而 `fixed<<setprecision(6)` 给 `10.816654`（6 位小数）。两者不一样！题面说"直接使用 cout"，所以正确答案是 `10.8167`。**结论：第 4、6、8、11 题一律用裸 `cout`，不要加任何 `fixed`/`setprecision`。** 第 4 题的 $500/3=166.6666\ldots$ 恰好 6 位有效数字是 `166.667`，与裸 `cout` 一致，所以四题可以统一处理。

**再踩 $\pi$ 的坑。** 第 8、13 题明确"取 $\pi=3.141593$"，不是 `acos(-1)`。用真 $\pi$ 会让第 8 题周长变成 `31.4159`→ 仍是 `31.4159`？不，面积 $78.539816\ldots$ 与 $78.539825$ 在第 6 位有效数字上都是 `78.5398`，看似没差；但体积 $523.5987756$ vs $523.5988333$ 也都给 `523.599`。可第 13 题就敏感了：棱长 $16.4567$，取整后都是 $16$。**虽然这几题碰巧对 $\pi$ 不敏感，仍必须严格按题面用 $3.141593$**，否则一旦换数据就错。我把它定义成 `constexpr double pi{3.141593};`。

**第 10 题差点建成正比例。** 直觉是"8 台 30 分钟 ⇒ 每台每分钟效率固定 ⇒ 总量固定 ⇒ 台数×时间恒定"，于是 $8\times30=240$，$10$ 分钟要 $240/10=24$ 台。但题面第二句"10 台 6 分钟"给出 $10\times6=60\ne240$，**直接否定了"总量固定"**。关键句是"评测任务是**单位时间内均匀增加**的"——队列在增长！这是经典**牛吃草**模型：原有草量 $S$、每天长草 $v$、每头牛每天吃 $1$。这里对应"原有队列 $S$、每分钟新增 $v$、每台机每分钟评 $1$"。两个方程解出 $S,v$，再代入 $10$ 分钟即可。

**第 14 题差点只取一个根。** "定价 $110$ 元有 $10$ 人，每降 $1$ 元多 $1$ 人"⇒ 定价 $p$ 时人数 $120-p$，收入 $p(120-p)=3500$。这是开口向下的抛物线，$3500$ 低于顶点 $3600$，所以**有两个根**。题面也明说"有两个答案符合要求，取较小的"。解得 $50$ 和 $70$，取 $50$。还要注意"四舍五入精确到整数"——本题根恰为整数，但代码里仍应写 `round` 以符合题意。

**第 13 题是"舍去"不是"四舍五入"。** 棱长 $16.4567\ldots$，题面说"舍去小数点之后的数字"⇒ 向下取整 $16$。若误用 `round` 会得 $16$（碰巧一样），但若换成别的半径就会错。必须用 `(int)` 截断或 `floor`。

**第 9 题逆推要验证奇偶。** "吃一半再多吃一个"⇒ 剩 $x/2-1$。逆推 $x_{\text{前}}=2(x_{\text{后}}+1)$。从第 4 天的 $1$ 逆推三天得 $22$。但"一半"要求每天开始时的桃子数是**偶数**，否则"刚好一半"无意义。$22,10,4$ 全是偶数，且正向模拟 $22\to10\to4\to1$ 完全吻合，所以 $22$ 合法。

把 $14$ 个答案全部手算/推导并用高精度独立复核后，程序就只剩一个分发器了。

## 二、思维链：完整证明

下面逐题给出**完整推导**。凡涉及建模的，先证模型正确再解；凡涉及精度的，先证输出格式再给值。

### 问题 1：输出字符串

直接输出 `I love Luogu!`。无需证明。

### 问题 2：苹果减法

小 A 拿 $2$、Uim 拿 $4$，共 $2+4=6$；小 B 拿剩下 $10-2-4=4$。输出 `6 4`（空格分隔）。
*正确性*：加法交换律与减法定义，显然。

### 问题 3：带余除法

$14$ 个苹果均分给 $4$ 人，分不掉的放回。由**带余除法唯一性**：存在唯一 $q,r$ 使 $14=4q+r$，$0\le r<4$。计算 $q=\lfloor14/4\rfloor=3$，$r=14-4\times3=2$。
- 每人 $q=3$ 个；
- 共分出 $4q=12$ 个；
- 放回 $r=2$ 个。

输出三行 `3`、`12`、`2`。
*唯一性证明*：若 $14=4q+r=4q'+r'$ 且 $0\le r,r'<4$，则 $4(q-q')=r'-r\in(-4,4)$，左边是 $4$ 的倍数，只能为 $0$，故 $q=q',r=r'$。证毕。

### 问题 4：$500/3$ 保留 6 位有效数字

$500/3=166.\overline{6}$。**有效数字**从左边第一个非零数字起数 $6$ 位：$1,6,6,6,6,6$，第 $7$ 位是 $6\ge5$，故第 $6$ 位进一：$166.667$。
*输出格式证明*：`cout` 默认 `defaultfloat`、精度 $6$，即保留 $6$ 位有效数字且不用科学计数法（数值在 $[10^{-4},10^{6})$ 内时）。$166.667$ 落在此范围，故裸 `cout<<500.0/3` 恰好输出 `166.667`，与题面"保留 6 位有效数字、不使用科学计数法"完全一致。证毕。

### 问题 5：火车相遇（相对运动）

甲长 $260$、速 $12$；乙长 $220$、速 $20$；相向而行。求"车头相遇"到"车尾相离"的时间。

**建模**：设甲车头位置 $h_A(t)=12t$，则甲车尾 $12t-260$；乙车头 $h_B(t)=-20t$（相向），乙车尾 $-20t+220$。$t=0$ 时两车头相遇于原点。两车占据的区间分别为 $[12t-260,\,12t]$ 与 $[-20t,\,-20t+220]$。

**车尾相离的时刻**即两区间不再重叠的时刻，等价于甲车尾追上乙车尾：
$$12t-260=-20t+220\ \Longrightarrow\ 32t=480\ \Longrightarrow\ t=15.$$

**相对运动解释**：以甲为参照，乙以 $12+20=32$ 米/秒接近；从车头相遇到车尾相离，乙相对甲需走过"两车长度之和"$260+220=480$ 米。故 $t=480/32=15$ 秒。两种方法一致。
*输出*：题面说"答案是整数"，$15$ 确为整数，输出 `15`。证毕。

### 问题 6：长方形对角线

长 $9$、宽 $6$，由**勾股定理**对角线 $d=\sqrt{9^2+6^2}=\sqrt{117}=3\sqrt{13}=10.8166538\ldots$。
*输出格式*：题面"直接使用 cout 输出"⇒ 默认 $6$ 位有效数字 ⇒ `10.8167`（第 $7$ 位有效数字是 $5$，进一）。
*勾股定理适用性*：长方形对角线与两邻边构成直角三角形，直角在长方形顶点，故 $d^2=9^2+6^2$。证毕。

### 问题 7：账户余额

初始 $100$。
1. 存 $10$：$100+10=110$；
2. 花 $20$：$110-20=90$；
3. 全取出：$90-90=0$。

每次操作后输出，故三行 `110`、`90`、`0`。
*正确性*：余额是前一步余额加/减操作额，逐步计算即可。证毕。

### 问题 8：圆的周长、面积、球体积（$\pi=3.141593$，$r=5$）

- 周长 $C=2\pi r=2\times3.141593\times5=31.41593$；
- 面积 $A=\pi r^2=3.141593\times25=78.539825$；
- 球体积 $V=\frac43\pi r^3=\frac43\times3.141593\times125=523.5988333\ldots$。

*输出格式*：裸 `cout`（$6$ 位有效数字）：
- $31.41593\to$ `31.4159`（第 $7$ 位 $3<5$，舍）；
- $78.539825\to$ `78.5398`（第 $7$ 位 $2<5$，舍）；
- $523.5988333\to$ `523.599`（第 $7$ 位 $8\ge5$，进）。

三行输出。
*公式适用性*：$C=2\pi r$、$A=\pi r^2$ 是圆的标准公式；$V=\frac43\pi r^3$ 是球体积公式（可由祖暅原理或积分 $\int_{-r}^{r}\pi(r^2-x^2)\,dx=\frac43\pi r^3$ 证明，此处作为已知几何公式使用）。题面指定 $\pi=3.141593$，故必须用此值而非真 $\pi$。证毕。

### 问题 9：猴子吃桃（逆推）

设第 $k$ 天**开始**时有 $x_k$ 个桃。当天吃"一半多一个"，即吃 $\frac{x_k}2+1$，剩
$$x_{k+1}=x_k-\Bigl(\frac{x_k}2+1\Bigr)=\frac{x_k}2-1.$$
已知第 $4$ 天开始剩 $x_4=1$，求 $x_1$。

**逆推公式**：由 $x_{k+1}=\frac{x_k}2-1$ 解出 $x_k=2(x_{k+1}+1)$。
- $x_3=2(1+1)=4$；
- $x_2=2(4+1)=10$；
- $x_1=2(10+1)=22$。

**合法性（偶数性）**：题面"刚好一半"要求 $x_k$ 为偶数。$x_1=22,x_2=10,x_3=4$ 均为偶数，✓。
**正向验证**：$22\to$ 吃 $11+1=12$ 剩 $10$；$10\to$ 吃 $5+1=6$ 剩 $4$；$4\to$ 吃 $2+1=3$ 剩 $1$。与 $x_4=1$ 吻合。
**唯一性**：映射 $x\mapsto x/2-1$ 在偶数上是单射（$x/2-1=y/2-1\Rightarrow x=y$），故逆推唯一。答案 `22`。证毕。

### 问题 10：评测机（牛吃草模型）

**建模**：设初始队列 $S$（单位：台·分钟），每分钟新增 $v$（同单位），每台机每分钟评 $1$ 单位。"刚好评完"意味着"总评测量 = 初始 + 期间新增"：
$$\begin{cases}8\times30=S+30v,\\10\times6=S+6v.\end{cases}\quad\Longrightarrow\quad\begin{cases}240=S+30v,\\60=S+6v.\end{cases}$$

**解方程**：两式相减 $180=24v\Rightarrow v=7.5$；代回 $S=60-6\times7.5=15$。
*唯一性*：系数矩阵 $\begin{pmatrix}1&30\\1&6\end{pmatrix}$ 行列式 $6-30=-24\ne0$，故 $(S,v)$ 唯一。

**求 $10$ 分钟所需台数 $x$**：$10x=S+10v=15+75=90\Rightarrow x=9$。
*单位无关性*：若每台机效率为 $c$（而非 $1$），则方程变为 $240c=S+30v$、$60c=S+6v$，解得 $v=7.5c,S=15c$，代入 $10xc=90c\Rightarrow x=9$，与 $c$ 无关。故归一化 $c=1$ 不失一般性。
答案 `9`。证毕。

> **为什么不是正比例**：若队列不增长（$v=0$），则 $S=240=60$，矛盾。故"均匀增加"是本题核心，必须用牛吃草而非反比例。

### 问题 11：追及问题

小 A 速 $5$、小 B 速 $8$，B 在 A 后 $100$ 米，同时同向起跑。B 追上 A 需弥补 $100$ 米差距，相对速度 $8-5=3$ 米/秒，故
$$t=\frac{100}{8-5}=\frac{100}3=33.\overline3\ \text{秒}.$$
*输出格式*：裸 `cout` ⇒ $6$ 位有效数字 ⇒ `33.3333`。
*追及公式证明*：设 $t$ 秒后 A 位置 $5t$、B 位置 $8t-100$（B 起点落后 $100$）。相遇 $5t=8t-100\Rightarrow3t=100\Rightarrow t=100/3$。证毕。

### 问题 12：字母序号

A 是第 $1$ 个，故第 $k$ 个字母是 `'A'+k-1`。
- M 的序号：`'M'-'A'+1=13`（M 是第 $13$ 个字母）；
- 第 $18$ 个字母：`'A'+17='R'`。

输出两行 `13`、`R`。
*正确性*：ASCII 中大写字母连续，`'M'-'A'=12`，加 $1$ 得 $13$；`'A'+17` 即第 $18$ 个字母 R。证毕。

### 问题 13：橡皮泥正方体（体积守恒 + 向下取整）

两球半径 $4,10$，揉成正方体，**体积守恒**：
$$V=\frac43\pi(4^3+10^3)=\frac43\times3.141593\times(64+1000)=\frac43\times3.141593\times1064=4456.8732693\ldots$$
设棱长 $a$，则 $a^3=V\Rightarrow a=V^{1/3}=16.4567256\ldots$。

**向下取整的严格验证（不用浮点）**：只需证 $16^3\le V<17^3$。
- $16^3=4096\le4456.873$ ✓；
- $17^3=4913>4456.873$ ✓。

故 $16\le a<17$，$\lfloor a\rfloor=16$。题面"舍去小数点之后的数字"即向下取整（$a>0$），答案 `16`。
*体积守恒适用性*：橡皮泥揉合不增减物质，总体积等于两球体积之和；正方体体积 $a^3$。立方根在 $V>0$ 上严格单调，故 $a$ 唯一。证毕。

### 问题 14：课程定价（一元二次方程，取较小根）

定价 $110$ 时 $10$ 人；每降 $1$ 元多 $1$ 人 ⇒ 定价 $p$ 时人数 $10+(110-p)=120-p$。收入
$$R(p)=p(120-p)=3500\ \Longrightarrow\ p^2-120p+3500=0.$$

**求根**：判别式 $\Delta=120^2-4\times3500=14400-14000=400>0$，故有两实根
$$p=\frac{120\pm\sqrt{400}}2=\frac{120\pm20}2=70\ \text{或}\ 50.$$

**取较小根**：题面"有两个答案符合要求，取较小的"⇒ $p=50$。
**四舍五入**：$50$ 已是整数，`round(50)=50`。
**验证两收入**：$p=50$ 时人数 $70$，收入 $50\times70=3500$ ✓；$p=70$ 时人数 $50$，收入 $70\times50=3500$ ✓。两根均合法（人数 $>0$），取小者 $50$。
*模型正确性*：人数关于价格线性（题面"每降 1 元多 1 人，反之亦然"），故 $R(p)$ 是开口向下抛物线，顶点 $p=60$ 时 $R=3600>3500$，所以 $3500$ 对应两个价格，与题面"两个答案"一致。证毕。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| `T` | 输入的题号，$1\le T\le14$ | `int`，读入 |
| `pi` | 题面指定的圆周率 $3.141593$ | `constexpr double` |
| `x` | 第 9 题逆推的桃子数 | `int`，初值 $1$，循环 $3$ 次 `x=(x+1)*2` |
| `v,s` | 第 10 题每分钟新增量、初始队列 | `double`，由两方程解出 |
| `V,a` | 第 13 题总体积、棱长 | 推导量，`cbrt` 后 `(int)` 截断 |
| `D` | 第 14 题判别式 $120^2-4\times3500=400$ | 推导量 |

本题无数组、无多测，故不需要 `mxn`/哨兵；`1145141919` 无用武之地。

### 算法步骤

1. 读入 $T$。
2. 用 `if(T==1)…else if(T==14)` 分发：
   - $T=1$：输出字符串。
   - $T=2,3,7,12$：直接整数运算/字符运算。
   - $T=4,6,8,11$：裸 `cout` 输出浮点（默认 6 位有效数字）。
   - $T=5$：输出 `(260+220)/(12+20)`。
   - $T=9$：`x=1` 循环 $3$ 次 `x=(x+1)*2`，输出 `x`。
   - $T=10$：解 $v=(8\cdot30-10\cdot6)/(30-6)$、$s=10\cdot6-6v$，输出 `round((s+10v)/10)`。
   - $T=13$：输出 `(int)cbrt(4.0/3*pi*(64+1000))`。
   - $T=14$：输出 `(int)round((120-sqrt(120*120-4*3500))/2)`。
3. 每个分支末尾输出 `'\n'`（多行答案逐行输出）。

### 复杂度

- 时间：$O(1)$（每个分支常数次运算；第 9 题固定 $3$ 次循环）。
- 空间：$O(1)$。

### 验证状态

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2433 【深基1-2】小学数学 N 合一
// 读题号 T，分发到 14 个小题；浮点一律裸 cout（默认 6 位有效数字）
#include<bits/stdc++.h>
using namespace std;

constexpr double pi{3.141593};	// 题面指定，不能用 acos(-1)

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int T;
	cin>>T;
	if(T==1)
		cout<<"I love Luogu!\n";
	else if(T==2)
		cout<<2+4<<' '<<10-2-4<<'\n';
	else if(T==3)
		cout<<14/4<<'\n'<<14/4*4<<'\n'<<14%4<<'\n';
	else if(T==4)
		cout<<500.0/3<<'\n';			// 6 位有效数字 166.667
	else if(T==5)
		cout<<(260+220)/(12+20)<<'\n';		// 相对运动 480/32=15
	else if(T==6)
		cout<<sqrt(9.0*9+6.0*6)<<'\n';		// 勾股 sqrt(117)
	else if(T==7)
		cout<<100+10<<'\n'<<100+10-20<<'\n'<<0<<'\n';
	else if(T==8)
		cout<<2*pi*5<<'\n'<<pi*5*5<<'\n'<<4.0/3*pi*5*5*5<<'\n';
	else if(T==9)
	{
		int x=1;				// 第 4 天剩 1，逆推 3 天
		for(int i=0;i<3;++i)
			x=(x+1)*2;
		cout<<x<<'\n';
	}
	else if(T==10)
	{
		// 牛吃草：8*30=S+30v, 10*6=S+6v
		double v=(8.0*30-10.0*6)/(30-6),s=10.0*6-6*v;
		cout<<(int)round((s+10*v)/10)<<'\n';
	}
	else if(T==11)
		cout<<100.0/(8-5)<<'\n';		// 追及 100/3
	else if(T==12)
		cout<<'M'-'A'+1<<'\n'<<(char)('A'+18-1)<<'\n';
	else if(T==13)
		cout<<(int)cbrt(4.0/3*pi*(4*4*4+10*10*10))<<'\n';	// 体积守恒，舍去小数
	else if(T==14)
		cout<<(int)round((120-sqrt(120.0*120-4*3500))/2)<<'\n';	// 取较小根
	return 0;
}
```

### 代码说明

- **浮点精度**：第 4、6、8、11 题全部用裸 `cout`，依赖其默认 `defaultfloat` + 精度 $6$（即 $6$ 位有效数字）。**绝不能**加 `fixed`/`setprecision`，否则变成 $6$ 位小数，答案错误。
- **$\pi$ 常量**：`constexpr double pi{3.141593}` 严格按题面，第 8、13 题共用。
- **第 9 题**用循环逆推而非硬编码 `22`，体现推导过程；第 10 题用方程解出 $v,s$ 而非硬编码 `9`；第 14 题用求根公式而非硬编码 `50`。这样代码与第二节的数学推导一一对应。
- **第 13 题** `(int)cbrt(...)` 是向零截断，因棱长为正等价于向下取整，符合"舍去小数"。
- **第 14 题** `round` 实现"四舍五入精确到整数"，本题根恰为整数故无影响，但写法符合题意。
- 多行答案（3、7、8、12）用 `'\n'` 分隔，末尾也带 `'\n'`，符合风格规范。
