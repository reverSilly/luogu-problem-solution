# P2118 [NOIP 2014 普及组] 比例简化 — 题解

## 一、解题过程：人类思考叙事

题目：给出支持人数 $A$、反对人数 $B$ 和上限 $L$，要求找到 $A',B'$，满足

- $A'\le L$，$B'\le L$；
- $\gcd(A',B')=1$（互质）；
- $\dfrac{A'}{B'}\ge \dfrac{A}{B}$；
- $\dfrac{A'}{B'}-\dfrac{A}{B}$ 尽可能小。

数据范围：$1\le A,B\le 10^6$，$1\le L\le 100$，且 $\dfrac AB\le L$。

第一反应是"枚举 + 找最优"，而 $L\le 100$ 意味着 $(A',B')$ 最多 $100\times 100=10^4$ 对，暴力枚举完全可行。

但关键是把**优化目标**看清楚。目标写的是"$\dfrac{A'}{B'}-\dfrac AB$ 尽可能小"。注意 $\dfrac AB$ 是一个**常数**（由输入固定），所以

$$\frac{A'}{B'}-\frac AB \text{ 最小} \iff \frac{A'}{B'} \text{ 最小}.$$

也就是说，问题等价于：**在所有满足"$\frac{A'}{B'}\ge\frac AB$、$A'\le L$、$B'\le L$、互质"的候选中，选 $\frac{A'}{B'}$ 最小的那个。**

这是一个非常舒服的转化——不用去比较两个分数的差（那要比较 $\frac{A'_1B_2-A B'_2}{B'_1B_2}$ 与 $\frac{A'_2B_1-A B'_1}{B'_2B_1}$，又要做交叉相乘又要约分，很麻烦），直接比较 $\frac{A'}{B'}$ 就行。

比较两个分数 $\frac{a_1}{b_1}$ 与 $\frac{a_2}{b_2}$，用交叉相乘：$\frac{a_1}{b_1}<\frac{a_2}{b_2}\iff a_1b_2<a_2b_1$。因为分母都是正数，所以不需要考虑符号翻转。数值范围：$a,b\le 100$，乘积 $\le 10^4$，`int` 都够，但保险起见用 `long long`。

同理，判定 $\frac{A'}{B'}\ge\frac AB$ 就是 $A'\cdot B\ge A\cdot B'$。$A,B\le 10^6$，乘积 $\le 10^8$，`int` 够（$10^8<2.1\times 10^9$），但依然用 `long long` 稳妥。

互质判定用 `gcd(a,b)==1`。

还有一个"存在性"的问题：会不会一个合法候选都没有？题目保证 $\frac AB\le L$，取 $A'=L$、$B'=1$，则 $\frac{A'}{B'}=L\ge\frac AB$，且 $L\le L$，$1\le L$，但 $\gcd(L,1)=1$ 恒成立。所以 $(L,1)$ 一定合法，答案必然存在。

完整算法：

```
ba = 0, bb = 0   // 当前最优
for a = 1..L:
    for b = 1..L:
        if gcd(a,b) != 1: continue
        if a*B < A*b: continue          // 不满足 A'/B' >= A/B
        if ba == 0 || a*bb < ba*b:      // 比当前最优更小
            ba = a, bb = b
输出 ba, bb
```

`ba == 0` 的判断用来处理"还没有最优解"的情况（此时 `bb` 也是 0，不能参与比较，否则 `a*0 < 0*b` 即 `0<0` 为假，会永远更新不了）。

样例验证：$A=1498,B=902,L=10$。$\frac AB\approx 1.6608$。候选中：$5/3\approx 1.6667$ 满足条件且差值 $0.0059$；$10/6$ 不互质（等价 $5/3$）；$9/5=1.8$、$8/5=1.6$ 不满足 $\ge$。所以答案是 `5 3`，与官方一致。

复杂度：$O(L^2\log L)$，其中 $\log L$ 来自 `gcd`；$L\le 100$ 时完全无压力。

## 二、思维链：完整证明

**记号约定**：可行对集合 $\mathcal{F}=\{(a,b): 1\le a\le L,\,1\le b\le L,\,\gcd(a,b)=1,\,aB\ge Ab\}$。对 $(a,b)\in\mathcal{F}$，记其比例 $r(a,b)=a/b$，差值 $d(a,b)=r(a,b)-A/B$。

**引理 1**：$\mathcal{F}\ne\varnothing$。

*证明*：由数据保证 $\frac AB\le L$，取 $a=L,b=1$：$1\le L\le L$ 显然成立；$\gcd(L,1)=1$；且 $aB=LB\ge AB=Ab$（因 $B\ge 1$ 且 $L\ge A/B$）。故 $(L,1)\in\mathcal{F}$，集合非空。证毕。

**引理 2**：对任意可行对 $(a,b)$，$d(a,b)=r(a,b)-A/B$，其中 $A/B$ 与 $(a,b)$ 无关。

*证明*：$A,B$ 是输入给定的固定整数，$A/B$ 是常数。$d(a,b)$ 的定义就是两个数相减，其中第二项是常数。因此 $d$ 在 $\mathcal{F}$ 上的大小关系与 $r$ 在 $\mathcal{F}$ 上的大小关系**完全一致**：$d(a_1,b_1)<d(a_2,b_2)\iff r(a_1,b_1)<r(a_2,b_2)$。证毕。

**引理 3**：在 $\mathcal{F}$ 中最小化 $d$ 等价于在 $\mathcal{F}$ 中最小化 $r$；且最小化 $d$ 等价于最小化 $r$。

*证明*：由引理 2 直接得到。证毕。

**引理 4**：对任意正整数对 $(a_1,b_1),(a_2,b_2)$，$r(a_1,b_1)<r(a_2,b_2)\iff a_1b_2<a_2b_1$。

*证明*：因 $b_1,b_2>0$，两边同乘 $b_1b_2>0$ 不改变不等号方向：$r(a_1,b_1)<r(a_2,b_2)\iff \frac{a_1b_2}{b_1b_2}<\frac{a_2b_1}{b_1b_2}\iff a_1b_2<a_2b_1$。证毕。

**引理 5**：算法输出的 $(ba,bb)$ 是 $\mathcal{F}$ 中 $r$ 最小的元素。

*证明*：算法用两重循环枚举了所有 $1\le a\le L$、$1\le b\le L$ 的组合，即枚举了所有可能的候选对。对每个组合：

- 若 $\gcd(a,b)\ne 1$，跳过——它不属于 $\mathcal{F}$，跳过不损失最优解。
- 若 $aB<Ab$，跳过——由 $B>0,b>0$，这等价于 $a/b<A/B$，不满足题目要求，同样不损失最优解。
- 否则 $(a,b)\in\mathcal{F}$，进入比较。

比较逻辑为：若当前还没有记录最优解（`ba==0`），直接记录；否则由引理 4，用 `a*bb < ba*b` 判断新候选是否严格更小，是则替换。

由于 `ba==0` 时的特判保证了"第一个可行解一定被记录"，且之后每次替换都基于严格更小的正确比较，由归纳可知：处理完任意前缀的枚举后，`(ba,bb)` 始终是已处理的可行解中 $r$ 最小的那个。

全部枚举结束后，由引理 1 可行解非空，故 `(ba,bb)` 是 $\mathcal{F}$ 中 $r$ 最小的元素。证毕。

**定理**：算法输出的是满足题目全部要求、且差值 $\frac{A'}{B'}-\frac AB$ 最小的比例 $A':B'$。

*证明*：由引理 5，输出对 $(ba,bb)$ 在 $\mathcal{F}$ 中；$\mathcal{F}$ 的定义恰好保证 $ba\le L$、$bb\le L$、$\gcd(ba,bb)=1$、$\frac{ba}{bb}\ge\frac AB$。由引理 3，最小化 $r$ 等价于最小化差值，故输出的差值最小。证毕。

## 三、模式总结（按实际思考顺序）

1. **先看清目标函数的结构** — "$\frac{A'}{B'}-\frac AB$ 最小"里第二项是常数，于是问题变成"$\frac{A'}{B'}$ 最小"，避免了比较两个分数之差的麻烦。
2. **估枚举规模** — $L\le 100$，$10^4$ 对，直接暴力枚举毫无压力，不需要任何优化技巧。
3. **三个筛选条件** — 互质（`gcd`）、比例下界（交叉相乘 $aB\ge Ab$）、取最小（交叉相乘 $a\cdot b_{old}<a_{old}\cdot b$）。
4. **小心边界** — 需要一个"还没有最优解"的哨兵判断，否则初始化的 0 会让第一次比较永远不成立。
5. **数值安全** — 交叉相乘一律用 `long long`，避免中间乘积溢出隐患。
6. **存在性确认** — $(L,1)$ 恒为合法解，保证答案存在（题目也保证了 $A/B\le L$）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $A$ | 支持人数 | `int`，$\le 10^6$ |
| $B$ | 反对人数 | `int`，$\le 10^6$ |
| $L$ | 分子分母上限 | `int`，$\le 100$ |
| $a,b$ | 枚举中的候选分子分母 | `int`，$1..L$ |
| `ba,bb` | 当前最优的分子分母，`ba==0` 表示尚无解 | `int` |
| $\mathcal{F}$ | 可行对集合 | — |

### 算法步骤

1. 读入 $A,B,L$。
2. 初始化 `ba=0,bb=0`。
3. 两重循环 `a=1..L`、`b=1..L`：
   - `if(gcd(a,b)!=1) continue;`（不互质）。
   - `if(1LL*a*B<1LL*A*b) continue;`（比例低于 $A/B$）。
   - `if(ba==0 || 1LL*a*bb<1LL*ba*b)` 则 `ba=a, bb=b;`。
4. 输出 `ba` 与 `bb`（中间一个空格）。

### 复杂度

- 时间复杂度：$O(L^2\log L)$。共 $L^2$ 对，每对一次 `gcd`（$O(\log L)$）。
- 空间复杂度：$O(1)$。

### 验证状态

- 标程 `P2118.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `1498 902 10` 输出 `5 3`，与官方一致。
- 编写暴力 `P2118_brute.cpp`（直接比较两个候选的差值 $\frac{aB-Ab}{b}$，用分数比较）与对拍脚本 `P2118_check.py`，在随机 $A,B,L$ 上对拍 **2000 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2118 [NOIP 2014 普及组] 比例简化
#include<bits/stdc++.h>
using namespace std;

using i64=long long;

int A,B,L;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>A>>B>>L;

	int ba=0,bb=0;
	for(int a=1;a<=L;++a)
		for(int b=1;b<=L;++b)
		{
			if(gcd(a,b)!=1) continue;
			if(1LL*a*B<1LL*A*b) continue;
			if(ba==0 || 1LL*a*bb<1LL*ba*b)
			{
				ba=a;
				bb=b;
			}
		}
	cout<<ba<<' '<<bb<<'\n';
	return 0;
}
```

### 代码说明

- 优化目标被化简为"最小化 $\frac{A'}{B'}$"，因为 $\frac AB$ 是常数。比较时只需交叉相乘，不必去比较两个分数的差。
- `1LL*a*B<1LL*A*b` 判定 $\frac AB>\frac ab$：注意方向，写反了会把答案选反。
- `ba==0` 是"尚未找到可行解"的哨兵。因为 $(L,1)$ 恒合法，循环结束后一定有解。
- 所有乘法都显式转成 `long long`：`A*B` 可达 $10^8$，虽然 `int` 尚未溢出，但写成 `1LL*` 更保险，也便于审阅。
- `gcd(a,b)!=1` 过滤掉的是**未化简**的比例；这些比例虽然数值上等价于某个已化简的比例，但 $(A',B')$ 本身必须互质，所以必须过滤而不是"化简后再用"。
