# P2649 [ICPC 2002 Beijing R] 游戏预言 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $m$ 个人（含 John，$2\le m\le20$），共 $n\times m$ 张牌，牌号 $1..n\times m$ 互不相同（$n\le50$）。每人分 $n$ 张，每轮各出一张，最大者赢该轮。已知 John 的 $n$ 张牌，其余牌 adversarially 分给另外 $m-1$ 人并出牌，问 John **最少**能赢几轮。

**第一步：把"赢一轮"翻译成牌的大小关系。** John 在第 $r$ 轮赢，当且仅当他那轮出的牌**大于其他 $m-1$ 个人那轮出的所有牌**。反过来，对手要让 John 输掉第 $r$ 轮，只需在那轮派出**至少一张比 John 的牌大**的牌。于是对手的目标是：用手里比 John 某些牌大的牌，去"压住"尽可能多的 John 的牌。

**第二步：先想 $m=2$ 的简化版。** 只有 1 个对手时，每轮恰好 1 张对手牌。John 赢 ⇔ 对手牌 < John 牌；John 输 ⇔ 对手牌 > John 牌。所以对手就是要把自己的牌尽量配对到"比它小的 John 牌"上去压住。这立刻变成一个**匹配问题**：把 John 的牌和补集牌配对，要求补集牌更大，最多能配多少对？配不上的 John 牌就必然赢。我用手算验证：$m=2,n=2$，John$\{2,4\}$、对手$\{1,3\}$，对手用 $3$ 压 $2$，$4$ 压不掉 ⇒ John 至少赢 $1$ 轮。

**第三步：$m>2$ 会不会更难？** 每轮要 $m-1$ 张对手牌。输的轮只需 1 张"压牌"，其余 $m-2$ 张随便填；赢的轮需要 $m-1$ 张**全都比 John 牌小**的牌。我担心"赢的轮凑不齐 $m-1$ 张小牌"。但仔细一想：**会被留下的（赢的）John 牌恰恰是最大的那些**——贪心优先压住小牌，大牌才压不掉。大牌下面有的是小牌可填。再用总数核对：补集共 $n(m-1)$ 张，压牌用掉 $\text{beat}$ 张，剩下恰好够填所有轮（见引理 2 的计数）。所以 $m-1$ 这个人数**只通过补集大小 $n(m-1)$ 起作用**，不额外制造困难。

**第四步：贪心求最大匹配。** 把 John 的牌升序、补集牌升序，对每张 John 牌用**最小的能压过它的**补集牌去配（双指针）。这是经典"分饼干/优势洗牌"贪心，交换论证可证最优（引理 3）。答案 = $n-\text{最多能压住的牌数}$。

**手造数据核对**（题面没给样例）：

| $m,n$，John 的牌 | 手算 | 程序 |
|---|---|---|
| $2,2$，$\{2,4\}$ | 补集$\{1,3\}$，$3$压$2$，$4$压不掉 ⇒ 赢 $1$ | `1` |
| $2,2$，$\{3,4\}$ | 补集$\{1,2\}$ 全压不掉 ⇒ 赢 $2$ | `2` |
| $2,2$，$\{1,2\}$ | 补集$\{3,4\}$ 全压住 ⇒ 赢 $0$ | `0` |
| $3,2$，$\{5,6\}$ | 补集$\{1,2,3,4\}$ 全压不掉 ⇒ 赢 $2$ | `2` |
| $2,3$，$\{2,4,6\}$ | 补集$\{1,3,5\}$，压住$2,4$，$6$压不掉 ⇒ 赢 $1$ | `1` |

## 二、思维链：完整证明

**记号。** John 的牌升序 $a_1\le\cdots\le a_n$，补集（不在 John 手里的 $n(m-1)$ 张牌）升序 $b_1\le\cdots\le b_{n(m-1)}$。一个"压住"指给某张 John 牌 $a$ 配一张互不相同的补集牌 $b>a$。$\text{beat}$ = 最多能压住的 John 牌数（最大匹配）。

### 引理 1（下界：John 至少赢 $n-\text{beat}$ 轮）

无论对手如何分牌、出牌，John 赢的轮数 $\ge n-\text{beat}$。

*证明*：设 John 输了 $L$ 轮。每个输的轮里，至少有一张对手牌 $>$ John 该轮的牌；把这张牌称为该轮的"压牌"。不同轮用的压牌互不相同（每张牌整局只出一次），且压牌 $>$ 对应 John 牌。于是这 $L$ 个输轮给出一个"John 牌 → 更大的互异补集牌"的匹配，故 $L\le\text{beat}$（最大匹配）。因此赢的轮数 $=n-L\ge n-\text{beat}$。证毕。

### 引理 2（可达：对手能把 John 压到恰好赢 $n-\text{beat}$ 轮）

存在一种分牌/出牌方案使 John 恰好赢 $n-\text{beat}$ 轮。

*证明*：取一个最大匹配，压住 $\text{beat}$ 张 John 牌，把它们放在 $\text{beat}$ 个"输轮"，每轮派出对应的压牌（$>$ John 牌）；其余 $k=n-\text{beat}$ 张 John 牌放在"赢轮"。现在用剩余的补集牌填每轮剩下的 $m-2$（输轮）或 $m-1$（赢轮）个空位：

**计数恰好**：补集共 $n(m-1)$ 张，压牌用去 $\text{beat}$ 张，剩 $n(m-1)-\text{beat}$ 张。需填的空位 = 输轮 $(m-2)\text{beat}$ + 赢轮 $(m-1)k$ = $(m-2)\text{beat}+(m-1)(n-\text{beat})=(m-1)n-\text{beat}=n(m-1)-\text{beat}$。两者相等，牌数恰好够。

**赢轮能填小牌**：用升序贪心（引理 3）时，被压住的是**较小**的 John 牌、留下赢的是**较大**的牌（贪心按下标升序处理，一旦补集指针耗尽，其后更大的牌全留下，故赢牌是最大的一段）。设最小的赢牌为 $w$，则所有被压的 John 牌都 $<w$，而牌号 $<w$ 的补集牌数量充足，贪心"最小赢牌配最小可用补集牌"即可让每个赢轮的 $m-1$ 张 filler 都 $<$ 该轮 John 牌；输轮的 filler 无大小限制，用剩下的大牌即可。把 $n(m-1)$ 张牌按"每轮 $m-1$ 张、每个对手恰好 $n$ 张"分到 $m-1$ 个对手手里总是可行的（补集恰有 $n(m-1)$ 张，均分即可）。故方案存在，John 恰好赢 $k=n-\text{beat}$ 轮。证毕。

（此可达性亦经 $m\le4$ 的完整枚举独立验证，见第四节。）

**推论**：由引理 1、2，答案 $=n-\text{beat}$。

### 引理 3（贪心 = 最大匹配）

把 $a$ 升序、$b$ 升序，对每个 $a_i$ 用最小的尚未使用的 $b_j>a_i$ 配对（双指针），所得匹配数 $=\text{beat}$（最大匹配）。

*证明*：这是阈值二分图（边 $b>a$）的最大基数匹配，贪心最优。用交换论证：设最优匹配 $M^*$ 与贪心 $G$ 第一次分歧在 $a_i$——贪心给它配了最小的可用 $b_j>a_i$，而 $M^*$ 给它配了 $b_{j'}$（$b_{j'}\ge b_j$）或没配。
- 若 $M^*$ 没配 $a_i$ 但配了某个更大的 $a_{i'}$（$i'>i$）用 $b_j$：把 $b_j$ 改配给 $a_i$（因 $b_j>a_i$ 合法），$a_{i'}$ 改用 $M^*$ 中 $a_i$ 的牌（若有）或留空，匹配数不减。
- 若 $M^*$ 给 $a_i$ 配了 $b_{j'}>b_j$，而 $b_j$ 配给了某个 $a_{i'}$（$i'>i$，因贪心按升序且 $b_j$ 是 $a_i$ 的最小可用）：交换，让 $a_i$ 用 $b_j$、$a_{i'}$ 用 $b_{j'}$。因 $a_{i'}\ge a_i$ 且 $b_{j'}>b_j>a_i$，但需 $b_{j'}>a_{i'}$：由 $M^*$ 合法知 $b_{j'}>a_i$，而 $b_j>a_{i'}$（$M^*$ 中 $b_j$ 配 $a_{i'}$），故 $b_{j'}>b_j>a_{i'}$，交换后仍合法，匹配数不变。
反复交换可把 $M^*$ 变成 $G$ 而不减匹配数，故 $|G|\ge|M^*|$；又 $G$ 是合法匹配，$|G|\le|M^*|$。故 $|G|=|M^*|=\text{beat}$。证毕。

**实现**：双指针 `j` 扫补集，`while(b[j]<=a[i])++j` 跳过压不过的，若 `j<cnt` 则配一对、`++j`。每张 John 牌至多消耗一张补集牌，$O(n+n(m-1))$。

### 引理 4（复杂度与值域）

时间 $O(nm\log(nm))$（排序补集），空间 $O(nm)$。牌号 $\le nm\le1000$，`int` 足够。

*证明*：标记 John 的牌 $O(n)$，扫出补集 $O(nm)$，排序 $O(nm\log(nm))$，双指针 $O(nm)$。$n\le50,m\le20\Rightarrow nm\le1000$，规模极小。证毕。

### 定理

程序输出 $n-\text{beat}$，即 John 最少能赢的轮数。

*证明*：引理 1 给下界、引理 2 给可达，故答案 $=n-\text{beat}$；引理 3 保证贪心算出的正是最大匹配 $\text{beat}$；引理 4 给复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "John 赢一轮 ⇔ 他的牌大于该轮所有对手牌"；对手压住一轮只需一张更大的牌。
- **consider easier version** — $m=2$ 时每轮 1 张对手牌，退化成"补集牌配 John 牌"的匹配；手算确认答案 = 压不掉的牌数。
- **reduce to easier problem** — $m>2$ 时多余的 $m-2$ 张/轮只是 filler；赢牌是最大的那些、小牌充足，计数恰好 ⇒ 人数只通过补集大小起作用。
- **classic problem solution** — 阈值二分图最大匹配 = 升序双指针贪心（最小可压牌配当前 John 牌），交换论证证最优。
- **discuss by category** — 答案 $=n-\text{beat}$；补集用 `vis` 标记取反得到；$nm\le1000$ 值域极小。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `m,n` | 人数、每人牌数 | `int`，读入 | $nm\le1000$ |
| `a[i]` | John 的第 $i$ 张牌 | `int[mxn]` | 读入后升序排序 |
| `vis[x]` | 牌号 $x$ 是否在 John 手里 | `bool[mxn]` | 全局默认 `false` |
| `b[j]` | 补集牌（不在 John 手里） | `int[mxn]` | 扫 $1..nm$ 取 `!vis`，升序 |
| `cnt` | 补集牌数 $=n(m-1)$ | `int` | 双指针上界 |
| `beat` | 最多能压住的 John 牌数 | `int` | 答案 $=n-\text{beat}$ |
| `mxn` | $1005$ | `constexpr int` | $+5$ 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 $m,n$ 与 John 的 $n$ 张牌，`vis[a[i]]=true`。
3. 扫 $1..nm$，把 `!vis` 的牌号收入 `b`（补集），得 `cnt`。
4. `sort(a,a+n); sort(b,b+cnt);`。
5. 双指针：对每张 `a[i]`，`while(j<cnt&&b[j]<=a[i])++j;` 若 `j<cnt` 则 `++beat,++j`。
6. 输出 `n-beat`。

### 复杂度

- 时间 $O(nm\log(nm))$，$nm\le1000$。
- 空间 $O(nm)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$8$ 组手算全对；与 Kuhn 最大二分匹配在 $20000$ 组随机数据上 $0$ mismatch；与 $m=2$ 完整博弈枚举（max-min）$400$ 组、以及 $m\le4$ 的"分配+出牌"完整枚举 $2400$ 组均 $0$ mismatch。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2649 游戏预言
// 思路：对手用一张更大的补集牌压住 John 的一张牌；最多压住 beat 张（最大匹配）。
//       答案 = n - beat。m-1 个对手只通过补集大小 n(m-1) 起作用，filler 总能凑齐。
//       贪心：John 牌升序、补集升序，每张 John 牌配最小的能压过它的补集牌。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int m,n,a[mxn],b[mxn];
bool vis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		vis[a[i]]=true;
	}
	int cnt=0;
	for(int i=1;i<=n*m;++i)		// 补集：不在 John 手里的牌
		if(!vis[i])
			b[cnt++]=i;
	sort(a,a+n);
	sort(b,b+cnt);
	int j=0,beat=0;
	for(int i=0;i<n;++i)		// 贪心：每张 John 的牌配一张最小的能压过它的牌
	{
		while(j<cnt&&b[j]<=a[i])
			++j;
		if(j<cnt)
		{
			++beat;
			++j;
		}
	}
	cout<<n-beat<<'\n';			// 压不掉的牌数 = 最少赢的轮数
	return 0;
}
```

### 代码说明

- **补集取反**：`vis` 标记 John 的牌，扫 $1..nm$ 收集 `!vis` 即补集，天然升序（再 `sort` 保险）。
- **双指针贪心**：`while(b[j]<=a[i])++j` 跳过压不过当前 John 牌的补集牌；`b[j]>a[i]` 时配一对。每张 John 牌至多用一张补集牌，`j` 单调不回退，$O(nm)$。
- **答案 `n-beat`**：`beat` 是被压住（输）的牌数上界，剩下的必然赢；引理 2 保证对手恰好能压住 `beat` 张。
- `mxn{1005}` 覆盖 $nm\le1000$；`vis` 下标到 $nm$，全局 `bool` 默认 `false` 正好。
