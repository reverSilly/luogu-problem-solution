# P2356 弹珠游戏 — 题解

## 一、解题过程：人类思考叙事

题意：一个 $n\times n$ 的矩阵，格子里是敌人的分数（正整数），$0$ 表示空格。你要选一个**空格**站立，弹珠会消灭你所在**整行与整列**的所有敌人，得分是所有被消灭敌人的分数之和。求能获得的最高分；如果一个空格都没有，输出 `Bad Game!`。$n\le1000$，保证空格数小于 $10000$，每个格子的分数不超过 $1000$。

先明确"得分"怎么算。站在 $(i,j)$ 时，被消灭的敌人是"第 $i$ 行的全部敌人"并上"第 $j$ 列的全部敌人"。这两个集合的交集只有 $(i,j)$ 这一格，而 $(i,j)$ 必须是空格（分数为 $0$），所以它虽然被算了两次，但每次都是 $0$，不产生重复计数。于是

$$\text{score}(i,j)=\text{rowSum}[i]+\text{colSum}[j],$$

其中 `rowSum[i]` 是第 $i$ 行所有格子分数之和，`colSum[j]` 是第 $j$ 列之和。

**最朴素的做法**：枚举每个空格，现场扫一遍它所在的行和列求和。单次 $O(n)$ 行加 $O(n)$ 列，最多 $n^2$ 个位置，总复杂度 $O(n^3)$。$n=1000$ 时是 $10^9$ 次加法，太慢。

**优化很自然**：行和、列和与"你站在哪"无关，可以**预处理**。读入时顺便把每个格子的分数累加到它所在行的 `rowSum` 和所在列的 `colSum` 里，之后每个空格的得分 $O(1)$ 就能算出来。总复杂度降到 $O(n^2)$，正好等于读入规模。

**一个诱人的贪心（但是错的）**：既然得分是行和加列和，是不是取"行和最大的行"与"列和最大的列"，答案就是两者之和？不一定——它们的交点可能是个敌人格，你根本站不上去。反例：

$$\begin{pmatrix}0&5\\3&4\end{pmatrix}.$$

行和是 $(5,7)$，列和是 $(3,9)$。最大行是第 $2$ 行、最大列是第 $2$ 列，两者之和为 $7+9=16$，但交点 $(2,2)$ 的分数是 $4$，是敌人，站不上去。真正的合法选择只有 $(1,1)$，得分 $5+3=8$。所以"行最大 + 列最大"给出的值可能根本不是一个合法的站位，必须老老实实枚举所有空格。

**无解怎么判？** 如果矩阵里没有 $0$，就没有容身之地。用一个初值为 $-1$ 的 `ans` 记录最大值：所有合法得分都 $\ge0$，所以扫描结束后 `ans` 仍为 $-1$ 就说明一个空格都没有。这里要和"全 0 矩阵"区分开：全 0 时到处都是空格，得分是 $0$，应输出 `0` 而不是 `Bad Game!`。

**数据范围的暗示**：题面特意保证"空格数小于 $10000$"，这像是在提示"只枚举空格"。但读入 $n^2$ 个格子本身就至少 $10^6$ 次操作，直接扫描全部 $n^2$ 个格子与"先存下所有空格再枚举"是同一量级，前者还更简单，不必特意收集空格。分数上界也安全：每行至多 $1000\times1000=10^6$，行和加列和至多 $2\times10^6$，`int` 足够。

手造小数据核对：

- $\begin{pmatrix}0&5\\3&4\end{pmatrix}$：唯一空格 $(1,1)$ 得 $5+3=8$，输出 `8`。
- $\begin{pmatrix}1&2\\3&4\end{pmatrix}$：没有空格，输出 `Bad Game!`。
- $(0)$：唯一的格子是空格，得分 $0$，输出 `0`。

## 二、思维链：完整证明

记格子 $(i,j)$ 的分数为 $a_{i,j}\ge0$（$0\le i,j<n$），空格即 $a_{i,j}=0$。记

$$\mathrm{rs}_i=\sum_{c=0}^{n-1}a_{i,c},\qquad \mathrm{cs}_j=\sum_{r=0}^{n-1}a_{r,j}.$$

**引理 1（得分公式）**：若 $a_{i,j}=0$，则站在 $(i,j)$ 的得分为 $\mathrm{rs}_i+\mathrm{cs}_j$。

*证明*：被消灭的格子集合是第 $i$ 行 $R_i=\{(i,c):0\le c<n\}$ 与第 $j$ 列 $C_j=\{(r,j):0\le r<n\}$ 的并集。两集合的交为 $\{(i,j)\}$：若 $(x,y)\in R_i\cap C_j$，则 $x=i$ 且 $y=j$。于是由容斥，

$$\sum_{(x,y)\in R_i\cup C_j}a_{x,y}
=\sum_{R_i}a+\sum_{C_j}a-a_{i,j}
=\mathrm{rs}_i+\mathrm{cs}_j-0
=\mathrm{rs}_i+\mathrm{cs}_j.$$

这里用到"同一格的分数只算一次"，而交集那格的分数恰为 $0$。证毕。

**引理 2（可行域与目标）**：合法的站立位置恰为所有满足 $a_{i,j}=0$ 的格子；题目所求为

$$\max\{\mathrm{rs}_i+\mathrm{cs}_j:0\le i,j<n,\ a_{i,j}=0\},$$

若该集合为空则无解。

*证明*：题面要求"不能和敌人在一个地方"，即只能站在分数为 $0$ 的格子，这给出可行域；由引理 1，每个可行位置的得分是 $\mathrm{rs}_i+\mathrm{cs}_j$；对有限集合取最大值即为最优得分，集合为空时无可行解。证毕。

**引理 3（贪心反例）**：令 $i^*=\arg\max_i\mathrm{rs}_i$，$j^*=\arg\max_j\mathrm{cs}_j$。"取 $\mathrm{rs}_{i^*}+\mathrm{cs}_{j^*}$"不能作为答案：该值可能对应一个敌人格，因而不可行。

*证明*：给出一个反例。取

$$A=\begin{pmatrix}0&5\\3&4\end{pmatrix}.$$

则 $\mathrm{rs}=(5,7)$，$\mathrm{cs}=(3,9)$，$i^*=1$、$j^*=1$（$0$-based），$\mathrm{rs}_{i^*}+\mathrm{cs}_{j^*}=16$。但 $a_{1,1}=4\ne0$，该位置不可站。全部空格只有 $(0,0)$，得分为 $5+3=8$。因此贪心给出的 $16$ 不是任何合法站位的得分，更不是正确答案 $8$。证毕。

**引理 4（无解判定）**：把 `ans` 初始化为 $-1$，扫描全部格子、对每个 $a_{i,j}=0$ 的位置用 $\mathrm{rs}_i+\mathrm{cs}_j$ 更新 `ans`。扫描结束后，`ans`$\,=-1$ 当且仅当不存在空格。

*证明*：所有 $a_{i,j}\ge0$，故 $\mathrm{rs}_i,\mathrm{cs}_j\ge0$，任何一次更新写入的值都 $\ge0$。若存在空格，至少有一次更新，`ans` 被改成 $\ge0$ 的值，不再是 $-1$；若不存在空格，一次更新都没有，`ans` 保持 $-1$。证毕。

**引理 5（数值范围）**：最大得分不超过 $2\times10^6$，`int` 足够。

*证明*：每格分数 $\le1000$，一行至多 $1000$ 格，故 $\mathrm{rs}_i\le1000\times1000=10^6$；同理 $\mathrm{cs}_j\le10^6$；两者之和 $\le2\times10^6<2^{31}-1$。证毕。

**引理 6（复杂度）**：时间复杂度 $O(n^2)$，空间复杂度 $O(n^2)$。

*证明*：读入并累加行和、列和共 $n^2$ 次；扫描全部格子一次，共 $n^2$ 次；数组 `a` 有 $n^2$ 个元素，`rs,cs` 各 $n$ 个。证毕。

**定理（正确性）**：程序输出即为题面所求的最大得分，或在无空格时输出 `Bad Game!`。

*证明*：由引理 2，所求是全部空格上 $\mathrm{rs}_i+\mathrm{cs}_j$ 的最大值；程序扫描了全部格子（因而扫描了全部空格），按引理 1 的公式取值并取最大，故输出正确。由引理 4，`ans<0` 恰对应无空格，此时输出 `Bad Game!` 正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 得分分解为"行和 + 列和"，交点是空格所以不会重复计数。
2. **consider easier version** — 朴素做法对每个空格现场扫行扫列，$O(n^3)$ 超时。
3. **classic problem solution** — 预处理每行、每列的和，把单点查询降到 $O(1)$。
4. **贪心反例** — "最大行 + 最大列"可能落在敌人格上，不可行。
5. **discuss by category** — 有空格输出最大得分，无空格输出 `Bad Game!`。
6. **verify boundary** — 全 0 矩阵答案是 $0$，必须与无解（哨兵 $-1$）区分。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| `n` | 矩阵边长 | 输入 |
| `a[i][j]` | 格子 $(i,j)$ 的敌人分数，$0$ 表示空格 | 读入 |
| `rs[i]` | 第 $i$ 行的分数和 | 0，读入时累加 |
| `cs[j]` | 第 $j$ 列的分数和 | 0，读入时累加 |
| `ans` | 所有空格得分的最大值 | $-1$，兼作无解哨兵 |
| `mxn` | 边长上界 $1000$（+5 松弛） | 常量 |

### 算法步骤

1. 读入 $n$。
2. 对每个格子 $(i,j)$：读入 `a[i][j]`，并执行 `rs[i]+=a[i][j]`、`cs[j]+=a[i][j]`。
3. 初始化 `ans=-1`。
4. 扫描全部格子：若 `a[i][j]==0`，用 `rs[i]+cs[j]` 更新 `ans`。
5. 若 `ans<0` 输出 `Bad Game!`，否则输出 `ans`。

### 复杂度

- 时间复杂度：$O(n^2)$。
- 空间复杂度：$O(n^2)$（`int` 网格约 $4$ MB）。

### 验证状态

g++ 16.2（`-std=c++20 -O2 -Wall -Wextra`）编译通过且无警告；与 $O(n^3)$ 暴力在 300 组随机小矩阵（$n\le12$，含全非零、全零、混合三种模式）上完全一致；手算三组分别得到 `8`、`Bad Game!`、`0`，均吻合；$n=1000$ 的极限网格实测约 $0.15$ 秒。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2356 弹珠游戏
// 思路：站在空格 (i,j) 的得分 = 第 i 行敌人分数和 + 第 j 列敌人分数和
//       （该格本身是 0，不会被重复计算）。预处理每行、每列的和后扫描所有空格。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n;
int a[mxn][mxn],rs[mxn],cs[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
		{
			cin>>a[i][j];
			rs[i]+=a[i][j];
			cs[j]+=a[i][j];
		}
	int ans=-1;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			if(a[i][j]==0)
				ans=max(ans,rs[i]+cs[j]);
	if(ans<0)
		cout<<"Bad Game!\n";
	else
		cout<<ans<<'\n';
	return 0;
}
```
