# P2191 小Z的情书 — 题解

## 一、解题过程：人类思考叙事

题意翻译：有两张 $N\times N$ 的纸。一张是**透明纸**，上面某些格子被涂黑（用 `#` 表示涂黑、`O` 表示没涂黑）；另一张是**字母纸**，每格一个大写字母。

小 Z 把透明纸盖在字母纸上，约定了一个读法：
1. 把透明纸盖在字母纸上，把**露出来的**（即透明纸上没涂黑、`O` 的）格子里的字母，**从上到下、从左到右**写下来；
2. 转 $90$ 度，再读一遍；
3. 再转 $90$ 度，再读一遍；
4. 再转 $90$ 度，再读一遍。

一共读四遍，把这些字母连起来就是情书内容。

关键问题：**转的是哪张纸？**

题面说"把透明的纸盖在另一张纸上……然后转个 90 度，再读一遍"。既然透明纸始终"盖在"字母纸上，那转动的是**透明纸**（你把盖着的那层纸转个角度，底下的字母纸不动）。样例也印证了这一点——如果转字母纸，读出来的顺序会完全不同。

我拿样例验证一下（$N=4$）：

```
透明纸 mask        字母纸 tx
##O#              ARAO
#O#O              PCEM
####              LEEN
###O              TURC
```

第一遍（不旋转）：mask 中 `O` 的位置是 $(0,2),(1,1),(1,3),(3,3)$。按行优先读出对应字母：$tx[0][2]='A'$，$tx[1][1]='C'$，$tx[1][3]='M'$，$tx[3][3]='C'$ → `"ACMC"`。

第二遍（旋转 90° 后）：得到 `"ENT"`。
第三遍：`"RAL"`。
第四遍：`"EU"`。

拼起来：`ACMC` + `ENT` + `RAL` + `EU` = `ACMCENTRALEUROPE` ✓ 正是题面说的"CM CENTRAL EUROPE"（中欧）！

所以读法确认无误。

现在说实现。

**旋转公式**。顺时针旋转 90°：原来位置 $(i,j)$ 的格子，旋转后到 $(j, N-1-i)$。等价地，新图的 $(i,j)$ 位置放的是旧图的 $(N-1-j, i)$。即

$$\text{new}[i][j] = \text{old}[N-1-j][i].$$

验证一下：old 的左上角 $(0,0)$ 顺时针转 90° 后应到右上角 $(0,N-1)$。按公式 new$[0][N-1]$ = old$[N-1-(N-1)][0]$ = old$[0][0]$ ✓。

（转置的写法 `new[i][j] = old[j][N-1-i]` 是逆时针，我一开始想当然写成了逆时针，靠样例才发现。这是个容易错的点。）

**读字母**。每次旋转后，遍历 mask 的所有格子，遇到 `'O'` 就把 `tx[i][j]` 追加到答案串末尾。因为遍历是"外层行、内层列"，天然就是行优先（从上到下、从左到右）✓。

**次数**。题目说"转个 90 度，再读一遍……一共读四遍"。所以是：读 → 转 → 读 → 转 → 读 → 转 → 读。即初始读 1 次，转 3 次，共 4 次读。

注意**只旋转透明纸**，字母纸 `tx` 始终不动。

**复杂度**：$O(N^2)$ 读 4 次 + $O(N^2)$ 转 3 次，共 $O(N^2)$。$N\le 1000$，完全够。

**细节**：
- 答案串长度最多 $4N^2\le 4\times10^6$，用 `string` 存没问题。
- 用 `ans += tx[i][j]` 追加字符。
- 旋转时用一个临时数组 `tmp[mxn][mxn]`。$1005^2$ 个 `char` 约 1MB，放栈上有点悬（Linux 默认栈 8MB，其实够，但保险起见用 `static` 或全局）。我把它放在函数内的局部数组——1005×1005 = 1005025 字节 ≈ 1MB，局部变量超过 1MB 在某些环境下有风险，但 8MB 栈没问题。为了保险我把它改成全局/静态。

实际上我把 `tmp` 声明为函数内的 `char tmp[mxn][mxn]`，就是 1MB 栈帧。OJ 上一般 OK，但稳妥起见改成 `static`。我在代码里改用 `static char tmp[mxn][mxn];`。

**输入**：`cin >> msk[i]` 读一整行字符串（N 个字符）；`cin >> tx[i]` 同理。字符都是大写或 `#`/`O`，没有空格，`cin` 读字符串没问题。

## 二、思维链：完整证明

**记号约定**：$N$ 为纸张边长；$\mathrm{msk}[i][j]\in\{\texttt{O},\texttt{\#}\}$ 为透明纸第 $i$ 行第 $j$ 列（$0$ 下标）；$\mathrm{tx}[i][j]$ 为字母纸对应位置的字母；$\mathrm{rot}$ 表示把透明纸顺时针旋转 $90^\circ$ 后的透明纸。

**引理 1**（旋转公式）：设旋转前的透明纸为 $A$，旋转后为 $B$，则对一切 $0\le i,j<N$ 有 $B[i][j]=A[N-1-j][i]$。

*证明*：顺时针旋转 $90^\circ$ 时，原位于 $(r,c)$ 的格子移动到 $(c,N-1-r)$。令 $r=N-1-j$、$c=i$，则该格移动到 $(i, N-1-(N-1-j))=(i,j)$。故新位置 $(i,j)$ 上的内容来自旧位置 $(N-1-j,i)$，即 $B[i][j]=A[N-1-j][i]$。证毕。

**引理 2**（一轮读取的顺序）：算法在某一轮中按"先枚举行 $i$ 从小到大、再枚举列 $j$ 从小到大"的顺序访问格子，因此读出的字母顺序恰为题面要求的"从上到下、从左到右"。

*证明*：双重循环 `for(i) for(j)` 的执行顺序是 $(0,0),(0,1),\dots,(0,N-1),(1,0),\dots$，即先行后列，行号与列号都非降。这正是"从上到下、同一行内从左到右"的顺序。每次访问时若该格为 `O` 则追加字母，故追加顺序与要求一致。证毕。

**引理 3**（四轮读到的内容）：算法的四轮读取，恰好对应题面的四次读取（初始、第 1 次旋转后、第 2 次旋转后、第 3 次旋转后）。

*证明*：算法先在未旋转状态下读一轮（$t=0$），随后每次读完后若 $t<3$ 则旋转一次。归纳可得：第 $t$ 轮（$t=0,1,2,3$）读到的透明纸恰好是原始透明纸顺时针旋转 $90^\circ t$ 次的结果，因为第 $t$ 轮之前恰好发生了 $t$ 次旋转。由引理 1，每次旋转的结果与真实旋转一致。又由引理 2，每轮的读取顺序与题面一致。证毕。

**引理 4**（透明纸旋转、字母纸不动）：算法始终以当前的 `msk` 作为透明纸、`tx` 始终不变，符合题面"把透明纸盖在字母纸上，转个 90 度再读"的物理过程。

*证明*：算法中 `rot()` 只修改 `msk`，`tx` 从未被写；读取时用同一份 `tx` 与当前的 `msk` 逐格配对。这正是"透明纸在动、字母纸静止"的叠放方式。证毕。

**定理**：算法输出的字符串即题目要求的情书内容。

*证明*：由引理 3，算法进行了题面要求的四次读取，每次的透明纸状态正确（引理 1、4）；由引理 2，每次读取的字母顺序与题面一致；每次读取只取透明纸上未涂黑（`O`）的格子对应的字母，与"把露出来的字母写下来"一致。所有四次的字母按时间顺序拼接即为情书内容。证毕。

## 三、模式总结（按实际思考顺序）

1. **读题时最关键的一句话是"转的是透明纸"** — 因为它"盖在"字母纸上，动的是上面那层。
2. **用样例确认** — 算出 `ACMCENTRALEUROPE`，与题面"CM CENTRAL EUROPE"吻合，确认理解无误（也能排除"转字母纸"的误解）。
3. **推旋转坐标** — 顺时针 90°：$(r,c)\to(c,N-1-r)$，等价 `new[i][j]=old[N-1-j][i]`。这里差点写成逆时针，靠样例抓到。
4. **读法就是行优先扫描** — 双层循环天然有序，不需要额外排序。
5. **次数** — 读 4 次，中间转 3 次。
6. **规模** — $N\le1000$，$O(N^2)$ 无压力。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $N$ | 纸张边长 | `int`，$\le 1000$ |
| `msk[i][j]` | 透明纸第 $i$ 行第 $j$ 列：`O` 露出、`#` 涂黑 | `char[][ ]`，$0..N-1$ |
| `tx[i][j]` | 字母纸对应位置的字母 | `char[][ ]`，$0..N-1$ |
| `ans` | 拼接出的情书内容 | `string`，长度 $\le 4N^2$ |
| `rot()` | 把透明纸顺时针转 $90^\circ$ | 无返回值 |

### 算法步骤

1. 读入 $N$；读入 $N$ 行透明纸 `msk`、$N$ 行字母纸 `tx`。
2. `ans` 清空。
3. 对 $t=0,1,2,3$：
   - 双层循环遍历 `msk`，遇 `msk[i][j]=='O'` 则 `ans += tx[i][j]`；
   - 若 $t<3$ 则调用 `rot()` 把透明纸顺时针转 $90^\circ$。
4. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(N^2)$（读 4 遍、转 3 遍，均为 $O(N^2)$）。
- 空间复杂度：$O(N^2)$（两张纸 + 一张旋转用临时表）。

### 验证状态

- 标程 `P2191.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 编写暴力 `P2191_brute.cpp`（采用与标程**不同**的旋转实现：直接把旧矩阵按 $(r,c)\to(c,N-1-r)$ 就地重排到另一个缓冲区，坐标映射写法与标程相反，用于交叉验证旋转公式）与对拍脚本 `P2191_check.py`，在 $1\le N\le 12$ 的随机透明纸/字母纸上对拍 **2000 组全部通过**。
- 手工验证：题面样例（$N=4$）输出 `ACMCENTRALEUROPE`，与题面"CM CENTRAL EUROPE"的示意一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2191 小Z的情书
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n;
char msk[mxn][mxn],tx[mxn][mxn];

// 顺时针旋转 90 度：new[i][j] = old[n-1-j][i]
void rot()
{
	static char tmp[mxn][mxn];
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			tmp[i][j]=msk[n-1-j][i];
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			msk[i][j]=tmp[i][j];
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>msk[i];
	for(int i=0;i<n;++i)
		cin>>tx[i];
	string ans;
	// 只旋转透明纸，字母纸固定不动，共读 4 遍
	for(int t=0;t<4;++t)
	{
		for(int i=0;i<n;++i)
			for(int j=0;j<n;++j)
				if(msk[i][j]=='O')
					ans+=tx[i][j];
		if(t<3)
			rot();
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `rot()` 里 `tmp` 声明为 `static`，避免 $1005^2\approx1$ MB 的局部数组占用栈空间。
- 旋转公式 `tmp[i][j]=msk[n-1-j][i]` 是**顺时针**；写成 `msk[j][n-1-i]` 就变成逆时针了，是本题最容易搞反的地方。
- 只旋转 `msk`，`tx` 全程不动——这正是"透明纸盖在字母纸上、转动透明纸"的含义。
- 读取时用 `msk[i][j]=='O'` 判断露出（涂黑的是 `'#'`）。
- 循环 `for(t=0;t<4;++t)` 中只在 `t<3` 时旋转，保证总共读 4 遍、只转 3 次。
- 答案串用 `string` 累加，`ans += tx[i][j]` 逐字符追加，长度可达 $4\times10^6$，`string` 会自动扩容。
