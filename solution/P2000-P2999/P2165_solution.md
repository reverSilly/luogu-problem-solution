# P2165 [AHOI2009] 飞行棋 — 题解

## 一、解题过程：人类思考叙事

题目给一个圆，圆周上按顺序摆着 $N$ 个点，给出相邻点之间的弧长（正整数），问这些点能围出多少个**互不重复的矩形**。

$N\le 20$，$N^4=160000$，枚举四个点判断能否围成矩形，暴力完全可行。所以本题的难点**不在算法，而在几何**：

> 圆内接四边形是矩形，当且仅当它的两条对角线都是直径。

这就是**泰勒斯定理**（半圆所对的圆周角是直角）的推论。

推论怎么来的？

- **必要性**：矩形的四个角都是直角，由泰勒斯定理，$90^\circ$ 的圆周角所对的弦是直径。而矩形的两条对角线各自平分一个对角（都是 $90^\circ$），所以两条对角线都是直径。反过来说，矩形的对角线交点就是圆心（矩形外接圆圆心在对角线交点）。
- **充分性**：若四点的两条对角线都是直径，那么每个内角所对的弧是半圆，圆周角为 $90^\circ$，四边形就是矩形。

于是问题变成：**数一数圆上有多少对点是对径点（互为直径端点）**。

设对径点对的数量为 $cnt$，则答案就是从这 $cnt$ 条直径里任选两条：$\binom{cnt}{2}=\dfrac{cnt(cnt-1)}{2}$。

为什么选两条直径就唯一确定一个矩形？因为两条不同的直径端点共 $4$ 个点，按圆周顺序排开，相邻两点连线、相对两点连成直径，就是一个矩形；反过来每个矩形恰好由它的两条对角线（两条直径）唯一确定，所以不会重复计数。

### 怎么数对径点？

把圆周"拉直"成一个长度为 $S$ 的区间（$S=\sum len_i$ 即周长），用**弧长前缀和**给每个点定位：

$$pos[0]=0,\qquad pos[i]=pos[i-1]+len[i-1].$$

点 $i$ 的坐标就是从点 $0$ 沿正方向走到的弧长 $pos[i]$。点 $i,j$（$i<j$）互为对径点，当且仅当两点间弧长恰好是周长的一半：

$$pos[j]-pos[i]=\frac{S}{2}.$$

因为 $S$ 可能是奇数而弧长是整数，所以 $S$ 为奇数时**不存在**对径点，答案直接为 $0$。

枚举所有点对 $(i,j)$，$i<j$，判断 `pos[j]-pos[i]==S/2`，统计个数 `cnt`，最后输出 `cnt*(cnt-1)/2`。

时间复杂度 $O(N^2)$，比 $O(N^4)$ 的暴力优雅得多，而且 $N\le20$ 时完全够用。

## 二、思维链：完整证明

**引理 1（泰勒斯定理的推论：半圆所对圆周角为直角）**：在圆上，若点 $P,Q,R$ 满足 $PQ$ 是直径，则 $\angle PRQ=90^\circ$；反之，若 $\angle PRQ=90^\circ$ 则 $PQ$ 是直径。

*证明*：设圆心为原点 $O=(0,0)$，半径为 $R$。
**正向**（直径所对的圆周角是直角）：设 $P=(-R,0)$、$Q=(R,0)$ 是直径两端，任取圆上点 $W=(R\cos\varphi,R\sin\varphi)$，则
$$\overrightarrow{WP}=(-R-R\cos\varphi,\,-R\sin\varphi),\qquad \overrightarrow{WQ}=(R-R\cos\varphi,\,-R\sin\varphi),$$
两者点积为
$$(-R-R\cos\varphi)(R-R\cos\varphi)+R^2\sin^2\varphi=-R^2+R^2\cos^2\varphi+R^2\sin^2\varphi=0,$$
故 $WP\perp WQ$，即 $\angle PWQ=90^\circ$。
**逆向**（直角所对的弦是直径）：设 $\angle PWQ=90^\circ$，$P,W,Q$ 互异。令 $M$ 为 $PQ$ 的中点。由勾股定理 $PQ^2=PW^2+WQ^2$，由中线公式
$$MW^2=\frac{PW^2+WQ^2}{2}-\frac{PQ^2}{4}=\frac{PQ^2}{2}-\frac{PQ^2}{4}=\frac{PQ^2}{4},$$
又 $MP=MQ=PQ/2$，故 $MP=MQ=MW$，即 $P,W,Q$ 同在以 $M$ 为圆心、$PQ/2$ 为半径的圆 $\Gamma'$ 上。
又 $P,W,Q$ 三点互异且不共线（否则 $\angle PWQ$ 无意义），而它们同时也在原圆 $\Gamma$ 上；两个不同的圆最多有两个公共点，故 $\Gamma'=\Gamma$。于是 $\Gamma$ 的直径为 $PQ$，即 $PQ$ 过圆心 $O$，是直径。证毕。

**引理 2（矩形的充要条件）**：圆上四点（互不相同）能围成一个矩形，当且仅当把它们按圆周顺序记为 $P_1,P_2,P_3,P_4$ 时，$P_1P_3$ 与 $P_2P_4$ 都是直径。

*证明*：
（$\Rightarrow$）设四边形 $P_1P_2P_3P_4$ 是矩形。矩形的两条对角线等长且互相平分，设交点为 $M$，则 $M$ 是 $P_1P_3$ 与 $P_2P_4$ 的中点。由矩形的勾股关系 $P_1P_2^2+P_2P_3^2=P_1P_3^2$，在三角形 $P_1P_2P_3$ 中由中线公式
$$MP_2^2=\frac{P_1P_2^2+P_2P_3^2}{2}-\frac{P_1P_3^2}{4}=\frac{P_1P_3^2}{2}-\frac{P_1P_3^2}{4}=\frac{P_1P_3^2}{4},$$
故 $MP_2=P_1P_3/2=MP_1$。同理由 $P_1P_2P_4P_3$ 得 $MP_4=MP_2$。于是 $MP_1=MP_2=MP_3=MP_4$，即 $M$ 到四个顶点等距，故 $M$ 就是四边形外接圆（也即题目的圆）的圆心 $O$。于是对角线 $P_1P_3$ 与 $P_2P_4$ 都过 $O$，即都是直径。
（$\Leftarrow$）设 $P_1P_3$ 与 $P_2P_4$ 都是直径。由引理 1，$\angle P_1P_2P_3=90^\circ$（它所对的弦 $P_1P_3$ 是直径），$\angle P_2P_3P_4=90^\circ$（所对弦 $P_2P_4$ 是直径），同理其余两角也都是 $90^\circ$，故四边形为矩形。证毕。

**引理 3（对径点的弧长刻画）**：设圆周长为 $S$，点 $i,j$ 的弧长坐标为 $pos[i]<pos[j]$，则点 $i,j$ 互为对径点，当且仅当 $pos[j]-pos[i]=S/2$。

*证明*：设圆心为 $O$，把点 $i$ 记为 $A$，沿正方向转过的弧长 $s$ 到达点 $j$ 记为 $B$。则圆心角 $\angle AOB=360^\circ\cdot s/S$。$A,B$ 互为对径点当且仅当 $\angle AOB=180^\circ$（两点关于圆心对称），即 $s=S/2$。而 $s=pos[j]-pos[i]$（弧长前缀和的定义），故结论成立。证毕。

**引理 4（`cnt` 的正确性）**：算法统计出的 `cnt` 等于圆上互为对径点的点对数。

*证明*：算法枚举所有 $0\le i<j<N$ 的点对。由引理 3，$i,j$ 互为对径点当且仅当 $pos[j]-pos[i]=S/2$，这正是算法所判断的条件，故被计入 `cnt` 的点对恰为全部对径点对。又因 $i<j$ 保证每对只被计一次。若 $S$ 为奇数，则 $S/2$ 非整数，而所有 $pos[j]-pos[i]$ 均为整数，不可能相等，故 `cnt=0`，此时跳过整个枚举是正确的。证毕。

**引理 5（答案公式的正确性）**：设对径点对数为 $cnt$，则能围成的互不重复矩形个数为 $\dfrac{cnt(cnt-1)}{2}$。

*证明*：
先证**存在性**：任取两条不同的直径，其四个端点互不相同（两条不同的直径除圆心外交于一点，端点必不同），按圆周顺序记为 $P_1,P_2,P_3,P_4$，则 $P_1P_3$ 与 $P_2P_4$ 正是这两条直径，由引理 2 这四点围成矩形。故每对直径对应一个矩形。
再证**唯一性（不重复）**：设 $P_1,P_2,P_3,P_4$ 按圆周顺序构成一个矩形。由引理 2，它的对角线 $P_1P_3$ 与 $P_2P_4$ 都是直径。反过来，若 $P_1P_3$ 与 $P_2P_4$ 是某两条直径 $d_1,d_2$，则矩形由 $d_1,d_2$ 唯一确定；且矩形的对角线只有这一对（矩形的对角线是确定的两条对角线），所以不同的直径对不可能产生同一个矩形。
最后，每个对径点对唯一对应一条直径（$cnt$ 就是直径条数），任选两条直径的方法数为 $\binom{cnt}{2}=\frac{cnt(cnt-1)}{2}$，由存在性与唯一性，答案即此值。证毕。

**定理**：算法输出的即题目所求的不重复矩形个数。

*证明*：由引理 4，算法得到的 `cnt` 是直径条数；由引理 5，答案恰为 $\frac{cnt(cnt-1)}{2}$，即程序输出。证毕。

**补充说明（`cnt` 的上界）**：一个点至多有一个对径点（对径点由它唯一确定：过该点的直径唯一），故 $cnt\le\lfloor N/2\rfloor$。因此答案最大为 $\binom{\lfloor N/2\rfloor}{2}$，在 $N\le20$ 时不超过 $45$，`int` 绰绰有余。

## 三、模式总结（按实际思考顺序）

1. "圆上的点围成矩形" ⇒ 想到**圆内接矩形 ⇒ 两条对角线是直径**（泰勒斯定理推论）
2. 于是"数矩形" ⇒ "数**直径条数**" ⇒ 答案 $\binom{cnt}{2}$，并证明一一对应（不重不漏）
3. "点是否互为对径点" ⇒ 把圆周拉成区间，用**弧长前缀和** $pos[i]$ 定位 ⇒ 判据 $pos[j]-pos[i]=S/2$
4. $S$ 为奇数 ⇒ $S/2$ 非整数 ⇒ 无对径点 ⇒ 答案 $0$，特判一下
5. 枚举点对计数 ⇒ $O(N^2)$，比 $O(N^4)$ 的暴力更优雅

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 |
|------|------|------|
| $N$ | 圆周上的点数 | `int` |
| `len[i]` | 点 $i$ 与点 $i+1$ 之间的弧长（下标 $N-1$ 对应最后一点回到点 $0$） | `int[mxn]` |
| `sum` | 圆周长 $S=\sum len[i]$ | `int` |
| `pos[i]` | 从点 $0$ 沿正方向走到点 $i$ 的弧长，$pos[0]=0$ | `int[mxn]` |
| `cnt` | 对径点对数 = 直径条数 | `int` |
| `ans` | 答案 $cnt(cnt-1)/2$ | `int` |

### 算法步骤

1. 读入 $N$ 与 `len[0..N-1]`，累加得 `sum`（圆周长）。
2. 计算弧长前缀和：`pos[0]=0`，`pos[i]=pos[i-1]+len[i-1]`。
3. 若 `sum` 为奇数，则 `cnt=0`（不存在整数弧长的一半），跳过枚举。
4. 否则枚举所有 $0\le i<j<N$，若 `pos[j]-pos[i]==sum/2` 则 `cnt++`。
5. 输出 `cnt*(cnt-1)/2`。

### 复杂度

- 时间复杂度 $O(N^2)$（枚举点对），$N\le20$ 时最多 $190$ 次比较。
- 空间复杂度 $O(N)$。
- 若用 $O(N^4)$ 的四点枚举暴力也可通过（$20^4/24\approx 6670$），但 $O(N^2)$ 的计数法更贴合结构。

### 验证状态

- 标程 `g++ -O2 -std=c++17` 编译通过。
- **对拍**：与附录 `P2165_brute.cpp`（枚举四点、判断两组对边是否均为对径点）随机对拍 $300$ 组（$N\in[4,10]$，弧长偏向小值以制造更多直径），全部一致（`all 300 cases match`）。
- 手工核对：`N=4`、弧长 `1 1 1 1`（正方形）⇒ $S=4$，对径点对为 $(0,2),(1,3)$，`cnt=2`，答案 $1$，符合预期；`N=4`、弧长 `1 1 1 2`（$S=5$ 奇数）⇒ 无对径点，答案 $0$，符合预期。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};

int len[mxn],pos[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	int sum=0;
	for(int i=0;i<n;++i)
	{
		cin>>len[i];
		sum+=len[i];
	}
	pos[0]=0;
	for(int i=1;i<n;++i)
		pos[i]=pos[i-1]+len[i-1];

	//内接矩形的对角线必为直径，统计直径条数再两两配对
	int cnt=0;
	if(sum%2==0)
		for(int i=0;i<n;++i)
			for(int j=i+1;j<n;++j)
				if(pos[j]-pos[i]==sum/2)
					++cnt;
	cout<<cnt*(cnt-1)/2<<'\n';
	return 0;
}
```

### 代码说明

- `mxn{25}` = 约束上界 $20$ + 5，符合"+5 松弛约定"。
- `len`、`pos` 是全局静态 `int` 数组，全局数组自动初始化为 $0$。
- 弧长前缀和 `pos[0]=0` 必须显式写，因为 `pos[1]=pos[0]+len[0]` 依赖它。
- `if(sum%2==0)` 特判奇数周长：此时 `sum/2` 不是整数，不存在对径点，`cnt` 保持 $0$。
- 点对枚举用 `for(int j=i+1;...)`，保证每对只数一次。
- 输出 `cnt*(cnt-1)/2`，`cnt` 至多 $10$，不会溢出。
- 换行用 `'\n'`。
