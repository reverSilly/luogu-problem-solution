# P2909 [USACO08OPEN] Cow Cars S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 有 $N$ 头牛（$1\le N\le 5\times10^4$），第 $i$ 头牛的"底子速度"为 $S_i$（$1\le S_i\le 10^6$）。高速公路有 $M$ 条车道（$1\le M\le N$）。一头牛若被安排上高速，它所在车道里排在它**前面**每多一头牛，它的实际速度就减少 $D$（$0\le D\le 5000$）：前面有 $K$ 头牛时实际速度为 $\max(S_i-DK,\,0)$。法律要求上高速的每头牛实际速度 $\ge L$（$1\le L\le 10^6$）。问最多能安排多少头牛上高速（每头牛最多占一个位置，车道内顺序任意安排）。

**口径说明（题面歧义的处理）。** 译文只说"在它前面的每一头奶牛"，没明说是否限同车道。我按**同车道**解读，依据有二：其一，若"前面"按全高速计数，则车道数 $M$ 对答案毫无影响，出题人给 $M$ 就成了废条件；其二，题面提示里"三头牛、一条车道"的语境正是把前后关系放在单车道内讨论的。这也是 USACO 原题的本意。

**两个立刻能做的化简。**

1. 因为 $L\ge 1>0$，条件 $\max(S_i-DK,0)\ge L$ 等价于 $S_i-DK\ge L$，即 $S_i\ge L+DK$。$\max$ 里的 $0$ 永远不可能达标，可以直接扔掉。
2. 一头牛合不合法，**只取决于它在车道里的深度**（前面有几头牛），与前面具体是谁无关。于是"车道 + 深度"这个位置本身自带一个门槛：深度 $k$ 的位置要求牛速 $\ge L+Dk$。

**第一步试探：这是不是一个匹配问题？** 把每条车道的每个深度看成一个"槽位"：深度 $0$ 有 $M$ 个槽（门槛 $L$），深度 $1$ 有 $M$ 个槽（门槛 $L+D$），……牛 $i$ 能放进槽位当且仅当 $S_i\ge$ 槽的门槛。目标是选出尽量多的"牛—槽"配对。看起来就是经典的"门槛匹配"。

但马上碰壁：**槽位不是独立的**。一条车道里深度 $2$ 的位置有人，深度 $0,1$ 必须也有人——你不能让一头牛悬空排在第三的位置而前面没牛。直接做匹配会不会选出"不合法"的槽位集合？

**修正：压缩引理。** 仔细一想这个担心是多余的：如果某条车道深度 $k$ 有牛而更浅的 $k'<k$ 空着，把这头牛**往前挪**到 $k'$，门槛从 $L+Dk$ 降到 $L+Dk'$，原来就达标的牛现在更达标。反复挪，任何匹配都能变成"每条车道从深度 $0$ 起连续占用"的合法形态，且配对数不减。所以**最大匹配数 = 答案**，槽位的依赖约束可以无视。

**第二步：门槛匹配怎么贪心？** 所有槽位按门槛排好是 $M$ 个 $L$、$M$ 个 $L+D$、$M$ 个 $L+2D$、……单调不降。牛按速度升序排。经典贪心：**从门槛最小的槽开始，每次用"能达标的牛里最慢的那头"去填**。两头直觉支撑：

- 慢牛留着没用——后面的槽门槛只会更高，现在都达不了标的牛，以后永远达不了标，直接丢弃；
- 好钢用在刀刃上——快牛应该留给后面更深的槽，浅槽用慢牛填才不浪费。

这两条都能用交换论证严格证明（Part 2 引理 4）。

**第三步：把贪心压成一行。** 槽位按门槛升序排成序列，第 $t$ 个槽（$0$-based）的深度是 $\lfloor t/M\rfloor$（每 $M$ 个槽一层，轮流分配给 $M$ 条车道）。设已填 $ans$ 个槽，下一个槽门槛就是 $L+D\lfloor ans/M\rfloor$。于是排序后扫一遍牛：`if(s[i]>=L+D*(ans/M)) ++ans;`。这个填槽顺序还**自动满足前缀连续**：深度 $k$ 的槽一定在深度 $k-1$ 的 $M$ 个槽全填完之后才轮到，压缩引理都省了。

**边界核对。** $D=0$：门槛恒为 $L$，算法退化为"数一数有多少 $S_i\ge L$"，正确。$M=N$：每头牛都可以独占一条车道深度 $0$，门槛恒为 $L$（$ans/M\le (N-1)/N=0$），同样正确。$L>S_i$ 的牛永远进不来，排序后第一头就不达标，$ans$ 停在 $0$。

**手造小数据核对**（题面没有正式样例，只有提示文字；我按提示构造并另造两组）：

第一组，按提示"三头牛、一条车道、$D=1$、$L=5$，可让速度 $5$ 和 $7$ 的牛上路"，取 $S=\{5,7,5\}$：

```
输入：3 1 1 5 / 5 7 5
排序后 5,5,7；槽门槛 5,6,7。
5≥5 收（ans=1）；5<6 丢；7≥6 收（ans=2）。输出 2 ✓
```

与提示"两头牛（$5$ 在前、$7$ 在后，$7-1=6\ge5$）"吻合；第三头 $5$ 无论放哪深度都 $\ge1$，$5-1=4<5$，确实上不了。

第二组，专打"慢牛被跳过、快牛补深槽"：$N=4,M=2,D=3,L=4$，$S=\{4,4,4,100\}$。槽门槛 $4,4,7,7$。排序 $4,4,4,100$：前两头填深度 $0$；第三头 $4<7$ 丢弃；$100\ge7$ 填深度 $1$。输出 $3$。手工验证：两条车道各一头 $4$ 打头，其中一条后面跟 $100$（$100-3=97\ge4$），第三头 $4$ 放任何深度 $1$ 都只剩 $1<4$，$3$ 确为最优。

第三组，专打 $D=0$ 与 $M=N$：$N=4,M=4,D=5000,L=1$，$S=\{1,1,1,1\}$，每头独占一车道，输出 $4$；以及 $N=1,M=1,D=0,L=10^6,S_1=10^6$，输出 $1$（恰好踩线）。

## 二、思维链：完整证明

**记号。** 牛速多重集 $S=\{S_1,\dots,S_N\}$。槽位集合 $\mathcal{T}=\{(j,k):0\le j<M,\ k\ge0\}$，槽 $(j,k)$ 表示车道 $j$ 深度 $k$，门槛 $t(j,k)=L+Dk$。一个**配置**是：选若干牛，每条车道排出一个先后序列。配置合法当且仅当每头上路的牛满足 $S_i\ge L+D\cdot(\text{它前面的牛数})$。

---

### 引理 1（ legality 的门槛化）

配置中一头位于深度 $k$ 的牛合法 $\iff S_i\ge L+Dk$。

*证明*：题面条件为 $\max(S_i-Dk,0)\ge L$。若 $S_i-Dk\le 0$，左边 $=0<L$（因 $L\ge1$），不合法；若 $S_i-Dk>0$，左边 $=S_i-Dk$，条件即 $S_i-Dk\ge L\iff S_i\ge L+Dk$。而 $S_i\ge L+Dk\ge L\ge1>0$ 时自动落入第二分支。故两条件等价。证毕。

这条引理把 $\max$ 彻底消掉，后面不再出现。

---

### 引理 2（配置 $\Rightarrow$ 匹配）

任何合法配置若含 $K$ 头牛，则存在一个大小为 $K$ 的"牛—槽"匹配，每对 $(i,(j,k))$ 满足 $S_i\ge t(j,k)$。

*证明*：把每头牛映到它实际占据的 (车道, 深度)。不同牛占不同位置，故是单射；深度 $k$ 的定义就是"同车道前面的牛数"，由引理 1，$S_i\ge L+Dk=t(j,k)$。证毕。

---

### 引理 3（匹配 $\Rightarrow$ 合法配置：压缩）

任何大小为 $K$ 的"牛—槽"匹配（每对满足门槛），都能改造成含 $K$ 头牛的**合法配置**。

*证明*：先做**压缩**：若某车道 $j$ 的占用深度集合不是 $\{0,1,\dots,c_j-1\}$ 的形式（$c_j$ 为该车道被占槽数），则存在深度 $k$ 被占而某 $k'<k$ 空闲；把深度 $k$ 的牛移到 $k'$，门槛由 $L+Dk$ 降为 $L+Dk'\le L+Dk\le S_i$，仍达标。每做一次压缩，该车道占用深度之和严格减小（$k\to k'$），且所有深度非负，故过程必然终止；终止时每条车道占用深度恰为 $\{0,\dots,c_j-1\}$。

再**落地**：车道 $j$ 里把牛按深度从小到大排成先后序列。深度 $k$ 的牛前面恰有 $k$ 头牛（深度 $0..k-1$ 各一头），由引理 1 它合法。所有 $K$ 头牛都合法，配置合法。证毕。

**推论**：答案 $=$ 牛与槽之间满足门槛的最大匹配数。引理 2 给"$\le$"，引理 3 给"$\ge$"。

---

### 引理 4（门槛匹配的贪心最优性）

把槽按门槛升序排成 $t_0\le t_1\le t_2\le\cdots$（本题即 $M$ 个 $L$、$M$ 个 $L+D$、……），牛按速度升序排成 $s_0\le s_1\le\cdots\le s_{N-1}$。执行贪心：指针 $j=0$；依次看每头牛 $s_i$，若 $s_i\ge t_j$ 则配对 $(i,j)$ 并 $++j$，否则丢弃牛 $i$。则贪心配对数等于最大匹配数。

*证明*：先注意门槛序列单调不降（$t_j=L+D\lfloor j/M\rfloor$），这是全部论证的支点。

**观察 A（丢弃无害）**：若 $s_i<t_j$，则对一切 $j'\ge j$ 有 $s_i<t_j\le t_{j'}$，牛 $i$ 在任何"尚未填的槽"里都不达标。

**观察 B（最小配最小）**：设当前要填槽 $j$，$s_i$ 是剩余牛中第一头达标的。若某最优解把更大的牛 $s_{i'}\ (i'>i)$ 放在槽 $j$，而 $s_i$ 放在更深的槽 $j''>j$ 或闲置，则可以交换：$s_i\ge t_j$ 已知；$s_{i'}\ge s_i\ge t_{j''}$（升序），故 $s_{i'}$ 放 $j''$ 也达标。交换后匹配数不减。

下面用**归纳不变量**把两条观察拼成严格证明。设贪心处理完前 $i$ 头牛、填了 $j$ 个槽。不变量 $P(i)$：存在一个**最大**匹配 $\mathrm{OPT}$，使得

- 牛 $0..i-1$ 中恰有贪心选中的那 $j$ 头出现在 $\mathrm{OPT}$ 里，且它们配的正是槽 $0..j-1$（与贪心逐对相同）；
- 牛 $0..i-1$ 中其余的牛不出现在 $\mathrm{OPT}$ 里。

**基例** $i=0$：任何最大匹配都满足（前 $0$ 头牛为空）。

**归纳步**：设 $P(i)$ 成立，看牛 $i$。

*情形 1：$s_i<t_j$（贪心丢弃）。* $\mathrm{OPT}$ 里槽 $0..j-1$ 已被贪心选中的牛占据；牛 $i$ 若能出现在 $\mathrm{OPT}$，只能配某个槽 $j'\ge j$，但 $s_i<t_j\le t_{j'}$，不达标。故牛 $i$ 本就不在 $\mathrm{OPT}$ 里，$P(i+1)$ 直接成立（$j$ 不变）。

*情形 2：$s_i\ge t_j$（贪心配对 $(i,j)$）。* 分四个子情形改造 $\mathrm{OPT}$，保持"最大"与不变量：

- (2a) $\mathrm{OPT}$ 已含 $(i,j)$：无需改动。
- (2b) $\mathrm{OPT}$ 含 $(i,j'')$，$j''>j$，且槽 $j$ 被某牛 $c$ 占据：由不变量，$c$ 的编号 $\ge i$（编号 $<i$ 的牛只配槽 $<j$），故 $s_c\ge s_i$；又 $(i,j'')\in\mathrm{OPT}$ 给出 $s_i\ge t_{j''}$。于是 $s_c\ge t_{j''}$，把 $(i,j''),(c,j)$ 换成 $(i,j),(c,j'')$，仍全达标，大小不变。
- (2c) $\mathrm{OPT}$ 含 $(i,j'')$，$j''>j$，槽 $j$ 空闲：把 $(i,j'')$ 改成 $(i,j)$（$t_j\le t_{j''}$，达标），大小不变。
- (2d) $\mathrm{OPT}$ 不含牛 $i$：若槽 $j$ 被牛 $c$ 占据，同上 $s_c\ge s_i\ge t_j$，把 $(c,j)$ 换成 $(i,j)$，大小不变；若槽 $j$ 也空闲，则加入 $(i,j)$ 使匹配变大 $1$，与 $\mathrm{OPT}$ 最大矛盾——此子情形不可能发生。

四个子情形穷尽（牛 $i$ 在/不在 $\mathrm{OPT}$；在则配槽 $j$ 或更深；不在则槽 $j$ 被占或空），每个都得到满足 $P(i+1)$ 的最大匹配（$j$ 加 $1$）。归纳完成。

处理完全部 $N$ 头牛后，$P(N)$ 说：存在最大匹配，其中被使用的牛恰为贪心选中的 $ans$ 头（其余牛都不在）。该匹配大小 $\le ans$（槽 $0..ans-1$ 各一对），而它又是最大的且贪心匹配本身合法，故最大匹配数 $=ans$。证毕。

---

### 引理 5（一行实现的槽序正确性）

贪心第 $j$ 个槽（$0$-based）可取为车道 $j\bmod M$、深度 $\lfloor j/M\rfloor$，门槛 $L+D\lfloor j/M\rfloor$；且按此顺序填槽自动满足"每车道前缀连续"。

*证明*：门槛只依赖深度。深度 $k$ 的槽共 $M$ 个，把槽按 $(k,j)$ 字典序排列即得序列 $t_j=L+D\lfloor j/M\rfloor$，单调不降，正是引理 4 需要的顺序。前缀连续：车道 $j$ 深度 $k$ 的槽序号为 $kM+j$，它被填时所有序号 $<kM+j$ 的槽都已填（贪心顺序填），特别地同车道深度 $k-1$ 的槽序号 $(k-1)M+j<kM+j$ 已填。故任何时刻每条车道的占用深度都是 $\{0,\dots,c-1\}$。证毕。

于是代码里 `ans` 就是已填槽数，下一槽门槛 `l+d*(ans/m)`，无需真的维护 $M$ 条车道。

---

### 引理 6（复杂度与整数范围）

时间 $O(N\log N)$，空间 $O(N)$；全程 `int` 不溢出。

*证明*：排序 $O(N\log N)$，扫描 $O(N)$，每头牛一次比较。空间只有一个 $N$ 长的速度数组。范围：$ans\le N\le5\times10^4$，$\lfloor ans/M\rfloor\le5\times10^4$，$D\lfloor ans/M\rfloor\le5000\times5\times10^4=2.5\times10^8$，加 $L\le10^6$ 后 $\le2.51\times10^8<2^{31}-1\approx2.147\times10^9$，`int` 安全。证毕。

---

### 定理

程序输出合法上路的最大牛数，时间 $O(N\log N)$。

*证明*：引理 1 把 legality 化成门槛；引理 2、3 把原问题等价归约为牛—槽最大匹配；引理 4 证明升序贪心给出最大匹配；引理 5 证明一行扫描正是该贪心且填槽形态合法；引理 6 给出复杂度与范围安全。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — $L\ge1$ 使 $\max(S-DK,0)\ge L\iff S\ge L+DK$；合法性只依赖"车道内深度"，位置自带门槛。
2. **reduce to easier problem** — 把配置归约成"牛—槽"门槛匹配；槽位的前缀依赖用压缩引理消除（往前挪门槛只降不升）。
3. **consider easier version** — 先想 $D=0$：门槛恒为 $L$，答案就是 $\ge L$ 的牛数；提示一般情形只是"门槛分层"。
4. **classic problem solution** — 门槛匹配的经典贪心：双方升序，最小达标牛填最小空槽；丢弃不达标牛、交换论证保最优。
5. **reduce to easier problem** — 槽按深度分层、每层 $M$ 个 ⇒ 第 $ans$ 个槽门槛 $L+D\lfloor ans/M\rfloor$，整个贪心塌缩成排序后一行 `if`。
6. **explore its property** — 范围核算 $D\cdot N+L\le2.51\times10^8$，`int` 够用；$D=0$、$M=N$、全不达标三个边界逐一核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,m,d,l` | 牛数、车道数、每头前方牛减速、最低限速 | `int` | 读入 |
| `s[i]` | 第 $i$ 头牛的底子速度（读入后排序，编号不再重要） | `int[mxn]` | 读入，升序排序 |
| `ans` | 已填槽数 = 已收牛数 | `int` | 全局默认 $0$；**下一槽深度 = `ans/m`** |
| `mxn` | $50000+5$ | `constexpr int` | 速度数组尺寸 |
| `l+d*(ans/m)` | 下一个槽的门槛 $L+D\lfloor ans/M\rfloor$ | `int` 表达式 | 每头牛现算；$\le2.51\times10^8$ 不爆 |

### 算法步骤

1. I/O 加速三行；读 $N,M,D,L$ 与全部 $S_i$。
2. `sort(s,s+n)` 升序。
3. 顺序扫每头牛：若 `s[i]>=l+d*(ans/m)` 则 `++ans`（收进当前最浅空槽），否则丢弃。
4. 输出 `ans`。

### 复杂度

- 时间 $O(N\log N)$（排序主导），空间 $O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；提示反推数据（$3,1,1,5$；$5,7,5$）输出 $2$，另造"慢牛跳过快牛补深槽"（输出 $3$）、$D=0$/$M=N$（输出 $4$）、踩线 $L=S=10^6$（输出 $1$）共五组手算数据全部吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2909 [USACO08OPEN] Cow Cars S
// 每头在高速上的牛速度 = max(S-D*同车道前方牛数,0)，须 >=L。
// 位置 (车道,深度k) 是一个门槛为 L+D*k 的"槽位"；按门槛从小到大、
// 牛速从小到大贪心匹配：排序后扫一遍，s[i]>=L+D*(ans/M) 就收。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005};

int n,m,d,l,s[mxn],ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>d>>l;
	for(int i=0;i<n;++i)
		cin>>s[i];
	sort(s,s+n);
	for(int i=0;i<n;++i)
		if(s[i]>=l+d*(ans/m))	// ans/m = 当前最浅空槽的深度；d*(ans/m)<=2.5e8 不爆 int
			++ans;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 全部魔法都在 `l+d*(ans/m)` 这一个表达式里：`ans` 是已收牛数，第 `ans` 个槽的深度是 `ans/m`（每 $M$ 个槽一层）。不需要显式维护 $M$ 条车道。
- 排序必须**升序**：贪心是"最慢的达标牛填最浅的槽"。降序会先把快牛浪费在浅槽上，直接错。
- 不达标的牛被 `if` 静默跳过——它连当前最浅的空槽都进不了，更深的槽门槛更高，永远没用（引理 4 观察 A）。
- `ans/m` 是整数除法，恰好是 $\lfloor ans/M\rfloor$；`d*(ans/m)` 上界 $2.5\times10^8$，`int` 安全，无需 `long long`。
- 本题没有"不可达"状态，`ans` 从 $0$ 起步就是正确初值，不涉及 INF 填充陷阱。
