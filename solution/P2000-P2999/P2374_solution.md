# P2374 搬运工 — 题解

## 一、解题过程：人类思考叙事

**先把题面准确重述一遍。** 桌上有三堆书，分别有 $i,j,k$ 本，第 $t$ 堆的书从**下到上**给出质量（$t=1,2,3$）。每次只能从**某一堆的最上面**取一本书，一共取 $i+j+k$ 次把所有书取完。取第 $m$ 本书时"体力系数"为 $m$，这一次的体力消耗是 $m\times$ 这本书的质量。要求设计取书顺序，使总消耗**最大**，输出这个最大值。

规模：$0\le i,j,k<100$（即每堆至多 $99$ 本，总书数至多 $297$）。题面保证最终答案在 `int` 范围内。

**第一件事：看清目标函数是什么。** 总消耗 $=\sum_{m=1}^{N}m\cdot w_m$，其中 $w_m$ 是第 $m$ 个被取出的书的质量，$N=i+j+k$。也就是说：**越晚被取出的书，系数越大**。要让总和最大，就希望**重的书拿到大的系数**（晚取），轻的书拿小的系数（早取）。

如果能自由排序，答案就是把所有书按质量升序取出（任意一对"重的在前、轻的在后"的相邻书都能交换，交换后总和增加 $w_{\text{前}}-w_{\text{后}}>0$）——但排序被"栈"约束住了：每堆内部的取出顺序被强制成"从上到下"。

**第一个念头：贪心——每次取当前三堆顶部最重的那本。** 乍看很合理（"重的先取，让它先出场"）。但等一下，重书先出场就意味着它拿到的是**小系数**，方向反了。手算一个反例：

- 第一堆（下→上）：$100,\ 1$，即顶上是 1；第二堆：$99$。
- "最重优先"：取 $99$（系数 1），再取 $1$（系数 2），最后取 $100$（系数 3），总消耗 $=99+2+300=401$。
- 而顺序 $1,99,100$：$1+198+300=499$。**更好。**

所以"最重优先"错得很离谱：它把最贵的系数 $3$ 送给了本来应该早点走的那本书。

**第二个念头：那就反过来，每次取顶部最轻的。** 这个方向看起来是对的：轻书早走拿小系数，重书晚走拿大系数。先用**交换论证**把这个直觉固定下来：

> 若相邻两次取书来自**不同**的堆，设先取 $x$ 后取 $y$。交换这两次的顺序仍然合法（$x$ 在交换前就露在顶上，$y$ 的堆中间没有被取过书）。交换后总消耗的变化是 $w_x-w_y$。所以只要 $w_x>w_y$，交换就能让答案变大。

于是得到一条**必要条件**：最优顺序里，任何"相邻且来自不同堆"的两本书，必须满足前面的不比后面的重。

"顶部最轻优先"看起来正好符合这条必要条件，很多人到这里就收工了。但它**仍然是错的**：

- 第一堆：$5$（只有一本）；第二堆（下→上）：$1,1,1,10$，顶上是 10。
- "顶部最轻优先"：先取 $5$（系数 1），再取 $10$（系数 2），然后三个 $1$（系数 $3,4,5$），总消耗 $=5+20+3+4+5=37$。
- 而顺序 $10,1,1,1,5$：$10+2+3+4+25=44$。**更好。**

**为什么会这样？** 看贪心给出的顺序 $5,10,1$：$10$ 后面紧跟着来自另一堆的 $1$，$10>1$，**恰好违反了上面那条必要条件**，所以它不可能是最优的。问题出在：那三个 $1$ 被 $10$ 压在下面，**根本不可能提前出场**，它们没有资格参与"谁先谁后"的竞争；而 $5$ 是"自由身"，可以安排在任何位置，那就应该把它留到**系数最大**的末尾去。贪心只比较"当前的顶部"，看不到"顶部下面还压着什么"，也看不到"这本书将来能拿到多大的系数"。

**关键反思：为什么贪心注定不行？** 因为一本书贡献的是"系数 $\times$ 质量"，而系数是它在**整个序列**里的位置。任何"当前这一步选谁"的局部规则，都无法预知这个选择会把后面多少本书的系数推后、会把哪个大系数留给谁。局部信息不足以决定全局最优。

**既然局部规则不行，就只能把"所有可能的交错方式"都考虑进来。** 直接枚举是 $(i+j+k)!/(i!j!k!)$ 种，天文数字。但注意到一件事：**一个局面的全部信息就是"三堆各取走了多少本"**。取走 $a$ 本之后，第一堆剩下的必然是"底下 $i-a$ 本"，下一次露出来的书是确定的，下一次的系数也确定是 $a+b+c+1$。所以状态 $(a,b,c)$ 是一个**完备摘要**，而它只有 $(i+1)(j+1)(k+1)\le100^3=10^6$ 个。

于是问题变成一个三维网格上的 DP：从 $(0,0,0)$ 走到 $(i,j,k)$，每步让某一维 $+1$，路径的权值就是每次取书的花费。**转移**很自然：$f[a][b][c]$ 表示"三堆各取走 $a,b,c$ 本时的最大消耗"，那么第 $a+b+c$ 次（最后一次）取的书只可能来自某一堆的顶部，三种来源取 $\max$。

**下标要小心。** 输入是"由下到上"给的，所以第一堆的第 $a$ 次取出（$a$ 从 1 开始）对应数组下标 $i-a+1$：$a=1$ 时是 $i$（最上面那本），$a=i$ 时是 $1$（最底下那本）。

**手造几组小数据走一遍**（题面没有给出样例数据）：

1. 只有一堆（后两堆是空的，所以后两行是空行）
```
3 0 0
1 2 3


```
顺序被完全锁死：$3,2,1$（上面先走），总消耗 $3\times1+2\times2+1\times3=10$。

2. 前面那个"最重优先"的反例
```
2 1 0
100 1
99

```
答案是 $499$（顺序 $1,99,100$）。

3. 前面那个"最轻优先"的反例
```
1 4 0
5
1 1 1 10
```
答案是 $44$（顺序 $10,1,1,1,5$）。

4. 三堆都空
```
0 0 0


```
没有任何书可取，总消耗 $0$。

**实现上的坑：**

- 某一堆为 $0$ 本时，题面那一行是空的；用 `cin>>` 连着读 $i+j+k$ 个数最省事，空白（包括空行）会被自动跳过，不必按行处理。
- `f` 数组要开 $(99+1)^3$ 级别的空间，`105³` 个 `int` 约 $4.6$ MB，安全；`int` 就够，因为题面保证答案在 `int` 内，且所有中间值都不超过答案（见引理 5）。
- 全局 `int` 数组默认是 0：本题恰好不需要 INF。$f[0][0][0]=0$ 是正确答案（一本没取，消耗 0），其它状态都会被转移式算出，且所有状态都可达（总可以先把某一堆取空再取下一堆）。这与"最短路"那类题必须 `fill` 成 INF 的情形不同。

## 二、思维链：完整证明

**记号**：第 $t$ 堆（$t=1,2,3$）的书从下到上编号为 $w_t[1],w_t[2],\dots,w_t[n_t]$（$n_1=i,n_2=j,n_3=k$），质量记 $w_t[s]$。$N=i+j+k$。一个"取书顺序"是长度为 $N$ 的序列，每项是一个堆号。

**引理 1（合法顺序的刻画）**：一个序列是合法的取书顺序，当且仅当对每个 $t$，第 $t$ 堆的书在序列中出现的顺序是 $w_t[n_t],w_t[n_t-1],\dots,w_t[1]$（即由顶到底）。并且第 $m$ 次取出的书的体力系数就是 $m$。

*证明*：系数部分是题意直接给出的（"取第 $m$ 本书时体力系数为 $m$"）。
（$\Rightarrow$）设序列合法。对第 $t$ 堆用归纳法：第一次从第 $t$ 堆取书时，这堆还完整，能取的只有最上面那本 $w_t[n_t]$；假设前 $r-1$ 次从该堆取走的依次是 $w_t[n_t],\dots,w_t[n_t-r+2]$，那么此刻该堆剩下的最上面一本正是 $w_t[n_t-r+1]$，所以第 $r$ 次只能取它。归纳得整堆的取出顺序由上到下。
（$\Leftarrow$）设每个堆内部都按由上到下的顺序出现。对序列长度归纳：第 $m$ 步要取的是第 $t$ 堆中尚未取过的第一本（按由上到下），由于它的所有上方书本已在前面出现过并被取走，它此刻就在顶上，所以这一步合法。证毕。

*这条引理说明"合法顺序"与"保持三个序列内部次序的归并（interleaving）"是一回事。*

**引理 2（状态完备性）**：设某个合法顺序的前 $a+b+c$ 次中，从三堆分别取了 $a,b,c$ 本。则（1）第 $t$ 堆已取走的恰是它最上面的 $a_t$ 本（$a_1=a,a_2=b,a_3=c$），剩下的恰是 $w_t[1..n_t-a_t]$；（2）下一次从第 $t$ 堆取书时取到的是 $w_t[n_t-a_t]$；（3）第 $a+b+c+1$ 次的体力系数是 $a+b+c+1$。以上三点都只依赖 $(a,b,c)$，与前面 $a+b+c$ 次的具体顺序无关。

*证明*：(1) 由引理 1，第 $t$ 堆的取出顺序是由上到下，所以取走 $a_t$ 本之后，被取走的正是最上面 $a_t$ 本，剩下的是底部 $n_t-a_t$ 本。(2) 紧接着要取的是这 $n_t-a_t$ 本中最上面的一本，即下标 $n_t-a_t$；把话说全：取第 $t$ 堆的**第 $r$ 本**（$r\ge1$）时，取到的是 $w_t[n_t-r+1]$（$r=1$ 给 $n_t$，即顶端；$r=n_t$ 给 $1$，即底端）。(3) 已取总数是 $a+b+c$，由引理 1 系数等于位置。三点都只由 $(a,b,c)$ 决定。证毕。

**引理 3（最优子结构与转移方程）**：定义
$$f[a][b][c]=\max\{\text{前 }a+b+c\text{ 次取书的总消耗}\ :\ \text{该前缀合法，且三堆分别取了 }a,b,c\text{ 本}\}.$$
（$0\le a\le i,0\le b\le j,0\le c\le k$；该集合非空，见引理 6。）则 $f[0][0][0]=0$，且当 $(a,b,c)\ne(0,0,0)$ 时
$$f[a][b][c]=\max\begin{cases}
f[a-1][b][c]+(a+b+c)\,w_1[i-a+1], & a>0,\\[2pt]
f[a][b-1][c]+(a+b+c)\,w_2[j-b+1], & b>0,\\[2pt]
f[a][b][c-1]+(a+b+c)\,w_3[k-c+1], & c>0.
\end{cases}$$

*证明*：

**上界方向。** 取一个取到 $f[a][b][c]$ 的合法前缀 $P$（长度 $a+b+c>0$）。它的最后一次取书来自某一堆，设来自第 1 堆（另两种情形对称）。删掉最后一次，得到长度 $a+b+c-1$ 的前缀 $P'$；$P'$ 仍合法，因为第 $m$ 步的合法性只取决于它前面取了哪些书，删掉末尾不改变前面任何一步；且 $P'$ 的三堆计数是 $(a-1,b,c)$。所以 $\mathrm{cost}(P')\le f[a-1][b][c]$。而由引理 2(2)(3)，最后一次取的是 $w_1[i-a+1]$、系数是 $a+b+c$，故
$$\mathrm{cost}(P)=\mathrm{cost}(P')+(a+b+c)w_1[i-a+1]\le f[a-1][b][c]+(a+b+c)w_1[i-a+1].$$
三种来源分别给出三个上界，故 $f[a][b][c]$ 不超过右端三项的最大值。

**下界方向（可构造）。** 设 $a>0$，取一个取到 $f[a-1][b][c]$ 的合法前缀 $P'$（存在性由引理 6），在它末尾追加"从第 1 堆取一本"。由引理 2(2)，此时第 1 堆的顶正是 $w_1[i-a+1]$，所以这一步合法；新前缀的计数是 $(a,b,c)$，消耗为 $f[a-1][b][c]+(a+b+c)w_1[i-a+1]$。故 $f[a][b][c]\ge$ 该项。对 $b>0$、$c>0$ 同理，取三者最大值仍不超过 $f[a][b][c]$。

两个方向合并，等式成立。$f[0][0][0]=0$ 是因为空前缀消耗为 0（且它是唯一的）。证毕。

**引理 4（迭代顺序满足依赖）**：对每个状态 $(a,b,c)$，转移式右端只引用 $a+b+c$ 严格更小的状态，因此按 $a$ 升序、$b$ 升序、$c$ 升序三重循环时，所有被引用的状态都已被计算。

*证明*：右端三个状态的和分别是 $(a-1)+b+c$、$a+(b-1)+c$、$a+b+(c-1)$，都等于 $a+b+c-1$。三重循环按字典序（$a$ 最外层）遍历，任何和更小的状态在字典序下都排在前面：若 $a'<a$ 则先被遍历；若 $a'=a,b'<b$ 则先被遍历；若 $a'=a,b'=b,c'<c$ 则先被遍历。故依赖先于使用。证毕。

**引理 5（`int` 够用）**：对任意状态 $(a,b,c)$，$f[a][b][c]\le f[i][j][k]$，即所有中间值都不超过最终答案；因此若答案在 `int` 范围内，全部 DP 值也在 `int` 范围内。

*证明*：设 $P$ 是取到 $f[a][b][c]$ 的合法前缀。由引理 6，$P$ 可以补全成一个完整的合法顺序 $Q$（长度 $N$）。$Q$ 的消耗 $=$ $\mathrm{cost}(P)+\sum_{\text{补上的部分}}m\cdot w_m$，而补上的每一项系数 $m\ge1$、质量 $w_m\ge0$（书的质量非负），故 $\mathrm{cost}(Q)\ge\mathrm{cost}(P)=f[a][b][c]$。而 $f[i][j][k]$ 是所有完整顺序消耗的最大值，故 $\ge\mathrm{cost}(Q)\ge f[a][b][c]$。证毕。

**引理 6（状态集非空且可补全）**：对任意 $0\le a\le i,0\le b\le j,0\le c\le k$，存在合法的、三堆计数为 $(a,b,c)$ 的前缀；并且任何这样的前缀都能补全为完整合法顺序。

*证明*：非空性：按"先取第 1 堆的 $a$ 本（由上到下）、再取第 2 堆的 $b$ 本、最后取第 3 堆的 $c$ 本"构造，每一步都取当前顶部，合法。可补全性：在这个前缀之后，把三堆剩下的书继续按"第 1 堆取完 → 第 2 堆取完 → 第 3 堆取完"的顺序取，每一步取的都是当前顶部，合法；补齐后总长度为 $N$。证毕。

**定理（答案）**：程序输出 $f[i][j][k]$，它等于所有合法完整顺序消耗的最大值。

*证明*：$f[i][j][k]$ 的定义就是"三堆各取 $i,j,k$ 本的合法前缀（即完整顺序）消耗的最大值"，与所求完全一致。引理 1 保证"合法前缀"与题面的取书规则等价，引理 3 保证转移式正确，引理 4 保证迭代能算出全部状态，因此程序输出的数就是答案。证毕。

**附：为什么"顶部最轻优先"会失败（引理 7 只给必要条件）**

*交换引理*：若一个合法顺序中相邻两次取书来自不同的堆，先取 $x$ 后取 $y$，则交换这两次后仍然合法，且总消耗变化量为 $w_x-w_y$。

*证明*：合法性：交换前第 $m$ 步取 $x$、第 $m+1$ 步取 $y$。交换后第 $m$ 步取 $y$：$y$ 在交换前第 $m+1$ 步合法，说明它当时在顶上，而第 $m$ 步只从 $x$ 所在的另一堆取走了 $x$，$y$ 所在堆没被动过，故 $y$ 现在仍在顶上；第 $m+1$ 步取 $x$：同理 $x$ 在交换前第 $m$ 步就在顶上，此后 $x$ 所在堆没被动过，故仍合法。消耗变化：交换前这两步贡献 $m\,w_x+(m+1)w_y$，交换后为 $m\,w_y+(m+1)w_x$，两者之差恰为 $w_x-w_y$。证毕。

推论：**最优顺序中不存在"相邻、来自不同堆、且前面那本更重"的两步**（否则交换后严格更优，矛盾）。这就是"必要条件"。

而"顶部最轻优先"不满足它：在反例 `[5]` 与 `[1,1,1,10]` 中，它给出的顺序 $5,10,1,1,1$ 里有相邻的 $10,1$（不同堆且 $10>1$），故一定不是最优。这正说明**必要条件的局部满足不等价于全局最优**——局部规则看不到"被压在下面的书暂时没有参赛资格"，也看不到"哪本书应该被留给末尾的大系数"。因此我们放弃贪心，改用可以覆盖全部交错方式的 DP。

## 三、模式总结（按实际思考顺序）

- explore its property — 总消耗 $=\sum_m m\cdot w_m$，系数是"全局位置"，故重书希望晚取；但每堆内部顺序被锁死成由上到下
- explore the greedy — 交换论证：相邻且来自不同堆的两步可以交换，消耗变化量 $=w_{\text{前}}-w_{\text{后}}$，于是最优解中这类相邻对必须"不减"
- refute the greedy — "顶部最重优先"反例（$[100,1]$ 与 $[99]$，401 vs 499）；"顶部最轻优先"反例（$[5]$ 与 $[1,1,1,10]$，37 vs 44），且后者给出的顺序本身就违反了交换引理
- reconsider the state — 系数取决于全局位置，局部信息不够；但"三堆各取走多少本"这组计数是局面的完备摘要（剩余内容与下一次系数都确定）
- classic problem solution — 在 $(a,b,c)$ 的三维计数格上做 DP，转移枚举"最后一次来自哪一堆"（三种），共 $(i+1)(j+1)(k+1)$ 个状态
- handle boundaries — 某一堆为 0 本；由下到上的下标映射 $n_t-a_t+1$；$f[0][0][0]=0$ 且无需 INF；所有中间值不超过答案故 `int` 安全

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|----------------|
| $i,j,k$（代码 `A,B,C`） | 三堆的书本数 | `int` | 输入，$<100$ |
| `w[t][s]` | 第 $t$ 堆（$t=0,1,2$）**由下到上**第 $s$ 本的质量 | `int[3][105]` | 输入，下标从 1 开始 |
| `f[a][b][c]` | 三堆各取走 $a,b,c$ 本时的最大总消耗 | `int[105][105][105]` | 全局默认 0，$f[0][0][0]=0$ 恰为正确答案；**无需 INF** |
| $a,b,c$ | 循环变量：各堆已取走的本数 | `int` | $0\le a\le A$ 等 |
| $t$ | 当前体力系数 $=a+b+c$ | `int` | 也是"已取总数"，即最后一次的系数 |
| `best` | 三种来源转移的最大值 | `int` | 初值 $-1$（每个状态至少有一种来源） |

### 算法步骤

1. 读入 $A,B,C$；依次读入三堆的质量，`w[0][1..A]`、`w[1][1..B]`、`w[2][1..C]`（由下到上）。某一堆为 0 本时那一行是空的，`cin>>` 会自动跳过空白。
2. 三重循环 `a=0..A`、`b=0..B`、`c=0..C`：
   1. `t=a+b+c`；若 `t==0` 跳过（$f[0][0][0]=0$ 已是答案）。
   2. `best=-1`；若 `a>0`，用 `f[a-1][b][c]+t*w[0][A-a+1]` 更新；`b>0`、`c>0` 同理用 `w[1][B-b+1]`、`w[2][C-c+1]`。
   3. `f[a][b][c]=best`。
3. 输出 `f[A][B][C]`。

下标记忆点：从第 $t$ 堆取第 $a_t$ 本时，取到的是 `w[t][n_t-a_t+1]`——`a_t=1` 取到顶端那本（下标 $n_t$），`a_t=n_t` 取到最底那本（下标 1）。

### 复杂度

- 时间：$O\big((i+1)(j+1)(k+1)\big)$，每个状态 3 次转移；最坏 $100^3=10^6$。
- 空间：$O\big((i+1)(j+1)(k+1)\big)$ 个 `int`，最坏约 $4.6$ MB。

### 状态的一句话验证

$f$ 的下标是"已取本数"而不是"剩余本数"，因此系数就是下标之和 $t$，最后一次的取书对象是 `w[t][n-t+1]` 的顶端；三个来源对应"最后一次来自哪一堆"，与引理 3 的转移逐一对应。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2374 搬运工
// f[a][b][c]：三堆分别已经取走 a,b,c 本时的最大消耗；此时体力系数 t=a+b+c，
// 最后一次取的书只能来自某一堆的顶部，三种来源取 max
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int A,B,C;
int w[3][mxn];        //w[t][1..n_t] 由下到上
int f[mxn][mxn][mxn]; //f[a][b][c]=前三堆各取 a,b,c 本的最大消耗

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>A>>B>>C;
	for(int i=1;i<=A;++i)cin>>w[0][i];
	for(int i=1;i<=B;++i)cin>>w[1][i];
	for(int i=1;i<=C;++i)cin>>w[2][i];
	for(int a=0;a<=A;++a)
		for(int b=0;b<=B;++b)
			for(int c=0;c<=C;++c)
			{
				int t=a+b+c;
				if(t==0)
					continue;
				int best=-1;
				if(a)best=max(best,f[a-1][b][c]+t*w[0][A-a+1]);
				if(b)best=max(best,f[a][b-1][c]+t*w[1][B-b+1]);
				if(c)best=max(best,f[a][b][c-1]+t*w[2][C-c+1]);
				f[a][b][c]=best;
			}
	cout<<f[A][B][C]<<'\n';
	return 0;
}
```

### 代码说明

- `w[t][s]` 是"由下到上"存储，所以"第 $a$ 次从该堆取"对应 `w[t][n_t-a+1]`，三处转移里分别写成 `A-a+1`、`B-b+1`、`C-c+1`。
- `f` 用全局三维数组，靠"全局默认 0"正好提供 $f[0][0][0]=0$；其它状态都在循环里被赋值，没有"未定义"的危险，因此不需要 `fill` 成 INF。
- `if(a)`、`if(b)`、`if(c)` 同时起到"越界保护"和"这堆还有书可取"的作用；因为状态数有限且每步只取一本，不可能从空堆取书。
- `best` 初值 $-1$：当 $t>0$ 时三种来源至少有一种可用，故一定会被更新。
- 三重循环的顺序满足引理 4 的依赖关系（$a$ 最外层，字典序保证 $a+b+c$ 更小的状态先算完）。
- 题面保证答案在 `int` 内，且由引理 5 所有中间值不超过答案，故全程 `int` 安全；若质量量级更大应改用 `long long`。
