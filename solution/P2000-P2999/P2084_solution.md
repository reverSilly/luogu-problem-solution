# P2084 进制转换 — 题解

## 一、解题过程：人类思考叙事

题目把进制转换写成了展开式：$(10101)_2 = 1\times 2^4 + 0\times 2^3 + 1\times 2^2 + 0\times 2^1 + 1\times 2^0$，并且强调"当系数为 $0$ 时，该单项式要省略"。

所以这题**根本不需要真的算出那个十进制大数**，它要的是**字符串**。这看起来像模拟题，但有两个细节容易翻车：

第一个细节：**$N$ 的位数不超过 1000**。$1000$ 位的十进制数早就超了 `long long`（$2^{63}$ 只有约 $19$ 位），所以必须用字符串 `string` 读入，一个字符一个字符处理。

第二个细节：**输出格式**。看官方样例：

```
输入
2 10101
输出
1*2^4+1*2^2+1*2^0
```

也就是说每一项的格式是 `系数*进制^指数`，项之间用 `+` 连接，而且**指数即使是 0 也要写出来**（`^0` 出现在样例末尾）。系数为 0 的项直接不输出。注意：项与项之间是 `+`，没有空格。

那系数为 0 的项省略之后，剩下的项用 `+` 连起来，怎么处理"第一个项前面不能有 `+`"？用一个 `first` 标志位即可。

那顺序呢？按题面给的式子，是**从高位到低位**（指数递减）。也就是字符串从左往右扫，指数从 `len-1` 递减到 `0`。

再看数据范围 $1 < M < 10$，也就是 $M\in\{2,\dots,9\}$，是个一位数，直接输出即可。而且因为 $M<10$ 且各位都是"正整数"（$0$ 除外，$0$ 只是要省略），系数字符本身直接就是那一位数字的值，输出字符 `'3'` 就等于输出系数 $3$。

等等，"$N$ 的位数不超过 1000 且均为正整数" —— 这里"均为正整数"应该指 $N$ 本身是正整数，即输入的数没有前导零（最高位不为 0）。不过为了稳妥，代码里不需要特殊处理前导零：如果最高位是 0 就说明该项系数为 0，按规则省略即可，逻辑自洽。

那么这题的做法就是：从左往右扫字符串，第 $i$ 个字符（0-based）对应的指数是 `len-1-i`；若该字符不是 `'0'`，就输出 `字符* M ^ 指数`，并按需在前面补 `+`。

这大概是整个 P2000~P2200 区间里最水的一题了。但它也是一道"读题读仔细"的题：输出格式里的 `*`、`^`、`+`、零项省略、`^0` 保留，每一个都是判题点。

## 二、思维链：完整证明

**引理 1**：设输入的 $M$ 进制数 $N$ 的十进制展开式为 $\sum_{k=0}^{L-1} d_k M^k$（$L$ 为 $N$ 的位数，$d_k$ 为对应数位上的数字），则从左往右第 $i$ 个字符（0-based）对应的指数为 $L-1-i$。

*证明*：$M$ 进制数的高位权重大。一个 $L$ 位数的最高位权值为 $M^{L-1}$，次高位为 $M^{L-2}$，依此类推，最低位为 $M^0$。字符串下标 $i$ 从左往右数，左端为最高位即指数 $L-1$，向右一位指数减一，故下标 $i$ 处指数为 $L-1-i$。证毕。

**引理 2**：算法输出的表达式与题目要求的展开式一致（仅省略了系数为 $0$ 的项）。

*证明*：由引理 1，算法为第 $i$ 个字符生成的项是 $d_i M^{L-1-i}$，正是 $M$ 进制展开式中该数位对应的项。

对任意 $i$，若 $d_i = 0$，该项为 $0$，题目规定"该单项式要省略"，算法用 `if(s[i]=='0') continue;` 跳过它，符合要求；若 $d_i \ne 0$，算法输出 `d_i*M^(L-1-i)`，与题目要求的项一致，且指数为 $0$ 时仍写出 `^0`（因为格式串中的指数部分是直接打印的数值，不因指数为 $0$ 而省略）。

因此输出包含且仅包含所有非零系数项，且每项的格式、指数均正确。证毕。

**引理 3**：算法输出的各项之间恰以一个 `+` 连接，首项前无 `+`，末项后无 `+`。

*证明*：算法维护布尔量 `first`，初始为 `true`。每次输出一个非零项之前，若 `first` 为 `true` 则置 `false` 而不打印 `+`；否则先打印一个 `+` 再打印该项。故第一项前无 `+`，其后每一项前恰有一个 `+`，且没有任何多余的 `+` 出现在末项之后。证毕。

**引理 4**：算法能正确处理长度为 $1000$ 的输入。

*证明*：算法把 $N$ 读入 `std::string`，逐字符访问下标 $i\in[0,L-1]$，只用到字符串长度和下标，不做任何数值转换。$1000$ 位字符串的长度可以用 `int` 精确保存（远小于 $2^{31}$），下标运算 `len-1-i` 也不会溢出。因此对任意 $L\le 1000$ 均能正确处理；若强行用整数类型读入，反而会在 $L\ge 20$ 时溢出。证毕。

**定理**：算法输出的字符串是题目要求的答案。

*证明*：由引理 2，输出的项集合与格式正确；由引理 3，连接符正确；由引理 4，长输入的处理正确。三者合起来即答案正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别题型：不是"进制转换"，是"按格式打印展开式"** — 题目要的是字符串，不是那个巨大的十进制数。
2. **大数意识：$1000$ 位 ⇒ 必须用 `string`** — 用 `long long` 存不下。
3. **对齐输出格式** — `系数*进制^指数`，`+` 连接，指数为 $0$ 也照写。
4. **零项省略** — 系数为 $0$ 的整项跳过，不参与 `+` 的连接。
5. **首位标记位** — 用 `first` 避免输出多余的 `+`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $M$ | 进制 | `int`，$2\le M\le 9$ |
| $N$ | $M$ 进制数本身 | `string`，长度 $L\le 1000$ |
| $L$ | $N$ 的位数 | `int`，$\le 1000$ |
| $s[i]$ | $N$ 的第 $i$ 位数字字符（0-based） | `char` |
| $d_i$ | $s[i]$ 对应的数值 | `int`，$0\le d_i\le 9$ |
| `first` | 是否还没输出过任何一项（控制 `+` 的有无） | `bool` |

### 算法步骤

1. 读入 $M$ 与 $N$（$N$ 用 `string` 读）。
2. 令 `len = s.size()`，`first = true`。
3. 对 $i = 0,1,\dots,L-1$：
   - 若 `s[i] == '0'`，跳过（零系数项省略）；
   - 否则：若 `first` 为 `false` 先输出 `'+'`；置 `first = false`；输出 `s[i]`、`'*'`、`M`、`'^'`、`len-1-i`。
4. 换行输出。

### 复杂度

- 时间复杂度：$O(L)$，其中 $L$ 为 $N$ 的位数。
- 空间复杂度：$O(L)$，存储输入字符串；额外工作空间 $O(1)$。

### 验证状态

- 标程 `P2084.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `2 10101` 输出 `1*2^4+1*2^2+1*2^0`，与官方一致。
- 由于本题的"暴力"就是题面本身的定义，另写 `P2084_check.py`：用 Python 独立实现一遍"按同样的展开规则拼字符串"的期望答案，与标程输出逐字符比对，在随机 $M\in[2,9]$、随机位数 $\le 30$ 的数据以及"含大段零系数位 / 1000 位纯 1 / 1000 位含零"等极端构造上交叉校验 **2004 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2084 进制转换
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int m;
string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>s;
	int len=(int)s.size();
	bool first=true;
	for(int i=0;i<len;++i)
	{
		if(s[i]=='0')
			continue;                       // 系数为 0 的单项式省略
		if(!first)
			cout<<'+';
		first=false;
		cout<<s[i]<<'*'<<m<<'^'<<len-1-i;
	}
	cout<<'\n';
	return 0;
}
```

### 代码说明

- `s` 用 `string` 存，避免 1000 位数字溢出；`mxn{1005}` 只是给长度留出余量的习惯常量。
- 指数直接由 `len-1-i` 得到，左高右低，符合题面展开式顺序。
- `^0` 会被自然打印出来（指数是普通整数，不做特判），与官方样例一致。
- `first` 标志位保证 `+` 只出现在两项之间。
- 输出使用 `'\n'` 而非 `endl`。
