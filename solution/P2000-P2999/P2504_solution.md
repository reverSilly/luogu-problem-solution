# P2504 [HAOI2006] 聪明的猴子 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 棵树（$2\le N\le 1000$），坐标为 $[-1000,1000]$ 内的整数且两两不同；$M$ 只猴子（$2\le M\le 500$），第 $i$ 只的最大跳跃距离为整数 $d_i\in[1,1000]$。猴子不会游泳，只能在树冠间跳跃，**每一跳的距离不能超过自己的跳跃力，但可以连续多跳**。问有多少只猴子能到达（从而在所有树冠上觅食）全部 $N$ 棵树。题面没有样例，下面的例子都是手算并用程序核对过的。

**第一步：把"能觅食所有树"翻译成图论语言。** 固定一只跳跃力为 $d$ 的猴子，建图 $G_d$：顶点是 $N$ 棵树，两棵树之间连边当且仅当它们的欧氏距离 $\le d$。猴子的一次合法跳跃就是走一条边，连续多跳就是走一条路径。于是：

> 猴子能觅食所有树 $\iff$ $G_d$ 连通。

这个等价与猴子**起始在哪棵树无关**：连通则从任何树出发都能到任何树；不连通则猴子被困在自己所在的连通块里，永远跳不出去（证明见引理 1）。所以"统计猴子"变成了"对每个 $d_i$ 判断 $G_{d_i}$ 是否连通"。

**第二步：先想暴力，确认瓶颈。** 对每只猴子现场建图 + BFS：建图要算 $O(N^2)$ 个距离，BFS 也是 $O(N^2)$（稠密图），总共 $O(MN^2)=500\times 10^6=5\times 10^8$，妥妥超时。而且直觉上很浪费：$M$ 只猴子面对的是**同一批树**，只是阈值不同，答案应该能共享某种预处理。

**第三步：发现单调性——答案只取决于一个临界值。** $d$ 增大时 $G_d$ 的边只增不减，所以"连通"关于 $d$ 单调：一旦连通，更大的 $d$ 也连通。于是存在临界值
$$d^\*=\min\{d:G_d\text{ 连通}\},$$
跳跃力 $\ge d^\*$ 的猴子全部合格，$<d^\*$ 的全部不合格。**整道题塌缩成：求 $d^\*$，再数一数。** 答案 $=\#\{i:d_i\ge d^\*\}$。

**第四步：$d^\*$ 是什么？——最小瓶颈生成树。** $G_d$ 连通 $\iff$ 存在一棵生成树，其所有边长 $\le d$。所以
$$d^\*=\min_{T\text{ 是生成树}}\ \max_{e\in T}w(e),$$
即**最小化最大边**的生成树（最小瓶颈生成树）的瓶颈值。注意这里优化的是 $\max$ 而不是 $\sum$——一个自然的疑问是：我们熟知的最小生成树（MST，最小化**边权和**）跟它是一回事吗？

**答案是肯定的：任何 MST 都是最小瓶颈生成树。** 用交换论证想清楚：设 $T$ 是 MST，$e$ 是 $T$ 中最长的边。若另一棵生成树 $T'$ 的最大边比 $w(e)$ 还小，把 $e$ 从 $T$ 里删掉，$T$ 断成两块 $S$ 与 $V\setminus S$；$T'$ 连通全图，必有一条跨这两块的边 $f$，且 $w(f)<w(e)$。用 $f$ 换掉 $e$ 得到一棵**总权更小**的生成树——与 $T$ 是 MST 矛盾。完整证明见引理 4。所以：

$$d^\*=\text{MST 的最大边长}.$$

**这里要停下来排除两个常见的错误直觉：**

- **错误一：要求跳跃力 $\ge$ 树的"直径"（最远两棵树的距离）。** 反例：三棵树 $(0,0),(3,0),(6,0)$，直径是 $6$，但跳跃力 $3$ 的猴子可以 $0\to3\to6$ 两跳到访所有树。多跳的存在使条件严格弱于直径——这正是"瓶颈"与"直径"的区别。
- **错误二：拿跳跃力和 MST 的边权总和比。** 总和与"每一跳够不够长"毫无关系；起作用的只有**最长的那条边**。上面的链例子里 MST 总权 $6$、瓶颈 $3$，跳跃力 $3$ 合格——比总和小的跳跃力照样可行。

**第五步：怎么求 MST？Prim $O(N^2)$，顺便记录最大边。** 图是完全图，边数 $\binom{N}{2}\approx 5\times 10^5$。Kruskal 要存下并排序全部边（$O(N^2\log N)$）；Prim 只需要 $N\times N$ 的距离现算，$O(N^2)=10^6$，还不用存边。选 Prim：维护 `dis[v]` = 树外点 $v$ 到已建树的最短边，每轮取最小的并入树，**并入时顺手 `bst=max(bst,dis[u])`**——循环结束时 `bst` 就是 MST 的最大边。

**第六步：浮点陷阱？根本不用浮点。** 距离是 $\sqrt{dx^2+dy^2}$，跳跃力是整数，比较 $\sqrt{dx^2+dy^2}\le d$ 两边都非负，**平方后等价**：$dx^2+dy^2\le d^2$。于是全程整数运算：边权用距离平方，阈值比较用 `jmp[i]*jmp[i]>=bst`。没有 `sqrt`、没有 `eps`、没有精度焦虑，连"跳跃力恰好等于瓶颈"的边界都是精确判定。范围也安全：$|dx|,|dy|\le 2000\Rightarrow d^2\le 8\times10^6$，`int` 绰绰有余。

**手造数据核对**（覆盖多跳、瓶颈≠直径、瓶颈≠总和、恰好相等、不可达、极端坐标）：

| 输入（猴子 / 树） | 手算 | 程序 |
|---|---|---|
| 跳跃力 `1 2`；树 $(0,0),(1,0)$ | 瓶颈 $1$，两只都够 → $2$ | $2$ ✓ |
| 跳跃力 `2 3 4`；树 $(0,0),(3,0),(6,0)$ | 链，瓶颈 $3$（直径 $6$！）→ $2$ | $2$ ✓ |
| 跳跃力 `98 99`；树 $(0,0),(1,0),(100,0)$ | MST 边 $1,99$，瓶颈 $99$ → $1$ | $1$ ✓ |
| 跳跃力 `9 10`；正方形 $(0,0),(10,0),(0,10),(10,10)$ | MST 取三条边长 $10$ 的边，瓶颈 $10$（对角线 $14.1$ 用不上）→ $1$ | $1$ ✓ |
| 跳跃力 `4 5`；树 $(0,0),(3,4)$ | 距离恰为 $5$，`25>=25` 边界 → $1$ | $1$ ✓ |
| 跳跃力 `1 1`；树 $(0,0),(100,0),(0,100)$ | 瓶颈 $100>1$ → $0$ | $0$ ✓ |
| 跳跃力 `1000`；树 $(-1000,-1000),(1000,1000)$ | $d^2=8\times10^6>10^6$ → $0$ | $0$ ✓ |

另外 $N=1000,M=500$ 的极限规模实测 $0.05$ s，远低于时限。

## 二、思维链：完整证明

**记号。** 树编号 $0..N-1$，坐标 $(x_i,y_i)$ 为整数且两两不同。$w(u,v)=\sqrt{(x_u-x_v)^2+(y_u-y_v)^2}$ 为欧氏距离，$w_2(u,v)=(x_u-x_v)^2+(y_u-y_v)^2$ 为其平方。完全图 $K_N$ 赋权 $w$。对 $d\ge 0$，$G_d=(V,E_d)$，$E_d=\{\{u,v\}:w(u,v)\le d\}$。猴子跳跃力 $d_1,\dots,d_M$。`bst` 为 Prim 过程中并入边的最大 $w_2$ 值。

---

### 引理 1（图模型：合格 $\iff$ $G_d$ 连通，与起始树无关）

跳跃力为 $d$ 的猴子能到訪所有树 $\iff$ $G_d$ 连通。

*证明*：猴子的移动规则是"从当前树跳到距离 $\le d$ 的另一棵树"，即沿 $E_d$ 中的边移动；有限次移动可达的顶点集恰为其起始顶点在 $G_d$ 中的**连通块**（路径可达性）。

（$\Leftarrow$）$G_d$ 连通 ⇒ 任何起始树的连通块都是 $V$ ⇒ 所有树可达。

（$\Rightarrow$）逆否：$G_d$ 不连通 ⇒ 起始树所在连通块 $C\subsetneq V$。猴子任何一跳的落点与起点有边相连，故仍在 $C$ 内；对跳数归纳，猴子永远在 $C$ 内，$V\setminus C$ 中的树不可达，不合格。

两个方向都与起始树的具体选择无关，故"合格"是 $G_d$ 的连通性的函数。证毕。

### 引理 2（单调性与临界值）

(a) $d_1\le d_2\Rightarrow E_{d_1}\subseteq E_{d_2}$，且 $G_{d_1}$ 连通 $\Rightarrow G_{d_2}$ 连通。
(b) $d^\*=\min\{d\ge 0:G_d\text{ 连通}\}$ 存在，且等于某对树的距离。
(c) 答案 $=\#\{i:d_i\ge d^\*\}$。

*证明*：(a) $w(u,v)\le d_1\le d_2$ 给出边集包含；连通图的生成超图（同顶点集、边更多）仍连通（原路径全部保留）。

(b) 取 $D=\max_{u,v}w(u,v)$，则 $G_D=K_N$ 连通，集合非空；它有下界 $0$。又连通性只在"某条边恰好出现"时改变：令 $d^\*=\min\{w(u,v):G_{w(u,v)}\text{ 连通}\}$（有限非空集合的最小值），对任意 $d<d^\*$，$E_d$ 中每条边 $\{u,v\}$ 满足 $w(u,v)\le d<d^\*$，故 $G_d$ 与 $G_{w(u,v)}$ 中某个更小的阈值图边集相同……更直接地：若 $G_d$ 连通，则 $d\ge$ 某对树距离且该距离处已连通（边集只依赖 $\le d$ 的边，把 $d$ 降到 $E_d$ 中的最大边权 $d'\le d$，$G_{d'}=G_d$ 仍连通），故 $d'\ge d^\*$，从而 $d\ge d^\*$。所以 $d^\*$ 就是最小值且可达。

(c) $d_i\ge d^\*$：由 (a) 单调性，$G_{d_i}$ 连通，由引理 1 合格。$d_i<d^\*$：由 $d^\*$ 的最小性 $G_{d_i}$ 不连通，不合格。计数即得。证毕。

### 引理 3（$d^\*$ = 最小瓶颈生成树值）

$$d^\*=\min_{T\text{ 为 }K_N\text{ 的生成树}}\max_{e\in T}w(e)\ \ (\triangleq B^\*).$$

*证明*：两个方向夹逼。

（$d^\*\le B^\*$）取达到 $B^\*$ 的生成树 $T'$。$T'$ 的每条边 $w\le B^\*$，故 $T'\subseteq G_{B^\*}$。$T'$ 连通全图 ⇒ $G_{B^\*}$ 连通 ⇒ $d^\*\le B^\*$。

（$B^\*\le d^\*$）$G_{d^\*}$ 连通 ⇒ 它含一棵生成树 $T''$（连通图必有生成树），$T''$ 的边都来自 $E_{d^\*}$，即 $w\le d^\*$ ⇒ $B^\*\le\max_{e\in T''}w(e)\le d^\*$。

夹逼得等式。证毕。

### 引理 4（交换论证：任何 MST 都是最小瓶颈生成树）

设 $T$ 是 $K_N$ 关于权 $w$ 的最小生成树，$B=\max_{e\in T}w(e)$。则对任意生成树 $T'$，$\max_{e\in T'}w(e)\ge B$。从而 $B^\*=B$，$d^\*=B$。

*证明*：反证。设某生成树 $T'$ 满足 $\max_{e\in T'}w(e)<B$。取 $e^\*\in T$ 使 $w(e^\*)=B$。

1. **删边断成两块**：树的每条边都是桥，$T-e^\*$ 恰有两个连通分支，顶点集记为 $S$ 与 $V\setminus S$，均非空。
2. **$T'$ 必有跨块边**：$T'$ 连通全图，取 $u\in S,v\in V\setminus S$，$T'$ 中 $u\to v$ 的路径必在某处从 $S$ 跨到 $V\setminus S$，该边 $f$ 满足 $w(f)\le\max_{e\in T'}w(e)<B=w(e^\*)$。
3. **交换得到更轻的生成树**：$T''=T-e^\*+f$ 有 $N-1$ 条边；$f$ 把两个分支重新连通，故 $T''$ 连通，是生成树。总权 $w(T'')=w(T)-w(e^\*)+w(f)<w(T)$，与 $T$ 的最小性矛盾。

故不存在最大边 $<B$ 的生成树，$B^\*\ge B$；又 $T$ 本身是生成树，$B^\*\le B$；得 $B^\*=B$。结合引理 3，$d^\*=B$。证毕。

**推论**：所有 MST 的最大边都等于同一个 $d^\*$（瓶颈值唯一），所以 Prim 随便求出哪棵 MST 都行。

### 引理 5（Prim 的正确性与 `bst` 的含义）

Prim 算法（从顶点 $0$ 出发，`dis[v]` 初始为 $\infty$、`dis[0]=0`，每轮取未访问的 `dis` 最小者 $u$ 并入，再用 $w_2(u,\cdot)$ 松弛）结束时：并入的 $N-1$ 条边构成一棵 MST（按 $w_2$ 权），且 `bst` $=\max$ 边权（$w_2$ 域）。

*证明*：先证**割性质**：对任意割 $(S,V\setminus S)$，权最小的跨割边 $e$ 属于某棵 MST。设 $T$ 是任一 MST，若 $e\in T$ 完毕；否则 $T+e$ 含唯一环，该环从 $S$ 跨出又跨回，故环上另有跨割边 $f\in T$，$w(f)\ge w(e)$（$e$ 是最小跨割边）。$T'=T+e-f$ 连通（环上删边不断连通）且 $N-1$ 条边，是生成树，$w(T')\le w(T)$ ⇒ $T'$ 也是 MST 且含 $e$。

再对轮数归纳**不变量**：已访问集 $S$ 上的已选边构成树，且存在一棵 MST 包含全部已选边；对 $v\notin S$，`dis[v]`$=\min_{u\in S}w_2(u,v)$。

- 初始 $S=\{0\}$，无边，任何 MST 都"包含空边集"；`dis` 由第一轮松弛后成立（`dis[0]=0` 是哨兵，见下）。
- 每轮选的 $u$ 使 `dis[u]` 最小，即选中了割 $(S,V\setminus S)$ 的最小跨割边（由不变量 `dis` 的含义）。由割性质，存在 MST 包含已选边 $+$ 这条新边；归纳保持。松弛步骤 `dis[v]=min(dis[v],w2(u,v))` 恰好把新入树的 $u$ 计入 $\min$，不变量保持。
- $N-1$ 轮后已选边是 $S=V$ 上的树（每轮连一个新点），且被某棵 MST 包含；两者都是 $N-1$ 条边，故**已选边就是那棵 MST**。

`bst` 记录每轮并入时的 `dis[u]`。第一轮 `dis[0]=0` 不是真实边，但坐标两两不同且为整数 ⇒ 真实边权 $w_2\ge 1>0$，`max` 里混入一个 $0$ 不影响结果。其余每轮 `dis[u]` 正是并入边的 $w_2$ 权。故 `bst` $=$ MST 最大边的平方。证毕。

### 引理 6（平方比较的精确性与值域）

(a) 对非负实数 $a,b$：$a\le b\iff a^2\le b^2$。
(b) 全程 `int` 安全：$w_2\le 8\times10^6$，$d_i^2\le 10^6$，哨兵 `inf`$=1145141919>8\times10^6$。
(c) 判定 `jmp[i]*jmp[i]>=bst` 与 $d_i\ge d^\*$ 完全等价，等号边界精确。

*证明*：(a) $b^2-a^2=(b-a)(b+a)$。若 $a+b>0$，则 $b^2-a^2$ 与 $b-a$ 同号，等价成立；若 $a+b=0$ 则 $a=b=0$，两边都取等。

(b) $|x_u-x_v|\le 2000,|y_u-y_v|\le 2000\Rightarrow w_2\le 2000^2+2000^2=8\times10^6$；中间量 `dx*dx`$\le 4\times10^6$，加法 $\le 8\times10^6$；$d_i\le 1000\Rightarrow d_i^2\le 10^6$。全部远小于 `int` 上限 $2.1\times10^9$。哨兵大于一切真实边权，故"不可达"不会被误当成短边（完全图中其实不会发生，但语义必须对）。

(c) 由引理 5，`bst`$=(d^\*)^2$（$d^\*$ 是某对树的距离，其平方为整数）。由 (a)，$d_i\ge d^\*\iff d_i^2\ge(d^\*)^2=$`bst`。整数比较无舍入，$d_i=d^\*$ 时取等成立——"恰好跳到"算合格，与题面"最大跳跃距离"含等号一致。证毕。

### 引理 7（复杂度）

时间 $O(N^2+M)$，空间 $O(N+M)$。

*证明*：Prim 共 $N$ 轮，每轮一次 $O(N)$ 选最小 + 一次 $O(N)$ 松弛，每次松弛 $O(1)$ 算 $w_2$，合计 $O(N^2)=10^6$；读入 $O(N+M)$；计数 $O(M)$。数组 `x,y,dis,vis` 各 $O(N)$，`jmp` $O(M)$。代入 $N=1000,M=500$：约 $10^6$ 次基本运算，实测极限数据 $0.05$ s。证毕。

### 定理

程序输出 $\#\{i:d_i\ge d^\*\}$，即能觅食所有树的猴子数；时间 $O(N^2+M)$，空间 $O(N+M)$。

*证明*：引理 1 把题意化为连通性；引理 2 把 $M$ 次判定化为单一阈值 $d^\*$；引理 3 把 $d^\*$ 化为最小瓶颈生成树值；引理 4 证明 MST 即达最小瓶颈；引理 5 保证 Prim 求出 MST 且 `bst` 是其最大边平方；引理 6 保证平方域整数判定与原问题逐只等价（含等号）；引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "能觅食所有树" $=$ 阈值图 $G_d$（边 $\iff$ 距离 $\le$ 跳跃力）连通；多跳合法，与起始树无关。
- **consider easier version** — 单只猴子建图 + BFS 是 $O(N^2)$；$M$ 只重复做是 $O(MN^2)=5\times10^8$，超时且浪费 ⇒ 寻找共享阈值。
- **explore its property** — 边集随 $d$ 单调增 ⇒ 连通性单调 ⇒ 唯一临界 $d^\*$，答案 $=\#\{d_i\ge d^\*\}$。
- **reduce to easier problem** — $d^\*=$ 最小瓶颈生成树值（$\min\max$ 边，不是 $\min\sum$ 边，也不是直径）。
- **classic problem solution** — 交换论证：MST 必是最小瓶颈生成树 ⇒ Prim $O(N^2)$ 建 MST，顺手记录最大边。
- **explore its property** — 非负数比较可平方：$d\le d_i\iff d^2\le d_i^2$，全程整数，等号边界天然精确，无需 `sqrt`/`eps`。
- **discuss by category** — 边界核对：跳跃力恰等于瓶颈算合格；瓶颈 $>1000$ 时答案 $0$；`dis[0]=0` 不污染 `bst`（真实边权 $\ge1$）。

| `dis[v]` | Prim 中树外点 $v$ 到已建树的最短边（**平方距离**） | `int[mxn]`，`fill_n(dis,n,inf)`，`dis[0]=0` | 全局默认 0 的陷阱：必须显式填 INF |
| `vis[v]` | $v$ 是否已并入树 | `bool[mxn]`，默认 `false` | |
| `bst` | 已并入边的最大平方边权 = MST 瓶颈的平方 | `int`，初值 $0$ | 答案阈值；真实边权 $\ge1$，首轮 $0$ 无害 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | $>8\times10^6$，不会与真实距离混淆 |
| `d2(u,v)` | $(x_u-x_v)^2+(y_u-y_v)^2$ | `int(int,int)` | 全程平方域，无浮点 |
| `ans` | 合格猴子数 | `int`，初值 $0$ | `jmp[i]*jmp[i]>=bst` 计数 |

### 算法步骤

1. I/O 加速三行。
2. 读 `m` 与 `jmp[0..m-1]`；读 `n` 与 `n` 个坐标。
3. `fill_n(dis,n,inf); dis[0]=0;`，`bst=0`。
4. Prim 循环 $N$ 轮：线性扫描选未访问且 `dis` 最小的 $u$；`vis[u]=true`；`bst=max(bst,dis[u])`；对所有未访问 $v$ 松弛 `dis[v]=min(dis[v],d2(u,v))`。
5. 对每只猴子判 `jmp[i]*jmp[i]>=bst`，计数输出。

### 复杂度

- 时间：$O(N^2+M)$，$N=1000$ 时约 $10^6$ 次运算，实测极限数据 $0.05$ s。
- 空间：$O(N+M)$，几个长度 $1005$ 的 `int` 数组，约 $20$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面无样例，手造 $7$ 组数据（链状多跳、瓶颈≠直径、瓶颈≠总和、正方形带对角线、距离恰好相等、全不可达、极端坐标 $d^2=8\times10^6$）全部与手算一致；$N=1000,M=500$ 极限规模运行 $0.05$ s。本题为经典 MST 瓶颈性质应用，证明已闭合（引理 4 交换论证），未写对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2504 [HAOI2006] 聪明的猴子
// 思路：猴子能遍历所有树 ⟺ 只保留长度≤跳跃力的边时图连通
//       ⟺ 最小生成树的最大边（瓶颈）≤跳跃力（MST 即最小瓶颈生成树）
//       全程用距离平方比较，避开浮点：d≤jump ⟺ d²≤jump²
//       Prim O(N²) 求 MST 瓶颈，再数 jump²≥瓶颈² 的猴子
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},mxm{505},inf{1145141919};

int m,n,jmp[mxm],x[mxn],y[mxn],dis[mxn];
bool vis[mxn];

int d2(int u,int v)
{
	int dx=x[u]-x[v],dy=y[u]-y[v];
	return dx*dx+dy*dy;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m;
	for(int i=0;i<m;++i)
		cin>>jmp[i];
	cin>>n;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];

	fill_n(dis,n,inf);
	dis[0]=0;
	int bst=0;	// MST 最大边的平方（瓶颈），平方域下比较
	for(int t=0;t<n;++t)
	{
		int u=-1;
		for(int v=0;v<n;++v)
			if(!vis[v]&&(u==-1||dis[v]<dis[u]))
				u=v;
		vis[u]=true;
		bst=max(bst,dis[u]);
		for(int v=0;v<n;++v)
			if(!vis[v])
				dis[v]=min(dis[v],d2(u,v));
	}
	int ans=0;
	for(int i=0;i<m;++i)
		if(jmp[i]*jmp[i]>=bst)
			++ans;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **输入顺序**：先 `m` 与跳跃力表，再 `n` 与坐标——题面顺序如此，别读反。
- **平方域一以贯之**：`d2` 返回平方距离，`dis`、`bst`、判定 `jmp[i]*jmp[i]>=bst` 全在平方域，只在最后与猴子比较时把跳跃力也平方。任何一处偷偷 `sqrt` 都会引入不必要的浮点误差。
- **`fill_n(dis,n,inf)` 必须显式写**：全局 `int` 默认 $0$，不填的话所有点都"距离树 $0$"，Prim 第一轮之后全乱。`dis[0]=0` 是起点哨兵，真实边权 $\ge1$（整点且两两不同），所以它混进 `bst=max(bst,dis[u])` 无害。
- **`bst` 在并入时更新**，不是在松弛时——松弛改的是"候选边"，并入的才是 MST 的边。
- 完全图不需要邻接表，距离现算 $O(1)$，这是 Prim $O(N^2)$ 比 Kruskal 省事的原因：不存 $5\times10^5$ 条边、不排序。
- `inf=1145141919` 远大于最大可能边权 $8\times10^6$，不会发生"哨兵被当成真实距离"或加法溢出。
