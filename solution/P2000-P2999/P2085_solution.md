# P2085 最小函数值 — 题解

## 一、解题过程：人类思考叙事

题目：$n$ 个二次函数 $F_i(x)=A_i x^2+B_i x+C_i$（$x\in\mathbb N^*$），要输出所有函数值中最小的 $m$ 个。

第一反应：暴力。对每个函数算 $x=1,2,3,\dots$ 的值，全部收集起来排序取前 $m$ 个。但 $x$ 要算到多大？如果算到 $x=m$，量级是 $n\cdot m = 10^8$ 个数，加上排序，$O(nm\log(nm))$ 直接爆炸。

先看清数据范围：$1\le A_i\le 10$，$0\le B_i\le 100$，$0\le C_i\le 10^4$，$n,m\le 10^4$。三个系数全都非负，而且 $A_i\ge 1$。这说明 $F_i$ 是一个**开口向上、一阶导恒正**的抛物线，在 $x\ge 0$ 上**严格单调递增**。

这就是本题的题眼：每个函数在正整数上产生一个**严格递增序列**
$$F_i(1) < F_i(2) < F_i(3) < \cdots$$

于是问题变成：**$n$ 个有序序列合并，求最小的 $m$ 个数**。这是经典的多路归并。

具体怎么做？维护一个小根堆，堆里放"每个序列当前还没取出的最小元素"。初始把每个序列的第一个元素 $F_i(1)=A_i+B_i+C_i$ 放进去。每次弹出堆顶（这就是全局尚未取出的最小值），输出它，然后把**它所属的那个序列**的下一个元素推进堆。重复 $m$ 次即可。

堆里为什么要存"序列编号"？因为要知道弹出的是哪个函数的下一个值，要从哪个函数继续推。用 `pair<值, 编号>`，配合 `greater<>` 就是小根堆。

复杂度：堆里最多 $n$ 个元素，每次 `push`/`pop` 是 $O(\log n)$，共 $m$ 次，总共 $O((n+m)\log n)$，非常舒服。

不过等一下，这里有个容易被忽略的细节：每个函数被推入堆的元素值要能算得出来。我们存下每个函数当前推进到哪个 $x$（记为 `xs[i]`），那么堆里的值就是 $A_i xs[i]^2 + B_i xs[i] + C_i$。

另一个细节：**$x$ 从 1 开始**，不是 0。题目写的是 $x\in\mathbb N^*$，$\mathbb N^*$ 是正整数集 $\{1,2,3,\dots\}$。所以初始值是 $F_i(1)=A_i+B_i+C_i$，不是 $C_i$。这是本题的一个经典坑。

再一个细节：答案可能超出 `int`。$A\le 10$，$x$ 最大到多少？堆里第 $i$ 个函数的 $x$ 最多推进到 $m+1$（每次弹出只推进一个函数），所以 $x\le m+1\le 10001$，$A x^2 \le 10\cdot 10^8 = 10^9$。加上 $B x \le 100\cdot 10^4 = 10^6$，总和约 $10^9$，确实在 `int` 边缘（$2^{31}-1\approx 2.1\times 10^9$），但用 `long long` 更稳。实际上很多 AC 代码用 `int` 也能过，我们用 `i64` 图省心。

再看重复值的处理：题目说"如有重复的要输出多个"。小根堆天然保留重复（两个序列里相同的值各占一个堆元素），自然满足。

最后验证一下多路归并的思路对不对：每次弹堆顶 = 所有 $n$ 个序列"未取部分的首元素"中的最小者 = 所有未取元素中的最小者。所以弹出 $m$ 次得到的就是全局最小的 $m$ 个（按非降序）。✓

## 二、思维链：完整证明

**引理 1**：对任意 $i$，序列 $F_i(1),F_i(2),\dots$ 严格递增。

*证明*：设 $1\le x<y$，则
$$F_i(y)-F_i(x)=A_i(y^2-x^2)+B_i(y-x)=(y-x)\big(A_i(x+y)+B_i\big).$$
由数据范围 $A_i\ge 1$、$x+y\ge 3>0$、$B_i\ge 0$，得 $A_i(x+y)+B_i>0$；又 $y-x>0$，故 $F_i(y)-F_i(x)>0$，即 $F_i$ 在正整数上严格递增。证毕。

**引理 2**：设某个时刻堆中第 $i$ 个元素为 $F_i(x_i)$，其中 $x_i$ 是函数 $i$ 当前推进到的位置，则堆中该元素是函数 $i$ 尚未被取出的所有值中最小的那个。

*证明*：由引理 1，$F_i$ 严格递增，故未取出的值为 $F_i(x_i),F_i(x_i+1),\dots$，其中最小者为 $F_i(x_i)$。而堆中存的恰是 $F_i(x_i)$（初始化时 $x_i=1$，堆中为 $F_i(1)$，是函数 $i$ 的最小值）。证毕。

**引理 3**：每次弹出的堆顶是当前所有尚未被取出的函数值中的最小者。

*证明*：设堆顶为 $F_j(x_j)$。对任意函数 $i$，由引理 2，其未取出的最小值为 $F_i(x_i)$，而 $F_i(x_i)$ 就在堆中。由于堆是维护在全体 $\{F_i(x_i)\}_{i=1}^n$ 上的小根堆，堆顶是这个集合的最小元，故 $F_j(x_j)\le F_i(x_i)$ 对一切 $i$ 成立。而 $F_i(x_i)$ 已是函数 $i$ 未取值的最小者，故一切未取出的值都 $\ge F_i(x_i)\ge F_j(x_j)$。所以堆顶是全体未取值中的最小者。证毕。

**引理 4**：算法输出的第 $k$ 个数是所有函数值中第 $k$ 小的值（重复值按重数分别计入）。

*证明*：由引理 3，第 $k$ 次弹出得到的是"去掉前 $k-1$ 次弹出的元素后，剩余元素中的最小者"。归纳地，前 $k-1$ 次弹出恰好取走了全体元素中最小的 $k-1$ 个（按重数计），故第 $k$ 次弹出的是第 $k$ 小的元素。证毕。

**引理 5**：算法正确推进每个函数的取值位置，不会重复取同一个函数值，也不会漏取。

*证明*：初始化时每个函数 $i$ 的 `xs[i]=1`，堆中压入 $F_i(1)$，即函数 $i$ 的第一个值。弹出堆元素后，算法执行 `++xs[id]` 并压入 $F_i(xs[i]+1)$（即新位置的值），因此每个函数被压入堆的值依次是 $F_i(1),F_i(2),\dots$，每个值恰好被压一次、被弹一次。弹出 $m$ 次即取走 $m$ 个互不重复的"取值事件"（同一函数不同 $x$ 的值互不相同；不同函数的同一数值作为两个独立事件分别被取，符合"重复要输出多个"的要求）。证毕。

**定理**：算法输出的正是所有函数的所有函数值中最小的 $m$ 个。

*证明*：由引理 5，弹出的 $m$ 个值都是真实的函数值；由引理 4，它们按非降序恰好是全体函数值中最小的 $m$ 个。证毕。

## 三、模式总结（按实际思考顺序）

1. **读范围找单调性** — $A_i\ge 1$、$B_i\ge 0$ ⇒ 每个 $F_i$ 在正整数上严格递增。
2. **把"求最小 $m$ 个"翻译成"合并有序序列"** — $n$ 个严格递增序列，求整体前 $m$ 小。
3. **经典多路归并 = 小根堆** — 堆里存"每个序列当前最小未取值"，弹一个补一个。
4. **堆元素要带序列编号** — `pair<值, 编号>`，弹出后才知道该推进哪条序列。
5. **注意 $x$ 从 1 开始** — $x\in\mathbb N^*$，初始值是 $A_i+B_i+C_i$ 而非 $C_i$。
6. **重复值天然保留** — 堆不合并相等元素，"重复要输出多个"自动满足。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 函数个数 | `int`，$\le 10^4$ |
| $m$ | 要输出的最小值个数 | `int`，$\le 10^4$ |
| $A_i,B_i,C_i$ | 第 $i$ 个函数的系数 | `i64`，$A_i\in[1,10]$、$B_i\in[0,100]$、$C_i\in[0,10^4]$ |
| $F_i(x)$ | 第 $i$ 个函数在 $x$ 处的值 | `i64` |
| `xs[i]` | 函数 $i$ 当前推进到的自变量（已取走 $F_i(1..xs[i]-1)$） | `int`，初值 $1$ |
| `Q` | 小根堆，元素为 `(函数值, 函数编号)` | `priority_queue` |
| `val, id` | 弹出的堆顶：值与所属函数编号 | `i64, int` |

### 算法步骤

1. 读入 $n,m$ 与所有函数的三个系数。
2. 对每个 $i$：置 `xs[i]=1`，把 $(A_i+B_i+C_i,\ i)$ 压入小根堆 `Q`（即 $F_i(1)$）。
3. 重复 $m$ 次：
   - 弹出堆顶 `(val,id)`，输出 `val`；
   - 执行 `++xs[id]`；
   - 计算 $F_{id}(xs[id])=A_{id}\,xs[id]^2+B_{id}\,xs[id]+C_{id}$，压入堆。
4. 输出完毕后结束。

### 复杂度

- 时间复杂度：$O((n+m)\log n)$。建堆 $n$ 次插入共 $O(n\log n)$，取 $m$ 次共 $O(m\log n)$。
- 空间复杂度：$O(n)$，堆中最多 $n$ 个元素。

### 验证状态

- 标程 `P2085.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `3 10 / 4 5 3 / 3 4 5 / 1 7 1` 输出 `9 12 12 19 25 29 31 44 45 54`，与官方一致。
- 编写暴力 `P2085_brute.cpp`（每个函数直接取 $x=1..m$，全部收集后排序取前 $m$；由引理 1，$m$ 个最小值必然落在 $x\le m$ 范围内）与对拍脚本 `P2085_check.py`，在 $n\le 5$、$m\le 8$ 的随机数据上对拍 **2000 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2085 最小函数值
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};

int n,m;
i64 A[mxn],B[mxn],C[mxn];
int xs[mxn];

// 每个函数的值随 x 严格递增，用小根堆做 n 路归并
priority_queue<pair<i64,int>,vector<pair<i64,int>>,greater<pair<i64,int>>> Q;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
	{
		cin>>A[i]>>B[i]>>C[i];
		xs[i]=1;
		Q.push({A[i]+B[i]+C[i],i});
	}
	for(int i=0;i<m;++i)
	{
		auto[val,id]=Q.top();
		Q.pop();
		cout<<val<<(i==m-1?'\n':' ');
		++xs[id];
		Q.push({A[id]*xs[id]*xs[id]+B[id]*xs[id]+C[id],id});
	}
	return 0;
}
```

### 代码说明

- 堆元素是 `pair<i64,int>`，配合 `greater<>` 构成小根堆；第二项是函数编号，用来决定弹出后推进哪条序列。
- 初始压入的是 $F_i(1)=A_i+B_i+C_i$（$x$ 从 $1$ 开始，不是 $0$）。
- 弹出后先 `++xs[id]` 再算新值并压回，保持"堆中第 $i$ 项恒为 $F_i(xs[i])$"这一不变量。
- 用 `i64` 存函数值：`$A x^2$` 在 $x$ 接近 $10^4$ 时量级为 $10^9$，用 `long long` 稳妥。
- 输出时用 `(i==m-1?'\n':' ')` 保证行内空格分隔、末尾恰好一个换行。
