# P2970 [USACO09DEC] Selfish Grazing S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 数轴上有 $N$ 头牛（$N\le5\times10^4$），第 $i$ 头想吃区间 $(S_i,E_i)$（$1\le S_i<E_i\le10^8$）。两头牛 $i,j$ 能同时吃草当且仅当 $S_i\ge E_j$ 或 $E_i\le S_j$——即区间**不共享任何内部点，但端点相接是合法的**（$E_i=S_j$ 允许）。求最多能选出多少头两两兼容的牛。输出一个整数。

这就是把「活动选择问题」（区间调度）换了个牛皮：每头牛 = 一个活动，兼容 = 区间不重叠（可相接），求最大两两不交子集的大小。

**第一步：暴力与 DP 的量级。** 枚举子集 $2^N$ 不可能。经典 DP：按右端点排序后 $f_i=\max(f_{i-1},1+f_{p(i)})$，$p(i)$ 是最后一个与 $i$ 兼容的位置；线性找 $p(i)$ 是 $O(N^2)=2.5\times10^9$，超时（二分找可到 $O(N\log N)$，但既然标签写着「贪心」，先试贪心）。

**第二步：贪心按什么排序？逐个试错。** 最大不交子集问题的贪心候选排序有三种，我逐一检验：

- **按左端点升序，能选就选？** 反例：$(1,100),(2,3),(4,5)$。先选 $(1,100)$，后两个全被堵死，得 $1$；最优是 $(2,3),(4,5)$ 得 $2$。**失败根源**：左端点小不代表「占用的未来空间」小，一个早开始的长区间会封死整条时间轴。
- **按长度升序，能选就选？** 反例：$(1,4),(3,5),(4,7)$。最短的是 $(3,5)$（长 $2$），选它后 $(1,4)$ 与 $(4,7)$ 都与它重叠（$3<4$、$4<5$），得 $1$；最优是 $(1,4),(4,7)$ 得 $2$。**失败根源**：短区间可能横跨在两个本可共存的区间中间，「性价比」高但「位置」坏。
- **按右端点升序，能选就选？** 直觉：右端点最小 = 最早结束 = 给后面留下的空间最大。上面两个反例它都答对：第一组选 $(2,3),(4,5)$ 得 $2$；第二组选 $(1,4),(4,7)$ 得 $2$。直觉上每次选择都把「对未来的伤害」压到最小——但这只是直觉，**必须证明**（第二部分引理 2 的交换论证）。

**第三步：把直觉写成算法。** 按 $E$ 升序排序；维护 `cur` = 已选最后一头牛的右端点；顺序扫描，若 $S_i\ge\texttt{cur}$ 就选它并令 `cur`$=E_i$。注意是 $\ge$ 不是 $>$：端点相接合法。`cur` 初值取哨兵 $-114514$（$S_i\ge1$，保证第一头必可选）。

**第四步：细节核对。**

1. **相接合法**：$(1,2),(2,3),(3,4)$ 三头全选，答案 $3$。写成 `s>cur` 会错成 $1$。
2. **右端点相同的区间**：排序比较器只比 `e`，并列时顺序任意——不影响正确性（引理 2 的证明对并列成立：交换时只用到 $E_g\le E_o$）。
3. **值域**：坐标 $\le10^8<2^{31}$，`int` 足够；答案 $\le N\le5\times10^4$，`int` 足够。
4. **哨兵**：`cur` 不能初始化为 $0$ 以外的「看起来小」的值吗？其实 $0$ 也行（$S_i\ge1>0$），但用 $-114514$ 家族哨兵是风格约定，且语义上明确表示「还没选任何牛」。

**手造数据核对。** 题面样例：$(2,4),(1,12),(4,5),(7,10),(7,8)$。按 $E$ 排序：$(2,4),(4,5),(7,8),(7,10),(1,12)$。扫描：选 $(2,4)$，`cur`$=4$；$(4,5)$ 的 $S=4\ge4$ 选，`cur`$=5$；$(7,8)$ 选，`cur`$=8$；$(7,10)$ 的 $7<8$ 跳过；$(1,12)$ 跳过。答案 $3$，与题面「第一、三、四（或五）头」一致 ✓。

第二组（相接链）：$(1,2),(2,3),(3,4)$ → $3$ ✓（专打 $\ge$ vs $>$）。
第三组（左端点贪心反例）：$(1,100),(2,3),(4,5)$ → 排序后 $(2,3),(4,5),(1,100)$，选前两个，答案 $2$ ✓。
第四组（长度贪心反例）：$(1,4),(3,5),(4,7)$ → 排序后 $(1,4),(3,5),(4,7)$，选 $(1,4)$ 后 $(3,5)$ 的 $3<4$ 跳过，$(4,7)$ 的 $4\ge4$ 选，答案 $2$ ✓。

## 二、思维链：完整证明

**记号。** 牛 $i$ 对应半开区间 $[S_i,E_i)$，$S_i<E_i$。称集合 $A$ **可行**，若其中任意两头牛兼容。目标是 $\max|A|$。把牛按 $E$ 升序排序后下标为 $0..N-1$（并列任意）。

---

### 引理 1（兼容 $\iff$ 半开区间不交）

牛 $i,j$ 兼容（$S_i\ge E_j$ 或 $E_i\le S_j$）$\iff[S_i,E_i)\cap[S_j,E_j)=\varnothing$。

*证明*：($\Leftarrow$ 的逆否，即证「不兼容 $\Rightarrow$ 相交」) 若不兼容，则 $S_i<E_j$ 且 $S_j<E_i$。取 $x=\max(S_i,S_j)$。由 $S_i<E_j$ 与 $S_j<E_j$ 得 $x<E_j$；同理由 $S_j<E_i$ 与 $S_i<E_i$ 得 $x<E_i$。又 $x\ge S_i$、$x\ge S_j$。故 $x\in[S_i,E_i)\cap[S_j,E_j)$，相交。

($\Rightarrow$ 的逆否，即证「相交 $\Rightarrow$ 不兼容」) 若存在 $x$ 同属两区间，则 $S_i\le x<E_i$ 且 $S_j\le x<E_j$。于是 $S_i<E_j$ 且 $S_j<E_i$，两个兼容条件都不成立。

两方向互为逆否，等价成立。证毕。

**推论**：可行集 = 两两不交的半开区间族。特别地，$E_i=S_j$（端点相接）时两区间不交，兼容——与题面 $\le,\ge$ 一致。以下全部用「不交」语言。

---

### 引理 2（贪心选择性质：最早结束者必可入选某个最优解）

设 $g$ 是全体区间中右端点最小者（并列时任取一个）。则存在一个**最大**可行集包含 $g$。

*证明*（交换论证）：设 $O$ 是任一最大可行集。若 $g\in O$，结论已成立。下设 $g\notin O$。取 $o\in O$ 为 $O$ 中右端点最小者。

**断言**：对所有 $o'\in O\setminus\{o\}$，有 $S_{o'}\ge E_o$。
证：$o'$ 与 $o$ 兼容，故 $S_{o'}\ge E_o$ 或 $E_{o'}\le S_o$。若后者成立，则 $E_{o'}\le S_o<E_o$（$S_o<E_o$ 是题设），即 $o'$ 的右端点比 $o$ 还小，与 $o$ 的最小性矛盾。故前者成立。断言证毕。

由 $g$ 的全局最小性，$E_g\le E_o$。于是对所有 $o'\in O\setminus\{o\}$：$S_{o'}\ge E_o\ge E_g$，即 $g$ 与每个 $o'$ 兼容（引理 1）。令 $O'=(O\setminus\{o\})\cup\{g\}$。$g\notin O$ 保证 $|O'|=|O|$；$O\setminus\{o\}$ 内部两两兼容（子集继承），$g$ 与其余每个兼容，故 $O'$ 可行。$O'$ 可行且与最大解等势，故也是最大可行集，且包含 $g$。证毕。

**这条引理正是「按右端点排序」的理论依据**：它说「先选最早结束的」不会把最优解选丢。对比两个失败贪心：按左端点排序时，最早**开始**者没有类似性质（反例 $(1,100)$ 不在任何最优解里）；按长度排序同理（$(3,5)$ 不在任何最优解里）。失败的根源在证明里看得很清楚：交换论证需要「其余区间的左端点 $\ge$ 被换者的右端点」，这只有「被换者是右端点最小者」时才推得出来。

---

### 引理 3（最优子结构）

设 $g$ 如引理 2，令残量实例 $I_g=\{i:S_i\ge E_g\}$（所有与 $g$ 兼容、排在 $g$ 之后的区间）。则

$$\mathrm{OPT}(I)=1+\mathrm{OPT}(I_g),$$

其中 $\mathrm{OPT}$ 表示最大可行集大小。

*证明*：($\ge$) 取 $I_g$ 的最大可行集 $A$，则 $A\cup\{g\}$ 可行（$A$ 中每个 $S\ge E_g$，与 $g$ 不交；$A$ 内部两两不交），故 $\mathrm{OPT}(I)\ge1+|A|=1+\mathrm{OPT}(I_g)$。

($\le$) 由引理 2，存在包含 $g$ 的最大可行集 $O^\*$。$O^\*\setminus\{g\}$ 中每个区间与 $g$ 兼容，由引理 1 即 $S\ge E_g$（$E\le S_g$ 不可能：那将 $E<E_g$，与 $E_g$ 全局最小矛盾），故 $O^\*\setminus\{g\}\subseteq I_g$ 且可行，于是 $\mathrm{OPT}(I_g)\ge|O^\*|-1=\mathrm{OPT}(I)-1$。

两方向夹逼得等式。证毕。

**意义**：选完 $g$ 之后，剩下的问题**与原问题同形**（还是「最大不交子集」），只是实例缩小为 $I_g$。于是可以递归地反复应用引理 2——贪心不是一锤子买卖，而是每一步都踩在最优子结构上。

---

### 引理 4（扫描算法恰好实现上述递归）

算法：按 $E$ 升序排序；`cur` 初始为 $-\infty$（哨兵 $-114514<S_i$ 恒成立）；顺序扫描，遇 $S_i\ge\texttt{cur}$ 则选之并令 `cur`$=E_i$。则算法输出 $=\mathrm{OPT}(I)$。

*证明*：对「已做出的选择次数」归纳，维持不变量：

> 设已选 $k$ 头，`cur` 为第 $k$ 头的右端点。则 (a) 已选集合是「前 $k$ 次贪心选择」的结果，即对当前残量实例反复应用引理 2 所选；(b) 尚未扫描的区间中，属于残量实例 $\{i:S_i\ge\texttt{cur}\}$ 者，其右端点最小者恰是**下一个被扫描到的满足 $S_i\ge\texttt{cur}$ 的区间**；(c) 已扫描但未选的区间永远不再属于残量实例。

$k=0$：`cur`$=-\infty$，残量实例 = 全体，排序后第一个区间右端点最小，(a)(b)(c) 平凡成立。

归纳步：设不变量对 $k$ 成立。扫描继续推进：
- 遇到 $S_i<\texttt{cur}$ 的区间：跳过。它不属于残量实例；且 `cur` 只增不减（每次更新 `cur`$=E_i>S_i\ge\texttt{cur}$，严格增大），故它**永远**不属于后续残量实例——(c) 保持。
- 遇到第一个 $S_i\ge\texttt{cur}$ 的区间：由 (b)，它是残量实例中右端点最小者，即引理 2 的 $g$。选它，`cur`$=E_i$。由引理 3，最优值分解为 $1+\mathrm{OPT}(I_g)$，而新残量实例恰为 $I_g=\{j:S_j\ge E_i\}$。已扫描未选者由 (c) 不在 $I_g$ 中；未扫描者中满足 $S_j\ge E_i$ 的，右端点最小者仍是「下一个满足条件的被扫描区间」（排序保证右端点升序）——(a)(b)(c) 对 $k+1$ 成立。

扫描结束时，残量实例为空（所有区间要么被选、要么由 (c) 永久出局），$\mathrm{OPT}(\varnothing)=0$。由引理 3 逐层展开，$\mathrm{OPT}(I)=k+\mathrm{OPT}(\varnothing)=k$，即算法选中的数量就是最优值。证毕。

---

### 引理 5（实现细节的正确性）

(a) 哨兵：`cur`$=-114514$ 时，任何区间 $S_i\ge1>\texttt{cur}$，第一头必被选——与引理 2 一致（全局最早结束者必可入选某最优解）。
(b) 判据 `a[i].s>=cur` 中的 $\ge$ 实现「端点相接合法」；若误写 $>$，相接链 $(1,2),(2,3),(3,4)$ 会只得 $1$ 而非 $3$。
(c) 排序比较器只比 `e`，并列顺序任意：引理 2 只用到 $E_g\le E_o$，引理 4(b) 只用到「右端点升序」，并列不影响任何一步。
(d) `cur` 严格递增：每次更新 `cur`$=E_i>S_i\ge\texttt{cur}_{old}$。这保证 (c) 中「永久出局」的论证成立。

*证明*：(a) 题设 $S_i\ge1$，$-114514<1$，直接代入。(b) 引理 1 已证兼容含相接；扫描判据 $S_i\ge\texttt{cur}=E_{last}$ 正是「与已选最后一头兼容」，而已选集合右端点递增，与最后一头兼容 $\Rightarrow$ 与所有已选兼容（$S_i\ge E_{last}\ge E_{prev}$）。(c) 逐条已述。(d) $E_i>S_i$ 是题设，$S_i\ge\texttt{cur}_{old}$ 是选择条件，串联即得。证毕。

---

### 引理 6（复杂度与值域）

时间 $O(N\log N)$，空间 $O(N)$。坐标 $\le10^8$、答案 $\le N$，均在 `int` 内。

*证明*：排序 $O(N\log N)$（`std::sort`），扫描 $O(N)$（每区间一次比较、至多一次更新），合计 $O(N\log N)\approx5\times10^4\times16=8\times10^5$ 次比较。空间：区间数组 $O(N)$，排序栈 $O(\log N)$。值域：$E_i\le10^8<2^{31}-1$；答案 $\le N\le5\times10^4$；哨兵 $-114514$ 与坐标运算无溢出（只做比较，不做加减）。证毕。

---

### 定理

程序输出最大可同时吃草的牛数，总复杂度 $O(N\log N)$。

*证明*：引理 1 把题面兼容条件等价翻译成半开区间不交；引理 2 证明「选最早结束者」不损失最优性；引理 3 证明选后问题同形缩小；引理 4 证明排序 + 扫描恰好逐层实现引理 2/3 的递归，故选中的数量 $=\mathrm{OPT}$；引理 5 核对哨兵、$\ge$ 判据、并列排序、`cur` 单调四个实现点；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 兼容条件 $S_i\ge E_j\lor E_i\le S_j$ 等价于半开区间 $[S,E)$ 两两不交；端点相接合法。
2. **consider easier version** — 子集枚举 $2^N$、朴素 DP $O(N^2)=2.5\times10^9$ 都不可行，锁定贪心方向。
3. **explore its property** — 试错两种贪心：按左端点排序被 $(1,100),(2,3),(4,5)$ 反例击毙；按长度排序被 $(1,4),(3,5),(4,7)$ 反例击毙；失败根源都是「对未来的占用」不受控。
4. **classic problem solution** — 活动选择贪心：按右端点升序 + 能选就选；交换论证证明最早结束者必可入选某最优解。
5. **reduce to easier problem** — 选完 $g$ 后残量实例 $\{S\ge E_g\}$ 与原问题同形（最优子结构），扫描 = 逐层递归。
6. **discuss by category** — 哨兵 `cur=-114514`；判据 $\ge$ 而非 $>$；右端点并列任意序；`cur` 严格递增保证跳过者永久出局。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 牛数 $N\le5\times10^4$ | `int` | 读入 |
| `mxn` | $50000+5$ | `constexpr int` | 数组尺寸松弛 |
| `a[i].s` | 第 $i$ 头牛区间左端点 $S$（排序后重排） | `int` | 读入；$S\ge1$ |
| `a[i].e` | 右端点 $E$，**排序关键字** | `int` | 读入；$S<E\le10^8$ |
| `cur` | 已选最后一头的右端点；兼容判据的右操作数 | `int` | 初值 $-114514$（哨兵，$<$ 一切 $S$）；**只增不减** |
| `ans` | 已选牛数 | `int` | 全局默认 $0$，每选一头 $+1$ |

### 算法步骤

1. I/O 加速三行。
2. 读 $N$ 与每头牛的 $(S_i,E_i)$。
3. 按 `e` 升序 `sort`（并列任意）。
4. `cur=-114514`；顺序扫描：若 `a[i].s>=cur`，则 `++ans; cur=a[i].e;`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(N\log N)$，排序主导；$N=5\times10^4$ 时约 $8\times10^5$ 次比较。
- 空间：$O(N)$，区间数组约 $0.4$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例输出 $3$ 吻合；另造「相接链」「左端点贪心反例」「长度贪心反例」三组手算数据全对。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2970 [USACO09DEC] Selfish Grazing S
// 经典活动选择：按右端点排序，能选就选（端点相接合法）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005};

int n,ans;
struct seg{int s,e;}a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i].s>>a[i].e;
	sort(a,a+n,[](seg x,seg y){return x.e<y.e;});
	int cur{-114514};	// 已选最后一头的 E；S_i>=1，哨兵保证第一头必可选
	for(int i=0;i<n;++i)
		if(a[i].s>=cur)	// 相接合法：S>=cur 即可，不是 S>cur
		{
			++ans;
			cur=a[i].e;
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **排序关键字是 `e` 不是 `s`**：引理 2 的交换论证只对「右端点最小者」成立；按左端点或长度排序都有反例（第一部分）。
- **判据 `>=`**：题面允许 $E_i=S_j$ 相接。写成 `>` 是本题最常见的 WA 点，相接链数据立刻暴露。
- `cur{-114514}`：114514 家族哨兵，语义是「尚未选任何牛」。因 $S_i\ge1$，第一头必被选，与贪心选择性质一致。`cur` 每次更新为 $E_i>S_i\ge\texttt{cur}$，严格递增，被跳过的区间永久不可能再兼容。
- 比较器按值传参 `seg x,seg y`（两个 `int`，拷贝零成本）；并列时顺序任意，正确性不受影响（引理 5(c)）。
- 全程只做比较与赋值，不做坐标加减，`int` 无溢出风险；答案 $\le N$ 也在 `int` 内。
