# P2674 《瞿葩的数字游戏》T2-多边形数 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 多边形数：能排成正 $K$ 边形的整数。第 $K$ 类（$K\ge3$）的第 $n$ 个记作 $P(K,n)$，题面给了前几项的表：

| $n$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 三角形 $K=3$ | 1 | 3 | 6 | 10 | 15 | 21 | 28 | 36 |
| 正方形 $K=4$ | 1 | 4 | 9 | 16 | 25 | 36 | 49 | 64 |
| 五边形 $K=5$ | 1 | 5 | 12 | 22 | 35 | 51 | 70 | 92 |
| 六边形 $K=6$ | 1 | 6 | 15 | 28 | 45 | 66 | 91 | 120 |

给 $N$（$\le10^6$，共 $ng\le100$ 组），求 $N$ 是哪些 $K$ 边形数。**若同时是多种，输出最小的 $K_1$ 和次小的 $K_2$**；若不是多边形数，输出 `Poor`+该数字。题面注明"中间无空格"。

**第一步：先从表里把通项公式抠出来。** 这是题面明说的"规律题"。观察每一行：第 $1$ 项都是 $1$，第 $2$ 项恰好等于 $K$（三角形第 2 项 3、正方形第 2 项 4、五边形 5、六边形 6）。再看相邻项的差（以三角形为例）：$3-1=2,\ 6-3=3,\ 10-6=4$，差是 $2,3,4,\dots$；正方形差是 $3,5,7,9$（奇数）；五边形差是 $4,7,10,13$（公差 3）；六边形差是 $5,9,13,17$（公差 4）。

规律：第 $K$ 类的差构成首项为 $2$、公差为 $K-2$ 的等差数列，即 $P(K,n)-P(K,n-1)=(K-2)(n-1)+1$。累加：

$$P(K,n)=\sum_{j=1}^{n}\bigl[(K-2)(j-1)+1\bigr]=n+(K-2)\cdot\frac{n(n-1)}2=\frac{(K-2)n^2-(K-4)n}2.$$

代回四行全部吻合（$K=3$ 得 $\frac{n(n+1)}2$ 三角形数，$K=4$ 得 $n^2$ 平方数，$K=5$ 得 $\frac{n(3n-1)}2$，$K=6$ 得 $n(2n-1)$）。公式到手。

**第二步：发现一个藏得很深的性质——$P(K,2)=K$。** 把 $n=2$ 代入：$P(K,2)=2+(K-2)\cdot1=K$。这意味着**每个 $N\ge3$ 都是 $N$ 边形数**（取 $K=N,n=2$）！所以"不是多边形数"的情况几乎不存在。再结合 $P(K,1)=1$（所有 $K$）和 $n\ge2$ 时 $P(K,n)\ge K\ge3$，可以精确判定：

- $N=1$：是**每一个** $K\ge3$ 的多边形数（$n=1$），最小两个 $K$ 是 $3,4$。
- $N=2$：$P(K,1)=1\ne2$，$P(K,n)\ge3>2$（$n\ge2$），**没有任何 $K$**，输出 `Poor2`。
- $N\ge3$：至少含 $K=N$，一定非空。

这就是本题真正的"规律"：`Poor` 分支只对 $N=2$ 触发。想通这一点，才不会在"找不到多边形数"上浪费精力。

**第三步：怎么求出所有的 $K$？两条路。**

- **路线 A（枚举 $K$）**：$K$ 从 $3$ 到 $N$，对每个 $K$ 解二次方程 $(K-2)n^2-(K-4)n-2N=0$，看判别式 $(K-4)^2+8N(K-2)$ 是否完全平方、$n$ 是否正整数。单次 $O(N)$，$ng=100$、$N=10^6$ 时约 $10^8$ 次带 `sqrt` 的运算，偏慢且浮点判完全平方有精度风险。
- **路线 B（反解 $K$，枚举 $n$）**：注意到 $P(K,n)=n+(K-2)\frac{n(n-1)}2$ 对 $K$ 是**线性**的！固定 $n$，直接反解：
  $$N=n+(K-2)\frac{n(n-1)}2\ \Longrightarrow\ K=2+\frac{2N-2n}{n(n-1)}.$$
  只要 $n(n-1)\mid(2N-2n)$ 且商 $\ge1$（即 $K\ge3$），就得到一个合法 $K$。而 $n$ 的范围很小：因为 $K\ge3$ 时 $P(K,n)\ge P(3,n)=\frac{n(n+1)}2$，所以 $N=P(K,n)$ 必有 $\frac{n(n+1)}2\le N$，即 $n\le\sqrt{2N}\approx1414$。枚举 $n=2..1414$，单次 $O(\sqrt N)$，$100$ 组才 $1.4\times10^5$ 次运算。**路线 B 完胜**，选它。

**第四步：几个必须抠清楚的细节。**

1. **$n=1$ 单独处理**：反解公式分母 $n(n-1)=0$ 会除零，且 $n=1$ 对应 $N=1$（所有 $K$）。所以 $N=1$ 直接输出 $3,4$，循环从 $n=2$ 开始。
2. **$K\ge3$ 自动成立**：当 $\frac{n(n+1)}2\le N$ 时，$K=2+\frac{2N-2n}{n(n-1)}\ge2+\frac{n(n+1)-2n}{n(n-1)}=2+\frac{n(n-1)}{n(n-1)}=3$。所以只要 $n$ 在枚举范围内、整除成立，$K$ 必 $\ge3$（代码仍保留判断做保险）。
3. **$K$ 互不相同**：固定 $N$，$K(n)=2+\frac{2N-2n}{n(n-1)}$ 随 $n$ 增大**严格递减**（分子减小、分母增大），故不同 $n$ 给出不同 $K$，无需去重。
4. **排序取前二**：把收集到的 $K$ 升序排序，取最小两个。由于 $K(n)$ 递减，收集顺序其实是降序，排序后反转。
5. **输出格式（题意解读）**：题面"（中间无空格）"放在输出格式描述末尾，我按**整行无空格**理解：$K_1K_2$ 直接拼接（如 $36$ 输出 `34`），`Poor`+数字直接拼接（`Poor2`）。"若同时是多种……输出最小和第二小"反过来意味着**只有一种时只输出那一个 $K$**（如 $N=3$ 输出 `3`）。这是题面字面最自然的读法，我在第二节明确标注。

**手造数据核对**（题面没给样例输入输出，我按公式手算几组，并用独立暴力程序全量核对，见第四节）：

| $N$ | 合法 $K$ 集合 | 输出 |
|---|---|---|
| $1$ | 所有 $K\ge3$ | `34` |
| $2$ | 空 | `Poor2` |
| $3$ | $\{3\}$ | `3` |
| $6$ | $\{3,6\}$（$T_3=6$，$P(6,2)=6$） | `36` |
| $10$ | $\{3,10\}$（$T_4=10$） | `310` |
| $15$ | $\{3,6,15\}$（$T_5=15$，$P(6,3)=15$） | `36` |
| $36$ | $\{3,4,13,36\}$（$T_8=36$，$6^2=36$，$P(13,3)=36$，$P(36,2)=36$） | `34` |
| $10^6$ | $\{4,204,\dots\}$（$1000^2=10^6$，$P(204,100)=10^6$） | `4204` |

$N=36$ 与题面"36 是三边形数和四边形数"的说法一致（最小两个正是 3、4）。程序输出与这些手算逐一吻合。

## 二、思维链：完整证明

**记号。** $P(K,n)=n+(K-2)\frac{n(n-1)}2=\frac{(K-2)n^2-(K-4)n}2$，$K\ge3$，$n\ge1$。$T_n=\frac{n(n+1)}2$。称 $K$ 对 $N$ **合法**，若存在 $n\ge1$ 使 $P(K,n)=N$。

---

### 引理 1（通项公式与表一致）

$P(K,n)=n+(K-2)\frac{n(n-1)}2$ 给出的数列，与题面表中 $K=3,4,5,6$ 的前 $8$ 项逐项相等；且 $P(K,1)=1$，$P(K,2)=K$。

*证明*：先验证差分。$P(K,n)-P(K,n-1)=\bigl[n+(K-2)\frac{n(n-1)}2\bigr]-\bigl[(n-1)+(K-2)\frac{(n-1)(n-2)}2\bigr]=1+(K-2)\frac{(n-1)[n-(n-2)]}2=1+(K-2)(n-1)$。这正是从表里读出的"首项 $2$、公差 $K-2$ 的等差差分"（$n=2$ 时差 $=1+(K-2)=K-1$；三角形 $K=3$ 差 $2$，正方形 $K=4$ 差 $3$，五边形差 $4$，六边形差 $5$，与表吻合）。又 $P(K,1)=1+(K-2)\cdot0=1$，与表首项一致。由首项与差分唯一确定数列，故公式与表逐项相等。

直接代入：$P(K,1)=1$；$P(K,2)=2+(K-2)\cdot\frac{2\cdot1}2=2+(K-2)=K$。

特例核对：$K=3$：$n+(1)\frac{n(n-1)}2=\frac{2n+n^2-n}2=\frac{n(n+1)}2=T_n$（三角形数 1,3,6,10,15,21,28,36 ✓）。$K=4$：$n+2\cdot\frac{n(n-1)}2=n+n(n-1)=n^2$（1,4,9,16,25,36,49,64 ✓）。$K=5$：$n+3\frac{n(n-1)}2=\frac{2n+3n^2-3n}2=\frac{n(3n-1)}2$（1,5,12,22,35,51,70,92 ✓）。$K=6$：$n+4\frac{n(n-1)}2=n+2n(n-1)=2n^2-n=n(2n-1)$（1,6,15,28,45,66,91,120 ✓）。证毕。

---

### 引理 2（单调性）

(a) 固定 $K\ge3$，$P(K,n)$ 关于 $n$ 严格递增；(b) 固定 $n\ge2$，$P(K,n)$ 关于 $K$ 严格递增；(c) $n\ge2$ 时 $P(K,n)\ge K$，$n\ge1$ 时 $P(K,n)\ge T_n$。

*证明*：(a) 由引理 1 的差分 $P(K,n)-P(K,n-1)=1+(K-2)(n-1)\ge1>0$（$K\ge3,n\ge1$），故严格递增。

(b) $P(K,n)=n+(K-2)\frac{n(n-1)}2$，$n\ge2$ 时系数 $\frac{n(n-1)}2>0$，故 $K$ 增大 $1$，$P$ 增大 $\frac{n(n-1)}2>0$，严格递增。

(c) 由 (a)，$n\ge2$ 时 $P(K,n)\ge P(K,2)=K$。由 (b)，$K\ge3$ 时 $P(K,n)\ge P(3,n)=T_n$（$n=1$ 时两边都是 $1$，也成立）。证毕。

---

### 引理 3（$N=1$ 与 $N=2$ 的完全判定）

$N=1$ 对每个 $K\ge3$ 都合法（唯一 $n=1$），最小两个 $K$ 为 $3,4$。$N=2$ 没有任何合法 $K$。

*证明*：$N=1$：$P(K,1)=1$（引理 1），故每个 $K\ge3$ 合法。又 $n\ge2$ 时 $P(K,n)\ge K\ge3>1$（引理 2c），故 $n=1$ 是唯一表示。合法 $K$ 集合为 $\{3,4,5,\dots\}$，最小两个 $3,4$。

$N=2$：$n=1$ 时 $P=1\ne2$；$n\ge2$ 时 $P(K,n)\ge K\ge3>2$（引理 2c）。故无合法 $K$，输出 `Poor2`。证毕。

---

### 引理 4（普遍性：每个 $N\ge3$ 都是 $N$ 边形数）

对任意 $N\ge3$，$K=N$ 合法（取 $n=2$）。故 $N\ge3$ 的合法 $K$ 集合非空，`Poor` 分支仅对 $N=2$ 触发。

*证明*：由引理 1，$P(N,2)=N$。$N\ge3$ 满足 $K\ge3$，故 $K=N$ 是合法表示。结合引理 3（$N=1$ 非空、$N=2$ 空），得：合法集为空 $\iff N=2$。证毕。

**这是本题的核心规律**：表面上要判"是不是多边形数"，实际上除了 $2$ 以外全是。

---

### 引理 5（反解公式）

对 $n\ge2$，$N=P(K,n)$ 当且仅当 $K=2+\frac{2N-2n}{n(n-1)}$。因此 $K$ 为合法整数当且仅当 $n(n-1)\mid(2N-2n)$ 且由此算出的 $K\ge3$。

*证明*：$N=n+(K-2)\frac{n(n-1)}2\iff 2N=2n+(K-2)n(n-1)\iff (K-2)n(n-1)=2N-2n\iff K-2=\frac{2N-2n}{n(n-1)}$（$n\ge2$ 时 $n(n-1)\ne0$，可除）$\iff K=2+\frac{2N-2n}{n(n-1)}$。每一步都是等价变形，故双向成立。$K$ 须为 $\ge3$ 的整数，即要求整除且商 $\ge1$。证毕。

---

### 引理 6（枚举范围的完备性）

若 $K\ge3$ 对 $N$ 合法且表示为 $P(K,n)=N$，则 $n=1$（此时 $N=1$）或 $2\le n\le n_{\max}$，其中 $n_{\max}=\max\{n:T_n\le N\}$。故枚举 $n=2..n_{\max}$ 加上 $N=1$ 特判，覆盖全部合法表示，无遗漏。

*证明*：由引理 2c，$N=P(K,n)\ge T_n$，故 $T_n\le N$，即 $n\le n_{\max}$。若 $n=1$ 则 $N=P(K,1)=1$（引理 1），归入特判。若 $n\ge2$，则 $2\le n\le n_{\max}$，被循环覆盖。反之循环里每个整除成立的 $n$ 由引理 5 给出合法 $K$。故"循环收集的 $K$"恰为"$N$ 的全部 $n\ge2$ 表示对应的 $K$"，加上 $N=1$ 的特判即完整。证毕。

$n_{\max}$ 的量级：$T_n\le N\iff n^2+n\le2N\iff n\le\frac{-1+\sqrt{1+8N}}2\approx\sqrt{2N}$。$N=10^6$ 时 $n_{\max}=1413$（$T_{1413}=998991\le10^6<T_{1414}=1000405$）。

---

### 引理 7（$K\ge3$ 自动成立）

当 $T_n\le N$（即 $n$ 在枚举范围内）且 $n(n-1)\mid(2N-2n)$ 时，引理 5 算出的 $K\ge3$。

*证明*：$T_n\le N\iff n(n+1)\le2N\iff 2N-2n\ge n(n+1)-2n=n^2-n=n(n-1)$。故 $\frac{2N-2n}{n(n-1)}\ge1$，从而 $K=2+\frac{2N-2n}{n(n-1)}\ge3$。证毕。

（代码仍写 `if(K>=3)` 做防御性检查，逻辑上冗余但无害。）

---

### 引理 8（合法 $K$ 互不相同）

固定 $N$，函数 $K(n)=2+\frac{2N-2n}{n(n-1)}$ 在 $n\ge2$、$T_n\le N$ 上严格递减。故不同 $n$ 给出不同 $K$，收集到的 $K$ 无重复。

*证明*：设 $2\le n_1<n_2$ 且都在范围内。分子 $2N-2n$ 随 $n$ 增大严格减小（$2N-2n_1>2N-2n_2\ge0$，非负由引理 7）；分母 $n(n-1)$ 随 $n$ 增大严格增大（$n_1(n_1-1)<n_2(n_2-1)$，均为正）。分子减小、分母增大且都非负/正，故分数 $\frac{2N-2n_1}{n_1(n_1-1)}>\frac{2N-2n_2}{n_2(n_2-1)}$，即 $K(n_1)>K(n_2)$。严格递减 ⇒ 单射 ⇒ 无重复。证毕。

（另证：由引理 2a，固定 $K$ 时 $P(K,n)$ 关于 $n$ 严格递增，故一个 $K$ 至多对应一个 $n$；结合引理 5 一个 $n$ 至多一个 $K$，表示对 $(K,n)$ 一一对应，$K$ 自然互异。）

### 引理 9（输出规则与题意解读）

设合法 $K$ 升序为 $K_1<K_2<\dots$。输出规则：
- 集合为空（仅 $N=2$）：输出 `Poor`+N（无空格）；
- 恰一个：输出 $K_1$；
- 至少两个：输出 $K_1$ 紧接 $K_2$（无空格）；
- $N=1$：输出 `34`。

*证明（题意解读层面的论证）*：题面输出格式为"$N$ 相应的 $K_1$ 和 $K_2$，若不是多边形数，输出 Poor + 该数字。（中间无空格）"。

1. **"中间无空格"** 置于整段输出描述末尾，最自然的读法是**整行不含空格**：$K_1,K_2$ 直接拼接，`Poor` 与数字直接拼接（`Poor`+数字的"+"号也暗示拼接）。若 $K_1K_2$ 之间有空格，则与"中间无空格"矛盾。故取无空格拼接。
2. **"若同时是多种……输出最小和第二小"** 是一个条件句，隐含"只有一种时输出那一种"。故恰一个合法 $K$ 时只输出 $K_1$（如 $N=3\to$`3`）。
3. $N=1$ 由引理 3 合法集为全体 $K\ge3$，最小两个 $3,4$，按规则 1 拼接为 `34`。

这是题面字面最自洽的解读。题面未给样例输入输出，无法用样例进一步区分，本文按此解读实现，并在此明确标注（与 P2412 处理"输出是否保留大小写"的方式一致：选择让题面每条规则都生效的读法）。证毕。

### 引理 10（复杂度与值域）

单组 $O(\sqrt N)$ 时间、$O(\sqrt N)$ 空间；$ng$ 组共 $O(ng\sqrt N)$。中间量用 `i64` 安全。

*证明*：循环 $n=2..n_{\max}$，$n_{\max}\approx\sqrt{2N}\le1414$（$N\le10^6$），每次 $O(1)$ 整除判断，故单组 $O(\sqrt N)$。收集到的 $K$ 个数 $\le n_{\max}$，排序 $O(\sqrt N\log\sqrt N)$，仍 $O(\sqrt N)$ 量级。$ng\le100$，总迭代 $\le100\times1414\approx1.4\times10^5$。

值域：$N\le10^6$，$2N\le2\times10^6$，$n(n-1)\le1413\times1412\approx2\times10^6$，$2N-2n$、$n(n+1)$ 等均 $\le$ 几百万，`int` 本可容纳；但 $K$ 可达 $N=10^6$、乘积中间量统一用 `i64` 杜绝任何溢出隐患。空间存 $K$ 的数组 $\le1414$ 个 `i64`，约 $11$ KB。证毕。

### 定理

程序对每组 $N$ 输出其最小两个合法 $K$（无空格拼接；单个则只输出一个；$N=2$ 输出 `Poor2`；$N=1$ 输出 `34`），总时间 $O(ng\sqrt N)$。

*证明*：引理 1 确立公式，引理 2 给出单调性，引理 3、4 完全判定 $N=1,2$ 与普遍性，引理 5 给出反解，引理 6 保证枚举范围完备无遗漏，引理 7 保证 $K\ge3$，引理 8 保证无重复，引理 9 确定输出规则，引理 10 给出复杂度与值域。排序后取前二即最小两个合法 $K$。证毕。

**独立验证**：另写一份"正向枚举 $(n,K)$ 直接算 $P(K,n)$ 判等"的暴力（不依赖反解代数），对全部 $N=1..3000$、$16$ 个手工边界（含 $998991,1000405,999999,10^6$ 等）与 $300$ 个 $[1,10^6]$ 随机 $N$，共 $3316$ 组，比较两者给出的最小两个 $K$ 及输出串，**$0$ 处不一致**（见 `appendix/P2674/P2674_check.cpp`）。这独立验证了反解公式、枚举界与边界判定的正确性。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 从表里抠通项：差分是首项 $2$、公差 $K-2$ 的等差数列 ⇒ $P(K,n)=n+(K-2)\frac{n(n-1)}2$，代回四行验证。
- **explore its property** — 隐藏规律 $P(K,2)=K$ ⇒ 每个 $N\ge3$ 都是 $N$ 边形数；$N=1$ 是所有 $K$；`Poor` 仅 $N=2$。
- **consider easier version** — 先想枚举 $K=3..N$ + 判别式判完全平方：$O(N)$/组，$10^8$ 偏慢且有浮点精度风险。
- **reduce to easier problem** — $P$ 对 $K$ 线性 ⇒ 反解 $K=2+\frac{2N-2n}{n(n-1)}$，改枚举 $n$；由 $P(K,n)\ge T_n$ 得 $n\le\sqrt{2N}$，降到 $O(\sqrt N)$/组。
- **classic problem solution** — 整除枚举 + 三角形数定界：$n(n+1)/2\le N$ 框住 $n$，$n(n-1)\mid(2N-2n)$ 筛合法 $K$。
- **discuss by category** — $N=1$（全体 $K$，输出 34）、$N=2$（Poor2）、单个 $K$（只输出一个）、多个 $K$（排序取前二）；输出无空格拼接（题意解读，已标注）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `ng` | 数据组数（$\le100$） | `int`，读入 | 多测 |
| `N` | 当前询问的数（$\le10^6$） | `i64`，读入 | 用 i64 防中间溢出 |
| `n` | 多边形数的"项数/边点数" | `i64`，循环 $2..n_{\max}$ | $n=1$ 特判（$N=1$） |
| `num` | $2N-2n$ | `i64` | 反解分子 |
| `den` | $n(n-1)$ | `i64` | 反解分母，$n\ge2$ 非零 |
| `K` | 反解出的边数 $2+\text{num}/\text{den}$ | `i64` | 整除且 $\ge3$ 才合法 |
| `kk[]` | 收集到的合法 $K$ | `i64[mxk]` | 升序排序后取前二 |
| `cnt` | 合法 $K$ 个数 | `int`，每组初值 $0$ | $0\Rightarrow$ Poor |
| `mxk` | $K$ 数组尺寸 $1420$（$n_{\max}\le1413$，+5 松弛） | `constexpr int` | 单组合法 $K$ 不超过 $n_{\max}$ |

### 算法步骤

1. I/O 加速三行；读 `ng`。
2. 每组读 `N`：
   1. 若 `N==1`，输出 `34`， continue（引理 3）。
   2. `cnt=0`；对 `n=2` 起、当 `n*(n+1)/2<=N`：`num=2*N-2*n`，`den=n*(n-1)`；若 `num%den==0`，`K=2+num/den`，若 `K>=3` 则 `kk[cnt++]=K`（引理 5、6、7）。
   3. 若 `cnt==0` 输出 `Poor`+N（仅 $N=2$，引理 4）；否则排序 `kk[0..cnt)`，输出 `kk[0]`，若 `cnt>=2` 再输出 `kk[1]`，换行（引理 9）。

### 复杂度

- 时间：$O(ng\sqrt N)$，$ng=100,N=10^6$ 时约 $1.4\times10^5$ 次迭代。
- 空间：$O(\sqrt N)$，`kk` 约 $11$ KB。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；手算 $N=1,2,3,6,10,15,36,10^6$ 八组与程序输出逐一吻合（$N=36\to$`34` 与题面说法一致）；另用独立的"正向枚举 $(n,K)$ 算 $P$"暴力对全部 $N\le3000$ + $16$ 边界 + $300$ 随机大数共 $3316$ 组核对最小两个 $K$，$0$ mismatch（`appendix/P2674/P2674_check.cpp`，仅 C++）。**唯一疑虑**：输出格式按"整行无空格、单个 $K$ 只输出一个"的字面解读实现（引理 9），题面无样例可进一步区分。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2674 《瞿葩的数字游戏》T2-多边形数
// 通项 P(K,n)=n+(K-2)*n*(n-1)/2，对 K 线性 ⇒ 反解 K=2+(2N-2n)/(n(n-1))
// 隐藏规律 P(K,2)=K ⇒ 每个 N>=3 都是 N 边形数；N=1 是所有 K；Poor 仅 N=2
// P(K,n)>=T_n ⇒ n<=sqrt(2N)，枚举 n 即 O(sqrt N)/组
// 输出按题面"中间无空格"：K1K2 拼接 / Poor+N 拼接 / 单个 K 只输出一个
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxk{1420};	// n_max<=1413 (N<=1e6)，合法 K 个数不超过 n_max

int ng,cnt;
i64 kk[mxk];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>ng;
	while(ng--)
	{
		i64 N;
		cin>>N;
		if(N==1)	// P(K,1)=1 对所有 K>=3，最小两个是 3,4
		{
			cout<<"34\n";
			continue;
		}
		cnt=0;
		for(i64 n=2;n*(n+1)/2<=N;++n)	// P(K,n)>=T_n ⇒ n 受三角形数定界
		{
			i64 num=2*N-2*n,den=n*(n-1);
			if(num%den==0)
			{
				i64 K=2+num/den;
				if(K>=3)	// 范围内自动 >=3，防御性保留
					kk[cnt++]=K;
			}
		}
		if(cnt==0)
			cout<<"Poor"<<N<<'\n';	// 仅 N=2 会走到这里
		else
		{
			sort(kk,kk+cnt);
			cout<<kk[0];
			if(cnt>=2)
				cout<<kk[1];
			cout<<'\n';
		}
	}
	return 0;
}
```

### 代码说明

- **反解而非枚举 $K$**：$P$ 对 $K$ 线性，固定 $n$ 一步算出 $K$，把 $O(N)$ 降到 $O(\sqrt N)$。`num%den==0` 是整除判据，全程整数运算，无浮点精度问题。
- **循环条件 `n*(n+1)/2<=N`**：即 $T_n\le N$，由 $P(K,n)\ge T_n$ 保证完备（引理 6）；`n` 用 `i64`，`n*(n+1)` 不会溢出。
- **`N==1` 特判**：避开 $n=1$ 时分母 $n(n-1)=0$ 的除零，且 $N=1$ 合法 $K$ 是无穷集，直接给最小两个 `34`。
- **`cnt==0` 即 Poor**：由引理 4，只有 $N=2$ 会空；$N\ge3$ 时 $n=2$ 必给出 $K=N$，`cnt` 至少 $1$。
- **排序取前二**：$K(n)$ 随 $n$ 递减（引理 8），收集顺序是降序，`sort` 后 `kk[0],kk[1]` 即最小两个；无重复，无需去重。
- **输出无空格**：`cout<<kk[0]<<kk[1]` 直接拼接，`"Poor"<<N` 直接拼接，符合题面"中间无空格"（引理 9 的解读）。
