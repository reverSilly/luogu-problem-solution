# P2360 地下城主 — 题解

## 一、解题过程：人类思考叙事

**重述题意。** 地牢是 $L$ 层、每层 $R$ 行 $C$ 列的三维格子（$1\le L,R,C\le30$），格子有三种：`S` 起点、`E` 出口、`#` 岩石（不可通行）、`.` 空地。每一分钟可以从当前格子走到**前/后/左/右/上一层/下一层**这六个相邻格子之一。问从 `S` 到 `E` 的最短时间，能到就输出 `Escaped in x minute(s).`，否则输出 `Trapped!`。两层之间有空行。

**第一步：看清"代价结构"。** 题目只有一个关键词——**每走一小格花费一分钟**，也就是所有转移的代价都是 $1$。一旦"所有边权相等"，最短路就退化成了"最少步数"，而最少步数正是 BFS 的看家本领（BFS 按距离一层层扩张，节点第一次被访问时的距离就是最短距离）。所以这题不需要 Dijkstra，更不需要任何贪心。

**第二步：把格子变成状态。** 一个状态就是三元组 $(\text{层},\text{行},\text{列})$。为了不写三维的队列，我把状态压成一个整数
$$\mathrm{id}=(\text{层}\cdot R+\text{行})\cdot C+\text{列},$$
队列和 `dis` 数组都是一维的，容量 $LRC\le27000$。

**第三步：六个方向。** 三个方向的位移数组拼成六种组合即可（层 $\pm1$、行 $\pm1$、列 $\pm1$），无需特判方向。越界、岩石、已访问三种情况直接 `continue`。

**踩坑记录（真实发生）。** 解码时我一开始写的是 `int i=u/(R*C),j=u/C%C,k=u%C;`（错）。`u/C` 得到的是 $iR+j$，要对 **$R$** 取模才能得到 $j$，我写成了对 $C$ 取模。在 $R=C$ 的数据上它碰巧是对的，一旦 $R\ne C$ 就会把状态解到错误的行/列上去，表现为"明明有路却输出 `Trapped!`"。自造的第一组数据是 $3\times4\times5$、答案 $7$，程序却输出 `Trapped!`，正是这个下标问题。改成 `j=u/C%R` 才对。

**第四步：读入的坑。** 题面说"两层地牢中间有空行隔开"。如果用 `getline` 逐行读，空行会打乱行数；但用 `cin>>ch` 读**单个字符**时，`operator>>` 会自动跳过所有空白（空格、换行、空行），所以把 $LRC$ 个字符一个不漏地顺序读下来就行，空行完全不用管。这是本题读入最省事的写法。

**第五步：无解与多组数据。** BFS 结束后如果 `dis[E]` 还是 $-1$，说明 $E$ 与 $S$ 不连通（出口被岩石封死，或根本在两个隔离区），输出 `Trapped!`。另外本题原型（POJ 2251）是多组数据并以 `0 0 0` 结尾，而洛谷这版题面只描述了一组；我把读入写成 `while(cin>>L>>R>>C)` 并在 $L=0$ 时退出，两种数据都能吃下，单组数据也只会输出一行。

**自造数据（题面无样例）。** 用三组手算数据检验：

| 数据 | 手算最短时间 |
| --- | --- |
| $3\times4\times5$，须先下到第 0 层最左列、再逐层下沉、再横移两格到 `E` | $3+2+2=7$ |
| $1\times3\times3$：`S#E` / `###` / `###`，`E` 左侧是岩石且上下都是岩石 | 不通，`Trapped!` |
| $2\times1\times2$：第一层 `S.`，第二层 `.E` | 右一步 + 下一步 $=2$ |

三组全部吻合。此外写了一个"DFS 枚举全部简单路径取最短"的独立暴力，在 $300$ 组 $L,R\le2,\ C\le3$ 的随机小地牢（含大量死角与孤岛）上对拍，输出完全一致。

## 二、思维链：完整证明

### 2.0 图模型

把每个非岩石格子看作一个顶点，若两个格子在这六个方向上相邻则连一条无向边，边权为 $1$（走一步一分钟）。记这个图为 $G=(V,E_g)$，顶点数 $|V|\le LRC$。题目的"从 `S` 沿格子移动到 `E` 的最短时间"就是 $G$ 中 $\mathrm{id}(S)$ 到 $\mathrm{id}(E)$ 的最短路长度（每条边权为 $1$）。

**引理 1（路径 ↔ 走法一一对应）**：$G$ 中从 $s$ 到 $t$ 的一条路径 $(v_0=s,v_1,\dots,v_d=t)$ 与"用 $d$ 分钟从 $s$ 走到 $t$"的一种走法一一对应，且时间恰为 $d$。

*证明*：走法的每一步都是从一个格子到六邻域内的另一个非岩石格子，正是一条边；反过来，$G$ 的一条路径的相邻顶点在六方向上相邻，按顺序走一遍即是一种合法走法。每步一分钟，$d$ 步即 $d$ 分钟。证毕。

由引理 1，"最短时间" $=\operatorname{dist}_G(s,t)$（无边权图的最短路 = 最少边数）。

### 2.1 引理 2：BFS 求出的是最短路

**引理 2**：在边权全为 $1$ 的图上，BFS 中任一顶点 $v$ 第一次被访问（入队）时记录的 `dis[v]` 等于 $\operatorname{dist}(s,v)$。

*证明*：对 $\operatorname{dist}(s,v)$ 归纳。BFS 用先进先出队列，出队顺序的 `dis` 值单调不降（这是队列 BFS 的标准不变量：若队首 `dis` 为 $d$，则队列中所有元素的 `dis` 只能是 $d$ 或 $d+1$）。

- 基础：$v=s$，`dis[s]=0` 正确。
- 归纳：设所有距离 $<d$ 的顶点都已正确标号。取距离为 $d$ 的顶点 $v$，设 $u$ 是它在某条最短路上的前驱，$\operatorname{dist}(s,u)=d-1$。由归纳假设 $u$ 的 `dis` 正确；$u$ 出队时必然考察了邻居 $v$，若 $v$ 当时未被访问就会把 `dis[v]` 设为 $d$。若 $v$ 在更早时刻被访问过，则由队列按层扩张的性质，那次赋值只能是某个 `dis` 为 $d-1$ 的邻居给出的，值也是 $d$。而 $v$ 不可能被赋成 $<d$ 的值，因为那意味着存在长度 $<d$ 的路径，与距离为 $d$ 矛盾。故 `dis[v]=d`。

证毕。

**引理 3**：BFS 结束后 `dis[E]==-1` 当且仅当 $E$ 与 $S$ 不连通。

*证明*：BFS 会访问 $s$ 所在的整个连通块（每个连通块内的顶点都能沿边被逐层发现）。$E$ 被访问 $\iff$ 与 $S$ 同属一个连通块 $\iff$ 存在路径 $\iff$ 可达。反方向同理。证毕。

### 2.2 引理 4：状态编码无冲突

**引理 4**：映射 $(\text{层},\text{行},\text{列})\mapsto(\text{层}\cdot R+\text{行})\cdot C+\text{列}$ 在 $0\le \text{层}<L,\ 0\le\text{行}<R,\ 0\le\text{列}<C$ 上是双射，其逆为
$$\text{层}=\mathrm{id}\ \text{div}\ (RC),\qquad \text{行}=(\mathrm{id}\ \text{div}\ C)\bmod R,\qquad \text{列}=\mathrm{id}\bmod C.$$

*证明*：这是混合进制表示（进制依次为 $1,C,RC$）。唯一性：若两个三元组编码相同，模 $C$ 得列相同，整除 $C$ 后归约为 $(\text{层},\text{行})$ 的二进制混合表示，同理得行、层相同。存在性：任一 $\mathrm{id}<LRC$ 按上式解出的三元组满足 $\text{列}<C$、$\text{行}<R$、$\text{层}<L$，代入编码式还原 $\mathrm{id}$。证毕。

**引理 5（复杂度）**：时间 $O(LRC)$，空间 $O(LRC)$。

*证明*：每个顶点至多入队一次（入队即置 `dis`，入队前检查 `dis==-1`），出队时考察 $6$ 个邻居，故总操作数 $\le 7LRC$。空间为三个 $O(LRC)$ 的数组（`mp`、`dis`、`Q`）。证毕。

**定理**：程序对每组数据输出的时间是最短时间，不可达时输出 `Trapped!`。

*证明*：由引理 1 把问题化为图最短路；由引理 2 BFS 给出的 `dis[E]` 就是最短路长度；由引理 3 判 `dis[E]==-1` 恰为不可达；由引理 4 编解码正确，队列里处理的确实是输入地图上的格子，且每个格子只被处理一次。故输出正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 每走一格都花 $1$ 分钟 ⇒ 所有转移等权，问题退化为"最少步数"。
2. **reduce to easier problem** — 把三维格子当成无权图顶点，六个方向当成边，问题化为无权图最短路。
3. **classic problem solution** — 无权图最短路用 BFS，节点首次入队时得到的就是最短距离（不需要 Dijkstra / 优先队列）。
4. **explore its property** — 用混合进制把三元组压成一个整数，队列与 `dis` 都降成一维；解码时 `u/C` 要对 **$R$** 取模。
5. **discuss by category** — 越界 / 岩石 / 已访问三类非法转移统一 `continue`；BFS 结束后 `dis[E]==-1` 即 `Trapped!`。
6. **handle input carefully** — 空行用 `cin>>char` 天然跳过；顺手用 `while(cin>>L>>R>>C)` + $L=0$ 退出兼容多组数据。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
| --- | --- | --- |
| $L,R,C$ | 层数、每层行数、每层列数 | 读入，$\le30$ |
| `mp[i][j][k]` | 第 $i$ 层第 $j$ 行第 $k$ 列的内容 | `char`，全局数组 |
| $S$ | 起点状态编码 | 读入时扫到 `S` 记下 |
| $E$ | 出口状态编码 | 读入时扫到 `E` 记下 |
| `dis[u]` | 从 $S$ 到 $u$ 的最短时间；$-1$ 表示未访问 | 每组数据 `fill_n(dis,tot,-1)` |
| `Q` | BFS 队列（存状态编码） | `hd/tl` 双指针，不用 `queue` |
| `dx,dy,dz` | 六个方向的位移：$(\pm1,0,0),(0,\pm1,0),(0,0,\pm1)$ | 常量数组 |
| $tot$ | $LRC$，状态总数 | 每组数据现算 |
| `hd,tl` | 队首、队尾 | 初始 $0$ |

### 算法步骤

1. 读 $L,R,C$；若有一个为 $0$ 则结束程序。
2. 三重循环读入 $LRC$ 个字符存进 `mp`（`cin>>char` 自动跳过层间空行），同时记录 `S`、`E` 的编码。
3. `fill_n(dis,L*R*C,-1)`；把 $S$ 入队并令 `dis[S]=0`。
4. 当队列非空：取队首 $u$，解出 $(i,j,k)$；枚举六个方向 $(ni,nj,nk)$，若越界、是 `#`、或 `dis` 已赋值，跳过；否则 `dis[v]=dis[u]+1` 并入队。
5. BFS 结束后：`dis[E]==-1` 输出 `Trapped!`，否则输出 `Escaped in dis[E] minute(s).`。
6. 回到步骤 1 继续读下一组（读到文件结束自动退出）。

### 复杂度

- 时间 $O(LRC)$，空间 $O(LRC)$（$LRC\le27000$）。

### 验证状态

- `g++ -std=c++20 -O2` 编译通过。
- 题面无样例，自造三组数据（答案 $7$、`Trapped!`、$2$）全部吻合；其中 $3\times4\times5$ 那组正是暴露"`u/C%C` 应为 `u/C%R`"的那组。
- 用"DFS 枚举所有简单路径取最短"作为独立暴力，对拍 $300$ 组随机小地牢（$L,R\le2$，$C\le3$，$30\%$ 岩石），输出逐字符一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2360 地下城主
// 三维无权图最短路: 六个方向 BFS, 每步 1 分钟
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{32};

int L,R,C;
char mp[mxn][mxn][mxn];
int dis[mxn*mxn*mxn],Q[mxn*mxn*mxn];
const int dx[6]={1,-1,0,0,0,0};
const int dy[6]={0,0,1,-1,0,0};
const int dz[6]={0,0,0,0,1,-1};

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	while(cin>>L>>R>>C)
	{
		if(L==0||R==0||C==0)
			break;
		int S=-1,E=-1;
		for(int i=0;i<L;++i)
			for(int j=0;j<R;++j)
				for(int k=0;k<C;++k)
				{
					cin>>mp[i][j][k];   // operator>> 会跳过层间空行
					if(mp[i][j][k]=='S')
						S=(i*R+j)*C+k;
					if(mp[i][j][k]=='E')
						E=(i*R+j)*C+k;
				}
		int tot=L*R*C;
		fill_n(dis,tot,-1);
		int hd=0,tl=0;
		Q[tl++]=S;
		dis[S]=0;
		while(hd<tl)
		{
			int u=Q[hd++];
			int i=u/(R*C),j=u/C%R,k=u%C;   // u/C 要对 R 取模
			for(int d=0;d<6;++d)
			{
				int ni=i+dx[d],nj=j+dy[d],nk=k+dz[d];
				if(ni<0||ni>=L||nj<0||nj>=R||nk<0||nk>=C)
					continue;
				if(mp[ni][nj][nk]=='#')
					continue;
				int v=(ni*R+nj)*C+nk;
				if(dis[v]!=-1)
					continue;
				dis[v]=dis[u]+1;
				Q[tl++]=v;
			}
		}
		if(dis[E]<0)
			cout<<"Trapped!"<<'\n';
		else
			cout<<"Escaped in "<<dis[E]<<" minute(s)."<<'\n';
	}
	return 0;
}
```

### 代码说明

- 六个方向写成三个平行数组，行/列/层各取 $\pm1$ 与 $0$，六种组合天然去重，不需要额外判重。
- `dis[v]!=-1` 兼作"已访问"标记，省掉一个 `vis` 数组；`dis` 每组数据都要 `fill_n(dis,tot,-1)`（全局数组默认是 $0$，不清零会把"未访问"误当"距离 $0$"）。
- `j=u/C%R`：先整除 $C$ 得到 $iR+j$，再对 $R$ 取模；写成 `%C` 在 $R\ne C$ 时全错。
- 输出 `Escaped in x minute(s).` 的括号和句点是题面原文的一部分，不能省。
- `while(cin>>L>>R>>C)` 兼容"只有一组"和"多组 + `0 0 0` 结尾"两种数据形态。
