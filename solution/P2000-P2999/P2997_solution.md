# P2997 [USACO10NOV] Banner S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 平面上有 $(W+1)\times(H+1)$ 个整点（$0\le x\le W,\ 0\le y\le H$，$W,H\le 1000$）。要数出满足两个条件的**无序点对** $\{P,Q\}$ 的个数：

1. 欧氏距离 $|PQ|\in[L_1,L_2]$（$1\le L_1\le L_2\le 1500$，闭区间）；
2. 线段 $PQ$ 的**内部**（不含两端点）没有别的整点。

答案可能超 32 位，要开 `long long`。

**口径说明。** 题面说"电线下方没有柱子"，结合样例：$(0,0)-(2,0)$ 因中点 $(1,0)$ 有柱子被排除，而**两端点本身就是柱子**却合法——所以条件精确地是"开区间内无整点"。长度范围按样例（$2.00$ 与 $2.24$ 都算进 $2..3$）取**闭区间**。$L_1,L_2$ 是整数，这一点后面会成为消除浮点误差的关键。

**第一步：暴力有多大？** 点数 $\approx 10^6$，点对数 $\approx 5\times10^{11}$，枚举点对绝对不行。但点对虽多，**位移向量**却很少：$\Delta=(dx,dy)$ 满足 $|dx|\le W\le 1000,|dy|\le H\le 1000$，只有 $\approx 4\times10^6$ 种（利用对称还能砍到 $10^6$）。而条件 1、2 都**只依赖位移**，不依赖具体位置！这提示按位移分类计数：

$$\text{答案}=\sum_{\Delta\ \text{合法}}(\text{该位移能平移出的点对数}).$$

**第二步：条件 2 的数论刻画。** 线段 $(0,0)\to(dx,dy)$ 内部的整点个数是 $\gcd(|dx|,|dy|)-1$。这是经典结论：线段上的整点恰为 $\bigl(k\cdot\frac{dx}{g},k\cdot\frac{dy}{g}\bigr)$，$k=0,1,\dots,g$，其中 $g=\gcd$。所以"内部无整点" $\iff\gcd(|dx|,|dy|)=1$（互素）。特别地，水平位移 $(dx,0)$ 的 $\gcd=|dx|$，只有 $dx=1$ 合法；竖直同理。

**第三步：长度条件用整数判。** $|PQ|=\sqrt{dx^2+dy^2}$，条件 $L_1\le\sqrt{dx^2+dy^2}\le L_2$ 两边平方（都非负，平方保序）：

$$L_1^2\le dx^2+dy^2\le L_2^2.$$

全是整数运算，**零浮点误差**。若用 `sqrt` 再比较，$\sqrt{5}\approx2.2360679\dots$ 这类无理数没事，但完全平方数边界（如 $dx^2+dy^2=L_1^2$）可能因舍入被误判——整数平方比较把这个坑彻底填掉。

**第四步：每个位移贡献多少点对？** 固定 $dx\ge0,dy\ge0$（先只枚举第一象限方向）：

- $dx>0,dy>0$：斜率有正负两种。正斜率点对 $\{(x,y),(x+dx,y+dy)\}$，左下角 $(x,y)$ 可取 $0\le x\le W-dx,\ 0\le y\le H-dy$，共 $(W+1-dx)(H+1-dy)$ 个；负斜率点对 $\{(x,y+dy),(x+dx,y)\}$ 同样多。两类不重叠（斜率符号不同），贡献 $2(W+1-dx)(H+1-dy)$。
- $dx=0,dy=1$（竖直单位段）：只有"竖直"一种朝向，贡献 $(W+1)\cdot H$。
- $dx=1,dy=0$（水平单位段）：贡献 $W\cdot(H+1)$。
- $dx=dy=0$：不是点对，排除。

为什么水平/竖直不乘 $2$？因为 $(dx,0)$ 与 $(-dx,0)$ 给出**同一个无序点对集合**（无序对没有方向），正负斜率则给出不同集合。统一写法：枚举 $dx\in[0,W]$，$dy\in[0,H]$（$dx=0$ 时 $dy$ 从 $1$ 起），仅当 $dx>0$ 且 $dy>0$ 时乘 $2$。

**第五步：范围与溢出。** 单位贡献 $\le 2\times1001\times1001\approx2\times10^6$，位移数 $\le10^6$，粗上界 $2\times10^{12}$；更紧地，答案不超过总点对数 $\binom{1002^2}{2}\approx5\times10^{11}$。都远超 `int`（题面也明说了），`long long` 绰绰有余。中间量 $dx^2+dy^2\le2\times10^6$、$L_2^2\le2.25\times10^6$ 用 `int` 就够，但我统一提为 `i64` 防手滑。

**复杂度**：$O(W\cdot H\cdot\log)$（每对位移一次 gcd），$\approx10^6$ 次，轻松通过。

**手造数据核对。**

第一组，题面样例 $W=2,H=1,L_1=2,L_2=3$：枚举 $dx\in[0,2],dy\in[0,1]$：

| $(dx,dy)$ | $dx^2+dy^2$ | 在 $[4,9]$？ | $\gcd$ | 贡献 |
|---|---|---|---|---|
| $(0,1)$ | $1$ | 否 | — | $0$ |
| $(1,0)$ | $1$ | 否 | — | $0$ |
| $(1,1)$ | $2$ | 否 | — | $0$ |
| $(2,0)$ | $4$ | 是 | $2\ne1$ | $0$ |
| $(2,1)$ | $5$ | 是 | $1$ ✓ | $2\times(3-2)\times(2-1)=2$ |

答案 $2$，与题面"只有两对合适"一致（正是 $(0,0)-(2,1)$ 与 $(0,1)-(2,0)$）。

第二组，$W=1,H=1,L_1=1,L_2=2$：单位正方形 $4$ 点，全部 $\binom42=6$ 对：$4$ 条边长 $1$（内部无整点），$2$ 条对角线长 $\sqrt2\approx1.414$（$\gcd(1,1)=1$，内部无整点），全合法，答案 $6$。公式：$(0,1)$ 贡献 $2\times1=2$，$(1,0)$ 贡献 $1\times2=2$，$(1,1)$ 长度平方 $2\in[1,4]$ 贡献 $2\times1\times1=2$，合计 $6$ ✓。

第三组，$W=2,H=0,L_1=1,L_2=2$：一行 $3$ 个点。合法点对只有相邻两对（长 $1$）；$(0,0)-(2,0)$ 长 $2$ 但中点有柱。公式：只有 $(1,0)$ 通过（$\gcd=1$，长 $1$），贡献 $W\cdot(H+1)=2\times1=2$ ✓。

## 二、思维链：完整证明

**记号。** 格点集 $G=\{(x,y)\in\mathbb Z^2:0\le x\le W,0\le y\le H\}$。无序点对 $\{P,Q\}$（$P\ne Q$）合法当且仅当 $L_1\le|PQ|\le L_2$ 且开线段 $(P,Q)$ 内无 $G$ 中的点。位移 $\Delta(P,Q)=(|x_P-x_Q|,|y_P-y_Q|)=(dx,dy)$（取绝对值，$dx,dy\ge0$，不同时为 $0$）。

---

### 引理 1（线段内整点数 = gcd − 1）

设 $dx,dy\ge0$ 不全为 $0$，$g=\gcd(dx,dy)$（约定 $\gcd(a,0)=a$）。则线段 $(0,0)\to(dx,dy)$ 上的整点恰为
$$\Bigl(k\cdot\frac{dx}{g},\ k\cdot\frac{dy}{g}\Bigr),\quad k=0,1,\dots,g,$$
共 $g+1$ 个，内部（去掉两端）$g-1$ 个。

*证明*：记 $a=dx/g,\ b=dy/g$，则 $\gcd(a,b)=1$（$g$ 是最大公约数；若 $dy=0$ 则 $a=1,b=0$，$\gcd(1,0)=1$ 仍成立）。

**这些点都是整点且在线段上**：$k(a,b)$ 坐标为整数，且 $k/g\in[0,1]$ 使其位于线段参数式 $t\cdot(dx,dy)$ 上（$t=k/g$）。

**没有别的整点**：设整点 $(x,y)$ 在线段上，则 $(x,y)=t(dx,dy)$，$t\in[0,1]$。由 $x\cdot dy=y\cdot dx$ 得 $xb=ya$。若 $a=0$（即 $dx=0$），则 $b=1$，$xb=ya$ 给出 $x=0$，$y=t\cdot dy\in[0,dy]$ 为整数，正是 $k(0,1)$，$k=y$。若 $a>0$：$a\mid xb$ 且 $\gcd(a,b)=1$，由欧几里得引理 $a\mid x$，设 $x=ka$，代入得 $y=kb$；$t=k/g\in[0,1]$ 给出 $0\le k\le g$。故整点必在所列集合中。

两端对应 $k=0,g$，内部 $g-1$ 个。证毕。

**推论**：条件 2 $\iff\gcd(dx,dy)=1$。注意内部整点若存在必在线段上、坐标介于两端之间，故自动落在矩形 $G$ 内——"内部无 $G$ 中整点"与"内部无整点"等价，无需额外检查越界。

---

### 引理 2（长度条件的整数化）

$L_1\le\sqrt{dx^2+dy^2}\le L_2\iff L_1^2\le dx^2+dy^2\le L_2^2$。

*证明*：$t\mapsto t^2$ 在 $[0,\infty)$ 上严格递增，故对非负数 $u,v$：$u\le v\iff u^2\le v^2$。取 $u=L_1,v=\sqrt{dx^2+dy^2}$ 与 $u=\sqrt{dx^2+dy^2},v=L_2$ 分别应用即得。所有量均为整数（$L_1,L_2$ 题面给定为整数），比较精确无舍入。证毕。

---

### 引理 3（按位移分类的计数公式）

固定 $(dx,dy)$，$dx,dy\ge0$ 不全为 $0$。位移绝对值恰为 $(dx,dy)$ 的无序点对个数为
$$c(dx,dy)=\begin{cases}2(W+1-dx)(H+1-dy),&dx>0,\ dy>0\\(W+1)(H+1-dy),&dx=0\\(W+1-dx)(H+1),&dy=0\end{cases}$$
（当 $dx\le W,dy\le H$ 时；否则为 $0$）。

*证明*：分三类，每类建立**双射**。

**类 A：$dx>0,dy>0$。** 点对分两个子型：正斜率型 $\{(x,y),(x+dx,y+dy)\}$ 与负斜率型 $\{(x,y+dy),(x+dx,y)\}$。两子型不交：前者两点 $y$ 差与 $x$ 差同号，后者异号（$dx,dy>0$）。正斜率型由左下端点 $(x,y)$ 唯一确定，两端都在 $G$ 内 $\iff 0\le x\le W-dx$ 且 $0\le y\le H-dy$（右上端点坐标更大，只需它不越界；左下端点 $\ge0$ 自动），共 $(W+1-dx)(H+1-dy)$ 个，且不同 $(x,y)$ 给出不同点对（左下端点可从点对恢复：取 $x$ 较小者）。负斜率型由左上端点 $(x,y+dy)$ 唯一确定，同理 $(W+1-dx)(H+1-dy)$ 个。合计 $2(W+1-dx)(H+1-dy)$。

**类 B：$dx=0,dy>0$。** 点对必为 $\{(x,y),(x,y+dy)\}$，由下端点唯一确定，$0\le x\le W,\ 0\le y\le H-dy$，共 $(W+1)(H+1-dy)$。**不乘 $2$**：无序对 $\{(x,y),(x,y+dy)\}$ 与"方向翻转"是同一个集合，没有第二个子型。

**类 C：$dy=0,dx>0$。** 对称地 $(W+1-dx)(H+1)$。

三类按 $(dx,dy)$ 的零/非零模式划分，穷尽且不重。证毕。

---

### 引理 4（合法性只依赖位移）

点对 $\{P,Q\}$ 合法 $\iff$ 其位移 $(dx,dy)$ 满足 $\gcd(dx,dy)=1$ 且 $L_1^2\le dx^2+dy^2\le L_2^2$。

*证明*：长度只依赖位移（平移不变）✓。内部整点：把 $P$ 平移到原点后，由引理 1，内部整点存在性只依赖 $(dx,dy)$；且推论已说明内部整点自动在 $G$ 内，故"内部无柱"也只依赖位移。两条件合取即得。证毕。

---

### 引理 5（答案公式与不重不漏）

$$\text{答案}=\sum_{\substack{0\le dx\le W,\ 0\le dy\le H\\(dx,dy)\ne(0,0)\\ \gcd(dx,dy)=1,\ L_1^2\le dx^2+dy^2\le L_2^2}}c(dx,dy).$$

*证明*：每个无序点对有唯一的绝对位移 $(dx,dy)$（引理 3 的分类），故按位移分类是对全体点对的一个**划分**；由引理 4，同一类内点对要么全合法要么全不合法；合法类的点对数由引理 3 给出。对划分求和即得，不重不漏。证毕。

---

### 引理 6（范围：必须 64 位）

答案 $\le\binom{(W+1)(H+1)}{2}\le\binom{1002001}{2}\approx5.02\times10^{11}$，且可达 $\Theta(10^{11})$ 量级，超出 `int` 上限 $2.147\times10^9$；`long long` 上限 $9.22\times10^{18}$ 足够。

*证明*：答案是全体点对的子集，上界即总点对数。下界构造：取 $L_1=1,L_2=1500,W=H=1000$，则所有互素位移都合法；仅 $dx,dy\in[1,1000]$ 中互素对约占 $6/\pi^2\approx60.8\%$，每个贡献 $2(W+1-dx)(H+1-dy)$，求和量级为 $2\times0.608\times\bigl(\sum_{d=1}^{1000}(1001-d)\bigr)^2/10^6\approx 2\times0.608\times(5\times10^5)^2/10^6\approx3\times10^{11}$，远超 32 位。中间量：$dx^2+dy^2\le2\times10^6$、$L_2^2\le2.25\times10^6$、单类贡献 $\le2\times10^6$，`int` 可容，但累加器必须 `i64`。证毕。

---

### 引理 7（复杂度）

时间 $O(WH\log\min(W,H))$，空间 $O(1)$。

*证明*：双重循环至多 $(W+1)(H+1)\le1.002\times10^6$ 次；每次先做 $O(1)$ 的平方与区间判断，通过者再做一次欧几里得 gcd，$O(\log\min(dx,dy))\le O(\log 1000)\approx10$ 步。故总时间 $O(WH\log)$，实际约 $10^6\sim10^7$ 次基本运算。只用常数个变量，空间 $O(1)$。证毕。

---

### 定理

程序输出合法点对数，精确无浮点误差，时间 $O(WH\log)$。

*证明*：引理 1 把"内部无柱"翻译成 $\gcd=1$；引理 2 把长度区间翻译成整数平方区间；引理 4 说明合法性只依赖位移；引理 3、5 给出不重不漏的计数公式；引理 6 保证 `i64` 不溢出；引理 7 给出复杂度。代码逐条实现该公式。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 两个条件（长度区间、内部无整点）都**只依赖位移向量**，与点对绝对位置无关。
2. **consider easier version** — 点对 $\approx5\times10^{11}$ 不可枚举，但位移只有 $\approx10^6$ 种 ⇒ 按位移分类，把"数点对"降维成"数位移 × 平移方案数"。
3. **classic problem solution** — 线段整点定理：$(0,0)\to(dx,dy)$ 内部整点数 $=\gcd(dx,dy)-1$ ⇒ 条件 2 即互素。
4. **reduce to easier problem** — 长度区间两边平方（$L_1,L_2$ 是整数）⇒ 纯整数判定，零浮点误差。
5. **discuss by category** — 位移分三类：双正（正负斜率 ×2）、纯竖直、纯水平（无序对无方向，不乘 2）；$(0,0)$ 排除。
6. **explore its property** — 答案量级 $10^{11}$ 超 `int`，累加器开 `long long`；中间平方量 $10^6$ 级安全。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `w,h` | 牧场宽高，格点为 $[0,W]\times[0,H]$ | `int` | 读入；点数是 $(W+1)(H+1)$ |
| `l1,l2` | 长度闭区间端点（整数） | `int` | 读入 |
| `lo,hi` | $L_1^2,L_2^2$ | `i64` | 平方后全程整数比较 |
| `dx,dy` | 枚举的绝对位移 | `int` | $dx\in[0,W]$；$dy$ 从 `(dx==0)` 起（排除 $(0,0)$） |
| `d2` | $dx^2+dy^2$ | `i64` | 每对位移现算 |
| `cnt` | 单朝向平移方案数 $(W+1-dx)(H+1-dy)$ | `i64` | 双正位移乘 $2$ |
| `ans` | 合法点对总数 | `i64`，初值 $0$ | 必须 64 位（引理 6） |
| `gcd(a,b)` | 欧几里得最大公约数，$\gcd(a,0)=a$ | `int(int,int)` | 递归一行式 |

### 算法步骤

1. I/O 加速三行；读 `w,h,l1,l2`；算 `lo=l1*l1,hi=l2*l2`（`i64`）。
2. 枚举 `dx=0..w`，`dy=(dx==0)..h`：
   - 算 `d2=dx*dx+dy*dy`；若 `d2<lo||d2>hi` 或 `gcd(dx,dy)!=1`，跳过；
   - `cnt=(w+1-dx)*(h+1-dy)`；`ans+=(dx>0&&dy>0?2:1)*cnt`。
3. 输出 `ans`。

### 复杂度

- 时间 $O(WH\log\min(W,H))\approx10^6$ 次循环 + gcd；空间 $O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例 $(W,H,L_1,L_2)=(2,1,2,3)$ 输出 $2$ 吻合；单位正方形全合法（$6$）、单行三点（$2$）等手造数据正确。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2997 [USACO10NOV] Banner S
// 按位移分类：内部无整点 ⟺ gcd(dx,dy)=1；长度用平方整数比较，零浮点
// dx>0 且 dy>0 时正负两种斜率各贡献 (W+1-dx)*(H+1-dy) 个平移位置
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int w,h,l1,l2;

int gcd(int a,int b){return b?gcd(b,a%b):a;}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>w>>h>>l1>>l2;
	i64 lo=(i64)l1*l1,hi=(i64)l2*l2,ans=0;
	for(int dx=0;dx<=w;++dx)
		for(int dy=(dx==0);dy<=h;++dy)	// dx=0 时 dy 从 1 起，排除 (0,0)
		{
			i64 d2=(i64)dx*dx+(i64)dy*dy;
			if(d2<lo||d2>hi||gcd(dx,dy)!=1)
				continue;
			i64 cnt=(i64)(w+1-dx)*(h+1-dy);
			ans+=(dx>0&&dy>0?2:1)*cnt;	// 水平/竖直无序对无方向，不乘 2
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **先判长度再判 gcd**：平方比较是 $O(1)$，先把大多数位移筛掉，gcd 只对少数幸存者调用。
- `dy=(dx==0)` 是紧凑写法：`dx==0` 为真时从 $1$ 起（跳过 $(0,0)$ 且避免 $\gcd(0,0)=0$ 的歧义），否则从 $0$ 起。
- `gcd(0,dy)=dy`：递归式 `b?gcd(b,a%b):a` 在 `a=0` 时返回 `b`，恰好实现 $\gcd(0,k)=k$，竖直位移只有 $dy=1$ 通过。
- 乘 $2$ 的条件是 `dx>0&&dy>0`：正负斜率是两类不同的无序点对；水平/竖直翻转方向后是同一集合。
- 累加器与平方量全部 `i64`：答案可达 $\approx5\times10^{11}$（引理 6），`int` 必炸。
- 全程无 `sqrt`/`double`：$L_1,L_2$ 是整数，平方比较精确（引理 2），边界 $d2=L_1^2$ 或 $L_2^2$ 不会因舍入误判。
