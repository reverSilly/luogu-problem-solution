# P2782 友好城市 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一条河有平行的南北两岸，南岸有 $N$ 个城市、北岸有 $N$ 个城市，**每岸内部坐标互不相同**，且南岸城市与北岸城市一一配对（友好城市是双射）。每对城市申请一条直线航道。要批准尽量多的申请，使得**任意两条被批准的航道都不相交**。$N\le 2\times 10^5$，坐标 $0\le x_i\le 10^6$；$50\%$ 的数据 $N\le 5000$。输入每行一对坐标：南岸、北岸。

**第一步：探性质——画个图，两条航道什么时候交叉？** 把两岸画成两条平行线。直觉上：如果南岸城市 $A$ 在 $B$ 左边，而它们的友好城市在北岸却是 $A'$ 在 $B'$ 右边，两条线段必然"拧"在一起。反过来，如果两岸的左右顺序一致，两条线段就像铁轨的枕木，永远平行不交。

拿最小例子验证：$(s,n)=(1,2),(2,1)$——南岸 $1<2$、北岸 $2>1$，顺序相反，画图确实交叉；$(1,1),(2,2)$——顺序相同，不交。再想三个城市的情形：只要**每一对**都顺序一致，整体就互不相交。于是：

> **批准集合合法 $\iff$ 按南岸坐标排序后，北岸坐标严格递增。**

"不相交"这个几何条件，被翻译成了纯序列条件。

**第二步：归约——这就是 LIS。** 把 $N$ 对坐标按南岸坐标从小到大排序，得到北岸坐标序列 $t_1,t_2,\dots,t_N$。合法批准集合 $\iff$ 这个序列的一个**严格上升子序列**（选出的城市对，南岸序已排好，北岸序必须同向）。要批准最多 $\iff$ 求**最长上升子序列（LIS）**。经典问题，标签里的"排序、DP、二分、树状数组"全部对上了。

**第三步：简化版——$N\le 5000$ 的 $O(N^2)$ DP。** 设 $f_i$ 为"以第 $i$ 对城市结尾的最长合法链"，则

$$f_i=1+\max\{\,f_j:\ j<i,\ t_j<t_i\,\}\quad(\text{无合法 }j\text{ 时 }f_i=1),$$

答案 $\max_i f_i$。$5000^2=2.5\times 10^7$，能过一半数据。但 $N=2\times 10^5$ 时 $N^2=4\times 10^{10}$，妥妥超时——DP 的瓶颈是"对每个 $i$ 扫一遍前面所有 $j$"。

**第四步：经典优化——LIS 的 $O(N\log N)$ 贪心 + 二分。** 回忆 LIS 的标准做法：维护数组 `tail`，`tail[j]` 存"长度为 $j+1$ 的上升子序列的**最小可能结尾值**"。关键性质：`tail` 严格递增（结尾越长的链，结尾值至少不会更小——后面严格证明）。于是对新元素 $x$：

- 在 `tail` 里二分找第一个 $\ge x$ 的位置 $p$（`lower_bound`）；
- `tail[p]=x`：要么把某个长度的最优结尾变得更小（$p<len$），要么把最长链延长一位（$p=len$）。

直觉动机：同样长度的链，结尾越小，后面越容易接上新元素——所以每个长度只留最小结尾，是"不丢最优解"的贪心。每次二分 $O(\log N)$，总 $O(N\log N)\approx 3.6\times 10^6$ 次比较，轻松通过。

**第五步：抠细节——严格还是非严格？** 题面保证**每岸坐标互不相同**，所以北岸序列里没有相等值，`lower_bound`（第一个 $\ge x$）与 `upper_bound`（第一个 $>x$）行为一致。但我仍写 `lower_bound`：它实现的是**严格**上升，与"航道不相交"的语义精确对齐——假如北岸坐标相等，意味着两条航道共享北岸端点（同一个城市），而友好关系是双射、每城市只有一条航道，这种情况根本不存在。用严格版是把题面条件"用满"，不依赖任何侥幸。

另外：排序按南岸坐标；南岸坐标也互不相同，排序结果唯一，不存在"相等南岸怎么排"的歧义。

**手造数据核对**（题面没有样例，我造六组，覆盖交叉、全平行、逆序、乱序输入、单点）：

| 输入（南岸 北岸） | 排序后北岸序列 | LIS | 输出 |
|---|---|---|---|
| $(1,3),(2,1),(3,4),(4,2)$ | $3,1,4,2$ | $1,4$ 或 $1,2$ 或 $3,4$ | $2$ |
| $(1,1),(2,2),(3,3)$ | $1,2,3$ | 全取 | $3$ |
| $(1,2),(2,1)$ | $2,1$ | 只能取一个 | $1$ |
| $(3,3),(1,1),(2,2)$（乱序输入） | $1,2,3$ | 全取 | $3$ |
| $(5,5)$ | $5$ | 单点 | $1$ |
| $(1,5),(2,4),(3,3),(4,2),(5,1)$ | $5,4,3,2,1$ | 全逆序 | $1$ |

六组与程序输出逐一一致。第一组专门验证"交叉对只能二选一"，第四组验证"必须先排序"（不排序直接对输入序做 LIS 会错），第六组验证全逆序时答案为 $1$ 而不是 $0$。

## 二、思维链：完整证明

**记号与建模。** 南岸城市坐标 $s_i$、北岸友好城市坐标 $t_i$，$i=1..N$。题面保证：$\{s_i\}$ 两两不同，$\{t_i\}$ 两两不同（每岸位置各不相同），且配对是双射。把两岸建模为平行直线 $y=0$（南）与 $y=1$（北）：任何两条平行河岸都可以经一个仿射变换映到这两条线，仿射变换保持共线性与线段相交关系，且保持每条岸上坐标的左右顺序，故**不失一般性**。第 $i$ 条航道是连接 $(s_i,0)$ 与 $(t_i,1)$ 的线段。"批准集合合法"指其中任意两条线段不相交（无公共点）。

---

### 引理 1（交叉判据：顺序相反 $\iff$ 相交）

设两条航道 $i,j$ 满足 $s_i<s_j$。则它们相交 $\iff t_i>t_j$。

*证明*：参数化。航道 $i$ 上的点为 $A(\tau)=(1-\tau)(s_i,0)+\tau(t_i,1)$，$\tau\in[0,1]$；航道 $j$ 同理得 $B(\tau)$。两条线段的纵坐标都随 $\tau$ 从 $0$ 线性增到 $1$，故若它们有公共点，公共点必在**同一高度** $\tau$ 处（纵坐标相等 $\Rightarrow$ 参数相等）。于是相交 $\iff$ 存在 $\tau\in[0,1]$ 使横坐标相等。

定义横坐标差 $d(\tau)=x_B(\tau)-x_A(\tau)=(1-\tau)(s_j-s_i)+\tau(t_j-t_i)$。这是 $\tau$ 的线性函数，且 $d(0)=s_j-s_i>0$。

**情形 A：$t_j>t_i$。** 则 $d(1)=t_j-t_i>0$。线性函数在两端点都为正，则整段为正：$d(\tau)=(1-\tau)d(0)+\tau d(1)>0$ 对一切 $\tau\in[0,1]$（正数的凸组合为正）。无零点，不相交 ✓。

**情形 B：$t_j<t_i$。** 则 $d(1)<0<d(0)$。由线性函数的介值性，唯一零点

$$\tau^\*=\frac{d(0)}{d(0)-d(1)}=\frac{s_j-s_i}{(s_j-s_i)+(t_i-t_j)}\in(0,1)$$

（分子分母皆正，且分子 < 分母）。在高度 $\tau^\*\in(0,1)$ 处两线段横坐标相等，即**严格内部相交** ✓。

**情形 C：$t_j=t_i$。** 被题面排除（北岸坐标互不相同）。即便考虑它，$d(1)=0$ 意味着交于北岸端点 $(t_i,1)$——但那要求两条航道共享同一个北岸城市，与双射矛盾，故合法输入中不会出现。

三情形穷尽，判据成立。证毕。

**注**：证明同时说明"相交"必是横穿（交点在两河之间），不存在端点重合或擦边的退化情形——这让"不相交"与"严格递增"的对应干净利落。

---

### 引理 2（合法集合 $\iff$ 双序同向链）

批准集合 $S\subseteq\{1..N\}$ 合法（任意两条不相交）$\iff$ 把 $S$ 中元素按南岸坐标升序排列后，北岸坐标**严格递增**。

*证明*：($\Rightarrow$) 设 $S$ 合法。任取 $S$ 中两个元素 $i,j$，$s_i<s_j$。由引理 1，不相交 $\Rightarrow$ 非 $(t_i>t_j)$；又 $t_i\ne t_j$（互不相同），故 $t_i<t_j$。即**每一对**都同向，按南岸排序后北岸严格递增。

($\Leftarrow$) 设排序后北岸严格递增。任取两条 $i,j$（$s_i<s_j$），有 $t_i<t_j$，由引理 1 情形 A 不相交。对任意对成立，故 $S$ 合法。证毕。

---

### 引理 3（归约：答案 = 排序后北岸序列的 LIS 长度）

把全部 $N$ 对按南岸坐标升序排序（南岸互不相同 $\Rightarrow$ 排序唯一），得北岸序列 $t_1,\dots,t_N$。则最大合法批准数 = 该序列的**最长严格上升子序列**长度。

*证明*：构造双向映射。给定合法集合 $S$，由引理 2，$S$ 中元素按南岸序（即排序后的下标序）排列时北岸严格递增——这恰好是序列 $t$ 的一个严格上升子序列，长度 $|S|$。反之，给定 $t$ 的一个严格上升子序列（下标 $i_1<\dots<i_k$），对应城市对集合按南岸序北岸递增，由引理 2 合法，大小 $k$。两个映射互逆，故合法集合与上升子序列**一一对应且保大小**，最大值相等。证毕。

---

### 引理 4（$O(N^2)$ DP 的正确性——$50\%$ 数据的解）

设 $f_i$ 为以位置 $i$ 结尾的最长严格上升子序列长度。则 $f_i=1+\max\{f_j:j<i,\ t_j<t_i\}$（集合空时 $f_i=1$），且 LIS 长度 $=\max_i f_i$。

*证明*：任何以 $i$ 结尾、长度 $\ge 2$ 的上升子序列，去掉末项 $t_i$ 后是以某个 $j<i$ 结尾、且 $t_j<t_i$ 的上升子序列；反之任何这样的 $j$ 结尾子序列都能接上 $t_i$。故"以 $i$ 结尾的最长长度" = $1+$"所有可行 $j$ 的最长长度的最大值"，即转移式。对 $i$ 归纳（$i$ 的转移只依赖 $j<i$，无后效性），$f_i$ 计算正确。任何上升子序列必有末项，故全局最长 $=\max_i f_i$。证毕。

**复杂度瓶颈**：每个 $i$ 扫全部 $j<i$，总 $\Theta(N^2)$。$N=5000$ 时 $2.5\times 10^7$ 可行；$N=2\times 10^5$ 时 $4\times 10^{10}$ 不可行。需要把"找 $\max\{f_j:t_j<t_i\}$"加速——这正是下面贪心结构做的事。

---

### 引理 5（`tail` 数组的不变量——$O(N\log N)$ 算法的地基）

算法：`len=0`；对每个 $x=t_i$，$p=\texttt{lower\_bound}(tail,tail+len,x)-tail$（第一个 $\ge x$ 的下标，不存在则 $p=len$）；置 `tail[p]=x`；若 $p=len$ 则 `++len`。

则处理完前 $i$ 个元素后，对一切 $1\le j\le len$：

**(I)** `tail[j-1]` $=$ 前缀中所有长度为 $j$ 的严格上升子序列的**结尾值的最小值**（这样的子序列存在）；

**(II)** `tail[0]<tail[1]<...<tail[len-1]`（严格递增）；

**(III)** `len` $=$ 前缀的 LIS 长度。

*证明*：对 $i$ 归纳。$i=0$：`len=0`，三条空成立 ✓。

设处理前 $i-1$ 个后 (I)(II)(III) 成立，记旧数组为 `tail`、旧长度 `len`。来了 $x=t_i$，$p$ 为第一个 $\ge x$ 的位置。

**第一步：以 $x$ 结尾的最长上升子序列长度恰为 $p+1$。**

*上界*：设存在以 $x$ 结尾、长度 $L$ 的上升子序列。若 $L\ge 2$，其倒数第二项是前缀中某长度 $L-1$ 上升子序列的结尾，值 $<x$。由 (I)，`tail[L-2]` $\le$ 该值 $<x$，故 `tail[L-2]`$<x$，由 $p$ 的定义（第一个 $\ge x$）得 $L-2<p$，即 $L\le p+1$。$L=1$ 时显然 $1\le p+1$。

*可达*：若 $p\ge 1$，由 (I) 存在前缀中长度 $p$ 的上升子序列以 `tail[p-1]` 结尾，且 `tail[p-1]`$<x$（$p$ 是第一个 $\ge x$），接上 $x$ 得长度 $p+1$ ✓。若 $p=0$，单元素子序列 $(x)$ 长度 $1=p+1$ ✓。

**第二步：$x$ 只可能改变长度 $p+1$ 的最小结尾，其余长度的最小结尾不变。**

对长度 $j\le p$（即 $j-1<p$）：由 $p$ 的定义，`tail[j-1]`$<x$。含 $x$ 的长度 $j$ 上升子序列只能以 $x$ 为结尾（$x$ 是最新元素），其结尾值为 $x$；要改进长度 $j$ 的最小结尾需要 $x<$ `tail[j-1]`，与 `tail[j-1]`$<x$ 矛盾，故不可能改进 ✓。

对长度 $j>p+1$：以 $x$ 结尾的长度 $j$ 子序列需要前缀中存在长度 $j-1>p$ 的上升子序列结尾 $<x$。但由 (II)，`tail[j-2]` $\ge$ `tail[p]` $\ge x$（$j-2\ge p$），而由 (I) 一切长度 $j-1$ 子序列的结尾 $\ge$ `tail[j-2]` $\ge x$，没有 $<x$ 的，故这种子序列不存在，长度 $j$ 的最小结尾不受 $x$ 影响 ✓。

对长度 $p+1$：由第一步，存在以 $x$ 结尾的长度 $p+1$ 子序列；旧最小结尾 `tail[p]` $\ge x$（$p<len$ 时由 $p$ 的定义；$p=len$ 时旧最小结尾不存在）。故新最小结尾 $=\min(\text{旧},x)=x$，代码 `tail[p]=x` 恰好维护 (I) ✓。

**第三步：(II) 保持。** 只需检查新 `tail[p]=x` 与邻居的关系：左邻 `tail[p-1]`$<x$（$p$ 的定义，$p\ge 1$ 时）；右邻 `tail[p+1]`（若存在）：旧数组严格递增且 `tail[p]`$<\,$`tail[p+1]`，而 $x\le$ `tail[p]`，故 $x<$ `tail[p+1]` ✓。其余位置未动。

**第四步：(III) 保持。** 新前缀的 LIS 要么不含 $x$（长度 = 旧 `len`），要么以 $x$ 结尾（长度 $\le p+1$，第一步）。若 $p<len$：$p+1\le len$，最长不变，`len` 不动 ✓。若 $p=len$：第一步给出长度 $len+1$ 的上升子序列，且不含 $x$ 的最长仍为 $len$，故新 LIS $=len+1$，代码 `++len` ✓。

归纳完成。证毕。

**推论**：处理完全部 $N$ 个元素后 `len` 就是 LIS 长度，即答案。`tail` 里存的**不是**某个具体的 LIS（反例：序列 $3,1,2$，最终 `tail`$=[1,2]$，但 LIS 可以是 $1,2$；序列 $2,5,3,4$ 的 `tail` 演化会覆盖掉实际链的元素），只有长度可信——本题恰好只要长度。

---

### 引理 6（`lower_bound` 与严格性、二分合法性）

(a) 在严格递增数组上 `lower_bound` 返回第一个 $\ge x$ 的位置，等价于"严格上升 LIS"的接入位置；(b) 每次二分合法的前提 (II) 由引理 5 全程维护。

*证明*：(a) 严格上升子序列接上 $x$ 要求前一项 $<x$。由 (I)(II)，长度 $j$ 的链能接 $x$ $\iff$ `tail[j-1]`$<x$ $\iff j-1<p$ $\iff j\le p$。故 $x$ 能续到的最长链长 $p$，接上后长 $p+1$，替换位置 $p$——与引理 5 第一步一致。若用 `upper_bound`（第一个 $>x$），得到的是**非严格**上升（允许相等）的版本；本题北岸坐标互不相同，两者结果相同，但 `lower_bound` 与"不相交 $\iff$ 严格递增"（引理 1、2）语义精确对齐，不依赖"坐标互异"之外的任何假设。(b) 引理 5 第三步已证 (II) 是归纳不变量，故每次 `lower_bound` 作用在严格递增数组上，二分正确。证毕。

---

### 引理 7（复杂度）

时间 $O(N\log N)$，空间 $O(N)$。

*证明*：排序 $O(N\log N)$。主循环 $N$ 次，每次一个 `lower_bound`（区间长 $\le len\le N$，$O(\log N)$）加常数次赋值，$O(N\log N)$。合计 $O(N\log N)$。代入 $N=2\times 10^5$：约 $2\times 2\times 10^5\times 18\approx 7\times 10^6$ 次基本操作，远低于时限。空间：`a` 数组 $N$ 个二元组、`tail` 数组 $N$ 个 `int`，$O(N)$（约 $2.4$ MB）。对比 $O(N^2)$ DP 的 $4\times 10^{10}$，加速约 $10^4$ 倍。证毕。

---

### 定理

程序输出最大可批准申请数，总复杂度 $O(N\log N)$。

*证明*：引理 1 把几何相交判据化为坐标顺序；引理 2 把"任意两条不相交"化为"双序同向链"；引理 3 把最大合法集合归约为排序后北岸序列的严格 LIS；引理 5、6 保证 `tail`+`lower_bound` 算法正确维护最小结尾不变量并输出 LIS 长度；引理 7 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 画平行两岸图：两条直线航道相交 $\iff$ 两岸端点顺序相反（线性插值 $d(\tau)$ 的零点判据）。
- reduce to easier problem — 合法批准集合 $\iff$ 按南岸排序后北岸严格递增 $\iff$ 严格上升子序列；几何题塌缩成 LIS。
- consider easier version — $N\le 5000$：$O(N^2)$ DP $f_i=1+\max\{f_j:t_j<t_i\}$，先拿一半分并看清瓶颈。
- classic problem solution — LIS 的 $O(N\log N)$ 贪心 + 二分：`tail[j]` = 长度 $j+1$ 链的最小结尾，严格递增，`lower_bound` 定位替换。
- explore its property — 坐标互异 $\Rightarrow$ 严格版（`lower_bound`）与非严格版等价，但严格版与"不相交"语义精确对齐；`tail` 内容不是具体方案，只有长度可信。

| `tail[j]` | 长度 $j+1$ 的严格上升子序列的**最小结尾值**（北岸坐标） | `int[mxn]` | 只在 $[0,len)$ 有定义；严格递增 |
| `len` | 当前前缀的 LIS 长度 | `int`，全局默认 $0$ | 最终即答案 |
| `p` | `lower_bound(tail,tail+len,x)` 的位置 | `int`，每轮现算 | 第一个 $\ge x$；`p==len` 时延长最长链 |

### 算法步骤

1. I/O 加速三行；读 $N$ 与 $N$ 对 $(s,t)$。
2. 按 $s$ 升序排序（$s$ 互不相同，排序唯一）。
3. 依次取排序后的 $t$：`p=lower_bound(tail,tail+len,t)-tail`；`tail[p]=t`；若 `p==len` 则 `++len`。
4. 输出 `len`。

### 复杂度

- 时间：$O(N\log N)$，$N=2\times 10^5$ 时约 $7\times 10^6$ 次基本操作。
- 空间：$O(N)$，约 $2.4$ MB。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过、无警告；题面无样例，自造六组手算数据（交叉对二选一、全平行、单交叉、乱序输入、单点、全逆序）输出 $2,3,1,3,1,1$ 全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2782 友好城市
// 两条航道相交 ⇔ 两岸坐标顺序相反 ⇒ 按南岸排序后，答案就是北岸坐标的严格 LIS。
// N=2e5 ⇒ O(N log N) 贪心 + 二分（tails 数组）。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{200005};

int n,len,tail[mxn];
struct{int s,t;}a[mxn];	// s=南岸坐标，t=北岸坐标

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i].s>>a[i].t;
	sort(a,a+n,[](auto x,auto y){return x.s<y.s;});
	for(int i=0;i<n;++i)
	{
		int p=lower_bound(tail,tail+len,a[i].t)-tail;	// 严格递增 ⇒ lower_bound
		tail[p]=a[i].t;
		if(p==len)
			++len;
	}
	cout<<len<<'\n';
	return 0;
}
```

### 代码说明

- **排序键是南岸 `s`**，LIS 跑在北岸 `t` 上。两者搞反虽然答案相同（对称性），但"排序 + LIS"的对应关系要清楚：排序消掉一维，LIS 处理另一维。
- `tail` 全局默认 $0$，但只有 `[0,len)` 被读写，`len=0` 起步，未初始化区域永远不参与二分——这里不需要填 INF（`tail` 不是"不可达"语义，而是"前缀最优结尾"语义）。
- `p==len` 时 `tail[len]=x` 写入后才 `++len`，顺序不能反（反了会把 `x` 写到 `tail[len+1]`）。
- `lower_bound` 作用于严格递增的 `tail[0..len)`（引理 5(II) 保证），返回第一个 $\ge x$ 的位置；坐标互异时不会出现相等替换的歧义。
- 答案只输出长度 `len`。若题目要求输出具体批准方案，`tail` 数组本身不够（它可能覆盖掉真实链上的元素），需要额外记录每个元素接入时的长度与前驱——本题不需要。
