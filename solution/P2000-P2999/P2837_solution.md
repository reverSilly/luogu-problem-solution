# P2837 [USACO08FEB] Dining Cows B — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 头奶牛排成一队（$1\le N\le3\times10^4$），第 $i$ 头的卡片写着 $D_i\in\{1,2\}$。奶牛**不动**，FJ 沿队伍走一遍，把若干卡片上的编号改掉（$1\leftrightarrow2$），要求最终队伍形如"前面全是 $1$、后面全是 $2$"——即 $11\dots122\dots2$；允许只有一组（全 $1$ 或全 $2$）。问**最少改几张卡片**。

**第一步：先刻画"合法终态"长什么样。** 题目说"每个组中的奶牛都站在一起"，且第 $1$ 批在前、第 $2$ 批在后。因为编号只有 $1,2$ 两种，合法终态必然是：存在一个分界 $k$（$0\le k\le N$），前 $k$ 个位置全是 $1$，后 $N-k$ 个位置全是 $2$。$k=0$ 就是全 $2$，$k=N$ 就是全 $1$——题面明确允许"只有一组"，所以这两个极端也合法。于是**合法终态恰好 $N+1$ 种**，由 $k$ 唯一参数化。这一步把"改成想要的样子"这个模糊目标变成了一个有限的、可枚举的集合。

**第二步：固定终态后，最少修改数是什么？** 奶牛不动、只能改卡片，所以从初始序列 $D$ 变成某个固定终态 $T$，最少修改次数就是**逐位不同的位置数**（Hamming 距离）：每个不同的位置必须改至少一次，而每个不同的位置改一次就够（$1\to2$ 或 $2\to1$ 都是一次）。相同的位置不用动。所以对分界 $k$：

$$\mathrm{cost}(k)=\underbrace{\#\{i<k:\ D_i=2\}}_{\text{前缀里该是 1 却是 2}}+\underbrace{\#\{i\ge k:\ D_i=1\}}_{\text{后缀里该是 2 却是 1}.$$

答案就是 $\min_{0\le k\le N}\mathrm{cost}(k)$。

**第三步：先试朴素实现，撞墙。** 最直接的做法：对每个 $k$ 扫一遍全序列数 mismatch，$O(N^2)=9\times10^8$。$N=3\times10^4$ 时这接近 $10^9$ 次操作，在通常 $1$ 秒时限下很悬。我需要一个 $O(N)$ 的办法。

**第四步：撞墙之后找结构——两个计数都是"前缀计数"。** 观察 $\mathrm{cost}(k)$ 的两项：

- 前缀 $[0,k)$ 里 $2$ 的个数 $=k-(\text{前缀里 }1\text{ 的个数})$；
- 后缀 $[k,N)$ 里 $1$ 的个数 $=(\text{全序列 }1\text{ 的个数})-(\text{前缀里 }1\text{ 的个数})$。

两项都只依赖同一个量：**前 $k$ 个位置里 $1$ 的个数**。令 $c_1[k]=\#\{i<k:D_i=1\}$（$c_1[0]=0$），则

$$\mathrm{cost}(k)=(k-c_1[k])+(c_1[N]-c_1[k])=c_1[N]+k-2c_1[k].$$

而 $c_1$ 是经典**前缀和**：$c_1[k+1]=c_1[k]+[D_k=1]$，一遍 $O(N)$ 递推。之后每个 $k$ 的 cost 是 $O(1)$ 公式，枚举 $N+1$ 个 $k$ 共 $O(N)$。总复杂度 $O(N)$，墙拆掉了。

**第五步：有没有别的经典视角？（交叉验证）** 这题标签里有"DP、递推"。确实也可以两状态 DP：$f[i][0]$ = 前 $i$ 头已合法且第 $i$ 头终态为 $1$ 的最小修改数，$f[i][1]$ 类似（终态为 $2$）。转移 $f[i][0]=f[i-1][0]+[D_i\ne1]$（$1$ 段只能接在 $1$ 段后），$f[i][1]=\min(f[i-1][0],f[i-1][1])+[D_i\ne2]$（$2$ 段可接在 $1$ 段或 $2$ 段后）。答案 $\min(f[N][0],f[N][1])$。它和枚举分界本质相同（$f[i][1]$ 里的 $\min$ 就是在选分界），但前缀和写法更短、更不容易错，我选前缀和。两种视角互相印证：答案一定形如"某个分界 + 两侧 mismatch"。

**第六步：手造数据核对**（题面无样例）：

| 输入 $D$ | 最优分界 | 输出 |
|---|---|---|
| `2 1 2 1`（$N=4$） | $k=0$（全 $2$，改第 $2,4$ 张）或 $k=2$（$1122$，改第 $1,4$ 张）等 | `2` |
| `1 1 2 2` | $k=2$，已合法 | `0` |
| `2`（$N=1$） | $k=0$，全 $2$ | `0` |

第一组手算：$c_1=[0,0,1,1,2]$，$\mathrm{cost}(k)=2+k-2c_1[k]$ 依次为 $2,3,2,3,2$，最小 $2$ ✓。第三组说明"单组合法"必须覆盖（$k=0$ 或 $N$），否则 $N=1$ 的 `2` 会被误判成必须改。

## 二、思维链：完整证明

**记号。** 初始序列 $D_0,\dots,D_{N-1}\in\{1,2\}$（0-based）。一次操作 = 选一个位置把编号 $1\leftrightarrow2$ 翻转。终态合法 $\iff$ 存在 $k\in[0,N]$ 使前 $k$ 位全 $1$、后 $N-k$ 位全 $2$。记该终态为 $T^{(k)}$。$c_1[k]=\#\{i<k:D_i=1\}$，$c_1[0]=0$。

---

### 引理 1（合法终态恰为 $\{T^{(k)}:0\le k\le N\}$，共 $N+1$ 个且互异）

*证明*：

**合法性**：题面要求"第 $1$ 批在前、第 $2$ 批在后、每组站在一起、允许只有一组"。$T^{(k)}$ 前 $k$ 位全 $1$、后 $N-k$ 位全 $2$，显然满足（$k=0$ 全 $2$、$k=N$ 全 $1$ 即"只有一组"）。故每个 $T^{(k)}$ 合法。

**完备性**：设 $T$ 是任一合法终态。若 $T$ 全 $1$，则 $T=T^{(N)}$；若全 $2$，则 $T=T^{(0)}$。否则 $T$ 同时含 $1$ 和 $2$，且所有 $1$ 在所有 $2$ 之前（两组各自连续、$1$ 组在前）。设 $1$ 的个数为 $k$（$1\le k\le N-1$），则前 $k$ 位必全为 $1$（否则某个 $2$ 出现在某个 $1$ 之前，违反"$1$ 组在前且连续"），后 $N-k$ 位全 $2$，即 $T=T^{(k)}$。

**互异性**：$k\ne k'$ 时 $T^{(k)}$ 与 $T^{(k')}$ 的 $1$ 的个数不同（分别为 $k,k'$），故不同。共 $N+1$ 个。证毕。

---

### 引理 2（到固定终态的最少操作数 = Hamming 距离）

设 $T$ 为任一固定终态。把 $D$ 变成 $T$ 的最少操作次数为 $\mathrm{dist}(D,T)=\#\{i:D_i\ne T_i\}$。

*证明*：

**下界**：每次操作只改变一个位置的编号。若位置 $i$ 满足 $D_i\ne T_i$，则它至少被操作一次（否则终态该位仍是 $D_i\ne T_i$）。不同位置的操作互不替代，故总次数 $\ge\mathrm{dist}(D,T)$。

**上界（可达）**：对每个 $D_i\ne T_i$ 的位置恰好操作一次（因编号只有 $1,2$，一次翻转即把 $D_i$ 变成 $T_i$），其余位置不动。共 $\mathrm{dist}(D,T)$ 次操作后逐位等于 $T$。

上下界相等，故最少次数 $=\mathrm{dist}(D,T)$。证毕。

---

### 引理 3（$\mathrm{cost}(k)$ 的前缀和公式）

对 $0\le k\le N$，
$$\mathrm{dist}(D,T^{(k)})=(k-c_1[k])+(c_1[N]-c_1[k])=c_1[N]+k-2c_1[k].$$

*证明*：按位置分两段。

**前缀 $i<k$**：$T^{(k)}_i=1$，mismatch 当且仅当 $D_i=2$。前缀共 $k$ 个位置，其中 $1$ 有 $c_1[k]$ 个，故 $2$ 有 $k-c_1[k]$ 个。这一段 mismatch 数 $=k-c_1[k]$。

**后缀 $i\ge k$**：$T^{(k)}_i=2$，mismatch 当且仅当 $D_i=1$。全序列 $1$ 共 $c_1[N]$ 个，前缀占了 $c_1[k]$ 个，故后缀 $1$ 有 $c_1[N]-c_1[k]$ 个。这一段 mismatch 数 $=c_1[N]-c_1[k]$。

两段不交且并为全体位置，相加即 $\mathrm{dist}(D,T^{(k)})=(k-c_1[k])+(c_1[N]-c_1[k])$。合并同类项 $=c_1[N]+k-2c_1[k]$。证毕。

---

### 引理 4（前缀和递推正确）

$c_1[0]=0$，$c_1[k+1]=c_1[k]+[D_k=1]$（$0\le k<N$）。则对所有 $0\le k\le N$，$c_1[k]=\#\{i<k:D_i=1\}$。

*证明*：对 $k$ 归纳。$k=0$：空集计数 $0=c_1[0]$ ✓。设 $c_1[k]$ 正确。集合 $\{i<k+1:D_i=1\}=\{i<k:D_i=1\}\cup\{k\ \text{若}\ D_k=1\}$，两部分不交，故计数 $=c_1[k]+[D_k=1]=c_1[k+1]$ ✓。证毕。

---

### 引理 5（答案 = $\min_k\mathrm{cost}(k)$，且算法取到它）

最少操作次数 $=\min_{0\le k\le N}\big(c_1[N]+k-2c_1[k]\big)$。算法枚举全部 $k$ 取最小，故输出正确。

*证明*：任何合法终态必为某个 $T^{(k)}$（引理 1），到它的最少操作数为 $\mathrm{dist}(D,T^{(k)})=\mathrm{cost}(k)$（引理 2、3）。要在所有合法终态里选最省的，即 $\min_k\mathrm{cost}(k)$。算法用引理 4 的 $c_1$ 对每个 $k\in[0,N]$ 算 $\mathrm{cost}(k)$ 并取 min，恰好遍历了全部 $N+1$ 个候选（含 $k=0,N$ 的单组情形），故输出 $=\min_k\mathrm{cost}(k)$。证毕。

---

### 引理 6（复杂度）

时间 $O(N)$，空间 $O(N)$。

*证明*：读入 $O(N)$；前缀和递推 $N$ 步 $O(N)$；枚举 $k=0..N$ 每步 $O(1)$ 公式，$O(N)$。合计 $O(N)\le3\times10^4$。空间：$D$ 与 $c_1$ 各 $O(N)$。证毕。

---

### 定理

算法输出把队伍改成"前 $1$ 后 $2$（允许单组）"的最少卡片修改数，时间 $O(N)$。

*证明*：引理 1 刻画全部合法终态；引理 2 把"到固定终态的最少修改"化为 Hamming 距离；引理 3、4 用前缀和 $O(1)$ 算每个分界的距离；引理 5 取 min 得全局最优；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 合法终态 = "前 $k$ 个 $1$ + 后 $N-k$ 个 $2$"，由分界 $k\in[0,N]$ 唯一参数化，共 $N+1$ 种（含全 $1$/全 $2$）。
2. **reduce to easier problem** — 奶牛不动、只改卡片 ⇒ 到固定终态的最少修改 = Hamming 距离 = 前缀 $2$ 数 + 后缀 $1$ 数。
3. **consider easier version** — 朴素每个 $k$ 扫全序列是 $O(N^2)\approx9\times10^8$，撞墙，需要 $O(N)$。
4. **classic problem solution** — 两项计数都只依赖"前缀 $1$ 的个数" $c_1[k]$；前缀和递推 + 公式 $\mathrm{cost}(k)=c_1[N]+k-2c_1[k]$，枚举 $k$ 取 min，$O(N)$。
5. **discuss by category** — 交叉验证：两状态 DP（$1$ 段/ $2$ 段）与枚举分界等价；单组情形 $k=0,N$ 必须纳入。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 奶牛数 $N$，$\le3\times10^4$ | `int` | 读入 |
| `d[i]` | 第 $i$ 头卡片编号（0-based），$\in\{1,2\}$ | `int[mxn]` | 读入；`mxn=30005` |
| `c1[k]` | 前 $k$ 头里编号 $1$ 的个数 | `int[mxn]` | `c1[0]=0`（全局默认）；`c1[i+1]=c1[i]+(d[i]==1)` |
| `k` | 分界：前 $k$ 头终态为 $1$，其余为 $2$ | `int` | 枚举 $0..n$ |
| `cost` | 该分界下的修改数 $=c_1[n]+k-2c_1[k]$ | `int` | 每 $k$ 现算 |
| `ans` | 最少修改数 | `int` | 初值 `n`（全改上界），逐 $k$ 取 min |

### 算法步骤

1. I/O 加速三行。
2. 读 `n`；读 `d[0..n-1]`。
3. 递推前缀和：`c1[i+1]=c1[i]+(d[i]==1)`，$i=0..n-1$（`c1[0]=0`）。
4. `ans=n`；对 `k=0..n`：`cost=(k-c1[k])+(c1[n]-c1[k])`，`ans=min(ans,cost)`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(N)\le3\times10^4$。
- 空间：$O(N)$（`d` 与 `c1`）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 `2 1 2 1`$\to2$、`1 1 2 2`$\to0$、单头 `2`$\to0$ 均与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2837 [USACO08FEB] Dining Cows B
// 合法终态 = 前 k 个 1 + 后 N-k 个 2；最少修改 = Hamming 距离。
// cost(k) = 前缀 2 数 + 后缀 1 数 = c1[N]+k-2*c1[k]，c1 为前缀 1 计数。
// 枚举 k=0..N 取 min，O(N)。k=0/N 覆盖"全 2 / 全 1"单组情形。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{30005};

int n,d[mxn],c1[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>d[i];
	for(int i=0;i<n;++i)
		c1[i+1]=c1[i]+(d[i]==1);	// c1[k]=前 k 头里 1 的个数，c1[0]=0
	int ans=n;						// 上界：全改成 1 至多改 n 张
	for(int k=0;k<=n;++k)			// 枚举分界：前 k 头为 1，其余为 2
	{
		int cost=(k-c1[k])+(c1[n]-c1[k]);	// 前缀里的 2 + 后缀里的 1
		ans=min(ans,cost);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `c1[k]` 是"前 $k$ 头里 $1$ 的个数"，`c1[0]=0` 依赖全局零初始化，恰好正确。
- `cost=(k-c1[k])+(c1[n]-c1[k])`：前缀 $k$ 个位置里 $2$ 的个数 + 后缀里 $1$ 的个数，正是到 $T^{(k)}$ 的 Hamming 距离（引理 3）。
- 枚举 `k=0..n` **含两端**：$k=0$ 全 $2$、$k=n$ 全 $1$，覆盖题面允许的"只有一组"。漏掉端点会在 $N=1$ 或全同序列上出错。
- `ans` 初值 `n` 是安全上界（把全部改成 $1$ 至多 $n$ 次），也可用哨兵；这里 `n` 更紧。
- 全程 `int` 足够：$\mathrm{cost}\le N\le3\times10^4$。
