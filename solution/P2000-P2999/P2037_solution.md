# P2037 [ECNA 1999] 电话号码 — 题解

## 一、解题过程：人类思考叙事

题意：一本电话簿，号码可能写成字母，也可能带连字符。要按"标准形式"（七位数字，前三位与后四位之间加一个连字符）把号码归一化，找出出现超过一次的号码，按字典序输出标准形式和出现次数。没有重复就输出 `No duplicates.`。

这题拆开来是三件事：**归一化**、**计数**、**有序输出**。

**归一化。** 题面给了字母到数字的映射表。这里有个**必须小心**的地方：普通的老式电话键盘上 `Q` 和 `Z` 是不占位置的，所以 `7` 对应的是 `P,R,S`（不是 `P,Q,R,S`），`9` 对应 `W,X,Y`（不是 `W,X,Y,Z`）。题面里特意写"你会发现其中没有字母 `Q` 和 `Z`"就是在提醒这一点。如果照搬"标准电话键盘"的 `PQRS=7, WXYZ=9`，`Q`/`Z` 会映射错，虽然输入里不会出现 `Q`/`Z` 导致结果看起来一样，但逻辑上是错的——更重要的是，如果映射表写成 `PQRS` 的连续四字母形式而输入里出现了 `Q`，就会静默给出错误答案。所以我按题面给的八组严格写死：

`ABC→2, DEF→3, GHI→4, JKL→5, MNO→6, PRS→7, TUV→8, WXY→9`

写成代码就是一个长度 8 的字符串数组，每组三个字母，赋值 `mp[c-'A'] = '2'+i`。

处理每个号码字符时：
- `-` 直接跳过（题面说"连字符是可以忽略"）；
- 数字直接留下；
- 大写字母查表转成数字。

得到纯数字串 `dig` 后，标准形式 = `dig` 的前 3 位 + `-` + 后 4 位。

**计数与有序输出。** 用 `map<string,int>` 最省事：key 是标准形式字符串，value 是出现次数。`map` 自带按 key 的字典序遍历，所以最后扫一遍 map，把 `cnt>1` 的输出出来就是字典序了。

如果一个都没输出，就打印 `No duplicates.`。注意题面特意说明"最后一个字母 `s` 有一个点"，还给了"不要输出多余空行"，这些细节要照做。

样例：`TUT-GLOP` → `8884567` → `888-4567`；`3-10-10-10` → `3101010` → `310-1010`；`310-1010` → `310-1010`。后两者相同，出现 2 次，输出 `310-1010 2` ✓。

数据范围 $N\le 10^5$，号码长度 $\le 1000$（这个上界很宽松，实际号码是 7 位数字加可能的连字符）。用 `map` 的话最坏 $O(N\log N\cdot L)$，完全够。

这里我犹豫了一下要不要用 `map` 还是"排序后扫一遍"。`map` 更直观，而且天然满足字典序要求；排序版本需要额外处理"分组统计"。两种都能过，我选 `map`，代码更短、意图更清楚。

## 二、思维链：完整证明

**引理 1**（归一化的正确性）：算法为每个号码生成的标准形式，与题目定义的标准形式一致。

*证明*：设输入号码为 $w$。算法逐字符处理 $w$：

- 遇到 `-`：按题面"电话中的连字符是可以忽略"，跳过；
- 遇到数字：题目规定数字就是数字本身，直接保留；
- 遇到大写字母：按题面给出的映射表把它替换成对应的数字。题面保证输入不含 `Q` 与 `Z`，且这八个分组恰好覆盖其余 24 个字母，故查表必定成功。

处理完毕后 `dig` 中恰好包含原号码的所有数字位，且顺序与原号码一致。于是 `dig` 就是题目说的"七位数字"的数字串。再按题目"中间用连字号分成前三个和后四个数字"，取前 3 位、`-`、剩余 4 位，得到的正是标准形式。证毕。

**引理 2**（相等的充要条件）：两个号码的标准形式相同，当且仅当题目认定它们是同一个电话号码。

*证明*：题目定义"如果两个电话号码的标准形式是一样的，那么这两个电话号码就是一样的"，即标准形式相同 $\Rightarrow$ 是同一个号码。反过来，由引理 1，标准形式是号码经"去连字符 + 字母转数字"后的数字串的重新分组，两个不同号码若标准形式相同，则它们的数字串相同，去掉连字符、还原字母后也相同——注意这里可能有歧义（不同字母组合映射到同一数字，如 `A` 和 `B` 都对应 `2`），但题目正是以"标准形式相同"为准绳定义相等，故结论与题目定义完全一致。证毕。

**引理 3**（计数的正确性）：`cnt[key]` 等于标准形式为 `key` 的号码个数。

*证明*：算法对每个输入号码恰好执行一次 `cnt[key]++`，其中 `key` 是该号码的标准形式（引理 1）。由引理 2，标准形式为 `key` 的号码恰好就是题目认定为"与 `key` 是同一个号码"的那批。因此 `cnt[key]` 恰好统计了这批号码的个数。证毕。

**引理 4**（输出的完整性与有序性）：算法输出的恰好是所有出现次数大于 $1$ 的标准形式，且按字典序排列。

*证明*：`map` 中的键互不重复（由引理 3，每个不同的标准形式对应一个键），且 `map` 的迭代顺序是键的字典序。算法遍历整个 map，仅输出 `p.second>1` 的项。由引理 3，被输出的项恰好是出现次数大于 $1$ 的标准形式，没有遗漏也没有多余的；输出顺序即 `map` 的迭代顺序，即字典序。证毕。

**引理 5**（无重复时的输出）：若不存在重复号码，算法输出且仅输出 `No duplicates.`。

*证明*：若所有 `p.second` 都不大于 $1$，则循环体一次都不执行，`any` 保持 `false`，算法输出 `No duplicates.` 且不输出其他任何内容。反之若存在重复号码，由引理 4 循环体必然执行过至少一次，`any` 为 `true`，不输出该行。两种情形下输出都符合题面要求。证毕。

**定理**：算法输出正确。

*证明*：由引理 1、3、4、5 直接成立。证毕。

## 三、模式总结（按实际思考顺序）

1. **拆三件事** — 归一化 → 计数 → 按字典序输出，顺序不能颠倒（必须先归一化才能比较）。
2. **抠映射表的坑** — 电话键盘上 `Q`/`Z` 不占位，所以 `7=PRS`、`9=WXY`，不能照抄标准键盘表。
3. **归一化的三步处理** — 去连字符 / 数字原样保留 / 字母查表。
4. **选数据结构** — `map<string,int>` 一手完成计数与字典序遍历。
5. **边界输出** — 一个都没重复时输出 `No duplicates.`（带句点）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $N$ | 电话号码个数 | `int`，$\le 10^5$ |
| `mp` | 字母 → 数字的映射表（`'A'`..`'Z'`） | `char[26]` |
| `raw` | 读入的原始号码 | `string` |
| `dig` | 归一化后的纯数字串 | `string` |
| `key` | 标准形式（前 3 位 + `-` + 后 4 位） | `string` |
| `cnt` | 标准形式 → 出现次数 | `map<string,int>` |
| `any` | 是否输出过重复号码 | `bool` |

### 算法步骤

1. 初始化映射表 `mp`：`{"ABC","DEF","GHI","JKL","MNO","PRS","TUV","WXY"}` 八组，第 $i$ 组的三个字母都映射到字符 `'2'+i`。
2. 读入 $N$。
3. 对每个号码：
   - 读入 `raw`，扫描字符：`-` 跳过；数字直接追加；大写字母追加 `mp[c-'A']`；
   - 得到 `dig` 后计算 `key = dig.substr(0,3) + "-" + dig.substr(3)`；
   - 执行 `cnt[key]++`。
4. 遍历 `cnt`，对 `p.second>1` 的项输出 `p.first << ' ' << p.second`。
5. 若没有任何项被输出，输出 `No duplicates.`。

### 复杂度

- 时间复杂度：$O(N\cdot L\cdot \log N)$，其中 $L$ 为号码长度（实际 $L\approx 7$）；其中归一化部分 $O(NL)$，`map` 插入 $O(\log N)$ 次比较，每次比较 $O(L)$。
- 空间复杂度：$O(N\cdot L)$，存储所有不同的标准形式。

### 验证状态

- 标程 `P2037.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面样例 `3 / TUT-GLOP / 3-10-10-10 / 310-1010` 输出 `310-1010 2`，与官方一致。
- 编写暴力 `P2037_brute.cpp`（归一化后存进 `vector` 排序再分组统计，与 `map` 写法完全不同）与对拍脚本 `P2037_check.py`：随机生成含字母、数字、随机连字符的号码，覆盖 `N\in[1,12]`，对拍 **1200 组全部通过**；同时验证了无重复时输出 `No duplicates.` 的分支。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2037 [ECNA 1999] 电话号码
// 把号码统一成"前3位-后4位"的标准形式，再用 map 统计出现次数
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

char mp[26];	// 字母 -> 数字，'Q' 与 'Z' 不出现
map<string,int> cnt;

void init()
{
	// 注意：7 对应 P,R,S；9 对应 W,X,Y（题面无 Q、Z）
	const string g[8]={"ABC","DEF","GHI","JKL","MNO","PRS","TUV","WXY"};
	for(int i=0;i<8;++i)
		for(char c:g[i]) mp[c-'A']=char('2'+i);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	init();
	int N;
	cin>>N;
	for(int i=0;i<N;++i)
	{
		string raw;
		cin>>raw;
		string dig;
		for(char c:raw)
		{
			if(c=='-') continue;			// 连字符可忽略
			if(c>='0'&&c<='9') dig+=c;
			else dig+=mp[c-'A'];
		}
		// 标准形式：七位数字，中间用连字符分成前三个和后四个
		string key=dig.substr(0,3)+"-"+dig.substr(3);
		cnt[key]++;
	}
	bool any=false;
	for(auto &p:cnt)
		if(p.second>1)
		{
			cout<<p.first<<' '<<p.second<<'\n';
			any=true;
		}
	if(!any) cout<<"No duplicates.\n";
	return 0;
}
```

### 代码说明

- 映射表刻意只列八组各三个字母，`'2'+i` 对应第 $i$ 组（$i=0..7$ 即数字 $2..9$），**不用**常见的 `PQRS`/`WXYZ` 写法，因为题面无 `Q`/`Z`。
- `mp` 是全局数组，未被赋值的 `'Q'`、`'Z'` 位置保持 `'\0'`，但由于输入保证不出现这两个字母，永远不会被查表命中。
- 归一化用 `for(char c:raw)` 遍历；数字判断写成 `c>='0'&&c<='9'` 而不是 `isdigit`，避免 `isdigit` 需要传 `unsigned char` 的坑（`isdigit` 传 `char` 在负值时是未定义行为）。
- `map` 自动按 key 的字典序迭代，所以输出天然有序，不需要额外 `sort`。
- `any` 标志用于区分"没有重复号码"的情形。
