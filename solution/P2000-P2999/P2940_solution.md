# P2940 [USACO09FEB] The Leprechaun S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 一个 $N\times N$（$1\le N\le 200$）的方格，每格写一个 $[-10^6,10^6]$ 的整数。贝茜沿**一个固定方向**（行方向、列方向、两种斜对角方向）每步走一格，踩过的数字之和就是财富；走到边界会**绕到对边**继续（环面/torus 拓扑）。求能踩出的最大和。

先把两处题面歧义钉死（这也是本题最容易想歪的地方）：

1. **一段最多走 $N$ 格。** 题面说"找一段连续的数字"。沿任一方向走 $N$ 步恰好回到起点（下面引理 1 会证），若允许走超过 $N$ 格，就会重复踩格；一旦某条线的总和为正，绕圈越多和越大，答案无上界，题目就不成立了。所以合理解读是：**段是环上一条不重复经过格子的连续弧，长度 $1\sim N$**。
2. **段非空，答案可以为负。** 输出格式写"一行一个正整数"，但格子里允许全负数。若允许空段则答案恒 $\ge 0$，"正整数"的说法才自洽；但"踩过的数字的和"字面上要求至少踩一格。我选择**非空段**口径：全负时答案就是最大的那个单格（负数）。依据：这是"行走获利"类问题的通行约定（必须走一步才算走过），且若数据全负而标准答案允许空段，题面应明确说"可以不踩"。两种口径只在"全负"这一种数据上相差一个 $\max(0,\cdot)$，实现里我会把这一分支单独写清楚。

**手造小数据核对**（题面的 24 配图无法读取，自己造）：

第一组，$N=2$：

```
1 -2
-3 4
```

行：$[1,-2]$ 最优 $1$，$[-3,4]$ 最优 $4$；列同理 $1,4$；两条对角线族在 $N=2$ 时重合，线 $\{(0,0),(1,1)\}=[1,4]$ 整段和 $5$，另一条 $[-3,-2]$ 最优 $-2$。答案 $5$。

第二组，专打"绕边界"的行段，$N=3$：

```
5 -100 4
-100 -100 -100
-100 -100 -100
```

第 $0$ 行环形段 $4,5$（跨过左右边界）和为 $9$；其余行、列、对角线都不超过 $5$。答案 $9$。注意普通（不绕环）最大子段和只有 $5$——这组数据专门否掉"直接 Kadane 不做环形处理"的写法。

第三组，专打"绕边界"的对角线段，$N=3$：

```
4 -100 -100
-100 -100 -100
-100 -100 5
```

主对角线 $(0,0),(1,1),(2,2)=[4,-100,5]$，环形段 $5,4$ 和为 $9$；其余所有线最优 $\le 5$。答案 $9$。

第四组，$N=1$，单格 $-7$：非空口径答案 $-7$（若空段口径则是 $0$）；单格 $7$ 答案 $7$。

这四组覆盖了：普通段、绕环行段、绕环对角线段、全负边界。程序输出依次为 $5,9,9,-7,7$，与手算一致。

## 二、思维链：完整证明

### 第一步：把"绕边界走"翻译成图论对象

**探索性质。** 在环面上沿固定方向走，轨迹是什么？以行方向为例：固定行 $i$，列坐标每次 $+1\bmod N$，走 $N$ 步回到起点——这是一个**长度为 $N$ 的环**。列方向同理。对角线呢？右下方向每步 $(+1,+1)\bmod N$，量 $(\text{行}-\text{列})\bmod N$ 不变；右上方向每步 $(-1,+1)\bmod N$，量 $(\text{行}+\text{列})\bmod N$ 不变。于是直觉上：四个方向族各自把网格划分成 $N$ 个环。先证这件事。

### 引理 1（环面线的结构）

固定 $N$。定义四个方向 $d\in\{(0,1),(1,0),(1,1),(-1,1)\}$（列增、行增、右下、右上）。从格子 $(r,c)$ 出发沿 $d$ 走，轨迹为 $(r+k d_r\bmod N,\ c+k d_c\bmod N)$，$k=0,1,2,\dots$。则：

(a) 轨迹恰含 $N$ 个互不相同的格子，第 $N$ 步回到起点；
(b) 同一方向族的所有轨迹构成网格的一个划分，共 $N$ 条环，每条环长 $N$；
(c) 每条环都有唯一编号：行方向由行号 $i$ 编号，列方向由列号 $j$ 编号；两族对角线（$d_c=1$）的环上列坐标取遍 $0..N-1$，故与第 $0$ 列恰交于一格 $(s,0)$，可由 $s$ 编号。

*证明*：(a) 设 $0\le k_1<k_2<N$ 两步落在同格，则 $(k_2-k_1)d_r\equiv 0$ 且 $(k_2-k_1)d_c\equiv 0\pmod N$。四个方向的 $(d_r,d_c)$ 中至少有一个分量是 $\pm1$，故 $k_2-k_1\equiv 0\pmod N$，与 $0<k_2-k_1<N$ 矛盾。所以前 $N$ 步互异；第 $N$ 步位移 $(Nd_r,Nd_c)\equiv(0,0)$，回到起点。轨迹恰为 $N$ 格环。

(b) "落在同一条环上"是等价关系（互相可达）：自反（$k=0$）、对称（沿反方向走 $N-k$ 步）、传递（步数相加）。每个等价类大小由 (a) 为 $N$，总格数 $N^2$，故恰 $N$ 个类。

(c) 行方向的环固定行号 $i$、列方向的环固定列号 $j$，编号显然唯一。两族对角线方向 $d_c=1$，环上格子的列坐标随 $k$ 取遍 $0..N-1$，故恰一步列坐标为 $0$，交点 $(s,0)$ 唯一确定该环。证毕。

**推论**：任意合法行走完全落在某一条环上；反之环上任意一段连续弧（长 $1\sim N$）都可由某次行走实现（选好起点与方向）。所以

$$\text{答案}=\max_{\text{全部 }4N\text{ 条环}}\bigl(\text{该环的非空环形最大子段和}\bigr).$$

（方向取反不产生新段：反向走出的段与正向某段是同一组格子，故只需 $4$ 个方向族而非 $8$ 个方向。）

### 第二步：先解没有绕环的简化版

**考虑简化版。** 如果方格不绕环，每条线就是一条普通序列，答案是经典**最大子段和**，Kadane 算法 $O(N)$。先把它的正确性证完整，因为环形版要复用两遍（一遍 max、一遍 min）。

### 引理 2（Kadane 不变量）

对序列 $x_0,\dots,x_{N-1}$，维护 $c_i=\max(x_i,\ c_{i-1}+x_i)$（$c_{-1}=0$ 视作"前面没有段"，即 $c_0=x_0$），$M_i=\max(M_{i-1},c_i)$。则

(a) $c_i=\max\{\sum_{t=l}^{i}x_t:\ 0\le l\le i\}$，即**以 $i$ 结尾**的非空子段的最大和；
(b) $M_i=\max\{\sum_{t=l}^{r}x_t:\ 0\le l\le r\le i\}$，即前缀 $[0,i]$ 内的非空最大子段和。

把 $\max$ 全部换成 $\min$，结论对称成立（最小子段和 $m$）。

*证明*：对 $i$ 归纳。(a) $i=0$：以 $0$ 结尾的段只有 $[0,0]$，$c_0=x_0$ ✓。设 $c_{i-1}$ 正确。以 $i$ 结尾的段按左端点分两类：$l=i$（单格，和 $x_i$）；$l<i$（去掉末格 $x_i$ 后是以 $i-1$ 结尾的段，和 $\le c_{i-1}$，且取到 $c_{i-1}$ 的段接上 $x_i$ 可达 $c_{i-1}+x_i$）。两类取 max 即 $\max(x_i,c_{i-1}+x_i)$ ✓。(b) 前缀 $[0,i]$ 的段按右端点分类：右端点 $<i$ 的由 $M_{i-1}$ 覆盖，右端点 $=i$ 的由 $c_i$ 覆盖，取 max ✓。$\min$ 版本把每个 $\max$ 换 $\min$，论证逐字对称。证毕。

### 第三步：绕环段怎么归约？

**碰壁与修正。** 直接把序列倍长成 $2N$ 再限制窗口 $\le N$ 也能做（单调队列），但更漂亮的归约是：**一个绕环段，恰好是某个不绕环段的补集**。环上挖掉一段连续弧，剩下的还是一段连续弧。于是"绕环段的最大和" = "总和 $-$ 挖掉那段的最小和"。这就是把环形问题归约回普通最小子段和。需要小心两个洞：补集为空（段长 $N$）与全负序列。

### 引理 3（环形最大子段和公式）

设环上序列 $x_0,\dots,x_{N-1}$，总和 $T$，非空最大子段和 $M$，非空最小子段和 $m$（均由引理 2 求出）。则非空环形最大子段和为

$$\mathrm{ans}=\begin{cases}M,&M<0,\\ \max(M,\ T-m),&M\ge 0.\end{cases}$$

*证明*：把全部合法段（长 $1\sim N$ 的弧）按形态分三类：

**类 A（不绕环）**：即线性序下的连续区间 $[l,r]$，$0\le l\le r<N$（含整条 $[0,N-1]$）。最大和为 $M$（引理 2）。

**类 B（绕环且长 $<N$）**：形如 $[l,N-1]\cup[0,r]$，$r+1<l$。其补集 $[r+1,l-1]$ 是**非空**不绕环区间，故该类段和 $=T-\text{补集和}\le T-m$；反之取补集为最小子段（和 $m$、长 $\le N-1$？若最小子段就是整条，则此类为空，见下），其补集是合法的类 B 段，和恰 $T-m$。所以当类 B 非空时其上确界 $=T-m$ 且可达。

**类 C（长 $N$）**：整条环，和 $T$。

于是 $\mathrm{ans}=\max(M,\ T-m\text{（若类 B 非空）},\ T)$。下面化简。

**情形 1：$M<0$。** 每个单格段和 $x_i\le M<0$，故全负。此时整条环的和最小（任何真子段删掉若干负数后和变大），即 $m=T$，类 B 为空（补集非空要求最小子段长 $<N$，但唯一最小段是整条）。类 C 的 $T=\sum x_i\le\max x_i=M$（负数越加越小）。故 $\mathrm{ans}=M$ ✓。**这正是"全局数组默认 0 不是 INF"式的陷阱**：若无脑取 $\max(M,T-m)$，这里 $T-m=0$ 对应**空段**，会在全负数据上错误输出 $0$。

**情形 2：$M\ge 0$。** 先证 $\max(M,T-m)\ge T$，从而类 C 被吞并：若 $m\le 0$，$T-m\ge T$ ✓；若 $m>0$，则每个单格 $x_i\ge m>0$ 全正，Kadane 一路累加得 $M=T$ ✓。再证 $T-m$ 不会"虚高"：若类 B 非空，$T-m$ 可达，取 max 正确；若类 B 为空，则 $m=T$，$T-m=0\le M$，取 max 后仍是可达的 $M$，公式值不变。故 $\mathrm{ans}=\max(M,T-m)$ ✓。证毕。

### 引理 4（枚举不重不漏）

实现按四类枚举：行 $i=0..N-1$；列 $j=0..N-1$；右下对角线 $s=0..N-1$，第 $k$ 格取 $a[(s+k)\bmod N][k]$；右上对角线 $s=0..N-1$，第 $k$ 格取 $a[(s-k+N)\bmod N][k]$。则恰枚举了引理 1 的全部 $4N$ 条环，各一次。

*证明*：行、列显然各 $N$ 条不重不漏。右下族：第 $k$ 格行列差 $=(s+k)-k=s\bmod N$，故整条落在不变量 $(r-c)\bmod N=s$ 的类里；由引理 1(b) 该类恰 $N$ 格，而枚举给出 $N$ 个互异格（列坐标 $k$ 互异），故恰为该类。不同 $s$ 的不变量不同，不重；$s$ 取遍 $0..N-1$，不漏。右上族同理，不变量 $(r+c)\bmod N=s$：$(s-k)+k=s$ ✓。$(s-k+N)\bmod N$ 中 $+N$ 保证 $s-k\ge -N+1>-N$，取模非负，C++ 负数取模陷阱被显式填平。证毕。

### 引理 5（复杂度与值域）

时间 $O(N^2)$，空间 $O(N^2)$；所有累加和的绝对值 $\le N\cdot 10^6\le 2\times 10^8$。

*证明*：$4N$ 条环，每条 $O(N)$ 提取 + $O(N)$ 一遍 Kadane（max/min 同遍维护），共 $O(4N^2)=O(N^2)$，$N=200$ 时约 $1.6\times 10^5$ 次基本操作。空间：网格 $N^2$ 个 int 约 $160$ KB + 临时数组 $O(N)$。值域：任一段 $\le N$ 格，每格 $\le 10^6$ 绝对值，故 $|\text{段和}|\le 2\times 10^8$，int 都装得下；实现用 i64 是零成本保险。哨兵 $\pm 1145141919810$ 远大于 $2\times 10^8$，不会与真实值混淆。证毕。

### 定理

程序输出环面上沿行/列/对角线方向、长 $1\sim N$ 的非空连续段的最大和，复杂度 $O(N^2)$。

*证明*：引理 1 把合法行走归约为 $4N$ 条环上的弧；引理 4 保证枚举不重不漏；引理 2 保证每条环的 $M,m$ 正确；引理 3 保证由 $M,m,T$ 合成环形答案正确（含全负与整环两个边界）；引理 5 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 绕边界 ⇒ 每个方向族的轨迹是长 $N$ 的环；用不变量 $(r\pm c)\bmod N$ 给对角线分类；段长必须 $\le N$，否则答案无上界。
- consider easier version — 先去掉绕环：每条线是普通序列，最大子段和 Kadane $O(N)$。
- reduce to easier problem — 绕环段 = 某个不绕环段的补集 ⇒ 环形最大 = 总和 $-$ 最小子段和，归约回 Kadane（跑 min 版）。
- classic problem solution — Kadane 一遍同时维护最大/最小子段和与总和，$O(N)$ 每线。
- discuss by category — 全负时 $T-m=0$ 对应空段必须屏蔽；整环段（长 $N$）被 $\max(M,T-m)$ 吞并，分 $m\le0$ / $m>0$ 两类证明。
- explore its property — 负数取模陷阱：右上对角线写 $(s-k+N)\bmod N$ 显式补 $N$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 网格边长 $\le 200$ | `int` | 读入 |
| `a[i][j]` | 格子数值，$\lvert a\rvert\le 10^6$ | `int[mxn][mxn]` | 读入，0-based |
| `tmp[k]` | 当前环展开成的线性序列 | `int[mxn]` | 每条线现填 |
| `mxn` | $200+5$ | `constexpr int` | 网格尺寸 |
| `inf` | 哨兵 $1145141919810$ | `constexpr i64` | 远大于可能段和 $2\times10^8$ |
| `ans` | 全局答案 | `i64` | **显式初始化 $-\infty$**（全局默认 0 会在"全负"数据上出错） |
| `tot` | 当前环总和 $T$ | `i64`，每线清零 | |
| `mx` / `cmx` | 最大子段和 $M$ / 以当前格结尾的最大段和 | `i64` | `mx=-inf`，`cmx=0`（首格由 `max(x,0+x)` 接管） |
| `mn` / `cmn` | 最小子段和 $m$ / 以当前格结尾的最小段和 | `i64` | `mn=inf`，`cmn=0` |
| `circ()` | 返回 `tmp` 的非空环形最大子段和 | `i64()` | 引理 3 公式 |

### 算法步骤

1. I/O 加速三行；读 $N$ 与网格。
2. 对每行 $i$：`tmp[j]=a[i][j]`，`ans=max(ans,circ())`。
3. 对每列 $j$：`tmp[i]=a[i][j]`，同上。
4. 对每个 $s$：右下对角线 `tmp[k]=a[(s+k)%n][k]`，同上。
5. 对每个 $s$：右上对角线 `tmp[k]=a[(s-k+n)%n][k]`，同上。
6. `circ()` 内一遍扫描维护 $T,M,m$；$M<0$ 返回 $M$，否则返回 $\max(M,T-m)$。
7. 输出 `ans`。

### 复杂度

- 时间：$O(4N^2)=O(N^2)$，$N=200$ 时约 $1.6\times 10^5$ 次操作。
- 空间：$O(N^2)$，约 $160$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；四组手造数据（普通段 $5$、绕环行段 $9$、绕环对角线段 $9$、全负单格 $-7$ / 正单格 $7$）全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2940 [USACO09FEB] The Leprechaun S
// 环面网格：行/列/两条对角线共 4N 条环状线，每条线求非空环形最大子段和
// 环形最大子段和 = max(普通 Kadane, 总和-最小子段和)，全负时只能取前者
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{205};
constexpr i64 inf{1145141919810};

int n,a[mxn][mxn],tmp[mxn];
i64 ans=-inf;

i64 circ()	// tmp[0..n) 的非空环形最大子段和
{
	i64 tot=0,mx=-inf,mn=inf,cmx=0,cmn=0;
	for(int i=0;i<n;++i)
	{
		i64 x=tmp[i];
		tot+=x;
		cmx=max(x,cmx+x);mx=max(mx,cmx);
		cmn=min(x,cmn+x);mn=min(mn,cmn);
	}
	if(mx<0)
		return mx;	// 全负：tot-mn=0 对应空段，不合法
	return max(mx,tot-mn);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			cin>>a[i][j];
	for(int i=0;i<n;++i)	// 行
	{
		for(int j=0;j<n;++j)
			tmp[j]=a[i][j];
		ans=max(ans,circ());
	}
	for(int j=0;j<n;++j)	// 列
	{
		for(int i=0;i<n;++i)
			tmp[i]=a[i][j];
		ans=max(ans,circ());
	}
	for(int s=0;s<n;++s)	// 主对角线方向：(s,0) 出发右下绕环
	{
		for(int k=0;k<n;++k)
			tmp[k]=a[(s+k)%n][k];
		ans=max(ans,circ());
	}
	for(int s=0;s<n;++s)	// 副对角线方向：(s,0) 出发右上绕环
	{
		for(int k=0;k<n;++k)
			tmp[k]=a[(s-k+n)%n][k];
		ans=max(ans,circ());
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `ans` 必须显式初始化成 $-\infty$：全局 `i64` 默认 $0$，若数据全负，$0$ 会冒充答案——这是"全局数组默认 0 不是 INF"陷阱的变体。
- `circ()` 里 `cmx/cmn` 初值 $0$ 是安全的：首格 `max(x,0+x)=x`、`min(x,0+x)=x`，等价于"段从首格重新开始"，不会引入空段。
- `mx<0` 分支是引理 3 情形 1：全负时 `tot-mn=0` 对应空段，必须屏蔽。
- 右上对角线 `(s-k+n)%n` 显式 $+N$：C++ 负数取模得负，直接 `(s-k)%n` 会数组越界。
- 四个方向族而非八个方向：反向行走的段集合与正向相同，枚举翻倍纯属浪费。
- 段和上界 $2\times 10^8$ 其实 int 可容，用 `i64` 是零成本保险；哨兵取 114514 家族的 `1145141919810`。
