# P2616 [USACO10JAN] Buying Feed, II S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** FJ 从坐标 $0$ 出发，只能向前走，到坐标 $E$ 回家，途中要买够 $K$ 吨饲料。数轴上有 $N$ 家商店，第 $i$ 家在 $X_i$（$0<X_i<E$），每吨售价 $C_i$，最多卖 $F_i$ 吨。车上有 $X$ 吨时开 $D$ 公里花 $D\times X$ 元。求买齐 $K$ 吨的最小总花费（购买 + 运输）。范围：$K\le100$，$E\le350$，$N\le100$，$F_i\le100$，$C_i\le10^6$；同一坐标可以有多家店。

**第一反应：DP。** 标签写着"DP、贪心、排序"，先想 DP。设 $dp[i][j]$ 为"走完前 $i$ 家店、买到 $j$ 吨"的最小花费。麻烦在运费：它取决于"每一吨是什么时候上车的"，看起来要把载重过程整个记下来。但仔细一想——**只能向前走**，所以在第 $i$ 家店买的任何一吨，都必然被载着走完剩下的 $E-X_i$ 公里，一公里不多一公里不少。于是买 $t$ 吨的转移代价就是 $t\cdot C_i + t\cdot(E-X_i)$，与之前买了什么完全无关：

$$dp[i][j]=\min_{0\le t\le\min(F_i,j)}\bigl(dp[i-1][j-t]+t\cdot(C_i+E-X_i)\bigr).$$

这是个有界背包，$O(N\cdot K\cdot F)\approx10^6$，能过。

**第二反应：等等，这个转移暴露了本质。** 上面式子里每一吨的代价都是 $C_i+E-X_i$，**吨与吨之间毫无耦合**——运费对载重是线性的，所以可以"摊到每吨头上"：在 $x$ 处买一吨，总代价就是 $C+(E-x)$，不管别的吨在哪买、买多少。整道题塌缩成：

> 有 $N$ 种物品，第 $i$ 种最多 $F_i$ 件，单价 $p_i=C_i+E-X_i$，买**恰好** $K$ 件，最小化总价。

这就是"带容量限制的采购"：**按单价排序，从便宜的开始能买多少买多少**。连 DP 都不用了，$O(N\log N)$。

**第三步：碰壁检验——按售价 $C$ 排序行不行？** 不行，运费会惩罚远店。手造反例：$K=2,E=10$，店 A$(X=1,F=2,C=1)$，店 B$(X=9,F=2,C=5)$。按 $C$ 排序买 A：$2\times1+2\times9=20$ 元；但有效单价 A 是 $1+9=10$、B 是 $5+1=6$，买 B 只要 $2\times5+2\times1=12$ 元。**"便宜"的远店算上运费反而贵**，排序键必须是 $p_i=C_i+E-X_i$，不是 $C_i$。

**第四步：几个边界。**

1. **恰好 $K$ 吨。** $p_i=C_i+(E-X_i)\ge1+1=2>0$，多买一吨纯亏，最优解一定恰好买 $K$ 吨。
2. **同坐标多店。** 每吨独立计价，同坐标的不同店就是不同"物品"，互不干扰，无需合并。
3. **可行性。** 数据保证 $\sum F_i\ge K$（否则无解，题目未定义输出）；贪心循环买够 $K$ 吨即停。
4. **值域。** 答案 $\le K\cdot(\max C_i+E)\le100\times1000349\approx1.0003\times10^8$，`int` 其实装得下，仍用 `i64` 保险。

**手造数据核对。** 题面 Hint 说"在离家较近的两家商店里各购买一吨饲料，花费路上的钱是 $1+2=3$，花在店里的钱是 $2+2=4$"——据此反推一组数据：$K=2,E=5$，店 $(3,1,2)$、$(4,1,2)$、$(1,5,1)$。有效单价分别为 $4,3,5$，贪心买 $(4,1,2)$ 与 $(3,1,2)$ 各一吨：运费 $(5-4)+(5-3)=1+2=3$，购买 $2+2=4$，总 $7$，与 Hint 的两个分项逐一吻合。另造四组：上面"按 $C$ 排序"反例（答案 $12$）、容量受限组 $K=3,E=10$，店 $(9,1,5),(1,5,1)$（答案 $1\times6+2\times10=26$）、最小规模 $K=1,E=2$，店 $(1,1,1)$（答案 $2$）、同坐标组 $K=2,E=5$，店 $(3,1,2),(3,1,1)$（答案 $7$）。五组程序输出全部与手算一致。

## 二、思维链：完整证明

**记号。** 购买方案为整数向量 $t=(t_1,\dots,t_N)$，$0\le t_i\le F_i$；总吨数 $T=\sum_i t_i$。有效单价 $p_i=C_i+(E-X_i)$。不妨把商店按 $p_i$ 升序重新编号（$p_1\le p_2\le\cdots\le p_N$，平局任意固定）。贪心方案 $g$ 定义为
$$g_i=\min\Bigl(F_i,\ K-\sum_{j<i}g_j\Bigr).$$

---

### 引理 1（运费摊吨：总花费的封闭形式）

任意方案 $t$ 的总花费（购买 + 运输）为
$$\mathrm{cost}(t)=\sum_{i=1}^{N}t_i\cdot C_i+\sum_{i=1}^{N}t_i\cdot(E-X_i)=\sum_{i=1}^{N}t_i\,p_i.$$

*证明*：购买花费显然是 $\sum t_iC_i$，关键是运输。把 $0,E$ 与所有互异的商店坐标合并排序：$0=z_0<z_1<\cdots<z_L=E$。FJ 只能向前走，在路段 $[z_j,z_{j+1})$ 上车载恒为"坐标 $\le z_j$ 的店已购吨数"：
$$\text{load}_j=\sum_{i:\,X_i\le z_j}t_i.$$
（经过坐标 $z_j$ 处的店时可能补货，载重只在该点跳变；路段内部无店，载重不变。）由题面计费规则，运输花费为
$$\sum_{j=0}^{L-1}(z_{j+1}-z_j)\cdot\text{load}_j=\sum_{j=0}^{L-1}(z_{j+1}-z_j)\sum_{i:\,X_i\le z_j}t_i.$$
这是有限和，交换求和次序：
$$=\sum_{i=1}^{N}t_i\sum_{j:\,z_j\ge X_i}(z_{j+1}-z_j)=\sum_{i=1}^{N}t_i\,(E-X_i).$$
最后一步是望远镜求和：$X_i$ 本身是某个 $z_{j_0}$（$j_0<L$，因 $X_i<E$），满足 $z_j\ge X_i$ 的路段恰为 $[z_{j_0},z_{j_0+1}),\dots,[z_{L-1},z_L)$，长度之和 $=z_L-z_{j_0}=E-X_i$。证毕。

**这条引理是全题支点**：运费对载重线性 + 单向行驶 ⇒ 每吨的运输距离在购买瞬间就锁死为 $E-X_i$，吨与吨解耦。

---

### 引理 2（最优解恰好买 $K$ 吨）

$p_i\ge2>0$；任何 $T>K$ 的可行方案都不是最优。故答案 $=\min\{\sum t_ip_i:\ 0\le t_i\le F_i,\ \sum t_i=K\}$。

*证明*：$C_i\ge1$；$X_i<E$ 且均为整数 ⇒ $E-X_i\ge1$；故 $p_i\ge2$。设可行方案 $t$ 满足 $T>K$，取任一 $t_i>0$，令 $t'_i=t_i-1$，其余不变：$t'$ 仍满足容量约束且 $T'=T-1\ge K$（仍买够 $K$ 吨，合法），$\mathrm{cost}(t')=\mathrm{cost}(t)-p_i<\mathrm{cost}(t)$。故最优解必有 $T=K$。结合引理 1，答案就是所述约束最小化问题。证毕。

---

### 引理 3（贪心最优：交换论证）

按 $p$ 升序编号后，贪心方案 $g$ 是引理 2 约束问题的最优解。

*证明*：先确认 $g$ 可行：归纳可知 $\sum_{j\le i}g_j=\min(K,\sum_{j\le i}F_j)$，故 $g_i\le F_i$、$g_i\ge0$，且 $\sum g_i=\min(K,\sum F_i)=K$（数据保证 $\sum F_i\ge K$，见引理 4）。

设 $t^\*$ 为任一最优解。若 $t^\*\ne g$，取**第一个**不同的下标 $i$：$t^\*_j=g_j\ (j<i)$，$t^\*_i\ne g_i$。

**断言 1：$t^\*_i<g_i$。** 由 $t^\*$ 可行：$t^\*_i\le F_i$ 且 $\sum_{j\le i}t^\*_j\le K$，即 $t^\*_i\le K-\sum_{j<i}t^\*_j=K-\sum_{j<i}g_j$。故 $t^\*_i\le\min(F_i,K-\sum_{j<i}g_j)=g_i$；又 $t^\*_i\ne g_i$，得 $t^\*_i<g_i$。特别地 $t^\*_i<g_i\le F_i$：店 $i$ 在 $t^\*$ 下**还有剩余容量**。

**断言 2：存在 $j>i$ 使 $t^\*_j>g_j\ge0$。** 两方案总和都是 $K$，前 $i-1$ 项相等而第 $i$ 项 $t^\*_i<g_i$，故后缀和 $\sum_{j>i}t^\*_j>\sum_{j>i}g_j$，必有一项 $t^\*_j>g_j$。于是 $t^\*_j\ge1$。

**交换**：把一吨从店 $j$ 挪到店 $i$：$t'_i=t^\*_i+1,\ t'_j=t^\*_j-1$，其余不变。容量：$t'_i\le g_i\le F_i$ ✓，$t'_j\ge g_j\ge0$ ✓；总和不变 ✓。花费变化 $=p_i-p_j\le0$（$i<j$ 且已按 $p$ 升序）。故 $t'$ 可行且 $\mathrm{cost}(t')\le\mathrm{cost}(t^\*)$，$t'$ 也是最优解。

**终止**：$t'$ 与 $g$ 的相等前缀至少延长到 $i$（原来只到 $i-1$）。以"与 $g$ 相等的前缀长度"为势函数，每轮交换严格 $+1$，上界 $N$，故有限轮后得到与 $g$ 完全相等的最优解。全程花费不增，故 $\mathrm{cost}(g)\le\mathrm{cost}(t^\*)=\text{最优值}$；又 $g$ 可行，$\mathrm{cost}(g)\ge\text{最优值}$。夹逼得 $g$ 最优。证毕。

**注**：平局 $p_i=p_j$ 时交换不改变花费，论证依然成立——这正是"排序键相同任取顺序"不影响答案的原因。

---

### 引理 4（可行性与贪心循环的终止）

$\sum_iF_i\ge K\iff$ 贪心恰好买到 $K$ 吨。题目数据保证前者（否则问题无解、输出未定义）。

*证明*：由引理 3 中的归纳式 $\sum_{j\le i}g_j=\min(K,\sum_{j\le i}F_j)$：$i=0$ 时 $0=\min(K,0)$ ✓；归纳步 $\sum_{j\le i}g_j=\min(K,\sum_{j<i}F_j)+\min(F_i,K-\min(K,\sum_{j<i}F_j))=\min(K,\sum_{j\le i}F_j)$（分 $\sum_{j<i}F_j\ge K$ 与 $<K$ 两种情形直接验证）。取 $i=N$ 即得。代码中 `k-=t` 到 $0$ 时循环条件 `i<n&&k` 退出，恰好买够。证毕。

---

### 引理 5（排序键等价与值域安全）

按 $C_i-X_i$ 升序排序等价于按 $p_i=C_i+E-X_i$ 升序排序；比较器中的减法与最终答案均不溢出。

*证明*：$p_i-p_j=(C_i-X_i)-(C_j-X_j)$（常数 $E$ 相消），故两个键诱导完全相同的序（含平局结构）。$C_i-X_i\in[1-349,\ 10^6-1]=[-348,\ 999999]$，`int` 减法安全。答案 $\le K\cdot\max p_i\le100\times(10^6+349)=100034900<2^{31}-1$，`int` 本已足够；代码用 `i64` 累加，余量更大。证毕。

---

### 引理 6（复杂度）

时间 $O(N\log N)$，空间 $O(N)$。

*证明*：读入 $O(N)$；排序 $O(N\log N)$；贪心循环至多 $N$ 次、每次 $O(1)$。合计 $O(N\log N)$，$N\le100$ 时不足千次操作。空间为 $N$ 个三元组。证毕。

---

### 定理

程序输出的 `ans` 等于买齐 $K$ 吨饲料的最小总花费。

*证明*：引理 1 把总花费化为 $\sum t_ip_i$；引理 2 把问题化为"恰好 $K$ 件、容量 $F_i$、单价 $p_i$"的约束最小化；引理 5 保证代码的排序键与 $p_i$ 同序；引理 3 证明该序下的贪心最优；引理 4 保证买够 $K$ 吨；引理 6 给出复杂度。证毕。

---

### 附注：与 DP 解法的关系

标签里的"DP"对应有界背包写法 $dp[i][j]=\min_{0\le t\le\min(F_i,j)}(dp[i-1][j-t]+t\cdot p_i)$，$O(NKF)\approx10^6$ 也能通过。引理 3 的交换论证说明该 DP 的最优解必具贪心结构，因此排序贪心是它的"闭式解"——先想 DP 再发现可贪心，是本题最自然的思维路径。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 运费 = 载重 × 距离，对载重**线性**；只能向前走 ⇒ 每吨的运输距离在购买瞬间锁死为 $E-X_i$。
- **consider easier version** — 先写有界背包 DP $dp[i][j]$（$O(NKF)\approx10^6$），在转移里发现每吨贡献独立、吨间无耦合。
- **reduce to easier problem** — 运费摊到每吨：有效单价 $p_i=C_i+(E-X_i)$，原题塌缩为"容量受限、买恰好 $K$ 件、最小总价"。
- **classic problem solution** — 按有效单价排序 + 贪心装容量，交换论证（第一个差异位 + 势函数终止）证明最优，$O(N\log N)$。
- **discuss by category** — 反例检验：按 $C$ 排序错（远店运费惩罚）；恰好 $K$ vs 多于 $K$（$p_i>0$）；同坐标多店互不干扰；排序键 $C-X$ 与 $C+E-X$ 等价。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `k` | 还需购买的吨数 $K\le100$ | `int`，读入 | 贪心循环中递减到 $0$ |
| `e` | 终点坐标 $E\le350$ | `int`，读入 | 每吨运费 $=E-X_i$ |
| `n` | 商店数 $N\le100$ | `int`，读入 | 同坐标可多店 |
| `a[i].x/.f/.c` | 第 $i$ 店坐标 / 库存 / 售价 | `struct node[mxn]`，读入 | 输入顺序 $X_i,F_i,C_i$ |
| $p_i$ | 有效单价 $C_i+E-X_i$ | 不显式存 | 排序用等价的 $C_i-X_i$ |
| `ans` | 最小总花费 | `i64`，初值 $0$ | $\le1.0003\times10^8$ |
| `t` | 本轮在第 $i$ 店买的吨数 | `int`，`min(k,a[i].f)` | 能买多少买多少 |
| `mxn` | $100+5$ | `constexpr int{105}` | +5 松弛 |

### 算法步骤

1. I/O 加速三行；读入 `k,e,n` 与 $N$ 个三元组 `(x,f,c)`。
2. 按 `c-x` 升序排序（引理 5：等价于按有效单价 $p_i$ 排序）。
3. 顺序扫店：`t=min(k,a[i].f)`，`ans+=(i64)t*(a[i].c+e-a[i].x)`，`k-=t`；`k==0` 即停。
4. 输出 `ans`。

### 复杂度

- 时间 $O(N\log N)$；空间 $O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；五组手造数据（Hint 反推组、按 $C$ 排序反例组、容量受限组、最小组、同坐标组）输出 $7,12,26,2,7$，全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2616 [USACO10JAN] Buying Feed, II S
// 思路：运费对载重线性 ⇒ 每吨饲料独立计费：在 x 处买一吨花费 C+(E-x)。
//       问题塌缩成「N 种物品、每种 F_i 件、单价 p_i=C_i+E-X_i，买恰好 K 件」
//       ⇒ 按有效单价排序贪心装容量，交换论证保证最优。O(N log N)。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};

int k,e,n;
struct node{int x,f,c;}a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>k>>e>>n;
	for(int i=0;i<n;++i)
		cin>>a[i].x>>a[i].f>>a[i].c;
	// E 是常数，按 C-X 排序等价于按有效单价 C+(E-X) 排序
	sort(a,a+n,[](node u,node v){return u.c-u.x<v.c-v.x;});
	i64 ans=0;
	for(int i=0;i<n&&k;++i)
	{
		int t=min(k,a[i].f);
		ans+=(i64)t*(a[i].c+e-a[i].x);
		k-=t;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **排序键是 `c-x` 不是 `c`**：$E$ 为常数，`c-x` 与有效单价 `c+e-x` 同序（引理 5）；只按售价排序会被"便宜的远店"反例击穿。
- **`(i64)t*(...)` 先转型再乘**：本题极限约 $10^8$，`int` 本不会溢出，但养成"累加进 `i64` 前先转型"的习惯，换大数据不炸。
- **循环条件 `i<n&&k`**：买够 $K$ 吨立即停；数据保证 $\sum F_i\ge K$，循环结束时 `k==0`。
- **不需要按坐标排序、不需要处理同坐标**：引理 1 已把位置信息吸收进单价，商店之间完全解耦。
- 结构体数组 + 比较器 lambda 按值传 `node`（三个 `int`，拷贝开销可忽略），符合风格指南的纯聚合习惯。
