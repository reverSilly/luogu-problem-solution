# P2951 [USACO09OPEN] Hide and Seek S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 个谷仓（$2\le N\le 5\times10^4$）、$M$ 条无向边（$1\le M\le 5\times10^4$），边没有权值。FJ 在 $1$ 号谷仓。两个谷仓间的"距离"定义为它们之间**最短路径的边数**。要求三个量：距 $1$ 号谷仓最远的距离 $d^\*$、达到这个距离的谷仓中**编号最小**的那个、以及达到这个距离的谷仓**个数**。一行输出：编号、距离、个数。

**先抠两处题意口径：**

1. **连通性。** 题面写"每两个仓谷间当然会有最短路径"，这句话暗示图是连通的（否则不可达谷仓对之间根本没有路径，"距离"无从谈起）。我按"图连通"为主口径；代码里仍把不可达谷仓（BFS 后 `dis` 保持 INF）**排除在统计之外**作为保险——在连通口径下这个分支永远不会触发，两种解读下行为一致，不需要赌数据。
2. **$1$ 号谷仓自己算不算？** FJ 站在 $1$ 号，贝西藏在"别的"谷仓。连通且 $N\ge2$ 时必有谷仓距离 $\ge1$，而 $1$ 号自身距离为 $0$，永远成不了最大值，所以"算不算自己"在合法数据下**不可观测**，无需纠结。

**第一反应：这是什么距离？** 边无权，"最短路径"就是最少边数。这一句话直接淘汰两个重型工具：Floyd 要 $O(N^3)=1.25\times10^{14}$，死路；Dijkstra 的堆是为一边权各不相同的图准备的，这里所有边权都是 $1$，堆退化成"按距离分层"，而**分层恰好就是 BFS 的队列天然做的事**。于是问题归约成最经典的**单源 BFS**：从 $0$（内部 0-based 的 $1$ 号）出发，`dis[v]` 记录最短边数。

**第二步：BFS 为什么对？** 这是全题唯一需要认真证明的地方。"先被访问到的层数就是最短距离"听起来显然，但"显然"两个字在 OI 里最危险。我把它拆成两个方向夹逼：

- **上界方向**（`dis` 不会偏小）：每次赋值 `dis[v]=dis[u]+1` 都对应一条真实存在的路径（到 $u$ 的路径 + 边 $u\to v$），所以 `dis[v]` 永远 $\ge$ 真实最短距离 $\delta(v)$；
- **下界方向**（`dis` 不会偏大）：对 $\delta$ 归纳——$\delta(v)=k$ 的点在最短路上有个 $\delta=k-1$ 的前驱 $w$，归纳假设 $w$ 已被正确赋值并出队，出队时扫描到边 $w\to v$，此刻 $v$ 要么已赋值（$\le dis[w]+1=k$），要么当场被赋成 $k$。

两个方向一夹，`dis[v]` 恰好等于 $\delta(v)$。不过先别急着写"证毕"：下界方向的归纳在"$v$ 已被别人更早赋值"的分支上会偷偷引用尚未证完的结论，两条归纳线互相依赖。真正的收口要靠一条结构引理——**队列里的距离值单调**，于是出队顺序就是层序，按层推进的归纳才无循环依赖（引理 3 完整展开这段碰壁与修正）。

**第三步：三个答案量怎么取？** BFS 结束后 `dis` 数组就是全部信息。从左到右扫一遍（下标升序 = 编号升序）：遇到**严格更大**的距离就更新最大值、把编号记成当前下标、计数重置为 $1$；遇到**相等**的只加计数。"严格大于才换编号"保证了并列时留下的是**最先扫到的**（编号最小的）那个——题目要的平局规则被扫描顺序自动满足，不需要任何额外处理。

**第四步：一个必须记住的陷阱。** `dis` 是"未定义/不可达"语义的数组，全局 `int` 默认是 $0$——而 $0$ 在这里是**合法距离**（源点自己的距离）！不显式 `fill` 成 INF，所有没访问到的点都会被当成"距离 $0$ 的可达点"，BFS 的判重条件 `dis[v]==inf` 也会失效（每个点都"已访问"，队列里只有源点）。所以 `fill_n(dis,n,inf)` 一行是生死线，不是装饰。

**手造数据核对**（题面提示给了输出 `4 2 3` 但配图不可见，我按提示文字"谷仓 4,5,6 距 1 号都是 2"反推构造了一张吻合的图；另造四组打边界）：

| 输入 | 手算 | 输出 |

| `6 5` / 边 `1-2,1-3,2-4,2-5,3-6` | 距离：$2,3$ 号 $=1$；$4,5,6$ 号 $=2$；最远 $2$，并列取最小 $4$，共 $3$ 个（与提示文字一致） | `4 2 3` |

## 二、思维链：完整证明

**记号。** 谷仓内部编号 $0\le v<N$（读入时 `--u;--v`），源点 $s=0$。无向无权图 $G=(V,E)$。$\delta(v)$ 表示 $s$ 到 $v$ 的最短路径边数（不可达时 $\delta(v)=\infty$）。数组 `dis` 初值全为 `inf`（$1145141919$，远大于任何真实距离 $\le N-1$），`dis[s]=0`。队列 `que[hd..tl)`，初始只有 $s$。算法：当 `hd<tl` 时取出 $u=\texttt{que[hd++]}$，对每条边 $u\to v$，若 `dis[v]==inf` 则令 `dis[v]=dis[u]+1` 并把 $v$ 入队。结束后升序扫描 `dis` 提取三元组。

---

### 引理 1（上界：`dis` 永远不小于真实距离）

算法运行的任意时刻，对每个 $v$：若 $\texttt{dis}[v]\ne\texttt{inf}$，则存在一条 $s\to v$ 的、长度恰为 $\texttt{dis}[v]$ 的路径，从而 $\texttt{dis}[v]\ge\delta(v)$。

*证明*：对赋值次数归纳。初始只有 $\texttt{dis}[s]=0$，对应长度 $0$ 的平凡路径 ✓。设某次赋值前命题对所有点成立，此刻执行 $\texttt{dis}[v]\leftarrow\texttt{dis}[u]+1$。由归纳假设，存在长度 $\texttt{dis}[u]$ 的 $s\to u$ 路径 $P$；边 $(u,v)\in E$（赋值只在扫描 $u$ 的邻接表时发生），把这条边接在 $P$ 后面得到长度 $\texttt{dis}[u]+1=\texttt{dis}[v]$ 的 $s\to v$ 通路。通路包含路径（去掉环只会更短），故 $\delta(v)\le\texttt{dis}[v]$。又 `dis[v]` 只在 `dis[v]==inf` 时被赋值一次，之后不再改变，所以"任意时刻"的断言对已赋值的点持续成立。证毕。

---

### 引理 2（覆盖性：每个可达点恰好被发现一次、出队一次）

(a) 每个满足 $\delta(v)<\infty$ 的点都会被赋值并入队；(b) 每个点至多入队一次；(c) 每个入队的点恰好出队一次，且算法终止。

*证明*：(b) 入队只发生在 `dis[v]==inf` 分支里，赋值后 `dis[v]` 变为有限值且永不改回（引理 1 的赋值规则），故同一点不可能第二次满足入队条件 ✓。

(c) 每次循环 `hd` 加 $1$，入队总次数 $\le N$（由 (b)），故 `tl`$\le N$，循环至多执行 $N$ 次后 `hd==tl` 终止；每个入队元素被 `hd` 扫过恰好一次 ✓。

(a) 对 $\delta(v)$ 归纳。$\delta(v)=0$：只有 $s$ 自己（边数非负，长度 $0$ 的路径只能是平凡路径），初始已入队 ✓。设 $\delta(v)=k\ge1$，取一条最短路径，其倒数第二个点 $w$ 满足 $\delta(w)=k-1$（最短路的前缀也是最短路：若 $s\to w$ 有更短路径，接上边 $w\to v$ 就得到 $s\to v$ 的更短通路，与 $\delta(v)=k$ 矛盾）。由归纳假设 $w$ 被赋值入队，由 (c) $w$ 出队；出队时扫描 $w$ 的**全部**邻接边，包括 $w\to v$。此刻若 $v$ 已赋值则结论成立；否则当场赋值为 $\texttt{dis}[w]+1$ 并入队 ✓。证毕。

---

### 引理 3（下界与夹逼：终态 `dis[v]=δ(v)`）

算法终止后，对每个可达点 $v$ 有 $\texttt{dis}[v]=\delta(v)$；不可达点保持 `dis[v]==inf`。

*证明*：先说清一个**证明论层面的坑**，再给正式证明。

最朴素的尝试是两条独立归纳：一条证"每次赋值 $\texttt{dis}[v]=\texttt{dis}[u]+1\ge\delta(v)$"（引理 1 已完成），另一条证"$\delta(v)=k$ 的点会被前驱 $w$（$\delta=k-1$）赋成 $\le k$"。但第二条归纳在"$v$ 在 $w$ 出队前已被别人赋值"的分支上卡住：要断言那次更早的赋值也 $\le k$，就得对**赋值事件的时间序**再归纳，而事件序归纳又要用到"$w$ 何时出队"——两条归纳线互相引用对方尚未证完的部分，形成循环依赖。破局点是引入一条**结构引理**把时间钉死：队列里的距离值单调，于是"出队顺序 = 层序"，按层推进的归纳就不需要回头引用任何未证的事件。

**结构引理（队列单调性）**：任意时刻，队列 `que[hd..tl)` 中元素的 `dis` 值自队首到队尾非降，且队尾值 $\le$ 队首值 $+1$。

对操作归纳：初始队列 $[0]$，平凡。出队只删队首，不破坏。入队发生在 $u$ 刚出队之后，新值 $=\texttt{dis}[u]+1$：出队前队列所有值 $\in[\texttt{dis}[u],\texttt{dis}[u]+1]$（归纳假设，$u$ 是队首），删首后剩余元素仍 $\ge\texttt{dis}[u]$ 且非降；新值 $\texttt{dis}[u]+1$ 不小于一切剩余值，接在队尾保持非降；新队首（若存在）$\ge\texttt{dis}[u]$，故新队尾 $\le$ 新队首 $+1$ ✓。

**主证明**：对 $k\ge0$ 归纳命题 $P(k)$：当第 $k$ 层（$\delta=k$ 的点）全部出队完毕的时刻 $T_k$，(i) 所有 $\delta(v)\le k$ 的点都已赋值且值恰为 $\delta(v)$；(ii) 队列中恰是全体 $\delta=k+1$ 的点，值都是 $k+1$。

$P(0)$：$\delta=0$ 的点只有 $s$（路径边数非负），初始 $\texttt{dis}[s]=0$ ✓。$s$ 出队时给每个邻居赋 $1$；$s$ 的邻居 $\delta$ 恰为 $1$（有边直达故 $\le1$，不是 $s$ 故 $\ge1$），所以 (ii) 中"值 $1$ 的点都是 $\delta=1$"与"全体 $\delta=1$ 的点都已入队"同时成立 ✓。

$P(k-1)\Rightarrow P(k)$：由 $P(k-1)$(ii)，$T_{k-1}$ 时队列恰是全体 $\delta=k$ 的点、值都是 $k$。先补一个小断言：**任何时刻，值 $k$ 的点必 $\delta=k$**——引理 1 给 $\delta\le$ 值 $=k$；若 $\delta<k$，由 $P(k-1)$(i) 它早已赋成 $\delta<k$，而赋值唯一（引理 2(b)），值不可能再是 $k$，矛盾。于是本层出队的点值 $k$、$\delta=k$，出队时给尚未赋值的邻居赋 $k+1$。

任取 $\delta(v)=k+1$ 的点，其最短路前驱 $w$ 满足 $\delta(w)=k$，在本层出队。$w$ 扫描边 $w\to v$ 时：若 $v$ 未赋值，当场赋成 $k+1$ ✓；若 $v$ 已赋值，那次赋值只能来自某个值 $k$ 的点（值 $k-1$ 及更小的点赋的值 $\le k$，但引理 1 要求值 $\ge\delta(v)=k+1$，矛盾），故值也是 $k+1$ ✓。这说明全体 $\delta=k+1$ 的点在本层结束前都已赋成 $k+1$。反过来，本层新赋的点值 $k+1$，由小断言（把 $k$ 换成 $k+1$，论证相同：$\delta\le k+1$，若 $\delta\le k$ 则与 $P(k)$(i) 的"值 $=\delta$"冲突）其 $\delta=k+1$。故 $T_k$ 时 (i) 对 $\delta\le k$ 成立（归纳假设 + 本层出队点），(ii) 队列恰剩全体 $\delta=k+1$ 的点、值 $k+1$ ✓。

由引理 2(c) 算法终止；取 $k\ge$ 图的直径，$P(k)$ 给出**所有可达点终态 $\texttt{dis}[v]=\delta(v)$**。不可达点若被赋值，引理 1 给出 $s$ 到它的路径，与不可达矛盾，故保持 `inf`。证毕。

（复盘：队列单调性不是 BFS 正确性的"装饰品"，而是把两条互相依赖的归纳线解耦成单向分层归纳的关键桥梁——这正是"先碰壁、再修正"的价值所在。）

---

### 引理 4（哨兵语义：`inf` 必须显式填）

`dis` 的判重与"不可达"判定都依赖 `dis[v]==inf`。若省略 `fill_n(dis,n,inf)`，全局零初始化使所有点初始 `dis=0`，算法将只处理源点、其余点全部被误判为"已访问的距离 $0$ 点"。

*证明*：不 fill 时初始 `dis[v]=0≠inf` 对一切 $v$ 成立。源点出队扫描邻居时条件 `dis[v]==inf` 恒假，无任何赋值与入队，队列耗尽。终态所有 `dis=0`，扫描提取出"最远距离 $0$、编号 $1$、计数 $N$"——与任何 $N\ge2$ 的连通图的真答案（最远距离 $\ge1$）矛盾。故 fill 不可省略。另一方面 `inf`$=1145141919>N-1\ge\delta(v)$，真实距离永远不会撞上哨兵值，判重条件不会把可达点误判为不可达。证毕。

（这是"全局 `int` 默认 $0$ 不是 INF"陷阱的标准实例：$0$ 在本题是**合法距离**，静默错误不会崩溃、只会输出看似合理的答案。）

---

### 引理 5（扫描提取的三元组正确）

设终态 `dis` 如引理 3。扫描逻辑：`mx=-1,id=0,cnt=0`；对 $i=0..N-1$，跳过 `dis[i]==inf`；若 `dis[i]>mx` 则 `mx=dis[i],id=i,cnt=1`；否则若 `dis[i]==mx` 则 `++cnt`。则输出的 `(id+1,mx,cnt)` 满足：$mx=\max_{v\text{ 可达}}\delta(v)$，$id+1$ 是取到 $mx$ 的最小 1-based 编号，$cnt$ 是取到 $mx$ 的可达点数。

*证明*：对扫描前缀归纳不变量：处理完 $0..i$ 后，`mx` 是前缀中可达点 `dis` 的最大值（前缀无可见可达点时 $-1$），`id` 是前缀中**最小**的取到 `mx` 的下标，`cnt` 是前缀中取到 `mx` 的点数。初始 $-1,0,0$ 平凡。处理 $i$：不可达跳过，不变量保持 ✓；$\texttt{dis}[i]>mx$：新最大值唯一属于 $i$（前缀里没人到过这个值），`id=i,cnt=1` ✓；$\texttt{dis}[i]==mx$：最大值不变，取到者多一个，`id` 不动——由于扫描升序，`id` 仍是**最早**（最小）的取到者 ✓；$\texttt{dis}[i]<mx$：三个量都不动 ✓。取 $i=N-1$ 即全数组结论。连通口径下所有点可达且 $N\ge2$，故 $mx\ge1$，源点（$\texttt{dis}=0$）不会成为最大值，`id`$\ne0$，输出 `id+1` 即 1-based 编号。证毕。

---

### 引理 6（复杂度）

时间 $O(N+M)$，空间 $O(N+M)$。

*证明*：建图：每条无向边两次 `push_back`，$O(M)$。BFS：由引理 2(b)(c)，每点至多入队、出队各一次；出队时扫描其邻接表，总扫描量 $=\sum_v\deg(v)=2M$；每次扫描 $O(1)$（一次比较、可能一次赋值入队）。故 BFS $O(N+M)$。提取扫描 $O(N)$。总计 $O(N+M)$。空间：邻接表 $2M$ 个 `int` 加 $N$ 个 `vector` 头，`dis`、`que` 各 $N$，合计 $O(N+M)$。代入 $N=M=5\times10^4$：约 $1.5\times10^5$ 次基本操作，毫无压力。证毕。

---

### 定理

程序输出"距 $1$ 号谷仓的最短路径最大值、取到该值的最小谷仓编号、取到该值的谷仓个数"，时间 $O(N+M)$、空间 $O(N+M)$。

*证明*：引理 1 给出 `dis`$\ge\delta$ 的上界方向；引理 2 保证每个可达点恰好被发现、出队一次（算法良定义且终止）；引理 3 用队列单调性 + 分层归纳给出下界方向并夹逼出 `dis`$=\delta$，同时确认不可达点保持 `inf`；引理 4 说明哨兵必须显式填、且 `inf` 不与任何真实距离冲突；引理 5 保证升序扫描 + 严格大于更新的三元组恰是题目所求（平局取最小编号由扫描顺序自动满足）；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 剥掉捉迷藏背景：边无权，"距离"= 最短路径边数；题面"每两谷仓间有最短路径"暗示连通，不可达分支只作保险。
2. **consider easier version** — Floyd $O(N^3)=1.25\times10^{14}$ 死路；Dijkstra 的堆在边权全 $1$ 时退化为分层，确认不需要带权最短路。
3. **classic problem solution** — 单源 BFS：`dis[v]==inf` 判重、`dis[v]=dis[u]+1` 赋值、手写数组队列，$O(N+M)$。
4. **explore its property** — 正确性双向夹逼：赋值对应真实路径（`dis`$\ge\delta$）；队列单调 + 按层归纳（`dis`$\le\delta$）；两条朴素归纳线会循环依赖，分层推进才收口。
5. **reduce to easier problem** — 三元组（最小编号、最大距离、计数）归约为一次升序扫描：严格 `>` 才换编号，平局规则被扫描顺序自动满足。
6. **discuss by category** — 全局 `int` 默认 $0$ 是合法距离不是 INF，`dis` 必须显式 fill；$N\ge2$ 连通时源点距离 $0$ 成不了最大值，"算不算自己"不可观测。

| `m` | 边数 $M\le5\times10^4$ | `int` | 读入 |
| `mxn` | $50000+5$ | `constexpr int` | 约束 $+5$ |
| `inf` | 不可达哨兵 $1145141919$ | `constexpr int` | 远大于真实距离 $\le N-1$ |
| `graph[u]` | $u$ 的邻居列表（无向边存两份） | `vector<int>[mxn]` | 读入 `--u;--v` 后双向 `push_back` |
| `dis[v]` | $s=0$ 到 $v$ 的最短边数 | `int[mxn]` | **显式 `fill_n(dis,n,inf)`**，再 `dis[0]=0`；全局默认 $0$ 是合法距离，不 fill 必错 |
| `que[hd..tl)` | BFS 队列（手写数组） | `int[mxn]` | 初始 `que[0]=0,hd=0,tl=1`；每点至多入队一次，$N$ 格够用 |
| `hd,tl` | 队首 / 队尾后一格 | `int` | `hd==tl` 即空 |
| `mx` | 已扫描可达点的最大距离 | `int` | $-1$（保证源点的 $0$ 也能触发首次更新） |
| `id` | 取到 `mx` 的最小下标（0-based） | `int` | 严格 `>` 时才更新，输出 `id+1` |
| `cnt` | 取到 `mx` 的可达点数 | `int` | 新最大值重置 $1$，相等 `++` |

### 算法步骤

1. I/O 加速三行；读 `n,m`；每条边 `--u;--v` 后双向建邻接表。
2. `fill_n(dis,n,inf)`；`dis[0]=0`；源点入队。
3. BFS：`hd<tl` 时取 $u$，扫邻居，`dis[v]==inf` 则赋 `dis[u]+1` 并入队。
4. 升序扫描 `dis`：跳过 `inf`；严格更大则更新 `mx,id,cnt=1`；相等则 `++cnt`。
5. 输出 `id+1`、`mx`、`cnt`，空格分隔。

### 复杂度

- 时间：$O(N+M)$（每点进出队一次、每条边被扫两次）。
- 空间：$O(N+M)$（邻接表 $2M$ 个 `int`，`dis`/`que` 各 $N$）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；按题面提示文字反推的 $6$ 点图输出 `4 2 3` 与提示一致；另造最小规模、链、菊花、环+长尾四组手算数据全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2951 [USACO09OPEN] Hide and Seek S
// 无权无向图 BFS：dis=距 1 号谷仓的最短边数；再扫一遍求最大距离、最小编号、个数
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005},inf{1145141919};

int n,m,dis[mxn],que[mxn];
vector<int>graph[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,u,v;i<m;++i)
	{
		cin>>u>>v;--u;--v;
		graph[u].push_back(v);
		graph[v].push_back(u);
	}
	fill_n(dis,n,inf);	// 全局默认 0 是合法距离，必须显式置 INF
	dis[0]=0;
	int hd=0,tl=0;
	que[tl++]=0;
	while(hd<tl)
	{
		int u=que[hd++];
		for(int v:graph[u])
			if(dis[v]==inf)
			{
				dis[v]=dis[u]+1;
				que[tl++]=v;
			}
	}
	int mx=-1,id=0,cnt=0;
	for(int i=0;i<n;++i)
	{
		if(dis[i]==inf)	// 不可达不参与统计（题面保证连通，此分支只是保险）
			continue;
		if(dis[i]>mx)
		{
			mx=dis[i];id=i;cnt=1;
		}
		else if(dis[i]==mx)
			++cnt;
	}
	cout<<id+1<<' '<<mx<<' '<<cnt<<'\n';
	return 0;
}
```

### 代码说明

- **`fill_n(dis,n,inf)` 是生死线**：`dis` 兼作判重标记，全局默认 $0$ 会让所有点"看起来已访问"，BFS 只剩源点（引理 4）。这是"全局数组默认 $0$ 不是 INF"陷阱的直接应用。
- **手写数组队列**：每点至多入队一次（`dis[v]==inf` 判重保证），`que` 开 `mxn` 必然够用；`hd`/`tl` 两个 `int` 比 `std::queue` 更轻。
- **`mx` 初值 $-1$**：让源点的距离 $0$ 也能触发首次更新，扫描逻辑对"前缀暂无可达点"的边界统一成立；连通且 $N\ge2$ 时终态 $mx\ge1$，源点不会被计入答案。
- **严格 `>` 才更新 `id`**：升序扫描下并列最大值保留最先遇到的下标，恰好实现"编号最小"；`else if(==)` 只加计数。一个扫描同时产出三个答案量，无需排序或第二遍。
- 不可达点 `continue` 跳过：题面暗示连通，此分支是零成本保险，两种题意解读下行为一致。
- 输出 `id+1` 还原 1-based；`'\n'` 换行；边读入边 `--u;--v` 转 0-based，全程内部 0-based。
