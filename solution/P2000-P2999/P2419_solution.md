# P2419 [USACO08JAN] Cow Contest S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 头奶牛（$1\le N\le100$）的编程能力构成一个**严格全序**（没有并列）。给出 $M$ 场比赛结果（$1\le M\le4500$），每行 `A B` 表示 $A$ 赢了 $B$，即 $A$ 强于 $B$。结果保证不自相矛盾。问：**有多少头奶牛的名次可以被唯一确定**？

**第一步：把"名次确定"翻译成数学语言。** 真实排名我们不知道，只知道它必须与所有比赛结果相容。所以"奶牛 $i$ 的名次确定"意思是：

> 在**所有**与已知结果相容的排名里，$i$ 都排在同一个位置。

这不是"我们能算出完整排名"，也不是"$i$ 赢的场数已知"。把这句话写清楚之后，问题就变成了：**偏序的线性扩张中，某个元素的位置是否恒定**。

**第二步：建图，把"强于"的传递性用起来。** 每场比赛是一条有向边 $A\to B$（$A$ 强于 $B$）。"强于"是传递的：$A$ 赢 $B$、$B$ 赢 $C$，就必然有 $A$ 强于 $C$，哪怕它们没比过。所以已知的信息不只是 $M$ 条边，而是这些边的**传递闭包**：只要存在 $i\to\cdots\to j$ 的路径，就知道 $i$ 强于 $j$。

$N\le100$，$N^3=10^6$，**Floyd 传递闭包**正好合适（把 Floyd 的 `min(+,+)` 换成 `or(&&)` 即可）。

**第三步：猜判定条件。** 设闭包里有 $k$ 头牛强于 $i$、有 $l$ 头牛弱于 $i$。如果 $k+l=N-1$，也就是**其余每头牛都与 $i$ 可比**，那么任何相容排名里，$i$ 前面恰好是那 $k$ 头牛，名次必为 $k+1$——确定。

反过来，如果存在某头牛 $j$ 与 $i$ 不可比（既没有 $i\to j$ 也没有 $j\to i$ 的路径），名次还能确定吗？我先拿小例子试：

- **链**：$1\to2\to3$。闭包补出 $1\to3$，三头牛两两可比，答案 $3$。
- **星**：$1\to2$、$1\to3$。牛 $1$ 强于其余两头，名次必为 $1$，确定；牛 $2$ 与牛 $3$ 不可比，它们可以是 $(2,3)$ 也可以是 $(3,2)$，都不确定。答案 $1$。
- **只有一场**：$N=3$，$1\to2$。牛 $3$ 与谁都没比过，它可以排第 $1$、第 $2$、第 $3$；牛 $1$ 可以排第 $1$（$1>2>3$）也可以排第 $2$（$3>1>2$）；牛 $2$ 可以排第 $2$ 或第 $3$。答案 $0$。

这些例子都支持猜想：**确定 $\iff$ 与其余所有牛可比**。但"看起来对"不够——万一存在某种巧妙的约束，让不可比的两头牛的名次仍然被夹死呢？

**第四步：把反方向证出来（这是本题真正的思维关口）。** 我要证明：只要 $j$ 与 $i$ 不可比，就能造出两个相容排名，让 $i$ 的位置不同。

一开始我想用"交换 $i,j$"的说法，但仔细一想，**交换两个元素的位置不一定改变 $i$ 的名次编号**（还得看别人在哪），这个论证不严密。换个更硬的思路：**直接算出 $i$ 的名次能取到的最小值和最大值，并证明两端都能达到。**

记 $D_i=\{z:z\text{ 强于 }i\}$（闭包意义下），$U_i=\{z:i\text{ 强于 }z\}$。

- 任何相容排名里，$D_i$ 全部排在 $i$ 前面，$U_i$ 全部排在 $i$ 后面，所以
  $$|D_i|+1\ \le\ \mathrm{rank}(i)\ \le\ N-|U_i|.$$
- **下界可达**：把 $D_i$ 内部按任意相容顺序排好放最前，紧接着放 $i$，剩下的牛（与 $i$ 不可比的那些）再按它们内部的相容顺序排在后面。这个排法合法吗？关键是"剩下的牛里会不会有人必须排在 $D_i$ 中某头牛前面"——若 $r$ 强于 $d\in D_i$，则 $r$ 强于 $d$ 强于 $i$，由传递性 $r\in D_i$，矛盾。所以不会，构造合法，此时 $\mathrm{rank}(i)=|D_i|+1$。
- **上界可达**：对称地，把"非 $U_i$ 且非 $i$"的牛排前面，然后 $i$，最后 $U_i$。若某头前面的牛 $r$ 被 $U_i$ 中的 $u$ 强于（$u$ 强于 $r$），则 $i$ 强于 $u$ 强于 $r$，$r\in U_i$，矛盾。构造合法，$\mathrm{rank}(i)=N-|U_i|$。

于是 $i$ 的名次**恰好取遍** $[\,|D_i|+1,\ N-|U_i|\,]$ 中的某些值，而两端都可达。区间退化成一点 $\iff |D_i|+|U_i|=N-1 \iff$ 与其余所有牛可比。**充要条件证完了**，猜想成立，而且不是"看起来对"。

**第五步：落地成代码。** Floyd 求出 `f[i][j]`（$i$ 强于 $j$），然后对每头 $i$ 数一遍 `cnt = #{j≠i : f[i][j]||f[j][i]}`，`cnt==n-1` 就 `++ans`。

**几个实现细节 / 坑：**

1. **方向**：每行第一个数是**胜者**，所以 `f[u][v]=1`（`--u;--v` 转 0-based）。有趣的是，把全部边反向，答案的**计数**不变（可比性是对称的），但每头牛的具体名次会变——所以方向写反不会在这题暴露，仍要写对。
2. **`f[i][i]` 不要算进去**：数 `cnt` 时显式 `j!=i`。数据无矛盾 ⇒ 图无环 ⇒ `f[i][i]` 本来就是 $0$，但显式跳过更稳。
3. **$D_i$ 与 $U_i$ 不交**：这一点是"cnt = |D|+|U|"的前提。若两者相交（存在 $i$ 强于 $j$ 且 $j$ 强于 $i$），说明有环，与"结果不自相矛盾"冲突。所以 `f[i][j]||f[j][i]` 不会重复计数。
4. **全局 `bool` 默认 `false` 正好是"未知"**，本题不需要填 INF；但如果是多测就必须清空（本题单测）。
5. **重复比赛**：同一对牛可能比多次，`f[u][v]=1` 是幂等赋值，天然去重。
6. **$N=1$**：`cnt=0==n-1=0`，答案 $1$（只有一头牛，名次当然是第 $1$）。代码不需要特判。
7. **规模**：$N^3=10^6$，加上读入 $M\le4500$，远远够用。也可以对每个点做一次 DFS/BFS 求可达集（$O(N(N+M))$），但 Floyd 三行循环最省心。

**手造数据核对**（题面只给了样例解释，没有样例输入输出；下面第一组按解释反推）：

第一组，按 Hint 反推：$N=5$，牛 $2$ 输给 $1,3,4$、赢了 $5$，即
```
5 4
1 2
3 2
4 2
2 5
```
闭包补出 $1,3,4$ 都强于 $5$。牛 $2$：$3$ 头强于它 $+1$ 头弱于它 $=4=N-1$ ⇒ 名次必为 $4$；牛 $5$：$4$ 头强于它 ⇒ 名次必为 $5$；牛 $1,3,4$ 彼此不可比 ⇒ 不确定。答案 `2`，与解释"其他 $3$ 头奶牛的排名仍无法确定"完全吻合。

第二组，全链 $1\to2\to3\to4\to5$（`5 4 / 1 2 / 2 3 / 3 4 / 4 5`）：闭包补全所有对，答案 `5`。

第三组，$N=4$，`1 2 / 1 3 / 1 4 / 2 3 / 2 4`：牛 $1$ 强于所有（确定），牛 $2$ 输给 $1$、强于 $3,4$（确定），牛 $3$ 与牛 $4$ 不可比（都不确定），答案 `2`。

第四组，$N=3$ 只有 `1 2`：答案 `0`。第五组，`1 0`（一头牛零场比赛）：答案 `1`。

## 二、思维链：完整证明

**记号。** 顶点集 $V=\{0,\dots,N-1\}$（0-based 牛编号）。已知边集 $E=\{(u,v):\text{输入中 }u\text{ 胜 }v\}$。定义关系 $u\rightsquigarrow v$ 当且仅当图中存在 $u$ 到 $v$ 的有向路径（长度 $\ge1$），即 $E$ 的**传递闭包**；程序的 `f[u][v]` 就是要计算它。

称 $V$ 上的一个**排名**为一个双射 $\mathrm{rank}:V\to\{1,\dots,N\}$（等价于一个全序）。排名与数据**相容**指对每条 $(u,v)\in E$ 都有 $\mathrm{rank}(u)<\mathrm{rank}(v)$（强的排前面，名次数字小）。记全体相容排名为 $\mathcal L$。题面保证 $\mathcal L\ne\varnothing$。

奶牛 $i$ 的名次**可确定**指 $\{\mathrm{rank}(i):\mathrm{rank}\in\mathcal L\}$ 是单元素集。程序要输出可确定的奶牛数。

对 $i\in V$ 记
$$D_i=\{z\ne i:z\rightsquigarrow i\},\qquad U_i=\{z\ne i:i\rightsquigarrow z\}.$$

---

### 引理 1（无矛盾 $\Rightarrow$ 无环 $\Rightarrow$ 闭包是严格偏序）

题面"比赛结果保证不会自相矛盾"等价于 $\mathcal L\ne\varnothing$，由此可推出：

(a) 图 $(V,E)$ 无有向环；
(b) 关系 $\rightsquigarrow$ 非自反（$i\not\rightsquigarrow i$）、传递，因而 $D_i\cap U_i=\varnothing$，且 $D_i\cup U_i\subseteq V\setminus\{i\}$；
(c) $\rightsquigarrow$ 是 $V$ 上的严格偏序（非自反 + 传递 $\Rightarrow$ 反对称）。

*证明*：(a) 反设存在环 $v_1\to v_2\to\cdots\to v_k\to v_1$（$k\ge1$，边属于 $E$）。取任一相容排名 $\mathrm{rank}\in\mathcal L$，则 $\mathrm{rank}(v_1)<\mathrm{rank}(v_2)<\cdots<\mathrm{rank}(v_k)<\mathrm{rank}(v_1)$，得 $\mathrm{rank}(v_1)<\mathrm{rank}(v_1)$，矛盾。故无环。

(b) 非自反：若 $i\rightsquigarrow i$，则存在一条从 $i$ 回到 $i$ 的路径，即有环，与 (a) 矛盾。传递：若 $i\rightsquigarrow j$（路径 $P_1$）且 $j\rightsquigarrow k$（路径 $P_2$），把 $P_1$ 与 $P_2$ 首尾拼接得到 $i$ 到 $k$ 的游走，其中必含一条 $i$ 到 $k$ 的路径（去掉重复顶点形成的环即可），故 $i\rightsquigarrow k$。

不交：若 $z\in D_i\cap U_i$，则 $z\rightsquigarrow i$ 且 $i\rightsquigarrow z$，由传递性 $z\rightsquigarrow z$，与非自反矛盾。包含关系由定义（$z\ne i$）直接得到。

(c) 反对称：若 $i\rightsquigarrow j$ 且 $j\rightsquigarrow i$，则 $i\rightsquigarrow i$，矛盾；故两者不能同时成立，这正是严格偏序的反对称形式。证毕。

---

### 引理 2（相容排名 = 闭包偏序的线性扩张）

$\mathcal L$ 恰好是严格偏序 $(V,\rightsquigarrow)$ 的全部**线性扩张**（即把偏序扩展成全序的排名）。

*证明*：两个方向。

($\subseteq$) 设 $\mathrm{rank}\in\mathcal L$。若 $i\rightsquigarrow j$，则存在路径 $i=v_0\to v_1\to\cdots\to v_k=j$，每条边属于 $E$，故 $\mathrm{rank}(v_0)<\mathrm{rank}(v_1)<\cdots<\mathrm{rank}(v_k)$，得 $\mathrm{rank}(i)<\mathrm{rank}(j)$。所以 $\mathrm{rank}$ 保持闭包关系，是线性扩张。

($\supseteq$) 设 $\mathrm{rank}$ 是 $(V,\rightsquigarrow)$ 的线性扩张。因 $E\subseteq\rightsquigarrow$（每条边本身就是长度 $1$ 的路径），对每条 $(u,v)\in E$ 有 $u\rightsquigarrow v$，故 $\mathrm{rank}(u)<\mathrm{rank}(v)$，即 $\mathrm{rank}\in\mathcal L$。证毕。

**意义**：从此可以完全忘掉原始比赛，只在闭包偏序上推理；而"名次可确定"就是"该元素在所有线性扩张中位置相同"。

---

### 引理 3（Floyd 恰好算出传递闭包）

程序三重循环
```
for k: for i: if(f[i][k]) for j: if(f[k][j]) f[i][j]=1;
```
结束后，`f[i][j]`$=1\iff i\rightsquigarrow j$。

*证明*：先明确"路径的内部顶点"指除首尾外的顶点。对 $k$ 归纳证明命题 $P(k)$：**处理完外层第 $k$ 轮（即 $k'=0..k$ 都做完）后，`f[i][j]`$=1$ 当且仅当存在 $i\to j$ 的路径，其内部顶点全属于 $\{0,\dots,k\}$**（允许路径长度为 $1$，此时无内部顶点，条件空真）。

**基础 $P(-1)$（一轮未做）**：`f` 只被输入置位，`f[i][j]`$=1\iff(i,j)\in E\iff$ 存在长度为 $1$ 的路径（内部顶点集为空 $\subseteq\varnothing$）✓。注意 `f[i][i]` 初值为 `false`（全局 `bool` 默认 $0$），而由引理 1 无环，确实不存在 $i\to i$ 的路径 ✓。

**归纳 $P(k-1)\Rightarrow P(k)$**：第 $k$ 轮对每对 $(i,j)$ 执行 `f[i][j] |= f[i][k] && f[k][j]`（`if(f[i][k])` 只是跳过必然为假的更新，不改变语义）。

- **soundness（置位必有路径）**：若本轮把 `f[i][j]` 置 $1$，则 `f[i][k]` 与 `f[k][j]` 在本轮读取时为 $1$。注意本轮中 `f[i][k]`、`f[k][j]` 的值不会被第 $k$ 轮自身改变：更新 `f[i][k]` 需要 `f[i][k]&&f[k][k]`，而 `f[k][k]` 恒为 $0$（无环，且本轮也不会把它置 $1$，因为置 `f[k][k]` 需要 `f[k][k]&&f[k][k]`，初值 $0$ 无法自举）；同理 `f[k][j]` 不被改变。故由 $P(k-1)$，存在内部顶点 $\subseteq\{0..k-1\}$ 的路径 $i\to k$ 与 $k\to j$，拼接得到内部顶点 $\subseteq\{0..k\}$ 的 $i\to j$ 路径（$k$ 成为新的内部顶点；若拼接出现重复顶点，去掉其中的环仍是合法路径且内部顶点集不扩大）。
- **completeness（有路径必置位）**：设存在 $i\to j$ 路径，内部顶点 $\subseteq\{0..k\}$。若 $k$ 不是内部顶点，则内部顶点 $\subseteq\{0..k-1\}$，由 $P(k-1)$ 已有 `f[i][j]=1`，本轮不会清除（只做 `|=`）。若 $k$ 是内部顶点，把路径在 $k$ 处切成 $i\to k$ 与 $k\to j$ 两段，各自内部顶点 $\subseteq\{0..k-1\}$（$k$ 在两段中都是端点），由 $P(k-1)$ 得 `f[i][k]=f[k][j]=1`；这两个值本轮不变（上一段已证），故本轮把 `f[i][j]` 置 $1$。

于是 $P(k)$ 成立。取 $k=N-1$：内部顶点 $\subseteq\{0..N-1\}=V$ 是空条件，故 `f[i][j]`$=1\iff$ 存在 $i\to j$ 路径 $\iff i\rightsquigarrow j$。证毕。

### 引理 4（任何相容排名中 $i$ 的名次上下界）

对任意 $\mathrm{rank}\in\mathcal L$，
$$|D_i|+1\ \le\ \mathrm{rank}(i)\ \le\ N-|U_i|.$$

*证明*：由引理 2，$\mathrm{rank}$ 保持 $\rightsquigarrow$。对每个 $z\in D_i$ 有 $z\rightsquigarrow i$，故 $\mathrm{rank}(z)<\mathrm{rank}(i)$；这些 $z$ 互不相同且都不等于 $i$（引理 1(b)），所以排在 $i$ 前面的至少有 $|D_i|$ 头牛，$\mathrm{rank}(i)\ge|D_i|+1$。

对每个 $z\in U_i$ 有 $i\rightsquigarrow z$，故 $\mathrm{rank}(z)>\mathrm{rank}(i)$，即至少 $|U_i|$ 头牛排在 $i$ 后面，于是排在 $i$ 前面的至多 $N-1-|U_i|$ 头，$\mathrm{rank}(i)\le N-|U_i|$。证毕。

---

### 引理 5（有限偏序必有线性扩张）

任何有限严格偏序 $(W,\prec)$ 都存在线性扩张。

*证明*：对 $|W|$ 归纳。$|W|=0$ 时空排名即可。设 $|W|\ge1$。

**先证存在极小元**（没有元素严格小于它）：任取 $w_0\in W$，若不是极小元则存在 $w_1\prec w_0$；若 $w_1$ 不是极小元则存在 $w_2\prec w_1$……由传递性，$w_0,w_1,w_2,\dots$ 两两不同（若 $w_a=w_b$（$a<b$）则 $w_a\prec\cdots\prec w_a$，与非自反矛盾）。$W$ 有限，故该链必在有限步终止于某个极小元 $m$。

删去 $m$，$(W\setminus\{m\},\prec)$ 仍是严格偏序（非自反、传递性对子集继承），由归纳假设有线性扩张 $r'$。把 $m$ 放在最前面、其余按 $r'$ 排，得到 $W$ 的排名 $r$。验证：对任意 $a\prec b$，若 $a=m$ 则 $r(m)=1<r(b)$ ✓；若 $a,b\ne m$ 则由 $r'$ 保持 ✓；$b=m$ 不可能（$m$ 极小，没有元素 $\prec m$）。故 $r$ 是线性扩张。证毕。

### 引理 6（上下界都可达）

存在 $\mathrm{rank}^{\min},\mathrm{rank}^{\max}\in\mathcal L$ 使
$$\mathrm{rank}^{\min}(i)=|D_i|+1,\qquad \mathrm{rank}^{\max}(i)=N-|U_i|.$$

*证明*：**下界构造**。令 $R=V\setminus(D_i\cup\{i\})$（即与 $i$ 不可比的元素，加上 $U_i$）。分三段排：

1. 第一段：$D_i$，内部按 $(D_i,\rightsquigarrow)$ 的某个线性扩张排（引理 5 保证存在，子集继承严格偏序）；
2. 第二段：$i$；
3. 第三段：$R$，内部按 $(R,\rightsquigarrow)$ 的某个线性扩张排。

要验证这是 $(V,\rightsquigarrow)$ 的线性扩张，只需检查**所有跨段的偏序关系都朝前**（段内已由线性扩张保证）：

- $d\in D_i$ 与 $i$：$d\rightsquigarrow i$，$d$ 在前 ✓；反向 $i\rightsquigarrow d$ 不可能（否则 $i\rightsquigarrow d\rightsquigarrow i$ 成环）。
- $d\in D_i$ 与 $r\in R$：若 $r\rightsquigarrow d$，则由传递性 $r\rightsquigarrow d\rightsquigarrow i$，得 $r\in D_i$，与 $r\in R$ 矛盾。故只可能 $d\rightsquigarrow r$（朝前 ✓）或不可比（无约束 ✓）。
- $i$ 与 $r\in R$：若 $r\rightsquigarrow i$ 则 $r\in D_i$，矛盾；故只可能 $i\rightsquigarrow r$（朝前 ✓）或不可比 ✓。

三段拼接是 $V$ 的一个排名，且保持全部偏序关系，由引理 2 属于 $\mathcal L$。$i$ 前面恰有 $|D_i|$ 个元素，故 $\mathrm{rank}^{\min}(i)=|D_i|+1$。

**上界构造**（对称）。令 $R'=V\setminus(U_i\cup\{i\})$（含 $D_i$ 与不可比元素）。三段：$R'$（内部线性扩张）、$i$、$U_i$（内部线性扩张）。跨段检查：

- $r\in R'$ 与 $i$：若 $i\rightsquigarrow r$ 则 $r\in U_i$，矛盾；故只可能 $r\rightsquigarrow i$（朝前 ✓）或不可比 ✓。
- $i$ 与 $u\in U_i$：$i\rightsquigarrow u$，$i$ 在前 ✓。
- $r\in R'$ 与 $u\in U_i$：若 $u\rightsquigarrow r$，则 $i\rightsquigarrow u\rightsquigarrow r$，得 $r\in U_i$，矛盾。故只可能 $r\rightsquigarrow u$（朝前 ✓）或不可比 ✓。

同样得到 $\mathcal L$ 中的排名，$i$ 前面有 $|R'|=N-|U_i|-1$ 个元素，故 $\mathrm{rank}^{\max}(i)=N-|U_i|$。证毕。

### 引理 7（充要条件）

奶牛 $i$ 的名次可确定 $\iff |D_i|+|U_i|=N-1 \iff$ 对每个 $j\ne i$ 都有 $i\rightsquigarrow j$ 或 $j\rightsquigarrow i$（即 $i$ 与其余所有牛可比）。

*证明*：由引理 4，所有相容排名中 $\mathrm{rank}(i)$ 落在整数区间 $I=[\,|D_i|+1,\ N-|U_i|\,]$ 内；由引理 6，$I$ 的两个端点都被取到。

- 若 $|D_i|+|U_i|=N-1$，则 $|D_i|+1=N-|U_i|$，区间 $I$ 只含一个整数，故 $\mathrm{rank}(i)$ 在所有相容排名中恒为该值 ⇒ 可确定。
- 若 $|D_i|+|U_i|<N-1$，则 $|D_i|+1<N-|U_i|$，区间含至少两个整数，且两端点都可达 ⇒ 存在两个相容排名给 $i$ 不同名次 ⇒ 不可确定。

（由引理 1(b)，$D_i,U_i$ 是 $V\setminus\{i\}$ 的不交子集，故 $|D_i|+|U_i|\le N-1$，上面两种情形穷尽。）

第二个等价：$D_i\cup U_i=V\setminus\{i\}$ 当且仅当每个 $j\ne i$ 属于 $D_i$ 或 $U_i$，即 $j\rightsquigarrow i$ 或 $i\rightsquigarrow j$；而不交子集之并的大小等于 $N-1$ 当且仅当该并就是 $V\setminus\{i\}$（大小上界为 $N-1$）。证毕。

**注**：这条引理同时否掉了"只要赢的场数够多就能确定"之类的弱判据——星形例子里牛 $2$ 一场没赢、只输一场，但它的对手 $3$ 与它不可比，故不确定；判据必须是**可比性覆盖全部对手**。

---

### 引理 8（程序的计数正确）

程序对每头 $i$ 计算 `cnt`$=|\{j\ne i:\texttt{f[i][j]}\lor\texttt{f[j][i]}\}|$，则 `cnt`$=|D_i|+|U_i|$，且 `cnt==n-1` 恰是引理 7 的判定条件。

*证明*：由引理 3，`f[i][j]`$=1\iff i\rightsquigarrow j$。故被计数的 $j$ 集合为 $\{j\ne i:i\rightsquigarrow j\}\cup\{j\ne i:j\rightsquigarrow i\}=U_i\cup D_i$。由引理 1(b) 两者不交，故并的大小 $=|U_i|+|D_i|$，即 `cnt`。条件 `cnt==n-1` 就是 $|D_i|+|U_i|=N-1$。程序对满足者 `++ans`，故 `ans` 是可确定的奶牛数。证毕。

---

### 引理 9（边界与实现细节）

(a) $N=1$：`cnt`$=0=N-1$，答案 $1$。
(b) 重复边、$M$ 大于不同对数：`f[u][v]=1` 幂等，不影响闭包。
(c) 全局 `bool f` 默认 `false` 恰为"未知/不可达"，无需填 INF；`f[i][i]` 保持 `false`（引理 1 无环），计数时又显式跳过 `j==i`，双重保险。
(d) 把全部边反向不改变答案计数。

*证明*：(a) $V\setminus\{i\}=\varnothing$，$D_i=U_i=\varnothing$，$|D_i|+|U_i|=0=N-1$，由引理 7 可确定；直观上只有一头牛，名次必为 $1$。

(b) 闭包只依赖边集 $E$ 的**集合**语义（路径存在性），重复边不改变 $E$；布尔赋值 `f[u][v]=1` 对同一对多次执行结果相同。

(c) 全局静态数组零初始化，`bool` 的 $0$ 即 `false`，语义正是"尚未知道 $i$ 强于 $j$"，与"距离数组默认 $0$ 会被当成 $0$ 代价可达"那类坑不同——这里 $0$ 就是正确答案的一部分。`f[i][i]` 在 Floyd 中不会被置 $1$（引理 3 的 soundness 论证里已用到）。

(d) 反向后闭包关系变为原来的逆关系 $\rightsquigarrow^{-1}$，于是 $D_i,U_i$ 互换，$|D_i|+|U_i|$ 不变，由引理 7 判定结果不变。证毕。

---

### 引理 10（复杂度）

时间 $O(N^3+M+N^2)=O(N^3)$，空间 $O(N^2)$。

*证明*：读入 $M$ 条边 $O(M)$。Floyd 三重循环各 $N$ 次，内层 $O(1)$，共 $O(N^3)$（`if(f[i][k])` 剪枝只减少常数）。统计阶段每头牛扫 $N$ 个 $j$，共 $O(N^2)$。$N=100$ 时 $N^3=10^6$，实测 $0.04$ s 量级。空间：`f` 为 $105\times105$ 的 `bool` 数组 $\approx11$ KB，即 $O(N^2)$。证毕。

---

### 定理

程序输出的整数等于"名次可被唯一确定的奶牛数"。

*证明*：引理 1 保证闭包是严格偏序（无矛盾前提的使用）；引理 3 保证 `f` 就是闭包；引理 2 把"相容排名"等同于线性扩张；引理 4、5、6 给出名次的可达区间及其两端可达性；引理 7 得到充要判据；引理 8 说明程序计数与判据一致；引理 9 覆盖边界；引理 10 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "名次确定"= 在所有与数据相容的排名中位置恒定，不是"能算出完整排名"。
2. **explore its property** — "强于"是传递的 ⇒ 已知信息是 $M$ 条边的**传递闭包**，不是 $M$ 条边本身。
3. **classic problem solution** — $N\le100$ ⇒ Floyd 把 `min(+,+)` 换成 `or(&&)` 求传递闭包，$O(N^3)=10^6$。
4. **consider easier version** — 手玩链 / 星 / 单场三个小例子，猜出判据"与其余所有牛可比"。
5. **reduce to easier problem** — 把问题变成偏序线性扩张中元素位置是否恒定；记 $D_i$（强于它的）与 $U_i$（它强于的），名次被夹在 $[|D_i|+1,\ N-|U_i|]$。
6. **classic problem solution** — 构造性证明两端可达（$D_i$ 前置 / $U_i$ 后置，用传递性排除跨段逆序），得到**充要**条件 $|D_i|+|U_i|=N-1$。
7. **discuss by category** — 计数时 `j!=i`；$D_i\cap U_i=\varnothing$ 依赖无矛盾；$N=1$、重复边、边反向都不需要特判。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N$ | 奶牛数，$\le100$ | `int n` | 读入 |
| $M$ | 比赛场数，$\le4500$ | `int m` | 读入 |
| `f[i][j]` | $i$ 是否强于 $j$（**闭包**，直接或间接） | `bool[mxn][mxn]` | 全局默认 `false`；读入时置直接边；Floyd 后为闭包 |
| `mxn` | $100+5=105$ | `constexpr int` | 数组尺寸 |
| `u,v` | 一场比赛的胜者、败者（读入后转 0-based） | `int` | **第一个数是胜者** |
| `k,i,j` | Floyd 的中间点、起点、终点 | `int` | `k` 必须在最外层 |
| `cnt` | 与 $i$ 可比的其它牛数 $=|D_i|+|U_i|$ | `int` | 每头牛重置 $0$ |
| `ans` | 名次可确定的奶牛数 | `int` | 全局默认 $0$ |
| $D_i,U_i$ | 闭包中强于 $i$ / 弱于 $i$ 的牛集合 | 概念量 | 不交（无矛盾保证），代码里不显式存 |

### 算法步骤

1. I/O 加速三行。
2. 读 $N,M$；对每场比赛读 `u,v`，`--u;--v`，`f[u][v]=1`。
3. Floyd 传递闭包：`for k=0..N-1` → `for i=0..N-1`（`if(f[i][k])` 剪枝）→ `for j=0..N-1`，若 `f[k][j]` 则 `f[i][j]=1`。
4. 对每头 $i$：`cnt=0`；扫 $j=0..N-1$，若 `j!=i&&(f[i][j]||f[j][i])` 则 `++cnt`；若 `cnt==n-1` 则 `++ans`。
5. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(N^3+M+N^2)=O(N^3)$，$N=100$ 时约 $10^6$ 次布尔运算。
- 空间：$O(N^2)$（`bool f[105][105]`，约 $11$ KB）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；按样例解释反推的 $5$ 牛 $4$ 场数据输出 `2`，与解释一致；另造全链（`5`）、部分序（`2`）、单场（`0`）、$N=1$（`1`）等 $8$ 组手算数据全对；$308$ 组随机小数据（$N\le7$，随机真实排名 + 随机密度 $10\%\sim100\%$ 的边，含重复边）与"枚举全部 $N!$ 个排列、筛出相容排名、看每头牛位置是否唯一"的暴力一致；另加 $20$ 组 $N=8,9$ 的同款对拍，合计 $328$ 组 $0$ mismatch；$N=100,M=4500$ 极限数据运行 $0.042$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2419 [USACO08JAN] Cow Contest S
// 思路：Floyd 求「强于」关系的传递闭包 f[i][j]。
//       牛 i 的名次确定 ⇔ 它与其余每头牛都可比（f[i][j]||f[j][i]）。
//       证明：名次被夹在 [|D_i|+1, N-|U_i|]，且两端都能构造出相容排名达到，
//             故区间退化为一点 ⇔ |D_i|+|U_i|=N-1。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n,m,ans;
bool f[mxn][mxn];	// f[i][j]=1 表示 i 强于 j（直接或间接）

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,u,v;i<m;++i)
	{
		cin>>u>>v;--u;--v;
		f[u][v]=1;			// 胜者在前
	}
	for(int k=0;k<n;++k)		// Floyd 传递闭包
		for(int i=0;i<n;++i)
			if(f[i][k])
				for(int j=0;j<n;++j)
					if(f[k][j])
						f[i][j]=1;
	for(int i=0;i<n;++i)
	{
		int cnt=0;
		for(int j=0;j<n;++j)
			if(j!=i&&(f[i][j]||f[j][i]))
				++cnt;
		if(cnt==n-1)			// 与其余每头牛都可比 ⇒ 排名唯一
			++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **Floyd 的 `k` 必须在最外层**：引理 3 的归纳正是按"允许使用的中间点集合 $\{0..k\}$"逐层扩张，`k` 放内层会漏掉路径。
- `if(f[i][k])` 是纯剪枝：`f[i][k]` 为假时内层不可能置位任何 `f[i][j]`，跳过不影响正确性（引理 3 已论证本轮不会改变 `f[i][k]`、`f[k][j]`）。
- `bool f` 全局默认 `false` 正是"未知"，**不需要**像距离数组那样填 INF；`f[i][i]` 也不会被置真（无环）。
- 计数时 `j!=i` 显式排除自己；`f[i][j]||f[j][i]` 不会重复计数，因为无矛盾保证 $D_i\cap U_i=\varnothing$（引理 1）。
- `cnt==n-1` 而不是 `cnt==n`：自己不算对手。$N=1$ 时 `cnt=0==n-1`，答案 $1$，无需特判。
- 重复比赛、边反向都不影响答案（引理 9），但读入方向仍按题面"第一个数是胜者"写。
- 换行用 `'\n'`。
