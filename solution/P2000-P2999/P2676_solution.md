# P2676 [USACO07DEC] Bookshelf B — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 头奶牛（$1\le N\le20000$），身高 $H_i$（$1\le H_i\le10000$），总和 $S$。书架高 $B$，保证 $1\le B\le S<2\,000\,000\,007$。奶牛叠塔，塔高 = 塔中奶牛身高之和，要 $\ge B$ 才够到书架顶。求**最少用几头奶牛**。

**第一反应：贪心，先挑最高的。** 要让奶牛数最少，直觉就是"每头都尽量高"，于是从高到矮排序，一头一头往上加，加到总高 $\ge B$ 就停，数一下用了几头。这个直觉对不对？得证。

**第二步：为什么"取最高的 $k$ 头"是对的？** 关键观察：答案只关心"选出的奶牛身高之和"，不关心具体选了谁。那么固定用 $k$ 头时，**哪 $k$ 头的和最大**？显然是最高的 $k$ 头。用交换论证：如果某个 $k$ 头方案里有一头矮牛 $l$，而外面还有一头比它高的牛 $j$ 没被选，把 $l$ 换成 $j$，和只会变大（$H_j\ge H_l$）。不断换下去，最终必然换成"最高的 $k$ 头"，且每一步和不减。所以**最高的 $k$ 头之和 $T_k$ 是所有 $k$ 头方案里的最大和**。

于是：用 $k$ 头能够到书架 $\iff T_k\ge B$（因为 $T_k$ 是 $k$ 头能达到的最大和，它都 $<B$ 的话别的 $k$ 头方案更不行）。又因为每头身高 $\ge1$，$T_k$ 随 $k$ **严格递增**，所以"够得到"的 $k$ 构成一个后缀区间，最小的那个就是**第一个使 $T_k\ge B$ 的 $k$**。贪心扫描排序后的数组、累加到 $\ge B$ 停，数的正是这个 $k$。直觉被严格证明了。

**第三步：值域——那个吓人的 $2\,000\,000\,007$。** 题面把 $S$ 的上界设成 $2\,000\,000\,007$，很贴近 `int` 上限 $2\,147\,483\,647$。算一下：所有部分和都 $\le S<2\,000\,000\,007<2^{31}-1$，所以其实 `int` 装得下。但上界贴得这么近，为了彻底安心，我用 `i64` 存 `B` 和累加和 `sum`（身高 `h[]` 仍 `int`，$\le10000$）。这样无论怎么加都不会溢出。实际上 $N\le20000,H_i\le10000$ 时 $S\le2\times10^8$，远没到 $2\times10^9$，题面那个上界是宽松写的。

**第四步：边界。** $B\le\max H_i$ 时第一头就够，答案 $1$；$B=S$ 时要全部 $N$ 头；$N=1$ 时 $B\le S=H_1$，答案 $1$。贪心循环 `for(i=0;i<n&&sum<B;++i)` 天然处理这些：`sum<B` 控制何时停，`i<n` 保证不越界（题目保证 $B\le S=T_N$，所以一定在 $i<n$ 内停下）。

**手造数据核对**（题面只给了"输入说明/输出说明"，没给具体样例输入输出，我按说明造一组）：

说明里讲：$6$ 头牛、$B=40$、身高在 $6\dots19$ 之间，且 $18+11+13=42\ge40$ 是一种 $3$ 头的方案。我造身高 $\{6,8,11,13,18,19\}$（含 $18,11,13$，$6$ 头，都在 $[6,19]$，$S=75\ge40$）。从高到矮：$19,18,13,11,8,6$，前缀和 $19,37,50$。前 $2$ 头和 $37<40$，前 $3$ 头和 $50\ge40$，故答案 $3$——与说明"只用 $3$ 头"一致（说明给的是 $18+11+13$，贪心给的是 $19+18+13$，都是 $3$ 头，答案相同）。

另造边界：$N=1,H=5,B=5\to1$；$\{2,2,2,2\},B=5\to3$（$2+2=4<5$，$2+2+2=6\ge5$）；$B=1\to1$；$N=20000$ 全 $10000$、$B=S=2\times10^8\to20000$，$B=199990000\to19999$。程序输出全部吻合。

## 二、思维链：完整证明

**记号。** 身高降序排列后为 $h_1\ge h_2\ge\dots\ge h_N\ge1$。前缀和 $T_k=\sum_{i=1}^{k}h_i$，$T_0=0$，$T_N=S$。$B$ 满足 $1\le B\le S$。一个方案是选一个下标子集 $U\subseteq\{1..N\}$，塔高 $\sum_{i\in U}h_i$，可行当且仅当 $\ge B$，代价 $|U|$。答案 $=\min\{|U|:\sum_{i\in U}h_i\ge B\}$。

---

### 引理 1（最高的 $k$ 头最大化 $k$ 头之和）

对任意 $k$（$0\le k\le N$）与任意 $k$ 元子集 $U$，$\sum_{i\in U}h_i\le T_k$。即 $T_k=\max_{|U|=k}\sum_{i\in U}h_i$。

*证明*：交换论证。若 $U=\{1..k\}$ 则等号成立。否则存在 $j\le k$ 但 $j\notin U$，以及 $l>k$ 但 $l\in U$（因为 $|U|=k$，$U$ 缺了前 $k$ 个里的某个，必然多占了后面的某个）。由降序 $h_j\ge h_l$。令 $U'=(U\setminus\{l\})\cup\{j\}$，则 $|U'|=k$ 且 $\sum_{i\in U'}h_i=\sum_{i\in U}h_i-h_l+h_j\ge\sum_{i\in U}h_i$。每次交换把 $U$ 中"前 $k$ 个下标"的个数加 $1$，至多 $k$ 次后 $U=\{1..k\}$，且全程和不减。故 $\sum_{i\in U}h_i\le T_k$。证毕。

---

### 引理 2（前缀和严格递增，可行性是后缀）

$T_k-T_{k-1}=h_k\ge1>0$，故 $T_0<T_1<\dots<T_N=S$。从而 $\{k:T_k\ge B\}$ 是一个后缀 $\{k^\*,k^\*+1,\dots,N\}$，其中 $k^\*=\min\{k:T_k\ge B\}$ 存在（因 $T_N=S\ge B$）。

*证明*：$T_k=\sum_{i=1}^k h_i$，故 $T_k-T_{k-1}=h_k\ge1$（题面 $H_i\ge1$），严格递增。$T_N=S\ge B$ 保证集合非空；$T_0=0<B$（$B\ge1$）保证 $k^\*\ge1$。严格递增序列一旦 $\ge B$ 便永远 $\ge B$，故可行 $k$ 构成后缀，最小元 $k^\*$ 存在唯一。证毕。

---

### 引理 3（答案 = $k^\*$）

最少奶牛数 $=k^\*=\min\{k:T_k\ge B\}$。

*证明*：分两步。

**可行（$\le k^\*$）**：取 $U=\{1..k^\*\}$（最高的 $k^\*$ 头），塔高 $T_{k^\*}\ge B$，代价 $k^\*$，故答案 $\le k^\*$。

**最优（$\ge k^\*$）**：设任意可行方案 $U$，$|U|=c$，$\sum_{i\in U}h_i\ge B$。由引理 1，$T_c\ge\sum_{i\in U}h_i\ge B$，故 $c$ 是可行 $k$，由引理 2 的后缀性 $c\ge k^\*$。故答案 $\ge k^\*$。

双向夹逼得答案 $=k^\*$。证毕。

**失败条件剖析（反证视角）**：若贪心不取最高的而取某头矮牛，相当于用了一个 $c$ 元子集 $U\ne\{1..c\}$，其和 $<T_c$（引理 1 的交换严格增大，除非 $U$ 已是前 $c$ 个）。于是可能 $T_c\ge B$ 但 $\sum_U h_i<B$，导致同样 $c$ 头却够不到，被迫多用牛——这正是"取最高"避免的失败模式。引理 1 保证取最高时这个失败模式不存在。

---

### 引理 4（贪心扫描计算 $k^\*$）

程序 `sort` 降序后，`for(i=0;i<n&&sum<B;++i){sum+=h[i];++ans;}` 结束时 `ans`$=k^\*$。

*证明*：循环第 $t$ 次迭代（$t$ 从 $1$）把 $h_t$（0-based 的 `h[t-1]`）加入 `sum`，故第 $t$ 次后 `sum`$=T_t$、`ans`$=t$。循环条件 `sum<B` 即 $T_{t-1}<B$ 时继续。由引理 2，$T_0=0<B$，故至少进入第一次；当首次 $T_t\ge B$（即 $t=k^\*$）时，该次迭代把 `ans` 增到 $k^\*$、`sum` 增到 $T_{k^\*}\ge B$，下一次条件 `sum<B` 为假退出。故 `ans`$=k^\*$。`i<n` 保证不越界：因 $T_N=S\ge B$，$k^\*\le N$，循环必在 $i<N$ 内停止。证毕。

---

### 引理 5（值域：`i64` 安全，`int` 其实也够）

所有部分和 $\le S<2\,000\,000\,007<2^{31}-1$，`int` 可容纳；用 `i64` 存 `B,sum` 更保险。身高 `h[i]`$\le10000$ 用 `int`。

*证明*：`sum` 单调增且最终 $\le T_N=S<2\,000\,000\,007$。`int` 上限 $2^{31}-1=2\,147\,483\,647>2\,000\,000\,007$，故 `int` 不溢出。但上界仅差约 $1.47\times10^8$，余量小，用 `i64`（上限 $9.2\times10^{18}$）彻底消除隐患。每次 `sum+=h[i]` 中 `h[i]`$\le10000$，`sum`$\le S$，和 $\le S+10000$ 仍远小于 `i64` 上限。实际上 $N\le20000,H_i\le10000\Rightarrow S\le2\times10^8$，题面 $2\times10^9$ 上界是宽松的。证毕。

---

### 引理 6（复杂度）

时间 $O(N\log N)$（排序主导），空间 $O(N)$。

*证明*：`sort` 降序 $O(N\log N)$；扫描至多 $N$ 次 $O(N)$；读入 $O(N)$。合计 $O(N\log N)$。`h[]` 占 $O(N)$ 个 `int`（$20005\times4\approx80$ KB）。证毕。$N=20000$ 时约 $20000\times15\approx3\times10^5$ 次比较，远低于时限。

---

### 定理

程序输出够到书架顶所需的最少奶牛数 $k^\*$，时间 $O(N\log N)$，空间 $O(N)$。

*证明*：引理 1 证明最高 $k$ 头之和最大，引理 2 证明前缀和严格递增、可行性是后缀，引理 3 证明答案 $=k^\*=\min\{k:T_k\ge B\}$，引理 4 证明贪心扫描恰计算 $k^\*$，引理 5 保证值域安全，引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 目标只依赖"选中身高之和"，与具体选谁无关；固定头数 $k$ 时只需最大化和。
- **classic problem solution** — 贪心"先取最大" + 降序排序：最高的 $k$ 头之和 $T_k$ 是 $k$ 头方案的最大和。
- **explore its property** — 交换论证证明前缀最优；$H_i\ge1\Rightarrow T_k$ 严格递增 ⇒ 第一个 $T_k\ge B$ 的 $k$ 即答案。
- **discuss by category** — $B\le\max H\to1$、$B=S\to N$、$N=1\to1$；$S$ 上界贴近 $2^{31}$，用 `i64` 存和保险。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 奶牛数（$\le20000$） | `int`，读入 | 0-based 下标 |
| `B` | 书架高度（$\le S$） | `i64`，读入 | 目标阈值 |
| `h[i]` | 第 $i$ 头身高（$\le10000$） | `int[mxn]`，读入后降序排序 | "从高到矮" |
| `sum` | 已选奶牛身高和（前缀和 $T_k$） | `i64`，初值 $0$ | 单调增，$\le S$ |
| `ans` | 已选奶牛数 | `int`，初值 $0$ | 答案 $k^\*$ |
| `mxn` | $20000+5$ | `constexpr int{20005}` | +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 `n,B`；读 `h[0..n-1]`。
3. `sort(h,h+n,greater<>())` 降序。
4. `sum=0,ans=0`；`for(i=0;i<n&&sum<B;++i){sum+=h[i];++ans;}`。
5. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(N\log N)$，$N=20000$ 时约 $3\times10^5$ 次比较。
- 空间：$O(N)$，`h[]` 约 $80$ KB。
- 值域：部分和 $\le S<2\times10^9$，`i64` 安全（引理 5）。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；按题面说明造 $6$ 头 $\{6,8,11,13,18,19\},B=40\to3$（与"只用 $3$ 头"一致）；另造 $N=1$、$\{2,2,2,2\}B=5$、$B=1$、$N=20000$ 全 $10000$ 的 $B=S$ 与 $B=S-10000$ 边界，输出全对。普及-贪心题，未写对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2676 [USACO07DEC] Bookshelf B
// 思路：降序排序，贪心取最高的牛直到身高和 >= B。
//       最高的 k 头之和 T_k 是 k 头方案的最大和（交换论证）；
//       H_i>=1 ⇒ T_k 严格递增 ⇒ 第一个 T_k>=B 的 k 即最少头数。
//       S<2e9 贴近 int 上限，用 i64 存 B 与 sum 保险。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{20005};

int n,h[mxn];
i64 B,sum;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>B;
	for(int i=0;i<n;++i)
		cin>>h[i];
	sort(h,h+n,greater<>());	// 从高到矮
	int ans=0;
	for(int i=0;i<n&&sum<B;++i)
	{
		sum+=h[i];
		++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`greater<>()` 降序**：贪心要先取最高的牛，透明比较器 `greater<>` 一行搞定降序排序。
- **循环条件 `i<n&&sum<B`**：`sum<B` 决定何时够到书架顶就停；`i<n` 防越界。题目保证 $B\le S=T_N$，所以一定在 $i<n$ 内停下，`ans` 即最少头数（引理 4）。
- **`i64 B,sum`**：$S$ 上界 $2\,000\,000\,007$ 贴近 `int` 上限，用 `i64` 彻底免溢出；`h[]` 仍 `int`（$\le10000$），`sum+=h[i]` 自动提升为 `i64` 运算。
- **0-based**：读入、排序、扫描全程 0-based，答案 `ans` 是头数（不是下标），直接输出，无需 `+1`。
- 全局 `sum` 默认 $0$，单测无需清空；`ans` 局部初值 $0$。
