# P2728 [USACO3.2] 纺车的轮子 Spinning Wheels — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 五个同心不透明轮子，每个轮子边缘有若干缺口（弧）。第 $i$ 个轮子转速 $\omega_i$ 度/秒（$1\le\omega_i\le180$，整数），有 $n_i\le5$ 个缺口，每个缺口用「起始角 $\theta$、宽度 $\varphi$」描述。$t=0$ 时所有轮子的 $0$ 度标记对齐。轮子沿角度增大方向转，角度对 $360$ 取模。求**最早的整数秒 $t$**，使得存在某个角度 $\alpha$，五个轮子在 $\alpha$ 处**都是缺口**（一束光能穿过五层）；若永远不可能，输出 `none`。所有角度、宽度、转速都是整数。

标签是「模拟」，方向明确：直接按秒模拟。但动手前有三个必须先抠清楚的点，否则模拟会静默出错。

**第一步：把「光能穿过」翻译成集合语言。** 一个轮子在某一时刻，边缘上哪些角度是「透光」的？就是它所有缺口覆盖的角度之并。记第 $i$ 轮在时刻 $t$ 的透光角度集合为 $O_i(t)\subseteq\{0,1,\dots,359\}$。光能穿过 $\iff$ 存在一个角度同时属于五个集合 $\iff$

$$O_0(t)\cap O_1(t)\cap O_2(t)\cap O_3(t)\cap O_4(t)\ne\varnothing.$$

于是整道题塌缩成：**对每个 $t$，求五个 $360$ 元集合的交，判空**。集合只有 $360$ 个元素，用 `bitset<360>` 表示，交集就是按位与，判空就是 `.any()`——这是最自然的实现。

**第二步：宽度到底覆盖几个角度？（本题第一个坑）** 题面专门强调：

> 宽度也包含缺口起始和终止的角度，即 `0 179` 包括 $[0,179]$ 共计 $180$ 个角度。

也就是说宽度 $\varphi$ 的缺口覆盖 $\theta,\theta+1,\dots,\theta+\varphi$，共 $\varphi+1$ 个整数角度，**两端都算**。如果误写成「覆盖 $\varphi$ 个角度」（$d$ 从 $0$ 到 $\varphi-1$），每个缺口少算一个角度，恰好卡在边界上的对齐就会被漏掉。我用手造数据专门验证了这一点（见下）。

**第三步：时刻 $t$ 时缺口转到哪了？** 轮子沿角度增大方向转，$t$ 秒转过 $\omega_i t$ 度。所以 $t=0$ 时在角度 $\beta$ 的缺口边缘点，$t$ 秒后到了 $(\beta+\omega_i t)\bmod360$。于是

$$O_i(t)=\bigl\{(\theta_{ij}+d+\omega_i t)\bmod360:\ 0\le j<n_i,\ 0\le d\le\varphi_{ij}\bigr\}.$$

直接对每个 $t$、每个轮子、每个缺口、每个 $d$ 把对应位置标记成 $1$ 即可。

**第四步：要模拟到什么时候？（本题第二个坑）** 时间无上界，难道要一直模拟下去？关键观察：**配置是周期的**。因为 $\omega_i$ 是整数，

$$\omega_i(t+360)=\omega_i t+360\omega_i\equiv\omega_i t\pmod{360},$$

所以每个轮子在 $t+360$ 秒的位置与 $t$ 秒**完全相同**，五个集合的交也相同。于是「最早对齐时刻」若存在，一定落在 $[0,359]$ 内（任何 $t\ge360$ 都能减去 $360$ 得到一个更早且同样对齐的时刻）。**只需枚举 $t=0,1,\dots,359$；这 $360$ 秒都不行，就永远不行，输出 `none`。** 这一步把「无限时间」变成了「有限 $360$ 次检查」。

**第五步：$t=0$ 算不算？** 算。题面「设时间为 $0$」，若起始就对齐，答案是 $0$。循环从 $t=0$ 开始即可。

**实现选型。** 每轮用一个 `bitset<360> b`（默认全 $0$）标记透光角度，再用一个 `cur`（初值全 $1$）逐轮 `cur&=b`。五轮交完 `cur.any()` 非空就输出 $t$。每个缺口标记 $\varphi+1$ 个位；由于同一轮上缺口之间至少隔 $1$ 度，各缺口覆盖的角度互不重叠，故每轮每秒最多标记 $360$ 个位，总量 $360\times5\times360\approx6.5\times10^5$，远低于时限。

**手造数据核对**（题面只给了「样例解释」，没有给样例输入输出，我按解释反推了一组输入，再另造两组打边界）：

第一组，按样例解释反推。解释说到 $9$ 秒时五个缺口分别处于 $[270,30],[240,330],[240,330],[90,270],[270,330]$。我构造输入：

```
30 1 0 120
50 1 150 90
60 1 60 90
70 1 180 180
90 1 180 60
```

逐轮核对 $t=9$：
- 轮 1：$\omega=30$，缺口 $[0,120]$，转 $270$ → $[270,390]\equiv[270,30]$（跨 $0$ 回绕）✓
- 轮 2：$\omega=50$，缺口 $[150,240]$，转 $450\equiv90$ → $[240,330]$ ✓
- 轮 3：$\omega=60$，缺口 $[60,150]$，转 $540\equiv180$ → $[240,330]$ ✓
- 轮 4：$\omega=70$，缺口 $[180,360]$，转 $630\equiv270$ → $[450,630]\equiv[90,270]$ ✓
- 轮 5：$\omega=90$，缺口 $[180,240]$，转 $810\equiv90$ → $[270,330]$ ✓

五段交：$[270,30]\cap[240,330]=[270,330]$，再交 $[240,330]$ 不变，再交 $[90,270]=\{270\}$，再交 $[270,330]=\{270\}$，非空。程序输出 `9`，与解释吻合（且程序确认 $0\sim8$ 秒都不行）。注意轮 4 宽度 $180$ 覆盖 $181$ 个角度、轮 1 跨 $0$ 回绕，都被「$d$ 取 $0..\varphi$ 再 $\bmod360$」自动处理。

第二组，专打 `none`：五轮转速都为 $1$，缺口分别在 $0,90,180,270,45$ 度、宽度都 $0$。它们像刚体一起转，相对位置永远不变，五个单点永不重合 → 输出 `none`。

第三组，专打 $t=0$：五轮缺口都在 $0$ 度、宽度 $0$，转速任意。起始就对齐 → 输出 `0`。

这三组把「宽度含两端」「跨 $0$ 回绕」「周期判无解」「$t=0$」四个易错点全覆盖了。

## 二、思维链：完整证明

**记号。** 角度集合 $\mathbb Z_{360}=\{0,1,\dots,359\}$，加法均 $\bmod360$。第 $i$ 轮（$0\le i<5$）转速 $\omega_i\in[1,180]$，缺口 $j$（$0\le j<n_i\le5$）起始角 $\theta_{ij}$、宽度 $\varphi_{ij}$，均为 $[0,359]$ 内整数。定义第 $i$ 轮 $t$ 秒的透光集合

$$O_i(t)=\bigcup_{j=0}^{n_i-1}\bigl\{(\theta_{ij}+d+\omega_i t)\bmod360:\ 0\le d\le\varphi_{ij}\bigr\}.$$

程序对每个整数 $t\in[0,359]$ 计算 $C(t)=\bigcap_{i=0}^{4}O_i(t)$，输出首个使 $C(t)\ne\varnothing$ 的 $t$，否则输出 `none`。

---

### 引理 1（宽度语义：缺口覆盖 $\varphi+1$ 个角度）

宽度为 $\varphi$、起始角 $\theta$ 的缺口，在 $t=0$ 时覆盖的角度集合恰为 $\{\theta,\theta+1,\dots,\theta+\varphi\}\bmod360$，共 $\varphi+1$ 个不同角度（当 $\varphi\le359$）。

*证明*：题面明确「宽度包含起始和终止角度」，并以 `0 179` 覆盖 $[0,179]$ 共 $180$ 个角度为例。把该例一般化：起始 $\theta$、宽度 $\varphi$ 的缺口，其终止角为 $\theta+\varphi$，覆盖从 $\theta$ 到 $\theta+\varphi$ 的**所有整数角度（含两端）**，即 $\theta+d$（$d=0,1,\dots,\varphi$），共 $\varphi+1$ 个。因 $\varphi\le359<360$，这 $\varphi+1$ 个连续整数 $\bmod360$ 后互不相同（连续 $\le360$ 个整数模 $360$ 不重复），故确为 $\varphi+1$ 个不同角度。证毕。

**推论（实现）**：标记循环必须写 `for(d=0;d<=phi;++d)`（含等号）。写成 `d<phi` 会漏掉终止角，是本题最常见的 off-by-one。

---

### 引理 2（旋转：$t$ 秒的透光集合）

第 $i$ 轮在整数时刻 $t$ 的透光集合为
$$O_i(t)=\bigl\{(\beta+\omega_i t)\bmod360:\ \beta\in O_i(0)\bigr\},$$
即把 $t=0$ 的透光集合整体「加 $\omega_i t$」再 $\bmod360$。

*证明*：轮子是刚体，沿角度增大方向以 $\omega_i$ 度/秒匀速旋转。$t$ 秒后其上每一点的角度都增加 $\omega_i t$（再 $\bmod360$）。缺口是轮子上的固定弧，故其覆盖的角度集合整体平移 $\omega_i t$。$t=0$ 时缺口 $j$ 覆盖 $\{\theta_{ij}+d:0\le d\le\varphi_{ij}\}$（引理 1），平移后为 $\{\theta_{ij}+d+\omega_i t\bmod360\}$，对 $j$ 取并即 $O_i(t)$。这与记号中 $O_i(t)$ 的定义逐字一致。证毕。

**推论（实现）**：代码 `b.set((th[i][j]+d+w[i]*t)%360)` 正是把 $O_i(t)$ 的每个元素置 $1$。`w[i]*t` 最大 $180\times359=64620$，`int` 不溢出；先加后取模保证跨 $0$ 回绕正确。

---

### 引理 3（透光判据：五集合之交非空）

时刻 $t$ 光能穿过五个轮子 $\iff C(t)=\bigcap_{i=0}^{4}O_i(t)\ne\varnothing$。

*证明*：光沿某条半径方向（角度 $\alpha$）穿过，当且仅当它在**每一层**轮子处都遇到缺口，即 $\alpha\in O_i(t)$ 对所有 $i$ 成立，亦即 $\alpha\in\bigcap_i O_i(t)=C(t)$。故「存在这样的 $\alpha$」$\iff C(t)\ne\varnothing$。题面「这些缺口在任意一个角度对准」正是说 $\alpha$ 可以是任意角度，不要求特定方向，与「交非空」一致。证毕。

---

### 引理 4（周期性：只需检查 $t\in[0,359]$）

对任意整数 $t\ge0$ 与每个 $i$，有 $O_i(t+360)=O_i(t)$，从而 $C(t+360)=C(t)$。因此：若存在对齐时刻，则最早对齐时刻 $t^\*\in[0,359]$；若 $[0,359]$ 内无对齐，则永远无对齐。

*证明*：由引理 2，$O_i(t+360)$ 是把 $O_i(0)$ 平移 $\omega_i(t+360)$。而
$$\omega_i(t+360)=\omega_i t+360\omega_i\equiv\omega_i t\pmod{360}$$
（因 $360\omega_i$ 是 $360$ 的倍数）。平移量模 $360$ 相同，故 $O_i(t+360)=O_i(t)$。五集合逐一相等，其交也相等：$C(t+360)=C(t)$。

**最早性**：设对齐时刻集合 $T=\{t\ge0:C(t)\ne\varnothing\}$ 非空，取 $t^\*=\min T$。若 $t^\*\ge360$，则 $t^\*-360\ge0$ 且 $C(t^\*-360)=C(t^\*)\ne\varnothing$（周期性反向也成立），故 $t^\*-360\in T$ 且更小，与 $t^\*$ 最小矛盾。故 $t^\*\le359$。

**无解判定**：若对所有 $t\in[0,359]$ 都有 $C(t)=\varnothing$，则对任意 $t\ge0$，写 $t=360q+r$（$0\le r<359$），$C(t)=C(r)=\varnothing$，故 $T=\varnothing$，永远无对齐。证毕。

**推论（实现）**：外层循环 `for(t=0;t<360;++t)`，循环结束仍未返回就输出 `none`。无需更大的时间上界，也无需担心「漏掉很晚才对齐」的情况。

---

### 引理 5（bitset 模拟正确计算 $C(t)$）

固定 $t$。程序令 `cur` 初值全 $1$，对每个 $i$ 构造 `bitset<360> b`（初值全 $0$）并按引理 2 置位，再 `cur&=b`。五轮结束后 `cur` 恰为 $C(t)$ 的特征向量，`cur.any()` 为真 $\iff C(t)\ne\varnothing$。

*证明*：对轮数归纳。设处理完前 $k$ 轮后 `cur`$=\bigcap_{i<k}O_i(t)$ 的特征向量。$k=0$ 时 `cur` 全 $1$，是全集 $\mathbb Z_{360}$ 的特征向量，而空交约定为全集，成立。处理第 $k$ 轮：`b` 经引理 2 的置位后是 $O_k(t)$ 的特征向量（每个被标记的角度对应一个元素，未标记为 $0$）；`cur&=b` 按位与，结果的第 $\alpha$ 位为 $1$ $\iff$ 原 `cur` 第 $\alpha$ 位与 `b` 第 $\alpha$ 位都为 $1$ $\iff\alpha\in\bigcap_{i<k}O_i(t)$ 且 $\alpha\in O_k(t)$ $\iff\alpha\in\bigcap_{i<k+1}O_i(t)$。归纳成立。五轮后 `cur`$=C(t)$ 的特征向量。`.any()` 检测是否存在为 $1$ 的位，即 $C(t)$ 是否非空。证毕。

**边界**：`bitset<360> b;` 默认构造保证全 $0$（C++ 标准规定 `bitset` 默认构造将所有位置 $0$），不会残留上一轮/上一秒的位；`cur.set()` 每秒重置为全 $1$。这两处初始化是「全局/复用容器必须显式重置」纪律的体现。

---

### 引理 6（复杂度）

时间 $O\bigl(360\cdot\sum_{i}(\text{第 }i\text{ 轮缺口覆盖角度数})+360\cdot5\cdot\tfrac{360}{w}\bigr)$，其中 $w$ 为机器字长；在本题约束下不超过 $O(360^2\cdot5)\approx6.5\times10^5$ 次位标记。空间 $O(5\cdot5+360/8)$ 字节量级。

*证明*：外层 $360$ 个 $t$。每个 $t$：对每轮 $i$，标记 $\sum_j(\varphi_{ij}+1)$ 个位。由题面「同一轮上两缺口之间至少隔一度」，各缺口覆盖的角度集互不相交，故 $\sum_j(\varphi_{ij}+1)\le360$。于是每秒标记 $\le5\times360=1800$ 个位，$360$ 秒共 $\le648000$ 次 `set`（每次 $O(1)$）。另每秒做 $5$ 次 `bitset<360>` 按位与与一次 `any()`，各 $O(360/w)=O(6)$ 字操作，可忽略。总计 $O(6.5\times10^5)$，远低于 $1$ 秒时限。空间：存 $5$ 轮各 $\le5$ 个缺口的 $(\theta,\varphi)$ 与转速，$O(50)$ 个 `int`；两个 `bitset<360>` 各 $45$ 字节。证毕。

---

### 定理

程序输出最早使五轮缺口在某角度对齐的整数秒 $t\in[0,359]$，若不存在则输出 `none`。

*证明*：引理 1、2 保证每秒每轮透光集合 $O_i(t)$ 被正确构造（宽度含两端、旋转取模）；引理 3 保证「对齐」等价于五集合交非空；引理 5 保证 `bitset` 按位与正确计算交并判空；引理 4 保证只需检查 $[0,359]$ 且循环顺序递增故首个命中即最早，无命中即无解；引理 6 保证在时限内完成。证毕。

**题意模型说明**：题面声明「这是一个整数问题」，转速、角度、宽度均为整数，输出为整数秒，故按整数秒 $t$ 搜索（与 USACO 本题的标准模型一致）。引理 4 的周期性正是建立在「$\omega_i$ 为整数、$t$ 为整数」之上。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 把「光穿过五层」翻译成「五个透光角度集合之交非空」，整题塌缩成集合判空。
- **explore its property** — 宽度 $\varphi$ 含两端 ⇒ 覆盖 $\varphi+1$ 个角度（`d=0..phi`），这是最易错的 off-by-one。
- **reduce to easier problem** — 刚体旋转 ⇒ $O_i(t)$ 是 $O_i(0)$ 整体平移 $\omega_i t\bmod360$，直接逐角度标记即可。
- **explore its property** — 整数转速 ⇒ 配置以 $360$ 秒为周期，把「无限时间」压成「枚举 $t=0..359$」，并给出 `none` 的判据。
- **classic problem solution** — 用 `bitset<360>` 表示角度集合，按位与求交、`.any()` 判空，$O(360^2\cdot5)$ 模拟。
- **discuss by category** — 边界分类核对：$t=0$ 对齐、跨 $0$ 回绕、宽度含两端、刚体同速永不重合（`none`）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `w[i]` | 第 $i$ 轮转速 $\omega_i$（度/秒） | `int[mxw]`，读入 | $1\le\omega\le180$ |
| `ng[i]` | 第 $i$ 轮缺口数 $n_i$ | `int[mxw]`，读入 | $\le5$ |
| `th[i][j]` | 第 $i$ 轮第 $j$ 缺口起始角 $\theta$ | `int[mxw][mxg]`，读入 | $0..359$ |
| `ph[i][j]` | 第 $i$ 轮第 $j$ 缺口宽度 $\varphi$ | `int[mxw][mxg]`，读入 | 覆盖 $\varphi+1$ 个角度 |
| `b` | 当前轮在当前秒的透光角度集合 | `bitset<360>`，每秒每轮重置全 $0$ | 默认构造即全 $0$ |
| `cur` | 已处理各轮透光集合之交 | `bitset<360>`，每秒 `set()` 全 $1$ | 五轮交完即 $C(t)$ |
| `t` | 当前枚举的整数秒 | `int`，$0..359$ | 周期上界 $360$ |
| `mxw,mxg,mxd` | $5,\ 5+1,\ 360$ | `constexpr int` | 轮数 / 缺口数松弛 / 角度数 |

### 算法步骤

1. I/O 加速三行。
2. 读五轮：每轮读 `w[i],ng[i]`，再读 `ng[i]` 对 `th[i][j],ph[i][j]`。
3. 对 `t=0..359`：
   1. `cur.set()`（全 $1$）。
   2. 对每轮 `i`：新建 `bitset<360> b`（全 $0$）；对每个缺口 `j`、每个 `d=0..ph[i][j]`，`b.set((th[i][j]+d+w[i]*t)%360)`；`cur&=b`。
   3. 若 `cur.any()`：输出 `t` 并结束。
4. 循环结束仍未输出 ⇒ 输出 `none`。

### 复杂度

- 时间：$O(360^2\cdot5)\approx6.5\times10^5$ 次位标记（引理 6），远低于时限。
- 空间：$O(50)$ 个 `int` $+$ 两个 `bitset<360>`，可视为 $O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；按样例解释反推的 $5$ 轮数据输出 `9`（与解释逐轮吻合）；另造「刚体同速永不重合 → none」「起始即对齐 → 0」两组手算数据全对。本题为直接模拟，未写暴力对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2728 [USACO3.2] 纺车的轮子 Spinning Wheels
// 思路：整数秒 t 时第 i 轮缺口角度 = (theta+d+omega_i*t)%360，宽度 phi 含两端共 phi+1 个角度。
//       用 bitset<360> 标记每轮透光角度集合，五轮取交，非空即有光通过。
//       配置以 360 秒为周期（omega*360 ≡ 0 mod 360），故只需枚举 t=0..359，否则 none。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxw{5},mxg{6},mxd{360};

int w[mxw],ng[mxw],th[mxw][mxg],ph[mxw][mxg];
bitset<mxd> cur;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(int i=0;i<5;++i)
	{
		cin>>w[i]>>ng[i];
		for(int j=0;j<ng[i];++j)
			cin>>th[i][j]>>ph[i][j];
	}
	for(int t=0;t<360;++t)	// 周期 360：t 与 t+360 各轮位置完全相同
	{
		cur.set();	// 全 1，准备逐轮取交
		for(int i=0;i<5;++i)
		{
			bitset<mxd> b;	// 默认全 0：本轮当前不透光
			for(int j=0;j<ng[i];++j)
				for(int d=0;d<=ph[i][j];++d)	// 宽度含两端 ⇒ d 取 0..phi
					b.set((th[i][j]+d+w[i]*t)%360);
			cur&=b;
		}
		if(cur.any())
		{
			cout<<t<<'\n';
			return 0;
		}
	}
	cout<<"none\n";
	return 0;
}
```

### 代码说明

- **`d<=ph` 而非 `d<ph`**：宽度含两端（引理 1），少一个等号就漏掉终止角，边界对齐会被误判为 `none`。
- **`(th+d+w*t)%360`**：先加后取模，自动处理跨 $0$ 回绕（如 $[270,30]$）；`w*t` 最大 $64620$，`int` 安全。
- **`bitset<360> b;` 默认全 $0$、`cur.set()` 每秒全 $1$**：两处初始化缺一不可。`b` 若不清零会残留上一轮的透光位；`cur` 若不重置会残留上一秒的交。
- **外层 `t<360`**：由周期性（引理 4）这是充分且必要的搜索范围，循环自然结束即代表无解。
- **`cur.any()`**：$O(360/w)$ 判空，比逐位扫描更快；非空即找到最早 $t$，立即 `return 0`。
- 下标 $0$-based（轮 $0..4$、缺口 $0..n_i-1$），与题面「第几个」无关，无需 $\pm1$ 转换。
