# P2873 [USACO07DEC] Mud Puddles S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 二维整数坐标平面上，约翰从 $(0,0)$ 走到 $(X,Y)$（$-500\le X,Y\le 500$）。平面上有 $N\le 10^4$ 个泥坑，第 $i$ 个在整点 $(A_i,B_i)$（坐标同样在 $[-500,500]$ 内），**每个泥坑只占它所在的那一个点**。约翰只能沿平行于坐标轴的方向走、只能在整点转弯，不能踩进任何泥坑点。求最短行走距离。题目保证存在不踩泥的路径。

剥掉背景，这就是：**带点障碍的网格最短路**。两个关键词决定了建模方式：

- "平行于坐标轴走、整点转弯"：任何合法路线都是若干条水平/竖直线段首尾相接，端点全是整点。把每条线段按单位长度切开，整条路线就是一串**上下左右单位步**组成的格点路径；反过来任何单位步格点路径都合法。所以"最短距离"= 单位步数 = 网格图上的最短路长度。无障碍时答案就是曼哈顿距离 $|X|+|Y|$。
- "泥坑只占一个点"：障碍是**点**不是边，两个相邻干净点之间永远可以走。这让建模特别干净：删点不删边。

**口径说明（题面两处留白，我按最合理解读处理）：**

1. 题面没说约翰的活动范围是否限于 $[-500,500]$。我按**整个整数平面都可走**理解（"田地在坐标平面上"，泥坑坐标有界不代表边界有墙）。这不是偷懒——第二部分引理 2 会严格证明：最短路一定可以限制在 $[-501,501]^2$ 内，所以就算真有一堵 $[-500,500]$ 的墙，答案也不变，两种口径殊途同归。
2. "最短距离"按**路径总长度**（单位步数）理解，不是欧氏直线距离——只能轴平行行走时这是唯一自然的度量。
3. 保证有解 $\Rightarrow$ 起点 $(0,0)$ 与终点 $(X,Y)$ 都不是泥坑（否则最后一步必踩泥），也 $\Rightarrow$ 泥坑不会把终点围死。重复给出的泥坑坐标按同一个点处理（布尔标记天然幂等）。

**试探：贪心绕行行不行？** 第一反应是"朝目标走，被泥挡住就侧移一步"。手造一组数据立刻打脸：目标 $(3,0)$，泥坑 $(1,0),(1,1),(1,-1),(2,0)$。朝 $x$ 正方向走，$(1,0)$ 挡住；侧移到 $(0,1)$ 再前进，$(1,1)$ 挡住；再侧移……局部贪心看不到"$x=1$ 处有一堵三格高的墙，必须翻到 $y=2$ 或 $y=-2$ 才能过"，来回震荡甚至走回头路。答案是 $7$（曼哈顿 $3$ 加上翻墙多走的 $4$），任何"只看脚下一步"的策略都不可靠。**碰壁的根源**：绕障碍的代价是全局的，局部信息不足以决策。这正是"最短路"而非"贪心"问题的信号。

**归约：无障碍图上的单源最短路。** 把每个干净整点看作顶点，上下左右相邻连边，边权全为 $1$。边权全 $1$ 的最短路——BFS 即可，不需要 Dijkstra。剩下的唯一麻烦是**平面无限大**，BFS 不能跑在无限图上。

**收界：最短路出不了 $[-501,501]^2$。** 直觉是"绕一个点障碍最多往外凸一格，没必要跑远"。严格化靠一个**夹逼（clamp）论证**：取任意一条最优路径，把每个超出盒子 $B=[-501,501]^2$ 的顶点"按坐标截断"投影回 $B$ 的边界。截断映射在曼哈顿度量下是 $1$-Lipschitz 的（每个坐标各自截断，距离只缩不涨），所以投影后的路径不会变长；起点终点本来就在 $B$ 内不动；而 $B$ 的边界上坐标含 $\pm501$，泥坑坐标全在 $[-500,500]$，**边界上不可能有泥**——投影把"外面的点"搬到边界时不会砸进泥坑。于是得到一条不更长、全程在 $B$ 内的合法路径。结论：在 $1003\times1003$ 的有限网格上 BFS 就是原问题的精确答案。

**手造数据核对**（题面无样例，全部自造）：

| 输入（$X\ Y\ N$ + 泥坑） | 手算 | 程序输出 |
|---|---|---|
| `2 0 1`，泥 `(1,0)` | 直路被挡，绕 $(0,1)$：$4$ | `4` ✓ |
| `1 1 1`，泥 `(5,5)` | 泥不在路上，曼哈顿 $2$ | `2` ✓ |
| `0 0 1`，泥 `(3,3)` | 起点即终点，$0$ | `0` ✓ |
| `-2 -2 3`，泥 `(-1,0),(0,-1),(-1,-1)` | 两步出口全堵；长度与曼哈顿同奇偶，$4$ 不可能、$5$ 奇偶不符，绕外圈 $6$ | `6` ✓ |
| `500 500 2`，泥 `(1,0),(0,1)` | 出口全堵，绕一侧多 $2$ 步：$1002$ | `1002` ✓ |
| `3 0 4`，泥 `(1,0),(1,1),(1,-1),(2,0)` | 翻三格墙：$7$（上文贪心反例） | `7` ✓ |

第四组顺手验证了一个有用的检验工具：**每走一步 $x+y$ 的奇偶性翻转**，所以任何路径长度与 $|X|+|Y|$ 同奇偶，答案不可能是曼哈顿距离加奇数。

## 二、思维链：完整证明

**记号。** 泥坑集合 $M\subseteq[-500,500]^2\cap\mathbb Z^2$，$|M|\le 10^4$（重复坐标去重后只少不多）。起点 $s=(0,0)$，终点 $t=(X,Y)$，保证 $s,t\notin M$ 且存在合法路径。合法路径指顶点序列 $p_0=s,p_1,\dots,p_L=t$，相邻顶点曼哈顿距离恰为 $1$，且所有 $p_i\notin M$；长度 $L$ 即行走距离。盒子 $B=[-501,501]^2\cap\mathbb Z^2$，边长 $1003$。网格图 $G$：顶点为 $B\setminus M$，四邻接连边。

---

### 引理 1（合法路线 $\iff$ 单位步格点路径）

任何"轴平行行走、整点转弯、不踩泥"的路线，其长度等于某条合法格点路径的步数；反之亦然。因此答案 $=\min L$，且无障碍时 $\min L=|X|+|Y|$。

*证明*：($\Rightarrow$) 路线由有限条轴平行线段组成，端点为整点（转弯点与起终点）。一条从整点 $(a,b)$ 到 $(a',b)$ 的水平线段长度为 $|a'-a|$，把它切成 $|a'-a|$ 个单位步，途经点 $(a\pm k,b)$ 全是整点且都在线段上——路线不踩泥意味着线段上每个整点都干净，故切出的每个顶点 $\notin M$。竖直同理。拼接后得到合法格点路径，总步数 $=$ 各线段长度和 $=$ 路线长度。

($\Leftarrow$) 单位步格点路径的每一步都是轴平行线段，顶点是整点（可视为转弯点），不踩泥由顶点 $\notin M$ 保证（泥只占点，步的中点非整点、必不是泥）。长度 $=$ 步数。

无障碍下界：每步至多让 $|x-X|+|y-Y|$ 减少 $1$，故 $L\ge|X|+|Y|$；单调路径（只朝目标方向走）取到等号。有障碍时该下界仍成立，但可能取不到。证毕。

**推论（奇偶检验）**：每步使 $x+y$ 变化 $\pm1$，故 $L\equiv X+Y\pmod 2$。任何候选答案若与曼哈顿距离奇偶不同，必错。

---

### 引理 2（夹逼引理：最短路可限制在 $B=[-501,501]^2$ 内）

存在一条长度最优的合法路径，其所有顶点都属于 $B$。

*证明*：定义截断映射 $c:\mathbb Z^2\to B$，$c(x,y)=(\mathrm{clamp}(x),\mathrm{clamp}(y))$，其中 $\mathrm{clamp}(v)=\max(-501,\min(501,v))$。

**第一步：$c$ 在曼哈顿度量下 $1$-Lipschitz。** 单坐标截断满足 $|\mathrm{clamp}(a)-\mathrm{clamp}(b)|\le|a-b|$：若 $a,b$ 同侧越界则差为 $0$；若都在 $[-501,501]$ 内则差不变；若一内一外（或两侧），截断把两点距离缩短（例如 $a<-501\le b\le 501$ 时 $|\mathrm{clamp}(a)-\mathrm{clamp}(b)|=b+501\le b-a=|a-b|$；$a<-501, b>501$ 时左边 $=1002< b-a$）。逐坐标相加得 $\|c(p)-c(q)\|_1\le\|p-q\|_1$。

**第二步：投影路径仍合法且不更长。** 取任意最优合法路径 $p_0,\dots,p_L$。令 $q_i=c(p_i)$。由第一步，$\|q_{i+1}-q_i\|_1\le\|p_{i+1}-p_i\|_1=1$；坐标为整数，故该距离是 $0$ 或 $1$。删去相邻重复点（距离 $0$ 的步），剩下的序列相邻距离恰为 $1$，是一条格点路径；端点 $q_0=c(s)=s$、$q_L=c(t)=t$（$s,t$ 坐标在 $[-500,500]\subset B$ 内，截断不动）。长度 $\le L$。

**第三步：投影路径不踩泥。** 分两类看 $q_i$：若 $p_i\in B$，则 $q_i=p_i\notin M$；若 $p_i\notin B$，则 $q_i$ 落在 $B$ 的边界上，即至少一个坐标为 $\pm501$。而 $M$ 中点的两坐标都在 $[-500,500]$，故边界点 $\notin M$。两类都干净。

于是投影路径是合法路径、长度 $\le L$、全程在 $B$ 内。又 $L$ 已是最优，故它也是最优路径。证毕。

**注**：盒子取 $[-500,500]$ 不行——边界上可能有泥，第三步失效；外扩一格正是为了让"边界无泥"成立。这就是偏移量取 $501$ 而不是 $500$ 的原因。

---

### 引理 3（BFS 的距离不变量）

在有限无权图 $G$ 上从 $s$ 做 BFS（首次到达时记录 `dis` 并入队，出队时向未访问邻居松弛），则每个可达顶点 $v$ 的 `dis[v]` 恰等于 $s\to v$ 的最短路步数 $\delta(v)$；不可达顶点保持 INF。

*证明*：两个方向夹逼。

**$\texttt{dis}[v]\ge\delta(v)$**：`dis[v]` 被赋值时，存在一条从 $s$ 出发、沿已松弛边走到 $v$ 的实际路径，长度恰为 `dis[v]`（对松弛次数归纳：`dis[s]=0`；`dis[nx]=dis[x]+1` 时把 $x$ 的路径接一步）。实际路径长度 $\ge$ 最短路，故 `dis[v]` $\ge\delta(v)$。且 `dis` 只在 INF 时被赋值一次，之后不变。

**$\texttt{dis}[v]\le\delta(v)$**：对 $\delta(v)=d$ 归纳。$d=0$：$v=s$，`dis[s]=0` ✓。设所有 $\delta=d$ 的点都已入队且 `dis`$=d$。取 $\delta(v)=d+1$，最短路倒数第二点 $u$ 满足 $\delta(u)=d$。由归纳假设 $u$ 入队、`dis[u]`$=d$；BFS 中每个入队点必被出队处理（队列有限、每点入队至多一次），处理 $u$ 时检查邻居 $v$：若 `dis[v]` 已非 INF，则它 $\le$ 某个时刻的赋值，而赋值只能来自某邻居 $w$ 的 `dis[w]+1`；由队列的层序性质（入队序列的 `dis` 单调不减，且同一时刻队列中至多两种相邻取值——对入队操作归纳可得），$v$ 若在 $u$ 之前被赋值，其值 $\le d+1$；若尚未赋值，此刻被赋为 $d+1$。两种情况都有 `dis[v]`$\le d+1=\delta(v)$。

夹逼得等号。不可达点永远不会被松弛（松弛沿实际边传播，只能到达可达点），保持 INF。证毕。

**推论**：本题保证 $t$ 可达，故 `dis[t]` 就是引理 1、2 意义下的答案；INF 不会被输出。

---

### 引理 4（实现细节的语义正确）

(a) 偏移 `off=501` 是 $[-501,501]\to[0,1002]$ 的双射，四邻接关系保持不变；(b) 布尔数组 `mud` 对重复泥坑幂等；(c) `dis` 必须先 `fill` 成 INF；(d) 越界检查 `nx<0||nx>=lim`（`lim=1003`）恰好把搜索限制在 $B$ 内。

*证明*：(a) 平移是等距同构：$\|(a+501,b+501)-(a'+501,b'+501)\|_1=\|(a,b)-(a',b')\|_1$，故路径长度、邻接、泥坑归属全部保持。(b) `mud[x][y]=true` 重复执行结果不变，语义上泥坑集合本来就是集合，重复元素无影响。(c) 全局 `int` 数组零初始化，$0$ 是**合法距离值**；若不显式填 INF，`dis[nx][ny]!=inf` 的"已访问"判据会把所有未访问点误判为已访问（$0\ne\text{inf}$ 为真），BFS 一步都走不出去，输出 INF 或错误值。这是本题最致命的静默错误。(d) 下标 $[0,1002]$ 经 (a) 的逆映射恰为坐标 $[-501,501]$，即 $B$；由引理 2，限制在 $B$ 内不损失最优解。证毕。

---

### 引理 5（复杂度）

时间 $O(|B|+N)=O(1003^2+N)\approx 10^6$ 量级，空间 $O(|B|)$。

*证明*：`fill` 扫 $1010^2\approx1.02\times10^6$ 格；读泥坑 $O(N)$。BFS 每顶点至多入队一次（引理 3 的判据），每次出队检查 $4$ 个邻居，总边检查 $\le 4|B|\approx4.02\times10^6$，每次 $O(1)$。队列长度 $\le|B|$。空间：`dis` 约 $4.08$ MB、`mud` 约 $1.02$ MB、队列最坏 $O(|B|)$ 个 `pair<int,int>`。合计约 $10^6$ 次基本操作、$6$ MB 级内存，远在限制内。证毕。

---

### 定理

程序输出约翰从 $(0,0)$ 到 $(X,Y)$ 不踩泥的最短行走距离。

*证明*：引理 1 把原问题化为格点图最短路；引理 2 把无限平面安全收缩到有限盒子 $B$；引理 4 保证偏移、去重、INF 初始化、边界检查都忠实实现 $G$；引理 3 保证 BFS 给出的 `dis[t]` 恰为 $G$ 上最短路；引理 5 保证资源可行。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "轴平行 + 整点转弯" $\iff$ 单位步格点路径；"泥坑只占点" $\iff$ 删点不删边；距离 = 步数。
2. **consider easier version** — 无障碍时答案是曼哈顿距离；有障碍时先试"朝目标走、遇泥侧移"的贪心。
3. **explore its property** — 手造三格墙反例击溃局部贪心：绕障代价是全局的，局部决策会震荡。
4. **reduce to easier problem** — 归约为边权全 $1$ 的网格图单源最短路。
5. **explore its property** — 平面无限大不能直接 BFS；夹逼（clamp）论证：截断映射 $1$-Lipschitz + 外扩一格边界无泥 $\Rightarrow$ 最短路出不了 $[-501,501]^2$。
6. **classic problem solution** — 无权图最短路用 BFS，$O(V+E)$；首次到达即最优，无需堆。
7. **discuss by category** — 坐标平移 $+501$；重复泥坑布尔幂等；`dis` 显式填 INF（全局默认 $0$ 是合法距离，静默出错）；起点即终点输出 $0$；奇偶性可作手算检验。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `off` | 坐标偏移 $501$，把 $[-501,501]$ 映到 $[0,1002]$ | `constexpr int` | 外扩一格保证边界无泥 |
| `lim` | 合法下标上界（开）$1003$ | `constexpr int` | 越界检查用 |
| `mxn` | 数组尺寸 $1010$（$1003+5$ 松弛） | `constexpr int` | 宁可虚高不可越界 |
| `inf` | 不可达哨兵 $1145141919$ | `constexpr int` | 距离最大 $2004$，远小于它 |
| `X,Y` | 终点坐标，读入后立即 `+=off` 转下标 | `int` | 内部全程 0-based 下标 |
| `mud[x][y]` | 下标 $(x,y)$ 处是否有泥 | `bool[mxn][mxn]` | 全局默认 `false`，读入置 `true`，重复幂等 |
| `dis[x][y]` | 起点到 $(x,y)$ 的最短步数 | `int[mxn][mxn]` | **必须 `fill_n` 成 `inf`**，`dis[off][off]=0` |
| `dx,dy` | 四方向增量 | `int[4]` | 上下左右 |
| `Q` | BFS 队列，存下标对 | `queue<pair<int,int>>` | 初始只有起点 |

### 算法步骤

1. I/O 加速三行；读 $X,Y,N$，`X+=off;Y+=off`。
2. 读 $N$ 个泥坑，`mud[a+off][b+off]=true`。
3. `fill_n(&dis[0][0],mxn*mxn,inf)`；`dis[off][off]=0`，起点入队。
4. 标准 BFS：出队 $(x,y)$，枚举四邻 $(nx,ny)$，越界 / 有泥 / 已访问则跳过，否则 `dis[nx][ny]=dis[x][y]+1` 并入队。
5. 输出 `dis[X][Y]`（保证可达，必非 INF）。

### 复杂度

- 时间：$O(1003^2+N)\approx10^6$ 次基本操作（每点至多入队一次、每点 $4$ 次邻居检查）。
- 空间：$O(1003^2)\approx6$ MB（`dis` 4 MB + `mud` 1 MB + 队列）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Part 1 六组手造数据（含起点即终点、双出口封锁、三格墙、奇偶检验、$500$ 边界）全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2873 [USACO07DEC] Mud Puddles S
// 点障碍网格最短路 ⇒ BFS；坐标平移 +501，范围 [-501,501] 足够（夹逼引理）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1010},off{501},lim{1003};	// 合法下标 [0,1002] ↔ 坐标 [-501,501]
constexpr int inf{1145141919};

int X,Y,n,dis[mxn][mxn];
bool mud[mxn][mxn];
int dx[4]{1,-1,0,0},dy[4]{0,0,1,-1};

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>X>>Y>>n;
	X+=off;Y+=off;
	for(int i=0,a,b;i<n;++i)
	{
		cin>>a>>b;
		mud[a+off][b+off]=true;
	}
	fill_n(&dis[0][0],mxn*mxn,inf);	// 全局 int 默认 0 不是 INF！
	queue<pair<int,int>>Q;
	dis[off][off]=0;
	Q.push({off,off});
	while(!Q.empty())
	{
		auto[x,y]=Q.front();Q.pop();
		for(int d=0;d<4;++d)
		{
			int nx=x+dx[d],ny=y+dy[d];
			if(nx<0||nx>=lim||ny<0||ny>=lim||mud[nx][ny]||dis[nx][ny]!=inf)
				continue;
			dis[nx][ny]=dis[x][y]+1;
			Q.push({nx,ny});
		}
	}
	cout<<dis[X][Y]<<'\n';
	return 0;
}
```

### 代码说明

- **`fill_n(&dis[0][0],mxn*mxn,inf)` 是生死线**：全局 `int` 默认 $0$，而 $0$ 是合法距离；不填 INF 的话 `dis[nx][ny]!=inf` 会把所有点当成"已访问"，BFS 原地熄火。二维数组按行主序连续，`&dis[0][0]` 起填 `mxn*mxn` 个恰好覆盖全数组。
- 偏移取 $501$ 而非 $500$：夹逼引理要求盒子边界上无泥，外扩一格正是为此；`lim=1003` 把搜索精确限制在 $[-501,501]^2$。
- `mud` 用 `bool`：重复泥坑自动幂等，不需要去重逻辑。
- 判据 `dis[nx][ny]!=inf` 兼作 visited 标记，每点至多入队一次，无需额外 `vis` 数组。
- 起点即终点时队列只弹出起点、答案 `dis[off][off]=0`，自然正确；泥坑若含起点/终点与"保证有解"矛盾，不必特判。
- 全程下标 0-based，读入即 `+=off`，输出无需还原（答案是距离不是坐标）。
