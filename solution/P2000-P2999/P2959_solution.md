# P2959 [USACO09OCT] The Leisurely Stroll G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 有 $P-1$ 个分岔节点（编号 $1\dots P-1$，$1\le P\le 1000$），编号 $1$ 是牛棚（根）。每个分岔节点引出**恰好两条**小径，每条小径通向另一个分岔节点或一片草地（输入用 $0$ 表示草地）。**从牛棚到任何节点的路径唯一**。Bessie 从牛棚出发，在每个分岔节点任选一条小径走，直到到达草地为止。求她最多能走过多少条小径。

输入 $P-1$ 行，每行 `C D1 D2`：节点 $C$ 的两条小径终点（$0$ 表示草地）。**行的顺序不保证按编号排**，要按 $C$ 存。

**口径说明（两处歧义，都在此定死）：**

1. **输出"最多节点数"还是"最多小径数"？** 输出格式写的是"最多节点数"，但题目描述与 Hint 都明确说示例答案是 **7 条小径**（路径 `1-2-5-6-7-8-9-草地`）。注意这条路径经过 $7$ 个分岔节点、$7$ 条小径、$8$ 个"位置"（含草地）。也就是说：**根到叶路径上，分岔节点数 = 小径数**（每个分岔节点恰好贡献一条"离开它"的小径，最后一条通向草地）。两种读法数值相同，我按"小径数 = 边数"实现，与 Hint 的 $7$ 吻合。
2. **$P=1$ 怎么办？** 此时没有分岔节点，与"一出牛棚就有 2 条路径"的描述矛盾，说明实际数据大概率 $P\ge 2$。防御性地，我让递推自然处理：把牛棚视作一个两条小径都直通草地的节点，答案为 $1$。这只影响这个退化边界，不影响主逻辑。

**结构一眼看穿：这是一棵满二叉树。** "从牛棚到任何节点路径唯一"排除了环和"两个父亲"，每个分岔节点恰有两个孩子，草地是叶子。于是"最多小径数"就是**根到叶的最长路径长度（边数）**——树的高度。这是树形 DP 的入门形态：$f(u)=1+\max(f(d_1),f(d_2))$，草地 $f=0$。

**手造数据核对。** 题面给了示意图但没给样例输入输出，我按图把树重建出来（$P=10$，分岔节点 $1\dots 9$）：

```
10
1 2 3
2 0 5
3 0 4
4 0 0
5 6 0
6 7 0
7 8 0
8 0 9
9 0 0
```

核对图的结构：$1$ 的孩子是 $2,3$；$2$ 通草地与 $5$；$3$ 通草地与 $4$；$4$ 通两片草地；$5$ 通 $6$ 与草地；$6$ 通 $7$ 与草地；$7$ 通 $8$ 与草地（图上 `7----8`）；$8$ 通草地与 $9$；$9$ 通两片草地。草地总数 $=1+1+2+1+1+1+1+2=10=P$ ✓（满二叉树叶子数 = 内部节点数 $+1$）。最长路径 `1-2-5-6-7-8-9-草地` 共 $7$ 条小径，程序输出 $7$，与 Hint 一致。

再造两组小的：链状 $P=4$（`1→2→3→草地`，每个节点另一条通草地），答案 $3$；把输入行打乱顺序（`3 0 0` 写在第一行），答案仍是 $3$，验证"按编号存"的必要性；$P=2$（`1 0 0`），答案 $1$。全部吻合。

**实现上唯一的坑**：内部用 0-based 后，节点编号 $0$ 是**合法节点**（原来的 $1$ 号牛棚），不能再拿 $0$ 当草地哨兵——我用 $-1$ 表示草地，并且**全局数组必须显式 fill 成 $-1$**（默认 $0$ 会让没读到的孩子指向牛棚自己，$P=1$ 时直接无限递归）。

## 二、思维链：完整证明

**记号。** 分岔节点集合 $B=\{1,\dots,P-1\}$，牛棚为节点 $1$。每个 $u\in B$ 有两个孩子 $d_1(u),d_2(u)\in B\cup\{\text{草地}\}$。把草地看作叶子顶点（每片草地是**独立的**叶子，即使输入里都写 $0$）。题目保证：从节点 $1$ 到图中任何顶点的路径唯一。内部实现把节点 $v$ 映射为下标 $v-1$，草地映射为 $-1$。

---

### 引理 1（图是以牛棚为根的满二叉树，草地恰有 $P$ 片）

由"路径唯一"与"每个分岔节点出度 $2$"可知：整个图是一棵以 $1$ 为根的树，分岔节点是内部节点（恰两个孩子），草地是叶子；叶子总数为 $P$。

*证明*：分三步。

**(i) 无环、无多父。** 所有顶点都从 $1$ 可达（题面"引向 $P$ 片草地"，且每个节点都由某条小径引出）。若存在两个不同父亲 $p\ne q$ 指向同一顶点 $v$，则取 $1\to p$ 的路径接边 $p\to v$，与 $1\to q$ 的路径接边 $q\to v$，是两条不同的 $1\to v$ 路径（倒数第二条边不同），与唯一性矛盾。若存在（无向意义下的）环，取环上离 $1$ 最近的顶点 $w$：到 $w$ 有两条不同路径（沿环两侧），同样矛盾。故图无环且每点至多一个父亲；又每点可达，图是树，根为 $1$。

**(ii) 内部节点恰两个孩子。** 每个分岔节点引出两条小径，指向两个**不同**顶点（若指向同一顶点则该顶点有两个父亲，违反 (i)；指向自身则成环）。草地没有出边，是叶子。

**(iii) 叶子数。** 设草地 $L$ 片。树的边数 = 顶点数 $-1=(P-1)+L-1$。另一方面每条边恰由一个分岔节点引出，边数 $=2(P-1)$。联立：$2(P-1)=P-2+L\Rightarrow L=P$。与题面"引向 $P$ 片草地"一致。证毕。

---

### 引理 2（任何合法走法 = 一条根到叶的下行路径；小径数 = 经过的分岔节点数）

Bessie 的一次完整散步恰为一条从根 $1$ 到某片草地的树路径；若她经过 $k$ 个分岔节点，则走过 $k$ 条小径。反之，任何根到叶路径都对应一种合法选择方案。

*证明*：小径是有方向的（从分岔节点"引出"），Bessie 只能沿出边走。由引理 1，图是树，沿出边走不可能回到已访问顶点（否则成环），故走法是简单下行路径，终点必为叶子（草地）——内部节点总有出边可走，过程只在草地停止。设路径为 $1=v_1\to v_2\to\dots\to v_k\to \ell$，其中 $v_1,\dots,v_k$ 是分岔节点、$\ell$ 是草地：边恰为 $v_1\to v_2,\dots,v_{k-1}\to v_k,v_k\to\ell$，共 $k$ 条，即"小径数 = 分岔节点数"。反之，给定任一根到叶路径，在每个分岔节点选择"路径上的那条出边"即实现该走法（每个节点恰两条出边，选择合法）。证毕。

**推论**：答案 $=\max_{\ell\text{ 是草地}}\mathrm{dist}(1,\ell)$，即树高（边数）。这也解释了题面"节点数/小径数"两种措辞数值相同：路径上的分岔节点数与边数都是 $k$。

---

### 引理 3（最优子结构与递推）

对任意顶点 $u$，定义 $f(u)$ 为从 $u$ 出发沿出边到其子树内某片草地的最多小径数。则

$$f(\text{草地})=0,\qquad f(u)=1+\max\bigl(f(d_1(u)),\,f(d_2(u))\bigr)\quad(u\in B).$$

且该递推良定义（递归有限步终止）。

*证明*：**良定义**：由引理 1 图是树，子树严格变小（孩子的子树不含 $u$），对子树高度归纳即知递归终止。

**草地**：已在草地，无需再走，$f=0$。

**分岔节点**：从 $u$ 出发的任何走法，第一条小径必为 $u\to d_1$ 或 $u\to d_2$（恰两条出边），走完它之后问题变成"从 $d_i$ 出发到草地的最多小径数"，即 $f(d_i)$；故任何走法的小径数 $\le 1+\max(f(d_1),f(d_2))$（上界）。反之，取 $i^\*=\arg\max f(d_i)$，先走 $u\to d_{i^\*}$，再沿实现 $f(d_{i^\*})$ 的最优走法走（引理 2 保证它存在且合法），总小径数恰为 $1+\max(f(d_1),f(d_2))$（可达）。上界与可达相等，递推成立。证毕。

---

### 引理 4（答案 = $f(1)$；DFS 每点恰算一次）

程序输出 $f(\text{根})$，即最多小径数；递归 `dfs` 对每个分岔节点恰调用一次（草地哨兵除外），总工作量 $O(P)$。

*证明*：由引理 2 推论，答案 $=\max_\ell\mathrm{dist}(1,\ell)$；由引理 3，$f(1)$ 按递推展开恰是这个最大值（对树高归纳：$f(1)=1+\max f(d_i)$，而 $\max_\ell\mathrm{dist}(1,\ell)=1+\max_i\max_{\ell\in\text{subtree}(d_i)}\mathrm{dist}(d_i,\ell)$，两者逐项一致）。故输出 $f(1)$ 正确。

调用次数：由引理 1，每个分岔节点恰有一个父亲，故在递归树中恰被其父亲调用一次；根被 `main` 调用一次。草地哨兵 $-1$ 每次被调用立即返回，调用次数 $\le 2(P-1)$。总调用 $O(P)$，每次 $O(1)$ 工作。证毕。

---

### 引理 5（哨兵与初始化的必要性）

内部 0-based 后必须用 $-1$（而非 $0$）表示草地，且 `ch` 数组必须显式初始化为 $-1$。

*证明*：节点 $v$ 存于下标 $v-1$，故下标 $0$ 是牛棚本身。若沿用 $0$ 作草地哨兵，`dfs(0)` 会把牛棚当成草地返回 $0$，答案恒 $0$，错。改用 $-1$ 后，读入时 `d?d-1:-1` 正确区分两类终点。又全局 `int` 数组默认 $0$：$P=1$ 时没有任何读入，`ch[0]` 保持默认 $0$，`dfs(0)` 会递归到 `dfs(ch[0][0])=dfs(0)`——**无限递归**。显式 `fill` 成 $-1$ 后，`dfs(0)=1+\max(0,0)=1`，与第一部分约定的退化口径一致。证毕。

---

### 引理 6（复杂度）

时间 $O(P)$，空间 $O(P)$，递归深度 $\le P$。

*证明*：读入 $P-1$ 行 $O(P)$；`fill` $O(\text{mxn})=O(P)$ 量级；由引理 4，DFS 总调用 $O(P)$、每次 $O(1)$。递归栈深度不超过最长链上的分岔节点数 $\le P-1\le 999$，不会爆栈。空间为 `ch[1005][2]`，$O(P)$。证毕。

---

### 定理

程序输出的整数恰为 Bessie 最多可走过的小径数。

*证明*：引理 1 确认结构是满二叉树；引理 2 把"最多小径"化归为根到叶最长路径；引理 3 给出正确的递推；引理 4 保证 DFS 计算的 $f(1)$ 就是该最长路径且线性时间；引理 5 保证哨兵与初始化在 0-based 与 $P=1$ 边界下正确；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "从牛棚路径唯一" + "每节点恰两条出边" ⇒ 满二叉树；草地是叶子，叶子数 $=P$。
2. **reduce to easier problem** — 最多小径数 = 根到叶最长路径（树高，边数）；路径上分岔节点数 = 边数，两种题面措辞数值一致。
3. **classic problem solution** — 树形 DP：$f(u)=1+\max(f(d_1),f(d_2))$，草地 $f=0$，一次 DFS 出答案。
4. **discuss by category** — 输入行乱序 ⇒ 按编号 $C$ 存孩子；$P=1$ 退化情形让递推自然给出 $1$。
5. **explore its property** — 0-based 后 $0$ 是合法节点（牛棚），草地哨兵改用 $-1$ 且全局数组必须显式 fill，否则 $P=1$ 无限递归。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `p` | 草地数 $P$，分岔节点数 $P-1$ | `int` | 读入 |
| `ch[u][0/1]` | 节点 $u$（0-based，原编号 $u+1$）的两条小径终点 | `int[mxn][2]` | **显式 fill 成 $-1$**；$-1$ = 草地 |
| `mxn` | $1000+5$ | `constexpr int` | 节点下标上界 |
| `dfs(u)` | $f(u)$：$u$ 到子树内草地的最多小径数 | `int(int)` | $u=-1$ 返回 $0$；否则 $1+\max$ 两孩子 |
| `c,d1,d2` | 一行输入：节点编号与两个终点 | `int` | `--c`；`d?d-1:-1` |

### 算法步骤

1. I/O 加速三行；`fill_n(&ch[0][0],mxn*2,-1)`。
2. 读 $P$；对 $P-1$ 行读 `c,d1,d2`，`--c`，存 `ch[c][0]=d1?d1-1:-1`、`ch[c][1]=d2?d2-1:-1`（按编号存，天然免疫乱序）。
3. 输出 `dfs(0)`（牛棚 = 原编号 $1$ = 下标 $0$）。

### 复杂度

- 时间 $O(P)\le 1000$ 个节点，每点常数次操作。
- 空间 $O(P)$；递归深度 $\le 999$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；按题面示意图重建的 $P=10$ 数据输出 $7$（与 Hint 一致）；链状 $P=4$ 输出 $3$、乱序输入仍 $3$、$P=2$ 输出 $1$、$P=1$ 输出 $1$，均与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2959 [USACO09OCT] The Leisurely Stroll G
// 满二叉树上求根到叶的最长路径（边数）：f(u)=1+max(f(d1),f(d2))，叶子 f=0
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int p,ch[mxn][2];

int dfs(int u)	// u=-1 表示草地；返回 u 到下方草地的最多小径数
{
	if(u==-1)
		return 0;
	return 1+max(dfs(ch[u][0]),dfs(ch[u][1]));
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	fill_n(&ch[0][0],mxn*2,-1);	// 全局默认 0 是合法结点编号，必须显式置 -1
	cin>>p;
	for(int i=1,c,d1,d2;i<p;++i)
	{
		cin>>c>>d1>>d2;--c;
		ch[c][0]=d1?d1-1:-1;
		ch[c][1]=d2?d2-1:-1;
	}
	cout<<dfs(0)<<'\n';
	return 0;
}
```

### 代码说明

- **哨兵是 $-1$ 不是 $0$**：0-based 后下标 $0$ 是牛棚。`fill` 成 $-1$ 同时解决两件事：草地标记、$P=1$ 时未读入节点的默认孩子（否则 `dfs(0)` 递归到自己，无限递归）。这是"全局数组默认 $0$ 不是哨兵"陷阱的又一实例。
- `d1?d1-1:-1`：输入的 $0$（草地）映射为 $-1$，非零编号减一转 0-based，一行完成两种转换。
- 按 `c` 存孩子而不是按行号存，输入乱序也无所谓。
- 不需要记忆化：树中每点恰一个父亲，`dfs` 天然每点算一次（引理 4），$O(P)$。
- 答案数的是**边**：草地返回 $0$，每个分岔节点 `+1`，与 Hint 的"7 条小径"口径一致。
