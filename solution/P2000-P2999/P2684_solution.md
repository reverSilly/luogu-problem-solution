# P2684 搞清洁 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一天被切成 $T$ 个时间段（$1\le T\le 10^6$），编号 $1\dots T$。有 $N$ 头奶牛（$1\le N\le 2.5\times10^4$），第 $i$ 头能工作的是一个**闭区间** $[s_i,e_i]$（样例解释明确说"时间 $7$ 也在工作的"，所以两端都算）。要选出**最少**的奶牛，使得 $1\dots T$ 每个时间段都至少被一头选中的奶牛覆盖；覆盖不了输出 `-1`。

**第一眼先看数据范围。** $T\le10^6$、$N\le2.5\times10^4$，这两个数字的**悬殊比例**就是提示：任何"对每个时间段枚举每头奶牛"的做法都是 $O(NT)=2.5\times10^{10}$，必死；而"以区间为单位"的做法最多只要处理 $2.5\times10^4$ 个对象。所以思考的粒度应该是**区间**，不是时间点。顺带一提：答案上界是 $N$（全选总能覆盖，只要可行），这也暗示"选出的区间个数"是个很小的量。

于是问题被翻译成一句经典话：**用最少的闭区间覆盖 $[1,T]$**（minimum interval covering）。

**第一步：先试几个"看起来很像"的贪心，然后被反例打脸。**

我脑子里先冒出来的是活动选择问题（activity selection）的肌肉记忆——"按右端点排序，能选就选"。但那是**选最多互不相交区间**，这里是**用最少区间盖满一整段**，目标完全相反。造个反例：$T=4$，区间 $[1,2],[1,4],[3,4]$。

- 按右端点升序：$[1,2](r=2),[3,4](r=4),[1,4](r=4)$。先拿 $[1,2]$，覆盖到 $2$；下一个能接上的是 $[3,4]$，覆盖到 $4$。用了 **2** 个。
- 但 $[1,4]$ 一个就够了，最优是 **1**。

失败原因很清楚：**"结束得早"在覆盖问题里是缺点不是优点**，我要的是"伸得远"。

第二个念头："每次选最长的区间"。反例：$T=10$，区间 $[1,5],[4,9],[6,10]$。最长的是 $[4,9]$（长 $6$），先拿它；可是时间段 $1$ 还没人管，只能再拿 $[1,5]$；时间段 $10$ 也没人管，再拿 $[6,10]$。共 **3** 个。而 $[1,5]+[6,10]$ 只要 **2** 个。

失败原因也很清楚：**长度和"能不能接上当前缺口"无关**。$[4,9]$ 再长，它的左端 $4$ 也够不到时间段 $1$，选它并没有解决"最左边那个洞"。

**第二步：把两次失败抽象成同一个模式。** 两个错误贪心的共同点是：它们的评价标准（右端点小 / 长度大）**都与"当前最左边还没被覆盖的时间段"无关**。而覆盖问题的约束是"每个点都要被盖住"，其中**最左边的未覆盖点是最紧迫的**——它左边的点已经安全了，它右边的点以后再说。任何合法方案都必须有某个区间盖住这个点，那么在这个点的所有候选区间里，我为什么不挑**右端点最大**的那个？它盖住了同样的左边，还额外多盖了右边，怎么看都不亏。

这就是本题的贪心：**维护 `cur` = 最左未覆盖时间段；在所有 $l\le \texttt{cur}$ 的区间里取 $r$ 最大者；令 $\texttt{cur}\leftarrow r+1$，计数加一。** 一直做到 $\texttt{cur}>T$。

"不亏"这三个字必须证——第二部分用交换论证把它变成严格引理（还要处理一个我一开始漏掉的情形：挑中的区间**已经在**最优解里了怎么办）。

**第三步：无解怎么判？** 如果某一轮所有 $l\le\texttt{cur}$ 的区间都满足 $r<\texttt{cur}$，那就说明**没有任何区间能盖住 `cur`**（能盖住 `cur` 的区间必须 $l\le\texttt{cur}\le r$）。这不是贪心不行，是题目本身无解，直接 `-1`。反过来，只要有解，贪心每一轮都至少能找到盖住 `cur` 的区间，永远不会卡住。判定与求解共用一个循环，很干净。

**第四步：怎么高效地"在所有 $l\le\texttt{cur}$ 的区间里取 $r$ 最大"？** 每轮重新扫一遍全部 $N$ 个区间是 $O(N\cdot\text{答案})=O(N^2)=6.25\times10^8$，勉强但难看。注意到 `cur` **严格递增**，所以候选集合 $\{i:l_i\le\texttt{cur}\}$ 是**单调扩张**的：把区间按 $l$ 升序排序，用一个指针 `i` 从头往后扫，本轮把新进入候选的区间的 $r$ 拿去更新最大值即可，指针**永不回退**。

这里有个必须验证的细节：**上一轮扫过的区间，这一轮会不会突然变得有用？** 不会。上一轮扫过的区间 $r$ 都 $\le$ 上一轮的最大值 $=\texttt{cur}_{\text{新}}-1<\texttt{cur}_{\text{新}}$，它们连当前的 `cur` 都盖不住，彻底废了。所以"只看新扫进来的"与"看全部候选"等价（引理 2）。这样总扫描量是 $O(N)$，加上排序 $O(N\log N)$，**复杂度与 $T$ 完全无关**——$T=10^6$ 只出现在比较里，不需要开 $10^6$ 的数组。

**第五步：还有别的路吗？** 有：设 $f[t]$ = 覆盖 $[1,t]$ 的最少区间数，则 $f[t]=\min_{[l,r]\ni t}\{f[l-1]+1\}$，用线段树维护区间最小值可以做到 $O((N+T)\log T)$。但 $T=10^6$ 时它比贪心慢一个 $\log$ 还多吃几十 MB，而且正确性证明更长。**贪心已经严格最优，就没必要上数据结构。** 这一步是"识别经典模型"的价值：认出最小区间覆盖，直接拿 $O(N\log N)$ 的标准解。

**手造数据核对。** 题面只给了样例解释、没给样例输入输出，我按解释反推一组，再另造几组专打边界与前面两个反例：

| 输入（$N\ T$ + 区间） | 手算 | 程序 |
|---|---|---|
| `3 10` / `1 7`,`3 6`,`8 10`（样例解释） | $2$（第 1、3 头） | 2 |
| `2 5` / `1 2`,`4 5` | $-1$（时间段 3 是洞） | -1 |

## 二、思维链：完整证明

**记号。** 时间段集合 $U=\{1,2,\dots,T\}$。第 $i$ 头奶牛对应闭区间 $I_i=[l_i,r_i]$，$1\le l_i\le r_i\le T$（题面样例解释的语义；下文会说明 $r_i>T$ 或空区间也不影响结论）。称 $S\subseteq\{1..N\}$ 是一个**覆盖**，若 $\bigcup_{i\in S}I_i\supseteq U$。$\mathrm{OPT}=\min\{|S|:S\text{ 是覆盖}\}$，无覆盖时 $\mathrm{OPT}=\infty$。

**贪心的形式化。** 令 $c_1=1$。第 $k$ 轮：候选集 $A_k=\{i:l_i\le c_k\}$，$R_k=\max_{i\in A_k}r_i$（$A_k=\varnothing$ 时 $R_k=-\infty$）。

- 若 $R_k<c_k$：**失败**，输出 `-1` 并停机；
- 否则任取 $g_k\in A_k$ 使 $r_{g_k}=R_k$（并列时任取一个），令 $c_{k+1}=R_k+1$；
- 若 $c_{k+1}>T$：停机，输出 $k$。

记停机时共选了 $K$ 个区间（失败则 $K$ 无定义）。代码里 `cur` 就是 $c_k-1$（0-based），`mx` 就是 $R_k-1$。

---

### 引理 1（`cur` 严格递增；选中的区间互不相同；前缀覆盖不变量）

若贪心不失败，则对每个 $k\ge1$：

(a) $c_{k+1}\ge c_k+1$；
(b) $g_1,\dots,g_k$ 两两不同，且 $r_{g_1}<r_{g_2}<\dots<r_{g_k}$；
(c) $\bigcup_{j\le k}I_{g_j}\supseteq[1,c_{k+1}-1]$，且 $I_{g_j}\ni c_j$ 对每个 $j\le k$ 成立。

*证明*：(a) 不失败意味着 $R_k\ge c_k$，故 $c_{k+1}=R_k+1\ge c_k+1$。

(b) 由 (a)，$c_j$ 严格递增。对 $j<k$：$r_{g_j}=c_{j+1}-1\le c_k-1<c_k\le R_k=r_{g_k}$，故右端点严格递增，区间下标必然互不相同（同一个区间右端点固定）。**推论：$K\le N$，贪心最多 $N$ 轮就停**（要么覆盖完成，要么失败）。

(c) 对 $k$ 归纳。$k=1$：$g_1\in A_1$ 给出 $l_{g_1}\le c_1=1$，又 $r_{g_1}=R_1\ge c_1=1$，故 $I_{g_1}\supseteq[1,r_{g_1}]=[1,c_2-1]$ ✓。设 $k-1$ 成立，即前 $k-1$ 个区间盖住 $[1,c_k-1]$。第 $k$ 个满足 $l_{g_k}\le c_k\le r_{g_k}$，故 $I_{g_k}\supseteq[c_k,r_{g_k}]=[c_k,c_{k+1}-1]$。两段**首尾相接**（前一段右端 $c_k-1$，后一段左端 $c_k$），并集为 $[1,c_{k+1}-1]$ ✓。证毕。

**这条引理保证：贪心正常停机时输出的是一个合法覆盖**（$c_{K+1}>T$ ⇒ 盖住 $[1,T]$），因此 $K\ge\mathrm{OPT}$。剩下要证的是 $K\le\mathrm{OPT}$。

---

### 引理 2（单调指针：只看新扫入的区间就够了）

把区间按 $l$ 升序排序。设指针 `i` 在第 $k$ 轮把满足 $l\le c_k$ 的区间全部扫过（扫过的恰是排序后的一个前缀）。则

(a) 第 $k$ 轮结束时，已扫过的集合恰为 $A_k$；
(b) 对任意在第 $j<k$ 轮被扫过的区间 $i$，有 $r_i\le c_{j+1}-1\le c_k-1<c_k$；
(c) 因此 $\max\{r_i:i\text{ 在第 }k\text{ 轮新扫入}\}$ 与 $R_k=\max_{i\in A_k}r_i$ 在"是否 $\ge c_k$"以及"取到最大值时的右端点"上完全一致（若新扫入集合为空，则 $R_k<c_k$，判失败正确）。

*证明*：(a) 排序后 $l$ 单调不减，故 $\{i:l_i\le c_k\}$ 是排序序列的一个前缀；指针从头单向推进、每轮推进到第一个 $l>c_k$ 的位置，扫过的正是该前缀。又由引理 1(a)，$c_k$ 递增 ⇒ $A_1\subseteq A_2\subseteq\dots$，指针无需回退。

(b) 在第 $j$ 轮被扫过 ⇒ $i\in A_j$ ⇒ $r_i\le R_j=c_{j+1}-1$。再由 $c$ 严格递增得 $c_{j+1}-1\le c_k-1<c_k$。

(c) 由 (a)，$A_k=(\text{第 }k\text{ 轮新扫入})\cup(\text{之前扫过})$。由 (b)，后一部分的每个 $r_i<c_k$，故它们**既不能使 $R_k\ge c_k$ 成立，也不可能成为 $R_k$ 的取值**（只要 $R_k\ge c_k$，最大值必在新扫入部分取到）。于是：若新扫入部分的最大值 $<c_k$（含空集），则 $R_k<c_k$，贪心判失败与"用全体 $A_k$"一致；否则两者取到同一个 $R_k$。证毕。

**意义**：指针总共推进 $\le N$ 次，外层循环 $\le N$ 轮（引理 1(b)），故扫描部分总代价 $O(N)$，而不是 $O(N\cdot K)$。**这是"排序 + 单调指针"这一经典实现的全部合法性来源。**

---

### 引理 3（失败 $\iff$ 无解）

贪心在第 $k$ 轮失败（$R_k<c_k$）当且仅当不存在任何覆盖。

*证明*：

**（⇒）失败 ⇒ 无解。** 用反证法。设存在覆盖 $S$。由 $c_k\le T$（否则上一轮就停机了），$c_k\in U$，故存在 $o\in S$ 使 $c_k\in I_o$，即 $l_o\le c_k\le r_o$。前者给出 $o\in A_k$，后者给出 $R_k\ge r_o\ge c_k$，与 $R_k<c_k$ 矛盾。故无覆盖。

**（⇐）无解 ⇒ 失败。** 逆否命题：若贪心从不失败，则它必在有限轮内正常停机并输出一个覆盖。有限性：由引理 1(a)，$c_k\ge k$，故最多 $T$ 轮就有 $c_k>T$；更紧地由引理 1(b)，最多 $N$ 轮。不失败 ⇒ 每轮都执行 $c_{k+1}=R_k+1$，最终 $c_{K+1}>T$，由引理 1(c) 得到合法覆盖。故"无解"时贪心不可能永不失败。证毕。

**注**：这条引理同时说明**不需要单独写一个可行性判定**：`-1` 与正常答案出自同一个循环，且判据是"点 $c_k$ 无人能盖"这一**与贪心策略无关**的客观事实。

---

### 引理 4（贪心选择性质：交换论证）

设第 $k$ 轮开始时 $c=c_k\le T$，且存在一个最优覆盖 $O$（$|O|=\mathrm{OPT}$）满足

$$\{g_1,\dots,g_{k-1}\}\subseteq O,\qquad \bigcup_{j<k}I_{g_j}\supseteq[1,c-1].\tag{H}$$

令 $g=g_k$（贪心第 $k$ 轮的选择）。则存在最优覆盖 $O'$ 满足 (H) 把 $k-1$ 换成 $k$，即 $\{g_1,\dots,g_k\}\subseteq O'$ 且前 $k$ 个盖住 $[1,c_{k+1}-1]$。

*证明*：由引理 3 的论证（$c\le T$ 且 $O$ 是覆盖），存在 $o\in O$ 使 $l_o\le c\le r_o$。

**先定位 $o$**：$o\notin\{g_1,\dots,g_{k-1}\}$。因为对 $j<k$ 有 $r_{g_j}=c_{j+1}-1\le c_k-1=c-1<c$，而 $r_o\ge c$。故 $o\in O\setminus\{g_1..g_{k-1}\}$。

**再用贪心的极大性**：$l_o\le c$ ⇒ $o\in A_k$ ⇒ $r_o\le R_k=r_g$。同时 $l_g\le c$。于是

$$I_g\supseteq[c,r_g]\supseteq[c,r_o]\ni c.\tag{$\star$}$$

分三种情形（穷尽）：

**情形 1：$o=g$。** 取 $O'=O$，则 $g_k=g\in O'$，(H) 自动升级（覆盖部分由引理 1(c) 给出）。✓

**情形 2：$o\ne g$ 且 $g\in O$。** 考察 $O^-=O\setminus\{o\}$，$|O^-|=\mathrm{OPT}-1$。断言 $O^-$ 仍是覆盖：任取 $p\in U$，
- $p<c$：由 (H) 被 $\{g_1..g_{k-1}\}\subseteq O^-$ 盖住；
- $c\le p\le r_o$：由 ($\star$) 被 $g\in O^-$ 盖住；
- $p>r_o$：$o$ 盖不住 $p$，而 $O$ 是覆盖，故存在 $O$ 中**异于 $o$** 的区间盖住 $p$，它属于 $O^-$。

三类穷尽 $U$，故 $O^-$ 是更小的覆盖，与 $|O|=\mathrm{OPT}$ 矛盾。**所以情形 2 不可能发生**——这正是"贪心挑中的区间已经在最优解里"时不需要担心重复计数的原因：那时 $o$ 本身就是多余的，最优解不可能含冗余。

**情形 3：$o\ne g$ 且 $g\notin O$。** 取 $O'=(O\setminus\{o\})\cup\{g\}$，则 $|O'|=|O|=\mathrm{OPT}$，且 $\{g_1..g_{k-1}\}\subseteq O'$（它们不等于 $o$）、$g\in O'$。覆盖性用与情形 2 完全相同的三段分类：$p<c$ 由前缀盖住；$c\le p\le r_o$ 由 $g$ 盖住（($\star$)）；$p>r_o$ 由 $O\setminus\{o\}$ 中某个区间盖住。故 $O'$ 是最优覆盖且含 $\{g_1..g_k\}$，覆盖前缀由引理 1(c) 给出。✓

三情形穷尽，引理成立。证毕。

**为什么三段分类是"找失败条件"的产物**：交换论证最容易翻车的地方是"删掉 $o$ 之后，$o$ 原来盖的、$g$ 又没盖的部分谁负责"。这里 $r_g\ge r_o$ 保证了 $g$ 接手了 $o$ 的**整个右半**，而 $o$ 的**左半**（$<c$ 的部分）本来就由贪心前缀负责——**左边界 $c$ 恰好是"前缀已覆盖"与"待覆盖"的分界线**，这就是为什么贪心必须盯着最左未覆盖点，而不是随便挑一个区间。若把候选条件放宽成"任意区间"，$l_g$ 可能 $>c$，三段分类立刻在 $[c,l_g)$ 上出现空洞，交换失败。

### 引理 5（归纳基：$k=1$ 时 (H) 成立）

任取一个最优覆盖 $O$（若存在），则 $\{g_1,\dots,g_0\}=\varnothing\subseteq O$，且 $[1,c_1-1]=[1,0]=\varnothing$ 被空集覆盖。故 (H) 对 $k=1$ 成立。

*证明*：空集是任何集合的子集；空区间不含任何点，"覆盖空集"是空真命题。证毕。

（若不存在最优覆盖，由引理 3 贪心会失败并输出 `-1`，无需讨论。）

---

### 定理（贪心输出 $=\mathrm{OPT}$）

若存在覆盖，贪心正常停机且输出 $K=\mathrm{OPT}$；否则输出 `-1`。

*证明*：无解情形由引理 3 给出。设有解。由引理 5 与引理 4 对 $k$ 归纳：对每个 $k\le K$，存在最优覆盖 $O_k\supseteq\{g_1,\dots,g_k\}$。（归纳步骤：$k=1$ 由引理 5 提供基；若 $k<K$ 则第 $k+1$ 轮开始时 $c_{k+1}\le T$，引理 4 的前提满足，把 $O_k$ 升级为 $O_{k+1}$。）

取 $k=K$：$O_K$ 含 $K$ 个**互不相同**的区间（引理 1(b)），故 $\mathrm{OPT}=|O_K|\ge K$。另一方面引理 1(c) + 停机条件 $c_{K+1}>T$ 说明贪心自己就是一个大小为 $K$ 的覆盖，故 $K\ge\mathrm{OPT}$。两式夹逼得 $K=\mathrm{OPT}$。证毕。

---

### 引理 6（复杂度与 $T$ 无关）

时间 $O(N\log N)$，空间 $O(N)$；**不含 $T$ 的任何因子**（$T$ 只参与整数比较）。

*证明*：读入 $O(N)$。排序 $O(N\log N)$。主循环：外层轮数 $K\le N$（引理 1(b)）；内层指针 `i` 单调递增且 $\le N$，故内层总执行次数 $\le N$（引理 2 保证不回退）；每轮除内层外只做常数次比较与赋值。故循环总计 $O(N+K)=O(N)$。合计 $O(N\log N)$。空间：区间数组 $2N$ 个 `int`，排序 `std::sort` 的 $O(\log N)$ 栈，合计 $O(N)$。

代入 $N=2.5\times10^4$：约 $2.5\times10^4\times15\approx3.7\times10^5$ 次比较，实测 $0.09$ s（含读入）。对比：$O(NT)=2.5\times10^{10}$ 的逐点暴力、$O((N+T)\log T)\approx2\times10^7$ 且需 $O(T)$ 空间的线段树 DP，都明显更差。证毕。

---

### 引理 7（边界与鲁棒性）

(a) $T=1$：$c_1=1\le T$，若有区间含 $1$ 则 $R_1\ge1$，$c_2\ge2>T$，输出 $1$；否则输出 `-1`。正确。
(b) 区间嵌套 / 完全重复：不影响。贪心只关心 $R_k$ 的**值**，并列时任取一个（引理 4 不依赖具体取哪一个），重复区间只会被选一次（引理 1(b) 右端点严格递增）。
(c) 若某区间 $r_i>T$（题面未显式禁止）：$c_{k+1}=r_i+1>T$ 直接停机，该区间被计入一次，仍是最优（它单独盖住了剩余全部）。
(d) 若某区间为空（$l_i>r_i$，题面未显式禁止）：它不含任何点，$r_i<l_i\le c_k$ 时不满足 $r_i\ge c_k$，对 $R_k\ge c_k$ 无贡献；若它恰好是最大值且 $<c_k$，则 $R_k<c_k$ 判无解，与引理 3 一致。故不会误判。
(e) 输入乱序：排序后处理，与输入顺序无关。

*证明*：逐条已在上文给出；(c)(d) 的关键是引理 3 的判据"是否存在区间含点 $c_k$"只依赖区间的**点集语义**，与端点是否越界、是否为空无关。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — $T\le10^6$ 而 $N\le2.5\times10^4$：思考粒度必须是"区间"而非"时间点"，答案上界 $N$。
- **reduce to easier problem** — 翻译成经典模型：用最少的闭区间覆盖 $[1,T]$。
- **discuss by category** — 逐个试贪心判据并各造反例：右端点最小优先（$T=4$，$[1,2],[1,4],[3,4]$ → 2 而非 1）、长度最大优先（$T=10$，$[1,5],[4,9],[6,10]$ → 3 而非 2）。
- **explore its property** — 抽象两次失败的共因：评价标准脱离了"最左未覆盖点 `cur`"；覆盖问题里"伸得远"才是优点。
- **classic problem solution** — 最小区间覆盖贪心：在 $l\le\texttt{cur}$ 的区间中取 $r$ 最大者，$\texttt{cur}\leftarrow r+1$。
- **explore its property** — 交换论证证贪心选择性质，按 $p<c$ / $c\le p\le r_o$ / $p>r_o$ 三段分类；并发现"$g$ 已在最优解中"的情形会导出更小的覆盖，从而不可能发生。
- **reduce to easier problem** — 无解判定归约为同一循环里的"点 `cur` 无人能盖"，不需要独立的可行性算法。
- **classic problem solution** — 排序 + 单调指针：`cur` 递增 ⇒ 候选集单调扩张，旧候选恒废，扫描总量 $O(N)$。
- **discuss by category** — 边界分类：$T=1$、嵌套重复、乱序、右端越界、空区间，逐一核对不破坏证明。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 奶牛数 $N\le2.5\times10^4$ | `int`，读入 | 区间个数 |
| `t` | 时间段数 $T\le10^6$ | `int`，读入 | 要盖满 $[1,T]$；只参与比较 |
| `mxn` | $25000+5$ | `constexpr int{25005}` | 区间数组尺寸 |
| `inf` | $1145141919$ | `constexpr int` | 哨兵；`mx` 初值取 `-inf` |
| `a[i].l/.r` | 第 $i$ 头奶牛的区间端点，**读入后 `--` 转 0-based** | `struct seg{int l,r;}a[mxn]` | 内部时间段编号 $0\dots T-1$ |
| `cur` | 最左**未覆盖**时间段（0-based），即证明中的 $c_k-1$ | `int`，初值 $0$ | 每轮跳到 `mx+1` |
| `i` | 排序后的单调扫描指针 | `int`，初值 $0$ | **永不回退**（引理 2） |
| `mx` | 本轮候选中的最大右端点（0-based），即 $R_k-1$ | `int`，每轮重置 `-inf` | `mx<cur` ⇒ 无解 |
| `ans` | 已选奶牛数 $K$ | `int`，全局默认 $0$ | 每成功一轮 `++ans` |
| `upd(x,v)` | `x=max(x,v)` | 一行辅助函数 | 松弛最大值 |

### 算法步骤

1. I/O 加速三行（`cin.tie` → `cout.tie` → `sync_with_stdio`）。
2. 读 `n,t`；读 $N$ 个区间，端点各 `--` 转 0-based。
3. 按 `l` 升序排序（并列顺序任意，引理 4 不依赖）。
4. `cur=0,i=0`。当 `cur<t` 时循环：
   1. `mx=-inf`；
   2. 只要 `i<n && a[i].l<=cur`：`upd(mx,a[i].r)`，`++i`（单调指针）；
   3. 若 `mx<cur`：输出 `-1`，结束（引理 3）；
   4. 否则 `cur=mx+1`，`++ans`。
5. 循环正常结束（`cur>=t`）⇒ 输出 `ans`。

### 复杂度

- 时间：$O(N\log N)$（排序主导；扫描 $O(N)$，与 $T$ 无关）。$N=2.5\times10^4$ 时约 $3.7\times10^5$ 次比较。
- 空间：$O(N)$，约 $200$ KB；**不开 $T$ 大小的数组**。
- 验证状态：`/d/mingw64/bin/g++.exe -std=c++20 -O2 -Wall -Wextra` 编译零警告；题面无样例输入输出，自造 $10$ 组小数据（含样例解释反推、两个错误贪心的反例、洞 / 嵌套 / 乱序 / $T=1$ / $T=10^6$）全部与手算一致；另跑 $N=25000,T=10^6$ 的链条数据（输出 $25000$）与全左端为 $1$ 的不可行数据（输出 `-1`），均 $0.1$ s 内完成。本题贪心最优性已由引理 4 + 定理严格证明，未写暴力对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2684 搞清洁（USACO Cleaning Shifts）
// 最小区间覆盖：cur = 最左未覆盖时间段，在 l<=cur 的区间里取 r 最大者，cur=r+1
// 排序 + 单调指针：cur 递增 ⇒ 旧候选的 r 恒 < cur，永远不用回头扫
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25005};
constexpr int inf{1145141919};

int n,t,ans;
struct seg{int l,r;}a[mxn];

void upd(int&x,int v){x=max(x,v);}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>t;
	for(int i=0;i<n;++i)
	{
		cin>>a[i].l>>a[i].r;
		--a[i].l;--a[i].r;	// 内部 0-based：时间段 0..t-1
	}
	sort(a,a+n,[](seg x,seg y){return x.l<y.l;});
	int cur=0,i=0;	// cur=最左未覆盖点；i=永不回退的扫描指针
	while(cur<t)
	{
		int mx=-inf;	// 本轮候选的最大右端点；旧候选恒废，不能沿用
		while(i<n&&a[i].l<=cur)
			upd(mx,a[i].r),++i;
		if(mx<cur)	// 没有任何区间能盖住 cur ⇒ 客观无解
		{
			cout<<-1<<'\n';
			return 0;
		}
		cur=mx+1;++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`mx` 每轮重置为 `-inf`**：它代表"本轮候选的最大右端点"。若沿用上一轮的值，会把已经废掉的旧区间当成候选，可能在本该 `-1` 的地方继续跳（引理 2(b) 说明旧区间恒废，但前提是**不把它们算进本轮最大值**）。
- **`mx<cur` 而非 `mx<=cur`**：区间是**闭**的，`r==cur` 恰好盖住 `cur`，是合法的。写成 `<=` 会在"刚好接上"的数据上误判 `-1`。
- **指针 `i` 定义在循环外**：这是 $O(N)$ 扫描的关键；写进循环内就退化成 $O(NK)$。
- **`cur=mx+1`**：`mx` 已被覆盖，下一个缺口是它的后一格；0-based 下 `cur<t` 等价于 1-based 的 $c_k\le T$。
- 排序比较器只比 `l`，并列时任取——引理 4 对 $g_k$ 的选取只要求 $r_{g_k}=R_k$，与并列顺序无关。
- 全程没有 $T$ 大小的数组，$T=10^6$ 只是比较的上界。
