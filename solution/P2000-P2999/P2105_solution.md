# P2105 K皇后 — 题解

## 一、解题过程：人类思考叙事

题目：$n$ 行 $m$ 列的棋盘上放了 $K$ 个皇后，问还有多少个格子**不会被攻击**。

一个皇后会攻击：自己所在的那一行、那一列、以及两条对角线。数据范围 $n,m\le 2\times 10^4$，$K\le 500$。

最直觉的做法：开一个 $n\times m$ 的 bool 数组，标记所有被攻击的格子，最后统计 false 的个数。但 $n\cdot m$ 最大是 $4\times 10^8$，**这个数组开都开不下**（哪怕用 bit 也要 50MB），更别说时间。

所以必须换一个思路：**不逐格标记，而是逐行统计**。

关键观察：哪些格子被攻击？

- 格子 $(x,y)$ 被攻击，当且仅当：第 $x$ 行有皇后，或第 $y$ 列有皇后，或它落在某条对角线上。
- 被"行攻击"和"列攻击"的部分是整行整列，非常好统计。
- 难点只剩对角线。

对角线的处理有两种朴素写法：
1. 用 `d1[x+y]` 和 `d2[x-y]` 两个数组标记"哪些对角线上有皇后"，然后对每个格子查两个数组 —— 仍是 $O(nm)$。
2. 逐行处理：对固定的行 $x$，问"这一行里，哪些列 $y$ 落在某条对角线上"。

第 2 种好在哪？因为皇后只有 $K\le 500$ 个。对角线一共只有 $2K\le 1000$ 条（每个皇后贡献两条），而这些对角线与某一行的交点最多也就 $2K$ 个。所以对每一行，只要拿 $K$ 个皇后，算出"它们的哪条对角线穿过本行、交于哪一列"，最多得到 $2K$ 个被对角线攻击的列。

怎么算交点在哪一列？皇后在 $(q_x,q_y)$。它的一条对角线是 $x-y=q_x-q_y$，即 $y=x-(q_x-q_y)$；另一条是 $x+y=q_x+q_y$，即 $y=(q_x+q_y)-x$。对当前行 $x$，直接代入即可得到两个候选列 $y$。

于是算法是：

- 先标记 `rowHit[x]`（第 $x$ 行有皇后）、`colHit[y]`（第 $y$ 列有皇后），并统计被皇后占的**列数** `colCnt`。
- 逐行 $x=1..n$：
  - 若 `rowHit[x]` 为真，这一行整行被攻击，贡献 $0$，跳过。
  - 否则，计算本行被对角线攻击的列集合大小 `cnt`。
  - 本行安全格子数 $=m-\text{colCnt}-\text{cnt}$。

这里有个细节：被对角线攻击的列里，可能**同时**有皇后（那列已经被 `colCnt` 减过了），不能重复减。所以判断时要用 `!colHit[y]` 排除掉。

还有一个细节：同一条对角线上的两个皇后可能**同时**通过同一列攻击当前行吗？不会——同一条对角线与一行只交于一点。但**不同**皇后的不同对角线可能交于同一列：比如皇后 A 的主对角线和皇后 B 的副对角线可能过同一个格子（这在物理上就是两个皇后互相攻击的交点）。更常见的是：一个皇后的主对角线和**另一个**皇后的主对角线是两条平行线，不会交。但两个不同皇后的对角线是可能相交的（皇后之间互相攻击），所以**必须去重**。

去重怎么做？用**时间戳数组** `stamp[y]`：处理第 $x$ 行时，若 `stamp[y]==x` 说明这一列本行已经算过了，跳过；否则 `stamp[y]=x` 并计数。这样无需每次清空数组，也无需排序。

为什么时间戳是安全的？因为我们按 $x=1,2,\dots,n$ 递增处理行，而 `x` 本身在 $[1,n]$ 内唯一且递增。用 $x$ 当标记，天然区分不同行。数组 `stamp` 大小开到 $m$ 即可。

正确性上还有一个坑：对角线攻击与"行被皇后占据"会不会重复计算？不会——`rowHit[x]` 为真时我们整行跳过。若 `rowHit[x]` 为假，那么这一行没有皇后，本行也不可能是任何皇后的行，所以"行攻击"不会与"对角线攻击"重叠。而"列攻击"与"对角线攻击"的重叠通过 `!colHit[y]` 排除了。

复杂度：$O(nK)$，$2\times 10^4\times 500=10^7$，常数很小，稳过。

样例验证：$n=12,m=13,K=6$，官方答案 $25$。

## 二、思维链：完整证明

**记号约定**：皇后集合 $Q=\{(q_{x_1},q_{y_1}),\dots,(q_{x_K},q_{y_K})\}$；$R=\{x: \exists i, q_{x_i}=x\}$ 为"有皇后的行"集合，$C=\{y:\exists i,q_{y_i}=y\}$ 为"有皇后的列"集合；$c=|C|$；格子 $(x,y)$ 被攻击当且仅当 $x\in R$，或 $y\in C$，或 $\exists i$ 使 $|x-q_{x_i}|=|y-q_{y_i}|$。

**引理 1**：格子 $(x,y)$ 被攻击当且仅当 $x\in R$ 或 $y\in C$ 或 $\exists i$ 使 $x-q_{x_i}=\pm(y-q_{y_i})$。

*证明*：按题目定义，皇后攻击其所在行、所在列及两条对角线。所在行即 $x=q_{x_i}$ 的那些行，合起来是 $R$；所在列合起来是 $C$；经过皇后 $(q_{x_i},q_{y_i})$ 的主对角线满足 $x-y=q_{x_i}-q_{y_i}$，副对角线满足 $x+y=q_{x_i}+q_{y_i}$，两者合起来等价于 $x-q_{x_i}=\pm(y-q_{y_i})$。三类覆盖全部攻击方式且互不遗漏，故结论成立。证毕。

**引理 2**：若第 $x$ 行没有皇后（$x\notin R$），则第 $x$ 行中被对角线攻击的格子，恰好是那些列 $y$ 满足"存在 $i$ 使 $y=x-(q_{x_i}-q_{y_i})$ 或 $y=(q_{x_i}+q_{y_i})-x$，且 $1\le y\le m$"的位置。

*证明*：由引理 1，第 $x$ 行内被对角线攻击的格子恰为满足 $\exists i: x-q_{x_i}=\pm(y-q_{y_i})$ 的 $(x,y)$。对固定的 $i$，主对角线条件 $x-y=q_{x_i}-q_{y_i}$ 等价于 $y=x-(q_{x_i}-q_{y_i})$；副对角线条件 $x+y=q_{x_i}+q_{y_i}$ 等价于 $y=(q_{x_i}+q_{y_i})-x$。每个 $i$ 至多贡献 2 个 $y$，取遍所有 $i$ 并限制 $1\le y\le m$（否则不在棋盘内），即得引理。证毕。

**引理 3**：算法用时间戳数组统计出的 `cnt`，恰为第 $x$ 行中被对角线攻击、且该列没有皇后的列的个数。

*证明*：由引理 2，算法枚举了所有"被对角线攻击"的候选列。对每个候选列 $y$：若 `colHit[y]` 为真则该列有皇后，被 `colCnt` 项排除，跳过是正确的（避免重复计数）；否则 `stamp[y]==x` 表示本行已计过该列，跳过同样正确；否则 `stamp[y]=x` 并计数，恰好计入一次。

需要说明 `stamp` 的作用不会跨行串扰：算法按 $x$ 严格递增处理各行，初始时 `stamp` 全为 0（而 $x\ge 1$），故处理第 $x$ 行时 `stamp[y]==x` 成立当且仅当该列在**本次**处理中被计过。因此去重是精确的，既不漏计也不重计。证毕。

**引理 4**：算法累加得到的该行贡献 $m-\text{colCnt}-\text{cnt}$，恰为第 $x$ 行中不被攻击的格子数。

*证明*：设 $x\notin R$。第 $x$ 行共有 $m$ 个格子。其中 $C$ 中的 $c$ 列整列被攻击，共 $c$ 个格子；由引理 3，其余被对角线攻击的格子恰有 `cnt` 个。

需验证两类不重叠：$C$ 中的列与被对角线攻击的格子不在同一列（被 `!colHit[y]` 排除），故不重叠；又因 $x\notin R$，第 $x$ 行没有皇后，不会出现"皇后所在格"这种既是行攻击又是列攻击的重复源。

此外还需验证"行攻击"这一类在第 $x$ 行不产生贡献：因为 $x\notin R$，本行没有任何格子因"行攻击"而被攻击。

综上，被攻击的格子共 $c+\text{cnt}$ 个，不被攻击的共 $m-c-\text{cnt}$ 个，与算法累加值一致。证毕。

**引理 5**：算法对所有行的贡献之和等于棋盘上不被攻击的格子总数。

*证明*：若 $x\in R$，整行被攻击，贡献 $0$，正确（由引理 4 的论证，行被攻击时贡献 0）。若 $x\notin R$，由引理 4 贡献正确。棋盘被这些行不重不漏地划分，故总和即全盘不被攻击的格子数。证毕。

**定理**：算法输出的就是不被攻击的格子数。

*证明*：由引理 5，算法输出等于不被攻击的格子总数。证毕。

## 三、模式总结（按实际思考顺序）

1. **先算数组大小** — $n\times m$ 最多 $4\times 10^8$，逐格标记的数组根本开不下，必须放弃逐格思路。
2. **把"被攻击"拆成三类** — 行、列、对角线；行列是整行整列好统计，难点在对角线。
3. **从"逐格"转为"逐行"** — 皇后只有 $K\le 500$ 个，对角线只有 $2K$ 条；对一行而言，与这些对角线的交点最多 $2K$ 个，于是每行只需 $O(K)$ 就能算清。
4. **直接解方程求交点列号** — 主对角线 $y=x-(q_x-q_y)$，副对角线 $y=(q_x+q_y)-x$，代入当前行 $x$ 即得列号 $y$。
5. **用时间戳数组去重** — 不同皇后的对角线可能交于同一格；用 `stamp[y]=x` 标记"本行已计过"，既去重又无需清空数组。
6. **注意排除重叠** — 被对角线攻击的列若同时有皇后，已被"列攻击"项统计，须用 `!colHit[y]` 排除，否则重复减。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 棋盘行数 | `int`，$\le 2\times 10^4$ |
| $m$ | 棋盘列数 | `int`，$\le 2\times 10^4$ |
| $K$ | 皇后个数 | `int`，$\le 500$ |
| $q_x[i],q_y[i]$ | 第 $i$ 个皇后的位置 | `int[]`，$0..K-1$ |
| `rowHit[x]` | 第 $x$ 行是否有皇后 | `bool[]`，大小 $n+5$ |
| `colHit[y]` | 第 $y$ 列是否有皇后 | `bool[]`，大小 $m+5$ |
| `colCnt` | 有皇后的列数 $c$ | `int` |
| `stamp[y]` | 去重时间戳，等于行号 $x$ 表示本行已计过该列 | `int[]` |
| `cnt` | 当前行被对角线攻击（且该列无皇后）的列数 | `int` |
| `ans` | 答案 | `i64` |

### 算法步骤

1. 读入 $n,m,K$ 及 $K$ 个皇后坐标，同时置 `rowHit[qx[i]]=true`、`colHit[qy[i]]=true`。
2. 统计 `colCnt` = 满足 `colHit[y]` 的列数。
3. 逐行 $x=1..n$：
   - 若 `rowHit[x]` 为真，`continue`（整行被攻击，贡献 0）。
   - 令 `cnt=0`，遍历每个皇后 $i$，算两个候选列 $y_1=x-(q_x[i]-q_y[i])$、$y_2=(q_x[i]+q_y[i])-x$；对每个候选列，若 $1\le y\le m$、且 `!colHit[y]`、且 `stamp[y]!=x`，则 `stamp[y]=x` 并 `++cnt`。
   - `ans += m - colCnt - cnt`。
4. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(nK)$。外层 $n$ 行，内层 $K$ 个皇后，$2\times 10^4\times 500=10^7$ 次内层操作。
- 空间复杂度：$O(n+m+K)$。只存皇后坐标和几个一维标记数组，不存棋盘。

### 验证状态

- 标程 `P2105.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `12 13 6` + 6 个皇后输出 `25`，与官方一致。
- 编写暴力 `P2105_brute.cpp`（用 `d1[x+y]`、`d2[x-y+mxn]` 标记对角线后逐格统计）与对拍脚本 `P2105_check.py`，在随机小棋盘上对拍 **2000 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2105 K皇后
#include<bits/stdc++.h>
using namespace std;

using i64=long long;

constexpr int mxn{20005};

int n,m,K;
int qx[mxn],qy[mxn];
bool rowHit[mxn],colHit[mxn];
int stamp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>K;
	for(int i=0;i<K;++i)
	{
		cin>>qx[i]>>qy[i];
		rowHit[qx[i]]=true;
		colHit[qy[i]]=true;
	}
	int colCnt=0;
	for(int j=1;j<=m;++j)
		if(colHit[j]) ++colCnt;

	i64 ans=0;
	for(int x=1;x<=n;++x)
	{
		if(rowHit[x]) continue;
		// 本行被对角线打到的列(去重, 且不含已被皇后占的列)
		int cnt=0;
		for(int i=0;i<K;++i)
		{
			int y1=x-(qx[i]-qy[i]);
			if(y1>=1 && y1<=m && !colHit[y1] && stamp[y1]!=x)
			{
				stamp[y1]=x;
				++cnt;
			}
			int y2=(qx[i]+qy[i])-x;
			if(y2>=1 && y2<=m && !colHit[y2] && stamp[y2]!=x)
			{
				stamp[y2]=x;
				++cnt;
			}
		}
		ans+=m-colCnt-cnt;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 不开 $n\times m$ 数组。整个算法只用到长度 $O(n+m+K)$ 的一维数组。
- `stamp[y]=x` 用行号当时间戳：因为行号严格递增且从 $1$ 开始，天然完成"每行独立去重"，不需要在每行前清空数组。
- `!colHit[y]` 的判断不能省：被对角线攻击的列如果本来就有皇后，那一列已经被 `colCnt` 扣过一次，再扣就重复了。
- `y1 = x-(qx[i]-qy[i])` 是主对角线与本行的交点，`y2 = (qx[i]+qy[i])-x` 是副对角线与本行的交点；两者都可能越界，必须判 `1<=y<=m`。
- `ans` 用 `i64`：$n\cdot m$ 最大 $4\times 10^8$，虽然实际被攻击的格子数会更小，但用 `long long` 免去边界上的担心。
