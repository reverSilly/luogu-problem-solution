# P2978 [USACO10JAN] Tea Time S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 头奶牛（$N\le1000$），初始有 $M$ 对朋友关系（$M\le2000$，无重边，$A_i\ne B_i$）。关系是对称的。演化规则：若 $i$ 与 $k$ 是朋友、$k$ 与 $j$ 是朋友，则 $i$ 与 $j$ 会在某次活动中成为朋友。这个过程一直进行到**没有新朋友产生**为止。$Q$ 个询问（$Q\le100$），每个给一对不同编号 $X_j,Y_j$，问最终它们是否认识，输出 `Y` 或 `N`。

**第一步：直接模拟行不行？** 把规则写成「每轮枚举所有三元组 $(i,k,j)$，有 $i\!-\!k$、$k\!-\!j$ 就加边 $i\!-\!j$」。每轮 $O(N^3)=10^9$，轮数最坏可达 $O(N)$（长链要一轮轮缩短），总量完全不可控。就算优化成「枚举 $k$ 再枚举它的邻居对」，每轮 $O(\sum_k\deg(k)^2)$，稠密时仍是 $O(N^3)$ 级。**模拟不是出路，得找闭式刻画。**

**第二步：盯着题面的例子找规律。** 初始边 $2\!-\!5,2\!-\!3,4\!-\!5$。图 (a) 里 $\{2,3,4,5\}$ 连成一片，$1$ 是孤立点。演化：第一轮 $2$ 和 $4$ 通过共同朋友 $5$ 认识、$3$ 和 $5$ 通过 $2$ 认识；第二轮 $3$ 和 $4$ 通过 $2$（或 $5$）认识。终态 (c)：$\{2,3,4,5\}$ **两两认识**（完全图），$1$ 依旧谁也不认识。

规律呼之欲出：**一个连通块最终变成完全图；不同连通块之间永远不产生新边。** 若此猜想成立，「最终是否认识」就等价于「初始图里是否连通」——动态闭包过程被归约成静态连通性判定，并查集直接秒杀。

**第三步：为什么猜想可能对？两个方向的直觉。**

- **不同块之间不会连边**：新边 $i\!-\!j$ 要求存在 $k$ 使 $i\!-\!k$、$k\!-\!j$ 都是（当时的）边。这条长度 $2$ 的路径说明 $i,j$ **本来就连通**——新边永远连接「同一连通块内」的两点，连通块划分从不改变。这是不变量。
- **同一块内迟早两两认识**：任何两点间有一条初始路径 $v_0v_1\dots v_k$。规则能把长度 $2$ 的路径「短路」成边；反复短路，长路径也能缩成边。比如链 $1\!-\!2\!-\!3\!-\!4$：第一轮加 $1\!-\!3,2\!-\!4$，第二轮 $1$ 和 $4$ 通过 $2$（$1\!-\!2$ 与 $2\!-\!4$）认识。对路径长度做归纳就能严格证明（引理 3）。

**第四步：落地成并查集。** 读入每条初始边就 `union`；询问时 `getrt(x)==getrt(y)` 输出 `Y`，否则 `N`。不需要真的模拟任何一轮活动。

**第五步：细节核对。**

1. **孤立点**：没有边的牛只认识自己；询问保证 $X\ne Y$，所以孤立点与任何其它牛都答 `N`。并查集里它自成一个根，天然正确。
2. **$X\ne Y$ 保证**：题面明说询问是「一对不同的奶牛编号」，不用处理自问。
3. **无重边保证**：有重边也不影响并查集（`union` 幂等），这个保证只是让 $M$ 的计数干净。
4. **0-based**：读入 `--u;--v`，`iota(f,f+n,0)` 初始化。
5. **「很久以后」的语义**：过程单调加边、边集有限，必然到达不动点（引理 1），所以「直到没有新认识」是良定义的终态，与轮数细节无关。

**手造数据核对。** 第一组用题面例子：$N=5,M=3$，边 $2\!-\!5,2\!-\!3,4\!-\!5$；询问 $(3,4),(1,2),(2,4),(1,5)$。$\{2,3,4,5\}$ 同块、$1$ 孤立，期望 `Y N Y N`。程序输出一致 ✓。

第二组专打「需要多轮演化」的长链：$N=4$，边 $1\!-\!2,2\!-\!3,3\!-\!4$；询问 $(1,4),(1,3)$。$1$ 与 $4$ 初始距离 $3$，第一轮加 $1\!-\!3,2\!-\!4$，第二轮 $1,4$ 通过共同朋友 $2$ 认识——终态认识，期望 `Y Y`。程序输出一致 ✓。这组数据说明「只加一轮边」的假算法会错，而连通性判定不受轮数影响。

## 二、思维链：完整证明

**记号。** 顶点集 $V=\{1..N\}$。初始边集 $E_0$（无向、无重边、无自环）。演化：$E_{t+1}=E_t\cup\bigl\{\{i,j\}:\exists k\in V,\{i,k\}\in E_t\land\{k,j\}\in E_t\bigr\}$。注意 $i\ne j$（题面朋友关系发生在不同牛之间；即便允许 $i=j$ 也不影响下文任何结论，因为自环不改变连通性）。$E_\infty=\bigcup_{t\ge0}E_t$。「最终认识」定义为 $\{X,Y\}\in E_\infty$。

---

### 引理 1（单调性与终止：$E_\infty$ 是良定义的不动点）

(a) $E_t\subseteq E_{t+1}$ 对所有 $t$ 成立；
(b) 存在 $t^\*\le\binom{N}{2}$ 使 $E_{t^\*}=E_{t^\*+1}=\dots=E_\infty$；
(c) $E_\infty$ 对规则封闭：若 $\{i,k\},\{k,j\}\in E_\infty$，则 $\{i,j\}\in E_\infty$。

*证明*：(a) 由定义 $E_{t+1}=E_t\cup(\dots)\supseteq E_t$。

(b) 所有 $E_t$ 都是「$V$ 上无序对」这个有限集合（大小 $\binom{N}{2}$）的子集，且链单调递增。每步要么严格增大（至少加一条新边），要么不变。严格增大至多发生 $\binom{N}{2}$ 次，故存在 $t^\*\le\binom{N}{2}$ 使 $E_{t^\*+1}=E_{t^\*}$。一旦相等，由规则的确定性（$E_{t+1}$ 是 $E_t$ 的函数），归纳得此后所有 $E_t$ 都等于 $E_{t^\*}$，故 $E_\infty=E_{t^\*}$。

(c) 设 $\{i,k\},\{k,j\}\in E_\infty=E_{t^\*}$。由规则，$\{i,j\}\in E_{t^\*+1}=E_{t^\*}=E_\infty$。证毕。

**意义**：题面「举办很久以后（直到没有新的奶牛彼此认识）」说的就是 $E_\infty$；(b) 保证它存在且有限步可达，(c) 保证它确实是「不再有新朋友」的终态。

---

### 引理 2（连通块不变量）

对所有 $t$，图 $(V,E_t)$ 的连通块划分与 $(V,E_0)$ 完全相同。

*证明*：对 $t$ 归纳。$t=0$ 平凡。设 $E_t$ 与 $E_0$ 同划分。考察 $E_{t+1}$ 新增的每条边 $\{i,j\}$：由规则存在 $k$ 使 $\{i,k\},\{k,j\}\in E_t$，即 $i,j$ 在 $E_t$ 中已被长度 $2$ 的路径连通，属于同一连通块。

**断言**：在同一连通块内部加边不改变连通块划分。证：加边只可能让「原本不连通的点对」变连通；而新边两端本就连通，任何经过新边的路径都可以把新边替换成原有的 $i\!-\!k\!-\!j$ 路径，故「点对连通」关系不变，划分不变。

逐条加入新边（有限条），每条都不改变划分，故 $E_{t+1}$ 与 $E_t$ 同划分，由归纳假设与 $E_0$ 同划分。证毕。

**推论（必要性方向）**：若 $\{X,Y\}\in E_\infty$，则 $X,Y$ 在 $E_\infty$ 中连通（一条边当然连通），由引理 2 它们在 $E_0$ 中连通。**不同初始连通块的牛永远不认识。**

---

### 引理 3（路径短路：初始路径的两端终将成为朋友）

设 $v_0v_1\dots v_k$ 是 $E_0$ 中的一条路径（$k\ge1$，顶点两两不同）。则 $\{v_0,v_k\}\in E_\infty$。

*证明*：对 $k$ 强归纳。

**$k=1$**：$\{v_0,v_1\}\in E_0\subseteq E_\infty$（引理 1(a)）✓。

**$k=2$**：$\{v_0,v_1\},\{v_1,v_2\}\in E_0$，$v_1$ 是共同朋友，由规则 $\{v_0,v_2\}\in E_1\subseteq E_\infty$ ✓。

**$k\ge3$**：考虑两条更短的子路径：
- $v_0v_1\dots v_{k-2}$，长度 $k-2$。因 $k\ge3$，$1\le k-2<k$，由归纳假设 $\{v_0,v_{k-2}\}\in E_\infty$。
- $v_{k-2}v_{k-1}v_k$，长度 $2<k$，由归纳假设（或直接 $k=2$ 情形）$\{v_{k-2},v_k\}\in E_\infty$。

由引理 1(b)，$E_\infty=E_{t^\*}$，故这两条边**同时**存在于 $E_{t^\*}$ 中（单调性保证「各自最终出现」可以取时刻的最大值合并成「同时存在」——这里直接用了不动点刻画，更干净）。$v_{k-2}$ 是 $v_0$ 与 $v_k$ 的共同朋友，由规则 $\{v_0,v_k\}\in E_{t^\*+1}=E_\infty$ ✓。

三情形穷尽，归纳完成。证毕。

**注**：证明只要求「子路径是原路径的连续段」，顶点互异性自动继承，无需额外处理。$k=3$ 时第一条子路径长度 $1$、第二条长度 $2$，都落在基础情形，归纳链条闭合。

---

### 引理 4（终态刻画：认识 $\iff$ 初始连通）

对任意不同顶点 $X,Y$：$\{X,Y\}\in E_\infty\iff X,Y$ 在 $(V,E_0)$ 中连通。进一步，$(V,E_\infty)$ 的每个连通块都是完全图。

*证明*：($\Rightarrow$) 引理 2 推论。

($\Leftarrow$) $X,Y$ 在 $E_0$ 中连通 $\Rightarrow$ 存在 $E_0$ 中的路径 $v_0=X,\dots,v_k=Y$（连通的标准定义；可取简单路径使顶点互异）。由引理 3，$\{X,Y\}\in E_\infty$。

「每个连通块是完全图」：任取同一块内两点，由 ($\Leftarrow$) 它们相邻；块内所有点对都相邻即完全图。证毕。

**这就是第二部分的中心结论**：动态的「朋友的朋友」闭包过程，其终态被静态的连通性完全刻画。第一部分观察到的「$\{2,3,4,5\}$ 变完全图、$1$ 孤立」是它的一个实例。

---

### 引理 5（并查集正确性）

程序维护森林 `f[]`：初始 `f[i]=i`；每读入一条边 $(u,v)$ 执行 `f[getrt(u)]=getrt(v)`；`getrt` 带路径压缩。则任意时刻，`getrt(x)==getrt(y)` $\iff x,y$ 在**已读入边**构成的图中连通。

*证明*：维护不变量：「`f` 森林的每棵树恰为一个连通块，树根是该块的代表」。

初始：$N$ 棵单点树，$E=\varnothing$，每点自成一连通块 ✓。

合并操作：设读入边 $(u,v)$，$r_u=\texttt{getrt}(u)$、$r_v=\texttt{getrt}(v)$。
- 若 $r_u=r_v$：$u,v$ 已连通，加边不改变划分（引理 2 断言），代码执行 `f[r_u]=r_v` 即 `f[r]=r`，森林不变 ✓。
- 若 $r_u\ne r_v$：$u,v$ 分属两块，加边恰好把这两块合并成一块（新边提供跨块连接；其余点对的连通性不变）。代码把 $r_u$ 所在整棵树挂到 $r_v$ 下，两棵树并为一棵，其余树不动——森林划分恰好同步于连通块划分 ✓。

路径压缩：`getrt(x)` 递归把 $x$ 到根路径上的所有节点直接挂到根下。每个节点的根不变（压缩前沿父链走到根 $r$，压缩后仍指向 $r$），树成员集合不变，故不变量保持；返回值仍是该块代表。

对读入边数归纳，不变量恒成立。询问时所有 $M$ 条边已读入，故 `getrt(x)==getrt(y)` $\iff$ 初始图连通。证毕。

---

### 引理 6（复杂度）

时间 $O\bigl(N+(M+Q)\,\alpha(N)\bigr)$，空间 $O(N)$。

*证明*：`iota` 初始化 $O(N)$。每次 `getrt` 均摊 $O(\alpha(N))$（路径压缩的经典均摊界，$\alpha$ 为反阿克曼函数，$N\le1000$ 时 $\alpha\le4$）；$M$ 次合并各 $2$ 次 `getrt`，$Q$ 次询问各 $2$ 次，合计 $O((M+Q)\alpha(N))$。代入 $N=1000,M=2000,Q=100$：约数千次基本操作，远低于任何时限。空间仅 `f` 数组 $O(N)$。证毕。

---

### 定理

程序对每个询问输出 `Y` 当且仅当两头牛在终态 $E_\infty$ 中认识，总复杂度 $O(N+(M+Q)\alpha(N))$。

*证明*：引理 1 保证终态 $E_\infty$ 良定义；引理 2 给出必要性（认识 $\Rightarrow$ 初始连通）；引理 3 给出充分性的核心（初始路径 $\Rightarrow$ 终态有边）；引理 4 合并成充要条件「认识 $\iff$ 初始连通」；引理 5 保证并查集恰好判定初始连通性；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 新边只出现在「长度 $2$ 路径的两端」；规则单调加边、边集有限 ⇒ 终态存在且封闭。
2. **consider easier version** — 直接模拟每轮 $O(N^3)$、轮数不可控，放弃模拟，寻找闭式刻画。
3. **explore its property** — 手推题面例子：连通块 $\{2,3,4,5\}$ 变完全图、孤立点不变 ⇒ 猜想「终态认识 = 初始连通」。
4. **explore its property** — 两个不变量撑起猜想：新边两端本就连通（块划分不变）；路径可反复短路（块内变完全图），后者对路径长度强归纳。
5. **reduce to easier problem** — 动态闭包过程归约为静态连通性判定，完全不用模拟轮次。
6. **classic problem solution** — 并查集：读边即合并，询问比根，$O(\alpha(N))$ 每问。
7. **discuss by category** — 归纳基础 $k=1,2$ 与递推 $k\ge3$ 分类；孤立点、$X\ne Y$ 保证、重边幂等逐一核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 牛数 $N\le1000$ | `int` | 读入 |
| `m` | 初始朋友对数 $M\le2000$ | `int` | 读入 |
| `q` | 询问数 $Q\le100$ | `int` | 读入 |
| `mxn` | $1000+5$ | `constexpr int` | 数组尺寸松弛 |
| `f[i]` | 并查集父指针；根满足 `f[i]==i` | `int[mxn]` | `iota(f,f+n,0)`；**每棵树 = 一个初始连通块** |
| `getrt(x)` | 找根 + 路径压缩 | `int(int)` | 返回值 = $x$ 所在连通块代表 |
| `u,v` / `x,y` | 读入的边 / 询问对（转 0-based） | `int` | 循环内临时 |

### 算法步骤

1. I/O 加速三行。
2. 读 $N,M,Q$；`iota(f,f+n,0)`。
3. 读每条边 $(u,v)$，`--u;--v`，执行 `f[getrt(u)]=getrt(v)`。
4. 每个询问读 $(x,y)$，`--x;--y`，输出 `getrt(x)==getrt(y)?"Y\n":"N\n"`。

### 复杂度

- 时间：$O(N+(M+Q)\alpha(N))$，本题规模下约数千次操作。
- 空间：$O(N)$，一个 `int` 数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子（边 $2\!-\!5,2\!-\!3,4\!-\!5$，询问 $(3,4),(1,2),(2,4),(1,5)$）输出 `Y N Y N` 吻合；另造「长度 $3$ 链需两轮演化」数据输出 `Y Y` 吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2978 [USACO10JAN] Tea Time S
// 「共同朋友」闭包 = 初始图的连通块（每个连通块最终变成完全图）⇒ 并查集
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,m,q,f[mxn];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>q;
	iota(f,f+n,0);
	for(int i=0,u,v;i<m;++i)
	{
		cin>>u>>v;--u;--v;
		f[getrt(u)]=getrt(v);
	}
	for(int i=0,x,y;i<q;++i)
	{
		cin>>x>>y;--x;--y;
		cout<<(getrt(x)==getrt(y)?"Y\n":"N\n");
	}
	return 0;
}
```

### 代码说明

- **核心是「不模拟」**：代码里没有任何一轮「活动」，因为引理 4 证明了终态认识关系就是初始连通性。模拟轮次是本题最大的思维陷阱。
- `iota(f,f+n,0)` 必须在读边之前；`f` 是全局数组默认 $0$，若不初始化，所有点的根都会错误地指向 $0$——这是并查集最经典的「默认 $0$ 不是合法初值」陷阱（本题 $0$ 号点真实存在，错得悄无声息）。
- `f[getrt(u)]=getrt(v)` 一行合并：两侧都先取根，保证挂的是树根而不是中间节点；同根时是自赋值，幂等无害（重边也安全）。
- `getrt` 路径压缩写成一行递归 `return f[x]=getrt(f[x]);`，压缩不改变任何点的根（引理 5）。
- 输出用三目拼 `"Y\n"/"N\n"`，大小写严格按题面；询问保证 $X\ne Y$，无需处理自问。
