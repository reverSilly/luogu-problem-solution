# P2367 语文成绩 — 题解

## 一、解题过程：人类思考叙事

题意很直白：$n$ 个学生的初始成绩 $a_1\sim a_n$，接下来 $p$ 次操作，每次把第 $x$ 到第 $y$ 个学生每人加 $z$ 分，全部操作结束后输出**全班最低分**。

数据范围是本题的全部难点：$n\le 5\times 10^6$，$p\le n$。初始成绩 $\le 100$，$z\le 100$。

**第一反应：直接模拟。**

对每次操作，从 $x$ 循环到 $y$ 逐个加 $z$。单次操作最坏 $O(n)$，总复杂度 $O(np)=2.5\times 10^{13}$，彻底没戏。不过这个想法很有价值：它说明**每个位置最终的值 = 初始值 + 覆盖它的所有操作的 $z$ 之和**。也就是说，"谁加了多少"是独立算的，答案只是这个结果的最小值。

**第二反应：既然只要最小值，能不能只维护最小值？**

也就是：维护当前最小值 $mn$ 及其位置，每次区间加时只更新这个 $mn$。问题是区间加会把区间内的一大片元素同时抬高，最小值可能"搬家"到区间外，而"区间外的次小值"这个信息我们并没有存。一个两步的反例就致命：

$$a=[5,6]\quad\xrightarrow{[1,1]\mathrel{+}=1}\quad a=[6,6].$$

操作前最小值是 $5$，操作后最小值变成 $6$——要想算出这个 $6$，就必须知道"第二小的值是 $6$"。推广一步：覆盖区间是任意的，所以要能回答任何一次区间加后的最小值，本质上得掌握整个数组（次小值、第三小值、……）。所以"只维护最小值"这条路走不通，我们被迫承认：**必须算出每个位置最终的值**。

**第三反应：能不能用数据结构维护区间加 + 全局最小？**

能。线段树打懒标记，区间加 $O(\log n)$、全局最小 $O(1)$，总复杂度 $O((n+p)\log n)\approx 2\times 10^8$。但这里有两个现实问题：常数大（$5\times 10^6$ 的线段树要开 $4n$ 个结点、每个结点存懒标记，内存和常数都很吃力），而且**这是个离线问题**——我们只需要最后的答案，不需要中途查询。既然如此，用带 $\log$ 的结构是杀鸡用牛刀。

**第四反应（关键）：区间加能不能变成 $O(1)$？**

能，这就是**差分**。设

$$d_1=a_1,\qquad d_i=a_i-a_{i-1}\ (2\le i\le n).$$

那么 $a_i=\sum_{j\le i}d_j$（前缀和）。而"把 $a_x\sim a_y$ 全加 $z$"这件事，在差分数组上只体现为**两个单点修改**：

$$d_x\mathrel{+}=z,\qquad d_{y+1}\mathrel{-}=z .$$

为什么？差分记录的是"相邻元素的跳跃量"。区间内部相邻元素的差不变（都加了 $z$），只有两个"边界"上的差会变：$x-1$ 与 $x$ 之间多跳了 $z$，$y$ 与 $y+1$ 之间少了 $z$。区间加的复杂度从 $O(\text{区间长})$ 掉到 $O(1)$，总复杂度 $O(n+p)$。

**第五反应：既然只加不改，能不能只在最后算一次前缀和？**

可以，而且必须这样。因为所有操作都是加法，加法可交换、可叠加：每一步都在同一个差分数组上累加，最后做**一次**前缀和就能还原所有 $a_i$，边还原边取最小值。全过程 $O(n+p)$，一次扫描。

**接下来的坑都是工程级的：**

- **输入量**：$n+p$ 次读入，每次 1 或 3 个整数，最多约 $2\times 10^7$ 个整数、上百 MB。`cin`（即使关了同步）在这个量级上偏慢，必须自己用 `fread` 缓冲读入。
- **内存**：$n=5\times 10^6$ 时一个 `int` 数组就是 20 MB。不要再开第二个数组存原始成绩——可以在读完之后**原地倒着减**，把 $a$ 变成 $d$（见引理 5）。
- **下标越界**：$d_{y+1}$ 在 $y=n$ 时是 $d_{n+1}$，数组必须开到 $n+2$。而 $d_{n+1}$ 只影响"第 $n+1$ 个学生的值"，那个学生不存在，所以它有没有被减都无所谓——但**必须**有地方放它，不能写到数组外。
- **$x=1$ 的情形**：$d_1$ 的定义是 $a_1$ 本身（而不是 $a_1-a_0$），要单独确认"$d_x\mathrel{+}=z$"在 $x=1$ 时仍然成立。

**第六反应：值会不会超 int？**

初始分 $\le 100$，每次加 $\le 100$，最多 $p\le n\le 5\times10^6$ 次操作，所以任何位置最终 $\le 100+5\times10^6\times100=5.000001\times10^8<2^{31}-1$。int 安全，不用 long long（省一半内存，这在 20 MB 的规模上是实打实的好处）。

自造小例子（题面无样例）验证理解：

```
3 2
5 5 5
1 2 3
2 3 1
```

初始 $a=[5,5,5]$，倒序差分成 $d=[5,0,0]$。第一次操作 $(1,2,3)$：$d_1\mathrel{+}=3,\ d_3\mathrel{-}=3$ ⇒ $d=[8,0,-3]$。第二次操作 $(2,3,1)$：$d_2\mathrel{+}=1,\ d_4\mathrel{-}=1$（$d_4$ 是"幽灵位"，无数组下标 $4$ 的学生，不影响任何 $A_i$）⇒ $d=[8,1,-3]$。前缀和还原 $A=[8,9,6]$，最小值 $6$。

手算核对：$[5,5,5]\xrightarrow{1\sim2\text{ 加 }3}[8,8,5]\xrightarrow{2\sim3\text{ 加 }1}[8,9,6]$，最小 $6$ ✓。

这里正好踩到差分最容易错的两处：$d_{y+1}$ 的那一项在 $y<n$ 时真实生效、在 $y=n$ 时是幽灵位（要有槽位但不起作用）；而 $d_x$ 的 $+z$ 在 $x=1$ 时同样成立（因为 $a_0=0$ 前后不变）。

## 二、思维链：完整证明

固定记号：初始成绩 $a_1,\dots,a_n$；补充定义 $a_0=0$；差分

$$d_i=a_i-a_{i-1}\qquad(1\le i\le n),$$

其中 $a_0=0$，于是 $d_1=a_1$。另外为了写操作方便，形式上也记 $d_{n+1}=a_{n+1}-a_n$，$a_{n+1}$ 是"不存在的学生"，其值我们从不使用。

**引理 1（差分还原）**：对任意 $1\le i\le n$，$\sum_{j=1}^{i}d_j=a_i$。

*证明*：把定义代入，得到裂项求和

$$\sum_{j=1}^{i}d_j=\sum_{j=1}^{i}(a_j-a_{j-1})=(a_1-a_0)+(a_2-a_1)+\cdots+(a_i-a_{i-1})=a_i-a_0=a_i,$$

因为中间项两两抵消（$+a_1$ 与 $-a_1$，$+a_2$ 与 $-a_2$，……），只剩首尾。又 $a_0=0$。证毕。

**引理 2（区间加 = 两个单点修改）**：设对 $a_x\sim a_y$ 全部加 $z$（$1\le x\le y\le n$），得到新数组 $a'$，新差分 $d'$。则

$$d'_x=d_x+z,\qquad d'_{y+1}=d_{y+1}-z,\qquad d'_i=d_i\ (\text{其它 }i).$$

*证明*：逐类讨论 $i$ 的位置。注意 $d'_i=a'_i-a'_{i-1}$，而 $a'_i=a_i+z$ 当且仅当 $x\le i\le y$，否则 $a'_i=a_i$（$i=0$ 时约定 $a'_0=a_0=0$）。

- $i<x$：$i$ 与 $i-1$ 都不在 $[x,y]$ 内（$i-1<i<x$），故 $a'_i-a'_{i-1}=a_i-a_{i-1}=d_i$。
- $i=x$：$a'_x=a_x+z$，而 $x-1\notin[x,y]$ 故 $a'_{x-1}=a_{x-1}$（$x=1$ 时 $a'_0=0=a_0$ 同样成立）。故 $d'_x=d_x+z$。
- $x<i\le y$：$i$ 与 $i-1$ 都在区间内，故 $d'_i=(a_i+z)-(a_{i-1}+z)=d_i$。
- $i=y+1$（若 $y<n$）：$a'_{y+1}=a_{y+1}$（不在区间内），$a'_y=a_y+z$，故 $d'_{y+1}=a_{y+1}-a_y-z=d_{y+1}-z$。若 $y=n$，则 $d_{n+1}$ 只出现在"还原 $a_{n+1}$"里，而我们从不还原 $a_{n+1}$，故这一项无实际作用，但形式上仍记作减 $z$。
- $i>y+1$：$i$ 与 $i-1$ 都不在区间内，故不变。

五类位置穷尽了所有可能（$i< x$、$i=x$、$x<i\le y$、$i=y+1$、$i>y+1$），故结论成立。证毕。

注意 $x=1$ 的情形已包含在"$i=x$"一类中，因为 $a_0=0$ 在加操作前后都不变，所以 $d_1=a_1$ 与 $d_1=a_1-a_0$ 两种写法结论相同。

**引理 3（多个操作可叠加，故只需最后一次前缀和）**：设依次执行了 $p$ 次区间加，第 $k$ 次为 $(x_k,y_k,z_k)$。则最终的第 $i$ 个成绩为

$$A_i=a_i+\sum_{k:\,x_k\le i\le y_k}z_k,$$

并且"每步都对差分数组执行引理 2 的两点修改"与"先在空差分上累加所有修改、最后一次前缀和"给出相同结果。

*证明*：第一个等式可由引理 2 逐步归纳（每一步之后都满足引理 1，故还原正确）；或直接对 $i$ 计数：$a_i$ 增加了所有覆盖 $i$ 的操作之和。

第二个结论：整个过程中我们只对差分数组做加法。令 $\Delta_i$ 表示总共施加在 $d_i$ 上的增量。由引理 2，$\Delta_i=+\sum_{k:x_k=i}z_k-\sum_{k:y_k+1=i}z_k$。这些加法与执行次序无关（加法可交换、可结合），故"边做边累加"与"先攒后做"结果相同；再由引理 1，最终 $A_i=\sum_{j\le i}(d_j+\Delta_j)$，只需算一次前缀和。证毕。

**引理 4（为什么无法只维护一个最小值）**：答案按定义是 $\min_{1\le i\le n}A_i$，因此正确做法必须掌握全部 $A_i$；"只记当前最小值及其位置"的信息量不足以应对区间加。

*证明*：反例指出信息不足。取 $n=2$，$a=[5,6]$，操作 $[1,1]\mathrel{+}=1$。旧的最小值是 $5$（位置 $1$），并且位置 $1$ 落在被覆盖区间内，操作后变成 $6$；此时覆盖区外的位置 $2$ 仍然是 $6$，全局最小值是 $6$。算法若只持有 $(mn=5,\ pos=1)$ 这两个量，操作后它无法回答"新的最小值是多少"——它不知道位置 $2$ 的值，也就无法与"覆盖内平移后的值"比较。要让这种比较成为可能，必须知道"覆盖外的最小值"（甚至次小值、第三小值……因为覆盖区间是任意的），这等价于掌握整个数组。另一方面，本算法确实遍历了全部 $i\in[1,n]$，所以不存在这类遗漏：它按引理 1 还原出每个 $A_i$，再取 $\min$。证毕。

**引理 5（原地倒序差分）**：把成绩读入数组 `d[1..n]` 后，令 $i$ 从 $n$ 递减到 $1$ 执行 `d[i]-=d[i-1]`（`d[0]=0`），结束时 `d[i]=a[i]-a[i-1]`。

*证明*：对 $i$ 做归纳（沿 $n,n-1,\dots,1$ 的顺序，即对"还剩几个待处理"归纳）。当处理 $i$ 时，位置 $1..i-1$ 还没被处理过，故 `d[i-1]` 仍是原始的 $a_{i-1}$（归纳假设：所有 $j>i$ 的位置已被改写，而 $j>i$ 的改写只读取 $d[j-1]$ 中的 $a_{j-1}$，写的是 $d[j]$，不会污染 $d[i-1]$）。于是 `d[i]=a[i]-a[i-1]` 正确。$i=1$ 时 `d[0]` 是全局数组的初值 $0$，正对应 $a_0=0$。证毕。（若正序遍历，$d[i-1]$ 已被改写成差分，$d[i]-d[i-1]$ 就变成了 $(a_i-a_{i-1})-(a_{i-1}-a_{i-2})$，全错。这是本题最典型的实现陷阱。）

**引理 6（值域与哨兵安全）**：所有中间量都在 int 范围内；初值 $1145141919$ 的哨兵一定大于真实答案，不会残留。

*证明*：设第 $i$ 位成绩为 $A_i$。初始 $A_i\le 100$；每次操作对单个位置的增量 $z_k\le 100$，且覆盖某位置的操作至多 $p\le n\le 5\times 10^6$ 次，故

$$0\le A_i\le 100+5\times10^6\cdot 100=500\,000\,100<2^{31}-1\approx2.15\times10^9 .$$

（若 $z$ 取到负数，同理 $A_i\ge -5\times10^8$，绝对值仍安全。）差分数组的元素是相邻两值之差，故 $|d_i|\le 5.000001\times10^8+5\times10^8\approx1.0\times10^9<2^{31}-1$，再叠加一次 $z$ 也不越界；前缀和 `cur` 的值域就是 $A_i$ 的值域。哨兵 $1145141919>5.000001\times10^8\ge$ 任何 $A_i$，而循环遍历了所有 $1..n$（$n\ge1$），故哨兵必被某个真实值取代。证毕。

**引理 7（复杂度）**：时间 $O(n+p)$，空间 $O(n)$。

*证明*：读入 $n$ 个数与 $p$ 组三数共 $O(n+p)$；原地差分一次倒序扫描 $O(n)$；$p$ 次操作每次 $O(1)$；最后一次前缀和 + 取最小 $O(n)$。合计 $O(n+p)$。空间上只有一个长度 $n+2$ 的 int 数组（约 $20$ MB）与一个 $1$ MB 读入缓冲。证毕。

**定理（算法正确性）**：按引理 5 得到差分，按引理 2、3 施加全部操作，按引理 1 前缀和还原，按引理 4 扫描全体取最小，输出的数就是题目要求的全班最低分。

*证明*：引理 3 说明最终 $A_i$ 与真实过程结果一致；引理 1 说明前缀和恰好还原 $A_i$；引理 4 说明取最小必须覆盖全部位置而算法确实覆盖了；引理 6 说明没有溢出与哨兵残留。故输出正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 每个位置的值 = 初始值 + 覆盖它的操作之和；答案只是这组值的最小值。
2. **碰壁与修正** — 想只维护最小值 ⇒ 反例 $a=[5,6]$ 加 $[1,1]+1$ 后最小值从 5 变 6，必须知道全体值。
3. **consider easier version** — 如果只需要"最终数组"而不需要中途查询，就不必用带 $\log$ 的结构（线段树 = 杀鸡用牛刀）。
4. **classic problem solution** — 差分：区间加变成 $d_x\mathrel{+}=z,\ d_{y+1}\mathrel{-}=z$ 两个单点修改。
5. **reduce to easier problem** — 全部操作都是加法 ⇒ 可交换可叠加 ⇒ 只在最后做一次前缀和。
6. **explore its property** — 原地倒序把 $a$ 改写成 $d$，省掉第二个 $5\times10^6$ 的数组。
7. **boundary check** — $d_{n+1}$ 的"幽灵位"、$x=1$ 时 $d_1$ 的定义、$5\times10^6$ 输入量的 fread 快读、值域 int 安全。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|----------------|
| `n` | 学生人数，$\le 5\times10^6$ | `int` | 由 `rd()` 读入 |
| `p` | 操作次数，$\le n$ | `int` | 由 `rd()` 读入 |
| `d[i]` | 先存 $a_i$，改写后存差分 $a_i-a_{i-1}$（$d_0=0$） | `int[5000005]` | 全局数组，默认 0；容量到 $n+1$ |
| `cur` | 当前前缀和，即还原出的 $A_i$ | `int` | 0，逐位累加 |
| `ans` | 全班最低分 | `int` | `1145141919` 哨兵 |
| `buf, len, pos` | `fread` 读入缓冲（$1$ MB）与游标 | `char[]/int` | 首次 `gc` 时填充 |
| `gc(), rd()` | 取一个字符 / 读一个非负整数 | 函数 | `rd` 跳过所有非数字字符 |

### 算法步骤

1. 用 `rd()` 读入 `n`、`p`。
2. 循环 $i=1..n$：`d[i]=rd()`（先当普通数组存）。
3. 倒序循环 $i=n..1$：`d[i]-=d[i-1]`，把 `d` 原地变成差分（`d[0]` 恒为 0）。
4. 循环 $p$ 次：读 `x,y,z`，执行 `d[x]+=z; d[y+1]-=z;`（`y=n` 时写的是幽灵位 `d[n+1]`）。
5. `cur=0, ans=1145141919`；正序循环 $i=1..n$：`cur+=d[i]`，用 `cur` 更新 `ans`。
6. 输出 `ans` 换行。

### 复杂度

- 时间：$O(n+p)$（读入 + 差分 + $p$ 次 $O(1)$ 修改 + 一次前缀和）。
- 空间：$O(n)$，即一个 $(n+2)$ 的 `int` 数组（$\approx20$ MB）加 $1$ MB 缓冲。

### 验证状态

编译通过（`g++ -std=c++20 -O2`）；与 $O(np)$ 暴力在 300 组随机小数据（$n\le60$、$p\le25$）上完全一致；极限数据 $n=p=5\times10^6$（约 112 MB 输入）本地运行约 1.1 s；手算小例子 `3 2 / 5 5 5 / 1 2 3 / 2 3 1` 输出 `6`，与程序一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2367 语文成绩
// 思路：区间加 -> 差分数组上两个单点修改；所有操作做完只做一次前缀和，边还原边取最小
//       n 到 5e6、操作到 5e6，输入量约 2e7 个整数，用 fread 自己读
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{5000005};

int n,p,d[mxn];

char buf[1<<20];          // 1 MB 缓冲，把 fread 的调用次数压到几百次
int len=0,pos=0;

int gc()
{
	if(pos==len)
	{
		len=(int)fread(buf,1,sizeof(buf),stdin);
		pos=0;
		if(len<=0)
			return -1;
	}
	return buf[pos++];
}
int rd()
{
	int c=gc();
	while(c<'0'||c>'9')
		c=gc();
	int x=0;
	while(c>='0'&&c<='9')
	{
		x=x*10+(c-'0');
		c=gc();
	}
	return x;
}

int main()
{
	n=rd();p=rd();
	for(int i=1;i<=n;++i)
		d[i]=rd();                 // 先存原数组
	for(int i=n;i>=1;--i)
		d[i]-=d[i-1];              // 倒序原地变成差分：d[i]=a[i]-a[i-1]，d[0]=0
	for(int i=0;i<p;++i)
	{
		int x=rd(),y=rd(),z=rd();
		d[x]+=z;
		d[y+1]-=z;                 // y=n 时写的是幽灵位 d[n+1]，不影响任何 a[i]
	}
	int ans=1145141919,cur=0;
	for(int i=1;i<=n;++i)
	{
		cur+=d[i];                 // 前缀和还原 A[i]
		if(cur<ans)
			ans=cur;
	}
	printf("%d\n",ans);
	return 0;
}
```

### 代码说明

- **倒序差分**是正确性的关键（引理 5）：正序会把 $d_{i-1}$ 先改掉，导致 $d_i$ 被减成二阶差分。
- `mxn{5000005}` 覆盖 $n+1=5000001$ 这个"幽灵位"下标；`d[0]` 是全局数组的 0，正好充当 $a_0=0$。
- `d[y+1]-=z` 在 $y=n$ 时写 `d[n+1]`：它不会被任何前缀和用到，但必须有槽位，否则越界。
- 值域已证 $\le5.000001\times10^8$，`int` 足够；用 `int` 而不是 `long long` 让数组只占 20 MB。
- 哨兵 `1145141919` 大于任何可能的答案（引理 6），且 $n\ge1$ 时循环必然覆盖某次真实比较。
- 读入用 `fread` + `gc/rd`：$2\times10^7$ 个数用 `cin` 风险太大；`rd()` 跳过所有非数字字符，所以换行、空格、Windows 的 `\r` 都能兼容。
