# P2697 宝石串 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一行一个只含 `G`（绿宝石）和 `R`（红宝石）的字符串，长度 $n\le 10^6$。要截取一段**连续**子串，使其中 G 和 R 的数目相同（"稳定"），求最长这样的子串含多少颗宝石。题面 Hint 只有一句"`RGGR` 为答案"，没有完整样例，下面的例子都是我手造并手算核对的。

**第一反应：暴力枚举。** 枚举左端点 $i$，向右延伸右端点 $j$，增量维护 G、R 计数差，差为 $0$ 时更新答案。这是 $O(n^2)$：$n=10^6$ 时约 $5\times10^{11}$ 次操作，铁定超时。数据范围把暴力直接否掉了，需要 $O(n)$ 或 $O(n\log n)$。

**第二反应：滑动窗口 / Kadane？都不行。** 双指针要求"窗口性质单调"——右端扩张时左端只需前进不需回头。但"平衡"不单调：窗口 `GR` 平衡，右扩成 `GRG` 不平衡，再扩成 `GRGR` 又平衡了，左端点根本没有单调移动的理由。Kadane 也不行：那是求**和最大**的子段，本题要的是**和恰好为 0** 的子段，"最大"和"恰好"是两码事。两条直觉路线都碰壁，说明得先挖掘"数目相同"这个条件本身的性质。

**第三步：探性质——把"数目相同"翻译成"和为 0"。** 给字符赋值：G 记 $+1$，R 记 $-1$。那么一段子串的赋值和 $=\#G-\#R$，于是

$$\text{子串稳定}\iff \#G=\#R\iff \text{子串赋值和}=0.$$

再套上前缀和这个万能翻译器：令 $s_0=0$，$s_j=\sum_{k\le j}a_k$，则子串 $(i,j]$（第 $i+1$ 到第 $j$ 颗）的和是 $s_j-s_i$。所以

$$\text{子串 }(i,j]\text{ 稳定}\iff s_i=s_j.$$

**整道题塌缩成一个极其干净的问题：在数组 $s_0,s_1,\dots,s_n$ 里找两个相等的值，使它们的下标差 $j-i$ 最大。** 这就是"最远等值对"。

**第四步：简化版试水，然后碰壁。** 先只想一个特例：子串必须从第 $1$ 颗开始（即 $i=0$）。那只要找最后一个 $s_j=0$ 的位置 $j$，答案就是 $j$。这提示我："对每个值，记住它**第一次**出现的位置，之后每次再遇到就结算一次距离"。

但"只记 $0$ 的第一次出现"够不够？造个反例：`GGGRGR`。前缀和依次是 $0,1,2,3,2,3,2$——值 $0$ 只在位置 $0$ 出现过一次，"只盯 $0$"的做法会输出 $0$；可真正的最优子串是第 $3\sim6$ 颗 `GRGR`（$2$ 个 G、$2$ 个 R），长度 $4$，它对应的是**值 $2$** 在位置 $2$ 和位置 $6$ 的等值对。反例说明：**每个前缀和值都要记第一次出现位置**，不能只记 $0$。

**第五步：归约到经典算法——first occurrence 表。** 对固定的右端点 $j$，能让 $(i,j]$ 稳定的左端点 $i$ 必须满足 $s_i=s_j$；长度 $j-i$ 要最大，$i$ 就要**最早**。于是算法呼之欲出：

- 开一张表 `fst[v]` = 前缀和值 $v$ 第一次出现的下标；
- 从左到右扫 $j=1..n$：若 `fst[s_j]` 还没记录，就记下 $j$；否则用 $j-\texttt{fst}[s_j]$ 更新答案。

为什么这样不重不漏？每一对等值位置 $(i,j)$ 都会在扫到右端点 $j$ 时被考虑，而那时表里存的恰是 $s_j$ 的最早出现位置——对每个 $j$ 都结算了它能得到的最长稳定子串，全局最大值自然被扫出来。一趟扫描，$O(n)$。

**第六步：实现边界，三个坑。**

1. **负下标。** $s_j\in[-n,n]$（全是 R 时到 $-n$，全是 G 时到 $+n$），数组下标不能为负，统一偏移 $+n$，用 `fst[s_j+n]`，表开 $2n+1$ 个格子。
2. **哨兵必须显式填。** "还没出现"不能用 $0$ 表示——$0$ 是**合法下标**（位置 $0$ 就是 $s_0$）！全局 `int` 数组默认 $0$，不填哨兵的话，`GGG` 这种根本没有稳定子串的输入会在 $j=1$ 时把默认值 $0$ 当成"值 $1$ 在位置 $0$ 出现过"，错误地输出 $1$。必须 `fill_n(fst,2*n+1,inf)`。
3. **$s_0=0$ 要预注册。** 扫描从 $j=1$ 开始，若不先把 `fst[0+n]=0` 写好，所有从第 $1$ 颗开始的稳定子串都会被漏掉：`GR` 的 $s_2=0$，表里没有 $0$ 的记录，会输出 $0$ 而不是 $2$。

另外答案初值 $0$：不存在稳定子串时（如 `GGG`）输出 $0$，与"最长长度"的自然语义一致。顺带一提，稳定子串长度必为偶数（G、R 各一半），可以用来自查。

**手造数据核对**（题面无完整样例，全部手算）：

| 输入 | 前缀和序列 $s_0..s_n$ | 答案 | 说明 |
|---|---|---|---|
| `RGGR` | $0,-1,0,1,0$ | $4$ | Hint 点名的串，值 $0$ 在位置 $0,4$ |
| `GGGRRR` | $0,1,2,3,2,1,0$ | $6$ | 整串平衡 |
| `GGGRGR` | $0,1,2,3,2,3,2$ | $4$ | 打掉"只记 0"的反例，最优对是值 $2$ |
| `GR` | $0,1,0$ | $2$ | 打掉"漏注册 $s_0$"的边界 |
| `GGG` | $0,1,2,3$ | $0$ | 无解；也打掉"不填哨兵"的边界 |
| `GRGRG` | $0,1,0,1,0,1$ | $4$ | 奇数长度全串不平衡，最优是前 $4$ 颗 |
| `RGGRRG` | $0,-1,0,1,0,-1,0$ | $6$ | 整串平衡，负值区也要覆盖 |

再补三组 $n=10^6$ 的极限边界：全 `G`（前缀和一路涨到 $n$，打表上界 $2n$）→ $0$；`GR` 交替 $50$ 万遍 → $1000000$；前 $50$ 万个 `G` 后 $50$ 万个 `R`（前缀和先升到 $5\times10^5$ 再落回 $0$）→ $1000000$。程序全部给出正确答案，单组运行约 $0.05$ 秒。

## 二、思维链：完整证明

**记号。** 输入串 $c_1c_2\dots c_n$，$c_k\in\{\texttt G,\texttt R\}$。赋值 $a_k=+1$（$c_k=\texttt G$）或 $-1$（$c_k=\texttt R$）。前缀和 $s_0=0$，$s_j=\sum_{k=1}^{j}a_k$（$1\le j\le n$）。子串 $(i,j]$ 指第 $i+1$ 到第 $j$ 颗宝石（$0\le i<j\le n$），长度 $j-i$。记 $\#G(i,j]$、$\#R(i,j]$ 为其中两种宝石的颗数。"稳定"定义为 $\#G=\#R$。答案 $\mathrm{OPT}=\max\{j-i:0\le i<j\le n,\ (i,j]\text{ 稳定}\}$，集合为空时定义 $\mathrm{OPT}=0$。

---

### 引理 1（稳定 $\iff$ 两端前缀和相等）

对任意 $0\le i<j\le n$：
$$(i,j]\text{ 稳定}\iff s_j=s_i.$$
且稳定子串的长度必为偶数。

*证明*：由赋值定义，
$$s_j-s_i=\sum_{k=i+1}^{j}a_k=\sum_{k=i+1}^{j}\bigl([c_k=\texttt G]-[c_k=\texttt R]\bigr)=\#G(i,j]-\#R(i,j],$$
其中第一步是前缀和的裂项（$s_j$ 与 $s_i$ 的公共前缀 $\sum_{k\le i}a_k$ 相消），第二步逐项展开。于是
$$(i,j]\text{ 稳定}\iff\#G(i,j]=\#R(i,j]\iff\#G(i,j]-\#R(i,j]=0\iff s_j-s_i=0\iff s_j=s_i.$$
长度方面：$j-i=\#G(i,j]+\#R(i,j]=2\,\#G(i,j]$（稳定时两者相等），故为偶数。证毕。

**这条引理是全题的支点**：它把"数两种字符的个数"这个二维条件压成"一个整数相等"的一维条件，问题从字符串领域搬进了整数数组领域。

---

### 引理 2（固定右端点时，最早等值位置最优）

固定 $j\in[1,n]$，令 $I_j=\{i:0\le i<j,\ s_i=s_j\}$。若 $I_j\ne\varnothing$，则以 $j$ 为右端点的最长稳定子串长度为 $j-\min I_j$；若 $I_j=\varnothing$，则不存在以 $j$ 为右端点的稳定子串。

*证明*：由引理 1，以 $j$ 为右端点的稳定子串与 $I_j$ 中的元素一一对应（$i\leftrightarrow(i,j]$），长度为 $j-i$。函数 $i\mapsto j-i$ 在整数上严格递减，故在 $I_j$ 上的最大值在 $i=\min I_j$ 处取到（有限非空整数集必有最小元）。$I_j=\varnothing$ 时没有任何合法左端点，结论显然。证毕。

**注意这里没有"显然成立"的跳步**：为什么不能取更晚的 $i$？因为 $j$ 固定后长度只由 $i$ 决定，$i$ 越小长度越大，这是严格单调性，不依赖任何贪心直觉。

---

### 引理 3（first-occurrence 扫描的全局正确性）

算法：预注册 `fst`$_{s_0}=0$；对 $j=1..n$，若 `fst`$_{s_j}$ 未记录则置为 $j$，否则 $\mathrm{ans}\leftarrow\max(\mathrm{ans},\,j-\texttt{fst}_{s_j})$。则扫描过程中始终有不变量

$$\texttt{fst}_v=\min\{t:0\le t\le j,\ s_t=v\}\quad(\text{若集合非空；否则未记录}),$$

且最终 $\mathrm{ans}=\mathrm{OPT}$。

*证明*：**不变量**对 $j$ 归纳。初始（$j=0$）：只注册了 $s_0=0$ 在位置 $0$，对 $v=0$ 有 $\min\{t\le0:s_t=0\}=0$ ✓，其余 $v$ 的集合为空、未记录 ✓。设处理完 $j-1$ 后不变量成立。处理 $j$ 时，值 $s_j$ 的出现位置集合从 $\{t\le j-1\}$ 变为 $\{t\le j\}$，新增元素只有 $j$ 自己：若原先为空，最小元就是 $j$，算法恰好记录 $j$ ✓；若原先非空，原最小元 $\le j-1<j$，加入 $j$ 不改变最小元，算法不动表 ✓。其他值的集合不变 ✓。不变量得证。

**答案正确性**，双向夹逼。

（$\mathrm{ans}\le\mathrm{OPT}$）：算法的每次更新都发生在 `fst`$_{s_j}$ 已记录时，由不变量其值是某个 $i<j$ 且 $s_i=s_j$，由引理 1，$(i,j]$ 是真实存在的稳定子串，长度 $j-i\le\mathrm{OPT}$。$\mathrm{ans}$ 初值 $0\le\mathrm{OPT}$，故全程 $\mathrm{ans}\le\mathrm{OPT}$。

（$\mathrm{ans}\ge\mathrm{OPT}$）：若 $\mathrm{OPT}=0$ 平凡。否则设最优对为 $(i^\*,j^\*)$，$s_{i^\*}=s_{j^\*}$，$j^\*-i^\*=\mathrm{OPT}$。考察算法扫到 $j=j^\*$ 的时刻：$i^\*\in\{t<j^\*:s_t=s_{j^\*}\}$，该集合非空，故 `fst`$_{s_{j^\*}}$ 已记录，且由不变量等于 $\min\{t<j^\*:s_t=s_{j^\*}\}\le i^\*$。于是这一次更新使
$$\mathrm{ans}\ge j^\*-\texttt{fst}_{s_{j^\*}}\ge j^\*-i^\*=\mathrm{OPT}.$$
（这里用到引理 2 的单调性：最早位置给出的长度不小于任何其它合法位置。）双向夹逼得 $\mathrm{ans}=\mathrm{OPT}$。证毕。

**换个角度看**：$\mathrm{OPT}=\max_v(\text{last}_v-\text{first}_v)$（每个值的最远等值对就是它的首末出现位置之差）。本算法在扫到每个值的每次出现时都拿"当前下标 $-$ 首次下标"结算，扫到末次出现时恰好结算出 $\text{last}_v-\text{first}_v$，所以一趟扫描就隐式算出了所有值的首末差的最大值——不需要第二趟。

---

### 引理 4（值域、偏移与哨兵的必要性）

(a) 对所有 $0\le j\le n$ 有 $|s_j|\le j\le n$，故偏移下标 $v=s_j+n\in[0,2n]$，表开 $2n+1$ 个格子足够。
(b) "未记录"必须用显式哨兵（如 $1145141919>n$）表示，不能用 $0$。
(c) 必须预注册 $s_0=0$ 在位置 $0$。

*证明*：(a) $s_j$ 是 $j$ 个 $\pm1$ 之和，绝对值不超过项数 $j$（三角不等式，或逐项放缩 $-j\le s_j\le j$）。加 $n$ 后落在 $[0,2n]$，共 $2n+1$ 个可能值。代码取 `mxn=1000005`，`fst[mxn*2]` 有 $2000010\ge2n+1=2000001$ 个格子 ✓。

(b) 反证：若用 $0$ 表示"未记录"，考虑输入 `GGG`（$n=3$，无任何稳定子串，$\mathrm{OPT}=0$）。$s_1=1$，偏移下标 $v=4$。`fst[4]` 的全局默认值是 $0$，算法会把它误判为"值 $1$ 在位置 $0$ 出现过"，更新 $\mathrm{ans}=1-0=1\ne0$。错误的根源：位置 $0$ 是**真实存在**的前缀和下标（$s_0$），$0$ 作为"已记录"的取值完全合法，所以"未记录"必须选一个不可能与任何合法下标混淆的值。哨兵 $1145141919>n\ge$ 任何合法下标，不会混淆 ✓。这正是"全局 `int` 数组默认 $0$"的经典移植陷阱。

(c) 反证：若不预注册，考虑输入 `GR`（$\mathrm{OPT}=2$）。$s_1=1$：值 $1$ 未记录，记 `fst`$_1=1$；$s_2=0$：值 $0$ 未记录（$s_0$ 没进表），记 `fst`$_0=2$；全程无更新，输出 $0\ne2$。漏掉的恰是所有 $i=0$ 的合法对。预注册 `fst[n]=0` 后，$j=2$ 时值 $0$ 已记录为 $0$，更新 $\mathrm{ans}=2-0=2$ ✓。证毕。

---

### 引理 5（复杂度与值域安全）

时间 $O(n)$，空间 $O(n)$；所有中间量在 `int` 范围内。

*证明*：读入串 $O(n)$；`fill_n` 填 $2n+1$ 个格子 $O(n)$；主循环 $n$ 次，每次一个字符判断、一次加法、一次查表、至多一次 $\max$，均 $O(1)$。合计 $O(n)$，$n=10^6$ 时约 $10^6$ 次基本操作，实测 $0.05$ 秒。

空间：`fst` 为 $2n+1$ 个 `int`，$n=10^6$ 时约 $8$ MB；串 $s$ 约 $1$ MB；其余 $O(1)$。合计 $O(n)$，约 $9$ MB。

值域：$|s_j|\le n\le10^6$；偏移下标 $\le2n\le2\times10^6$；答案 $\le n\le10^6$；哨兵 $1145141919<2^{31}-1$。所有量都远在 `int` 内，且哨兵只参与相等比较、不参与加减，无溢出风险。证毕。

---

### 定理

程序输出最长稳定子串的宝石数（不存在时为 $0$），时间 $O(n)$、空间 $O(n)$。

*证明*：引理 1 把题目等价翻译成"前缀和数组的最远等值对"；引理 2 给出固定右端点的最优左端点；引理 3 证明扫描算法恰好对每个右端点结算其最优左端点、从而全局正确；引理 4 保证偏移、哨兵、预注册三处实现细节不破坏上述数学事实；引理 5 给出复杂度与值域安全。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **consider easier version** — 先想 $O(n^2)$ 枚举端点暴力（$5\times10^{11}$ 次操作，被 $n\le10^6$ 否掉）；双指针与 Kadane 也因"平衡不单调""要和为 0 而非最大"相继碰壁。
- **explore its property** — "G、R 数目相同" $\iff$ 赋 $+1/-1$ 后子串和为 $0$；二维计数条件压成一维整数条件。
- **reduce to easier problem** — 前缀和裂项：子串 $(i,j]$ 稳定 $\iff s_i=s_j$，原题变成"前缀和数组的最远等值对"。
- **consider easier version** — 特例"子串从第 $1$ 颗开始"只需盯值 $0$；反例 `GGGRGR` 证明只盯 $0$ 不够，每个值都要记。
- **classic problem solution** — first-occurrence 表：固定右端点取最早等值左端点，一趟扫描 $O(n)$ 结算所有值的首末出现差。
- **discuss by category** — 三个实现边界逐类排雷：负前缀和偏移 $+n$；"未出现"显式填哨兵（$0$ 是合法下标）；$s_0=0$ 预注册（否则漏掉从头开始的子串）；无解输出 $0$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `s` | 输入的宝石串（`string`，下标 $0..n-1$） | 读入 | 第 $j$ 颗宝石是 `s[j-1]` |
| `n` | 串长，$\le10^6$ | `int`，`s.size()` | 前缀和共 $n+1$ 个：$s_0..s_n$ |
| `cur` | 当前前缀和 $s_j$（G $+1$，R $-1$） | `int`，初值 $0$ | 范围 $[-n,n]$ |
| `fst[v]` | 前缀和值 $v-n$ **第一次**出现的下标 $j\in[0,n]$ | `int[mxn*2]`，显式填 `inf` | "first occurrence"；`fst[n]=0` 预注册 $s_0$ |
| `v` | 偏移下标 $s_j+n\in[0,2n]$ | `int`，每步现算 | 负前缀和 $\to$ 非负下标 |
| `inf` | 哨兵 $1145141919$，表示"该值还没出现过" | `constexpr int` | 必须 $>n$；$0$ 是合法下标不能当哨兵 |
| `mxn` | $10^6+5$ | `constexpr int{1000005}` | `fst` 开 `mxn*2`，覆盖 $2n+1$ |
| `ans` | 最长稳定子串长度 | `int`，全局默认 $0$ | 无解时就是 $0$ |
| `j` | 扫描的右端点（前缀和下标，$1..n$） | `int` | 子串为 $(i,j]$，长度 $j-i$ |

### 算法步骤

1. I/O 加速三行；读入串 `s`，`n=s.size()`。
2. `fill_n(fst,2*n+1,inf)`：全部值标记"未出现"（引理 4(b)）。
3. `fst[n]=0`：预注册 $s_0=0$ 出现在位置 $0$（引理 4(c)）。
4. `cur=0`；对 `j=1..n`：
   1. `cur+=s[j-1]=='G'?1:-1`，得到 $s_j$；`v=cur+n`。
   2. 若 `fst[v]==inf`：`fst[v]=j`（第一次出现，只记录不结算）；
   3. 否则：`ans=max(ans,j-fst[v])`（引理 2：最早左端点给出以 `j` 结尾的最长稳定子串）。
5. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(n)$，$n=10^6$ 时一趟扫描，实测约 $0.05$ 秒。
- 空间：$O(n)$，`fst` 约 $8$ MB + 串约 $1$ MB。
- 验证状态：`g++ -std=c++20 -O2 -Wall -Wextra` 编译零警告；$9$ 组手造小数据（含 `GGGRGR`、`GR`、`GGG` 三个专打错误写法的反例）与手算全部一致；$4$ 组 $n=10^6$ 极限边界（全 G / 全 R / GR 交替 / 前半 G 后半 R）答案正确。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2697 宝石串
// G=+1,R=-1 ⇒ 子串稳定 ⟺ 两端前缀和相等 ⇒ 求最远等值前缀和对
// fst[v] 记录前缀和值 v 第一次出现的位置，扫右端点 j 取 j-fst[s[j]]
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005},inf{1145141919};

int n,fst[mxn*2],ans;
string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	n=s.size();
	fill_n(fst,2*n+1,inf);	// 0 是合法位置，"未出现"必须显式填哨兵
	fst[n]=0;	// s[0]=0，下标偏移 +n
	int cur=0;
	for(int j=1;j<=n;++j)
	{
		cur+=s[j-1]=='G'?1:-1;
		int v=cur+n;
		if(fst[v]==inf)
			fst[v]=j;
		else
			ans=max(ans,j-fst[v]);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **一趟扫描、两种动作**：第一次遇到某个前缀和值只"登记"，之后每次遇到才"结算"。登记保证 `fst[v]` 永远是最早位置（引理 3 不变量），结算保证每个右端点都拿到它能配出的最长子串。
- **`fill_n(fst,2*n+1,inf)` 一行都不能省**：全局 `int` 默认 $0$，而 $0$ 是合法下标（$s_0$ 的位置）。不填哨兵，`GGG` 会输出 $1$（引理 4(b) 的反例）。
- **`fst[n]=0` 是预注册 $s_0$**：偏移量是 $+n$，所以值 $0$ 的格子下标是 `n`。漏了它，`GR` 会输出 $0$（引理 4(c) 的反例）。
- **下标语义**：串 `s` 是 0-based（第 $j$ 颗是 `s[j-1]`），前缀和与 `fst` 记录的位置是 1-based 的"前 $j$ 颗"口径，$j-i$ 直接就是宝石数，两套口径在 `s[j-1]` 处对齐，不需要额外 $\pm1$。
- `ans` 依赖全局默认 $0$，恰好是"无稳定子串"的正确答案；`cur` 是局部变量显式置 $0$。
- 哨兵只参与 `==inf` 比较，从不参与加减，无溢出；答案 $\le10^6$，`int` 足够。
