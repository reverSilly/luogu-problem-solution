# P2878 [USACO07JAN] Protecting the Flowers S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n\le 10^5$ 头奶牛在花园吃花，第 $i$ 头距离牛圈 $T_i\le 2\times10^6$ 分钟路程，每分钟吃 $D_i\le 100$ 朵。FJ 每次只能赶一头回牛圈，赶第 $i$ 头**来回共耗时 $2T_i$ 分钟**；这段时间里**其它**奶牛继续吃（速度不变），**正在被赶的那头不吃**。求最优赶牛顺序下被吃掉的花的最小总数。

题面把计费模型写得非常明确，不需要猜测：第 $k$ 次运输耗时 $2T_{\pi(k)}$，期间吃花的恰是"还没被赶回的牛"去掉"正在被赶的这头"，即 $\pi(k+1),\dots,\pi(n)$。被赶回的牛从此不再吃。于是总损失只由**顺序** $\pi$ 决定。

**第一个观察：总时长与顺序无关。** 无论怎么排，FJ 的总工作时间都是 $\sum_i 2T_i$。顺序改变的不是"花被吃多久"，而是"**谁**在**什么时候**吃"。这提示我们：要让"吃得快的牛"尽早闭嘴，让"赶起来费时的牛"造成的等待尽量短——两个因素在打架。

**试探单关键字贪心，各给一个反例。**

- "先赶最近的（$T$ 小优先）"？取两头牛 $A=(T{=}1,D{=}1)$、$B=(T{=}2,D{=}100)$。先 $A$：运输 $A$ 的 $2$ 分钟里 $B$ 吃掉 $200$ 朵；先 $B$：运输 $B$ 的 $4$ 分钟里 $A$ 只吃 $4$ 朵。$T$ 小优先给出 $200$，最优是 $4$。**失败原因**：$T$ 小但 $D$ 也小的牛，赶它省下的时间不值钱。
- "先赶吃得快的（$D$ 大优先）"？取 $A=(T{=}100,D{=}100)$、$B=(T{=}1,D{=}2)$。先 $A$：$200$ 分钟里 $B$ 吃 $400$ 朵；先 $B$：$2$ 分钟里 $A$ 吃 $200$ 朵。$D$ 大优先给出 $400$，最优是 $200$。**失败原因**：$D$ 大但 $T$ 巨大的牛，赶它期间让别人等太久。

两个反例互为镜像，说明答案必须**同时**权衡 $T$ 和 $D$。自然的候选是比值 $T_i/D_i$："每单位吃花速度要花多少运输时间"。但比值是从哪来的？不能拍脑袋——用**邻项交换**把它推出来。

**推导：只看相邻两头牛。** 设顺序中相邻位置是 $\dots,x,y,\dots$。交换 $x,y$ 会改变多少损失？关键事实：交换只影响"$x,y$ 这一对"的相对先后，其它任何一对牛的先后关系不变（$x,y$ 与外部牛 $z$ 的先后、外部牛之间的先后都原样保留）。而总损失可以写成"每对牛的贡献之和"（下面引理 1 严格展开）：$x$ 在 $y$ 前时，$y$ 在运输 $x$ 的 $2T_x$ 分钟里吃 $2T_xD_y$ 朵；反过来是 $2T_yD_x$ 朵。所以

$$x\text{ 排在 }y\text{ 前更优}\iff T_xD_y\le T_yD_x\iff \frac{T_x}{D_x}\le\frac{T_y}{D_y}\quad(D>0).$$

比值判据**自己浮现**了，而且用交叉相乘 $T_xD_y<T_yD_x$ 比较，全程整数、零浮点误差。

**从"相邻不逆序"到"全局最优"。** 邻项交换只说明"最优排列里相邻元素必须满足比值升序"。还需要两步收尾：(1) 这个比较关系有传递性（全预序），所以"相邻不逆序"等价于"整体已排序"；(2) 任何排列都能通过不断交换相邻逆序对（冒泡）变成排序排列，每次交换不增加损失——所以排序排列不劣于任何排列，即最优。这是贪心正确性的标准闭环，第二部分逐条证明。

**算答案：后缀和扫描。** 排好序后按顺序模拟：维护 `sumd` = 尚未赶回的牛的 $D$ 之和。处理第 $i$ 头时先 `sumd-=D_i`（它被赶了，不吃），再 `ans+=2*T_i*sumd`（运输它的 $2T_i$ 分钟里其余牛吃掉的量）。一次扫描 $O(n)$。

**范围检查（$n=10^5$ 时必做）。** $\sum T\le 2\times10^{11}$，$\sum D\le 10^7$，损失 $\le 2(\sum T)(\sum D)=4\times10^{18}$，**超 `int` 十倍亿倍、但在 `long long`（$9.22\times10^{18}$）内**。答案与 `sumd` 必须 `i64`；比较器乘积 $T_xD_y\le 2\times10^8$ 虽不超 `int`，也顺手转 `i64` 保险。

**手造数据核对**（题面只有"样例解释"没有样例数据，全部自造）：

| 输入 | 手算 | 程序 |
|---|---|---|
| $n=2$：$(1,1),(2,100)$ | 先赶 $(2,100)$：$4$；反之 $200$ | `4` ✓ |
| $n=2$：$(1,2),(2,4)$（比值同为 $0.5$） | 两种顺序都是 $8$，平局任排 | `8` ✓ |
| $n=1$：$(5,7)$ | 赶它时没人吃，$0$ | `0` ✓ |
| $n=3$：$(1,1),(1,1),(1,1)$ | $2\cdot1\cdot2+2\cdot1\cdot1=6$ | `6` ✓ |
| $n=3$：$(3,1),(1,1),(2,3)$ | 枚举全部 $6$ 种顺序，最小 $10$（顺序 $(2,3)\to(1,1)\to(3,1)$） | `10` ✓ |
| $n=6$：$(6,2),(2,2),(3,2),(4,2),(10,2),(1,2)$ | 比值 $3,1,1.5,2,5,0.5$，排序恰为 $6\to2\to3\to4\to1\to5$，**与题面样例解释的顺序一致**；手算 $20+32+36+32+24=144$ | `144` ✓ |

最后一组是专门构造来复现题面"最优策略按 $6\to2\to3\to4\to1\to5$"这句话的：它验证了排序判据与出题人的最优顺序吻合。

## 二、思维链：完整证明

**记号。** 牛 $i$ 参数 $(T_i,D_i)$，$T_i,D_i\ge 1$。顺序为排列 $\pi$。定义比较关系 $x\preceq y\iff T_xD_y\le T_yD_x$（等价于 $T_x/D_x\le T_y/D_y$）。

---

### 引理 1（损失的对偶求和公式）

顺序 $\pi$ 的总损失为
$$C(\pi)=\sum_{k=1}^{n}2T_{\pi(k)}\sum_{j>k}D_{\pi(j)}=\sum_{1\le j<k\le n}2\,T_{\pi(j)}D_{\pi(k)}.$$

*证明*：按题面模型，第 $k$ 次运输耗时 $2T_{\pi(k)}$，期间吃花的牛恰为 $\{\pi(j):j>k\}$（$\pi(1..\!k\!-\!1)$ 已在牛圈，$\pi(k)$ 正被赶）。每分钟损失 $\sum_{j>k}D_{\pi(j)}$，速率恒定，故该次运输期间损失 $2T_{\pi(k)}\sum_{j>k}D_{\pi(j)}$。各次运输时间段互不重叠且覆盖全部"有牛在吃"的时间，总损失为各段之和，即第一个等号。把乘积展开：$2T_{\pi(k)}\sum_{j>k}D_{\pi(j)}=\sum_{j>k}2T_{\pi(k)}D_{\pi(j)}$，对 $k$ 求和即遍历所有满足"前者下标 $k$ 小于后者下标 $j$"的牛对，重命名指标得第二个等号。证毕。

**解读**：每对牛 $(u,v)$，若 $u$ 先被赶，则 $v$ 在运输 $u$ 期间吃 $2T_uD_v$ 朵；这是这对牛对总损失的**唯一**贡献（运输 $v$ 时 $u$ 已不在吃）。损失 = 所有牛对贡献之和。

---

### 引理 2（邻项交换差分）

设排列 $\pi$ 在位置 $k,k+1$ 处为牛 $x,y$，$\pi'$ 为交换这两头后的排列。则
$$C(\pi')-C(\pi)=2\bigl(T_yD_x-T_xD_y\bigr).$$
特别地，$x$ 在 $y$ 前不劣 $\iff T_xD_y\le T_yD_x\iff x\preceq y$。

*证明*：用引理 1 的对偶形式，逐项比较牛对贡献。牛对分三类：

1. **$\{x,y\}$ 自身**：$\pi$ 中 $x$ 在前，贡献 $2T_xD_y$；$\pi'$ 中 $y$ 在前，贡献 $2T_yD_x$。差 $2(T_yD_x-T_xD_y)$。
2. **恰含 $x,y$ 之一与外部牛 $z$**：$z$ 在位置 $k,k+1$ 之外。若 $z$ 在两者之前，$\pi$ 与 $\pi'$ 中都是 $z$ 先，贡献均为 $2T_zD_x+2T_zD_y$；若 $z$ 在两者之后，贡献均为 $2T_xD_z+2T_yD_z$。交换不改变 $z$ 与 $x$、$z$ 与 $y$ 的先后，贡献不变。
3. **不含 $x,y$**：位置与先后完全不变，贡献不变。

三类穷尽所有牛对，故总差即第 1 类的差。由于 $D_x,D_y>0$，$T_xD_y\le T_yD_x\iff T_x/D_x\le T_y/D_y$（两边同除 $D_xD_y$）。证毕。

---

### 引理 3（$\preceq$ 是全预序）

关系 $\preceq$ 满足自反性、完全性（任意两头可比）、传递性。

*证明*：**自反**：$T_xD_x\le T_xD_x$ 显然。**完全**：整数 $T_xD_y$ 与 $T_yD_x$ 必有一个 $\le$ 另一个。

**传递**：设 $x\preceq y$、$y\preceq z$，即
$$T_xD_y\le T_yD_x,\qquad T_yD_z\le T_zD_y.$$
所有量均为正整数。两式相乘（正数不等式同向可乘）：
$$T_xD_y\cdot T_yD_z\le T_yD_x\cdot T_zD_y.$$
两边同除以正数 $T_yD_y$（$T_y\ge1,D_y\ge1$）：
$$T_xD_z\le D_xT_z,$$
即 $x\preceq z$。证毕。

**推论**：严格比较器 `x.t*y.d < y.t*x.d` 是合法排序比较器（严格弱序：不可比即等价，等价类内比值相等）；"相邻无逆序"的序列由传递性整体单调：$\pi(1)\preceq\pi(2)\preceq\cdots\preceq\pi(n)$。

---

### 引理 4（排序排列最优，且所有排序排列同价）

(a) 任何最优排列必满足相邻无逆序，从而整体按 $\preceq$ 升序；(b) 任何按 $\preceq$ 升序的排列都是最优的；(c) 所有升序排列的 $C$ 值相同。

*证明*：(a) 若最优排列 $\pi$ 在某相邻位置 $k,k+1$ 有 $\pi(k)\succ\pi(k+1)$（即 $T_{\pi(k)}D_{\pi(k+1)}>T_{\pi(k+1)}D_{\pi(k)}$），由引理 2 交换后 $C$ 严格减小，与最优矛盾。故相邻皆 $\preceq$；由引理 3 传递性，整体升序。

(b) 任取排列 $\sigma$。对其做冒泡排序：只要存在相邻逆序就交换。每次交换由引理 2 使 $C$ **不增**（逆序交换时差 $2(T_yD_x-T_xD_y)<0$，严格减；过程有限，因为每次交换减少逆序对总数——交换相邻逆序对恰好消灭这一个逆序对且不产生新逆序对：外部元素与这两者的先后关系不变）。有限步后得到升序排列 $\sigma^\*$，且 $C(\sigma^\*)\le C(\sigma)$。取 $\sigma$ 为最优排列即知升序排列达到最小值。

(c) 两个升序排列只在等价类（比值相等的牛）内部顺序不同。等价类内相邻交换满足 $T_xD_y=T_yD_x$，引理 2 给出差为 $0$；类内任意重排可分解为相邻交换，故 $C$ 不变。证毕。

---

### 引理 5（线性扫描正确计算 $C$）

按升序处理，维护 `sumd` 初值 $\sum_iD_i$；第 $i$ 步先 `sumd-=D_{\pi(i)}` 再 `ans+=2*T_{\pi(i)}*sumd`。则处理完前 $k$ 头后
$$\texttt{ans}=\sum_{j\le k}2T_{\pi(j)}\sum_{l>j}D_{\pi(l)},\qquad \texttt{sumd}=\sum_{l>k}D_{\pi(l)}.$$
特别地 $k=n$ 时 `ans`$=C(\pi)$。

*证明*：对 $k$ 归纳。$k=0$：`ans`$=0$（空和），`sumd`$=\sum_lD_{\pi(l)}$ ✓。设 $k-1$ 成立。第 $k$ 步开始 `sumd`$=\sum_{l>k-1}D_{\pi(l)}$；减去 $D_{\pi(k)}$ 后 `sumd`$=\sum_{l>k}D_{\pi(l)}$ ✓。`ans` 增加 $2T_{\pi(k)}\sum_{l>k}D_{\pi(l)}$，恰为和式第 $k$ 项 ✓。证毕。

---

### 引理 6（数值范围：`i64` 必要且充分）

$C\le 4\times10^{18}<2^{63}-1$；中间量 `2*T_i*sumd` $\le 4\times10^{13}$；比较器乘积 $\le 2\times10^8$。故答案与 `sumd` 用 `long long` 安全，`int` 必然溢出。

*证明*：由引理 1，$C=\sum_{j<k}2T_{\pi(j)}D_{\pi(k)}\le 2\bigl(\sum_jT_j\bigr)\bigl(\sum_kD_k\bigr)$（把限制 $j<k$ 放宽为全部有序对，每项非负）。代入 $\sum T\le n\max T=10^5\times2\times10^6=2\times10^{11}$、$\sum D\le 10^5\times100=10^7$：$C\le 2\times2\times10^{11}\times10^7=4\times10^{18}$。而 $2^{63}-1=9.223\times10^{18}$，安全；`int` 上限 $2.1\times10^9$，连单项 $2T_i\cdot\texttt{sumd}\le 4\times10^6\times10^7=4\times10^{13}$ 都装不下，必须 `i64`。代码中 `2*a[i].t` 是 `int` 乘法，$\le 4\times10^6$ 不溢出，随后与 `i64` 的 `sumd` 相乘自动提升。比较器 $(T_xD_y)\le 2\times10^6\times100=2\times10^8$，`int` 本可容纳，显式转 `i64` 是零成本保险。证毕。

---

### 定理

程序输出最小总损失，时间 $O(n\log n)$。

*证明*：引理 1 建立损失公式；引理 2 给出邻项交换判据；引理 3 保证判据可排序（全预序）；引理 4 保证升序排列最优；引理 5 保证扫描算出的正是该排列的 $C$；引理 6 保证数值不溢出。排序 $O(n\log n)$、扫描 $O(n)$，合计 $O(n\log n)$。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 总时长 $\sum2T_i$ 与顺序无关；顺序只决定"谁在谁的运输期间吃花"，损失可拆成牛对贡献之和。
2. **consider easier version** — $n=2$ 时直接比较两种顺序，得到判据 $T_xD_y$ vs $T_yD_x$ 的雏形。
3. **explore its property** — 单关键字贪心各有镜像反例（$T$ 小优先、$D$ 大优先都错），必须双因子权衡。
4. **classic problem solution** — 邻项交换论证：相邻交换只改变这一对的贡献，差 $2(T_yD_x-T_xD_y)$ $\Rightarrow$ 按 $T/D$ 升序，交叉相乘免浮点。
5. **explore its property** — 证明比较关系的传递性（正数不等式相乘再约元），确认它是全预序、排序合法。
6. **classic problem solution** — 冒泡/逆序对论证闭环：最优排列无相邻逆序 $\Rightarrow$ 已排序；任何排列冒泡到排序态代价不增 $\Rightarrow$ 排序态最优。
7. **reduce to easier problem** — 对偶求和 $\to$ 后缀和线性扫描：`sumd-=D_i; ans+=2*T_i*sumd`，$O(n)$ 算完。
8. **discuss by category** — 范围分析：$C\le4\times10^{18}$ 必须 `i64`；比值相等任排（差为 $0$）；$n=1$ 答案 $0$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `mxn` | $10^5+5$ | `constexpr int` | 数组尺寸 |
| `a[i].t` | 第 $i$ 头牛的单程时间 $T_i$ | `int`（结构体 `cow`） | 读入 |
| `a[i].d` | 第 $i$ 头牛的吃花速率 $D_i$ | `int` | 读入 |
| `sumd` | 尚未赶回的牛的 $D$ 之和 | `i64` | 初值 $\sum D_i$；每步先减后乘 |
| `ans` | 累计最小损失 | `i64` | 全局默认 $0$ |
| 比较器 | `x.t*y.d < y.t*x.d`，即 $T/D$ 升序 | lambda | 乘积转 `i64`；相等返回 `false`（严格弱序） |

### 算法步骤

1. I/O 加速三行；读 $n$ 与每头 $(T_i,D_i)$，同时累加 `sumd`。
2. 按交叉相乘比较器 `sort`（$T/D$ 升序）。
3. 顺序扫描：`sumd-=a[i].d`（被赶的牛不吃），`ans+=2*a[i].t*sumd`（其余牛在 $2T_i$ 分钟里的损失）。
4. 输出 `ans`。

### 复杂度

- 时间：$O(n\log n)$（排序主导），$n=10^5$ 约 $1.7\times10^6$ 次比较。
- 空间：$O(n)$，结构体数组约 $0.8$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Part 1 六组手造数据全对，含 $n=3$ 全排列枚举核对、平局比值、$n=1$，以及专门复现题面样例解释顺序 $6\to2\to3\to4\to1\to5$ 的 $6$ 牛数据（手算 $144$）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2878 [USACO07JAN] Protecting the Flowers S
// 邻项交换 ⇒ 按 T/D 升序（交叉相乘比较）；ans=Σ 2*T_i*(尚未赶回的 D 之和)
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n;
struct cow{int t,d;}a[mxn];
i64 ans,sumd;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i].t>>a[i].d;
		sumd+=a[i].d;
	}
	sort(a,a+n,[](cow x,cow y){return (i64)x.t*y.d<(i64)y.t*x.d;});
	for(int i=0;i<n;++i)
	{
		sumd-=a[i].d;	// 正在被赶的牛不吃花
		ans+=2*a[i].t*sumd;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **先减后乘**是语义核心：`sumd-=a[i].d` 把"正在被赶的这头"从吃花队伍里去掉，对应题面"正在被赶回牛圈的奶牛不能继续吃了"。顺序写反（先乘后减）会多算 $2T_iD_i$。
- 比较器用**交叉相乘**而非 `double` 比值：$T/D$ 可能无限接近但不相等，浮点比较会在边界数据上排错序；整数乘积精确，且 $\le2\times10^8$ 无溢出（仍转 `i64` 保险）。
- 比值相等的牛比较器两向都返回 `false`，构成等价类，`sort` 任排——引理 4(c) 保证同价，无需稳定排序。
- `ans`、`sumd` 必须 `i64`：极限答案 $4\times10^{18}$ 超 `int` 约 $2\times10^9$ 倍（引理 6）。`2*a[i].t` 本身 $\le4\times10^6$ 不溢出，与 `sumd` 相乘时自动提升为 `i64`。
- 不需要显式模拟时间轴：后缀和扫描就是引理 1 公式的逐项累加，$O(n)$。
