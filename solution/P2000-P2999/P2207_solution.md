# P2207 [USACO13OPEN] Photo B — 题解

## 一、解题过程：人类思考叙事

题面：$n$ 头奶牛站成一排，编号 $1\sim n$。一张照片可以拍下编号连续的一段 $[l,r]$。要求每头奶牛至少出现在一张照片里；同时有 $k$ 对"关系不好"的奶牛（$a_i,b_i$），任何一张照片都不能同时拍到某一对的两头牛。求最少照片数。$n\le10^9$，$k\le1000$。

**先看数据范围的反差**：$n$ 大到 $10^9$，$k$ 只有 $1000$。这说明限制信息非常稀疏，算法绝不能逐个位置扫，复杂度应该只和 $k$ 有关。

**第一步：把"一张照片合法"翻译成条件。** 把每对规范成 $a_i<b_i$。照片 $[l,r]$ 拍到了第 $i$ 对的两头牛，当且仅当 $l\le a_i$ 且 $b_i\le r$。所以 $[l,r]$ 合法，当且仅当不存在 $i$ 同时满足 $a_i\ge l$、$b_i\le r$。

**第二步：固定左端点，右端点最远能到哪？** 对给定的 $l$，所有满足 $a_i\ge l$ 的坏对都"潜在"会被拍到；要避免它们，右端点必须严格小于这些坏对中**最小的 $b_i$**。记
$$\text{lim}(l)=\min\{b_i: a_i\ge l\},$$
若集合为空则 $\text{lim}(l)=+\infty$。那么 $[l,r]$ 合法等价于 $r<\text{lim}(l)$。于是从 $l$ 出发最多拍到 $\text{lim}(l)-1$。

这个 $\text{lim}$ 很好算：对每个候选左端点扫一遍 $k$ 对即可，$O(k)$。

**第三步：怎么用最少的照片覆盖 $1..n$？** 这是经典的"区间覆盖"结构：当前位置是 $cur$（第一个还没被覆盖的奶牛），为了让这张照片尽量"多干活"，应该拍到 $[\text{cur},\text{lim}(\text{cur})-1]$，然后令 $cur=\text{lim}(\text{cur})$，继续拍。如果 $\text{lim}(cur)=+\infty$，说明剩下的位置没有任何坏对限制，一张照片拍完 $[cur,n]$ 即可结束。

**为什么"拍得最远"一定不亏？** 直观上，任何覆盖 $cur$ 的合法照片，左端点 $l\le cur$，而它往右不可能超过 $\text{lim}(cur)-1$（因为 $a_i\ge cur$ 的坏对也满足 $a_i\ge l$）。既然别的照片右端点更短，把它换成最远的那张，只会多覆盖、不会少覆盖，剩下的照片照样覆盖后面，张数不增加。这正是区间覆盖贪心的标准交换论证。

**为什么可以假设照片从 $cur$ 开始？** 一张覆盖 $cur$ 的照片可能从 $cur$ 左边开始，但它的任何子区间也合法（子区间包含的坏对只会更少），所以 $[cur,r]$ 合法，且向右能到达同样的最远位置。于是"从当前位置开始拍"不会损失最优性。

**第四步：跳多少次？** 每次有限跳转后 $cur$ 变成某个 $b_i$（$\text{lim}$ 是某些 $b_i$ 的最小值）。由于 $b_i>a_i\ge cur$，所以 $\text{lim}(cur)>cur$，$cur$ 严格递增；而 $b_i$ 至多 $k$ 个不同取值，故最多跳 $k$ 次，再加最后一次 $\text{lim}=+\infty$ 的收尾。总共 $O(k)$ 轮，每轮扫 $k$ 对，$O(k^2)$，$k=1000$ 时是 $10^6$，轻松。

**用题面样例解释反推核对**：题面说可以只拍三张：$[1,2],[3,5],[6,7]$，对应 $n=7$。能让贪心产生这三段的坏对例如 $(1,3),(2,4),(5,6)$：

- $\text{lim}(1)=\min\{3,4\}=3$，拍 $[1,2]$，$cur=3$；
- $\text{lim}(3)=6$（只有 $(5,6)$ 满足 $a_i\ge3$），拍 $[3,5]$，$cur=6$；
- 没有 $a_i\ge6$ 的坏对，拍 $[6,7]$，结束，共 $3$ 张。

与样例解释完全吻合。虽然题面没有给出样例输入，这组自造数据足以验证贪心的行为。

**实现细节**：

- 坏对输入顺序不保证 $a_i<b_i$，要交换规范。
- $n$ 很大，但 $cur$ 只在 $b_i$ 之间跳，绝不逐个位置枚举。
- 循环里若 $\text{lim}=+\infty$，拍完 $[cur,n]$ 后必须 `break`，否则会死循环。
- 答案最大约 $k+1$，`int` 足够。

## 二、思维链：完整证明

**约定**：把所有坏对规范为 $a_i<b_i$（$1\le i\le k$）。一张照片是区间 $[l,r]$，$1\le l\le r\le n$。称 $[l,r]$ 合法，若不存在 $i$ 使 $l\le a_i$ 且 $b_i\le r$。定义
$$\text{lim}(l)=\min\{b_i: a_i\ge l\},$$
若集合为空则 $\text{lim}(l)=+\infty$。

**引理 1（合法性判定）**：$[l,r]$ 合法 $\iff$ 对每个 $i$，要么 $a_i<l$，要么 $b_i>r$。

*证明*：第 $i$ 对的两头牛都在 $[l,r]$ 内，当且仅当 $l\le a_i$ 且 $b_i\le r$（这里用到 $a_i<b_i$，所以只需检查左端点 $a_i$ 不小于 $l$、右端点 $b_i$ 不大于 $r$，中间自然都在区间内）。合法就是不存在这样的 $i$，即对每个 $i$ 至少有一个不等式不成立，也就是 $a_i<l$ 或 $b_i>r$。证毕。

**引理 2（最远右端点）**：$[l,r]$ 合法 $\iff r<\text{lim}(l)$。因此以 $l$ 为左端点时，合法照片的最大右端点是 $\text{lim}(l)-1$（当 $\text{lim}(l)$ 有限时；有限时必有 $\text{lim}(l)\le n$）。

*证明*：由引理 1，$[l,r]$ 合法等价于：对所有满足 $a_i\ge l$ 的 $i$，都有 $b_i>r$。这等价于 $\min\{b_i:a_i\ge l\}>r$。若集合为空，最小值约定为 $+\infty$，条件对任意 $r\le n$ 都成立；若集合非空，条件就是 $\text{lim}(l)>r$。两种情形统一写成 $r<\text{lim}(l)$。因为每个 $b_i\le n$，有限时 $\text{lim}(l)\le n$，所以最大右端点 $\text{lim}(l)-1\le n-1$ 合法。证毕。

**引理 3（每步有进展）**：若 $\text{lim}(cur)$ 有限，则 $\text{lim}(cur)\ge cur+1$，照片 $[cur,\text{lim}(cur)-1]$ 非空；并且下一轮的起点严格大于本轮起点。

*证明*：$\text{lim}(cur)$ 是某个满足 $a_i\ge cur$ 的 $b_i$。由 $b_i>a_i\ge cur$ 得 $b_i\ge cur+1$，故 $\text{lim}(cur)\ge cur+1$，右端点 $\text{lim}(cur)-1\ge cur$，照片非空。下一轮起点为 $\text{lim}(cur)>cur$，严格递增。证毕。

**引理 4（贪心构造的是一个合法覆盖）**：若每轮都拍 $[cur,\text{lim}(cur)-1]$（$\text{lim}$ 有限）或 $[cur,n]$（$\text{lim}=+\infty$），则这些照片都合法，且它们恰好首尾相接、不重不漏地覆盖 $[1,n]$。

*证明*：合法性由引理 2 直接得到（有限情形 $r=\text{lim}(cur)-1<\text{lim}(cur)$；无限情形没有任何 $a_i\ge cur$ 的坏对，因而也不存在整对落在 $[cur,n]$ 内，由引理 1 合法）。非空性由引理 3。覆盖性：初始 $cur=1$；每轮照片是 $[cur,\text{lim}(cur)-1]$，下一轮起点变成 $\text{lim}(cur)$，恰好是上一张的右端点 $+1$，所以区间依次首尾相接、互不重叠。又有限跳转后 $cur=\text{lim}(cur_{\text{旧}})\le n$，不可能超过 $n$，所以过程只能通过某轮 $\text{lim}=+\infty$ 并拍 $[cur,n]$ 来结束；此时这些区间恰好拼满 $[1,n]$。证毕。

**引理 5（任何照片都无法越过最远点）**：设照片 $[l,r]$ 覆盖 $cur$（即 $l\le cur\le r$）且合法，则 $r<\text{lim}(cur)$。

*证明*：任取满足 $a_i\ge cur$ 的 $i$。因 $l\le cur\le a_i$，有 $a_i\ge l$；由引理 1 的合法性，$b_i>r$。于是所有满足 $a_i\ge cur$ 的 $b_i$ 都 $>r$，它们的最小值（若存在）也 $>r$；若集合为空则 $\text{lim}=+\infty>r$。总之 $r<\text{lim}(cur)$。证毕。

**引理 6（贪心最优）**：设 $G(cur)$ 为从位置 $cur$ 开始按贪心拍完 $[cur,n]$ 所需照片数，$OPT(cur)$ 为覆盖 $[cur,n]$ 的最少照片数，则 $G(cur)=OPT(cur)$。

*证明*：对剩余长度 $n-cur$ 做强归纳。当 $cur>n$ 时两者都是 $0$，成立。设 $cur\le n$。

- 若 $\text{lim}(cur)=+\infty$：贪心用一张 $[cur,n]$，而至少需要一张，故 $G(cur)=1=OPT(cur)$。
- 若 $\text{lim}(cur)$ 有限，记 $R=\text{lim}(cur)-1\ge cur$。贪心为 $1+G(R+1)$。

  任取一个覆盖 $[cur,n]$ 的方案，设用了 $m$ 张照片。因为 $cur$ 必须被覆盖，方案中存在一张照片 $P=[l,r]$ 满足 $l\le cur\le r$。由引理 5，$r\le R$。把 $P$ 换成 $P'=[cur,R]$：由引理 2，$P'$ 合法；由 $R\ge r$，$P'$ 覆盖了 $P$ 在 $[cur,n]$ 内覆盖的全部位置。于是新方案仍是覆盖，且照片数仍为 $m$。

  在新方案中，任何位置 $x>R$ 都不被 $P'$ 覆盖（$P'$ 的右端点是 $R$），而旧方案中被 $P$ 覆盖的位置也不超过 $r\le R$，所以这些 $x$ 原本就由其余 $m-1$ 张照片覆盖。因此其余 $m-1$ 张照片构成 $[R+1,n]$ 的一个覆盖，于是 $OPT(R+1)\le m-1$。

  由归纳假设（$R+1>cur$，剩余长度更短）$G(R+1)=OPT(R+1)\le m-1$，故 $G(cur)=1+G(R+1)\le m$。该不等式对任意覆盖方案成立，取 $m=OPT(cur)$ 得 $G(cur)\le OPT(cur)$。另一方面贪心本身由引理 4 是一个覆盖，故 $OPT(cur)\le G(cur)$。

  两者结合得 $G(cur)=OPT(cur)$。证毕。

**引理 7（迭代次数与复杂度）**：主循环至多执行 $k+1$ 轮，总时间复杂度 $O(k^2)$，空间复杂度 $O(k)$。

*证明*：由引理 3，每轮（除最后一轮）结束后 $cur$ 严格增大，且新 $cur=\text{lim}(cur_{\text{旧}})$ 等于某个 $b_i$。所有 $b_i$ 至多有 $k$ 个不同取值，严格递增的 $cur$ 不可能重复取同一个值，所以"有限跳转"至多 $k$ 次。跳转后 $cur\le n$（因为 $b_i\le n$），若仍有 $a_i\ge cur$ 的坏对则继续跳；当没有这样的坏对时 $\text{lim}=+\infty$，再执行一轮收尾。故总轮数 $\le k+1$。每轮扫描 $k$ 对求最小值，时间 $O(k)$，总计 $O(k^2)$。只存 $k$ 对端点，空间 $O(k)$。证毕。

**定理**：贪心输出的照片数等于最少需要的照片数。

*证明*：由引理 4 贪心给出合法覆盖，由引理 6 其数量等于 $OPT(1)$，即最少照片数。由引理 7 复杂度满足要求。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 一张照片是否合法，只取决于是否有坏对"整对"落在区间内。
- **reduce to easier problem** — 固定左端点后，最远右端点由 $\min\{b_i:a_i\ge l\}-1$ 决定，问题化为若干"最远可达点"。
- **explore its property** — $n$ 很大而 $k$ 很小；$\text{lim}$ 的取值只可能是某些 $b_i$，因此位置可以跳跃前进。
- **classic problem solution** — 区间覆盖贪心：每次从当前未覆盖点出发拍到最远，段数最少。
- **prove greedy by exchange** — 任何覆盖当前点的照片都越不过 $\text{lim}(cur)-1$，替换为最远照片不会增加张数。
- **discuss by category** — $\text{lim}$ 有限时跳到 $b_i$；$\text{lim}=+\infty$ 时一张收尾；据此证明至多 $k+1$ 轮。
- **boundary check** — 坏对端点顺序任意要交换；跳转后起点严格递增，不会死循环。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 奶牛总数 | 输入，可达 $10^9$ |
| $k$ | 坏对数量 | 输入，$\le1000$ |
| `a[i],b[i]` | 第 $i$ 对坏对的左右端点，保证 `a[i]<b[i]` | 读入后若反序则交换 |
| `cur` | 当前第一头尚未被覆盖的奶牛编号 | $1$ |
| `lim` | $\min\{b_i:a_i\ge cur\}$，无则 $+\infty$ | 每轮重新扫描，初值 `inf` |
| `ans` | 已拍照片数 | $0$ |
| `inf` | 无穷哨兵 | $1145141919$ |

### 算法步骤

1. 读入 $n,k$；读入 $k$ 对端点，若 $a_i>b_i$ 则交换。
2. `cur=1`，`ans=0`。
3. 当 `cur<=n`：
   1. `lim=inf`；
   2. 扫描所有坏对，若 `a[i]>=cur`，令 `lim=min(lim,b[i])`；
   3. `ans++`；
   4. 若 `lim==inf`，说明 $[cur,n]$ 已无任何限制，收尾并 `break`；
   5. 否则 `cur=lim`，进入下一轮。
4. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(k^2)$。主循环至多 $k+1$ 轮，每轮 $O(k)$ 扫描；与 $n$ 无关。
- 空间复杂度：$O(k)$，只存 $k$ 对端点。

### 验证状态

编译通过；按题面样例解释反推的数据 `7 3 / 1 3 / 2 4 / 5 6` 输出 `3`，与解释中的三张照片 $[1,2],[3,5],[6,7]$ 一致；另在 3000 组随机小数据（$n\le12$，$k\le8$，坏对互异）上与"枚举所有合法区间 + 区间覆盖 DP"的暴力逐组比对，全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxk{1005};
constexpr int inf{1145141919};

int n,k;
int a[mxk],b[mxk];   // 第i对：a[i]<=b[i]

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int i=0;i<k;++i)
	{
		cin>>a[i]>>b[i];
		if(a[i]>b[i])
			swap(a[i],b[i]);
	}
	int cur=1,ans=0;
	while(cur<=n)
	{
		int lim=inf;   // lim=min{b_i : a_i>=cur}
		for(int i=0;i<k;++i)
			if(a[i]>=cur)
				lim=min(lim,b[i]);
		++ans;
		if(lim==inf)
			break;
		cur=lim;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 每轮重新扫描 $k$ 对求 `lim`，没有预排序；$O(k^2)$ 在 $k\le1000$ 时足够，代码也最短。
- `lim` 用大于 $n$ 的哨兵 `inf`：如果扫完仍是 `inf`，说明没有 $a_i\ge cur$ 的坏对，最后一张照片拍到 $n$ 即可结束。
- `cur=lim` 而不是 `cur=lim+1`：$\text{lim}$ 是"不能与当前段同框"的那头牛的编号，它自己还没有被覆盖，必须成为下一段的起点；这也正是照片首尾相接的原因。
- 坏对端点可能反序，先交换再处理。
- 循环条件 `cur<=n` 与 `break` 配合，保证 $n$ 再大也只跳 $O(k)$ 次。
