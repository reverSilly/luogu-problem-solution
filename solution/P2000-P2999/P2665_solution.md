# P2665 [USACO08FEB] Game of Lines S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 木板上 $N$ 个**不重合**的整点（$2\le N\le200$，$-1000\le X_i,Y_i\le1000$）。贝茜每次选两点画一条过它们的直线，**当且仅当已画出的直线中没有与它平行的**才允许画。求最多能画多少条。

**第一步：把游戏规则读透——"平行"是唯一限制。** 两条直线平行 ⇔ 斜率相同（竖直线之间也互相平行）。规则说"不能与已画的平行"，也就是：**每个斜率方向至多画一条**。

那"至多"能不能取到？能。把所有出现过的方向各挑一条代表直线，**按任意顺序**画：画第 $k$ 条时，前 $k-1$ 条的方向都与它不同（每个方向只挑了一条），所以永远合法。于是

$$\text{最大得分}=\text{所有点对能产生的不同方向（斜率）个数}.$$

上界（每方向至多一条）+ 构造（每方向各画一条）两头一夹，游戏策略问题就塌缩成一个**计数问题**：数不同斜率。画的顺序根本不影响答案——这是本题第一个关键观察。

**第二步：方向怎么表示？竖直线是个坑。** 斜率 $=\dfrac{y_j-y_i}{x_j-x_i}$。两个麻烦：

1. **竖直线**（$x_j=x_i$）斜率不存在，但所有竖直线互相平行，必须算作**一个**方向，不能漏也不能重复。
2. **浮点精度**。用 `double` 存斜率行不行？本题分析一下：$|dy|,|dx|\le2000$，两个不同既约分数 $\frac ab\ne\frac cd$（$b,d\le2000$）之差 $\ge\frac1{bd}\ge\frac1{2000\times1999}\approx2.5\times10^{-7}$，而 `double` 在斜率量级（$\le2000$）上的绝对误差约 $10^{-13}$，远小于间隔——**这题用 `double` 其实碰巧安全**。但竖直线仍要特判，而且"碰巧安全"依赖数据范围，换个题就炸。更干净的做法是**精确整数表示**：既约分数。

**第三步：既约分数 + 符号规范化。** 对点对 $(i,j)$，令 $dx=x_j-x_i$，$dy=y_j-y_i$：

- 若 $dx=0$：竖直线，统一记作键 $(1,0)$（所有竖直线共用）。
- 否则：$g=\gcd(|dx|,|dy|)$，令 $dx\mathrel{/}=g$，$dy\mathrel{/}=g$；若 $dx<0$ 则同时取反，保证 **$dx>0$**。键为 $(dy,dx)$。

这样每个方向有**唯一**的键：同一条斜率的不同点对（比如 $(1,2)$ 与 $(-1,-2)$、$(2,4)$）都化到同一个既约、分母为正的 $(dy,dx)$。水平线 $dy=0$ 化到 $(0,1)$。点不重合保证 $(dx,dy)\ne(0,0)$，$\gcd$ 不会遇到 $0,0$。

**第四步：数键。** 枚举所有无序点对 $i<j$（方向与两点顺序无关，规范化后 $(i,j)$ 与 $(j,i)$ 同键），把键丢进 `set<pair<int,int>>`，答案就是 `set.size()`。点对数 $\binom{200}{2}=19900$，$O(N^2\log N)$ 约几十万次比较，瞬间跑完。也可以用排序 + 去重或叉积比较器，但 `set` 最短。

**第五步：易错点清单。**

- 漏掉竖直线，或把每条竖直线各算一个方向（应共算 $1$ 个）。
- 不做符号规范化：$(1,2)$ 与 $(-1,-2)$ 被当成两个方向，答案翻倍。
- 共线点：三点共线时三对点同斜率，只算 $1$ 个方向（不是 $3$）。
- 用 `double` 又不特判竖直，或精度分析想当然。

**手造数据核对**（题面只给样例解释"能画出 $-1,0,\frac13,1$ 四种斜率"，我按解释反推一组，再造几组打竖直/共线/边界）：

| 输入 | 方向 | 答案 |
|---|---|---|
| `4` / `(0,0),(1,1),(2,0),(3,1)` | 斜率 $1,0,\frac13,-1$，与样例解释完全一致 | $4$ |
| `4` / `(0,0),(0,1),(1,0),(1,1)` | 竖直、水平、$1$、$-1$（正方形四边+两对角线） | $4$ |
| `3` / `(0,0),(1,1),(2,2)` | 三点共线，只有斜率 $1$ | $1$ |
| `2` / `(-1000,-1000),(1000,1000)` | 坐标极值，斜率 $1$ | $1$ |
| `3` / `(0,0),(0,5),(3,0)` | 竖直、水平、$-\frac53$ | $3$ |

另外用 $20\times10$ 整点网格（$N=200$）跑了一遍，答案 $232$；我手工按"既约分数计数"独立核算：对 $dx=1..19$ 数 $[-9,9]$ 中与 $dx$ 互素的 $dy$ 个数，求和得 $231$，再加竖直方向 $1$ 个，恰为 $232$，与程序一致。

## 二、思维链：完整证明

**记号。** 点 $P_i=(x_i,y_i)$ 两两不同。点对 $(i,j)$（$i<j$）的方向向量 $(dx,dy)=(x_j-x_i,\;y_j-y_i)\ne(0,0)$。直线方向分两类：非竖直（$dx\ne0$，斜率 $dy/dx\in\mathbb Q$）与竖直（$dx=0$）。键函数 $\kappa$：竖直 $\mapsto(1,0)$；非竖直 $\mapsto$ 既约且 $dx>0$ 的 $(dy,dx)$。

### 引理 1（平行 ⇔ 同方向类）

两条由点对确定的直线平行 $\iff$ 它们方向相同：要么都竖直，要么斜率相等（$dy_1/dx_1=dy_2/dx_2$，等价于叉积 $dy_1dx_2=dy_2dx_1$）。

*证明*：平面几何中两直线平行 $\iff$ 方向向量共线 $\iff$ 二维叉积为 $0$：$dx_1dy_2-dy_1dx_2=0$。若 $dx_1,dx_2\ne0$，两边除以 $dx_1dx_2$ 得 $dy_1/dx_1=dy_2/dx_2$；若 $dx_1=0$，叉积为 $0$ 强制 $dx_2=0$（因 $dy_1\ne0$，点不重合），即都竖直。反之亦然。故"平行"恰好把方向划成等价类：每个非竖直斜率一类、所有竖直一类。证毕。

### 引理 2（答案 = 方向类数：上界 + 可达）

设 $\mathcal D$ 为所有点对产生的方向类集合。最大得分 $=|\mathcal D|$。

*证明*：

**上界**：任何合法画法中，任意两条已画直线不平行（否则后画的那条违反规则），由引理 1 它们方向类两两不同，故条数 $\le|\mathcal D|$。

**可达**：对每个方向类 $D\in\mathcal D$ 任取一个代表点对，得到 $|\mathcal D|$ 条直线。按任意顺序画它们：画第 $k$ 条时，已画的 $k-1$ 条分属 $k-1$ 个不同方向类，第 $k$ 条的方向类不在其中，故没有平行线，合法。于是能画满 $|\mathcal D|$ 条。

上下界相等，最大得分 $=|\mathcal D|$，且与画的顺序无关。证毕。

### 引理 3（既约分数唯一性）

设 $\frac ab=\frac cd$，$b,d>0$，$\gcd(|a|,b)=\gcd(|c|,d)=1$，则 $a=c$ 且 $b=d$。

*证明*：由 $\frac ab=\frac cd$ 得 $ad=bc$。于是 $b\mid ad$；又 $\gcd(b,a)=1$（$\gcd(|a|,b)=1$），由 Bézout 存在整数 $x,y$ 使 $bx+ay=1$，两边乘 $d$：$bdx+ady=d$，$b$ 整除左边两项（$b\mid bdx$，$b\mid ady$ 因 $b\mid ad$），故 $b\mid d$。对称地 $d\mid b$。$b,d>0$ 故 $b=d$，代回 $ad=bc$ 得 $a=c$。证毕。

### 引理 4（键函数 $\kappa$ 良定义且与方向类一一对应）

每个方向类有唯一的键；两点对平行 $\iff$ 键相同。

*证明*：

**良定义**：非竖直点对 $(dx,dy)$，$dx\ne0$，$(dx,dy)\ne(0,0)$ 故 $g=\gcd(|dx|,|dy|)\ge1$。除以 $g$ 后 $\gcd(|dy/g|,|dx/g|)=1$；若 $dx/g<0$ 同时取反，得 $dx'>0$ 且仍互素。整个过程确定性，键 $(dy',dx')$ 满足 $dx'>0$、$\gcd(|dy'|,dx')=1$。竖直点对（$dx=0,dy\ne0$）统一映到 $(1,0)$。

**单射（同键 ⇒ 平行）**：键相同则 $dx'$ 同为 $0$（都竖直，平行）或同为正且既约分数相等（斜率相等，平行）。

**满射到类 / 类内同键（平行 ⇒ 同键）**：两非竖直点对平行 ⇒ 斜率相等 $\frac{dy_1}{dx_1}=\frac{dy_2}{dx_2}$。规范化后两者都是"分母为正、既约"的同一有理数的表示，由引理 3 分子分母分别相等 ⇒ 键相同。竖直点对都映到 $(1,0)$ ⇒ 同键。

**竖直与非竖直不撞键**：非竖直键 $dx'>0$，竖直键 $dx=0$，不可能相等。水平线 $dy=0$：$g=|dx|$，化到 $(0,1)$，自成一类。

故 $\kappa$ 把方向类双射到键集合，$|\mathcal D|=|\{\kappa(i,j):i<j\}|$。证毕。

### 引理 5（欧几里得算法正确，$\gcd$ 可用）

$\gcd(a,b)=\gcd(b,a\bmod b)$（$b>0$），$\gcd(a,0)=|a|$；`std::gcd` 据此终止且返回最大公约数。

*证明*：设 $a=qb+r$，$r=a\bmod b$。若 $d\mid a,d\mid b$ 则 $d\mid(a-qb)=r$；若 $d\mid b,d\mid r$ 则 $d\mid(qb+r)=a$。故 $(a,b)$ 与 $(b,r)$ 的公约数集合相同，最大者相等。每步第二参数严格减小（$0\le r<b$）且非负，必在有限步到 $0$，此时 $\gcd(a,0)=|a|$。代码用 `gcd(abs(dx),abs(dy))`，参数非负，返回正的最大公约数。证毕。

### 引理 6（值域与复杂度）

$|dx|,|dy|\le2000$，键与中间量均 `int` 安全；点对 $\le\binom{200}{2}=19900$；时间 $O(N^2\log N)$、空间 $O(N^2)$。

*证明*：坐标 $\in[-1000,1000]$，差 $\in[-2000,2000]$，`int` 安全（本解法不做叉积乘法，连 $4\times10^6$ 的中间量都不出现）。无序点对数 $\binom N2\le19900$，每对一次 $\gcd$（$O(\log 2000)$）+ 一次 `set` 插入（$O(\log|\text{set}|)\le O(\log 19900)$），合计 $O(N^2\log N)\approx3\times10^5$ 次基本操作。`set` 至多 $19900$ 个键，空间 $O(N^2)$。答案 $\le19900$，`int` 安全。证毕。

### 定理

程序输出所有点对的不同方向数，即最大得分；时间 $O(N^2\log N)$、空间 $O(N^2)$。

*证明*：引理 1 把"平行"刻画为方向类；引理 2 把游戏归约为方向类计数（上界+可达）；引理 3、4、5 保证键函数把方向类双射到既约分数键、`gcd` 正确；引理 6 给出复杂度。`set.size()` 即不同键数 $=|\mathcal D|=$ 答案。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 规则"不能与已画平行" ⇒ 每个斜率方向至多画一条；竖直线互相平行算一个方向。
- **reduce to easier problem** — 上界（每方向至多一条）+ 构造（每方向各画一条、任意顺序合法）⇒ 最大得分 = 不同方向数，与画的顺序无关。
- **explore its property** — 方向 = 斜率（竖直单独一类）；方向与点对顺序无关 ⇒ 只枚举 $i<j$。
- **discuss by category** — `double` 斜率本题分析下碰巧安全（最小间隔 $2.5\times10^{-7}\gg$ 误差 $10^{-13}$），但竖直仍需特判；改用精确既约分数更稳。
- **classic problem solution** — 既约分数规范化：$\gcd$ 约分 + 分母化正，竖直统一 $(1,0)$；`set<pair>` 去重计数，$O(N^2\log N)$。
- **discuss by category** — 易错点：符号规范化（$(1,2)$ 与 $(-1,-2)$ 同向）、共线点只算一类、竖直不重不漏。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 点数（$2\le N\le200$） | `int`，读入 | |
| `x[i],y[i]` | 第 $i$ 点坐标（$[-1000,1000]$） | `int[mxn]`，读入 | 0-based |
| `dx,dy` | 点对方向向量分量 | `int`，每对现算 | $\|dx\|,\|dy\|\le2000$ |
| `g` | $\gcd(\|dx\|,\|dy\|)$ | `int` | 点不重合 ⇒ $g\ge1$ |
| `S` | 方向键集合，键 $(dy,dx)$ | `set<pair<int,int>>` | 竖直 $(1,0)$；非竖直 $dx>0$ 既约 |
| `mxn` | $200+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 $n$ 与 $n$ 个点坐标。
3. 枚举 $i<j$：算 $dx=x_j-x_i$，$dy=y_j-y_i$。
   - $dx=0$：`S.emplace(1,0)`（竖直方向），continue。
   - 否则 $g=\gcd(|dx|,|dy|)$，$dx/=g,dy/=g$；若 $dx<0$ 则 $dx=-dx,dy=-dy$；`S.emplace(dy,dx)`。
4. 输出 `S.size()` 与 `'\n'`（引理 2、4）。

### 复杂度

- 时间 $O(N^2\log N)$：$\le19900$ 对，每对 $O(\log)$ 的 $\gcd$ 与 `set` 插入。
- 空间 $O(N^2)$：`set` 至多 $19900$ 个键。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$5$ 组手造数据全对（含按样例解释反推的 $4$ 斜率组、竖直正方形、共线、坐标极值）；$N=200$ 的 $20\times10$ 网格答案 $232$，与手工既约分数计数（$231$ 个非竖直 $+1$ 竖直）一致；全竖直 $N=200$ 答案 $1$，运行约 $0.02$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2665 [USACO08FEB] Game of Lines S
// 思路：每个方向（斜率）至多画一条、也必能画一条 ⇒ 答案 = 不同方向数。
//       方向用既约分数 (dy,dx) 规范化：dx>0、gcd=1；竖直线统一记 (1,0)。
//       枚举所有无序点对，set 去重计数。O(N^2 log N)。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{205};

int n,x[mxn],y[mxn];
set<pair<int,int>>S;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];
	for(int i=0;i<n;++i)
		for(int j=i+1;j<n;++j)
		{
			int dx=x[j]-x[i],dy=y[j]-y[i];
			if(!dx)
			{
				S.emplace(1,0);		// 竖直线：所有竖直线互相平行，只算一个方向
				continue;
			}
			int g=gcd(abs(dx),abs(dy));
			dx/=g;dy/=g;
			if(dx<0)
				dx=-dx,dy=-dy;		// 分母规范化为正：(1,2) 与 (-1,-2) 同向
			S.emplace(dy,dx);
		}
	cout<<S.size()<<'\n';
	return 0;
}
```

### 代码说明

- **键是 `(dy,dx)`，竖直是 `(1,0)`**：第一维 $dy$、第二维 $dx$。竖直键 $dx=0$ 与非竖直键 $dx>0$ 天然不撞，水平线化到 $(0,1)$，无需额外标记。
- **符号规范化不可省**：`if(dx<0)dx=-dx,dy=-dy;` 把 $(i,j)$ 与 $(j,i)$、$(1,2)$ 与 $(-1,-2)$ 统一成同一键，否则答案翻倍。
- **只枚举 $i<j$**：方向与点对顺序无关，无序对足够，省一半。
- **`gcd(abs(dx),abs(dy))`**：点不重合保证非 $(0,0)$，$g\ge1$；`std::gcd` 非负参数返回正公约数（引理 5）。
- 用 `set` 而非 `double`：精确、无精度顾虑，竖直特判也自然融入键表示。
