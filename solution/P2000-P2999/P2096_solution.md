# P2096 最佳旅游线路 — 题解

## 一、解题过程：人类思考叙事

题意翻译：网格里有 $m$ 条**东西向**的旅游街（单行道，只能自西向东走）和 $n+1$ 条**南北向**的林阴道（双向，不计分）。每个格子 $(i,j)$ 是"第 $i$ 条旅游街上、自西向东第 $j$ 小段"的分值（$-100\sim 100$）。阿龙可以从任意一段旅游街出发，在任意一段旅游街结束，求经过的旅游街段分值和的最大值。

先把"能怎么走"这件事彻底搞清楚——这是本题唯一需要动脑的地方。

网格的路口是"行 × 列"的交点。第 $i$ 条旅游街就是第 $i$ 行，第 $j$ 小段旅游街连接的是第 $j$ 与第 $j+1$ 条林阴道。

- 沿旅游街走 = 向东走一格 = 从第 $j$ 列跨到第 $j+1$ 列，拿到 $a_{i,j}$ 的分。
- 沿林阴道走 = 在同一列里上下挪一格 = **免费**，而且方向随便。

于是整条路线可以这样描述：在某一列里上下随便挪（免费），然后向东吃掉一条旅游街段；到了下一列，再上下随便挪，再向东吃一段……如此下去。

所以有两个结论，几乎是显然的：

1. **路线经过的列一定是一个连续区间**。因为只能向东走，一旦离开某列就再也回不去了（西向是单行道，禁止）。
2. **在某一列里，吃哪一行完全自由，且各列之间互不影响**。因为列内的上下挪动免费且双向，每一列都可以独立地在 $m$ 行里挑一个。而且第 $j$ 列结束时的行，与第 $j+1$ 列开始时的行之间，只隔着一次免费的林阴道移动——想怎么接就怎么接。

第 2 条尤其关键：很多人第一反应是"二维 DP"，其实列与列之间根本没有约束。

那么在第 $j$ 列里挑哪一行最好？当然是挑分值最大的那一行。记

$$c_j=\max_{1\le i\le m} a_{i,j},$$

则路线的总分就是它经过的这段连续列上 $c_j$ 的和。

于是问题变成：**给定数列 $c_1,c_2,\dots,c_n$，求连续子段和的最大值**。这是 Kadane 算法，一趟扫过去就行。

不过有两个细节要抠：

- 分值可以是负数。"所有分值不可能全是负分"保证了答案不会是"必须选一段负数"的尴尬局面，但我们的 Kadane 必须**允许中途放弃**（`cur = max(c_j, cur + c_j)`），否则会把负前缀带进后面的正数里，把答案算小。
- 答案不能是"什么都不走"的 0。路线至少要经过一段旅游街，所以 `cur` 的初值要按"第一列就必须选"来写，不能用 `cur = max(0, cur) + c_j` 那种允许空段的写法（那种写法在 `c_j` 全负时会返回 0，而本题正确答案应是其中最大的那个负数）。所幸题目保证不全为负，但为了逻辑严密，我用"先取 `c_j`，再和 `cur + c_j` 取大"的写法。

数据范围：$m\le 100$，$n\le 20001$，$nm\le 2\times 10^6$，读入本身就够，时间完全不是瓶颈。

样例验证：$3\times 5$ 的矩阵，列最大值分别是

$$c=(17,\ -3,\ 36,\ 34,\ -8),$$

连续子段 $17-3+36+34=84$，与官方答案一致。

## 二、思维链：完整证明

**记号约定**：矩阵 $a_{i,j}$ 表示第 $i$ 条旅游街（行）、第 $j$ 小段（列）的分值；$m$ 为旅游街条数（行数），$n$ 为每条旅游街的小段数（列数）；一条合法路线记为从列 $l$ 到列 $r$（$l\le r$）的一串横跨段。

**引理 1**：任何合法路线所经过的列构成一个连续区间 $[l,r]$，且该路线恰好在第 $j\in[l,r]$ 列吃掉一个横跨段（一个格子）。

*证明*：一条横跨段 $a_{i,j}$ 位于第 $j$ 与第 $j+1$ 条林阴道之间，走过它一定是从第 $j$ 列移动到第 $j+1$ 列。旅游街是单行道，只能自西向东，因此列坐标严格递增且每次恰好加一，于是经过的列必为连续区间 $[l,r]$，且在每个 $j\in[l,r]$ 内恰好走一个横跨段。证毕。

**引理 2**：固定路线经过的列区间 $[l,r]$，其总分不超过 $\sum_{j=l}^{r} c_j$，且该上界可以取到。

*证明*：由引理 1，路线在每个列 $j\in[l,r]$ 内恰走一个格子 $a_{i_j,j}$，总分 $=\sum_{j=l}^{r} a_{i_j,j}\le \sum_{j=l}^{r}\max_i a_{i,j}=\sum_{j=l}^{r}c_j$，上界成立。

下面证上界可达。构造路线：令 $i_j$ 取第 $j$ 列中分值最大的那一行。构造方法为——从路口 $(i_l,l)$ 出发；吃掉 $a_{i_l,l}$ 走到 $(i_l,l+1)$；在第 $l+1$ 条林阴道上向下（或向上）移动到 $(i_{l+1},l+1)$，再吃掉 $a_{i_{l+1},l+1}$；如此继续直到第 $r$ 列。

此构造的合法性：林阴道双向且不计分，故列内上下移动永远合法；旅游街只要求向东，本构造每一步都向东，合法。

此构造的分数：由引理 1，每列恰吃一段，分数 $=\sum_{j=l}^{r}a_{i_j,j}=\sum_{j=l}^{r}c_j$，达到上界。证毕。

**引理 3**：在区间 $[l,r]$ 内的最优分数恰为 $\sum_{j=l}^{r}c_j$。

*证明*：由引理 2，任何经过该区间的路线分数 $\le\sum c_j$，且引理 2 的构造给出分数恰为 $\sum c_j$ 的路线。两者相等即为结论。证毕。

**引理 4**：设 $f_j$ 表示"以第 $j$ 列结尾的连续列区间的最大 $c$ 之和"，则递推 $f_j=\max(c_j,\ f_{j-1}+c_j)$ 正确，且全局答案为 $\max_{1\le j\le n} f_j$。

*证明*：以第 $j$ 列结尾的非空连续区间只有两种形态：

- 只含第 $j$ 列本身，其和为 $c_j$；
- 形如 $[l,j]$ 且 $l<j$，其和为 $\sum_{k=l}^{j-1}c_k+c_j$，其中 $\sum_{k=l}^{j-1}c_k\le f_{j-1}$，且取 $l$ 使其等于 $f_{j-1}$ 的那个区间可以接上第 $j$ 列（引理 2 的构造允许列与列自由衔接），故这一类的最大值恰为 $f_{j-1}+c_j$。

取两者最大即得递推式。而每条非空连续区间都有唯一的右端点，故全局最大值 $=\max_j f_j$。证毕。

**定理**：算法输出的就是最佳游览线路的总分值。

*证明*：由引理 3，最佳路线等价于求数列 $c$ 的最大连续子段和；由引理 4，Kadane 递推恰好求出该值，故算法输出正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **先把"能怎么走"搞清楚** — 旅游街只东向、林阴道免费双向 ⇒ 路线经过的列是连续区间，列内可上下自由挪动。
2. **发现列与列之间无约束** — 每列结束时的行与下一列开始时的行之间隔着一次免费移动 ⇒ 不需要二维 DP，按列压成一维。
3. **每列取最大** — 列内自由 ⇒ 该列必取 $c_j=\max_i a_{i,j}$。
4. **归约到经典问题** — 答案 = 数列 $c$ 的最大连续子段和 ⇒ Kadane 一趟扫。
5. **补上负数细节** — 答案必须非空 ⇒ 递推写成 `max(c_j, f_{j-1}+c_j)` 而非允许空段的写法。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $m$ | 旅游街条数（行数） | `int`，$\le 100$ |
| $n$ | 每条旅游街的小段数（列数） | `int`，$\le 20001$ |
| $a_{i,j}$ | 第 $i$ 行第 $j$ 列的分值 | `int`，$[-100,100]$ |
| `col[j]` | 第 $j$ 列的最大分值 $c_j$ | `int[]`，下标 $0..n-1$，初值 $-\infty$ |
| `cur` | 以当前列结尾的最大子段和 $f_j$ | `int` |
| `ans` | 全局最大子段和 | `int` |

### 算法步骤

1. 读入 $m,n$。
2. 用 `fill_n(col,n,-1145141919)` 把每列的最大值初始化为负无穷（分值可能全负，不能初始化为 0）。
3. 逐行读入 $mn$ 个分值，每次 `col[j]=max(col[j],x)`，读完全部得到每列最大值。
4. Kadane 一趟扫：`cur=0`、`ans=-1145141919`；对每个 `j` 依次执行 `cur=max(col[j],cur+col[j])`、`ans=max(ans,cur)`。
   - `cur` 初值为 0 时首个元素自然取成 `col[0]`（`max(col[0],0+col[0])`），保证区间非空。
5. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(mn)$，读入 $mn$ 个数是下界（每个数都要读一遍），扫描列是 $O(n)$。
- 空间复杂度：$O(n)$，只需存每列最大值，不必存整个矩阵。

### 验证状态

- 标程 `P2096.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `3 5 / -50 -47 36 -30 -23 / 17 -19 -34 -13 -8 / -42 -3 -43 34 -45` 输出 `84`，与官方一致。
- 编写暴力 `P2096_brute.cpp`（二维 DP，显式维护"当前停在第几行"，换行免费）与对拍脚本 `P2096_check.py`，在 $m,n\le 12$、分值 $\in[-100,100]$ 的随机数据上对拍 **2000 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2096 最佳旅游线路
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20005};

int m,n;
int col[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n;
	//col 存每一列(林阴道之间的一小段旅游街)的最大值
	fill_n(col,n,-1145141919);
	for(int i=0;i<m;++i)
		for(int j=0;j<n;++j)
		{
			int x;cin>>x;
			col[j]=max(col[j],x);
		}

	//最大子段和:col 的连续若干列之和的最大值
	int cur=0,ans=-1145141919;
	for(int j=0;j<n;++j)
	{
		cur=max(col[j],cur+col[j]);
		ans=max(ans,cur);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `col[]` 只存每列最大值，不存矩阵。读入时 `fill_n(col,n,-1145141919)` 必须做：分值可以是负数，若初始化为 0 会把负列错误地抬高。
- `cur=max(col[j],cur+col[j])` 而不是 `cur=max(0,cur)+col[j]`：后者允许空区间，在"列最大值全为负"时会返回 0，而本题要求至少经过一段旅游街。
- `ans` 初值同样取负无穷哨兵 `-1145141919`，保证答案一定是某个真实区间的和。
- 答案绝对值不超过 $100\times 20001\approx 2\times 10^6$，`int` 足够。
