# P2524 Uim的情人节礼物·其之弐 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N\le 9$，给出 $1..N$ 的一个排列，**写成一个没有空格的整数 $X$**（如 $N=3$ 时 `213`）。问它是所有 $N!$ 个排列按字典序排序后的**第几小**（从 $1$ 开始）。题面没有样例，下面的例子都是手算并用程序核对过的。

**第一反应：枚举。** 从最小排列 $123\dots N$ 出发反复 `next_permutation`，数到 $X$ 为止。$9!=362880$，每步 $O(N)$，最坏约 $3\times10^6$ 次操作——**说实话这题枚举就能过**，我不想假装它超时。但"数到它"是笨办法：排名本质是一个**计数问题**——"有多少个排列比 $X$ 小？"直接数出来，$O(N^2)$ 一步到位，而且这正是标签里的**康托展开**。前传 P2525 是它的逆运算（给排名构造排列），两题合起来就是"排列 $\leftrightarrow$ 排名"的双射。

**第二步：把"比它小"分类。** 设排列为 $a_0a_1\dots a_{N-1}$。一个排列 $b$ 比 $a$ 小，意味着在**第一个不同的位置** $i$ 上 $b_i<a_i$（字典序的定义）。按这个"第一个不同位置"分类：

- 第 $i$ 类：$b_0\dots b_{i-1}$ 与 $a$ 完全相同，$b_i<a_i$，后面随便排。

各类**不重**（第一个不同位置唯一）**不漏**（任何更小的排列必有第一个不同位置）。于是只需数每一类的大小。

**第三步：数第 $i$ 类。** 前缀 $a_0..a_{i-1}$ 固定后，用掉的数字恰好是这几个，**剩下的可用数字就是后缀 $\{a_i,\dots,a_{N-1}\}$**（作为集合）。所以：

- $b_i$ 的选择：后缀中比 $a_i$ 小的数字，设个数为 $c_i$。由于元素互不相同，$c_i=\#\{j>i:a_j<a_i\}$——**往后扫一遍就能数**，不需要额外的"用过没用过"标记。
- 后面 $N-1-i$ 个位置：剩余 $N-1-i$ 个数字任意排列，$(N-1-i)!$ 种。

乘法原理：第 $i$ 类大小 $=c_i\cdot(N-1-i)!$。求和再加 $1$（排名从 $1$ 起，数出来的是"严格更小"的个数）：

$$\boxed{\mathrm{rank}(a)=1+\sum_{i=0}^{N-1}c_i\cdot(N-1-i)!}$$

这就是康托展开。手算验证：$a=213$，$c_0=1$（后缀里 $1<2$），$c_1=c_2=0$，$\mathrm{rank}=1+1\times2!=3$；枚举 $123,132,213,\dots$ 确实第 $3$ ✓。

**第四步：输入陷阱——没有空格。** 题面特意提醒"输入的排列没有空格"。$N\le 9$ 保证每个元素都是一位数，且排列含 $1..N$、**不含 $0$**，所以 $X$ 的十进制位与排列元素一一对应，也不存在前导零丢失问题。最稳的读法：`cin>>n>>s`（字符串），`a[i]=s[i]-'0'`。若按 `int` 读再逐位拆也行，但字符串天然保位。

**第五步：范围与边界。** $9!=362880$，`int` 绰绰有余；中间项 $c_i\cdot(N-1-i)!\le 8\times 8!=322560$，求和 $\le 362879$，无溢出。$N=1$：唯一排列 `1`，$c_0=0$，输出 $1$ ✓。两个极端自查：升序 $123\dots N$ 所有 $c_i=0$ → 排名 $1$；降序 $N\dots 21$ 的 $c_i=N-1-i$，求和 $\sum_{i}(N-1-i)(N-1-i)!=N!-1$（裂项，引理 4 证）→ 排名 $N!$ ✓。

**手造数据核对**（程序输出全部吻合）：

| 输入 | 期望 | 依据 |
|---|---|---|
| `3` / `123` | $1$ | 最小排列 |
| `3` / `213` | $3$ | $123,132,213$ |
| `3` / `321` | $6$ | 最大排列，$3!=6$ |
| `4` / `2143` | $8$ | 首位 $1$ 的 $6$ 个 + $2134$(第7) + $2143$(第8) |
| `1` / `1` | $1$ | 唯一排列 |
| `9` / `123456789` | $1$ | 升序 |
| `9` / `987654321` | $362880$ | 降序 $=9!$ |

## 二、思维链：完整证明

**记号。** $a=(a_0,\dots,a_{n-1})$ 是 $[n]=\{1,\dots,n\}$ 的排列，$n\le 9$。字典序：$b<a\iff$ 存在 $p$ 使 $b_0..b_{p-1}=a_0..a_{p-1}$ 且 $b_p<a_p$（第一个不同位处更小）。$\mathrm{rank}(a)=\#\{b\in S_n:b<a\}+1$。$c_i=\#\{j>i:a_j<a_i\}$。$\mathrm{fac}[k]=k!$。

---

### 引理 1（字典序是有限全序，排名良定义）

字典序是 $S_n$ 上的严格全序（非自反、传递、三分），故 $\mathrm{rank}(a)\in\{1,\dots,n!\}$ 良定义，且 $\mathrm{rank}$ 是 $S_n$ 到 $\{1..n!\}$ 的双射。

*证明*：非自反：$a<a$ 要求某位 $a_p<a_p$，假。三分：$a\ne b$ 时取第一个不同位 $p$（存在，因 $a\ne b$ 且等长），$a_p\ne b_p$ 是整数比较，恰一方向成立。传递：设 $a<b$（首个不同位 $p$）、$b<c$（首个不同位 $q$），取 $r=\min(p,q)$。在 $r$ 之前三者两两相等；若 $p<q$：$a_p<b_p=c_p$ ⇒ $a<c$；若 $q<p$：$a_q=b_q<c_q$ ⇒ $a<c$；若 $p=q$：$a_p<b_p<c_p$ ⇒ $a<c$。故传递。

有限全序中"比 $a$ 小的元素个数 $+1$"就是 $a$ 的位次；不同位次的排列排名不同，$n!$ 个排列占满 $1..n!$。证毕。

### 引理 2（按第一个不同位划分"更小集合"）

令 $S_i=\{b\in S_n:b_0..b_{i-1}=a_0..a_{i-1},\ b_i<a_i\}$（$i=0..n-1$）。则
$$\{b:b<a\}=\bigsqcup_{i=0}^{n-1}S_i\quad(\text{不交并}).$$

*证明*：**不漏**：$b<a$ ⇒ 存在第一个不同位 $p$ 且 $b_p<a_p$ ⇒ $b\in S_p$。**不重**：若 $b\in S_i$，则 $b$ 与 $a$ 在 $i$ 之前逐位相等、在 $i$ 处 $b_i<a_i$（故 $b_i\ne a_i$），所以 $i$ **就是** $b$ 与 $a$ 的第一个不同位；第一个不同位唯一，故 $b$ 不能同时属于 $S_j\ (j\ne i)$。**每个 $S_i$ 确实都更小**：$b\in S_i$ 满足字典序定义（首个不同位 $i$ 处更小），故 $b<a$。证毕。

### 引理 3（第 $i$ 类的大小 $=c_i\cdot(n-1-i)!$）

$|S_i|=c_i\cdot(n-1-i)!$，其中 $c_i=\#\{j>i:a_j<a_i\}$。

*证明*：构造双射。$b\in S_i$ 的前缀固定为 $a_0..a_{i-1}$，故 $b$ 在位置 $i..n-1$ 上用的数字集合恰为 $R=[n]\setminus\{a_0,\dots,a_{i-1}\}=\{a_i,\dots,a_{n-1}\}$（$a$ 是排列，前缀用掉的与后缀剩下的互补）。

- **位置 $i$ 的选择**：$b_i\in R$ 且 $b_i<a_i$。$R$ 中满足 $v<a_i$ 的元素个数：$a_i$ 本身不满足（$<$ 非自反），其余 $R\setminus\{a_i\}=\{a_{i+1},\dots,a_{n-1}\}$ 中满足者即 $\#\{j>i:a_j<a_i\}=c_i$。
- **其余位置**：选定 $b_i=v$ 后，剩 $n-1-i$ 个数字填 $n-1-i$ 个位置，任意排列都合法（前缀与 $b_i$ 已定，无其他约束），共 $(n-1-i)!$ 种，且互不相同。

映射 $b\mapsto(b_i,\ (b_{i+1},\dots,b_{n-1}))$ 是 $S_i$ 到"$c_i$ 个选择 $\times$ $(n-1-i)!$ 个排列"的双射（逆映射：拼前缀 $+$ 选值 $+$ 尾排列，唯一还原）。乘法原理得 $|S_i|=c_i\cdot(n-1-i)!$。证毕。

### 引理 4（康托展开公式与两个极端）

$$\mathrm{rank}(a)=1+\sum_{i=0}^{n-1}c_i\cdot(n-1-i)!.$$
特别地：升序排列排名 $1$；降序排列排名 $n!$。

*证明*：由引理 1，$\mathrm{rank}(a)=\#\{b:b<a\}+1$；由引理 2 的不交并，$\#\{b:b<a\}=\sum_i|S_i|$；由引理 3 代入即得公式。

**升序** $a=(1,2,\dots,n)$：每个后缀都升序，$a_i$ 是后缀最小值，$c_i=0$，$\mathrm{rank}=1$ ✓（它确实是字典序最小）。

**降序** $a=(n,n-1,\dots,1)$：$c_i=n-1-i$（后缀全部比 $a_i$ 小）。令和式 $T=\sum_{i=0}^{n-1}(n-1-i)\cdot(n-1-i)!$。换元 $k=n-1-i$：$T=\sum_{k=0}^{n-1}k\cdot k!=\sum_{k=1}^{n-1}k\cdot k!$。用裂项恒等式 $k\cdot k!=(k+1)!-k!$（因 $(k+1)!=(k+1)k!=k\cdot k!+k!$）：
$$T=\sum_{k=1}^{n-1}\bigl((k+1)!-k!\bigr)=n!-1!=n!-1.$$
故 $\mathrm{rank}=1+T=n!$ ✓（最大排列排最后）。证毕。

### 引理 5（无空格输入的解析正确性）

把第二行按字符串读入 $s$，令 $a_i=s_i-'0'$，得到的恰为题目给出的排列。

*证明*：题面保证排列元素为 $1..n$、$n\le 9$，故每个元素是**一位**十进制数字且 $\in\{1..9\}$。"没有空格"意味着 $X$ 的十进制表示就是这 $n$ 个数字依次拼接：$X=\sum_{i}a_i\cdot 10^{n-1-i}$。由于不含 $0$，最高位 $a_0\ge 1$，十进制表示无前导零，位数恰为 $n$，逐位对应唯一。字符串读入保留全部字符（`cin>>s` 按空白切分，不会丢位），$s_i-'0'$ 还原数字。证毕。

### 引理 6（值域与复杂度）

所有中间量与答案都在 `int` 范围内；时间 $O(n^2)$，空间 $O(n)$。

*证明*：$\mathrm{fac}[k]=k!\le 9!=362880$；$c_i\le n-1-i\le 8$；单项 $c_i\cdot(n-1-i)!\le 8\times 8!=322560$；由引理 4，部分和 $\le n!-1\le 362879$，答案 $\le 362880$，远小于 $2^{31}-1$。时间：双重循环数 $c_i$ 共 $\sum_i(n-1-i)=\binom n2\le 36$ 次比较，阶乘预处理 $O(n)$；空间：`a,fac` 各 $O(n)$。证毕。

### 定理

程序输出 $1+\sum_i c_i\cdot(n-1-i)!$，即排列 $a$ 的字典序排名（$1$-based）；时间 $O(n^2)$，空间 $O(n)$。

*证明*：引理 5 保证读入的 $a$ 正确；引理 1 保证排名良定义；引理 2、3 把"更小排列计数"化为不交类计数；引理 4 给出公式并核对两个极端；引理 6 保证 `int` 与复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **consider easier version** — $N\le 9\Rightarrow 9!=362880$，`next_permutation` 枚举数步数其实能过；但直接计数更优雅，$O(N^2)$。
- **explore its property** — 排名 $=$ 严格更小的排列数 $+1$；更小排列按"第一个不同位 $i$"分类，前缀固定 $\Rightarrow$ 可用数字恰为原排列的后缀集合。
- **reduce to easier problem** — 第 $i$ 类 $=$ $c_i$ 种选值 $\times$ $(n-1-i)!$ 种自由排列；各类不重不漏，乘法原理 $+$ 加法原理。
- **classic problem solution** — 康托展开 $\mathrm{rank}=1+\sum c_i\cdot(n-1-i)!$，$c_i$ 用后缀扫描 $O(N^2)$ 数出，无需标记数组。
- **discuss by category** — 无空格输入按字符串读；$N=1$；别忘了 $+1$；升序 $\to1$、降序 $\to N!$（裂项求和自查）；$9!$ 在 `int` 内。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 排列长度（$\le 9$） | `int`，读入 | |
| `s` | 第二行无空格整数 $X$ 的字符串形式 | `string`，读入 | 逐位 `-'0'` 即排列 |
| `a[i]` | 排列第 $i$ 位（$0$-based，值 $1..n$） | `int[mxn]` | 由 `s` 解析 |
| `fac[k]` | $k!$ | `int[mxn]`，`fac[0]=1` 递推 | $\le 9!=362880$ |
| `c` | 当前位的 $c_i=\#\{j>i:a_j<a_i\}$ | `int`，每轮清零 | 后缀里比 `a[i]` 小的个数 |
| `ans` | 排名 | `int`，**初值 $1$** | 康托展开数的是"严格更小"，$+1$ 在初始化里 |
| `mxn` | $9+5$ 松弛 | `constexpr int{15}` | |

### 算法步骤

1. I/O 加速三行。
2. 读 `n` 与字符串 `s`；`a[i]=s[i]-'0'`。
3. 预处理 `fac[0..n]`：`fac[0]=1; fac[i]=fac[i-1]*i`。
4. `ans=1`；对 `i=0..n-1`：内层扫 `j=i+1..n-1` 数 `c`；`ans+=c*fac[n-1-i]`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(n^2)\le 36$ 次比较 $+$ $O(n)$ 阶乘预处理。
- 空间：$O(n)$，两个长度 $15$ 的数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面无样例，手造 $7$ 组（升序/降序/中间排列 `213`、`2143`、$N=1$、$N=9$ 两个极端）全部与手工枚举/裂项公式一致。入门级康托展开直套，证明已闭合（引理 2、3 不重不漏），未写对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2524 Uim的情人节礼物·其之弐
// 思路：康托展开：比 a 小的排列按"第一个不同位 i"分类，
//       第 i 类有 c_i·(n-1-i)! 个（c_i=后缀中比 a[i] 小的个数）
//       排名 = 1 + Σ c_i·(n-1-i)!
//       输入排列无空格 ⇒ 按字符串读入逐位取数字
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{15};

int n,a[mxn],fac[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	string s;
	cin>>n>>s;
	for(int i=0;i<n;++i)
		a[i]=s[i]-'0';
	fac[0]=1;
	for(int i=1;i<=n;++i)
		fac[i]=fac[i-1]*i;
	int ans=1;	// 康托展开数的是"严格更小"，排名要 +1
	for(int i=0;i<n;++i)
	{
		int c=0;
		for(int j=i+1;j<n;++j)
			if(a[j]<a[i])
				++c;
		ans+=c*fac[n-1-i];
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **字符串读入**是题面"排列没有空格"的直接应对：`cin>>n>>s` 一次读两个 token，`s[i]-'0'` 逐位还原。排列不含 $0$，无前导零歧义；$N\le 9$ 保证每位就是一个元素。
- **`ans` 初值 $1$**：康托展开算出的是"比它小的排列个数"，排名从 $1$ 起。忘加 $1$ 是本题最常见的 WA（升序排列会输出 $0$）。
- **`c` 往后扫而不是开 `vis` 数组**：前缀固定后"未用数字"恰为后缀，元素互异使"未用且更小"等价于"后缀中更小"，$O(N^2)$ 足够，无需 BIT/标记。
- `fac[n-1-i]` 是"后面还剩几个位置"的阶乘，别写成 `fac[i]`；`fac[0]=1` 处理最后一位（$c_{n-1}$ 恒 $0$，乘 $1$ 无害）。
- 全程 `int`：最大答案 $9!=362880$，最大中间项 $8\times 8!=322560$，无溢出。
