# P2958 [USACO09OCT] Papaya Jungle G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 一个 $R$ 行 $C$ 列的网格（$1\le R,C\le 40$），每格有 $F_{ij}$ 个木瓜（$1\le F_{ij}\le 100$）。Bessie 从 $(1,1)$ 出发，规则完全固定：

1. 吃掉当前格里**所有**木瓜；
2. 用望远镜看上下左右四个方向上**网格内**的邻格，数每格**还没被吃掉**的木瓜数；
3. 走向数目最多的那个邻格（题目保证这样的格子**唯一**）；
4. 重复，直到到达 $(R,C)$，吃掉那里的木瓜后停止。

求她一共吃了多少个木瓜。

**先抠清楚几个口径**（题面叙述比较文学化，必须落地成无歧义的规则）：

- **"沿跟 X 轴或 Y 轴平行的直线走到邻接的另一个格"**：即四连通邻格（上下左右），不含对角线，也不含越界的格子。
- **"没有被吃掉的木瓜"**：暗示她吃过的格子木瓜数归零。她在 $(1,1)$ 时就在"咀嚼木瓜"，所以**起点也要吃**；终点 $(R,C)$ 的木瓜也计入（"在右下角谷仓吃完木瓜时吃的木瓜总数"）。
- **没有任何决策自由度**：每一步走向哪里被规则唯一确定。这不是最优化问题，是**纯模拟**——唯一的"算法内容"是证明这个模拟良定义、会停机，以及"吃光"如何体现在状态里。

**手造小数据核对**（题面只有一张顺序示意图，没有样例输入输出，我自己造）：

第一组，$2\times 2$：

```
5 7
3 9
```

起点吃 $5$；邻格 $7$（右）与 $3$（下），走右吃 $7$；邻格 $0$（左，已吃）与 $9$（下），走下吃 $9$，恰好是终点。答案 $5+7+9=21$。

第二组，$3\times 3$，路径会拐弯：

```
1 9 2
3 8 4
5 6 7
```

吃 $1\to$ 右吃 $9\to$ 下吃 $8\to$ 下吃 $6\to$ 右吃 $7$（终点）。每一步的最大值都唯一（例如在 $8$ 处邻格为 $0,3,4,6$，最大 $6$ 唯一），答案 $1+9+8+6+7=31$。

第三组，边界情形 $1\times 1$：只有一格，起点即终点，答案就是 $F_{11}$（造 $100$，输出 $100$）。

第四组，单行 $1\times 4$：`2 5 3 9`。起点只有一个邻格 $5$，走过去吃 $5$；邻格 $0$ 与 $3$，走 $3$；邻格 $0$ 与 $9$，走 $9$（终点）。答案 $2+5+3+9=19$。这组专门检查"单行网格端点只有一个邻格"的边界。

四组手算全部与程序输出一致。

**一个必须想清楚的问题：模拟会不会死循环？** 网格有限，但如果 Bessie 在几个吃空的格子之间来回走，`while` 就停不下来了。题面只说"最终总是会在 $(R,C)$ 停止"，这是**承诺**不是**证明**；写代码前我要确认：在满足"最大值唯一"保证的数据上，她**根本不会踏上已吃空的格子**，于是每步都吃新格子，至多 $RC-1$ 步必然结束。这个性质是本题唯一非平凡的地方，下面引理 2 完整证明。

## 二、思维链：完整证明

**记号。** 网格内部用 0-based 坐标 $(i,j)$，$0\le i<R$，$0\le j<C$。初始木瓜数 $F_{ij}\ge 1$。$a_{ij}$ 表示**当前未被吃掉**的木瓜数（初始 $=F_{ij}$，吃过后 $=0$）。"邻格"指四连通且在网格内的格子。终点 $t=(R-1,C-1)$。题目保证：在到达 $t$ 之前的每一步，当前格的所有邻格中 $a$ 值最大者**唯一**。

---

### 引理 1（吃光 = 置零；答案 = 访问过的格子的初始值之和）

Bessie 在第 $k$ 次到达格子 $v$ 时吃掉的木瓜数为：$k=1$ 时 $F_v$，$k\ge 2$ 时 $0$。因此总食用量 $=\sum_{v\in V}F_v$，其中 $V$ 是她访问过的**不同**格子集合。

*证明*：对访问次数归纳。规则 1 说"吃掉当前格里所有木瓜"，故首次到达时吃掉全部 $F_v$ 个，此后 $a_v=0$。第二次及以后到达时，格子里未被吃掉的木瓜数为 $0$（期间没有任何规则会往格子里**添加**木瓜——木瓜只会减少不会增加），所以她吃 $0$ 个。于是每个格子对总量的贡献恰为"首次访问时的 $F_v$"，与访问次数无关。把所有格子的贡献相加即得 $\sum_{v\in V}F_v$。证毕。

**推论（实现口径）**：维护数组 $a$，进入一格就 `ans+=a[x][y]; a[x][y]=0;`。这样"望远镜数未吃木瓜"直接读 $a$，"总食用量"直接累加，两件事用同一份状态完成，不需要额外的 `vis` 数组。

---

### 引理 2（合法数据上，每一步都踏上未吃过的格子）

在满足题目保证（到达终点前每步最大邻格唯一）的数据上，Bessie 的每一次移动的目标格都满足 $a\ge 1$，即从未吃过。

*证明*：反证 + 最小反例。假设存在踏上已吃格子的移动，取**时间最早**的一次，设它发生在时刻 $t$，从 $u$ 走向 $v$。因为 $v$ 已被吃过，$a_v=0$；又 $v$ 是最大值获得者，所以 $u$ 的**所有**网格内邻格的 $a$ 值都 $\le 0$，即都等于 $0$（$a$ 非负），即**全部被吃过**。过程尚未停止，故 $u\ne t$。下面按网格形状数 $u$ 的邻格个数：

**情形 A：$R\ge 2$ 且 $C\ge 2$。** 角格有 $2$ 个邻格，边格 $3$ 个，内部格 $4$ 个——任何格子都至少 $2$ 个邻格。于是至少两个邻格并列最大值 $0$，与"最大值唯一"的保证矛盾。

**情形 B：$R=1$（单行；$C=1$ 对称）。** 此时端点 $(0,0)$ 与 $(0,C-1)$ 各只有 $1$ 个邻格，其余格子有 $2$ 个。
- $u=(0,C-1)$ 就是终点 $t$，与 $u\ne t$ 矛盾。
- $u=(0,0)$：若 $t=0$（第一步），此刻所有格子都未吃（$F\ge 1$），唯一邻格 $(0,1)$ 的 $a=F_{0,1}\ge 1$，目标未吃，与"$v$ 已吃"矛盾。若 $t>0$，则 Bessie 在时刻 $t$ 之前曾**回到** $(0,0)$；而 $(0,0)$ 在时刻 $0$ 就被吃空，回到它本身就是一次"踏上已吃格子"的移动，发生时刻 $<t$，与 $t$ 的最小性矛盾。
- 其余格子有 $2$ 个邻格，同情形 A 矛盾。

**情形 C：$R=C=1$。** 起点即终点，没有任何移动，反例不存在。

所有情形都导出矛盾，故不存在这样的最早反例，即**任何移动的目标都未吃过**。证毕。

**这条引理是全部代码合法性的地基**：它把题面的文学承诺（"最终会停在 $(R,C)$"）强化成了一个可检验的不变量——模拟循环每轮吃一个新格子。

---

### 引理 3（停机性与步数上界）

模拟过程至多执行 $RC$ 轮"吃 + 移动"，必然停机；且由题目保证，停机位置是 $(R,C)$。

*证明*：由引理 2，每次移动进入一个**从未访问过**的格子（吃过 $\iff$ 访问过，因为进入即吃光）。网格共 $RC$ 个格子，起点占去 $1$ 个，故移动次数 $\le RC-1$，"吃"的轮数 $\le RC$。有限步内要么到达 $t$ 停止，要么格子耗尽；而格子耗尽前过程不会卡住（引理 2 的证明表明：只要还没停，当前格必有未吃邻格，否则唯一性保证被违反），题目进一步保证停止位置为 $t$。因此 `while(true){吃; if(终点)break; 走;}` 至多 $RC$ 轮后从 `break` 退出。证毕。

---

### 引理 4（模拟不变量：程序状态 = 真实过程状态）

设程序循环执行了 $k$ 轮"吃"之后（尚未判断是否终点），则：
(a) 程序中 $(x,y)$ 等于 Bessie 真实位置；
(b) 数组 $a_{ij}$ 等于真实未吃木瓜数；
(c) `ans` 等于 Bessie 已吃掉的木瓜总数。

*证明*：对 $k$ 归纳。

$k=1$（初始进入循环）：$(x,y)=(0,0)$ 即起点 ✓；$a$ 刚读入，等于 $F$，尚无格子被吃 ✓；`ans`$=0$ ✓。执行"吃"：`ans+=a[x][y]` 把当前格全部未吃木瓜计入，`a[x][y]=0` 置空——由引理 1，这正是真实吃法的状态转移，三条不变量保持。

设第 $k$ 轮吃之前不变量成立。吃之后如上保持。若当前是终点，程序与真实过程同时停止，无需再证。否则程序扫描四个方向、跳过越界格、取 $a$ 值最大的邻格 $(bx,by)$。由 (b)，程序比较的 $a$ 值就是望远镜看到的"未吃木瓜数"；由题目保证最大值唯一，`>` 的严格比较选出的格子与规则 3 指定的格子**同一个**（唯一最大值不受扫描顺序影响）。于是移动后 (a) 保持；移动不改 $a$ 与 `ans`，(b)(c) 保持。归纳完成。证毕。

**注意"唯一性"在实现上的作用**：代码用 `if(a[nx][ny]>best)` 顺序扫描，平局时取先扫到的。合法数据无平局（保证），所以扫描顺序无关紧要；若数据非法，行为未定义——但那不在题目范围内。

---

### 引理 5（复杂度）

时间 $O(RC)$，空间 $O(RC)$。

*证明*：读入 $O(RC)$。由引理 3，循环至多 $RC$ 轮，每轮做常数次操作（累加、置零、至多 $4$ 个邻格的比较）。故总时间 $O(RC)\le 1600$ 次基本操作。空间为一个 $45\times 45$ 的 `int` 数组，$O(RC)$。证毕。

---

### 定理

程序输出的整数恰为 Bessie 按题目规则吃掉的木瓜总数。

*证明*：引理 1 把"总食用量"化归为"访问格子的初始值之和"，并给出"累加后立刻置零"的等价实现；引理 2 保证合法数据上每步都走向未吃格子，从而引理 3 保证循环有限步停机于终点；引理 4 保证程序每一步的位置、剩余木瓜、累计食用量都与真实过程一致；停机时 `ans` 即总量（含起点与终点）。引理 5 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 移动规则完全确定、无决策自由度：这是纯模拟，不是最优化；"未吃木瓜数"= 吃光后置零的数组值。
2. **explore its property** — 担心死循环 → 追问"会不会踏上吃空的格子"，发现已吃格值为 $0$ 而初始值 $\ge 1$。
3. **discuss by category** — 按网格形状数邻格（内部 $4$/边 $3$/角 $2$/单行端点 $1$）：除起点与终点外任何格子至少 $2$ 个邻格，"全邻格吃空"必造成平局，与唯一性保证矛盾 ⇒ 永不重访。
4. **reduce to easier problem** — 总食用量 = 访问过的不同格子的初始值之和 ⇒ `ans+=a; a=0;` 一份状态同时维护"望远镜读数"与"累计答案"。
5. **classic problem solution** — 方向数组 `dx/dy` + 越界判断的网格模拟；`while(true)` 吃→判终点→走，至多 $RC$ 轮。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `r,c` | 网格行数、列数，$\le 40$ | `int` | 读入 |
| `a[i][j]` | 格子 $(i,j)$ **当前未吃**木瓜数 | `int[mxn][mxn]` | 读入 $F$；吃过置 $0$ |
| `mxn` | $40+5=45$ | `constexpr int` | 数组尺寸 |
| `dx,dy` | 四方向偏移（上下左右） | `constexpr int[4]` | 与题意"平行于坐标轴"对应 |
| `x,y` | Bessie 当前位置（0-based） | `int` | 初始 $(0,0)$ |
| `ans` | 已吃木瓜总数 | `int` | 全局默认 $0$；上界 $40\times40\times100=1.6\times10^5$，`int` 足够 |
| `bx,by,best` | 本轮最优邻格坐标与其 $a$ 值 | `int` | `best=-1`（$a\ge 0$，保证任何合法邻格都能更新它） |

### 算法步骤

1. I/O 加速三行；读入 $R,C$ 与网格 $a$。
2. 令 $(x,y)=(0,0)$，进入循环：
   1. `ans+=a[x][y]; a[x][y]=0;`（吃光当前格）。
   2. 若 $(x,y)=(R-1,C-1)$，`break`。
   3. 枚举 $4$ 个方向，跳过越界格，用严格 `>` 取 $a$ 值最大的邻格 $(bx,by)$。
   4. $(x,y)\leftarrow(bx,by)$。
3. 输出 `ans`。

### 复杂度

- 时间 $O(RC)\le 1600$ 轮，每轮 $O(4)$。
- 空间 $O(RC)$，一个 $45\times45$ 的 `int` 数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 $2\times2$（$21$）、$3\times3$ 拐弯路径（$31$）、$1\times1$（$100$）、$1\times4$ 单行（$19$）四组数据手算与程序输出一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2958 [USACO09OCT] Papaya Jungle G
// 纯模拟：吃光当前格（置零），走向四邻中未吃木瓜最多的格子，直到 (R,C)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{45};
constexpr int dx[4]{-1,1,0,0},dy[4]{0,0,-1,1};

int r,c,a[mxn][mxn],ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>r>>c;
	for(int i=0;i<r;++i)
		for(int j=0;j<c;++j)
			cin>>a[i][j];
	int x=0,y=0;
	while(true)
	{
		ans+=a[x][y];
		a[x][y]=0;		// 吃光即置零，重访不再贡献
		if(x==r-1&&y==c-1)
			break;
		int bx=-1,by=-1,best=-1;
		for(int d=0;d<4;++d)
		{
			int nx=x+dx[d],ny=y+dy[d];
			if(nx<0||nx>=r||ny<0||ny>=c)
				continue;
			if(a[nx][ny]>best)
				best=a[nx][ny],bx=nx,by=ny;
		}
		x=bx;y=by;		// 题目保证最大值唯一且过程终于 (R,C)
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **一份状态两用**：`a[x][y]` 既是"望远镜读数"（选方向时比较），又是"待结算的食用量"（进入时累加）。吃光立刻置零，两件事天然同步，不需要 `vis` 数组。
- `best=-1`：$a$ 值非负，任何合法邻格都能更新它；合法数据保证当前格至少有一个邻格（引理 2 情形 B/C 的分析），`bx,by` 不会保持 $-1$。
- 严格 `>` 扫描在平局时取先扫到的方向，但合法数据无平局（题目保证唯一），扫描顺序不影响结果。
- 先吃、再判终点、后移动：终点 $(R,C)$ 的木瓜在 `break` 前已计入；$1\times1$ 时第一轮就 `break`，答案 $F_{11}$。
- 由引理 2/3，循环至多 $RC$ 轮，不需要额外的步数保险丝。
