# P2758 编辑距离 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给两个只含小写字母的字符串 $A,B$（$1\le |A|,|B|\le 2000$），每次操作可以**删除**一个字符、**插入**一个字符、或把某个字符**替换**成另一个字符，求把 $A$ 变成 $B$ 的最少操作次数。

$2000\times2000=4\times10^6$，这个规模几乎明示了 $O(|A||B|)$ 的二维 DP。但我不想直接背转移方程——先试试贪心，看看它是怎么失败的，失败的原因恰好就是状态设计的来源。

**第一次尝试：尽量保留原字符。** 删除和插入都不改变"保留下来的字符"，所以直觉是：保留 $A,B$ 的最长公共子序列（LCS），其余的删掉、补上。若只有删除和插入两种操作，这确实是最优的（答案 $=|A|+|B|-2\,\mathrm{LCS}$）。但本题有**替换**：$A=\texttt{a},B=\texttt{b}$ 时 LCS 为空，删+插要 $2$ 步，而直接替换只要 $1$ 步。贪心失败，原因是它把"一个字符变成另一个字符"拆成了两次操作，忽略了第三种操作的存在。

**第二次尝试：从左到右逐位对齐，不同就替换。** 这个贪心尊重了替换，但忽略了"插入/删除会造成错位"：$A=\texttt{abc},B=\texttt{yabc}$，逐位比较得 $\texttt{a}\to\texttt{y},\texttt{b}\to\texttt{a},\texttt{c}\to\texttt{b}$ 三次替换，末尾再插一个 $\texttt{c}$，共 $4$ 步；而最优解是在开头插入 $\texttt{y}$，只要 $1$ 步。贪心又失败，原因是它强行让"第 $k$ 个位置对第 $k$ 个位置"，不允许字符整体平移。

**两次失败合起来指向一个结构：每个原字符有三种命运，每个目标字符有两种来源。** 把两次贪心的教训拼起来：

- $A$ 的每个字符要么被**删除**，要么**存活**到最终串（存活期间可能被替换过）；
- $B$ 的每个字符要么来自某个存活的原字符，要么是被**插入**的；
- 关键性质：三种操作都**不会打乱已有字符的相对顺序**（删除是抽走、替换是原地改、插入是塞缝），所以"存活原字符"与"它们对应的 $B$ 字符"的配对必然**保序**。

这正是"对齐"（alignment）的定义：把 $A,B$ 上下排成两行，允许塞空位，每列要么上下配对、要么上字符对空位（删）、要么空位对下字符（插）。于是"最少操作数"被归约成"最小代价对齐"，而对齐是纯粹的静态组合对象，可以干净地做 DP：**看最后一列**。最后一列只有三种可能（删 $A$ 末字符 / 插 $B$ 末字符 / $A,B$ 末字符配对），去掉它就落到一个更小的子问题。这就是转移方程。

**边界与细节。**

1. $dp[i][0]=i$（全删），$dp[0][j]=j$（全插）。这两条边界必须显式写。
2. 配对列的代价是 $[A_{i-1}\ne B_{j-1}]$：相同免费（匹配），不同一次替换。**不要**把替换拆成删+插（那是 $2$，会算出偏大的答案——第一次贪心的错误换个形式又回来了）。
3. 题面说"只有一个正整数"，但 $A=B$ 时答案是 $0$。措辞不严谨，按真实最小值输出即可，不要强行 $+1$ 或特判。
4. 空间：$2005^2$ 个 `int` 约 $16$ MB，能过；滚动数组可压到 $O(|B|)$，但全表更直观，且本题不需要输出方案，两者皆可。我选全表。
5. 本题**所有状态都可达**（任何前缀对都能互变），不存在"不可达填 INF"的问题——全局数组默认 $0$ 在这里无害，但边界仍要显式赋值，否则第 $0$ 行/列会被当成 $0$。

**手算核对。**

- $\texttt{kitten}\to\texttt{sitting}$：对齐 $(\texttt{k},\texttt{s}),(\texttt{i},\texttt{i}),(\texttt{t},\texttt{t}),(\texttt{t},\texttt{t}),(\texttt{e},\texttt{i}),(\texttt{n},\texttt{n}),(-,\texttt{g})$，两个错配列 + 一个插入列 $=3$。
- $\texttt{abc}\to\texttt{yabc}$：$(-,\texttt{y}),(\texttt{a},\texttt{a}),(\texttt{b},\texttt{b}),(\texttt{c},\texttt{c})$，代价 $1$（逐位贪心的反例，DP 给出正确值）。
- $\texttt{a}\to\texttt{b}$：$(\texttt{a},\texttt{b})$，代价 $1$（LCS 贪心的反例）。
- $\texttt{ab}\to\texttt{ba}$：两个错配列，代价 $2$（删+插也是 $2$，殊途同归）。
- $\texttt{abcde}\to\texttt{bcdef}$：删 $\texttt{a}$、插 $\texttt{f}$，代价 $2$（整体平移，逐位贪心会算成 $5$）。

程序对这 $10$ 组手算数据全部吻合。

## 二、思维链：完整证明

**记号。** $A=a_0a_1\dots a_{n-1}$，$B=b_0b_1\dots b_{m-1}$；$A_i$ 表示 $A$ 的长度为 $i$ 的前缀（$A_0$ 为空串），$B_j$ 同理。操作模型：对当前串 $S$，$\mathrm{del}(p)$ 删除位置 $p$ 的字符，$\mathrm{ins}(p,c)$ 在位置 $p$ 前插入字符 $c$（$p=|S|$ 表示追加到末尾），$\mathrm{rep}(p,c)$ 把位置 $p$ 的字符改为 $c$。**脚本**是操作的有限序列，代价为操作个数；$d(i,j)$ 为把 $A_i$ 变成 $B_j$ 的最小代价（脚本存在：全删再全插，故最小值良定义）。

**定义（对齐）。** 串 $X,Y$ 的一个**对齐**是若干列的序列，每列形如 $(x,y)$、$(x,-)$、$(-,y)$，其中 $x$ 是 $X$ 的字符、$y$ 是 $Y$ 的字符、$-$ 是空位，满足：按顺序读出所有列的第一分量中的非空位字符，恰为 $X$；第二分量同理恰为 $Y$。对齐的代价 $c=\#(x,-)+\#(-,y)+\#\{(x,y):x\ne y\}$。记 $M(i,j)$ 为 $(A_i,B_j)$ 的最小对齐代价。

---

### 引理 1（脚本 $\Rightarrow$ 对齐，代价不增）

任何把 $A_i$ 变成 $B_j$、代价为 $k$ 的脚本，都对应一个代价 $\le k$ 的 $(A_i,B_j)$ 对齐。从而 $M(i,j)\le d(i,j)$。

*证明*：给字符打上"token"标记追踪：初始时 $A_i$ 的每个字符是一个**原 token**；$\mathrm{ins}$ 产生一个**插入 token**；$\mathrm{del}$ 移除一个 token；$\mathrm{rep}$ 原地修改 token 的字符。三种操作都**不改变已有 token 的相对顺序**（删除是抽走、替换是原地改、插入是在缝隙里加新 token），这是贯穿全证明的不变量。

脚本结束时 token 序列恰好拼出 $B_j$。把原 token 分类：

- **被删除的原 token**：每个至多被删一次（删掉就不存在了），设共 $D$ 个；
- **存活到结束的原 token**：由不变量，它们按原始相对顺序出现在最终序列中，占据 $B_j$ 中一组**严格递增**的位置。

$B_j$ 的每个位置恰被一个 token 占据：要么是存活原 token，要么是存活到结束的插入 token。据此构造对齐：按 $B_j$ 的位置从左到右扫描，该位置的 token 若是存活原 token（原字符 $a$、终字符 $b$）则放列 $(a,b)$，若是插入 token（终字符 $b$）则放列 $(-,b)$；再把每个被删除原 token 的列 $(a,-)$ 按其原始顺序插回到第一分量序列中对应的位置。这个"归并"是良定义的：存活原 token 在"原 token 原始顺序"与"$B_j$ 位置顺序"两个全序中都是保序嵌入，两个序列沿公共子序列归并唯一确定。构造结果的第一分量按序读恰为 $A_i$（存活+被删原 token 各就各位），第二分量恰为 $B_j$ ✓。

代价核算：

- $\#(x,-)=D\le$ 脚本中 $\mathrm{del}$ 的个数（每次 $\mathrm{del}$ 恰删一个 token；被删的插入 token 不产生列，只让不等式更松）；
- $\#(-,y)=$ 存活插入 token 数 $\le$ 脚本中 $\mathrm{ins}$ 的个数（中途被删的插入 token 不产生列）；
- 每个错配列 $(a,b),a\ne b$ 对应一个存活原 token 的终字符 $\ne$ 原字符，它至少被 $\mathrm{rep}$ 过一次，故 $\#$错配列 $\le$ 脚本中 $\mathrm{rep}$ 的个数（同一 token 被替换多次只算一列，不等式更松）。

三者相加 $\le \#\mathrm{del}+\#\mathrm{ins}+\#\mathrm{rep}=k$。证毕。

---

### 引理 2（对齐 $\Rightarrow$ 脚本，代价相等）

任何代价为 $c$ 的 $(A_i,B_j)$ 对齐，都对应一个代价恰为 $c$ 的脚本。从而 $d(i,j)\le M(i,j)$。

*证明*：从左到右逐列执行，维护不变量：**当前串 = （已"输出"的 $B$ 前缀）+（尚未被任何列覆盖的原 $A$ 字符，按原顺序、带原字符）**。初始时输出前缀为空、未覆盖部分为整个 $A_i$，不变量成立。设已输出 $t$ 个 $B$ 字符，则下一个未覆盖原字符（若存在）恰在位置 $t$。

- 列 $(a,-)$：由第一分量的顺序，$a$ 正是下一个未覆盖原字符，位于位置 $t$。执行 $\mathrm{del}(t)$：它被移除，输出前缀不变，不变量保持。
- 列 $(-,b)$：执行 $\mathrm{ins}(t,b)$：输出前缀增长为 $B$ 的下一个字符（由第二分量顺序），未覆盖部分不变，不变量保持。
- 列 $(a,b)$：$a$ 在位置 $t$。若 $a\ne b$ 执行 $\mathrm{rep}(t,b)$（$a=b$ 则不操作）；随后把该字符计入"已输出"（它现在等于 $B$ 的下一个字符），不变量保持。

所有列处理完后，原字符全部被覆盖、$B$ 字符全部输出，当前串 $=B_j$。操作次数 $=\#(x,-)+\#(-,y)+\#$错配列 $=c$（匹配列不操作）。证毕。

**定理 A**：$d(i,j)=M(i,j)$。由引理 1、2 双向夹逼即得。**这一步把"动态的操作序列"归约成了"静态的对齐对象"**——操作的位置、顺序等一切动态细节都被证明无关紧要，只剩下"谁删、谁插、谁配谁"。

---

### 引理 3（边界）

$M(i,0)=i$，$M(0,j)=j$。

*证明*：$(A_i,\varepsilon)$ 的对齐中第二分量全为空位，故每列都是 $(a,-)$，第一分量要读出 $i$ 个字符，恰 $i$ 列，代价 $i$；这样的对齐存在（全删列）。故 $M(i,0)=i$。对称地 $M(0,j)=j$。证毕。

---

### 引理 4（最后一列分解，核心转移）

对 $i,j\ge1$：
$$M(i,j)=\min\bigl(M(i-1,j)+1,\ M(i,j-1)+1,\ M(i-1,j-1)+[a_{i-1}\ne b_{j-1}]\bigr).$$

*证明*：分两个方向。

**（$\ge$）** 任取 $(A_i,B_j)$ 的一个对齐，代价 $c$。看它的**最后一列**：第一分量若非空位，必为 $a_{i-1}$（它是第一分量读出的最后一个字符）；第二分量若非空位，必为 $b_{j-1}$。最后一列至少有一个非空位分量，故只有三种可能：

1. $(a_{i-1},-)$：去掉最后一列，剩余列的第一分量读出 $A_{i-1}$、第二分量仍读出 $B_j$，是 $(A_{i-1},B_j)$ 的合法对齐，代价 $c-1$。故 $c-1\ge M(i-1,j)$，即 $c\ge M(i-1,j)+1$。
2. $(-,b_{j-1})$：同理 $c\ge M(i,j-1)+1$。
3. $(a_{i-1},b_{j-1})$：去掉后是 $(A_{i-1},B_{j-1})$ 的对齐，代价 $c-[a_{i-1}\ne b_{j-1}]$，故 $c\ge M(i-1,j-1)+[a_{i-1}\ne b_{j-1}]$。

三种情形穷尽，故 $c\ge$ 三项之 $\min$；对最优对齐取等号方向得 $M(i,j)\ge\min$。

**（$\le$）** 反向构造：取 $(A_{i-1},B_j)$ 的最优对齐（代价 $M(i-1,j)$），末尾追加列 $(a_{i-1},-)$：第一分量变为读出 $A_i$（$a_{i-1}$ 接在最后 ✓），第二分量不变 ✓，是合法对齐，代价 $+1$。故 $M(i,j)\le M(i-1,j)+1$。同理追加 $(-,b_{j-1})$ 得 $M(i,j)\le M(i,j-1)+1$；追加 $(a_{i-1},b_{j-1})$ 得 $M(i,j)\le M(i-1,j-1)+[a_{i-1}\ne b_{j-1}]$。三者取 $\min$ 即 $M(i,j)\le\min$。

双向夹逼得等式。证毕。

**注**：情形 1 允许 $b_{j-1}$ 出现在更早的列里（最后一列第二分量是空位），情形 2 允许 $a_{i-1}$ 更早被删——分解不要求"两个末字符互相配对"，这正是逐位贪心（强行末位对末位之外的位置也对齐）所缺失的自由度。

---

### 引理 5（DP 正确性）

按 $dp[i][0]=i$、$dp[0][j]=j$、$dp[i][j]=\min(dp[i-1][j]+1,\ dp[i][j-1]+1,\ dp[i-1][j-1]+[a_{i-1}\ne b_{j-1}])$ 计算，则对所有 $0\le i\le n,0\le j\le m$ 有 $dp[i][j]=M(i,j)=d(i,j)$。

*证明*：对 $i+j$ 归纳。$i=0$ 或 $j=0$ 时由引理 3 与边界初始化直接成立。设 $i+j=s$ 时对所有更小和成立；$i,j\ge1$ 时三个依赖 $(i-1,j),(i,j-1),(i-1,j-1)$ 的坐标和都 $<s$，由归纳假设分别等于对应的 $M$，代入引理 4 的等式即得 $dp[i][j]=M(i,j)$。再由定理 A 等于 $d(i,j)$。特别地，程序输出 $dp[n][m]=d(n,m)$ 正是题目所求。证毕。

---

### 引理 6（值域、状态可达性与复杂度）

(a) $0\le dp[i][j]\le\max(i,j)\le2000$，`int` 安全；(b) 每个状态 $(i,j)$ 都可达，不存在需要填 INF 的"不可达"格子；(c) 时间 $O(nm)$，空间 $O(nm)$（全表约 $16$ MB），可用滚动数组降到 $O(m)$。

*证明*：(a) 下界：代价是非负计数。上界：把 $A_i$ 变成 $B_j$ 可以"前 $\min(i,j)$ 位逐位替换（不同才换）+ 多退少补"，代价 $\le\min(i,j)+|i-j|=\max(i,j)$；故 $dp[i][j]\le\max(i,j)\le2000$，远小于 `int` 上限。(b) 全删再全插的脚本对任何 $(i,j)$ 存在，故 $d(i,j)$ 有限，所有格子都有定义——全局数组默认 $0$ 不会把"不可达"误当可达（但第 $0$ 行/列的正确值非零，仍须显式初始化）。(c) 状态数 $(n+1)(m+1)\le2001^2\approx4.0\times10^6$，每个状态一次三项 $\min$，$O(1)$；故时间 $O(nm)$。全表 `int dp[2005][2005]` 占 $2005^2\times4\approx16.1$ MB。滚动数组合法性：计算第 $i$ 行只依赖第 $i-1$ 行与本行左侧，两行缓冲即可，空间 $O(m)$；本题不要求输出方案，两种实现等价，题解采用全表。证毕。

---

### 定理

程序输出把 $A$ 变成 $B$ 的最少操作次数，时间 $O(|A||B|)$，空间 $O(|A||B|)$。

*证明*：引理 1、2 建立"脚本 = 对齐"的保代价归约（定理 A）；引理 3、4 给出对齐代价的完整边界与转移；引理 5 保证 DP 逐格等于真实最小值；引理 6 保证值域与复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 三种操作都是"局部"的：删除抽走、替换原地改、插入塞缝，都不打乱已有字符的相对顺序。
- **consider easier version** — 贪心一"尽量保留原字符"（LCS+删插）被 $\texttt{a}\to\texttt{b}$ 反例击破（忽略替换）；贪心二"逐位不同就替换"被 $\texttt{abc}\to\texttt{yabc}$ 反例击破（忽略错位）。
- **reduce to easier problem** — 每个原字符三种命运（删/存活/存活且被换）、每个目标字符两种来源（原字符/插入），保序配对 ⇒ 操作序列归约为静态"对齐"，且双向保代价（引理 1、2）。
- **classic problem solution** — 对齐按最后一列分解 ⇒ 三项前缀 DP：$dp[i][j]=\min(dp[i-1][j]+1,dp[i][j-1]+1,dp[i-1][j-1]+[a_{i-1}\ne b_{j-1}])$，$O(nm)$。
- **discuss by category** — 边界全删/全插显式初始化；相同串答案 $0$（题面"正整数"措辞不严谨）；全表 $16$ MB 与滚动数组 $O(m)$ 的取舍。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `a`,`b` | 输入串 $A,B$ | `string`，读入 | 内部字符下标 0-based |
| `n`,`m` | $\lvert A\rvert,\lvert B\rvert\le2000$ | `int` | `a.size()`,`b.size()` |
| `dp[i][j]` | $A$ 的前 $i$ 个字符 $\to$ $B$ 的前 $j$ 个字符的最少操作数 | `int[mxn][mxn]` | "前缀长度"下标，$i,j$ 从 $0$ 起 |
| `dp[i][0]` | 全删 | 显式置 $i$ | 边界，勿依赖默认 $0$ |
| `dp[0][j]` | 全插 | 显式置 $j$ | 边界 |
| `mxn` | $2000+5$ | `constexpr int{2005}` | +5 松弛 |
| `a[i-1]`,`b[j-1]` | 第 $i$/第 $j$ 个字符 | — | 长度下标 $\to$ 字符下标减 $1$ |

### 算法步骤

1. I/O 加速三行；读入 `a,b`，记 `n,m`。
2. 初始化边界：`dp[i][0]=i`（$i=0..n$），`dp[0][j]=j`（$j=0..m$）。
3. 外层 `i=1..n`、内层 `j=1..m`：`dp[i][j]=min({dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1]+(a[i-1]!=b[j-1])})`（删 / 插 / 替换或匹配，引理 4）。
4. 输出 `dp[n][m]`。

### 复杂度

- 时间：$O(nm)\le4.0\times10^6$ 次 $O(1)$ 转移。
- 空间：$O(nm)$，`2005*2005` 的 `int` 约 $16$ MB（滚动数组可降至 $O(m)$，本题不必）。
- 值域：$dp\le\max(n,m)\le2000$，`int` 安全；无不可达状态，无需 INF。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；$10$ 组手算数据（kitten→sitting=3、intention→execution=5、horse→ros=3、abc→adc=1、a→b=1、ab→ba=2、abc→abc=0、a→abcd=3、abcd→ab=2、abcde→bcdef=2）全部吻合，其中两组正是第一节两个贪心反例。经典 DP，证明已闭合，不做对拍。

```cpp
// 题目：P2758 编辑距离
// dp[i][j]：A 的前 i 个字符变成 B 的前 j 个字符的最少操作数
// dp[i][j]=min(dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1]+(a[i-1]!=b[j-1]))
//          删 A 末尾     插入 B 末尾     替换/匹配末尾
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005};

int n,m,dp[mxn][mxn];
string a,b;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b;
	n=a.size();m=b.size();
	for(int i=0;i<=n;++i)
		dp[i][0]=i;	// 全删
	for(int j=0;j<=m;++j)
		dp[0][j]=j;	// 全插
	for(int i=1;i<=n;++i)
		for(int j=1;j<=m;++j)
			dp[i][j]=min({dp[i-1][j]+1,dp[i][j-1]+1,dp[i-1][j-1]+(a[i-1]!=b[j-1])});
	cout<<dp[n][m]<<'\n';
	return 0;
}
```

### 代码说明

- **下标语义**：`dp` 用"前缀长度"作下标（$0$ 表示空前缀），字符用 `a[i-1]`、`b[j-1]` 取——长度下标与字符下标差 $1$，这是本题最容易写错的一处。
- **三项转移一个都不能少**：少了替换项就退化成 LCS 型删插距离（$\texttt{a}\to\texttt{b}$ 会算成 $2$）；把替换写成 `+2`（删+插）同样错。匹配时 `a[i-1]!=b[j-1]` 为 `false`（$0$），自动免费。
- **边界显式写**：`dp[i][0]=i`、`dp[0][j]=j`。全局数组默认 $0$，若不初始化，第 $0$ 行/列会被当成"空串互变零代价"，整张表全错。本题所有状态可达，不需要 INF 哨兵。
- `min({...})` 是 C++11 的 `initializer_list` 版本，三项一次取最小，比嵌套 `min` 少键击。
- 全表 $16$ MB 在限制内；若卡空间，把 `dp` 换成两行滚动（`dp[2][mxn]`，行号 `i&1`），转移不变。
- 答案可能为 $0$（$A=B$），直接输出 `dp[n][m]`，不要被题面"正整数"误导。
