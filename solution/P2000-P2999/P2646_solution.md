# P2646 数数zzy — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给一行仅含小写字母的字符串 $s$（$1\le|s|\le10^6$），统计其中等于 `zzy` 的**子序列**个数（**注意是子序列而非子串**）。答案不超过 $2^{63}-1$。

**第一步：先把"子序列"和"子串"分清。** 这是全题第一个、也是最致命的阅读点。子串要求**连续**，子序列只要求**下标递增**、可以跳着选。所以 `zzy` 的一个出现就是三个下标 $i<j<k$ 满足 $s_i=\texttt z,\ s_j=\texttt z,\ s_k=\texttt y$，中间夹别的字母无所谓。

举个例子立刻看清差别：$s=\texttt{zzzy}$。

- 作为**子串**，`zzy` 只出现 $1$ 次（下标 $1,2,3$）；
- 作为**子序列**，`zzy` 出现 $3$ 次：从三个 `z`（下标 $0,1,2$）里任选两个、再配末尾的 `y`，$\binom32=3$。

再如 $s=\texttt{z x z y}$（`zxzy`），子串 `zzy` 出现 $0$ 次，但子序列出现 $1$ 次（下标 $0,2,3$）。**如果按子串做，答案会严重偏小。** 我特意把这两个例子记下来当校验。

**第二步：暴力为什么不行。** 直接枚举所有三元组 $(i,j,k)$ 判是否 `zzy`，$O(|s|^3)$。$|s|=10^6$ 时约 $10^{18}$ 次，宇宙毁灭都跑不完。哪怕优化到"枚举 `y`，再数它前面 `zz` 对数"也要 $O(|s|^2)$，$10^{12}$ 仍超时。必须 $O(|s|)$。

**第三步：归约到经典的"定长子序列计数 DP"。** 统计一个**固定模式串**（这里 `zzy`，长度 3）作为子序列的出现次数，有个标准套路：边扫边维护"已匹配到模式各前缀"的方案数。模式 `zzy` 的前缀有 `z`、`zz`、`zzy`，于是维护三个计数器：

- $c_z$：当前已扫前缀里，子序列 `z` 的个数（就是已见过的 `z` 字符数）；
- $c_{zz}$：已扫前缀里，子序列 `zz` 的个数；
- $c_{zzy}$：已扫前缀里，子序列 `zzy` 的个数（最终答案）。

从左到右扫每个字符 $c$：

- 若 $c=\texttt y$：它能接在**任何已有的 `zz`** 后面凑成 `zzy`，故 $c_{zzy}\mathrel{+}=c_{zz}$；
- 若 $c=\texttt z$：它既能接在**任何已有的 `z`** 后面凑成 `zz`（$c_{zz}\mathrel{+}=c_z$），它自己又是一个新的 `z`（$c_z\mathrel{+}=1$）；
- 其它字母：与模式无关，跳过。

**第四步：本题真正的坑——更新顺序。** 处理 `z` 时，$c_{zz}\mathrel{+}=c_z$ 必须用**自增前**的旧 $c_z$，然后才 $c_z\mathrel{+}=1$。为什么？新来的这个 `z` 只能和**它前面**的 `z` 配对成 `zz`，不能和它自己配。若先 $c_z\mathrel{+}=1$ 再 $c_{zz}\mathrel{+}=c_z$，就把"自己和自己"也算进去了，每个 `z` 多算 $1$ 个 `zz`，答案全错。

我用 $s=\texttt{zz}$ 验证这个坑：正确应是 $c_{zz}=1$（下标 $0,1$ 一对）、$c_{zzy}=0$。

- 正确顺序：第一个 `z`：$c_{zz}\mathrel{+}=0$，$c_z=1$；第二个 `z`：$c_{zz}\mathrel{+}=1\Rightarrow c_{zz}=1$，$c_z=2$。✓
- 错误顺序（先自增）：第一个 `z`：$c_z=1$，$c_{zz}\mathrel{+}=1\Rightarrow1$；第二个 `z`：$c_z=2$，$c_{zz}\mathrel{+}=2\Rightarrow3$。✗（把自配对算进去了）

所以代码里务必先 `czz+=cz;` 再 `++cz;`。

**第五步：溢出与类型。** 答案 $\le2^{63}-1$，必须 64 位。三个计数器都要 `long long`：

- $c_z\le|s|\le10^6$；
- $c_{zz}\le\binom{|s|}2\approx5\times10^{11}$（即使全是 `z`）；
- $c_{zzy}\le$ 答案 $\le2^{63}-1$，且它单调递增到最终值，中途不会超过最终值。

实际上 $|s|=10^6$ 时 `zzy` 子序列数的最大值约 $7.4\times10^{16}$（把 `z` 全放前、`y` 全放后，约 $\frac23|s|$ 个 `z` 时取到），远小于 $2^{63}-1$，但既然题目给了 $2^{63}-1$ 的上界，就老老实实用 `i64`，`int` 必炸。

**手造数据核对**（题面无样例）：

| 输入 | 分析 | 输出 |
|---|---|---|
| `zzzy` | $\binom32\times1=3$ | $3$ |
| `zzy` | 恰好一个 | $1$ |
| `zyz` | `y` 在第二个 `z` 前，凑不出 `zzy` | $0$ |
| `zz` | 没有 `y` | $0$ |
| `zzyzzy` | 第一个 `y` 前 $\binom22=1$，第二个 `y` 前 $\binom42=6$，共 $7$ | $7$ |
| `zzzzyy` | 两个 `y` 各配 $\binom42=6$，共 $12$ | $12$ |

## 二、思维链：完整证明

**记号。** $s=s_0s_1\dots s_{L-1}$，$L=|s|$。模式 $P=\texttt{zzy}$。一个**出现**指下标三元组 $(i,j,k)$，$0\le i<j<k\le L-1$ 且 $s_i=\texttt z,s_j=\texttt z,s_k=\texttt y$。记 $\mathrm{Ans}$ 为出现总数。

对前缀 $s[0..t]$（含 $t$），定义：
- $Z(t)=\#\{i\le t:s_i=\texttt z\}$（前缀里 `z` 的个数，即子序列 `z` 的出现数）；
- $D(t)=\#\{(i,j):i<j\le t,\ s_i=s_j=\texttt z\}$（子序列 `zz` 的出现数）；
- $T(t)=\#\{(i,j,k):i<j<k\le t,\ s_i=s_j=\texttt z,s_k=\texttt y\}$（子序列 `zzy` 的出现数）。

代码的 $c_z,c_{zz},c_{zzy}$ 声称在处理完下标 $t$ 后分别等于 $Z(t),D(t),T(t)$。

---

### 引理 1（子序列出现 = 递增下标三元组）

`zzy` 作为子序列的出现与满足 $i<j<k$、$s_i=s_j=\texttt z$、$s_k=\texttt y$ 的三元组一一对应；故 $\mathrm{Ans}=T(L-1)$。

*证明*：子序列的定义是从原串中按下标递增顺序选出若干字符（可不连续）拼成的串。选出的字符拼成 `zzy` 当且仅当选了三个下标 $i<j<k$ 且对应字符依次为 `z`,`z`,`y`。每个这样的三元组唯一确定一个出现，每个出现唯一确定一个三元组，故一一对应。$\mathrm{Ans}$ 是整串的出现数 $=T(L-1)$。证毕。

**对比子串**：子串额外要求 $j=i+1,k=j+1$（连续），是三元组的一个真子集，故子串计数 $\le$ 子序列计数，一般严格小于（如 `zzzy`：$1<3$）。本题要子序列。

---

### 引理 2（DP 不变量）

代码从左到右处理每个下标 $t$ 后，$c_z=Z(t)$、$c_{zz}=D(t)$、$c_{zzy}=T(t)$。

*证明*：对 $t$ 归纳。

**基例**：处理前（$t=-1$，空前缀）$c_z=c_{zz}=c_{zzy}=0$（全局默认），而 $Z(-1)=D(-1)=T(-1)=0$（空集无出现），成立。

**归纳步**：设处理完 $t-1$ 后三计数器等于 $Z(t-1),D(t-1),T(t-1)$。考察下标 $t$ 的字符 $s_t$，分三类（与代码分支一致）：

1. **$s_t=\texttt y$**：代码 `czzy+=czz`，即 $c_{zzy}\leftarrow T(t-1)+D(t-1)$，$c_z,c_{zz}$ 不变。需证 $Z(t)=Z(t-1)$、$D(t)=D(t-1)$、$T(t)=T(t-1)+D(t-1)$。
   - $Z,D$ 只数 `z`，$s_t=\texttt y$ 不新增 `z`，故 $Z(t)=Z(t-1)$、$D(t)=D(t-1)$。✓
   - $T(t)$ 比 $T(t-1)$ 多出的出现，恰是那些**以 $t$ 为末位**（$k=t$）的 `zzy`。这样的出现需要 $i<j<t$ 且 $s_i=s_j=\texttt z$，即前缀 $t-1$ 里的一个 `zz` 出现，个数 $=D(t-1)$。每个 `zz` 出现 $(i,j)$ 配上 $k=t$ 唯一确定一个新 `zzy` 出现，反之亦然。故 $T(t)=T(t-1)+D(t-1)$。✓
2. **$s_t=\texttt z$**：代码先 `czz+=cz`（用旧 $c_z=Z(t-1)$）再 `++cz`，即 $c_{zz}\leftarrow D(t-1)+Z(t-1)$、$c_z\leftarrow Z(t-1)+1$，$c_{zzy}$ 不变。需证 $Z(t)=Z(t-1)+1$、$D(t)=D(t-1)+Z(t-1)$、$T(t)=T(t-1)$。
   - $s_t=\texttt z$ 新增一个 `z`，$Z(t)=Z(t-1)+1$。✓
   - $D(t)$ 比 $D(t-1)$ 多出的出现，恰是以 $t$ 为末位（$j=t$）的 `zz`：需 $i<t$ 且 $s_i=\texttt z$，个数 $=Z(t-1)$。故 $D(t)=D(t-1)+Z(t-1)$。**这里必须用旧的 $Z(t-1)$**：$i<t$ 严格小于，不含 $t$ 自己。✓
   - $T$ 只数以 `y` 结尾的出现，$s_t=\texttt z$ 不能作为末位 `y`，故 $T(t)=T(t-1)$。✓
3. **其它字母**：代码不动任何计数器。$s_t\notin\{\texttt z,\texttt y\}$ 不新增任何 `z`/`zz`/`zzy` 出现（三种模式都只含 `z`,`y`），故 $Z,D,T$ 均不变。✓

三类穷尽所有字符，归纳步成立。由归纳法，处理完每个 $t$ 后不变量成立。证毕。

---

### 引理 3（更新顺序的必要性：先 $c_{zz}\mathrel{+}=c_z$ 再 $++c_z$）

处理 `z` 时若颠倒顺序（先 `++cz` 再 `czz+=cz`），则 $c_{zz}$ 会比 $D(t)$ 多算，导致最终答案错误。

*证明*：由引理 2 情形 2，正确增量是 $D(t)=D(t-1)+Z(t-1)$，用的是**旧** $Z(t-1)$（末位 $j=t$ 的 `zz` 需要 $i<t$，不含 $t$）。若先 `++cz`，则 $c_z$ 变成 $Z(t-1)+1=Z(t)$，再 `czz+=cz` 得到 $D(t-1)+Z(t)=D(t-1)+Z(t-1)+1=D(t)+1$，**每个 `z` 字符多算 $1$**（相当于把 $(i,j)=(t,t)$ 这个非法的"自配对"计入，违反 $i<j$）。

反例 $s=\texttt{zz}$：正确 $D(1)=1$；颠倒顺序后 $c_{zz}=3$（第一个 `z` 贡献 $1$、第二个贡献 $2$），多算 $2$。进而若后面有 `y`，$c_{zzy}$ 会基于错误的 $c_{zz}$ 累加，答案偏大。故顺序不可颠倒。证毕。

**等价写法**：也可先 `++cz` 再 `czz+=cz-1`，或用一个临时量保存旧 $c_z$；但最简洁、最不易错的就是"先加后自增"。

---

### 引理 4（不重不漏：每个出现恰在其末位被计一次）

每个 `zzy` 出现 $(i,j,k)$ 恰在算法处理下标 $k$ 时被计入 $c_{zzy}$ 一次，总计 $\mathrm{Ans}$ 次。

*证明*：由引理 2 情形 1，处理 $s_k=\texttt y$ 时 $c_{zzy}$ 增加 $D(k-1)$，即前缀 $k-1$ 里所有 `zz` 出现 $(i,j)$（$i<j<k$）各配 $k$ 贡献 $1$。出现 $(i,j,k)$ 的末位是 $k$，故恰在处理 $k$ 时被计一次。处理其它下标 $t\ne k$ 时：若 $s_t=\texttt z$ 则 $c_{zzy}$ 不变（情形 2）；若 $s_t=\texttt y$ 但 $t\ne k$，新增的是末位为 $t$ 的出现，与末位为 $k$ 的出现不同（末位下标不同）。故 $(i,j,k)$ 不会被重复计，也不会在别处被计。所有出现按末位下标划分，互不重叠，总和 $=T(L-1)=\mathrm{Ans}$。证毕。

---

### 引理 5（值域与溢出安全）

$c_z\le L\le10^6$；$c_{zz}\le\binom L2<5\times10^{11}$；$c_{zzy}\le\mathrm{Ans}\le2^{63}-1$，且单调递增故中途不超最终值。三者用 `i64=long long` 均安全。

*证明*：
- $c_z=Z(t)\le t+1\le L\le10^6$。
- $c_{zz}=D(t)=\binom{Z(t)}2\le\binom L2=\frac{L(L-1)}2\le\frac{10^6\times(10^6-1)}2=499999500000<5\times10^{11}$，远小于 $2^{63}-1\approx9.22\times10^{18}$。
- $c_{zzy}=T(t)$ 随 $t$ 单调不减（每次 `y` 只增不减），故 $T(t)\le T(L-1)=\mathrm{Ans}\le2^{63}-1$（题面保证）。中途值不超最终值，不溢出。

`long long` 范围 $[-2^{63},2^{63}-1]$，三个计数器都非负且 $\le2^{63}-1$，加法 `czzy+=czz` 的结果 $\le\mathrm{Ans}\le2^{63}-1$，不溢出。`int`（$\le2.1\times10^9$）连 $c_{zz}$ 都装不下，必炸，故必须 `i64`。证毕。

**附（$L=10^6$ 时答案的真实上界）**：要最大化 `zzy` 出现数，应把所有 `z` 放前、所有 `y` 放后（这样每对 `z` 都先于每个 `y`）。设 $k$ 个 `z`、$L-k$ 个 `y`，出现数 $=\binom k2(L-k)$。对 $k$ 求极值约在 $k=\frac23L$ 处，代入 $L=10^6$ 得约 $7.4\times10^{16}$，确实 $<2^{63}-1$。题面给的 $2^{63}-1$ 是宽松上界，但用 `i64` 万无一失。

---

### 引理 6（复杂度）

时间 $O(L)$，空间 $O(L)$（存输入串）；若流式读入可做到额外空间 $O(1)$。

*证明*：每个字符被处理一次，每次 $O(1)$（常数次比较与加法），合计 $O(L)$。代码用全局 `char s[mxn]` 存整串，$O(L)$ 空间；三个 `i64` 计数器 $O(1)$。$L=10^6$ 时实测约 $0.06$ s。证毕。

---

### 定理

程序输出 $c_{zzy}=T(L-1)=\mathrm{Ans}$，即 $s$ 中 `zzy` 子序列的个数；时间 $O(L)$，空间 $O(L)$。

*证明*：引理 1 把题意化为 $T(L-1)$；引理 2 证明三计数器维护正确不变量；引理 3 证明更新顺序不可颠倒；引理 4 证明不重不漏；引理 5 证明 `i64` 安全；引理 6 给出复杂度。处理完整串后 $c_{zzy}=T(L-1)=\mathrm{Ans}$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 子序列 $\ne$ 子串：`zzy` 出现 = 递增下标三元组 $(i<j<k)$，可跳选；`zzzy` 子序列 $3$ 个而子串仅 $1$ 个。
- **consider easier version** — 暴力枚举三元组 $O(L^3)=10^{18}$、枚举 `y` 数前面 `zz` 对 $O(L^2)=10^{12}$ 都超时，必须 $O(L)$。
- **classic problem solution** — 定长模式子序列计数 DP：维护匹配到各前缀的方案数 $c_z,c_{zz},c_{zzy}$，边扫边转移。
- **explore its property** — 更新顺序坑：处理 `z` 必须先 `czz+=cz`（旧值）再 `++cz`，否则把自配对算进去，每个 `z` 多算 $1$。
- **discuss by category** — 字符分三类（`y` 接 `zz`、`z` 接 `z` 且自成新 `z`、其它跳过）；溢出用 `i64`（$c_{zz}$ 可达 $5\times10^{11}$，答案 $\le2^{63}-1$）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `s` | 输入串（仅小写字母，$\le10^6$） | `char[mxn]`，`cin>>s` | 0-based，以 `\0` 结尾 |
| `mxn` | $10^6+5$ | `constexpr int{1000005}` | +5 松弛 |
| `cz` | 已扫前缀中子序列 `z` 的个数 $Z(t)$ | `i64`，全局默认 $0$ | 就是已见 `z` 字符数 |
| `czz` | 已扫前缀中子序列 `zz` 的个数 $D(t)$ | `i64`，全局默认 $0$ | "zz 对数" |
| `czzy` | 已扫前缀中子序列 `zzy` 的个数 $T(t)$ | `i64`，全局默认 $0$ | 最终答案 |

### 算法步骤

1. I/O 加速三行。
2. `cin>>s` 读入整串。
3. 从左到右扫 `s[i]` 直到 `\0`：
   - 若 `s[i]=='y'`：`czzy+=czz`；
   - 否则若 `s[i]=='z'`：**先** `czz+=cz`，**再** `++cz`；
   - 其它字符：跳过。
4. 输出 `czzy` 与 `'\n'`。

### 复杂度

- 时间：$O(L)$，$L=10^6$ 时实测约 $0.06$ s。
- 空间：$O(L)$，`char s[mxn]` 约 $1$ MB + 三个 `i64`。
- 值域：$c_{zz}\le5\times10^{11}$、$c_{zzy}\le2^{63}-1$，`i64` 安全（引理 5）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；6 组手造数据（`zzzy`→3、`zzy`→1、`zyz`→0、`zz`→0、`zzyzzy`→7、`zzzzyy`→12）逐条吻合；与 $O(L^3)$ 暴力枚举三元组对拍 $200000$ 组随机小串（$L\le12$，刻意偏向 `z`/`y` 制造命中），$0$ mismatch；$L=10^6$ 最大计数布局（$666667$ 个 `z` + $333333$ 个 `y`）输出 $74073962962962963$，与解析值 $\binom{666667}2\times333333$ 一致，运行 $0.06$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2646 数数zzy
// 思路：统计子序列(非子串) zzy 的个数 = 递增下标三元组 i<j<k 且 s_i=s_j='z',s_k='y'。
//       定长模式子序列计数 DP：维护 cz/czz/czzy = 已扫前缀里 z/zz/zzy 的出现数。
//       遇 'y'：czzy+=czz；遇 'z'：先 czz+=cz(旧值) 再 ++cz；其它跳过。
//       答案可达 2^63-1，全程 i64。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1000005};

char s[mxn];
i64 cz,czz,czzy;	// 已扫前缀中 "z" / "zz" / "zzy" 子序列的个数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	for(int i=0;s[i];++i)
	{
		if(s[i]=='y')
			czzy+=czz;	// 每个已有 zz 接上这个 y 成一个 zzy
		else if(s[i]=='z')
		{
			czz+=cz;	// 先用旧的 cz 与新 z 配对（i<j，不含自己）
			++cz;		// 再把这个 z 计入单字符前缀
		}
	}
	cout<<czzy<<'\n';
	return 0;
}
```

### 代码说明

- **三个计数器就是模式 `zzy` 的三个前缀**：`cz`↔`z`、`czz`↔`zz`、`czzy`↔`zzy`。每来一个字符，看它能延长哪些前缀（引理 2）。
- **顺序是命门**：`czz+=cz;` 必须在 `++cz;` 之前。新 `z` 只能和它**前面**的 `z` 配对，用旧 `cz` 才不含自己；颠倒会每个 `z` 多算一个 `zz`（引理 3）。
- **`y` 只动 `czzy`，`z` 只动 `czz`/`cz`**：因为 `y` 不能当 `z`/`zz` 的字符，`z` 不能当 `zzy` 的末位 `y`，分支互不干扰。
- **其它字母直接跳过**：模式只含 `z`,`y`，别的字符对三个计数器都无贡献。
- **全程 `i64`**：`czz` 可达 $\binom{10^6}2\approx5\times10^{11}$、答案可达 $2^{63}-1$，`int` 必溢出（引理 5）。全局 `i64` 默认 $0$ 正是空前缀的初值。
- `char s[mxn]` + `cin>>s`：串仅含小写字母无空格，一次读入整串；`for(...;s[i];...)` 扫到 `\0` 止，$O(L)$。
