# P2694 接金币 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 二维平面上有 $n$ 个金币（$n\le50$），第 $i$ 个初始在 $(x_i,y_i)$，$-10^3\le x_i\le10^3$，$0\le y_i\le10^3$。所有金币每秒竖直下落 $1$ 单位，故 $t$ 秒后第 $i$ 个在 $(x_i,\ y_i-t)$。FJ 初始在 $(0,0)$，**只能左右移动**（每秒至多 $1$ 单位，也可不动），所以他的纵坐标恒为 $0$。某时刻金币与 FJ 位置重合就接住。问能否接住**全部**金币，能输出 `Abletocatch`，否则 `Notabletocatch`。共 $g\le5$ 组数据。题面无样例，下面的例子都是我手算的。

**第一步：金币什么时候、在哪里能被接住？** FJ 在 $(p(t),0)$，金币 $i$ 在 $(x_i,y_i-t)$。重合要求纵坐标相等：$y_i-t=0\Rightarrow t=y_i$；此时横坐标也要相等：$p(y_i)=x_i$。

**这是全题的支点**：金币 $i$ **只能在时刻 $y_i$、位置 $x_i$ 被接住**，早一秒晚一秒都不行（早了金币还在天上，晚了已经落地穿过 $y=0$ 继续下落——题目只说下落，落地后 $y<0$ 就再也碰不到 $y=0$ 的 FJ 了）。于是"接住所有金币"被精确翻译成：

> FJ 必须在时刻 $y_i$ 恰好站在 $x_i$，对每个 $i$ 都成立。

**第二步：把"接金币"归约成"按时到达路标"。** 现在问题与金币无关了，只剩一个运动学问题：FJ 从 $(0,0)$（时刻 $0$）出发，速度 $\le1$，能否依次在时刻 $y_i$ 到达 $x_i$？由于每个时刻是**固定**的，访问顺序被 $y_i$ 唯一确定——**按 $y$ 升序**就是必须遵守的时间表。

**第三步：两点之间什么时候可达？** FJ 在时刻 $t_1$ 位于 $p_1$，要在时刻 $t_2\ge t_1$ 位于 $p_2$。他每秒至多走 $1$，所以 $t_2-t_1$ 秒内位移至多 $t_2-t_1$，必要条件是 $|p_2-p_1|\le t_2-t_1$。反过来，若 $|p_2-p_1|\le t_2-t_1$，他可以朝 $p_2$ 每秒走 $1$、走 $|p_2-p_1|$ 秒到达，然后原地等剩下的时间——**充分**。注意"可以不动"这条很关键：它消掉了奇偶性限制（若只能走不能停，$p_2-p_1$ 与 $t_2-t_1$ 还得同奇偶，本题不需要）。

**第四步：排序 + 相邻检查。** 把金币按 $(y,x)$ 升序排序，记排序后为 $(x_1,y_1),\dots,(x_n,y_n)$，并虚拟一个起点 $(x_0,y_0)=(0,0)$。可行 $\iff$ 对每个 $i$ 都有
$$|x_i-x_{i-1}|\le y_i-y_{i-1}.$$
必要性：任何可行路径在相邻两个路标之间都满足第三步的可达条件。充分性：若每段都可达，就把各段"直走 + 等待"的路径首尾拼接，得到一条全程合法的路径，在每个 $y_i$ 恰好站在 $x_i$。**一条链，逐段检查即可**，不需要任何搜索或 DP。

**第五步：几个必须想清楚的边界。**

1. **同一时刻多个金币。** 若 $y_i=y_{i+1}$ 而 $x_i\ne x_{i+1}$，则 $\Delta y=0$、$|\Delta x|>0$，检查失败——FJ 不可能同时站在两处，正确判 `Notabletocatch`。若 $x$ 也相同，$\Delta x=0$，通过（一次接住两个）。按 $(y,x)$ 排序后同时刻金币相邻，逐对检查就能捕获冲突。
2. **$y_i=0$ 的金币。** 它一开始就在地上，FJ 时刻 $0$ 在 $0$，所以必须 $x_i=0$ 才接得住。检查 $|x_i-0|\le0-0$ 即 $x_i=0$，自动处理。
3. **负坐标。** $x_i$ 可为负，$|x_i-x_{i-1}|$ 用绝对值，向左走同样每秒 $1$，无特殊。
4. **第一个金币从原点出发。** 虚拟起点 $(0,0)$ 让"第一段"与后续段用同一个公式，不必特判。

**手造数据核对：**

| 输入（$g=1$） | 手算 | 程序 |
|---|---|---|
| $n=2$：$(0,1),(1,2)$ | $\|0\|\le1$、$\|1-0\|\le2-1$ ⇒ Able | Abletocatch |
| $n=2$：$(2,1),(0,2)$ | $\|2\|\le1$ 假 ⇒ Not | Notabletocatch |
| $n=2$：$(1,1),(-1,1)$ | 同时刻不同位置 ⇒ Not | Notabletocatch |
| $n=1$：$(0,0)$ | $\|0\|\le0$ ⇒ Able | Abletocatch |
| $n=1$：$(1,0)$ | $\|1\|\le0$ 假 ⇒ Not | Notabletocatch |

另测 $g=2$、两组之间夹空行（题面 tips 说组间有换行），`cin>>` 按空白切分自动跳过，输出两行正确。

## 二、思维链：完整证明

**记号。** 金币 $i$ 初始 $(x_i,y_i)$，$t$ 秒后在 $(x_i,y_i-t)$。FJ 位置 $(p(t),0)$，$p(0)=0$，$|p(t+1)-p(t)|\le1$（每秒至多移动 $1$，可停）。按 $(y,x)$ 升序排序后记 $(x_1,y_1),\dots,(x_n,y_n)$，$y_1\le\dots\le y_n$；虚拟起点 $(x_0,y_0)=(0,0)$。

---

### 引理 1（接住时刻与位置被唯一确定）

金币 $i$ 能被接住 $\iff$ 存在时刻 $t$ 使 $p(t)=x_i$ 且 $y_i-t=0$，即 $t=y_i$ 且 $p(y_i)=x_i$。

*证明*：重合定义为两坐标分别相等。纵坐标：FJ 恒在 $y=0$（只左右移动），金币在 $y_i-t$，故 $y_i-t=0\Rightarrow t=y_i$（唯一）。横坐标：$p(t)=x_i$。代入 $t=y_i$ 得 $p(y_i)=x_i$。反之若 $p(y_i)=x_i$，则时刻 $y_i$ 两者都在 $(x_i,0)$，重合，接住。

**唯一性**：$t=y_i$ 是唯一解，故每个金币的接住时刻**固定**，FJ 没有"提前/延后接"的自由。这把原问题彻底化为定点定时访问。证毕。

---

### 引理 2（单段可达的充要条件）

设 $t_2\ge t_1$。FJ 能从 $(p_1,t_1)$ 移动到 $(p_2,t_2)$ $\iff|p_2-p_1|\le t_2-t_1$。

*证明*：**必要（$\Rightarrow$）**：每秒位移 $\le1$，故 $t_2-t_1$ 秒内总位移 $\le t_2-t_1$，即 $|p_2-p_1|\le t_2-t_1$（三角不等式逐秒累加）。

**充分（$\Leftarrow$）**：设 $d=|p_2-p_1|\le t_2-t_1$。构造路径：前 $d$ 秒每秒朝 $p_2$ 方向走 $1$（若 $p_2>p_1$ 向右，反之向左），到达 $p_2$；剩余 $t_2-t_1-d\ge0$ 秒原地不动。每步位移 $\in\{-1,0,1\}$，合法；终点 $p_2$、时刻 $t_2$，符合要求。"可以不动"保证等待合法，也消掉了奇偶约束。证毕。

**注**：若题目改成"每秒必须走 $1$、不能停"，则还需 $p_2-p_1\equiv t_2-t_1\pmod2$；本题明确"也可以不移动"，故无此约束。

---

### 引理 3（全链可行的充要条件）

存在接住全部金币的合法路径 $\iff$ 对所有 $i=1..n$ 有 $|x_i-x_{i-1}|\le y_i-y_{i-1}$（$(x_0,y_0)=(0,0)$）。

*证明*：**必要**：设路径合法。由引理 1，FJ 在时刻 $y_{i-1}$ 位于 $x_{i-1}$、时刻 $y_i$ 位于 $x_i$（$i=1$ 时 $y_0=0,x_0=0$ 是出发点）。因 $y_i\ge y_{i-1}$（排序保证），由引理 2 得 $|x_i-x_{i-1}|\le y_i-y_{i-1}$。

**充分**：设所有不等式成立。逐段构造：第 $i$ 段从 $(x_{i-1},y_{i-1})$ 到 $(x_i,y_i)$，由引理 2（取 $p_1=x_{i-1},t_1=y_{i-1},p_2=x_i,t_2=y_i$，条件恰为 $|x_i-x_{i-1}|\le y_i-y_{i-1}$）可行。把 $n$ 段路径首尾拼接：第 $i$ 段终点 $(x_i,y_i)$ 正是第 $i+1$ 段起点，时刻连续、位置连续，拼接后仍合法。由引理 1，FJ 在每个 $y_i$ 站在 $x_i$，接住全部金币。证毕。

**推论（算法）**：排序后令 `px=py=0`，顺序扫描，若某段 `abs(x-px)>y-py` 则不可行；否则更新 `px=x,py=y`。全部通过则可行。这正是充分性构造的逐段验证。

---

### 引理 4（同时刻冲突与 $y=0$ 边界被检查自动覆盖）

(a) 若两金币 $y$ 相同、$x$ 不同，则检查必失败；(b) $y_i=0$ 的金币可接 $\iff x_i=0$。

*证明*：(a) 按 $(y,x)$ 排序后，同 $y$ 的金币相邻。设相邻两枚 $y_i=y_{i+1}$、$x_i\ne x_{i+1}$，则第 $i+1$ 段检查 $|x_{i+1}-x_i|\le y_{i+1}-y_i=0$，左边 $>0$，失败。反之若同 $y$ 的金币 $x$ 全相同，则每段 $|\Delta x|=0\le0$ 通过（一次接住多枚）。故"同时刻不同位置"被精确判为不可行。

(b) $y_i=0$ 时，若它是排序后第一枚，检查 $|x_i-0|\le0-0\iff x_i=0$；若前面还有 $y=0$ 的金币，则 $x$ 必全为 $0$（否则 (a) 已失败），同样要求 $x_i=0$。与引理 1（时刻 $0$ FJ 在 $0$）一致。证毕。

---

### 定理（正确性与复杂度）

程序对每组数据输出 `Abletocatch` $\iff$ 存在接住全部金币的合法路径；单组时间 $O(n\log n)$，空间 $O(n)$。

*证明*：引理 1 把"接金币"化为定点定时访问；引理 2 给出单段可达充要条件；引理 3 把全链可行化为相邻检查，并证明排序扫描算法恰好验证它；引理 4 保证同时刻冲突与 $y=0$ 边界自动正确。复杂度：排序 $O(n\log n)$，扫描 $O(n)$，$g\le5$ 组共 $O(gn\log n)$；存 $n$ 个金币 $O(n)$。$n\le50$，远低于限制。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 金币只在 $t=y_i$ 落到 $y=0$，故接住时刻与位置被唯一钉死为 $(x_i,y_i)$。
- **reduce to easier problem** — "接住全部"归约为"从 $(0,0)$ 出发、速度 $\le1$、按时 $y_i$ 到达 $x_i$"的定点访问问题。
- **classic problem solution** — 按时间排序 + 相邻可达检查 $|\Delta x|\le\Delta t$；"可停"消掉奇偶约束，直走+等待给出充分性。
- **discuss by category** — 同时刻不同位置必败、$y=0$ 需 $x=0$、负坐标用绝对值；虚拟起点 $(0,0)$ 统一第一段。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `g` | 数据组数，$\le5$ | `int`，读入 | 外层循环 |
| `n` | 当前组金币数，$\le50$ | `int`，读入 | 每组重置 |
| `a[i]` | 第 $i$ 个金币 `{x,y}` | `struct coin[mxn]` | 排序前读入 |
| `mxn` | $50+5=55$ | `constexpr int` | +5 松弛 |
| `px,py` | 上一个路标的位置/时刻（初始原点） | `int`，初值 $0$ | "p = previous" |
| `ok` | 当前组是否可行 | `bool`，初值 `true` | 任一段失败置 `false` |
| 排序键 | 先 $y$ 升序、再 $x$ 升序 | lambda | 时间表顺序 |

### 算法步骤

1. I/O 加速三行；读 `g`。
2. 每组：读 `n` 与 `n` 个 `{x,y}`；按 `(y,x)` 升序排序。
3. 令 `px=py=0, ok=true`；顺序扫描每个金币：若 `abs(a[i].x-px)>a[i].y-py` 则 `ok=false` 并 `break`；否则 `px=a[i].x, py=a[i].y`。
4. 输出 `ok?"Abletocatch\n":"Notabletocatch\n"`。

### 复杂度

- 时间：单组 $O(n\log n)$（排序主导），$g\le5$ 组共 $O(gn\log n)$；$n\le50$ 极小。
- 空间：$O(n)$，一个 `coin[55]`。
- 验证状态：`g++ -std=c++20 -O2 -Wall -Wextra` 编译通过；题面无样例，手造 $5$ 组（可达 / 首段超速 / 同时刻冲突 / $y=0$ 原点 / $y=0$ 非原点）与手算逐一吻合；另测 $g=2$ 组间夹空行，`cin>>` 正确跳过空白输出两行。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2694 接金币
// 思路：金币 i 只在 t=y_i 落到 y=0，故必须时刻 y_i 站在 x_i。
//       按 (y,x) 排序，从 (0,0) 起逐段检查 |Δx|≤Δy（速度≤1，可停⇒无奇偶约束）。
//       同时刻不同位置 / y=0 非原点 都被该检查自动判否。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{55};

struct coin{int x,y;}a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int g;
	cin>>g;
	while(g--)
	{
		int n;
		cin>>n;
		for(int i=0;i<n;++i)
			cin>>a[i].x>>a[i].y;
		sort(a,a+n,[](coin p,coin q){return p.y!=q.y?p.y<q.y:p.x<q.x;});
		int px=0,py=0;	// 虚拟起点 (0,0)
		bool ok=true;
		for(int i=0;i<n;++i)
		{
			if(abs(a[i].x-px)>a[i].y-py)	// 该段超速 ⇒ 不可行
			{
				ok=false;
				break;
			}
			px=a[i].x;
			py=a[i].y;
		}
		cout<<(ok?"Abletocatch\n":"Notabletocatch\n");
	}
	return 0;
}
```

### 代码说明

- **排序键 `(y,x)`**：先按接住时刻 $y$ 升序（时间表），同时刻再按 $x$ 升序，使同 $y$ 金币相邻、冲突被相邻检查捕获。
- **`px=py=0` 虚拟起点**：让第一段与后续段共用 `abs(x-px)<=y-py`，不必特判"从原点出发"。
- **`abs` 处理负坐标**：$x_i\in[-10^3,10^3]$，向左走同样每秒 $1$，绝对值统一。
- **`y-py` 非负**：排序保证 $y$ 升序，`py` 是上一枚的 $y$，故 $\Delta y\ge0$，不会把"时间倒流"误判为可达。
- **可停 ⇒ 无奇偶约束**：题面"也可以不移动"，所以只需 $|\Delta x|\le\Delta y$，无需同奇偶；若改成必须移动则要加 parity 判断。
- `mxn{55}` 是 $50+5$ 松弛；多测间 `a` 被新读入覆盖，无需清空。
