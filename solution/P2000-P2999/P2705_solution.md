# P2705 小球 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $R$ 个红盒子、$B$ 个蓝盒子，$R$ 个红球、$B$ 个蓝球（$1\le R,B\le100$）。每个盒子恰好装一个球，每个球都要装进盒子。红球进红盒得 $C$ 分，蓝球进蓝盒得 $D$ 分，异色相配（无论哪种）都得 $E$ 分（$-1000\le C,D,E\le1000$，**可以是负数**）。求最大总得分。入门题，但"入门"不等于可以想当然——这题的贪心直觉全是坑。

**第一步：从最小情形入手。** $R=B=1$：一共两个球两个盒，只有两种放法——同色配（红进红、蓝进蓝）得 $C+D$；交叉配（红进蓝、蓝进红）得 $2E$。答案 $\max(C+D,2E)$。比如 $C=D=1,E=100$ 时交叉配得 $200$，远胜同色配的 $2$。

**第二步：贪心直觉碰壁。** 顺着"同色配是常态"的直觉，容易写出贪心："先把每个球放进同色盒子，放不下再异色"。反例立刻打脸：$C=D=1,E=100,R=B=1$，贪心给出 $2$，最优是 $200$。另一个方向的坑是**负分**：$C=D=E=-1000$ 时所有放法都得 $-2000$，但球**必须**全部放完，不能"负分就不放"——答案可以是负数，任何"跳过负收益"的贪心都非法。两次碰壁说明：不能按球逐个决策，得先弄清**一种放置方案到底由什么决定**。

**第三步：探性质——异色放置必然成对。** 设 $x=$ 放进蓝盒子的红球数。数一数守恒关系：

- 蓝盒子共 $B$ 个，被 $x$ 个红球占了，剩下 $B-x$ 个装蓝球；
- 蓝球共 $B$ 个，$B-x$ 个在蓝盒里，剩下 $x$ 个**只能在红盒里**；
- 红盒子共 $R$ 个：$R-x$ 个红球 $+x$ 个蓝球，恰好 $R$，自洽 ✓。

所以"红球进蓝盒"与"蓝球进红盒"的数量**永远相等**，都是 $x$——异色放置天生一对一对出现，不可能只发生一半。整个方案被唯一的自由度 $x$ 完全刻画：$x$ 对交叉、$R-x$ 个红红配、$B-x$ 个蓝蓝配。$x$ 的范围：非负，且 $R-x\ge0$、$B-x\ge0$，即 $0\le x\le\min(R,B)$。

**第四步：把总分写成 $x$ 的函数。**

$$\mathrm{Score}(x)=(R-x)C+(B-x)D+xE+xE=RC+BD+x\,(2E-C-D).$$

**这是关于 $x$ 的一次函数！** 记 $\Delta=2E-C-D$（每多凑一对交叉的净收益：赚 $2E$，赔掉一个 $C$ 和一个 $D$）。一次函数在闭区间上的最大值必在端点：

- $\Delta>0$：$x$ 越大越好，取 $x=\min(R,B)$，能交叉多少对就交叉多少对；
- $\Delta<0$：$x$ 越小越好，取 $x=0$，全部同色配；
- $\Delta=0$：怎么放都一样，得分恒为 $RC+BD$。

于是 $\text{ans}=RC+BD+\max\bigl(0,\ \min(R,B)\cdot\Delta\bigr)$，一行公式。

**换个角度验证（交换论证）**：从全同色配（$x=0$）出发，每次把"一个红红配 $+$ 一个蓝蓝配"改成"一对交叉"，得分变化恰为 $\Delta$，**与已经换了多少对无关**（边际收益恒定，没有递减）。所以要么一对都不换（$\Delta\le0$），要么换到不能换为止（$\Delta>0$，上限 $\min(R,B)$ 对）。中间状态永远不严格优于两个端点——这和一次函数的结论互相印证。

**第五步：值域与实现。** 总球数 $R+B\le200$，每球得分 $\in[-1000,1000]$，故 $|\text{ans}|\le2\times10^5$；中间量 $RC+BD\le2\times10^5$、$\min(R,B)\cdot\Delta\le100\times4000=4\times10^5$，`int` 绰绰有余。读五个数、套公式、输出，$O(1)$。

**手造数据核对**（题面无样例，全部手算）：

| 输入 `R B C D E` | 输出 | 打的点 |
|---|---|---|
| `1 1 1 1 2` | $4$ | $\Delta=2>0$，交叉优于同色 |
| `2 3 5 4 1` | $22$ | $\Delta=-7<0$，全同色：$10+12$ |
| `1 1 -5 -5 0` | $0$ | 负分但交叉能救回：$-10+10$ |
| `1 1 -1000 -1000 -1000` | $-2000$ | 全负，必须放完，答案为负 |
| `3 1 10 10 20` | $60$ | $R\ne B$：$x$ 上限 $\min=1$，$40+20$ |
| `2 2 3 7 5` | $20$ | $\Delta=0$，怎么放都是 $6+14$ |
| `100 100 1000 1000 1000` | $200000$ | 上界：$200$ 球各 $1000$ |
| `100 100 -1000 -1000 1000` | $200000$ | $\Delta=4000$，全交叉把 $-200000$ 翻成 $+200000$ |
| `100 100 -1000 -1000 -1000` | $-200000$ | 下界 |

程序输出与手算逐条一致。

## 二、思维链：完整证明

**记号。** 球集合：$R$ 个红球、$B$ 个蓝球；盒子集合：$R$ 个红盒、$B$ 个蓝盒。**放置方案** = 球到盒子的双射（每盒恰一球、每球必入盒，两边总数都是 $R+B$，双射存在）。对方案 $\pi$，记四个计数：$a=$ 红球入红盒数，$b=$ 蓝球入蓝盒数，$c=$ 红球入蓝盒数，$d=$ 蓝球入红盒数。得分 $\mathrm{Score}(\pi)=aC+bD+(c+d)E$。令 $x=c$。$\Delta=2E-C-D$，$m=\min(R,B)$。

---

### 引理 1（守恒：异色成对，自由度唯一）

对任何方案 $\pi$：$a=R-x$，$b=B-x$，$d=x$，且 $x$ 是整数、$0\le x\le m$。反之，对任何整数 $x\in[0,m]$，存在方案实现它。故方案按得分分类后与 $[0,m]\cap\mathbb Z$ 一一对应。

*证明*：**必要性**（计数守恒）。红球共 $R$ 个，分入红盒 $a$ 个、蓝盒 $c=x$ 个，故 $a+x=R$，$a=R-x$。蓝盒共 $B$ 个，装红球 $x$ 个、蓝球 $b$ 个，故 $x+b=B$，$b=B-x$。蓝球共 $B$ 个，分入蓝盒 $b=B-x$ 个、红盒 $d$ 个，故 $d=B-b=B-(B-x)=x$。红盒容量核对：$a+d=(R-x)+x=R$ ✓（与红盒总数一致，无矛盾）。非负性：$a,b,c,d\ge0$ 给出 $x\ge0$、$x\le R$、$x\le B$，即 $0\le x\le\min(R,B)=m$。$x$ 是计数，必为整数。

**充分性**（构造）。给定整数 $x\in[0,m]$：把 $R-x$ 个红球放入红盒、$x$ 个红球放入蓝盒；把 $B-x$ 个蓝球放入蓝盒、$x$ 个蓝球放入红盒。红盒占用 $(R-x)+x=R$ ✓，蓝盒占用 $x+(B-x)=B$ ✓，红球用尽 $(R-x)+x=R$ ✓，蓝球用尽 $(B-x)+x=B$ ✓。所有数量非负（$x\le m\le R,B$），故这是一个合法双射，且其 $c=x$。

两方向合起来：可行 $x$ 集恰为 $[0,m]\cap\mathbb Z$，且由必要性，**同一 $x$ 的所有方案四个计数完全相同、得分相同**——具体哪个球进哪个盒不影响得分，自由度只有 $x$。证毕。

**这条引理是全题的支点**：它把"指数级多的双射"压缩成"至多 $101$ 个整数 $x$"，而且压缩是**无损**的（得分只依赖 $x$）。"异色成对"不是巧合，是两边球数与盒数按颜色分别相等（红球=红盒=$R$，蓝球=蓝盒=$B$）的必然推论。

---

### 引理 2（得分是 $x$ 的一次函数）

$\mathrm{Score}(x)=(R-x)C+(B-x)D+2xE=RC+BD+x\Delta$，其中 $\Delta=2E-C-D$。

*证明*：由引理 1，$a=R-x$，$b=B-x$，$c=d=x$。代入得分定义：
$$\mathrm{Score}=aC+bD+(c+d)E=(R-x)C+(B-x)D+(x+x)E.$$
展开：$RC-xC+BD-xD+2xE=RC+BD+x(2E-C-D)=RC+BD+x\Delta$。每一步是分配律与合并同类项，恒等变形。证毕。

**$\Delta$ 的组合意义**：把一对"红红配 $+$ 蓝蓝配"（贡献 $C+D$）替换成一对交叉（贡献 $2E$），得分变化 $2E-(C+D)=\Delta$。这正是交换论证里的边际收益。

---

### 引理 3（一次函数在整数闭区间上的最大值在端点）

$\max_{x\in[0,m]\cap\mathbb Z}\mathrm{Score}(x)=RC+BD+\max(0,m\Delta)$。且最优 $x$ 可显式给出：$\Delta>0$ 取 $x=m$；$\Delta<0$ 取 $x=0$；$\Delta=0$ 任意 $x$。

*证明*：常数项 $RC+BD$ 与 $x$ 无关，只需最大化 $f(x)=x\Delta$。按 $\Delta$ 符号分三类（穷尽）：

- **$\Delta>0$**：对任意 $x\in[0,m]$，$f(x)=x\Delta\le m\Delta=f(m)$（不等式两边乘正数 $\Delta$ 保序，$x\le m$）。最大值 $m\Delta>0$，在 $x=m$ 取到。
- **$\Delta<0$**：对任意 $x\in[0,m]$，$x\ge0$ 乘负数 $\Delta$ 得 $f(x)=x\Delta\le0=f(0)$。最大值 $0$，在 $x=0$ 取到。
- **$\Delta=0$**：$f(x)\equiv0$，最大值 $0$，处处取到。

三类合并：$\max f=\max(0,m\Delta)$（$\Delta>0$ 时 $m\Delta>0$ 取前者，$\Delta\le0$ 时 $m\Delta\le0$ 取 $0$）。加上常数项即得公式。

**交换论证的第二证明**（不依赖一次函数理论）：从 $x=0$ 出发，任何方案都可经 $x$ 次"把一对同色配改成一对交叉"的交换到达（引理 1 的构造保证每步中间状态合法：$x'<m$ 时红盒有红球 $R-x'>0$、蓝盒有蓝球 $B-x'>0$，可各取一个互换）。每次交换得分变化恰为 $\Delta$（引理 2），与历史无关。若 $\Delta\le0$，任何交换都不增分，$x=0$ 最优；若 $\Delta>0$，每次交换严格增分，换到 $x=m$ 不能再换为止最优。两条路线结论一致。证毕。

---

### 引理 4（值域与 `int` 安全）

$|\text{ans}|\le(R+B)\times1000\le2\times10^5$；公式的所有中间量绝对值 $\le6\times10^5$，`int` 安全。

*证明*：最终得分是 $R+B\le200$ 个球的得分之和，每球得分 $\in\{C,D,E\}\subseteq[-1000,1000]$，故 $|\text{ans}|\le200\times1000=2\times10^5$。中间量：$|RC|\le100\times1000=10^5$，$|BD|\le10^5$；$|\Delta|=|2E-C-D|\le2\times1000+1000+1000=4000$，$|m\Delta|\le100\times4000=4\times10^5$；$\max(0,m\Delta)\in[0,4\times10^5]$；总和绝对值 $\le2\times10^5+4\times10^5=6\times10^5\ll2^{31}-1\approx2.1\times10^9$。所有运算在 `int` 内精确，无溢出。证毕。

**注意答案为负是合法输出**：$C=D=E=-1000$ 时任何方案都得 $-(R+B)\times1000$，公式给出 $RC+BD+\max(0,m\cdot0)=-1000(R+B)$ ✓。"最大化"不等于"非负"，球必须全部放完（引理 1 的双射定义），没有"放弃放置"的选项。

---

### 定理

程序输出 $RC+BD+\max(0,\min(R,B)(2E-C-D))$，等于最大总得分；时间 $O(1)$，空间 $O(1)$。

*证明*：引理 1 把全部方案无损压缩到整数 $x\in[0,m]$；引理 2 给出得分关于 $x$ 的精确表达式；引理 3 求出该表达式在可行域上的最大值及取到方式；引理 4 保证 `int` 实现无溢出。程序逐字实现该公式，读入五个数、常数次算术、一次输出，时间与空间均 $O(1)$。证毕。

## 三、模式总结（按实际思考顺序）

- **consider easier version** — $R=B=1$ 只有两种放法：$\max(C+D,2E)$，先看清"同色 vs 交叉"的基本权衡。
- **explore its property** — "先同色后异色"贪心被 $C=D=1,E=100$ 反例打掉；负分数据禁止"不放"，答案可为负。
- **explore its property** — 计数守恒：红球=红盒、蓝球=蓝盒 $\Rightarrow$ 异色放置必然成对，方案由唯一自由度 $x\in[0,\min(R,B)]$ 完全刻画。
- **reduce to easier problem** — 总分 $=RC+BD+x(2E-C-D)$，组合优化塌缩成一次函数求最值。
- **classic problem solution** — 一次函数在闭区间端点取最值；交换论证印证：每对交叉的边际收益恒为 $\Delta$，要么全换要么不换。
- **discuss by category** — $\Delta>0/\Delta<0/\Delta=0$ 三类；$R\ne B$ 时上限是 $\min$；值域 $|\text{ans}|\le2\times10^5$，`int` 足够。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `R,B` | 红 / 蓝的盒子数（也是同色球数），$\le100$ | `int`，读入 | 球数=盒数按颜色分别相等 |
| `C,D,E` | 红红 / 蓝蓝 / 异色单球得分，$\in[-1000,1000]$ | `int`，读入 | 可为负 |
| `gain` | $\Delta=2E-C-D$，每对交叉的净收益 | `int`，现算 | "换一对赚多少" |
| $x$（推导用，代码不出现） | 红球入蓝盒数 = 蓝球入红盒数 | $[0,\min(R,B)]$ 整数 | 异色成对，唯一自由度 |
| `min(R,B)` | $x$ 的上限 $m$ | 现算 | 少数色决定交叉对数上限 |
| `ans`（表达式） | $RC+BD+\max(0,m\Delta)$ | `int` | 全同色得分 + 最优交叉增益 |

### 算法步骤

1. I/O 加速三行；读入 `R,B,C,D,E`。
2. `gain=2*E-C-D`。
3. 输出 `R*C+B*D+max(0,min(R,B)*gain)` 与 `'\n'`（引理 3：$\Delta>0$ 时全交叉，否则全同色）。

### 复杂度

- 时间：$O(1)$，常数次算术。
- 空间：$O(1)$，五个输入变量加一个中间量。
- 验证状态：`g++ -std=c++20 -O2 -Wall -Wextra` 编译零警告；$11$ 组手造数据（含 $\Delta$ 三种符号、$R\ne B$、全负分、上下界 $200000/-200000$）与手算逐条一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2705 小球
// 设 x=红球放蓝盒的个数，守恒 ⇒ 蓝球放红盒也恰是 x 个
// 得分=RC+BD+x(2E-C-D)，关于 x 线性 ⇒ 端点最优
#include<bits/stdc++.h>
using namespace std;

int R,B,C,D,E;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>R>>B>>C>>D>>E;
	int gain=2*E-C-D;	// 每多凑一对"交叉放置"的净收益
	cout<<R*C+B*D+max(0,min(R,B)*gain)<<'\n';
	return 0;
}
```

### 代码说明

- **一行公式就是全部算法**：`R*C+B*D` 是 $x=0$（全同色）的基准分；`max(0,min(R,B)*gain)` 是最优交叉增益——`gain>0` 时换满 $\min(R,B)$ 对，否则一对不换（引理 3）。
- **`min(R,B)` 而不是 `max`**：交叉对数受少数色限制，$x\le R$ 且 $x\le B$ 必须同时成立（引理 1 的非负性）。
- **不需要枚举 $x$**：虽然 $x$ 只有至多 $101$ 个取值、枚举也能过，但一次函数的端点性质让枚举成为多余——这正是"入门题也有数学结构"的体现。
- **负数天然正确**：`max(0,...)` 只截断**增益**，不截断总分；全负数据输出负数，符合"必须放完"的题意。
- **`int` 足够**：总分绝对值 $\le2\times10^5$，中间量 $\le6\times10^5$（引理 4），不需要 `long long`。
- 变量名沿用题面符号 `R,B,C,D,E`，与公式一一对应，便于核对。
