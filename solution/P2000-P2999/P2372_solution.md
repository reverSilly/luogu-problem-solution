# P2372 yyy2015c01挑战算周长 — 题解

## 一、解题过程：人类思考叙事

**重述题意。** 给一个 $M$ 行 $N$ 列的网格，每格是 `.`（空）或 `X`。把每个 `X` 看成一个完整的单位方格；两个 `X` 如果落在**八邻域**（上下左右 + 四个斜角）里，就算相邻；相邻关系传递下去，连成一片的所有 `X` 叫做一个**目标**。给一个必然落在 `X` 上的格子 $(X,Y)$，求它所在目标的周长（以单位边长为单位）。题面还保证目标里没有完全封闭的孔。

输入顺序要小心：第一行是 `M N X Y`，其中 `X` 是**行号**、`Y` 是**列号**，都从 $1$ 开始。

**第一反应：像走迷宫一样把轮廓"描"一圈。** 沿着边界走（wall-following），每走一格算一段长度。想在纸上推一下就知道这条路有多坑：要维护当前朝向、要判断"贴着走"的转向规则，还会遇到两个格子只在**对角**相碰的情形——轮廓在那个点自相接触，脚本站住的地方要特殊处理。$M,N\le20$ 虽然小，但这种状态机极易写错，而且一旦错了很难定位。**放弃描轮廓。**

**换一个角度：周长是"长度"，不是"路线"。** 周长 = 边界的总长度。既然每个 `X` 是一个单位正方形、每条边长 1，那就不必知道边界"怎么走"，只要数清"边界上有多少条单位线段"即可。这正是把几何问题换成计数问题的关键一步。

**怎么数？** 先把每个 `X` 的四条边都算进来：共 $4C$ 条（$C$ 是目标里格子的个数）。但两个格子若**共用一条边**，这条边其实在目标内部，不是边界，而它在 $4C$ 里被数了两次，所以要减掉 $2$。于是

$$\text{周长}=4C-2E,$$

其中 $E$ 是"目标内部共用一条边的格子对数"。

这里有一个必须想清楚、否则整道题都会错的细节：**斜着相碰的两个格子算不算共用边？** 不算。它们在**一个点**上接触，接触部分的长度是 $0$，既不增加也不减少周长。所以"八连通"只用来**判断哪些格子属于同一个目标**，而"减边"只能用**四邻域**（上下左右）。这两件事用的邻域不一样，混用必错：若把斜邻接也拿去减边，上例 `X.X/.X./X.X` 会算成 $20-2\times4=12$，而正确答案是 $20$。

**子问题一：哪些格子属于目标？** 从 $(X,Y)$ 出发做八方向 flood fill（BFS/DFS 都行），标记出整个连通块。这就是目标。

**子问题二：怎么数 $4C-2E$？** 最直接的办法是**逐格数它有几条边是"外面"**：对目标里的每个格子，看它的上下左右四个邻居，只要那个邻居不在目标里（越界也算不在），周长就 $+1$。把 $4C-2E$ 展开正好就是这个和（第 2 节会证明）。

**这里有一个非常容易踩的坑：什么时候数。** 如果一边 BFS 一边数"邻居是不是已访问"，就会错：某个同样在目标里的邻居可能**还没被扩展到**，于是被当成"外面"，周长偏大。比如目标是一整片 $2\times3$ 的矩形，从左上角开始 BFS，第一格出队时它的右邻、下邻都还没标记，若此时计数就会把它们当成边界。所以代码里**先把整个目标标记完，再单独扫一遍数边**。

**顺带一个让人安心的观察。** 其实"邻居在不在目标里"和"邻居是不是 `X`"是同一件事：如果某个 `X` 与目标里的格子**共用一条边**，它俩就是八邻接的，按定义必然属于同一个目标。所以第二遍扫描时用 `vis` 判断和用 `g=='X'` 判断，结果一定一样。这个等价关系是"两遍扫描"之所以安全的理论依据（正式的证明见引理 3、引理 4）。

**手造几组小数据走一遍**（题面只给了"网格 1/网格 2"的文字描述，没有给出可直接对拍的数据，所以自己造）：

1. 单个格子
```
3 3 2 2
...
.X.
...
```
目标是 1 个格子、没有共享边 ⇒ $4\times1-0=4$。

2. $2\times2$ 实心块
```
2 2 1 1
XX
XX
```
$C=4$，共用边 4 对（横 2 对 + 竖 2 对）⇒ $16-8=8$，正是边长为 2 的正方形周长。

3. 只有斜接的五格十字
```
3 3 1 1
X.X
.X.
X.X
```
四个角都只与中心点接触，同一个目标，$C=5$、$E=0$ ⇒ $20$。

4. 实心 $2\times3$
```
2 3 1 1
XXX
XXX
```
$C=6$，横向共用 4 对、竖向 3 对，$E=7$ ⇒ $24-14=10=2(2+3)$。

**关于"没有孔"这条保证。** 上面的数法把所有边界线段都数了：外轮廓算、孔的内轮廓也算。题面说不会有孔，于是"周长"只有外轮廓一种理解；即使有孔，本做法给出的也是"总边界长度"，同样自洽。这条保证只是帮我们省掉了"到底要不要算内轮廓"的争论。

## 二、思维链：完整证明

**约定**：$S$ 表示所有 `X` 格子的集合；每个格子 $u$ 用一个单位闭正方形代表，坐标取 $(r,c)\mapsto[r,r+1]\times[c,c+1]$。两个格子"四邻接"指它们的行、列坐标之差恰有一个为 $\pm1$、另一个为 $0$；"八邻接"指两者不同且两个坐标差都 $\in\{-1,0,1\}$。目标 $T$ 指 $(X,Y)$ 所在的连通块。

**引理 1（连通块是等价类，目标定义良好）**：在 $S$ 上定义 $u\sim^* v$ 当且仅当存在一列 $u=u_0,u_1,\dots,u_k=v\in S$ 使相邻两项八邻接。则 $\sim^*$ 是 $S$ 上的等价关系，从而是 $S$ 的一个划分，"$u$ 所在的目标"指 $u$ 的那个等价类。

*证明*：自反性：取 $k=0$。对称性：把序列反向。传递性：若 $u\sim^*v$ 有序列 $u_0..u_k$、$v\sim^*w$ 有序列 $v_0..v_m$，则 $u_0..u_k,v_1..v_m$ 是 $u$ 到 $w$ 的合法序列。三条都成立，故为等价关系；等价关系的等价类互不相交且并集为 $S$，故构成划分。证毕。

**引理 2（BFS 标记的恰是目标）**：从 $(X,Y)$ 出发、只沿八邻接的 `X` 扩展，被标记的格子集合恰为 $T$。

*证明*：
（标记的都 $\in T$）对 BFS 中被标记的格子 $u$ 归纳：起点 $(X,Y)$ 属于 $T$，因为 $T$ 定义为它所在的等价类而等价类含自身；若 $u$ 是由已标记的 $v$ 扩展而来，则 $v\sim u$（八邻接）且 $v\in T$，于是 $v\sim^*u$，由等价类的封闭性 $u\in T$。
（$T$ 的都被标记）设 $u\in T$，取一条从 $(X,Y)$ 到 $u$ 的八邻接链 $u_0,\dots,u_k$。对 $i$ 归纳：$u_0$ 一开始就标记；若 $u_{i-1}$ 被标记，那么它出队时一定会检查它的八邻居 $u_i$——若 $u_i$ 未标记则会被标记入队。所以 $u_i$ 终将被标记。故 $u$ 被标记。证毕。

**备注（为什么"认亲"必须是八邻接，而"减边"必须是四邻接）**：两处用的邻域不同，这是本题最容易混的地方，各举一个反例。
- 若把认亲误写成四邻接：在 `X.X/.X./X.X` 里，四个角与中心都只"共点"，没有一条共享边，于是目标被切成 5 个互不相干的部分，从中心出发只能得到 1 格、答案变成 4，而题意下它们是一个目标、答案 20。这说明"在拐角处相碰也算相邻"（题面原话："其网格方形区域在边界或拐角处是重叠的"）。
- 若把减边误写成八邻接：在同一个例子里，中心会与四个角"共边"四次，$4\times5-2\times4=12$，而正确答案是 20。这说明只有**真正共用一条边**（四邻接）的格子对才会让两条边互相抵消。

**引理 3（共用一条边的两格必同目标）**：若 $u,v\in S$ 四邻接，则 $u\sim^*v$，进而两者属于同一个目标。

*证明*：四邻接的定义中两个坐标差都 $\in\{-1,0,1\}$ 且不全为 0，故八邻接，取 $k=1$ 的链即得 $u\sim^*v$；再由引理 1，同一等价类。证毕。

**引理 4（数边时"在 $vis$ 里"与"是 X"等价）**：设 $u\in T$，$v$ 是 $u$ 的四邻居且**在网格内**。则 $v\in T\iff g[v]=\texttt{'X'}$。

*证明*：（$\Leftarrow$）$g[v]=\texttt{'X'}$ 即 $v\in S$，由引理 3 得 $v\sim^*u$，故 $v\in T$。（$\Rightarrow$）$T\subseteq S$。证毕。
推论：BFS 结束之后，对目标内格子的四邻居，判 `!vis[v]` 与判 `g[v]!='X'` 结果相同；而 BFS 过程中两者可能不同（未扩展到的同目标格子）。这就是"必须在第二遍扫描里数边"的原因。

**引理 5（周长公式）**：设目标内部四邻接的格子对数为 $E$，格子数为 $C$，则目标的边界总长度 $=\ 4C-2E$。

*证明*：考虑"带重数的单位线段族" $\mathcal M$：把 $T$ 中每个格子的 4 条边都放进去（同一条线段出现多次就记多次）。由构造，每个格子恰好贡献 4 条边，故按重数计 $|\mathcal M|=4C$。

第一步：每条网格单位线段的出现次数只可能是 $0,1,2$。理由：一条单位线段位于某条网格线上，它的两侧各至多容纳一个格子，而一个格子对这条线段的贡献至多 1 次，故总次数 $\le2$。

第二步：出现 2 次的线段与"$T$ 内四邻接的格子对"一一对应。若线段 $s$ 出现 2 次，则它两侧的格子 $u,v$ 都在 $T$ 中且共用 $s$，即 $u,v$ 四邻接，对应唯一一对；反之任一对四邻接的格子共用唯一的线段，该线段在 $\mathcal M$ 中出现 2 次。故出现 2 次的线段恰有 $E$ 条，出现 1 次的线段有 $4C-2E$ 条。

第三步：**出现 1 次的线段之并（去掉有限个端点）恰是目标的边界**。取出现 1 次的线段 $s$ 内部一点 $p$。$s$ 只有一侧被 $T$ 中的格子覆盖；另一侧紧邻的点不被 $T$ 中任何格子覆盖（否则那个格子也会贡献 $s$，使其次数为 2），所以 $p$ 的任意小邻域内既有 $T$ 的点又有补集的点，$p$ 是边界点。反之，设 $p$ 是边界点。$p$ 只有三种可能：某个格子的内部、某条网格单位线段的内部、或网格顶点。若 $p$ 在格子 $w$ 内部且 $w\notin T$，则取足够小的球落在 $w$ 内部，球与 $\bigcup T$ 不相交，$p$ 是补集内点，矛盾；若 $w\in T$，则 $p$ 是并集内点，矛盾。故 $p$ 不在任何格子内部。于是边界 $\subseteq$（出现 1 次的线段之并）$\cup$（顶点集），而后者中的线段部分正是出现 1 次的线段（出现 2 次的线段两侧都被覆盖，是内点集）。顶点只有有限个，长度（一维测度）为 $0$，不影响总长度。故边界总长度 $=$ 出现 1 次的线段条数 $=4C-2E$。证毕。

**引理 6（逐格数边等于 $4C-2E$）**：设对每个 $u\in T$ 记 $d(u)$ 为其四邻居中属于 $T$ 的个数，则 $\sum_{u\in T}\big(4-d(u)\big)=4C-2E$。

*证明*：$\sum_{u\in T}4=4C$。而 $\sum_{u\in T}d(u)$ 数的是"有序对 $(u,v)$，$u\in T$，$v$ 与 $u$ 四邻接且 $v\in T$"。四邻接是对称关系，每一对内部相邻格子 $\{u,v\}$ 恰好贡献两个有序对，故 $\sum_{u\in T}d(u)=2E$。相减即得。证毕。

**定理（算法正确）**：程序输出目标 $T$ 的周长。

*证明*：由引理 2，第一遍 BFS 标记的集合恰为 $T$，即第二遍扫描时 `vis[u]` 恒等于"$u\in T$"。于是第二遍的循环恰好遍历 $T$ 中的格子。对 $u\in T$ 的四个方向逐个看它的邻居 $v$：
- 若 $v$ 越界，代码计 1：这条边外侧根本没有格子，是并集的边界，计 1 正确。
- 若 $v$ 在网格内且 $v\notin T$，代码计 1（因为 `!vis[v]`）：这条边两侧只有 $u$ 属于 $T$，另一侧是补集，是边界，正确（引理 4 还保证此时 $v$ 连 `X` 都不是，所以这份判据与"直接看 `g`"给出同一结论）。
- 若 $v\in T$，代码不计：这条边两侧都是 $T$ 的格子，是内部共享边，正确。
所以累加值恰为 $\sum_{u\in T}\big(4-d(u)\big)$，由引理 6 等于 $4C-2E$，由引理 5 等于目标的边界总长度，即所求周长。证毕。

**复杂度**：BFS 每个格子至多入队一次、每次检查 8 个方向，$O(MN)$；第二遍扫描每格检查 4 个方向，$O(MN)$。总时间 $O(MN)$，空间 $O(MN)$（`g`、`vis`、队列）。

## 三、模式总结（按实际思考顺序）

- explore its property — 把 `X` 看成单位正方形，目标是若干单位正方形的并，"周长"就是并集边界的一维长度
- try the direct approach — 沿边界"描轮廓"（wall-following）需要维护朝向与转向规则，斜角自接触还要特判，易错且难调试，放弃
- reduce to easier problem — 不去"走"边界，改成"数"边界上的单位线段条数
- explore its property — 每条单位线段至多属于两个格子 ⇒ 周长 $=4C-2E$；斜接触只共点、长度为 0，不参与抵消
- classic problem solution — 八方向 flood fill（BFS）取出 $(X,Y)$ 所在的连通块
- explore its property（第二次） — 四邻接的 `X` 必属同一目标 ⇒ "在目标内"与"是 `X`"等价，但**只有 BFS 结束后**才等价
- handle boundaries — 数边必须在标记完成后的第二遍扫描里做（否则把未扩展的同目标邻居误判为边界）；越界的四条边都算边界；$X$ 是行、$Y$ 是列
- discuss the promise — "无孔"只是消除"外轮廓 vs 总边界"的歧义，本做法数的是总边界

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|----------------|
| $M$ | 网格行数 | `int` | 输入 |
| $N$ | 网格列数 | `int` | 输入 |
| $X$ | 脚踩格子的**行**号（1-based） | `int` | 输入后 `--X` 转 0-based |
| $Y$ | 脚踩格子的**列**号（1-based） | `int` | 输入后 `--Y` 转 0-based |
| `g[i][j]` | 第 $i$ 行第 $j$ 列的字符（`.` / `X`） | `char[25][25]` | 输入，0-based |
| `vis[i][j]` | 该格是否属于目标 $T$ | `bool[25][25]` | 全局默认 `false`，BFS 时置真 |
| `q[]` | BFS 队列，存 `x*n+y` 编码的格子 | `int[625]` | 手写头尾指针 `hd,tl` |
| `dx,dy` | 8 个方向的位移（含斜向） | `const int[8]` | 用于**认亲**（连通块） |
| `ax,ay` | 4 个方向的位移（上下左右） | `const int[4]` | 用于**数边**，两者不可混用 |
| `ans` | 边界单位线段总数 = 周长 | `int` | 初值 0（空目标无边界，无需哨兵） |

### 算法步骤

1. 读入 $M,N,X,Y$，读入 $M\times N$ 个字符；$X,Y$ 各减一。
2. 从 $(X,Y)$ 开始 BFS：出队格子 $(x,y)$，枚举 `dx/dy` 的 8 个方向，落在网格内、是 `X`、且未访问的邻居入队并标记 `vis`。
3. BFS 结束后，对每个 `vis` 为真的格子 $(i,j)$，枚举 `ax/ay` 的 4 个方向：若邻居越界或 `vis` 为假，则 `++ans`。
4. 输出 `ans`。

### 复杂度

- 时间：$O(MN)$（BFS $O(MN)$ + 数边 $O(MN)$）。
- 空间：$O(MN)$。

### 状态的一句话验证

$4C-2E$ 与"逐格数未共享的边"是同一个量的两种算法（引理 5、6），代码取后者；而"`!vis` 等价于不在目标内"这条只在 BFS 结束之后成立（引理 4），对应代码中 BFS 与计数被拆成两段循环。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2372 yyy2015c01挑战算周长
// 先从脚踩的格子出发，按 8 连通 BFS 把整个目标标记出来
// 再逐格数「四条边里对面不是同目标格子的那几条」，总和就是这个目标的周长
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};

int m,n,X,Y;
char g[mxn][mxn];
bool vis[mxn][mxn];

const int dx[8]={-1,-1,-1,0,0,1,1,1};
const int dy[8]={-1,0,1,-1,1,-1,0,1};
const int ax[4]={-1,1,0,0};
const int ay[4]={0,0,-1,1};

int q[mxn*mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n>>X>>Y;
	for(int i=0;i<m;++i)
		for(int j=0;j<n;++j)
			cin>>g[i][j];
	--X;--Y;
	int hd=0,tl=0;
	q[tl++]=X*n+Y;
	vis[X][Y]=1;
	while(hd<tl)
	{
		int u=q[hd++],x=u/n,y=u%n;
		for(int k=0;k<8;++k)
		{
			int tx=x+dx[k],ty=y+dy[k];
			if(tx<0||tx>=m||ty<0||ty>=n)continue;
			if(vis[tx][ty]||g[tx][ty]!='X')continue;
			vis[tx][ty]=1;
			q[tl++]=tx*n+ty;
		}
	}
	//目标已标记完，现在逐格数「不与任何同目标格子共享」的边
	int ans=0;
	for(int i=0;i<m;++i)
		for(int j=0;j<n;++j)
		{
			if(!vis[i][j])continue;
			for(int k=0;k<4;++k)
			{
				int ti=i+ax[k],tj=j+ay[k];
				if(ti<0||ti>=m||tj<0||tj>=n||!vis[ti][tj])
					++ans;
			}
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 两套方向数组不能合并：`dx/dy` 是 8 邻域，只用于找连通块；`ax/ay` 是 4 邻域，只用于数边。混用会把斜接触也当成"共边"，$2\times2$ 的实心块会被算成 $16-4=12$ 而不是 $8$。
- BFS 与计数分成两个独立循环，是为了避免"同目标但尚未扩展"的邻居被误计为边界（引理 4 的推论）。
- 队列开 `mxn*mxn` 足够：每个格子至多入队一次。
- 越界的四个方向直接计 1，等价于网格外是空白，符合"目标边界"的定义。
- `ans` 初值 0 即可：它是一段加法计数，不存在"不可达"的语义，因此不需要哨兵。
