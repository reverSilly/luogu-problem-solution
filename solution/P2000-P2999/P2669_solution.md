# P2669 [NOIP 2015 普及组] 金币 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 骑士领工资，发放规则是"分组"的：第 $1$ 天领 $1$ 枚；接下来 $2$ 天（第 $2,3$ 天）每天领 $2$ 枚；接下来 $3$ 天（第 $4,5,6$ 天）每天领 $3$ 枚；……一般地，**第 $n$ 组持续 $n$ 天，每天领 $n$ 枚**。问前 $k$ 天一共领了多少枚。$1\le k\le 10^4$。

**第一反应：逐天模拟，直接就能过。** 维护"当前是第几组 $n$"和"这一组已经发了几天"，每过一天就 `ans+=n`，组内天数发满就把 $n$ 加一。总共就 $k\le 10^4$ 天，$O(k)$ 次加法，随便过。所以这题本质上是个入门模拟，不需要任何高级算法。我先把这个最朴素的版本在脑子里跑通：

```
day=1: n=1, ans=1
day=2,3: n=2, ans=1+2+2=5
day=4,5,6: n=3, ans=5+3+3+3=14   ← k=6 时答案 14，和题面样例说明一致
```

**第二步：注意到"组"才是天然单位。** 逐天模拟当然对，但 $k$ 天里其实只有大约 $\sqrt{2k}$ 个组。第 $n$ 组占据的那些天，每天领的钱**都一样**（都是 $n$ 枚），所以这一整组的贡献就是 $n\times(\text{该组在前 }k\text{ 天里的天数})$，可以一步算完，不必一天一天加。

组与组的分界点是**三角形数**：记 $T_n=1+2+\dots+n=\frac{n(n+1)}2$，那么第 $n$ 组恰好占据第 $T_{n-1}+1$ 天到第 $T_n$ 天。前 $k$ 天会完整覆盖前若干个组，最后一个组可能被"截断"（只取了前几天）。于是：

$$\text{ans}=\sum_{n\ge1} n\cdot t_n,\qquad t_n=\text{第 }n\text{ 组落在前 }k\text{ 天里的天数}=\max\bigl(0,\ \min(T_n,k)-T_{n-1}\bigr).$$

**第三步：把组级求和写成一个循环。** 我不需要显式算三角形数，只要维护"已经过了多少天 `day`"：第 $n$ 组本来有 $n$ 天，但只剩 $k-\text{day}$ 天可发，所以实际发 $t=\min(n,\ k-\text{day})$ 天，贡献 $n\cdot t$。发完 `day+=t`，`day==k` 就停。循环只跑约 $\sqrt{2k}$ 次（$k=10^4$ 时 $141$ 次），比逐天模拟还快，而且代码更短。

**第四步：值域要不要开 long long？** 估一下上界：$k=10^4$ 时最多发到第 $141$ 组（$T_{140}=9870<10^4\le T_{141}=10011$），每天最多领 $141$ 枚，所以 $\text{ans}\le 141\times10^4=1.41\times10^6$，远小于 `int` 上限 $2.1\times10^9$。中间量 $n\cdot t\le141^2\approx2\times10^4$ 也不会溢出。**`int` 足够**，不必上 `i64`。（精确值：$k=10^4$ 时 $\text{ans}=\sum_{n=1}^{140}n^2+130\times141=924490+18330=942820$。）

**第五步：还能更快吗？（顺便想想，不采用）** 既然完整组的贡献是 $\sum n^2$，可以用平方和公式 $\frac{m(m+1)(2m+1)}6$ 一步算出前 $m$ 个完整组，再加上截断组。这样是 $O(\sqrt k)$ 求 $m$ + $O(1)$ 公式。但组级循环已经是 $O(\sqrt k)$ 且只有 $141$ 次迭代，公式版反而要多推一个平方和、多处理边界，得不偿失。**最终就用组级循环**，简洁又够快。

**手造数据核对**（题面只给了 $k=6$ 的样例说明，我另造几组手算）：

| $k$ | 手算过程 | 答案 |
|---|---|---|
| $1$ | 第 1 天 1 枚 | $1$ |
| $6$ | $1+2+2+3+3+3$ | $14$（与题面说明一致） |
| $10$ | 前 3 组满（$1+4+9=14$）+ 第 4 组 4 天（$4\times4=16$） | $30$ |
| $10000$ | $\sum_{n=1}^{140}n^2+130\times141=924490+18330$ | $942820$ |

程序输出与这四组手算逐一吻合。

## 二、思维链：完整证明

**记号。** $T_n=\frac{n(n+1)}2$ 为第 $n$ 个三角形数，$T_0=0$。第 $n$ 组指"每天领 $n$ 枚"的那连续 $n$ 天。$k$ 为总天数。程序变量：`day` 已处理天数，`ans` 已累加金币，`n` 当前组号，`t` 本组实际发放天数。

---

### 引理 1（分组划分：第 $n$ 组占据 $[T_{n-1}+1,\ T_n]$）

按题意，第 $n$ 组恰好覆盖第 $T_{n-1}+1$ 天到第 $T_n$ 天，且第 $d$ 天领的金币数等于它所属的组号 $n$（即满足 $T_{n-1}<d\le T_n$ 的唯一 $n$）。

*证明*：对 $n$ 归纳。

$n=1$：第 $1$ 组持续 $1$ 天，从第 $1$ 天开始，覆盖 $[1,1]=[T_0+1,T_1]$（$T_0=0,T_1=1$）✓。

设前 $n-1$ 组恰好覆盖第 $1$ 天到第 $T_{n-1}$ 天（归纳假设）。题意说"连续 $n-1$ 天每天 $n-1$ 枚之后，是连续 $n$ 天每天 $n$ 枚"，故第 $n$ 组紧接第 $n-1$ 组之后，从第 $T_{n-1}+1$ 天开始，持续 $n$ 天，覆盖 $[T_{n-1}+1,\ T_{n-1}+n]$。而 $T_n=T_{n-1}+n$（三角形数递推），所以第 $n$ 组覆盖 $[T_{n-1}+1,T_n]$ ✓。

各组区间首尾相接、互不重叠，并集为 $[1,\infty)$，故每个正整数 $d$ 落在唯一组里，该组号 $n$ 由 $T_{n-1}<d\le T_n$ 唯一确定（$T_n$ 严格递增）。第 $d$ 天领 $n$ 枚。证毕。

---

### 引理 2（总金币 = 组贡献之和，末组可截断）

前 $k$ 天的总金币为
$$\text{ans}=\sum_{n\ge1}n\cdot t_n,\qquad t_n=\max\bigl(0,\ \min(T_n,k)-T_{n-1}\bigr),$$
其中只有有限个 $t_n>0$，且最后一个非零项可能满足 $t_n<n$（截断）。

*证明*：由引理 1，第 $d$ 天领 $n(d)$ 枚，故 $\text{ans}=\sum_{d=1}^{k}n(d)$。按组归类：第 $n$ 组里落在 $[1,k]$ 的天，是区间 $[T_{n-1}+1,T_n]\cap[1,k]=[T_{n-1}+1,\ \min(T_n,k)]$（当 $T_{n-1}<k$ 时非空）。其天数 $t_n=\min(T_n,k)-T_{n-1}$（若为负则取 $0$，即该组完全在 $k$ 之后）。这些天每天领 $n$ 枚，贡献 $n\cdot t_n$。各组不交，求和即得。

当 $T_{n-1}<k<T_n$ 时，$t_n=k-T_{n-1}<n$，这就是被截断的末组；更大的 $n$ 满足 $T_{n-1}\ge k$，$t_n=0$。故非零项有限。证毕。

---

### 引理 3（组级循环的不变量与正确性）

程序
```
for(int n=1,day=0;day<k;++n){ int t=min(n,k-day); ans+=n*t; day+=t; }
```
满足：每次进入循环体时 `day` 等于已处理天数、`ans` 等于前 `day` 天的金币总数；循环结束时 `day==k` 且 `ans` 为前 $k$ 天总金币。

*证明*：对循环迭代次数归纳，维护不变量 $I$：`day` $=\sum_{j<n}t_j$（前 $n-1$ 组实际发放天数），`ans` $=\sum_{j<n}j\cdot t_j$，且 `day` $=\min(T_{n-1},k)$。

初始 $n=1$：`day=0`$=\min(T_0,k)$，`ans=0`，$I$ 成立。

设进入第 $n$ 次迭代时 $I$ 成立，即 `day`$=\min(T_{n-1},k)$。此时 `k-day`$=k-\min(T_{n-1},k)=\max(0,k-T_{n-1})$。代码取 `t=min(n,k-day)`：
- 若 $T_{n-1}\ge k$：`day==k`，循环条件 `day<k` 为假，根本不会进入此迭代（故只需考虑 $T_{n-1}<k$）。
- 若 $T_{n-1}<k$：`k-day`$=k-T_{n-1}>0$，`t=min(n,k-T_{n-1})`。而引理 2 的 $t_n=\min(T_n,k)-T_{n-1}=\min(T_{n-1}+n,k)-T_{n-1}=\min(n,k-T_{n-1})$，恰等于 `t` ✓。

于是 `ans+=n*t` 把第 $n$ 组贡献 $n\cdot t_n$ 加入，`day+=t` 使 `day`$=\min(T_{n-1},k)+t_n=\min(T_n,k)$（因为 $t_n=\min(T_n,k)-T_{n-1}$ 且 $T_{n-1}<k$）。这正是下一次迭代（$n+1$）所需的 $I$。归纳成立。

终止：`day`$=\min(T_{n-1},k)$ 随 $n$ 增大最终达到 $k$（$T_n\to\infty$），循环条件 `day<k` 变假退出，此时 `day==k`，`ans`$=\sum_{j}j\cdot t_j$ 即前 $k$ 天总金币（引理 2）。证毕。

---

### 引理 4（迭代次数 = $O(\sqrt k)$）

循环迭代次数等于最小的 $m$ 使 $T_m\ge k$，即 $m=\left\lceil\frac{\sqrt{8k+1}-1}2\right\rceil=O(\sqrt k)$。$k=10^4$ 时 $m=141$。

*证明*：由引理 3，第 $n$ 次迭代后 `day`$=\min(T_n,k)$。循环在 `day==k` 时停止，即首次 $T_n\ge k$ 的那个 $n$ 之后停止，故迭代次数 $m=\min\{n:T_n\ge k\}$。解 $\frac{n(n+1)}2\ge k\iff n^2+n-2k\ge0\iff n\ge\frac{-1+\sqrt{1+8k}}2$，取上整得 $m$。量级 $\sqrt{2k}=O(\sqrt k)$。

$k=10^4$：$T_{140}=9870<10^4$，$T_{141}=10011\ge10^4$，故 $m=141$。证毕。

---

### 引理 5（值域：`int` 安全）

$k\le10^4$ 时 $\text{ans}\le1.41\times10^6<2^{31}-1$，且中间量 $n\cdot t\le141^2<2\times10^4$，全程 `int` 不溢出。

*证明*：由引理 4，最大组号 $m\le141$，每天领的金币 $\le m\le141$。前 $k\le10^4$ 天，故 $\text{ans}\le141\times10^4=1.41\times10^6$。`int` 上限 $2^{31}-1=2147483647\approx2.1\times10^9$，余量约 $1500$ 倍。中间量 `n*t` 中 $n\le141$、$t\le n\le141$，故 $n\cdot t\le19881$，`ans+=n*t` 的加法两操作数均 $\le1.41\times10^6$，和 $\le1.41\times10^6$，无溢出。证毕。

（更紧的界：$\text{ans}\le\sum_{n=1}^{141}n^2=\frac{141\cdot142\cdot283}6=944371$，同样远小于 `int` 上限。）

---

### 定理

程序输出前 $k$ 天骑士获得的金币总数，时间 $O(\sqrt k)$，空间 $O(1)$。

*证明*：引理 1 确立分组结构，引理 2 把总数写成组贡献之和，引理 3 证明组级循环逐项计算这些贡献且终止时 `day==k`、`ans` 正确，引理 4 给出 $O(\sqrt k)$ 迭代次数，引理 5 保证 `int` 安全。只用了常数个变量，空间 $O(1)$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 工资是分段常数：第 $n$ 组连续 $n$ 天每天 $n$ 枚，分界点是三角形数 $T_n=\frac{n(n+1)}2$。
- **consider easier version** — 先写逐天 $O(k)$ 模拟，$k\le10^4$ 直接能过，确认这是入门模拟而非难题。
- **reduce to easier problem** — 把"一天一天加"塌缩成"一组一组加"：第 $n$ 组贡献 $n\times\min(n,k-\text{day})$，迭代降到 $O(\sqrt k)$。
- **discuss by category** — 末组截断用 `min(n,k-day)` 统一处理；估上界 $1.41\times10^6$ 确认 `int` 够用；$k=1$ 边界自然成立。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `k` | 总天数（$\le10^4$） | `int`，读入 | 唯一输入 |
| `ans` | 前 `day` 天累计金币 | `int`，初值 $0$ | 答案，全局/局部均可 |
| `n` | 当前组号（第 $n$ 组每天 $n$ 枚） | `int`，循环从 $1$ 递增 | "组号=每天金币数=组天数" |
| `day` | 已处理天数 | `int`，初值 $0$ | 不变量 `day==min(T_{n-1},k)` |
| `t` | 第 $n$ 组在前 $k$ 天里实际发放的天数 | `int`，`min(n,k-day)` | 末组截断的关键 |
| $T_n$ | 三角形数 $\frac{n(n+1)}2$ | 数学量，不显式存 | 组分界点 |

### 算法步骤

1. I/O 加速三行。
2. 读入 `k`，`ans=0`。
3. 循环 `n=1,day=0`；当 `day<k`：`t=min(n,k-day)`；`ans+=n*t`；`day+=t`；`++n`。
4. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(\sqrt k)$，$k=10^4$ 时 $141$ 次迭代。
- 空间：$O(1)$。
- 值域：$\text{ans}\le1.41\times10^6$，`int` 安全（引理 5）。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；$k=6\to14$ 与题面样例说明一致；另造 $k=1,10,10000$ 三组手算数据（$1,30,942820$）逐一吻合。入门模拟题，未写对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2669 [NOIP 2015 普及组] 金币
// 思路：第 n 组连续 n 天、每天 n 枚 ⇒ 按组求和，第 n 组贡献 n*min(n,k-day)
//       组数约 sqrt(2k)，O(sqrt k)；ans<=1.41e6，int 足够
#include<bits/stdc++.h>
using namespace std;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int k,ans=0;
	cin>>k;
	for(int n=1,day=0;day<k;++n)
	{
		int t=min(n,k-day);	// 第 n 组实际发放 t 天（末组可能被截断）
		ans+=n*t;
		day+=t;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`min(n,k-day)` 一行搞定截断**：第 $n$ 组本有 $n$ 天，但只剩 $k-\text{day}$ 天，取小者就是实际天数；完整组时 $k-\text{day}\ge n$ 取 $n$，末组时取剩余天数，无需分支。
- **循环条件 `day<k`**：`day` 恰好等于 $\min(T_{n-1},k)$（引理 3），一旦够 $k$ 天立即停止，不会多发。
- **`int` 而非 `i64`**：上界 $1.41\times10^6$ 远在 `int` 内（引理 5），开 `long long` 没必要。
- 没有显式三角形数数组：`day` 的累加隐式维护了 $T_n$，代码更短。
