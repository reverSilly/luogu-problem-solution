# P2265 路边的水沟 — 题解

## 一、解题过程：人类思考叙事

题意可以这样重述：有一个 $n\times m$ 的矩形格点阵，每个格点都有一个闸门；从右下角的闸门走到左上角的闸门，每一步只能向左或向上，求不同的路径（水流）条数，答案对 $10^9+7$ 取模。数据范围 $n,m\le 10^6$。

先把"$n\times m$"的含义钉死。题面说的是"$n\times m$ 的矩形网格，网格的每个格点都安装了闸门"，也就是格点阵有 $n$ 行 $m$ 列，共 $nm$ 个闸门；起点是第 $n$ 行第 $m$ 列，终点是第 $1$ 行第 $1$ 列。如果误把 $n,m$ 当成格子数，端点数会变成 $(n+1)(m+1)$，答案会整体偏移一圈。本文按题面的"格点"来读，下面的小规模验证也会按这个模型跑。

第一反应是 DP：设 $f[i][j]$ 表示从右下角走到格点 $(i,j)$ 的方案数，则 $f[i][j]=f[i+1][j]+f[i][j+1]$（从下方或右方走来）。这个东西在 $n,m\le 10$ 时很好用，在 $n,m\le 1000$ 时也行，但 $n=m=10^6$ 时状态数是 $10^{12}$，连一格都存不下。子任务从 $10$ 到 $1000$ 到 $50000$ 到 $10^6$ 的跳跃，也在提示正解必须绕开二维 DP。

换个角度：一条路径真正自由的只有"先走哪一步"。从第 $n$ 行走到第 $1$ 行，向上走的总次数一定是 $n-1$；从第 $m$ 列走到第 $1$ 列，向左走的总次数一定是 $m-1$。两个数字都被端点锁死了，路径的总步数也固定为 $n+m-2$。于是每条路径都对应一个由 $n-1$ 个"上"和 $m-1$ 个"左"组成的序列，反过来，任何一个这样的序列都能走出一条合法路径——因为无论怎么排列，向上次数不会超过 $n-1$，向左次数不会超过 $m-1$，永远不会走出网格。

这样一来，问题从"数网格里的路径"变成了"数由固定个数的两种字符组成的序列"，这是组合数学里最标准的问题：从 $n+m-2$ 个位置里选出 $n-1$ 个放"上"，剩下的放"左"，方案数是
$$\binom{n+m-2}{n-1}=\binom{n+m-2}{m-1}.$$

用手边的小数据核对一下：$n=m=1$ 时只有原地不动的空路径，共 $1$ 条，公式给 $\binom00=1$；$n=m=2$ 时两条路径（上左、左上），公式给 $\binom21=2$；$n=3,m=2$ 时需要 $2$ 上 $1$ 左，序列有 $3$ 个位置可选"左"，公式给 $\binom32=3$。之后我写了 $O(nm)$ 的网格 DP 暴力，把 $1\le n,m\le 12$ 的 $144$ 组全部比了一遍，公式与 DP 完全一致，这基本确认了"格点阵"的读法与公式。

最后是计算。$n,m\le 10^6$ 时 $N=n+m-2\le 1999998$，远小于模数 $10^9+7$。预处理阶乘 $\text{fac}[i]=i!\bmod p$，然后用费马小定理求两个阶乘的逆元，按
$$\text{ans}=\text{fac}[N]\cdot\text{fac}[n-1]^{p-2}\cdot\text{fac}[m-1]^{p-2}\pmod p$$
计算即可。要特别注意乘法必须用 `long long`（两个 $10^9$ 量级的数相乘会爆 `int`），阶乘数组也要开到 $2\times 10^6+5$。

## 二、思维链：完整证明

**记号**：把格点用坐标 $(i,j)$ 表示，$1\le i\le n$ 为行号（从下往上增大），$1\le j\le m$ 为列号（从左往右增大）。起点 $S=(n,m)$，终点 $T=(1,1)$。"上"使行号减 $1$，"左"使列号减 $1$。

**引理 1**：任意一条从 $S$ 到 $T$ 的合法路径，恰好包含 $n-1$ 次"上"和 $m-1$ 次"左"，总步数为 $n+m-2$。

*证明*：路径中的每一步只能是"上"或"左"。"上"使行号减 $1$，"左"不改变行号；行号从 $n$ 出发，最终必须到达 $1$，而它只会减小、不会增大，所以行号总共减少了 $n-1$，这只能由 $n-1$ 次"上"完成。同理，列号从 $m$ 出发到达 $1$，只由"左"改变，故"左"恰好 $m-1$ 次。两类步数相加得总步数 $n+m-2$。证毕。

**引理 2**：任意一个由 $n-1$ 个"上"和 $m-1$ 个"左"组成的序列，从 $S$ 出发依次执行，路径上的每一个格点都落在 $1\le i\le n,\ 1\le j\le m$ 之内，因此它是一条合法的水流。

*证明*：考虑执行完序列的任意一个前缀时的位置。设这个前缀里用了 $u$ 次"上"、$l$ 次"左"，则当前位置为
$$(i,j)=(n-u,\ m-l).$$
由前缀长度不超过总长度，$0\le u\le n-1$、$0\le l\le m-1$。于是
$$i=n-u\in[1,n],\qquad j=m-l\in[1,m].$$
每一步都使行号或列号减少 $1$，所以相邻两个位置是网格中相邻的格点，且移动方向只能是"上"或"左"，符合题目要求。前缀的任意性说明整条路径不越界，是一条合法水流。证毕。

**引理 3**：所有合法水流与所有"含 $n-1$ 个上、$m-1$ 个左"的序列之间存在一一对应。

*证明*：定义映射 $\varphi$：给定水流，按时间顺序记录每一步的方向，得到一个由"上""左"组成的序列。由引理 1，这个序列恰含 $n-1$ 个"上"、$m-1$ 个"左"。再定义反向映射 $\psi$：给定序列，从 $S$ 出发依次执行，得到一条路径；由引理 2 它是合法水流。

先看 $\psi(\varphi(\text{路径}))$：按原路径的方向序列重新走一遍，起点相同、每一步方向相同，由归纳法每个时刻的位置都与原路径相同，所以得到原路径。再看 $\varphi(\psi(\text{序列}))$：执行序列时记录的正是序列本身。两个映射互为逆映射，因此是双射。证毕。

**引理 4**：含 $n-1$ 个"上"、$m-1$ 个"左"的序列总数为 $\binom{n+m-2}{n-1}$。

*证明*：序列一共有 $N=n+m-2$ 个位置。只要选定其中哪 $n-1$ 个位置放"上"，剩下的 $m-1$ 个位置就必然全放"左"，序列被唯一确定；不同的位置集合给出不同的序列。因此序列总数等于从 $N$ 个位置中选 $n-1$ 个的方案数，即 $\binom{N}{n-1}$。由组合数的对称性，它也等于 $\binom{N}{m-1}$。证毕。

**引理 5（模运算）**：设 $p=10^9+7$，$N=n+m-2$。若已预处理 $\text{fac}[i]=i!\bmod p$，且 $p$ 是素数、$N<p$，则
$$\text{fac}[N]\cdot\text{fac}[n-1]^{p-2}\cdot\text{fac}[m-1]^{p-2}\bmod p=\binom{N}{n-1}\bmod p.$$

*证明*：分三步。

（1）$N\le 1999998<p$，所以 $1,2,\dots,N$ 中没有 $p$ 的倍数。$p$ 是素数，若 $p$ 整除乘积 $N!$，由欧几里得引理，$p$ 必须整除某个因子 $1\le i\le N$，这与"没有 $p$ 的倍数"矛盾。因此 $\text{fac}[N]\not\equiv0\pmod p$，它在模 $p$ 下可逆。同理 $\text{fac}[n-1]$、$\text{fac}[m-1]$ 也可逆（它们的因子范围更小）。

（2）费马小定理：若 $p$ 是素数且 $p\nmid a$，则 $a^{p-1}\equiv1\pmod p$。于是
$$a^{p-2}\cdot a\equiv a^{p-1}\equiv1\pmod p,$$
即 $a^{p-2}$ 是 $a$ 在模 $p$ 下的乘法逆元。取 $a=\text{fac}[n-1]$ 与 $a=\text{fac}[m-1]$，由（1）它们都满足 $p\nmid a$，逆元存在。

（3）在模 $p$ 下做乘除法：把除以 $(n-1)!$ 和 $(m-1)!$ 换成乘以它们的逆元，得到
$$\frac{N!}{(n-1)!(m-1)!}\bmod p=\text{fac}[N]\cdot(\text{fac}[n-1])^{p-2}\cdot(\text{fac}[m-1])^{p-2}\bmod p.$$
而左边的分数正是 $\binom{N}{n-1}$ 的整数表达式（组合数公式），它在模 $p$ 下的值就等于上式。证毕。

> 这里用到 $p=10^9+7$ 是素数这一模数的基本事实；费马小定理的适用前提"$p$ 素且 $a$ 不是 $p$ 的倍数"已在（1）中逐项验证。

**引理 6（边界）**：当 $n=1$ 或 $m=1$ 时，公式仍给出正确答案。

*证明*：若 $n=1$，行号已经是 $1$，不需要任何"上"步，路径只能是连续向左走 $m-1$ 步，恰有一条，答案为 $1$。公式给出 $\binom{m-1}{0}=1$。若 $m=1$，对称地有唯一一条连续向上的路径，公式给出 $\binom{n-1}{n-1}=1$。若 $n=m=1$，起点即终点，空路径一条，公式给出 $\binom00=1$。证毕。

**定理**：算法输出的数值等于题面所问的水流条数对 $10^9+7$ 取模的结果。

*证明*：由引理 3，水流与"$n-1$ 上、$m-1$ 左"的序列一一对应；由引理 4，这样的序列有 $\binom{n+m-2}{n-1}$ 个；由引理 5，程序用阶乘与费马逆元正确算出了这个组合数对 $p$ 取模的值；由引理 6，边界情形也包含在公式内。因此输出正确。证毕。

**引理 7（复杂度）**：时间复杂度 $O(n+m+\log p)$，空间复杂度 $O(n+m)$。

*证明*：阶乘表从 $1$ 递推到 $N=n+m-2$，共 $O(n+m)$ 次乘法；两次快速幂各 $O(\log p)$ 次乘法。空间上只存一个长度为 $N+1$ 的 `long long` 阶乘数组，$N\le 1999998$，即 $O(n+m)$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 只允许向上/向左，行、列各自单调变化，两类步数被端点差锁死。
- **consider easier version** — 小网格用 $O(nm)$ 的格路 DP 数路径，得到的数值就是杨辉三角的一行。
- **reduce to easier problem** — 路径与"固定个数的 U/L 排列"一一对应，几何问题化为计数问题。
- **classic problem solution** — 从 $n+m-2$ 个位置中选 $n-1$ 个放"上"，得到二项式系数 $\binom{n+m-2}{n-1}$。
- **classic problem solution** — 模素数下的组合数：预处理阶乘 + 费马小定理求逆元。
- **discuss by category** — $n=1$ 或 $m=1$ 时公式自动退化为 $1$，无需特判。
- **complexity check** — $n,m\le10^6$ 时阶乘表长度约 $2\times10^6$，时间与空间都可行。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初始化 / 记忆点 |
|------|------|------|----------------|
| $n,m$ | 格点阵的行数、列数 | `int` | 输入 |
| $N$ | 总步数 $n+m-2$ | `int` | 计算得出，$0\le N\le1999998$ |
| $p$ | 模数 $10^9+7$ | `constexpr i64` | 素数 |
| $\text{fac}[i]$ | $i!\bmod p$ | `i64[]` | $\text{fac}[0]=1$，随后 `fac[i]=fac[i-1]*i%p` |
| $\text{ans}$ | 答案 | `i64` | $\text{fac}[N]\cdot\text{fac}[n-1]^{p-2}\cdot\text{fac}[m-1]^{p-2}\bmod p$ |
| $\text{qpow}(a,b)$ | 快速幂 $a^b\bmod p$ | 函数 | 二进制拆分，`res` 初值 $1$ |

### 算法步骤

1. 读入 $n,m$，计算 $N=n+m-2$。
2. 令 $\text{fac}[0]=1$，对 $i=1,2,\dots,N$ 递推 $\text{fac}[i]=\text{fac}[i-1]\cdot i\bmod p$。
3. 用快速幂算出 $\text{inv}_1=\text{qpow}(\text{fac}[n-1],p-2)$ 和 $\text{inv}_2=\text{qpow}(\text{fac}[m-1],p-2)$。
4. 计算 $\text{ans}=\text{fac}[N]\cdot\text{inv}_1\bmod p\cdot\text{inv}_2\bmod p$。
5. 输出 $\text{ans}$。

### 复杂度

- 时间复杂度：$O(n+m+\log p)$，其中阶乘递推 $O(n+m)$，两次快速幂各 $O(\log p)$。
- 空间复杂度：$O(n+m)$，即长度 $N+1\le1999999$ 的 `long long` 阶乘数组（约 $16$ MB）。

### 验证状态

编译通过（`g++ -std=c++20 -O2`）；本题题面无样例，用 $1\le n,m\le 12$ 的 $144$ 组数据与 $O(nm)$ 的格路 DP 暴力逐一比对全部一致，并在 $n=m=10^6$ 的极限数据上运行约 $0.08$ 秒、数组未越界。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2265 路边的水沟
// 从右下格点到左上格点，只许向左/向上
// 需要 n-1 次向上、m-1 次向左，方案数 C(n+m-2,n-1)
// 预处理阶乘，费马小定理求逆元
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2000005};
constexpr i64 p{1'000'000'007};

i64 fac[mxn];

i64 qpow(i64 a,i64 b)
{
	i64 r=1;
	for(;b;b>>=1,a=a*a%p)
		if(b&1)
			r=r*a%p;
	return r;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m;
	cin>>n>>m;
	int N=n+m-2;
	fac[0]=1;
	for(int i=1;i<=N;++i)
		fac[i]=fac[i-1]*i%p;
	i64 ans=fac[N]*qpow(fac[n-1],p-2)%p*qpow(fac[m-1],p-2)%p;
	cout<<ans<<'\n';
	return 0;
}
```
