# P2052 [NOI2011] 道路修建 — 题解

## 一、解题过程：人类思考叙事

$n$ 个国家，用 $n-1$ 条双向道路连成一个**树**（连通 + 恰好 $n-1$ 条边 ⇒ 树）。每条边的费用是"边长 × 两端国家个数之差的绝对值"。

这句话初看很含糊——"道路两端的国家个数"是什么？其实指的是：把这条道路**删掉**，树会分成两个连通块，两个连通块各有若干个国家，费用 = 边长 × |两块大小之差|。题面的示意图就是在说这件事：虚线道路把 6 个国家分成 2 个和 4 个两块，费用 $1\times|2-4|=2$。

于是问题转化为：**对每条边，删掉它后树分成两块，块大小分别是 $s$ 和 $n-s$，求 $\sum w\cdot|s-(n-s)|$**。

朴素做法：对每条边单独跑一次 BFS/DFS 看能到多少个点，$O(n^2)$，$n=10^6$ 完全不行。

关键观察是：**删掉一条边 $(u,v)$ 后，两块的大小只取决于"以某点为根时 $v$ 的子树大小"**。把树以任意一点为根，设 $sz[v]$ 是 $v$ 的子树点数，则删掉 $v$ 与父亲之间的边后，两块大小就是 $sz[v]$ 和 $n-sz[v]$，费用 $=w\cdot|sz[v]-(n-sz[v])|=w\cdot|2\,sz[v]-n|$。

所以只要算出所有点的子树大小即可，这是标准的"一次 DFS"的事。

但 $n=10^6$ 有两个现实问题：

1. **递归会爆栈**。链状树的 DFS 深度是 $10^6$，递归调用栈吃不消。所以必须写成**非递归**的遍历。
2. **邻接表的内存**。$10^6$ 个点、$2\times10^6$ 条有向边，用 `vector<int> g[n]` 会有 $10^6$ 个 vector 对象（每个 24 字节，24MB）外加 $2\times10^6$ 次堆分配，既慢又浪费。更好的选择是**链式前向星**：用三个平行数组 `to[]`、`nxt[]`、`ew[]` 存边，用 `H[u]` 存 $u$ 的第一条出边下标。整体内存紧凑、遍历快。

非递归遍历怎么做？我用**队列式的 BFS 序**：`ord[]` 既是队列又是"父亲先于孩子"的遍历序。

- 从根出发，令 `ord[0]=root`，`fa[root]=-1`；
- 依次处理 `ord[0], ord[1], ...`，对 $u$ 的每个邻点 $v$，若 $v\ne fa[u]$ 就令 `fa[v]=u`、`ord[tot++]=v`。

这样 `ord` 里父亲一定排在孩子前面。那么**逆序遍历 `ord`** 就可以自底向上累加子树大小：

```cpp
for(int i=n-1;i>=1;--i){
	int u=ord[i];
	ans += w(u,fa[u]) * llabs(1LL*sz[u]-(n-sz[u]));
	sz[fa[u]] += sz[u];
}
```

`i` 从 $n-1$ 到 $1$ 跳过 `ord[0]`（根没有父边）。注意顺序：**先算 $u$ 的费用，再把 $sz[u]$ 加到父亲上**，这样算费用时 $sz[u]$ 已经是完整的子树大小了。

费用可能超 `int`：边长最大 $10^6$，差值最大 $10^6$，单条边费用最大 $10^{12}$，总和更是 $10^{18}$ 级别，必须用 `long long`（`i64`）。乘的时候要写成 `(i64)w * ...` 让乘法在 64 位下进行。

样例：
```
6
1 2 1
1 3 1
1 4 2
6 3 1
5 2 1
```
以 $1$ 为根：$sz[1]=6$。$sz[2]=2$（国家 2、5），$sz[5]=1$，$sz[3]=2$（3、6），$sz[6]=1$，$sz[4]=1$。
- 边 $1-2$（长 $1$）：$|2-4|=2$，费用 $2$；
- 边 $1-3$（长 $1$）：$|2-4|=2$，费用 $2$；
- 边 $1-4$（长 $2$）：$|1-5|=4$，费用 $8$；
- 边 $3-6$（长 $1$）：$|1-5|=4$，费用 $4$；
- 边 $2-5$（长 $1$）：$|1-5|=4$，费用 $4$。

总费用 $=2+2+8+4+4=20$，与题面样例一致。

## 二、思维链：完整证明

**引理 1**（删边与子树大小的对应）：把树以 $r$ 为根，删去边 $(fa[v],v)$ 后得到的两个连通块，其点数分别为 $sz[v]$ 与 $n-sz[v]$。

*证明*：树上任意两点的唯一路径称为简单路径。删去边 $e=(fa[v],v)$ 后，$v$ 的子树内任一点 $x$ 与 $r$ 之间的简单路径必经 $e$，故 $x$ 与 $r$ 不连通；而 $v$ 子树外的任一点 $y$ 与 $r$ 之间的简单路径不经过 $e$（$e$ 是 $v$ 与其父亲之间的唯一连接），故 $y$ 与 $r$ 连通。

于是删边后的两个连通块恰为"以 $v$ 为根的子树"和"其余部分"，点数分别为 $sz[v]$ 与 $n-sz[v]$。证毕。

**引理 2**（遍历序的性质）：算法生成的 `ord` 数组中，每个非根节点 $v$ 的父亲 `fa[v]` 出现在 $v$ 之前。

*证明*：算法在处理 `ord[i]`（记为 $u$）时才把新发现的邻点 $v$ 追加到 `ord` 的末尾，故 $v$ 的下标严格大于 $u$ 的下标。而 $fa[v]=u$，所以 $u$（即 $fa[v]$）出现在 $v$ 之前。证毕。

**引理 3**（子树大小的计算正确性）：算法结束后，$sz[u]$ 等于以 $u$ 为根的子树点数。

*证明*：初始时所有 `sz[u]=1`，表示节点自身。算法按 `ord` 的逆序处理节点。

由引理 2 及其逆序性质，当处理节点 $u$ 时，$u$ 的所有子孙节点都已在 $u$ 之前被处理完毕。子孙 $x$ 在被处理时执行了 `sz[fa[x]] += sz[x]`，而 $fa[x]$ 或是 $u$ 本身，或是 $u$ 的某个后代——后者在逆序中先于 $u$ 被处理，因此其大小已被完整累加到 $u$ 上。

归纳地，$u$ 的每个直接子节点 $c$ 被处理时，$sz[c]$ 已等于 $c$ 子树的点数，并被加到 $sz[u]$ 上。于是处理 $u$ 时，$sz[u] = 1 + \sum_{c \text{ 是 } u \text{ 的儿子}} sz[c] = u$ 的子树点数（对叶子显然成立，由归纳得证）。证毕。

**引理 4**（每条边的费用计算正确）：算法对边 $(fa[v],v)$ 累加的贡献等于该边的真实费用。

*证明*：由引理 1，删去该边后两块大小为 $sz[v]$ 与 $n-sz[v]$；由引理 3，算法此时 `sz[v]` 正是 $v$ 的子树点数。题目规定费用为"边长 × |两块点数之差|"，算法累加的是 $w\cdot|sz[v]-(n-sz[v])|$，两者一致。证毕。

**定理**：算法输出的总费用等于题目要求的总费用。

*证明*：由引理 2，逆序遍历中每个非根节点 $v$ 恰好被处理一次，对应树中恰好一条边 $(fa[v],v)$；$n$ 个点的树有 $n-1$ 条边，而根之外的节点恰有 $n-1$ 个，二者一一对应，故所有边都被计算且只被计算一次。由引理 4，每次累加的都是该边的真实费用，求和即为总费用。证毕。

## 三、模式总结（按实际思考顺序）

1. **翻译题意** — "道路两端的国家个数"= 删掉这条边后两个连通块的大小。
2. **发现结构** — 块大小只与"子树大小"有关，于是转化为一次遍历求子树大小。
3. **数据规模意识** — $n=10^6$ 逼出两个工程决策：非递归遍历（防爆栈）、链式前向星（防内存爆炸）。
4. **非递归求子树大小** — 先求"父亲在孩子前"的遍历序，再逆序累加。
5. **先算费用再上传** — 顺序反了就会用到未完成的子树大小。
6. **64 位与乘法提升** — 费用可能到 $10^{18}$，且 `(i64)w * x` 中必须让 $w$ 先转 64 位。
7. **验证方式** — 题面样例手算核对；另写"逐边删边 + BFS 数块大小"的暴力做对拍。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 国家数 | `int`，$2\le n\le 10^6$ |
| $w_e$ | 边长 | `int`，$0\le w\le10^6$ |
| $sz[u]$ | 以 $u$ 为根的子树点数 | `int`，$1\le sz\le10^6$ |
| $fa[u]$ | $u$ 的父亲 | `int[]` |
| `ord[i]` | 遍历序中第 $i$ 个节点（父在前、子在后） | `int[]`，长度 $n$ |
| `H[u]` | $u$ 的第一条出边下标（链式前向星） | `int[]` |
| `to/nxt/ew` | 前向星的终点 / 下一条边 / 边权 | `int[]` |
| `ans` | 总费用 | `i64` |

### 算法步骤

1. 读入 $n$ 与 $n-1$ 条边，双向建边到链式前向星（`H[]` 初始化为 $-1`）。
2. **非递归遍历**：以节点 $0$ 为根，`ord[0]=0`、`fa[0]=-1`；用 `ord` 当队列，依次扫描其元素，对每个未访问方向的邻点 $v$ 设 `fa[v]=u` 并追加到 `ord` 末尾。
3. 初始化 `sz[u]=1`（全体）。
4. **逆序累加**：对 $i=n-1$ 到 $1$：
   - $u=\text{ord}[i]$；
   - 在 $u$ 的出边中找到终点为 `fa[u]` 的那条，取出边长 $w$；
   - `ans += (i64)w * llabs(1LL*sz[u]-(n-sz[u]))`；
   - `sz[fa[u]] += sz[u]`。
5. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(n)$，每个点、每条边只被访问常数次。
- 空间复杂度：$O(n)$。前向星三个 `int` 数组各 $2\times10^6$、三个节点级 `int` 数组各 $10^6$，合计约 $36$MB，满足 125MB 限制。

### 验证状态

- 标程 `P2052.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 题面样例（$n=6$，五条边）输出 `20`，与手算逐边求和一致。
- 另写暴力 `P2052_brute.cpp`：对每条边临时删除，用 BFS 数出连通块大小 $s$ 与 $n-s$，累加 $w\cdot|s-(n-s)|$。
- 对拍脚本 `P2052_check.py`：**203 组**用例（200 组随机树 $n\le30$ + 3 组极端：$n=2$、链、纯星形），标程与暴力输出 **0 处不一致**。
- 极端规模检查：$n=10^6$ 的链与星形均能正常完成遍历（全程无递归，无爆栈）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2052 [NOI2011] 道路修建
// 思路：删掉一条边后树分成两块，费用 = 边长 × |两块点数之差|
//       用子树大小 sz 表述即 边长 × |sz - (n-sz)|，非递归遍历避免爆栈
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1000005};
constexpr int mxm{2000005};

int H[mxn],to[mxm],nxt[mxm],ew[mxm],ecnt;
int fa[mxn],sz[mxn],ord[mxn];

void addedge(int u,int v,int w)
{
	to[ecnt]=v;
	ew[ecnt]=w;
	nxt[ecnt]=H[u];
	H[u]=ecnt++;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	fill(H,H+mxn,-1);
	for(int i=1;i<n;++i)
	{
		int u,v,w;
		cin>>u>>v>>w;
		--u;--v;
		addedge(u,v,w);
		addedge(v,u,w);
	}
	// 非递归遍历：ord 既是队列也是遍历序
	int tot=1;
	ord[0]=0;
	fa[0]=-1;
	for(int i=0;i<tot;++i)
	{
		int u=ord[i];
		for(int e=H[u];e!=-1;e=nxt[e])
		{
			int v=to[e];
			if(v==fa[u]) continue;
			fa[v]=u;
			ord[tot++]=v;
		}
	}
	// 逆序累加子树大小
	for(int i=1;i<n;++i) sz[i]=1;
	sz[0]=1;
	i64 ans=0;
	for(int i=n-1;i>=1;--i)
	{
		int u=ord[i];
		// 边 (u,fa[u]) 的长度；删掉它后两块大小为 sz[u] 与 n-sz[u]
		int w=0;
		for(int e=H[u];e!=-1;e=nxt[e])
			if(to[e]==fa[u]) w=ew[e];
		ans+=(i64)w*llabs(1LL*sz[u]-(n-sz[u]));
		sz[fa[u]]+=sz[u];
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `fill(H,H+mxn,-1)` 必须有：链式前向星用 $-1$ 作为"链表结束"标记，全局数组默认是 $0$，不初始化会把边表串成环。
- 遍历用 `for(int i=0;i<tot;++i)` 配 `tot` 递增，等价于队列 BFS；`tot` 既是队列长度也是已发现节点数，`ord` 因此天然满足"父亲在下标上更小"（见引理 2）。
- 逆序循环从 `i=n-1` 到 `1`，跳过 `ord[0]`（根没有父边）。`ord` 的下标与节点编号无关，所以下标必须用 `n-1` 而不能写 `ord` 的其它形式。
- `ans+=(i64)w*llabs(...)`：先把边长提升为 `long long` 再乘，否则 `int×int` 会先溢出。`llabs` 的参数也写成 `1LL*sz[u]-(n-sz[u])`，保证在 64 位下计算。
- **先累加费用再 `sz[fa[u]] += sz[u]`**：顺序颠倒会让本行用到的 `sz[u]` 少算子孙。
- `sz` 初始化写成 `for(int i=1;i<n;++i) sz[i]=1;` 再单独 `sz[0]=1`，是为了让"编号 0 是根"这件事显式可见。
