# P2785 物理1（phsic1）- 磁通量 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 磁场区域是一个多边形，按顺序给出 $N$ 个顶点坐标（实数），磁感应强度 $B$ 为实数，$0<B\le 10$。磁通量 $=$ 磁感应强度 $\times$ 磁场区域面积。输出磁通量，四舍五入保留 $4$ 位小数。题面文本未给 $N$ 与坐标的上界（$N$ 的范围没有出现在文字里），所以算法最好对任意 $N$ 都稳。

**第一步：物理壳，几何核。** 公式已经直接给出：$\Phi=B\cdot S$。$B$ 是读入的常数，整道题就是**求多边形面积**。顶点"依次"给出，说明是简单多边形（边只在相邻顶点处相接）；但**没说顺时针还是逆时针**——这个细节后面会变成绝对值。

**第二步：简化版——凸多边形，扇形剖分。** 最朴素的面积算法：从某个顶点（比如 $P_0$）出发，把多边形切成 $N-2$ 个三角形 $(P_0,P_i,P_{i+1})$，每个三角形面积用叉积 $\frac12|\mathrm{cross}(P_i-P_0,\ P_{i+1}-P_0)|$，加起来。凸多边形时这些三角形恰好不重不漏地铺满多边形，正确。

**第三步：碰壁——凹多边形反例。** 取一个凹的 L 形六边形 $(0,0),(3,0),(3,1),(1,1),(1,3),(0,3)$（$3\times3$ 正方形挖掉右上 $2\times2$，真实面积 $9-4=5$）。从顶点 $(3,0)$ 做扇形剖分，四个三角形的**无符号**面积分别是：

- $(3,0),(3,1),(1,1)$：$1$；
- $(3,0),(1,1),(1,3)$：$2$；
- $(3,0),(1,3),(0,3)$：$1.5$；
- $(3,0),(0,3),(0,0)$：$4.5$。

加起来 $1+2+1.5+4.5=9\ne 5$。**多算了 $4$**——因为 $(3,0)$ 不在多边形的"核"里，有两个三角形伸到了多边形外面，无符号面积把外部区域也计入了。失败模式很清楚：**剖分三角形越界时，无符号求和必然重复计数。**

**第四步：修复——有向面积，让越界部分自己抵消。** 给每个三角形面积带上符号：顶点逆时针为正、顺时针为负。上面四个三角形的**有向**面积是 $+1,\ -2,\ +1.5,\ +4.5$（第二个三角形 $(3,0)\to(1,1)\to(1,3)$ 是顺时针，取负），求和 $1-2+1.5+4.5=5$ ✓！越界的部分恰好被负号扣掉。这不是巧合，是可以证明的恒等式（第二部分引理 3、4）：

$$S=\frac12\Bigl|\sum_{i=0}^{N-1}\mathrm{cross}(P_i,\ P_{i+1})\Bigr|=\frac12\Bigl|\sum_{i=0}^{N-1}(x_i y_{i+1}-x_{i+1}y_i)\Bigr|\quad(P_N=P_0).$$

这就是**鞋带公式**（shoelace）。它不需要剖分、不需要判凸凹、不需要找核内点，一个循环累加叉积就完事。

**第五步：两个工程洞察。**

1. **绝对值**：顶点序可能是顺时针也可能是逆时针，鞋带和的符号随之翻转（逆时针为正、顺时针为负），面积取绝对值即可。$B>0$，所以 $\Phi=B\cdot|S|\ge 0$。
2. **流式读入 + 平移**：鞋带和只依赖**相邻两点**，所以根本不用存下全部 $N$ 个点——留一个"上一点"变量就够，$O(1)$ 额外空间，$N$ 的上界未知也不怕。另外，鞋带和有**平移不变性**（引理 2）：把所有点减去同一个偏移，和不变。于是读入首点 $P_0$ 后，把后续点都减去 $P_0$——叉积的量级就从"绝对坐标的平方"降为"多边形自身尺寸的平方"。假如坐标是 $10^9$ 附近的一个单位正方形，不平移时叉积 $\sim 10^{18}$，相减抵消后只剩 $2$，有效数字被吃掉大半；平移后叉积直接就是 $0,1$ 量级，**精度零损失**。这是把证明里的引理直接变成代码里的精度保险。

**第六步：输出。** `long double` 累加，`fabsl(s)/2*B`，`fixed<<setprecision(4)`。闭合边 $P_{N-1}\to P_0$ 在平移后是"末点 $\to$ 原点"，叉积恒 $0$，连显式补加都省了（代码里注释说明）。

**手造数据核对**（题面没有样例输入输出，我造八组，覆盖凸/凹、顺/逆时针、平移、小数坐标、大偏移）：

| 组 | 输入要点 | 手算面积 | $\Phi$（$B$） | 输出 |
|---|---|---|---|---|
| 1 | 单位正方形，逆时针，$B=2$ | $1$ | $2$ | `2.0000` |
| 2 | 同一正方形，**顺时针**，$B=2$ | $1$ | $2$ | `2.0000` |
| 3 | 直角三角形 $(0,0),(4,0),(0,3)$，$B=1$ | $6$ | $6$ | `6.0000` |
| 4 | 凹 L 形 $(0,0),(2,0),(2,1),(1,1),(1,2),(0,2)$，$B=0.5$ | $3$ | $1.5$ | `1.5000` |
| 5 | 正方形平移到 $(100,100)$，$B=1$ | $1$ | $1$ | `1.0000` |
| 6 | 小数坐标三角形 $(0.5,0.5),(2.5,0.5),(0.5,3.5)$，$B=2.5$ | $3$ | $7.5$ | `7.5000` |
| 7 | 第三步的凹反例 $(0,0),(3,0),(3,1),(1,1),(1,3),(0,3)$，$B=1$ | $5$ | $5$ | `5.0000` |

## 二、思维链：完整证明

**记号。** 顶点 $P_i=(x_i,y_i)$，$i=0..N-1$，按输入顺序构成简单多边形（边不自交），$P_N=P_0$。叉积 $\mathrm{cross}(A,B)=x_A y_B-x_B y_A$。鞋带和 $\Sigma=\sum_{i=0}^{N-1}\mathrm{cross}(P_i,P_{i+1})$。有向三角形面积 $\sigma(A,B,C)=\frac12\mathrm{cross}(B-A,\ C-A)$（逆时针为正）。多边形（无向）面积记 $S$。

---

### 引理 1（叉积 = 有向平行四边形面积）

对原点 $O$ 与点 $A,B$：$|\mathrm{cross}(A,B)|$ 等于以 $OA,OB$ 为邻边的平行四边形面积；$\mathrm{cross}(A,B)$ 的符号在 $B$ 位于 $OA$ 逆时针方向时为正。从而 $\sigma(O,A,B)=\frac12\mathrm{cross}(A,B)$ 是有向三角形面积。

*证明*：设 $|OA|=a$、$|OB|=b$、从 $OA$ 到 $OB$ 的有向角为 $\theta$。以 $OA$ 为底，平行四边形的高是 $B$ 到直线 $OA$ 的距离 $b|\sin\theta|$，面积 $=ab|\sin\theta|$。另一方面，把 $A=(a\cos\alpha,a\sin\alpha)$、$B=(b\cos\beta,b\sin\beta)$ 代入叉积定义：

$$\mathrm{cross}(A,B)=ab(\cos\alpha\sin\beta-\sin\alpha\cos\beta)=ab\sin(\beta-\alpha)=ab\sin\theta.$$

取绝对值即平行四边形面积 ✓；符号由 $\sin\theta$ 决定：$\theta\in(0,\pi)$（逆时针）时正，$\theta\in(-\pi,0)$（顺时针）时负 ✓。三角形是平行四边形的一半（对角线平分），故 $\sigma(O,A,B)=\frac12\mathrm{cross}(A,B)$。退化情形 $\sin\theta=0$（三点共线）两边都是 $0$ ✓。证毕。

---

### 引理 2（鞋带和的平移不变性）

对任意偏移向量 $O$：$\sum_{i}\mathrm{cross}(P_i-O,\ P_{i+1}-O)=\Sigma$。

*证明*：逐项展开（叉积双线性、$\mathrm{cross}(A,A)=0$、$\mathrm{cross}(A,B)=-\mathrm{cross}(B,A)$）：

$$\mathrm{cross}(P_i-O,P_{i+1}-O)=\mathrm{cross}(P_i,P_{i+1})-\mathrm{cross}(P_i,O)-\mathrm{cross}(O,P_{i+1})+\underbrace{\mathrm{cross}(O,O)}_{0}.$$

对 $i$ 求和，后两项合并：$-\sum_i\mathrm{cross}(P_i,O)-\sum_i\mathrm{cross}(O,P_{i+1})=-\sum_i\mathrm{cross}(P_i,O)+\sum_i\mathrm{cross}(P_{i+1},O)$。两个和式只是下标循环移位（$P_N=P_0$），逐项相消，总和 $0$。故只剩 $\Sigma$ ✓。证毕。

**推论（代码里的精度保险）**：把所有点减去首点 $P_0$，鞋带和不变；但新坐标的量级是"顶点相对首点的位移"，叉积量级 $\le 2D^2$（$D$ 为多边形直径），与绝对坐标位置无关。大偏移小图形（如 $10^9$ 处的单位正方形）不再发生"大数相消吃有效位"。

---

### 引理 3（三角形的鞋带和 = 两倍有向面积）

对三角形 $(A,B,C)$：$\mathrm{cross}(A,B)+\mathrm{cross}(B,C)+\mathrm{cross}(C,A)=\mathrm{cross}(B-A,\ C-A)=2\sigma(A,B,C)$。

*证明*：纯代数展开右边：

$$\mathrm{cross}(B-A,C-A)=\mathrm{cross}(B,C)-\mathrm{cross}(B,A)-\mathrm{cross}(A,C)+\mathrm{cross}(A,A)$$
$$=\mathrm{cross}(B,C)+\mathrm{cross}(A,B)+\mathrm{cross}(C,A)+0,$$

（用了 $-\mathrm{cross}(B,A)=\mathrm{cross}(A,B)$、$-\mathrm{cross}(A,C)=\mathrm{cross}(C,A)$）恰为左边 ✓。再由引理 1（把原点平移到 $A$，引理 2 保证有向面积定义一致），$\frac12\mathrm{cross}(B-A,C-A)=\sigma(A,B,C)$ ✓。证毕。

**注**：这条引理说明"从顶点 $A$ 扇形剖分"与"鞋带和"对三角形是同一件事——为引理 4 的剖分论证铺路。

---

### 引理 4（鞋带公式：$S=\frac12|\Sigma|$ 对一切简单多边形成立）

*证明*：分四步。

**(i) 三角剖分存在。** 经典定理：任何 $N\ge 3$ 顶点的简单多边形可以用**仅以原顶点为端点**的对角线剖分成 $N-2$ 个三角形。证明梗概（对 $N$ 归纳）：$N=3$ 平凡。$N\ge 4$ 时必存在一条内对角线（取凸包上的一个"耳"顶点：若其两邻点连线在多边形内则为耳；否则该三角形内含其他顶点，取其中距该顶点最远者，连线必为内对角线——这是"两耳定理"的标准论证）。沿对角线切成两个更小的简单多边形，各自归纳剖分，合并即得。剖分中每个三角形继承多边形的定向（逆时针多边形的剖分三角形全部逆时针）。

**(ii) 内部边相消。** 把每个三角形的鞋带和（按继承定向绕行）加起来。剖分的每条**内对角线**被恰好两个三角形共享，且两个三角形沿它的绕行方向**相反**（一个 $A\to B$、另一个 $B\to A$），贡献 $\mathrm{cross}(A,B)+\mathrm{cross}(B,A)=0$，全部相消。**边界边**每条只属于一个三角形，方向与多边形边界一致，保留。故

$$\sum_{\text{三角形}T}\bigl(T\text{ 的鞋带和}\bigr)=\Sigma.$$

**(iii) 每个三角形贡献两倍有向面积。** 由引理 3，三角形 $T$ 的鞋带和 $=2\sigma(T)$。多边形逆时针时所有剖分三角形逆时针，$\sigma(T)=+\mathrm{area}(T)$；剖分不重不漏，$\sum_T\mathrm{area}(T)=S$。故 $\Sigma=2S$。多边形顺时针时所有 $\sigma(T)=-\mathrm{area}(T)$，$\Sigma=-2S$。

**(iv) 合并。** 两种定向下都有 $|\Sigma|=2S$，即 $S=\frac12|\Sigma|$ ✓。

**回看第三步的反例**：L 形面积 $5$，从 $(3,0)$ 扇形剖分的四个三角形有向面积 $+1,-2,+1.5,+4.5$，和 $=5$——负号三角形正是"越界"部分，(ii) 的相消机制在扇形剖分（允许三角形越界、带符号）下同样生效，这就是"无符号算出 $9$、有向算出 $5$"的根源。证毕。

---

### 引理 5（定向未知 $\Rightarrow$ 必须取绝对值；$\Phi\ge 0$）

输入顶点序可能顺时针也可能逆时针；$\Phi=B\cdot\frac12|\Sigma|$ 与定向无关，且非负。

*证明*：把顶点序反转（$P_i\mapsto P_{N-i}$），每条边 $(P_i,P_{i+1})$ 变成反向边，$\mathrm{cross}$ 反号，故 $\Sigma\mapsto-\Sigma$（引理 3 的反对称性逐项生效）。由引理 4，$|\Sigma|$ 不变，面积不变 ✓。题面只说"依次为该磁场的各个顶点"，未指定绕向，故代码必须 `fabsl`。又 $B>0$（题面 $0<B\le 10$）、$S\ge 0$，故 $\Phi\ge 0$，输出不会出现负号。证毕。

---

### 引理 6（流式累加不变量）

代码读入首点后置 `px=py=0`（相对坐标原点），每读一点 $(x,y)$ 先减首点、再 `s+=px*y-x*py`、再更新 `px,py`。则读完第 $i$ 个点（$i\ge 1$）后 `s`$=\sum_{j=0}^{i-1}\mathrm{cross}(Q_j,Q_{j+1})$，其中 $Q_j=P_j-P_0$；读完全部 $N$ 点后 `s`$=\Sigma$。

*证明*：对 $i$ 归纳。$i=1$：`px=py=0` 即 $Q_0=(0,0)$，`s+=cross(Q_0,Q_1)=0`，而 $\sum_{j=0}^{0}\mathrm{cross}(Q_j,Q_{j+1})=\mathrm{cross}(Q_0,Q_1)=0$ ✓（首边叉积为 $0$，因为 $Q_0$ 是原点）。设读完第 $i-1$ 点后成立，此时 `px,py`$=Q_{i-1}$；读第 $i$ 点，累加 $\mathrm{cross}(Q_{i-1},Q_i)$，恰好多出第 $i-1$ 项 ✓。读完第 $N-1$ 点后 $s=\sum_{j=0}^{N-2}\mathrm{cross}(Q_j,Q_{j+1})$；缺的闭合边 $\mathrm{cross}(Q_{N-1},Q_0)=\mathrm{cross}(Q_{N-1},0)=0$，故 $s=\Sigma$ ✓（引理 2 保证平移后的 $\Sigma$ 与原 $\Sigma$ 相等）。

退化情形：$N=1$ 时循环不执行，$s=0$；$N=2$ 时 $s=\mathrm{cross}(Q_0,Q_1)=0$——面积 $0$，公式自然成立，无需特判。证毕。

---

### 引理 7（精度与舍入）

用 `long double`（x86 上 80 位，$u=2^{-64}\approx 5.4\times 10^{-20}$）累加，平移后每项 $|\mathrm{cross}(Q_j,Q_{j+1})|\le 2D^2$（$D$ 为多边形直径），输出粒度 $10^{-4}$、进位阈值 $5\times 10^{-5}$，误差安全。

*证明*：浮点累加的标准一阶误差界 $|\hat\Sigma-\Sigma|\le N\cdot u\cdot\sum_j|t_j|$（$t_j$ 为各项）。这是**所有舍入误差同向叠满**的病态上界；实际误差呈随机游走量级 $\approx\sqrt N\cdot u\cdot\max|\text{部分和}|$，而部分和是"折线围成的有向面积"，量级 $\le S+O(D^2)$，远小于 $\sum|t_j|$。代入现实规模（$N\le 10^6$、$D\le 10^6$）：随机游走估计 $\le 10^3\times 5.4\times 10^{-20}\times 10^{12}\approx 5.4\times 10^{-5}$，再乘 $B\le 10$ 后与阈值同量级——但这是把"部分和上界"也取满的双重病态估计；正常数据（$D\le 10^4$、$N\le 10^5$）下误差 $\le 316\times 5.4\times 10^{-20}\times 10^8\times 10\approx 1.7\times 10^{-8}\ll 5\times 10^{-5}$，余量三个数量级以上。若坐标范围极端，平移（引理 2 推论）已把 $D$ 压到图形自身尺寸，是不依赖坐标绝对位置的最后一道保险。

舍入：`fixed<<setprecision(4)` 对二进制值做正确舍入的十进制转换（就近舍入）。题目要求"四舍五入"，两者仅在"第 $5$ 位小数恰为 $5$ 且其后全 $0$"的十进制精确半位上可能分歧；而这样的十进制数（如 $0.00005$）在二进制中不可精确表示，存储值必偏上或偏下，转换结果与四舍五入一致。实测第 6 组（$7.5$）、第 4 组（$1.5$）等边界输出均正确。证毕。

---

### 引理 8（复杂度）

时间 $O(N)$，额外空间 $O(1)$。

*证明*：每点读入 $O(1)$、两次减法、一次叉积（$4$ 乘 $2$ 减）、一次累加，共 $O(N)$。变量只有 `x0,y0,px,py,x,y,s,B` 常数个 `long double`，不存顶点数组——$N$ 的上界未知也无内存风险。证毕。

---

### 定理

程序输出 $\Phi=B\cdot S$ 四舍五入到 $4$ 位小数的值，时间 $O(N)$、额外空间 $O(1)$。

*证明*：引理 1 建立叉积与有向面积的对应；引理 3、4 证明鞋带和的绝对值之半就是简单多边形面积（凸凹通吃）；引理 5 处理定向未知；引理 2 保证平移合法并给出精度保险；引理 6 保证流式累加恰好算出 $\Sigma$（含闭合边为零的退化情形）；引理 7 保证数值误差远低于输出粒度；引理 8 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- reduce to easier problem — 物理公式 $\Phi=B\cdot S$ 已给出，整题归约为纯几何：求简单多边形面积。
- consider easier version — 凸多边形：从顶点扇形剖分成三角形，无符号叉积面积求和即可。
- explore its property — 凹反例（L 形，真实面积 $5$）：核外顶点扇形剖分无符号求和得 $9$，越界三角形被重复计数——失败模式定位。
- classic problem solution — 有向面积修复：鞋带公式 $S=\frac12|\sum\mathrm{cross}(P_i,P_{i+1})|$；平移不变 + 三角剖分内部边相消给出完整证明。
- explore its property — 顶点绕向未知 $\Rightarrow$ 鞋带和符号不定 $\Rightarrow$ 必须绝对值；$B>0\Rightarrow\Phi\ge 0$。
- reduce to easier problem — 流式化：鞋带和只依赖相邻两点 $\Rightarrow$ 只留上一点，$O(1)$ 空间，免疫未知 $N$ 上界。
- explore its property — 平移不变性用作精度保险：减去首点，叉积量级从绝对坐标平方降为图形尺寸平方，大偏移小图形零精度损失。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 顶点数 $N$（题面未给上界） | `int`，读入 | 流式处理，不开数组 |
| `B` | 磁感应强度，$0<B\le 10$ | `long double`，读入 | $\Phi=B\cdot S$ |
| `x0,y0` | 首点 $P_0$ 的绝对坐标 | `long double`，读入 | 平移基准，全程不变 |
| `px,py` | 上一点的**相对坐标** $Q_{i-1}=P_{i-1}-P_0$ | `long double`，初值 $0$ | 首点平移后是原点 |
| `x,y` | 当前点读入后立即减 `x0,y0` | `long double` | 相对坐标 $Q_i$ |
| `s` | 鞋带和 $\Sigma=\sum\mathrm{cross}(Q_j,Q_{j+1})$ | `long double`，初值 $0$ | 有向面积的两倍，可正可负 |
| 答案 | `fabsl(s)/2*B` | `long double` | `fixed<<setprecision(4)` |

### 算法步骤

1. I/O 加速三行；读 $N,B$ 与首点 $(x_0,y_0)$；`px=py=0`（首点的相对坐标）。
2. 对 $i=1..N-1$：读 $(x,y)$，`x-=x0;y-=y0`；`s+=px*y-x*py`；`px=x;py=y`。
3. 闭合边 $\mathrm{cross}(Q_{N-1},Q_0)=0$，无需补加（引理 6）。
4. 输出 `fixed<<setprecision(4)<<fabsl(s)/2*B`。

### 复杂度

- 时间：$O(N)$；额外空间：$O(1)$（常数个 `long double`，不存顶点）。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过、无警告；题面无样例，自造八组手算数据（凸/凹、顺/逆时针、平移、小数坐标、$10^9$ 大偏移）输出 `2.0000 / 2.0000 / 6.0000 / 1.5000 / 1.0000 / 7.5000 / 5.0000 / 1.0000` 全部一致；其中凹 L 形组正是无符号扇形剖分会算错（$9\ne 5$）的反例。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2785 物理1（phsic1）- 磁通量
// 磁通量 = B × 多边形面积；面积用鞋带公式（有向面积取绝对值）。
// 平移到首点原点：鞋带和不变（平移不变性），叉积量级只随多边形自身尺寸，精度更稳。
// 流式读入：只留上一点（相对坐标），O(1) 额外空间，N 再大也不怕。
#include<bits/stdc++.h>
using namespace std;

int n;
long double B;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>B;
	long double x0,y0,px=0,py=0,x,y,s=0;
	cin>>x0>>y0;
	for(int i=1;i<n;++i)
	{
		cin>>x>>y;
		x-=x0;y-=y0;	// 平移不改变鞋带和；首点变为原点
		s+=px*y-x*py;	// 有向叉积累加
		px=x;py=y;
	}
	// 闭合边 cross(末点,首点)=cross(末点,原点)=0，无需显式累加
	cout<<fixed<<setprecision(4)<<fabsl(s)/2*B<<'\n';
	return 0;
}
```

### 代码说明

- **`px=py=0` 是平移后的首点**，不是"未初始化"。第一项累加 `cross(原点,Q_1)=0`，恰好等于首边贡献，循环从 $i=1$ 起步不多不少。
- **闭合边为零是平移的红利**：不平移的版本必须显式补 `s+=px*y0-x0*py`；平移后 $Q_0=(0,0)$，闭合叉积恒 $0$，省一行也省一个出错点。
- `fabsl` 配 `long double`（`fabs` 是 `double` 版，混用会丢精度）；`/2*B` 先除后乘，量级更小。
- 全程无顶点数组：$N$ 的上界题面未给，流式是唯一不需要猜测范围的做法。
- 若想要更高精度保险，可把平移基准从首点换成顶点均值（引理 2 对任意偏移成立），但首点已消除绝对位置量级，本题足够。
