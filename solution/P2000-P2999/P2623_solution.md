# P2623 物品选取 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 背包容量 $m$（$m\le 2000$），$n$ 样物品（$n\le 100$），分三类，参数都在 $[0,200]$：

- **甲（$x=1$）**：给两个参数 $A,B$。你**分配给它体积 $t$**，就获得价值 $v(t)=At^2-Bt$。"每个体积的甲类物品只有一个"——也就是说这一样物品你只能选**一个**体积 $t$（$t$ 可以是 $0$，即不选），不是无限拿。
- **乙（$x=2$）**：价值 $A$、体积 $B$、个数 $C$，最多拿 $C$ 件（多重背包）。
- **丙（$x=3$）**：价值 $A$、体积 $B$，无限件（完全背包），且题目特别保证 **$x=3$ 时 $B>0$**。

求背包能装下的最大价值（体积**不超过** $m$ 即可，不必恰好装满）。

**第一步：先把认识的兩类解决掉。** 子任务里写着"50% 只有乙和丙"，这就是提示：乙丙是**标准混合背包**。

- 丙是完全背包：`for j=B..m: f[j]=max(f[j],f[j-B]+A)`，**正序**枚举容量，让同一件物品被重复使用。题目保证 $B>0$，所以 `j-B<j`，不会自己引用自己、也不会死循环——这句"特别的 $B>0$"就是为完全背包兜底的。
- 乙是多重背包：$C\le 200$，直接拆成 $C$ 件 01 物品是 $O(mC)$，$100\times2000\times200=4\times10^7$ 也能过，但更漂亮的是**二进制拆分**：把 $C$ 拆成 $1,2,4,\dots,2^{k-1},r$ 若干"打包件"，每件当成一个 01 物品（体积 $B\cdot t$、价值 $A\cdot t$），复杂度降到 $O(m\log C)$。

**第二步：甲类才是本题的真正考点。** 甲的体积不固定、价值随体积变，它既不是 01 也不是完全。我盯着 $v(t)=At^2-Bt$ 想：这其实是**泛化物品**——一样物品对应一整条"体积→价值"的曲线，你从曲线上选**一个点** $(t,v(t))$。

于是转移自然写成：对每个容量 $j$，
$$f[j]=\max_{0\le t\le j}\bigl(f[j-t]+v(t)\bigr).$$
这就是**分组背包**的形式：把 $\{(t,v(t)):t=0..m\}$ 看成一个组，组里至多选一件。

**这里我卡了一下：会不会把同一件甲物品用两次？** 如果正序枚举 $j$，算 $f[j]$ 时用到的 $f[j-t]$ 可能已经在本轮被更新过（即已经装过这件甲物品），那就重复了。解决办法和分组背包一模一样：**容量 $j$ 倒序枚举**。倒序时 $f[j-t]$（$t\ge1$，下标更小）还没被本轮碰过，存的是"上一件物品处理完"的旧值，于是这件甲物品只会被选一次。我在第二节用归纳法严格证明了这一点，并写了暴力对拍 3000 组确认。

**第三步：$v(t)$ 会是负的，要不要管？** $v(t)=t(At-B)$，当 $t$ 较小、$At<B$ 时 $v(t)<0$。但转移里 $t=0$ 这一项是 $f[j-0]+v(0)=f[j]+0=f[j]$，即"不选这件甲物品"。$\max$ 里既然有"不选"兜底，负价值的分配永远不会被取到，**不需要特殊处理**。$A=0$ 时 $v(t)=-Bt\le0$，整件物品没用，$\max$ 自动选 $t=0$。

**第四步：算复杂度，确认能过。** 甲类每件 $O(m^2)$（$\sum_{j=0}^{m}j\approx m^2/2$），最坏 100 件全是甲：$100\times\frac{2000\times2001}{2}\approx2\times10^8$。这个量级在 C++ -O2 下大约 0.2~0.4 秒（我实测最坏数据 257 ms），能过。关键优化是**每件甲物品先把 $v[0..m]$ 预处理出来**，内层循环就只剩一次数组读 + 加法 + $\max$，不再重复算 $At^2-Bt$。乙 $O(m\log C)$、丙 $O(m)$ 都远小于甲，可忽略。

**第五步：初始化与答案。** 题目是"体积不超过 $m$"，所以 $f[j]$ 的语义是"容量 $j$ 时的最大价值"，**全初始化为 $0$**（空选合法），答案就是 $f[m]$。不要初始化成 $f[0]=0$、其余 $-\infty$（那是"恰好装满"的语义，虽然最后对 $j$ 取 max 也能得到同样答案，但没必要）。

**第六步：溢出。** 价值上界：所有甲物品分的体积之和 $\le m$，而 $\sum A_it_i^2\le 200(\sum t_i)^2\le 200m^2=8\times10^8$，乙丙贡献更小，总价值 $<10^9$。其实 `int` 也装得下，但中间量 $f[j-t]+v[t]$ 可能到 $1.6\times10^9$，离 `int` 上限 $2.1\times10^9$ 不算远，我直接用 `long long` 图个安稳。

**手造数据核对**（题面无样例）：

| 输入 | 含义 | 答案 |
|---|---|---|
| `1 3` / `3 2 1` | 丙：价值 2 体积 1，容量 3 | $6$（拿 3 件） |
| `1 3` / `1 1 0` | 甲：$v(t)=t^2$，容量 3 | $9$（全给 $t=3$） |
| `1 6` / `2 5 2 3` | 乙：价值 5 体积 2 共 3 件，容量 6 | $15$（拿 3 件） |
| `2 4` / `1 1 0` / `3 1 1` | 甲 $v=t^2$ + 丙价值1体积1，容量4 | $16$（甲独占 $t=4$，凸函数集中更优） |

最后一组很能说明甲的"凸性"：$v(t)=t^2$ 是下凸的，把体积集中给一件比分散给多件更划算（$4^2=16>3^2+1^2=10$）。这也解释了为什么最坏答案恰好是 $200\times2000^2=8\times10^8$。

## 二、思维链：完整证明

### 记号与状态定义

- 容量上限 $m$，物品按输入顺序处理。$f[j]$ 表示**处理完当前若干件物品后、总体积不超过 $j$ 时的最大价值**，$0\le j\le m$。初始 $f[j]=0$（空选）。
- 甲物品参数 $A,B$，价值函数 $v(t)=At^2-Bt$（$t\in[0,m]$，$t=0$ 时 $v=0$）。
- 乙物品参数 $A$（价值）、$B$（体积）、$C$（个数）。
- 丙物品参数 $A$（价值）、$B$（体积，$B>0$）。

整个算法是"逐件物品更新 $f$"，最终答案 $f[m]$。下面证明每一类的更新都**恰好**把该类物品的所有合法选取纳入、且不重复使用。

---

### 引理 1（"体积不超过 $m$"语义与初始化）

把 $f[j]$ 定义为"总体积 $\le j$ 的最大价值"，初始 $f[j]=0$ 合法；处理完所有物品后 $f[m]$ 即答案。

*证明*：空集的体积为 $0\le j$、价值为 $0$，故任何容量 $j$ 下最大价值 $\ge0$，初始 $f[j]=0$ 是"还没放任何物品"时的正确值。题目要求总体积 $\le m$ 的最大价值，正是 $f[m]$ 的定义。又因为容量越大可选方案越多（体积 $\le j$ 的方案集合包含体积 $\le j-1$ 的），$f[j]$ 关于 $j$ 单调不减，故 $f[m]=\max_{j\le m}f[j]$，无需再对 $j$ 取 max。证毕。

---

### 引理 2（甲＝泛化物品／分组背包，倒序保证只用一次）

对一件甲物品，令更新前的数组为 $f^{\text{old}}$。执行
```
for j = m downto 0:
    for t = 1..j:  f[j] = max(f[j], f[j-t] + v[t])
```
（$t=0$ 项是 $f[j]$ 自身，无需写）后，对每个 $j$ 有
$$f[j]=\max_{0\le t\le j}\bigl(f^{\text{old}}[j-t]+v(t)\bigr),$$
即这件甲物品**至多被分配一个体积**。

*证明*：分两点。

**(a) 内层读取的都是旧值。** 固定外层 $j$。内层访问 $f[j-t]$，$t\ge1$，故下标 $j-t<j$。外层 $j$ 从 $m$ 递减，意味着"下标 $<j$ 的格子在本轮尚未被赋值"（本轮只赋值过 $m,m-1,\dots,j+1$，都 $>j$）。所以内层读到的 $f[j-t]$ 全是 $f^{\text{old}}[j-t]$。而 $f[j]$ 自身在内层只是被 $\max$ 累积，初值是 $f^{\text{old}}[j]$（对应 $t=0$）。于是内层结束后
$$f[j]=\max\Bigl(f^{\text{old}}[j],\ \max_{1\le t\le j}(f^{\text{old}}[j-t]+v(t))\Bigr)=\max_{0\le t\le j}(f^{\text{old}}[j-t]+v(t)).$$

**(b) 语义正确（不重不漏）。** 这件甲物品的一个合法选取就是"分配体积 $t$、获得 $v(t)$"，其余体积 $j-t$ 留给**之前的物品**，其最优值恰为 $f^{\text{old}}[j-t]$（归纳假设：$f^{\text{old}}$ 是处理完前面物品后的正确数组）。对所有 $t$ 取 max 即枚举了这件甲物品的全部选取，且每个 $f^{\text{old}}[j-t]$ 不含本物品，故本物品只用一次。$t=0$（不选）也被包含。证毕。

**反证：为什么不能正序。** 若外层 $j$ 正序，算 $f[j]$ 时 $f[j-t]$（$j-t<j$）可能已在本轮更新过，即已含本甲物品；再加 $v(t)$ 就等于把同一件甲物品分配了两次体积，违反"每个体积只有一个 / 至多选一个"。倒序正是切断这种自引用的标准手段（与分组背包"组内至多选一件"同构）。

---

### 引理 3（负价值自动被规避）

甲物品转移中，$v(t)<0$ 的分配永远不会成为最优。

*证明*：$t=0$ 项给出 $f^{\text{old}}[j]+v(0)=f^{\text{old}}[j]$。对任意 $t$ 使 $v(t)<0$，有 $f^{\text{old}}[j-t]+v(t)\le f^{\text{old}}[j-t]\le f^{\text{old}}[j]$（最后一步由引理 1 的单调性 $f^{\text{old}}[j-t]\le f^{\text{old}}[j]$，因 $j-t\le j$）。故这些项都 $\le$ $t=0$ 项，$\max$ 不会取到它们。特别地 $A=0$ 时 $v(t)=-Bt\le0$ 对所有 $t$，整件物品等价于不选。证毕。

---

### 引理 4（乙＝二进制拆分多重背包的正确性）

把个数 $C$ 按 `for(k=1;C>0;k<<=1){t=min(k,C);C-=t;}` 拆成若干件 $t_1,t_2,\dots,t_s$（$\sum t_i=C$），每件当作体积 $B t_i$、价值 $A t_i$ 的 01 物品（倒序更新）。则这些 01 物品的子集选取，与"原乙物品拿 $0..C$ 件"**一一对应价值与体积**。

*证明*：拆分产生的件为 $1,2,4,\dots,2^{j-1}$（若干完整 2 的幂）外加最后一件余量 $r$，其中 $r\le 2^{j}$（因为循环在 `t=min(2^j, 剩余)` 处取走剩余，剩余 $\le 2^j$）。

**可表示性**：完整的 $1,2,\dots,2^{j-1}$ 由二进制可表示 $[0,2^j-1]$ 内任意整数。加上余量 $r$ 后，子集和的取值集合是 $[0,2^j-1]\cup[r,\,r+2^j-1]=[0,2^j-1]\cup[r,C]$。因 $r\le 2^j$，即 $r-1\le 2^j-1$，两段区间**衔接或重叠**，并为 $[0,C]$。故 $0..C$ 的任意件数都能被某个子集精确表示。

**不超额**：每件是 01 物品（倒序更新，引理 2 同理保证每件至多选一次），子集里各件互不相同，总件数 $=\sum_{i\in\text{子集}}t_i\le\sum_i t_i=C$，不会超过 $C$。

**价值体积一致**：选子集 $S$ 对应拿 $\sum_{i\in S}t_i$ 件原物品，体积 $B\sum t_i$、价值 $A\sum t_i$，与拆分件的体积和 $\sum B t_i$、价值和 $\sum A t_i$ 完全相同。故两种模型等价。证毕。

**边界 $B=0$**：拆分件体积全为 $0$、价值 $A t_i\ge0$。01 倒序更新 `f[j]=max(f[j],f[j-0]+A t_i)=f[j]+A t_i`，每件把价值加一次，合计 $A\sum t_i=AC$，即"零体积物品全拿"，正确（$A\ge0$ 保证不会因负值出错）。

---

### 引理 5（丙＝完全背包，正序允许重复，$B>0$ 保证良定义）

对一件丙物品，`for j=B..m: f[j]=max(f[j],f[j-B]+A)`（正序）后，$f[j]$ 等于"在旧方案基础上再拿任意多件该丙物品"的最优值。

*证明*：正序时算 $f[j]$ 用到的 $f[j-B]$（$j-B<j$，因 $B>0$）**已在本轮更新**，即已含本丙物品的若干件；再加一件 $A$、体积 $B$，相当于件数 $+1$。对 $j$ 归纳：$f[j]=\max_{c\ge0,\,cB\le j}(f^{\text{old}}[j-cB]+cA)$。

- $c=0$：$f^{\text{old}}[j]$，是 $f[j]$ 的初值。
- 设 $f[j-B]=\max_{c\ge0}(f^{\text{old}}[j-B-cB]+cA)$（归纳假设，$j-B<j$ 已算）。则 $f[j-B]+A=\max_{c\ge0}(f^{\text{old}}[j-(c+1)B]+(c+1)A)=\max_{c\ge1}(f^{\text{old}}[j-cB]+cA)$。与 $c=0$ 项取 max 即得 $f[j]=\max_{c\ge0}(f^{\text{old}}[j-cB]+cA)$。

$B>0$ 是关键：它保证 $j-B<j$（归纳有基、无自引用），且件数上界 $\lfloor j/B\rfloor$ 有限。若 $B=0$ 且 $A>0$，正序会退化成 $f[j]=f[j]+A$ 反复自加、语义崩坏——题目"特别的 $x=3$ 时 $B>0$"正是排除这一情形。证毕。

---

### 引理 6（逐件处理的无后效性与最终正确性）

按输入顺序逐件更新 $f$，每件更新都只依赖"处理完前面物品"的 $f^{\text{old}}$，故处理完全部 $n$ 件后 $f[m]$ 是全局最优。

*证明*：对物品件数归纳。$0$ 件时 $f[j]=0$ 正确（引理 1）。设处理完前 $i-1$ 件后 $f$ 正确（即 $f[j]$ 是前 $i-1$ 件、体积 $\le j$ 的最大价值）。第 $i$ 件按类别用引理 2／4／5 更新，三者都证明更新后的 $f[j]=\max(\text{不用第 }i\text{ 件},\ \text{用第 }i\text{ 件的某种合法选取}+\text{前 }i-1\text{ 件在剩余容量的最优})$，恰是前 $i$ 件的最优。故归纳成立，$n$ 件后 $f[m]$ 为答案。三类物品的更新互不干扰（每件独立处理），顺序无关正确性。证毕。

---

### 引理 7（值域与溢出安全）

最终价值 $<10^9$，中间量 $f[j-t]+v[t]<1.7\times10^9$，用 `long long` 绝对安全（`int` 亦勉强够，但余量小）。

*证明*：设甲物品分的体积为 $t_1,\dots,t_p$，乙丙占用体积合计 $u$，则 $\sum t_i+u\le m$。甲贡献 $\sum(A_it_i^2-B_it_i)\le\sum A_it_i^2\le 200\sum t_i^2\le 200(\sum t_i)^2\le 200m^2=8\times10^8$（用 $\sum t_i^2\le(\sum t_i)^2$ 及 $A_i\le200$）。乙贡献 $\le$ 每件 $A\cdot C\le200\times200=4\times10^4$（$B=0$ 时）或 $A\cdot\lfloor m/B\rfloor\le200\times2000=4\times10^5$（$B\ge1$ 时），$100$ 件 $\le4\times10^7$。丙贡献 $\le100\times200\times2000=4\times10^7$。合计 $<8\times10^8+8\times10^7<10^9$。中间量 $f[j-t]\le10^9$、$v[t]\le200m^2=8\times10^8$，和 $<1.8\times10^9$。`long long`（$\pm9.2\times10^{18}$）远超，安全。证毕。

---

### 引理 8（复杂度）

时间 $O(nm^2)$（最坏全甲），空间 $O(m)$。

*证明*：甲每件预处理 $v[0..m]$ 为 $O(m)$，双重循环 $\sum_{j=0}^{m}j=m(m+1)/2=O(m^2)$。乙每件二进制拆分 $O(\log C)$ 件、每件 01 更新 $O(m)$，合 $O(m\log C)$。丙每件 $O(m)$。最坏 $n$ 件全甲：$O(nm^2)=100\times2000^2/2\approx2\times10^8$ 次基本运算，实测 257 ms。空间只有 $f[0..m]$、$v[0..m]$ 两个长度 $m+1$ 的数组，$O(m)$。证毕。

---

### 定理

程序输出 $f[m]$，等于体积不超过 $m$ 时的最大价值；时间 $O(nm^2)$、空间 $O(m)$。

*证明*：引理 1 确立语义与答案位置；引理 2、4、5 分别证明甲（泛化／分组）、乙（二进制拆分多重）、丙（完全）三类更新各自不重不漏；引理 3 保证负价值无害；引理 6 把逐件更新串成全局正确性；引理 7 保证数值安全；引理 8 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **discuss by category** — 三类物品分别对应完全背包（丙）、多重背包（乙）、泛化物品（甲），先认领标准的两类。
- **classic problem solution** — 丙完全背包正序 `f[j]=max(f[j],f[j-B]+A)`；题目保证 $B>0$ 正是为它兜底。
- **classic problem solution** — 乙多重背包二进制拆分 $1,2,4,\dots,r$，把 $O(mC)$ 降到 $O(m\log C)$。
- **explore its property** — 甲"价值随分配体积变、每个体积只有一个" $=$ 泛化物品：从曲线 $(t,At^2-Bt)$ 上选一个点。
- **reduce to easier problem** — 泛化物品 $=$ 分组背包（组内至多选一件），$f[j]=\max_t(f[j-t]+v(t))$，**容量倒序**切断自引用。
- **explore its property** — $v(t)$ 可为负，但 $t=0$ 项兜底，$\max$ 自动规避；凸性使体积集中更优。
- **discuss by category** — 初始化全 $0$（"不超过 $m$"语义）、答案 $f[m]$；值域 $<10^9$ 用 `long long`；预处理 $v[]$ 把内层循环压到最简。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 物品件数（$\le100$） | `int`，读入 | 逐件处理 |
| `m` | 背包容量（$\le2000$） | `int`，读入 | 答案在 `f[m]` |
| `f[j]` | 处理完当前物品后、体积 $\le j$ 的最大价值 | `i64[mxm]`，全 $0$ | "不超过"语义，空选合法 |
| `v[t]` | 当前甲物品分配体积 $t$ 的价值 $At^2-Bt$ | `i64[mxm]`，每件重算 | 预处理省掉内层重复乘法 |
| `x` | 当前物品类别 $1/2/3$ | `int`，读入 | 甲/乙/丙 |
| `A,B,C` | 类别参数（甲：$A,B$；乙：$A,B,C$；丙：$A,B$） | `i64`，读入 | 丙保证 $B>0$ |
| `t` | 甲分配的体积 / 乙拆分件的件数 | `int`/`i64` | 甲 $t\in[0,j]$；乙 $t=\min(k,C)$ |
| `vol,val` | 乙拆分件的体积 $Bt$、价值 $At$ | `i64` | 当成一个 01 物品 |
| `mxm` | $2000+5$ | `constexpr int{2005}` | +5 松弛 |

### 算法步骤

1. I/O 加速三行；读 `n,m`；`f` 全局默认 $0$（引理 1）。
2. 逐件读类别 `x`：
   - **甲（x=1）**：读 `A,B`；预处理 `v[t]=A*t*t-B*t`（$t=0..m$）；`for j=m..0` 倒序、`for t=1..j`：`f[j]=max(f[j],f[j-t]+v[t])`（引理 2）。
   - **乙（x=2）**：读 `A,B,C`；`for k=1;C>0;k<<=1`：`t=min(k,C);C-=t;vol=B*t;val=A*t`；`for j=m..vol` 倒序：`f[j]=max(f[j],f[j-vol]+val)`（引理 4）。
   - **丙（x=3）**：读 `A,B`（$B>0$）；`for j=B..m` 正序：`f[j]=max(f[j],f[j-B]+A)`（引理 5）。
3. 输出 `f[m]`。

### 复杂度

- 时间：$O(nm^2)$，最坏 $100\times2000^2/2\approx2\times10^8$，实测 257 ms。
- 空间：$O(m)$，两个长度 $2005$ 的 `i64` 数组，约 32 KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面无样例，手造 4 组（丙/甲/乙/甲丙混合）手算一致；与"递归枚举每件物品选取体积/个数"的独立暴力**端到端对拍 3000 组**（$n\le5,m\le8$，三类随机、含 $B=0$ 与负价值）$0$ mismatch；最坏规模 100 件甲、$m=2000$ 输出 $800000000=200\times2000^2$，与理论上界吻合，运行 257 ms。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2623 物品选取
// 混合背包：甲=泛化物品(分组背包,容量倒序) / 乙=多重(二进制拆分) / 丙=完全(正序)
// f[j]=体积不超过 j 的最大价值，全 0 初始化，答案 f[m]
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxm{2005};

int n,m;
i64 f[mxm],v[mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
	{
		int x;cin>>x;
		if(x==1)	// 甲：泛化物品，体积 t 任选一个，价值 A*t^2-B*t
		{
			i64 A,B;cin>>A>>B;
			for(int t=0;t<=m;++t)
				v[t]=A*t*t-B*t;
			for(int j=m;j>=0;--j)	// 倒序枚举容量：本物品只被选一次
				for(int t=1;t<=j;++t)
					f[j]=max(f[j],f[j-t]+v[t]);
		}
		else if(x==2)	// 乙：多重背包，二进制拆分成 01 物品
		{
			i64 A,B,C;cin>>A>>B>>C;
			for(i64 k=1;C>0;k<<=1)
			{
				i64 t=min(k,C);C-=t;
				i64 vol=B*t,val=A*t;
				for(int j=m;j>=vol;--j)
					f[j]=max(f[j],f[j-vol]+val);
			}
		}
		else	// 丙：完全背包，题目保证 B>0
		{
			i64 A,B;cin>>A>>B;
			for(int j=B;j<=m;++j)
				f[j]=max(f[j],f[j-B]+A);
		}
	}
	cout<<f[m]<<'\n';
	return 0;
}
```

### 代码说明

- **甲的倒序是命门**：`for j=m..0` 保证内层 `f[j-t]` 读到的是上一件物品的旧值，本甲物品只被分配一个体积；写成正序就会重复使用（引理 2 的反证）。
- **`v[]` 预处理**：把 $At^2-Bt$ 提到内层循环外，$2\times10^8$ 次内层只剩"读数组 + 加 + max"，这是最坏数据能压到 257 ms 的关键。
- **乙的 `for(int j=m;j>=vol;--j)`**：`vol` 是 `i64`，`j>=vol` 自动提升比较；`vol>m` 时循环不执行，`vol=0`（$B=0$）时退化为给每个 `f[j]` 加 `val` 一次，恰好等于零体积物品全拿（引理 4 边界）。
- **丙的正序 + $B>0$**：`for j=B..m` 让 `f[j-B]` 已含本物品，实现无限件；题目保证 $B>0$ 杜绝自加死循环。
- **全 $0$ 初始化**：`f` 是全局 `i64` 数组，默认 $0$，正好是"不超过 $j$、空选合法"的初值，不需要显式填 $-\infty$。
- **`long long`**：价值与中间量都 $<1.8\times10^9$，`int` 勉强够但余量小，用 `i64` 一劳永逸。
