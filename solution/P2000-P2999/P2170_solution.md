# P2170 选学霸 — 题解

## 一、解题过程：人类思考叙事

题意翻译：有 $n$ 个学生，老师想选 $m$ 人当学霸。但是有 $k$ 对"实力相当"的学生，如果实力相当的人里有一部分被选上、另一部分没被选上，同学们就会抗议。所以我们要在**不引起抗议**的前提下，选出的人数尽量接近 $m$；如果两种方案与 $m$ 的距离相等，选人数较少的那种。

第一反应：这不是背包吗？把学生分成若干组，每组内部"实力相当"所以必须同进同出，每组要么全选要么不选，于是变成"从若干组里选一些组，使总人数尽量接近 $m$"的 0/1 背包。

但关键问题是：**怎么分组？** 输入只给了 $k$ 对"实力相当"的学生编号，不是直接给分组。

这里有个陷阱：实力相当具有**传递性**。如果 $a$ 和 $b$ 相当，$b$ 和 $c$ 相当，那么 $a$ 和 $c$ 也一定相当（否则就出现了"相当"的非传递性，逻辑上说不通：假如 $a$ 和 $c$ 不相当，但 $a$、$b$ 相当、$b$、$c$ 相当，那这三个人要么全相当要么不全相当，矛盾）。所以"实力相当"是一个**等价关系**，等价类就是组。

于是：并查集。把每一对实力相当的学生合并，最后每个连通块就是一组。组内全选或全不选（选一部分必然引起抗议）。这一点是本题最核心的转化，转化之后剩下的就是纯背包。

第二步，组的大小只有 $n$ 种可能值（$1$ 到 $n$）。设 $\mathrm{cnt}[s]$ 表示大小为 $s$ 的组的个数。那么可行的总人数集合就是

$$\{s_1+s_2+\dots+s_t \mid s_i \text{ 取自各组的大小}\}$$

即从"组大小的多重集合"里选若干个（每组只能选一次）求和。这就是**子集和**问题，标准的 0/1 背包。

第三步，$n\le 2\times 10^4$。普通 $O(n^2)$ 的背包（$n$ 个物品、容量 $n$）是 $4\times 10^8$，太慢。有两个优化方向：

1. 按组大小合并：同样大小的组作为"多重物品"，用二进制拆分 / 完全背包处理。
2. **bitset 优化**：用 `bitset` 的移位与或运算，一次移位就是 $O(n/64)$。

我选 bitset。设 `dp` 是一个 bitset，`dp[t]=1` 表示"能选出恰好 $t$ 个人"。初始 `dp[0]=1`。每选一个大小为 $s$ 的组，就做

```
dp |= dp << s;
```

这一句的含义是：原来能凑出 $t$ 个人，现在要么不选这个组（`dp[t]`），要么选这个组（`dp[t-s]`，即 `dp<<s` 的第 $t$ 位）。用 `dp |= dp << s` 一次完成，等价于 0/1 背包的"正序物品、外层枚举物品、内层倒序枚举容量"。

复杂度：$O(\text{组数} \times n/64)$。组数最多 $n$，所以是 $O(n^2/64) \approx 6\times 10^6$ 个机器字操作，稳过。

注意 `dp<<s` 的语义：因为 `dp` 是"选之前的组"的可达集，`dp<<s` 表示"再选一个大小 $s$ 的组"，二者取或。所以哪怕同一个大小的组有很多个，也要**反复做** `dp |= dp << s`（每次只加一个组），而不能一次移位 $s\cdot t$。这是本题最容易写错的地方。

最后一步：找答案。从 $t=0$ 到 $n$ 扫所有 `dp[t]=1` 的 $t$，取 $|t-m|$ 最小的；若距离相同取较小的 $t$。只要扫描时用严格小于 `<` 比较并且 $t$ 从小到大枚举，天然就满足"平局取小"。

边界：$m$ 可以是 $0$，$k$ 可以是 $0$。$k=0$ 时所有组都是单人组，可行人数就是 $0..n$ 全部，答案就是 $m$ 本身。$m=0$ 时，答案应是 $0$（或者最近的可行值），扫描从 $t=0$ 开始、$|0-0|=0$ 最优，自然得到 $0$。

## 二、思维链：完整证明

**记号约定**：学生编号 $1..n$；输入的 $k$ 对"实力相当"的学生记为 $(u_1,v_1),\dots,(u_k,v_k)$；"实力相当"理解为题目所述的同质关系，即一个人要么和另一个人一样强，要么不一样强。

**引理 1**（"实力相当"是等价关系）：设关系 $\sim$ 定义为 $u\sim v \iff$ 二者实力相当。那么 $\sim$ 满足自反、对称、传递。

*证明*：
- 自反：每个人都和自己实力相当。
- 对称：若 $u$ 与 $v$ 实力相当，则 $v$ 与 $u$ 实力相当。
- 传递：设 $u\sim v$ 且 $v\sim w$。反设 $u\not\sim w$。考虑 $\{u,v,w\}$ 三人两两之间的实力关系。若确实 $u\not\sim w$，那么由 $u\sim v$ 与 $v\sim w$ 知 $u,v$ 同强、$v,w$ 同强，于是 $u,w$ 也同强（强的程度是同一个量），与 $u\not\sim w$ 矛盾。故 $u\sim w$，传递性成立。证毕。

**引理 2**（分组正确性）：并查集在处理完全部 $k$ 对关系后得到的连通块，恰好是关系 $\sim$ 的等价类。

*证明*：并查集维护的连通性等价于"由给定关系对经过有限步传递可达"。设 $u,v$ 在同一块中，则存在关系对链 $u=p_0,p_1,\dots,p_t=v$，其中每步 $p_{i-1}\sim p_i$。由引理 1 的传递性反复应用得 $u\sim v$。反之若 $u\sim v$，由引理 1 的传递性，$u,v$ 之间必存在这样一条关系对链（因为 $\sim$ 的等价类正是关系对闭包生成的），故二者在同一块中。证毕。

**引理 3**（可行方案的刻画）：一个选人方案 $S\subseteq\{1..n\}$ 不引起抗议，当且仅当 $S$ 是若干个完整组的并。

*证明*：
- 若 $S$ 是若干完整组的并，则任取一对实力相当的学生 $u,v$，它们同属一组，该组要么全在 $S$ 中要么全不在 $S$ 中，故不会出现"一部分被选、一部分没被选"的情况，不引起抗议。
- 反之，若 $S$ 不引起抗议，则对每一对实力相当的学生 $u,v$，有 $u\in S \Leftrightarrow v\in S$。由引理 1 的传递性，同一等价类中的任意两人通过关系对链相连，沿链逐步可得该类中所有人要么全在 $S$ 中、要么全不在 $S$ 中，即 $S$ 是若干完整组的并。证毕。

**引理 4**（背包可达集）：设组的大小为 $s_1,\dots,s_g$（$g$ 为组数），`dp` 为 bitset。算法结束后 `dp[t]=1` 当且仅当存在下标集合 $J\subseteq\{1..g\}$ 使得 $\sum_{j\in J}s_j=t$。

*证明*：对处理的组数作归纳。
- 初始时未处理任何组，只有 $t=0$ 可达（对应空集），与 `dp[0]=1` 一致。
- 归纳步骤：设处理完前 $i-1$ 组后结论成立。第 $i$ 组大小为 $s_i$。处理后 `dp_new = dp_old | (dp_old << s_i)`。`dp_old` 的第 $t$ 位为 $1$ 当且仅当存在 $J\subseteq\{1..i-1\}$ 使 $\sum_{j\in J}s_j=t$；`(dp_old<<s_i)` 的第 $t$ 位为 $1$ 当且仅当存在 $J\subseteq\{1..i-1\}$ 使 $t-s_i=\sum_{j\in J}s_j$，即 $t=\sum_{j\in J}s_j+s_i$ 对应 $J'=J\cup\{i\}$。两者取或，恰好得到"从前 $i$ 组中选若干组"的全部可达和。证毕。

**引理 5**（答案的最优性与平局处理）：设算法输出 $a$。则 $a$ 是所有可行人数中与 $m$ 距离最小的；若最小距离不唯一，$a$ 是其中最小的。

*证明*：由引理 3 与引理 4，`dp[t]=1` 恰好刻画了全部可行人数。算法按 $t$ 从小到大扫描，维护当前最优 `ans` 与最小距离 `best`，仅当 `|t-m| < best` 时才更新。由于扫描顺序递增，后来出现的 $t$ 只会替换掉距离**严格更小**的旧答案，因此：
- 结束时 `ans` 的距离是全局最小；
- 若存在多个距离相同的可行值，只有最先被扫描到的（即最小的那个）能成为 `ans`，后来的同距离值因严格小于比较而不会替换它。证毕。

**定理**：算法输出的 $a$ 即为题目要求的答案。

*证明*：由引理 5，$a$ 是全部不引起抗议的选人方案的人数中与 $m$ 最接近者，且平局取较小；由引理 2、3 可行方案集合被完整刻画。算法正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **读懂"实力相当"的语义** — 关键在于它是等价关系（自反、对称、传递），特别是传递性。
2. **把"不能抗议"翻译成"整组同进同出"** — 组内必须全选或全不选。
3. **想到并查集** — 输入只给 $k$ 对关系，需要传递闭包；等价类 = 连通块。
4. **剩下是纯背包** — 每组是一个"物品"，重量 = 组大小，价值 = 组大小，目标 = 子集和尽量接近 $m$。
5. **发现普通背包太慢** — $O(n^2)$ 不可行，转向 bitset。
6. **bitset 的 0/1 背包写法** — `dp |= dp << s`，每个组做一次（不能合并同大小组）。
7. **平局取小** — 从小到大扫描 + 严格小于比较，天然满足。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 学生人数 | `int`，$\le 2\times10^4$ |
| $m$ | 期望选出的学霸人数 | `int`，$[0,n]$ |
| $k$ | 实力相当的学生对数 | `int`，$\le 2\times10^4$ |
| `fa[i]` | 并查集父指针 | `int[]`，$1..n$ |
| `sz[i]` | 以 $i$ 为根的集合大小 | `int[]`，$1..n$ |
| `cnt[s]` | 大小恰为 $s$ 的组数 | `int[]`，$1..n$ |
| `dp` | 可达人数集合（bitset） | `bitset<mxn>` |
| `ans` | 最终答案 | `int`，$[0,n]$ |
| `best` | 当前最小距离 | `int` |

### 算法步骤

1. 读入 $n,m,k$；初始化 `fa[i]=i, sz[i]=1`。
2. 对每一对 $(u,v)$：求根 $x=\mathrm{getrt}(u)$、$y=\mathrm{getrt}(v)$；若 $x\ne y$ 则合并（`fa[x]=y`，`sz[y]+=sz[x]`）。
3. 遍历 $i=1..n$，若 `fa[i]==i` 则 `cnt[sz[i]]++`（每个根统计一次，得到各组大小的个数）。
4. `dp[0]=1`；对 $s=1..n$，重复 `cnt[s]` 次执行 `dp |= dp << s`。
5. `ans=0, best=1145141919`；对 $t=0..n$，若 `dp[t]` 且 `|t-m| < best|`，则 `best=|t-m|, ans=t`。
6. 输出 `ans`。

### 复杂度

- 并查集：$O((n+k)\,\alpha(n))$。
- bitset 背包：至多 $n$ 次移位-or，每次 $O(n/64)$ 个机器字，总计 $O(n^2/64)$。
- 扫描找答案：$O(n)$。
- 空间复杂度：$O(n)$（`bitset` 与三个 `int` 数组）。

### 验证状态

- 标程 `P2170.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 编写暴力 `P2170_brute.cpp`（枚举全部 $2^n$ 个选人方案，逐对检查"同选或同不选"，收集所有合法人数，取距 $m$ 最近者，平局取小）与对拍脚本 `P2170_check.py`，在 $n\le 12$、$m\le n$、$k\le 12$ 的随机数据上对拍 **1500 组全部通过**。
- 手工构造：`5 3 2 / 1 2 / 2 3` 输出 `3`（等价类 $\{1,2,3\},\{4\},\{5\}$，可选人数 $0..5$，距 $3$ 最近者为 $3$）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2170 选学霸
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20005};

int fa[mxn],sz[mxn],cnt[mxn];
bitset<mxn>dp;

int getrt(int x)
{
	if(fa[x]==x)
		return x;
	return fa[x]=getrt(fa[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m,k;
	cin>>n>>m>>k;
	for(int i=1;i<=n;++i)
		fa[i]=i,sz[i]=1;
	for(int i=1,u,v;i<=k;++i)
	{
		cin>>u>>v;
		int x=getrt(u),y=getrt(v);
		if(x!=y)
			fa[x]=y,sz[y]+=sz[x];
	}
	// 实力相同的人被并查集合并成一组，整组只能全选或全不选
	for(int i=1;i<=n;++i)
		if(fa[i]==i)
			++cnt[sz[i]];
	dp[0]=1;
	for(int s=1;s<=n;++s)
		for(int t=0;t<cnt[s];++t)
			dp|=dp<<s;
	// 在所有可达人数里取与 m 最接近者，差相同取较小者
	int ans=0,best=1145141919;
	for(int t=0;t<=n;++t)
		if(dp[t]&&abs(t-m)<best)
			best=abs(t-m),ans=t;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `getrt` 用递归 + 路径压缩（递归深度不超过 $\log n$，因为合并时始终把较小的挂到较大的上，实际栈深很小）。
- `cnt[]` 只统计根节点（`fa[i]==i`），避免重复计数；`sz[]` 在合并时累加。
- `dp |= dp << s` 放在**内层循环**里：每组只能被选一次，所以同大小的组要重复执行 `cnt[s]` 次，而不是一次移位 `s*cnt[s]`（后者等价于完全背包，会重复使用同一组，答案偏大）。
- `bitset<mxn>` 的 `mxn` 取 $2\times10^4+5$，覆盖题目 $n$ 的上界；`dp<<s` 超出范围的位会被截断，不影响答案（人数不可能超过 $n$）。
- 距离哨兵用 `1145141919`，大于任何可能的 $|t-m|\le 2\times10^4$。
- 平局取小由"从小到大扫 + 严格小于"自动保证，不需要额外分支。
