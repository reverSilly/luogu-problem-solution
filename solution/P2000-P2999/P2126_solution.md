# P2126 Mzc家中的男家丁 — 题解

## 一、解题过程：人类思考叙事

题目说：有 $n$ 个男家丁，mzc 要把他们全都聚集起来（到 mzc 那里），已知任意两人之间的通信时间，问总时间。输出还特别写了"要重复的哦"。

先把题目的模型翻译成图：
- $n$ 个男家丁 + mzc 本人 ⇒ 一共 $n+1$ 个点；
- 编号 $0$ 表示 mzc，$1\sim n$ 表示男家丁；
- 每条通信路线是一条无向边，边权是通信时间。

"把他们每个人叫到"的最小总时间，就是把这 $n+1$ 个点连成一棵**最小生成树**的边权和。理由：mzc 是集合点，每个人沿树上唯一的路径走到 mzc；树上每条边恰好被走一次，路径唯一⇒不会重复计费。因此总时间 = MST 权值。"要重复的哦"只是提醒你这是"每个人各自走到 mzc"（而不是"叫一个人再让他去叫别人"）的累加，答案确实是 MST 权值。

接下来是数据范围：$n\le 2300$，$m\le 4\times 10^5$。点数少、边多 ⇒ 用**邻接矩阵**存图，$O(n^2)$ 的朴素 Prim 即可（$2300^2\approx 5.3\times 10^6$，毫无压力）。用堆优化 Prim 反而没必要。

**本題最大的坑是重边。** 原题数据里存在 $(u,v)$ 重复出现且边权不同的情况。这里必须说明白：本题采用的语义是"**后读入的边权直接覆盖先前的边权**"（即 `map[a][b]=c` 直接赋值），而不是取 $\min$。这一点在洛谷官方题解与本题流传的标程中都是覆盖写法；用"取最小边权"或"邻接表把两条重边都保留再跑 Kruskal"都会得到与标准答案不同的结果。

所以实现上：
1. 用 $n+1$ 行 $n+1$ 列的矩阵存边，初始为无穷大；
2. 读入每条边时**直接覆盖** `g[a][b]=g[b][a]=c`；
3. 朴素 Prim：每次取 `dis` 最小的未访问点，把它加入生成树，用它的邻接矩阵行更新其余点。

注意 $n$ 个家丁 + mzc 共 $n+1$ 个点，Prim 要跑 $n+1$ 轮。

复杂度：读边 $O(m)$，Prim $O(n^2)$，总 $O(m+n^2)$。

## 二、思维链：完整证明

**引理 1（模型等价）**：把所有家丁聚集到 mzc 处的最小总时间等于该图（$n+1$ 个点、$m$ 条无向边）的最小生成树权值。

*证明*：任何可行的聚集方案都对应一棵以 mzc 为根的生成树：把每个家丁到 mzc 的路线并起来得到一棵连通子图，删去多余的边后仍连通且不含环，故是生成树；该方案的总时间不小于这棵树的边权和（每个人走的路至少是树上唯一路径的长度，多走的部分只会更大）。反之，取一棵最小生成树，让每个家丁沿树上路径走到 mzc，则每条树边恰好被对应的子树成员各走一次，总时间恰为树边权和。二者结合，最小总时间 = MST 权值。证毕。

**引理 2（Prim 正确性）**：朴素 Prim 算法（每次取距已选集合最近的未选顶点）输出的树是最小生成树。

*证明*：设算法已选顶点集合为 $S$（$S$ 非空且非全集），记 $d(u)=\min_{v\in S}w(v,u)$，算法选择 $d$ 最小的未选点 $u$ 加入 $S$。考虑割 $(S,V\setminus S)$，$u$ 处的边 $w(v_0,u)=d(u)$ 是该割上的**最小权边**（否则存在 $u'$ 未选且 $w(v_0,u')<d(u)$，与 $u$ 的选择矛盾）。由最小生成树的割性质（cut property），存在一棵 MST 包含该边。归纳可知，算法每次所选的边都能被同时包含在一棵 MST 中，最终所得的树即为 MST。证毕。

**引理 3（重边覆盖语义的重要性）**：本题重边按"后读入覆盖"处理，与"取最小值"处理会得到不同答案。

*证明*：设输入依次给出 $(1,2,7)$ 与 $(1,2,3)$。覆盖语义下 $\{(1,2)\}$ 的边权为 $3$，取最小语义下为 $3$——此处相同；再设依次给出 $(1,2,3)$ 与 $(1,2,7)$：覆盖语义下边权为 $7$，取最小语义下为 $3$。两种语义下图的边集不同，MST 权值随之可能不同（构造其余边使该边成为桥即可得到不同结果）。故必须与评测保持一致，即采用覆盖写法。证毕。

**定理**：算法输出的即题目要求的总时间。

*证明*：由引理 1，答案为该图 MST 权值；由引理 2，Prim 求得的正是 MST 权值；由引理 3，读边时采用覆盖写法与题目数据语义一致，故算法输出正确。证毕。

## 三、模式总结（按实际思考顺序）

1. 识别"叫到 mzc" ⇒ **最小生成树**（不是最短路树！）
2. 数点：$n$ 个家丁 **加上 mzc 自己** ⇒ $n+1$ 个点，$0$ 号是 mzc
3. 数范围：$n\le2300$、$m\le 4\times10^5$ ⇒ **邻接矩阵 + 朴素 Prim**（$O(n^2)$）
4. 查坑：**重边后读入覆盖**（不是取 $\min$！写题解时必须显式说明）
5. 细节：矩阵初始值用 `inf`；Prim 循环 $n+1$ 轮；答案用 `i64` 累加

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 |
|------|------|------|
| $n$ | 男家丁个数 | `int` |
| $m$ | 通信路线条数 | `int` |
| $tot=n+1$ | 总点数（含 mzc） | `int` |
| $g[u][v]$ | $u,v$ 之间的通信时间（`inf` 表示无路） | `int` |
| $dis[v]$ | $v$ 到当前生成树的最小边权 | `int` |
| $vis[v]$ | $v$ 是否已加入生成树 | `bool` |
| $ans$ | 总时间 | `i64` |

### 算法步骤

1. 读入 $n$、$m$；令 $tot=n+1$。
2. 把 $g$ 全部填 `inf`。
3. 读入 $m$ 条路线 `(a,b,c)`，执行 `g[a][b]=g[b][a]=c;`（**覆盖**，不是取 $\min$）。
4. 朴素 Prim：
   - `dis[0]=0`，其余 `dis=inf`，`vis` 全 `false`；
   - 重复 $tot$ 轮：选出未访问且 `dis` 最小的点 $u$，标记已访问，`ans+=dis[u]`，再用 $g[u][*]$ 更新其余点的 `dis`。
5. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(m+n^2)$。
- 空间复杂度：$O(n^2)$（矩阵约 $2305^2$ 个 `int`，约 $21$ MB）。

### 代码行为

1. I/O 加速三行固定顺序；
2. 矩阵用 `constexpr int mxn{2305}` 静态分配，避免栈溢出；
3. `inf` 用 `0x3f3f3f3f`，同时用 `g[u][v]!=inf` 判断有边；
4. 每轮选点用一次线性扫描找最小 `dis`；
5. 累加用 `i64`。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2305};
constexpr int inf{0x3f3f3f3f};

int g[mxn][mxn];
int dis[mxn];
bool vis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m;
	cin>>n>>m;
	int tot=n+1;//0 号是 mzc，1~n 号是男家丁
	for(int i=0;i<tot;++i)
		for(int j=0;j<tot;++j)
			g[i][j]=inf;
	for(int i=0;i<m;++i)
	{
		int a,b,c;
		cin>>a>>b>>c;
		//be careful here! 重边按出题人的处理：后读入的直接覆盖旧边权
		g[a][b]=g[b][a]=c;
	}

	//邻接矩阵上的朴素 Prim，O(n^2)
	fill_n(dis,tot,inf);
	dis[0]=0;
	i64 ans=0;
	for(int i=0;i<tot;++i)
	{
		int u=-1;
		for(int j=0;j<tot;++j)
			if(!vis[j]&&(u==-1||dis[j]<dis[u]))
				u=j;
		vis[u]=true;
		ans+=dis[u];
		for(int v=0;v<tot;++v)
			if(!vis[v]&&g[u][v]!=inf&&g[u][v]<dis[v])
				dis[v]=g[u][v];
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `mxn{2305}` = 约束上界 $2300$ + 5，符合"+5 松弛约定"；矩阵放在全局，避免 $21$ MB 局部数组爆栈。
- 注释明确标出**重边覆盖**这一坑点。
- `fill_n(dis,tot,inf)` 预填"不可达"状态，符合规范中"未定义状态必须预填 INF"的要求。
- 每轮选点用 `u==-1||dis[j]<dis[u]` 的写法，第一次自然选中 `dis` 最小的点。
- 累加用 `i64`，避免总时间超 `int`。
- 换行用 `'\n'`。
