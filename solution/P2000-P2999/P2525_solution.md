# P2525 Uim的情人节礼物·其之壱 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N\le 9$，给出 $1..N$ 的一个排列（$N$ 个整数，空格分隔），输出它的**字典序前一个排列**；若它已经是字典序第一个（升序 $1,2,\dots,N$），输出 `ERROR`。题面没有样例，下面的例子都是手算并用程序核对过的。

**第一反应：借前传 P2524 的康托展开。** 先算排名 $r$，再"解排名" $r-1$ 构造排列。能做，但绕：康托展开 $+$ 逆展开两套代码，还要处理 $r=1$。字典序前驱应该有更直接的**构造法**。另一个偷懒选项是 `std::prev_permutation`——它确实就是本题答案，但作为题解，我要把这四步**为什么对**想清楚，再亲手写出来（与 STL 行为逐位一致）。

**第二步：把"前驱"拆成贪心三原则。** 前驱 $=$ **所有比 $a$ 小的排列中最大的那个**。字典序是"高位主导"的：要让结果尽量大，就要

1. **改得尽量靠右**——第一个变小的位置越靠后，结果越大（前面保持与 $a$ 相同的高位压死一切）；
2. **减得尽量少**——在那个位置上，选"可用数字中小于 $a_i$ 的**最大**者"；
3. **尾巴尽量大**——位置定了之后，剩余数字按**降序**排（该集合的最大排列）。

三原则的优先级是严格的：原则 1 压原则 2，原则 2 压原则 3（引理 2、3、4 逐一证明）。现在的问题是：每一步的"可用"到底是什么？

**第三步：哪里"能变小"？——找最右下降位。** 固定前缀 $a_0..a_{p-1}$ 后，位置 $p$ 的可用数字恰为后缀集合 $\{a_p,\dots,a_{n-1}\}$。位置 $p$ 能变小 $\iff$ 后缀里存在比 $a_p$ 小的数。

从右往左找第一个**下降位** $i$（$a_i>a_{i+1}$）：
- $p>i$：$i$ 是最右下降位，所以 $a_{i+1}..a_{n-1}$ **升序**，于是 $a_p$ 是 $\{a_p..a_{n-1}\}$ 的最小值——**没有更小的可用数**，这些位置全都不能变小。
- $p=i$：$a_{i+1}<a_i$，能变小 ✓。
- $p<i$：也许能变小，但由原则 1，改在 $i$ 一定比改在更左边大。

所以**第一个变小位置就是最右下降位 $i$**。顺带得到 ERROR 判据：**没有下降位 $\iff$ 整个排列升序 $\iff$ 它就是 $1,2,\dots,N$（第一个排列）**，没有前驱。

**第四步：在 $i$ 处减多少？——最右的更小者。** 后缀 $a_{i+1}..a_{n-1}$ 升序，所以"小于 $a_i$ 的可用数"里最大的那个，就是**从右往左第一个满足 $a_j<a_i$ 的 $a_j$**（升序序列里越靠右越大）。$j$ 一定存在（$a_{i+1}<a_i$ 兜底）。交换 $a_i,a_j$。

**第五步：尾巴怎么最大？——反转。** 这里有个必须验证的细节：**交换之后缀还是升序吗？** 是：换进位置 $j$ 的新值 $a_i$ 满足"左邻 $a_{j-1}<a_j<a_i$（若 $j-1>i$）"且"右邻 $a_{j+1}>a_i$（若存在；否则 $j$ 就不是最右的更小者）"，其余位置没动。所以后缀仍升序，**反转一次**就变成降序 $=$ 剩余数字的最大排列，$O(N)$，不用排序。

四步合起来：**找最右下降位 → 找最右更小者 → 交换 → 反转后缀**。这正是 `std::prev_permutation` 的实现。

**手造数据核对**（程序输出全部吻合，排列按字典序枚举验证）：

| 输入 | 期望 | 依据 |
|---|---|---|
| `3` / `1 2 3` | `ERROR` | 升序即第一个 |
| `3` / `3 2 1` | `3 1 2` | $\dots,312,321$ |
| `3` / `2 3 1` | `2 1 3` | $\dots,213,231,\dots$ |
| `3` / `3 1 2` | `2 3 1` | $\dots,231,312,\dots$（换首位 $3\to2$，尾巴 $1,3$ 反成 $3,1$） |
| `4` / `2 1 3 4` | `1 4 3 2` | $2134$ 是第 $6$ 个，第 $5$ 个是 $1432$ |
| `4` / `1 2 4 3` | `1 2 3 4` | 最右下降位在末尾，交换即回退一步 |
| `4` / `4 3 2 1` | `4 3 1 2` | 最大排列的前驱 |
| `1` / `1` | `ERROR` | $N=1$ 只有一个排列 |

其中 `3 1 2 → 2 3 1` 最能说明"反转后缀"的必要性：只交换不反转会得到 `2 1 3`，那不是前驱（`2 3 1` 更大且仍小于 `3 1 2`）。

## 二、思维链：完整证明

**记号。** $a=(a_0,\dots,a_{n-1})$ 是 $[n]$ 的排列。字典序与"第一个不同位"记法同 P2524。称 $p$ 为**下降位**若 $p<n-1$ 且 $a_p>a_{p+1}$。前驱 $\mathrm{pred}(a)=\max\{b\in S_n:b<a\}$（若集合非空）。

---

### 引理 0（升序排列唯一且最小；ERROR 判据）

$S_n$ 的字典序最小元是 $\mathrm{id}=(1,2,\dots,n)$，且它是唯一的升序排列。从而：$a$ 无前驱 $\iff a$ 无下降位 $\iff a=\mathrm{id}$。

*证明*：设 $b\ne\mathrm{id}$，取第一个不同位 $p$：$b_0..b_{p-1}=(1,\dots,p)$，故 $b_p\in\{p+1,\dots,n\}$ 且 $b_p\ne p+1$，得 $b_p>p+1=\mathrm{id}_p$，即 $b>\mathrm{id}$。故 $\mathrm{id}$ 严格最小。升序排列唯一：若 $b$ 升序且 $b\ne\mathrm{id}$，同上得 $b>\mathrm{id}$，但 $\mathrm{id}$ 也升序——而升序序列由元素集合唯一决定（归纳：首元必为最小元 $1$，删去后递归），矛盾。故升序 $\iff b=\mathrm{id}$。

"无下降位"即逐位 $a_p\le a_{p+1}$，元素互异故严格升序 $\iff a=\mathrm{id}$。$\{b:b<a\}$ 非空 $\iff a$ 不是最小元 $\iff a\ne\mathrm{id}$。有限全序中非空子集必有最大元，故前驱存在 $\iff a\ne\mathrm{id}$。证毕。

### 引理 1（位置 $p$ 能变小 $\iff p\le i$，其中 $i$ 为最右下降位）

设 $a$ 有下降位，$i=\max\{p:a_p>a_{p+1}\}$。固定前缀 $a_0..a_{p-1}$ 时位置 $p$ 的可用数字集为 $R_p=\{a_p,\dots,a_{n-1}\}$。则：
(a) 对 $p>i$，$a_p=\min R_p$，不存在 $b<a$ 以 $p$ 为第一个不同位；
(b) 对 $p=i$，存在 $v\in R_i$，$v<a_i$（例如 $a_{i+1}$）。

*证明*：$i$ 是最右下降位 ⇒ 对所有 $q>i$（$q\le n-2$）有 $a_q<a_{q+1}$，即后缀 $a_{i+1}..a_{n-1}$ 严格升序。

(a) $p\ge i+1$ ⇒ $a_p..a_{n-1}$ 是升序序列的后缀，仍升序 ⇒ $a_p=\min R_p$。若 $b$ 以 $p$ 为第一个不同位且 $b<a$，需 $b_p<a_p$ 且 $b_p\in R_p$（前缀用掉的数字恰为 $a_0..a_{p-1}$），与 $a_p$ 是最小值矛盾。

(b) $a_{i+1}<a_i$ 且 $a_{i+1}\in R_i$。证毕。

### 引理 2（前驱的第一个不同位恰为 $i$）

$\mathrm{pred}(a)$ 与 $a$ 的第一个不同位是 $i$。

*证明*：记 $B=\{b:b<a\}$（非空，引理 0）。按第一个不同位把 $B$ 分层：$B_p=\{b\in B:\text{首个不同位}=p\}$。

1. **$p>i$ 的层为空**：引理 1(a)。
2. **$B_i$ 非空**：取 $b$ 为"交换 $a_i,a_{i+1}$、其余不动"，则 $b_i=a_{i+1}<a_i$，前缀相同，$b<a$，$b\in B_i$。
3. **层间支配**：$p<i$ 时，任取 $b\in B_p,c\in B_i$：在位置 $p$，$b_p<a_p$ 而 $c_p=a_p$（$c$ 的首个不同位在 $i>p$），且 $p$ 之前两者都等于 $a$ ⇒ $b<c$。

故 $B$ 的最大元必在"最高的非空层" $B_i$ 中（任何更低层的元素都被 $B_i$ 的元素压住；更高层为空）。即 $\mathrm{pred}(a)$ 的首个不同位为 $i$。证毕。

### 引理 3（位置 $i$ 的最优取值 = 最右更小者）

在 $B_i$ 中，最大元 $b$ 满足 $b_i=v^\*\triangleq\max\{v\in R_i:v<a_i\}$；且 $v^\*=a_j$，其中 $j=\max\{q>i:a_q<a_i\}$（从右往左第一个更小者）。

*证明*：**取值上界与可达**：$b\in B_i$ 要求 $b_i\in R_i$ 且 $b_i<a_i$，故 $b_i\le v^\*$；反之 $v^\*$ 可达（把 $v^\*$ 放位置 $i$，其余数字任意排，前缀不变，所得排列 $\in B_i$）。**层内支配**：$b_i<c_i$ 且前缀相同 ⇒ $b<c$（位置 $i$ 是首个不同位），与尾巴无关。故最大元必取 $b_i=v^\*$。

**$v^\*=a_j$**：$R_i=\{a_i\}\cup\{a_{i+1},\dots,a_{n-1}\}$，$a_i\not<a_i$，故候选集为后缀 $\{a_{i+1},\dots,a_{n-1}\}$ 中小于 $a_i$ 者；后缀严格升序（引理 1），其中小于 $a_i$ 的元素构成后缀的一个**前缀段**，该段最右端即最大值。$j=\max\{q>i:a_q<a_i\}$ 正是这段的右端点，$v^\*=a_j$。$j$ 存在：$a_{i+1}<a_i$ 保证集合非空。证毕。

### 引理 4（交换后后缀仍升序；降序是集合的最大排列）

(a) 交换 $a_i,a_j$（$j$ 如引理 3）后，后缀 $a_{i+1}..a_{n-1}$ 仍严格升序。
(b) 一个互异数字集合的字典序最大排列是其**降序**排列。

*证明*：(a) 交换只改动后缀中的位置 $j$（新值 $a_i$），其余位置的相邻关系不变，只需检查 $j$ 的两个邻接：
- 左邻（若 $j-1\ge i+1$）：原升序给 $a_{j-1}<a_j$，又 $a_j<a_i$，故 $a_{j-1}<a_i$（新值）✓。
- 右邻（若 $j+1\le n-1$）：由 $j$ 的**最大性**，$a_{j+1}\not<a_i$；互异排除 $a_{j+1}=a_i$；故 $a_{j+1}>a_i$（新值）✓。
- $j=i+1$ 时无左邻；$j=n-1$ 时无右邻。所有邻接仍升序。

(b) 设 $d$ 为降序排列，$c$ 为该集合任一其他排列，取首个不同位 $p$。$d_0..d_{p-1}=c_0..c_{p-1}$，故两者在 $p$ 处的可用集合相同，都是"剩余元素"；降序的 $d_p$ 是剩余元素的**最大值**，而 $c_p$ 是剩余元素之一且 $c_p\ne d_p$，故 $c_p<d_p$ ⇒ $c<d$。证毕。

### 引理 5（四步构造 = 前驱）

算法输出 $b$：前缀 $a_0..a_{i-1}$ 不变，$b_i=a_j$（交换），$b_{i+1}..b_{n-1}$ 为交换后后缀的反转（降序）。则 $b=\mathrm{pred}(a)$。

*证明*：由引理 4(a)，反转前缀后缀升序，反转后严格降序；由引理 4(b)，它是剩余数字集合的最大排列。故 $b$ 是"首个不同位为 $i$、$b_i=v^\*$"这一类中的最大元（引理 3 的层内支配：值相同则比尾巴，尾巴最大者胜）。

再证 $b=\max B$：任取 $c\in B$，设其首个不同位为 $p$。
- $p>i$：不可能（引理 1(a)）。
- $p<i$：$c<b$（引理 2 的层间支配，$b\in B_i$）。
- $p=i$：$c_i\le v^\*=b_i$。若 $c_i<b_i$，则 $c<b$；若 $c_i=b_i$，则 $c$ 与 $b$ 前 $i+1$ 位相同，尾巴是同一剩余集合的排列，由引理 4(b)，$c$ 的尾巴 $\le b$ 的降序尾巴，故 $c\le b$。

综上 $b$ 是 $B$ 的最大元，即前驱。证毕。

### 引理 6（算法实现与复杂度）

代码的四个步骤恰好计算引理 5 的 $b$；无下降位时输出 `ERROR` 正确；时间 $O(n)$，空间 $O(n)$。

*证明*：`while(i>=0&&a[i]<=a[i+1])--i` 从 $n-2$ 向左找第一个 $a_i>a_{i+1}$，即最右下降位；`i<0` 即无下降位，由引理 0 输出 `ERROR` ✓。`while(a[j]>=a[i])--j` 从 $n-1$ 向左找第一个 $a_j<a_i$；由引理 3 该 $j$ 存在且 $\ge i+1$，循环必在越界前停（$a_{i+1}<a_i$ 兜底）；互异性保证 `>=` 中的等号只在 $j=i$ 时才可能取到，而循环到不了那里。`swap` 与 `reverse(a+i+1,a+n)` 正是引理 5 的交换与反转。每步至多一次线性扫描，$O(n)$；$n\le 9$。证毕。

### 定理

程序在 $a\ne\mathrm{id}$ 时输出 $\mathrm{pred}(a)$，在 $a=\mathrm{id}$ 时输出 `ERROR`；时间 $O(n)$，空间 $O(n)$。

*证明*：引理 0 定存在性与 ERROR 判据；引理 1、2 定首个不同位；引理 3 定该位取值；引理 4 保证交换后后缀仍升序、反转得最大尾巴；引理 5 拼装并证明全局最大性；引理 6 保证代码逐位实现上述构造。证毕。

## 三、模式总结（按实际思考顺序）

- **reduce to easier problem** — 前驱 $=$ "更小者中的最大" $\Rightarrow$ 字典序贪心三原则：改得尽量靠右、减得尽量少、尾巴尽量大（优先级严格递减）。
- **explore its property** — 位置 $p$ 能变小 $\iff$ 后缀有比 $a_p$ 小的数 $\iff p\le$ 最右下降位 $i$；无下降位 $\iff$ 升序 $\iff$ 第一个排列 $\Rightarrow$ `ERROR`。
- **explore its property** — 后缀升序 $\Rightarrow$ "最右的更小者" $=$ "最大的更小者"；交换后后缀**仍**升序（左右邻各验一次），反转即得最大尾巴，免排序。
- **classic problem solution** — `prev_permutation` 四步：找最右下降位 → 找最右更小者 → 交换 → 反转后缀；`std::prev_permutation` 即此实现。
- **discuss by category** — $N=1$ / 已升序输出 `ERROR`；输出空格分隔；与 P2524（康托展开求排名）互为逆运算，但直接构造远比"排名 $-1$ 再解码"简单。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 排列长度（$\le 9$） | `int`，读入 | |
| `a[i]` | 排列第 $i$ 位（$0$-based，值 $1..n$） | `int[mxn]`，读入 | 空格分隔，直接 `cin>>a[i]` |
| `i` | 最右下降位（$a_i>a_{i+1}$） | `int`，从 `n-2` 左扫 | `i<0` ⇒ 升序 ⇒ `ERROR` |
| `j` | $i$ 右侧最右的更小者（$a_j<a_i$） | `int`，从 `n-1` 左扫 | 后缀升序 ⇒ 即"最大的更小者"；$a_{i+1}<a_i$ 保证存在 |
| `mxn` | $9+5$ 松弛 | `constexpr int{15}` | |

### 算法步骤

1. I/O 加速三行；读 `n` 与 `a[0..n-1]`。
2. `i=n-2`；当 `i>=0&&a[i]<=a[i+1]` 时 `--i`（找最右下降位）。
3. 若 `i<0`：输出 `ERROR`，结束。
4. `j=n-1`；当 `a[j]>=a[i]` 时 `--j`（找最右更小者，必停）。
5. `swap(a[i],a[j])`；`reverse(a+i+1,a+n)`（后缀升序 → 降序）。
6. 空格分隔输出 `a[0..n-1]`。

### 复杂度

- 时间：$O(n)$，三次线性扫描 $+$ 一次反转，$n\le 9$。
- 空间：$O(n)$，一个长度 $15$ 的数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面无样例，手造 $8$ 组（升序 ERROR、$N=1$ ERROR、最大排列、最右下降位在末尾/中间/首位、需要反转后缀的 `3 1 2 → 2 3 1`、跨首位回退的 `2 1 3 4 → 1 4 3 2`）全部与手工枚举的字典序一致。普及-级经典构造，证明已闭合（引理 2、3、5 的支配论证），未写对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2525 Uim的情人节礼物·其之壱
// 思路：prev_permutation 四步构造字典序前驱：
//       1) 从右找第一个下降位 i（a[i]>a[i+1]）；没有 ⇒ 已是升序（第一个）⇒ ERROR
//       2) 后缀升序 ⇒ 从右找第一个 a[j]<a[i]，即"小于 a[i] 的最大值"
//       3) 交换 a[i],a[j]（后缀仍升序）
//       4) 反转后缀 ⇒ 降序 = 剩余元素的最大排列
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{15};

int n,a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	int i=n-2;
	while(i>=0&&a[i]<=a[i+1])
		--i;
	if(i<0)
	{
		cout<<"ERROR\n";
		return 0;
	}
	int j=n-1;
	while(a[j]>=a[i])
		--j;
	swap(a[i],a[j]);
	reverse(a+i+1,a+n);
	for(int k=0;k<n;++k)
		cout<<a[k]<<(k+1==n?'\n':' ');
	return 0;
}
```

### 代码说明

- **两个 `while` 的方向都是"从右往左"**：第一个找最右下降位（改得尽量靠右），第二个找最右更小者（减得尽量少）。第二个循环不会越界：$a_{i+1}<a_i$ 保证在 $j=i+1$ 之前必停。
- **`reverse` 的区间是 `[i+1,n)`**：只反转后缀，位置 $i$ 与前缀不动。漏掉反转是最常见错误——`3 1 2` 只交换会得到 `2 1 3`，而正确前驱是 `2 3 1`。
- **`i<0` 的分支覆盖 $N=1$**：此时 `i=n-2=-1`，循环不执行，直接 `ERROR`，无需特判。
- 与 STL 的关系：`prev_permutation(a,a+n)` 返回 `false` 时即本代码的 `ERROR` 分支，四步行为逐位一致；手写是为了让每一步与引理对应，也避免"只会调库不知其所以然"。
- 输出用 `(k+1==n?'\n':' ')` 控制分隔，无行尾多余空格；全程 `'\n'` 不用 `endl`。
