# P2772 寻找平面上的极大点 — 题解

## 一、解题过程：人类思考叙事

题目：平面上 $n$ 个**互不重合**的点（$n\le 5\times10^5$，$0\le x,y\le 10^5$）。若 $x\ge a$ 且 $y\ge b$，称 $(x,y)$ **支配** $(a,b)$——即 $(a,b)$ 落在以 $(x,y)$ 为右上角的闭无限矩形里。不被任何点支配的点叫**极大点**，要求按 $x$ 升序输出全部极大点，格式 `(x1,y1),(x2,y2),...`，逗号分隔、末尾无逗号。题面没有样例，下面的例子都是我自己造并手算核对的。

### 第一步：把"支配"翻译成人话

$(x,y)$ 支配 $(a,b)$，就是 $(x,y)$ 站在 $(a,b)$ 的**右上方（含正右、正上、含边界）**。一个点是极大点，当且仅当它的闭右上象限里**没有别的点**。把所有极大点连起来看，就是点集的"天际线"（skyline）：从左上方往右下方走的一条阶梯轮廓，轮廓上的点谁也压不住谁。

这里有个**题面措辞的坑**必须先定下来：字面上"不会被集合中的**任何一点**所支配"包括它自己——每个点都满足 $x\ge x,y\ge y$，那极大点集合就恒为空，和题面"一定存在若干个点"直接矛盾。所以唯一自洽的读法是：**支配关系只在不同点之间讨论**。又因为题目保证没有重合点，"存在另一个点坐标两维都 $\ge$ 我"就是一个干净的判定条件，不用担心重合点互相支配的歧义。

### 第二步：暴力为什么不行

对每个点枚举其余所有点检查是否支配它：$O(n^2)$。$n=5\times10^5$ 时约 $\frac{n(n-1)}2\approx1.25\times10^{11}$ 次比较，铁定超时。$50\%$ 的部分分 $n\le100$ 倒是随便过——这提示正解和 $n$ 的关系应该是 $O(n\log n)$ 或更好。

### 第三步：简化版——先假设所有 $x$ 互不相同

支配要求 $x$ 坐标不减，所以**如果 $x$ 互不相同，能支配 $p$ 的点一定在 $p$ 的右边**（$x$ 严格更大）。把点按 $x$ 升序排好，从右往左扫，维护"右边所有点的 $y$ 最大值" $M$：

- 当前点 $y>M$：右边没人压得住它，它是极大点；
- 当前点 $y\le M$：右边存在 $y\ge$ 它的点，它被支配。

一次排序 $O(n\log n)$、一次扫描 $O(n)$，这就是经典的"后缀最大值"套路。简化版给了我们全部直觉：**支配是单向的（只来自右方），所以一个后缀最大值就浓缩了所有可能的支配者。**

### 第四步：碰壁——$x$ 相同怎么办？

题目可没说 $x$ 互不相同。只按 $x$ 排序时，同 $x$ 组的内部顺序是任意的，"支配者只在右边"立刻失效。造个反例：$P=\{(1,5),(1,1)\}$。$(1,5)$ 支配 $(1,1)$，唯一极大点是 $(1,5)$。但若排序恰好把 $(1,1)$ 放在最右，从右往左扫先看到 $(1,1)$，此时后缀为空、$M=-\infty$，它会被误判成极大点——**错**。

剖析一下失败原因：同 $x$ 组里，$y$ 小的点排到了 $y$ 大的点右边，于是它的"后缀"漏掉了真正的支配者。修复办法呼之欲出：**加第二关键字 $y$ 升序**，按 $(x,y)$ 字典序排。这样同 $x$ 组内 $y$ 大的在右，任何可能支配我的点（$x$ 更大，或 $x$ 相同但 $y$ 更大）都恰好落在我的后缀里——简化版的逻辑原封不动地回来了。

### 第五步：第二个坑——$y$ 相等也算支配

支配的定义是 $\ge$，含等号。所以 $(2,3)$ 支配 $(1,3)$：$x$ 更大、$y$ 相等。判据必须是**严格** $y>M$，写成 $y\ge M$ 就会把 $(1,3),(2,3)$ 两个都输出。反例虽小，却是本题最容易 WA 的一个符号。

顺带第三个坑：$y$ 可以取 $0$，所以后缀最大值的初值（哨兵）必须**小于 $0$**。若顺手初始化 `mxy=0`，单点 $(0,0)$ 会被误判为"被支配"而输出空串。我用 $-114514$ 作哨兵。

### 第六步：输出顺序——收集是倒着的，怎么办？

题目要 $x$ **升序**，而我们从右往左收集，得到的是 $x$ 降序。直接反转就行吗？得先确认一件事：**极大点之间 $x$ 会不会相同？** 不会——同 $x$ 的两个不同点，$y$ 大的支配 $y$ 小的，两者不可能同时极大。所以极大点的 $x$ 互不相同，收集序列的 $x$ 严格递减，**反转后恰好是严格升序**，正是题目要的顺序。还能顺带看出：极大点按 $x$ 升序排列时 $y$ 严格递减（否则右边的点支配左边的），天际线果然是一条下降阶梯。

另外，排序后最右端的点（$x$ 最大、同 $x$ 中 $y$ 最大）后缀为空，必是极大点，所以答案**永不落空**，与题面"一定存在若干个点"吻合，输出循环不用处理空集特判。

### 第七步：复杂度与一个备选

排序 $O(n\log n)\approx 5\times10^5\times19\approx10^7$ 次比较，扫描 $O(n)$，轻松通过。其实注意到 $x\le10^5$，还可以按 $x$ 桶排、每个 $x$ 只留最大 $y$，做到 $O(n+10^5)$；但排序写法更通用、代码更短，且本题时限下毫无压力，最终选排序。

## 二、思维链：完整证明

### 记号与定义

点集 $P=\{p_0,\dots,p_{n-1}\}$，$p_i=(x_i,y_i)$，**两两不同**（题面保证），$0\le x_i,y_i\le10^5$。

- **支配**：对 $q\ne p$，$q\succ p\iff q.x\ge p.x\ \land\ q.y\ge p.y$。
- **极大点**：$p\in P$ 满足 $\nexists q\in P,\ q\succ p$。
- 把 $P$ 按 $(x,y)$ **字典序升序**排序后仍记为 $p_0,\dots,p_{n-1}$：$i<j\implies x_i<x_j$，或 $x_i=x_j\land y_i<y_j$。
- **后缀最大 $y$**：$M_i=\max\{y_j:j>i\}$，约定 $M_{n-1}=-\infty$。

### 引理 1（题意良定性与极大点存在性）

"任何一点"必须解释为"任何**其它**点"；在此解释下极大点集合非空，特别地，排序后的末位点 $p_{n-1}$ 必为极大点。

*证明*：若允许自己支配自己，则每个点都被自己支配，极大点集合恒空，与题面"一定存在若干个点，它们不会被集合中的任何一点所支配"矛盾。故支配只能在不同点之间讨论，这不是可选约定而是题面自洽的唯一读法。

存在性：考察 $p_{n-1}$。对任意 $j<n-1$，字典序给出 $x_j<x_{n-1}$，或 $x_j=x_{n-1}\land y_j<y_{n-1}$。前者 $x$ 维不满足 $\ge$，后者 $y$ 维不满足 $\ge$（这里用到"无重合点"：同 $x$ 时 $y_j\ne y_{n-1}$，字典序才给出严格 $<$）。两种情形都有 $p_j\not\succ p_{n-1}$，故 $p_{n-1}$ 极大，集合非空。证毕。

### 引理 2（支配者的位置刻画：字典序把支配者全部赶进后缀）

对排序后的任意 $i$ 与 $j\ne i$：
$$p_j\succ p_i\iff j>i\ \land\ y_j\ge y_i.$$

*证明*：分两段。

**（$j<i$ 不可能支配）** 字典序升序给出：$x_j<x_i$，或 $x_j=x_i\land y_j<y_i$。前者 $x_j\ge x_i$ 不成立；后者 $y_j\ge y_i$ 不成立。故 $p_j\not\succ p_i$。

**（$j>i$ 时支配等价于 $y$ 条件）** 字典序给出 $x_j\ge x_i$ 恒成立（$x_j>x_i$，或 $x_j=x_i$ 但此时 $y_j>y_i$）。于是 $p_j\succ p_i$ 的两个条件中 $x$ 维自动满足，只剩 $y_j\ge y_i$；$j\ne i$ 也自动满足。故 $p_j\succ p_i\iff y_j\ge y_i$。

两段合并即得等价式。证毕。

**注**：这条引理是第四节"第二关键字 $y$ 升序"的全部意义——它把二维的支配判定压缩成一维的"后缀里有没有 $y\ge$ 我的点"。若只按 $x$ 排序，$j>i$ 推不出 $x_j\ge x_i$ 之外的任何东西，同 $x$ 组内 $y_j<y_i$ 的点也会混进后缀，等价式立刻崩坏（见引理 6 的反例）。

### 引理 3（极大点判据：严格大于后缀最大值）

$$p_i\text{ 是极大点}\iff y_i>M_i.$$

*证明*：两个方向都从引理 2 出发。

**（$\Leftarrow$）** 设 $y_i>M_i$。对 $j>i$：$y_j\le M_i<y_i$，由引理 2，$p_j\not\succ p_i$；对 $j<i$：引理 2 直接排除。故没有任何点支配 $p_i$，它极大。

**（$\Rightarrow$，证逆否）** 设 $y_i\le M_i$。若 $i=n-1$，$M_i=-\infty$，$y_i\le-\infty$ 不可能，故此情形必有 $i<n-1$，最大值在某个 $j>i$ 处取到：$y_j=M_i\ge y_i$。由引理 2，$p_j\succ p_i$，$p_i$ 不极大。

两方向合起来即等价式。证毕。

**等号归哪边？** 归"被支配"：$y_i=M_i$ 时存在 $j>i$ 使 $y_j=y_i$ 且 $x_j\ge x_i$，按定义（$\ge$ 含等号）这就是支配。所以判据是**严格** $>$，差一个等号就是 WA——对应第一节第五步的反例 $(1,3),(2,3)$。

### 引理 4（扫描不变量：`mxy` 恰好维护 $M_i$）

从右往左的循环中，**处理下标 $i$ 之前**，变量 `mxy` 的值等于 $M_i$（在"与所有合法 $y$ 比较"的意义下，$-\infty$ 用哨兵 $-114514$ 实现）。因此判断 `a[i].y>mxy` 恰好实现引理 3 的判据，`res` 收集到的恰为全体极大点。

*证明*：对 $i$ 从 $n-1$ 递减做归纳。

**基础**：$i=n-1$ 时 `mxy`$=-114514$。因一切 $y_j\ge0>-114514$，对任何合法输入，比较 $y_{n-1}>\texttt{mxy}$ 恒真，与 $M_{n-1}=-\infty$ 时判据 $y_{n-1}>-\infty$ 恒真完全一致；且 $-114514$ 不会与任何真实 $y$ 相等或更大，故在后续所有 $\max$ 与比较中它都表现如 $-\infty$。

**归纳**：设处理 $i$ 前 `mxy`$=M_i$（或等价的哨兵）。处理 $i$ 时：若 $y_i>\texttt{mxy}$，代码令 `mxy`$=y_i=\max(M_i,y_i)$；否则 `mxy` 不变，而 $y_i\le M_i$ 时 $\max(M_i,y_i)=M_i$ 也不变。两种分支都有处理后的 `mxy`$=\max(M_i,y_i)=M_{i-1}$（$i=0$ 时无需再维护）。归纳成立。

于是不变量在处理每个 $i$ 前都成立，判断 `a[i].y>mxy` 就是 $y_i>M_i$，由引理 3，当且仅当 $p_i$ 极大时它被收进 `res`。不重不漏。证毕。

**哨兵为什么不能取 $0$**：$y$ 允许为 $0$。若 `mxy` 初值为 $0$，则 $y_i=0$ 的末位点判据 $0>0$ 为假，被误杀；引理 1 保证末位点必极大，矛盾立刻暴露（单点 $(0,0)$ 输出空串）。哨兵必须严格小于坐标下界 $0$。

### 引理 5（极大点集的结构：$x$ 互异、$y$ 随 $x$ 严格递减）

设 $q,q'$ 是两个不同的极大点。则：

1. $q.x\ne q'.x$；
2. 若 $q.x<q'.x$，则 $q.y>q'.y$。

*证明*：

1. 反证。若 $q.x=q'.x$，因两点不同必有 $q.y\ne q'.y$。不妨 $q.y>q'.y$，则 $q.x\ge q'.x$ 且 $q.y\ge q'.y$，即 $q\succ q'$，与 $q'$ 极大矛盾。
2. 反证。若 $q.y\le q'.y$，结合 $q.x<q'.x$ 得 $q'.x\ge q.x\land q'.y\ge q.y$，即 $q'\succ q$，与 $q$ 极大矛盾。证毕。

**推论（输出顺序正确）**：`res` 按扫描顺序（下标递减）收集极大点。由字典序与结论 1，收集序列的 $x$ **严格递减**；把它反转，得到 $x$ **严格升序**的极大点序列，恰为题目要求的输出顺序。结论 2 说明这条输出序列的 $y$ 严格递减——天际线是一条下降阶梯，可用作肉眼验算的不变量。又由引理 1，`cnt`$\ge1$，输出循环无需空集特判。

### 引理 6（第二关键字的必要性：失败条件的充要刻画）

只按 $x$ 排序（同 $x$ 组内顺序任意）时，扫描算法出错**当且仅当**存在某个同 $x$ 组内，$y$ 较小的点被排在 $y$ 较大的点右边。而按 $(x,y)$ 字典序排序恰好排除一切这种情形。

*证明*：

**失败构造（$\Leftarrow$）**：设同 $x=c$ 组内 $y_a<y_b$，但排序把 $p_a$ 放在 $p_b$ 右边。考察 $p_a$：它的后缀不含 $p_b$。若 $p_a$ 右侧其余点的 $y$ 都 $<y_a$（例如整个点集就是 $\{(c,y_b),(c,y_a)\}$，$p_a$ 是最右端），则扫描判 $p_a$ 极大；但 $p_b\succ p_a$（同 $x$、$y_b>y_a$），矛盾。具体反例：$P=\{(1,5),(1,1)\}$ 排成 $[(1,5),(1,1)]$，输出含 $(1,1)$，错。

**修复验证（$\Rightarrow$）**：若每个同 $x$ 组内 $y$ 升序（即整体字典序），则引理 2 的证明逐字成立——它只用到"$j>i\implies x_j\ge x_i$，且 $x_j=x_i\implies y_j>y_i$"，这正是字典序的定义。于是引理 3、4、5 全部生效，算法正确。证毕。

**等价修复（备选路线）**：同 $x$ 组内只有 $y$ 最大的点可能极大（其余都被它支配），所以也可以先对每个 $x$ 取 $\max y$（桶，$O(n+10^5)$），再对桶做后缀扫描。这与字典序排序在逻辑上等价：都是"把同 $x$ 组的支配关系提前消化掉"。本题采用排序写法。

### 定理（总正确性）

算法输出的序列恰为 $P$ 的全体极大点，按 $x$ 升序排列，格式为 `(x,y)` 逗号分隔、末尾无逗号。

*证明*：引理 2 把支配判定归约为后缀条件；引理 3 给出极大点的充要判据 $y_i>M_i$；引理 4 证明扫描不变量使代码判断与判据逐点一致，故 `res` 不重不漏地收集全体极大点；引理 5 及其推论保证反转后 $x$ 严格升序且非空；输出循环中 `if(i!=cnt-1)cout<<','` 使逗号只出现在相邻两点之间，首尾无多余逗号，每个点按 `'('<<x<<','<<y<<')'` 打印，与题面格式逐字符一致。证毕。

### 复杂度

排序 $O(n\log n)$；扫描每点一次比较、至多一次赋值，$O(n)$；输出 $O(k)$，$k\le n$ 为极大点数。总计 **时间 $O(n\log n)$**，$n=5\times10^5$ 时约 $n\log_2 n\approx9.5\times10^6$ 次比较，远低于时限。两个 `point` 数组各 $5\times10^5\times8$ 字节 $\approx4$ MB，**空间 $O(n)$**，共约 $8$ MB。

## 三、模式总结（按实际思考顺序）

- explore its property — 支配 $=$ 闭右上象限；极大点 $=$ 象限内无其它点，即点集的天际线（Pareto 前沿）。
- explore its property — 题面"任何一点"字面含自身会导致极大点恒空，必须读作"任何其它点"；无重合点保证判定干净。
- consider easier version — 先解"$x$ 互不相同"的简化版：支配者只可能在右方，一个后缀最大值浓缩全部支配信息。
- classic problem solution — 排序 $+$ 从右往左后缀最大值扫描，$O(n\log n)$，天际线问题的标准套路。
- explore its property — 同 $x$ 反例 $(1,5),(1,1)$：只按 $x$ 排序时"支配者只在后缀"失效，失败条件是同组内 $y$ 小者居右。
- reduce to easier problem — 第二关键字 $y$ 升序（字典序）把同 $x$ 情形归约回简化版逻辑；等价地可按 $x$ 桶取 $\max y$。
- discuss by category — $y$ 相等也算支配 $\Rightarrow$ 判据严格 $>$；$y\ge0$ $\Rightarrow$ 哨兵必须 $<0$（取 $0$ 会误杀 $(0,0)$）。
- explore its property — 极大点 $x$ 互异、$y$ 随 $x$ 严格递减 $\Rightarrow$ 倒序收集再反转即得升序输出，且答案非空。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `mxn` | 数组尺寸 | `constexpr int{500005}` | $n\le5\times10^5$，$+5$ 松弛 |
| `a[mxn]` | 排序后的点数组，`a[i]`$=(x_i,y_i)$ | `struct point{int x,y;}` | 按 $(x,y)$ 字典序升序；下标即证明里的 $i$ |
| `res[mxn]` | 从右往左收集的极大点 | 同上 | $x$ 严格递减，输出时倒序 |
| `cnt` | 极大点个数 $k$ | `int`，全局默认 $0$ | 引理 1 保证 $\ge1$ |
| `mxy` | 后缀最大 $y$，即 $M_i$ | `int`，初值 $-114514$ | 哨兵必须 $<0$：$y$ 可取 $0$，初值 $0$ 会误杀 |
| `n` | 点数 | `int` | 读入即得 |

### 算法步骤

1. 读入 $n$ 与 $n$ 个点存入 `a`。
2. 按 $(x,y)$ 字典序升序 `sort`（比较器：$x$ 不同比 $x$，$x$ 相同比 $y$）——第二关键字是引理 6 的修复，不可省。
3. `mxy=-114514`；`for(i=n-1;i>=0;--i)`：若 `a[i].y>mxy`（**严格**大于，引理 3），把 `a[i]` 收进 `res[cnt++]` 并令 `mxy=a[i].y`（引理 4 的不变量维护）。
4. 倒序遍历 `res`（`i=cnt-1..0`），先输出分隔逗号（`i!=cnt-1` 时），再输出 `'('<<x<<','<<y<<')'`。
5. 末尾输出 `'\n'`。

### 复杂度

- 时间：$O(n\log n)$（排序主导），$n=5\times10^5$ 约 $10^7$ 次比较。
- 空间：$O(n)$，两个点数组约 $8$ MB。

### 验证状态

`g++ -std=c++20 -O2 -Wall` 编译无错误无警告；题面无样例，自造 $5$ 组边界数据（一般情形、同 $x$、同 $y$、单点 $(0,0)$、全同 $x$）全部与手算一致；证明闭合（引理 1–6 + 定理），属简单贪心，未做暴力对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2772 寻找平面上的极大点
// 按 (x,y) 字典序升序排序，从右往左扫后缀最大 y；y 严格大于后缀最大值 ⟺ 极大点
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{500005};

struct point{int x,y;}a[mxn],res[mxn];
int n,cnt;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i].x>>a[i].y;
	sort(a,a+n,[](point p,point q){return p.x!=q.x?p.x<q.x:p.y<q.y;});
	int mxy=-114514;	// y>=0，哨兵低于一切合法坐标
	for(int i=n-1;i>=0;--i)
		if(a[i].y>mxy)	// 必须严格 >：x 更大而 y 相等也算支配
		{
			res[cnt++]=a[i];
			mxy=a[i].y;
		}
	for(int i=cnt-1;i>=0;--i)	// 从右往左收集，倒序输出即 x 升序
	{
		if(i!=cnt-1)
			cout<<',';
		cout<<'('<<res[i].x<<','<<res[i].y<<')';
	}
	cout<<'\n';
	return 0;
}
```

### 代码说明

- 比较器 `p.x!=q.x?p.x<q.x:p.y<q.y` 就是 $(x,y)$ 字典序；第二关键字 $y$ 升序保证同 $x$ 组内高点居右，是引理 2 成立的前提，删掉它会在同 $x$ 数据上 WA。
- `mxy` 只在 `a[i].y>mxy` 时赋值，与 `mxy=max(mxy,a[i].y)` 等价（不大于时最大值不变），恰好维护引理 4 的后缀最大值不变量。
- 判据是严格 `>`：`y==mxy` 意味着右边存在同 $y$ 且 $x\ge$ 的点，按定义已被支配。
- `res` 倒序输出即 $x$ 升序（引理 5：极大点 $x$ 互异），无需二次排序；`cnt>=1` 恒成立，逗号逻辑 `i!=cnt-1` 天然处理"只有一个极大点"的情形。
- 坐标本身就是 $0$ 起的数值，不涉及编号换算；全程无浮点、无 `long long` 需求（坐标 $\le10^5$，`int` 足够）。
