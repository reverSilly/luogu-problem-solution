# P2036 [COCI 2008/2009 #2] PERKET — 题解

## 一、解题过程：人类思考叙事

题意：有 $n$ 种配料，第 $i$ 种酸度 $s_i$、苦度 $b_i$。选一个**非空**子集，总酸度 = 选中配料的 $s$ 的**乘积**，总苦度 = 选中配料的 $b$ 的**和**。求 $|总酸度 - 总苦度|$ 的最小值。

$n\le 10$！这直接告诉我们：**枚举所有子集**。$2^{10}=1024$ 个子集，每个子集 $O(n)$ 算一遍，$10^4$ 量级，随便怎么写都过。

所以这题的全部难度在于**怎么把枚举写干净**。

先想暴力版：二进制枚举子集，`mask` 的第 $i$ 位为 1 表示选第 $i$ 种。从 `mask=1` 开始（跳过 `mask=0`，因为必须至少选一种），对每个 `mask` 算乘积与和，取绝对差最小。这个写法非常直白，二重循环里的 `if(mask>>i&1)` 就是"选/不选"的判定。

但我觉得还能更优雅一点：**DFS 逐个决定选不选**。

定义 `dfs(i, prod, sum, used)` 表示"正在处理第 $i$ 种配料，当前已选配料的酸度乘积为 `prod`、苦度和为 `sum`，`used` 表示是否已经选过至少一种"。每一步两个分支：

- 不选第 $i$ 种：`dfs(i+1, prod, sum, used)`；
- 选第 $i$ 种：`dfs(i+1, prod*s[i], sum+b[i], true)`。

走到 $i=n$ 时，若 `used` 为真，说明选了个非空子集，用 $|prod-sum|$ 更新答案。

这个 DFS 有两个好处：
1. **乘积是增量维护的**，不需要每次从头乘一遍；
2. **`used` 标志自然地排除了空集**，而且**剪枝天然生效**——空集那条分支（一个都不选）在叶子处被 `used=false` 直接丢掉。

而且 DFS 天然不需要 `mask` 变量，也不用 `if(mask>>i&1)` 这种位运算技巧，读起来更符合"人类思考"的顺序：一种配料一种配料地考虑。

关于数值范围：题目说"将所有可用食材全部使用产生的总酸度和总苦度小于 $1\times 10^9$"。既然**全部**使用的乘积都小于 $10^9$，那么任何子集的乘积都不会超过它（前提是 $s_i\ge 1$；题面没说 $s_i$ 可以为 0，但即使有 0 也不会变大）。所以 `int` 就够。不过我还是用 `long long` 更保险——万一某个子集的乘积因为 $s_i$ 取值问题超出预期，`i64` 能兜住。

答案是"最小绝对差"，所以用 `llabs(prod-sum)`。

样例 3：$n=4$，$(1,7),(2,6),(3,8),(4,9)$。选后三种：酸度 $2\times 3\times 4=24$，苦度 $6+8+9=23$，差 $1$。枚举全部 15 个非空子集能验证最小值确实是 1。

再验证样例 1：$n=1,(3,10)$，只有一个子集 $\{1\}$，酸度 $3$，苦度 $10$，差 $7$ ✓。

样例 2：$n=2,(3,8),(5,8)$。三个非空子集：$\{1\}$ 差 $|3-8|=5$；$\{2\}$ 差 $|5-8|=3$；$\{1,2\}$ 酸度 $15$ 苦度 $16$ 差 $1$。最小 $1$ ✓。

## 二、思维链：完整证明

**引理 1**：DFS 枚举的叶节点与 $\{1,2,\dots,n\}$ 的所有非空子集一一对应。

*证明*：DFS 在每一层对应一种配料 $i$，恰好分为"选"与"不选"两个分支。从根到任何叶节点的路径唯一确定了一个选择序列，因而唯一确定了一个子集 $\{i : \text{路径在第 } i \text{ 层走了"选"分支}\}$。反过来，给定任意子集 $S$，按 $i=1,2,\dots,n$ 依次在第 $i$ 层走"选"分支（当 $i\in S$）或"不选"分支（当 $i\notin S$），就得到一条唯一的根到叶路径。

这条路径的终点满足 `used=true` 当且仅当 $S\ne\varnothing$：因为 `used` 初始为 `false`，只在走"选"分支时被置为 `true` 且永不复位。故 `used` 为真的叶节点恰对应非空子集，且由上的一一对应性知它们覆盖了全部非空子集，不重不漏。证毕。

**引理 2**：到达叶节点时，`prod` 等于该子集中所有配料酸度的乘积，`sum` 等于该子集中所有配料苦度的和。

*证明*：对 DFS 深度归纳。根节点 `prod=1`（空乘积）、`sum=0`（空和），正确。若在第 $i$ 层的 `prod`、`sum` 正确，走"不选"分支时二者不变，仍对应于"已选集合不含 $i$"的乘积与和；走"选"分支时变为 `prod*s[i]`、`sum+b[i]`，恰好是加入第 $i$ 种后的乘积与和。由归纳法，到任意叶节点时结论成立。证毕。

**引理 3**：算法输出的 `ans` 等于所有非空子集的 $|总酸度 - 总苦度|$ 的最小值。

*证明*：由引理 1，DFS 恰好访问了每个非空子集一次；由引理 2，在该叶节点处计算的 `llabs(prod-sum)` 正是该子集的目标值。算法在所有被访问的叶节点上取 `min`，故最终 `ans` 是所有非空子集目标值的最小值。证毕。

**定理**：算法输出正确。

*证明*：由引理 3 直接成立。证毕。

**复杂度说明**：DFS 节点总数为 $2^{n+1}-1=O(2^n)$，每个节点 $O(1)$ 工作，总时间 $O(2^n)$；递归深度 $n$，空间 $O(n)$。

## 三、模式总结（按实际思考顺序）

1. **读数据范围定方向** — $n\le 10$，$2^{10}=1024$，枚举子集是唯一且显然的选择，不用任何剪枝或 DP。
2. **想清楚枚举的形式** — 两种都行：二进制 `mask` 枚举，或 DFS 逐个选/不选。
3. **选择 DFS 并维护增量** — 乘积与和在递归中增量更新，不用每次重算。
4. **用 `used` 标志处理"至少选一种"** — 空集在叶子处被自然排除，不需要额外特判。
5. **数值范围确认** — 全部食材的乘积都 $<10^9$，子集乘积自然更小，`i64` 兜底即可。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 配料种数 | `int`，$\le 10$ |
| $s_i$ | 第 $i$ 种配料的酸度 | `i64` |
| $b_i$ | 第 $i$ 种配料的苦度 | `i64` |
| `prod` | 已选配料的酸度乘积 | `i64`，初值 $1$ |
| `sum` | 已选配料的苦度和 | `i64`，初值 $0$ |
| `used` | 是否已选过至少一种配料 | `bool` |
| `ans` | 最小绝对差 | `i64`，初值 `inf` |
| `inf` | 答案哨兵 | `i64`，$2^{62}$ |

### 算法步骤

1. 读入 $n$ 与每种配料的 $(s_i,b_i)$。
2. 调用 `dfs(0, 1, 0, false)` 开始枚举。
3. `dfs(i, prod, sum, used)`：
   - 若 $i=n$：`used` 为真则 `ans = min(ans, llabs(prod-sum))`，返回；
   - 分支一（不选）：`dfs(i+1, prod, sum, used)`；
   - 分支二（选）：`dfs(i+1, prod*s[i], sum+b[i], true)`。
4. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(2^n)$，$n\le 10$ 时最多约 $2\times 10^3$ 个节点。
- 空间复杂度：$O(n)$（递归栈）。

### 验证状态

- 标程 `P2036.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面三个样例全部通过：`1 / 3 10` → `7`；`2 / (3,8) (5,8)` → `1`；`4 / (1,7) (2,6) (3,8) (4,9)` → `1`。
- 编写暴力 `P2036_brute.cpp`（二进制枚举子集，与 DFS 写法完全不同）与对拍脚本 `P2036_check.py`，在 $n\in[1,10]$、$s,b\in[1,30]$ 的随机数据上对拍 **3000 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2036 [COCI 2008/2009 #2] PERKET
// 枚举配料子集：n<=10，直接暴力枚举 2^n 种选法
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{15};
constexpr i64 inf{1LL<<62};

int n;
i64 s[mxn],b[mxn];
i64 ans=inf;

void dfs(int i,i64 prod,i64 sum,bool used)
{
	if(i==n)
	{
		if(used) ans=min(ans,llabs(prod-sum));
		return;
	}
	dfs(i+1,prod,sum,used);			// 不选第 i 种
	dfs(i+1,prod*s[i],sum+b[i],true);	// 选第 i 种
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i) cin>>s[i]>>b[i];
	dfs(0,1,0,false);
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `dfs(0,1,0,false)` 的四个参数分别是：当前处理的配料下标、已选酸度乘积、已选苦度和、是否已选过配料。酸度乘积的初值是 `1`（乘法单位元），不是 `0`。
- `used` 只置 `true` 不置 `false`，因此它准确表示"到当前为止是否选过至少一种"，在叶子处即"整个子集非空"。
- `llabs(prod-sum)` 取绝对差；因 `prod`、`sum` 均为 `i64`，`llabs` 的参数类型匹配，不会溢出。
- `ans` 初值用 `1LL<<62`，足够大且不会在 `min` 比较中被误判为有效答案（因为至少有一个非空子集必然被访问到）。
- 数据范围保证全部配料的酸度乘积 $<10^9$，但仍用 `i64` 存储以防万一。
