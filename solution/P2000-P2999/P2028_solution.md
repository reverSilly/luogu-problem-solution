# P2028 龙兄摘苹果 — 题解

## 一、解题过程：人类思考叙事

$n$ 个**互不相同**的苹果，放进 $k$ 个**无标号**、**非空**的篮子里，问有多少种放法，答案对 $p$ 取模。

先把"方案"的含义定清楚：篮子**无标号**，所以 $\{1\},\{2,3,4\}$ 与 $\{2\},\{1,3,4\}$ 是不同的方案（因为苹果的分组不同），但 $\{1,2\},\{3,4\}$ 与 $\{3,4\},\{1,2\}$ 是**同一种**方案（只是把两个篮子调换了顺序）。这正是题目样例解释里列的 7 种：

- $\{1\},\{2,3,4\}$；$\{2\},\{1,3,4\}$；$\{3\},\{1,2,4\}$；$\{4\},\{1,2,3\}$（4 种：拆成 1+3）；
- $\{1,2\},\{3,4\}$；$\{1,3\},\{2,4\}$；$\{1,4\},\{2,3\}$（3 种：拆成 2+2）。

$4+3=7$，$7 \bmod 3 = 1$。✓ 这与样例输出一致。

「把 $n$ 个不同元素划分为 $k$ 个非空无序子集」的方案数，就是**第二类斯特林数** $S(n,k)$。

标签里也直接写了 Stirling 数。所以接下来就是如何计算它。

**递推式**：考虑第 $n$ 个苹果（按编号从小到大依次放入）。

- 情况 A：第 $n$ 个苹果**独占**一个篮子。那么前 $n-1$ 个苹果要放进 $k-1$ 个篮子，方案数 $S(n-1,k-1)$。
- 情况 B：第 $n$ 个苹果**加入某个已有**的篮子。此时前 $n-1$ 个苹果已经放好了 $k$ 个篮子（且不能有另一个篮子是空的，否则苹果就重复算了），选一个篮子放进去，共 $k$ 种选择，方案数 $k\cdot S(n-1,k)$。

两种情况互斥且穷尽，故

$$S(n,k) = S(n-1,k-1) + k\cdot S(n-1,k)$$

边界：$S(0,0)=1$（空集划分为空个篮子，1 种），$S(i,0)=0$（$i>0$ 时不能分成 0 篮子），$S(0,k)=0$（$k>0$）。

**取模的坑**：$p$ **不保证是质数**！所以不能用形如 $S(n,k)=\frac{1}{k!}\sum\cdots$ 的公式——那些公式需要求模逆元，$p$ 不是质数时逆元可能不存在。

但我们的递推式是纯乘加法，**每一步取模即可**，完全不需要除法，对 $p$ 是否为质数没有任何要求。

**复杂度**：$n \le 10000$，$k \le 1000$，直接二维 DP 是 $O(nk) = 10^7$ 个状态，完全可行。而且第 $i$ 层只依赖第 $i-1$ 层，可以滚动成**一维**数组，把空间降到 $O(k)$。

**一维滚动**：令 `f[j]` 表示当前层 $S(i,j)$。转移 `S(i,j) = S(i-1,j-1) + j*S(i-1,j)`，其中 `S(i-1,j-1)` 是上一层的 `f[j-1]`，`S(i-1,j)` 是上一层的 `f[j]`。如果 $j$ **从小到大**更新，`f[j-1]` 已经被本层覆盖了（变成了 $S(i,j-1)$），就错了。所以必须 **$j$ 从大到小**更新：

```text
for j = min(i,k) down to 1:
    f[j] = (f[j-1] + j*f[j]) % p
```

从大到小时，`f[j]` 还没被本层更新（还是 $S(i-1,j)$），`f[j-1]` 也还没被更新（还是 $S(i-1,j-1)$，因为 $j-1 < j$ 还没轮到）。✓

另外每层结束后要 `f[0] = 0`，因为 $S(i,0)=0$（$i\ge 1$）。初始 $f[0] = 1$ 表示 $S(0,0)=1$。

**溢出的坑**：$j\cdot S(i-1,j)$ 中 $j \le 1000$，$S$ 已经取模到 $< p$。而 $p$ 呢？题面说"答案在 64 位整型范围内"，这暗示 $p$ 可能很大。如果 $p$ 能到 $10^{18}$，那 $1000 \times 10^{18} = 10^{21}$ 就超了 `long long`。所以乘法用 `__uint128_t` 更稳。

同理，答案要输出"方法数除以 $p$ 的余数"，即 $S(n,k) \bmod p$，需要 $p$ 用 `unsigned long long` 存（题面说 64 位整型范围）。

再想想 $p$ 的取值范围：题面「保证所有数据 $n \ge k$，且答案在 $64$ 位整型范围内」。「答案在 64 位整型范围内」说的是**取模后的答案**（或者说是真实方案数？）在 64 位内。如果是真实方案数在 64 位内，那 $S(n,k) \bmod p$ 必然也小。但 $p$ 本身的上界题面没写。我用 `u64` 存 $p$，`u128` 做乘法，是最保险的。

**$k>n$ 的情况**：题面保证 $n\ge k$，但代码里还是加了判断输出 0（$k>n$ 时无法分成 $k$ 个非空篮子，方案数为 0）。

极限数据 $n=10000, k=1000$：$10^7$ 次取模运算，实测 0.02 秒，远在 1 秒限制内。

**验证**：写一个暴力——枚举 $n$ 个元素的**受限增长串**（restricted growth string），这是集合划分的经典标准形：令 $a_1=1$，每个 $a_i \in [1, \max(a_1,\dots,a_{i-1})+1]$。$a_i$ 表示第 $i$ 个元素属于第 $a_i$ 个块。这样的串与集合划分一一对应（因为块的编号按其首次出现的顺序递增），统计块数恰为 $k$ 的串数即可。$n\le 10$ 时完全可行。

## 二、思维链：完整证明

**引理 1**：题目所求方案数等于第二类斯特林数 $S(n,k)$。

*证明*：题目要求把 $n$ 个互不相同的苹果放入 $k$ 个无标号、非空的篮子。一个方案等价于把苹果集合 $\{1,\dots,n\}$ 划分成 $k$ 个非空的无序子集族。（"无标号"意味着篮子的顺序不计，"非空"意味着每个子集非空。）第二类斯特林数 $S(n,k)$ 的定义正是"$n$ 个有区别的元素分成 $k$ 个非空无序集合的方案数"。故两者相等。证毕。

**引理 2**（递推式）：$S(n,k) = S(n-1,k-1) + k\cdot S(n-1,k)$。

*证明*：把 $n$ 个元素划分成 $k$ 个非空无序子集。按**元素 $n$ 所在子集的大小**分类：

- **情况 A**：元素 $n$ 所在的子集只有它自己。删去这个单元素子集，剩下的 $n-1$ 个元素恰好被划分成 $k-1$ 个非空无序子集。反之，任取一个 $n-1$ 元素的 $k-1$ 划分，加入单元素子集 $\{n\}$ 就得到一个 $n$ 元素的 $k$ 划分。这是一一对应，计 $S(n-1,k-1)$ 种。
- **情况 B**：元素 $n$ 所在的子集至少有两个元素。删去元素 $n$，其所在子集仍非空，于是剩下 $n-1$ 个元素被划分成 $k$ 个非空无序子集。反之，任取一个这样的划分，有 $k$ 个子集可选，把元素 $n$ 加入其中某一个，得到一个合法的 $n$ 元素的 $k$ 划分。且不同的（划分，加入的子集）不会给出相同结果——因为从结果可以唯一还原出删去 $n$ 后的划分和 $n$ 原本所在的子集。这是一一对应，计 $k\cdot S(n-1,k)$ 种。

两种情况按"元素 $n$ 所在子集是否为单元素"划分，互斥且穷尽所有划分。故递推式成立。证毕。

**引理 3**（取模安全性）：递推过程中每步取模与最终取模的结果相同。

*证明*：递推式中的运算只有加法与乘法，而 $(a+b)\bmod p = ((a\bmod p)+(b\bmod p))\bmod p$，$(ab)\bmod p = ((a\bmod p)(b\bmod p))\bmod p$。因此由归纳法，把中间结果替换为模 $p$ 的余数不改变最终结果的余数。证毕。

**引理 4**（一维滚动的等价性与正确性）：按 $j$ 从大到小更新 `f[j] = (f[j-1] + j*f[j]) % p`，并在每层结束时置 `f[0]=0`，则第 $i$ 层结束后 `f[j]` 等于 $S(i,j) \bmod p$（对 $j\le \min(i,k)$）。

*证明*：考察第 $i$ 层中下标为 $j$ 的更新时刻。由于 $j$ 从 $\min(i,k)$ 递减到 1，当处理 $j$ 时：

- 下标 $j$ 尚未在本层被写过（因为本层只写 $j' \ge j$ 的位置，且 $j$ 是当前值），故 `f[j]` 仍持有上一层的值 $S(i-1,j)\bmod p$；
- 下标 $j-1$ 也尚未在本层被写过（$j-1 < j$，还没轮到），故 `f[j-1]` 仍持有上一层的值 $S(i-1,j-1)\bmod p$。

（当 $j-1=0$ 时，`f[0]` 在本层末尾才被置 0，故更新时刻它仍是上一层的 $S(i-1,0)$。）

因此更新结果为 $(S(i-1,j-1) + j\cdot S(i-1,j)) \bmod p = S(i,j)\bmod p$（引理 2、3）。

再看不更新到的下标：$j > \min(i,k)$ 的位置在第 $i$ 层不被写入，它们保留的是更早的值。但 $S(i,j)=0$（当 $j>i$ 时无法把 $i$ 个元素分成 $j$ 个非空块），这些位置最终不被使用；实现上这些位置从 $j=i+1$ 起每次都会被正确写入，故不影响答案 $f[k]$（$k\le n$ 时 $f[k]$ 在第 $n$ 层被正确写入）。

关于 `f[0]`：初值为 $S(0,0)=1$；第 $i\ge 1$ 层后应置为 $S(i,0)=0$，实现中每层末尾置 0，符合定义。证毕。

**引理 5**（暴力枚举的正确性）：受限增长串与集合划分一一对应，且其块数等于划分中的子集个数。

*证明*：给定一个划分 $\{B_1,\dots,B_k\}$，按各子集中最小元素的升序重新编号为 $B_1,B_2,\dots,B_k$（这样编号是唯一的）。令 $a_i$ 为元素 $i$ 所属子集的新编号。则 $a_1=1$，且 $a_i \le 1+\max(a_1,\dots,a_{i-1})$：因为元素 $i$ 所属子集的编号不超过"前 $i-1$ 个元素中出现过的最大编号 + 1"（若 $i$ 引入新子集则为新编号，否则为其所属旧子集的编号）。同时 $a_i\ge 1$。

反之，给定一个满足 $a_1=1$、$a_i\in[1,\max(a_1,\dots,a_{i-1})+1]$ 的串，按 $a_i$ 把元素 $i$ 分入第 $a_i$ 组，则每一组非空（因为编号 $j$ 首次出现时必然来自"最大值 + 1"），且组编号按首次出现顺序递增，故这种编号是唯一的——这正是划分的规范表示。

两方向互为逆，故一一对应。而编号 $j$ 首次出现的次数即为组数，也即串中最大值 $\max a_i$ 等于块数。证毕。

**定理**：算法输出的是所求方案数对 $p$ 取模的结果。

*证明*：由引理 1，所求即 $S(n,k)$；由引理 2，递推式正确；由引理 3，取模不改变结果；由引理 4，一维滚动实现与二维 DP 等价且计算正确。故输出 $S(n,k)\bmod p$ 正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **把方案翻译成数学对象** — 「无标号、非空篮子」= 把 $n$ 个不同元素划分成 $k$ 个非空无序子集 = 第二类斯特林数 $S(n,k)$。
2. **用样例解释校验理解** — 样例列出 7 种方案（4 种 1+3、3 种 2+2），正好是 $S(4,2)=7$，确认"篮子无标号"的含义。
3. **推导递推式** — 第 $n$ 个元素独占一块（$S(n-1,k-1)$）或加入已有的某块（$k\cdot S(n-1,k)$），互斥穷尽。
4. **警惕 $p$ 不一定是质数** — 不能用含除法/逆元的斯特林数闭式公式；纯乘加递推每步取模即可。
5. **滚动数组降空间** — 层间只依赖上一层，$O(nk)$ 时间换 $O(k)$ 空间。
6. **一维更新的方向** — $j$ 必须**从大到小**，否则 `f[j-1]` 会被本层覆盖。
7. **溢出防护** — $j\cdot f[j]$ 可能超 64 位，用 `__uint128_t`；$p$ 用 `unsigned long long`。
8. **验证方式** — 受限增长串枚举集合划分（引理 5），与 DP 对拍。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 苹果个数 | `int`，$\le 10000$ |
| $k$ | 篮子个数 | `int`，$\le 1000$，且 $k\le n$ |
| $p$ | 取模的模数 | `unsigned long long`（64 位整型范围） |
| $S(i,j)$ | 把 $i$ 个不同元素划分成 $j$ 个非空无序子集的方案数 | 概念量 |
| `f[j]` | 滚动数组，当前层的 $S(i,j)\bmod p$ | `unsigned long long[]`，长度 $k+1$ |
| `val` | 单次转移的中间值 | `__uint128_t` |

### 算法步骤

1. 读入 $n, k, p$。
2. 初始化 `f[0] = 1 % p`（表示 $S(0,0)=1$），其余为 0。
3. 对 $i = 1, 2, \dots, n$：
   1. 令 $up = \min(i,k)$。
   2. 对 $j = up, up-1, \dots, 1$（**从大到小**）：
      - `val = (u128)j * f[j] + f[j-1]`；
      - `f[j] = (u64)(val % p)`。
   3. 令 `f[0] = 0`（因为 $S(i,0)=0$）。
4. 若 $k>n$，输出 0；否则输出 `f[k]`。

### 复杂度

- 时间复杂度：$O(n\cdot k)$，最多约 $10^7$ 次常数运算。
- 空间复杂度：$O(k)$。

### 验证状态

- 标程 `P2028.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面样例 `4 2 3` 输出 `1`，与官方一致（$S(4,2)=7$，$7\bmod 3=1$）。
- 编写暴力 `P2028_brute.cpp`（DFS 枚举 $n$ 个元素的受限增长串，即所有集合划分的规范表示，统计块数恰为 $k$ 的方案数）与对拍脚本 `P2028_check.py`，在 $n\le 10$、$k\le n$、$p\in\{1,2,3,7,100,999983,10^9+7,\text{随机}\}$ 的随机数据上对拍 **200 组全部通过**。
- 极限数据 $n=10000, k=1000, p=10^9+7$ 实测运行时间约 $0.01$ 秒，满足题面 1 秒限制；其结果另用独立的 Python 二维 DP 校验一致（$963964536$）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2028 龙兄摘苹果
// 第二类斯特林数 S(n,k)：S(i,j)=S(i-1,j-1)+j*S(i-1,j)，模 p 递推
#include<bits/stdc++.h>
using namespace std;
using i64=long long;
using u64=unsigned long long;
using u128=__uint128_t;

constexpr int mxn{10005};

int n,k;
u64 p;
u64 f[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k>>p;
	f[0]=1%p;
	for(int i=1;i<=n;++i)
	{
		int up=min(i,k);
		for(int j=up;j>=1;--j)
		{
			//f[j]=f[j-1]+j*f[j]，用 128 位防溢出
			u128 val=(u128)j*f[j]+f[j-1];
			f[j]=(u64)(val%p);
		}
		f[0]=0;
	}
	if(k>n)
		cout<<0<<'\n';
	else
		cout<<f[k]<<'\n';
	return 0;
}
```

### 代码说明

- 滚动数组 `f` 长度取 `mxn = 10005`，覆盖 $k\le 1000$ 的需求（同时也留出了 `n` 的量级余量）。
- 内层循环 `for(int j=up;j>=1;--j)` **必须从大到小**：从小到大更新时 `f[j-1]` 已被本层覆盖，会算成 $S(i,j-1)+j\cdot S(i,j-1)$，结果错误。
- `(u128)j*f[j]+f[j-1]` 把乘法提升到 128 位，避免 $j\le 1000$ 与接近 $2^{64}$ 的 `f[j]` 相乘时溢出 `unsigned long long`。
- `f[0]=1%p` 处理了 $p=1$ 的极端情况（此时所有余数均为 0），避免 `1 % 0` 之类的问题。
- 每层末尾 `f[0]=0` 对应 $S(i,0)=0$（$i\ge 1$）。
- `k>n` 时输出 0（虽然题面保证 $n\ge k$，代码仍作防御性处理）。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
