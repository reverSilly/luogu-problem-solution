# P2074 危险区域 — 题解

## 一、解题过程：人类思考叙事

题目：城市里有 $N\times M$ 个街区，每个街区有坐标 $(x,y)$。有 $k$ 个可能的炸弹位置，炸弹威力为 $t$，即所有到该炸弹的**直线距离**不超过 $t$ 的街区都受威胁。问最坏情况下（炸弹放在哪个候选位置）有多少街区受威胁。

数据范围：$N,M\le10^5$，$k\le50$，$t\le300$。

**第一个直觉：枚举每个候选炸弹位置，统计圆内的格点数。** 这是标准的"圆内整点计数"。

**第二个问题：怎么枚举？** 最直接的想法是遍历整个 $N\times M$ 网格，对每个格子算它到炸弹的距离。每个炸弹 $O(NM)=10^{10}$，$k$ 个炸弹更完蛋，太慢。

**关键观察：$t\le300$！** 炸弹威力只有 300，受威胁的街区必然在炸弹周围 $300$ 的范围内。也就是说，对一个炸弹，只需要看它周围 $[-t,t]\times[-t,t]$ 这个 $(2t+1)^2=601^2\approx36$ 万的方框，再从中挑出圆内的格子。$k=50$ 个炸弹，总共 $50\times36$ 万 $=1.8\times10^7$ 次判断，秒过。

所以：**双重循环枚举炸弹位置，内层只枚举相对偏移 $(\Delta x,\Delta y)\in[-t,t]^2$，用距离平方判断是否在圆内。**

**第三个问题：圆内格点的判定。** 直线距离不超过 $t$，即
$$\sqrt{\Delta x^2+\Delta y^2}\le t \;\Longleftrightarrow\; \Delta x^2+\Delta y^2\le t^2 .$$
用平方比较，全程整数，不存在精度问题（这比用 `sqrt` 再比较更稳）。

**第四个问题：越界。** 街区坐标 $x\in[1,N]$、$y\in[1,M]$。枚举出来的 $(x+\Delta x, y+\Delta y)$ 可能超出范围，要跳过。注意题面表格里坐标是 **(行, 列)**：第一行是 $x=1$，第一列是 $y=1$。所以 $x$ 的范围是 $[1,N]$，$y$ 的范围是 $[1,M]$。

**第五个问题：答案范围。** 一个半径 300 的圆最多包含多少整点？约 $\pi t^2\approx2.8\times10^5$，`int` 装得下。但保险起见用 `long long` 存计数——不，其实 $\pi\cdot300^2\approx282743$，`int` 完全够。不过 $N\times M$ 上限是 $10^{10}$，虽然本题受 $t$ 限制不会到那么大，但用 `i64` 更稳。我用 `i64`。

**最后：取最大值。** 题目问"最坏情况下"，所以答案是所有候选位置受威胁街区数的**最大值**。注意每个候选位置要**独立**统计（各自一个圆），而不是所有圆的并集。

样例：`4 5 3 2 / 1 2 / 3 4 / 4 5`，即 $N=4,M=5,k=3,t=2$，三个候选位置 $(1,2),(3,4),(4,5)$。

算一下 $(3,4)$（$x=3,y=4$）：$t=2$，圆内满足 $\Delta x^2+\Delta y^2\le4$ 的整点有 $(\pm1,0),(0,\pm1),(\pm2,0),(0,\pm2),(\pm1,\pm1)$ 共 12 个。但要落在 $x\in[1,4]$、$y\in[1,5]$ 内：
- $\Delta x=-2$ → $x=1$ ✓；$\Delta x=+2$ → $x=5$ ✗（超出 $N=4$）
- $\Delta y=-2$ → $y=2$ ✓；$\Delta y=+2$ → $y=6$ ✗（超出 $M=5$）
- $(\pm1,\pm1)$：$\Delta x=-1$→$x=2$✓，$\Delta x=+1$→$x=4$✓；$\Delta y=-1$→$y=3$✓，$\Delta y=+1$→$y=5$✓，四种全在范围内。

所以 $(3,4)$ 的计数 = $(0,0),(±1,0),(0,±1),(\pm1,\pm1)$ = 1+2+2+4 = 9，加上 $\Delta x=-2$ 的 $(\pm2,0)$：$(-2,0)$✓、$(0,-2)$✓ → 11。答案 11 ✓ 与样例一致。

思路完全清晰，$O(k t^2)$。

## 二、思维链：完整证明

**引理 1**：对某个候选炸弹位置 $(b_x,b_y)$，街区 $(x,y)$ 受威胁当且仅当 $(x-b_x)^2+(y-b_y)^2\le t^2$。

*证明*：题目定义"所有到这个街区的直线距离小于等于 $t$ 的街区都会受威胁"。街区 $(x,y)$ 到炸弹 $(b_x,b_y)$ 的直线距离为 $\sqrt{(x-b_x)^2+(y-b_y)^2}$。因距离非负，$\sqrt{u}\le t$ 等价于 $u\le t^2$，即 $(x-b_x)^2+(y-b_y)^2\le t^2$。证毕。

**引理 2**：任何受威胁的街区 $(x,y)$ 必满足 $|x-b_x|\le t$ 且 $|y-b_y|\le t$。

*证明*：由引理 1，$(x-b_x)^2+(y-b_y)^2\le t^2$。因平方项非负，故 $(x-b_x)^2\le t^2$，即 $|x-b_x|\le t$；同理 $|y-b_y|\le t$。证毕。

**引理 3**：只枚举 $\Delta x,\Delta y\in[-t,t]$ 不会漏掉任何受威胁的街区。

*证明*：由引理 2，受威胁街区对应的 $(\Delta x,\Delta y)=(x-b_x,y-b_y)$ 必落在 $[-t,t]^2$ 内，而该范围被完整枚举。证毕。

**引理 4**：算法对每个候选炸弹位置统计出的 `cnt` 等于该位置的受威胁街区数。

*证明*：由引理 1，算法判定格子受威胁的条件与定义等价；由引理 3，所有可能受威胁的格子都被枚举到；由引理 1 的逆否（不在 $[-t,t]^2$ 内的格子不受威胁），枚举范围外无需考虑。边界检查 `1<=x<=n, 1<=y<=m` 剔除了不存在的街区，且每个街区恰好被枚举一次（偏移与街区一一对应）。故 `cnt` 恰为受威胁街区数。证毕。

**定理**：算法输出的最大值即为题目所求。

*证明*：题目问"最坏情况下会有多少街区受威胁"，而炸弹只能放在给定的 $k$ 个候选位置之一。由引理 4，算法精确算出每个候选位置的受威胁街区数，取这些数的最大值即最坏情况下的答案。证毕。

## 三、模式总结（按实际思考顺序）

1. **先看数据范围里的关键小量** — $N,M$ 高达 $10^5$ 看着吓人，但 $t\le300$ 才是关键：受威胁范围只在炸弹周围 $t$ 之内。
2. **把"全图扫描"改成"局部窗口扫描"** — 从 $O(NM)$ 降到 $O(t^2)$，这是本题的全部难度所在。
3. **距离比较用平方** — $\Delta x^2+\Delta y^2\le t^2$，整数运算，零精度问题。
4. **注意题面坐标是 (行, 列)** — 表格里第一行是 $x=1$、第一列是 $y=1$，所以 $x$ 范围 $[1,N]$、$y$ 范围 $[1,M]$，别搞反。
5. **边界检查不能省** — 圆心靠边时，一半的圆在网格外。
6. **"最坏情况"= 取最大值** — 每个候选位置独立统计其圆内格点，再取 max，不是求并集。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 街区行数（$x$ 方向） | `int`，$\le10^5$ |
| $m$ | 街区列数（$y$ 方向） | `int`，$\le10^5$ |
| $k$ | 候选炸弹位置数 | `int`，$\le50$ |
| $t$ | 炸弹威力（半径） | `int`，$\le300$ |
| `bx[i], by[i]` | 第 $i$ 个候选炸弹的坐标 | `int`，$x\in[1,n]$，$y\in[1,m]$ |
| $\Delta x,\Delta y$ | 街区相对炸弹的偏移 | `int`，$\in[-t,t]$ |
| `cnt` | 当前炸弹的受威胁街区数 | `i64` |
| `ans` | 所有候选中的最大受威胁街区数 | `i64` |

**初始化约定**：`bx[]`、`by[]` 为全局数组，默认全 0，读入时逐个覆盖；`ans` 在 `main` 内显式初始化为 0。

### 算法步骤

1. 读入 $n,m,k,t$。
2. 读入 $k$ 个候选炸弹坐标到 `bx[]`、`by[]`。
3. 初始化 `ans=0`。
4. 对 $i=1\ldots k$：
   - 初始化 `cnt=0`；
   - 枚举 $\Delta x=-t\ldots t$，令 $x=bx[i]+\Delta x$，若 $x<1$ 或 $x>n$ 则跳过；
   - 枚举 $\Delta y=-t\ldots t$，令 $y=by[i]+\Delta y$，若 $y<1$ 或 $y>m$ 则跳过；
   - 若 $\Delta x^2+\Delta y^2\le t^2$ 则 `++cnt`；
   - `ans=max(ans,cnt)`。
5. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(k\,t^2)$。每个炸弹枚举 $(2t+1)^2$ 个偏移，最大 $50\times601^2\approx1.8\times10^7$ 次判断。
- 空间复杂度：$O(k)$，存储候选炸弹坐标（不使用 $N\times M$ 的网格）。

### 验证状态

- 标程 `P2074.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `4 5 3 2 / 1 2 / 3 4 / 4 5` 输出 `11`，与官方一致。
- 编写独立暴力 `P2074_brute.cpp`（对每个炸弹**遍历整个 $N\times M$ 网格**，用 `sqrt` 浮点开方判断，坐标范围与枚举方式都与标程完全不同）与对拍脚本 `P2074_check.py`：随机生成 $1\le n,m\le12$、$1\le k\le8$、$0\le t\le6$ 的数据，并附加"$t=0$ / 炸弹在角落 / 炸弹在正中间 / 官方样例"等极端构造，**对拍 2004 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{55};

int n,m,k,t;
//bomb[i]：第 i 个候选炸弹位置
int bx[mxn],by[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>k>>t;
	for(int i=1;i<=k;++i)
		cin>>bx[i]>>by[i];

	i64 ans=0;
	for(int i=1;i<=k;++i)
	{
		i64 cnt=0;
		//只枚举炸弹周围的 (2t+1)^2 个格子
		for(int dx=-t;dx<=t;++dx)
		{
			int x=bx[i]+dx;
			if(x<1||x>n)
				continue;
			for(int dy=-t;dy<=t;++dy)
			{
				int y=by[i]+dy;
				if(y<1||y>m)
					continue;
				if(dx*dx+dy*dy<=t*t)
					++cnt;
			}
		}
		ans=max(ans,cnt);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `bx[]`、`by[]` 为全局数组，默认 0；因 $k\le50$，数组开到 55 足够。
- 计数用 `i64`：`cnt` 与 `ans` 都用 `long long`，避免"格子总数乘以候选数"这类中间量溢出。
- 边界检查用 `continue` 直接跳过外层/内层，不写嵌套大括号，代码更扁平。
- 距离判定用 `dx*dx+dy*dy<=t*t` 的整数平方比较，不引入 `sqrt` 浮点。
- 全程使用 `'\n'` 而非 `endl`；`main` 以 `return 0;` 正常结束。
