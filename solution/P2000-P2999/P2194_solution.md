# P2194 HXY烧情侣 — 题解

## 一、解题过程：人类思考叙事

题意梳理：图上 $n$ 个点，点 $i$ 的"汽油费"是 $w_i$。HXY 每次从**任意一个点**出发，走一条**闭合行走**（走一圈回到起点），这条闭合路径上所有的情侣都被烧掉，而这一次行动的花费**只等于起点那个点的汽油费**。同一个点可以被重复经过，目标是用最少的总花费烧掉所有点，问最小花费以及达到最小花费的方案数。

第一反应是强连通分量（Tarjan 的经典应用）。理由：一条闭合行走中，从起点出发经过的点 $v$，一定有"起点 $\to v$"和"$v \to$ 起点"两条路径，也就是 $v$ 与起点**互相可达**。而"互相可达"正是强连通的定义。所以在一条闭合行走里的所有点，两两强连通，**必然全部落在同一个强连通分量内**。反过来，一个强连通分量里的所有点，也确实能被一条闭合行走全部覆盖：从分量内任意一点出发，先依次走到每个还没烧的点，最后走回起点（强连通保证这些路径都存在）。

于是问题化归：**每个强连通分量至少要烧一次，一次就能烧完整个分量。**

为什么"至少一次"？因为闭合行走不能跨分量，所以分量里的点不可能被别的分量的行动烧到；而"一次就够"上面已经证明。

费用怎么算？对于一个强连通分量 $C$，一次行动的花费是起点的汽油费。选哪个起点最省钱？当然是分量内 $w$ 最小的那个点，于是这个分量的最小花费是 $\min_{i \in C} w_i$。总最小花费就是所有分量的最小点权之和。

方案数呢？一次行动可以选的"最优起点"就是这个分量里所有达到最小点权的点，数量记为 $cnt_C$。不同分量的选择互相独立（每个分量单独烧），由乘法原理，方案数 $= \prod_C cnt_C$，对 $10^9+7$ 取模。

样例验证：样例 1 的图是 $1 \to 2 \to 3 \to 2$，强连通分量为 $\{1\}$ 与 $\{2,3\}$，最小点权分别是 $1$ 和 $2$，总花费 $3$；两个分量的最优起点都只有 1 个，方案数 $1$。输出 `3 1` ✓。样例 2 中 $1\leftrightarrow 3$、$1\leftrightarrow 2$ 使三点全在一个强连通分量里，$w = (10,20,10)$，最小点权 $10$ 且有两个点取到，输出 `10 2` ✓。

工程上要注意：$n \le 10^5$，递归版 Tarjan 在链状图上深度可达 $10^5$，栈会爆。所以这里写**非递归 Tarjan**：用两个栈——一个 Tarjan 栈（保存还在强连通分量中的点），一个显式的 DFS 调用栈（模拟递归调用帧），再用 `idx[u]` 记录每个点已经遍历到第几条出边，这样就能把递归展开成循环。

## 二、思维链：完整证明

**引理 1**：任意一条闭合行走中经过的所有点，都属于同一个强连通分量。

*证明*：设闭合行走为 $v_0, v_1, \dots, v_k = v_0$。对任意 $i$，从 $v_0$ 沿行走的前半段到 $v_i$ 存在有向路径，从 $v_i$ 沿后半段回到 $v_0$ 也存在有向路径，故 $v_0$ 与 $v_i$ 互相可达。同理对任意 $i, j$，$v_i$ 到 $v_j$ 可经 $v_0$ 中转（$v_i \leadsto v_0 \leadsto v_j$）。因此这些点两两强连通，属于同一个强连通分量。证毕。

**引理 2**：设强连通分量 $C$，则存在一条从 $C$ 内某点出发并回到该点、经过 $C$ 中全部点的闭合行走。

*证明*：记 $C$ 中全部点的枚举为 $v_1, v_2, \dots, v_k$。取起点 $s = v_1$。由强连通的定义，$s$ 与每个 $v_i$ 互相可达，故存在有向路径 $s \leadsto v_2 \leadsto v_3 \leadsto \cdots \leadsto v_k$，其中相邻两段可以拼接（走完一段到达 $v_i$ 后再走下一段 $v_i \leadsto v_{i+1}$）。走完 $v_k$ 后，由强连通性存在路径 $v_k \leadsto s$。把上述路径依次连接即得所需闭合行走。证毕。

**引理 3**：任何烧掉 $C$ 中全部点的方案集合，必须包含至少一次完全落在 $C$ 内的闭合行走。

*证明*：由引理 1，每次行动（闭合行走）都完全落在某一个强连通分量内，不会跨越两个分量。取任意一个属于 $C$ 的点 $v$，$v$ 被烧到必然发生在某次行动中，那次行动按引理 1 落在包含 $v$ 的强连通分量中，而包含 $v$ 的强连通分量唯一就是 $C$。所以那次行动完全落在 $C$ 内。证毕。

**引理 4**：烧完强连通分量 $C$ 的最小花费是 $\min_{i \in C} w_i$，且达到该花费的"最优起点"恰为 $C$ 中所有满足 $w_i = \min_{j \in C} w_j$ 的点。

*证明*：由引理 3，至少一次行动落在 $C$ 内，由引理 2 一次就够，故最优方案恰好做一次这样的行动。该行动的花费是起点的汽油费 $w_s$（$s \in C$），显然 $w_s \ge \min_{i\in C} w_i$，取 $s$ 为达到最小值的点时取到等号，故最小花费为 $\min_{i \in C} w_i$。而由于 $w_s \ge \min$ 且总花费要最小，等号必须成立，即 $w_s = \min$，所以最优起点恰为取到最小点权的那些点。证毕。

**引理 5**：全局最小花费为 $\sum_{C} \min_{i \in C} w_i$，且最优方案数为 $\prod_{C} |\{i \in C : w_i = \min_{j \in C} w_j\}|$。

*证明*：由引理 3，每个强连通分量 $C$ 都至少要付一次该分量的最小花费，累加得总花费下界 $\sum_C \min_{i\in C} w_i$。由引理 2 与引理 4，对每个分量各做一次、起点取其最小点权的点，即可恰好达到这个下界，故最小花费就是该和。
在达到最小花费的前提下，每个分量的花费必须恰好等于其最小花费（否则总和更大），由引理 4，该分量的起点有 $cnt_C$ 种选择。各分量的选择互不影响、互相独立（题面允许每次从任意点出发，且道路可重复走），由乘法原理，方案数为 $\prod_C cnt_C$。证毕。

**引理 6**：算法中的非递归 Tarjan 与标准递归 Tarjan 求出的强连通分量完全相同。

*证明*：标准递归 Tarjan 的核心不变式是：DFS 进入点 $u$ 时记 `dfn[u]=low[u]=++timer`，把 $u$ 压入 Tarjan 栈；访问子点 $v$ 时，若 $v$ 未访问则递归后 `low[u]=min(low[u],low[v])`，若 $v$ 已访问且仍在栈中则 `low[u]=min(low[u],dfn[v])`；回溯 $u$ 时若 `low[u]==dfn[u]` 则弹出栈顶直到 $u$，这些点构成一个强连通分量。
本算法用显式的 `dfs` 栈保存"递归调用帧"，`idx[u]` 记录 $u$ 的出边遍历进度：每次循环处理 $u$ 的一条出边，处理后立即把 `idx[u]` 前移到下一条边，这等价于递归函数中"进入 $u$ 后依次处理每条出边"的语义；当 `idx[u]` 归零时相当于递归返回，此时执行与递归版本完全相同的回溯逻辑（判断 `low[u]==dfn[u]` 并向父帧回传 `low`）。因此两种实现在每个点上产生的 `dfn`、`low` 与出栈分组完全一致，强连通分量划分相同。证毕。

**定理**：本算法输出的最小花费与方案数即为题目所求。

*证明*：由引理 6，算法正确求出了全部强连通分量；由引理 4，对每个分量统计最小点权 `mn` 与其出现次数 `cnt` 正确；由引理 5，`cost = Σ mn` 即最小花费，`ways = Π cnt` 即方案数（取模后同理）。证毕。

**引理 7**：本算法的时间复杂度为 $O(n + m)$，空间复杂度为 $O(n + m)$。

*证明*：Tarjan 中每个点入栈出栈各一次，每条边被访问一次（每条边至多在两个端点处各考察一次），总时间 $O(n+m)$。统计与汇总部分遍历点与分量各一次，$O(n)$。程序使用的数组大小均为 $O(n+m)$，空间 $O(n+m)$。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别题型** → 图论 + 强连通分量，题目 tags 也点明了
2. **抓关键约束"闭合行走"** → 一条回路只能在一个 SCC 内，别的分量帮不上忙 ⇒ **每个 SCC 恰好烧一次**
3. **算费用** → 一次行动的花费 = 起点点权 ⇒ 该 SCC 的最小花费 = 分量内最小点权
4. **算方案数** → 分量内"最小点权出现了几次"；各分量独立 ⇒ 乘法原理
5. **实现细节** → $n \le 10^5$，递归 Tarjan 会爆栈 ⇒ 写**非递归 Tarjan**（双栈 + 出边游标）
6. **写代码** → 建图 → 非递归 Tarjan → 统计 `mn/cnt` → 求和求积

## 四、解法说明

### 算法

非递归 Tarjan 求强连通分量，按分量统计最小点权及其出现次数，求和求积。

### 符号表

| 符号 | 含义 | 类型 | 初始化 / 记忆点 |
|------|------|------|----------------|
| $n$ | 顶点数 | `int` | 输入 |
| $m$ | 有向边数 | `int` | 输入 |
| $w_i$ | 点 $i$ 的汽油费 | `int[]` | 输入，$\le 10^9$ |
| $head/to/nxt$ | 链式前向星 | `int[]` | `ecnt` 自增 |
| $dfn[u]$ | DFS 访问序 | `int[]` | 全局零 |
| $low[u]$ | Tarjan 的 low 值 | `int[]` | 与 `dfn` 同步赋值 |
| $comp[u]$ | $u$ 所属的强连通分量编号 | `int[]` | 由 Tarjan 赋值 |
| $stk` / `top` | Tarjan 栈（栈内点尚未归入分量） | `int[]` | `top=0` |
| `dfs` / `dftop` | 显式 DFS 调用栈（模拟递归帧） | `int[]` | `dftop=0` |
| `idx[u]` | $u$ 的出边遍历游标 | `int[]` | 进入 $u$ 时置为 `head[u]` |
| `instk[u]` | $u$ 是否在 Tarjan 栈中 | `bool[]` | `false` |
| `cc` | 强连通分量个数 | `int` | 随分量弹出自增 |
| $mn[c]$ | 分量 $c$ 的最小点权 | `int[]` | 初始化为 `1145141919` |
| $cnt[c]$ | 分量 $c$ 中最小点权的出现次数 | `int[]` | 初始化为 $0$ |
| $cost$ | 最小总花费 | `i64` | 累加 `mn` |
| $ways$ | 方案数 | `i64` | 各 `cnt` 相乘取模 |

### 算法步骤

1. 初始化 I/O 加速（`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`）。
2. 读入 $n$ 与 $w_1 \dots w_n$，读入 $m$ 并用链式前向星建图（有向边，只加 $x \to y$）。
3. 对每个未访问的点调用非递归 `tarjan`，求出 `comp` 划分与分量数 `cc`。
4. 对每个点 $i$：设 $c = comp[i]$，若 $w_i < mn[c]$ 则令 `mn[c]=w_i, cnt[c]=1`，若 $w_i = mn[c]$ 则 `cnt[c]++`。
5. 遍历所有分量：`cost += mn[c]`，`ways = ways * cnt[c] % p`。
6. 输出 `cost` 与 `ways`。

### 复杂度

- 时间复杂度：$O(n + m)$。
- 空间复杂度：$O(n + m)$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2194 HXY烧情侣
// 思路：一条回路（闭合行走）完全落在某个强连通分量内
//       每个分量至少要烧一次，最优费用 = 分量内最小点权
//       方案数 = 分量内最小点权的出现次数，各分量相乘
//       n=1e5 递归 Tarjan 容易爆栈，这里写非递归 Tarjan
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};
constexpr int mxe{300005};
constexpr i64 p{1000000007};

int n,m,w[mxn];
int head[mxn],nxt[mxe],to[mxe],ecnt=0;

int dfn[mxn],low[mxn],comp[mxn],idx[mxn];
int stk[mxn],top=0;          // Tarjan 栈
int dfs[mxn],dftop=0;        // DFS 调用栈
bool instk[mxn];
int timer=0,cc=0;

void tarjan(int s)
{
	dfn[s]=low[s]=++timer;
	idx[s]=head[s];
	instk[s]=1;
	stk[top++]=s;
	dfs[dftop++]=s;
	while(dftop)
	{
		int u=dfs[dftop-1];
		if(idx[u])
		{
			int e=idx[u];idx[u]=nxt[e];
			int v=to[e];
			if(!dfn[v])
			{
				dfn[v]=low[v]=++timer;
				idx[v]=head[v];
				instk[v]=1;
				stk[top++]=v;
				dfs[dftop++]=v;
			}
			else if(instk[v])low[u]=min(low[u],dfn[v]);
		}
		else
		{
			--dftop;
			if(low[u]==dfn[u])
			{
				++cc;
				int x;
				do
				{
					x=stk[--top];
					comp[x]=cc;
					instk[x]=0;
				}while(x!=u);
			}
			if(dftop)
			{
				int fa=dfs[dftop-1];
				low[fa]=min(low[fa],low[u]);
			}
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)cin>>w[i];
	cin>>m;
	for(int i=1;i<=m;++i)
	{
		int x,y;cin>>x>>y;
		++ecnt;to[ecnt]=y;nxt[ecnt]=head[x];head[x]=ecnt;
	}
	for(int i=1;i<=n;++i)
		if(!dfn[i])tarjan(i);

	int mn[mxn],cnt[mxn];
	for(int i=1;i<=cc;++i)mn[i]=1145141919,cnt[i]=0;
	for(int i=1;i<=n;++i)
	{
		int c=comp[i];
		if(w[i]<mn[c])
		{
			mn[c]=w[i];
			cnt[c]=1;
		}
		else if(w[i]==mn[c])++cnt[c];
	}
	i64 cost=0,ways=1;
	for(int i=1;i<=cc;++i)
	{
		cost+=mn[i];
		ways=ways*cnt[i]%p;
	}
	cout<<cost<<' '<<ways<<'\n';
	return 0;
}
```

### 代码说明

- 链式前向星存图：`head[u]` 是 $u$ 的第一条出边，`nxt[e]` 是同起点的下一条边，`to[e]` 是终点。边数上界 `mxe{300005}` 对应 $m \le 3\times 10^5$。
- **非递归 Tarjan** 是本题代码上的重点：
  - `stk` 是 Tarjan 栈，保存"已访问但尚未归入某个分量的点"；
  - `dfs` 是模拟递归的调用栈，每层对应一个递归帧；
  - `idx[u]` 是出边游标，进入 $u$ 时置为 `head[u]`，每处理一条出边就前移，`idx[u]==0` 表示 $u$ 的出边全部处理完，相当于递归返回；
  - 返回时先判断 `low[u]==dfn[u]` 以弹出整个分量，再向父帧回传 `low[fa]=min(low[fa],low[u])`。
- `mn` 的初值用哨兵 `1145141919`，因为 $w_i \le 10^9$ 严格小于该值，保证第一个点一定会刷新 `mn`。
- `cost` 用 `i64`：$10^5$ 个分量各 $10^9$ 会到 $10^{14}$，`int` 会溢出。
- `ways` 每乘一次就取模，乘数 `cnt[c] \le 10^5 < p`，`i64` 中间结果不会溢出。
- 换行使用 `'\n'`，`main` 正常结束 `return 0`。

### 验证状态

- 编译：`g++ -O2 -std=c++17` 通过，无警告。
- 官方样例两组全部通过：`3 / 1 2 3 / 3 / 1 2 / 2 3 / 3 2` → `3 1`；`3 / 10 20 10 / 4 / 1 2 / 1 3 / 3 1 / 2 1` → `10 2`。
- 对拍：使用 `P2194_brute.cpp` 暴力求强连通分量（逐点做可达性搜索）并按分量统计最小点权与计数，与标程在 2000 组随机数据上比对，全部一致。
