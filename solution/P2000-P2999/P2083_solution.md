# P2083 找人 — 题解

## 一、解题过程：人类思考叙事

先读题。小明知道同学住在 $x$ 层 $y$ 房间，但不知道具体是哪个房间……等等，重读一遍：**他只知道"某一单元"，不知道房间**。$x,y$ 是告诉我们的"同学在第几层第几号房间"，是输入给我们的信息。

小明的行为是确定的：站在某个房间，问这个人，得到下一个房间号，走过去，再问……如此反复。体力消耗只和**跨了几层楼**有关：每爬一层消耗 $v$。

于是把每个房间看成一个点，"房间 $u$ 的人告诉你去房间 $w$"看成一条有向边 $u \to w$。**每个房间恰好有一条出边**（每个住客只提供一个房间号）。这叫**函数图**（基环内向树 / 每个连通块恰好有一个环的图）。

关键观察来了：既然每个点只有一条出边，那么从任何一个起点出发，路线是**唯一确定**的，不存在"走哪条路更省"的选择问题。这和一般的最短路图完全不同。

那问题就变成：从第一层的每个房间出发，沿着唯一的链走下去，走到同学房间时的累计体力是多少，取最小值。

最直接的做法：对第一层的 $m$ 个房间各模拟一遍。链最长 $n\cdot m = 10^5$ 步，总共 $m \cdot nm = 100 \cdot 10^5 = 10^7$ 步，其实能过。但每次模拟都从第一层出发，重复走了大量公共的后缀，浪费。

换个角度想：我们真正想知道的是"从房间 $u$ 出发到同学房间的最短体力"。这其实是一个最短路问题，只不过图是函数图。

**反向建图**！把边反过来：以同学房间为源点，在反图上跑一次最短路。反图上从同学房间出发能到达的房间 $u$，恰好就是"沿链走能走到同学"的那些房间；而反图路径长度正好等于原图路径长度（边权对称）。

更进一步：原图中每个点只有一条出边，所以从任意 $u$ 到同学的路径**唯一**，那"最短路"其实是"唯一路"。既然唯一，就不需要 Dijkstra —— 但边权不是 $1$，BFS 还是不对。

不过等等，我再想想。我们最终只要第一层各房间的答案，而链是唯一的。有没有更省事的？

有一个漂亮的观察：原图是函数图，每个弱连通分量恰好有一个环。同学房间自己指向自己（题目说"同学的信息就是自己的房间号"），所以同学房间是一个自环，也就是所在连通分量的环。我们要从同学出发，沿反向边 BFS，把所有能到达同学的房间的 `dis` 求出来。反向边从 $w$ 指向所有"指向 $w$"的房间，边权 = $|楼层(w) - 楼层(u)| \cdot v$。

由于函数图中每个点只有一条出边，反向图里每个点的"父亲"唯一（它指向的那个房间是它唯一的出边终点），所以从同学出发在反图上的可达结构是一棵**树**（以同学为根），树上每个点到根的路径唯一！因此用带权 BFS 累积路径和即可 —— 因为树上路径唯一，不存在多条路径取最小的问题，累加出来的 `dis` 就是唯一路径的长度。

不过为了稳妥，用**带权 BFS（队列里累积 dis）**在这棵树上是对的，但我更愿意直接写"从同学房间反向 BFS，dis 首次被赋值即为其唯一路径长度"，因为每个点只会被访问一次（它只有一个出边终点，所以反向遍历时每个点至多被一条路径到达）。

嗯，还是要说清楚一点：反向 BFS 时，一个点 $u$ 的入边（反图）来源是"所有指向它的房间"，它被访问的路径唯一，因为原图里 $u$ 只有一条出边，反图里 $u$ 也就只有一个"父亲" $succ[u]$。所以从同学出发沿反图向下走，$u$ 一定且只会被 $succ[u]$ 访问一次。于是 `dis[u] = dis[succ[u]] + 楼层差 * v` 是唯一的、也是正确的距离。

这甚至不需要队列——但队列写法更自然，也顺便处理了"某个房间可能指向同学、也可能指向别人"的情况。

最后，答案 = 第一层所有房间的 `dis` 最小值；若有房间不可达（`dis` 仍为无穷），说明从第一层出发的所有链都进不了同学的环，输出 `impossible`。

边界情况：如果同学就在第一层，且小明恰好站在同学房间，那么答案 $0$。这自然由 `dis[同学房间] = 0` 处理。

还有一个细节：同学房间的信息是自己，所以它的出边是自环，反向 BFS 时它会出现在自己的反向邻接表里——但 `dis[s]=0` 已经设过了，`dis[p]!=inf` 的判断会跳过它，没问题。

## 二、思维链：完整证明

**引理 1**：每个房间 $u$ 在原图中恰有一条出边 $u \to succ(u)$，且从 $u$ 出发的行走路线唯一。

*证明*：题目输入为每个房间的住客提供一个"层、房间"二元组，即恰好一个后继房间，故出度恰为 $1$。从任意房间出发，下一步只能走向它唯一的后继，递推下去路线完全确定，不存在分叉。证毕。

**引理 2**：设 $succ(u)$ 为 $u$ 的唯一后继，则从 $u$ 走到同学房间 $s$ 的体力消耗（若可达）为
$$dis(u) = dis(succ(u)) + \big|\text{floor}(u) - \text{floor}(succ(u))\big| \cdot v,
\quad dis(s)=0,$$
其中 $\text{floor}(\cdot)$ 是房间所在楼层。

*证明*：从 $u$ 出发，第一步必然走到 $succ(u)$（引理 1），这一步跨越的楼层数为 $|\text{floor}(u)-\text{floor}(succ(u))|$，消耗该值乘 $v$ 的体力。此后过程与"从 $succ(u)$ 出发找同学"完全一致，消耗 $dis(succ(u))$。两段消耗相加即得递推式。对 $s$ 本身无需移动，消耗 $0$。证毕。

**引理 3**：以 $s$ 为源点在反图（把 $u\to succ(u)$ 反向为 $succ(u)\to u$，边权 $w(u)=|\text{floor}(u)-\text{floor}(succ(u))|\cdot v$）上做 BFS，第一次访问某个房间 $u$ 时记录的 `dis[u]` 等于引理 2 中的 $dis(u)$。

*证明*：反图中每个房间 $u$ 只有一条出边（指向 $succ(u)$），因此从 $s$ 出发在反图上到达 $u$ 的路径唯一。若 $u$ 可达，设其反图路径为 $s = p_0 \to p_1 \to \cdots \to p_k = u$，则由反图边的定义，$p_{i+1}$ 的原图后继恰为 $p_i$。把这条路径倒过来，就是原图中从 $u$ 出发经 $p_{k-1},\dots,p_1,s$ 到达同学的唯一路线（引理 1 保证原图路线唯一，故这条就是它）。

由引理 2 的递推式沿路径逐点展开，
$$dis(u) = \sum_{i=0}^{k-1} \big|\text{floor}(p_{i+1})-\text{floor}(p_i)\big|\cdot v,$$
这正是 BFS 沿唯一反图路径累加边权所得的值。由于路径唯一，BFS 第一次访问 $u$ 时累加出的就是这个值，且 $u$ 不会被第二次访问（它在反图中出度为 $1$，只可能由 $succ(u)$ 访问到一次）。证毕。

**引理 4**：反图 BFS 结束后，`dis[u]` 仍为无穷当且仅当从 $u$ 出发永远到不了同学房间。

*证明*：若 `dis[u]` 被赋值，则由引理 3，存在一条反图路径 $s\to\cdots\to u$，倒过来即为原图中 $u\to\cdots\to s$ 的合法行走路线，故可达。

反之，若从 $u$ 出发能到达 $s$，则该路线倒过来是一条反图路径 $s\to\cdots\to u$，BFS 必然沿它访问到 $u$，故 `dis[u]` 被赋值。证毕。

**引理 5**：答案等于第一层所有房间的 `dis` 最小值。

*证明*：小明只能从第一层的某个房间出发。他的行走路线由起点唯一确定（引理 1），消耗为该起点的 $dis$（引理 3）。他要找的是所有可能起点中最省体力的一个，故答案是 $\min_{j} dis(\text{第一层第 } j \text{ 房间})$。若第一层所有房间都不可达（引理 4），则无论从哪出发都找不到同学，应输出 `impossible`。证毕。

**定理**：算法输出的答案正确。

*证明*：由引理 3，标程算出的 `dis` 数组是每个房间到同学房间的准确体力消耗；由引理 5，取第一层的最小值即为答案；不可达时输出 `impossible`，与题意一致。证毕。

## 三、模式总结（按实际思考顺序）

1. **建模：把房间看成点、"住客指路"看成有向边** — 得到一张**每个点出度恰为 1** 的函数图。
2. **发现路线唯一** — 出度为 1 意味着从任何起点只有一条路，"最短路"退化为"唯一路"，不必上 Dijkstra。
3. **反向建图，把"从同学出发"变成一次多源（实为单源）遍历** — 只跑一次 BFS 就算出所有房间的答案，避免对第一层每个房间各模拟一遍。
4. **认出树上路径唯一 → 带权 BFS 即可** — 每个点只被访问一次，累加边权即得唯一路径长。
5. **答案在"第一层"上取最小** — 小明的起点被限制在第一层。
6. **不可达判定** — `dis` 仍为无穷 ⇒ `impossible`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 楼层数 | `int`，$\le 1000$ |
| $m$ | 每层房间数 | `int`，$\le 100$ |
| $v$ | 每爬一层楼消耗的体力 | `int`，$\le 50$ |
| $(t_x,t_y)$ | 同学所在房间（层、房间号） | `int` |
| $s$ | 同学房间的编号（0-based） | `int`，$=(t_x-1)m+(t_y-1)$ |
| `succ[u]` | 房间 $u$ 的唯一后继房间编号 | `int[]`，长度 $nm$ |
| `head[u]` | 反图中房间 $u$ 的第一条入边起点 | `int[]` |
| `rnxt[u]` | 反图中与 $u$ 同属一个源点的下一条边 | `int[]` |
| `dis[u]` | 从房间 $u$ 出发找到同学的最小体力 | `i64[]`，初值 `inf` |
| `que[]` | BFS 队列 | `int[]`，长度 $nm$ |
| `inf` | 不可达哨兵 | `i64`，$1\ll 60$ |

### 房间编号约定

把第 $i$ 层第 $j$ 个房间（$i,j$ 均从 $1$ 开始）映射为编号 $u=(i-1)m+(j-1)$，于是
$$\text{floor}(u)=\left\lfloor \frac{u}{m}\right\rfloor \ (\text{0-based}),\qquad \text{room}(u)=u\bmod m .$$
这样"楼层"就是 `u/m`，"同层换房免费"这类判断都退化为一次整除。

### 算法步骤

1. 读入 $n,m,v,t_x,t_y$。
2. 对每个房间读入其指路的"层、房间"二元组，转成 0-based 编号存入 `succ[]`。
3. 建反图：对每个 $u$，把 $u$ 挂到 `head[succ[u]]` 的链表上。
4. 以同学房间 $s$ 为源点做 BFS：
   - `dis[s] = 0`，$s$ 入队；
   - 每次弹出 $u$，遍历其反图入边 $p$：若 `dis[p]` 仍为无穷，则 `dis[p] = dis[u] + |p/m - u/m| * v`，并把 $p$ 入队。
5. 在第一层的 $m$ 个房间（编号 $0 \dots m-1$）上取 `dis` 最小值；若仍为 `inf` 输出 `impossible`，否则输出该值。

### 复杂度

- 时间复杂度：$O(nm)$，每个房间只入队一次，每个反图边只访问一次。
- 空间复杂度：$O(nm)$，存储 `succ`、`head`、`rnxt`、`dis`、队列。

### 验证状态

- 标程 `P2083.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `3 3 2 2 3 / 1 3 3 3 2 1 / 2 3 1 1 2 3 / 1 1 1 2 2 3` 输出 `2`，与官方一致。
- 编写暴力 `P2083_brute.cpp`（从第一层每个房间出发顺着指针走，靠 `vis` 判环）与对拍脚本 `P2083_check.py`，在 $n\le 6$、$m\le 4$、$v\le 5$ 的随机数据上对拍 **3000 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2083 找人
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};
constexpr i64 inf{1LL<<60};

int n,m,v,tx,ty;
int succ[mxn];        // succ[u] = u 的唯一后继房间
int head[mxn];        // 反图邻接表头
int rnxt[mxn];
i64 dis[mxn];
int que[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>v>>tx>>ty;
	int tot=n*m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
		{
			int a,b;
			cin>>a>>b;
			succ[i*m+j]=(a-1)*m+(b-1);
		}
	for(int i=0;i<tot;++i)
		head[i]=-1;
	for(int u=0;u<tot;++u)
	{
		rnxt[u]=head[succ[u]];
		head[succ[u]]=u;
	}

	// 反向 BFS：原图每个房间只有一条出边，故反图上从同学出发到某房间的路径唯一
	int s=(tx-1)*m+(ty-1);
	fill_n(dis,tot,inf);
	int hh=0,tt=0;
	dis[s]=0;
	que[tt++]=s;
	while(hh<tt)
	{
		int u=que[hh++];
		for(int p=head[u];p!=-1;p=rnxt[p])
		{
			if(dis[p]!=inf)
				continue;
			dis[p]=dis[u]+abs(p/m-u/m)*v;   // 只按楼层差计体力，同层换房免费
			que[tt++]=p;
		}
	}

	i64 ans=inf;
	for(int j=0;j<m;++j)
		ans=min(ans,dis[j]);
	if(ans==inf)
		cout<<"impossible\n";
	else
		cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 房间用一维编号 `i*m+j`（$i,j$ 均 0-based），楼层即 `u/m`，省去二维数组。
- `head` / `rnxt` 手写链式前向星存反图，避免 `vector` 逐个分配。
- `fill_n(dis,tot,inf)` 必须写：全局 `int` 数组默认是 `0`，若不预填，不可达房间会被误判成"消耗 $0$ 体力可达"。
- `dis[p]!=inf` 的判重同时承担"每个房间只被访问一次"的职责（引理 3 的路径唯一性保证了这里的正确性）。
- 同学房间自带自环，反向邻接表里会出现它自己，但 `dis[s]` 已被设为 $0$，会被 `dis[p]!=inf` 拦下，不会重复入队。
- 输出 `impossible` 严格按题面要求的小写形式。
