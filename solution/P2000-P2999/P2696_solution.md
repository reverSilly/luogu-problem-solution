# P2696 慈善的约瑟夫 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 个人（$1\le N\le 10^5$）编号 $1..N$ 站成一圈，玩标准约瑟夫游戏：从第 $1$ 人开始，留一个、去掉一个（即第 $2$ 人第一个被暂时去掉），直到只剩一名幸存者，设其编号为 $s$。随后编号 $>s$ 的人**每人拿 $1$ 金币永久离开**，剩下编号 $1..s$ 的人**重新从头玩同样的游戏**。一旦某轮人数不再减少，游戏结束，最后剩下的每个人拿 $2$ 金币。求总付款。

**第一步：先把"一轮"到底发生了什么算清楚。** 一轮游戏就是经典的 $k=2$ 约瑟夫问题。手算小数据（$J(n)$ 记 $n$ 人游戏的幸存者编号）：

- $n=1$：$J=1$。
- $n=2$：留 $1$ 去 $2$，$J=1$。
- $n=3$：去 $2$，剩 $1,3$；接着去 $1$，$J=3$。
- $n=4$：去 $2,4$，剩 $1,3$；从 $1$ 继续：留 $1$ 去 $3$，$J=1$。
- $n=5$：去 $2,4$，剩 $1,3,5$；留 $5$ 去 $1$，剩 $3,5$；留 $3$ 去 $5$，$J=3$。

得到 $J(1..5)=1,1,3,1,3$。这正是教科书里约瑟夫递推 $f(1)=0,\ f(i)=(f(i-1)+2)\bmod i$（$0$-based）加 $1$ 的结果，说明我对"从第 $1$ 人开始交替去掉"的理解（$1$ 留、$2$ 去）与经典约瑟夫一致。

**第二步：把整场游戏的付款写出来，发现它是个望远镜。** 设各轮开始时的人数为 $n_0=N,n_1,n_2,\dots,n_t=F$。一轮结束后剩下编号 $1..J(n_i)$ 的人，所以 $n_{i+1}=J(n_i)$；这一轮付出去 $(n_i-n_{i+1})$ 个金币（每个离开的人恰好拿 $1$ 个，且每人只离开一次）。终止条件是"人数不再减少"，即 $J(F)=F$，此时 $F$ 个人各拿 $2$ 个金币。总付款

$$\sum_{i=0}^{t-1}(n_i-n_{i+1})+2F=(N-F)+2F=N+F.$$

**中间项全部消掉了！** 于是整道题只剩一个问题：**迭代 $n\mapsto J(n)$ 最终停在哪个 $F$？** 总付款就是 $N+F$，根本不需要逐轮模拟付款。

**第三步：$J$ 的闭式——二进制循环左移。** 直接递推 $f(i)=(f(i-1)+2)\bmod i$ 可以 $O(N)$ 算出 $J(N)$，但我们要迭代很多轮，想要更快的结构。经典结论：写 $n=2^m+l$（$0\le l<2^m$，即 $2^m$ 是不超过 $n$ 的最大 $2$ 的幂），则

$$J(n)=2l+1.$$

验证：$J(5)=2\cdot1+1=3$ ✓，$J(4)=2\cdot0+1=1$ ✓，$J(3)=2\cdot1+1=3$ ✓。把 $n$ 写成二进制 $n=(1\,b_{m-1}\dots b_0)_2$，则 $l=(b_{m-1}\dots b_0)_2$，而 $2l+1=(b_{m-1}\dots b_0\,1)_2$——**$J$ 就是把最高位的 $1$ 搬到末尾**（循环左移一位）。

**第四步：什么时候停？二进制的形状说了算。** 由闭式，$J(n)-n=(2l+1)-(2^m+l)=l+1-2^m\le0$，等号当且仅当 $l=2^m-1$，即 $n=2^{m+1}-1$——**二进制全 $1$**。所以：

- 人数每轮严格递减（除非已经全 $1$），正整数不能无限递减，游戏必然终止；
- 终态 $F$ 一定是某个 $2^k-1$。

是哪个 $k$？注意到**循环移位不改变二进制里 $1$ 的个数**，所以每一轮 $\mathrm{popcount}$ 都不变，$\mathrm{popcount}(F)=\mathrm{popcount}(N)$。而全 $1$ 的数由 $1$ 的个数唯一决定：$F=2^{\mathrm{popcount}(N)}-1$。

**第五步：合起来。** 答案 $=N+F=N+2^{\mathrm{popcount}(N)}-1$。一行公式。

手算核对（付款列是逐轮模拟的金币数）：

| $N$ | 人数链 | 逐轮付款 | 总计 | $\mathrm{popcount}$ | 公式 |
|---|---|---|---|---|---|
| $1$ | $1$ | $2$ | $2$ | $1$ | $1+2-1=2$ ✓ |
| $2$ | $2\to1$ | $1+2$ | $3$ | $1$ | $2+2-1=3$ ✓ |
| $3$ | $3$ | $6$ | $6$ | $2$ | $3+4-1=6$ ✓ |
| $4$ | $4\to1$ | $3+2$ | $5$ | $1$ | $4+2-1=5$ ✓ |
| $5$ | $5\to3$ | $2+6$ | $8$ | $2$ | $5+4-1=8$ ✓ |
| $6$ | $6\to5\to3$ | $1+2+6$ | $9$ | $2$ | $6+4-1=9$ ✓ |
| $7$ | $7$ | $14$ | $14$ | $3$ | $7+8-1=14$ ✓ |
| $10$ | $10\to5\to3$ | $5+2+6$ | $13$ | $2$ | $10+4-1=13$ ✓ |

**边界与读题细节。**

1. "从第 $1$ 人开始交替去掉"按经典约瑟夫理解：$1$ 留、$2$ 第一个被去掉。若理解成"$1$ 第一个被去掉"，$J(2)$ 会变成 $2$、$J(3)$ 变成 $2$，与递推 $f(i)=(f(i-1)+2)\bmod i$ 不符，也与本题"数论"标签指向的漂亮结论不符。
2. "暂时去掉"只是游戏内机制：一轮结束幸存者选出后，编号 $\le s$ 的人（包括游戏中被暂时去掉的）全部回到圈里重玩，所以每轮确实是完整的 $J(n_i)$。
3. 每个永久离开的人只拿 $1$ 金币（离开那一刻），不会在后续轮里再拿钱——望远镜求和依赖这一点。
4. $N=1$：第一轮就"人数不再减少"，$1$ 人拿 $2$ 金币，公式给 $2$，正确。
5. 范围：$N\le10^5<2^{17}$，$\mathrm{popcount}(N)\le16$（$65535=(1111111111111111)_2$ 有 $16$ 个 $1$，而 $17$ 个 $1$ 的最小数 $131071>10^5$），答案 $\le10^5+65535=165535$，`int` 绰绰有余。

## 二、思维链：完整证明

**记号。** 人数 $n\ge1$，编号 $1..n$。游戏规则：从 $1$ 开始沿圈交替"留、去"，第一个被去掉的是 $2$；被去掉者暂时出局，直到剩一人，其编号记为 $J(n)$。整场游戏的人数序列 $n_0=N,\ n_{i+1}=J(n_i)$，终止于 $J(F)=F$。$\mathrm{pc}(n)$ 记 $n$ 的二进制中 $1$ 的个数。

---

### 引理 1（约瑟夫递推）

$$J(1)=1,\qquad J(2m)=2J(m)-1,\qquad J(2m+1)=2J(m)+1\quad(m\ge1).$$

*证明*：$J(1)=1$ 平凡。

**偶数 $n=2m$。** 第一圈依次处理 $1,2,\dots,2m$：奇数留、偶数去，恰好去掉 $2,4,\dots,2m$ 共 $m$ 人。处理完 $2m$（去）后，下一个是 $1$，按交替规则 $1$ 留、$3$ 去、$5$ 留……即**下一个被去掉的是 $3$**。此时圈里剩 $1,3,5,\dots,2m-1$ 共 $m$ 人。把它们重编号：$2i-1\mapsto i$（$i=1..m$）。重编号后"下一个被去掉的是 $3$"变成"下一个被去掉的是新 $2$ 号"，且此后仍是留一去一——这与 $m$ 人游戏的初始局面（从新 $1$ 号开始、新 $2$ 号第一个被去）**逐字相同**。故幸存者新编号为 $J(m)$，原编号 $2J(m)-1$。

**奇数 $n=2m+1$。** 第一圈去掉 $2,4,\dots,2m$；接着 $2m+1$ 留，然后 $1$ 去。此时剩 $3,5,\dots,2m+1$ 共 $m$ 人，刚去掉 $1$，故下一个 $3$ 留、$5$ 去——**下一个被去掉的是 $5$**。重编号 $2i+1\mapsto i$（$i=1..m$，即 $3\mapsto1,5\mapsto2,\dots,2m+1\mapsto m$），则"下一个被去的是 $5$"变成"下一个被去的是新 $2$ 号"，又是标准 $m$ 人游戏。幸存者原编号 $2J(m)+1$。证毕。

（两条递推的关键都是验证**重编号后的"第一个被去者"恰好是新 $2$ 号**，否则游戏不是原样重演，递推就不成立。）

---

### 引理 2（闭式与二进制旋转）

写 $n=2^m+l$，其中 $2^m\le n<2^{m+1}$，$0\le l<2^m$。则 $J(n)=2l+1$。等价地：$J$ 把 $n$ 的二进制表示的最高位 $1$ 移到末尾（循环左移一位，忽略前导零）。

*证明*：对 $n$ 强归纳。

$n=1$：$m=0,l=0$，$2l+1=1=J(1)$ ✓。

设结论对所有 $<n$ 成立。写 $n$ 的二进制为 $(1\,b_{m-1}\dots b_0)_2$，则 $l=(b_{m-1}\dots b_0)_2$。

**$n=2m'$ 为偶数**（$m'=n/2<n$）：$m'$ 的二进制是 $(1\,b_{m-1}\dots b_1)_2$，即 $m'=2^{m-1}+l'$，$l'=(b_{m-1}\dots b_1)_2=\lfloor l/2\rfloor$，且 $b_0=0$ 故 $l=2l'$。由引理 1 与归纳假设：
$$J(n)=2J(m')-1=2(2l'+1)-1=4l'+1=2l+1.\ ✓$$

**$n=2m'+1$ 为奇数**（$m'=(n-1)/2<n$）：$m'$ 的二进制同样是 $(1\,b_{m-1}\dots b_1)_2$，$l'=\lfloor l/2\rfloor$，且 $b_0=1$ 故 $l=2l'+1$。由引理 1 与归纳假设：
$$J(n)=2J(m')+1=2(2l'+1)+1=4l'+3=2(2l'+1)+1=2l+1.\ ✓$$

二进制表述：$n=(1\,b_{m-1}\dots b_0)_2$，$2l+1=(b_{m-1}\dots b_0\,1)_2$，正是把最高位 $1$ 搬到末尾。证毕。

---

### 引理 3（单调性与不动点）

对一切 $n\ge1$，$J(n)\le n$；且 $J(n)=n\iff n=2^k-1$（某个 $k\ge1$，即二进制全 $1$）。

*证明*：沿用引理 2 的分解，
$$J(n)-n=(2l+1)-(2^m+l)=l+1-2^m.$$
由 $0\le l\le2^m-1$ 得 $l+1-2^m\le0$，故 $J(n)\le n$。等号成立 $\iff l=2^m-1\iff n=2^m+(2^m-1)=2^{m+1}-1$，即二进制为 $m+1$ 个 $1$。反之全 $1$ 的数显然满足 $l=2^m-1$。证毕。

**推论（终止性）**：人数序列 $n_{i+1}=J(n_i)$ 在到达不动点前严格递减，是正整数序列，故有限步内必到达某个 $F=2^k-1$；此时"人数不再减少"，按题意终止。

---

### 引理 4（付款望远镜）

总付款 $=N+F$，其中 $F$ 是终态人数。

*证明*：第 $i$ 轮（人数 $n_i$）结束后，幸存者编号 $s=J(n_i)=n_{i+1}$，编号 $n_{i+1}+1,\dots,n_i$ 的 $n_i-n_{i+1}$ 人各拿 $1$ 金币永久离开。每个人至多离开一次（离开后不再参与），故这部分付款逐人对应，总额为 $\sum_{i=0}^{t-1}(n_i-n_{i+1})$。这是望远镜和：
$$\sum_{i=0}^{t-1}(n_i-n_{i+1})=n_0-n_t=N-F.$$
终止轮 $F$ 人各拿 $2$ 金币，共 $2F$。总计 $(N-F)+2F=N+F$。证毕。

（注意：这里用到"剩下的人编号恰为 $1..s$"——因为离开的是编号 $>s$ 的人，圈里保序剩下 $1..s$，下一轮仍是同一规则的标准游戏，引理 1–3 才能逐轮套用。）

---

### 引理 5（$\mathrm{popcount}$ 不变量与终态唯一确定）

迭代过程中 $\mathrm{pc}(n_i)$ 恒等于 $\mathrm{pc}(N)$；终态 $F=2^{\mathrm{pc}(N)}-1$。

*证明*：由引理 2，$J$ 是二进制位的循环移位：把位串 $(1\,b_{m-1}\dots b_0)$ 变成 $(b_{m-1}\dots b_0\,1)$。移位是位的多重集的双射，$1$ 的个数不变，故 $\mathrm{pc}(J(n))=\mathrm{pc}(n)$。归纳得 $\mathrm{pc}(n_i)=\mathrm{pc}(N)$ 对所有 $i$。

由引理 3 的推论，终态 $F=2^k-1$，其二进制是 $k$ 个 $1$，故 $\mathrm{pc}(F)=k$。又 $\mathrm{pc}(F)=\mathrm{pc}(N)$，所以 $k=\mathrm{pc}(N)$，$F=2^{\mathrm{pc}(N)}-1$。证毕。

---

### 定理（答案公式）

$$\boxed{\text{总付款}=N+2^{\mathrm{pc}(N)}-1.}$$

*证明*：引理 4 给出总付款 $=N+F$；引理 3 保证迭代终止于不动点；引理 5 确定 $F=2^{\mathrm{pc}(N)}-1$。代入即得。证毕。

---

### 引理 6（数值范围与复杂度）

$N\le10^5$ 时 $\mathrm{pc}(N)\le16$，答案 $\le165535$，`int` 安全；计算复杂度 $O(\log N)$（`__builtin_popcount` 为常数级位运算，整体视作 $O(1)$ 亦可），空间 $O(1)$。

*证明*：$N\le10^5<131071=2^{17}-1$。若 $\mathrm{pc}(N)\ge17$，则 $N\ge2^{17}-1=131071>10^5$，矛盾，故 $\mathrm{pc}(N)\le16$。于是 $2^{\mathrm{pc}(N)}-1\le65535$，答案 $\le10^5+65535=165535<2^{31}-1$。`1<<pc` 中 `pc<=16`，无移位溢出。公式只含一次 popcount、一次移位、两次加法，$O(1)$。证毕。

**与递推模拟的对照**：不用闭式也可以做——$f(1)=0,\ f(i)=(f(i-1)+2)\bmod i$ 递推出 $J$，然后逐轮 $n\leftarrow J(n)$ 直到不动点，累加 $N+F$。每轮 $O(n)$，人数至少减半意义下快速下降（$J(n)\le n$ 且二进制长度不增），总复杂度约 $O(N\log N)$，$N=10^5$ 也能过；但闭式把整道题压缩成一行，且证明揭示了结构。

## 三、模式总结（按实际思考顺序）

- explore its property — 手算 $n\le5$ 的约瑟夫幸存者，确认规则就是经典 $k=2$ 约瑟夫（$1$ 留 $2$ 去）。
- reduce to easier problem — 把逐轮付款写成望远镜和 $\sum(n_i-n_{i+1})+2F=N+F$，整场游戏塌缩成"求终态人数 $F$"一个问题。
- classic problem solution — 约瑟夫闭式 $J(2^m+l)=2l+1$（由 $J(2m)=2J(m)-1,\ J(2m+1)=2J(m)+1$ 归纳证明）。
- explore its property — 闭式的二进制解读：$J$ = 循环左移一位；$J(n)\le n$，不动点恰为全 $1$ 数 $2^k-1$，故迭代必终止。
- explore its property — 循环移位保持 $\mathrm{popcount}$，终态由 $\mathrm{pc}(N)$ 唯一确定：$F=2^{\mathrm{pc}(N)}-1$。
- discuss by category — 核对 $N=1$、"暂时去掉后全员回归"、"每人只拿一次离开钱"、答案范围 $\le165535$ 等边界。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 初始人数 $N\le10^5$ | `int`，读入 | 唯一输入 |
| `J(n)` | $n$ 人约瑟夫（$k=2$）幸存者编号 | 数学量，$J(2^m+l)=2l+1$ | 二进制循环左移 |
| `F` | 终态人数 | 数学量，$F=2^{\mathrm{pc}(N)}-1$ | 全 $1$ 二进制 |
| `pc` | $\mathrm{pc}(N)$，$N$ 的二进制 $1$ 个数 | `int`，`__builtin_popcount(n)` | 移位不变量 |
| `ans` | 总付款 $N+F$ | `int` | $N+2^{pc}-1$，$\le165535$ |

### 算法步骤

1. I/O 加速三行，读入 $N$。
2. `pc=__builtin_popcount(n)`。
3. 输出 `n+(1<<pc)-1`。

### 复杂度

- 时间：$O(1)$（一次位运算 + 一次移位；按位数计为 $O(\log N)$）。
- 空间：$O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$N=1..10$ 与逐轮手算模拟全部一致（见第一部分表格），$N=100000$ 输出 $100063$（$\mathrm{pc}=6$，$100000+64-1$）。公式题，证明封闭，不做对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2696 慈善的约瑟夫
// 每轮付款 n_i-n_{i+1}，望远镜求和 ⇒ 总付款 = N + 终态人数 F
// J(n)=2l+1（n=2^m+l）是二进制循环左移：保持 popcount，不动点为全 1 数
// ⇒ F=2^popcount(N)-1，答案一行：N+(1<<popcount(N))-1
#include<bits/stdc++.h>
using namespace std;

int n;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	int pc=__builtin_popcount(n);	// 循环移位不变量：1 的个数
	cout<<n+(1<<pc)-1<<'\n';	// N<=1e5 ⇒ pc<=16，答案<=165535，int 安全
	return 0;
}
```

### 代码说明

- 全部数学内容都在第二部分：代码只是定理的直译。`1<<pc` 最大 $2^{16}=65536$，`int` 内无溢出（引理 6）。
- `__builtin_popcount` 是 GCC 内建位计数，$O(1)$；不放心也可手写 `for(;n;n>>=1)pc+=n&1;`，复杂度不变。
- 若采用递推模拟路线（$f(i)=(f(i-1)+2)\bmod i$ 逐轮迭代），答案相同但代码更长；本题数据范围下两者都能过，闭式是更优写法。
