# P2397 yyy loves Maths VI (mode) / 摩尔投票 — 题解

## 一、解题过程：人类思考叙事

题目：给出 $n$ 个正整数 $a_i$（$1\le n\le 2\times10^6+1$，$a_i\in[1,2^{31})$），**保证存在一个数出现次数超过 $\lfloor n/2\rfloor$**（即严格超过一半），求这个数。题面还特意警告："有人想水过，但我告诉你这空间是不够的。"

### 第一步：排序 / 哈希计数，为什么不行

最直接的两种想法：

- **排序后扫一遍**：$O(n\log n)$ 时间，但要把 $2\times10^6$ 个 `int` 全存下来，$8\text{ MB}$；
- **哈希表计数**：$O(n)$ 时间，但 `unordered_map` 的节点开销远超 $8\text{ MB}$。

题目那句"空间是不够的"就是在堵这两条路。更关键的是：**我们真的需要知道每个数出现了多少次吗？** 不需要。题目只问"那个超过一半的数**是谁**"，而且保证它存在。计数是为了"找出出现最多的"，但这里"超过一半"是一个极强的结构条件，应该能直接利用它，而不是绕道统计。

### 第二步：把"超过一半"翻译成"抵消不掉"

想象一个游戏：每次从序列里挑出**两个不同的数**，把它们一起删掉。问：那个超过一半的数会不会被删光？

不会。设它出现了 $k>n/2$ 次，总共 $n$ 个数。每次删除最多带走它的一个副本（因为两个被删的数不同，至多一个是它），而删除次数最多 $\lfloor n/2\rfloor$ 次（每次删 $2$ 个）。删完后它至少还剩 $k-\lfloor n/2\rfloor\ge 1$ 个。**所以"两两抵消不同元素"这个过程结束时，活下来的必然包含那个多数元素。**

这就是摩尔投票（Boyer–Moore majority vote）的直觉。但"每次挑两个不同的删掉"需要维护整个序列，空间还是 $O(n)$。能不能只用两个变量模拟这个抵消过程？

### 第三步：用 (候选, 计数) 两个标量模拟抵消

能。维护 `cand`（当前候选）和 `cnt`（当前"未被抵消的候选副本数"），流式读入每个 $x$：

- `cnt==0`：前面的全抵消完了，手里没牌 → 把 $x$ 立为新候选，`cnt=1`；
- `x==cand`：又多一个同伙 → `++cnt`；
- `x!=cand` 且 `cnt>0`：拿一个候选副本和 $x$ 抵消 → `--cnt`。

**为什么这三条就是"两两抵消"？** 因为 `cnt` 始终等于"当前还没被配对掉的 `cand` 副本数"，而所有被配对掉的元素都是"一个 `cand` + 一个非 `cand`"的异值对。第三条分支正是新建这样一个异值对；第一条分支是"手里空了，重新立候选"；第二条是"攒一个未配对的副本"。整个过程不需要存任何历史，空间 $O(1)$。

### 第四步：为什么不用第二遍验证

很多摩尔投票的模板最后还要再扫一遍确认 `cand` 真的超过一半——那是因为**一般序列可能根本没有多数元素**。但本题**保证存在**，于是可以证明：结束时 `cand` 一定就是答案，而且 `cnt` 一定 $>0$（见引理 3）。所以一遍流式扫描就够，不需要回头，也不需要存数组。

### 第五步：几个必须注意的边界

- **$a_i$ 最大 $2^{31}-1=2147483647$**，恰好是 `int` 的上限，能装下；但千万别用 `short`/`char`，也别开 `int a[2000005]`（那就违背了 $O(1)$ 空间的初衷，而且可能 MLE）。
- **`if(!cnt)` 必须放在 `x==cand` 之前**。若 `cnt==0` 时还去比较 `x==cand`，就会和一个"已经抵消完的旧候选"比较，逻辑错乱。正确顺序是：先看手里有没有牌，没有就重新立候选。
- **$n=1$**：第一个数直接成为候选，`cnt=1`，输出它。
- **最坏形态**：多数元素与非多数元素交替出现（如 `M,m,M,m,...,M`），`cnt` 长期在 $0/1$ 之间抖动，但最后一定停在多数元素上。实测 $n=2\times10^6+1$ 的这种交替数据，`cin`（关同步）耗时 $0.26$ 秒。

### 自己造的小例子（题面没有样例）

**例 1**：$n=5$，$a=(1,2,1,2,1)$。$1$ 出现 $3>2.5$ 次，答案是 $1$。逐步跟踪：

| 读入 | 分支 | `cand` | `cnt` |
|---|---|---|---|
| $1$ | `cnt==0` → 立候选 | $1$ | $1$ |
| $2$ | 异值 → 抵消 | $1$ | $0$ |
| $1$ | `cnt==0` → 立候选 | $1$ | $1$ |
| $2$ | 异值 → 抵消 | $1$ | $0$ |
| $1$ | `cnt==0` → 立候选 | $1$ | $1$ |

输出 $1$ ✓。注意中间 `cand` 一直是 $1$，但 `cnt` 两次归零——这正说明"候选"不是"当前出现最多的"，而是"当前未被抵消的"。

**例 2**：$n=7$，$a=(2,2,1,1,1,2,2)$。$2$ 出现 $4>3.5$ 次，答案是 $2$。跟踪：$(2,1)\to(2,2)\to(2,1)\to(2,0)\to$ 立 $(1,1)\to(1,0)\to$ 立 $(2,1)$。输出 $2$ ✓。这里候选中途从 $2$ 变成了 $1$ 又变回 $2$，说明**候选会换人**，但最终一定回到多数元素。

**例 3**：$n=1$，$a=(2147483647)$。输出 $2147483647$，验证 `int` 边界。

## 二、思维链：完整证明

### 引理 1（多数元素唯一）

至多有一个值出现次数严格超过 $n/2$。

*证明*：反证。设 $u\ne v$ 都出现 $>n/2$ 次，则两者出现次数之和 $>n/2+n/2=n$，但它们都是序列中的元素，总出现次数 $\le n$，矛盾。故至多一个。结合题面"保证存在"，答案**存在且唯一**，问题良定义。证毕。

### 引理 2（抵消不变量）

设算法处理完前 $m$ 个元素后状态为 $(\texttt{cand},\texttt{cnt})$。则这 $m$ 个元素构成的多重集可以被划分为：

- $\texttt{cnt}$ 个值等于 `cand` 的"未配对副本"；
- $p=\dfrac{m-\texttt{cnt}}{2}$ 个"异值对"，每对是两个**不同**的值。

特别地，$m-\texttt{cnt}$ 是非负偶数，且 $0\le\texttt{cnt}\le m$。

*证明*：对 $m$ 归纳。

**基础 $m=0$**：$\texttt{cnt}=0$，`cand` 未定义，空多重集划分为 $0$ 个副本 + $0$ 个对，$p=0$。成立。

**归纳步**：设处理完前 $m$ 个后不变量成立，现读入第 $m+1$ 个元素 $x$，分三种分支。

1. **$\texttt{cnt}=0$（立候选）**：由归纳假设 $m=2p$（全是异值对，没有未配对副本）。置 $\texttt{cand}'=x$、$\texttt{cnt}'=1$。新多重集 $=$ 旧的 $p$ 个异值对 $+$ 一个值为 $x$ 的新副本。故 $\texttt{cnt}'=1$ 个 `cand'` 副本 $+$ $p$ 个对，且 $(m+1)-1=m=2p$ 仍是偶数。成立。

2. **$x=\texttt{cand}$ 且 $\texttt{cnt}>0$（攒副本）**：$\texttt{cnt}'=\texttt{cnt}+1$，`cand'`$=$`cand`。新多重集 $=$ 旧的 $\texttt{cnt}$ 个副本 $+$ $p$ 个对 $+$ 一个值为 `cand` 的新副本 $=$ $\texttt{cnt}+1$ 个副本 $+$ $p$ 个对。$(m+1)-(\texttt{cnt}+1)=m-\texttt{cnt}=2p$。成立。

3. **$x\ne\texttt{cand}$ 且 $\texttt{cnt}>0$（抵消）**：$\texttt{cnt}'=\texttt{cnt}-1$，`cand'`$=$`cand`。从旧的 $\texttt{cnt}$ 个 `cand` 副本中取出一个，与新元素 $x$ 配成一个异值对（因 $x\ne\texttt{cand}$，确实异值）。新多重集 $=$ $(\texttt{cnt}-1)$ 个副本 $+$ $(p+1)$ 个对。$(m+1)-(\texttt{cnt}-1)=m-\texttt{cnt}+2=2p+2=2(p+1)$。成立。

三分支穷尽（$\texttt{cnt}=0$ 与 $\texttt{cnt}>0$ 互斥且覆盖，后者再按 $x$ 是否等于 `cand` 分两类），且每步都保持 $0\le\texttt{cnt}'\le m+1$（分支 1 得 $1\le m+1$；分支 2 得 $\texttt{cnt}+1\le m+1$；分支 3 得 $\texttt{cnt}-1\ge 0$）。归纳完成。证毕。

**这条引理是整道题的灵魂**：它把"两个标量的增减"严格等价于"多重集的异值配对划分"，从而把空间 $O(n)$ 的"真的去删元素"压缩成了空间 $O(1)$ 的"只记未配对副本数"。

### 引理 3（多数元素必然存活，且无需第二遍验证）

设整个序列长 $n$，值 $v$ 出现次数 $>n/2$。算法结束时 $\texttt{cand}=v$ 且 $\texttt{cnt}\ge 1$。

*证明*：由引理 2（取 $m=n$），整个序列被划分为 $\texttt{cnt}$ 个 `cand` 副本与 $p=(n-\texttt{cnt})/2$ 个异值对，故 $n=\texttt{cnt}+2p$。

统计 $v$ 的出现次数：每个异值对里两个值不同，故**至多含一个 $v$**；$\texttt{cnt}$ 个副本里，若 $\texttt{cand}=v$ 则贡献 $\texttt{cnt}$ 个 $v$，否则贡献 $0$ 个。于是
$$\#v\ \le\ p+\texttt{cnt}\cdot[\texttt{cand}=v].$$

**先证 $\texttt{cand}=v$**：反设 $\texttt{cand}\ne v$，则 $\#v\le p=\dfrac{n-\texttt{cnt}}{2}\le\dfrac n2$，与 $\#v>n/2$ 矛盾。故 $\texttt{cand}=v$。

**再证 $\texttt{cnt}\ge 1$**：既然 $\texttt{cand}=v$，上式变成 $\#v\le p+\texttt{cnt}$。若 $\texttt{cnt}=0$，则 $n=2p$，$\#v\le p=n/2$，仍与 $\#v>n/2$ 矛盾。故 $\texttt{cnt}\ge 1$。

两步都用到了"$\#v>n/2$"这个**严格**不等式：若只保证 $\ge n/2$，则 $\texttt{cnt}=0$、$\#v=n/2$ 的情形无法排除，这也是为什么一般摩尔投票需要第二遍验证、而本题不需要。证毕。

**推论**：算法结束时直接输出 `cand` 即为答案，不需要再扫一遍计数，也不需要把序列存下来。

### 引理 4（算法确实维护了引理 2 的不变量）

代码的三条分支与引理 2 归纳步的三种情形一一对应：

| 代码 | 引理 2 的情形 | 多重集操作 |
|---|---|---|
| `if(!cnt) cand=x,cnt=1;` | 情形 1 | 旧的全是异值对，新立一个未配对副本 |
| `else if(x==cand) ++cnt;` | 情形 2 | 新增一个同值未配对副本 |
| `else --cnt;` | 情形 3 | 取一个 `cand` 副本与 $x$ 配成异值对 |

*证明*：逐行对照即可。关键是分支顺序：`!cnt` 必须先判，否则 $\texttt{cnt}=0$ 时会误入"异值抵消"分支把 `cnt` 减成 $-1$，破坏 $0\le\texttt{cnt}$ 的不变量。代码用 `if/else if/else` 保证了三分支互斥且穷尽，与引理 2 的归纳步完全一致。故算法运行全过程不变量成立，结束时引理 3 适用。证毕。

### 引理 5（复杂度与值域）

时间 $O(n)$，空间 $O(1)$；`int` 足以容纳 $a_i$。

*证明*：每个元素只做常数次比较与加减，共 $n$ 次，故 $O(n)$。全程只有 `n,cand,cnt,x` 四个 `int` 标量，不存序列，故 $O(1)$。值域 $a_i\in[1,2^{31})$ 即 $a_i\le 2^{31}-1=2147483647=\texttt{INT\_MAX}$，恰好落在 32 位有符号 `int` 范围内（注意是**开区间** $2^{31}$，所以不会取到 $2^{31}$ 而溢出）。`cnt` 最大 $n\le 2\times10^6+1$，也远在 `int` 内。实测 $n=2\times10^6+1$ 的交替最坏数据，关同步的 `cin` 耗时 $0.26$ 秒。证毕。

### 引理 6（边界情形）

- $n=1$：第一个元素走情形 1，$\texttt{cand}=a_1$、$\texttt{cnt}=1$，输出 $a_1$。由引理 1，$a_1$ 出现 $1>0.5$ 次，确为答案。
- 全部元素相同：每个都走情形 2，$\texttt{cnt}=n$，$\texttt{cand}=a_1$，正确。
- 多数与非多数交替（最坏形态）：$\texttt{cnt}$ 在 $0/1$ 间抖动，但由引理 3，最后一个元素必使 $\texttt{cand}$ 停在多数元素上。例：$n=2k+1$，序列 $M,m,M,m,\dots,M$（$M$ 出现 $k+1>k+0.5$ 次），跟踪得 $\texttt{cnt}$ 序列 $1,0,1,0,\dots,1$，结束时 $\texttt{cand}=M$。
- $a_i=2^{31}-1$：`int` 恰好装下，比较与输出都正确（例 3 已验证）。

*证明*：逐条代入引理 2、3 即可。交替形态中，每读一个 $m$ 就把 $\texttt{cnt}$ 从 $1$ 减到 $0$，每读一个 $M$ 就因 $\texttt{cnt}=0$ 重新立候选 $M$、$\texttt{cnt}=1$；因 $n$ 为奇数且以 $M$ 结尾，最后 $\texttt{cnt}=1$、$\texttt{cand}=M$。证毕。

### 定理

算法输出的 `cand` 就是出现次数超过一半的那个数。

*证明*：引理 4 保证算法全程维护引理 2 的抵消不变量；引理 3 保证在"存在严格多数"的题设下，结束时 $\texttt{cand}$ 必为该多数元素且 $\texttt{cnt}\ge1$；引理 1 保证答案唯一；引理 6 保证边界无需特判。故直接输出 `cand` 正确。证毕。

### 为什么"随便输出一个数有 1/2 几率"是错的

题面里 kkksc03 开玩笑说"随便输出一个数字都有 $1/2$ 的几率"。这其实不成立：答案唯一（引理 1），而值域是 $[1,2^{31})$，随便猜一个命中的概率约 $2^{-31}$，远不是 $1/2$。这句玩笑恰恰反衬出**必须用正解**——而正解只需要两个 `int`。

## 三、模式总结（按实际思考顺序）

- explore its property — 只问"是谁"不问"多少次"，且保证严格超过一半 ⇒ 不需要计数容器，只需要利用"多数"这个结构。
- consider easier version — 若允许 $O(n)$ 空间，排序 / 哈希计数即可；空间受限逼出流式算法。
- classic problem solution — 摩尔投票：不同元素两两抵消，多数元素抵消不掉。
- reduce to easier problem — 把"真的去删元素"压缩成 $(\texttt{cand},\texttt{cnt})$ 两个标量，空间 $O(1)$、时间 $O(n)$、单遍流式。
- explore its property — 抵消不变量（引理 2）+ 严格多数（引理 3）⇒ 结束时 `cand` 必为答案且 `cnt>0`，**无需第二遍验证**。
- discuss by category — $n=1$ / 全同 / 交替最坏形态 / $a_i=2^{31}-1$ 的 `int` 边界，逐类核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 元素个数 | `int`，读入 | $\le 2\times10^6+1$ |
| `x` | 当前读入的元素 | `int`，循环内临时 | $a_i\le 2^{31}-1$，`int` 恰好装下 |
| `cand` | 当前候选（未被抵消的那个值） | `int`，初值 $0$ | 会中途换人，最终停在多数元素 |
| `cnt` | 当前未配对的 `cand` 副本数 | `int`，初值 $0$ | 不是"出现次数"，是"抵消后剩下的" |
| `i` | 流式循环下标 | `int` | $0..n-1$，不存数组 |

### 算法步骤

1. 读入 $n$。
2. 对 $i=0..n-1$，读入 $x$：
   1. 若 `cnt==0`：`cand=x, cnt=1`（立候选）；
   2. 否则若 `x==cand`：`++cnt`（攒副本）；
   3. 否则：`--cnt`（异值抵消）。
3. 输出 `cand`。

### 复杂度

- 时间：$O(n)$，每个元素常数次操作。
- 空间：$O(1)$，只有四个 `int` 标量，**不存序列**。

### 验证状态

编译（`g++ -std=c++20 -O2`）无错误无警告；题面无样例，自造 $5$ 组边界数据（$n=1$、全同、交替、$a_i=2^{31}-1$）与"排序后统计"暴力对拍 **300 组随机数据**（$n\le40$，值域含 $2^{31}-1$ 边界，保证存在严格多数）全部一致；另跑 $n=2\times10^6+1$ 的交替最坏数据，耗时 $0.26$ 秒、答案正确。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2397 yyy loves Maths VI (mode)
// 摩尔投票：O(1) 空间流式求出现次数超过一半的数，不开数组
#include<bits/stdc++.h>
using namespace std;

int n,cand,cnt;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0,x;i<n;++i)
	{
		cin>>x;
		if(!cnt)
			cand=x,cnt=1;
		else if(x==cand)
			++cnt;
		else
			--cnt;
	}
	cout<<cand<<'\n';
	return 0;
}
```

### 代码说明

- **不开数组**是本题的硬要求：`cand`/`cnt` 两个标量就模拟了整个"异值抵消"过程（引理 2），空间 $O(1)$。开 `int a[2000005]` 既违背题意又可能 MLE。
- `if(!cnt)` **必须**在 `x==cand` 之前：`cnt==0` 时手里没有未配对副本，必须重新立候选，而不是去和旧候选比较（引理 4）。
- `for(int i=0,x;i<n;++i)` 把循环下标与临时读入变量一起声明在 `for` 头里，符合仓库风格；`x` 每轮重新读入，不留历史。
- `int` 足以容纳 $a_i\le 2^{31}-1=\texttt{INT\_MAX}$（题面是开区间 $2^{31}$，不会溢出）；`cnt` 最大 $n\le 2\times10^6+1$，也在 `int` 内。
- 结束时**直接输出 `cand`**，不做第二遍计数验证——因为题面保证严格多数存在，引理 3 已证 `cand` 必为答案且 `cnt>0`。
- 关同步的 `cin` 读 $2\times10^6$ 个 `int` 实测 $0.26$ 秒，无需手写快读。
