# P2138 小Z的关系距离 — 题解

## 一、解题过程：人类思考叙事

题目定义了一个很朴素的关系：两个字符串 $a,b$，如果**各自删掉不超过自身长度一半的字符**之后能变得一样，就叫它们"距离为 1"。

注意这里的"删除不超过自身长度一半"是**对每个串分别算的**，不是对总长度算的。这一点是全题的枢纽。

先看最直接的解释：删完之后剩下的两个串相等，意味着 $a,b$ 有一个公共子序列 $s$，且

$$|s| \ge \lceil |a|/2\rceil,\qquad |s| \ge \lceil |b|/2\rceil .$$

因为从 $a$ 里最多删 $|a|/2$ 个，剩下的至少 $\lceil |a|/2\rceil$ 个字符；$b$ 同理。反过来，如果有一个公共子序列 $s$ 满足上面两个不等式，那从 $a$ 删掉 $|a|-|s|$ 个、留 $s$，从 $b$ 删掉 $|b|-|s|$ 个、留 $s$，两个删除量都合法。

于是：

> **距离为 1** $\iff$ $2\cdot \mathrm{LCS}(a,b)\ge \max(|a|,|b|)$。

设 $L=\mathrm{LCS}(a,b)$，$m=\min(|a|,|b|)$，$n=\max(|a|,|b|)$，则"一步"合法等价于 $2L\ge n$。

问题变成了：允许中间串，从 $a$ 走到 $b$，最少几步？

$n\le 100$，看起来像是可以 BFS：把所有字符串当点，距离 1 的连边。但字符串空间是无限（长度可以任意增长），根本枚举不出来。必须找一个**只依赖 $(L,m,n)$ 的判据**。

### 关键一步：单步的"长度不能翻倍太多"

假设 $u\to v$ 是合法的一步。设 $p=|u|,q=|v|$。由上面 $2\mathrm{LCS}(u,v)\ge\max(p,q)$，而 $\mathrm{LCS}(u,v)\le\min(p,q)$，得

$$\max(p,q)\le 2\min(p,q),$$

也就是**一步之内长度最多翻倍**（短的至少是长的一半）。同时被删掉/插入的字符总数是可数的：

$$\delta(u,v):=|u|+|v|-2\mathrm{LCS}(u,v)\ \le\ \min(p,q).$$

$\delta$ 就是"只允许插入和删除时，把 $u$ 变成 $v$ 的最少操作数"，它是插删操作图上的最短路，因此满足三角不等式。

现在看一条 $D$ 步的链 $x_0=a,x_1,\dots,x_D=b$，记 $u_i=|x_i|$。不妨令 $a$ 是短的那个（$u_0=m$）。由三角不等式

$$\delta(a,b)\le\sum_{i=1}^{D}\delta(x_{i-1},x_i)\le\sum_{i=1}^{D}u_{i-1},$$

而每步长度最多翻倍，故 $u_{i-1}\le m\cdot 2^{i-1}$，于是

$$m+n-2L\ \le\ m(1+2+\dots+2^{D-1})=m(2^D-1),$$

整理得

$$\boxed{\ n\le 2L+m(2^D-2)\ }$$

这是一条**必要条件**。而且注意它非常漂亮：$D$ 每加 $1$，右边的余量就翻一倍还多一点点——这正是"每步长度最多翻倍"带来的指数。

### 关键第二步：这个条件也充分

猜都猜得到：$D$ 从 1 开始往上加，第一个满足 $n\le 2L+m(2^D-2)$ 的 $D$ 就是答案。

为什么充分？需要能真的造出一条 $D$ 步的链。构造思路：

- 设短串为 $s$（长 $m$），长串为 $t$（长 $n$），取它们的某个 LCS 对齐（$s$ 中位置集 $I$，$t$ 中位置集 $J$，各长 $L$）。
- 从 $t$ 中**没被对齐用到的**位置里挑出 $\sigma$ 个，其中
  $$\sigma=\max\bigl(\lceil n/2\rceil-L,\ m-2L,\ 0\bigr).$$
- 把这 $\sigma$ 个字符按 $t$ 中的位置顺序插进 $s$，得到 $s^\*$，长度 $m+\sigma$。这样 $s^\*$ 与 $t$ 有长度至少 $L+\sigma$ 的公共子序列（对齐的 $L$ 个 + 插入的 $\sigma$ 个，按 $t$ 的顺序排列）。
- 再把 $\sigma$ 个字符**分 $D-1$ 步**逐步插进去，每步插的个数不超过当前串长（这样每步长度最多翻倍，$s_i\to s_{i+1}$ 是子序列关系且 $|s_{i+1}|\le 2|s_i|$，是合法的一步）。
- 最后一步 $s_{D-1}\to t$：$\mathrm{LCS}(s_{D-1},t)\ge L+\sigma$，且 $|s_{D-1}|=m+\sigma$，需 $2(L+\sigma)\ge\max(m+\sigma,n)$，这正好由 $\sigma\ge m-2L$ 和 $\sigma\ge\lceil n/2\rceil-L$ 保证。
- 步数够用：$D-1$ 步最多能插 $m(2^{D-1}-1)$ 个字符，而条件 $n\le 2L+m(2^D-2)$ 恰好保证 $\sigma\le m(2^{D-1}-1)$。

所以条件是充要的。整个问题塌缩成了一个**只和 $(L,m,n)$ 有关的公式**，LCS 用 $O(n^2)$ DP 算，剩下是一个 while 循环。

### 最后看标程的循环

标程里是这样的：

```
ans = L; cnt = 0;
while(ans*2 < n) { ++cnt; ans += m; m *= 2; }
输出 cnt+1
```

记初始短串长为 $m_0$。第 $k$ 次循环检查时（$k$ 从 0 开始）有

$$\text{ans}=L+m_0(2^k-1),\qquad m=m_0 2^k .$$

循环条件 $2\cdot\text{ans}<n$ 等价于 $2L+2m_0(2^k-1)<n$，即 $n>2L+m_0(2^{k+1}-2)$，正好是"$D\ge k+2$"。所以循环在 $k=D-1$ 时停下，输出 $cnt+1=D$。**公式和代码是完全对得上的。**

## 二、思维链：完整证明

**引理 1（单步刻画）**：$u,v$ 有距离为 1 的关系，当且仅当 $2\cdot\mathrm{LCS}(u,v)\ge\max(|u|,|v|)$。

*证明*：
（$\Rightarrow$）设删掉 $u$ 中 $d_u$ 个、$v$ 中 $d_v$ 个字符后得到相同的串 $s$，其中 $d_u\le\lfloor |u|/2\rfloor$、$d_v\le\lfloor |v|/2\rfloor$。则 $|s|=|u|-d_u\ge\lceil|u|/2\rceil$，同理 $|s|\ge\lceil|v|/2\rceil$，故 $|s|\ge\lceil\max(|u|,|v|)/2\rceil$。又 $s$ 是 $u,v$ 的公共子序列（$s$ 由 $u,v$ 各自删去若干字符后得到，其字符在两个原串中的先后顺序不变），故 $\mathrm{LCS}(u,v)\ge|s|\ge\lceil\max(|u|,|v|)/2\rceil$，两边乘 $2$ 得 $2\mathrm{LCS}(u,v)\ge\max(|u|,|v|)$。
（$\Leftarrow$）设 $2\mathrm{LCS}(u,v)\ge\max(|u|,|v|)$。取 $u,v$ 的一个最长公共子序列 $s$，则 $|s|=\mathrm{LCS}(u,v)\ge\lceil\max(|u|,|v|)/2\rceil$。从 $u$ 删去 $|u|-|s|$ 个字符、留下 $s$，删除量 $|u|-|s|\le |u|-\lceil|u|/2\rceil=\lfloor|u|/2\rfloor\le|u|/2$，合法；$v$ 同理。两个串删完都得到 $s$，故距离为 1。证毕。

**引理 2（一步内的长度约束）**：若 $u,v$ 有距离为 1 的关系，设 $p=|u|,q=|v|$，则 $\max(p,q)\le 2\min(p,q)$ 且 $\delta(u,v)\le\min(p,q)$，其中 $\delta(u,v)=p+q-2\mathrm{LCS}(u,v)$。

*证明*：由引理 1，$2\mathrm{LCS}(u,v)\ge\max(p,q)$；又恒有 $\mathrm{LCS}(u,v)\le\min(p,q)$。两式合并得 $\max(p,q)\le 2\min(p,q)$。
再看 $\delta$：$\delta=p+q-2\mathrm{LCS}\le p+q-\max(p,q)=\min(p,q)$。证毕。

**引理 3（$\delta$ 的三角不等式）**：$\delta(x,z)\le\delta(x,y)+\delta(y,z)$。

*证明*：考虑一个无限图，顶点是所有有限字符串，$x,y$ 之间连一条边当且仅当它们只差一次插入或一次删除，边权为 $1$。由"只允许插入删除"可知，把 $x$ 变成 $y$ 恰好就是把 $x$ 变成 $y$ 的某种插删序列（每次可插入或删除一个字符）；而任何这样的序列都对应图中的一条路径，反之亦然。而 $\delta(x,y)=|x|+|y|-2\mathrm{LCS}(x,y)$ 恰为最短路径长度：上界是取一个 LCS，把 $x$ 中不在该 LCS 里的 $|x|-\mathrm{LCS}$ 个字符删掉，再插入 $y$ 中不在该 LCS 里的 $|y|-\mathrm{LCS}$ 个字符，共 $|x|+|y|-2\mathrm{LCS}$ 步；下界是设任一插删序列共删 $D$ 个、插 $I$ 个字符，$|x|-D=|y|-I$，且 $x$ 中未被删掉的字符按原顺序出现于 $y$，构成 $x,y$ 的公共子序列，长度 $x$ 中存活字符数 $=|x|-D$，故 $\mathrm{LCS}(x,y)\ge|x|-D$，$D\ge|x|-\mathrm{LCS}$，同理 $I\ge|y|-\mathrm{LCS}$，于是总步数 $D+I\ge|x|+|y|-2\mathrm{LCS}$。
既然 $\delta$ 是图上最短路距离，任意 $x\to y\to z$ 的路径拼接成 $x\to z$ 的路径，长度为 $\delta(x,y)+\delta(y,z)$，故 $\delta(x,z)\le\delta(x,y)+\delta(y,z)$。证毕。

**引理 4（必要条件）**：若 $a,b$ 之间存在一条 $D$ 步的关系链（$D\ge1$），记 $L=\mathrm{LCS}(a,b)$、$m=\min(|a|,|b|)$、$n=\max(|a|,|b|)$，则 $n\le 2L+m(2^D-2)$。

*证明*：设链为 $x_0=a,x_1,\dots,x_D=b$，$u_i=|x_i|$。注意"距离为 1 的关系"是对称的（两串各自删除不超过自身长度一半后相等，把两串的角色互换条件不变），故把链反向读 $b\to a$ 仍是一条合法链；因此不妨设短串是链的起点，即 $|a|=m$，$u_0=m$。
由引理 2，每一步 $\delta(x_{i-1},x_i)\le\min(u_{i-1},u_i)\le u_{i-1}$；又 $\max(u_{i-1},u_i)\le2\min(u_{i-1},u_i)$，若 $u_i\ge u_{i-1}$ 则 $u_i\le2u_{i-1}$，若 $u_i<u_{i-1}$ 则 $u_i<u_{i-1}\le2u_{i-1}$，两种情形均有 $u_i\le2u_{i-1}$。归纳得 $u_{i-1}\le m\cdot2^{i-1}$。
由引理 3，
$$\delta(a,b)\le\sum_{i=1}^{D}\delta(x_{i-1},x_i)\le\sum_{i=1}^{D}u_{i-1}\le\sum_{i=1}^{D}m\,2^{i-1}=m(2^D-1).$$
而 $\delta(a,b)=m+n-2L$，故 $m+n-2L\le m(2^D-1)$，即 $n\le 2L+m(2^D-2)$。证毕。

**引理 5（$\sigma$ 的可行范围）**：设 $D\ge1$ 且 $n\le 2L+m(2^D-2)$，取
$$\sigma=\max\bigl(\lceil n/2\rceil-L,\ m-2L,\ 0\bigr),$$
则 $\sigma\le n-L$ 且 $\sigma\le m(2^{D-1}-1)$。

*证明*：
先证 $\sigma\le n-L$。三部分逐一比较：
- $\lceil n/2\rceil-L\le n-L$，因 $\lceil n/2\rceil\le n$；
- $m-2L\le n-L$，因 $m\le n+L$（即 $m-L\le n$，由 $m\le n$ 与 $L\ge0$ 立得）；
- $0\le n-L$。
三者取最大仍不超过 $n-L$。
再证 $\sigma\le m(2^{D-1}-1)$：
- 若 $D=1$：条件化为 $n\le 2L$，故 $\lceil n/2\rceil-L\le 0$，又 $m\le n\le2L$ 故 $m-2L\le0$，于是 $\sigma=0\le 0$。
- 若 $D\ge2$：令 $K=L+m(2^{D-1}-1)$，它是整数。由 $n\le 2L+m(2^D-2)=2L+2m(2^{D-1}-1)=2K$ 得 $\lceil n/2\rceil\le K$，故 $\lceil n/2\rceil-L\le m(2^{D-1}-1)$；又 $m-2L\le m\le m(2^{D-1}-1)$（因 $2^{D-1}-1\ge1$），且 $0\le m(2^{D-1}-1)$。取最大仍满足。证毕。

**引理 6（充分性）**：设 $D\ge1$ 且 $n\le 2L+m(2^D-2)$，则存在一条恰含 $D$ 步的合法关系链连接 $a,b$。

*证明*：设短串 $s$（长 $m$）、长串 $t$（长 $n$），$L=\mathrm{LCS}(s,t)$。取一个 LCS 对齐，即 $s$ 中的位置集 $I=\{i_1<\dots<i_L\}$ 与 $t$ 中的位置集 $J=\{j_1<\dots<j_L\}$，满足 $s_{i_k}=t_{j_k}$，且 $i_1<\dots<i_L$、$j_1<\dots<j_L$。
由引理 5，$\sigma\le n-L$，故 $t$ 中不属于 $J$ 的位置有 $n-L$ 个，足够选出 $\sigma$ 个。取这些位置的集合 $P$（若 $\sigma=0$ 则 $P=\varnothing$）。
构造 $s^\*$：从左到右扫描 $s$，遇到 $i_k\in I$ 时，先把 $P$ 中所有小于 $j_k$ 的位置对应的字符按序插入，再输出 $s_{i_k}$；$s$ 中不属于 $I$ 的字符按原位置顺序直接输出；最后把 $P 中剩余位置对应的字符按序补在末尾。于是 $s^\*$ 长度为 $m+\sigma$，且 $s^\*$ 中来自 $I$ 与 $P$ 的 $L+\sigma$ 个字符，按 $t$ 中的位置严格递增排列且与 $t$ 中对应字符相同，故它们构成 $s^\*$ 与 $t$ 的一个公共子序列，故
$$\mathrm{LCS}(s^\*,t)\ge L+\sigma .$$
现把这 $\sigma$ 个插入字符（按它们在 $s^\*$ 中出现的顺序编号 $1..\sigma$）分批加入。设第 $i$ 步（$i=1..D-1$）加入 $t_i$ 个，累计已加入 $c_i=\sum_{j\le i}t_j$ 个，当前串长 $m+c_i$。取
$$t_i=\min\bigl(\sigma-c_{i-1},\ m+c_{i-1}\bigr),\qquad c_0=0 .$$
断言：$c_i=\min\bigl(\sigma,\,m(2^i-1)\bigr)$。用归纳法证明。$i=0$：$c_0=0=\min(\sigma,m(2^0-1))=\min(\sigma,0)$，成立。设对 $i-1$ 成立，记 $C=m(2^{i-1}-1)$。
- 若 $\sigma\le C$：则 $c_{i-1}=\sigma$，剩余 $0$，$t_i=0$，$c_i=\sigma=\min(\sigma,m(2^i-1))$，成立。
- 若 $\sigma>C$：则 $c_{i-1}=C$，剩余 $\sigma-C>0$，而本步上限 $m+c_{i-1}=m+C=m\cdot2^{i-1}$，故 $c_i=C+\min(\sigma-C,\,m2^{i-1})=\min(\sigma,\,C+m2^{i-1})=\min(\sigma,m(2^i-1))$，成立。
故断言成立。由引理 5，$\sigma\le m(2^{D-1}-1)$，代入 $i=D-1$ 得 $c_{D-1}=\sigma$，即到第 $D-1$ 步结束时所有插入字符都已加入。
记 $z_i$ 为加入前 $i$ 批后的串（$z_0=s$），则 $z_{i+1}$ 由 $z_i$ 插入若干字符得到，故 $z_i$ 是 $z_{i+1}$ 的子序列，$\mathrm{LCS}(z_i,z_{i+1})=|z_i|$；同时 $|z_{i+1}|=m+c_{i+1}=m+c_i+t_i\le m+c_i+(m+c_i)=2(m+c_i)=2|z_i|$。于是 $2\mathrm{LCS}(z_i,z_{i+1})=2|z_i|\ge\max(|z_i|,|z_{i+1}|)$，由引理 1 的充分性方向（条件 $\Rightarrow$ 距离为 1），$z_i,z_{i+1}$ 有距离为 1 的关系（$z_i=z_{i+1}$ 时即"两边各删 $0$ 个字符"，同样符合定义）。
最后一步 $z_{D-1}\to t$：此时 $z_{D-1}$ 包含全部 $\sigma$ 个插入字符，故 $\mathrm{LCS}(z_{D-1},t)\ge L+\sigma$；又 $|z_{D-1}|=m+\sigma$、$|t|=n$。由 $\sigma\ge m-2L$ 得 $2(L+\sigma)\ge 2L+2\sigma\ge m+\sigma$；由 $\sigma\ge\lceil n/2\rceil-L$ 得 $2(L+\sigma)\ge n$。于是 $2\mathrm{LCS}(z_{D-1},t)\ge\max(m+\sigma,n)=\max(|z_{D-1}|,|t|)$，由引理 1，$z_{D-1},t$ 有距离为 1 的关系。
于是 $z_0=s,\dots,z_{D-1},t$ 构成一条恰含 $D$ 步的合法链。证毕。

**定理（核心定理）**：记
$$D^\*=\min\bigl\{D\ge1:\ n\le 2L+m(2^D-2)\bigr\},$$
则 $a,b$ 之间关系的最小距离恰为 $D^\*$。

*证明*：存在性——当 $D$ 足够大时 $m(2^D-2)$ 可以覆盖 $n$，故集合非空，最小元存在。
下界——设最小距离为 $D$，由引理 4 得 $n\le2L+m(2^D-2)$，即 $D\ge D^\*$。
上界——由引理 5、6，取 $D=D^\*$ 可构造一条恰含 $D^\*$ 步的合法链，故最小距离 $\le D^\*$。
两边合起来得最小距离 $=D^\*$。证毕。

**引理 7（标程循环与公式的对应）**：设初始短串长 $m_0$。标程的 `while` 循环在第 $k$ 次判断时（$k$ 从 0 计数）满足 `ans` $=L+m_0(2^k-1)$、`m` $=m_0 2^k$；循环在 $k=D^\*-1$ 时首次不成立并退出，此时输出 $cnt+1=D^\*$。

*证明*：用归纳法证明不变式。$k=0$ 时 `ans`$=L=L+m_0(2^0-1)$、`m`$=m_0=m_0 2^0$，成立。设第 $k$ 次成立，则该次循环体执行 `ans+=m` 与 `m*=2`，得 `ans` $=L+m_0(2^k-1)+m_0 2^k=L+m_0(2^{k+1}-1)$、`m` $=m_0 2^{k+1}$，不变式对 $k+1$ 成立。
循环继续的条件是 $2\cdot\text{ans}<n$，代入得 $2L+2m_0(2^k-1)<n$，即 $n>2L+m_0(2^{k+1}-2)$，这等价于"$D^\*\ge k+2$"（因为 $D^\*$ 是使 $n\le2L+m_0(2^D-2)$ 成立的最小 $D$，该不等式成立恰好说明 $D^\*>k+1$，即 $D^\*\ge k+2$）。
故循环体执行了 $k$ 次当且仅当 $D^\*\ge k+1$；循环在第一个使 $D^\*\le k+1$ 的 $k$ 处退出，即 $k=D^\*-1$。此时 `cnt`$=D^\*-1$，输出 `cnt+1`$=D^\*$。证毕。

**补充说明（$a=b$ 的情形）**：当 $a=b$ 时 $L=m=n$，由引理 4 的条件 $D=1$ 时 $n\le2L$ 成立，故 $D^\*=1$。这与题面一致：同一个串删掉 $0$ 个字符即相等，距离为 1。程序输出 1，正确。

## 三、模式总结（按实际思考顺序）

1. 读懂"删除不超过自身长度一半" ⇒ 距离 1 等价于"存在足够长的公共子序列" ⇒ 化为 $2\mathrm{LCS}\ge\max$ 的纯判定条件
2. 一步之内长度最多翻倍 ⇒ 链上长度呈指数增长 ⇒ 答案只可能很小（$O(\log n)$ 步）
3. 用插删编辑距离 $\delta=|x|+|y|-2\mathrm{LCS}$ 把"步数"变成可累加的量，靠三角不等式得到**必要条件** $n\le 2L+m(2^D-2)$
4. 猜条件也充分 ⇒ 回头**构造**一条链：LCS 对齐 + 从长串未用位置取字符插入短串 + 分步插入保证每步长度不翻倍
5. 把构造里"插几个、插几步"的可行性算清楚 ⇒ 条件 $\lceil n/2\rceil-L$ 与 $m-2L$ 恰好对应最后一跳的两个约束
6. 条件化成公式后，循环上界就是 $O(\log n)$ ⇒ 一段 `while` 搞定，无需二分、无需 BFS

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 |
|------|------|------|
| $a,b$ | 输入的两个字符串 | `string` |
| $la,lb$ | $a,b$ 的长度 | `int` |
| `dp[i][j]` | $a$ 的前 $i$ 个与 $b$ 的前 $j$ 个字符的 LCS 长度 | `int[mxn][mxn]` |
| $L$ | `dp[la][lb]`，两串最长公共子序列长度 | `int` |
| $m$ | $\min(la,lb)$，短串长度（循环中会翻倍） | `int` |
| $n$ | $\max(la,lb)$，长串长度 | `int` |
| `ans` | 循环变量，含义为 $L+m_0(2^k-1)$ | `int` |
| `cnt` | 已执行的循环步数，最终答案 $=cnt+1$ | `int` |

### 算法步骤

1. 读入两个字符串 `a`、`b`，长度 `la`、`lb`。
2. 用 LCS 动态规划填 `dp[1..la][1..lb]`：`a[i-1]==b[j-1]` 时 `dp[i][j]=dp[i-1][j-1]+1`，否则 `dp[i][j]=max(dp[i-1][j],dp[i][j-1])`。
3. 取 $L=\text{dp}[la][lb]$，$n=\max(la,lb)$，$m=\min(la,lb)$。
4. 初始化 `ans = L`（即 $L+m_0(2^0-1)$），`cnt = 0`。
5. 循环：当 $2\cdot\text{ans}<n$（等价于 $D\ge k+2$）时，执行 `++cnt; ans += m; m *= 2;`，把区间右端翻倍继续推进。
6. 循环停止时 `cnt` $=D-1$，输出 `cnt+1`。

### 复杂度

- LCS 动态规划：时间 $O(la\cdot lb)\le O(100^2)$，空间 $O(la\cdot lb)$。
- 循环：每次 $m$ 翻倍，步数为 $O(\log_2 n)$，本数据下不超过 10 次。
- 总时间复杂度 $O(la\cdot lb+\log n)$，空间复杂度 $O(la\cdot lb)$（`dp` 数组 $105\times105$ 个 `int`，约 44 KB）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int dp[mxn][mxn];
string a,b;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b;
	int la=a.size(),lb=b.size();
	for(int i=1;i<=la;++i)
		for(int j=1;j<=lb;++j)
			if(a[i-1]==b[j-1])
				dp[i][j]=dp[i-1][j-1]+1;
			else
				dp[i][j]=max(dp[i-1][j],dp[i][j-1]);

	int L=dp[la][lb];//最长公共子序列长度
	int n=max(la,lb),m=min(la,lb);
	int ans=L,cnt=0;
	while(ans*2<n)
	{
		++cnt;
		ans+=m;
		m*=2;
	}
	cout<<cnt+1<<'\n';
	return 0;
}
```

### 代码说明

- `mxn{105}` = 约束上界 $100$ + 5，符合"+5 松弛约定"。
- `dp` 是全局静态数组，`dp[0][*]`、`dp[*][0]` 天然为 $0$，正好是 LCS 的边界。
- LCS 用一维 $O(nm)$ 的经典写法：字符相等取对角线 $+1$，否则取上、左两者的较大值。
- `ans`/`m` 的初值恰好是不变式在 $k=0$ 处的取值，`m` 每轮翻倍对应"每步长度最多翻倍"。
- 循环条件写成 `ans*2<n`，而不是直接算 $2^D$，避免大数溢出与浮点误差。
- `a==b` 时 $L=m=n$，循环不执行，直接输出 $1$，与题面一致。
- 换行用 `'\n'`。

---

*本题的精髓是：把"关系"看成一张无限图上的最短路，再用"一步内长度最多翻倍"这个不变式把它压成一个只依赖 $(L,m,n)$ 的显式公式。整个 $O(\log n)$ 的循环，其实就是把指数右端一格一格往外推。*
