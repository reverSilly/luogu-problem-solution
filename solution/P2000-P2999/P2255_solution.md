# P2255 [USACO14JAN] Recording the Moolympics S — 题解

## 一、解题过程：人类思考叙事

题意：有 $N\le 150$ 个节目，第 $i$ 个占用时间 $[s_i,t_i)$（半开区间，端点可到 $10^9$）。FJ 的录音机有两个调谐器，可以同时录两个节目；同一个调谐器上的节目时间不能重叠。求最多能完整录下多少个节目。

先把“两个调谐器”翻译成组合语言：把选中的节目分成两组，每组内部两两不重叠，两组各自可以按时间排成一条“链”。答案就是两条链能容纳的节目总数最大值。

**只有一个调谐器**时这是经典问题：按结束时间从小到大排序，能放就放。正确性来自交换论证——最早结束的节目给后面留的余地最大。现在有两个调谐器，最自然的推广是：仍然按结束时间排序，维护两个调谐器各自“空闲下来的时刻” $e_0\le e_1$；当前节目开始于 $s$，若 $s\ge e_1$ 则两台都空闲，若 $e_0\le s<e_1$ 则只有较早空闲的那台可用，若 $s<e_0$ 则两台都忙，只能跳过。

两台都空闲时，应该用哪一台？直觉是**用空闲得最晚的那台**（即把 $e_1$ 更新为 $t$，保留更早空闲的 $e_0$）。因为 $e_0$ 更小，能给未来那些“开始时间很早”的节目留出机会；把较大的 $e_1$ 消耗掉，是在牺牲最不 valuable 的资源。这个策略也叫 best-fit。

但贪心看起来越自然，越要小心反例。最容易想到的质疑是：**当前这个节目虽然能录，会不会“占掉”某个调谐器，导致后面两个节目只能录一个？** 例如三个完全相同的 $[0,10)$ 加两个 $[10,20)$：前三个只能录两个，后两个都能录，总数 $4$，而最优也是 $4$，没有损失。再比如 $[0,5),[1,2),[3,4)$：按结束时间先录后两个，再把 $[0,5)$ 放到另一台，三个全录，说明“先录早结束的”确实给长的那个留了另一台。

要进一步确认，可以枚举小数据暴力（把每个节目分给“不录 / 调谐器 0 / 调谐器 1”，检查同一调谐器内是否重叠）。我随机跑了几百组 $N\le 8$ 的数据，贪心与暴力完全一致。但“跑过很多组”不是证明，下面必须给出严格的交换/归纳论证。

证明的关键难点在于：贪心接受一个节目时，可能和某个最优解的“选择”不同；简单地把最优解中的某个节目换掉，又可能引入新的冲突。解决方法是**加强归纳假设**：不仅证明贪心在每一个前缀上选的个数最多，还要证明它的两个“空闲时刻”在所有达到最大个数的方案中是**逐分量最小**的。只有拿到这个更强的结论，才能保证“当前能塞进贪心，就一定能塞进某个最优方案”。

几个实现边界：

1. 区间是半开的 $[s,t)$，所以 $s=t'$ 不算冲突，判断用 `s>=end` 而不是 `s>end`。
2. 按结束时间 $t$ 排序，不能按开始时间排序。
3. 坐标到 $10^9$，不能开桶；只排序，不需要离散化。
4. $N$ 很小（$150$），$O(N\log N)$ 的贪心绰绰有余；即使写 $O(N^3)$ 的 DP 也能过，但贪心代码更短。
5. 本地题面只给了“样例解释”而没有样例输入输出，我按题意手造了五组数据（见第五节）。

## 二、思维链：完整证明

### 约定与记号

把所有节目按结束时间非降序排列，重编号后仍记为 $1,\dots,N$，满足

$$t_1\le t_2\le\cdots\le t_N.$$

称前 $m$ 个节目为“前缀 $m$”。处理第 $m$ 个节目时，记它的开始时间为 $s$，结束时间为 $t=t_m$。由于排序，$t$ 不小于此前所有节目的结束时间。

一个**方案**是对某个节目子集 $S$ 的每个节目指定调谐器 $0$ 或 $1$，使得同一调谐器上的任意两个节目时间不重叠。一个调谐器的**结束时刻**定义为分配给它且被选中的节目中最大的 $t$；若没有节目则为 $0$。方案 $S$ 的两个结束时刻排序后记为 $x_1\le x_2$。

贪心维护 $e_1\le e_2$（代码中的 `e[0],e[1]`）。设贪心在前缀 $m$ 上共接受了 $G$ 个节目，把它们的结束时间按接受顺序记为

$$h_1\le h_2\le\cdots\le h_G.$$

由于节目按 $t$ 排序，接受顺序就是 $t$ 非降序，所以 $h$ 序列确实非降。补充约定 $h_0=0$。

**引理 0（半开区间的相容判定）**：两个节目 $[s,t)$ 与 $[s',t')$ 不重叠，当且仅当 $t\le s'$ 或 $t'\le s$。

*证明*：两区间重叠等价于存在 $x$ 满足 $\max(s,s')\le x<\min(t,t')$，即 $\max(s,s')<\min(t,t')$。其否定是 $\max(s,s')\ge\min(t,t')$，这等价于两个区间一左一右分离，即其中一个的右端点不超过另一个的左端点：$t\le s'$ 或 $t'\le s$。代码中“新节目开始时间 $s\ge$ 调谐器结束时刻 $e$”就是 $e\le s$，符合该判定。证毕。

**引理 1（状态转移）**：设处理第 $m$ 个节目前贪心状态为 $e_1\le e_2$，接受数为 $G$。则：

1. 若 $s\ge e_2$：接受，新状态为 $(e_1,t)$，接受数 $G+1$；
2. 若 $e_1\le s<e_2$：接受，新状态为 $(e_2,t)$，接受数 $G+1$；
3. 若 $s<e_1$：拒绝，状态与接受数不变。

*证明*：由排序，$t\ge$ 之前所有节目的结束时间；而 $e_2$ 要么是 $0$，要么是某个此前被接受节目的结束时间，故 $t\ge e_2$。

- 情形 1：$s\ge e_2$ 意味着两台都空闲。按 best-fit 规则，把新节目放到结束时刻较大的那台，即把 $e_2$ 更新为 $t$；另一台保持 $e_1$。因为 $t\ge e_2\ge e_1$，排序后状态就是 $(e_1,t)$。
- 情形 2：$e_1\le s<e_2$ 意味着只有结束时刻为 $e_1$ 的那台空闲。把 $e_1$ 更新为 $t$，另一台仍为 $e_2$。因为 $t\ge e_2$，排序后状态为 $(e_2,t)$。
- 情形 3：$s<e_1\le e_2$，两台都在 $s$ 之后才空闲，均不能放，拒绝。

三种情形与代码的两个 `if` 分支完全对应。证毕。

**引理 2（最优性与结束时刻最小性）**：处理完前缀 $m$ 后，设贪心接受数为 $G$，结束时刻为 $e_1\le e_2$。则

1. 前缀 $m$ 的任意可行方案最多接受 $G$ 个节目；
2. 任意接受恰好 $G$ 个节目的可行方案，其两个结束时刻排序后为 $x_1\le x_2$，都满足 $x_1\ge e_1$ 且 $x_2\ge e_2$。

*证明*：对 $m$ 归纳。

**基始 $m=0$**：$G=0$，$e_1=e_2=0$；唯一方案为空，$x_1=x_2=0$，成立。

**归纳步**：设前缀 $m-1$ 满足引理，旧状态为 $e_1\le e_2$、旧接受数为 $G$。考察第 $m$ 个节目。

**情形 A：贪心接受 $m$**（$s\ge e_1$）。由引理 1，新接受数 $G+1$，新状态为

- 若 $s\ge e_2$：$(e_1,t)$；
- 若 $e_1\le s<e_2$：$(e_2,t)$。

先证 (1)：前缀 $m$ 的任意方案从前缀 $m-1$ 至多取 $G$ 个（旧 (1)），再加第 $m$ 个至多 $G+1$ 个；贪心本身达到 $G+1$，故新最大数就是 $G+1$。

再证 (2)：设 $S$ 是前缀 $m$ 上接受 $G+1$ 个节目的方案。若 $m\notin S$，则 $S$ 是前缀 $m-1$ 上 $G+1$ 个的方案，违反旧 (1)，故 $m\in S$。令 $S'=S\setminus\{m\}$，它是前缀 $m-1$ 上接受 $G$ 个的方案，由旧 (2)，其两个结束时刻 $y_1\le y_2$ 满足 $y_1\ge e_1,y_2\ge e_2$。在 $S$ 中，$m$ 被放到某台空闲的调谐器上（放之前该台结束时刻 $\le s$），另一台的结束时刻 $z$ 不变。$S$ 的两个结束时刻就是 $z$ 与 $t$；又 $z\le t$（$z$ 是 $S'$ 某台的结束时刻或 $0$，而 $S'$ 所有节目结束时间都 $\le t$）。

- 若 $s\ge e_2$：$m$ 可以放到 $S'$ 的任一台。若它占了结束时刻为 $y_2$ 的那台，则 $z=y_1\ge e_1$；若占了 $y_1$ 那台，则 $z=y_2\ge e_2\ge e_1$。总之 $z\ge e_1$。于是 $S$ 的结束时刻 $(z,t)$ 逐分量不小于新状态 $(e_1,t)$。
- 若 $e_1\le s<e_2$：由于 $y_2\ge e_2>s$，$m$ 不可能放到结束时刻为 $y_2$ 的那台，只能占 $y_1$ 那台，故 $z=y_2\ge e_2$。于是 $(z,t)$ 逐分量不小于新状态 $(e_2,t)$。

故 (2) 成立。

**情形 B：贪心拒绝 $m$**（$s<e_1$）。由引理 1，新接受数仍为 $G$。

先证 (1)：若存在前缀 $m$ 上接受 $G+1$ 个节目的方案 $S$，则 $m\in S$（否则违反旧 (1)）。令 $S'=S\setminus\{m\}$，它是前缀 $m-1$ 上接受 $G$ 个的方案，由旧 (2) 其结束时刻 $y_1\le y_2$ 满足 $y_1\ge e_1$。但 $m$ 必须放到一台空闲的调谐器上，即某台结束时刻 $\le s<e_1\le y_1\le y_2$，两台都不满足，矛盾。故新最大数仍为 $G$。

再证 (2)：设 $S$ 是前缀 $m$ 上接受 $G$ 个节目的方案。

- 若 $m\notin S$：$S$ 是前缀 $m-1$ 上的 $G$ 个方案，由旧 (2) 直接得 $x_1\ge e_1,x_2\ge e_2$（贪心状态未变）。
- 若 $m\in S$：令 $S'=S\setminus\{m\}$，它接受 $G-1$ 个节目。首先注意 $G\ge 2$：若 $G=0$，则 $e_1=0$，与 $s<e_1$ 矛盾（$s\ge 0$）；若 $G=1$，则较小结束时刻 $e_1=0$（另一台从未使用），同样与 $s<0$ 矛盾。故 $G\ge 2$。
  在 $S$ 中，$m$ 放到某台，该台放之前结束时刻 $u\le s<e_1$；另一台结束时刻为 $x$。$S$ 的两个结束时刻为 $x$ 与 $t$，且 $x\le t$。较大者 $x_2=t\ge e_2$：因为 $e_2$ 要么是 $0$，要么是某个此前被接受节目的结束时间，都不超过当前最大结束时间 $t$。下面证明 $x\ge e_1$。

  反设 $x<e_1$。则 $S'$ 的两台结束时刻 $u,x$ 都 $<e_1$，所以 $S'$ 中每个节目的结束时间都 $<e_1$。令 $m_0$ 为满足 $t_i<e_1$ 的节目个数（即结束时间 $<e_1$ 的最大前缀长度）。由于结束时间为 $e_1$ 的那个已接受节目属于前缀 $m-1$，有 $m_0\le m-1<m$。于是 $S'$ 是前缀 $m_0$ 上接受 $G-1$ 个节目的可行方案。由归纳假设 $P(m_0)$ 的 (1)，贪心在前缀 $m_0$ 的接受数 $G_0$ 满足

  $$G_0\ge G-1. \tag{$\ast$}$$

  另一方面，$e_1>0$（因 $s<e_1$ 且 $s\ge 0$），所以 $e_1$ 是某台调谐器的结束时刻，即某个已接受节目的结束时间。设 $j$ 是满足 $h_j=e_1$ 的**最小**下标。下面说明 $j\le G-1$。

  先证一个事实：较大的结束时刻 $e_2$ 恒等于 $h_G$。每次接受节目时，新节目的结束时间就是当前的 $h_G$，它被放到某台后，该台结束时刻变为 $h_G$，而另一台的结束时刻不超过它（所有已接受节目的结束时间都 $\le h_G$），所以两台结束时刻的最大值就是 $h_G$。

  若 $j=G$，则 $e_1=h_G$。又 $e_1\le e_2\le h_G$（$e_2$ 是两台结束时刻的最大值，且由上述事实 $e_2=h_G$），故 $e_1=e_2=h_G$。两台结束时刻都等于 $h_G$；第 $G$ 个节目只占其中一台，另一台的结束时刻 $h_G$ 必是某个更早被接受节目的结束时间，即存在 $k<G$ 使 $h_k=h_G=e_1$，这与 $j$ 是满足 $h_j=e_1$ 的最小下标矛盾。故 $j\le G-1$。

  由于 $h$ 非降且 $j$ 是最小满足 $h_j=e_1$ 的下标，贪心接受的前 $j-1$ 个节目的结束时间都 $<e_1$，而第 $j$ 个及以后的结束时间都 $\ge e_1$。因此贪心在前缀 $m_0$ 接受的节目恰好是前 $j-1$ 个，即

  $$G_0=j-1\le G-2,$$

  这与 $(\ast)$ 的 $G_0\ge G-1$ 矛盾。故反设不成立，$x\ge e_1$。

  于是 $S$ 的结束时刻 $(x,t)$ 逐分量不小于 $(e_1,e_2)$。证毕。

由归纳，$P(N)$ 成立。

**定理（贪心最优）**：贪心接受的节目数就是最大可录节目数。

*证明*：引理 2 的 (1) 说明任意可行方案至多接受 $G_N$ 个；贪心本身接受 $G_N$ 个且每步都放在空闲的调谐器上，方案可行，故 $G_N$ 就是最大值。证毕。

**引理 3（复杂度）**：时间 $O(N\log N)$，空间 $O(N)$。

*证明*：排序 $O(N\log N)$；扫描每个节目一次，常数次比较与赋值，$O(N)$；区间数组 $O(N)$。证毕。

**关于 tie-breaking 的说明**：证明中情形 A 的第一种（两机都空闲）用到了“保留较小的 $e_1$、更新较大的 $e_2$”这一 best-fit 规则。若两机都空闲却更新 $e_1$，新状态为 $(e_2,t)$，逐分量不小于 $(e_1,t)$，引理 2 的 (2) 就不再成立，归纳会断掉。因此代码必须严格按此规则更新。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 两个调谐器等价于把选中的节目分成两条互不重叠的链。
- **classic problem solution** — 单机区间调度：按结束时间排序，能放就放。
- **consider easier version** — 把单机贪心推广到双机，维护两个空闲时刻。
- **discuss by category** — 当前节目到来时：两机都空闲 / 只有较早空闲的一台可用 / 两机都忙，三种情况分别处理。
- **strengthen the invariant** — 只证“个数最多”不够，交换时还需要“空闲时刻逐分量最小”，否则无法把最优解改造成与贪心一致。
- **exchange argument / induction on prefix** — 对前 $m$ 个节目同时证明“个数最优”和“结束时刻最小”。
- **find counterexample** — 两机都空闲时必须更新较大的结束时刻（best-fit），更新较小者会破坏最小性。
- **boundary discipline** — 半开区间 $s\ge end$ 即相容；按结束时间排序；坐标很大只排序不建桶。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 |
|------|------|-------------|
| $N$ | 节目个数 | `int`，输入 |
| $a[i].s,\ a[i].t$ | 第 $i$ 个节目的开始、结束时间 | `interval` 数组，输入 |
| $e[0]$ | 两台调谐器中**较早**空闲的时刻 | `int`，初值 $0$ |
| $e[1]$ | 两台调谐器中**较晚**空闲的时刻，恒有 $e[0]\le e[1]$ | `int`，初值 $0$ |
| $ans$ | 已录制的节目数 | `int`，初值 $0$ |

### 算法步骤

1. 关闭流同步，读入 $N$ 与 $N$ 个区间。
2. 按结束时间 $t$ 非降序排序（`sort` + lambda）。
3. 初始化 $e[0]=e[1]=0$，$ans=0$。
4. 依次扫描每个区间 $[s,t]$：
   1. 若 $s\ge e[1]$：两台都空闲，令 $e[1]=t$，$ans$ 加一（保留较小的 $e[0]$）。
   2. 否则若 $s\ge e[0]$：只有较早空闲的那台可用，令 $e[0]=t$；若此时 $e[0]>e[1]$ 则交换，维持 $e[0]\le e[1]$；$ans$ 加一。
   3. 否则两台都忙，跳过。
5. 输出 $ans$。

### 复杂度

- 时间复杂度：$O(N\log N)$（排序为主），扫描 $O(N)$。
- 空间复杂度：$O(N)$。

### 验证状态

- 使用 `/d/mingw64/bin/g++.exe -std=c++20 -O2` 编译通过，无错误。
- 本地题面无样例输入输出（只有样例解释文字），手造并跑通 5 组：
  - `4 / [0,2) [1,3) [2,4) [3,5)` → `4`；
  - `5 / 三个 [0,10) + 两个 [10,20)` → `4`；
  - `3 / [0,5) [1,2) [3,4)` → `3`；
  - `1 / [0,10^9)` → `1`；
  - `2 / [0,1) [1,2)` → `2`。
- 与 $3^N$ 枚举（每个节目：不选 / 调谐器 0 / 调谐器 1）的暴力对拍 **500 组**随机小数据（$N\le 8$），输出完全一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2255 [USACO14JAN] Recording the Moolympics S
// 思路：按结束时间排序，维护两台调谐器各自的空闲时刻 e[0]<=e[1]
//       能放就放；两机都空闲时更新较大的 e[1]（保留更早空闲的 e[0]）
//       半开区间：s>=end 即相容
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{155};

int n;
struct interval{int s,t;}a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i].s>>a[i].t;
	sort(a,a+n,[](interval x,interval y){return x.t<y.t;});
	int e[2]={0,0},ans=0;
	for(int i=0;i<n;++i)
	{
		int s=a[i].s,t=a[i].t;
		if(s>=e[1])
		{
			// 两台都空闲，用空闲得最晚的那台
			e[1]=t;
			++ans;
		}
		else if(s>=e[0])
		{
			// 只有较早空闲的那台可用
			e[0]=t;
			if(e[0]>e[1])
				swap(e[0],e[1]);
			++ans;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 排序只按结束时间；结束时间相同的节目顺序任意（归纳证明只用到 $t$ 非降）。
- `e[0]` 始终是较小的空闲时刻，`e[1]` 是较大的；两个 `if` 分支分别对应“两台都空闲”和“只有一台空闲”。
- 两机都空闲时只更新 `e[1]`，保留 `e[0]`，这是归纳证明中“结束时刻逐分量最小”的关键；写成更新 `e[0]` 会破坏该性质。
- 第二分支更新 `e[0]=t` 后可能超过 `e[1]`，用 `swap` 恢复有序。
- 判断是 `s>=e[...]`，不是 `s>e[...]`：半开区间端点相接不冲突。
- 坐标范围到 $10^9$，没有开桶或离散化，只做排序。

*本题真正的难点是证明而不是代码：双机贪心的“能放就放”必须配合 best-fit 的 tie-breaking，并且归纳假设要同时包含“个数最优”和“空闲时刻逐分量最小”。少任何一个，交换论证都走不通。*
