# P2800 又上锁妖塔 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 塔有 $n$ 层（$n\le 10^6$），第 $i$ 层高 $h_i\in[1,100]$。小 A 从地面（第 $0$ 层）出发，要到第 $n$ 层。两种动作：

- **爬**：从第 $i-1$ 层上到第 $i$ 层，耗时 $h_i$；
- **跳**：仙术向上跳 $1$ 层或 $2$ 层，耗时 $0$；但**每次跳跃后必须再爬过至少一层**，才能再次跳跃。

求到塔顶的最短时间。题面无样例，下面所有例子都是我手算并程序核对的。

**第一步：把规则翻译成动作序列。** 一个方案就是一串动作：爬（记 C，爬到哪层就付哪层的 $h$）、跳一层（J1）、跳两层（J2）。"跳后必须爬至少一层才能再跳"等价于一条纯粹的序列约束：**任意两个跳动作不相邻**（中间至少夹一个 C）。起点是地面、终点恰为第 $n$ 层，动作只升不降。目标：最小化被爬楼层的 $h$ 之和。跳过的楼层不付钱——这就是仙术的价值。

还有一个边界要先定：**地面能不能直接起跳？** 题面说"每用一次（仙术）可以向上跳一层或两层"，限制只针对"跳跃之后"；初始没跳过，力气是满的，所以地面可以 J1 到第 $1$ 层、J2 到第 $2$ 层。于是 $n=1$ 时答案是 $0$（直接跳上去），$n=2$ 也是 $0$。这个读法后面用状态初值 $f[0][0]=0$ 表达。

**第二步：先看等高版本，摸清"跳的密度上限"。** 若所有 $h_i=w$，代价只取决于爬的层数 $c$。设跳了 $j$ 次：不相邻约束给出 $j\le c+1$（$c$ 个 C 把序列分成至多 $c+1$ 个空隙，每隙至多一个跳）；总升高 $n\le c+2j\le 3c+2$，故

$$c\ge\left\lceil\frac{n-2}3\right\rceil,$$

且模式 $\underbrace{J2,C,J2,C,\dots}_{\text{每 }3\text{ 层付 }1\text{ 次爬}}$ 恰好达到下界。**每 $3$ 层爬 $1$ 层**是理论极限。这说明最优方案里爬是稀缺资源，应该把爬花在"刀刃"上。

**第三步：高度不同，贪心立刻碰壁。** 既然爬要省着用，直觉贪心是"能跳就跳、尽量跳两层"。反例：$h=[5,1,5,1,5]$（$n=5$）。

- 贪心"能跳就跳 2"：J2 到 $2$，必须爬 $3$（付 $5$），J2 到 $5$。总代价 $5$。
- 最优：J1 到 $1$，爬 $2$（付 $1$），J1 到 $3$，爬 $4$（付 $1$），J1 到 $5$。总代价 $2$。

失败原因很清楚：**"爬哪几层"不是局部决策**——为了把爬落在便宜的楼层上，有时要故意只跳一层去"对齐相位"。贪心看不见未来楼层的价格，必然失败。那就 DP。

**第四步：状态里到底要记什么？** 站在第 $i$ 层时，历史对未来的全部影响只有一件事：**下一步能不能跳**。而这又只取决于"最后一步是不是跳"。所以两个状态就够了：

- $f[i][0]$：到第 $i$ 层、最后一步是**爬**（或还没动过），力气满，下一步可跳可爬；
- $f[i][1]$：到第 $i$ 层、最后一步是**跳**，力气空，下一步**只能爬**。

**第五步：写转移，每条都对着规则读。**

- **爬到 $i$**（付 $h_i$）：上一步在 $i-1$，两种状态都能爬（爬永远合法）：
  $$f[i][0]=\min(f[i-1][0],\ f[i-1][1])+h_i.$$
- **跳到 $i$**（免费）：起跳点只能是 $i-1$（J1）或 $i-2$（J2），且起跳前力气必须满——**只允许从状态 $0$ 起跳**：
  $$f[i][1]=\min(f[i-1][0],\ f[i-2][0]).$$
  注意第二项里**没有** $f[i-1][1],f[i-2][1]$：跳完再跳违反规则，这两条边根本不存在。

答案 $\min(f[n][0],f[n][1])$：最后一步爬上去或跳上去都算登顶。

**第六步：边界与数值。**

- $f[0][0]=0$：地面、力气满、零耗时（第一步的读法）。
- $f[0][1]=+\infty$：不可能"跳着到达地面"，这是不可能状态，**必须显式填 INF**（全局数组默认 $0$ 会被当成合法零代价状态）。
- $i=1$ 时 $f[i-2]$ 不存在，$f[1][1]$ 只能从 $f[0][0]$ 跳一层而来。
- **INF 会不会被加到 $h$ 上溢出？** 不会：全爬方案永远合法，故 $f[i-1][0]\le\sum_{t\le i-1}h_t$ 恒有限，$\min(f[i-1][0],f[i-1][1])$ 永远取到有限值。INF 只参与 $\min$ 比较。
- **值域**：答案 $\le\sum h_i\le10^6\times100=10^8$，`int` 足够，不需要 `long long`。

**手造数据核对：**

| 输入 | 最优方案 | 答案 |
|---|---|---|
| $n=1,h=[5]$ | 地面 J1 | $0$ |
| $n=2,h=[3,4]$ | 地面 J2 | $0$ |
| $n=3,h=[1,2,3]$ | 爬 $1$（付 $1$），J2 到 $3$ | $1$ |
| $n=4,h=[1,2,3,4]$ | J1，爬 $2$（付 $2$），J2 到 $4$ | $2$ |
| $n=5,h=[5,1,5,1,5]$ | J1，爬 $2$，J1，爬 $4$，J1（第三步的反例） | $2$ |
| $n=6$，全 $1$ | J2，爬 $3$，J2，爬 $6$ | $2=\lceil4/3\rceil$ |
| $n=7$，全 $1$ | J2，爬 $3$，J2，爬 $6$，J1 | $2=\lceil5/3\rceil$ |

$n=3$ 那组值得细看：J2 到 $2$ 再爬 $3$ 要付 $3$，反而不如先爬便宜的 $1$ 再 J2——"爬哪层"确实要看价格，DP 的必要性再次确认。

## 二、思维链：完整证明

**记号。** 楼层 $0..n$，$0$ 为地面。动作序列 $\sigma=(\sigma_1,\dots,\sigma_m)$，每个 $\sigma_t\in\{C,J1,J2\}$；位置序列 $p_0=0$，$C$ 使 $p{+}{=}1$，$J1$ 使 $p{+}{=}1$，$J2$ 使 $p{+}{=}2$。代价 $\mathrm{cost}(\sigma)=\sum_{t:\sigma_t=C}h_{p_t}$（爬到的楼层付钱）。$\mathrm{last}(\sigma)$ 为最后一个动作的类型（爬 / 跳）。前缀和 $H_i=\sum_{t=1}^i h_t$，$H_0=0$。

---

### 引理 1（规则 ⟺ 动作序列模型）

题目的小 A 合法方案与满足下列条件的动作序列一一对应：$p_0=0$，$p_m=n$，所有 $p_t\in[0,n]$，且**任意两个跳动作不相邻**；方案耗时 $=\mathrm{cost}(\sigma)$。

*证明*：逐条翻译题面。(i) "爬上第 $i$ 层花费 $h_i$"：爬动作从 $i-1$ 到 $i$，付 $h_i$，即 $C$ 的代价定义。(ii) "跳一层或两层不花时间"：$J1/J2$ 位移 $1/2$、代价 $0$。(iii) "每次跳跃后必须再爬过至少一层休息才可以继续跳"：设第 $t$ 步是跳，则下一次跳之前至少有一个 $C$，即不存在相邻两个跳；反之若序列无相邻跳，则每个跳之后到下一个跳之间至少一个爬，规则满足。(iv) 初始在地面、目标塔顶：$p_0=0,p_m=n$；动作只升不降，故 $p_t\le p_m=n$ 自动成立，$p_t\ge0$ 显然。(v) 地面起跳合法：规则 (iii) 只约束"跳跃后"，首步为跳时前面没有跳，不违反任何条款。对应关系：方案的动作按时间排成序列即得 $\sigma$；序列按步执行即得方案，二者互逆。证毕。

---

### 引理 2（无后效性：状态只需"楼层 + 最后一步类型"）

设两个合法前缀 $\sigma,\sigma'$ 都终于楼层 $i$，且 $\mathrm{last}$ 同类（同爬或同跳）。则它们的合法续接集合相同，且续接的代价只依赖于续接本身。

*证明*：由引理 1，续接 $\tau$ 合法当且仅当：拼接后仍无相邻跳、位置不超 $n$、终于 $n$。位置约束只看当前楼层 $i$ 与 $\tau$ 的位移；相邻跳约束在拼接处只涉及 $\mathrm{last}(\sigma)$ 与 $\tau$ 的首动作，内部只看 $\tau$ 自身；代价 $\mathrm{cost}(\tau)=\sum_{C\in\tau}h_{\text{到达层}}$，到达层由 $i$ 与 $\tau$ 的位移决定，与更早的历史无关。故 $\sigma,\sigma'$ 的楼层与末步类型相同 ⇒ 续接合法性与代价完全一致。证毕。

**推论**：最优子结构成立——最优方案的前缀必是同状态下的最优前缀（否则用更优前缀替换，续接不变，总代价更小，矛盾）。于是可以按 $(i,\text{末步类型})$ 定义 DP 状态。

---

### 引理 3（状态定义与转移）

定义 $f[i][0]=\min\{\mathrm{cost}(\sigma):\sigma\text{ 合法前缀},p_{\mathrm{end}}=i,\mathrm{last}=C\text{ 或 }\sigma\text{ 为空}\}$，$f[i][1]=\min\{\mathrm{cost}(\sigma):p_{\mathrm{end}}=i,\mathrm{last}\in\{J1,J2\}\}$，空集取 $+\infty$。则对 $i\ge1$：

$$f[i][0]=\min(f[i-1][0],f[i-1][1])+h_i,\qquad f[i][1]=\min\bigl(f[i-1][0],\ [i\ge2]\,f[i-2][0]\bigr).$$

*证明*：两式各证两个方向。

**爬式（$\ge$，构造可达）**：取达到 $f[i-1][0]$（或 $f[i-1][1]$）的前缀，末尾接一个 $C$ 到 $i$。爬永远合法（规则只限制跳），末步变为爬，代价加 $h_i$。故 $f[i][0]\le\min(\cdot,\cdot)+h_i$。

**爬式（$\le$，最优子结构）**：取达到 $f[i][0]$ 的前缀 $\sigma$（$i\ge1$ 故非空），末步必为 $C$（状态 $0$ 的定义），从 $i-1$ 爬到 $i$。删去末步得前缀 $\sigma'$，终于 $i-1$，末步类型任意（爬或跳），故 $\mathrm{cost}(\sigma')\ge\min(f[i-1][0],f[i-1][1])$，得 $f[i][0]\ge\min(\cdot,\cdot)+h_i$。夹逼得等式。

**跳式（$\ge$）**：取达到 $f[i-1][0]$ 的前缀接 $J1$，或（$i\ge2$ 时）取达到 $f[i-2][0]$ 的前缀接 $J2$。起跳前末步是爬（或空，即地面），接跳不产生相邻跳，合法；末步为跳，代价加 $0$。故 $f[i][1]\le\min(\cdot,\cdot)$。

**跳式（$\le$）**：取达到 $f[i][1]$ 的前缀 $\sigma$，末步是 $J1$ 或 $J2$。若 $J1$：删去末步得 $\sigma'$ 终于 $i-1$；$\sigma$ 合法 ⇒ $\sigma'$ 的末步不能是跳（否则 $\sigma$ 中两跳相邻），故 $\sigma'$ 末步是爬或为空，$\mathrm{cost}(\sigma')\ge f[i-1][0]$。若 $J2$：同理 $\sigma'$ 终于 $i-2$、末步非跳，$\mathrm{cost}(\sigma')\ge f[i-2][0]$（$J2$ 到 $i\ge1$ 要求 $i\ge2$，$i=1$ 时此分支不存在）。故 $f[i][1]\ge\min(\cdot,\cdot)$。夹逼得等式。

**为什么跳式里没有状态 $1$ 的项**：上面（$\le$）方向证明了起跳前末步**必须非跳**——这正是"跳后必须爬"的规则在转移里的全部体现；多写 $f[i-1][1]$ 或 $f[i-2][1]$ 会允许连跳，产生非法方案。证毕。

---

### 引理 4（边界与答案）

$f[0][0]=0$，$f[0][1]=+\infty$；最终答案 $=\min(f[n][0],f[n][1])$。

*证明*：终于楼层 $0$ 的前缀只有空前缀（动作只升不降，任何非空序列位置 $\ge1$）。空前缀归入状态 $0$（"还没动过，力气满"，引理 1(v) 保证首步可跳），代价 $0$，故 $f[0][0]=0$；不存在末步为跳的前缀终于 $0$，集合为空，$f[0][1]=+\infty$。登顶方案末步爬或跳皆可（题面只要求到达第 $n$ 层），故对两个状态取 $\min$。证毕。

**实现陷阱**：全局 `int` 数组默认 $0$。$f[0][0]=0$ 恰好与默认一致，但 $f[0][1]$ 必须**显式**填 INF，否则"跳着到达地面、代价 $0$"这个非法状态会污染 $f[1][0]=\min(f[0][0],f[0][1])+h_1$——本题因 $f[0][0]=0$ 也在 $\min$ 里而侥幸数值不变，但语义已错，且 $f[1][1]$ 若误从 $f[0][1]$ 转移就会直接出错。

---

### 引理 5（有限性、INF 安全与值域）

对一切 $i\ge0$：$f[i][0]\le H_i$（有限）；对 $i\ge1$：$f[i][1]\le f[i-1][0]$（有限）。因此转移中 INF 从不参与加法；所有有限值 $\le H_n\le10^8$，`int` 安全。

*证明*：全爬序列 $C^i$ 合法（没有跳，约束空真），终于 $i$、末步爬、代价 $H_i$，故 $f[i][0]\le H_i<\infty$。$i\ge1$ 时从 $f[i-1][0]$ 的见证前缀接 $J1$ 合法（引理 3 跳式构造），故 $f[i][1]\le f[i-1][0]<\infty$。

于是爬式中 $\min(f[i-1][0],f[i-1][1])\le f[i-1][0]$ 恒有限，$+h_i$ 永不作用在 INF 上；唯一的 INF 是 $f[0][1]$，它只出现在 $f[1][0]$ 的 $\min$ 比较里。值域：$f$ 的有限值是非负代价的最小值，$\le H_n\le10^6\times100=10^8<2^{31}-1\approx2.1\times10^9$，`int` 足够；INF 取 $1145141919\approx1.1\times10^9$ 也仍在 `int` 内且大于一切有限值。证毕。

---

### 引理 6（计算顺序）

按 $i=1..n$ 递增计算，每行先 $f[i][0]$ 后 $f[i][1]$（或任意顺序），所有依赖已就绪；对 $i$ 归纳即得整表正确。

*证明*：$f[i][0]$ 依赖第 $i-1$ 行两格；$f[i][1]$ 依赖第 $i-1$、$i-2$ 行的状态 $0$。全部依赖行号 $<i$，按行递增是拓扑序。第 $0$ 行由引理 4 初始化。归纳：设前 $i-1$ 行正确，引理 3 的等式给出第 $i$ 行正确。证毕。

---

### 引理 7（等高情形的闭式——大规模验证的标尺）

若所有 $h_i=w$，则答案 $=w\cdot\max\bigl(0,\lceil(n-2)/3\rceil\bigr)$。

*证明*：代价 $=w\cdot c$（$c$ 为爬的次数），只需最小化 $c$。

**下界**：设跳 $j$ 次。无相邻跳 ⇒ 把 $c$ 个爬排好后，跳只能插在 $c+1$ 个空隙（含首尾）里、每隙至多一个，故 $j\le c+1$。总升高 $n=c+(\text{跳的位移和})\le c+2j\le3c+2$，故 $c\ge(n-2)/3$，整数化 $c\ge\lceil(n-2)/3\rceil$；又 $c\ge0$。

**可达**：写 $n=3q+r$，$r\in\{0,1,2\}$，$q\ge0$。取模式 $(J2,C)^q$：每轮升 $3$ 层、爬 $1$ 次，轮内跳后紧跟爬、轮间爬后接跳，无相邻跳；$q$ 轮后位于 $3q$、末步为爬（$q\ge1$）或地面（$q=0$）。再按 $r$ 收尾：$r=0$ 不动；$r=1$ 接 $J1$；$r=2$ 接 $J2$（末步是爬或地面，起跳合法）。总爬数 $q$。核对 $q=\max(0,\lceil(n-2)/3\rceil)$：$r=0$ 时 $\lceil(3q-2)/3\rceil=q$（$q\ge1$）；$r=1$ 时 $\lceil(3q-1)/3\rceil=q$；$r=2$ 时 $\lceil3q/3\rceil=q$；$n=1,2$ 时 $q=0$ 且下界 $\le0$。上下界吻合。证毕。

这条引理不参与算法，但给出了 $n=10^6$、全 $h=100$ 时的独立标尺：$100\times\lceil999998/3\rceil=100\times333333=33333300$，程序输出与之一致。

---

### 引理 8（复杂度）

时间 $O(n)$，空间 $O(n)$。

*证明*：读入 $O(n)$；每行两个状态各一次 $\min$ 与一次加法，$O(1)$，共 $O(n)$。空间：`h` 与 `f[·][2]` 各 $10^6$ 量级 `int`，约 $4+8=12$ MB，$O(n)$。（理论上滚动三个变量可降到 $O(1)$ 额外空间，但 $12$ MB 远低于常见限制，保留数组更贴合转移式、可读性更好。）证毕。

---

### 定理

程序输出 $\min(f[n][0],f[n][1])$，等于登顶最短时间；时间 $O(n)$，空间 $O(n)$。

*证明*：引理 1 把题目化为动作序列优化；引理 2 证明状态（楼层 + 末步类型）无后效；引理 3 给出完整转移（双向夹逼）；引理 4 给出边界与答案表达式；引理 5 保证 INF 安全与 `int` 值域；引理 6 保证按序求值正确；引理 8 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "跳后必须爬一层才能再跳" ⟺ 动作序列中**任意两个跳不相邻**；爬第 $i$ 层付 $h_i$，跳过的层不付钱；地面力气满、首步可跳。
- **consider easier version** — 等高情形：$j\le c+1$ 与 $n\le c+2j$ 给出 $c\ge\lceil(n-2)/3\rceil$，$(J2,C)^q$ 模式达到下界——每 $3$ 层爬 $1$ 层是极限。
- **discuss by category** — 变高度时贪心"能跳就跳 2"碰壁：$h=[5,1,5,1,5]$ 上贪心付 $5$、最优付 $2$；爬哪层是为未来"对齐相位"的全局决策。
- **classic problem solution** — 两状态线性 DP：$f[i][0/1]$ = 到 $i$ 层末步爬 / 跳；爬从两状态来，跳只从状态 $0$ 来（$i-1$ 或 $i-2$）。
- **discuss by category** — 边界与数值：$f[0][0]=0$、$f[0][1]$ 显式 INF、$i=1$ 无 $i-2$ 项、答案两状态取 $\min$；全爬方案保证 INF 永不参与加法，答案 $\le10^8$ 用 `int`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 层数，$\le10^6$ | `int`，读入 | 地面是第 $0$ 层 |
| `h[i]` | 第 $i$ 层高度，$[1,100]$ | `int[mxn]`，读入 | 1-based，与楼层编号一致 |
| `f[i][0]` | 到 $i$ 层、末步**爬**（或起点）的最短时间 | `int[mxn][2]` | "0 = 力气满，可跳"；$f[0][0]=0$ |
| `f[i][1]` | 到 $i$ 层、末步**跳**的最短时间 | `int[mxn][2]` | "1 = 力气空，只能爬"；$f[0][1]=\text{inf}$ 显式填 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 只参与 $\min$，不参与加法（引理 5） |
| `mxn` | $10^6+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行；读 `n` 与 `h[1..n]`。
2. 初始化 `f[0][0]=0`、`f[0][1]=inf`。
3. 对 `i=1..n`：
   1. `f[i][0]=min(f[i-1][0],f[i-1][1])+h[i]`（爬上来，两种状态都能爬）；
   2. `f[i][1]=f[i-1][0]`（跳一层，起跳前必须力气满）；若 `i>=2` 再 `f[i][1]=min(f[i][1],f[i-2][0])`（跳两层）。
4. 输出 `min(f[n][0],f[n][1])` 与 `'\n'`。

### 复杂度

- 时间：$O(n)$，$n=10^6$ 实测 $0.12$ s 量级。
- 空间：$O(n)$，`h` 约 $4$ MB + `f` 约 $8$ MB。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过；题面无样例，手造 $8$ 组（$n=1,2$ 地面起跳、$n=3$ 先爬便宜层、贪心反例 $[5,1,5,1,5]$、全 $1$ 的 $n=5,6,7$）全部与手算一致；$n=10^6$ 全 $100$ 输出 $33333300$，与引理 7 闭式 $100\lceil(n-2)/3\rceil$ 吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2800 又上锁妖塔
// 规则翻译：动作序列中任意两个跳不相邻；爬第 i 层付 h[i]，跳免费
// f[i][0]：到 i 层末步爬（力气满，可跳）；f[i][1]：末步跳（力气空，只能爬）
// f[i][0]=min(f[i-1][0],f[i-1][1])+h[i]   爬从两状态来
// f[i][1]=min(f[i-1][0],f[i-2][0])        跳只从状态 0 来，跳 1 层 / 跳 2 层
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005},inf{1145141919};

int n,h[mxn],f[mxn][2];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)
		cin>>h[i];
	f[0][0]=0;	// 地面：力气满，首步可跳
	f[0][1]=inf;	// 不可能「跳着到达地面」，必须显式填（全局默认 0 是陷阱）
	for(int i=1;i<=n;++i)
	{
		f[i][0]=min(f[i-1][0],f[i-1][1])+h[i];
		f[i][1]=f[i-1][0];
		if(i>=2)
			f[i][1]=min(f[i][1],f[i-2][0]);
	}
	cout<<min(f[n][0],f[n][1])<<'\n';
	return 0;
}
```

### 代码说明

- **跳式只从状态 $0$ 转移**：`f[i][1]` 的两个来源都是 `f[·][0]`，这就是"跳后必须爬"的全部实现；若误写成 `min(f[i-1][0],f[i-1][1],...)` 会允许连跳，答案偏小。
- **`f[0][1]=inf` 必须显式写**：全局 `int` 默认 $0$，会把"跳着到达地面"当成合法零代价状态。本题数值上侥幸不炸（$f[0][0]=0$ 也在 $\min$ 里），但语义必须写对。
- **INF 永不参与加法**：全爬方案保证 `f[i-1][0]` 恒有限（引理 5），`min(f[i-1][0],f[i-1][1])` 永远取到有限值，`+h[i]` 不会作用在哨兵上。
- **`i=1` 无 `i-2` 项**：`if(i>=2)` 守住越界；$f[1][1]=f[0][0]=0$ 正是"地面跳一层"。
- **1-based 楼层**：状态以"到第 $i$ 层"定义，地面 $i=0$ 是天然边界，与题面楼层编号一致，故不做 `--i` 转换（同 P2389 的前缀型 DP 处理）。
- **`int` 足够**：答案 $\le\sum h_i\le10^8$，哨兵 $1145141919$ 也在 `int` 内；不需要 `long long`。
