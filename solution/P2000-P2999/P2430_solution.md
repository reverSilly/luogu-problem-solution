# P2430 严酷的训练 — 题解

## 一、解题过程：人类思考叙事

题目：WKY 水平值 $a$、老王水平值 $b$（$b$ 是 $a$ 的整数倍且 $a<b$）。"水平值的比值与做题时间的比值成反比"——例：WKY 水平 1、老王水平 2，则 WKY 做同一题的时间是老王的 2 倍。有 $n$ 个知识点，老王做第 $i$ 个知识点的题耗时 $t_i$；$m$ 道题，第 $j$ 道属知识点 $p_j$、奖励 $q_j$。**同一知识点的题对 WKY 一样难**（耗时相同）。问在规定时间 $T$ 内，WKY 选题做能拿到的**最大奖励和**。$n,m\le100$，$T\le5000$，$q\le1000$。

**第一步：把"水平/时间反比"翻译成耗时。** 水平比 $a:b$，时间比与之成反比，故 $\frac{\text{WKY 时间}}{\text{老王时间}}=\frac{b}{a}$。记 $k=b/a$（整数，$\ge2$），则 WKY 做一道知识点 $i$ 的题耗时 $k\cdot t_i$。这就是每道题的"重量"。

**第二步：认出背包结构。** 每道题 $j$ 是一个**独立物品**：重量 $w_j=k\cdot t_{p_j}$（依赖它所属的知识点——这正是题面说的"依赖"：耗时由知识点决定），价值 $v_j=q_j$。在总重量 $\le T$ 的前提下选一个子集使价值和最大。每题只做一次 ⇒ **0/1 背包**。所谓"带依赖"只是"重量依赖于知识点类别"，物品之间并无先后约束，仍是标准 0/1 背包。

**为什么不是贪心？** 按"性价比 $q/w$"排序贪心是错的：物品不可分割，经典反例（容量 10，物品 $(w=6,v=10),(w=5,v=9),(w=5,v=9)$，贪心取第一个得 10，最优取后两个得 18）。所以必须 DP。

**第三步：0/1 背包 DP。** 设 $f[c]$ 为总耗时**不超过** $c$ 时的最大奖励。初始 $f[0..T]=0$（什么都不做得 0）。逐题处理，对每个容量 $c$ 从 $T$ **倒序**到 $w_j$：
$$f[c]=\max(f[c],\ f[c-w_j]+v_j).$$
倒序是 0/1 背包的灵魂：它保证更新 $f[c]$ 时用到的 $f[c-w_j]$ 还是"上一题"的旧值，从而每题最多被选一次（若正序就变成可重复选的完全背包）。答案 $f[T]$。

**几个坑：**
- **重量可能超容量**：若 $w_j>T$，这题永远做不完，直接跳过。
- **算重量用 `i64`**：$k\cdot t_i$ 中 $k=b/a$ 与 $t_i$ 都可能不小，先以 `long long` 算，超过 $T$ 就跳过，否则转 `int`（此时 $\le T\le5000$）。
- **$T$ 在最后一行**：要先读完所有题、存下重量价值，再读 $T$ 做背包。
- **$f$ 全局默认 0 恰好正确**：空集奖励为 0，不是 INF；本题"不超过 $T$"语义下 $f$ 初值 0 天然成立，无需填哨兵。

## 二、思维链：完整证明

**引理 1（耗时换算）**：WKY 做一道知识点 $i$ 的题耗时为 $k\cdot t_i$，其中 $k=b/a$。

*证明*：题设"水平值的比值与所用时间的比值成反比"，即 $\frac{a}{b}=\frac{\text{老王时间}}{\text{WKY 时间}}$，取倒数得 $\frac{\text{WKY 时间}}{\text{老王时间}}=\frac{b}{a}=k$。老王做知识点 $i$ 的题耗时 $t_i$，故 WKY 耗时 $k\cdot t_i$。又 $b$ 是 $a$ 的整数倍，$k$ 为整数。证毕。

**引理 2（化为 0/1 背包）**：原问题等价于：有 $m$ 个物品，第 $j$ 个重量 $w_j=k\,t_{p_j}$、价值 $v_j=q_j$，求总重量 $\le T$ 的子集的最大价值和。

*证明*：由引理 1，做题 $j$ 耗时 $w_j$、得奖励 $v_j$；各题独立、每题至多做一次（0/1）；总耗时 $\le T$ 即总重量 $\le T$；目标最大化奖励和即价值和。题面"同一知识点一样难"只意味着同知识点的题重量相同（都等于 $k\,t_i$），不引入物品间约束，故仍是独立的 0/1 选择。一一对应得等价。证毕。

**引理 3（DP 状态含义）**：设 $f_j[c]$ 为只考虑前 $j$ 个物品、总重量 $\le c$ 时的最大价值，则 $f_0[c]=0$，且
$$f_j[c]=\begin{cases}\max(f_{j-1}[c],\ f_{j-1}[c-w_j]+v_j),&c\ge w_j,\\ f_{j-1}[c],&c<w_j.\end{cases}$$

*证明*：对前 $j$ 个物品的最优子集，按"是否含物品 $j$"分类。不含 $j$：即前 $j-1$ 个物品在容量 $c$ 下的最优，价值 $f_{j-1}[c]$。含 $j$（需 $c\ge w_j$）：去掉 $j$ 后是前 $j-1$ 个物品在容量 $c-w_j$ 下的最优子集（重量 $\le c-w_j$，加上 $j$ 后 $\le c$），价值 $f_{j-1}[c-w_j]+v_j$。两类取最大即得。$c<w_j$ 时物品 $j$ 放不下，只能不含。$f_0[c]=0$（无物品可选，空集价值 0）。证毕。

**引理 4（倒序滚动实现 0/1）**：用一维数组 $f$ 滚动，处理物品 $j$ 时让 $c$ 从 $T$ **递减**到 $w_j$ 执行 $f[c]\gets\max(f[c],f[c-w_j]+v_j)$，则处理完后 $f[c]=f_j[c]$，且每个物品至多被计一次。

*证明*：归纳设处理物品 $j$ 前 $f[c]=f_{j-1}[c]$。更新按 $c$ 从大到小：当更新 $f[c]$ 时，下标 $c-w_j<c$ 尚未在本轮被更新（更大的下标先更新），故 $f[c-w_j]$ 仍等于 $f_{j-1}[c-w_j]$。于是
$$f[c]\gets\max(f_{j-1}[c],\ f_{j-1}[c-w_j]+v_j)=f_j[c]$$
（引理 3）。未被更新的小下标 $c<w_j$ 保持 $f_{j-1}[c]=f_j[c]$（物品 $j$ 放不下）。故一轮结束后 $f=f_j$。关键在"倒序"：若正序，$f[c-w_j]$ 已被本轮更新为 $f_j[c-w_j]$（含物品 $j$），再用它更新 $f[c]$ 会让物品 $j$ 被重复计入，退化为完全背包。倒序杜绝了这一点，保证 0/1。证毕。

**引理 5（答案与边界）**：答案为 $f[T]$；重量 $w_j>T$ 的物品可安全跳过；$T=0$ 时答案为 0（无零重量物品时）。

*证明*："规定时间内"即总耗时 $\le T$，由引理 3、4，$f[T]=f_m[T]$ 即容量 $T$ 下最大价值，是答案。若 $w_j>T$，则任何含 $j$ 的子集重量 $\ge w_j>T$ 不可行，故 $j$ 永不入选，跳过不影响最优。$T=0$ 时只有总重 0 的子集可行；若所有 $w_j\ge1$ 则只能空集，价值 0。证毕。

**引理 6（复杂度）**：时间 $O(mT)$，空间 $O(T+n+m)$。

*证明*：$m$ 个物品各做一轮容量循环，每轮 $\le T$ 次转移，共 $O(mT)$；$m,T\le100,5000$ 时约 $5\times10^5$ 次。存 $f[0..T]$、$t[1..n]$、$w/v[0..m-1]$，空间 $O(T+n+m)$。证毕。

**定理**：算法输出最大奖励和。

*证明*：由引理 1、2 原问题等价于 0/1 背包；由引理 3、4 倒序 DP 正确算出 $f_m[T]$；由引理 5 它即"时间内最大奖励"，边界（超重跳过、$T=0$）均正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 水平/时间反比 $\Rightarrow$ WKY 耗时 $=(b/a)\times$ 老王耗时，先算出每题重量。
2. **reduce to easier problem** — 每题 = 独立物品（重量 $k\,t_{p_j}$、价值 $q_j$），"依赖"只是重量随知识点定 ⇒ 标准 0/1 背包。
3. **classic problem solution** — 0/1 背包 DP，容量**倒序**滚动保证每题至多选一次。
4. **discuss by category** — 重量 $>T$ 跳过；$k\,t$ 用 `i64` 防溢出；$f$ 默认 0 即空集，无需哨兵。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|----------------|
| $a,b$ | WKY、老王水平值 | `int` | 输入，$b=ka$ |
| $k$ | 时间倍率 $b/a$ | `int` | $\ge2$ |
| $n,m$ | 知识点数、题目数 | `int` | 输入 |
| $t[i]$ | 老王做知识点 $i$ 的题耗时 | `int[]` | 输入，1-based |
| $w[j]$ | 题 $j$ 的 WKY 耗时 $k\,t_{p_j}$ | `i64[]` | 读题时算 |
| $v[j]$ | 题 $j$ 的奖励 $q_j$ | `int[]` | 读题时存 |
| $T$ | 规定时间（容量） | `int` | 最后一行输入 |
| $f[c]$ | 总耗时 $\le c$ 的最大奖励 | `int[]` | 全局默认 0（空集） |
| 答案 | $f[T]$ | `int` | 时间内最大奖励 |

### 算法步骤

1. I/O 加速；读 $a,b$，读 $m,n$，读 $t[1..n]$，令 $k=b/a$。
2. 读 $m$ 道题 `(p,q)`，存 $w[j]=k\cdot t[p]$（`i64`）、$v[j]=q$。
3. 读 $T$。
4. 对每题 $j$：若 $w[j]>T$ 跳过；否则令 $ww=w[j]$，对 $c=T$ 倒序到 $ww$：$f[c]=\max(f[c],f[c-ww]+v[j])$。
5. 输出 $f[T]$。

### 复杂度

- 时间 $O(mT)$（$\le5\times10^5$）；空间 $O(T+n+m)$。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过。
- 题面无样例，手造 4 组：① $k=2,t=[1,2]$，题 $(1,5),(2,10),(1,7),T=4$ → `12`；② 同①但 $T=0$ → `0`；③ 所有重量 $>T$ → `0`；④ 重物品更优 $(1,5),(2,100),T=6,k=2,t=[1,3]$ → `100`。均与手算一致。
- 对拍：暴力（枚举全部 $2^m$ 个子集，检查总重 $\le T$ 取最大价值和，独立于 DP）与标程在 **300 组**随机数据（$m\le8,n\le5,k\in[2,4],T\le30$）上比对，全部一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2430 严酷的训练
// 思路：WKY 耗时 = (b/a)*老王耗时；每题是独立物品(重量 k*t[p], 价值 q)
//       0/1 背包：f[c]=总耗时<=c 的最大奖励，容量倒序滚动
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105},mxt{5005};

int n,m,T,a,b,t[mxn],v[mxn],f[mxt];
i64 w[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b;
	cin>>m>>n;
	for(int i=1;i<=n;++i)cin>>t[i];
	int k=b/a;
	for(int j=0;j<m;++j)
	{
		int p,q;cin>>p>>q;
		w[j]=(i64)k*t[p];
		v[j]=q;
	}
	cin>>T;
	// 0/1 knapsack: f[c]=max reward with total time <= c
	for(int j=0;j<m;++j)
	{
		if(w[j]>T)continue;
		int ww=(int)w[j];
		for(int c=T;c>=ww;--c)
			f[c]=max(f[c],f[c-ww]+v[j]);
	}
	cout<<f[T]<<'\n';
	return 0;
}
```

### 代码说明

- **重量用 `i64`**：$k\cdot t[p]$ 可能超 `int`，先以 `long long` 存；`w[j]>T` 直接跳过（永远做不完），否则此时 $w_j\le T\le5000$，转 `int` 安全。
- **倒序容量循环** `for(int c=T;c>=ww;--c)` 是 0/1 背包的关键，保证每题至多选一次（引理 4）；正序会退化为完全背包。
- `f` 全局默认 0，恰为"空集奖励 0"，本题"不超过 $T$"语义下无需填哨兵——这与"求最短路要填 INF"相反，切勿混淆。
- $T$ 在最后一行读入，故先存下所有题的 $w,v$ 再做背包。
- 下标：知识点 $t[1..n]$ 用 1-based（与输入 $p\in[1,n]$ 一致），题目 $w/v[0..m-1]$ 用 0-based；`mxn{105}`、`mxt{5005}` 为 $+5$ 松弛。
- 答案 `f[T]`，换行 `'\n'`。
