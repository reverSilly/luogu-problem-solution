# P2736 [USACO3.4] “破锣摇滚”乐队 Raucous Rockers — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 首歌（$1\le N\le20$），按创作时间排好序，第 $i$ 首时长 $a_i$ 分钟。要发行最多 $M$ 张 CD（$1\le M\le20$），每张容量 $T$ 分钟（$1\le T\le20$）。约束：

- 歌不能拆分到两张 CD；
- **保序**：第 $i$ 张 CD 的最后一首必须早于第 $i+1$ 张的第一首（即所有选中的歌按原顺序切成若干段，每段装一张 CD）；
- CD 可以用不完；
- 目标：选中的歌**数量**最多。

**第一步：看清结构——选一个子序列，再切成 $\le M$ 段。** "保序"意味着：选中的歌保持原相对顺序，第 $1$ 张 CD 装最前面的一段、第 $2$ 张装接下来的一段……每张 CD 内的歌是原序列的一个**连续段**（在选中的子序列里连续），且段内时长和 $\le T$。于是问题 = 选一个子序列，把它切成 $\le M$ 个连续段、每段和 $\le T$，最大化子序列长度。

**第二步：为什么不能贪心？** 直觉"每张 CD 尽量装满"会错。例：$T=10$，歌长 $[6,5,5]$，$M=2$。贪心第一张装 $6$（再装 $5$ 超了），第二张装 $5+5=10$，共 $3$ 首——这例恰好对。但换 $[4,6,6,4]$，$T=10,M=2$：贪心第一张 $4+6=10$，第二张 $6+4=10$，$4$ 首，也对。再想：贪心"能装就装"在**固定子序列**下确实最优（后面引理 5 证），但**选哪些歌**本身不能贪心——跳过一首短歌可能让后面更长的一段装得下。选择 + 分段两件事耦合，需要 DP。

**第三步：设计状态——逐首决策，记录"当前 CD 还剩多少"。** 按创作顺序一首一首决策，每首三选一：**跳过** / **塞进当前 CD** / **新开一张 CD 装它**。要判断"塞得下吗"，必须知道当前 CD 剩余容量；要判断"还能开新 CD 吗"，必须知道已开几张。于是状态：

$$dp[i][j][t]=\text{考虑完前 }i\text{ 首歌、已开 }j\text{ 张 CD、当前 CD 还剩 }t\text{ 分钟时，最多选了几首}.$$

范围 $0\le i\le N,0\le j\le M,0\le t\le T$，全是 $\le20$ 的小数，状态总数 $\le21^3=9261$，极小。

**第四步：转移。** 对第 $i$ 首（时长 $a_i$），从 $dp[i][j][t]$ 出发：
- 跳过：$dp[i+1][j][t]\leftarrow dp[i][j][t]$；
- 塞进当前 CD（需 $j\ge1$ 且 $a_i\le t$）：$dp[i+1][j][t-a_i]\leftarrow dp[i][j][t]+1$；
- 新开一张（需 $j<M$ 且 $a_i\le T$）：$dp[i+1][j+1][T-a_i]\leftarrow dp[i][j][t]+1$。

答案 $=\max_{j,t}dp[N][j][t]$。

**第五步：碰壁——一个隐蔽的"幽灵 CD"bug。** 我最初把初值设成 $dp[0][0][T]=0$（"还没开 CD，剩余时间记为 $T$"），并且"塞进当前 CD"只判 $a_i\le t$。结果随机对拍立刻翻车：$N=9,T=9,M=2$，歌长 $[7,10,1,2,5,5,7,11,10]$，我的 DP 输出 $5$，暴力输出 $4$。

手工核对：时长 $>T=9$ 的歌（$10,11,10$）根本选不了；可选的 $6$ 首 $[7,1,2,5,5,7]$ 总和 $27$，任选 $5$ 首总和 $\ge20>2\times9=18$，**两张 CD 装不下 $5$ 首**，正确答案是 $4$。我的 DP 多算了 $1$ 首——问题出在 $j=0$：此时"当前 CD"根本不存在，可 $t=T$ 让 $a_i\le t$ 成立，于是歌被塞进了一张**不存在的幽灵 CD**，$j$ 还停在 $0$；之后又能正常开 $M$ 张真 CD。等于白送了 $1$ 张 CD，总共 $M+1$ 张！

**修复**：$j=0$ 表示"没有当前 CD"，剩余时间应记为 $0$ 而非 $T$。改初值 $dp[0][0][0]=0$，并给"塞进当前 CD"加守卫 $j>0$。这样 $j=0$ 时只能"新开第一张 CD"，幽灵 CD 消失。修复后 $500$ 组随机 + $15$ 组 $N=18$ 大数据与暴力全对。

**第六步：不可达状态必须填 $-\infty$。** 全局 `int` 数组默认 $0$，而 $dp$ 求 $\max$，$0$ 会被当成"合法地选了 $0$ 首"，让不可达状态凭空贡献答案。必须 `fill_n(...,-inf)`，只留 $dp[0][0][0]=0$。

**手造数据核对**（题面无样例）：

| 输入 | 分析 | 输出 |
|---|---|---|
| `3 3 2` / `1 2 3` | CD1 装 $1+2=3$，CD2 装 $3$，共 $3$ 首 | `3` |
| `4 3 1` / `1 1 1 1` | 只 $1$ 张 CD 容量 $3$，最多 $3$ 首 | `3` |
| `5 5 2` / `3 3 3 3 3` | 每张装 $1$ 首（$3+3=6>5$），$2$ 张共 $2$ 首 | `2` |
| `3 2 2` / `3 3 3` | 每首都 $>T=2$，选不了 | `0` |

注意第二、三组正是"幽灵 CD"bug 的照妖镜：bug 版会输出 $4$ 和 $3$（多送一张 CD），修复后才是 $3$ 和 $2$。

## 二、思维链：完整证明

**记号。** 歌长 $a_0,\dots,a_{N-1}$（0-based），$a_i\ge1$。容量 $T$，CD 上限 $M$。状态 $dp[i][j][t]$：考虑完前 $i$ 首、已开 $j$ 张 CD、当前 CD 剩余 $t$ 分钟时的最大选中数。约定 $j=0$ 表示尚未开 CD，此时 $t=0$。初值 $dp[0][0][0]=0$，其余 $-\infty$。

---

### 引理 1（可行方案的段结构）

一个方案可行，当且仅当它选中的歌（按原顺序）可划分为 $c\le M$ 个**非空连续段**，每段时长和 $\le T$；选中数 = 各段歌数之和。

*证明*：题面要求"第 $i$ 张 CD 的最后一首创作时间早于第 $i+1$ 张的第一首"，且歌按创作时间排序。故若把选中的歌按原顺序列出，第 $1$ 张 CD 的歌必是其中一段前缀、第 $2$ 张是接下来一段……每张 CD 对应选中子序列的一个连续段，段间顺序与原序一致。每张 CD 容量 $T$ 即段和 $\le T$；CD 数 $\le M$ 即段数 $c\le M$；歌不拆分即每首完整属于某一段。反之，任何这样的划分都给出一个合法装盘方案。选中数显然是各段歌数之和。证毕。

---

### 引理 2（DP 状态与决策的完备性）

任何可行方案都能被"逐首三选一（跳过 / 塞当前 CD / 新开 CD）"的决策序列生成，且决策过程中 $j$ 等于已开 CD 数、$t$ 等于当前 CD 剩余容量。

*证明*：按引理 1，方案把选中歌切成 $c\le M$ 段。按原序扫描每首歌 $i$：
- 若 $i$ 未选中 → 决策"跳过"，$j,t$ 不变。
- 若 $i$ 选中且是某段的第一首：若它是第 $1$ 段第一首，此前 $j=0$，决策"新开 CD"，$j\to1,t\to T-a_i$；若它是第 $k\ge2$ 段第一首，此前刚结束第 $k-1$ 段，决策"新开 CD"，$j\to k,t\to T-a_i$。
- 若 $i$ 选中且不是段首 → 它接在当前段末尾，决策"塞当前 CD"，$t\to t-a_i$（因段和 $\le T$，必有 $a_i\le t$）。

每步决策都满足转移守卫（塞需 $j\ge1,a_i\le t$；新开需 $j<M,a_i\le T$——段和 $\le T$ 保证 $a_i\le T$，段数 $c\le M$ 保证新开时 $j<M$）。扫描结束 $j=c\le M$，选中数 = 决策中"塞 + 新开"的次数。故方案被决策序列生成，状态变量含义与约定一致。证毕。

---

### 引理 3（转移正确性与无后效性）

按 $i=0,\dots,N-1$ 递增、对每个 $(j,t)$ 用三选一转移更新 $dp[i+1]$，则 $dp[i][j][t]$ 恰为"前 $i$ 首、开 $j$ 张、当前剩 $t$"下的最大选中数；不可达状态为 $-\infty$。

*证明*：对 $i$ 归纳。

**基例 $i=0$**：未考虑任何歌，只能 $j=0,t=0$、选中 $0$ 首，$dp[0][0][0]=0$；其余状态不可达，$-\infty$。✓

**归纳步**：设 $dp[i][\cdot][\cdot]$ 正确。考虑前 $i+1$ 首的任一最优决策序列，其最后一步（第 $i$ 首的决策）必为三选一之一，且前 $i$ 步构成一个到达某状态 $(j',t')$ 的合法决策序列。由归纳假设，$dp[i][j'][t']$ 是前 $i$ 首在该状态下的最大选中数。最后一步：
- 跳过 → 状态 $(j',t')$ 不变，选中数 $+0$，转移到 $dp[i+1][j'][t']$；
- 塞（$j'\ge1,a_i\le t'$）→ 状态 $(j',t'-a_i)$，选中数 $+1$；
- 新开（$j'<M,a_i\le T$）→ 状态 $(j'+1,T-a_i)$，选中数 $+1$。

代码对每个可达 $dp[i][j'][t']$ 恰好执行这三种更新（取 $\max$），故 $dp[i+1][j][t]$ 收集了所有"最后一步到达 $(j,t)$"的方案的最大选中数。由引理 2，任何可行方案都被某决策序列生成，故不会遗漏；转移只从可达状态（$dp\ge0$）出发，不可达状态保持 $-\infty$。无后效性：第 $i$ 首的决策只依赖当前 $(j,t)$，不依赖更早的具体选择，故"前 $i$ 首的最优"可安全延拓。证毕。

---

### 引理 4（$j=0$ 约定与幽灵 CD 的排除）

约定 $j=0\Rightarrow t=0$，且"塞当前 CD"转移带守卫 $j>0$，则不存在"把歌塞进不存在的 CD"的非法转移；$j=0$ 的状态在整个 DP 中只有 $(0,0)$ 且值恒为 $0$。

*证明*：初值仅 $dp[0][0][0]=0$ 可达（$j=0,t=0$）。从 $j=0$ 状态出发的三种转移：
- 跳过 → $j=0,t=0$（仍 $(0,0)$）；
- 塞：守卫 $j>0$ 为假，**不执行**（即使不加守卫，$t=0<a_i$（$a_i\ge1$）也使 $a_i\le t$ 为假）；
- 新开 → $j=1$，离开 $j=0$。

故 $j$ 一旦 $\ge1$ 就不再回到 $0$（跳过/塞保持 $j$，新开使 $j$ 增），$j=0$ 仅存在于"尚未开任何 CD"的前缀，且唯一可达状态是 $(0,0)$、值 $0$。不存在 $j=0,t>0$ 的可达状态，因此"塞进当前 CD"在 $j=0$ 时绝不发生——幽灵 CD 被排除。

**反例（错误约定的危害）**：若初值设 $dp[0][0][T]=0$ 且塞转移无 $j>0$ 守卫，则 $j=0,t=T$ 可达，$a_i\le T$ 使"塞"执行，把歌放进 $j=0$ 的" phantom CD"，$j$ 仍 $0$；之后还能新开 $M$ 张真 CD，等效 $M+1$ 张，答案偏大。这正是叙事中 $N=9,T=9,M=2$ 翻车的根源。证毕。

---

### 引理 5（固定子序列下"尽量装满当前 CD"贪心最优——暴力校验器的依据）

给定一个选中的歌子序列（按原序），把它切成每段和 $\le T$ 的连续段，**最少段数**由贪心达到：从左到右，能塞进当前段就塞，塞不下才开新段。

*证明*：交换论证。设贪心段划分为 $G_1,G_2,\dots,G_g$，任一合法划分为 $O_1,O_2,\dots,O_o$。证 $g\le o$。

对段数归纳。贪心第一段 $G_1$ 是"和 $\le T$ 的最长前缀"。$O_1$ 也是某个前缀且和 $\le T$，由 $G_1$ 的最长性，$G_1$ 覆盖的歌数 $\ge O_1$ 覆盖的歌数，即 $G_1$ 的右端点 $\ge O_1$ 的右端点。

去掉各自第一段后，剩余子序列上贪心继续。由归纳假设，贪心在剩余部分用的段数 $\le$ 最优在剩余部分用的段数。但需注意剩余部分起点不同：贪心剩余从 $G_1$ 右端点之后开始，最优剩余从 $O_1$ 右端点之后开始，前者起点 $\ge$ 后者（$G_1$ 更长）。起点更靠后意味着剩余更短，贪心在更短序列上的段数 $\le$ 在更长序列上的段数（单调性：序列变短，最少段数不增——可把更长序列的最优划分限制到更短序列，去掉空段即得）。故 $g-1\le o-1$，即 $g\le o$。证毕。

**用途**：独立暴力枚举所有 $2^N$ 子集，对每个子序列用此贪心求最少段数，$\le M$ 则可行，取最大子集大小。引理 5 保证贪心段数 = 真实最少段数，故暴力判定可行性的充要条件正确，可作对拍基准。

---

### 引理 6（答案提取）

答案 $=\max_{0\le j\le M,0\le t\le T}dp[N][j][t]$。

*证明*：由引理 3，$dp[N][j][t]$ 是"考虑完全部 $N$ 首、开 $j$ 张、当前剩 $t$"的最大选中数。题目允许 CD 用不完（$j\le M$ 任意）、不关心最后剩余容量（$t$ 任意），故对所有合法 $(j,t)$ 取 $\max$ 即全局最大选中数。不可达状态为 $-\infty$，不影响 $\max$；$dp[N][0][0]=0$（一首没选）保证 $\max\ge0$。证毕。

---

### 引理 7（复杂度）

时间 $O(N\cdot M\cdot T)$，空间 $O(N\cdot M\cdot T)$。

*证明*：外层 $i$ 共 $N$ 次，内层 $(j,t)$ 共 $(M+1)(T+1)$ 个状态，每个状态常数次转移（三选一）。故时间 $O(N(M+1)(T+1))=O(NMT)$。代入 $20\times21\times21\approx8820$ 次状态更新，瞬间完成。空间为三维数组 $21^3$ 个 `int` $\approx37$ KB。证毕。

---

### 定理

程序输出最多可选中的歌曲数，复杂度 $O(NMT)$。

*证明*：引理 1 刻画可行方案的段结构；引理 2 证明逐首三选一决策完备；引理 3 证明 DP 转移正确且无后效；引理 4 排除幽灵 CD；引理 6 保证答案提取正确；引理 7 给出复杂度。引理 5 为对拍暴力提供正确性依据。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — "保序"= 选中子序列切成 $\le M$ 个连续段、每段和 $\le T$；选择与分段耦合，贪心选歌不可行。
- consider easier version — 固定子序列后，"最少段数"可由"尽量装满当前 CD"贪心最优（交换论证），这给出对拍暴力。
- classic problem solution — 逐首决策 DP：$dp[i][j][t]$ = 前 $i$ 首、开 $j$ 张 CD、当前剩 $t$ 分钟的最大选中数；三选一转移（跳过 / 塞当前 / 新开）。
- explore its property — 碰壁反例：$j=0$ 时若 $t=T$ 且塞转移无守卫，歌被塞进"幽灵 CD"，等效 $M+1$ 张；修复为 $j=0\Rightarrow t=0$ 且塞需 $j>0$。
- discuss by category — 不可达状态填 $-\infty$（全局默认 $0$ 会污染 $\max$）；$a_i>T$ 的歌自动只能跳过；答案对 $j\le M,t$ 任意取 $\max$（CD 可用不完）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,T,m` | 歌数、单 CD 容量、CD 上限 | `int`，读入 | 均 $\le20$ |
| `a[i]` | 第 $i$ 首歌时长（0-based） | `int[mxn]`，读入 | $a_i\ge1$ |
| `mxn` | 数组尺寸 $25$ | `constexpr int` | $20+5$ 松弛 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 不可达填 `-inf` |
| `dp[i][j][t]` | 前 $i$ 首、开 $j$ 张 CD、当前剩 $t$ 分钟的最大选中数 | `int[mxn][mxn][mxn]` | **全填 `-inf`**，仅 `dp[0][0][0]=0` |
| `j` | 已开 CD 数 | $0\dots M$ | $j=0$ 表示没开 CD，此时 $t=0$ |
| `t` | 当前 CD 剩余分钟 | $0\dots T$ | 塞需 $j>0$ 且 $a_i\le t$ |
| `ans` | 最大选中数 | `int`，初值 $0$ | $\max_{j,t}dp[n][j][t]$ |

### 算法步骤

1. I/O 加速三行。
2. 读 `n,T,m` 与 $n$ 个歌长。
3. `fill_n(&dp[0][0][0],mxn*mxn*mxn,-inf)`；`dp[0][0][0]=0`。
4. 对 $i=0,\dots,n-1$，对 $j=0,\dots,m$，对 $t=0,\dots,T$：若 `dp[i][j][t]<0` 跳过；否则三选一更新 `dp[i+1]`：
   - 跳过：`dp[i+1][j][t]=max(...,cur)`；
   - 塞（`j>0&&a[i]<=t`）：`dp[i+1][j][t-a[i]]=max(...,cur+1)`；
   - 新开（`j<m&&a[i]<=T`）：`dp[i+1][j+1][T-a[i]]=max(...,cur+1)`。
5. `ans=max(ans,dp[n][j][t])` 遍历所有 $j,t$。
6. 输出 `ans`。

### 复杂度

- 时间：$O(NMT)\approx8820$ 次状态更新。
- 空间：$O(NMT)\approx37$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；手造 `3 3 2 / 1 2 3`→`3`、`4 3 1 / 1 1 1 1`→`3`、`5 5 2 / 3 3 3 3 3`→`2`、`3 2 2 / 3 3 3`→`0` 均手算吻合；$500$ 组随机（$N\le12,T\le10,M\le5$）+ $15$ 组 $N=18$ 大数据与"枚举子集 + 贪心分段"独立暴力逐一一致（修复幽灵 CD bug 后）。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2736 [USACO3.4] “破锣摇滚”乐队 Raucous Rockers
// dp[i][j][t]=考虑完前 i 首歌、已开 j 张 CD、当前 CD 还剩 t 分钟时，最多选了几首。
// j=0 表示还没开 CD，此时 t=0（没有「当前 CD」可塞）。
// 每首歌三选一：跳过 / 塞进当前 CD（j>0 且 a[i]<=t）/ 新开一张 CD（j<M 且 a[i]<=T）。
// 顺序约束由「按 i 递增决策、CD 只前进不回头」自动保证。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25},inf{1145141919};

int n,T,m,a[mxn],dp[mxn][mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>T>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	fill_n(&dp[0][0][0],mxn*mxn*mxn,-inf);	// 不可达状态必须显式填 -INF
	dp[0][0][0]=0;	// 还没开 CD：j=0,t=0
	for(int i=0;i<n;++i)
		for(int j=0;j<=m;++j)
			for(int t=0;t<=T;++t)
			{
				if(dp[i][j][t]<0)
					continue;
				int cur=dp[i][j][t];
				dp[i+1][j][t]=max(dp[i+1][j][t],cur);	// 跳过第 i 首
				if(j>0&&a[i]<=t)	// 放进当前 CD（必须已有 CD）
					dp[i+1][j][t-a[i]]=max(dp[i+1][j][t-a[i]],cur+1);
				if(j<m&&a[i]<=T)	// 新开一张 CD
					dp[i+1][j+1][T-a[i]]=max(dp[i+1][j+1][T-a[i]],cur+1);
			}
	int ans=0;
	for(int j=0;j<=m;++j)
		for(int t=0;t<=T;++t)
			ans=max(ans,dp[n][j][t]);
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **状态三维**：$i$（决策到第几首）、$j$（已开 CD 数）、$t$（当前 CD 剩余）。三者都 $\le20$，数组 $21^3$ 极小。
- **$j=0$ 的约定是命门**：$j=0$ 表示没有当前 CD，$t$ 必须为 $0$，初值 `dp[0][0][0]=0`。若误设 `dp[0][0][T]=0` 且塞转移不加 `j>0`，歌会被塞进"幽灵 CD"，等效多送一张 CD，答案偏大（叙事中的翻车反例）。
- **塞转移守卫 `j>0&&a[i]<=t`**：双重保险——既要求已有 CD，又要求装得下。
- **新开转移 `j<m&&a[i]<=T`**：CD 没用完且这首歌本身装得下一张 CD。
- **不可达填 `-inf`**：求 $\max$ 的 DP，全局默认 $0$ 会让不可达状态凭空贡献，必须 `fill_n(&dp[0][0][0],mxn*mxn*mxn,-inf)`。
- **答案取 $\max_{j,t}$**：CD 可用不完、剩余容量任意，故遍历所有终态取最大。
- 顺序约束无需额外处理：按 $i$ 递增决策、CD 编号只增不减，天然保证"前一张的最后一首早于后一张的第一首"。
