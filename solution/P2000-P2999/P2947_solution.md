# P2947 [USACO09MAR] Look Up S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 头奶牛排成一排（$1\le N\le10^5$），第 $i$ 头身高 $H_i$（$1\le H_i\le10^6$）。对每头牛 $i$，找**下标最小**的 $j$ 满足 $j>i$ 且 $H_j>H_i$（严格高于，等高不算），输出 $j$；不存在则输出 $0$。这就是经典的"右侧第一个更大元素"（Next Greater Element），只是把"更大"写成了"仰望"。

两个立刻要抠住的边界：**严格大于**——身高相同的牛互相不能仰望；**最近**——不是右边最高的，而是右边第一个比它高的。

**第一反应：暴力。** 每头牛向右扫到第一个更高者，最坏（身高严格递减）每头都要扫到底，$O(N^2)=10^{10}$，超时。

**第二步：换个视角——不是"每头牛去找答案"，而是"每个新来的牛去宣布谁的答案"。** 从左往右扫描，维护一个"还在等待答案的牛"的名单。新牛 $i$ 到来时，名单里所有身高 $<H_i$ 的牛，答案都是 $i$（因为它们是第一次遇到更高者——之前每一步都没能解决它们）。宣布完把它们移出名单，再把 $i$ 加入名单等待。

这个朴素名单版仍然可能 $O(N^2)$：身高递减时名单越积越长，每头新牛都要把整个名单扫一遍（虽然一个都宣布不了）。**卡住之后观察名单的结构**：

> 名单里任意两头牛 $k_1<k_2$（都还没等到答案），必有 $H_{k_1}\ge H_{k_2}$。

为什么？因为 $k_2$ 入名单那一刻，如果 $H_{k_1}<H_{k_2}$，$k_1$ 就该被 $k_2$ 宣布答案、移出名单了，不可能还留着。也就是说，**等待名单自动按身高递减排列**——这不是我们刻意维护的，是"等待"这个身份自带的性质！

**第三步：递减名单 ⇒ 栈。** 既然名单身高递减，新牛 $i$ 能宣布的牛（身高 $<H_i$）恰好是名单**末尾的一段连续后缀**。于是只需要一个栈：从栈顶往下，只要栈顶身高 $<H_i$ 就弹出并记答案，遇到第一个 $\ge H_i$ 的停手，然后把 $i$ 压栈。每头牛进栈一次、出栈至多一次，总操作 $O(N)$。这就是单调栈。

**第四步：等高陷阱。** 弹栈条件必须是**严格** `h[栈顶]<h[i]`。如果手滑写成 `<=`，等高的牛会被弹出：要么把答案错记成等高者（违反严格大于），要么直接丢弃、让它永远错过后面真正的更高者。反例：身高 `2 2 3`，正确答案 `3 3 0`；若按 `<=` 弹，第一头牛在处理第二头时就被弹出，答案变成 $0$，错。

**第五步：输出约定。** 内部 0-based，`ans[i]` 初始化为 $-1$ 表示"没有仰望对象"，输出 `ans[i]+1`：有答案时恰好还原成 1-based 编号，无答案时 $-1+1=0$，与题目要求的 $0$ 严丝合缝，一个哨兵两用。

**手造数据核对**（题面给了输入/输出说明，可直接当样例；另造三组打边界）：

| 输入身高 | 手算 | 输出 |
|---|---|---|
| `3 2 6 1 1 2`（题面说明） | 牛1,2→牛3；牛4,5→牛6（牛5身高1，牛6身高2严格更高）；牛3,6 无 | `3 3 0 6 6 0` |
| `2 2 3` | 前两头等高互不仰望，都等到第三头 | `3 3 0` |
| `5 4 3 2 1` | 严格递减，谁也没有更高者 | `0 0 0 0 0` |
| `1 1 1 1` | 全等高，严格大于不成立 | `0 0 0 0` |

四组全部与程序输出一致（另测 $N=1$ 输出 `0`）。

## 二、思维链：完整证明

**记号。** 牛下标 $0\le i<N$（内部 0-based），身高 $h_i$。定义答案 $a(i)=\min\{j:j>i,\ h_j>h_i\}$，集合为空时 $a(i)$ 不存在（输出 $0$）。栈 `stk[0..top-1]`，`stk[top-1]` 为栈顶。算法：依次处理 $i=0..N-1$，先反复执行"若 `top>0` 且 $h_{\texttt{stk[top-1]}}<h_i$，则弹出栈顶 $k$ 并令 $\texttt{ans}[k]=i$"，再把 $i$ 压栈。

---

### 引理 1（栈不变量）

处理完前 $i+1$ 头牛（即 $0..i$ 都已入栈过）后：

(a) 栈中下标自底向顶严格递增；
(b) 栈中身高自底向顶非严格递减（底 $\ge$ 顶）；
(c) 栈中每个下标 $k$ 满足：不存在 $j\in(k,i]$ 使 $h_j>h_k$，且 $\texttt{ans}[k]$ 尚未被赋值（仍为 $-1$）。

*证明*：对 $i$ 归纳。$i=-1$（空栈）三条平凡成立。

设处理完 $0..i-1$ 后成立，考察处理 $i$：

(a) 弹出只删元素不改相对顺序；$i$ 比栈中所有下标都大（它们都 $<i$），压到栈顶后仍递增 ✓。

(b) 弹栈循环结束时，要么栈空，要么栈顶 $k'$ 满足 $h_{k'}\ge h_i$（否则会继续弹）。压入 $i$ 后新栈顶对 $(k',i)$ 满足 $h_{k'}\ge h_i$；其余相邻对未被触动，由归纳假设仍递减 ✓。

(c) 分两类。**被弹出的 $k$**：不属于处理后的栈，无需验证（其答案正确性由引理 2 单独证）。**留下的 $k$**：由归纳假设，$(k,i-1]$ 中无更高者；而 $k$ 没被弹出说明弹栈循环在它之上停住了或根本没轮到它——无论哪种，循环终止条件保证此刻栈中每个元素身高都 $\ge h_i$（被弹的是顶部连续一段，剩下的都 $\ge h_i$；严格论证：弹栈只从顶往下进行，停止时栈顶 $\ge h_i$，由 (b) 栈内其余元素 $\ge$ 栈顶 $\ge h_i$）。故 $h_k\ge h_i$，$i$ 也不是 $k$ 的更高者，$(k,i]$ 中无更高者 ✓；$\texttt{ans}[k]$ 只在弹出时赋值，$k$ 从未被弹出故仍为 $-1$ ✓。证毕。

---

### 引理 2（弹出时刻的赋值就是最近仰望对象）

若下标 $k$ 在处理 $i$ 时被弹出，则 $a(k)=i$，即 $\texttt{ans}[k]=i$ 正确。

*证明*：弹出条件给出 $h_i>h_k$ 且 $i>k$（$k$ 在栈中，下标都小于当前 $i$），故 $i$ 是 $k$ 的一个合法仰望对象，$a(k)\le i$。

再证不存在更近的：任取 $j$ 满足 $k<j<i$。$k$ 在处理 $i$ 时才**首次**被弹出（每个下标只入栈一次、至多弹出一次），所以在处理 $j$ 的整个过程中 $k$ 一直在栈里。处理 $j$ 时若 $h_j>h_k$，由引理 1(c) 的论证，弹栈循环会把栈中所有身高 $<h_j$ 的元素弹光，$k$ 必在其列（$k$ 在栈中且 $h_k<h_j$，而循环停止时栈内元素都 $\ge h_j$），与"$k$ 存活到 $i$"矛盾。故 $h_j\le h_k$，$j$ 不是合法仰望对象。

于是 $(k,i)$ 开区间内没有合法对象，$i$ 是最近的，$a(k)=i$。证毕。

---

### 引理 3（终态栈中元素无解）

全部 $N$ 头牛处理完后，仍留在栈中的下标 $k$ 满足 $a(k)$ 不存在，输出 $0$ 正确。

*证明*：在引理 1 中取 $i=N-1$，(c) 给出：不存在 $j\in(k,N-1]$ 使 $h_j>h_k$。而 $k$ 的仰望对象只可能在 $(k,N-1]$ 中，故集合为空，$a(k)$ 不存在。程序对从未赋值的 $\texttt{ans}[k]=-1$ 输出 $-1+1=0$ ✓。证毕。

---

### 引理 4（弹栈条件必须严格：`<=` 的反例）

把弹栈条件放宽为 $h_{\texttt{stk[top-1]}}\le h_i$ 是错误的。

*证明*（构造反例）：$h=[2,2,3]$，正确答案 $a(0)=2,a(1)=2,a(2)$ 不存在（1-based 输出 `3 3 0`）。

用 `<=` 版模拟：处理 $i=0$，栈 $[0]$。处理 $i=1$：$h_0=2\le h_1=2$，弹出 $0$ 并令 $\texttt{ans}[0]=1$——但 $h_1=h_0$，不满足严格大于，答案已错；即便改成"弹出但不赋值"，$0$ 也从此丢失，处理 $i=2$（$h=3$）时只能给 $1$ 赋值，$\texttt{ans}[0]$ 永远是 $-1$，输出 $0$，仍错（正确是 $3$）。两种修补都失败，根源是**等高者不能解决等待者，等待者必须继续留在栈里**。严格版中 $i=1$ 不弹 $0$，栈 $[0,1]$（身高 $2,2$ 非严格递减，合法）；$i=2$ 时 $2<3$ 连弹两个，$\texttt{ans}[0]=\texttt{ans}[1]=2$ ✓。证毕。

---

### 引理 5（复杂度）

时间 $O(N)$，空间 $O(N)$。

*证明*：每个下标恰好入栈一次；弹出至多一次（弹出后不再入栈）。弹栈循环的总执行次数 $\le$ 总弹出次数 $\le N$；每次循环体 $O(1)$。其余操作（读入、比较、压栈、输出）每头牛 $O(1)$。故总时间 $O(N)$。空间：$h,\texttt{ans},\texttt{stk}$ 各一个长度 $N$ 的数组，栈深 $\le N$，$O(N)$。代入 $N=10^5$：约几 $\times10^5$ 次基本操作。证毕。

---

### 定理

程序对每头牛输出其最近严格更高者的 1-based 编号（无则 $0$），时间 $O(N)$、空间 $O(N)$。

*证明*：每头牛要么在某步被弹出——由引理 2 得到正确的 $a(k)$；要么留到终态——由引理 3 得到正确的"无解"。两种情形穷尽所有下标（每人恰好入栈一次）。引理 1 保证整个过程栈结构合法、弹栈只会发生在顶部连续段，算法良定义；引理 4 说明严格比较不可放松；引理 5 给出复杂度。输出时 `ans[i]+1` 把 0-based 答案还原为 1-based、把哨兵 $-1$ 还原为 $0$。证毕。

## 三、模式总结（按实际思考顺序）

1. **consider easier version** — 暴力每头牛向右扫，$O(N^2)=10^{10}$ 超时；确认需要批量处理。
2. **explore its property** — 反转视角：不是"牛找答案"，而是"新牛宣布等待名单中所有更矮者的答案"。
3. **explore its property** — 等待名单自动身高递减（矮者早被后来者解决）⇒ 能被新牛解决的是名单末尾连续段。
4. **classic problem solution** — 递减名单 = 单调栈：栈顶严格更矮就弹出记答案，每元素进出各一次，$O(N)$。
5. **discuss by category** — 等高不能弹（严格 `<`，反例 `2 2 3`）；无解哨兵 $-1$ 输出时 $+1$ 恰好变 $0$，与 1-based 还原共用一个加法。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 牛数 $N\le10^5$ | `int` | 读入 |
| `mxn` | $10^5+5$ | `constexpr int` | 约束 $+5$ |
| `h[i]` | 第 $i$ 头牛身高（0-based） | `int[mxn]` | 读入 |
| `ans[i]` | $i$ 的最近仰望对象下标（0-based） | `int[mxn]` | **显式 `fill_n(ans,n,-1)`**；$-1$=无解，输出 $+1$ 变 $0$ |
| `stk[0..top-1]` | 等待中的牛下标，身高自底向顶非严格递减 | `int[mxn]` | 空栈开始 |
| `top` | 栈内元素个数，栈顶是 `stk[top-1]` | `int` | 全局默认 $0$=空栈 |

### 算法步骤

1. I/O 加速三行；读 `n`；`fill_n(ans,n,-1)`。
2. 对 $i=0..N-1$：读 `h[i]`；当栈非空且 `h[stk[top-1]]<h[i]` 时，弹出栈顶 $k$ 并令 `ans[k]=i`；把 $i$ 压栈。
3. 对 $i=0..N-1$ 输出 `ans[i]+1` 与 `'\n'`。

### 复杂度

- 时间：$O(N)$（每下标进出栈各至多一次）。
- 空间：$O(N)$，三个长度 $10^5+5$ 的 `int` 数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面说明样例（`3 2 6 1 1 2`）与三组手造边界（等高、严格递减、全等高）及 $N=1$ 全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2947 [USACO09MAR] Look Up S
// 单调栈：栈内身高自底向顶非严格递减；新牛严格高于栈顶时，栈顶就找到了最近仰望对象
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n,h[mxn],ans[mxn],stk[mxn],top;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	fill_n(ans,n,-1);	// -1=无仰望对象；输出时 +1 恰好变 0
	for(int i=0;i<n;++i)
	{
		cin>>h[i];
		while(top&&h[stk[top-1]]<h[i])	// 严格小于才弹：等高不算仰望，不能弹
			ans[stk[--top]]=i;
		stk[top++]=i;
	}
	for(int i=0;i<n;++i)
		cout<<ans[i]+1<<'\n';
	return 0;
}
```

### 代码说明

- **手写数组栈**：`stk`+`top` 两个全局量即可，`stk[top-1]` 是栈顶，`--top` 弹出、`top++` 压入，比 `std::stack` 更省更直观。
- **弹栈条件严格 `<`**：等高者互相不能仰望，必须继续等待（引理 4 的反例 `2 2 3`）。这也让栈保持"非严格递减"而非"严格递减"，两者都合法，但只有前者正确。
- `ans` 是"未定义"语义数组，**必须显式 fill 成 $-1$**——全局默认 $0$ 在这里是合法的 0-based 下标，不 fill 会把所有无解牛静默错报成"仰望第 1 头"。这是全局数组零初始化陷阱的又一实例。
- `ans[i]+1` 一个加法干两件事：0-based → 1-based 还原；哨兵 $-1$ → 题目要求的 $0$。
- 边读边处理：身高读入后立即进栈逻辑，不需要第二遍扫描；答案数组最后统一输出。
