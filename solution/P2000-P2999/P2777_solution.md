# P2777 [AHOI2016初中组] 自行车比赛 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 位选手（$3\le N\le3\times10^5$），第 $i$ 位已有累计分 $B_i$（$0\le B_i\le2\times10^6$）。最后一天按名次发放 $N,N-1,\dots,1$ 分（名次互不相同，即得分是 $\{1,\dots,N\}$ 的一个排列）。问有多少位选手**有可能**成为最终冠军——存在一种最后一天的名次安排，使他的累计总分**严格高于**其他所有人。

先抠一下"冠军"的口径：题面说"按照累计得分决出冠军""获得累计总分第一名"。若允许并列，$B=[0,1,2],N=3$ 时给 0 号发 3 分、1 号发 2 分、2 号发 1 分，三人总分都是 3，"并列第一"算不算冠军？我按**严格第一**理解（冠军是唯一的总分最高者），这也是本题的标准口径；上面这组数据恰好能区分两种解读（严格口径答案为 2，并列口径为 3），后面用它自检。

**第一步：把"存在性"变成"最优安排"。** 选手 $i$ 有可能夺冠，当且仅当在**对他最有利**的安排下他能严格第一。最有利的安排显然有两部分：

1. 他自己拿满 $N$ 分——直觉上"自己分越高越好"，严格证明用交换：若某个夺冠安排里他只拿 $k<N$ 分，把拿 $N$ 分的那个人的分与他互换，他的总分升高、对方降低、其他人不变，他仍然严格第一。所以**不妨设他拿 $N$ 分**。
2. 其余 $N-1$ 人瓜分 $\{1,\dots,N-1\}$，要让**其他人的最大总分尽量小**。

**第二步：其他人怎么分才"压得最狠"？** 猜：分数高的人拿低分（反序配对）。小例子验证：其他人已有分 $[0,5]$，可发 $\{1,2\}$。同序（0 拿 1、5 拿 2）最大总分 $7$；反序（0 拿 2、5 拿 1）最大总分 $6$。反序更优。一般证明用相邻交换：只要存在"分低的人反而拿低分"的相邻对，交换这两人的得分，最大总分不增；不断交换直到完全反序。于是候选人 $i$ 的判定条件就是：

$$B_i+N\;>\;\max_{\text{其他人 }j}\bigl(B_j+\text{反序发给 }j\text{ 的分}\bigr).$$

**第三步：暴力与瓶颈。** 对每个 $i$ 扫一遍其他人算最大值：$O(N^2)=9\times10^{10}$，只能拿 50%（$N\le10^4$ 时 $10^8$ 勉强）。瓶颈是**每个候选人都要重算一遍"其他人的最大值"**。能不能预处理？

**第四步：排序后拆开看。** 把 $B$ **升序**排序。候选人 $i$ 拿 $N$ 分后，其他人按升序排是 $c_0\le\cdots\le c_{N-2}$（即去掉 $B_i$ 的序列），反序配对给 $c_j$ 发 $N-1-j$ 分。定义

$$f_j=B_j+(N-1-j)$$

——"升序第 $j$ 人在反序分配下的虚拟总分"。关键观察：去掉 $i$ 会让下标**错位一格**：

- $j<i$ 时 $c_j=B_j$，总分 $=f_j$；
- $j\ge i$ 时 $c_j=B_{j+1}$，总分 $=B_{j+1}+N-1-j=f_{j+1}+1$。

所以其他人的最大值恰好拆成两段：

$$M_i=\max\Bigl(\underbrace{\max_{j<i}f_j}_{\text{前缀最大值}},\;\underbrace{\max_{j>i}f_j}_{\text{后缀最大值}}+1\Bigr).$$

前缀/后缀最大值各扫一遍预处理，每个候选人 $O(1)$ 判定。总复杂度 $O(N\log N)$（排序瓶颈）。

**第五步：一个漂亮的副产品。** 可以证明：**若 $i$ 能夺冠，则 $i+1$（分更高者）也能**——冠军集合是排序后的一个后缀。特别地，最高分者永远能夺冠（答案 $\ge1$）。这给了另一种解法（二分边界）和一个免费的正确性自检。

**手造数据核对**（题面无样例，自造三组）：

```
N=3, B=[0,1,2]：
  0 号：0+3=3；其他人 [1,2] 反序发 2,1 → 总分 3,3，最大 3。3>3 不成立 ✗
  1 号：1+3=4；其他人 [0,2] 反序发 2,1 → 总分 2,3，最大 3。4>3 ✓
  2 号：2+3=5；其他人 [0,1] 反序发 2,1 → 总分 2,2，最大 2。5>2 ✓
  答案 2（正是区分"严格/并列"口径的那组）

N=3, B=[0,0,0]：任何人拿 3，其他人最多 0+2=2<3，答案 3。

N=4, B=[10,0,0,0]：
  10 号：10+4=14，其他人最大 0+3=3 ✓
  0 号：0+4=4；其他人 [0,0,10] 反序发 3,2,1 → 总分 3,2,11，最大 11 ✗
  答案 1。
```

另外用 $N\le6$ 的 3000 组随机数据与"枚举所有得分排列"的暴力自检，零差异（暴力仅用于验证，正解是前缀/后缀做法）。

## 二、思维链：完整证明

**记号。** 升序排序后 $b_0\le b_1\le\cdots\le b_{n-1}$（即排序后的 $B$）。最后一天的得分是 $\{1,\dots,n\}$ 的排列 $p$，选手 $j$ 的总分为 $b_j+p_j$。候选人 $i$ **能夺冠**指存在排列 $p$ 使 $b_i+p_i>b_j+p_j\ (\forall j\ne i)$。定义 $f_j=b_j+(n-1-j)$，$\mathrm{pre}_i=\max_{j<i}f_j$（$\mathrm{pre}_0=-\infty$），$\mathrm{suf}_k=\max_{j\ge k}f_j$（$\mathrm{suf}_n=-\infty$）。

---

### 引理 1（候选人拿满 $n$ 分是无损假设）

$i$ 能夺冠 $\iff$ 存在排列 $p$ 使 $p_i=n$ 且 $b_i+n>b_j+p_j\ (\forall j\ne i)$。

*证明*：($\Leftarrow$) 平凡。($\Rightarrow$) 设夺冠排列为 $p$，$p_i=k$。若 $k=n$ 已完成。否则设 $p_\ell=n$（$\ell\ne i$，排列中 $n$ 必有人拿）。构造 $p'$：$p'_i=n,\ p'_\ell=k$，其余不变。则 $i$ 的总分增加 $n-k>0$，$\ell$ 的总分减少 $n-k<0$，其他人不变。原安排中 $b_i+k$ 严格大于所有其他总分，新安排中 $b_i+n>b_i+k>$ 所有 $j\notin\{i,\ell\}$ 的总分，且 $b_i+n>b_i+k>b_\ell+n>b_\ell+k$。故 $p'$ 仍使 $i$ 严格夺冠。证毕。

---

### 引理 2（反序配对最小化"其他人的最大总分"）

设 $c_0\le c_1\le\cdots\le c_{m-1}$（$m=n-1$），$q$ 是 $\{1,\dots,m\}$ 的任一排列。则

$$\max_{0\le j<m}(c_j+q_j)\;\ge\;\max_{0\le j<m}\bigl(c_j+(m-j)\bigr),$$

即"最大 $c$ 配最小分、次大配次小……"的反序配对使最大值最小。

*证明*：对排列 $q$ 定义**升序对数** $\mathrm{inv}(q)=\#\{(a,b):a<b,\ q_a<q_b\}$。$\mathrm{inv}(q)=0\iff q$ 严格递减 $\iff q_j=m-j$（值互异）。

若 $q$ 不严格递减，存在**相邻**位置 $j$ 使 $q_j<q_{j+1}$。交换这两个值，得到 $q'$。考察最大值的变化：

- 位置 $j,j+1$ 上：原来的两个和是 $c_j+q_j,\ c_{j+1}+q_{j+1}$，其中较大者为 $c_{j+1}+q_{j+1}$（因 $c_j\le c_{j+1}$ 且 $q_j<q_{j+1}$）。交换后两个和是 $c_j+q_{j+1},\ c_{j+1}+q_j$，两者都 $\le c_{j+1}+q_{j+1}$（前者因 $c_j\le c_{j+1}$，后者因 $q_j<q_{j+1}$）。故这两个位置的最大值**不增**。
- 其他位置的和完全不变。

所以 $\max(c+q')\le\max(c+q)$。再看 $\mathrm{inv}$：交换相邻的 $q_j<q_{j+1}$ 后，$(j,j+1)$ 这一对从升序变降序，贡献 $-1$；对任何 $k\notin\{j,j+1\}$，$k$ 与 $j,j+1$ 中每个位置的"升序/降序"关系只取决于 $q_k$ 与集合 $\{q_j,q_{j+1}\}$ 中各值的大小以及 $k$ 在 $j,j+1$ 的哪一侧——交换 $j,j+1$ 两位置的值不改变 $k$ 与这两位置构成的升序对**总数**（两个值还在同一侧，只是换了位置）。故 $\mathrm{inv}(q')=\mathrm{inv}(q)-1$。

从任意 $q$ 出发反复做此交换，$\mathrm{inv}$ 严格递减、非负，故有限步内到 $0$，即严格递减排列 $q_j=m-j$；全程最大值不增。所以反序配对的最大值 $\le$ 任意配对的最大值。证毕。

---

### 引理 3（夺冠判据）

记 $M_i=\max\bigl(\mathrm{pre}_i,\ \mathrm{suf}_{i+1}+1\bigr)$。则 $i$ 能夺冠 $\iff b_i+n>M_i$。

*证明*：先证 $M_i$ 就是" $i$ 拿 $n$ 分时，其他人按最优（反序）分配的最大总分"。其他人升序序列为 $c_j=b_j\ (j<i)$、$c_j=b_{j+1}\ (j\ge i)$，共 $m=n-1$ 个。由引理 2，最优分配给 $c_j$ 发 $m-j=n-1-j$ 分：

- $j<i$：总分 $b_j+(n-1-j)=f_j$，这些的最大值 $=\mathrm{pre}_i$；
- $j\ge i$：总分 $b_{j+1}+(n-1-j)=\bigl(b_{j+1}+(n-1-(j+1))\bigr)+1=f_{j+1}+1$，$j+1$ 跑遍 $i+1..n-1$，最大值 $=\mathrm{suf}_{i+1}+1$。

两段取 $\max$ 即 $M_i$（$i=0$ 时左段为空 $=-\infty$，$i=n-1$ 时右段为空 $=-\infty$，公式仍成立）。

再证判据。($\Leftarrow$) 取该反序分配并令 $p_i=n$，则 $i$ 的总分 $b_i+n>M_i\ge$ 每个其他人的总分，严格夺冠 ✓。

($\Rightarrow$) 反证：设 $b_i+n\le M_i$ 但 $i$ 能夺冠。由引理 1 可设夺冠排列中 $p_i=n$，于是 $i$ 的总分 $=b_i+n$。其余人拿到 $\{1,\dots,n-1\}$ 的某个排列，由引理 2，他们的最大总分 $\ge M_i\ge b_i+n=$ $i$ 的总分，与"严格大于所有人"矛盾。证毕。

---

### 引理 4（前缀/后缀预处理的正确性）

代码中 `pre[0]=-inf`，`pre[i]=max(pre[i-1],f[i-1])`；`suf[n]=-inf`，`suf[i]=max(suf[i+1],f[i])`。则 $\mathrm{pre}_i=\max_{j<i}f_j$、$\mathrm{suf}_i=\max_{j\ge i}f_j$，且判定式 `b[i]+n>max(pre[i],suf[i+1]+1)` 与引理 3 一致。

*证明*：对 $i$ 归纳。$\mathrm{pre}_0$：空集最大值定义为 $-\infty$，代码置 `-inf` ✓（**不能用全局默认 0**：$f_j$ 可为负吗？$f_j=b_j+n-1-j\ge0+ n-1-(n-1)=0$，其实非负，但 $-\infty$ 哨兵仍必须显式设置——若用 0 当"空集最大值"，在 $f$ 全为 0 时碰巧对，逻辑上却是把"无人"当成"有个 0 分的人"，一旦数据允许负分就静默出错；显式 `-inf` 才是语义正确的空集最大值）。$\mathrm{pre}_i=\max(\max_{j<i-1}f_j,\ f_{i-1})=\max(\mathrm{pre}_{i-1},f_{i-1})$ ✓。后缀对称。判定式逐字对应引理 3。

数值范围：$b_i+n\le2\times10^6+3\times10^5<2^{31}$，$f_j\le2\times10^6+n$，`suf[i+1]+1` 在空段时为 $-\texttt{inf}+1$ 仍是极小值，`int` 全程无溢出。证毕。

---

### 引理 5（冠军集合是后缀）

若 $i$ 能夺冠（$i<n-1$），则 $i+1$ 也能。特别地 $n-1$（最高分者）恒能夺冠，答案 $\ge1$。

*证明*：已知 $b_i+n>M_i=\max(\mathrm{pre}_i,\mathrm{suf}_{i+1}+1)$，且 $b_{i+1}\ge b_i$。考察

$$M_{i+1}=\max(\mathrm{pre}_{i+1},\ \mathrm{suf}_{i+2}+1)=\max(\mathrm{pre}_i,\ f_i,\ \mathrm{suf}_{i+2}+1).$$

逐项与 $b_{i+1}+n$ 比较：

- $\mathrm{pre}_i\le M_i<b_i+n\le b_{i+1}+n$；
- $f_i=b_i+n-1-i\le b_i+n-1<b_i+n\le b_{i+1}+n$；
- $\mathrm{suf}_{i+2}+1\le\mathrm{suf}_{i+1}+1\le M_i<b_{i+1}+n$。

故 $M_{i+1}<b_{i+1}+n$，由引理 3，$i+1$ 能夺冠。对 $i=n-1$：$M_{n-1}=\mathrm{pre}_{n-1}=\max_{j<n-1}f_j\le b_{n-2}+n-1\le b_{n-1}+n-1<b_{n-1}+n$，恒夺冠。证毕。

**推论**：答案 $=n-(\text{最小的能夺冠下标})$，可以二分边界（每次 $O(n)$ 验证，总 $O(n\log n)$）；本解法直接 $O(n)$ 扫全部候选人，同样复杂度且更直白。后缀性也是免费自检：程序输出的冠军集合必须恰为排序后的一个后缀。

---

### 引理 6（复杂度）

时间 $O(n\log n)$，空间 $O(n)$。

*证明*：排序 $O(n\log n)$；$f,\mathrm{pre},\mathrm{suf}$ 与判定各一遍 $O(n)$。数组 `b,f,pre,suf` 各 $O(n)$。代入 $n=3\times10^5$：排序约 $n\log_2n\approx5.5\times10^6$ 次比较，远低于时限。证毕。

---

### 定理

程序输出的 `ans` 恰为有可能获得严格总分第一的选手数，复杂度 $O(n\log n)$。

*证明*：引理 1 把存在性归约到"候选人拿 $n$ 分"；引理 2 证明反序配对最小化其他人最大值；引理 3 给出充要判据 $b_i+n>M_i$；引理 4 证明 $M_i$ 的前缀/后缀实现与数值安全；引理 5 给出后缀结构（自检与替代解法）；引理 6 给出复杂度。判据对每个 $i$ 独立成立，计数即答案。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "有可能夺冠"是存在性问题 ⇒ 转化为对候选人最有利的安排：自己拿满 $n$ 分 + 其他人最大总分最小化。
2. **classic problem solution** — 交换论证（第一步）：候选人与 $n$ 分持有者互换得分，自己升对方降，夺冠性保持 ⇒ 拿 $n$ 分是无损假设。
3. **classic problem solution** — 交换论证（第二步）：其他人"分高者得低分"反序配对最小化最大值；相邻交换 + 升序对数严格递减证明过程终止于反序。
4. **consider easier version** — 每候选人 $O(n)$ 重算其他人最大值，$O(n^2)$ 拿 50%；瓶颈是重复计算。
5. **reduce to easier problem** — 升序排序后去掉 $i$ 造成下标错位一格：左半段总分 $=f_j$、右半段 $=f_{j+1}+1$ ⇒ 前缀/后缀最大值，$O(1)$ 判定每人。
6. **explore its property** — 冠军集合是排序后的后缀（分高者恒能夺冠），可二分边界，也用作正确性自检。
7. **discuss by category** — "冠军"按严格总分第一解读，并列不算；手造 $[0,1,2],n=3$ 区分两种口径（答案 2）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 选手数，$\le3\times10^5$ | `int` | 读入 |
| `b[i]` | 升序排序后的已有分 | `int[mxn]` | 读入后 `sort` |
| `f[i]` | $b_i+n-1-i$，反序分配下升序第 $i$ 人的虚拟总分 | `int[mxn]` | 排序后一遍算出 |
| `pre[i]` | $\max_{j<i}f_j$（左段最大值） | `int[mxn]` | `pre[0]=-inf`，**显式**设哨兵 |
| `suf[i]` | $\max_{j\ge i}f_j$（右段最大值） | `int[mxn]` | `suf[n]=-inf` |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 空集最大值用 `-inf` |
| `ans` | 能严格夺冠的人数 | `int` | 0 起累加 |

### 算法步骤

1. I/O 加速三行；读 `n` 与 `b[0..n-1]`；升序排序。
2. 算 `f[i]=b[i]+n-1-i`。
3. 递推 `pre`（`pre[0]=-inf`）与 `suf`（`suf[n]=-inf`）。
4. 对每个 $i$：若 `b[i]+n>max(pre[i],suf[i+1]+1)` 则 `++ans`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(n\log n)$（排序瓶颈），其余 $O(n)$。
- 空间：$O(n)$，四个 `int` 数组约 $4.8$ MB。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过；三组手造数据（含并列口径判别组）逐条吻合；$n\le6$ 的 3000 组随机数据与全排列枚举暴力零差异。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2777 [AHOI2016初中组] 自行车比赛
// 思路：选手 i 能夺冠 <=> 给他 n 分、其余人按"分高者得低分"反序分配 1..n-1 后，
//       他的总分仍严格大于其他人最大总分（交换论证两步）。
//       升序排序后令 f[j]=b[j]+n-1-j，则其他人最大值 M_i=max(pre[i],suf[i+1]+1)，
//       pre/suf 为 f 的前缀/后缀最大值 ⇒ 每个候选人 O(1) 判定。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{300005};
constexpr int inf{1145141919};

int n,b[mxn],f[mxn],pre[mxn],suf[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>b[i];
	sort(b,b+n);
	for(int i=0;i<n;++i)
		f[i]=b[i]+n-1-i;	// 反序分配下升序第 i 人的"虚拟总分"
	pre[0]=-inf;			// 空集最大值 = -inf，不可用全局默认 0！
	for(int i=1;i<n;++i)
		pre[i]=max(pre[i-1],f[i-1]);
	suf[n]=-inf;
	for(int i=n-1;i>=0;--i)
		suf[i]=max(suf[i+1],f[i]);
	int ans=0;
	for(int i=0;i<n;++i)
		if(b[i]+n>max(pre[i],suf[i+1]+1))	// 严格大于 ⇒ 唯一冠军
			++ans;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `suf[i+1]+1` 里的 `+1` 是下标错位的补偿：候选人 $i$ 右侧的人在新序列里下标前移一格，反序得分多 1。漏掉这个 `+1` 会在"冠军右边还有人"的数据上系统性偏松。
- `pre[0]` 与 `suf[n]` 必须**显式**填 `-inf`：全局 `int` 默认 0，而 0 是合法总分，会被当成"存在一个 0 分对手"。本题 $f_j\ge0$ 时碰巧不影响答案，但语义上空集最大值就是 $-\infty$，显式设置才稳。
- 判定用严格 `>`：并列总分不算冠军（题意口径，见第一部分讨论）。
- 不需要真的构造名次排列——引理 2 保证反序配对就是最优压制，判定式只是它的最大值。
- 全程 `int` 足够：最大中间量 $b_i+n\le2.3\times10^6$，无需 `long long`。
