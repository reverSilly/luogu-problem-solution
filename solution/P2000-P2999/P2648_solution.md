# P2648 赚钱 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $C$ 座城市（$C\le 300$），$P$ 条免费单向路径（$P\le 200$），$F$ 条单向航线（$F\le 400$，第 $i$ 条花费 $T_i\le 1000$）。zzy 每到一个城市工作就赚 $D$ 元（$D\le 1000$），可以无限次往返、在任意城市出发、在任意城市退休。问最多能赚多少钱；若能无限赚，输出 `orz`。

**第一步：把"赚钱"翻译成图上的收益。** 我先把"一次旅行"拆成动作序列：从某城出发赚 $D$，然后沿一条路径或航线走到下一城、再赚 $D$（坐飞机还要扣 $T$），如此反复，最后在某城退休。关键观察是：**每"到达"一座城市就赚 $D$，而"移动"本身要么免费（路径）要么花 $T$（航线）**。于是把每条移动看成一条带权边：

- 路径 $u\to v$：走过去赚 $D$，边权 $+D$；
- 航线 $u\to v$：飞过去赚 $D$ 但付 $T$，边权 $+(D-T)$。

这样一次旅行就是图上的一条**途径（walk，允许重复点）**，其边权和恰好等于总收益（出发赚的那次 $D$ 稍后单独处理）。因为 $D>0$，"每到一城必赚 $D$"总是最优，不存在"路过不赚"的更优策略。

**第二步：起点任意、终点任意 ⇒ 超级源 + 取最大。** 题目说可以从任何城市出发。我加一个 $0$ 号超级源，向每座城市 $i$ 连一条权为 $D$ 的边——这条边就代表"从城市 $i$ 出发、先赚 $D$"。于是"从任意城市出发"统一成"从 $0$ 号源出发"。又因为可以在任何城市退休，答案就是**所有城市里最长路距离的最大值**（而不是某个固定终点）。

**第三步：为什么会 `orz`？正环。** 途径允许重复点。如果存在一个**边权和为正的环**，zzy 就能绕着它无限圈钱，收益无上界 ⇒ `orz`。反之，若所有环的权都 $\le 0$，那么绕环只会不增收益，把环删掉总能让途径变成一条**简单路径**而不减少收益——所以最优解就是一条简单路径，答案有限。这一步把"无限赚"精确刻画成了"存在正环"。

**第四步：选算法。** 现在问题是"带正环检测的最长路"。最短路工具（Dijkstra）不能处理负权/正环，而本题边权 $D-T$ 可正可负，所以用 **Bellman-Ford / SPFA 这类按边松弛的算法**。我选 Bellman-Ford 按轮松弛：它判正环的正确性最容易证（见引理 5），而且 $V\le 301,E\le 900$，$O(VE)\approx 2.7\times10^5$ 完全够用。做法：从源跑 $V$ 轮最长路松弛，若第 $V$ 轮仍能松弛 ⇒ 有正环 ⇒ `orz`；否则取 $\max_{i\ge1}\texttt{dis}[i]$。

**手造数据核对**（题面没给样例，我按规则手算了几组）：

| 输入（$D,P,C,F$ + 边） | 手算 | 程序 |
|---|---|---|
| $D=10$，路径 $1\to2$ | 出发赚 $10$，走到 $2$ 再赚 $10$，共 $20$ | `20` |
| $D=10$，路径 $1\to2,2\to1$ | 环权 $20>0$，无限圈钱 | `orz` |
| $D=10$，航线 $1\to2$ 花 $15$ | 飞过去净赚 $-5$，不如原地退休赚 $10$ | `10` |
| $D=10$，航线 $1\to2$ 花 $3$ | $10+(10-3)=17$ | `17` |
| $D=10$，航线 $1\to2,2\to1$ 各花 $3$ | 环权 $(10-3)\times2=14>0$ | `orz` |
| $D=10$，航线 $1\to2,2\to1$ 各花 $15$ | 环权 $-10<0$，不圈钱，最优 $10$ | `10` |

最后一组专门打"有环但非正环"的边界：有环不等于 `orz`，必须是**正**环。

## 二、思维链：完整证明

**记号。** 城市 $1..C$，超级源 $0$，共 $V=C+1$ 个点。边集 $E$：源边 $(0,i,D)$（$1\le i\le C$）；路径边 $(A,B,D)$；航线边 $(J,K,D-T)$。边权记 $w(e)$。一条从 $0$ 出发的途径 $W=(0=c_0',c_1,\dots,c_k)$（这里把源也记作起点）的权为 $\mathrm{wt}(W)=\sum w$。$\texttt{dis}[v]$ 为算法维护的"源到 $v$ 当前最长途径权"。

### 引理 1（旅行 ↔ 途径，收益 = 边权和）

zzy 的任一合法旅行与一条从 $0$ 出发的途径一一对应，且旅行总收益恰等于该途径的边权和。

*证明*：设旅行依次到达城市 $c_1,c_2,\dots,c_k$（$c_1$ 为出发城），第 $j$ 段移动用路径或航线、花费 $\mathrm{cost}_j\in\{0,T\}$。收益 = 出发赚 $D$ + 每段到达赚 $D$ − 机票 = $D+\sum_{j=2}^{k}(D-\mathrm{cost}_j)$。对应途径 $0\to c_1\to c_2\to\cdots\to c_k$，边权为 $D$（源边）与 $D-\mathrm{cost}_j$（移动边），其和正是 $D+\sum_{j=2}^k(D-\mathrm{cost}_j)$。反过来，任一途径 $0\to c_1\to\cdots\to c_k$ 的每条非源边都是输入里的一条路径/航线，故对应一个合法旅行（"无限往返"对应途径可重复点）。双射成立，收益 = 边权和。证毕。

**推论**：答案 = $\max$（从 $0$ 出发的途径权），其中最大值取遍所有终点 $c_k\in\{1..C\}$（任意退休）。"无限赚" ⇔ 途径权无上界。

### 引理 2（无上界 ⇔ 存在可达正环）

途径权无上界 $\iff$ 图中存在一个边权和 $>0$ 的环。且由于源向每座城市连边，**任何环都从源可达**，故无需额外判可达性。

*证明*：
（$\Leftarrow$）设正环 $\gamma$ 权 $w_\gamma>0$，且源可达环上某点 $v$（源边直达）。取一条源到 $v$ 的途径 $P$，再绕 $\gamma$ 任意 $m$ 圈，得途径权 $\mathrm{wt}(P)+m\,w_\gamma\to+\infty$（$m\to\infty$）。故无上界。
（$\Rightarrow$）反证。设所有环权 $\le0$。任取途径 $W$，若它含环，把该环删去：因环权 $\le0$，删环后权**不减**，且途径变短。反复删环得一条简单路径 $P$，$\mathrm{wt}(P)\ge\mathrm{wt}(W)$。简单路径至多 $V-1$ 条边，每条边权 $\le D\le1000$，故 $\mathrm{wt}(W)\le\mathrm{wt}(P)\le(V-1)D$，有统一上界，与"无上界"矛盾。故必有正环。
可达性：源边 $(0,i,D)$ 对每个 $i$ 存在，故每个点、每个环都从源一步/多步可达。证毕。

### 引理 3（无正环时最优 = 最长简单路径）

若不存在正环，则最大途径权 = 最长简单路径权，且后者可用"源到各点最长路"求得。

*证明*：由引理 2（$\Rightarrow$）的删环论证，任一途径都能删成权不减的简单路径，故 $\max$ 途径权 = $\max$ 简单路径权。而"从源出发的最长简单路径"的终点可以是任意城市，其权就是 $\max_{v}\texttt{dis}^*[v]$，其中 $\texttt{dis}^*[v]$ 是源到 $v$ 的最长路（无正环时最长路 = 最长简单路径，有限）。证毕。

### 引理 4（Bellman-Ford 的轮次语义）

从 $\texttt{dis}[0]=0$、其余 $-\infty$ 出发，每轮对所有边做一次松弛 $\texttt{dis}[v]\gets\max(\texttt{dis}[v],\texttt{dis}[u]+w)$。则**第 $k$ 轮结束后**，$\texttt{dis}[v]$ 等于"源到 $v$、边数 $\le k$ 的途径"的最大权（不可达为 $-\infty$）。

*证明*：对 $k$ 归纳。$k=0$：只有 $\texttt{dis}[0]=0$（$0$ 条边的途径），其余 $-\infty$，成立。设 $k-1$ 成立。第 $k$ 轮松弛边 $(u,v,w)$ 时，用"边数 $\le k-1$ 到 $u$ 的最优"接一条边得到"边数 $\le k$ 到 $v$ 的一条途径"，取 $\max$ 即覆盖所有"最后一条边为 $(u,v)$、边数 $\le k$"的途径；对所有边取 $\max$ 并保留上一轮值（对应边数 $\le k-1$ 的途径），恰好得到"边数 $\le k$"的最大值。松弛顺序在一轮内可能让同一条边被多次使用，但归纳保证第 $k$ 轮**结束时**的值不超过"边数 $\le k$"的最优，且所有边数 $\le k$ 的途径都会被某轮松弛覆盖（标准 Bellman-Ford 论证：任一 $k$ 边途径的边按轮次依次被松弛）。故第 $k$ 轮结束 $\texttt{dis}[v]=\max_{\text{边数}\le k}\mathrm{wt}$。证毕。

### 引理 5（正环检测：第 $V$ 轮仍松弛 ⇔ 正环）

跑 $V$ 轮。若第 $V$ 轮仍有边被松弛，则存在正环；若某轮无任何松弛（提前收敛），则无正环。

*证明*：
**（第 $V$ 轮仍松弛 ⇒ 正环）** 反证设无正环。由引理 3，最优途径可删环成简单路径，边数 $\le V-1$。由引理 4，第 $V-1$ 轮后 $\texttt{dis}$ 已等于"边数 $\le V-1$"的最大权 = 真实最长路（无正环时任何更长途径删环后权不减且边数 $\le V-1$，已被覆盖）。故第 $V$ 轮不可能再改进任何 $\texttt{dis}$，与"仍松弛"矛盾。故有正环。
**（正环 ⇒ 第 $V$ 轮仍松弛）** 设正环可达。由引理 2，途径权无上界，故对任意 $k$，"边数 $\le k$"的最大权随 $k$ 严格递增（绕环一圈边数 $+|\gamma|$、权 $+w_\gamma>0$）。由引理 4，第 $V$ 轮的值 > 第 $V-1$ 轮的值，必有边被松弛。
**（提前收敛 ⇒ 无正环）** 若第 $k$ 轮无松弛，则 $\texttt{dis}$ 已是不动点；若有正环，由上一条每轮都松弛，矛盾。故无正环。证毕。

**实现对应**：代码里 `it` 从 $0$ 到 $V-1$ 共 $V$ 轮，`it==V-1` 即第 $V$ 轮；若该轮 `chg` 为真则置 `orz`。若中途 `!chg` 则 `break`（无正环）。这与引理 5 逐字对应。

### 引理 6（超级源与"任意退休"的正确性）

源边 $(0,i,D)$ 使"从任意城市出发"被统一；答案取 $\max_{i\ge1}\texttt{dis}[i]$ 实现"任意城市退休"。

*证明*：由引理 1，出发赚 $D$ 对应源边权 $D$，且源向每个 $i$ 连边，故"从 $i$ 出发"= 途径第一步走 $(0,i)$，起点任意性被穷尽。退休于 $c_k$ 即途径终点为 $c_k$，故对所有终点取最大 = $\max_{i\ge1}\texttt{dis}[i]$（无正环时 $\texttt{dis}[i]$ 即源到 $i$ 最长路）。又 $\texttt{dis}[i]\ge D>0$，答案至少为 $D$（出发即退休），符合题意。证毕。

### 引理 7（值域与复杂度）

无正环时答案 $\le(V-1)D\le300\times1000=3\times10^5$，`int` 足够；哨兵 $-\infty=-1145141919$ 只参与比较不参与加法（松弛前有 `dis[u]>-inf` 守卫）。时间 $O(VE)$，空间 $O(V+E)$。

*证明*：值域由引理 3（简单路径 $\le V-1$ 边、每边 $\le D$）。即使有正环，算法在第 $V$ 轮就判 `orz`，期间 $\texttt{dis}$ 增量 $\le V\cdot D\approx3\times10^5$，不溢出。每轮扫 $E$ 条边、共 $\le V$ 轮，故 $O(VE)$；$V\le301,E\le C+P+F\le900$，约 $2.7\times10^5$ 次松弛。存 `dis[V]` 与边表 `E[E]`，空间 $O(V+E)$。证毕。

### 定理

程序正确输出最大收益或 `orz`。

*证明*：引理 1 把题目化为最长途径；引理 2 把"无限"化为正环；引理 3、4、5 保证 Bellman-Ford 在无正环时算出最长路、有正环时在第 $V$ 轮检出；引理 6 保证起点/终点任意性；引理 7 保证数值与复杂度安全。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "每到一城赚 $D$、移动免费或花 $T$"⇒ 把移动建成边权 $D$（路径）/ $D-T$（航线）的图，旅行 = 途径，收益 = 边权和。
- **reduce to easier problem** — "起点任意"加超级源（源边权 $D$），"终点任意"取各点最长路最大值，统一成单源最长路。
- **explore its property** — 途径可重复点 ⇒ 正环 ⇔ 收益无上界（`orz`）；无正环时删环不降权 ⇒ 最优是简单路径。
- **classic problem solution** — 带正环检测的最长路：Bellman-Ford 按轮松弛，第 $V$ 轮仍松弛 ⇔ 正环（SPFA 亦可，判环用入队次数）。
- **discuss by category** — 边权 $D-T$ 可负，Dijkstra 不适用；有环≠`orz`，必须正环；`int` 值域 $\le3\times10^5$ 安全。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `D,P,C,F` | 每城收益、路径数、城市数、航线数 | `int`，读入 | $C\le300,P\le200,F\le400$ |
| `V` | 点数 $=C+1$（含超级源 $0$） | `int` | 城市 $1..C$，源 $0$ |
| `E[e]={u,v,w}` | 边表：源边/路径边/航线边 | `edge[mxm]` | `ecnt` 计数 |
| `dis[v]` | 源到 $v$ 当前最长途径权 | `int[mxn]`，初 $-\infty$，`dis[0]=0` | 全局默认 $0$ 的陷阱：必须显式填 $-\infty$ |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 用 $-\infty$ 表不可达 |
| `mxn,mxm` | $305,1205$ | `constexpr int` | $+5$ 松弛 |
| `orz` | 是否检出正环 | `bool` | 第 $V$ 轮仍松弛置真 |

### 算法步骤

1. I/O 加速三行。
2. 读 $D,P,C,F$；令 $V=C+1$。建源边 $(0,i,D)$；读 $P$ 条路径建边 $(A,B,D)$；读 $F$ 条航线建边 $(J,K,D-T)$。
3. `fill_n(dis,V,-inf); dis[0]=0;`（**不可达数组必须显式填 $-\infty$**）。
4. 对 `it=0..V-1`：扫所有边松弛 `dis[v]=max(dis[v],dis[u]+w)`（守卫 `dis[u]>-inf`）；若本轮无松弛 `break`；若 `it==V-1` 仍松弛则 `orz=true`。
5. 若 `orz` 输出 `orz`；否则输出 $\max_{i=1..C}\texttt{dis}[i]$。

### 复杂度

- 时间 $O(VE)$，$V\le301,E\le900$，约 $2.7\times10^5$ 次松弛。
- 空间 $O(V+E)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$7$ 组手算边界（含"有环非正环"）全对；与"枚举简单环判 `orz` + 枚举简单路径取最大"的独立暴力在 $3000$ 组随机小数据（$C\le6$）上 $0$ mismatch。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2648 赚钱
// 思路：每到一城赚 D ⇒ 路径边权 D、航线边权 D-T，旅行=途径、收益=边权和。
//       超级源 0 向每城连权 D 的边（起点任意），答案取各城最长路最大（终点任意）。
//       正环 ⇔ 无限赚（orz）；Bellman-Ford 最长路，第 V 轮仍松弛 ⇔ 正环。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{305},mxm{1205},inf{1145141919};

int D,P,C,F,dis[mxn];
struct edge{int u,v,w;}E[mxm];
int ecnt;

void addedge(int u,int v,int w){E[ecnt++]={u,v,w};}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>D>>P>>C>>F;
	int V=C+1;					// 0 号超级源 + C 座城市
	for(int i=1;i<=C;++i)
		addedge(0,i,D);			// 从任意城市出发，先赚 D
	for(int i=0,a,b;i<P;++i)
	{
		cin>>a>>b;
		addedge(a,b,D);			// 免费路径：走到下一城再赚 D
	}
	for(int i=0,j,k,t;i<F;++i)
	{
		cin>>j>>k>>t;
		addedge(j,k,D-t);		// 航线：赚 D 但付机票 t
	}
	fill_n(dis,V,-inf);			// 不可达必须显式 -inf，全局默认 0 是陷阱
	dis[0]=0;
	bool orz=false;
	for(int it=0;it<V;++it)		// Bellman-Ford 最长路，共 V 轮
	{
		bool chg=false;
		for(int e=0;e<ecnt;++e)
		{
			auto[u,v,w]=E[e];
			if(dis[u]>-inf&&dis[u]+w>dis[v])
			{
				dis[v]=dis[u]+w;
				chg=true;
			}
		}
		if(!chg)
			break;				// 提前收敛 ⇒ 无正环
		if(it==V-1)
			orz=true;			// 第 V 轮仍能松弛 ⇒ 存在正环
	}
	if(orz)
		cout<<"orz\n";
	else
	{
		int ans=0;
		for(int i=1;i<=C;++i)
			ans=max(ans,dis[i]);
		cout<<ans<<'\n';
	}
	return 0;
}
```

### 代码说明

- **边权即净收益**：源边 $D$（出发赚）、路径边 $D$、航线边 $D-T$。一次途径的边权和就是总收益，无需额外记账。
- **`fill_n(dis,V,-inf)` 必须写**：全局 `int` 默认 $0$，而 $0$ 会被误当成"源到该点已有权 $0$ 的途径"，污染最长路松弛。不可达数组显式填 $-\infty$ 是本题最易踩的坑。
- **判环用轮数而非入队次数**：Bellman-Ford 第 $V$ 轮仍松弛 ⇔ 正环（引理 5），证明干净；`!chg` 提前 `break` 对应"无正环提前收敛"。
- **`dis[u]>-inf` 守卫**：防止用不可达点的 $-\infty$ 去松弛（也避免 $-\infty+w$ 的无意义运算）。
- 答案取 $\max_{i\ge1}\texttt{dis}[i]$ 实现"任意城市退休"；有正环输出 `orz`。
