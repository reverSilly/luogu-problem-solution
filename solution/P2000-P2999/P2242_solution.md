# P2242 公路维修问题 — 题解

## 一、解题过程：人类思考叙事

题意复述：一条笔直公路上有 $n$ 个坑，坐标从小到大给出（互不相同）。要选 $m$ 处地段（每处是一段连续的公路区间）实施交通管制，要求所有坑都落在被管制的路段里，最小化被管制路段的总长度。$2\le m\le n\le15000$。

第一反应是「区间覆盖」类的 DP：按坑的顺序分段，设 $dp[i][j]$ 表示前 $i$ 个坑用 $j$ 段覆盖的最小代价，转移枚举上一段的终点
$$dp[i][j]=\min_{p<i}\big(dp[p][j-1]+\operatorname{len}(p+1,i)\big),$$
复杂度 $O(n^2m)$。$n=15000$ 时是 $3\times10^{12}$ 级别，直接死。必须找结构。

先做一步直接的化简：**任何一段管制区域，都可以缩到「它覆盖的最左坑」到「它覆盖的最右坑」**。缩小不会漏掉坑（区间内的坑还在），也不会让长度变大。所以可以认为每段的两端都是坑。

缩完之后，如果两段管制区域有重叠，把它们的并当成一段、另一段腾出来不用，总长度只会变小（并集长度不超过两段长度之和）。于是最优解可以看成：**把排序后的 $n$ 个坑切成 $m$ 个连续块，每块用一段「从块首坑到块尾坑」的区间覆盖**，代价是 $\sum\operatorname{len}(l,r)$。

接下来要确定 $\operatorname{len}(l,r)$ 到底是什么。一开始想当然地按「数轴上的距离」算，即 $\operatorname{len}(l,r)=a_r-a_l$，于是：
- $m=1$ 时答案应是 $a_n-a_1$；
- 在第 $i$ 与第 $i+1$ 个坑之间切一刀，总长减少 $g_i=a_{i+1}-a_i$；
- $m$ 段就是切 $m-1$ 刀，答案 $=(a_n-a_1)-\sum_{\text{被切的 }m-1\text{ 个最大的 }g_i}$。

看起来非常顺。但拿题面的样例说明对一下就会发现不对。提示说取 $[3,8],[14,21],[25,31],[40,43]$ 这四段，长度总和为 $6+8+7+4=25$。可是按距离算：
$$8-3=5,\quad 21-14=7,\quad 31-25=6,\quad 43-40=3,$$
加起来是 $21$，不是 $25$。差在哪？$6=8-3+1$、$8=21-14+1$、$7=31-25+1$、$4=43-40+1$——**每段都多算了 $1$**。这说明题面把一段 $[l,r]$ 的长度定义为 **$r-l+1$**（闭区间覆盖的整数位置个数），而不是 $r-l$。

这个 $+1$ 会连锁地改变所有常数：
- 一整段 $[a_1,a_n]$ 的长度是 $a_n-a_1+1$；
- 在间隔 $g$ 处把 $[l,r]$ 切成 $[l,c]$、$[c+1,r]$，长度从 $a_r-a_l+1$ 变成 $(a_c-a_l+1)+(a_r-a_{c+1}+1)=a_r-a_l+2-g$，即**只减少 $g-1$**，不是 $g$；
- 切 $m-1$ 刀后
$$\text{总长}=(a_n-a_1+1)-\sum_{\text{被切的间隔}}(g_i-1).$$

要最小化总长，仍然等价于**最大化被切间隔之和**（每个被切间隔固定贡献一个 $-1$，切 $m-1$ 刀是固定的），所以还是取最大的 $m-1$ 个间隔。与距离模型相比，答案整体多出 $m$：基准多了 $1$，而每刀少减 $1$，共 $m-1$ 刀。

用提示的四段验证：切开的三个间隔长度是 $14-8=6$、$25-21=4$、$40-31=9$，节省 $(6-1)+(4-1)+(9-1)=16$；一整段 $[3,43]$ 的基准长度是 $43-3+1=41$，$41-16=25$，与提示的 $25$ 完全一致。若沿用距离模型，四段长度会是 $5+7+6+3=21$，或把基准当 $40$ 再减去 $6+4+9=19$ 得 $21$，都与提示不符。

再把两个极端算一遍，确认公式自洽：
- $m=1$：一刀不切，答案 $a_n-a_1+1$；
- $m=n$：每个坑单独一段，每段长度 $1$，答案 $n$。公式：$(a_n-a_1+1)-\sum_{i=1}^{n-1}(g_i-1)=(a_n-a_1+1)-((a_n-a_1)-(n-1))=n$ ✓。

实现上的坑：
- **长度定义**：基准是 $a_n-a_1+1$，每刀减 $g_i-1$。写成只减 $g_i$ 会整体少 $m$，样例都过不去。
- **坐标范围**：坐标在「长整范围内」，两坐标之差可能超过 $2^{31}-1$（如 $-2^{31}$ 到 $2^{31}-1$ 相差 $2^{32}-1$），坐标、间隔、答案全部用 `long long`。
- **只排间隔**：$n-1$ 个间隔排一次序，不必对坐标排序（题目已保证升序）。
- **取前 $m-1$ 大**：`sort(g+1,g+n,greater<>())` 后从下标 $1$ 开始减 $m-1$ 个。

## 二、思维链：完整证明

把坑看成整数点 $a_1<a_2<\dots<a_n$，一段管制区域是闭区间 $[x,y]$，按题面样例的计数方式定义其长度
$$|[x,y]|=y-x+1 .$$
记间隔 $g_i=a_{i+1}-a_i\ge1$（$1\le i<n$）。

**引理 0（区间 DP 为什么正确、又为什么必须放弃）**：设 $f(i,j)$ 为把前 $i$ 个坑分成 $j$ 段的最小总长，则
$$f(1,1)=1,\qquad f(i,1)=a_i-a_1+1,\qquad f(i,j)=\min_{j-1\le p<i}\big(f(p,j-1)+a_i-a_{p+1}+1\big),$$
且答案为 $f(n,m)$；但该 DP 需要 $O(nm)$ 个状态、每次 $O(n)$ 转移，总计 $O(n^2m)$，$n=15000$ 时约 $3.4\times10^{12}$ 次运算，不可行。

*证明*：最优划分中，最后一段必是某个连续块 $[p+1,i]$。因为前 $p$ 个坑要分成 $j-1$ 个非空块，必须 $p\ge j-1$，且 $p<i$。最后一段的长度是 $a_i-a_{p+1}+1$，前 $p$ 个坑的最优代价是 $f(p,j-1)$，两部分的决策互不影响（最后一段只依赖 $p$ 和 $i$），故对所有可能的 $p$ 取最小即得转移。边界：$f(1,1)=1$（单点段长度 $1$），$f(i,1)=a_i-a_1+1$（一整段覆盖前 $i$ 个坑）。由于「最后一段的起点 $p+1$」把最优划分的集合不重不漏地分类，对 $i,j$ 归纳即知 $f(n,m)$ 是最优值。状态数 $O(nm)$，每个状态枚举 $O(n)$ 个 $p$，总复杂度 $O(n^2m)$。证毕。

（正因为 DP 的这个复杂度，我们才需要下面的结构：分块代价可以写成望远镜和，从而把「划分」问题降成「选间隔」问题。）

**引理 1（规范形：收缩、合并、补足）**：对任意用 $m$ 个区间覆盖所有坑的方案，都存在一个方案，把坑集划分成 $m$ 个连续非空块 $B_1,\dots,B_m$，并用区间 $[\min B_t,\max B_t]$ 覆盖第 $t$ 块，其总长度不超过原方案。

*证明*：分三步。
(1) **合并**。设原区间为 $I_1,\dots,I_m$。把它们的并写成若干个互不相交的连通分量 $J_1,\dots,J_t$（每个 $J_s$ 是区间，$t\le m$）。由于各分量互不相交且都含于并集，$\sum_s|J_s|=|\bigcup_i I_i|\le\sum_i|I_i|$（并集里每个整数位置只算一次，原方案里可能重复计算）。所以合并后总长度不增，且仍覆盖全部坑。
(2) **按坑分块**。每个 $J_s$ 是区间，故它包含的坑的下标构成一段连续区间 $[l_s,r_s]$（可能为空）：若 $a_i,a_k\in J_s$ 且 $i<j<k$，则 $a_i<a_j<a_k$，由区间的凸性 $a_j\in J_s$。又各 $J_s$ 两两不交且并集覆盖全部坑，故这些下标区间两两不交、并为 $\{1,\dots,n\}$，即把坑划分成若干连续块。把 $J_s$ 换成 $[a_{l_s},a_{r_s}]$（空块丢弃），长度 $a_{r_s}-a_{l_s}+1\le|J_s|$（因为 $a_{l_s},a_{r_s}\in J_s$，替换后的区间含于 $J_s$），覆盖性不变，总长度不增。
(3) **补足到 $m$ 块**。若当前非空块数 $t'<m$，因 $m\le n$，必有某块含至少两个坑，取块内相邻两坑 $a_c,a_{c+1}$ 切开。该块代价从 $a_r-a_l+1$ 变为
$$(a_c-a_l+1)+(a_r-a_{c+1}+1)=(a_r-a_l+1)-(g_c-1)\le a_r-a_l+1,$$
其中 $g_c=a_{c+1}-a_c\ge1$ 保证 $(g_c-1)\ge0$。故总长不增。重复至恰有 $m$ 块（每步块数 $+1$，且 $n\ge m$ 保证总能找到可切的块）。
综上，存在一个「$m$ 个连续非空块」的方案，总长度不超过任意给定方案。证毕。

**引理 2（分块代价的望远镜形式）**：设切成 $m$ 块，切点为间隔下标集合 $C\subseteq\{1,\dots,n-1\}$，$|C|=m-1$。则
$$\text{总长}=\sum_{\text{块}}(a_r-a_l+1)=(a_n-a_1+1)-\sum_{i\in C}(g_i-1).$$
反过来，任意 $m-1$ 个不同间隔都能作为切点，得到 $m$ 个非空块。

*证明*：块 $[l,r]$ 的代价 $a_r-a_l+1=\sum_{i=l}^{r-1}g_i+1$。把所有块相加：每个间隔 $g_i$ 被计入当且仅当 $i$ 两侧的坑同块，即 $i\notin C$；每个块贡献一个 $1$，共 $m$ 个。于是总长
$$=\sum_{i\notin C}g_i+m=\Big(\sum_{i=1}^{n-1}g_i-\sum_{i\in C}g_i\Big)+m=(a_n-a_1+1)-\sum_{i\in C}(g_i-1),$$
最后一步用了 $\sum_{i=1}^{n-1}g_i=a_n-a_1$ 与 $m-1=|C|$。反过来，给定 $C=\{c_1<\dots<c_{m-1}\}$，块取 $[1,c_1],[c_1+1,c_2],\dots,[c_{m-1}+1,n]$，共 $m$ 块且都非空。证毕。

**引理 2′（切刀相互独立；「每次切当前最大间隔」也正确）**：记全体间隔降序为 $h_1\ge h_2\ge\dots\ge h_{n-1}$。
1. 若已切了集合 $C_0$，再切 $j\notin C_0$，总长恰减少 $g_j-1$，与 $C_0$ 的选取无关；
2. 「每一步都在尚未切的间隔中切最大者」执行 $m-1$ 步，得到的切点集合恰是最大的 $m-1$ 个间隔。

*证明*：1 由引理 2，切 $C_0$ 后总长 $L_0=(a_n-a_1+1)-\sum_{i\in C_0}(g_i-1)$，再切 $j$ 后为 $(a_n-a_1+1)-\sum_{i\in C_0\cup\{j\}}(g_i-1)=L_0-(g_j-1)$。
2 对步数 $t$ 归纳：$t=0$ 时为空集，是「前 $0$ 大」。设第 $t$ 步后已切的是 $h_1,\dots,h_t$；第 $t+1$ 步在剩余间隔中取最大值，剩余间隔正是第 $t+1,t+2,\dots$ 大，最大值为 $h_{t+1}$（并列时任取一个，值仍是 $h_{t+1}$），故切完后是前 $t+1$ 大。证毕。

**引理 3（最优切法）**：对任意 $|C|=m-1$，
$$\sum_{i\in C}(g_i-1)\le\sum_{t=1}^{m-1}(h_t-1),$$
且取等号可由 $C=\{$最大的 $m-1$ 个间隔所在位置$\}$ 实现。

*证明*：由于 $|C|=m-1$ 固定，$\sum_{i\in C}(g_i-1)=\sum_{i\in C}g_i-(m-1)$，故只需证 $\sum_{i\in C}g_i\le\sum_{t=1}^{m-1}h_t$。
把 $C$ 中元素按值降序写成 $c_1\ge c_2\ge\dots\ge c_{m-1}$。断言 $c_t\le h_t$：反设 $c_t>h_t$，则 $c_1,\dots,c_t$ 这 $t$ 个间隔的值都严格大于 $h_t$；但按降序排列的定义，$h_t$ 前面只有 $t-1$ 个位置，值严格大于 $h_t$ 的间隔至多 $t-1$ 个（相等的不算），矛盾。于是逐项相加得 $\sum_t c_t\le\sum_t h_t$，两边再减 $m-1$ 即得原式。
取 $C$ 为最大的 $m-1$ 个间隔的位置（值恰为 $h_1,\dots,h_{m-1}$，位置互不相同），由引理 2 对应一个合法切法，节省量恰为 $\sum_{t=1}^{m-1}(h_t-1)$。证毕。

**引理 3″（对段数归纳的第二条证明）**：记 $OPT(j)$ 为分成 $j$ 段的最小总长，则 $OPT(1)=a_n-a_1+1$，且对 $1\le j<n$ 有
$$OPT(j+1)=OPT(j)-(h_j-1),$$
从而 $OPT(m)=(a_n-a_1+1)-\sum_{t=1}^{m-1}(h_t-1)$。

*证明*：**上界**：由引理 3 的构造，存在最优的 $j$ 段划分，其切点恰为前 $j-1$ 大的间隔。在这个划分上再切剩余间隔中最大者（全体第 $j$ 大 $h_j$），由引理 2′ 第 1 条总长减少 $h_j-1$，故 $OPT(j+1)\le OPT(j)-(h_j-1)$。
**下界**：取 $j+1$ 段最优划分，切点集 $C$ 含 $j$ 个间隔。把 $C$ 按值降序排列，其第 $j$ 大（即最小者）记为 $c_{\min}$。由引理 3 中「$t$ 大 $\le$ 全体第 $t$ 大」的论证（取 $t=j$），$c_{\min}\le h_j$。取消 $c_{\min}$ 这个切点（合并其两侧的块）得到 $j$ 段方案，总长增加 $c_{\min}-1\le h_j-1$，故 $OPT(j)\le OPT(j+1)+(h_j-1)$，即 $OPT(j+1)\ge OPT(j)-(h_j-1)$。
两方向合并得 $OPT(j+1)=OPT(j)-(h_j-1)$。又 $OPT(1)=a_n-a_1+1$（引理 2，切点集为空），逐次递推即得公式。证毕。

引理 3 与引理 3″ 分别从「一次选定所有切点」与「逐段增加」两个角度证明了同一个最优值，互为独立验证。

**定理**：算法输出 $(a_n-a_1+1)-\sum_{t=1}^{m-1}(h_t-1)$，是最小总长度。

*证明*：由引理 1，最优覆盖可化为 $m$ 个连续非空块；由引理 2，其总长为 $(a_n-a_1+1)-\sum_{i\in C}(g_i-1)$；由引理 3，该值最小当且仅当 $C$ 是最大的 $m-1$ 个间隔，此时达到下界 $(a_n-a_1+1)-\sum_{t=1}^{m-1}(h_t-1)$，且该下界可由引理 2 反向构造。故算法输出最优值。证毕。

**引理 4（边界与下界）**：答案不小于 $m$；$m=1$ 时为 $a_n-a_1+1$，$m=n$ 时为 $n$。

*证明*：任何方案由 $m$ 个非空块组成（引理 1 的规范形），每块至少含一个坑，长度 $\ge1$，故总长 $\ge m$。公式也给出同一结论：$(a_n-a_1+1)-\sum_{t<m}(h_t-1)=(a_n-a_1)+1-\sum_{t<m}h_t+(m-1)\ge m$，因为被切的 $m-1$ 个间隔互不重叠，其和不超过 $a_n-a_1$。
$m=1$ 时减去的空和为 $0$，得 $a_n-a_1+1$。$m=n$ 时 $m-1=n-1$，$\sum_{t=1}^{n-1}h_t=\sum_{i=1}^{n-1}g_i=a_n-a_1$，故答案 $=(a_n-a_1+1)-(a_n-a_1)+(n-1)=n$，与「$n$ 个单坑段、每段长度 $1$」一致。证毕。

**引理 5（复杂度与数值范围）**：时间 $O(n\log n)$，空间 $O(n)$；坐标差最大约 $2^{32}$，`long long` 足够。

*证明*：排序 $n-1$ 个间隔 $O(n\log n)$，扫描 $O(n)$；存储两个长度 $n$ 的 `long long` 数组。若坐标在 $32$ 位有符号整数范围内，则 $a_n-a_1+1\le2^{32}<2^{63}-1$，中间量（间隔、答案）同样不溢出。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 管制段可收缩到「覆盖到的最左坑~最右坑」，重叠段可合并，问题化为把坑划分成 $m$ 个连续块
- **consider easier version** — 先看 $m=1$（一段覆盖全部）与 $m=n$（每坑一段）
- **explore its property** — 用样例说明的算式反推长度定义：$[3,8]$ 记作 $6=8-3+1$，说明长度是闭区间里的整数点个数
- **reduce to easier problem** — 分块代价可望远镜求和：在间隔 $g$ 处切一刀，总长恰好减少 $g-1$
- **classic problem solution** — $m$ 段 = 切 $m-1$ 刀，取最大的 $m-1$ 个间隔
- **exchange argument** — 任意 $m-1$ 个间隔之和不超过最大的 $m-1$ 个（第 $t$ 大不超过全体第 $t$ 大）

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 坑的个数 | 输入 |
| $m$ | 需要管制的段数 | 输入，$2\le m\le n$ |
| `a[i]` | 第 $i$ 个坑的坐标（0-based，已升序） | 输入（`i64`） |
| `g[i]` | 第 $i-1$ 与第 $i$ 个坑的间隔 $a_i-a_{i-1}$，$i=1..n-1$ | 由 `a` 算出；`g[0]` 不用 |
| `ans` | 最小总长度 | 初值 $a_{n-1}-a_0+1$，再对前 $m-1$ 大的间隔各减 $(g-1)$ |

### 算法步骤

1. 读入 $n,m$ 和 $n$ 个升序坐标 `a[0..n-1]`。
2. 对 $i=1..n-1$ 计算 `g[i]=a[i]-a[i-1]`。
3. 把 `g[1..n-1]` 降序排序。
4. 令 `ans=a[n-1]-a[0]+1`；对 $i=1..m-1$ 执行 `ans-=g[i]-1`。
5. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(n\log n)$（排序间隔）。
- 空间复杂度：$O(n)$。

### 验证状态

- 编译：`g++ -std=c++20 -O2` 通过，无错误。
- 题面没有给出输入样例，但样例说明里的算式足够构造一组数据反向核对：取 $n=25,\ m=4$，坑为 $3\sim8$、$14\sim21$、$25\sim31$、$40\sim43$ 的全部整数，题面提示的四段恰好是最优解，长度 $6+8+7+4=25$；程序输出 `25`，与该算式一致（若误用距离 $r-l$，会得到 $18$ 或 $21$，都不对）。
- 其它手造数据：`3 1 / -2147483648 0 2147483647` → `4294967296`（验证 `long long` 与 $+1$）；`3 2 / 同上` → `2147483649`；`3 3 / 同上` → `3`（每坑一段，长度各 $1$）。
- 对拍：暴力枚举所有 $\binom{n-1}{m-1}$ 种切法（代价按 $r-l+1$），随机 $300$ 组 $n\le12$、$m\le n$、坐标范围 $[-30,30]$，全部一致（$0$ 处不同）；上面那组 $n=25$ 的构造数据暴力也给出 `25`。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2242 公路维修问题
// 思路：m 段 = 在相邻坑之间切 m-1 刀；一段 [l,r] 的长度按题面样例是 r-l+1，
//       故基准为 a[n-1]-a[0]+1，每切一刀减少 g-1，切最大的 m-1 个间隔
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{15005};

int n,m;
i64 a[mxn],g[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=1;i<n;++i)
		g[i]=a[i]-a[i-1];
	sort(g+1,g+n,greater<>());   // g[1..n-1] 降序

	i64 ans=a[n-1]-a[0]+1;       // 一整段的长度（闭区间整数点个数）
	for(int i=1;i<=m-1;++i)
		ans-=g[i]-1;             // 切开的间隔不再被覆盖，省下 g-1
	cout<<ans<<'\n';
	return 0;
}
```
