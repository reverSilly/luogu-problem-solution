# P2819 图的 m 着色问题 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给一个无向图 $G$（$n$ 个点、$k$ 条边，$1\le n\le100$，$1\le k\le2500$）和 $m$ 种颜色，求**所有**合法着色方案数：每个点染一种颜色，每条边的两个端点颜色不同。题面还有三条很关键的保证：

- 图连通；
- **答案不超过 $20000$**；
- "$n$ 很大时保证 $k$ 足够大"，且数据是在满足这些条件的合法数据中**随机采样**得到的。

注意 $m$ **没有给上界**。这三条保证不是装饰，它们直接决定了"暴力搜索能不能过"，后面会一条条用上。

### 第一步：把"合法"翻译成可检查的局部条件

一个着色就是一个函数 $c:V\to\{0,1,\dots,m-1\}$，合法当且仅当 $\forall (u,v)\in E,\ c(u)\ne c(v)$。约束**只发生在边上**，没有边相连的两个点颜色随便相同。这就是本题的全部性质：它是"逐点赋值 + 边约束"的 CSP，天然适合回溯。

### 第二步：先想最笨的办法，看看它笨在哪

枚举所有 $m^n$ 个函数，再逐个检查 $k$ 条边。$n=100,m=3$ 时 $3^{100}\approx5\times10^{47}$，宇宙毁灭也算不完。

笨在哪？**它把"已经确定非法"的部分赋值也完整枚举到底了**。比如点 $1$ 染红、点 $2$ 染红，而 $(1,2)$ 是条边——这时候后面 $98$ 个点怎么染都救不回来，可暴力还是把 $m^{98}$ 种后缀全跑了一遍。

于是自然的修正：**按某个顺序逐点染色，一旦新染的点与某个已染的邻居同色，立刻回溯**。这就是"剪枝"，剪掉的是整棵子树。

### 第三步：只检查"已染色的邻居"够不够？

这里我停下来质疑了一下自己：检查时只看已经染色的邻居，那些"两端都还没染"的边会不会被漏掉？

不会，而且理由很干净：**每条边恰好被检查一次——在它的两个端点中较晚被染色的那个点上**。设顺序为 $v_1,v_2,\dots,v_n$，边 $(v_i,v_j)$（$i<j$）在染 $v_j$ 时被检查（此时 $v_i$ 已染色）。所以"每一步都局部合法" $\iff$ "最终全局合法"。这一步是回溯正确性的地基，必须证（引理 1）。

同时要证**不重不漏**：搜索树的每片叶子对应一个合法着色，每个合法着色对应唯一一片叶子（引理 2）。否则计数会错。

### 第四步：撞墙——叶子数 $\le 20000$，但节点数可以天文数字

"答案 $\le20000$"看起来很美好：叶子最多两万，搜索能有多大？

**这个推理是错的**，因为搜索树的节点数不是叶子数，而是**每一层前缀的合法着色数之和**。前缀合法不代表能扩展成整体合法，前缀计数可以远远大于答案。

最小反例（我手造的）：**菊花图**。$n=100$，中心是编号 $100$ 的点，边为 $(1,100),(2,100),\dots,(99,100)$，$k=99$，$m=2$。

- 真实答案：中心 $2$ 种选择，每个叶子被迫染另一种，共 $2$ 种。
- 但如果按编号 $1..n$ 的顺序染：前 $99$ 个点两两无边，**任何染色都合法**，第 $d$ 层有 $2^d$ 个节点。搜索树节点数 $\approx 2^{100}\approx1.3\times10^{30}$。

答案只有 $2$，搜索却要跑 $10^{30}$ 步。墙撞得很结实。

**解剖失败原因**：约束全集中在中心点上，而中心被排到了最后。前面 $99$ 步没有任何约束可剪，指数爆炸发生在"约束到来之前"。

### 第五步：修正——把约束强的点先染

既然爆炸来自"约束来得太晚"，那就让约束来得早：**按度数从大到小排序，度大的先染**。

- 菊花图：中心度 $99$ 排第一。染完中心后，每个叶子都只有一个已染邻居，$m=2$ 时只剩 $1$ 种选择——搜索树退化成两条长度 $100$ 的链，节点数 $O(n)$。
- 更一般的"前面一堆稀疏点、后面一个稠密团"的构造同理：团的点度数大，被提前，稀疏点随后立刻被团的颜色挤死。

**关键疑问：换顺序会不会改变答案？** 不会。着色方案是"点 $\to$ 颜色"的函数，与我们按什么顺序枚举它无关；引理 2 的双射对**任意固定顺序**都成立，所以叶子集合恒等于合法着色集合，计数不变（引理 3）。顺序只影响**搜索树的形状**（也就是效率），不影响**叶子的集合**（也就是答案）。这是"自由换序"的许可证。

顺带一提：还可以用颜色对称性（只允许"已用过的颜色"或"编号最小的新颜色"，最后乘上排列数）把分支数从 $m$ 压到 $n+1$。但下面第六步会证明本题 $m\le141$，这个优化没必要，代码保持最朴素的回溯。

### 第六步：$m$ 没给上界，会不会被卡？

这是第二个必须自己回答的问题。如果数据里 $m=10^9$，每个点都要试 $10^9$ 种颜色，直接完蛋。

但"答案 $\le20000$"这条保证把 $m$ 锁死了。推理：

1. 去掉自环、把平行边去重后，$G$ 是 $n$ 个点的简单图，因此是 $K_n$ 的**子图**。子图的合法着色集合是超图的**超集**（约束更少），所以 $P_G(m)\ge P_{K_n}(m)=m(m-1)\cdots(m-n+1)$。
2. 若 $m\ge n\ge2$：上式右端至少含前两个因子 $m,m-1$，其余因子 $\ge1$，故答案 $\ge m(m-1)$。由答案 $\le20000$ 得 $m(m-1)\le20000$，即 $m\le141$（$141\times140=19740\le20000$，$142\times141=20022>20000$）。
3. 若 $m<n$：$m\le n-1\le99$。

两种情形合起来：**只要没有自环，合法数据必有 $m\le141$**。而 $n=1$ 时 $k\ge1$ 逼出的唯一可能是自环 $(1,1)$，属于下面第七步的特判。所以颜色循环最多 $141$ 次，`int` 存答案也够（$\le20000$）。

这一步让我放心地写下 `for(int c=0;c<m;++c)`，而不是提心吊胆地猜 $m$ 的范围。

### 第七步：两个"图论口径"的坑

**坑一：自环。** 题面说"无向连通图"，但 $n=1,k\ge1$ 时唯一的边只能是 $(1,1)$。自环要求 $c(u)\ne c(u)$，**永远不可能**，答案是 $0$。而我们的检查逻辑是"看已染色的邻居"，染 $u$ 时 $u$ 自己还没染色，**自环根本不会被检查到**，程序会若无其事地输出 $m$。必须在读入时发现 $u=v$ 就直接判 $0$。

**坑二：平行边。** 两点之间多条边对"颜色不同"这条约束没有任何新增作用（同一条约束重复而已），但会让邻接表里出现重复邻居，白白多检查几次。用邻接矩阵 `g[u][v]` 去重后再建邻接表，顺便把度数算准（度数用来排序，重复边会把度数虚高，虽然不影响正确性但影响剪枝效果）。

### 第八步：一个移植必踩的坑——`col[]` 的初值

颜色用 $0..m-1$ 表示，"未染色"用 $-1$。**全局 `int` 数组默认是 $0$，而 $0$ 是一个合法颜色！** 如果不显式 `fill_n(col,n,-1)`，那么"未染色的邻居"会被当成"染了颜色 $0$ 的邻居"，于是颜色 $0$ 在任何有边的图上都被禁掉，答案静默变小。回溯时也必须把 `col[u]` 还原成 $-1$ 而不是 $0$。这是本题最容易写挂的一行。

## 二、思维链：完整证明

**记号。** 点集 $V=\{0,\dots,n-1\}$（读入时 `--u` 转 $0$-based），颜色集 $C=\{0,\dots,m-1\}$。$E$ 为去重、去自环后的边集，$\mathrm{adj}(u)$ 为邻接表。$\pi=(\pi_0,\dots,\pi_{n-1})$ 是 $V$ 的一个排列（程序取度数降序）。部分赋值 $c_d:\{\pi_0,\dots,\pi_{d-1}\}\to C$。合法着色集合

$$\mathcal{C}=\{c:V\to C\mid \forall(u,v)\in E,\ c(u)\ne c(v)\}.$$

若原图含自环则 $\mathcal C=\varnothing$（引理 5）。搜索树：根为 $c_0=\varnothing$；节点 $c_d$ 的儿子是对 $\pi_d$ 尝试每个颜色 $c\in C$、且与所有**已染色邻居**不同色的那些扩展。`dfs(d)` 在 $d=n$ 时 `++ans`。

---

### 引理 1（局部检查 $\iff$ 全局合法；每条边恰查一次）

设 $c_n$ 是搜索树的一个叶子（即每一步都通过了局部检查）。则 $c_n\in\mathcal C$。反之，任意 $c\in\mathcal C$ 在每一步都能通过局部检查。

*证明*：先注意自环已被排除（引理 5 单独处理），故 $E$ 中每条边两端不同。

**（$\Rightarrow$）** 任取边 $(u,v)\in E$。设 $u=\pi_i,v=\pi_j$，不失一般性 $i<j$（$u\ne v$ 故 $i\ne j$）。在深度 $j$ 给 $\pi_j=v$ 染色时，$u=\pi_i$（$i<j$）已染色，故 $u\in\mathrm{adj}(v)$ 且 `col[u]`$=c_n(u)\ne-1$，局部检查显式比较了 $c_n(v)$ 与 $c_n(u)$ 并要求不等。叶子通过了该检查，故 $c_n(u)\ne c_n(v)$。这对每条边都成立，故 $c_n\in\mathcal C$。

**（$\Leftarrow$）** 设 $c\in\mathcal C$。在深度 $d$ 给 $\pi_d$ 染 $c(\pi_d)$ 时，任一已染色邻居 $v=\pi_i$（$i<d$）满足 $(\pi_d,v)\in E$，由 $c\in\mathcal C$ 得 $c(\pi_d)\ne c(v)$，故局部检查通过。

**"恰一次"**：边 $(\pi_i,\pi_j)$（$i<j$）只在深度 $j$ 被检查（深度 $i$ 时 $\pi_j$ 未染色，`col`$=-1\ne c$，不构成冲突判断；深度 $>j$ 时不再检查 $\pi_j$ 的赋值）。故既不遗漏也不重复。证毕。

---

### 引理 2（叶子与合法着色一一对应）

对任意固定排列 $\pi$，搜索树的叶子集合与 $\mathcal C$ 之间存在双射：叶子 $c_n\mapsto c_n$。因此 `ans`$=|\mathcal C|$。

*证明*：

**良定义与单射**：由引理 1，每个叶子都属于 $\mathcal C$。两片不同叶子必在某个最浅深度 $d$ 分叉：分叉前缀相同（故 $d$ 之前染的点与颜色完全一致，特别地**被染的点也一致**，因为顺序 $\pi$ 固定），而在深度 $d$ 给同一个点 $\pi_d$ 染了不同颜色，故两个函数在 $\pi_d$ 处取值不同，是不同的着色。单射成立。

**满射**：任取 $c\in\mathcal C$，构造路径：在深度 $d$ 选择颜色 $c(\pi_d)$。由引理 1（$\Leftarrow$），该选择一定通过局部检查，故这条路径存在于搜索树中，且深度 $n$ 时得到的函数正是 $c$。满射成立。

综上是双射，`ans`（叶子计数）$=|\mathcal C|$。证毕。

**注**：证明只用到"$\pi$ 是固定排列"，没有用到任何关于度数的性质——这正是下一步换序的许可证。

---

### 引理 3（枚举顺序不影响答案）

对 $V$ 的任意两个排列 $\pi,\pi'$，相应搜索树的叶子数相同，都等于 $|\mathcal C|$。

*证明*：由引理 2，两者的叶子集合都与同一个集合 $\mathcal C$ 双射，故基数都等于 $|\mathcal C|$，与排列无关。证毕。

**推论**：可以自由选择顺序来优化效率。程序选"度数降序、度数相同按下标升序"（后者只为让行为确定，与正确性无关）。

---

### 引理 4（前缀计数可以远大于答案；度降序修复菊花图）

设 $G_d$ 为 $\{\pi_0,\dots,\pi_{d-1}\}$ 上的诱导子图，$P_d=|\{G_d\text{ 的合法 }m\text{-着色}\}|$。则搜索树深度 $d$ 的节点数恰为 $P_d$，总节点数 $T=\sum_{d=0}^{n}P_d$，而 $P_n=|\mathcal C|=$ 答案。

(a) 存在合法数据使 $P_{n-1}$ 达到 $2^{99}$ 而答案仅为 $2$（按编号序的菊花图）。
(b) 同一张图按度数降序时 $T=O(n)$。

*证明*：节点数 $=P_d$：深度 $d$ 的节点就是从根出发、每步通过局部检查的长度 $d$ 路径，由引理 1 的论证（把"$n$"换成"$d$"，边集换成 $E(G_d)$）它们与 $G_d$ 的合法着色一一对应。求和即 $T$。

(a) 菊花图：中心 $z=99$（$0$-based），叶子 $0..98$，$m=2$。按编号序 $\pi=(0,1,\dots,99)$，前 $d\le99$ 个点都是叶子，两两无边，故 $G_d$ 无边，$P_d=2^d$。特别地 $P_{99}=2^{99}$。而 $G_{100}=G$ 的合法着色：中心 $2$ 选 $1$，每个叶子被迫取另一色，故 $P_{100}=2$。于是 $T\ge2^{99}\approx6.3\times10^{29}$，答案却只有 $2$。这说明"答案 $\le20000$"**不能**直接推出搜索规模小。

(b) 度数：中心 $99$，叶子各 $1$，故 $\pi_0=z$。$P_1=2$。对 $d\ge2$：$G_d$ 是中心加 $d-1$ 个叶子的菊花，合法着色数仍为 $2$（中心 $2$ 选 $1$，叶子全被迫）。故 $P_d=2$ 对所有 $d\ge1$，$T=1+2n=O(n)$。证毕。

**诚实的复杂度声明**：一般图的 $T$ 没有多项式上界（计数着色是 #P-完全问题），本题之所以能搜索，靠的是题面三条保证：答案 $\le20000$（叶子少）、$n$ 大时 $k$ 足够大（约束密，死分支早剪）、随机采样（不会出现刻意构造的"前缀爆炸"图）。度降序是把"约束尽早生效"这一原则落地的零成本保险，它消灭了 (a) 这类最自然的病态族。

### 引理 5（自环与平行边）

(a) 若输入含自环 $(u,u)$，则 $\mathcal C=\varnothing$，答案为 $0$。
(b) 两点间的平行边不改变 $\mathcal C$；去掉重复边后度数与邻接表仍正确反映约束。

*证明*：(a) 合法着色要求每条边两端异色。自环 $(u,u)$ 要求 $c(u)\ne c(u)$，这是矛盾式，任何函数都不满足，故 $\mathcal C=\varnothing$。

**为什么必须显式特判**：程序的局部检查遍历 `graph[u]` 中**已染色**的邻居。若把自环也放进邻接表，染 $u$ 时 `col[u]`$=-1$，而尝试的颜色 $c\ge0$，判断 `col[u]==c` 恒假，自环被无声跳过，程序会输出 $m^n$ 类的正数。故读入时发现 `u==v` 必须置标志并在搜索前输出 $0$。

(b) 设 $u,v$ 间有 $t\ge1$ 条平行边。约束集合是 $\{c(u)\ne c(v)\}$ 重复 $t$ 次，与 $t=1$ 时的约束集合**逻辑等价**（同一个命题的合取幂等：$p\land p\iff p$）。故 $\mathcal C$ 不变。用 `g[u][v]` 判重后只建一条邻接表项，度数各 $+1$，得到的简单图与原多重图有相同的 $\mathcal C$，由引理 2 计数相同。证毕。

---

### 引理 6（子图单调性与 $m$ 的上界）

(a) 若 $G\subseteq H$（同点集，$E(G)\subseteq E(H)$），则 $P_G(m)\ge P_H(m)$。
(b) 在题面保证（答案 $\le20000$、$n\le100$、$k\ge1$）下，去掉自环后必有 $m\le141$。

*证明*：(a) 恒等映射 $\mathrm{id}:\mathcal C_H\to\mathcal C_G$ 良定义：若 $c$ 满足 $H$ 的所有边约束，则对 $E(G)\subseteq E(H)$ 中的边自然也满足，故 $c\in\mathcal C_G$。恒等映射是单射，故 $|\mathcal C_H|\le|\mathcal C_G|$。

(b) 由引理 5，去自环、去重后 $G$ 是 $n$ 点简单图，故 $G\subseteq K_n$。由 (a)：

$$\text{答案}=P_G(m)\ge P_{K_n}(m)=m(m-1)\cdots(m-n+1)\quad(m\ge n),$$

其中 $P_{K_n}(m)$ 的公式来自"逐个点选色，第 $i$ 个点必须避开前 $i-1$ 个互不相同的颜色，剩 $m-i+1$ 种"（乘法原理）。

- **情形 1：$m\ge n$ 且 $n\ge2$。** 乘积含 $n\ge2$ 个因子，前两个是 $m,m-1$，其余 $\ge m-n+1\ge1$，故答案 $\ge m(m-1)$。由答案 $\le20000$：$m(m-1)\le20000$。因 $141\times140=19740\le20000<20022=142\times141$，且 $m(m-1)$ 关于 $m\ge1$ 单调递增，得 $m\le141$。
- **情形 2：$m<n$。** 则 $m\le n-1\le99<141$。
- **情形 3：$n=1$。** $k\ge1$ 且端点只能是 $1$，故必有自环，已被引理 5 特判输出 $0$，不进入搜索。

三情形穷尽，故进入搜索时 $m\le141$。证毕。

**推论**：颜色循环 `for(c=0;c<m;++c)` 至多 $141$ 次；`ans`$\le20000$ 用 `int` 绝不溢出；不需要颜色对称性压缩。

### 引理 7（`col[]` 必须以 $-1$ 初始化）

程序用 `col[v]==c`（$c\ge0$）判断冲突，其正确性依赖不变量："`col[v]`$=-1$ $\iff$ $v$ 尚未染色"。全局数组默认 $0$ 会破坏它。

*证明*：设某邻居 $v$ 未染色。若 `col[v]`$=0$（默认值），则尝试 $c=0$ 时判断 `col[v]==c` 为真，程序误判冲突并跳过颜色 $0$；而按引理 1，未染色的邻居不应参与任何约束。于是所有含边的图都会漏掉大量合法着色。最小反例：$n=2$、单边 $(0,1)$、$m=2$，真实答案 $2$（$(0,1)$ 与 $(1,0)$）。默认值下：染点 $0$ 时 `col[1]`$=0$，颜色 $0$ 被误禁，只剩 `col[0]=1` 一支；染点 $1$ 时颜色 $0$ 合法、颜色 $1$ 与 `col[0]` 冲突，故只数到 $1$ 个方案，答案静默减半。故必须 `fill_n(col,n,-1)`，且回溯时还原为 $-1$。

反过来，若不变量成立：已染色邻居的 `col`$\in[0,m-1]$ 参与比较（正确，引理 1），未染色邻居的 `col`$=-1\notin C$ 永不等于任何 $c$（正确地不参与）。证毕。

### 引理 8（复杂度）

时间 $O(k+n^2+T\cdot(n+m\Delta))$，空间 $O(n^2+k)$，其中 $T=\sum_d P_d$ 为搜索树节点数，$\Delta\le n-1$ 为最大度。

*证明*：读入与去重 $O(k)$（矩阵判重 $O(1)$）；排序 $O(n\log n)$；`fill_n` $O(n)$。搜索：每个节点 $d$ 枚举 $m$ 种颜色，每种颜色遍历 $\mathrm{adj}(\pi_d)$，代价 $O(\deg(\pi_d))\le O(\Delta)$，加上 `break` 提前退出只会更小；故单节点 $O(m\Delta)$，总计 $O(Tm\Delta)$。递归深度 $n\le100$，栈空间 $O(n)$。空间：矩阵 $n^2$ 个 `bool`、邻接表 $O(n^2)$（去重后至多 $\binom{n}{2}$ 条）、若干 $O(n)$ 数组。

代入：$n=100,m\le141,\Delta\le99$，单节点最坏 $\approx1.4\times10^4$ 次比较；叶子数 $=$ 答案 $\le20000$，"通向叶子的节点"至多 $n\cdot20000=2\times10^6$，而度降序 + 稠密保证使死分支极早被剪，实际 $T$ 远小于此。题面明确"答案 $\le20000$、$n$ 大时 $k$ 足够大、随机采样"，正是为这个搜索量身定做的保证。证毕。

### 定理

程序输出图 $G$ 的不同 $m$-着色方案数。

*证明*：引理 5 处理自环（答案 $0$）与平行边（可去重）；引理 6 保证 $m\le141$、答案可用 `int`；引理 7 保证"未染色"哨兵正确；引理 1 保证局部检查等价于全局合法；引理 2 保证叶子与合法着色双射，故 `ans`$=|\mathcal C|$；引理 3 保证度降序不改变计数；引理 4 说明度降序把病态前缀爆炸压回线性；引理 8 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 合法着色 = 函数 $c:V\to[m]$ 且每条边两端异色；约束只在边上，天然逐点回溯。
2. **consider easier version** — 先想 $m^n$ 全枚举 + 事后检查，$3^{100}$ 爆炸；病因是"已非法的前缀还被枚举到底"。
3. **classic problem solution** — 回溯剪枝：逐点染色，与已染邻居同色立即回溯，剪掉整棵子树。
4. **explore its property** — 每条边恰在其较晚端点被检查一次 ⇒ 局部合法 $\iff$ 全局合法；叶子与方案双射 ⇒ 计数不重不漏。
5. **consider easier version** — 质疑"答案 $\le20000$ 所以搜索很小"：菊花图 $m=2$ 答案 $2$、按编号序节点 $2^{99}$，反例打脸。
6. **reduce to easier problem** — 病因是"约束来得太晚"⇒ 度数降序先染约束强的点；换序不改答案（双射对任意排列成立）。
7. **explore its property** — 用"答案 $\le20000$"反推 $m\le141$：$G\subseteq K_n\Rightarrow P_G(m)\ge m(m-1)$，颜色循环与 `int` 都安全。
8. **discuss by category** — 自环（$n=1,k\ge1$ 必然出现）读入即判 $0$；平行边用矩阵去重；`col[]` 必须 `fill_n(...,-1)`，全局默认 $0$ 是合法颜色。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $n,k,m$ | 点数、边数、颜色数 | `int` | 读入；$n\le100,k\le2500$，$m\le141$（引理 6） |
| `g[u][v]` | 去重用的邻接矩阵 | `bool[mxn][mxn]` | 全局默认 `false`；只用来判"这条边见过没" |
| `graph[u]` | $u$ 的邻居（去重、无自环） | `vector<int>[mxn]` | 读入时建；搜索时只遍历它 |
| `deg[u]` | $u$ 的度数（去重后） | `int[mxn]` | 建边时 `++`；排序键 |
| `ord[d]` | 第 $d$ 个被染色的点 | `int[mxn]` | `iota` 后按 `deg` 降序、下标升序排序 |
| `col[u]` | $u$ 当前颜色，$-1$ 表示未染色 | `int[mxn]` | **必须 `fill_n(col,n,-1)`**；$0$ 是合法颜色，默认值会静默出错 |
| `ans` | 合法着色方案数 | `int` | 全局默认 $0$；每片叶子 `++`；$\le20000$ |
| `loop` | 是否读到自环 | `bool` | 有自环 ⇒ 直接输出 $0$ |
| `dfs(d)` | 已染完 `ord[0..d)`，继续染 `ord[d]` | `void(int)` | `d==n` 时计数并返回 |

### 算法步骤

1. I/O 加速三行；读 `n,k,m`。
2. 逐条读边 `u,v`，`--u;--v`：若 `u==v` 置 `loop=true`；否则若 `!g[u][v]`，置矩阵、双向 push 邻接表、`++deg[u];++deg[v]`。
3. 若 `loop`：输出 `0` 并结束（引理 5）。
4. `fill_n(col,n,-1)`；`iota(ord,ord+n,0)`；按 `deg` 降序（同度按下标升序）排序 `ord`。
5. `dfs(0)`：取 `u=ord[d]`，对每个颜色 `c∈[0,m)` 遍历 `graph[u]`，若存在 `col[v]==c` 则跳过；否则 `col[u]=c`，`dfs(d+1)`，回溯 `col[u]=-1`。`d==n` 时 `++ans`。
6. 输出 `ans`。

### 复杂度

- 时间：$O(k+n\log n+T\cdot m\Delta)$，$T$ 为搜索树节点数（叶子数 $=$ 答案 $\le20000$）；$m\le141$、$\Delta\le99$。
- 空间：$O(n^2)$（矩阵 + 去重邻接表），递归栈 $O(n)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$12$ 组手造数据（三角形、链、单边、$K_4$、菊花、三角形+悬挂点、自环、平行边、不连通、$C_{10}$、$K_{3,3}$）与手算/色多项式公式逐一吻合（如 $C_{10},m=3$ 得 $2^{10}+2=1026$，$K_{3,3},m=3$ 得 $42$）；另跑 $n=100$ 菊花（$m=2$，答案 $2$）与 $n=100,k=2500$ 随机稠密图（$m=3$，答案 $0$）均瞬间出解，验证度降序的剪枝效果。本题是标准回溯计数，证明已闭合，不建对拍附录。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2819 图的 m 着色问题
// 逐点回溯计数：每条边恰在其较晚端点被检查一次 ⇒ 局部合法即全局合法
// 度数降序染色：把约束尽早引入，避免菊花图那种"前缀 2^99、答案 2"的爆炸
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n,k,m,ans,col[mxn],deg[mxn],ord[mxn];
bool g[mxn][mxn];
vector<int>graph[mxn];

void dfs(int d)
{
	if(d==n){++ans;return;}
	int u=ord[d];
	for(int c=0;c<m;++c)
	{
		bool ok=true;
		for(int v:graph[u])
			if(col[v]==c){ok=false;break;}	// 未染色邻居 col=-1，永不等于 c
		if(!ok)
			continue;
		col[u]=c;
		dfs(d+1);
		col[u]=-1;		// 回溯还原成"未着色"，不是 0
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k>>m;
	bool loop=false;
	for(int i=0,u,v;i<k;++i)
	{
		cin>>u>>v;--u;--v;
		if(u==v){loop=true;continue;}	// 自环要求 c(u)!=c(u)，恒无解
		if(!g[u][v])
		{
			g[u][v]=g[v][u]=true;
			graph[u].push_back(v);
			graph[v].push_back(u);
			++deg[u];++deg[v];
		}
	}
	if(loop){cout<<0<<'\n';return 0;}
	fill_n(col,n,-1);	// 全局 int 默认 0 是合法颜色！必须显式置 -1
	iota(ord,ord+n,0);
	sort(ord,ord+n,[](int x,int y){return deg[x]!=deg[y]?deg[x]>deg[y]:x<y;});
	dfs(0);
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`col` 的 $-1$ 哨兵**是整份代码最脆的一环：颜色是 $0..m-1$，全局数组默认 $0$ 会被当成"邻居染了颜色 $0$"，把颜色 $0$ 在所有有边的图上禁掉。初始化和回溯两处都必须是 $-1$。
- **`g` 矩阵只用于去重**，搜索走邻接表：平行边不新增约束（引理 5），去重同时让 `deg` 准确，排序才有意义。
- **自环在读入阶段就判死**：搜索里的"已染邻居"检查天然看不到自己，若不特判，$n=1,k=1$ 的数据会输出 $m$ 而不是 $0$。
- **`ord` 度降序**：由引理 3，任意排列的叶子集合都等于合法着色集合，所以换序只赚效率不赔正确性；同度按下标升序仅为确定性。
- `dfs` 里 `break` 提前退出冲突检查，`continue` 跳过该颜色；`d==n` 才计数，保证只统计完整赋值。
- `ans` 用 `int`：题面保证 $\le20000$；`m` 不需要防爆，引理 6 已证 $m\le141$。
- 递归深度 $\le n=100$，无栈溢出风险；输出 `'\n'`。
