# P2663 越越的组队 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 个学生（$1\le n\le100$，$n$ 为偶数），成绩 $a_i\in[0,100]$。要选出**恰好一半**（$n/2$ 人），使成绩和**不超过班级总分一半**且尽量大。输出这个最大和。

三个关键词：**恰好 $n/2$ 人**（个数约束）、**和 $\le\lfloor\text{sum}/2\rfloor$**（容量约束）、**最大化**（目标）。总分 $\le100\times100=10000$，容量 $\le5000$——数值很小，是典型的"伪多项式 DP"信号。

**第一步：先试贪心，立刻碰壁。** 直觉是"从大到小拿，装不下就跳过"。两个反例把它打回：

- $a=[5,4,3,3]$：总分 $15$，容量 $\lfloor15/2\rfloor=7$，要选 $2$ 人。贪心拿 $5$，然后 $4$（$9>7$）、$3$（$8>7$）、$3$（$8>7$）全装不下，只选了 $1$ 人——**连个数约束都满足不了**。正确答案 $\{4,3\}=7$。
- $a=[9,8,4,1,1,1]$：总分 $24$，容量 $12$，要选 $3$ 人。贪心拿 $9$，跳过 $8$（$17$）、$4$（$13$），再拿三个 $1$ 得 $12$——但这是 **$4$ 个人**，非法！恰好 $3$ 人的最优是 $\{9,1,1\}=11$。

第二个反例尤其说明问题：**去掉个数约束后的最优解（$12$，$4$ 人）比带约束的最优解（$11$，$3$ 人）更大**，所以"先做普通子集和再凑人数"也不行，个数必须进状态。反过来"从小到大拿最小的 $n/2$ 个"虽然合法，但和太小（上例只有 $3$），远非最优。贪心全线失败，上 DP。

**第二步：认亲——这是带个数限制的 0/1 背包。** 去掉个数约束，就是经典子集和：$f[s]$ 表示和 $s$ 能否凑出，每件物品选或不选。现在多一个"恰好 $j$ 件"，自然加一维：

$$f[j][s]=\text{“在已处理的学生里恰好选 }j\text{ 人、成绩和恰为 }s\text{”是否可行}.$$

每来一个学生 $a$，转移 $f[j][s]\mathrel{|}=f[j-1][s-a]$（选他：人数 $+1$、和 $+a$）。这是布尔可达性 DP，不需要存"最大和"——因为最后只要在可达的 $s$ 里取最大的即可。

**第三步：滚动数组与循环方向。** 物品维滚掉，$f$ 只剩 $[j][s]$ 两维。**$j$ 必须倒序**：更新 $f[j]$ 时读的是 $f[j-1]$，倒序保证 $f[j-1]$ 还是"上一件物品之前"的旧值，每人最多被选一次（0/1 背包的老规矩）。一个容易想错的细节：在**这种二维写法里 $s$ 的方向其实无所谓**——读的是 $j-1$ 行、写的是 $j$ 行，行与行不串；只有把 $j$ 维也压掉的一维写法才必须 $s$ 倒序。我仍按习惯写 $s$ 倒序，但证明里会讲清真正的关键是 $j$ 倒序。

**第四步：容量取整与答案提取。** "不超过总分一半"：和是整数，$s\le\text{sum}/2$（实数）$\iff s\le\lfloor\text{sum}/2\rfloor$。总分为奇数时（如 $21$）容量是 $10$ 不是 $10.5$，整数除法 `sum/2` 恰好正确。答案 $=\max\{s\le\text{half}:f[n/2][s]=\text{true}\}$，从 `half` 往下扫第一个真值即可。

**第五步：答案一定存在吗？** 一定。把成绩升序排，**最小的一半人之和 $\le$ 总分一半**（逐位配对：第 $i$ 小 $\le$ 第 $i+n/2$ 小，求和即得）。所以 $f[n/2][\cdot]$ 在容量内必有真值，不会无解。这条也保证答案 $\ge0$。

**第六步：复杂度与边界。** 状态 $(n/2+1)\times(\text{half}+1)\le51\times5001$，转移 $n\times(n/2)\times\text{half}\le100\times50\times5000=2.5\times10^7$ 次布尔运算，`bool` 数组约 $275$ KB——不开 O2 也轻松过（题目标签的"O2优化"多半是给三维 `int` DP 准备的）。边界：$a_i=0$ 合法且照样占一个名额（个数维与数值无关）；$n=2$、全 $0$ 都正常。想更快可以用 `bitset`：$f[j]\mathrel{|}=f[j-1]\ll a$，快 $64$ 倍，但本题没必要。

**手造数据核对**（题面只给了样例 1 的文字解释，我按解释反推一组，再造几组打贪心与边界）：

| 输入 | 说明 | 答案 |
|---|---|---|
| `8` / `56 77 84 56 100 100 77 0` | 总分 $550$、容量 $275$，选 $\{56,77,84,56\}=273$，与样例解释一致 | $273$ |
| `6` / `9 8 4 1 1 1` | 贪心陷阱：无约束最优 $12$（$4$ 人）非法 | $11$ |
| `4` / `5 4 3 3` | 贪心连人数都凑不齐 | $7$ |
| `2` / `3 5` | 最小规模，选小的 | $3$ |
| `2` / `0 0` | 全 $0$ | $0$ |
| `4` / `1 1 1 1` | 全选一半 | $2$ |

第一组我手工枚举了全部 $\binom{8}{4}=70$ 个四元组中和 $\le275$ 者，最大确为 $273$（含两个 $100$ 的组合最小是 $256$、次小 $277$ 超界；不含 $100$ 的最大是 $84+77+56+56=273$）。

## 二、思维链：完整证明

**记号。** 成绩 $a_0,\dots,a_{n-1}\in[0,100]$，$n$ 偶数。$\text{sum}=\sum a_i$，$\text{half}=\lfloor\text{sum}/2\rfloor$，$h=n/2$。处理到第 $i$ 件物品时，$\mathrm{Old}[j][s]$ 表示"前 $i$ 件（下标 $0..i-1$）中恰好选 $j$ 件、和恰为 $s$"的可行性，$\mathrm{New}$ 表示前 $i+1$ 件。$f$ 是滚动数组。

### 引理 1（容量取整等价）

对整数 $s$：$s\le\text{sum}/2$（实数除法）$\iff s\le\lfloor\text{sum}/2\rfloor=\texttt{half}$。

*证明*：设 $\text{sum}=2q+r$，$r\in\{0,1\}$，则 $\text{sum}/2=q+r/2$，$\lfloor\text{sum}/2\rfloor=q$。整数 $s\le q+r/2\iff s\le q$（$s$ 是整数，$q\le q+r/2<q+1$，故 $s\le q+r/2$ 当且仅当 $s\le q$）。证毕。

**推论**：代码用 `half=sum/2`（C++ 整数除法向零截断，$\text{sum}\ge0$ 故即下取整）作容量，与题意严格一致；总分为奇数不会出错。

### 引理 2（可行性：答案必存在且 $\ge0$）

$f[h][s]$ 在某个 $s\le\texttt{half}$ 处为真；从而答案良定义、$\ge0$。

*证明*：把 $a$ 升序排为 $b_1\le\cdots\le b_n$。对 $i=1..h$ 有 $b_i\le b_{i+h}$，求和得 $S_{\text{lo}}=\sum_{i\le h}b_i\le\sum_{i>h}b_i=S_{\text{hi}}$。又 $S_{\text{lo}}+S_{\text{hi}}=\text{sum}$，故 $2S_{\text{lo}}\le\text{sum}$，$S_{\text{lo}}\le\text{sum}/2$；$S_{\text{lo}}$ 是整数，由引理 1 $S_{\text{lo}}\le\texttt{half}$。取最小的 $h$ 人即得一个和为 $S_{\text{lo}}\le\texttt{half}$ 的合法方案，故 $f[h][S_{\text{lo}}]$ 为真。所有 $a_i\ge0$ 故答案 $\ge0$。证毕。

### 引理 3（DP 语义与转移）

$\mathrm{New}[j][s]=\mathrm{Old}[j][s]\lor\bigl(j\ge1\land s\ge a_i\land\mathrm{Old}[j-1][s-a_i]\bigr)$。

*证明*：把"前 $i+1$ 件中选 $j$ 件、和 $s$"的方案集按**是否含第 $i$ 件**划分：

- 不含：方案就是前 $i$ 件中选 $j$ 件和 $s$，可行性 $\mathrm{Old}[j][s]$。
- 含：去掉第 $i$ 件，剩下是前 $i$ 件中选 $j-1$ 件、和 $s-a_i$ 的方案；反之任何这样的方案添上第 $i$ 件都合法。这是双射，故可行性 $=\mathrm{Old}[j-1][s-a_i]$（要求 $j\ge1$、$s\ge a_i$，否则无此分支）。

两支不交且并为全体，取或即得。初始 $\mathrm{Old}$（$i=0$，无物品）：$f[0][0]=\text{true}$，其余 false（选 $0$ 件只能和 $0$）。证毕。

### 引理 4（原地倒序循环恰好实现转移）

代码对每件 $a_i$：`for j=min(i+1,h) down to 1: for s=half down to a_i: f[j][s] |= f[j-1][s-a_i]`。则处理完后 $f=\mathrm{New}$（在 $j\le h,s\le\texttt{half}$ 范围内）。

*证明*：固定物品 $i$，考察循环执行期间数组状态。关键不变量：**写第 $j$ 行时，第 $j-1$ 行尚未被本件物品触碰，仍是 $\mathrm{Old}$**。因为 $j$ 从大到小，处理到 $j$ 时只写过 $>j$ 的行。于是每次赋值 `f[j][s]|=f[j-1][s-a_i]` 读到的 `f[j-1][s-a_i]` 是 $\mathrm{Old}[j-1][s-a_i]$；而 `f[j][s]` 在本件物品中至多被写一次（$s$ 严格递减，每个 $s$ 一次），写前仍是 $\mathrm{Old}[j][s]$。故每个被写的格子恰好算出 $\mathrm{Old}[j][s]\lor\mathrm{Old}[j-1][s-a_i]=\mathrm{New}[j][s]$ ✓。

未被写的格子也正确：

- $s<a_i$：第 $i$ 件放不进和 $s$（$a_i>s$），$\mathrm{New}=\mathrm{Old}$，不写 ✓。
- $j=0$：选 $0$ 件不含第 $i$ 件，$\mathrm{New}[0][s]=\mathrm{Old}[0][s]$，不写 ✓。
- $j>\min(i+1,h)$：若 $j>i+1$，前 $i+1$ 件选不出 $j$ 件，$\mathrm{New}=\mathrm{Old}=\text{false}$，不写 ✓；若 $j>h$，超出关心的范围（答案只用 $j=h$），不影响 ✓。

**$s$ 的方向无关紧要**：读的是 $j-1$ 行、写的是 $j$ 行，$j-1$ 行在整个第 $j$ 行处理期间都是 $\mathrm{Old}$，与 $s$ 升降序无关。真正不可换的是 **$j$ 倒序**——若 $j$ 升序，写 $f[j]$ 时 $f[j-1]$ 已被本件更新成 $\mathrm{New}$，会把第 $i$ 件重复选入（变成完全背包）。证毕。

### 引理 5（答案提取正确）

$\texttt{ans}=\max\{s\le\texttt{half}:f[h][s]\}$ 等于题目所求。

*证明*：由引理 3 归纳，全部物品处理后 $f[h][s]$ 为真 $\iff$ 存在恰好 $h=n/2$ 人、和为 $s$ 的选法。由引理 1，$s\le\texttt{half}\iff$ 和不超过总分一半。故合法方案的成绩和集合恰为 $\{s\le\texttt{half}:f[h][s]\}$，题目要其最大值，即从 `half` 往下扫的第一个真值。引理 2 保证集合非空。证毕。

### 引理 6（贪心为何失败：反例与结构）

"从大到小装得下就拿"既不保证个数、也不保证最优；不存在只按大小排序的贪心能解此题。

*证明*（构造反例）：

- $a=[5,4,3,3]$，$\texttt{half}=7$，$h=2$：贪心取 $5$ 后，$4,3,3$ 均使和 $>7$，只取 $1$ 件，违反恰好 $2$ 件。合法最优 $\{4,3\}=7$。
- $a=[9,8,4,1,1,1]$，$\texttt{half}=12$，$h=3$：贪心取 $\{9,1,1,1\}=12$ 共 $4$ 件，非法。穷举全部 $\binom{6}{3}=20$ 个三元组的和：$21$；$18(\times3)$；$14(\times3)$；$11(\times3)$；$13(\times3)$；$10(\times3)$；$6(\times3)$；$3$。$\le12$ 者为 $11,10,6,3$，最大 $11$。故答案 $11$，而**去掉个数约束**的子集和最优是 $12$（$\{9,1,1,1\}$）——两者不同，证明个数维不可省略。

结构上：子集和的最优解不满足拟阵/交换性质（加入一个大元素可能挤掉多个小元素，且个数约束把可行解集切成非遗传的层），交换论证无法建立，故必须 DP 枚举所有 $(j,s)$ 可达性。证毕。

### 引理 7（值域与复杂度）

$\text{sum}\le10000$，$\texttt{half}\le5000$；时间 $O(n\cdot h\cdot\texttt{half})\le2.5\times10^7$，空间 $O(h\cdot\texttt{half})$（`bool` 约 $275$ KB）；`int` 足够。

*证明*：$\text{sum}=\sum a_i\le100\times100=10000$，$\texttt{half}\le5000$，所有和 $\le10000$，`int` 安全。状态数 $(h+1)(\texttt{half}+1)\le51\times5001\approx2.55\times10^5$；每件物品对每个 $(j,s)$（$j\le h,s\le\texttt{half}$）至多一次或运算，共 $\le n\cdot h\cdot\texttt{half}=2.5\times10^7$ 次。`bool f[105][5005]` 约 $105\times5005\approx5.3\times10^5$ 字节（实际只用 $51\times5001\approx275$ KB）。证毕。

### 定理

程序输出"恰好 $n/2$ 人、和 $\le\lfloor\text{sum}/2\rfloor$"的最大和；时间 $O(n\cdot h\cdot\texttt{half})$、空间 $O(h\cdot\texttt{half})$。

*证明*：引理 1 把容量约束化为整数 `half`；引理 3、4 保证滚动 DP 逐件正确维护可达性；引理 5 保证答案提取即所求；引理 2 保证有解；引理 6 说明贪心不可行、DP 必要；引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 拆出三要素：恰好 $n/2$ 人（个数）、和 $\le\lfloor\text{sum}/2\rfloor$（容量）、最大化；总分 $\le10000$ 提示伪多项式 DP。
- **consider easier version** — 先试贪心（从大到小拿），两个反例击溃：凑不齐人数 / 拿到非法的 $4$ 人解。
- **reduce to easier problem** — 去掉个数约束即子集和（0/1 背包，价值=重量）；但反例证明无约束最优 $\ne$ 有约束最优，个数必须进状态。
- **classic problem solution** — 加一维个数：$f[j][s]$ 布尔可达性，$f[j][s]\mathrel{|}=f[j-1][s-a]$，物品维滚动。
- **explore its property** — $j$ 倒序保证读到旧的 $f[j-1]$（0/1 性质）；二维写法里 $s$ 方向其实自由，关键是行不串。
- **explore its property** — 容量 `sum/2` 下取整对奇数总分正确；答案必存在（最小一半人 $\le$ 总分一半，配对证明）。
- **discuss by category** — 答案 = 容量内最大可达 $s$；$a_i=0$ 照占名额；`bool` 足够，`bitset` 可再快 $64$ 倍但非必要。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 人数（偶数，$\le100$） | `int`，读入 | $h=n/2$ |
| `a[i]` | 第 $i$ 人成绩（$[0,100]$） | `int[mxn]`，读入 | 0-based |
| `sum` | 总分 $\le10000$ | `int`，$0$ 起累加 | |
| `half` | 容量 $\lfloor\text{sum}/2\rfloor\le5000$ | `int` | 整数除法即下取整 |
| `f[j][s]` | 已处理前缀中**恰好选 $j$ 人、和恰为 $s$** 是否可行 | `bool[mxn][mxs]`，全局默认 false | "f = 可达性"，非最大和 |
| `f[0][0]` | 选 $0$ 人和 $0$，唯一初始真值 | 显式置 true | 其余边界全 false |
| `ans` | 容量内最大可达 $s$ | `int` | 从 `half` 下扫首个真值 |
| `mxn,mxs` | $100+5$、$5000+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 $n$ 与 $a_{0..n-1}$，累加 `sum`；`half=sum/2`。
3. `f[0][0]=true`。
4. 对每件 $i=0..n-1$：$j$ 从 $\min(i+1,n/2)$ **倒序**到 $1$，$s$ 从 `half` 倒序到 $a_i$：`f[j][s]=f[j][s]||f[j-1][s-a[i]]`（引理 4）。
5. $s$ 从 `half` 递减到 $0$，首个 `f[n/2][s]` 为真即 `ans=s`，break（引理 2 保证必找到）。
6. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间 $O(n\cdot\frac n2\cdot\frac{\text{sum}}2)\le2.5\times10^7$ 次布尔运算。
- 空间 $O(\frac n2\cdot\frac{\text{sum}}2)$，`bool` 数组约 $275$ KB（声明 $105\times5005$）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$6$ 组手造数据全对（含按样例解释反推、手工枚举 $70$ 个四元组核实的总分 $550$ 组，以及两个贪心反例）；$n=100$ 全 $100$（答案 $5000$）、全 $0$（答案 $0$）与随机大规模均正确，运行约 $0.02$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2663 越越的组队
// 思路：恰好选 n/2 人、总和 ≤ ⌊sum/2⌋、最大化总和 ⇒ 带个数限制的 0/1 背包。
//       f[j][s]：前缀里恰好选 j 人、和恰为 s 是否可行。
//       逐个物品滚动，j 倒序保证读到的 f[j-1] 还是旧值（每人最多选一次）。
//       答案 = 最大的 s ≤ sum/2 使 f[n/2][s] 为真（取最小的一半人保证可行）。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105},mxs{5005};

int n,a[mxn],sum,half,ans;
bool f[mxn][mxs];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		sum+=a[i];
	}
	half=sum/2;
	f[0][0]=true;
	for(int i=0;i<n;++i)
		for(int j=min(i+1,n/2);j>=1;--j)
			for(int s=half;s>=a[i];--s)
				f[j][s]=f[j][s]||f[j-1][s-a[i]];
	for(int s=half;s>=0;--s)
		if(f[n/2][s])
		{
			ans=s;
			break;
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`f` 是布尔可达性而非"最大和"**：状态只回答"恰好 $j$ 人和 $s$ 能不能凑出"，最后从容量往下扫第一个真值就是答案。比存最大和的写法更省、更不易错。
- **`j` 倒序是 0/1 性质的命门**：写 `f[j]` 时 `f[j-1]` 必须还是旧值。`j` 上界 `min(i+1,n/2)` 是剪枝——前 $i+1$ 件选不出更多，且只关心到 $n/2$。
- **`s` 倒序在二维写法里只是习惯**：读 $j-1$ 行、写 $j$ 行，行不串，$s$ 升降都对；真正不能换的是 $j$ 的方向（引理 4）。
- **`half=sum/2`**：整数下取整，奇数总分自动正确（引理 1）。
- **无需特判无解**：最小的一半人之和 $\le$ 总分一半（引理 2），`f[n/2][s]` 在容量内必有真值，扫描必命中。
- `a[i]=0` 时内层 `s` 从 `half` 到 $0$，照样把人数 $+1$，正确占用名额。
