# P2778 [AHOI2016初中组] 迷宫 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 平面上 $N$ 堵环形墙（$N\le8000$），每堵是一个圆，**任意两圆不相交、不重合、不相切，但可嵌套**。$Q$ 组询问（$Q\le8000$），每组给两点 $A=(a,b)$、$B=(c,d)$（不在任何圆上），问两人要相见（可在任意位置）**至少破坏几堵墙**。坐标绝对值 $\le10^8$，大数据时限 3 s。

**第一步：一堵墙什么时候"挡路"？** 圆是 Jordan 曲线，把平面分成内、外两部分。从 $A$ 走到 $B$，每穿过一个圆一次，"在这个圆内/外"的状态就翻转一次。于是：

- 若 $A,B$ **恰好一个在圆内**：起点状态 $\ne$ 终点状态，必须穿过**奇数次**，至少 $1$ 次 ⇒ 这堵墙**非拆不可**。
- 若 $A,B$ 同在圆内或同在圆外：穿偶数次（可以是 $0$）⇒ 这堵墙**可以不拆**。

所以答案的下界是"**恰好包含两点之一的圆的个数**"，即两个包含集合的对称差 $|S_A\triangle S_B|$。

**第二步：下界能不能取到？这才是真正的难点。** 会不会有些墙虽然不"分隔"两点，却因地形所迫不得不拆？或者拆了分隔墙之后仍绕不开别的墙？这里必须用上"**两圆不交不切**"这个强条件。

**第三步：不交不切 ⇒ laminar（层状）结构。** 两个圆既然边界不相碰，就只有两种关系：**完全分离**，或**一个严格包含另一个**。于是"包含"关系构成一片**森林**：每个圆的父亲是"严格包含它的最小圆"，最外层圆的父亲是虚拟根（整个平面）。包含某个点的所有圆恰好是森林中从该点所在节点到根的一条**链**。

把每个圆盘面挖掉它的孩子圆盘，得到一块**连通的"细胞"**（带孔圆盘，孔彼此分离且不贴边，绕得过去）。点 $A$ 落在唯一一块细胞里。相邻细胞（父子）共享一段**自由的圆弧**（孩子圆上没被孙子圆盖住的部分，因不切不交而非空）。

**第四步：沿树路径走，上界成立。** 从 $A$ 的细胞沿森林路径走到 $B$ 的细胞：先向上爬到最近公共祖先，再向下走到 $B$。每下一条树边就穿过对应的圆一次，且只穿一次。路径上穿过的圆恰为 $S_A\triangle S_B$（共同祖先在两条链里都出现，抵消）。所以**只拆这些分隔墙、每堵拆一次**就能相见，上界 $=|S_A\triangle S_B|$。结合下界，答案就是它。

"可在任意位置相见"会不会更省？不会：对任何分隔墙（$A$ 内 $B$ 外），无论约定在哪见面，见面点要么在墙内（$B$ 必须穿墙过来）要么在墙外（$A$ 必须穿墙出去），这堵墙总得拆。所以分隔墙数仍是下界，而在 $B$ 点见面恰好取到。

**第五步：根本不用建树！** 答案 $=|S_A\triangle S_B|=\sum_i[\,\text{inside}(A,C_i)\oplus\text{inside}(B,C_i)\,]$。每组询问扫一遍所有圆，判两点各自是否在圆内，异或计数即可。$O(NQ)=6.4\times10^7$，3 s 绰绰有余（实测极限数据 0.19 s）。森林只是**证明工具**，不是代码的一部分。

**第六步：唯一的实现陷阱——溢出。** 判 inside 用 $(a-x)^2+(b-y)^2<r^2$。坐标 $\le10^8$，差 $\le2\times10^8$，平方 $\le4\times10^{16}$，两项和 $\le8\times10^{16}$——**远超 `int`（$2.1\times10^9$）**，必须 `long long`。用 `int` 会静默溢出、答案乱掉。点不在圆上由题目保证，所以严格 `<` 没有等号歧义。

**手造数据核对**（题面无样例，自造嵌套 / 分离 / 退化三组）：

```
输入：
2
0 0 10          ← 大圆
0 0 3           ← 嵌套小圆
3
0 0 5 0         A=(0,0) 在两圆内，B=(5,0) 只在大圆内 ⇒ 小圆分隔 ⇒ 1
0 0 20 0        A 在两圆内，B 在两圆外 ⇒ 两圆都分隔 ⇒ 2
1 0 2 0         A,B 都在两圆内 ⇒ 无分隔 ⇒ 0
输出：
1
2
0

输入：
0               ← 没有墙
2
0 0 1 1
5 5 5 5
输出：
0
0
```

另造分离圆 $(0,0,2),(10,0,2)$，$A=(0,0),B=(10,0)$：各含一点 ⇒ 答案 2；$A=(0,0),B=(1,0)$ 同在第一圆内 ⇒ 0。程序输出与手推全部一致。

## 二、思维链：完整证明

**记号。** 圆 $C_i$ 圆心 $(x_i,y_i)$、半径 $r_i>0$，盘面 $D_i$ 为闭圆盘。点 $P$ 的包含集 $S_P=\{i:P\in\mathrm{int}(D_i)\}$（$P$ 不在任何圆上，故开闭无差）。$\mathrm{inside}(P,C_i)\iff (P_x-x_i)^2+(P_y-y_i)^2<r_i^2$。答案记 $\mathrm{opt}(A,B)$。

---

### 引理 1（不交不切 ⇒ laminar）

任意两圆 $C_i,C_j$ 要么盘面分离（$D_i\cap D_j=\varnothing$），要么一个严格含于另一个内部。

*证明*：设圆心距 $d$、半径 $r_i,r_j$。两圆边界相交或相切的充要条件是 $|r_i-r_j|\le d\le r_i+r_j$（相交取严格不等，外切 $d=r_i+r_j$，内切 $d=|r_i-r_j|$，重合 $d=0,r_i=r_j$）。题设排除所有这些，故 $d>r_i+r_j$ 或 $d<|r_i-r_j|$。

- $d>r_i+r_j$：两盘面最近距离 $=d-r_i-r_j>0$，分离。
- $d<|r_i-r_j|$：不妨 $r_i>r_j$，则 $d+r_j<r_i$。$D_j$ 中任一点到圆心 $i$ 的距离 $\le d+r_j<r_i$，故 $D_j\subset\mathrm{int}(D_i)$，严格嵌套。

两种情形穷尽，故包含关系是层状的。证毕。

---

### 引理 2（下界：每堵分隔墙必拆）

设 $A,B$ 不在任何圆上。任何使两人相见的方案，破坏的墙数 $\ge|S_A\triangle S_B|$。

*证明*：取任一 $i\in S_A\triangle S_B$，不妨 $A\in\mathrm{int}(D_i)$、$B\notin D_i$。设两人约定在点 $M$ 相见。若 $M\in\mathrm{int}(D_i)$，则 $B$ 从圆外到圆内，其轨迹必穿过圆 $C_i$ 至少一次（Jordan 曲线定理：圆内外的任何连续道路必与圆相交）；若 $M\notin D_i$，则 $A$ 从圆内到圆外，同样必穿 $C_i$。穿墙必须先破坏它，故 $C_i$ 必被拆。这对每个 $i\in S_A\triangle S_B$ 独立成立，故拆墙数 $\ge|S_A\triangle S_B|$。证毕。

（注：此论证对"任意位置相见"都成立，无需假设在 $B$ 见面。）

---

### 引理 3（包含森林与细胞）

定义每个圆 $C_i$ 的父亲为"严格包含 $C_i$ 的最小圆"（若不存在则父亲为虚拟根，代表整个平面）。则：

(a) 父亲良定义，全体构成一棵以虚拟根为根的树（森林加根）；
(b) 点 $P$（不在任何圆上）的包含集 $S_P$ 恰为"$P$ 所在节点到根路径上的真实圆"，是一条链；
(c) 每个节点对应的细胞（圆盘挖去所有孩子圆盘；虚拟根为平面挖去所有根圆盘）是道路连通的；
(d) 父子细胞共享一段非空自由圆弧，可从中穿过而不碰其他圆。

*证明*：
(a) 包含 $C_i$ 的圆两两都含 $C_i$ 的内部，故彼此相交，由引理 1 必嵌套，构成一条链；有限链有唯一最小元，即父亲。无父亲者为根，挂在虚拟根下。每个非根节点恰一个父亲、无环（严格包含关系反对称且传递），故是树。

(b) $P$ 的包含集是链（同理两两嵌套）。设其中最小圆为 $C_k$（若空则 $P$ 在虚拟根细胞）。$P$ 落在 $C_k$ 的细胞里（在 $C_k$ 内但不在任何孩子内，否则孩子也含 $P$，与 $C_k$ 最小矛盾）。$S_P$ 恰为 $C_k$ 及其所有祖先 = 节点到根路径上的真实圆。

(c) 细胞 = 一个开圆盘去掉有限个**两两分离、且严格位于内部（不贴边界）**的闭子圆盘。圆盘去掉这样的孔仍道路连通：任意两点可先沿不碰孔的折线相连（孔有限且互不贴、离边界有正距离，总绕得开）。虚拟根细胞 = 平面去掉有限个分离闭圆盘，同样连通。

(d) 父 $C_p$、子 $C_c$：$C_c$ 的边界上，被孙子圆盘盖住的部分是有限段闭弧（孙子严格在 $C_c$ 内且两两分离、不与 $C_c$ 相切），故 $C_c$ 边界上存在非空开弧不属于任何孙子。这段弧一侧是父细胞、另一侧是子细胞，穿过它只跨 $C_c$ 一个圆。证毕。

---

### 引理 4（上界：沿树路径恰好拆分隔墙）

存在一条从 $A$ 到 $B$ 的道路，穿过的圆恰为 $S_A\triangle S_B$，每个一次。故 $\mathrm{opt}(A,B)\le|S_A\triangle S_B|$。

*证明*：设 $A,B$ 所在细胞节点为 $u,v$，最近公共祖先为 $w$。沿树路径 $u\to w\to v$ 行走：每经过一条树边（父↔子），由引理 3(d) 从共享自由弧穿过对应的子圆一次。整条路径穿过的圆 = 路径上除 $w$ 外的所有节点对应的圆。

而 $S_A=$ $u$ 到根的祖先链（含 $u$），$S_B=$ $v$ 到根的祖先链（含 $v$）。两链的交 = $w$ 到根的链（含 $w$）。故对称差 $S_A\triangle S_B=$（$u$ 到 $w$ 不含 $w$）$\cup$（$v$ 到 $w$ 不含 $w$）= 路径上除 $w$ 外的节点。两者逐一对应，且每个只穿一次。

于是只破坏 $S_A\triangle S_B$ 这些墙（各一次）即可从 $A$ 走到 $B$ 相见，上界成立。结合引理 2，$\mathrm{opt}(A,B)=|S_A\triangle S_B|$。证毕。

---

### 引理 5（计数公式与整数判据）

$\mathrm{opt}(A,B)=\sum_{i=0}^{N-1}\bigl[\mathrm{inside}(A,C_i)\ne\mathrm{inside}(B,C_i)\bigr]$，其中 $\mathrm{inside}(P,C_i)\iff(P_x-x_i)^2+(P_y-y_i)^2<r_i^2$。

*证明*：$|S_A\triangle S_B|$ 按定义即"恰好属于一个集合"的元素个数，逐圆判断 $\mathrm{inside}(A)\oplus\mathrm{inside}(B)$ 求和即是。点在圆内 $\iff$ 到圆心距离 $<r$ $\iff$ 距离平方 $<r^2$（两边非负，平方保序）；点不在圆上保证不取等号，严格 $<$ 良定义。证毕。

---

### 引理 6（64 位必要性）

坐标 $\in[-10^8,10^8]$，故 $|P_x-x_i|\le2\times10^8$，$(P_x-x_i)^2\le4\times10^{16}$，距离平方 $\le8\times10^{16}$；$r_i^2\le10^{16}$。`int` 上限 $\approx2.1\times10^9$ 远不够，必须 `long long`（上限 $9.2\times10^{18}$）。

*证明*：直接代入上界。$8\times10^{16}<9.2\times10^{18}$，`long long` 安全；所有减法、乘法、比较都在 `long long` 下进行（读入即用 `i64`，半径平方 `(i64)r*r` 预处理）。证毕。

---

### 引理 7（复杂度）

时间 $O(NQ)$，空间 $O(N)$。$N=Q=8000$ 时 $6.4\times10^7$ 次内层迭代，每次常数次 64 位乘加与比较，实测 0.19 s，远低于 3 s。

*证明*：每组询问扫 $N$ 个圆，每圆 $O(1)$（两次距离平方 + 两次比较 + 一次异或），共 $O(NQ)$。预处理 $r_i^2$ 为 $O(N)$。数组 `x,y,r2` 各 $O(N)$。证毕。

---

### 定理

程序对每组询问输出 $|S_A\triangle S_B|$，即最少破坏墙数，总复杂度 $O(NQ)$、64 位无溢出。

*证明*：引理 1 确立 laminar 结构；引理 2 给下界；引理 3、4 用包含森林与细胞连通性构造达到下界的路径，得 $\mathrm{opt}=|S_A\triangle S_B|$；引理 5 把它化为逐圆异或计数；引理 6 保证 64 位实现正确；引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 圆是 Jordan 曲线，穿过翻转内/外 ⇒ 一堵墙必拆 ⟺ 它恰好包含两点之一（奇偶性下界）。
2. **explore its property** — "不交不切"⇒ laminar：圆要么分离要么嵌套，包含集是链，可建包含森林。
3. **reduce to easier problem** — 上界构造：沿包含树路径走，细胞连通、相邻细胞共享自由弧 ⇒ 每堵分隔墙恰穿一次 ⇒ 答案 $=|S_A\triangle S_B|$；"任意位置相见"不改变下界。
4. **classic problem solution** — 无需真的建树：每询问 $O(N)$ 扫描，$\mathrm{inside}(A)\oplus\mathrm{inside}(B)$ 计数，$r^2$ 预处理。
5. **discuss by category** — 坐标 $10^8$ ⇒ 距离平方 $8\times10^{16}$ 必须 `long long`；点不在圆上 ⇒ 严格 `<`；$N=0$ 或 $Q=0$ 自然退化。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,q` | 墙数 / 询问数，$\le8000$ | `int` | 读入 |
| `x[i],y[i]` | 第 $i$ 圆圆心 | `i64[mxn]` | 读入即 64 位 |
| `r2[i]` | 第 $i$ 圆半径平方 $r_i^2$ | `i64[mxn]` | `(i64)r*r` 预处理 |
| `a,b,c,d` | 当前询问 $A=(a,b),B=(c,d)$ | `i64` | 每询问读入 |
| `da,db` | $A,B$ 到当前圆心的距离平方 | `i64` | 每圆现算 |
| `ans` | 当前询问答案 = 分隔墙数 | `int` | 每询问清 0，异或累加 |
| `mxn` | $8000+5$ | `constexpr int` | +5 松弛 |

### 算法步骤

1. I/O 加速三行；读 `n`，对每圆读 `x,y,r` 并存 `r2=(i64)r*r`。
2. 读 `q`；每询问读 `a,b,c,d`，`ans=0`。
3. 扫每个圆：算 `da=(a-x)²+(b-y)²`、`db=(c-x)²+(d-y)²`（全 `i64`）；`ans+=(da<r2)!=(db<r2)`。
4. 输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(NQ)\le6.4\times10^7$ 次常数次 64 位运算，实测极限 0.19 s（时限 3 s）。
- 空间：$O(N)$，三个 `i64` 数组约 $0.2$ MB。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过；嵌套 / 分离 / $N=0$ 三组手造数据逐条吻合；$N=Q=8000$ 极限数据 0.19 s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2778 [AHOI2016初中组] 迷宫
// 思路：圆两两不交不切 ⇒ 包含关系 laminar（不相交即嵌套）。
//       一堵墙必须拆 <=> 它恰好包含两点之一：奇偶性给下界，沿包含树路径走给上界。
//       答案 = #{圆恰好包含一点}，每询问 O(N) 扫一遍 insideA^insideB 计数，无需建树。
//       坐标 1e8 ⇒ 距离平方最大 8e16，必须 i64；点不在圆上 ⇒ 严格 < 即可。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{8005};

int n,q;
i64 x[mxn],y[mxn],r2[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0,r;i<n;++i)
	{
		cin>>x[i]>>y[i]>>r;
		r2[i]=(i64)r*r;		// 半径平方预处理，避免每询问重算
	}
	cin>>q;
	for(i64 a,b,c,d;q--;)
	{
		cin>>a>>b>>c>>d;
		int ans=0;
		for(int i=0;i<n;++i)
		{
			i64 da=(a-x[i])*(a-x[i])+(b-y[i])*(b-y[i]);
			i64 db=(c-x[i])*(c-x[i])+(d-y[i])*(d-y[i]);
			ans+=(da<r2[i])!=(db<r2[i]);	// 恰好包含一点 ⇒ 这堵墙横在两人之间
		}
		cout<<ans<<'\n';
	}
	return 0;
}
```

### 代码说明

- 整份代码没有树、没有几何构造——森林与细胞连通性只在第二部分用来**证明** $|S_A\triangle S_B|$ 既是下界又可达；计算层面就是逐圆异或计数。
- `x,y,r2,a,b,c,d,da,db` 全部 `i64`：任何一处用 `int` 都会在 $8\times10^{16}$ 量级溢出。半径读入用临时 `int r`（$\le10^8$ 安全），但 `r2[i]=(i64)r*r` 先转 64 位再乘，避免 `r*r` 以 `int` 溢出。
- `(da<r2[i])!=(db<r2[i])` 是布尔异或：两 inside 状态不同则 $+1$。严格 `<` 依赖"点不在圆上"的保证，无需处理等号。
- `ans` 是 `int`：最多 $N\le8000$，远不溢出；每询问重置 0。
- $N=0$ 时内层循环不执行，`ans=0`；$Q=0$ 时不读询问、无输出——退化情形自动正确。
