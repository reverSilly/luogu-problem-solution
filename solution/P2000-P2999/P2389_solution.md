# P2389 电脑班的裁员 — 题解

## 一、解题过程：人类思考叙事

题目：$n$ 个同学排成一排（$n\le 500$），第 $i$ 个得分 $a_i\in[-1000,1000]$，**可以为负**。要选出**不大于 $k$ 段**（$k\le n$）相邻的同学留下，其余裁掉，最大化留下同学的得分和。题面没有样例，下面的例子都是我手算并用程序核对过的。

**第一反应：这是"最大子段和"的加强版。** $k=1$ 时就是经典 Kadane：$f_i=\max(f_{i-1}+a_i,\ a_i)$。现在允许 $k$ 段，直觉是"做 $k$ 次最大子段和"——但这个直觉立刻有问题：第一段取走之后，剩下的部分被切成两截，第二次该在哪一截里取？而且"取走一段"和"在剩下的里再取"并不独立，贪心地反复取最大子段会错。

**先弄清"段"的组合结构。** 留下的同学构成 $\{1..n\}$ 的一个子集 $S$。把 $S$ 里极大的连续块叫"段"，那么"选出不大于 $k$ 段相邻的同学"就等价于：**$S$ 是至多 $k$ 个互不相交的非空连续区间的并**。反过来，任何这样的并集都合法。注意两个被选中的区间如果**紧挨着**（比如 $[1,3]$ 和 $[4,5]$），它们的并其实是一整段 $[1,5]$，段数是 $1$ 而不是 $2$——这一点后面会影响状态设计的语义。

**一个必须先定下来的边界：能不能一段都不选？** 题面写的是"**不大于** $k$ 段"，$0\le k$，所以 $0$ 段合法，对应"把所有人裁掉"，得分和为 $0$。于是：

$$\text{ans}\ge 0,\qquad \text{若所有 }a_i<0\text{，则 ans}=0.$$

我特意用 $a=[-1,-2,-3],k=2$ 验证：程序输出 $0$。这一条不能想当然——如果误写成"恰好 $k$ 段"或"至少一段"，全负数据就会输出 $-1$（最大的单个元素）而不是 $0$。**本文按题面字面取"至多 $k$ 段、可为 $0$ 段"。**（若某份数据要求至少留一段，全负时的答案会变成 $\max a_i$；这是题意分歧点，我在第四节明确标注。）

**第二反应：朴素 DP + 前缀和。** 设 $s_i=\sum_{t\le i}a_t$。定义 $g[i][j]$ 为"前 $i$ 个同学、至多 $j$ 段"的最大得分和。考虑第 $i$ 个同学选不选：

- 不选：$g[i-1][j]$；
- 选：那么他所在的最后一段是 $[t+1,i]$，其中 $0\le t<i$，前面 $t$ 个同学里至多 $j-1$ 段。贡献 $g[t][j-1]+s_i-s_t$。

于是
$$g[i][j]=\max\Bigl(g[i-1][j],\ \max_{0\le t<i}\bigl(g[t][j-1]-s_t\bigr)+s_i\Bigr).$$

复杂度 $O(n^2k)$。$n=k=500$ 时约 $\frac{n(n+1)}2\cdot k\approx6.3\times10^7$ 次加法与比较——**说实话这个量级在 C++ 里大概率能过**，我不想假装它 TLE。但它的写法笨重（三重循环、$t$ 的边界容易错），而且式子里那个 $\max_{t<i}(g[t][j-1]-s_t)$ 明摆着是个**前缀最大值**，可以边扫边维护。

**第三反应：把前缀最大值变成一个状态。** 令
$$h[i][j]=\max_{0\le t\le i}\bigl(g[t][j-1]-s_t\bigr),$$
则 $h[i][j]=\max(h[i-1][j],\ g[i][j-1]-s_i)$，$O(1)$ 递推。这样总复杂度降到 $O(nk)=2.5\times10^5$。

再往前走一步：把 $h$ 换个写法会更漂亮。定义 $f[i][j]$ 为"前 $i$ 个同学、至多 $j$ 段、**且第 $i$ 个同学被选**（他是最后一段的右端点）"的最大得分和。注意 $f[i][j]-s_i$ 恰好就是"以 $i$ 结尾的最后一段"对应的 $g[t][j-1]-s_t$ 的最大值，也就是 $h[i-1][j]$ 那一族东西。直接对 $f$ 列转移：第 $i$ 个人被选时，第 $i-1$ 个人选没选？

- **选了**：把 $i$ 接到上一段末尾，段数不变 ⇒ $f[i-1][j]+a_i$；
- **没选**：$i$ 自己开一段，前面至多 $j-1$ 段 ⇒ $g[i-1][j-1]+a_i$。

$$\boxed{f[i][j]=\max(f[i-1][j],\ g[i-1][j-1])+a_i},\qquad \boxed{g[i][j]=\max(g[i-1][j],\ f[i][j])}.$$

两个 $O(1)$ 转移，$O(nk)$，而且**不需要显式前缀和数组**——前缀和的思想被吸收进 $f$ 这个状态里了。这就是最终实现。

**这里有个语义细节必须想清楚，否则会怀疑自己写错了。** 我把 $f,g$ 都定义成"**至多** $j$ 段"而不是"恰好 $j$ 段"。好处是：上面"没选 $i-1$ ⇒ $i$ 开新段"的推理里，如果实际上 $i-1$ 被选了（走的是另一支），两段会合并成一段，段数不增反减——但"至多 $j$"对合并是**封闭**的，所以两支都不会产生非法方案。若用"恰好 $j$ 段"，就必须额外禁止相邻，转移要麻烦得多。而"至多"语义还白送一条单调性：$g[i][j]\ge g[i][j-1]$，所以最后直接输出 $g[n][k]$，不用再对 $j$ 取一遍 max。

**边界与初始化（本题真正的坑）：**

- $g[0][j]=0$：前 $0$ 个人只能空选。
- $g[i][0]=0$：至多 $0$ 段也只能空选。**这两条都是 $0$，恰好等于全局数组默认值。**
- $f[0][j]=-\infty$：前 $0$ 个人里"第 $0$ 个人被选"是不可能的状态。
- $f[i][0]=-\infty$：$0$ 段却要求第 $i$ 个人被选，不可能。

**全局 `int` 数组默认是 $0$ 而不是 $-\infty$**，所以 $f$ 的第 $0$ 行必须显式填 $-\infty$。好在本题 $g\ge0$ 恒成立，$\max(f[i-1][j],g[i-1][j-1])\ge g[i-1][j-1]\ge0$，永远不会真的把 $-\infty$ 拿去加 $a_i$，所以不会有 $-\infty$ 溢出问题——但语义上仍应填对。

**手算校验：**

- $a=[1,-2,3,-4,5]$：$k=1\to5$（只留 $[5]$）；$k=2\to8$（留 $[3]$ 和 $[5]$，注意这比 $[1,-2,3]+[5]=7$ 更好）；$k=3\to9$（留 $1,3,5$ 三个单点）。这个例子很好地说明"段数上限"是怎么起作用的：$k=2$ 时不能把 $1,3,5$ 都单独留。
- $a=[-1,5,-1,5,-1,5]$：$k=2\to14$（$[5,-1,5]+[5]=9+5$）；$k=3\to15$（三个 $5$ 各一段）。
- $a=[-1,-2,-3],k=2\to0$（全裁）。
- $a=[1,2,3],k=3\to6$（一段就够，"至多"不会强迫用满 $k$）。

## 二、思维链：完整证明

### 记号与状态定义

- $a_1,\dots,a_n$ 为得分，$s_i=\sum_{t=1}^{i}a_t$，$s_0=0$。
- 对子集 $S\subseteq\{1..i\}$，记 $\mathrm{run}(S)$ 为 $S$ 的极大连续块个数（$\mathrm{run}(\varnothing)=0$），$\mathrm{sum}(S)=\sum_{t\in S}a_t$。
- $\mathrm{Sel}(i,j)=\{S\subseteq\{1..i\}:\mathrm{run}(S)\le j\}$。
- $\mathrm{F}(i,j)=\{S\in\mathrm{Sel}(i,j):i\in S\}$（$i\ge1$）。
- $g[i][j]=\max_{S\in\mathrm{Sel}(i,j)}\mathrm{sum}(S)$；$f[i][j]=\max_{S\in\mathrm{F}(i,j)}\mathrm{sum}(S)$，若 $\mathrm{F}(i,j)=\varnothing$ 则定义为 $-\infty$。

### 引理 1（方案刻画与空选合法性）

题目的合法方案与 $\mathrm{Sel}(n,k)$ 一一对应；$\varnothing\in\mathrm{Sel}(n,k)$，故答案 $\ge0$，且当所有 $a_i<0$ 时答案 $=0$。

*证明*：一个方案就是"留下哪些同学"，即一个子集 $S\subseteq\{1..n\}$。$S$ 的极大连续块就是题面说的"段"，它们互不相交、每段非空连续，且 $S$ 是它们的并；反之任何至多 $k$ 个互不相交非空连续区间的并，其极大连续块个数不超过 $k$（每个区间至多贡献一个块，相邻区间合并只会减少块数）。故合法方案集合 $=\mathrm{Sel}(n,k)$，得分和 $=\mathrm{sum}(S)$，答案 $=g[n][k]$。

$\mathrm{run}(\varnothing)=0\le k$，故 $\varnothing$ 合法，$\mathrm{sum}(\varnothing)=0$，答案 $\ge0$。若所有 $a_i<0$，则任何非空 $S$ 都有 $\mathrm{sum}(S)<0$，最大值在 $S=\varnothing$ 取到，答案 $=0$。证毕。

**题意分歧点说明**：这里用的是题面"不大于 $k$ 段"的字面含义（含 $0$ 段）。若改成"至少一段"，则答案应为 $\max_{S\ne\varnothing}\mathrm{sum}(S)$，全负时等于 $\max_i a_i$。本文按字面处理。

### 引理 2（$g$ 的转移）

对 $i\ge1,j\ge0$：$g[i][j]=\max(g[i-1][j],\ f[i][j])$。

*证明*：把 $\mathrm{Sel}(i,j)$ 按"是否含 $i$"划分：
$$\mathrm{Sel}(i,j)=\underbrace{\{S\in\mathrm{Sel}(i,j):i\notin S\}}_{=\ \mathrm{Sel}(i-1,j)}\ \sqcup\ \underbrace{\{S\in\mathrm{Sel}(i,j):i\in S\}}_{=\ \mathrm{F}(i,j)}.$$
第一个等号：不含 $i$ 的子集就是 $\{1..i-1\}$ 的子集，且块数不变，故条件 $\mathrm{run}\le j$ 完全一致。第二个等号是 $\mathrm{F}$ 的定义。两集合不交且并为全体，故最大值等于两部分最大值的较大者，即 $\max(g[i-1][j],f[i][j])$。证毕。

### 引理 3（$f$ 的转移，核心）

对 $i\ge1,j\ge1$：
$$f[i][j]=a_i+\max\bigl(f[i-1][j],\ g[i-1][j-1]\bigr).$$

*证明*：分两个方向。

**（$\ge$，构造可达）**

- 取 $S'\in\mathrm{F}(i-1,j)$ 使 $\mathrm{sum}(S')=f[i-1][j]$（若 $\mathrm{F}(i-1,j)=\varnothing$ 则此项为 $-\infty$，不等式自动成立）。令 $S=S'\cup\{i\}$。因 $i-1\in S'$，$i$ 与 $S'$ 的最后一块相连，$\mathrm{run}(S)=\mathrm{run}(S')\le j$；又 $S\subseteq\{1..i\}$、$i\in S$，故 $S\in\mathrm{F}(i,j)$，$\mathrm{sum}(S)=f[i-1][j]+a_i$。
- 取 $S'\in\mathrm{Sel}(i-1,j-1)$ 使 $\mathrm{sum}(S')=g[i-1][j-1]$。令 $S=S'\cup\{i\}$。加入一个元素至多让块数增加 $1$（若 $i-1\in S'$ 则合并，块数不变；否则新增一块），故 $\mathrm{run}(S)\le(j-1)+1=j$，$S\in\mathrm{F}(i,j)$，$\mathrm{sum}(S)=g[i-1][j-1]+a_i$。

两者都是 $\mathrm{F}(i,j)$ 中的合法元素，故 $f[i][j]\ge a_i+\max(\cdot,\cdot)$。

**（$\le$，最优子结构）** 取 $S\in\mathrm{F}(i,j)$ 使 $\mathrm{sum}(S)=f[i][j]$，令 $S'=S\setminus\{i\}$。因 $i\in S$ 且 $i$ 是 $\{1..i\}$ 的最大元，$i$ 必是 $S$ 最后一块的右端点。分两种情形：

- **$i\ge2$ 且 $i-1\in S$**：则 $i-1\in S'$，且含 $i$ 的那一块长度 $\ge2$，删去 $i$ 后该块仍非空，块数不变：$\mathrm{run}(S')=\mathrm{run}(S)\le j$。故 $S'\in\mathrm{F}(i-1,j)$，$\mathrm{sum}(S')\le f[i-1][j]$，得 $f[i][j]\le f[i-1][j]+a_i$。
- **$i=1$ 或 $i-1\notin S$**：则 $i$ 在 $S$ 中自成一个单点块（左边没有相邻被选元素），删去它使块数**恰好减 $1$**：$\mathrm{run}(S')=\mathrm{run}(S)-1\le j-1$。故 $S'\in\mathrm{Sel}(i-1,j-1)$，$\mathrm{sum}(S')\le g[i-1][j-1]$，得 $f[i][j]\le g[i-1][j-1]+a_i$。

两种情形都 $\le a_i+\max(\cdot,\cdot)$。双向夹逼得等式。证毕。

**注（为什么"至多"语义让证明变简单）**：若把状态定义成"恰好 $j$ 段"，则（$\ge$）的第二条构造在 $i-1\in S'$ 时会得到 $j-1$ 段而非 $j$ 段，构造失效，必须额外强制 $i-1\notin S'$。用"至多"语义后，块数减少永远合法，两条构造都无条件成立——这正是第一节里"相邻区间合并"那个观察的用处。

### 引理 4（边界条件）

$g[0][j]=0\ (j\ge0)$；$g[i][0]=0\ (i\ge0)$；$f[0][j]=-\infty\ (j\ge0)$；$f[i][0]=-\infty\ (i\ge1)$。

*证明*：
- $\mathrm{Sel}(0,j)=\{\varnothing\}$（$\{1..0\}=\varnothing$ 只有空子集），$\mathrm{sum}=0$，故 $g[0][j]=0$。
- $\mathrm{Sel}(i,0)=\{S:\mathrm{run}(S)\le0\}=\{\varnothing\}$，故 $g[i][0]=0$。
- $\mathrm{F}(0,j)$ 要求 $0\in S\subseteq\varnothing$，不可能，集合为空，故 $f[0][j]=-\infty$。
- $\mathrm{F}(i,0)$ 要求 $S\ne\varnothing$（含 $i$）却 $\mathrm{run}(S)\le0$，矛盾，集合为空，故 $f[i][0]=-\infty$。证毕。

**实现陷阱**：全局 `int` 数组默认 $0$。$g$ 的边界恰好都是 $0$，可以不管；但 $f$ 的第 $0$ 行与第 $0$ 列必须显式填 $-\infty$，否则 $f[0][j]=0$ 会被当成"存在一个和为 $0$ 的合法方案"，虽然本题因 $g\ge0$ 而不会算错数值（见引理 6），语义上仍是错的，换个题就会炸。

### 引理 5（单调性：不必对 $j$ 再取 max）

$g[i][j]\ge g[i][j-1]$，$f[i][j]\ge f[i][j-1]$（$j\ge1$）。特别地 $g[i][j]\ge0$。

*证明*：$\mathrm{Sel}(i,j-1)\subseteq\mathrm{Sel}(i,j)$（约束 $\mathrm{run}\le j-1$ 比 $\mathrm{run}\le j$ 更强），在更大集合上取最大值不会更小，故 $g[i][j]\ge g[i][j-1]$。同理 $\mathrm{F}(i,j-1)\subseteq\mathrm{F}(i,j)$ 给出 $f$ 的单调性。又 $\varnothing\in\mathrm{Sel}(i,j)$ 且 $\mathrm{sum}(\varnothing)=0$，故 $g[i][j]\ge0$。证毕。

推论：最终答案就是 $g[n][k]$，不需要 $\max_{j\le k}g[n][j]$；且 $k=0$ 时输出 $0$，与引理 1 一致。

### 引理 6（值域与 $-\infty$ 安全性）

$|g[i][j]|\le\sum_{t=1}^{n}|a_t|\le5\times10^5$，$f[i][j]\ge-1000$（$j\ge1$）；转移中不会出现 $-\infty+a_i$ 的运算。故 `int` 足够，哨兵取 `1145141919` 安全。

*证明*：任何 $S\subseteq\{1..n\}$ 满足 $|\mathrm{sum}(S)|\le\sum|a_t|\le500\times1000=5\times10^5$，故 $g,f$ 的有限值都在 $[-5\times10^5,5\times10^5]$ 内，`int`（$\pm2.1\times10^9$）绰绰有余。

由引理 5，$g[i-1][j-1]\ge0$，故 $\max(f[i-1][j],g[i-1][j-1])\ge0$，转移里被加 $a_i$ 的那个数**永远非负**，$-\infty$ 只参与 $\max$ 比较、不参与加法，不会溢出也不会污染结果。又 $f[i][j]\ge g[i-1][j-1]+a_i\ge a_i\ge-1000$。证毕。

### 引理 7（与前缀和 DP 的等价性 / $O(n^2k)\to O(nk)$ 的合法性）

设 $h[i][j]=f[i][j]-s_i$，则
$$h[i][j]=\max\bigl(h[i-1][j],\ g[i-1][j-1]-s_{i-1}\bigr)=\max_{0\le t\le i-1}\bigl(g[t][j-1]-s_t\bigr),$$
从而
$$g[i][j]=\max\Bigl(g[i-1][j],\ s_i+\max_{0\le t<i}\bigl(g[t][j-1]-s_t\bigr)\Bigr).$$

*证明*：由引理 3，$f[i][j]=a_i+\max(f[i-1][j],g[i-1][j-1])$。两边减 $s_i$，并用 $a_i=s_i-s_{i-1}$：
$$f[i][j]-s_i=\max(f[i-1][j],g[i-1][j-1])-s_{i-1}=\max(f[i-1][j]-s_{i-1},\ g[i-1][j-1]-s_{i-1}),$$
即 $h[i][j]=\max(h[i-1][j],g[i-1][j-1]-s_{i-1})$。展开这个一阶递推（$h[0][j]=f[0][j]-s_0=-\infty$）得 $h[i][j]=\max_{0\le t\le i-1}(g[t][j-1]-s_t)$。

再由引理 2，$g[i][j]=\max(g[i-1][j],f[i][j])=\max(g[i-1][j],s_i+h[i][j])$，代入即得第二式。

**组合解释**：$s_i-s_t=\mathrm{sum}([t+1,i])$，所以第二式正是"枚举最后一段的左端点 $t+1$"的朴素 DP。这说明 $f/g$ 写法与朴素前缀和写法**逐项相等**，只是把内层的 $\max_{t<i}$ 用 $f$ 这个状态增量维护掉了：每个 $(i,j)$ 只做一次 $\max$ 而不是 $i$ 次，复杂度从 $O(n^2k)$ 降到 $O(nk)$。证毕。

### 引理 8（计算顺序与无后效性）

按 $i=1..n$ 外层、$j=1..k$ 内层的顺序计算，所有依赖都已就绪。

*证明*：计算 $f[i][j]$ 需要 $f[i-1][j]$（上一行、同列）与 $g[i-1][j-1]$（上一行、前一列）；计算 $g[i][j]$ 需要 $g[i-1][j]$（上一行、同列）与刚算出的 $f[i][j]$。全部依赖都在**上一行**或**本格**，故按行递增、行内列递增的顺序拓扑合法。第 $0$ 行由引理 4 显式初始化。对 $i$ 归纳即得整表正确。证毕。

### 定理（算法正确性与复杂度）

程序输出 $g[n][k]$，等于题目所求最大得分和；时间 $O(nk)$，空间 $O(nk)$。

*证明*：引理 1 把题目化为 $\max_{S\in\mathrm{Sel}(n,k)}\mathrm{sum}(S)=g[n][k]$；引理 2、3、4 给出 $f,g$ 的完整转移与边界；引理 8 保证按序求值正确；引理 5 保证无需对 $j$ 再取 max；引理 6 保证 `int` 与哨兵安全；引理 7 说明该 $O(nk)$ 写法与朴素 $O(n^2k)$ 前缀和 DP 等价。状态数 $2(n+1)(k+1)$，每个 $O(1)$ 转移，故时间 $O(nk)$；两个 $(n+1)\times(k+1)$ 的 `int` 数组，$505^2\times4\times2\approx2$ MB，空间 $O(nk)$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "不大于 $k$ 段相邻同学" $=$ 至多 $k$ 个互不相交连续区间的并；相邻区间会合并，所以要用"至多"而非"恰好"语义。
- **discuss by category** — 先定边界：$0$ 段合法 ⇒ 答案 $\ge0$，全负时答案为 $0$（题意分歧点，按字面取"至多"）。
- **consider easier version** — $k=1$ 退化为最大子段和（Kadane）；"反复取最大子段"的贪心因剩余部分被切断而失效。
- **classic problem solution** — 划分型 DP + 前缀和：$g[i][j]=\max(g[i-1][j],\ s_i+\max_{t<i}(g[t][j-1]-s_t))$，$O(n^2k)\approx6\times10^7$。
- **reduce to easier problem** — 内层 $\max_{t<i}(g[t][j-1]-s_t)$ 是前缀最大值 ⇒ 增量维护，降到 $O(nk)$。
- **explore its property** — 把前缀最大值吸收进状态：引入"第 $i$ 人必选且为最后一段右端点"的 $f[i][j]$，转移只剩"接上一段 / 另起一段"两项。
- **classic problem solution** — $f/g$ 双状态 DP：$f[i][j]=\max(f[i-1][j],g[i-1][j-1])+a_i$，$g[i][j]=\max(g[i-1][j],f[i][j])$。
- **discuss by category** — 初始化与值域：$g$ 的边界全是 $0$（与全局默认一致），$f$ 的第 $0$ 行/列必须显式 $-\infty$；$g\ge0$ 保证 $-\infty$ 不参与加法。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 同学数（$\le500$） | `int`，读入 | 下标 $1..n$ |
| `k` | 段数上限（$\le n$） | `int`，读入 | "至多"，可为 $0$ |
| `a[i]` | 第 $i$ 个同学得分（$[-1000,1000]$） | `int[mxn]`，读入 | 1-based |
| `f[i][j]` | 前 $i$ 人、至多 $j$ 段、**第 $i$ 人被选且是最后一段右端点**的最大和 | `int[mxn][mxn]` | "f = 结尾必选" |
| `g[i][j]` | 前 $i$ 人、至多 $j$ 段（第 $i$ 人选不选都行）的最大和 | `int[mxn][mxn]` | "g = 全局最优"，答案 `g[n][k]` |
| `f[0][j]` | 不可能状态 | 显式置 `-inf` | **全局默认 0 的陷阱** |
| `f[i][0]` | 不可能状态（$0$ 段却含 $i$） | 显式置 `-inf` | 实际不参与转移 |
| `g[0][j]`,`g[i][0]` | 只能空选 | $0$（全局默认即可） | 空选合法 ⇒ $g\ge0$ |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 只参与 `max`，不参与加法 |
| `mxn` | $500+5$ | `constexpr int mxn{505}` | +5 松弛 |

### 算法步骤

1. I/O 加速：`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`。
2. 读入 `n,k` 与 `a[1..n]`。
3. 初始化：对 `j=0..k` 令 `f[0][j]=-inf`；`g` 的第 $0$ 行与第 $0$ 列保持全局默认 $0$。
4. 外层 `i=1..n`：先令 `f[i][0]=-inf`；内层 `j=1..k`：
   1. `f[i][j]=max(f[i-1][j],g[i-1][j-1])+a[i]`（接上一段 / 另起一段，引理 3）；
   2. `g[i][j]=max(g[i-1][j],f[i][j])`（第 $i$ 人不选 / 选，引理 2）。
5. 输出 `g[n][k]` 与 `'\n'`（引理 5 保证这就是"至多 $k$ 段"的最优值）。

### 复杂度

- 时间：$O(nk)$，$n=k=500$ 时约 $2.5\times10^5$ 次转移。
- 空间：$O(nk)$，两个 `505*505` 的 `int` 数组约 $2$ MB。
- 值域：$|ans|\le5\times10^5$，`int` 安全（引理 6）。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；题面无样例，改为与"枚举全部 $2^n$ 个子集、数极大连续段 $\le k$ 取最大和（含空集）"的暴力**端到端对拍 373 组**（$n\le12$，含 13 组手工边界 + 300 组随机 + 60 组全负/全正/近零），$0$ mismatch；另在 $n=500$、$k\in\{1,3,250,500\}$ 的 8 组大规模随机数据上与独立的 $O(n^2k)$ 前缀和 DP 逐项一致。**唯一疑虑**：全负数据的答案取 $0$（"至多 $k$ 段"含 $0$ 段）；若判题数据要求至少留一段，则应为 $\max a_i$——本文按题面字面处理。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2389 电脑班的裁员
// 思路：至多 k 段不相交连续区间的最大和（0 段合法 ⇒ 答案非负）
//       f[i][j]：前 i 人、至多 j 段、第 i 人必选且为最后一段右端点
//       g[i][j]：前 i 人、至多 j 段（第 i 人可选可不选）
//       f[i][j]=max(f[i-1][j],g[i-1][j-1])+a[i]   接上一段 / 另起一段
//       g[i][j]=max(g[i-1][j],f[i][j])            第 i 人不选 / 选
//       等价于前缀和 DP 把 max_{t<i}(g[t][j-1]-s[t]) 增量维护，O(nk)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{505},inf{1145141919};

int n,k,a[mxn],f[mxn][mxn],g[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int i=1;i<=n;++i)
		cin>>a[i];

	// g 的边界全为 0（空选合法），全局默认值正好；f 的不可能状态必须显式 -inf
	for(int j=0;j<=k;++j)
		f[0][j]=-inf;
	for(int i=1;i<=n;++i)
	{
		f[i][0]=-inf;
		for(int j=1;j<=k;++j)
		{
			f[i][j]=max(f[i-1][j],g[i-1][j-1])+a[i];
			g[i][j]=max(g[i-1][j],f[i][j]);
		}
	}
	cout<<g[n][k]<<'\n';
	return 0;
}
```

### 代码说明

- **两个状态缺一不可**：只有 $g$ 无法表达"最后一段延伸到哪"，只有 $f$ 无法表达"跳过第 $i$ 个人"。$f$ 负责"连续"，$g$ 负责"断开"，二者互相喂饭。
- **"至多 $j$ 段"而非"恰好 $j$ 段"**：这让"另起一段"时即使 $i-1$ 恰好被选（两段合并）也仍然合法，转移无需额外条件；同时白送 $g[i][j]\ge g[i][j-1]$，最后不必对 $j$ 取 max。
- **`f[0][j]=-inf` 必须显式写**：全局 `int` 数组默认 $0$，而"前 $0$ 个人里第 $0$ 个人被选"是不可能状态。本题因 $g\ge0$ 使 $\max$ 结果永不为 $-\infty$，数值上侥幸不出错，但语义必须写对（换个 $g$ 可为负的题就立刻炸）。
- **`-inf` 只参与 `max`，不参与加法**：由 $g[i-1][j-1]\ge0$，`max(...)` 恒 $\ge0$，所以 `+a[i]` 绝不会作用在哨兵上，无溢出风险。
- **下标 1-based**：本题状态天然以"前 $i$ 个人"定义，$i=0$ 表示空前缀，用 1-based 比 0-based 更贴合递推，故不做 `--i` 转换。
- 空间约 $2$ MB（两个 `505*505` 的 `int`），时间 $2.5\times10^5$ 次转移，远低于限制。
