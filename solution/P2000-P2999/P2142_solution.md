# P2142 高精度减法 — 题解

## 一、解题过程：人类思考叙事

题目给两个正整数（最大 $10^{10086}$，也就是一万多位），求 $a-b$，负的话输出负号。

$10^{10086}$ 已经远超 `long long` 的表示范围（约 $9.2\times10^{18}$），必须用字符串做高精度。

先想最朴素的做法：把两个数**倒过来**（低位在前），逐位相减，不够减就从低位借 $10$，最后反转回去。这就是小学竖式减法。

但朴素做法有几个坑：

**坑一：谁减谁？** 题目没说 $a\ge b$。如果 $a<b$，直接做竖式会一路借位，最后得到一堆 $9$。所以必须先比较大小，把小的换到被减的位置（`swap`），并记一个负号标记。

**坑二：怎么比大小？** 两个数可能长度不同（位数不同），也可能长度相同但字典序不同。
- 位数不同 ⇒ 位数多的那个大。
- 位数相同 ⇒ 逐位比较，从高到低第一个不同的位决定大小。

在 C++ 里，如果两个字符串**长度相同**，那么 `a < b` 的字典序比较就等价于数值比较（前提是没有前导零）。这正是 `string` 的 `operator<` 提供的。但当长度不同时，`a < b` 的字典序结果和数值大小**完全无关**（比如 `"9" < "10"` 字典序成立，但 $9>10$）。所以比较必须先比长度，再比字典序。

**坑三：前导零。** 输入可能有前导零吗？题面说"正整数"，按理说没有。但既然要按字符串比较，先把前导零去掉是稳妥做法，而且不改变数值。去掉前导零后，"0" 要单独处理（不能变成空串）。

这一步还有一个好处：**去掉前导零后，长度相同的两个串，字典序比较就是数值比较**——这正是上面第二点成立的前提。所以顺序必须是：先 trim，再比较。

**坑四：结果的零。** $a-b$ 可能等于 $0$。$0$ 不应该输出成 `-0`。所以负号只在结果非零时输出。

**坑五：结果的前导零。** 竖式减法 $1000-1=999$、$1000-999=1$，中间结果低位可能出现 $0$（比如 $1000-1$ 高位是 $000$）。所以反转之后要去掉前导零。

注意这里的顺序细节：程序是**先**去尾零（此时 `res` 是逆序的，尾部对应数值高位）**再**反转。这样"去尾零"等价于"去结果的前导零"。如果写成"先反转再去前导零"也完全正确，但顺序反过来就得小心别重复处理。

**坑六：借位。** 逐位相减时，若当前位不够减，就从高一位借 $1$（本位 +10），并向下传递借位标志 `borrow`。这就是标准竖式。

所以整个算法是：

1. 读入两个字符串 `a`、`b`，trim 前导零。
2. 比较：若 `a.size()<b.size()` 或（长度相同且 `a<b`），则 `swap(a,b)` 并置 `neg=true`。此时保证 `a>=b`。
3. 从低位到高位逐位相减，带借位，结果 `push_back` 到 `res`（此时逆序）。
4. 去掉 `res` 末尾多余的 `'0'`（对应数值的前导零），但至少保留一位。
5. `reverse` 得到正常顺序。
6. 若 `neg` 且 `res != "0"`，输出负号，然后输出 `res`。

复杂度是 $O(\max(|a|,|b|))$，一万位完全没问题。

## 二、思维链：完整证明

**引理 1（trim 不改变数值）**：删除一个十进制正整数字符串的前导零，不改变其数值；若全为零，则该数为 $0$。

*证明*：设字符串为 $d_k d_{k-1}\dots d_0$，其中 $d_k\ne0$ 表示最高位下标（从右往左编号），其数值为 $\sum_{i=0}^{k}d_i 10^i$。删除前导零就是减小 $k$ 而保持 $d_i$ 与 $i$ 不变，故数值不变。若所有字符都是 `'0'`，则数值为 $0$，trim 后置为 `"0"` 仍表示 $0$。证毕。

**引理 2（trim 后长度相同则字典序等价数值序）**：设 $x,y$ 是两个无前导零的十进制串且 $|x|=|y|=k$，则 $x<y$（字典序）当且仅当 $\mathrm{val}(x)<\mathrm{val}(y)$。

*证明*：设 $x,y$ 在最左侧第一个不同的位置为 $i$（从 $0$ 开始编号，最左为 $0$）。若两串完全相同则数值相同，结论成立。否则不妨设 $x_i<y_i$，此时字典序有 $x<y$。
记第 $p$ 位数字为 $x_p,y_p$。由于 $i$ 是第一个不同的位置，对 $p<i$ 有 $x_p=y_p$，故
$$\mathrm{val}(y)-\mathrm{val}(x)=(y_i-x_i)10^{k-1-i}+\sum_{p=i+1}^{k-1}(y_p-x_p)10^{k-1-p}.$$
其中 $y_i-x_i\ge1$，而 $y_p-x_p\ge-9$，故
$$\mathrm{val}(y)-\mathrm{val}(x)\ \ge\ 10^{k-1-i}-9\sum_{p=i+1}^{k-1}10^{k-1-p}=10^{k-1-i}-\bigl(10^{k-1-i}-1\bigr)=1>0,$$
这里用了等比数列求和 $\sum_{p=i+1}^{k-1}10^{k-1-p}=10^{k-2-i}+\dots+10^0=\frac{10^{k-1-i}-1}{9}$（当 $i=k-1$ 时该和为 $0$，结论同样成立）。
故 $\mathrm{val}(x)<\mathrm{val}(y)$。交换 $x,y$ 同理，证毕。

**引理 2'（无前导零时位数越多数值越大）**：设 $x,y$ 是两个无前导零的非负整数十进制串，$|x|<|y|$，则 $\mathrm{val}(x)<\mathrm{val}(y)$。

*证明*：设 $|x|=k$，$|y|=k+r$（$r\ge1$）。$x$ 无前导零故 $\mathrm{val}(x)\le 10^k-1$；$y$ 无前导零故其第 $k+r-1$ 位非零，$\mathrm{val}(y)\ge 10^{k+r-1}\ge10^k>10^k-1\ge\mathrm{val}(x)$。证毕。

**引理 3（比较阶段正确确定符号与大小关系）**：经过 trim 与比较后，`a` 的数值不小于 `b`，且 `neg` 为真当且仅当原来的 $a<b$。

*证明*：trim 由引理 1 不改变数值，故只讨论已 trim 的两串。
若 $|a|<|b|$，由引理 $2'$（无前导零时位数越多数值越大）得 $\mathrm{val}(a)<\mathrm{val}(b)$，执行 `swap` 后新的 `a` 是原 `b`，`neg=true`，正确。
若 $|a|=|b|$，由引理 2，字典序与数值序一致，故 `a<b` 当且仅当 $\mathrm{val}(a)<\mathrm{val}(b)$，同样处理正确。
若 $|a|>|b|$，则 $\mathrm{val}(a)>\mathrm{val}(b)$，不交换、`neg=false`，正确。
两种交换情形恰好覆盖 $\mathrm{val}(a)<\mathrm{val}(b)$ 的全部情形，故交换后必有 $\mathrm{val}(a)\ge\mathrm{val}(b)$，且 `neg` 恰在原 $a<b$ 时为真。证毕。

**引理 4（逐位借位算法正确）**：设输入为无前导零的 $a,b$，且 $\mathrm{val}(a)\ge\mathrm{val}(b)$，算法输出的 `res`（反转前）满足：反转后得到的整数等于 $\mathrm{val}(a)-\mathrm{val}(b)$。

*证明*：把 $a,b$ 看作 $k=\max(|a|,|b|)$ 位（高位补零），记第 $i$ 位（从低到高，$0$ 起始）为 $a_i,b_i$。
算法维护不变量：处理完第 $i$ 位后，已确定的低 $i+1$ 位构成的数值
$$R_i:=\sum_{j=0}^{i}r_j10^j=\sum_{j=0}^{i}(a_j-b_j)10^j+10^{i+1}\cdot \text{borrow}_{i+1},$$
其中 $r_j$ 是写入 `res` 的第 $j$ 个字符对应的数字（`res` 按低位在前存储，故 `res` 的第 $j$ 个字符就是 $r_j$），$\text{borrow}_{i+1}\in\{0,1\}$ 是处理完第 $i$ 位后的借位标志。

归纳验证 $i=0$：初值 $\text{borrow}_0=0$，计算 $x=a_0-\text{borrow}_0=a_0$，$y=b_0$。
- 若 $x\ge y$：$r_0=x-y=a_0-b_0$，$\text{borrow}_1=0$。此时 $R_0=a_0-b_0=\sum_{j=0}^{0}(a_j-b_j)10^j+10^1\cdot0$，成立。
- 若 $x<y$：$r_0=x+10-y=a_0-b_0+10$，$\text{borrow}_1=1$。此时 $R_0=a_0-b_0+10=\sum_{j=0}^{0}(a_j-b_j)10^j+10^1\cdot1$，成立。

归纳步：设不变量对 $i-1$ 成立，即 $R_{i-1}=\sum_{j=0}^{i-1}(a_j-b_j)10^j+10^{i}\cdot\text{borrow}_i$。处理第 $i$ 位时 $x=a_i-\text{borrow}_i$，$y=b_i$。
- 若 $x\ge y$：$r_i=x-y=a_i-b_i-\text{borrow}_i$，$\text{borrow}_{i+1}=0$。于是
$$R_i=R_{i-1}+r_i10^i=\Bigl(\sum_{j=0}^{i-1}(a_j-b_j)10^j+10^{i}\text{borrow}_i\Bigr)+\bigl(a_i-b_i-\text{borrow}_i\bigr)10^{i}=\sum_{j=0}^{i}(a_j-b_j)10^j+10^{i+1}\cdot0,$$
成立。
- 若 $x<y$：$r_i=x+10-y=a_i-b_i-\text{borrow}_i+10$，$\text{borrow}_{i+1}=1$。于是
$$R_i=R_{i-1}+r_i10^i=\Bigl(\sum_{j=0}^{i-1}(a_j-b_j)10^j+10^{i}\text{borrow}_i\Bigr)+\bigl(a_i-b_i-\text{borrow}_i+10\bigr)10^{i}=\sum_{j=0}^{i}(a_j-b_j)10^j+10^{i+1}\cdot1,$$
成立。
故不变量对所有 $i$ 成立。

最终处理完 $k-1$ 位后，$\text{borrow}_k$ 必为 $0$：否则由不变量 $R_{k-1}=\sum_{j=0}^{k-1}(a_j-b_j)10^j+10^k=\mathrm{val}(a)-\mathrm{val}(b)+10^k>10^k$，但 $R_{k-1}$ 是 $k$ 位数，必有 $R_{k-1}\le10^k-1$，矛盾。于是
$$R_{k-1}=\sum_{j=0}^{k-1}(a_j-b_j)10^j=\mathrm{val}(a)-\mathrm{val}(b).$$
反转 `res`（低在前变高在前）得到的数字串正是该整数。证毕。

**引理 5（去零与符号处理正确）**：算法输出的整数等于题目要求的 $a-b$。

*证明*：
- 去零：反转前的 `res` 是低位在前存储，末尾对应数值最高位；删除末尾的 `'0'` 就是删除数值的前导零，不改变数值，循环条件 `res.size()>1` 保证至少保留一位（$0$ 本身保留为 `"0"`）。
- 符号：由引理 3，交换后 `a` 是较大者，$\mathrm{val}(a)-\mathrm{val}(b)\ge0$。原题要求输出 $a-b$：若原 $a\ge b$，`neg=false`，输出 $\mathrm{val}(a)-\mathrm{val}(b)$，正确；若原 $a<b$，`neg=true`，算法输出 $-(\mathrm{val}(b)-\mathrm{val}(a))=\mathrm{val}(a)-\mathrm{val}(b)$，正确。
- 当差为 $0$ 时 `res=="0"`，条件 `neg&&res!="0"` 使程序不输出负号，避免出现 `-0` 这种非法表示。
由引理 4 与上面两点，输出恰为 $a-b$。证毕。

**定理**：算法正确求出 $a-b$。

*证明*：由引理 5 直接得出。证毕。

## 三、模式总结（按实际思考顺序）

1. 数位超过 `long long` ⇒ **字符串存数**，逐位做竖式减法
2. 先要确定"谁减谁" ⇒ **比较大小 + swap + 负号标记**
3. 比较大小不能直接用字典序（位数不同会错）⇒ **先比长度，再比字典序**
4. 字典序比较数值的前提是**没有前导零** ⇒ **先 trim 再比较**（trim 不改变数值，故不破坏正确性）
5. 竖式减法的两个要点：**借位** 与 **低位在前存储**
6. 输出前的两个清理：**去结果的前导零** 与 **$0$ 不带负号**

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 |
|------|------|------|
| `a`,`b` | 两个正整数的十进制字符串 | `string` |
| `neg` | 结果是否为负（交换后原 $a<b$ 则为真） | `bool` |
| `borrow` | 当前位的借位标志，$0$ 或 $1$ | `int` |
| `x` | 当前位算出的被减数（已减去借位） | `int` |
| `y` | 当前位算出的减数（高位不足时为 $0$） | `int` |
| `res` | 结果串，**低位在前**存储 | `string` |

### 算法步骤

1. 读入 `a`、`b`。
2. `trim`：用 `find_first_not_of('0')` 找到第一个非零字符，全零则置为 `"0"`。
3. 比较：若 `a.size()<b.size()` 或（长度相同且 `a<b`），则 `swap(a,b)` 并 `neg=true`；此后保证 $a\ge b$。
4. 逐位相减：从 `a` 的最后一位与 `b` 的最后一位同时向左走，`j` 到 $-1$ 后 `y` 记 $0$；`x<y` 时 `x+=10` 且 `borrow=1`，否则 `borrow=0`；把 `x-y` 压入 `res`。
5. 去掉 `res` 末尾的 `'0'`（至少留一位）。
6. `reverse(res)`。
7. 若 `neg && res!="0"` 先输出 `'-'`，再输出 `res` 与换行。

### 复杂度

- 时间复杂度 $O(\max(|a|,|b|))$：trim、比较、逐位减法、去零、反转各线性扫一遍。
- 空间复杂度 $O(\max(|a|,|b|))$：存储两个输入串与结果串。
- 最大数据位数 $10086$，实际耗时在微秒量级。

### 验证状态

- 标程 `g++ -O2 -std=c++17` 编译通过；题面未附样例输入输出，改用手算用例核对：`123456789 987654321` 输出 `-864197532`，`1000000 1` 输出 `999999`，与竖式手算一致。
- **对拍**：以 Python 内置大整数为基准，随机 $300$ 组（含超长随机数）+ $6$ 组手选边界（`5 5`、`10 9`、`100000000000 1`、`0 0`、`000123 000023`、`1000 1000`），共 $306$ 组与标程输出全部一致（`all 306 cases match`）。
- 边界自查：`5 5` 输出 `0` 且无负号，验证了"零不带负号"；`000123 000023` 输出 `100`，验证了 trim 与去前导零；`1000 1000` 输出 `0`，验证了结果为全零时保留一位。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

string a,b;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b;
	//去掉前导零，方便比较
	auto trim=[](string&s){
		size_t p=s.find_first_not_of('0');
		if(p==string::npos)
			s="0";
		else
			s=s.substr(p);
	};
	trim(a);
	trim(b);

	bool neg=false;
	if(a.size()<b.size()||(a.size()==b.size()&&a<b))
	{
		swap(a,b);
		neg=true;
	}

	//a>=b，逐位借位
	string res;
	int borrow=0;
	for(int i=(int)a.size()-1,j=(int)b.size()-1;i>=0;--i,--j)
	{
		int x=a[i]-'0'-borrow;
		int y=j>=0?b[j]-'0':0;
		if(x<y)
		{
			x+=10;
			borrow=1;
		}
		else
			borrow=0;
		res.push_back(char('0'+x-y));
	}
	while(res.size()>1&&res.back()=='0')
		res.pop_back();
	reverse(res.begin(),res.end());

	if(neg&&res!="0")
		cout<<'-';
	cout<<res<<'\n';
	return 0;
}
```

### 代码说明

- 用 `string` 存数，`trim` 用 lambda 写成，逻辑只有"找第一个非零"这一句。
- 比较写成 `a.size()<b.size()||(a.size()==b.size()&&a<b)`，**先比长度再比字典序**，这是字符串比大小的唯一正确写法。
- `j>=0?b[j]-'0':0` 处理两个数位数不等的情况（短的高位补零）。
- 结果 `res` 是**低位在前**压入的，所以去零用 `res.back()`（对应数值高位），去零后再 `reverse`。
- `while(res.size()>1&&res.back()=='0')` 保证结果为 $0$ 时保留 `"0"` 而不是空串。
- 输出负号的条件是 `neg&&res!="0"`，避免输出 `-0`。
- 换行用 `'\n'`。

---

*高精度减法的三个坑，都藏在"字符串不是数"这件事里：字典序不等于数值序（除非等长且无前导零）、低位在前的高精度表示不能直接去前导零、$0$ 不能带负号。把 trim 放在比较之前、把去零放在反转之前，两个顺序问题就都解决了。*
