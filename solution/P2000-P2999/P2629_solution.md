# P2629 好消息，坏消息 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 条消息（$n\le10^6$），第 $i$ 条好坏度 $A_i\in[-1000,1000]$。老板心情初始 $0$，每通报一条就加上它的好坏度，**一旦心情 $<0$ 立刻炒鱿鱼**。可以任选 $k\in[1,n]$，按 $k,k+1,\dots,n,1,\dots,k-1$ 的**循环顺序**通报。问有多少个 $k$ 能让老板全程不发怒（所有前缀心情 $\ge0$）。

**第一步：暴力先写出来，看清瓶颈。** 对每个 $k$，模拟一遍循环序列、累加心情、检查是否中途 $<0$。单次 $O(n)$，$n$ 个 $k$ 就是 $O(n^2)=10^{12}$，$n=10^6$ 时绝对超时。瓶颈在于：**每个旋转都从头累加一遍前缀和**，而这些前缀和之间高度重叠，应该复用。

**第二步：前缀和 + 倍长，把"循环"拉直。** 循环序列不好处理，经典技巧是**把数组复制一份接在后面**（倍长）：$B=A_1..A_nA_1..A_n$，长度 $2n$。这样"从 $k$ 开始的旋转"就是 $B$ 上一段**长度为 $n$ 的连续窗口** $B_k..B_{k+n-1}$（$1$-based）。

设 $B$ 的前缀和 $P_0=0,\ P_i=\sum_{t\le i}B_t$。旋转 $k$ 的第 $j$ 条通报后的心情，就是这段窗口的前缀和：
$$\text{mood}_j=P_{k+j-1}-P_{k-1}\quad(j=1..n).$$
（我用 $0$-based 重写更清爽，见下。）全程不发怒 $\iff$ 所有 $\text{mood}_j\ge0$ $\iff$
$$\min_{i=k}^{k+n-1}P_i\ \ge\ P_{k-1}.$$

**这一步是本题的思维跳跃**：原本"对每个 $k$ 扫一遍 $n$ 条消息"的 $O(n^2)$，变成了"对每个 $k$ 求一段定长窗口的 $P$ 最小值，再和窗口左端前一个 $P$ 比较"。而**定长滑动窗口最小值**正是单调队列的拿手好戏，$O(n)$ 搞定。

**第三步：换成 $0$-based，把下标钉死。** 令 $A[0..n-1]$，$B[i]=A[i\bmod n]$，$P[0]=0,\ P[i]=P[i-1]+B[i-1]$。旋转起点 $k\in[0,n-1]$（对应题面 $k+1$）的窗口是 $B[k..k+n-1]$，其前缀和为 $P[k+j]-P[k]$（$j=1..n$）。条件：
$$\min_{i=k+1}^{k+n}P[i]\ \ge\ P[k].$$
即：对每个 $k$，看 $P$ 在窗口 $[k+1,k+n]$（恰好 $n$ 个元素）的最小值是否 $\ge P[k]$。

**第四步：单调队列滑窗口。** 让窗口右端点 $i$ 从 $1$ 走到 $2n-1$，窗口就是 $[i-n+1,\,i]$，对应 $k=i-n$。维护一个**下标单调队列**：队首到队尾的 $P$ 值严格递增，队首即窗口最小值。每步：

1. 把 $i$ 入队前，从队尾弹掉所有 $P[\text{队尾}]\ge P[i]$ 的下标（它们被 $i$ "支配"：更晚出窗、值还不更小）；
2. $i$ 入队；
3. 从队首弹掉所有下标 $<i-n+1$ 的（已出窗）；
4. 当 $i\ge n$（即 $k=i-n\ge0$）时，若 $P[\text{队首}]\ge P[i-n]$，答案 $+1$。

每个下标至多入队一次、出队一次，总 $O(n)$。

**第五步：一个白送的性质——总和为负直接全灭。** 设 $S=\sum A_i=P[n]$。注意窗口右端 $P[k+n]=P[k]+S$（窗口里恰好 $n$ 个 $B$ 元素，其和就是 $S$）。若 $S<0$，则 $P[k+n]<P[k]$，而 $k+n$ 在窗口 $[k+1,k+n]$ 内，故 $\min<P[k]$，**每个 $k$ 都失败**，答案 $0$。这不需要特判——单调队列的条件自动把它判成 $0$。我特意用随机大数据（$S$ 多半为负）验证输出 $0$，又用全 $1$ 数据（$S=n>0$）验证输出 $n$。

**第六步：值域与内存。** $|P_i|\le i\cdot1000\le2n\cdot1000=2\times10^9$，逼近 `int` 上限 $2.147\times10^9$，用 `long long` 稳妥。数组：$P$ 长 $2n+1$ 的 `i64`（约 16 MB）、队列长 $2n$ 的 `int`（约 8 MB）、$A$ 长 $n$ 的 `int`（约 4 MB），合计约 28 MB，在限制内。

**手造数据核对**（题面样例解释给了可行顺序，我反推出数组）：样例说 $k=2,3$ 可行、对应好坏度 $5\to1\to2\to(-3)$ 与 $1\to2\to(-3)\to5$，反推 $A=[-3,5,1,2]$（$n=4$）。手算：$k=1$ 首条 $-3<0$ 灭；$k=2$：$5,6,8,5$ 全 $\ge0$ ✓；$k=3$：$1,3,0,5$ 全 $\ge0$ ✓；$k=4$：$2,-1<0$ 灭。答案 $2$，程序输出 $2$。另造 $A=[-1,2]$：$k=1$ 灭、$k=2$（$2,1$）✓，答案 $1$；$A=[0,0]$ 答案 $2$；$A=[-5]$ 答案 $0$。

## 二、思维链：完整证明

### 记号与状态定义

- $A[0..n-1]$，$A_i\in[-1000,1000]$。倍长 $B[i]=A[i\bmod n]$（$i=0..2n-1$）。
- 前缀和 $P[0]=0$，$P[i]=\sum_{t=0}^{i-1}B[t]$（$i=1..2n$），即 $P[i]=P[i-1]+A[(i-1)\bmod n]$。
- 旋转起点 $k\in[0,n-1]$（题面 $k+1$）。其通报序列为 $B[k],B[k+1],\dots,B[k+n-1]$。
- 总和 $S=\sum_{i=0}^{n-1}A_i=P[n]$。
- 答案 $=$ 满足"旋转 $k$ 的所有前缀心情 $\ge0$"的 $k$ 的个数。

---

### 引理 1（旋转前缀心情 $=$ 倍长前缀和之差）

旋转 $k$ 通报前 $j$ 条（$1\le j\le n$）后的心情为 $P[k+j]-P[k]$。

*证明*：心情初始 $0$，前 $j$ 条是 $B[k],\dots,B[k+j-1]$，故心情 $=\sum_{t=0}^{j-1}B[k+t]$。由前缀和定义 $P[k+j]=\sum_{t=0}^{k+j-1}B[t]$、$P[k]=\sum_{t=0}^{k-1}B[t]$，相减（ telescoping）得 $P[k+j]-P[k]=\sum_{t=k}^{k+j-1}B[t]=\sum_{t=0}^{j-1}B[k+t]$。证毕。

**合法性**：$k\le n-1,\ j\le n\Rightarrow k+j\le2n-1<2n$，故 $P[k+j]$ 在已算范围内；$B[k..k+n-1]$ 恰好是 $A$ 的一个循环移位（$k+t$ 对 $n$ 取模遍历所有下标各一次），与题面"$k..n,1..k-1$"一致。

---

### 引理 2（不发怒 $\iff$ 窗口最小值 $\ge P[k]$）

旋转 $k$ 合法 $\iff\displaystyle\min_{i=k+1}^{k+n}P[i]\ \ge\ P[k]$。

*证明*：由引理 1，合法 $\iff$ 对所有 $j\in[1,n]$，$P[k+j]-P[k]\ge0$ $\iff$ 对所有 $j$，$P[k+j]\ge P[k]$ $\iff\min_{j\in[1,n]}P[k+j]\ge P[k]$。而 $\{k+j:j\in[1,n]\}=\{k+1,\dots,k+n\}$，即窗口 $[k+1,k+n]$。证毕。

**等价视角**：条件也等价于"$P[k]$ 是 $P[k..k+n]$ 的最小值"（把 $P[k]$ 自己并入窗口）。这连接了经典"环形加油站"问题，但本题要**计数所有**合法起点，故用滑动窗口最小值逐个判定。

---

### 引理 3（窗口与右端点的对应，覆盖每个 $k$ 恰一次）

令右端点 $i=k+n$，则窗口 $[k+1,k+n]=[i-n+1,i]$，$k=i-n$。当 $i$ 遍历 $[n,2n-1]$ 时，$k$ 遍历 $[0,n-1]$ 各一次。

*证明*：$k\in[0,n-1]\Rightarrow i=k+n\in[n,2n-1]$，是一一对应（$i\mapsto i-n$ 为双射）。窗口左端 $i-n+1=k+1$、右端 $i=k+n$，恰 $n$ 个元素，与引理 2 的窗口一致。代码循环 $i=1..2n-1$，仅在 $i\ge n$ 时判定，故判定的 $i$ 恰为 $[n,2n-1]$，覆盖每个 $k$ 一次、不重不漏。证毕。

---

### 引理 4（单调队列的支配关系：弹队尾安全）

若下标 $j<i$ 且 $P[j]\ge P[i]$，则在任意同时包含 $j,i$ 的窗口里，$j$ 都不可能是"唯一必需的最小值候选"，可以永久丢弃 $j$。

*证明*：窗口是连续区间 $[l,r]$。若 $j,i$ 都在窗口内，则 $l\le j<i\le r$。因 $P[i]\le P[j]$，$i$ 是比 $j$ 更优（或相等）的最小值候选。又窗口右端 $r$ 随时间递增、左端 $l=r-n+1$ 也递增，$i>j$ 意味着 $i$ 比 $j$ **更晚**被左端淘汰（$i$ 出窗需 $l>i$，$j$ 出窗需 $l>j$，后者更早）。故只要 $j$ 还在窗内，$i$ 必也在窗内且 $P[i]\le P[j]$，$j$ 永远轮不到当最小值。丢弃 $j$ 不影响任何未来窗口的最小值。证毕。

**推论**：入队 $i$ 前弹掉所有 $P[\text{队尾}]\ge P[i]$ 的下标后，队列里 $P$ 值**严格递增**（队尾 $<P[i]$ 才保留），且下标递增。

---

### 引理 5（队首即窗口最小值）

处理完右端点 $i$（入队 $i$、弹掉出窗下标）后，若 $i\ge n$，则 $P[\text{队首}]=\min_{t\in[i-n+1,i]}P[t]$。

*证明*：设窗口 $W=[i-n+1,i]$，真实最小值在某个下标 $m\in W$ 取到。

**(a) 队列下标都在 $W$ 内**：入队只加 $\le i$ 的下标；步骤 3 弹掉所有 $<i-n+1$ 的下标，故剩余下标 $\in[i-n+1,i]=W$。

**(b) 队列 $P$ 严格递增**（引理 4 推论），故队首是队列中 $P$ 最小者。

**(c) 真实最小值 $P[m]$ 必被队首取到**：反证，设 $P[\text{队首}]>P[m]$。$m$ 要么在队列里、要么被弹过。
- 若 $m$ 在队列里：由 (b) 队首 $P$ 最小，$P[\text{队首}]\le P[m]$，与假设矛盾。
- 若 $m$ 被从**队尾**弹过：由引理 4，存在 $m'>m$、$P[m']\le P[m]$ 且 $m'$ 当时入队。$m'$ 现在要么在队列、要么又被更后的 $m''$ 支配……沿这条链最终有个下标 $m^*\ge m$ 留在队列里且 $P[m^*]\le P[m]$（链有限，因下标递增 $\le i$）。$m^*\in W$（由 (a)），故 $P[\text{队首}]\le P[m^*]\le P[m]$，矛盾。
- 若 $m$ 被从**队首**弹过：那是在某步 $i'<i$ 时因 $m<i'-n+1$ 出窗。但 $m\in W$ 意味 $m\ge i-n+1>i'-n+1$（$i'<i$），即 $m$ 在 $i'$ 步尚未出窗，不会被弹，矛盾。

三种情形都矛盾，故 $P[\text{队首}]\le P[m]$；又队首 $\in W$ 故 $P[\text{队首}]\ge P[m]$。夹逼得 $P[\text{队首}]=P[m]=\min_W P$。证毕。

---

### 引理 6（判定式与答案）

当 $i\ge n$ 时，`P[队首]>=P[i-n]` 成立 $\iff$ 旋转 $k=i-n$ 合法；答案累加即合法 $k$ 的个数。

*证明*：由引理 5，$P[\text{队首}]=\min_{t\in[i-n+1,i]}P[t]=\min_{t\in[k+1,k+n]}P[t]$（引理 3）。由引理 2，旋转 $k$ 合法 $\iff$ 该最小值 $\ge P[k]=P[i-n]$。故判定式正确。引理 3 保证每个 $k$ 恰判定一次，累加即个数。证毕。

---

### 引理 7（总和为负 $\Rightarrow$ 答案 $0$，无需特判）

若 $S=P[n]<0$，则对所有 $k$，$\min_{i\in[k+1,k+n]}P[i]<P[k]$，答案 $0$。

*证明*：窗口含 $n$ 个连续 $B$ 元素 $B[k..k+n-1]$，其和 $=\sum_{t=0}^{n-1}A[t]=S$（一个完整循环）。故 $P[k+n]-P[k]=S$，即 $P[k+n]=P[k]+S<P[k]$（$S<0$）。而 $k+n\in[k+1,k+n]$，所以 $\min_{[k+1,k+n]}P\le P[k+n]<P[k]$，引理 2 条件对每个 $k$ 都失败。单调队列判定自动给出 $0$，不需额外分支。证毕。

---

### 引理 8（复杂度与值域）

时间 $O(n)$，空间 $O(n)$；$|P[i]|\le2\times10^9$，用 `long long` 安全。

*证明*：前缀和 $2n$ 次加法 $O(n)$。队列循环 $i=1..2n-1$，每个下标入队一次；弹队尾/队首各至多一次（弹出后不再回来），故总弹出 $\le2n$，循环 $O(n)$。合计 $O(n)$。

值域：$|P[i]|=|\sum_{t<i}B[t]|\le i\cdot\max|A|\le2n\cdot1000=2\times10^9$。`int` 上限 $2.147\times10^9$ 虽勉强够，但比较与差值接近边界，用 `i64`（$\pm9.2\times10^{18}$）绝对安全。空间：$P$ 为 $2n+1$ 个 `i64`（$\approx16$ MB）、队列 $2n$ 个 `int`（$\approx8$ MB）、$A$ 为 $n$ 个 `int`（$\approx4$ MB），$O(n)$，约 28 MB。证毕。

---

### 定理

程序输出合法旋转起点 $k$ 的个数，时间 $O(n)$、空间 $O(n)$。

*证明*：引理 1 把循环心情写成倍长前缀和之差；引理 2 把"全程 $\ge0$"化为窗口最小值判定；引理 3 保证窗口与 $k$ 一一对应；引理 4、5 保证单调队列队首恰为窗口最小值；引理 6 把判定式与答案计数对应；引理 7 说明 $S<0$ 自动全灭；引理 8 给出复杂度与数值安全。证毕。

## 三、模式总结（按实际思考顺序）

- **consider easier version** — 先写"每个 $k$ 模拟一遍"的 $O(n^2)$ 暴力，定位瓶颈是重复累加前缀和。
- **classic problem solution** — 倍长数组把循环移位拉直成定长连续窗口；前缀和之差表示窗口内前缀心情。
- **reduce to easier problem** — "所有前缀 $\ge0$" $\iff\min_{[k+1,k+n]}P\ge P[k]$，把计数问题化为滑动窗口最小值。
- **classic problem solution** — 单调队列维护定长窗口最小值：弹队尾（支配关系）、弹队首（出窗），队首即最小，$O(n)$。
- **explore its property** — 窗口右端 $i=k+n$、左端 $i-n+1$，$i\in[n,2n-1]$ 与 $k\in[0,n-1]$ 一一对应。
- **explore its property** — 总和 $S<0\Rightarrow P[k+n]<P[k]\Rightarrow$ 全灭，答案 $0$，无需特判。
- **discuss by category** — $|P|\le2\times10^9$ 用 `long long`；$P$/队列/$A$ 三数组约 28 MB。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 消息数（$\le10^6$） | `int`，读入 | 旋转起点 $k\in[0,n-1]$ |
| `a[i]` | 第 $i$ 条好坏度（$0$-based） | `int[mxn]`，读入 | $[-1000,1000]$ |
| `P[i]` | 倍长数组前 $i$ 项前缀和 | `i64[mxn*2]`，`P[0]=0` | $P[i]=P[i-1]+a[(i-1)\%n]$ |
| `dq[]` | 单调队列，存 $P$ 的下标 | `int[mxn*2]` | 队首→队尾 $P$ 严格递增 |
| `head,tail` | 队列区间 $[\text{head},\text{tail})$ | `int`，初值 $0$ | 队首 `dq[head]`，队尾 `dq[tail-1]` |
| `i` | 窗口右端点 | `int`，$1..2n-1$ | 窗口 $[i-n+1,i]$，$k=i-n$ |
| `ans` | 合法 $k$ 的个数 | `int`，初值 $0$ | $i\ge n$ 且 $P[\text{队首}]\ge P[i-n]$ 时 $+1$ |
| `mxn` | $10^6+5$ | `constexpr int{1000005}` | $P$/队列开 $2$ 倍 |

### 算法步骤

1. I/O 加速三行；读 `n` 与 `a[0..n-1]`。
2. 倍长前缀和：`P[0]=0`；`for i=1..2n: P[i]=P[i-1]+a[(i-1)%n]`（引理 1）。
3. `head=tail=0,ans=0`；`for i=1..2n-1`：
   1. `while(head<tail && P[dq[tail-1]]>=P[i]) --tail;`（弹队尾，引理 4）；
   2. `dq[tail++]=i;`（入队）；
   3. `while(head<tail && dq[head]<i-n+1) ++head;`（弹出窗，引理 5a）；
   4. `if(i>=n && P[dq[head]]>=P[i-n]) ++ans;`（判定，引理 6）。
4. 输出 `ans`。

### 复杂度

- 时间：$O(n)$，$n=10^6$ 实测约 228 ms。
- 空间：$O(n)$，约 28 MB（$P$ 16 MB + 队列 8 MB + $A$ 4 MB）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例反推 $A=[-3,5,1,2]$ 输出 $2$，与样例解释（$k=2,3$ 可行）一致；手造 $[-1,2]\to1$、$[0,0]\to2$、$[-5]\to0$ 均对；与"枚举每个旋转逐条模拟"的独立暴力**端到端对拍 5000 组**（$n\le9$，$A_i\in[-4,4]$，含全负/全零/正负交替）$0$ mismatch；$n=10^6$ 随机数据输出 $0$（$S<0$）、全 $1$ 数据输出 $1000000$（引理 7 与全正情形），运行 228 ms。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2629 好消息，坏消息
// 倍长前缀和 P，旋转 k 合法 <=> min P[k+1..k+n] >= P[k]
// 单调队列滑动窗口最小值，右端 i=k+n，窗口 [i-n+1,i]，O(n)
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1000005};

int n,a[mxn],dq[mxn*2];
i64 P[mxn*2];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	P[0]=0;	// 倍长前缀和：P[i]=a 重复两遍后前 i 项之和
	for(int i=1;i<=2*n;++i)
		P[i]=P[i-1]+a[(i-1)%n];
	int head=0,tail=0,ans=0;	// dq[head..tail) 存下标，对应 P 值单调递增
	for(int i=1;i<2*n;++i)
	{
		while(head<tail&&P[dq[tail-1]]>=P[i])--tail;	// 弹队尾：被 i 支配
		dq[tail++]=i;
		while(head<tail&&dq[head]<i-n+1)++head;	// 弹队首：出窗 [i-n+1,i]
		if(i>=n&&P[dq[head]]>=P[i-n])	// 旋转起点 k=i-n
			++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **倍长前缀和**：`P[i]=P[i-1]+a[(i-1)%n]`，把循环移位变成 $B$ 上的连续窗口，避免对每个 $k$ 重新累加（引理 1）。
- **窗口与判定**：右端 `i` 对应 `k=i-n`，窗口 `[i-n+1,i]`；`i>=n` 才判定，恰好覆盖 `k=0..n-1` 各一次（引理 3、6）。
- **弹队尾用 `>=`**：$P$ 相等时弹掉较早下标、保留较晚的（更晚出窗），队列 $P$ 严格递增，队首即最小（引理 4、5）。
- **`head<tail` 守卫**：每次弹队首/队尾前都判空，避免越界；入队后队列非空，`dq[head]` 合法。
- **`long long` 的 `P`**：$|P|\le2\times10^9$ 逼近 `int` 上限，用 `i64` 杜绝溢出（引理 8）。
- **$S<0$ 自动全灭**：窗口含 $P[k+n]=P[k]+S<P[k]$，判定恒失败，无需特判（引理 7）。
- **数组开 $2$ 倍**：`P`、`dq` 都用到下标 $\approx2n$，故 `mxn*2`；`a` 只需 `mxn`。
