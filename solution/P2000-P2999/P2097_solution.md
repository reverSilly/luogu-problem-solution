# P2097 资料分发 1 — 题解

## 一、解题过程：人类思考叙事

题意翻译：$n$ 台电脑，点 $1\sim n$；$m$ 条双向数据线 $(p,q)$。数据可以沿数据线传播。你手里有一份数据，问**最少**要手动输入几台电脑，才能让所有电脑都拿到数据。

第一反应：把电脑看成点、数据线看成边，得到一张无向图。数据能从一台电脑传到与它连通的任何电脑——这正是"连通块"的定义。

于是问题变成：**无向图的连通块个数是多少**。

再想想下界：一个连通块里的电脑只能从这个连通块内部获得数据（数据出不去，也进不来，除非手动输入）。所以每个连通块至少得手动输入一台电脑。

上界也很直接：每个连通块随便挑一台手动输入，数据就会沿着连通块内的路径扩散到整个连通块。

所以答案 = **连通块个数**。上下界一夹，结论就钉死了。

接下来是"怎么数连通块"。

方法一：BFS/DFS 遍历图，没被访问过的点就 ++ans。$n\le 10^5$，$m\le 2\times 10^5$，邻接表跑一遍是 $O(n+m)$，完全够用。

方法二：并查集。这个题几乎是并查集的标准模板题——一条边的作用就是把两个集合合并，而答案就是"从 $n$ 个集合出发，被合并掉了多少次"。具体做法：初始 `ans=n`，每读入一条边 $(u,v)$，若 `getrt(u) != getrt(v)`，说明这两个集合还没连上，把它们合并，`ans--`。最后输出 `ans`。

方法二更优的地方在于：**边可以边读边处理，不需要建图、不需要邻接表**，空间只要一个 $fa$ 数组。而且题目明确说"数据可能存在重边自环"，并查集天然处理这两种情况：重边第二次合并时两个根已经相同，`ans` 不变；自环的两个端点本来就同根，同样不变。而 BFS 也不怕重边自环，所以两条路都能过。

我选并查集。理由是本题的"合并"语义和并查集完全同构，读完边就有答案，连图都不用建。

边界情况：
- $n$ 可以是 0。此时没有任何电脑，答案是 0，`ans=n=0` 自然正确。
- $m$ 可以是 0。此时每个点自成一个连通块，答案是 $n$。
- 重边、自环如上所述。

用 `getrt` 做路径压缩，递归实现即可（并查集树高经过路径压缩后极小，不会爆栈）。

数据范围：$n\le 10^5$，$m\le 2\times 10^5$。时间 $O((n+m)\alpha(n))$，空间 $O(n)$。

样例：4 个点 5 条边（`1 2 / 1 3 / 2 3 / 2 1 / 3 4`），所有点连成一个块，答案 1，与官方一致。

## 二、思维链：完整证明

**记号约定**：图 $G=(V,E)$，$V=\{1,\dots,n\}$，$E$ 是 $m$ 条无向边（可能有重边、自环）；$C_1,\dots,C_t$ 是 $G$ 的连通块。

**引理 1**：任何可行的手动输入方案，至少要向每个连通块输入一次。

*证明*：设某个连通块 $C$ 没有被手动输入过。那么最初 $C$ 中没有任何电脑持有数据；而数据只能沿数据线传播，数据线是双向的，其两端必然在同一个连通块内，所以数据无法从 $C$ 之外传入 $C$；同时 $C$ 内部也没有初始的数据源可用归纳法说明：对 $C$ 中的电脑按"距离块内某个源点的路径长度"排序，若没有源点则全无数据。综上 $C$ 中永远拿不到数据，与"所有电脑都得到数据"矛盾。故每个连通块至少一次。证毕。

**引理 2**：向每个连通块各输入一台电脑，一定能让所有电脑得到数据。

*证明*：取连通块 $C$ 中任意一台电脑 $s$ 作为输入点。对 $C$ 中任意电脑 $v$，由连通性，存在一条从 $s$ 到 $v$ 的路径 $s=p_0,p_1,\dots,p_k=v$。数据在 $p_0$ 处被输入，由于数据线双向，它可以沿该路径依次传到 $p_1,\dots,p_k=v$。因此 $v$ 拿到了数据。证毕。

**引理 3**：算法维护的 `fa` 划分（`fa` 的每个等价类）在读完前 $k$ 条边后，恰好等于图 $G_k=(V,\{e_1,\dots,e_k\})$ 的连通块划分。

*证明*：归纳法。

- $k=0$：图无边，每个点自成一个连通块，等价类也恰为 $n$ 个单点，结论成立。
- 归纳步：设读完前 $k-1$ 条边结论成立，读入第 $k$ 条边 $e_k=(u,v)$。
  - 若 $u,v$ 在同一等价类（等价地，在 $G_{k-1}$ 的同一连通块中），加入 $e_k$ 不会合并任何连通块，算法也不做合并，等价类不变，结论成立。
  - 若 $u,v$ 在不同等价类，加入 $e_k$ 恰好把这两个连通块连成一个连通块（$G_k$ 的连通块恰是 $G_{k-1}$ 中含 $u$ 的块与含 $v$ 的块之并，其余不变），算法执行 `fa[a]=b` 把两个类合并为一个，等价类划分与 $G_k$ 的连通块划分一致。

故归纳成立。证毕。

**引理 4**：算法输出的 `ans` 等于 $G$ 的连通块个数。

*证明*：初始有 $n$ 个等价类，每个等价类对应一个连通块（引理 3）。每处理一条边，若发生合并，则等价类数减一，且连通块数也恰好减一（引理 3 的归纳步中"两个连通块合并为一个"）；若不发生合并，两者都不变。因此在整个过程中"等价类数 = 连通块数"始终成立。而算法里 `ans` 初值为 $n$，每次合并 `--ans`，所以 `ans` 始终等于当前的等价类数，即最终的连通块个数 $t$。证毕。

**定理**：算法输出的 `ans` 就是最少需要手动输入的电脑数量。

*证明*：由引理 4，`ans` 等于连通块个数 $t$；由引理 1，任何方案至少输入 $t$ 台；由引理 2，输入 $t$ 台总是可行。故最优值恰为 $t=\texttt{ans}$。证毕。

## 三、模式总结（按实际思考顺序）

1. **建模** — 电脑=点，双向数据线=无向图；数据沿边扩散 ⇒ 连通块内互相可达。
2. **上下界夹逼** — 连通块外的数据进不来 ⇒ 每个块至少输入一次；块内沿路径扩散 ⇒ 每块一次足够 ⇒ 答案=连通块个数。
3. **数连通块** — 并查集：一条边=一次"合并两个集合"，答案 = 初始集合数 − 合并次数。
4. **顺手处理重边自环** — 第二次合并时两根已相同，`ans` 不变，天然免疫。
5. **不建图** — 边读进边处理，只需一个 `fa` 数组，空间 $O(n)$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 电脑数（点数） | `int`，$[0,10^5]$ |
| $m$ | 数据线数（边数） | `int`，$[0,2\times10^5]$ |
| `fa[i]` | 并查集父指针，$i$ 的代表元为 `getrt(i)` | `int[]`，下标 $0..n-1$ |
| `getrt(x)` | 查找 $x$ 所在集合的代表元（带路径压缩） | `int` |
| `ans` | 当前等价类个数，初始 $n$，每次成功合并减一 | `int`，$[0,n]$ |

### 算法步骤

1. 读入 $n,m$。
2. 初始化 `fa[i]=i`（$i=0..n-1$），`ans=n`。
3. 依次读入 $m$ 条边 $(u,v)$，转成 0-based（`--u; --v;`）：
   - `a=getrt(u)`，`b=getrt(v)`；
   - 若 `a!=b`：执行 `fa[a]=b`（把 $v$ 所在集合挂到 $u$ 所在集合下），`ans--`；
   - 否则什么都不做（重边或自环）。
4. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(n+m\alpha(n))$。初始化 $O(n)$，每条边两次 `getrt`，路径压缩后均摊 $O(\alpha(n))$。
- 空间复杂度：$O(n)$，一个 `fa` 数组，不建邻接表。

### 验证状态

- 标程 `P2097.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `4 5 / 1 2 / 1 3 / 2 3 / 2 1 / 3 4` 输出 `1`，与官方一致。
- 编写暴力 `P2097_brute.cpp`（邻接表 + BFS 统计连通块）与对拍脚本 `P2097_check.py`，在 $n\le 12$、$m\le 20$ 且**含重边与自环**的随机数据上对拍 **2000 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2097 资料分发 1
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n,m;
int fa[mxn];

int getrt(int x)
{
	if(fa[x]==x)
		return x;
	return fa[x]=getrt(fa[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		fa[i]=i;
	int ans=n;
	for(int i=0,u,v;i<m;++i)
	{
		cin>>u>>v;--u;--v;
		int a=getrt(u),b=getrt(v);
		if(a!=b)
		{
			fa[a]=b;
			--ans;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `ans` 初值 $n$，每成功合并一次减一，最后的 `ans` 就是连通块个数。
- 重边：第二条同端点的边读入时 `getrt(u)==getrt(v)`，直接跳过，`ans` 不变。
- 自环：$u=v$ 时两个 `getrt` 必然相等，同样跳过。
- $n=0$ 时 `fa` 初始化循环不执行、`ans=0`、也没有合法边，输出 0，正确。
- 并查集数组用 0-based，读入时 `--u; --v;` 立刻转换。
- `getrt` 用递归 + 路径压缩，合并方向固定为 `fa[a]=b`；由于有路径压缩，实际树高极小，递归不会爆栈。
