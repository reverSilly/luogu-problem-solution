# P2904 [USACO08MAR] River Crossing S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** FJ 和 $N$ 头牛（$1\le N\le 2500$）在近岸，要全部到对岸。只有一只木筏，**FJ 必须始终在筏上**（牛不会划船）。筏上没有牛时划一趟要 $M$ 分钟（$1\le M\le 1000$）；载 $k$ 头牛时划一趟要 $M+\sum_{i=1}^{k}M_i$ 分钟，其中 $M_i$（$1\le M_i\le 1000$）是"从 $i-1$ 头加到 $i$ 头"的增量。记 $pre[k]=\sum_{i=1}^k M_i$，则载 $k$ 头单程耗时 $M+pre[k]$。FJ 可以分批送牛：送一批过去、划回来、再送下一批……**回程也要计时**（哪怕空筏）。求把所有牛送到对岸的最短总时间。木筏容量没有上限。

**第一步：两个朴素贪心，都被样例打掉。**

- "一次全带走"：不用回程，耗时 $M+pre[N]$。Hint 里 $N=5,M=10,M_i=3,4,6,100,1$：$pre[5]=114$，一次带完要 $124$ 分钟。但样例方案"带 $3$ 头（$23$）→ 空返（$10$）→ 带 $2$ 头（$17$）"只要 $50$。**增量 $M_i$ 可以暴涨**（第 $4$ 头起每头 $+100$），多带未必划算。
- "一次带一头"：$N$ 趟去程 $+N-1$ 趟回程。同一组数据：$13\times5+10\times4=105>50$。回程太贵，少带也未必划算。

两个方向的贪心都有反例，说明"每批带几头"是一个需要**全局权衡的划分问题**——这正是 DP 的气味。

**第二步：把"方案"规范化，砍掉无用动作。** 一个方案是若干趟"去 / 回 / 去 / 回……"。先问：最优方案里会不会有"空筏去程"或"带牛回程"？

- 空筏去程毫无意义：它后面必跟一趟回程（否则牛早已全在对岸，这趟直接删掉），两趟一起删，牛的位置不变、FJ 位置不变，时间净省 $\ge 2M>0$。
- 带牛回程更是亏：牛被带回近岸后**还得再送过去一次**。不如当初就把它留在对岸，同时从它后来那趟去程里删掉它——回程变空（省 $pre[c]>0$），去程变轻（$M_i\ge1$，时间不增反减）。

所以**存在最优方案：每趟去程至少带 $1$ 头牛，每趟回程都是空筏，最后一趟是去程（之后不必回来）**。这一步是交换论证，第二部分引理 1 严格证。

**第三步：方案塌缩成"整数拆分"。** 规范化后，方案完全由各批牛数 $k_1,k_2,\dots,k_T$（$k_t\ge1$，$\sum k_t=N$）决定：

$$\text{总时间}=\sum_{t=1}^{T}\bigl(M+pre[k_t]\bigr)+(T-1)\cdot M.$$

批次的**顺序无关紧要**（代价只跟每批大小有关），于是问题变成：把 $N$ 拆成若干正整数之和，最小化上式。这是经典的**划分型 DP**（和完全背包同构：每种"批大小 $k$"是一件费用 $M+pre[k]+M$、体积 $k$ 的物品，恰好装满体积 $N$）。

**第四步：状态设计的小技巧——把最后一次回程也算进去。** 直接设 $f[i]$="送 $i$ 头过河且 FJ 在对岸"会在转移时纠结"这是不是最后一批"。换个定义：$g[i]$="送 $i$ 头过河且 FJ **回到近岸**（每批之后都空返，包括最后一批）"的最短时间。这样每批的代价统一是 $M+pre[k]+M$，转移干净：

$$g[0]=0,\qquad g[i]=\min_{1\le k\le i}\bigl(g[i-k]+pre[k]+2M\bigr).$$

真实答案里最后一批之后**不需要**空返，而任何" ending 在对岸"的方案与"ending 在近岸"的方案只差一趟时间为 $M$ 的空返（一一对应），所以

$$\text{答案}=g[N]-M.$$

**第五步：范围与实现细节。** $N\le2500$，$O(N^2)$ 转移约 $3.1\times10^6$ 次，轻松。值域：$g[i]\le 2M+pre[i]\le 2.502\times10^6$（"一批带完"总是可行解），`int` 其实够，但用 `i64` 零成本保险。**陷阱**：`g[1..N]` 必须先 `fill` 成 INF——全局数组默认 $0$，而 $0$ 比任何真实代价都小，`min` 会被未初始化的 $0$ 污染。$g[0]=0$ 恰好是合法初值，保留。

**手造数据核对。** Hint 给了完整例子当第一组；另造四组打边界与"必须分批"：

第一组（Hint 原例）：`5 10 / 3 4 6 100 1`。$pre=3,7,13,113,114$。手算 $g$：$g[1]=23$，$g[2]=\min(23+13+10,\ 0+17+10)=27$，$g[3]=\min(27+23,\ 23+27,\ 33)=33$，$g[4]=\min(33+23,\ 27+27,\ 23+33,\ 133)=54$，$g[5]=\min(54+23,\ 33+27,\ 27+33,\ 23+133,\ 134)=60$。答案 $60-10=50$ ✓（对应 $3+2$ 分批：$23+10+17$）。程序输出 `50`。

第二组（$N=1$）：`1 5 / 2`。只能一趟带 $1$ 头：$5+2=7$，无回程。$g[1]=0+2+10=12$，答案 $12-5=7$ ✓。

第三组（$N=2$，增量极小）：`2 1 / 1 1`。一批带完：$1+1+1=3$；分两批：$2+1+2=5$。$g[2]=\min(g[1]+1+2,\ 0+2+2)=\min(6,4)=4$，答案 $4-1=3$ ✓——这组打掉"一律分批"的反向贪心。

第四组（必须分批，且批大小不均）：`4 10 / 1 1 100 100`。$pre=1,2,102,202$。枚举拆分：$\{4\}:212$；$\{2,2\}:12+10+12=34$；$\{3,1\}:112+10+11=133$；$\{2,1,1\}:12+10+11+10+11=54$；$\{1,1,1,1\}:11\times4+10\times3=74$。最优 $34$。程序输出 `34` ✓。

第五组（极限规模）：$N=2500,M=1000$，全部 $M_i=1000$。$pre[k]=1000k$，拆 $T$ 批代价 $2.5\times10^6+1000(2T-1)$，$T=1$ 最优，答案 $2501000$。程序输出 `2501000` ✓，瞬间跑完。

## 二、思维链：完整证明

**记号。** $pre[0]=0$，$pre[k]=\sum_{i=1}^k M_i$（$1\le k\le N$）。因 $M_i\ge1$，$pre$ 严格递增且 $pre[k]\ge k$。载 $k$ 头牛的单程时间 $c(k)=M+pre[k]$，空筏单程 $c(0)=M$。一个**方案**是交替的渡河序列：去、回、去、回……（FJ 起点在近岸，第一趟必为去程），每趟 FJ 都在筏上；方案合法当且仅当结束时所有牛在对岸。不妨设最后一趟是去程（若最后是回程，则回程前牛已全在对岸，删掉它更优）。

---

### 引理 1（规范形：去程非空、回程全空）

存在最优方案满足：(a) 每趟去程载牛数 $\ge1$；(b) 每趟回程载牛数 $=0$；(c) 最后一趟是去程。

*证明*：任取最优方案 $\Pi$，施加两类**严格改进**变换，直到不能再改。

**变换 A（删空去程）**：设某趟去程载 $0$ 头。若它是最后一趟，则此刻牛已全在对岸（方案合法），删去它，总时间减少 $M>0$，仍合法。否则它后面紧跟一趟回程，把"空去程 + 该回程"两趟一起删：这两趟对牛的位置净影响为 $0$（去程没带牛，回程带的牛……注意回程可能带牛！）。——为严谨，先做变换 B 再做变换 A：

**变换 B（清空回程）**：设某趟回程 $r$ 载了 $c\ge1$ 头牛。对每头这样的牛 $w$，它在 $r$ 之后回到近岸，而方案结束时它在对岸，故存在 $r$ 之后**最后一趟**载 $w$ 的去程 $f_w$。构造新方案 $\Pi'$：
- 每趟回程都改为空筏；
- 每趟去程 $f$ 改为只载"最后一趟载它的去程恰为 $f$"的那些牛。

核对 $\Pi'$ 合法：牛 $w$ 在 $\Pi'$ 中只在 $f_w$ 过河一次。$f_w$ 之前 $w$ 从未过河（它的唯一过河趟就是 $f_w$），故一直在近岸，$f_w$ 时上筏可行；$f_w$ 之后一直在对岸。结束时所有牛都在对岸 ✓。FJ 的航次骨架不变（每趟仍在筏上）✓。

核对代价：回程 $r$ 的时间从 $M+pre[c_r]$ 降为 $M$，省 $pre[c_r]\ge c_r\ge1$；每趟去程的载牛数只减不增（$\Pi'$ 中 $f$ 的牛集是 $\Pi$ 中 $f$ 的牛集的子集），$pre$ 单调不减 ⇒ 去程时间不增。故 $\Pi'$ 总时间**严格小于** $\Pi$（只要存在带牛回程）。

**变换 A（补做）**：对 $\Pi'$ 中载 $0$ 头的去程，它后面若跟回程，两趟一起删——此时回程已全空，删去两趟对牛位置净影响 $0$、FJ 位置复原（近→远→近），省 $M+M=2M>0$；若是最后一趟则直接删（牛已全在对岸）。反复施行直到没有空去程。

两类变换都严格减时间且保持合法，最优方案不可能还能施行它们，故最优方案必满足 (a)(b)；(c) 已在开头说明。证毕。

### 引理 2（方案 = 整数拆分，代价公式）

规范形方案与 $N$ 的**有序拆分** $(k_1,\dots,k_T)$（$k_t\ge1$，$\sum_t k_t=N$）一一对应（忽略批次顺序后为无序拆分），其总时间为
$$C(k_1,\dots,k_T)=\sum_{t=1}^{T}\bigl(M+pre[k_t]\bigr)+(T-1)\,M.$$
从而原问题等价于 $\min C$  over 所有拆分。

*证明*：规范形方案有 $T$ 趟去程（每趟 $\ge1$ 头）与 $T-1$ 趟空回程（插在相邻去程之间，最后无回程）。设第 $t$ 趟去程载 $k_t$ 头，则 $\sum k_t=N$（每头牛恰好过河一次：去程只往前送、回程不带牛）。去程耗时 $M+pre[k_t]$，回程耗时 $M$，求和即公式。反之给定拆分，按任意顺序执行"载 $k_t$ 头过去、空返（末批除外）"即得合法规范形方案。公式中批次顺序只影响求和次序，不影响值，故代价只依赖拆分的**多重集**。证毕。

**注**：两个贪心反例（第一部分）说明 $C$ 既不是"批数越少越好"也不是"批数越多越好"——$pre$ 的增量结构任意，必须 DP。

---

### 引理 3（DP 状态与转移的正确性）

定义 $g[i]$（$0\le i\le N$）为：把 $i$ 头牛送到对岸、且 FJ **回到近岸**的规范形方案（$T$ 趟去程 $+T$ 趟空回程，含末批后的空返）的最短时间；$i=0$ 时 $g[0]=0$（零趟）。则
$$g[i]=\min_{1\le k\le i}\bigl(g[i-k]+pre[k]+2M\bigr)\quad(i\ge1).$$

*证明*：对 $i$ 归纳，同时证"$g[i]$ 恰为最优值"。

$i=0$：不渡河，时间 $0$ ✓。

设 $g[0..i-1]$ 均正确。考察任一送 $i$ 头、FJ 回近岸的规范形方案，其**最后一趟去程**载 $k$ 头（$1\le k\le i$，引理 1(a)），耗时 $M+pre[k]$，随后一趟空返耗时 $M$。在这最后一去程之前，已有 $i-k$ 头牛在对岸、FJ 在近岸（刚完成上一趟空返；$k=i$ 时之前是初始状态），且之前的航次构成一个送 $i-k$ 头、FJ 回近岸的规范形方案，耗时 $\ge g[i-k]$（归纳假设）。故总时间 $\ge g[i-k]+pre[k]+2M\ge\min_k(\cdots)$，即 $g[i]\ge$ 右式。

反向：对任一 $k$，取送 $i-k$ 头、FJ 回近岸的最优方案（耗时 $g[i-k]$，归纳假设可达），追加"载 $k$ 头去程 + 空返"，得到送 $i$ 头、FJ 回近岸的合法方案，耗时 $g[i-k]+pre[k]+2M$。故 $g[i]\le$ 右式。两边夹得等式。证毕。

（这就是"最优子结构"的剪贴论证：前缀若不最优，换成更优前缀，后缀可行性不受影响——后缀只关心"近岸还剩 $k$ 头、FJ 在近岸"，与前缀内部怎么划无关。）

---

### 引理 4（答案 = $g[N]-M$）

设 $h[N]$ 为把 $N$ 头牛全送到对岸（FJ 终点任意）的最短时间，则 $h[N]=g[N]-M$。

*证明*：由引理 1(c)，最优方案最后一趟是去程，FJ 终点在对岸，共 $T$ 去 $+T-1$ 回。构造双射：
- 任一"送 $N$ 头、FJ 终在对岸"的规范形方案，末尾追加一趟空返，得"送 $N$ 头、FJ 终在近岸"的规范形方案，时间 $+M$；
- 任一"送 $N$ 头、FJ 终在近岸"的规范形方案，其最后一趟必为空返（去程后 FJ 在对岸，要回近岸只能靠回程；回程全空），删去它，得"送 $N$ 头、FJ 终在对岸"的规范形方案（牛已在对岸），时间 $-M$。

两映射互逆，故两类方案的最优值恰差 $M$：$g[N]=h[N]+M$。证毕。

---

### 引理 5（值域、INF 初始化与复杂度）

(a) 对所有 $i$，$g[i]\le 2M+pre[i]\le 2\times1000+2500\times1000=2.502\times10^6$；答案 $\le M+pre[N]\le2.501\times10^6$。`int` 足够，`i64` 更保险。
(b) 计算前必须把 $g[1..N]$ 显式置为 INF（$g[0]=0$ 保留），否则全局默认的 $0$ 会被 `min` 当成"已达成的零代价"，输出恒为 $-M$ 之类的错误值。
(c) 时间 $O(N^2)$，空间 $O(N)$。

*证明*：(a) 转移中取 $k=i$ 得 $g[i]\le g[0]+pre[i]+2M=pre[i]+2M$；$pre[i]\le i\cdot\max M_i\le2.5\times10^6$。答案 $=g[N]-M\le pre[N]+M$。(b) `min` 的语义是"在候选中取最小"，未计算的状态若为 $0$，则任何 $g[i-k]+pre[k]+2M>0$ 都输给 $0$，DP 全面失效；INF 取 $1145141919810\gg2.5\times10^6$ 且加法不溢出 `i64`。(c) 前缀和 $O(N)$；双重循环 $\sum_{i=1}^N i=N(N+1)/2\approx3.13\times10^6$ 次转移，每次 $O(1)$；数组 $a,pre,g$ 各 $O(N)$。证毕。

### 定理

程序输出 $h[N]=\min C$（所有牛过河的最短时间），总复杂度 $O(N^2)$。

*证明*：引理 1 把搜索空间限制到规范形（不损失最优解）；引理 2 把规范形方案等价成整数拆分及其代价公式；引理 3 证明 $g$ 的递推恰好算出"含末批空返"的最优拆分值；引理 4 用双射扣掉最后一趟空返得到真实答案；引理 5 保证数值范围、初始化与复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 单程时间只依赖载牛数：$c(k)=M+pre[k]$，$pre$ 是增量前缀和；FJ 必须始终在筏上，回程也计时。
2. **consider easier version** — 试两个贪心："一次全带"被 Hint 的 $124>50$ 打掉，"一次一头"被 $105>50$ 打掉 ⇒ 批大小需要全局权衡。
3. **explore its property** — 交换论证规范化：带牛回程严格亏（牛还得再送一次）、空去程可连同回程一起删 ⇒ 最优方案 = $N$ 的整数拆分，代价 $\sum(M+pre[k_t])+(T-1)M$。
4. **classic problem solution** — 划分型 DP（完全背包同构）：$g[i]=\min_k g[i-k]+pre[k]+2M$，$O(N^2)$。
5. **reduce to easier problem** — 状态定义成"FJ 回到近岸"（每批都含空返），转移统一；答案 $g[N]-M$ 一减了之，避免"最后一批"分类讨论。
6. **discuss by category** — $N=1$ 无回程；值域 $\le2.5\times10^6$；`g[1..N]` 必须显式填 INF（全局默认 $0$ 是陷阱）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,m` | 牛数 $N$、空筏单程时间 $M$ | `int` | 读入 |
| `a[i]` | 增量 $M_{i+1}$（第 $i+1$ 头牛的增量） | `int[mxn]` | 读入，0-based |
| `pre[k]` | 载 $k$ 头比空筏多花的时间 $\sum_{i\le k}M_i$ | `i64[mxn]` | `pre[0]=0`（全局默认），`pre[i+1]=pre[i]+a[i]` |
| `g[i]` | 送 $i$ 头过河且 FJ **回到近岸**的最短时间（含末批空返） | `i64[mxn]` | `g[0]=0`；**`g[1..n]` 先 `fill` 成 `inf`** |
| `inf` | $1145141919810$ | `constexpr i64` | 远大于真实值 $\le2.5\times10^6$，加法不溢出 |
| `mxn` | $2500+5$ | `constexpr int` | 数组尺寸 |

### 算法步骤

1. I/O 加速三行；读 $N,M$；读 $N$ 个增量并递推 `pre[1..N]`。
2. `fill_n(g+1,n,inf)`，保留 `g[0]=0`。
3. 对 $i=1..N$，枚举末批大小 $k=1..i$：`g[i]=min(g[i],g[i-k]+pre[k]+2*m)`。
4. 输出 `g[n]-m`（扣掉最后一次不需要的空返）。

### 复杂度

- 时间：$O(N^2)$，$N=2500$ 时约 $3.1\times10^6$ 次转移。
- 空间：$O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Hint 原例输出 `50`；另造 $N=1$、"增量极小应一批带完"、"增量暴涨必须分批（手枚举全部拆分最优 $34$）"三组小数据与 $N=2500$ 全 $1000$ 极限数据（理论最优 $2501000$），输出 `7 / 3 / 34 / 2501000` 全部吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2904 [USACO08MAR] River Crossing S
// 最优方案：去程每批≥1头、回程必空 ⇒ 方案= N 的一个有序拆分，代价 Σ(M+pre[k])+(批数-1)*M
// g[i]=送 i 头过河且 FJ 回到近岸的最短时间（含最后一次空返）；g[i]=min g[i-k]+pre[k]+2M
// 答案 g[n]-m：扣掉最后一次不需要的空返
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2505};
constexpr i64 inf{1145141919810};

int n,m,a[mxn];
i64 pre[mxn],g[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		pre[i+1]=pre[i]+a[i];	// pre[k]=带 k 头牛比独自划多花的时间
	}
	fill_n(g+1,n,inf);	// g[0]=0；其余必须先填 INF，全局默认 0 会错
	for(int i=1;i<=n;++i)
		for(int k=1;k<=i;++k)
			g[i]=min(g[i],g[i-k]+pre[k]+2LL*m);
	cout<<g[n]-m<<'\n';
	return 0;
}
```

### 代码说明

- **状态口径**：`g[i]` 含"末批之后的空返"，所以每批统一加 `2*m`（一去一回）；最后输出减一个 `m`。若把状态定义成"FJ 在对岸"，转移就要区分是否最后一批，徒增分支。
- **`fill_n(g+1,n,inf)`**：从 `g[1]` 起填 $N$ 个，恰好保留 `g[0]=0`。这是全局数组 DP 的经典陷阱——不填的话 `min` 会选中默认的 $0$。
- **`2LL*m`**：把整条表达式提升到 `i64`，与 `g/pre` 类型一致；本题值域其实 `int` 就够（引理 5），`i64` 是零成本保险。
- `pre` 用 1-based 计数下标（`pre[k]` 对应 $k$ 头牛），读入的 `a` 是 0-based；`g` 的下标是"牛的头数"，天然从 $0$ 到 $N$，不涉及实体编号转换。
- 转移顺序 $i$ 从小到大、$k\le i$，保证用到的 `g[i-k]` 都已算好；`k=i` 的候选自动覆盖"一批带完"，无需特判 $N=1$。
