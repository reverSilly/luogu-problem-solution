# P2771 [USACO16JAN] Build Gates S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** FJ 从 $(0,0)$ 出发走 $N\le1000$ 步，每步向 N/E/S/W 之一移动一单位，走过的每一步都留下一段单位长度的围栏（同一段可能被重复走、重复建）。现在要在**已建好的**某段围栏上开门，门让该段两侧可以互相穿越。求最少开多少扇门，使得农场上**任意区域到任意区域**都可到达。

**第一步：手玩小例子，猜答案的组合意义。**

| 路径 | 围栏形状 | 答案 |
|---|---|---|
| `N` | 一段孤零零的墙 | $0$（没围出任何东西） |
| `NS` | 同上（重复建一段） | $0$ |
| `NESW` | 一个单位正方形 | $1$（围出 $1$ 块内部区域） |
| `NNNNEEEESSSSWWWW` | $4\times4$ 正方形 | $1$（内部再大也只围出 $1$ 块） |
| `NESWWNES` | 两个共边正方形 | $2$ |
| `NESWNWNES` | 两个仅共一个顶点的正方形 | $2$ |

规律呼之欲出：**答案 = 被围出来的区域块数**。注意"区域"要把**无界的外部**也算一块：正方形把平面分成"内部 + 外部"共 $2$ 块，答案 $1=2-1$；两个正方形分成 $3$ 块，答案 $2=3-1$。

**第二步：为什么是"区域数 $-1$"？** 开一扇门 = 把一段墙打通，它**两侧的两块区域合并成一块**。于是：

- **下界**：每扇门至多让区域数减 $1$，要从 $F$ 块变到 $1$ 块，至少 $F-1$ 扇门。
- **上界**：把"区域"当点、"共享一段围栏"当边，建**区域邻接图**。它是连通的（从任一区域走到任一区域，沿途穿过有限段围栏，就得到邻接图上的一条路），取一棵生成树，开树上 $F-1$ 条边对应的 $F-1$ 扇门，每扇门都恰好合并两块尚未连通的区域——$F-1$ 扇足够。

所以答案 $=F-1$，$F$ 是围栏把平面分成的区域总数。**问题归约为数区域。**

**第三步：数区域不用搜索——Euler 公式。** 直接 flood fill 数区域当然可以，但要把"格点、半格点、捏点"处理得一清二楚，容易写错。退一步看围栏本身的结构：

- 把**到过的不同格点**当顶点（$V$ 个），**建过的不同单位线段**当边（$E$ 条）；
- 围栏是沿一条连续走法建起来的，所以这张图**连通**；
- 单位横平竖直线段只在端点处相交（整数格点上，横段的内部 $x$ 坐标不是整数，竖段穿不进去），所以它是**平面图**，区域就是平面嵌入的面。

连通平面图满足 Euler 公式 $V-E+F=2$，于是

$$\boxed{\text{答案}=F-1=E-V+1}.$$

整道题塌缩成：**模拟走一遍，数不同的点和不同的线段**。不需要任何搜索！验证一下：正方形 $V=4,E=4\Rightarrow1$ ✓；共边双方形 $V=6,E=7\Rightarrow2$ ✓；共点双方形 $V=7,E=8\Rightarrow2$ ✓；孤段 $V=2,E=1\Rightarrow0$ ✓。

**第四步：实现里真正要抠的细节。**

1. **重复不计**：同一段走两次只算一条边（`NS` 的 $E$ 是 $1$ 不是 $2$）；同一个点到两次只算一个点。用 `bool` 数组标记，第一次标记时才计数。
2. **线段的规范表示**：横段 $(x,y)-(x+1,y)$ 记在**左端点** `(x,y)`，竖段 $(x,y)-(x,y+1)$ 记在**下端点** `(x,y)`——从两个方向走同一段必须落到同一个数组格子，所以统一取 `min` 端点。
3. **负坐标**：走法可能到 $(-1000,-1000)$，整体平移 $\text{ofs}=1001$，坐标落在 $[1,2001]$，数组开 $2005$。
4. **捏点不影响公式**：两个区域只在一个格点相触（如共点双方形的外部在触点处"掐断"再绕通），它们仍是两块面，Euler 公式对任何平面嵌入都成立，自动处理。反倒是如果用 flood fill 验证，**必须四邻接不能八邻接**——八邻接会在捏点处把两块面错误连通。
5. 答案非负：连通图 $E\ge V-1$，故 $E-V+1\ge0$；初始连通（树状围栏）时恰为 $0$，与题面提示一致。

**验证。** 题面没有样例输入输出，上表 $7$ 组手算数据程序全对。由于"答案 $=E-V+1$"是个隐蔽性质，我另写了一个完全独立的算法——在"单元格中心"的四邻接图上 flood fill 直接数区域（相邻单元格被挡当且仅当对应围栏段建过）——对 $4000$ 条随机走法（带惯性随机游走 + 随机矩形周界拼接，$N\le80$）逐条对比，$0$ 不一致（`appendix/P2771/verify.cpp`）。

## 二、思维链：完整证明

**记号。** 走法 $p_0=(0,0),p_1,\dots,p_N$，相邻相差一个单位轴向量。$V=\{p_0,\dots,p_N\}$（不同格点集），$E=\{\{p_{i-1},p_i\}:1\le i\le N\}$（不同单位线段集），以下 $V,E$ 也记其元素个数。围栏图形 $\mathcal F=\bigcup_{e\in E}e$（闭线段的并）。**区域** = $\mathbb R^2\setminus\mathcal F$ 的连通分支，个数记 $F$（含唯一的无界分支）。开门 = 选 $g$ 条边，把它们的**内部**从围栏中移除（允许穿越），新图形 $\mathcal F_g=\mathcal F\setminus\bigcup_{j=1}^g\mathrm{int}(e_j)$。答案 = 使 $\mathbb R^2\setminus\mathcal F_g$ 连通的最小 $g$。

---

### 引理 1（围栏是连通平面图的直线嵌入）

图 $G=(V,E)$ 连通；且 $E$ 中任意两条不同线段只可能在公共端点处相交（内部互不相交）。从而 $\mathcal F$ 是 $G$ 的一个平面嵌入，区域即其面。

*证明*：**连通**：走法本身给出 $p_0\to p_1\to\cdots\to p_N$ 的一条途径，$\{p_{i-1},p_i\}\in E$，故每个 $p_i$ 与 $p_0$ 在 $G$ 中连通；$V$ 中点都是某个 $p_i$ ✓。

**内部不交**：$E$ 中元素是整数端点的单位轴平行线段，分三类核对。两横段：若 $y$ 不同则不交；若 $y$ 相同，$x$ 区间都是长度 $1$ 的整数区间 $[a,a+1]$，相交必重合（同一条边，与"不同"矛盾）或仅在端点接触。两竖段对称。一横一竖：横段 $y=c,x\in[a,a+1]$，竖段 $x=d,y\in[b,b+1]$。若相交于内部，需 $a<d<a+1$ 且 $b<c<b+1$；但 $d$ 是整数而 $(a,a+1)$ 内无整数，矛盾。故交点只能是端点 ✓。

因此线段并是 $G$ 的无交叉直线嵌入，$\mathbb R^2\setminus\mathcal F$ 的连通分支就是嵌入的面。证毕。

---

### 引理 2（Euler 公式）

连通平面图 $G$ 的平面嵌入满足 $V-E+F=2$。

*证明*：对**圈秩** $r=E-V+1$ 归纳（$r\ge0$，连通图 $E\ge V-1$）。

**基例 $r=0$（$G$ 是树）**：证 $F=1$，即树的嵌入补集连通。对 $V$ 归纳：$V=1$ 时补集是 $\mathbb R^2$ 去掉一点，连通 ✓。设 $V-1$ 个顶点的树补集连通；$V$ 个顶点的树必有叶子 $w$（度 $1$），设其唯一邻边 $uw$。删去 $w$ 与 $uw$ 得 $V-1$ 顶点的树 $T'$，其补集连通（归纳假设）。$T$ 的补集 = $T'$ 的补集再挖去开线段 $\mathrm{int}(uw)$。挖去一条**一端是自由叶端点**的开线段不破坏连通性：$T'$ 补集中任何穿过 $\mathrm{int}(uw)$ 的路径，可在 $w$ 附近绕行——$w$ 不在 $T'$ 的任何边上，取 $w$ 的一个小圆盘邻域，它与 $T'$ 不交，圆盘减去一条从圆心出发的半径状线段仍连通（绕叶尖端走），故路径可局部改道避开 $\mathrm{int}(uw)$。于是 $T$ 补集连通，$F=1=0+2-0$ ✓（$V-E+F=V-(V-1)+1=2$）。

**归纳步**：设圈秩 $r-1$ 时成立。圈秩 $r\ge1$ 的连通图 $G$：取生成树 $T$，任取一条非树边 $e=\{u,v\}$，令 $G'=G-e$（仍连通，圈秩 $r-1$）。$G'$ 的嵌入是 $G$ 嵌入去掉 $\mathrm{int}(e)$，由归纳假设 $F(G')=E(G')-V+2=E-V+1$。$e$ 的内部落在 $G'$ 的某个面 $f$ 内（$\mathrm{int}(e)$ 与 $G'$ 的边不交，引理 1）。在 $G'$ 中取 $u\to v$ 的简单路径 $P$，则 $P\cup e$ 是一条简单闭曲线（Jordan 曲线），由 Jordan 曲线定理把平面分成内外两部分。$f\setminus\mathrm{int}(e)$ 恰有 **2** 个连通分支：$\mathrm{int}(e)$ 是面 $f$ 的一条"横截弧"（两端在 $\partial f$ 上），其两侧局部属于不同分支（否则存在 $f$ 内绕开 $e$ 连接两侧的路径，它与一小段横穿 $e$ 的弧拼成与 Jordan 曲线恰交一次的闭曲线，矛盾）；而 $f$ 内任一点可在 $f$ 内走到 $e$ 的某一侧（$f$ 连通、$e$ 是紧弧），故至多 2 个分支。其余面不含 $\mathrm{int}(e)$，不受影响。所以 $F(G)=F(G')+1=E-V+2$，即 $V-E+F=2$。证毕。

---

### 引理 3（一扇门至多合并两块区域：下界）

开 $g$ 扇门后区域数 $\ge F-g$。从而答案 $\ge F-1$。

*证明*：先证单扇门的情形。设当前围栏图形 $\mathcal H$（若干闭线段之并），区域数 $c$。开一段 $e\in\mathcal H$：新补集 = 旧补集 $\cup\,\mathrm{int}(e)$。$\mathrm{int}(e)$ 是连通集；沿 $\mathrm{int}(e)$ 不经过任何顶点（$e$ 是单位线段，内部无格点），故 $e$ 两侧的面沿整段**各自恒定**：取 $\mathrm{int}(e)$ 中点的小圆盘，被 $e$ 分成两个半圆盘，各含于某个区域 $f_1,f_2$（可能相同），且 $\mathrm{int}(e)$ 的闭包只接触这两个区域。于是加入 $\mathrm{int}(e)$ 至多把 $f_1,f_2$ 两个分支并成一个：$c$ 减 $1$（$f_1\ne f_2$）或不变（$f_1=f_2$），其余分支不动。

对 $g$ 归纳：每开一扇门区域数至多减 $1$，故开 $g$ 扇后 $\ge F-g$。要连通（$=1$）需 $F-g\le1$，即 $g\ge F-1$。证毕。

---

### 引理 4（区域邻接图连通）

定义对偶图 $D$：点 = $F$ 个区域；$f_1\ne f_2$ 之间连边当且仅当它们共享某条围栏线段（该线段两侧分别是 $f_1,f_2$）。则 $D$ 连通。

*证明*：任取两区域 $f_1,f_2$，取点 $x\in f_1,y\in f_2$。格点只有有限个，选一个"一般位置"的中间点 $z$（例如坐标取无理数，避开有限条"坏直线"），使折线 $x\to z\to y$ 不经过任何格点、也不与任何围栏线段共线重叠。于是折线与 $\mathcal F$ 的交是有限个点，且都在线段**内部**、横截穿过。沿折线走：不穿围栏时停留在同一区域；每穿过一段 $e_i$ 的内部，就从 $e_i$ 一侧的区域进入另一侧的区域——这正是 $D$ 中的一条边。如此得到 $D$ 中 $f_1\to f_2$ 的途径。$D$ 连通。证毕。

---

### 引理 5（$F-1$ 扇门足够：上界）

答案 $\le F-1$。

*证明*：$D$ 连通（引理 4），取生成树 $T^\*$，恰 $F-1$ 条边。按任意顺序开这 $F-1$ 条边对应的围栏线段。关键不变量：**开若干扇门后的区域分支，恰等于"以已开门的对偶边为边集"的 $D$ 子图的连通分支**——因为新补集 = 各区域（连通）$\cup$ 各开门内部（连通，且恰好连接其两侧区域），分支结构完全由这些连接决定。

现在开 $T^\*$ 的边 $\{f_1,f_2\}$ 时：已开门对应 $T^\*\setminus\{\text{该边}\}$ 的一个子集；树去掉一条边后 $f_1,f_2$ 分属两个分支，其任何子集更不可能连接它们，故 $f_1,f_2$ 当前**尚未连通**，这扇门恰好合并两个不同分支，区域数减 $1$（引理 3 的"$f_1\ne f_2$"情形）。$F-1$ 扇门后区域数 $=F-(F-1)=1$，连通 ✓。证毕。

**定理 A**：答案 $=F-1$。（引理 3 下界 + 引理 5 上界。）

---

### 引理 6（计数实现正确）

程序模拟走法，用平移 $\mathrm{ofs}=1001$ 后的 `vis` 标记不同格点、`eh[x][y]` 标记横段 $(x,y)-(x+1,y)$、`ev[x][y]` 标记竖段 $(x,y)-(x,y+1)$（均记在较小端点），首次标记时 `++vcnt`/`++ecnt`。则结束时 `vcnt`$=V$、`ecnt`$=E$，且所有数组访问不越界。

*证明*：**双射**：每条单位线段要么横要么竖。横段由其左端点 $(\min x,y)$ 唯一确定（右端点 $=(\min x+1,y)$），竖段由其下端点 $(x,\min y)$ 唯一确定；程序对横步取 `xx=min(x,nx)`、竖步取 `yy=min(y,ny)`，故从两个方向走同一段落到同一格子，"首次标记才计数"恰好数出不同线段数 $E$。格点同理得 $V$。

**范围**：$N\le1000$ 步，坐标 $\in[-1000,1000]$，平移后 $\in[1,2001]$。`vis` 访问 $\le2001<2005$ ✓；横段锚点 $x\le2000$（因 $x+1\le2001$）、竖段锚点 $y\le2000$，`eh/ev` 访问 $\le2000<2005$ ✓。

**初值**：全局 `bool` 数组零初始化，单测无需清空；起点先标记、`vcnt=1` ✓。证毕。

### 引理 7（复杂度与非负性）

时间 $O(N)$，空间 $O(\text{mxn}^2)\approx12$ MB；答案 $E-V+1\ge0$。

*证明*：每步常数次标记与比较，共 $N$ 步；全局数组零初始化由加载器完成，无显式填充开销。三个 `2005*2005` 的 `bool` 数组共 $\approx12.1$ MB。非负性：$G$ 连通（引理 1）$\Rightarrow E\ge V-1\Rightarrow E-V+1\ge0$；等号成立当且仅当 $G$ 是树（无圈），即围栏未围出任何区域，与题面"初始连通答案为 $0$"一致。证毕。

### 定理

程序输出保证全区域连通所需的最少门数，时间 $O(N)$。

*证明*：引理 1 把围栏建模为连通平面嵌入；引理 2 给出 $F=E-V+2$；定理 A（引理 3、5）给出答案 $=F-1=E-V+1$；引理 6 保证程序正确数出 $V,E$；引理 7 给出复杂度与非负性。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 一扇门 = 打通一段围栏、合并其两侧区域；目标是所有区域（含无界外部）连通。
- **consider easier version** — 手玩孤段 / 正方形 / 共边双方形 / 共点双方形：答案 = 围出的区域块数 = 总区域数 $-1$。
- **reduce to easier problem** — 最少门数 = 区域数 $-1$：下界"每门至多合并两块"，上界"区域邻接图连通 ⇒ 生成树 $F-1$ 条边逐扇打开"。
- **classic problem solution** — 围栏是连通平面图，Euler 公式 $V-E+F=2$ ⇒ 答案 $E-V+1$，数区域归约为数不同点与不同线段，搜索完全消失。
- **explore its property** — 重复走不计重边重点；线段统一记在较小端点保证双向同格；负坐标整体平移。
- **discuss by category** — 捏点（两区域仅共一格点）不影响 Euler；若用 flood fill 独立验证必须四邻接而非八邻接。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 步数 $\le1000$ | `int`，读入 | |
| `s` | 走法字符串（N/E/S/W） | `string`，读入 | |
| `x`,`y` | 当前位置（平移后坐标） | `int`，初值 `ofs,ofs` | 即原点 $(0,0)$ |
| `nx`,`ny` | 下一步位置 | `int` | 按字符增减 |
| `ofs` | 坐标平移量 $1001$ | `constexpr int` | 坐标 $\in[-1000,1000]\to[1,2001]$ |
| `mxn` | 数组尺寸 $2005$ | `constexpr int` | $2\times1000+5$ |
| `vis[x][y]` | 格点是否到过 | `bool[mxn][mxn]`，全局默认 `false` | 首次标记 `++vcnt` |
| `eh[x][y]` | 横段 $(x,y)-(x+1,y)$ 是否建过 | `bool[mxn][mxn]` | **记左端点** |
| `ev[x][y]` | 竖段 $(x,y)-(x,y+1)$ 是否建过 | `bool[mxn][mxn]` | **记下端点** |
| `vcnt`,`ecnt` | 不同格点数 $V$、不同线段数 $E$ | `int`，初值 $1,0$ | 起点先计 |
| 答案 | `ecnt-vcnt+1` | `int` | $E-V+1=F-1$ |

### 算法步骤

1. I/O 加速三行；读 `n,s`；置 `x=y=ofs`，标记起点，`vcnt=1`。
2. 逐字符模拟：按 N/E/S/W 得 `(nx,ny)`；新格点首次标记则 `++vcnt`。
3. 竖步（`nx==x`）：锚点 `(x,min(y,ny))`，`ev` 首次标记则 `++ecnt`；横步：锚点 `(min(x,nx),y)`，`eh` 首次标记则 `++ecnt`。
4. `x=nx;y=ny` 继续。
5. 输出 `ecnt-vcnt+1`。

### 复杂度

- 时间：$O(N)$，每步 $O(1)$。
- 空间：$O(\text{mxn}^2)$，三个 `2005*2005` `bool` 数组约 $12$ MB（用 `set<pair<int,int>>` 可降至 $O(N)$ 空间、$O(N\log N)$ 时间，本题不必）。
- 答案范围：$0\le E-V+1\le N-1$（每步至多新增一条边）。

### 验证状态

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2771 [USACO16JAN] Build Gates S
// 围栏是连通平面图：V 个不同格点、E 条不同单位线段。
// Euler 公式 V-E+F=2 ⇒ 区域数 F=E-V+2；每扇门至多合并两个区域 ⇒ 答案 F-1=E-V+1。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005},ofs{1001};	// 坐标 ∈[-1000,1000]，平移 ofs 后 ∈[1,2001]

int n,vcnt,ecnt;
bool vis[mxn][mxn],eh[mxn][mxn],ev[mxn][mxn];
// eh[x][y]：横线段 (x,y)-(x+1,y)；ev[x][y]：竖线段 (x,y)-(x,y+1)；都记在较小端点
string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>s;
	int x=ofs,y=ofs;
	vis[x][y]=true;vcnt=1;
	for(char c:s)
	{
		int nx=x,ny=y;
		if(c=='N')++ny;
		else if(c=='S')--ny;
		else if(c=='E')++nx;
		else --nx;
		if(!vis[nx][ny])
		{
			vis[nx][ny]=true;
			++vcnt;
		}
		if(nx==x)	// 竖线段
		{
			int yy=min(y,ny);
			if(!ev[x][yy])
			{
				ev[x][yy]=true;
				++ecnt;
			}
		}
		else	// 横线段
		{
			int xx=min(x,nx);
			if(!eh[xx][y])
			{
				eh[xx][y]=true;
				++ecnt;
			}
		}
		x=nx;y=ny;
	}
	cout<<ecnt-vcnt+1<<'\n';
	return 0;
}
```

### 代码说明

- **核心只有一行输出**：`ecnt-vcnt+1`。全部思维重量在"Euler 公式 + 门合并区域"的证明里，代码只是数两个集合的大小——这正是"思维链是灵魂，代码是副产品"的典型。
- **`min` 端点是去重的关键**：从 $(x,y)$ 走到 $(x+1,y)$ 与从 $(x+1,y)$ 走回 $(x,y)$ 必须命中同一个 `eh[x][y]`；竖段同理取 `min(y,ny)`。漏了 `min` 会把同一段数成两条，答案偏大。
- **首次标记才计数**：`vcnt/ecnt` 只在 `bool` 从 `false` 翻 `true` 时自增，重复走不重复计。起点单独先计（`vcnt=1`）。
- **平移防负下标**：`ofs=1001` 把 $[-1000,1000]$ 映到 $[1,2001]$；线段锚点最大 $2000$，`mxn=2005` 留足松弛。
- **全局 `bool` 默认 `false`** 恰好是"未建过"，单测无需清空；本题没有"不可达填 INF"的需求。
- 答案恒 $\ge0$（连通图 $E\ge V-1$），树状走法输出 $0$，与题面提示吻合。
