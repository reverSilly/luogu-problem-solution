# P2067 Cytus-Holyknight — 题解

## 一、解题过程：人类思考叙事

题目给一张 $n\times n$ 的字符图，其中 `'1'` 画的是坐标轴，`'x'` 是直线上的点，`'0'` 是直线外的点，要我们反推出这条直线的方程。

第一反应：拿两个 `'x'` 求一次函数不就行了。$k=\dfrac{y_2-y_1}{x_2-x_1}$，$b=y_1-kx_1$，三分钟写完。

但真写起来会立刻卡住两个地方。

**第一个卡点：坐标系在哪？** 图上只有一堆字符，我们要知道原点在第几行第几列，还要知道 $y$ 轴朝上还是朝下。题目说"横行的 `1` 是 $x$ 轴，竖列的 `1` 是 $y$ 轴"，所以 $x$ 轴是某一整行 `1`，$y$ 轴是某一整列 `1`，它们的交点就是原点。

**第二个卡点，也是本题真正的坑：石子会压在坐标轴上。** 很多人第一反应是"找一整行全是 `1` 的行当 $x$ 轴，找一整列全是 `1` 的列当 $y$ 轴"。这在石子不压轴时是对的，可一旦石子落在轴上，那一行/那一列就不再全是 `1` 了，判定直接失效。

更阴的是：如果一个石子正好压在原点上，那么"横行的 `1`"和"竖列的 `1`"这两条线本身就被石子打断了一格。

那怎么稳妥地定位坐标轴？我用的办法是**枚举 + 校验**：

- 枚举所有 $(rx, cy)$，含义是"第 $rx$ 行是 $x$ 轴，第 $cy$ 列是 $y$ 轴"。
- 校验两条性质：
  1. 图上**所有** `'1'` 都必须落在第 $rx$ 行或第 $cy$ 列上——因为 `'1'` 只用来画坐标轴，轴外不可能出现 `'1'`。
  2. 第 $rx$ 行和第 $cy$ 列上**不能出现 `'0'`**——轴上的格子要么是 `'1'`（轴本身），要么是 `'x'`（石子正好压在上面），绝不可能是 `'0'`（`'0'` 的定义是"该整点不在直线上"，而轴上的点必然在轴上）。
- 如果有多个候选满足，取 `'1'` 最多的那个十字（真正的轴一定是 `'1` 最多的那条），并要求 $rx$ 行和 $cy$ 列上都至少有一个 `'1'`（否则说明这条线根本没画出来，是伪候选）。

$n\le 16$，枚举 $16^2=256$ 个候选、每个候选扫一遍 $16^2$ 个格子，$O(n^4)$，不到十万次运算，随便跑。

**坐标换算**是另一个容易翻车的点。设网格坐标为 $(j,i)$（$j$ 是列号、$i$ 是行号，**都从 0 开始，行号从上往下增大**），原点在网格的 $(cy, rx)$。那么数学坐标是

$$X = j - cy,\qquad Y = rx - i .$$

注意 $Y = rx - i$ 里有个负号：网格行号往下增大，而数学 $y$ 往上增大，所以要反号。$X = j - cy$ 则是正的（列号往右增大，数学 $x$ 也往右增大）。

**直线方程怎么算才不飘浮点？** 硬做 $k=\frac{y_2-y_1}{x_2-x_1}$ 再代回求 $b$，中间全是除法，最后四舍五入容易出 `y=0.3333x2.3333` 这种漏掉 `+` 号的丑输出（我第一次写就踩了这个坑：截距的符号和分母的符号会互相抵消）。

所以我改用**一般式**：设直线为 $A x + B y + C = 0$，其中 $x$ 是列号、$y$ 是行号（网格坐标）。过两点 $(x_1,y_1),(x_2,y_2)$ 的直线取

$$A = y_1-y_2,\quad B = x_2-x_1,\quad C = x_1y_2-x_2y_1 .$$

这一步全是整数乘法，没有除法，不存在精度问题。

然后换算到数学坐标系：把 $j = X+cy$、$i = rx-Y$ 代入 $A j + B i + C = 0$，整理得

$$A(X+cy) + B(rx-Y) + C = 0 \;\Longrightarrow\; B Y = A X + (A\,cy + B\,rx + C),$$

即

$$k = \frac{A}{B},\qquad b = \frac{A\,cy + B\,rx + C}{B}.$$

**输出分类**也要注意。题目要求输出 $y=kx+b$ / $y=kx$ / $y=b$ / $x=b$ 四种形式之一，常数保留四位小数。分三种情况：

- $B=0$：$A j + C = 0$，是一整列，竖直线，输出 $x=b$，其中 $b = -\frac{C}{A} - cy$（网格列号换成数学横坐标）。
- $A=0$：$B i + C = 0$，是一整行，水平线，输出 $y=b$，其中 $b = rx + \frac{C}{B}$。
- $A,B$ 都非零：输出 $y=kx+b$，$b>0$ 时打 `+`，$b<0$ 时直接打负数（负号自带），$b=0$ 时只打 `y=kx` 不带常数。

还要防一手：$b$ 算出来是 $-0.0000003$ 这种，用 `fabs(b)<1e-9` 归零，避免输出 `y=1.0000x-0.0000` 这种怪东西。

## 二、思维链：完整证明

**引理 1**：若第 $rx$ 行是 $x$ 轴、第 $cy$ 列是 $y$ 轴，则图上所有 `'1'` 都满足 $i=rx$ 或 $j=cy$。

*证明*：按题面，"横行的 `1` 是 $x$ 轴，竖列的 `1` 是 $y$ 轴"，即字符 `'1'` 只在坐标轴上出现。坐标轴恰由第 $rx$ 行与第 $cy$ 列构成，故任一 `'1'` 必满足 $i=rx$ 或 $j=cy$。证毕。

**引理 2**：第 $rx$ 行与第 $cy$ 列上不可能出现 `'0'`。

*证明*：第 $rx$ 行与第 $cy$ 列上的格子都在坐标轴上。按题面，`'0'` 表示"该整点不在直线上"，`'1'` 表示"坐标轴"，`'x'` 表示"该整点在直线上"。坐标轴上的格子按定义是坐标轴（`'1'`），若恰好又是直线上的点则为 `'x'`，无论哪种都不该是 `'0'`；`'0'` 的语义恰恰排除了它。证毕。

**引理 3**：`axisok(rx,cy)` 返回真的坐标轴。

*证明*：设真实坐标轴为 $(rx^\*, cy^\*)$。由引理 1，真实坐标轴满足"'1' 全在轴上"这条校验；由引理 2，它满足"轴上没有 '0'"这条校验；且 $rx^\*$ 行、$cy^\*$ 列上确实有 `'1'`（轴被画出来了）。故真实坐标轴一定被 `axisok` 接受。反过来，被接受的候选中"轴上没有 `'0'`"意味着这条十字真的可能是轴，"所有 `'1'` 都在十字上"意味着图上的 `'1'` 全被它解释掉了；题面保证有唯一解，故这样的候选就是真实坐标轴。证毕。

**引理 4**：两个不同石子确定的直线 $A j + B i + C = 0$（$A=y_1-y_2,\ B=x_2-x_1,\ C=x_1y_2-x_2y_1$）经过这两个石子。

*证明*：代入点 $(x_1,y_1)$：
$$A x_1 + B y_1 + C = (y_1-y_2)x_1 + (x_2-x_1)y_1 + x_1y_2-x_2y_1 = y_1x_1 - y_2x_1 + x_2y_1 - x_1y_1 + x_1y_2 - x_2y_1 = 0 .$$
代入点 $(x_2,y_2)$ 同理为 $0$。故该直线过两点。因两点不同且 $A,B$ 不同时为 $0$（否则 $x_1=x_2$ 且 $y_1=y_2$，与"不同石子"矛盾），它就是这两点确定的唯一直线。证毕。

**引理 5**：数学坐标下该直线的斜率 $k=\frac{A}{B}$、截距 $b=\frac{A\,cy+B\,rx+C}{B}$。

*证明*：网格坐标 $(j,i)$ 与数学坐标 $(X,Y)$ 的关系是 $j=X+cy$、$i=rx-Y$。代入引理 4 的直线方程：
$$A(X+cy)+B(rx-Y)+C=0 \;\Longrightarrow\; BY = AX + (A\,cy+B\,rx+C).$$
当 $B\ne0$ 时两边除以 $B$，即 $Y=\frac{A}{B}X+\frac{A\,cy+B\,rx+C}{B}$，与题给的 $y=kx+b$ 比较即得 $k=\frac{A}{B}$、$b=\frac{A\,cy+B\,rx+C}{B}$。证毕。

**引理 6**：三种分类输出的方程与直线一致。

*证明*：
- $B=0$：直线化为 $Aj+C=0$，即 $j=-\frac{C}{A}$，是竖直线。所有点在同一列，数学横坐标 $X=j-cy=-\frac{C}{A}-cy$ 恒定，故直线方程为 $x=-\frac{C}{A}-cy$，与输出一致。
- $A=0$：直线化为 $Bi+C=0$，即 $i=-\frac{C}{B}$，是水平线。数学纵坐标 $Y=rx-i=rx+\frac{C}{B}$ 恒定，故方程为 $y=rx+\frac{C}{B}$，与输出一致。
- $A,B\ne0$：由引理 5 直接成立。

三种情形覆盖了 $A,B$ 的全部可能（$A,B$ 不会同时为 $0$，见引理 4），故输出总是正确且唯一。证毕。

**定理**：算法输出的即为题目要求的直线方程。

*证明*：由引理 3，枚举选出的 $(rx,cy)$ 就是真实坐标轴，从而换算关系 $X=j-cy,\ Y=rx-i$ 正确。由引理 4，直线方程正确。由引理 6，输出的形式与数值都正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **先想清楚坐标系怎么定** — 字符图题的第一步永远是"把字符位置翻译成数学坐标"，本题靠"横行的 `1` 是 $x$ 轴、竖列的 `1` 是 $y$ 轴"这句话。
2. **警惕"石子压在轴上"这个坑** — 不要用"整行全是 `1`"这种脆弱判据，改用"枚举候选 + 语义校验"。
3. **用语义做校验** — `'1'` 只能在轴上、轴上不能有 `'0'`，这两条都是直接从题面定义推出来的，比"数一数有几个 `1`"稳得多。
4. **一般式代替斜截式做中间量** — 整数叉积定直线，全程无除法，精度问题从根上消失。
5. **换算时把负号想清楚** — 网格行号向下增大，数学 $y$ 向上增大，$Y=rx-i$ 里的负号最容易写错。
6. **输出要分类且注意符号** — 竖直 / 水平 / 一般三种，$b>0$ 补 `+`，$b<0$ 让负号自己出来，$b=0$ 不带常数。
7. **浮点结果做一次"负零"归一** — `fabs(b)<1e-9` 归零，避免输出 `-0.0000`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 图的边长 | `int`，$3\le n\le16$ |
| `g[i][j]` | 第 $i$ 行第 $j$ 列字符（$i$ 为行号、$j$ 为列号，均 0-based） | `char`，取 `'0'/'1'/'x'` |
| `sx[], sy[]` | 第 $k$ 个石子的列号、行号 | `int`，$0\le <n^2$ |
| `scnt` | 石子个数 | `int` |
| $rx$ | $x$ 轴所在行号（网格行） | `int`，$0\le rx<n$ |
| $cy$ | $y$ 轴所在列号（网格列） | `int`，$0\le cy<n$ |
| $A,B,C$ | 直线一般式系数 $A j + B i + C = 0$ | `int`，绝对值 $\le n^2$ |
| $k$ | 斜率 | `double` |
| $b$ | 截距 | `double` |

**初始化约定**：全局 `char g[mxn][mxn]` 自动初始化为 `'\0'`；`sx/sy` 全局数组默认全 0，`scnt` 初始为 0（全局数组默认初始化）。

### 算法步骤

1. 读入 $n$ 与字符图 `g[]`。
2. 扫描全图，把所有 `'x'` 的列号、行号记入 `sx[]`、`sy[]`，计数 `scnt`。
3. 取前两个石子定出一般式：$A=sy[0]-sy[1]$，$B=sx[1]-sx[0]$，$C=sx[0]\cdot sy[1]-sx[1]\cdot sy[0]$。
4. 枚举 $rx=0\ldots n-1$、$cy=0\ldots n-1$：
   - 校验一：所有 `'1'` 必须在第 $rx$ 行或第 $cy$ 列；
   - 校验二：第 $rx$ 行与第 $cy$ 列上不能有 `'0'`；
   - 校验三：第 $rx$ 行与第 $cy$ 列上至少各有一个 `'1'`；
   - 合法候选按 `rowone(rx)+colone(cy)` 打分，取分最高者。
5. 按 $A,B$ 分类输出：
   - $B=0$：`x = -C/A - cy`；
   - $A=0$：`y = rx + C/B`；
   - 否则：`k=A/B`，$b=(A\cdot cy+B\cdot rx+C)/B$，输出 `y=kx`（$b=0$）或 `y=kx+b`（$b>0$ 补 `+`，$b<0$ 打负数）。

### 复杂度

- 时间复杂度：$O(n^4)$。枚举 $n^2$ 个轴候选，每个候选扫 $n^2$ 个格子；$n\le16$ 时约 $6.5\times10^4$ 次格子检查。
- 空间复杂度：$O(n^2)$，存储字符图与石子坐标。

### 验证状态

- 标程 `P2067.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `3 / 010 / 111 / x1x` 输出 `y=-1.0000`，与官方一致。
- 另一份题解给出的公开测试数据 `6 / 000010 / 000x10 / x00010 / 111111 / 000010 / 000010` 输出 `y=0.3333x+2.3333`，与该数据给出的答案一致（该数据同时覆盖了"石子压在 $x$ 轴上方一行"与斜截式输出）。
- 额外自造竖直线数据 `5 / x0100 / x0100 / x1111 / x0100 / x0100` 输出 `x=-2.0000`，验证了 $B=0$ 分支与 `x=b` 输出形式。
- 本题的几何约定（原点位置、$y$ 轴朝向、输出格式）依赖图形约定，无法写独立暴力程序对拍，故未生成对拍脚本；验证方式为官方样例 + 两份独立题解给出的公开数据 + 自造竖直线数据。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};

int n;
char g[mxn][mxn];
//石子（'x'）在网格中的位置：sx 为列号，sy 为行号
int sx[mxn*mxn],sy[mxn*mxn],scnt=0;
//直线的 一般式 A*x+B*y+C=0（网格坐标 x 为列，y 为行）
int A,B,C;

//坐标轴候选：rx 行与 cy 列必须覆盖全部 '1'，
//且轴上不能出现 '0'（轴上的格子要么是 '1'，要么压着石子 'x'）
bool axisok(int rx,int cy)
{
	int cntr=0,cntc=0;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
		{
			if(g[i][j]=='0'&&(i==rx||j==cy))
				return false;
			if(g[i][j]=='1'&&i!=rx&&j!=cy)
				return false;
			if(g[i][j]=='1')
			{
				if(i==rx)
					++cntr;
				if(j==cy)
					++cntc;
			}
		}
	return cntr>0&&cntc>0;
}

//该行 / 该列上 '1' 的个数
int rowone(int r)
{
	int cnt=0;
	for(int j=0;j<n;++j)
		if(g[r][j]=='1')
			++cnt;
	return cnt;
}

int colone(int c)
{
	int cnt=0;
	for(int i=0;i<n;++i)
		if(g[i][c]=='1')
			++cnt;
	return cnt;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>g[i];
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			if(g[i][j]=='x')
			{
				sx[scnt]=j;
				sy[scnt]=i;
				++scnt;
			}

	//两个石子定出直线（网格坐标）
	A=sy[0]-sy[1];
	B=sx[1]-sx[0];
	C=sx[0]*sy[1]-sx[1]*sy[0];

	//选坐标轴：候选中 '1' 最多的那条十字即为真正的坐标轴
	int rx=-1,cy=-1,bestscore=-1;
	for(int r=0;r<n;++r)
		for(int c=0;c<n;++c)
		{
			if(!axisok(r,c))
				continue;
			int score=rowone(r)+colone(c);
			if(score>bestscore)
			{
				bestscore=score;
				rx=r;
				cy=c;
			}
		}

	//换算到以 (rx,cy) 为原点、Y 轴向上的坐标系
	if(!B)
	{
		//竖直线：网格列 j=-C/A，数学横坐标 X=j-cy
		printf("x=%.4f\n",(double)(-C)/A-cy);
		return 0;
	}
	if(!A)
	{
		//水平线：网格行 i=-C/B，数学纵坐标 Y=rx-i
		printf("y=%.4f\n",(double)rx+(double)C/B);
		return 0;
	}
	double k=(double)A/B;
	double b=(double)(A*cy+B*rx+C)/B;
	if(fabs(b)<1e-9)
		b=0;
	printf("y=%.4fx",k);
	if(b>0)
		printf("+%.4f",b);
	else if(b<0)
		printf("%.4f",b);
	printf("\n");
	return 0;
}
```

### 代码说明

- 全局 `char g[25][25]` 与 `int sx[25*25]` 自动初始化为 0，不需要额外 `fill`。
- `axisok` 一次性做三条校验，把"轴上不能有 `'0'`"和"所有 `'1'` 都在轴上"这两条语义直接翻译成代码。
- `A,B,C` 全程整数运算，仅在最后输出时才转 `double` 做除法。
- 输出用 `printf` 的 `%.4f` 精确控制四位小数，负数自带负号，正数截距手动补 `+`。
- `'\n'` 而非 `endl`；`main` 以 `return 0;` 结束。
