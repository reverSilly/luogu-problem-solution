# P2309 loidc，卖卖萌 — 题解

## 一、解题过程：人类思考叙事

题意：给一个长度为 $n$ 的整数串（$n\le 10^5$，每个数在 $-100\sim100$ 之间），数出有多少个**连续子段**的和为正数。$30\%$ 的数据 $n\le 10^3$。

**最朴素的做法。** 枚举左端点 $l$，从 $l$ 往右累加，每加一个数就判断一次是否为正。复杂度 $O(n^2)$；$n=10^3$ 时是 $10^6$，正好对上前 $30\%$ 的部分分；但 $n=10^5$ 时是 $5\times10^9$ 次加法，$1$ s 内绝无可能。所以必须把「枚举所有子段」换成「一次性数出所有合法子段」。

**换一个「和」的表示法。** 子段和用前缀和表示是最自然的：令 $S_0=0$，$S_i=S_{i-1}+a_i$，则子段 $[l,r]$ 的和为 $S_r-S_{l-1}$。于是
$$S_r-S_{l-1}>0\iff S_r>S_{l-1}.$$
原本的「求和再判正」消失了，只剩一个**纯粹的大小关系**。这一步是本题的转折点：问题从「区间求和」变成了「数点对」。

**把子段翻译成下标对。** 每个子段 $[l,r]$ 唯一对应一个下标对 $(l-1,r)$，其中 $0\le l-1<r\le n$；反过来每个满足 $i<j$ 的下标对 $(i,j)$ 也唯一对应子段 $[i+1,j]$。于是

> 答案 = 满足 $0\le i<j\le n$ 且 $S_i<S_j$ 的下标对个数。

这是一个非常经典的形状：**按时间顺序数「前面有多少个比我小」**。注意 $S$ 一共有 $n+1$ 个元素，所以下标对总数是 $\binom{n+1}{2}\approx 5\times10^9$——答案本身就可能超过 `int`，输出必须用 64 位。

**怎么数得动？** 从左往右扫 $j=0,1,\dots,n$，每次需要知道「已经出现过的 $S_i\ (i<j)$ 中有多少个严格小于 $S_j$」。这是一个「动态插入 + 前缀计数」的需求，标准工具是**树状数组**（或权值线段树）。每次查询 $O(\log n)$，插入 $O(\log n)$，总 $O(n\log n)$。

**树状数组要开多大？** 直接按值域开是不行的：$|S_i|\le n\times100=10^7$，值域宽度 $2\times10^7$，开 `int` 数组要 80 MB，太浪费（而且负数下标还要平移）。但真正出现过的 $S$ 值只有 $n+1$ 个，**离散化**成 $1\sim k$（$k\le n+1$）即可，树状数组只要 $10^5$ 出头。

**两个容易错的细节。**

细节一：**必须严格小于。** 若 $S_i=S_j$，则子段和为 $0$，不是正数却被算进去了。所以查询的是「排名 $<$ 当前排名」的前缀和，即 `sigma(rk-1)`，而不是 `sigma(rk)`。这是本题最容易 WA 的地方，构造 `0 0` 这种数据立刻能测出来（答案应为 $0$，写错会输出 $1$）。

细节二：**别忘了 $S_0=0$ 也要参与。** $i$ 可以取 $0$，代表子段从第 $1$ 个数开始。若只把 $S_1..S_n$ 插入树状数组，就会漏掉所有「从开头开始」的子段。代码里循环从 $i=0$ 起、并把 $S_0$ 一并离散化即可。

**手造数据核对。** 题面无样例，手造：

- `3 / 1 -2 3`：正和子段为 $[1],[1,3],[-2,3],[3]$，共 $4$ 个；前缀和 $S=(0,1,-1,2)$，满足 $S_i<S_j$ 的对为 $(0,1),(0,3),(1,3),(2,3)$，也是 $4$ 个。
- `2 / 0 0`：任何子段和都是 $0$，答案 $0$；前缀和全相等，严格小于的对数为 $0$。
- `1 / -5`：答案 $0$；`1 / 5`：答案 $1$。
- `4 / 1 -1 1 -1`：正和子段是 $[1],[1,3],[3]$，答案 $3$。

这些用例的程序输出依次为 `4 0 0 1 3`，与手算全部一致。

## 二、思维链：完整证明

**引理 1（前缀和恒等式）**：对任意 $1\le l\le r\le n$，有 $\sum_{t=l}^{r}a_t=S_r-S_{l-1}$。

*证明*：由定义 $S_r=\sum_{t=1}^{r}a_t$，$S_{l-1}=\sum_{t=1}^{l-1}a_t$，两式相减，公共前缀 $\sum_{t=1}^{l-1}a_t$ 抵消，剩下 $\sum_{t=l}^{r}a_t$。证毕。

**引理 2（子段与下标对的双射）**：映射 $[l,r]\mapsto(l-1,r)$ 是「所有子段」到「所有满足 $0\le i<j\le n$ 的下标对」的双射。

*证明*：先证像落在目标集合内：$1\le l\le r\le n$ 给出 $0\le l-1<r\le n$。再证单射：$[l,r]\ne[l',r']$ 时，至少左端点或右端点不同，于是 $l-1\ne l'-1$ 或 $r\ne r'$，像不同。再证满射：任取 $0\le i<j\le n$，令 $l=i+1$，$r=j$，则 $1\le l\le r\le n$，且 $[l,r]$ 的像是 $(i,j)$。故为双射。证毕。

**引理 3（正和判定）**：子段 $[l,r]$ 的和为正 $\iff S_{l-1}<S_r$。

*证明*：由引理 1，和为 $S_r-S_{l-1}$。$S_r-S_{l-1}>0\iff S_r>S_{l-1}\iff S_{l-1}<S_r$。证毕。

**推论**：答案等于满足 $0\le i<j\le n$ 且 $S_i<S_j$ 的下标对 $(i,j)$ 的个数。

*证明*：由引理 2 的双射，子段与下标对一一对应；由引理 3，在该对应下「正和」等价于「$S_i<S_j$」。故两侧的计数相等。证毕。

**引理 4（离散化保序）**：把 $S_0,\dots,S_n$ 复制一份排序去重得到严格递增数组 $b_0<\dots<b_{k-1}$，定义 $\mathrm{rk}(x)=\operatorname{lower\_bound}(b,x)+1$（1-based）。则对任意 $x,y\in\{S_i\}$：
$$x<y\iff \mathrm{rk}(x)<\mathrm{rk}(y),\qquad x=y\iff \mathrm{rk}(x)=\mathrm{rk}(y).$$

*证明*：因为 $x$ 一定出现在 $b$ 中，`lower_bound` 返回的是 $b$ 中第一个 $\ge x$ 的位置；$b$ 已去重且严格递增，唯一满足 $b_p=x$ 的下标就是它，故 $\mathrm{rk}(x)-1$ 正是 $x$ 在严格递增序列 $b$ 中的下标。严格递增序列上「值的大小关系」与「下标的大小关系」完全一致：若 $x<y$，则 $\mathrm{rk}(x)-1<\mathrm{rk}(y)-1$；若 $x=y$，两者下标相同；反之亦然。证毕。

**引理 5（树状数组不变量）**：设 `bit[j]` 维护的是
$$\texttt{bit}[j]=\sum_{t=j-\mathrm{lowbit}(j)+1}^{j}A_t,$$
即下标区间 $(j-\mathrm{lowbit}(j),\,j]$ 的和。

1. `add(x,v)` 沿 $x,\,x+\mathrm{lowbit}(x),\,\dots$ 逐点加 $v$，恰好给「区间包含 $x$」的每个节点加上了 $v$；
2. `sigma(i)` 沿 $i,\,i-\mathrm{lowbit}(i),\,\dots$ 累加，恰好把 $[1,i]$ 划分成若干互不相交的节点区间，因此返回 $\sum_{t=1}^{i}A_t$。

*证明*：

(2) 先看查询链。令 $i_0=i$，$i_{t+1}=i_t-\mathrm{lowbit}(i_t)$。第 $t$ 步累加的节点 $i_t$ 覆盖区间 $(i_{t+1},i_t]$，而下一次累加的节点正是 $i_{t+1}$，其覆盖区间以 $i_{t+1}$ 为右端点。所以这些区间依次首尾相接：$(i_1,i_0],(i_2,i_1],\dots$，两两不交。又每步都把 $i_t$ 的最低位 $1$ 清零，$i_t$ 严格减小且非负，最终到达 $0$，故并集恰为 $(0,i]=[1,i]$。于是累加和等于 $\sum_{t=1}^{i}A_t$。

(1) 再看更新链。先证「链上的每个节点 $j$ 的区间都含 $x$」。设当前节点为 $j'$、$\mathrm{lowbit}(j')=2^m$，则 $j'$ 的二进制第 $0..m-1$ 位为 $0$、第 $m$ 位为 $1$。加到 $j=j'+2^m$ 后，第 $m$ 位变 $0$ 并向更高位进位，于是 $j$ 的第 $0..m$ 位全为 $0$，即 $\mathrm{lowbit}(j)\ge2^{m+1}$。因此
$$j-\mathrm{lowbit}(j)\le j-2^{m+1}=j'-2^m=j'-\mathrm{lowbit}(j')<x,$$
（最后一个不等号来自归纳假设 $x>j'-\mathrm{lowbit}(j')$），又 $x\le j'<j$，故 $x\in(j-\mathrm{lowbit}(j),j]$，即 $j$ 的区间含 $x$。链首 $j'=x$ 时区间 $(x-\mathrm{lowbit}(x),x]$ 的右端点就是 $x$，故含 $x$。归纳得链上所有节点都覆盖 $x$。

再证「不在链上的节点都不覆盖 $x$」。若 $j<x$，区间右端点 $j<x$，故不含 $x$。设 $j\ge x$ 且 $j'<j<j'+\mathrm{lowbit}(j')=j''$，其中 $j'$ 是链上 $\le j$ 的最后一个节点（链首为 $x\le j$，故这样的 $j'$ 存在）。写 $\mathrm{lowbit}(j')=2^m$，则 $j=j'+r$，$1\le r<2^m$，于是 $j$ 的第 $0..m-1$ 位就是 $r$ 的二进制、第 $m$ 位仍为 $1$，故 $\mathrm{lowbit}(j)=\mathrm{lowbit}(r)\le 2^{m-1}$。于是
$$j-\mathrm{lowbit}(j)=j'+r-\mathrm{lowbit}(r)\ge j'\ge x,$$
即 $x\notin(j-\mathrm{lowbit}(j),j]$，该节点不覆盖 $x$。结合两段，覆盖 $x$ 的节点恰为更新链，故 `add` 的正确性得证。证毕。

**引理 6（扫描不变量）**：设扫描到下标 $j$ 之前，树状数组里恰好存有 $S_0,\dots,S_{j-1}$ 的排名（每个各计一次），则 `sigma(rk(S_j)-1)` 等于 $\#\{i<j: S_i<S_j\}$。

*证明*：由引理 5，`sigma(rk-1)` 是树状数组中排名 $\le \mathrm{rk}(S_j)-1$ 的元素个数。由引理 4，排名 $\le \mathrm{rk}(S_j)-1$ 等价于值 $<S_j$。而树状数组中存的正是一一对应、各计一次的 $S_0,\dots,S_{j-1}$，故该计数等于 $\#\{i<j:S_i<S_j\}$。证毕。

**定理（答案正确）**：程序输出的 `ans` 等于正和子段的个数。

*证明*：程序对 $j=0,1,\dots,n$ 依次执行「查询 `sigma(rk-1)` 累加到 `ans`，再插入 $S_j$」。对 $j$ 归纳可验证扫描不变量（引理 6 的前提）成立：$j=0$ 时树状数组为空，恰是 $S_0,\dots,S_{-1}$ 的集合（空集）；每次查询后插入 $S_j$，集合从 $S_0..S_{j-1}$ 变为 $S_0..S_j$。于是
$$\texttt{ans}=\sum_{j=0}^{n}\#\{i<j:S_i<S_j\}=\#\{(i,j):0\le i<j\le n,\ S_i<S_j\},$$
由推论即得答案。证毕。

**引理 7（复杂度）**：时间 $O(n\log n)$，空间 $O(n)$。

*证明*：排序去重 $O(n\log n)$；扫描 $n+1$ 轮，每轮一次查询、一次插入，各 $O(\log(n+1))$。空间为前缀和、离散化数组、树状数组，均 $O(n)$。证毕。

**关于 64 位**：答案最大为 $\binom{n+1}{2}=\frac{10^5\cdot(10^5+1)}{2}=5000050000>2^{31}-1$，`ans` 必须用 `i64`；树状数组内部计数不超过 $10^5$，用 `i64` 只是省心。

## 三、模式总结（按实际思考顺序）

- **consider easier version** — $O(n^2)$ 枚举左右端点，正好吃掉 $30\%$（$n\le10^3$）的部分分。
- **explore its property** — 用前缀和把「区间和为正」化为「两个前缀和的大小关系」$S_{l-1}<S_r$，求和运算整体消失。
- **reduce to easier problem** — 子段与下标对 $(i,j)$ 一一对应，问题变成「数满足 $i<j$ 且 $S_i<S_j$ 的点对」。
- **classic problem solution** — 扫描 $j$，用树状数组动态维护已出现前缀和的排名计数，查询严格小于者；$O(n\log n)$。
- **explore its property** — 值域宽 $2\times10^7$ 但只出现 $n+1$ 个值，离散化把树状数组压到 $O(n)$；离散化保序，故「排名小」等价于「值小」。
- **排查边界** — 严格不等号（等值代表和为 $0$）、$S_0=0$ 必须参与、答案超 `int`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
|------|------|----------------|
| $n$ | 数串长度 | 读入 |
| `a[1..n]` | 原数组 | 读入 |
| `s[0..n]` | 前缀和，`s[i]=s[i-1]+a[i]` | `s[0]=0`，用 `i64` |
| `b[0..n]` | `s[0..n]` 的排序去重副本 | 用于离散化 |
| `k` | 不同前缀和的个数 | `unique` 后的长度 |
| `bit[1..k]` | 树状数组，维护各排名出现次数 | 全 $0$；`lowbit` 树 |
| `rk` | 当前前缀和的 1-based 排名 | `lower_bound(b,b+k,s[i])-b+1` |
| `ans` | 正和子段个数 | $0$，`i64` |

### 算法步骤

1. 读入 $n$ 与 $a_1..a_n$；递推 `s[i]=s[i-1]+a[i]`（$i=1..n$）。
2. 把 `s[0..n]` 复制到 `b[0..n]`，`sort` 后 `unique`，得到严格递增的 `b[0..k-1]`。
3. 依次令 $i=0,1,\dots,n$：
   1. 求排名 `rk=lower_bound(b,b+k,s[i])-b+1`。
   2. `ans += sigma(rk-1)`——只数**严格小于**当前前缀和的历史值。
   3. `add(rk,1)`——把当前前缀和插入。
4. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(n\log n)$（排序 $O(n\log n)$，$n+1$ 次树状数组操作各 $O(\log n)$）。
- 空间复杂度：$O(n)$。
- 极限 $n=10^5$ 实测约 $0.05$ s。

### 验证状态

- 编译：`g++ -std=c++20 -O2 -Wall` 无错误无警告。
- 题面无样例，手造 5 组：`1 -2 3 → 4`、`0 0 → 0`、`-5 → 0`、`5 → 1`、`1 -1 1 -1 → 3`，全部与手算一致。
- 对拍：暴力 $O(n^2)$ 枚举左右端点，在 $n\le60$、含大量 $0$、全非负、全非正四种模式的 $300$ 组随机数据上比对，**0 mismatch**。
- 极限验证：$n=10^5$ 且全部为 $100$ 时输出 `5000050000`，确认 64 位未溢出；随机数据 $0.06$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2309 loidc，卖卖萌
// 思路：子段 (l..r) 的和 = s[r]-s[l-1]，>0 等价于 s[l-1]<s[r]
//       于是答案 = 下标对 (i<j) 且 s[i]<s[j] 的个数
//       从左往右扫描，树状数组维护已出现前缀和的排名次数
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n;
int a[mxn];
i64 s[mxn],b[mxn],bit[mxn];

void add(int i,int v)
{
	for(;i<=n+1;i+=i&-i)
		bit[i]+=v;
}
i64 sigma(int i)
{
	i64 r=0;
	for(;i>0;i-=i&-i)
		r+=bit[i];
	return r;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)
		cin>>a[i];
	for(int i=1;i<=n;++i)
		s[i]=s[i-1]+a[i];

	for(int i=0;i<=n;++i)
		b[i]=s[i];
	sort(b,b+n+1);
	int k=unique(b,b+n+1)-b;

	i64 ans=0;
	for(int i=0;i<=n;++i)
	{
		int rk=lower_bound(b,b+k,s[i])-b+1;   // 1-based 排名
		ans+=sigma(rk-1);                     // 只数严格小的，差为 0 的不算
		add(rk,1);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 下标循环从 $i=0$ 开始：$S_0=0$ 代表「空前缀」，它必须参与，否则所有从第 $1$ 个数起的子段都会漏掉。
- 查询用 `sigma(rk-1)` 而不是 `sigma(rk)`：排名相同意味着前缀和相等、子段和为 $0$，不属于正数。
- 离散化用 `sort + unique + lower_bound`，数组 `b` 严格递增；因为每个 `s[i]` 必然出现在 `b` 中，`lower_bound` 得到的排名与值的大小关系严格一致。
- 树状数组上界写成 `n+1`（即排名最大值），`k` 不超过它，循环条件 `i<=n+1` 保证不漏更新。
- `ans` 用 `i64`：$n=10^5$ 时答案可达 $5000050000$，`int` 必爆。
- 用 `i64` 存 `s`：$|s_i|\le10^7$ 用 `int` 也够，但统一 64 位后不必再为中间量操心。
