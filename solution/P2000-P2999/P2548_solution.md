# P2548 [AHOI2004] 智能探险车 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 个决策因素（$N\le 100$），某种行为有 $M$ 条决策条件（$M\le 1000$）。每条条件是 $N$ 个单词（小写字母、长度 $\le 10$），第 $j$ 个单词是第 $j$ 个因素在该条件下的取值。要归纳出一条**决策模板**：也是 $N$ 个位置，每个位置要么填一个具体单词、要么填 `*`（表示"该因素不影响决策"）。模板必须**涵盖全部 $M$ 条条件**——即对每条条件、每个因素，模板该位置是 `*` 或与条件里的单词相同。在涵盖全部条件的前提下，要求 `*` **尽可能少**（模板越精确越好）。输出这条模板。

**第一反应：这是不是一个搜索/优化问题？** 模板每个位置有"若干单词 + `*`"这么多种选择，$N$ 个位置组合起来天文数字，难道要搜索？我盯着"涵盖所有条件"这句话看了一会儿，发现一个关键结构：

> 模板的第 $j$ 个位置，只跟所有条件的**第 $j$ 列**打交道，跟别的列毫无关系。

也就是说，"模板涵盖条件 $i$"这件事，可以**拆成 $N$ 个独立的列约束**：对每一列 $j$，模板要么填 `*`（对该列所有条件都放行），要么填一个单词 $w$（那么**所有** $M$ 条条件在第 $j$ 列都必须是 $w$，否则有一条对不上）。列与列之间没有任何耦合。于是"$N$ 个位置的联合优化"**塌缩成 $N$ 个互不相干的单列决策**。这一步是整题的支点：看似要搜索，其实每列独立、一眼可解。

**第二步：单列到底怎么填最省 `*`？** 对第 $j$ 列，把 $M$ 条条件在该列的单词拿出来看：

- **如果 $M$ 个单词全都相同**（设都是 $w$）：填 $w$ 就能涵盖所有条件，且用了 $0$ 个 `*`。这是最省的——填 `*` 反而多一个。
- **如果 $M$ 个单词不全相同**：能不能填某个具体单词 $w$？不行。只要有一条条件在该列是 $w'\ne w$，模板填 $w$ 就涵盖不了它。而填任何具体单词都要求"全列一致"，现在不一致，所以**唯一合法的选择就是 `*`**（$1$ 个，被迫的）。

所以每列的答案是**唯一确定**的：全列一致就输出那个单词，否则输出 `*`。把 $N$ 列各自的最优拼起来，就是全局 `*` 最少的模板——因为各列独立，全局最优 = 各列最优之和，没有"牺牲一列换另一列"的余地。

**第三步：落到代码。** 我不需要把 $M\times N$ 个单词全存下来。逐行读入，对每列 $j$ 维护两样东西：第一行见到的单词 `word[j]`，以及一个布尔 `same[j]`（到目前为止该列是否仍然全一致）。读到第 $i$ 行第 $j$ 列的单词 $w$：若 $i=0$ 就记 `word[j]=w`；否则若 $w\ne$ `word[j]` 就置 `same[j]=false`。读完后，`same[j]` 为真输出 `word[j]`，否则输出 `*`。时间 $O(NM)$（每个单词比较一次），空间只要 $O(N)$ 个单词。

**手造数据核对**（题面给了一个采集矿石的例子，我直接用它，另造三组打边界）：

题面例子（$N=4,M=3$）：

```
sunny Plain full Few
sunny mountain full Many
sunny mountain full Many
```

逐列看：第 1 列全 `sunny` → `sunny`；第 2 列 `Plain/mountain/mountain` 不一致 → `*`；第 3 列全 `full` → `full`；第 4 列 `Few/Many/Many` 不一致 → `*`。输出 `sunny * full *`，与题面给出的决策模板逐字吻合。

另造三组：`a b / a c`（$N=2,M=2$）→ `a *`（第 2 列不一致）；`x`（$N=1,M=1$）→ `x`（只有一条条件，必然全一致）；`aa bb cc / aa bb cc`（$N=3,M=2$）→ `aa bb cc`（两行完全相同，零 `*`）。这三组分别覆盖了"部分列不一致""单因素单条件""全一致"三种情形。

## 二、思维链：完整证明

**记号。** 条件矩阵 $C_{i,j}$（$1\le i\le M$，$1\le j\le N$）为第 $i$ 条条件第 $j$ 个因素的单词。模板 $T=(T_1,\dots,T_N)$，每个 $T_j$ 是一个单词或 `*`。称 $T$ **涵盖**条件 $i$，当且仅当 $\forall j:\ T_j=\texttt{*}\ \lor\ T_j=C_{i,j}$。称 $T$ **合法**，当且仅当它涵盖全部 $M$ 条条件。目标：在合法模板中最小化 $\bigl|\{j:T_j=\texttt{*}\}\bigr|$。

---

### 引理 1（合法性按列分解）

$T$ 合法 $\iff$ 对每个 $j$，下列之一成立：(a) $T_j=\texttt{*}$；(b) $T_j=w$ 且 $\forall i:\ C_{i,j}=w$（即第 $j$ 列 $M$ 个单词全等于 $w$）。

*证明*：按定义，$T$ 合法 $\iff\forall i\,\forall j:\ (T_j=\texttt{*}\lor T_j=C_{i,j})$。全称量词 $\forall i\,\forall j$ 可交换为 $\forall j\,\forall i$，故等价于 $\forall j:\ \bigl[\forall i:\ (T_j=\texttt{*}\lor T_j=C_{i,j})\bigr]$。固定 $j$，内层 $\forall i$ 的含义：若 $T_j=\texttt{*}$，则每个 $i$ 的析取式都因左支为真而成立，与 $C_{i,j}$ 无关，即 (a)；若 $T_j=w\ne\texttt{*}$，则每个 $i$ 必须右支为真，即 $\forall i:\ C_{i,j}=w$，即 (b)。两分支穷尽 $T_j$ 的取值（单词或 `*`），故得证。证毕。

**推论（列独立性）**：合法性的约束是 $N$ 个**互不耦合**的列约束的合取——第 $j$ 列能否填某单词，只取决于第 $j$ 列的 $M$ 个单词，与其它列无关。因此模板的合法集合是各列合法选择集合的**笛卡尔积**。

---

### 引理 2（单列最优选择唯一）

对第 $j$ 列，令 $S_j=\{C_{1,j},\dots,C_{M,j}\}$（去重后的单词集合）。

- 若 $|S_j|=1$（全列一致，设唯一单词为 $w$）：填 $T_j=w$ 合法且用 $0$ 个 `*`，是该列唯一的最优选择。
- 若 $|S_j|\ge 2$（不一致）：该列**任何**具体单词都不合法，唯一合法选择是 $T_j=\texttt{*}$，用 $1$ 个 `*`。

*证明*：分两种情形。

**情形 A：$|S_j|=1$。** 由引理 1(b)，填 $w$ 满足 $\forall i:\ C_{i,j}=w$，合法，`*` 数为 $0$。`*` 数是非负整数，$0$ 是下界，故 $T_j=w$ 最优。唯一性：若改填 `*`，`*` 数为 $1>0$，更差；若改填另一单词 $w'\ne w$，因 $M\ge 1$ 且存在 $C_{i,j}=w\ne w'$，引理 1(b) 不满足、又非 `*`，不合法。故最优选择唯一为 $w$。

**情形 B：$|S_j|\ge 2$。** 反证任何具体单词 $w$ 合法：由引理 1(b) 需 $\forall i:\ C_{i,j}=w$，即 $S_j=\{w\}$，与 $|S_j|\ge 2$ 矛盾。故具体单词全不合法，由引理 1 只剩 $T_j=\texttt{*}$，合法（(a) 分支恒成立），`*` 数为 $1$，且是唯一合法选择。证毕。

---

### 引理 3（全局最优 = 各列最优之拼接，且唯一）

设 $T^\*$ 按引理 2 对每列取最优选择。则 $T^\*$ 合法、`*` 数全局最小，且是**唯一**的最小 `*` 模板。

*证明*：**合法性**：每列选择都满足引理 1 的对应分支，由引理 1 的合取，$T^\*$ 合法。

**最优性**：设 $T$ 为任一合法模板，其 `*` 数为 $\sum_{j=1}^{N}\mathbf 1[T_j=\texttt{*}]$。由引理 2，对每列 $j$，$T_j$ 的 `*` 贡献 $\ge$ $T^\*_j$ 的 `*` 贡献（情形 A：$T^\*_j$ 贡献 $0$ 是下界；情形 B：两者都只能贡献 $1$）。逐项相加得 $\texttt{*}(T)\ge\texttt{*}(T^\*)$。故 $T^\*$ 全局最小。这里用到引理 1 推论的列独立性：目标函数是各列贡献之**和**，约束是各列约束之**积**，故可逐列独立最小化再求和，不存在跨列权衡。

**唯一性**：若合法模板 $T$ 与 $T^\*$ 有相同的 `*` 数（即也达最小），则对每列 $j$，$T_j$ 的 `*` 贡献必须等于 $T^\*_j$ 的贡献（否则某列严格更大，总和严格更大，矛盾）。情形 A 列：贡献 $0$ 迫使 $T_j=w=T^\*_j$（引理 2 唯一性）；情形 B 列：贡献 $1$ 迫使 $T_j=\texttt{*}=T^\*_j$。故 $T=T^\*$。证毕。

**注（"智能性"是副产品，不是约束）**：题面提到模板会顺带涵盖一些未列出的条件（`*` 越多涵盖越广）。但目标只是"涵盖全部已列条件 + `*` 最少"，并未限制"不能涵盖额外条件"。引理 2 的逐列共识恰好给出满足覆盖约束的最精确模板；它涵盖额外条件与否不影响合法性与最优性，故无需额外处理。

---

### 引理 4（算法实现与引理 2 一致）

程序对每列 $j$ 维护 `word[j]`（首行单词）与 `same[j]`（是否仍全一致），读完后 `same[j]` 为真输出 `word[j]`、否则输出 `*`。则输出恰为 $T^\*$。

*证明*：先证不变量——读完前 $i$ 行后，`same[j]` 为真 $\iff C_{1,j}=\dots=C_{i,j}$，且此时 `word[j]`$=C_{1,j}$。对 $i$ 归纳：$i=1$ 时 `word[j]`$=C_{1,j}$、`same[j]`$=$true，单元素平凡一致 ✓。设前 $i-1$ 行成立，读第 $i$ 行：若 $C_{i,j}\ne$`word[j]`$=C_{1,j}$ 则置 `same[j]`$=$false；否则保持。故 `same[j]` 为真 $\iff$ 前 $i-1$ 行一致且 $C_{i,j}=C_{1,j}$ $\iff$ 前 $i$ 行全一致 ✓。读完 $M$ 行，`same[j]` 为真 $\iff$ 第 $j$ 列全一致 $\iff |S_j|=1$，此时 `word[j]` 即唯一单词 $w$，输出 $w$；否则输出 `*`。逐字对应引理 2 的两情形，故输出 $=T^\*$。证毕。

---

### 引理 5（复杂度）

时间 $O(NM\cdot L)$，空间 $O(N\cdot L)$，其中 $L\le 10$ 为单词长度上限。

*证明*：共读入 $NM$ 个单词，每个与 `word[j]` 做一次长度 $\le L$ 的串比较，$O(L)$，合计 $O(NML)$。只需存 $N$ 个 `word`（各 $\le L$ 字符）与 $N$ 个布尔，$O(NL)$。代入 $N=100,M=1000,L=10$：约 $10^6$ 次字符比较，远低于限制。证毕。

---

### 定理

程序输出的模板合法、`*` 数全局最小且唯一，复杂度 $O(NML)$。

*证明*：引理 1 把合法性分解为独立列约束；引理 2 给出每列唯一最优；引理 3 证逐列拼接即全局唯一最优；引理 4 证实现与之一致；引理 5 给复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — "模板涵盖条件"按因素拆成 $N$ 个独立列约束：第 $j$ 列填单词要求该列 $M$ 个单词全一致，否则只能 `*`。
- **reduce to easier problem** — 看似 $N$ 位联合搜索，因列独立 + 目标是各列 `*` 数之和，塌缩成 $N$ 个互不相干的单列决策。
- **discuss by category** — 每列分两类：全一致 → 输出该单词（$0$ 个 `*`，唯一最优）；不一致 → 任何具体单词都覆盖不了，被迫 `*`。
- **classic problem solution** — 逐列共识（consensus）扫描：边读边维护"首词 + 是否仍一致"，$O(NM)$ 时间、$O(N)$ 空间，无需存整个矩阵。
- **explore its property** — 最优模板唯一：一致列填词严格优于 `*`，不一致列只能 `*`，故"最少 `*`"与"逐列共识"是同一件事。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 决策因素个数（$\le 100$） | `int`，读入 | 即模板长度、列数 |
| `m` | 决策条件条数（$\le 1000$） | `int`，读入 | 即行数 |
| `word[j]` | 第 $j$ 列**首行**见到的单词 | `string[mxn]` | 仅当全列一致时它是答案 |
| `same[j]` | 第 $j$ 列到目前为止是否仍全一致 | `bool[mxn]`，初值 `true` | `fill_n(same,n,true)` |
| `w` | 当前读入的单词 | `string`，临时 | 与 `word[j]` 比较 |
| `mxn` | $100+5$ | `constexpr int{105}` | 列数上界 +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 `n,m`；`fill_n(same,n,true)`。
3. 对每行 $i=0..m-1$、每列 $j=0..n-1$：读单词 `w`；若 $i=0$ 置 `word[j]=w`，否则若 `w!=word[j]` 置 `same[j]=false`。
4. 对每列 $j=0..n-1$：列间输出一个空格（首列前不输出）；`same[j]` 为真输出 `word[j]`，否则输出 `*`。
5. 末尾输出 `'\n'`（行首行末无多余空白）。

### 复杂度

- 时间：$O(NM\cdot L)$，$L\le 10$；$N=100,M=1000$ 时约 $10^6$ 次字符比较。
- 空间：$O(N\cdot L)$，只存 $N$ 个单词与 $N$ 个布尔。

### 验证状态

`g++ -std=c++20 -O2` 编译通过；题面采集矿石例子输出 `sunny * full *` 逐字吻合；另造"部分列不一致 / 单因素单条件 / 全一致"三组手算数据全对。本题为逐列共识的直接模拟，性质清晰、无隐蔽边界，未写对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2548 [AHOI2004] 智能探险车
// 思路：模板按因素拆成 N 个独立列约束。第 j 列填单词要求该列 M 个单词全一致，
//       否则只能 '*'。故逐列求共识：全一致输出该词，否则 '*'，即 '*' 最少的唯一模板。
//       边读边维护"首词 + 是否仍一致"，O(NM) 时间、O(N) 空间。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n,m;
string word[mxn];
bool same[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	fill_n(same,n,true);
	for(int i=0;i<m;++i)
		for(int j=0;j<n;++j)
		{
			string w;
			cin>>w;
			if(i==0)
				word[j]=w;
			else if(w!=word[j])
				same[j]=false;	// 该列出现分歧，只能 '*'
		}
	for(int j=0;j<n;++j)
	{
		if(j)
			cout<<' ';
		cout<<(same[j]?word[j]:string("*"));
	}
	cout<<'\n';
	return 0;
}
```

### 代码说明

- **不存整个矩阵**：只需每列的"首词 + 是否仍一致"，空间 $O(N)$。读到分歧就把 `same[j]` 永久置 `false`（之后即使再一致也不改回——因为已经出现过不同单词，全列一致已被破坏）。
- `same[j]` 初值 `true`，第一行只记录 `word[j]` 不做比较（单元素平凡一致）；从第二行起才比较。
- 输出用 `if(j)cout<<' ';` 保证**列间恰好一个空格、行首行末无空白**，符合题面格式要求。
- 三目 `same[j]?word[j]:string("*")` 两侧统一为 `string`，避免 `const char*` 与 `string` 混用的歧义。
- 本题每个因素独立，无需任何跨列数据结构；"最少 `*`"由逐列共识自动保证（引理 3）。
