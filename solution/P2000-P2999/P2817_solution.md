# P2817 宋荣子的城堡 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 个房间（$1\le n\le10^{18}$），每个房间写一个数字 $p_i\in[1,n]$，表示"从 $i$ 下一步去 $p_i$"。给定 $k$（$1\le k\le\min(n,8)$），重写所有 $p_i$ 使得：

- 从 $1..k$ 中**任何**房间出发，沿 $p$ 走（至少一步）**能走到 $1$**（$p_1=1$ 时 $1\to1$ 也算）；
- 从编号 $>k$ 的房间出发，**一定不能**走到 $1$。

求方案数 $\bmod\ 10^9+7$。

**第一步：识别结构——函数图。** 每个点恰有一条出边 $i\to p_i$，这是经典的**函数图**（functional graph）：每个连通分量是"一个环 + 若干棵指向环的内向树"（$\rho$ 形）。从 $i$ 出发的轨迹 $i,p_i,p_{p_i},\dots$ 最终进入唯一的环并绕圈。

**关键观察**："$i$ 能走到 $1$" 等价于 "$1$ 在 $i$ 最终进入的那个环上"。为什么？若 $1$ 在环上，轨迹进环后必然经过 $1$；若 $1$ 不在环上，轨迹进环后再也出不来，而 $1$ 若在"尾巴"上则只在进环前经过一次——但题目还要求**从 $1$ 出发也能走回 $1$**，这迫使 $1$ 本身在环上（否则 $1$ 的轨迹进环后永不回 $1$）。所以：

> $1$ 必须在环上；且 $i$ 能走到 $1$ ⟺ $i$ 流入"$1$ 所在的那个环"。

**第二步：把两个条件翻译成对 $p$ 的约束。** 记 $A=\{1..k\}$，$B=\{k+1..n\}$。

- **$B$ 中的点不能走到 $1$**。若某个 $i\in B$ 有 $p_i\in A$，则 $i\to p_i$，而 $p_i\in A$ 必须能走到 $1$，于是 $i$ 也走到 $1$，矛盾。所以 **$i\in B\Rightarrow p_i\in B$**。反过来，若所有 $B$ 的点都指向 $B$，它们的轨迹永远留在 $B$，碰不到 $1$，条件满足。
- **$A$ 中的点必须走到 $1$**。若某个 $i\in A$ 有 $p_i\in B$，则 $i$ 流入 $B$，而 $B$ 的点碰不到 $1$，于是 $i$ 也碰不到 $1$，矛盾。所以 **$i\in A\Rightarrow p_i\in A$**。

**结论**：$p$ 必须**保持划分** $A\sqcup B$——$A$ 内部自成函数图，$B$ 内部自成函数图，两部分**独立**。

**第三步：$B$ 部分随便填。** $B$ 有 $n-k$ 个点，每个 $p_i$ 可取 $B$ 中任意一个（$n-k$ 种），共 $(n-k)^{n-k}$ 种。这部分没有任何额外约束（只要不碰 $1$，而留在 $B$ 就自动不碰）。

**第四步：$A$ 部分——唯一环且含 $1$。** $p$ 限制在 $A$（$k$ 个点）上是函数 $f:[k]\to[k]$。条件"$A$ 中每点都走到 $1$"加上"$1$ 在环上"，等价于：**$f$ 的函数图只有一个环，且这个环含 $1$**。（若有第二个环，环上的点走不到 $1$；若唯一环不含 $1$，则 $1$ 走不回自己。）

设这个计数为 $S(k)$。答案 $=S(k)\cdot(n-k)^{n-k}$。

**第五步：数 $S(k)$——拆环成树。** $k\le8$ 很小，但我想要一个干净的闭式。盯住环上 $1$ 的那条出边 $1\to f(1)$：

**把这条边删掉**，函数图变成什么？原来唯一的环被剪断，$1$ 不再有出边，其余点 $i\ne1$ 仍指向 $f(i)$。现在从任何点沿 $f$ 走，最终都停在 $1$（因为唯一的环没了，而 $1$ 是唯一的"汇"）。这正是一棵**以 $1$ 为根的内向树**（$k$ 个点、$k-1$ 条边、连通、无环）！

反过来，给定一棵以 $1$ 为根的树（即 $i\ne1$ 的父亲 $f(i)$），再**任选** $f(1)=v\in[k]$，就恢复出一个合法函数图：环是 $1\to v\to(\text{树上 }v\text{ 到 }1\text{ 的路径})\to1$，含 $1$ 且唯一，所有点流入它。

所以 **$S(k)=(\text{以 }1\text{ 为根的 }k\text{ 点标号树数})\times k$**（$f(1)$ 有 $k$ 种选法）。

**第六步：Cayley 公式 + Prüfer 序列。** 以 $1$ 为根的 $k$ 点标号树数 $=$ $k$ 点标号树数（每棵无根树恰有一种方式以 $1$ 为根）$=k^{k-2}$（Cayley 公式，用 Prüfer 序列证：$k$ 点标号树 $\leftrightarrow$ 长 $k-2$、值域 $[k]$ 的序列，共 $k^{k-2}$ 个）。

于是 $S(k)=k\cdot k^{k-2}=k^{k-1}$。

**第七步：合起来。** 答案

$$\boxed{k^{k-1}\cdot(n-k)^{n-k}\bmod(10^9+7)}.$$

$n=k$ 时 $(n-k)^{n-k}=0^0$，组合意义是"空积 $=1$"（$B$ 为空，没有点要填），快速幂 `qpow(0,0)=1` 恰好正确处理。$k\le8$ 故 $k^{k-1}$ 极小；$(n-k)^{n-k}$ 用快速幂，指数 $n-k\le10^{18}$ 在 `long long` 内。

**手造小数据枚举验证**（$k$ 小，直接列出所有 $f:[k]\to[k]$ 检验）：

- $k=1$：$f(1)=1$，唯一，$S(1)=1=1^0$ ✓。
- $k=2$：$4$ 个函数。$(p_1,p_2)=(1,1)$：环 $\{1\}$，$2\to1$ ✓；$(2,1)$：环 $1\to2\to1$ 含 $1$ ✓；$(1,2)$：环 $\{1\}$ 与 $\{2\}$ 两个，$2$ 走不到 $1$ ✗；$(2,2)$：$1\to2\to2$，$1$ 不在环上 ✗。合法 $2$ 个，$S(2)=2=2^1$ ✓。
- $k=3$：按环大小分类。环 $\{1\}$（$f(1)=1$）：$2,3$ 构成以 $1$ 为根的树，$3^{3-2}=3$ 种；环含 $1$ 和另一个（$2$ 选 $1$）$\times$ 环排列 $1!\times$ 剩 $1$ 点挂到 $2$ 个环点之一（$2$ 种）$=2\times1\times2=4$；环含全部 $3$ 点：$(3-1)!=2$。共 $3+4+9$？重算：$3+4+2=9=3^2$ ✓。

$n=3,k=2$：答案 $2^1\cdot1^1=2$（$A$ 部分 $2$ 种，$B=\{3\}$ 只能 $p_3=3$）✓。$n=4,k=2$：$2^1\cdot2^2=8$ ✓。

## 二、思维链：完整证明

**记号。** $[m]=\{1,\dots,m\}$。$A=[k]$，$B=[n]\setminus A$，$|B|=n-k$。$p:[n]\to[n]$。$f=p|_A$。模数 $P=10^9+7$。

---

### 引理 1（函数图的轨迹与环）

在函数图 $p$ 中，从 $i$ 出发的轨迹最终进入唯一的一个有向环 $C(i)$ 并周期绕行。$i$ 的轨迹经过 $1$ 当且仅当 $1\in C(i)$，**前提是 $1$ 本身在某个环上**。特别地，"从 $1$ 出发至少一步走回 $1$" 等价于 "$1$ 在环上"。

*证明*：每点出度恰 $1$，轨迹 $i,p_i,p_{p_i},\dots$ 是无限序列但取值有限（$[n]$），必有重复；设首次重复为 $p^{(a)}(i)=p^{(b)}(i)$（$a<b$），则 $p^{(a)}(i),\dots,p^{(b-1)}(i)$ 构成一个环，此后周期绕行。由出度唯一，这个环是 $i$ 最终进入的唯一环 $C(i)$。

"$1$ 在环上 ⟺ 从 $1$ 走回 $1$"：若 $1$ 在环 $C$ 上，沿环走 $|C|$ 步回到 $1$（$\ge1$ 步）✓。若 $1$ 不在任何环上，则 $1$ 的轨迹进入 $C(1)$ 后永不离开，而 $1\notin C(1)$，故永不回 $1$ ✗。

"轨迹经过 $1$ ⟺ $1\in C(i)$"（在 $1$ 位于环上的前提下）：若 $1\in C(i)$，轨迹进环后经过 $1$ ✓。若 $1\notin C(i)$：轨迹在进环前是一段简单路径（无重复），进环后只在 $C(i)$ 上。若 $1$ 在进环前的尾巴上，则从 $1$ 继续走会进入 $C(i)$ 且永不回 $1$（因 $1\notin C(i)$），与"$1$ 在环上"矛盾。故 $1$ 既不在尾巴也不在 $C(i)$，轨迹不经过 $1$。证毕。

---

### 引理 2（条件等价于保持划分 + $A$ 内唯一含 $1$ 环）

$p$ 合法（$A$ 中每点走到 $1$、$B$ 中每点走不到 $1$、$1$ 走回 $1$）当且仅当：

(i) $i\in A\Rightarrow p_i\in A$；$i\in B\Rightarrow p_i\in B$；

(ii) $f=p|_A$ 的函数图恰有一个环且含 $1$。

*证明*：

**必要性**。先证 $1$ 在环上（引理 1，由"从 $1$ 走回 $1$"）。

证 (i) 的 $B$ 部分：若 $i\in B$ 且 $p_i\in A$，则 $i$ 的轨迹经过 $p_i$；而 $p_i\in A$ 须走到 $1$，故 $i$ 也走到 $1$，与"$B$ 走不到 $1$"矛盾。故 $p_i\in B$。

证 (i) 的 $A$ 部分：若 $i\in A$ 且 $p_i\in B$，则 $i$ 流入 $B$。由 $B$ 部分（刚证）$B$ 的点轨迹永留 $B$，碰不到 $1$（$1\in A$），故 $i$ 走不到 $1$，矛盾。故 $p_i\in A$。

证 (ii)：由 (i)，$f$ 是 $A$ 上的函数图。$A$ 中每点走到 $1$，由引理 1 即每点 $i\in A$ 满足 $1\in C(i)$，亦即 $C(i)$ 都是"$1$ 所在的环"。故 $A$ 中所有点流入同一个含 $1$ 的环，即唯一环含 $1$。

**充分性**。设 (i)(ii) 成立。$B$ 的点轨迹永留 $B$（由 (i)），$1\in A$，故 $B$ 走不到 $1$ ✓。$A$ 的点流入唯一含 $1$ 的环（由 (ii)），故都经过 $1$ ✓；$1$ 在环上故走回 $1$ ✓。证毕。

---

### 引理 3（两部分独立，$B$ 部分计数）

合法 $p$ 与"($A$ 上满足 (ii) 的 $f$) $\times$ ($B$ 上任意函数 $g:B\to B$)"一一对应。故总数 $=S(k)\cdot(n-k)^{n-k}$，其中 $S(k)$ 为 $A$ 上唯一含 $1$ 环的函数数。

*证明*：由引理 2，$p$ 合法 ⟺ $p|_A$ 满足 (ii) 且 $p|_B$ 是 $B\to B$ 的任意函数（(i) 自动满足，$B$ 无额外约束）。两部分定义域不交、取值不交，独立选取。$|B|=n-k$，每点 $n-k$ 种选择，共 $(n-k)^{n-k}$。$n=k$ 时 $B=\varnothing$，空函数唯一，$(n-k)^{n-k}=0^0:=1$。证毕。

---

### 引理 4（拆环双射：$S(k)=k\cdot T(k)$）

设 $T(k)$ 为以 $1$ 为根的 $k$ 点标号树数（$k\ge1$）。则 $S(k)=k\cdot T(k)$。

*证明*：构造双射。设 $\mathcal F$ 为 $A=[k]$ 上唯一含 $1$ 环的函数集合，$\mathcal T$ 为以 $1$ 为根的 $k$ 点标号树集合。

**映射 $\Phi:\mathcal F\to\mathcal T\times[k]$**：给定 $f\in\mathcal F$，令 $v=f(1)$，并定义树 $T_f$：顶点 $[k]$，对 $i\ne1$ 连边 $i\to f(i)$（$i$ 的父亲为 $f(i)$），$1$ 为根（无父亲）。

证 $T_f\in\mathcal T$：边数 $k-1$（每个 $i\ne1$ 一条）。连通且无环：$f$ 的函数图是唯一环 $C$（含 $1$）加内向树；删去环上边 $1\to f(1)$ 后，环被剪断成路径，所有点沿 $f$ 最终到 $1$（$1$ 无出边）。故 $T_f$ 中每点有唯一到根 $1$ 的路径，是树。

**映射 $\Psi:\mathcal T\times[k]\to\mathcal F$**：给定 $(T,v)$，定义 $f(1)=v$，$f(i)=T$ 中 $i$ 的父亲（$i\ne1$）。

证 $f\in\mathcal F$：$T$ 是以 $1$ 为根的树，故 $i\ne1$ 沿父亲走必到 $1$。$f$ 的轨迹：从 $1$ 走 $1\to v\to(\text{父亲链})\to1$，形成一个含 $1$ 的环；其余点流入此环。这是唯一环（树部分无环，加上 $1\to v$ 只造出这一个环）。故 $f\in\mathcal F$。

**互逆**：$\Psi(\Phi(f))$：$\Phi(f)=(T_f,f(1))$，$\Psi$ 重建 $f'(1)=f(1)$、$f'(i)=T_f$ 中父亲 $=f(i)$（$i\ne1$），故 $f'=f$。$\Phi(\Psi(T,v))$：$\Psi(T,v)=f$ 满足 $f(1)=v$、$i\ne1$ 父亲为 $T$ 的父亲；$\Phi(f)$ 删 $1\to v$ 恢复 $T$，且 $v=f(1)$，故 $=(T,v)$。

双射成立，$|\mathcal F|=|\mathcal T|\cdot k$，即 $S(k)=k\cdot T(k)$。证毕。

---

### 引理 5（Prüfer 双射与 Cayley 公式）

对 $k\ge2$，$k$ 点标号树（顶点 $[k]$）与长度 $k-2$、值域 $[k]$ 的序列一一对应。故标号树数 $=k^{k-2}$，且 $T(k)=k^{k-2}$（以 $1$ 为根不改变计数）。

*证明*：

**编码**。给定树 $T$，重复 $k-2$ 次：取当前**标号最小的叶子** $u$，记录其唯一邻居 $w$ 到序列末尾，删除 $u$。剩 $2$ 个点时停止。得到长 $k-2$ 的序列 $\mathrm{pr}(T)\in[k]^{k-2}$。

**关键事实**：顶点 $v$ 在 $\mathrm{pr}(T)$ 中出现次数 $=\deg_T(v)-1$。

证：$v$ 被记录，当且仅当某步删除的叶子 $u$ 的邻居是 $v$，即 $v$ 的一个邻居被删且当时 $v$ 仍在。每发生一次，$v$ 的度数减 $1$。$v$ 自身被删时它是叶子（度 $1$），不再被记录；或 $v$ 是最后剩下的两点之一，也不被记录。故 $v$ 被记录的次数 $=$ 它从初始度 $\deg_T(v)$ 降到 $1$ 所经历的"邻居被删"次数 $=\deg_T(v)-1$。

**解码**。给定序列 $(a_1,\dots,a_{k-2})$。令 $\deg(v)=1+\#\{j:a_j=v\}$（由关键事实，这是目标树中 $v$ 的度）。重复 $k-2$ 次：取**不在剩余序列中出现**的最小标号顶点 $u$（此时 $\deg(u)=1$，是叶子），连边 $u\!-\!a_1$，$\deg(u),\deg(a_1)$ 各减 $1$，删去 $a_1$（序列前进）。最后剩两个 $\deg=1$ 的点，连边。

**解码良定义**：每步"不在剩余序列中的最小顶点"存在——剩余序列长 $m$ 时至多 $m$ 个不同值出现在其中，而当前有 $m+2$ 个顶点，故至少 $2$ 个顶点不在序列中，最小者存在且其 $\deg=1$（因 $\deg(v)=1+$ 出现次数，出现次数 $0$ 则 $\deg=1$）。

**互逆**：编码第 $t$ 步删的叶子 $u_t$，是当时最小叶子；其邻居 $w_t=a_t$。解码第 $t$ 步取的 $u$ 是"不在剩余序列 $\{a_t,\dots\}$ 中的最小顶点"。由关键事实，编码时 $u_t$ 被删后不再出现于序列后续（它度变 $0$），且 $u_t$ 是当时最小叶子；可归纳证明解码取的恰是 $u_t$、连的恰是 $u_t\!-\!a_t$。故解码重建原树。反之解码出的树编码回原序列（度序列匹配、叶子删除顺序匹配）。双射成立。

计数：序列每位 $k$ 种、长 $k-2$，共 $k^{k-2}$。每棵无根标号树以 $1$ 为根恰得一棵 rooted 树（根固定不增加选择），故 $T(k)=k^{k-2}$。$k=1$ 时单点树唯一，$T(1)=1$（约定 $1^{-1}=1$）。证毕。

---

### 引理 6（$S(k)=k^{k-1}$）

对 $k\ge1$，$S(k)=k^{k-1}$。

*证明*：$k\ge2$：由引理 4，$S(k)=k\cdot T(k)$；由引理 5，$T(k)=k^{k-2}$；故 $S(k)=k\cdot k^{k-2}=k^{k-1}$。$k=1$：$S(1)=1$（唯一函数 $f(1)=1$），$1^{0}=1$ ✓。证毕。

---

### 引理 7（最终公式与取模）

合法方案数 $=k^{k-1}(n-k)^{n-k}$。$\bmod P$ 计算：$k^{k-1}\bmod P$ 直接快速幂（$k\le8$）；$(n-k)^{n-k}\bmod P$ 用快速幂，底数 $(n-k)\bmod P$、指数 $n-k$（$\le10^{18}$，`long long` 容纳）。$n=k$ 时指数 $0$，快速幂返回 $1$，正确实现 $0^0=1$。

*证明*：由引理 3、6 得公式。取模：乘法模满足 $(ab)\bmod P=((a\bmod P)(b\bmod P))\bmod P$；快速幂 `qpow(a,b)` 用 $a\bmod P$ 作底、$b$ 作指数，逐位平方乘，中间量 $<P^2\approx10^{18}<2^{63}-1$，`long long` 不溢出。指数 $n-k\le10^{18}$ 无需欧拉降幂（直接二进制快速幂 $O(\log(n-k))$）。$b=0$ 时循环不执行返回 $1$，故 $0^0=1$。证毕。

---

### 定理

程序输出 $k^{k-1}(n-k)^{n-k}\bmod(10^9+7)$，即合法书写方案数。

*证明*：引理 1 刻画函数图轨迹；引理 2 把题目条件等价转化为保持划分 + $A$ 内唯一含 $1$ 环；引理 3 分离两部分并计 $B$；引理 4 拆环双射把 $S(k)$ 化为树计数；引理 5 Prüfer 双射证 Cayley；引理 6 得 $S(k)=k^{k-1}$；引理 7 合并并保证取模与溢出正确。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 每点一条出边 ⇒ 函数图（环 + 内向树）；"走到 $1$" ⟺ 流入 $1$ 所在环，且 $1$ 必须在环上。
2. **reduce to easier problem** — 两条件迫使 $p$ 保持划分 $A=[k]\sqcup B$；$B$ 任意填 $(n-k)^{n-k}$，$A$ 须唯一含 $1$ 环。
3. **explore its property** — 删去环上边 $1\to f(1)$，函数图塌成以 $1$ 为根的树；反之树 + 任选 $f(1)$ 恢复 ⇒ $S(k)=k\cdot T(k)$。
4. **classic problem solution** — Prüfer 序列双射证 Cayley：$k$ 点标号树 $=k^{k-2}$，故 $S(k)=k^{k-1}$。
5. **classic problem solution** — 快速幂求 $(n-k)^{n-k}\bmod P$，指数 $10^{18}$ 用 `long long`；$0^0=1$ 由 `qpow(_,0)=1` 自然处理。

| `k` | 前缀房间数 $\le\min(n,8)$ | `i64` | 读入 |
| `qpow(a,b)` | $a^b\bmod P$，二进制快速幂 | `i64(i64,i64)` | `b=0` 返回 $1$（含 $0^0$） |
| `ans` | $k^{k-1}(n-k)^{n-k}\bmod P$ | `i64` | 两次 `qpow` 相乘取模 |

### 算法步骤

1. I/O 加速三行；读 `n,k`（`i64`）。
2. 计算 `qpow(k,k-1)`（$A$ 部分 $S(k)=k^{k-1}$）。
3. 计算 `qpow((n-k)%p,n-k)`（$B$ 部分 $(n-k)^{n-k}$；$n=k$ 时指数 $0$ 返回 $1$）。
4. 输出两者之积 $\bmod P$。

### 复杂度

- 时间：$O(\log n)$（快速幂指数 $n-k\le10^{18}$，约 $60$ 次平方乘）。
- 空间：$O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$k=1,2,3$ 枚举与公式吻合，$n=3,k=2$ 与 $n=4,k=2$ 手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2817 宋荣子的城堡
// 函数图：条件迫使 p 保持划分 [1..k] / [k+1..n]。
// 外部 (n-k)^(n-k) 任意；内部须唯一含 1 环，拆环成树 ⇒ S(k)=k*k^(k-2)=k^(k-1)。
// 答案 k^(k-1) * (n-k)^(n-k) mod 1e9+7；n=k 时 0^0=1 由 qpow(_,0)=1 处理。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr i64 p{1'000'000'007};

i64 qpow(i64 a,i64 b)
{
	i64 r=1;
	for(;b;b>>=1,a=a*a%p)
		if(b&1)
			r=r*a%p;
	return r;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	i64 n,k;
	cin>>n>>k;
	cout<<qpow(k,k-1)*qpow((n-k)%p,n-k)%p<<'\n';
	return 0;
}
```

### 代码说明

- 全题只有两次快速幂相乘：`qpow(k,k-1)` 是内部 $S(k)=k^{k-1}$，`qpow((n-k)%p,n-k)` 是外部 $(n-k)^{n-k}$。
- `n,k` 用 `i64`：$n\le10^{18}$ 超 `int`。指数 $n-k$ 也在 `i64` 内，直接二进制快速幂，无需欧拉降幂。
- 底数先 `%p`：$n-k$ 可达 $10^{18}$，不取模会在 `a*a` 时溢出；取模后 $a<10^9+7$，$a^2<10^{18}<2^{63}-1$，安全。
- `qpow` 的 `b=0` 返回 $1$：$n=k$ 时外部指数 $0$，自动得到 $0^0=1$（空积），无需特判。
- `k=1` 时 `qpow(1,0)=1`，内部 $S(1)=1$，正确。
