# P2689 东南西北 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 起点 $(x_1,y_1)$、终点 $(x_2,y_2)$，坐标都是 $1\dots50$ 的正整数。接下来 $T\le50$ 个时刻，每个时刻给一个风向：`E`（东，$+x$）、`W`（西，$-x$）、`N`（北，$+y$）、`S`（南，$-y$）。**每个时刻你只有两个选择**：顺着这个风向走 $1$ 个单位，或者原地不动。"不动"不计步数，只有真正偏移才算一步。求走到终点的**最少移动步数**；走不到输出 `-1`。

**第一反应：搜索。** 题目标签写着"模拟, 搜索"，数据又小（$T\le50$，坐标 $\le50$），很自然会想 BFS：状态 $(\text{时刻},x,y)$，每层两条边（走 / 不走），求第一次到达终点时的步数。状态数约 $51\times51\times51\approx1.3\times10^5$，完全跑得动。

但我立刻碰到一个不舒服的地方：**坐标的边界在哪里？** 起点终点都在 $[1,50]$，可是顺风走完全可以走出这个范围（比如在 $(1,1)$ 遇到 `W`，走到 $(0,1)$；题目没说不能出去，也没说出去就失败）。BFS 要开多大的网格？$[-50,100]^2$ 是我拍脑袋定的，凭什么保证够？这种"靠猜边界"的写法让我警觉：**也许状态里根本不需要坐标。**

**第二步：先做简化版——把 $y$ 轴砍掉。** 假设只有一维，起点 $x_1$、终点 $x_2$，每个时刻的风只能推你 $+1$、$-1$ 或不动。设 $dx=x_2-x_1$：

- 若 $dx>0$：每次 `E` 让你 $+1$，`W` 让你 $-1$。要净赚 $dx$，**至少**要 $dx$ 次 `E`（`W` 只会帮倒忙）。所以只要 `E` 的时刻数 $\ge dx$，答案就是 $dx$；否则永远到不了。
- 若 $dx<0$：对称，需要 $\ge|dx|$ 次 `W`。
- 若 $dx=0$：一步都不用走，答案 $0$。

一维版本是个**纯计数公式**，根本不用搜索。这里的关键观察是：**"不动"是免费的，而且时刻之间没有任何互相约束**——我可以在任意挑选的时刻走，其余时刻全部躺平。所以"顺序"完全不重要，重要的只是"某个方向的风刮了几次"。

**第三步：把增量加回来——两个轴会不会互相干扰？** 检查每种风的作用：`E`/`W` 只改 $x$，`N`/`S` 只改 $y$。**一个时刻的风只有一个方向，所以它要么服务于 $x$ 轴，要么服务于 $y$ 轴，绝不会同时服务两者，也绝不会互相抵消。** 于是：

$$\text{二维问题}=\text{两个独立的一维问题},\qquad \text{答案}=\text{答案}_x+\text{答案}_y.$$

需要的步数下界是 $|dx|+|dy|$（曼哈顿距离），而只要"$x$ 所需方向的风次数够"且"$y$ 所需方向的风次数够"，就能各自挑出互不冲突的时刻达成下界。**搜索被彻底消掉了，剩下一个 $O(T)$ 的计数。**

**第四步：几个必须想清楚的细节。**

1. **早到要不要等？** 题目问"到达终点的最少移动步数"。就算要求"第 $T$ 时刻必须在终点"，也不影响答案：到早了就把剩下的时刻全部选"不动"，位置不变、步数不变。所以"某时刻到达"与"$T$ 时刻在终点"等价（引理 1）。
2. **绕路会不会更省？** 不会。每步只把一个坐标改 $\pm1$，所以净位移 $dx$ 至少要 $|dx|$ 步作用于 $x$ 轴，$dy$ 同理，总步数 $\ge|dx|+|dy|$。而构造恰好达到这个下界，故不可能更省（引理 3 + 引理 5）。特别地，"先反向走再走回来"纯属浪费。
3. **$dx=0$ 时该查哪个方向的计数？** 查 `W` 或 `E` 都行，因为需求是 $0$，任何计数都 $\ge0$。代码里 `dx>0?cnt['E']:cnt['W']` 把 $dx=0$ 归到 `W` 分支，是安全的。
4. **起点就是终点**：$dx=dy=0$，答案 $0$，哪怕 $T$ 个时刻全是反方向的风。
5. **读入**：方向是每行一个字符，`cin>>c` 自动跳过空白与换行，不用管行末。

**手造数据核对。** 题面只给了样例解释（"样例 1：向东走一步，向北走一步"），没有样例输入输出，我自己造了 $8$ 组：

| 输入 | 手算 | 程序 |
|---|---|---|
| `1 1` / `2 2` / `3` / `E N S` | $dx=dy=1$，`E`≥1、`N`≥1 → $2$（对应样例解释） | 2 |
| `1 1` / `3 1` / `2` / `E E` | $dx=2,dy=0$，`E`=2 → $2$ | 2 |
| `1 1` / `2 2` / `2` / `E E` | 缺 `N` → $-1$ | -1 |
| `5 5` / `5 5` / `1` / `W` | 已在终点 → $0$ | 0 |
| `3 4` / `1 1` / `5` / `W W S S N` | 需 2`W`+3`S`，只有 2`S` → $-1$ | -1 |
| `3 4` / `1 1` / `6` / `W W S S S N` | 需 2`W`+3`S`，够 → $5$ | 5 |
| `1 1` / `1 3` / `2` / `N N` | $dx=0$ 走 `W` 分支需求 $0$ → $2$ | 2 |
| `1 1` / `2 1` / `1` / `W` | 要东却只有西风 → $-1$ | -1 |

八组全部与手算一致。

## 二、思维链：完整证明

**记号。** 时刻 $t=1,\dots,T$，风向 $d_t\in\{E,W,N,S\}$，对应位移向量

$$\mathrm{vec}(E)=(1,0),\quad \mathrm{vec}(W)=(-1,0),\quad \mathrm{vec}(N)=(0,1),\quad \mathrm{vec}(S)=(0,-1).$$

一个**策略**是 $u=(u_1,\dots,u_T)\in\{0,1\}^T$，$u_t=1$ 表示第 $t$ 时刻顺风走一步，$u_t=0$ 表示不动。**代价** $\mathrm{cost}(u)=\sum_t u_t$（只有移动计步）。位置递推 $P_0=(x_1,y_1)$，$P_t=P_{t-1}+u_t\cdot\mathrm{vec}(d_t)$。记 $\Delta x=x_2-x_1$、$\Delta y=y_2-y_1$。

策略**成功**定义为 $\exists t\le T,\ P_t=(x_2,y_2)$。答案 $=\min\{\mathrm{cost}(u):u\text{ 成功}\}$，无成功策略时为 $-1$。

对方向 $D$ 记 $\mathrm{cnt}(D)=\#\{t:d_t=D\}$，$e,w,n,s$ 分别表示策略中在 `E`,`W`,`N`,`S` 时刻选择移动的次数，故 $0\le e\le\mathrm{cnt}(E)$ 等。

---

### 引理 1（到达时刻无关：早到可以躺平）

$$\min\{\mathrm{cost}(u):\exists t\le T,\ P_t=(x_2,y_2)\}=\min\{\mathrm{cost}(u):P_T=(x_2,y_2)\}.$$

即"某时刻到达终点"与"第 $T$ 时刻停在终点"两种要求下的最少步数**相同**（两边都无解时同约定为 $+\infty$）。

*证明*：记左边为 $A$、右边为 $B$，分别证 $B\le A$ 与 $A\le B$。

**$B\le A$（躺平引理）**：取达到 $A$ 的策略 $u$，设 $P_{t^\*}=(x_2,y_2)$。构造 $u'$：$u'_t=u_t$ 对 $t\le t^\*$，$u'_t=0$ 对 $t>t^\*$。对 $t\le t^\*$ 位置逐字不变；对 $t>t^\*$，$P'_t=P'_{t-1}+0\cdot\mathrm{vec}(d_t)=P_{t^\*}$，故 $P'_T=(x_2,y_2)$，$u'$ 是右边的可行解。代价 $\mathrm{cost}(u')=\sum_{t\le t^\*}u_t\le\sum_{t\le T}u_t=A$（丢弃的项非负）。故 $B\le\mathrm{cost}(u')\le A$。

**$A\le B$**：任何满足 $P_T=(x_2,y_2)$ 的策略，取 $t=T$ 即满足"存在时刻到达终点"，故右边的可行解集是左边的子集，最小值只会更大或相等：$A\le B$。

两式夹逼得 $A=B$。若两边可行解集皆空，则按约定同为 $+\infty$，等式仍成立。证毕。

**意义**：可以把成功条件统一写成 $P_T=(x_2,y_2)$，不必记录"第一次到达的时刻"，也不必担心"到早了之后被迫继续走"——不动是永远可选的。

---

### 引理 2（两轴解耦：位置的闭式）

对任意策略 $u$，

$$P_T=\bigl(x_1+e-w,\ \ y_1+n-s\bigr).$$

特别地，$P_T=(x_2,y_2)\iff e-w=\Delta x\ \land\ n-s=\Delta y$。

*证明*：把递推展开：$P_T=P_0+\sum_{t=1}^{T}u_t\,\mathrm{vec}(d_t)$（向量加法结合律，逐项代入即得，对 $T$ 归纳平凡）。按方向分组求和：

$$\sum_t u_t\,\mathrm{vec}(d_t)=e\,(1,0)+w\,(-1,0)+n\,(0,1)+s\,(0,-1)=(e-w,\ n-s).$$

这里用到"每个时刻恰有一个方向"，故四个分组**互不重叠**，每个 $u_t$ 恰好被计入一个系数。于是 $x$ 分量只含 $e,w$，$y$ 分量只含 $n,s$，两轴无任何交叉项。等价条件由分量相等即得。证毕。

**这条引理是全题的支点**：它把"二维网格上的路径搜索"变成了"四个非负整数的线性方程组 + 上界约束"。

---

### 引理 3（下界：曼哈顿距离）

任何成功策略满足 $\mathrm{cost}(u)\ge|\Delta x|+|\Delta y|$。

*证明*：先证一个初等不等式：对非负整数 $a,b$，$a+b\ge|a-b|$。事实上 $a+b-|a-b|=2\min(a,b)\ge0$（分 $a\ge b$ 与 $a<b$ 两种情形直接展开绝对值即得）。

由引理 2，成功 ⇒ $e-w=\Delta x$、$n-s=\Delta y$。故

$$\mathrm{cost}(u)=e+w+n+s\ge|e-w|+|n-s|=|\Delta x|+|\Delta y|.$$

证毕。

**推论（绕路无益）**：任何"先反向再折返"的移动都会让 $\min(e,w)$ 或 $\min(n,s)$ 变正，从而把代价抬到下界之上；最优策略必然满足 $\min(e,w)=0$ 且 $\min(n,s)=0$，即**每个轴只朝一个方向走**。

---

### 引理 4（必要条件：所需方向的风次数）

若存在成功策略，则

$$\bigl(\Delta x>0\Rightarrow \mathrm{cnt}(E)\ge\Delta x\bigr)\ \land\ \bigl(\Delta x<0\Rightarrow \mathrm{cnt}(W)\ge-\Delta x\bigr)\ \land\ \bigl(\Delta y>0\Rightarrow \mathrm{cnt}(N)\ge\Delta y\bigr)\ \land\ \bigl(\Delta y<0\Rightarrow \mathrm{cnt}(S)\ge-\Delta y\bigr).$$

*证明*：设成功策略的四个计数为 $e,w,n,s$。由引理 2，$e-w=\Delta x$。

- 若 $\Delta x>0$：$e=\Delta x+w\ge\Delta x$（$w\ge0$）。又每个 `E` 时刻至多贡献一次移动（$u_t\in\{0,1\}$），故 $e\le\mathrm{cnt}(E)$。夹逼得 $\mathrm{cnt}(E)\ge\Delta x$。
- 若 $\Delta x<0$：$w=e-\Delta x=e+|\Delta x|\ge|\Delta x|$，同理 $w\le\mathrm{cnt}(W)$，得 $\mathrm{cnt}(W)\ge|\Delta x|$。
- 若 $\Delta x=0$：无约束（$e=w$ 即可，取 $e=w=0$ 最省）。

$y$ 轴完全对称。证毕。

**注意 $\Delta x=0$ 的情形**：此时不需要任何 $x$ 方向的风，代码里把它归到 `W` 分支去查 $\mathrm{cnt}(W)\ge0$，恒真，不会误判。

---

### 引理 5（充分性：计数够就能构造出达到下界的策略）

若引理 4 的四个条件全部成立，则存在成功策略且代价恰为 $|\Delta x|+|\Delta y|$。

*证明*：显式构造。定义四个"需求时刻集合"：

$$\mathcal E=\begin{cases}\text{任选 }\Delta x\text{ 个 }d_t=E\text{ 的时刻},&\Delta x>0\\ \varnothing,&\Delta x\le0\end{cases}\qquad
\mathcal W=\begin{cases}\text{任选 }|\Delta x|\text{ 个 }d_t=W\text{ 的时刻},&\Delta x<0\\ \varnothing,&\Delta x\ge0\end{cases}$$

$\mathcal N,\mathcal S$ 对 $y$ 轴同理。由引理 4 的条件，所需个数都 $\le$ 对应方向的可用时刻数，故"任选"总是可行（有限集合中取指定大小的子集）。

**四个集合两两不交**：$\mathcal E$ 与 $\mathcal W$ 不交，因为 $\Delta x>0$ 与 $\Delta x<0$ 互斥（至少一个为空）；$\mathcal E,\mathcal W$ 中的时刻风向属于 $\{E,W\}$，$\mathcal N,\mathcal S$ 中的属于 $\{N,S\}$，而每个时刻风向唯一，故跨轴也不交。

令 $u_t=1\iff t\in\mathcal E\cup\mathcal W\cup\mathcal N\cup\mathcal S$，其余 $u_t=0$。由不交性，$e=|\mathcal E|=\max(\Delta x,0)$、$w=|\mathcal W|=\max(-\Delta x,0)$、$n=\max(\Delta y,0)$、$s=\max(-\Delta y,0)$。于是

$$e-w=\max(\Delta x,0)-\max(-\Delta x,0)=\Delta x,\qquad n-s=\Delta y,$$

（恒等式 $\max(a,0)-\max(-a,0)=a$ 对任意实数 $a$ 成立，分 $a\ge0$、$a<0$ 验证即可）。由引理 2，$P_T=(x_2,y_2)$，策略成功。代价

$$\mathrm{cost}(u)=e+w+n+s=|\Delta x|+|\Delta y|$$

（因为 $e,w$ 中恰一个非零，$n,s$ 同理）。证毕。

---

### 定理（答案公式）

$$\text{答案}=\begin{cases}|\Delta x|+|\Delta y|,&\text{引理 4 的四个条件全部成立}\\-1,&\text{否则}\end{cases}$$

*证明*：条件成立时，引理 5 给出代价 $|\Delta x|+|\Delta y|$ 的成功策略，引理 3 给出同值的下界，故最优值恰为 $|\Delta x|+|\Delta y|$。条件不成立时，引理 4 的逆否命题说明不存在成功策略，按题意输出 $-1$。两情形穷尽。证毕。

**代码判据与定理的对应**：`nx = dx>0?cnt['E']:cnt['W']`，`ny = dy>0?cnt['N']:cnt['S']`；`nx<abs(dx)||ny<abs(dy)` 恰是引理 4 条件的否定（$\Delta x=0$ 时 `abs(dx)=0`，判据恒假，与"无约束"一致）。

---

### 引理 6（BFS 路线为什么可以扔掉）

状态 $(t,x,y)$ 的 BFS 也能给出正确答案，但需要人为设定坐标范围，且复杂度 $O(T\cdot X\cdot Y)$ 严格劣于 $O(T)$。

*证明*：正确性方面：由引理 1，可把目标统一为 $P_T$ 终点；BFS 按"移动步数"分层（走一步边权 $1$、不动边权 $0$，需用 0-1 BFS 或把"不动"处理成同层扩展）才能求最少步数——**朴素的按时刻 BFS 求的是"最早到达时刻"，不是"最少步数"**，这是搜索路线的一个隐藏陷阱：例如 $T=3$、风为 `E N E`、$\Delta x=1,\Delta y=1$，最早到达时刻是 $2$（走 `E`,`N`，代价 $2$），但若风为 `N E E` 且 $\Delta x=1,\Delta y=0$，最早到达时刻 $2$ 而最少步数 $1$（第 $1$ 时刻不动、第 $2$ 时刻走 `E`）。两者不同，必须用 0-1 BFS 或 Dijkstra 语义。

范围方面：策略可以在中途走出 $[1,50]$（例如从 $(1,1)$ 遇 `W`），题目未禁止，故 BFS 的网格必须包含所有可能位置。由引理 3 的推论，最优策略不绕路，但**搜索算法本身不知道这一点**，为保正确必须把网格开到 $[1-T,50+T]^2$ 之类，规模 $O(T^2)$ 每层。

而公式法由引理 2–5 严格证明，无需任何坐标范围假设，时间 $O(T)$、额外空间 $O(1)$。故搜索路线在正确性上可实现但更繁琐、在复杂度上更差，应当放弃。证毕。

---

### 引理 7（复杂度与实现边界）

时间 $O(T)$，额外空间 $O(1)$（$4$ 个计数器）。所有中间量的绝对值 $\le 100$，`int` 绰绰有余。

*证明*：读入 $4$ 个坐标与 $T$ 是 $O(1)$；读 $T$ 个字符并自增计数器是 $O(T)$；此后常数次比较与加法。空间：`cnt` 数组按 ASCII 开 $128$ 个 `int`（$512$ B），是与 $T$ 无关的常数。数值范围：$|\Delta x|,|\Delta y|\le49$，$\mathrm{cnt}\le T\le50$，答案 $\le98$，`abs` 与加法均在 `int` 内。证毕。

**实现注意**：全局变量**不要命名为 `y1`/`y0`/`yn`**——`<bits/stdc++.h>` 间接包含的数学头文件在部分平台上把 `y0/y1/yn` 声明为贝塞尔函数，同名全局变量会与之冲突导致编译错误。本文代码用 `sx,sy,tx,ty`。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 每时刻只有"顺风走 $1$ / 不动"两种选择，不动免费 ⇒ 代价只数移动次数，时刻之间无耦合约束。
- **consider easier version** — 先砍掉 $y$ 轴做一维版：答案 $=|\Delta x|$ 当且仅当所需方向的风次数够，是个纯计数公式。
- **explore its property** — `E`/`W` 只改 $x$、`N`/`S` 只改 $y$，且一个时刻只有一个方向 ⇒ 两轴完全解耦，四个方向计数互不重叠。
- **reduce to easier problem** — 二维 = 两个独立一维，答案相加；网格搜索被消掉，连坐标范围都不用假设。
- **classic problem solution** — 曼哈顿距离下界（$a+b\ge|a-b|$）+ 显式构造达到下界 ⇒ 最优值公式。
- **explore its property** — "早到可以躺平"使"某时刻到达"与"$T$ 时刻在终点"等价，去掉了对到达时刻的讨论。
- **discuss by category** — $\Delta x>0$ / $<0$ / $=0$ 三类分别核对需求方向；起点=终点、反向风、缺风等边界逐一验证。
- **discuss by category** — 反思搜索路线：按时刻 BFS 求的是"最早到达时刻"而非"最少步数"，需 0-1 BFS；且要人为猜坐标范围，故放弃。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `sx,sy` | 起点 $(x_1,y_1)$ | `int`，读入 | s = start；**不叫 `x1,y1`**（`y1` 与数学库贝塞尔函数同名） |
| `tx,ty` | 终点 $(x_2,y_2)$ | `int`，读入 | t = target |
| `t` | 时刻数 $T\le50$ | `int`，读入 | 风向字符个数 |
| `mxc` | ASCII 计数桶尺寸 $128$ | `constexpr int{128}` | `cnt[(int)c]`，只用 `E/W/N/S` 四格 |
| `cnt[c]` | 风向字符 `c` 出现的时刻数 | `int[mxc]`，全局默认 $0$ | 计数即"可用移动次数上限" |
| `dx,dy` | $\Delta x=x_2-x_1$、$\Delta y=y_2-y_1$ | `int` | 带符号；`abs` 后是步数下界 |
| `nx` | $x$ 轴所需方向的可用次数 | `int` | `dx>0?cnt['E']:cnt['W']`；`dx==0` 时需求 $0$，恒够 |
| `ny` | $y$ 轴所需方向的可用次数 | `int` | `dy>0?cnt['N']:cnt['S']` |
| 输出 | `abs(dx)+abs(dy)` 或 `-1` | — | 可行 $\iff$ `nx>=abs(dx) && ny>=abs(dy)` |

### 算法步骤

1. I/O 加速三行。
2. 读 `sx,sy,tx,ty,t`。
3. 循环 $T$ 次读字符 `c`，`++cnt[(int)c]`（`cin>>c` 自动跳过换行）。
4. `dx=tx-sx`，`dy=ty-sy`。
5. `nx = dx>0 ? cnt['E'] : cnt['W']`；`ny = dy>0 ? cnt['N'] : cnt['S']`。
6. 若 `nx<abs(dx) || ny<abs(dy)` 输出 `-1`；否则输出 `abs(dx)+abs(dy)`。

### 复杂度

- 时间：$O(T)\le50$ 次字符读入 + 常数次运算。
- 空间：$O(1)$（$128$ 个 `int` 的计数桶，$512$ B）。
- 验证状态：`/d/mingw64/bin/g++.exe -std=c++20 -O2 -Wall -Wextra` 编译零警告；题面无样例输入输出，自造 $8$ 组小数据（含样例解释对应的 `E N S`、$\Delta x=0$、$\Delta y=0$、起点=终点、反向风、缺风、负方向双轴）全部与手算一致。结论已由引理 3（下界）+ 引理 5（构造）夹逼证明，属公式题，未写暴力对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2689 东南西北
// E/W 只改 x，N/S 只改 y ⇒ 两轴解耦，各自是一维计数问题
// 下界 |dx|+|dy|（每步只改一个坐标 1），所需方向风次数够时可构造达到下界
// 于是答案就是曼哈顿距离，或者 -1；不需要搜索，也不需要假设坐标范围
#include<bits/stdc++.h>
using namespace std;

constexpr int mxc{128};	// ASCII 计数桶

int sx,sy,tx,ty,t,cnt[mxc];	// 别用 y1 当变量名：与数学库贝塞尔函数冲突

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>sx>>sy>>tx>>ty>>t;
	for(int i=0;i<t;++i)
	{
		char c;cin>>c;	// 每行一个字符，>> 自动跳过换行
		++cnt[(int)c];
	}
	int dx=tx-sx,dy=ty-sy;
	int nx=dx>0?cnt['E']:cnt['W'];	// dx==0 归到 W 分支，需求 0 恒满足
	int ny=dy>0?cnt['N']:cnt['S'];
	if(nx<abs(dx)||ny<abs(dy))
		cout<<-1<<'\n';
	else
		cout<<abs(dx)+abs(dy)<<'\n';
	return 0;
}
```

### 代码说明

- **`cnt` 按 ASCII 下标计数**：`'E'=69,'W'=87,'N'=78,'S'=83` 都 $<128$，四个桶互不干扰；比写四个 `if` 更省键击，也天然忽略任何非法字符（题目保证只有四种）。
- **`dx>0?cnt['E']:cnt['W']`**：把 $\Delta x=0$ 与 $\Delta x<0$ 合并到同一分支。$\Delta x=0$ 时 `abs(dx)=0`，无论 `cnt['W']` 是多少都满足 `nx>=0`，与引理 4"无约束"一致，不需要额外 `if`。
- **没有坐标数组、没有 vis、没有队列**：引理 2 把位置写成四个计数的线性组合后，网格彻底消失，因此也不必猜"能不能走出 $[1,50]$"。
- **`abs` 用两次**：`abs(dx)+abs(dy)` 就是曼哈顿距离，也是引理 3 的下界与引理 5 的构造值。
- 变量名避开 `y0/y1/yn`：这些名字在部分平台被 `<cmath>` 声明为函数，全局同名变量会编译失败（引理 7 的实现注意）。
