# P2937 [USACO09JAN] Laserphones S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 牧场是 $W\times H$ 的点阵（$1\le W,H\le100$，$W$ 是列数、$H$ 是行数）。`.` 是空地，`*` 是岩石/树等阻挡物，恰好两个 `C` 是两头要通信的奶牛。激光沿直线传播，遇到对角镜 `/` 或 `\` 会偏转 $90^\circ$。求让两头奶牛的激光连通所需安装的**最少镜子数** $M$。题面保证一定有解。

**口径说明。** 输入第 $2..H+1$ 行是地图，每行一个长度为 $W$ 的**连续字符串**（题面示意图里的空格只是排版，真实数据无空格）。行的上下顺序不影响答案（我们只关心格子的四邻接关系），按读入顺序当作 $r=0..H-1$ 即可。`C` 格可通行（激光可以到达/穿过奶牛格）；`*` 格阻挡。镜子只能放在可通行格上，把激光转 $90^\circ$。

**第一步：代价到底是什么？** 激光**直行不花镜子**，只有**转弯才花一面镜子**。所以我们要最小化的不是"走了多少格"，而是"转了多少次弯"。这一点立刻否掉了普通 BFS：普通格子 BFS 最小化的是步数，而一条步数多的直路可能比步数少的弯路更省镜子。例如竖直一条长廊尽头再横拐，步数很大但只需 $1$ 面镜子；普通 BFS 会误以为"绕近路"更好。

**第二步：把"方向"塞进状态。** 既然代价取决于"在哪转弯"，而转弯意味着方向改变，那么光知道"在哪个格子"不够，还得知道"激光正朝哪个方向走"。于是状态设为 **(格子, 方向)**，方向取上/右/下/左四种。在这个状态图上：
- **直行**：$(r,c,d)\to(r+\Delta r_d,\,c+\Delta c_d,\,d)$，目标格可通行时边权 $0$；
- **转弯**：$(r,c,d)\to(r,c,d')$，$d'$ 与 $d$ 垂直，边权 $1$（在 $(r,c)$ 放一面镜子）。

起点奶牛向四个方向**免费发射**激光：$\texttt{dist}[s][d]=0$（$d=0..3$）。终点答案 $=\min_d\texttt{dist}[t][d]$（激光以任意方向到达终点都算连通）。

**第三步：识别经典模型——0/1 边权最短路。** 边权只有 $0$ 和 $1$，这正是 **0-1 BFS** 的适用场景：用双端队列，$0$ 边松弛后入队首、$1$ 边松弛后入队尾，弹出队首即得最终距离。它是 Dijkstra 在 $0/1$ 权下的特化，复杂度 $O(\text{状态数}+\text{边数})=O(WH)$，比堆优化 Dijkstra 还省一个 $\log$。

**第四步：方向编码的小技巧。** 把方向按"上 $0$、右 $1$、下 $2$、左 $3$"排列，则 $d$ 的两个垂直方向恰是 $d\oplus1$ 与 $d\oplus3$（异或），反向是 $d\oplus2$。验证：上 $0$ 的垂直是右 $1$、左 $3$（$0\oplus1=1,0\oplus3=3$ ✓）；右 $1$ 的垂直是上 $0$、下 $2$（$1\oplus1=0,1\oplus3=2$ ✓）；下 $2$、左 $3$ 同理。掉头（$d\oplus2$）需要两面镜子且永远不优，直接不建这条边。

**第五步：几个边界。** 起点四方向已免费初始化，所以在起点"转弯"（花 $1$）永远不优，自动被压制；终点取四方向 min，不需要在终点再转弯。只有两个 `C`，不存在"激光穿过第三头奶牛格还要放镜子"的冲突。障碍 `*` 阻挡直行；转弯发生在当前格（一定可通行，因为我们只走进可通行格）。

**手造数据核对。**

第一组直接用题面地图（$W=7,H=8$）：
```
.......
......C
......*
*****.*
....*..
....*..
.C..*..
.......
```
题面右图给出一种 $3$ 面镜子的方案：左下 `C` 向下到第 $0$ 行放 `\` 右转，沿第 $0$ 行到第 $5$ 列放 `/` 上转，沿第 $5$ 列上行到第 $6$ 行放 `/` 右转接到右上 `C`。程序输出 `3`，与图示一致。

第二组相邻：`2 1` / `CC`，激光直射，$0$ 面镜子，输出 `0`。

第四组需拐一次：`3 3` / `C..` / `...` / `..C`，起点左上、终点右下，L 形拐一次，输出 `1`。

## 二、思维链：完整证明

**记号。** 网格 $H$ 行 $W$ 列，格 $(r,c)$，$0\le r<H,0\le c<W$。可通行 $\iff g[r][c]\ne$ `*`。起点 $s$、终点 $t$ 为两个 `C`。方向集 $D=\{0,1,2,3\}$（上右下左），位移 $(\Delta r,\Delta c)$：$0=(-1,0),1=(0,1),2=(1,0),3=(0,-1)$。状态 $(r,c,d)$。$\texttt{dist}[r][c][d]$ 为从起点激光以方向 $d$ 到达 $(r,c)$ 所需的最少镜子数。

---

### 引理 1（激光路径 = 转弯计数的矩形路径）

一套能连通 $s,t$ 的镜子方案，对应一条从 $s$ 到 $t$、逐格四邻接移动、只经过可通行格的路径；所需镜子数等于该路径的**方向改变次数**（每次 $90^\circ$ 转弯放一面镜子）。反之，任何这样的矩形路径，在其每个转弯格放一面镜子即可实现，镜子数 = 转弯数。故 $M=\min_{\text{路径}}(\text{转弯数})$。

*证明*：
**（方案 $\Rightarrow$ 路径）** 激光从 $s$ 出发沿某方向直行，每遇一面镜子偏转 $90^\circ$，直到到达 $t$。把激光经过的格子按顺序列出，相邻格四邻接（直行或转弯都只跨一格），且都不可能是 `*`（镜子放在可通行格、激光被 `*` 阻挡）。每次偏转就是路径的一次方向改变，对应一面镜子；直行段不花镜子。故镜子数 = 转弯数。
**（路径 $\Rightarrow$ 方案）** 给定矩形路径，在每个方向改变处（转弯格）放一面恰当朝向（`/` 或 `\`）的镜子，把入射方向转成出射方向（两者垂直，恰是一面镜子的能力）；直行段不放镜子。激光沿该路径从 $s$ 走到 $t$，镜子数 = 转弯数。
**掉头不优**：$180^\circ$ 掉头需两面镜子（转两次 $90^\circ$），且把路径折回已走过的格子，删去这段折返只会减少转弯、不破坏连通，故最优路径不含掉头。
两边取最小即 $M=\min(\text{转弯数})$。证毕。

---

### 引理 2（状态图最短路 = 最少镜子数）

构造有向图：顶点为状态 $(r,c,d)$（$(r,c)$ 可通行）；边
- 直行：$(r,c,d)\to(r+\Delta r_d,c+\Delta c_d,d)$，若目标在界内且可通行，权 $0$；
- 转弯：$(r,c,d)\to(r,c,d')$，$d'\perp d$，权 $1$。

源点为 $(s,d)$（$d\in D$），初始距离 $0$。则 $\min_d\texttt{dist}[t][d]$ 等于状态图源到 $\{(t,d)\}$ 的最短路长度，且等于 $M$。

*证明*：由引理 1，一条激光路径的方向序列唯一确定一条状态图路径：直行段对应权 $0$ 的直行边，转弯对应权 $1$ 的转弯边；路径总权 = 转弯数 = 镜子数。起点免费发射对应"四个 $(s,d)$ 都以距离 $0$ 作源"。激光以方向 $d$ 到达 $t$ 对应状态 $(t,d)$，故最优 $=\min_d$ 到 $(t,d)$ 的最短路。反之状态图任一路径还原成一条激光路径（权 $0$ 边直行、权 $1$ 边在该格转弯放镜），权即镜子数。两个方向一一对应且保权，故最短路长度 $=M$。证毕。

---

### 引理 3（方向异或编码）

按上 $0$、右 $1$、下 $2$、左 $3$ 编码，$d$ 的两个垂直方向为 $d\oplus1$ 与 $d\oplus3$，反向为 $d\oplus2$。

*证明*：逐一验证。$d=0$（上）：垂直为右 $1$、左 $3$；$0\oplus1=1$、$0\oplus3=3$ ✓，反向 $0\oplus2=2$（下）✓。$d=1$（右）：垂直为上 $0$、下 $2$；$1\oplus1=0$、$1\oplus3=2$ ✓，反向 $1\oplus2=3$（左）✓。$d=2$（下）：垂直为左 $3$、右 $1$；$2\oplus1=3$、$2\oplus3=1$ ✓，反向 $2\oplus2=0$（上）✓。$d=3$（左）：垂直为下 $2$、上 $0$；$3\oplus1=2$、$3\oplus3=0$ ✓，反向 $3\oplus2=1$（右）✓。四种情形穷尽。证毕。

**推论**：转弯边只需对 `nd∈{d^1,d^3}` 建两条；掉头 $d\oplus2$ 不建（引理 1 已证不优）。

---

### 引理 4（0-1 BFS 正确性）

在边权 $\in\{0,1\}$ 的图上，用双端队列：源距离 $0$ 入队；弹出队首状态 $u$（其距离已最终确定），对每条出边松弛，若改进则 $0$ 边把目标入队首、$1$ 边入队尾。则每个状态被弹出时 $\texttt{dist}$ 即源到它的最短路长度。

*证明*：维护不变量——**队列中状态的距离从队首到队尾单调不减，且最大与最小之差 $\le1$**。
- 初始：源距离 $0$，队列仅含 $0$，成立。
- 弹出队首 $u$，设其距离 $d_u$ 为当前队列最小。由不变量，队列其余距离 $\in\{d_u,d_u+1\}$。任何尚未处理的松弛都来自距离 $\ge d_u$ 的状态，边权 $\ge0$，故不可能产生 $<d_u$ 的新距离来改进 $u$；因此 $d_u$ 已是源到 $u$ 的最短路（Dijkstra 的"最小暂定距离即最终"论证，这里因 $0/1$ 权可用队列代替堆）。
- 松弛 $u$ 的出边：$0$ 边产生距离 $d_u$，入队首——队列最小仍是 $d_u$，单调性保持；$1$ 边产生 $d_u+1$，入队尾——队列最大 $\le d_u+1$，差 $\le1$ 保持。被改进的目标若已在队列中，其旧条目距离更大，留在原处不影响"队首最小"（弹出时用 `done` 跳过已最终化的重复条目）。

由归纳，每个状态首次被弹出（`done` 置真）时距离最终且正确。故 $\texttt{dist}$ 为最短路。证毕。

**实现注**：代码用 `done[r][c][d]` 标记已最终化状态，弹出时若已 `done` 则跳过，保证每状态只处理一次，复杂度线性。

---

### 引理 5（复杂度）

状态数 $4WH$，每状态出边 $\le3$（$1$ 直行 $+2$ 转弯），0-1 BFS 时间 $O(WH)$，空间 $O(WH)$。

*证明*：可通行格 $\le WH$，每格 $4$ 个方向，状态 $\le4WH$。每状态常数次松弛（引理 3、4），每状态最终化一次（`done`），故总操作 $O(4WH)=O(WH)$。空间：$\texttt{dist}$ 与 `done` 各 $4WH$，网格 $WH$，均 $O(WH)$。$W,H\le100$ 时状态 $\le4\times10^4$，极快。证毕。

---

### 定理

程序输出 $\min_d\texttt{dist}[t][d]$，即连通两头奶牛所需的最少镜子数 $M$；时间 $O(WH)$，空间 $O(WH)$。

*证明*：引理 1 把物理问题化为"最小转弯数的矩形路径"；引理 2 把它化为 (格,方向) 状态图上的 $0/1$ 权最短路；引理 3 保证转弯边编码正确；引理 4 保证 0-1 BFS 算出正确最短路；引理 5 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 激光直行免费、转弯花一面镜子：代价是"转弯数"而非"步数"。
2. **consider easier version** — 普通格子 BFS 最小化步数 ⇒ 错（长直路可能比短弯路省镜子），确认要换模型。
3. **reduce to easier problem** — 把"方向"塞进状态 $(r,c,d)$：直行 = $0$ 边、转弯 = $1$ 边 ⇒ $0/1$ 边权最短路。
4. **classic problem solution** — 0-1 BFS（双端队列，$0$ 边入首、$1$ 边入尾，`done` 去重），$O(WH)$，是 Dijkstra 的 $0/1$ 特化。
5. **discuss by category** — 起点四方向免费发射、终点取四方向 min；垂直方向用 $d\oplus1,d\oplus3$；掉头不优跳过；`*` 阻挡、`C` 可通行。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $W,H$ | 列数、行数 | `int w,h` | 读入 |
| `g[r][c]` | 地图字符 | `char[mxn][mxn]` | 逐行 `cin>>g[r]` |
| `sr,sc` / `tr,tc` | 起点 / 终点 `C` 的行列 | `int` | 扫描时第一个 `C` 为起点、第二个为终点 |
| `dr[4],dc[4]` | 上右下左的位移 | `constexpr int[4]` | $\{-1,0,1,0\},\{0,1,0,-1\}$ |
| `dist[r][c][d]` | 以方向 $d$ 到达 $(r,c)$ 的最少镜子数 | `int[mxn][mxn][4]` | **`fill` 成 `inf`**；起点四方向置 $0$ |
| `done[r][c][d]` | 该状态距离是否已最终化 | `bool[mxn][mxn][4]` | 全局默认 `false` |
| `Q` | 0-1 BFS 双端队列，元素 `{r,c,d}` | `deque<array<int,3>>` | 起点四状态入队首 |
| `inf` | 不可达哨兵 $1145141919$ | `constexpr int` | 保证有解，答案 $<$ `inf` |

### 算法步骤

1. I/O 加速三行。
2. 读 $W,H$；逐行读 `g[r]`，扫描记录两个 `C` 为 $(sr,sc),(tr,tc)$。
3. `fill_n(&dist[0][0][0],mxn*mxn*4,inf)`。
4. 对 $d=0..3$：`dist[sr][sc][d]=0`，`{sr,sc,d}` 入队首。
5. 0-1 BFS：弹队首 `{r,c,d}`，若 `done` 跳过否则置 `done`；取 `cur=dist[r][c][d]`。
   - 直行：$(nr,nc)=(r+dr[d],c+dc[d])$，在界内、非 `*`、`cur<dist[nr][nc][d]` 时更新并入队首。
   - 转弯：对 `nd∈{d^1,d^3}`，`cur+1<dist[r][c][nd]` 时更新并入队尾。
6. 答案 `ans=min_d dist[tr][tc][d]`，输出 `ans` 与 `'\n'`。

### 复杂度

- 时间：$O(WH)$（状态 $4WH$，每状态常数松弛）。
- 空间：$O(WH)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面地图输出 `3` 与图示一致；另造"相邻 0""同行 0""L 形 1""竖墙缺口 2"四组手算数据全对；$100\times100$ 开阔网格对角 `C` 输出 `1`（L 形）正确。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2937 [USACO09JAN] Laserphones S
// 状态 (格,方向)：直行边权 0，转弯(放镜子)边权 1 ⇒ 0-1 BFS
// 方向 上0 右1 下2 左3，垂直方向 = d^1 与 d^3；答案 = min_d dist[终点][d]
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105},inf{1145141919};
constexpr int dr[4]{-1,0,1,0},dc[4]{0,1,0,-1};

int w,h,dist[mxn][mxn][4];
char g[mxn][mxn];
bool done[mxn][mxn][4];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>w>>h;
	int sr=-1,sc=-1,tr=-1,tc=-1;
	for(int r=0;r<h;++r)
	{
		cin>>g[r];
		for(int c=0;c<w;++c)
			if(g[r][c]=='C')
			{
				if(sr<0)sr=r,sc=c;
				else tr=r,tc=c;
			}
	}
	fill_n(&dist[0][0][0],mxn*mxn*4,inf);
	deque<array<int,3>>Q;
	for(int d=0;d<4;++d)
	{
		dist[sr][sc][d]=0;	// 起点向任意方向免费发射激光
		Q.push_front({sr,sc,d});
	}
	while(!Q.empty())
	{
		auto[r,c,d]=Q.front();Q.pop_front();
		if(done[r][c][d])continue;
		done[r][c][d]=true;
		int cur=dist[r][c][d];
		int nr=r+dr[d],nc=c+dc[d];
		if(nr>=0&&nr<h&&nc>=0&&nc<w&&g[nr][nc]!='*'&&cur<dist[nr][nc][d])
		{
			dist[nr][nc][d]=cur;	// 直行 0 代价，入队首
			Q.push_front({nr,nc,d});
		}
		for(int nd:{d^1,d^3})
			if(cur+1<dist[r][c][nd])
			{
				dist[r][c][nd]=cur+1;	// 原地放镜子转 90°，1 代价，入队尾
				Q.push_back({r,c,nd});
			}
	}
	int ans=inf;
	for(int d=0;d<4;++d)
		ans=min(ans,dist[tr][tc][d]);
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **状态必须带方向**：`dist[r][c][d]` 三维。只记格子会丢失"朝哪走"，无法区分直行（$0$）与转弯（$1$），这是全题的建模关键。
- **`fill_n(&dist[0][0][0],mxn*mxn*4,inf)`**：三维全局数组默认 $0$ 不是 INF，必须显式填，否则所有状态一开始就被当成"零镜子可达"。
- `for(int nd:{d^1,d^3})` 用异或枚举两个垂直方向（引理 3），掉头 $d\oplus2$ 不建边。
- 直行入 `push_front`、转弯入 `push_back` 是 0-1 BFS 的灵魂；`done` 去重保证每状态只最终化一次（引理 4）。
- 起点四方向都置 $0$ 入队（免费发射）；终点取四方向 `min`（任意方向到达即连通）。
- 转弯发生在当前格，当前格必可通行（只走进非 `*` 格、起点是 `C`），故转弯无需再判障碍。
