# P2724 [IOI 1998 / USACO3.1] 联系 Contact — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给一个只含 `0`/`1` 的字符串 $s$（$|s|\le 2\times 10^5$，分若干行给出，按顺序拼接），以及 $A,B,n$（$1\le A\le B\le 12$，$1\le n\le 50$）。要统计所有**长度在 $[A,B]$ 的比特序列**在 $s$ 中的出现次数（**位置可重叠**，每个至少出现一次的序列都要计数），输出出现频率最高的前 $n$ 个。排序规则：频率降序；频率相同按长度升序；长度也相同按二进制数值升序。输出时按频率分组：每组先单独一行输出频率值，再输出该频率的序列，**每行 $6$ 个**（不足 $6$ 个则一行），空格分隔。若不同序列总数少于 $n$，输出全部。

**第一步：先估规模，决定能不能暴力。** 长度 $\le 12$ 的比特序列总共 $\sum_{L=1}^{12}2^L=2^{13}-2=8190$ 个，很少。但 $s$ 长达 $2\times 10^5$。若对每个序列都扫一遍 $s$ 去匹配，是 $8190\times 2\times 10^5\approx 1.6\times 10^9$，太慢。换个方向：**对 $s$ 的每个位置，把它结尾的所有长度 $A..B$ 的窗口各记一次**，窗口总数 $\le |s|\times(B-A+1)\le 2\times 10^5\times 12=2.4\times 10^6$，完全可行。这是"枚举窗口"而非"枚举模式"的视角转换。

**第二步：固定长度 $L$ 时，怎么 $O(1)$ 拿到每个窗口？** 用**滚动哈希 / 滑动窗口**：维护一个整数 $v$ 表示当前末 $L$ 位的数值。读入新位 $b$ 时 `v=((v<<1)|b)&mask`，其中 `mask=(1<<L)-1` 把超出 $L$ 位的高位截掉。这样每步 $O(1)$，扫一遍 $s$ 就统计完所有长度 $L$ 的窗口。对 $L=A..B$ 各扫一遍，总 $O(|s|(B-A+1))$。

**第三步：为什么这样计数恰好"可重叠、不重不漏"。** 一个长度 $L$ 的序列 $w$ 在 $s$ 中的一次出现，由它的**结束位置** $i$ 唯一确定（起点 $=i-L+1$）。当扫描到 $i\ge L-1$ 时，窗口 $s[i-L+1..i]$ 恰好是一个长度 $L$ 的序列，`++cnt[L][v]` 给它记一票。不同的结束位置 = 不同的出现（即使内容相同、即使重叠），各记一票；每个出现也恰被记一次。所以 `cnt[L][v]` 就是序列 $(L,v)$ 的出现次数，重叠自然被计入。

**第四步：排序键怎么定。** 每个序列由 (长度 $L$, 数值 $v$) 唯一确定（长度定了位数，数值定了每一位）。题目三级排序：频率 $c$ 降、长度 $L$ 升、数值 $v$ 升。注意"二进制数值升序"在**同长度**下就是整数 $v$ 升序（前导零不影响数值），所以比较器直接写 `c 降 → L 升 → v 升`。把所有 `cnt>0` 的 $(c,L,v)$ 收进数组排序，取前 $\min(n,\text{tot})$ 个。

**第五步：输出格式是最容易翻车的地方。** 排序后相同频率的序列必然**连续**成段。对每一段：先 `cout<<频率<<'\n'`；再段内每 $6$ 个一行，序列间空格分隔，行末（每满 $6$ 个或段尾）换行。序列要**按 $L$ 位输出、保留前导零**（例如 $L=2,v=0$ 输出 `00`），所以从高位到低位逐位 `cout<<((v>>b)&1)`。我用 `(k-i)%6` 控制"非行首才打空格"、`(k-i)%6==5||k==j-1` 控制换行，避免行尾多余空格。

**第六步：边界。** 不同序列总数 `tot` 可能 $<n$（例如 $s$ 全 $0$，只有 $B-A+1$ 个序列），取 `min(n,tot)` 即可。$|s|<A$ 时一个窗口都没有，`tot=0`，输出为空。多行输入用 `while(cin>>t)s+=t` 拼接（$s$ 只含 `0`/`1`，每行就是一个 token）。

**手造数据核对**（题面只给了样例解释的文字，没有完整样例输入输出，我自造）：

1. `A=1,B=2,n=50`，$s=$`010101`：长度 $1$ 的 `0`,`1` 各 $3$ 次；长度 $2$ 的 `01` $3$ 次（位置 $0,2,4$）、`10` $2$ 次（位置 $1,3$）。排序：频率 $3$ 组按长度升、数值升 → `0 1 01`；频率 $2$ 组 → `10`。输出：
   ```

   ```
   这组同时打了"频率相同先比长度（`0`,`1` 在 `01` 前）"和"同长度比数值（`0` 在 `1` 前）"。

2. `A=3,B=3,n=50`，$s=$`0001011100`（$3$ 阶 de Bruijn 序列）：$8$ 个长度 $3$ 的序列各出现 $1$ 次，按数值升序 `000 001 010 011 100 101 110 111`，每行 $6$ 个 → 第一行 $6$ 个、第二行 $2$ 个：

## 二、思维链：完整证明

**记号。** $s[0..len-1]\in\{0,1\}$。长度 $L\in[A,B]$，窗口值 $v\in[0,2^L)$。$\text{cnt}[L][v]$ 为序列"长度 $L$、数值 $v$"的出现次数。序列与二元组 $(L,v)$ 一一对应。$\text{all}[]$ 收集所有 $\text{cnt}>0$ 的 $(c,L,v)$，$\text{tot}$ 为其个数。

---

### 引理 1（滚动窗口不变量）

对固定 $L$，令 $v_0=0$，$v_{i+1}=((v_i\ll 1)\,|\,s[i])\ \&\ (2^L-1)$。则对每个 $i\ge 0$，$v_{i+1}$ 等于子串 $s[\max(0,i-L+1)..i]$ 的二进制数值。特别地，$i\ge L-1$ 时 $v_{i+1}$ 是长度恰为 $L$ 的窗口 $s[i-L+1..i]$ 的数值。

*证明*：对 $i$ 归纳。$i=0$：$v_1=(0\ll 1|s[0])\&(2^L-1)=s[0]$（$s[0]<2\le 2^L$），而 $\max(0,0-L+1)=0$，子串 $s[0..0]=s[0]$ ✓。

设 $v_i$ 是 $s[\max(0,i-1-L+1)..i-1]=s[\max(0,i-L)..i-1]$ 的数值，该子串长度 $\ell=\min(i,L)\le L$。则 $v_i<2^\ell\le 2^L$。左移一位或上 $s[i]$：$(v_i\ll 1)|s[i]$ 是 $s[\max(0,i-L)..i]$ 的数值，长度 $\ell+1\le L+1$。
- 若 $\ell+1\le L$：该值 $<2^{\ell+1}\le 2^L$，`& (2^L-1)` 不截断，结果即 $s[\max(0,i-L)..i]$；此时 $\max(0,i-L+1)=\max(0,i-L)$（因 $i-L+1\le 0$ 当 $i<L$），与目标一致。
- 若 $\ell+1=L+1$（即 $i\ge L$）：该值有 $L+1$ 位，`& (2^L-1)` 恰截掉最高位 $s[i-L]$，留下低 $L$ 位 $=s[i-L+1..i]$ 的数值，与目标 $\max(0,i-L+1)=i-L+1$ 一致。

两种情形都成立，归纳完成。证毕。

---

### 引理 2（计数 = 出现次数，重叠计入、不重不漏）

扫描结束后 $\text{cnt}[L][v]$ 等于序列 $(L,v)$ 在 $s$ 中的出现次数（位置可重叠）。

*证明*：序列 $(L,v)$ 的一次出现是一个起点 $p$（$0\le p\le len-L$）使 $s[p..p+L-1]$ 的数值为 $v$；等价地由结束位置 $i=p+L-1$（$L-1\le i\le len-1$）唯一确定。代码在每一步 $i\ge L-1$ 执行 `++cnt[L][v_{i+1}]`，由引理 1，$v_{i+1}$ 正是窗口 $s[i-L+1..i]$ 的数值。于是：
- **不漏**：每个出现对应唯一的 $i\in[L-1,len-1]$，该步必给对应 $(L,v)$ 记一票。
- **不重**：每个 $i$ 只产生一个窗口、只记一票；不同出现对应不同 $i$，互不干扰。
- **重叠计入**：两个重叠的出现有不同的结束位置 $i$，各记一票，故重叠不被合并。

因此 $\text{cnt}[L][v]$ 恰为出现次数。证毕。

---

### 引理 3（序列空间上界与唯一标识）

不同序列总数 $\text{tot}\le\sum_{L=A}^{B}2^L\le 2^{B+1}-2^A\le 8190$；每个序列由 $(L,v)$ 唯一确定，故 $\text{all}[]$ 中无重复元素。

*证明*：长度 $L$ 的比特序列共 $2^L$ 个，长度范围 $[A,B]$ 故总数 $\le\sum_{L=A}^{B}2^L=2^{B+1}-2^A\le 2^{13}-2=8190$（$B\le 12$）。一个序列的位数 $=L$、各位由数值 $v$ 的二进制表示（含前导零）唯一给出，故 $(L,v)$ 与序列一一对应。收集时对每个 $(L,v)$ 至多 push 一次（`cnt[L][v]>0` 判断），无重复。数组 `all[8200]` 足够（$8190+10$ 松弛）。证毕。

---

### 引理 4（比较器 = 题目排序规则）

比较器"`c$ 降 → $L$ 升 → $v$ 升"在 $\text{all}[]$ 上实现题目的三级排序，且是严格全序（无歧义）。

*证明*：题目规则：频率高者优先（$c$ 降）；频率同则短者优先（$L$ 升）；长度同则二进制数值小者优先。对同长度 $L$，序列的二进制数值就是整数 $v$（前导零不改变数值），故"数值升序"$=v$ 升序。比较器三级依次对应这三条。

严格全序：$\text{all}[]$ 中元素 $(c,L,v)$ 的 $(L,v)$ 互不相同（引理 3）。对任意两个不同元素，若 $c$ 不同则第一级定序；$c$ 同 $L$ 不同则第二级定序；$c,L$ 同则 $v$ 必不同（否则 $(L,v)$ 重复），第三级定序。故任意两元素恰有一个方向成立，排序结果唯一确定。证毕。

---

### 引理 5（前 $n$ 与分组正确）

取排序后前 $\text{take}=\min(n,\text{tot})$ 个即题目所求；相同频率的元素在排序后连续成段，逐段输出即"按频率分组"。

*证明*：题目要"频率最高的前 $n$ 个"，即按引理 4 全序排序后的前 $n$ 个；不足 $n$ 则全部，故 $\text{take}=\min(n,\text{tot})$。

分组：排序后序列按 $c$ 降序排列，故相同 $c$ 的元素必连续（若 $c$ 相同的两元素之间夹了别的元素，该元素 $c$ 要么更大要么更小，违反降序）。代码用双指针 `i,j` 扫出极大等 $c$ 段 $[i,j)$，每段先输出 $c$ 再输出段内序列，正是"每个频率先输出一行频率值、再输出该频率的序列"。证毕。

---

### 引理 6（输出格式：前导零、每行 6 个、空格分隔）

段内第 $k$ 个序列（段内序号 $r=k-i$）按 $L$ 位输出（含前导零）；$r\bmod 6\ne 0$ 时前置空格；$r\bmod 6=5$ 或 $k=j-1$（段尾）时换行。这与"每行 $6$ 个、空格分隔、不足 $6$ 个一行"一致，且无行尾多余空格。

*证明*：前导零：从 $b=L-1$  downto $0$ 输出 $(v\gg b)\&1$，恰输出 $L$ 位（高位为 $0$ 也输出），故 $L=2,v=0$ 输出 `00` ✓。

行结构：段内序号 $r=0,1,2,\dots$。$r\bmod 6=0$（行首）不打空格，否则打一个空格分隔，故每行内序列间恰一个空格、行首无空格。换行条件 $r\bmod 6=5$（该行第 $6$ 个，满 $6$ 换行）或 $k=j-1$（段尾，不足 $6$ 也换行）。于是每行恰 $6$ 个（最后一行可能不足），段尾必换行，下一段的频率值另起一行。行尾无多余空格（空格只在非行首元素前打）。证毕。

---

### 引理 7（复杂度）

时间 $O(|s|(B-A+1)+2^{B+1}\log(2^{B+1})+\text{输出量})$，空间 $O(2^{B+1}\cdot B+|s|)$。

*证明*：统计：对 $L=A..B$ 各扫一遍 $s$，每步 $O(1)$，共 $O(|s|(B-A+1))\le 2.4\times 10^6$。收集：遍历 $\sum 2^L\le 8190$ 个 $(L,v)$，$O(2^{B+1})$。排序：$\text{tot}\le 8190$，$O(\text{tot}\log\text{tot})\le 8190\times 13\approx 10^5$。输出：$\text{take}\le 50$ 个序列、每个 $\le 12$ 位，$O(50\times 12)$。合计 dominated by $O(|s|(B-A+1))$。

空间：`cnt[13][4096]` 约 $213$ KB，`all[8200]` 约 $98$ KB，$s$ 约 $200$ KB，合计 $O(2^{B+1}B+|s|)$。实测 $|s|=2\times 10^5,A=1,B=12$ 约 $0.07$ 秒。证毕。

### 定理

程序正确统计所有长度 $[A,B]$ 序列的重叠出现次数，按题目三级排序输出前 $\min(n,\text{tot})$ 个，并按频率分组、每行 $6$ 个、保留前导零；复杂度如引理 7。

*证明*：引理 1、2 保证计数正确；引理 3 保证序列空间与唯一标识；引理 4 保证排序规则；引理 5 保证前 $n$ 与分组；引理 6 保证输出格式；引理 7 保证复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — $B\le 12$ ⇒ 序列至多 $8190$ 个；$|s|\le 2\times 10^5$ ⇒ 枚举窗口（$2.4\times 10^6$）而非枚举模式匹配（$1.6\times 10^9$）。
- **consider easier version** — 固定长度 $L$：滑动窗口 `v=((v<<1)|bit)&mask` 每步 $O(1)$ 拿到末 $L$ 位数值。
- **explore its property** — 出现 ↔ 结束位置一一对应 ⇒ 每个窗口记一票即"可重叠、不重不漏"计数。
- **classic problem solution** — 三级比较器排序（频率降 / 长度升 / 数值升）；$(L,v)$ 唯一标识序列，同长度数值序 = 整数序。
- **reduce to easier problem** — 排序后同频率连续成段 ⇒ 双指针分段，把"分组输出"化为逐段处理。
- **discuss by category** — 输出格式：前导零逐位打印、每行 $6$ 个、空格只在非行首、段尾换行；$\text{tot}<n$ 取全部、$|s|<A$ 输出空。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `A,B,n` | 长度下/上界、输出个数 | `int`，读入 | $1\le A\le B\le 12$，$n\le 50$ |
| `s` | 拼接后的完整比特串 | `string` | `while(cin>>t)s+=t` |
| `cnt[L][v]` | 长度 $L$、数值 $v$ 的序列出现次数 | `int[13][4096]`，全 $0$ | 滚动窗口累加 |
| `all[tot]` | 所有出现过的序列 `(c,L,v)` | `node[8200]`，`tot=0` | $c$=次数，$L$=长度，$v$=数值 |
| `mask` | $(1\ll L)-1$，截断用 | `int` | 保留末 $L$ 位 |
| `take` | 实际输出个数 $\min(n,\text{tot})$ | `int` | 不足 $n$ 输出全部 |
| `mxl,mxv` | $13$、$4096$ | `constexpr int` | $L\le 12$，$v<2^{12}$ |

### 算法步骤

1. I/O 加速三行；读 `A,B,n`；`while(cin>>t)s+=t` 拼接。
2. 对 `L=A..B`：`v=0,mask=(1<<L)-1`；扫 `i=0..len-1`：`v=((v<<1)|(s[i]-'0'))&mask`；若 `i>=L-1` 则 `++cnt[L][v]`。
3. 收集：对 `L=A..B`、`v=0..(1<<L)-1`，若 `cnt[L][v]>0` 则 `all[tot++]={cnt[L][v],L,v}`。
4. 排序 `all[0..tot)`：`c` 降 → `L` 升 → `v` 升。
5. `take=min(n,tot)`；双指针 `i` 扫段：`j` 扩到等 `c` 段尾；输出 `all[i].c` 换行；段内 `k=i..j-1`：非行首打空格，逐位输出 $L$ 位（含前导零），满 $6$ 或段尾换行；`i=j`。

### 复杂度

- 时间：$O(|s|(B-A+1)+2^{B+1}\log 2^{B+1})\le 2.5\times 10^6$，实测极限 $0.07$ 秒。
- 空间：$O(2^{B+1}B+|s|)\approx 0.5$ MB。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译无警告；$5$ 组手造样例（长度/数值平局、de Bruijn 每行 $6$ 个换行、取前 $n$、多行拼接、$|s|<A$ 空输出）全部与手算一致；$|s|=2\times 10^5$ 极限数据 $0.07$ 秒。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2724 [IOI 1998 / USACO3.1] 联系 Contact
// B≤12 ⇒ 不同序列至多 8190 个；对每个长度 L 用滚动窗口 O(|s|) 统计出现次数（可重叠）。
// 按 (频率降, 长度升, 数值升) 排序取前 n，同频率分组、每行 6 个输出。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxl{13},mxv{4096};

int A,B,n,cnt[mxl][mxv],tot;
string s;
struct node{int c,L,v;}all[8200];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>A>>B>>n;
	string t;
	while(cin>>t)
		s+=t;	// 逐行读入并按顺序拼接
	int len=s.size();
	for(int L=A;L<=B;++L)
	{
		int v=0,mask=(1<<L)-1;
		for(int i=0;i<len;++i)
		{
			v=((v<<1)|(s[i]-'0'))&mask;	// 滚动保留末 L 位
			if(i>=L-1)
				++cnt[L][v];
		}
	}
	for(int L=A;L<=B;++L)
		for(int v=0;v<(1<<L);++v)
			if(cnt[L][v])
				all[tot++]={cnt[L][v],L,v};
	sort(all,all+tot,[](node a,node b){
		if(a.c!=b.c)return a.c>b.c;
		if(a.L!=b.L)return a.L<b.L;
		return a.v<b.v;
	});
	int take=min(n,tot);
	for(int i=0;i<take;)
	{
		int j=i;
		while(j<take&&all[j].c==all[i].c)
			++j;
		cout<<all[i].c<<'\n';
		for(int k=i;k<j;++k)
		{
			if((k-i)%6)
				cout<<' ';
			for(int b=all[k].L-1;b>=0;--b)
				cout<<((all[k].v>>b)&1);
			if((k-i)%6==5||k==j-1)
				cout<<'\n';
		}
		i=j;
	}
	return 0;
}
```

### 代码说明

- **滚动窗口**：`v=((v<<1)|(s[i]-'0'))&mask` 每步 $O(1)$ 维护末 $L$ 位；`i>=L-1` 才开始计数，避免把不足 $L$ 位的前缀误计。
- **计数即出现次数**：每个结束位置记一票，重叠出现因结束位置不同而各记一票（引理 2）。
- **三级比较器**：`c` 降 → `L` 升 → `v` 升；同长度下数值序就是整数序，前导零不影响比较。
- **输出格式**：`(k-i)%6` 控制空格（行首不打），`(k-i)%6==5||k==j-1` 控制换行（满 $6$ 或段尾），逐位打印保留前导零。这是本题最易错处，务必无行尾空格。
- **`all[8200]`**：$\sum_{L=1}^{12}2^L=8190$，留 $10$ 松弛；`cnt[13][4096]` 覆盖 $L\le 12,v<4096$。
- **边界**：`take=min(n,tot)` 处理不足 $n$；$|s|<A$ 时 `tot=0`，外层循环不执行，输出空。
