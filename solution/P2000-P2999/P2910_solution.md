# P2910 [USACO08OPEN] Clear And Present Danger S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 给定 $N$ 个点的**完全有向图**（$1\le N\le 100$）：任意有序对 $(i,j)$ 都有一条边，危险指数 $D_{i,j}\in[0,10^5]$，$D_{i,i}=0$，且**不保证对称**（$D_{i,j}\ne D_{j,i}$ 完全可能）。再给一个长度 $M$ 的必经序列 $A_1,\dots,A_M$（$2\le M\le 10^4$，$A_1=1$，$A_M=N$）。要从 $1$ 走到 $N$，使得航行轨迹（一个点序列，**允许重复经过任何点**）把 $A_1,\dots,A_M$ 作为**子序列**包含（"依次出现、不一定相邻"），最小化经过的所有边的危险指数之和。

**第一步：把"子序列约束"翻译成段。** 关键词是"不一定相邻"与样例说明里的"回到 $1$ 号岛屿"——轨迹可以反复折返。一条合法轨迹长这样：

$$1=v_0,v_1,\dots,v_T=N,\qquad \exists\ t_1<t_2<\cdots<t_M,\ v_{t_i}=A_i.$$

在这些"打卡点"处把轨迹剪开，得到 $M-1$ 段：第 $i$ 段是从 $A_i$ 到 $A_{i+1}$ 的一条**任意行走**（walk，可重复点）。反过来，把任意 $M-1$ 条"从 $A_i$ 到 $A_{i+1}$ 的行走"首尾拼接，打卡点就取在拼接处，必然合法。于是：

$$\text{答案}=\sum_{i=1}^{M-1}\mathrm{dis}(A_i,A_{i+1}),$$

其中 $\mathrm{dis}(u,v)$ 是 $u\to v$ 的最短路。**下界**：每段费用 $\ge\mathrm{dis}$，打卡点之外的前后缀费用非负；**上界**：取每段的最短路拼接即达。这一步把"带顺序约束的路径规划"彻底拆成了 $M-1$ 个独立的最短路查询——顺序约束本身不再产生任何额外代价。

这里要停一下确认两个容易疑心的点：

- **会不会"抄近路时顺便提前打卡"更优？** 不会更优也不会更差：下界论证对**任何**一组合法打卡位置都成立，拼接方案只是恰好达到下界的一个构造。提前打卡只是换了组 $t_i$，不改变下界。
- **相邻两个 $A$ 相同怎么办？** $\mathrm{dis}(u,u)=0$（不走即可），段费用为 $0$，公式照用。

**第二步：选最短路算法。** 查询次数 $M-1\le 9999$，点数 $N\le100$。

- 每次查询跑一遍 Dijkstra：$O(M N^2)\approx 10^8$（稠密图朴素 Dijkstra），能过但笨重；
- **Floyd**：一次 $O(N^3)=10^6$ 预处理出**全源**最短路，之后每次查询 $O(1)$ 查表。总量 $10^6+10^4$，毫无压力。

查询这么多、点这么少，Floyd 是天选。而且图是完全图，读入的矩阵**本身就是初始距离矩阵**，连 INF 都不用填——这正好绕开了"全局数组默认 $0$ 不是 INF"的经典陷阱（本题没有不可达对）。

**第三步：Floyd 的两个正确性要点。** 一是转移为什么对：$\mathrm{dis}[i][j]=\min(\mathrm{dis}[i][j],\mathrm{dis}[i][k]+\mathrm{dis}[k][j])$，按"路径是否经过中转点 $k$"分类；二是**原地更新**为什么对：第 $k$ 轮里 $\mathrm{dis}[i][k]$ 与 $\mathrm{dis}[k][j]$ 会不会被本轮改脏？不会——因为 $D_{k,k}=0$ 且边权非负，经过 $k$ 绕一圈不可能更短，第 $k$ 行第 $k$ 列整轮冻结。这两条都在 Part 2 给完整证明。

**第四步：范围核算。** 完全图保证 $\mathrm{dis}(u,v)\le D_{u,v}\le 10^5$（直飞就是一条候选路），故答案 $\le (M-1)\times10^5=9999\times10^5=9.999\times10^8$，**恰好**在 `int` 上限 $2.147\times10^9$ 之内——但余量只有 $2$ 倍出头，我仍用 `long long` 存答案，零成本买保险。Floyd 中间量 $\mathrm{dis}[i][k]+\mathrm{dis}[k][j]\le 2\times10^5$，`int` 绰绰有余。

**样例核对**（题面只给了样例说明，按其反推输入：$N=3,M=4,A=(1,2,1,3)$，$D_{1,2}=D_{2,1}=5$，$D_{2,3}=D_{3,2}=2$，$D_{3,1}=D_{1,3}=1$）：

```
输入：
3 4
1 2 1 3
0 5 1
5 0 2
1 2 0
```

Floyd 后 $\mathrm{dis}(1,2)=\min(5,1+2)=3$，其余 $\mathrm{dis}(2,1)=3,\mathrm{dis}(1,3)=1$。答案 $=3+3+1=7$，与说明"最小总危险指数 $7$"吻合；说明里的走法 $1,3,2,3,1,3$ 费用 $1+2+2+1+1=7$，正是"每段走最短路"的拼接（$1\to2$ 借道 $3$，$2\to1$ 借道 $3$，$1\to3$ 直飞）。

**另造两组手算数据。**

第二组，专打非对称：$N=2,M=4,A=(1,2,1,2)$，$D_{1,2}=5,D_{2,1}=1$。答案 $5+1+5=11$；若误把图当无向会算成 $1+1+1=3$，立刻暴露。

第三组，专打"绕远路反而便宜"与重复打卡：$N=4$，边 $1\to2\to3\to4\to1$ 各为 $1$，其余方向全为 $9$；$A=(1,4,2,4,4)$。$\mathrm{dis}(1,4)=3$（顺环走），$\mathrm{dis}(4,2)=2$，$\mathrm{dis}(2,4)=2$，$\mathrm{dis}(4,4)=0$，答案 $3+2+2+0=7$。

## 二、思维链：完整证明

**记号。** 点集 $V=\{0,\dots,N-1\}$（内部 0-based）。边权 $D_{i,j}\ge0$，$D_{i,i}=0$，完全图。行走 $W=(v_0,\dots,v_T)$ 的费用 $c(W)=\sum_{t=0}^{T-1}D_{v_t,v_{t+1}}$。$\mathrm{dis}(u,v)=\min\{c(W):W\text{ 从 }u\text{ 到 }v\}$。必经序列 $A_1..A_M$，$A_1=1,A_M=N$（编号意义下）。

---

### 引理 1（最短路存在、可取简单路、且不超过直飞）

对任意 $u,v$：$\mathrm{dis}(u,v)$ 存在，且等于"所有**简单路径**（无重复点）费用的最小值"；特别地 $\mathrm{dis}(u,v)\le D_{u,v}\le 10^5$，$\mathrm{dis}(u,u)=0$。

*证明*：完全图保证 $u\to v$ 有直飞边，候选集非空；费用非负，下界 $0$，且简单路径只有有限条，故最小值存在。任取一条行走 $W$，若它有重复点，则含一个环（从某点出发回到该点的子段）；环费用 $\ge0$（边权非负），删去环得到费用不增的更短行走。反复删环必终止（长度严格减），终态是简单路径。故对每条行走都存在费用 $\le$ 它的简单路径，两边取最小即得"行走最小值 = 简单路径最小值"。$\mathrm{dis}(u,v)\le D_{u,v}$ 因直飞是候选；$\mathrm{dis}(u,u)\le D_{u,u}=0$ 又费用非负故 $=0$。证毕。

---

### 引理 2（顺序约束的分解定理）

合法轨迹的最小费用 $=\sum_{i=1}^{M-1}\mathrm{dis}(A_i,A_{i+1})$。

*证明*：**下界。** 设 $W=(v_0,\dots,v_T)$ 合法：$v_0=1,v_T=N$，且存在 $0\le t_1<\cdots<t_M\le T$ 使 $v_{t_i}=A_i$。把费用按打卡点切段：

$$c(W)=\underbrace{c(v_0..v_{t_1})}_{\ge0}+\sum_{i=1}^{M-1}c(v_{t_i}..v_{t_{i+1}})+\underbrace{c(v_{t_M}..v_T)}_{\ge0}\ \ge\ \sum_{i=1}^{M-1}\mathrm{dis}(A_i,A_{i+1}),$$

因为第 $i$ 段是从 $A_i$ 到 $A_{i+1}$ 的行走，费用 $\ge\mathrm{dis}(A_i,A_{i+1})$；前后缀费用非负（边权非负）。注意 $A_1=1=v_0$、$A_M=N=v_T$ 保证可以取到覆盖全程的打卡（即使 $t_1>0$ 或 $t_M<T$，前后缀也只是白送的非负费用，下界不变）。

**上界。** 对每 $i$ 取一条达到 $\mathrm{dis}(A_i,A_{i+1})$ 的最短路 $P_i$（引理 1 保证存在）。把 $P_1,\dots,P_{M-1}$ 首尾拼接（连接点重合，只算一次）得行走 $W^\*$：起点 $A_1=1$，终点 $A_M=N$，费用恰为 $\sum\mathrm{dis}$。打卡点取各拼接处即可，但要小心**相邻重复**：若 $A_i=A_{i+1}$，该段长 $0$，两个打卡点会落在同一下标上，不满足子序列要求的**严格**递增 $t_1<\cdots<t_M$。

修补（压缩法）：把 $A$ 中连续重复的元素合并成一次打卡。合并不改变费用和——被合并的段贡献 $\mathrm{dis}(u,u)=0$。压缩后相邻元素互异，每段至少含一条边，拼接行走的打卡下标天然严格递增；首尾 $A_1=1,A_M=N$ 不受影响。于是 $W^\*$ 是合法轨迹且费用达下界。

故最小费用 $\le\sum\mathrm{dis}$。夹逼得等号。证毕。

**这条引理是 full reduction**：原问题的一切顺序结构都被吸进"相邻 $A$ 的最短路"里，之后只剩纯最短路。

---

### 引理 3（Floyd 的阶段不变量）

定义 $d^{(k)}[i][j]$ 为"从 $i$ 到 $j$、**中间点**（不含端点）全部属于 $\{0,\dots,k-1\}$ 的行走的最小费用"。则

$$d^{(0)}[i][j]=D_{i,j},\qquad d^{(k+1)}[i][j]=\min\bigl(d^{(k)}[i][j],\ d^{(k)}[i][k]+d^{(k)}[k][j]\bigr),$$

且 $d^{(N)}[i][j]=\mathrm{dis}(i,j)$。

*证明*：$k=0$：中间点集为空，行走只能是直飞边（或 $i=j$ 的零长行走），费用 $D_{i,j}$（$D_{i,i}=0$ 一致）。

递推：设 $W$ 是达到 $d^{(k+1)}[i][j]$ 的最优行走（有限候选、非负费用，存在）。分两类：

- $W$ 的中间点不含 $k$：则 $W$ 的中间点 $\subseteq\{0..k-1\}$，$c(W)\ge d^{(k)}[i][j]$。
- $W$ 的中间点含 $k$：由引理 1 的删环论证，可设 $W$ 是简单路径（删环不增费用且不引入新中间点），故 $k$ 恰出现一次。在 $k$ 处切开：$i\to k$ 段与 $k\to j$ 段的中间点都 $\subseteq\{0..k-1\}$（$k$ 在两段里都是端点），故 $c(W)\ge d^{(k)}[i][k]+d^{(k)}[k][j]$。

于是 $d^{(k+1)}[i][j]\ge\min(\cdots)$。反向：$d^{(k)}[i][j]$ 对应的行走中间点 $\subseteq\{0..k\}$，是 $d^{(k+1)}$ 的候选；$d^{(k)}[i][k]$ 与 $d^{(k)}[k][j]$ 对应行走拼接后中间点 $\subseteq\{0..k\}$（$k$ 变成中间点），费用为两者之和，也是候选。故 $d^{(k+1)}[i][j]\le\min(\cdots)$。等号成立。

$k=N$：中间点可取全部 $V$，无限制，$d^{(N)}=\mathrm{dis}$。证毕。

---

### 引理 4（原地更新不脏：第 $k$ 行/列冻结）

Floyd 第 $k$ 轮外层循环执行期间，对一切 $i,j$：$\mathrm{dis}[i][k]$ 与 $\mathrm{dis}[k][j]$ 的值保持为本轮开始时的值。因此原地三重循环计算的恰是引理 3 的递推。

*证明*：先证 $\mathrm{dis}[k][k]$ 恒为 $0$：初始 $D_{k,k}=0$；任何一轮对它的更新是 $\min(\mathrm{dis}[k][k],\mathrm{dis}[k][k]+\mathrm{dis}[k][k])$，值非负时 $\min(x,2x)=x$，故永远 $0$。（非负性由归纳保持：初值非负，$\min$ 与非负加法不产生负数。）

第 $k$ 轮中，$\mathrm{dis}[i][k]$ 的唯一可能更新是 $\min(\mathrm{dis}[i][k],\mathrm{dis}[i][k]+\mathrm{dis}[k][k])=\min(x,x+0)=x$，不变；$\mathrm{dis}[k][j]$ 同理 $\min(x,0+x)=x$，不变。故本轮内读到的 $\mathrm{dis}[i][k],\mathrm{dis}[k][j]$ 都是"阶段 $k$"的值 $d^{(k)}[i][k],d^{(k)}[k][j]$，与它们在本轮中被访问的先后无关。

再看一般格子 $\mathrm{dis}[i][j]$（$i,j\ne k$）：它在第 $k$ 轮至多被更新一次（内层 $i,j$ 各枚举一次），更新式 $\min(\text{旧值},d^{(k)}[i][k]+d^{(k)}[k][j])$，旧值即 $d^{(k)}[i][j]$（此前各轮已按归纳算好）。故本轮结束 $\mathrm{dis}=d^{(k+1)}$。对 $k$ 归纳即得终态 $\mathrm{dis}=d^{(N)}$。证毕。

**注**：这条引理依赖"非负权 + 对角线 $0$"。若存在负权边，第 $k$ 行/列可能被本轮改脏，原地 Floyd 的语义就要重新讨论——本题边权 $\ge0$，安全。

---

### 引理 5（范围与类型选择）

答案 $\le 9.999\times10^8<2^{31}-1$；Floyd 中间和 $\le 2\times10^5$。用 `int` 存 `dis`、`long long` 存 `ans` 均安全。

*证明*：引理 1 给 $\mathrm{dis}(u,v)\le D_{u,v}\le10^5$。答案 $=\sum_{i=1}^{M-1}\mathrm{dis}(A_i,A_{i+1})\le(M-1)\cdot10^5\le9999\times10^5=999\,900\,000$。$2^{31}-1=2\,147\,483\,647$，故 `int` 其实装得下，但余量仅约 $2.15$ 倍；`ans` 用 `i64` 是零成本保险。Floyd 中 $\mathrm{dis}[i][k]+\mathrm{dis}[k][j]\le2\times10^5\ll2^{31}$，`int` 安全。证毕。

---

### 引理 6（复杂度）

时间 $O(N^3+M+N^2)$，空间 $O(N^2+M)$。

*证明*：读入 $O(M+N^2)$；Floyd 三重循环恰 $N^3\le10^6$ 次 $\min$ 更新；求和 $O(M)$。空间：距离矩阵 $N^2\le10^4$ 个 `int`，序列 $M\le10^4$ 个 `int`，合计约 $80$ KB。证毕。

---

### 定理

程序输出找到宝藏前提下的最小危险指数和，时间 $O(N^3+M)$。

*证明*：引理 2 把原问题归约为 $\sum\mathrm{dis}(A_i,A_{i+1})$；引理 1 保证各 $\mathrm{dis}$ 存在且 $\le10^5$；引理 3、4 保证 Floyd 原地迭代正确算出全部 $\mathrm{dis}$；引理 5 保证无溢出；引理 6 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "依次出现、不一定相邻"= 子序列约束；轨迹可重复点，边权非负、图完全、方向不对称。
2. **reduce to easier problem** — 在打卡点处剪开轨迹：答案 $=\sum_{i}\mathrm{dis}(A_i,A_{i+1})$，下界切段、上界拼接，顺序约束零额外代价。
3. **consider easier version** — 先想单段"从 $u$ 到 $v$ 最便宜"：裸最短路；重复打卡段 $\mathrm{dis}(u,u)=0$ 自动处理。
4. **classic problem solution** — 查询多（$10^4$）点少（$100$）⇒ Floyd 全源最短路 $O(N^3)=10^6$，查询 $O(1)$。
5. **explore its property** — 完全图 ⇒ 读入矩阵即初始距离，无需 INF；非负权 + 零对角线 ⇒ 第 $k$ 行/列冻结，原地 Floyd 合法。
6. **explore its property** — 范围核算：$\mathrm{dis}\le10^5$、答案 $\le9.999\times10^8$ 恰在 `int` 内，仍用 `i64` 买保险。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,m` | 岛屿数 $\le100$、必经序列长 $\le10^4$ | `int` | 读入 |
| `a[i]` | 第 $i$ 个必经岛屿（读入即 `--` 转 0-based） | `int[mxm]` | $a_0=0,a_{m-1}=n-1$ |
| `dis[i][j]` | $i\to j$ 最短路；**初值就是读入的 $D_{i,j}$** | `int[mxn][mxn]` | 完全图无不可达，**不需要 INF** |
| `ans` | $\sum\mathrm{dis}(A_i,A_{i+1})$ | `i64` | 全局默认 $0$，累加 |
| `mxn,mxm` | $100+5$、$10000+5$ | `constexpr int` | 数组尺寸 |

### 算法步骤

1. I/O 加速三行；读 $N,M$；读 $A_{1..M}$ 并转 0-based。
2. 读 $N\times N$ 危险矩阵入 `dis`（它就是 $d^{(0)}$）。
3. Floyd：`for k for i for j: dis[i][j]=min(dis[i][j],dis[i][k]+dis[k][j])`。
4. `ans=Σ dis[a[i-1]][a[i]]`（$i=1..M-1$），输出。

### 复杂度

- 时间 $O(N^3+M)\approx10^6$；空间 $O(N^2+M)\approx80$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例说明反推数据输出 $7$ 吻合；另造非对称（输出 $11$）、$N=1$（输出 $0$）、环状绕路 + 重复打卡（输出 $7$）、最大边权直飞（输出 $100000$）共五组手算数据全部吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2910 [USACO08OPEN] Clear And Present Danger S
// 必经序列 A1..AM 只是"子序列"约束 ⇒ 答案 = Σ dis[A_i][A_{i+1}]。
// 完全有向图、边权非负，Floyd 求全源最短路；dis 初值就是读入矩阵，无需 INF。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105},mxm{10005};

int n,m,a[mxm],dis[mxn][mxn];
i64 ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<m;++i)
	{
		cin>>a[i];--a[i];
	}
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			cin>>dis[i][j];
	for(int k=0;k<n;++k)
		for(int i=0;i<n;++i)
			for(int j=0;j<n;++j)
				dis[i][j]=min(dis[i][j],dis[i][k]+dis[k][j]);
	for(int i=1;i<m;++i)
		ans+=dis[a[i-1]][a[i]];
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `dis` **不填 INF**：完全图每对点都有直飞边，读入矩阵就是合法的初始距离。这是本题与一般最短路题最大的不同——"全局数组默认 $0$"的陷阱在这里不存在，因为每个格子都会被读入覆盖。
- Floyd 的 `k` 必须在**最外层**：它枚举的是"允许使用的中转点集合"的阶段，放内层就不是引理 3 的递推了。
- 原地更新合法的依据是引理 4（非负权 + 零对角线 ⇒ 第 $k$ 行/列本轮冻结），不需要滚动数组。
- `ans` 用 `i64`：理论上界 $9.999\times10^8$ 虽在 `int` 内，但余量小，`long long` 零成本。
- 方向敏感：`dis[a[i-1]][a[i]]` 的下标顺序就是航行方向，写反即错（题面明确警告不对称）。
- 相邻重复的 $A_i=A_{i+1}$ 贡献 `dis[u][u]=0`，无需特判。
