# P2903 [USACO08MAR] The Loathesome Hay Baler S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 平面上有 $N$ 个齿轮（$2\le N\le 1050$），第 $i$ 个给出圆心 $(x_i,y_i)$（$|x|,|y|\le 5000$）与半径 $r_i$（$3\le r_i\le 800$）。位于 $(0,0)$ 的是驱动齿轮，转速 $+10000$ 转/小时（顺时针为正）；位于 $(X_t,Y_t)$ 的是工作齿轮。两个齿轮**相接**（外切，即圆心距恰好等于半径之和）时互相传动：若半径 $R_d$ 的齿轮转速为 $S$，则被它带动的半径 $R_x$ 的齿轮转速为 $-S\cdot R_d/R_x$（转向相反、线速度守恒）。题目保证：**除驱动齿轮外，每个齿轮恰好被一个别的齿轮带动**。能量从驱动齿轮传到工作齿轮会经过一条齿轮链（传动序列），要求输出这条链上**所有齿轮转速绝对值之和**（一个整数）。不在链上的齿轮一律忽略。

先把三处题意口径说清楚（题面没有逐字明说，但都能从约束与输出格式合理推出）：

1. **"相接" = 外切**，即 $\sqrt{(x_i-x_j)^2+(y_i-y_j)^2}=r_i+r_j$。齿轮是实体圆盘，内切意味着重叠，物理上不存在；相交（距离小于半径和）同样不可能。所以判定用**整数平方等式** $(x_i-x_j)^2+(y_i-y_j)^2=(r_i+r_j)^2$，不开方、不用 eps。
2. **"传动序列" = 驱动齿轮到工作齿轮的唯一路径**。"每个齿轮恰被一个齿轮带动"说明"带动关系"里每个非根结点入度恰为 $1$；能量唯一来源是驱动齿轮，沿"我被谁带动"回溯不可能绕圈（否则圈上齿轮没有能量来源），必然终止于驱动齿轮。于是带动关系是一棵以驱动齿轮为根的树；而"相接"与"带动"是同一件事（相切即传动），所以**相切图本身就是这棵树**，树上两点间路径唯一，BFS 记父指针再回溯即可。
3. **输出是一个整数** ⇒ 数据保证绝对值之和恰为整数。注意**单个齿轮的转速未必是整数**：比如 $r_{\text{根}}=10$、链上某齿轮 $r=3$，其转速绝对值 $100000/3$ 不是整数，但若干项之和可以是整数（$100000/3+100000/6=50000$）。所以不能对每一项做整数除法，要用高精度浮点求和后四舍五入，并证明误差远小于 $0.5$（引理 5）。

**第一步：暴力建图。** $N\le 1050$，两两枚举 $O(N^2)\approx 5.5\times10^5$ 对，每对做一次整数平方比较，毫无压力。坐标差 $\le 10^4$，平方和 $\le 2\times10^8$；半径和 $\le 1600$，平方 $\le 2.56\times10^6$——`int` 其实装得下，但用 `i64` 存中间量零成本保险。

**第二步：找路径。** 从驱动齿轮 BFS，`prv[v]` 记录第一次访问 $v$ 的结点。因为图是树，第一次访问走的就是唯一树路径，回溯 `gt → prv[gt] → … → rt` 得到传动序列。$O(N)$。

**第三步：转速怎么算？发现"望远镜"。** 老实模拟的话，沿路径递推 $S_{i+1}=-S_i\cdot r_i/r_{i+1}$，要存每个中间转速。但写几项就发现规律：

$$|S_1|=10000\cdot\frac{r_0}{r_1},\quad |S_2|=10000\cdot\frac{r_0}{r_1}\cdot\frac{r_1}{r_2}=10000\cdot\frac{r_0}{r_2},\quad\dots$$

中间半径**全部约掉**！链上第 $i$ 个齿轮的转速绝对值只跟**根半径与它自己的半径**有关：$|S_i|=10000\cdot r_0/r_i$。于是答案 $=\sum_{\text{路径}}10000\,r_0/r_i$，连符号都不用管（题目只要绝对值）。这一步把"模拟传动"归约成了"路径上求一个简单函数之和"。

**第四步：数值细节。** 每项 $\le 10000\times 800/3\approx 2.67\times10^6$，路径 $\le 1050$ 项，总和 $\le 2.8\times10^9$（超 `int`，输出用 `i64`）。用 `long double`（x86 上 80 位扩展精度）逐项累加，最后 `llroundl` 四舍五入。误差分析（引理 5）：总误差 $<10^{-6}$，而真实答案是整数，距离舍入边界至少 $0.5$，舍入必然正确。顺带一提，即便 `long double` 退化成 `double`，误差界也只有 $\approx 3\times10^{-4}$，同样安全。

**手造数据核对。** 题面 Hint 给了完整例子，直接拿来当第一组；另造三组分别打"不同半径比""链式望远镜""单项非整数但总和为整数"：

第一组（Hint 原例，$4$ 个齿轮，工作齿轮 $(32,54)$）：

```
输入：
4 32 54
0 0 10
0 30 20
32 54 20
-40 30 20
```

相切关系：$(0,0)$–$(0,30)$ 距离 $30=10+20$ ✓；$(0,30)$–$(32,54)$ 距离 $\sqrt{32^2+24^2}=40=20+20$ ✓；$(0,30)$–$(-40,30)$ 距离 $40$ ✓（但它不在路径上，忽略）。路径转速 $10000,-5000$（原文表格第三行 $-5000$ 对应 $(32,54)$），绝对值和 $10000+5000+5000=20000$。程序输出 `20000` ✓。把这 $4$ 行输入**打乱顺序**再跑，仍输出 `20000`（根靠坐标找，不靠输入顺序）。

第二组（两个齿轮，半径 $3$ 与 $6$）：`2 9 0 / 0 0 3 / 9 0 6`。距离 $9=3+6$ ✓，转速 $10000$ 与 $-10000\times3/6=-5000$，输出 `15000` ✓。

第三组（三级链 $6\to3\to12$）：`3 24 0 / 0 0 6 / 9 0 3 / 24 0 12`。距离 $9=6+3$、$15=3+12$ ✓。转速绝对值 $10000,\ 10000\times6/3=20000,\ 10000\times6/12=5000$，和 `35000` ✓——注意中间齿轮半径 $3$ 在望远镜里约掉了，末项只留 $r_0/r_2$。

第四组（单项非整数）：`3 22 0 / 0 0 10 / 13 0 3 / 22 0 6`。距离 $13=10+3$、$9=3+6$ ✓。三项为 $10000,\ 100000/3,\ 100000/6$，后两项都不是整数但和为 $50000$，总答案 `60000` ✓。这组专门验证"整数除法逐项截断"的错误写法会在这里翻车（截断得 $10000+33333+16666=59999$），而浮点求和 + 舍入正确。

## 二、思维链：完整证明

**记号。** 齿轮下标 $0\le i<N$。圆心 $p_i=(x_i,y_i)$，半径 $r_i$。根 $rt$ 满足 $p_{rt}=(0,0)$，目标 $gt$ 满足 $p_{gt}=(X_t,Y_t)$。传动路径为 $g_0=rt,g_1,\dots,g_L=gt$。$S(g)$ 表示齿轮 $g$ 的转速（带符号），$S(g_0)=10000$。

---

### 引理 1（相切判定的整数化）

齿轮 $i,j$ 相切当且仅当
$$(x_i-x_j)^2+(y_i-y_j)^2=(r_i+r_j)^2,$$
且该等式两边都是不超过 $2\times10^8$ 的非负整数，用 `i64` 计算精确无溢出。

*证明*：两圆外切的定义是圆心距等于半径和：$\|p_i-p_j\|=r_i+r_j$。两边均非负，平方是 $[0,\infty)$ 上的严格单调函数，故等式成立当且仅当平方后相等，即 $(x_i-x_j)^2+(y_i-y_j)^2=(r_i+r_j)^2$。内切（$\|p_i-p_j\|=|r_i-r_j|$）与相交被题意排除（口径 1：实体齿轮不重叠）。

范围：$|x_i-x_j|\le 10^4$，故左边 $\le 2\times10^8$；$r_i+r_j\le 1600$，右边 $\le 2.56\times10^6$。两者都远小于 $2^{63}$，`i64` 中间量 `dx*dx+dy*dy` 与 `rs*rs` 精确。整数判等不涉及任何浮点舍入，**不存在"距离差一点点算不算相切"的精度边界问题**——这正是不开方的好处。证毕。

---

### 引理 2（相切图是以驱动齿轮为根的树）

在题目保证下（每个非驱动齿轮恰好被一个齿轮带动；驱动齿轮是能量唯一来源；相切即传动），把"相接"关系建成无向图 $G$，则 $G$ 是一棵含全部 $N$ 个齿轮的树，根为 $rt$。从而 $rt$ 到 $gt$ 的路径唯一，且就是传动序列。

*证明*：先分析**带动关系**（有向图 $D$：边 $u\to v$ 表示 $u$ 带动 $v$）。

(a) 每个非根结点入度恰为 $1$（题面："除了驱动齿轮以外的所有齿轮都被另外某个齿轮带动，并且不会出现 $2$ 个不同的齿轮带动同一个齿轮"）；根入度为 $0$（它是能量来源，不被带动）。故 $D$ 恰有 $N-1$ 条边。

(b) $D$ 无有向环。反证：设环 $v_1\to v_2\to\cdots\to v_k\to v_1$。环上每个齿轮的转动都由其驱动者引起，而驱动者也在环上——这个因果链没有任何外部能量输入。但机器中能量唯一来源是驱动齿轮（题面：驱动齿轮顺时针转动，能量由它传送到工作齿轮），环上齿轮既不在从根出发的能量流上，又无独立动力，不可能转动，与"被带动"矛盾。故无环。

(c) 由 (a)(b)，从任一结点沿唯一入边回溯，结点不重复（无环），有限步内必终止；终止点入度为 $0$，只能是根。故所有结点都可达根，$D$ 连通。$N$ 个点、$N-1$ 条边、连通 ⇒ $D$ 是树（忽略方向后）。

(d) $G=D$（忽略方向）：相切的两齿轮必然互相传动（物理接触即传动，口径 1），传动方向由能量流决定，恰为 $D$ 中的一条边；反之 $D$ 的每条边都来自相切。故两图边集相同，$G$ 是树。

树上任意两点路径唯一，BFS 从 $rt$ 出发第一次到达 $gt$ 所经路径就是这条唯一路径，即"能量由驱动齿轮传送到工作齿轮的过程中用到的所有齿轮"——传动序列。证毕。

---

### 引理 3（BFS 父指针回溯给出传动序列）

在树 $G$ 上从 $rt$ 做 BFS，令 `prv[rt]=rt`，其余 `prv[v]` 为 $v$ 第一次被访问时的出队结点 $u$。则对任意 $v$，序列 $v,\texttt{prv}[v],\texttt{prv}[\texttt{prv}[v]],\dots$ 严格沿树路径走向 $rt$，且以 $rt$ 终止（`prv[rt]=rt` 为终止标志）。特别地，从 $gt$ 回溯得到的结点集合恰为传动序列。

*证明*：先证不变量：**每个被访问结点 $v\ne rt$ 的 `prv[v]` 是 $v$ 在树上的父亲**（以 $rt$ 为根）。对 BFS 访问顺序归纳：根显然。设 $v$ 第一次被访问，是由已访问结点 $u$ 松弛而来，故 $(u,v)$ 是树边。若 $u$ 不是 $v$ 的父亲，则 $u$ 是 $v$ 的儿子，$u$ 到根的路径经过 $v$，$u$ 被访问时 $v$ 必已先被访问（树上从根到 $u$ 的唯一路径经过 $v$，BFS 按距根距离分层访问，$v$ 层数更小），与"$v$ 第一次被访问"矛盾。故 $u$ 是父亲，`prv[v]=u` 正确。

于是回溯每步走到父亲，深度严格减 $1$，必在深度 $0$（根）处因 `prv[rt]=rt` 终止，不会越界（`prv` 虽预填哨兵 $1145141919$，但由引理 2 所有结点都被访问，回溯路径上的 `prv` 全部有定义）。树路径唯一 ⇒ 回溯结点集 = $rt$ 到 $gt$ 的唯一路径 = 传动序列（引理 2）。证毕。

---

### 引理 4（转速望远镜公式）

对传动路径上第 $i$ 个齿轮 $g_i$（$0\le i\le L$），
$$S(g_i)=(-1)^i\cdot 10000\cdot\frac{r_{g_0}}{r_{g_i}},\qquad\text{故}\quad |S(g_i)|=10000\cdot\frac{r_{rt}}{r_{g_i}}.$$

*证明*：对 $i$ 归纳。$i=0$：$S(g_0)=10000=(-1)^0\cdot10000\cdot r_{g_0}/r_{g_0}$ ✓。

设 $i-1$ 成立。由传动规则，$g_i$ 被 $g_{i-1}$ 带动（引理 3：回溯方向即带动方向的反向），
$$S(g_i)=-S(g_{i-1})\cdot\frac{r_{g_{i-1}}}{r_{g_i}}=-(-1)^{i-1}\cdot10000\cdot\frac{r_{g_0}}{r_{g_{i-1}}}\cdot\frac{r_{g_{i-1}}}{r_{g_i}}=(-1)^i\cdot10000\cdot\frac{r_{g_0}}{r_{g_i}}.$$
中间半径 $r_{g_{i-1}}$ 约掉——这就是"望远镜"：乘积 $\prod_{j=1}^{i}\frac{r_{g_{j-1}}}{r_{g_j}}$ 逐项相消只剩首尾。取绝对值消去 $(-1)^i$。证毕。

**推论**：答案 $=\sum_{i=0}^{L}10000\cdot r_{rt}/r_{g_i}$，只需路径上每个齿轮的半径与根半径，**无需模拟符号、无需存中间转速**。

---

### 引理 5（浮点求和 + 四舍五入的精确性）

设真实答案 $A=\sum_{i=0}^{L}10000\,r_{rt}/r_{g_i}$ 为整数（口径 3）。用 `long double`（x86 扩展精度，单位舍入 $u=2^{-64}\approx5.42\times10^{-20}$）按任意顺序逐项计算 `10000.0L*r[rt]/r[u]` 并累加得 $\hat A$，则 $|\hat A-A|<10^{-6}$，从而 `(i64)llroundl(ans)` $=A$。

*证明*：记项 $t_i=10000\,r_{rt}/r_{g_i}$。范围：$r_{rt}\le800$、$r_{g_i}\ge3$ ⇒ $t_i\le 10000\times800/3<2.667\times10^6$；项数 $\le N\le1050$ ⇒ $A\le 1050\times2.667\times10^6<2.8\times10^9$。

**单项误差**：`10000.0L*r[rt]` 是 $\le8\times10^6$ 的整数，`long double` 尾数 $64$ 位精确表示；除以 $r_{g_i}$ 一次舍入，相对误差 $\le u$，故计算值 $\hat t_i$ 满足 $|\hat t_i-t_i|\le u\,t_i<1.45\times10^{-13}$。

**累加误差**：标准顺序求和误差界（每次加法相对误差 $\le u$，误差按当前部分和放大）：
$$\Big|\sum\hat t_i-\sum t_i\Big|\le\sum_i|\hat t_i-t_i|+(n-1)\,u\,\sum_i t_i+O(nu^2)<1050\times1.45\times10^{-13}+1049\times5.42\times10^{-20}\times2.8\times10^9<1.6\times10^{-10}+1.6\times10^{-7}<10^{-6}.$$

**舍入正确**：$A$ 是整数，$\hat A\in(A-10^{-6},A+10^{-6})$，距最近的两类舍入边界 $A\pm0.5$ 都大于 $0.499999$，故四舍五入到整数必得 $A$。`llroundl` 正是"四舍五入、平局远离零"，而 $\hat A$ 不可能恰落在半整数边界上（误差 $<10^{-6}$），平局分支不会被触发。

**退化保险**：若评测环境 `long double` 等同 `double`（$u=2^{-53}\approx1.11\times10^{-16}$），同法得误差界 $1050\times2.667\times10^6\times1.11\times10^{-16}\times2\approx3.1\times10^{-4}<0.5$，结论不变。证毕。

**为什么不能逐项整数除法**：$t_i$ 未必是整数（第一部分第四组数据：$100000/3$）。逐项截断会丢小数，而"先精确求和再舍入"与"先截断再求和"结果不同（$59999$ vs $60000$）。也不能用公分母精确分数：分母是路径半径的 lcm，$1050$ 个 $\le800$ 的数的 lcm 可达数百位，远超 `__int128`。浮点 + 误差界是本题最干净的精确路线。

---

### 引理 6（复杂度与值域）

时间 $O(N^2)$，空间 $O(N)$。答案 $A<2.8\times10^9$ 超出 `int`，须用 `i64` 输出。

*证明*：建图两重循环枚举 $\binom{N}{2}<5.5\times10^5$ 对，每对常数次 `i64` 乘加；BFS 每结点入队一次、每边检查两次，$O(N+|E|)=O(N)$（树 $|E|=N-1$）；回溯 $\le N$ 步，每步一次 `long double` 除法加法。合计 $O(N^2)$，$N=1050$ 时约 $5.5\times10^5$ 次整数运算，毫秒级。空间：坐标半径数组 $O(N)$、邻接表 $O(N)$（树）、`prv/vis` $O(N)$、队列 $O(N)$。值域由引理 5 的估计 $A<2.8\times10^9>2^{31}-1\approx2.15\times10^9$，故输出变量用 `i64`（`llroundl` 返回值本身就是 `long long`）。证毕。

---

### 定理

程序输出传动序列上所有齿轮转速绝对值之和（整数），总复杂度 $O(N^2)$。

*证明*：引理 1 保证建边判据精确且与"相接"一致；引理 2 保证相切图是树、传动序列即树上唯一路径；引理 3 保证 BFS 父指针回溯恰好枚举这条路径（不重不漏，含根与目标）；引理 4 把每项转速化为 $10000\,r_{rt}/r_{g_i}$；引理 5 保证 `long double` 求和 + `llroundl` 恰好还原整数答案；引理 6 给出复杂度与输出类型。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "相接"= 外切 = 圆心距等于半径和；两边平方化成纯整数判等，杜绝开方精度问题。
2. **explore its property** — "每个齿轮恰被一个齿轮带动"+ 能量唯一来源 ⇒ 带动关系无环、每点入度 $1$ ⇒ 相切图是树 ⇒ 传动序列是唯一路径。
3. **consider easier version** — 先想老实模拟：沿路径递推带符号转速；写几项后发现中间半径全部约掉。
4. **reduce to easier problem** — 望远镜公式 $|S_i|=10000\,r_0/r_i$：答案只是路径上"根半径/自身半径"之和，符号与中间半径都不用管。
5. **classic problem solution** — BFS 记父指针，从目标回溯到根，$O(N)$ 取出唯一树路径。
6. **discuss by category** — 单项转速未必整数、总和保证整数：逐项整数除法错、精确分数分母爆炸，选 `long double` 求和 + `llroundl`，用误差界 $<10^{-6}\ll0.5$ 证明舍入必然正确。

| `n,Xt,Yt` | 齿轮数、工作齿轮坐标 | `int` | 读入；$N\le1050$ 按题面字面 |
| `x[i],y[i],r[i]` | 第 $i$ 个齿轮的圆心与半径 | `int[mxn]` | 读入，0-based |
| `rt,gt` | 驱动齿轮 / 工作齿轮下标 | `int` | 按坐标 $(0,0)$ / $(X_t,Y_t)$ 匹配，初值 $-1$ |
| `graph[i]` | 相切邻接表（树） | `vector<int>[mxn]` | 两两枚举平方判等建边 |
| `prv[v]` | BFS 树中 $v$ 的父亲 | `int[mxn]` | **先 `fill` 成 $1145141919$**；`prv[rt]=rt` 作回溯终止标志 |
| `vis[v]` | BFS 访问标记 | `bool[mxn]` | 全局默认 `false` |
| `ans` | $\sum 10000\,r_{rt}/r_u$（路径上） | `long double` | 累加器；输出前 `llroundl` |
| `mxn` | $1050+5$ | `constexpr int` | 数组尺寸 |

### 算法步骤

1. I/O 加速三行；读 $N,X_t,Y_t$ 与 $N$ 个三元组，顺带按坐标定位 `rt,gt`。
2. 两两枚举 $(i,j)$，若 $(x_i-x_j)^2+(y_i-y_j)^2=(r_i+r_j)^2$（`i64` 中间量）则连无向边。
3. `fill_n(prv,n,1145141919)`；从 `rt` BFS，`prv[rt]=rt`，首次访问 $v$ 时记 `prv[v]=u`。
4. 从 `gt` 沿 `prv` 回溯到 `rt`（含两端），每步 `ans+=10000.0L*r[rt]/r[u]`。
5. 输出 `(i64)llroundl(ans)`。

### 复杂度

- 时间：$O(N^2)$（建图主导，$\le5.5\times10^5$ 对）；BFS 与回溯 $O(N)$。
- 空间：$O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Hint 原例输出 `20000`（输入打乱顺序后仍 `20000`）；另造"半径比 $3:6$""三级链 $6\to3\to12$""单项非整数但总和为整数"三组手算数据，输出 `15000 / 35000 / 60000` 全部吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2903 [USACO08MAR] The Loathesome Hay Baler S
// 相切判定 dist²==(ri+rj)²；每个齿轮恰被一个齿轮带动 ⇒ 相切图是树，BFS 父指针回溯唯一传动路径
// |S_i|=10000*r0/r_i（传动比叠乘望远镜）；long double 求和后四舍五入（数据保证和为整数）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1055};

int n,Xt,Yt,x[mxn],y[mxn],r[mxn],prv[mxn];
vector<int>graph[mxn];
bool vis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>Xt>>Yt;
	int rt=-1,gt=-1;
	for(int i=0;i<n;++i)
	{
		cin>>x[i]>>y[i]>>r[i];
		if(x[i]==0&&y[i]==0)
			rt=i;
		if(x[i]==Xt&&y[i]==Yt)
			gt=i;
	}
	for(int i=0;i<n;++i)
		for(int j=i+1;j<n;++j)
		{
			i64 dx=x[i]-x[j],dy=y[i]-y[j],rs=r[i]+r[j];
			if(dx*dx+dy*dy==rs*rs)	// 外切才传动，整数判等无精度问题
			{
				graph[i].push_back(j);
				graph[j].push_back(i);
			}
		}
	fill_n(prv,n,1145141919);
	queue<int>Q;
	Q.push(rt);vis[rt]=true;prv[rt]=rt;	// 根的父指针指向自己，回溯终止标志
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		for(int v:graph[u])
			if(!vis[v])
			{
				vis[v]=true;prv[v]=u;
				Q.push(v);
			}
	}
	long double ans=0;
	for(int u=gt;;u=prv[u])
	{
		ans+=10000.0L*r[rt]/r[u];	// 望远镜：|S_u|=10000*r[rt]/r[u]，与路径中间半径无关
		if(u==rt)
			break;
	}
	cout<<(i64)llroundl(ans)<<'\n';
	return 0;
}
```

### 代码说明

- **建边用 `i64` 平方判等**：`dx*dx+dy*dy==rs*rs`，不开方、无 eps。坐标差与半径和的范围保证不溢出（引理 1）。
- **`prv` 必须显式 `fill` 哨兵**：全局 `int` 默认 $0$，而 $0$ 是合法下标；虽然本题树连通、所有 `prv` 都会被 BFS 赋值，预填哨兵仍是防御性习惯。`prv[rt]=rt` 让回溯循环 `for(int u=gt;;u=prv[u])` 在根处自然终止，`gt==rt` 的退化情形也正确（只加根的一项 $10000$）。
- **回溯循环先加项再判停**：根与工作齿轮都计入答案（题面"传动序列中所有齿轮"含两端，Hint 表格把驱动齿轮的 $10000$ 也算进了 $20000$）。
- **`10000.0L`** 的 `L` 后缀保证整个表达式按 `long double` 计算；写成 `10000*r[rt]/r[u]` 会先做整数除法截断，正是第四组手造数据打掉的错误。
- **输出 `(i64)llroundl(ans)`**：答案可达 $2.8\times10^9$ 超 `int`；`llroundl` 返回 `long long`，四舍五入语义与引理 5 一致。
