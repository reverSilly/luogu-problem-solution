# P2095 营养膳食 — 题解

## 一、解题过程：人类思考叙事

题意翻译：Mr.L 有一顿饭最多吃 $m$ 份食品；有 $n$ 种食品，分成 $k$ 类，第 $b$ 类最多吃 `lim[b]` 份；每种食品有脂肪指数 $a_i$。求能吃到的最大脂肪指数和。

第一反应：排序 + 贪心。把食品按脂肪指数从大到小排，然后从高到低扫：
- 如果这一份的类别还有配额（`lim[b] > 0`），就吃；
- 否则跳过，看下一份；
- 吃满 $m$ 份就停。

这就是"每次挑当前能吃的里面脂肪最高的"。看起来天经地义，但"看起来对"和"一定对"是两回事，我要证一下。

先试着找反例。假设有两类，A 类配额 $1$，B 类配额 $1$，总共只能吃 $m=1$ 份。有三份食品：$a=10$（A 类）、$b=9$（A 类）、$c=8$（B 类）。贪心先吃 $10$（A 类配额用掉），然后 $9$ 跳不过（配额没了），$8$ 也没机会了（$m$ 用完）。答案 $10$。最优也是 $10$（因为只能吃一份）。没问题。

再来：$m=2$，A 类配额 $1$，B 类配额 $1$。食品 $10$（A）、$9$（A）、$8$（B）。贪心吃 $10$（A 满），跳过 $9$（A 满），吃 $8$（B）。共 $18$。最优：$10+8=18$ 或 $9+8=17$。贪心不劣。

会不会出现"贪心拿了一份高脂肪的，把某个类的配额提前用光，导致后面本来能凑出更多份的情况"？这个担心在一般的"分组背包 + 数量上限"里是真实存在的坑。但这里的关键在于：**配额是"每类至多 $c$ 份"这种形式，它是层流（laminar）的** —— 所有类的集合两两不交，而"全集"包含它们。这种约束结构有一个漂亮的性质：可行集合满足**交换公理**（即可行集合构成一个拟阵），从而"按权重降序、可行就加入"的贪心一定最优。

我不用去背拟阵理论，直接用交换论证证一遍就行（见证明部分）。

另外还有一个更朴素的直觉版本也可以证：对任意可行方案 $S$ 和贪心选出的 $G$，可以逐个把 $S$ 的元素"换"成 $G$ 的元素且不减少总脂肪。核心是：如果 $S$ 里有某份 $x$ 不在 $G$ 中，而 $G$ 里有某份 $y$ 不在 $S$ 中，那么 $a_y\ge a_x$（因为 $G$ 是按脂肪降序贪心得到的），并且把 $x$ 换成 $y$ 仍可行。这后半句需要论证：$y$ 所在类在 $S$ 中是否还有余量？如果 $S$ 中 $y$ 所在类已经满了，那么 $G$ 中同类的元素更多…… 需要仔细处理，见证明。

好，最后写实现。数据范围：$n\le 200$，$m\le 100$，$k\le 100$，$a_i\le 100$。注意第二行的配额"不超过 $10$"，但按题面它只说是正整数，我就按输入值处理，不写死 $10$。

输出一个整数，最大脂肪和 $\le m\cdot \max a_i \le 100\cdot 100 = 10^4$，`int` 足够。

## 二、思维链：完整证明

**记号约定**：把全部 $n$ 种食品看作集合 $E$；把第 $b$ 类食品构成的集合记作 $C_b$（$C_1,\dots,C_k$ 两两不交，并集为 $E$）；`lim[b]` 是第 $b$ 类的份数上限；$m$ 是总份数上限。

**引理 1**：一个食品集合 $S$ 可行（能作为一顿饭的选法）当且仅当
$$|S|\le m \quad\text{且}\quad \forall b,\ |S\cap C_b|\le \mathrm{lim}[b].$$

*证明*：题目的全部限制只有两条：总份数不超过 $m$；第 $b$ 类不超过 `lim[b]` 份。两条限制恰好是上面两个不等式，且它们合起来充分必要（反之任何满足它们的选法都符合题意）。证毕。

**引理 2**（层流结构）：集合族 $\{E,C_1,\dots,C_k\}$ 中，任意两个成员要么不交，要么一个包含另一个。

*证明*：$C_1,\dots,C_k$ 是 $E$ 的一个划分，故两两不交；每个 $C_b\subseteq E$。因此任取两个成员，要么是同一个 $C_b$（不交），要么一个是 $C_b$、另一个是 $E$（包含关系），要么都是 $E$。证毕。

**引理 3**（交换性）：设 $S,T$ 都可行且 $|S|<|T|$，则存在 $x\in T\setminus S$，使得 $S\cup\{x\}$ 仍可行。

*证明*：记 $B$ 为"在 $S$ 中配额已用满的类别"之集合，即 $B=\{b:\ |S\cap C_b|=\mathrm{lim}[b]\}$。

反设对所有 $x\in T\setminus S$，$S\cup\{x\}$ 都不可行。由引理 1，$S\cup\{x\}$ 不可行只可能是两种原因之一：

- $|S|+1>m$，即 $|S|=m$。但 $|S|<|T|$ 且 $T$ 可行故 $|T|\le m$，于是 $|S|=m\ge|T|$，与 $|S|<|T|$ 矛盾。故此情形不可能发生。
- $x$ 所在类 $b$ 在 $S$ 中已满，即 $|S\cap C_b|=\mathrm{lim}[b]$。

因此 $T\setminus S$ 中每个元素所在的类都属于 $B$。于是

$$T\setminus S\subseteq \bigcup_{b\in B}C_b .$$

另一方面，$T$ 可行给出对每个 $b\in B$：$|T\cap C_b|\le \mathrm{lim}[b]=|S\cap C_b|$，求和得
$$\Big|T\cap \bigcup_{b\in B}C_b\Big|\le \Big|S\cap \bigcup_{b\in B}C_b\Big| .$$
再对 $b\notin B$，由 $T\setminus S\subseteq\bigcup_{b\in B}C_b$ 知 $T\cap\bigcup_{b\notin B}C_b\subseteq S\cap\bigcup_{b\notin B}C_b$（否则存在 $x\in T\setminus S$ 落在非 $B$ 类中，矛盾），故
$$\Big|T\cap \bigcup_{b\notin B}C_b\Big|\le \Big|S\cap \bigcup_{b\notin B}C_b\Big| .$$
两式相加得 $|T|\le|S|$，与 $|S|<|T|$ 矛盾。故反设不成立，交换性成立。证毕。

**引理 4**（极大可行集合等势）：设 $G$ 是可行集合且无法再加入任何元素（极大可行集合），则任意可行集合 $S$ 都满足 $|S|\le |G|$。

*证明*：反设 $|S|>|G|$。由引理 3（交换性），存在 $x\in S\setminus G$ 使 $G\cup\{x\}$ 仍可行，与 $G$ 极大矛盾。证毕。

**引理 5**（贪心集合是极大可行集合）：设贪心按脂肪降序扫描得到的集合为 $G=\{g_1,g_2,\dots,g_r\}$（按加入顺序），则 $G$ 可行且极大。

*证明*：可行性显然：每次加入前都检查了总份数与该类配额。

再看极大性。任取 $e\notin G$。设贪心考察 $e$ 的那一刻已选集合为 $G_t\subseteq G$，则 $G_t\cup\{e\}$ 不可行（否则 $e$ 会被选入）。而可行性约束是"向下封闭"的：若 $G\cup\{e\}$ 可行，则其任意子集 $G_t\cup\{e\}$ 也可行。两者结合可知 $G\cup\{e\}$ 不可行。所以 $G$ 无法再加入任何元素，是极大可行集合。证毕。

**引理 6**（贪心最优）：对任意可行集合 $S$，有 $\sum_{x\in G}a_x\ge\sum_{x\in S}a_x$。

*证明*：记 $G_j=\{g_1,\dots,g_j\}$（贪心前 $j$ 次选入的元素），$a_{g_1}\ge a_{g_2}\ge\cdots\ge a_{g_r}$。

先注意一个关键性质：

> 性质 $\star$：$g_j$ 是所有"能与 $G_{j-1}$ 合并成可行集合"的食品中脂肪指数最大的一个。

因为贪心按脂肪降序扫描，跳过不可行的、接受第一个可行的，所以当它选入 $g_j$ 时，所有脂肪指数比 $a_{g_j}$ 更大的食品都已经被考察过且在当时被判为不可行。

严格地说：设某份食品 $x$ 能在 $G_{j-1}$ 的基础上加入，即 $G_{j-1}\cup\{x\}$ 可行。若 $x$ 在扫描中被考察过，那时贪心的已选集合是某个 $G_t\subseteq G_{j-1}$（$t\le j-1$）。由引理 1 的两条约束都是"向下封闭"的（集合变小则仍满足约束），可知 $G_t\cup\{x\}$ 也可行，于是贪心当时就会把 $x$ 选入，与 $x\notin G_{j-1}$ 矛盾。故 $x$ 必在 $g_j$ 之后被考察，从而 $a_x\le a_{g_j}$。性质 $\star$ 成立。

下面归纳证明更强的命题：

> 命题 $P(j)$：对任意大小恰为 $j$ 的可行集合 $S$，都有 $\sum_{x\in S}a_x\le\sum_{x\in G_j}a_x$。

**基例 $j=1$**：任一份食品单独选都可行（总份数 $1\le m$，该类 $1\le\mathrm{lim}[b]$），而贪心第一步选的就是全体食品中脂肪指数最大的那一份，故 $P(1)$ 成立。

**归纳步骤**：设 $P(j-1)$ 成立。取任意大小为 $j$ 的可行集合 $S$。

- 由 $|S|=j>|G_{j-1}|=j-1$ 及两者可行，引理 3 给出 $x\in S\setminus G_{j-1}$，使 $G_{j-1}\cup\{x\}$ 可行。
- 由性质 $\star$，$x$ 是 $g_j$ 的候选者，故 $a_x\le a_{g_j}$。
- $S' = S\setminus\{x\}$ 是 $S$ 的子集，故仍可行，大小为 $j-1$。由归纳假设 $P(j-1)$，$\sum_{y\in S'}a_y\le\sum_{y\in G_{j-1}}a_y$。

两式相加：
$$\sum_{y\in S}a_y=a_x+\sum_{y\in S'}a_y\le a_{g_j}+\sum_{y\in G_{j-1}}a_y=\sum_{y\in G_j}a_y .$$
故 $P(j)$ 成立。

最后处理 $|S|\ne r$ 的情形。由引理 4、5，$G$ 极大，故任意可行 $S$ 满足 $|S|\le r$。

- 若 $|S|=s\le r$，由 $P(s)$ 得 $\sum_{y\in S}a_y\le\sum_{y\in G_s}a_y$；又因所有 $a_{g_j}>0$（数据范围 $a_i\ge 1$），有 $\sum_{y\in G_s}a_y\le\sum_{y\in G}a_y$。
- 若 $|S|>r$，由引理 4 不可能发生。

综上，$\sum_{y\in S}a_y\le\sum_{y\in G}a_y$ 对一切可行 $S$ 成立。证毕。

**定理**：算法输出的答案是最大脂肪指数和。

*证明*：算法按脂肪降序扫描、可行就加入，正是引理 6 中刻画的最优贪心；可行性判定由引理 1 给出（检查总份数与该类配额）。故输出的总脂肪指数和最大。证毕。

## 三、模式总结（按实际思考顺序）

1. **翻译题意 → 两个不等式** — 总份数 $\le m$，每类份数 $\le \mathrm{lim}[b]$。
2. **先试排序贪心** — 按脂肪降序、可吃就吃，直觉上显然最优。
3. **但要证** — 担心"提前用光某类配额会浪费数量"，于是去找反例，没找到。
4. **识别约束结构：层流** — 各类集合两两不交、都被全集包含，$\{E,C_1,\dots,C_k\}$ 是层流族。
5. **层流 ⇒ 可行集满足交换公理 ⇒ 降序贪心最优** — 用交换论证直接证（引理 3、6）。
6. **实现** — 排序后一趟扫描，`lim[b]` 边吃边减，`m` 边吃边减。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 食品种数 | `int`，$\le 200$ |
| $m$ | 一顿最多吃几份 | `int`，$\le 100$ |
| $k$ | 类别数 | `int`，$\le 100$ |
| $a_i$ | 第 $i$ 份食品的脂肪指数 | `int`，$[1,100]$ |
| $b_i$ | 第 $i$ 份食品所属类别 | `int`，$[1,k]$ |
| $\mathrm{lim}[b]$ | 第 $b$ 类最多吃几份 | `int[]`，下标 $1..k$ |
| `f[i]` | 排序后的第 $i$ 份食品 | `struct{int a,b;}` |
| `ans` | 累计脂肪指数和 | `int`，$\le 10^4$ |

### 算法步骤

1. 读入 $n,m,k$。
2. 读入 `lim[1..k]`。
3. 读入 $n$ 份食品的 $(a_i,b_i)$ 存入 `f[]`。
4. 把 `f[]` 按 $a$ **降序**排序（$a$ 相同时顺序任意，不影响最优性）。
5. 从 $i=0$ 开始扫描，`m` 份上限与各类配额同时递减：
   - 若 `m<=0`（吃满了）则停止；
   - 若 `lim[f[i].b] > 0`（该类还有配额）则吃下：答案加上 `f[i].a`，`lim[f[i].b]--`，`m--`；
   - 否则跳过这一份（该类已满，后面同类的更小的脂肪也不必再看）。
6. 输出 `ans`。

### 复杂度

- 时间复杂度：$O(n\log n)$，排序占主导，扫描 $O(n)$。
- 空间复杂度：$O(n+k)$。

### 验证状态

- 标程 `P2095.cpp` 用 `g++ -O2 -std=c++17` 编译通过。
- 题面官方样例 `6 6 3 / 3 3 2 / 15 1 / 15 2 / 10 2 / 15 2 / 10 2 / 5 3` 输出 `60`，与官方一致。
- 编写暴力 `P2095_brute.cpp`（枚举全部 $2^n$ 个子集，检查总份数与每类配额后取最大脂肪和）与对拍脚本 `P2095_check.py`，在 $n\le 12$、$m\le 8$、$k\le 4$ 的随机数据上对拍 **2000 组全部通过**。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2095 营养膳食
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{205};

int n,m,k;
int lim[mxn];
struct food{int a,b;}f[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>k;
	for(int i=1;i<=k;++i)
		cin>>lim[i];
	for(int i=0;i<n;++i)
		cin>>f[i].a>>f[i].b;
	sort(f,f+n,[](food x,food y){
		return x.a>y.a;
	});
	int ans=0;
	for(int i=0;i<n&&m>0;++i)
	{
		if(lim[f[i].b]>0)
		{
			lim[f[i].b]--;
			--m;
			ans+=f[i].a;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `lim[]` 是"剩余配额"，吃到一份就 `--`，省去额外记录已吃份数。
- `m` 直接当作"剩余可吃份数"用，每次吃一份 `--`，循环条件 `i<n&&m>0` 同时实现了"吃满即停"。
- 排序比较器只按 `a` 降序；`a` 相同的食品顺序任意（拟阵贪心下同权元素的取舍不影响总脂肪最优值）。
- 某类配额用尽后，该类剩余食品都会被 `lim[f[i].b]>0` 拦下自动跳过，不必单独分类处理。
- 答案上界 $m\cdot \max a_i\le 10^4$，`int` 足够。
