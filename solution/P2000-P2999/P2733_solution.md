# P2733 [USACO3.3] 家的范围 Home on the Range — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N\times N$ 的 $0/1$ 网格（$2\le N\le250$），$1$ 表示完好、$0$ 表示被毁。统计**所有边长 $\ge2$ 的全 $1$ 正方形**的个数（允许重叠），按边长从小到大输出「边长 个数」，每个存在的边长一行。

**第一反应：暴力枚举正方形。** 一个正方形由「右下角 $(i,j)$ + 边长 $s$」确定，共 $O(N^3)$ 个候选；每个用二维前缀和 $O(1)$ 判断是否全 $1$。总量 $O(N^3)=250^3\approx1.6\times10^7$，其实能过。但写起来要预处理前缀和、三重循环，略笨。有没有更漂亮的？

**第二步：认出经典模型——「最大正方形」DP。** 标签里有「动态规划、前缀和」。我想到一个经典状态：

$$dp[i][j]=\text{以 }(i,j)\text{ 为右下角的、最大的全 }1\text{ 正方形的边长}.$$

它的递推是著名的「三邻居取 min 加一」：若 $g[i][j]=1$，

$$dp[i][j]=\min\bigl(dp[i-1][j],\ dp[i][j-1],\ dp[i-1][j-1]\bigr)+1,$$

否则 $dp[i][j]=0$。直觉：要在 $(i,j)$ 撑起一个边长 $s$ 的正方形，它的「上边一行、左边一列、左上角那块」必须都撑得起 $s-1$，三者里最矮的那个决定了上限。这个递推把「枚举所有边长」压成了「每个格子算一次」，$O(N^2)$。

**第三步：从「最大边长」到「各边长计数」——本题真正的思维跳跃。** 题目要的不是最大正方形，而是**每个边长各有多少个**。乍看 $dp$ 只给了最大值，好像信息不够。但仔细想：

> 如果一个格子能撑起边长 $d$ 的全 $1$ 正方形，那它**同时**是边长 $1,2,\dots,d$ 的正方形的右下角（大正方形里嵌套着同右下角的小正方形）。

反过来，一个边长 $s$ 的正方形有**唯一**的右下角。于是：

$$\text{边长 }s\text{ 的正方形个数}=\#\{(i,j):dp[i][j]\ge s\}.$$

这就把「计数」变成了「对 $dp$ 值做后缀统计」！令 $freq[d]$ 为 $dp$ 恰等于 $d$ 的格子数，则边长 $s$ 的个数 $=\sum_{d\ge s}freq[d]$，一个**后缀和**搞定。

**第四步：边界与输出。** 用 $1$-based 的 $dp$，把第 $0$ 行、第 $0$ 列当作哨兵 $0$（全局数组默认就是 $0$），递推式在边界也统一成立，不用特判。最后从 $s=2$ 到 $N$ 扫一遍，个数 $>0$ 就输出「$s$ 个数」。若没有任何 $\ge2$ 的正方形，自然一行都不输出（题面只要求输出「存在的」边长）。

**手造数据核对**（题面无样例，我手算了几组）：

第一组，$4\times4$ 全 $1$：

```
4
1111
1111
1111
1111
```

$dp$ 表（$1$-based）：

```
1 1 1 1
1 2 2 2
1 2 3 3
1 2 3 4
```

$freq[1]=7,freq[2]=5,freq[3]=3,freq[4]=1$。后缀和：边长 $2$ 个数 $=5+3+1=9$，边长 $3=3+1=4$，边长 $4=1$。输出：

```
2 9
3 4
4 1
```

手算验证：$4\times4$ 全 $1$ 网格里，$2\times2$ 正方形有 $3\times3=9$ 个、$3\times3$ 有 $2\times2=4$ 个、$4\times4$ 有 $1$ 个，完全吻合。

第二组，$3\times3$ 中间挖空：

```
3
111
101
111
```

中心是 $0$，任何 $2\times2$ 都必然盖到中心 → 没有 $\ge2$ 的正方形，输出为空。程序确实无输出。

第三组，左上角一个 $2\times2$：

```
3
110
110
000
```

只有左上角一个 $2\times2$ 全 $1$，输出 `2 1`。程序吻合。

这三组分别覆盖了「全 $1$ 满网格」「中心障碍导致无解」「稀疏小计数」，把递推、后缀计数、空输出都验证到了。

## 二、思维链：完整证明

**记号。** 网格 $g[1..N][1..N]\in\{0,1\}$。定义 $dp[i][j]$（$1\le i,j\le N$）为「以 $(i,j)$ 为右下角的全 $1$ 正方形的最大边长」，若 $g[i][j]=0$ 则为 $0$。约定哨兵 $dp[0][j]=dp[i][0]=0$。令 $freq[d]=\#\{(i,j):dp[i][j]=d\}$，$\mathrm{cnt}[s]=\#\{(i,j):dp[i][j]\ge s\}$。

---

### 引理 1（最大正方形递推）

若 $g[i][j]=0$，则 $dp[i][j]=0$。若 $g[i][j]=1$，则
$$dp[i][j]=\min\bigl(dp[i-1][j],\ dp[i][j-1],\ dp[i-1][j-1]\bigr)+1.$$

*证明*：$g[i][j]=0$ 时任何含 $(i,j)$ 的正方形都不是全 $1$，故 $dp[i][j]=0$。下设 $g[i][j]=1$，记 $m=\min(dp[i-1][j],dp[i][j-1],dp[i-1][j-1])$，证 $dp[i][j]=m+1$，分两个方向。

**（$\le$：$dp[i][j]\le m+1$）** 设 $s=dp[i][j]\ge1$，即以 $(i,j)$ 为右下角的 $s\times s$ 区域 $R=[i-s+1,i]\times[j-s+1,j]$ 全 $1$。考察三个 $(s-1)\times(s-1)$ 子区域：
- 以 $(i-1,j)$ 为右下角：$[i-s+1,i-1]\times[j-s+2,j]\subseteq R$，全 $1$，故 $dp[i-1][j]\ge s-1$；
- 以 $(i,j-1)$ 为右下角：$[i-s+2,i]\times[j-s+1,j-1]\subseteq R$，全 $1$，故 $dp[i][j-1]\ge s-1$；
- 以 $(i-1,j-1)$ 为右下角：$[i-s+1,i-1]\times[j-s+1,j-1]\subseteq R$，全 $1$，故 $dp[i-1][j-1]\ge s-1$。

（当 $s=1$ 时子区域边长 $0$，$dp\ge0$ 平凡成立；当 $i=1$ 或 $j=1$ 时用到哨兵 $dp[0][\cdot]=0$，不等式仍成立。）三者都 $\ge s-1$，故 $m\ge s-1$，即 $s\le m+1$。

**（$\ge$：$dp[i][j]\ge m+1$）** 若 $m=0$，则 $g[i][j]=1$ 本身给出边长 $1=m+1$ 的正方形，成立。设 $m\ge1$。由 $dp[i-1][j]\ge m$、$dp[i][j-1]\ge m$、$dp[i-1][j-1]\ge m$，下面三个 $m\times m$ 区域全 $1$：
- $A=[i-m,i-1]\times[j-m+1,j]$（右下角 $(i-1,j)$）；
- $B=[i-m+1,i]\times[j-m,j-1]$（右下角 $(i,j-1)$）；
- $C=[i-m,i-1]\times[j-m,j-1]$（右下角 $(i-1,j-1)$）。

要证 $(m+1)\times(m+1)$ 区域 $R'=[i-m,i]\times[j-m,j]$ 全 $1$。把 $R'$ 的格子按「行是否 $=i$、列是否 $=j$」分四类（相对坐标 $r=i-m..i$、$c=j-m..j$）：
- $r\le i-1,\ c\le j-1$：被 $C$ 覆盖；
- $r\le i-1,\ c=j$：被 $A$ 覆盖（$A$ 的列含 $j$，行含 $i-m..i-1$）；
- $r=i,\ c\le j-1$：被 $B$ 覆盖（$B$ 的行含 $i$，列含 $j-m..j-1$）；
- $r=i,\ c=j$：即 $(i,j)$，$g[i][j]=1$。

四类穷尽 $R'$，每格都属于某个全 $1$ 区域或就是 $(i,j)$，故 $R'$ 全 $1$，$dp[i][j]\ge m+1$。

双向夹逼得 $dp[i][j]=m+1$。证毕。

---

### 引理 2（计数双射：边长 $s$ 的个数 $=\#\{dp\ge s\}$）

对 $1\le s\le N$，全 $1$ 的边长 $s$ 正方形个数等于 $\mathrm{cnt}[s]=\#\{(i,j):dp[i][j]\ge s\}$。

*证明*：每个边长 $s$ 的正方形由其右下角 $(i,j)$ **唯一**确定（右下角 + 边长唯一确定正方形位置）。故「边长 $s$ 的全 $1$ 正方形」与「满足『以 $(i,j)$ 为右下角的 $s\times s$ 区域全 $1$』的格子 $(i,j)$」一一对应。

下证：以 $(i,j)$ 为右下角的 $s\times s$ 区域全 $1$ $\iff dp[i][j]\ge s$。
-（$\Rightarrow$）若该 $s\times s$ 区域全 $1$，则存在以 $(i,j)$ 为右下角、边长 $s$ 的全 $1$ 正方形，最大边长 $dp[i][j]\ge s$。
-（$\Leftarrow$）若 $dp[i][j]=d\ge s$，则 $d\times d$ 区域 $[i-d+1,i]\times[j-d+1,j]$ 全 $1$；其子区域 $[i-s+1,i]\times[j-s+1,j]$（边长 $s$，同右下角）因 $s\le d$ 而被包含，故也全 $1$。

于是边长 $s$ 的正方形个数 $=\#\{(i,j):dp[i][j]\ge s\}=\mathrm{cnt}[s]$。证毕。

**注**：这条引理是「最大正方形 DP」能顺便解决「各边长计数」的关键——$dp$ 虽只存最大值，但「$\ge s$」恰好刻画了「能放下边长 $s$」，嵌套结构让一个格子同时贡献给所有 $\le dp$ 的边长。

---

### 引理 3（后缀和计算 $\mathrm{cnt}$）

$freq[d]=\#\{dp=d\}$，则 $\mathrm{cnt}[s]=\sum_{d=s}^{N}freq[d]$。就地递推 `for(s=N-1 downto 1) freq[s]+=freq[s+1]` 后，$freq[s]=\mathrm{cnt}[s]$。

*证明*：$\{dp\ge s\}=\bigsqcup_{d=s}^{N}\{dp=d\}$（按 $dp$ 的确切值划分，互不相交），故 $\mathrm{cnt}[s]=\sum_{d\ge s}freq[d]$。又 $dp\le N$（正方形边长不超过网格边长），故求和上界为 $N$。

就地递推：初始 $freq[N]=\mathrm{cnt}[N]$（无 $dp>N$）。设处理到 $s+1$ 时已有 $freq[s+1]=\mathrm{cnt}[s+1]=\sum_{d\ge s+1}freq_{\text{原}}[d]$。执行 $freq[s]\mathrel{+}=freq[s+1]$ 后，$freq[s]=freq_{\text{原}}[s]+\mathrm{cnt}[s+1]=\sum_{d\ge s}freq_{\text{原}}[d]=\mathrm{cnt}[s]$。从 $s=N-1$ 递减到 $1$ 归纳成立。证毕。

---

### 引理 4（哨兵边界）

取 $dp[0][j]=dp[i][0]=0$（全局数组默认值），则引理 1 的递推对 $i=1$ 或 $j=1$ 的边界格子同样给出正确值，无需特判。

*证明*：以 $i=1,j\ge1$ 为例（顶行）。真实情况下顶行格子最多撑起边长 $1$ 的正方形（上方无行）。递推中 $dp[i-1][j]=dp[0][j]=0$、$dp[i-1][j-1]=dp[0][j-1]=0$，故 $m=\min(0,dp[1][j-1],0)=0$，$dp[1][j]=0+1=1$（当 $g=1$），正确。$j=1$（左列）同理 $dp[i][0]=0$ 使 $m=0$。角点 $(1,1)$：三个哨兵全 $0$，$dp=1$。故哨兵 $0$ 恰好把「边界外无格子」编码成「撑不起任何正方形」，递推统一成立。证毕。

**实现陷阱**：全局 `int` 数组默认 $0$，这里**恰好**是需要的哨兵值，无需显式填充；但若把 $dp$ 改成局部数组或复用，就必须显式清零第 $0$ 行/列。

---

### 引理 5（复杂度）

时间 $O(N^2)$，空间 $O(N^2)$。

*证明*：读入 $O(N^2)$ 个字符。DP 双重循环 $N^2$ 个格子，每格一次 $\min$（三元素）与加法，$O(1)$，共 $O(N^2)$。后缀和 $O(N)$，输出 $O(N)$。总计 $O(N^2)$。$N=250$ 时 $N^2=62500$，极快。空间：$dp$ 为 $(N+1)^2$ 个 `int`，$g$ 为 $N\times N$ 字符，$freq$ 为 $N+1$ 个 `int`，共 $O(N^2)$，约 $255^2\times4\approx260$ KB。证毕。

---

### 定理

程序按边长递增输出每个存在的全 $1$ 正方形（边长 $\ge2$）的「边长 个数」。

*证明*：引理 1、4 保证 $dp$ 表正确（含边界）；引理 2 保证边长 $s$ 的个数 $=\mathrm{cnt}[s]$；引理 3 保证后缀和正确算出 $\mathrm{cnt}$；输出从 $s=2$ 到 $N$ 递增、仅输出 $\mathrm{cnt}[s]>0$ 的行，符合题面「输出存在的正方形边长和个数，一种一行」。引理 5 保证效率。证毕。

## 三、模式总结（按实际思考顺序）

- **consider easier version** — 先想暴力：枚举右下角 + 边长 + 二维前缀和判全 $1$，$O(N^3)\approx1.6\times10^7$ 可过但笨。
- **classic problem solution** — 认出「最大正方形」DP：$dp[i][j]=\min(\text{上},\text{左},\text{左上})+1$，把枚举压成 $O(N^2)$。
- **explore its property** — 嵌套结构：$dp=d$ 的格子同时是边长 $1..d$ 正方形的右下角 ⇒ 边长 $s$ 个数 $=\#\{dp\ge s\}$。
- **reduce to easier problem** — 「各边长计数」归约为对 $dp$ 值做后缀和：$freq[d]$ 统计恰为 $d$，后缀累加得 $\mathrm{cnt}[s]$。
- **discuss by category** — 哨兵第 $0$ 行/列统一边界；只输出 $s\ge2$ 且个数 $>0$；无解时自然空输出。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `n` | 网格边长 $N$（$\le250$） | `int`，读入 | |
| `g[i][j]` | 网格字符（$0$-based 读入） | `char[mxn][mxn]` | `'1'` 完好 / `'0'` 毁坏 |
| `dp[i][j]` | 以 $(i,j)$ 为右下角的最大全 $1$ 正方形边长（$1$-based） | `int[mxn][mxn]`，全局默认 $0$ | 第 $0$ 行/列是哨兵 $0$ |
| `freq[d]` | 先：$dp$ 恰为 $d$ 的格子数；后缀和后：$dp\ge d$ 的格子数 | `int[mxn]`，默认 $0$ | 一个数组两用 |
| `s` | 当前边长 | `int` | 输出从 $2$ 到 $n$ |
| `mxn` | $250+5$ | `constexpr int{255}` | +5 松弛 |

### 算法步骤

1. I/O 加速三行。
2. 读 `n`，逐行读 `g[i]`（$i=0..n-1$，每行 $n$ 个字符）。
3. 双重循环 `i,j=1..n`：若 `g[i-1][j-1]=='1'`，`dp[i][j]=min({dp[i-1][j],dp[i][j-1],dp[i-1][j-1]})+1`，`++freq[dp[i][j]]`。
4. 后缀和：`for(s=n-1;s>=1;--s) freq[s]+=freq[s+1]`。
5. `for(s=2;s<=n;++s)` 若 `freq[s]>0` 输出 `s freq[s]`。

### 复杂度

- 时间：$O(N^2)$，$N=250$ 时约 $6.25\times10^4$ 次转移。
- 空间：$O(N^2)$，$dp$ 约 $260$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$4\times4$ 全 $1$ 输出 `2 9 / 3 4 / 4 1`（与手算 $9,4,1$ 吻合）；「中心挖空 → 空输出」「左上单个 $2\times2$ → 2 1」两组手算数据全对。本题为经典 DP，未写暴力对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2733 [USACO3.3] 家的范围 Home on the Range
// 思路：dp[i][j] = 以 (i,j) 为右下角的最大全 1 正方形边长。
//       g=1 时 dp[i][j]=min(上,左,左上)+1，否则 0；第 0 行/列作哨兵 0（全局默认）。
//       边长 s 的正方形个数 = dp>=s 的格子数 = freq 的后缀和。输出 s>=2 且个数>0 的行。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{255};

int n,dp[mxn][mxn],freq[mxn];
char g[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>g[i];
	for(int i=1;i<=n;++i)
		for(int j=1;j<=n;++j)
			if(g[i-1][j-1]=='1')
			{
				dp[i][j]=min({dp[i-1][j],dp[i][j-1],dp[i-1][j-1]})+1;
				++freq[dp[i][j]];
			}
	for(int s=n-1;s>=1;--s)	// 后缀和：freq[s] 变为「dp>=s 的格子数」
		freq[s]+=freq[s+1];
	for(int s=2;s<=n;++s)
		if(freq[s])
			cout<<s<<' '<<freq[s]<<'\n';
	return 0;
}
```

### 代码说明

- **`dp` 用 $1$-based、`g` 用 $0$-based**：`dp[i][j]` 对应 `g[i-1][j-1]`，这样第 $0$ 行/列天然是哨兵 $0$，递推 `min({上,左,左上})+1` 在边界也统一成立，无需 `if(i==0||j==0)` 特判。
- **`min({...})` 三元素**：C++11 起的 `initializer_list` 版 `min`，一次取三个邻居最小值，比嵌套 `min(min(a,b),c)` 清爽。
- **`freq` 一个数组两用**：先累计「$dp$ 恰为 $d$」的格子数，再就地后缀和变成「$dp\ge d$」的格子数（引理 3），省一个数组。
- **后缀和从 `n-1` 递减到 `1`**：`freq[n]` 本身就是 $\mathrm{cnt}[n]$（无 $dp>n$），不用动；递减保证 `freq[s+1]` 已是后缀和。
- **只输出 `s>=2` 且 `freq[s]>0`**：题面要求边长 $\ge2$、只输出存在的边长；无解时循环不输出任何行，正确。
- **全局默认 $0$ 恰好是哨兵**：本题 $dp$ 的「不可达/边界」值就是 $0$，与全局默认一致，无需显式 `fill`（与「不可达必须填 INF」的题相反，这里 $0$ 是合法哨兵）。
