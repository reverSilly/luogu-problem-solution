# P2842 纸币问题 1 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $n$ 种纸币，第 $i$ 种面额 $a_i$，**每种无限张**。要恰好凑出金额 $w$，求最少张数（保证有解）。范围：$1\le n\le 10^3$，$1\le a_i,w\le 10^4$；$40\%$ 的数据 $n\le 10,w\le 100$。

先读范围猜意图：$n\cdot w=10^3\times10^4=10^7$，这个乘积不大不小，恰好是"枚举每种纸币 $\times$ 每个金额"的二维 DP 的规模。标签也写着"背包 DP"。但我不想直接套模板——先把最自然的想法试一遍，看它死在哪里。

**第一步：贪心行不行？** 生活经验（人民币面额 $1,5,10,20,50,100$）告诉我：每次拿不超过剩余金额的最大面额，似乎就是最优。但题目给的是**任意**面额集合，生活经验不能直接搬。构造最小反例：$a=\{1,3,4\}$，$w=6$。

- 贪心：先拿 $4$，剩 $2$，再拿 $1+1$，共 $3$ 张；
- 最优：$3+3$，只要 $2$ 张。

贪心错了。错在哪？贪心默认"最大面额一定出现在某个最优解里"，但这里 $6=3+3$ 根本不用 $4$。拿 $4$ 之后剩下的 $2$ 是个"烂尾金额"，只能靠两张 $1$ 收尾；而少拿一点、把金额拆成两个 $3$，反而更省。**局部最优（这一步拿最大）推不出全局最优（总张数最少）**，因为剩余金额的"可凑性结构"被这一步破坏了。贪心淘汰。

**第二步：退到小数据想搜索。** $40\%$ 子任务 $n\le 10,w\le 100$，可以 DFS 枚举每种纸币用几张。但仔细一想，搜索树里大量重复：凑出金额 $j$ 的最少张数，**与之前按什么顺序拿的纸币完全无关**——张数只取决于"各面额各用了几张"，而约束只有"面额加权和 $=j$"。所以走到剩余金额 $j$ 时，历史可以全部忘掉，状态只需要一个数 $j$。这就是无后效性。记忆化之后，状态数只有 $w+1$ 个。

**第三步：把"最后一张纸币"作为决策。** 设 $f(j)$ 为凑出 $j$ 的最少张数。任何一个凑出 $j$ 的方案，手里总有"最后一张"纸币（顺序无所谓，随便指定一张），设它面额 $a_i$，那么其余纸币恰好凑出 $j-a_i$。于是

$$f(j)=\min_{i:\,a_i\le j}\bigl(f(j-a_i)+1\bigr),\qquad f(0)=0.$$

因为 $a_i\ge 1$，$j-a_i<j$，右端只依赖更小的金额——按 $j$ 从小到大递推即可，无后效性在这里落地成了拓扑序。

**第四步：认出来这是完全背包。** 把"纸币种类"看成物品、"金额"看成容量、"张数"看成价值（求 min），每件物品无限个——这就是**完全背包的最值形式**。标准写法：外层枚举面额 $i$，内层金额 $j$ **升序**从 $a_i$ 到 $w$：

$$\texttt{dp}[j]\leftarrow\min(\texttt{dp}[j],\texttt{dp}[j-a_i]+1).$$

为什么升序就实现了"无限张"？因为更新 $\texttt{dp}[j]$ 时用到的 $\texttt{dp}[j-a_i]$ 下标更小，**本轮已经被更新过**，它里面可能已经用了若干张第 $i$ 种纸币——再叠一张，就是"同一种用多次"。对照 01 背包：那里必须降序，保证 $\texttt{dp}[j-a_i]$ 还是上一轮（没用过第 $i$ 件）的值。一个循环方向，区分了两种背包，这是必须在证明里抠死的点（引理 4）。

**第五步：两个实现层面的坑。**

1. **INF 预填充。** 全局 `int dp[]` 默认是 $0$，而 $0$ 是合法答案（"凑出 $0$ 要 $0$ 张"）。如果不把"凑不出"的状态显式填成 INF，递推会把所有金额都当成 $0$ 张可达，输出恒 $0$。必须 `fill_n(dp,w+1,inf)` 后再 `dp[0]=0`。这是全局数组移植的经典坑。
2. **INF 的算术安全。** 取 `inf=1145141919`，则 `inf+1=1145141920` 仍在 `int` 范围内（$<2^{31}-1$），不会溢出成负数；且 $\min(\texttt{inf},\texttt{inf}+1)=\texttt{inf}$，不可达状态不会被"inf+1"污染成别的值（引理 5 会证明不变量）。另外 $a_i>w$ 时内层循环 `for(j=a[i];j<=w;...)` 自然为空，无需特判。

**手造数据核对**（题面无样例，按规则自造）：

| 输入 | 手算 | 说明 |
|---|---|---|
| `3 6` / `1 3 4` | $2$ | 贪心反例，$3+3$ |
| `2 10` / `2 5` | $2$ | $5+5$，贪心此处恰好也对 |
| `3 11` / `3 5 7` | $3$ | $3+3+5$；贪心先拿 $7$ 剩 $4$ 直接凑不出，连可行性都保证不了 |
| `1 10000` / `1` | $10000$ | 极限规模，全 $1$ |

第三组特别说明问题：贪心不但可能不优，还可能把"有解"走成"无解"，而 DP 不受影响。

## 二、思维链：完整证明

**记号。** 面额集 $A=\{a_1,\dots,a_n\}$（可重复，重复不影响任何结论），$1\le a_i\le 10^4$。目标金额 $w$。"方案"指一个计数向量 $(x_1,\dots,x_n)\in\mathbb Z_{\ge0}^n$ 满足 $\sum x_i a_i=j$，代价为 $\sum x_i$。$f(j)$ 为凑出 $j$ 的最小代价，无解记 $+\infty$。$f_i(j)$ 为只允许使用前 $i$ 种面额时的最小代价。

### 引理 1（贪心不成立：反例与失效机理）

对 $A=\{1,3,4\},w=6$，"每次取不超过剩余金额的最大面额"输出 $3$ 张，而最优为 $2$ 张。

*证明*：穷举 $6$ 的全部方案（按 $4$ 的张数分类）：用 $1$ 张 $4$ 则余 $2$，只能 $1+1$，共 $3$ 张；不用 $4$ 则 $3$ 的张数可为 $2$（$3+3$，$2$ 张）、$1$（$3+1+1+1$，$4$ 张）、$0$（六个 $1$，$6$ 张）。最小值 $2$。贪心执行：$6\ge4$ 取 $4$ 剩 $2$；$2<3$ 取 $1$ 剩 $1$；取 $1$ 剩 $0$，共 $3$ 张。$3>2$，贪心错。

机理：贪心正确需要"存在包含最大面额的最优解"（贪心选择性质）。此处 $6$ 的唯一最优解 $3+3$ 不含 $4$，性质不成立。人民币面额体系恰好满足该性质（所谓 canonical coin system），但题目面额任意，不能继承。证毕。

### 引理 2（最优子结构：最后一张递推）

$f(0)=0$；对 $j\ge1$，
$$f(j)=\min_{i:\,a_i\le j}\bigl(f(j-a_i)+1\bigr),$$
其中 $\min$ 在空集上定义为 $+\infty$，且 $+\infty+1=+\infty$。

*证明*：对 $j$ 归纳。$j=0$：空方案代价 $0$，且任何方案代价 $\ge0$，故 $f(0)=0$。

设 $j\ge1$ 且结论对所有更小金额成立。分两个方向。

**($\le$)**：对任一 $a_i\le j$，取凑出 $j-a_i$ 的最优方案（若 $f(j-a_i)=+\infty$ 则右端为 $+\infty$，不等式平凡成立），追加一张面额 $a_i$，得到凑出 $j$ 的合法方案，代价 $f(j-a_i)+1$。$f(j)$ 是所有合法方案的最小值，故 $f(j)\le f(j-a_i)+1$；对 $i$ 取 $\min$ 得 $f(j)\le$ 右端。

**($\ge$)**：若 $f(j)=+\infty$ 平凡。否则取凑出 $j$ 的最优方案 $(x_1,\dots,x_n)$，代价 $f(j)\ge1$（因 $j\ge1$），故存在 $x_i\ge1$。令 $x_i'=x_i-1$，其余不变，则 $\sum x'_k a_k=j-a_i$，是凑出 $j-a_i$ 的合法方案，代价 $f(j)-1$。于是 $f(j-a_i)\le f(j)-1$，即 $f(j)\ge f(j-a_i)+1\ge\min$ 右端。

两方向夹逼得等式。右端只涉及 $j-a_i<j$，归纳良基。证毕。

**推论**：按 $j=0,1,\dots,w$ 顺序计算即可；状态数 $w+1$，每个状态转移 $O(n)$，直接实现是 $O(nw)$。

### 引理 3（分阶段递推）

定义 $f_0(0)=0$，$f_0(j)=+\infty\ (j\ge1)$。对 $i\ge1$：
$$f_i(j)=\begin{cases}f_{i-1}(j),&j<a_i,\\ \min\bigl(f_{i-1}(j),\;f_i(j-a_i)+1\bigr),&j\ge a_i.\end{cases}$$

*证明*：$j<a_i$ 时第 $i$ 种一张也用不了，$f_i(j)=f_{i-1}(j)$。$j\ge a_i$ 时，把"只用前 $i$ 种凑出 $j$"的方案按 $x_i$ 是否为 $0$ 分类：

- $x_i=0$：方案只用前 $i-1$ 种，最小代价 $f_{i-1}(j)$；
- $x_i\ge1$：拿走一张第 $i$ 种（引理 2 的 ($\ge$) 方向操作），剩下是"只用前 $i$ 种凑出 $j-a_i$"的方案，代价 $\ge f_i(j-a_i)+1$；反之任一这样的方案加一张第 $i$ 种即回到本类（引理 2 的 ($\le$) 方向操作）。故本类最小代价恰为 $f_i(j-a_i)+1$。

两类取 $\min$ 即得。注意第二项是 $f_i$ 而非 $f_{i-1}$：拿走一张后**仍允许再用第 $i$ 种**，这正是"无限张"与 01 背包的分水岭。证毕。

### 引理 4（滚动数组 + 升序循环实现引理 3）

代码执行 `dp[0]=0; dp[1..w]=inf;` 后，对 $i=1..n$ 依次执行 `for(j=a[i];j<=w;++j) dp[j]=min(dp[j],dp[j-a[i]]+1);`。则第 $i$ 轮结束后，对所有 $0\le j\le w$ 有 $\texttt{dp}[j]=f_i(j)$。

*证明*：对 $i$ 归纳。$i=0$（初始）：$\texttt{dp}[0]=0=f_0(0)$，其余 $\texttt{inf}=f_0(j)$，成立。

设第 $i-1$ 轮结束后 $\texttt{dp}[j]=f_{i-1}(j)$ 对所有 $j$ 成立。考察第 $i$ 轮，对 $j$ 从小到大归纳：

- $j<a_i$：循环不触碰，$\texttt{dp}[j]$ 保持 $f_{i-1}(j)=f_i(j)$（引理 3 第一行）。
- $j\ge a_i$：更新前，$\texttt{dp}[j]$ 尚未被本轮触碰（升序，本轮只处理过 $<j$ 的下标），故其值为 $f_{i-1}(j)$；而 $j-a_i<j$，由内层归纳假设 $\texttt{dp}[j-a_i]$ 已是本轮更新后的值 $f_i(j-a_i)$。于是赋值恰好计算 $\min(f_{i-1}(j),f_i(j-a_i)+1)=f_i(j)$（引理 3 第二行）。

内层归纳对 $j=0..w$ 全部成立，外层归纳完成。特别地，$a_i>w$ 时循环为空，$\texttt{dp}$ 不变，与引理 3 的 $j<a_i$ 分支一致。

**升序的作用**：$\texttt{dp}[j-a_i]$ 取到的是 $f_i$（本轮已更新）而非 $f_{i-1}$，允许第 $i$ 种被重复使用。若改成降序，$\texttt{dp}[j-a_i]$ 还是 $f_{i-1}$，实现的就是 01 背包——一字之差，语义全变。证毕。

### 引理 5（INF 不变量与算术安全）

取 $\texttt{inf}=1145141919$。整个过程中：(a) 每个 $\texttt{dp}[j]\in\{\text{真实最优值}\}\cup\{\texttt{inf}\}$，即 $\texttt{dp}[j]\le\texttt{inf}$ 恒成立，且 $\texttt{dp}[j]=\texttt{inf}$ 当且仅当该金额（在当前阶段）不可达；(b) 所有加法不溢出 `int`。

*证明*：(b) 过程中出现的最大算术值是 $\texttt{inf}+1=1145141920<2^{31}-1=2147483647$；真实最优值 $\le w\le10^4$（全用面额 $1$ 的张数上界，若有解），加 $1$ 后 $\le10^4+1$。故无溢出。

(a) 对操作次数归纳。初始：$\texttt{dp}[0]=0$ 是真实值，其余 $\texttt{inf}$ 表示不可达（$f_0$ 定义），成立。每次操作 $\texttt{dp}[j]\leftarrow\min(\texttt{dp}[j],\texttt{dp}[j-a_i]+1)$：由归纳假设两个被比较的值都 $\le\texttt{inf}$ 或等于 $\texttt{inf}$。若 $\texttt{dp}[j-a_i]=\texttt{inf}$，候选值 $\texttt{inf}+1>\texttt{inf}\ge\texttt{dp}[j]$，$\min$ 不改变 $\texttt{dp}[j]$——不可达状态不会传播出 $\texttt{inf}+1$ 这种"脏值"；若 $\texttt{dp}[j-a_i]$ 是真实值，候选值是真实值 $+1$，$\min$ 结果要么保持原值要么变成更小的真实值。结合引理 4（$\texttt{dp}$ 始终等于某个 $f_i$，而 $f_i$ 的值域就是真实值 $\cup\{+\infty\}$），不变量保持。证毕。

**反面警示**：若不 `fill_n` 而依赖全局默认 $0$，则初始 $\texttt{dp}[j]=0$ 会被引理 4 的归纳当成"$f_0(j)=0$"，即"任何金额都能 $0$ 张凑出"，最终输出 $0$。$0$ 在本题是**合法值**，这种错误不会崩溃、只会静默输出错解——必须显式预填充。

### 引理 6（复杂度）

时间 $O(nw)$，空间 $O(n+w)$。

*证明*：外层 $n$ 轮，第 $i$ 轮内层至多 $w-a_i+1\le w$ 次 $O(1)$ 操作，合计 $\le nw=10^7$。读入 $O(n)$。空间：`a` 数组 $O(n)$，`dp` 数组 $O(w)$，无递归栈。$10^7$ 次简单 `min` 运算在 $1$ 秒时限内绰绰有余。证毕。

### 定理

程序输出 $f_n(w)$，即凑出 $w$ 的最少张数；题目保证有解，故输出为有限整数。

*证明*：引理 3 给出分阶段递推的正确性，引理 4 证明代码的循环结构恰好实现它，故终态 $\texttt{dp}[w]=f_n(w)=f(w)$（$f_n$ 即不限种类）。引理 5 保证 INF 语义与算术全程无污染，引理 1 说明为何必须走 DP 而非贪心，引理 6 给出复杂度。题目保证可凑出，$f(w)<+\infty$，输出的就是最少张数。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 张数只取决于各面额用了几张、与顺序无关 ⇒ 剩余金额是唯一状态（无后效性）。
2. **classic problem solution** — 先试贪心（最大面额优先），用 $\{1,3,4\},w=6$ 的反例否定：最大面额未必出现在最优解里。
3. **consider easier version** — $40\%$ 小数据可 DFS；搜索树中"剩余金额相同则历史无关"催生记忆化，状态压到 $w+1$ 个。
4. **reduce to easier problem** — 按"最后一张纸币"分解：$f(j)=\min_i f(j-a_i)+1$，即完全背包的最值形式。
5. **classic problem solution** — 完全背包滚动数组：外层面额、内层金额**升序**；升序使 $\texttt{dp}[j-a_i]$ 含本轮更新，正是"无限张"的实现（对照 01 背包降序）。
6. **discuss by category** — 实现坑分类：`dp` 必须 `fill_n` 成 INF（全局默认 $0$ 是合法值）；$\texttt{inf}+1$ 不溢出且不污染 $\min$；$a_i>w$ 循环自然为空。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|---|---|---|---|
| `n` | 纸币种数，$\le10^3$ | `int` | 读入 |
| `w` | 目标金额，$\le10^4$ | `int` | 读入 |
| `mxn` | $1000+5$ | `constexpr int` | 面额数组尺寸 |
| `mxw` | $10000+5$ | `constexpr int` | DP 数组尺寸 |
| `inf` | 不可达哨兵 $1145141919$ | `constexpr int` | $+1$ 后仍不溢出 `int` |
| `a[i]` | 第 $i$ 种面额（0-based） | `int[mxn]` | 读入；可重复、可 $>w$ |
| `dp[j]` | 凑出金额 $j$ 的最少张数；不可达为 `inf` | `int[mxw]` | **先 `fill_n(dp,w+1,inf)` 再 `dp[0]=0`**；第 $i$ 轮后 $=f_i(j)$ |

### 算法步骤

1. I/O 加速三行；读入 `n,w` 与 `a[0..n-1]`。
2. `fill_n(dp,w+1,inf)`，`dp[0]=0`（全局默认 $0$ 不是 INF，必须显式填）。
3. 对每种面额 `i=0..n-1`：对金额 `j=a[i]..w` 升序执行 `dp[j]=min(dp[j],dp[j-a[i]]+1)`。
4. 输出 `dp[w]`。

### 复杂度

- 时间 $O(nw)\le10^7$；空间 $O(n+w)$（约 $44$ KB）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；四组手造数据（贪心反例 $\{1,3,4\}/6\to2$、$\{2,5\}/10\to2$、$\{3,5,7\}/11\to3$、$\{1\}/10000\to10000$）全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2842 纸币问题 1
// 完全背包最值形式：dp[j]=凑出 j 的最少张数
// 外层面额、内层金额升序 ⇒ dp[j-a[i]] 已含本轮更新 ⇒ 同种纸币可无限用
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},mxw{10005};
constexpr int inf{1145141919};

int n,w,a[mxn],dp[mxw];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>w;
	for(int i=0;i<n;++i)
		cin>>a[i];
	fill_n(dp,w+1,inf);	// 全局默认 0 是合法张数！必须显式填 INF
	dp[0]=0;
	for(int i=0;i<n;++i)
		for(int j=a[i];j<=w;++j)	// 升序=完全背包；a[i]>w 时循环为空
			dp[j]=min(dp[j],dp[j-a[i]]+1);	// inf+1 不溢出，min 不会选中它
	cout<<dp[w]<<'\n';
	return 0;
}
```

### 代码说明

- 核心只有四行递推，全部思想在引理 3、4：升序让 `dp[j-a[i]]` 带上本轮已用的第 `i` 种纸币，实现"无限张"；若误写成降序就变成 01 背包（每种至多一张），答案偏大甚至无解。
- `fill_n(dp,w+1,inf)` 只填到 `w`，不填整个 `mxw`——`w` 之后的格子永远不会被读到，省一点初始化时间；`dp[0]=0` 必须在填充之后。
- `inf+1=1145141920` 仍在 `int` 内，且恒大于 `inf`，所以不可达状态既不会溢出也不会被 `min` 误选（引理 5），无需额外 `if(dp[j-a[i]]!=inf)` 判断。
- 面额重复、$a_i>w$ 都无需特判：前者只是多跑一轮等价转移，后者内层循环为空。
