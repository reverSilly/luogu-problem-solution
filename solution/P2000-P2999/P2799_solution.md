# P2799 国王的魔镜 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有一条珍珠项链，用大写字母串表示。魔镜操作：把项链的一端接触镜面，串变成"原串 + 原串的镜像"。题目举例：`AB` 用 B 端接触 → `ABBA`；再用一端接触 → `ABBAABBA`（并假定国王始终只用某一端接触）。给定最终串 $T$（长度 $\le 10^5$），问**最初的项链可能的最小长度**。题面没有样例输入输出，下面的例子全部是我手算并用程序核对的。

**第一步：把操作写成数学式子，盯住小例子。** 设原串为 $X$，$\mathrm{rev}(X)$ 表示反转。B 端接触镜面时，镜里看到的是从 B 端往回读的像，接在原串后面：

$$M(X)=X\cdot\mathrm{rev}(X).$$

验证题目的例子：$M(\texttt{AB})=\texttt{AB}\cdot\texttt{BA}=\texttt{ABBA}$ ✓；$M(\texttt{ABBA})=\texttt{ABBA}\cdot\texttt{ABBA}=\texttt{ABBAABBA}$ ✓（`ABBA` 自己是回文，反转不变）。

盯着这两个结果看：`ABBA` 是回文，`ABBAABBA` 也是回文，而且长度都是偶数。再试几个：$M(\texttt{ABC})=\texttt{ABCCBA}$，回文；$M(\texttt{A})=\texttt{AA}$，回文。**猜想：任何镜像结果都是偶数长度的回文串。** 这不是巧合：$\mathrm{rev}(X\cdot\mathrm{rev}(X))=X\cdot\mathrm{rev}(X)$，反转整个串等于把两半交换再各自反转，恰好换回自己。

**第二步：反过来想——给定 $T$，能不能"撤销"一次镜像？** 这是本题的思维转向：正向构造有无穷多种可能（不知道原串、不知道用了几次镜子），但**逆向**呢？

若 $T=M(X)$，则 $|T|=2|X|$，且 $T$ 的**前半段就是 $X$**——原像被 $T$ 完全确定，没有任何选择余地！结合第一步的猜想：

$$T\text{ 有原像}\iff |T|\text{ 为偶数且 }T\text{ 是回文};\qquad\text{有原像时原像唯一，就是前半段}.$$

（$\Leftarrow$：取 $X=$ 前半段，$T$ 回文 ⇒ 后半段 $=\mathrm{rev}(X)$ ⇒ $T=X\cdot\mathrm{rev}(X)=M(X)$。）

于是"搜索所有可能的原串"这个看似要搜索/递归的问题（标签里写着"搜索、递归"），**塌缩成一条确定的折半链**：只要当前串是偶数长回文，就唯一地折半；否则停。没有分支，没有回溯，贪心即唯一。

**第三步：为什么"一直折半"就是最小长度？** 每用一次镜子长度翻倍，所以若原串 $X$ 用了 $j$ 次镜子得到 $T$，则 $|X|=|T|/2^j$。要最小化 $|X|$ 就要最大化 $j$。而第二步说明每一步折半是**强制且唯一**的：能折就折、不能折就停，折半次数 $k$ 是 $T$ 的固有属性，所有可能的原串长度恰好是 $|T|/2^j\ (0\le j\le k)$。最小值 $=|T|/2^k$，就是折到不能折时的长度。"可能的最小"这个措辞也提示我们：题目允许假定国王用了尽可能多次镜子。

**第四步：实现上的漂亮简化——当前串永远是输入的前缀。** 折半取的是前半段，前半段的前半段还是前缀……所以整条折半链上的串都是 $T$ 的前缀！根本不用 `substr` 拷贝新串，只需维护一个长度 $L$，每轮检查 $T[0..L)$ 是否回文（比较 $s[i]$ 与 $s[L-1-i]$，$i<L/2$）。总比较次数

$$\frac n2+\frac n4+\frac n8+\cdots<n,$$

几何级数，**$O(n)$**。若每轮真的拷贝子串，总拷贝量同样是几何级数 $O(n)$，但白白多了内存与代码；维护长度是零成本写法。

**第五步：一个必须想清楚的题意分歧——"只用某一端"到底是哪端？** 如果国王用的是 A 端，操作会是 $M'(X)=\mathrm{rev}(X)\cdot X$（像接在前面）。这时原像变成"前半段的反转"，折半链上的串不再是前缀了！但注意：$M'(X)=M(\mathrm{rev}(X))$，所以 $M'$ 链的原像集合恰好是 $M$ 链原像集合的逐一反转，**长度完全相同**；而"是否偶数长回文"这个折半判据对 $M$ 和 $M'$ 一模一样（$M'$ 的结果也是偶数长回文）。题目只问长度，两种解读答案相同——分歧被输出要求自动消解，不需要猜出题人用的哪端。

**手造数据核对：**

| 输入 | 推理 | 答案 |
|---|---|---|
| `ABBAABBA` | 回文→`ABBA`，回文→`AB`，非回文停（正是题面故事的逆过程） | $2$ |
| `ABBA` | 回文→`AB`，非回文停 | $2$ |
| `AAAA` | →`AA`→`A`，奇数停（`A`→`AA`→`AAAA`） | $1$ |
| `ABCCBAABCCBA` | →`ABCCBA`→`ABC`，奇数停 | $3$ |
| `ABC` | 奇数长，根本不是镜像结果 | $3$ |
| `AABB` | 偶数长但非回文 | $4$ |
| `ABCBA` | **奇数长回文**：回文也没用，镜像必偶数长 | $5$ |
| `A` | 长度 $1$ | $1$ |

`ABCBA` 这组专门打"只判回文不判奇偶"的错误写法；`AABB` 打"只判奇偶不判回文"的错误写法。

## 二、思维链：完整证明

**记号。** 串 $X$ 的长度 $|X|$，反转 $\mathrm{rev}(X)$，拼接 $X\cdot Y$。镜像操作 $M(X)=X\cdot\mathrm{rev}(X)$。回文指 $\mathrm{rev}(T)=T$。$T$ 为输入串，$n=|T|\ge1$（题面：一个大写字母串）。定义折半链：$T_0=T$；若 $T_j$ 偶数长且回文，则 $T_{j+1}=T_j$ 的前半段，否则链终止。$k$ 为链上最后一个有定义的下标（$T_0$ 总有定义，故 $k\ge0$）。

---

### 引理 1（反转的两条运算律）

对任意串 $A,B$：(a) $\mathrm{rev}(\mathrm{rev}(A))=A$；(b) $\mathrm{rev}(A\cdot B)=\mathrm{rev}(B)\cdot\mathrm{rev}(A)$。

*证明*：设 $A=a_1\dots a_p$，$B=b_1\dots b_q$。(a) $\mathrm{rev}(A)=a_p\dots a_1$，再反转回 $a_1\dots a_p=A$。(b) $A\cdot B=a_1\dots a_pb_1\dots b_q$，逐位倒序读出为 $b_q\dots b_1a_p\dots a_1=\mathrm{rev}(B)\cdot\mathrm{rev}(A)$。证毕。

---

### 引理 2（镜像结果的刻画）

对任意 $X$，$M(X)$ 是偶数长度回文，且其前半段恰为 $X$。

*证明*：$|M(X)|=|X|+|\mathrm{rev}(X)|=2|X|$，偶数。由引理 1：

$$\mathrm{rev}(M(X))=\mathrm{rev}(X\cdot\mathrm{rev}(X))=\mathrm{rev}(\mathrm{rev}(X))\cdot\mathrm{rev}(X)=X\cdot\mathrm{rev}(X)=M(X),$$

故回文。前半段：$M(X)$ 的前 $|X|$ 个字符就是拼接的第一因子 $X$。证毕。

---

### 引理 3（原像存在性与唯一性——本题的支点）

串 $T$ 在 $M$ 下有原像（$\exists X,M(X)=T$），当且仅当 $|T|$ 为偶数且 $T$ 回文；此时原像**唯一**，等于 $T$ 的前半段。

*证明*：

**（$\Rightarrow$）** 若 $T=M(X)$，由引理 2，$|T|=2|X|$ 偶数、$T$ 回文，且 $X$ 是 $T$ 的前半段——这同时证明了唯一性：任何原像都必须等于前半段，至多一个。

**（$\Leftarrow$）** 设 $|T|=2m$ 且 $T$ 回文。令 $X=T[0..m)$（前半段），$Y=T[m..2m)$（后半段）。回文条件 $T[i]=T[2m-1-i]$ 对 $i<m$ 逐位给出 $Y=\mathrm{rev}(X)$：$Y[j]=T[m+j]=T[2m-1-m-j]=T[m-1-j]=X[m-1-j]=\mathrm{rev}(X)[j]$。故 $T=X\cdot Y=X\cdot\mathrm{rev}(X)=M(X)$，原像存在。证毕。

**推论（逆向无分支）**：撤销镜像不是一个"搜索"问题：判据（偶数 + 回文）与原像（前半段）都由当前串唯一决定。

---

### 引理 4（折半链刻画全部可能的原串）

对任意 $j\ge0$ 与串 $X$：

$$X\text{ 经恰好 }j\text{ 次 }M\text{ 得到 }T\iff j\le k\ \text{且}\ X=T_j.$$

从而可能的原串长度集合为 $\{n/2^j:0\le j\le k\}$，最小可能长度 $=n/2^k=|T_k|$。

*证明*：对 $j$ 归纳。

$j=0$：$X$ 经 $0$ 次得到 $T\iff X=T=T_0$，且 $0\le k$ 恒成立 ✓。

设对 $j$ 成立。$X$ 经 $j+1$ 次得到 $T$ $\iff$ $M(X)$ 经 $j$ 次得到 $T$ $\iff$（归纳假设）$j\le k$ 且 $M(X)=T_j$。而由引理 3，$M(X)=T_j$ 有解 $\iff$ $T_j$ 偶数长且回文 $\iff$ 折半链在 $T_j$ 之后还能延伸一步 $\iff$ $j+1\le k$；有解时唯一解 $X=T_j$ 的前半段 $=T_{j+1}$。合起来：$X$ 经 $j+1$ 次得到 $T\iff j+1\le k$ 且 $X=T_{j+1}$ ✓。

长度：$|T_j|=n/2^j$（每步折半），$j$ 取遍 $0..k$，最小在 $j=k$ 取到。证毕。

**注（为什么贪心没有风险）**：一般"能操作就操作"的贪心要担心"现在操作会不会堵死后面更优的选择"。这里每步的原像**唯一**（引理 3），不存在选择，折半链是 $T$ 的固有结构；"最小长度"对应的 $j=k$ 自动可达。贪心正确性不依赖交换论证，而依赖**逆向确定性**——这是比交换论证更强的一种结构。

---

### 引理 5（前缀性质）

对一切 $0\le j\le k$，$T_j=T[0..n/2^j)$，即折半链上每个串都是输入 $T$ 的前缀。

*证明*：对 $j$ 归纳。$j=0$：$T_0=T$ ✓。设 $T_j=T[0..m)$，$m=n/2^j$。$T_{j+1}$ 是 $T_j$ 的前半段 $=T_j[0..m/2)=T[0..m/2)$，仍是 $T$ 的前缀 ✓。证毕。

**推论（实现）**：只需维护长度 $L$（初值 $n$），第 $j$ 轮的回文检查是"$s[i]=s[L-1-i]$ 对 $i<L/2$"，全部落在原输入串上，无需任何子串拷贝。

---

### 引理 6（另一端约定不改变答案）

设另一端约定的操作为 $M'(X)=\mathrm{rev}(X)\cdot X$。则 $T$ 在 $M'$ 下的可能原串长度集合与 $M$ 下完全相同，最小长度不变。

*证明*：由引理 1，$M(\mathrm{rev}(X))=\mathrm{rev}(X)\cdot\mathrm{rev}(\mathrm{rev}(X))=\mathrm{rev}(X)\cdot X=M'(X)$，即 $M'=M\circ\mathrm{rev}$。于是

$$X\text{ 经 }j\text{ 次 }M'\text{ 得到 }T\iff \mathrm{rev}(X)\text{ 经 }j\text{ 次 }M\text{ 得到 }T\iff j\le k\ \text{且}\ \mathrm{rev}(X)=T_j\iff j\le k\ \text{且}\ X=\mathrm{rev}(T_j),$$

（第二步用引理 4，注意 $M$ 的迭代与 $\mathrm{rev}$ 可交换：$M^j(\mathrm{rev}(X))=\mathrm{rev}(M'^j(X))$ 逐步成立。）长度 $|\mathrm{rev}(T_j)|=|T_j|=n/2^j$，集合与最小值完全一致。证毕。

**另证（判据层面）**：$M'(X)$ 也是偶数长回文（$\mathrm{rev}(M'(X))=\mathrm{rev}(X)\cdot X=M'(X)$），且 $T$ 有 $M'$-原像 $\iff$ $T$ 偶数长回文（原像为后半段 $=\mathrm{rev}($前半段$)$）。折半判据与次数逐轮相同，故 $k$ 相同。两种解读下答案一致，题面"只用某一端"的歧义对输出无影响。

---

### 引理 7（终止性与复杂度）

算法至多进行 $\lfloor\log_2 n\rfloor+1$ 轮检查，总字符比较次数 $<n$，时间 $O(n)$；额外空间 $O(1)$。

*证明*：每轮成功折半使 $L$ 严格减半，$L\ge1$ 恒成立（偶数 $L\ge2$ 折半后 $\ge1$），故成功轮数 $\le\lfloor\log_2 n\rfloor$；失败或奇数立即终止，总轮数 $\le\lfloor\log_2 n\rfloor+1$。第 $j$ 轮（从 $0$ 计）检查的 $L=n/2^j$，比较 $\lfloor L/2\rfloor$ 对字符，总比较次数

$$\sum_{j\ge0}\frac{n}{2^{j+1}}<n\sum_{j\ge0}2^{-(j+1)}=n.$$

（失败那轮最多再贡献 $n/2^{j+1}$ 次，仍被几何级数控制。）每轮只读原串、只改一个 `int`，额外空间 $O(1)$；存输入本身 $O(n)$。证毕。

**边界核对**：$n$ 奇数 ⇒ 第一轮都不进（$L\%2\ne0$），输出 $n$（引理 2：镜像必偶数长，奇数串不可能是镜像结果，$k=0$）✓。$n=1$ ⇒ 输出 $1$ ✓。偶数长非回文 ⇒ 第一轮检查失败退出，输出 $n$ ✓。输入非空（题面保证是一个字母串），不存在 $L=0$ 的死循环风险。

---

### 定理

程序输出的 $L$ 等于最终串 $T$ 在魔镜操作下所有可能原串的最小长度，时间 $O(n)$。

*证明*：引理 2、3 确立"偶数长回文 ⇔ 可撤销，且原像唯一 = 前半段"；引理 4 把可能的原串完全刻画为折半链 $\{T_j\}_{j\le k}$，最小长度 $=|T_k|$；引理 5 保证只需在原串上维护长度 $L$ 即可模拟整条链；引理 6 保证另一端约定不改变答案；引理 7 保证终止与 $O(n)$ 复杂度。程序正是"while $L$ 偶数：检查 $T[0..L)$ 回文，是则 $L\gets L/2$，否则停"，输出 $L=|T_k|$。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 手算 `AB→ABBA→ABBAABBA`，发现镜像结果恒为**偶数长回文**（$\mathrm{rev}(X\cdot\mathrm{rev}(X))$ 换回自己）。
- **reduce to easier problem** — 逆向思考：原像存在 $\iff$ 偶数长回文，且原像**唯一** = 前半段；"搜索所有原串"塌缩成一条确定的折半链。
- **consider easier version** — 每次镜像长度翻倍 ⇒ 最小原长 = 折半到不能折为止；逆向唯一性使贪心零风险（比交换论证更强的结构）。
- **explore its property** — 折半永远取前缀 ⇒ 当前串始终是输入的前缀，只维护长度 $L$，检查总代价几何级数 $O(n)$。
- **discuss by category** — 另一端约定 $M'=M\circ\mathrm{rev}$ 只把原串反转、不改长度，答案对题意歧义免疫；奇数长 / 非回文 / 奇数长回文三类停止边界逐一核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `s` | 最终项链 $T$，大写字母串 | `string`，读入 | 折半链上所有串都是它的前缀 |
| `L` | 当前候选原串长度，对应前缀 `s[0..L)` | `int`，初值 `s.size()` | 只缩不涨；偶数且回文才折半 |
| $k$ | 折半次数（代码中不显式出现） | — | 答案 $=n/2^k$，即最终的 `L` |
| $M(X)$ | $X\cdot\mathrm{rev}(X)$ | — | 镜像 = 原串 + 反转；结果必偶数长回文 |

### 算法步骤

1. I/O 加速三行；读入 `s`，`L=s.size()`。
2. 当 `L` 为偶数时循环：
   1. 对 `i=0..L/2-1` 检查 `s[i]==s[L-1-i]`；发现不等立即跳出整个循环（`goto done`，当前前缀非回文，不可再拆）。
   2. 全部相等 ⇒ 前缀是回文 ⇒ `L/=2`（唯一原像 = 前半段，引理 3）。
3. `L` 为奇数时循环条件不满足，自然终止。
4. 输出 `L` 与 `'\n'`。

### 复杂度

- 时间：$O(n)$，比较总次数 $<n$（几何级数，引理 7）；$n=10^5$ 全 `A` 实测 $0.03$ s 量级。
- 空间：$O(n)$ 存输入串，额外 $O(1)$（只有一个 `L`）。
- 验证状态：`g++ -std=c++20 -O2 -Wall` 编译通过；题面无样例，手造 $8$ 组（题面故事逆过程 `ABBAABBA→2`、全同字符 `AAAA→1`、奇数长回文 `ABCBA→5`、偶数非回文 `AABB→4`、两次镜像 `ABCCBAABCCBA→3` 等）全部与手算一致；$10^5$ 个 `A` 输出 $3125=10^5/2^5$，与"折半 $5$ 次到奇数"的手推一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2799 国王的魔镜
// 镜像 M(X)=X+rev(X) 必为偶数长回文，且原像唯一 = 前半段
// ⇒ 逆向折半链：偶数长且回文就折半，否则停；答案 = 最终长度
// 折半永远取前缀 ⇒ 只需在原串上维护长度 L，总比较次数几何级数 O(n)
#include<bits/stdc++.h>
using namespace std;

string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	int L=s.size();
	while(L%2==0)
	{
		for(int i=0;i<L/2;++i)
			if(s[i]!=s[L-1-i])
				goto done;	// 不是回文：不可能再拆
		L/=2;
	}
done:;
	cout<<L<<'\n';
	return 0;
}
```

### 代码说明

- **判据必须"偶数 + 回文"两条都查**：`while(L%2==0)` 管奇偶（奇数长回文如 `ABCBA` 不是镜像结果），内层逐位比较管回文（偶数非回文如 `AABB` 也不是）。漏任何一条都会在对应反例上出错。
- **`goto done` 跳出双重循环**：内层 `for` 发现失配时要同时终止外层 `while`，风格规范允许的 `goto` 正好用最干净的方式做到；标号后是空语句 `done:;`。
- **不拷贝子串**：由引理 5，当前串永远是 `s` 的前缀 `[0,L)`，回文检查直接用原串下标，省掉 `substr` 的拷贝与内存。
- **终止性**：`L` 每轮严格减半且恒 $\ge1$（输入非空），奇数立即停，无死循环；`L=1` 时 `while` 条件为假，输出 $1$。
- **另一端约定无需处理**：$M'(X)=M(\mathrm{rev}(X))$ 只改变原串的内容不改变长度（引理 6），题目只问长度，这份代码对两种解读都正确。
