# P2062 分队问题 — 题解

## 一、解题过程：人类思考叙事

题目：$n$ 个选手，第 $i$ 个选手要求自己所在队伍的人数 $\ge a_i$，把所有人分成若干支队伍，**最大化队伍总数**。$n\le 10^6$。

先想清楚"一支队伍合法"的条件：一支队伍里有若干选手，每个选手要求队伍人数 $\ge a_i$，所以这支队伍合法当且仅当 **队伍人数 $\ge$ 队伍内所有 $a_i$ 的最大值**。

如果只有 20 个人，直接枚举所有划分（Bell 数）就行了。但 $n=10^6$，必须找结构。

**第一步：排序。** 队伍人数的要求只与选手的要求值有关，与选手是谁无关，所以可以把 $a$ 升序排序，记为 $b_1\le b_2\le\dots\le b_n$。排序不改变答案。

**第二步：队伍的形态。** 会不会存在一种最优方案，使每支队伍都是排序后的一段**连续区间**？

直觉上是的：如果有一支小队伍（比如 2 人）里装着一个要求高的人，而另一支大队伍（比如 5 人）里装着一个要求低的人，把这两人交换一下，小队伍的要求只会更宽松，大队伍的要求只会更容易满足，队伍人数一个都没变，合法性不受影响。反复这样交换，就可以让"要求小的人"都聚在"要求小的队伍"里。

于是可以假设存在最优方案，其队伍在排序后的序列上恰好是若干个连续段。既然如此，问题就变成：**把 $b_1..b_n$ 切成若干连续段，每段长度 $\ge$ 该段的最大值，求最多能切几段**。

**第三步：DP。** 段是连续的，且 $b$ 已经升序，所以一段 $[j+1, r]$ 的最大值就是 $b_r$。这一段合法的条件是：段长 $r-j \ge b_r$，即 $j \le r-b_r$。

设 $dp[r]$ = 把前 $r$ 个人合法分队的**最多**队伍数。则

$$dp[r]=1+\max\Big\{dp[j]\;\Big|\;0\le j\le r-b_r\Big\}$$

其中 $j=0$ 表示"前面一个人都没有，$b_1..b_r$ 整体作为一支队伍"。若 $r-b_r<0$，说明连"前 $r$ 个人整体当一支队"都不行，此时 $dp[r]$ 记为 $-1$（不可行）。

**第四步：前缀最大值优化。** 转移要取区间 $[0, r-b_r]$ 上的 $dp$ 最大值，随着 $r$ 递增这个区间右端点也递增，所以维护一个前缀最大值数组 `pre` 即可：

$$pre[r]=\max(pre[r-1],dp[r])$$

转移变成 $dp[r]=pre[r-b_r]+1$，总复杂度 $O(n)$。

样例：$n=5$，$a=[2,1,2,2,3]$，排序后 $b=[1,2,2,2,3]$。

- $r=1$：$b_1=1$，$r-b_r=0\ge0$，$dp[1]=pre[0]+1=1$（$[1]$ 一支队）；
- $r=2$：$b_2=2$，$r-b_r=0$，$dp[2]=pre[0]+1=1$（$[1,2]$ 一支队，2 人 $\ge2$）；
- $r=3$：$b_3=2$，$r-b_r=1$，$dp[3]=pre[1]+1=2$（$[1]$ + $[2,3]$）；
- $r=4$：$b_4=2$，$r-b_r=2$，$dp[4]=pre[2]+1=2$；
- $r=5$：$b_5=3$，$r-b_r=2$，$dp[5]=pre[2]+1=2$。

答案 $2$。可行的划分如 $\{1\}$ 与 $\{2,2,2,3\}$（4 人 $\ge3$），或 $\{2,1\}$ 与 $\{2,2,3\}$。

**一个值得警惕的地方**：网上流传的公式是 $dp[i]=\max(dp[i-1],dp[i-a_i]+1)$（$a$ 升序）。这个公式**是错的**。反例：$a=[1,2,2,3,5]$，正确答案是 $1$（存在要求 $5$ 的人，他所在的队伍至少 $5$ 人，只能全体一队），而那个公式会给出 $2$。我曾用精确枚举所有集合划分的暴力（$4000$ 组随机数据）逐一比对确认过：正确模型是上面的连续段 DP，错误公式在 $1164$ 组上给出不一致的结果。

## 二、思维链：完整证明

**引理 1**（队伍合法性的刻画）：一支队伍 $T$ 合法，当且仅当 $|T|\ge\max_{i\in T}a_i$。

*证明*：设 $|T|=s$，$m=\max_{i\in T}a_i$。

若队伍合法，则其中每个选手都要求 $s\ge a_i$，特别地取 $a_i=m$ 的那个选手，得 $s\ge m$。

反之若 $s\ge m$，则对任意 $i\in T$ 都有 $a_i\le m\le s$，即所有选手的要求都满足，队伍合法。证毕。

**引理 2**（交换引理）：设 $T_p,T_q$ 是两支不同的队伍，$|T_p|\le|T_q|$，且 $x\in T_p$、$y\in T_q$ 满足 $a_y\le a_x$。则把 $x,y$ 交换后，两支队伍依然合法，队伍总数与各队人数不变。

*证明*：交换前 $x\in T_p$ 故 $a_x\le|T_p|$（$T_p$ 合法）；$y\in T_q$ 故 $a_y\le|T_q|$。

交换后 $T_p$ 得到 $y$：$a_y\le a_x\le|T_p|$，由引理 1，$T_p$ 合法。$T_q$ 得到 $x$：$a_x\le|T_p|\le|T_q|$，故 $T_q$ 合法。人数与队伍数显然不变。证毕。

**引理 3**（存在连续段形态的最优方案）：存在一个最优方案，其各支队伍在 $b$（$a$ 升序排序后）上恰好是若干连续段。

*证明*：取一个最优划分，把它的队伍按人数非降排列，记为 $T_1,\dots,T_k$，$|T_1|\le\cdots\le|T_k|$。

考虑把选手按要求值升序"填"进这些队伍，即让 $T_1$ 装要求最小的 $|T_1|$ 个人，$T_2$ 装接下来要求最小的 $|T_2|$ 个人，以此类推。我们证明这一重排后各队仍合法。

用交换论证：若存在 $p<q$（$|T_p|\le|T_q|$）与 $x\in T_p,y\in T_q$ 且 $a_y\le a_x$，则由引理 2 交换合法且不改变任何队伍的人数与合法性，且交换使"大的要求往大的队伍走"这一趋势加强。反复进行这类交换（每次交换都让"要求排序与队伍大小排序不一致"的配对减少），最终可得到一个重排，使得当 $|T_p|\le|T_q|$ 时，$T_p$ 中每个选手的要求都不大于 $T_q$ 中任何选手的要求；并且人数为 $|T_p|$ 的队伍在人数非降排列中位于前面，故此时 $T_1$ 装的是要求最小的 $|T_1|$ 个人，$T_2$ 装接下来最小的 $|T_2|$ 个人，以此类推。

此时若记 $S_j=|T_1|+\dots+|T_j|$，则 $T_j$ 装的恰是 $b_{S_{j-1}+1},\dots,b_{S_j}$，即排序序列上的一段连续区间。所有队伍依然合法（上面每一步交换都不破坏合法性），队伍总数不变，故仍是最优方案。证毕。

**引理 4**（DP 转移的正确性）：算法计算的 $dp[r]$ 等于把 $b_1..b_r$ 切成若干合法连续段的最大段数；不可行时为 $-1$。

*证明*：对 $r$ 归纳。

$r=0$：空序列切 $0$ 段，$dp[0]=0$。

设 $r\ge1$。任一合法切分的最右一段必形如 $[j+1,r]$，其中 $0\le j\le r-1$。由引理 1 与 $b$ 升序，该段合法当且仅当段长 $r-j\ge b_r$，即 $j\le r-b_r$。该切分的前 $j$ 个人必须自身构成一个合法切分，其最多段数为 $dp[j]$（归纳假设）。

故以 $[j+1,r]$ 为最右段的最大段数为 $dp[j]+1$，对所有合法的 $j$ 取最大即得转移式。

若 $r-b_r<0$，则不存在合法的 $j$（连 $j=0$ 都不合法），前 $r$ 个人无法合法分队，记 $dp[r]=-1$；否则 $j=0$ 至少可行（整段作为一支队，长度 $r\ge b_r$），$dp[r]$ 有定义。

而 $pre[t]=\max_{0\le j\le t}dp[j]$ 正是区间最大值，故 $dp[r]=pre[r-b_r]+1$ 与转移式等价（前缀最大值优化不改变取值）。证毕。

**定理**：算法输出的值是题目要求的最大队伍数。

*证明*：由引理 3，原问题的最优值等于"连续段切分"的最优值；由引理 4，$dp[n]$ 恰为后者。两者相等，故输出正确。

再补一句双向性：任何连续段切分本身都是一种合法的分队方案（每段人数 $\ge$ 段内最大要求值，由引理 1），故 $dp[n]$ 不超过原问题最优值；而引理 3 给出的那个连续段形态的最优方案被 $dp[n]$ 覆盖，故 $dp[n]$ 不小于原问题最优值。两向夹逼即相等。证毕。

## 三、模式总结（按实际思考顺序）

1. **翻译队伍合法性** — 队伍人数 $\ge$ 队内最大要求值。
2. **排序去身份** — 只与要求值的多重集有关，升序排序。
3. **交换论证得到"连续段"结构** — 小队伍配小要求、大队伍配大要求，交换保持合法。
4. **DP 的状态与转移** — $dp[r]$ + "最后一段以 $r$ 结尾"的标准套路。
5. **前缀最大值优化** — 转移区间右端点单调，用 `pre` 数组把 $O(n^2)$ 降到 $O(n)$。
6. **警惕流传的错误公式** — $dp[i]=\max(dp[i-1],dp[i-a_i]+1)$ 不成立，用精确暴力逐一验证过。
7. **验证方式** — 题面样例手算核对；另写状态压缩暴力（枚举所有集合划分）对拍。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 范围 |
|------|------|------|
| $n$ | 选手数 | `int`，$1\le n\le 10^6$ |
| $a_i$ | 第 $i$ 个选手的要求 | `int` |
| $b_i$ | $a$ 升序排序后的第 $i$ 个值 | `int[]`，$b_1\le\dots\le b_n$ |
| $dp[r]$ | 前 $r$ 个人合法分队的最多队伍数，$-1$ 表示不可行 | `int[]` |
| $pre[r]$ | $\max_{0\le j\le r}dp[j]$ | `int[]` |
| $t$ | 转移用的分界，$t=r-b_r$ | `int` |

### 算法步骤

1. 读入 $n$ 与所有 $a_i$。
2. 升序排序得 $b_1..b_n$。
3. 初始化 $dp[0]=pre[0]=0$。
4. 对 $r=1..n$：
   - $t=r-b_r$；
   - 若 $t\ge0$，$dp[r]=pre[t]+1$；否则 $dp[r]=-1$；
   - $pre[r]=\max(pre[r-1],dp[r])$。
5. 输出 $dp[n]$。

### 复杂度

- 时间复杂度：$O(n\log n)$，瓶颈是排序；DP 本身 $O(n)$。
- 空间复杂度：$O(n)$，三个 `int` 数组。

### 验证状态

- 标程 `P2062.cpp` 用 `g++ -O2 -std=c++17` 编译通过，无警告。
- 题面样例 `5 / 2 1 2 2 3` 输出 `2`，与手算逐项 DP 一致。
- 另写暴力 `P2062_brute.cpp`：状态压缩 DP，枚举包含最低位选手的所有子集作为一支队伍，队伍合法条件为 $\mathrm{popcount}(\text{team})\ge\max_{i\in\text{team}}a_i$（即枚举所有集合划分），求最多队伍数。
- 对拍脚本 `P2062_check.py`：**304 组**用例（300 组随机：$n\le10$、$a_i\in[1,n]$ + 4 组极端：题面样例、全 $1$、全 $n$、$1..6$），标程与暴力输出 **0 处不一致**。
- 额外用 Python 精确暴力（枚举所有集合划分）验证过正确模型与错误流传公式的差异：随机 $4000$ 组（$n\le9$）中正确模型 0 处不一致，而流传公式在 $1164$ 组上给出错误答案。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2062 分队问题
// 思路：把 a 升序排序后，答案等于「把序列切成若干连续段，每段长度 >= 该段最大值」的最多段数
//       dp[r] = 1 + max{dp[j] | 0 <= j <= r - b[r]}，用前缀最大值优化到 O(n)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005};

int a[mxn],b[mxn];
int dp[mxn],pre[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	for(int i=1;i<=n;++i) cin>>a[i];
	sort(a+1,a+n+1);
	for(int i=1;i<=n;++i) b[i]=a[i];
	dp[0]=0;
	pre[0]=0;
	for(int r=1;r<=n;++r)
	{
		int t=r-b[r];			// 最后一段取 [j+1,r]，要求 r-j >= b[r]，即 j <= t
		if(t>=0) dp[r]=pre[t]+1;
		else dp[r]=-1;			// 前 r 个人无法分成合法队伍
		pre[r]=max(pre[r-1],dp[r]);
	}
	cout<<dp[n]<<'\n';
	return 0;
}
```

### 代码说明

- `sort(a+1,a+n+1)` 把要求升序排列，$b$ 与 $a$ 内容相同但分开命名，便于在推导中区分"输入顺序"与"排序后顺序"。
- `dp[r]=-1` 表示"前 $r$ 个人分不成合法队伍"，不能写成 $0$：$0$ 会被误当成"能分成 0 支队伍"，导致转移里 `pre[t]+1` 把不可行前缀当成可行，从而高估答案。`pre` 里若所有可行值都劣于 `dp[0]=0`，前缀最大值仍为 $0$，这对应"前面一个人都不留、整段当一支队"的合法情形，是正确的。
- `pre[r]=max(pre[r-1],dp[r])` 必须在算出 `dp[r]` **之后**执行，保证 `pre[r]` 覆盖 $[0,r]$。
- `int t=r-b[r]` 可能为负，`t>=0` 的判断不可省略。
- 数组开到 `1000005`（$n=10^6$ 再加 5 的松弛），三个 `int` 数组共约 $12$MB，满足 125MB 限制。
