# P2412 查单词 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 个单词（$N\le 5\times 10^4$，每个长度 $\le 15$，含大小写字母），$M$ 个询问（$M\le 3\times 10^5$）。每个询问给出 $x,y$，要在第 $x$ 到第 $y$ 个单词里找出**忽略大小写后字典序最大**的那个；如果忽略大小写后字典序相同，**输出靠后的那个**（下标大的）。输出 $M$ 行，每行一个单词。

数据范围一眼就否掉了暴力：$N\cdot M=5\times10^4\times3\times10^5=1.5\times10^{10}$，每次比较还要扫最多 $15$ 个字符，妥妥超时。标签里写着"线段树、ST 表"，方向很明确：**区间最值查询（RMQ）**。但这题的"最值"不是数字，麻烦全在"怎么定义大小"上。

**第一步：先把"忽略大小写"落地。** 比较时把每个字母都当成小写即可：`AbC` 与 `aBc` 视为同一个键 `abc`。于是每个单词 $i$ 有一个**比较键** `low[i]`（全小写副本）。注意 `low` 只用来比较，**原串 `s[i]` 要留着输出**。

这里我停下来想了很久：**输出到底要不要保留原来的大小写？** 题面只说"每行为一个字符串"，样例说明里的单词又恰好全是小写，看不出来。破局点是那条平局规则：

> 如果有两个单词忽略大小写情况下字典序相同，输出靠后的那个。

假设输出的是全小写形式，那么"忽略大小写相同"的两个单词，小写形式**一模一样**，选谁输出的字节都相同——这条规则就成了**完全不可观测**的废话。出题人专门写一条规则，通常是因为它会影响输出。所以合理的解读是：**输出保留单词在原表中的大小写**，平局规则用来决定输出 `Abc` 还是 `abc`。我按这个解读实现（这也是"找出那个单词"的字面意思：找到的是书里的那个词，不是它的规范化形式）。

**第二步：把两条规则捏成一个"大小"。** 现在的选择标准是两级的：先比 `low` 的字典序，再比下标。RMQ 数据结构只认**一个**二元运算 `max`，所以我要把两级标准打包成一个**全序**：

$$\text{值}(i)=\bigl(\texttt{low}[i],\;i\bigr),\qquad (u,p)\prec(v,q)\iff u<_{\mathrm{lex}}v\ \text{或}\ (u=v\ \text{且}\ p<q).$$

这就是二元组的字典序。于是"询问答案"= 区间内 $\prec$ 意义下的**最大值的下标**。一次比较函数 `btr(a,b)` 搞定：键不同返回键大的，键相同返回下标大的。

**这一步是本题真正的思维跳跃**：只要把"最大"定义成一个全序上的 max，它就自动满足**结合律、交换律、幂等律**，于是所有 RMQ 工具（线段树、ST 表）原封不动可用。

**第三步：选 ST 表还是线段树？** 两者都对：

- 线段树：建树 $O(N)$，单查 $O(\log N)$，总量 $3\times10^5\times16\approx5\times10^6$ 次合并，能过。
- ST 表：预处理 $O(N\log N)$，单查 $O(1)$，总量 $5\times10^4\times16+3\times10^5\times2\approx1.4\times10^6$ 次合并，更快。

ST 表查询能 $O(1)$ 的**唯一理由**是 max 幂等：允许用两个**重叠**的 $2^k$ 长区间盖住询问区间，重叠部分被重复计入也不影响最大值。要是换成"区间和"，ST 表就不能这么查了。既然我已经有全序 max，那就用 ST 表。

**第四步：存下标而不是存字符串。** `st[k][i]` 存"区间 $[i,i+2^k)$ 里最优单词的下标"，合并时调用 `btr` 现比。这样 ST 表是 `int` 数组：$20\times50005\times4\approx4$ MB；要是存 `string`，光对象开销就翻好几倍，复制也慢。

**第五步：几个必须抠清楚的细节。**

1. **前缀规则。** 字典序里 `ab` < `abc`（短的前缀小）。`std::string` 的 `<`/`>` 已经内置这条规则，不用手写；但自己写比较器时很容易漏，我在暴力里专门显式处理了长度不等的情况来交叉验证。
2. **`lg` 表。** `lg[len]=⌊log2 len⌋`，递推 `lg[i]=lg[i>>1]+1`，`lg[1]=0`（全局数组默认 $0$，恰好正确）。查询取 `k=lg[y-x+1]`，两块是 `[x,x+2^k)` 与 `[y-2^k+1,y+1)`。
3. **半开区间与边界。** 建树循环写 `for(i=0;i+(1<<k)<=n;++i)`，保证 `st[k][i]` 覆盖的区间不越界；`k` 只到 $(1<<k)\le n$，$n\le5\times10^4<2^{16}$，所以 `mxk=20` 绰绰有余。**查询时访问的两个格子一定被建过**（下面引理 6 会证），不会读到全局默认的 $0$——这一点很关键，因为 $0$ 是个合法下标，读到未初始化的格子不会崩，只会静默出错。
4. **0-based。** 读入 `x,y` 后立刻 `--x;--y`，输出时用 `s[idx]`（下标本来就是 0-based，不用加回）。
5. **`x>y` 怎么办？** 题面样例都是 $x\le y$，但加一句 `if(x>y)swap(x,y);` 是零成本的保险。
6. **大小写转换别用 `tolower` 的 locale 版本踩坑。** 直接 `if(c>='A'&&c<='Z')c+=32;` 最稳（题面保证只有字母）。

**手造数据核对**（题面只给了"样例说明"，没有给样例输入输出，我按说明反推出单词表与询问，再另造两组专门打平局与前缀）：

第一组，按样例说明反推（单词 `absi hansbug lzn kkk yyy`，询问 `1 5 / 1 1 / 1 2 / 2 3 / 4 4`）：

```
yyy
absi
hansbug
lzn
kkk
```

与说明里"第一次 yyy、第二次 absi、第三次 hansbug、第四次 lzn、第五次 kkk"逐条吻合。

第二组，专打"只差大小写"的平局（`Abc abc aBc ABd`，询问 `1 3 / 1 4 / 2 2`）：

```
aBc      ← 前三个键都是 abc，取最靠后的第 3 个，原样输出 aBc
ABd      ← abd > abc
abc      ← 只有一个
```

第三组，专打前缀规则（`a ab abc Ab A`，询问 `1 5 / 2 4 / 1 1 / 4 5`）：

```
abc      ← abc 比 ab、a 都大（前缀规则）
abc
a
Ab       ← 键 ab > a，输出原样 Ab
```

这三组把"平局取后""前缀规则""保留原大小写"三个易错点全部覆盖到了。

## 二、思维链：完整证明

**记号。** 单词下标 $0\le i<N$。原串 $s_i$，键 $\ell_i=\mathrm{fold}(s_i)$，其中 $\mathrm{fold}$ 把每个大写字母换成对应小写字母、其余不变。询问区间 $[x,y]$（0-based，闭）。定义二元组值 $v(i)=(\ell_i,i)$，以及关系
$$(u,p)\prec(v,q)\iff \bigl(u<_{\mathrm{lex}}v\bigr)\ \lor\ \bigl(u=v\ \land\ p<q\bigr).$$
`btr(a,b)` 返回 $\{a,b\}$ 中 $v$ 值在 $\prec$ 下较大的那个下标。

---

### 引理 1（fold 把"忽略大小写字典序"变成普通字典序）

设字母表 $\Sigma=\{A..Z,a..z\}$。定义字母上的等价关系 $c\sim d\iff\mathrm{fold}(c)=\mathrm{fold}(d)$，以及"忽略大小写的字母先后" $c\prec_\Sigma d\iff\mathrm{fold}(c)<\mathrm{fold}(d)$（右侧是 ASCII 比较）。则对任意两个单词 $A,B\in\Sigma^*$：

(a) $A$ 与 $B$ 忽略大小写相等 $\iff\mathrm{fold}(A)=\mathrm{fold}(B)$；
(b) $A$ 在忽略大小写的字典序下小于 $B$ $\iff\mathrm{fold}(A)<_{\mathrm{lex}}\mathrm{fold}(B)$。

*证明*：先验证 $\prec_\Sigma$ 是良定义的（与代表元选取无关）：若 $c\sim c'$、$d\sim d'$，则 $\mathrm{fold}(c)=\mathrm{fold}(c')$、$\mathrm{fold}(d)=\mathrm{fold}(d')$，故 $\mathrm{fold}(c)<\mathrm{fold}(d)\iff\mathrm{fold}(c')<\mathrm{fold}(d')$。又 $\mathrm{fold}$ 把 $26$ 个等价类一一映到 $\{a..z\}$，而 ASCII 中 `'a'<'b'<...<'z'`（$97<98<\dots<122$）正是字母表顺序，所以 $\prec_\Sigma$ 就是"按字母表顺序、不分大小写"。

(a) 忽略大小写相等定义为 $|A|=|B|$ 且逐位 $A_j\sim B_j$，即 $\mathrm{fold}(A_j)=\mathrm{fold}(B_j)$ 对所有 $j$，也就是 $\mathrm{fold}(A)=\mathrm{fold}(B)$。

(b) 忽略大小写的字典序定义为：存在 $t<\min(|A|,|B|)$ 使前 $t$ 位满足 $A_j\sim B_j$ 且 $A_t\prec_\Sigma B_t$；或 $A$ 是 $B$ 的真前缀（逐位 $\sim$）。把 $\sim$ 换成"fold 后相等"、$\prec_\Sigma$ 换成"fold 后 ASCII 更小"，这两个分支逐字变成 $\mathrm{fold}(A)<_{\mathrm{lex}}\mathrm{fold}(B)$ 的定义（前缀分支不受 fold 影响，因为 fold 不改变长度）。两个方向都成立。证毕。

**推论**：用 `std::string` 的 `>` 比较 `low[a]` 与 `low[b]`，实现的正是题面的"忽略大小写字典序"，且自带前缀规则（`ab`<`abc`）。

---

### 引理 2（$\prec$ 是严格全序）

关系 $\prec$ 在值集合 $\{(\ell_i,i)\}$ 上满足：非自反、传递、三分性（任意两个不同值恰有一个方向成立）。

*证明*：设 $p=(u,a)$、$q=(v,b)$、$r=(w,c)$。

**非自反**：$p\prec p$ 要求 $u<_{\mathrm{lex}}u$（假，字符串字典序非自反）或 $u=u\land a<a$（假）。故 $p\not\prec p$。

**三分性**：若 $p\ne q$，则 $u\ne v$ 或 $a\ne b$。字符串字典序是全序，故 $u\ne v$ 时 $u<_{\mathrm{lex}}v$ 与 $v<_{\mathrm{lex}}u$ 恰一成立，对应 $p\prec q$ 与 $q\prec p$ 恰一成立；$u=v$ 时 $a\ne b$，整数序给出 $a<b$ 与 $b<a$ 恰一成立，同样恰一方向。故任意两个不同值可比且只在一个方向可比。

**传递**：设 $p\prec q$、$q\prec r$，分四种情形。
1. $u<_{\mathrm{lex}}v$ 且 $v<_{\mathrm{lex}}w$：字符串字典序传递 ⇒ $u<_{\mathrm{lex}}w$ ⇒ $p\prec r$。
2. $u<_{\mathrm{lex}}v$ 且 $v=w,\ b<c$：则 $u<_{\mathrm{lex}}w$ ⇒ $p\prec r$。
3. $u=v,\ a<b$ 且 $v<_{\mathrm{lex}}w$：则 $u<_{\mathrm{lex}}w$ ⇒ $p\prec r$。
4. $u=v,\ a<b$ 且 $v=w,\ b<c$：则 $u=w$ 且 $a<c$（整数传递）⇒ $p\prec r$。
四种情形穷尽（每个 $\prec$ 只有两个分支），故传递。证毕。

**这条引理是全部数据结构合法性的地基**：只有全序才能谈"区间最大值"，也只有全序才能保证最大值唯一（下标互不相同 ⇒ 值互不相同）。

---

### 引理 3（询问答案 = 区间 $\prec$-最大值的下标）

设 $I=[x,y]$，$i^\*=\arg\max_{i\in I}v(i)$（$\prec$ 意义下）。则 $s_{i^\*}$ 就是题目要求输出的单词。

*证明*：题目要求：在 $I$ 中找忽略大小写字典序最大的单词；若有多个，取靠后的。

由引理 1，"忽略大小写字典序最大"等价于 $\ell_i$ 在 $<_{\mathrm{lex}}$ 下最大。设 $L=\max_{i\in I}\ell_i$，$T=\{i\in I:\ell_i=L\}$。$T$ 非空（有限非空集合必有最大值）。题目要的输出是 $s_{j}$，其中 $j=\max T$（"靠后"= 下标大）。

另一方面，按 $\prec$ 的定义：对任意 $i\in I$，若 $\ell_i<L$ 则 $v(i)\prec v(j)$（第一分支）；若 $\ell_i=L$ 则 $i\in T$，$i\le j$，故 $v(i)\prec v(j)$ 或 $i=j$。所以 $j$ 是 $\prec$-最大值。又由引理 2 的三分性，最大值唯一，故 $i^\*=j$。证毕。

---

### 引理 4（max 的三条运算律）

在严格全序集合上定义 $\mathrm{mx}(a,b)$ 为 $\{a,b\}$ 中较大者（相等时任取，值相同）。则对任意 $a,b,c$：

(a) 交换律 $\mathrm{mx}(a,b)=\mathrm{mx}(b,a)$；
(b) 结合律 $\mathrm{mx}(\mathrm{mx}(a,b),c)=\mathrm{mx}(a,\mathrm{mx}(b,c))$；
(c) 幂等律 $\mathrm{mx}(a,a)=a$。

进一步，对任意**有限非空多重集** $S$，反复用 $\mathrm{mx}$ 合并的结果等于 $S$ 中最大元素，**与合并顺序、与元素重复次数无关**。

*证明*：(a) 由定义中 $\{a,b\}$ 是无序对即得。(c) $\{a,a\}$ 的最大元素是 $a$。

(b) 设 $m$ 为 $\{a,b,c\}$ 的最大元素（全序 ⇒ 存在且唯一）。左边：$\mathrm{mx}(a,b)\in\{a,b\}$ 且 $\succeq a,b$；再与 $c$ 取 max，结果 $\succeq\mathrm{mx}(a,b)\succeq a,b$ 且 $\succeq c$，故结果 $\succeq m$；又结果属于 $\{a,b,c\}$，故 $\preceq m$；由反对称（三分性的推论）得结果 $=m$。右边同理 $=m$。故两边相等。

多重集情形：对元素个数归纳。个数 $1$ 平凡。设个数 $t$ 时成立，$t+1$ 个元素的任何合并过程，最后一步必是 $\mathrm{mx}(X,Y)$，其中 $X,Y$ 分别是两个非空子多重集的合并结果；由归纳假设 $X=\max S_1$、$Y=\max S_2$，而 $\mathrm{mx}(\max S_1,\max S_2)=\max(S_1\cup S_2)$（由 (b) 的论证，两个最大值的 max 就是并的最大值）。重复元素不影响：$\max$ 只关心"是否存在更大者"，把某元素多算几次不改变最大值（由 (c)）。证毕。

**推论（ST 表可用的充要条件）**：因为 $\mathrm{mx}$ 幂等，**允许用重叠区间覆盖询问区间**；因为结合 + 交换，允许任意分块预处理。

---

### 引理 5（ST 表预处理不变量）

建树后，对所有 $k\ge0$ 与 $0\le i$ 满足 $i+2^k\le N$，有
$$\texttt{st}[k][i]=\arg\max_{j\in[i,\;i+2^k)}v(j).$$

*证明*：对 $k$ 归纳。

$k=0$：代码 `st[0][i]=i`，区间 $[i,i+1)=\{i\}$，最大值下标就是 $i$ ✓。

设 $k-1$ 成立。区间 $[i,i+2^k)$ 可**不交**地拆成 $[i,i+2^{k-1})$ 与 $[i+2^{k-1},i+2^k)$（两半长度都是 $2^{k-1}$，且首尾相接）。由归纳假设，`st[k-1][i]` 与 `st[k-1][i+(1<<(k-1))]` 分别是两半的最大值下标。由引理 4 的多重集结论，两半最大值的 $\mathrm{mx}$ 就是并的最大值；而 `btr` 正是 $\mathrm{mx}$ 在下标上的实现（引理 2 保证全序、引理 3 保证 `btr` 的判据与 $v$ 一致）。代码 `st[k][i]=btr(st[k-1][i],st[k-1][i+(1<<(k-1))])` 恰好计算它。

边界：循环条件 `i+(1<<k)<=n` 保证两个子区间都在 $[0,N)$ 内，故引用的 `st[k-1][*]` 都已被建过（$i+2^{k-1}+2^{k-1}=i+2^k\le N$）。$k$ 的外层条件 `(1<<k)<=n` 保证至少存在一个合法 $i$。证毕。

### 引理 6（$O(1)$ 查询的两块覆盖）

设询问 $[x,y]\subseteq[0,N)$，$len=y-x+1\ge1$，$k=\lfloor\log_2 len\rfloor$。令 $B_1=[x,x+2^k)$、$B_2=[y-2^k+1,\;y+1)$。则

(a) $B_1,B_2\subseteq[x,y+1)$；
(b) $B_1\cup B_2=[x,y+1)$；
(c) `st[k][x]` 与 `st[k][y-(1<<k)+1]` 都是已建好的合法格子；
(d) `btr(st[k][x],st[k][y-(1<<k)+1])` 就是询问答案的下标。

*证明*：由 $k=\lfloor\log_2 len\rfloor$ 得 $2^k\le len<2^{k+1}$。

(a) $B_1$ 的右端 $x+2^k\le x+len=y+1$ ✓，左端 $x\ge x$ ✓。$B_2$ 的左端 $y-2^k+1\ge y-len+1=x$ ✓，右端 $y+1$ ✓。

(b) 只需证两区间**无空隙**：$B_2$ 的左端 $\le B_1$ 的右端，即 $y-2^k+1\le x+2^k\iff len=y-x+1\le 2^{k+1}$，由 $len<2^{k+1}$ 成立 ✓。于是 $B_1$ 从 $x$ 覆盖到 $x+2^k-1$，$B_2$ 从 $y-2^k+1\le x+2^k$ 覆盖到 $y$，并集恰为 $[x,y]$。（当 $len=2^k$ 时两块完全重合，也成立。）

(c) `st[k][x]` 需要 $x+2^k\le N$：由 (a) $x+2^k\le y+1\le N$ ✓。`st[k][y-2^k+1]` 需要 $(y-2^k+1)+2^k=y+1\le N$ ✓。又 $k=\lfloor\log_2 len\rfloor\le\lfloor\log_2 N\rfloor$，故外层建树循环一定执行到了第 $k$ 层。两者都被引理 5 覆盖，**不会读到未初始化格子**。

(d) 由引理 5，两个格子分别是 $\max B_1$、$\max B_2$ 的下标。由引理 4（幂等 ⇒ 重叠无害），$\mathrm{mx}(\max B_1,\max B_2)=\max(B_1\cup B_2)=\max[x,y+1)$。再由引理 3，这个下标对应的原串就是答案。证毕。

### 引理 7（`lg` 表正确）

代码 `lg[1]=0`（全局默认），`for(i=2..N) lg[i]=lg[i>>1]+1`。则对所有 $1\le i\le N$，$\texttt{lg}[i]=\lfloor\log_2 i\rfloor$。

*证明*：先证数论恒等式：对整数 $i\ge2$，$\lfloor\log_2 i\rfloor=\lfloor\log_2\lfloor i/2\rfloor\rfloor+1$。

设 $k=\lfloor\log_2 i\rfloor$，则 $2^k\le i<2^{k+1}$，且 $k\ge1$。由 $i\ge2^k$ 得 $\lfloor i/2\rfloor\ge\lfloor 2^k/2\rfloor=2^{k-1}$；由 $i\le 2^{k+1}-1$ 得 $\lfloor i/2\rfloor\le\lfloor(2^{k+1}-1)/2\rfloor=2^k-1<2^k$。故 $2^{k-1}\le\lfloor i/2\rfloor<2^k$，即 $\lfloor\log_2\lfloor i/2\rfloor\rfloor=k-1$，恒等式成立。

再对 $i$ 归纳：$i=1$ 时 $\lfloor\log_2 1\rfloor=0=\texttt{lg}[1]$ ✓。$i\ge2$ 时 `i>>1`$=\lfloor i/2\rfloor<i$，由归纳假设 $\texttt{lg}[i>>1]=\lfloor\log_2\lfloor i/2\rfloor\rfloor$，加 $1$ 后由恒等式等于 $\lfloor\log_2 i\rfloor$ ✓。证毕。

### 引理 8（输出保留原大小写，且平局规则可观测）

程序输出 `s[idx]`（原串），不是 `low[idx]`。在"输出原串"的约定下，题面的平局规则是**可观测**的；在"输出小写"的约定下则不可观测。

*证明*：设 $i<j$ 且 $\ell_i=\ell_j$ 但 $s_i\ne s_j$（例如 `Abc` 与 `abc`）。题面要求输出靠后的，即 $s_j$。程序由引理 3 取 $i^\*=j$，输出 $s_j$ ✓。若改为输出 $\ell_{i^\*}$，则 $\ell_i=\ell_j$ 使两种选择输出同一字节串，规则对输出无任何影响。故只有"输出原串"能让该规则产生可区分的行为，这与题面专门给出该规则的事实一致。证毕。

（这是一条**题意解读**层面的论证：题面没有明说输出是否保留大小写，样例说明中的单词又全为小写，无法从样例区分。我们选择让题面每条规则都有效的那个解读。）

---

### 引理 9（复杂度）

设 $L=15$ 为单词长度上限，$K=\lfloor\log_2 N\rfloor+1$。时间 $O(N\log N\cdot L+M\cdot L)$，空间 $O(N\log N+N\cdot L)$。

*证明*：读入与 fold：$O(NL)$。`lg` 表：$O(N)$。建树：层数 $K$，第 $k$ 层有 $N-2^k+1\le N$ 个格子，每格一次 `btr`；`btr` 最坏比较两个长度 $\le L$ 的串，$O(L)$。故建树 $O(NKL)=O(N\log N\cdot L)$。查询：每次一次 `lg` 查表 + 一次 `btr` + 一次输出，$O(L)$，共 $O(ML)$。合计 $O(NL\log N+ML)$。

代入：$N=5\times10^4,K=16,M=3\times10^5,L=15$ ⇒ 约 $(5\times10^4\times16+3\times10^5)\times15\approx1.65\times10^7$ 次字符级操作，实测 $0.2$ s 量级。

空间：`st` 为 $20\times50005$ 个 `int` $\approx4$ MB；`s`、`low` 各 $N$ 个长度 $\le15$ 的串（SSO 内联，无堆分配）$\approx2\times50005\times32$ B $\approx3.2$ MB；`lg` $0.2$ MB。总计 $O(N\log N+NL)$，约 $8$ MB。证毕。

---

### 定理

程序对每个询问输出区间内忽略大小写字典序最大、平局取靠后的那个单词的**原始写法**，总复杂度 $O(NL\log N+ML)$。

*证明*：引理 1 保证比较键正确；引理 2 保证"最大"是良定义的全序运算；引理 3 保证答案就是该全序的区间最大值；引理 4 保证可以分块 + 重叠合并；引理 5、7 保证预处理与 `lg` 正确；引理 6 保证每次查询取到的两块合法且覆盖完整、结果正确；引理 8 保证输出形式与平局规则一致；引理 9 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "忽略大小写"= 先把每个单词 fold 成全小写键；前缀规则（`ab`<`abc`）由字符串比较自带。
2. **explore its property** — 从"平局取靠后"这条规则反推输出必须保留原大小写，否则该规则不可观测。
3. **consider easier version** — 先想暴力：每询问扫一遍区间，$O(NM)=1.5\times10^{10}$ 超时，确认需要 RMQ。
4. **reduce to easier problem** — 把"先比键、再比下标"的两级标准打包成二元组 $(\ell_i,i)$ 的字典序，两级规则塌缩成一个全序 max。
5. **classic problem solution** — 全序 max 满足结合/交换/幂等 ⇒ ST 表（$O(N\log N)$ 预处理、$O(1)$ 查询）；幂等正是允许两块重叠覆盖的理由。
6. **classic problem solution** — `lg[i]=lg[i>>1]+1` 递推 $\lfloor\log_2\rfloor$，查询取 $k=\texttt{lg}[len]$，两块 $[x,x+2^k)$ 与 $[y-2^k+1,y+1)$。
7. **discuss by category** — 存下标不存串（省内存省拷贝）；`x>y` 时 swap；`btr` 里键相同才比下标；输出用原串 `s[idx]`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N$ | 单词个数，$\le5\times10^4$ | `int n` | 读入 |
| $M$ | 询问个数，$\le3\times10^5$ | `int m` | 读入 |
| `s[i]` | 第 $i$ 个单词的**原始写法**，用于输出 | `string[mxn]` | 读入，0-based |
| `low[i]` | `s[i]` 的全小写副本，**只用于比较** | `string[mxn]` | 由 `s[i]` 逐字符 `+32` 得到 |
| `mxn` | $50000+5$ | `constexpr int` | 单词数组尺寸 |
| `mxk` | ST 表层数上界 $20$（$2^{16}>5\times10^4$） | `constexpr int` | `st` 第一维 |
| `lg[len]` | $\lfloor\log_2 len\rfloor$ | `int[mxn]` | `lg[1]=0`（全局默认），`lg[i]=lg[i>>1]+1` |
| `st[k][i]` | 区间 $[i,i+2^k)$ 内最优单词的**下标** | `int[mxk][mxn]` | `st[0][i]=i`；其余由 `btr` 合并；**只在 $i+2^k\le N$ 处有定义** |
| `btr(a,b)` | 返回 $a,b$ 中更优者：键大优先，键同则下标大优先 | `int(int,int)` | 全序 max 的实现 |
| `x,y` | 询问端点（读入后转 0-based，必要时 swap） | `int` | 每询问读入 |
| `k` | 查询块长的指数，`k=lg[y-x+1]` | `int` | 每询问现算 |

### 算法步骤

1. I/O 加速三行。
2. 读 $N,M$；对每个 $i$ 读 `s[i]`，复制出 `low[i]` 并把其中 `'A'..'Z'` 加 $32$ 变小写。
3. 递推 `lg[2..N]`：`lg[i]=lg[i>>1]+1`。
4. `st[0][i]=i`（$i=0..N-1$）。
5. 对 $k=1,2,\dots$ 直到 $2^k>N$：对 $i=0..N-2^k$，`st[k][i]=btr(st[k-1][i],st[k-1][i+2^{k-1}])`。
6. 每个询问：读 `x,y`，`--x;--y`，若 `x>y` 则 swap；`k=lg[y-x+1]`；`idx=btr(st[k][x],st[k][y-2^k+1])`；输出 `s[idx]` 与 `'\n'`。

### 复杂度

- 时间：$O(NL\log N+ML)$，$L\le15$；$N=5\times10^4,M=3\times10^5$ 时约 $1.7\times10^7$ 字符级操作。
- 空间：$O(N\log N+NL)\approx8$ MB（`st` 约 $4$ MB）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；按样例说明反推的 $5$ 单词 $5$ 询问逐条吻合；另造"只差大小写平局""前缀关系"两组手算数据全对；$305$ 组随机小数据（$N,M\le30$，字母表 $\{a,b,c,A,B,C\}$ 或全字母，刻意注入重复与前缀）与逐字符比较 + 线性扫描的独立暴力逐字节一致，$0$ mismatch；$N=2000,M=4000$ 与 $N=50000,M=200$（ST 表用到第 $15$ 层）两组中/大规模也与暴力一致；$N=50000,M=300000$ 极限数据运行 $0.205$ s。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2412 查单词
// 思路：忽略大小写 ⇒ 每个单词存一份全小写键 low[]，原串 s[] 留着输出。
//       「键大优先，键同则靠后优先」打包成二元组 (low[i],i) 的字典序 ⇒ 一个全序 max。
//       max 幂等 ⇒ ST 表可以用两块重叠区间 O(1) 回答询问。
//       st[k][i] 存下标而不是字符串，省内存省拷贝。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005},mxk{20};

int n,m,lg[mxn],st[mxk][mxn];
string s[mxn],low[mxn];

int btr(int a,int b)	// 忽略大小写字典序大者优先；相同则靠后（下标大）者优先
{
	if(low[a]!=low[b])
		return low[a]>low[b]?a:b;
	return a>b?a:b;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
	{
		cin>>s[i];
		low[i]=s[i];
		for(char&c:low[i])
			if(c>='A'&&c<='Z')
				c+=32;			// low 只用于比较，s 保留原样用于输出
	}
	for(int i=2;i<=n;++i)
		lg[i]=lg[i>>1]+1;
	for(int i=0;i<n;++i)
		st[0][i]=i;
	for(int k=1;(1<<k)<=n;++k)
		for(int i=0;i+(1<<k)<=n;++i)
			st[k][i]=btr(st[k-1][i],st[k-1][i+(1<<(k-1))]);
	for(int q=0,x,y;q<m;++q)
	{
		cin>>x>>y;--x;--y;
		if(x>y)
			swap(x,y);
		int k=lg[y-x+1];
		cout<<s[btr(st[k][x],st[k][y-(1<<k)+1])]<<'\n';
	}
	return 0;
}
```

### 代码说明

- **两份串**：`low` 是键、`s` 是答案。把两者混用（比较用原串、或输出用小写）都会错：前者大小写敏感，后者让"平局取靠后"失效。
- `btr` 是整份代码的核心：`low[a]!=low[b]` 时按键取大，否则按下标取大。它实现的是引理 2 的全序 max，因此结合律、幂等律都成立，ST 表才敢用重叠区间。
- `st[k][i]` 存**下标**：`int` 数组 $20\times50005\approx4$ MB；若存 `string` 会显著变大且每次合并都要拷贝。
- 建树边界 `i+(1<<k)<=n` 与外层 `(1<<k)<=n` 保证只建有定义的格子；查询访问的两格由引理 6(c) 保证一定建过——**全局 `int` 默认 $0$ 是合法下标，读到未建格子不会报错只会静默出错**，所以这两处边界必须写对。
- `lg[1]=0` 依赖全局数组零初始化，恰好正确；`lg[0]` 不会被用到（询问长度 $\ge1$）。
- `mxk{20}` 是 $+5$ 松弛：$N\le5\times10^4<2^{16}$，实际只用到第 $15$ 层。
- 输出 `s[idx]` 保留原大小写；`'\n'` 换行；`x>y` 时 swap 是零成本保险。
