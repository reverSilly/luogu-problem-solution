# P2559 [AHOI2002] 哈利·波特与魔法石 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 星球上有七种地形，穿越每种地形有一个基础耗时 $h$：石子路 $h_1=2$、森林 $h_2=6$、草地 $h_3=4$、山地 $h_4=8$、雪地 $h_5=6$、沼泽 $h_6=10$、沙漠 $h_7=14$。若地形 $u$ 的区域里有魔法石（$s_u=1$），穿越时间减半为 $h_u/2$；否则（$s_u=0$）仍是 $h_u$。城市之间由道路直接相连，每条道路有一种地形。图是连通的（任意两城市间至少有一条路径）。给定起点 $i$、终点 $j$ 和所有道路，求从 $i$ 到 $j$ 的**最快路线**耗时。城市编号 $\le100$ 但未必连续，道路数 $c\le10000$。

**第一步：把"最快路线"翻译成图论语言。** 城市是顶点，道路是边，穿越一条边的耗时就是边权。一条路线的总耗时 = 路径上各边权之和。"最快路线"就是**边权和最小的路径**——这正是**单源最短路径**。于是问题归约为：建图 → 跑最短路 → 输出 `dis[终点]`。

**第二步：边权怎么算？——减半且必为整数。** 一条地形为 $t$ 的边，权值是
$$w=\begin{cases}h_t/2,&s_t=1\\ h_t,&s_t=0\end{cases}$$
我注意到 $h=\{2,6,4,8,6,10,14\}$ **全是偶数**，所以 $h_t/2$ 一定是整数（$\{1,3,2,4,3,5,7\}$），边权全程是整数，不用碰浮点。这一步很关键：如果 $h$ 有奇数，减半会出现 $.5$，就得考虑浮点或翻倍处理；但本题偶数保证让一切都干净。所有边权 $\ge1>0$，**没有负权**，这直接决定了能用 Dijkstra。

**第三步：图是有向还是无向？** 题面说"任意两个能够不经过别的城市而直接通达的城市 $i$ 和 $j$ 之间都只有一种地形 $t_{i,j}$"，记号 $t_{i,j}$ 对称，且例子里路线 $1\to2\to4$ 把边 $1$-$2$、$2$-$4$ 当作可双向通行。所以是**无向图**，读入一条边 $(u,v,t)$ 时要往两个方向都加。

**第四步：城市编号不连续怎么办？** 编号 $\le100$ 但未必连续（可能只有城市 $1,5,99$）。最省事的办法是**直接拿编号当数组下标**：开 `graph[105]`、`dis[105]`，编号 $1\sim100$ 都能放下，没用到的编号对应的邻接表为空、`dis` 保持 $\infty$，不影响 Dijkstra。这样就不用做"编号→连续下标"的离散化映射，代码更短。

**第五步：选 Dijkstra。** 边权全正、顶点 $\le100$、边 $\le10000$，Dijkstra（堆优化）$O((V+E)\log V)$ 绰绰有余。我用惰性删除的写法：堆里存 `(dis, 顶点)`，弹出时若已 `vis` 就跳过，否则标记并松弛邻居。图连通保证 `dis[终点]` 有限。

**手造数据核对**（题面给了一个例子，我把它当主测试，再补两个边界）：

主测试，按题面例子：$s=[0,1,0,0,0,0,0]$（只有森林有魔法石），起点 $1$ 终点 $4$，四条边 $1$-$2$ 地形 $1$、$1$-$3$ 地形 $3$、$2$-$4$ 地形 $2$、$3$-$4$ 地形 $3$。边权：$1$-$2$ 是石子路 $s_1=0\to2$；$2$-$4$ 是森林 $s_2=1\to6/2=3$；$1$-$3$、$3$-$4$ 是草地 $s_3=0\to4$。路线 $1\to2\to4=2+3=5$，路线 $1\to3\to4=4+4=8$，最快 $5$。程序输出 $5$ ✓。

边界一，起点 = 终点：输出 $0$（不用走任何边）。

边界二，验证减半确实生效：$s_6=1$（沼泽有石），边 $1$-$2$、$2$-$3$ 都是沼泽（$h_6=10\to5$），另有直连 $1$-$3$ 沙漠（$h_7=14$）。路线 $1\to2\to3=5+5=10 < 14$，输出 $10$，确认减半后的权值被正确用于比较。

## 二、思维链：完整证明

**记号。** 顶点集 $V\subseteq\{1,\dots,100\}$（城市编号），边集 $E$（无向），边 $(u,v)$ 地形 $t$ 的权 $w(u,v)=s_t?h_t/2:h_t$。起点 $st$、终点 $ed$。$\delta(st,v)$ 为 $st$ 到 $v$ 的真实最短距离。`dis[v]` 为算法维护的距离估计，`vis[v]` 标记是否已确定。$h=\{0,2,6,4,8,6,10,14\}$（$1$-based，$h_0$ 占位）。

---

### 引理 1（边权为正整数）

对任意边，$w\in\{1,2,3,4,5,6,7,8,10,14\}$，特别地 $w\ge1>0$ 且为整数。

*证明*：$h_t\in\{2,6,4,8,6,10,14\}$ 全为偶数，故 $s_t=1$ 时 $w=h_t/2\in\{1,3,2,4,3,5,7\}$ 为整数；$s_t=0$ 时 $w=h_t\in\{2,6,4,8,6,10,14\}$。两情形并集为 $\{1,2,3,4,5,6,7,8,10,14\}$，最小值 $1>0$。故所有边权是正整数。证毕。

**推论**：无负权 ⇒ Dijkstra 适用；权值为整数 ⇒ 全程 `int` 运算无精度问题；最大路径长 $\le(|V|-1)\cdot\max w\le99\times14=1386$，`int` 足够，哨兵 `inf=1145141919` 远大于任何真实距离。

---

### 引理 2（最快路线 = 最短路径）

从 $st$ 到 $ed$ 的最快路线耗时等于图论最短距离 $\delta(st,ed)$。

*证明*：一条路线是顶点序列 $st=v_0,v_1,\dots,v_k=ed$，相邻顶点有边相连。穿越每条边 $(v_{j},v_{j+1})$ 耗时 $w(v_j,v_{j+1})$（引理 1），总耗时 $\sum_{j=0}^{k-1}w(v_j,v_{j+1})$，即该路径的边权和。"最快"即最小化此和，正是最短路径定义 $\delta(st,ed)=\min_{\text{路径}}\sum w$。图连通（题面"任意两城市间至少一条道路"）保证至少存在一条路径，$\delta$ 有限。故最快路线耗时 $=\delta(st,ed)$。证毕。

---

### 引理 3（`dis` 始终是某条路径的长度，且为上界）

算法运行中任意时刻，对每个 $v$：`dis[v]` 要么为 $\infty$，要么等于某条 $st\to v$ 路径的边权和；从而 `dis[v]`$\ge\delta(st,v)$。

*证明*：对松弛操作归纳。初始 `dis[st]=0`（空路径，和为 $0$），其余 $\infty$，成立。每次松弛 `dis[v]=dis[u]+w(u,v)`：由归纳假设 `dis[u]` 是某条 $st\to u$ 路径 $P$ 的和，则 `dis[u]+w(u,v)` 是路径 $P$ 接上边 $(u,v)$ 得到的 $st\to v$ 路径的和。故 `dis[v]` 始终是某条真实路径的长度。而 $\delta(st,v)$ 是所有路径和的最小值，故 `dis[v]`$\ge\delta(st,v)$。证毕。

---

### 引理 4（Dijkstra 确定序正确性：弹出即最优）

设算法按堆顶弹出顺序确定顶点（惰性删除：`vis` 过的跳过）。则每个顶点 $u$ **首次被确定**（弹出且未 `vis`）时，`dis[u]`$=\delta(st,u)$。

*证明*：对确定顺序归纳。

**基础**：第一个确定的是 $st$（`dis[st]=0` 最小），$\delta(st,st)=0$（无负权，空路径最优），成立。

**归纳**：设此前确定的顶点 $x$ 都满足 `dis[x]`$=\delta(st,x)$。令 $u$ 为下一个被确定的顶点（堆中未确定顶点里 `dis` 最小者）。反设 `dis[u]`$>\delta(st,u)$。

取一条真实最短路径 $P:st\to u$，其和为 $\delta(st,u)$。沿 $P$ 从 $st$ 走向 $u$，因 $st$ 已确定、$u$ 尚未确定，必存在 $P$ 上第一条边 $(x,y)$ 使 $x$ 已确定、$y$ 未确定（$y$ 可能就是 $u$）。

- $x$ 已确定，由归纳假设 `dis[x]`$=\delta(st,x)$。
- $x$ 被确定时松弛了边 $(x,y)$，故此后 `dis[y]`$\le$`dis[x]`$+w(x,y)=\delta(st,x)+w(x,y)$。
- 因 $P$ 是最短路径且权非负，其前缀 $st\to x$ 也是最短的（否则可替换前缀得到更短的 $st\to u$ 路径，矛盾），且 $\delta(st,x)+w(x,y)=\delta(st,y)$（$x,y$ 是 $P$ 上相邻点，前缀最优）。故 `dis[y]`$\le\delta(st,y)$。
- 结合引理 3（`dis[y]`$\ge\delta(st,y)$），得 `dis[y]`$=\delta(st,y)$。

因 $y$ 在 $P$ 上、权非负，$\delta(st,y)\le\delta(st,u)<$`dis[u]`，故 `dis[y]`$<$`dis[u]`。但 $y$ 未确定且 `dis[y]` 有限（在堆中），而 $u$ 是堆中未确定顶点的最小者，应有 `dis[u]`$\le$`dis[y]`，矛盾。

故反设不成立，`dis[u]`$=\delta(st,u)$。归纳完成。证毕。

**注（非负权是必要条件）**：证明中"$\delta(st,y)\le\delta(st,u)$"依赖权非负（$y$ 在 $st\to u$ 最短路径上，前缀距离不超过全程）。若存在负权，此步断裂，Dijkstra 失效。本题引理 1 保证权 $\ge1>0$，条件满足。

---

### 引理 5（建图与编号处理正确）

把每条输入边 $(u,v,t)$ 以权 $w$（引理 1）加入 `graph[u]` 与 `graph[v]`（无向），直接用编号 $1\sim100$ 作下标（`mxn=105`），所得图与题意一致；未出现的编号邻接表为空，不影响最短路。

*证明*：无向性由引理 2 的题意分析（$t_{i,j}$ 对称、例子双向通行）确立，故加双向边正确。编号 $\le100$，`mxn=105` 覆盖下标 $0\sim104$，所有合法编号可作下标。未出现的编号不出现在任何边中，其邻接表为空，Dijkstra 永远不会松弛到它们（`dis` 保持 $\infty$），故不影响 $st\to ed$ 的最短路。平行边（若输入重复）会被分别加入，Dijkstra 松弛时取最小 `dis`，自动保留最优，不影响正确性。证毕。

---

### 引理 6（复杂度）

时间 $O((|V|+|E|)\log|V|)$，空间 $O(|V|+|E|)$。

*证明*：堆优化 Dijkstra：每条边至多触发一次成功松弛并入堆，堆大小 $O(|E|)$，每次入堆/弹出 $O(\log|E|)=O(\log|V|)$（$|E|\le|V|^2$）。总时间 $O((|V|+|E|)\log|V|)$。代入 $|V|\le100,|E|\le2c\le20000$（无向双向），约 $2\times10^4\times7\approx1.4\times10^5$ 次操作，远低于限制。空间：邻接表 $O(|E|)$，`dis/vis` $O(|V|)$，堆 $O(|E|)$。证毕。

---

### 定理

程序输出 $\delta(st,ed)$，即起点到终点的最快路线耗时；时间 $O((|V|+|E|)\log|V|)$。

*证明*：引理 1 保证边权为正整数（Dijkstra 适用、无精度问题）；引理 2 把最快路线归约为最短路径；引理 5 保证建图正确；引理 3、4 保证 Dijkstra 弹出即最优，故 `dis[ed]`$=\delta(st,ed)$；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 边权 $=s_t?h_t/2:h_t$；$h$ 全偶 ⇒ 减半仍为整数，权 $\ge1>0$ 无负权。
- **reduce to easier problem** — "最快路线"= 边权和最小的路径 = 单源最短路径；无向图、连通。
- **classic problem solution** — 正权最短路 ⇒ 堆优化 Dijkstra（惰性删除 + `vis`），弹出即最优（引理 4 的交换论证）。
- **discuss by category** — 编号 $\le100$ 不连续 ⇒ 直接拿编号当下标（`mxn=105`），未用编号邻接表空、`dis` 保持 $\infty$，无需离散化。
- **explore its property** — 起点 = 终点时 `dis=0`；平行边自动取最优；图连通保证答案有限。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `s[u]` | 地形 $u$ 是否有魔法石（$0/1$） | `int[8]`，读入 | $u=1..7$ |
| `h[u]` | 地形 $u$ 基础耗时 | `int[8]={0,2,6,4,8,6,10,14}` | $h_0$ 占位，$h_1..h_7$ 如题 |
| `graph[u]` | 城市 $u$ 的邻接表 `{邻点,权}` | `vector<pair<int,int>>[mxn]` | 无向，双向加边 |
| `dis[v]` | $st$ 到 $v$ 的当前最短估计 | `int[mxn]`，`fill` 为 `inf` | `dis[st]=0` |
| `vis[v]` | $v$ 是否已确定（弹出过） | `bool[mxn]`，默认 `false` | 惰性删除跳过已确定 |
| `st,ed` | 起点、终点编号 | `int`，读入 | 直接用编号作下标 |
| `c` | 道路数（$\le10000$） | `int`，读入 | 每条边读 $u,v,t$ |
| `mxn` | $100+5$ | `constexpr int{105}` | 编号 $\le100$，$+5$ 松弛 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 远大于最大真实距离 $1386$ |

### 算法步骤

1. I/O 加速三行。
2. 读 $s[1..7]$；读 `st,ed,c`。
3. 读 $c$ 条边 $(u,v,t)$，算 $w=s[t]?h[t]/2:h[t]$，`graph[u].push({v,w})`、`graph[v].push({u,w})`。
4. `fill_n(dis,mxn,inf)`；`dis[st]=0`；堆 `Q.push({0,st})`。
5. Dijkstra：弹堆顶 `(d,u)`，若 `vis[u]` 跳过；否则 `vis[u]=true`，松弛每个邻居 `v`：若 `dis[u]+w<dis[v]` 则更新并入堆。
6. 输出 `dis[ed]`。

### 复杂度

- 时间：$O((|V|+|E|)\log|V|)$，$|V|\le100,|E|\le20000$，约 $1.4\times10^5$ 次操作。
- 空间：$O(|V|+|E|)$（邻接表 + 堆）。
- 值域：最大距离 $\le1386$，`int` 安全；`inf=1145141919` 不会被误当真实距离。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子（$1\to2\to4$ 森林减半）输出 $5$ 吻合；另测起点=终点（输出 $0$）、沼泽减半多段路径（输出 $10$）两组边界全对。普及/提高-级标准最短路，证明已闭合，无需对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2559 [AHOI2002] 哈利·波特与魔法石
// 无向图，边权 = h[t]（该地形有魔法石则减半），Dijkstra 求起点到终点最短路
// 城市编号 ≤ 100 但未必连续，直接用编号作数组下标
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105},inf{1145141919};

int s[8],dis[mxn];
bool vis[mxn];
vector<pair<int,int>>graph[mxn];	// {邻点, 边权}
int h[8]={0,2,6,4,8,6,10,14};		// h[1..7]，h[0] 占位不用

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(int i=1;i<=7;++i)
		cin>>s[i];
	int st,ed,c;
	cin>>st>>ed>>c;
	for(int i=0,u,v,t;i<c;++i)
	{
		cin>>u>>v>>t;
		int w=s[t]?h[t]/2:h[t];		// 有魔法石减半，h 全为偶数故整除
		graph[u].push_back({v,w});
		graph[v].push_back({u,w});
	}
	fill_n(dis,mxn,inf);
	dis[st]=0;
	priority_queue<pair<int,int>,vector<pair<int,int>>,greater<>>Q;
	Q.push({0,st});
	while(!Q.empty())
	{
		auto[d,u]=Q.top();Q.pop();
		if(vis[u])
			continue;
		vis[u]=true;
		for(auto[v,w]:graph[u])
			if(dis[u]+w<dis[v])
			{
				dis[v]=dis[u]+w;
				Q.push({dis[v],v});
			}
	}
	cout<<dis[ed]<<'\n';
	return 0;
}
```

### 代码说明

- **`h[8]={0,2,6,4,8,6,10,14}`**：$1$-based 存七种地形耗时，`h[0]` 占位（地形编号 $1\sim7$）。全偶数保证 `h[t]/2` 整除（引理 1）。
- **`w=s[t]?h[t]/2:h[t]`**：有魔法石减半。`s[t]` 为 $0/1$，三目直接选权值，无浮点。
- **双向加边**：无向图（引理 5），`graph[u]` 与 `graph[v]` 各加一次。平行边会被分别加入，松弛取最小自动保留最优。
- **编号直接作下标**：`mxn=105` 覆盖编号 $1\sim100$，未用编号邻接表空、`dis` 保持 `inf`，Dijkstra 不会触及，无需离散化（引理 5）。
- **`fill_n(dis,mxn,inf)` 必须显式写**：全局 `int` 数组默认 $0$，而 $0$ 是合法距离，会把所有点误判为"已可达且距离 $0$"。这是风格规范强调的"不可达数组必须显式填 INF"陷阱。
- **惰性删除 `if(vis[u])continue;`**：堆里可能有同一顶点的多个旧估计，弹出时若已确定就跳过，保证每个顶点只松弛一次（引理 4 的确定序）。
- **`greater<>` 小根堆**：`pair<dis,顶点>` 按 `dis` 升序，堆顶是当前最小估计，符合 Dijkstra 贪心。
- **`dis[ed]` 即答案**：图连通保证有限；起点=终点时 `dis[st]=0` 直接输出 $0$。
