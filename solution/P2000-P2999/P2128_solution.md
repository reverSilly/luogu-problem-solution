# P2128 [NWERC 2013] 赤壁之战 — 题解

## 一、解题过程：人类思考叙事

题目讲的是"连环计"：战船之间用铁索相连，要选出一些战船，使得它们**两两之间都有铁索直接连接**，并让这些战船的总价值最大。

翻译成图论语言：给每个战船一个点，每条铁索是一条无向边。题目要求选出一个**团**（clique），使得团内点的权值之和最大。

如果只是"最大权团"，那是 NP-难的。但本题有一句常被忽略的关键条件：

> 没有铁索两两相交或穿过战船。

这句话把图限制成了**平面图**。而平面图有一个经典性质：它不可能包含 $K_5$（完全图 $K_5$ 是非平面的）。所以：

**答案中选出的战船最多只有 4 艘！**

于是问题从"最大权团"退化成了"在所有大小为 1、2、3、4 的团里挑价值和最大的那个"，可以暴力枚举。

具体怎么做？$N\le 450$，$M\le 900$。如果直接三重/四重循环枚举，$450^4\approx 4\times10^{10}$，太慢。

注意到 $N=450$ 很小，可以用 `bitset<455>` 存邻接矩阵，然后：
- 枚举边 $(u,v)$：这是 2 元团；
- `common = adj[u] & adj[v]`：所有同时与 $u,v$ 相邻的点，3 元团只需再枚举 $w\in common$ 且 $w>v$；
- `three = common & adj[w]`：同时与 $u,v,w$ 都相邻的点，4 元团只需枚举 $z\in three$ 且 $z>w$。

用"编号递增"（$u<v<w<z$）来保证每个团只被数一次。

复杂度：枚举边的部分是 $O(N^2)$，每条边做一次 bitset 交（$N/64\approx 8$ 个字长）。然后 3 元团枚举是 $O(N^2\cdot N/64)$… 实际上 `common` 只在有边处非空，且 3 元团数量至多 $O(M)$ 级别（平面图的三角形数是 $O(N)$），4 元团同理。所以实际很快。

严谨地说，平面图中 $M\le 3N-6=1344$，而三角形数量也受平面图性质约束（$O(N)$），所以枚举量很小。

另外 1 元团也要考虑（可能只有一个点，且它没有边）——答案初值取所有单点价值的最大值。

还有一个细节：$V_i\le 6000$，$N\le450$，最大和 $4\times6000=24000$，`int` 够用。

## 二、思维链：完整证明

**引理 1**：题目要求的"被点燃的战船集合"恰好是图中的一个团。

*证明*：题目要求"被点燃的曹军船只两两之间都有铁索连接"，即集合内任意两点之间都有一条铁索直接相连，这正是团的定义。证毕。

**引理 2**：本题的图是平面图。

*证明*：题目保证"没有铁索两两相交或穿过战船"，即任意两条铁索作为连接船顶点的线段在平面上不相交，也不穿过任何战船（顶点）。因此把战船放在平面上对应位置、以铁索为边，得到的嵌入中任意两条边不内部相交，是一个平面嵌入，即该图是平面图。证毕。

**引理 3**：平面图中不存在 $K_5$。

*证明*：设平面图有 $n\ge 3$ 个点、$m$ 条边。由 Euler 公式 $n-m+f=2$（$f$ 为面数）以及每条边被两个面界定、每个面至少有 3 条边，得 $3f\le 2m$，从而
$$m\le 3n-6.$$
若平面图含 $K_5$ 作为子图，则该子图有 $n'=5$、$m'=10$ 条边。但 $10>3\times5-6=9$，与 $m'\le 3n'-6$ 矛盾。证毕。

**引理 4**：任意团的大小至多为 4。

*证明*：若团大小 $\ge 5$，则它包含一个 5 元子团，该 5 个点两两相连，即包含 $K_5$ 作为子图。平面图的子图仍是平面图（删点删边不破坏平面性），由引理 3 矛盾。证毕。

**引理 5（枚举的完备性与唯一性）**：算法枚举了所有大小为 1、2、3、4 的团，且每个恰被枚举一次。

*证明*：
- 大小为 1 的团：单独在第一段循环中枚举，共 $N$ 次。
- 大小为 2 的团：形如 $\{u,v\}$，恰有一对 $u<v$，在边枚举中恰被处理一次。
- 大小为 3 的团：形如 $\{u,v,w\}$，其三个点两两相连，故 $(u,v)$ 是边，$w$ 必在 `common = adj[u]&adj[v]` 中，且 $w>v$（因 $v<w$）。故该团在处理边 $(u,v)$ 的内层循环中被枚举一次；又因编号严格递增，不会从其他边 $(u',v')$ 处重复枚举（那要求 $u',v'$ 是同一对）。
- 大小为 4 的团：同理，形如 $\{u,v,w,z\}$，$(u,v)$ 为边，$w\in common$，$w>v$；$z$ 同时与三者相邻故 $z\in common\&adj[w]$，且 $z>w$。故恰被枚举一次。
- 由引理 4，不存在大小 $\ge5$ 的团。

故枚举既无遗漏也无重复。证毕。

**定理**：算法输出的即最大可摧毁总价值。

*证明*：由引理 1，可行方案与团一一对应，目标为团内权值和最大。由引理 4，所有可行方案对应大小 $\le 4$ 的团；由引理 5，算法枚举了全部这些团并对每个团计算了权值和，取其中最大者即全局最优。证毕。

## 三、模式总结（按实际思考顺序）

1. "两两之间都有铁索连接" ⇒ 找**团**，权值和最大 ⇒ 表面上是 NP-难的最大权团
2. 读题抓关键句："没有铁索两两相交或穿过战船" ⇒ **平面图**
3. 平面图不含 $K_5$（Euler 公式 $m\le3n-6$）⇒ **团大小 $\le 4$
4. 枚举 1/2/3/4 元团；用 `bitset` 求公共邻居加速
5. 用"编号严格递增"保证不重复计数
6. 答案初值必须取单点最大价值（只有一艘船的情况）

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 |
|------|------|------|
| $N$ | 战船数量 | `int` |
| $M$ | 铁索数量 | `int` |
| $V_i$ | 第 $i$ 艘战船的战略价值 | `int` |
| `adj[u]` | 与 $u$ 有铁索相连的点的位集合 | `bitset<mxn>` |
| `common` | `adj[u] & adj[v]`，$u,v$ 的公共邻居 | `bitset<mxn>` |
| `three` | `common & adj[w]`，三元团的公共邻居 | `bitset<mxn>` |
| `ans` | 答案 | `int` |

### 算法步骤

1. 读入 $N,M$ 与价值数组 `val`。
2. 读入每条铁索 $(a,b)$，置 `adj[a][b]=adj[b][a]=1`（内部 0-based）。
3. `ans` 初始化为所有单点价值的最大值（1 元团）。
4. 枚举每对 $u<v$：
   - 若 $(u,v)$ 不是边，跳过；
   - 用 `ans = max(ans, val[u]+val[v])` 更新 2 元团；
   - 计算 `common = adj[u]&adj[v]`，枚举 $w>v$ 且 `common[w]` 为真：用三者之和更新 3 元团；
   - 计算 `three = common&adj[w]`，枚举 $z>w$ 且 `three[z]` 为真：用四者之和更新 4 元团。
5. 输出 `ans`。

### 复杂度

- 位运算按 $O(N/64)$ 计：
  - 边枚举 $O(N^2)$；
  - 每条边一次 `bitset` 交：$O(N^2\cdot N/64)$；
  - 3 元团与 4 元团的枚举次数等于平面图中三角形、四边形的个数，均为 $O(N)$ 量级，每次数组查询 $O(1)$。
- 总时间复杂度上界 $O(N^3/64)$，实际远小于此；$N=450$ 时轻松通过。
- 空间复杂度 $O(N^2/64)$ 个机器字（约 $450\times455/8\approx 25$ KB）。

### 代码行为

1. I/O 加速三行固定顺序；
2. `bitset<mxn>adj[mxn]` 全局静态分配，`mxn{455}` = 上界 $450$+5；
3. 价值数组 `val` 全局，内部下标 0-based，读入铁索时 `--a;--b;`；
4. 枚举顺序 `$u<v$`、`$w>v$`、`$z>w$` 保证不重不漏；
5. 输出用 `'\n'`。

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{455};

int val[mxn];
bitset<mxn>adj[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m;
	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>val[i];
	for(int i=0;i<m;++i)
	{
		int a,b;
		cin>>a>>b;
		--a;--b;
		adj[a][b]=adj[b][a]=1;
	}

	int ans=0;
	for(int i=0;i<n;++i)
		ans=max(ans,val[i]);

	//铁索两两不相交 => 平面图 => 团的大小至多 4
	for(int u=0;u<n;++u)
		for(int v=u+1;v<n;++v)
		{
			if(!adj[u][v])
				continue;
			ans=max(ans,val[u]+val[v]);
			bitset<mxn>common=adj[u]&adj[v];
			for(int w=v+1;w<n;++w)
			{
				if(!common[w])
					continue;
				ans=max(ans,val[u]+val[v]+val[w]);
				bitset<mxn>three=common&adj[w];
				for(int z=w+1;z<n;++z)
					if(three[z])
						ans=max(ans,val[u]+val[v]+val[w]+val[z]);
			}
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `mxn{455}` = 约束上界 $450$ + 5，符合"+5 松弛约定"。
- 注释标出**平面图 ⇒ 团大小至多 4**这一核心结论。
- `common`/`three` 是 `bitset` 按值运算，每次得到一个新的位集合；`three` 只在发现 3 元团后才计算，避免无谓开销。
- 枚举顺序 `$u<v$、$w>v$、$z>w$` 保证每个团恰被枚举一次。
- 价值数组与邻接矩阵都放全局，避免栈溢出。
- 换行用 `'\n'`。
