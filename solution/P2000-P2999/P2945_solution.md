# P2945 [USACO09MAR] Sand Castle S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 有 $N$ 个垛堞（$1\le N\le 25000$），当前高度 $M_1,\dots,M_N$（$1\le M_i\le 10^5$）。给定目标高度的**多重集** $\{B_1,\dots,B_N\}$（$1\le B_i\le 10^5$），可以把它们以**任意排列**分配给 $N$ 个垛堞。把高度 $m$ 改成 $b$ 的费用：升高每单位 $X$，降低每单位 $Y$（$1\le X,Y\le 100$），即

$$g(m,b)=\begin{cases}X\,(b-m),&b\ge m,\\ Y\,(m-b),&b<m.\end{cases}$$

求最优排列下的最小总费用。答案保证在 32 位有符号整数内。子任务：约 $40\%$ 数据 $N\le 9$，约 $60\%$ 数据 $N\le 18$。

**子任务在暗示什么？** $N\le 9$ 可以枚举全排列（$9!=362880$）；$N\le 18$ 可以状压 DP（$2^{18}\times 18\approx 4.7\times 10^6$）。这说明本题**本质是一个指派问题**（每个 $M_i$ 配一个 $B_j$，最小化费用和），而满分做法必须利用费用函数的特殊结构把指派问题塌缩成排序。方向明确：找贪心。

**手造小数据核对**（题面 Hint 给了一组样例，另造两组打交叉配对）：

第一组（题面样例）：$N=3,X=6,Y=5$，$M=(3,1,1)$，$B=(1,2,2)$。Hint 的方案：$3\to 2$ 降 $1$ 花 $5$，$1\to 2$ 升 $1$ 花 $6$，$1\to 1$ 不动，共 $11$。排序后按序配对：$M'=(1,1,3)$，$B'=(1,2,2)$，$(1,1)\to 0$，$(1,2)\to 6$，$(3,2)\to 5$，也是 $11$ ✓。

第二组（专打"交叉配对更差"）：$N=2,X=Y=1$，$M=(1,5)$，$B=(2,4)$。按序配对 $(1,2),(5,4)$：$1+1=2$；交叉配对 $(1,4),(5,2)$：$3+3=6$。答案 $2$。

第三组（$X\ne Y$ 时贪心是否仍成立）：$N=2,X=1,Y=10$，$M=(1,5)$，$B=(2,4)$。按序：升 $1$ 花 $1$ + 降 $1$ 花 $10$ = $11$；交叉：升 $3$ 花 $3$ + 降 $3$ 花 $30$ = $33$。答案 $11$。**降低很贵时，直觉上似乎该"让大的 $M$ 配大的 $B$ 避免下降"——但按序配对已经正是这么做的**，这组数据验证贪心不受 $X,Y$ 相对大小影响。

## 二、思维链：完整证明

**记号。** 把 $M$ 升序排好记 $m_1\le m_2\le\cdots\le m_N$，$B$ 升序排好记 $b_1\le\cdots\le b_N$。一个方案是排列 $\pi$，费用 $C(\pi)=\sum_{i=1}^N g(m_i,b_{\pi(i)})$。目标 $\min_\pi C(\pi)$。

### 第一步：探索费用函数的结构

**探索性质。** 一般指派问题要 Hungarian 算法 $O(N^3)$，$N=25000$ 完全不可行。但本题费用不是任意矩阵：$g(m,b)$ 只依赖差 $b-m$，且是**分段线性凸函数**。令

$$h(t)=X\max(0,t)+Y\max(0,-t)=\begin{cases}Xt,&t\ge 0,\\ -Yt,&t<0,\end{cases}\qquad g(m,b)=h(b-m).$$

$h$ 是两条直线取 max（$h(t)=\max(Xt,-Yt)$，因 $X,Y>0$），斜率从 $-Y$ 跳到 $X$，是凸函数。"凸函数 + 差值结构"正是**排序配对最优**（重排不等式家族）的标志性条件。

还有一个有用的分解（后面注记用）：

$$g(m,b)=X(b-m)+(X+Y)\max(0,m-b).$$

验证：$b\ge m$ 时右边 $=X(b-m)+0$ ✓；$b<m$ 时 $=X(b-m)+(X+Y)(m-b)=Y(m-b)$ ✓。对 $\pi$ 求和，第一项 $X(\sum B-\sum M)$ 是**与排列无关的常数**，所以最小化总费用等价于最小化 $\sum_i\max(0,m_i-b_{\pi(i)})$——"总下降量"。这给了贪心一个直观解释：升高总量被守恒律锁死，唯一能优化的是别制造多余的下降。

### 第二步：先解最简单的版本

**考虑简化版。** $X=Y=1$ 时 $g(m,b)=|b-m|$。这是经典结论：两列数各自排序后按序配对，绝对差之和最小。证明靠"交叉配对可以解交叉而不增费用"。本题 $X\ne Y$ 时绝对值换成了不对称的凸折线，**同样的交换论证能不能走通？** 关键是证一个四边形不等式。

### 第三步：交换论证的核心——四边形不等式

**碰壁与修正。** 直接对 $g$ 分"谁大谁小"讨论 $m_1,m_2,b_1,b_2$ 的相对顺序，要分 $6$ 种排列情形，繁琐易漏。更干净的路线：把 $g$ 写成 $h(b-m)$，利用凸函数"增量随基点右移而不减"的性质，一个代数恒等式搞定所有情形。

### 引理 1（$h$ 的增量单调性）

对固定 $\delta\ge 0$，函数 $I(v)=h(v+\delta)-h(v)$ 关于 $v$ 单调不减。

*证明*：先给 $h$ 一个便于作差的表达式：

$$h(t)=Xt-(X+Y)\min(0,t).$$

验证：$t\ge 0$ 时 $\min(0,t)=0$，右边 $=Xt=h(t)$ ✓；$t<0$ 时右边 $=Xt-(X+Y)t=-Yt=h(t)$ ✓。

记 $\psi(t)=\min(0,t)$。则

$$I(v)=X\delta-(X+Y)\bigl(\psi(v+\delta)-\psi(v)\bigr).$$

计算 $\psi$ 的增量 $D(v)=\psi(v+\delta)-\psi(v)$，分三类：

- $v\ge 0$：$\psi(v)=\psi(v+\delta)=0$，$D(v)=0$；
- $v+\delta\le 0$：$\psi(v)=v,\ \psi(v+\delta)=v+\delta$，$D(v)=\delta$；
- $v<0<v+\delta$：$\psi(v)=v,\ \psi(v+\delta)=0$，$D(v)=-v$。

三类统一为 $D(v)=\min\bigl(\delta,\max(0,-v)\bigr)$（逐类代入即验证）。$\max(0,-v)$ 关于 $v$ 单调不增，与常数 $\delta$ 取 min 仍单调不增，故 $D(v)$ 单调不增。$X+Y>0$，所以 $I(v)=X\delta-(X+Y)D(v)$ 单调不减。证毕。

（直观：$I(v)$ 是 $h$ 在长为 $\delta$ 的窗口 $[v,v+\delta]$ 上的增量；窗口右移时扫过的斜率从 $-Y$ 段换到 $X$ 段，只增不减——这就是凸性。）

### 引理 2（四边形不等式 / 解交叉不增费用）

设 $m_1\le m_2$，$b_1\le b_2$。则

$$g(m_1,b_1)+g(m_2,b_2)\ \le\ g(m_1,b_2)+g(m_2,b_1).$$

即"小配小、大配大"不劣于"交叉配"。

*证明*：记 $\delta=m_2-m_1\ge 0$，$\varepsilon=b_2-b_1\ge 0$，$t=b_1-m_2$。把四个差值用 $t,\delta,\varepsilon$ 表示：

$$b_1-m_1=t+\delta,\quad b_2-m_2=t+\varepsilon,\quad b_1-m_2=t,\quad b_2-m_1=t+\delta+\varepsilon.$$

于是

$$\Delta:=\bigl[g(m_1,b_2)+g(m_2,b_1)\bigr]-\bigl[g(m_1,b_1)+g(m_2,b_2)\bigr]=h(t+\delta+\varepsilon)+h(t)-h(t+\delta)-h(t+\varepsilon).$$

按增量 $I(v)=h(v+\delta)-h(v)$ 重组：

$$\Delta=\bigl[h(t+\varepsilon+\delta)-h(t+\varepsilon)\bigr]-\bigl[h(t+\delta)-h(t)\bigr]=I(t+\varepsilon)-I(t).$$

$\varepsilon\ge 0$，由引理 1，$I(t+\varepsilon)\ge I(t)$，故 $\Delta\ge 0$。证毕。

**注意这个证明对 $X,Y$ 的相对大小没有任何假设**——$X<Y$、$X>Y$、$X=Y$ 一律成立。这解释了第三组手造数据：哪怕降低贵 $10$ 倍，解交叉依然不增费用。

### 第四步：从局部交换到全局最优

**归约。** 有了"相邻逆序对换不增费用"，就能把任意排列一步步冒泡成恒等排列（按序配对），每步费用不增——于是按序配对最优。这是交换论证的标准收尾，但要把"逆序对换恰好对应引理 2 的条件"核对清楚。

### 引理 3（冒泡归约）

对任意排列 $\pi$，存在一系列对换，把 $\pi$ 变成恒等排列，且每次对换后总费用不增。从而 $C(\mathrm{id})\le C(\pi)$。

*证明*：若 $\pi\ne\mathrm{id}$，则存在**相邻逆序**：位置 $i<j=i+1$ 使 $\pi(i)>\pi(j)$（任何非恒等排列都有相邻逆序——否则 $\pi(1)<\pi(2)<\cdots<\pi(N)$ 迫使 $\pi=\mathrm{id}$）。对换 $\pi(i),\pi(j)$：费用变化只涉及这两项，其余项不动。因 $m$ 已升序，$m_i\le m_j$；记 $b_{\pi(j)}\le b_{\pi(i)}$，由引理 2（取 $m_1=m_i,m_2=m_j,b_1=b_{\pi(j)},b_2=b_{\pi(i)}$）：

$$g(m_i,b_{\pi(j)})+g(m_j,b_{\pi(i)})\le g(m_i,b_{\pi(i)})+g(m_j,b_{\pi(j)}),$$

即对换后费用不增。每次对换消除一个逆序对（相邻对换使逆序总数恰减 $1$），逆序总数有限（$\le N(N-1)/2$），故有限步后 $\pi=\mathrm{id}$，全程费用不增。证毕。

### 定理（排序按序配对最优）

$\min_\pi C(\pi)=\sum_{i=1}^N g(m_i,b_i)$，其中 $m,b$ 各自升序。算法：两数组排序，按序累加 $g$，时间 $O(N\log N)$，空间 $O(N)$。

*证明*：引理 3 给出 $C(\mathrm{id})\le C(\pi)$ 对所有 $\pi$，故恒等排列（按序配对）最优；引理 2 保证每步交换合法，引理 1 是引理 2 的地基。复杂度：两次 `sort` 各 $O(N\log N)$，累加 $O(N)$；空间两个 `int` 数组 $O(N)$。值域：单项费用 $\le 100\times 10^5=10^7$，总和理论上界 $2.5\times 10^{11}$ 超 `int`，但题设保证答案在 32 位内；实现仍用 `i64` 累加，零成本保险。证毕。

**注记（守恒律视角）**：由第一步的分解，$\sum_i g(m_i,b_{\pi(i)})=X(\sum B-\sum M)+(X+Y)\sum_i\max(0,m_i-b_{\pi(i)})$。第一项与 $\pi$ 无关，故最优排列就是最小化"总下降量"的排列；引理 2 对 $\max(0,m-b)$ 同样成立（它是 $h$ 取 $X=0,Y=1$ 的特例），两条路线殊途同归。这个视角解释了为什么答案与 $X,Y$ 的具体比例"几乎无关"：比例只影响常数项与惩罚权重，不影响最优排列本身。

## 三、模式总结（按实际思考顺序）

- explore its property — 费用只依赖差 $b-m$，是斜率 $-Y\to X$ 的凸折线 $h$；本题本质是指派问题，子任务 $N\le 9/18$ 暗示排列枚举/状压 DP 只能拿部分分。
- consider easier version — $X=Y=1$ 时 $g=|b-m|$，经典"排序按序配对"；问：不对称凸折线能否沿用同一交换论证？
- classic problem solution — 交换论证：证四边形不等式 $g(m_1,b_1)+g(m_2,b_2)\le g(m_1,b_2)+g(m_2,b_1)$（$m_1\le m_2,b_1\le b_2$）。
- reduce to easier problem — 把 $h$ 写成 $Xt-(X+Y)\min(0,t)$，增量 $I(v)$ 单调不减一行代数搞定，避免 $6$ 种大小关系分类。
- classic problem solution — 冒泡归约：任意排列经相邻逆序对换变成按序配对，每步不增费用 ⇒ 排序贪心最优。
- explore its property — 守恒律分解：总费用 = 常数 $X(\sum B-\sum M)$ + $(X+Y)\times$总下降量，最优排列与 $X,Y$ 比例无关。
- discuss by category — $b>m$ 付 $X$、$b<m$ 付 $Y$、相等为 $0$；累加用 `i64` 防中间量溢出（题设保证最终答案在 32 位内）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 垛堞数，$\le 25000$ | `int` | 读入 |
| `x,y` | 升高/降低单价，$\le 100$ | `int` | 读入；**x 是升高、y 是降低** |
| `m[i]` | 当前高度，读入后升序排序 | `int[mxn]` | 0-based |
| `b[i]` | 目标高度多重集，读入后升序排序 | `int[mxn]` | 与 `m` 按序配对 |
| `ans` | 最小总费用 | `i64` | 全局默认 $0$，累加即可（费用非负，无 INF 陷阱） |
| `mxn` | $25000+5$ | `constexpr int` | |

### 算法步骤

1. I/O 加速三行；读 `n,x,y`。
2. 逐行读 `m[i],b[i]`（同一行给出一对，但两个数组各自独立排序，配对关系被打散重排）。
3. `sort(m,m+n)`，`sort(b,b+n)`。
4. 对每个 $i$：`b[i]>m[i]` 累加 `x*(b[i]-m[i])`，否则累加 `y*(m[i]-b[i])`（相等时加 $0$）。
5. 输出 `ans`。

### 复杂度

- 时间：$O(N\log N)$，$N=25000$ 时约 $3\times 10^5$ 次比较。
- 空间：$O(N)$，两个 `int` 数组约 $200$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例输出 $11$ 与 Hint 方案一致；另两组手造数据（$X=Y$ 交叉配对 $2$、$X\ne Y$ 交叉配对 $11$）均与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2945 [USACO09MAR] Sand Castle S
// 排序后按序配对最优（交换论证：代价函数关于 (m,b) 满足四边形不等式）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{25005};

int n,x,y,m[mxn],b[mxn];
i64 ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>x>>y;
	for(int i=0;i<n;++i)
		cin>>m[i]>>b[i];
	sort(m,m+n);sort(b,b+n);
	for(int i=0;i<n;++i)
		ans+=b[i]>m[i]?(i64)x*(b[i]-m[i]):(i64)y*(m[i]-b[i]);
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **两个数组各自独立排序**：输入虽然每行给一对 $(M_i,B_i)$，但那只是读入格式，$B$ 是多重集、可任意重排；保留原配对关系就错了。
- 三目里先转 `(i64)` 再乘：单项 $\le 10^7$ 其实 `int` 装得下，但累加和理论上界 $2.5\times 10^{11}$，`i64` 是零成本保险（题设保证答案在 32 位内，输出不受影响）。
- `b[i]==m[i]` 走 else 分支加 `y*0=0`，无需第三分支。
- `ans` 全局默认 $0$ 恰好是正确初值（费用非负、求最小）——本题没有"不可达"状态，不存在 INF 陷阱；若误写成求最大或初始化 INF 反而要另行处理。
- 贪心对 $X<Y$ 与 $X>Y$ 同样成立（引理 2 的证明不依赖两者大小），不需要按 $X,Y$ 关系分类讨论。
