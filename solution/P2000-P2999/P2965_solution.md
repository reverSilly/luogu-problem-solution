# P2965 [USACO09NOV] The Grand Farm-off S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 有 $3N$ 头牛（$1\le N\le 5\times10^5$），编号 $i=0,1,\dots,3N-1$。每头牛有两个属性，由多项式生成：

$$W_i=(a\cdot i^5+b\cdot i^2+c)\bmod d,\qquad U_i=(e\cdot i^5+f\cdot i^3+g)\bmod h,$$

其中 $0\le a,b,c,d,e,f,g,h\le 10^9$。要选出**恰好 $N$ 头**，第一目标是 $\sum U$ 最大，第二目标是在第一目标最优的所有方案里 $\sum W$ 最小。输出这个最小总重量 $\bmod M$（$10^7\le M\le 10^9$）。

**口径说明（三处，都按最合理解读定死）：**

1. **$i$ 从 $0$ 开始。** 英文原文明确 "for each cow $0\le i<3N$"；中文翻译的"编号 1..3N"是误译。Hint 也佐证：$W$ 序列 $5,6,9,14,21,30$ 恰是 $i^2+5$ 在 $i=0\dots5$ 的值（$i=0$ 给出 $c\bmod d=5$）。我按 $0$-based 生成。
2. **$d,h\ge 1$。** 系数范围写 $0\le d,h$，但题面同时说 $1\le W_i\le d$、$1\le U_i\le h$，隐含模数非零（否则 $\bmod 0$ 无定义）。我按 $d,h\ge 1$ 理解，代码里仍加一句防御：模数为 $0$ 时该属性取 $0$，避免除零崩溃。
3. **$W_i,U_i$ 可以为 $0$。** $\bmod d$ 的值域是 $[0,d)$，与"$1\le W_i$"略有出入，但这不影响任何推导（重量非负即可），照公式算。

**手造数据核对。** Hint 给了一个可反推的样例：$N=2$，$W$ 为 $5,6,9,14,21,30$、$U$ 为 $0,1,8,27,64,125$。取 $a=0,b=1,c=5,d=10^9$（$W_i=i^2+5$），$e=0,f=1,g=0,h=10^9$（$U_i=i^3$），$M=10^7$：

```
2 0 1 5 1000000000 0 1 0 1000000000 10000000
```

$U$ 最大的两头是 $i=4,5$（$64,125$），重量 $21+30=51$，输出 $51$ ✓。

再造四组专打易错点：

- **全平局**：$N=1$，$b=1,c=0,d=100$（$W=0,1,4$），$g=5,h=10$（$U$ 全 $5$）。三头 $U$ 相同，选最轻的 $0$，输出 $0$。同参数 $N=2$ 输出 $0+1=1$。
- **阈值处平局**：$N=2$，$f=1,h=2$（$U_i=i^3\bmod 2=i\bmod 2$：$0,1,0,1,0,1$），$W_i=i^2$：$0,1,4,9,16,25$。$U=1$ 的三头重量 $1,9,25$，取最轻两头 $1+9=10$。这组检验"平局组内按重量挑"。
- **取模回绕**：$c=9999999,b=1,d=10^9$，$U_i=i^3$，$N=2$：选 $i=4,5$，重量 $10000015+10000024=20000039$，$\bmod 10^7=39$。检验"先求真实和、最后才取模"。
- **大系数溢出探针**：$a=\dots=h=10^9$、$d=h=7$、$N=1$。手算：$i=0$：$W=U=10^9\bmod 7=6$；$i=1$：$W=U=3\times10^9\bmod 7=4$；$i=2$：$i^5\bmod 7=4,i^2\bmod 7=4,i^3\bmod 7=1$，$W=(4+4+1)\times10^9\bmod 7=9\times10^9\bmod 7=5$，$U=(4+1+1)\times10^9\bmod 7=6\times10^9\bmod 7=1$。$U$ 最大是 $i=0$，输出 $6$。这组里 $a\cdot(i^5\bmod d)$ 达 $4\times10^{18}$，专门检验中间量不溢出。

五组全部与程序输出一致；另跑 $N=5\times10^5$、系数全近 $10^9$ 的极限数据，程序正常完成。

**思路是怎么来的。** 两个子问题叠在一起：

1. **生成属性**：$i$ 最大 $1.5\times10^6$，$i^5\approx 7.6\times10^{30}$，`long long` 直接爆。但公式外面套着 $\bmod d$——**每一步乘法后立刻取模**，中间量永远 $<d\le 10^9$，两数相乘 $<10^{18}$，恰好落在 `long long` 范围内。这是"模运算同态"的直接应用。
2. **选牛**：先忽略第二目标。$\sum U$ 最大显然取 $U$ 最大的 $N$ 头——但"显然"两个字不够，平局时到底选谁？盯着平局看：设第 $N$ 大的 $U$ 值为 $u^\*$，那么 $U>u^\*$ 的牛**必须全带**（不带就能换进来涨分），$U<u^\*$ 的牛**一头都不能带**，剩下名额在 $U=u^\*$ 的牛里挑——挑最轻的。于是两级目标塌缩成一次排序：**按 $U$ 降序、$U$ 相同按 $W$ 升序，取前 $N$ 个**。交换论证可以严格证明这正是最优解。

最后 $\sum W<5\times10^5\times10^9=5\times10^{14}$，`long long` 装得下，累加完再 $\bmod M$ 即可。

## 二、思维链：完整证明

**记号。** 牛 $i\in\{0,\dots,3N-1\}$，属性 $(U_i,W_i)$ 由公式生成。把 $U$ 值降序排列为 $u_{(1)}\ge u_{(2)}\ge\dots\ge u_{(3N)}$，记 $u^\*=u_{(N)}$（第 $N$ 大），$m=\#\{i:U_i>u^\*\}$，$T=\#\{i:U_i=u^\*\}$，$k=N-m$。由定义 $m\le N-1$ 且 $m+T\ge N$（前 $N$ 大都 $\ge u^\*$），故 $1\le k\le T$。

---

### 引理 1（逐步取模的生成公式：正确且不溢出）

对任意模数 $m\ge 1$ 与 $i\ge 0$，按如下方式计算：

$$t=i\bmod m,\quad t_2=t\cdot t\bmod m,\quad t_3=t_2\cdot t\bmod m,\quad t_5=t_3\cdot t_2\bmod m,$$

则 $t_2\equiv i^2$、$t_3\equiv i^3$、$t_5\equiv i^5\pmod m$；进而

$$W_i=\bigl(a\cdot t_5^{(d)}+b\cdot t_2^{(d)}+c\bigr)\bmod d,\qquad U_i=\bigl(e\cdot t_5^{(h)}+f\cdot t_3^{(h)}+g\bigr)\bmod h$$

与题面公式完全一致（上标表示对相应模数计算）。且当 $m\le 10^9$、系数 $\le 10^9$ 时，所有中间量 $\le 2\times10^{18}+10^9<2^{63}-1$，64 位有符号整数不溢出。

*证明*：**正确性**：模运算对加法、乘法是同态：$x\equiv x'\pmod m$、$y\equiv y'\pmod m\Rightarrow xy\equiv x'y'\pmod m$。由 $t\equiv i$ 逐步得 $t_2\equiv t^2\equiv i^2$，$t_3\equiv i^3$，$t_5\equiv i^3\cdot i^2=i^5$。于是 $a\cdot t_5+b\cdot t_2+c\equiv a\cdot i^5+b\cdot i^2+c\pmod d$；两边都是非负整数，取 $\bmod d$ 后得到同一个 $[0,d)$ 内的代表元，即 $W_i$。$U_i$ 同理。

**范围**：$0\le t,t_2,t_3,t_5\le m-1\le 10^9-1$。每步乘积 $\le(10^9-1)^2<10^{18}$；`t2*t%d*t2%d` 的两次乘法各自 $<10^{18}$。最终 $a\cdot t_5+b\cdot t_2+c\le 10^9(10^9-1)+10^9(10^9-1)+10^9=2\times10^{18}-10^9<9.22\times10^{18}=2^{63}-1$。故全程 `long long` 安全。

**为什么必须逐步取模**：$i\le 1.5\times10^6-1$，$i^5\le(1.5\times10^6)^5\approx7.6\times10^{30}$，超出 `long long` 约 $12$ 个数量级，甚至 `unsigned long long` 也装不下；先算 $i^5$ 再取模的写法**必然**溢出。逐步取模把中间量压回 $<m$，是唯一自然的出路。证毕。

---

### 引理 2（最大有用度和的结构被完全钉死）

设 $S$ 是 $N$ 头牛的集合。则 $\sum_{i\in S}U_i$ 达到最大，**当且仅当** $S$ 包含全部 $m$ 头 $U>u^\*$ 的牛、恰好 $k=N-m$ 头 $U=u^\*$ 的牛、不含任何 $U<u^\*$ 的牛。此时 $\sum U=\sum_{j=1}^{N}u_{(j)}$。

*证明*：先证上界：任何 $N$ 元子集的第 $j$ 大 $U$ 值 $\le u_{(j)}$（全体的第 $j$ 大是任何子集第 $j$ 大的上界），逐项相加得 $\sum_{i\in S}U_i\le\sum_{j\le N}u_{(j)}$；取前 $N$ 大的集合达到等号，故最大值就是 $\sum_{j\le N}u_{(j)}$。

再证最优集的结构，用**交换论证**（反证）：

**(i) 必含全部 $U>u^\*$ 的牛。** 设最优集 $S$ 漏掉了某头 $x$（$U_x>u^\*$）。$S$ 中 $U>u^\*$ 的牛至多 $m-1$ 头，故 $S$ 中至少有一头 $y$ 满足 $U_y\le u^\*<U_x$。把 $y$ 换成 $x$：$\sum U$ 严格增加 $U_x-U_y>0$，与最优矛盾。

**(ii) 不含任何 $U<u^\*$ 的牛。** 设最优集 $S$ 含某头 $y$（$U_y<u^\*$）。$S$ 中 $U=u^\*$ 的牛至多 $N-m-1$ 头（$N$ 个位置，$\le m$ 个高于阈值，$\ge 1$ 个低于阈值）。而全体 $U=u^\*$ 的牛有 $T\ge N-m>N-m-1$ 头，故存在**未入选**的 $z$ 满足 $U_z=u^\*>U_y$。换 $y\to z$，$\sum U$ 严格增加，矛盾。

由 (i)(ii)，最优集恰为"$m$ 头高阈值牛 + $k$ 头阈值牛"。反之，任何这种结构的集合，其 $U$ 值多重集都等于 $\{u_{(1)},\dots,u_{(N)}\}$，$\sum U$ 达到上界，故最优。证毕。

---

### 引理 3（第二目标 = 阈值组内挑最轻的 $k$ 头）

在引理 2 刻画的所有最优集中，$\sum W$ 最小者恰为：带上全部 $m$ 头 $U>u^\*$ 的牛，再带 $U=u^\*$ 组中**最轻的 $k$ 头**。且最小总重量唯一确定（作为数值）。

*证明*：$m$ 头高阈值牛在所有最优集中固定，贡献常数 $C=\sum_{U_i>u^\*}W_i$。可变部分只有"从 $T$ 头阈值牛中选 $k$ 头"。设某方案选了阈值组中的 $y$ 而没选 $x$，且 $W_x<W_y$：把 $y$ 换成 $x$，由引理 2 结构不变（仍是最优集），$\sum W$ 严格减少 $W_y-W_x>0$。故任何"选了较重而漏了较轻"的方案都不是重量最小。反复交换直到选中组内最轻的 $k$ 头（每次交换严格减重，有限步终止），得到唯一的最小重量构型；其重量和 $=C+$（阈值组最轻 $k$ 头的重量和）。即使最轻 $k$ 头内部有同重量并列，选哪几头不影响重量**和**，故最小总重量作为数值唯一。证毕。

---

### 引理 4（一次双关键字排序取前缀 = 引理 3 的最优集）

把 $3N$ 头牛按关键字 $(U\ \text{降序},\ W\ \text{升序})$ 排序，取前 $N$ 头，其重量和恰为引理 3 的最小总重量。

*证明*：排序后序列分三段：前 $m$ 个位置是所有 $U>u^\*$ 的牛（它们的 $U$ 严格大于其余所有牛，必然排在最前）；接下来 $T$ 个位置是 $U=u^\*$ 的牛，段内按 $W$ 升序；最后是 $U<u^\*$ 的牛。前缀长度 $N=m+k$：恰好取走全部 $m$ 头高阈值牛，以及阈值段的前 $k$ 个——即 $W$ 最小的 $k$ 头（段内升序）。这正是引理 3 的构型。$(U,W)$ 完全相同的牛谁排前谁排后不影响重量和。证毕。

**推论**：不需要 `nth_element` 或堆来"部分选择"，一次完整排序就同时实现两级目标；排序比较器 `x.first!=y.first ? x.first>y.first : x.second<y.second` 是严格弱序（字典序的变体），`std::sort` 合法。

---

### 引理 5（重量和的范围与取模时机）

$\sum_{i\in S}W_i<N\cdot d\le 5\times10^5\times10^9=5\times10^{14}<2^{63}-1$，故用 `long long` 累加**不取模**也安全；最后输出 $\bigl(\sum W\bigr)\bmod M$ 即题目要求。

*证明*：每头 $W_i\le d-1$（引理 1），$N$ 头相加 $<N\cdot d\le 5\times10^{14}$。$M\ge 10^7>0$，取模良定义。模运算对加法同态，故"边加边模"与"加完再模"结果相同；这里范围足够，选更简单的后者。注意**不能**对 $U$ 或排序关键字取模——那会破坏大小关系；取模只作用于最终答案。证毕。

---

### 引理 6（复杂度）

时间 $O(N\log N)$，空间 $O(N)$。

*证明*：生成 $3N$ 头牛，每头常数次 64 位乘法/取模（引理 1），$O(N)$。排序 $3N\le 1.5\times10^6$ 个 `pair<int,int>`：$O(3N\log 3N)\approx 1.5\times10^6\times21\approx3.1\times10^7$ 次比较，每次比较是常数次整数运算。累加前 $N$ 个 $O(N)$。合计 $O(N\log N)$。空间：`pair<int,int>` 数组 $1.5\times10^6\times8$ B $=12$ MB，$O(N)$；排序递归栈 $O(\log N)$。证毕。

---

### 定理

程序输出的整数恰为"有用度和最大的 $N$ 头牛方案中的最小总重量" $\bmod M$。

*证明*：引理 1 保证每头牛的 $(U_i,W_i)$ 与题面公式逐位一致且不溢出；引理 2 钉死最大有用度和方案的结构；引理 3 在该结构内用交换论证确定最小重量构型；引理 4 证明双关键字排序取前缀恰好实现该构型；引理 5 保证累加与取模正确；引理 6 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — $i^5\approx7.6\times10^{30}$ 爆 `long long`，但公式外套 $\bmod$：每步乘法后立刻取模，中间量 $<10^{18}$ 恰好安全（模运算同态）。
2. **consider easier version** — 先扔掉第二目标：$\sum U$ 最大 = 取 $U$ 最大的 $N$ 头；上界逐项相加即证。
3. **explore its property** — 平局结构被钉死：$U>u^\*$ 全带、$U<u^\*$ 不带、恰好 $k$ 头 $U=u^\*$（两次交换论证）。
4. **reduce to easier problem** — 第二目标塌缩成"阈值组内挑最轻 $k$ 头"，再证"选重漏轻"必可交换改进。
5. **classic problem solution** — 双关键字排序 $(U\downarrow,W\uparrow)$ 取前 $N$，一次排序同时实现两级目标。
6. **discuss by category** — $i$ 从 $0$ 起（中文翻译误译）；$d,h=0$ 防御；$\sum W<5\times10^{14}$ 用 `long long` 加完再 $\bmod M$；排序关键字绝不取模。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 要选的头数 $N\le5\times10^5$，总牛数 $3N$ | `int` | 读入 |
| `a..h` | 生成多项式系数与模数，$\le10^9$ | `i64` | 读入；用 64 位防乘法溢出 |
| `M` | 答案模数，$10^7\le M\le10^9$ | `i64` | 读入 |
| `cow[i]` | 第 $i$ 头牛的 `{U,W}` | `pair<int,int>[mxn]` | $U<h\le10^9$、$W<d\le10^9$，`int` 装得下 |
| `mxn` | $3\times5\times10^5+5=1500005$ | `constexpr int` | 数组尺寸 |
| `t,t2,t3,t5` | $i\bmod m$ 的 $1,2,3,5$ 次幂（逐步取模） | `i64` | 每头牛现算；乘积 $<10^{18}$ |
| `ans` | 前 $N$ 头的重量和 | `i64` | $<5\times10^{14}$；输出 `ans%M` |

### 算法步骤

1. I/O 加速三行；读入 $N,a,b,c,d,e,f,g,h,M$。
2. 对 $i=0\dots3N-1$：若 $d>0$，算 $t=i\bmod d,\ t_2=t^2\bmod d,\ t_5=t_2\cdot t\bmod d\cdot t_2\bmod d$，$W=(a t_5+b t_2+c)\bmod d$；若 $h>0$，算 $t,t_2,t_3,t_5$（模 $h$），$U=(e t_5+f t_3+g)\bmod h$；存 `cow[i]={U,W}`。
3. `sort`：$U$ 降序，$U$ 相同 $W$ 升序。
4. `ans` = 前 $N$ 个 `cow[i].second` 之和（`i64`）。
5. 输出 `ans%M`。

### 复杂度

- 时间 $O(N\log N)$：生成 $O(N)$ + 排序 $O(3N\log 3N)\approx3\times10^7$ 次比较 + 求和 $O(N)$。
- 空间 $O(N)$：$1.5\times10^6$ 个 `pair<int,int>` 约 $12$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Hint 反推样例输出 $51$；全平局（$0$/$1$）、阈值平局（$10$）、取模回绕（$39$）、大系数溢出探针（$6$）四组手算一致；$N=5\times10^5$ 极限数据正常运行。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2965 [USACO09NOV] The Grand Farm-off S
// 按 (U 降序, W 升序) 排序取前 N：先最大化有用度之和，再最小化体重和
// i^5 最大约 7.6e30，必须逐步取模；每步乘积 < 1e18，i64 恰好装得下
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1500005};

int n;
i64 a,b,c,d,e,f,g,h,M;
pair<int,int>cow[mxn];	// {U,W}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>a>>b>>c>>d>>e>>f>>g>>h>>M;
	for(int i=0;i<3*n;++i)
	{
		i64 w=0,u=0;
		if(d)	// 题面 1<=W<=d 隐含 d>=1；d=0 时按 0 处理以防除零
		{
			i64 t=i%d,t2=t*t%d,t5=t2*t%d*t2%d;
			w=(a*t5+b*t2+c)%d;
		}
		if(h)
		{
			i64 t=i%h,t2=t*t%h,t3=t2*t%h,t5=t3*t2%h;
			u=(e*t5+f*t3+g)%h;
		}
		cow[i]={u,w};
	}
	sort(cow,cow+3*n,[](auto x,auto y){return x.first!=y.first?x.first>y.first:x.second<y.second;});
	i64 ans=0;
	for(int i=0;i<n;++i)
		ans+=cow[i].second;	// 和 < 5e5*1e9 = 5e14，i64 安全
	cout<<ans%M<<'\n';
	return 0;
}
```

### 代码说明

- **逐步取模是生死线**：`t5=t2*t%d*t2%d` 按左结合展开为 `((t2*t)%d*t2)%d`，即 $i^5=(i^2\cdot i)\cdot i^2$ 每步都压回 $<d$。任何"先算 $i^5$ 再取模"的写法在 $i\approx10^6$ 时必然溢出。
- **系数用 `i64` 读入**：`a*t5` 可达 $10^{18}$，若系数是 `int` 则乘法在 32 位里进行，直接错。`t,t2` 等中间量也全是 `i64`。
- `cow[i]={u,w}`：`u,w` 已 $<10^9$，收窄到 `int` 无损；排序搬运 8 字节对比搬 16 字节快。
- 比较器先比 `first`（$U$）降序、再比 `second`（$W$）升序，是严格弱序；**不要**把两个关键字压成一个整数（$U,W$ 各需 30 位，压不进 64 位还易错）。
- `ans` 加完再 `%M`：和 $<5\times10^{14}$ 不需要中途取模；取模只作用于答案，绝不作用于排序关键字。
- `if(d)/if(h)` 是对"$0\le d,h$"系数范围的防御（题面语义隐含 $d,h\ge1$）；$M\ge10^7$ 保证最后取模合法。
