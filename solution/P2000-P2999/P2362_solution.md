# P2362 围栏木桩 — 题解

## 一、解题过程：人类思考叙事

**重述题意。** 有 $m$ 组询问（$m\le5$），每组给 $n$ 根木桩的高度 $h_1..h_n$（$n\le20$，$h_i\le150$）。要选出一个下标集合 $i_1<i_2<\dots<i_t$，使得 $h_{i_1}\le h_{i_2}\le\dots\le h_{i_t}$（题面原话是"任何一个数都不小于它之前的任何一个数"，所以是**不下降**，相等的元素可以连选）。求最大的 $t$，以及达到 $t$ 的**下标集合的方案数** $c$。每组输出一行。

**第一步：看清"升序"的含义。** 这是第一个容易翻车的地方。如果按"严格递增"做，样例自测就会错：$n=3,h=(1,1,1)$ 应该能选出 $3$ 根（$t=3,c=1$），严格递增只能选出 $1$ 根。题面括号里那句"不小于它之前的任何一个数"已经把定义钉死成 $\le$，所以转移条件是 $h_j\le h_i$。

**第二步：先想暴力。** $n\le20$，直接枚举 $2^n$ 个子集，检查是否不下降，统计最长者与个数。$2^{20}\times20\times5\approx10^8$，卡常能过但很勉强；而且这题的标签是 DP，说明存在更稳的做法。不过这个暴力非常有价值——它天然是"按下标集合计数"的直译，可以用来检查 DP 的计数有没有算重、算漏。

**第三步：DP 求长度。** 最长不下降子序列（LNDS）是经典 DP：设 $f_i$ 为**以第 $i$ 根结尾**的最长不下降子序列长度，则
$$f_i=1+\max\{f_j: j<i,\ h_j\le h_i\},$$
空集时 $f_i=1$（只选它自己）。答案 $t=\max_i f_i$。$O(n^2)$，$n=20$ 完全够。

**第四步：把"方案数"塞进同一个 DP。** 设 $cnt_i$ 为"以 $i$ 结尾、长度为 $f_i$ 的不下降子序列个数"。一开始我很自然地写

$$cnt_i=\sum_{j<i,\ h_j\le h_i,\ f_j\le f_i-1} cnt_j,$$

结果在一个小数据上就爆了：$h=(1,2,1,2)$ 时 $f=(1,2,2,3)$，$i=4$ 把 $j=1$（长度 $1$）也加了进去，可"以 $1$ 结尾、长度 $1$"的序列接上 $h_4$ 只得到长度 $2$，根本不是最长的那批 $3$，却被算成了方案。所以求和时必须**只累加 $f_j=f_i-1$ 的那些 $j$**。

**第五步：$cnt_i$ 的初值要不要算"只选自己"。** 如果 $f_i=1$，那么"只选 $i$"确实是长度 $f_i$ 的合法方案，$cnt_i=1$。如果 $f_i>1$，那么"只选 $i$"长度不足 $f_i$，不该算。写成"先令 $cnt_i=1$，然后一旦有 $j$ 给出 $f_j+1>f_i$ 就整体覆盖成 $cnt_j$"正好能自动处理：因为 $f_j+1\ge2>1$，第一次覆盖必然把初值 $1$ 冲掉；如果从头到尾没有合法 $j$，$f_i$ 保持 $1$、$cnt_i$ 保持 $1$，也对。

**第六步：合并答案。** $c=\sum_{f_i=t}cnt_i$。为什么这样不会重复？因为每一棵被选中的木桩（一个下标集合）都有**唯一的最后一个下标**，按"结尾位置"分类是一个划分，不同 $i$ 的方案互不相同。

**自造数据检验（题面无样例）。**

| 输入 | 期望 | 说明 |
| --- | --- | --- |
| `4 1 2 1 2` | `3 2` | `1,1,2`（下标 1,3,4）与 `1,2,2`（下标 1,2,4） |
| `3 1 1 1` | `3 1` | 全相等，只能全选 |
| `3 3 1 2` | `2 1` | 只有 `1,2` 一种 |

三组都对。再把 $2^n$ 枚举暴力当基准，在 $300$ 组随机小数据（$n\le12$，$h\le5$，故意让高度大量重复）和 $20$ 组 $n=20$、$h\le3$ 的极限数据上对拍，输出逐字节一致。

## 二、思维链：完整证明

约定：一个"方案"是一个下标集合 $S=\{i_1<\dots<i_t\}$ 且 $h_{i_1}\le\dots\le h_{i_t}$；其"末尾下标"是 $\max S$。

### 引理 1：$f_i$ 的递推正确

**引理 1**：设 $f_i$ 为以 $i$ 结尾的最长不下降子序列长度，则
$$f_i=\max\Bigl(1,\ \max_{j<i,\ h_j\le h_i}\bigl(f_j+1\bigr)\Bigr).$$

*证明*：分两个方向。

（$\ge$）若存在 $j<i$ 且 $h_j\le h_i$，取以 $j$ 结尾的长度 $f_j$ 的不下降序列，接上 $h_i$：下标仍递增、末尾 $h_j\le h_i$，故合法，长度 $f_j+1$，所以 $f_i\ge f_j+1$。另外单元素集合 $\{i\}$ 恒合法，故 $f_i\ge1$。

（$\le$）取以 $i$ 结尾的最长不下降序列 $S$，长度 $f_i$。若 $|S|=1$，则 $f_i=1$ 已被右端覆盖。否则设 $S$ 去掉 $i$ 后的末尾为 $j$：由下标递增 $j<i$；由不下降 $h_j\le h_i$；由定义 $f_j\ge |S|-1=f_i-1$，即 $f_i\le f_j+1$，被右端覆盖。

两侧合并即得等号。证毕。

**推论 1′**：$t=\max_i f_i$ 就是所求最长长度。

*证明*：任一不下降方案 $S$ 满足 $|S|\le f_{\max S}\le t$；另一方面取 $i^*$ 使 $f_{i^*}=t$，对应的方案长度就是 $t$。故最大值为 $t$。证毕。

### 引理 2：$cnt_i$ 的递推正确（计数的核心）

**引理 2**：设
$$\mathcal F_i=\{S:\ \max S=i,\ |S|=f_i,\ S\ \text{不下降}\},\qquad cnt_i=|\mathcal F_i|.$$
则
$$cnt_i=\begin{cases}1,& f_i=1,\\[2pt] \displaystyle\sum_{\substack{j<i\\ h_j\le h_i\\ f_j=f_i-1}} cnt_j,& f_i>1.\end{cases}$$

*证明*：

**情形 $f_i=1$。** 由引理 1，不存在 $j<i$ 使 $h_j\le h_i$（否则 $f_i\ge f_j+1\ge2$）。故任何以 $i$ 结尾的不下降方案只能是 $\{i\}$，$\mathcal F_i=\{\{i\}\}$，$cnt_i=1$。

**情形 $f_i>1$。** 构造映射
$$\varphi:\ \mathcal F_i\longrightarrow \bigcup_{j}\mathcal F_j,\qquad S\mapsto S\setminus\{i\},$$
这里并集取遍满足 $j<i,\ h_j\le h_i$ 的 $j$。注意 $f_i>1$ 保证 $|S|\ge2$（因为 $|S|=f_i\ge2$），所以 $S\setminus\{i\}\ne\varnothing$，有末尾下标 $j$。

- *$\varphi$ 的像落在 $\mathcal F_j$ 里且 $f_j=f_i-1$*：$S\setminus\{i\}$ 是以 $j$ 结尾的不下降方案，长度 $f_i-1$，故 $f_j\ge f_i-1$；另一方面由引理 1，$f_i\ge f_j+1$，即 $f_j\le f_i-1$。故 $f_j=f_i-1$，且 $S\setminus\{i\}\in\mathcal F_j$（它是"以 $j$ 结尾且长度恰为 $f_j$"的方案）。
- *$\varphi$ 是单射*：$S=\varphi(S)\cup\{i\}$，由像可还原原像。
- *$\varphi$ 是满射（到这些 $\mathcal F_j$ 的并）*：任取 $j<i,\ h_j\le h_i,\ f_j=f_i-1$ 与 $S'\in\mathcal F_j$，令 $S=S'\cup\{i\}$：下标递增、末尾关系 $h_j\le h_i$ 保证不下降，长度 $f_j+1=f_i$，末尾下标为 $i$，故 $S\in\mathcal F_i$，且 $\varphi(S)=S'$。

所以 $\varphi$ 是 $\mathcal F_i$ 与 $\bigcup_j \mathcal F_j$ 之间的双射。又不同的 $j$ 对应不同的末尾下标，故 $\mathcal F_j$ 两两不交，并集大小 $=\sum_j|\mathcal F_j|=\sum_j cnt_j$。于是 $cnt_i=\sum_{j}cnt_j$，即所求递推。证毕。

> 反过来看第四步那个错误式子：它把 $f_j<f_i-1$ 的 $\mathcal F_j$ 也算进来了，此时 $S'\cup\{i\}$ 的长度是 $f_j+1<f_i$，不属于 $\mathcal F_i$，于是 $\varphi$ 的单射/满射论证在那一侧断裂——这就是"算重/算错"的根源。

### 引理 3：合并答案不重不漏

**引理 3**：$c=\sum_{i:\,f_i=t}cnt_i$ 恰为"长度为 $t$ 的不下降方案总数"。

*证明*：令 $\mathcal A=\{S: |S|=t,\ S\ \text{不下降}\}$。对每个 $S\in\mathcal A$，设其末尾下标为 $i$。由引理 1 的推论 $|S|\le f_i\le t$，故 $f_i=t$ 且 $|S|=f_i$，即 $S\in\mathcal F_i$。反之 $\mathcal F_i\subseteq\mathcal A$（长度 $f_i=t$、合法）。故
$$\mathcal A=\bigcup_{i:\,f_i=t}\mathcal F_i .$$
每个方案只有一个末尾下标，故各 $\mathcal F_i$ 互不相交（$i\ne i'$ 时 $\max S=i\ne i'=\max S'$）。因此 $|\mathcal A|=\sum_{f_i=t}|\mathcal F_i|=\sum_{f_i=t}cnt_i$。证毕。

### 引理 4：复杂度与数值范围

**引理 4**：单组询问时间 $O(n^2)$、空间 $O(n)$；$c$ 不超过 $\binom{20}{10}=184756<2^{31}$，用 `int` 不会溢出。

*证明*：两重循环 $i<j$，每对做 $O(1)$ 次比较与加法。方案数是 $n$ 个元素的下标子集个数，最多 $2^n$，但"长度恰为最长"的方案数不超过 $\binom{n}{\lfloor n/2\rfloor}$（所有 $\lfloor n/2\rfloor$ 元子集都比它多），$n=20$ 时为 $184756$。证毕。

**定理**：程序对每组询问输出的 $(t,c)$ 正确。

*证明*：$t$ 由引理 1 与推论 1′ 正确；$cnt_i$ 由引理 2 正确（双射计数，不重不漏）；合并由引理 3 正确；数值范围由引理 4 保证。每次询问前 `f,cnt` 都按 $i$ 顺序重新赋值（`f[i]=1;cnt[i]=1` 起手），故多组询问之间不会串数据。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "升序"被题面定义成"不小于之前的任何一个数"，即**不下降**，相等可连选。
2. **consider easier version** — 先写 $2^n$ 枚举子集的暴力：它直译"按下标集合计数"，可当计数正确性的基准。
3. **classic problem solution** — 最长不下降子序列的 $O(n^2)$ DP：$f_i$ 表示以 $i$ 结尾的最长长度。
4. **explore its property** — 方案数必须**按末尾下标分类**：每个下标集合有唯一末尾，这是不重不漏的关键。
5. **classic problem solution** — 在长度 DP 上并列挂一个计数 DP：$cnt_i$ 只累加 $f_j=f_i-1$ 的 $j$（用双射证明），并用 $cnt_i$ 的初值 $1$ 处理"只选自己"。
6. **discuss by category** — 答案合并：$t=\max f_i$，$c=\sum_{f_i=t}cnt_i$，各 $\mathcal F_i$ 互不相交。
7. **check the bound** — $n\le20$ 时方案数 $\le\binom{20}{10}$，`int` 够用，不必开 `long long`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 初值 / 记忆点 |
| --- | --- | --- |
| $m$ | 询问组数 | 读入，$\le5$ |
| $n$ | 本组木桩数 | 读入，$\le20$ |
| $h_i$ | 第 $i$ 根木桩高度（$0$ 基） | 读入，$\le150$ |
| $f_i$ | 以 $i$ 结尾的最长不下降子序列长度 | 每轮置 $1$ 再更新 |
| $cnt_i$ | 以 $i$ 结尾且长度恰为 $f_i$ 的方案数 | 每轮置 $1$ 再更新 |
| $t$ | 全局最长长度 $\max f_i$ | 初值 $0$ |
| $c$ | 长度 $t$ 的方案总数 | 初值 $0$ |

### 算法步骤

1. 读 $m$；循环 $m$ 次，每次读 $n$ 与 $h_0..h_{n-1}$。
2. 对 $i=0..n-1$：令 `f[i]=1, cnt[i]=1`；对 $j=0..i-1$，若 $h_j\le h_i$：
   - 若 `f[j]+1 > f[i]`：`f[i]=f[j]+1; cnt[i]=cnt[j]`（覆盖初值）；
   - 否则若 `f[j]+1 == f[i]`：`cnt[i]+=cnt[j]`。
3. 扫一遍 $i$：若 `f[i]>t` 则 `t=f[i]; c=cnt[i]`；否则若 `f[i]==t` 则 `c+=cnt[i]`。
4. 输出 `t c`（空格分隔），换行；处理下一组。

### 复杂度

- 时间 $O(mn^2)\le5\times400$，空间 $O(n)$。

### 验证状态

- `g++ -std=c++20 -O2` 编译通过。
- 题面无样例，自造三组（`3 2`、`3 1`、`2 1`）全部吻合，其中含"全相等"和"严格递减"两个边界。
- 与 $2^n$ 枚举子集的暴力对拍：$300$ 组随机小数据（$n\le12$，$h\le5$）+ $20$ 组 $n=20,h\le3$ 的极限数据，输出逐字节一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2362 围栏木桩
// 最长不下降子序列长度 + 方案数, 按「以 i 结尾」分类计数
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};

int m,n,h[mxn],f[mxn],cnt[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m;
	while(m--)
	{
		cin>>n;
		for(int i=0;i<n;++i)
			cin>>h[i];
		for(int i=0;i<n;++i)
		{
			f[i]=1;cnt[i]=1;   // 只取自己
			for(int j=0;j<i;++j)
				if(h[j]<=h[i])
				{
					if(f[j]+1>f[i])
					{
						f[i]=f[j]+1;   // 变长, 方案数整体覆盖
						cnt[i]=cnt[j];
					}
					else if(f[j]+1==f[i])
						cnt[i]+=cnt[j];   // 并列最长, 累加
				}
		}
		int t=0,c=0;
		for(int i=0;i<n;++i)
			if(f[i]>t)
			{
				t=f[i];
				c=cnt[i];
			}
			else if(f[i]==t)
				c+=cnt[i];
		cout<<t<<' '<<c<<'\n';
	}
	return 0;
}
```

### 代码说明

- 转移用 `h[j]<=h[i]`（不是 `<`）：题面的"升序"定义为不下降。
- `cnt[i]=cnt[j]` 用**赋值**而非 `+=`：`f[j]+1>f[i]` 意味着之前那些较短的方案全部作废，这也顺带把初值 `1` 冲掉。
- 合并答案时也必须"先覆盖再累加"，与 $cnt$ 的语义保持一致。
- 每组询问都重新给 `f[i],cnt[i]` 赋初值，不依赖上一组的数据（多组之间无需整段 `memset`）。
- 输出两个数用空格分隔、`'\n'` 换行。
