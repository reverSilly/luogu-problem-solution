# P2913 [USACO08OCT] Wheel Rotation G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离收割机背景）。** 有 $N$ 个滑轮（$2\le N\le 1000$）和 $N-1$ 条皮带。按题面描述，皮带把滑轮串成一条驱动链：滑轮 1 驱动滑轮 2，滑轮 2 驱动滑轮 3，……直到滑轮 $N$。每条皮带用三个整数给出：驱动轮 $S_i$、被驱动轮 $D_i$、连接类型 $C_i$（$0$=直连，两轮转向**相同**；$1$=交叉，两轮转向**相反**）。已知滑轮 1 顺时针转。输入中皮带的**行序是乱的**。求滑轮 $N$ 的转向，输出 $0$（顺时针）或 $1$（逆时针）。

约束与边界：

- $N\le 1000$，规模极小，任何 $O(N)$ 甚至 $O(N^2)$ 的做法都绰绰有余；难点不在复杂度，而在**"乱序"导致不能按读入顺序递推**。
- $N=2$ 是最小规模：只有一条皮带，答案就是 $C_1$。
- 转向只有两种，且"相同/相反"关系是**对称**的（直连的两轮无论谁驱动谁，转向都相同；交叉则都相反），所以皮带可以当无向边处理。
- 口径说明：题面说链是 $1\to 2\to\cdots\to N$，但输入显式给出了每条边的 $S_i,D_i$，**不保证** $S_i=i,D_i=i+1$，也不保证行序。我按"显式建图、从滑轮 1 出发传播"实现，这对任何连通的 $N-1$ 边结构（树）都正确，链只是它的特例。输出编码 $0$=顺时针、$1$=逆时针，恰好与"从 $0$ 出发做 XOR"天然一致。

**手造极简数据核对**（题面只有图示说明，没有样例输入输出，我按规则自造）：

第一组，$N=4$，链 $1\xrightarrow{0}2\xrightarrow{0}3\xrightarrow{1}4$，故意乱序输入：

```
输入：
4
3 4 1
1 2 0
2 3 0

输出：
1
```

手算：滑轮 1 顺（0）→ 直连 → 滑轮 2 顺（0）→ 直连 → 滑轮 3 顺（0）→ 交叉 → 滑轮 4 逆（1）。与题面图示说明"pulley 4 rotates counterclockwise"一致。

第二组，$N=3$，两次交叉互相抵消：

```
输入：
3
2 3 1
1 2 1

输出：
0
```

手算：$0\oplus 1\oplus 1=0$，滑轮 3 顺时针。这组专门检验"交叉次数看**奇偶**而不是条数"。

第三组，最小规模 $N=2$：输入 `2` 和 `1 2 0`，输出 `0`。

## 二、思维链：完整证明

**记号。** 滑轮内部编号 $0..N-1$（读入后 `--s;--d`）。$\mathrm{dir}[v]\in\{0,1\}$ 表示滑轮 $v$ 的转向（$0$ 顺、$1$ 逆）。皮带 $(s,d,c)$ 表示 $s$ 与 $d$ 之间一条类型为 $c$ 的边。

### 第一步：把"转向"压成一个比特——explore its property

转向只有顺/逆两种，天然适合 $0/1$ 编码。再看两种皮带的物理规则：

- 直连（$c=0$）：$\mathrm{dir}[d]=\mathrm{dir}[s]$；
- 交叉（$c=1$）：$\mathrm{dir}[d]=1-\mathrm{dir}[s]$。

两条规则可以**合并成一个式子**：$\mathrm{dir}[d]=\mathrm{dir}[s]\oplus c$。这就是本题的全部物理内容。

**引理 1（XOR 传播律）。** 对任意皮带 $(s,d,c)$，若 $\mathrm{dir}[s]$ 已知，则 $\mathrm{dir}[d]=\mathrm{dir}[s]\oplus c$；且该关系对称，$\mathrm{dir}[s]=\mathrm{dir}[d]\oplus c$ 也成立。

*证明*：穷举全部四种组合。$(\mathrm{dir}[s],c)=(0,0)$：直连同向，$\mathrm{dir}[d]=0=0\oplus 0$ ✓；$(1,0)$：$\mathrm{dir}[d]=1=1\oplus 0$ ✓；$(0,1)$：交叉反向，$\mathrm{dir}[d]=1=0\oplus 1$ ✓；$(1,1)$：$\mathrm{dir}[d]=0=1\oplus 1$ ✓。对称性：XOR 满足 $(x\oplus c)\oplus c=x$（$c\oplus c=0$，逐位验证 $0\oplus0=0,1\oplus1=0$），故从 $d$ 反推 $s$ 用同一式子。这也说明"谁驱动谁"不影响转向关系，建**无向边**合法。证毕。

### 第二步：按输入顺序递推为什么不行——碰壁与反例

最省事的写法是边读边算：`dir[d]=dir[s]^c`。但行序是乱的。**反例**就是第一部分的第一组数据：第一条读入的是 `3 4 1`，此时 $\mathrm{dir}[3]$ 还根本不知道（滑轮 3 的驱动边 `2 3 0` 排在第三行）。若用全局数组默认的 $0$ 当"未知"，会算出 $\mathrm{dir}[4]=0\oplus1=1$——这组碰巧对，但把第二行改成 `1 2 1`（滑轮 2 逆时针），正确答案仍是 $1\oplus0\oplus1=0$，而乱序递推给出 $\mathrm{dir}[4]=1$，**错了**。

失败的根源：**递推必须沿着"已知 → 未知"的方向进行**，而输入顺序不保证这个方向。修正方式：先把所有边存下来，再从唯一已知的滑轮 1 出发，沿边传播。

### 第三步：传播会不会"打架"？——图结构保证良定义

从滑轮 1 出发传播时，一个自然的担心：如果某个滑轮能从两条不同路径到达，两条路径算出的转向不一致怎么办？

**引理 2（驱动图是树，路径唯一）。** $N$ 个滑轮、$N-1$ 条皮带、且按题面构成从 1 到 $N$ 的驱动链（连通），则该图是树；树中任意两点间路径唯一。

*证明*：先证"连通 + $N-1$ 边 ⇒ 无环"。反证：若有环，取环上一条边 $e$ 删去，图仍连通（环上两点可绕环的另一侧互达，其余点对的最短路若经过 $e$ 也可改绕环），于是得到 $N$ 点 $N-2$ 边的连通图。但任何 $N$ 点连通图至少含一棵生成树，生成树恰有 $N-1$ 条边（树边数公式：对 $N$ 归纳，叶子删去后 $N-1$ 点 $N-2$ 边），故连通图边数 $\ge N-1>N-2$，矛盾。所以原图无环，连通无环图即树。

再证路径唯一：若 $u,v$ 间有两条不同的简单路径 $P_1\ne P_2$，从 $u$ 出发沿两条路径走，设第一个分岔点为 $a$、之后第一个重新汇合的点为 $b$（$v$ 本身就是一个汇合点，故 $b$ 存在），则 $P_1,P_2$ 上 $a\to b$ 的两段内部不相交，拼起来是一个环，与无环矛盾。证毕。

**推论**：滑轮 1 到滑轮 $N$ 的路径唯一，沿途 XOR 的结果**良定义**，不存在"打架"。

### 第四步：答案就是路径上交叉次数的奇偶——reduce to easier problem

**引理 3（答案 = 路径 XOR）。** 设滑轮 $0$ 到滑轮 $N-1$ 的唯一路径为 $0=v_0,v_1,\dots,v_k=N-1$，边类型依次为 $c_1,\dots,c_k$。则 $\mathrm{dir}[N-1]=\bigoplus_{t=1}^{k}c_t$，即**交叉皮带条数的奇偶性**（奇数条交叉 → 逆时针 1，偶数条 → 顺时针 0）。

*证明*：对路径长度 $k$ 归纳。$k=0$（$N=1$，本题 $N\ge2$ 不出现，但作为归纳基显然）：$\mathrm{dir}[0]=0$，空 XOR 为 $0$ ✓。设长度 $k-1$ 成立，即 $\mathrm{dir}[v_{k-1}]=\bigoplus_{t=1}^{k-1}c_t$。由引理 1，$\mathrm{dir}[v_k]=\mathrm{dir}[v_{k-1}]\oplus c_k=\bigoplus_{t=1}^{k}c_t$ ✓。又 $\bigoplus c_t$ 中每个 $c_t\in\{0,1\}$，XOR 就是模 2 加法，故结果 $=\big(\sum c_t\big)\bmod 2$，即交叉条数的奇偶。证毕。

到这一步，题目已经归约成"求树上两点路径的边权 XOR"。但 $N\le1000$，根本不需要 LCA/倍增——**一次 BFS 顺便把每个点的 dir 算出来**即可。

### 第五步：BFS 传播的正确性——classic problem solution

**引理 4（BFS 不变量）。** 以 $\mathrm{dir}[0]=0$ 为源做 BFS，规则是"取出 $u$，对每条边 $(u,v,c)$，若 $v$ 未访问则置 $\mathrm{dir}[v]=\mathrm{dir}[u]\oplus c$ 并入队"。则算法结束时，每个点 $v$ 的 $\mathrm{dir}[v]$ 恰等于引理 3 中路径 XOR 的值；特别地 $\mathrm{dir}[N-1]$ 就是答案。

*证明*：对 BFS 的访问顺序归纳，证明不变量"$v$ 被赋值时，$\mathrm{dir}[v]=\bigoplus(\text{树上 }0\to v\text{ 路径的边类型})$"。

源点：$\mathrm{dir}[0]=0$，空路径 XOR 为 $0$ ✓。

设 $v$ 经由边 $(u,v,c)$ 首次被赋值，且 $u$ 满足不变量。树上 $0\to v$ 的唯一路径必以 $v$ 的唯一"父方向"邻居结尾；而 BFS 中 $u$ 是 $v$ 的赋值者。关键：树上 $0\to u$ 的路径加上边 $(u,v)$ 是否就是 $0\to v$ 的路径？由于树无环，$0\to u$ 路径不可能经过 $v$（否则 $v$ 会比 $u$ 先被访问——BFS 沿边逐层扩展，$v$ 在 $u$ 之前出现在某条更短路径上就会先被赋值，与"$v$ 经由 $u$ **首次**赋值"矛盾），故拼接后仍是一条简单路径，由引理 2 的唯一性它就是树上 $0\to v$ 路径。于是 $\mathrm{dir}[v]=\mathrm{dir}[u]\oplus c=\bigoplus(0\to u)\oplus c=\bigoplus(0\to v)$ ✓。

连通性保证所有点都会被访问（BFS 标准性质：源点所在连通分量内每点必入队），故 $\mathrm{dir}[N-1]$ 有定义且正确。证毕。

**实现陷阱（必须显式处理）**：全局 `int dir[]` 默认是 $0$，而 $0$ 是**合法方向**（顺时针）！若拿"$\mathrm{dir}[v]==0$"当"未访问"，会把所有未访问点误判成已访问，BFS 只走源点一步就停。所以必须 `fill_n(dir,n,inf)`（`inf=1145141919`，一个不可能是 $0/1$ 的哨兵），用 `dir[v]==inf` 判未访问。另外 XOR 只对**已赋值**的点做（`dir[u]` 出队时必已赋值），哨兵本身永远不会参与 XOR 运算。

**引理 5（复杂度）。** 时间 $O(N)$，空间 $O(N)$。

*证明*：建图读入 $N-1$ 条边、每条push两次，$O(N)$。BFS 每点入队出队各一次，每条无向边被两个端点各扫一次，共 $2(N-1)$ 次邻接访问，$O(N)$。邻接表存 $2(N-1)$ 个 `{邻居,类型}` 对，`dir` 长 $N$，队列至多 $N$ 个元素，空间 $O(N)$。$N\le1000$，远低于任何时限。证毕。

### 定理

程序输出滑轮 $N$ 的转向编码（$0$ 顺、$1$ 逆），等于驱动链上交叉皮带条数模 2。

*证明*：引理 1 把物理规则翻译成 XOR 传播；引理 2 保证驱动图是树、路径唯一，传播良定义；引理 3 给出答案的路径 XOR 刻画；引理 4 保证 BFS 恰好算出每个点的路径 XOR；引理 5 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 转向只有两种 ⇒ 0/1 编码；直连/交叉两条物理规则合并成一条 $\mathrm{dir}[d]=\mathrm{dir}[s]\oplus c$，且关系对称可建无向边。
2. **consider easier version** — 若皮带按驱动顺序给出，边读边递推即可；乱序打破"已知→未知"方向，构造反例确认必须存图后从源传播。
3. **explore its property** — $N$ 点 $N-1$ 边连通 ⇒ 树 ⇒ 路径唯一 ⇒ 沿途 XOR 良定义，不会"打架"。
4. **reduce to easier problem** — 答案 = 树上 $1\to N$ 路径边权 XOR = 交叉条数的奇偶。
5. **classic problem solution** — 从源点 BFS，`dir[v]=dir[u]^c` 一次传播所有点，$O(N)$。
6. **discuss by category** — 全局数组默认 0 是合法方向，未访问必须显式 fill 成 inf 哨兵；读入 `--s;--d` 转 0-based。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N$ | 滑轮数，$2\le N\le1000$ | `int n` | 读入 |
| `mxn` | $1000+5$ | `constexpr int` | 数组尺寸 |
| `inf` | 未访问哨兵 $1145141919$ | `constexpr int` | 不可能是 0/1，专用于"未定义" |
| `graph[u]` | $u$ 的邻接表，元素 `{v,c}`：邻居与连接类型 | `vector<pair<int,int>>[mxn]` | 无向，每条皮带 push 两次 |
| `dir[v]` | 滑轮 $v$ 的转向（0 顺 1 逆），未访问为 `inf` | `int[mxn]` | **必须 `fill_n(dir,n,inf)`**，再置 `dir[0]=0` |
| `Q` | BFS 队列 | `queue<int>` | 初始只含源点 0 |
| `s,d,c` | 一条皮带的驱动轮、被驱动轮、类型 | `int` | 读入后 `--s;--d` |

### 算法步骤

1. I/O 加速三行；读 $N$。
2. `fill_n(dir,n,inf)`；读 $N-1$ 条皮带，`--s;--d`，双向加入 `graph`。
3. `dir[0]=0`，源点入队。
4. BFS：取出 $u$，对每条 `{v,c}`，若 `dir[v]==inf` 则 `dir[v]=dir[u]^c` 并入队。
5. 输出 `dir[n-1]`。

### 复杂度

- 时间 $O(N)$；空间 $O(N)$。$N\le1000$，瞬间完成。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；三组手造数据（乱序四滑轮链、双交叉抵消、$N=2$ 最小规模）输出与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2913 [USACO08OCT] Wheel Rotation G
// 转向 0/1 编码：直连 XOR 0，交叉 XOR 1 ⇒ dir[v]=dir[u]^c。
// N 点 N-1 边连通 ⇒ 树，路径唯一 ⇒ 从滑轮 1 BFS 传播即可。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},inf{1145141919};

int n,dir[mxn];
vector<pair<int,int>>graph[mxn];	// {邻居,连接类型}，无向

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	fill_n(dir,n,inf);	// 全局默认 0 是合法方向！未访问必须显式置 inf
	for(int i=1,s,d,c;i<n;++i)
	{
		cin>>s>>d>>c;--s;--d;
		graph[s].push_back({d,c});
		graph[d].push_back({s,c});
	}
	queue<int>Q;
	dir[0]=0;Q.push(0);	// 滑轮 1 顺时针
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		for(auto[v,c]:graph[u])
			if(dir[v]==inf)
			{
				dir[v]=dir[u]^c;
				Q.push(v);
			}
	}
	cout<<dir[n-1]<<'\n';
	return 0;
}
```

### 代码说明

- `dir` 的初始化是本题**唯一容易静默出错**的地方：$0$ 既是"顺时针"又是全局默认值，不 fill 成 `inf` 就无法区分"未访问"与"顺时针"，BFS 会寸步难行。
- 皮带建无向边：引理 1 证明转向关系对称，"谁驱动谁"不影响结果，乱序输入因此完全无害。
- `dir[v]=dir[u]^c` 一行就是全部物理；答案 `dir[n-1]` 自动等于链上交叉次数的奇偶。
- 内部 0-based：读入 `--s;--d`，输出用 `dir[n-1]`（第 $N$ 个滑轮）。
