# P2381 圆圆舞蹈 — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 只奶牛围成一圈（$2\le n\le10^5$），给出相邻两只之间的顺时针距离 $d_1,\dots,d_n$（$d_i\ge1$，且 $d_n$ 是第 $n$ 只回到第 $1$ 只的距离），所有 $d_i$ 之和 $S\le2^{31}-1$。两只奶牛 $A,B$ 之间的距离定义为"从 $A$ 顺时针走到 $B$"与"逆时针走到 $B$"两条路里较短的那条。求所有奶牛对中最大的这个距离。

**先想最笨的。** 把圈从第 $1$ 只奶牛处剪开摊直，做前缀和 $P_0=0,\ P_k=\sum_{i\le k}d_i$（$P_n=S$）。对任意一对 $i<j$，顺时针弧长是 $P_j-P_i$，另一条路是 $S-(P_j-P_i)$，两者取小。枚举所有 $n(n-1)/2$ 对，$O(n^2)$。$n=10^5$ 时是 $5\times10^9$ 次运算，必死。要 $O(n)$ 或 $O(n\log n)$。

**关键性质：把"距离"看成一个关于弧长的函数。** 记弧长 $A$，则这一对奶牛的距离是
$$f(A)=\min(A,\ S-A).$$
这是一条"帐篷"曲线：$A$ 从 $0$ 涨到 $S/2$ 时 $f=A$ 线性上升，$A$ 从 $S/2$ 涨到 $S$ 时 $f=S-A$ 线性下降，峰值在 $A=S/2$（值 $S/2$）。于是"最大距离"这个问题变成：

> 在所有奶牛对里，找一对**弧长最接近半圈**的。

**固定起点再优化。** 对每个起点 $i$，让终点 $j$ 从 $i+1$ 走到 $i+n-1$（在"展开成两圈"的数组上，见下），弧长 $A(j)=P_j-P_i$ 随 $j$ **严格递增**（每个 $d_i\ge1$）。在递增序列上，帐篷函数 $f(A)$ 关于 $j$ 是**单峰**的：先增后减。单峰函数在整数点上的最大值只可能在峰的左右两个邻居处取到，也就是：

- 满足 $A(j)\le S/2$ 的**最后一个** $j$（记为 $j_0$）；
- $j_0+1$（第一个越过半圈的 $j$，若它还在合法范围内）。

**为什么会想到"展开成两圈"。** 从第 $i$ 只出发绕一圈，会依次经过 $i+1,i+2,\dots,i+n-1$（下标模 $n$）。若只用单圈下标，$i$ 后面的奶牛会"绕回开头"，处理起来全是取模。标准做法是把 $d$ 复制一份接在后面，前缀和数组开到 $2n$，这样 $[i,i+n-1]$ 就是一段普通区间，顺时针弧长始终是 $P_j-P_i$。每一对奶牛会在这段枚举里出现两次（正、反两个方向各一次），但两次算出的值都是 $f(A)$，对取最大值没有影响。

**第一次碰壁：漏掉"越过半圈"的那一侧。** 我最初只取"最大的不超过半圈的弧"，以为那就是最接近半圈的。反例：$d=[10,1,1]$，$S=12$，半圈是 $6$。从第 $1$ 只出发：到第 $2$ 只弧长 $10$（已越过 $6$），到第 $3$ 只弧长 $11$，都不满足"$\le6$"。若只认"$\le S/2$"，就一个候选也没有，直接崩。正确做法是承认峰可能落在区间外：此时最接近半圈的点就是**区间的第一个点** $j=i+1$，取 $S-A$。于是要给指针一个"虚拟起点" $j=i$（弧长 $0$，必然满足 $\le S/2$），再从它往后推，这样"$j_0$ 不存在"的情形自然退化成"$j_0=i$、候选是 $j_0+1=i+1$"。

**第二次优化：指针不用回退。** 对固定的 $j$，当起点 $i$ 变大时弧长 $P_j-P_i$ 变小（$P_i$ 变大）。所以"满足 $A\le S/2$ 的最大 $j$"随 $i$ 单调不减：$i$ 右移只会让更多 $j$ 变得合法。于是每个 $i$ 不必重新从 $i$ 找起，直接沿用上一轮的 $j$ 往后推即可，总推进次数 $O(n)$——双指针。

**边界与坑。**

- 合法的 $j$ 必须 $>i$（不能和自己配对）且 $\le i+n-1$（超过一整圈没有意义，因为再往后就是重复的方向）。
- 比较"弧长是否不超过半圈"时不要用浮点或除法：把不等式乘 $2$，写成 $2A\le S$，全是整数运算。
- $A$ 最大到 $S\le2^{31}-1$，$2A$ 会超 `int`，所以前缀和与答案都用 64 位。
- 答案最大是 $\lfloor S/2\rfloor$，用 64 位输出更省心。

**手造数据核对。**

| 输入 | 答案 | 说明 |
|------|------|------|
| $n=2,\ d=(3,4)$ | $3$ | 只有一对，$\min(3,4)=3$ |
| $n=3,\ d=(1,1,10)$ | $2$ | 第 1、3 只之间弧长 $2$ 与 $10$，取 $2$ |
| $n=4,\ d=(3,3,3,3)$ | $6$ | 正对面的两对，恰好半圈 |
| $n=3,\ d=(5,5,5)$ | $5$ | 任意一对弧长 $5$ 或 $10$，取 $5$ |
| $n=3,\ d=(10,1,1)$ | $2$ | 单步就超过半圈，走"虚拟起点"分支 |

## 二、思维链：完整证明

**记号。** 把 $d$ 复制一份接在后面，定义 $P_0=0$，$P_k=P_{k-1}+d_{(k-1)\bmod n}$（$1\le k\le2n$），于是 $P_{k+n}=P_k+S$。第 $i$ 只奶牛视为位置 $i$（$0\le i<n$），它在展开数组里也记为 $i+n$。窗口 $\mathcal W=\{(i,j):0\le i<n,\ i<j\le i+n-1\}$。

**引理 1（弧长公式）。** 对任意 $(i,j)\in\mathcal W$，从奶牛 $i$ 顺时针走到奶牛 $j$ 的路程为 $P_j-P_i$。

*证明：* 由 $P$ 的定义，$P_j-P_i=\sum_{k=i}^{j-1}d_{k\bmod n}$，而顺时针从 $i$ 出发依次经过的段正是 $d_{i\bmod n},d_{(i+1)\bmod n},\dots,d_{(j-1)\bmod n}$（下标不重复，因为 $j-i\le n-1$）。逐段相加即得。证毕。

**引理 2（距离公式）。** 设 $A=P_j-P_i$（$0<A<S$），则奶牛 $i$ 与奶牛 $j$ 的距离为 $f(A)=\min(A,S-A)$。

*证明：* 从 $i$ 到 $j$ 有且只有两条简单路径：顺时针一条，长 $A$（引理 1）；逆时针一条，等于整圈减去顺时针，长 $S-A$。题面定义距离为两者较短者。由 $0<A<S$（每个 $d\ge1$，且 $j\ne i$、$j-i\le n-1$ 保证既非空也非整圈），$S-A>0$。证毕。

**引理 3（窗口枚举恰好覆盖每对两次）。** 每个无序对 $\{u,v\}$（$0\le u<v<n$）在窗口 $\mathcal W$ 中恰出现两次，为 $(u,v)$ 与 $(v,u+n)$，且这两次的 $f$ 值相同。

*证明：* 分三步。

**第一步（这两个元素确实在窗口里）**：对 $(u,v)$：$0\le u<n$ ✓，$u<v$ ✓，$v\le n-1\le u+n-1$ ✓。对 $(v,u+n)$：$0\le v<n$ ✓，$v<u+n$ ✓，$u+n\le v+n-1$（因 $u\le v-1$）✓。

**第二步（没有第三个元素）**：设 $(i,j)\in\mathcal W$ 且 $\{i\bmod n,\ j\bmod n\}=\{u,v\}$。由窗口定义 $0\le i<n$、$i<j\le i+n-1<2n$，故 $j<2n$ 且 $j\ge1$。分两类：

- $j<n$：此时 $i,j\in[0,n)$ 且 $i\ne j$（否则模 $n$ 相同，不能等于两个不同的数），故 $\{i,j\}=\{u,v\}$，又 $i<j$，所以 $(i,j)=(u,v)$。
- $j\ge n$：令 $j'=j-n\in[0,n)$。由 $j\le i+n-1$ 得 $j'=j-n\le i-1<i$，且 $i\in[0,n)$，故 $i,j'$ 都在 $[0,n)$ 内、互不相同，于是 $\{i,j'\}=\{u,v\}$。再由 $j'<i$ 得 $j'=u,\ i=v$，即 $(i,j)=(v,u+n)$。

两类穷尽了所有可能，故窗口里对应 $\{u,v\}$ 的只有这两项。

**第三步（两次的值相同）**：$(u,v)$ 的弧长 $A=P_v-P_u$；$(v,u+n)$ 的弧长 $P_{u+n}-P_v=(P_u+S)-P_v=S-A$。二者代入 $f(A)=\min(A,S-A)$ 得同一个值 $\min(A,S-A)$。证毕。

**推论 3.1**：$|\mathcal W|=n(n-1)$，而无序对有 $\frac{n(n-1)}2$ 个、每个出现两次，两边吻合；于是
$$\max_{(i,j)\in\mathcal W}f(P_j-P_i)=\max_{\{u,v\}}\text{dist}(u,v).$$

**引理 4（帐篷函数的单调性）。** $f(A)=\min(A,S-A)$ 在 $[0,S/2]$ 上单调不减，在 $[S/2,S]$ 上单调不增，在 $A=S/2$ 处取得最大值 $S/2$（$S$ 为奇数时峰值落在 $\lfloor S/2\rfloor$ 一侧，仍是整数点上的最大）。

*证明：* 设 $0\le A_1\le A_2\le S/2$。此时 $S-A_2\ge S-A_1\ge S/2\ge A_2\ge A_1$，故 $f(A_1)=\min(A_1,S-A_1)=A_1$、$f(A_2)=A_2$，$f(A_1)\le f(A_2)$。设 $S/2\le A_1\le A_2\le S$，同理 $A_1,A_2\ge S/2$ 而 $S-A_1\le S-A_2\le S/2$，故 $f(A_i)=S-A_i$，$f(A_1)\ge f(A_2)$。最大值显然不超过 $S/2$，在 $A=S/2$ 处取到（若 $S$ 偶且半圈弧可实现）。证毕。

**引理 5（每个起点只需两个候选）。** 固定 $i$。由于 $d\ge1$，$A_i(j)=P_j-P_i$ 在 $j\in[i,i+n-1]$ 上严格递增。令
$$j_0=\max\{j\in[i,i+n-1]:2A_i(j)\le S\}$$
（$j=i$ 时 $A_i=0$，故集合非空，$j_0$ 存在）。则窗口内所有 $j$ 的 $f(A_i(j))$ 的最大值等于下列两个值中的较大者（忽略越界的那个）：
$$A_i(j_0)\quad(j_0\ge i+1),\qquad S-A_i(j_0+1)\quad(j_0+1\le i+n-1).$$

*证明：* 把合法 $j$ 的集合 $[i+1,i+n-1]$ 切成两段：$[i+1,j_0]$ 与 $[j_0+1,i+n-1]$（可能有一段为空）。

- 第一段上 $2A\le S$，即 $A\le S/2$，由引理 4 的单调不减性与 $A_i(j)$ 的严格递增，$f$ 在此段严格递增，最大值在右端点 $j_0$ 取到，值为 $A_i(j_0)$。
- 第二段上 $2A>S$，即 $A>S/2$，$f=S-A$ 随 $A$ 增而减，最大值在左端点 $j_0+1$ 取到，值为 $S-A_i(j_0+1)$。
- 全局最大即两段最大值的较大者。第一段为空时（$j_0<i+1$，即 $j_0=i$）只剩第二个候选；第二段为空时（$j_0=i+n-1$）只剩第一个。证毕。

**引理 6（$j_0$ 关于 $i$ 单调）。** 记 $j_0(i)$ 为引理 5 中对应起点 $i$ 的位置。则 $j_0(i+1)\ge j_0(i)$。

*证明：* 取 $j=j_0(i)$。

- 若 $j\ge i+2$：直接验证 $(i+1,j)$ 合法——$j>i+1$ ✓，$j\le i+n-1<(i+1)+n-1$ ✓；且 $A_{i+1}(j)=P_j-P_{i+1}=A_i(j)-d_i<A_i(j)\le S/2$，故 $j$ 对 $i+1$ 也满足 $2A\le S$。于是 $j_0(i+1)\ge j\ge j_0(i)$。
- 若 $j=i$（即单个 $d_i$ 就超过半圈），则 $j_0(i)=i<i+1\le j_0(i+1)$（后者至少是 $i+1$，因为它自己的虚拟起点），结论成立。
- 若 $j=i+1$，则 $j_0(i+1)\ge i+1=j$。

三种情形都给出 $j_0(i+1)\ge j_0(i)$。证毕。

**引理 7（算法输出的就是答案）。** 程序对所有 $i\in[0,n)$ 取引理 5 的两个候选的最大值，该值等于 $\max_{\{u,v\}}f$。

*证明：* 由引理 5，对每个 $i$，程序取到的值等于"固定 $i$ 时窗口内所有合法 $j$ 的 $f$ 值"的最大值（两个候选之一即为该最大值）。对所有 $i$ 再取最大，等于窗口 $\mathcal W$ 上 $f$ 的最大值。由引理 3，$\mathcal W$ 上 $f$ 的最大值等于所有奶牛对的 $f$ 最大值，即题面所求。证毕。

**引理 8（压缩循环范围不丢解）。** 算法的 `while` 让 $j$ 停在 $j_0(i)$，并只考察 $j_0(i)$ 与 $j_0(i)+1$，不需要回退 $j$。

*证明：* 这是引理 6 的直接推论：由于 $j_0(i)$ 单调不减，从上一轮的 $j$ 继续往后推，若上一轮的 $j$ 恰好是 $j_0(i-1)\le j_0(i)$，则从它继续推进必然到达 $j_0(i)$；指针初值为 $0$、$i$ 逐轮增大，偶尔会落在 $i$ 之前（例如 $i=1$ 而上一轮 $j=0$），代码用 `if(j<i) j=i;` 归位到虚拟起点，这不会跳过任何合法终点（$j<i$ 的下标本就不是合法终点）。推进的总次数不超过 $2n$（$j$ 单调，上界 $i+n-1\le2n-2$）。证毕。

**引理 9（数值安全）。** 所有中间量在 64 位带符号整数内。

*证明：* $S\le2^{31}-1$，故 $P_k\le P_{2n}=2S\le2^{32}-2$；$A\le S$；比较式 $2A\le 2S\le2^{32}-2<2^{63}$；答案 $\le S/2<2^{31}$。代码中 `P` 用 `i64`，比较式 `2*(P[j+1]-P[i])` 也在 `i64` 中求值，不会溢出。证毕。

**引理 10（复杂度）。** 时间 $O(n)$，空间 $O(n)$。

*证明：* 外层 $i$ 循环 $n$ 次；由引理 8，`j` 总共只前进 $O(n)$ 次，故内层 `while` 的累计代价 $O(n)$。空间为 `d[1..n]` 与 `P[0..2n]`，共 $O(n)$。证毕。

**定理。** 程序输出题面所求的最大距离。

*证明：* 由引理 1、2 距离公式正确；由引理 7、8 算法的枚举与压缩不丢最优解；由引理 9 数值正确；由引理 10 复杂度符合约束。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 一圈上两点间的距离是 $\min(A,S-A)$：一个关于顺时针弧长的"帐篷"函数，峰值在正对面。
2. **consider easier version** — 摊直 + 前缀和，$O(n^2)$ 枚举所有对，先确认目标量是"弧长最接近半圈"。
3. **explore its property** — 单峰函数在递增的弧长序列上取最大值，只需看"峰左右的两个邻居"。
4. **explore its property** — 把 $d$ 复制一份展开成两圈，窗口 $[i,i+n-1]$ 里每对奶牛恰好出现两次，两次的值相同。
5. **classic problem solution** — 双指针：起点右移时合法终点右移（弧长随起点增大而减小），每轮 $j$ 不回退，摊还 $O(n)$。
6. **discuss by category** — 当单步就超过半圈时"不超过半圈的 $j$"不存在，用虚拟起点 $j=i$ 把这种情形并入统一框架。
7. **classic problem solution** — 用 $2A\le S$ 代替除法/浮点比较，并用 64 位防溢出。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $n$ | 奶牛只数 | `int` | 输入 |
| $d_i$ | 第 $i$ 只到第 $i+1$ 只的顺时针距离（0-based，$d_{n-1}$ 回到第 $0$ 只） | `int[]` | 输入 |
| $S$ | 整圈长度 $\sum d_i$ | `i64` | 读入时累加，$\le2^{31}-1$ |
| $P_k$ | 展开数组上的前缀和，$P_k=\sum_{t<k}d_{t\bmod n}$ | `i64[]` | `P[0]=0`，`P[k]=P[k-1]+d[(k-1)%n]`，长度 $2n+1$ |
| $i$ | 枚举的起点奶牛 | `int` | $0\le i<n$ |
| $j$ | 双指针，满足 $2(P_j-P_i)\le S$ 的最大合法下标 | `int` | 单调不减，只前进 |
| `ans` | 当前最大距离 | `i64` | 初值 $0$ |

### 算法步骤

1. I/O 加速三行。
2. 读入 $n$ 与 $d_0..d_{n-1}$，同时累加 $S$。
3. 展开造前缀和：`P[0]=0`；对 $k=0..2n-1$ 执行 `P[k+1]=P[k]+d[k%n]`。
4. 令 `j=0`、`ans=0`。对 $i=0..n-1$：
   1. 若 `j<i`，置 `j=i`（虚拟起点，弧长 $0$，必然满足 $2A\le S$）。
   2. `while(j+1<=i+n-1 && 2*(P[j+1]-P[i])<=S) ++j;`——把 $j$ 推到引理 5 的 $j_0$。
   3. 若 `j>=i+1`，用 `P[j]-P[i]` 更新 `ans`（峰的左侧端点）。
   4. 若 `j+1<=i+n-1`，用 `S-(P[j+1]-P[i])` 更新 `ans`（峰的右侧端点）。
5. 输出 `ans`。

### 复杂度

- 时间：$O(n)$（$i$ 循环 $n$ 次，$j$ 总推进量 $O(n)$）。
- 空间：$O(n)$（`d` 与 `P` 两个数组）。
- 验证状态：编译通过；5 组手造边界（含单步超过半圈、偶数半圈）全对；300 组随机数据与 $O(n^2)$ 暴力完全一致；$n=10^5$、每段 $21474$ 的极限数据 0.055s 出解且答案恰为 $S/2=1073700000$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2381 圆圆舞蹈
// 思路：把环展开成两圈做前缀和；一对奶牛的距离是 min(弧长, S-弧长)，
//       它是弧长的单峰函数（峰在半圈处）。对每个起点双指针找
//       "弧长不超过半圈的最后一个终点 j"，只需考察 j 与 j+1 两个候选。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n,d[mxn];
i64 P[mxn*2];		// P[k]=前 k 段顺时针距离之和（展开成两圈），P[0]=0

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	i64 S=0;
	for(int i=0;i<n;++i)
	{
		cin>>d[i];
		S+=d[i];
	}
	for(int i=0;i<2*n;++i)
		P[i+1]=P[i]+d[i%n];
	i64 ans=0;
	int j=0;
	for(int i=0;i<n;++i)
	{
		if(j<i)						// 虚拟起点：弧长 0
			j=i;
		while(j+1<=i+n-1&&2*(P[j+1]-P[i])<=S)	// 2A 与 S 比较，避免除法
			++j;
		if(j>=i+1)					// 峰左侧的最后一个
			ans=max(ans,P[j]-P[i]);
		if(j+1<=i+n-1)				// 峰右侧的第一个
			ans=max(ans,S-(P[j+1]-P[i]));
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `P` 开到 `mxn*2`，用 `d[i%n]` 展开，从而 `[i,i+n-1]` 是普通区间，弧长恒为 `P[j]-P[i]`（引理 1）。
- `if(j<i)j=i;` 是"单步超过半圈"的关键兜底：让指针从虚拟起点出发，使 `j0` 不存在的情形自然退化为候选 `j+1=i+1`（引理 5 的第二种情形）。
- 判断条件写 `2*(P[j+1]-P[i])<=S` 而不是 `P[j+1]-P[i]<=S/2`，避免偶数/奇数半圈的取整错误，也不需要浮点。
- 两个 `if` 分别对应峰的左、右邻居；越界时自动跳过，无需特判空区间。
- `ans` 用 `i64`；虽然 $S\le2^{31}-1$ 时答案也能塞进 `int`，但中间量 $2A$ 会超，统一 64 位最省心。
- 复杂度 $O(n)$：`j` 在外层循环中单调前进，累计不超过 $2n$ 次。
