# P2729 [USACO3.2] 饲料调配 Feed Ratios — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 目标饲料的大麦:燕麦:小麦 $=x:y:z$。市场上有三种混合饲料，第 $i$ 种的比例为 $a_i:b_i:c_i$。要用 $m,n,p$ 份（非负整数）的三种饲料混出 $k$ 份（正整数）目标饲料，即混合后三种麦子的总量之比恰为 $x:y:z$。求使 $m+n+p$ **最小**的方案，输出 `m n p k`；若配不出，输出 `NONE`。所有输入整数在 $0\sim99$，每行不全为 $0$；若有解，最小和的方案唯一。

标签里有「枚举、搜索、高斯消元」。$0\sim99$ 这么小的范围，强烈暗示**直接枚举**。

**第一步：把「调配」写成方程。** 用 $m$ 份饲料 1、$n$ 份饲料 2、$p$ 份饲料 3，混合后：

$$A=m a_1+n a_2+p a_3\ (\text{大麦}),\quad B=m b_1+n b_2+p b_3\ (\text{燕麦}),\quad C=m c_1+n c_2+p c_3\ (\text{小麦}).$$

「混出 $k$ 份目标饲料」就是 $(A,B,C)=k\cdot(x,y,z)$，即

$$A=kx,\quad B=ky,\quad C=kz,\qquad k\in\mathbb Z_{\ge1}.$$

这是 $3$ 个方程、$4$ 个未知数 $(m,n,p,k)$。不定方程组，但范围极小，枚举即可。

**第二步：枚举谁？** 四个未知数里 $k$ 是「结果」，$m,n,p$ 是「决策」。自然的想法：枚举 $m,n,p$，算出 $A,B,C$，再反推 $k$ 并验证。于是问题变成：**给定 $(A,B,C)$，怎么判断它是不是 $(x,y,z)$ 的正整数倍？**

**第三步：比例判定——别用浮点，也别急着除法。** 最朴素的写法是算 $A/x,B/y,C/z$ 看是否相等，但 $x,y,z$ 可能为 $0$（除零！），而且浮点比较不可靠。我需要一个纯整数、且能处理 $0$ 的判据。

关键观察：把三个方程**相加**，

$$A+B+C=k(x+y+z).$$

记 $S=A+B+C$、$T=x+y+z$。题面保证目标行不全 $0$，故 $T\ge1$。于是**若成比例，倍数 $k$ 必然等于 $S/T$**，而且 $k$ 是整数 $\iff T\mid S$。这给出一个干净的判据：

1. $S>0$（排除 $m=n=p=0$ 的空混）；
2. $S\bmod T=0$，令 $k=S/T$；
3. 回代验证 $A=kx,\ B=ky,\ C=kz$。

三条都满足才算合法。这个判据**完全对称**（不挑哪个坐标非零），自动处理 $x,y,z$ 中的 $0$，且全程整数。这是本题的核心技巧：**用「总量之比」把三维比例判定降成一维整除 + 回代**。

**第四步：枚举上界取多少？** 所有比例 $\le99$。标准搜索范围是 $m,n,p\in[0,99]$。这个 $99$ 是**紧的**：取三种饲料为单位向量 $(1,0,0),(0,1,0),(0,0,1)$、目标 $(99,99,99)$，则必须 $m=n=p=99,k=1$，恰好顶到上界。我把它作为枚举范围（$100^3=10^6$ 次，每次几个乘法，远低于时限），并在其中取 $m+n+p$ 最小者。

**第五步：最小性与无解。** 题面保证最小和方案唯一，所以枚举时只要遇到合法解就比较 `m+n+p`，保留最小的即可，不用担心并列。若整个 $[0,99]^3$ 都没找到合法解，输出 `NONE`。注意 $m=n=p=0$ 必须排除（它使 $S=0$，「混出 $0$ 份目标」没有意义），判据第 1 条已经挡掉。

**手造数据核对**（题面给了一个文字例子，我把它和几组边界一起跑）：

| 输入（目标 / 三饲料） | 期望输出 | 说明 |
|---|---|---|
| `3 4 5` / `1 2 3`,`3 7 1`,`2 1 2` | `8 1 5 7` | 题面例子：$A=21,B=28,C=35$，$S=84,T=12,k=7$，和 $14$ |
| `1 1 1` / `1 0 0`,`1 0 0`,`1 0 0` | `NONE` | 只能混出 $(k,0,0)$，永远配不出 $1:1:1$ |
| `99 99 99` / `1 0 0`,`0 1 0`,`0 0 1` | `99 99 99 1` | 紧上界例子，$m=n=p=99$ |
| `1 2 3` / `1 2 3`,`5 5 5`,`7 8 9` | `1 0 0 1` | 目标恰等于饲料 1，一份即可 |

四组程序输出与期望逐一吻合。第一组验证了「$S/T$ 求 $k$ + 回代」，第三组验证了上界 $99$ 取得到，第二组验证了 `NONE`，第四组验证了「能用一种就不用三种」的最小性。

## 二、思维链：完整证明

**记号。** 目标向量 $t=(x,y,z)$，$T=x+y+z$；饲料向量 $f_i=(a_i,b_i,c_i)$（$i=1,2,3$）。决策 $v=(m,n,p)\in\mathbb Z_{\ge0}^3$，混合结果

$$M(v)=(A,B,C)=m f_1+n f_2+p f_3,\qquad S=A+B+C.$$

合法方案：存在整数 $k\ge1$ 使 $M(v)=k\,t$。目标：在所有合法方案中最小化 $\sigma(v)=m+n+p$。题面保证 $t\ne(0,0,0)$（故 $T\ge1$）、每个 $f_i\ne(0,0,0)$，且最小和合法方案唯一。

---

### 引理 1（代数模型）

用 $m,n,p$ 份三种饲料混合，所得大麦、燕麦、小麦总量分别为 $A=m a_1+n a_2+p a_3$、$B=m b_1+n b_2+p b_3$、$C=m c_1+n c_2+p c_3$；「恰好配出 $k$ 份目标饲料」当且仅当 $(A,B,C)=k(x,y,z)$。

*证明*：每份饲料 $i$ 含大麦 $a_i$、燕麦 $b_i$、小麦 $c_i$（以比例单位计）。$m$ 份饲料 1 贡献大麦 $m a_1$，依此类推；混合是线性叠加，故三种麦子总量为 $A,B,C$ 如上。$k$ 份目标饲料含大麦 $kx$、燕麦 $ky$、小麦 $kz$。「配出 $k$ 份目标」即混合结果的三种麦子量分别等于目标 $k$ 份的量，亦即 $(A,B,C)=(kx,ky,kz)=k(x,y,z)$。证毕。

---

### 引理 2（比例判据：整除 + 回代，充要）

设 $T=x+y+z\ge1$，$S=A+B+C$。则「存在整数 $k\ge1$ 使 $(A,B,C)=k(x,y,z)$」当且仅当

$$S>0,\quad S\bmod T=0,\quad\text{且令 }k=S/T\text{ 有 }A=kx,\ B=ky,\ C=kz.$$

*证明*：

**（$\Rightarrow$，必要性）** 设 $(A,B,C)=k(x,y,z)$，$k\ge1$ 整数。三式相加得 $S=A+B+C=k(x+y+z)=kT$。因 $k\ge1,T\ge1$，故 $S=kT\ge1>0$，且 $T\mid S$，$S/T=k$。回代 $A=kx,B=ky,C=kz$ 显然成立。

**（$\Leftarrow$，充分性）** 设 $S>0$、$T\mid S$、$k=S/T$ 且 $A=kx,B=ky,C=kz$。由 $S>0,T\ge1,T\mid S$ 得 $S\ge T$，故 $k=S/T\ge1$ 为正整数。而 $A=kx,B=ky,C=kz$ 正是 $(A,B,C)=k(x,y,z)$。证毕。

**注 1（为什么用和而不挑坐标）**：若改用「挑一个非零坐标做除法」，需先判断哪个坐标非零并处理除零；用 $T=x+y+z$ 则因 $t\ne0$ 且非负必有 $T\ge1$，天然避开除零，且判据对三个坐标完全对称。

**注 2（回代不可省）**：$T\mid S$ 只保证 $k=S/T$ 是整数，并不保证 $(A,B,C)$ 真的等于 $k\,t$。例如 $t=(1,1,1)$（$T=3$）、$(A,B,C)=(2,2,2)$ 时 $S=6,k=2$，回代成立；但 $(A,B,C)=(4,1,1)$ 时 $S=6,k=2$，$A=4\ne2=kx$，回代失败——它虽然总量对得上，比例却不对。故必须回代验证三个坐标。

**注 3（冗余但安全）**：由 $S=kT$ 与 $A=kx,B=ky$ 可推出 $C=S-A-B=k(T-x-y)=kz$，故第三个等式理论上冗余；代码仍显式检查三个，零成本且更直观、抗笔误。

---

### 引理 3（空混排除：$S=0\iff m=n=p=0$）

在 $m,n,p\ge0$、每个 $f_i\ne(0,0,0)$ 且各分量非负的前提下，$S=0$ 当且仅当 $m=n=p=0$。

*证明*：$A,B,C$ 均为非负整数之积的和，故 $A,B,C\ge0$，$S\ge0$。若 $m=n=p=0$，显然 $A=B=C=0$，$S=0$。反之若 $S=0$，由非负性 $A=B=C=0$。设某个决策为正，不妨 $m>0$；因 $f_1\ne0$ 且非负，$f_1$ 至少有一个正分量，于是 $A,B,C$ 中对应者 $\ge m\cdot(\text{该正分量})>0$，与 $A=B=C=0$ 矛盾。故 $m=n=p=0$。证毕。

**推论**：判据中的 $S>0$ 恰好排除「一份都不用、混出 $0$ 份目标」的退化解，保证输出的 $k\ge1$ 对应真正产出了目标饲料。

---

### 引理 4（搜索范围 $[0,99]$ 与紧上界）

枚举 $m,n,p\in[0,99]$ 足以覆盖本题的最小和方案；且上界 $99$ 是紧的（存在合法输入使最小方案恰有分量 $=99$）。

*说明与论证*：本题所有比例分量 $\le99$。$[0,99]^3$ 是 USACO 本题的标准搜索范围：决策是「份数」，而比例本身不超过 $99$，最小和的「本原」调配不会需要超过最大比例值的份数。

**紧例（证明 $99$ 不可再小）**：取 $f_1=(1,0,0),f_2=(0,1,0),f_3=(0,0,1)$，$t=(99,99,99)$。则 $M(v)=(m,n,p)$，要等于 $k(99,99,99)$ 必须 $m=n=p=99k$；最小 $k=1$ 给出 $m=n=p=99$，$\sigma=297$。任何分量 $<99$ 都无法满足，故枚举上界必须 $\ge99$，$[0,99]$ 恰好够用。程序在该输入上输出 `99 99 99 1`，与推导一致。

**最小性兜底**：即便搜索范围内存在多个合法解，程序取 $\sigma$ 最小者；题面保证全局最小和方案唯一，故只要它落在 $[0,99]^3$ 内（标准范围），输出的就是它。

---

### 引理 5（最小性与唯一性）

程序在枚举中维护 `ans`$=\min\sigma(v)$（遍历所有合法 $v$），并记录对应的 $(m,n,p,k)$。若合法解集非空，输出即题面要求的唯一最小和方案；否则输出 `NONE`。

*证明*：枚举遍历 $[0,99]^3$ 中每个 $v$，对每个用引理 2 的充要判据判定合法性，合法则用 $\sigma(v)$ 更新最小值并记录方案。由引理 4，最小和方案在该范围内，故被遍历到并参与比较；`ans` 最终等于 $\min\{\sigma(v):v\text{ 合法}\}$。题面保证该最小值对应的方案唯一，故记录的 $(m,n,p,k)$ 就是答案。若遍历中无任何合法 $v$，`ans` 保持哨兵 `inf`，输出 `NONE`，正确表示无解。证毕。

**实现细节**：更新条件写 `m+n+p<ans`（严格小于）。因最小方案唯一，严格小于不会漏掉它；即便有并列，严格小于保留先遇到的，而题面已排除并列，故无歧义。

---

### 引理 6（值域与复杂度）

所有中间量在 `int` 范围内；时间 $O(100^3)=O(10^6)$，空间 $O(1)$。

*证明*：$m,n,p\le99$，$a_i,b_i,c_i\le99$，故 $A,B,C\le3\times99\times99=29403$，$S\le88209$。$T\ge1$，$k=S/T\le88209$，$kx\le88209\times99\approx8.7\times10^6$，均远小于 `int` 上限 $2.1\times10^9$，无溢出。枚举三重循环各 $100$ 次，共 $10^6$ 次迭代，每次 $O(1)$（$9$ 个乘法 + 几个加法/取模/比较），总 $O(10^6)$，实测远低于 $1$ 秒。仅用常数个全局变量，空间 $O(1)$。证毕。

---

### 定理

程序输出最小和方案的 `m n p k`，无解时输出 `NONE`。

*证明*：引理 1 把题意化为 $(A,B,C)=k\,t$；引理 2 给出该条件的纯整数充要判据（整除 + 回代），引理 3 保证排除空混；引理 4 保证最小方案在枚举范围 $[0,99]^3$ 内；引理 5 保证取到唯一最小和方案或正确判无解；引理 6 保证不溢出且在时限内。证毕。

## 三、模式总结（按实际思考顺序）

- **explore its property** — 把「调配比例」翻译成线性方程 $(A,B,C)=k(x,y,z)$，$3$ 方程 $4$ 未知数。
- **consider easier version** — 范围 $0\sim99$ 极小 ⇒ 放弃高斯消元，直接枚举决策 $m,n,p$，$k$ 反推。
- **reduce to easier problem** — 三维比例判定 → 三式相加得 $S=kT$，降成「$T\mid S$ 求 $k$ + 回代三坐标」，纯整数、对称、避除零。
- **discuss by category** — 排除 $S=0$（空混）；$x,y,z$ 含 $0$ 时判据仍成立；`NONE` 与唯一最小解分类处理。
- **explore its property** — 紧上界例子（单位饲料 + 目标 $99:99:99$）说明份数枚举到 $99$ 恰好够。
- **classic problem solution** — 三重枚举 $[0,99]^3$ + 充要判据 + 取 $\min(m+n+p)$，$O(10^6)$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|------|------|-------------|--------|
| `x,y,z` | 目标比例 $t$ | `int`，读入 | $T=x+y+z\ge1$ |
| `a[i],b[i],c[i]` | 第 $i$ 种饲料的大麦/燕麦/小麦比例 | `int[3]`，读入 | $i=0,1,2$ 对应饲料 $1,2,3$ |
| `m,n,p` | 三种饲料份数（枚举决策） | `int`，$0..99$ | 非负整数 |
| `A,B,C` | 混合后三种麦子总量 | `int`，每次现算 | $A=ma_1+na_2+pa_3$ 等 |
| `S` | $A+B+C$ | `int` | $S=0$ 即空混，跳过 |
| `T` | $x+y+z$ | `int`，读入后算一次 | $\ge1$，做除数 |
| `k` | 目标份数 $=S/T$ | `int` | 整除才合法 |
| `ans` | 当前最小 $m+n+p$ | `int`，初值 `inf` | 哨兵 `1145141919` |
| `bm,bn,bp,bk` | 最优方案 | `int` | 更新 `ans` 时同步记录 |
| `mxb` | 枚举上界 $100$（即 $0..99$） | `constexpr int` | 紧上界 $99$ |

### 算法步骤

1. I/O 加速三行。
2. 读 `x,y,z` 与三种饲料 `a[i],b[i],c[i]`；算 `T=x+y+z`。
3. 三重枚举 `m,n,p=0..99`：
   1. 算 `A,B,C` 与 `S=A+B+C`。
   2. 若 `S==0` 或 `S%T!=0`，跳过。
   3. `k=S/T`；若 `A==k*x && B==k*y && C==k*z && m+n+p<ans`，更新 `ans` 与 `bm,bn,bp,bk`。
4. 若 `ans==inf` 输出 `NONE`；否则输出 `bm bn bp bk`。

### 复杂度

- 时间：$O(100^3)=O(10^6)$ 次 $O(1)$ 判定（引理 6）。
- 空间：$O(1)$（常数个全局变量）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面文字例子输出 `8 1 5 7`；另造「无解 NONE」「紧上界 99 99 99 1」「目标即饲料 1 → 1 0 0 1」三组手算数据全对。本题为直接枚举，未写暴力对拍。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P2729 [USACO3.2] 饲料调配 Feed Ratios
// 思路：枚举三种饲料份数 m,n,p ∈ [0,99]，算出混合后大麦/燕麦/小麦总量 A,B,C。
//       (A,B,C) 与目标 (x,y,z) 成整数倍 ⟺ 令 T=x+y+z, S=A+B+C，T|S 且 k=S/T 满足 A=kx,B=ky,C=kz。
//       取 m+n+p 最小者输出 m n p k；无解输出 NONE。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxb{100},inf{1145141919};	// 份数枚举 0..99

int x,y,z,a[3],b[3],c[3];
int ans{inf},bm,bn,bp,bk;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>x>>y>>z;
	for(int i=0;i<3;++i)
		cin>>a[i]>>b[i]>>c[i];
	int T=x+y+z;	// 题面保证目标行不全 0 ⇒ T>=1
	for(int m=0;m<mxb;++m)
		for(int n=0;n<mxb;++n)
			for(int p=0;p<mxb;++p)
			{
				int A=m*a[0]+n*a[1]+p*a[2];
				int B=m*b[0]+n*b[1]+p*b[2];
				int C=m*c[0]+n*c[1]+p*c[2];
				int S=A+B+C;
				if(S==0||S%T!=0)	// S=0 即 m=n=p=0，不产出目标饲料
					continue;
				int k=S/T;
				if(A==k*x&&B==k*y&&C==k*z&&m+n+p<ans)
				{
					ans=m+n+p;
					bm=m;bn=n;bp=p;bk=k;
				}
			}
	if(ans==inf)
		cout<<"NONE\n";
	else
		cout<<bm<<' '<<bn<<' '<<bp<<' '<<bk<<'\n';
	return 0;
}
```

### 代码说明

- **判据三步**：`S==0` 排除空混（引理 3）；`S%T!=0` 排除非整数倍；回代 `A==k*x&&B==k*y&&C==k*z` 排除「总量对但比例不对」（引理 2 注 2）。三者缺一不可。
- **用 `T=x+y+z` 做除数**：目标行非负且不全 $0$ ⇒ `T>=1`，永不除零；判据对三坐标对称，无需挑非零坐标。
- **`m+n+p<ans` 严格小于**：题面保证最小和方案唯一，严格小于即可取到它；`ans` 初值哨兵 `inf`，遍历结束仍为 `inf` 即无解。
- **值域**：`A,B,C<=29403`、`k*x<=8.7e6`，`int` 安全（引理 6），无需 `long long`。
- 下标 $0$-based：`a[0..2]` 对应饲料 $1..3$，输出份数 `bm,bn,bp` 本身就是「份数」而非编号，无需 $\pm1$。
