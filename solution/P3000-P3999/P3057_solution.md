# P3057 [USACO12NOV] Distant Pastures S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N\times N$ 网格（$1\le N\le 30$），每格种两种草之一，用字符 `(` 和 `)` 表示（**这里括号只是两种草的代号，与括号匹配毫无关系**）。上下左右相邻两格间走一步：草相同耗时 $A$，草不同耗时 $B$（$0\le A,B\le 10^6$）。对每对格子，奶牛走最短路；求所有格子对的最短路时间的**最大值**（即图的直径）。输出一个整数。

**边界与口径。** $N=1$ 时只有一格，"牧场对"退化为自身到自身，时间 $0$，输出 `0`。$A$ 或 $B$ 可以为 $0$：零权边合法，最短路仍然存在（无负权），但"按步数 BFS"之类的做法要格外小心。网格四连通，任意两格互相可达，答案有限。

**第一步：剥掉故事，认出图论模型。** 格子 = 点（共 $V=N^2\le 900$ 个），相邻格子间连无向边，边权 $w(u,v)=A$（同字符）或 $B$（异字符）。"所有点对最短路最大值"就是**带权无向图的直径**。注意边权对称：$u\to v$ 与 $v\to u$ 耗时相同（只看两格草是否相同），所以 $\mathrm{dist}(s,t)=\mathrm{dist}(t,s)$。

**第二步：能不能不跑最短路，直接公式算？** 一个诱人的想法：两点间曼哈顿距离 $\times$ 某个权。立刻找到反例：$A=10,B=1$，网格
```
())
(()
())
```
左上角 $(0,0)$ 到左下角 $(2,0)$：竖直直走两步都是同草（`(`→`(`→`(`），耗时 $20$；但绕道 $(0,1)\to(1,1)\to(2,1)\to(2,0)$ 四步**全是异草**，耗时 $4$。最短路可以**绕远路**（步数更多但更便宜），任何"曼哈顿 $\times$ 权"的公式都错。甚至当 $A>B$ 时，最短路的形状完全不可预测——必须老老实实跑最短路算法。

**第三步：选算法。** 两条经典路线：
- **Floyd**：$O(V^3)=900^3\approx 7.3\times 10^8$ 次内层操作，1 秒时限下非常悬，不选。
- **对每个源点跑 Dijkstra**：边数 $E\le 4V\approx 3600$（有向计），单次 $O(E\log V)$，总共 $V$ 次，约 $900\times 3600\times 10\approx 3\times 10^7$，稳过。边权非负（$A,B\ge 0$），Dijkstra 的前提满足。

$V=900$ 这个规模就是"多源 Dijkstra 舒适区、Floyd 危险区"的分界，出题人把 $N$ 卡在 $30$ 正是此意。

**第四步：实现细节。**
1. 点编号 $u=r\cdot N+c$（0-based），邻接关系不用建表，Dijkstra 里现算四个方向即可。
2. 边权现算：`g[nr][nc]==g[r][c]?A:B`。
3. `dis` 用 `i64` 并显式 fill 成 INF（$1145141919810$）——虽然本题所有点可达、不会读到 INF，但"全局数组默认 0 不是 INF"是必须防御的陷阱。
4. 每轮 Dijkstra 结束后把 `dis` 的最大值并入全局 `ans`。零权边不影响 Dijkstra 正确性（证明只要求非负）。
5. 堆用惰性删除：弹出时 `vis[u]` 已置位就跳过。

**手造数据核对。** 题面 Hint 说样例网格左上到右下耗时 5，但没给样例的 $A,B$，无法直接复用；全部手造：

第一组（上文反例网格，$N=3,A=10,B=1$）：
```
())
(()
())
```
手算关键距离：$(0,0)\to(2,0)=4$（绕路）；$(1,0)\to(0,2)$：任何路线都至少要踩一条同草边，最便宜的如 $(1,0)\to(0,0)[10]\to(0,1)[1]\to(0,2)[10]=21$，或 $(1,0)\to(1,1)[10]\to(1,2)[1]\to(0,2)[10]=21$，逐一枚举更长的路线都 $\ge 21$；同理 $(1,0)\to(2,2)=21$。其余点对都 $\le 21$。直径 $=21$，输出 `21`。

第二组（$N=1$）：`(`，$A=B=0$，输出 `0`。

第三组（$A=B=2$，$N=3$，任意网格）：所有边权都是 $2$，最短路 = 曼哈顿距离 $\times 2$，直径 $=2\times(2+2)=8$。这组专门检验"权相等时退化为 BFS 语义"。

第四组（$N=2,A=10,B=1$，棋盘格 `()` / `)(`）：所有边异草权 $1$，直径 = 对角曼哈顿 $2$，输出 `2`。

## 二、思维链：完整证明

**记号。** 图 $G=(V,E)$：$V=\{0..N^2-1\}$，$u=rN+c$；$(u,v)\in E$ 当且仅当两格四连通相邻；$w(u,v)=A$ 若 $g_u=g_v$，否则 $B$。$w\ge 0$。$\delta(s,t)$ 为最短路长度（路径权和的最小值；$s=t$ 时 $0$）。答案 $D=\max_{s,t}\delta(s,t)$。

---

### 引理 1（模型等价性）

原题"所有牧场对按最短路行走的最大时间"等于 $D=\max_{s,t\in V}\delta(s,t)$。

*证明*：一条行走路线是格子序列，相邻格四连通，耗时为各步耗时之和——这正是 $G$ 中一条路径的权和；反之 $G$ 中每条路径对应一条合法行走路线。故"最短时间"= 最短路 $\delta$。"所有牧场对"遍历 $V\times V$（含 $s=t$，贡献 $0$，不影响 max）。边权对称（$w(u,v)$ 只依赖两格字符是否相同，与方向无关），故 $\delta$ 对称，但这对正确性非必要，只是说明无需区分有序对。证毕。

---

### 引理 2（为什么不能用曼哈顿公式：绕路反例）

存在合法输入与点对 $(s,t)$，使 $\delta(s,t)$ 严格小于任何单调路径（只向目标方向走的路径）的权和；特别地 $\delta(s,t)\ne(\text{曼哈顿距离})\times\min(A,B)$ 之类的公式。

*证明*：取 $N=3,A=10,B=1$，网格 `()) / (() / ())`，$s=(0,0),t=(2,0)$。单调路径只有竖直向下：$(0,0)\to(1,0)\to(2,0)$，两步皆同草（三个 `(`），权 $20$。非单调路径 $(0,0)\to(0,1)\to(1,1)\to(2,1)\to(2,0)$：字符序列 `(`→`)`→`(`→`)`→`(`，四步皆异草，权 $4$。故 $\delta(s,t)\le 4<20$，任何只数步数的公式都不可能给出 $4$（曼哈顿距离是 $2$，$2\times\min(A,B)=2\ne 4$，$2\times A=20\ne 4$）。证毕。

**推论**：必须使用真正处理边权的最短路算法；边权只有两种取值这一事实不能简化问题结构。

---

### 引理 3（Dijkstra 的正确性，非负权）

对固定源 $s$，算法（`dis[s]=0`，其余 INF；小根堆按 `dis` 弹出；首次弹出 $u$ 时置 `vis[u]` 并松弛其出边）结束时，每个被弹出的 $u$ 满足 `dis[u]`$=\delta(s,u)$；网格连通故所有点都会被弹出。

*证明*：两个不变量。

**不变量 A**：任何时刻 `dis[v]` 要么是 INF，要么等于某条真实 $s\to v$ 路径的权和，故 `dis[v]`$\ge\delta(s,v)$。归纳：初始 `dis[s]=0` 是空路径；每次松弛 `dis[v]=dis[u]+w(u,v)`，而 `dis[u]` 对应一条真实路径，接上边 $(u,v)$ 仍是真实路径。

**不变量 B**：按弹出顺序归纳，第 $k$ 个首次弹出的点 $u$ 满足 `dis[u]`$=\delta(s,u)$。
- $k=1$：堆中初始只有 $(0,s)$，弹出 $s$，`dis[s]=0`；非负权下 $\delta(s,s)=0$ ✓。
- 归纳步：设前 $k-1$ 个弹出的点都已"定值"（`dis`$=\delta$）。第 $k$ 个弹出 $u$，键值 $d=$`dis[u]`。反证设 $\delta(s,u)<d$。取一条 $s\to u$ 最短路，设 $y$ 是其上第一个**尚未定值**的点，$x$ 为 $y$ 的前驱（$x$ 已定值，可能是 $s$）。最短路的前缀仍是最短路（否则替换前缀得到更短的 $s\to u$ 路，矛盾；这里不需要非负性，只需最优子结构），故 $\delta(s,y)=\delta(s,x)+w(x,y)$。$x$ 定值时松弛过边 $(x,y)$，由不变量 A 的归纳过程得 `dis[y]`$\le\delta(s,x)+w(x,y)=\delta(s,y)$；结合不变量 A 得 `dis[y]`$=\delta(s,y)$。$y$ 未定值意味着它从未被首次弹出，而它被松弛入堆后其键值条目仍在堆中（惰性删除只跳过已定值点的重复条目），故堆中最小键 $\le$`dis[y]`$=\delta(s,y)\le\delta(s,u)<d$（最后一步：$y$ 在 $s\to u$ 最短路上且权非负，前缀 $\le$ 全程）。这与"弹出的是堆中最小键 $d$"矛盾。故 $\delta(s,u)\ge d$；结合不变量 A 得等号。

连通性：网格四连通，任意点有路径可达，松弛会沿路径传播，所有点最终入堆并弹出。证毕。

**零权注记**：证明只用了 $w\ge 0$（前缀 $\le$ 全程一步），$A=0$ 或 $B=0$ 完全合法；负权才会破坏它。

---

### 引理 4（多源取 max 即直径）

对每个 $s\in V$ 跑一遍引理 3 的 Dijkstra，把每轮 $\max_v$`dis[v]` 并入 `ans`，则最终 `ans`$=D$。

*证明*：第 $s$ 轮结束时 `dis[v]`$=\delta(s,v)$ 对所有 $v$（引理 3 + 连通），故该轮贡献 $\max_v\delta(s,v)$。`ans` 是各轮贡献的最大值 $=\max_s\max_v\delta(s,v)=D$。`ans` 全局初值 $0$，而 $D\ge 0$（$\delta(s,s)=0$），初值不会污染结果；$N=1$ 时唯一一轮贡献 $0$，输出 $0$ ✓。证毕。

---

### 引理 5（复杂度与数值范围）

时间 $O(N^2\cdot E\log E)=O(N^4\log N)$，空间 $O(N^2)$。`i64` 足够且必要地安全。

*证明*：$V=N^2\le 900$，有向边数 $E\le 4V$。单次 Dijkstra：每条边至多触发一次成功松弛入堆，堆操作 $O(E\log E)$；共 $V$ 轮，$O(VE\log E)\le 900\times 3600\times\log_2 3600\approx 3.8\times 10^7$。空间：`dis`、`vis` 各 $O(V)$，堆 $O(E)$。数值：任何最短路 $\le$ 某单调路径权 $\le 2(N-1)\max(A,B)\le 58\times 10^6$，其实 `int` 就够；但松弛中间量 `dis[u]+w` 与 INF 相加等场景用 `i64` 一劳永逸，INF 取 $1145141919810\approx 1.1\times 10^{12}$，远大于任何真实距离且加上 $10^6$ 不溢出。证毕。

**与 Floyd 对比**：$O(V^3)=7.29\times 10^8$，常数虽小但总量大一个数量级以上，1 秒时限下风险高；多源 Dijkstra 是本题的预期解法（标签"最短路"）。

---

### 定理

程序输出所有牧场对最短路时间的最大值，复杂度 $O(N^4\log N)$。

*证明*：引理 1 把原题翻译成带权图直径；引理 2 排除公式化捷径，确认必须跑最短路；引理 3 保证每轮 Dijkstra 定值正确（非负权，含零权）；引理 4 保证多源取 max 恰为直径；引理 5 给出复杂度与数值安全。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 括号只是两种草的代号；格子=点、相邻=边、同/异草=两种边权，原题=带权无向图直径。
2. **consider easier version** — 先想"曼哈顿×权"公式，被 $A=10,B=1$ 的绕路反例（直走 20、绕行 4）击毙：最短路可以步数更多但更便宜。
3. **discuss by category** — Floyd $900^3\approx 7.3\times 10^8$ 危险 vs 多源 Dijkstra $\approx 3\times 10^7$ 稳过，按规模选后者。
4. **classic problem solution** — 堆优化 Dijkstra（惰性删除 + `greater<>`），非负权含零权均正确；邻接现算四方向，不建边表。
5. **classic problem solution** — 直径 = 对每个源点跑最短路后取全局 max；`ans` 初值 0 被 $\delta(s,s)=0$ 兜底。
6. **explore its property** — 数值体检：真实距离 $\le 5.8\times 10^7$，`i64` + INF 显式 fill，防全局 0 陷阱与溢出。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,A,B` | 网格边长、同草耗时、异草耗时 | `int` | 读入；$A,B\ge 0$ |
| `g[r][c]` | 第 $r$ 行第 $c$ 列的草字符 | `char[35][35]` | 按行读入 |
| `mxn` | 点数上界 $30^2+5=905$ | `constexpr int` | `dis/vis` 尺寸 |
| `dis[u]` | 当前源到 $u$ 的最短路估计 | `i64[mxn]` | **每轮 fill INF**；`dis[s]=0` |
| `vis[u]` | $u$ 是否已定值（首次弹出） | `bool[mxn]` | 每轮 fill false |
| `inf` | $1145141919810$ | `constexpr i64` | 远大于真实距离 $\le 5.8\times 10^7$ |
| `dr,dc` | 四方向偏移 | `constexpr int[4]` | 上下左右 |
| `ans` | 直径（所有轮的最大值） | `i64` | 全局 0；$\delta(s,s)=0$ 兜底 |
| `u=r*n+c` | 格子的一维编号，0-based | `int` | 读入天然 0-based，无需 -- |

### 算法步骤

1. I/O 加速三行；读 $N,A,B$ 与 $N$ 行网格。
2. 对每个源 $s=0..N^2-1$：`dis` fill INF、`vis` fill false；`dis[s]=0` 入堆；标准堆优化 Dijkstra，松弛时边权现算 `g[nr][nc]==g[r][c]?A:B`。
3. 每轮结束扫一遍 `dis`，`ans=max(ans,dis[i])`。
4. 输出 `ans`。

### 复杂度

- 时间 $O(N^2\cdot E\log E)\approx 3.8\times 10^7$（$N=30$）；空间 $O(N^2)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；绕路反例网格输出 21（手算直径一致）；$N=1$ 输出 0；$A=B=2$ 输出 8；棋盘 $2\times 2$ 输出 2。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3057 [USACO12NOV] Distant Pastures S
// 格子=点，相邻边权 A(同草)/B(异草)；答案=图直径。
// V<=900：Floyd 7.3e8 危险，多源 Dijkstra ~3e7 稳过。B<A 时最短路会绕路，不能套曼哈顿公式。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{905};
constexpr i64 inf{1145141919810};
constexpr int dr[4]{-1,1,0,0},dc[4]{0,0,-1,1};

int n,A,B;
char g[35][35];
i64 dis[mxn],ans;
bool vis[mxn];

void dij(int s)
{
	fill_n(dis,n*n,inf);	// 每轮必须重填 INF，全局 0 不是无穷
	fill_n(vis,n*n,false);
	priority_queue<pair<i64,int>,vector<pair<i64,int>>,greater<>>Q;
	dis[s]=0;
	Q.emplace(0,s);
	while(!Q.empty())
	{
		auto[d,u]=Q.top();Q.pop();
		if(vis[u])
			continue;	// 惰性删除：过期条目
		vis[u]=true;
		int r=u/n,c=u%n;
		for(int k=0;k<4;++k)
		{
			int nr=r+dr[k],nc=c+dc[k];
			if(nr<0||nr>=n||nc<0||nc>=n)
				continue;
			int v=nr*n+nc;
			i64 w=g[nr][nc]==g[r][c]?A:B;
			if(dis[u]+w<dis[v])
				dis[v]=dis[u]+w,Q.emplace(dis[v],v);
		}
	}
	for(int i=0;i<n*n;++i)
		ans=max(ans,dis[i]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>A>>B;
	for(int i=0;i<n;++i)
		cin>>g[i];
	for(int s=0;s<n*n;++s)
		dij(s);
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 邻接关系在松弛时现算（`r=u/n,c=u%n` + 四方向），省掉建图代码；边权 `g[nr][nc]==g[r][c]?A:B` 一行搞定两种草。
- `dis` 用 `i64`：真实距离其实 $\le 5.8\times 10^7$ 装得下 `int`，但 INF 参与加法时用 64 位一劳永逸。
- 每轮 Dijkstra 前 `fill_n` 重置 `dis` 与 `vis`——多源复用全局数组时漏重置是经典静默错误。
- 零权边（$A=0$ 或 $B=0$）不需要任何特判：Dijkstra 的正确性只要求非负。
- `ans` 全局初值 0 恰好正确：$\delta(s,s)=0$ 保证直径 $\ge 0$，$N=1$ 时直接输出 0。
