# P3062 [USACO12DEC] Wifi Setup S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 数轴上 $N$ 头奶牛（$1\le N\le 2000$），位置为 $[0,10^6]$ 的**互不相同**的整数。要安装若干无线基站覆盖所有牛：功率 $r$ 的基站花费 $A+B\cdot r$（$0\le A,B\le 1000$），装在位置 $x$ 可覆盖 $[x-r,x+r]$ 内的所有牛；$r=0$ 合法（只覆盖同位置的牛）。基站位置与 $r$ 都可以是任意实数（样例就用了 $3.5$）。求最小总花费。

**输出口径。** 题面只说"输出最小成本"。由样例解释（$A=20,B=5$，牛 $0,7,100$，最优 $37.5+20=57.5$）可知答案可以是半整数；后文会证明答案**一定是 $0.5$ 的整数倍**。按原题惯例：答案是整数就输出整数，否则输出形如 `57.5` 的一位小数。

**第一步：排序。** 牛在数轴上，覆盖区间也是数轴上的区间，位置无序毫无意义——先排序，$x_0<x_1<\dots<x_{N-1}$。

**第二步：单个基站的最优形态。** 若一个基站负责覆盖牛 $x_j..x_{i-1}$（排序后的一段），它至少要罩住 $x_j$ 和 $x_{i-1}$，故 $r\ge(x_{i-1}-x_j)/2$；取等号时装在中点 $(x_j+x_{i-1})/2$，花费 $A+\frac B2(x_{i-1}-x_j)$。**中点 + 半跨度**是覆盖一段牛的最便宜单基站，没有之一。这也解释了为什么答案以 $0.5$ 为粒度：$x$ 是整数，$B$ 是整数，$\frac B2(x_{i-1}-x_j)$ 是 $0.5$ 的倍数。

**第三步：关键结构断言——最优解里每个基站恰好负责一段连续的牛。** 直觉上"区间覆盖区间"不该交叉，但直觉会骗人：两个基站的覆盖范围完全可以重叠，甚至一个包另一个。需要一个**交换论证**把任意最优解"梳理"成"连续分段、每段一个中点基站"的规范形，且花费不增。这是全题唯一非平凡的性质，第二部分用"跨度势函数"严格证明：交叉或嵌套的两段可以重排成左右两段，总跨度严格变小，而花费 $\le$ 原花费；势函数（总跨度）是非负整数，严格递减必然终止，终止时就是连续分段。

**第四步：DP。** 有了规范形，设 $f[i]=$ 覆盖前 $i$ 头牛的最小花费。枚举最后一段的起点 $j$：
$$f[i]=\min_{0\le j<i}\Bigl(f[j]+A+\frac B2(x_{i-1}-x_j)\Bigr),\quad f[0]=0.$$
$O(N^2)=4\times 10^6$，已经能过。

**第五步：消分数。** $\frac B2$ 是小数，浮点累加 $2000$ 次虽然这题量级小不至于翻车，但完全没必要：**全程乘 2**。令 $F[i]=2f[i]$，转移变成纯整数
$$F[i]=\min_{0\le j<i}\bigl(F[j]+2A+B(x_{i-1}-x_j)\bigr).$$
最后 $F[N]$ 是偶数就输出 $F[N]/2$，是奇数就输出 `F[N]/2` 加 `.5`。零浮点，零误差。

**第六步：还能更快——转移可分离。** 盯着转移式看：
$$F[i]=2A+B\cdot x_{i-1}+\min_{0\le j<i}\bigl(F[j]-B\cdot x_j\bigr).$$
对固定的 $i$，$2A+B x_{i-1}$ 是常数，min 里的东西**只依赖 $j$**！维护前缀最小值 $mn=\min_{j<i}(F[j]-Bx_j)$，每步 $O(1)$ 转移、$O(1)$ 更新，总复杂度降到排序的 $O(N\log N)$。$N\le 2000$ 用不上这份富余，但"把 $\min$ 里与 $i$ 无关的部分提出来"是 DP 优化的通用第一招，值得写进题解。

**手造数据核对。** 题面 Hint 给了样例说明，按 Input Format 组装：

第一组（Hint 原例）：$N=3,A=20,B=5$，位置 $7,0,100$。排序 $0,7,100$。$\{0,7\}$ 一个中点基站 $r=3.5$ 花 $37.5$，$\{100\}$ 一个 $r=0$ 花 $20$，共 $57.5$；一个基站罩全部要 $r=50$ 花 $270$；三个 $r=0$ 花 $60$。最优 `57.5`。

第二组（$A$ 大 $B$ 小，倾向合并）：$N=2,A=10,B=1$，位置 $0,100$。合并花 $10+50=60$，分开花 $20$。输出 `20`。

第三组（$A=0$，免费建站）：$N=2,A=0,B=1$，位置 $0,100$。每头牛一个 $r=0$ 基站，花费 `0`。

第四组（$B=0$，功率免费）：$N=3,A=7,B=0$，位置 $1,5,9$。一个基站罩全部花 `7`。

第五组（单牛）：$N=1,A=5,B=3$，位置 $10$。$r=0$ 花 `5`。

第六组（密集牛）：$N=4,A=10,B=2$，位置 $0,1,2,3$。一个基站 $r=1.5$ 花 $13$，优于任何拆分。输出 `13`。

## 二、思维链：完整证明

**记号。** 排序后位置 $x_0<\dots<x_{N-1}$（整数）。一个**方案**是有限个基站 $(p_t,r_t)$，$r_t\ge 0$，覆盖条件：每头牛至少落在一个 $[p_t-r_t,p_t+r_t]$ 内。花费 $\mathrm{cost}=\sum_t(A+Br_t)$。$\mathrm{OPT}$ 为最小花费。一段牛 $x_j..x_{i-1}$ 的**跨度** $\mathrm{span}=x_{i-1}-x_j$（单牛跨度 $0$）。

---

### 引理 1（收缩：基站可换成"所负责牛集的中点基站"，花费不增）

给定方案与一个"每头牛指派给一个覆盖它的基站"的指派。把每个基站替换为**它被指派到的牛集**的中点基站（中心 $(L+R)/2$、半径 $(R-L)/2$，$L,R$ 为该牛集最小/最大位置）；没被指派到牛的基站直接删除。则新方案仍覆盖所有牛，且花费不增。

*证明*：覆盖性：每头牛仍被"它指派到的那个基站"的新形态覆盖（新基站罩住整个指派牛集）。花费：原基站罩住其指派牛集，故其区间包含 $[L,R]$，半径 $r\ge(R-L)/2$，于是 $A+Br\ge A+\frac B2(R-L)$，恰为新基站花费；删除空基站只会再省 $A\ge 0$。逐基站不增，求和不增。证毕。

此后每个基站对应一个非空牛集，花费恰为 $A+\frac B2\mathrm{span}$，各牛集构成牛的一个划分。

---

### 引理 2（解交叉 / 解嵌套：总跨度严格下降的交换）

设两个牛集 $S_1,S_2$（引理 1 后的形态）。若它们的跨度区间**交叉**（存在 $a,b\in S_1,c,d\in S_2$ 使 $a<c<b<d$）或**嵌套**（一个的跨度区间真包含另一个），则可以把 $S_1\cup S_2$ 重新划分为左右两个非空牛集 $U_L,U_R$（$U_L$ 的所有位置 $<U_R$ 的所有位置），换成各自的中点基站，使
$$\mathrm{span}(U_L)+\mathrm{span}(U_R)\ <\ \mathrm{span}(S_1)+\mathrm{span}(S_2),$$
从而这两段的花费严格下降（$A$ 的份数不变，都是 2）。

*证明*：记 $U=S_1\cup S_2$，$\mathrm{span}(U)=\max U-\min U$。把 $U$ 在某个"间隙"（相邻两元素之间）切开成左右两段，则
$$\mathrm{span}(U_L)+\mathrm{span}(U_R)=\mathrm{span}(U)-\text{间隙宽度}. \tag{$\ast$}$$
（左段跨度 = 切点左元素 $-\min U$，右段跨度 = $\max U-$ 切点右元素，相加即得。）

**嵌套情形**：设 $\mathrm{span}(S_2)$ 区间真含于 $\mathrm{span}(S_1)$ 区间，则 $\mathrm{span}(U)=\mathrm{span}(S_1)$。任取一个间隙切开，由 $(\ast)$，新跨度和 $=\mathrm{span}(S_1)-\text{间隙}<\mathrm{span}(S_1)\le\mathrm{span}(S_1)+\mathrm{span}(S_2)$（间隙 $\ge 1$，位置是互异整数）。✓

**交叉情形**：在所有交叉四元组 $(a,c,b,d)$ 中取 **$b-c$ 最小**的一个。断言：$c,b$ 在 $U$ 中相邻。否则存在 $e\in U$，$c<e<b$：若 $e\in S_1$，则 $(a,c,e,d)$ 是交叉（$a<c<e<d$，$a,e\in S_1$，$c,d\in S_2$）且 $e-c<b-c$，矛盾；若 $e\in S_2$，则 $(a,e,b,d)$ 是交叉（$a<e<b<d$）且 $b-e<b-c$，矛盾。故在 $c,b$ 之间切开，间隙 $=b-c$。另一方面，$[c,b]\subseteq\mathrm{span}(S_1)\cap\mathrm{span}(S_2)$（$\mathrm{span}(S_1)\supseteq[a,b]$，$\mathrm{span}(S_2)\supseteq[c,d]$），两区间长度和 $=$ 并长 $+$ 交长 $\ge\mathrm{span}(U)+(b-c)$。代入 $(\ast)$：
$$\text{新跨度和}=\mathrm{span}(U)-(b-c)\le\bigl(\mathrm{span}(S_1)+\mathrm{span}(S_2)\bigr)-2(b-c)<\text{旧跨度和}.$$
✓。两种情形都保持"每个牛集被其中点基站覆盖"，且 $U_L,U_R$ 非空（切点在 $U$ 内部）。证毕。

---

### 引理 3（规范形定理：$\mathrm{OPT}=$ 连续分段、每段一个中点基站的最优花费）

存在最优方案，其基站与"排序后牛的连续分段"一一对应，每段基站位于中点、半径为半跨度。从而
$$\mathrm{OPT}=\min_{\text{连续分段}}\ \sum_{\text{段}}\Bigl(A+\frac B2\mathrm{span}\Bigr).$$

*证明*：**（$\ge$）** 取任一最优方案，任取一个合法指派，先做引理 1 的收缩（花费不增）。然后只要还存在交叉或嵌套的两段，就做引理 2 的交换。势函数 $\Phi=\sum\mathrm{span}$ 是非负整数，每次交换严格下降至少 $1$，故有限步终止。终止时无交叉无嵌套。断言此时各牛集**两两分离**（一个的最大位置 $<$ 另一个的最小位置）：若两段不分离，其跨度区间相交；相等不可能（牛集不交、位置互异）；真包含是嵌套，部分重叠则取 $a=\min S_1,c=\min S_2,b=\max S_1,d=\max S_2$ 构成交叉（$a<c<b<d$，其中 $c<b$ 因为若 $c=b$ 则两集共享位置 $c$，矛盾）——都已排除。两两分离的划分按位置排序就是连续分段，每段恰好一个中点基站，花费 $\le\mathrm{OPT}$。

**（$\le$）** 任何连续分段方案都是合法方案（中点基站罩住整段），故 $\mathrm{OPT}\le$ 右端。夹逼得等号。证毕。

**注**：这条定理同时说明最优解中基站数 $\le N$、位置是整数或半整数、半径是半跨度——答案必为 $0.5$ 的整数倍（$A,B,x$ 皆整数）。

---

### 引理 4（DP 正确性）

令 $F[0]=0$，$F[i]=\min_{0\le j<i}\bigl(F[j]+2A+B(x_{i-1}-x_j)\bigr)$（$1\le i\le N$）。则 $F[i]=2\times$（覆盖前 $i$ 头牛的最小花费）。

*证明*：对 $i$ 归纳。$i=0$：空集花费 $0$ ✓。设结论对 $<i$ 成立。由引理 3（限制在前 $i$ 头牛上，论证完全相同），最优方案是连续分段；设最后一段为 $x_j..x_{i-1}$，则其余段是前 $j$ 头牛的一个合法分段方案，花费 $\ge F[j]/2$（归纳假设），最后一段花费 $A+\frac B2(x_{i-1}-x_j)$。故最优 $\ge\min_j(F[j]/2+A+\frac B2(x_{i-1}-x_j))=F[i]/2$。反之对任一 $j$，"前 $j$ 头的最优方案 + 最后一段中点基站"是前 $i$ 头的合法方案，花费 $=F[j]/2+A+\frac B2(x_{i-1}-x_j)$，故最优 $\le F[i]/2$。夹逼得等号。证毕。

---

### 引理 5（前缀最小值优化）

$F[i]=2A+B\cdot x_{i-1}+mn_i$，其中 $mn_i=\min_{0\le j<i}(F[j]-B\cdot x_j)$；且 $mn_{i+1}=\min(mn_i,\ F[i]-B\cdot x_i)$。从而全部 $F$ 可在 $O(N)$ 时间（排序后）算出。

*证明*：转移式中 $2A+B x_{i-1}$ 与 $j$ 无关，提出 min 号即得第一式（min 的线性平移不变性：$\min_j(c+t_j)=c+\min_j t_j$）。第二式：$mn_{i+1}$ 的候选集比 $mn_i$ 恰多一个 $j=i$，取 min 即增量更新。初值 $mn_1=F[0]-Bx_0=-Bx_0$。每步 $O(1)$，共 $N$ 步。证毕。

---

### 引理 6（整数化与输出格式）

$F[i]$ 全程为整数，$F[N]=2\,\mathrm{OPT}$。若 $F[N]$ 偶，输出 $F[N]/2$；若奇，输出 $\lfloor F[N]/2\rfloor$ 后接 `.5`。该输出恰为 $\mathrm{OPT}$ 的十进制表示。

*证明*：$2A,B,x$ 皆整数，转移只有整数加减与 min，归纳得 $F$ 皆整数；$F[N]=2\,\mathrm{OPT}$ 由引理 4。$\mathrm{OPT}=F[N]/2$：偶时是整数 $F[N]/2$；奇时 $F[N]=2q+1$（$q=\lfloor F[N]/2\rfloor$，$F[N]\ge 0$），$\mathrm{OPT}=q+0.5$，十进制恰为 `q.5`。C++ 非负整数除法向零截断即向下取整，`f[n]/2` 正确。证毕。

---

### 引理 7（复杂度与数值范围）

时间 $O(N\log N)$（排序主导），空间 $O(N)$。`i64` 必需。

*证明*：排序 $O(N\log N)$；DP 由引理 5 为 $O(N)$。数值：$F[N]\le N(2A+B\cdot 10^6)\le 2000\times(2000+10^9)\approx 2\times 10^{12}$，远超 `int`（$2.1\times 10^9$），必须 `i64`；中间量 $F[j]-Bx_j\ge -10^9$，$mn+2A+Bx_{i-1}\le 2\times 10^{12}+10^9$，均在 `i64` 内。空间 $O(N)$ 两个数组。证毕。

---

### 定理

程序输出覆盖所有奶牛的最小成本（整数或 `.5` 形式），复杂度 $O(N\log N)$。

*证明*：引理 1、2、3 把任意最优解无损地归约为"连续分段 + 每段中点基站"；引理 4 证明该结构上的 DP 恰为最优值的两倍；引理 5 把 DP 优化到线性；引理 6 保证整数运算与输出格式精确；引理 7 给出复杂度与 64 位必要性。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 覆盖一段牛的最便宜单基站 = 中点 + 半跨度，花费 $A+\frac B2\mathrm{span}$；答案粒度必为 $0.5$。
2. **consider easier version** — 先假设"每个基站负责连续一段"，直接写出 $O(N^2)$ 分段 DP。
3. **explore its property** — 补上结构证明：收缩到中点（引理 1）+ 解交叉/解嵌套的跨度势函数交换（引理 2），终止即连续分段（引理 3）。
4. **reduce to easier problem** — 全程乘 2 消半整数：$F[i]=\min_j(F[j]+2A+B(x_{i-1}-x_j))$，纯整数 DP，输出按奇偶拼 `.5`。
5. **classic problem solution** — 转移可分离：$F[i]=2A+Bx_{i-1}+\min_{j<i}(F[j]-Bx_j)$，前缀 min 增量维护，$O(N^2)\to O(N)$。
6. **explore its property** — 数值体检：$F\le 2\times 10^{12}$ 必须 `i64`；$A=0/B=0/N=1$ 各退化情形手算核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,A,B` | 牛数、固定成本、单位距离成本 | `int` | 读入 |
| `x[i]` | 排序后第 $i$ 头牛位置，0-based | `int[mxn]`，`mxn{2005}` | 读入后 `sort` |
| `f[i]` | 覆盖前 $i$ 头牛的最小花费的 **2 倍**（半成本单位） | `i64[mxn]` | `f[0]=0`（全局默认）；其余递推 |
| `mn` | $\min_{j<i}(F[j]-B\cdot x_j)$ | `i64` | 初值 $-B\cdot x_0$（只有 $j=0$）；记忆点：把与 $i$ 无关的部分攒起来 |
| `i` | 当前要覆盖前 $i$ 头牛 | `int` | $1..N$；最后一段是 $x_j..x_{i-1}$ |

### 算法步骤

1. I/O 加速三行；读 $N,A,B$ 与位置数组，排序。
2. `mn = -B*x[0]`（对应 $j=0$，$F[0]=0$）。
3. 对 $i=1..N$：`f[i] = mn + 2*A + B*x[i-1]`；若 $i<N$，`mn = min(mn, f[i]-B*x[i])`。
4. `f[n]` 偶则输出 `f[n]/2`；奇则输出 `f[n]/2` 与 `".5"`。

### 复杂度

- 时间 $O(N\log N)$（排序；DP 本身 $O(N)$，朴素 $O(N^2)$ 也绰绰有余）；空间 $O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Hint 样例输出 `57.5`；另 5 组手造边界（$A$ 大 $B$ 小、$A=0$、$B=0$、单牛、密集）与手算一致；前缀 min 版与朴素 $O(N^2)$ 双倍成本 DP 在多组随机小数据上输出一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3062 [USACO12DEC] Wifi Setup S
// 最优解 = 连续分段，每段一个中点基站，花费 A+B*span/2。
// 全程乘 2 化整数：F[i]=min_j(F[j]+2A+B*(x[i-1]-x[j]))。
// 转移可分离 ⇒ 前缀 min 维护 F[j]-B*x[j]，O(N) 完成 DP。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005};

int n,A,B,x[mxn];
i64 f[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>A>>B;
	for(int i=0;i<n;++i)
		cin>>x[i];
	sort(x,x+n);
	i64 mn=-(i64)B*x[0];	// min_{j<i}(f[j]-B*x[j])，初始只有 j=0（f[0]=0）
	for(int i=1;i<=n;++i)
	{
		f[i]=mn+2*A+(i64)B*x[i-1];	// 最后一段 x[j..i-1]，j 由 mn 隐含取最优
		if(i<n)
			mn=min(mn,f[i]-(i64)B*x[i]);
	}
	if(f[n]%2==0)
		cout<<f[n]/2<<'\n';
	else
		cout<<f[n]/2<<".5\n";	// 答案必为 0.5 的整数倍
	return 0;
}
```

### 代码说明

- `f` 的单位是**半成本**（真实花费的 2 倍），转移里 `2*A` 与 `B*(x[i-1]-x[j])` 都是整数，全程无浮点。
- `mn` 的初值是 `-B*x[0]` 而不是 0：$j=0$ 项是 $F[0]-Bx_0=-Bx_0$，漏掉 $-Bx_0$ 会在第一段就错。
- `if(i<n)` 的守卫：$i=N$ 时 `x[i]` 越界，且最后一轮不再需要更新 `mn`。
- `B*x[i]` 可达 $10^9$，`f` 可达 $2\times 10^{12}$，所有乘法前先转 `i64`，否则 `int` 乘法静默溢出。
- 输出分支：`f[n]` 非负，`/2` 向零截断即下取整，奇数时整数部分恰为 `f[n]/2`，拼 `.5` 即可。
- 本题没有"不可达"状态（任何前缀都能被覆盖），故不需要 INF；`f[0]=0` 靠全局零初始化恰好正确。
