# P3028 [USACO10OCT] Soda Machine G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 数轴上有 $N$ 个闭区间 $[A_i,B_i]$（$1\le A_i\le B_i\le 10^9$，$N\le 5\times 10^4$）。选一个整数点 $x\in[1,10^9]$，被覆盖的区间数记为 $\mathrm{cnt}(x)=\#\{i:A_i\le x\le B_i\}$。求 $\max_x \mathrm{cnt}(x)$。就是经典的**最多区间重叠数**。

**第一步：值域否掉朴素做法。** 对每个 $x$ 扫所有区间是 $O(10^9\cdot N)$；就算开差分数组，$10^9$ 的下标也开不下。但 $N\le 5\times 10^4$ 很小——**信息量只有 $2N$ 个端点**，$10^9$ 的值域是虚胖。两条路：离散化 + 差分，或者事件排序扫描线。后者不用显式离散化，代码更短，我选它。

**第二步：把区间拆成两个事件。** 区间 $[A,B]$ 对 $\mathrm{cnt}$ 的贡献是：从 $A$ 起 $+1$，从 $B+1$ 起 $-1$（闭区间，$B$ 本身仍被覆盖，所以撤走发生在 $B+1$）。把 $2N$ 个事件 $(A_i,+1),(B_i+1,-1)$ 按坐标排序，从小到大扫，维护运行和 $s$，$s$ 就是"当前点的覆盖数"，全程取 max 即答案。

**第三步：撞一个隐蔽的坑——同坐标事件的顺序。** 排序时若两个事件坐标相同，先处理谁？考虑相邻区间 $[1,2]$ 和 $[3,4]$：真实答案是 $1$（没有公共点）。事件是 $(1,+1),(3,-1),(3,+1),(5,-1)$。若在坐标 3 处**先 $+1$ 后 $-1$**，运行和会瞬间变成 $2$——把"2 结束"和"3 开始"错当成同时覆盖，答案错成 2！所以同坐标必须**先处理 $-1$ 再处理 $+1$**：先撤走所有在 $x-1$ 处结束的区间，再让从 $x$ 开始的区间进场。妙处在于：把事件存成 `pair<int,int>{坐标,±1}` 用默认字典序排序，$-1<+1$，**自动**就是"先撤后进"，一行都不用多写。

**第四步：为什么扫事件点就够了？** $\mathrm{cnt}(x)$ 是分段常值函数，只在 $A_i$ 与 $B_i+1$ 处跳变。两个相邻事件坐标之间 $\mathrm{cnt}$ 不变，所以最大值必在"某个事件坐标处、该坐标全部事件处理完之后"取到。而"先 $-1$ 后 $+1$"的顺序保证：处理到坐标 $x$ 的最后一个事件时，运行和恰等于 $\mathrm{cnt}(x)$；中途的瞬时值要么等于 $\mathrm{cnt}(x)$ 要么更小（还没进完场），**不会虚高**。于是"每处理一个事件就取一次 max"既不漏也不冒。

**第五步：边界核对。** $B_i+1\le 10^9+1<2^{31}$，`int` 装得下；答案 $\le N\le 5\times 10^4$，`int` 够；最优点一定落在某个 $[A_i,B_i]\subseteq[1,10^9]$ 内，不会越出题面允许的安装范围；$N=1$ 时答案 1。

**手造数据核对。**

第一组（题面例子）：$[3,5],[4,8],[1,2],[5,10]$。$x=5$ 被第 1、2、4 个区间覆盖，答案 $3$。✓

第二组（相邻陷阱）：$[1,2],[3,4]$。答案 $1$。若同坐标顺序写错会输出 2，这组专门抓这个 bug。

第三组（单点区间）：$[5,5],[5,5],[6,6]$。$x=5$ 覆盖 2 个，答案 $2$。抓"$B$ 处仍覆盖、$B+1$ 才撤"的闭区间语义。

第四组（单区间）：$[1,10^9]$。答案 $1$，顺带验证大坐标不溢出。

## 二、思维链：完整证明

**记号。** 区间 $I_i=[A_i,B_i]$，$i\in\{0,\dots,N-1\}$。覆盖函数 $\mathrm{cnt}(x)=\#\{i:A_i\le x\le B_i\}$，$x\in\mathbb Z$。事件多重集 $\mathcal E=\{(A_i,+1)\}\cup\{(B_i+1,-1)\}$，共 $2N$ 个。按（坐标, 增量）字典序升序排成 $e_1,\dots,e_{2N}$，$e_t=(x_t,d_t)$。运行和 $s_t=\sum_{u\le t}d_u$。算法输出 $\max_t s_t$。

---

### 引理 1（$\mathrm{cnt}$ 的分段常值结构与最大值位置）

对任意整数 $x$，$\mathrm{cnt}(x)=\#\{i:A_i\le x\}-\#\{i:B_i+1\le x\}$。$\mathrm{cnt}$ 只在事件坐标处可能变化；$\max_{x\in[1,10^9]}\mathrm{cnt}(x)$ 必在某个 $A_i$ 处取到（$N\ge 1$ 时）。

*证明*：第一式：$A_i\le x\le B_i\iff A_i\le x\land\lnot(B_i+1\le x)$，而 $A_i\le B_i$ 保证 $\{B_i+1\le x\}\subseteq\{A_i\le x\}$，故满足前者的 $i$ 数 = 两个计数之差。

变化位置：$\mathrm{cnt}(x)-\mathrm{cnt}(x-1)=\#\{i:A_i=x\}-\#\{i:B_i+1=x\}$，非事件坐标处两项皆 0，函数值不变。

最大值位置：$\mathrm{cnt}$ 在 $(-\infty,\min A_i)$ 上为 0，在 $[\max B_i+1,\infty)$ 上为 0，中间分段常值。设最大值 $m\ge 1$（$N\ge 1$ 时 $\mathrm{cnt}(A_0)\ge 1$），取达到 $m$ 的最小整数 $x^\*$。若 $x^\*$ 不是任何 $A_i$：由第一式，$\mathrm{cnt}(x^\*)-\mathrm{cnt}(x^\*-1)=-\#\{i:B_i+1=x^\*\}\le 0$，故 $\mathrm{cnt}(x^\*-1)\ge m$，与 $x^\*$ 最小矛盾。所以 $x^\*$ 是某个 $A_i$，且 $x^\*\in[A_i,B_i]\subseteq[1,10^9]$，落在合法安装范围内。证毕。

---

### 引理 2（同坐标"先 $-1$ 后 $+1$"下，运行和的精确刻画）

按（坐标, 增量）字典序排序后，对每个 $t$：
$$s_t=\#\{i:A_i\le x_t\}-\#\{i:B_i+1\le x_t\}-\#\{u>t:x_u=x_t,\ d_u=+1\}.$$
特别地，(a) 若 $e_t$ 是坐标 $x_t$ 的**最后一个**事件，则 $s_t=\mathrm{cnt}(x_t)$；(b) 对一切 $t$，$s_t\le\mathrm{cnt}(x_t)$。

*证明*：$s_t$ 是前 $t$ 个事件的增量和。全体坐标 $\le x_t$ 的事件中，前 $t$ 个包含了：所有坐标 $<x_t$ 的事件（排序保证），以及坐标 $=x_t$ 的事件中排在 $e_t$ 及之前的。坐标 $=x_t$ 的事件按增量排序，$-1$ 全部在 $+1$ 之前，故"排在 $e_t$ 之后且同坐标"的只可能是 $+1$ 事件（若 $e_t$ 本身是 $-1$，则同坐标的 $+1$ 全在其后；若 $e_t$ 是 $+1$，则其后同坐标的也都是 $+1$）。于是
$$s_t=\underbrace{\#\{A_i\le x_t\}-\#\{B_i+1\le x_t\}}_{=\ \mathrm{cnt}(x_t)\text{（引理 1）}}-\#\{u>t:x_u=x_t,d_u=+1\},$$
即所证等式。(a)：最后一个事件之后没有同坐标事件，修正项为 0。(b)：修正项非负。证毕。

**这条引理同时解释了错误顺序为何致命**：若同坐标先 $+1$ 后 $-1$，则处理 $+1$ 时"尚未处理的同坐标事件"里含 $-1$，修正项变号，$s_t$ 可能**超过** $\mathrm{cnt}(x_t)$——把已在 $x_t-1$ 结束的区间误计入 $x_t$。反例：$[1,2],[3,4]$，在 $x=3$ 先处理 $(3,+1)$ 得 $s=2>\mathrm{cnt}(3)=1$。

---

### 引理 3（算法输出 = 最优值）

$\max_{1\le t\le 2N}s_t=\max_{x\in[1,10^9]}\mathrm{cnt}(x)$。

*证明*：($\le$)：由引理 2(b)，每个 $s_t\le\mathrm{cnt}(x_t)$。事件坐标 $x_t\in\{A_i\}\cup\{B_i+1\}$：若 $x_t=A_i\in[1,10^9]$，则 $\mathrm{cnt}(x_t)\le$ 右端；若 $x_t=B_i+1$ 且 $\mathrm{cnt}(x_t)>0$，则 $x_t$ 被某区间覆盖，$x_t\le B_j\le 10^9$ 且 $x_t\ge A_j\ge 1$，仍在范围内；若 $\mathrm{cnt}(x_t)=0$ 则 $s_t\le 0\le$ 右端（右端 $\ge 1$）。故左端 $\le$ 右端。

($\ge$)：由引理 1，右端在某个 $A_i$ 处取到。$A_i$ 是事件坐标，设其最后一个事件是 $e_t$，由引理 2(a)，$s_t=\mathrm{cnt}(A_i)=$ 右端。故左端 $\ge$ 右端。两边夹得相等。证毕。

---

### 引理 4（闭区间语义：为什么是 $B+1$ 而不是 $B$）

把撤走事件放在 $B_i+1$ 恰好实现闭区间 $[A_i,B_i]$；若放在 $B_i$ 会漏算端点。

*证明*：由引理 1 的计数式，区间 $i$ 对 $\mathrm{cnt}(x)$ 贡献 1 当且仅当 $A_i\le x$ 且 $B_i+1>x$，即 $A_i\le x\le B_i$，正是闭区间。若改用 $B_i$ 作撤走点，贡献条件变成 $A_i\le x<B_i$（半开区间），$x=B_i$ 处漏计。反例：$[5,5]$ 单点区间，撤走点若为 5，则事件 $(5,+1),(5,-1)$ 按先 $-1$ 后 $+1$ 排序后运行和先 $-1$ 再回 0，最大值 0，而正确答案是 1。证毕。

---

### 引理 5（值域与类型安全）

所有事件坐标 $\le 10^9+1<2^{31}-1$，运行和与答案 $\in[0,N]$，全程 `int` 安全。

*证明*：坐标来自 $A_i\le 10^9$ 或 $B_i+1\le 10^9+1=1000000001<2147483647$。运行和是若干 $\pm 1$ 的部分和：由引理 2 等式，$s_t\le\mathrm{cnt}(x_t)\le N$；下界方面，坐标 $<\min A_i$ 无事件，扫描从第一个 $+1$ 开始，且每个 $-1$ 必有配对的 $+1$ 已在其前（$A_i<B_i+1$，排序严格在前），故 $s_t\ge 0$。$N\le 5\times 10^4$，`int` 足够。证毕。

---

### 引理 6（复杂度）

时间 $O(N\log N)$，空间 $O(N)$。

*证明*：生成 $2N$ 个事件 $O(N)$；排序 $O(2N\log 2N)=O(N\log N)$；扫描 $O(N)$。代入 $N=5\times 10^4$：约 $10^5\times 17\approx 1.7\times 10^6$ 次比较。空间：事件数组 $2N$ 个 `pair<int,int>`，约 800 KB。证毕。

---

### 定理

程序输出 $\max_x\#\{i:A_i\le x\le B_i\}$，即最多能满足的奶牛数。

*证明*：引理 1 把连续值域上的最大化归约到有限个事件坐标；引理 4 保证事件构造忠实于闭区间语义；引理 2 保证排序顺序下运行和不虚高、且在每个坐标收尾处精确；引理 3 把两者串成"扫描取 max = 全局最优"；引理 5、6 保证类型与时限安全。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 覆盖数只在 $A_i$ 与 $B_i+1$ 处跳变：$10^9$ 值域里只有 $2N$ 个"有效点"。
2. **consider easier version** — 值域小就是裸差分数组；值域大而端点少 ⇒ 离散化/事件排序，把差分搬到排序后的事件轴上。
3. **classic problem solution** — 扫描线：区间拆 $(A,+1),(B+1,-1)$，排序后扫运行和取 max。
4. **explore its property** — 相邻区间 $[1,2],[3,4]$ 反例暴露同坐标顺序坑：必须先 $-1$ 后 $+1$；`pair` 默认字典序恰好免费提供这个顺序。
5. **discuss by category** — 闭区间 ⇒ 撤走点 $B+1$（单点区间 $[5,5]$ 验证）；$B+1\le 10^9+1$ 仍在 `int` 内；最优点必在某 $A_i$，不越安装范围。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N$ | 区间数 | `int n` | 读入 |
| `mxn` | $5\times 10^4+5$ | `constexpr int` | 牛数组尺寸 |
| `e[t]` | 第 $t$ 个事件 `{坐标,±1}` | `pair<int,int>[mxn*2]` | $(A_i,+1),(B_i+1,-1)$；**第二维是增量，排序时兼当"先撤后进"的键** |
| `s` | 运行和（当前覆盖数的下界，坐标收尾处精确） | `int`，初值 $0$ | 每事件 `s+=e[t].second` |
| `ans` | 最大覆盖数 | `int`，初值 $0$ | 每事件后 `ans=max(ans,s)` |
| `a,b` | 读入端点临时量 | `int` | 循环内 |

### 算法步骤

1. I/O 加速三行；读 $N$。
2. 对每个区间读 $A_i,B_i$，写入事件 `e[2i]={A_i,1}`、`e[2i+1]={B_i+1,-1}`。
3. `sort(e,e+2*n)`：默认字典序 =（坐标升序，同坐标 $-1$ 在前）。
4. 扫描：`s+=e[t].second; ans=max(ans,s);`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(N\log N)\approx 1.7\times 10^6$ 次比较。
- 空间：$O(N)\approx 800$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子（3）、相邻陷阱（1）、单点区间（2）、单区间大坐标（1）四组手造数据全部吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3028 [USACO10OCT] Soda Machine G
// 扫描线：闭区间 [A,B] 拆成 (A,+1),(B+1,-1)，排序后扫运行和取 max
// pair 默认字典序：同坐标 -1 排在 +1 前 = 先撤走再进场，杜绝相邻区间的瞬时虚高
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005};

int n;
pair<int,int>e[mxn*2];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0,a,b;i<n;++i)
	{
		cin>>a>>b;
		e[2*i]={a,1};
		e[2*i+1]={b+1,-1};	// 闭区间：B 处仍覆盖，B+1 才撤（b+1<=1e9+1 不爆 int）
	}
	sort(e,e+2*n);
	int s=0,ans=0;
	for(int t=0;t<2*n;++t)
	{
		s+=e[t].second;
		ans=max(ans,s);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **事件的第二维一石二鸟**：既是增量，又是排序键——`pair` 字典序让同坐标的 $-1$ 自动排在 $+1$ 前。若改成"先 $+1$ 后 $-1$"（比如把增量存成 $1/0$ 或自定义比较器写反），相邻区间 $[1,2],[3,4]$ 就会错出 2（引理 2 后的反例）。
- 撤走点是 `b+1` 不是 `b`：闭区间语义（引理 4），单点区间 $[5,5]$ 是最小检验。
- `ans` 初值 0 即可：$N\ge 1$ 保证答案 $\ge 1$，扫描第一个事件后 `s=1` 必然更新；这里没有"不可达"语义，不需要 INF。
- 不需要显式离散化：排序后的事件轴就是隐式离散化，`s` 只在事件点更新，两点之间的常值段由引理 1 保证不影响最大值。
- 全程 `int`：坐标 $\le 10^9+1$，和 $\le 5\times 10^4$（引理 5）。
