# P3009 [USACO11JAN] Profits S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给定 $N$ 天的利润 $P_1,\dots,P_N$（$1\le N\le 10^5$，$|P_i|\le 1000$，可正可负），求一个**连续**时间段 $[l,r]$（$1\le l\le r\le N$）使 $\sum_{i=l}^r P_i$ 最大，输出这个最大值。

剥掉奶牛生意的背景，这就是最经典的**最大非空连续子段和**。先把约束里的关键信息抠出来：

- **"连续时间的周期长度范围从第一天到第 $N$ 天"**——这句话规定了区间长度 $\in[1,N]$，即**子段非空**（$l\le r$）。这是全题最重要的隐含约束：它意味着**不能选空区间**。当所有 $P_i$ 都是负数时，答案必须是"最大的那个负数"，而**不是 $0$**。很多写法在这里翻车。
- $N\le10^5$：$O(N^2)$ 枚举所有区间是 $10^{10}$ 量级，超时；需要 $O(N)$ 或 $O(N\log N)$。
- $|P_i|\le1000$：答案绝对值 $\le N\times1000=10^8$，落在 `int`（$2.1\times10^9$）内，**不需要 `long long`**。但答案哨兵要取一个比 $-10^8$ 更小的负无穷。

**第一步：暴力为什么不行。** 枚举所有 $(l,r)$ 共 $\frac{N(N+1)}2\approx5\times10^9$ 个区间，即便用前缀和把每个区间的和压成 $O(1)$，总量仍是 $O(N^2)=10^{10}$，妥妥超时。所以必须找到"不用枚举所有区间"的结构。

**第二步：固定右端点，把二维枚举降成一维。** 我停下来想：与其枚举 $(l,r)$ 两个自由变量，不如**固定右端点 $r$**，问"以 $r$ 结尾的最优区间是什么"。设前缀和 $s_k=\sum_{i=1}^k P_i$（$s_0=0$），则区间 $[l,r]$ 的和 $=s_r-s_{l-1}$。对固定的 $r$，$s_r$ 是常数，要让和最大就要让 $s_{l-1}$ **最小**，其中 $l-1$ 取遍 $0,1,\dots,r-1$。于是

$$\text{以 }r\text{ 结尾的最优值}=s_r-\min_{0\le k<r}s_k.$$

只要一边从左往右扫 $r$，一边维护"到目前为止的最小前缀和 $\min_{k<r}s_k$"，每个 $r$ 的答案就是 $O(1)$。整体 $O(N)$。**这一步把"枚举所有区间"归约成了"扫描 + 维护一个最小值"**，是本题的第一个正解视角。

**第三步：换一个更顺手的等价写法——Kadane。** 前缀和视角要维护 $s_r$ 和 $\min s_k$ 两个量。我试着把它改写成一个变量的递推：设 $cur_r$ 为"以第 $r$ 天结尾的最大非空子段和"。以 $r$ 结尾的区间只有两种形态：

- 只含第 $r$ 天自己：和为 $P_r$；
- 由"以 $r-1$ 结尾的某个区间"向右延伸一天：和为（那个区间的和）$+P_r$，要最大就取 $cur_{r-1}+P_r$。

所以 $cur_r=\max(P_r,\ cur_{r-1}+P_r)$。这就是 **Kadane 算法**。它的直观含义是：**如果前面累加的和 $cur_{r-1}$ 是负的，那它只会拖后腿，不如丢掉、从 $P_r$ 重新开始**；如果 $cur_{r-1}\ge0$，就接着累加。最终答案 $=\max_r cur_r$。一个变量 `cur` 滚动、一个变量 `ans` 取全程最大，$O(N)$ 时间 $O(1)$ 空间，比前缀和写法还省。

**第四步：死磕"非空"这个坑。** 这是本题真正的分水岭。网上很多 Kadane 模板写成 `cur=max(0,cur+x); ans=max(ans,cur);`，初值 `cur=ans=0`。这个版本**允许空区间**（`cur` 被 `0` 兜底），对"全负"数据会输出 $0$。但本题区间长度 $\ge1$，全负时正确答案是最大单元素（负数）。

我构造反例确认：$P=[-3,-1,-2]$。允许空区间的版本输出 $0$；本题正确答案是 $-1$（选第 $2$ 天）。两者不同，**必须用非空版本**。非空版本的关键就是把递推写成 `cur=max(x,cur+x)`（**不**和 $0$ 取 max），这样 `cur` 永远代表一个真实存在的非空区间；`ans` 初值设成负无穷哨兵 `-1145141919`（$\approx-1.14\times10^9<-10^8$），保证第一个 `cur` 一定能更新它。第一天读入 $x$ 时 `cur` 全局初值 $0$，`max(x,0+x)=x`，恰好就是"只含第一天"，无需特殊初始化。

**第五步：范围与哨兵。** 答案 $\in[-10^8,10^8]$，`int` 装得下。哨兵 `-1145141919` 比最小可能答案 $-10^8$ 还小，且 `cur+x` 的中间量绝对值 $\le10^8+1000$，远不溢出 `int`。全程 `int` 即可，不必 `long long`。

**手造数据核对**（题面样例解释只说"取 $[2,6]$ 得 $14$"，我据此反推出利润序列，再另造全负、单元素、全正三组打边界）：

第一组，按样例解释反推（$N=7$，$P=[-5,3,-1,6,2,4,-8]$，$[2,6]=3-1+6+2+4=14$）：

```
输入：
7
-5
3
-1
6
2
4
-8
输出：14
```

与样例解释"取区间 $[2,6]$ 的和得到最大值 $14$"吻合。

第二组，全负（$P=[-3,-1,-2]$）：

```
输出：-1
```

专门验证"非空"约束：答案是最大单元素 $-1$，**不是** $0$。

第三组，单元素正 / 负（$P=[5]$ 与 $P=[-5]$）：

```

```


整段全选，$1+2+3+4=10$。四组覆盖"正常混合 / 全负 / 单元素 / 全正"四类。

## 二、思维链：完整证明

**记号。** 利润序列 $P_1,\dots,P_N$。前缀和 $s_k=\sum_{i=1}^k P_i$，$s_0=0$。区间 $[l,r]$ 的和 $\Sigma(l,r)=\sum_{i=l}^r P_i=s_r-s_{l-1}$。定义 $cur_r=\max_{1\le l\le r}\Sigma(l,r)$（以 $r$ 结尾的最大**非空**子段和），答案 $A=\max_{1\le r\le N}cur_r$。

---

### 引理 1（Kadane 递推的正确性）

对 $r\ge1$，$cur_r=\max(P_r,\ cur_{r-1}+P_r)$，其中约定 $cur_0$ 不参与（$r=1$ 时 $cur_1=P_1$）。

*证明*：以 $r$ 结尾的非空区间 $[l,r]$ 按左端点 $l$ 分两类，穷尽所有可能：

- **$l=r$**：区间只含第 $r$ 天，$\Sigma(r,r)=P_r$。
- **$l<r$**：区间 $[l,r]=[l,r-1]$ 向右延伸一天，$\Sigma(l,r)=\Sigma(l,r-1)+P_r$。这类区间的最大值 $=\max_{1\le l\le r-1}\bigl(\Sigma(l,r-1)+P_r\bigr)=\bigl(\max_{1\le l\le r-1}\Sigma(l,r-1)\bigr)+P_r=cur_{r-1}+P_r$（$P_r$ 是与 $l$ 无关的常数，可提出 max）。

两类取最大即 $cur_r=\max(P_r,\ cur_{r-1}+P_r)$。

**基础 $r=1$**：以 $1$ 结尾的非空区间只有 $[1,1]$，$cur_1=P_1$。代码中 `cur` 全局初值 $0$，第一天执行 `cur=max(P_1,0+P_1)=P_1`，与 $cur_1=P_1$ 一致（这里 $cur_0=0$ 只是让公式在 $r=1$ 也成立的占位，不代表真实空区间被选）。证毕。

---

### 引理 2（答案 = 所有 $cur_r$ 的最大值）

$A=\max_{1\le r\le N}cur_r$ 等于题目所求的最大非空连续子段和。

*证明*：设题目最优区间为 $[l^\*,r^\*]$，值 $A^\*=\Sigma(l^\*,r^\*)$。

**$A\ge A^\*$**：$[l^\*,r^\*]$ 是以 $r^\*$ 结尾的非空区间，故 $cur_{r^\*}\ge\Sigma(l^\*,r^\*)=A^\*$（$cur_{r^\*}$ 是这类区间的最大值）。而 $A=\max_r cur_r\ge cur_{r^\*}\ge A^\*$。

**$A\le A^\*$**：对每个 $r$，$cur_r$ 由某个真实区间 $[l_r,r]$ 取到（引理 1 的两类都对应真实区间），故 $cur_r=\Sigma(l_r,r)\le A^\*$（$A^\*$ 是全局最优）。于是 $A=\max_r cur_r\le A^\*$。

两向夹逼得 $A=A^\*$。证毕。

---

### 引理 3（非空约束与全负情形）

递推 $cur_r=\max(P_r,cur_{r-1}+P_r)$ 保证每个 $cur_r$ 对应一个**非空**区间；当所有 $P_i<0$ 时，$A=\max_i P_i$（最大单元素，为负），而非 $0$。

*证明*：**非空性**：对 $r$ 归纳。$cur_1=P_1$ 对应 $[1,1]$，非空。设 $cur_{r-1}$ 对应某非空区间 $[l,r-1]$。$cur_r$ 取 $P_r$（对应 $[r,r]$，非空）或 $cur_{r-1}+P_r$（对应 $[l,r]$，非空）之一，两者都非空。故 $cur_r$ 恒对应非空区间，$A$ 是某个非空区间的和，不会退化成空区间的 $0$。

**全负情形**：所有 $P_i<0$。断言 $cur_r=P_r$ 对所有 $r$ 成立。归纳：$cur_1=P_1$ ✓。设 $cur_{r-1}=P_{r-1}<0$，则 $cur_{r-1}+P_r<P_r$（因 $cur_{r-1}<0$），故 $cur_r=\max(P_r,cur_{r-1}+P_r)=P_r$ ✓。于是 $A=\max_r cur_r=\max_r P_r$，即最大单元素。因所有 $P_i<0$，$A<0$，**绝不输出 $0$**。

**对照错误版本**：若写成 $cur_r=\max(0,cur_{r-1}+P_r)$、$A=\max(0,\dots)$，则全负时 $cur_r$ 恒为 $0$、$A=0$，对应空区间，违反长度 $\ge1$。反例 $P=[-3,-1,-2]$：正确版 $A=-1$，错误版 $A=0$。故必须用非空版本。证毕。

---

### 引理 4（前缀和视角的等价性）

$A=\max_{1\le r\le N}\bigl(s_r-\min_{0\le k<r}s_k\bigr)$，与 Kadane 结果一致。

*证明*：固定 $r$，以 $r$ 结尾的区间和 $\Sigma(l,r)=s_r-s_{l-1}$，$l-1$ 取遍 $[0,r-1]$。$s_r$ 固定，故 $\max_{1\le l\le r}\Sigma(l,r)=s_r-\min_{0\le k<r}s_k=cur_r$。对 $r$ 取最大即 $A=\max_r cur_r=\max_r(s_r-\min_{k<r}s_k)$。这与引理 1、2 的 Kadane 是同一量的两种计算方式：扫描时维护"历史最小前缀和"即可 $O(1)$ 算出每个 $cur_r$。两视角等价。证毕。

**实现取舍**：前缀和视角需维护 $s_r$ 与 $\min s_k$ 两个滚动量；Kadane 只需 `cur` 一个滚动量 + `ans`，更省，故代码采用 Kadane。

---

### 引理 5（数值范围与哨兵安全）

$|A|\le N\cdot\max|P_i|\le10^5\times1000=10^8$，落在 `int` 范围；哨兵 `-1145141919`$\approx-1.145\times10^9<-10^8$，保证被第一个真实 $cur$ 更新；中间量 `cur+x` 绝对值 $\le10^8+1000$，不溢出 `int`。

*证明*：任一区间和的绝对值 $\le\sum_{i=1}^N|P_i|\le N\times1000=10^8$，故 $A\in[-10^8,10^8]\subset[-2^{31},2^{31}-1]$，`int` 安全。哨兵 $-1145141919<-10^8\le A$，故 `ans` 初值严格小于任何可能答案，第一次 `ans=max(ans,cur)` 必被更新，不会把哨兵误当答案输出。`cur` 恒为某区间和，$|cur|\le10^8$，`cur+x` 的 $|x|\le1000$，故 $|cur+x|\le10^8+1000\ll2^{31}$，无溢出。证毕。

---

### 引理 6（复杂度）

时间 $O(N)$，空间 $O(1)$。

*证明*：单趟扫描 $N$ 天，每天读入 $x$、一次 `max(x,cur+x)`、一次 `max(ans,cur)`，均 $O(1)$，故 $O(N)$。只用 `n,ans,cur,x` 常数个 `int`，无数组，空间 $O(1)$。$N=10^5$ 时约 $10^5$ 次操作，远低于时限。证毕。

---

### 定理

程序输出最大非空连续子段和 $A$，全负时输出最大单元素（负数），时间 $O(N)$、空间 $O(1)$。

*证明*：引理 1 保证 `cur` 递推正确算出每个 $cur_r$；引理 2 保证 `ans`$=\max_r cur_r=A$ 即题目最优；引理 3 保证非空约束被遵守、全负情形正确；引理 4 给出等价的前缀和视角佐证；引理 5 保证 `int` 与哨兵安全；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 剥掉背景即"最大非空连续子段和"；抠出"长度 $\in[1,N]$"⇒ 子段非空，全负时答案是最大负数而非 $0$。
2. **consider easier version** — 先想暴力枚举所有 $(l,r)$，$O(N^2)=10^{10}$ 超时，确认需要线性算法。
3. **reduce to easier problem** — 固定右端点 $r$，区间和 $=s_r-s_{l-1}$，最优 $=s_r-\min_{k<r}s_k$，把二维枚举降成"扫描 + 维护最小前缀和"。
4. **classic problem solution** — 改写成单变量递推 $cur_r=\max(P_r,cur_{r-1}+P_r)$（Kadane），$O(N)$ 时间 $O(1)$ 空间。
5. **discuss by category** — 死磕非空坑：用 `max(x,cur+x)` 而非 `max(0,cur+x)`，`ans` 设负无穷哨兵，全负反例 $[-3,-1,-2]\to-1$ 验证。
6. **explore its property** — 范围 $|A|\le10^8$ 进 `int`，哨兵 `-1145141919` 比最小答案更小，中间量不溢出。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 天数 $N\le10^5$ | `int` | 读入 |
| `x` | 当天利润 $P_i$，$\lvert x\rvert\le1000$ | `int` | 循环内读入 |
| `cur` | 以当天结尾的最大**非空**子段和 $cur_r$ | `int` | 全局默认 $0$（仅作 $r=1$ 占位）；每天 `cur=max(x,cur+x)` |
| `ans` | 全程最大子段和 $A$ | `int` | **`-1145141919`**（负无穷哨兵，必须显式设，不能靠默认 $0$） |

### 算法步骤

1. I/O 加速三行。
2. 读 `n`；`ans` 初始化为 `-1145141919`，`cur` 全局默认 $0$。
3. 对 $i=0..n-1$：读 `x`；`cur=max(x,cur+x)`；`ans=max(ans,cur)`。
4. 输出 `ans`。

### 复杂度

- 时间：$O(N)$，单趟扫描。
- 空间：$O(1)$，仅常数个 `int`，无数组。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例解释反推的 $7$ 天数据输出 $14$ 与"$[2,6]=14$"一致；全负 $[-3,-1,-2]\to-1$、单元素 $5\to5$/$-5\to-5$、全正 $[1,2,3,4]\to10$ 三组边界手算数据全对。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3009 [USACO11JAN] Profits S
// 最大非空连续子段和：Kadane，cur=max(x,cur+x)，ans 取全程最大
// 全负数据答案为最大单元素（负数），ans 哨兵必须显式设负无穷
#include<bits/stdc++.h>
using namespace std;

int n,ans{-1145141919},cur;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0,x;i<n;++i)
	{
		cin>>x;
		cur=max(x,cur+x);	// cur：以第 i 天结尾的最大非空子段和
		ans=max(ans,cur);
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **非空是灵魂**：`cur=max(x,cur+x)` 里的 `x`（而非 `0`）保证 `cur` 永远对应一个真实非空区间。写成 `max(0,cur+x)` 会允许空区间，全负数据错误地输出 $0$（引理 3 反例）。
- **`ans` 哨兵必须显式设**：全局 `int` 默认 $0$，若 `ans` 不初始化，全负数据会错误地保留 $0$。`-1145141919` 比最小可能答案 $-10^8$ 更小，第一个 `cur` 必更新它——这是"全局数组默认 0 不是负无穷"陷阱的标量版。
- **`cur` 全局默认 $0$ 恰好正确**：第一天 `max(x,0+x)=x`，正是"只含第一天"，无需额外初始化；但这个 $0$ 只是 $r=1$ 的占位，不代表选了空区间。
- **全程 `int`**：答案 $\le10^8$、中间量 $\le10^8+1000$，都不溢出（引理 5），不必 `long long`。
- $O(1)$ 空间：边读边算，不存整个数组，`cur`/`ans` 两个滚动量足矣。
