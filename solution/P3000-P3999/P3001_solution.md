# P3001 [USACO10DEC] Big Macs Around the World G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 给一张 $N\le2000$ 点、$M\le25000$ 条**有向边**的图，边 $(i,j)$ 带汇率 $e_{ij}\in[0.1,10]$（实数）。商品在起点国 $A$ 的价格为 $V$（$1\le V\le10^{12}$，**不一定是整数**）；沿一条路径 $A\to x_1\to\cdots\to B$ 换算，价格在 $B$ 国变为 $V\cdot\prod e$（连乘）。求 $B$ 国可能的**最低价格**，精确到 $10^{-6}$；若**没有最小值**（价格可以无限压低），输出 $0$。题目保证答案 $<10^{15}$、所有国家可互相兑换（强连通）。

**口径说明。** "没有最小值"指下确界为 $0$ 但取不到：只要存在一个**从 $A$ 可达、且能到达 $B$** 的"乘积 $<1$ 的环"，就能绕环任意多圈把价格压向 $0$。注意环必须**既可达又能到 $B$**——别处的套利环与 $A\to B$ 的换算无关。题面保证强连通，此时任何负环都符合条件，但我仍按一般情形实现（多一层保险，不依赖翻译可能有偏差的保证）。

**第一步：这是什么经典问题？** 路径权值是**连乘**而非连加，目标是**最小**。取对数：$\log\bigl(V\prod e\bigr)=\log V+\sum\log e$。$\log$ 严格递增，最小化乘积 $\iff$ 最小化 $\sum w$，其中 $w=\ln e\in[-\ln10,\ln10]\approx[-2.303,2.303]$。于是变成**带负权的单源最短路**——Dijkstra 立刻出局（负权破坏其贪心不变量），标准工具是 **Bellman-Ford**。而"乘积 $<1$ 的环" $\iff$ "$\sum w<0$ 的环" = **负环**：Bellman-Ford 恰好自带负环检测。整道题归约为：BF 求最短路 + 判断负环是否影响 $B$。

**第二步：为什么取对数还有数值上的必要性？** 如果直接对价格做乘法松弛 $d[v]\leftarrow d[u]\cdot e$，中间值会失控：一条 $2000$ 条边、汇率全是 $10$ 的路径乘积达 $10^{2000}$，`double`（上限 $10^{308}$）直接上溢成 `inf`；负环反复绕圈又会下溢成 $0$，让"还能改进"的检测失真。取对数后一切权值落在 $\pm2.303$，任何 $\le N-1$ 条边的路径和落在 $\pm4606$，即使 BF 中间轮次的"游走"长达 $(N-1)M$ 条边，和也不过 $\pm1.2\times10^8$——**永远不上溢不下溢**。这是本题实现上最重要的决定。

**第三步：负环检测的细节。** 标准流程：松弛 $N-1$ 轮；第 $N$ 轮若还有边能改进，说明存在从 $A$ 可达的负环。但**不能一发现负环就输出 $0$**：要检查它能否到达 $B$。做法：把第 $N$ 轮仍可改进的边的终点入队，沿出边 BFS 标记所有"受影响点"（从负环出发可达的点，价格都能被无限压低）；`bad[B]` 为真才输出 $0$。

**第四步：浮点判环的阈值。** 零环（乘积恰为 $1$，如 $0.2\times5$）不是负环，但浮点舍入会让它每圈漂移一点点，可能被误判。用 `long double`（$64$ 位尾数，单位舍入 $u\approx5.4\times10^{-20}$）：环上距离绝对值 $\le4606$，每次加法舍入 $\le4606u\approx2.5\times10^{-16}$，$N-1$ 轮里环上总松弛次数 $\le N$（每轮每条边至多一次），总漂移 $\le N\cdot2.5\times10^{-16}\approx5\times10^{-13}$。取判环阈值 $\varepsilon=10^{-11}$：比漂移上界大 $20$ 倍（不误报），又足够小（真实负环的每边改进量通常 $\gg10^{-11}$，不漏报）。松弛本身用严格 `<`，不加阈值，保证距离单调下降。

**第五步：输出精度。** 答案 $=V\cdot e^{d[B]}$。$d[B]$ 是 $\le N-1$ 个 $\ln e$ 的和，绝对误差 $\le(N-1)\cdot4606u\approx5\times10^{-13}$，经 $\exp$ 变成**相对误差** $\approx5\times10^{-13}$，远小于 $10^{-6}$ 的要求。$V$ 用 `long double` 读入（非整数！），输出 `fixed<<setprecision(6)`。注意答案可达 $10^{15}$，`double` 在该量级 ulp 已是 $0.125$，连 $10^{-6}$ 的边都摸不到——`long double`（ulp $\approx10^{-4}$）配合 SPJ 的误差容忍才稳妥；这也是全程 `f80` 的第二个理由。

**手造数据核对。**

第一组，题面例子（美国 $60$ 美元，美$\to$加 $0.2$，美$\to$英 $5$，英$\to$加 $0.5$，加$\to$美 $5$；$A=$美，$B=$加）：

```
3 4 60 1 2
1 2 0.2
1 3 5
3 2 0.5
2 1 5
```

两条路径：直接 $60\times0.2=12$；绕英 $60\times5\times0.5=150$。环 美$\to$加$\to$美 乘积 $0.2\times5=1$（零环，**不能**误判输出 $0$）；环 美$\to$英$\to$加$\to$美 乘积 $12.5>1$。答案 `12.000000` ✓。这组同时检验了零环不误报。

第二组，真负环：`2 2 10 1 2 / 1 2 0.5 / 2 1 0.5`。环乘积 $0.25<1$，绕 $k$ 圈价格 $10\times0.5\times0.25^k\to0$，无最小值，输出 `0` ✓。

第三组，负环**到不了 $B$**：`4 4 10 1 2 / 1 2 1 / 1 3 1 / 3 4 0.5 / 4 3 0.5`。$\{3,4\}$ 是负环且从 $A$ 可达，但无法回到 $2$；$A\to B$ 最低价 $10$，输出 `10.000000`（检验"不能见环就输出 0"）。

第四组，负环**不可达**：`4 4 10 1 2 / 1 2 2 / 3 4 0.5 / 4 3 0.5 / 3 2 1`。负环 $\{3,4\}$ 能到 $B$ 但从 $A$ 到不了，$d[3]=\infty$ 不参与检测；答案 $20$，输出 `20.000000`。

## 二、思维链：完整证明

**记号。** 图 $G=(V,E)$，$|V|=N,|E|=M$，边权 $w_{ij}=\ln e_{ij}\in[-\ln10,\ln10]$。路径 $P$ 的权和 $w(P)=\sum_{e\in P}w_e$，对应价格 $\mathrm{price}(P)=V\cdot e^{w(P)}$。$d[v]$ 为 BF 维护的距离（$\log$ 域），初值 $d[A]=0$、其余 $+\infty$（哨兵 `inf=1e18`）。$\delta(v)=\inf\{w(P):P\text{ 是 }A\to v\text{ 的游走}\}$。环 $C$ 的权 $w(C)<0$ 称负环（对应乘积 $<1$）。

---

### 引理 1（对数归约的保序性）

对任意两条 $A\to B$ 游走 $P,Q$：$\mathrm{price}(P)\le\mathrm{price}(Q)\iff w(P)\le w(Q)$。故最低价格 $=V\cdot e^{\delta(B)}$（若下确界可达）。

*证明*：$\mathrm{price}(P)=V\prod e=V\exp(\sum\ln e)=V e^{w(P)}$（$\exp$ 与 $\ln$ 互逆，乘积化连加）。$V>0$ 固定，$x\mapsto Ve^x$ 严格递增，保序。下确界经连续严格递增函数映射：$\inf_P Ve^{w(P)}=Ve^{\inf_P w(P)}=Ve^{\delta(B)}$。证毕。

---

### 引理 2（无负环时最小值在简单路径上取到）

若不存在"从 $A$ 可达且能到达 $B$"的负环，则 $\delta(B)=\min\{w(P):P\text{ 是 }A\to B\text{ 简单路径}\}$，最小值存在且取到。

*证明*：任取 $A\to B$ 游走 $W$。若 $W$ 重复经过某点，则含一个环 $C$；$C$ 上的点从 $A$ 可达（沿 $W$ 前段）、能到 $B$（沿 $W$ 后段），由假设 $w(C)\ge0$。删去 $C$ 得游走 $W'$，$w(W')=w(W)-w(C)\le w(W)$。反复删环（每次点数严格减少）终得简单路径 $P$，$w(P)\le w(W)$。故游走的下确界等于简单路径集的最小值；简单路径只有有限条（$\le N!$ 量级但有限），有限集必有最小值。证毕。

**推论**：此时答案 $=Ve^{\delta(B)}$，是一个真正的最小值；且 $\delta(B)$ 由 $\le N-1$ 条边的路径实现。

---

### 引理 3（有负环时无最小值，下确界为 0）

若存在从 $A$ 可达、能到达 $B$ 的负环 $C$（$w(C)=c<0$），则 $B$ 国价格的下确界为 $0$ 且取不到，应输出 $0$。

*证明*：取路径 $P_1:A\leadsto u$（$u\in C$）、绕 $C$ $k$ 圈、路径 $P_2:u\leadsto B$，拼成游走 $W_k$，$w(W_k)=w(P_1)+kc+w(P_2)\to-\infty$（$k\to\infty$）。价格 $Ve^{w(W_k)}\to0$，故对任何 $\epsilon>0$ 存在换算方案价格 $<\epsilon$：任何正数都不是最小值（总能更小），而价格恒正（$V>0,e>0$），$0$ 取不到。下确界为 $0$、无最小值，按题意输出 $0$。证毕。

---

### 引理 4（Bellman-Ford 不变量）

按任意固定边序做松弛 $d[v]\leftarrow\min(d[v],d[u]+w_{uv})$。则第 $k$ 轮结束后：

(a) $d[v]\le$ 任何"$\le k$ 条边的 $A\to v$ 游走"的权和（上界性）；
(b) $d[v]$ 总等于**某条** $A\to v$ 游走的权和（或 $+\infty$ 表示暂无）（真实性）；
(c) 若无从 $A$ 可达的负环，$N-1$ 轮后 $d[v]=\delta(v)$（$\delta(v)$ 有限时）。

*证明*：(b) 归纳：初值 $d[A]=0$ 是空游走，其余 $\infty$。每次松弛把 $d[v]$ 置为 $d[u]+w$，由归纳 $d[u]$ 是某游走权和，接上一条边仍是游走权和。

(a) 对 $k$ 归纳。$k=0$：$\le0$ 条边的游走只有 $A$ 处空游走，$d[A]=0$ ✓。设 $k-1$ 成立；任取 $\le k$ 条边的游走 $W$ 到 $v$，拆成 $W'$（$\le k-1$ 条边，到 $u$）加末边 $(u,v)$。第 $k$ 轮处理 $(u,v)$ 时，$d[u]\le w(W')$（归纳假设：第 $k-1$ 轮后的值 $\le w(W')$，而松弛只减不增），故松弛后 $d[v]\le d[u]+w\le w(W)$。若该轮 $d[u]$ 更小则 $d[v]$ 更小，不等式保持。✓

(c) 无负环时由引理 2 的删环论证（对任意终点 $v$ 同样成立），$\delta(v)$ 由 $\le N-1$ 条边的简单路径实现；由 (a) $d[v]\le\delta(v)$，由 (b) $d[v]\ge\delta(v)$（任何游走 $\ge$ 下确界），故相等。证毕。

---

### 引理 5（第 N 轮可改进 ⟺ 存在可达负环）

在精确算术下：$N-1$ 轮后仍存在边 $(u,v)$ 使 $d[u]+w<d[v]$（$d[u]$ 有限）$\iff$ 存在从 $A$ 可达的负环。

*证明*：

**（⇐）** 设负环 $C$ 从 $A$ 可达。反设 $N-1$ 轮后 $C$ 上所有边都不可改进：$\forall(u,v)\in C,\ d[v]\le d[u]+w$。沿 $C$ 求和：$\sum_{C}d[v]\le\sum_C d[u]+w(C)$，两边 $\sum d$ 相同（环上每点各出现一次），得 $0\le w(C)<0$，矛盾。故 $C$ 上必有可改进边。（可达性保证 $C$ 上 $d$ 有限：$A\leadsto u$ 的路径 $\le N-1$ 条边，引理 4(a) 使 $d[u]$ 有限。）

**（⇒）** 设第 $N$ 轮边 $(u,v)$ 可改进。由引理 4(b)，$d[u]$ 对应某游走 $W_u$；$W_u$ 加边 $(u,v)$ 是到 $v$ 的游走，权和 $<d[v]$。由引理 4(a)，$d[v]\le$ 任何 $\le N-1$ 条边游走的权和，故 $W_u+(u,v)$ 至少 $N$ 条边，含重复点，即含环 $C$。若 $C$ 非负，删去后得到边数更少、权和不增的游走；反复删环得 $\le N-1$ 条边的游走 $P$，$w(P)\le w(W_u)+w<d[v]$，与引理 4(a) 矛盾。故 $C$ 是负环，且其点在 $W_u$ 上，从 $A$ 可达。证毕。

**浮点修正**：`long double` 下每次加法舍入 $\le\mathrm{ulp}(|d|)$。参与判环的 $d$ 值：无负环时 $|d|\le(N-1)\ln10\approx4606$；有负环时最坏 $|d|\le(N-1)M\ln10\approx1.2\times10^8$（每轮每条边至多松弛一次）。零环引起的累计漂移 $\le N\cdot\mathrm{ulp}(4606)\approx2000\times2.5\times10^{-16}=5\times10^{-13}$。取阈值 $\varepsilon=10^{-11}$（漂移上界的 $20$ 倍），判据改为 $d[u]+w<d[v]-\varepsilon$：零环漂移够不到阈值（不误报）；真实负环每轮总改进量 $|w(C)|$ 持续累积，只要 $|w(C)|/|C|>10^{-11}+\text{误差}$ 即可检出（对汇率为有限位小数的实际数据绰绰有余）。

---

### 引理 6（BFS 标记 = 受负环影响的点集）

把第 $N$ 轮满足 $d[u]+w<d[v]-\varepsilon$ 的边的终点 $v$ 作种子，沿出边 BFS 标记 `bad`。则（精确算术下）`bad[x]` 为真 $\iff$ 存在从 $A$ 可达的负环能到达 $x$ $\iff$ $x$ 的价格下确界为 $0$（$x$ 作终点时）。

*证明*：种子 $v$：由引理 5 的（⇒）论证，可改进边所在的负环 $C$ 从 $A$ 可达，且 $v$ 在 $C$ 上或在 $C$ 下游（$W_u$ 含 $C$，$v$ 是 $W_u$ 的终点延伸），故 $C\leadsto v$。BFS 闭包：从种子可达的点都能被某个这样的负环到达。反向：若负环 $C$（$A$ 可达）能到 $x$，由引理 5（⇐）$C$ 上有可改进边，其终点 $v_0\in C$ 是种子，$C$ 强连通故 $v_0\leadsto x$，BFS 必标记 $x$。最后，"负环可达 $x$"时引理 3 给出 $x$ 价格下确界 $0$；反之若无此环，引理 2 给出正的最小值。证毕。

**推论**：`bad[B]` 为真 $\iff$ 应输出 $0$；否则输出 $Ve^{d[B]}$（引理 4(c) 保证 $d[B]=\delta(B)$）。

---

### 引理 7（数值精度）

最终输出的相对误差 $\le10^{-12}$ 量级，满足 $10^{-6}$ 精度要求；全程无上溢/下溢。

*证明*：范围：任何被赋值的 $d$ 是 $\le(N-1)M$ 条边的游走权和，$|d|\le1.2\times10^8\ll$ `inf`$=10^{18}\ll$ `long double` 上限 $10^{4932}$；判环只在 $d$ 有限时进行，`inf` 哨兵精确保持（只由 `fill` 写入、从不参与算术），`d[u]!=inf` 判据可靠。

精度：无负环影响 $B$ 时，$d[B]$ 是 $\le N-1$ 个 $w$ 的和，每个 $|w|\le\ln10$，部分和 $|s|\le4606$。每次加法误差 $\le\mathrm{ulp}(4606)\approx2.5\times10^{-16}$，总误差 $\le(N-1)\times2.5\times10^{-16}\approx5\times10^{-13}$（绝对）。$\exp$ 的相对误差 $\approx$ 自变量绝对误差（$|e^{x+\Delta}-e^x|/e^x=|e^\Delta-1|\approx|\Delta|$），再加 `expl` 自身 $\le1$ ulp 的相对误差 $\approx10^{-19}$，合计 $\le10^{-12}$。$V$ 读入误差 $\le1$ ulp（相对 $10^{-19}$）。输出 $10^{-6}$ 精度要求下余量 $6$ 个数量级。证毕。

---

### 引理 8（复杂度）

时间 $O(NM)$，空间 $O(N+M)$。

*证明*：至多 $N-1$ 轮，每轮扫 $M$ 条边各一次加法一次比较，$O(NM)=2000\times25000=5\times10^7$；无负环且数据温和时"本轮无更新即 break"提前结束。判环一轮 $O(M)$，BFS $O(N+M)$。空间：边集 $M$ 个 `{int,int,f80}`、出边邻接表 $M$ 个 `int`、$d$/$bad$ 各 $N$。证毕。

---

### 定理

程序在存在影响 $B$ 的负环时输出 $0$，否则输出 $B$ 国最低价格（相对误差 $\le10^{-12}$），时间 $O(NM)$。

*证明*：引理 1 把连乘最小化归约为 $\log$ 域最短路；引理 2、3 给出"有/无影响 $B$ 的负环"两种情形的答案语义（最小值 vs 下确界 $0$）；引理 4 保证 BF 在无负环时算出 $\delta(B)$；引理 5、6 保证判环与 BFS 标记恰好识别"影响 $B$ 的负环"，浮点阈值分析排除零环误报；引理 7 保证数值精度与范围安全；引理 8 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 价格沿路径**连乘**，汇率 $\in[0.1,10]$ 可 $<1$ ⇒ 权值可负，Dijkstra 出局。
2. **reduce to easier problem** — 取对数：$\min\prod e\iff\min\sum\ln e$，乘法最短路归约为加法最短路；"乘积 $<1$ 的环" = 负环。
3. **classic problem solution** — Bellman-Ford：$N-1$ 轮松弛得最短路，第 $N$ 轮仍可改进 ⟺ 可达负环。
4. **explore its property** — 直接乘法松弛会上溢（$10^{2000}$）/下溢（绕负环），$\log$ 域把一切压进 $\pm1.2\times10^8$，数值安全是对数归约的第二重理由。
5. **discuss by category** — 负环分三类：影响 $B$（输出 $0$）、可达但到不了 $B$、不可达——只有第一类输出 $0$；用"种子 + 正向 BFS"精确圈定受影响点集。
6. **explore its property** — 零环（乘积 $=1$）浮点漂移 $\le5\times10^{-13}$，判环阈值 $\varepsilon=10^{-11}$ 夹在"漂移上界"与"真实负环改进量"之间；`long double` 全程。
7. **classic problem solution** — 输出 $V\cdot\mathrm{expl}(d[B])$，`fixed<<setprecision(6)`；$V$ 非整数必须浮点读入。

| `eps` | 判环阈值 $10^{-11}$ | `constexpr f80` | 零环漂移上界 $\approx5\times10^{-13}$ 的 $20$ 倍 |
| `bad[v]` | $v$ 的价格可被无限压低 | `bool[mxn]` | 默认 `false`；种子 + BFS 置 `true` |
| `mxn,mxm` | $2005,25005$ | `constexpr int` | 约束 $+5$ |

记忆点：**d 是 log 域（可负！），不是价格**；价格只在最后一步 `V*expl(d[B])` 还原。

### 算法步骤

1. I/O 加速三行；读 `n,m,V,A,B`（`--A;--B`）；读边，$w=\mathrm{logl}(e)$，建边集与出边邻接表。
2. `fill_n(d,n,inf); d[A]=0;`（**全局默认 0 不是 INF**，漏填会把所有点当成 0 距离可达）。
3. 至多 $N-1$ 轮：按输入序扫边，`d[u]!=inf&&d[u]+w<d[v]` 则松弛；整轮无更新提前 break。
4. 判环：再扫一遍边，`d[u]!=inf&&d[u]+w<d[v]-eps` 的终点入队并标 `bad`；沿 `graph` BFS 扩散 `bad`。
5. `bad[B]||d[B]==inf` ⇒ 输出 `0`；否则输出 `fixed<<setprecision(6)<<V*expl(d[B])`。

### 复杂度

- 时间 $O(NM)=5\times10^7$（常提前 break）；空间 $O(N+M)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子输出 `12.000000`（零环不误报）；真负环输出 `0`；负环到不了 $B$ / 不可达两组分别输出 `10.000000` / `20.000000`，全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3001 [USACO10DEC] Big Macs Around the World G
// 价格连乘 ⇒ 取对数变加法最短路（权可负，Dijkstra 不可用）⇒ Bellman-Ford
// 乘积<1 的环 = 负环；仅当负环从 A 可达且能到 B 时价格无下界，输出 0
// log 域杜绝乘法松弛的上溢/下溢；long double + eps 防零环误报
#include<bits/stdc++.h>
using namespace std;
using f80=long double;

constexpr int mxn{2005},mxm{25005};
constexpr f80 inf{1e18},eps{1e-11};

int n,m,A,B;
f80 V,d[mxn];
struct edge{int u,v;f80 w;}E[mxm];
vector<int>graph[mxn];
bool bad[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>V>>A>>B;--A;--B;
	for(int i=0;i<m;++i)
	{
		f80 e;
		cin>>E[i].u>>E[i].v>>e;--E[i].u;--E[i].v;
		E[i].w=logl(e);
		graph[E[i].u].push_back(E[i].v);
	}
	fill_n(d,n,inf);	// 全局默认 0 不是 INF！d[A]=0 才是唯一合法起点
	d[A]=0;
	for(int it=0;it<n-1;++it)
	{
		bool upd=false;
		for(int i=0;i<m;++i)
		{
			auto[u,v,w]=E[i];
			if(d[u]!=inf&&d[u]+w<d[v])
			{
				d[v]=d[u]+w;
				upd=true;
			}
		}
		if(!upd)
			break;
	}
	// 第 n 轮仍能改进超过 eps ⇒ 可达负环；正向 BFS 圈定受影响点
	queue<int>Q;
	for(int i=0;i<m;++i)
	{
		auto[u,v,w]=E[i];
		if(d[u]!=inf&&d[u]+w<d[v]-eps&&!bad[v])
		{
			bad[v]=true;
			Q.push(v);
		}
	}
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		for(int v:graph[u])
			if(!bad[v])
			{
				bad[v]=true;
				Q.push(v);
			}
	}
	if(bad[B]||d[B]==inf)
		cout<<"0\n";
	else
		cout<<fixed<<setprecision(6)<<V*expl(d[B])<<'\n';
	return 0;
}
```

### 代码说明

- **`fill_n(d,n,inf)` 是生死线**：`d` 是距离数组，全局默认 $0$ 会被当成"所有点 $0$ 代价可达"，整个 BF 静默出错。`inf=1e18` 远大于合法 $|d|\le1.2\times10^8$，且哨兵从不参与算术（`d[u]!=inf` 守卫），精确相等比较可靠。
- **松弛用严格 `<`，判环才用 `-eps`**：松弛加阈值会损失最优性；判环不加阈值会被零环的浮点漂移（$\le5\times10^{-13}$）误触发。$\varepsilon=10^{-11}$ 两边都留了余量（引理 5）。
- **判环种子是边的终点 $v$**，再沿出边 BFS：负环强连通，环上一点被标记后整环及下游全部被标记，恰好等于"价格可无限压低"的点集（引理 6）。只判 `bad[B]`，别处的负环不影响答案。
- `logl`/`expl` 是 `long double` 版本，别写成 `log`/`exp`（那会截成 `double`，精度前功尽弃）。
- $V$ 非整数，必须 `f80` 读入；答案只在最后一步还原到价格域，中间全程 $\log$ 域。
- `d[B]==inf`（不可达）按题意兜底输出 `0`；题目保证强连通，此分支实际不会触发。
