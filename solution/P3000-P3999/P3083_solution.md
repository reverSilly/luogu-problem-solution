# P3083 [USACO13OPEN] Luxury River Cruise S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 个港口（$1\le N\le 10^3$），每个港口恰好有两条单向河道：左河道、右河道，各通向一个港口。贝西从港口 $1$ 出发。导游有一个长度 $M$（$1\le M\le 500$）的方向序列（`L`/`R`），**重复执行 $K$ 遍**（$1\le K\le 10^9$）：每遍按序列依次选左/右河道走 $M$ 步。问最终停在哪个港口。

**口径说明（两处，先钉死）：**

1. "重复 $K$ 次"指整个序列执行 $K$ 遍，共 $K\cdot M$ 步，方向序列**不**在每遍之间重置起点——上一遍的终点就是下一遍的起点。依据：Hint 明确写"第一遍后到 $2$，第二遍从 $2$ 出发到 $3$，第三遍从 $3$ 出发到 $4$"。
2. 题面说两条河道"通向其他港口"，但**没有禁止两条河道通向同一个港口**，也没有明确禁止自环。Hint 反推出的样例里港口 $2$ 的左右河道就都通向 $3$（见下）。算法对这两种情形都天然正确，不需要特殊处理。

**手造小数据核对。** 题面只有 Hint 的路径描述，没有样例输入输出。我按 Hint 反推：三遍路径为 $1\to2\to3\to2$、$2\to3\to4\to3$、$3\to4\to1\to4$，故 $N=4,M=3,K=3$。设方向为 $(d_1,d_2,d_3)$，对照各步：港口 $1$ 走 $d_1$ 到 $2$、走 $d_3$ 到 $4$；港口 $3$ 走 $d_2,d_1$ 都到 $4$、走 $d_3$ 到 $2$。取 $d_1=d_2=\texttt L,d_3=\texttt R$ 全部吻合，于是边表为：$1:(2,4),\ 2:(3,3),\ 3:(4,2),\ 4:(1,3)$。输入：

```
4 3 3
2 4
3 3
4 2
1 3
L L R
```

答案 $4$，与 Hint 逐遍路径一致。另造两组极简数据：$N=2$，边 $1:(2,2),2:(1,1)$，序列 `L`——每遍恰好走一步，港口在 $1,2$ 间交替；$K=10^9$（偶数）答案 $1$，$K=10^9-1$（奇数）答案 $2$。这组专门打"$K$ 巨大"的边界。

**第一步：直接模拟为什么不行？** 总步数 $K\cdot M\le 10^9\times 500=5\times 10^{11}$，哪怕一步 $O(1)$ 也要跑几百秒，远超时限。但注意**状态只有 $N\le 1000$ 个港口**——走了这么多步，必然在原地打转。信息量极小，重复量极大，这是"找结构压缩重复"的典型信号。

**第二步：先解简化版。** 若 $K=1$：从 $1$ 出发按序列走 $M$ 步，$O(M)$ 模拟即可。若 $K$ 很小：走 $K\cdot M$ 步。关键观察藏在"$K=1$ 的解"里：**一整遍序列的效果只取决于起点**。起点是 $u$，走完 $M$ 步停在某个确定的港口——这就是一个函数 $f:V\to V$！而且 $f$ 与"这是第几遍"无关（序列固定、图固定）。于是原问题变成：

$$\text{答案}=f^K(1)\quad(\text{函数 }f\text{ 迭代 }K\text{ 次}).$$

**第三步：算 $f$ 本身。** 对每个起点 $u$ 模拟一遍序列：$O(M)$；共 $N$ 个起点，$O(NM)=5\times 10^5$，完全可行。这一步把"$K$ 遍"的庞大过程压缩成一张 $N$ 个entries的函数表。

**第四步：$f^K$ 怎么快算？两条路。**

- **路线 A（找环）**：函数图（每点出度 $1$）上从 $1$ 出发迭代，至多 $N+1$ 步必遇重复点，轨迹呈"$\rho$"形：一段尾巴 + 一个环。设尾长 $\mu$、环长 $\lambda$，则 $f^K(1)=f^{\mu+((K-\mu)\bmod\lambda)}(1)$（$K\ge\mu$ 时）。$O(N)$ 搞定。
- **路线 B（倍增）**：预处理 $g_j(u)=f^{2^j}(u)$，递推 $g_j(u)=g_{j-1}(g_{j-1}(u))$；把 $K$ 拆成二进制，按位复合。$O(N\log K)$。

两条都对。题目标签写着"倍增"，且倍增不需要讨论 $\mu,\lambda,K<\mu$ 的分类，代码更直白，我选 B：$K\le 10^9<2^{30}$，预处理 $30$ 层，每层 $N$ 个值，共 $3\times 10^4$ 次查表；查询按 $K$ 的至多 $30$ 个二进制位跳。

**第五步：为什么"按位跳"是对的？** 因为所有 $f^{2^j}$ 都是**同一个函数**的幂，彼此可交换：$f^a\circ f^b=f^{a+b}=f^b\circ f^a$。所以从低位到高位依次复合，累计指数恰好是 $K$ 的二进制展开之和，顺序无关。这和快速幂 $a^K=\prod a^{2^j}$ 是同一个代数结构，只是"乘法"换成了"函数复合"。

## 二、思维链：完整证明

**记号。** 港口集 $V=\{0,\dots,N-1\}$（内部 0-based）。$\mathrm{to}[u][0/1]$ 为左/右河道目标。方向序列 $d_0,\dots,d_{M-1}\in\{0,1\}$。定义单步函数 $\mathrm{step}(u,c)=\mathrm{to}[u][c]$，一遍序列的函数
$$f(u)=\mathrm{step}(\cdots\mathrm{step}(\mathrm{step}(u,d_0),d_1)\cdots,d_{M-1}).$$
$f^0=\mathrm{id}$，$f^{t+1}=f\circ f^t$。出发点是 $0$（港口 $1$）。

---

### 引理 1（原问题 = 函数迭代）

执行完第 $t$ 遍序列后贝西所在港口为 $f^t(0)$；最终答案为 $f^K(0)$。

*证明*：对 $t$ 归纳。$t=0$：尚未出发任何遍，在起点 $0=f^0(0)$ ✓。设第 $t$ 遍后在 $f^t(0)$。第 $t+1$ 遍从该点出发，按固定序列 $d_0..d_{M-1}$ 走 $M$ 步——由 $f$ 的定义，终点为 $f(f^t(0))=f^{t+1}(0)$ ✓（$f$ 的定义与遍数无关，只依赖起点，这正是"序列固定、图固定"的语义）。取 $t=K$ 即得。证毕。

---

### 引理 2（$f$ 表的计算正确）

代码对每个 $u$ 令 `cur=u`，依次 `cur=to[cur][dir[i]]`（$i=0..M-1$），存入 `f[0][u]`。则 `f[0][u]`$=f(u)$。

*证明*：内层循环是对 $i$ 的 straightforward 归纳：循环不变量"`cur` 等于从 $u$ 出发按前 $i$ 个方向走过的港口"。$i=0$ 时 `cur`$=u$（走 $0$ 步）✓；每步 `cur=to[cur][dir[i]]` 恰为 $\mathrm{step}(\text{cur},d_i)$，不变量保持 ✓。循环结束 `cur`$=f(u)$。外层对每个 $u$ 独立执行，互不干扰。证毕。

---

### 引理 3（倍增预处理不变量）

对所有 $0\le j<30$ 与 $u\in V$：`f[j][u]`$=f^{2^j}(u)$。

*证明*：对 $j$ 归纳。$j=0$：$2^0=1$，由引理 2 ✓。设 $j-1$ 层成立。函数幂满足 $f^{2^j}=f^{2^{j-1}+2^{j-1}}=f^{2^{j-1}}\circ f^{2^{j-1}}$（指数相加律：$f^a\circ f^b=f^{a+b}$，对 $b$ 归纳即得）。故
$$f^{2^j}(u)=f^{2^{j-1}}\bigl(f^{2^{j-1}}(u)\bigr)=\texttt{f[j-1][f[j-1][u]]},$$
正是代码的递推式。又 $f^{2^{j-1}}(u)\in V$（$f$ 是 $V\to V$ 的函数），查表下标合法。证毕。

---

### 引理 4（按二进制位复合 = $f^K$）

设 $K=\sum_{j=0}^{29}b_j2^j$（$b_j\in\{0,1\}$，$K\le 10^9<2^{30}$ 保证 $30$ 位足够）。代码令 `cur=0`，对 $j=0..29$：若 $b_j=1$ 则 `cur=f[j][cur]`。则结束后 `cur`$=f^K(0)$。

*证明*：先证**同函数幂可交换**：$f^a\circ f^b=f^{a+b}=f^{b+a}=f^b\circ f^a$（指数相加律 + 整数加法交换）。

再证循环不变量：处理完第 $j$ 位后，`cur`$=f^{K\bmod 2^{j+1}}(0)$。对 $j$ 归纳。$j=-1$（未处理）：$K\bmod 1=0$，`cur`$=0=f^0(0)$ ✓。设处理完 $j-1$ 后 `cur`$=f^{K\bmod 2^j}(0)$。第 $j$ 位：若 $b_j=0$，`cur` 不变，而 $K\bmod 2^{j+1}=K\bmod 2^j$（第 $j$ 位为 $0$）✓。若 $b_j=1$，`cur`$=f^{2^j}(\text{cur})=f^{2^j}\circ f^{K\bmod 2^j}(0)=f^{2^j+(K\bmod 2^j)}(0)$；而 $K\bmod 2^{j+1}=(K\bmod 2^j)+b_j2^j=(K\bmod 2^j)+2^j$ ✓。处理完 $j=29$ 后 $K\bmod 2^{30}=K$，故 `cur`$=f^K(0)$。证毕。

**注**：可交换性保证了"从低位到高位"与任何别的顺序结果相同——这是快速幂结构在函数复合下的直接移植。

---

### 引理 5（层数与复杂度）

$30$ 层足够；时间 $O(NM+N\log K)$，空间 $O(N\log K+M)$。

*证明*：$K\le 10^9<2^{30}=1073741824$，故 $K$ 的二进制至多 $30$ 位（第 $0..29$ 位），引理 4 的循环覆盖所有位 ✓。

时间：读入 $O(N+M)$；$f$ 表 $N$ 个起点各模拟 $M$ 步，$O(NM)\le 5\times 10^5$；倍增 $29$ 层 $\times N$ 次查表，$O(N\log K)\le 3\times 10^4$；查询至多 $30$ 次查表。合计 $O(NM+N\log K)$。

空间：`f` 为 $35\times 1005$ 个 `int` $\approx 140$ KB，`to` $O(N)$，`dir` $O(M)$。证毕。

---

### 引理 6（替代路线：找环的正确性，供对照）

函数图迭代轨迹必呈 $\rho$ 形：存在 $\mu\ge 0,\lambda\ge 1$ 使 $f^\mu(0)$ 是首个重复出现的点，且 $f^{\mu+\lambda}(0)=f^\mu(0)$；对 $K\ge\mu$，$f^K(0)=f^{\mu+((K-\mu)\bmod\lambda)}(0)$。

*证明*：序列 $f^0(0),f^1(0),\dots,f^N(0)$ 共 $N+1$ 项取值于 $N$ 元集，由鸽笼原理必有重复；设首次重复为 $f^a(0)=f^b(0)$（$a<b\le N$，$a$ 最小）。令 $\mu=a,\lambda=b-a$。由 $f$ 是函数，等式两边继续迭代得 $f^{a+t}(0)=f^{b+t}(0)$ 对所有 $t\ge 0$，即从 $\mu$ 起以 $\lambda$ 为周期。对 $K\ge\mu$，写 $K=\mu+q\lambda+r$（$0\le r<\lambda$），反复用周期性削去 $q$ 个周期即得 $f^K(0)=f^{\mu+r}(0)$。证毕。

这条路线 $O(NM+N)$ 同样可行，但需分类 $K<\mu$ 与 $K\ge\mu$；倍增版无分类，故正文采用倍增。

---

### 定理

程序输出 $f^K(0)+1$，即贝西执行 $K$ 遍方向序列后停靠的港口编号；时间 $O(NM+N\log K)$，空间 $O(N\log K)$。

*证明*：引理 1 把原题归约为 $f^K(0)$；引理 2 保证 `f[0]` 正确；引理 3 保证倍增表正确；引理 4 保证按位复合恰为 $f^K$；引理 5 保证层数足够并给出复杂度；输出 `cur+1` 还原 1-based 编号。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 总步数 $K\cdot M\le 5\times 10^{11}$ 不可模拟，但状态只有 $N\le 1000$ 个：重复量巨大、信息量极小，必有压缩结构。
2. **consider easier version** — $K=1$ 时模拟 $M$ 步即可；发现"一整遍的效果只依赖起点"，与遍数无关。
3. **reduce to easier problem** — 一遍序列 = 函数 $f:V\to V$，原问题归约为函数迭代 $f^K(1)$；$f$ 表 $O(NM)$ 预处理。
4. **classic problem solution** — 函数快速幂 = 倍增：$g_j=g_{j-1}\circ g_{j-1}$，$K$ 按二进制位复合，$O(N\log K)$。
5. **explore its property** — 同函数幂可交换（$f^a\circ f^b=f^{a+b}$），保证按位跳的顺序无关，这是快速幂代数结构的移植。
6. **discuss by category** — 替代路线找环（$\rho$ 形轨迹，$K$ 对环长取模）同样正确但需分类 $K<\mu$；倍增无分类，选之。
7. **discuss by category** — 左右河道同目标、自环均不影响函数语义，无需特判；$K<2^{30}$ 定层数。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,m,K` | 港口数 $\le 10^3$、序列长 $\le 500$、重复遍数 $\le 10^9$ | `int` | 读入；$K$ 在 `int` 内 |
| `to[u][0/1]` | 港口 $u$ 的左/右河道目标（0-based） | `int[mxn][2]` | 读入后 `--` |
| `dir[i]` | 第 $i$ 个方向：`false`=L，`true`=R | `bool[mxm]` | `c=='R'` |
| `f[j][u]` | $f^{2^j}(u)$：从 $u$ 走 $2^j$ 遍序列后的港口 | `int[mxk][mxn]` | `f[0]` 模拟；高层递推；**每格都有定义，无需 INF** |
| `mxk` | $35$（$30$ 层 $+5$ 松弛） | `constexpr int` | $K<2^{30}$ |
| `cur` | 当前港口（0-based），初始 $0$ = 港口 $1$ | `int` | 查询时按位跳 |

### 算法步骤

1. I/O 加速三行；读 $N,M,K$；读边表（转 0-based）；读 $M$ 个方向字符存 `dir`。
2. 对每个 $u$：模拟一遍序列得 `f[0][u]`。
3. 对 $j=1..29$：`f[j][u]=f[j-1][f[j-1][u]]`。
4. `cur=0`；对 $j=0..29$：若 `K>>j&1` 则 `cur=f[j][cur]`。
5. 输出 `cur+1`。

### 复杂度

- 时间：$O(NM+N\log K)\approx 5.3\times 10^5$。
- 空间：$O(N\log K)\approx 140$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；五组手造数据（Hint 反推样例 / $K=10^9$ 偶 / $K=10^9-1$ 奇 / 自环 / $K=1$）输出 $4,1,2,1,2$ 全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3083 [USACO13OPEN] Luxury River Cruise S
// 一整遍方向序列 = 函数 f；重复 K 遍 = f^K，倍增预处理后按 K 的二进制位跳
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005},mxk{35},mxm{505};

int n,m,K,to[mxn][2],f[mxk][mxn];	// f[j][u] = 从 u 走 2^j 遍序列后的港口
bool dir[mxm];	// 0=L, 1=R

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>K;
	for(int i=0;i<n;++i)
	{
		cin>>to[i][0]>>to[i][1];
		--to[i][0];--to[i][1];
	}
	for(int i=0;i<m;++i)
	{
		char c;cin>>c;
		dir[i]=(c=='R');
	}
	for(int u=0;u<n;++u)
	{
		int cur=u;
		for(int i=0;i<m;++i)
			cur=to[cur][dir[i]];
		f[0][u]=cur;
	}
	for(int j=1;j<30;++j)	// K<=1e9<2^30，第 0..29 层足够
		for(int u=0;u<n;++u)
			f[j][u]=f[j-1][f[j-1][u]];
	int cur=0;	// 从 1 号港口出发（0-based）
	for(int j=0;j<30;++j)
		if(K>>j&1)
			cur=f[j][cur];
	cout<<cur+1<<'\n';
	return 0;
}
```

### 代码说明

- **两层压缩**：先把"$M$ 步"压成函数 $f$（$O(NM)$），再把"$K$ 次迭代"压成倍增（$O(N\log K)$）。直接模拟是 $O(KM)=5\times 10^{11}$，两级压缩后约 $5\times 10^5$。
- `f[j][u]=f[j-1][f[j-1][u]]` 是函数复合的倍增写法，与快速幂 `a=a*a` 同构；所有格子对每个 $u$ 都有定义（$f$ 是全函数），**不存在"不可达"，无需 INF**。
- 层数写死 $30$：$K\le 10^9<2^{30}$，第 $29$ 位是最高可能位；`mxk{35}` 留 $+5$ 松弛。
- `cin>>c` 逐字符读方向，自动跳过空格，正好匹配"$M$ 个空格隔开的字符"的输入格式。
- `bool dir` 直接当 `to` 的第二维下标（`false`=0=L，`true`=1=R），省一次分支。
- 输出 `cur+1` 还原 1-based；起点 `cur=0` 对应港口 $1$。
