# P3021 [USACO11MAR] Bovine Bridge Battle S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 平面上有 $N$ 个**互不相同**的整点 $(X_i,Y_i)$，$4\le N\le 1000$，$|X_i|,|Y_i|\le 10^9$。要数出有多少个**四元子集** $\{A,B,C,D\}$ 满足：存在一个点 $X$（$X$ 不等于这四个点中的任何一个），使得把组内**任意一头牛**绕 $X$ 旋转 $180^\circ$ 后，恰好落在组内**另一头牛**的位置上。换句话说：绕 $X$ 的 $180^\circ$ 旋转把这个四点集合**整体映到自身**，且每个点都换到了别的点。答案保证不超过有符号 32 位整数。

先把三个口径钉死（都有题面依据）：

1. **共线的退化四边形也算。** 题面例子明确把 $\{c,d,g,h\}=\{(-3,0),(-2,0),(2,0),(3,0)\}$ 列为合法组——四个点全在 $x$ 轴上。所以不要偷偷加"必须构成真正的平行四边形（不共线）"的限制。
2. **中心 $X$ 可以是半整数点。** 例子里 $\{b,c,e,f\}$ 的旋转中心是 $(-1.5,1.5)$。这提示我们：比较"中点"时会遇到 $.5$，最好一开始就**用坐标和代替中点**，全程整数。
3. **"另一头牛"= 没有不动点。** 旋转把每头牛映到组内*别的*牛；再加上 $X$ 不在组内，这两条合起来决定了置换的结构（下面引理 2）。

**暴力为什么不行。** 枚举四元组是 $\binom{1000}{4}\approx 4.14\times 10^{10}$，每个还要验证旋转，远超时限。必须找结构。

**第一步：盯着"旋转 $180^\circ$"看它到底是什么。** 绕 $X$ 旋转 $180^\circ$ 就是**中心对称（点反射）**：$P\mapsto 2X-P$。它有两个立刻能写出来的性质：做两次回到原地（对合）；唯一不动的点就是 $X$ 自己。于是"旋转把四点集映到自身"这件事，翻译成一个**置换**语言：这个置换作用在 4 个点上，平方是恒等，且**没有不动点**（$X$ 不在组内，而 $X$ 是旋转唯一的不动点）。平方恒等的置换只有 1-循环和 2-循环；去掉 1-循环，4 个点只能拆成**两个 2-循环**——即两对点 $\{A,B\},\{C,D\}$，每对关于 $X$ 对称：$A+B=2X=C+D$。

反过来，只要四个点能分成**坐标和相等的两对**，取 $X$ 为公共中点，旋转就交换每对内的两点，条件全部满足。这就是初中几何"平行四边形对角线互相平分"的逆命题——只不过这里**允许退化**（四点共线时就是数轴上关于 $X$ 对称的两对点）。

**第二步：把几何条件翻译成计数对象。** 合法四元组 $\iff$ 两对点、坐标和相同。于是问题变成：

> 把所有 $\binom{N}{2}$ 个点对的坐标和 $(x_i+x_j,\;y_i+y_j)$ 列出来，统计"和相同的点对有多少对"。

这是最经典的"统计相等元素对数"套路：排序，扫相等段，段长 $k$ 贡献 $\binom{k}{2}$。$\binom{1000}{2}=499500$ 个元素，排序约 $10^7$ 次比较，轻松。

**第三步：三个"会不会算重/算漏"的担心，逐个排查。** 这是本题真正需要证的地方，直觉上都要过一遍：

- *担心 1：和相同的两个点对会不会共用一个点？* 那样就凑不出 4 个不同的点。设 $\{i,j\}$ 与 $\{i,k\}$ 和相同，则 $P_j=(P_i+P_j)-P_i=(P_i+P_k)-P_i=P_k$，点互异 $\Rightarrow j=k$，是同一个点对。**不可能共用**，担心消除。
- *担心 2：同一个四元组会不会有两种不同的"等和配对"，被数两次？* 比如 $A+B=C+D$ 且 $A+C=B+D$。两式相减得 $B-C=C-B$，即 $B=C$，与点互异矛盾。三种配对方式两两互斥，**每个合法四元组恰好被数一次**。
- *担心 3：题目要求 $X$ 不与四个点重合，要不要额外减掉什么？* 若 $X=A$，则 $B=2X-A=A$，又推出两点重合。**自动满足**，不用管。

三个担心全部被"点互异"这一条条件化解——这也是为什么题面要专门强调"提供的牛的位置都是不同的"。

**第四步：实现细节。** 存**和**不存中点（避免半整数）；和的分量范围 $[-2\times10^9,2\times10^9]$，`int` 装得下（$2\times10^9<2^{31}-1=2147483647$，余量约 $1.47\times10^8$）；答案虽然题目保证 fit int32，但理论上 $\binom{1000}{4}\approx4.1\times10^{10}$ 超 int，累加器开 `long long` 零成本保平安。

**手造数据核对。**

第一组（极简正方形，4 点）：$(0,0),(1,0),(0,1),(1,1)$。六个点对和为 $(1,0),(0,1),(1,1),(1,1),(2,1),(1,2)$，只有 $(1,1)$ 出现两次（两条对角线 $\{(0,0),(1,1)\}$ 与 $\{(1,0),(0,1)\}$），答案 $1$。程序输出 $1$ ✓。

第二组（中心对称 6 点，专门测 $k>2$）：$(1,0),(0,1),(-1,0),(0,-1),(1,1),(-1,-1)$，即三对关于原点对称的点。和为 $(0,0)$ 的点对有 3 个：$\{(1,0),(-1,0)\},\{(0,1),(0,-1)\},\{(1,1),(-1,-1)\}$，贡献 $\binom{3}{2}=3$；其余和互不相同。答案 $3$，对应三个合法四元组（一个正方形 + 两个普通平行四边形）。程序输出 $3$ ✓。

第三组（题面自带的 8 点例子）：$a(-3,1),b(-2,2),c(-3,0),d(-2,0),e(-1,1),f(0,3),g(2,0),h(3,0)$。手工列出全部 28 个点对和，出现重复的只有三处：$(-4,2)$：$a+e,b+d$；$(-3,3)$：$b+e,c+f$；$(0,0)$：$c+h,d+g$。答案 $3$，与题面给的三个合法组 $\{a,b,e,d\},\{b,c,e,f\},\{c,d,g,h\}$ 逐一对应（注意第三个正是共线退化情形）。程序输出 $3$ ✓。

## 二、思维链：完整证明

**记号。** 点 $P_i=(x_i,y_i)\in\mathbb Z^2$，$0\le i<N$，两两不同。绕 $X$ 的 $180^\circ$ 旋转记作 $\rho_X(P)=2X-P$（坐标逐分量运算）。点对 $\{i,j\}$（$i<j$）的**和**记作 $\sigma(i,j)=P_i+P_j$。称四元子集 $S$ **合法**，若存在 $X\notin S$ 使 $\rho_X$ 把 $S$ 映到自身且 $S$ 中无不动点。

---

### 引理 1（点反射的代数性质）

$\rho_X$ 是对合：$\rho_X(\rho_X(P))=P$；且 $\rho_X(P)=P\iff P=X$。即 $X$ 是 $\rho_X$ 在**整个平面**上唯一的不动点。

*证明*：$\rho_X(\rho_X(P))=2X-(2X-P)=P$，对合成立。$\rho_X(P)=P\iff 2X-P=P\iff 2X=2P\iff X=P$（在 $\mathbb R^2$ 中除以 2 合法）。两个方向都成立，故不动点恰为 $X$。证毕。

---

### 引理 2（合法 $\iff$ 可分成等和的两对）

四元集 $S=\{A,B,C,D\}$（四点互异）合法，当且仅当存在一种把它分成两对 $\{A,B\},\{C,D\}$ 的方式，使得
$$A+B=C+D.$$
此时旋转中心必为 $X=(A+B)/2$，且条件"$X\notin S$"自动成立。

*证明*：

**（$\Rightarrow$）** 设 $S$ 合法，中心为 $X$。$\rho_X$ 把 $S$ 映到自身，诱导 $S$ 上的置换 $\pi$。由引理 1，$\rho_X^2=\mathrm{id}$，故 $\pi^2=\mathrm{id}$，$\pi$ 的循环长度只能整除 2，即只有 1-循环与 2-循环。又 $X\notin S$，而 $X$ 是 $\rho_X$ 唯一不动点（引理 1），故 $S$ 中每个点都不是不动点，$\pi$ 没有 1-循环。4 个元素全被 2-循环覆盖，只能是**恰好两个 2-循环**，记为 $(A\;B)(C\;D)$。由 $\rho_X(A)=B$ 得 $B=2X-A$，即 $A+B=2X$；同理 $C+D=2X$。故 $A+B=C+D$，且 $X=(A+B)/2$。

**（$\Leftarrow$）** 设 $A+B=C+D$，令 $X=(A+B)/2$。则 $\rho_X(A)=2X-A=B$，$\rho_X(B)=A$，$\rho_X(C)=D$，$\rho_X(D)=C$：$\rho_X$ 把 $S$ 映到自身，且每个点映到**另一个**点（$A\ne B,C\ne D$）。还需验证 $X\notin S$：若 $X=A$，则 $B=2X-A=A$，与四点互异矛盾；$X=B,C,D$ 同理（分别推出 $A=B$、$D=C$、$C=D$）。故 $X\notin S$，$S$ 合法。证毕。

**注**：这里没有排除共线情形——引理对退化四边形同样成立，与题面例子 $\{c,d,g,h\}$ 一致。也注意 $\pi$ **不可能是 4-循环**：$\pi^2=\mathrm{id}$ 直接排除了它，所以"正方形绕中心转 $90^\circ$"之类的对称与本题无关，题目只问 $180^\circ$。

---

### 引理 3（用整数和代替中点）

两对点中点相同 $\iff$ 坐标和相同；且所有 $\sigma(i,j)$ 的分量落在 $[-2\times10^9,\,2\times10^9]\subset[-(2^{31}-1),\,2^{31}-1]$，可用 `int` 精确存储，全程不出现分数。

*证明*：$\{i,j\}$ 的中点是 $\sigma(i,j)/2$。$\sigma(i,j)/2=\sigma(k,l)/2\iff\sigma(i,j)=\sigma(k,l)$（两边乘 2，$\mathbb Z^2$ 中消去律成立）。范围：$|x_i|\le10^9\Rightarrow|x_i+x_j|\le2\times10^9$，而 $2^{31}-1=2147483647>2\times10^9$，`int` 加法不溢出；$y$ 同理。中点可能是半整数（如 $(-1.5,1.5)$），但和永远是整数——这就是"存和不存中点"的理由。证毕。

---

### 引理 4（等和的不同点对必不相交）

若 $\{i,j\}\ne\{k,l\}$ 且 $\sigma(i,j)=\sigma(k,l)$，则 $\{i,j\}\cap\{k,l\}=\varnothing$。从而同一和值组里任取两个点对，必给出 **4 个互异的点**。

*证明*：反证。设共享一个点，不妨 $i=k$。则 $P_j=\sigma(i,j)-P_i=\sigma(k,l)-P_k=P_l$。点两两不同 $\Rightarrow j=l$，于是 $\{i,j\}=\{k,l\}$，与"不同点对"矛盾。故不相交。两个不相交的点对共 4 个下标，对应 4 个互异的点。证毕。

**推论**：和值为 $S$ 的点对组大小 $k$ 满足 $2k\le N$（$k$ 个两两不交的点对各占 2 个点），即 $k\le 500$。

---

### 引理 5（每个四元组至多一种等和配对，中心唯一）

四个互异的点 $A,B,C,D$ 的三种配对方式 $(AB|CD),(AC|BD),(AD|BC)$ 中，**至多一种**满足"两对和相等"。从而合法四元组的旋转中心唯一，不会被重复计数。

*证明*：穷举三种"两种配对同时等和"的组合，各推出矛盾：

1. $A+B=C+D$ 且 $A+C=B+D$：两式相减得 $B-C=C-B$，即 $2(B-C)=0$，$B=C$，矛盾。
2. $A+B=C+D$ 且 $A+D=B+C$：相减得 $B-D=D-B$，$B=D$，矛盾。
3. $A+C=B+D$ 且 $A+D=B+C$：相减得 $C-D=D-C$，$C=D$，矛盾。

所有情形都与四点互异矛盾，故至多一种配对等和。由引理 2，中心 $X=(A+B)/2$ 由该配对唯一确定。证毕。

---

### 引理 6（计数公式）

设把所有 $\binom{N}{2}$ 个点对按和值分组，和值 $S$ 的组大小为 $k_S$。则
$$\text{答案}=\sum_{S}\binom{k_S}{2}.$$

*证明*：构造双射。定义
$$\mathcal A=\{\text{合法四元子集}\},\qquad \mathcal B=\bigl\{\{\{i,j\},\{k,l\}\}:\{i,j\}\ne\{k,l\},\ \sigma(i,j)=\sigma(k,l)\bigr\}$$
（$\mathcal B$ 的元素是"两个不同等和点对"组成的无序对）。

- $\mathcal B\to\mathcal A$：取 $\{\{i,j\},\{k,l\}\}\in\mathcal B$。由引理 4，四个下标互异，得四元集 $S$；由 $\sigma(i,j)=\sigma(k,l)$ 与引理 2（$\Leftarrow$），$S$ 合法。映射良定义。
- $\mathcal A\to\mathcal B$：取合法 $S$。由引理 2（$\Rightarrow$），$S$ 有一种等和配对，给出 $\mathcal B$ 的一个元素；由引理 5，这种配对唯一，故映射良定义（不依赖选择）。
- 互逆：从 $\mathcal B$ 出发到 $\mathcal A$ 再回来，配对就是原来那对（引理 5 的唯一性）；从 $\mathcal A$ 出发到 $\mathcal B$ 再回来，点集不变（引理 4 保证点集恰好是那四个点）。

故 $|\mathcal A|=|\mathcal B|$。而 $\mathcal B$ 的计数：先按和值分组，组内任取两个不同点对即得 $\mathcal B$ 的一个元素，不同组之间和值不同不可能配对，故 $|\mathcal B|=\sum_S\binom{k_S}{2}$。证毕。

---

### 引理 7（排序 + 扫描相等段实现公式）

把 $M=\binom{N}{2}$ 个和值存入数组 `s[0..M)`，`sort(s,s+M)` 后，相同和值占据连续段；顺序扫描每个极大相等段（段长 $k$）并累加 $\binom{k}{2}$，结果恰为引理 6 的 $\sum_S\binom{k_S}{2}$。

*证明*：`pair<int,int>` 的默认 `<` 是字典序，是严格全序（分量整数序的字典序，三分性、传递性逐分量继承），`sort` 后数组非降。相等元素在非降序列中必连续：若 $s_a=s_b$（$a<b$）而中间某 $s_c$ 不同，则非降性给出 $s_a\le s_c\le s_b=s_a$，迫使 $s_c=s_a$，矛盾。故每个和值类恰对应一个极大相等段，段长即 $k_S$。扫描循环 `i` 从段首跳到段尾（`i+=k`），每段恰好访问一次、贡献 $\binom{k}{2}$ 一次，不重不漏。证毕。

---

### 引理 8（复杂度与数值范围）

时间 $O(N^2\log N)$，空间 $O(N^2)$；所有中间量不溢出。

*证明*：$M=N(N-1)/2\le 1000\times999/2=499500$。生成点对 $O(N^2)$；排序 $O(M\log M)=O(N^2\log N)$，代入约 $499500\times19\approx9.5\times10^6$ 次比较；扫描 $O(M)$。空间：`s` 为 $500005$ 个 `pair<int,int>` $\approx4$ MB，坐标数组 $O(N)$。

数值：和值分量 $\le2\times10^9<$ `int` 上限（引理 3）。段长 $k\le N/2=500$（引理 4 推论），$\binom{k}{2}\le124750$，单段贡献 `int` 可容；但总和理论上可达 $\binom{1000}{4}\approx4.14\times10^{10}>2^{31}-1$（题目保证实际答案不超，仍用 `i64` 累加杜绝隐患），`(i64)k*(k-1)/2` 先提升再乘，无溢出。证毕。

---

### 定理

程序输出的数恰为合法四牛组合数，总复杂度 $O(N^2\log N)$、空间 $O(N^2)$。

*证明*：引理 1、2 把"存在旋转中心"的几何条件等价翻译成"可分成等和两对"；引理 3 保证用整数和比较中点精确无误差；引理 4 保证等和点对自动给出 4 个互异点（且中心自动不在组内，引理 2）；引理 5 保证每个合法四元组只对应一种配对、不重；引理 6 建立双射得出 $\sum_S\binom{k_S}{2}$；引理 7 保证排序扫描正确计算该式；引理 8 保证复杂度与数值安全。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

- explore its property — 旋转 $180^\circ$ = 点反射 $P\mapsto2X-P$：对合，全平面唯一不动点是 $X$。
- explore its property — "映到组内另一头牛" + $X\notin$ 组 $\Rightarrow$ 诱导置换无不动点且平方恒等 $\Rightarrow$ 恰为两个 2-循环。
- reduce to easier problem — 合法四元组 $\iff$ 两对点坐标和相等（平行四边形对角线互相平分，含共线退化）；几何题塌缩成"统计相等的点对和"。
- consider easier version — 先排查三个简化隐患：等和点对是否共点、四元组是否有两种配对、中心是否与组内点重合——全部被"点互异"反证掉，计数无需修正项。
- classic problem solution — 枚举 $\binom{N}{2}$ 个点对和，排序 + 扫描相等段，$\sum\binom{k}{2}$（经典"相等元素对数"套路）。
- discuss by category — 存和不存中点（避开半整数）；$\pm2\times10^9$ 恰好 `int` 可容；答案累加器开 `i64`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 牛数 $N\le1000$ | `int`，读入 | — |
| `x[i],y[i]` | 第 $i$ 头牛坐标（0-based） | `int[mxn]`，读入 | 点互异由题目保证 |
| `mxn` | $1000+5$ | `constexpr int{1005}` | 坐标数组尺寸 |
| `mxm` | $\binom{1000}{2}+5$ | `constexpr int{500005}` | 点对和数组尺寸 |
| `s[t]` | 第 $t$ 个点对的坐标和 $(x_i+x_j,y_i+y_j)$ | `pair<int,int>[mxm]` | **存和 = 2 倍中点**，只填 $[0,m)$，排序也只排这段 |
| `m` | 点对总数 $N(N-1)/2$ | `int`，初值 $0$ | 双循环 `i<j` 计数 |
| `ans` | 合法四元组数 | `i64`，初值 $0$ | $\sum\binom{k}{2}$ |
| `k` | 当前相等段长度（= 某和值的点对数 $k_S$） | `int` | 每段重置为 $1$ |

本题没有"不可达/未定义"状态数组，唯一的大数组 `s` 只读取已填充并排序过的 $[0,m)$ 段，不存在全局默认 $0$ 被误读的问题。

### 算法步骤

1. I/O 加速三行；读入 `n` 与 `x[],y[]`。
2. 双重循环 $i<j$，把 $\{x_i+x_j,\;y_i+y_j\}$ 写入 `s[m++]`。
3. `sort(s,s+m)`（字典序）。
4. 扫描：`i` 从 $0$ 起，`k=1`，向后延伸相等段；累加 `ans+=(i64)k*(k-1)/2`；`i+=k`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(N^2\log N)$，$N=1000$ 时约 $9.5\times10^6$ 次比较。
- 空间：$O(N^2)$，`s` 约 $4$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面 8 点例（答案 3）与正方形、中心对称 6 点、共线 4 点、非平行四边形 4 点、$\pm10^9$ 极端坐标共 6 组手造数据全部吻合；$N=1000$ 网格数据与独立的"按中点逐格计数"闭式公式核对一致。

```cpp
// 题目：P3021 [USACO11MAR] Bovine Bridge Battle S
// 180° 旋转是对合且唯一不动点是中心 ⇒ 合法四元组 = 两对「坐标和相同」的点对
// 枚举所有点对的和，排序后扫描相等段，每段长 k 贡献 C(k,2)
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005},mxm{500005};	// C(1000,2)=499500

int n,x[mxn],y[mxn];
pair<int,int>s[mxm];					// 点对坐标和（=2 倍中点，避免半整数）

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];
	int m=0;
	for(int i=0;i<n;++i)
		for(int j=i+1;j<n;++j)
			s[m++]={x[i]+x[j],y[i]+y[j]};	// 和的范围 ±2e9，int 装得下
	sort(s,s+m);
	i64 ans=0;
	for(int i=0,k;i<m;)
	{
		k=1;
		while(i+k<m&&s[i+k]==s[i])
			++k;
		ans+=(i64)k*(k-1)/2;				// 同和的两对点自动不交，且每个四元组只有一种配对
		i+=k;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **存和而非中点**：`s[t]={x[i]+x[j],y[i]+y[j]}`。中点可能是半整数，和永远是整数；判"中点相同"等价于判"和相同"（引理 3），还省掉一次除法。
- **三个正确性支柱都靠"点互异"**：等和点对不共点（引理 4）、四元组配对唯一（引理 5）、中心不在组内（引理 2）——所以扫描段长直接 $\binom{k}{2}$，**没有任何修正项**。若题目允许重点，这三条全崩，写法要完全不同。
- `pair<int,int>` 默认字典序比较与 `==` 正好是"两个坐标和都相等"，不需要手写比较器。
- `x[i]+x[j]` 上界 $2\times10^9<2^{31}-1$，`int` 安全；但 `(i64)k*(k-1)/2` 仍先转 `i64`——理论上答案可达 $\binom{1000}{4}\approx4.1\times10^{10}$，题目虽保证 fit int32，累加器开 64 位是零成本保险。
- 只排序、只扫描 `[0,m)`：全局数组其余位置是默认 $0$，但永远不会被读到（本题无"未定义状态"陷阱）。
- 段扫描 `i+=k` 保证每段恰算一次；`while` 条件先查 `i+k<m` 再访问 `s[i+k]`，短路求值不越界。
