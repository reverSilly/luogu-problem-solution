# P3027 [USACO10OCT] Making Money G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 有 $N$ 种古董（$1\le N\le 100$），第 $i$ 种进价 $C_i$、售价 $R_i$（$1\le C_i,R_i\le 10^5$），每种可以买**任意多件**（无限量），买进的每一件都保证能卖出。初始资金 $M$（$1\le M\le 10^5$），总进价不能超过 $M$，可以不花光。求最大总利润 $\sum_i (R_i-C_i)\cdot x_i$，其中 $x_i\ge 0$ 是第 $i$ 种的购买件数。题目保证答案 $\le 10^9$。

**口径澄清一：利润到底怎么算？** 题面写"利润 = 初始钱数 - 总花费 + 总收入"，但看样例：$M=17$，买 5 件 3 号（花 15）+ 1 件 1 号（花 2），总收入 $5\times 7+4=39$，按那条公式是 $17-17+39=39$，而样例明说答案是 $5\times(7-3)+1\times(4-2)=22$。两者矛盾。样例是更硬的证据：那条公式算的其实是**年末总钱数**，利润应当是"年末钱数 $-$ 初始钱数"$=\sum(R_i-C_i)x_i$。本解按样例口径实现：目标函数 $\sum(R_i-C_i)x_i$，剩在手里的钱不算利润。

**口径澄清二：能不能卖了再买、滚动投资？** 题面说"可以以任意顺序卖出货物"，容易让人想"先买一件高价差古董，卖掉回笼资金，再买更多"。**这是不允许的（或者说与题意矛盾）**，可以用样例本身反证：若允许年中卖出再投资，样例里 3 号古董进 3 卖 7，买 5 件卖 35（资金变 37），再买 12 件卖 84（资金变 85）……资金每轮约乘 $7/3$，利润无上界，与样例答案 22、与"答案不超过 $10^9$"的保证都矛盾。所以正确模型是：**所有购买都受初始资金 $M$ 约束（$\sum C_i x_i\le M$），卖出只发生在年末清算，顺序无关紧要**。

**第一步：识别模型。** 目标 $\max\sum v_i x_i$（$v_i=R_i-C_i$），约束 $\sum C_i x_i\le M$，$x_i$ 为非负整数、无上界——这就是**完全背包**（无界背包）：体积 $C_i$、价值 $v_i$、容量 $M$。$N\cdot M=100\times 10^5=10^7$，一维滚动数组正序循环轻松通过。

**第二步：先试贪心，撞个反例。** 直觉上"性价比 $v_i/C_i$ 最高的先买满"很诱人，但整数件数会留下买不动的零头。手造反例：$M=10$，古董 A $(C=6,R=13)$ 性价比 $7/6\approx 1.17$，古董 B $(C=5,R=10)$ 性价比 $1$。贪心先买 1 件 A 花 6 赚 7，剩 4 元啥也买不了，总利润 7；而买 2 件 B 花 10 赚 **10**。贪心错，反例成立，老老实实 DP。这个反例也解释了题面提示"第二个样例很有挑战性，但我们的答案是正确的"——最优解可能不选性价比之王，也可能不花光钱。

**第三步：负利润古董直接扔。** 若 $R_i\le C_i$（$v_i\le 0$），买它只会占资金又不赚（甚至亏）。严格地说：任何包含这种古董的方案，把它的所有件删掉，花费不增（仍可行）、利润不减。所以预处理时跳过它们，不影响最优值。

**第四步：完全背包的一维写法与"恰好/至多"。** 一维数组 `dp[j]` 表示"预算**至多** $j$ 元时的最大利润"。初始化**全 0**——因为"什么都不买"永远可行、利润 0，所以"至多"语义下 0 是合法初值，**不需要**把非零位置设成 $-\infty$（那是"恰好花光"语义才要的）。转移对每种古董 $i$、$j$ 从 $C_i$ **正序**到 $M$：`dp[j]=max(dp[j],dp[j-C[i]]+v[i])`。正序是完全背包的标志：`dp[j-C[i]]` 在本轮可能已经被同种古董更新过，恰好允许"同一物品拿多件"。

**第五步：值域检查。** 答案 $\le 10^9$ 有保证；`dp[j]` 关于 $j$ 单调不减（预算大能模仿预算小的方案），故所有 `dp[j]<=dp[M]<=1e9`，中间量 `dp[j-C]+v<=1e9+1e5`，`int` 安全，不需要 `long long`。

**手造数据核对。**

第一组（题面样例）：$N=3,M=17$，$(2,4),(5,6),(3,7)$。$v=(2,1,4)$。最优 $x=(1,0,5)$：花费 $2+15=17$，利润 $2+20=22$。✓

第二组（买不起）：$N=1,M=1$，$(2,100)$。$C=2>M$，一件也买不了，答案 $0$。这组专打"全 0 初始化"的正确性。

第三组（贪心反例）：$N=2,M=10$，$(6,13),(5,10)$。答案 $10$（两件 B），不是贪心的 $7$。

第四组（负利润 + 不花光）：$N=2,M=10$，$(4,3),(3,5)$。A 亏钱跳过；B 买 3 件花 9 赚 6，剩 1 元。答案 $6$。验证"不必花光"与"跳过负价值"。

## 二、思维链：完整证明

**记号。** 物品种类 $i\in\{0,\dots,N-1\}$，费用 $C_i\ge 1$，价值 $v_i=R_i-C_i$（可负）。方案为向量 $x\in\mathbb Z_{\ge0}^N$，费用 $\mathrm{cost}(x)=\sum C_i x_i$，利润 $\mathrm{val}(x)=\sum v_i x_i$。可行 $\iff\mathrm{cost}(x)\le M$。定义
$$\mathrm{opt}(j)=\max\{\mathrm{val}(x):x\ge 0,\ \mathrm{cost}(x)\le j\},\qquad 0\le j\le M,$$
空方案保证 $\mathrm{opt}(j)\ge 0$（最大值在有限非空集合上取得：每件数 $x_i\le j/C_i$ 有界）。目标是 $\mathrm{opt}(M)$。

---

### 引理 1（模型口径：可行域就是 $\mathrm{cost}(x)\le M$）

在"购买受初始资金约束、年末统一清算"的口径下，方案可行当且仅当 $\sum C_i x_i\le M$；且该口径是唯一与样例相容的口径。

*证明*：口径的充分必要部分是建模假设：所有购买发生在卖出之前（或等价地，卖出所得不可再投资），故购买总额受 $M$ 限制；反之任何 $\mathrm{cost}(x)\le M$ 的购买清单都能按任意顺序完成支付。唯一性论证（反证）：若允许"卖出所得立即再投资"，取样例中 3 号古董（$C=3,R=7$），从 $M=17$ 出发反复"全仓买入再全卖出"：每轮资金 $\ge 17\ge 3$ 至少买得起一件，每件净赚 4，故每轮资金严格增加至少 4（首轮 $17\to 17-15+35=37$），无限轮后利润无上界，与样例答案 22 及"答案 $\le 10^9$"矛盾。故再投资口径被排除。利润公式按样例取 $\mathrm{val}(x)=\sum(R_i-C_i)x_i$（题面文字公式与样例矛盾，以样例为准，见 Part 1）。证毕。

---

### 引理 2（非正价值物品可剔除）

设 $I^+=\{i:v_i>0\}$。则 $\mathrm{opt}(M)$ 在只允许使用 $I^+$ 中物品时不变。

*证明*：只允许 $I^+$ 是原问题的限制，最优值不增，即 $\mathrm{opt}^+(M)\le\mathrm{opt}(M)$。反向：取原问题最优方案 $x^\*$，构造 $x'$：$x'_i=x^\*_i$（$i\in I^+$），$x'_i=0$（$i\notin I^+$）。则 $\mathrm{cost}(x')\le\mathrm{cost}(x^\*)\le M$（删项费用不增，$C_i>0$），且 $\mathrm{val}(x')=\mathrm{val}(x^\*)-\sum_{i\notin I^+}v_i x^\*_i\ge\mathrm{val}(x^\*)$（删掉的每项 $v_i x_i\le 0$）。故 $x'$ 是限制问题的可行解且价值不减，$\mathrm{opt}^+(M)\ge\mathrm{opt}(M)$。两边夹得相等。证毕。

---

### 引理 3（性价比贪心不正确：显式反例）

"按 $v_i/C_i$ 降序尽量多买"的贪心不总是最优。

*证明*：构造 $M=10$，物品 A $(C=6,v=7)$、B $(C=5,v=5)$。性价比 A $=7/6>1=$ B。贪心买 $\lfloor 10/6\rfloor=1$ 件 A，余 4 元买不起任何物品，利润 7。而方案 $x_B=2$ 费用 10、利润 10 $>7$。贪心输出 7 $\ne\mathrm{opt}(10)=10$（10 已是上界：任何方案利润 $\le\max_i(v_i/C_i)\cdot M=7/6\times 10<12$，枚举件数组合可验证 10 最优：A 至多 1 件，A=1 时 B=0 得 7；A=0 时 B$\le$2 得 10）。证毕。

**失败模式剖析**：贪心把资金当成可分割的连续量，但件数是整数，高性价比物品留下的"零头"可能浪费掉比性价比差距更多的钱。这个失败模式对一切"整数 + 容量"问题通用，正是背包 DP 存在的理由。

---

### 引理 4（最优子结构：拆掉一件）

对 $j\ge 0$：
$$\mathrm{opt}(j)=\max\Big(0,\ \max_{i:\,C_i\le j}\big[\mathrm{opt}(j-C_i)+v_i\big]\Big).$$

*证明*：($\ge$)：0 由空方案取得。对任一 $C_i\le j$，取预算 $j-C_i$ 的最优方案 $y$，令 $x=y+e_i$（第 $i$ 种加一件），则 $\mathrm{cost}(x)=\mathrm{cost}(y)+C_i\le j$，$\mathrm{val}(x)=\mathrm{opt}(j-C_i)+v_i$，可行故 $\mathrm{opt}(j)\ge$ 该值。对所有 $i$ 取 max 得 $\ge$。

($\le$)：取预算 $j$ 的最优方案 $x^\*$。若 $x^\*=0$，$\mathrm{opt}(j)=0$ 被右端第一项覆盖。否则存在 $i$ 使 $x^\*_i\ge 1$，令 $y=x^\*-e_i$，则 $\mathrm{cost}(y)=\mathrm{cost}(x^\*)-C_i\le j-C_i$（同时说明 $C_i\le j$），故 $\mathrm{val}(y)\le\mathrm{opt}(j-C_i)$，于是 $\mathrm{opt}(j)=\mathrm{val}(y)+v_i\le\mathrm{opt}(j-C_i)+v_i\le$ 右端。两边夹得等式。证毕。

**注意**：这条递推对"物品种类"没有分层——右端引用的 $\mathrm{opt}(j-C_i)$ 允许再次使用物品 $i$，这正是"无限量"的体现；而 $C_i\ge 1$ 保证 $j-C_i<j$，递推按 $j$ 严格递减、无环，可直接按 $j$ 正序递推。

---

### 引理 5（一维完全背包循环的不变量）

代码按物品种类外层（跳过 $v_i\le 0$）、$j$ 从 $C_i$ 到 $M$ **正序**内层执行 `dp[j]=max(dp[j],dp[j-C[i]]+v[i])`，初始 `dp` 全 0。则处理完前 $t$ 种（指 $I^+$ 中前 $t$ 种）后，对所有 $j$：
$$\texttt{dp}[j]=\mathrm{opt}_t(j):=\max\{\mathrm{val}(x):\text{只用前 }t\text{ 种},\ \mathrm{cost}(x)\le j\}.$$

*证明*：对 $t$ 归纳。$t=0$：只许空方案，$\mathrm{opt}_0(j)=0=\texttt{dp}[j]$ ✓。

设处理完 $t-1$ 种后不变量成立，现处理第 $t$ 种（费用 $c=C_{i_t}>0$，价值 $v=v_{i_t}>0$）。内层再对 $j$ 归纳，命题 $P(j)$：本轮处理完位置 $j$ 后 $\texttt{dp}[j]=\mathrm{opt}_t(j)$，且本轮尚未处理的位置 $j'>j$ 仍存 $\mathrm{opt}_{t-1}(j')$。

$j<c$：本轮不动它，$\texttt{dp}[j]=\mathrm{opt}_{t-1}(j)$；而预算 $j<c$ 装不下第 $t$ 种，$\mathrm{opt}_t(j)=\mathrm{opt}_{t-1}(j)$ ✓。

$j\ge c$：执行前 `dp[j]`$=\mathrm{opt}_{t-1}(j)$（未处理），`dp[j-c]`$=\mathrm{opt}_t(j-c)$（$j-c<j$，由内层归纳假设已处理；$j-c<c$ 时它是 $\mathrm{opt}_{t-1}(j-c)=\mathrm{opt}_t(j-c)$，同样成立）。执行后
$$\texttt{dp}[j]=\max\big(\mathrm{opt}_{t-1}(j),\ \mathrm{opt}_t(j-c)+v\big).$$
另一方面，把引理 4 的"拆一件"论证限制在前 $t$ 种物品上：预算 $j$ 的最优方案要么不用第 $t$ 种（价值 $\le\mathrm{opt}_{t-1}(j)$，且可取到），要么至少用一件（拆掉一件后是前 $t$ 种、预算 $j-c$ 的可行方案，价值 $\le\mathrm{opt}_t(j-c)+v$，且由"$\mathrm{opt}_t(j-c)$ 的方案加一件"可取到）。故
$$\mathrm{opt}_t(j)=\max\big(\mathrm{opt}_{t-1}(j),\ \mathrm{opt}_t(j-c)+v\big)=\texttt{dp}[j].\ ✓$$
内层归纳完成，外层归纳完成。处理完全部 $|I^+|$ 种后 $\texttt{dp}[M]=\mathrm{opt}_{|I^+|}(M)=\mathrm{opt}(M)$（最后一步用引理 2）。证毕。

**正序 vs 逆序的一句话**：正序让 `dp[j-c]` 已含第 $t$ 种，实现"同种无限件"；若逆序则 `dp[j-c]` 还是 $\mathrm{opt}_{t-1}$，退化成 0/1 背包。

---

### 引理 6（单调性与 `int` 安全性）

$\mathrm{opt}(j)$ 关于 $j$ 单调不减；所有 `dp[j]` 及中间量 `dp[j-c]+v` 都在 `int` 范围内。

*证明*：单调性：预算 $j_1\le j_2$ 的可行方案集合是包含关系（$\mathrm{cost}\le j_1\Rightarrow\mathrm{cost}\le j_2$），max 在更大集合上不减。故 $\texttt{dp}[j]=\mathrm{opt}(j)\le\mathrm{opt}(M)\le 10^9$（题目保证）。中间量 $\texttt{dp}[j-c]+v\le 10^9+10^5<2^{31}-1\approx 2.147\times 10^9$。下界方面 `dp` 恒 $\ge 0$。故全程 `int` 无溢出。证毕。

---

### 引理 7（复杂度）

时间 $O(NM)$，空间 $O(M+N)$。

*证明*：外层至多 $N$ 种，内层至多 $M$ 个位置，每位置一次加法一次 max，$O(1)$。代入 $N=100,M=10^5$ 得 $10^7$ 次基本运算，远低于 1 秒时限的常规容量。空间：`dp` 一维 $M+5$ 个 `int`（约 400 KB），物品数组 $O(N)$。证毕。

---

### 定理

程序输出 $\mathrm{opt}(M)=\max\{\sum(R_i-C_i)x_i:\sum C_i x_i\le M,\ x\in\mathbb Z_{\ge0}^N\}$，即题面（按样例口径）要求的最大利润。

*证明*：引理 1 确立可行域与目标函数的口径；引理 2 保证跳过非正价值物品不改变最优值；引理 3 排除贪心捷径、确认需要 DP；引理 4 给出无环的最优子结构；引理 5 证明一维正序循环恰好逐层计算出 $\mathrm{opt}_t(j)$，终态 `dp[M]` 即答案；引理 6 保证数值安全；引理 7 保证时限。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 用样例戳破题面两处歧义：利润是 $\sum(R-C)x$（不是年末总钱数）；卖出不可再投资（否则样例利润无上界）。
2. **reduce to easier problem** — 无限量购买 + 总费用 $\le M$ + 线性利润 $\Rightarrow$ 标准完全背包（体积 $C_i$，价值 $R_i-C_i$）。
3. **consider easier version** — 先试性价比贪心，手造 $M=10,(6,13),(5,10)$ 反例（贪心 7，最优 10），确认整数零头会杀死贪心。
4. **explore its property** — $v_i\le 0$ 的物品删掉不劣（删项论证），预处理跳过。
5. **classic problem solution** — 一维完全背包：全 0 初始化（"至多"语义，空方案可行），$j$ 正序循环允许同种重复选取。
6. **explore its property** — 值域核对：dp 单调不减 + 答案 $\le 10^9$ $\Rightarrow$ `int` 全程安全。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N,M$ | 物品种数、初始资金 | `int n,m` | 读入 |
| `mxn` | $100+5$ | `constexpr int` | 物品数组尺寸 |
| `mxm` | $10^5+5$ | `constexpr int` | dp 尺寸 |
| `c[i]` | 第 $i$ 种进价 $C_i$ | `int[mxn]` | 读入 |
| `v[i]` | 单件利润 $R_i-C_i$ | `int[mxn]` | 读入 $R$ 后现算；$\le 0$ 的跳过 |
| `dp[j]` | 预算**至多** $j$ 的最大利润 | `int[mxm]` | **全 0**（空方案可行，"至多"语义不需要 INF） |
| `r` | 读入售价的临时变量 | `int` | 循环内 |

### 算法步骤

1. I/O 加速三行；读 $N,M$；对每种读 $C_i,R_i$，令 `v[i]=r-c[i]`。
2. 对每种 $i$：若 `v[i]<=0` 跳过；否则 $j$ 从 `c[i]` **正序**到 $M$：`dp[j]=max(dp[j],dp[j-c[i]]+v[i])`。
3. 输出 `dp[m]`。

### 复杂度

- 时间：$O(NM)=10^7$。
- 空间：$O(M+N)\approx 400$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例（22）、买不起（0）、贪心反例（10）、负利润+不花光（6）四组手造数据全部吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3027 [USACO10OCT] Making Money G
// 完全背包：体积 C_i，价值 R_i-C_i，容量 M；利润按样例口径 = sum((R-C)*x)
// 全 0 初始化 = "预算至多 j"语义（空方案永远可行）；j 正序 = 同种无限件
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105},mxm{100005};

int n,m,c[mxn],v[mxn],dp[mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,r;i<n;++i)
	{
		cin>>c[i]>>r;
		v[i]=r-c[i];
	}
	for(int i=0;i<n;++i)
	{
		if(v[i]<=0)
			continue;	// 非正利润：删掉不劣（引理 2）
		for(int j=c[i];j<=m;++j)
			dp[j]=max(dp[j],dp[j-c[i]]+v[i]);	// 正序：dp[j-c] 可能已含第 i 种
	}
	cout<<dp[m]<<'\n';
	return 0;
}
```

### 代码说明

- **全 0 初始化是对的**：`dp[j]` 是"至多花 $j$ 元"的最优值，空方案利润 0 永远可行。只有"恰好花光"语义才需要把 `dp[1..M]` 填成 $-\infty$——本题不需要，别惯性套模板。
- `j` **正序**是完全背包与 0/1 背包唯一的代码差别：正序时 `dp[j-c[i]]` 已被本轮更新，等价于允许第 $i$ 种再拿一件。
- `v[i]<=0` 跳过是纯优化 + 语义清晰，不跳过也不会错（max 会拒绝劣转移），但跳过让引理 5 的归纳对象干净。
- 全程 `int`：`dp` 单调不减且答案 $\le 10^9$，中间量 $\le 10^9+10^5$，不越界（引理 6）。
- 读入售价用循环头临时变量 `r`，`v[i]` 现算，少开一个数组。
