# P3093 [USACO13DEC] Milk Scheduling S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 有 $N\le 10^4$ 头牛，每头挤奶恰花 $1$ 单位时间。牛 $i$ 有截止时间 $d_i\le 10^4$ 与产量 $g_i\le 1000$：只有把它安排在某个整点时刻 $t$ 开始、且 $t+1\le d_i$（即"在 $d_i$ 之前挤完"），才能拿到 $g_i$ 加仑，否则 $0$。时刻从 $0$ 开始，同一时刻只能挤一头牛。选一个安排方案，最大化总产量。

**时间口径。** 题面说"在时间 $t=x$ 之前，最多可以给 $x$ 头奶牛挤牛奶"，Hint 又强调"时刻 $3$ 之前（不包含时刻 $3$）"。据此：截止 $d$ 的牛可用的开始时刻是 $0,1,\dots,d-1$，共 $d$ 个**槽位**。等价地说，把时间轴切成单位槽 $[0,1),[1,2),\dots$，牛 $i$ 必须占一个编号 $<d_i$ 的槽。下文一律用这个口径。

**手造数据核对。** 题面 Hint 描述了 $4$ 头牛的例子但没给输入输出，按描述反推（牛 $1$：$g=10,d=3$；牛 $3$：$g=8,d=1$，$0$ 时刻挤；牛 $2$：$g=7$，$2$ 时刻挤，故 $d_2\ge3$，取 $5$；牛 $4$ 与牛 $3$ 冲突故 $d_4=1$，产量小于 $8$，取 $2$）：

```
4
10 3
7 5
8 1
2 1
```

最优：$t=0$ 挤牛 $3$（$8$），$t=1$ 挤牛 $1$（$10$），$t=2$ 挤牛 $2$（$7$），放弃牛 $4$。总产量 $8+10+7=25$，与 Hint 一致。

再造三组小数据备用：

- `3 / 1 1 / 100 2 / 2 2`：手算最优 $102$（挤 $100$ 和 $2$，放弃 $1$）。这组后面会用来**枪毙一个错误的贪心**。
- `3 / 5 1 / 4 1 / 3 1`：截止全是 $1$，只有一个槽，答案 $5$。
- `3 / 5 2 / 4 2 / 100 2`：截止全是 $2$，两个槽，答案 $100+5=105$。

**第一步：把"可行"翻译成数学条件。** 每头牛占一个槽、槽互不相同，牛 $i$ 只能用 $<d_i$ 的槽。一个牛集合 $S$ 能全部安排下，当且仅当

$$\forall t\ge1:\quad |\{j\in S:d_j\le t\}|\le t.$$

必要性显然：截止 $\le t$ 的牛只能挤在前 $t$ 个槽里。充分性也不难：把 $S$ 按截止升序排，第 $k$ 头放槽 $k-1$，条件恰好保证 $k\le d$。这一步把"排时间表"压缩成了"数个数"，是后面一切的地基（引理 1 严格证）。

**第二步：考虑简化版——所有截止相同。** 若所有 $d_i=D$，问题退化成"从 $N$ 个数里挑最大的 $D$ 个"。这提示一个**容量视角**：截止 $t$ 就是"前 $t$ 个槽的容量"。如果按 $d$ 升序处理牛，那么处理到牛 $i$ 时，已选牛截止都 $\le d_i$，它们加上牛 $i$ 可行的**唯一**障碍就是"总数超过 $d_i$"——前缀条件在更小的 $t$ 处早已满足。

**第三步： naive 贪心碰壁。** 顺着容量视角，最自然的写法是：按 $d$ 升序扫，`若已选数量 < d_i 就收下牛 i`。拿第二组小数据一跑：$(1,1)$ 收下（$1$ 个 $\le1$）；$(100,2)$ 收下（$2$ 个 $\le2$，满了）；$(2,2)$ 到来时已满，拒收。得 $101$。但最优是 $102$：把最早收下的 $1$ **吐出来**，换成 $2$。

失败模式很清楚：**早收下的牛不一定值得占着槽**。截止相同的后来者可能更优，而"满了就拒收"没有给后来者任何机会。修正：每头牛都**先无条件收下**，一旦总数超过当前容量 $d_i$，就踢掉已选里**产量最小**的那头。这就是**反悔贪心**：用一个小根堆维护已选产量，超容量就弹堆顶。刚才的反例里，$(2,2)$ 进来后堆 $\{1,100,2\}$ 大小 $3>2$，弹掉 $1$，得 $\{100,2\}=102$ ✓。

**第四步：为什么"踢最小"是对的，而不是踢别的？** 直觉上：容量只跟"数量"有关，跟踢谁无关（踢任何一头都恢复可行）；那当然踢损失最小的。但"每步局部损失最小"不等于"全局最优"——早先踢掉的牛会不会后面又需要？这里按 $d$ 升序处理救了场：后面的牛截止只会更大、容量只会更松，被踢的牛永远没有"复活"的机会与必要。严格证明走归纳 + 交换论证：设处理完前 $i-1$ 头时堆 $H$ 已是前 $i-1$ 头的最优可行子集，考察第 $i$ 头加入/弹出后的 $H'$，对最优解 $O$ 分"$c\in O$ / $c\notin O$"讨论，关键一步用**交换引理**（两个可行集，小的能从大的里借一个元素保持可行）把 $O$ 与 $H$ 接起来。全部细节在 Part 2。

**第五步：实现与范围。** 排序 $O(N\log N)$，每头牛一次 push、至多一次 pop，堆大小 $\le\max d\le10^4$。答案上界 $N\cdot\max g=10^7$，`int` 足够。堆里存 `int` 产量即可——产量相同的牛互相等价，弹哪头不影响权重。

## 二、思维链：完整证明

**记号。** 牛按截止升序重排为 $(g_1,d_1),\dots,(g_N,d_N)$，$d_1\le\dots\le d_N$（排序稳定性无关紧要）。对牛集合 $S$ 与整数 $t\ge1$，记 $\mathrm{cnt}_S(t)=|\{j\in S:d_j\le t\}|$，$w(S)=\sum_{j\in S}g_j$。称 $S$ **可行**，若存在把 $S$ 中每头牛放入互不相同的槽、牛 $j$ 的槽编号 $<d_j$ 的方案。算法维护已选集合 $H_i$（处理完前 $i$ 头后），$H_0=\varnothing$；第 $i$ 步：$H_{i-1}\cup\{i\}$ 若大小 $>d_i$ 则再删去其中 $g$ 最小的一头 $m$，得 $H_i$。小根堆正是 $H_i$ 的权重多重集实现。

---

### 引理 1（可行性的前缀计数判据）

$S$ 可行 $\iff\forall t\ge1:\mathrm{cnt}_S(t)\le t$。

*证明*：**必要性**：设方案存在。截止 $\le t$ 的牛所占槽编号 $<d_j\le t$，即都属于 $\{0,\dots,t-1\}$，共 $t$ 个；槽互不相同，故 $\mathrm{cnt}_S(t)\le t$。

**充分性**：设条件成立，$|S|=k$。把 $S$ 按截止升序排为 $e_1,\dots,e_k$，令 $e_j$ 占槽 $j-1$。槽互不相同 ✓。只需验证 $j-1<d_{e_j}$，即 $j\le d_{e_j}$：前 $j$ 头 $e_1,\dots,e_j$ 截止都 $\le d_{e_j}$，故 $\mathrm{cnt}_S(d_{e_j})\ge j$；由条件 $\mathrm{cnt}_S(d_{e_j})\le d_{e_j}$。两式夹出 $j\le d_{e_j}$ ✓。证毕。

**推论（遗传性）**：可行集的子集可行——子集的 $\mathrm{cnt}$ 逐点不超过原集合。后文交换论证与归纳都默认使用。

---

### 引理 2（截止升序下，可行性只查"总数"）

设 $S$ 可行且其中所有牛截止 $\le D$。则对截止恰为 $D$ 的新牛 $c$：$S\cup\{c\}$ 可行 $\iff|S|+1\le D$。

*证明*：($\Rightarrow$) 由引理 1 取 $t=D$：$\mathrm{cnt}_{S+c}(D)=|S|+1\le D$。($\Leftarrow$) 设 $|S|+1\le D$。对 $t<D$：$\mathrm{cnt}_{S+c}(t)=\mathrm{cnt}_S(t)\le t$（$c$ 截止 $D>t$ 不计入，$S$ 可行）。对 $t\ge D$：$\mathrm{cnt}_{S+c}(t)=|S|+1\le D\le t$。引理 1 判据全部满足。证毕。

**注**：证明只用到"$c$ 的截止是 $S\cup\{c\}$ 中最大者"，所以按 $d$ 升序处理时，"堆大小 $\le d_i$"就是**唯一**需要检查的约束——这正是算法里那个 `if` 的全部含义。

---

### 引理 3（交换引理）

设 $A,B$ 可行且 $|A|<|B|$。则存在 $x\in B\setminus A$ 使 $A\cup\{x\}$ 可行。

*证明*：$B\setminus A\ne\varnothing$。反设其中**每个** $x$ 都使 $A+x$ 不可行。由引理 1，对每个这样的 $x$ 存在 $t$ 使 $\mathrm{cnt}_{A+x}(t)>t$。而 $\mathrm{cnt}_{A+x}(t)=\mathrm{cnt}_A(t)+[d_x\le t]$ 且 $\mathrm{cnt}_A(t)\le t$（$A$ 可行），故必须

$$\mathrm{cnt}_A(t)=t\quad\text{且}\quad d_x\le t.$$

称满足 $\mathrm{cnt}_A(t)=t$ 的 $t$ 为**紧时刻**，集合记 $T$。上式说明 $T\ne\varnothing$；又 $t\in T\Rightarrow t=\mathrm{cnt}_A(t)\le|A|$，故 $T$ 有限，取 $t^\*=\max T$。

**断言：每个 $x\in B\setminus A$ 都有 $d_x\le t^\*$。** 若某个 $d_x>t^\*$：对 $t<d_x$，$\mathrm{cnt}_{A+x}(t)=\mathrm{cnt}_A(t)\le t$；对 $t\ge d_x>t^\*$，$t\notin T$，故 $\mathrm{cnt}_A(t)\le t-1$，加 $1$ 后 $\le t$。判据全满足，$A+x$ 可行，与反设矛盾。断言成立。

于是 $B$ 中截止 $\le t^\*$ 的牛至少包含 $A\cap B$ 里截止 $\le t^\*$ 的全部，再加上整个 $B\setminus A$：

$$\mathrm{cnt}_B(t^\*)\ \ge\ \mathrm{cnt}_{A\cap B}(t^\*)+|B\setminus A|\ =\ \bigl(t^\*-\mathrm{cnt}_{A\setminus B}(t^\*)\bigr)+|B\setminus A|\ \ge\ t^\*-|A\setminus B|+|B\setminus A|\ =\ t^\*+|B|-|A|\ >\ t^\*,$$

与 $B$ 可行（引理 1 在 $t^\*$ 处）矛盾。反设不成立，引理得证。证毕。

---

### 引理 4（算法每步的可行性与容量结构）

对每个 $i$：$H_i$ 可行，$|H_i|\le d_i$，且 $H_i$ 中所有牛截止 $\le d_i$。进一步，若第 $i$ 步发生弹出，则弹出前 $|H_{i-1}|=d_i$。

*证明*：对 $i$ 归纳。$H_0=\varnothing$ 平凡。设 $H=H_{i-1}$ 可行、截止均 $\le d_{i-1}\le d_i$，记 $c$ 为第 $i$ 头牛，$d=d_i$。

**不弹分支**（$|H|+1\le d$）：引理 2 给出 $H'=H+c$ 可行；$|H'|=|H|+1\le d$；截止均 $\le d$ ✓。

**弹出分支**（$|H|+1>d$）：先证 $|H|=d$。$H$ 可行且截止均 $\le d_{i-1}$，引理 1 取 $t=d_{i-1}$ 得 $|H|=\mathrm{cnt}_H(d_{i-1})\le d_{i-1}\le d$；分支条件给 $|H|\ge d$。夹出 $|H|=d$（顺带 $d_{i-1}=d$）。弹掉 $m$ 后 $|H'|=d$。可行性逐点验证：对 $t<d$，$\mathrm{cnt}_{H'}(t)=\mathrm{cnt}_H(t)+[d_c\le t]-[d_m\le t]=\mathrm{cnt}_H(t)-[d_m\le t]\le t$（$d_c=d>t$，$c$ 不计入）；对 $t\ge d$，$\mathrm{cnt}_{H'}(t)=|H'|=d\le t$。引理 1 判据满足 ✓。注意**无论弹的是谁都可行**——"踢最小"的合法性不靠可行性，靠下一条引理的最优性。证毕。

---

### 引理 5（最优性归纳：$H_i$ 是前 $i$ 头牛的最优可行子集）

对每个 $i$，$w(H_i)=\max\{w(S):S\subseteq\{1,\dots,i\},S\text{ 可行}\}$。

*证明*：对 $i$ 归纳。$i=0$ 平凡。设 $H=H_{i-1}$ 对前 $i-1$ 头最优（归纳假设），$c,g,d$ 为第 $i$ 头牛及其参数，$O$ 为前 $i$ 头牛的任一最优可行解。由引理 4，$H'$（即 $H_i$）可行，故只需证 $w(O)\le w(H')$。

**情形 A：不弹出，$H'=H+c$。**
- $c\in O$：$O-c$ 可行（遗传性）且含于前 $i-1$ 头，归纳假设给 $w(O-c)\le w(H)$，故 $w(O)=w(O-c)+g\le w(H)+g=w(H')$ ✓。
- $c\notin O$：$O$ 本身就是前 $i-1$ 头的可行解，$w(O)\le w(H)\le w(H')$ ✓。

**情形 B：弹出，$H'=H+c-m$，$g_m=\min(H+c)$ 的产量，$|H|=d$（引理 4）。**
- $c\notin O$：$w(O)\le w(H)$。若 $m=c$，$H'=H$，直接 $w(O)\le w(H')$ ✓；若 $m\ne c$，则 $g_m\le g_c$，$w(H')=w(H)+g_c-g_m\ge w(H)\ge w(O)$ ✓。
- $c\in O$：$O$ 可行且其中截止均 $\le d$，引理 1 取 $t=d$ 得 $|O|\le d=|H|$，故 $|O-c|\le d-1<|H|$。$O-c$ 与 $H$ 都是前 $i-1$ 头中的可行集，对它们用**引理 3**（$A=O-c$，$B=H$）：存在 $x\in H\setminus(O-c)$ 使 $(O-c)+x$ 可行。它含于前 $i-1$ 头，归纳假设给

$$w(O-c)+g_x\ \le\ w(H).$$

  又 $x\in H$，故 $g_x\ge\min(H)\ge g_m$（$m$ 是更大的集合 $H+c$ 的最小者）。于是

$$w(O)=w(O-c)+g_c\ \le\ w(H)-g_x+g_c\ \le\ w(H)-g_m+g_c\ =\ w(H').$$

  （$m=c$ 时 $g_m=g_c$，上式给出 $w(O)\le w(H)=w(H')$，同样成立。）✓

两情形穷尽，归纳完成。证毕。

**复盘**：整个证明的支点是三件事——引理 1 把 scheduling 变成计数；按 $d$ 升序使"超容量"成为唯一冲突（引理 2、4）；交换引理（引理 3）让"最优解 $O$ 含 $c$"这一最难情形能借 $H$ 的元素补位，而补位元素产量 $\ge g_m$ 恰好把"踢最小的损失"抵消。直觉"踢最小损失最小"由此升级为定理。

---

### 引理 6（堆实现与数值范围）

小根堆多重集与 $H_i$ 一一对应（按产量）；`ans` 始终等于 $w(H_i)$；最终答案 $\le10^7$，`int` 安全。

*证明*：每步 `push(g_i)` 对应加入 $c$；`if(size>d_i) pop()` 对应弹出最小产量者——产量相同的牛在权重意义下等价，弹哪头都不改变 $w(H')$ 与后续推理（引理 5 只用到 $g_m=\min$）。`ans+=g_i` 与 `ans-=Q.top()` 精确跟踪加入/弹出，故 `ans`$=w(H_i)$。上界：$w(H_N)\le\sum g_i\le N\cdot\max g=10^4\times1000=10^7<2^{31}$。堆大小 $\le\max d\le10^4$。证毕。

---

### 定理

程序输出最大总产量，时间 $O(N\log N)$，空间 $O(N)$。

*证明*：引理 1、2 保证"按 $d$ 升序 + 只查堆大小"正确刻画可行性；引理 4 保证每步 $H_i$ 可行；引理 3、5 保证 $H_N$ 最优；引理 6 保证堆与 `ans` 忠实实现 $H_i$ 及其权重。复杂度：排序 $O(N\log N)$；$N$ 次 push、至多 $N$ 次 pop，每次 $O(\log N)$；总计 $O(N\log N)$。空间：牛数组与堆均 $O(N)$。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 单位时长 + 截止时间 ⇒ 可行 $\iff\forall t:\mathrm{cnt}(d\le t)\le t$（Hall 型前缀计数），排时间表塌缩成数个数。
2. **consider easier version** — 所有截止同为 $D$ 时就是"挑最大的 $D$ 个"⇒ 容量视角：截止 = 前缀槽容量。
3. **explore its property** — 按 $d$ 升序处理时，已选截止都 $\le d_i$，新牛可行的唯一障碍是总数 $>d_i$，只需查堆大小。
4. **discuss by category** — "满了就拒收"被反例 $(1,1),(100,2),(2,2)$ 枪毙（$101<102$）：早收的小产量牛霸占槽位 ⇒ 必须允许反悔。
5. **classic problem solution** — 反悔贪心：小根堆维护已选产量，先无条件收，超容量弹堆顶；$O(N\log N)$。
6. **classic problem solution** — 交换引理（紧时刻计数反证）+ 对最优解分 $c\in O/c\notin O$ 的归纳，把"踢最小"证成全局最优。
7. **explore its property** — 答案 $\le10^7$ 用 `int`；堆存产量即可，同产量牛等价。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 牛数 $\le10^4$ | `int`，读入 | |
| `c[i].g` | 第 $i$ 头牛产量 $\le1000$ | `int` | 排序后按 $d$ 升序 |
| `c[i].d` | 第 $i$ 头牛截止 $\le10^4$ | `int` | 可用槽 $0\dots d-1$ |
| `mxn` | $10005$ | `constexpr int` | 约束 $+5$ |
| `Q` | 已选牛产量的**小根堆** | `priority_queue<int,vector<int>,greater<>>` | 堆顶 = 最该反悔的牛 |
| `ans` | 当前已选总产量 $w(H_i)$ | `int`，全局默认 $0$ | push 加、pop 减，最终即答案 |

### 算法步骤

1. I/O 加速三行；读 $N$ 与每头 $(g_i,d_i)$。
2. 按 $d$ 升序排序。
3. 顺序扫每头牛：`Q.push(g)`、`ans+=g`；若 `Q.size()>d`，`ans-=Q.top()`、`Q.pop()`（每步至多弹一次：上一步堆大小 $\le d_{i-1}\le d_i$，加一后最多超 $1$）。
4. 输出 `ans`。

### 复杂度

- 时间：$O(N\log N)$（排序 + $2N$ 次堆操作），$N\le10^4$。
- 空间：$O(N)$，堆大小 $\le\max d\le10^4$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Hint 反推样例输出 `25` 吻合；反悔反例输出 `102`、全截止 $1$ 输出 `5`、全截止 $2$ 输出 `105`、单牛输出 `1000`，均与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3093 [USACO13DEC] Milk Scheduling S
// 单位时长任务 + 截止时间 + 收益 ⇒ 按 d 升序扫，小根堆反悔贪心：
// 先收下当前牛，堆大小超过 d 就踢掉产量最小的（反悔）。
// 不变量：处理完前 i 头后，堆是前 i 头中收益最大的可行子集。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int n,ans;
struct cow{int g,d;}c[mxn];
priority_queue<int,vector<int>,greater<>>Q;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>c[i].g>>c[i].d;
	sort(c,c+n,[](cow a,cow b){return a.d<b.d;});
	for(int i=0;i<n;++i)
	{
		Q.push(c[i].g);
		ans+=c[i].g;
		if((int)Q.size()>c[i].d)	// 超容量则反悔：踢掉产量最小的
		{
			ans-=Q.top();
			Q.pop();
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **先收后踢**是反悔贪心的标志：`push` 无条件执行，`if` 只负责恢复容量。写成"满了就拒收"会在 $(1,1),(100,2),(2,2)$ 上输出 $101$ 而非 $102$。
- 每步至多弹一次：归纳有 $|H_{i-1}|\le d_{i-1}\le d_i$，加一后最多超出 $1$，所以 `if` 不用写 `while`。
- `(int)Q.size()` 的强转避免 `size_t` 与 `int` 比较的符号警告/隐患。
- 堆里只存产量不存牛：同产量牛在权重与可行性上完全等价（可行性只看数量与截止，而截止条件已由扫描顺序保证），弹哪头都一样。
- `ans` 上界 $10^7$，`int` 足够；若 $g_i$ 范围放大到 $10^9$ 级别才需要 `i64`。
- 排序比较器只比 $d$；$d$ 相同时顺序任意，引理 5 的证明对同截止牛的任意顺序都成立。
