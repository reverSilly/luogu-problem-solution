# P3074 [USACO13FEB] Milk Scheduling S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N$ 头奶牛（$1\le N\le 10^4$），第 $i$ 头挤奶要 $T_i$ 单位时间（$1\le T_i\le 10^5$）。$M$ 条约束（$1\le M\le 5\times 10^4$），每条形如"$A$ 必须**完全挤完**后，$B$ 才能**开始**"。工人无限多，可以同时给任意多头牛挤奶。约束保证无环。求挤完所有牛的**最短总时间**（makespan）。

**口径说明。** 题面 Hint 给了一个说明性例子：$3$ 头牛，$T=(10,5,6)$，约束 $3\to 2$；"$1$ 和 $3$ 同时开始，$3$ 完成后（时刻 $6$）开始 $2$，总耗时 $6+5=11$"。注意总时间**不是** $10+5+6=21$（那是只有一个工人的串行和），也**不是** $\max T_i=10$（那忽略了约束）。这钉死了语义：时间从 $0$ 起算，每头牛占用一个连续区间 $[s_i,s_i+T_i)$，约束是 $s_B\ge s_A+T_A$，答案是 $\max_i(s_i+T_i)$ 的最小值。

**手造小数据核对**（题面只有文字 Hint，没有样例输入输出，我把 Hint 写成输入，再补两组）：

第一组（即 Hint）：$N=3,M=1$，$T=(10,5,6)$，约束 $3\to 2$。牛 $1$ 无约束，$[0,10)$；牛 $3$ 无约束，$[0,6)$；牛 $2$ 必须等牛 $3$，$[6,11)$。答案 $11$。

第二组（纯链）：$N=3,M=2$，$T=(1,2,3)$，约束 $1\to 2,2\to 3$。只能串行：$1+2+3=6$。答案 $6$。

第三组（菱形）：$N=4,M=4$，$T=(5,1,1,5)$，约束 $1\to 2,1\to 3,2\to 4,3\to 4$。牛 $1$ 在 $[0,5)$；牛 $2,3$ 并行 $[5,6)$；牛 $4$ 在 $[6,11)$。答案 $11$。注意这里**不能**把牛 $2,3$ 的时间加起来——它们并行。

**第一步：先想两个退化版本找感觉。**

- 没有约束（$M=0$）：所有牛同时开始，答案 $\max_i T_i$。
- 约束构成一条链 $v_1\to v_2\to\cdots\to v_k$：链上必须串行，答案至少 $\sum T_{v_i}$；让链外牛随便并行，答案恰好 $\sum T_{v_i}$。

两个版本合起来提示：**答案由"最耗时的那条链"决定**——链内串行求和，链间并行取 max。这正是 DAG 上的**点权最长路**。

**第二步：下界好证，上界才是关键。** "任何可行方案的时间 $\ge$ 任何一条链的 $T$ 之和"几乎显然（链上后一头必须等前一头挤完）。但"存在一个方案恰好等于最长链"需要构造：会不会出现"链与链互相交错，逼得某头牛比最长链暗示的更晚"？

构造**最早开始调度**：每头牛一旦所有前驱挤完就立刻开始，一秒都不等。直觉上它不会比任何别的方案更晚——任何方案里牛 $v$ 的开始时间都被前驱的完成时间顶着，而最早开始调度把每个"顶着"都取到最紧。用归纳法可以严格证明：这个调度里牛 $v$ 的完成时刻 $f[v]$ 恰好等于"以 $v$ 结尾的最长链的 $T$ 之和"。于是 makespan $=\max_v f[v]=$ 全图最长链，下界被取到。

**第三步：怎么算 $f[v]$？** 递推式 $f[v]=T_v+\max_{u\to v}f[u]$（无前驱时 $\max$ 取 $0$）。它要求"算 $v$ 之前所有前驱 $u$ 的 $f[u]$ 已定"——这正是**拓扑序**。约束无环保证拓扑序存在，Kahn 算法（入度归零入队）一遍扫完即可，顺手把 DP 做了。

**第四步：实现上的一个小设计。** 可以让 `f[v]` 分两阶段：先当"前驱完成时刻的最大值"用（出队前不断被前驱 `max` 更新），出队时 `f[u]+=t[u]` 一步变成自身完成时刻。这样不需要第二个数组，且全局默认 $0$ 恰好是"无前驱"的正确初值——**本题不需要 INF**，因为 $\max$ 的单位元就是 $0$，而时间非负。

**第五步：范围核对。** 答案 $\le N\cdot\max T_i=10^4\times 10^5=10^9$，`int` 装得下（$<2^{31}-1$），但离上限不远，用 `i64` 更稳，也避免任何中间加法的疑虑。

## 二、思维链：完整证明

**记号。** DAG $G=(V,E)$，$|V|=N,|E|=M$，点权 $T_v\ge 1$。边 $u\to v$ 表示 $v$ 必须在 $u$ 完成后开始。调度给每点一个开始时刻 $s_v\ge 0$，可行当且仅当 $\forall(u\to v)\in E:\ s_v\ge s_u+T_u$。makespan 为 $\max_v(s_v+T_v)$。记 $L=\max\limits_{\text{路径 }v_1\to\cdots\to v_k}\sum_{i=1}^k T_{v_i}$（点权最长路，单点也算路径）。

---

### 引理 1（下界：任何可行调度的 makespan $\ge L$）

*证明*：任取路径 $v_1\to v_2\to\cdots\to v_k$ 与任何可行调度。由可行性，$s_{v_{i+1}}\ge s_{v_i}+T_{v_i}$。对 $i$ 归纳：$s_{v_i}\ge\sum_{j<i}T_{v_j}$。$i=1$ 时 $s_{v_1}\ge 0$（空和）✓；设对 $i$ 成立，则 $s_{v_{i+1}}\ge s_{v_i}+T_{v_i}\ge\sum_{j<i}T_{v_j}+T_{v_i}=\sum_{j<i+1}T_{v_j}$ ✓。于是
$$\text{makespan}\ge s_{v_k}+T_{v_k}\ge\sum_{j=1}^k T_{v_j}.$$
对所有路径取 max 即得 makespan $\ge L$。证毕。

---

### 引理 2（最早开始调度可行，且完成时刻 = 最长路 DP 值）

定义 $f[v]=T_v+\max\bigl(\{f[u]:u\to v\}\cup\{0\}\bigr)$（DAG 上按拓扑序良定义）。调度 $\mathcal A$：$s_v=f[v]-T_v=\max\bigl(\{f[u]:u\to v\}\cup\{0\}\bigr)$，每头牛连续挤 $T_v$ 时间。则：

(a) $\mathcal A$ 可行；
(b) $f[v]$ 等于以 $v$ 结尾的所有路径的最大点权和；
(c) $\mathcal A$ 的 makespan $=L$。

*证明*：(a) 对边 $u\to v$：$s_v=\max(\{f[w]:w\to v\}\cup\{0\})\ge f[u]=s_u+T_u$ ✓。

(b) 按拓扑序归纳。拓扑序保证归纳时所有前驱的结论已成立。以 $v$ 结尾的路径分两类：单点路径 $\{v\}$，权和 $T_v$；以及某前驱 $u$ 的"以 $u$ 结尾路径"接上 $v$，权和为（该路径权和）$+T_v$。由归纳假设，前一类最大值 $T_v$，后一类对固定 $u$ 的最大值是 $f[u]+T_v$。故
$$\max_{\text{以 }v\text{ 结尾}}=T_v+\max\bigl(\{f[u]:u\to v\}\cup\{0\}\bigr)=f[v].$$
（无前驱时只有单点路径，$\max$ 取 $0$，$f[v]=T_v$ ✓。）

(c) makespan $=\max_v(s_v+T_v)=\max_v f[v]$，由 (b) 即"所有路径的最大权和" $=L$（任何路径都以某点结尾）。证毕。

---

### 引理 3（最优性）

最短 makespan 恰为 $L$。

*证明*：引理 1 给出 $\ge L$，引理 2 构造出 $=L$ 的可行调度，夹逼即得。证毕。

**注**：这同时说明"最早开始"这个贪心**不会失败**——它的失败模式（某头牛被无谓拖延）被"一秒都不等"的构造直接排除，而引理 2(b) 证明不拖延恰好把每头牛顶在最长路给出的最早可能时刻上。

---

### 引理 4（Kahn 算法处理全部点，且出队时前驱均已处理）

DAG 上跑 Kahn：入度 $0$ 入队；出队 $u$ 时把每条出边 $u\to v$ 的 `deg[v]--`，归零则 $v$ 入队。则每个点恰好入队、出队一次，且 $v$ 出队时其所有前驱都已出队。

*证明*：先证**任何非空 DAG 有入度 $0$ 的点**：反设所有点入度 $\ge 1$，从任一点沿入边反向走，每步都有前驱可走，$N+1$ 步内必重复某点（鸽笼），重复段即环，与无环矛盾。

再证算法不会"卡住"：设某时刻队列空但还有点未出队。未出队点构成的诱导子图仍是 DAG（子图无环），由上段它有入度 $0$ 的点 $w$（在子图内）。$w$ 在原图的前驱要么已出队（其出边已删，`deg` 已减），要么也在子图内——后者与 $w$ 子图入度 $0$ 矛盾。故 $w$ 的所有前驱已出队，`deg[w]` 已被减到 $0$，$w$ 早已入队，与队列空矛盾。故所有点都会出队。

每点入队仅当 `deg` 归零，而 `deg` 只减不增，故至多入队一次；每条边恰在其起点出队时被处理一次，`deg[v]` 恰被减（$v$ 的入度）次，故 $v$ 入队当且仅当所有前驱出队完毕。出队顺序即拓扑序。证毕。

---

### 引理 5（代码的两阶段 `f` 正确实现 DP）

代码中 `f[v]` 初值 $0$；前驱 $u$ 出队时执行 `f[v]=max(f[v],f[u])`；$v$ 自己出队时执行 `f[v]+=t[v]`。则 $v$ 出队后 `f[v]` 等于引理 2 的 $f[v]$。

*证明*：由引理 4，$v$ 出队时所有前驱已出队，且每个前驱 $u$ 出队时已把**自身的最终** `f[u]`（出队即 `+=t[u]` 之后）传播给 $v$。故 $v$ 出队前 `f[v]`$=\max(\{f[u]:u\to v\}\cup\{0\})$（初值 $0$ 提供空集情形；`max` 结合交换，传播顺序无关）。出队时 `+=t[v]` 后恰为 $T_v+\max(\cdots)$，即引理 2 的递推值。又由引理 4 的拓扑序，前驱的 `f[u]` 在传播时已是最终值，归纳成立。证毕。

**实现要点**：这里全局数组默认 $0$ **恰好正确**（$\max$ 单位元、时间非负），与"最短路必须 fill INF"的情形相反——判断标准是"默认值是不是该运算的合法单位元"。

---

### 引理 6（复杂度与数值范围）

时间 $O(N+M)$，空间 $O(N+M)$；答案 $\le 10^9$。

*证明*：读入 $O(N+M)$；初始扫入度 $O(N)$；Kahn 每点出队一次、每边处理一次，$O(N+M)$。空间：`graph` 共 $M$ 个 `int`，其余数组 $O(N)$。答案 $=L\le$ 某条路径点数 $\times\max T\le N\cdot 10^5=10^9<2^{31}-1$，`int` 可容；代码用 `i64` 留余量。证毕。

---

### 定理

程序输出 DAG 点权最长路长度 $L$，即最短挤奶总时间；时间 $O(N+M)$，空间 $O(N+M)$。

*证明*：引理 1、2、3 确立"答案 $=L$"；引理 4 保证 Kahn 给出合法拓扑序；引理 5 保证代码算出的 `f` 就是最长路 DP 值，`ans=max f` 即 $L$；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "工人无限"意味着并行不受限，约束只有先后关系；总时间不是串行和也不是 $\max T_i$，而是 makespan。
2. **consider easier version** — 无约束 ⇒ $\max T_i$；单链 ⇒ $\sum T$。两个退化版拼出猜想：答案 = 最耗时链。
3. **reduce to easier problem** — 原问题归约为 DAG 点权最长路：链内串行求和、链间并行取 max。
4. **explore its property** — 下界（任何链必须串行）易证；上界靠构造"最早开始调度"，归纳证明其完成时刻恰为最长路 DP 值，贪心无失败模式。
5. **classic problem solution** — 拓扑排序（Kahn 入度归零）+ 拓扑序上 DP：$f[v]=T_v+\max_{u\to v}f[u]$，一遍扫完。
6. **discuss by category** — 无前驱时 $\max$ 取 $0$，全局默认 $0$ 恰好是单位元，本题**不需要** INF；答案上界 $10^9$ 用 `i64` 留余量。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,m` | 牛数 $\le 10^4$、约束数 $\le 5\times 10^4$ | `int` | 读入 |
| `t[i]` | 牛 $i$ 的挤奶时长 $T_i$ | `int[mxn]` | 读入，0-based |
| `deg[v]` | $v$ 的剩余入度（未处理前驱数） | `int[mxn]` | 建图时 `++`，默认 $0$ 正确 |
| `graph[u]` | $u$ 的后继列表 | `vector<int>[mxn]` | 边 $u\to v$ |
| `f[v]` | 两阶段：出队前 = 前驱完成时刻最大值；出队后 = $v$ 的完成时刻 | `i64[mxn]` | 默认 $0$ = $\max$ 单位元，**无需 INF** |
| `q,qh,qt` | Kahn 队列（入度已归零的点） | `int[mxn]` + 下标 | 初始扫一遍入度 |
| `ans` | $\max_v f[v]$，即最长路 | `i64` | 每次出队 `max` 更新 |

### 算法步骤

1. I/O 加速三行；读 $N,M$ 与全部 $T_i$。
2. 读约束 $A,B$（转 0-based），建边 `graph[A].push_back(B)`，`++deg[B]`。
3. 所有 `deg==0` 的点入队。
4. 出队 $u$：`f[u]+=t[u]`（此刻成为最终完成时刻）；`ans=max(ans,f[u])`；对每个后继 $v$：`f[v]=max(f[v],f[u])`，`--deg[v]` 归零则入队。
5. 队空后输出 `ans`。

### 复杂度

- 时间：$O(N+M)$；$N=10^4,M=5\times 10^4$ 时约 $6\times 10^4$ 次基本操作。
- 空间：$O(N+M)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；四组手造数据（Hint 例 / 纯链 / 菱形 / 无约束）输出 $11,6,11,7$ 全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3074 [USACO13FEB] Milk Scheduling S
// 无限工人 ⇒ 最短总时间 = DAG 点权最长路；拓扑序上 DP f[v]=t[v]+max f[u]
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005},mxm{50005};

int n,m,t[mxn],deg[mxn];
i64 f[mxn];	// f[v] 先存"前驱完成时刻的最大值"，出队时 +=t[v] 变成自身完成时刻
vector<int>graph[mxn];
int q[mxn],qh,qt;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>t[i];
	for(int i=0,u,v;i<m;++i)
	{
		cin>>u>>v;--u;--v;
		graph[u].push_back(v);
		++deg[v];
	}
	for(int i=0;i<n;++i)
		if(!deg[i])
			q[qt++]=i;
	i64 ans=0;
	while(qh<qt)
	{
		int u=q[qh++];
		f[u]+=t[u];	// 此刻 f[u] 已是最终完成时刻（所有前驱都处理过）
		ans=max(ans,f[u]);
		for(int v:graph[u])
		{
			f[v]=max(f[v],f[u]);
			if(!--deg[v])
				q[qt++]=v;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **两阶段 `f`**：出队前 `f[v]` 是"前驱完成时刻的 max"，出队瞬间 `+=t[u]` 变成自身完成时刻再传播。一个数组干两件事，靠的是引理 4 保证"出队时前驱全部处理完"。
- **不需要 INF**：`f` 的初值 $0$ 是 $\max$ 的单位元且时间非负，无前驱的牛自然得到 $f=T_v$。这与最短路问题（$0$ 会被误当可达）本质不同。
- `if(!--deg[v])`：先减再判零，归零即所有前驱处理完毕，入队时机恰好。
- 答案用 `i64`：理论上界 $10^9$ 虽在 `int` 内，留余量防任何中间量意外。
- 题面保证无环，故不必检查"是否所有点都出队"；若有环，Kahn 会漏点，但本题不存在该情形。
