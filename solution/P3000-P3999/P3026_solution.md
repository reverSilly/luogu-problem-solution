# P3026 [USACO11OPEN] Learning Languages S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 有 $N$ 头奶牛（$2\le N\le 10^4$）和 $M$ 种语言（$1\le M\le 3\times10^4$）。第 $i$ 头牛会 $K_i$ 种语言（$1\le K_i\le M$，且 $\sum K_i\le 10^5$）。两头牛能"交流"当且仅当它们会同一门语言，或者能通过若干头牛接力翻译（每相邻两头共享一门语言）。一本书 = 教某头牛某门语言。问最少买几本书，才能让所有牛两两都能交流。

**输出口径（必须先定下来）。** 原题要求输出最少书数 + 一组具体方案，但题面开头的管理组提示明确写着：

> 本题 SPJ 缺失，故目前只应当输出第一行而不需要输出方案。

所以本题解（与代码）**只输出一个整数**：最少书数。这不是偷懒，而是当前评测方式的硬性要求——多输出方案行反而会 WA。

**第一步：把"交流"翻译成图论语言。** "共享一门语言"是牛与牛之间的一条无向边；"接力翻译"就是沿边走一条路径。于是"所有牛两两能交流" $\iff$ 这张图**连通**。问题变成：每次操作可以给图加若干条边（教牛 $u$ 语言 $\ell$，等于把 $u$ 和所有会 $\ell$ 的牛连边），最少几次操作让图连通。

**第二步：答案的猜测。** 图论直觉立刻给出候选答案：**连通块个数 $c$ 减一**。理由的两半都不难：

- 下界：一本书最多把两个连通块粘成一个（会同一门语言的牛本来就两两相邻，必在同一个块里），块数一次最多减 $1$，从 $c$ 到 $1$ 至少要 $c-1$ 本书。
- 上界：随便挑一门有牛会的语言 $\ell^\*$（$K_1\ge 1$ 保证存在），给其余 $c-1$ 个块各挑一头代表牛教 $\ell^\*$，所有块就都挂到 $\ell^\*$ 所在的块上了，恰好 $c-1$ 本。

两边一夹，答案就是 $c-1$。**注意题面保证 $K_i\ge 1$**：原版 USACO 允许 $K_i=0$，那时若所有牛都是"文盲"答案是 $N$ 而不是 $c-1=N-1$（第一本书不会把文盲挂到任何块上）。本题约束把这个恼人的特判直接排除了——读约束时就要意识到这一点。

**第三步：怎么数连通块？** 直接建牛-牛边最坏 $\Theta(N^2)$（一万头牛全会同一门语言），不可行。但 $\sum K_i\le 10^5$ 提示我们：**边数应该按"牛-语言"关系算，而不是按"牛-牛"算**。经典手法是并查集 + "每种语言记第一头会它的牛"：

- 开数组 `fst[l]`：语言 $\ell$ 第一次被哪头牛提到。初值 $-1$ 表示还没牛会。
- 牛 $i$ 会语言 $\ell$：若 `fst[l]==-1` 就记下 `fst[l]=i`；否则把 $i$ 和 `fst[l]` 所在集合合并。

这样每门语言的全体使用者都被串到 `fst[l]` 上，形成一个"星形"，与"两两连边"的连通性完全一致，但只用了 $\sum K_i$ 次合并。最后扫一遍牛，数 `getrt(i)==i` 的个数就是 $c$。

**第四步：一个必须警惕的实现陷阱。** `fst` 是全局 `int` 数组，默认值是 $0$——而 $0$ 是**合法的牛下标**（内部 0-based）！不显式 `fill_n(fst,m,-1)` 的话，每门语言都会被当成"第 0 头牛已经会了"，把所有牛错误地并成一坨，答案恒为 $0$。这正是"全局数组默认 0 不是 INF/未定义"这条铁律的活例子。

**手造数据核对。**

第一组（题面正文里的例子）：$N=3,M=3$；Alberta 会 $\{2,3\}$，Bessie 会 $\{2\}$，Contessa 会 $\{1\}$。Alberta–Bessie 共享语言 2 连通，Contessa 独立，$c=2$，答案 $1$。与题面"买一本书教 Contessa 语言 2"一致。

```
输入：
3 3
2 2 3
1 2
1 1
输出：
1
```

第二组（边界：已经连通 / 全独立）：

```
输入：
2 1
1 1
1 1
输出：
0        ← 两头牛都会语言 1，c=1，一本书都不用买
```

```
输入：
4 4
1 1
1 2
1 3
1 4
输出：
3        ← 四头牛各会一门互不相同的语言，c=4
```

第三组（专打"星形合并"的传递性）：牛 1 会 $\{1,2\}$，牛 2 会 $\{2,3\}$，牛 3 会 $\{3\}$。没有任何两头牛"直接共享很多语言"，但 $1-2$ 通过语言 2、$2-3$ 通过语言 3 连成一条链，$c=1$，答案 $0$。这组验证了"接力翻译"确实被并查集正确捕捉。

## 二、思维链：完整证明

**记号。** 牛集合 $V=\{0,\dots,N-1\}$（0-based），语言集合 $\{0,\dots,M-1\}$。$S_i\subseteq\{0,\dots,M-1\}$ 是牛 $i$ 会的语言集，$|S_i|=K_i\ge 1$。定义无向图 $G=(V,E)$：$\{u,v\}\in E\iff u\ne v\land S_u\cap S_v\ne\varnothing$。设 $G$ 的连通块数为 $c$。一本书是一个二元组 $(u,\ell)$，效果是 $S_u\leftarrow S_u\cup\{\ell\}$（从而更新 $E$）。

---

### 引理 1（"能交流"恰好是图连通性）

牛 $A$ 与 $B$ 能交流（含 $A=B$ 的平凡情形）$\iff$ $A,B$ 在 $G$ 的同一连通块。

*证明*：题面定义：$A,B$ 能交流当且仅当存在牛序列 $T_1,\dots,T_k$（$k\ge 0$，$k=0$ 理解为 $A,B$ 直接共享语言或 $A=B$），使 $A$ 与 $T_1$、相邻 $T_j$ 之间、$T_k$ 与 $B$ 都共享语言。把序列写成 $A,T_1,\dots,T_k,B$，"相邻两牛共享语言"逐字就是 $G$ 中一条从 $A$ 到 $B$ 的路径（相邻顶点有边）。反之 $G$ 中任一路径去掉端点就是合法的翻译序列。故"能交流"$=$"存在路径"$=$"同一连通块"（连通块的定义就是路径可达等价类；自反性由长度 $0$ 的路径给出，对称性由无向边给出，传递性由路径拼接给出）。证毕。

**推论**：目标"所有牛两两能交流" $\iff$ $G$ 连通 $\iff$ 块数 $=1$。

---

### 引理 2（星形并查集算出的块数就是 $c$）

算法：`f` 为牛上的并查集（初始各自成块）；`fst[l]` 初始 $-1$。按输入顺序处理每对 $(i,\ell)$（$\ell\in S_i$）：若 `fst[l]==-1` 则置 `fst[l]=i`，否则合并 $i$ 与 `fst[l]`。处理完后，对任意两头牛 $u,v$：它们在并查集中同集合 $\iff$ 在 $G$ 中同连通块。特别地，`getrt(i)==i` 的 $i$ 的个数等于 $c$。

*证明*：记并查集最终形成的等价关系为 $\approx$，图连通关系为 $\sim$。

**($\approx\Rightarrow\sim$)**：并查集的每次合并在 $i$ 与 `fst[l]` 之间进行，而这两头牛都会语言 $\ell$（`fst[l]` 只在某头会 $\ell$ 的牛处被赋值，且此后不变），故 $\{i,\texttt{fst}[l]\}\in E$ 是一条真实的边。并查集同集合意味着存在一串这样的合并边把 $u,v$ 连起来，即 $G$ 中一条路径，故 $u\sim v$。

**($\sim\Rightarrow\approx$)**：只需证每条图边 $\{u,v\}\in E$ 的两端满足 $u\approx v$（因为 $\approx$ 是等价关系，路径上逐边传递即可）。设 $u,v$ 共享语言 $\ell$。处理完 $(u,\ell)$ 与 $(v,\ell)$ 两对之后，`fst[l]` 已被赋值为某个会 $\ell$ 的牛 $w$（两者中先被处理的那个），且 $u$ 与 $w$、$v$ 与 $w$ 都发生过合并（或本人就是 $w$）。由传递性 $u\approx w\approx v$。

两个方向合起来 $\approx\;=\;\sim$。等价类个数即连通块数；并查集每个等价类恰有一个根（`f[x]==x` 的代表），故数根即数块。证毕。

---

### 引理 3（一本书至多让块数减一）

设当前图为 $G$（块数 $c\ge 2$），执行任意一本书 $(u,\ell)$ 后块数 $c'$ 满足 $c'\ge c-1$。

*证明*：教 $u$ 语言 $\ell$ 只改变 $S_u$，新增的边全部形如 $\{u,v\}$，其中 $\ell\in S_v$（$v\ne u$）。关键观察：**所有会 $\ell$ 的牛两两共享 $\ell$，两两有边，必在同一个连通块里**（若没有任何牛会 $\ell$，则一本书不加任何边，$c'=c$）。设会 $\ell$ 的牛所在块为 $B_\ell$，$u$ 所在块为 $B_u$。新边只连接 $B_u$ 与 $B_\ell$：

- 若 $B_u=B_\ell$（含 $u$ 已会 $\ell$ 的情形），无块合并，$c'=c$；
- 若 $B_u\ne B_\ell$，恰好这两个块合并成一个，其余块不受影响，$c'=c-1$。

两种情形都有 $c'\ge c-1$。证毕。

---

### 引理 4（下界：至少 $c-1$ 本）

任何使图连通的购书序列长度 $\ge c-1$。

*证明*：设买了 $t$ 本书，块数序列 $c=c_0\ge c_1\ge\dots\ge c_t=1$。由引理 3，每步 $c_{j}-c_{j+1}\le 1$，故 $c-1=\sum_{j=0}^{t-1}(c_j-c_{j+1})\le t$。证毕。

---

### 引理 5（上界：$c-1$ 本足够，且构造显式）

存在 $c-1$ 本书使图连通。

*证明*：由 $K_0\ge 1$，牛 $0$ 至少会一门语言，任取其一记 $\ell^\*\in S_0$。设 $c$ 个连通块为 $C_0\ni 0,C_1,\dots,C_{c-1}$。对每个 $j=1,\dots,c-1$，任取代表牛 $r_j\in C_j$，买书 $(r_j,\ell^\*)$。每本书让 $r_j$ 与牛 $0$ 共享 $\ell^\*$，产生边 $\{r_j,0\}$，把 $C_j$ 与 $C_0$ 合并。$c-1$ 本书后所有块并入 $C_0$，图连通。共用 $c-1$ 本。证毕。

（若采用"只输出第一行"的口径，这个构造不需要真的输出；但它的存在性是答案正确性的另一半，必须证。）

**约束的作用**：若允许 $K_i=0$ 且所有牛都文盲，则不存在 $\ell^\*$，上界构造失效；此时第一本书只能凭空造出一个"会某语言的牛"，其余 $N-1$ 头仍需各一本，答案为 $N$。本题 $K_i\ge 1$ 排除了该情形，故无需特判。

---

### 引理 6（`fst` 必须显式初始化为 $-1$）

若 `fst` 保持全局默认的 $0$，算法结果可能错误；`fill_n(fst,m,-1)` 后算法正确。

*证明*：$0$ 是合法牛下标。若语言 $\ell$ 实际上没有牛会，但 `fst[l]==0`，则第一头会 $\ell$ 的牛 $i$ 会走"否则"分支与牛 $0$ 合并——而牛 $0$ 未必会 $\ell$，这条合并不对应任何真实边，引理 2 的 ($\approx\Rightarrow\sim$) 方向被破坏。例如 $N=2$，牛 0 会 $\{1\}$、牛 1 会 $\{2\}$：正确答案 $1$，但未初始化时牛 1 被错误并入牛 0，输出 $0$。显式填 $-1$ 后，"还没牛会"与"牛 0 会"被区分开，引理 2 的前提恢复。证毕。

---

### 引理 7（复杂度）

时间 $O\big((N+\sum K_i)\,\alpha(N)\big)$，空间 $O(N+M)$；其中 $\alpha$ 为反阿克曼函数（路径压缩 + 按秩合并的并查集单次操作均摊上界；仅路径压缩时为均摊 $O(\log N)$ 量级，同样远低于时限）。

*证明*：初始化 `iota`/`fill` 共 $O(N+M)$。每对 $(i,\ell)$ 至多两次 `getrt` 与一次合并，共 $O(\sum K_i)$ 次并查集操作。最后数根 $O(N)$ 次 `getrt`。代入 $N\le 10^4,\sum K_i\le 10^5$，操作数约 $1.1\times 10^5$ 次均摊近常数操作。空间：`f` 占 $O(N)$，`fst` 占 $O(M)$。证毕。

---

### 定理

程序输出的整数恰为最少购书数 $c-1$。

*证明*：引理 1 把目标归约为图连通；引理 2 保证并查集数出的块数就是 $G$ 的块数 $c$（引理 6 保证其初始化前提成立）；引理 4 给出下界 $c-1$，引理 5 给出可达的上界 $c-1$，二者相夹得最优值恰为 $c-1$；引理 7 保证在约束内跑得完。按管理组提示只输出第一行，与当前评测口径一致。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "接力翻译"就是路径可达：把"共享语言"建边，目标即图连通。
2. **explore its property** — 一本书只能把"牛所在块"与"该语言使用者所在块"合并，块数一次至多减一。
3. **reduce to easier problem** — 最少操作数被上下界夹死为连通块数 $c-1$，问题归约为数连通块。
4. **consider easier version** — 直接建牛-牛边最坏 $\Theta(N^2)$；改按"牛-语言"关系（$\sum K_i\le 10^5$）建星形边。
5. **classic problem solution** — 并查集 + 每种语言记首个使用者 `fst[l]`，星形合并等价于团合并。
6. **discuss by category** — $K_i\ge 1$ 排除"全文盲答案为 $N$"的特判；SPJ 缺失 ⇒ 只输出第一行；`fst` 必须 fill 成 $-1$（$0$ 是合法下标）。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N,M$ | 牛数、语言数 | `int n,m` | 读入 |
| `mxn` | $10^4+5$ | `constexpr int` | 牛数组尺寸 |
| `mxm` | $3\times10^4+5$ | `constexpr int` | 语言数组尺寸 |
| `f[i]` | 并查集父亲 | `int[mxn]` | `iota(f,f+n,0)`，各自成块 |
| `fst[l]` | 语言 $\ell$ 的**首个使用者**（牛下标） | `int[mxm]` | **必须 `fill_n(fst,m,-1)`**；$-1$=尚无牛会，$0$ 是合法下标 |
| `getrt(x)` | 路径压缩找根 | `int(int)` | 一行递归 |
| `k,l` | 当前牛的语言数 / 当前语言（读入后 `--l`） | `int` | 循环内临时 |
| `ans` | 连通块数 $c$，输出前减一 | `int`，初值 $0$ | 数 `getrt(i)==i` |

### 算法步骤

1. I/O 加速三行；读 $N,M$。
2. `iota(f,f+n,0)`；`fill_n(fst,m,-1)`。
3. 对每头牛 $i$：读 $K_i$；对每门语言 $\ell$（`--l`）：若 `fst[l]==-1` 置 `fst[l]=i`，否则 `f[getrt(i)]=getrt(fst[l])`。
4. 扫 $i=0..N-1$，统计 `getrt(i)==i` 的个数得 $c$。
5. 输出 $c-1$（只输出第一行，SPJ 缺失口径）。

### 复杂度

- 时间：$O((N+\sum K_i)\,\alpha(N))$，约 $1.1\times10^5$ 次并查集操作。
- 空间：$O(N+M)$，约 $160$ KB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面例子（答案 1）、全连通（答案 0）、全独立（答案 3）、链式传递（答案 0）四组手造数据全部吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3026 [USACO11OPEN] Learning Languages S
// 答案 = 牛-语言图的连通块数 - 1（K_i>=1 保证无"全文盲"特判）
// 每门语言记首个使用者 fst[l]，把该语言的所有使用者星形合并，等价于两两连边
// SPJ 缺失：只输出第一行的最少书数
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005},mxm{30005};

int n,m,f[mxn],fst[mxm];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	iota(f,f+n,0);
	fill_n(fst,m,-1);	// 0 是合法牛下标，"尚无牛会"必须用 -1，不能靠默认 0
	for(int i=0,k,l;i<n;++i)
	{
		cin>>k;
		for(int j=0;j<k;++j)
		{
			cin>>l;--l;
			if(fst[l]==-1)
				fst[l]=i;
			else
				f[getrt(i)]=getrt(fst[l]);	// 星形合并：都挂到首个使用者上
		}
	}
	int ans=0;
	for(int i=0;i<n;++i)
		if(getrt(i)==i)
			++ans;
	cout<<ans-1<<'\n';
	return 0;
}
```

### 代码说明

- `fst` 的 `fill_n(...,-1)` 是全代码最容易翻车的一行：不填的话每门语言都被当成"牛 0 已会"，所有牛被错误连通，答案恒 $0$（引理 6 给了显式反例）。
- 合并写成 `f[getrt(i)]=getrt(fst[l])`：把 $i$ 的根挂到语言首个使用者的根上。只有路径压缩没有按秩合并，最坏单次 $O(\log N)$ 均摊，本题规模绰绰有余。
- 数块用"根的个数"而不是"不同 `getrt` 值的个数"：每个等价类恰有一个根，二者等价，前者少开一个数组。
- 输出 `ans-1`：$K_i\ge 1$ 保证 $c\ge 1$，结果非负；按管理组提示不输出方案行。
