# P3016 [USACO11FEB] The Triangle S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给定一个 $N$ 行的数字三角形（第 $i$ 行 $i$ 个数，$1\le K\le N\le 700$，$K\le 20$，$-10^9\le v_{i,j}\le 10^9$）。从中选一个**行数至少为 $K$** 的子三角形——子三角形必须沿网格对齐，可以**正立**（尖朝上），也可以**倒立**（尖朝下）。把子三角形内所有数求平均，**抹除小数**得到金币数（负数则扣金币），求最大金币数。时限 2 秒，空间 32 MB。

两个必须先钉死的口径：

1. **"抹除小数"= 向零截断**，不是向下取整。题面例子 $2.333\dots\to 2$ 看不出区别，但"抹除"的字面意思就是删掉小数部分：$-2.333\dots$ 应得 $-2$ 而不是 $-3$。C++ 的整数除法（C++11 起标准规定向零截断）恰好就是这个语义，负数分支我会专门造数据核对。
2. **子三角形的形状**：正立三角形由顶点 $(i,j)$ 与行数 $s$ 确定，第 $t$ 层（$t=0..s-1$）占据行 $i+t$ 的第 $j..j+t$ 列；倒立三角形由**底点** $(i,j)$ 与行数 $s$ 确定，第 $t$ 层占据行 $i-t$ 的第 $j-t..j$ 列（越往上越宽）。内部一律 0-based。

题面样例（$N=3,K=2$，网格 `5 / -8 4 / 2 -3 6`）答案为 $2$：最优是倒立三角形 $\{4,-3,6\}$，平均 $7/3=2.333\dots$，截断得 $2$。注意题面说这个例子里共有 **5 个**合法子三角形——这个数字后面会用来核对我枚举的完备性。

**手造数据核对**（样例之外另造三组，各打一个易错点）：

| 输入 | 手算 | 输出 |
|---|---|---|
| `3 2` / `2` / `0 0` / `2 0 2` | 所有 2 行子三角形平均 $\le 2/3$（截断 $0$），整体 3 行平均 $6/6=1$ | `1` |
| `2 2` / `-1` / `0 0` | 唯一子三角形是整体，平均 $-1/3$，**向零截断**得 $0$（向下取整会错成 $-1$） | `0` |
| `3 1` / `-5` / `-7 -2` / `-9 -4 -1` | $K=1$ 可选单格，最大单格 $-1$ | `-1` |

第一组不是随便造的——它是本题最重要的**反例**，下面会看到它直接击毙一个非常诱人的贪心。

## 二、思维链：完整证明

### 第一步：诱人的贪心——"只取恰好 $K$ 行"

$K\le 20$ 这个约束非常扎眼：如果只需枚举**恰好 $K$ 行**的子三角形，个数是 $O(N^2)$ 量级，每个用前缀和 $O(1)$ 求和，总复杂度 $O(N^2K)$ 甚至 $O(N^2)$，绰绰有余。出题人把 $K$ 压到 $20$，似乎在暗示这条路。

为什么"恰好 $K$"看起来有道理？因为有一个经典的**剖分鸽笼**论证：

> 若一个大三角形能被剖分成若干个行数 $\ge K$ 的小三角形，则大三角形的平均值是各小块平均值的**加权平均**（权重为块内格子数），必有一块平均值 $\ge$ 整体平均值；又截断函数单调，该块截断后的平均值 $\ge$ 整体截断后的平均值。于是"更大的三角形不会更优"。

如果每个 $m>K$ 行的三角形都能被 $K$ 行三角形剖分，贪心就成立了。我试着剖分最小的反例情形：$3$ 行三角形剖成 $2$ 行三角形。

**引理 0（$3$ 行三角形无法剖分成 $2$ 行三角形）。**

*证明*：设正立 $3$ 行三角形格子为：第 $1$ 行 $\{a\}$，第 $2$ 行 $\{b,c\}$，第 $3$ 行 $\{d,e,f\}$（1-based 记法）。含顶点 $a$ 的 $2$ 行子三角形只有一个：正立、顶点为 $a$ 的 $\{a,b,c\}$（倒立 $2$ 行三角形需要顶点上方有一整行两格，$a$ 上方没有格子）。取走它后剩下 $\{d,e,f\}$——单独一行，而任何 $2$ 行三角形都跨两行，故剩余部分放不下任何 $2$ 行三角形。剖分不存在。证毕。

剖分论证在 $K\nmid m$ 时失效，但这只说明**证明方法**坏了，不代表**结论**坏了——也许存在别的论证？不，直接造数值反例：

**引理 1（"恰好 $K$ 行"贪心是错的）。** 取 $N=3,K=2$，网格

```
    2
   0 0
  2 0 2
```

则最优子三角形行数为 $3$，贪心答案 $0$，正确答案 $1$。

*证明*：穷举全部行数 $\ge 2$ 的子三角形（用第一部分的形状定义，0-based）：

- 正立 $2$ 行，顶点 $(0,0)$：$\{2,0,0\}$，和 $2$，平均 $2/3$，截断 $0$；
- 正立 $2$ 行，顶点 $(1,0)$：$\{0,2,0\}$，平均 $2/3$，截断 $0$；
- 正立 $2$ 行，顶点 $(1,1)$：$\{0,0,2\}$，平均 $2/3$，截断 $0$；
- 倒立 $2$ 行，底点 $(2,1)$：$\{(2,1),(1,0),(1,1)\}=\{0,0,0\}$，平均 $0$；
- 正立 $3$ 行，顶点 $(0,0)$：全部 $6$ 格，和 $6$，平均 $1$，截断 $1$。

（倒立 $2$ 行底点 $(2,0)$ 需要第 $1$ 行有第 $-1$ 列、底点 $(2,2)$ 需要第 $1$ 行有第 $2$ 列，均不存在；倒立 $3$ 行需要顶行 $3$ 格，第 $0$ 行只有 $1$ 格，不存在。）恰好 $5$ 个，与题面"5 个子三角形"的计数一致。最大值 $1$ 由 $3$ 行三角形取得，而所有 $2$ 行三角形截断后都是 $0$。贪心输出 $0\ne 1$。证毕。

**结论：必须枚举行数 $s=K,K+1,\dots,N$ 的所有子三角形。** $K\le 20$ 只是个烟雾弹（或者说，它保证 $s<K$ 的跳过分支很少，对复杂度无实质影响）。

### 第二步：全枚举的代价核算

数一下三角形总数。正立三角形由（顶点，行数）唯一确定，顶点 $(i,j)$ 最多能长到 $N-i$ 行，故正立（顶点，$s$）对数为

$$\sum_{i=0}^{N-1}(i+1)(N-i)=\binom{N+2}{3}\approx\frac{N^3}{6}.$$

倒立三角形底点 $(i,j)$ 的最大行数是 $\min(j,\,i-j)+1$（引理 3 会证），对 $j$ 求和约 $i^2/4$，再对 $i$ 求和约 $N^3/12$。两者合计约

$$\frac{N^3}{4}\approx\frac{700^3}{4}\approx 8.6\times 10^7.$$

八千多万次——只要**每个三角形 $O(1)$**，2 秒完全够。于是问题归约为：如何 $O(1)$ 求一个三角形的和？

### 第三步：逐层生长 + 行前缀和

关键观察：**固定顶点（或底点），把行数从 $s-1$ 长到 $s$，只新增一整行的一段连续区间**。而"一行的一段连续区间之和"正是行前缀和的拿手好戏。于是对每个顶点，让 $s$ 从 $1$ 递增到上限，维护累加和 `cur`，每步 $O(1)$；$s\ge K$ 时顺手更新答案。不需要任何二维三角形前缀和，也不需要枚举 $s$ 的外层循环。

**引理 2（截断函数的性质）。** 记 $\mathrm{trunc}(x)$ 为向零截断。则 (a) $\mathrm{trunc}$ 单调不减；(b) 对整数 $x$ 与正整数 $c$，C++ 的 `x/c` 等于 $\mathrm{trunc}(x/c)$（精确有理数意义）；(c) 本题答案 $\ge -10^9$。

*证明*：(a) $x\ge 0$ 时 $\mathrm{trunc}(x)=\lfloor x\rfloor$，$x<0$ 时 $\mathrm{trunc}(x)=\lceil x\rceil$，两者各自单调；跨零时 $x<0\le y\Rightarrow\mathrm{trunc}(x)\le 0\le\mathrm{trunc}(y)$。故整体单调。(b) C++11 标准规定整数除法向零截断；`x/c` 的数学值即 $x/c$，截断后正是 $\mathrm{trunc}(x/c)$，无浮点参与，零误差。(c) 每个格子的值 $\ge -10^9$，平均值 $\ge -10^9$，截断后仍 $\ge -10^9$（单调性 + $\mathrm{trunc}(-10^9)=-10^9$）。证毕。

由 (a)，"先对每个三角形截断再取 max"与"先取最大平均值再截断"结果相同，算法可以逐个三角形截断更新，无需分数比较。

**引理 3（形状、存在性与增量求和）。** 0-based 网格，行 $i$ 含列 $0..i$。记行前缀和 $\mathrm{pre}[i][j]=\sum_{c<j}v_{i,c}$。

(a) 正立三角形 $T^\uparrow(i,j,s)=\{(i+t,\,j+c):0\le t<s,\ 0\le c\le t\}$ 合法 $\iff j\le i$ 且 $i+s\le N$；其和满足
$$\mathrm{sum}(i,j,s)=\mathrm{sum}(i,j,s-1)+\mathrm{pre}[i+s-1][j+s]-\mathrm{pre}[i+s-1][j].$$

(b) 倒立三角形 $T^\downarrow(i,j,s)=\{(i-t,\,j-c):0\le t<s,\ 0\le c\le t\}$ 合法 $\iff j\le i$ 且 $1\le s\le\min(j,\,i-j)+1$；其和满足
$$\mathrm{sum}(i,j,s)=\mathrm{sum}(i,j,s-1)+\mathrm{pre}[i-s+1][j+1]-\mathrm{pre}[i-s+1][j-s+1].$$

*证明*：(a) 合法性：最深一层是行 $i+s-1$，需 $i+s-1\le N-1$ 即 $i+s\le N$；该层最右列 $j+s-1$ 需 $\le i+s-1$，即 $j\le i$，与顶点合法条件相同；其余各层同理被这两条覆盖。增量：$T^\uparrow(i,j,s)\setminus T^\uparrow(i,j,s-1)$ 恰为第 $t=s-1$ 层 $\{(i+s-1,\,j+c):0\le c\le s-1\}$，即行 $i+s-1$ 的列区间 $[j,\,j+s-1]$，其和为 $\mathrm{pre}[i+s-1][j+s]-\mathrm{pre}[i+s-1][j]$。对 $s$ 归纳即得和公式（$s=1$ 时 $\mathrm{sum}=v_{i,j}=\mathrm{pre}[i][j+1]-\mathrm{pre}[i][j]$，与公式一致）。

(b) 合法性：第 $t$ 层在行 $i-t$、列 $[j-t,\,j]$。需行号 $\ge 0$：$t\le i$；需列号 $\ge 0$：$t\le j$；需列号 $\le$ 行号（行 $i-t$ 只有列 $0..i-t$）：$j\le i-t$ 即 $t\le i-j$。三条对 $t=0..s-1$ 都要成立，最紧的是 $s-1\le\min(i,\,j,\,i-j)$；由 $j\ge 0$ 有 $i-j\le i$，故等价于 $s\le\min(j,\,i-j)+1$。增量：新增层 $t=s-1$ 是行 $i-s+1$ 的列区间 $[j-s+1,\,j]$，和为 $\mathrm{pre}[i-s+1][j+1]-\mathrm{pre}[i-s+1][j-s+1]$。归纳同上。证毕。

**引理 4（枚举不重不漏）。** 每个合法子三角形恰被算法访问一次。

*证明*：任何子三角形有确定的朝向、行数 $s$，以及唯一的最尖格（正立的顶点 / 倒立的底点）——尖格是三角形中唯一"所在行只贡献一格"的端点行格子，由形状定义唯一确定。故（朝向，尖格，$s$）三元组与子三角形一一对应。算法的两重循环遍历所有合法尖格 $(i,j)$（$0\le j\le i<N$），内层 $s$ 恰好跑遍引理 3 给出的合法范围，且只在 $s\ge K$ 时更新答案——正是题目要求的候选集合。证毕。

### 第四步：八千万次除法要不要省？

每个候选三角形更新答案要做一次 64 位除法 `cur/cnt[s]`。$8\times 10^7$ 次变量除法在老评测机上可能逼近 1 秒。能不能跳过绝大多数？能——答案 `ans` 单调不降，只有 $\mathrm{trunc}(cur/c)>\text{ans}$ 时才需要真的除。而这个条件可以**只用乘法**判定：

**引理 5（除法跳过判据）。** 设整数 $cur$、正整数 $c$、整数 $ans$，$q=\mathrm{trunc}(cur/c)$。则
$$q>ans\iff\begin{cases}cur\ge(ans+1)\cdot c,&cur\ge 0\\ cur>ans\cdot c,&cur<0\end{cases}$$

*证明*：$q>ans\iff q\ge ans+1$（整数）。

情形 $cur\ge 0$：$q=\lfloor cur/c\rfloor$。对整数 $k$ 有 $\lfloor x\rfloor\ge k\iff x\ge k$（$\Rightarrow$：$x\ge\lfloor x\rfloor\ge k$；$\Leftarrow$：$\lfloor x\rfloor\ge\lfloor k\rfloor=k$）。取 $k=ans+1$ 得 $q\ge ans+1\iff cur/c\ge ans+1\iff cur\ge(ans+1)c$。

情形 $cur<0$：$q=\lceil cur/c\rceil$。对整数 $k$ 有 $\lceil x\rceil\ge k\iff x>k-1$（$\Rightarrow$：$x>\lceil x\rceil-1\ge k-1$；$\Leftarrow$：$\lceil x\rceil\ge\lceil k-1+\varepsilon\rceil=k$，严格不等号排除了 $x=k-1$）。取 $k=ans+1$ 得 $q\ge ans+1\iff cur/c>ans\iff cur>ans\cdot c$。证毕。

**注意两个分支的判据不同**（$\ge(ans+1)c$ vs $>ans\cdot c$），统一写成 `cur>ans*c` 会在 $cur\ge 0$ 时把"恰好等于 $ans+1$ 倍"的更新漏掉吗？不会漏更新但会多做除法；反过来统一写 `cur>=(ans+1)*c` 在负数分支会**漏掉合法更新**（如 $cur=-1,c=3,ans=-1$：$q=0>-1$ 应更新，但 $-1\ge 0\cdot 3$ 为假）。所以必须分支。

判据通过时执行 `ans=cur/c`，由引理 5 保证新值严格大于旧值；判据不通过时 $q\le ans$，跳过无损。于是 `ans` 始终等于"已扫描三角形的截断平均值之最大值"，而除法只在答案真正刷新时执行——随机数据下刷新次数是 $O(\log)$ 级别的，除法几乎被全部省掉。

### 第五步：范围与溢出核算

**引理 6（所有中间量在 `long long` 内）。**

*证明*：格子总数 $\le 700\cdot 701/2=245350$，故 $|cur|\le 245350\times 10^9\approx 2.45\times 10^{14}$。$cnt[s]=s(s+1)/2\le 245350$。判据中的乘积：初始 $ans=-1145141919810$，$|(ans+1)\cdot c|\le 1.15\times 10^{12}\times 2.45\times 10^5\approx 2.8\times 10^{17}$；首次更新后 $|ans|\le 10^9$（引理 2(c) 及值域上界），乘积 $\le 2.5\times 10^{14}$。全部远小于 $9.22\times 10^{18}$。行前缀和同理 $\le 700\times 10^9=7\times 10^{11}$。证毕。

初值 $ans=-1145141919810<-10^9\le$ 任何合法答案（引理 2(c)），保证第一个候选必然刷新。

### 引理 7（复杂度）

时间 $O(N^3)$，空间 $O(N^2)$。

*证明*：内层循环总步数 = 正立对数 $\binom{N+2}{3}$ + 倒立对数 $\sum_i\sum_j(\min(j,i-j)+1)=\Theta(N^3/12)$，合计 $\approx N^3/4\approx 8.6\times 10^7$（$N=700$）。每步常数次加载、加法、比较；除法次数 = 答案刷新次数 $\le$ 候选数但实际极少。行前缀和预处理 $O(N^2)$。空间：`pre` 为 $705\times 705$ 个 `long long` $\approx 4$ MB，远低于 32 MB。证毕。

### 定理

程序输出所有行数 $\ge K$ 的子三角形（两种朝向）的平均值向零截断后的最大值。

*证明*：引理 3 保证每个三角形的和被精确计算；引理 4 保证候选集合不重不漏；引理 2 保证 `cur/c` 就是题意的"抹除小数"；引理 5 保证跳过判据与"截断值是否刷新"完全等价，故 `ans` 等于已扫描候选的最大截断平均值；引理 6 保证无溢出、初值合法；扫描完所有候选后由引理 4 即得全局最大值。引理 1 说明为什么不能只扫 $s=K$。引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 形式化两种朝向的子三角形（顶点/底点 + 行数），钉死"抹除小数 = 向零截断"。
2. **consider easier version** — 先试"只取恰好 $K$ 行"的贪心，$K\le 20$ 强烈暗示 $O(N^2K)$。
3. **explore its property** — 剖分鸽笼论证在 $K\nmid m$ 时失效（$3$ 行剖不成 $2$ 行）；数值反例 `2/0 0/2 0 2` 直接击毙贪心。
4. **reduce to easier problem** — 全枚举 $\approx N^3/4$ 个三角形；固定尖格逐层生长，每个三角形只新增一行的一段区间。
5. **classic problem solution** — 行前缀和把"新增一行区间"变 $O(1)$，总 $O(N^3)$ 压线通过。
6. **explore its property** — 截断单调 + 答案单调不降 ⇒ 用纯乘法判据跳过几乎全部 64 位除法；正负分支判据不同。
7. **discuss by category** — 负平均值向零截断（$-1/3\to 0$）、$K=1$ 单格、$K=N$ 只有整体；`ans` 初值取 $-1145141919810$。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,k` | 行数、最小行数 | `int`，读入 | $K\le 20$ 是烟雾弹，$s$ 要枚举到 $N$ |
| `pre[i][j]` | 行 $i$ 前 $j$ 个数之和（0-based，半开） | `i64[mxn][mxn]`，读入时递推 | 区间和 = `pre[i][r+1]-pre[i][l]` |
| `cnt[s]` | $s$ 行三角形的格子数 $s(s+1)/2$ | `i64[mxn]`，`cnt[s]=cnt[s-1]+s` | 平均值分母 |
| `cur` | 当前尖格、当前行数 $s$ 的三角形和 | `i64`，每个尖格重置 $0$ | 逐层累加，增量 = 一行区间 |
| `ans` | 已扫描候选的最大截断平均值 | `i64`，初值 $-1145141919810$ | 单调不降；小于一切合法答案 |
| `mxn` | $700+5$ | `constexpr int{705}` | 两种朝向共用 |

### 算法步骤

1. 读 $N,K$；逐行读入并递推行前缀和 `pre`；递推 `cnt`。
2. **正立扫描**：对每个顶点 $(i,j)$（$0\le j\le i<N$），`cur=0`，$s=1..N-i$：`cur+=pre[i+s-1][j+s]-pre[i+s-1][j]`；若 $s\ge K$，按引理 5 判据决定是否 `ans=cur/cnt[s]`。
3. **倒立扫描**：对每个底点 $(i,j)$，`cur=0`，$s=1..\min(j,i-j)+1$：`cur+=pre[i-s+1][j+1]-pre[i-s+1][j-s+1]`；同样的更新判据。
4. 输出 `ans`。

### 复杂度

- 时间 $O(N^3)$：约 $N^3/4\approx 8.6\times 10^7$ 次 $O(1)$ 层增量；除法被乘法判据省到极少。
- 空间 $O(N^2)$：`pre` 约 4 MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例输出 $2$；手造反例 `2/0 0/2 0 2` 输出 $1$、负截断 `-1/0 0` 输出 $0$、$K=1$ 全负输出 $-1$、$K=N$ 输出 $1$ 均与手算一致；300 组随机小数据（$N\le 8$，值 $[-20,20]$）与逐格累加的独立暴力完全一致；$N=700,K=20$ 全值域极限数据轻松通过。

```cpp
// 题目：P3016 [USACO11FEB] The Triangle S
// 枚举所有行数 >=K 的正立/倒立子三角形，行前缀和 + 逐层增量使每个三角形 O(1)
// 答案 = 各三角形平均值向零截断后的最大值；C++ 整除恰为向零截断
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{705};

int n,k;
i64 pre[mxn][mxn],cnt[mxn],ans=-1145141919810;	// pre[i][j]=第 i 行前 j 个数之和；cnt[s]=s(s+1)/2

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int i=0;i<n;++i)
		for(int j=0,v;j<=i;++j)
		{
			cin>>v;
			pre[i][j+1]=pre[i][j]+v;
		}
	for(int s=1;s<=n;++s)
		cnt[s]=cnt[s-1]+s;
	// 正立：顶点 (i,j)，第 s 层新增行 i+s-1 的 [j,j+s-1]
	for(int i=0;i<n;++i)
		for(int j=0;j<=i;++j)
		{
			i64 cur=0;
			for(int s=1;i+s<=n;++s)
			{
				cur+=pre[i+s-1][j+s]-pre[i+s-1][j];
				if(s<k)
					continue;
				i64 c=cnt[s];
				// 截断单调：仅当 trunc(cur/c)>ans 才做除法（负数分支判据不同！）
				if(cur>=0?cur>=(ans+1)*c:cur>ans*c)
					ans=cur/c;
			}
		}
	// 倒立：底点 (i,j)，第 s 层新增行 i-s+1 的 [j-s+1,j]
	for(int i=0;i<n;++i)
		for(int j=0;j<=i;++j)
		{
			i64 cur=0;
			for(int s=1,mx=min(j,i-j)+1;s<=mx;++s)
			{
				cur+=pre[i-s+1][j+1]-pre[i-s+1][j-s+1];
				if(s<k)
					continue;
				i64 c=cnt[s];
				if(cur>=0?cur>=(ans+1)*c:cur>ans*c)
					ans=cur/c;
			}
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **两个扫描的几何是全部易错点**：正立第 $s$ 层在行 `i+s-1`、列 `[j,j+s-1]`；倒立第 $s$ 层在行 `i-s+1`、列 `[j-s+1,j]`。倒立上限 `min(j,i-j)+1` 同时卡住"列不越左界"与"列不超行号"两条约束（引理 3(b)）。
- `cur` 逐层累加而不是每次重算，是把 $O(N^4)$ 暴力压到 $O(N^3)$ 的关键；`s<k` 时也要累加（小三角形是大三角形的前缀），只是不更新答案。
- 更新判据 `cur>=0?cur>=(ans+1)*c:cur>ans*c` 两个分支**不能合并**（引理 5）：负数分支用 `>=（ans+1)*c` 会漏更新。判据通过才做除法，八千万次除法被省成几十次。
- `ans` 初值 $-1145141919810$ 小于一切合法答案（$\ge -10^9$），且判据中的乘积仍在 `long long` 内（引理 6）。
- `cur/c` 是 C++ 向零截断除法，恰好实现"抹除小数"；负平均值（如 $-1/3\to 0$）不需要任何特判。
- `pre` 用 `i64`：单行和可达 $7\times 10^{11}$，`int` 必炸。
