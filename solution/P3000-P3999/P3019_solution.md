# P3019 [USACO11MAR] Meeting Place S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一棵以牧场 $1$ 为根的树，$N\le 1000$ 个节点。输入给出每个节点 $i\ (2\le i\le N)$ 的父亲 $P_i$（共 $N-1$ 行）。$M\le 1000$ 个询问，每次给出两个节点 $B_k,J_k$，输出它们的**最近公共祖先（LCA）**——既是 $B_k$ 的祖先又是 $J_k$ 的祖先、且深度最大的节点（节点是自己的祖先）。每询问一行。

剥离背景后就一句话：**裸 LCA**。约束 $N,M\le 1000$ 小到连 $O(NM)$ 的朴素爬树都只有 $10^6$ 步，完全不需要倍增。但有两个读入细节必须先看清：

1. **父亲编号可以比儿子大**。题面例子里 $P_5=8$：节点 $5$ 的父亲是 $8$。所以**不能**按输入顺序递推深度（`dep[i]=dep[P_i]+1` 会读到还没算的 `dep[8]`），必须沿父链递归/迭代到底。
2. 输入第 $2\sim N$ 行依次是 $P_2,P_3,\dots,P_N$，共 $N-1$ 个数，根没有父亲行。$N=1$ 时没有父亲行，直接是询问。

**手造数据核对。** 直接用题面给的 $9$ 节点树（父亲表：$P_2=1,P_3=1,P_4=2,P_5=8,P_6=1,P_7=8,P_8=6,P_9=6$）与 $6$ 个询问：

```
输入：9 6 / 1 1 2 8 1 8 6 6（逐行）/ 询问 (2,7) (4,2) (1,1) (4,1) (7,5) (9,5)
输出：1 2 1 1 8 6（逐行）
```

逐条手算：$(2,7)$：$7\to8\to6\to1$，$2\to1$，首个公共是 $1$ ✓；$(4,2)$：$4$ 的祖先链 $4,2,1$ 含 $2$ ✓；$(7,5)$：$7\to8$，$5\to8$，在 $8$ 相遇 ✓；$(9,5)$：$9\to6$，$5\to8\to6$，在 $6$ 相遇 ✓。另造边界 $N=1,M=1$，询问 $(1,1)$，输出 $1$（根是自己的祖先）。

## 二、思维链：完整证明

### 第一步：把"会面地点"翻译成 LCA，并确认它良定义

"既是双方祖先、又最近"——最近即深度最大。先证这个最大值存在且唯一。

**引理 1（父链必达根，深度良定义）。** 从任意节点 $u$ 出发反复取父亲，必在有限步内到达根 $1$，且路径唯一；因此每个节点的深度（到根的边数）良定义，记忆化递归 `getdep(u)=getdep(fa[u])+1` 必然终止。

*证明*：树是无向连通无环图，每个非根节点恰有一个父亲。若从 $u$ 出发的父链出现重复节点 $x$（$x\to\cdots\to x$），则这段父链对应原树中的一个无向环，与树无环矛盾。故父链上节点互不相同，节点总数 $N$ 有限，链必终止；唯一没有父亲的节点是根，故终止于根。父链唯一（每步父亲唯一），深度 = 链长 $-1$ 良定义。递归 `getdep` 沿父链下行，链有限故终止；每个节点只被真正计算一次（算完后 `dep[u]>=0`，之后直接命中记忆），总代价 $O(N)$。证毕。

**引理 2（LCA 存在且唯一）。** 任意 $u,v$ 的公共祖先集合非空，且其中深度最大者唯一。

*证明*：根是所有节点的祖先（引理 1 的父链终止于根），故公共祖先集合非空。$u$ 的全部祖先恰为其父链上的节点（祖先定义 = 父链可达），由引理 1 父链无重复，是一条**链**：其中任意两点一个是另一个的祖先，深度互不相同（链上每步深度减 $1$）。公共祖先集合是这条链的子集，故其中深度互不相同，有限非空集合的最大深度元唯一。证毕。

特别地 $\mathrm{LCA}(u,u)=u$（$u$ 是自己的祖先且深度最大）。

### 第二步：朴素爬树的两条不变量

算法只有两个动作：**深的先往上爬**；**同深后一起往上爬**。每一步都必须保持"当前两点的 LCA = 原询问的 LCA"，否则爬着爬着答案就丢了。

**引理 3（抬深保 LCA）。** 若 $\mathrm{dep}[u]>\mathrm{dep}[v]$，则 $\mathrm{LCA}(u,v)=\mathrm{LCA}(\mathrm{fa}[u],v)$。

*证明*：记 $w=\mathrm{LCA}(u,v)$。$w$ 是 $u$ 的祖先且 $\mathrm{dep}[w]\le\mathrm{dep}[v]<\mathrm{dep}[u]$，故 $w\ne u$，即 $w$ 是 $u$ 的**真**祖先。$u$ 的祖先链 = $\{u\}\cup(\mathrm{fa}[u]\text{ 的祖先链})$，所以 $w$ 也是 $\mathrm{fa}[u]$ 的祖先，从而是 $(\mathrm{fa}[u],v)$ 的公共祖先，$\mathrm{dep}[w]\le\mathrm{dep}[\mathrm{LCA}(\mathrm{fa}[u],v)]$。反向：$(\mathrm{fa}[u],v)$ 的任何公共祖先都是 $\mathrm{fa}[u]$ 的祖先，因而是 $u$ 的祖先（祖先关系传递），也是 $v$ 的祖先，即 $(u,v)$ 的公共祖先，深度 $\le\mathrm{dep}[w]$。两边夹得深度相等，由引理 2 的唯一性，两点相同。证毕。

**引理 4（同深同步爬保 LCA）。** 若 $\mathrm{dep}[u]=\mathrm{dep}[v]$ 且 $u\ne v$，则 $\mathrm{LCA}(u,v)=\mathrm{LCA}(\mathrm{fa}[u],\mathrm{fa}[v])$。

*证明*：记 $w=\mathrm{LCA}(u,v)$。若 $w=u$，则 $u$ 是 $v$ 的祖先且同深，祖先链上同深节点唯一（引理 2 证明中链的性质），得 $u=v$，矛盾。故 $w\ne u$，同理 $w\ne v$，$w$ 是两者的真祖先，从而是 $\mathrm{fa}[u],\mathrm{fa}[v]$ 的公共祖先。反向同引理 3：$(\mathrm{fa}[u],\mathrm{fa}[v])$ 的公共祖先都是 $(u,v)$ 的公共祖先。两边夹 + 唯一性得证。证毕。

**引理 5（终止性）。** 两阶段循环必在有限步内以 $u=v$ 结束。

*证明*：阶段一每步把较深者的深度减 $1$，深度差严格减小，有限步后同深（深度 $\ge 0$）。阶段二每步两者深度各减 $1$，深度严格下降；深度为 $0$ 的节点只有根，故最迟在根处 $u=v$。证毕。

### 第三步：串联

**定理。** 程序对每个询问输出 $\mathrm{LCA}(B_k,J_k)$；总时间 $O(N+MN)$，空间 $O(N)$。

*证明*：预处理由引理 1 正确算出所有深度（注意父亲编号可大于儿子编号，记忆化递归不依赖输入顺序）。询问开始时 $(u,v)=(B_k,J_k)$。阶段一反复应用引理 3，LCA 不变量保持；阶段二反复应用引理 4，不变量保持；由引理 5 终止于 $u=v$，此时 $\mathrm{LCA}(u,u)=u$（引理 2 附注），即原询问的 LCA。输出 `u+1` 还原 1-based。复杂度：深度预处理 $O(N)$（每节点恰算一次）；每询问爬升步数 $\le\mathrm{dep}[u]+\mathrm{dep}[v]\le 2N$，共 $O(MN)\le 2\times 10^6$。空间只有 `fa`、`dep` 两个 $O(N)$ 数组。证毕。

### 第四步：要不要上倍增？

$N,M\le 1000$ 时 $O(NM)=10^6$，朴素爬树已经绰绰有余，倍增的 $O((N+M)\log N)$ 反而多写多错。若 $N,M$ 到 $10^5$ 量级，则把"一步爬一格"换成"一次爬 $2^k$ 格"（倍增表 `gf[u][k]`），两条引理 3、4 的不变量论证原封不动适用——这正是 LCA 模板的推导骨架。本题按约束选朴素版。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "最近的公共祖先牧场"就是 LCA；公共祖先集合是父链的子集，最深者存在且唯一。
2. **explore its property** — 父亲编号可大于儿子编号（$P_5=8$），深度不能按输入顺序递推，要记忆化沿父链递归。
3. **consider easier version** — $N,M\le 1000$，先放弃倍增，考虑沿父指针一格一格爬的朴素版。
4. **classic problem solution** — 两阶段 LCA：深的先抬到同深，再同步上爬；每阶段用交换/夹逼论证证明 LCA 不变量。
5. **discuss by category** — $N=1$、$u=v$、一方是另一方祖先等边界都被"同深后同步爬"统一覆盖；大规模时换倍增。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,m` | 节点数、询问数 | `int`，读入 | 均 $\le 1000$ |
| `fa[i]` | 节点 $i$ 的父亲（0-based） | `int[mxn]`，读入 `--` | `fa[0]` 无意义，不会被访问 |
| `dep[i]` | 节点 $i$ 的深度，根为 $0$ | `int[mxn]`，**先 `fill_n(dep,n,-1)` 再 `dep[0]=0`** | $-1$ = 未计算；全局默认 $0$ 不是"未计算"！ |
| `getdep(u)` | 记忆化求深度 | `int(int)` | 父链必达根 ⇒ 递归必终止 |
| `u,v` | 当前询问的两点（0-based） | `int`，读入 `--` | 爬升中就地修改，输出 `u+1` |

### 算法步骤

1. 读 $N,M$；`dep` 全填 $-1$，`dep[0]=0`；读 $P_2..P_N$ 存入 `fa[1..N-1]`（转 0-based）。
2. 对每个 $i$ 调 `getdep(i)`，记忆化算完所有深度。
3. 每个询问：读 $u,v$ 转 0-based；`while(dep[u]>dep[v])u=fa[u];` 与对称循环抬到同深；`while(u!=v)u=fa[u],v=fa[v];` 同步爬；输出 `u+1`。

### 复杂度

- 时间 $O(N+MN)\le 2\times 10^6$ 步。
- 空间 $O(N)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面 $9$ 节点 $6$ 询问样例输出 `1 2 1 1 8 6` 逐条吻合；$N=1$ 询问 $(1,1)$ 输出 $1$。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3019 [USACO11MAR] Meeting Place S
// 裸 LCA：记忆化求深度，先把深的抬到同深，再同步上爬
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,m,fa[mxn],dep[mxn];

int getdep(int u)
{
	if(dep[u]>=0)
		return dep[u];
	return dep[u]=getdep(fa[u])+1;	// 父链必达根，递归必终止
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	fill_n(dep,n,-1);
	dep[0]=0;				// 根深度 0；其余 -1 表示未算
	for(int i=1;i<n;++i)
	{
		cin>>fa[i];--fa[i];
	}
	for(int i=0;i<n;++i)
		getdep(i);
	for(int q=0,u,v;q<m;++q)
	{
		cin>>u>>v;--u;--v;
		while(dep[u]>dep[v])
			u=fa[u];
		while(dep[v]>dep[u])
			v=fa[v];
		while(u!=v)
			u=fa[u],v=fa[v];
		cout<<u+1<<'\n';
	}
	return 0;
}
```

### 代码说明

- **`dep` 必须显式填 $-1$**：全局 `int` 默认 $0$，而 $0$ 是根的合法深度——不填的话所有节点都会被误认为"已算好、深度 $0$"，这是本题唯一的初始化陷阱。
- `getdep` 沿父链递归而不是按编号递推，因为父亲编号可能更大（$P_5=8$）；树保证父链无环，递归深度 $\le N\le 1000$，不会爆栈。
- 三个 `while` 分别对应引理 3（抬深）、引理 4（同步爬）；$u=v$ 的各种边界（同点、祖先关系、$N=1$）都自然落入循环零次或同步爬，无需特判。
- 内部 0-based：读入 `--`，输出 `u+1`；`fa[0]` 永远不会被访问（根的深度已预置，抬深循环在根处必停）。
