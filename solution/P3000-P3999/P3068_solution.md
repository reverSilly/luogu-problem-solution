# P3068 [USACO13JAN] Party Invitations S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 头奶牛（$1\le N\le 10^6$），编号 $1..N$，其中 $1$ 号**已经被邀请**。有 $G$ 个"朋友圈"，第 $g$ 个圈是 $k_g$ 头牛组成的集合；所有圈的大小之和 $M=\sum k_g\le 2.5\times 10^5$（于是 $G\le M$）。规则只有一条：

> 对每个圈，若其中已有 $k_g-1$ 头被邀请，则剩下的那头**必须**也被邀请。

这条规则会连锁触发：邀请了一头新牛，可能让别的圈凑齐 $k-1$，又逼出新牛。问最终**最少**要邀请多少头牛。

**口径说明（两处歧义，先钉死）：**

1. "最少需要邀请多少头"按 USACO 原题惯例理解为**最终参加聚会的牛的总数，包含已被邀请的 $1$ 号**。依据：题面把"$1$ 号已被邀请"作为初始条件而非扣除项，问的是整个邀请方案的大小；若问"额外再邀请几头"，题面应明确说"除 $1$ 号外"。
2. 朋友圈是**集合**：同一头牛在一个圈里至多出现一次（"朋友圈"的自然语义），不同圈可以相交、可以互相包含，只是没有两个完全相同的圈。

**手造小数据核对**（题面没有给样例输入输出，按规则自造）：

第一组：$N=5$，圈为 $\{1,2\},\{2,3\},\{4\}$。
- $1$ 已邀请 → 圈 $\{1,2\}$ 凑齐 $1=k-1$ → 逼出 $2$；
- $2$ 被邀请 → 圈 $\{2,3\}$ 凑齐 $1$ → 逼出 $3$；
- 圈 $\{4\}$ 大小 $k=1$，$k-1=0$：**一个人都不需要邀请就满足条件**，直接逼出 $4$；
- $5$ 不在任何圈里，永远不会被邀请。答案 $4$（牛 $1,2,3,4$）。

第二组：$N=4$，圈为 $\{2,3,4\},\{1,2\}$。
- $1$ 已邀请 → 圈 $\{1,2\}$ 逼出 $2$；
- 圈 $\{2,3,4\}$ 需要 $2$ 头才触发，现在只有 $2$ 号一头，**停住**。答案 $2$。

第三组：$N=6$，圈为 $\{1,2,3\},\{3,4,5\},\{5,6\}$。
- $1$ 已邀请，圈 $\{1,2,3\}$ 只有 $1$ 头 $<2$，不触发；其余圈更是 $0$ 头。答案 $1$。

这三组分别覆盖了"链式传播""传播中途停住""$k=1$ 立即触发"三种情形。

**第一个疑问：这题有"决策"吗？** 题面问"最少"，听起来像要选一个最优邀请方案。但仔细读规则：它是一条**强制**规则——条件满足就**必须**邀请，没有任何"可以不邀请"的自由。也就是说，从 $\{1\}$ 出发，所有被逼出来的牛都非邀不可；而"主动多邀"只会让条件更容易满足、逼出更多牛，绝不会变少。所以直觉上答案唯一：**把强制规则反复用到不能再用的那个集合**。后面的证明会把这句话变成定理。

**第二个疑问：怎么模拟才不超时？** 最朴素的做法是"一轮一轮扫"：每轮检查所有 $G$ 个圈，发现凑齐 $k-1$ 的就邀请剩下一头，直到某轮没有任何新邀请。每轮至少新增 $1$ 头（否则终止），而被邀请的牛至多 $M+1$ 头（不在任何圈里的牛除了 $1$ 号都不会被邀请），所以至多 $O(M)$ 轮；每轮扫全部成员要 $O(M)$。总复杂度 $O(M^2)\approx 6.25\times 10^{10}$，超时。

瓶颈在哪？**绝大多数圈在大多数轮里根本没变化，却被反复检查。** 一个圈的状态只在"它的某个成员被邀请"时才改变。于是自然想到**事件驱动**：把"牛 $u$ 被邀请"看作事件，只检查 $u$ 所属的那些圈。这正是 BFS 的形状：队列里放新邀请的牛，出队时更新它所属圈的计数。

**第三个疑问：计数到什么程度触发？** 给每个圈维护 `cnt[g]` = 已邀请成员数。每当 `cnt[g]` 涨到 $k_g-1$，圈里恰好剩一头没邀请，扫一遍成员找出它、邀请它。注意 `cnt` 单调递增，**每个圈至多触发一次**（触发后剩下一头也被邀请，`cnt` 直奔 $k$，不会再等于 $k-1$），所以"触发时扫一遍成员"的总代价摊下来是 $O(M)$，不会退化。

**第四个疑问（真正的坑）：$k=1$ 的圈怎么办？** 事件驱动有个盲区：$k=1$ 的圈触发条件是 $k-1=0$，即**初始时刻就满足**，但它的唯一成员此时还没被邀请，永远不会产生"成员被邀请"的事件来唤醒这个圈。第一组手造数据里的圈 $\{4\}$ 就是这种。所以必须在初始化阶段**单独把所有 $k=1$ 的圈触发一遍**。其余的圈（$k\ge 2$）初始 `cnt=0<k-1`，都等着 BFS 事件即可。

**第五个疑问（实现陷阱）：$1$ 号牛的计数会不会算两次？** 我第一版在读入时顺手给含 $1$ 号的圈 `++cnt`，BFS 处理 $1$ 号时又 `++cnt`，结果 $1$ 号被数了两次，$k=3$ 的圈只邀请了 $1$ 头就误触发。修正：**计数统一只在 BFS 出队时做**，读入阶段 `cnt` 全为 $0$，初始特判只留 $k=1$ 一条。这样"每头被邀请的牛恰好贡献一次计数"的不变量才干净。

至此算法成型：读入建"牛 → 所属圈"的邻接表（链式前向星，$N$ 太大不能用 `vector` 数组硬开 $10^6$ 个对象也不划算，前向星只要两个 `int` 数组）；邀请 $1$ 号入队；特判 $k=1$；BFS 传播；输出邀请总数。

## 二、思维链：完整证明

**记号。** 牛集合 $V=\{1,\dots,N\}$。圈 $g$ 是 $V$ 的子集，$|g|=k_g$。邀请集合 $S\subseteq V$。称 $S$ **合法**，当且仅当 $1\in S$ 且对每个圈 $g$：$|S\cap g|=k_g-1\Rightarrow g\subseteq S$。题目要求 $\min\{|S|:S\text{ 合法}\}$。

把规则改写一下更好用：

**引理 0（规则的等价形式）。** $S$ 合法 $\iff$ $1\in S$ 且对每个圈 $g$，$|S\cap g|\ne k_g-1$。

*证明*：若 $|S\cap g|=k_g-1$，规则要求 $g\subseteq S$，即 $|S\cap g|=k_g$，与 $k_g-1$ 矛盾（$k_g\ge 1$）。故合法集中任何圈的交集大小只能是 $0,1,\dots,k_g-2$ 或 $k_g$，即 $\ne k_g-1$。反之，若所有圈都满足 $|S\cap g|\ne k_g-1$，则规则的前提永不成立，规则空真，$S$ 合法。证毕。

这条引理说明：**"合法"就是"没有任何圈恰好卡在 $k-1$"**。模拟的目标就是把所有卡在 $k-1$ 的圈补满。

---

### 引理 1（合法集对交封闭 ⇒ 最小合法集存在且唯一）

设 $S,T$ 都合法，则 $S\cap T$ 也合法。从而所有合法集的交 $S^\*=\bigcap\{S:S\text{ 合法}\}$ 是唯一的**最小**合法集（按包含序，也是大小最小的）。

*证明*：$1\in S$ 且 $1\in T$，故 $1\in S\cap T$。任取圈 $g$，反设 $|(S\cap T)\cap g|=k_g-1$。由 $(S\cap T)\cap g\subseteq S\cap g$ 得 $|S\cap g|\ge k_g-1$；又 $S$ 合法，由引理 0 知 $|S\cap g|\ne k_g-1$，故 $|S\cap g|=k_g$，即 $g\subseteq S$。同理 $g\subseteq T$。于是 $g\subseteq S\cap T$，得 $|(S\cap T)\cap g|=k_g\ne k_g-1$，矛盾。故 $S\cap T$ 满足引理 0 的条件，合法。

合法集族非空（$V$ 本身合法：每个圈交集大小都是 $k_g$），对交封闭，故其全体之交 $S^\*$ 仍合法（有限交归纳；$V$ 有限，不同子集只有有限多个，交可写成有限次两两交）。任何合法集都包含 $S^\*$，故 $S^\*$ 是唯一的最小元，大小也最小。证毕。

**这条引理回答了"最少"二字**：答案不是某个需要搜索的优化值，而是唯一确定的闭包 $S^\*$ 的大小。剩下的任务只是把 $S^\*$ 算出来。

---

### 引理 2（强制传播算子的单调性）

定义算子 $F(S)=S\cup\bigl\{\,g\setminus S\text{ 的唯一元素}:|S\cap g|=k_g-1\,\bigr\}$（对每个卡在 $k-1$ 的圈，补进剩下一头）。则：

(a) $S\subseteq F(S)$（扩张性）；
(b) $S\subseteq T\Rightarrow F(S)\subseteq F(T)$（单调性）；
(c) $S$ 合法 $\iff F(S)=S$（不动点即合法）。

*证明*：(a) 由并的定义直接成立。

(b) 设 $x\in F(S)\setminus S$，则存在圈 $g$ 使 $|S\cap g|=k_g-1$ 且 $g\setminus S=\{x\}$。由 $S\subseteq T$ 得 $|T\cap g|\ge k_g-1$。若 $|T\cap g|=k_g-1$，则 $g\setminus T$ 也是单点集；又 $T\cap g\supseteq S\cap g$ 且两者大小同为 $k_g-1$，故 $T\cap g=S\cap g$，于是 $g\setminus T=g\setminus S=\{x\}$，$x\in F(T)$。若 $|T\cap g|=k_g$，则 $g\subseteq T$，$x\in T\subseteq F(T)$。两种情形都有 $x\in F(T)$，故 $F(S)\subseteq F(T)$。

(c) $F(S)=S$ 意味着没有任何圈满足 $|S\cap g|=k_g-1$（否则 $F$ 会 strictly 加入新元素），由引理 0 即合法（$1\in S$ 由构造保证）。反之合法集没有卡在 $k-1$ 的圈，$F$ 不加任何元素。证毕。

---

### 引理 3（迭代收敛到 $S^\*$）

令 $S_0=\{1\}$，$S_{t+1}=F(S_t)$。则存在 $T\le N$ 使 $S_T=S_{T+1}$，且 $S_T=S^\*$（引理 1 的最小合法集）。

*证明*：由引理 2(a)，$S_0\subseteq S_1\subseteq\cdots$ 是递增链，元素个数单调不减且 $\le N$。若 $S_{t+1}\ne S_t$ 则大小至少 $+1$，故至多 $N$ 步后稳定，设稳定于 $S_T$。由引理 2(c)，$S_T$ 合法。

再证 $S_T\subseteq S^\*$：对 $t$ 归纳证明 $S_t\subseteq S^\*$。$t=0$：$1\in S^\*$（合法集必含 $1$）✓。设 $S_t\subseteq S^\*$，由引理 2(b) 单调性，$S_{t+1}=F(S_t)\subseteq F(S^\*)=S^\*$（最后一步用 $S^\*$ 合法及引理 2(c)）✓。故 $S_T\subseteq S^\*$；又 $S^\*$ 是最小合法集而 $S_T$ 合法，$S^\*\subseteq S_T$。两者相等。证毕。

**推论**：任何"把强制规则用到不能用为止"的过程，无论触发顺序如何，结果都是同一个 $S^\*$。这保证了我们的 BFS 顺序（乃至任何乱序）都不影响答案。

---

### 引理 4（BFS 模拟恰好计算迭代闭包）

算法维护：`inv[v]` 标记已邀请；队列 `q` 存放已邀请但尚未处理其事件的牛；`cnt[g]` 记录圈 $g$ 中**已处理事件**的成员数。过程：

1. 邀请 $1$ 号入队；对每个 $k_g=1$ 的圈，邀请其唯一成员入队（若未邀请）。
2. 出队 $u$，对 $u$ 所属的每个圈 $g$：`++cnt[g]`；若 `cnt[g]==k_g-1`，扫 $g$ 的成员，把未邀请者邀请入队。
3. 队空时输出邀请总数。

则算法终止时 `inv` 标记的集合恰为 $S^\*$。

*证明*：分三步。

**(i) 计数不变量**：任何时刻 `cnt[g]` $\le$ $|S_{\text{inv}}\cap g|$（$S_{\text{inv}}$ 是当前已邀请集），且每头被邀请的牛在其出队时对所属每个圈恰好贡献 $1$。因此当所有已邀请牛都处理完（队空）时，`cnt[g]` $=|S_{\text{inv}}\cap g|$ 精确成立。读入阶段不做任何计数（这是修正后的版本），$1$ 号也只通过出队计数一次，不变量从 $0$ 开始干净建立。

**(ii) 终止时合法**：队空时反设某圈 $|S_{\text{inv}}\cap g|=k_g-1$。由 (i)，`cnt[g]`$=k_g-1$。`cnt[g]` 从 $0$ 每次 $+1$ 涨到 $k_g-1$，必然在某个时刻**等于** $k_g-1$：若该时刻发生在初始特判之前（即 $k_g=1$，`cnt` 恒 $0$），初始特判已把唯一成员邀请；否则发生在某次出队 `++cnt` 之后，算法当场扫描并邀请了未邀请成员。两种情形都使 $g$ 的成员全部被邀请（$k=1$ 情形直接全邀；$k\ge 2$ 情形 `cnt==k-1` 时已邀请数 $\ge$ `cnt` $=k-1$，未邀请者至多 $1$ 头，扫描把它补上），与 $|S_{\text{inv}}\cap g|=k_g-1$ 矛盾。故终止时所有圈都不卡在 $k-1$，由引理 0，$S_{\text{inv}}$ 合法。

（补一句扫描的正确性：`cnt[g]==k_g-1` 时已邀请成员数 $\ge k_g-1$，未邀请成员数 $\le 1$，所以"扫一遍找未邀请者"要么找到恰好一头、要么一头都没有——后者说明该圈其实已经全邀，什么都不做也正确。）

**(iii) 终止时最小**：对邀请发生的顺序归纳，证明每头被邀请的牛都属于 $S^\*$。$1$ 号 $\in S^\*$ ✓。$k=1$ 圈的成员：任何合法集都必须包含它（引理 0：$k=1$ 时交集大小不能是 $0$），故 $\in S^\*$ ✓。BFS 中因 `cnt[g]==k_g-1` 被邀请的牛 $x$：此时 $g$ 中已有 $k_g-1$ 头被邀请，由归纳假设它们都在 $S^\*$ 中，故 $|S^\*\cap g|\ge k_g-1$；$S^\*$ 合法，由引理 0 得 $|S^\*\cap g|=k_g$，即 $g\subseteq S^\*$，$x\in S^\*$ ✓。于是 $S_{\text{inv}}\subseteq S^\*$；结合 (ii) 的合法性与 $S^\*$ 的最小性，$S_{\text{inv}}=S^\*$。证毕。

---

### 引理 5（每个圈至多触发一次扫描）

算法运行全程，"因 `cnt[g]==k_g-1` 而扫描圈 $g$ 成员"这件事对每个圈至多发生一次；初始特判的扫描也至多每圈一次。

*证明*：`cnt[g]` 只增不减，故 `cnt[g]==k_g-1` 这个等式在时间轴上至多成立一次（一旦越过就永不回来）。初始特判只对 $k_g=1$ 的圈执行，每圈一次。证毕。

**推论**：触发扫描的总代价 $\le\sum_g k_g=M$。这是"触发时线性扫成员"不会退化的关键——不需要任何额外数据结构去 $O(1)$ 定位"剩下一头"。

---

### 引理 6（复杂度）

时间 $O(N+M)$，空间 $O(N+M)$。

*证明*：读入 $O(M)$；`fill_n(H,n,-1)` 为 $O(N)$；初始特判 $O(G)\le O(M)$。BFS 中每头牛至多入队一次（`invite` 里 `inv` 判重），出队时遍历其所有所属圈：全部牛的所属圈条目总数恰为 $M$（每条成员关系建一条边），故 BFS 的边遍历总量 $O(M)$。由引理 5，触发扫描总量 $O(M)$。合计 $O(N+M)$。

空间：`H` 为 $N$ 个 `int`（$4$ MB），`E` 为 $M$ 个 `{g,nx}`（$2$ MB），`mem/sz/gs/cnt` 共 $O(M)$，`q/inv` 共 $O(N)$，总计 $O(N+M)$，约 $15$ MB。证毕。

---

### 定理

算法输出的整数恰为最小合法邀请集的大小 $|S^\*|$（含 $1$ 号），时间 $O(N+M)$，空间 $O(N+M)$。

*证明*：引理 1 确立最小合法集存在唯一；引理 2、3 说明它就是强制传播的闭包；引理 4 证明 BFS 模拟（含 $k=1$ 初始特判）恰好算出该闭包；引理 5、6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 规则是"必须"而非"可以"：没有决策自由度，"最少"其实是唯一的强制闭包，答案与触发顺序无关。
2. **consider easier version** — 先想朴素"每轮全量扫所有圈"：$O(M^2)\approx 6\times 10^{10}$ 超时，瓶颈是反复检查没有变化的圈。
3. **reduce to easier problem** — 圈的状态只在"成员被邀请"时改变 ⇒ 事件驱动：新牛入队，出队只更新它所属的圈，变成 BFS。
4. **classic problem solution** — 计数器 `cnt[g]` + 阈值 $k-1$ 触发，形状同拓扑排序的入度归零；触发后扫成员找剩下一头。
5. **explore its property** — `cnt` 单调 ⇒ 每圈至多触发一次 ⇒ 扫描代价摊还 $O(M)$，无需额外定位结构。
6. **discuss by category** — $k=1$ 的圈没有事件源（条件初始即满足），必须初始化特判；$k\ge 2$ 的圈初始 `cnt=0<k-1`，统一走 BFS。
7. **explore its property** — 计数口径统一：$1$ 号只在出队时计一次，读入时预计数会导致双重计数、$k=3$ 的圈误触发（第一版真实踩过的坑）。

| `gs[i]` | 圈 $i$ 的成员在 `mem` 中的起始下标 | `int[mxm]` | 读入时累加 `mp` |
| `mem[mp]` | 所有圈成员平铺（0-based 牛编号） | `int[mxm]` | 按圈连续存放 |

| `q,qh,qt` | BFS 队列（已邀请待处理的牛） | `int[mxn]` + 两个下标 | `qh==qt` 即队空 |
| `ans` | 已邀请总数（含 $1$ 号） | `int` | `invite` 里 `++` |
| `invite(v)` | 邀请 $v$：判重、标记、入队、计数 | `void(int)` | 唯一的邀请入口，保证每牛至多入队一次 |

### 算法步骤

1. I/O 加速三行；读 $N,G$；`fill_n(H,n,-1)`。
2. 逐圈读入 $k$ 与成员：平铺进 `mem`，记录 `sz/gs`；对每个成员 $v$（转 0-based）建边 `E[tot]={i,H[v]}; H[v]=tot++`。**读入阶段不做任何计数。**
3. `invite(0)`（$1$ 号）。
4. 初始特判：对每个 `sz[i]==1` 的圈，`invite(mem[gs[i]])`。
5. BFS：出队 $u$，沿 `H[u]` 遍历所属圈 $t$：`++cnt[t]`；若 `cnt[t]==sz[t]-1`，扫 `mem[gs[t]..gs[t]+sz[t])`，对未邀请者 `invite`。
6. 队空后输出 `ans`。

### 复杂度

- 时间：$O(N+M)$（引理 6）；$N=10^6,M=2.5\times 10^5$ 时约几百万次基本操作。
- 空间：$O(N+M)\approx 15$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；五组手造数据（链式传播 / 中途停住 / $k=1$ 含 $1$ 号 / 大圈不触发 / 混合）输出 $4,2,1,1,3$ 全部与手算一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3068 [USACO13JAN] Party Invitations S
// 闭包模拟：cnt[g] 记录朋友圈 g 中已邀请数，达到 k-1 就邀请剩下一头
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005},mxm{250005};

int n,g,sz[mxm],gs[mxm],cnt[mxm],mem[mxm];
int H[mxn],tot;
struct{int g,nx;}E[mxm];	// 牛 -> 所属朋友圈 的链式前向星
bool inv[mxn];
int q[mxn],qh,qt,ans;

void invite(int v)
{
	if(inv[v])
		return;
	inv[v]=true;
	q[qt++]=v;
	++ans;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>g;
	fill_n(H,n,-1);	// 全局默认 0 是合法边下标，必须显式置 -1
	int mp=0;
	for(int i=0,k;i<g;++i)
	{
		cin>>k;
		sz[i]=k;gs[i]=mp;
		for(int j=0,v;j<k;++j)
		{
			cin>>v;--v;
			mem[mp++]=v;
			E[tot]={i,H[v]};H[v]=tot++;
		}
	}
	invite(0);
	for(int i=0;i<g;++i)	// k=1 的圈：0 人邀请即满足 k-1，BFS 永远等不到它
		if(sz[i]==1)
			invite(mem[gs[i]]);
	while(qh<qt)
	{
		int u=q[qh++];
		for(int i=H[u];i!=-1;i=E[i].nx)
		{
			int t=E[i].g;
			++cnt[t];
			if(cnt[t]==sz[t]-1)	// 每圈至多触发一次：触发后 cnt 直奔 k
				for(int j=gs[t];j<gs[t]+sz[t];++j)
					if(!inv[mem[j]])
						invite(mem[j]);
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **计数口径**：`cnt` 只在 BFS 出队时 `++`，读入时预计数 $1$ 号会让它被数两次（$k=3$ 的圈只邀 $1$ 头就误触发）。`cnt` 全局默认 $0$ 在本题恰好是正确初值，无需 fill；但 `H` 的 $-1$ 哨兵**必须**显式填，因为 $0$ 是合法边下标。
- **`invite` 判重**：同一头牛可能被多个圈同时逼出，`inv` 判重保证每牛至多入队一次，这是 $O(M)$ 边遍历总量的前提。
- **触发扫描的摊还**：`cnt` 单调，等式 `cnt==sz-1` 每圈至多成立一次，所以内层 `for` 扫成员的总次数 $\le M$，不需要"快速找未邀请者"的额外结构。
- **$k=1$ 特判**放在 `invite(0)` 之后：若该圈成员就是 $1$ 号，`invite` 判重直接返回，不会重复计数。
- 队列开 `mxn`：被邀请的牛至多 $N$ 头（实际上 $\le M+1$，但按 $N$ 开最稳）。
