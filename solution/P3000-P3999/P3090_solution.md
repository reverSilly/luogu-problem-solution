# P3090 [USACO13NOV] Empty Stalls G — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 环上有 $N$ 个房间，编号 $0\dots N-1$（$2\le N\le 3\times10^6$），$N-1$ 与 $0$ 相邻。若干头牛依次进来，第 $t$ 头牛有一个喜好房间 $p_t$：它从 $p_t$ 开始**沿编号增大方向**逐个查看（走到 $N-1$ 后绕回 $0$），占用遇到的**第一个空房间**。牛的总数 $C\le N-1$，所以结束后至少剩一个空房。问：**最终空房间里编号最小的是哪个**。

输入是压缩的：$K\le 10^4$ 行，每行 $X,Y,A,B$ 表示 $Y$ 批牛、每批 $X$ 头，第 $j$ 批（$j=1\dots Y$）的 $X$ 头牛喜好都是 $(A\times j+B)\bmod N$，其中 $A,B\le 10^9$。另有一条刺眼的约束：**空间只有 64 MB**。

题面还送了一句"答案与奶牛进入顺序无关"。先记住它，但**不要急着用**——后面会看到，我们根本不需要这条性质。

**手造数据核对。** 题面 Hint 给了一个 $N=10$ 的例子但没给输入输出格式，我按 Hint 反推出输入：

```
10 3
3 2 2 4
2 1 0 1
1 1 1 7
```

第一行展开：批 $1$ 喜好 $(2\cdot1+4)\bmod10=6$ 的 $3$ 头，批 $2$ 喜好 $8$ 的 $3$ 头；第二行：$2$ 头喜好 $1$；第三行：$1$ 头喜好 $8$。共 $9=N-1$ 头。按生成顺序模拟：

| 牛喜好 | 实际占用 | 说明 |
|---|---|---|
| 6,6,6 | 6,7,8 | 第一头占 6，后两头依次向后 |
| 8,8,8 | 9,0,1 | 8 已占，绕环：9→0→1 |
| 1,1 | 2,3 | 1 已占 |
| 8 | 4 | 8,9,0,1,2,3 全占，落到 4 |

占用 $\{0,1,2,3,4,6,7,8,9\}$，唯一空房 $5$，输出 `5`，与 Hint"除了牛栏 5 之外全被占用"吻合。

再造两组专打边界的小数据：

- `2 1 / 1 1 0 1`：$N=2$，$1$ 头牛喜好 $1$，占 $1$，答案 `0`（最小空房在喜好之前，验证"输出的是空房最小编号而非最后占用位置"）。
- `3 1 / 2 1 0 2`：$N=3$，$2$ 头牛都喜好 $2$：第一头占 $2$，第二头从 $2$ 出发绕到 $0$ 占用，空房只剩 $1$，答案 `1`（专打**绕环**）。

**第一步：暴力为什么不行。** 每头牛从 $p$ 逐格扫到第一个空房，最坏一头牛扫 $O(N)$ 格，总量 $O(CN)=O(N^2)\approx 9\times10^{12}$，想都不用想。瓶颈是"找 $\ge p$ 的第一个空房"这个查询被反复线性执行。

**第二步：抓结构性质——占用是不可逆的。** 房间一旦被占就**永远不空回来**。这意味着"空房集合"只缩不涨，"从 $p$ 向前的第一个空房"只会**向后移动**，不会回头。一个只朝一个方向挪、且挪过之后旧位置永远作废的指针——这正是**并查集"找后继"**（successor DSU）的标准场景：把每个已占房间用指针挂到它后面第一个候选空房上，查询沿指针跳，路径压缩把跳过的格子直接钉到终点。均摊近乎线性。

具体地：$f[i]$ 表示"从 $i$ 出发找空房时下一个该看的房间"。初始 $f[i]=i$（全空）。牛喜好 $p$：$r=\mathrm{getrt}(p)$ 就是第一个空房；占用它，令 $f[r]=(r+1)\bmod N$。环状只是把直线版的 $f[r]=r+1$ 加了个取模，结构完全一样。

**第三步：64 MB 是来真的。** 我第一反应其实是 `std::set<int>` 存所有空房，`lower_bound(p)` 找后继（绕环就查两次），$O(N\log N)$ 时间没问题。但算一下内存：红黑树每个节点约 $48$ 字节（三个指针 + 颜色 + 值 + 对齐），$3\times10^6$ 个节点 $\approx 144$ MB，**直接爆掉 64 MB**。线段树维护"区间内最左空房"要 $\approx 4N$ 个 `int` $\approx 48$ MB，贴着上限走钢丝还要搭建树代码。而 successor DSU 只要**一个 `int f[3000005]`，12 MB**，时间还更快。空间约束在这里不是装饰，它直接淘汰了 set 路线。

**第四步：两个会静默出错的坑。**

1. **递归爆栈。** 路径压缩的教科书 `getrt` 是递归的。构造一组毒数据：$N-2$ 头牛喜好依次为 $0,1,2,\dots$（每头恰好占自己的喜好房），则 $f[0]\to1\to2\to\cdots$ 形成一条**从未被压缩过的长链**；最后一头牛喜好 $0$，递归 `getrt(0)` 深度 $\approx 3\times10^6$，栈帧再小也要上百 MB，必然爆栈。所以 `getrt` 必须写**迭代式**：先走到根，再回头把路径上的 $f$ 全部钉到根。我用 $N=3\times10^6$ 的这组毒数据实测，迭代版正常输出。
2. **生成喜好时溢出。** $A\le10^9$，$j\le Y\le C\le 3\times10^6$，$A\times j+B$ 可达 $3\times10^{15}$，`int` 装不下，必须 `long long` 乘完再取模。

**第五步：答案怎么取。** 不需要再开任何结构：占用 $r$ 时 $f[r]$ 被改成 $(r+1)\bmod N\ne r$，而空房的 $f$ 永远等于自己（压缩只改"已占"格子的指针，见引理 2、5）。所以结束后**从小到大扫一遍，第一个满足 $f[i]=i$ 的 $i$ 就是答案**。$C\le N-1$ 保证它存在。

至于题面那句"答案与顺序无关"：我们的模拟按输入生成顺序逐头执行，每步都严格照规则走，这本身就是一个合法的进房顺序，所以答案直接正确——那条性质只是出题人安慰选手的话，**不是算法的前提**。

## 二、思维链：完整证明

**记号。** 房间集 $\mathbb Z_N=\{0,\dots,N-1\}$，环后继 $s(i)=(i+1)\bmod N$。时刻 $t$（已处理 $t$ 头牛）的空房集记 $E_t$，$E_0=\mathbb Z_N$。对 $i\in\mathbb Z_N$，定义 $\mathrm{nxt}_t(i)$ 为从 $i$ 出发沿 $s$ 方向遇到的第一个 $E_t$ 中元素（$E_t\ne\varnothing$ 时良定义）。数组 $f$ 初始 $f[i]=i$。操作序列：对每头牛喜好 $p$，执行 $r\leftarrow\mathrm{getrt}(p)$（沿 $f$ 走到自环根，并把路径上所有点的 $f$ 改指向 $r$），然后 $f[r]\leftarrow s(r)$。

---

### 引理 1（单调性：占用不可逆，空房集只缩不涨）

对任意 $t$，$E_{t+1}\subseteq E_t$，且 $|E_t|=N-t$。从而只要 $t\le N-1$，$E_t\ne\varnothing$，$\mathrm{nxt}_t(i)$ 对所有 $i$ 良定义。

*证明*：规则中只有"占用"操作，没有任何"腾出"操作，故 $E_{t+1}=E_t\setminus\{r_t\}$，其中 $r_t$ 是第 $t+1$ 头牛占用的房间。每头牛恰占一间（$\mathrm{nxt}$ 存在时），故 $|E_t|=N-t$。题面保证牛的总数 $C\le N-1$，故全过程 $E_t\supseteq E_C\ne\varnothing$。环是连通的：从任意 $i$ 出发沿 $s$ 走 $N$ 步遍历所有房间，必遇到 $E_t$ 中元素，故 $\mathrm{nxt}_t(i)$ 存在且唯一（第一个遇到的）。证毕。

**这条引理是并查集合法性的根基**：指针 $f[r]\leftarrow s(r)$ 把"已占"的 $r$ 永久挂到后面，正因为 $r$ 永远不会变回空房，这个"作废"才不需要撤销。若房间会腾出，successor DSU 就彻底失效。

---

### 引理 2（核心不变量）

任意时刻，对每个房间 $i$：

(a) 若 $i$ 空，则 $f[i]=i$；
(b) 若 $i$ 已占，则沿 $f$ 从 $i$ 出发的链 $i,f[i],f[f[i]],\dots$ 有限、无环，终点恰为 $\mathrm{nxt}(i)$，且链上除终点外全部已占。

*证明*：对操作次数归纳。初始 $f[i]=i$、全空，(a) 成立，(b) 空集平凡。设某时刻不变量成立，考察接下来的一次完整操作（$\mathrm{getrt}(p)$ + 占用）。

**先证路径压缩不破坏不变量。** $\mathrm{getrt}(p)$ 沿链走到根 $r$。由归纳假设，链终点 $r$ 满足 $f[r]=r$；由 (a)(b) 的逆否（链上非终点皆已占、已占者 $f\ne$ 自身——后者见下面 (c) 的同步归纳），$r$ 是空房且 $r=\mathrm{nxt}(p)$。压缩把链上每个 $x\ne r$ 的 $f[x]$ 改为 $r$：这些 $x$ 原本已占，其链终点原本就是 $r$，改后终点仍是 $r=\mathrm{nxt}(x)$（$\mathrm{nxt}$ 只依赖空房集，压缩不改空房集），(b) 保持；$r$ 自身与链外点的 $f$ 未动，(a) 与其余 (b) 保持。

**(c) 同步归纳"已占 $\Rightarrow f[i]\ne i$"。** 初始平凡。压缩中被改的 $x$ 已占而 $r$ 空，故 $f[x]=r\ne x$；占用操作把空房 $r$ 变为已占并置 $f[r]=s(r)$，因 $N\ge2$ 有 $s(r)\ne r$ ✓。故该性质全程成立，上面"根必为空房"的推理闭环：若根 $r$ 已占则 $f[r]\ne r$，与根的定义矛盾。

**再证占用 $f[r]\leftarrow s(r)$ 后不变量恢复。** 此刻 $r=\mathrm{nxt}(p)$ 由空变占，其余房间占用状态不变。逐类核对：

1. **空房 $j\ne r$**：$f[j]=j$ 未被任何步骤触碰（压缩只改已占点，占用只改 $r$），(a) ✓。
2. **新占的 $r$**：$f[r]=s(r)$。若 $s(r)$ 空，链 $r\to s(r)$ 终止，而 $r$ 已占后从 $r$ 出发第一个空房正是从 $s(r)$ 出发第一个空房 $=\mathrm{nxt}_{new}(r)$ ✓。若 $s(r)$ 已占，由归纳 (b) 其链终点为 $\mathrm{nxt}(s(r))$；$r$ 占用后 $\mathrm{nxt}_{new}(r)=\mathrm{nxt}_{new}(s(r))=\mathrm{nxt}(s(r))$（$s(r)$ 的占用状态与空房集在 $s(r)$ 之后均未变），链 $r\to s(r)\to\cdots$ 终点正确，中间点皆已占 ✓。
3. **已占且原 $\mathrm{nxt}(i)=r$ 的 $i$**：原链终点为 $r$，现经 $r$ 续到 $\mathrm{nxt}(s(r))$。而 $r$ 变占后，从 $i$ 出发原本在 $r$ 处停下，现在继续走到 $r$ 之后第一个空房，即 $\mathrm{nxt}_{new}(i)=\mathrm{nxt}(s(r))$，与新链终点一致 ✓。
4. **已占且原 $\mathrm{nxt}(i)\ne r$ 的 $i$**：先证原链不经过 $r$——若经过，则链终点（$r$ 空时沿 $f$ 必停在 $r$，因 $f[r]=r$）就是 $r$，与 $\mathrm{nxt}(i)\ne r$ 矛盾。故链未动。再证 $\mathrm{nxt}_{new}(i)=\mathrm{nxt}(i)$：从 $i$ 沿 $s$ 行走，原第一个空房是 $\mathrm{nxt}(i)$；$r$ 若出现在 $\mathrm{nxt}(i)$ 之前，则 $r$ 当时为空会先被遇到，矛盾；故 $r$ 在 $\mathrm{nxt}(i)$ 之后（或就是它，已排除），把 $r$ 变占不影响"第一个遇到的空房" ✓。

四类穷尽所有房间，归纳完成。证毕。

---

### 引理 3（$\mathrm{getrt}$ 的语义与终止性）

$\mathrm{getrt}(p)$ 在有限步内返回 $\mathrm{nxt}(p)$，且返回值就是本次该牛按题面规则应占用的房间。

*证明*：终止性：由引理 2(b)，从任意 $p$ 出发的 $f$ 链有限无环、终点为空房；迭代写法先沿链走到自环根，步数不超过链长 $\le N$，再沿原路回写，同样有限。返回值：链终点 $r$ 满足 $f[r]=r$，由引理 2(a)(c) 知 $r$ 空；由 (b)（$p$ 已占时）或 (a)（$p$ 空时 $r=p=\mathrm{nxt}(p)$）知 $r=\mathrm{nxt}(p)$。题面规则"从 $p$ 向前挨个探索直到第一个空房"正是 $\mathrm{nxt}(p)$ 的定义。证毕。

**注**：迭代而非递归是实现层面的必须（见引理 7 的栈深分析），语义与递归版完全相同。

---

### 引理 4（模拟与题目过程逐头一致）

按输入生成顺序展开所有牛并逐头执行引理 3 的操作，则每头牛占用的房间与题面规则下该顺序进房的结果完全相同；最终空房集即题目所求的最终状态。

*证明*：对牛数归纳。第 $t+1$ 头牛进房前，由归纳假设已占集与题面过程一致，故空房集一致，$\mathrm{nxt}(p_{t+1})$ 一致；引理 3 保证本算法占用 $\mathrm{nxt}(p_{t+1})$，题面规则也占用它。归纳成立。生成顺序是一个合法的进房顺序，而题面明言答案与顺序无关，故即使不按"真实”顺序模拟，最小空房编号也不受影响——但注意本证明**没有用到**顺序无关性：我们模拟的就是一个合法顺序，答案直接正确。证毕。

---

### 引理 5（答案判据：$f[i]=i\iff i$ 最终为空）

全部牛处理完后，$f[i]=i$ 当且仅当房间 $i$ 未被占用。因此最小的满足 $f[i]=i$ 的 $i$ 就是答案，且一定存在。

*证明*：($\Leftarrow$) 空房由引理 2(a) 直接得 $f[i]=i$。($\Rightarrow$) 逆否：已占 $\Rightarrow f[i]\ne i$，即引理 2 证明中的 (c)，全程归纳成立。存在性：$C\le N-1\Rightarrow$ 至少一间空房 $\Rightarrow$ 至少一个 $i$ 满足 $f[i]=i$。最小性：从小到大扫描取第一个命中者，即空房编号最小者。证毕。

**易错点**：不能想当然认为"压缩可能把某个已占点的 $f$ 改回自己"——压缩的目标 $r$ 恒为空房、被改的 $x$ 恒已占，$x\ne r$，故 $f[x]=r\ne x$；也不能认为"空房的 $f$ 会被别人顺手改掉"——压缩只触碰链上已占点，占用只触碰被占的那间空房（它随即变占）。两条路都封死了，判据才成立。

---

### 引理 6（输入展开的正确性与溢出界）

每行 $(X,Y,A,B)$ 展开为 $\sum_{j=1}^{Y}X$ 头牛，第 $j$ 批喜好 $p_j=(A\cdot j+B)\bmod N$。用 `i64` 计算 $A\cdot j+B$ 精确无溢出；所有行展开的总牛数 $C\le N-1$。

*证明*：题面定义即"第 $i$ 批 $X$ 头喜好 $(A\times i+B)\bmod N$"，代码 `for j=1..Y` 内层 `for t=0..X-1` 逐头占用同一 $p_j$，与定义逐字对应（同批牛喜好相同，先后占用结果由引理 4 保证与顺序无关地正确）。范围：$A\le10^9$，$j\le Y\le C\le N-1<3\times10^6$，故 $A\cdot j+B\le 10^9\times3\times10^6+10^9=3.001\times10^{15}<2^{63}-1\approx9.22\times10^{18}$，`i64` 精确；取模后 $p_j<N$ 落入 `int` ✓。若误用 `int`，$A\cdot j$ 在 $A\cdot j\ge2^{31}$ 时回绕，喜好全错且**不会报错**。总牛数上界是题面保证。证毕。

---

### 引理 7（复杂度与空间）

时间 $O(N+C\log N)$（路径压缩单独使用的经典均摊上界；本结构实际接近 $O(N+C\,\alpha)$），空间 $O(N)$，恰一个 `int` 数组 $\approx12$ MB $<64$ MB。

*证明*：初始化 `iota` 与末轮扫描各 $O(N)$。展开输入 $O(K+C)$。每头牛一次 $\mathrm{getrt}$ 加一次 $O(1)$ 赋值；只有路径压缩（无按秩合并）的并查集，$m$ 次操作均摊 $O(\log N)$ 是经典结论，故总计 $O(N+C\log N)\le 3\times10^6\times22\approx6.6\times10^7$ 次指针操作，远在时限内；对"占用即挂到后继"这一特殊结构，压缩后链长极短，实测接近线性。

空间：$f$ 为 $3000005$ 个 `int` $\approx12$ MB，其余 $O(1)$。对比：`std::set` 每节点约 $48$ B，$3\times10^6$ 节点 $\approx144$ MB，超限；线段树 $\approx4N$ 个 `int` $\approx48$ MB，贴限且更慢。

**栈深**：递归 `getrt` 最坏深度 $\Theta(N)$——取 $N-2$ 头牛喜好依次为 $0,1,\dots,N-3$（各占己房，链 $f[i]=i+1$ 从未被压缩），末牛喜好 $0$ 即触发。$3\times10^6$ 层栈帧远超任何默认栈，故必须迭代。迭代版只用 $O(1)$ 栈空间。证毕。

---

### 定理

程序输出最终未被占用的最小编号房间，时间 $O(N+C\log N)$、空间 $12$ MB。

*证明*：引理 6 保证输入展开精确；引理 1 保证空房集单调、$\mathrm{nxt}$ 全程良定义；引理 2 保证 $f$ 结构在压缩与占用下始终刻画 $\mathrm{nxt}$；引理 3 保证每头牛占对房间；引理 4 保证整体模拟与题目过程一致；引理 5 保证扫描判据取到最小空房；引理 7 给出复杂度与空间。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 占用不可逆、空房集只缩不涨 ⇒ "向前找第一个空房"是单向挪动的后继查询，指针作废旧位置无需撤销。
2. **consider easier version** — 先想直线版：$f[r]=r+1$、哨兵 $N$；环状只是把赋值改成 $(r+1)\bmod N$，结构原封不动。
3. **classic problem solution** — successor 并查集 + 路径压缩：查询沿指针跳到第一个空房，均摊近线性，替代每头牛 $O(N)$ 的线性扫描。
4. **explore its property** — 64 MB 空间约束淘汰 `std::set`（$\approx144$ MB）；单 `int` 数组 12 MB 的 DSU 是唯一轻松过关的结构。
5. **discuss by category** — 毒数据链深 $\Theta(N)$ ⇒ `getrt` 必须迭代两遍式压缩；$A\cdot j$ 达 $3\times10^{15}$ ⇒ 生成喜好必须 `i64`。
6. **reduce to easier problem** — 答案不再需要任何查询结构：已占 $\iff f[i]\ne i$，末轮线性扫描取第一个 $f[i]=i$。

| `k` | 压缩输入行数 $\le10^4$ | `int`，读入 | 不是牛数！ |
| `mxn` | $3000005$ | `constexpr int` | 约束 $+5$ |
| `f[i]` | 从 $i$ 找空房的下一候选；空房恒 $f[i]=i$ | `int[mxn]`，`iota(f,f+n,0)` | **占用即挂到 $(i+1)\bmod n$**；判据 $f[i]=i\iff$ 空 |
| `getrt(x)` | 沿 $f$ 找根并迭代压缩，返回 $\mathrm{nxt}(x)$ | `int(int)` | 两遍循环，**绝不递归** |
| `X,Y` | 每批头数 / 批数 | `int`，每行读入 | 本行共 $X\cdot Y$ 头 |
| `A,B` | 喜好生成参数 $\le10^9$ | `i64`，每行读入 | $A\cdot j+B$ 达 $3\times10^{15}$ |
| `p` | 当前批喜好 $(A j+B)\bmod n$ | `int` | `i64` 乘完取模再落 `int` |
| `r` | 本头牛实际占用的房间 | `int` | `r=getrt(p)` 后置 `f[r]=(r+1)%n` |

### 算法步骤

1. I/O 加速三行；读 $N,K$；`iota(f,f+n,0)`。
2. 每行读 $X,Y,A,B$（$A,B$ 用 `i64`）；对 $j=1\dots Y$ 算 $p=(Aj+B)\bmod N$；对批内每头牛：$r=\mathrm{getrt}(p)$，$f[r]\leftarrow(r+1)\bmod N$。
3. 全部处理完后，$i$ 从 $0$ 到 $N-1$ 扫描，输出第一个 $f[i]=i$ 的 $i$ 并结束。

### 复杂度

- 时间：$O(N+C\log N)$（压缩单独使用的均摊上界，实际近线性），$C\le N-1\le3\times10^6$。
- 空间：$O(N)$，单 `int` 数组 $\approx12$ MB $<64$ MB；迭代压缩栈空间 $O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Hint 反推样例输出 `5` 吻合；$N=2$ 两例与 $N=3$ 绕环例均与手算一致；$N=3\times10^6$ 深链毒数据（末牛触发 $\approx3\times10^6$ 长链）正常输出 `2999999`。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3090 [USACO13NOV] Empty Stalls G
// 每头牛占用「从喜好房间起向前第一个空房」⇒ successor 并查集：f[i]=从 i 出发第一个空房候选
// 占用 r 后 f[r]=(r+1)%n；全程 f[i]==i ⟺ i 空。答案=最小的 f[i]==i。
// 迭代式路径压缩：链长可达 3e6，递归会爆栈。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{3000005};

int n,k,f[mxn];

int getrt(int x)
{
	int r=x;
	while(f[r]!=r)
		r=f[r];
	while(f[x]!=x)
	{
		int t=f[x];
		f[x]=r;
		x=t;
	}
	return r;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	iota(f,f+n,0);
	for(int i=0,X,Y;i<k;++i)
	{
		i64 A,B;
		cin>>X>>Y>>A>>B;
		for(int j=1;j<=Y;++j)
		{
			int p=(A*j+B)%n;	// A*j 最大 3e15，必须 i64
			for(int t=0;t<X;++t)
			{
				int r=getrt(p);
				f[r]=(r+1)%n;	// r 被占用，指向环上下一间
			}
		}
	}
	for(int i=0;i<n;++i)
		if(f[i]==i)
		{
			cout<<i<<'\n';
			return 0;
		}
	return 0;
}
```

### 代码说明

- `getrt` 两遍循环：第一遍找根，第二遍把路径上所有 $f$ 钉到根。**不要写成递归**——存在链深 $\Theta(N)$ 的合法数据（引理 7），$3\times10^6$ 层递归必爆栈。
- 压缩只改已占点、根恒为空房，这保证了"空房 $f[i]=i$、已占 $f[i]\ne i$"的判据全程成立（引理 2、5），末轮扫描才敢只看 $f[i]==i$。
- `i64 A,B` 是硬需求：$A\cdot j+B$ 可达 $3\times10^{15}$；`int` 乘法会静默回绕。
- `f[r]=(r+1)%n` 一个取模就把直线版 successor DSU 变成环版；$C\le N-1$ 保证任何时刻都有空房，`getrt` 不会在"全占环"上死循环。
- 本题房间编号本来就是 $0\dots N-1$，无需 `--u` 转换；输出即编号本身。
- 内存只有一个 `f` 数组（12 MB），`X,Y,A,B` 随行读入随用随弃，不存牛列表，稳过 64 MB。
