# P3020 [USACO11MAR] Package Delivery S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $N\le 50000$ 个谷仓、$M\le 50000$ 条**双向**道路，每条路上有 $c_i\ (0\le c_i\le 1000)$ 头奶牛；两点间可能有**多条**直接道路。FJ 从 $1$ 号走到 $N$ 号，每遇到一头**不同的**奶牛就给一份点心（同一头牛只给一次）。求最少带多少份点心。路程长短无所谓。

剥离背景：边权非负的无向多重图上，求 $1\to N$ 的**最短路**。但"每头不同的牛只喂一次"这句话让代价定义和"边权之和"有一层微妙的差别——走回头路时牛已经喂过了，不再花点心。这层差别会不会让"绕路/重复走"比任何简单路径更省？第二部分会严格证明不会。

两个口径先写明：

1. **不同边上的牛视为不同的牛**（题面按边给牛数，样例也按边权求和），于是"一条路线的点心数 = 路线用到的**不同边**的边权之和"。
2. 原题保证 $1$ 能到达 $N$（否则无合法答案）；$N=1$ 时起点即终点，答案 $0$。本文按可达处理。

**手造数据核对。** 题面样例：$6$ 点 $8$ 边：$(1,2,1),(2,3,6),(1,4,4),(2,4,0),(3,4,4),(3,6,2),(4,5,3),(5,6,1)$。最优路线 $1\to2\to4\to5\to6$，花费 $1+0+3+1=5$，输出 `5`。另造三组边界：

| 输入 | 手算 | 输出 |
|---|---|---|
| `2 2` / `1 2 5` / `1 2 3` | 重边取小 | `3` |
| `2 1` / `1 2 0` | 零权边 | `0` |
| `4 4` / `1 2 1000` / `2 4 1000` / `1 3 1` / `3 4 1` | 边数少 ≠ 点心少，$1\to3\to4$ 花 $2$ | `2` |

第三组提醒自己：这不是 BFS（无权最短路），权值差异巨大，必须按权值贪心。

## 二、思维链：完整证明

### 第一步：代价到底是什么——"不同边之和" vs "边权之和"

FJ 的路线是一条**游走**（walk，允许重复点/边）。点心数 = 用到的不同边的权值和。如果直接跑最短路，算的是"每次经过都计费"的边权和。两者相等吗？

**引理 1（最优游走可取为简单路径，两种代价一致）。** 设边权 $c\ge 0$。则
$$\min_{\text{游走 }W:1\to N}\ \sum_{e\in E(W)}c(e)\;=\;\min_{\text{简单路径 }P:1\to N}\ \sum_{e\in P}c(e)\;=\;\mathrm{dist}(1,N),$$
其中 $E(W)$ 是 $W$ 用到的**不同边**集合，$\mathrm{dist}$ 是通常意义的最短路长度。

*证明*：三个量逐对夹逼。

(a) **任何游走的代价 $\ge$ 某条简单路径的代价。** 若 $W$ 重复经过某点 $x$，把两次经过 $x$ 之间的闭合子游走整段删去，得到仍从 $1$ 到 $N$ 的更短游走 $W'$，且 $E(W')\subseteq E(W)$，故代价不增（$c\ge 0$）。反复删环，有限步后得到简单路径 $P$（点数有限，每次删环至少删一条边），$E(P)\subseteq E(W)$，于是 $\sum_{E(W)}c\ge\sum_{E(P)}c=\sum_{e\in P}c$（简单路径每条边恰走一次，两种计费一致）。

(b) **简单路径也是游走**，且其"不同边之和"恰等于边权和，故第一个 min $\le$ 第二个 min。结合 (a) 得两者相等。

(c) **第二个 min = $\mathrm{dist}(1,N)$。** 通常最短路定义为所有游走边权和的最小值；对非负权，任何游走删环后边权和同样不增（删去的边权 $\ge 0$），故最小值在简单路径处取得，与第二个 min 相同。证毕。

**结论：题目就是裸最短路**，"每头牛只喂一次"的机制在非负权下不产生任何额外收益——绕回去喂"免费的旧牛"省下的钱，永远抵不过多走的路（多走的边哪怕权为 $0$ 也不赚）。这一步把看似特殊的计费规则**归约**成了经典问题。

### 第二步：选算法——非负权、多重边、零权

边权 $\ge 0$ ⇒ Dijkstra 适用；有重边 ⇒ 邻接表照单全收，松弛时自然取小；有零权 ⇒ Dijkstra 的正确性证明只要求非负，不要求严格正（下面引理 3 会看到证明在哪里用到 $\ge 0$）。BFS 不行（权不等），Bellman-Ford 的 $O(NM)=2.5\times 10^9$ 太慢，堆优化 Dijkstra 的 $O(M\log M)$ 正好。

**引理 2（`dis` 的两侧夹逼）。** 算法运行中，对任意 $u$：(a) `dis[u]` 总等于某条 $1\to u$ 游走的边权和，故 `dis[u]` $\ge\mathrm{dist}(1,u)$；(b) 若 $1\to u$ 的最短路径上除 $u$ 外所有点都已"定型"（出堆并被接受），则 `dis[u]` $\le\mathrm{dist}(1,u)$。

*证明*：(a) 对松弛次数归纳。初始 `dis[0]=0` 是空游走；每次 `dis[v]=d+w` 中 $d$ 是 $u$ 的某游走路长（归纳），接上边 $(u,v,w)$ 即得 $v$ 的游走。故 `dis` 永远是真实游走路长，不小于最短距离。

(b) 取 $1\to u$ 的一条最短路径 $P$（非负权下可取简单路径，引理 1(c)）。设 $P$ 上除 $u$ 外所有点已定型，$x$ 为 $u$ 在 $P$ 上的前驱，则 $x$ 已定型。最短路的前缀仍是最短路（否则换掉前缀得到更短的 $1\to x$ 路，矛盾），故 $\mathrm{dist}(1,u)=\mathrm{dist}(1,x)+w(x,u)$。$x$ 定型时算法扫描了它的所有出边（含重边），由归纳假设其定型值 $=\mathrm{dist}(1,x)$，执行后 `dis[u]` $\le\mathrm{dist}(1,x)+w(x,u)=\mathrm{dist}(1,u)$；此后 `dis[u]` 只减不增，结论保持。证毕。

（这条引理说明：只要最短路径的"前沿"推进到 $u$ 的前驱，`dis[u]` 就被压到真实距离。最后一步"出堆瞬间完成夹逼"见下。）

**引理 3（出堆即定型，Dijkstra 核心不变量）。** 每次从堆顶弹出一个**未定型**点 $u$（键值 $d$）时，$d=\mathrm{dist}(1,u)$。

*证明*：对出堆顺序归纳。设此前所有被接受的点都满足结论。考察当前弹出的 $(d,u)$，`vis[u]=false`。

首先 $d=$ `dis[u]`：堆中关于 $u$ 的条目都是某次松弛写入的 `dis[u]` 快照；`dis[u]` 只减不增，故最小快照就是当前 `dis[u]`，而堆顶是全局最小键，弹出的必是 $u$ 的最小快照（更大的快照要么还在堆里、要么已被弹出——但 $u$ 未定型意味着从未被接受过，任何此前弹出的 $u$ 条目都会被接受，矛盾；故最小快照仍在堆中且就是堆顶）。于是 $d=$ `dis[u]` $\ge\mathrm{dist}(1,u)$（引理 2(a))。

反向：若 $u$ 不可达则 `dis[u]=inf` 永远不会被松弛出有限值，而堆中只有有限键条目（`inf` 从未入堆），故弹出的 $u$ 必可达。取最短路径 $P$，$y$ 为 $P$ 上第一个未定型点、$x$ 为其前驱（$x$ 已定型；若 $y=u$ 则 $x$ 是 $u$ 的前驱，同样已定型）。由引理 2(b) 的推导，`dis[y]` $\le\mathrm{dist}(1,y)$，且条目 $(\texttt{dis}[y],y)$ 在 $x$ 定型时入堆、$y$ 未定型故仍在堆中。堆顶最小：$d\le\texttt{dis}[y]\le\mathrm{dist}(1,y)\le\mathrm{dist}(1,u)$（最后一步用非负权：$y$ 在最短路径 $P$ 上位于 $u$ 之前）。

两侧夹逼：$\mathrm{dist}(1,u)\le d\le\mathrm{dist}(1,u)$，故 $d=\mathrm{dist}(1,u)$。**非负权用在两处**：最短路前缀距离单调（$\mathrm{dist}(1,y)\le\mathrm{dist}(1,u)$），以及引理 1 的删环不增。证毕。

**推论（惰性删除与重边、零权无害）。** 同一节点可能多次入堆（每次松弛成功一次），`vis` 保证只有第一次（键最小的一次，由引理 3）被接受，其余弹出即弃；重边只是同一对点之间多条松弛候选，`if(dis[v]>d+w)` 自动取小；零权边不破坏引理 3 的任何一步（证明只用了 $\ge 0$）。

**引理 4（终止与答案）。** 堆空时，所有可达点都已定型，`dis[n-1]` $=\mathrm{dist}(1,N)$ 即答案。

*证明*：反证。设可达点 $u$ 未定型且 `dis[u]` 有限（可达 ⇒ 沿最短路径逐段松弛，归纳可得 `dis` 有限，同引理 2(b) 的机制）。取未定型可达点中 `dis` 最小者 $u$，其最短路径前驱 $x$：若 $x$ 未定型则 `dis[x]` $\le\mathrm{dist}(1,x)\le\mathrm{dist}(1,u)=$ `dis[u]`（$x$ 也可达），与 $u$ 的最小性结合引理 3 的夹逼可推出 $x$ 应先于 $u$ 定型……更直接地：条目 $(\texttt{dis}[u],u)$ 有限且曾入堆，堆空意味着它被弹出过；弹出时若 `vis[u]` 已真则 $u$ 已定型，矛盾；否则按引理 3 接受并定型，也矛盾。故所有可达点定型。由引理 3，定型值即真实距离。证毕。

### 第三步：工程细节核算

**引理 5（值域与 INF）。** 任何最短距离 $\le (N-1)\times 1000=4.9999\times 10^7<\texttt{inf}=1145141919$，`int` 足够；`dis` 必须显式填 `inf`。

*证明*：可达时存在简单路径，边数 $\le N-1$，每边 $\le 1000$。松弛中间量 $d+w\le 4.9999\times 10^7+1000<$ `inf`，不会把 `inf` 误当有限距离松弛出去（`inf` 点从未出堆，$d$ 永远有限）。全局 `int` 数组默认 $0$：若不填 `inf`，所有点初始 `dis=0`，`if(dis[v]>d+w)` 永远不成立，算法输出 `dis[n-1]=0`——**静默全错**，这是本题最经典的陷阱。证毕。

### 引理 6（复杂度）

时间 $O((N+M)\log M)$，空间 $O(N+M)$。

*证明*：每条无向边存两份，松弛总次数 $\le 2M$，每次成功松弛入堆一次，堆中条目 $\le 2M+1$，每次入堆/出堆 $O(\log M)$；每点定型一次、扫描其邻接表一次，共 $O(N+M)$。代入 $N=M=5\times 10^4$：约 $10^5\times 17\approx 1.7\times 10^6$ 次堆操作。空间：邻接表 $2M$ 个 `pair<int,int>` + `dis/vis` $O(N)$。证毕。

### 定理

程序输出 FJ 从 $1$ 到 $N$ 最少需要携带的点心数。

*证明*：引理 1 把"不同牛只喂一次"的游走代价归约为非负权最短路；引理 2、3 保证堆优化 Dijkstra 每次出堆即得真实距离（重边、零权由推论覆盖）；引理 4 保证终点定型且值正确；引理 5 保证值域安全、INF 初始化正确；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 点心数 = 路线用到的**不同边**的权值和，不是逐次经过的边权和；"喂旧牛免费"看似特殊机制。
2. **reduce to easier problem** — 非负权下游走删环不增代价 ⇒ 最优游走可取简单路径 ⇒ 两种计费一致，归约为裸最短路。
3. **discuss by category** — 权不等否掉 BFS，$O(NM)$ 否掉 Bellman-Ford；非负 + 重边 + 零权 ⇒ 堆优化 Dijkstra。
4. **classic problem solution** — 惰性删除 Dijkstra：出堆即定型（夹逼证明），`vis` 弃旧条目，重边松弛自动取小。
5. **explore its property** — 距离上界 $(N-1)\cdot 1000\approx 5\times 10^7$，`int` 够用；`dis` 必须显式填 INF，全局默认 $0$ 会静默全错。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n,m` | 谷仓数、道路数 | `int`，读入 | 均 $\le 50000$ |
| `graph[u]` | $u$ 的出边 `{v,w}`（无向存两份） | `vector<pair<int,int>>[mxn]` | 重边照单全收 |
| `dis[u]` | $1\to u$ 的当前最短估计 | `int[mxn]`，**`fill_n(dis,n,inf)`**，`dis[0]=0` | 出堆定型后 = 真实距离 |
| `vis[u]` | $u$ 是否已定型 | `bool[mxn]`，默认 `false` | 惰性删除的开关 |
| `Q` | 小根堆 `{dis快照, 点}` | `priority_queue<...,greater<>>` | 快照可能过期，弹出时查 `vis` |
| `inf` | $1145141919$ | `constexpr int` | 大于一切合法距离 $5\times 10^7$ |

### 算法步骤

1. 读 $N,M$ 与每条边 $(u,v,w)$，转 0-based，双向加边。
2. `dis` 填 `inf`，`dis[0]=0`，$(0,0)$ 入堆。
3. 堆非空时弹出 $(d,u)$；`vis[u]` 为真则弃；否则置真，扫描 $u$ 的出边，`dis[v]>d+w` 则更新并入堆。
4. 输出 `dis[n-1]`。

### 复杂度

- 时间 $O((N+M)\log M)$，约 $1.7\times 10^6$ 次堆操作。
- 空间 $O(N+M)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面 $6$ 点样例输出 $5$；重边取小输出 $3$、零权输出 $0$、"边数少不等于点心少"输出 $2$ 均与手算一致；$N=M=50000$ 的链 + 捷径极限数据输出正确且轻松通过。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3020 [USACO11MAR] Package Delivery S
// 非负边权无向图 1->N 最短路 = 最少点心；堆优化 Dijkstra，惰性删除
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005},inf{1145141919};

int n,m,dis[mxn];
bool vis[mxn];
vector<pair<int,int>>graph[mxn];	// {v,w}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,u,v,w;i<m;++i)
	{
		cin>>u>>v>>w;--u;--v;
		graph[u].push_back({v,w});
		graph[v].push_back({u,w});
	}
	fill_n(dis,n,inf);		// 全局默认 0 不是 INF！必须显式填
	dis[0]=0;
	priority_queue<pair<int,int>,vector<pair<int,int>>,greater<>>Q;
	Q.push({0,0});
	while(!Q.empty())
	{
		auto[d,u]=Q.top();Q.pop();
		if(vis[u])
			continue;
		vis[u]=true;		// 出堆即定型（边权非负）
		for(auto[v,w]:graph[u])
			if(dis[v]>d+w)
			{
				dis[v]=d+w;
				Q.push({dis[v],v});
			}
	}
	cout<<dis[n-1]<<'\n';
	return 0;
}
```

### 代码说明

- **`fill_n(dis,n,inf)` 一行都不能省**：全局 `int` 默认 $0$，不填的话所有松弛条件 `dis[v]>d+w` 恒假，程序安静地输出 $0$（引理 5）。
- 松弛用出堆的 $d$ 而不是 `dis[u]`：两者此刻相等（引理 3），但用快照 $d$ 是惰性删除写法下的标准习惯，语义上"以定型距离扩展"。
- `vis` 在**接受时**置真而不是入堆时：同一点可多次入堆，只有最小快照那次被接受，其余弹出即弃（引理 3 推论）。
- 重边、零权无需特判：邻接表存所有边，松弛取小；正确性证明只要求 $c\ge 0$。
- `pair` 的第一维是距离，`greater<>` 按字典序先比距离，恰好是小根堆所需；`{dis快照, 点}` 顺序不能反。
- $N=1$ 时 `dis[0]=0` 直接输出 $0$；不可达情形原题保证不存在。
