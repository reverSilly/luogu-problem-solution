# P3029 [USACO11NOV] Cow Lineup S — 题解

## 一、解题过程：人类思考叙事

**题意重述（剥离背景）。** 数轴上 $N$ 头牛（$1\le N\le 5\times 10^4$），位置 $x_i$ 两两不同，品种 ID $b_i$；$x_i,b_i\le 10^9$。选一段连续坐标区间拍照，要求**每种出现过的品种至少有一头牛在画面里**，代价 = 区间内最大 $x$ 减最小 $x$。求最小代价。即：把牛按 $x$ 排序后，找一个**包含全部品种的最短连续窗口**，最小化窗口两端牛的坐标差。

**第一步：照片一定可以"收紧"到牛身上。** 照片是任意实数区间 $[L,R]$，但代价只取决于画面里最左/最右的牛。把 $L$ 右移到画面内最左牛的位置、$R$ 左移到最右牛的位置，画面里的牛集合不变、代价不增。所以只需考虑"排序后的一段连续牛 $a_l..a_r$，代价 $x_r-x_l$"。又因为画面必须覆盖全部品种，**窗口合法当且仅当其中的品种集合 = 全体品种集合**。问题彻底离散化：排序数组上的最短全覆盖窗口。

**第二步：品种 ID 高达 $10^9$，先离散化。** 窗口里只关心"品种是否相同"，不关心 ID 数值大小。把 $N$ 个 ID 排序去重得到 $tot$ 种，每头牛的 ID 换成它在去重表里的下标（`lower_bound`），就能开 `cnt[50005]` 数每个品种在窗口里出现几次。$O(N\log N)$。

**第三步：暴力窗口 $O(N^2)$，找单调性。** 枚举 $l,r$ 检查全覆盖是 $O(N^2)$ 甚至 $O(N^2\cdot tot)$，$N=5\times10^4$ 必炸。盯着"合法"二字看：固定右端 $r$，左端 $l$ 越往右窗口越小、越难合法——**合法性关于 $l$ 单调**：若 $[l,r]$ 合法，则 $[l',r]$（$l'\le l$）也合法（超集只会多不会少）。于是合法左端构成一个前缀 $[0,L(r)]$，最优的左端就是最靠右的 $L(r)$。再看 $L(r)$ 关于 $r$：右端右移只会添牛不会删牛，原来合法的左端仍然合法，所以 $L(r)$ **单调不减**。两个单调性合起来 = **双指针（尺取法）**：$r$ 从头扫到尾，$l$ 只前进不后退，总移动 $O(N)$。

**第四步：窗口里"品种齐不齐"怎么 $O(1)$ 维护？** 开 `cnt[b]` 记窗口内品种 $b$ 的牛数，再记 `have` = 窗口内**不同**品种数。进一头牛：`cnt[b]` 从 0 变 1 时 `have++`；出一头牛：`cnt[b]` 从 1 变 0 时 `have--`。`have==tot` 就是全覆盖。每次指针移动 $O(1)$。

**第五步：什么时候记答案？** 我的写法是：$r$ 每进一头牛后，只要 `have==tot` 就循环"记答案 $x_r-x_l$、弹出 $a_l$、$l{+}{+}$"，直到窗口不再合法。这样对每个 $r$，从当前 $l$ 起的合法左端被逐个记录。有个微妙之处：$l$ 不回退，偶尔会"跳过"某个 $r$ 的最优左端 $L(r)$——但那只发生在 $L(r)=L(r-1)$ 时，此时 $x_r-x_{L(r)}>x_{r-1}-x_{L(r-1)}$，被跳过的代价严格大于上一轮已记录的代价，**对最小值毫无影响**（引理 5 给完整证明）。注意 `ans` 初值必须是 INF（`1145141919`），不能是 0——0 是"代价"的合法取值，混用会让 min 永远输出 0。不过本题 $N\ge 1$ 且全窗口 $[0,N-1]$ 必合法，答案一定会被更新，INF 只是语义正确的保险。

**边界。** $N=1$：只有一种品种，窗口就是那头牛自己，代价 $x_0-x_0=0$。全部同品种：同理答案 0。位置互异保证排序严格、窗口非空时代价定义无歧义。

**手造数据核对。**

第一组（题面样例）：$(25,7),(26,1),(15,1),(22,3),(20,1),(30,1)$。按 $x$ 排序：$15(1),20(1),22(3),25(7),26(1),30(1)$，品种 $\{1,3,7\}$ 共 3 种。窗口 $[22,26]$ 含品种 $3,7,1$，代价 $4$；更短的窗口凑不齐 3 种。答案 $4$。✓

第二组（单牛）：$(10^9,10^9)$。答案 $0$。顺带验证大 ID、大坐标。

第三组（全同品种）：$(5,2),(1,2),(9,2)$。排序 $1,5,9$，任何单牛窗口已覆盖唯一品种，答案 $0$。

第四组（必须横跨整条线）：$(1,1),(2,2),(3,3),(4,1)$。品种 $\{1,2,3\}$；含品种 2、3 的窗口必须含位置 2、3，再配一头品种 1（位置 1 或 4）：$[1,3]$ 代价 2，$[2,4]$ 代价 2。答案 $2$。这组验证"窗口端点不必是首尾牛"。

## 二、思维链：完整证明

**记号。** 牛按 $x$ 升序排序后记 $a_0,\dots,a_{N-1}$，$a_i=(x_i,b_i)$，$x_0<x_1<\dots<x_{N-1}$（位置互异）。品种全集 $B=\{b_i\}$，$tot=|B|$。窗口 $[l,r]$（$0\le l\le r<N$）指牛集合 $\{a_l,\dots,a_r\}$，其品种集 $B(l,r)=\{b_i:l\le i\le r\}$，代价 $w(l,r)=x_r-x_l$。合法 $\iff B(l,r)=B$。目标 $\min\{w(l,r):B(l,r)=B\}$（全窗口 $[0,N-1]$ 合法，故最小值存在）。

---

### 引理 1（连续照片归约为排序数组上的窗口）

任意合法照片（实数区间 $[L,R]$，画面内牛的品种集 $=B$）的代价 $\ge$ 某个合法窗口的代价；反之每个合法窗口对应一张同代价的合法照片。故两问题最优值相等。

*证明*：设照片画面内的牛按位置为 $a_p,\dots,a_q$（画面是坐标区间，夹在 $L,R$ 之间的牛恰是排序后连续一段；画面非空因为 $B\ne\varnothing$）。合法性给出 $B(p,q)=B$。照片代价 $R-L\ge x_q-x_p=w(p,q)$（$L\le x_p$、$R\ge x_q$）。故照片代价 $\ge$ 合法窗口 $[p,q]$ 的代价。反向：窗口 $[l,r]$ 取照片 $[x_l,x_r]$，画面内牛恰为 $a_l..a_r$（位置互异且有序），代价恰为 $w(l,r)$。两个方向合起来最优值相等。证毕。

---

### 引理 2（离散化保持品种相等关系）

设去重排序后的品种表为 $t_0<\dots<t_{tot-1}$，映射 $\varphi(b_j)=\text{lower\_bound}(t,b_j)$ 的下标。则 $b_i=b_j\iff\varphi(b_i)=\varphi(b_j)$，且 $|\{\varphi(b_i)\}|=tot$。从而用 $\varphi$ 替换 ID 后，一切窗口的合法性与代价不变。

*证明*：$\varphi$ 是 $B$ 到 $\{0,\dots,tot-1\}$ 的双射（排序去重表与原品种集一一对应，`lower_bound` 恰好取到对应下标），双射保持相等与不等，也保持集合的势。合法性只由"窗口品种集是否等于全集"决定，代价只由 $x$ 决定，二者在重命名下不变。证毕。

---

### 引理 3（合法性对左端单调；$L(r)$ 存在且单调不减）

固定 $r$：若 $[l,r]$ 合法且 $l'\le l$，则 $[l',r]$ 合法。定义 $L(r)=\max\{l:[l,r]\text{ 合法}\}$（集合非空时）。则：(a) $[l,r]$ 合法 $\iff l\le L(r)$（在 $L(r)$ 有定义时）；(b) 若 $L(r)$ 有定义，则 $L(r+1)$ 有定义且 $L(r+1)\ge L(r)$。

*证明*：单调性：$l'\le l\Rightarrow B(l,r)\subseteq B(l',r)\subseteq B$，而 $B(l,r)=B$，夹得 $B(l',r)=B$。(a)：$\Leftarrow$ 由单调性（$l\le L(r)$ 且 $[L(r),r]$ 合法）；$\Rightarrow$ 由 $L(r)$ 的最大性。(b)：$[L(r),r]$ 合法 $\Rightarrow B(L(r),r)=B\subseteq B(L(r),r+1)\subseteq B\Rightarrow[L(r),r+1]$ 合法，故 $L(r+1)$ 有定义且 $\ge L(r)$。证毕。

**推论**：固定 $r$ 时代价最小的合法窗口是 $[L(r),r]$（$w(l,r)=x_r-x_l$ 关于 $l$ 递减，$x$ 严格递增）。全局最优 $=\min_{r:\,L(r)\text{ 有定义}}w(L(r),r)$。

---

### 引理 4（`cnt`/`have` 不变量）

维护窗口 $[l,r)$（左闭右开，方便实现）的 `cnt[b]` = 窗口内品种 $b$ 的牛数，`have` = $\#\{b:\texttt{cnt}[b]>0\}$。初始空窗口全 0。则"右端加入 $a_r$：`if(cnt[b]++==0)++have;`"与"左端弹出 $a_l$：`if(--cnt[b]==0)--have;`"保持该不变量。

*证明*：加入前不变量成立。加入品种 $b$ 的一头牛：`cnt[b]` 加 1；其余 `cnt` 不变。$\{b':\texttt{cnt}[b']>0\}$ 的变化仅可能发生在 $b$ 上：原 `cnt[b]==0` 则新为正，集合恰增一个元素，`have++` 正确（代码用后缀 `++` 判旧值 0）；原 `cnt[b]>0` 则仍为正，集合不变，不动 `have` 正确。弹出对称：`cnt[b]` 减 1（窗口含 $a_l$ 保证减前 $\ge 1$，不会负），减后为 0 则集合恰删一个元素，`have--` 正确（前缀 `--` 判新值 0）；否则不动。归纳于操作次数即得。证毕。

**推论**：`have==tot` $\iff$ 窗口品种集 $=B$（`have` 是窗口品种集大小，$\le tot$，取等即全覆盖）。

---

### 引理 5（双指针循环的正确性：最小值不漏）

代码：`l=0`；对 $r=0..N-1$：加入 $a_r$；`while(have==tot){ ans=min(ans,x[r]-x[l]); 弹出 a[l]; ++l; }`。则最终 `ans` $=\min\{w(l,r):[l,r]\text{ 合法}\}$，且总操作数 $O(N)$。

*证明*：先注意引理 3(b) 的一个推论：**$L$ 一旦有定义就永远有定义**（$L(r)$ 有定义 $\Rightarrow L(r+1)$ 有定义），故"$L(r)$ 有定义"的 $r$ 构成一个后缀 $[r_0,N-1]$；$r_0$ 是首个使窗口可能合法的右端。

**轮末不变量**：对每个 $r\ge r_0$，第 $r$ 轮结束时 $l=L(r)+1$。

对 $r$ 归纳。先证**轮初界**：第 $r$ 轮（$r\ge r_0$）开始时 $l\le L(r)+1$。
- $r=r_0$：此前各轮 $L$ 无定义，while 从未执行（窗口不合法），$l$ 仍为 $0\le L(r_0)+1$ ✓。
- $r>r_0$：由归纳假设，第 $r-1$ 轮末 $l=L(r-1)+1\le L(r)+1$（引理 3(b) 单调性）✓。

第 $r$ 轮加入 $a_r$ 后，while 的条件"窗口 $[l,r]$ 合法"由引理 3(a) 等价于 $l\le L(r)$。于是：
- 若轮初 $l\le L(r)$：while 依次在左端 $l,l+1,\dots,L(r)$ 处各执行一次（每次记录 $w(\cdot,r)$ 后 $l$ 加一），在 $l=L(r)+1$ 处条件首次为假而停止。**特别地，$w(L(r),r)$ 被记录**。轮末 $l=L(r)+1$ ✓。
- 若轮初 $l=L(r)+1$（由轮初界，这是唯一剩下的可能）：while 一次都不执行，轮末 $l=L(r)+1$ ✓。此时结合归纳假设 $l=L(r-1)+1$，得 $L(r)=L(r-1)$，故
$$w(L(r),r)=x_r-x_{L(r)}>x_{r-1}-x_{L(r-1)}=w(L(r-1),r-1),$$
即**被跳过的代价严格大于上一轮的最优窗口代价**。

对 $r<r_0$：$L(r)$ 无定义，没有合法窗口以 $r$ 结尾，while 不执行、无需记录，$l$ 保持 0。

**汇总**：设全局最优在 $r^\*$ 处取得，值为 $\mathrm{OPT}=w(L(r^\*),r^\*)$。
- ($\texttt{ans}\ge\mathrm{OPT}$)：每次记录的窗口都合法（while 条件保证），故 `ans` 是若干合法窗口代价的 min，$\ge\mathrm{OPT}$。
- ($\texttt{ans}\le\mathrm{OPT}$)：反证。若 $w(L(r^\*),r^\*)$ 在第 $r^\*$ 轮被记录，则 $\texttt{ans}\le\mathrm{OPT}$ 直接成立。否则它落入"被跳过"情形，存在 $r^\*-1\ge r_0$ 使 $L(r^\*)=L(r^\*-1)$ 且 $w(L(r^\*-1),r^\*-1)<\mathrm{OPT}$；而 $[L(r^\*-1),r^\*-1]$ 合法，其代价 $<\mathrm{OPT}$ 与 $\mathrm{OPT}$ 是全局最小矛盾。故必被记录，$\texttt{ans}\le\mathrm{OPT}$。

两边夹得 $\texttt{ans}=\mathrm{OPT}$。

**复杂度**：`l` 与 `r` 都只增不减且始终 $\le N$，while 总弹出次数 $\le N$，外层加入 $N$ 次，每次 $O(1)$（引理 4），共 $O(N)$。证毕。

---

### 引理 6（初值与边界）

`ans` 初始化为 `1145141919`（INF）；$N\ge 1$ 时答案必被更新为某个 $w(l,r)\le x_{N-1}-x_0<10^9<$ INF，故 INF 不会泄漏到输出。$N=1$ 或全体同品种时答案为 0。

*证明*：全窗口 $[0,N-1]$ 合法，$L(N-1)$ 有定义，由引理 5 其最优窗口被记录，故 `ans` $\le x_{N-1}-x_0\le 10^9-1<1145141919$。$N=1$：$r=0$ 加入后 `have=tot=1`，记录 $x_0-x_0=0$。全同品种：每个 $r$ 加入后 `have=tot=1`，while 弹到只剩 $a_r$，记录 $x_r-x_r=0$。两种情形 `ans`$=0$ 且代价非负，最优。证毕。

**陷阱说明**：若 `ans` 初值错写成 0（全局默认），`min` 恒 0，所有数据都输出 0——"答案数组"的全局默认 0 恰是合法代价，必须显式给 INF。这与"距离数组必须 fill INF"是同一条铁律。

---

### 引理 7（复杂度）

时间 $O(N\log N)$，空间 $O(N)$。

*证明*：读入 $O(N)$；按 $x$ 排序 $O(N\log N)$；品种表排序去重 $O(N\log N)$；每头牛 `lower_bound` $O(\log N)$ 共 $O(N\log N)$；双指针 $O(N)$（引理 5）。合计 $O(N\log N)$，$N=5\times10^4$ 时约 $3\times 5\times10^4\times 16\approx 2.4\times 10^6$ 次比较。空间：牛数组、品种表、`cnt` 各 $O(N)$。证毕。

---

### 定理

程序输出包含全部品种的最短照片的最小代价。

*证明*：引理 1 把连续照片归约为排序数组窗口；引理 2 保证离散化不改问题；引理 3 给出"合法左端是前缀 + $L(r)$ 单调"的双指针前提与"只需看 $[L(r),r]$"的归约；引理 4 保证 $O(1)$ 判定全覆盖；引理 5 证明循环记录的合法窗口代价的最小值恰为全局最优（被跳过的窗口代价严格大于已记录值，不可能唯一最小）；引理 6 保证初值与边界正确；引理 7 保证时限。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 照片可收紧到画面内最左/最右牛：连续区间问题 ⇒ 排序数组上的连续窗口问题。
2. **reduce to easier problem** — 品种 ID 只用于判等 ⇒ 排序去重 + `lower_bound` 离散化到 $[0,tot)$，`cnt` 数组开得起。
3. **consider easier version** — 暴力枚举 $l,r$ 是 $O(N^2)$；盯住"窗口越小越难合法"找单调性。
4. **explore its property** — 合法左端构成前缀（超集论证），$L(r)$ 关于 $r$ 单调不减 ⇒ 双指针合法。
5. **classic problem solution** — 尺取法 + `cnt[b]`/`have` 增量维护"不同品种数"，`have==tot` 即全覆盖；while 内记答案，被跳过的最优左端其代价必被更早记录值严格压制，全局最小不漏。
6. **discuss by category** — $N=1$/全同品种答案 0；`ans` 必须显式 INF（0 是合法代价）；位置互异保证排序严格。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| $N$ | 牛数 | `int n` | 读入 |
| `mxn` | $5\times 10^4+5$ | `constexpr int` | 各数组尺寸 |
| `inf` | $1145141919$ | `constexpr int` | 答案哨兵；$>10^9\ge$ 任何真实代价 |
| `a[i]` | 排序后第 $i$ 头牛 `{x,b}` | `struct{int x,b;}[mxn]` | 读入后按 `x` 升序 sort |
| `bs[j]` | 去重排序后的品种表 | `int[mxn]` | sort+unique；`tot`=表长 |
| `tot` | 不同品种总数 | `int` | 离散化后 `a[i].b` 换成表下标 |
| `cnt[b]` | 窗口内品种 $b$ 的牛数 | `int[mxn]` | 全局默认 0 = 空窗口，**这里 0 恰好是正确初值** |
| `have` | 窗口内不同品种数 | `int`，初值 $0$ | `cnt` 跨 0 边界时 $\pm 1$ |
| `l,r` | 双指针（窗口左端 / 当前右端） | `int`，初值 $0$ | 只增不减 |
| `ans` | 最小代价 | `int`，初值 `inf` | **必须显式 INF，0 是合法代价** |

### 算法步骤

1. I/O 加速三行；读 $N$ 与每头牛 $(x_i,b_i)$，同时把 $b_i$ 复制进 `bs`。
2. `a` 按 `x` 升序排序；`bs` 排序 + `unique` 得 `tot`；每头牛 `a[i].b=lower_bound(bs,bs+tot,b_i)-bs`。
3. 双指针：$r=0..N-1$：`if(cnt[a[r].b]++==0)++have;`；`while(have==tot){ans=min(ans,a[r].x-a[l].x); if(--cnt[a[l].b]==0)--have; ++l;}`。
4. 输出 `ans`。

### 复杂度

- 时间：$O(N\log N)\approx 2.4\times 10^6$ 次比较 + $O(N)$ 扫描。
- 空间：$O(N)\approx 1.2$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面样例（4）、单牛（0）、全同品种（0）、横跨窗口（2）四组手造数据全部吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3029 [USACO11NOV] Cow Lineup S
// 按 x 排序 + 品种离散化，尺取法找覆盖全部品种的最短窗口
// 合法左端是前缀、L(r) 单调不减 ⇒ 双指针只进不退；have==tot 即全覆盖
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{50005};
constexpr int inf{1145141919};

struct cow{int x,b;};

int n,tot,bs[mxn],cnt[mxn];
cow a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i].x>>a[i].b;
		bs[i]=a[i].b;
	}
	sort(a,a+n,[](cow u,cow v){return u.x<v.x;});
	sort(bs,bs+n);
	tot=unique(bs,bs+n)-bs;
	for(int i=0;i<n;++i)
		a[i].b=lower_bound(bs,bs+tot,a[i].b)-bs;	// 品种只判等，离散化不丢信息
	int l=0,have=0,ans=inf;	// ans 必须 INF：0 是合法代价，不能靠全局默认
	for(int r=0;r<n;++r)
	{
		if(cnt[a[r].b]++==0)
			++have;
		while(have==tot)
		{
			ans=min(ans,a[r].x-a[l].x);
			if(--cnt[a[l].b]==0)
				--have;
			++l;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- `cnt[a[r].b]++==0` 用**后缀**自增判"进窗前是 0"，`--cnt[a[l].b]==0` 用**前缀**自减判"出窗后是 0"——两处方向相反，写反会让 `have` 漂移（引理 4 的不变量被破坏）。
- while 里"先记答案再弹左端"：对每个 $r$ 从当前 `l` 起扫过合法左端；偶尔跳过 $L(r)$ 只发生在 $L(r)=L(r-1)$ 时，其代价严格大于上一轮已记录值，最小值不漏（引理 5）。弹出到不合法就停，`l` 全程不回退。
- `cnt` 全 0 初值在这里**恰好正确**（空窗口计数为 0），与 `ans` 必须显式 INF 形成对照：同是全局默认 0，一个是合法初值一个是陷阱，逐个数组想清楚语义再决定要不要 fill。
- 离散化用 sort+unique+`lower_bound` 三连，$O(N\log N)$；也可以用 `map`，但常数更大且不符合全局静态数组风格。
- 窗口代价用 `a[r].x-a[l].x`（两端都是牛的位置），对应引理 1 的"收紧"结论；位置互异保证 `x` 严格递增，引理 3 的"代价关于 $l$ 递减"成立。
