# P3052 [USACO12MAR] Cows in a Skyscraper G — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 头奶牛（$1\le N\le 18$），第 $i$ 头重 $C_i$（$1\le C_i\le W$），电梯载重上限 $W$（$1\le W\le 10^8$）。每次电梯可以装任意若干头牛，只要总重 $\le W$；每头牛必须恰好坐一次电梯。求把所有牛送下楼所需的**最少电梯次数**。背景故事（爬楼比赛、不肯走楼梯）全部可以剥掉，这就是一个一维装箱问题（bin packing）：把 $N$ 个物品装进容量为 $W$ 的箱子，最小化箱子数。

**边界与口径。** 题面保证 $C_i\le W$，所以每头牛单独坐一次总是合法的，答案一定存在且 $\le N$；$N=1$ 时答案为 $1$。电梯次数只与"怎么分组"有关，与组的先后顺序无关——这一点后面会反复用到。

**第一眼：这是 NP 难的装箱，但 $N\le 18$ 在喊"指数算法"。** 装箱问题没有已知的多项式最优算法，所以别指望贪心。$N\le 18$ 这个范围非常刻意：$2^{18}=262144$，$18\cdot 2^{18}\approx 4.7\times 10^6$，正是状压 DP 的舒适区。方向定了：**对"哪些牛已经上电梯"这个集合做 DP**。

**试探一：只记"最少次数"够不够？** 最自然的设法是 $f[S]=$ 送完集合 $S$ 的最少电梯次数。但写转移时立刻卡住：从 $S$ 加入一头新牛 $i$，到底要不要新开一次电梯？这取决于**当前这次电梯已经装了多少**——而 $f[S]$ 把这个信息丢掉了。同一个 $S$、同样的最少次数，当前电梯的剩余容量可能完全不同，后续可行性也就完全不同。状态不满足无后效性，直接设 $f[S]$ 是错的。

**碰壁的具体反例。** $W=10$，牛 $\{6,5,4,5\}$。看子集 $\{6,5,4\}$：
- 按顺序 $6,5,4$ 上电梯：第一趟装 $6$（再装 $5$ 超重），第二趟装 $5+4=9$，状态是"2 趟，当前载重 9"；
- 按顺序 $6,4,5$：第一趟装 $6+4=10$，第二趟装 $5$，状态是"2 趟，当前载重 5"。

两种都是 2 趟，但接下来上最后一头 $5$：载重 9 的那边 $9+5>10$，被迫开第三趟，得 3；载重 5 的那边 $5+5=10$ 恰好塞进，得 2。而真实最优就是 2（$\{6,4\}$ 一趟、$\{5,5\}$ 一趟）。**结论：次数相同时，当前电梯装得越少越好，必须把"当前载重"也纳入状态。**

**试探二：枚举"最后一趟装谁"？** 另一条路是 $f[S]=\min_{T\subseteq S,\ \mathrm{sum}(T)\le W} f[S\setminus T]+1$，枚举最后一趟的子集。这是对的，但复杂度 $O(3^N)$（子集的子集），$3^{18}\approx 3.9\times 10^8$，在 1 秒时限边缘跳舞，不优雅。

**修正：二元组状态 + 字典序取 min。** 把状态设成二元组
$$\mathrm{dp}[S]=\bigl(k[S],\ w[S]\bigr)=(\text{最少电梯次数},\ \text{该次数下当前电梯的最小载重}),$$
按**字典序**取最小（先比次数，次数相同比载重）。转移极简单：枚举 $S$ 中"最后上电梯"的牛 $i$，令 $p=S\setminus\{i\}$：
- 若 $w[p]+C_i\le W$：牛 $i$ 挤进当前电梯，候选 $(k[p],\ w[p]+C_i)$；
- 否则：新开一趟，候选 $(k[p]+1,\ C_i)$。

对所有 $i$ 取字典序 min。初值 $\mathrm{dp}[\varnothing]=(1,0)$（第一趟电梯已经开着，空的），答案 $k[\text{全集}]$。复杂度 $O(2^N N)$，稳过。

**但这里藏着一个必须证明的断言**：凭什么"次数相同取载重最小"不会丢掉最优解？会不会存在某个中间状态载重稍大、却能在后面"逆袭"？直觉上剩余容量越大越好，但直觉不是证明——第二部分用"转移的单调性"把它钉死。

**手造数据核对。** 题面 Hint 给了样例说明（无正式样例输入输出格式，按 Input Format 组装）：

第一组（Hint 原例）：$N=4,W=10$，牛 $5,6,3,7$。$3$ 可以和任何一头拼，但 $5+6,5+7,6+7$ 都超 $10$，所以至少 3 趟；$\{5,3\},\{6\},\{7\}$ 恰好 3 趟。输出 `3`。

第二组（专打"次关键字"的反例）：$N=4,W=10$，牛 $6,5,4,5$。如上分析，输出 `2`。只记次数的错误 DP 会在这里输出 3。

第三组（边界）：$N=1,W=1$，牛 $1$，输出 `1`；$N=3,W=10$，牛 $10,10,10$，谁都拼不了，输出 `3`。

## 二、思维链：完整证明

**记号。** 牛下标 $0\le i<N$，重量 $c_i\in[1,W]$。一个**状态**是二元组 $(k,w)$：$k\ge 1$ 表示已开启的电梯趟数（含当前趟），$w\in[0,W]$ 表示当前趟已装载重。初始状态 $(1,0)$。给定一个牛的排列（顺序）$\pi$，**顺序装载过程**依次处理每头牛：当前载重 $w$ 满足 $w+c\le W$ 就装进当前趟（$w\leftarrow w+c$），否则新开一趟（$k\leftarrow k+1,\ w\leftarrow c$）。记单步转移为
$$T_c(k,w)=\begin{cases}(k,\ w+c),&w+c\le W\\(k+1,\ c),&w+c>W.\end{cases}$$
二元组按字典序比较：$(k_1,w_1)\le_{\mathrm{lex}}(k_2,w_2)\iff k_1<k_2\ \lor\ (k_1=k_2\land w_1\le w_2)$。这是全序（两个分量都是全序，字典序保序性显然成立，逐分支验证传递性与三分性即可，与 P2412 引理 2 同构）。

---

### 引理 1（顺序装载过程与分组方案等价）

(a) 任意排列 $\pi$ 的顺序装载过程结束时，$k$ 等于一个合法分组方案的组数（每头牛恰好属于一组、每组总重 $\le W$）。

(b) 任意合法分组方案（$r$ 组），把各组按任意顺序、组内牛按任意顺序排成排列 $\pi$，则顺序装载过程的最终趟数 $k\le r$。

从而 $\min_{\pi} k(\pi)=\min_{\text{分组}} r$，即**原问题答案等于所有排列上顺序装载趟数的最小值**。

*证明*：(a) 把每趟电梯装载的牛集合记为一组。每头牛被处理一次、恰好进入一趟，故是划分；每趟的载重只在 $w+c\le W$ 时增加，新开趟时 $w=c\le W$（题面保证 $c_i\le W$），故每组总重 $\le W$。组数就是 $k$。

(b) 关键断言：**每组至多包含某一趟电梯的"第一头牛"**。反证：设第 $t$ 趟与第 $t+1$ 趟的第一头牛都属于同一组 $G$。排列中各组连续排列，故从第 $t$ 趟第一头牛到第 $t+1$ 趟第一头牛之间的所有牛都属于 $G$（它们夹在 $G$ 的两头牛之间，而 $G$ 在排列中是一段连续区间）。第 $t$ 趟的第一头牛属于 $G$，意味着第 $t$ 趟装载的牛全部属于 $G$（第 $t$ 趟的牛在排列中也是连续的一段，且起点在 $G$ 的区间内、终点在第 $t+1$ 趟第一头牛之前，仍在 $G$ 的区间内）。设第 $t+1$ 趟因牛 $c\in G$ 而开启，则开启条件是 $w+c>W$，其中 $w$ 是第 $t$ 趟载重。但第 $t$ 趟的牛与 $c$ 都是 $G$ 的成员，故 $w+c\le\mathrm{sum}(G)\le W$，矛盾。所以不同趟的第一头牛落在不同组，趟数 $k\le$ 组数 $r$。

综合：$\min_\pi k(\pi)\ge\min_{\text{分组}}r$（由 (a)，每个排列给出一个合法分组）；$\min_\pi k(\pi)\le\min_{\text{分组}}r$（由 (b)，取最优分组对应的排列）。两边夹得等号。证毕。

**这条引理把"无序的集合划分"归约成了"有序的排列扫描"**，后者才能做"逐头加入"的 DP。注意 (b) 里 $k$ 可以**严格小于** $r$（相邻两组若拼得下会被过程自动合并），这不影响取 min。

### 引理 2（单步转移 $T_c$ 对字典序单调）

设 $(k_1,w_1)\le_{\mathrm{lex}}(k_2,w_2)$，$c\in[1,W]$。则 $T_c(k_1,w_1)\le_{\mathrm{lex}}T_c(k_2,w_2)$。

*证明*：分两大情形。

**情形 A：$k_1<k_2$。** 转移使趟数至多 $+1$，故左边结果趟数 $\le k_1+1\le k_2\le$ 右边结果趟数。若左边趟数 $<$ 右边趟数，字典序已成立。若相等，则必 $k_1+1=k_2$ 且左边开了新趟（$w_1+c>W$，结果 $(k_2,c)$）、右边没开新趟（$w_2+c\le W$，结果 $(k_2,w_2+c)$）。此时 $c\le w_2+c$，第二分量也成立。

**情形 B：$k_1=k_2=k$，$w_1\le w_2$。** 按 $c$ 与两个载重的关系分三小类：
1. $w_2+c\le W$：则 $w_1+c\le w_2+c\le W$，两边都不开新趟，结果 $(k,w_1+c)\le_{\mathrm{lex}}(k,w_2+c)$ ✓。
2. $w_1+c\le W<w_2+c$：左边 $(k,w_1+c)$，右边 $(k+1,c)$，趟数 $k<k+1$ ✓。
3. $w_1+c>W$（从而 $w_2+c>W$）：两边都开新趟，结果都是 $(k+1,c)$，相等 ✓。

三小类穷尽（$w_1\le w_2$ 时不可能 $w_1+c>W\ge w_2+c$）。证毕。

**推论（min 与转移可交换）**：对任意有限状态集 $\mathcal S$，$\min_{\mathrm{lex}}\{T_c(s):s\in\mathcal S\}=T_c\bigl(\min_{\mathrm{lex}}\mathcal S\bigr)$。证明：设 $s^\*=\min\mathcal S$。对任意 $s\in\mathcal S$，由单调性 $T_c(s^\*)\le T_c(s)$，故 $T_c(s^\*)$ 是像集的下界；又 $T_c(s^\*)$ 本身在像集中，故它就是最小值。

**这就是"载重小永不劣"的严格版本**：剩余容量 $W-w$ 越大，未来任何加入序列的结果都不会更差——不是"大概率更好"，而是逐状态 domination。

---

### 引理 3（DP 不变量）

代码按 $S$ 从小到大计算 $\mathrm{dp}[S]$：$\mathrm{dp}[\varnothing]=(1,0)$；对 $S\ne\varnothing$，
$$\mathrm{dp}[S]=\min_{i\in S,\ \mathrm{lex}}\ T_{c_i}\bigl(\mathrm{dp}[S\setminus\{i\}]\bigr).$$
则对所有 $S$，$\mathrm{dp}[S]=\min_{\mathrm{lex}}\bigl\{\text{按 }\pi\text{ 顺序装载 }S\text{ 结束时的状态}:\pi\text{ 是 }S\text{ 的排列}\bigr\}$。

*证明*：对 $|S|$ 归纳。$|S|=0$：空排列结束状态 $(1,0)$ ✓。

设 $|S|=t\ge 1$ 且结论对一切更小的集合成立。$S$ 的任一排列 $\pi$ 可唯一写成"前缀 $\pi'$（$S\setminus\{i\}$ 的排列）+ 末尾牛 $i$"，结束状态为 $T_{c_i}(\text{状态}(\pi'))$。于是
$$\min_{\pi}\text{状态}(\pi)=\min_{i\in S}\ \min_{\pi'\text{ 是 }S\setminus\{i\}\text{ 的排列}}T_{c_i}(\text{状态}(\pi')).$$
由归纳假设，内层 $\pi'$ 的状态集的最小元是 $\mathrm{dp}[S\setminus\{i\}]$；由引理 2 的推论（$T_{c_i}$ 单调，min 可穿透），内层 min 等于 $T_{c_i}(\mathrm{dp}[S\setminus\{i\}])$。代回即得代码的转移式。

良定义性：$p=S\setminus\{i\}<S$（数值上），故按 $S$ 升序计算时 $\mathrm{dp}[p]$ 已就绪；又每头牛 $c_i\le W$，任何子集都可达，$\mathrm{dp}[p]$ 不会是哨兵 INF（代码仍显式 fill INF，防御"全局数组默认 0 被当成合法状态"的经典陷阱）。证毕。

---

### 引理 4（答案就是 $k[\text{全集}]$）

设 $\mathrm{dp}[\text{全集}]=(k^\*,w^\*)$。则原问题答案 $R=k^\*$。

*证明*：由引理 3，$(k^\*,w^\*)$ 是所有排列结束状态的字典序最小元，故 $k^\*=\min_\pi k(\pi)$（字典序最小必然第一分量最小：若某排列 $k<k^\*$，其状态字典序更小，矛盾）。由引理 1，$\min_\pi k(\pi)=R$。证毕。

注意 $w^\*$ 本身没有意义（最后一趟装了多少不影响答案），它只是"为了未来"而维护的辅助量；在全集处它完成了历史使命。

---

### 引理 5（复杂度与数值范围）

时间 $O(2^N N)$，空间 $O(2^N)$。所有量在 `int` 内安全。

*证明*：状态数 $2^N$，每个状态枚举 $N$ 个末尾牛，每次转移 $O(1)$，共 $N2^N\le 18\times 262144\approx 4.7\times 10^6$ 次基本操作。空间两个长度 $2^{18}$ 的 `int` 数组约 $2$ MB。数值：$k\le N\le 18$；$w\le W\le 10^8$；转移中 $w+c\le 2\times 10^8<2^{31}-1$；哨兵 $1145141919\approx 1.1\times 10^9$ 加上 $c$ 也不会溢出（且可达状态根本不会用到哨兵）。证毕。

---

### 定理

程序输出把所有牛送下楼的最少电梯次数，复杂度 $O(2^N N)$。

*证明*：引理 1 把集合划分问题归约为排列扫描问题；引理 2 证明"次数优先、载重次之"的字典序在转移下单调，从而局部取 min 不丢全局最优；引理 3 用归纳法证明 DP 恰好算出所有排列结束状态的字典序最小元；引理 4 把该最小元的第一分量与原题答案等同；引理 5 给出复杂度与数值安全性。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 剥掉故事：一维装箱最小化箱数；电梯次数只依赖分组、与顺序无关。
2. **consider easier version** — 先试最朴素的状压 $f[S]=$ 最少次数，发现转移需要"当前电梯载重"，状态有后效性。
3. **explore its property** — 手造反例 $\{6,5,4\}+5,W=10$：同次数下载重 9 与 5 导致后续 3 趟 vs 2 趟，确认必须记第二关键字。
4. **discuss by category** — 备选 $O(3^N)$ 枚举最后一趟子集，正确但 $3^{18}$ 太悬，放弃。
5. **reduce to easier problem** — 引理 1：无序分组 $\iff$ 有序排列的顺序装载（趟数取 min 相等），把划分问题变成可逐头 DP 的扫描问题。
6. **classic problem solution** — 二元组 $(k,w)$ 字典序状压 DP；核心是证明转移 $T_c$ 单调（引理 2），于是"同次数取最小载重"的贪心式压缩是无损的。
7. **explore its property** — 数值体检：$w+c\le 2\times 10^8$ 不爆 `int`；INF 显式 fill，防全局 0 陷阱。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 牛数 $N\le 18$ | `int` | 读入 |
| `W` | 电梯载重上限 $\le 10^8$ | `int` | 读入 |
| `c[i]` | 第 $i$ 头牛体重，0-based | `int[mxn]`，`mxn{20}` | 读入；保证 $\le W$ |
| `f[S]` | 送完集合 $S$ 的最少趟数 $k$ | `int[mxs]`，`mxs{(1<<18)+5}` | **fill INF**；`f[0]=1`（第一趟已开着） |
| `g[S]` | 在 `f[S]` 趟前提下当前趟的最小载重 $w$ | `int[mxs]` | **fill INF**；`g[0]=0`；记忆点：f=次数，g=当前载重 |
| `inf` | 哨兵 $1145141919$ | `constexpr int` | 显著大于任何合法 $(k,w)$ |
| `full` | 全集掩码 $(1\ll n)-1$ | `int` | 答案在 `f[full]` |
| `p` | 前驱状态 $S\oplus(1\ll i)$ | `int` | 枚举末尾牛 $i$ 时现算 |

### 算法步骤

1. I/O 加速三行；读 $N,W$ 与 $c_0..c_{N-1}$。
2. `f[0..full]`、`g[0..full]` 全部 fill 成 `inf`；置 `f[0]=1,g[0]=0`。
3. 对 $S=1..full$：枚举 $i\in[0,N)$ 且 $S$ 含 $i$；取 $p=S\oplus 2^i$；若 `g[p]+c[i]<=W` 候选 `(f[p],g[p]+c[i])`，否则候选 `(f[p]+1,c[i])`；按字典序更新 `(f[S],g[S])`。
4. 输出 `f[full]`。

### 复杂度

- 时间 $O(2^N N)\approx 4.7\times 10^6$；空间 $O(2^N)$，两个 `int` 数组约 $2$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；Hint 样例（4 头牛 5/6/3/7，W=10）输出 3；反例数据 6/5/4/5 输出 2；单牛、全满（10/10/10）等边界手算核对一致。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3052 [USACO12MAR] Cows in a Skyscraper G
// 状压 DP：dp[S]=(最少趟数, 该趟数下当前电梯最小载重)，字典序取 min。
// 正确性支柱：单步转移 T_c 对字典序单调 ⇒ 同次数下载重小者永不劣。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20},mxs{(1<<18)+5};
constexpr int inf{1145141919};

int n,W,c[mxn],f[mxs],g[mxs];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>W;
	for(int i=0;i<n;++i)
		cin>>c[i];
	int full=(1<<n)-1;
	fill_n(f,full+1,inf);	// 全局默认 0 不是 INF，必须显式填
	fill_n(g,full+1,inf);
	f[0]=1;g[0]=0;	// 空集：第一趟电梯已开着，载重 0
	for(int S=1;S<=full;++S)
		for(int i=0;i<n;++i)
			if(S>>i&1)
			{
				int p=S^(1<<i),nf,ng;
				if(g[p]+c[i]<=W)
					nf=f[p],ng=g[p]+c[i];	// 挤进当前趟
				else
					nf=f[p]+1,ng=c[i];	// 新开一趟
				if(nf<f[S]||(nf==f[S]&&ng<g[S]))
					f[S]=nf,g[S]=ng;
			}
	cout<<f[full]<<'\n';
	return 0;
}
```

### 代码说明

- `f[0]=1` 而不是 0：把"第一趟电梯已经开着"编码进初值，转移里就不必特判"当前趟是否存在"；答案直接读 `f[full]`，不用再加一。
- 字典序比较写成 `nf<f[S]||(nf==f[S]&&ng<g[S])`，先次数后载重，顺序不能反——载重小但次数多的状态绝不更优。
- `p=S^(1<<i)<S` 保证按掩码升序遍历时前驱已算好，无需记忆化搜索。
- `g[p]+c[i]` 最大 $2\times 10^8$，`int` 安全；若 $W$ 更大就要换 `i64`。
- 两个数组都显式 fill INF：虽然本题所有子集可达、哨兵实际不会被读到，但这是状压 DP 的肌肉记忆——漏填时 0 会被当成"0 趟 0 载重"的合法状态，静默出错。
