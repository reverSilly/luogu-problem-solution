# P3003 [USACO10DEC] Apple Delivery S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 一张 $P$ 个点（$1\le P\le 10^5$）、$C$ 条边（$1\le C\le 2\times10^5$）的**无向连通图**，边权 $D_i>0$ 且 $\sum D_i\le 2\times10^9$。给定三个**互不相同**的点：起点 $PB$、两个目标 $PA_1,PA_2$。Bessie 从 $PB$ 出发，要**按任意顺序**经过 $PA_1$ 和 $PA_2$（把两个苹果送到），送完即可停在任意点，求走过的**最小总距离**。

先把背景剥掉：这就是"从 $s$ 出发，必须访问两个指定点 $a,b$，顺序自选，求最短行走长度"。注意几个边界：

- 图**连通**，所以任意两点距离有限，不用担心无解。
- 边权为正，$\sum D_i\le 2\times10^9$ 保证**单条最短路** $\le 2\times10^9$，落在 `int` 范围（$2.1\times10^9$）内；但**答案**是两段最短路之和，可达 $4\times10^9$，**超 `int`**，必须用 `long long`。这是第一个坑。
- 输入第一行顺序是 $C,P,PB,PA_1,PA_2$——**边数在前、点数在后**，和常见的"先 $n$ 后 $m$"相反，读入时极易写反。这是第二个坑。
- 送完第二个苹果就结束，**不需要回到起点**，也不需要停在某个特定点。

**第一步：枚举访问顺序。** 只有两个目标，顺序只有两种：$PB\to PA_1\to PA_2$ 或 $PB\to PA_2\to PA_1$。对固定顺序，"从 $x$ 走到 $y$ 再走到 $z$"的最短长度是不是就是 $d(x,y)+d(y,z)$？直觉上是，但这里要警惕一个陷阱：**路径会不会重复走边、会不会有"顺路"的捷径？** 比如 $PB\to PA_1$ 的最短路恰好经过 $PA_2$，那是不是可以少走路？

我停下来想了想：即便 $PB\to PA_1$ 路上经过 $PA_2$，题目要求的是"访问两个点"，经过就算访问。但无论怎样，**任何一条合法行走路线**都可以被"第一次到达 $PA_1$"和"之后第一次到达 $PA_2$"这两个时刻切成三段（或两段），每一段的长度都 $\ge$ 对应两点的最短路。所以 $d(PB,PA_1)+d(PA_1,PA_2)$ 是"先 1 后 2"这个顺序的**下界**，而把两条最短路首尾拼接又能**取到**这个下界。于是固定顺序的最优值恰好是 $d(PB,PA_1)+d(PA_1,PA_2)$，"顺路"不会让它更小（下界已经卡死）。这一步在引理 1、2 里严格证。

**第二步：合并两种顺序。** 答案 $=\min\bigl(d(PB,PA_1)+d(PA_1,PA_2),\ d(PB,PA_2)+d(PA_2,PA_1)\bigr)$。无向图里 $d(PA_1,PA_2)=d(PA_2,PA_1)$，记为 $d_{12}$，提公因式：

$$\text{ans}=d_{12}+\min\bigl(d(PB,PA_1),\ d(PB,PA_2)\bigr).$$

**这一步是本题的思维跳跃**：原本以为要跑三次最短路（$PB,PA_1,PA_2$ 各一次），化简后发现只需要 $d_{12}$、$d(PB,PA_1)$、$d(PB,PA_2)$ 三个量。而 $d(PB,PA_1)=d(PA_1,PB)$、$d(PB,PA_2)=d(PA_2,PB)$，所以**只要从 $PA_1$ 和 $PA_2$ 各跑一次 Dijkstra**，就能一次性拿到全部三个量：

- 从 $PA_1$ 跑：得到 $d_1[PA_2]=d_{12}$ 和 $d_1[PB]=d(PA_1,PB)$。
- 从 $PA_2$ 跑：得到 $d_2[PB]=d(PA_2,PB)$。

答案 $=d_1[PA_2]+\min(d_1[PB],d_2[PB])$。**两次** Dijkstra 足矣，省掉一次。

**第三步：选最短路算法。** 边权为正、$P\le10^5,C\le2\times10^5$，堆优化 Dijkstra 是标准选择，单次 $O((P+C)\log P)$，两次约 $2\times(3\times10^5)\times17\approx10^7$，稳过。SPFA 最坏会被卡，BFS 只适用于无权图，Floyd 是 $O(P^3)$ 直接爆炸。所以堆优化 Dijkstra。

**第四步：几个必须抠清楚的实现细节。**

1. **`long long`。** 距离数组 `d1/d2` 用 `i64`，答案用 `i64`。虽然单源最短路 $\le2\times10^9$ 勉强进 `int`，但松弛时 `d+w` 的中间量、以及最终两段相加都可能超 `int`，统一 `i64` 最省心。哨兵 `inf` 取 `1145141919810`（约 $1.1\times10^{12}$），远大于任何真实距离又远小于 `i64` 上限，相加不溢出。
2. **链式前向星的 `H` 必须填 `-1`。** 全局 `int H[]` 默认是 $0$，而 $0$ 是**合法边编号**！若不显式 `fill_n(H,P,-1)`，每个点的邻接表头会错误地指向第 $0$ 条边，导致遍历错乱。这是风格指南里反复强调的"全局数组默认 0 不是哨兵"陷阱的图论版。
3. **无向图建双向边。** 每条输入边 `addedge(u,v,w)` 再 `addedge(v,u,w)`，`E` 数组开 `mxm*2`。
4. **两次 Dijkstra 之间重置 `vis`。** `vis` 标记"已确定最短路的点"，第二次跑必须 `fill_n(vis,P,false)`，否则所有点都被当成已访问，直接跳过。`dis` 数组每次也要重填 `inf`。
5. **0-based。** 读入 `b,a1,a2` 与每条边的 `u,v` 后立刻 `--`，内部全程 0-based，输出是距离数值不涉及下标还原。

**手造数据核对**（题面给了地图说明，我按图反推边表，再另造两组打卡顺序与"必须折返"）：

第一组，按题面地图（$P=7,C=9$，$PB=5,PA_1=1,PA_2=4$）：

## 二、思维链：完整证明

**记号。** 无向连通图 $G=(V,E)$，$|V|=P$，边权 $w(e)>0$。$d(x,y)$ 表示 $x$ 到 $y$ 的最短路长度（连通 ⇒ 有限）。起点 $s=PB$，两目标 $a=PA_1,b=PA_2$，三点互异。一条**合法路线**是从 $s$ 出发、依次经过 $a$ 与 $b$（顺序任意）的行走（walk，允许重复点边），其长度为所经边权之和。

---

### 引理 1（固定顺序的下界）

设合法路线 $W$ 的访问顺序为"先 $a$ 后 $b$"。则 $\mathrm{len}(W)\ge d(s,a)+d(a,b)$。

*证明*：在 $W$ 上取两个时刻：$t_1=$ 第一次到达 $a$ 的位置，$t_2=$ 在 $t_1$ 之后（含 $t_1$ 之后）第一次到达 $b$ 的位置。因为 $W$ 先访问 $a$ 再访问 $b$，且 $a\ne b$，故 $t_1<t_2$ 良定义。$W$ 被切成三段：

- $W_1$：从起点 $s$ 到 $t_1$（终点 $a$），是一条 $s\to a$ 的行走，$\mathrm{len}(W_1)\ge d(s,a)$（最短路是所有行走的最小值）。
- $W_2$：从 $t_1$（点 $a$）到 $t_2$（点 $b$），是一条 $a\to b$ 的行走，$\mathrm{len}(W_2)\ge d(a,b)$。
- $W_3$：从 $t_2$ 到路线终点，$\mathrm{len}(W_3)\ge 0$（边权正）。

三段长度之和 $=\mathrm{len}(W)$，故 $\mathrm{len}(W)\ge d(s,a)+d(a,b)+0$。证毕。

**关于"顺路"的澄清**：若 $W_1$ 在到达 $a$ 之前已经过 $b$，那访问顺序其实是"先 $b$ 后 $a$"，应归入另一种顺序讨论；本引理只处理"第一次到达 $a$ 早于第一次到达 $b$"的路线，切分点 $t_1,t_2$ 的选取保证了 $W_2$ 确实从 $a$ 走到 $b$。无论哪种顺序，下界论证都成立，不会因"顺路"而失效。

---

### 引理 2（固定顺序可达下界）

存在一条"先 $a$ 后 $b$"的合法路线，长度恰为 $d(s,a)+d(a,b)$。

*证明*：取 $s\to a$ 的一条最短路 $Q_1$（长度 $d(s,a)$）与 $a\to b$ 的一条最短路 $Q_2$（长度 $d(a,b)$）。把 $Q_2$ 接在 $Q_1$ 末尾（$Q_1$ 终点 $=Q_2$ 起点 $=a$），得到行走 $W=Q_1\cdot Q_2$。$W$ 从 $s$ 出发，在 $Q_1$ 末尾到达 $a$，在 $Q_2$ 末尾到达 $b$，是合法路线（先 $a$ 后 $b$）。$\mathrm{len}(W)=\mathrm{len}(Q_1)+\mathrm{len}(Q_2)=d(s,a)+d(a,b)$。即使 $Q_1,Q_2$ 共享边（重复走），行走长度仍是两者相加，定义允许重复。证毕。

**推论**：由引理 1、2，"先 $a$ 后 $b$"顺序的最优值 $=d(s,a)+d(a,b)$。同理"先 $b$ 后 $a$"顺序的最优值 $=d(s,b)+d(b,a)$。

---

### 引理 3（答案公式与两次 Dijkstra 的充分性）

最优答案 $\mathrm{ans}=d(a,b)+\min\bigl(d(s,a),d(s,b)\bigr)$，且只需从 $a$、$b$ 各跑一次单源最短路即可求得。

*证明*：合法路线必属两种顺序之一，故

$$\mathrm{ans}=\min\bigl(d(s,a)+d(a,b),\ d(s,b)+d(b,a)\bigr).$$

无向图最短路对称：$d(a,b)=d(b,a)$（任一条 $a\to b$ 路径反转即 $b\to a$ 路径，长度不变，故两者最小值相等）。代入并提取公因子 $d(a,b)$：

$$\mathrm{ans}=d(a,b)+\min\bigl(d(s,a),d(s,b)\bigr).$$

再用对称性 $d(s,a)=d(a,s)$、$d(s,b)=d(b,s)$。从 $a$ 跑单源最短路得数组 $d_1[\cdot]=d(a,\cdot)$，于是 $d_1[b]=d(a,b)$、$d_1[s]=d(a,s)=d(s,a)$；从 $b$ 跑得 $d_2[\cdot]=d(b,\cdot)$，于是 $d_2[s]=d(b,s)=d(s,b)$。三个所需量全部到手，无需从 $s$ 跑第三次。证毕。

---

### 引理 4（堆优化 Dijkstra 的正确性）

设边权非负，源点 $s$。算法维护 `dis[v]`（当前已知 $s\to v$ 最短路上界）与 `vis[v]`（是否已"定稿"）。每次从堆中取出 `dis` 最小且未定稿的点 $u$，置 `vis[u]=true`，并用 $u$ 松弛其邻边。则每次 $u$ 被定稿时 `dis[u]`$=d(s,u)$。

*证明*：对定稿顺序归纳。记第 $k$ 个定稿的点为 $u_k$，断言 `dis[u_k]`$=d(s,u_k)$ 且 `dis[u_k]` 随 $k$ 单调不减。

**基础**：第一个定稿的是 $s$（`dis[s]=0` 最小），$d(s,s)=0$ ✓。

**归纳**：设前 $k-1$ 个定稿点都已满足 `dis`$=d$。考虑第 $k$ 个取出的点 $u=u_k$，其堆键为 `dis[u]`。反设 `dis[u]`$>d(s,u)$。取一条 $s\to u$ 的真实最短路 $Q$。$Q$ 从已定稿的 $s$ 出发、到未定稿的 $u$ 结束，故 $Q$ 上存在第一条"离开已定稿集合"的边 $(x,y)$：$x$ 已定稿、$y$ 未定稿（$y$ 可能就是 $u$）。由归纳假设 `dis[x]`$=d(s,x)$，且 $x$ 定稿时已松弛过边 $(x,y)$，故

$$\texttt{dis}[y]\le \texttt{dis}[x]+w(x,y)=d(s,x)+w(x,y)=d(s,y)\le d(s,u),$$

最后一步因 $y$ 在 $s\to u$ 最短路 $Q$ 上、边权非负 ⇒ $d(s,y)\le d(s,u)$。又 `dis[u]`$>d(s,u)\ge$`dis[y]`，即未定稿点 $y$ 的 `dis` 严格小于 $u$ 的 `dis`。但算法取的是未定稿中 `dis` 最小者，应取 $y$ 而非 $u$，矛盾。故 `dis[u]`$=d(s,u)$。

单调性：第 $k$ 个取出的键 $\ge$ 第 $k-1$ 个取出的键（堆每次取最小，且松弛只把键变小、新入堆的键 $\ge$ 当前定稿键，因边权非负），故定稿键单调不减。证毕。

**推论**：所有点最终定稿（连通 + 每次至少定稿一个），`dis[v]`$=d(s,v)$ 对全部 $v$ 成立。两次调用分别以 $a,b$ 为源即得 $d_1,d_2$。

---

### 引理 5（数值范围与哨兵安全）

单源最短路 $d(x,y)\le\sum_e w(e)\le 2\times10^9$；答案 $\le 4\times10^9$，超 `int` 上限 $2147483647$，须用 `i64`。哨兵 `inf`$=1145141919810\approx1.15\times10^{12}$ 满足：真实距离 $<$ `inf`，且松弛中间量 `inf+w`（$w\le2\times10^9$）与答案 `inf+inf` 均 $<$ `i64` 上限 $9.2\times10^{18}$，不溢出。

*证明*：任一 $x\to y$ 路径是边集的子集（简单路径不含重复边），其长度 $\le$ 全图边权和 $\le2\times10^9$；最短路取最小，同样 $\le2\times10^9$。答案 $=d(a,b)+\min(\cdots)\le2\times10^9+2\times10^9=4\times10^9>2^{31}-1$，故 `int` 溢出，`i64` 必要。`inf`$\approx1.15\times10^{12}\gg2\times10^9$ 保证不可达态不会被误当真实距离；`inf+inf`$\approx2.3\times10^{12}\ll9.2\times10^{18}$，加法安全。证毕。

---

### 引理 6（复杂度）

单次堆优化 Dijkstra 时间 $O((P+C)\log P)$，两次共 $O((P+C)\log P)$；空间 $O(P+C)$。

*证明*：每个点最多定稿一次（`vis` 拦截重复），每次定稿遍历其邻边一次，总松弛次数 $O(C)$（无向图 $2C$ 条有向边）。每次成功松弛入堆一次，堆中元素 $O(C)$，每次入堆/出堆 $O(\log C)=O(\log P)$（$C\le2\times10^5< P^2$，$\log C=O(\log P)$）。故单次 $O((P+C)\log P)$。空间：`E` 存 $2C$ 条边 $O(C)$，`H/dis/vis` 各 $O(P)$，堆 $O(C)$。代入 $P=10^5,C=2\times10^5$：约 $2\times3\times10^5\times17\approx10^7$ 次基本操作，远低于时限。证毕。

---

### 定理

程序输出 $d(a,b)+\min(d(s,a),d(s,b))$，即 Bessie 送完两个苹果的最小总距离，复杂度 $O((P+C)\log P)$。

*证明*：引理 1、2 确定每种顺序的最优值；引理 3 合并两顺序得公式并证明两次 Dijkstra 充分；引理 4 保证 Dijkstra 求出的 $d_1,d_2$ 正确；引理 5 保证 `i64` 与哨兵不溢出、答案数值正确；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 剥掉送苹果背景：从 $s$ 出发访问两个指定点、顺序自选、不必返回的最短行走。
2. **discuss by category** — 只有两种访问顺序，分别求最优再取 min；警惕"顺路捷径"，用切分下界论证它不会更优。
3. **reduce to easier problem** — 固定顺序最优 $=d(s,a)+d(a,b)$（下界 + 拼接可达），把"行走"归约成"两段最短路之和"。
4. **explore its property** — 无向图 $d(a,b)=d(b,a)$，提公因式得 $\mathrm{ans}=d(a,b)+\min(d(s,a),d(s,b))$，发现只需两次单源最短路。
5. **classic problem solution** — 正权图单源最短路 ⇒ 堆优化 Dijkstra，从 $a,b$ 各跑一次拿全三个量。
6. **discuss by category** — 答案可达 $4\times10^9$ 超 int ⇒ `i64`；输入 $C$ 在前 $P$ 在后；前向星 `H` 填 $-1$；两次跑之间重置 `vis`/`dis`。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `C` | 边数，$\le2\times10^5$ | `int` | 读入（第一行第一个） |
| `P` | 点数，$\le10^5$ | `int` | 读入（第一行第二个） |
| `b,a1,a2` | 起点 $PB$、目标 $PA_1,PA_2$（0-based） | `int` | 读入后 `--` |
| `mxn` | $100000+5$ | `constexpr int` | 点数组尺寸 |
| `mxm` | $200000+5$ | `constexpr int` | 边数组尺寸（`E` 开 `mxm*2`） |
| `inf` | 距离哨兵 $\approx1.15\times10^{12}$ | `constexpr i64` | `1145141919810` |
| `H[u]` | 点 $u$ 邻接表头边编号 | `int[mxn]` | **`fill_n(H,P,-1)`**，$-1$ 表示空 |
| `E[i]` | 第 $i$ 条有向边 `{v,w,nx}` | 结构体 `[mxm*2]` | `cnt` 递增分配 |
| `cnt` | 已建边数 | `int` | 全局默认 $0$ |
| `d1[v]` | $d(a_1,v)$ | `i64[mxn]` | 每次 dij 重填 `inf` |
| `d2[v]` | $d(a_2,v)$ | `i64[mxn]` | 每次 dij 重填 `inf` |
| `vis[v]` | $v$ 最短路是否已定稿 | `bool[mxn]` | 每次 dij 重填 `false` |
| `dij(s,dis)` | 从 $s$ 跑堆优化 Dijkstra 写入 `dis` | `void(int,i64*)` | 惰性删除小根堆 |

### 算法步骤

1. I/O 加速三行。
2. 读 `C,P,b,a1,a2`，`--b;--a1;--a2`。
3. `fill_n(H,P,-1)`；读 $C$ 条边，每条 `--u;--v` 后 `addedge(u,v,w)` 与 `addedge(v,u,w)`。
4. `dij(a1,d1)`：得 $d_1[a_2]=d(a_1,a_2)$、$d_1[b]=d(a_1,b)$。
5. `dij(a2,d2)`：得 $d_2[b]=d(a_2,b)$。
6. 输出 `d1[a2]+min(d1[b],d2[b])`。

### 复杂度

- 时间：$O((P+C)\log P)$，两次 Dijkstra，约 $10^7$ 次操作。
- 空间：$O(P+C)$，`E` 约 $2C$ 条边、`H/d1/d2/vis` 各 $O(P)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；题面地图反推的 $7$ 点 $9$ 边数据输出 $12$ 与说明一致；另造三角形（输出 $2$）与链式折返（输出 $17$）两组手算数据全对。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3003 [USACO10DEC] Apple Delivery S
// 答案 = d(A1,A2) + min(d(B,A1), d(B,A2))，从 A1、A2 各跑一次 Dijkstra 即可
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005},mxm{200005};
constexpr i64 inf{1145141919810};

int C,P,b,a1,a2,cnt,H[mxn];
struct{int v,w,nx;}E[mxm*2];
i64 d1[mxn],d2[mxn];
bool vis[mxn];

void addedge(int u,int v,int w)
{
	E[cnt]={v,w,H[u]};H[u]=cnt++;
}

void dij(int s,i64*dis)
{
	fill_n(dis,P,inf);
	fill_n(vis,P,false);
	priority_queue<pair<i64,int>,vector<pair<i64,int>>,greater<>>Q;
	dis[s]=0;Q.emplace(0,s);
	while(!Q.empty())
	{
		auto[d,u]=Q.top();Q.pop();
		if(vis[u])
			continue;
		vis[u]=true;
		for(int i=H[u];i!=-1;i=E[i].nx)
		{
			int v=E[i].v;
			if(dis[v]>d+E[i].w)
			{
				dis[v]=d+E[i].w;
				Q.emplace(dis[v],v);
			}
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>C>>P>>b>>a1>>a2;--b;--a1;--a2;	// 注意输入顺序是 C 在前 P 在后
	fill_n(H,P,-1);	// H 必须填 -1：0 是合法边编号，全局默认 0 会静默出错
	for(int i=0,u,v,w;i<C;++i)
	{
		cin>>u>>v>>w;--u;--v;
		addedge(u,v,w);
		addedge(v,u,w);
	}
	dij(a1,d1);
	dij(a2,d2);
	cout<<d1[a2]+min(d1[b],d2[b])<<'\n';
	return 0;
}
```

### 代码说明

- **公式是灵魂**：`d1[a2]+min(d1[b],d2[b])` 一行就是引理 3 的答案。`d1` 从 $a_1$ 跑、`d2` 从 $a_2$ 跑，靠无向图对称性把"从 $s$ 到两目标"的距离转成"从两目标到 $s$"，省掉第三次 Dijkstra。
- **`i64` 不可省**：答案上界 $4\times10^9$ 超 `int`（引理 5）；`dis` 数组、`inf`、答案全程 `i64`。
- **`H` 填 `-1`**：链式前向星的空表头是 $-1$ 不是 $0$，全局默认 $0$ 会指向第 $0$ 条边造成错乱——这是图论版的"全局数组默认 0 不是哨兵"陷阱。
- **两次 dij 各自重置**：`fill_n(dis,P,inf)` 与 `fill_n(vis,P,false)` 写在 `dij` 内部，保证第二次跑不被第一次的 `vis` 污染。
- **惰性删除**：堆里可能有点的多个旧键，`if(vis[u])continue;` 跳过已定稿的过期条目，是堆优化 Dijkstra 的标准写法。
- 输入 `C>>P` 顺序与常见 `n>>m` 相反，读入后 `--b;--a1;--a2` 与每条边 `--u;--v` 转 0-based。
