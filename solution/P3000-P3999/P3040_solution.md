# P3040 [USACO12JAN] Bale Share S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** $n$ 包干草（$n\le20$），第 $i$ 包重 $s_i$（$1\le s_i\le100$）。把每包干草分给三个农场之一（农场可以空着），设三个农场总重为 $b_1,b_2,b_3$，要最小化 $\max(b_1,b_2,b_3)$。输出这个最小值。

**规模一眼定方向。** 总重 $S=\sum s_i\le20\times100=2000$。暴力枚举每包的去向是 $3^{20}\approx3.4\times10^9$，超时；但"总重只有 $2000$"强烈暗示**按重量做背包 DP**——状态空间由 $S$ 而不是 $n$ 的指数控制。答案有平凡下界 $\lceil S/3\rceil$（最大堆不小于平均），但**下界不一定可达**：$n=4$、四包各 $100$ 时 $S=400$、$\lceil400/3\rceil=134$，而任何分法都是 $(2,1,1)$ 堆，答案 $200$。所以不能只算下界，必须精确求可达状态。

**第一步：三维状态塌缩成二维。** 最自然的 DP 是 $f[i][a][b][c]$：前 $i$ 包、三农场各重 $a,b,c$ 是否可达。但 $a+b+c$ 恒等于前 $i$ 包的前缀和，**第三个坐标完全冗余**：$c=\text{prefix}_i-a-b$。于是状态只需 $(a,b)$，规模 $2001^2\approx4\times10^6$，转移 $3$ 选 $1$。这是本题第一个关键观察。

**第二步：滚动掉物品维。** 第 $i$ 包只影响第 $i$ 层，用二维表原地更新即可（01 背包套路）。转移：$(a,b)\to(a+s_i,b)$（给农场 1）、$(a,b)\to(a,b+s_i)$（给农场 2）、$(a,b)\to(a,b)$（给农场 3，**原地不动就是转移**）。

**第三步：bitset 压掉第二维。** 可达性是布尔量，$4\times10^6$ 个 `bool` 逐位转移约 $20\times4\times10^6=8\times10^7$ 次操作，能过但不够优雅。把第二维 $b$ 压进 `bitset<2005>`：`dp[a]` 的第 $b$ 位 = $(a,b)$ 可达。则"给农场 2"整行一次性完成：`dp[a]|=dp[a]<<s[i]`；"给农场 1"是行间 OR：`dp[a+s[i]]|=dp[a]`。复杂度除以 $64$，约 $10^6$ 字操作。

**第四步：原地更新会不会把同一包放两次？** 01 背包的经典答案是**倒序**。这里有两维，需要仔细核对（引理 2 给完整证明）：$a$ 从大到小扫，行内 `dp[a+s]|=dp[a]` 先做、`dp[a]|=dp[a]<<s` 后做。处理第 $a$ 行时，它还没被本轮碰过（能写它的只有第 $a-s$ 行，倒序下尚未处理），所以读到的 `dp[a]` 是"未放第 $i$ 包"的旧值；写入的目标行 $a+s>a$ 已处理完、不会再被当源读。每个状态恰好从旧状态转移一次，每包至多放一次。

**第五步：扫表取答案。** 全部放完后，对每个可达 $(a,b)$，三堆为 $(a,b,S-a-b)$，候选答案 $\max(a,b,S-a-b)$，取最小。只需扫 $a+b\le S$ 的三角区域，约 $2\times10^6$ 次位测试。

**手造数据核对**（题面只给样例解释，按解释反推第一组）：

第一组（样例解释反推：$n=8$，$s=(2,9,15,4,8,14,5,20)$）：解释给出分法 $\{2,9,15\}=26$、$\{4,8,14\}=26$、$\{5,20\}=25$，$S=77$，$\lceil77/3\rceil=26$，达到下界。程序输出 `26` ✓。

第二组（$n=1,s=(5)$）：只能 $(5,0,0)$，输出 `5` ✓。

第三组（$n=3,s=(1,1,1)$）：各放一包，输出 `1` ✓。

第四组（$n=2,s=(3,3)$）：$(3,3,0)$，输出 `3` ✓（空农场合法）。

第五组（$n=4,s=(100,100,100,100)$）：下界 $134$ 不可达，输出 `200` ✓。

## 二、思维链：完整证明

**记号。** 物品序 $s_0,\dots,s_{n-1}$，前缀和 $P_i=\sum_{t<i}s_t$（$P_0=0$，$P_n=S\le2000$）。$R_i\subseteq\mathbb Z_{\ge0}^2$ 为"前 $i$ 包分完后（农场 1 重，农场 2 重）"的可达对集合，农场 3 重由 $P_i-a-b$ 隐式给出。`dp[a]` 是 `bitset<2005>`，第 $b$ 位记 $(a,b)$ 可达。

### 引理 1（第三维冗余：二维状态充分）

前 $i$ 包的任一分配方案由 $(a,b)\in R_i$ 完全决定其三堆重量 $(a,b,P_i-a-b)$；且
$$R_0=\{(0,0)\},\qquad R_{i+1}=\{(a+s_i,b),(a,b+s_i),(a,b):(a,b)\in R_i\}.$$

*证明*：每包恰好进入一个农场，故三堆之和恒为 $P_i$，第三堆 $=P_i-a-b$，映射 $(a,b)\mapsto(a,b,P_i-a-b)$ 是单射，二维状态无信息损失。

递推：前 $i+1$ 包的方案 = 前 $i$ 包的方案 + 第 $i$ 包的去处（三选一）。去农场 1：$(a,b)\to(a+s_i,b)$；去农场 2：$(a,b)\to(a,b+s_i)$；去农场 3：$(a,b)$ 不变（第三堆隐式 $+s_i$）。三个像的并即 $R_{i+1}$；反之 $R_{i+1}$ 中任一元素按第 $i$ 包去处分类必来自某个 $R_i$ 元素，无遗漏无多余。对 $i$ 归纳即得递推式。证毕。

### 引理 2（bitset 倒序原地更新正确实现递推）

代码片段
```
for a=cur down to 0:
    dp[a+s]|=dp[a];
    dp[a]|=dp[a]<<s;
```
（`cur` 为本轮前的前缀和，`s=s[i]`）执行后，`dp` 恰表示 $R_{i+1}$，且每包至多被计入一次。

*证明*：设本轮开始前 `dp` 恰表示 $R_i$（归纳假设，初始 `dp[0][0]=1` 表示 $R_0$ ✓）。需证两点：**读旧**（每次作为源读取的 `dp[a]` 都是 $R_i$ 的第 $a$ 行）与**写全**（$R_{i+1}$ 的三个像都被写入）。

**读旧**：本轮中能修改第 $a$ 行的操作只有两种——处理第 $a-s$ 行时的 `dp[(a-s)+s]|=dp[a-s]`（写入第 $a$ 行），以及处理第 $a$ 行自身时的 `dp[a]|=dp[a]<<s`。$a$ 倒序枚举，$a-s<a$ 尚未处理，故开始处理第 $a$ 行时第 $a$ 行未被本轮修改，仍是 $R_i$ 的行。于是第一条 `dp[a+s]|=dp[a]` 读的是旧行 ✓；第一条写的是第 $a+s$ 行（$a+s\ne a$，因 $s\ge1$），不污染第 $a$ 行，第二条 `dp[a]|=dp[a]<<s` 读的仍是旧行 ✓。又写入目标行 $a+s>a$ 已处理完毕，之后不会再被当源读取（后续处理的行号 $<a<a+s$），故"旧值"不会被二次消费——每包至多放一次。

**写全**：对任意 $(a,b)\in R_i$（$a\le P_i=\text{cur}$，循环覆盖所有这样的行）：处理第 $a$ 行时，`dp[a+s]|=dp[a]` 把 $(a+s,b)$ 写入 ✓；`dp[a]|=dp[a]<<s` 把 $(a,b+s)$ 写入（左移 $s$ 位正是第二坐标 $+s$）✓；$(a,b)$ 本身保留（OR 不清位）✓。三个像全部落入 `dp`。反之本轮写入的每个位都来自某个旧行位，由上即 $R_{i+1}$ 的元素，无多余。

边界：$a+s\le P_i+s=P_{i+1}\le S\le2000<2005$，`dp[a+s]` 不越界；左移超出 $2004$ 的位被 `bitset` 自动丢弃，而那些位对应 $b+s>S$ 的不可能状态，丢弃无害。归纳完成。证毕。

### 引理 3（答案提取）

$\displaystyle\mathrm{ans}=\min_{(a,b)\in R_n}\max(a,b,S-a-b)$，且只需在 $a\ge0,b\ge0,a+b\le S$ 范围内扫描；初值 $\mathrm{ans}=S$ 合法。

*证明*：由引理 1，$n$ 包分配方案与 $R_n$ 中的 $(a,b)$ 一一对应（农场 3 重 $S-a-b$），方案的目标值就是 $\max(a,b,S-a-b)$，故最小值公式成立。可达对自动满足 $a+b\le P_n=S$（三堆非负），扫描范围 $b\le S-a$ 不漏解；范围外的 `dp` 位恒 $0$（引理 2 的转移保持 $a+b\le$ 前缀和），即使误扫也无害。初值：$(S,0)\in R_n$（全给农场 1，逐包走"农场 1"转移即达），对应目标值 $\max(S,0,0)=S$，故 $\mathrm{ans}=S$ 是一个可达上界，`min` 过程正确。证毕。

### 引理 4（下界与不可达例）

$\lceil S/3\rceil\le\mathrm{ans}\le S$；下界不一定取到：$n=4,s\equiv100$ 时 $\mathrm{ans}=200>134=\lceil400/3\rceil$。

*证明*：设三堆排序后 $b_1\ge b_2\ge b_3$，则 $3b_1\ge b_1+b_2+b_3=S\Rightarrow b_1\ge S/3$，整数性给出 $b_1\ge\lceil S/3\rceil$，对一切方案成立故对最优成立。上界：全放一堆得 $S$。反例：四包各 $100$，每堆是 $100$ 的整数倍，堆数 $3$、包数 $4$，由抽屉原理必有一堆 $\ge2$ 包即 $\ge200$；分法 $(2,1,1)$ 达到 $200$，故 $\mathrm{ans}=200$。证毕。

### 引理 5（复杂度）

时间 $O\bigl(n\cdot S\cdot\lceil S/64\rceil+S^2\bigr)$，空间 $O(S^2/8)$。代入 $S\le2000,n\le20$：位并行部分 $\le20\times2001\times32\approx1.3\times10^6$ 字操作，扫表 $\le(S+1)(S+2)/2\approx2\times10^6$ 次位测试；空间 $2005\times2005$ 位 $\approx0.5$ MB。

*证明*：每包一轮，每轮扫 $\text{cur}+1\le S+1$ 行，每行两次 `bitset` 运算（OR 与移位 OR），各 $O(\lceil S/64\rceil)$ 字操作。扫表双重循环 $a\in[0,S],b\in[0,S-a]$ 共 $(S+1)(S+2)/2$ 次 `dp[a][b]` 测试，每次 $O(1)$。空间为 `dp` 的 $2005$ 个 `bitset<2005>`，每个 $\lceil2005/64\rceil\times8=256$ 字节。证毕。

### 定理

程序输出 $\max(b_1,b_2,b_3)$ 的最小可能值，复杂度如引理 5。

*证明*：引理 1 证明二维可达集完整刻画所有分配；引理 2 证明 bitset 倒序更新精确实现可达集递推、无重复放置；引理 3 证明扫表公式即所求最优值；引理 4 给出答案的界与"下界不可达"的警示（说明必须精确 DP 而非公式）；引理 5 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 三堆之和恒为前缀和 ⇒ 第三维冗余，状态 $(a,b)$ 二维足够；$S\le2000$ 暗示按重量背包而非 $3^{20}$ 枚举。
2. **consider easier version** — 先想两组划分（子集和可达性），第三组当作"不选"，三组问题 = 二维 01 背包。
3. **classic problem solution** — 可行性背包 $R_{i+1}=R_i$ 的三个平移像之并，滚动掉物品维。
4. **classic problem solution** — `bitset` 压第二维：`dp[a]|=dp[a]<<s` 整行完成"给农场 2"，倒序行扫保证 01 性质（每包至多放一次）。
5. **reduce to easier problem** — 答案 = 扫可达表取 $\min\max(a,b,S-a-b)$，最优化塌缩成一次线性扫描。
6. **discuss by category** — 下界 $\lceil S/3\rceil$ 不一定可达（$100\times4\to200$）；空农场合法；$a+b\le S$ 三角扫描。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 干草包数 $\le20$ | `int` | 读入 |
| `s[i]` | 第 $i$ 包重量 $\le100$ | `int[25]` | 读入，0-based |
| `sum` | 总重 $S\le2000$ | `int` | 读入时累加 |
| `dp[a]` | 第二维压成 bitset：第 $b$ 位 = (农场1重$a$, 农场2重$b$) 可达 | `bitset<mxs>[mxs]` | 全局默认全 $0$，置 `dp[0][0]=1`；**农场3 = 前缀和$-a-b$，不占状态** |
| `cur` | 已处理包的前缀和（行扫描上界） | `int` | 初值 $0$，每轮 `+=s[i]` |
| `ans` | 最小的最大堆重 | `int` | 初值 `sum`（全放一堆的合法上界） |
| `mxs` | $2005$（$S$ 上界 $+5$） | `constexpr int` | bitset 宽度与行数 |

### 算法步骤

1. I/O 加速三行；读 `n` 与 `s[i]`，累加 `sum`。
2. `dp[0][0]=1`，`cur=0`。
3. 对每包 `s[i]`：`a` 从 `cur` 倒序到 $0$，先 `dp[a+s[i]]|=dp[a]`（给农场 1），再 `dp[a]|=dp[a]<<s[i]`（给农场 2；给农场 3 = 保留）；然后 `cur+=s[i]`。
4. `ans=sum`；对 `a=0..sum`、`b=0..sum-a`：若 `dp[a][b]`，则 `ans=min(ans,max({a,b,sum-a-b}))`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(nS^2/64+S^2)\approx1.3\times10^6$ 字操作 $+2\times10^6$ 位测试。
- 空间：$O(S^2/8)\approx0.5$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例解释反推数据输出 `26` ✓；`5`→`5`、`1 1 1`→`1`、`3 3`→`3`、`100×4`→`200` 均与手算一致 ✓；极限 $n=20$ 全 $100$ 输出 `700`（$7/7/6$ 堆，$\lceil2000/3\rceil=667$ 不可达，$700$ 正确）✓。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3040 [USACO12JAN] Bale Share S
// dp[a][b]=能否凑出农场1重a、农场2重b（农场3=前缀和-a-b）；bitset压第二维
#include<bits/stdc++.h>
using namespace std;

constexpr int mxs{2005};

int n,s[25],sum;
bitset<mxs>dp[mxs];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>s[i],sum+=s[i];
	dp[0][0]=1;
	int cur=0;
	for(int i=0;i<n;++i)
	{
		for(int a=cur;a>=0;--a)	// 倒序：读到的dp[a]仍是"未放第i包"的旧值
		{
			dp[a+s[i]]|=dp[a];		// 第i包给农场1
			dp[a]|=dp[a]<<s[i];		// 第i包给农场2；给农场3=原地保留
		}
		cur+=s[i];
	}
	int ans=sum;
	for(int a=0;a<=sum;++a)
		for(int b=0;b<=sum-a;++b)
			if(dp[a][b])
				ans=min(ans,max({a,b,sum-a-b}));
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **两条语句的顺序不能反**：先 `dp[a+s]|=dp[a]` 再 `dp[a]|=dp[a]<<s`。若先移位，`dp[a]` 已含"第 $i$ 包给了农场 2"的新状态，再 OR 进 `dp[a+s]` 就等于同一包既给农场 2 又给农场 1——重复放置。先 OR 后移位时，两条读的都是旧 `dp[a]`（引理 2）。
- **行倒序**是 01 性质的另一半保证：写入目标行 `a+s>a` 已处理完，不会再被当源读；正序会把刚写入的新状态再次转移，同一包放多次。
- `dp` 是可达性（布尔）表，全局默认 $0$ 恰好是"不可达"，**无需填 INF**——这与求最小值的 DP 相反，别混淆。
- `cur` 限制行扫描上界为当前前缀和，避免扫无效行；`a+s[i]≤sum≤2000<2005` 不越界。
- 扫表只走 `a+b≤sum` 三角区：可达态自动满足，`max({a,b,sum-a-b})` 用初始化列表一次取三堆最大。
- `ans` 初值 `sum` 是合法上界（全给农场 1），无需哨兵。
