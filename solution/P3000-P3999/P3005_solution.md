# P3005 [USACO10DEC] The Trough Game S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 个槽（$1\le N\le 20$），每个槽要么有食物（$1$）要么没有（$0$），真实状态是一个未知的 $01$ 向量 $x=(x_1,\dots,x_N)$。给出 $M$ 条询问（$1\le M\le 100$），第 $i$ 条是一个长度为 $N$ 的 $01$ 串 $S_i$（$1$ 表示"问到这个槽"）加一个整数 $t_i$，含义是

$$\sum_{j:\,S_i[j]=1} x_j = t_i,$$

即"被问到的槽里恰好有 $t_i$ 个有食物"。要求判定并输出：

- 没有任何 $x$ 满足全部询问 → `IMPOSSIBLE`；
- 满足的 $x$ 不止一个 → `NOT UNIQUE`；
- 恰好一个 → 输出那个 $01$ 串（顺序与输入串一致，第 $j$ 位对应第 $j$ 个槽）。

**边界先抠清楚**：$t_i$ 可以为 $0$（问到的全空）也可以等于子集大小（全满）；询问可以重复、可以互相矛盾；$N=1$ 也合法。输出串的位序必须和输入串一致——题面没有明说"第 1 位对应槽 1"，但输入串按槽编号顺序给出、样例解释也按此对应，这是唯一合理的口径。

**第一步：照着样例做逻辑推理，行不行？** 样例的解法是一条漂亮的推理链：问 1 说"槽 1 有 1 个食物"→ 槽 1 必满；问 3"槽 1、4 共 1 个"→ 槽 4 必空；问 4"槽 3、4 共 1 个"→ 槽 3 必满；问 2"槽 2、3 共 1 个"→ 槽 2 必空。这提示我写一个"传播器"：$t=0$ 推出子集全 $0$，$t=|S|$ 推出子集全 $1$，然后反复代入。

但我很快构造出传播器卡住的例子：$N=2$，唯一询问 `11 1`（两个槽里恰一个满）。没有任何单槽能被确定——传播器一步都走不动。而真实答案是"两个解"（`10` 和 `01`），应输出 `NOT UNIQUE`。再比如 $N=3$，询问 `110 1`、`011 1`、`101 1`：三式相加得 $2(x_1+x_2+x_3)=3$，左边偶右边奇，**无解**——传播器也看不出这种全局矛盾。**结论：局部传播不完备，一般情形必须搜索/枚举。**

**第二步：线性代数？域不对。** 看到"子集和 = 常数"，第一反应是高斯消元。但注意：这里的和是**整数加法**（$t$ 是计数），不是异或！如果询问给的是奇偶性（$t\bmod 2$），那才是 $\mathrm{GF}(2)$ 上的线性方程组，可以消元。现在 $x_j\in\{0,1\}$、方程是整数等式，这是 **0/1 整数线性方程组可行性**问题，一般情形 NP 难，没有多项式消元法。这条路也堵死。

**第三步：回头看数据范围——$N\le 20$ 就是答案。** 为什么出题人把 $N$ 卡在 $20$？因为 $2^{20}=1\,048\,576\approx10^6$：**全部可能的状态可以直接枚举**！对每个候选 $x$，逐条核对 $M\le100$ 个询问，总检查次数 $\le 2^{20}\times100\approx10^8$。每次检查若用"逐位扫 $N$ 位"要再乘 $20$，就是 $2\times10^9$，危险；所以必须把单次检查压到 $O(1)$。

**第四步：位压缩 + popcount 表，把检查压成 $O(1)$。** 两个标准动作：

1. 把每个询问串压成整数掩码 `msk[i]`（第 $j$ 位为 $1$ 表示问到槽 $j+1$）；候选状态直接用循环变量 `s`（$0$ 到 $2^N-1$）的二进制位表示。于是"被问到的槽里满的个数" $=\mathrm{popcount}(\texttt{s}\ \&\ \texttt{msk}[i])$，一次按位与搞定子集提取。
2. $\mathrm{popcount}$ 用**预处理表**：`pc[v]` 存 $16$ 位整数 $v$ 的 $1$ 个数，递推 `pc[v]=pc[v>>1]+(v&1)`。$20$ 位的 $x$ 拆成低 $16$ 位与高 $4$ 位两次查表相加。比 `__builtin_popcount` 更稳（不依赖编译器是否生成 `popcnt` 指令），两次访存 + 一次加法，常数极小。

这样总工作量 $\approx10^8$ 次"与 + 两次查表 + 加法 + 比较"，实测最坏数据（$99$ 条恒真询问 + $1$ 条强约束，逼着每个候选都扫满 $100$ 条）也在 $0.2$ 秒内跑完，稳过。

**第五步：只数到 2 就停。** 题目要区分的是"0 个 / 1 个 / ≥2 个"三档，**不需要知道解的确切总数**。所以找到第 $2$ 个合法状态就可以立刻 `break` 输出 `NOT UNIQUE`。这让"解很多"的数据（比如询问全是 `00…0 0` 这种恒真式）在枚举头两个候选后就结束，快得惊人；真正要扫满 $2^{20}$ 的只有"无解或唯一解"的数据。

**第六步：输出位序。** 候选 `s` 的第 $j$ 位对应输入串第 $j$ 位（槽 $j+1$），所以输出时从 $j=0$ 到 $N-1$ 逐位打印 `(ans>>j)&1`，**不能**按整数高位到低位打印，否则串会反过来。

**手造数据核对**（题面样例解释给了四条询问，我按解释反推输入；另造三组打三种输出分支）：

第一组，样例反推（$N=4,M=4$）：

```
输入：
4 4
1000 1
0110 1
1001 1
0011 1
输出：1010
```

与样例解释"槽 1 满、槽 4 空、槽 3 满、槽 2 空"逐位吻合，且唯一。

第二组，直接矛盾（$N=1$，问"槽 1 有 1 个"又问"槽 1 有 0 个"）：

```
输入：
1 2
1 1
1 0
输出：IMPOSSIBLE
```

第三组，传播器卡住的多解例（$N=2$，`11 1`）：

```
输出：NOT UNIQUE
```

第四组，全满唯一解（$N=3$，`111 3`）：

```
输出：111
```

四组恰好覆盖三种输出分支 + 全满边界。

## 二、思维链：完整证明

**记号。** 真实状态 $x\in\{0,1\}^N$。第 $i$ 条询问的子集 $S_i=\{j:S_i[j]=1\}$，约束 $C_i(x):\sum_{j\in S_i}x_j=t_i$。解集 $\mathcal X=\{x\in\{0,1\}^N:\forall i,\ C_i(x)\}$。候选整数 $s\in[0,2^N)$ 与向量按位对应：$x_j=(s\gg j)\,\&\,1$。掩码 $m_i=\sum_{j\in S_i}2^j$。

---

### 引理 1（位压缩把约束核对变成一次与 + 一次 popcount）

对任意候选 $s$ 与询问 $i$，$\mathrm{popcount}(s\ \&\ m_i)=\sum_{j\in S_i}x_j$，其中 $x_j$ 是 $s$ 的第 $j$ 位。

*证明*：按位与的定义：$(s\ \&\ m_i)$ 的第 $j$ 位 $=s$ 的第 $j$ 位 $\land$ $m_i$ 的第 $j$ 位。$m_i$ 的第 $j$ 位为 $1$ 当且仅当 $j\in S_i$（掩码构造方式）。故 $(s\ \&\ m_i)$ 的第 $j$ 位 $=x_j$（当 $j\in S_i$）或 $0$（当 $j\notin S_i$）。$\mathrm{popcount}$ 数的是 $1$ 位个数，即 $\sum_{j\in S_i}x_j$。证毕。

**推论**：`pc[(s&msk[i])&65535]+pc[(s&msk[i])>>16]==t[i]` 恰好判定 $C_i(x)$，前提是 `pc` 表正确（引理 2）。

---

### 引理 2（popcount 表的递推正确性）

定义 `pc[0]=0`，`pc[v]=pc[v>>1]+(v&1)`（$1\le v<2^{16}$）。则对所有 $v$，`pc[v]`$=\mathrm{popcount}(v)$。

*证明*：先证恒等式 $\mathrm{popcount}(v)=\mathrm{popcount}(\lfloor v/2\rfloor)+(v\bmod 2)$。$v$ 的二进制表示为 $b_kb_{k-1}\dots b_1b_0$，则 $\lfloor v/2\rfloor$ 的二进制是 $b_kb_{k-1}\dots b_1$（右移丢掉最低位），$v\bmod 2=b_0$。故 $\mathrm{popcount}(v)=\sum_{t=0}^k b_t=\bigl(\sum_{t=1}^k b_t\bigr)+b_0=\mathrm{popcount}(\lfloor v/2\rfloor)+(v\bmod 2)$。

再对 $v$ 强归纳：$v=0$ 时 $\mathrm{popcount}(0)=0=$`pc[0]` ✓。$v\ge1$ 时 $v\gg1=\lfloor v/2\rfloor<v$，由归纳假设 `pc[v>>1]`$=\mathrm{popcount}(\lfloor v/2\rfloor)$；`v&1`$=v\bmod 2$。代入恒等式即得 `pc[v]`$=\mathrm{popcount}(v)$。证毕。

**拆分正确性**：$s<2^{20}$、$m_i<2^{20}$ ⇒ $x=s\ \&\ m_i<2^{20}$。写 $x=2^{16}\cdot h+\ell$，$0\le\ell<2^{16}$、$0\le h<2^4$。$x$ 的低 $16$ 位就是 $\ell$、高位部分就是 $h$，二者无重叠位，故 $\mathrm{popcount}(x)=\mathrm{popcount}(\ell)+\mathrm{popcount}(h)=$`pc[x&65535]+pc[x>>16]`。两次查表都在 $[0,2^{16})$ 界内。证毕。

---

### 引理 3（枚举的完备性）

循环 `for(s=0;s<(1<<n);++s)` 恰好遍历 $\{0,1\}^N$ 中每个状态一次。

*证明*：映射 $s\mapsto(x_0,\dots,x_{N-1})$，$x_j=(s\gg j)\&1$ 是 $[0,2^N)$ 到 $\{0,1\}^N$ 的双射（二进制表示的存在唯一性：每个 $s$ 有唯一 $N$ 位二进制展开，每个 $01$ 向量按权展开还原唯一 $s$）。循环不重不漏地取遍 $[0,2^N)$，故取遍全部状态。证毕。

---

### 引理 4（提前退出的三档判定正确性）

设算法按引理 3 的顺序扫描，`cnt` 记录已发现的解数，发现第 $2$ 个解时立即 `break`。则：

(a) 输出 `IMPOSSIBLE` $\iff\mathcal X=\varnothing$；
(b) 输出 `NOT UNIQUE` $\iff|\mathcal X|\ge2$；
(c) 输出 $01$ 串 $\iff\mathcal X$ 恰含一个元素，且输出的就是它。

*证明*：循环不变量：每次迭代开始时，`cnt`$=\min(2,\ |\mathcal X\cap[0,s)|)$，且若 `cnt`$=1$ 则 `ans` 是 $[0,s)$ 中唯一解；若 `cnt`$\ge2$ 循环已终止。

**保持**：考察候选 $s$。由引理 1、2，内层核对通过 $\iff x(s)\in\mathcal X$。若不通过，`cnt` 不变，$s$ 前进，不变量保持。若通过：`cnt` 加 $1$、`ans=s`。若加完 `cnt`$=1$，则 $[0,s]$ 中恰一解且为 `ans` ✓；若加完 `cnt`$=2$，则 $|\mathcal X\cap[0,s]|\ge2$，`break`，此时全局 $|\mathcal X|\ge2$ ✓。

**终止分类**：
- 若循环自然结束（未 break），则扫完全部 $2^N$ 个候选，`cnt`$=\min(2,|\mathcal X|)$。`cnt==0` ⇒ $|\mathcal X|=0$，输出 `IMPOSSIBLE`，(a) ✓；`cnt==1` ⇒ $|\mathcal X|=1$，`ans` 是唯一解，输出其位串，(c) ✓。
- 若 break，则 `cnt`$=2$，$|\mathcal X|\ge2$，输出 `NOT UNIQUE`，(b) ✓。

反过来：$\mathcal X=\varnothing$ 时没有任何候选通过核对，不会 break，自然结束且 `cnt==0` ⇒ 必输出 `IMPOSSIBLE`；$|\mathcal X|\ge2$ 时设最小的两个解为 $s_1<s_2$，扫描到 $s_2$ 时 `cnt` 达到 $2$ 触发 break（或更早——不可能更早，因为 $s_2$ 之前只有 $s_1$ 一个解），必输出 `NOT UNIQUE`；$|\mathcal X|=1$ 时永远不会 break，自然结束 `cnt==1`，输出该解。三个方向都闭合。证毕。

---

### 引理 5（输出位序与输入一致）

输出循环 `for(j=0..N-1) cout<<((ans>>j)&1)` 打印的串，第 $j$ 位等于解向量 $x_j$，与输入询问串"第 $j$ 位对应槽 $j+1$"的约定一致。

*证明*：由引理 3 的对应关系，`ans` 的第 $j$ 位就是 $x_j$。输出按 $j$ 升序逐位打印，故输出串第 $j$ 位 $=x_j$。输入掩码构造时 `s[j]=='1' → msk|=1<<j`，用的正是同一对应。两者一致，串不会反转。证毕。

---

### 引理 6（复杂度）

时间 $O(2^{16}+2^N\cdot M)$，最坏 $\approx1.05\times10^8$ 次常数级检查；空间 $O(2^{16}+M+N)$。

*证明*：`pc` 表预处理 $2^{16}-1$ 次递推。主循环至多 $2^N$ 个候选，每个候选至多核对 $M$ 条询问（失败即 break，只会更少），每次核对是常数次位运算 + 两次查表 + 一次加法比较。故上界 $2^N\cdot M=2^{20}\times100\approx1.05\times10^8$。"解 ≥2"的数据在第二个解处终止，实际远小于上界；只有无解/唯一解数据可能扫满。空间：`pc` 表 $2^{16}$ 个 `int`（$256$ KB），询问数组 $O(M)$，其余 $O(N)$。证毕。

---

### 定理

程序对任意合法输入正确输出 `IMPOSSIBLE` / `NOT UNIQUE` / 唯一解 $01$ 串三档之一，时间 $O(2^{16}+2^N M)$、空间 $O(2^{16})$。

*证明*：引理 3 保证枚举不重不漏；引理 1、2 保证每个候选的核对与原始约束逐条等价；引理 4 保证三档判定与解集大小严格对应；引理 5 保证唯一解的输出位序正确；引理 6 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 把询问翻译成 0/1 向量的整数子集和约束 $\sum_{j\in S_i}x_j=t_i$；目标是解集的三档分类（0/1/≥2）。
2. **consider easier version** — 先试样例式的局部传播（$t=0$ 全空、$t=|S|$ 全满），构造 `11 1` 卡死例与奇偶矛盾例，证明传播不完备。
3. **classic problem solution** — 想用高斯消元，发现和是整数计数不是异或，域不对（0/1 整数可行性一般 NP 难），放弃。
4. **explore its property** — $N\le20$ 是题眼：$2^{20}\approx10^6$ 个状态可全枚举，问题归约为"枚举 + 快速核对"。
5. **reduce to easier problem** — 状态与询问都压成整数位掩码，子集和 $=\mathrm{popcount}(s\&m_i)$，单次核对 $O(1)$。
6. **classic problem solution** — $16$ 位 popcount 递推表 `pc[v]=pc[v>>1]+(v&1)`，$20$ 位拆两半查表，避免逐位扫与编译器指令差异。
7. **discuss by category** — 只区分 0/1/≥2 三档 ⇒ 数到第 $2$ 个解立即 break；输出按位升序打印保证与输入串同序。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,m` | 槽数 $\le20$、询问数 $\le100$ | `int` | 读入 |
| `msk[i]` | 第 $i$ 条询问的子集掩码（第 $j$ 位 ↔ 槽 $j+1$） | `int[mxm]` | 读串时逐位 `|=1<<j`，全局默认 $0$ |
| `t[i]` | 第 $i$ 条询问的答案（子集内满槽数） | `int[mxm]` | 读入 |
| `pc[v]` | $16$ 位整数 $v$ 的二进制 $1$ 个数 | `int[mxh]` | `pc[0]=0`（全局默认），`pc[v]=pc[v>>1]+(v&1)` |
| `s` | 当前候选状态（$0..2^N-1$，位 $j$ = 槽 $j+1$ 是否满） | `int` | 循环变量 |
| `cnt` | 已发现的解数（封顶 $2$） | `int` | 全局默认 $0$ |
| `ans` | 最近发现的解（`cnt==1` 时即唯一解） | `int` | 全局默认 $0$ |
| `mxh` | $2^{16}=65536$ | `constexpr int` | popcount 表尺寸 |

### 算法步骤

1. I/O 加速三行；递推 `pc[1..65535]`。
2. 读 `n,m`；每条询问读串与 `t[i]`，把串压成 `msk[i]`。
3. 枚举 `s=0..2^n-1`：对每条询问算 `x=s&msk[i]`，若 `pc[x&65535]+pc[x>>16]!=t[i]` 则该候选失败、break 内层。
4. 全部询问通过 ⇒ `++cnt; ans=s;`；`cnt>=2` 立即 break 外层。
5. `cnt==0` 输出 `IMPOSSIBLE`；`cnt>=2` 输出 `NOT UNIQUE`；否则按 $j=0..n-1$ 逐位输出 `(ans>>j)&1`。

### 复杂度

- 时间：$O(2^{16}+2^N\cdot M)$，最坏 $\approx10^8$ 次常数级核对；多解数据提前终止。
- 空间：$O(2^{16}+M)$，`pc` 表 $256$ KB 为主。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例反推数据输出 `1010` 与解释一致；矛盾（`IMPOSSIBLE`）、多解（`NOT UNIQUE`）、全满唯一解（`111`）三组手造数据全对；另构造 $N=20,M=100$ 的逼满扫描数据（$99$ 条恒真询问 + 唯一解 `000…0`）验证最坏分支输出正确。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3005 [USACO10DEC] The Trough Game S
// N<=20 ⇒ 枚举全部 2^N 个 01 状态，用 bitmask+popcount 表 O(1) 核对每条询问
// 只需区分 0/1/>=2 个解，找到第 2 个解立即退出
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25},mxm{105},mxh{65536};

int n,m,t[mxm],msk[mxm],pc[mxh];
int cnt,ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(int i=1;i<mxh;++i)
		pc[i]=pc[i>>1]+(i&1);	// pc[i]=i 的二进制 1 个数，pc[0]=0 靠全局默认
	cin>>n>>m;
	for(int i=0;i<m;++i)
	{
		string s;
		cin>>s>>t[i];
		for(int j=0;j<n;++j)
			if(s[j]=='1')
				msk[i]|=1<<j;	// 字符串第 j 位 ↔ 整数第 j 位，输出同序
	}
	for(int s=0;s<(1<<n);++s)
	{
		bool ok=true;
		for(int i=0;i<m;++i)
		{
			int x=s&msk[i];
			if(pc[x&65535]+pc[x>>16]!=t[i])
			{ok=false;break;}
		}
		if(ok)
		{
			++cnt;ans=s;
			if(cnt>=2)
				break;	// 已能断定 NOT UNIQUE，不必数完
		}
	}
	if(cnt==0)
		cout<<"IMPOSSIBLE\n";
	else if(cnt>=2)
		cout<<"NOT UNIQUE\n";
	else
	{
		for(int j=0;j<n;++j)
			cout<<((ans>>j)&1);
		cout<<'\n';
	}
	return 0;
}
```

### 代码说明

- **枚举即正解**：$N\le20$ 时 $2^{20}$ 个状态全枚举是出题人预设的路线；不要试图消元——约束是整数计数和，不是 $\mathrm{GF}(2)$ 异或方程。
- **`pc` 表拆半查**：$20$ 位的 `x` 拆成 `x&65535`（低 $16$ 位）与 `x>>16`（高 $4$ 位），两次查表相加。表只开 $2^{16}$，递推 $O(2^{16})$ 一次性完成；比逐位扫 $20$ 次快一个量级，也不依赖 `__builtin_popcount` 的指令生成。
- **数到 2 就停**：题目只要三档分类，`cnt>=2` 立即 break 是正确且关键的优化（引理 4）；`ans` 只在 `cnt==1` 时被输出，此时它就是唯一解。
- **位序一致**：输入串第 $j$ 位 ↔ 掩码第 $j$ 位 ↔ 输出第 $j$ 位，全程同一约定，输出按 $j$ 升序打印，串不会反转。
- `pc[0]=0`、`msk[i]=0`、`cnt=0` 都依赖全局零初始化，恰好正确；`t[i]` 越界（$<0$ 或 $>$ 子集大小）无需特判——枚举自然得出 $0$ 个解。
