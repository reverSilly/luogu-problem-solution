# P3056 [USACO12NOV] Clumsy Cows S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给一个只含 `(` 和 `)` 的字符串，长度 $n$ 为**偶数**，$n\le 10^5$。每次操作可以把一个字符反转（`(`↔`)`）。求最少反转多少次，使字符串变成"平衡括号串"：`(` 与 `)` 总数相等，且**每个前缀**里 `(` 不少于 `)`。输出一个整数。

**口径说明。** 题面保证长度为偶数，这一点至关重要：平衡串长度必为偶数，所以题目一定有解（最坏全反转成 `(((...)))` 的一半一半），不需要讨论无解。反转只改字符、不改长度、不改位置。

**第一步：把"平衡"翻译成前缀和语言。** 令 `(` 记 $+1$、`)` 记 $-1$，前缀和 $P_i=\sum_{j\le i}v_j$。平衡 $\iff P_n=0$ 且所有 $P_i\ge 0$。一次反转把某个位置的 $\pm1$ 变号，等价于：**把该位置之后的所有前缀和整体 $\pm2$**（`)`→`(` 是 $+2$，`(`→`)` 是 $-2$）。这个观察是整道题的支点：反转不是局部修补，而是对后缀前缀和的平移。

**第二步：先想"哪里必须修"。** 扫描时维护当前余额 `cnt`（已处理部分中未匹配的 `(` 数）。遇到 `(` 就 `++cnt`；遇到 `)` 且 `cnt>0` 就匹配掉（`--cnt`）；遇到 `)` 且 `cnt==0` 时，这个右括号**前面没有任何未匹配的左括号可配对**——它是一个"裸右括号"。直觉：这种位置不反转就不可能平衡，反转它（变成 `(`）是最便宜的救法：一次反转既消掉一个多余的 `)`，又制造一个可用的 `(`，对前缀和是 $+2$，一步到位。于是贪心：`cnt==0` 遇 `)` 就反转，`++ans,++cnt`。

**第三步：扫完之后还剩什么？** 扫描结束后 `cnt` 是"多出来的 `(`"的个数（所有能匹配的都已匹配）。因为 $n$ 是偶数、且扫描中的反转每次把前缀和改变 $2$，可以证明 `cnt` 一定是偶数（后面引理 3 严格证）。把其中 `cnt/2` 个 `(` 反转成 `)`，总数就配平了。为了不把前缀搞负，应该反转**最靠右**的那些 `(`——靠右的 `(` 只影响很短的后缀，破坏力最小。答案 $=$ 扫描中的强制反转数 $+$ `cnt/2`。

**第四步：贪心会不会错？两个怀疑点。**
1. "裸右括号处反转一个就够吗？会不会反转两个更好？"——不会：两个相邻裸右括号 `))` 只需反转第一个变成 `()`，第二个自动获得配对；贪心恰好就是这么做的（反转后 `cnt=1`，下一个 `)` 被匹配）。反转两个反而浪费。
2. "最后反转 `cnt/2` 个 `(`，会不会前面被迫多反转了？"——需要一个**下界证明**：任何合法方案的反转数都不少于贪心的反转数。思路是两条独立的约束：最深的前缀坑（ deficit）要求足够多的"正向反转"，而总数配平又把正向、反向反转的差钉死。两条约束联立，恰好解出贪心达到的那个数。这比"交换论证"更干净，第二部分照此写。

**手造数据核对**（题面 Hint 只有文字解释，没有给出样例串，全部手造）：

| 输入 | 手算过程 | 输出 |
|---|---|---|
| `()` | 一路匹配，cnt=0 | `0` |
| `)(` | 第 1 位裸 `)` 反转（ans=1,cnt=1），第 2 位 `(` cnt=2；末尾再反转 1 个 | `2` |
| `())(` | 第 3 位裸 `)` 反转（ans=1,cnt=1），第 4 位 `(` cnt=2；末尾 +1 | `2` |
| `))((` | 第 1 位反转(ans=1,cnt=1)，第 2 位匹配(cnt=0)，两个 `(` cnt=2；末尾 +1 | `2` |
| `))))` | 第 1、3 位反转，ans=2，cnt=0 | `2` |
| `((((` | cnt=4，末尾反转 2 个 | `2` |
| `((()))` | 完全平衡 | `0` |

注意 `)(` 的答案是 2 不是 1：只反转一个得到 `((` 或 `))`，都不平衡。这个例子专门检验"长度为偶数 $\Rightarrow$ 裸右括号数与多余左括号数同奇偶"的奇偶细节。

## 二、思维链：完整证明

**记号。** 串 $s_1..s_n$，$n$ 偶。$v_i=+1$（`(`）或 $-1$（`)`），前缀和 $P_i=\sum_{j\le i}v_j$，$P_0=0$。记
$$m=-\min_{0\le i\le n}P_i\ (\ge 0),\qquad d=P_n.$$
$d$ 是偶数（$n$ 偶，$P_n\equiv n\pmod 2$）。一个反转方案用 $(F^+,F^-)$ 描述：$F^+$ 是把 `)` 翻成 `(` 的位置集，$F^-$ 反之。方案合法 $\iff$ 翻转后的串平衡。

---

### 引理 1（反转对前缀和的作用）

在位置 $j$ 反转：若 $j\in F^+$，则所有 $i\ge j$ 的前缀和 $+2$，$i<j$ 不变；若 $j\in F^-$，则所有 $i\ge j$ 的前缀和 $-2$。从而翻转后的前缀和为
$$P'_i=P_i+2\bigl(|F^+\cap[1,i]|-|F^-\cap[1,i]|\bigr).$$

*证明*：$v_j$ 从 $-1$ 变 $+1$ 增 $2$（或反之减 $2$），前缀和 $P_i=\sum_{j\le i}v_j$ 中含 $v_j$ 当且仅当 $i\ge j$。各位置反转的效果线性叠加（每个 $v_j$ 至多被翻一次；翻两次等于没翻，最优方案不会这么做）。证毕。

---

### 引理 2（下界：任何合法方案至少 $\lceil m/2\rceil+\lceil (d+m)/2\rceil$ 次反转）

设方案合法，$f^+=|F^+|,f^-=|F^-|$。则总反转数
$$f^++f^-\ \ge\ 2\left\lceil\frac m2\right\rceil+\frac d2\ =\ \left\lceil\frac m2\right\rceil+\left\lceil\frac{d+m}2\right\rceil.$$

*证明*：两条约束。

**约束一（总数配平）**：$P'_n=0$。由引理 1，$0=d+2(f^+-f^-)$，故
$$f^+-f^-=-\frac d2\quad(\text{注意 }d\text{ 偶，右侧是整数}).$$

**约束二（填平最深的坑）**：取 $i^\*$ 使 $P_{i^\*}=-m$。要求 $P'_{i^\*}\ge 0$，即
$$-m+2\bigl(|F^+\cap[1,i^\*]|-|F^-\cap[1,i^\*]|\bigr)\ge 0\ \Rightarrow\ |F^+\cap[1,i^\*]|\ \ge\ \frac m2+|F^-\cap[1,i^\*]|\ \ge\ \frac m2.$$
左侧是整数，故 $f^+\ge|F^+\cap[1,i^\*]|\ge\lceil m/2\rceil$。

联立：$f^-=f^++d/2$，于是
$$f^++f^-=2f^++\frac d2\ \ge\ 2\left\lceil\frac m2\right\rceil+\frac d2.$$
最后验证两种写法相等：$m$ 偶时 $\lceil m/2\rceil=m/2$，且 $d+m$ 偶，$\lceil(d+m)/2\rceil=(d+m)/2$，两式都是 $m+d/2$；$m$ 奇时 $d+m$ 奇，两式都是 $m+1+d/2$。证毕。

**解读**：$m$ 就是"未匹配右括号数"（引理 4 证），$d+m$ 就是"未匹配左括号数"。下界 $=\lceil a/2\rceil+\lceil b/2\rceil$，正是经典公式。

---

### 引理 3（扫描贪心的精确刻画）

扫描算法：`cnt=0,ans=0`；遇 `(` 则 `++cnt`；遇 `)` 且 `cnt>0` 则 `--cnt`；遇 `)` 且 `cnt==0` 则 `++ans,++cnt`（记这次反转位置入 $F^+$）。设处理完前 $i$ 个字符后，$x_i$ 为已发生的强制反转数，$m_i=-\min_{0\le j\le i}P_j$（**原始**前缀和的坑深）。则不变量
$$x_i=\left\lceil\frac{m_i}2\right\rceil,\qquad \mathrm{cnt}_i=P_i+2x_i\ \ge 0$$
对所有 $i$ 成立。特别地，扫描结束时 $x_n=\lceil m/2\rceil$，$\mathrm{cnt}_n=d+2\lceil m/2\rceil$ 为偶数。

*证明*：对 $i$ 归纳。$i=0$：$x_0=0,m_0=0,\mathrm{cnt}_0=0$ ✓。注意 $\mathrm{cnt}_i=P_i+2\lceil m_i/2\rceil\in\{P_i+m_i,\ P_i+m_i+1\}$，而 $P_i\ge -m_i$，故 $\mathrm{cnt}_i\ge 0$ 自动成立；且
$$\mathrm{cnt}_i=0\iff m_i\text{ 偶且 }P_i=-m_i;\qquad \mathrm{cnt}_i=1\iff (m_i\text{ 奇},P_i=-m_i)\text{ 或 }(m_i\text{ 偶},P_i=-m_i+1).$$
设不变量对 $i-1$ 成立，看第 $i$ 个字符（以下 $P,m,\mathrm{cnt},x$ 均指 $i-1$ 时刻）：

1. **`(`**：$P_i=P+1>-m$，不产生新坑，$m_i=m$；$\mathrm{cnt}_i=\mathrm{cnt}+1=P_i+2x$ ✓，$x_i=x=\lceil m_i/2\rceil$ ✓。
2. **`)` 且 $\mathrm{cnt}>0$**：不反转，$x_i=x$。$P_i=P-1$。若 $P-1\ge -m$：$m_i=m$，$\lceil m_i/2\rceil=x$ ✓，$\mathrm{cnt}_i=\mathrm{cnt}-1=P_i+2x$ ✓。若 $P-1<-m$：只能 $P=-m$，此时 $\mathrm{cnt}>0$ 迫使 $m$ 奇（$\mathrm{cnt}=1$）；新坑 $m_i=m+1$（偶），$\lceil m_i/2\rceil=(m+1)/2=\lceil m/2\rceil=x$ ✓，$\mathrm{cnt}_i=0=P_i+2x$（$P_i=-(m+1)$，$2x=m+1$）✓。
3. **`)` 且 $\mathrm{cnt}=0$**：由上面的刻画，$m$ 偶、$P=-m$。反转：$x_i=x+1$，$P_i=P-1=-m-1$（原始前缀和照算），新坑 $m_i=m+1$（奇），$\lceil m_i/2\rceil=(m+2)/2=x+1=x_i$ ✓；$\mathrm{cnt}_i=\mathrm{cnt}+1=1$，而 $P_i+2x_i=-m-1+m+2=1$ ✓。

三类穷尽，归纳完成。结束时 $x_n=\lceil m/2\rceil$；$\mathrm{cnt}_n=d+2\lceil m/2\rceil$：$m$ 偶时 $=d+m$（偶+偶），$m$ 奇时 $=d+m+1$（偶+奇+1），皆偶。证毕。

---

### 引理 4（坑深 $m$ = 未匹配右括号数，$d+m$ = 未匹配左括号数）

用标准栈匹配（左括号入栈，右括号与栈顶配对，栈空时的右括号记为未匹配）扫描**原串**，设未匹配右括号数 $a$、未匹配左括号数 $b$。则 $a=m$，$b=d+m$。

*证明*：维护栈高 $h_i$ 与未匹配右括号计数 $u_i$。断言 $P_i=h_i-u_i$：每个入栈左括号贡献 $+1$，每次成功匹配净贡献 $0$（$+1-1$），每个未匹配右括号贡献 $-1$，逐字符累加即得。未匹配右括号恰在 $h=0$ 时遇到 `)` 发生，此时 $P$ 下降 $1$ 且 $u$ 增 $1$；其余时刻 $h\ge 0$ 故 $P_i=h_i-u_i\ge -u_i$，而每次未匹配事件后 $P=-u$ 恰好触底。所以 $\min P=-a$，即 $m=a$。又 $b=h_n=P_n+u_n=d+a=d+m$。证毕。

---

### 引理 5（收尾阶段可行：反转最靠右的 $\mathrm{cnt}_n/2$ 个 `(` 后串平衡）

设扫描（含强制反转）后的串为 $t$，其前缀和 $Q_i\ge 0$（引理 3 的 $\mathrm{cnt}_i$ 就是 $t$ 的前缀和），$Q_n=2k$（$k=\mathrm{cnt}_n/2$）。把 $t$ 中**最靠右**的 $k$ 个 `(` 反转成 `)`，所得串平衡。

*证明*：总数：$Q_n$ 从 $2k$ 减 $2k$ 变 $0$ ✓。前缀非负：设被反转的 `(` 位置为 $q_1<\dots<q_k$（它们是 $t$ 中最后 $k$ 个 `(`）。对任意前缀 $e$，设其中含 $j$ 个被反转位置（$0\le j\le k$），新前缀和 $=Q_e-2j$，需证 $Q_e\ge 2j$。$j=0$ 时显然。$j\ge 1$ 时 $e\ge q_j$，考察后缀 $(e,n]$：由于 $q_1..q_k$ 是**最后** $k$ 个 `(`，位置 $>q_j$ 的 `(` 全部在被反转集合里，故后缀中 `(` 的个数 $\le k-j$，从而后缀贡献
$$Q_n-Q_e=\#\text{后缀}(`(`)-\#\text{后缀}(`)`) \le k-j.$$
于是 $Q_e\ge 2k-(k-j)=k+j\ge 2j$（因 $j\le k$）✓。证毕。

（直观：越靠右的 `(`，反转它波及的前缀越少；而"最后 $k$ 个"保证任何前缀里被波及的个数 $j$ 都不超过它自身余额的一半。）

---

### 引理 6（贪心达到下界）

扫描贪心 + 引理 5 收尾的总反转数为
$$x_n+\frac{\mathrm{cnt}_n}2=\left\lceil\frac m2\right\rceil+\frac{d+2\lceil m/2\rceil}2=2\left\lceil\frac m2\right\rceil+\frac d2,$$
恰等于引理 2 的下界。

*证明*：代入引理 3 的 $x_n,\mathrm{cnt}_n$ 直接计算；与引理 2 右端逐项相同。证毕。

---

### 引理 7（复杂度）

时间 $O(n)$，额外空间 $O(1)$（不计输入串）。

*证明*：一次线性扫描，每字符 $O(1)$；收尾只需知道 $\mathrm{cnt}_n$，不必真的构造翻转后的串（题目只要次数）。计数器两个 `int`。$n\le 10^5$，远低于时限。证毕。

---

### 定理

程序输出的整数是最少反转次数。

*证明*：引理 1 给出反转的前缀和语义；引理 2 证明任何合法方案至少 $2\lceil m/2\rceil+d/2$ 次；引理 3 刻画扫描贪心恰好做 $\lceil m/2\rceil$ 次强制反转、留下偶数余额 $d+2\lceil m/2\rceil$；引理 5 证明再反转余额一半的靠右 `(` 确实得到平衡串（上界可达）；引理 6 核对上界 = 下界；引理 4 把公式翻译成经典的 $\lceil a/2\rceil+\lceil b/2\rceil$ 以便手算核对；引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 平衡 = 前缀和非负 + 总和为零；一次反转 = 对该位置之后的所有前缀和 $\pm2$。
2. **explore its property** — 扫描中 `cnt==0` 遇 `)` 是"裸右括号"，必须修；反转它一步 $+2$ 最划算。
3. **consider easier version** — 先只想"扫完剩多少多余左括号"，得到答案雏形：强制反转数 + 余额/2。
4. **explore its property** — 奇偶体检：$n$ 偶 $\Rightarrow$ 余额必偶（引理 3），`)(` 答案为 2 而非 1，专治"想当然除 2"。
5. **classic problem solution** — 下界双约束：最深坑 $m$ 逼出 $f^+\ge\lceil m/2\rceil$，总和配平钉死 $f^+-f^-=-d/2$，联立得 $2\lceil m/2\rceil+d/2$。
6. **reduce to easier problem** — 坑深 $m$ = 未匹配右括号数、$d+m$ = 未匹配左括号数，公式归约为经典 $\lceil a/2\rceil+\lceil b/2\rceil$。
7. **classic problem solution** — 收尾反转"最靠右的 $k$ 个左括号"保前缀非负（后缀计数论证），上界可达，夹住下界。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `s` | 输入括号串，长度偶 $\le 10^5$ | `char[mxn]`，`mxn{100005}` | `cin>>s` |
| `cnt` | 扫描余额：当前未匹配 `(` 数（含强制反转产生的） | `int` | 初值 0；恒 $\ge 0$，结束必偶 |
| `ans` | 扫描中的强制反转数 $x$（裸 `)` 翻成 `(`） | `int` | 初值 0；最终答案还要加 `cnt/2` |
| $P_i$ | 原始前缀和（`(`=+1,`)`=-1） | 证明用 | $P_0=0$ |
| $m$ | 坑深 $-\min P_i$ = 未匹配右括号数 | 证明用 | 代码不显式维护 |
| $d$ | $P_n$，偶数 | 证明用 | 同上 |

### 算法步骤

1. I/O 加速三行；读入串 `s`。
2. 线性扫描：`(` → `++cnt`；`)` 且 `cnt>0` → `--cnt`；`)` 且 `cnt==0` → `++ans,++cnt`。
3. 输出 `ans+cnt/2`。

### 复杂度

- 时间 $O(n)$；空间 $O(n)$ 存串（算法本身 $O(1)$）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；7 组手造数据（含 `)(`、`))((`、`))))`、`((((`、全平衡）与手算逐一吻合。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3056 [USACO12NOV] Clumsy Cows S
// 扫描：cnt==0 遇 ')' 强制反转（ans++,cnt++）；结束后余额必偶，再翻 cnt/2 个靠右 '('。
// 答案 = ceil(未匹配右括号/2) + ceil(未匹配左括号/2)，下界由"最深坑+总数配平"双约束给出。
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

char s[mxn];
int ans,cnt;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	for(int i=0;s[i];++i)
	{
		if(s[i]=='(')
			++cnt;
		else if(cnt)
			--cnt;
		else
			++ans,++cnt;	// 裸右括号：翻成 '('，一次反转对前缀和 +2
	}
	cout<<ans+cnt/2<<'\n';	// n 偶 ⇒ cnt 必偶，整除安全
	return 0;
}
```

### 代码说明

- 强制反转分支写 `++ans,++cnt`：反转后这个位置变成 `(`，所以余额是 $+1$ 而不是 $-1$——这正是"一次反转 $+2$"的落地。
- `cnt/2` 不需要真的去翻转字符：题目只问次数；引理 5 保证"翻最靠右的 `cnt/2` 个 `(`"这步在计数上总是可行且最优。
- 奇偶是本题唯一的暗坑：若长度为奇数，`cnt` 可能为奇数，`cnt/2` 会向下取整出错——题面保证偶数，代码才敢直接整除。
- 全程没有栈数组：余额 `cnt` 就是栈高的压缩表示，空间 $O(1)$。
