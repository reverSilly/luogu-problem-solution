# P3015 [USACO11FEB] Best Parenthesis S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 给一个长度为 $n$（$2\le n\le 10^5$）的括号串，得分规则是三条：

- 空括号对 `()` 得 $1$ 分；
- 并列（互不包含）的两段 $A,B$：得分相加，$\mathrm{score}(AB)=\mathrm{score}(A)+\mathrm{score}(B)$；
- 包裹：$\mathrm{score}((A))=2\cdot\mathrm{score}(A)$。

输入格式很特别：第一行 $n$，接下来 $n$ 行每行一个数字，$0$ 表示 `(`，$1$ 表示 `)`。输出得分对 $12345678910$ 取模的结果。

**先写明两个口径**（题面有歧义处）：

1. **合法性**：题面只说"只包含左右括号的字符串"，没明说保证合法。但三条得分规则只对**合法括号序列**（任意前缀左括号不少于右括号、总数相等）有定义——非法串根本无法按规则打分。故按"输入保证是合法括号序列"解读（这也是 USACO 原题的设定），$n$ 必为偶数。
2. **模数**：$p=12345678910\approx1.23\times10^{10}$ **超 `int`**（$2.1\times10^9$），所有涉及取模的量必须 `long long`。它不是质数，但本题只做加法和乘 $2$，不需要逆元，非质数无影响。

**第一步：顺着规则写栈模拟。** 规则是递归的，最自然的实现是栈：遇 `(` 压入一个"待累加的内部得分"；遇 `)` 弹出栈顶 $v$，这一对的得分是"内部为空则 $1$，否则 $2v$"，再把它加进新的栈顶（外层括号的累加器）或总答案。逻辑上完全对。

**但这里藏着一个取模特有的坑**：怎么判断"内部为空"？常见偷懒写法是把压入的累加器初值设为 $0$，弹出时看到 $0$ 就认为是空串、得 $1$ 分。问题是——**取了模之后，非空内部的得分也可能恰好 $\equiv0\pmod p$**！这时 $0$ 既可能是"真空串"也可能是"得分模成 $0$ 的非空串"，两者被混淆，答案就错了。

我认真验证了这个坑是不是"理论上存在、数据里碰不到"：得分其实是若干个 $2$ 的幂之和（下面会证），而 $p=12345678910$ 本身是偶数，把 $p$ 写成二进制（$p=\sum 2^{e_i}$），再构造一个括号串，让它的每个空括号对恰好落在深度 $e_i+1$ 上，得分就恰为 $p\equiv0$。$p<2^{34}$，所需深度 $\le34$、串长不过两千多，**完全在 $n\le10^5$ 范围内可构造**。所以这不是杞人忧天，是实打实的反例。要用栈就得额外记"有没有孩子"（计数器或 $-1$ 标记），不能拿 $0$ 当标记。

**第二步：与其修补栈，不如把递归展开。** 我盯着三条规则看：$1$ 分只从 `()` 产生；并列是加法；包裹是乘 $2$。把一条得分 recursively 展开到底，每个 `()` 叶子贡献的 $1$ 分会被它外面的每一层包裹翻一倍。于是猜：

$$\mathrm{score}(S)=\sum_{\text{每个空括号对 }()}\ 2^{\,\mathrm{depth}-1},$$

其中 depth 是这个 `()` 所在的嵌套深度（最外层为 $1$）。验证几个小例子：`(())` 只有一个叶子、深度 $2$ → $2^1=2$ ✓；`()()` 两个叶子、深度都是 $1$ → $1+1=2$ ✓；`(()())` 两个叶子、深度都是 $2$ → $2+2=4$，而按规则 $2\times(1+1)=4$ ✓。猜想成立（引理 3 用结构归纳严格证）。

**这一步是本题真正的思维跳跃**：得分不再需要"自底向上合并"，而是**每个叶子独立贡献一个 $2$ 的幂**，彼此只通过深度耦合。于是整个计算塌缩成一遍扫描。

**第三步：一遍扫描怎么写。** 维护当前深度 `dep`：遇 `(` 加 $1$，遇 `)` 减 $1$。怎么识别叶子？**一个 `(` 的下一个字符紧跟 `)`，它就是空括号对**——即输入里相邻的 `0 1`。在位置 $i$ 遇到 `0` 且 $a[i+1]=1$ 时，`dep` 刚加完 $1$，正是这个叶子的深度，把预处理的 `pw[dep-1]`（$2^{dep-1}\bmod p$）累进答案。每个叶子在其**左括号处**被恰好计数一次，右括号处只做 `--dep`，不重复计。

预处理 `pw[0]=1, pw[i]=pw[i-1]*2%p` 到 $n$ 即可（深度 $\le n/2$）。全程只有加法、乘 $2$、取模，`i64` 下中间量 $\le2p\approx2.5\times10^{10}$，离 `i64` 上限十万八千里。**没有栈、没有"空串标记"，第一步的坑被彻底绕开**——因为公式里根本不需要判断"内部是否为空"，只需要数叶子和深度。

**第四步：边界核对。** 深度最大 $n/2=50000$，`pw` 开到 `mxn=100005` 绰绰有余；`dep-1` 最小 $0$（最外层叶子），`pw[0]=1` 正确；$n=2$ 的最短串 `()` 输出 $1$。答案可能巨大（$2^{49999}$ 量级），但全程取模，输出的是模后值。

**手造数据核对**（题面 Hint 说样例串是 `(())()`，我按输入格式展开；另造四组打规则与取模）：

## 二、思维链：完整证明

**记号。** 合法括号序列集合 $\mathcal B$ 由三条生成规则归纳定义：$()\in\mathcal B$；$A,B\in\mathcal B\Rightarrow AB\in\mathcal B$；$A\in\mathcal B\Rightarrow(A)\in\mathcal B$。得分函数 $\mathrm{score}:\mathcal B\to\mathbb Z_{\ge0}$：$\mathrm{score}(())=1$，$\mathrm{score}(AB)=\mathrm{score}(A)+\mathrm{score}(B)$，$\mathrm{score}((A))=2\,\mathrm{score}(A)$。深度：字符的嵌套深度 = 它之前（含自身的左括号）未匹配的左括号数；一个 `()` 对的深度 = 其左括号的深度。$p=12345678910$。

---

### 引理 1（合法序列的唯一分解）

每个非空 $S\in\mathcal B$ 恰属于以下三类之一，且分解唯一：

(a) $S=()$；
(b) $S=(A)$，$A\in\mathcal B$ 非空；
(c) $S=AB$，$A,B\in\mathcal B$ 均非空，且 $A$ 是 $S$ 的**最短非空合法前缀**。

*证明*：定义前缀深度 $d_k=$ 前 $k$ 个字符中 `(` 数减 `)` 数。合法性即 $d_k\ge0$ 对所有 $k$、$d_{|S|}=0$。设 $t$ 为最小的 $k\ge1$ 使 $d_k=0$（存在，因 $d_{|S|}=0$）。

**存在性**：若 $t=2$，则前两字符必为 `()`（$d_1\ge0$ 且首字符只能是 `(`，$d_2=0$ 要求第二字符是 `)`）。此时若 $|S|=2$ 属 (a)；否则 $S=()\cdot S'$，$S'$ 是剩余部分，其前缀深度 = 原深度平移，仍合法，属 (c)。若 $t>2$，则首字符 `(`、末位（第 $t$ 位）`)`，且中间 $d_k>0$（$1\le k<t$ 时 $d_k\ne0$ 且 $\ge0$），故 $S[2..t-1]$ 的前缀深度 = $d_k-1\ge0$、末尾 $d_{t-1}-1=0$，是合法串 $A$；于是 $S[1..t]=(A)$。若 $t=|S|$ 属 (b)，否则属 (c)。

**唯一性**：(a)(b) 与 (c) 互斥——(a)(b) 的最短零深度前缀就是整个串（$t=|S|$），(c) 要求 $t<|S|$。(a) 与 (b) 按长度 $2$ 与否互斥。(c) 中 $A$ 必须是前 $t$ 个字符（任何合法前缀的末尾深度为 $0$，最短者唯一确定为 $t$），$B$ 随之唯一。证毕。

**推论**：$\mathrm{score}$ 沿唯一分解递归计算是良定义的（不依赖分解方式），且可对 $|S|$ 做结构归纳。

---

### 引理 2（"0 当空串标记"的栈写法不健全：可构造反例）

存在合法括号串 $S$，$|S|\le10^5$，其某个**非空**子序列的得分 $\equiv0\pmod p$。因此"弹出累加器为 $0$ 即视为空串"的栈实现会把非空内部误判为空、输出错误。

*证明*：先指出得分的结构（详细公式见引理 3，此处只用其显然推论）：任何得分都是若干个 $2$ 的非负整数幂之和（叶子贡献 $2^{\mathrm{depth}-1}$，深度 $\ge1$）。反之，**任何**正整数 $M$ 都能写成 $2$ 的幂之和（二进制展开 $M=\sum 2^{e_i}$），而每个 $2^{e_i}$ 可由一个深度 $e_i+1$ 的叶子实现。

取 $M=p=12345678910$。$2^{33}=8589934592\le p<2^{34}=17179869184$，故 $p$ 的二进制展开最高位 $e_{\max}=33$，所需最大深度 $34$。构造"毛毛虫"串：沿一条主脊柱嵌套到深度 $34$，在深度 $e_i+1$ 处各挂一个叶子 `()`（同一深度需要多个叶子时就并列挂多个）。串长 $\le2\times34+2\times(\text{叶子数})\le2\times34+2\times34=136\ll10^5$（叶子数 $\le$ 二进制位数 $\le34$）。该串合法，得分恰为 $p\equiv0\pmod p$，但其内部显然非空。

于是"累加器 $=0$"与"内部为空"不等价：前者还包含"得分模成 $0$ 的非空内部"。用 $0$ 当空串标记的栈实现在此输入上会把某个包裹层的得分错算成 $1$ 而非 $2\times0=0$，结果错误。证毕。

**对策**：要么栈里额外记孩子个数（或用 $-1$ 之类不可能与合法得分混淆的标记），要么干脆用引理 3 的叶子公式绕开"判空"需求。本文选后者。

---

### 引理 3（叶子展开公式）

对任意 $S\in\mathcal B$，设其全部空括号对（叶子）为 $\ell_1,\dots,\ell_k$，深度分别为 $d_1,\dots,d_k$，则

$$\mathrm{score}(S)=\sum_{j=1}^k 2^{d_j-1}.$$

*证明*：对 $|S|$ 结构归纳（引理 1 保证分解唯一、归纳合法）。

**基础 (a)**：$S=()$，唯一叶子深度 $1$，公式给 $2^0=1=\mathrm{score}(())$ ✓。

**归纳 (b)**：$S=(A)$，$A$ 非空。$S$ 的叶子与 $A$ 的叶子一一对应（包裹不产生新叶子），每个深度加 $1$：$d_j'=d_j+1$。由归纳假设 $\mathrm{score}(A)=\sum 2^{d_j-1}$，故

$$\mathrm{score}(S)=2\,\mathrm{score}(A)=2\sum_j 2^{d_j-1}=\sum_j 2^{d_j}=\sum_j 2^{d_j'-1}\ ✓.$$

**归纳 (c)**：$S=AB$。$S$ 的叶子是 $A$ 的叶子与 $B$ 的叶子的不交并（并列不改变任何叶子的深度，$A,B$ 处于同一外层深度）。由归纳假设与加法规则：

$$\mathrm{score}(S)=\mathrm{score}(A)+\mathrm{score}(B)=\sum_{\ell\in A}2^{d_\ell-1}+\sum_{\ell\in B}2^{d_\ell-1}=\sum_{\ell\in S}2^{d_\ell-1}\ ✓.$$

三类穷尽（引理 1），归纳闭合。证毕。

---

### 引理 4（扫描算法正确计数每个叶子恰好一次、深度正确）

设输入数组 $a[0..n-1]$（$0=$`(`，$1=$`)`）合法。算法：`dep` 初值 $0$；对每个 $i$，若 $a[i]=0$ 则 `++dep`，且若 $i+1<n$ 且 $a[i+1]=1$ 则 `ans+=pw[dep-1]`；若 $a[i]=1$ 则 `--dep`。则每次累加恰对应一个叶子，指数 `dep-1` 恰为该叶子深度减 $1$，且每个叶子被累加一次。

*证明*：**深度不变量**：处理完位置 $i$ 后，`dep`$=d_{i+1}$（前 $i+1$ 个字符的前缀深度）。归纳：初始 $d_0=0=$`dep`；遇 `(` 深度加 $1$、遇 `)` 深度减 $1$，与 $d$ 的递推逐字一致。

**叶子识别**：一个 `()` 对是叶子 $\iff$ 其内部为空 $\iff$ 左括号与右括号相邻 $\iff$ 存在 $i$ 使 $a[i]=0,a[i+1]=1$。合法串中每个 `(` 恰匹配一个 `)`，相邻的 `0 1` 必然互为匹配（中间无字符可插），故"相邻 `0 1`"与"叶子"一一对应。

**计数位置与深度**：叶子在其左括号位置 $i$ 被检测到，此刻 `dep` 刚执行 `++dep`，由不变量 `dep`$=d_{i+1}=$ 该左括号的深度 $=$ 叶子深度 $d$。累加项 `pw[dep-1]`$=2^{d-1}\bmod p$（引理 5），正是引理 3 中该叶子的贡献。右括号位置 $i+1$ 处 $a[i+1]=1$ 走 `--dep` 分支，不再累加；其他位置不满足"相邻 `0 1`"，不累加。故每个叶子恰好贡献一次、指数正确。

**求和**：由引理 3，$\mathrm{score}(S)=\sum_{\text{叶子}}2^{d-1}$；算法把每项模 $p$ 后累加再模 $p$，由模加法同态 $(\sum x_j)\bmod p=(\sum(x_j\bmod p))\bmod p$，最终 `ans`$=\mathrm{score}(S)\bmod p$。证毕。

---

### 引理 5（幂表与数值范围）

`pw[0]=1`，`pw[i]=pw[i-1]*2%p` ⇒ `pw[i]`$=2^i\bmod p$。全程 `i64` 下所有中间量 $\le2p<2.5\times10^{10}$，不溢出；深度 $\le n/2\le50000<$ `mxn`，数组不越界。

*证明*：幂表归纳：$i=0$ 时 $2^0\bmod p=1=$`pw[0]` ✓；设 `pw[i-1]`$=2^{i-1}\bmod p$，则 `pw[i-1]*2`$\equiv2^i\pmod p$，再 `%p` 得 $2^i\bmod p$ ✓。

范围：`pw[i]`$\in[0,p)$，`pw[i-1]*2`$<2p\approx2.47\times10^{10}$；`ans+pw[dep-1]`$<2p$ 同界；均 $\ll$ `i64` 上限 $9.2\times10^{18}$。$p>2^{31}-1$ 故必须 `i64`（`int` 会在存 $p$ 本身就溢出）。深度：合法串任意前缀 `(` 数 $\le n/2$（每个 `(` 都要一个 `)` 配对），故 `dep`$\le n/2\le50000$，`pw[dep-1]` 下标 $\le49999<$`mxn`$=100005$；幂表预处理到 $n$ 覆盖所有可能指数。证毕。

---

### 引理 6（复杂度）

时间 $O(n)$，空间 $O(n)$。

*证明*：读入 $n$ 个数 $O(n)$；幂表递推 $n$ 次 $O(n)$；扫描 $n$ 个位置、每位置常数次操作 $O(n)$。空间：`a` 与 `pw` 各 $O(n)$ 个元素（`pw` 为 `i64`，$10^5\times8=0.8$ MB）。证毕。

---

### 定理

程序对任意合法输入输出 $\mathrm{score}(S)\bmod12345678910$，时间 $O(n)$、空间 $O(n)$。

*证明*：引理 1 保证得分良定义、可结构归纳；引理 3 把得分展开为叶子的 $2$ 的幂之和；引理 4 保证扫描恰好按正确深度计数每个叶子一次；引理 5 保证幂表与取模在 `i64` 下精确无溢出；引理 6 给出复杂度。引理 2 说明为何不采用"0 标记"栈而选择叶子公式——后者从根上消除了判空歧义。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 三条得分规则是递归结构：`()`=1、并列相加、包裹乘 2；输入是 $n$ 行 0/1，模数 $12345678910$ 超 int 须 i64。
2. **classic problem solution** — 顺规则写栈模拟；发现"累加器 0 当空串标记"在取模下不健全。
3. **explore its property** — 构造反例证明坑真实存在：得分是 2 的幂之和，$p$ 本身可按二进制构造成合法串的非空内部得分 $\equiv0$。
4. **reduce to easier problem** — 把递归展开：$\mathrm{score}=\sum_{\text{叶子}()}2^{\mathrm{depth}-1}$，自底向上合并塌缩成每个叶子的独立贡献。
5. **classic problem solution** — 一遍扫描维护深度，"相邻 0 1"识别叶子，预处理 $2$ 的幂表查表累加，$O(n)$。
6. **discuss by category** — 边界：最外层叶子指数 0、最大深度 $n/2$、取模回绕（$2^{34}\bmod p$）手算核对。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 串长，$\le10^5$，偶数 | `int` | 读入 |
| `a[i]` | 第 $i$ 个字符：$0=$`(`，$1=$`)` | `int[mxn]` | 读入，0-based |
| `p` | 模数 $12345678910$ | `constexpr i64` | 超 int，必须 i64 |
| `pw[i]` | $2^i\bmod p$ | `i64[mxn]` | `pw[0]=1`，`pw[i]=pw[i-1]*2%p` |
| `dep` | 当前嵌套深度（处理完位置 $i$ 后 = 前缀深度 $d_{i+1}$） | `int` | 全局默认 $0$；`(` 加 $1$、`)` 减 $1$ |
| `ans` | 得分模 $p$ 的累加器 | `i64` | 全局默认 $0$ |
| `mxn` | $100000+5$ | `constexpr int` | 深度 $\le n/2$，幂表指数 $\le n$，均够用 |

### 算法步骤

1. I/O 加速三行；读 `n`。
2. 预处理 `pw[0]=1`，`pw[1..n]` 递推乘 $2$ 取模。
3. 读入 $n$ 个 0/1 到 `a`。
4. 扫描 $i=0..n-1$：`a[i]==0` 则 `++dep`，且若 `a[i+1]==1` 则 `ans=(ans+pw[dep-1])%p`；`a[i]==1` 则 `--dep`。
5. 输出 `ans`。

### 复杂度

- 时间：$O(n)$，三趟线性扫描。
- 空间：$O(n)$，`a`（int）+ `pw`（i64）约 $1.2$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例 `(())()` 输出 $3$；`((()))`$\to4$、`(()())`$\to4$、`()()`$\to2$ 手算全对；$35$ 层嵌套取模回绕输出 $4834190274$ 与手算 $2^{34}-p$ 一致；$n=10^5$ 极限深度数据正常运行。

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};
constexpr i64 p{12345678910};

int n,a[mxn],dep;
i64 pw[mxn],ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	pw[0]=1;
	for(int i=1;i<=n;++i)
		pw[i]=pw[i-1]*2%p;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0;i<n;++i)
	{
		if(a[i]==0)
		{
			++dep;
			if(i+1<n&&a[i+1]==1)	// 紧邻的 () 是叶子，贡献 2^(dep-1)
				ans=(ans+pw[dep-1])%p;
		}
		else
			--dep;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **公式是灵魂**：`ans+=pw[dep-1]` 一行就是引理 3 的叶子贡献。不需要栈、不需要判断"内部是否为空"，引理 2 的取模判空坑被整体绕开。
- **叶子识别**：`a[i]==0&&a[i+1]==1` 即相邻的 `()`；在**左括号处**计数（此时 `dep` 刚加完，正是叶子深度），右括号处只 `--dep`，保证每个叶子恰好计一次。
- **`i64` 不可省**：模数 $p\approx1.23\times10^{10}$ 本身就超 `int`；`pw`、`ans` 全程 `i64`，中间量 $<2p$ 远不溢出（引理 5）。
- **幂表到 $n$**：深度 $\le n/2$，指数 `dep-1`$\le n/2-1$，预处理到 $n$ 富余一倍；`pw[0]=1` 对应最外层叶子的 $2^0$。
- `dep`、`ans` 全局默认 $0$ 恰好是正确初值；`a` 按 $n$ 行逐个 `cin>>` 读入，跨行空白自动处理。
