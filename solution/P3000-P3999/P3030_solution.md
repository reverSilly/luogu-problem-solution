# P3030 [USACO11NOV] Tile Exchanging S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 有 $N$ 块正方形瓷砖（$N\le 10$），第 $i$ 块边长 $A_i$（$1\le A_i\le 100$）。可以给每块砖换一个最终边长 $B_i$：把边长 $A_i$ 的砖换成边长 $B_i$ 的砖花费 $(A_i-B_i)^2$，换完后这块砖的面积是 $B_i^2$。**换过的砖不能再换**（禁止 $3\to2\to1$ 这种链式操作）。要求最终总面积 $\sum B_i^2$ **恰好**等于 $M$（$1\le M\le 10000$），求最小总花费；凑不出 $M$ 输出 `-1`。

**口径说明（题面歧义处）。** 题面没有明说 $B_i$ 能否取 $0$。本文采用 **$B_i\in\{0,1,\dots,100\}$，$B_i=0$ 表示退掉这块砖**（花费 $(A_i-0)^2=A_i^2$，面积 $0$）的口径。依据：其一，代价公式 $|A_i-B_i|^2$ 在 $B_i=0$ 处自然成立，"换成边长 $0$"即"不再持有这块砖"；其二，若禁止 $B_i=0$，则 $M<N$ 时必然无解（每块砖面积至少 $1$），而题面只给了 $M\ge1$，没有排除 $M<N$；其三，这也是本题通行参考解法的口径（枚举新边长从 $0$ 开始）。若评测口径相反，只需把下文枚举下界从 $0$ 改成 $1$，算法框架不变。另外 $B_i$ 的上界不用操心：$B_i^2\le M\le 10000\Rightarrow B_i\le 100$，自动满足。

**第一步：把"禁止二次交换"翻译成数学语言。** 这条规则乍看是限制，其实是**简化**：它保证每块砖从 $A_i$ 到最终边长 $B_i$ 只走一步，花费就是 $(A_i-B_i)^2$，而不是"沿某条交换链的逐步花费之和"。如果没有这条规则，$3\to1$ 可以走 $3\to2\to1$，花费 $1+1=2<4=(3-1)^2$，每块砖的代价就变成了一个最短路矩阵，问题会复杂得多。有了规则，**每块砖的选择完全独立**：选一个 $B_i$，贡献面积 $B_i^2$、代价 $(A_i-B_i)^2$，砖与砖之间唯一的耦合是"面积之和恰为 $M$"。

**第二步：贪心试探——"只动一两块砖"行不行？** 直觉上花费 $(A_i-B_i)^2$ 随改动幅度平方增长，似乎应该尽量少动砖。造一组数据检验：$N=10$，全部 $A_i=1$，$M=9999$。

- 只动 $1$ 块：需要 $b^2+9=9999$，即 $b^2=9990$，不是完全平方数，**无解**。
- 只动 $2$ 块：需要 $b^2+c^2=9991$。但平方数模 $4$ 只余 $0$ 或 $1$，两个平方数之和模 $4$ 不可能余 $3$，而 $9991\equiv3\pmod4$，**无解**。
- 动 $3$ 块：有解，例如 $94^2+34^2+0^2=8836+1156=9992$，再加 $7$ 块不动的 $1$，总面积 $9999$，花费 $93^2+33^2+1^2=8649+1089+1=9739$。

而程序跑出的最优解是 **$9379$**，对应边长 $\{25,28,32,32,32,32,32,33,34,35\}$：面积 $625+784+5\times1024+1089+1156+1225=9999$，花费 $24^2+27^2+5\times31^2+32^2+33^2+34^2=576+729+4805+1024+1089+1156=9379<9739$。**最优解把 $10$ 块砖全动了**，边长摊在 $25\sim35$ 之间。原因：面积按 $b^2$ 增长、代价按 $(b-1)^2$ 增长，两者都是凸的，把"面积增量"摊到多块砖上比堆在一块上便宜。贪心方向被这组数据彻底否掉。

**第三步：归约到经典模型。** 每块砖是一组物品：组内第 $b$ 个物品体积 $b^2$、代价 $(A_i-b)^2$，**每组恰好选一个**（$b=A_i$ 即"不换"，代价 $0$；$b=0$ 即"退掉"）。要求总体积恰为 $M$、总代价最小——这就是**分组背包求恰好装满的最小代价**，二维 DP 直接写：$f[i][j]$ 表示前 $i$ 块砖凑出面积 $j$ 的最小花费。

**第四步：规模核对。** 状态数 $N\times M\le10\times10001$，每个状态枚举 $b\le101$ 种选择，总量约 $10^7$，轻松通过。花费上界 $N\times100^2=10^5$，`int` 足够；不可达状态用 `inf=1145141919` 显式填充（**全局数组默认 $0$ 不是 INF**，不填会把所有状态当成"零花费可达"，答案恒为 $0$）。

**手造数据核对**（题面只给了样例解释，没有样例输入输出，按解释反推第一组）：

第一组（样例解释反推：$N=3,M=6,A=(3,3,1)$）：一块 $3\to2$（面积 $4$，花费 $1$），一块 $3\to1$（面积 $1$，花费 $4$），$1$ 不动，总面积 $6$，花费 $5$。程序输出 `5`，与解释一致。

第二组（$N=1,M=3,A=(2)$）：$3$ 不是完全平方数，输出 `-1`。

第三组（$N=2,M=1,A=(5,7)$，专打 $B=0$ 口径）：退掉 $5$（花费 $25$）、$7\to1$（花费 $36$），总花费 $61$；另一方向 $5\to1$（$16$）+ 退掉 $7$（$49$）$=65$ 更贵。程序输出 `61`。

## 二、思维链：完整证明

**记号。** 砖下标 $0\le i<N$，边长 $A_i$，最终边长 $B_i$，目标面积 $M$。方案即向量 $(B_0,\dots,B_{N-1})$，面积 $\sum B_i^2$，代价 $\sum(A_i-B_i)^2$。$f[i][j]$ 为 DP 表，$\mathrm{INF}=1145141919$。

### 引理 1（规则等价于"每砖独立选一步"）

在"换过的砖不能再换"的规则下，合法最终方案与向量 $(B_0,\dots,B_{N-1})\in\{0,\dots,100\}^N$ 一一对应，且方案代价恰为 $\sum_i(A_i-B_i)^2$、面积恰为 $\sum_iB_i^2$。

*证明*：每块砖至多被交换一次。若被交换，设换成的边长为 $B_i$，由题面代价公式花费 $(A_i-B_i)^2$，此后不能再动，故最终边长就是 $B_i$；若未被交换，最终边长 $B_i=A_i$，花费 $0=(A_i-A_i)^2$，公式统一成立。反之，任给向量 $(B_i)$，对每块 $B_i\ne A_i$ 的砖执行一次 $A_i\to B_i$ 的交换即实现该方案，不违反规则。总面积、总代价按砖求和即得。

**规则为何不可省**：若允许链式交换，$3\to2\to1$ 花费 $1+1=2$，而公式 $(3-1)^2=4$，代价不再由 $(A_i,B_i)$ 唯一决定（变成链上逐步平方和的最小值），引理 1 的"独立选择"结构被破坏。题面专门加这条规则，正是为了让代价矩阵保持 $(A_i-B_i)^2$ 的简单形式。证毕。

### 引理 2（枚举范围有限且充分）

任何可行方案中 $0\le B_i\le\lfloor\sqrt M\rfloor\le100$。因此 DP 中每块砖只需枚举 $b\in[0,100]$ 且 $b^2\le$ 剩余面积。

*证明*：面积非负，故 $B_i^2\le\sum_jB_j^2=M$，开方即得 $B_i\le\lfloor\sqrt M\rfloor$；$M\le10000$ 给出 $\le100$。反过来，枚举上界取 $100$ 不会漏掉任何可行选择（可行选择必 $\le100$），也不会引入非法选择（$b^2>M$ 的分支被循环条件 `b*b<=m-j` 剪掉，因为剩余面积 $M-j\ge0$ 时 $j+b^2>M$ 的状态对最终答案无贡献）。证毕。

### 引理 3（"少动砖"贪心的反例：模 $4$ 障碍）

设 $N=10$、所有 $A_i=1$、$M=9999$。则任何"至多改动 $2$ 块砖"的方案都不可行；而存在改动全部 $10$ 块、代价 $9379$ 的可行方案。

*证明*：设改动了 $k$ 块，新边长 $b_1,\dots,b_k$，其余 $10-k$ 块面积仍为 $1$。面积方程 $\sum_{t=1}^k b_t^2=9999-(10-k)=9989+k$。

$k=1$：$b_1^2=9990$。$99^2=9801<9990<10000=100^2$，非完全平方数，无整数解。

$k=2$：$b_1^2+b_2^2=9991$。对任意整数 $x$，$x\bmod4\in\{0,1,2,3\}\Rightarrow x^2\bmod4\in\{0,1\}$，故两平方和模 $4$ 属于 $\{0,1,2\}$；而 $9991=4\times2497+3\equiv3\pmod4$，矛盾，无解。

$k=10$ 的构造：取边长 $(25,28,32,32,32,32,32,33,34,35)$。面积和 $=625+784+5\times1024+1089+1156+1225=9999$ ✓；代价和 $=24^2+27^2+5\times31^2+32^2+33^2+34^2=576+729+4805+1024+1089+1156=9379$。又 $k=3$ 的可行解 $(94,34,0,\underbrace{1,\dots,1}_{7})$ 代价 $93^2+33^2+1^2=9739>9379$。故"改动越少越好"的贪心被显式反例否定。证毕。

（这条反例同时解释了最优解的形态：$(b-1)^2$ 与 $b^2$ 都是凸函数，把面积增量摊薄到多块砖上更省——但"摊薄"的精确最优只能靠 DP，不能靠贪心。）

### 引理 4（DP 状态与转移的正确性）

定义 $f[i][j]$ 为"只考虑前 $i$ 块砖、总面积恰为 $j$"的最小代价（不可达为 $\mathrm{INF}$）。则初值 $f[0][0]=0$、$f[0][j>0]=\mathrm{INF}$，且对 $0\le i<N$：
$$f[i+1][j+b^2]=\min\bigl(f[i+1][j+b^2],\;f[i][j]+(A_i-b)^2\bigr),\qquad 0\le b\le100,\ j+b^2\le M,$$
按此递推（跳过 $f[i][j]=\mathrm{INF}$ 的状态）计算出的表满足定义。

*证明*：对 $i$ 归纳。$i=0$：没有砖，面积只能为 $0$、代价 $0$；$j>0$ 无方案，$\mathrm{INF}$ ✓。

设 $f[i][\cdot]$ 正确。考察前 $i+1$ 块砖凑面积 $j'$ 的任一最优方案，设第 $i$ 块（第 $i+1$ 个）最终边长为 $b$，则前 $i$ 块凑出面积 $j'-b^2$，且**前 $i$ 块部分必是该子问题的最优解**：否则用更便宜的前 $i$ 块方案替换它，第 $i$ 块选择不变，总面积不变、总代价更小，与整体最优矛盾（最优子结构）。故
$$f[i+1][j']=\min_{\substack{0\le b\le100\\b^2\le j'}}\bigl(f[i][j'-b^2]+(A_i-b)^2\bigr),$$
其中不可达子状态取 $\mathrm{INF}$ 不参与最小值。代码以"推送"形式写同一递推：枚举 $j$（即 $j'-b^2$）与 $b$，更新 $f[i+1][j+b^2]$，两者等价（每个 $(j',b)$ 对恰被访问一次）。跳过 $f[i][j]=\mathrm{INF}$ 保证不会把 $\mathrm{INF}+(A_i-b)^2$ 当成合法代价写入；即使不跳，$\mathrm{INF}+10^5<2^{31}-1$ 也不会溢出污染最小值，但跳过更干净。由引理 2，枚举范围不漏解。归纳完成。证毕。

### 引理 5（答案提取与 `-1` 判定）

$f[N][M]<\mathrm{INF}$ 时答案为 $f[N][M]$，否则答案为 `-1`。

*证明*：由引理 1，原问题的可行方案集与 $\{(B_i)\in[0,100]^N:\sum B_i^2=M\}$ 相同，代价函数相同；由引理 2 枚举范围充分；由引理 4，$f[N][M]$ 恰是该集合上的最小代价（集合为空时为 $\mathrm{INF}$）。故有限即最优值，$\mathrm{INF}$ 即无解。证毕。

### 引理 6（复杂度）

时间 $O(N\cdot M\cdot\min(101,\lfloor\sqrt M\rfloor+1))=O(NM\sqrt M)$，空间 $O(NM)$。

*证明*：外层 $i$ 共 $N$ 轮，每轮枚举 $j\in[0,M]$ 共 $M+1$ 个状态，每个状态枚举 $b$ 至多 $\min(101,\lfloor\sqrt{M-j}\rfloor+1)\le101$ 次，每次 $O(1)$ 转移。总量 $\le10\times10001\times101\approx1.01\times10^7$。空间为 $f$ 表 $(N+1)\times(M+1)$ 个 `int`，$\le11\times10005\times4\approx0.44$ MB。证毕。

### 定理

程序输出恰为"总面积恰为 $M$ 的最小交换代价"，无解时输出 `-1`，复杂度 $O(NM\sqrt M)$。

*证明*：引理 1 把原问题化为独立选择向量上的优化；引理 2 保证枚举范围；引理 3 说明贪心不可行、必须精确搜索（DP）；引理 4 保证 DP 表正确；引理 5 保证答案提取与无解判定；引理 6 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — "禁止二次交换"⇒ 每块砖独立选最终边长 $B_i$，代价 $(A_i-B_i)^2$、面积 $B_i^2$；规则反而简化了代价结构。
2. **explore its property** — $B_i^2\le M\le10000\Rightarrow B_i\le100$；$B_i=0$ 解释为退砖（口径在 Part 1 显式声明）。
3. **consider easier version** — 先试"只动一两块砖"的贪心：$N=10,A\equiv1,M=9999$ 时动 $1$ 块要求 $9990$ 是平方数、动 $2$ 块撞模 $4$ 障碍，均无解；最优反而全动（$9379<9739$）。
4. **reduce to easier problem** — 每砖一组物品（体积 $b^2$、代价 $(A_i-b)^2$、组内恰选一个）⇒ 分组背包"恰好装满求最小代价"。
5. **classic problem solution** — 二维 DP $f[i][j]$，推送式转移，$\mathrm{INF}$ 显式填充 + 跳过不可达状态。
6. **discuss by category** — 花费上界 $10^5$ 用 `int` 即可；$f[N][M]=\mathrm{INF}$ 输出 `-1`；$b=A_i$ 的零代价分支天然包含"不换"。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,m` | 砖数 $N\le10$、目标面积 $M\le10000$ | `int` | 读入 |
| `a[i]` | 第 $i$ 块砖原边长 $A_i$ | `int[mxn]` | 读入，0-based |
| `f[i][j]` | 前 $i$ 块砖凑出面积**恰为** $j$ 的最小代价 | `int[mxn][mxm]` | **全表 `fill` 成 `inf`**，再置 `f[0][0]=0`；$i$ 是"已处理砖数" |
| `inf` | 不可达哨兵 $1145141919$ | `constexpr int` | $\mathrm{INF}+10^5$ 仍在 `int` 内 |
| `mxn,mxm` | $15$、$10005$（约束 $+5$） | `constexpr int` | $f$ 的两维尺寸 |
| `b` | 枚举的新边长，$0$ 表示退砖 | `int` | 循环条件 `b<=100&&b*b<=m-j` |

### 算法步骤

1. I/O 加速三行；读 `n,m` 与 `a[0..n-1]`。
2. `fill_n(&f[0][0],mxn*mxm,inf)`，`f[0][0]=0`。
3. 对 $i=0..n-1$、$j=0..M$：若 `f[i][j]==inf` 跳过；否则对 $b=0..\min(100,\lfloor\sqrt{M-j}\rfloor)$，用 `f[i][j]+(a[i]-b)^2` 更新 `f[i+1][j+b*b]` 取 `min`。
4. 输出 `f[n][m]==inf ? -1 : f[n][m]`。

### 复杂度

- 时间：$O(NM\sqrt M)\le1.01\times10^7$ 次转移。
- 空间：$O(NM)\approx0.44$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例解释反推数据输出 `5` ✓；`1 3 / 2` 输出 `-1` ✓；退砖口径数据 `2 1 / 5 7` 输出 `61` ✓；极限 `10 9999 / 1×10` 输出 `9379`，与独立构造的边长组 $\{25,28,32\times5,33,34,35\}$（面积 $9999$、代价 $9379$）吻合 ✓。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3030 [USACO11NOV] Tile Exchanging S
// 每块砖独立选最终边长 b（0=退掉），面积 b*b、代价 (a-b)^2 ⇒ 分组背包
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{15},mxm{10005},inf{1145141919};

int n,m,a[mxn],f[mxn][mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	fill_n(&f[0][0],mxn*mxm,inf);	// 全局默认0不是INF！不可达必须显式填
	f[0][0]=0;
	for(int i=0;i<n;++i)
		for(int j=0;j<=m;++j)
		{
			if(f[i][j]==inf)
				continue;
			for(int b=0;b<=100&&b*b<=m-j;++b)	// b=0表示退掉这块砖
				f[i+1][j+b*b]=min(f[i+1][j+b*b],f[i][j]+(a[i]-b)*(a[i]-b));
		}
	cout<<(f[n][m]==inf?-1:f[n][m])<<'\n';
	return 0;
}
```

### 代码说明

- `f` 是"恰好装满"型 DP：**必须整表填 `inf`**。全局 `int` 默认 $0$，不填的话每个面积都会被当成"零花费可达"，答案恒 $0$——这是本题最容易静默出错的地方。
- 推送式转移（从 `f[i][j]` 推向 `f[i+1][j+b*b]`）与拉取式等价，但推送式只需一层 `b` 循环、且 `f[i][j]==inf` 时整段跳过，常数更小。
- `b<=100` 与 `b*b<=m-j` 双条件：前者是边长上界（引理 2），后者保证不越出目标面积；`b*b` 最大 $10000$，`int` 无溢出。
- 代价 `(a[i]-b)*(a[i]-b)` 最大 $10000$，总代价最大 $10^5$，`int` 足够；`inf+10^5<2^{31}-1`，即使误加也不会溢出成负数。
- `b=0` 分支即"退砖"，代价 `a[i]*a[i]`；若评测口径不允许退砖，把循环起点改为 `b=1` 即可。
- 输出用三目拼接 `-1`，换行 `'\n'`。
