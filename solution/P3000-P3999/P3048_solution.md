# P3048 [USACO12FEB] Cow IDs S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 把所有**二进制表示中恰好含 $K$ 个 $1$** 的正整数按升序排列（$1\le K\le10$），求第 $N$ 个（$1\le N\le10^7$），输出它的二进制串（最高位自然是 $1$，无前导零）。

"前导位始终是 1"不是额外限制，只是二进制写法的常识：编号 $x$ 合法 $\iff\mathrm{popcount}(x)=K$。例如 $K=2$ 时序列是 $3,5,6,9,10,12,\dots$，即 `11,101,110,1001,1010,1100,...`。

**第一步：暴力为什么不行。** 逐个整数检查 popcount：第 $N$ 个数最大能到多大？$K=1$ 时序列是 $1,2,4,8,\dots$，第 $N$ 个是 $2^{N-1}$，$N=10^7$ 时**位数就有一千万位**，数值本身是天文数字，逐个枚举彻底无望。必须直接"构造"第 $N$ 个，而不是"数到"第 $N$ 个。

**第二步：按位数分层计数。** 一个位数（最高位位置）为 $L$ 的数，最高位固定是 $1$，剩下 $K-1$ 个 $1$ 要在低 $L-1$ 位里选位置——恰好 $\binom{L-1}{K-1}$ 个。于是"第 $N$ 个数有几位"可以逐层累加确定：从 $L=K$（最小的合法位数，$K$ 个 $1$ 挤满）开始，累加 $\binom{L-1}{K-1}$ 直到 $\ge N$，余下的排名 $r$ 就是它在"长度为 $L$ 的数"内部的序号。

**第三步：层内反排名（unranking）。** 长度固定为 $L$ 时，数值大小 = 二进制串从高位到低位的字典序。于是逐位决定：设当前处理位 $p$（从低往高数还剩 $p+1$ 个位置），还要放 $\mathrm{rem}$ 个 $1$。**该位填 $0$** 的数共有 $\binom{p}{\mathrm{rem}}$ 个（$\mathrm{rem}$ 个 $1$ 全放低 $p$ 位），且它们全部小于该位填 $1$ 的数。若 $r\le\binom{p}{\mathrm{rem}}$，答案该位是 $0$；否则该位是 $1$，$r$ 减去 $\binom{p}{\mathrm{rem}}$、$\mathrm{rem}$ 减一。这就是组合数的经典反排名，和康托展开求第 $k$ 个排列同一套路。

**第四步：两个规模陷阱。**

1. **$K=1$ 必须特判**：此时位数 $L=N$ 可达 $10^7$，组合数表开不下，也没必要——答案就是 `1` 后跟 $N-1$ 个 `0`。$K\ge2$ 时位数很小：$K=2$ 最坏 $L=4473$（$\binom{4473}{2}=10001628\ge10^7$），$K$ 更大 $L$ 更小（引理 2 证明 $L\le4473$ 对一切 $K\in[2,10]$ 成立），表开 $5005$ 足够。
2. **组合数会爆 `long long`**：$\binom{4472}{9}\approx10^{27}$ 远超 $9.2\times10^{18}$。但算法里组合数只用来和 $r\le N\le10^7$ 比较、或做 $r\mathrel{-}=\binom{p}{\mathrm{rem}}$（仅当它 $<r$ 时）。所以把每个组合数**截断到 $\mathrm{cap}=2\times10^9>N$**：真实值超过 cap 时比较结果不变（都判"$r$ 不够大"），减法永远不会用到被截断的值。截断后的 Pascal 递推两数之和 $\le4\times10^9$，`i64` 安全（引理 4）。

**手造数据核对**（题面无样例，全部手造并与手工枚举对照）：

$K=2$：$N=1,2,3,4$ 应输出 `11,101,110,1001`（即 $3,5,6,9$）。程序逐一吻合 ✓。

$K=3$：合法序列开头为 $7,11,13,14,19,21,22,25,26,28$，$N=1..5,10$ 应输出 `111,1011,1101,1110,10011,11100`。程序逐一吻合 ✓。

$K=1$：$N=1,3$ 输出 `1,100` ✓。$K=10,N=1$ 输出 `1111111111`（$1023$）✓；$N=2$ 输出 `10111111111`（$1535$，第二小的 popcount=10 的数）✓。

## 二、思维链：完整证明

**记号。** $\mathrm{pc}(x)$ 为 $x$ 二进制中 $1$ 的个数；合法编号集 $\mathcal A_K=\{x\ge1:\mathrm{pc}(x)=K\}$，升序第 $N$ 个记 $x^\*$。位数 $L(x)=\lfloor\log_2x\rfloor+1$。$\binom nk$ 为组合数（$k>n$ 时 $0$）。$r$ 为层内 $1$-based 排名，$\mathrm{rem}$ 为待放置的 $1$ 的个数，$\mathrm{cap}=2\times10^9$。

### 引理 1（按位数分层计数 + hockey-stick）

位数恰为 $L$ 的合法编号有 $\binom{L-1}{K-1}$ 个（$L\ge K$；$L<K$ 时 $0$ 个）。位数 $\le L$ 的合法编号共 $\binom LK$ 个。

*证明*：位数 $L$ 即 $2^{L-1}\le x<2^L$，第 $L-1$ 位（最高位）必为 $1$，其余 $L-1$ 位中恰选 $K-1$ 位放 $1$，选法与数一一对应，共 $\binom{L-1}{K-1}$；$L<K$ 时 $K$ 个 $1$ 放不下，为 $0$（组合数约定一致）。

累计：$\sum_{l=K}^{L}\binom{l-1}{K-1}=\sum_{i=K-1}^{L-1}\binom{i}{K-1}=\binom{L}{K}$（hockey-stick 恒等式）。恒等式证明：对 $L$ 归纳，$L=K$ 时两边都是 $1$；$\binom{L}{K}+\binom{L}{K-1}=\binom{L+1}{K}$（Pascal 公式，按"第 $L+1$ 个元素选不选"分类即得），故 $\sum_{i=K-1}^{L}\binom{i}{K-1}=\binom{L}{K}+\binom{L}{K-1}=\binom{L+1}{K}$ ✓。证毕。

**推论（定位位数）**：$x^\*$ 的位数 $L^\*=\min\{L:\binom LK\ge N\}$，层内排名 $r=N-\binom{L^\*-1}{K}$。代码用逐层累加 $\binom{L-1}{K-1}$ 的循环实现同一件事：每轮 `r-=cnt` 正是减去前面各层的总数。

### 引理 2（位数上界：$K=1$ 时 $L=N$；$K\ge2$ 时 $L\le4473$）

$K=1$：$x^\*=2^{N-1}$，位数 $N$。$2\le K\le10$：$L^\*\le4473$，故组合数表只需 $p\le4472$，`mxp=5005` 充分。

*证明*：$K=1$ 时 $\mathcal A_1=\{2^0,2^1,\dots\}$ 升序即指数升序，第 $N$ 个是 $2^{N-1}$，位数 $N\le10^7$。

$K\ge2$：先证二项式行的单峰性：$\binom{n}{k+1}/\binom nk=(n-k)/(k+1)\ge1\iff k\le(n-1)/2$，故 $\binom nk$ 随 $k$ 先增后减，且由对称性 $\binom nk=\binom{n}{n-k}$，在区间 $k\in[2,n-2]$ 上的最小值在端点取得，等于 $\binom n2$。取 $n=4473$：对一切 $K\in[2,10]\subseteq[2,4471]$，
$$\binom{4473}{K}\ge\binom{4473}{2}=\frac{4473\times4472}{2}=10001628\ge10^7\ge N.$$
由引理 1 推论，$L^\*\le4473$。表中最大下标 $p=L^\*-1\le4472<5005$ ✓。证毕。

### 引理 3（层内反排名正确）

固定位数 $L$、层内排名 $r$（$1\le r\le\binom{L-1}{K-1}$）。最高位置 $1$ 后，从 $p=L-2$ 到 $0$ 逐位执行：
- 若 $\mathrm{rem}=0$：剩余位全 $0$；若 $\mathrm{rem}=p+1$：剩余位全 $1$；
- 否则若 $r\le\binom{p}{\mathrm{rem}}$：位 $p$ 填 $0$；
- 否则：位 $p$ 填 $1$，$r\mathrel{-}=\binom{p}{\mathrm{rem}}$，$\mathrm{rem}\mathrel{-}=1$。

所得二进制串恰为层内第 $r$ 小的数。

*证明*：先证**定长数值序 = 高位字典序**：两个 $L$ 位数若不同，设从高位起第一个不同位是 $p$，该位为 $1$ 者比另一者大 $2^p$，而更低位的总差 $<2^p$（$\sum_{i<p}2^i=2^p-1$），故该位为 $1$ 者更大。

对"剩余位置数 $p+1$"归纳。当前候选集 = 所有"高位前缀已固定、低 $p+1$ 位含 $\mathrm{rem}$ 个 $1$"的数，共 $\binom{p+1}{\mathrm{rem}}$ 个，$r$ 不超过它（初始由定位保证；每步下面验证）。按位 $p$ 分两类：填 $0$ 的 $\binom{p}{\mathrm{rem}}$ 个（$\mathrm{rem}$ 个 $1$ 全在低 $p$ 位），填 $1$ 的 $\binom{p}{\mathrm{rem}-1}$ 个；由字典序性质，**填 $0$ 类整体小于填 $1$ 类**。

- $r\le\binom{p}{\mathrm{rem}}$：目标在填 $0$ 类，且是其中第 $r$ 小。位 $p$ 置 $0$，子问题规模 $(p,\mathrm{rem},r)$，排名不变，归纳继续。
- $r>\binom{p}{\mathrm{rem}}$：目标在填 $1$ 类，是其中第 $r-\binom{p}{\mathrm{rem}}$ 小。位 $p$ 置 $1$，子问题 $(p,\mathrm{rem}-1,r-\binom{p}{\mathrm{rem}})$。新排名 $\le\binom{p}{\mathrm{rem}-1}$（因 $r\le\binom{p+1}{\mathrm{rem}}=\binom{p}{\mathrm{rem}}+\binom{p}{\mathrm{rem}-1}$，Pascal），归纳假设可用。
- 边界 $\mathrm{rem}=0$：候选只剩全 $0$ 一个（$\binom{p+1}{0}=1$，$r=1$），填 $0$ 正确；$\mathrm{rem}=p+1$：候选只剩全 $1$ 一个，填 $1$ 正确。两个短路正是这两类唯一候选的显式处理。

$p=-1$ 时候选集只剩空串，构造完成。归纳得证。证毕。

### 引理 4（截断 cap 不改变算法行为）

把表中每个组合数按 $\widehat C=\min(\mathrm{cap},C)$ 存储（Pascal 递推用截断后的值相加再截断），则定位循环与反排名中所有比较、减法的结果与使用真实值完全一致；且递推中间量 $\le2\,\mathrm{cap}=4\times10^9$，`i64` 不溢出。

*证明*：算法中组合数只出现在两种上下文，且始终有 $r\le N\le10^7<\mathrm{cap}$：

1. **比较 $r\le C$**（含定位循环的 `cnt<r`）：若真实 $C\le\mathrm{cap}$，则 $\widehat C=C$，结果相同；若真实 $C>\mathrm{cap}$，则 $\widehat C=\mathrm{cap}>r$，与真实 $C>r$ 同判。
2. **减法 $r\mathrel{-}=C$**：仅在 $C<r\le10^7<\mathrm{cap}$ 时执行，此时真实 $C<\mathrm{cap}$，$\widehat C=C$ 精确。

再证截断递推仍给出 $\widehat C=\min(\mathrm{cap},C)$：Pascal 公式 $C=C_1+C_2$，归纳设 $\widehat C_i=\min(\mathrm{cap},C_i)$。若 $C\le\mathrm{cap}$，则 $C_1,C_2\le C\le\mathrm{cap}$，$\widehat C_1+\widehat C_2=C_1+C_2=C$，再截断不变 ✓；若 $C>\mathrm{cap}$，则 $\widehat C_1+\widehat C_2\ge\min(\mathrm{cap},C_1+C_2)=\mathrm{cap}$（截断函数单调且 $\min(\mathrm{cap},a)+\min(\mathrm{cap},b)\ge\min(\mathrm{cap},a+b)$），截断后 $=\mathrm{cap}$ ✓。中间量 $\le2\,\mathrm{cap}=4\times10^9<9.2\times10^{18}$ ✓。证毕。

### 引理 5（$K=1$ 特判的输出形态）

$K=1$ 时答案为字符串 `1` 后跟 $N-1$ 个 `0`，长度 $N$。

*证明*：由引理 2，$x^\*=2^{N-1}$，其二进制表示恰为 $1$ 后跟 $N-1$ 个 $0$。$N=1$ 时为空后缀，输出 `1` ✓。证毕。

### 引理 6（复杂度）

$K\ge2$：时间 $O(\mathrm{mxp}\cdot K+L)$，空间 $O(\mathrm{mxp}\cdot K+L)$，$L\le4473$。$K=1$：时间 $O(N)$（输出主导），空间 $O(N)$，$N\le10^7$。

*证明*：建表 $\mathrm{mxp}\times(K+1)$ 个格子各 $O(1)$；定位循环每轮 $O(1)$、至多 $L-K+1$ 轮；反排名至多 $L$ 步，短路分支的批量填充总计 $\le L$ 字符；输出 $L$ 字符。$K=1$ 分支构造并输出长度 $N$ 的串。空间为表 $5005\times15\times8\approx0.6$ MB 加答案串（$K=1$ 极限 $10$ MB）。证毕。

### 定理

程序输出 $\mathcal A_K$ 中升序第 $N$ 个数的二进制表示，复杂度如引理 6。

*证明*：引理 1 保证分层计数与位数定位正确；引理 2 保证 $K\ge2$ 时表尺寸充分、$K=1$ 时位数可达 $10^7$ 必须特判（引理 5 给出特判形态）；引理 3 保证层内逐位反排名构造出第 $r$ 小的数；引理 4 保证截断组合数不改变任何分支与数值；引理 6 给出复杂度。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 编号 = popcount 恰为 $K$ 的正整数升序；"前导位是 1"只是二进制常识；$K=1$ 时第 $N$ 个是 $2^{N-1}$，位数可达 $10^7$，枚举数值无望。
2. **classic problem solution** — 按位数分层计数：长度 $L$ 共 $\binom{L-1}{K-1}$ 个，hockey-stick 累计 $\binom LK$，逐层减出位数 $L$ 与层内排名 $r$。
3. **discuss by category** — $K=1$ 特判直接输出；$K\ge2$ 用二项式行单峰性证 $L\le4473$，表开 $5005$。
4. **classic problem solution** — 组合数反排名（康托展开同款）：$r\le\binom{p}{\mathrm{rem}}$ 填 $0$，否则填 $1$ 并减排名，定长数值序 = 高位字典序是依据。
5. **explore its property** — 组合数只与 $r\le10^7$ 比较/相减 ⇒ 截断到 $\mathrm{cap}=2\times10^9$ 防溢出且不改任何分支。
6. **reduce to easier problem** — $\mathrm{rem}=0$ / $\mathrm{rem}=p+1$ 时剩余位唯一确定，批量填充跳出，避免逐位空转。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,k` | 排名 $N\le10^7$、$1$ 的个数 $K\le10$ | `int` | 读入 |
| `C[p][j]` | **截断后**的 $\binom pj$，$\mathrm{cap}=2\times10^9$ | `i64[mxp][mxk]` | Pascal 递推；$j>\min(p,k)$ 的格子保持 $0$（恰为 $\binom pj=0$） |
| `cap` | 截断上界，$>N$ 即可 | `constexpr i64` | $2\times10^9$；两数之和 $4\times10^9$ 在 `i64` 内 |
| `L` | 答案位数 | `int` | 从 `k` 起逐层累加定位 |
| `r` | 层内 $1$-based 排名 | `int` | 初值 `n`，每减一层 `r-=cnt`，反排名中继续减 |
| `rem` | 还需放置的 $1$ 的个数 | `int` | 初值 `k-1`（最高位已占一个） |
| `ans` | 答案二进制串，`ans[0]` 是最高位 | `string` | 全 `0` 起步，`ans[0]='1'`；位 $p$ 对应下标 `L-1-p` |
| `mxp,mxk` | $5005$、$15$ | `constexpr int` | $p\le4472$（引理 2）、$j\le K\le10$ |

### 算法步骤

1. I/O 加速三行；读 `n,k`。
2. 若 `k==1`：输出 `'1'<<string(n-1,'0')`，结束。
3. Pascal 建表：`C[p][0]=1`；`j=1..min(p,k)`：`C[p][j]=min(cap,C[p-1][j-1]+C[p-1][j])`。
4. 定位：`L=k,r=n`；当 `C[L-1][k-1]<r` 时 `r-=C[L-1][k-1],++L`。
5. `ans=string(L,'0')`，`ans[0]='1'`，`rem=k-1`；对 `p=L-2..0`：`rem==0` 跳出；`rem==p+1` 把位 $0..p$ 全置 $1$ 跳出；否则 `r<=C[p][rem]` 填 $0$（不动），不然 `r-=C[p][rem],--rem,ans[L-1-p]='1'`。
6. 输出 `ans`。

### 复杂度

- 时间：$K\ge2$ 时 $O(\mathrm{mxp}\cdot K+L)\approx5\times10^4$；$K=1$ 时 $O(N)$（输出 $10^7$ 字符主导）。
- 空间：表 $\approx0.6$ MB $+$ 答案串（$K=1$ 极限 $10$ MB）。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；$K=2$ 前 $4$ 项、$K=3$ 前 $5$ 项及第 $10$ 项、$K=1$、$K=10$ 共 $14$ 组手造小数据与手工枚举逐一吻合 ✓；极限 $N=10^7,K=2$ 输出长 $4473$、两个 $1$ 在位 $4472$ 与 $2843$，与独立闭式 $2^{4472}+2^{2843}$（由 $a(a+1)/2$ 累计排名推出）一致 ✓；$N=10^7,K=1$ 输出长 $10^7$ 恰一个 $1$ ✓；$N=10^7,K=10$ 输出长 $28$ 恰十个 $1$（$\binom{27}{10}<10^7\le\binom{28}{10}$）✓。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3048 [USACO12FEB] Cow IDs S
// 第N个popcount=K的数：先按位数定位（长度L共C(L-1,K-1)个），再逐位组合数反排名
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxp{5005},mxk{15};
constexpr i64 cap{2000000000};	// 截断上界>N即可：不改变任何比较/减法结果

int n,k;
i64 C[mxp][mxk];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	if(k==1)	// 编号即2^(n-1)：1后跟n-1个0，位数可达1e7，特判
	{
		cout<<'1'<<string(n-1,'0')<<'\n';
		return 0;
	}
	for(int p=0;p<mxp;++p)
	{
		C[p][0]=1;
		for(int j=1;j<=min(p,k);++j)
			C[p][j]=min(cap,C[p-1][j-1]+C[p-1][j]);
	}
	int L=k,r=n;
	for(i64 cnt=C[L-1][k-1];cnt<r;cnt=C[L-1][k-1])
	{
		r-=cnt;
		++L;
	}
	string ans(L,'0');
	ans[0]='1';	// 最高位必为1
	int rem=k-1;
	for(int p=L-2;p>=0;--p)
	{
		if(rem==0)
			break;	// 剩余位全0
		if(rem==p+1)	// 剩余位全1
		{
			for(int q=0;q<=p;++q)
				ans[L-1-q]='1';
			break;
		}
		if(r<=C[p][rem])
			continue;	// 该位填0时方案数已够
		r-=C[p][rem];
		--rem;
		ans[L-1-p]='1';
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`k==1` 特判是必须的**：此时位数 $L=N$ 可达 $10^7$，既开不下表也没必要——答案就是 `1` 后跟 $N-1$ 个 `0`。`string(n-1,'0')` 一次构造，输出 $10^7$ 字符。
- **截断 cap**：$\binom{4472}{9}\approx10^{27}$ 会爆 `i64`，但组合数只与 $r\le10^7$ 比较、只在 $<r$ 时被减，截断到 $2\times10^9$ 不改变任何分支（引理 4）。建表时 `min(cap, ...)` 一行完成。
- 表中 `j>min(p,k)` 的格子保持全局默认 $0$，恰好等于 $\binom pj=0$（$j>p$），Pascal 递推引用 `C[p-1][j]`（$j=p$ 时）读到的 $0$ 是**正确的数学值**，不是未初始化陷阱。
- 定位循环把 `cnt` 写进 `for` 的迭代表达式：每轮 `++L` 后重取 `C[L-1][k-1]`，`r` 始终 $\le N$，`r-=cnt` 只在 `cnt<r` 时发生，减的是精确值。
