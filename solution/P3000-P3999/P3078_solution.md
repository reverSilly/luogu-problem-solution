# P3078 [USACO13MAR] Poker Hands S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 牌面编号 $1..N$（$1\le N\le 10^5$），Bessie 手里有 $a_i$ 张牌面 $i$（$0\le a_i\le 10^5$）。一次操作（一个"顺子"）选区间 $[l,r]$，把手里牌面 $l,l+1,\dots,r$ 的牌**各打出一张**。求清空手牌的最少操作数。

**口径说明。** "打出从 $i$ 到 $j$ 的所有牌"按 Hint 的用法理解为**每种牌面各一张**（不是把该牌面的所有牌打光）：Hint 里"两个从 $2$ 到 $2$ 的顺子"说明单张顺子 $[2,2]$ 可以重复打，每次只消耗一张。于是问题等价于：把数组 $a$ 用尽量少的"区间减 $1$"操作变成全 $0$（过程中不能减成负数）。反过来看，就是用尽量少的"区间加 $1$"从全 $0$ 堆出 $a$——这正是 **NOIP2013 积木大赛（P1969）** 的模型，只是背景换成了扑克。

**手造小数据核对。** 题面 Hint 描述了一种 $6$ 步方案：顺子 $[1,5],[1,2],[4,5],[2,2],[2,2],[5,5]$。反推各牌面被覆盖次数：牌面 $1$ 被 $[1,5],[1,2]$ 覆盖 $2$ 次；牌面 $2$ 被 $[1,5],[1,2],[2,2],[2,2]$ 覆盖 $4$ 次；牌面 $3$ 被 $[1,5]$ 覆盖 $1$ 次；牌面 $4$ 被 $[1,5],[4,5]$ 覆盖 $2$ 次；牌面 $5$ 被 $[1,5],[4,5],[5,5]$ 覆盖 $3$ 次。所以 Hint 对应输入 $N=5,\ a=(2,4,1,2,3)$，答案 $6$。我把它当第一组手造数据。

再补两组极简的：$a=(0)$ → $0$ 步；$a=(5,5,5)$ → 一个 $[1,3]$ 重复打 $5$ 次即可，$5$ 步。

**第一步：猜公式。** 把 $a$ 画成直方图。$(2,4,1,2,3)$ 的"上升沿"：位置 $1$ 从 $0$ 升到 $2$（$+2$），位置 $2$ 从 $2$ 升到 $4$（$+2$），位置 $4$ 从 $1$ 升到 $2$（$+1$），位置 $5$ 从 $2$ 升到 $3$（$+1$）。上升总量 $2+2+1+1=6$，恰好等于 Hint 的答案！$(5,5,5)$ 只有位置 $1$ 上升 $5$，答案 $5$ ✓。猜想：

$$\text{答案}=\sum_{i=1}^{N}\max(0,\ a_i-a_{i-1}),\qquad a_0=0.$$

**第二步：为什么是"上升沿"？差分。** 区间操作在差分数组上只动两个位置：对 $[l,r]$ 加 $1$，等于 $d_l\text{+1},\ d_{r+1}\text{-1}$（$d_i=a_i-a_{i-1}$）。每个顺子只有一个"起点" $l$，它最多给某个 $d_l$ 贡献 $+1$；而目标差分里的每个正数 $d_i>0$ 都必须被"起点贡献"堆出来。所以**顺子数 $\ge$ 正差分之和**。这是下界，直觉是"每个上升沿都需要新的顺子在这里开头"。

**第三步：下界能取到吗？贪心构造。** 最自然的贪心：每次找一段**极长的全正区间**（左右都顶着 $0$ 或边界），打一个覆盖它的顺子。关键观察：这样的操作在差分上恰好是"把一个正的 $d_l$ 减 $1$、把一个负的 $d_{r+1}$ 加 $1$"——正部之和**恰好减 $1$**，一点不浪费。于是只要 $a$ 不全 $0$，就存在极长正段，打一步少 $1$，$P$ 步后归零。上下界夹住，公式得证。

**第四步：什么样的贪心会浪费？** 对比一下：如果顺子的左端 $l$ 处 $a_{l-1}>0$（不是上升沿开头），那么 $d_l\le 0$，这次操作对正部之和的削减可能为 $0$——白打一步。比如 $a=(1,2,1)$ 时先打 $[2,2]$：差分 $(1,1,-1,-1)$ 变成 $(1,0,0,-1)$，正部和从 $2$ 只降到 $1$……这一步其实也降了 $1$；但打 $[2,3]$（右端不是下降沿）就会把负差分往 $0$ 抬，可能完全不降正部。**"每一步都要削掉恰好 $1$ 的正部"是贪心不失败的充要条件**，极长正段贪心天然满足。

**第五步：溢出核对（真正的坑）。** 答案最大能到多少？交错数组 $a=(10^5,0,10^5,0,\dots)$，$N=10^5$：每个 $10^5$ 都是上升沿，答案 $=5\times 10^4\times 10^5=5\times 10^9$，**超过 `int` 上限 $2.147\times 10^9$ 两倍多**。必须 `long long`。我专门造了这组极限数据验证。

## 二、思维链：完整证明

**记号。** $a=(a_1,\dots,a_N)$，$a_i\ge 0$，约定 $a_0=0$。差分 $d_i=a_i-a_{i-1}$（$1\le i\le N$），另记 $d_{N+1}=-a_N$（相当于 $a_{N+1}=0$）。操作 $[l,r]$（$1\le l\le r\le N$）：$a_i\leftarrow a_i-1$（$l\le i\le r$），要求操作前这些位置都 $\ge 1$。定义**势函数**
$$P(a)=\sum_{i=1}^{N}\max(0,d_i).$$
（把 $d_{N+1}$ 加进求和也不变，因为 $d_{N+1}=-a_N\le 0$。）

---

### 引理 1（操作的差分效应）

对 $a$ 施行 $[l,r]$ 减 $1$ 后，新差分为：$d_l'=d_l-1$；若 $r+1\le N+1$ 则 $d_{r+1}'=d_{r+1}+1$；其余 $d_i'=d_i$。

*证明*：逐位核对 $d_i'=a_i'-a_{i-1}'$。$i<l$：两项都没变 ✓。$i=l$：$a_l$ 减 $1$、$a_{l-1}$ 不变，$d_l'=d_l-1$ ✓。$l<i\le r$：两项都减 $1$，差不变 ✓。$i=r+1$：$a_{r+1}$ 不变（或视为 $a_{N+1}=0$ 不变）、$a_r$ 减 $1$，$d_{r+1}'=d_{r+1}+1$ ✓。$i>r+1$：两项都不变 ✓。证毕。

---

### 引理 2（下界：任何清空方案至少 $P(a)$ 步）

设 $a$ 经 $t$ 次合法操作变成全 $0$，则 $t\ge P(a)$。

*证明*：先证 $P(\mathbf 0)=0$ 且 $P(a)=0\iff a=\mathbf 0$。全 $0$ 时所有 $d_i=0$，$P=0$ ✓。反之若 $P(a)=0$，则所有 $d_i\le 0$，即 $a_i\le a_{i-1}$；从 $a_0=0$ 递推得 $a_i\le 0$，又 $a_i\ge 0$，故全 $0$ ✓。

再证**每次操作使 $P$ 至多减少 $1$**。由引理 1，操作只改 $d_l$（减 $1$）与 $d_{r+1}$（加 $1$）。函数 $x\mapsto\max(0,x)$ 单调不减：$d_{r+1}$ 加 $1$ 使该项 $\max$ **不减**（变化 $\ge 0$）；$d_l$ 减 $1$ 使该项 $\max$ 至多减 $1$（$\max(0,x)-\max(0,x-1)\in\{0,1\}$）。故 $\Delta P\ge -1$。

于是 $0=P(\text{终})\ge P(a)-t$，即 $t\ge P(a)$。证毕。

---

### 引理 3（极长正段贪心每步恰好削 $1$）

设 $a\ne\mathbf 0$。则存在区间 $[l,r]$ 使 $a_l,\dots,a_r\ge 1$ 且 $a_{l-1}=0$（$l=1$ 时由 $a_0=0$ 自动满足）、$a_{r+1}=0$（$r=N$ 时由 $a_{N+1}=0$ 自动满足）。对这样的**极长正段**施行 $[l,r]$ 操作合法，且 $P$ 恰好减少 $1$。

*证明*：存在性：取任一 $a_i>0$，向左扩展到第一个 $0$（或边界）、向右同理，得到的段两端都顶着 $0$，段内全正。合法性：段内全 $\ge 1$，减 $1$ 后仍 $\ge 0$ ✓。

计算 $\Delta P$：由引理 1，只动 $d_l,d_{r+1}$。
- $d_l=a_l-a_{l-1}=a_l\ge 1>0$，减 $1$ 后 $d_l'=a_l-1\ge 0$，故 $\max(0,d_l')-\max(0,d_l)=-1$。
- $d_{r+1}=a_{r+1}-a_r=-a_r\le -1<0$，加 $1$ 后 $d_{r+1}'=1-a_r\le 0$，故两项 $\max$ 都是 $0$，变化 $0$。

合计 $\Delta P=-1$。证毕。

---

### 引理 4（上界：$P(a)$ 步可达）

反复执行引理 3 的极长正段操作，恰 $P(a)$ 步后 $a=\mathbf 0$。

*证明*：由引理 2 的等价刻画，$a\ne\mathbf 0\iff P(a)>0$（$P$ 是非负整数）。只要 $P>0$，引理 3 保证存在合法操作使 $P$ 减 $1$。故 $P$ 严格递减，恰 $P(a)$ 步后到 $0$，此时 $a=\mathbf 0$。证毕。

**推论（贪心不失败的刻画）**：任何"每步都选极长正段"的策略都是最优的，与选哪个正段、先后顺序无关；而选非极长段（左端不是上升沿或右端不是下降沿）可能一步只削 $0$，导致浪费。

---

### 引理 5（公式化简）

$P(a)=\sum_{i=1}^{N}\max(0,\ a_i-a_{i-1})$，其中 $a_0=0$。特别地，$i=1$ 项就是 $a_1$。

*证明*：这就是 $P$ 的定义展开；$d_{N+1}=-a_N\le 0$ 对正部和无贡献，故求和只需到 $N$。$a_1-a_0=a_1\ge 0$，$\max$ 可去掉。证毕。

---

### 引理 6（数值范围：必须 64 位）

答案上界为 $5\times 10^9$（在 $N=10^5,a_i\le 10^5$ 下），超过 `int` 上限；`long long` 安全。

*证明*：每个正差分 $\le 10^5$；正差分出现的次数 $\le\lceil N/2\rceil$（两个正差分之间至少隔一个非正差分？不必——更松的界：正差分个数 $\le N$）。直接用构造定界：取 $a=(10^5,0,10^5,0,\dots)$（$N=10^5$，共 $5\times 10^4$ 个峰），每个峰贡献 $10^5$，答案 $=5\times 10^4\times 10^5=5\times 10^9>2^{31}-1\approx 2.15\times 10^9$。故 `int` **必然**在此合法输入上溢出。另一方面 $P(a)\le\sum_i a_i\le 10^{10}\ll 9.2\times 10^{18}$，`long long` 绰绰有余。证毕。

---

### 引理 7（复杂度）

时间 $O(N)$，空间 $O(N)$（流式读入可降到 $O(1)$）。

*证明*：读入 $O(N)$；公式一遍扫描，每项一次减法、一次 $\max$、一次加法，$O(N)$。存 `a` 数组 $O(N)$；若边读边算只需记住前一个值，$O(1)$。证毕。

---

### 定理

最少顺子数 $=\sum_{i=1}^{N}\max(0,a_i-a_{i-1})$（$a_0=0$），用 `long long` 累加，$O(N)$ 时间。

*证明*：引理 1 给出操作的差分刻画；引理 2 证下界 $t\ge P(a)$；引理 3、4 构造出恰 $P(a)$ 步的方案，上下界夹逼得最优值 $=P(a)$；引理 5 化简成一行公式；引理 6 保证 `i64` 不溢出；引理 7 给出复杂度。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 顺子 = 区间减 $1$（每种牌面各一张），清空手牌 = 把 $a$ 减成全 $0$；反向看就是区间加 $1$ 堆直方图。
2. **classic problem solution** — 认出积木大赛（P1969）模型：最少区间加次数 = 差分数组正部之和。
3. **explore its property** — 手算 Hint 反推出 $a=(2,4,1,2,3)$，上升沿之和 $2+2+1+1=6$ 与答案吻合，确立猜想。
4. **reduce to easier problem** — 区间操作在差分上只动两个端点 ⇒ 用势函数 $P=\sum\max(0,d_i)$ 统一度量进度。
5. **explore its property** — 下界：每步至多削 $1$ 的 $P$（$\max(0,x)$ 单调 + 单点减 $1$ 至多降 $1$）；上界：极长正段操作恰好削 $1$（左端正差分、右端负差分），夹逼得证。
6. **discuss by category** — 贪心失败模式 = 顺子端点不顶在上升/下降沿上；极长正段贪心天然避开。
7. **explore its property** — 范围核对：交错峰值数据答案 $5\times 10^9$，`int` 必炸，`i64` 必需。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n` | 牌面种数 $N\le 10^5$ | `int` | 读入 |
| `a[i]` | 牌面 $i+1$ 的张数（0-based） | `int[mxn]` | 读入；$a_0=0$ 是虚拟边界，不占数组 |
| `ans` | $\sum\max(0,a_i-a_{i-1})$ | `i64` | 默认 $0$；**必须 64 位**（引理 6） |
| `mxn` | $10^5+5$ | `constexpr int` | 数组尺寸 |

### 算法步骤

1. I/O 加速三行；读 $N$ 与 $a_0..a_{N-1}$。
2. 对 $i=0..N-1$：`ans+=max(0,a[i]-(i?a[i-1]:0))`（$i=0$ 时前驱取虚拟 $0$）。
3. 输出 `ans`。

### 复杂度

- 时间：$O(N)$；$N=10^5$ 时约 $10^5$ 次运算。
- 空间：$O(N)$（`a` 数组）；流式可 $O(1)$。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；五组手造数据（Hint 反推 / 全零 / 平台 / 双峰 / $N=10^5$ 交错极限）输出 $6,0,5,200000,5000000000$ 全部与手算一致，极限组确认 `i64` 必要。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3078 [USACO13MAR] Poker Hands S
// 顺子 = 区间减 1；最少操作数 = 差分数组正部之和（积木大赛模型）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n,a[mxn];
i64 ans;	// 正差分和最大约 5e9，int 会溢出

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0;i<n;++i)
		ans+=max(0,a[i]-(i?a[i-1]:0));	// a[0] 前虚拟一个 0
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- 核心只有一行：`ans+=max(0,a[i]-(i?a[i-1]:0))`。`i?…:0` 实现虚拟边界 $a_0=0$，第一项恰好是 $a_1$（首列高度必须全部由新顺子开头）。
- `ans` 用 `i64`：交错数据 $(10^5,0,10^5,0,\dots)$ 的答案 $5\times 10^9$ 超 `int` 两倍多，这是本题唯一的硬坑。
- 不需要真的构造顺子方案：引理 3、4 保证方案存在，题目只问数量。
- 全程无 INF、无哨兵：$\max$ 与求和的初值 $0$ 都是合法单位元。
