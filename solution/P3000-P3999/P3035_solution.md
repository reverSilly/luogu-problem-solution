# P3035 [USACO11DEC] Umbrellas for Cows S — 题解

## 一、解题过程：人类思考叙事

**题意重述。** 数轴上 $1..M$（$M\le10^5$）有 $M$ 个牛棚，其中 $N$ 个（$N\le5000$）站着牛，坐标 $X_i$ 互不相同。买一把宽度 $W$ 的伞花费 $C_W$（$1\le C_W\le10^6$），它可以盖住任意一段长度为 $W$ 的连续坐标区间。**$C_W$ 不保证随 $W$ 单调**——大伞可能比小伞便宜。伞可以重叠。求盖住所有牛的最小总花费。

**口径说明。** 题面说伞"覆盖范围从 $X_i$ 到 $X_j$，宽度 $X_j-X_i+1$"，即伞是整数端点的闭区间、端点可自由放置。本文按此理解：买宽度 $W$ 的伞后可任选左端点 $l$，盖住 $[l,l+W-1]$。最优解总能把端点对齐到牛的坐标（见引理 2 的收缩步骤），所以"端点是否必须落在牛棚上"不影响答案。

**第一步：题目为什么特意提醒"最优解可能重叠"？** 因为 $C$ 不单调。造一组小数据：牛在 $1,2,3$，$C_1=10,C_2=1,C_3=100$。买两把宽度 $2$ 的伞 $[1,2]$ 和 $[2,3]$，花费 $2$，在牛 $2$ 处重叠；若强行要求"每头牛恰好被一把伞盖、伞不重叠"，只能 $\{1,2\}+\{3\}$ 花 $1+10=11$，或 $\{1\}+\{2,3\}$ 花 $11$，或一把宽度 $3$ 花 $100$。**原始代价下，重叠确实严格更优**，直接写"分段 DP"会错。

**第二步：把"大伞小用"合法化——后缀最小化。** 重叠之所以划算，本质是"宽度 $2$ 的伞便宜，我买它来盖宽度 $1$ 的活"。那就预先定义**有效代价**
$$c[w]=\min_{w'\ge w}C_{w'},$$
即"盖住宽度 $w$ 的一段所需的最少钱"。上例中 $c[1]=\min(10,1,100)=1$。这一步之后 $c$ **单调不增**，且原问题与"按 $c$ 计价"的问题最优值相同（引理 1：两边互相模拟）。于是"买大伞盖小段"被折算进了单价，不再需要靠重叠来表达。

**第三步：单调化之后，还需要重叠吗？** 不需要——这是本题的核心引理（引理 2，交换论证）：当单价单调不增时，任何最优解都可以"解交叉"：两把伞的区间若相交，就把交叠区的牛全划给右边那把、左边的牛留给左边那把，两把伞各自收缩到仍覆盖所分到的牛。收缩只会让宽度变小、花费不增；若左伞收缩后没牛可盖就扔掉它，花费严格下降。反复操作后得到**互不相交、每把伞恰好盖住排序后一段连续牛**的最优解。上例中 $c=(1,1,100)$，分段 $\{1,2\}+\{3\}$ 花 $c[2]+c[1]=2$，追平了重叠解。

**第四步：经典线性划分 DP。** 把牛坐标排序得 $x_0<x_1<\dots<x_{N-1}$。最优解 = 把序列切成若干连续段，每段一把伞、宽度 = 段首尾坐标差 $+1$、花费 $c[\text{宽度}]$。设 $dp[i]$ 为盖住前 $i$ 头牛的最小花费：
$$dp[0]=0,\qquad dp[i]=\min_{0\le j<i}\bigl(dp[j]+c[x_{i-1}-x_j+1]\bigr).$$
枚举最后一段的起点 $j$ 即可。$O(N^2)=2.5\times10^7$ 量级（实际只算 $j<i$ 的一半），通过。

**第五步：两个必须抠的细节。**

1. **溢出**：总花费上界 $N\cdot\max C=5000\times10^6=5\times10^9$，超 `int`，`dp` 必须 `long long`。
2. **宽度范围**：段宽 $x_{i-1}-x_j+1\le M$，所以 $c$ 数组开到 $M$ 就够，后缀最小化从 $M-1$ 倒着扫到 $1$。

**手造数据核对**（题面只给样例解释，没给样例输入输出）：

第一组，按样例解释反推：$N=6,M=12$，牛在 $1,2,4,8,11,12$；解释明说"宽度 $4$ 的伞花 $4$、宽度 $1$ 花 $2$、宽度 $2$ 花 $3$，总花费 $4+2+3=9$"。注意这与"覆盖 $1$ 个花 $2$、$2$ 个花 $3$、以此类推"（即 $C_W=W+1$）在 $W=4$ 处矛盾（$W+1=5\ne4$），**以显式数字为准**，取 $C=(2,3,4,4,5,6,7,8,9,10,11,12)$。分段 $\{1,2,4\}$（宽 $4$ 花 $4$）$+\{8\}$（宽 $1$ 花 $2$）$+\{11,12\}$（宽 $2$ 花 $3$）$=9$。程序输出 `9` ✓。

第二组（专打非单调）：$N=2,M=3$，牛在 $1,3$，$C=(5,100,2)$。后缀最小化后 $c=(2,2,2)$，一把宽 $3$ 的伞花 $2$ 盖两头牛。程序输出 `2` ✓（不做后缀最小化会输出 $10$）。

第三组（专打重叠反例）：$N=3,M=3$，牛在 $1,2,3$，$C=(10,1,100)$。程序输出 `2` ✓，与手工分析的重叠最优一致。

第四组（单牛）：$N=1,M=1$，牛在 $1$，$C_1=7$，输出 `7` ✓。

## 二、思维链：完整证明

**记号。** 牛坐标排序后 $x_0<x_1<\dots<x_{N-1}$（互异，题面保证）。伞 = 整数端点闭区间 $[l,r]$，宽度 $w=r-l+1\in[1,M]$，原始单价 $C_w$，有效单价 $c[w]=\min_{w'\ge w}C_{w'}$。一个"购买方案"是若干伞的多重集，合法当且仅当每头牛的坐标落在至少一把伞内；花费为单价之和。

### 引理 1（后缀最小化不改变最优值，且 $c$ 单调不增）

按 $C$ 计价的原问题与按 $c$ 计价的问题最优值相等；且 $w_1<w_2\Rightarrow c[w_1]\le c[w_2]$。

*证明*：记两问题最优值为 $\mathrm{opt}_C,\mathrm{opt}_c$。

**$\mathrm{opt}_c\le\mathrm{opt}_C$**：$c[w]\le C_w$（取 $w'=w$ 即知），故原问题的任何合法方案在新计价下花费不增，$\mathrm{opt}_c\le\mathrm{opt}_C$。

**$\mathrm{opt}_C\le\mathrm{opt}_c$**：取新问题的最优方案。其中每把宽度 $w$ 的伞花费 $c[w]=C_{w'}$（某个 $w'\ge w$，最小值在有限集上取到）。把它替换成宽度 $w'$、**左端点相同**的伞：新区间 $[l,l+w'-1]\supseteq[l,l+w-1]$，覆盖只增不减，花费 $C_{w'}=c[w]$ 不变。逐把替换后得到原问题的合法方案，花费相同，故 $\mathrm{opt}_C\le\mathrm{opt}_c$。

两向夹逼得相等。单调性：$w_1<w_2$ 时 $\{w'\ge w_2\}\subseteq\{w'\ge w_1\}$，子集上的最小值不小于全集上的最小值，即 $c[w_2]\ge c[w_1]$。证毕。

**推论**：此后只需研究单价单调不增的问题；"买大伞盖小段"已被 $c$ 吸收。

### 引理 2（解交叉：单调单价下存在"连续分段"最优解）

设单价函数 $c$ 单调不增且 $c[w]\ge1$。则存在一个最优方案，满足：(a) 每把伞覆盖的牛集合非空；(b) 各伞覆盖的牛集合两两不交，且按坐标排序后每把伞的牛构成一段**连续区间**；(c) 每把伞的区间恰为 $[\text{段首牛坐标},\text{段尾牛坐标}]$。

*证明*：在所有最优方案中取**总宽度最小**者（宽度为正整数，最小值存在），再取其中伞数最少者。

**预备（收缩与清理）**：把每头牛任意指派给一把盖住它的伞。若某伞没分到牛，删去它，花费严格减少（$c\ge1$），与最优矛盾，故每伞至少一头牛。把每把伞收缩为其所分到的牛的最小、最大坐标张成的区间：宽度不增，由单调性花费不增，故仍最优；若宽度严格减小则与"总宽度最小"矛盾，所以收缩后每把伞的端点就是其首尾牛坐标，(a)(c) 的形态已就绪。

**主步骤（无两伞区间相交）**：反设存在两伞区间 $[l_1,r_1],[l_2,r_2]$ 相交，不妨 $l_1\le l_2$，则 $l_2\le r_1$（相交；包含关系 $r_2\le r_1$ 也涵盖在内）。重新指派：**坐标 $<l_2$ 的牛全归伞 1，坐标 $\ge l_2$ 的牛全归伞 2**（只考虑原来被这两把伞之一盖住的牛，其余伞不动）。

- 覆盖不变：原来被两伞之一盖住的牛恰在 $[l_1,r_1]\cup[l_2,r_2]=[l_1,r_2]$ 内。其中坐标 $<l_2$ 的牛不可能原属伞 2（伞 2 的牛 $\ge l_2$），故原属伞 1、坐标 $\ge l_1$，新伞 1 收缩后仍盖住它；坐标 $\ge l_2$ 的牛 $\le r_2$，新伞 2 仍盖住它。
- 新伞 1 的区间 $\subseteq[l_1,r_1]$：其最右牛 $<l_2\le r_1$。新伞 2 的区间 $\subseteq[l_2,r_2]$：其牛都在原伞 2 范围内。故两伞宽度都不增，花费不增，方案仍最优。
- 若 $[l_1,l_2)$ 内没有牛：新伞 1 为空，删去它，花费严格下降，与最优矛盾。
- 若 $[l_1,l_2)$ 内有牛：新伞 1 的右端点 $\le l_2-1<r_1$（因 $l_2\le r_1$），宽度**严格减小**；新伞 2 宽度不增。总宽度严格减小而花费不增（仍最优），与"总宽度最小"矛盾。

两种情况都矛盾，故最优方案中任意两伞区间不相交。区间不相交 $\Rightarrow$ 各伞的牛集合按坐标完全分离 $\Rightarrow$ 排序后每伞的牛是连续一段（中间不会插入别伞的牛），(b) 成立。证毕。

**注**：单调性是本引理的命脉。$C$ 不单调时收缩可能**涨价**，引理失效——这正是 Part 1 重叠反例（$C=(10,1,100)$）的根源；先做引理 1 的后缀最小化，才换来引理 2 的分段结构。

### 引理 3（划分 DP 的正确性）

设 $dp[0]=0$，$dp[i]=\min_{0\le j<i}\bigl(dp[j]+c[x_{i-1}-x_j+1]\bigr)$（$1\le i\le N$）。则 $dp[i]$ 等于盖住前 $i$ 头牛（排序后）的最小花费，且所有下标合法：$1\le x_{i-1}-x_j+1\le M$。

*证明*：下标：$j\le i-1$ 且坐标互异递增 $\Rightarrow x_{i-1}\ge x_j\Rightarrow$ 宽度 $\ge1$；坐标 $\in[1,M]\Rightarrow$ 宽度 $\le M$ ✓。

对 $i$ 归纳证明 $dp[i]$ 正确。$i=0$：无牛，花费 $0$ ✓。设 $dp[0..i-1]$ 正确。

**$\le$**：对任意 $j<i$，"前 $j$ 头牛的最优分段方案 + 一把盖 $[x_j,x_{i-1}]$ 的伞"是前 $i$ 头牛的合法方案（引理 2 形态），花费 $dp[j]+c[x_{i-1}-x_j+1]$，故真实最优 $\le$ 右式对所有 $j$ 的最小值。

**$\ge$**：取前 $i$ 头牛的一个最优方案，由引理 2（把它限制在前 $i$ 头牛上：引理 2 的构造只涉及被盖住的牛，对子集同样适用）可设它是连续分段。设最后一段为第 $j..i-1$ 头牛（$0\le j<i$），该段伞宽 $x_{i-1}-x_j+1$、花费 $c[\cdot]$；前面各段构成前 $j$ 头牛的合法方案，其花费 $\ge dp[j]$（归纳假设：$dp[j]$ 是最小值）。故真实最优 $\ge dp[j]+c[x_{i-1}-x_j+1]\ge$ 右式最小值。

两向夹逼，$dp[i]$ 正确。证毕。

### 引理 4（复杂度与数值范围）

时间 $O(N^2+M)$，空间 $O(N+M)$；答案 $\le N\cdot\max_wC_w\le5\times10^9$，须用 64 位整数累加。

*证明*：排序 $O(N\log N)$；后缀最小化扫 $M-1$ 次 $O(M)$；DP 双重循环 $\sum_{i=1}^N i=N(N+1)/2\le1.25\times10^7$ 次 $O(1)$ 转移；合计 $O(N^2+M)$。空间：$x$ 数组 $N$、$c$ 数组 $M+1$、$dp$ 数组 $N+1$。数值：每头牛至少被一把伞盖，最优方案伞数 $\le N$（引理 2 形态下每段一把），每把花费 $\le\max C\le10^6$，故答案 $\le5000\times10^6=5\times10^9>2^{31}-1\approx2.15\times10^9$，`int` 会溢出，`dp` 用 `long long`（哨兵 $1145141919810$ 远大于任何真实答案）。证毕。

### 定理

程序输出盖住所有牛的最小花费，复杂度 $O(N^2+M)$。

*证明*：引理 1 保证后缀最小化不改最优值、并赋予单价单调性；引理 2 在单调单价下把最优解归约为连续分段形态；引理 3 保证分段 DP 逐状态正确、下标合法；引理 4 保证复杂度与 64 位累加不溢出。串联即得。证毕。

## 三、模式总结（按实际思考顺序）

1. **explore its property** — 伞是区间、牛是点；$C_W$ 不单调 ⇒ "恰好盖住一段"的贪心/直接分段都不安全。
2. **explore its property** — 重叠反例 $C=(10,1,100)$：原始单价下重叠严格更优，说明必须先改造单价。
3. **classic problem solution** — 后缀最小化 $c[w]=\min_{w'\ge w}C_{w'}$，把"大伞小用"折进单价，$c$ 单调不增且最优值不变。
4. **reduce to easier problem** — 交换论证（解交叉 + 收缩）：单调单价下存在最优解 = 排序牛的连续分段，每段一把伞 ⇒ 区间覆盖塌缩成线性划分。
5. **classic problem solution** — 划分 DP $dp[i]=\min_j dp[j]+c[x_{i-1}-x_j+1]$，$O(N^2)$。
6. **discuss by category** — 答案上界 $5\times10^9$ 用 `i64`；段宽 $\le M$ 保证 $c$ 下标合法；$N=1$、全 $C=1$ 等边界自然覆盖。

## 四、解法说明

### 符号表

| 符号 | 含义 | 类型 | 初值 / 记忆点 |
|------|------|------|---------------|
| `n,m` | 牛数 $N\le5000$、坐标/宽度上界 $M\le10^5$ | `int` | 读入 |
| `x[i]` | 第 $i$ 头牛坐标（**读入后排序**） | `int[mxn]` | 0-based，互异 |
| `c[w]` | 宽度 $w$ 的**有效单价** $\min_{w'\ge w}C_{w'}$ | `int[mxm]` | 先读入原始 $C_w$，再倒序后缀 `min`；$w\in[1,M]$ |
| `dp[i]` | 盖住排序后前 $i$ 头牛的最小花费 | `i64[mxn]` | `fill` 成 `inf`，`dp[0]=0`；**i64 防 $5\times10^9$ 溢出** |
| `inf` | $1145141919810$ | `constexpr i64` | 远大于任何真实答案 |
| `mxn,mxm` | $5005$、$100005$ | `constexpr int` | 约束 $+5$ |

### 算法步骤

1. I/O 加速三行；读 `n,m`、`x[0..n-1]`、`c[1..m]`（此时 `c` 存原始 $C$）。
2. `sort(x,x+n)`。
3. 后缀最小化：`for w=m-1..1: c[w]=min(c[w],c[w+1])`。
4. `dp[0]=0`，其余 `inf`；对 `i=1..n`、`j=0..i-1`：`dp[i]=min(dp[i],dp[j]+c[x[i-1]-x[j]+1])`。
5. 输出 `dp[n]`。

### 复杂度

- 时间：$O(N^2+M)\approx1.25\times10^7+10^5$。
- 空间：$O(N+M)\approx0.6$ MB。
- 验证状态：`g++ -std=c++20 -O2` 编译通过；样例解释反推数据输出 `9` ✓；非单调数据 `2 3 / 1 3 / 5 100 2` 输出 `2` ✓；重叠反例 `3 3 / 1 2 3 / 10 1 100` 输出 `2` ✓；单牛输出 `7` ✓；极限 $N=5000,M=10^5$：全 $C=1$ 输出 `1`、$C_w=w$ 输出 `5000`，均与手工分析一致 ✓。

## 五、示例代码（C++，Louis Li 风格）

```cpp
// 题目：P3035 [USACO11DEC] Umbrellas for Cows S
// 后缀最小化 c[w]=min_{w'>=w}C[w'] ⇒ 存在"连续分段"最优解 ⇒ dp[i]=min dp[j]+c[跨度]
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{5005},mxm{100005};
constexpr i64 inf{1145141919810};

int n,m,x[mxn],c[mxm];
i64 dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>x[i];
	for(int w=1;w<=m;++w)
		cin>>c[w];
	sort(x,x+n);
	for(int w=m-1;w>=1;--w)
		c[w]=min(c[w],c[w+1]);	// 大伞能盖小范围，有效代价单调不增
	fill_n(dp,n+1,inf);
	dp[0]=0;
	for(int i=1;i<=n;++i)
		for(int j=0;j<i;++j)
			dp[i]=min(dp[i],dp[j]+c[x[i-1]-x[j]+1]);	// 最后一段伞盖第j..i-1头牛
	cout<<dp[n]<<'\n';
	return 0;
}
```

### 代码说明

- `c` 数组一物两用：先存原始 $C_w$，后缀 `min` 原地变成有效单价。倒序扫描保证 `c[w+1]` 已是后缀最小值。
- **不做后缀最小化直接 DP 是错的**（重叠反例输出 $11$ 而非 $2$）；**不做交换论证直接假设分段也是错的**——两者缺一不可，顺序也不能反（先单调化，分段才成立）。
- `dp` 用 `i64`：$5000\times10^6=5\times10^9$ 超 `int`。`c` 本身 $\le10^6$，`int` 够用；`dp[j]+c[...]` 中 `c` 自动提升为 `i64`。
- `x[i-1]-x[j]+1` 是最后一段（第 $j..i-1$ 头牛，0-based）的跨度，$\in[1,M]$，`c` 下标安全。
- `dp` 仍按惯例 `fill` 成 `inf`：虽然本题所有 `dp[i]` 都可达（每头牛单独一把伞），显式初始化是防御性习惯，也避免"全局默认 0"类陷阱。
- $O(N^2)$ 内层只做一次加法一次 `min`，$1.25\times10^7$ 次，无需进一步优化。
