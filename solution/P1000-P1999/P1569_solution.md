# P1569 [USACO11FEB] Generic Cow Protests

> 标签：动态规划 DP / USACO / 前缀和 · 难度：普及-
> 本地题面：`P1569.md`（$1\le n\le 1000$，$|a_i|\le 10^5$，每组理智度之和须 $\ge 0$）。
> 验证：300 组随机用例 + 6 组手工边界，标程与暴力逐字节一致；$n=1000$ 最坏规模 0.0059s。

## 1. 重新读题

**问题重述（人话版）**

$n$ 头奶牛按顺序站成一列，第 $i$ 头理智度 $a_i$（可正可负、也可为 $0$）。要把**整列**奶牛切成若干段连续的区间（每头奶牛恰好属于一段，不能跳、不能重排）。要求：**每一段的理智度之和 $\ge 0$**。问最多能切成几段；若怎么做都做不到，输出 `Impossible`。

> 一句话版本：**把数组 $a$ 切成尽量多的连续段，使每一段的和非负**。

**容易漏掉的条款**

1. 「一些小组」$\Rightarrow$ 每组至少一头牛（空组不算），组数上限为 $n$。
2. 「位置必须是连续的」$\Rightarrow$ 每个小组是原序列的一个连续子数组，全体小组按原顺序恰好覆盖第 $1$ 到第 $n$ 头牛，等价于在序列上放若干「切点」。
3. 「输出 `Impossible`」$\Rightarrow$ 注意拼写（首字母大写、其余小写），且它**只在真的无解时出现**，而不是"答案为 $0$"时。本题答案最小为 $1$（把全体当一组）——只要总和非负，就不存在输出 $0$ 的情况。
4. $|a_i|\le 10^5$ 且允许为负 $\Rightarrow$ 总和可能为负，这正是唯一的无解来源（见引理 3）。

**数据范围与规模感受**

$$1\le n\le 1000,\qquad |a_i|\le 10^5.$$

前缀和 $|pre_i|\le 1000\times 10^5=10^8$，$n^2=10^6$，$O(n^2)$ 的 DP 完全够用；而分段方案共 $2^{n-1}$ 种，纯枚举必挂。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"分组"翻译成"切点链"

设切点为

$$0=p_0<p_1<p_2<\dots<p_k=n,$$

第 $t$ 组就是下标区间 $(p_{t-1},\,p_t]$（左开右闭），组数就是 $k$。

**引理 1（分组 $\leftrightarrow$ 切点链）**

"把第 $1\dots n$ 头牛切成 $k$ 个连续小组"与"选取切点链 $0=p_0<\dots<p_k=n$"一一对应。

**证明**：给定一个分组，取每组的右端点依次为 $p_1,\dots,p_k$（最后一组右端必为 $n$，最前一组左端必为 $1$，即 $p_0=0$），得到严格递增、首 $0$ 尾 $n$ 的切点链；反过来给定切点链，令第 $t$ 组为 $(p_{t-1},p_t]$，即得一个连续分组。两个映射互为逆，故为双射。$\blacksquare$

**引理 2（组和 = 前缀和之差）**

记 $pre_i=\sum_{j=1}^{i}a_j$（约定 $pre_0=0$）。第 $t$ 组的和为

$$S_t=\sum_{j=p_{t-1}+1}^{p_t}a_j=pre_{p_t}-pre_{p_{t-1}}.$$

**证明**：由前缀和定义 $pre_{p_t}=pre_{p_{t-1}}+\sum_{j=p_{t-1}+1}^{p_t}a_j$，移项即得该式。$\blacksquare$

于是"每组非负"就等价于**前缀和序列恰好在切点处非降**：

$$pre_{p_0}\le pre_{p_1}\le\dots\le pre_{p_k}.$$

这一步把"分组"彻底翻译掉了：题目剩下的唯一自由度，就是**在 $pre$ 上挑一条从下标 $0$ 到下标 $n$、取值非降的子序列**，最大化它的长度减一（即组数）。

### 2.2 先解决"是否有解"：无解的充要条件

**引理 3（存在合法分组 $\iff$ $pre_n\ge 0$）**

合法分组存在，当且仅当全列总和 $pre_n\ge 0$。

**证明**：
- （$\Rightarrow$）若存在合法分组 $0=p_0<\dots<p_k=n$，则 $pre_n=\sum_{t=1}^{k}S_t\ge 0$，因为每个 $S_t\ge 0$，有限个非负数之和自然非负。
- （$\Leftarrow$）若 $pre_n\ge 0$，取 $k=1$、切点链 $0<n$，唯一一组的和正好是 $pre_n\ge 0$，合法。故存在。$\blacksquare$

**推论**：输出 `Impossible` 当且仅当 $pre_n<0$。这就是题面里那个"否则"分支的全部内容。

> 这是第一处降维：先别急着求最大组数，**先确认无解条件**，它把输出格式里那个吓人的 `Impossible` 变成一个平凡的符号判断。

### 2.3 求最大组数：先看清贪心的失败，再上 DP

最自然的贪心是**从左往右，能切就尽早切**（当前段和一旦 $\ge 0$ 就立即断开）。它错在哪？看反例

$$a=[3,-2,-2,3],\qquad pre=[0,3,1,-1,2],\qquad pre_n=2\ge 0.$$

- 贪心（尽早切）：$pre_1=3\ge 0$，第一刀切在下标 $1$；从 $pre_1=3$ 出发要找 $pre\ge 3$ 的后继，但 $pre_2=1,\ pre_3=-1,\ pre_4=2$ 全小于 $3$，**卡死**，只能退回把整体当一组，得 $1$ 组。
- 真正的最优：切点在 $0\to 2\to 4$，即 $pre_0=0\le pre_2=1\le pre_4=2$，两组 $[3,-2]=1$、$[-2,3]=1$，得 $\mathbf{2}$ 组。

贪心失败的原因是：**当前切得越早，后续可用的 $pre$ 下限被抬得越高，可能把后面的路堵死**。局部最优不等于全局最优，所以必须存下"每个前缀的最佳状态"——这就是 DP。

定义 $dp_i$ = 把前 $i$ 头牛切成合法小组所能取得的**最大组数**；若前 $i$ 头牛根本无法合法分组，则记 $dp_i=-\infty$。

**引理 4（DP 转移）**

$$dp_i=\max\Big\{\,dp_j+1\ \Big|\ 0\le j<i,\ dp_j\ne-\infty,\ pre_j\le pre_i\,\Big\}\qquad(i\ge 1),$$

并有 $dp_0=0$；若右侧大括号为空，则 $dp_i=-\infty$。

**证明**（对 $i$ 归纳，双向包含）：
- **（上界方向）** 任取前 $i$ 头牛的一个合法分组 $0=p_0<\dots<p_k=i$。其最后一段是 $(p_{k-1},i]$；由引理 2 该段非负当且仅当 $pre_{p_{k-1}}\le pre_i$，且它的前 $k-1$ 段是前 $p_{k-1}$ 头牛的一个合法分组，故由归纳假设 $k-1\le dp_{p_{k-1}}$。于是组数 $k\le dp_{p_{k-1}}+1$ 落在转移的候选集合中，所以 $dp_i\ge k$。由分组任意性，$dp_i$ 不小于任何合法分组的组数。
- **（可达方向）** 任取候选 $j$ 满足 $j<i$、$dp_j\ne-\infty$、$pre_j\le pre_i$。由归纳假设存在前 $j$ 头牛的一个合法分组（组数 $dp_j$；$j=0$ 时取空前缀、$dp_0=0$，空分组合法）。又 $pre_j\le pre_i$ 使追加段 $(j,i]$ 非负，于是拼接得到前 $i$ 头牛的一个合法分组，组数 $dp_j+1$。故每个候选都真实可达，$dp_i$ 不小于候选中的最大值。
- 两方向合并：合法分组所能达到的最大组数恰为候选集合的最大值。$\blacksquare$

（代码里用 $-1$ 表示 $-\infty$：可达状态的 $dp_j+1$ 必 $\ge 1>0$，$0$ 只可能由 $dp_0$ 贡献。）

**引理 5（答案公式）**

最大组数 $=dp_n$；$dp_n=-\infty$ 时无解。

**证明**：由引理 4，$dp_n$ 按定义的语义就是"前 $n$ 头牛（即全体）合法分组的最大组数"，正是所求。无解时不存在任何合法分组，$dp_n$ 的候选集合为空，故 $dp_n=-\infty$。再由引理 3，$dp_n=-\infty\iff pre_n<0$，两种判定完全一致。$\blacksquare$

### 2.4 复杂度检查

- 时间：转移是 $i$ 与 $j$ 的二重循环，$O(n^2)\le 10^6$。
- 空间：$pre,dp$ 各一个 $O(n)$ 数组。

$n\le1000$ 时 $10^6$ 毫无压力，不需要任何数据结构优化。只有把 $n$ 放大到 $10^5$ 时，才需要用树状数组按 $pre$ 的值域维护"所有 $pre_j\le pre_i$ 的 $dp_j$ 最大值"；本题不需要。

### 2.5 失败思路小结

- **贪心尽早切**：反例 $a=[3,-2,-2,3]$ 见上，会卡死只得 $1$ 组，而正解是 $2$ 组。
- **把 `Impossible` 当成"答案为 $0$"**：本题答案至少为 $1$，永远不该输出 $0$；`Impossible` 只在总和为负时出现。
- **忘记把不可达状态排除**：若用全局 `int dp[mxn]`（默认全 $0$）而不显式置成 $-1$，则"不可达 $(=-\infty)$"会与 $dp_0=0$ 的合法零值混淆，把非法前缀当成可达，答案静默偏大。

## 3. 模式总结（Pattern Summary）

- explore its property — 把"连续分组"翻译成"切点链"，把"每段和非负"翻译成"前缀和序列在切点处非降"。
- consider easier version — 先剥离"最多几组"，只问"有没有解"，得到充要条件 $pre_n\ge 0$（引理 3），把 `Impossible` 化为平凡判断。
- identify failure of greedy — 用反例证明"尽早切"会卡死，暴露"切点越早、后续 $pre$ 下限越高"的耦合。
- classic problem solution — 在 $pre$ 上求"必以 $n$ 结尾的最长非降子序列"式 DP：$dp_i=\max\{dp_j+1:j<i,\ pre_j\le pre_i\}$，$O(n^2)$。
- defer the sentinel handling — 用 $-1$ 代表"不可达"，并显式初始化，和 $dp_0=0$ 的合法零值区分开。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| $n$ | `int` | 奶牛数 | 读入 | 题面 |
| `pre[i]` | `i64[1005]` | 前 $i$ 头牛的理智度之和，$pre_0=0$ | $pre_i=pre_{i-1}+a_i$ | prefix / 切点非降判据 |
| `dp[i]` | `int[1005]` | 前 $i$ 头牛合法分组的最大组数；$-1$ 表不可达 | `dp[0]=0`，其余 $-1$ | 分组数 |
| `mxn` | `constexpr int` | 数组尺寸 $1000+5$ | — | 松弛约定 |

### 4.2 编号步骤

1. 读入 $n$；循环读入每个 $a_i$ 并累出前缀和：`pre[i+1]=pre[i]+x`（内部 0-based，`pre[i]` 即前 $i$ 个之和）。
2. `fill_n(&dp[0],mxn,-1)` 把 $dp$ 全部置 $-1$（不可达），再 `dp[0]=0`。
3. 对 $i=1\dots n$，对 $j=0\dots i-1$：若 `dp[j]>=0` 且 `pre[j]<=pre[i]`，用 `dp[j]+1` 更新 `dp[i]`。
4. 若 `dp[n]<0` 输出 `Impossible`，否则输出 `dp[n]`。

### 4.3 复杂度与验证

- 时间 $O(n^2)$；空间 $O(n)$。
- 验证：300 组随机（$n\le12$，$a_i\in[-10,10]$，含总和为负的 `Impossible` 情形）+ 6 组手工边界，标程与 $2^{n-1}$ 切点枚举暴力输出逐字节一致；$n=1000$ 最坏（全 $1$，以及正负交替）耗时约 $0.006$s。

### 4.4 关键不变量

1. `dp[i]` 为 $-1$ $\iff$ 前 $i$ 头牛不存在合法分组。
2. 一切可达的 $i\ge1$ 都有 `dp[i]>=1`（每段至少一头牛）。
3. `dp[n]<0 \iff pre[n]<0 \iff` 输出 `Impossible`。
4. 转移条件只看 `pre[j]<=pre[i]`，与 $a$ 的内部结构无关。

## 5. 示例代码

### 5.1 主解：前缀和 + 切点 DP

```cpp
//
// 题目：P1569 [USACO11FEB] Generic Cow Protests
// https://www.luogu.com.cn/problem/P1569
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};          // n<=1000 (+5 松弛)

int n;
i64 pre[mxn];                     // pre[i]=前 i 头牛的理智度前缀和(0-based 端点)
int dp[mxn];                      // dp[i]=把前 i 头牛合法分组的最大组数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		i64 x;
		cin>>x;
		pre[i+1]=pre[i]+x;
	}

	fill_n(&dp[0],mxn,-1);        // -1 表示该前缀不可达;全局数组默认 0 会误判可达
	dp[0]=0;                      // 空前缀:0 组
	for(int i=1;i<=n;++i)
		for(int j=0;j<i;++j)
			if(dp[j]>=0&&pre[j]<=pre[i])   // 区间(j,i]的和 pre[i]-pre[j]>=0
				dp[i]=max(dp[i],dp[j]+1);

	if(dp[n]<0)
		cout<<"Impossible\n";     // 无合法分组 <=> 总和为负
	else
		cout<<dp[n]<<'\n';
	return 0;
}
```

### 5.2 对照实现：$2^{n-1}$ 切点枚举（仅用于小规模对拍）

```cpp
// 暴力基准:枚举所有"切割位置"子集,逐一检查每组和是否 >=0
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{25};            // 暴力仅跑 n<=20

int n;
i64 a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];

	int best=-1;
	for(int mask=0;mask<(1<<max(0,n-1));++mask)   // mask 的每一位表示此处是否切一刀
	{
		i64 cur=0;
		bool ok=true;
		int cnt=1;
		for(int i=0;i<n;++i)
		{
			cur+=a[i];
			int cut=(i<n-1)&&((mask>>i)&1);
			if(cut)
			{
				if(cur<0)
					ok=false;
				cur=0;
				++cnt;
			}
		}
		if(cur<0)
			ok=false;
		if(ok)
			best=max(best,cnt);
	}

	if(best<0)
		cout<<"Impossible\n";
	else
		cout<<best<<'\n';
	return 0;
}
```

两版输出逐字节一致（已用 $300$ 组随机数据确认）。这一版按定义枚举"每个位置切不切"，完全绕开 DP 转移，可独立交叉验证引理 4 的转移方向与引理 3 的无解判定；代价 $O(2^{n}n)$，仅能跑 $n\le12$。

### 5.3 易错点清单

- **把 `Impossible` 当"输出 $0$"** $\Rightarrow$ 本题答案至少为 $1$。
- **`dp` 未初始化为 $-1$** $\Rightarrow$ 全局默认 $0$ 会把不可达前缀误判为可达。
- **贪心尽早切** $\Rightarrow$ 反例 $[3,-2,-2,3]$ 少算一半组数。
- **`endl`**：违反项目风格指南，一律用 `'\n'`。
