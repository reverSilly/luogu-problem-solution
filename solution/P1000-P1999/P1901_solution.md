# P1901 发射站

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 个发射站从左到右排成一行，第 $i$ 个站有**互不相同**的高度 $H_i$ 和发射能量 $V_i$。每个站同时向左右两侧发射能量，能量只会被**该方向上离它最近、且比它高**的那个站接收；如果那一侧没有比它高的站，这份能量就没人接、直接消失。

一个站可能接收来自左侧某些站的能量，也可能接收来自右侧某些站的能量（题目说一个站发来的能量会被 $0/1/2$ 个站接收）。求**接收能量总和最大**的那个站收到的能量。

### 1.2 关键约束与规模暗示

- $1\le n\le 10^6$，$H_i\le 2\times 10^9$，$V_i\le 10^4$。
- $40\%$ 数据 $n\le 5000$：$O(n^2)$ 的「向左向右各扫一遍找第一个更高的」可以直接过。
- $70\%$ 数据 $n\le 10^5$：$O(n^2)$ 已经 $10^{10}$，必须换 $O(n\log n)$ 或 $O(n)$。
- $100\%$ 数据 $n\le 10^6$：**只有 $O(n)$ 或 $O(n\log n)$ 的线性扫描类做法**能过；而且 $H_i$ 值域 $2\times 10^9$ 远大于 $n$，说明不打算用「按高度开桶」这类值域数组。
- 答案保证在 $32$ 位带符号整数内，所以每个站最多被很多站「喂」能量，但总和有限；实现上用 `long long` 只是保险。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先把「能量流向」翻译成图论语言

对每个站 $i$，定义

$$
L_i=\max\{j<i:\ H_j>H_i\},\qquad R_i=\min\{j>i:\ H_j>H_i\},
$$

不存在时记为「无」。题目说得很清楚：$i$ 的能量送给 $L_i$ 和 $R_i$（存在的话）。于是

$$
\mathrm{recv}[k]=[\,L_i=k\text{ 的 }i\text{ 的 }V_i\text{ 之和}\,]+[\,R_i=k\text{ 的 }i\text{ 的 }V_i\text{ 之和}\,],
$$

答案就是 $\max_k \mathrm{recv}[k]$。问题归约为：对每个 $i$ 求出**左边第一个比它高的位置**和**右边第一个比它高的位置**。

### 2.2 先试暴力，看看瓶颈在哪

对每个 $i$ 向左扫描直到遇到更高的，再向右扫描。最坏情况下（高度单调递增），每个 $i$ 向左要扫 $i$ 步，总复杂度 $O(n^2)$，$n=10^6$ 时是 $10^{12}$，必死。

暴力里重复劳动太多：从 $i$ 向左找「第一个更高」，和从 $i+1$ 向左找「第一个更高」，中间大段区间被反复检查。这种「找第一个满足某单调条件的位置」正是**单调栈**的形状。

### 2.3 单调栈求「右侧第一个更高」

只考虑向右发射。从左到右扫描，维护一个栈，栈里存的是**还没找到右边更高站的候选下标**。设当前扫到 $i$。

**引理 1（栈内高度自底向顶严格递减）**：若每扫到一个 $i$ 就执行「当栈非空且栈顶高度 $<H_i$ 时弹栈，然后压入 $i$」，则任意时刻栈内高度自底向顶严格递减。

**证明**（对扫描过的元素个数归纳）：初始空栈，成立。设处理完前 $i$ 个元素后成立，栈顶高度记为 $h_{top}$。处理 $i$ 时，弹栈循环停止时要么栈空，要么 $h_{top}>H_i$（高度互不相同，不会相等）。压入 $i$ 后，栈顶下方所有高度都 $>h_{top}>H_i$，新栈仍严格递减。$\square$

**引理 2（弹出时刻就是右侧第一个更高）**：若在处理 $i$ 时 $j$ 被弹出（即 $H_j<H_i$），则 $i=R_j$，也就是 $i$ 是 $j$ 右边第一个比 $H_j$ 高的位置。

**证明**：

1. 弹出条件直接给出 $H_i>H_j$，所以 $i$ 是一个候选。
2. 反设存在 $k$ 满足 $j<k<i$ 且 $H_k>H_j$。由于 $j$ 直到时刻 $i$ 才被弹出，说明时刻 $k$（$k<i$）时 $j$ 仍在栈中。时刻 $k$ 的弹栈循环会不断弹出栈顶直到栈顶高度 $>H_k$；而 $j$ 在栈中且 $H_j<H_k$，只要 $j$ 变成栈顶就会被弹掉。若 $j$ 上面还有元素，那些元素要么更早被弹掉、要么高度 $<H_k$ 被弹掉，最终 $j$ 会暴露并满足 $H_j<H_k$，从而在时刻 $k$ 被弹出，与「$j$ 在时刻 $i$ 才弹出」矛盾。
3. 因此 $j$ 与 $i$ 之间没有比 $H_j$ 高的位置，$i$ 就是右边第一个比它高的。$\square$

于是「$j$ 在时刻 $i$ 被弹出」这件事一旦发生，就恰好说明 $i$ 接收 $j$ 向右发出的能量。由于每个下标只会入栈一次、出栈一次，把所有弹出事件里加上 $V_j$ 即可，总复杂度 $O(n)$。

### 2.4 左侧对称处理

把数组倒过来做完全一样的扫描：从右往左扫，遇到栈顶高度更小就弹出，弹出时说明当前 $i$ 是 $j$ **左边**第一个更高站，把 $V_j$ 加到 $\mathrm{recv}[i]$ 上。

两次扫描分别处理「向右发射」和「向左发射」。注意两次的方向不能混：第一次扫描时弹栈发生在右侧更高的位置，能量加到右边的接收站；第二次相反。

### 2.5 边界与坑点

- **高度互不相同**是引理 2 里「弹出条件 $H_j<H_i$，剩余栈顶 $>H_i$」成立的关键。若允许相等，需要改成「严格大于」才接收，弹栈条件应为 $\le$（相等不接收、也不能被挡住）。本题保证不同，写 `<` 即可。
- 一端的站没有更高邻居时，能量「消失」，不要把它加给任何人。对应实现里就是它一直留在栈里没被弹出。
- 每个站最多被弹出两次（左右各一次），所以 $\mathrm{recv}$ 的总量级有界；用 `long long` 存和。

---

## 3. 模式总结（Pattern Summary）

- **explore its property** — 把「能量被最近更高站接收」翻译成每个 $i$ 求左右第一个更高位置 $L_i,R_i$。
- **consider easier version** — 只做「向右发射」，问题变成对每个 $j$ 求右侧第一个更高。
- **classic problem solution** — 单调栈：高度递减栈，弹出 $j$ 的时刻正是右侧第一个更高位置。
- **reduce to easier problem** — 把数组翻转再做一次，得到左侧答案，两次结果按接收站累加。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 发射站数量 | 读入 | 规模 |
| `h[i]` | `int [1000005]` | 第 $i$ 个站高度 | 读入 | height |
| `v[i]` | `int [1000005]` | 第 $i$ 个站发射能量 | 读入 | value |
| `recv[i]` | `i64 [1000005]` | 第 $i$ 个站累计接收的能量 | 0 | receive |
| `stk[]`, `top` | `int [1000005]`, `int` | 单调栈存下标，`top` 为栈内元素个数 | 0 | stack |
| `ans` | `i64` | 最大接收能量 | 0 | answer |

### 4.2 算法步骤

1. 读入 $n$ 与所有 $(H_i,V_i)$（0-based 存储）。
2. **向右扫描**：`top=0`；对 $i=0\dots n-1$，当栈非空且 `h[stk[top-1]]<h[i]` 时：令 $j=$ 栈顶，`recv[i]+=v[j]`，弹栈；随后压入 $i$。
3. **向左扫描**：`top=0`；对 $i=n-1\dots 0$，同样地当栈顶高度小于 `h[i]` 时把 `v[栈顶]` 加给 `recv[i]` 并弹栈；随后压入 $i$。
4. 输出 $\max_i \mathrm{recv}[i]$。

### 4.3 复杂度分析

- **时间复杂度**：每个下标在每趟扫描中入栈、出栈各至多一次，两趟共 $O(n)$。
- **空间复杂度**：$O(n)$（四个长度 $n+5$ 的数组）。

## 5. 示例代码

```cpp
//
// 题目：P1901 发射站
// https://www.luogu.com.cn/problem/P1901
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1000005};

int n;
int h[mxn],v[mxn],stk[mxn];
i64 recv[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>h[i]>>v[i];

	int top{0};
	for(int i=0;i<n;++i)
	{
		while(top>0&&h[stk[top-1]]<h[i])
		{
			recv[i]+=v[stk[top-1]];
			--top;
		}
		stk[top++]=i;
	}

	top=0;
	for(int i=n-1;i>=0;--i)
	{
		while(top>0&&h[stk[top-1]]<h[i])
		{
			recv[i]+=v[stk[top-1]];
			--top;
		}
		stk[top++]=i;
	}

	i64 ans{0};
	for(int i=0;i<n;++i)
		ans=max(ans,recv[i]);
	cout<<ans<<'\n';
	return 0;
}
```
