# P1878 舞蹈课

> 难度：普及/提高- · 标签：链表 / 有序集合 / 模拟

## 1. 重新读题

### 1.1 问题重述（人话版）

$n$ 个人从左到右站成一排，每人有性别 `B` 或 `G`，以及舞蹈技术 $a_i$。只要还存在相邻的一男一女，就把 $|a_i-a_j|$ 最小的那一对拉出去；差值相同就拉最左边的那一对。两人离开后，队伍按原来的相对顺序并拢。按离开顺序输出每一对的原始编号（先小后大）。

### 1.2 关键约束与规模暗示

- $50\%$ 的数据 $n\le 200$，可以每次把当前队伍扫一遍。
- $100\%$ 的数据 $n\le 2\times 10^5$，所以每次扫描是 $O(n^2)$，不够。必须在 $O(\log n)$ 里找到当前最优相邻对，并在删掉他们之后只更新断掉的那几条邻边。
- 编号输出用最初的 $1..n$，人离开后不重新编号。
- $0\le a_i\le 10^7$，差值放得进 32 位整数。

## 2. 思维链（Chain-of-thought）

### 2.1 离开之后，谁和谁变成新邻居

用双向链表保存当前还在队伍里的人，`L[i]`、`R[i]` 是左右邻居。哨兵 $0$ 和 $n+1$ 不代表真人。

**引理 1（只改三条边）**。设当前被拉走的相邻对是 $(i,j)$，其中 $j=R[i]$。令 $li=L[i]$，$rj=R[j]$。删除 $i,j$ 之后，除了 $li$ 与 $rj$ 变成新邻居以外，其他仍在队伍里的人的左右邻居都不变。

**证明**。链表里不相邻的人本来就不相邻，中间还隔着别人，删掉远处的两个人不会让他们碰上。与 $i$ 或 $j$ 相邻的位置只有三段：$(li,i)$、$(i,j)$、$(j,rj)$。前两个人离开后，这三段同时消失，$li$ 的右边和 $rj$ 的左边接在一起。$\square$

所以候选相邻对的集合，每次只删除至多三条、插入至多一条。

### 2.2 最优对就是集合里的最小键

只把「当前相邻且性别不同」的对放进有序集合。键用 $(\lvert a_i-a_j\rvert,\,i)$，其中 $i$ 是这一对左边那个人的原始编号。

**引理 2（键的字典序就是题目的优先级）**。在原始编号从左到右递增、且链表始终保持原来的相对顺序的前提下，最左边的一对就是左端编号最小的一对。因此题目要的对，恰好是集合中键最小的那一对。

**证明**。第一关键字是技术差，与题面一致。技术差相等时，题面要最靠左的一对。因为任何人的左右顺序从不交换，左端点更靠左当且仅当左端点的原始编号更小。$\square$

每个人在链表里最多有一个右邻居，所以左端编号可以唯一确定一条边，集合里不会有两条边共用同一个第二关键字。

### 2.3 操作顺序不会取出过期边

标程在改链表之前，先按引理 1 把 $(li,i)$、$(i,j)$、$(j,rj)$ 从集合里删掉（性别相同的边本来就不在集合里，删除是空操作），再把 $li$ 与 $rj$ 接上，最后按性别决定要不要插入新边。

**引理 3**。每次取出的 `begin()` 都是当前队伍的一条真实相邻异性边，而且就是该时刻的最优对。

**证明**。归纳：初始时集合恰好是所有相邻异性对。每次取出最小键后，按引理 1 删除消失的边、插入新生的边，集合与链表恢复一致。有序集合的最小值就是引理 2 要的那一对。$\square$

同一对不会被插两次：一条边被删除后，只有在它的两端再次变成邻居时才会重新插入，那已经是后来的新局面。

总对数不超过 $\lfloor n/2\rfloor$。每次集合操作 $O(\log n)$，总时间 $O(n\log n)$。

暴力对照不使用集合：每一轮把 `vector` 里还活着的人线性扫一遍，取第一条差值严格最小的相邻异性（从左扫，相等时保留更左的），然后 `erase` 掉两个人。这是 $O(n^2)$，和链表写法不同。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 离开的人只破坏自己左右的邻接，新人只在缺口两侧产生一对新邻居。
- **consider easier version** — $n\le 400$ 时每步扫描当前队列，作为对照。
- **linked list + ordered set** — 用 $(差值, 左端编号)$ 当键，每次取最小再局部改链表。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `g[i]` | `char [200005]` | 性别 | 读入的串 | gender |
| `a[i]` | `int [200005]` | 技术值 | 读入 | ability |
| `L[i],R[i]` | `int [200005]` | 左右邻居 | $i-1,i+1$ | link |
| `st` | `set<pair<int,int>>` | 当前异性邻边 | 初始相邻异性 | set |
| `outp` | `pair [200005]` | 按离开顺序记录的编号对 | 空 | output |

### 4.2 算法步骤

1. 读入性别串和技术值，把 $1..n$ 串成双向链表，哨兵为 $0$ 与 $n+1$。
2. 把所有相邻异性对按 $(|a_i-a_{i+1}|,i)$ 插入集合。
3. 当集合非空：取出最小元素 $i$，令 $j=R[i]$，删除与 $i,j$ 相关的旧边，把 $L[i]$ 和 $R[j]$ 接上，必要时插入新边，记录 $(\min(i,j),\max(i,j))$。
4. 先输出对数，再按记录顺序输出。

### 4.3 复杂度与验证状态

- **时间**：$O(n\log n)$。
- **空间**：$O(n)$。
- **沙箱对拍**：`g++ -O2 -std=c++17 -Wall -Wextra` 零警告。三组 Codeforces 45C 样例以及 $n=1$、全是男生等边界正确。另 $65$ 组 $n\le 400$ 的随机数据与线性扫描暴力一致，共 $70$ 组。$n=2\times 10^5$ 的随机男女混合数据标程耗时 $0.5061\text{ s}$。

## 5. 示例代码

### 5.1 标程（`P1878.cpp`）

```cpp
//
// 题目：P1878 舞蹈课
// https://www.luogu.com.cn/problem/P1878
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{200005};

int a[mxn],L[mxn],R[mxn],n;
char g[mxn];
set<pair<int,int>> st;
pair<int,int> outp[mxn];
int kout;

void del_edge(int i)
{
	int j=R[i];
	if(i<1||i>n||j<1||j>n)
		return;
	if(g[i]==g[j])
		return;
	int d=a[i]-a[j];
	if(d<0)
		d=-d;
	st.erase({d,i});
}

void add_edge(int i)
{
	int j=R[i];
	if(i<1||i>n||j<1||j>n)
		return;
	if(g[i]==g[j])
		return;
	int d=a[i]-a[j];
	if(d<0)
		d=-d;
	st.insert({d,i});
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	string s;
	cin>>s;
	for(int i=1;i<=n;++i)
	{
		g[i]=s[i-1];
		cin>>a[i];
		L[i]=i-1;
		R[i]=i+1;
	}
	R[0]=1;
	L[n+1]=n;
	for(int i=1;i<n;++i)
		add_edge(i);
	while(!st.empty())
	{
		int i=st.begin()->second;
		st.erase(st.begin());
		int j=R[i];
		int li=L[i],rj=R[j];
		del_edge(li);
		del_edge(i);
		del_edge(j);
		R[li]=rj;
		L[rj]=li;
		add_edge(li);
		int x=i,y=j;
		if(x>y)
			swap(x,y);
		outp[kout++]={x,y};
	}
	cout<<kout<<'\n';
	for(int i=0;i<kout;++i)
		cout<<outp[i].first<<' '<<outp[i].second<<'\n';
	return 0;
}
```
