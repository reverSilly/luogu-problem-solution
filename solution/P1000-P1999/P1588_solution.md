# P1588 [USACO07OPEN] Catch That Cow S

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

数轴上 FJ 在 $x$，牛在 $y$ 且不动。FJ 每步可以把当前位置 $p$ 变成 $p+1$、$p-1$ 或 $2p$（$p-1$ 不能把位置变成负数）。求从 $x$ 到 $y$ 的最少步数。多组数据。

抽象成图论语言：以非负整数为顶点，每个 $p$ 向 $p+1$、$p-1$、$2p$ 连一条权为 $1$ 的无向/有向边（$p-1$ 是有向的退化情形），求 $x \to y$ 的最短路。因为边权全为 $1$，最短路就是 BFS 的层数。

### 输入输出格式

- **输入格式**：第一行 $t$（$1 \le t \le 10$），随后 $t$ 行每行两个正整数 $x,y$。
- **输出格式**：每组数据输出一行一个整数，表示最少步数。
- **数据规模**：$1 \le t \le 10$，$0 < x,y \le 10^5$。

### 关键约束分析

1. 图是**无限图**，直接 BFS 会溢出。必须先证明一个有限上界，这是本题唯一的思维难点：把上界写成 $y$（甚至 $10^5$）都会漏掉"先倍增越过 $y$ 再回落"的最优解（见 Part 5 易错点 1）。
2. 多组数据：`dis` 数组必须在每组数据前重置，且只重置到上界即可，避免 $10$ 次 $O(2\times10^5)$ 的无谓清空。
3. $2p$ 最大为 $2\times10^5$，在 `int` 范围内，无需 `long long`。
4. 边界：$x=y$ 答案为 $0$；$x>y$ 时倍增只会越走越远，答案为 $x-y$。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：先把"最少步数"翻译成 BFS

三种操作互不相关，且每次代价都是 $1$，所以"最少操作次数"就是无权图上的最短路。BFS 按层扩展，第一次弹出 $y$ 时的层数即答案。这一步没有难度，难点在于队列里可能出现的下标范围。

### 第二步：$x \ge y$ 的退化情形

若 $x \ge y$，任何 $+1$ 或 $\times 2$ 都让位置离 $y$ 更远，唯一有意义的是连续 $-1$，共 $x-y$ 步。这条捷径不仅省时间，还说明只有 $s<t$ 时才需要 BFS。

**引理 1（高于目标后只能下降）**：若 $p \ge y$，则从 $p$ 到 $y$ 的最少步数恰为 $p-y$。

*证明*：下界：每一步最多让坐标减少 $1$（$p+1$、$2p$ 都使坐标增大，$p-1$ 使坐标减 $1$），要从 $p$ 降到 $y$ 至少需要 $p-y$ 步。上界：连续执行 $p-y$ 次 $-1$，途中坐标依次为 $p-1,\dots,y$，全部非负（因为 $y \ge 1$），故合法且恰好 $p-y$ 步。两端夹逼得结论。$\square$

由引理 1 立刻得到一个推论：**任何最优路径，一旦走到 $\ge y$ 的位置，之后必然一路 $-1$**。否则把后缀换成 $-1$ 序列不会变长，而变短则与原路径最优矛盾。

### 第三步：给状态空间找上界

既然越过 $y$ 之后只会下降，那么路径唯一可能"冲高"的机会是**第一次**跨过 $y$ 的那一步。它只能由某个 $q<y$ 经过三种操作得到。

**引理 2（首次跨越的高度受限）**：设 $f$ 为最优路径中第一个满足位置 $\ge y$ 的时刻，则 $y \le \text{pos}_f \le 2y-2$。

*证明*：记 $q=\text{pos}_{f-1}<y$。三种操作分别给出：

- $q+1 \le y$，且由 $f$ 的最小性 $\text{pos}_f \ge y$，故 $\text{pos}_f=y$；
- $2q \le 2(y-1)=2y-2$，同时 $2q \ge y$；
- $q-1<y$，与 $f$ 的最小性矛盾，不可能发生。

合并得 $y \le \text{pos}_f \le 2y-2$。$\square$

**引理 3（状态上界 $2y$）**：存在一条最优路径，其经过的所有位置都 $\le 2y$。

*证明*：取一条最优路径。它在 $f$ 之前的位置都 $<y$；由引理 2，$\text{pos}_f \le 2y-2$。若 $f$ 之后的后缀不是全为 $-1$，由引理 1 可知把该后缀整体换成 $\text{pos}_f-y$ 次 $-1$ 得到的仍是一条最优路径，且位置单调下降。因此在两种情况下都存在一条最大位置 $\le \max(\text{pos}_f,\,y-1)=2y-2<2y$ 的最优路径。$\square$

**定理（BFS 截断正确）**：在顶点集 $\{0,1,\dots,2y\}$ 上做 BFS，得到的 $x \to y$ 距离等于原无限图上的距离。

*证明*：截断图上任何路径都是原图路径，故截断距离 $\ge$ 原距离；由引理 3，原图存在一条完全落在截断图内的最优路径，故截断距离 $\le$ 原距离。两者相等。$\square$

### 第四步：落地

于是每组数据只需在 $[0,2y]$ 上 BFS，队列与 `dis` 数组开到 $2\times 10^5+5$ 即可。为避免每组全量清空，用 `fill_n(dis,2*t+2,-1)` 精确清空用到的前缀。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 三种操作代价均为 1，"最少步数"等价于无权图最短路，于是锁定 BFS。
- `consider easier version` — 先解决 $x\ge y$：此时只有 $-1$ 有意义，答案为 $x-y$。
- `explore its property` — 位置一旦 $\ge y$，后续最优策略必为连续 $-1$（引理 1），路径不会再上升。
- `bound the state space` — 用"首次跨越点 $\le 2y-2$"把无限图截断成 $[0,2y]$，使 BFS 可执行。
- `classic problem solution` — BFS + `dis` 访问标记，每个顶点入队一次，线性时间。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $t$ | `m` | 数据组数（读入后即循环 `m` 次） |
| $x,y$ | `x`, `y` | 全局的起点与牛的位置，每组重新读入 |
| $\text{dis}[u]$ | `dis[u]` | 从起点到 $u$ 的最少步数；每组开始用 `fill_n` 置 $-1$ 表示未访问 |
| $Q$ | `Q[]` | 手写 BFS 队列，存待扩展的坐标 |
| $ql,qr$ | `ql`, `qr` | 队头、队尾指针，区间 $[ql,qr)$ |
| $u$ | `u` | 当前弹出的顶点 |
| $\text{nx}[3]$ | `nx[3]` | 当前点的三个后继 $\{u+1,u-1,2u\}$ |
| $v$ | `v` | 枚举到的后继顶点 |
| $2y$ | `2*t` | 状态上界，`dis` 与队列的容量依据 |

### 算法步骤

1. 读入组数 `m`。
2. 每组读入 `x,y`；若 `x>=y` 直接输出 `x-y` 并进入下一组（引理 1）。
3. 用 `fill_n(dis,2*t+2,-1)` 清空 $[0,2y]$ 的距离，`dis[x]=0`，`x` 入队。
4. 反复弹出队头 `u`：若 `u==y` 返回 `dis[u]`；否则枚举 `nx[3]`，对落在 $[0,2y]$ 且未访问的后继 `v` 置 `dis[v]=dis[u]+1` 并入队。
5. 输出距离，换行。

### 复杂度分析

- **时间复杂度**：每组 BFS 至多访问 $2y+1$ 个顶点、每点 $3$ 条出边，$\mathcal{O}(y)$；总 $\mathcal{O}(t \cdot \max y) \le 2\times 10^6$。
- **空间复杂度**：$\mathcal{O}(\max y)$，即两个长度 $2\times10^5+5$ 的静态数组。

### 正确性验证

由定理，$[0,2y]$ 上的 BFS 距离等于无限图上的最短路；BFS 在无权图上按层扩展得到的就是最短路（标准结论，归纳层数即可）。整数范围：坐标最大 $2\times10^5$，步数最多 $y$，`int` 足够；$x\ge y$ 分支输出 $x-y\ge0$。多组数据通过 `fill_n` 局部重置，不会相互污染。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1588 [USACO07OPEN] Catch That Cow S
// https://www.luogu.com.cn/problem/P1588
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{200005};

int x,y;
int dis[mxn],Q[mxn];

int bfs(int s,int t)
{
	if(s>=t)
		return s-t;            // 位置已不低于牛, 只有 -1 有用
	fill_n(dis,2*t+2,-1);      // 只需清空 [0,2t], 更远处不可能最优
	int ql=0,qr=0;
	dis[s]=0;
	Q[qr++]=s;
	while(ql<qr)
	{
		int u=Q[ql++];
		if(u==t)
			return dis[u];
		int nx[3]{u+1,u-1,u*2};
		for(int k=0;k<3;++k)
		{
			int v=nx[k];
			if(v>=0&&v<=2*t&&dis[v]==-1)
			{
				dis[v]=dis[u]+1;
				Q[qr++]=v;
			}
		}
	}
	return dis[t];
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int m;
	cin>>m;
	while(m--)
	{
		cin>>x>>y;
		cout<<bfs(x,y)<<'\n';
	}
	return 0;
}
```

### 易错点

1. **上界写成 $10^5$（数组容量而非 $2y$）**：最优解可能先倍增越过 $y$ 再回落，例如 $x=3,y=5$ 走 $3\to6\to5$ 需 $2$ 步，被限制在 $\le y$ 内就得走 $4$ 步；$x=50001,y=10^5$ 时更要先到 $100002$。所以状态必须开到 $2y$。
2. **多测不清空**：`dis` 是全局数组，第二组数据若不重置会把上一组的层数当成"已访问"，直接输出错误答案。
3. **清空范围过大**：每次 `fill_n` 到 $2\times10^5$ 而不是 `2*t+2`，$t\le10$ 时多花约 $2\times10^6$ 次写，虽不致命但没必要。
4. **`x>=y` 漏判**：此时 $2y<x$，`fill_n(dis,2*t+2,-1)` 清不到 `dis[x]`，可能残留上一组数据写入的值，BFS 一开始就把起点当成"已访问"或带着旧距离入队。必须提前返回 $x-y$。
