# P1129 [ZJOI2007] 矩阵游戏

---

## 1. 重新阅读问题

给定一个 $n \times n$ 的 01 矩阵（$0$ = 白色，$1$ = 黑色）。允许两种操作任意多次：

- **行交换**：交换任意两行的所有元素；
- **列交换**：交换任意两列的所有元素。

判断能否通过若干次操作使得**主对角线**（左上角到右下角）上的所有格子均为黑色（$1$）。

多组测试数据，$T \le 20$，$n \le 200$。

---

## 2. 思考链（含完整证明）

### 2.1 操作的本质

先严格分析一次操作对矩阵元素位置的影响。

记矩阵为 $A$，$A[i][j]$ 表示第 $i$ 行第 $j$ 列的值。

- 交换行 $p$ 和 $q$：原来在第 $p$ 行的所有元素整体移动到第 $q$ 行，反之亦然，**列下标不变**。
- 交换列 $p$ 和 $q$：原来在第 $p$ 列的所有元素整体移动到第 $q$ 列，反之亦然，**行下标不变**。

若干次行交换的复合效果是一个**行置换** $\sigma$：原来在第 $i$ 行的元素最终出现在第 $\sigma(i)$ 行。  
若干次列交换的复合效果是一个**列置换** $\tau$：原来在第 $j$ 列的元素最终出现在第 $\tau(j)$ 列。

因此，经过任意操作后，原矩阵 $A$ 变为 $A'$，满足：

$$
A'[i][j] = A[\sigma^{-1}(i)][\tau^{-1}(j)]
$$

或者等价地写成：

$$
A'[\sigma(i)][\tau(j)] = A[i][j]
$$

其中 $\sigma, \tau$ 是 $\{0,1,\dots,n-1\}$ 上的任意置换。

---

### 2.2 目标条件的翻译

最终目标：对于所有 $i \in [0, n-1]$，$A'[i][i] = 1$。

代入 $A'$ 的表达式：

$$
A[\sigma^{-1}(i)][\tau^{-1}(i)] = 1 \quad \forall i
$$

令 $p_i = \sigma^{-1}(i)$, $q_i = \tau^{-1}(i)$。由于 $\sigma^{-1}, \tau^{-1}$ 也是置换，$\{p_i\}$ 和 $\{q_i\}$ 各自是 $\{0,\dots,n-1\}$ 的一个排列。上式变为：

$$
A[p_i][q_i] = 1 \quad \forall i
$$

换句话说：需要从矩阵中选出 $n$ 个黑色格子 $(p_i, q_i)$，使得它们的行号互不相同（$p_i$ 是排列），列号也互不相同（$q_i$ 是排列）。这正是**一个 $n$ 元匹配**：每行恰好选一个格子，每列恰好选一个格子，且选中的格子都是 $1$。

---

### 2.3 二分图模型

据此建立二分图：

- 左部点：$n$ 行，编号 $0 \sim n-1$。
- 右部点：$n$ 列，编号 $0 \sim n-1$。
- 连边：若 $A[i][j] = 1$，则在左部点 $i$ 与右部点 $j$ 之间连一条无向边。

问题转化为：**该二分图是否存在完美匹配**（大小为 $n$ 的匹配）？

---

### 2.4 充要性证明

**充分性**：若存在完美匹配 $M = \{(r_0, c_0), (r_1, c_1), \dots, (r_{n-1}, c_{n-1})\}$，其中 $r_i$ 是行下标（互异），$c_i$ 是列下标（互异）。

构造行置换 $\sigma$ 使 $\sigma(i) = r_i$，列置换 $\tau$ 使 $\tau(i) = c_i$。则在变换后的矩阵 $A'$ 中：

$$
A'[i][i] = A[\sigma^{-1}(i)][\tau^{-1}(i)]
$$

注意 $\sigma^{-1}(r_i) = i$ 且 $\tau^{-1}(c_i) = i$，因此：

$$
A'[i][i] = A[r_i][c_i] = 1
$$

即对角线全黑，目标达成。$\square$

**必要性**：若存在操作序列使最终矩阵 $A'$ 的主对角线全为 $1$，则存在置换 $\sigma, \tau$ 使得 $A[\sigma^{-1}(i)][\tau^{-1}(i)] = 1$。令 $p_i = \sigma^{-1}(i), q_i = \tau^{-1}(i)$，则 $\{(p_i, q_i)\}$ 构成一个完美匹配（行互异、列互异、值均为 $1$）。$\square$

---

### 2.5 算法

对此二分图运行**最大匹配**算法，检查最大匹配基数是否等于 $n$。

- 使用 **Kuhn 算法**（DFS 增广路），复杂度 $O(n \cdot m)$，其中 $m$ 是边数。$n \le 200$ 时最坏 $O(n^3) = 8 \times 10^6$，即使 $T = 20$ 也绰绰有余。
- 也可使用 **Hopcroft–Karp** 达到 $O(E\sqrt{V})$，但非必须。

---

## 3. 模式总结

| 观察 | 结论 |
|------|------|
| 行/列交换可独立任意进行 | 等价于对行和列分别施加任意置换 |
| 目标：对角线上全为 $1$ | 需要从每行每列各取一个 $1$ |
| 每行/每列各取一个元素 | 经典二分图完美匹配模型 |
| 检查匹配基数是否等于 $n$ | 最大匹配算法 |

**关键范式总结**：当问题允许独立地重新排列两个维度（如交换行和列），且目标是对角线上出现某种属性时，往往转化为**二分图完美匹配**问题。判断条件为：能否从矩阵中选出 $n$ 个满足要求的元素，使其行/列两两不同。

---

## 4. 真实解法

### 4.1 算法描述

1. 建立二分图：左部 $n$ 个点表示行，右部 $n$ 个点表示列；若 $A[i][j] = 1$ 则连边。
2. 从每个左部点出发尝试 DFS 增广。
3. 若匹配数 $= n$ 输出 `Yes`，否则输出 `No`。

### 4.2 记号表

| 符号 | 含义 |
|------|------|
| $n$ | 矩阵大小 |
| $A[i][j]$ | 原矩阵第 $i$ 行第 $j$ 列的值（$0$ 或 $1$） |
| $\sigma$ | 行置换，$\sigma(i)$ 是原第 $i$ 行最终的行位置 |
| $\tau$ | 列置换，$\tau(j)$ 是原第 $j$ 列最终的列位置 |
| $match[v]$ | 右部点 $v$ 匹配的左部点编号（$-1$ = 未匹配） |
| $vis[v]$ | 当前 DFS 中右部点 $v$ 是否已被访问 |

### 4.3 复杂度

- 时间：$O(T \cdot n^3)$，$T \le 20, n \le 200$，最坏 $1.6 \times 10^8$ 次操作，实际常数极小，可通过。
- 空间：$O(n^2)$。

---

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{205};

int n;
vector<int> g[mxn];
int match[mxn], vis[mxn], timer;

bool dfs(int u)
{
	for (int v : g[u])
	{
		if (vis[v] == timer) continue;
		vis[v] = timer;
		if (match[v] == -1 || dfs(match[v]))
		{
			match[v] = u;
			return true;
		}
	}
	return false;
}

void solve()
{
	cin >> n;
	for (int i = 0; i < n; ++i) g[i].clear();
	for (int i = 0; i < n; ++i)
	{
		for (int j = 0; j < n; ++j)
		{
			int x; cin >> x;
			if (x) g[i].push_back(j);
		}
	}

	fill(match, match + n, -1);
	timer = 0;
	fill(vis, vis + n, 0);

	int cnt = 0;
	for (int i = 0; i < n; ++i)
	{
		++timer;
		if (dfs(i)) ++cnt;
	}

	cout << (cnt == n ? "Yes" : "No") << '\n';
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int T; cin >> T;
	while (T--) solve();

	return 0;
}
```
