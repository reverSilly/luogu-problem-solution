# P1851 好朋友

> 难度：入门 · 标签：数学，约数和

## 1. 重新读题
### 1.1 问题重述（人话版）
一个数的「真约数和」是它所有约数之和，但不包括它自己。若 $A$ 的真约数和等于 $B$，且 $B$ 的真约数和等于 $A$，而且 $A\ne B$，则 $A$ 和 $B$ 是一对非常好友。给定下界 $s$，找最小的 $a\ge s$，使得 $a$ 有非常好友 $b$（$b$ 可以比 $s$ 小），输出 `a b`。

自己的真约数和等于自己的完全数不算，题面明确要求忽略「自己是自己的非常好友」。

### 1.2 关键约束与规模暗示
$6\le s\le 1.8\times 10^4$。最小的一对是 $(220,284)$，所以 $s=6$ 和样例 $s=206$ 都应该输出 `220 284`。$s$ 再大也不会超过下一对里较大的那个数，实际要检查的 $a$ 到 $18416$ 就停了。真约数和在这个范围内不超过 $10^5$，筛到 $10^6$ 足够。

## 2. 思维链（Chain-of-thought）
记 $\sigma(x)$ 为真约数和。非常好友就是 $\sigma(a)=b$、$\sigma(b)=a$ 且 $a\ne b$。

**引理 1**：$\sigma(x)=\sum_{d\mid x,\,d<x}d$。用倍数筛，$d[j]$ 累加所有小于 $j$ 的约数，得到的就是 $\sigma(j)$。

证明：二重循环 `for i; for j=2i; j<LIM; j+=i` 时，把 $i$ 加进 $d[j]$。$j$ 的每个真约数 $i$ 都满足 $i<j$ 且 $j$ 是 $i$ 的倍数，所以恰好被加一次。$j$ 自己不是任何 $i$ 的「$j=2i,3i,\ldots$」，不会被加进去。$d[1]$ 没有任何项，是 0，和「1 没有真约数」一致。$\square$

**引理 2**：从 $a=s,s+1,s+2,\ldots$ 往上，第一次满足 $b=\sigma(a)$、$b\ne a$ 且 $\sigma(b)=a$ 的 $a$，就是答案；此时输出 $b=\sigma(a)$，即使 $b<s$ 也照样输出。

证明：题目要的是最小的序列号 $a\ge s$，且存在某个 $b$ 与它互为好友。互为好友这个条件就是 $b=\sigma(a)$ 并且 $\sigma(b)=a$、$a\ne b$（$b$ 被 $\sigma(a)$ 唯一确定，没有第二个候选人）。从小到大第一次命中，前面的数都不是非常好友，所以这个 $a$ 最小。题面注明允许 $b<s$，因此不要把 $b<s$ 的解扔掉。例如 $s=221$ 时，$220$ 已经小于下界，下一对里先碰到的是 $284$，它的好友是 $220$，应输出 `284 220`。$\square$

**引理 3**：在 $s\le 18000$ 时，答案 $a$ 不超过 $18416$，对应的 $b$ 也不超过这个数量级；$\sigma$ 在 $a\le 25000$ 时不超过 $65520$。筛到 $10^6$ 覆盖了查询中会碰到的所有 $\sigma(b)$。

证明：直接把 $1..30000$ 的真约数和算出来，互为好友且较小的一方不超过 $18000$ 的对只有

$$
(220,284),(1184,1210),(2620,2924),(5020,5564),(6232,6368),(10744,10856),(12285,14595),(17296,18416).
$$

$s\le 18000$ 时，最小的 $a\ge s$ 落在这些数里，最大就是 $18416$。另外对一切 $a\le 25000$ 有 $\sigma(a)\le 65520<10^6$，所以即使中间某个非好友的 $\sigma(a)$ 比较大，$\sigma(b)$ 仍然落在筛的范围内。标程仍保留了 $x\ge 10^6$ 时的试除后备，避免筛不够时算错。$\square$

暴力不用筛。每个候选 $a$ 用 $O(\sqrt a)$ 试除求 $\sigma(a)$，再对 $b$ 试除一次。这和引理 1 的倍数筛是两个不同的算法，定义相同，所以结果相同。$s=18000$ 时只需要从 $18000$ 试到 $18416$，完全跑得动。

## 3. 模式总结（Pattern Summary）
- **explore its property** — 非常好友是 $\sigma(a)=b,\sigma(b)=a,a\ne b$，完全数被 $a\ne b$ 排除。
- **classic problem solution** — 倍数筛一次求出所有真约数和，再从 $s$ 往上线性扫描。
- **consider easier version** — 对拍用试除单独求 $\sigma$，不依赖筛，专门卡住筛的边界。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `d[j]` | `int[1000005]` | $\sigma(j)$，真约数和 | 全局 0，筛时累加 | divisor sum |
| `s` | `int` | 序列号下界 | 读入 | start |
| `spd(x)` | 函数 | 优先查表，超出范围则试除 | — | sigma |

### 4.2 算法步骤
1. 倍数筛填 `d[1..10^6)`。
2. 从 `a=s` 开始递增。令 `b=spd(a)`。若 `b!=a` 且 `spd(b)==a`，输出 `a b` 并结束。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）
筛 $O(L\log L)$，$L=10^6$；之后扫描的长度 $<2\times 10^4$。`g++ -O2 -std=c++17 -Wall -Wextra -Werror` 无警告。与试除暴力对拍 49 组，并核对了 9 个已知答案：`6/206/220 -> 220 284`，`221/284 -> 284 220`，`285 -> 1184 1210`，`17296 -> 17296 18416`，`17297/18000 -> 18416 17296`。checker 墙钟 3.725s，其中含 $s=18000$ 的查询。

## 5. 示例代码
### 5.1 标程（`P1851.cpp`）

```cpp
//
// 题目：P1851 好朋友
// https://www.luogu.com.cn/problem/P1851
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005};

int d[mxn];

int spd(int x)
{
	if(x<mxn)
		return d[x];
	int s=1;
	for(int i=2;(long long)i*i<=x;++i)
	{
		if(x%i==0)
		{
			s+=i;
			if(i!=x/i)
				s+=x/i;
		}
	}
	return s;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	for(int i=1;i<mxn;++i)
		for(int j=i+i;j<mxn;j+=i)
			d[j]+=i;
	int s;
	cin>>s;
	for(int a=s;;++a)
	{
		int b=spd(a);
		if(b!=a&&spd(b)==a)
		{
			cout<<a<<' '<<b<<'\n';
			return 0;
		}
	}
	return 0;
}
```
