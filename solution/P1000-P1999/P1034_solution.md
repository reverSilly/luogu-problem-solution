# P1034 [NOIP 2002 提高组] 矩形覆盖 题解

---

## 一、发现叙事

第一次读题，直觉告诉我这有点像聚类——把 $n$ 个点分到 $k$ 个矩形里，每个矩形就是它覆盖的那些点的最小包围盒（谁也不会故意把矩形放大）。矩形之间不能重合，边和顶点都不能碰到。面积最小的方案就是答案。

样例给了四个点：
```
(1,1)  (2,2)  (3,6)  (0,7)
```
$k=2$ 时答案是 $4$。动手一试：按 $y$ 坐标排序，前两个点 $(1,1),(2,2)$ 分给一个矩形，后两个 $(3,6),(0,7)$ 分给另一个。前一个矩形宽 $1$ 高 $1$，面积 $1$；后一个宽 $3$ 高 $1$，面积 $3$，总和正好 $4$。这个分割本质上是在 $y=2$ 和 $y=6$ 之间「砍了一刀」——存在一条水平线把两个矩形隔开。

这一下就引出了一个关键性质：任何两个不相交的轴平行矩形，要么在 $x$ 方向上有间隔，要么在 $y$ 方向上有间隔。因为如果 $x$ 和 $y$ 投影都重叠，它们一定会相交。

再往深处想：对于任意一组互不相交的轴平行矩形，总存在一条竖直或水平的直线能把它们分成两个非空组。这条线就画在某两个矩形之间的「缝隙」上。这意味着我们可以**递归地分割**：先找到一个方向把矩形们分成两组，再对每组递归处理。

$k$ 最大只有 $4$，递归深度最多 $4$ 层。思路就此成形。

## 二、思维链与完整证明

### 2.1 不相交矩形的基本性质

**定义**。矩形用其最小包围盒表示：$[x_{\min}, x_{\max}] \times [y_{\min}, y_{\max}]$，四边平行于坐标轴。

**引理 1（分离判定）**。两个轴平行矩形不相交（内部、边、顶点均不重合）当且仅当它们在 $x$ 方向或 $y$ 方向上严格分离：
$$
R_a \cap R_b = \varnothing \iff R_a.x_2 < R_b.x_1 \;\lor\; R_b.x_2 < R_a.x_1 \;\lor\; R_a.y_2 < R_b.y_1 \;\lor\; R_b.y_2 < R_a.y_1.
$$

*证明*。两个轴平行矩形相交当且仅当 $x$ 和 $y$ 投影同时重叠：

- $x$ 投影重叠：$R_a.x_1 < R_b.x_2 \land R_b.x_1 < R_a.x_2$。
- $y$ 投影重叠：$R_a.y_1 < R_b.y_2 \land R_b.y_1 < R_a.y_2$。

若四个「分离条件」全部不满足，则两个投影都重叠，矩形相交。反之若任一分离条件成立，则至少在一个投影方向上存在严格间隙，矩形不可能相交。$\blacksquare$

### 2.2 Guillotine 分割存在性定理

**定理 1（Guillotine 分割）**。对于任意一组非空、互不相交的轴平行矩形，总存在一条竖直或水平的直线，不穿过任何矩形内部，并将矩形集分成两个非空子集。

*证明*。考虑所有矩形的右边界 $x_2$，取最小值 $x^* = \min_i R_i.x_2$。设达到该最小值的矩形为 $R_m$（若有多个任取一个）。

在 $x = x^*$ 处画一条竖直线（严格来说，应取 $x = x^* + \varepsilon$ 使得直线恰好不与 $R_m$ 接触，但整数坐标下可直接理解为其右侧紧邻的缝隙）。

将矩形分为两类：

- **右类**：满足 $R_i.x_1 > x^*$ 的矩形。它们完全位于该线右侧。
- **左类**：满足 $R_i.x_1 \le x^*$ 的矩形，包括 $R_m$ 本身。它们在 $x$ 投影上与 $R_m$ 重叠（因为 $R_m.x_1 \le x^* \le R_m.x_2$，且 $R_i.x_1 \le x^* \le R_i.x_2$ 对左类所有矩形成立）。

现分两种情况讨论：

**情况 A**：右类非空。此时竖直线 $x = x^*$ 将右类与左类严格分离，分割成立。

**情况 B**：右类为空，即所有矩形都满足 $R_i.x_1 \le x^*$。此时左类就是全集，所有矩形都与 $R_m$ 在 $x$ 投影上重叠。由引理 1，它们不能在 $x$ 上分离，因此必然在 $y$ 上分离。故每个矩形要么完全在 $R_m$ 上方（$R_i.y_1 > R_m.y_2$），要么完全在 $R_m$ 下方（$R_i.y_2 < R_m.y_1$）。

- 若存在至少一个矩形在上方，在 $y = R_m.y_2 + \varepsilon$ 处作水平线：上方矩形在该线上，$R_m$ 及下方矩形在线下，分割成立。
- 若不存在上方矩形，则所有矩形都在 $R_m$ 下方，在 $y = R_m.y_1 - \varepsilon$ 处作水平线：$R_m$ 在线上一侧，其余矩形在线另一侧，分割成立。

综上所述，总存在一个合法的分割。$\blacksquare$

**推论 1（递归分割）**。覆盖 $n$ 个点的 $k$ 个最优矩形一定可以通过递归地对点集进行竖直或水平分割得到。

*证明*。由定理 1，最优解对应的矩形集存在一条分隔线将其分为两个非空子集。分隔线两侧的矩形各自覆盖相应的点，且不跨过该线。因此原问题分解为两个独立的子问题：左侧点集用 $k_1$ 个矩形覆盖，右侧用 $k_2 = k - k_1$ 个覆盖。递归地对子问题应用定理 1 即得完整分解。$\blacksquare$

### 2.3 递归搜索算法

由推论 1，设计如下搜索过程：

```
solve(点集 S, 矩形数 k):
    若 |S| ≤ k: 每个点单独一个矩形面积为 0，返回 0
    若 k = 1: 返回 S 的最小包围盒面积
    
    ans = +∞
    
    // 尝试竖直分割
    按 x 将 S 中元素排序
    枚举分割位置 i，满足 S[i-1].x < S[i].x
        L = S[0..i-1], R = S[i..|S|-1]
        枚举 j = 1..k-1
            ans = min(ans, solve(L, j) + solve(R, k-j))
    
    // 尝试水平分割
    按 y 将 S 中元素排序
    （同上逻辑）
    
    返回 ans
```

### 2.4 正确性

定理 1 保证了最优解总存在一条递归分割路径。算法枚举了所有可能的分割位置（所有相邻不同坐标之间）和所有可能的矩形分配数量，因此一定能找到最优解。记忆化确保了同一子集不会重复计算。

### 2.5 复杂度分析

设状态数为 $T(N, K)$。每次调用枚举 $O(N)$ 个分割位置 $\times$ $O(K)$ 种分配 $\times$ $2$ 个方向，即 $O(NK)$ 种分支。

最坏情况下分支呈指数级。但 $K \le 4$，递归深度极浅：

- $K=4$：至多 $2N \times 3$ 种子调用
- $K=3$：至多 $2N \times 2$ 种子调用
- $K=2$：至多 $2N \times 1$ 种子调用

用 64 位整数掩码做记忆化，实际访问的不同子集数量通常远小于 $2^{50}$。对于 $N \le 50$，算法在竞赛时限内可通过。

## 三、模式总结

| 层面 | 要点 |
|------|------|
| **问题类型** | 最小覆盖、几何分割、递归划分 |
| **核心性质** | 不相交轴平行矩形存在 Guillotine 分割（定理 1） |
| **算法范式** | 递归 + 记忆化搜索（子集 DP） |
| **关键剪枝** | 仅允许在相邻不同坐标处分割，保证严格间隔 |
| **复杂度** | $O(N^2\log N \cdot 2^K)$ 级别（实际远小于上界） |
| **适用场景** | $k$ 很小的矩形覆盖问题 |

**讨论**：

- 如果允许矩形重叠，问题退化为 k-means 变体。
- 如果 $k$ 较大（如 $k \ge 10$），需改用状态压缩 DP 或整数规划。
- 如果矩形可旋转，问题难度显著上升。

## 四、真实解法

### 状态与表示

- 点编号为 $0 \dots n-1$。
- 用 `u64`（64 位无符号整数）的第 $i$ 位表示点 $i$ 是否在当前子集中。
- `mp[t][mask]`：子集 `mask` 用 $t$ 个矩形覆盖的最小面积（记忆化表）。

### 算法步骤

1. 读入 $n, k$ 及所有点的坐标 $(x_i, y_i)$。
2. 若 $k \ge n$，直接输出 $0$（每个点单独矩形面积为 0）。
3. 定义递归函数 `dfs(idx, k)`：
   - 若 `|idx| ≤ k`，返回 0。
   - 若 `k = 1`，计算 `idx` 对应点集的包围盒面积并返回。
   - **竖直分割**：按 $x$ 排序，在相邻不同 $x$ 处切开。枚举左右矩形数 $j$ 和 $k-j$。
   - **水平分割**：按 $y$ 排序，逻辑同上。
   - 记忆化并返回最小值。
4. 初始调用 `dfs(all, k)`，输出结果。

### 边界条件

- 单点矩形、共线点集：包围盒有一维或两维为零，面积 0。
- 分割时跳过坐标相等的相邻点：确保两个子矩形之间有严格间隙。
- $k \ge n$ 时直接输出 0。

### 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 点的个数 |
| $k$ | 矩形个数 |
| $p_i$ | 第 $i$ 个点，坐标为 $(x_i, y_i)$ |
| $R.x_1, R.x_2$ | 矩形左/右边界 |
| $R.y_1, R.y_2$ | 矩形下/上边界 |
| $\texttt{mp}[t][mask]$ | 记忆化表，子集 $mask$ 用 $t$ 个矩形的最小面积 |
| $\texttt{ans}$ | 最终答案 |

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using u64=unsigned long long;

constexpr int mxn{55};
struct Point{int x,y;}p[mxn];
int n,K;
unordered_map<u64,int>mp[5];

u64 mk(const vector<int>&idx)
{
	u64 m=0;
	for(int i:idx)
		m|=1ULL<<i;
	return m;
}

int dfs(vector<int>&idx,int k)
{
	if(idx.size()<=k)
		return 0;
	if(k==1)
	{
		int x1=114514,x2=0,y1=114514,y2=0;
		for(int i:idx)
		{
			if(p[i].x<x1)x1=p[i].x;
			if(p[i].x>x2)x2=p[i].x;
			if(p[i].y<y1)y1=p[i].y;
			if(p[i].y>y2)y2=p[i].y;
		}
		return (x2-x1)*(y2-y1);
	}
	u64 mask=mk(idx);
	if(mp[k].count(mask))
		return mp[k][mask];
	int ans=1145141919;
	//vertical split
	sort(idx.begin(),idx.end(),[](int a,int b){return p[a].x<p[b].x;});
	for(int i=1;i<idx.size();++i)
	{
		if(p[idx[i]].x==p[idx[i-1]].x)
			continue;
		vector<int>L(idx.begin(),idx.begin()+i);
		vector<int>R(idx.begin()+i,idx.end());
		for(int j=1;j<k;++j)
			ans=min(ans,dfs(L,j)+dfs(R,k-j));
	}
	//horizontal split
	sort(idx.begin(),idx.end(),[](int a,int b){return p[a].y<p[b].y;});
	for(int i=1;i<idx.size();++i)
	{
		if(p[idx[i]].y==p[idx[i-1]].y)
			continue;
		vector<int>L(idx.begin(),idx.begin()+i);
		vector<int>R(idx.begin()+i,idx.end());
		for(int j=1;j<k;++j)
			ans=min(ans,dfs(L,j)+dfs(R,k-j));
	}
	return mp[k][mask]=ans;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>K;
	for(int i=0;i<n;++i)
		cin>>p[i].x>>p[i].y;
	if(K>=n)
	{
		cout<<"0\n";
		return 0;
	}
	vector<int>all(n);
	iota(all.begin(),all.end(),0);
	cout<<dfs(all,K)<<'\n';
	return 0;
}
```
