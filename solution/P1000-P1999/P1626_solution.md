# P1626 象棋比赛

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

有 $N$ 个人，等级两两不同。要安排恰好 $K$ 场对弈，其中：

- 每场对弈的两人的等级不同，等级高者执黑、低者执白；
- 每个人**执黑至多一次、执白至多一次**（等价于最多参加两场，且两场一黑一白）；
- 一场对弈的"观赏代价"是两人等级之差。

求 $K$ 场对弈的等级差之和的最小值。

### 输入输出格式

- **输入格式**：第一行 $N,K$；随后 $N$ 行，每行一个正整数表示一位选手的等级（题面写作"第 $i$ 行表示第 $i-1$ 个人"，实际就是 $N$ 个等级，顺序无关）。
- **输出格式**：一行一个整数，最小等级差总和。
- **数据规模**：$N\le10^5$（$90\%$ 数据 $N\le3000$），等级 $<10^9$，$1\le K\le N-1$。

### 关键约束分析

1. $N\le10^5$，答案最大约 $10^5\times10^9=10^{14}$，必须用 64 位整数。
2. 等级互不相同，排序后严格递增，任意两人之差为正，这让我们可以只讨论"下标"。
3. $K\le N-1$ 保证至少有一种安排：相邻两人各赛一场即可。
4. 边界：$N=2,K=1$ 时答案就是两人之差；$K=N-1$ 时取全部相邻差。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：把"执黑/执白次数"翻译成图的结构

把每个人看成点，一场对弈看成一条边，方向由等级低指向等级高（低者执白、高者执黑）。则：

- 每个点出度 $\le1$（最多执白一次）、入度 $\le1$（最多执黑一次）；
- 因为边的方向严格沿等级上升，图中不可能有有向环。

**引理 1（路径分解）**：任一合法安排的对局图，是若干条**点不相交**的有向路径的并；每条路径上的点按等级严格递增。

*证明*：出度、入度均 $\le1$，故每个弱连通分量要么是路径、要么是环。若存在有向环 $v_1\to v_2\to\cdots\to v_t\to v_1$，则等级满足 $r_{v_1}<r_{v_2}<\cdots<r_{v_t}<r_{v_1}$，矛盾。故每个分量都是路径；沿有向边走等级严格递增。点不相交由"每条边贡献一个出度与一个入度"直接得到。$\square$

### 第二步：一条路径的代价只与两端有关

设排序后等级为 $v_1<v_2<\cdots<v_N$，记相邻差 $\Delta_j=v_{j+1}-v_j$（$1\le j<N$）。

**引理 2（路径代价 = 区间内相邻差之和）**：若一条路径的下标依次为 $a_1<a_2<\cdots<a_t$（相邻两点间有边），则该路径的代价为

$$\sum_{k=1}^{t-1}(v_{a_{k+1}}-v_{a_k})=v_{a_t}-v_{a_1}=\sum_{j=a_1}^{a_t-1}\Delta_j .$$

*证明*：望远镜求和给出第一个等号；第二个等号是把区间 $[a_1,a_t]$ 拆成相邻差之和。$\square$

也就是说：**一条有 $t$ 个点的路径，代价等于它"张成"的区间内所有相邻差之和，而它只用了 $t-1$ 条边。** 区间可能比边数长，这对下界有利（多出来的差都是正的，只会让代价更大）。

### 第三步：下界——任何方案都不便宜

**引理 3（下界）**：任一合法安排的代价 $\ge$ 最小的 $K$ 个相邻差之和 $S_K$。

*证明*：对每条对局边 $(a,b)$（$a<b$，$a$ 执白），把它映射到相邻差 $\Delta_a$。由引理 1，每个点出度 $\le1$，即每个下标 $a$ 至多是一条边的低端点，故这个映射是**单射**，像集 $U$ 恰有 $K$ 个不同的相邻差。

由引理 1，全部边按路径分组，由引理 2，总代价 $=\sum_{\text{路径 }p}\sum_{j\in[a_1^{(p)},a_t^{(p)}-1]}\Delta_j$。每条边 $(a,b)$ 所在的路径区间包含 $\Delta_a$，所以上式右端对每个 $j\in U$ 至少累加一次，且所有 $\Delta_j>0$，于是

$$\text{总代价}\ \ge\ \sum_{j\in U}\Delta_j\ \ge\ S_K,$$

最后一步因为 $|U|=K$，而 $S_K$ 是任取 $K$ 个相邻差之和的最小值。$\square$

### 第四步：上界——取最小的 $K$ 个相邻差真的可行

**引理 4（构造）**：把相邻差按大小排序，取最小的 $K$ 个，对每个选中的 $\Delta_j$ 安排一场 $v_j$ 与 $v_{j+1}$ 的对弈，则这个安排合法。

*证明*：只需要检查"每人至多执黑一次、至多执白一次"。选手 $v_j$ 只会出现在两场候选对局中：$(v_{j-1},v_j)$（他执黑）与 $(v_j,v_{j+1})$（他执白）。即使两场都被选中，也是一黑一白，各一次，合法。故任意子集都可行，特别地这 $K$ 场可行，代价恰为 $S_K$。$\square$

**定理**：答案为最小的 $K$ 个相邻差之和。

*证明*：引理 3 给出任何方案代价 $\ge S_K$，引理 4 给出达到 $S_K$ 的可行方案，故最小值为 $S_K$。$\square$

### 第五步：实现

排序 $O(N\log N)$；求 $N-1$ 个相邻差；再排序取前 $K$ 个求和，$O(N\log N)$。注意到"每人最多两场"的约束在引理 4 中被证明**从不生效**——任意相邻对子集都合法，所以本题退化为"取 $K$ 个最小相邻差"，不需要 DP 或匹配。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 执黑/执白各至多一次 $\Rightarrow$ 对局图是若干条等级递增的点不交路径。
- `explore its property` — 一条路径的代价等于其张成区间内相邻差之和（望远镜）。
- `consider easier version` — 只保留"相邻两人对弈"这一种子集，先看它是否总能取到最优。
- `classic problem solution` — 把每条边映射到它的低端点所在的相邻差，用单射给出下界。
- `classic problem solution` — 排序 + 取前 $K$ 小的相邻差，$\mathcal{O}(N\log N)$ 直接构造最优解。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $N$ | `n` | 人数 |
| $K$ | `k` | 对局场数 |
| $v_i$ | `a[i]` | 排序后的等级数组（0-based），读入后 `sort(a,a+n)` |
| $\Delta_i$ | `d[i]` | 相邻差 `a[i+1]-a[i]`，共 $n-1$ 个，随后再排序 |
| $S_K$ | `ans` | 前 $K$ 个相邻差之和，即答案，`i64` |
| — | `mxn` | 数组上界 $10^5+5$ |

### 算法步骤

1. 读入 $n,k$ 与 $n$ 个等级到 `a`。
2. `sort(a,a+n)` 升序排列。
3. 对 $i=0..n-2$ 计算 `d[i]=a[i+1]-a[i]`。
4. `sort(d,d+n-1)`，把 `d[0..k-1]` 累加进 `ans`。
5. 输出 `ans`。

### 复杂度分析

- **时间复杂度**：两次排序 $\mathcal{O}(N\log N)$，求和 $\mathcal{O}(K)$，总计 $\mathcal{O}(N\log N)$。$N=10^5$ 实测约 $0.02$ s。
- **空间复杂度**：$\mathcal{O}(N)$，两个静态数组。

### 正确性验证

引理 1 刻画了对局图的形状，引理 2 把代价化为区间相邻差之和，引理 3 用单射给出下界，引理 4 给出达到下界的构造，定理收尾。数值上单个差 $<10^9$，$K\le10^5$，和 $<10^{14}$，`long long` 安全；`a` 与 `d` 都用 `int` 足够（差也 $<10^9$，但累加必须用 `i64`）。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1626 象棋比赛
// https://www.luogu.com.cn/problem/P1626
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n,k,a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int i=0;i<n;++i)
		cin>>a[i];
	sort(a,a+n);
	// 任意若干条相邻差都能同时取到：每个选手最多占左右两条边各一次（左白右黑）
	static int d[mxn];
	for(int i=0;i+1<n;++i)
		d[i]=a[i+1]-a[i];
	sort(d,d+n-1);
	i64 ans=0;
	for(int i=0;i<k;++i)
		ans+=d[i];
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **不排序直接取差**：必须先按等级排序，"相邻"指的是等级相邻，不是输入相邻。
2. **用 `int` 存答案**：$K$ 个差累加可达 $10^{14}$，`ans` 必须是 `i64`。
3. **误加 DP/匹配**：本题"每人两场"的约束恒可满足（引理 4），不需要更复杂的模型，否则会写出又慢又错的代码。
4. **只取前 $K$ 个差却重复使用同一对**：要取 $K$ 个**不同下标**的相邻差，用 `sort` 后按下标取即可。
5. **`d` 的规模**：只有 $n-1$ 项，`sort(d,d+n-1)` 的边界不能写成 `n`。
