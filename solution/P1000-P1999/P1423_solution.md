# P1423 小玉在游泳

> 标签：模拟 / 等比数列 / 浮点误差 · 难度：入门

## 1. 重新读题

**条件**

- 第 1 步游 $2$ 米，**不衰减**。
- 第 $i$ 步（$i\ge 2$）游"上一步距离的 $98\%$"，即 $step_i=0.98\cdot step_{i-1}$。
- 每步距离严格为正且逐项递减。

**目标**

- 求最小整数 $n$，使前 $n$ 步累计距离 $\sum_{i=1}^{n}step_i\ge s$，输出 $n$。

**数据范围**

- $0\le s<100$，$s$ 小数点后最多一位。输入仅一个实数，无多组数据。

**陷阱与边界**

- $s=0$：一步都不用游，答案是 $0$，不是 $1$。用 `do…while` 或不判空就自增的写法会输出 $1$。
- **"游完第 $n$ 步恰好到达"算不算已到达**：算。题目问的是"要游到距离 $s$ 米的地方需要多少步"，第 $n$ 步结束那一瞬位置 $\ge s$ 就已满足。因此判定符号必须是 $\ge$（等价地循环条件用 `pre[n]<s`）。若误写成严格的 $>$，$s=2.0$ 会被判成 $2$ 步，而正确答案是 $1$ 步。
- 衰减"施加在哪一步"：递推是"先加本步、再算下步"。常见写错成先乘 $0.98$ 再加，于是第一步变成 $1.96$ 米，所有答案整体偏大。
- 上界陷阱：级数极限是 $100$ 米（见引理 3），$s$ 越接近 $100$ 步数越多；题目用 $s<100$ 保证有解，但循环必须能跑到约 $342$ 步，数组/循环上界不能按"入门题=几十步"随便取。
- 浮点累加误差：$0.98$ 与大多数一位小数（如 $99.9$）在二进制下都不可精确表示，连加数百次有漂移风险；$\varepsilon$ 容差的方向也要想清楚（见 §2.6）。
- 数据只有一组输入，没有多测、没有 $T$；$s$ 小数点后**最多**一位，所以 $2$、$2.0$、$0.5$ 都是合法输入形式。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制：把"上一步的 98%"翻译成通项

题面里唯一的特殊机制是那句话："接下来的每一步都只能游出上一步距离的 $98\%$"。先把这句话变成公式，因为后面所有的判断都靠它。

**引理 1（通项公式）** 第 $i$ 步的距离 $step_i=2\cdot 0.98^{\,i-1}$ 米。

**证明**（数学归纳法，对 $i$）

- $i=1$：$2\cdot 0.98^{0}=2\cdot 1=2$，与"第一步能游 $2$ 米"一致。
- 归纳假设 $i=k$ 成立，即 $step_k=2\cdot 0.98^{k-1}$。由机制 $step_{k+1}=0.98\cdot step_k=0.98\cdot 2\cdot 0.98^{k-1}=2\cdot 0.98^{k}$，即 $i=k+1$ 也成立。
- 由归纳法，对所有 $i\ge 1$ 成立。$\blacksquare$

**引理 2（前 $n$ 步累计的闭式）** $pre_n=\sum_{i=1}^{n}step_i=100\left(1-0.98^{\,n}\right)$。

**证明**（错位相减，不需要记等比求和公式）

记 $S=pre_n=2+2\cdot 0.98+\cdots+2\cdot 0.98^{n-1}$。两边乘 $0.98$：

$$0.98\,S=2\cdot 0.98+2\cdot 0.98^2+\cdots+2\cdot 0.98^{n}$$

两式相减，中间 $n-1$ 项 $2\cdot 0.98,\dots,2\cdot 0.98^{n-1}$ 完全对齐抵消，只剩首尾：

$$S-0.98S=2-2\cdot 0.98^{n}\ \Longrightarrow\ 0.02\,S=2\left(1-0.98^{n}\right)\ \Longrightarrow\ S=\frac{2}{0.02}\left(1-0.98^{n}\right)=100\left(1-0.98^{n}\right).\ \blacksquare$$

代入检查：$pre_1=100(1-0.98)=2$ ✓，$pre_2=2+1.96=3.96=100(1-0.9604)$ ✓。

**引理 3（单调性、上界与可达性）**

1. $pre_n$ 严格递增：$pre_{n+1}-pre_n=step_{n+1}=2\cdot 0.98^{n}>0$（引理 1 中 $0.98^{n}>0$）。
2. $pre_n<100$ 恒成立：由引理 2，$100-pre_n=100\cdot 0.98^{n}>0$。
3. 对任意 $s<100$，存在 $n$ 使 $pre_n\ge s$（题目一定有解）。

**证明** 前两式已在上文一行推出。第 3 式需要一个"上界"版本的 $0.98^{n}\to 0$：

- $0.98=\dfrac{49}{50}$，故 $0.98^{\,n}=\dfrac{1}{(1+\frac{1}{49})^{n}}$。
- 由伯努利不等式 $(1+x)^{n}\ge 1+nx$（$x\ge -1$ 时成立；对 $n$ 归纳即可证明：$n=1$ 取等，$(1+x)^{k+1}\ge(1+kx)(1+x)=1+(k+1)x+kx^{2}\ge 1+(k+1)x$），取 $x=\frac1{49}$ 得 $(1+\frac1{49})^{n}\ge 1+\frac{n}{49}$，于是 $0.98^{\,n}\le\dfrac{1}{1+n/49}$。
- 给定 $s<100$，只要取 $n>\dfrac{49s}{100-s}$（右端有限，因为 $100-s>0$），就有 $\dfrac{100}{1+n/49}<100-s$，从而
  $$pre_n=100-100\cdot 0.98^{\,n}\ \ge\ 100-\frac{100}{1+n/49}\ >\ 100-(100-s)=s.\ \blacksquare$$

> **机制小结**：这个机制就是一个公比 $0.98\in(0,1)$ 的等比数列。累计距离单调上升但被 $100$ 卡住——"永远游不到 100 米"，而 $s<100$ 恰好落在能达到的范围内。可达性有解（引理 3 第 3 条），但**解的位置对 $s$ 极端敏感**：$s=99.9$ 需要 $342$ 步，$s=2$ 只要 $1$ 步。

### 2.2 简化版：把衰减机制剥掉，先定义"最小步数"

**简化版**：每步恒游 $2$ 米，则 $pre_n=2n$，答案是 $\lceil s/2\rceil$。

**引理 4（简化版答案）** 无衰减时，最小的满足 $2n\ge s$ 的非负整数 $n$ 是 $\lceil s/2\rceil$；特别地 $s=0$ 时 $n=0$。

**证明** 集合 $A=\{n\in\mathbb{Z}_{\ge 0}:2n\ge s\}$ 非空（$n=\lceil s/2\rceil$ 属于它），故有最小元 $n^{*}=\min A$。$n^{*}-1\notin A\Rightarrow 2(n^{*}-1)<s\le 2n^{*}$，即 $s/2-1<n^{*}\le s/2$，区间 $(s/2-1,\,s/2]$ 内恰含一个整数 $\lceil s/2\rceil$，故 $n^{*}=\lceil s/2\rceil$。$s=0$ 时 $A=\mathbb{Z}_{\ge0}$，最小元 $0$。$\blacksquare$

这一步的真正收获不是公式，而是**把目标定成"下界"而不是"最接近"**：答案是"$\{n:pre_n\ge s\}$ 的最小元"，$pre_n$ 比 $s$ 大很多也没关系（$s=3.9$ 答案就是 $2$，因为 $3.96\ge3.9$），比 $s$ 差一点点也不行。加衰减后 $2n\ge s$ 不再成立，但"最小元"这个定义原封不动地保留下来。

### 2.3 剖析"套公式"为什么会翻车

有了引理 2，最自然的想法是直接反解：

$$pre_n\ge s\ \Longleftrightarrow\ 100\left(1-0.98^{n}\right)\ge s\ \Longleftrightarrow\ 0.98^{n}\le 1-\frac{s}{100}.$$

**引理 5（实数域的反解正确）** 记 $s_0=\max\{0,\,1-s/100\}$。若 $s_0>0$，则 $0.98^{n}\le s_0\Longleftrightarrow n\ge\dfrac{\ln s_0}{\ln 0.98}$（注意 $\ln 0.98<0$，取对数后不等号**反向**），故实数域答案是 $\left\lceil \dfrac{\ln s_0}{\ln 0.98}\right\rceil$。

**证明** $\ln$ 在 $(0,+\infty)$ 上严格递增，故 $0.98^{n}\le s_0\Longleftrightarrow n\ln 0.98\le \ln s_0$。$\ln 0.98=-0.0202027\ldots<0$，两边除以它必须变号：$n\ge \ln s_0/\ln 0.98$。右端记为 $r$，则满足 $n\ge r$ 的最小整数是 $\lceil r\rceil$。$\blacksquare$

公式在实数里是对的，但在浮点里不可信，失败原因有两类，都能构造具体数据：

- **失败模式 A（取整函数在整点上的双边敏感）**：$s=2.0$ 时真实 $r=\ln 0.98/\ln 0.98=1$ 是**整数**。程序里分子分母是两次不同的浮点运算结果，比值可能是 $0.99999999999999989$ 也可能是 $1.0000000000000002$；于是 `ceil(r)` 可能给出 $1$（碰巧对）或 $2$（错），而 `floor(r)+1` 会**稳定地**给出 $2$，与正确答案 $1$ 不符。手算确认：$pre_1=2\ge 2.0$，所以答案是 $1$。
- **失败模式 B（中间量的舍入误差）**：$s=99.9$ 时 $1-s/100$ 应为 $0.001$，但 $99.9$ 本身在二进制里就不是精确值（存成 $99.90000000000000568\ldots$），算出的 $1-s/100$ 是 $0.00099999999999994316\ldots$，与 $0.001$ 差 $5.7\times 10^{-17}$。这次比值仍落在 $341.9$ 附近、$\lceil\cdot\rceil$ 得 $342$（正确答案），属于"侥幸没跨越整数边界"。一旦真实 $r$ 的小数部分极接近 $0$ 或 $1$，这种扰动就会改变结果。

结论：公式法把"判定一次比较"变成了"两次超越函数 + 一次除法 + 一次取整"，误差被放大，且**没有任何廉价的补救方式**（想补救就得回代检验 $pre_{n}$ 与 $pre_{n-1}$，那等价于把模拟再做一遍）。所以放弃闭式反解，回到定义本身。

### 2.4 经典解法：顺序模拟（模拟累加 + 首次达标即停）

最朴素也最稳的做法：老老实实一步步游，维护"当前累计距离"，第一次不小于 $s$ 就报告步数。

**引理 6（模拟的正确性）** 设算法为

```
sum=0; n=0; step=2;
while(sum<s){ sum+=step; step*=0.98; n+=1; }
return n;
```

（所有量在**实数**域运算）则返回的 $n$ 恰是 $\min\{k\ge 0:pre_k\ge s\}$。

**证明** 先证循环不变式：进入第 $t$ 轮循环体之前有 $sum=pre_{t}$、$step=2\cdot 0.98^{\,t}$、$n=t$（对 $t$ 归纳：$t=0$ 时 $pre_0$ 定义为空和 $=0$，$step=2\cdot 0.98^{0}=2$，$n=0$，成立；一轮循环把 $sum$ 加上 $step=step_{t+1}$，由引理 1 正是第 $t+1$ 步的距离，故 $sum\leftarrow pre_{t+1}$，$step\leftarrow 0.98\cdot 2\cdot 0.98^{t}=2\cdot 0.98^{t+1}$，$n\leftarrow t+1$）。

- **终止性**：由引理 3 第 3 条，存在 $N$ 使 $pre_N\ge s$，故不变式表明 $sum$ 到第 $N$ 轮后 $\ge s$，循环条件必假，算法在有限步内退出。
- **返回值最小**：退出瞬间 $n=k$ 且 $pre_k=sum\ge s$（不变式），所以 $k\in A=\{j:pre_j\ge s\}$。而循环之所以执行了第 $k$ 轮，是因为当时 $pre_{k-1}=sum<s$，即 $k-1\notin A$；再由 $pre$ 严格递增（引理 3 第 1 条），$j<k-1\Rightarrow pre_j<pre_{k-1}<s$，故 $k-1$ 以下全不在 $A$ 中。于是 $k=\min A$。
- **$s=0$ 的边界**：$pre_0=0\ge 0$，循环条件 $0<0$ 为假，直接进入判断即返回 $n=0=\min A$。$\blacksquare$

注意"先加后乘"这个顺序：它是不变式 $step=2\cdot 0.98^{t}$ 成立的必要条件。**反例（顺序写错）**：若写成 `while(sum<s){step*=0.98; sum+=step; n+=1;}`，则第一轮加的是 $1.96$，$sum$ 序列变成 $1.96,3.8808,\dots$。取 $s=2.0$：真实答案 $1$（$pre_1=2\ge2$），错误程序走两轮（$1.96<2$，$1.96+1.9208=3.8808\ge2$）输出 $2$。这是本题最常见的 WA。

**另一个反例（判定符号写反）**：把条件写成 `while(sum<=s)`，即要求"严格超过 $s$"，$s=2.0$ 时 $sum=2\le 2$ 继续加，输出 $2$，同样错。这正是 §1 说的"恰好到达算不算已到达"。

### 2.5 归约到更简单的问题：单调数组上的 lower_bound

把引理 6 的过程"存档"，得到一个更清楚的视角：先算出 $pre_1,\dots,pre_{N}$ 放进数组，再问"$s$ 第一次被超过是在哪个下标"。

**引理 7（归约）** 求 $\min\{n:pre_n\ge s\}$ 等价于在**非递减**序列 `pre[0..N]`（`pre[0]=0`）上做 `lower_bound`，即"第一个不小于 $s$ 的位置"。

**证明** `lower_bound` 的定义就是 $\min\{i:\text{pre}[i]\ge s\}$，与目标集合 $A$ 的最小元同义。而 `lower_bound` 的正确性前提是序列非递减，正好由引理 3 第 1 条（$pre_{n+1}-pre_n=step_{n+1}>0$）提供。$\blacksquare$

这一步把"模拟一个物理过程"归约成"在一个单调数组上找下界"，好处有两个：

1. 线性扫描（本题 $N\le 342$，$O(N)$ 完全够）；
2. 若 $N$ 很大（例如公比更接近 $1$、或目标精度很高），可以先按倍增方式扩张数组长度再做二分，判定函数 `check(n)` 换成引理 2 的闭式即可 $O(\log N)$，代价是回到 §2.3 的浮点风险。

本题选 1：既然要模拟，就用递推 $step_{i+1}=0.98\,step_i$ 来填表，完全绕开 $\log/\exp$，判定只用一次减法级别的比较。

### 2.6 误差、上界与溢出防护

模拟法只剩两个技术问题：**(i)** 循环最多要跑多少轮（决定数组尺寸）；**(ii)** 浮点累加会不会把某次 `pre[n]<s` 的比较结果弄反。

**(i) 步数上界：答案是 $s$ 的单调函数，最坏情形 $s=99.9$。**

**引理 8（最坏步数）** 合法输入下答案不超过 $342$。

**证明** 由引理 3 第 1 条，$pre_n$ 随 $n$ 增，故"达到 $s$ 所需步数"随 $s$ 增大而不减；合法 $s$ 至多一位小数且 $s<100$，故 $s\le 99.9$，只需证 $pre_{342}\ge 99.9$ 且 $pre_{341}<99.9$。

- $pre_n\ge 99.9\Longleftrightarrow 0.98^{\,n}\le 0.001\Longleftrightarrow n\ln 0.98\le\ln 0.001$（变号，见引理 5）$\Longleftrightarrow n\ge \dfrac{\ln 1000}{-\ln 0.98}$。
- 手算 $-\ln 0.98=-\ln(1-0.02)=0.02+\dfrac{0.02^{2}}{2}+\dfrac{0.02^{3}}{3}+\dfrac{0.02^{4}}{4}+\cdots=0.02+0.0002+0.00000267+0.00000004=0.02020271$。级数各项为正，被舍掉的尾项满足 $\sum_{k\ge5}\dfrac{0.02^{k}}{k}\le\dfrac{1}{5}\sum_{k\ge5}0.02^{k}=\dfrac{0.02^{5}}{5(1-0.02)}<6.6\times10^{-10}$，所以真值落在 $\left(0.02020271,\ 0.02020271+7\times10^{-10}\right)$：分母只会更大、比值只会更小，变化量 $<341.92\times\dfrac{7\times10^{-10}}{0.0202}=1.2\times10^{-5}$，不影响下面的结论。
- $\ln 1000=3\ln 10=3\times 2.30258509=6.90775528$。
- 比值 $=6.90775528/0.02020271$：$0.02020271\times 340=6.8689$，余 $0.0388$，$0.0388/0.02020271=1.92$，即 $341.92$，误差量级 $10^{-5}$ 远小于 $341.92$ 到两端整数 $341$、$342$ 的距离（$0.08$ 与 $0.92$），故 $341<r<342$ 得证。
- 故 $n\ge 341.92$ 的最小整数是 $342$，$pre_{342}\ge 99.9$ 而 $pre_{341}<99.9$。$\blacksquare$

于是数组开 $405$（$342$ 加松弛）足够覆盖全部合法输入。

**(ii) 浮点误差的量级。**

**引理 9（累加误差上界）** 用 `double` 顺序累加到 $n\le 342$ 步时，计算值 $\widehat{pre}_n$ 与真值 $pre_n$ 满足 $|\widehat{pre}_n-pre_n|<3\times 10^{-11}$。

**证明** IEEE-754 双精度舍入模型：每次基本运算的结果等于精确结果乘 $(1+\delta)$，$|\delta|\le u=2^{-53}\approx 1.11\times 10^{-16}$。

1. 两个引理式事实：若 $2mu\le 1$，则 $(1+u)^{m}-1\le 2mu$（伯努利 $(1+u)^m\le e^{mu}\le 1+2mu$，后者对 $mu\le 1$ 成立）。
2. $\widehat{step}_i$ 由 $i-1$ 次"乘 $c=fl(0.98)=0.98(1+\delta_0)$"得到，每次乘法再带一个自身的舍入因子，故总共不超过 $2(i-1)$ 个 $(1+\delta_j)$：$\widehat{step}_i=step_i\prod_{j\le 2(i-1)}(1+\delta_j)$，相对误差 $\le(1+u)^{2i}-1\le 4iu$。
3. $\widehat{pre}_n$ 是 $n$ 次顺序加法的结果，第 $i$ 项 $\widehat{step}_i$ 被计入后又参与 $n-i+1$ 次加法的舍入，所以它前面的因子总数 $\le 2(i-1)+(n-i+1)\le 2n-1\le 3n$（$n\ge1$），即 $\widehat{pre}_n=\sum_i step_i\prod_{j\le 3n}(1+\delta_j)$，每一项的相对偏差 $\le(1+u)^{3n}-1\le 6nu$。
4. 因为所有加数**同号为正**，不存在正负抵消，绝对误差 $|\widehat{pre}_n-pre_n|\le 6nu\cdot pre_n\le 6\times 342\times 1.11\times 10^{-16}\times 100=2.28\times 10^{-11}<3\times 10^{-11}$。$\blacksquare$

有了误差量级，还要回答"$2.3\times 10^{-11}$ 会不会翻转某个比较"。真正危险的是 $pre_n$ 恰好等于 $s$，这一点可以完全刻画：

**引理 10（唯一的恰等边界）** 设 $n\ge 1$、$s=S/10$（$S\in\mathbb{Z}$，$0\le S\le 999$）。$pre_n=s$ 当且仅当 $n=1$ 且 $S=20$（即 $s=2.0$）。

**证明** 由引理 2，$pre_n=100(50^{n}-49^{n})/50^{n}$，于是
$$pre_n=\frac{S}{10}\ \Longleftrightarrow\ 1000(50^{n}-49^{n})=S\cdot 50^{n}\ \Longleftrightarrow\ 50^{n}(1000-S)=1000\cdot 49^{n}.$$
比较两边因子 $5$ 的个数 $v_5$：

- 左边 $v_5=2n+v_5(1000-S)\ge 2n$（$S\le 999$ 保证 $1000-S\ge 1$，$v_5\ge 0$）。
- 右边 $1000\cdot 49^{n}=2^{3}\cdot 5^{3}\cdot 49^{n}$，而 $\gcd(49,5)=1$，故 $v_5=3$。
- 相等要求 $2n\le 3$，即 $n\le 1$，结合 $n\ge 1$ 得 $n=1$。
- 回代 $n=1$：$50(1000-S)=1000\cdot 49=49000\Rightarrow 1000-S=980\Rightarrow S=20$ ✓。
- 反向：$n=1,S=20$ 即 $pre_1=2=s$ ✓。$\blacksquare$

**引理 11（不加 $\varepsilon$ 容差才更安全）** 本题应当用严格的 `pre[n]<s` 比较，不应写成 `pre[n]+eps<s` 之类。

**证明** 设把"未到达"的判据放宽为 $\widehat{pre}_n<s-\varepsilon$。若存在一组 $(n,s)$ 使真值满足 $s-\varepsilon<pre_n<s$（真实答案 $>n$，但 $pre_n$ 已经很接近 $s$），放宽后的算法会在 $n$ 处就停下并输出 $n$，**答案偏小**。要用这种放宽，就必须先证明"所有非恰等情形与 $0.1$ 网格的距离都 $>\varepsilon$"。而
$$\left|pre_n-s\right|=\frac{\left|50^{n}(1000-S)-1000\cdot 49^{n}\right|}{10\cdot 50^{n}},$$
分子由引理 10 是**非零整数**，只能给出下界 $\dfrac{1}{10\cdot 50^{n}}$，$n=342$ 时约 $10^{-584}$——完全不够用。
反过来，不加 $\varepsilon$ 时我们只需要担心 $pre_n=s$ 这一种情形，而引理 10 把它压缩到唯一的 $s=2.0,n=1$；此时 $2.0$、$0.0$ 都是二进制可精确表示的数，$pre_1=0.0+2.0$ 的计算结果逐位等于 $2.0$，读入 $2$ / `2.0` 也精确得到 $2.0$，比较 `2.0<2.0` 结果为假，算法恰好输出 $1$。即：**危险情形已被穷尽，且那一点上是位精确的，$\varepsilon$ 只会引入新的错误。**$\blacksquare$

剩下的非恰等情形靠"距离远大于 $2.3\times 10^{-11}$"来保证。这不是严格证明（上界只到 $10^{-584}$ 那种量级），所以给出可查证的两点实据：最紧的上界端 $s=99.9$ 处，$pre_{342}=100-100\times 0.00099843=99.90016$，与 $99.9$ 差 $1.6\times 10^{-4}$；$pre_{341}=100-100\times 0.00101881=99.89812$，与 $99.9$ 差 $1.9\times 10^{-3}$。而 $n\le 342$ 时最小步长 $step_{342}=2\cdot 0.98^{341}\approx 2.0\times 10^{-3}$，也就是说越靠近 $100$ 米，前缀和落在 $0.1$ 网格附近的"最坏运气"也就在这个量级；$1.6\times 10^{-4}$ 对 $2.3\times 10^{-11}$ 有 $7$ 个数量级余量。若想彻底安心，把 `double` 换成 `long double`（$u=2^{-64}\approx 5.4\times 10^{-20}$），引理 9 的误差界再缩小约 $2000$ 倍到 $1.2\times 10^{-14}$。

**溢出与死循环防护**

- 全程只有浮点加法与乘常数，没有整数乘法，$pre_n<100\ll 1.8\times 10^{308}$（`double` 上限），不会上溢；$step_{342}\approx 2\times 10^{-3}\gg 2.2\times 10^{-308}$（下溢阈值），不会下溢成 $0$。
- 真正的风险是"死循环"：如果有人把 $s$ 的上界改成 $100$（非法输入），$pre_n$ 永远达不到它；更糟的是浮点下当 $step$ 小于 $pre$ 的 ulp（$\approx 1.8\times 10^{-14}$，对应 $n\approx 1500$）后累加不再改变 $pre$，程序会无限循环。因此代码里保留 `n<mxn-2` 这个守卫，把"越界假设"退化成"输出一个有限数"而不是挂死。
- 数组尺寸 $405>342$（引理 8）。填表循环 `i` 最大取 $403$（`i<mxn-1`），写 `pre[403]` 与 `step[404]`，均 $<$ `mxn`，不越界；扫描循环的守卫把 `n` 限制在 $\le403$，只读被赋过值的 `pre[0..403]`（`pre[404]` 从未使用，它保持默认的 $0$，若误读会当成"已到达"——这里是刻意避开）。

## 3. 模式总结（Pattern Summary）

按真实思考顺序，一条一个技巧，重复出现的步骤拆开列：

- explore its property — 把"上一步的 98%"写成等比通项 + 错位相减求闭式，立刻得到上界 $100$ 与"严格递增"两条全局性质
- consider easier version — 去掉衰减成 $2n\ge s$，用来把目标敲定成"集合 $\{n:pre_n\ge s\}$ 的最小元"而不是"最接近 $s$"
- classic problem solution — 反解闭式 + `ceil`：实数域正确（引理 5），先确认它成立的条件
- dissect the failure — 同一套公式在浮点里失败，定位到两处：整点上的取整敏感（$s=2.0$）与超越函数舍入（$s=99.9$）
- reduce to easier problem — 放弃闭式，回到"最小元"定义本身，把物理过程归约成单调数组上的 lower_bound（引理 7）
- classic problem solution — 顺序模拟累加、首次达标即停；用循环不变式证正确性（引理 6）
- discuss by category — 同一个模拟有两个出口：线性扫描（本题）/ 预处理表 + 二分（$N$ 巨大时），按规模选
- bound the loop first — 答案对 $s$ 单调，故最坏步数在最大合法 $s=99.9$ 处取到，手算对数得 $342$，用它定数组尺寸
- error analysis, sign-aware — 同号相加才有相对误差界（引理 9）；危险点只有"恰等"，而恰等被数论穷尽成一点且二进制精确（引理 10、11）
- guard against the illegal input — 用 `n<mxn` 守卫把"s≥100 时无解 + 浮点累加饱和"导致的死循环降级为有限输出

## 4. 真实解法

### 4.1 符号表

| 符号 | 存什么 | 初始值 / 递推 | 一句话记忆 |
|---|---|---|---|
| `s` | 目标距离（米），`double` 读入 | `cin>>s` | 题目给的那个实数 |
| `step[i]` | 第 $i$ 步游几米（$i$ 从 $1$ 起） | `step[1]=2`；`step[i+1]=step[i]*0.98` | "这一步"，先被加进累计、再衰减出下一步 |
| `pre[i]` | 前 $i$ 步的累计距离（$i$ 从 $0$ 起） | `pre[0]=0`（全局数组自动为 $0$）；`pre[i]=pre[i-1]+step[i]` | 游完 $i$ 步后到达的位置 |
| `n` | 答案：最小的 $i$ 使 `pre[i]>=s` | `n=0`，`while(pre[n]<s) ++n` | "下界位置"，$0$ 步也合法（$s=0$） |
| `mxn` | 表长上界，编译期常量 | `constexpr int mxn{405}` | 引理 8 给出真实需求 $342$，$+5$ 松弛 |

不变量（引理 6 的证明）：填表循环第 $i$ 轮结束时 `pre[i]` $=pre_i$ 且 `step[i+1]` $=step_{i+1}$，即"先加后乘"。

### 4.2 步骤

1. 关同步、读入 `s`。
2. 置 `step[1]=2`：第一步不衰减，这是"先加后乘"的实现方式。
3. 递推填表 `for(int i=1;i<mxn-1;++i){pre[i]=pre[i-1]+step[i];step[i+1]=step[i]*0.98;}`，得到严格递增的 `pre[0..mxn-2]`（引理 3 第 1 条）。
4. `n=0` 起扫描，只要 `pre[n]<s` 就 `++n`，附守卫 `n<mxn-2` 防止非法输入挂死（§2.6 末）。
5. 输出 `n`。$s=0$ 时 `pre[0]=0<0` 为假直接输出 $0$；$s=2.0$ 时 `pre[1]=2<2` 为假输出 $1$（引理 10、11 的边界）。

（等价的原地写法：`while(sum<s){sum+=step;step*=0.98;++n;}`，即引理 6 的形式。本文件选填表版，是为了让 §2.5 的"单调数组 lower_bound"归约显式可见，也便于直接替换成 `lower_bound(pre,pre+mxn-1,s)`。）

### 4.3 复杂度

- 时间：填表 $O(mxn)$ + 扫描 $O(mxn)$，实测量级约 $800$ 次浮点运算，即 $O(N_{max})$，$N_{max}=342$（引理 8）。
- 空间：两个 $405$ 项 `double` 数组，约 $6.5\text{ KB}$。原地版本为 $O(1)$ 空间。
- 备选：闭式 + 二分是 $O(\log N_{max})$，但把误差放大到超越函数层面，本题不采用（§2.3）。

- **先乘后加**：$s=2.0$ 时累计变成 $1.96,\ 3.8808$，输出 $2$，正确是 $1$。
- **判据用 `<=`**：$s=2.0$ 时 `2<=2` 成立再加一步，输出 $2$，正确是 $1$。
- **`do…while` 且不处理 $s=0$**：$s=0$ 时先执行一轮，输出 $1$，正确是 $0$。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

// https://www.luogu.com.cn/problem/P1423
constexpr int mxn{405};                 // 引理 8：s<=99.9 时最多 342 步，尺寸按上界 +5 松弛
double step[mxn],pre[mxn];              // step[i]:第 i 步游几米(1 起); pre[i]:前 i 步累计(0 起)

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	double s;
	cin>>s;
	step[1]=2;                          // 第一步不衰减：先把它加进 pre，再算出下一步
	// pre[0] 依赖全局数组默认 0，正好是"空和 = 0"，也保证 s=0 时答案为 0
	for(int i=1;i<mxn-1;++i)
	{
		pre[i]=pre[i-1]+step[i];
		step[i+1]=step[i]*0.98;         // be careful: 乘 0.98 必须在累加之后
	}
	int n=0;
	while(n<mxn-2&&pre[n]<s)            // pre[n]<s <=> 还没到达，必须再游一步
		++n;                            // 用 < 而不是 <=：恰好到达即算已到达
	cout<<n<<'\n';
	return 0;
}

// 原地版本（O(1) 空间，引理 6 的字面实现），与上面等价：
// double s,sum=0,step=2;int n=0;
// cin>>s;

// cout<<n<<'\n';

// 已废弃：闭式反解 n=ceil(log(1-s/100)/log(0.98)) —— s=2.0 时比值落在整数 1 上，
// ceil/floor+1 在浮点扰动下会给 1 或 2，见 §2.3 失败模式 A。
// 已废弃：while(sum<=s) —— s=2.0 输出 2（正确 1）。

// 0 -> 0, 2 -> 1, 2.1 -> 2, 4 -> 3, 5 -> 3, 9.6 -> 5, 9.61 -> 6, 50 -> 35, 99.9 -> 342
```
