# P1060 [NOIP 2006 普及组] 开心的金明 — 题解

---

## 一、发现叙事

### 1.1 故事背景

金明得到了一间新房间，妈妈给他 N 元预算来购置物品。他看中了很多东西，但钱不够全部买下。于是，他给每件物品打了一个"重要度"分（1~5 分），希望在不超预算的前提下，让"价格 × 重要度"的总和最大。

### 1.2 直觉试探

先看一个简单例子。假设有 3 件物品：

| 物品 | 价格 v | 重要度 p | 价值 v×p |
|:---:|:------:|:--------:|:--------:|
|  A  |  800   |    2     |   1600   |
|  B  |  400   |    5     |   2000   |
|  C  |  300   |    5     |   1500   |

预算 N = 1000。

直观地想，B 的"性价比"（价值/价格 = 5）最高，但买了 B（400 元）后还剩 600 元，还能再买 C（300 元），总价值 = 2000 + 1500 = 3500。如果先买 A（800 元），剩 200 元什么也买不了，总价值只有 1600。显然**不能只看单个物品的价值，还要考虑剩余预算能否容纳更多物品**。

这就是背包问题的核心矛盾：**预算约束下，物品之间有"争夺空间"的竞争关系**。

### 1.3 从枚举到 DP

最朴素的想法：枚举所有子集，检查总价是否 ≤ N，取最大价值。m 件物品，2^m 个子集。题目中 m < 25，2^25 ≈ 3.3×10^7，在 2006 年的评测机上勉强可过，但若 m 稍大就会超时。我们需要更好的方法。

观察发现：对于任意一个预算额度 j，我们只关心**用前 i 件物品能凑出的最大价值是多少**，而不关心具体选了哪些物品。这就提示我们可以用**动态规划**来记录每个预算下的最优解。

更具体地，设 dp[j] 表示**花费不超过 j 元**时能获得的最大价值。处理每件物品时，我们有两种选择：
- **不买**：dp[j] 保持不变。
- **买**：花费 v 元，获得 v×p 的价值，剩余预算 j−v 元可以自由支配（对应 dp[j−v]）。

因此转移方程为：
$$
dp[j] = \max(dp[j],\; dp[j-v] + v \times p)
$$

为了保证每件物品最多选一次，预算 j 必须**从大到小**枚举（这样 dp[j−v] 引用的是还没考虑当前物品的状态）。

### 1.4 小例子验证

沿用上例，初始 dp[0..1000] = 0。

**处理物品 A（v=800, val=1600）：**

j 从 1000 向下到 800：dp[900] = max(0, dp[100] + 1600) = 1600，同理 dp[800..1000] = 1600。

**处理物品 B（v=400, val=2000）：**

j = 1000：dp[1000] = max(1600, dp[600] + 2000) = max(1600, 0 + 2000) = 2000
j = 900：dp[900] = max(1600, dp[500] + 2000) = max(1600, 0 + 2000) = 2000
...
j = 400：dp[400] = max(0, dp[0] + 2000) = 2000

**处理物品 C（v=300, val=1500）：**

j = 1000：dp[1000] = max(2000, dp[700] + 1500) = max(2000, 1600 + 1500) = 3100
j = 900：dp[900] = max(2000, dp[600] + 1500) = max(2000, 0 + 1500) = 2000
...

等等！这和我们手算的 3500 不一样！问题出在哪里？

再看一次：dp[700] 在 B 处理后是多少？j=700 从 400 到 700：dp[700] = max(dp[700], dp[300] + 2000) = 2000。所以 dp[700] = 2000。

那么 j=1000：dp[1000] = max(2000, 2000 + 1500) = 3500。正确！

这说明我们推导的转移方程是正确的。

## 二、思维链与完整证明

### 2.1 问题形式化

**输入：**
- 预算上限 N（正整数，N < 3×10^4）
- 物品数量 m（正整数，m < 25）
- 每件物品的价格 v_i（非负整数，v_i ≤ 10^4）和重要度 p_i（整数，1 ≤ p_i ≤ 5）

**定义：** 每件物品的"价值"为 w_i = v_i × p_i。

**目标：** 选择一个子集 S ⊆ {1, 2, ..., m}，使得 ∑_{i∈S} v_i ≤ N，且最大化 ∑_{i∈S} w_i。

### 2.2 最优子结构证明

**定理 1（最优子结构）：** 设 dp[i][j] 表示考虑前 i 件物品、总花费不超过 j 元时能获得的最大价值。那么对于第 i 件物品，有如下递推关系：

$$
dp[i][j] = \begin{cases}
dp[i-1][j] & \text{若 } j < v_i \text{（买不起）} \\[4pt]
\max\big(dp[i-1][j],\; dp[i-1][j-v_i] + w_i\big) & \text{若 } j \ge v_i
\end{cases}
$$

**证明：**
考虑前 i 件物品在预算 j 下的最优方案。对于第 i 件物品，只有两种可能：

1. **不选第 i 件**：那么最优方案完全由前 i−1 件物品在预算 j 下构成，价值为 dp[i−1][j]。
2. **选第 i 件**：需要花费 v_i 元，获得 w_i 的价值。剩余预算 j−v_i 元用于前 i−1 件物品，最优方案的价值为 dp[i−1][j−v_i]。总价值为 dp[i−1][j−v_i] + w_i。

两种可能性覆盖了所有情况，取最大值即为最优解。□

### 2.3 无后效性论证

**定理 2（无后效性）：** dp[i][j] 的计算只依赖 dp[i−1][·] 的值，与"如何达到 dp[i−1][·]"的具体物品组合无关。

**证明：** 从递推式可直接看出，dp[i][j] 的两种候选值都只涉及 dp[i−1] 行的状态。dp[i−1][·] 已经编码了前 i−1 件物品在各个预算下的最优价值，至于这个最优价值是通过哪几个物品达成的，对后续决策没有影响——我们只需要知道"能达到多少价值"，不需要知道"具体选了哪些物品"。因此决策满足无后效性。□

### 2.4 正确性证明（归纳法）

**定理 3：** 上述 DP 算法正确计算出 ≤ N 预算下的最大价值。

**证明（对 i 归纳）：**

**基础情况：** i = 0（没有物品可考虑）。显然 dp[0][j] = 0 对所有 j 成立，因为没有任何物品可选，价值必为 0。

**归纳步骤：** 假设 dp[i−1][·] 对所有预算值都是最优的。我们证明 dp[i][·] 也是最优的。

对于任意预算 j，设 S* 是前 i 件物品中满足预算约束的最优子集。
- 若 i ∉ S*，则 S* 也是前 i−1 件物品在预算 j 下的可行解，故 dp[i−1][j] ≥ value(S*) = dp[i][j]。又 dp[i][j] ≥ dp[i−1][j]（递推式中取 max），所以 dp[i][j] = dp[i−1][j]。
- 若 i ∈ S*，则 S*\{i} 是前 i−1 件物品在预算 j−v_i 下的可行解，故 dp[i−1][j−v_i] ≥ value(S*\{i})。于是 dp[i−1][j−v_i] + w_i ≥ value(S*) = dp[i][j]。同时递推式保证 dp[i][j] ≥ dp[i−1][j−v_i] + w_i，所以等式成立。

综上，dp[i][j] 正确取到最优值。□

### 2.5 空间优化

观察递推式：dp[i][j] 只依赖 dp[i−1][·]。这意味着我们不需要保留整个二维数组，用一个一维数组滚动更新即可。

但要注意：如果 j 从小到大更新，dp[j−v_i] 可能是**已经更新过**（即 dp[i][·] 而非 dp[i−1][·]）的值，这会导致一件物品被重复选取。因此必须**从大到小**枚举 j。

**空间优化后的转移：**
```
for j = N down to v_i:
    dp[j] = max(dp[j], dp[j - v_i] + w_i)
```

### 2.6 复杂度分析

- **时间复杂度：** O(m × N)。每个物品遍历一次预算数组。m < 25，N < 3×10^4，最坏约 7.5×10^5 次操作，轻松通过。
- **空间复杂度：** O(N)。一维数组 dp[0..N]。

## 三、模式总结

### 3.1 问题类型

**0/1 背包问题** — 最经典的动态规划入门模型。

### 3.2 关键特征

| 特征 | 本题表现 |
|:---|:---|
| 选择/不选择 | 每件物品买或不买 |
| 全局约束 | 总花费 ≤ N |
| 最大化目标 | 价格×重要度之和最大 |
| 物品唯一性 | 每件最多买一次（0/1 特点） |

### 3.3 识别技巧

当题目具有以下特征时，可考虑 0/1 背包模型：
1. 有**总量限制**（预算、容量、时间等）
2. 每个物体有**消耗**（价格、体积等）和**收益**（价值、满意度等）
3. 每个物体**最多选一次**
4. 目标是在总量内最大化总收益

### 3.4 常见变体

| 变体 | 差异 | 处理方式 |
|:---|:---|:---|
| 完全背包 | 每件可选无限次 | j 从小到大枚举 |
| 多重背包 | 每件有有限次数 | 二进制拆分或单调队列 |
| 分组背包 | 每组最多选一个 | 组内再做 0/1 决策 |
| 二维背包 | 两种约束（体积+重量） | dp 增加一维 |

### 3.5 调试要点

- **数组大小**：dp 数组长度至少为 N+1（N 的上界 + 5 做松弛）
- **初始化**：dp[0] = 0，其余 = 0（本题求最大值，非负价值）
- **循环方向**：内存循环**必须从大到小**，否则变成完全背包
- **答案取值**：dp[N] 即为不超过 N 元的最大价值

## 四、正式解法与符号表

### 4.1 符号表

| 符号 | 含义 | 范围 |
|:---|:---|:---|
| N | 总预算（背包容量） | < 3×10^4 |
| m | 物品个数 | < 25 |
| v_i | 第 i 件物品的价格 | ≤ 10^4 |
| p_i | 第 i 件物品的重要度（1~5） | 整数 |
| w_i | 第 i 件物品的价值 = v_i × p_i | ≤ 5×10^4 |
| dp[j] | 花费不超过 j 元的最大价值 | 一维数组，长度 N+1 |
| ans | 最终答案 = dp[N] | < 10^8 |

### 4.2 算法流程

```
1. 读入 N, m
2. 初始化 dp[0..N] = 0
3. 对于第 i 件物品 (i = 1..m):
     读入 v, p
     w = v * p
     for j = N down to v:
         dp[j] = max(dp[j], dp[j - v] + w)
4. 输出 dp[N]
```

### 4.3 正确性总结

- **最优子结构**：全局最优解包含子问题的最优解（见定理 1）
- **无后效性**：子问题的最优解一旦确定就不受后续决策影响（见定理 2）
- **归纳保证**：对物品个数归纳可证算法输出全局最优解（见定理 3）

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{30005};

int N,m,dp[mxn];

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>N>>m;
	for(int i=0,v,p,w;i<m;++i)
	{
		cin>>v>>p;
		w=v*p;
		for(int j=N;j>=v;--j)
			if(dp[j-v]+w>dp[j])
				dp[j]=dp[j-v]+w;
	}
	cout<<dp[N]<<'\n';
	return 0;
}
```

### 代码要点说明

- **数组大小**：`mxn{30005}` 对应 N < 3×10^4 的上界 + 5 松弛。
- **一维滚动 DP**：空间 O(N)，随读随处理，无需存储所有物品。
- **循环方向**：`for(int j=N;j>=v;--j)` 从大到小保证 0/1 性质。
- **转移写法**：用 `if` 比较而非 `max` 函数，减少函数调用开销（卡常风格）。
- **临时变量**：`v, p, w` 在循环头中声明，生命周期限于当次迭代。
