# P1910 L 国的战斗之间谍

## 1. 重新读题

有 $N$ 个候选人，第 $i$ 个人能提供 $A_i$ 份资料、伪装能力"差" $B_i$、要工资 $C_i$。选一个子集去 I 国，要求：

$$\sum B_i\le M,\qquad \sum C_i\le X,$$

最大化 $\sum A_i$（拿到的资料总数）。

### 关键约束与规模暗示

- $N\le100$，$M\le1000$，$X\le1000$。
- 两个容量、一个价值，这是标准的**二维费用 0/1 背包**。$O(NMX)=10^8$ 的朴素三重循环在可接受范围内（常数很小），不需要更高级的优化。
- 每个候选人只能选或不选（0/1），不是完全背包。

## 2. 思维链（Chain-of-thought）

### 2.1 先剥掉一个约束：一维背包

如果只有"工资 $\sum C_i\le X$"这一个约束，问题就是：每个物品体积 $C_i$、价值 $A_i$，0/1 背包，$dp[j]$ 表示花不超过 $j$ 元最多拿到多少资料，倒序枚举 $j$ 保证每件只用一次。

现在多了一个"伪装差 $\sum B_i\le M$"。仿照一维，把状态加一维即可：$dp[j][k]$ 表示**总伪装差不超过 $j$、总工资不超过 $k$** 时能拿到的最大资料数。每个物品相当于同时消耗 $B_i$ 和 $C_i$ 两种"体积"。

### 2.2 为什么不能按资料数贪心（失败尝试）

自然的贪心：按 $A_i$ 从大到小选，能塞下就塞。构造反例，取 $M=X=10$：

| 人 | $A$ | $B$ | $C$ |
| :--- | :--- | :--- | :--- |
| 1 | 12 | 6 | 6 |
| 2 | 7 | 5 | 5 |
| 3 | 7 | 5 | 5 |

按 $A$ 降序先选 1 号，用掉 $(6,6)$，剩余容量 $(4,4)$，两外两人都塞不下，只得 $12$。而选 2、3 号，总消耗 $(10,10)$，得到 $14$。**单个"性价比"最高的物品会同时吃掉两种资源，把两个中等物品挤掉**——两个约束耦合时，贪心连近似都不保证，必须做 DP。

### 2.3 状态与转移

设前 $t$ 个人已经决策完，记

$$dp_t[j][k]=\max\Big\{\sum_{i\in S}A_i:\ S\subseteq\{1,\dots,t\},\ \sum_{i\in S}B_i\le j,\ \sum_{i\in S}C_i\le k\Big\}.$$

初值 $dp_0[j][k]=0$（一个都不选）。对第 $t$ 个人：

$$dp_t[j][k]=\max\big(dp_{t-1}[j][k],\ dp_{t-1}[j-B_t][k-C_t]+A_t\big),$$

其中第二项仅在 $j\ge B_t,\ k\ge C_t$ 时存在。

**引理 1（转移正确）**：上式给出的 $dp_t$ 恰好等于定义中的最大值。

**证明**：对任意子集 $S\subseteq\{1,\dots,t\}$，分两类：

1. $t\notin S$：此时 $S\subseteq\{1,\dots,t-1\}$，其价值被 $dp_{t-1}[j][k]$ 覆盖（归纳假设），故不超过第一项。
2. $t\in S$：令 $S'=S\setminus\{t\}$，则 $S'$ 在容量 $(j-B_t,k-C_t)$ 下可行，价值 $\le dp_{t-1}[j-B_t][k-C_t]$，于是 $S$ 的价值 $\le$ 第二项。

所以 $dp_t\le$ 右端。反过来，右端两项分别对应合法子集（第二项要求 $j\ge B_t,k\ge C_t$ 才取），故 $dp_t\ge$ 右端。两边夹逼，等号成立。$\blacksquare$

**引理 2（倒序枚举实现 0/1）**：用一维滚动数组时，外层物品、内层 $j$ 从 $M$ 递减到 $B_t$、$k$ 从 $X$ 递减到 $C_t$，则每次读到的 $dp[j-B_t][k-C_t]$ 都还是"未考虑第 $t$ 个人"的旧值。

**证明**：分三种情况：

- $B_t>0$ 且 $C_t>0$：$(j-B_t,k-C_t)$ 的两个下标都严格更小；倒序枚举到 $(j,k)$ 时，更小的下标在本轮尚未被更新，存的是 $dp_{t-1}$ 的值。
- 恰有一个为 $0$（比如 $B_t=0,C_t>0$）：列下标 $k-C_t<k$，而 $k$ 是倒序的，更小的 $k$ 尚未更新，仍是旧值；$j$ 方向即使相等也无妨，因为只读同一列的旧值。
- $B_t=C_t=0$：读到的就是 $(j,k)$ 自己，每个 $(j,k)$ 在本轮只被更新一次，因此该物品至多被计入一次（若 $A_t>0$，效果是给它加一次 $A_t$；若 $A_t\le0$，`max` 保持原值）。

三种情况下每件物品都至多被选一次，故与二维递推等价。$\blacksquare$

### 2.4 边界处理

- 若 $B_t>M$ 或 $C_t>X$，该人任何方案都选不了，直接跳过（不影响答案）。
- 答案就是 $dp[M][X]$（"不超过"语义，天然包含所有可行子集）。
- 若 $A_i$ 可能为负，不选该人对应 $dp$ 初值 $0$，仍然正确（max 会避开负数）；但本题资料数为非负，直接处理即可。

## 3. 模式总结（Pattern Summary）

- **consider easier version** — 先解只有工资约束的一维 0/1 背包。
- **explore its property** — 两个约束独立累加，给状态加一维（二维费用背包）。
- **exchange argument（反例）** — 按 $A$ 贪心会被双资源耦合击败。
- **classic problem solution** — 二维费用 0/1 背包，倒序枚举两个容量。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 候选人数 $N$ | 读入 | 物品数 |
| `M` | `int` | 伪装差总和上限 | 读入 | 容量 1 |
| `X` | `int` | 工资总和上限 | 读入 | 容量 2 |
| `a[i]` | `int[105]` | 第 $i$ 人的资料数 $A_i$ | 读入 | value |
| `b[i]` | `int[105]` | 第 $i$ 人的伪装差 $B_i$ | 读入 | weight 1 |
| `c[i]` | `int[105]` | 第 $i$ 人的工资 $C_i$ | 读入 | weight 2 |
| `dp[j][k]` | `int[1005][1005]` | 伪装差 $\le j$、工资 $\le k$ 时的最大资料数 | 全 $0$ | 二维背包 |

### 4.2 算法步骤

1. 读入 $N,M,X$ 以及每个人的 $(A_i,B_i,C_i)$。
2. 对每个人 $i=0\dots N-1$：
   - 若 $B_i>M$ 或 $C_i>X$，跳过；
   - 否则 $j$ 从 $M$ 递减到 $B_i$，$k$ 从 $X$ 递减到 $C_i$，执行
     `dp[j][k]=max(dp[j][k],dp[j-b[i]][k-c[i]]+a[i])`。
3. 输出 `dp[M][X]`。

### 4.3 复杂度

- 时间 $O(NMX)\le10^8$，空间 $O(MX)\approx4$ MB。
- 所有量都在 `int` 范围内（资料总数不可能超过 $100\times$ 单人数值）。

## 5. 示例代码

```cpp
//
// 题目：P1910 L 国的战斗之间谍
// https://www.luogu.com.cn/problem/P1910
//
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105},mxm{1005},mxx{1005};

int n,M,X;
int a[mxn],b[mxn],c[mxn];
int dp[mxm][mxx];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>M>>X;
	for(int i=0;i<n;++i)
		cin>>a[i]>>b[i]>>c[i];
	for(int i=0;i<n;++i)
	{
		if(b[i]>M||c[i]>X)
			continue;
		for(int j=M;j>=b[i];--j)
			for(int k=X;k>=c[i];--k)
				dp[j][k]=max(dp[j][k],dp[j-b[i]][k-c[i]]+a[i]);
	}
	cout<<dp[M][X]<<'\n';
	return 0;
}
```
