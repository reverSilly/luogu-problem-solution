# P1510 精卫填海

> 标签：动态规划 DP / 背包 DP · 难度：普及-
> 本地题面：`P1510.md`（$0<n\le10^4$，所有读入数 $\in[0,10^4]$，答案 $\le c$）。验证：官方两组样例；400 组随机对拍全过；最坏 $n=c=10^4$ 约 $0.050$ s。

## 1. 重新读题

**问题重述（人话版）**

东海还差**至少 $v$ 体积**的木石才能填平。西山还剩 $n$ 块木石，第 $i$ 块体积 $k_i$、要花体力 $m_i$ 搬过去。精卫还剩体力 $c$。

选一个子集搬走：要求搬走木石的体积总和 $\ge v$（填平），且体力总和 $\le c$（搬得动）。在满足条件的前提下，**搬完剩下的体力越多越好**，即**消耗的体力越少越好**。输出这个最大剩余体力；若填不平（没有任何可行子集），输出 `Impossible`。

> 一句话版本：$0/1$ 背包——用"体力"当容量、"体积"当价值，求"价值 $\ge v$ 的最小代价"，再输出 $c$ 减去该代价。

**题面里容易漏掉的条款**

1. 「**至少**体积 $v$」$\Rightarrow$ 是 $\Sigma k_i\ge v$，不是恰好 $=$ $v$；超出也算填平。
2. 「$0<n$」和「所有读入的数均属于 $[0,10^4]$」$\Rightarrow$ $v,k_i,m_i$，甚至 $c$，都可以为 $0$。$v=0$ 时"空方案"就满足（消耗体力 $0$，剩 $c$）；$m_i=0$ 的木石是免费体积；$k_i=0$ 的木石是纯负担。
3. 「最大剩余体力」$\Rightarrow$ 等价于**最小化消耗体力** $\Sigma m_i$。答案不需要枚举具体方案，只要那个最小值。
4. 「否则输出 `Impossible`」$\Rightarrow$ 当且仅当**任何**可行子集都无法达到 $\Sigma k_i\ge v$ 时（含"体积总量够但体力都不够搬"）才输出。

**数据范围与规模感受**

$$0<n\le10^4,\qquad v,k_i,m_i,c\in[0,10^4] .$$

容量维上界 $c\le10^4$、物品数 $n\le10^4$，标准背包开销 $O(nc)=10^8$——**$10^8$ 次简单整数比较**，在 $1$ s、$125$ MB 下从容（实测 $\approx0.05$ s）。任何 $\Theta(2^n)$ 枚举在 $n=10^4$ 时不可行，提示正解是背包 DP。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"填海"翻译成"最小代价达成收益"

记第 $i$ 块木石 $p_i=(k_i,m_i)$。一次填海方案就是选一个下标子集 $S\subseteq\{1,\dots,n\}$，其
$$\text{体积}(S)=\sum_{i\in S}k_i,\qquad \text{体力}(S)=\sum_{i\in S}m_i .$$

**引理 1（问题模型）**

题目所求剩余体力为 $c-m^\*$，其中
$$m^\*=\min\{\text{体力}(S):\ S\subseteq\{1,\dots,n\},\ \text{体积}(S)\ge v,\ \text{体力}(S)\le c\};$$
若该集合为空（无可行 $S$）则输出 `Impossible`。$\blacksquare$（直接翻译题面。）

> 关键转变：把"最大化剩余体力"改写成"**最小化体力消耗**"——剩余 $=c-$消耗，$c$ 是常数，故两者等价。

### 2.2 考虑简化版：标准"容量 $\to$ 最大价值"的 $0/1$ 背包

如果只问"在体力 $\le j$ 的前提下最多能填多大体积"，那是教科书般的 $0/1$ 背包（容量 $=$ 体力、价值 $=$ 体积）。设

$$A[j]=\max\{\text{体积}(S):\ \text{体力}(S)\le j\}.$$

**引理 2（$A[j]$ 可由倒序一维背包求出）**

初值 $A[j]=0\ (\forall j)$，对每块木石 $i$ 令 $j$ 从 $c$ 递减到 $m_i$ 执行 $A[j]=\max(A[j],\ A[j-m_i]+k_i)$，则终态 $A[j]=\max\{\text{体积}(S):\text{体力}(S)\le j\}$。

**证明**（对已处理木石数 $t$ 归纳，兼证"容量 $\le$"语义）：

- **基例** $t=0$：只有空集，$\text{体积}=0\le j$，而 $A[j]$ 初值 $0$，成立。
- **归纳步**：设处理完前 $t-1$ 块后 $A_0[j]$ 正确。引入第 $t$ 块后任一子集 $S$ 分两类：
  - $t\notin S$：由 $A_0[j]$ 给出；
  - $t\in S$：令 $S'=S\setminus\{t\}$，则 $\text{体力}(S')\le j-m_t$（因 $m_t\ge0$），由定义 $S'$ 的体积 $\le A_0[j-m_t]$，故 $S$ 的体积 $= \text{体积}(S')+k_t\le A_0[j-m_t]+k_t$；取 $S'$ 为最优子集时等号可达。
  - 两类取 $\max$ 即 $A_{\text{new}}[j]$，等于引入第 $t$ 块后的最优值。$\blacksquare$

**引理 3（倒序 $\Rightarrow$ 每块至多用一次）**

$j$ 递减时，转移读的 $A[j-m_i]$（$j-m_i<j$）本轮尚未被改写，故是旧值；反之正序会读到本轮已更新的值，等价于允许同一块被反复搬运。

**证明**：同引理 2 归纳步所需，递减时"下标更小者"未处理、"下标更大者"不被读取；正序时 $j-m_i<j$ 已被本轮改写为 $A_{\text{new}}$，转移变成 $A_{\text{new}}[j]=\max(A_{\text{new}}[j],A_{\text{new}}[j-m_i]+k_i)$，即"第 $t$ 块可累加多次"的完全背包，与"每块只有一块"矛盾。$\blacksquare$

### 2.3 一次归约：从"最大体积"字典反查"最小体力"

$A[j]$ 只在某一条体力轴上给了最大体积，怎么从它读出 $m^\*$？

**引理 4（阈值反查即最小体力）**

设 $j^\*=\min\{j\in[0,c]:\ A[j]\ge v\}$（不存在时判 $j^\*$ 为空）。则 $m^\*=j^\*$；二者同时为空。

**证明**：

- 先证两方向集合相等：$A[j]\ge v\iff$ 存在子集 $S$ 使 $\text{体力}(S)\le j$ 且 $\text{体积}(S)\ge v$（由引理 2 的定义：$A[j]$ 就是该约束下的最大体积）。于是 $\{j:A[j]\ge v\}=\{j:\exists\,S,\ \text{体力}(S)\le j\le c,\ \text{体积}(S)\ge v\}$。
- 该集合的最小值 $=\min\{\text{体力}(S):\text{体力}(S)\le c,\ \text{体积}(S)\ge v\}=m^\*$：一方面任一满足条件的 $S$ 给出一个 $\ge$ 其体力的可行 $j$（取 $j=\text{体力}(S)$），故集合最小值 $\le m^\*$；另一方面集合里最小的 $j^\*$ 对应某 $S$ 且 $\text{体力}(S)\le j^\*$，故 $m^\*\le j^\*$。两边夹逼得相等。
- 存在性同步：集合为空 $\iff$ 不存在可行 $S$。$\blacksquare$

> 这一步把"最小代价"问题**完全化归**为"在单调数组上找第一个 $\ge v$ 的位置"——不需要任何额外枚举。由于"$\le j$ 的可行子集"随 $j$ 变大只增不减，$A[j]$ 天然单调，但即便不单调，**"从小到大第一个 $A[j]\ge v$"就等于 $m^\*$**（引理 4 的证明只用到集合相等，未用到单调性），所以直接线性扫最稳。

### 2.4 答案

**引理 5（输出形式）**

若能找到 $j^\*\le c$，输出 $c-j^\*$；否则输出 `Impossible`。

**证明**：由引理 4，$j^\*=m^\*$，剩余体力 $=c-m^\*=c-j^\*$。$j^\*\le c$ 是由 $j^\*$ 取值区间定义的。$\blacksquare$

### 2.5 剖析几个失败思路（都给出具体反例）

**失败 1：按"体积/体力比"贪心。**
反例：$v=6,c=5$，两块 $X=(5,2)$、$Y=(6,3)$（比值 $2.5$ 与 $2.0$）。贪心先取比值大的 $X$（体积 $5<6$ 未达标），再取 $Y$，总体力 $5\le5$，输出 $c-5=0$；但只取 $Y$ 即可填平，体力 $3$，输出 $c-3=2$。贪心**多花了体力**。$\Rightarrow$ 比值贪心在 $0/1$ 背包里没有最优性保证，必须 DP。

**失败 2：把"填平"读成"恰好 $=v$"。**
反例：$v=3,c=10$，单块 $A=(5,4)$。$5\ge3$ 明明填平了，但"恰好等于 $3$"的写法会认为 $A$ 不可用，错判 `Impossible`。$\Rightarrow$ 约束是 $\Sigma k_i\ge v$。

**失败 3：把容量语义写成"恰好用满体力"。**
本题用"$\le$ 容量"语义（初值 $A[j]=0$）：$A[j]$ 表示体力"不超过 $j$"的最大体积。若改成"恰好 $j$"（初值除 $A[0]$ 外全 $-\infty$），则 $A$ 不再单调、且"未用满体力"的可行方案会漏掉，反查 $j^\*$ 时容易错。$\Rightarrow$ 用"$\le$"语义最省心。

**失败 4：把体积当容量、体力当价值（方向反了）。**
体积总和上界是 $\sum k_i$，可能远超 $10^4$（就连 $v$ 也可能很大但答案只要求 $\ge v$），且目标是"最小化体力"，容量轴该选体力；若拿体积当容量，容量维会膨胀，复杂度和初值都失控。**判定依据是"约束用哪条轴、目标优化哪条轴"**——约束是 $\Sigma m_i\le c$（体力容量），目标是 $\min\Sigma m_i$，故体力做容量、体积做价值。

### 2.6 越界与状态体检

| 量 | 范围 | 上界 | `int` 够？ |
|---|---|---|---|
| $n,c$ | 题面 | $10^4$ | 是 |
| $v,k_i,m_i$ | 题面 | $10^4$ | 是 |
| $A[j]$（体积和） | $n\cdot\max k$ | $10^8$ | 是 |
| $c-j^\*$ | $[0,c]$ | $10^4$ | 是 |

结论：**全程 `int` 足够**（体积和最大 $10^8$ 未溢出）。要防的是：

1. **`dp` 必须用"$\le$"语义**（初值全 $0$），别改成"恰好装满"（失败 3）。
2. **内层必须倒序**（引理 3）。
3. **`m_i>c` 的木石直接跳过**（外层循环下界 `j>=mm[i]` 时自然不执行），不必特判。
4. **`m_i=0` 要能正确工作**：倒序到 $A[j]=\max(A[j],A[j]+k_i)$，即 $A[j]+=k_i$（免费体积）。

## 3. 模式总结（Pattern Summary）

按真实思考顺序排列，每条一行：

- explore its property — 把"最大化剩余体力"改写成"最小化体力消耗"，把填海翻译成受两条约束的子集选择（引理 1）。
- consider easier version — 先做标准"容量 $\to$ 最大价值"的 $0/1$ 背包 $A[j]$（引理 2）。
- classic problem solution — $0/1$ 背包的一维倒序实现保证每块至多一次（引理 3）。
- reduce to easier problem — 把"最小体力"化归为"在 $A$ 上找第一个 $\ge v$ 的下标"（引理 4）。
- pick the right axis — 约束轴（体力）做容量、目标轴（体积）做价值（失败 4）。
- threshold-scan paraphrase — "第一个 $\ge v$ 的位置"即最小代价，无需额外枚举（引理 4）。
- capacity semantics — 用"$\le$ 容量"（初值全 $0$），避免"恰好装满"的坑（失败 3）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $v$ | `int` | 需要的最小体积 | 读入 | 题面 |
| $n$ | `int` | 木石块数 | 读入 | 题面 |
| $c$ | `int` | 初始剩余体力（背包容量） | 读入 | 题面 |
| `k[i]` | `int [10005]` | 第 $i$ 块体积（价值） | 读入 | 题面 |
| `mm[i]` | `int [10005]` | 第 $i$ 块消耗体力（重量） | 读入 | **不可命名 `m`，会遮蔽容量**，故用 `mm` |
| `dp[j]` | `int [10005]` | 体力 $\le j$ 时能填的最大体积 $A[j]$ | 全 $0$ | 背包表 |
| `j` | `int` | 反查下标 / 最小体力 $m^\*$ | — | 引理 4 |

### 4.2 编号步骤

1. 读入 `v,n,c`，再读 $n$ 组 `k[i],mm[i]`。
2. `dp[*]=0`（体积 $\le j$ 的"空方案"体积为 $0$）。
3. 对每块 $i=0..n-1$：令 $j$ 从 `c` 递减到 `mm[i]`，执行 `dp[j]=max(dp[j],dp[j-mm[i]]+k[i])`。
4. 令 $j$ 从 $0$ 递增到 `c`，第一个满足 `dp[j]>=v` 的 $j$ 即 $m^\*$，输出 `c-j` 并结束。
5. 若扫完没有命中，输出 `Impossible`。

### 4.3 复杂度

- 时间：$O(nc)\le10^4\times10^4=10^8$ 次整数比较。
- 空间：`k`、`mm`、`dp` 三个 $10005$ 的 `int` 数组，约 $0.12$ MB，远低于 $125$ MB。
- 实测（见 §4.5）：$v=n=c=10^4$ 最快 $0.050$ s（含进程启动）。

### 4.4 关键不变量（值得写 `assert` 的地方）

1. 处理完前 $t$ 块后 `dp[j]` $=\max$ 体积（体力 $\le j$）（引理 2）。
2. 倒序循环保证每块至多一次（引理 3）。
3. `dp[j]>=v` $\iff$ 存在体力 $\le j$、体积 $\ge v$ 的可行子集（引理 4）。
4. 第一个命中的 `j` 就是最小体力 $m^\*$，答案 $=c-j$。

| 项目 | 状态 |
|---|---|
| 官方样例回归 | **通过**：样例1 `100 2 10 / 50 5 / 50 5` $\to$ `0`；样例2 `10 2 1 / 50 5 / 10 2` $\to$ `Impossible`（标程与暴力一致） |
| 随机数据对拍 | **通过**：$400$ 组随机小规模（$n\le12$、$c\le15$、$v$ 与 $k_i,m_i$ 可取 $0$，含超体力/超体积件），DP 与 $2^n$ 子集枚举**逐字节一致** |
| 边界用例 | **通过**：$v=0\to c$；全超体力 $\to$ `Impossible`；恰好装满用尽体力 $\to0$；零体力木石（免费）$\to3$；零体积木石 $\to3$；总体积不足 $\to$ `Impossible`；超体积但体力不足 $\to$ `Impossible` |

## 5. 示例代码

### 5.1 主解：$0/1$ 背包 + 阈值反查（与 `appendix/P1510/P1510.cpp` 逐字节一致）

```cpp
//
// 题目：P1510 精卫填海
// https://www.luogu.com.cn/problem/P1510
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};   // n<=1e4 (+5 松弛)
constexpr int mxc{10005};   // c<=1e4 (+5 松弛)

int v,n,c;
int k[mxn],mm[mxn];          // k=木石体积, mm=把它衔到东海消耗的体力
int dp[mxc];                 // dp[j]=总体力不超过 j 时能填的最大体积

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>v>>n>>c;
	for(int i=0;i<n;++i)
		cin>>k[i]>>mm[i];

	for(int i=0;i<n;++i)
		for(int j=c;j>=mm[i];--j)
			dp[j]=max(dp[j],dp[j-mm[i]]+k[i]);

	for(int j=0;j<=c;++j)
		if(dp[j]>=v)
		{
			cout<<c-j<<'\n';   // 最先满足的体积对应最小体力消耗
			return 0;
		}
	cout<<"Impossible\n";
	return 0;
}
```

**代码结构对照**：内层倒序是引理 3；`dp` 初值全 $0$ 是"$\le$ 容量"语义；`for(j=0..c) if(dp[j]>=v)` 就是引理 4 的阈值反查；输出 `c-j` 是引理 5。`mm` 而非 `m` 命名，是为避开与容量变量 `m` 的命名混淆（本题容量叫 `c`，但保持 `mm` 更清晰）。

### 5.2 对照实现：$2^n$ 子集枚举（仅用于小规模对拍）

```cpp
//
// 题目：P1510 精卫填海 (暴力基准)
// https://www.luogu.com.cn/problem/P1510
// 仅用于小规模对拍: 枚举全部子集, 求达到体积 v 的最小体力消耗
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};
constexpr int inf{1145141919};

int v,n,c;
int k[mxn],mm[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>v>>n>>c;
	for(int i=0;i<n;++i)
		cin>>k[i]>>mm[i];

	int best=inf;
	for(int mask=0;mask<(1<<n);++mask)
	{
		int sv=0,sc=0;
		for(int i=0;i<n;++i)
			if(mask>>i&1)
			{
				sv+=k[i];sc+=mm[i];
			}
		if(sv>=v&&sc<=c)
			best=min(best,sc);
	}
	if(best==inf)
		cout<<"Impossible\n";
	else
		cout<<c-best<<'\n';
	return 0;
}
```

两版输出**逐字节相同**（$400$ 组随机数据确认）。暴力直接按定义枚举每块搬/不搬、取达到 $v$ 的最小体力，完全绕过背包转移，可交叉验证引理 2/3；代价 $O(2^n n)$，不能提交。

### 5.3 易错点清单

- **贪心按体积/体力比取** $\Rightarrow$ 多花体力（失败 1 反例）。
- **把"填平"读成"恰好 $=v$"** $\Rightarrow$ 漏掉超额方案（失败 2）。
- **内层正序** $\Rightarrow$ 完全背包，每块可反复搬，答案偏大（引理 3）。
- **用"恰好装满"语义** $\Rightarrow$ 漏掉未用满体力的方案（失败 3）。
- **容量轴选错（拿体积当容量）** $\Rightarrow$ 容量维失控（失败 4）。
- **`cout<<...<<endl;`** 违反项目风格，一律 `'\n'`。
