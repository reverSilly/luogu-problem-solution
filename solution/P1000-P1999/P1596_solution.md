# P1596 [USACO10OCT] Lake Counting S

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给一个 $N\times M$ 的字符网格，`W` 表示水，`.` 表示干地。若两个水格在**八方向**（上下左右加四个对角）上相邻，就认为它们属于同一个水塘；水塘是连通的极大水格集合。求水塘个数。

把每个 `W` 格看作图的一个顶点，八邻接看作边，题目要求的正是这个无向图的**连通块个数**。

### 输入输出格式

- **输入格式**：第一行 $N,M$；随后 $N$ 行，每行 $M$ 个字符（`W` 或 `.`，无空格）。
- **输出格式**：一行一个整数，水塘数。
- **数据规模**：$1\le N,M\le100$。

### 关键约束分析

1. 网格最多 $100\times100=10^4$ 个格子，$O(NM)$ 的遍历绰绰有余，不需要并查集或更复杂结构。
2. 邻接是 **8 方向**，不是 4 方向；漏掉对角会多数出水塘，这是本题最常见错误。
3. 边界：$N=1$ 或 $M=1$ 时没有上下/左右，越界判断必须写全四个方向；全为 `.` 时答案是 $0$。
4. 每个格子只需访问一次，用 `vis` 标记即可保证线性复杂度。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：把"水塘"翻译成图论

"连通的水格组成的区域"就是连通块。统计连通块的标准做法只有两类：并查集（边合并）与遍历（DFS/BFS 泛洪）。本题 $10^4$ 个点，两者都行；遍历写起来更短，且不需要额外的边存储。

### 第二步：为什么遍历一遍就能数清

**引理 1（连通是等价关系）**：在"八邻接"意义下，把"$u$ 与 $v$ 属于同一水塘"记为 $u\sim v$。则 $\sim$ 是水格集合上的等价关系，从而水塘就是等价类。

*证明*：自反性：单点自身连通（零步路径）。对称性：相邻关系本身对称（$u$ 在 $v$ 的八邻域内等价于 $v$ 在 $u$ 的八邻域内），路径可反向走，故连通对称。传递性：两条路径首尾相接仍是一条路径。于是 $\sim$ 是等价关系，等价类即极大连通子集，互不相交。$\square$

**引理 2（泛洪的正确性）**：从任一点出发做 BFS/DFS 只沿八邻接走，访问到的点集恰为它所在的等价类。

*证明*：设起点为 $s$。**包含性**：遍历中每加入一个新点都与已访问点相邻，故存在从 $s$ 出发的路径到达它，即它与 $s$ 同类。**穷尽性**：若 $t\sim s$，取一条从 $s$ 到 $t$ 的路径 $s=p_0,p_1,\dots,p_k=t$，对 $i$ 归纳：$p_i$ 被访问后其邻居 $p_{i+1}$ 会在扩展它时被加入（除非已访问），故 $t$ 必被访问。两者相等。$\square$

**定理（计数正确）**：对网格从左到右、从上到下扫描，遇到未访问的 `W` 就把答案加一并泛洪标记整个连通块，最终答案等于水塘数。

*证明*：由引理 2，每次泛洪恰好"吃掉"一个完整的等价类；已标记的格子不会再被当作起点，故每个等价类恰好贡献 $1$，总计数等于等价类个数，即水塘数。$\square$

### 第三步：八方向的枚举方式

用两层 `dx,dy` 从 $-1$ 到 $1$ 的循环枚举 $9$ 个偏移，跳过 $(0,0)$ 自己，正好是 $8$ 个邻居。比手写 8 个 `if` 更不容易漏。

### 第四步：队列与访问标记

BFS 用手写数组队列，容量 $NM$（每个点至多入队一次），比 `std::queue` 略快且不涉及动态分配。入队时立刻置 `vis`，避免同一点重复入队。

## Part 3 — 模式总结 (Pattern Summary)

- `reduce to easier problem` — "水塘数"即八邻接图的连通块数。
- `explore its property` — 八邻接的连通关系是等价关系，等价类互不相交，可以逐个"吃掉"。
- `classic problem solution` — 网格泛洪（BFS/DFS）+ 访问标记，每个格子只处理一次。
- `classic problem solution` — 用 `dx,dy` 双层循环枚举八方向，避免手写漏项。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $N,M$ | `n`, `m` | 网格行数、列数 |
| 网格 | `g[i][j]` | 字符矩阵，`W` 为水，`.` 为干地；直接按行 `cin` 读入 |
| $\text{vis}[i][j]$ | `vis[i][j]` | 该格是否已被某个连通块认领，初值全 `false` |
| 队列 | `qx[]`, `qy[]` | 手写 BFS 队列，分别存行、列坐标，容量 $NM$ |
| $ql,qr$ | `ql`, `qr` | 队头、队尾指针，队列区间 $[ql,qr)$ |
| $x,y$ | `x`, `y` | 当前弹出的格子坐标 |
| $dx,dy$ | `dx`, `dy` | 八方向偏移，取值 $-1,0,1$ |
| $\text{ans}$ | `ans` | 已统计的水塘数 |

### 算法步骤

1. 读入 `n,m` 与 $n$ 行字符。
2. 逐格扫描 `(i,j)`：若 `g[i][j]!='W'` 或 `vis[i][j]` 为真，跳过。
3. 否则 `++ans`，把 `(i,j)` 标记并入队；当队列非空时弹出队头，枚举八个邻居，对越界的跳过，对未访问的 `W` 标记并入队。
4. 扫描结束输出 `ans`。

### 复杂度分析

- **时间复杂度**：每个格子至多入队一次，每次检查 $8$ 个邻居，$O(NM)$，即 $8\times10^4$ 次操作。
- **空间复杂度**：$O(NM)$，`g`、`vis` 与两个队列各 $10^4$ 量级。

### 正确性验证

引理 1 保证连通块（等价类）划分唯一，引理 2 保证一次泛洪恰好收集一个等价类，定理给出计数正确。八方向枚举覆盖全部邻居，`vis` 在入队时置位保证不重复计数；越界判断同时检查行列两个方向，$1\times M$、$N\times1$ 等退化网格也安全。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1596 [USACO10OCT] Lake Counting S
// https://www.luogu.com.cn/problem/P1596
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n,m,ans;
char g[mxn][mxn];
bool vis[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>g[i];

	int qx[mxn*mxn],qy[mxn*mxn];
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
		{
			if(g[i][j]!='W'||vis[i][j])
				continue;
			++ans;
			int ql=0,qr=0;
			vis[i][j]=true;
			qx[qr]=i;qy[qr]=j;++qr;
			while(ql<qr)
			{
				int x=qx[ql],y=qy[ql];
				++ql;
				for(int dx=-1;dx<=1;++dx)
					for(int dy=-1;dy<=1;++dy)
					{
						int nx=x+dx,ny=y+dy;
						if(nx<0||nx>=n||ny<0||ny>=m)
							continue;
						if(g[nx][ny]=='W'&&!vis[nx][ny])
						{
							vis[nx][ny]=true;
							qx[qr]=nx;qy[qr]=ny;++qr;
						}
					}
			}
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **只枚举 4 方向**：对角相连的水格会被拆成两个水塘，答案偏大。
2. **入队时才判重**：若在出队时才置 `vis`，同一点可能被多次入队，队列容量与复杂度都会失控。应在**入队时**置 `vis`。
3. **队列开小**：容量必须是 $N\times M$（最多所有格子都是水），写成 `mxn` 会越界。
4. **按字符读入踩到空白**：用 `cin>>g[i]` 按行读字符串最稳，`scanf("%c")` 需要额外处理换行。
5. **越界判断写一半**：`nx<0||nx>=n||ny<0||ny>=m` 四个条件都要写，退化网格（$n=1$）才不出错。
