# P1955 [NOI2015] 程序自动分析

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $t$ 个互相独立的问题。每个问题给出 $n$ 条约束，每条是
$$
x_i=x_j \quad(e=1)\qquad\text{或}\qquad x_i\ne x_j\quad(e=0).
$$
问：能否给每个变量赋一个值，使所有约束同时成立？能则输出 `YES`，否则 `NO`。

### 1.2 关键约束与规模暗示

- $1\le t\le10$，$1\le n\le10^5$，$e\in\{0,1\}$。
- 前 $7$ 个测试点 $i,j\le10^4$，后 $3$ 个测试点 $i,j\le10^9$。
- $n$ 高达 $10^5$，$O(n^2)$ 两两比较不可行，提示用近似线性的**并查集**。
- $i,j\le10^9$ 但真正出现的下标只有 $2n\le2\times10^5$ 个，这就是「值域大、出现次数少」的典型信号：**离散化**（或用哈希表）。
- $t\le10$ 且每组独立，注意每组重新初始化。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先把「相等」看成一张图

把每个变量看成一个点，每条 $e=1$ 的约束 $x_i=x_j$ 看成一条无向边。

等号是一个**等价关系**：自反、对称、传递。因此：

**引理 1** 只考虑 $e=1$ 的约束时，它们**永远**可以同时满足。

**证明**：取图（点 = 变量，边 = 相等约束）的每个连通块，给同一连通块内所有变量赋同一个值，不同连通块赋不同的值。于是每条相等边的两个端点在同一块内、取值相同，全部满足。$\square$

所以矛盾**只能来自不等约束**。关键问题变成：一条 $x_i\ne x_j$ 什么时候与相等约束冲突？

**定义**：把「$x_i=x_j$」的关系做传递闭包，得到的等价类就是图上的**连通块**（相互可达的点）。

**引理 2** 所有约束可同时满足，当且仅当对每条 $e=0$ 的约束 $x_i\ne x_j$，$i$ 与 $j$ 在相等约束图中**不在同一连通块**。

**证明**：

$(\Rightarrow)$ 若存在某条不等约束使 $i,j$ 在同一连通块，那么沿着连通块里的相等边，由等号的传递性（对路径长度归纳：$x_{u}=x_{v}$ 且 $x_v=x_w$ 推出 $x_u=x_w$）可得 $x_i=x_j$。但约束又要求 $x_i\ne x_j$，矛盾，不可能同时满足。

$(\Leftarrow)$ 若所有不等约束的两端都落在不同连通块：仍按引理 1 的构造，每个连通块赋一个**互不相同**的值。相等约束全部满足；每条不等约束的两端在不同块、取值不同，也满足。$\square$

### 2.2 为什么必须「先处理相等，再检查不等」

如果边读入边判断，会漏判：例如
$$
x_1\ne x_2,\qquad x_2=x_3,\qquad x_1=x_3
$$
读入第一条时 $1,2$ 还不连通，看似没问题；可后面两条相等约束把 $1,3$ 并到了一起，最终 $1,2$ 同块，矛盾。所以正确顺序是：

1. **第一遍**：只处理 $e=1$，把所有相等约束合并；
2. **第二遍**：逐条检查 $e=0$，若两端在同一集合则输出 `NO`。

这也正是引理 2 的「先取相等关系的传递闭包，再验证不等约束」的直接翻译。

### 2.3 用并查集维护连通块

并查集维护的就是相等关系的传递闭包：

- `find(x)` 返回 $x$ 所在连通块的代表元；
- 合并 $i,j$：`f[find(i)]=find(j)`；
- 判断是否同块：`find(i)==find(j)`。

路径压缩后单次操作近似 $O(1)$（严格说是 $O(\alpha(n))$）。

### 2.4 离散化

$i,j\le10^9$，不能直接拿值当下标。但所有出现过的下标总数不超过 $2n\le2\times10^5$。把它们收集到数组里排序去重，再用 `lower_bound` 映射到 $[0,2n)$ 即可。这一步不改变任何「相等/不等」的语义：只关心两个下标是否为同一个，压缩是双射。

（也可以用 `unordered_map`，但排序 + 二分没有哈希冲突风险，且常数稳定。）

### 2.5 多组数据的清空

每组数据：

- 并查集初值 `f[i]=i`（只对压缩后的 $cnt$ 个点初始化）；
- 三个长度为 $n$ 的数组重新读入覆盖；
- 值域数组重新收集、排序、去重。

注意不要漏掉「上一组残留」的问题：所有用到的下标都在新的一组里重新赋值，容量按本组 $n$ 处理即可。

### 2.6 一个容易忽略的点

约束里的 $i,j$ 可能相同（如 $x_5=x_5$ 或 $x_5\ne x_5$）。离散化后它们映射到同一下标，并查集天然处理：$x_5=x_5$ 无影响，$x_5\ne x_5$ 会在第二遍被判定为同块，输出 `NO`。无需特判，但值得知道这是对的。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 等号是等价关系，等价类 = 相等约束图的连通块。
- **reduce to easier problem** — 先只看相等约束（永远可满足），矛盾只能来自不等约束。
- **necessary and sufficient condition** — 可行 ⟺ 每条不等约束两端不在同一连通块。
- **classic problem solution** — 并查集维护相等关系的传递闭包。
- **coordinate compression** — 值域 $10^9$、出现次数 $2n$，离散化后映射到 $2n$ 个点。
- **defer reconstruction** — 必须分两遍：先合并所有相等，再检查所有不等。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `t` | `int` | 问题个数 | 读入 | $\le10$ |
| `n` | `int` | 当前问题约束条数 | 读入 | $\le10^5$ |
| `x[i],y[i]` | `int [mxn]` | 第 $i$ 条约束的两个变量（读入原值，之后换成压缩下标） | 读入 | 端点 |
| `e[i]` | `int [mxn]` | 第 $i$ 条约束的类型，$1$ 相等、$0$ 不等 | 读入 | equal |
| `val[]` | `int [mxn*2]` | 所有出现过的原下标，用于离散化 | 收集 | value |
| `cnt` | `int` | 去重后的下标个数 | 0 | count |
| `f[i]` | `int [mxn*2]` | 并查集父亲 | `f[i]=i` | father |
| `getrt(a)` | 函数 | 带路径压缩的查找 | — | get root |
| `ok` | `bool` | 当前问题是否可满足 | `true` | answer |

### 4.2 算法步骤

1. 读入 $t$，循环 $t$ 次。
2. 读入 $n$；对每条约束读入 $x_i,y_i,e_i$，同时把 $x_i,y_i$ 塞进 `val`，得到共 $2n$ 个数。
3. 对 `val[0..2n)` 排序、`unique` 去重，得到 `cnt`。
4. 用 `lower_bound` 把每个 $x_i,y_i$ 换成压缩后的下标（$[0,cnt)$）。
5. 初始化 `f[i]=i`（$i<cnt$）。
6. **第一遍**：对所有 $e_i=1$ 的约束，合并 `getrt(x[i])` 与 `getrt(y[i])`。
7. **第二遍**：对所有 $e_i=0$ 的约束，若 `getrt(x[i])==getrt(y[i])`，令 `ok=false` 并停止。
8. 输出 `YES` 或 `NO`。

### 4.3 复杂度分析

- 离散化：每组排序 $O(n\log n)$，二分 $O(n\log n)$。
- 并查集：$O(n\,\alpha(n))$。
- 总时间 $O(n\log n)$ 每组，$t$ 组独立；空间 $O(n)$。
- $n=10^5$、$t=10$ 时非常轻松。

## 5. 示例代码

```cpp
//
// 题目：P1955 [NOI2015] 程序自动分析
// https://www.luogu.com.cn/problem/P1955
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{200005};

int f[mxn],x[mxn],y[mxn],e[mxn],val[mxn];

int getrt(int a)
{
	if(f[a]==a)
		return a;
	return f[a]=getrt(f[a]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int t;
	cin>>t;
	while(t--)
	{
		int n;
		cin>>n;
		int cnt{0};
		for(int i=0;i<n;++i)
		{
			cin>>x[i]>>y[i]>>e[i];
			val[cnt++]=x[i];
			val[cnt++]=y[i];
		}
		sort(val,val+cnt);
		cnt=unique(val,val+cnt)-val;
		for(int i=0;i<cnt;++i)
			f[i]=i;
		for(int i=0;i<n;++i)
			x[i]=lower_bound(val,val+cnt,x[i])-val,
			y[i]=lower_bound(val,val+cnt,y[i])-val;

		for(int i=0;i<n;++i)
			if(e[i]==1)
			{
				int a=getrt(x[i]),b=getrt(y[i]);
				if(a!=b)
					f[a]=b;
			}
		bool ok{true};
		for(int i=0;i<n&&ok;++i)
			if(e[i]==0&&getrt(x[i])==getrt(y[i]))
				ok=false;
		cout<<(ok?"YES\n":"NO\n");
	}
	return 0;
}
```
