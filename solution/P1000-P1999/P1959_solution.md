# P1959 [JOI 2007 Final] 遗址

## 1. 重新读题

### 1.1 问题重述（人话版）

平面上有 $N$ 个互不相同的整点，坐标都在 $0$ 到 $5000$ 之间。要从其中选出 $4$ 个点，使它们恰好是一个正方形的四个顶点（边不必平行于坐标轴），求这个正方形可能的最大面积；一个都选不出来就输出 $0$。

### 1.2 关键约束与规模暗示

- $1\le N\le 3000$，坐标值域 $V=5001$（$0\sim 5000$）。
- $30\%$ 数据 $N\le 100$，$60\%$ 数据 $N\le 500$：这些档位连 $O(N^3)$ 甚至更暴力的做法都能过。
- $100\%$ 数据 $N\le 3000$：$O(N^2)=9\times10^6$ 是本题的目标复杂度；$O(N^3)=2.7\times10^{10}$ 必死。
- 坐标值域很小（$5001\times5001\approx 2.5\times10^7$），这提示我们：**判断“某个点是否存在”可以 $O(1)$ 查表**，而不必二分或哈希。
- 所有坐标都是整数，所以任意两点距离的平方 $dx^2+dy^2$ 是整数，正方形面积也是整数，**不需要任何浮点运算，也就不存在精度问题**。

---

## 2. 思维链（Chain-of-thought）

### 2.1 直接枚举四个点为什么不行

最朴素的想法是枚举四元组 $(a,b,c,d)$，判断它们能否拼成正方形，再取面积最大。四元组数量是 $\binom{3000}{4}\approx 3.4\times10^{13}$，即使每次判断只要几次乘法，也完全无法接受。

问题出在“四个点”里信息是冗余的：**只要确定了一条有向边，正方形的位置就完全确定了**。正方形有 $4$ 条边，边向量彼此只差 $90^\circ$ 旋转。这启发我们只枚举“一条边”。

### 2.2 一条边确定一个正方形

设两个不同点为 $A=(x_1,y_1)$、$B=(x_2,y_2)$，向量
$$
v=B-A=(dx,dy),\qquad R(v)=(-dy,dx),
$$
其中 $R$ 表示把向量逆时针旋转 $90^\circ$。定义
$$
C=B+R(v)=(x_2-dy,\;y_2+dx),\qquad D=A+R(v)=(x_1-dy,\;y_1+dx).
$$

**引理 1（构造出的是正方形）**：$A,B,C,D$ 按此顺序首尾相接，四条边向量依次为
$$
B-A=v,\quad C-B=R(v),\quad D-C=-v,\quad A-D=-R(v).
$$
它们模长都为 $|v|$，且相邻两边内积为 $v\cdot R(v)=dx(-dy)+dy\,dx=0$，所以四个角都是直角、四边相等，$A B C D$ 是一个正方形，面积为 $|v|^2=dx^2+dy^2$。

**证明**：已在上文直接算出边向量与内积。四边等长且四角为直角的四边形是正方形（这是正方形的判定定理，不需要再做额外假设）。$\square$

**引理 2（四个顶点互不相同）**：当 $v\ne 0$ 时 $A,B,C,D$ 两两不同。

**证明**：反设某两个重合。

- $C=B$ 即 $R(v)=0$，而 $R$ 是可逆线性变换，只能 $v=0$，矛盾。
- $D=A$ 同理 $R(v)=0$，矛盾。
- $C=D$ 即 $B+R(v)=A+R(v)\Rightarrow B=A$，矛盾。
- $C=A$ 即 $B+R(v)=A$，亦即 $R(v)=A-B=-v$。对向量 $v=(dx,dy)$ 而言 $R(v)=(-dy,dx)$，$R(v)=-v$ 给出 $-dy=-dx$ 且 $dx=-dy$，即 $dx=dy$ 与 $dx=-dy$ 同时成立，故 $dx=dy=0$，$v=0$，矛盾。
- $D=B$ 同理推出 $v=0$。

所以只要 $A\ne B$，构造出的四点互异。$\square$

### 2.3 覆盖性：每个正方形都会被枚举到

上面的构造固定了“逆时针旋转”。但一个正方形有两条“绕行方向”，会不会漏掉某些正方形？

**引理 3（每个正方形都被某个有序对枚举到）**：设 $P_0P_1P_2P_3$ 是任意一个按逆时针顺序排列的正方形。取 $A=P_0$、$B=P_1$，则 $v=P_1-P_0$，而逆时针旋转 $90^\circ$ 后 $R(v)=P_2-P_1$。于是按引理 1 的公式
$$
C=B+R(v)=P_1+(P_2-P_1)=P_2,\qquad D=A+R(v)=P_0+(P_2-P_1)=P_3.
$$
所以有序对 $(P_0,P_1)$ 会把这个正方形完整地找出来。

**证明**：正方形的逆时针边序列本身满足 $P_2-P_1=R(P_1-P_0)$（正方形每条边的方向恰由前一条逆时针转 $90^\circ$ 得到），代入即得 $C=P_2,D=P_3$。$\square$

由于我们枚举的是**所有有序对** $(i,j)$（$i\ne j$），每个正方形的某一条逆时针边一定会作为某个 $(A,B)$ 出现，因此不会漏解。交换 $i,j$ 会得到正方形在直线 $AB$ 另一侧的镜像，恰好覆盖了“另一个方向”，所以“所有有序对 + 固定逆时针旋转”与“所有无序对 + 两个旋转方向”是等价的，前者写起来更简单。

### 2.4 判定与去重

判定就是查表：预先用 `vis[x][y]` 标记输入中出现的点，枚举 $(A,B)$ 后算出 $C,D$，若二者坐标合法且都在点集中，就用 $dx^2+dy^2$ 更新答案。

同一个正方形会被它的 $4$ 条逆时针边各枚举一次，重复计算完全无害——我们只做 `max`，不计数、不存储。题目也不要求输出方案，所以不需要去重。

### 2.5 为什么不需要担心溢出与精度

- $|dx|,|dy|\le 5000$，$dx^2+dy^2\le 5\times10^7<2^{31}-1$，`int` 足够。
- 旋转只涉及加减法，$C,D$ 的坐标仍是整数；所有判定都是整数比较，没有 `double`，因此没有精度问题。
- 算出 $C,D$ 后先判坐标是否落在 $[0,5000]^2$，再查表，避免越界访问。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 正方形由“一条有向边 + 逆时针旋转 $90^\circ$”唯一确定。
- **consider easier version** — 若只考虑轴对齐正方形，枚举相邻两点即可；一般正方形同样只差一个旋转变换。
- **classic problem solution** — 枚举所有有序点对作为边，$O(1)$ 查表验证另外两个顶点。
- **geometry with integers** — 全部用整数坐标与距离平方，避免浮点精度。
- **over-count is harmless** — 同一正方形被多次枚举，取最大值不受影响。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 点数 | 读入 | $\le 3000$ |
| `x[i], y[i]` | `int [3005]` | 第 $i$ 个点坐标 | 读入 | 0-based |
| `vis[a][b]` | `unsigned char [5005][5005]` | 点 $(a,b)$ 是否存在 | 0 | visit / 存在标记 |
| `dx, dy` | `int` | 有向边向量 | 枚举时算 | $B-A$ |
| `cx, cy` | `int` | 顶点 $C$ 坐标 | 计算 | $B+R(v)$ |
| `ex, ey` | `int` | 顶点 $D$ 坐标 | 计算 | $A+R(v)$ |
| `ans` | `int` | 最大面积 | 0 | answer |

### 4.2 算法步骤

1. 读入所有点，`vis[x[i]][y[i]]=1`。
2. 枚举所有有序对 $(i,j)$，$i\ne j$：
   1. $dx=x_j-x_i,\ dy=y_j-y_i$；
   2. $C=(x_j-dy,\ y_j+dx)$，$D=(x_i-dy,\ y_i+dx)$；
   3. 若 $C,D$ 都在 $[0,5000]^2$ 内且 `vis[C]`、`vis[D]` 均为真，则 `ans=max(ans,dx*dx+dy*dy)`。
3. 输出 `ans`。

### 4.3 复杂度分析

- 时间：$O(N^2)$ 次枚举，每次 $O(1)$，共 $O(N^2)$。$N=3000$ 时约 $9\times10^6$ 次，实测 $0.07$ 秒。
- 空间：$O(V^2)$，$V=5001$，`unsigned char` 网格约 $25$ MB；另加 $O(N)$ 点数组。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{3005};
constexpr int mxv{5005};

int n;
int x[mxn],y[mxn];
unsigned char vis[mxv][mxv];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>x[i]>>y[i];
		vis[x[i]][y[i]]=1;
	}

	int ans{0};
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
		{
			if(i==j)
				continue;
			int dx=x[j]-x[i],dy=y[j]-y[i];
			int cx=x[j]-dy,cy=y[j]+dx;
			int ex=x[i]-dy,ey=y[i]+dx;
			if(cx<0||cx>5000||cy<0||cy>5000||ex<0||ex>5000||ey<0||ey>5000)
				continue;
			if(vis[cx][cy]&&vis[ex][ey])
				ans=max(ans,dx*dx+dy*dy);
		}
	cout<<ans<<'\n';
	return 0;
}
```
