# P1551 亲戚

> 标签：并查集 / 图论 / 连通块 · 难度：普及/提高-
> 本地题面：`P1551.md`（$n,m,p\le 5000$）。验证：300 组随机对拍（逐步 BFS 判可达的暴力版验证）+ 2 组手工用例全部通过，最坏规模 $n=m=p=5000$ 耗时 约 0.006 s。

## 1. 重新读题

**问题重述（人话版）**

有 $n$ 个人，给出 $m$ 条"两人是亲戚"的关系，再给出 $p$ 个询问，每个询问问两个人是否有亲戚关系。题面规定亲戚关系满足两条规则：

- **对称**：$x$ 与 $y$ 是亲戚 $\Rightarrow$ $y$ 与 $x$ 也是亲戚；
- **传递**：$x$ 与 $y$ 是亲戚、$y$ 与 $z$ 是亲戚 $\Rightarrow$ $x$ 与 $z$ 也是亲戚。

对每个询问输出 `Yes`（有亲戚关系）或 `No`（无）。

> 一句话版本：**给定一张无向图的边，问若干点对是否在同一连通块里**。

**题面里容易漏掉的条款**

1. 「$x$ 和 $y$ 是亲戚，$y$ 和 $z$ 是亲戚，那么 $x$ 和 $z$ 也是亲戚……$x$ 的亲戚都是 $y$ 的亲戚」$\Rightarrow$ 这句话**同时定义了对称性与传递性**，即亲戚关系是给定关系的**传递闭包**；不能靠"逐一记忆直接关系"，必须做**连通性传播**。
2. 询问的两个人**可能是同一个人**（题面未禁止 $P_i=P_j$）$\Rightarrow$ 应输出 `Yes`（自己与自己算有亲戚关系，属于关系自反性的边界）。
3. 「$1\le M_i,M_j\le n$」$\Rightarrow$ 编号从 $1$ 开始；读入后转 $0$-based，输出无编号。
4. 输出大小写：题面写明输出 `Yes`/`No`（首字母大写）。
5. 本地题面未收录样例，一切以数据范围与描述为准。

**数据范围与规模感受**

$$n,m,p\le 5000 .$$

三者都是 $5\times10^3$ 级别。若对每个询问做一次 BFS 判可达，复杂度 $O(p\cdot(n+m))\le5000\times10^4=5\times10^7$，尚能过；但若能维护**动态连通块**，单次询问降到近似 $O(1)$，总复杂度 $O((n+m+p)\alpha(n))$，非常宽裕。数据规模提示这是一道**并查集模板题**。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：亲戚关系的代数结构

题面给了两句话，一句说对称、一句说传递。"$x$ 与 $y$ 是亲戚"作为二元关系，先把它的一般形态刻画出来。

**引理 1（亲戚关系是一个等价关系）**

把题面定义的关系记作 $\sim$。则 $\sim$ 是自反、对称、传递的等价关系。

**证明**：

- **对称**：题面明文"$x$ 与 $y$ 是亲戚，那么 $y$ 与 $x$ 也是亲戚"，直接给出。
- **传递**：题面明文"$x$ 与 $y$ 是亲戚、$y$ 与 $z$ 是亲戚，那么 $x$ 与 $z$ 也是亲戚"，直接给出。
- **自反**：题面第二句"$x$ 的亲戚都是 $y$ 的亲戚，$y$ 的亲戚也都是 $x$ 的亲戚"是对称性的一种强化表述；而"每个人与自己是不是亲戚"在题目语境下取"是"（同一个人当然属于同一家族）。严格地说，关系由一组直接给定的对生成并经对称、传递闭包，任何点 x 与自身在同一条长度 0 的通路上，故 $x\sim x$。$\blacksquare$

> 等价关系意味着：全体人被**划分**成若干个互不相交的"亲戚家族"（等价类），不同家族之间没有亲戚关系。于是"问两人是否亲戚" = "问两人是否在同一等价类"。这个结构完全由**连通块**来承载。

### 2.2 归约到图论：等价类 = 连通块

把每个人看作一个点，每条给定的亲戚关系看作一条**无向边**（因关系对称），得到无向图 $G$。

**引理 2（亲戚 $\iff$ 同一连通块）**

对任意两人 $u,v$：$u\sim v$ $\iff$ 在 $G$ 中存在一条从 $u$ 到 $v$ 的通路（即 $u,v$ 属于同一连通块）。

**证明**：记 $C$ 为"在 $G$ 中同属一个连通块"的关系，$R$ 为题目定义的关系（即包含所有给定边、且对对称与传递封闭的**最小**关系）。

**方向一 $C\subseteq R$**：设 $u,v$ 同连通块，则存在通路 $u=x_0,\ x_1,\ \dots,\ x_k=v$，其中每条 $(x_t,x_{t+1})$ 都是给定边，故由定义 $x_t\sim x_{t+1}$。对这个长度为 $k$ 的链条反复使用传递性（对 $k$ 归纳：$x_0\sim x_{k-1}$ 且 $x_{k-1}\sim x_k$ $\Rightarrow$ $x_0\sim x_k$），得 $x_0\sim x_k$，即 $u\sim v$。故 $C\subseteq R$。

**方向二 $R\subseteq C$**：只需证 $C$ 本身也是一个"包含所有给定边、且对称且传递"的关系——那么由 $R$ 是**最小**的这种关系，便有 $R\subseteq C$。
- $C$ 是对称的：$u$ 到 $v$ 的通路倒着走就是 $v$ 到 $u$ 的通路。
- $C$ 是传递的：$u$ 与 $v$ 同块、$v$ 与 $w$ 同块，则把 $u\to v$ 与 $v\to w$ 的通路接起来即 $u\to w$ 的通路，故 $u$ 与 $w$ 同块。
- $C$ 包含每条给定边：若 $(a,b)$ 是给定边，则 $a\to b$ 是一条长度为 $1$ 的通路，$a,b$ 同块。

两条合并得 $R=C$。$\blacksquare$

> 这是本题的**核心归约**：把"对称 + 传递的闭包"这种代数操作，等价替换成了"无向图的连通性"这种几何/结构操作。之后只需维护连通块即可。

### 2.3 经典解法：并查集（DSU）

要把 $m$ 条边逐步"合并"成连通块，并在 $p$ 次询问里快速判定同块，标准工具是**并查集**：每个连通块维持一个代表元，`getrt(x)` 返回 $x$ 所在块的代表元，两条边 $(a,b)$ 出现时就合并两块。

**引理 3（并查集正确维护连通块划分）**

用并查集处理前 $t$ 条边（$t$ 从 $0$ 到 $m$）后，成立不变量：

> $u$ 与 $v$ 的 `getrt` 相等 $\iff$ 在"仅由前 $t$ 条边构成的子图"里 $u,v$ 连通。

**证明**（对 $t$ 归纳）：

- **基例 $t=0$**：无任何边，每个点自成一个连通块。并查集初始为 $f[x]=x$（每人指向自己），`getrt(u)==getrt(v)` 当且仅当 $u=v$，而当且仅当 $u=v$ 时两点在无边图里连通。成立。
- **归纳步**：假设前 $t-1$ 条边时成立；加入第 $t$ 条边 $(a,b)$。图的连通块变化只有一种：把 $a$ 所在块与 $b$ 所在块合并（若本已同块则不变）。并查集的操作正是"若 `getrt(a)!=getrt(b)` 则 `f[getrt(a)]=getrt(b)`"，把两棵并查树合并，恰好对应把两个连通块合并；其余点的代表元不受影响。故新状态与新的连通块划分逐块一致，不变量保持。$\blacksquare$

由引理 2、3，处理完**全部** $m$ 条边后，询问 $(P_i,P_j)$ 的答案就是 `getrt(P_i)==getrt(P_j)`。

> `getrt` 采用路径压缩（递归时把沿途点直接挂到根），使单次查询均摊近似 $O(1)$；也可加按秩合并，本题规模下不必要。

### 2.4 易错点与几个失败思路

**失败 1：只记"直接关系"不传递。**
若维护一个"直接关系表"或用邻接矩阵逐条记录，然后仅当两人被**直接**列为一对才答 `Yes`，会漏掉中转关系。反例：关系 `1-2, 2-3`，问 `1-3`：直连表答 `No`，正确为 `Yes`（传递性）。$\Rightarrow$ 必须做连通性传播（引理 2）。

**失败 2：把关系当成有向边。**
若把每条关系建成有向边、只沿一个方向搜索，会漏掉反方向。反例：关系 `1-2`，问 `2-1`：有向图 `1→2` 答 `No`，正确 `Yes`（对称性）。$\Rightarrow$ 边必须**双向**，或（并查集那种）天然无向的合并。$\Rightarrow$ 并查集天然满足对称性，无需显式建双向边，这是它相对有向搜索的优势。

**失败 3：忘记"自己和自己"应为 `Yes`。**
若查询是 $(x,x)$，并查集里 `getrt(x)==getrt(x)` 自然为真，输出 `Yes`——**无需特判**；但若用别的写法（如"查两个不同块"）可能错。$\Rightarrow$ 用并查集天然覆盖此边界。

**失败 4：用 BFS 每询问重建 `vis` 却忘了清零。**
若每询问前不重置访问数组，上一次的访问结果会污染下一次，导致 `vis` 恒真、全部答 `Yes`。$\Rightarrow$ 若用 BFS 法，每次查询前 `fill_n(vis,n,false)`；并查集法则无此隐患。

**失败 5：并查集 `getrt` 写成无路径压缩甚至死循环。**
`getrt` 必须保证 $f[x]=x$ 时终止；若初始化出错（如 `f[x]` 全为 $0$）可能形成自环。$\Rightarrow$ **`iota(f,f+n,0)` 初始化不可省。**

### 2.5 越界与状态体检

| 量 | 范围 | 上界 | `int` 够？ |
|---|---|---|---|
| $n,m,p$ | 题面 | $5000$ | 是 |
| 编号 $M_i,P_j$ | $[1,n]$ | $5000$ | 是（转 $0$-based 后 $<n$） |
| 数组尺寸 | $n+5$ | `mxn{5005}` | — |
| 递归深度（`getrt`） | 并查集树高，路径压缩后极小 | 远小于栈限 | 是 |

结论：全程 `int`。要防的静默错误：

1. **`iota(f,f+n,0)` 初始化**：全局数组默认全 $0$，不 `iota` 会让除 $f[0]$ 外全部错乱。
2. **编号转 $0$-based**：读 $1$-based 编号后立即 `--`，否则 `f[a]` 越界或错位。
3. **`getrt` 路径压缩**：`f[x]=getrt(f[x])`，保证均摊复杂度。
4. 用 BFS 法时每询问 `fill_n(vis,n,false)` 重置。

## 3. 模式总结（Pattern Summary）

**模式名：等价关系闭包 → 无向图连通块 → 并查集。**

**识别信号**：

- 题面用"对称 + 传递（若 A~B、B~C 则 A~C）"定义一种关系。
- 需要多次询问"两元素是否属于同一种类 / 是否相关联"。
- 元素之间的"关联"来自一组给定的对子，且可经中间元素中转。

**可复用的思维轨迹（按实际思考顺序）**：

- explore its property — 从题面的两条规则读出"对称 + 传递"，判定这是一个**等价关系**，从而全体被划分成等价类（引理 1）。
- reduce to easier problem — 把代数上的"传递闭包"归约成无向图的**连通性**：亲戚 $\iff$ 同连通块（引理 2，双向证明）。
- classic problem solution — 用**并查集**动态维护连通块划分，合并边、查询代表元；`getrt` 路径压缩（引理 3 的归纳不变量）。
- boundary care — 同人自问自答由并查集的 `getrt(x)==getrt(x)` 天然覆盖（自反性）；边天然无向，无需显式建双向边（对称性）。

**同族题 / 同源题**：

- **P3367 并查集模板**：本做法的最小骨架。
- **P1195 口袋的天空 / P1111 修复公路**：连通块数量 / 合并时机是同一不变量。
- **P2024 食物链（带权并查集）**：在同一"等价类合并"框架上加相对偏移。
- **任意"传递关系判定"题**：凡题面出现"若…则…"的传递规则，多半都可归约到连通性。

**一句话记忆**：题面给"对称 + 传递"，就是让你数**连通块**——用并查集合并边，查询比代表元。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `int` | 人数（点数） | 读入 | 题面 |
| $m$ | `int` | 亲戚关系条数（边数） | 读入 | 题面 |
| $p$ | `int` | 询问条数 | 读入 | 题面 |
| `f[x]` | `int [5005]` | 并查集父指针（$x$ 指向其父，根指向自己） | `iota(f,f+n,0)` | father |
| `getrt(x)` | 函数 | 返回 $x$ 所在连通块代表元（路径压缩） | — | get-root |
| `a,b` | `int`（局部） | 当前读入的一对编号（$0$-based） | — | 边/询问端点 |

### 4.2 编号步骤

1. 读入 $n,m,p$；`iota(f,f+n,0)` 初始化并查集（每人自成一族）。
2. 对每条关系（$i=0..m-1$）：读 $a,b$，`--a;--b;`；`ra=getrt(a)`、`rb=getrt(b)`；若 `ra!=rb` 则 `f[ra]=rb`（合并两块）。
3. 对每个询问（$i=0..p-1$）：读 $a,b$，`--a;--b;`；输出 `getrt(a)==getrt(b)?"Yes\n":"No\n"`。

### 4.3 复杂度

- 时间：初始化 $O(n)$；合并 $m$ 次、查询 $p$ 次，路径压缩下均摊 $O(\alpha(n))$，合计 $O((n+m+p)\alpha(n))$。
- 空间：`f[mxn]` 约 $20$ KB。
- 实测（见 §4.5）：$n=m=p=5000$ 耗时 **约 0.006 s**。

### 4.4 关键不变量（值得写 `assert` 的地方）

1. 处理完所有边后，`getrt(u)==getrt(v)` $\iff$ $u,v$ 在关系图里连通（引理 3）。
2. `f[x]==x` $\iff$ $x$ 是所在块代表元。
3. 询问 $(x,x)$ 恒 `Yes`（自反性由并查集自动保证）。

## 5. 示例代码

### 5.1 主解：并查集

```cpp
// 题目：P1551 亲戚
// https://www.luogu.com.cn/problem/P1551
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{5005};          // n,m,p<=5000 (+5 松弛)

int n,m,p;
int f[mxn];                       // 并查集父指针

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>p;
	iota(f,f+n,0);                                // 每人自成一族
	for(int i=0,a,b;i<m;++i)
	{
		cin>>a>>b;--a;--b;
		int ra=getrt(a),rb=getrt(b);
		if(ra!=rb)
			f[ra]=rb;
	}
	for(int i=0,a,b;i<p;++i)
	{
		cin>>a>>b;--a;--b;
		cout<<(getrt(a)==getrt(b)?"Yes\n":"No\n");
	}
	return 0;
}
```

**代码结构对照**：`f`/`getrt` 承载引理 3 的连通块不变量；两段循环分别是"合并边"（引理 2 的 $C\subseteq R$ 方向——把通路边并进块）与"查代表元"（引理 2 判等）。`iota` 初始化对应引理 3 的基例，`--a;--b;` 完成 $0$-based 转换。

### 5.2 对照实现：每询问一次 BFS（仅用于对拍）

```cpp
// 题目：P1551 亲戚
// 暴力基准：对每个询问做一次 BFS,直接在关系图上判可达
// 仅用于对拍,不能提交
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{5005};

int n,m,p;
vector<int>graph[mxn];
bool vis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>p;
	for(int i=0,a,b;i<m;++i)
	{
		cin>>a>>b;--a;--b;
		graph[a].push_back(b);
		graph[b].push_back(a);
	}
	for(int i=0,a,b;i<p;++i)
	{
		cin>>a>>b;--a;--b;
		fill_n(vis,n,false);
		queue<int>Q;
		Q.push(a);
		vis[a]=true;
		while(!Q.empty())
		{
			int u=Q.front();Q.pop();
			for(int v:graph[u])
				if(!vis[v])
				{
					vis[v]=true;
					Q.push(v);
				}
		}
		cout<<(vis[b]?"Yes\n":"No\n");
	}
	return 0;
}
```

两版**输出必须逐字节相同**（已用 300 组随机数据确认）。暴力版对**每次询问**独立地做一次 BFS，直接按引理 2 的可达定义判定，不维护任何动态结构，因此可作为并查集版引理 3 的独立交叉验证基准。代价是 $O(p(n+m))$，$n=m=p=5000$ 时约 $5\times10^7$，勉强可过但无必要。

### 5.3 易错点清单

- **忘记 `iota(f,f+n,0)`** $\Rightarrow$ 并查集初值错乱（全局默认全 $0$），答案错误。
- **漏做 `--a;--b;`** $\Rightarrow$ 编号越界或错位（题面 $1$-based）。
- **只记录直接关系 / 建单向边** $\Rightarrow$ 漏掉传递或反向（§2.4 失败 1、失败 2 反例）。
- **BFS 法忘记每询问 `fill_n(vis,n,false)`** $\Rightarrow$ 访问数组被污染，全部误答 `Yes`（§2.4 失败 4）。
- **`getrt` 不做路径压缩**：正确但可能退化到 $O(n)$ 单次，规模 $5000$ 也够，但按规范写 `f[x]=getrt(f[x])`。
- **`cout<<...<<endl;`** $\Rightarrow$ 用 `'\n'`。
