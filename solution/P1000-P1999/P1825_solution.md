# P1825 [USACO11OPEN] Corn Maze S

> 难度：普及/提高- · 标签：BFS, 最短路, USACO

## 1. 重新读题

### 1.1 问题重述（人话版）

$N\times M$ 的迷宫。`#` 不能走，`.` 是草地，`@` 是起点（也是草地），`=` 是出口。大写字母成对出现，是双向滑梯的两端：一踩上去就必须滑到另一端，滑动本身花 $0$ 时间。四方向走到相邻格子花 $1$。滑完一次之后，必须先用普通走路挪至少一步，才能再次滑动。求 `@` 到 `=` 的最短时间。

### 1.2 关键约束与规模暗示

- $2\le N,M\le 300$，格子 $9\cdot 10^4$，单位权最短路用 BFS 足够。
- 迷宫外圈是玉米，但代码仍要做越界判断。
- 同一字母恰好两个端点；不同滑梯不用同一字母。
- 「不能连续传送」容易被写成多余状态。它真正禁止的是：落到另一端后，不再走路就立刻按原路滑回去。
- 样例答案是 $3$：向右踩上 `W`（$1$）滑到另一端（$0$），再右、再上到达 `=`（再 $2$）。

## 2. 思维链（Chain-of-thought）

先把「踩上滑梯必须滑走」翻译成边，而不是翻译成格子上的驻留。

**引理 1（滑梯边的改写）**

站在某个非墙格 $u$，走向相邻格 $v$：

- 若 $v$ 不是字母，则得到一条权为 $1$ 的边 $u\to v$；
- 若 $v$ 是某字母的一端，另一端是 $t$，则得到一条权为 $1$ 的边 $u\to t$（走路的 $1$ 加上滑动的 $0$），不存在停在 $v$ 上的状态。

你真正能站着的字母格，只可能是「从它的另一端被滑过来」之后的落点。

**证明**：题面规定踩到任一端必须使用滑梯，滑动耗时 $0$。因此从邻格走进 $v$ 的那个时刻，位置立刻变成 $t$，总耗时只增加走进 $v$ 的 $1$。落在 $t$ 之后，下一次动作必须是走到 $t$ 的某个邻居；这一步是非传送移动。若该邻居又是滑梯，那也是先走了一步再滑，并不违反「传送后至少走一步」。模型里没有「落在 $t$ 上立刻再滑」的边，所以连续传送不会发生。$\blacksquare$

**引理 2（这张图的边权全是 $1$，BFS 第一次到达即最短）**

图是静态的：边只由格子和字母配对决定，不随「是否刚传送过」改变。每条边权都是 $1$。

**证明**：在非负单位权有向图里，BFS 按距离分层。设 $d(s,u)$ 为最短路。第一次出队 $u$ 时，它来自某个距离小 $1$ 的前驱，故到达时间 $\ge d(s,u)$ 且等于「前驱最短 $+1$」。若还有更短的路，它的最后一条边的起点会在更早的层被扩展，矛盾。所以第一次写入的距离就是最短路，之后再入队只会更长或相等，用 `dis!=-1` 丢掉即可。$\blacksquare$

一个容易错的实现是：走进字母格时把**入口和出口都标成已访问**。下面这张图会因此丢解（`#` 为墙）：

```text
#######
#@A.=.#
#######
#..A..#
#######
```

正确过程：从 `@` 向右踩上第一个 `A`，花 $1$ 落到下方的 `A`；再向左走到它左边一格（花 $1$），再向右重新踩上下方的 `A`，花 $1$ 滑回上方的 `A` 并**站在那里**；然后向右两步到 `=`。总时间 $5$。若第一次经过上方 `A` 时就把它标死，就永远不能「站上去再向右走出」，出口不可达。标程只标记**落点**，这张图输出 $5$，与 Bellman-Ford 暴力一致。

暴力不是 BFS：在同一张改写图上做 Bellman-Ford，松弛 $NM$ 轮。单位正权下它和 BFS 求的是同一个距离，但枚举顺序完全不同，适合做对拍。随机迷宫只生成到 $9\times 9$，因为 Bellman-Ford 是 $O((NM)^2)$。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 滑梯不是可停留格，走进入口的边应直接连到另一端，权仍为 $1$（引理 1）。
- **classic problem solution** — 改写之后是单位权静态图，BFS 第一次到达即最短（引理 2）。
- **boundary discipline** — 只标记落点，不标记被滑过的入口；样例与「必须滑回去再走出来」的图都要单独对上。
- **consider easier version** — 没有字母时退化为普通网格 BFS。$300\times 300$ 的空走廊用来卡规模，答案是同行两端的列差。

## 4. 真实解法

### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `n,m` | `int` | 行、列 | 读入 | 1-based 网格 |
| `g` | `char [305][305]` | 地图 | 读入 | `@ . # = A-Z` |
| `px,py,qx,qy` | `int [26]` | 每个字母两个端点 | 第一次写入 `p*`，第二次写入 `q*` | pair 的两端 |
| `seen` | `int [26]` | 该字母已经出现几次 | 全局 $0$ | 区分两端 |
| `dis` | `int [305][305]` | 最短时间，$-1$ 表示没到过 | `memset` 成 $-1$ | 兼当访问标记 |
| `dx,dy` | `int [4]` | 四方向 | `{1,-1,0,0}` 与 `{0,0,1,-1}` | 上下左右 |

### 4.2 算法步骤

1. 读地图。记下 `@`，并把每个大写字母的两个坐标存进 `p*` / `q*`。
2. 从起点 BFS。走向相邻格时，若是字母，目标改成另一端。
3. 目标格的 `dis` 已非 $-1$ 则跳过；否则写入 `当前+1`。
4. 若目标格是 `=`，立刻输出该距离。边权为正且图静态，第一次到达就是最短。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 时间、空间都是 $O(NM)$。
- 编译：`g++ -O2 -std=c++17 -Wall -Wextra -Werror`，无警告。
- 官方样例标程、Bellman-Ford、Python BFS 三者都是 `3`。上面那张必须「滑回去再走出」的图三者都是 `5`。另有一张无滑梯的 `4\times 5` 走廊，答案 `2`。
- 随机 $3\le N,M\le 9$、带 $0\sim 3$ 对滑梯且 Python 先筛掉走不到出口的图：200 组三者一致，耗时 $1.08$ s。
- 最大规模 $300\times 300$、第 $2$ 行从第 $2$ 列到第 $299$ 列是空走廊：标程答案 `297`，耗时 $0.0041$ s。
- 合计 `204 tests OK`。

## 5. 示例代码

### 5.1 标程（`P1825.cpp`）

```cpp
//
// 题目：P1825 [USACO11OPEN] Corn Maze S
// https://www.luogu.com.cn/problem/P1825
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{305};
constexpr int dx[4]{1,-1,0,0};
constexpr int dy[4]{0,0,1,-1};

int n,m;
char g[mxn][mxn];
int dis[mxn][mxn];
int px[26],py[26],qx[26],qy[26],seen[26];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>m;
	int sx=1,sy=1;
	for(int i=1;i<=n;++i)
	{
		string s;
		cin>>s;
		for(int j=1;j<=m;++j)
		{
			g[i][j]=s[j-1];
			if(g[i][j]=='@')
				sx=i,sy=j;
			if(g[i][j]>='A'&&g[i][j]<='Z')
			{
				int id=g[i][j]-'A';
				if(seen[id]==0)
					px[id]=i,py[id]=j;
				else
					qx[id]=i,qy[id]=j;
				++seen[id];
			}
		}
	}
	memset(dis,-1,sizeof(dis));
	dis[sx][sy]=0;
	queue<pair<int,int>>Q;
	Q.push({sx,sy});
	while(!Q.empty())
	{
		int x=Q.front().first,y=Q.front().second;
		Q.pop();
		for(int k=0;k<4;++k)
		{
			int nx=x+dx[k],ny=y+dy[k];
			if(nx<1||nx>n||ny<1||ny>m||g[nx][ny]=='#')
				continue;
			int tx=nx,ty=ny;
			if(g[nx][ny]>='A'&&g[nx][ny]<='Z')
			{
				int id=g[nx][ny]-'A';
				if(px[id]==nx&&py[id]==ny)
					tx=qx[id],ty=qy[id];
				else
					tx=px[id],ty=py[id];
			}
			if(dis[tx][ty]!=-1)
				continue;
			dis[tx][ty]=dis[x][y]+1;
			if(g[tx][ty]=='=')
			{
				cout<<dis[tx][ty]<<'\n';
				return 0;
			}
			Q.push({tx,ty});
		}
	}
	return 0;
}
```
