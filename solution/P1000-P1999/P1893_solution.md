# P1893 [USACO10OPEN] 山峰暸望 Mountain Watching B

> 难度：普及- · 标签：模拟, 枚举, USACO

## 1. 重新读题
### 1.1 问题重述（人话版）

给一排高度。一座「山」是一段连续位置，高度先不下降、再不上升（平台也算，纯上升或纯下降也算，相当于山顶贴在端点）。山的宽度是这段的长度。求最宽的山。

### 1.2 关键约束与规模暗示

`1 ≤ N ≤ 10^4`，高度到 `10^9`。`O(N^2)` 可以过，但每个位置向左右延伸可以做成 `O(N)`。样例 `3,2,3,5,4,1,6` 的答案是 5，对应 `2,3,5,4,1`。

## 2. 思维链（Chain-of-thought）

把下标写成 0-based。子段 `[l, r]` 是山，当且仅当存在山顶 `p`（`l ≤ p ≤ r`），使得 `h[l] ≤ h[l+1] ≤ … ≤ h[p]` 并且 `h[p] ≥ h[p+1] ≥ … ≥ h[r]`。相等允许出现在上坡、山顶平台或下坡的任何地方，定义里已经用了非严格不等号。

**引理 1（以 `i` 为山顶能向左右延伸多远）。** 定义

- `lf[i]`：最小的下标，使 `h[lf[i] .. i]` 不下降；
- `rg[i]`：最大的下标，使 `h[i .. rg[i]]` 不上升。

则 `[lf[i], rg[i]]` 是一座以 `i` 为山顶的山，宽度 `rg[i]-lf[i]+1`。并且任何以 `i` 为山顶的山都含在这个区间里。

证明：把左右两段接在 `i` 上，左边不下降、右边不上升，符合山的定义。若还有一座以 `i` 为山顶的 `[l, r]`，则 `[l, i]` 不下降，所以 `l` 不能比 `lf[i]` 更左，否则 `lf[i]` 就不是最小；同理 `r` 不能比 `rg[i]` 更右。

**引理 2（`lf`、`rg` 可以线性递推）。**

- `lf[0] = 0`。若 `h[i-1] ≤ h[i]`，则 `lf[i] = lf[i-1]`；否则 `lf[i] = i`。
- `rg[n-1] = n-1`。若 `h[i] ≥ h[i+1]`，则 `rg[i] = rg[i+1]`；否则 `rg[i] = i`。

证明只写 `lf`，`rg` 是对称的。对 `i` 归纳，`[lf[i], i]` 不下降，且不能再向左。

`i = 0` 时单点成立。设 `i ≥ 1`。

- 若 `h[i-1] > h[i]`，单点 `[i, i]` 不下降。左边那个元素已经更大，任何更长的、以 `i` 结尾的区间都会包含这对下降，所以不能再向左，`lf[i] = i`。
- 若 `h[i-1] ≤ h[i]`，由归纳 `[lf[i-1], i-1]` 不下降，接上 `h[i]` 后整段仍不下降。它也不能再向左：若 `lf[i-1] > 0`，归纳假设说 `h[lf[i-1]-1] > h[lf[i-1]]`，把起点再左移一位就会在那里下降。所以最远左端就是 `lf[i-1]`。

**定理。** 答案等于 `max_i (rg[i] - lf[i] + 1)`。

证明：引理 1 说明每个 `i` 都给出一座合法的山，所以这个最大值 `≤` 答案。反过来，任意一座山 `[l, r]` 有某个山顶 `p`。引理 1 的后半句说它的宽度 `≤ rg[p]-lf[p]+1`。取遍所有山，答案 `≤` 那个最大值。两边夹住。

单点的宽度是 1，`N ≥ 1` 时答案至少为 1。全相等时 `lf` 全部是 0、`rg` 全部是 `n-1`，答案是 `n`，整段是一座平顶山。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 山就是存在一个山顶，左边不下降、右边不上升。
- **reduce to easier problem** — 每个位置当山顶，答案是这些合法区间宽度的最大。
- **classic problem solution** — 最远左端点、最远右端点都可以从相邻位置 `O(1)` 转移。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `h[i]` | `int[10005]` | 高度，0-based | 读入 | height |
| `lf[i]` | `int[10005]` | 以 `i` 为右端的最长不下降段的左端 | `lf[0]=0`，向右递推 | left |
| `rg[i]` | `int[10005]` | 以 `i` 为左端的最长不上升段的右端 | `rg[n-1]=n-1`，向左递推 | right |
| `ans` | `int` | 最大宽度 | `0` | answer |

### 4.2 算法步骤

1. 读入 `n` 和 `h[0..n)`。
2. 从左到右求 `lf`，从右到左求 `rg`，规则见引理 2。
3. 扫描每个 `i`，用 `rg[i]-lf[i]+1` 更新答案并输出。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 `O(n)`，空间 `O(n)`。官方样例输出 `5`。暴力对每个左端点把右端点向右推，用「先尽量上升，剩下必须下降」判定是不是山；一旦失败就停止，因为山的任意前缀仍是山（山顶若在前缀右边，前缀就是纯上升）。手造的平顶、纯升、纯降、`3,1,1,2,3,4`（答案应为 5）等 10 组，加 30 组 `n ≤ 80`、8 组 `n ≤ 220`，都与标程相同。`n = 10000` 的随机高度只跑标程，答案 `9`，耗时 `0.0074 s`。合计 `50` 组，`-Wall -Wextra -Werror` 警告数为 0。

## 5. 示例代码
### 5.1 标程（`P1893.cpp`）

```cpp
//
// 题目：P1893 [USACO10OPEN] 山峰暸望 Mountain Watching B
// https://www.luogu.com.cn/problem/P1893
// 本地对拍验证通过

#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int n;
int h[mxn];
int lf[mxn],rg[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=0;i<n;++i){
		cin>>h[i];
	}
	lf[0]=0;
	for(int i=1;i<n;++i){
		if(h[i-1]<=h[i]){
			lf[i]=lf[i-1];
		}else{
			lf[i]=i;
		}
	}
	rg[n-1]=n-1;
	for(int i=n-2;i>=0;--i){
		if(h[i]>=h[i+1]){
			rg[i]=rg[i+1];
		}else{
			rg[i]=i;
		}
	}
	int ans=0;
	for(int i=0;i<n;++i){
		int w=rg[i]-lf[i]+1;
		if(w>ans){
			ans=w;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```
