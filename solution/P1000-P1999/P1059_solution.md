# P1059 [NOIP 2006 普及组] 明明的随机数 题解

---

## 一、发现叙事

### 1.1 题目在说什么

明明生成了 N 个 1 到 1000 之间的随机整数。实验规则要求：重复的数字只保留一个（去重），然后将剩下的数字从小到大排序（排序），最后按顺序找同学做调查。

我们需要输出两行：

- 第一行：去重后剩余的数字个数 M；
- 第二行：这 M 个数从小到大排列。

数据范围非常小：N ≤ 100，数值范围 1 ≤ a_i ≤ 1000。

### 1.2 从生活直觉到算法问题

把题目翻译成计算机术语，就是我们手中有一个长度为 N 的数组，里面可能有重复元素。我们需要：

1. 去掉重复元素，使每个元素唯一；
2. 对唯一元素集合按升序排列。

这是典型的"去重 + 排序"问题。因为 N 和值域都很小，我们可以用多种方式解决。但从 OI 学习的角度，这个问题可以引导我们思考几种不同的技术路线。

### 1.3 第一直觉：排序后去重

最朴素的想法：先把所有数排序，这样相同的数就会挨在一起。然后遍历一遍，遇到与前一个不同的数就保留。

这个思路的直接性让它成为最易理解的做法。但排序后去重的顺序是 O(N log N)（排序）加 O(N)（遍历），空间 O(N)。

### 1.4 第二直觉：桶计数

观察到一个重要性质：数值范围只有 1 到 1000。这意味着我们可以开一个大小为 1001 的布尔数组（或计数数组），在 O(N) 时间内完成去重——遇到一个数 x，就把桶标记为 true。然后遍历 1 到 1000，遇到标记为 true 的就输出。

这样排序甚至不需要写 sort——值域本身天然有序。总复杂度 O(N + V)，其中 V = 1000 是值域。

### 1.5 第三直觉：C++ STL 直接操作

如果我们使用 C++ 的 STL，可以用 `std::set` 或者 `std::unique` 来一行完成去重。但出于教学目的，我们选择最体现思维过程的方法。

## 二、思路链与完整证明

### 2.1 问题形式化

定义输入：

- 正整数 N（1 ≤ N ≤ 100）
- 序列 A = ⟨a_1, a_2, …, a_N⟩，其中 a_i ∈ [1, 1000]

定义输出：

- M = |{a_1, a_2, …, a_N}|，即集合的大小（不同元素的个数）
- 序列 B = ⟨b_1, b_2, …, b_M⟩，其中 {b_1, …, b_M} = {a_1, …, a_N} 且 b_1 < b_2 < … < b_M

### 2.2 解法一：排序 + 线性去重

**算法流程**：

1. 读入 N 和数组 a。
2. 对 a 按升序排序。
3. 遍历排序后的 a：维护一个指针 j，表示"去重后数组的尾部"。
   - 初始时 j = 0。
   - 对于 i 从 1 到 N（若 a_i ≠ a_{i-1}），则将 a_i 写入 a_j 并 ++j。
4. 输出 j 和 a[0..j-1]。

**正确性证明**：

- 排序后，相等的元素必然相邻。设排序后的数组为 a'，满足 a'_1 ≤ a'_2 ≤ … ≤ a'_N。
- 在遍历中，我们只保留 a'_i 与 a'_{i-1} 不相等的那些元素。
- 因为所有相等元素中，只有第一个被保留，其余被丢弃，所以每种值恰好保留一个。
- 又因为 a' 是有序的，保留下来的子序列保持相同的升序性质。
- 因此输出的序列就是排序且去重后的正确结果。

**复杂度**：O(N log N) 时间，O(N) 额外空间（若允许原地操作则 O(1) 额外空间）。

### 2.3 解法二：桶计数（值域哈希）

**算法流程**：

1. 读入 N。
2. 维护一个布尔数组 `vis[1001]`，初始全 false。
3. 对于每个读入的数 x：
   - 若 vis[x] == false，则 cnt++，vis[x] = true。
4. 遍历 i 从 1 到 1000：
   - 若 vis[i] == true，则输出 i。
5. 先输出 cnt，再输出遍历结果。

**正确性证明**：

- 定义指示函数 I(x) = [存在某个 i 使得 a_i = x]。
- `vis[x]` 准确地记录了 I(x) 的值。第一次遇到 x 时我们计数并标记，后续遇到相同 x 时标记已经为 true，不再重复计数。
- 所以 M = Σ_{x=1}^{1000} I(x) = cnt。
- 遍历 1 到 1000 时，按升序输出所有满足 I(x) = true 的 x，自然得到有序的唯一值序列。
- 值域的有限性保证了我们可以在 O(V) 时间内完成遍历。

**复杂度**：O(N + V) 时间，O(V) 空间（V = 1000 为值域上界）。当 V 很大时不再适用，但本题 V = 1000，是最高效的方案。

### 2.4 解法三：基于平衡树（std::set）

**算法流程**：

1. 读入 N。
2. 定义 `set<int> s`。
3. 对于每个读入的数 x：`s.insert(x)`。
4. 输出 `s.size()`，然后遍历 s 输出所有元素。

**正确性证明**：

- `std::set` 内部以红黑树实现，保证元素唯一且始终有序。
- `insert` 操作如果元素已存在则不产生任何效果。
- 所以 `s.size()` = M，遍历 s 即得到升序的唯一值序列。

**复杂度**：O(N log N) 时间，O(N) 空间。代码最简洁，但常数较大。

### 2.5 为什么桶计数是本问题的最优解

本题的特殊性在于：

- 值域 V = 1000 极小（与 N 同级甚至更小）；
- N 也只有 100。

在这种约束下：

- 桶计数运行 O(N + V) 约 1100 次操作；
- 排序方案运行 O(N log N) 约 100 × 7 = 700 次比较（外加元素移动）；
- set 方案运行 O(N log N) 约 100 × 7 = 700 次红黑树操作。

虽然绝对差距不大，但桶计数胜在实现简单、无需理解排序或平衡树、直观性强，是这道入门题最希望考察的能力——即**观察数据范围并选择合适方法**。

## 三、模式总结

> **"小值域去重排序 → 桶计数"**
>
> 当元素值域较小（通常 V ≤ 10^6）且 N 与 V 可比时，桶计数是去重 + 排序的最优方案：
>
> - 以布尔数组作为集合，值作为下标实现 O(1) 插入/查询；
> - 值域天然有序，遍历即排序；
> - 复杂度 O(N + V) 线性时间，常数极小。
>
> 关键识别信号：输入范围小、需要去重、需要有序输出。

**拓展语境**：

- 若值域很大（如 a_i ≤ 10^9），则需要排序或哈希表；
- 若还需要统计频次（不仅仅是去重），计数数组可扩展为 `int cnt[]` 而非 `bool vis[]`；
- 若 N 极大而值域极小（如 N = 10^7, V = 1000），桶计数依然高效——这正是计数排序的思想。

## 四、正式解法

### 4.1 符号表

| 符号 | 含义 |
|------|------|
| N | 输入的随机数个数 |
| a_i | 第 i 个随机数 |
| M | 去重后不同数值的个数 |
| vis[x] | 布尔数组，vis[x] = true 表示数值 x 出现过 |
| ans[] | 用于存储去重后有序结果的数组（可选） |

### 4.2 算法步骤（桶计数方案）

**Step 1：初始化**

```
vis[1..1000] ← false
cnt ← 0
```

**Step 2：读入并去重计数**

```
for i ← 1 to N:
    read x
    if not vis[x]:
        vis[x] ← true
        cnt ← cnt + 1
```

**Step 3：收集有序结果**

```
j ← 0
for i ← 1 to 1000:
    if vis[i]:
        ans[j] ← i
        j ← j + 1
```

**Step 4：输出**

```
print cnt
for i ← 0 to cnt-1:
    print ans[i] (以空格分隔)
```

### 4.3 算法正确性

已在第 2.3 节中证明，不再重复。

### 4.4 复杂度分析

- 时间复杂度：读入阶段 O(N)，收集阶段 O(V)，总 O(N + V)。最坏情况 N = 100, V = 1000，约 1100 次操作。
- 空间复杂度：O(V) = O(1000) 的布尔数组，加 O(M) ≤ O(N) 的结果数组，总 O(V)。

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

bool vis[1001];
int ans[105];

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;

	for(int i=0,x;i<n;++i)
	{
		cin>>x;
		if(!vis[x])
		{
			vis[x]=true;
		}
	}

	int m=0;
	for(int i=1;i<=1000;++i)
	{
		if(vis[i])
		{
			ans[m++]=i;
		}
	}

	cout<<m<<'\n';
	for(int i=0;i<m;++i)
	{
		cout<<ans[i]<<" \n"[i==m-1];
	}

	return 0;
}
```

### 5.1 代码要点说明

1. **`bool vis[1001]`**：下标 0 闲置，直接使用 1..1000 作桶，偏移为零。
2. **读入时去重**：若 `vis[x]` 为 false 则标记为 true；`m` 在收集阶段统一计算，也可以在读入时累加，这里选择分离逻辑更清晰。
3. **收集阶段 `for i=1 to 1000`**：自然升序，无需 sort。
4. **输出技巧 `" \n"[i==m-1]`**：对前 m-1 个数输出空格，最后一个数输出换行，避免行末多余空格。
5. 完全遵循规范：`#include<bits/stdc++.h>`、`using namespace std;`、`cin.tie(nullptr);` + `ios::sync_with_stdio(false);`、`'\n'` 替代 `endl`、Allman 风格花括号。

### 5.2 备选方案（排序 + unique）

```cpp
#include<bits/stdc++.h>
using namespace std;

int a[105];

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];

	sort(a,a+n);
	int m=unique(a,a+n)-a;

	cout<<m<<'\n';
	for(int i=0;i<m;++i)
		cout<<a[i]<<" \n"[i==m-1];

	return 0;
}
```

`std::unique` 将相邻重复元素移至数组末尾，返回指向"新结尾"的迭代器。配合 `sort` 可在两行内完成去重 + 排序。代码更短，但内部仍为 O(N log N)。
