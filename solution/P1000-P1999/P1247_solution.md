# P1247 取火柴游戏 — 题解

> 这是经典的 **Nim（尼姆博弈）** 问题。下面用"学生式发现"的顺序写出完整推导，并对每一个引理给出**完整证明**（不用"显然"）。

---

## Part 1 — 重读题意（用更简单的话说一遍）

有 $k$ 堆火柴，第 $i$ 堆有 $n_i$ 根（$k \le 5\times10^5$，$n_i \le 10^9$）。你（先手）和计算机轮流取，规则：

- 每一轮，从**某一个堆**中取走**任意正数**根火柴（可以一次把整堆取光）；
- **不能**一次跨两个堆取；**不能**不取；
- 谁取走**最后一根**火柴谁获胜（正常和局，normal play）。

任务：判断**先手必胜还是先手必败**。
- 若先手必胜：输出第一次该从哪一堆取多少根。若有多种走法，输出 $\langle b,a\rangle$ **字典序最小**的解，即**先让堆号 $b$ 最小**，再让取的数量 $a$ 最小。第一行输出 `a b`（注意顺序：先取的数量 $a$，后堆号 $b$），第二行输出第一次取完后 $k$ 个堆的状态（空格分隔）。
- 若先手必败：输出 `lose`。

一个关键提示：题目例子里反复把局面归结为 $(2,2)$、$(1,2,3)\to(0,2,2)$ 这类"**成对相等**"的局面，并说"不管对方怎么取我都必胜"。这个"成对"现象是 Nim 的核心直觉（异或为 0）。

## Part 2 — 思维链（完整推导 + 每个引理完整证明）

### 步骤 1：把"特殊机制"说清楚 —— 一个局面能怎么走

一个**局面**就是一个 $k$ 元组 $(n_1,n_2,\dots,n_k)$，$n_i\ge 0$，$\sum_i n_i>0$ 时为进行中局面，$(0,0,\dots,0)$ 为终局。

一次合法操作 = **选一个下标 $i$，把 $n_i$ 改成任意更小的非负整数**（即从这堆取走 $n_i-n_i'$ 根，$1\le n_i-n_i'\le n_i$，其余堆不动）。

终局 $(0,\dots,0)$ 没有任何合法后继。"取走最后一根获胜"意味着：**走到 $(0,\dots,0)$ 的那一方赢**，等价于"**轮到某一方时局面是 $(0,\dots,0)$，则该方输**"。

### 步骤 2：先解简化版 —— 只有一堆（k = 1）

只有一堆 $n_1$：
- 若 $n_1=0$：该走的人没得取，输。
- 若 $n_1\ge 1$：该走的人直接把整堆取光 $\to (0)$，对方输，所以**当前玩家赢**。

即单堆时：$n_1=0$ 是**先手必败**（轮到的人输），$n_1\ge 1$ 是**先手必胜**（轮到的人能立即取胜）。

这里"先手必胜/必败"始终指"**轮到当前玩家**的局面"。我们沿用这个约定，把"轮到当前玩家必败"记为 **P 位置（Previous player win，上一手赢）**，"轮到当前玩家必胜"记为 **N 位置（Next player win，下一手赢）**。

### 步骤 3：N/P 的递归定义（这是后面一切的地基）

**定义（P/N 位置，完整给出）：**
- 局面 $S$ 是 **N 位置** ⟺ 存在某个合法后继 $S'$，使得 $S'$ 是 **P 位置**。
- 局面 $S$ 是 **P 位置** ⟺ 它的**每一个**合法后继 $S'$ 都是 **N 位置**。
- 约定终局 $S_0=(0,\dots,0)$ 是 **P 位置**。

**为什么这个递归定义就是"必胜/必败"本身？** 下面给出完整的双向论证（不是"显然"）。

**命题 1.** 在有限、无环（每步总和严格减小，故必终止）的两人轮流游戏中，局面 $S$ 是 N 位置 ⟺ 轮到 $S$ 的一方在最优博弈下必胜。

*证明（对"总和 $\Sigma=\sum n_i$"做强归纳）。*

- **基础** $\Sigma=0$：$S=S_0$，无合法后继。按定义 $S_0$ 是 P 位置。轮到 $S_0$ 的一方没得取即输，即**轮到他的一方必败**，等价于"轮到他的一方不赢"，与"$S_0$ 不是 N"一致。✓

- **归纳假设**：对所有总和 $<\Sigma$ 的局面，"是 N 位置"与"轮到他的一方必胜"等价。

- **归纳步骤**，考虑总和为 $\Sigma$ 的局面 $S$。

  **(i) 若 $S$ 是 N 位置：** 按定义存在合法后继 $S'$ 为 P 位置。$\Sigma(S')<\Sigma$，由归纳假设"$S'$ 是 P 位置 $\Rightarrow$ 轮到 $S'$ 的一方必败"。当前玩家**主动走到** $S'$，于是"轮到 $S'$ 的一方"变成**对手**，对手必败 ⟹ 当前玩家必胜。✓

  **(ii) 若 $S$ 是 P 位置：** 按定义 $S$ 的**每一个**合法后继 $S'$ 都是 N 位置。无论当前玩家怎么走，都只能走到某个 $S'$，$\Sigma(S')<\Sigma$，由归纳假设"$S'$ 是 N 位置 $\Rightarrow$ 轮到 $S'$ 的一方必胜"。"轮到 $S'$ 的一方"是**对手**，对手必胜 ⟹ 当前玩家必败。✓

- 综合 (i)(ii) 完成归纳。$\blacksquare$

所以：**先手必胜 ⟺ 初始局面是 N 位置；先手必败 ⟺ 初始局面是 P 位置。** 现在只剩一件事：怎么**快速判定**一个局面是 P 还是 N。直接套递归定义要枚举指数级的后继，必须找结构。

### 步骤 4：找结构 —— 异或和（nim-sum）是 P/N 的分界线

对局面 $S=(n_1,\dots,n_k)$ 定义 **nim-sum**：
$$X := n_1\oplus n_2\oplus\cdots\oplus n_k$$
其中 $\oplus$ 是**按位异或**（binary XOR）。下面证明：**$S$ 是 P 位置 ⟺ $X=0$**。这是 Nim 的核心定理，必须分两个方向、每一步都写清楚。

> 下面反复用到的一个二进制定理先单独证明（它是 Nim 定理的关键引理）。

**引理 1（"能降到 0"的存在性）.** 给定一组非负整数 $n_1,\dots,n_k$，设 $X=n_1\oplus\cdots\oplus n_k\ne 0$。则**存在**某个下标 $i$，使得把 $n_i$ 改写成 $n_i' := n_i\oplus X$（满足 $0\le n_i'<n_i$），就能让新的异或和变成 $0$。

*证明.* 令 $b$ 为 $X$ 的**最高置位位**（即 $b=\lfloor\log_2 X\rfloor$）。因为 $X$ 在第 $b$ 位为 1，而 $X$ 是所有 $n_i$ 逐位异或的结果，所以在第 $b$ 位上，**奇数个** $n_i$ 为 1。于是至少存在一个 $i_0$ 使 $n_{i_0}$ 的第 $b$ 位为 1。

对这个 $i_0$ 计算 $n_{i_0}' = n_{i_0}\oplus X$：
- 在第 $b$ 位：$n_{i_0}$ 此处为 1，$X$ 此处为 1，异或后变 **0**。
- 在任意 $>b$ 的位：$X$ 这些位全为 0（$b$ 是 $X$ 最高置位），异或不变，所以 $n_{i_0}'$ 的高位与 $n_{i_0}$ 相同。
- 在 $<b$ 的位：由 $n_{i_0}\oplus X$ 决定，无约束。

因此 $n_{i_0}'$ 与 $n_{i_0}$ **在所有 $\ge b$ 的位上**：高位相同、第 $b$ 位从 1 变 0。由"高位全相同、首个不同的位 $b$ 上 $n_{i_0}'$ 更小"，得 $n_{i_0}' < n_{i_0}$。且 $n_{i_0}'\ge 0$（它是个二进制数）。

验证新异或和：
$$n_1\oplus\cdots\oplus n_{i_0}'\oplus\cdots\oplus n_k
= \underbrace{(n_1\oplus\cdots\oplus n_k)}_{X}\oplus n_{i_0}\oplus(n_{i_0}\oplus X)
= X\oplus n_{i_0}\oplus n_{i_0}\oplus X = 0.$$
（用了异或的结合律、交换律与 $a\oplus a=0$、$a\oplus 0=a$。）

所以确实存在这样的 $i_0$。$\blacksquare$

> 注意：引理 1 里 $n_{i_0}'$ 由 $n_{i_0}\oplus X$ **唯一确定**——一旦选定堆 $i_0$，要降到异或和 0，只能取到那个特定值。这点对后面的字典序最小**非常关键**。

**定理 2（Nim 判定）.** 局面 $S$ 是 **P 位置** ⟺ $X=0$；是 **N 位置** ⟺ $X\ne 0$。

*证明.*

- **方向 A：$X=0 \Rightarrow S$ 是 P 位置。**（要证：$S$ 的每个合法后继 $S'$ 都是 N 位置，即每个 $S'$ 的异或和 $\ne 0$。）
  设从 $S$ 走到 $S'$，操作只改了第 $i$ 堆：$n_i\to n_i'$，$0\le n_i'<n_i$，其余不变。$S'$ 的异或和为
  $$X' = n_1\oplus\cdots\oplus n_i'\oplus\cdots\oplus n_k = (n_1\oplus\cdots\oplus n_k)\oplus n_i\oplus n_i' = X\oplus n_i\oplus n_i' = n_i\oplus n_i'.$$
  若 $X'=0$，则 $n_i\oplus n_i'=0$，即 $n_i=n_i'$，与"$n_i'<n_i$"矛盾。故 $X'\ne 0$。
  也就是说：**$S$（$X=0$）的任何一个合法后继 $S'$ 都满足 $X'\ne 0$**。
  但"后继 $X'\ne0$"本身还没说是 N；这里用方向 B 的结论（下面会证"$X'\ne0\Rightarrow$ N 位置"）。为避免循环，我们改成：方向 A 与方向 B **互为对偶**，用同一个论证骨架。下面先证方向 B（它独立、自含），再用它补全方向 A。

  *（先保留，见下）*

- **方向 B：$X\ne 0 \Rightarrow S$ 是 N 位置。**（要证：$S$ 存在一个合法后继 $S'$ 是 P 位置，即存在 $S'$ 满足 $X'=0$。）
  由**引理 1**，存在下标 $i$，把 $n_i$ 改为 $n_i'=n_i\oplus X$，满足 $0\le n_i'<n_i$ 且新异或和 $X'=0$。"$0\le n_i'<n_i$"说明这是一次**合法操作**（从第 $i$ 堆取走 $n_i-n_i'$ 根）。于是 $S$ 存在一个异或和为 0 的合法后继 $S'$。结合方向 A（"$X'=0\Rightarrow S'$ 是 P"）即得 $S'$ 是 P 位置，故 $S$ 是 N 位置。✓

- **补全方向 A**（现在可依赖方向 B 已证）：$X=0$ 时，任取合法后继 $S'$，其 $X'=n_i\oplus n_i'\ne 0$（上面已证）。由方向 B，"$X'\ne0\Rightarrow S'$ 是 N 位置"。所以 $S$ 的**每个**合法后继都是 N 位置 ⟹ 按 P 的定义，$S$ 是 P 位置。✓

- 两个方向都证毕，定理 2 成立。$\blacksquare$

**一句话总结：**
$$\boxed{\text{先手必胜} \iff X=\bigoplus_{i=1}^{k} n_i \ne 0,\qquad \text{先手必败} \iff X=0}$$

这立刻解释了题目例子：
- $k=2,n=(2,2)$：$2\oplus2=0$，先手必败 → 先手（若 A 先取）必败，A 后取则胜，和题目"A 后取赢"一致。
- $k=3,n=(1,2,3)$：$1\oplus2\oplus3=0$，先手必败 → 所以 A 让 P 先手，A 后手必胜，与题目一致。

### 步骤 5：先手必胜时，如何构造"第一次该怎么取"，并且取到字典序最小

若 $X\ne 0$，先手必赢，需要输出第一次走法。由引理 1，走法的形式被**完全确定**为：

> 选一个堆 $b$，把它改成 $n_b' := n_b \oplus X$，从该堆取走 $a := n_b - n_b' = n_b - (n_b\oplus X)$ 根。

**为什么走法必须长这样？**（证明，避免"显然"。）由定理 2 的方向 B 的逆用：先手要赢，必须把局面变成**一个 P 位置**（异或和 0），否则把 N 位置交给对手，对手按定理 2 又可赢，先手必败。把异或和从 $X$ 变成 $0$，只能改某一堆；设改第 $b$ 堆 $n_b\to n_b'$，则新异或和 $=n_b\oplus n_b'$（同方向 A 的代数），要 $=0$ 必须 $n_b'=n_b\oplus X$，且必须 $n_b'<n_b$（合法）。所以：**能赢的第一步，必然且只能是"选某堆 $b$，取 $a=n_b-(n_b\oplus X)$ 根"**。引理 1 还保证了**至少存在一个**这样的 $b$（使 $n_b'<n_b$）。

**哪些堆 $b$ 是合法的？** 条件：$n_b\oplus X < n_b$（这样 $a>0$ 才是真的"取走"）。

- 由引理 1 的论证：$n_b$ 的**第 $b$（$X$ 的最高置位）位**若为 1，则 $n_b\oplus X$ 在该位由 1 变 0、高位不变 ⟹ $n_b\oplus X<n_b$，**合法**。
- 反之若 $n_b$ 的第 $b$ 位为 0，则 $n_b\oplus X$ 在该位由 0 变 1、高位不变 ⟹ $n_b\oplus X>n_b$，非法（相当于"负取"）。

**引理 2（合法堆的刻画）.** 堆 $b$ 可以作为"降低异或和到 0"的目标堆 ⟺ $n_b$ 的第 $h=\lfloor\log_2 X\rfloor$ 位为 1（即 $n_b\ \&\ (1<<h)\ne 0$）。

*证明.* 上面的两句分别给出了充分性（第 $h$ 位为 1 ⟹ 合法）与必要性（第 $h$ 位为 0 ⟹ $n_b\oplus X>n_b$ 非法）。两者合起来就是充要条件。$\blacksquare$

**字典序最小怎么选？** 题目要求：先让**堆号 $b$ 最小**，再让取的数量 $a$ 最小。

- 对**固定**的堆 $b$，$a=n_b-(n_b\oplus X)$ 由 $n_b$ 和 $X$ **唯一确定**（一个 $b$ 只有一个能赢的取法，见上）。所以"a 最小"在"$b$ 固定"后没有自由度。
- 因此字典序最小 ⟺ **选满足引理 2（合法）的最小堆号 $b$**；$a$ 随之确定。

**结论（构造算法）：**
1. 算 $X=\oplus_i n_i$。若 $X=0$：输出 `lose`。
2. 否则从堆 $1$ 到堆 $k$ 依次扫描，找**第一个**满足"$n_b$ 的第 $h$ 位为 1"的堆 $b$（$h=\lfloor\log_2 X\rfloor$）。
3. 令 $a=n_b-(n_b\oplus X)$，$n_b\leftarrow n_b\oplus X$。输出第一行 `a b`，第二行输出修改后的全部 $n_i$。

*正确性*：第 2 步扫到第一个合法堆即为最小合法 $b$（扫描顺序保证）；第 3 步由定理 2 + 引理 1 + 引理 2 保证该步合法且把异或和变为 0（交 P 位置给对手），故先手必胜。$\blacksquare$

> 复杂度上：算 $X$ 是 $O(k)$；找第一个合法堆也是 $O(k)$（顺带记录 $h$ 位）。$n_i\le 10^9<2^{30}$，$X<2^{30}$，用 32 位 `int` 存 $n_i$ 和 $X$ 足够（$n_i\oplus X<2^{30}$，$a\le n_i\le10^9$，无溢出）。总时间 $O(k)$，空间 $O(k)$ 存数组（用于输出修改后状态）。$k\le5\times10^5$，轻松通过。

## Part 3 — 模式总结（按真实思考顺序，一行一个标签）

- **探索机制** — 一次操作 = 把某一堆改成更小的非负数；"取最后一根赢" ⟺ 轮到 $(0,\dots,0)$ 者输。
- **解简化版（k=1）** — 单堆：0 是 P，>0 是 N，引出"轮到当前玩家"的 P/N 约定。
- **经典技术：SG / P-N 递归判定** — 用"存在 P 后继⟹N；全为 N 后继⟹P"递归定义胜负，并严格证明它等价于最优博弈胜负（命题 1）。
- **找结构** — 定义 nim-sum $X=\oplus n_i$，猜想它是 P/N 分界线。
- **经典技术：位运算 + 二进制定理** — 用"$X$ 最高置位 $h$、某堆第 $h$ 位为 1 则 $n_i\oplus X<n_i$"（引理 1）证明定理 2：$X=0\iff$ P。
- **逆用结构还原走法** — 赢的第一步必为"选堆 $b$，取 $n_b-(n_b\oplus X)$"，合法 ⟺ 该堆第 $h$ 位为 1（引理 2）。
- **字典序最小化** — 固定 $b$ 后 $a$ 唯一确定 ⟹ 最小合法堆号 $b$ 即字典序最小解。

## Part 4 — 真正的解法（代码做什么）

### 符号表（记号速查）

| 符号 | 含义 | 初始化 / 类型 |
|---|---|---|
| `k` | 堆数 | 输入，`int`，$\le5\times10^5$ |
| `a[i]`（`i=0..k-1`） | 第 $i+1$ 堆的火柴数 | 输入，`int`，$0\le a[i]\le10^9$（0-based 内部下标） |
| `x` | 当前异或和 $X=\oplus_i a[i]$ | `int`，初值 `0`，逐堆 `x^=a[i]` |
| `h` | $X$ 的最高置位下标 $h=\lfloor\log_2 X\rfloor$ | 由 `x` 求出（`31-__builtin_clz(x)`），仅当 $X\ne0$ 使用 |
| `b` | 选中的堆号（1-based 输出值） | 找到的第一个合法堆，`int` |
| `take` | 从第 $b$ 堆取走的数量 $a=n_b-(n_b\oplus X)$ | `int`，`take=a[b0]-(a[b0]^x)`（$b_0=b-1$ 为 0-based 下标） |
| `mask` | 第 $h$ 位的掩码 `1<<h` | `int`，用于判合法 |

*记忆点*：`x`=xor sum，`h`=X 的最高位，`mask`=该位的掩码，`b`=要动的堆（1-based），`take`=取走几根。

### 算法步骤

1. 读入 $k$ 与 $a[0..k-1]$；同时计算 $x=\oplus_{i=0}^{k-1} a[i]$。
2. 若 $x==0$：输出 `lose\n`，结束。
3. 否则：
   1. 求 $h=31-\_\text{builtin}\_\text{clz}(x)$（$x$ 的最高置位），`mask=1<<h`。
   2. 从 `i=0` 到 `k-1` 扫描，找**第一个**满足 `a[i]&mask`（即第 $h$ 位为 1）的下标，记 `b0=i`，堆号 `b=i+1`。（由引理 2，第一个这样的堆就是最小合法堆，保证字典序最小。）
   3. `take = a[b0] - (a[b0]^x)`；`a[b0] ^= x`（等价于 `a[b0] = a[b0]^x`，把该堆改为 $n_b\oplus X$）。
   4. 第一行输出 `take b`；第二行输出 $a[0..k-1]$（空格分隔）。

### 正确性

- 第 2 步：$x=0\iff$ P 位置 ⟹ 先手必败（定理 2 方向 A）。✓
- 第 3.2 步：找到的 $b_0$ 是"第 $h$ 位为 1"的最小下标，由引理 2 它合法（$a[b_0]^x<a[b_0]$，故 `take>0`），且是最小合法堆号。✓
- 第 3.3 步：改后异或和 $=x\oplus a[b_0]\oplus(a[b_0]^x)=0$，把 P 位置交给对手，先手必胜（定理 2 + 引理 1）。✓

### 复杂度

- 时间：$O(k)$（一次算异或 + 一次扫描 + 一次输出）。
- 空间：$O(k)$（存数组以输出修改后状态）。
- 数值范围：$n_i,X<2^{30}$，`int` 足够，无溢出。

### 验证状态

- 本解法按题目要求**仅书写、未编译运行**。
- 手工样例核对：
  - `k=2, (2,2)` → $2\oplus2=0$ → 输出 `lose`。✓（与题例"A 先取必败"一致）
  - `k=3, (1,2,3)` → $1\oplus2\oplus3=0$ → 输出 `lose`。✓
  - `k=3, (1,2,4)` → $x=1\oplus2\oplus4=7$，$h=2$，`mask=4`；扫描：`a[0]=1` 第 2 位 0，`a[1]=2` 第 2 位 0，`a[2]=4` 第 2 位 1 ⟹ `b=3`，`take=4-(4^7)=4-3=1`，`a[2]=3`。输出：
    ```
    1 3
    1 2 3
    ```
    改后 $1\oplus2\oplus3=0$，正确，且是最小合法堆（第 1、2 堆第 2 位均为 0 不合法）。✓

## Part 5 — 示例 C++ 代码（Louis Li 风格）

```cpp
//
// P1247 取火柴游戏
// https://www.luogu.com.cn/problem/P1247
// Nim: xor-sum == 0 -> lose; else pick smallest pile with the top bit of X set.
//

#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{500005};            // k <= 5e5, +5 slack

int k, a[mxn], x;                     // a[i] = pile i (0-based), x = xor-sum

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>k;
	for(int i=0;i<k;++i)
	{
		cin>>a[i];
		x^=a[i];
	}
	if(x==0)                          // P-position: first player loses
	{
		cout<<"lose\n";
		return 0;
	}
	int h=31-__builtin_clz(x);        // highest set bit of X
	int mask=1<<h;                    // only piles with this bit set can reduce X to 0
	int b0=-1;
	for(int i=0;i<k;++i)
	{
		if(a[i]&mask)                 // first such pile = smallest legal b (lexicographic min)
		{
			b0=i;
			break;
		}
	}
	int take=a[b0]-(a[b0]^x);         // amount to remove from pile b0
	a[b0]^=x;                         // new pile value = n_b xor X, makes xor-sum 0
	cout<<take<<' '<<b0+1<<'\n';      // output "a b" with b as 1-based
	for(int i=0;i<k;++i)
		cout<<a[i]<<(i+1==k?'\n':' ');
	return 0;
}
```

*实现要点（对应风格规范）：*
- 只用 `#include<bits/stdc++.h>`，`using namespace std;` 紧跟其后。
- 全局静态数组 `a[mxn]`，尺寸 = 约束 $5\times10^5$ 的 +5 松弛。
- `cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);` 固定顺序；换行用 `'\n'`。
- 内部 0-based（`a[b0]`），输出堆号时 `b0+1` 恢复 1-based。
- 单趟扫描顺带算异或，找最小合法堆时 `break`，$O(k)$。
