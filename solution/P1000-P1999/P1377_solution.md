# P1377 [TJOI2011] 树的序

> 标签：笛卡尔树 / 二叉查找树 / 拓扑序贪心 · 难度：省选/NOI-

## 1. 重新读题

**问题重述（简化版）**

给定一个长度 $n$ 的序列 $k_1..k_n$，它是 $1..n$ 的一个**排列**（题面明确："简单起见，$k_1\sim k_n$ 为 $1$ 到 $n$ 的排列"）。按题面两条规则把它逐键插入一棵二叉查找树（BST）：空树插 $k$ 得单结点；非空树插 $k$ 时，$k$ 小于根则插进左子树，**否则**（$k\ge$ 根）插进右子树。称这个插入序列为该树的一棵"生成序列"。要求：在**所有**能生成同一棵 BST 的长度为 $n$ 的生成序列中，输出**字典序最小**者（逐位置比较键值）。

以题面为准逐条核对容易走偏的口径：

1. **不是计数题**：题面只求输出最小序列本身，不要求"多少种插入顺序"，也**没有任何取模**（对比 P1358 那类计数+模 10007 的题，这里 `qpow/fac/ifac` 一概不需要）。计数公式只作为 2.1 节双射的副产品在第 2.2 节顺带说明。
2. **重复键口径**：题面规则 2 写"否则插右子树"，即 $k$ 等于根时也走右边——这是为"将来可能有重复键"补的全定义；但数据保证是 $1..n$ 的排列，**任意两键互异**，等号分支永不触发。下文所有证明只用到"左子树键 $<$ 根 $\le$ 右子树键"，即使允许重复（相等走右）结论仍成立，2.5 节末尾附一句说明。
3. **"先序序列"的角色**：题面本身没提先序；是推导（引理 1+2+3）证明"最小生成序列恰好是这棵树的**先序遍历**（根、左、右）"，即输出序列 = 树形先序序。这是本题的核心结论，必须证明而不是猜。

**数据范围（提示复杂度）**：$n\le 10^5$（20%：$n\le10$；50%：$n\le100$）。$n\le10$ 的子任务暗示可以"枚举全部 $n!$ 个排列建树对照"；$10^5$ 排除了朴素逐个下插（最坏链状 $O(n^2)$，例如插入序列本身就是一条链时深度 $O(n)$）。

## 2. 思维链（Chain-of-thought）

### 2.1 先刻画"哪些序列生成同一棵树"：结点一旦落下就不动

**引理 1（位置不动性）** 按插入规则建树，任何键一旦放到某个空位，此后它在树中的父子位置永远不变；后续插入只往空指针上挂新叶子。
**证明**：对插入过程逐步归纳。规则 2 的每次插入只沿比较结果下降，最后写入**一个为空的子指针**，不修改任何已存在结点的两条子指针。因此已放下的结点位置从不改变。$\blacksquare$

由此立刻得到必要方向：

**引理 2（生成序列必与祖先序相容）** 若 $s$ 生成树 $T$，则 $T$ 中每个结点的父亲在 $s$ 中排在它前面。
**证明**：设 $x$ 在 $T$ 中的父亲是 $y$。由引理 1，$x$ 被放下时的位置就是它在 $T$ 中的最终位置，该位置是 $y$ 的一个孩子，故放下 $x$ 的瞬间 $y$ 必须已经在树上占据父亲位（否则 $x$ 挂不到 $y$ 下）——即 $y$ 在 $s$ 中早于 $x$。$\blacksquare$

反过来：

**引理 3（祖先序相容的序列必生成 $T$）** 设 $T$ 是一棵 BST（键互异），序列 $s$ 是结点集上满足"父亲先于孩子"的一个排列，则按插入规则依次插入 $s$ 得到的树恰为 $T$。
**证明**：对已插入集合归纳为 $S$（$s$ 的前缀）。**断言**：当前树 = $T$ 限制到 $S$（每个 $S$ 结点保持它在 $T$ 中的父子关系）。基础 $S=\{根\}$ 显然（$s$ 的首元必须是 $T$ 的根，它是唯一祖先为空的结点）。设断言对前缀 $S$ 成立，下一个插入 $x$，记 $T$ 中根到 $x$ 的祖先链 $v_0,\dots,v_d$（$v_d$ 为 $x$ 的父亲）。祖先序相容保证 $v_0..v_d\in S$ 且都早于 $x$。下降过程：$v_0=k_1$ 是 $T$ 的根 = 当前树的根；在 $v_i$ 处比较 $x$ 与 $v_i$：因 $x$ 在 $T$ 中位于 $v_i$ 的左（右）子树，BST 性质给出 $x<v_i$（$x>v_i$），比较结果恰好把下降带到 $v_{i+1}$，而按断言 $v_{i+1}$ 正挂在 $v_i$ 该侧，故路径沿祖先链一路走到 $v_d$。最后看 $v_d$ 朝 $x$ 一侧的子指针：在 $T$ 中这个位置只属于 $x$（位置由父子关系唯一决定），$x\notin S$，按断言该指针为空。于是 $x$ 被挂到**正确位置**，断言对 $S\cup\{x\}$ 保持。归纳到 $|S|=n$ 即得整棵 $T$。$\blacksquare$

**命题（双射刻画）** $s$ 生成 $T$ $\iff$ $s$ 是树偏序"$u\prec v:\Leftrightarrow u$ 是 $v$ 的祖先"的一个**拓扑序**（线性扩张）。这是两个方向引理 2、3 的合成，它把"哪些插入顺序产生同一棵树"完全说清：恰是保持父先于子的全部排列。$\blacksquare$

### 2.2 副产品：计数口径（本题不需要，仅展示双射的威力）

由双射，生成序列数 = 树偏序的拓扑序个数 $e(T)$。删去根后左右子树结点间无先后约束，故 $e(T)=\binom{n_L+n_R}{n_L}e(T_L)e(T_R)$：双射是"从 $n_L+n_R$ 个空位中选出左子树占的位（交错模式）$\times$ 左子树内部拓扑序 $\times$ 右子树内部拓扑序"，任一拓扑序限制到子树仍合法且可唯一分解（交错模式 = 哪些位置被左结点占据）。本题**不要求计数、无取模**，此式只在验证时用来数"合法序列的个数"作对照。

### 2.3 字典序最小 = 贪心取"当前可输出的最小键"

把输出过程想成逐步生成拓扑序：第 $i$ 步可选的恰是"父亲已输出、自己未输出"的结点集合（可用集）。

**引理 4（贪心最优性，交换论证）** 反复输出可用集中键值最小者，得到字典序最小的拓扑序。
**证明**：反设某最优 $s$ 在首个分歧步没取可用最小元 $x$ 而取了 $y>x$，且 $x$ 在 $s$ 中位于第 $j$ 步。把 $x$ 提前到分歧步、原第 $i$ 到 $j-1$ 位整体后移一格：$x$ 的父亲早已输出（$x$ 可用），提前不破坏任何约束；被后移的每个结点其祖先本就在更前（原序合法、块内相对次序不变）；$y$ 挪到第 $j$ 位仍合法（$y$ 第 $i$ 步就可用）。得新合法序字典序更小，矛盾。$\blacksquare$

### 2.4 BST 的特殊性：贪心输出恰好是先序遍历

**引理 5（值域分离）** $T$ 中结点 $u$ 的左子树所有键 $<u$，右子树所有键 $>u$（对"相等走右"的重复键口径，右子树为 $\ge u$，证明不变）。
**证明**：任何在 $u$ 左（右）子树中的结点，其下降路径在 $u$ 处选择向左（右），当且仅当键 $<u$（否则 $\ge u$）。$\blacksquare$

**引理 6（贪心 = 先序）** 对 BST 用引理 4 的贪心，输出序列恰为先序遍历（根、左、右）。
**证明**：加强为归纳命题：*贪心刚输出结点 $u$ 之后，在"输出完 $u$ 的整个子树"之前不会输出任何子树外的结点，且子树内部的选序 = 以 $u$ 为根的独立贪心 = 先序$(u)$*。
全树根 $r$ 是偏序唯一极小元，第 1 步必为 $r$，命题对 $r$ 的第一半给出"先做完左子树再做右子树"。设命题对更小的子树成立，看刚输出 $u$ 之后的局面，可用集分成两块：**子树内可用**（$u$ 的孩子与更深的"最高未输出结点"，其父已输出，故子树未完时该块非空）与**外部可用**。外部可用元只可能是"某已输出祖先 $a$ 的未开始处理的兄弟子树"里的结点（每个已输出结点对可用集的贡献只有它的孩子，沿输出链展开）；兄弟分两种：

- **左兄弟子树**（通往 $u$ 的路在 $a$ 处向右）：其键全 $<a$，而 $u$ 的子树键全 $\ge a$（引理 5：$a$ 右子树 $\ge a$）。此情形**不可能出现**：$a$ 被输出的那一刻，其左、右孩子同时可用（缺孩子则少一路，结论更强），左孩子键 $<a\le$ 右孩子键，由命题对 $a$ 的左子树成立，贪心必先输出整个左子树才会进入右子树；而 $u$ 在右子树里，故 $u$ 被输出时该左兄弟子树早已完毕、不再贡献可用元。
- **右兄弟子树**（通往 $u$ 的路在 $a$ 处向左）：其键全 $\ge a$，而 $u$ 的子树键全 $<a$（$u$ 在 $a$ 的左子树内）。

于是子树未完时，子树内可用元的键严格小于一切外部可用元（严格号来自"左子树键 $<a$"这一侧的严格性），贪心下一步必选子树内。且外部元从不被选中，其存在不改变"子树内谁最小"，所以子树内部的输出序正是"把 $u$ 当作独立小树的贪心"，由归纳假设 $=$ 先序$(u)$；做完后按同一论证进入下一个兄弟（即 $u$ 的右侧），恰合先序的"根—左—右"。对 $r$ 展开归纳即得全局输出 $=$ 先序。$\blacksquare$

> 重复键备注（题面 $k\ge$ 根走右的口径）：引理 5 的严格号对左子树仍成立（在 $u$ 处向左要求键 $<u$），右子树键 $\ge u$，"左 $<$ 根 $\le$ 右"的分离不变，引理 6 逐字照用；只是本题数据是排列，这些都不会真的触发。

**于是整题化为两步**：① 由生成序列重建树；② 输出先序。（若不想证引理 6，也可以直接用优先队列跑引理 4 的贪心：$O(n\log n)$ 同样过，输出序列与先序逐位相同——先序版省一次堆、并且说清了"树的序"这个题名的含义。）

### 2.5 重建树：朴素 $O(n^2)$ → "父亲 = 前后继中后插入者" $O(n\log n)$

按定义逐个下插：插入序列本身可能是链（如 $1,2,\dots,n$ 每次沿右链到底），总代价 $\sum$ 深度 $=O(n^2)$，$n=10^5$ 不可接受。

**引理 7（落点判定）** 把 $x$ 插入已含集合 $S$ 的 BST：设 $p=\max\{a\in S:a<x\}$（前驱）、$q=\min\{a\in S:a>x\}$（后继）。则 $x$ 的父亲 $u\in\{p,q\}$；$u=q$ 时 $x$ 挂左孩子，$u=p$ 时挂右孩子；$p,q$ 恰缺一个时取存在的那个；$S=\varnothing$ 时 $x$ 是根。
**证明**：$x$ 只会被写入某个空子指针，落下即成叶子（规则 2 + 引理 1）。设 $x$ 挂在 $u$ 的**左**孩子：此刻树的中序遍历恰是 $S\cup\{x\}$ 的升序（BST 中序=键排序，对刚建成的树成立），而 $x$ 是无孩子的叶子，中序里紧跟在 $x$ 后面的结点就是它的父亲 $u$（左孩子 $x$ 之后第一个访问 $u$），故 $u$ 是 $S$ 中 $>x$ 的最小元，即 $u=q$。挂在右孩子时对称地 $u=p$。$q$ 不存在（$x$ 大于一切已有键）：下降在每个结点都走"否则"分支向右，终点即右链最下端——中序最后一个结点 $=\max S=p$；$p$ 不存在对称（左链最左 $=\min S=q$）。$\blacksquare$

**引理 8（同前后继对中，后插入者是父亲）** 设 $p,q$ 都在 $S$ 中，$t(a)$ 为键 $a$ 的插入时刻（题面下标）。若 $t(p)>t(q)$ 则 $u=p$（$x$ 挂 $p$ 右孩子）；若 $t(q)>t(p)$ 则 $u=q$（左孩子）。
**证明**：记"当前树"为前缀已建成的树。全程只用两个已证事实：前缀树 $=$ 最终树 $T$ 限制到当前前缀（引理 2/3），以及祖先必早于后代插入（引理 2）。注意 $(p,q)\cap S=\varnothing$（前后继定义）。

1. **$p,q$ 在当前树中互为祖先后代。** 反设都不是：当前树中 $a=\mathrm{LCA}(p,q)$ 存在且 $a\ne p,q$，$p,q$ 分居 $a$ 两侧，则 $p<a<q$（$a$ 左侧的键全 $<a$、右侧全 $\ge a$，两侧对称），$a\in(p,q)\cap S=\varnothing$，矛盾。
2. **设 $q$ 是祖先（此时 $p<q$，$p$ 在 $q$ 的左子树内）。** 下降通往 $p$ 的链 $q=v_0,v_1,\dots,v_m=p$ 上每个中间 $v_j$ 都满足 $v_j<p$：否则 $v_j>p$（键互异），而 $v_j$ 在 $q$ 左子树内故 $v_j<q$，得 $v_j\in(p,q)\cap S=\varnothing$，矛盾。于是 $x$ 的下降与 $p$ 的下降逐点同向：$q$ 之上的祖先 $z$ 是 $q$ 的祖先故 $z\notin(p,q)$（否则同样矛盾；$z=p$ 也不行，因 $p$ 是 $q$ 的后代），从而 $z<p<x$（两者比较都向右）或 $z>q>x$（都向左）；链上中间 $v_j<p<x$（都向右）；在 $q$ 处 $x<q,\;p<q$（都向左）。因此 $x$ 的下降沿同一根链走到 $p$。到 $p$ 后 $x>p$ 向右；而 $p$ 的右子树（若有点 $w$）满足 $p<w<q$（$p$ 整棵子树在 $q$ 左子树内，键 $<q$），即 $w\in(p,q)\cap S=\varnothing$，右指针为空，故 $x=p.\mathit{rg}$，$u=p$。
3. **祖先是谁。** 引理 2 给"祖先先插入"：$t(p)>t(q)\Rightarrow p$ 不是祖先 $\Rightarrow$ 第 2 步情形发生，$u=p$；$t(q)>t(p)\Rightarrow$ $p$ 是祖先，对称地（$q$ 在 $p$ 右子树内，链上中间点全 $>q$，否则落回 $(p,q)$；$x$ 沿链到 $q$ 后向左，$q$ 的左子树 $\subseteq(p,q)$ 为空）得 $x=q.\mathit{lf}$，$u=q$。$\blacksquare$

> 反例自查（说明为何不能偷懒说"$p,q$ 必直接父子"）：插入 $10,3,6,8$ 后，$p=8,q=10$ 是 $x=9$ 的前后继，但 $10.\mathit{lf}=3\ne8$（中间隔着 $3,6$，都 $<p$，正是第 2 步论证的形态）。按引理 8：$t(8)>t(10)\Rightarrow u=8$，$9$ 挂 $8$ 右孩子；朴素下降 $9<10\to3;\,9>3\to6;\,9>6\to8;\,9>8\to$ 空 ✓ 一致。

（重复键备注：引理 7、8 的区间论证对"相等走右"仍成立——$p$ 是严格小于 $x$ 的最大元、后继为严格大于，左右分支条件 $x<v$ / $x\ge v$ 与区间分离一致；但本题数据是排列，无需担心。）

**实现**：`std::set<int>` 维护已插入键，`tn[x]` 记录插入时刻，`lower_bound` 一次求 $p,q$，$O(\log n)$ 定父挂边，总 $O(n\log n)$。先序遍历用**显式栈**输出（链状树递归深度 $O(n)$，$10^5$ 层递归在 Windows/默认栈上有爆栈风险，迭代版稳）。
**更优但非必须**：该构造就是键序为 $1..n$、堆序为 $t(\cdot)$ 的**笛卡尔树**，单调栈 $O(n)$；题目标签"笛卡尔树"即指此。为可读与已证引理对齐，代码用 set 版。

### 2.6 复杂度与溢出预算

- 时间：建树 $n$ 次 `lower_bound/insert`，$O(n\log n)$；先序 $O(n)$；总 $O(n\log n)\approx 10^5\times 17$ 次操作。
- 空间：`tn/lf/rg/stk/set` 共 $O(n)$，全局 `int` 数组 $4\times10^5$ 个约 $1.6$ MB，`set` 结点约 $40$ B$\times n=4$ MB 量级，内存充裕。
- 溢出：全程只有比较与赋值，**无任何乘法/累加**，键值 $\le 10^5$ 在 `int` 内绰绰有余；输出总量 $\le 6\times10^5$ 字符，`sync_with_stdio(false)` 下无压力。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 引理 1"结点一旦落下就不动"：一切刻画的起点，父子先后关系由此双向锁死。
- **reduce to easier problem** — 引理 2+3 合成双射：生成序列集合 = 树偏序的拓扑序集合（计数副产品即多项式交错公式，本题不用）。
- **classic problem solution（拓扑序字典序贪心 + 交换论证）** — 引理 4：每步取可用最小元。
- **subtask check** — $n\le10$ 子任务提示可枚举全排列暴力建树对照；值域分离（引理 5）把"贪心"化简成"先序遍历"（引理 6）。
- **classic problem solution（前后继定父 + set）** — 引理 7+8：$O(n\log n)$ 重建，绕开链状 $O(n^2)$；这正是笛卡尔树构造（标签所指），单调栈可再降到 $O(n)$。
- **engineering pitfall** — 先序改显式栈，防 $O(n)$ 深递归爆栈。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n` | 结点数（键值域 $1..n$ 的排列） | `int`，输入 | $\le10^5$ |
| `tn[x]` | 键 $x$ 的插入时刻（题面序列下标，1 起） | `int tn[mxn]`，读入时 `tn[x]=i` | 越大越"晚" |
| `S` | `set<int>`：已插入的键集合 | 空 | 求前驱后继 |
| `p`,`q` | $x$ 的前驱 `*prev(it)` 与后继 `*it`（不存在记 0） | `int` | 0 = 不存在（键 $\ge1$） |
| `par` | $x$ 的父亲 = `p`,`q` 中 `tn` 较大者（缺元取存者） | `int` | 引理 8 |
| `lf[u]`,`rg[u]` | 树左、右孩子 | `int` 全局，默认 0 = 空 | 静态数组免清零 |
| `rt` | 根（第一个插入的键） | `int` | `S` 为空时确定 |
| `stk`,`tp` | 先序显式栈与栈顶指针 | 全局 | 先压右再压左 |

### 4.2 算法步骤

1. 读 $n$；按 $i=1..n$ 读 $x$：`tn[x]=i`；`S.lower_bound(x)` 得 $q$、前驱得 $p$；按引理 7/8 定 `par` 与左右侧，挂边（`lf[par]=x` 或 `rg[par]=x`）；`S.insert(x)`；首元记为 `rt`。
2. 显式栈先序：`stk[tp++]=rt`；弹顶输出，先压 `rg` 再压 `lf`（保证左先出）。
3. 空格分隔、行尾 `'\n'`。

**复杂度**：$O(n\log n)$ 时间、$O(n)$ 空间。**验证状态**：题面无官方样例，无法对标；见 4.3 手工枚举对照。

## 5. 示例代码（C++）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};            // n<=1e5 +5

int n,rt,tn[mxn],lf[mxn],rg[mxn],stk[mxn],tp;
set<int>S;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)
	{
		int x;
		cin>>x;
		tn[x]=i;                       // 插入时刻（题面下标，1 起）
		auto it=S.lower_bound(x);      // q=*it（后继）
		int q=0,p=0;
		if(it!=S.end())
			q=*it;
		if(it!=S.begin())
			p=*prev(it);               // 前驱
		if(S.empty())
		{
			rt=x;
		}
		else
		{
			int par=(!p||!q)?(p?p:q):((tn[p]>tn[q])?p:q);   // 缺元取存者；否则后插入者
			if(par==q)
				lf[par]=x;             // x<q：挂左
			else
				rg[par]=x;             // x>p：挂右
		}
		S.insert(x);
	}

	stk[tp++]=rt;                      // 显式栈先序，防链状 O(n) 递归爆栈
	for(bool first=true;tp;)
	{
		int u=stk[--tp];
		if(!first)
			cout<<' ';
		first=false;
		cout<<u;
		if(rg[u])
			stk[tp++]=rg[u];
		if(lf[u])
			stk[tp++]=lf[u];           // 左后压 => 左先出
	}
	cout<<'\n';
	return 0;
}
```

**$n\le3$ 全枚举**（每个排列朴素建树 → 按树形分组 → 拓扑序数 $e(T)$ 用 2.2 闭式与穷举双向对照）：

| 给定排列 | 树形 | 该树全部生成序列（穷举 6 个排列所得） | $e(T)$ | 答案=先序 |
|---|---|---|---|---|
| `1 2 3` | 右链 1→2→3 | 仅 [1,2,3] | 1 | `1 2 3` ✓ |
| `1 3 2` | 1 右 3，3 左 2 | 仅 [1,3,2] | 1 | `1 3 2` ✓ |
| `2 1 3` / `2 3 1` | 根 2 双叶 | [2,1,3]、[2,3,1] | $\binom{2}{1}=2$ | `2 1 3` ✓ |
| `3 1 2` | 3 左 1，1 右 2 | 仅 [3,1,2] | 1 | `3 1 2` ✓ |
| `3 2 1` | 左链 | 仅 [3,2,1] | 1 | `3 2 1` ✓ |

$\sum_T e(T)=1+1+2+1+1=6=3!$ ✓——双射把全部排列按树分类，类大小与闭式逐一吻合，没有序列被两类同时计入或漏计。$n=1$：`1` → 输出 `1` ✓。

**$n=4$ 两棵非平凡树全 24 排列手枚举**：
- T₁（`3 1 4 2` 之树：$3.\mathit{lf}=1,1.\mathit{rg}=2,3.\mathit{rg}=4$）：恰 [3,1,2,4]、[3,1,4,2]、[3,4,1,2] 三个排列生成它（其余 21 个抽查建树均异形），闭式 $e=\binom{2+1}{2}\cdot1\cdot1=3$ ✓，字典序最小 [3,1,2,4] = 先序 ✓。
- T₂（`2 4 1 3` 之树：$2.\mathit{lf}=1,2.\mathit{rg}=4,4.\mathit{lf}=3$）：恰 [2,1,4,3]、[2,4,1,3]、[2,4,3,1]，$e=\binom{1+2}{1}=3$ ✓，最小 [2,1,4,3] = 先序 ✓。用引理 4 的优先队列贪心独立复算：pop 2→可用{1,4}→1→可用{4}→4→可用{3}→3，得 `2 1 4 3`，与先序逐位一致 ✓。

- **代码路径手算**（输入 `4 / 3 1 4 2`）：i=1,x=3：S 空，rt=3；i=2,x=1：p=0,q=3→par=3，1<3 挂 lf[3]=1；i=3,x=4：p=3,q=0→par=3 挂 rg[3]=4；i=4,x=2：p=1(tn=2),q=3(tn=1)→par=1（后插入者），2>1 挂 rg[1]=2。栈先序：3→压4,1→弹1→压rg[1]=2→弹2→弹4：输出 `3 1 2 4`，与暴力枚举最小者一致 ✓。
