# P1124 [ZJOI2001] 文件压缩 — 题解

---

## 1. 重述问题（Read the Problem）

给定一个字符串 $S$（长度 $n$），题目描述的「文件压缩」算法如下：

1. 构造 $n$ 个循环移位串：第 $i$ 个串将 $S$ 的前 $i-1$ 个字符移到末尾（$1\le i\le n$）。这 $n$ 个串的长度均为 $n$。
2. 将这 $n$ 个串**按首字符从小到大排序**；若首字符相同，则按它们在原串 $S$ 中的原始位置（即下标 $i$）从小到大排序。
3. 取出排序后每个串的**末尾字符**，组成新串 $S'$（长度 $n$）。
4. 记录原串 $S$（即第 $1$ 个循环移位排在第 $p$ 位）。

**输入**： $n$、$S'$、$p$。  
**输出**： 原串 $S$。

**数据范围**： $n\le 10000$，仅含小写字母。

> 这就是著名的 **Burrows–Wheeler Transform (BWT)**。正向变换输入 $S$ 得到 $(S', p)$；本题要求做**逆变换**：从 $(S', p)$ 恢复 $S$。

---

## 2. 思考过程与完整证明（Chain‑of‑Thought）

### 2.1 符号约定

记排序后的 $n$ 个循环移位为 $R_0, R_1, \dots, R_{n-1}$（$0$ 基），称为**行（rows）**。  
对于第 $i$ 行 $R_i$，令：

- $F[i]$ 为其**首字符**（First）；
- $L[i]$ 为其**末字符**（Last）。

显然 $S' = L$（输入给定的串），而 $F$ 就是 $L$ 按字符升序排序的结果，因为 $F$ 来自所有循环移位的首字符的排序。

记原串 $S$ 对应第 $p-1$ 行（$1$ 基 $\to$ $0$ 基）。

### 2.2 核心观察：$F$ 与 $L$ 的「第 $k$ 次出现」对应关系

考虑原串 $S$ 中的任意位置 $t$（$0\le t<n$），字符 $c = S[t]$。

- $c$ 作为**首字符**出现在循环移位 $(t+1)$（即将 $S$ 的前 $t$ 个字符移到末尾的那个串）中，记为行 $R_i$，于是 $F[i]=c$。
- $c$ 作为**末字符**出现在循环移位 $(t-1 \bmod n)$ 中，记为行 $R_j$，于是 $L[j]=c$。

现在，对 $F$ 中所有首字符为 $c$ 的行，它们按原位置 $t$ 从小到大排序（题目规则 2）。  
这些行再分别「向右循环一位」，恰好以 $c$ 为末字符出现在 $L$ 中。

> **关键引理（LF-映射保序性）**：  
> $F$ 中 $c$ 的第 $k$ 次出现（按行号从小到大），与 $L$ 中 $c$ 的第 $k$ 次出现（也按行号从小到大），一一对应。

**证明**：  
设 $R_{i_1}, R_{i_2}, \dots, R_{i_m}$ 是 $F$ 中所有首字符为 $c$ 的行，且 $i_1<i_2<\dots<i_m$。  
这些行的原始循环移位分别是 $S[t_1..]\dots S[t_1-1]$，其中 $t_1<t_2<\dots<t_m$（题目规则保证了按原位置排序）。  
将它们各自向右循环一位，得到 $S[t_1-1]S[t_1]..S[t_1-2]$，末字符均为 $c$，首字符分别为 $S[t_1-1], S[t_2-1], \dots$。  
由于原位置 $t_1<t_2<\dots<t_m$，故新串的首字符序列的字典序与原序列的字典序**一致**（因为首字符相同的位置排序退化为按剩余部分排序，与原来的排序完全一致）。  
因此这些新串在 $L$ 中的行号顺序 $j_1<j_2<\dots<j_m$ 与 $i_1<i_2<\dots<i_m$ 完全相同。  
证毕。

### 2.3 逆变换算法

由上述引理，我们可以构造一个映射 `nxt[0..n-1]`：

```
nxt[i] = 在 F 中第 rank_L(i) 个字符 L[i] 出现的位置
       = start[L[i]] + rank_L[i] - 1
```

其中：

- `rank_L[i]` 是 `L[i]` 在 $L[0..i]$ 中出现的次数（$1$ 基）。
- `start[c]` 是字符 $c$ 在 $F$ 中第一次出现的位置（$0$ 基），即 $F$ 中所有小于 $c$ 的字符的总数。

这个 `nxt[i]` 的含义是：  
第 $i$ 行 $R_i$ 的首字符 $F[i]$ 的后继字符 $F[\text{nxt}[i]]$ 就是「在原串 $S$ 中紧跟在 $F[i]$ 后面的那个字符」。

更直接地，我们可以用 `nxt` 从右向左重建 $S$：

- 原串 $S$ 对应第 $p-1$ 行，该行的**末字符**就是 $S$ 的**最后一个字符**：
  $$S[n-1] = L[p-1]$$
- 然后，为了找到 $S[n-2]$，我们看「以 $L[p-1]$ 为末字符的行」，它对应于 `nxt[p-1]`。该行的**首字符** $F[\text{nxt}[p-1]]=L[p-1]$ 就是 $S$ 中紧跟在 $S[n-1]$ 前面的字符。但那只说 $F[\text{nxt}[p-1]]=L[p-1]$ 是恒等的，我们需要的是 $L[\text{nxt}[p-1]]$。

实际上是这个关系：
$$S[t] = L[\text{pos}_t]$$
其中 $\text{pos}_t$ 通过反复 $\text{pos} \gets \text{nxt}[\text{pos}]$ 从 $p-1$ 开始逆向迭代得到。

具体操作：

```
pos = p - 1
for k = n-1 downto 0:
    S[k] = L[pos]
    pos = nxt[pos]
```

**正确性证明**（归纳）：  
$S$ 的第 $p-1$ 行（即原串）的末字符为 $L[p-1]$，故 $S[n-1]=L[p-1]$ 正确。  
假设我们已确定 $S[k+1..n-1]$，当前 $\text{pos}$ 满足：当前行的末字符 $L[\text{pos}] = S[k+1]$。  
根据 `nxt` 的定义，`nxt[pos]` 指向的行满足 $F[\text{nxt}[pos]] = L[pos] = S[k+1]$。  
但 $F[\text{nxt}[pos]]$ 是某行的首字符，该行恰恰是「以 $S[k+1]$ 为末字符的循环移位向右循环一位」所得，故它的末字符 $L[\text{nxt}[pos]]$ 就是 $S$ 中在 $S[k+1]$ 前面的字符 $S[k]$。  
因此 $S[k] = L[\text{nxt}[pos]]$ 正确。归纳成立。

## 3. 模式总结（Pattern Summary）

| 概念 | 等价物 |
|------|--------|
| 排序后各行首字符列 $F$ | $S'$ 的升序排序 |
| 排序后各行末字符列 $L$ | 输入串 $S'$ |
| LF 映射 `nxt[i]` | `start[L[i]] + rank[L[i]] - 1` |
| 重建方向 | 从 **$p-1$** 出发，沿 **`nxt`** 逆向行走，从右到左填写 $S$ |

**模式识别**：BWT 是一个「字母重排 + 位置标记」的可逆变换。逆变换的核心在于 $F$ 和 $L$ 之间「第 $k$ 次出现对应」这一保序性。

## 4. 正式解法与符号表（Real Solution）

### 算法步骤

1. **读入** $n$，串 $L$，位置 $p$（$1$ 基）。
2. **计算 $F$**：对 $L$ 排序，得到 $F$。
3. **计算 `cnt` 与 `start`**：
   - `cnt[26]`：$L$ 中各字符出现次数。
   - `start[26]`：`start[c]` = $\sum_{d<c} \text{cnt}[d]$，即字符 $c$ 在 $F$ 中的首位置。
4. **计算 `rankL` 与 `nxt`**：
   - `rk[26]` 实时记录当前各字符已出现次数。
   - 遍历 $i=0..n-1$，`cur = L[i]`，`++rk[cur]`，则 `nxt[i] = start[cur] + rk[cur] - 1`。
5. **重建 $S$**：
   - `pos = p - 1`。
   - 逆序填 $S[n-1] \to S[0]$：`S[k] = L[pos]; pos = nxt[pos]`。
6. **输出 $S$**。

### 复杂度

- 时间：$O(n + |\Sigma|) = O(n)$，其中 $|\Sigma|=26$。
- 空间：$O(n)$。

### 符号表（Notation Glossary）

| 符号 | 含义 |
|------|------|
| $n$ | 串长 |
| $L$ | 末字符列（即输入的 $S'$） |
| $F$ | 首字符列（$L$ 排序所得） |
| $p$ | 原串在排序中的位置（$1$ 基） |
| $\text{start}[c]$ | 字符 $c$ 在 $F$ 中的首次出现位置（$0$ 基） |
| $\text{rk}[c]$ | 遍历 $L$ 时，$c$ 已出现的次数（动态） |
| $\text{nxt}[i]$ | LF 映射，$F[i]$ 的后继字符所在行号 |
| $\text{pos}$ | 迭代指针，初始为 $p-1$ |

## 5. 参考代码（Example Code）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;
constexpr int mxn{10005};

int n, p;
char L[mxn], F[mxn];
int nxt[mxn], start[26], cnt[26], rk[26];
char ans[mxn];

int main()
{
	cin.tie(nullptr)->sync_with_stdio(false);

	cin >> n >> L >> p;
	--p;

	// F = sorted(L)
	memcpy(F, L, n);
	sort(F, F + n);

	// count characters in F
	for (int i = 0; i < n; ++i)
		++cnt[F[i] - 'a'];

	// start positions in F
	for (int c = 1; c < 26; ++c)
		start[c] = start[c - 1] + cnt[c - 1];

	// LF mapping: nxt[i] = start[L[i]] + rank(L[i]) - 1
	for (int i = 0; i < n; ++i)
	{
		int c = L[i] - 'a';
		++rk[c];
		nxt[i] = start[c] + rk[c] - 1;
	}

	// reconstruct from right to left
	int pos = p;
	for (int k = n - 1; k >= 0; --k)
	{
		ans[k] = L[pos];
		pos = nxt[pos];
	}
	ans[n] = '\0';

	cout << ans << '\n';

	return 0;
}
```

### 关键说明

- `p` 从 $1$ 基转为 $0$ 基（`--p`）。
- `start[c]` 利用前缀和一次算出。
- 重建时从 $p$（已减 $1$）出发，逆序遍历 $k=n-1$ 到 $0$，每一步取 `L[pos]` 为当前字符，然后 `pos = nxt[pos]` 回退。
- 由于是循环移位，$n$ 步后 `pos` 必然回到起点，恢复整个串。
