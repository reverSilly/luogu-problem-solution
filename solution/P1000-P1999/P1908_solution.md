# P1908 逆序对

## 1. 重新读题

### 1.1 问题重述（人话版）

给定长度为 $n$ 的正整数序列 $a_1,\dots,a_n$（可以重复）。数出满足 $i<j$ 且 $a_i>a_j$ 的有序对 $(i,j)$ 的个数。

### 1.2 关键约束与规模暗示

- $1\le n\le 5\times10^5$，$a_i\le 10^9$。
- 25% 数据 $n\le2500$：$O(n^2)$ 暴力。
- 50% 数据 $n\le4\times10^4$：$O(n^2)$ 就已经 $1.6\times10^9$，开始危险。
- 100% 数据：必须 $O(n\log n)$。
- 答案最大约 $\binom{n}{2}\approx1.25\times10^{11}$，**必须开 `long long`**，这是本题最常见的错误。
- $a_i$ 值域 $10^9$，不能直接开值域树状数组，需要**离散化**。

---

## 2. 思维链（Chain-of-thought）

### 2.1 暴力与它的瓶颈

固定右端点 $j$，检查所有 $i<j$ 是否 $a_i>a_j$，累加。复杂度 $O(n^2)$，$n=5\times10^5$ 时 $1.25\times10^{11}$，必死。

瓶颈是「每次都要回头看前面所有数」。我们希望快速回答：**前面已经出现过的数里，有多少个严格大于 $a_j$？**

### 2.2 把「严格大于」换成「不超过」

记到当前为止已经插入了 $j-1$ 个数（$0$-based 时是 $j$ 个，见实现）。若我们能查询「前面 $\le a_j$ 的个数」，那么

$$
\text{前面大于 }a_j\text{ 的个数}=(j-1)-\#\{i<j:\ a_i\le a_j\}.
$$

这里用 $\le$ 而不是 $<$，正好处理重复数字：$a_i=a_j$ 不构成逆序对，必须从「大于」里排除。

### 2.3 数显式太大 → 离散化

需要「按数值大小做前缀计数」。$a_i\le10^9$，但只有 $n$ 个不同的值。把数组排序去重，用每个数在去重数组中的**排名**（$1$-based）代替原值。因为比较只依赖大小关系，排名完全保持 $\le$ 的关系。

**引理 1**：设 $b_i$ 为 $a_i$ 在去重升序数组中的排名，则对任意 $i,j$，$a_i\le a_j\iff b_i\le b_j$。

**证明**：去重升序数组严格递增，排名是保序双射；相等的数排名相同。$\square$

于是问题变成：在线插入排名，查询前缀和。

### 2.4 树状数组维护前缀计数

树状数组支持单点加 $1$、前缀和查询，均 $O(\log n)$。从左到右处理 $a_j$（0-based，下标 $j=0..n-1$）：

1. 查询前缀 $\mathrm{sum}(b_j)$ = 前面 $\le a_j$ 的个数；
2. 逆序对数增加 $j-\mathrm{sum}(b_j)$（前面一共 $j$ 个数）；
3. 在 $b_j$ 处加 $1$。

总复杂度 $O(n\log n)$。

**引理 2**：上述累加恰好等于逆序对总数。

**证明**：每个逆序对 $(i,j)$ 有唯一的右端点 $j$。在处理 $j$ 时，前 $j$ 个数（0-based 下标 $0..j-1$）中大于 $a_j$ 的个数正好是 $j-\mathrm{sum}(b_j)$，它把以 $j$ 为右端点的所有逆序对一次计清，且不重不漏。$\square$

### 2.5 另一条路：归并排序（只作为思维对照）

归并排序在合并两个有序段时，若右段元素被取出而左段还剩 $k$ 个，就产生 $k$ 个逆序对。复杂度同样 $O(n\log n)$，常数更小、不需要离散化。两种做法都对；本解法最终采用树状数组版本（更容易和「前缀计数」这一模型对上），归并版留作对照，不再重复给出代码。

**为什么归并也正确（简述）**：每次合并只统计「左段元素在右段元素之前且值更大」的对，而递归结构保证每对下标 $i<j$ 恰好在某个合并层被计入一次。$\square$

---

## 3. 模式总结（Pattern Summary）

- **explore its property** — 固定右端点，逆序数 = 前面元素总数 − 前面 $\le a_j$ 的个数。
- **reduce to easier problem** — 值域 $10^9$ 无法开桶，用「排序去重后的排名」替代原值（离散化保序）。
- **classic problem solution** — 树状数组维护排名上的前缀计数，边扫描边查询、边插入。

---

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 序列长度 | 读入 | 规模 |
| `a[i]` | `int [500005]` | 原序列 | 读入 | array |
| `b[i]` | `int [500005]` | 排序去重后的值 | `a` 的副本排序去重 | sorted |
| `tr[i]` | `i64 [500005]` | 树状数组，维护排名上的计数 | 0 | tree |
| `ans` | `i64` | 逆序对总数 | 0 | answer |

### 4.2 算法步骤

1. 读入 $n$ 与 $a_0..a_{n-1}$；把 `a` 复制到 `b`，对 `b` 排序并 `unique`，得到去重值表。
2. 对每个 $j=0\dots n-1$：
   1. `rk = lower_bound(b, b+len, a[j]) - b + 1`（$1$-based 排名）；
   2. `ans += j - sum(rk)`，其中 `sum(rk)` 是树状数组对 `rk` 的前缀和；
   3. `upd(rk)`：`tr[i] += 1` 沿 `i += i&-i`。
3. 输出 `ans`。

### 4.3 复杂度分析

- **时间复杂度**：排序去重 $O(n\log n)$，每个元素一次查询 + 一次修改，各 $O(\log n)$，总 $O(n\log n)$。
- **空间复杂度**：$O(n)$（原数组、去重数组、树状数组）。

## 5. 示例代码

```cpp
//
// 题目：P1908 逆序对
// https://www.luogu.com.cn/problem/P1908
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{500005};

int n;
int a[mxn],b[mxn];
i64 tr[mxn];

int lowbit(int x){return x&-x;}

void upd(int i)
{
	for(;i<=n;i+=lowbit(i))
		++tr[i];
}

i64 sigma(int i)
{
	i64 r{0};
	for(;i>0;i-=lowbit(i))
		r+=tr[i];
	return r;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		b[i]=a[i];
	}
	sort(b,b+n);
	int len=unique(b,b+n)-b;

	i64 ans{0};
	for(int j=0;j<n;++j)
	{
		int rk=lower_bound(b,b+len,a[j])-b+1;
		ans+=j-sigma(rk);
		upd(rk);
	}
	cout<<ans<<'\n';
	return 0;
}
```
