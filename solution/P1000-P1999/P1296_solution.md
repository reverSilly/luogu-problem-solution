# P1296 奶牛的耳语 — 题解

---

## Part 1 · 重新读题

一排直线上有 $n$ 头奶牛，第 $i$ 头在整数坐标 $p_i$（$0 \le p_i \le 10^8$）。每头牛发出的声音传播距离不超过 $d$（$0 \le d \le 10^4$）。两两牛若距离 $\le d$，则称为"可以相互交流"的一对。求总共多少对。

**数据规模：**
- $40\%$：$n \le 10^3$
- $100\%$：$n \le 10^6$

**复杂度暗示：** $n = 10^6$ 时，$O(n^2)$ 暴力是 $10^{12}$，完全不可行。需要 $O(n \log n)$ 或 $O(n)$。

---

## Part 2 · 思维链（发现过程）

### 第一步：精确刻画"可以交流"的条件

两牛 $i$、$j$ 可以交流 $\iff |p_i - p_j| \le d$。

注意题目说的是"距离"——直线上的欧氏距离就是坐标差的绝对值。所以条件就是：

$$|p_i - p_j| \le d$$

这对条件**只跟两牛的坐标有关**，跟它们的编号无关。换句话说，如果我们把坐标重新排列，"对数"不变——只要坐标集合没变，对数就不变。

### 第二步：排序后问题变简单

把坐标排序：$q_1 \le q_2 \le \cdots \le q_n$。

排序后，对于任意 $i < j$，有 $q_j \ge q_i$，所以 $|q_i - q_j| = q_j - q_i$。

两牛 $i$、$j$（$i < j$）可以交流 $\iff q_j - q_i \le d$。

这是一个**区间问题**：对每个 $i$，找最大的 $r_i$ 使得 $q_{r_i} - q_i \le d$，则 $i$ 与 $i+1, i+2, \ldots, r_i$ 都能交流，贡献 $(r_i - i)$ 对。

**引理 1（排序不改变对数）：** 排序前后，可以交流的对数相同。

**证明：** 设原始坐标集合为 $\{p_1, p_2, \ldots, p_n\}$，排序后为 $\{q_1, \ldots, q_n\}$。两集合是同一个集合（只是顺序不同）。可以交流的对是集合中的无序二元组 $\{i, j\}$，$i \ne j$。条件 $|p_i - p_j| \le d$ 仅取决于这两个坐标的值，与顺序无关。因此排序前后，满足条件的无序对集合完全相同，对数不变。$\blacksquare$

### 第三步：暴力——排序后对每头牛向右数

对每个 $i$，暴力向右扫，数出满足 $q_j - q_i \le d$ 的 $j$（$j > i$）。

复杂度：$O(n^2)$ 最坏情况（比如所有牛挤在一起，$d$ 很大）。$n = 10^6$ 时 $10^{12}$，太慢。

**观察：** 对 $i$ 找 $r_i$（最大的 $j$ 使得 $q_j - q_i \le d$），当 $i$ 增大时，$q_i$ 增大，$q_i + d$ 增大，所以 $r_i$ **单调不减**。

这正是**双指针**（滑动窗口）的适用场景。

### 第四步：双指针扫描

维护右指针 $r$（初始 $0$），对每个左指针 $i$（从 $0$ 到 $n-1$）：

1. 把 $r$ 推到尽可能右：只要 $r+1 < n$ 且 $q[r+1] - q[i] \le d$，就 $r$ 加 $1$。
2. 此时 $r$ 是满足 $q[r] - q[i] \le d$ 的最大下标（或保持上次的值，因为 $r$ 只增不减）。
3. 贡献 $\max(0, r - i)$ 对。

**引理 2（$r$ 单调不减）：** 对所有 $i$，$r_i \ge r_{i-1}$。

**证明：** 设 $r_i$ 是满足 $q[r] - q_i \le d$ 的最大下标。因为 $i$ 增大时 $q_i$ 不减，所以 $q_i \ge q_{i-1}$。取 $r = r_{i-1}$，则 $q[r] - q_i \le q[r] - q_{i-1} \le d$。即 $r_{i-1}$ 也满足 $r_i$ 的条件。所以 $r_i \ge r_{i-1}$。$\blacksquare$

**引理 3（双指针算法的正确性）：** 用双指针扫描，对每个 $i$ 得到的 $r$ 恰好是 $r_i$，累加 $\sum_{i=0}^{n-1}(r_i - i)$ 即为答案。

**证明：**

*（a）$r$ 只增不减。* 由引理 2，$r_i$ 单调不减，算法中 $r$ 从 $r_{i-1}$ 开始只向右推，所以处理完 $i$ 后的 $r$ 值 $\ge r_{i-1}$，与 $r_i$ 单调性一致。

*（b）$r$ 不会越推过头。* 算法只在 $q[r+1] - q[i] \le d$ 时才推 $r$。推完后 $r$ 是最大的满足条件的下标（否则还能推），所以 $r = r_i$。

*（c）累加值就是答案。* 对每个 $i$，满足 $i < j$ 且 $q_j - q_i \le d$ 的 $j$ 的个数恰好是 $r_i - i$（因为 $j$ 从 $i+1$ 到 $r_i$ 共 $r_i - i$ 个）。所有 $i$ 的贡献之和 $\sum_i (r_i - i)$ 恰好是所有无序对 $(i, j)$（$i < j$）中满足条件的对数，由引理 1 等于原始问题的答案。$\blacksquare$

**复杂度分析：**
- 排序：$O(n \log n)$
- 双指针：$r$ 总共最多推 $n$ 次，$i$ 总共推 $n$ 次，共 $O(n)$
- 总：$O(n \log n)$，$n = 10^6$ 约 $2 \times 10^7$ 次操作，轻松。

### 第五步：溢出检查

答案最大为 $\binom{10^6}{2} = \frac{10^6 \cdot (10^6 - 1)}{2} \approx 5 \times 10^{11}$，超过 $2^{31} \approx 2.1 \times 10^9$，必须用 `long long`。

## Part 3 · 模式总结

```
- explore its property — 交流条件只依赖坐标差的绝对值，与编号无关
- consider easier version — 排序后问题变为区间问题，对每头牛找右边最大可达范围
- classic problem solution — 双指针（滑动窗口）：右指针只增不减，O(n) 完成
```

## Part 4 · 正式解法

### 符号表

| 符号 | 含义 | 类型 |
|------|------|------|
| `n` | 奶牛数量 | `int` |
| `d` | 声音传播最远距离 | `int` |
| `q[0..n-1]` | 排序后的坐标数组，$q_i$ 递增 | `int` |
| `r` | 右指针：对当前左指针 $i$，$q[r] - q[i] \le d$ 的最大下标 | `int`，初始 $0$ |
| `ans` | 答案（对数） | `long long` |

### 算法步骤

1. **读入**：读 $n, d$ 和 $n$ 个坐标，存入 `q[0..n-1]`。
2. **排序**：将 `q` 升序排序。
3. **双指针扫描**：
   - 初始化 `r = 0`，`ans = 0`。
   - 对每个 `i`（从 `0` 到 `n-1`）：
     - 只要 `r + 1 < n` 且 `q[r+1] - q[i] <= d`，就 `r++`。
     - `ans += r - i`。
4. **输出** `ans`。

### 复杂度

- **时间**：$O(n \log n)$（排序主导）
- **空间**：$O(n)$（坐标数组）

### 验证状态

- 排序不改变对数（引理 1）✓
- 右指针单调不减（引理 2）✓
- 双指针累加值恰好等于答案（引理 3）✓
- 答案需 `long long`（最大 $\approx 5 \times 10^{11}$）✓

## Part 5 · 示例代码（C++）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005};

int n,d,q[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>d;
	for(int i=0;i<n;++i)
		cin>>q[i];
	sort(q,q+n);

	long long ans=0;
	int r=0;
	for(int i=0;i<n;++i)
	{
		while(r+1<n&&q[r+1]-q[i]<=d)
			++r;
		ans+=r-i;
	}
	cout<<ans<<'\n';
	return 0;
}
```

**代码说明：**

- `q[mxn]`：全局静态数组存排序后坐标，`mxn = 10^6 + 5`（+5 松弛）。
- `r`：右指针，初始 `0`。对每个 `i`，`r` 只增不减（引理 2），所以 `while` 循环总共最多执行 $n$ 次。
- `ans += r - i`：`i` 与 `i+1, ..., r` 共 `r - i` 头牛可以交流，累加到答案。
- `ans` 用 `long long`，因为最大答案 $\approx 5 \times 10^{11}$ 超出 `int` 范围。
