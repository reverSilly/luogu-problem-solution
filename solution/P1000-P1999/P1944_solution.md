# P1944 最长括号匹配

## 1. 重新读题

### 1.1 问题重述（人话版）

给一个只含 `(`、`)`、`[`、`]` 的非空字符串，求最长的**连续子串**，使得它本身是一个「括号匹配的串」（配对规则与通常的两种括号一致：`()`、`[]` 合法；合法串套括号、拼接仍合法）。若长度相同，输出**起点最靠前**的那个子串。

### 1.2 关键约束与规模暗示

- $n\le 10^6$，输入非空。
- 20% 数据 $n\le 100$：枚举所有子串再判定，$O(n^3)$ 也能过。
- 50% 数据 $n\le 10^4$：$O(n^2)$ 的「枚举起点向后扫 + 栈」能过。
- 100% 数据 $n\le 10^6$：只能 $O(n)$ 或 $O(n\log n)$；提示必须用「以每个位置结尾」的线性 DP（或等价的栈做法）。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先看一个子串怎么判定

用栈扫一遍：遇到左括号入栈；遇到右括号，若栈顶是与之配对的左括号就弹出，否则非法；扫完栈必须为空。

暴力枚举所有子串是 $O(n^3)$（$O(n^2)$ 个子串 × $O(n)$ 判定），$n=10^6$ 时不可行。注意到「子串必须连续、必须整体平衡」，而一段合法串的内部也是合法串，这天然适合**以右端点归约**。

### 2.2 定义以 $i$ 结尾的最长合法子串

令 $dp_i$ 表示**以位置 $i$ 结尾**的最长合法括号子串长度，若不存在则 $dp_i=0$。

**引理 1（$s_i$ 是左括号则 $dp_i=0$）**

**证明**：任何非空合法串的第一个字符必为左括号、最后一个字符必为右括号（由三条生成规则归纳：`()`/`[]` 以右括号收尾，套括号与拼接也以右括号收尾）。若 $s_i$ 是左括号，则不存在以它结尾的非空合法串。$\square$

所以只考虑 $s_i$ 是 `)` 或 `]` 的情况。

### 2.3 关键位置：$i-1-dp_{i-1}$

设 $s_i$ 是右括号。若它要成为某个合法串的最后一个字符，它必须和某个左括号 $s_j$ 配对，且 $s_{j+1}\dots s_{i-1}$ 也是合法串。于是 $[j+1,i-1]$ 是一个**以 $i-1$ 结尾**的合法串，长度 $i-1-j\le dp_{i-1}$，即
$$
j\ \ge\ i-1-dp_{i-1}\ =: \ L.
$$

**引理 2（$s_i$ 能配对的左括号只可能是位置 $L$，或不存在）**

**证明**：设存在某个合法子串以 $i$ 结尾，配对的左括号在 $j$，由上段 $j\ge L$。

反设 $j>L$。考虑以 $i-1$ 结尾的最长合法串 $V=s_{i-dp_{i-1}}\dots s_{i-1}$，其起点是 $i-dp_{i-1}=L+1$。因此 $j\in[L+1,\,i-1]$，即 $s_j$ 落在 $V$ 内部。

- 若 $s_j$ 是右括号，不可能作为配对左括号；
- 若 $s_j$ 是左括号，则在合法串 $V$ 内它已经和某个右括号 $s_k\ (j<k\le i-1)$ 唯一配对（合法串的配对方式唯一：用栈扫描时每一步的匹配都是强制的）。但另一方面，合法串 $s_j\dots s_i$ 要求 $s_j$ 与 $s_i$ 配对，且 $s_{j+1}\dots s_{i-1}$ 合法。两种配对都从 $s_j$ 出发，矛盾。

因此 $j>L$ 不可能，只能是 $j=L$。$\square$

**引理 3（转移式）**：设 $L=i-1-dp_{i-1}$。
$$
dp_i=
\begin{cases}
dp_{i-1}+2+dp_{L-1},& L\ge0,\ \text{且 } s_L,s_i\text{ 配对},\\
0,&\text{否则},
\end{cases}
$$
其中约定 $dp_{-1}=0$。

**证明**：先证「可以取到」。若 $s_L$ 与 $s_i$ 配对，则 $s_{L+1}\dots s_{i-1}$ 正是那个长度 $dp_{i-1}$ 的合法串，故 $s_L\dots s_i$ 合法，长度 $dp_{i-1}+2$。又若 $L>0$，$s_{L-dp_{L-1}}\dots s_{L-1}$ 是以 $L-1$ 结尾的最长合法串，与前面拼接仍合法，长度再加 $dp_{L-1}$。所以 $dp_i\ge$ 右端。

再证「不能更大」。引理 2 说明任何以 $i$ 结尾的合法串，其配对左括号只能是 $L$；若 $s_L$ 不配对，则连一个非空合法串都没有，$dp_i=0$。若配对，则该合法串形如「某个以 $L-1$ 结尾的合法串」+ $s_L$ +「某个以 $i-1$ 结尾的合法串」+ $s_i$。两段分别至多 $dp_{L-1}$、$dp_{i-1}$，故长度至多 $dp_{L-1}+dp_{i-1}+2$。$\square$

于是从 $i=0$ 到 $n-1$ 递推一遍即可，$O(n)$。

### 2.4 相同长度取最靠前的子串

**引理 4**：按 $i$ 从小到大扫描，只在 $dp_i$ **严格大于**当前最大值时更新答案，得到的就是起点最靠前的最大合法子串。

**证明**：长度固定为 $L$ 的候选子串，其起点 $=$ 终点 $-L+1$，终点越小起点越小。我们按终点递增扫描，第一次达到最大长度 $L^*$ 时，对应的终点最小，因此起点也最小。此后只在严格大于时更新，不会把答案换成同长度的更晚子串。$\square$

### 2.5 边界

- $L<0$：说明 $s_i$ 左侧没有足够的字符可供配对，$dp_i=0$。
- $L=0$：配对成功后没有前缀可拼，$dp_0$ 视为 $0$。
- 整个串没有合法子串时 $dp$ 全为 $0$，输出空行（空串是任何串的子串）。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 合法串一定以左括号开头、右括号结尾；内部仍是合法串。
- **consider easier version** — 先只判定一个子串：栈扫描 $O(n)$；暴力枚举全部子串不可取。
- **reduce to easier problem** — 用「以 $i$ 结尾的最长合法串」$dp_i$ 归约，配对位置被 $dp_{i-1}$ 唯一钉死。
- **classic problem solution** — 线性 DP，$dp_i=dp_{i-1}+2+dp_{L-1}$（配对时）。
- **tie-breaking** — 按终点递增、严格大于才更新，天然取到最靠前的同长子串。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `s` | `char [1000005]` | 输入字符串（0 基） | 读入 | string |
| `len` | `int` | 字符串长度 | `strlen(s)` | length |
| `dp[i]` | `int [1000005]` | 以 $i$ 结尾的最长合法子串长度 | 0 | DP |
| `L` | `int` | 候选配对位置 $i-1-dp[i-1]$ | 计算 | left |
| `best` | `int` | 目前最长长度 | 0 | answer |
| `bend` | `int` | 目前最长子串的右端点 | $-1$ | best end |

### 4.2 算法步骤

1. 读入字符串，求长度 `len`。
2. 对 $i=0\to len-1$：
   1. 若 $s_i$ 是 `(` 或 `[`，`dp[i]=0`，跳过；
   2. 否则令 `pre = (i>0 ? dp[i-1] : 0)`，`L=i-1-pre`；
   3. 若 `L>=0` 且 $s_L$ 与 $s_i$ 配对，则 `dp[i]=pre+2+(L>0?dp[L-1]:0)`；否则 `dp[i]=0`；
   4. 若 `dp[i]>best`，更新 `best=dp[i]`、`bend=i`。
3. 若 `best==0` 输出空行；否则输出 `s[bend-best+1 .. bend]`。

### 4.3 复杂度分析

- **时间**：一次扫描，$O(n)$。
- **空间**：$O(n)$（字符串 + `dp` 数组）。

## 5. 示例代码

```cpp
//
// 题目：P1944 最长括号匹配
// https://www.luogu.com.cn/problem/P1944
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005};

char s[mxn];
int dp[mxn];

bool match(char a,char b)
{
	return (a=='('&&b==')')||(a=='['&&b==']');
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	int len=strlen(s);

	int best{0},bend{-1};
	for(int i=0;i<len;++i)
	{
		if(s[i]=='('||s[i]=='[')
		{
			dp[i]=0;
			continue;
		}
		int pre=(i>0?dp[i-1]:0);
		int L=i-1-pre;
		if(L>=0&&match(s[L],s[i]))
			dp[i]=pre+2+(L>0?dp[L-1]:0);
		else
			dp[i]=0;
		if(dp[i]>best)
		{
			best=dp[i];
			bend=i;
		}
	}

	if(best==0)
		cout<<'\n';
	else
		cout<<string(s+bend-best+1,best)<<'\n';
	return 0;
}
```
