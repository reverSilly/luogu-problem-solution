# P1056 [NOIP 2008 普及组] 排座椅 · 题解

---

## 一、发现叙事（由表及里的推理过程）

### 1.1 直观印象

第一次读到题目，描述非常生活化：教室里有 `M×N` 个座位，有 `D` 对同学上课讲话，班主任可以在行之间、列之间放通道（aisle），一旦某对同学被通道隔开，他们就没法讲话了。现在要选 `K` 条横向通道和 `L` 条纵向通道，目标是**让能讲话的对数最少**。输出哪些行之间、哪些列之间放通道。

数据范围：`M,N ≤ 1000`，`D ≤ 2000`。规模不大，但也不是暴力能随便过的——要在最多 1000 行里选 `K` 条通道，如果枚举所有组合 `C(M-1, K)` 会爆炸。

### 1.2 核心观察：行列独立

每对讲话的同学只有两种可能的相邻方式：

1. **前后相邻**：两个人在同一列，行号相差 1，记作 `(X, Y)` 和 `(X+1, Y)`。只有**横向通道**（放在第 `X` 行和第 `X+1` 行之间）才能隔开他们。
2. **左右相邻**：两个人在同一行，列号相差 1，记作 `(X, Y)` 和 `(X, Y+1)`。只有**纵向通道**（放在第 `Y` 列和第 `Y+1` 列之间）才能隔开他们。

这里有一个极其重要的性质：**横向通道和纵向通道的决策互不干扰**。横向通道只会影响前后相邻的对，纵向通道只会影响左右相邻的对。一个"前后相邻"的对不可能被纵向通道隔开，反之亦然。

所以原问题可以一分为二，变成两个完全独立的子问题：

- **子问题 A**：在 `M-1` 个候选横向位置（行 1 与 2 之间、行 2 与 3 之间……行 M-1 与 M 之间）中，选 `K` 个位置放通道，使得被隔开的**前后相邻**对最多。
- **子问题 B**：在 `N-1` 个候选纵向位置中，选 `L` 个位置放通道，使得被隔开的**左右相邻**对最多。

两个子问题结构完全对称。

### 1.3 子问题本质：选前 K 大的计数

考虑子问题 A。统计一下：如果我们在第 `i` 行和第 `i+1` 行之间放一条通道，能隔开多少个前后相邻的讲话对？这个数量就是**所有满足 `X = i` 且 `Y = P` 且 `Q = i+1`（或反过来）的讲话对**的个数。换句话说，对于每个输入的前后相邻对 `(r,c)` 和 `(r+1,c)`，它会给位置 `r` 贡献 1。

于是我们可以：

1. 用一个数组 `rowCnt[i]` 表示在位置 `i`（i 从 1 到 M-1）放通道能隔开的对的数量。
2. 扫描所有 D 对输入，对前后相邻的：`rowCnt[min(X, P)]++`。
3. 问题转化为：从 M-1 个数中选 K 个，使得它们的和最大。

这就是经典的**选最大的 K 个数**问题——把 `rowCnt` 按值从大到小排序，取前 K 个，再把这些位置按编号从小到大输出即可。

子问题 B 完全对称：`colCnt[j]` 记录列间通道能隔开的左右相邻对的数量，选前 L 个。

### 1.4 为什么这样是最优的？

严格证明留到第二节，这里先给直觉：

- 每个前后相邻的讲话对**恰好**可以被一个横向通道隔开（即它所在的那一行间隙）。
- 不同的横向通道之间不冲突——一条通道能隔开的对不会因为另一条通道的存在而减少。
- 因此，选哪 K 个横向位置的问题就是：在 M-1 个候选位置中挑 K 个，使得这些位置对应的 `rowCnt` 值之和最大。显然，挑最大的 K 个是最优的。
- 纵向同理。

### 1.5 排序输出细节

题目要求输出时：

- 第一行：K 个整数，升序排列，表示选了哪些行间隙。
- 第二行：L 个整数，升序排列，表示选了哪些列间隙。

所以实现细节是：**按值从大到小选位置**，但**按编号从小到大输出**。

做法：把 `(位置编号, 计数值)` 组成结构体，先按计数值降序排序取前 K 个，再按位置编号升序排序后输出。

### 1.6 小结

这道题的关键洞察就是**行列独立**和**计数 + 贪心选取**。一旦看出这一点，实现就非常简单——排序两次即可。

## 二、思维链与完整证明

### 2.1 问题形式化

记教室的行集为 `R = {1,2,…,M}`，列集为 `C = {1,2,…,N}`。  
座位 `(i,j)` 表示第 i 行第 j 列。  

横向通道集合 `H = {(i,i+1) | 1 ≤ i ≤ M-1}`，共 M-1 个候选位置。  
纵向通道集合 `V = {(j,j+1) | 1 ≤ j ≤ N-1}`，共 N-1 个候选位置。

目标：选定子集 `H* ⊆ H`，`|H*| = K` 和 `V* ⊆ V`，`|V*| = L`，最大化被隔开的讲话对数。

### 2.2 每条讲话对的定义域唯一性

**引理 1**：对于每对输入 `(X,Y,P,Q)`，它们要么是前后相邻，要么是左右相邻。对于前后相邻的对话对，只有唯一的横向通道可以隔开它；对于左右相邻的对话对，只有唯一的纵向通道可以隔开它。

**证明**：输入保证两座位相邻，因此只可能有以下两种情况：

- 情况 1（前后相邻）：`Y = Q` 且 `|X - P| = 1`。那么唯一能隔开它们的横向通道就是 `(min(X,P), min(X,P)+1)`。
- 情况 2（左右相邻）：`X = P` 且 `|Y - Q| = 1`。那么唯一能隔开它们的纵向通道就是 `(min(Y,Q), min(Y,Q)+1)`。

引理得证。这一性质极其重要——它意味着**没有一条通道会"浪费"在同一对话对上**，也没有一对话对可以被两条不同的通道隔开。

### 2.3 目标函数的可分离性

设总讲话对数为 D。令：

- `S_H` 表示被我们选择的横向通道隔开的**前后相邻**对的集合。
- `S_V` 表示被我们选择的纵向通道隔开的**左右相邻**对的集合。

根据引理 1，`S_H ∩ S_V = ∅`（前后相邻和左右相邻是互斥的），所以被隔开的总对数 = `|S_H| + |S_V|`。

设：

- `R(i) =` 被横向通道 `(i,i+1)` 隔开的前后相邻对数（即 `rowCnt[i]`）。
- `C(j) =` 被纵向通道 `(j,j+1)` 隔开的左右相邻对数（即 `colCnt[j]`）。

则：

```
|S_H| = Σ_{i ∈ H*} R(i)
|S_V| = Σ_{j ∈ V*} C(j)
```

因为不同的横向通道之间互不影响（每个讲话对唯一属于某一行间隙），所以目标函数可以拆成两项独立求和：

```
maximize ( Σ_{i ∈ H*} R(i) + Σ_{j ∈ V*} C(j) )
```

约束：`|H*| = K`，`|V*| = L`。

由于两项之间没有耦合，最大值就等于**两项分别取最大值之和**。

### 2.4 子问题最优性（贪心选择性质的证明）

**问题**：给定 `m = M-1` 个非负整数 `R(1), R(2), …, R(m)`，从中选恰好 `K` 个，使其和最大。

**贪心策略**：选值最大的 K 个。

**正确性证明（调整法 / 交换论证）**：

设 `S*` 是最优解选的 K 个位置的集合。设 `G` 是贪心策略选的 K 个位置的集合（值最大的 K 个）。  
假设 `S* ≠ G`，则存在一个位置 `a ∈ G \ S*` 和一个位置 `b ∈ S* \ G`。

由于贪心选了值最大的 K 个，所以对于任何 `a ∈ G` 和 `b ∉ G`，有 `R(a) ≥ R(b)`。  
特别地，`R(a) ≥ R(b)`。

考虑将 `S*` 中的 `b` 替换为 `a`，得到新解 `S' = S* \ {b} ∪ {a}`。替换前后的总和变化为：

```
Σ_{i∈S'} R(i) - Σ_{i∈S*} R(i) = R(a) - R(b) ≥ 0
```

所以 `S'` 不劣于 `S*`。重复这一调整过程，可以将 `S*` 逐步变为 `G` 且不降低目标函数值。因此贪心解 `G` 一定是最优的。

子问题 B 的证明完全对称。

### 2.5 唯一性保证

题目保证"最优方案的唯一性"，意思是存在唯一的一组 `H*` 和 `V*` 使得目标最大化。在我们的算法中，这意味着：

- 第 K 大的 `R(i)` 和第 K+1 大的 `R(i)` 值不相等。
- 第 L 大的 `C(j)` 和第 L+1 大的 `C(j)` 值不相等。

因此排序后选取前 K / 前 L 个不会出现平局争议。

### 2.6 算法正确性总结

1. **分解**：利用行列独立性将原问题拆为两个不耦合的子问题。
2. **计数**：遍历输入，分别累加 `rowCnt` 和 `colCnt`。
3. **贪心**：每个子问题等价于选前 K（或前 L）大的数，用排序 + 截取实现。
4. **格式化输出**：先按值降序截取，再按编号升序输出。

## 三、模式总结

| 层面 | 内容 |
|------|------|
| **问题类型** | 贪心 + 排序（计数贪心） |
| **核心洞察** | 横向与纵向决策完全独立，将二维问题解耦为两个一维子问题 |
| **使用的技巧** | 计数数组 + 两次排序（按值降序选，按编号升序输出） |
| **复杂度** | 时间 `O(D + (M+N) log(M+N))`，空间 `O(M+N)` |
| **适用场景** | 任何"在若干候选位置中选固定数量位置使覆盖/收益最大"的计数贪心问题，尤其是当候选位置之间互不冲突时 |
| **相关题目** | 类似的"行列独立"思想也出现在：P1056 本身是经典；P1450 硬币购物是另一种计数思路；NOIP 2015 扫雷游戏等也有行列分解的影子 |

## 四、正式解法

### 4.1 输入与变量

| 符号 | 含义 |
|------|------|
| `M`, `N` | 教室行数、列数 |
| `K`, `L` | 需要放置的横向、纵向通道数 |
| `D` | 讲话同学的对数 |
| `rowCnt[i]` | 第 i 行与 i+1 行之间放通道能隔开的前后相邻对数（1 ≤ i ≤ M-1） |
| `colCnt[j]` | 第 j 列与 j+1 列之间放通道能隔开的左右相邻对数（1 ≤ j ≤ N-1） |

### 4.2 算法流程

```
1. 读入 M, N, K, L, D
2. 初始化 rowCnt[1..M-1] = 0, colCnt[1..N-1] = 0
3. 对于 D 对中的每一对 (X,Y,P,Q):
   a) 如果 Y == Q (前后相邻):
          rowCnt[min(X, P)] += 1
   b) 如果 X == P (左右相邻):
          colCnt[min(Y, Q)] += 1
4. 子问题 A (横向):
   a) 将 {(i, rowCnt[i]) | 1 ≤ i ≤ M-1} 按 rowCnt 降序排序
   b) 取前 K 个
   c) 将它们的 i 按升序排序
   d) 输出
5. 子问题 B (纵向):
   a) 将 {(j, colCnt[j]) | 1 ≤ j ≤ N-1} 按 colCnt 降序排序
   b) 取前 L 个
   c) 将它们的 j 按升序排序
   d) 输出
```

### 4.3 正确性依据

- **引理 1（唯一通道）**：每对相邻同学恰好对应一个候选通道位置。
- **引理 2（独立性）**：横向、纵向决策互不干扰，目标可拆为独立的两项和。
- **定理 1（贪心最优性）**：对非负序列，选 K 个最大者即得最大和（调整法证明）。
- **题目保证唯一性**：因此选前 K / 前 L 大的方案唯一。

### 4.4 复杂度分析

- 时间：读入 O(D)，排序 O(M log M + N log N)，总体 O(D + (M+N) log (M+N))。
- 空间：O(M + N)。

## 五、C++ 实现

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int rowCnt[mxn],colCnt[mxn];

int main()
{
    cin.tie(nullptr);
    ios::sync_with_stdio(false);

    int M,N,K,L,D;
    cin>>M>>N>>K>>L>>D;

    for(int i=0;i<D;++i)
    {
        int X,Y,P,Q;
        cin>>X>>Y>>P>>Q;
        if(Y==Q)
            ++rowCnt[min(X,P)];
        else
            ++colCnt[min(Y,Q)];
    }

    // ---- 横向 ----
    struct{int id,cnt;}a[mxn];
    for(int i=1;i<M;++i)
        a[i]={i,rowCnt[i]};
    sort(a+1,a+M,[](auto x,auto y){return x.cnt>y.cnt;});
    sort(a+1,a+K+1,[](auto x,auto y){return x.id<y.id;});
    for(int i=1;i<=K;++i)
        cout<<a[i].id<<" \n"[i==K];

    // ---- 纵向 ----
    struct{int id,cnt;}b[mxn];
    for(int j=1;j<N;++j)
        b[j]={j,colCnt[j]};
    sort(b+1,b+N,[](auto x,auto y){return x.cnt>y.cnt;});
    sort(b+1,b+L+1,[](auto x,auto y){return x.id<y.id;});
    for(int j=1;j<=L;++j)
        cout<<b[j].id<<" \n"[j==L];

    return 0;
}
```

### 5.1 代码说明

- **编号从 1 开始**：教室的行列编号为 1..M / 1..N，代码中直接使用 `min(X,P)` 和 `min(Y,Q)` 作为下标，符合题目语义。
- **判定相邻方向**：`Y == Q` 则前后相邻（横向通道解决），否则（`X == P`）左右相邻（纵向通道解决）。
- **两次排序**：第一次选前 K/L 个（按计数值降序），第二次让输出升序。数组下标 1-based 使第 1 到 K 个恰好是选中的。
- **" \n"[i==K]**：利用条件索引，当 i=K 时输出 `'\n'`，否则输出 `' '`，避免行尾多余空格。

### 5.2 易错点

- 记得用 `min` 确定通道位置——输入不保证 `X < P` 或 `Y < Q`。
- 横向通道数是 K，不是 M 或 N 相关的其他值。
- 输出必须升序，先按值排序选位置，再按编号排序输出。

### 5.3 测试样例

```
输入：
4 5 1 2 3
1 1 2 1
1 2 1 3
1 3 2 3

输出：
2
2 3
```

解释：第 2 行横向通道隔开 (1,1)-(2,1) 和 (1,3)-(2,3) 两对；列 2-3 间和列 3-4 间的纵向通道（如果有的话）对应题目示例。
