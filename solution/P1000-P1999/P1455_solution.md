# P1455 搭配购买

> 标签：并查集 / 背包 DP / 强连通分量 · 难度：普及/提高-

## 1. 重新读题

**问题重述（形式化）**

$n$ 朵云，第 $i$ 朵价钱 $c_i$、价值 $d_i$；给定 $m$ 条形如"$u_i,v_i$ 要搭配卖"的约束：
买 $u$ 就必须买 $v$，**并且**买 $v$ 就必须买 $u$（题面明确说了"同理"，所以约束是**双向**的）。
预算 $w$，求能获得的最大总价值。

令 $x_i\in\{0,1\}$ 表示是否买第 $i$ 朵，则：

$$\max \sum_i d_i x_i \quad \text{s.t.}\quad \sum_i c_i x_i \le w,\ \ \ x_{u_k}=x_{v_k}\ (k=1..m)$$

$x_{u}=x_{v}$ 是因为"$u\Rightarrow v$ 且 $v\Rightarrow u$"。

**逐句拆题面**

- "他会告诉你一些云朵要搭配起来买才卖，也就是说**买一朵云则与这朵云有搭配的云都要买**"
  → 这不是"打折"或"捆绑优惠"，而是**可行性约束**：搭配关系限制了哪些子集是允许买的。
- "第 $n+2$ 至 $n+1+m$ 行，每行两个整数 $u_i,v_i$。表示买第 $u_i$ 朵云就必须买第 $v_i$ 朵云,**同理**，如果买第 $v_i$ 朵就必须买第 $u_i$ 朵"
  → "**同理**"三个字把每条约束变成了**双向**蕴含，即等式 $x_{u_i}=x_{v_i}$。这一点决定了后面用并查集而不是缩点求 SCC。
- "你肯定是想用现有的钱买到尽量多价值的云"
  → 目标是价值和最大，约束只有钱；不要求花光，所以是"$\le$"型背包，不是"恰好装满"型。
- 可以一朵都不买吗？题面只说"用现有的钱买到尽量多价值"，没有强制至少买一朵。
  因此当所有块都超出 $w$ 时答案应为 $0$，而不是无解。这个边界要在 §5 的用例里覆盖。

**约束与子任务**

| 数据范围 | 规模 |
|---|---|
| 30% | $n\le 100$ |
| 50% | $n,w,c_i,d_i\le 10^3$，$m\le 100$ |
| 100% | $n,w,c_i,d_i\le 10^4$，$0\le m\le 5\times10^3$ |

**题面要点与缺口（以本地题面为准）**

1. 关系双向 $\Rightarrow$ 只需**无向连通块**，并查集足够；标签里的"强连通分量"是通用化说法（见 §2.7，引理 10 说明两者本题等价）。
2. $c_i,d_i\ge1$，$w\ge1$，$m$ 可为 $0$；双向性直接写在本地题面输入格式那一行（"**同理**，如果买第 $v_i$ 朵就必须买第 $u_i$ 朵"），外部提示亦认同（§2.7）。
3. **本地题面没有样例输入/输出**，无法与官方答案对标，验证全靠手算（§4.4 记录状态，§5.1 给出 6 个自造输入）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质 —— 搭配关系把云"焊死"成块

先不急着写代码，把"$u$ 与 $v$ 必须一起买"这个机制推到底。

按题面建**无向图** $G=(V,E)$：$V=\{1,\dots,n\}$，每条搭配 $(u_k,v_k)$ 是一条无向边。
一个购买方案就是子集 $S\subseteq V$，可行当且仅当

$$\forall (u,v)\in E:\ u\in S\iff v\in S$$

**引理 1（单条边的传递闭包）**
若路径 $a=v_0,v_1,\dots,t=v_p\ (p\ge 1)$ 上每对相邻点都是搭配关系，则任何可行方案满足
$a\in S\iff t\in S$。

**证明**：对路径长度 $p$ 归纳。
$p=1$ 时就是边的定义 $a\in S\iff b\in S$。
设结论对长度 $p-1$ 成立。对长度 $p$ 的路径，令 $b=v_{p-1}$，则 $a=v_0,\dots,v_{p-1}=b$ 是长度 $p-1$ 的路径，
由归纳假设 $a\in S\iff b\in S$；又 $(b,t)\in E$，故 $b\in S\iff t\in S$。
两者是"当且仅当"关系，可串联：$a\in S\iff b\in S\iff t\in S$。$\blacksquare$

> 注意这里"$\iff$"的双向性是关键。如果约束只是单向的"$u\in S\Rightarrow v\in S$"，
> 就只能推出 $a\in S\Rightarrow t\in S$，**推不回**，整块同买同卖就不成立了（见 §2.7）。

**引理 2（可行集 = 连通块的并集）**
$S$ 可行 $\iff$ $S$ 是若干完整连通块的并集，即 $\forall$ 连通块 $B$：$B\subseteq S$ 或 $B\cap S=\varnothing$。

**证明**：
（$\Leftarrow$）若 $S$ 是若干完整连通块的并集，任取边 $(u,v)\in E$，则 $u,v$ 同在一个连通块内。
该块要么整体在 $S$ 里（$u,v$ 都在），要么整体不在（$u,v$ 都不在），故 $u\in S\iff v\in S$，$S$ 可行。
（$\Rightarrow$）反设存在连通块 $B$ 使 $B\cap S\ne\varnothing$ 且 $B\setminus S\ne\varnothing$。
取 $a\in B\cap S$，$t\in B\setminus S$。因 $a,t$ 在同一连通块，图中存在 $a$ 到 $t$ 的路径，
由引理 1 得 $a\in S\iff t\in S$，与 $a\in S,\ t\notin S$ 矛盾。$\blacksquare$

**推论**：一个连通块在决策时**不可分割**，它等价于一个"新商品"：

$$\text{块 }B\text{ 的价钱 } C_B=\sum_{i\in B}c_i,\qquad \text{块 }B\text{ 的价值 } D_B=\sum_{i\in B}d_i$$

于是原问题里"$n$ 朵云 + 等式约束"塌缩成"若干块 + 无约束"。
**机制小结**：先做**结构压缩**（并查集求块，$O((n+m)\alpha(n))$，比 Tarjan 求 SCC 简单得多），再做**数值优化**（背包）。

### 2.2 简化版 —— 先把 $m=0$ 想清楚

取 $m=0$（题面允许 $m=0$），此时没有搭配，问题就是：

$$\max \sum d_i x_i\ \ \text{s.t.}\ \ \sum c_i x_i\le w,\ \ x_i\in\{0,1\}$$

这正是 **0/1 背包**。先在小数据上把简化版解掉，确认自己理解无误：

> 简化版手算：$n=3$，$w=5$，$(c,d)$ 分别是 $(2,3),(3,5),(4,6)$。
> 全部子集（$2^3=8$ 个）里满足价钱 $\le 5$ 的：
> $\varnothing\to0$，$\{1\}\to3$，$\{2\}\to5$，$\{3\}\to6$，$\{1,2\}\to 2+3=5\le 5,\ 3+5=8$，
> $\{1,3\}\to 6>5$ 不可行，$\{2,3\}\to 7>5$ 不可行，$\{1,2,3\}\to 9>5$ 不可行。
> 最优值 $8$（买 $\{1,2\}$）。

**引理 3（简化版不能用"排序 + 取前缀"解）**
存在 $n,w,c_i,d_i\le 10^4$ 的实例，使"按任意单项比率（价值/价钱、价值、价钱）排序后贪心取前缀"得到的价值严格小于最优值。

**证明**：构造性给出，见 §2.3 的三个反例，每个都列出贪心结果与最优结果的具体数值。$\blacksquare$

有了反例，说明**必须保留"选哪些块"这个组合信息**，这就是 DP 状态 $j$（已花的钱）的来源。

**30% 分档（$n\le100$）**：块数 $\le 100$，$w$ 可到 $10^4$，$O(nw)=10^6$，DP 已经轻松够。
所以从 30% 到 100%，复杂度的瓶颈**不在**"是否用 DP"，而在"$w$ 会不会太大"，
这暗示正解就是 DP，只需把常数与循环规模压住。

### 2.3 剖析贪心失败

我一开始的思路很自然："每块算性价比 $D_B/C_B$，排序后从大到小装"。下面用 4 组具体小数据把它逐个打掉。
每组都给出**贪心轨迹**与**穷举最优值**，方便复核。

**(a) 直接忽略搭配约束**

$w=10$；云 1$(c=2,d=10)$、云 2$(c=8,d=1)$ 且 $(1,2)$ 是搭配；云 3$(5,9)$、云 4$(5,9)$ 无搭配。
按单朵性价比排序：云 1(5.0)、云 3(1.8)、云 4(1.8)、云 2(0.125)。
贪心依次装：云 1（用 $2$，价值 $10$）→ 云 3（用 $7$，价值 $19$）→ 云 4 需 $12>10$ 拒 → 云 2 需 $15>10$ 拒 ⇒ 报 $19$。
但 $\{1,3,4\}$ **不可行**：买了云 1 却不买云 2。真实可行解是 $\{3,4\}$（价值 $18$）或 $\{1,2\}$（价值 $11$），最优 $18$。
⇒ 不合并就 DP，得到的数字连"能不能买到"都不保证。

**(b) 合并后按性价比贪心**

$w=10$，三个块：$A$：$C=6,D=12$（比率 $2.0$）；$B$：$C=5,D=9$（$1.8$）；$C'$：$C=5,D=9$（$1.8$）。
贪心：装 $A$（用 $6$，剩 $4$）→ $B$ 装不下 → $C'$ 装不下 ⇒ $12$。
穷举：$\{B,C'\}$ 价钱 $10\le w$，价值 $18$ ⇒ 最优 $18$。
$12<18$，贪心**差 6**，而且 $A$ 的比率最高，说明"先拿最优比率"本身就错。

**(c) 按价值降序贪心**

$w=10$，块：$A$：$C=9,D=15$；$B$：$C=5,D=9$；$C'$：$C=5,D=9$。
贪心：装 $A$（剩 $1$）⇒ $15$。穷举：$\{B,C'\}=18>15$。

**(d) 按价钱升序（"先买便宜的块，剩下再填缝"）贪心**

$w=10$，块：$A$：$C=2,D=2$；$B$：$C=5,D=100$；$C'$：$C=5,D=100$。
贪心：$A$（用 $2$）→ $B$（用 $7$）→ $C'$ 需 $12>10$ 拒 ⇒ $102$。穷举：$\{B,C'\}=200$。

**为什么贪心注定失败？** 因为容量是**整数且不可拆分**，"装下一个大件"会永久浪费掉不足一件大小的余量。

**引理 4（分数背包上比率贪心确实最优）**
若允许把物品**按比例切碎**买（买 $\lambda$ 份付 $\lambda C$、得 $\lambda D$，$0\le\lambda\le1$），
则"按 $D/C$ 降序填到容量满"给出最优解。

**证明**：把物品按 $r_i=D_i/C_i$ 降序排好（$r_1\ge r_2\ge\dots\ge r_n$），并把"在第 $i$ 项上花的钱"
$\mu_i=\lambda_iC_i\in[0,C_i]$ 当决策变量，则价值 $V=\sum_i r_i\mu_i$，约束 $\sum_i\mu_i\le w$。
贪心解 $G$ 的形状是：存在下标 $t$ 使 $\mu_i^G=C_i\ (i<t)$，$\mu_t^G=w-\sum_{i<t}C_i\in[0,C_t]$，$\mu_i^G=0\ (i>t)$。
任取可行解 $\mu^S$，分两步：

1. **先假设 $S$ 也花满 $w$**（$\sum_i\mu_i^S=w=\sum_i\mu_i^G$）。
   于是对任意常数 $\theta$，$\sum_i(\mu_i^G-\mu_i^S)=0$ 保证
   $\sum_ir_i(\mu_i^G-\mu_i^S)=\sum_i(r_i-\theta)(\mu_i^G-\mu_i^S)$。取 $\theta=r_t$：
   - $i<t$：$r_i-\theta\ge0$，且 $\mu_i^G=C_i\ge\mu_i^S$，乘积 $\ge0$；
   - $i=t$：$r_i-\theta=0$，乘积 $=0$；
   - $i>t$：$r_i-\theta\le0$，且 $\mu_i^G=0\le\mu_i^S$，故 $\mu_i^G-\mu_i^S\le0$，乘积仍 $\ge0$。

   三组相加：$V(G)-V(S)=\sum_i(r_i-r_t)(\mu_i^G-\mu_i^S)\ge0$。
2. **$S$ 没花满时先补满**：若 $\sum_i\mu_i^S<w$，按 $i=1,2,\dots$ 顺序把空闲容量填进还没到上限（$\mu_i<C_i$）的项，
   被填的项比率不小于任何后面项的比率，故价值单调不减，直到花满 $w$ 或所有 $\mu_i=C_i$（后者已是全局上界）。
   补满后的 $S'$ 价值 $\ge$ 原 $S$，再由第 1 步 $V(G)\ge V(S')$，故 $V(G)\ge V(S)$。

综上 $G$ 不劣于任意可行分数解，即比率贪心在分数背包中最优。$\blacksquare$

**推论（0/1 破坏它）**：0/1 约束就是给引理 4 加了 $\lambda_i\in\{0,1\}$。
引理 4 证明里"把 $S$ 的空闲容量补给第 $t$ 项"这一步在 0/1 下**做不到**，
反例 (b) 正是 $A$ 之后剩 $4$ 却无件可用，而 $B,C'$ 各需 $5$。
⇒ 必须用 DP 保留"每种余量"的最优值，这是下一步。

### 2.4 经典解法 —— 并查集合并 + 分组 0/1 背包

块求出来以后（设共有 $k$ 块，编号 $1..k$，第 $b$ 块 $(C_b,D_b)$），做标准 0/1 背包。

**DP 定义**

$$dp[j]=\text{只考虑已处理过的前若干块时，总价钱}\le j\text{ 的最大可获得价值}\qquad(0\le j\le w)$$

初始 $dp[j]=0$（一块都不买，价值 $0$，且对任何 $j\ge0$ 都可行）。

**转移**（依次处理每块，每块内 $j$ 从 $w$ **递减**到 $C_b$）：

$$dp[j]\leftarrow\max\big(dp[j],\ dp[j-C_b]+D_b\big)$$

**引理 5（"不超过 $j$"与"恰好花满"两种语义等价，且 $dp$ 单调）**
本题 $c_i,d_i\ge1$，用 $dp[j]=$"总价钱 $\le j$ 的最大价值"定义时：
(i) $dp$ 单调不降：$j_1<j_2\Rightarrow dp[j_1]\le dp[j_2]$；
(ii) 答案就是 $dp[w]$，不需要 $\max_{j\le w}dp[j]$；
(iii) 若改用"恰好花掉 $j$"语义（不可达记 $-\infty$），得到的最优值与 (i)(ii) 相同。

**证明**：
(i) 任何价钱 $\le j_1$ 的方案也满足 $\le j_2$（$j_1<j_2$），故 $j_2$ 可选方案集合包含 $j_1$ 的，
在非负价值集合上取 $\max$，包含者更大：$dp[j_2]\ge dp[j_1]$。
(ii) 由 (i) 直接 $dp[w]=\max_{0\le j\le w}dp[j]$，即"预算不超过 $w$"的全部可行方案中的最优值。
(iii) 设"恰好"语义下 $e[j]=$ 恰好花 $j$ 的最大价值，$e^\*=\max_{j\le w}e[j]$（不可达记 $-\infty$，至少 $e[0]=0$ 可达）。
对任意方案，其实际花费 $j_0\le w$，在 $e[j_0]$ 中被考虑，故 $e^\*\ge dp[w]$；
反之 $e$ 的每个可达值都对应一个"花费恰为 $j$ 因而 $\le j$"的方案，故 $e[j]\le dp[j]\le dp[w]$，取 $\max$ 得 $e^\*\le dp[w]$。
两边夹住 $e^\*=dp[w]$。$\blacksquare$

> 所以 §5 代码里 $dp$ 全 $0$ 起步、直接输出 $dp[w]$ 是合法的；
> 但若题面改成"至少得买一块"或允许 $d_i<0$（"什么都不买"不再是合法的基准解），
> 初值就必须换成 $-\infty$ 起步 + $dp[0]=0$ 的"恰好"语义，这是常见坑。

**引理 6（倒序循环保证"每块最多用一次"）**
处理块 $b$ 时，若 $j$ 从 $w$ 递减到 $C_b$ 更新，则转移中用到的 $dp[j-C_b]$ 一定是**只含前 $b-1$ 块**的旧值；
若改成升序，则可能重复取同一块多次。

**证明**：外层按块顺序处理。归纳假设：进入块 $b$ 的循环前，$dp[\cdot]$ 等于"前 $b-1$ 块"的答案。
考虑降序访问的某个 $j$，此时 $j-C_b<j$，而降序意味着比 $j$ 大的下标已更新完、比 $j$ 小的还没被碰过，
所以 $dp[j-C_b]$ 仍是进入块 $b$ 之前的值，即"前 $b-1$ 块、预算 $j-C_b$"的最优解；加上块 $b$ 后总花费 $\le j$、
价值 $+D_b$，正对应"前 $b$ 块且**含**块 $b$"的候选。另一支 $dp[j]$（旧值）对应"前 $b$ 块但不含块 $b$"。
两者取 $\max$ 后 $dp[j]$ 恰为"前 $b$ 块"的答案，归纳完成。
降序时 $j-C_b\ne j$（因 $C_b\ge1$）保证读写的不是同一个格子；若 $C_b=0$ 降序也会自我污染，本题 $c_i\ge1$ 排除了该情况。
升序时相反：更新 $dp[j]$ 之后紧接着更新的 $dp[j+C_b]$ 会读到**已含块 $b$** 的 $dp[j]$，等于允许一块买多份。
例如 $C=2,D=3,w=5$，升序得 $dp[2]=3,dp[4]=6,dp[5]=6$（同一块用了两次），降序得 $dp[5]=3$。$\blacksquare$

**引理 7（DP 最优子结构）**
"前 $b$ 块、预算 $j$"的最优方案 $S$：若 $b\in S$，则 $S\setminus\{b\}$ 是"前 $b-1$ 块、预算 $j-C_b$"的最优方案；
若 $b\notin S$，则 $S$ 本身是"前 $b-1$ 块、预算 $j$"的最优方案。

**证明**：两支都用切割法（cut-and-paste）。
第一支反设存在 $S'\subset\{1..b-1\}$，花费 $\le j-C_b$ 而价值 $>V(S\setminus\{b\})$，则 $S'\cup\{b\}$ 花费
$\le (j-C_b)+C_b=j$、价值 $>V(S)$，且仍合法（块是不可分割单位，$S'$ 是整块集合），与 $S$ 最优矛盾。
第二支反设存在 $S''\subset\{1..b-1\}$ 花费 $\le j$ 且价值 $>V(S)$，则 $S''$ 直接是"前 $b$ 块、预算 $j$"的更优方案，矛盾。$\blacksquare$

引理 5、6、7 合起来给出：**转移方程覆盖了所有子集，且不重复计数、不遗漏最优**。

### 2.5 归约：带等式约束的背包 $\to$ 普通 0/1 背包

**引理 8（问题等价 / 解双射）**
设 $G$ 的连通块为 $B_1,\dots,B_k$，$C_b=\sum_{i\in B_b}c_i$，$D_b=\sum_{i\in B_b}d_i$。则

$$\Phi:\ T\subseteq\{1,\dots,k\}\ \longmapsto\ S=\bigcup_{b\in T}B_b$$

是"块背包可行解集"到"原问题可行解集"的双射，且 $\sum_{b\in T}C_b=\sum_{i\in S}c_i$、$\sum_{b\in T}D_b=\sum_{i\in S}d_i$。

**证明**：
- **双射性**。$\Phi$ 是单射：连通块两两不交且非空，若 $T_1\ne T_2$，取 $b$ 属于其一不属于另一，则 $B_b$ 整体在其中一个像里、不在另一个里，两像不同。
  $\Phi$ 在"块背包解"上取到的 $S$ 显然是若干完整块的并，由引理 2 可行；反过来由引理 2，任何可行 $S$ 都是完整块的并，
  令 $T=\{b:B_b\subseteq S\}$ 即 $\Phi(T)=S$，故也是满射（在可行集之间）。
- **权重守恒**。$\sum_{i\in\Phi(T)}c_i=\sum_{b\in T}\sum_{i\in B_b}c_i=\sum_{b\in T}C_b$，
  第二个等号用到了"$B_b$ 两两不交"（可交换求和顺序）。$D$ 同理。
- **可行性对应**。$S$ 满足 $\sum_i c_i\le w$ $\iff$ $\sum_{b\in T}C_b\le w$（上一条），这正是块背包的容量约束；
  块背包没有别的约束，而原问题除容量外的约束（等式）已经被引理 2 完全编码进"块不可分割"。
- **目标值一致**。由权重守恒，两问题的目标函数在同一对对应解上取值相同，故最优值相等，且块背包的最优解经 $\Phi$ 就是原问题最优解。$\blacksquare$

**引理 9（"整块买不起就丢弃"剪枝正确）**
若某块 $C_b>w$，则存在最优解不含 $B_b$，DP 里直接跳过它不改变答案。

**证明**：任何含 $B_b$ 的方案 $S$，$\sum_{i\in S}c_i\ge\sum_{i\in B_b}c_i=C_b>w$（因为 $c_i\ge0$，子集和不超全集和），
不满足预算，本来就不可行。故可行解全都不含 $B_b$，跳过它等价于不生成这个物品，最优值不变。$\blacksquare$

**实现层面的对应**：代码里"枚举 $i=1..n$，只处理 $f[i]==i$ 的 $i$"就是枚举 $B_1..B_k$（每个块恰好有一个根代表），
所以循环次数是 $k\le n$，DP 转移对每块恰好一次 —— 与引理 8 的 $\{1..k\}$ 一一对应。
若错误地对所有 $i$ 都转移，会把同一个块重复计入多次（等价于"允许一块买多份"），破坏 0/1 语义。

### 2.6 溢出防护与复杂度

**逐项估量级（$n,w,c_i,d_i\le10^4$，$m\le5\cdot10^3$）**

| 量 | 上界 | 是否溢出 `int`(≈$2.1\times10^9$) | 处理 |
|---|---|---|---|
| 单块价钱 $C_b$ | $n\cdot\max c=10^4\cdot10^4=10^8$ | 不溢出，只剩 20 倍余量 | 累加用 `i64`，再 `min` 到 $w+1$ 或直接判 $>w$ |
| 单块价值 $D_b$ | $10^8$ | 同上 | `i64` |
| $dp[j]$ | $\le\sum_i d_i=10^8$ | 不溢出 | `i64` |
| 转移 $dp[j-C_b]+D_b$ | $\le 10^8$（两支来自**不交**的块集，见引理 8 权重守恒） | 不溢出 | `i64` |

结论：`int` 在本数据范围**够用**，但余量只有一档；把 $dp$、$C_b$、$D_b$ 写成 `i64`
只多花几十 KB（$10^4$ 个 `i64` = 80KB），换来"$c,d$ 上限若变成 $10^5$ 也不用改代码"的稳健性，值得。
反过来 $j$、$C_b$ 参与**下标运算**时又要收回 `int`（`int cst=(int)cost[i];`），
避免 `int - i64` 得到 `i64` 下标带来的隐式转换与编译警告，也顺带证明"$j-\text{cst}\ge0$ 由循环条件保证"。

**时间复杂度**

- 并查集：$O((n+m)\alpha(n))\le O(1.5\times10^4)$，可忽略。
- 累加：$O(n\alpha(n))$。
- 背包：$O\big(\sum_{b:\,C_b\le w}(w-C_b+1)\big)\le O(k\cdot w)\le 10^4\times10^4=10^8$。

**最坏情况真能打到吗？** 能：$m=0$、$n=10^4$、$\forall i,\ c_i=1$、$w=10^4$，
此时 $k=10^4$ 且每块 $C_b=1$，内层循环次数 $\approx 10^8$。
每次循环体只有一个 `max` + 一次加法 + 一次数组读写，常数极小（$O(10^8)$ 简单整数操作在现代评测机上约 $0.2\sim0.5$s）。
若真被卡，可用的加速是"前缀和封顶"：维护 `int lim=0;`，每块 `lim=min<i64>(lim+cst,w);` 后让 $j$ 从 `lim` 递减——
因为预算超过"已处理块总价"时 $dp[j]$ 不可能再变大，等于把内层长度压到 $\min(w,\text{prefix})$；
在上面那组最坏数据里 prefix 最终只到 $10^4$，总次数约 $\sum_{t=1}^{10^4}t=5\times10^7$，直接砍半。
（§5 代码保持朴素写法以便对照证明，注释里标出这一层可加的位置。）

**空间**：$O(n+w)$ 个 `i64` + `int` 数组，约 $300$KB，远低于限制。

**实现陷阱（每条都是真会写错的地方）**

1. **必须先读完所有搭配边、再做块权值累加**。若边还在读就把 $c_i$ 加到当前根上，之后合并会漏/重。
2. 累加时加到 `r=getrt(i)` 而不是 `i`；`i` 可能不是根。
3. 判根 `f[i]==i` 之所以可靠，是因为累加循环对**每个** $i$ 都调了 `getrt(i)`，把 $i$ 自己压缩到了根上；
   非根的 $f[i]$ 必为 $r\ne i$。若删掉那个循环，判根就会错。
4. 内层上界是 $w$，不是 $\sum C_b$（后者可达 $10^8$，会 MLE/TLE）。
5. 自环 $u=v$、重复边都被 `if(u!=v)` 天然吸收，不需要特判。
6. `getrt` 递归深度：边按 $(2,1),(3,2),(4,3),\dots$ 顺序给时会形成 $1\to2\to3\to\dots$ 的链，
   深度可达 $m+1\le5001$，栈上安全；且第一次查询后路径压缩就把它拉平了。

### 2.7 如果搭配是单向的？—— "强连通分量"标签的来历

题面标签里同时给了"并查集"和"强连通分量"，容易让人以为要做 Tarjan。想清楚两种解读的差别：

**解读 A（题面，双向）**："$u\Rightarrow v$ 且 $v\Rightarrow u$"。等式约束，用并查集。
**解读 B（假想，单向）**：只有"$u\Rightarrow v$"。此时只能得到 $a\in S\Rightarrow t\in S$（引理 1 的反向失效），
可行集是"**后继封闭**"集合：一旦选了某点就必须选它所有可达点。

**引理 10（双向图里 SCC = 连通块）**
把每条搭配 $(u,v)$ 看成两条有向边 $u\to v$、$v\to u$ 得到有向图 $D$。则 $D$ 的强连通分量与 $G$ 的连通块完全一致。

**证明**：
（$\Rightarrow$）若 $p,q$ 同属一个 SCC，则 $D$ 中有 $p$ 到 $q$ 的有向路径，该路径在 $G$ 里也是 $p,q$ 的一条路径，故同块。
（$\Leftarrow$）若 $p,q$ 同属 $G$ 的一个连通块，取 $G$ 中路径 $p=v_0,v_1,\dots,v_s=q$。
每条无向边 $(v_{i-1},v_i)$ 在 $D$ 中对应 $v_{i-1}\to v_i$ 与 $v_i\to v_{i-1}$ 两条有向边，
于是 $v_0\to v_1\to\dots\to v_s$ 是 $D$ 中 $p\to q$ 的有向路径，反向 $q\to p$ 同理，
$p,q$ 互相可达，属同一 SCC。$\blacksquare$

**所以**：本题用并查集与用 Tarjan 缩点得到**同一个划分**，但并查集代码更短、无栈深风险，故选并查集。
标签里的"强连通分量"是在提示"$u\Rightarrow v$ 类约束的通用处理是缩点"，属于思路外溢，不是必需步骤。
若真按解读 B 做，可行集要沿缩点后的 DAG 做"选了父亲必须选儿子"的**依赖背包**（DAG 版一般按树/森林处理），
比本题的"块 + 普通背包"复杂一个档次。

**外部提示核对（不冲突，仍以本地题面为准）**：本地 `P1455.md` 第 23 行的"**同理**"已经确定双向；
另有题面说明栏（不在本地文件里，属外部提示）进一步写明"$u,v$ 是双向关系"，并提到"除强连通分量外也可直接求无向图的弱连通分量"。
两者与本文一致，而"弱连通分量 = 连通块 = SCC"正是引理 10，故实现选并查集。

## 3. 模式总结（Pattern Summary）

**模式名：约束闭包 → 缩成整块 → 单约束 0/1 背包（"合并再装包"两步法）**

**识别信号**（看到其中两条就该往这个模式靠）

1. 题面出现"必须一起买 / 选了 A 就得选 B / 依赖关系"这类**布尔等式或蕴含约束**。
2. 约束条数 $m$ 与 $n$ 同量级（$m\le 5\times10^3$），说明它是**结构**信息而非数量信息，先用图论处理。
3. 目标只受**一个**线性约束（钱/容量 $\le w$），且 $w$ 只有 $10^4$ —— 容量维度可以开数组，即"伪多项式 DP 能吃下"。
4. 每项的价值与价钱**互不成比例**（$d_i/c_i$ 各不相同），提示贪心不可靠（§2.3 的四组反例）。

**套路步骤**

1. 把约束画成图，判明**方向**：双向 → 并查集（连通块）；单向 → 缩点（SCC）后做依赖背包。
2. 求块，**先把所有边合并完**，再一次性把点权累加到根上（避免中途合并导致的漏加）。
3. 块权值累加时顺手把 $C_b>w$ 的块判死（引理 9），减少物品数。
4. 在块上做标准 0/1 背包：$dp[j]$ 语义按引理 5 选——价值非负且无"必须花完"要求时用"$\le j$"（初值 $0$）最省事。
5. 内层**倒序**（引理 6）；上界取 $w$ 而非 $\sum C_b$。
6. 答案 $dp[w]$。

**同族题**：P2014 选课（单向依赖 → 树上背包，与本模式只差第 1 步的方向判断）、
P3387 缩点（"先缩结构再 DP"的模板，只是 DP 换成长路）、
任何"捆绑商品/成套装备 + 预算"的题。

**一句话记忆**：**"结构先塌缩，数值再背包"**——把等式约束吃进"物品粒度"，剩下的就是模板。

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 类型 / 尺寸 |
|---|---|---|
| $n,m,w$ | 云数 / 搭配数 / 预算 | `int`，$\le10^4,5\cdot10^3,10^4$ |
| `c[i]`,`d[i]` | 第 $i$ 朵云的价钱与价值（$1\le i\le n$，照题面 1-based） | `int[mxn]` |
| `f[i]` | 并查集父指针，初始 `f[i]=i` | `int[mxn]` |
| `getrt(x)` | 查根 + 路径压缩 | 引用 `f` |
| `cost[r]`,`val[r]` | 只在**根** $r$ 上有意义：所在块的总价钱 / 总价值 | `i64[mxn]` |
| $k$ | 块数（= 根的个数），$k\le n$ | 概念量，代码里不出现 |
| `dp[j]` | 已处理的若干块中，总价钱 $\le j$ 的最大价值 | `i64[mxn]`，用 $[0,w]$ |
| `cst` | 当前块总价钱的 `int` 视图（已由 $C_b\le w$ 保证 $\le10^4$） | `int` |
| `mxn{10005}` | 一份尺寸同时服务 $n\le10^4$ 与 $w\le10^4$ 两类下标 | `constexpr int` |

### 4.2 编号步骤

- **S1 读入并建 $n$ 个单点块**：$f[i]\leftarrow i$，同时存下 $c_i,d_i$。（$1\le i\le n$）
- **S2 合并**：对每条搭配 $(u,v)$，$r_u\leftarrow\text{getrt}(u)$，$r_v\leftarrow\text{getrt}(v)$，若 $r_u\ne r_v$ 令 $f[r_v]\leftarrow r_u$。
  这一步之后，$i,j$ 同块 $\iff$ $\text{getrt}(i)=\text{getrt}(j)$（引理 1、2、10）。
- **S3 累加块权值**：$r\leftarrow\text{getrt}(i)$，$\text{cost}[r]\mathrel{+}=c_i$，$\text{val}[r]\mathrel{+}=d_i$。
  **必须在 S2 全部完成后执行**（§2.6 陷阱 1）。此循环同时把每个点压缩到根，使 S4 的 `f[i]==i` 判根成立（陷阱 3）。
- **S4 生成物品表**：枚举 $i=1..n$，保留满足 $f[i]==i$ 且 $\text{cost}[i]\le w$ 的 $i$，得到 $k'\le k$ 个物品 $(\text{cost}[i],\text{val}[i])$。
  丢弃的部分由引理 9 保证不影响最优值；保留的部分与引理 8 的 $\{1..k\}$ 一一对应。
- **S5 初始化**：`fill_n(dp,w+1,0)`，语义"预算 $\le j$，一块都没处理"，由引理 5 的初值论证合法（一块不买永远可行且价值 $0$，
  且 $d_i\ge0$ 使 $0$ 是下界）。
- **S6 倒序转移**：对每个物品，`cst=(int)cost[i]`，`for(j=w;j>=cst;--j) dp[j]=max(dp[j],dp[j-cst]+val[i])`。
  正确性 = 引理 7（最优子结构给出两支）+ 引理 6（倒序保证每块至多用一次）。
- **S7 输出** `dp[w]`：由引理 5(i)(ii) 它就是"价钱 $\le w$"的全局最优值。

### 4.3 复杂度

$$T=O\big((n+m)\alpha(n)\big)+\underbrace{\sum_{b:\,C_b\le w}(w-C_b+1)}_{\le\, k\cdot w\,\le\,10^8}\,=\,O(10^8)$$

空间 $O(n+w)$（`i64` 数组若干，$\approx300$KB）。最坏输入见 §2.6。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};			// n<=10^4 与 w<=10^4 同尺寸够用

int n,m,w;
int c[mxn],d[mxn];				// 单朵云的价钱 / 价值（1-based，照题面编号）
int f[mxn];						// 并查集父指针
i64 cost[mxn],val[mxn];			// 挂在根上：整块的总价钱 / 总价值
i64 dp[mxn];					// dp[j]：预算不超过 j 时的最大价值

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);		// 链状最坏递归深度 m+1<=5001，安全
}

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>w;
	for(int i=1;i<=n;++i)
	{
		cin>>c[i]>>d[i];
		f[i]=i;					// S1：先建 n 个单点块
	}
	for(int i=1,u,v;i<=m;++i)
	{
		cin>>u>>v;
		u=getrt(u);v=getrt(v);
		if(u!=v)
			f[v]=u;				// S2：只合并，块权值延后统一累加；自环/重边被 if 吸收
	}
	for(int i=1;i<=n;++i)
	{
		int r=getrt(i);
		cost[r]+=c[i];val[r]+=d[i];	// S3 be careful here: 必须在所有 union 之后
	}
	fill_n(dp,w+1,0LL);			// S5：d_i>=0 -> "一块不买"恒可行且价值 0，无需 -INF
	for(int i=1;i<=n;++i)
	{
		if(f[i]!=i||cost[i]>w)		// S4：非根跳过；整块买不起直接丢弃
			continue;
		int cst=(int)cost[i];		// 已保证 cst<=w<=10^4，收回 int 做下标
		// 可选优化：int lim=min<i64>(lim+cst,w); 内层从 lim 递减，见 §2.6
		for(int j=w;j>=cst;--j)		// S6：倒序 = 每块最多用一次
			dp[j]=max(dp[j],dp[j-cst]+val[i]);
	}
	cout<<dp[w]<<'\n';			// S7
	return 0;
}
```

### 5.1 手算用例（本地题面无样例，以下全部自造）

**用例 1（$m=0$，只检验背包）** 输入 `3 0 5`，云 $(c,d)=(2,3),(3,5),(4,6)$。三朵云各自成块。

| 处理完 | dp[0] | dp[1] | dp[2] | dp[3] | dp[4] | dp[5] |
|---|---|---|---|---|---|---|
| 初值 | 0 | 0 | 0 | 0 | 0 | 0 |
| 块 1 $(2,3)$ | 0 | 0 | 3 | 3 | 3 | 3 |
| 块 2 $(3,5)$ | 0 | 0 | 3 | 5 | 5 | **8** |
| 块 3 $(4,6)$ | 0 | 0 | 3 | 5 | 6 | 8 |

块 2：$dp[5]=\max(3,\,dp[2]+5=3+5)=8$；块 3：$dp[5]=\max(8,\,dp[1]+6=6)=8$。输出 $8$，
与 §2.2 的 $2^3$ 全枚举最优 $\{1,2\}\to8$ 一致 ✔

**用例 2（有搭配 + 贪心会栽）** 输入 `4 1 10`，云 $(6,12),(5,9),(5,9),(1,1)$，搭配 $(2,3)$。
S2：$u=\text{getrt}(2)=2,\ v=\text{getrt}(3)=3\Rightarrow f[3]\leftarrow2$。
S3：根 $1,2,4$，$(C,D)=(6,12),(10,18),(1,1)$ —— 云 3 的 $5+9$ 被并进块 2，$i=3$ 因 $f[3]=2\ne3$ 在 S4 被跳过。
只列 $j=10$ 这一列的轨迹：$0\xrightarrow{\text{块1}}12\xrightarrow{\text{块2}}\max(12,dp[0]+18){}=18\xrightarrow{\text{块4}}\max(18,dp[9]+1)=18$。输出 $18$。
对照：按 $D/C$ 降序贪心先取块 1（比率 $2.0$）剩 $4$ 元塞不进任何块，只到 $12+1=13$；
全枚举可行块集 $\{1\}=12,\{2\}=18,\{4\}=1,\{1,4\}=13$（含块 2 的其余组合价钱 $\ge 11$）⇒ 最优 $18$ ✔（正是 §2.3(b) 的实例）。
