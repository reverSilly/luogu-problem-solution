# P1525 [NOIP 2010 提高组] 关押罪犯

> 标签：图论 / 贪心 / 二分图判定 / 扩展域并查集 / 二分答案 · 难度：提高/省选-
> 本地题面：`P1525.md`（$N\le 2\times 10^4,\,M\le 10^5,\,0<c_j\le 10^9$）。本文所用官方样例取自洛谷原题页 P1525（见 §4.4）。

## 1. 重新读题

**问题重述（人话版）**

有 $N$ 名罪犯（编号 $1\sim N$）和两座监狱。给定 $M$ 条仇恨关系 $(u_j,v_j,w_j)$：若 $u_j$ 与 $v_j$ 被分在**同一座**监狱，就会爆发影响力为 $w_j$ 的冲突。

请将 $N$ 名罪犯分配到两座监狱（每人恰好去一座，允许某座监狱为空），使得**所有处于同一座监狱的仇恨对中，最大冲突影响力尽可能小**。输出这个最小可能的最大影响力；若可以做到没有任何仇恨对处于同一监狱，输出 `0`。

> 一句话版本：**给定无向带权图 $G=(V,E,w)$，求顶点集二划分 $V=A\sqcup B$，最小化同侧边权的最大值 $\max_{(u,v)\in E(A)\cup E(B)}w(u,v)$（若 $G$ 本身是二分图则答案为 $0$）。**

**题面里容易漏掉的条款**

1. **只看最大的一条同狱边（瓶颈目标，而非求和）** $\Rightarrow$ Z 市长只看列表里的第一个事件（最大值）。这意味着只要某条大权边爆发了冲突，其它比它小的边爆不爆发完全不影响结果——这是典型的**瓶颈（Bottleneck / Min-Max）结构**，天然指向按边权降序贪心或二分答案。
2. **整张图可能是二分图（包括 $M=0$）** $\Rightarrow$ 此时所有边都能跨两座监狱放置，没有任何冲突，必须输出 `0`。
3. **并查集扩展域数组要开 $2N$** $\Rightarrow$ 每个罪犯 $u\in[0,N)$ 有“自身所在监狱域 $u$”和“敌对监狱域 $u+N$”两个虚拟结点，若并查集数组只开 `mxn` 而不乘 $2$，会在访问 `u+n` 时直接越界 RE。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：怎样的边集可以“零冲突”关押？

先把权值放一边，问一个最基本的问题：如果规定某批仇恨对 $E'\subseteq E$ **绝对不准**关在同一座监狱，什么时候能办到？

**引理 1（零冲突可分性 $\iff$ 二分图 / 无奇环）**

边子集 $E'\subseteq E$ 中的所有罪犯对都能被分在不同监狱（即存在二染色 $c:V\to\{0,1\}$ 使 $\forall (u,v)\in E',\,c(u)\ne c(v)$），当且仅当子图 $G'=(V,E')$ 是**二分图**（等价于 $G'$ 中不存在奇数长度的环）。

**证明**：将两座监狱记为颜色 $0$ 和 $1$。“$(u,v)$ 不在同一监狱”即 $c(u)\ne c(v)$，这恰为图论中合法二染色的定义；由 König 定理，无向图可二染色当且仅当图中不含奇环。$\blacksquare$

### 2.2 从二分判定到按边权降序贪心（附完整证明）

由引理 1，如果我们猜一个阈值 $W$，要求所有 $>W$ 的边都不爆发冲突，就等价于判断子图 $E_{>W}=\{(u,v)\in E:w(u,v)>W\}$ 是否为二分图（可用二分答案 + 染色在 $O((N+M)\log(\max w))$ 内解决）。

但我们甚至不需要二分答案！把所有边按权值从大到小排序：$w(e_1)\ge w(e_2)\ge\dots\ge w(e_M)$，依次往图里加边并维护“哪些点必须在同一监狱、哪些点必须在不同监狱”的等价关系，**第一条引发奇环（即两端点已被迫处于同一监狱）的边 $e_k$，其权值 $w(e_k)$ 就是答案**！

**引理 2（降序贪心首条奇环边即为全局最优解）**

将边按 $w(e_1)\ge w(e_2)\ge\dots\ge w(e_M)$ 排序。设 $k$ 是使得前缀边集 $\{e_1,e_2,\dots,e_k\}$ 不是二分图的**最小下标**（若 $\{e_1,\dots,e_M\}$ 仍是二分图，则答案为 $0$）。则最小可能的最大同狱冲突值恰等于 $w(e_k)$。

**证明**：

- **下界（任何划分方案的最大冲突值 $\ge w(e_k)$）**：因为 $\{e_1,\dots,e_k\}$ 不是二分图，由引理 1 知，在**任何**二划分方案 $V=A\sqcup B$ 下，$\{e_1,\dots,e_k\}$ 中都至少有一条边 $e_i\ (1\le i\le k)$ 的两端点落在同一座监狱。由于边按权值降序排列，该冲突边的权值满足 $w(e_i)\ge w(e_k)$，故该方案的最大冲突值 $\ge w(e_i)\ge w(e_k)$。
- **上界（存在划分方案使最大冲突值 $\le w(e_k)$）**：由 $k$ 的最小性，前缀 $\{e_1,\dots,e_{k-1}\}$ 是二分图！取 $\{e_1,\dots,e_{k-1}\}$ 的任意一个合法二染色方案 $V=A\sqcup B$，则 $e_1,\dots,e_{k-1}$ 全部两端异侧（不爆发冲突），唯一可能爆发冲突的边只来自 $\{e_k,e_{k+1},\dots,e_M\}$，其权值均 $\le w(e_k)$。因此该方案的最大冲突值 $\le w(e_k)$。
- 上下界重合，故最优值恰为 $w(e_k)$。$\blacksquare$

### 2.3 经典数据结构：扩展域并查集（Enemy DSU）动态判奇环

如何在按序加边 $e=(u,v)$ 时，在线维护二染色等价类并 $O(\alpha(N))$ 判定是否产生奇环？

为每个点 $x\in[0,N)$ 设立两个状态点：
- **同狱点 $x$**：代表“与 $x$ 分在同一座监狱”；
- **敌对点 $x+N$**：代表“与 $x$ 分在不同监狱”。

**引理 3（扩展域并查集的不变量与奇环判定）**

在依次处理边 $e_1,\dots,e_{i-1}$（设它们构成二分图）的过程中，对每条边 $(u,v)$ 执行合并 `merge(u, v+N)` 与 `merge(v, u+N)`。则对任意 $x,y\in[0,N)$：

1. `getrt(x) == getrt(y)` $\iff$ 在已加边构成的连通分量中，$x$ 与 $y$ 之间存在**偶数长度**路径（故在任何合法二染色中必有 $c(x)=c(y)$）；
2. `getrt(x) == getrt(y+N)` $\iff$ $x$ 与 $y$ 之间存在**奇数长度**路径（故必有 $c(x)\ne c(y)$）；
3. 新加入边 $e_i=(u,v)$ 破坏二分图性质 $\iff$ 加入前已有 `getrt(u) == getrt(v)`。

**证明**：

每次加入无奇环边 $(u,v)$，相当于建立一步奇偶翻转连边：$u$ 的同侧等于 $v$ 的异侧（`merge(u, v+N)`），$v$ 的同侧等于 $u$ 的异侧（`merge(v, u+N)`）。对路径长度归纳即知，原图中长度为偶数的路径对应扩展图中同域相连（$x\sim y$），长度为奇数的路径对应跨域相连（$x\sim y+N$）。当考虑新边 $(u,v)$ 时，若加入后形成奇环，当且仅当加入前 $u$ 与 $v$ 之间已存在偶数长度路径，即 `getrt(u) == getrt(v)`。$\blacksquare$

## 3. 模式总结（Pattern Summary）

按实际思考顺序列出本题的可迁移模式：

- **explore its property（零冲突 $=$ 二分图）** — 将“两座监狱无同侧边”翻译成图的可二染色性（无奇环）（引理 1）。
- **reduce to easier problem（Min-Max 瓶颈转降序贪心）** — 最大值最小化只取决于能否同时满足权值最大的那批边；按边权从大到小依次強制两端异侧，第一条无法满足的边即为充要瓶颈（引理 2）。
- **classic problem solution（扩展域并查集维护敌对关系）** — 用 $x$ 与 $x+N$ 分别表示同侧与异侧，通过 `getrt(u) == getrt(v)` 在线判奇环，用 `merge(u, v+N)` 与 `merge(v, u+N)` 维护敌人的敌人是朋友（引理 3）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| `n, m` | `int` | 罪犯人数 $N$、仇恨边数 $M$ | 读入 | $n\le 20000,m\le 100000$ |
| `E[i]` | `Edge [100005]` | 仇恨边 `{u, v, w}`（0-based 顶点） | 读入后按 `w` 降序排序 | 边集 |
| `f[x]` | `int [40010]` | 扩展域并查集父节点（$[0,n)$ 同域，$[n,2n)$ 敌域） | `iota(f, f+2*n, 0)` | 引理 3 |

### 4.2 编号步骤

1. 读入 $n,m$ 及 $m$ 条边 `E[i] = {u-1, v-1, w}`。
2. 将边数组 `E[0..m-1]` 按权值 `w` 从大到小排序；用 `iota(f, f + 2 * n, 0)` 初始化扩展域并查集。
3. 依次遍历 $i=0,1,\dots,m-1$：
   - 取出 `[u, v, w] = E[i]`；
   - 若 `getrt(u) == getrt(v)`，直接输出 `w` 并结束程序（引理 2、3）；
   - 否则执行 `f[getrt(u)] = getrt(v + n)` 与 `f[getrt(v)] = getrt(u + n)`。
4. 若全部 $m$ 条边均未触发冲突，输出 `0`。

### 4.3 复杂度

- **时间**：边排序 $O(M\log M)$，并查集扫描 $O(M\alpha(N))$，总时间复杂度 $O(M\log M)$。
- **空间**：边集 `E[100005]` 与并查集 `f[40010]`，空间复杂度 $O(N+M)\approx 1.4\text{ MB}$。

## 5. 示例代码

### 5.1 主解：按权降序贪心 + 扩展域并查集

```cpp
//
// 题目：P1525 [NOIP 2010 提高组] 关押罪犯
// https://www.luogu.com.cn/problem/P1525
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20005};         // N<=20000 (+5 松弛)
constexpr int mxm{100005};        // M<=100000 (+5 松弛)

int n,m;
int f[mxn*2];                     // 扩展域并查集: [0,n) 为同狱域, [n,2n) 为敌对异狱域

struct Edge
{
	int u,v,w;
	friend bool operator<(Edge a,Edge b){return a.w>b.w;}
}E[mxm];

int getrt(int x){return f[x]==x?x:f[x]=getrt(f[x]);}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	if(!(cin>>n>>m))
		return 0;
	for(int i=0;i<m;++i)
	{
		cin>>E[i].u>>E[i].v>>E[i].w;
		--E[i].u;--E[i].v;
	}
	sort(E,E+m);
	iota(f,f+2*n,0);

	for(int i=0;i<m;++i)
	{
		auto[u,v,w]=E[i];
		if(getrt(u)==getrt(v))
		{
			cout<<w<<'\n';        // 首条无法被分入不同监狱的边(奇环闭合处)即为最小可能的最大冲突值
			return 0;
		}
		f[getrt(u)]=getrt(v+n);
		f[getrt(v)]=getrt(u+n);
	}
	cout<<0<<'\n';
	return 0;
}
```

### 5.2 对照实现：$2^{N-1}$ 监狱划分穷举（仅用于小规模对拍）

```cpp
//
// 题目：P1525 [NOIP 2010 提高组] 关押罪犯
// 暴力基准: 枚举 2^(n-1) 种将 n 名罪犯分入两座监狱的 0/1 划分方案, 严格按定义求同狱最大冲突的最小值
#include<bits/stdc++.h>
using namespace std;

constexpr int mxm{1005};
constexpr int inf{1145141919};

int n,m;
int eu[mxm],ev[mxm],ew[mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	if(!(cin>>n>>m))
		return 0;
	for(int i=0;i<m;++i)
	{
		cin>>eu[i]>>ev[i]>>ew[i];
		--eu[i];--ev[i];
	}

	int ans=inf;
	int lim=1<<max(0,n-1);        // 固定 0 号在监狱 0, 对称减半
	for(int mask=0;mask<lim;++mask)
	{
		int mx=0;
		for(int i=0;i<m;++i)
		{
			int c1=(mask>>eu[i])&1;
			int c2=(mask>>ev[i])&1;
			if(c1==c2)
				mx=max(mx,ew[i]);
		}
		ans=min(ans,mx);
	}
	cout<<ans<<'\n';
	return 0;
}
```
