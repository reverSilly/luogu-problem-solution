# P1958 [JOI2007 预选赛] 上学路线

## 1. 重新读题

### 1.1 问题重述（人话版）

城市是一个 $a\times b$ 的网格（棋盘）。南北向的 $a$ 条街道从西到东编号 $1..a$，东西向的 $b$ 条街道从南到北编号 $1..b$，交点记作 $(x,y)$。你从 $(1,1)$ 出发，要到 $(a,b)$。

自行车只能沿街道走，且只能**向东**（$x$ 增大）或**向北**（$y$ 增大）。另有 $N$ 个路口在施工，不能经过。

求从 $(1,1)$ 到 $(a,b)$ 的路线总数。

### 1.2 关键约束与规模暗示

- $1\le a,b\le16$，$1\le N\le40$。
- 网格最大 $16\times16=256$ 个点，规模极小：搜索、递推、甚至打表都能过。
- 但状态数这么少恰恰说明出题人想考的是**计数**而不是搜索剪枝；最干净的做法是 $O(ab)$ 的递推。
- 只允许向东/向北，说明所有移动都让 $x+y$ 严格增大，路线不会绕圈，天然是 DAG 上的路径计数。
- 答案最大是 $\binom{30}{15}=155117520$，在 `int` 范围内；但用 `long long` 存储是零成本的保险。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先看没有施工路口的版本

如果没有任何禁行点，从 $(1,1)$ 到 $(a,b)$ 必须恰好向东走 $a-1$ 步、向北走 $b-1$ 步，共 $a+b-2$ 步，选择哪 $a-1$ 步向东即可，答案是 $\binom{a+b-2}{a-1}$。

但一旦加了禁行点，组合数公式不能直接减（路径可能经过多个禁行点，容斥会组合爆炸），必须按格子做计数。

### 2.2 关键观察：最后一步从哪里来

考虑任意一条到 $(x,y)$ 的合法路线。它的**最后一步**只有两种可能：

- 从 $(x-1,y)$ 向东走一步；
- 从 $(x,y-1)$ 向北走一步。

（$x=1$ 时不可能从西边来，$y=1$ 时不可能从南边来。）

**引理 1（递推的合法性）** 对 $x,y\ge1$，若 $(x,y)$ 不是施工点，
$$
dp[x][y]=dp[x-1][y]+dp[x][y-1],
$$
约定越界项为 $0$；若 $(x,y)$ 是施工点，则 $dp[x][y]=0$。

**证明**：设 $P$ 为所有从 $(1,1)$ 到 $(x,y)$ 的合法路线集合，$P_E$ 为最后一步向东的路线，$P_N$ 为最后一步向北的路线。

1. **不交**：最后一步的方向唯一，$P_E\cap P_N=\varnothing$。
2. **覆盖**：任一路线的最后一步必是东或北，故 $P=P_E\cup P_N$。
3. **双射**：去掉最后一步后，$P_E$ 与「到 $(x-1,y)$ 的合法路线」一一对应（东北方向都是增坐标，删除最后一步不会破坏任何前缀的合法性；反之在任一合法路线后接一步向东也合法，前提是终点 $(x,y)$ 本身不施工）。同理 $P_N$ 与「到 $(x,y-1)$ 的合法路线」一一对应。

因此 $|P|=|P_E|+|P_N|=dp[x-1][y]+dp[x][y-1]$。施工点本身不能到达，$dp=0$。$\square$

### 2.3 递推顺序

$dp[x][y]$ 只依赖 $x$ 更小或 $y$ 更小的格子。所以按 $x$ 从小到大、$y$ 从小到大（或反过来）逐格计算，保证用到的值都已算好。也可以在 $(x,y)$ 平面上把它看成一个 DAG：每条边从 $(x,y)$ 指向 $(x+1,y)$ 或 $(x,y+1)$，拓扑序就是字典序，所以顺序递推就是 DAG 上的路径计数。

### 2.4 起点与边界

- $dp[1][1]=1$（若 $(1,1)$ 不施工）。题面保证学校不在 $(1,1)$，并且保证一定能到达学校，所以实际数据里起点不会被封；代码仍然把「起点施工」处理成 $0$，这是最自然的兜底。
- 第一行 $y=1$：只能从西边来，$dp[x][1]=dp[x-1][1]$（未被封时）。
- 第一列 $x=1$：只能从南边来，$dp[1][y]=dp[1][y-1]$。
- 用「越界项为 $0$」统一处理，代码里不需要写特判分支，只要在取 `dp[x-1][y]` / `dp[x][y-1]` 时判断下标是否越界。

### 2.5 禁行点的处理与去重

施工点用 `bool block[x][y]` 标记，遇到就把 $dp$ 置 $0$。$N\le40$，可能有重复坐标，重复置 `true` 无影响；也可能有坐标落在网格外？题面没说，但若落到 $[1,a]\times[1,b]$ 之外，我们的数组下标是 0-based 且只遍历 $[0,a)\times[0,b)$，只要按题面数据在范围内就没问题；代码里对读入的 $x,y$ 直接 `--` 后写入，若越界会写坏内存，因此按题面约束理解为 $1\le X_i\le a,\ 1\le Y_i\le b$。

### 2.6 小例子

$a=b=3$，施工点 $(2,2)$。总路径 $\binom42=6$，经过 $(2,2)$ 的路径有 $2\times2=4$ 条，所以答案 $2$。递推也能得到 $2$：

$$
\begin{matrix}
1&1&1\\
1&0&1\\
1&1&2
\end{matrix}
$$
（行是 $x$，列是 $y$，右下角为 $2$。）

## 3. 模式总结（Pattern Summary）

- **explore its property** — 只能向东/向北，坐标严格增大，路线构成 DAG。
- **discuss by category** — 按「最后一步向东还是向北」分类，两类不交且覆盖。
- **classic problem solution** — 网格路径计数递推 $dp[x][y]=dp[x-1][y]+dp[x][y-1]$，禁行点置 $0$。
- **boundary handling** — 越界项视为 $0$，起点单独初始化。

---

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `a,b` | `int` | 街道数（$x$ 方向、$y$ 方向） | 读入 | $\le16$ |
| `n` | `int` | 施工路口数 | 读入 | $\le40$ |
| `block[x][y]` | `bool [20][20]` | $(x,y)$ 是否施工（0-based） | `false` | 禁行 |
| `dp[x][y]` | `i64 [20][20]` | 从 $(0,0)$ 到 $(x,y)$ 的合法路线数 | 0 | 计数 |
| `up` | `i64` | 从西边来的贡献 $dp[x-1][y]$ | 0 | — |
| `lf` | `i64` | 从南边来的贡献 $dp[x][y-1]$ | 0 | — |

### 4.2 算法步骤

1. 读入 $a,b$，把 $N$ 个施工点的坐标 `--` 后置 `block[x][y]=true`。
2. `dp[0][0] = block[0][0] ? 0 : 1`。
3. 对 $x=0..a-1$、$y=0..b-1$（跳过 $(0,0)$）：
   1. 若 `block[x][y]`，`dp[x][y]=0`，continue；
   2. `up = (x>0 ? dp[x-1][y] : 0)`，`lf = (y>0 ? dp[x][y-1] : 0)`；
   3. `dp[x][y] = up + lf`。
4. 输出 `dp[a-1][b-1]`。

### 4.3 复杂度分析

- 时间 $O(ab+N)\le 256+40$。
- 空间 $O(ab)$。
- 答案上界 $\binom{30}{15}=155117520$，`long long` 绰绰有余。

## 5. 示例代码

```cpp
//
// 题目：P1958 [JOI2007 预选赛] 上学路线
// https://www.luogu.com.cn/problem/P1958
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{20};

int a,b,n;
bool block[mxn][mxn];
i64 dp[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b>>n;
	for(int i=0,x,y;i<n;++i)
	{
		cin>>x>>y;--x;--y;
		block[x][y]=true;
	}
	dp[0][0]=block[0][0]?0:1;
	for(int i=0;i<a;++i)
		for(int j=0;j<b;++j)
		{
			if(i==0&&j==0)
				continue;
			if(block[i][j])
			{
				dp[i][j]=0;
				continue;
			}
			i64 up{i>0?dp[i-1][j]:0};
			i64 lf{j>0?dp[i][j-1]:0};
			dp[i][j]=up+lf;
		}
	cout<<dp[a-1][b-1]<<'\n';
	return 0;
}
```
