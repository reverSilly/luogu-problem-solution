# P1835 素数密度

> 难度：普及/提高- · 标签：数学, 素数, 分段筛

## 1. 重新读题

### 1.1 问题重述（人话版）

给出闭区间 $[L,R]$，输出里面有多少个素数。$1$ 不是素数。

### 1.2 关键约束与规模暗示

- $1\le L\le R<2^{31}$，也就是 $R\le 2147483647$，但 $R-L\le 10^6$。
- 右端点接近 $2^{31}$，不能开长度 $R$ 的数组，也不能写 `for(int i=L;i<=R;++i)`：当 $R=2147483647$ 时 `i++` 会溢出，循环停不下来。
- 区间长度只有 $10^6$，先筛出 $\sqrt{R}$ 以内的素数，再用它们去划 $[L,R]$ 里的合数。这就是分段筛。
- $2^{31}-1=2147483647$ 本身是素数。$L=1$ 必须单独把 $1$ 排除，筛子不会给它一个素因子。

## 2. 思维链（Chain-of-thought）

合数一定有一个小素因子，这是只筛到 $\sqrt{R}$ 的理由。

**引理 1（$[1,R]$ 里的合数必有不超过 $46340$ 的素因子）**

设 $R<2^{31}$。若 $x\le R$ 是合数，则 $x$ 有一个素因子 $\le \sqrt{x}\le \sqrt{R}<46341$，因而 $\le 46340$。

**证明**：合数 $x$ 可以写成 $ab$，其中 $1<a\le b<x$。若 $a>\sqrt{x}$，则 $b\ge a>\sqrt{x}$，从而 $x=ab>x$，矛盾。所以最小的真因子 $\le \sqrt{x}$，它的某个素因子也 $\le \sqrt{x}$。$\sqrt{2^{31}-1}<46340.95$，所以这个素因子是不超过 $46340$ 的整数。预先线性筛到 $50000$ 就覆盖了全部需要的素数；$p^2>R$ 的素数不可能是 $[L,R]$ 中合数的最小素因子，后面的素数可以直接停。$\blacksquare$

**引理 2（从 $\max(p^2,\lceil L/p\rceil\cdot p)$ 开始划，既不会划掉素数，也不会漏掉合数）**

对每个素数 $p$，令起点

$$st=\max\bigl(p^2,\ \lceil L/p\rceil\cdot p\bigr)$$

然后标记 $st,st+p,st+2p,\dots$ 中不超过 $R$ 的数。最后 $[L,R]$ 里没被标记、且 $\ge 2$ 的数都是素数。

**证明**：

- 不误伤素数：素数的真倍数才应被划掉。$p$ 自己在数轴上的位置是 $p<p^2\le st$，所以不会被选为起点，也不会出现在后面的公差为 $p$ 的序列里。
- 不漏合数：设 $x\in[L,R]$ 是合数，取它的最小素因子 $p$。由引理 1，$p$ 在表里，且 $p^2\le x\le R$，循环不会在 $p$ 之前停掉。$x$ 是 $p$ 的倍数且 $x\ge p^2$，又 $x\ge L$，所以 $x\ge st$。公差序列会经过 $x$。
- $1$：它不是素数，也没有素因子把它划掉。统计时用 $L+i\ge 2$ 排除。$L=1,R=1$ 时长度为 $1$，答案 $0$。

所有下标和循环变量用 `i64`。特别地，$(L+p-1)/p$ 与 $x+=p$ 在 $L$ 接近 $2^{31}$ 时，若用 $32$ 位整数会溢出成负数，划到错误的下标。$\blacksquare$

暴力对拍是逐个试除，只在 $R\le 2\cdot 10^5$、区间长度不大时使用。它和分段筛的标记过程不同：每个数单独除到 $\sqrt{x}$。最大区间不拿试除去对，只检查标程的耗时，并用两个已知点卡住溢出：

- $[2147483647,2147483647]$ 的答案是 $1$；
- $[2147483646,2147483647]$ 的答案是 $1$（左端点是偶数）；
- $[1,1000001]$ 的答案是 $\pi(10^6)=78498$（$1000000$ 与 $1000001$ 都不是素数）。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 区间里的合数必有 $\le 46340$ 的素因子，所以种子素数只筛到 $5\cdot 10^4$（引理 1）。
- **classic problem solution** — 用这些素数从 $\max(p^2,\lceil L/p\rceil p)$ 开始划掉 $[L,R]$ 中的合数（引理 2）。
- **boundary discipline** — $1$ 单独排除；$L,R$ 与循环全部用 `i64`；数组只开 $R-L+5$，不下标到 $R$ 本身。
- **consider easier version** — 小区间改成试除。$R=2^{31}-1$ 的单点、以及长度 $10^6$ 的两端，用来确认没有溢出。

## 4. 真实解法

### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `comp` | `bool [50005]` | $2..50000$ 的合数标记 | 全局 `false` | 种子筛 |
| `prime,pc` | `int [50005]`、`int` | 种子素数 | `pc=0` | $p\le 46340$ 才有用 |
| `L,R` | `i64` | 询问区间 | 读入 | 可能到 $2^{31}-1$ |
| `bad` | `bool [1000005]` | `bad[i]` 表示 $L+i$ 是合数 | 全局 `false` | 只开区间长度 |
| `st` | `i64` | $p$ 的第一个被划倍数 | $\max(p^2,\lceil L/p\rceil p)$ | 起点 |

### 4.2 算法步骤

1. 线性筛出 $<50005$ 的素数。
2. 读入 `L,R`，`len=R-L+1`。
3. 对每个素数 $p$，若 $p\cdot p>R$ 则停止。否则从引理 2 的起点每隔 $p$ 把 `bad[x-L]` 标真。
4. 统计 $L+i\ge 2$ 且未被标记的个数。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 种子筛 $O(5\cdot 10^4)$。划数的时间是 $\sum_{p\le \sqrt{R}}(R-L)/p=O((R-L)\log\log R)$，空间 $O(R-L)$。
- 编译：`g++ -O2 -std=c++17 -Wall -Wextra -Werror`，无警告。
- 样例 $[2,11]$ 标程与试除都是 `5`。另外固定 $[1,1]\to 0$、$[1,2]\to 1$、$[1,10]\to 4$、$[4,4]\to 0$、$[8,10]\to 0$、$[9,9]\to 0$、$[14,16]\to 0$、$[13,17]\to 2$、$[25,25]\to 0$、$[49,49]\to 0$，以及 $[1,100]$ 与试除一致。
- 随机小区间（右端 $\le 2\cdot 10^5$、长度 $\le 3000$）$40$ 组标程 = 试除。以上小数据合计 $53$ 组，耗时 $0.20$ s。
- 端点只跑标程：$[2147483647,2147483647]\to 1$，$[2147483646,2147483647]\to 1$，$[2147483637,2147483647]\to 1$。
- 最大长度且贴近上界：$L=2146483647,R=2147483647$，长度 $1000000$，答案 `46603`，耗时 $0.0053$ s。
- 长度同样打满但含 $1$：$[1,1000001]$ 标程与试除都是 `78498`，标程耗时 $0.0046$ s。
- 合计 `58 tests OK`。

## 5. 示例代码

### 5.1 标程（`P1835.cpp`）

```cpp
//
// 题目：P1835 素数密度
// https://www.luogu.com.cn/problem/P1835
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxp{50005};
constexpr int mxlen{1000005};

bool comp[mxp];
int prime[mxp],pc;
bool bad[mxlen];

void sieve()
{
	for(int i=2;i<mxp;++i)
	{
		if(!comp[i])
			prime[pc++]=i;
		for(int j=0;j<pc&&i*1LL*prime[j]<mxp;++j)
		{
			comp[i*prime[j]]=true;
			if(i%prime[j]==0)
				break;
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	sieve();
	i64 L,R;
	cin>>L>>R;
	int len=(int)(R-L+1);
	for(int i=0;i<pc;++i)
	{
		i64 p=prime[i];
		if(p*p>R)
			break;
		i64 st=(L+p-1)/p*p;
		if(st<p*p)
			st=p*p;
		for(i64 x=st;x<=R;x+=p)
			bad[(int)(x-L)]=true;
	}
	int ans=0;
	for(int i=0;i<len;++i)
		if(L+(i64)i>=2&&!bad[i])
			++ans;
	cout<<ans<<'\n';
	return 0;
}
```
