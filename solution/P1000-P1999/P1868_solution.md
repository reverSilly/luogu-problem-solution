# P1868 饥饿的奶牛

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 个区间 $[x_i,y_i]$，区间覆盖第 $x_i$ 堆到第 $y_i$ 堆共 $y_i-x_i+1$ 堆牧草。选若干个区间，要求任意两个被选区间没有公共的堆；求被覆盖的堆数总和的最大值。

"没有公共的堆"有两个容易读错的边界：

- 端点相接是可以的：$[0,2]$ 与 $[3,4]$ 没有共享堆，可以同时选；但 $[0,2]$ 与 $[2,4]$ 共享第 $2$ 堆，不能同时选。
- 同一个区间选两次没有意义（堆会被重复计算），题目也说的是"选择任意区间"，是集合意义上的选择。

### 1.2 关键约束与规模暗示

- $1\le n\le 1.5\times10^5$，$0\le x\le y\le 3\times10^6$。
- $n$ 到 $10^5$ 这一档直接排除 $O(n^2)$（约 $2\times10^{10}$）的区间两两 DP。
- 但坐标上界只有 $3\times10^6$，足以开一个按坐标的数组——这暗示"以坐标为阶段"的线性 DP：$O(n+\max y)$。
- 每个区间的收益是它自己的长度 $y-x+1$，不是 $1$。所以这是**带权**区间调度，不能照搬 P1803（线段覆盖）的贪心。

## 2. 思维链（Chain-of-thought）

### 2.1 第一步：把"选区间"翻译成结构

把选中的区间按左端点从小到大排序，得到 $[x_1,y_1],[x_2,y_2],\dots$。它们两两不共享堆，当且仅当

$$y_1<x_2,\quad y_2<x_3,\quad\dots$$

理由：若 $y_i\ge x_{i+1}$，因为 $x_{i+1}\le y_{i+1}$，两个区间都含第 $x_{i+1}$ 堆（注意 $x_{i+1}\le y_i$ 时第 $x_{i+1}$ 堆同时落在两区间里），冲突；反之若所有 $y_i<x_{i+1}$，那么按左端点排序后区间是"严格依次向右"的，任意两个被选区间都不重叠。

于是问题就是标准的**带权区间调度**：从 $n$ 个带权（权 $=y-x+1$）区间里选一个两两不交的子集，使权和最大。

### 2.2 为什么不能贪心：一个极简反例

P1803 的贪心（按右端点从早到晚选）在"权都是 $1$"时正确，因为那时少选一个区间只会少 $1$，而"结束得越早，后面越自由"能把这个损失补回来。

但这里权是长度，两个方案的"个数"与"总长度"可以完全相反：

- $A=[0,10]$，长度 $11$；
- $B=[0,1]$，长度 $2$；$C=[2,3]$，长度 $2$。

按右端点最早：先选 $B$（右端点 $1$），再选 $C$（左端点 $2>1$），总收益 $4$；而只选 $A$ 收益 $11$。贪心错得很离谱。

失败的根因：局部"最早结束"只优化了"给后面腾位置"，而完全无视了被丢弃区间的长度。这说明必须把"收益"显式放进状态。

### 2.3 换个角度：以坐标为主语

既然坐标范围小，就不要以区间为主语，而以坐标为主语。定义

$$f(t)=\text{只使用完全落在 }[0,t]\text{ 内的堆时，能获得的最大收益},\qquad f(-1)=0 .$$

**引理 1（$f$ 的递推）**：
$$f(t)=\max\Bigl\{\,f(t-1),\ \max_{\text{右端点为 }t\text{ 的区间}[x,t]}\bigl(f(x-1)+t-x+1\bigr)\Bigr\}.$$

**证明**：设 $\mathcal S$ 是任一合法方案，收益为 $W$。

- 情况 A：$\mathcal S$ 中没有任何右端点恰为 $t$ 的区间。那么所有被选区间的右端点都 $\le t-1$，它们全部落在 $[0,t-1]$ 内，由 $f(t-1)$ 的定义 $W\le f(t-1)$。
- 情况 B：$\mathcal S$ 中有一个右端点为 $t$ 的区间，记作 $[x,t]$。它不可能有第二个同伴：任何另一个右端点为 $t$ 的区间 $[x',t]$ 都包含第 $t$ 堆，与 $[x,t]$ 冲突。所以 $\mathcal S$ 中右端点为 $t$ 的区间恰好是这一个。

  设 $\mathcal S$ 中其余区间为 $[x',y']$。它们与 $[x,t]$ 不交，而 $y'\le t$（因为 $t$ 是全局最大坐标），所以只能有 $y'<x$，即其余区间全部落在 $[0,x-1]$。于是其余区间的收益和 $\le f(x-1)$，从而
  $$W\le f(x-1)+(t-x+1)\le \max_{\text{右端点为 }t}[f(x-1)+t-x+1].$$
  
  于是 $W\le$ 引理右端。

  这里要特别注意"$y'<x$ 而不是 $y'\le x$"：若 $y'=x$，则 $[x',x]$ 与 $[x,t]$ 都含第 $x$ 堆，冲突。所以确实是严格小于。

两个情况覆盖了所有合法方案，故 $f(t)\le$ 右端。

反过来，右端的两类方案都真实可构造：

- $f(t-1)$ 对应的方案不含 $t$ 及其右边，直接可作为 $t$ 问题的方案；
- 对某个右端点为 $t$ 的区间 $[x,t]$，把 $f(x-1)$ 的最优方案与 $[x,t]$ 放在一起：前者只在 $[0,x-1]$ 内，后者在 $[x,t]$ 内，两者不交，合法，收益恰为 $f(x-1)+t-x+1$。

所以 $f(t)\ge$ 右端。两者合并得等号。

最后对 $t$ 做归纳：$f(0)$ 只可能选 $[0,0]$（若存在），递推式直接成立；假设 $f(0..t-1)$ 都等于真实最优，上面的论证给出 $f(t)$ 也等于真实最优。$\square$

### 2.4 实现：把区间按右端点挂桶

递推需要"右端点恰为 $t$ 的所有区间"。用一个链式前向星按 $y$ 挂桶：`head[y]` 存第一个右端点为 $y$ 的区间编号，`nxt[i]` 串起来。然后 $t$ 从 $0$ 扫到 $\max y$，边扫边算 $f$。

每个区间只在它自己的右端点处被访问一次，加上坐标扫描，总时间 $O(n+\max y)$。

### 2.5 边界清点

1. $x=0$ 时 $f(x-1)=f(-1)=0$，代码里写成 `x?f[x-1]:0`。
2. 坐标从 $0$ 开始，所以 $f$ 的初值就是 $0$，不能设成负数把空方案排除掉。
3. 端点相接是允许的，递推里用 $f(x-1)$ 会自动把"上一个区间结束于 $x-1$"的方案接上，不能写成 $f(x)$（那会强迫两个区间之间空出一堆）。
4. 同一个 $t$ 上可能有多个区间，它们彼此冲突，所以是"取 max"而不是"累加"，这正是引理 1 中"至多选一个右端点为 $t$ 的区间"的直接体现。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 选中区间按左端点排序后必须满足 $y_i<x_{i+1}$，问题等价于带权区间调度。
- **counterexample against greedy** — 权为长度时"按右端点最早"会为了个数牺牲总长，$[0,10]$ 对 $[0,1]+[2,3]$ 是反例。
- **change the subject to coordinates** — 用坐标前缀最优 $f(t)$ 作状态，把区间调度变成单指针扫描。
- **prove by case split** — 按"有没有右端点为 $t$ 的区间"分类，得到完整递推并双向证明。
- **classic problem solution** — 区间按右端点挂桶 + 线性 DP，$O(n+\max y)$。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| $n$ | `int` | 区间个数 | 读入 | $\le 1.5\times10^5$ |
| `lx[i],ly[i]` | `int [150005]` | 第 $i$ 个区间的左右端点 | 读入 | left/right |
| `head[t]` | `int [3000005]` | 右端点恰为 $t$ 的区间链表头 | $-1$ | bucket |
| `nxt[i]` | `int [150005]` | 同一桶内下一个区间 | 挂桶时填 | next |
| `dp[t]` | `int [3000005]` | $f(t)$，坐标 $\le t$ 的最大收益 | $0$ | prefix best |

收益上界：$\sum(y-x+1)\le$ 所有堆数 $\le 3\times10^6+1$，`int` 足够。

### 4.2 算法步骤

1. 读入 $n$ 与全部区间；对每个区间 $i$，令 `nxt[i]=head[ly[i]]`、`head[ly[i]]=i`，完成按右端点挂桶；记录最大右端点 `mx`。
2. 对 $t=0,1,\dots,mx$：
   - 若 $t>0$，先 `dp[t]=dp[t-1]`（情况 A）；
   - 再遍历 `head[t]` 链上的每个区间 $[x,t]$，用 `(x?dp[x-1]:0)+t-x+1` 更新 `dp[t]`（情况 B）。
3. 输出 `dp[mx]`。

### 4.3 复杂度

- 时间 $O(n+\max y)$：每个区间被访问恰好一次，坐标扫描 $\max y+1$ 次。
- 空间 $O(n+\max y)$：两个坐标数组约 $24$ MB，区间数组约 $1.2$ MB。

## 5. 示例代码

```cpp
//
// 题目：P1868 饥饿的奶牛
// https://www.luogu.com.cn/problem/P1868
// 自测：手造小数据与子集枚举对拍通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{150005},mxy{3000005};

int n;
int head[mxy],nxt[mxn],lx[mxn],ly[mxn];
int dp[mxy];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	fill_n(head,mxy,-1);
	int mx{0};
	for(int i=0;i<n;++i)
	{
		cin>>lx[i]>>ly[i];
		nxt[i]=head[ly[i]];
		head[ly[i]]=i;
		mx=max(mx,ly[i]);
	}
	for(int y=0;y<=mx;++y)
	{
		if(y)
			dp[y]=dp[y-1];          // 情况 A：不选右端点为 y 的区间
		for(int i=head[y];i!=-1;i=nxt[i])
		{
			int x=lx[i];
			// 情况 B：选 [x,y]，前面只能用 [0,x-1]
			dp[y]=max(dp[y],(x?dp[x-1]:0)+y-x+1);
		}
	}
	cout<<dp[mx]<<'\n';
	return 0;
}
```
