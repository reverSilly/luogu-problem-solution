# P1948 [USACO08JAN] Telephone Lines S

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 根电话线杆（$1$ 号已接入全国网络，目标是 $n$ 号），$p$ 对线杆之间可以拉线，第 $i$ 对长度为 $l_i$。我们需要选一条从 $1$ 到 $n$ 的路径。

电信公司允许我们**免费指定 $k$ 对**线杆之间的线，剩下的线要自己付钱，总费用等于**自己付的那些线中最长的一条的长度**；如果整条路径的线数不超过 $k$（全部免费），费用为 $0$。

求最小可能的费用；若 $1$ 与 $n$ 根本不连通，输出 $-1$。

### 1.2 关键约束与规模暗示

- $n\le 10^3$，$p\le 10^4$，$k\le p$，$l_i\le 10^6$。
- 图是稀疏的（$p$ 与 $n$ 同阶），$O(p\log p)$ 或 $O((n+p)\log 10^6)$ 都轻松。
- 答案只可能是某条边的长度或者 $0$。$l_i\le10^6$，答案值域很小，直接对**答案数值**二分即可，不必先离散化所有边长。
- 注意「免费的线由我们指定」：不是固定免费某几条，而是对每条候选路径我们都能自己挑最长的那些免费。

## 2. 思维链（Chain-of-thought）

### 2.1 第一步：固定一条路径，最优的免费策略是什么

先别管图，假设已经选定了一条路径，边长为 $w_1\ge w_2\ge\dots\ge w_L$（降序）。

**引理 1（路径费用公式）**：在这条路径上，最小费用为

$$
\operatorname{cost}(P)=
\begin{cases}
0,& L\le k,\\
w_{k+1},& L>k,
\end{cases}
$$

也就是「免费掉最长的 $k$ 条，剩下的最长者就是第 $k+1$ 长的边」。

**证明**：

1. 上界：免费掉前 $k$ 长的 $k$ 条边（$L>k$ 时），剩下最长的是 $w_{k+1}$，费用不超过 $w_{k+1}$。
2. 下界：任意免费 $k$ 条边后，还至少有 $L-k\ge1$ 条付费边；其中前 $k+1$ 长的边里最多只有 $k$ 条被免费，所以 $w_1,\dots,w_{k+1}$ 中至少有一条在付费集合里，故最长付费边 $\ge w_{k+1}$。
3. 两界相等。$L\le k$ 时全部免费，费用 $0$，显然最小。$\square$

于是整题变成：

> 在所有 $1\to n$ 的路径中，最小化「路径上第 $k+1$ 大的边权」（不足 $k+1$ 条边时答案为 $0$）。

这是一个**极小化第 $k+1$ 大**的瓶颈型问题。先看最简单的特例 $k=0$。

### 2.2 第二步：先做 $k=0$（最小化路径最大边）

$k=0$ 就是经典的「瓶颈最短路」：求一条路径，使路径上最大边最小。做法是「二分答案 $X$ + 只走长度 $\le X$ 的边，看 $1,n$ 是否连通」。可行性关于 $X$ 单调，理由很朴素：$X$ 变大，允许走的边只增不减。

这个特例启发我们：**把「第 $k+1$ 大的边」也翻译成某种「计数约束」，再二分 $X$。**

### 2.3 第三步：用 0/1 权把「第 $k+1$ 大」变成「计数」

固定一个阈值 $X$。对每条边 $e$ 定义

$$
c_X(e)=
\begin{cases}
1,&l_e>X,\\
0,&l_e\le X.
\end{cases}
$$

对一条路径 $P$，$\sum_{e\in P}c_X(e)$ 恰好是路径上**长度严格大于 $X$ 的边数**。

**引理 2（阈值刻画）**：$\operatorname{cost}(P)\le X$ 当且仅当路径 $P$ 上长度 $>X$ 的边不超过 $k$ 条。

**证明**：

- 若 $L\le k$，费用为 $0\le X$，且所有边都 $>X$ 的数量 $\le L\le k$，两边都真。
- 否则费用 $=w_{k+1}$。费用 $\le X$ $\iff$ $w_{k+1}\le X$ $\iff$ 至多 $k$ 条边 $>X$（因为降序排列下 $>X$ 的边正好是 $w_1,\dots,w_j$，$j\le k$ 等价于 $w_{k+1}\le X$）。$\square$

因此

$$
\min_P\operatorname{cost}(P)\le X
\iff
\exists P:\ \#\{e\in P:l_e>X\}\le k
\iff
d_X(1,n)\le k,
$$

其中 $d_X$ 是以 $c_X$ 为边权的 0/1 图上的最短路（边权只有 0 和 1）。而 $d_X$ 恰好等于「最少经过多少条长边」。

### 2.4 第四步：单调性与二分

**引理 3（可行性单调）**：设 $X_1\le X_2$，则对每条边 $c_{X_2}(e)\le c_{X_1}(e)$，从而 $d_{X_2}(1,n)\le d_{X_1}(1,n)$；于是「可行」关于 $X$ 单调（一旦可行，更大的 $X$ 也可行）。

**证明**：$X$ 变大时集合 $\{e:l_e>X\}$ 只会变小，所以每条边的 0/1 权只会从 1 变成 0，不会反向。对任意一条路径，它的权值和只会变小；最短路是所有路径权值和的最小值，故也只会变小。$\square$

**引理 4（二分答案正确）**：设 $A=\min_P\operatorname{cost}(P)$。则

$$
A=\min\{X\in[0,10^6]:d_X(1,n)\le k\}.
$$

并且这个最小值一定存在（图连通时 $X=10^6$ 可行）。

**证明**：由引理 2，$\{X: d_X\le k\}=\{X:A\le X\}$。该集合非空（取 $X=10^6$，所有 $l_e\le10^6$，长边数为 0）且关于 $X$ 单调，故其最小元就是 $A$；并且对每个 $X<A$ 都有 $d_X>k$，说明 $A$ 确实被取到。注意 $X$ 可取 $0$：若某条路径边数 $\le k$，则 $d_0(1,n)\le k$，答案为 $0$，与题目「不超过 $k$ 对则支出为 $0$」一致。$\square$

于是对 $X\in[0,10^6]$ 二分，判定用 0/1 BFS 求 $d_X(1,n)$，判断是否 $\le k$。

### 2.5 第五步：0/1 BFS 的正确性

**引理 5（0/1 BFS）**：用双端队列维护待扩展点，初始 `dis[1]=0`。每次取出队头 $u$（若已确定则跳过），对边 $(u,v)$ 令 $c=c_X(e)$，若 `dis[v]>dis[u]+c` 则更新，并把 $v$ 放进队头（$c=0$）或队尾（$c=1$）。算法结束时 `dis[v]` 等于 0/1 最短路。

**证明**（把双端队列看成「代替堆的 Dijkstra」）：只需验证两条不变式：

1. **队内距离单调**：设队列中元素的距离（入队时的 `dis` 值）依次为 $q_1,q_2,\dots$。初始只有 $q_1=0$。每次从队头取出 $q_1$，新产生的候选距离为 $q_1$（0 边，压入队头）或 $q_1+1$（1 边，压入队尾）。若队列原本满足 $q_i\le q_{i+1}$ 且 $q_{\max}-q_1\le1$，则操作后仍满足同样的性质。故不变式成立。
2. **队头即当前最小未确定点**：由不变式，队头距离是队列中最小者；而所有「尚未入队」的候选点都是由队列中某点为前驱松弛出来的，其 `dis` 至少为队头距离。所以队头 $u$ 的 `dis[u]` 已经是全图剩余点中的最小值，可以像 Dijkstra 一样**最终确定**。

于是出队顺序与 Dijkstra 完全一致。每次松弛都令 `dis[v]≤dis[u]+c`，由三角不等式，`dis` 始终不小于真实最短路；Dijkstra 的贪心正确性保证被确定时取到真实最短路。$\square$

（代码里用 `vis[u]` 在出队时去重：同一个点可能被多次入队，第一次出队时距离最小，之后再出队直接跳过。）

### 2.6 第六步：不连通

若 $1$ 与 $n$ 不连通，则对任何 $X$，$d_X(1,n)=+\infty>k$，二分永远不可行。代码用 `check(10^6)` 先判一次：此时所有边权为 0，`check` 为真当且仅当 $1,n$ 连通（因为 $d=0\le k$）。不连通输出 $-1$。

**引理 6**：$1,n$ 不连通 $\iff$ `check(10^6)` 为假。

**证明**：$10^6\ge$ 所有 $l_e$，故 $c_{10^6}(e)\equiv0$，图中每条可走的边权为 0，$d_{10^6}(1,n)=0$ 当且仅当存在 $1\to n$ 的路径，即连通。不连通时 $d=+\infty>k$。$\square$

### 2.7 复杂度

- 单次 `check`：0/1 BFS，$O(n+p)$。
- 二分 $O(\log 10^6)\approx20$ 轮。
- 总时间 $O((n+p)\log 10^6)$，空间 $O(n+p)$。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 固定路径时，最优免费策略是免费最长的 $k$ 条，费用 $=$ 第 $k+1$ 大边权。
- **consider easier version** — $k=0$ 是瓶颈最短路：二分 $X$ + 只走 $\le X$ 的边判连通。
- **reduce to easier problem** — 一般 $k$ 用 0/1 边权把「第 $k+1$ 大」化成「长边计数」，判定变成 0/1 最短路是否 $\le k$。
- **classic problem solution** — 答案单调 $\Rightarrow$ 二分答案；判定用 0/1 BFS。
- **explore its property** — 不连通等价于 `check(10^6)` 为假。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 线杆数 | 读入 | 点 |
| `p` | `int` | 可拉线的对数 | 读入 | 边 |
| `k` | `int` | 免费线对数 | 读入 | free |
| `graph[u]` | `vector<edge>[1005]` | 邻接表，`edge{v,w}` | 读入 | 无向图 |
| `dis[v]` | `int [1005]` | 以 $c_X$ 为权的 0/1 最短路（最少长边数） | `inf` | distance |
| `vis[v]` | `bool [1005]` | 出队去重 | `false` | visited |
| `check(X)` | `bool` | 判断是否存在 $1\to n$ 路径且长边数 $\le k$ | — | 判定 |

### 4.2 算法步骤

1. 读入 $n,p,k$ 以及 $p$ 条无向边（转 0-based）。
2. 若 `check(1000000)` 为假，输出 `-1` 并结束。
3. 在 $[0,10^6]$ 上二分最小的 $X$ 使 `check(X)` 为真：
   - `mid=(lo+hi)>>1`；若 `check(mid)` 则 `hi=mid`，否则 `lo=mid+1`。
4. 输出 `lo`。

`check(X)` 内部：

1. `dis[*]=inf, vis[*]=false`，`dis[0]=0`，双端队列放入 $0$。
2. 取队头 $u$；若 `vis[u]` 跳过；置 `vis[u]=true`。
3. 对每条边 $(u,v,l)$：令 $c=[l>X]$，若 `dis[u]+c<dis[v]` 则更新；$c=0$ 压队头，$c=1$ 压队尾。
4. 返回 `dis[n-1]<=k`。

### 4.3 复杂度

- 时间：$O((n+p)\log 10^6)$。
- 空间：$O(n+p)$。

## 5. 示例代码

```cpp
//
// 题目：P1948 [USACO08JAN] Telephone Lines S
// https://www.luogu.com.cn/problem/P1948
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};
constexpr int inf{1145141919};

int n,p,k;
struct edge{int v,w;};
vector<edge> graph[mxn];
int dis[mxn];
bool vis[mxn];

bool check(int X)
{
	fill_n(dis,n,inf);
	fill_n(vis,n,false);
	deque<int>dq;
	dis[0]=0;
	dq.push_back(0);
	while(!dq.empty())
	{
		int u=dq.front();
		dq.pop_front();
		if(vis[u])
			continue;
		vis[u]=true;
		for(auto[v,w]:graph[u])
		{
			int c=w>X;	// 长度 >X 的边记 1，表示要付费
			if(dis[v]>dis[u]+c)
			{
				dis[v]=dis[u]+c;
				if(c)
					dq.push_back(v);
				else
					dq.push_front(v);
			}
		}
	}
	return dis[n-1]<=k;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>p>>k;
	for(int i=0,a,b,l;i<p;++i)
	{
		cin>>a>>b>>l;
		--a;--b;
		graph[a].push_back({b,l});
		graph[b].push_back({a,l});
	}

	if(!check(1000000))	// 边权全 0：等价于判连通
	{
		cout<<-1<<'\n';
		return 0;
	}

	int lo{0},hi{1000000};
	while(lo<hi)
	{
		int mid=(lo+hi)>>1;
		if(check(mid))
			hi=mid;
		else
			lo=mid+1;
	}
	cout<<lo<<'\n';
	return 0;
}
```
