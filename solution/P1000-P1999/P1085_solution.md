# P1085 [NOIP 2004 普及组] 不高兴的津津 — 题解

---

## 1. 重读题意（Re-read the problem）

津津每天的**总上课时间** = 在校上课时间 + 妈妈安排的课外上课时间。如果某天总时间 **> 8 小时**，津津当天就会不高兴。**不高兴程度** = 当天的总上课时间（越久越不高兴）。不高兴不会延续到第二天。

输入 7 行，每行两个小于 10 的非负整数（周一至周日）。需要输出：

- 如果 **所有天**的总时间都不超过 8，输出 0；
- 否则，输出**最不高兴的那天**（1~7 对应周一~周日）。如果有多个不高兴程度相同的天，输出**时间最靠前**的那个。

约束：每行两个数的范围 `[0, 9]`，总和最大 18。

---

## 2. 思维链与完整证明（Chain-of-thought with full proofs）

### 2.1 问题建模

定义第 \(i\) 天（\(i = 1..7\)）的输入为 \((a_i, b_i)\)，当天总时间

\[
t_i = a_i + b_i
\]

津津当天的**不高兴程度** \(h_i\) 定义为：

\[
h_i = \begin{cases}
t_i, & t_i > 8 \\
0, & t_i \le 8
\end{cases}
\]

**命题 1**：津津在某天不高兴当且仅当 \(t_i > 8\)。

证明：题目原文"如果一天上课超过八个小时就会不高兴"，"上得越久就会越不高兴"。当 \(t_i > 8\) 时，她产生不高兴情绪；当 \(t_i \le 8\) 时，不会不高兴。故命题成立。□

**命题 2**：不高兴程度 \(h_i\) 与 \(t_i\) 在 \(t_i > 8\) 时单调正相关。

证明：题目原文"上得越久就会越不高兴"。故在 \(t_i > 8\) 的前提下，\(t_i\) 越大，不高兴程度越高。□

### 2.2 输出规则的形式化

令

\[
S = \{i \mid t_i > 8,\; i = 1..7\}
\]

- 若 \(S = \varnothing\)，输出 0。
- 若 \(S \neq \varnothing\)，输出

\[
\arg\max_{i \in S} \, (t_i,\; -i)
\]

即先按 \(t_i\) 降序，再按下标 \(i\) 升序取第一个。

**命题 3**：该规则等价于：扫描 \(i = 1..7\)，维护当前最大 \(t_i\) 和对应下标；仅在 \(t_i > \text{当前最大}\) 时更新。

证明：设当前扫描到第 \(k\) 天，维护的答案为 \((mx, ans)\)。对于第 \(i\) 天：

- 若 \(t_i \le 8\)，不计入考虑。
- 若 \(t_i > mx\)，则 \(t_i\) 严格大于之前所有天的总时间，必须更新 \(ans \gets i\)。
- 若 \(t_i = mx\)，根据"时间最靠前"规则，不更新（保留更小的下标）。
- 若 \(t_i < mx\)，不影响。

扫描结束时，\(ans\) 即为满足条件的下标。所有天数最多被检查一次，正确性由上述归纳保证。□

### 2.3 复杂度分析

- 时间复杂度：\(O(7) = O(1)\)，一次线性扫描。
- 空间复杂度：\(O(1)\)（仅需常数额外空间，或 \(O(7)\) 的数组存储输入）。

## 3. 模式总结（Pattern summary）

| 要素 | 本问题模式 |
|------|-----------|
| 问题类型 | 线性扫描 + 最值维护 |
| 条件判断 | 阈值比较（> 8） |
| 最值规则 | 严格大于才更新（自然完成靠前优先） |
| 边界情况 | 无满足条件时输出 0 |
| 数据范围 | 极小（7 天，每值 < 10），无需优化 |

**学习要点**：当最值需要"靠前优先"时，用**严格比较**（`>` 而非 `>=`）可以自然实现，无需额外判断下标大小。

## 4. 正解（Real solution with notation glossary）

### 符号表

| 符号 | 含义 |
|------|------|
| \(a_i\) | 第 \(i\) 天在校时间 |
| \(b_i\) | 第 \(i\) 天课外时间 |
| \(t_i\) | \(a_i + b_i\)，当天总时间 |
| \(mx\) | 扫描过程中遇到的最大 \(t_i\)（且 \(> 8\)） |
| \(ans\) | 当前答案，即 \(mx\) 对应的天数（1-based） |

### 算法流程

1. 初始化 `mx = 0`，`ans = 0`。
2. 对 \(i = 1..7\)（或 0-based 循环体内部转换为 1-based）：
   - 读入 `a`、`b`，计算 `s = a + b`。
   - 若 `s > 8` 且 `s > mx`，则更新 `mx = s`，`ans = i`。
3. 输出 `ans`。

### 正确性

- 初始 `ans = 0` 对应"不会不高兴"的情况。只有某天满足 `s > 8` 后 `ans` 才会被改写为非零值。若全程无更新，`ans` 保持 0，输出 0，符合题意。
- `s > mx`（严格大于）保证多个相同最大值时保留第一个遇到的，符合"时间最靠前"要求。

## 5. 示例代码（Example code）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{12};
int a[mxn], b[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	int ans{0}, mx{0};
	for (int i{0}; i < 7; ++i)
	{
		cin >> a[i] >> b[i];
		int s = a[i] + b[i];
		if (s > 8 && s > mx)
		{
			mx = s;
			ans = i + 1;
		}
	}
	cout << ans << '\n';
}
```

### 代码说明

- **全局数组**：`a[mxn], b[mxn]` 利用静态存储区零初始化。`mxn = 12` 保证比最大天数 7 多 5 的松弛量。
- **0-based 循环**：`for (int i{0}; i < 7; ++i)` 读入，但输出时转换为 1-based（`ans = i + 1`）。
- **核心条件**：`s > 8 && s > mx`。前者筛除不高兴的天，后者确保严格最大且自动靠前优先。
- **I/O 优化**：`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);` 顺序固定，`'\n'` 代替 `endl`。
- **Allman 风格**：函数左大括号换行，Tab 缩进，运算符两侧无空格。
