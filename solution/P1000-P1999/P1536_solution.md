# P1536 村村通

> 标签：图论 · 并查集 · 连通块 · 难度：普及-
> 本地题面：`P1536.md`（多组数据，$1\le n<1000$，每组 $m$ 条道路，可重边自环；以单独一行 `0` 结束）。
> 验证：`appendix/P1536/` 对拍 300 组随机用例 + 官方样例（输出 `1 0 2 998`）+ 最坏 $n=999$ 二十组（耗时 $0.0122$ s）全部 PASS。

## 1. 重新读题

**问题重述（人话版）**

给出若干城镇和它们之间**已有的道路**，路是无向的。要求"任何两个城镇之间都可达（可以直接相连，也可以转好几手）"。问：**最少再修几条路，就能让全图连通？**

输入是多组：每组第一行 `n m`，接着 `m` 行道路 `u v`（城镇编号 1..n，允许重边、自环）；最后用**单独一行 `0`** 表示输入结束。对每组输出一个数，一行一个。

**题面里容易漏掉的条款**

1. **"两个城市间可以有多条道路相通"** $\Rightarrow$ 允许重边、乃至自环。这类冗余边**不影响连通性**，处理时必须能自然忽略（见引理 2）。
2. **终止符是单独一行 `0`** $\Rightarrow$ 读入 `n` 后判 `n==0` 即停；此时这一组不再有 `m`，直接结束。
3. **判定的是"可达"而非"直接相连"** $\Rightarrow$ 目标是把整张图的**连通分量**全部并成一个，这正是连通块计数问题。
4. **不要求输出具体方案，只要求条数** $\Rightarrow$ 只要算出连通分量个数即可。

**数据范围与规模感受**

$$1\le n<1000 .$$

$n$ 很小，但 $m$ 未给上界（可达 $O(n^2)$ 甚至更多组）。这提示用**近线性**的并查集（路径压缩）在线处理每条边，而不是每组合法都重做一遍 DFS；多组数据下并查集更是天然合适。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"最少加边"问题降维成"数连通块"

先追问：修一条路最多能让"城镇连通状况"改善多少？把当前图的城镇划分成若干**极大连通块**（互相可达的城镇归为一类）。

**引理 1（一条新边至多把连通块数减 1）**

设当前图有 $c$ 个连通块。任意新增一条边，连通块数只能减少 $0$ 或 $1$，**绝不会减少更多**。

**证明**：新增无向边只是连接它两个端点 $u,v$ 所在的连通块 $C_u,C_v$。
- 若 $C_u=C_v$（同块，含端点重复/自环）：并集不变，$c$ 不变（减少 0）。
- 若 $C_u\ne C_v$：新边把两块**合并为一个**连通块，其余连通块互不影响。合并是"两块并成一块"，块数从 $c$ 变为 $c-1$，减少 1。
无论·如何，单条边的效果都是把选中两块合成一块或不生效，故减少量 $\le1$。$\blacksquare$

**引理 2（最少加边数 = $c-1$）**

**（下界）** 由引理 1，加 $k$ 条边后连通块数 $\ge c-k$。要连通（即只剩 1 块）需 $c-k\le1$，即 $k\ge c-1$。

**（上界/可达）** 把 $c$ 个连通块 $C_1,\dots,C_c$ 各选一个代表点 $p_1,\dots,p_c$。只需加边 $p_1\!-\!p_2,\ p_2\!-\!p_3,\ \dots,\ p_{c-1}\!-\!p_c$ 共 $c-1$ 条，即可把这 $c$ 块串成一条**链**，整图连通。当 $c=1$ 时 $c-1=0$ 条，图本就连通。

下界与可达同时成立 $\Rightarrow$ 最少加边数恰为 $c-1$。$\blacksquare$

> 这是本题的**核心归约**：一个"要在图上做决策"的优化问题，被压成"只数连通块个数"这一纯计数问题。**注意下界用的是引理 1 这条"局部效应"性质，而不是想当然**。

### 2.2 重边与自环：为什么可以完全不管

**引理 3（重边、自环不改变连通块划分）**

平行边（同一对端点间的多条边）与自环（两端点是同一点）的加入，都不会改变任何两点的可达关系。

**证明**：可达关系由"存在路径"决定。自环 $u\!-\!u$ 是长度 1 的闭合回路，起点终点都是 $u$，不提供跨越不同点的连接，删除它不影响任何 $(x,y)$ 是否存在路径（含 $x=y$ 的情形）。平行边 $u\!-\!v$ 与已有的一条 $u\!-\!v$ 的"连接效果"完全相同：它们都只是把 $u,v$ 贴近同一块；删去多余的那些，可达性不变。$\blacksquare$

> 因此实现里对"已经在同一块"的边**直接跳过**即可，不必去重、不必存多重图。

### 2.3 经典技术：并查集增量维护连通块数

既然只需数连通块，用并查集（DSU）最省事：初始每个点自成一派（$c=n$），每读入一条边，若两端点**当前根不同**就合并，并让 $c$ 减 1；若相同就什么都不做。

**引理 4（$c$ 与 DSU 根数目一致）**

DSU 中"根节点"的个数恰好等于当前图连通块数 $c$。

**证明**：DSU 的每个集合由"合并"操作生成，而合并操作只在**存在一条边连接两个不同集合**时发生（引理 3 保证重复边不会触发合并）。因此 DSU 的一个集合 $\iff$ 图中的一个连通块：任一邻接的两点必被某次合并放进同一集合（对边的归纳），反之同一集合内任意两点由一连串合并串起，每次合并对应的边首尾相接构成一条路径，故它们互相可达。集合与连通块一一对应，其个数自然相等。$\blacksquare$

于是每当发生一次有效合并就 `--c`，全程 $c$ 始终等于"根数"，最终答案 `c-1`。

### 2.4 多组数据：别忘重置

每组都要把 `f[i]=i`、`c=n` 重置一遍。若沿用上一组并在同一批数组上继续跑，会把上一组的连通关系残留进来。

**失败思路**：把 $n$ 组数据的所有边混进一个 DSU。后果：不同组之间的编号会串味（比如组 A 的城镇 3 和组 B 的城镇 3 被当成同一个点），答案完全错乱。$\Rightarrow$ **每组独立重置**。

### 2.5 边界体检

- $n=1,m=0$：$c=1$，答案 $0$ ✓。
- 终止：读到 `n==0` 立刻结束；代码用 `while(cin>>n&&n)`，若 `n` 读失败或为 0 即停止。
- 复杂度：每组 $O((n+m)\,\alpha(n))$，$\alpha$ 为反阿克曼函数，几乎常数。

## 3. 模式总结（Pattern Summary）

**模式名：连通性最小补边的「连通块计数」归约。**

按实际思考顺序：

- **explore its property** — 单条新边对"连通块数"的影响至多为减少 1。
- **reduce to easier problem** — 由引理 1 的局部效应推出最少加边数 $=c-1$（下界 + 构造双向证明，引理 2）。
- **ignore irrelevant input** — 重边/自环不改变连通划分，直接跳过（引理 3）。
- **classic problem solution** — 用并查集增量维护连通块数：合并成功就 `--c`（引理 4）。
- **reset per test case** — 多组数据每组重置 `f[i]=i` 与 `c=n`，防止状态串味。

**一句话记忆**：问"最少加多少边让全图连通"，答案就是"连通块数 $-1$"；数连通块用并查集。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| `n` | `int` | 城镇数目 | 读入 | 题面 |
| `m` | `int` | 本组道路条数 | 读入 | 题面 |
| `f[x]` | `int[mxn]` | 并查集父指针（0-based） | 每组 `f[i]=i` | DSU father |
| `cnt` | `int` | 当前连通块数 $c$ | 每组 `cnt=n` | component count |
| `u`,`v` | `int`（循环内） | 一条道路的两个端点 | 读入后 `--` | 题面 1-based 转换 |

### 4.2 编号步骤

1. `cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`。
2. `for(int n,m; cin>>n&&n;)`：读到非 0 的 `n` 就处理，读到 0 结束。
   2.1 读 `m`；`for(i=0..n-1) f[i]=i;`，`cnt=n`。
   2.2 对每条边：读 `u,v` 并 `--`，求 `ru=getrt(u), rv=getrt(v)`。
   2.3 若 `ru!=rv`，`f[ru]=rv; --cnt;`（有效合并，引理 4）。
   2.4 输出 `cnt-1`（引理 2）。
3. 循环自然结束。

### 4.3 复杂度与验证状态

- 时间：每组 $O((n+m)\,\alpha(n))$，几乎线性；空间 $O(n)$。
- **官方样例**：`4 2/1 3/4 3/3 3/1 2/1 3/2 3/5 2/1 2/3 5/999 0/0` $\to \texttt{1 0 2 998}$ ✓（其中第 4 组 $n=999,m=0$ 输出 $998$，恰为 $c-1=999-1$）。
- **随机对拍**：$300$ 组（每组随机 $n\in[1,8]$、随机边含重边/自环，多组拼接后以 `0` 结尾）标程与"建图 DFS 数连通块"暴力**逐字节一致** ✓。
- **边界**：`1 0` $\to 0$；三重边 `3 4 / 1 2 / 1 2 / 2 1 / 1 2` $\to 1$ ✓。
- **最坏规模计时**：$20$ 组各 $n=999,m=3000$ 随机边，最后一行输出 $4$，耗时 **$0.0122$ s**。
- 残余风险：无（题面保证 $n<1000$，`mxn{1005}` 足够）。

## 5. 示例代码

### 5.1 主解：并查集增量维护（标程）

```cpp
//
// 题目：P1536 村村通
// https://www.luogu.com.cn/problem/P1536
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};          // n<1000 (+5 松弛)

int f[mxn];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(int n,m;cin>>n&&n;)        // 读到单独的 0 结束
	{
		cin>>m;
		for(int i=0;i<n;++i)
			f[i]=i;                // 每组重置并查集(0-based)
		int cnt=n;                 // 连通块数,初始 n 个孤点
		for(int j=0,u,v;j<m;++j)
		{
			cin>>u>>v;--u;--v;
			int ru=getrt(u),rv=getrt(v);
			if(ru!=rv)
			{
				f[ru]=rv;
				--cnt;             // 每合并一次,块数减一
			}
		}
		cout<<cnt-1<<'\n';         // 把 cnt 个连通块串起来需 cnt-1 条边
	}
	return 0;
}
```

### 5.2 对照实现：显式建图 + DFS 数连通块（仅用于对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;

// 独立基准：显式建图后 DFS 数连通块，与标程的并查集路径不同。
int n,m;
vector<int> g[1005];
bool vis[1005];

void dfs(int u)
{
	vis[u]=1;
	for(int v:g[u])
		if(!vis[v])
			dfs(v);
}

int main()
{
	while(cin>>n&&n)
	{
		cin>>m;
		for(int i=0;i<n;++i)
		{
			g[i].clear();
			vis[i]=0;
		}
		for(int j=0,u,v;j<m;++j)
		{
			cin>>u>>v;--u;--v;
			g[u].push_back(v);
			g[v].push_back(u);
		}
		int c=0;
		for(int i=0;i<n;++i)
			if(!vis[i])
			{
				++c;
				dfs(i);
			}
		cout<<c-1<<'\n';
	}
	return 0;
}
```

两版**输出逐字节相同**（$300$ 组随机 + 官方样例确认）。暴力版把"根数"换成"独立跑 DFS 数连通块"，绕开了并查集的路径压缩与合并计数，因此若标程在"合并条件/计数器增减"上有掩蔽性 bug，会被立刻发现。

### 5.3 易错点清单

- **合并时无条件 `--cnt`** $\Rightarrow$ 把重边/同块边也当有效合并，答案偏小；必须先比较根。
- **每组忘记重置 `f[i]=i`** $\Rightarrow$ 上一组关系残留，答案错乱。
- **忘记处理终止符 `0`** $\Rightarrow$ 死循环或把 0 当成 $n$ 去读 $m$。
- **输出 `cnt` 而非 `cnt-1`** $\Rightarrow$ 差 1（$n$ 个块要 $n-1$ 条边）。
- **城镇编号用 1-based 混进 0-based DSU** $\Rightarrow$ 越界；读入即 `--`。
- **`endl` 换行** $\Rightarrow$ 违反风格，用 `'\n'`。
