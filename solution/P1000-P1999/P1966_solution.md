# P1966 [NOIP 2013 提高组] 火柴排队

## 1. 重新读题

### 1.1 问题重述（人话版）

有两列各 $n$ 根火柴，第一列高度为 $a_1..a_n$，第二列高度为 $b_1..b_n$，同一列内高度互不相同。距离定义为

$$
D=\sum_{i=1}^{n}(a_i-b_i)^2 .
$$

每一步可以交换**任意一列中相邻的两根**火柴。问：先让 $D$ 达到最小，再在这个前提下让交换次数最少，这个最少次数对 $10^8-3$ 取模是多少。

注意：交换只在「本列内部」进行，两列的火柴不会互相移动；要求的是**两列的排列方式**，不要求 $a_i=b_i$，只要求 $D$ 最小。

### 1.2 关键约束与规模暗示

- $n\le 10^5$，$a_i,b_i<2^{31}$，同一列内元素互不相同。
- $10\%$：$n\le 10$；$30\%$：$n\le 100$；$60\%$：$n\le 10^3$。
- $n\le 10^5$ 排除了 $O(n^2)$ 的枚举配对和模拟交换，必须做到 $O(n\log n)$。
- 高度到 $2^{31}$，但只有相对大小有意义，因此要**离散化 / 按排名**处理。
- 取模 $10^8-3$ 说明交换次数本身可能非常大（最多约 $n(n-1)/2\approx 5\times 10^9$，超出 `int`），要用 `long long` 并在累加时取模。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先不管交换次数，只问：什么样的配对使 $D$ 最小

两列各自怎么排，等价于决定一个**配对**：第一列的每根火柴对应第二列的哪一根。因为位置只是一一对应，$D$ 只依赖这个配对。

先看 $n=2$ 的情形，记 $a_1<a_2$、$b_1<b_2$。只有两种配对方式：

$$
(a_1-b_1)^2+(a_2-b_2)^2 \quad\text{与}\quad (a_1-b_2)^2+(a_2-b_1)^2 .
$$

前者是「同序配对」，后者是「交叉配对」。直接相减：

$$
\begin{aligned}
&\big[(a_1-b_2)^2+(a_2-b_1)^2\big]-\big[(a_1-b_1)^2+(a_2-b_2)^2\big]\\
={}&2(a_2-a_1)(b_2-b_1)>0 .
\end{aligned}
$$

所以同序配对更优。

这提示了一个一般性的结论：**排序后对应位置配对**（都按升序）使平方和最小。下面用交换论证严格证明。

**引理 1（同序配对最优）**：设 $a_i<a_j$。若在某个配对中 $a_i$ 配了较大的 $b$、$a_j$ 配了较小的 $b$（即配成 $b_p>b_q$ 且 $a_i\leftrightarrow b_p,\ a_j\leftrightarrow b_q$），把这两人对调成 $a_i\leftrightarrow b_q,\ a_j\leftrightarrow b_p$ 后，$D$ 不会增大；若 $a_i<a_j$ 且 $b_q<b_p$ 严格，则 $D$ 严格减小。

**证明**：只需比较这两项，其它项不受影响。对调前（交叉）减去对调后（同序）：

$$
\begin{aligned}
&\big[(a_i-b_p)^2+(a_j-b_q)^2\big]-\big[(a_i-b_q)^2+(a_j-b_p)^2\big]\\
={}&-2a_ib_p-2a_jb_q+2a_ib_q+2a_jb_p\\
={}&2(a_j-a_i)(b_p-b_q)>0 .
\end{aligned}
$$

所以同序严格更小。$\square$

**推论**：把第一列按高度升序重排、第二列也按高度升序重排，对应位置配对时 $D$ 最小。

**证明**：任取一个最优配对。若存在 $a_i<a_j$ 而对应的 $b$ 是逆序的，由引理 1 对调后 $D$ 严格下降，与最优矛盾。因此最优配对中 $a$ 的顺序与对应 $b$ 的顺序完全一致，即「按 $a$ 升序排列后，$b$ 也升序」。

再说明这个配对唯一：设 $a$ 的最小元配了某个 $b$。如果它不是 $b$ 的最小元，那么 $b$ 的最小元配着某个更大的 $a$，这两对构成逆序，与上面的结论矛盾。故最小配最小。删去这对后对剩余元素重复同样论证，归纳得「$a$ 的第 $r$ 小配 $b$ 的第 $r$ 小」。$\square$

> 也可以都按降序，但「$a$ 第 $r$ 小配 $b$ 第 $r$ 小」与「$a$ 第 $r$ 大配 $b$ 第 $r$ 大」是同一个配对，所以答案唯一。

### 2.2 问题转化为「把配对摆正」需要多少次相邻交换

既然最优配对已经确定，剩下的问题是：初始排列到「每个位置上的 $a$ 与 $b$ 同排名」这个目标，最少要交换多少次相邻元素。

一个常见的误区是：先把某一列排好序，再数另一列的逆序对。这个做法**结果是对的**，但需要解释为什么「只动一列」不会比「两列都动」更差。

**把问题抽象成序列**。对第一列的位置 $i$，定义

$$
\pi_i=\text{第二列中与 }a_i\text{ 同排名的那根火柴当前所在的位置}.
$$

例如 $a_i$ 是第 $r$ 小的，那么 $\pi_i$ 就是「第二列第 $r$ 小的火柴现在站在第几号位置」。

**引理 2（配对摆正 $\iff$ $\pi$ 升序）**：目标状态（每个位置的两根火柴同排名）等价于 $\pi_1<\pi_2<\cdots<\pi_n$。

**证明**：

- 若目标达成，则对 $i<j$，位置 $i$ 的 $a$ 排名小于位置 $j$ 的 $a$ 排名，而两位置上的 $b$ 排名分别与它们相等，所以 $b$ 的排名也满足「位置 $i$ 小于位置 $j$」。同排名在第二列中的位置顺序与排名顺序一致，故 $\pi_i<\pi_j$。
- 反之若 $\pi_i<\pi_j$ 对所有 $i<j$ 成立，则第一列从左到右的排名递增，第二列中对应伙伴的位置也递增，即第二列从左到右排名同样递增，两列逐位置排名相等。$\square$

**引理 3（每次相邻交换最多修正一个逆序对）**：记 $\mathrm{inv}(\pi)$ 为 $\pi$ 的逆序对数。

1. 交换第一列相邻的两个元素，等价于交换 $\pi$ 中相邻的两个数，$\mathrm{inv}(\pi)$ 恰好变化 $\pm1$；
2. 交换第二列相邻的两根火柴（位置 $p,p+1$），等价于把 $\pi$ 中值为 $p$ 和 $p+1$ 的两个元素互换，这两个元素在 $\pi$ 中不一定相邻，但交换它们使 $\mathrm{inv}(\pi)$ 的变化量绝对值不超过 $1$。

**证明**：

1. 相邻交换只改变这两个元素之间的相对顺序，与其它元素的相对顺序都不变，所以逆序数变化 $\pm1$。这是逆序对的标准性质：被交换的两数若原本有序则逆序数 $+1$，否则 $-1$。
2. 设值 $p$ 在 $\pi$ 的位置为 $u$，值 $p+1$ 的位置为 $v$。交换后对任意第三个值 $q$，$(p,q)$ 与 $(p+1,q)$ 两对逆序贡献之和不变（分 $q<p$、$q>p+1$、$q$ 位于 $u,v$ 之间三种情况，计数都不变）。但 $p,p+1$ 是相邻整数，二者之间没有其它整数值，所以真正改变顺序的只有 $(p,p+1)$ 这一对本身，逆序数变化 $\pm1$。$\square$

**引理 4（最少交换次数 $=\mathrm{inv}(\pi)$）**：

**证明**：

- **下界**：目标要求 $\pi$ 升序，即 $\mathrm{inv}(\pi)=0$。由引理 3，无论交换哪一列的相邻元素，一次交换最多让 $\mathrm{inv}(\pi)$ 改变 $1$。初始逆序数为 $\mathrm{inv}(\pi_0)$，所以至少需要 $\mathrm{inv}(\pi_0)$ 次。
- **上界**：只对第一列做冒泡排序式的相邻交换，把 $\pi$ 排成升序。每交换一个逆序相邻对，逆序数恰好减 $1$，共用 $\mathrm{inv}(\pi_0)$ 次。这些交换都是合法的「第一列相邻交换」。故 $\mathrm{inv}(\pi_0)$ 次可行。

上下界相同，最少次数为 $\mathrm{inv}(\pi_0)$。$\square$

于是问题归结为：**构造 $\pi$ 并求逆序对数**，用树状数组或归并排序在 $O(n\log n)$ 完成。

### 2.3 具体怎么构造 $\pi$

1. 把第一列的下标按高度升序排序，得到 `ida[0..n-1]`：`ida[r]` 是「第 $r$ 小的 $a$ 所在的位置」。
2. 同理得到 `idb[r]`：第二列第 $r$ 小的火柴所在的位置。
3. 对每个排名 $r$，`a` 的位置 `ida[r]` 的伙伴是 `b` 的位置 `idb[r]`，所以令
   $$
   \pi_{\texttt{ida}[r]}=\texttt{idb}[r].
   $$

这样 $\pi$ 就是一个 $0\sim n-1$ 的排列。求它的逆序对：从左到右扫，用树状数组维护已经出现过的值，当前值 $v$ 之前比它大的个数为「已插入总数 $-$ 前缀和到 $v$」，累加即可。

### 2.4 坑点

- **离散化用排名，不要用高度值**：高度到 $2^{31}$，树状数组开不下，而且相等性不需要考虑（题面保证同列互不相同）。
- **取模**：逆序对最多约 $5\times10^9$，`int` 会溢出；用 `long long`，每次累加后对 $99999997$ 取模。
- 模数是 $10^8-3=99999997$，不是 $10^9+7$，抄错就全错。
- $n=1$ 时没有逆序对，输出 $0$。
- 排序比较器只比较高度，不比较下标；高度互不相同，所以不会出现平局。

## 3. 模式总结（Pattern Summary）

- **explore its property** — $D$ 只依赖配对方式，位置本身不重要。
- **exchange argument** — 交叉配对交换成同序配对后 $D$ 严格变小，故最优配对是「排名相同者配对」。
- **reduce to easier problem** — 固定最优配对后，问题变成「用相邻交换把相对顺序摆正」。
- **classic problem solution** — 构造「伙伴位置」排列 $\pi$，答案等于 $\pi$ 的逆序对数。
- **classic problem solution** — 树状数组 / 归并排序求逆序对，$O(n\log n)$。
- **modular accounting** — 逆序对用 `long long` 累加并对 $10^8-3$ 取模。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 火柴根数 | 读入 | 规模 |
| `a[]`, `b[]` | `int [100005]` | 两列高度 | 读入 | 原数组 |
| `ida[]`, `idb[]` | `int [100005]` | 按高度升序排好的下标 | 排序得到 | index sorted |
| `seq[]` | `int [100005]` | $\pi$：`seq[ida[r]]=idb[r]` | 构造 | 伙伴位置 |
| `BIT[]` | `int [100005]` | 树状数组，统计已出现值的个数 | 0 | 值域计数 |
| `ans` | `i64` | 逆序对数（随时取模） | 0 | 答案 |
| `p` | `constexpr int` | $10^8-3=99999997$ | — | 模数 |

### 4.2 算法步骤

1. 读入 $n,a,b$，初始化 `ida[i]=idb[i]=i`。
2. 分别按 `a`、`b` 的值升序排序下标数组。
3. 对 $r=0..n-1$ 令 `seq[ida[r]]=idb[r]`。
4. 从左到右扫 `seq`：设当前已插入 $i$ 个数，值 $v=\texttt{seq}[i]$。树状数组前缀查询得到 $\le v$ 的已插入个数 `le`，则新增逆序对为 $i-\texttt{le}$；累加并取模；然后把 $v$ 插入树状数组。
5. 输出 `ans % p`。

### 4.3 复杂度分析

- **时间复杂度**：两次排序 $O(n\log n)$，构造 $O(n)$，逆序对 $O(n\log n)$，总计 $O(n\log n)$。
- **空间复杂度**：$O(n)$。

## 5. 示例代码

```cpp
//
// 题目：P1966 [NOIP 2013 提高组] 火柴排队
// https://www.luogu.com.cn/problem/P1966
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};
constexpr int p{99999997};          // 10^8-3

int n;
int a[mxn],b[mxn],ida[mxn],idb[mxn],seq[mxn];
int BIT[mxn];

bool cmpa(int x,int y){return a[x]<a[y];}
bool cmpb(int x,int y){return b[x]<b[y];}

void add(int x)
{
	for(++x;x<=n;x+=x&-x)
		++BIT[x];
}
int sigma(int x)                     // 已插入值中 <=x 的个数，x 为 0-based
{
	int s{0};
	for(++x;x>0;x-=x&-x)
		s+=BIT[x];
	return s;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		ida[i]=i;
	}
	for(int i=0;i<n;++i)
	{
		cin>>b[i];
		idb[i]=i;
	}

	sort(ida,ida+n,cmpa);
	sort(idb,idb+n,cmpb);
	for(int r=0;r<n;++r)
		seq[ida[r]]=idb[r];

	i64 ans{0};
	for(int i=0;i<n;++i)
	{
		ans+=(i-sigma(seq[i]));      // 前面比 seq[i] 大的个数
		ans%=p;
		add(seq[i]);
	}
	cout<<ans%p<<'\n';
	return 0;
}
```
