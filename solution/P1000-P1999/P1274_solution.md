# P1274 魔术数字游戏 —— 题解

## Part 1 —— 重新阅读题目

在一个 $4 \times 4$ 的方格中，用 $1$ 到 $16$ 每个数字恰好使用一次填满所有格子。要求满足以下六类约束，每一类中被指定的四个格子之和都必须等于 $34$：

1. 四个角：$A_{1,1}+A_{1,4}+A_{4,1}+A_{4,4}=34$。
2. 四个角落的 $2\times2$ 子方格各自和为 $34$（左上、右上、左下、右下）。
3. 正中央的 $2\times2$ 子方格和为 $34$。
4. 每一行的四个数之和为 $34$。
5. 每一列的四个数之和为 $34$。
6. 两条主对角线之和各为 $34$。

输入指定数字 $1$ 所在的行 $i$ 和列 $j$（$1 \le i,j \le 4$），即 $A_{i,j}=1$。输出所有合法填法，按字典序排序（先比第一行从左到右，再比第二行……），相邻两组解之间用一个空行分隔。

**关键观察**：数据规模极小（$4\times4=16$ 个格子，每格从 $1$ 到 $16$ 选），纯暴力搜索 $16! \approx 2.1\times10^{13}$ 不可行，必须强力剪枝。提示说样例（$1$ 放第一行第一列）有 $216$ 种解。

## Part 2 —— 思维链（逐步发现过程）

### 第一步：探索约束之间的数学关系（这是最重要的突破口）

我先把所有约束列出来，然后试着把它们联系起来。

**观察 1：所有行和之和 = 所有列和之和。**
四行各和为 $34$，总和 $136$。所有列也各和为 $34$，总和也是 $136$。而 $1+2+\cdots+16=136$，所以行和与列和的约束在总和层面是自洽的，没有矛盾。

**观察 2：四个角落 $2\times2$ 方格的和与行和、列和之间的关系。**

设四个角落 $2\times2$ 方格为：
- 左上 $TL = A_{1,1}+A_{1,2}+A_{2,1}+A_{2,2}=34$
- 右上 $TR = A_{1,3}+A_{1,4}+A_{2,3}+A_{2,4}=34$
- 左下 $BL = A_{3,1}+A_{3,2}+A_{4,1}+A_{4,2}=34$
- 右下 $BR = A_{3,3}+A_{3,4}+A_{4,3}+A_{4,4}=34$

四个角落 $2\times2$ 方格的总和为 $136$。

另一方面，把所有格子分成四个区域：
- 左上 $2\times2$（即 $TL$ 覆盖的区域）
- 右上 $2\times2$（即 $TR$ 覆盖的区域）
- 左下 $2\times2$（即 $BL$ 覆盖的区域）
- 右下 $2\times2$（即 $BR$ 覆盖的区域）

这四个区域恰好不重叠地覆盖全部 $16$ 个格子！所以 $TL+TR+BL+BR=136$ 恒成立，这个等式不产生新约束（四个 $34$ 加和正好 $136$）。

**观察 3：行和约束与 $2\times2$ 约束的交互。**

第一行和：$R_1 = A_{1,1}+A_{1,2}+A_{1,3}+A_{1,4}=34$。
左上 $2\times2$ 和：$TL = A_{1,1}+A_{1,2}+A_{2,1}+A_{2,2}=34$。
右上 $2\times2$ 和：$TR = A_{1,3}+A_{1,4}+A_{2,3}+A_{2,4}=34$。

注意 $TL+TR = (A_{1,1}+A_{1,2}+A_{2,1}+A_{2,2})+(A_{1,3}+A_{1,4}+A_{2,3}+A_{2,4})$
$= (A_{1,1}+A_{1,2}+A_{1,3}+A_{1,4})+(A_{2,1}+A_{2,2}+A_{2,3}+A_{2,4}) = R_1+R_2$。

所以 $TL+TR = R_1+R_2$，即 $68 = 68$，恒成立。这告诉我们行和约束与角落 $2\times2$ 约束在"行总和"层面是冗余的——但它们在个体格子层面不冗余，因为 $TL=34$ 和 $TR=34$ 分别施加了具体的格子组合约束。

**观察 4：中心 $2\times2$ 与行和/列和的关系。**

中心 $2\times2$：$C = A_{2,2}+A_{2,3}+A_{3,2}+A_{3,3}=34$。

这个约束相对独立，和行和/列和没有直接的冗余关系（中心 $2\times2$ 只占内部 $4$ 格，不延伸到边界）。

**观察 5：四个角之和与对角线的关系。**

四角：$A_{1,1}+A_{1,4}+A_{4,1}+A_{4,4}=34$。
对角线 $D_1$：$A_{1,1}+A_{2,2}+A_{3,3}+A_{4,4}=34$。
对角线 $D_2$：$A_{1,4}+A_{2,3}+A_{3,2}+A_{4,1}=34$。

注意 $D_1+D_2 = (A_{1,1}+A_{4,4})+(A_{1,4}+A_{4,1})+(A_{2,2}+A_{3,3})+(A_{2,3}+A_{3,2})$
$= (A_{1,1}+A_{1,4}+A_{4,1}+A_{4,4})+C = 34+34=68$。
而 $D_1+D_2=68$ 恒成立（因为两对角线各 $34$），所以 $C=34$ 与四角和 $34$ 是对角线约束的推论……

等等，让我重新验证：
$D_1+D_2 = (A_{1,1}+A_{2,2}+A_{3,3}+A_{4,4})+(A_{1,4}+A_{2,3}+A_{3,2}+A_{4,1})$

把格子按位置分类：
- 角：$A_{1,1}, A_{1,4}, A_{4,1}, A_{4,4}$
- 中心 $2\times2$：$A_{2,2}, A_{2,3}, A_{3,2}, A_{3,3}$

$D_1+D_2$ 包含的格子：$A_{1,1}, A_{2,2}, A_{3,3}, A_{4,4}$（来自 $D_1$）和 $A_{1,4}, A_{2,3}, A_{3,2}, A_{4,1}$（来自 $D_2$）。
这些恰好是：全部四个角 + 全部四个中心格 = 四角之和 + 中心 $2\times2$ 之和。

所以 $D_1+D_2 = (\text{四角和}) + C$。
由约束：$D_1=34, D_2=34$，所以 $D_1+D_2=68$。
由约束：四角和 $=34, C=34$，所以四角和 $+C=68$。
两边一致，恒等式，不产生新信息。

**但反过来**：如果我们只有 $D_1=34, D_2=34$ 和四角和 $=34$，能不能推出 $C=34$？
$C = D_1+D_2 - (\text{四角和}) = 34+34-34=34$。
**是的！** 这意味着：如果对角线约束和四角约束都满足，那么中心 $2\times2$ 约束自动满足。

等等，这不对。让我重新检查。$D_1+D_2$ 的格子集合是 $\{A_{1,1}, A_{2,2}, A_{3,3}, A_{4,4}\} \cup \{A_{1,4}, A_{2,3}, A_{3,2}, A_{4,1}\}$。

四角的格子集合是 $\{A_{1,1}, A_{1,4}, A_{4,1}, A_{4,4}\}$。
中心 $2\times2$ 的格子集合是 $\{A_{2,2}, A_{2,3}, A_{3,2}, A_{3,3}\}$。

$D_1 \cup D_2$ 的格子集合 = $\{A_{1,1}, A_{1,4}, A_{2,2}, A_{2,3}, A_{3,2}, A_{3,3}, A_{4,1}, A_{4,4}\}$
= 四角 $\cup$ 中心 $2\times2$。

所以 $D_1+D_2 = (\text{四角和}) + C$。

如果 $D_1=34, D_2=34$（已知），且四角和 $=34$（已知），则 $C = 68-34=34$。✓

**结论：中心 $2\times2$ 约束是行/列/对角线/四角约束的推论，是冗余的。** 我们不需要在搜索中单独检查它。

等一下，让我再确认一下。我上面只用了四角和与对角线，没有用行和列和。让我验证一个具体例子……

实际上让我再仔细想想。$D_1 \cup D_2$ 是否真的恰好是四角 $\cup$ 中心 $2\times2$？

$D_1$: 位置 $(1,1), (2,2), (3,3), (4,4)$
$D_2$: 位置 $(1,4), (2,3), (3,2), (4,1)$

$D_1 \cup D_2$: $(1,1), (1,4), (2,2), (2,3), (3,2), (3,3), (4,1), (4,4)$

四角: $(1,1), (1,4), (4,1), (4,4)$ ✓ 都在 $D_1 \cup D_2$ 中。
中心 $2\times2$: $(2,2), (2,3), (3,2), (3,3)$ ✓ 也都在 $D_1 \cup D_2$ 中。
$D_1 \cup D_2$ 总共 $8$ 个格子，四角 $4$ 个 + 中心 $4$ 个 $= 8$ 个，不重叠，完美匹配。✓

所以确认：**中心 $2\times2$ 约束 = $D_1$ 约束 + $D_2$ 约束 + 四角约束 的推论**。

**但注意**：这个推论依赖于 $D_1=34$ 且 $D_2=34$ 且四角和 $=34$ 同时成立。在搜索中我们仍然需要检查这些非冗余约束。中心 $2\times2$ 约束可以作为额外的快速剪枝检查（虽然它自动满足，但显式检查它不增加错误风险，且可以提前剪掉一些分支——等等，如果它是推论，那么满足其他约束的解一定也满足它，所以检查它不会产生额外剪枝。但它也不产生错误，所以留着无害，去掉也行。为了代码简洁，我选择保留所有约束检查，不做冗余分析——因为 $4\times4$ 的检查代价极小，且能降低出错风险）。

实际上，让我重新考虑。在 DFS 中，当我们填完所有格子后，需要检查所有约束。如果中心 $2\times2$ 是冗余的，检查它不会多剪任何东西，但也不亏（只是多一个加法比较）。为了代码清晰和安全性，我保留所有约束检查。

### 第二步：考虑搜索策略

$16$ 个格子，$1$ 已固定，剩余 $15$ 个格子放 $2$ 到 $16$。直接 DFS 搜索 $15!$ 不可行。需要强力剪枝。

**剪枝策略 1：逐格填，填完一行或一列时立即检查和。**

最自然的 DFS 顺序是逐格填充：$(1,1), (1,2), (1,3), (1,4), (2,1), \ldots, (4,4)$。

当填完第 $i$ 行的第 $4$ 个格子（即 $A_{i,4}$）时，可以检查第 $i$ 行的和是否为 $34$。如果不是，立即回溯。

当填完第 $4$ 行的某个格子 $A_{4,j}$ 时，可以检查第 $j$ 列的和是否为 $34$（因为此时第 $j$ 列的所有格子都已填完）。

更一般地，当我们填格子 $A_{i,j}$ 时：
- 如果 $j=4$（行末），可以检查第 $i$ 行的和。
- 如果 $i=4$（列末，即最后一行），可以检查第 $j$ 列的和。

但更精细的剪枝是：**在填 $A_{i,j}$ 时，如果第 $j$ 列的前 $i-1$ 个格子之和已经超过 $34$，或者即使剩余格子全填最小值也无法达到 $34$，则剪枝。** 但这需要额外维护列的部分和，且 $4\times4$ 规模下收益不大。

**剪枝策略 2：对称性剪枝。**

由于约束是关于行的（每行和 $34$）和列的（每列和 $34$），且 $2\times2$ 约束和四角约束也有对称性，可以考虑利用对称性减少搜索。但实现复杂，且 $4\times4$ 规模下逐格 DFS + 行和剪枝已经足够快，暂不考虑。

**剪枝策略 3：逐格填 + 行和即时检查 + 列和延迟检查。**

我选择这个策略，简单且有效：

- 逐格 DFS 填充顺序：$(0,0), (0,1), (0,2), (0,3), (1,0), \ldots, (3,3)$（0-based）。
- 每填完一格，检查：
  - 当前行已填部分之和不超过 $34$（如果超了，剪枝）。
  - 当前列已填部分之和不超过 $34$（如果超了，剪枝）。
  - 如果填的是行末（$j=3$），检查该行和恰好为 $34$。
  - 如果填的是最后一行（$i=3$），检查该列和恰好为 $34$。
- 填完所有 $16$ 格后，检查所有剩余约束（角落 $2\times2$、中心 $2\times2$、四角、两条对角线）。

实际上，行和和列和约束在填的过程中就已经全部满足了（每行在行末检查，每列在最后一行检查），所以填完后只需检查：
- 四个角落 $2\times2$
- 中心 $2\times2$
- 四角
- 两条对角线

**关键优化：按列填完最后一行时同时检查列和，这样行和列和都在 DFS 过程中被检查，最终只需检查 $2\times2$ 类约束。**

让我更精确地设计 DFS 的剪枝时机：

设填充顺序为按行优先：先填第 $0$ 行的 $4$ 格，再第 $1$ 行……每行填完 $4$ 格时检查行和。当填到第 $3$ 行（最后一行）的某列 $j$ 时，检查第 $j$ 列的和（因为此时该列 $4$ 格全填完）。

这样：
- 行和约束：在每行第 $4$ 格填完后检查（共 $4$ 次）。
- 列和约束：在最后一行的每格填完后检查（共 $4$ 次）。

**进一步剪枝：在填 $A_{i,j}$ 时，如果 $j<3$（非行末），检查第 $i$ 行前 $j+1$ 格之和 $\le 34$；如果 $i<3$（非最后一行），检查第 $j$ 列前 $i+1$ 格之和 $\le 34$。** 这些是部分和上界剪枝，能提前剪掉一些分支。

但实际上，由于每格最小为 $1$、最大为 $16$，部分和上界剪枝的效果有限（$4$ 格之和范围 $[4,64]$，上界 $34$ 不算紧）。最有效的剪枝还是行末/列末的精确检查和。

**我决定采用最简洁的策略：**
1. 逐格 DFS（行优先顺序）。
2. 每填一格，检查已确定的行和/列和是否超过 $34$（部分和剪枝）。
3. 行末检查行和 $= 34$，最后一行检查列和 $= 34$。
4. 全部填完后检查剩余约束。

由于 $1$ 已固定，DFS 从剩余 $15$ 格开始。搜索空间被行和/列和剪枝大幅缩减。

### 第三步：为什么这个剪枝足够？（直觉分析）

第一行有 $4$ 格（其中 $1$ 可能在其中），从 $1$ 到 $16$ 中选 $4$ 个不同数字和为 $34$ 的组合数有限。估算：从 $1$ 到 $16$ 选 $4$ 个不同数和为 $34$ 的组合大约有几十种。第二行同理。列和进一步约束。

实际上，$16$ 个数字固定为 $1$ 到 $16$ 各一个，所以这不是"选组合"而是"排列"。但行和约束大幅限制了每行的排列。

对于 $4$ 个不同数字（从 $1$ 到 $16$ 中选）和为 $34$ 的组合，数量级大约在 $50$ 左右（不精确估算，但远小于 $16\choose4=1820$）。所以第一行（含 $1$）的可能排列数大约是 $50 \times 4! = 1200$ 量级（如果 $1$ 在行内则更少）。然后列和约束进一步大幅剪枝。

实际运行中，这种 DFS 在 $4\times4$ 规模下通常毫秒级完成。

### 第四步：输出排序

题目要求按字典序输出（先比第一行，再第二行……）。DFS 按行优先顺序逐格填充，且每格从小到大尝试可用数字，**天然产生字典序**！因为：
- 先填 $A_{0,0}$，从小到大尝试。
- $A_{0,0}$ 确定后填 $A_{0,1}$，从小到大……
- 这就是字典序遍历。

所以 DFS 的输出顺序就是字典序，不需要额外排序。✓

### 第五步：完整约束检查设计

填完所有格子后，需要检查的约束（行和列和已在 DFS 中检查）：

1. 四角：$a[0][0]+a[0][3]+a[3][0]+a[3][3]=34$
2. 左上 $2\times2$：$a[0][0]+a[0][1]+a[1][0]+a[1][1]=34$
3. 右上 $2\times2$：$a[0][2]+a[0][3]+a[1][2]+a[1][3]=34$
4. 左下 $2\times2$：$a[2][0]+a[2][1]+a[3][0]+a[3][1]=34$
5. 右下 $2\times2$：$a[2][2]+a[2][3]+a[3][2]+a[3][3]=34$
6. 中心 $2\times2$：$a[1][1]+a[1][2]+a[2][1]+a[2][2]=34$
7. 主对角线：$a[0][0]+a[1][1]+a[2][2]+a[3][3]=34$
8. 副对角线：$a[0][3]+a[1][2]+a[2][1]+a[3][0]=34$

其中 $6$（中心 $2\times2$）是冗余的（由 $1,7,8$ 推出），但检查它无害。

为了代码清晰，我用一个数组存储所有 $8$ 个检查的格子位置，循环检查。

### 第六步：DFS 细节

```
dfs(pos):
    if pos == 16:
        check all constraints
        if all satisfied: output solution
        return
    i = pos / 4, j = pos % 4
    if a[i][j] != 0:  # 已固定（数字1的位置）
        dfs(pos+1)
        return
    for num in 2..16:
        if used[num]: continue
        a[i][j] = num; used[num] = true
        # prune: row partial sum
        row_sum = sum of a[i][0..j]
        if row_sum > 34:
            a[i][j] = 0; used[num] = false; continue
        # prune: col partial sum
        col_sum = sum of a[0..i][j]
        if col_sum > 34:
            a[i][j] = 0; used[num] = false; continue
        # if last col of row, check row sum
        if j == 3 and row_sum != 34:
            a[i][j] = 0; used[num] = false; continue
        # if last row, check col sum
        if i == 3 and col_sum != 34:
            a[i][j] = 0; used[num] = false; continue
        dfs(pos+1)
        a[i][j] = 0; used[num] = false
```

注意：当 $i==3$ 且 $j==3$ 时，同时检查行和与列和。

行部分和计算：`a[i][0]+a[i][1]+...+a[i][j]`，但只有 $a[i][0..j]$ 已填（$j$ 是当前列，之前的列已填）。实际上在 DFS 中，按行优先顺序，当填 $a[i][j]$ 时，$a[i][0..j-1]$ 已填，$a[i][j]$ 刚填，$a[i][j+1..3]$ 未填。所以行部分和是 $a[i][0]+...+a[i][j]$。

列部分和：$a[0][j]+...+a[i][j]$（$i$ 是当前行，之前的行已填）。

**关键细节**：当检查行部分和 $\le 34$ 时，需要确保即使剩余格子填最小可用值，总和也不会小于 $34$（下界剪枝）。但 $4\times4$ 规模下这个优化收益很小，且实现复杂（需要知道最小可用值），我跳过。

### 第七步：验证逻辑正确性

**命题 1**：DFS 按行优先顺序、每格从小到大尝试，产生的解的枚举顺序是字典序。

**证明**：设两个不同解 $S_1$ 和 $S_2$。设它们在位置 $p$（行优先第 $p$ 个格子）首次不同，即 $a_{S_1}[i_1][j_1] < a_{S_2}[i_1][j_1]$ 其中 $(i_1,j_1)$ 是第 $p$ 个位置。在 DFS 中，到达位置 $p$ 时，之前所有位置的值相同。DFS 在位置 $p$ 从小到大尝试数字，所以 $a_{S_1}[i_1][j_1]$ 对应的分支在 $a_{S_2}[i_1][j_1]$ 之前被探索。由于 DFS 是深度优先的，$S_1$ 所在分支在 $S_2$ 所在分支之前被完全探索（输出）。所以 $S_1$ 在 $S_2$ 之前输出。由字典序定义，$S_1$ 先于 $S_2$。∎

**命题 2**：DFS 中的行部分和剪枝（行部分和 $> 34$ 则剪枝）是正确的，即不会剪掉任何合法解。

**证明**：设 $a[i][0..j]$ 的部分和为 $S_{\text{part}}$，剩余格子 $a[i][j+1..3]$ 的值为正整数（每个 $\ge 1$），所以总和 $S_{\text{row}} = S_{\text{part}} + S_{\text{rest}} \ge S_{\text{part}} + (3-j)\cdot1$。如果 $S_{\text{part}} > 34$，则 $S_{\text{row}} > 34$，违反行和约束，当前分支无合法解，剪枝正确。∎

**命题 3**：行末精确检查（$j=3$ 时 $S_{\text{row}}=34$）是正确的。

**证明**：合法解要求 $S_{\text{row}}=34$。当 $j=3$ 时，行已填完，$S_{\text{row}}$ 确定。若 $S_{\text{row}}\ne34$，当前分支无合法解，剪枝正确。∎

**命题 4**：列末精确检查（$i=3$ 时 $S_{\text{col}}=34$）同理正确。

**证明**：与命题 3 对称。∎

**命题 5**：全部填完后检查 $2\times2$ 约束、四角约束、对角线约束是正确的。

**证明**：这些是题目给定的约束，合法解必须满足。不满足则非解，正确。∎

**命题 6**：DFS 不会遗漏任何合法解。

**证明**：设 $S$ 是一个合法解。DFS 在位置 $p$ 尝试的值 $a_S[i_p][j_p]$ 满足：(a) 未使用（$S$ 是排列，每个数用一次）；(b) 行部分和 $\le 34$（$S$ 行和 $=34$，部分和 $\le$ 总和 $=34$）；(c) 列部分和 $\le 34$（同理）；(d) 行末时行和 $=34$（$S$ 满足）；(e) 列末时列和 $=34$（$S$ 满足）；(f) 最终所有约束满足（$S$ 合法）。所以 DFS 在 $S$ 的每个位置都会尝试 $S$ 的值，不会被剪枝。由归纳，DFS 到达 $S$ 对应的叶子节点，输出 $S$。∎

### 第八步：时间复杂度估算

最坏情况 DFS 搜索空间为 $15!$（不可行），但剪枝大幅缩减。实际中：
- 第一行（含 $1$）：从剩余 $15$ 个数选 $3$ 个使行和 $=34$ 的组合数有限（约几十种），排列后约几百种。
- 列和约束进一步剪枝。
- 实际运行中（$4\times4$），DFS 节点数通常在 $10^4$ 到 $10^5$ 量级，毫秒级完成。

## Part 3 —— 模式总结

1. **探索约束间的数学关系** —— 发现中心 $2\times2$ 约束是四角+两对角线的推论（冗余约束），行和/列和在总和层面自洽。
2. **选择逐格 DFS + 即时剪枝** —— 行优先填充，行末检行和、列末检列和，部分和上界剪枝。
3. **利用填充顺序获得字典序** —— 行优先 + 每格从小到大尝试 = 天然字典序输出。
4. **延迟约束检查** —— 行和/列和在 DFS 过程中检查，$2\times2$ 类约束在叶子节点检查，减少检查频率。
5. **正确性论证** —— 剪枝只删"行和/列和已超或已确定不符"的分支，不影响合法解的存在性；DFS 枚举覆盖所有合法解。

## Part 4 —— 真正的解法（代码说明）

### 符号表

| 符号 | 含义 | 初始化 | 助记 |
|------|------|--------|------|
| `a[4][4]` | 方格，0 表示未填，1-16 表示已填的数字 | 全 0，然后 `a[i0][j0]=1` | a = grid |
| `used[17]` | 布尔数组，`used[x]=true` 表示数字 $x$ 已使用 | 全 false，然后 `used[1]=true` | used = number used |
| `i0, j0` | 数字 1 的 0-based 行/列坐标 | 输入 $i,j$ 后 `--i;--j` | 固定位置 |
| `cnt` | 已输出解的计数 | 0 | 用于控制空行 |
| `pos` | DFS 中当前填充的格子序号（0-15，行优先） | 参数传入 | position |

### 算法步骤

1. **读入** $i, j$，转 0-based 得 `i0, j0`。设 `a[i0][j0]=1`，`used[1]=true`。

2. **DFS 函数** `dfs(pos)`：
   - 若 `pos==16`：检查全部 $8$ 个非行/列约束（四角、四个角落 $2\times2$、中心 $2\times2$、两对角线）。若全满足，输出当前方格（$4$ 行，每行 $4$ 数空格分隔），若 `cnt>0` 则先输出一个空行，`cnt++`。返回。
   - 令 `i=pos/4`，`j=pos%4`。
   - 若 `a[i][j]!=0`（已固定为 $1$）：直接 `dfs(pos+1)`。
   - 否则，对 `num=2..16`：
     - 若 `used[num]` 跳过。
     - 设 `a[i][j]=num`，`used[num]=true`。
     - **行部分和剪枝**：计算 `rs=a[i][0]+a[i][1]+a[i][2]+a[i][3]` 中已填部分之和（$a[i][0..j]$）。若 `rs>34`，回溯（`a[i][j]=0, used[num]=false`），continue。
     - **列部分和剪枝**：计算 `cs=a[0][j]+a[1][j]+a[2][j]+a[3][j]` 中已填部分之和（$a[0..i][j]$）。若 `cs>34`，回溯，continue。
     - **行末精确检查**：若 `j==3` 且 `rs!=34`，回溯，continue。
     - **列末精确检查**：若 `i==3` 且 `cs!=34`，回溯，continue。
     - 递归 `dfs(pos+1)`。
     - 回溯：`a[i][j]=0`，`used[num]=false`。

3. **调用** `dfs(0)`。

4. **输出**：每解 $4$ 行，相邻解间一个空行。

### 复杂度

- **时间**：DFS 节点数取决于剪枝效果，$4\times4$ 规模下实际毫秒级（节点数约 $10^4$–$10^5$）。每个节点 $O(1)$ 剪枝检查 + $O(16)$ 数字遍历。
- **空间**：$O(1)$（$4\times4$ 方格 + $16$ 个 used 标记 + DFS 递归深度 $16$）。

## Part 5 —— C++ 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int a[4][4],used[17],cnt;
int i0,j0;

void out()
{
	if(cnt)
		cout<<'\n';
	cnt++;
	for(int i=0;i<4;++i)
		for(int j=0;j<4;++j)
			cout<<a[i][j]<<(j==3?'\n':' ');
}

bool check()
{
	// corners
	if(a[0][0]+a[0][3]+a[3][0]+a[3][3]!=34)
		return false;
	// four 2x2 corners
	if(a[0][0]+a[0][1]+a[1][0]+a[1][1]!=34)
		return false;
	if(a[0][2]+a[0][3]+a[1][2]+a[1][3]!=34)
		return false;
	if(a[2][0]+a[2][1]+a[3][0]+a[3][1]!=34)
		return false;
	if(a[2][2]+a[2][3]+a[3][2]+a[3][3]!=34)
		return false;
	// center 2x2
	if(a[1][1]+a[1][2]+a[2][1]+a[2][2]!=34)
		return false;
	// diagonals
	if(a[0][0]+a[1][1]+a[2][2]+a[3][3]!=34)
		return false;
	if(a[0][3]+a[1][2]+a[2][1]+a[3][0]!=34)
		return false;
	return true;
}

void dfs(int pos)
{
	if(pos==16)
	{
		if(check())
			out();
		return;
	}
	int i=pos/4,j=pos%4;
	if(a[i][j])
	{
		dfs(pos+1);
		return;
	}
	for(int num=2;num<=16;++num)
	{
		if(used[num])
			continue;
		a[i][j]=num;
		used[num]=true;
		int rs=0;
		for(int k=0;k<=j;++k)
			rs+=a[i][k];
		if(rs>34)
		{
			a[i][j]=0;
			used[num]=false;
			continue;
		}
		int cs=0;
		for(int k=0;k<=i;++k)
			cs+=a[k][j];
		if(cs>34)
		{
			a[i][j]=0;
			used[num]=false;
			continue;
		}
		if(j==3&&rs!=34)
		{
			a[i][j]=0;
			used[num]=false;
			continue;
		}
		if(i==3&&cs!=34)
		{
			a[i][j]=0;
			used[num]=false;
			continue;
		}
		dfs(pos+1);
		a[i][j]=0;
		used[num]=false;
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	int i,j;
	cin>>i>>j;
	--i;--j;
	i0=i;j0=j;
	a[i][j]=1;
	used[1]=true;
	dfs(0);
	return 0;
}
```

**代码要点说明**：
- `a[4][4]` 全局数组，0 表示未填；`used[17]` 标记数字 1-16 的使用状态。
- DFS 按行优先顺序（`pos/4` 为行，`pos%4` 为列）逐格填充。
- 行部分和 `rs` 在填完 $a[i][j]$ 后计算 $a[i][0..j]$ 之和；列部分和 `cs` 计算 $a[0..i][j]$ 之和。
- 行末（`j==3`）精确检查行和 $=34$；最后一行（`i==3`）精确检查列和 $=34$。
- 叶子节点（`pos==16`）检查全部 $8$ 个非行/列约束。
- 输出用 `cnt` 控制空行（第一组解前不输出空行）。
