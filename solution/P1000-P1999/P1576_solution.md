# P1576 最小花费

> 标签：图论 · 最短路 · 难度：普及/提高-
> 本地题面：`statement/P1000-P1999/P1576.md`（$n\le2000$，$m\le10^5$，手续费 $z\%$ 且 $z<100$，保证 $A\to B$ 可达，答案 $\le10^4$，输出精确到小数点后 8 位）。验证：`appendix/P1576/` 对拍 300 组随机（$n\le7$，DFS 简单路径暴力）+ 3 个边界用例全部一致；最坏规模 $n=2000,m=10^5$ → 输出 `108.40551669`，耗时 $0.0194\text{s}$（本次复跑实测；主流程首次实测 $0.0187\text{s}$，两次输出一致——随机种子固定，输出确定）。

## 1. 重新读题

**问题重述（人话版）**

$n$ 个人，某些人两两之间可以互相转账；每一对 $(x,y)$ 之间转账要扣掉转出金额的 $z\%$，对方到手 $S\cdot\bigl(1-\frac{z}{100}\bigr)$。$A$ 要通过直接或间接（多跳中转）的方式让 $B$ **恰好到账 100 元**，求 $A$ 最少要准备多少钱。

> 一句话版本：**在一张无向图上找一条 $A\to B$ 的路，使剩余比例 $\bigl(1-\frac{z}{100}\bigr)$ 的连乘积最大；答案 $=\dfrac{100}{\text{最大连乘积}}$。**

**题面里容易漏掉的条款**

1. 「**互相**转账」$\Rightarrow$ 图是**无向**的：$x\to y$、$y\to x$ 都可以走，手续费相同（代码里每条输入边拆成方向相反、权重相同的两条有向边）。
2. 「从转账金额里扣除百分之几」$\Rightarrow$ 手续费**按比例**扣，不是固定金额。因此「效果沿路径**连乘**」，而不是「费率相加」或「手续费相加」。
3. 「可以直接或**间接**地转账」$\Rightarrow$ 允许多跳中转，且钱是一跳一跳到手的：第一跳先缩水，缩完的水作为第二跳的转出额。
4. 「$z<100$」$\Rightarrow$ 剩余比例 $1-\frac{z}{100}\in(0,1]$ **恒为正**，取对数一定有定义；$z=0$ 是合法输入（免费通道），边权为 $0$，非负权 Dijkstra 照样处理。
5. 「$A$ 最少需要多少钱使得转账后 $B$ 收到 100 元」$\Rightarrow$ 求的是 $A$ 的**总付出**，不是「手续费之和」；付出越多到账越多，所以「恰好 100」与「至少 100 的最小付出」是同一个优化。
6. 「保证 $A$ 与 $B$ 之间可以直接或间接地转账」+「保证答案不超过 $10^4$」$\Rightarrow$ 必有解；且最优乘积 $\ge\frac{100}{10^4}=0.01$，输出不会出现天文数字。
7. 「精确到小数点后 $8$ 位」$\Rightarrow$ `fixed`+`setprecision(8)`；答案 $\le10^4$，8 位小数远在 double 精度能力之内。

> **样例说明（如实交代）**：本地题面 `P1576.md` **没有收录样例**。本文使用的官网样例来自洛谷题目页（已联网核对，多个镜像一致）：输入 `3 3 / 1 2 1 / 2 3 2 / 1 3 3 / 1 3`，输出 `103.07153164`。该样例已用 `appendix/P1576/` 下的标程与暴力**各自实跑复算**，输出均为 `103.07153164`。

**数据范围与规模感受**

$$1\le n\le2000,\qquad m\le10^5,\qquad 0\le z<100 .$$

$n$ 只有 $2000$、$m$ 到 $10^5$：$O(n^2)=4\times10^6$ 的裸 Dijkstra 都绰绰有余，堆优化 $O(m\log n)$ 更是宽裕。**本题的难度全在建模（乘法怎么变加法），不在算法复杂度。** 存图用链式前向星，$2m$ 条有向边，每条 `{int,int,double}` 约 16 字节，合计约 3.2 MB。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：一笔转账到底「缩水」多少

先把题面翻译成数学语言。一对人 $(x,y)$ 手续费 $z\%$，若 $x$ 转出 $S$ 元，$y$ 到账

$$S\cdot\Bigl(1-\frac{z}{100}\Bigr).$$

记这条通道的**剩余比例**为 $f=1-\frac{z}{100}$。由条款 4，$f\in(0,1]$：手续费越高 $f$ 越小，$z=0$ 时 $f=1$（一分不扣）。

### 2.2 考虑简化版：只有一条边

若 $n=2$、$A,B$ 直连，答案是现成的：

$$S=\frac{100}{f}=\frac{100}{1-z/100}.$$

这个简化版告诉我们两件事：**(a)** 优化对象是「比例」而不是「手续费之和」（$z_1+z_2$ 大不代表更差，比如 $50\%+50\%$ 与 $99\%$ 不可直接比大小，要乘出来才算）；**(b)** 付出与比例是反比关系，**最大化比例**就是最小化付出。多跳无非是把「一个 $f$」换成「若干个 $f$ 相乘」。

### 2.3 多跳：比例沿路径连乘

设钱走了一条路 $A=x_0\to x_1\to\cdots\to x_k=B$，各边手续费 $z_1,\ldots,z_k$（第 $i$ 跳在 $x_{i-1}\to x_i$ 上扣除）。

**引理 1（多跳到账公式）**

$B$ 的到账金额为

$$T=S\cdot\prod_{i=1}^{k}\Bigl(1-\frac{z_i}{100}\Bigr)=S\cdot\prod_{i=1}^{k}f_i .$$

**证明**：对跳数 $k$ 归纳。

- **基例** $k=0$（不转账）：$T=S$，空乘积定义为 $1$，成立。
- **归纳步**：设 $k-1$ 跳后第 $k$ 个人 $x_{k-1}$ 手里有 $S\cdot\prod_{i=1}^{k-1}f_i$ 元（归纳假设）。最后一跳转出这个金额，按 2.1 的规则乘以 $f_k$，得
  $$T=\Bigl(S\cdot\prod_{i=1}^{k-1}f_i\Bigr)\cdot f_k=S\cdot\prod_{i=1}^{k}f_i.\qquad\blacksquare$$

于是「让 $B$ 到账 100」等价于

$$S=\frac{100}{\prod_{i=1}^{k}f_i},$$

**分母越大，$A$ 付出越少**。问题被归干净了：

> 找一条 $A\to B$ 的路，使 $\prod f_i$ 最大。

### 2.4 失败思路 1：按「中转次数最少」做 BFS

第一个冒出来的念头：中转越多被扣越多，那把「跳数最少」当目标，BFS 一把梭？

**反例（就用官网样例）**：$n=3$，边 $(1,2)$ 手续费 $1\%$、$(2,3)$ 手续费 $2\%$、$(1,3)$ 手续费 $3\%$，$A=1,B=3$。

- 直连 $1\to3$：$1$ 跳，$f=0.97$，需付出 $\dfrac{100}{0.97}=103.09278351$。
- 中转 $1\to2\to3$：$2$ 跳，$f=0.99\times0.98=0.9702$，需付出 $\dfrac{100}{0.9702}=103.07153164$。

跳数多的反而更便宜（标程实跑输出 `103.07153164`，与官网答案一致）。$\Rightarrow$ **边数不是优化目标，乘积才是**；BFS 只能回答「能不能到」，回答不了「最少花费」。

### 2.5 引理 2：最优解一定是简单路径

钱可不可能故意绕圈、重复经过某些人？比如 $A\to C\to A\to\cdots\to B$。答案是不会更优，这就是本节要钉死的事。

**引理 2（删环不亏）**

设 $W$ 是任意一条从 $A$ 到 $B$ 的走法（walk，点可以重复），其剩余比例乘积为 $R(W)$。则存在一条**简单路径** $P$（点不重复）使 $R(P)\ge R(W)$。因此

$$\max_{W}R(W)=\max_{P\text{ 简单}}R(P).$$

**证明**：若 $W$ 上没有重复点，它本身就是简单路径，结论平凡。否则取一个重复出现的点 $v$，设 $W$ 上两次经过 $v$ 之间的一段为环 $C=v\to\cdots\to v$。环上每条边的剩余比例 $f_i\in(0,1]$（条款 4），故

$$\prod_{e\in C}f_e\le1.$$

把 $C$ 从 $W$ 中删去、把后一段直接接回 $v$，得到更短的走法 $W'$，由引理 1

$$R(W')=\frac{R(W)}{\prod_{e\in C}f_e}\ge R(W),$$

即删环**不会减少**总乘积。每删一个环总边长严格减 1，有限步后必得到一个无重复点的简单路径 $P$，且 $R(P)\ge R(W)$。$\blacksquare$

> 这条引理一箭双雕：**(a)** 它告诉我们只需在简单路径里找最优，搜索空间从「无穷多走法」砍到「至多 $n-1$ 条边的路径」；**(b)** 它正是 §5.3 暴力程序「DFS 只走不重复点」的合法性依据——暴力没有漏掉任何更优解。

**零手续费的环**（$z=0$，环乘积恰为 $1$）删了不亏不赚，最优值不变；有正手续费的环删了严格更赚。标程实跑：`3 3 / 1 2 50 / 1 3 0 / 3 2 0 / 1 2`（$1\to3\to2$ 零手续费，另有一条 $50\%$ 直边）$\to$ `100.00000000`，即 $A$ 一分不多花。

### 2.6 失败思路 2：每步贪心选手续费最小的出边

第二个念头：Dijkstra 还没学过，先贪心——每次从当前的人手里，挑一条手续费最小的出边转出去，直到 $B$。

**反例**：$n=4$，边 $(1,2)$ 手续费 $1\%$、$(1,3)$ 手续费 $2\%$、$(2,4)$ 手续费 $50\%$、$(3,4)$ 手续费 $1\%$，$A=1,B=4$。

- 贪心：$1\to2$（$f=0.99$，当前最大）$\to4$（$f=0.5$），乘积 $0.495$，需付出 $\dfrac{100}{0.495}=202.02020202$。
- 最优：$1\to3\to4$，乘积 $0.98\times0.99=0.9702$，需付出 $\dfrac{100}{0.9702}=103.07153164$（标程与暴力实跑一致）。

贪心在第一步就因为「$0.99>0.98$ 一点点」把后面 $0.5$ 的巨坑照单全收。$\Rightarrow$ **局部因子最大 $\ne$ 全局乘积最大**，贪心没有「后悔药」，必须做全局优化。

### 2.7 归约到经典算法：取对数，乘法变加法

现在问题定格为：**带比例的图上，最大化路径边权乘积**。这不像任何经典题的「标准形式」——经典最短路是和式的。桥梁是对数。

**引理 3（对数变换保序）**

设两条路 $P_1,P_2$ 的乘积分别为 $\Pi_1,\Pi_2$。定义每条边的**权**

$$w_i=-\ln f_i=-\ln\Bigl(1-\frac{z_i}{100}\Bigr).$$

则 $\Pi_1>\Pi_2\iff \sum_{P_1}w_i<\sum_{P_2}w_i$。

**证明**：$\ln$ 在 $(0,+\infty)$ 上导数 $\frac1x>0$，故严格单调递增。于是

$$\Pi_1>\Pi_2\iff\ln\Pi_1>\ln\Pi_2\iff\sum_{P_1}\ln f_i>\sum_{P_2}\ln f_i\iff-\sum_{P_1}\ln f_i<-\sum_{P_2}\ln f_i,$$

最后一行正是 $\sum_{P_1}w_i<\sum_{P_2}w_i$。$\blacksquare$

**引理 4（权非负，且答案公式）**

对每条边，$f_i=1-\frac{z_i}{100}\in(0,1]$（$z<100$ 保证为正、$z\ge0$ 保证 $\le1$），故

$$w_i=-\ln f_i\ge0,\qquad w_i=0\iff z_i=0.$$

且若 $D$ 为 $A\to B$ 的最小权和，则

$$\text{最少付出}=\frac{100}{\max_P\prod_{P}f}=100\cdot e^{D}.$$

**证明**：非负性：$f\le1\Rightarrow\ln f\le0\Rightarrow-\ln f\ge0$；$f=1\iff z=0$ 时取等。答案公式：由引理 3，$\max_P\prod f=\exp\bigl(-\min_P\sum w\bigr)=e^{-D}$（$\exp$ 与 $\ln$ 互逆），代入 $S=\frac{100}{\prod f}$ 得 $S_{\min}=100\,e^{D}$。$\blacksquare$

> 至此完成归约：**带比例乘积的无向图最优化 $=$ 非负权单源最短路**。$n\le2000,m\le10^5$，标准 Dijkstra（堆优化）$O(m\log n)$ 轻松跑进 1 秒。这也和本地题面 Tags 里的「最短路」对上了号。

### 2.8 失败思路 3 / 设计取舍：为什么不直接连乘（最大乘积路）

其实把 Dijkstra 的 `min` 改成 `max`、`+` 改成 `×`，直接维护「到每个人的最大剩余比例」也能做（这就是网络可靠性里的最大可靠路问题）。但标程选择对数版，理由是：

1. **套教科书模板**：变换后就是最朴素的非负权最短路，不需要向读者解释「乘法 Dijkstra 为什么也对」；
2. **远离下溢**：简单路径最长 $n-1=1999$ 条边，每条 $f\ge0.01$，乘积最低可到 $10^{-3998}$，远超 double 下限 $10^{-308}$。取对数后权和累加，量级只有几千，彻底没有下溢风险；
3. **误差可控**：连乘 2000 个因子，每次乘法都带一次舍入；对数版把乘积累积换成「最后一次 `exp` 还原」，全程只引入一次舍入。

> 说明：乘法版在本题数据下其实也能过（下溢成 $0$ 的值对应的都是「极差路径」，`max` 松弛不会被它们污染），但正确性论证要额外处理下溢，对数版一步到位。这是**实现选型**，不是 bug。

### 2.9 Dijkstra 的正确性与两个实现细节

**引理 5（`dis` 始终是真实距离的上界）**

任意时刻，`dis[v]` 要么是 $+\infty$，要么等于某条 $A\to v$ 真实路径的权和；特别地 `dis[v]` $\ge$ 真实最短距离 $\delta(v)$。

**证明**：初始 `dis[A]=0`（零长路径）、其余 `inf`，成立。唯一改变 `dis[v]` 的操作是松弛 `dis[v]=dis[u]+w(u,v)`；由归纳假设 `dis[u]` 是某条 $A\to u$ 路径的权和，接上边 $(u,v)$ 就是一条 $A\to v$ 路径，其权和恰为 `dis[u]+w(u,v)`，故新值仍是某条真实路径的权（若它被写入）。$\blacksquare$

**引理 6（出堆即最终）**

当结点 $u$ 第一次被弹出且未标记时，`dis[u]` $=\delta(u)$，此后不会再变小。

**证明**（反证）：设弹出 $u$ 时 `dis[u]` $>\delta(u)$（由引理 5 知不可能小于）。取一条到 $u$ 的最短路 $P$，设 $x$ 是 $P$ 上第一个**未标记**的点（$A$ 已标记、$u$ 未标记，故 $x$ 存在），$p$ 是 $x$ 在 $P$ 上的前驱。$p$ 已标记，故按弹出顺序归纳有 `dis[p]` $=\delta(p)$；且 $p$ 出堆时一定松弛过 $(p,x)$（松弛循环遍历全部出边），于是

$$\texttt{dis}[x]\le\texttt{dis}[p]+w(p,x)=\delta(p)+w(p,x)=\delta(x),$$

最后一个等号用了「$P$ 是到 $u$ 的最短路，其上前缀也是到各点的最短路」。又由引理 5，`dis[x]` $\ge\delta(x)$，故 `dis[x]` $=\delta(x)$。边权非负（引理 4）$\Rightarrow\delta(x)\le\delta(u)<\texttt{dis}[u]$。

另一方面，`dis[x]` 每次被更新都会把一个键值为新 `dis[x]` 的副本压入堆，而 $x$ 至今未标记意味着这些副本都还没被「弹出并标记」过，故堆中此刻存在一个键值 $\le\texttt{dis}[x]$ 的元素。于是堆顶键值 $<\texttt{dis}[u]$，下一次弹出的该是某个比 $u$ 键更小的元素——与「$u$ 此刻被弹出」矛盾。$\blacksquare$

由引理 6，**`u==B` 出堆时即可 `break`**（代码第 49-50 行）：`dis[B]` 已是最终值，剩下的点不可能改进它。

**细节 A：惰性删除为什么对。** 堆里同一结点可能有多个过期副本。过期副本的键值是它**入堆时的旧 `dis`**，而 `dis` 只会被改小，故旧键值 $\ge$ 当前 `dis[u]`；当旧副本弹出时 `u` 必然早已标记 `vis`，被第 46-47 行原样丢弃，不会重复扩展、也不会破坏引理 6 的归纳。

**细节 B：链头 `H` 必须填 `-1`。** 全局 `int` 数组默认是 $0$ 而不是 $-1$。若忘记 `fill_n(&H[0],mxn,-1)`（代码第 30 行），`H[u]=0` 会被当成「$u$ 有一条出边，就是边 $0$」——于是每个点都会「借」来 $E[0]$ 的终点和权，静默连错图。这是本项目风格指南点名过的坑，代码注释也专门标了。

| 量 | 范围 | 上界 | 用什么类型 |
|---|---|---|---|
| $n$、$m$ | 题面 | $2000$ / $10^5$ | `int` |
| 有向边数 $2m$ | 输入推导 | $2\times10^5$ | `int`（`cnt`） |
| 边权 $w=-\ln(1-z/100)$ | $0\le w\le-\ln 0.01\approx4.605$ | $4.61$ | `double` |
| `dis` | 简单路径至多 $1999$ 条边 | $\le1999\times4.605\approx9206$ | `double` |
| 答案 | 题面保证 | $\le10^4$ | `double`（`100*exp(dis[B])`） |

三个必须显式处理的「静默错误源」：

1. **`H[]` 填 `-1`**（见 2.9 细节 B）；
2. **`z/100.0` 必须是浮点除法**：若写成 `z/100`，整数除法在 $z<100$ 时恒为 $0$，所有权值变 $0$，最短路退化成「任意路都等长」，答案错；
3. **`dis` 哨兵 `inf=1e18`**：远大于任何真实距离（$\le10^4$ 量级），且我们只从已出堆（即 `dis` 有限）的点发起松弛，不会出现把哨兵本身加爆的场面。

## 3. 模式总结（Pattern Summary）

按真实思考顺序：

- **explore its property** — 手续费按比例扣 $\Rightarrow$ 每条通道是一个「剩余比例因子」$f=1-z/100\in(0,1]$，多跳效果 $=$ 因子连乘（2.1、2.3）。
- **consider easier version** — 先算 $n=2$ 直连：答案 $\frac{100}{f}$，确认优化对象是「比例」而非「跳数 / 手续费之和」（2.2）。
- **reduce to easier problem** — 删环引理（引理 2）：环乘积 $\le1$、删了不亏 $\Rightarrow$ 最优解是简单路径，无穷多 walk 降为简单路径。
- **classic problem solution（对数变换）** — $\ln$ 严格单调：最大连乘积 $\Leftrightarrow$ 最小权和，边权 $-\ln(1-z/100)\ge0$，乘法半群变加法群（引理 3、4）。
- **classic problem solution（Dijkstra）** — 非负权单源最短路：小根堆 $+$ 惰性删除 $+$ 链式前向星，目标点出堆即停（引理 5、6）。
- **numerical-transform** — 连乘换对数和，避开 1999 条边连乘的下溢；答案用一次 `exp` 还原（2.8）。
- **verify against a dfs brute** — 小图 DFS 枚举简单路径取最大乘积作基准对拍（§4.5）。

| `cnt` | `int`（全局） | 已存入的有向边条数 | $0$ | 链式前向星的「新边槽位」指针 |
| `E[i]` | `struct{int v,nx;double w}`，`E[mxm*2]` | 第 $i$ 条有向边：终点 `v`、同起点下一条边 `nx`、权 `w` | `addedge` 写入 | v=vertex，nx=next，w=weight；每条无向通道存正反两条 |
| `H[u]` | `int [mxn]` | 点 $u$ 的第一条出边（链头），`-1` 表示没有出边 | **全 $-1$**（`fill_n`，第 30 行） | H=head |
| `dis[u]` | `double [mxn]` | $A\to u$ 的最小权和 $=-\ln(\text{最大剩余比例})$ | `inf`；`dis[A]=0.0` | 对数距离，引理 4 |
| `vis[u]` | `bool [mxn]` | $u$ 是否已被 Dijkstra 确定 | `false`（全局零初始化） | 出堆标记，引理 6 |
| `Q` | `priority_queue<pair<double,int>,…,greater<>>` | 小根堆，元素 `(距离, 点)` | 空 | 按距离出堆是引理 6 的前提；`greater<>` 把默认大根堆翻转成小根堆 |
| `A`、`B` | `int`（局部） | 源点、目标点（读入后 `--` 转 0-based） | 读入 | 题面 |
| `inf` | `constexpr double` | 距离哨兵 | `1e18` | 远大于任何真实距离（$\le10^4$ 量级） |
| `w`（边权） | `double`（`addedge` 参数） | $-\ln(1-z/100)\ge0$ | 读入时算出 | 引理 4 |

### 4.2 编号步骤

1. `fill_n(&H[0],mxn,-1)`（第 30 行）：链头清成 $-1$——全局 `int` 默认 $0$，不填就会幽灵连边（§2.9 细节 B）。
2. 读入 $n,m$；循环 $m$ 次读 `x,y,z`，`--x;--y` 转 0-based，调用 `addedge(x,y,-log(1.0-z/100.0))`（第 35 行）：每条无向通道拆成**方向相反、权重相同**的两条有向边；权重按引理 4 取 $-\ln f\ge0$。
3. 读入 `A,B`，`--A;--B`。
4. `fill_n(&dis[0],mxn,inf)`；`dis[A]=0.0`；堆推入 `{0.0,A}`。
5. Dijkstra 主循环（第 43-61 行）：
   5.1 堆空则结束；
   5.2 弹出 `(d,u)`；若 `vis[u]` 为真，丢弃（过期副本，§2.9 细节 A）；
   5.3 `vis[u]=true`；若 `u==B` 直接 `break`——由引理 6，`dis[B]` 已最终；
   5.4 沿链头 `for(int i=H[u];i!=-1;i=E[i].nx)` 遍历 $u$ 的每条出边，取 `v=E[i].v`、`w=E[i].w`；若 `dis[u]+w<dis[v]` 则更新并入堆（松弛）。
6. 输出 `cout<<fixed<<setprecision(8)<<100.0*exp(dis[B])<<'\n'`（第 63 行）：由引理 4，最少付出 $=100\,e^{D}$，$D=\texttt{dis[B]}$。

### 4.3 复杂度

- **时间**：建图 $O(m)$；每条边至多引发一次成功松弛、一次入堆，故 $O(m\log m)$；$n=2000,m=10^5$ 实测 **$0.0194\text{s}$**。
- **空间**：$E$ 数组 $2m\times16\text{B}\approx3.2\,\text{MB}$，加 $O(n)$ 的 `H/dis/vis`，总量不足 4 MB。
- 数据范围宽松到 $O(n^2)$ 裸 Dijkstra 也能过，堆优化属于「顺手用对的经典版」。

### 4.4 关键不变量

1. `dis[u]` 在 `vis[u]=true` 的时刻等于真实最短权和（引理 6），且全程是真实距离的上界（引理 5）。
2. 堆中同点多副本无害：旧副本键值 $\ge$ 当前 `dis`，弹出时必已被 `vis` 拦下（细节 A）。
3. `H[u]==-1` 是「无出边」的唯一表示；除第 30 行外任何地方不得依赖 `H` 的默认值。
4. 边权只由 $z$ 决定且非负（引理 4），这是 Dijkstra 可行的全部前提。

## 5. 示例代码

> 与 `appendix/P1576/P1576.cpp` **逐字节一致**。

```cpp
//
// 题目：P1576 最小花费
// https://www.luogu.com.cn/problem/P1576
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005};        // n<=2000 (+5 松弛)
constexpr int mxm{100005};      // m<=100000 (+5 松弛)
constexpr double inf{1e18};

int n,m,cnt;
struct{int v,nx;double w;}E[mxm*2];
int H[mxn];
double dis[mxn];
bool vis[mxn];

void addedge(int u,int v,double w)
{
	E[cnt]={v,H[u],w};H[u]=cnt++;
	E[cnt]={u,H[v],w};H[v]=cnt++;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	fill_n(&H[0],mxn,-1);        // 链式前向星表头默认应为 -1,全局 int 默认 0 必须显式填充
	cin>>n>>m;
	for(int i=0,x,y,z;i<m;++i)
	{
		cin>>x>>y>>z;--x;--y;
		addedge(x,y,-log(1.0-z/100.0));   // 手续费 z% => 边长 -ln(1-z/100) > 0
	}
	int A,B;
	cin>>A>>B;--A;--B;
	fill_n(&dis[0],mxn,inf);
	dis[A]=0.0;
	priority_queue<pair<double,int>,vector<pair<double,int>>,greater<>>Q;
	Q.push({0.0,A});
	while(!Q.empty())
	{
		auto[d,u]=Q.top();Q.pop();
		if(vis[u])
			continue;
		vis[u]=true;
		if(u==B)
			break;
		for(int i=H[u];i!=-1;i=E[i].nx)
		{
			int v=E[i].v;
			double w=E[i].w;
			if(dis[u]+w<dis[v])
			{
				dis[v]=dis[u]+w;
				Q.push({dis[v],v});
			}
		}
	}
	// 边长取 -ln(因子),最短路即 ln 最小 = 乘积最大方案;B 到账 100 => 最少付出 100/(最大乘积)
	cout<<fixed<<setprecision(8)<<100.0*exp(dis[B])<<'\n';
	return 0;
}
```

| 第 35 行 `-log(1.0-z/100.0)` | 引理 4（权非负）+ §2.10 第 2 条（必须浮点除法）。注释写「$>0$」是 $z\ge1$ 时的口径，$z=0$ 时为 $0$，非负即够 Dijkstra 用 |

### 5.3 对照实现：DFS 简单路径暴力

见 `appendix/P1576/P1576_brute.cpp`：$n\le7$ 的小图上，从 $A$ 出发 DFS 所有不重复点的路径，维护剩余比例乘积的最大值 `best`，最后输出 $\frac{100}{\texttt{best}}$。平行边保留比例最大的一条（`if(f>g[x][y]) g[x][y]=f;`）。引理 2 保证「只枚举简单路径」不漏最优解；300 组随机 + 3 个边界用例与标程全部一致。

### 5.4 易错点清单

- **把目标当成「中转次数最少」** $\Rightarrow$ BFS 错答（官网样例本身就是反例：2 跳 `103.07153164` < 1 跳 `103.09278351`）。
- **每步贪心最小手续费** $\Rightarrow$ 局部最优 $\ne$ 全局最优（§2.6 反例：贪心 `202.02020202` vs 最优 `103.07153164`）。
- **忘记 `fill_n(&H[0],mxn,-1)`** $\Rightarrow$ 全局默认 $0$ 变幽灵链头，静默连错图。
- **`z/100` 整数除法** $\Rightarrow$ $z<100$ 时恒为 $0$，所有权值为 $0$，答案错。
- **直接连乘不做对数** $\Rightarrow$ 1999 条边连乘可下溢（虽本题有「答案 $\le10^4$」兜底，但论证变复杂）；对数版一步到位（§2.8）。
- **`u==B` 出堆后不 `break` 也无妨**（只是多跑一会儿），但**没出堆就用 `dis[B]` 输出则错**——那一刻它还可能被改进。
- **输出忘记 `fixed`** $\Rightarrow$ 默认 6 位有效数字，`108.405517` 与 `108.40551669` 判错。
