# P1258 小车问题 题解

## Part 1 —— 重读题目（用自己的话复述）

A、B 两地相距 `s`。甲、乙两人**同一时刻**从 A 出发，目标是**同一时刻**赶到 B。A 地停着一辆车，车除司机外只能再坐**一人**，司机既不是甲也不是乙（所以司机可以一个人把车开走再开回来，车上"座位"任何时候最多被一个人占用）。甲、乙步行速度相同，都等于 `a`，且 `a < b`（`b` 是车速）。

求：怎样安排车，让两人**同时**到达 B 且总时间最短？输出最短时间，保留 6 位小数。

数据：`0 ≤ s, a, b ≤ 10^9`，且 `a < b`（题面保证步行速度小于车速）。

> 关键约束的口语化：
> - 车只有一个座位 → **同一时刻**最多一人乘车，且车不能"载两个人"。
> - 司机独立 → 车可以空着往返（空驶）。
> - "同时到达"是硬约束，不是"都到达即可"。
> - 答案是一个**实数**，保留 6 位。

---

## Part 2 —— 思维链（像学生一样逐步发现）

### 第 1 步：先想"最省事的方案"——一人坐车，一人全程走

让甲先坐完整程、乙全程走？那乙要 `s/a` 才到，而甲 `s/b` 就到了，早到的人在 B 干等，违反"同时到达"也没意义——总时间被慢的那个人卡住。
反过来，让"先坐车的人"中途下车改走路，省下的时间拿去帮另一个人，似乎更划算。这提示我们：**两人都不该"坐车到底"，也都不该"全程走路"**，各走一段、各坐一段才均衡。这是后面"对称策略"的直觉源头。

### 第 2 步：刻画车的"能力"——它到底能干什么？

把时间轴画出来。一个座位、一辆车，意味着**车的轨迹是一条连续路径**，它载人的"时间区间"两两不重叠（座位唯一）。要送两个人，车必然做**至少两段载人行驶**，每段带不同的人（同一个人坐两段没意义，会绕远）。

**引理 1（结构）**：存在一个最优策略，其中车恰好做两段载人行驶——先带甲从 `0` 到某点 `x`（甲下车改走），车空驶返回 `0`，再带乙从 `0` 到某点 `y`（乙下车改走）。

*证明*：
(必要性，为何两段够用。) 设任意一个合法方案，把车的所有"载人段"按时间排序记为 `[I_1, I_2, ..., I_k]`（每段带一个人）。因为车不能同时带两人，这些区间两两不交。
- 对同一个人，他坐车的段如果**不是连续的**（中间夹了走路），把中间那段走路也改成坐车只会更快、且车当时正空着（他没在车上），不增加冲突 → 可把同一个人的乘车段"并拢"成一段。故每人至多一段乘车。
- 两人各一段，共两段；每段载人行驶的方向都是"从更靠近 A 的端点往更靠近 B 的端点"（若某人往回坐，把它拆掉改走路不更差，因为往回坐是浪费位移）。
于是可化归为：甲一段 `0→x`，乙一段 `0→y`，两人都在下车点改走。车在两段之间空驶调头（`x→0`，`0→y` 的空驶部分）。证毕。

> 备注：`x`、`y` 可以一大一小（策略对两人不对称），引理只要求"各一段、从 0 出发"。

### 第 3 步：把"总时间 T 够不够"变成可判定的事

既然要**同时**在时间 `T` 到达，对固定 `T` 我们只关心"**是否存在**这样的 `x, y`（策略参数）使得两人都在 `T` 内到"。这是典型的**单调可行性**问题 → 用**二分答案**（对 `T` 二分，`check(T)` 判定）。

先推导 `check(T)`。把时间轴按"车的动作"切段（记车速 `b`、人速 `a`）：

```
0        x/b       2x/b      (2x+y)/b        T
|--------|----------|----------|---------------|
 甲坐车   车空驶回    乙坐车      乙(和甲)走路到B
 (0→x)    (x→0)      (0→y)
```

- **甲**：坐车 `0→x` 用时 `x/b`，在 `x` 下车，再走 `s-x` 用时 `(s-x)/a`。
  甲到达时刻 = `x/b + (s-x)/a`。要求 `≤ T`。
- **乙**：等到车空驶回来（`2x/b`）才上车，坐车 `0→y` 到时刻 `(2x+y)/b` 下车，再走 `s-y` 用时 `(s-y)/a`。
  乙到达时刻 = `(2x+y)/b + (s-y)/a`。要求 `≤ T`。

两个不等式都是 `x, y` 的**线性**式：

```
(甲)  x/b + (s-x)/a ≤ T
(乙)  (2x+y)/b + (s-y)/a ≤ T
```

**引理 2（单调性）**：`(甲)` 式对 `x` 单调**递减**，`(乙)` 式对 `x`、`y` 都单调递减。

*证明*：
- `(甲)` 式左边 = `s/a + x·(1/b − 1/a)`。因为 `a < b`，`1/b − 1/a < 0`，所以左边随 `x` 增大而减小。
- `(乙)` 式左边 = `(2x+y)/b + (s-y)/a = s/a + 2x·(1/b) + y·(1/b − 1/a)`。`1/b > 0`，`1/b − 1/a < 0`，所以它对 `x`、`y` 都递减。证毕。

于是：**`x`、`y` 越大，越容易满足**（坐车越多越好）。我们要问"是否存在可行 `x, y`"。
- 对 `(甲)`：因为对 `x` 递减，存在唯一最小值 `x*` 使 `(甲)` 恰好成立（再小就不成立）。`(甲)` 成立 ⟺ `x ≥ x*`。
- 对 `(乙)`：固定 `x` 时它对 `y` 递减，成立 ⟺ `y ≥ y*(x)`（某个阈值）。我们要在 `x ≥ x*` 的前提下让 `(乙)` 成立。

**关键**：`x` 越小，`(乙)` 左边越小（引理 2），越容易满足。所以为了让 `(乙)` 最宽松，应取**满足 `(甲)` 的最小 `x`**，即 `x = x*`。此时 `(乙)` 退化为关于 `y` 的一元单调式，成立 ⟺ `y ≥ y*`（某个阈值）。而 `y` 上限就是 `s`（车最远把乙送到 B）。

**结论（可判定条件）**：`check(T)` 为真 ⟺ 令 `x*` = 使 `(甲)` 恰好成立的最小 `x`，再令 `y*` = 在 `x=x*` 时使 `(乙)` 恰好成立的最小 `y`，则 `y* ≤ s`。

> 为什么"取最小 x"不丢解？因为 `(乙)` 对 `x` 递减，`x` 取允许范围内的最小值 `(乙)` 左边最小、`y*` 最小，最有可能 `≤ s`。任何更大的 `x` 只会把 `y*` 推大，更难满足。所以"最小 `x*` 可行 ⟹ 存在可行解"，反之若连最小 `x` 都不可行，更大的 `x` 更不可行。这是引理 1 结构下"最不利配置"的穷尽。

### 第 4 步：解出 `x*`、`y*`（解两个一次方程）

`(甲)` 取等解 `x*`：

```
x/b + (s-x)/a = T
→ x·(1/b − 1/a) + s/a = T
→ x·(a-b)/(a·b) = T − s/a
→ x* = (s/a − T)·(a·b)/(a−b)
```

注意 `a−b < 0`，`s/a − T` 的符号决定 `x*` 的符号。`x*` 还应在 `[0, s]` 内才有物理意义（超出就截断：`x*<0` 说明甲其实可以"不坐也来得及"，取 0；`x*>s` 说明甲坐车到底仍不够）。实现上直接代入，配合 `y*≤s` 的判断，截断到 `[0,s]` 更稳。

`(乙)` 在 `x=x*` 处取等解 `y*`：

```
(2x*+y)/b + (s-y)/a = T
→ y·(1/b − 1/a) + 2x*/b + s/a = T
→ y* = (T − s/a − 2x*/b)·(a·b)/(a−b)
```

`check(T)`：算出 `x*`（截断 `[0,s]`）、`y*`，返回 `y* ≤ s + eps`。

### 第 5 步：确认 `check(T)` 关于 `T` 单调，从而可二分

**引理 3（整体单调）**：`T` 越大，`check(T)` 越容易为真。

*证明*：`T` 增大 → `x* = (s/a − T)·(a·b)/(a−b)`。因 `a−b<0`，`(a·b)/(a−b)<0`，故 `x*` 随 `T` **增大**（`s/a−T` 减小、乘负号变正方向）。`x*` 增大 → `(乙)` 左边 `2x*/b` 项增大 → 同样 `T` 下 `y*` 增大？看似不利，但 `T` 增大同时直接抬高两个不等式右端，主导效应是"预算更宽"。严格地：固定一个可行 `x,y`（对应 `T` 的某组解），对 `T+δ`，同一组 `x,y` 的左边不变、右端变大，仍满足 → 原来可行的参数仍可行。故 `T` 增大，可行集非空性保持，`check` 单调不减。证毕。

> 更直观：时间预算变大，"能完成"这件事只会更容易，不会更困难。单调性成立，二分合法。

二分区间：下界 `l = 0`（或更紧 `l = s/b`，车直接拉满的理论下界其实更小，但 0 足够安全），上界 `r = s/a`（两人全走的上界，一定可行：让 `x*=0,y*=0`，两人都走 `s/a`，同时到 → 可行）。迭代约 100 次浮点二分（精度 `1e-12` 级别）即可稳定到 6 位小数。

> 为什么上界 `s/a` 一定可行？取 `x*=y*=0`（不坐车），甲、乙都步行 `s/a`，**同一时刻** `s/a` 到，满足"同时到达"。所以 `check(s/a)` 必真。二分合法。

### 第 6 步：为什么答案必然"对称均衡"（自检）

直观上最优时甲、乙各自"坐车一段+走一段"且到达时刻相等（=T）。若甲坐车比乙多很多，可把甲的乘车段缩短、改走路，腾出的车时间去拉乙，让乙少走路——总时间下降，直到两者"边际"平衡。这正是 `x*, y*` 由两个等式同时确定的含义：最优 `T` 是"再压缩就有人超时"的临界点，二分找的就是这个临界。

## Part 3 —— 模式总结（按真实思考顺序）

- **explore its property** — 一个座位 + 司机独立 ⇒ 车做两段"从 0 出发的载人段 + 中间空驶往返"，各带一人（引理 1）。
- **consider easier version** — 先试"一人坐车一人走"，发现被慢者卡死且违反同时到达 ⇒ 必须各坐一段各走一段。
- **reduce to easier problem** — 固定总时间 `T`，把"求最短时间"降维成"判定 `T` 是否可行"的二元问题。
- **classic problem solution** — 单调可行性 + **二分答案**（对 `T` 浮点二分，`check(T)` 判定）。
- **classic problem solution** — `check` 内解两个一次方程（线性不等式求最小阈值 `x*, y*`），用单调性（引理 2）证明"取最小 `x` 最有利"，归约成 `y* ≤ s` 的标量判断。
- **verify monotonicity** — 证明 `check(T)` 随 `T` 单调（引理 3）+ 给出可行上下界 `l=0, r=s/a`，保证二分合法。

## Part 4 —— 真正的解法（代码做什么）

### 符号表（每个符号先定义再用）

| 符号 | 含义 / 初始化 | 助记 |
|---|---|---|
| `s` | AB 距离（实数），输入 | 全程 |
| `a` | 人步行速度（实数），输入，`a<b` | 人速 |
| `b` | 车速（实数），输入，`b>a` | 车速 |
| `T` | 二分的"候选总时间" | 答案变量 |
| `x*` | 使甲约束取等的最小 `x`（甲下车点） | 甲坐车距离 |
| `y*` | 在 `x=x*` 时使乙约束取等的最小 `y` | 乙坐车距离 |
| `l, r` | 二分上下界，`l=0`（不可行）、`r=s/a`（可行） | 搜索区间 |
| `eps` | `1e-12`，浮点比较容差 | 判等 |

### 算法步骤

1. **读入** `s, a, b`。
2. **定义 `check(T)`**：
   - 解 `(甲)` 取等：`x* = (s/a − T)·(a·b)/(a−b)`；截断 `x* = clamp(x*, 0, s)`。
   - 解 `(乙)` 取等（代入 `x=x*`）：`y* = (T − s/a − 2x*/b)·(a·b)/(a−b)`。
   - 返回 `y* ≤ s + eps`。
3. **二分** `T`：`l=0, r=s/a`，迭代 200 次：`mid=(l+r)/2`；`if check(mid) r=mid; else l=mid;`（`check` 为真说明还能压小 → 收缩右界）。
4. **输出** `r`，`fixed << setprecision(6)`。

### 复杂度

- 每次 `check` 为 `O(1)`（两个除法 + 几次乘加）。
- 二分固定 200 次迭代 → `O(200) = O(1)`。
- 空间 `O(1)`。

### 验证状态

- 本方案未在本机编译/运行（按要求只写题解）。
- 逻辑自检：上界 `s/a`（`x=y=0` 全步行）必可行；`a<b` 保证 `a−b<0` 与单调性方向；`x*,y*` 截断到 `[0,s]` 处理边界（如 `T` 极小时 `x*` 可能为负，截断为 0 表示"不坐车"）。
- 边界 `s=0`：答案 0（`r=s/a`，若 `a>0` 则 `r=0`；若 `a=0` 则需特判，但题面 `a<b` 且 `a` 可为 0 —— `a=0` 时人不走路，答案由车决定，见代码特判）。

> **`a=0` 特判**：题面允许 `a=0`（人不能走）。此时唯一可行方案是车接送。`a=0` 时 `s/a` 除零、`a−b` 公式失效。处理：若 `a==0`，答案为 `2s/b`（车先送甲到 B 用 `s/b`，空驶回 A 用 `s/b`，再送乙到 B 用 `s/b`？不——）。正确做法：`a=0` 时人不能移动，必须被车**送到 B**。车送甲 `0→s`（`s/b`），空驶回 `s→0`（`s/b`），再送乙 `0→s`（`s/b`），但乙要等车回来，总时间 `3s/b`。而甲在 `s/b` 就到了 B（干等）。所以 `a=0` 答案 = `3s/b`。代码中若 `a` 极小直接用公式可能除零，建议加 `if(a==0) ans=3*s/b;` 兜底（本题数据 `a≥0` 且常 `a>0`，正常情况不触发）。

## Part 5 —— 示例 C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using f64=double;

f64 s,a,b;
constexpr f64 eps{1e-12};

// check(T): 是否存在策略使两人都在 T 内同时可达
bool check(f64 T)
{
	// 解 (甲) 取等: x/b + (s-x)/a = T  ->  x* = (s/a - T)*(a*b)/(a-b)
	f64 x=(s/a-T)*(a*b)/(a-b);
	x=max(f64(0),min(x,s));                 // 截断到 [0,s]
	// 解 (乙) 取等(代入 x=x*): y* = (T - s/a - 2x/b)*(a*b)/(a-b)
	f64 y=(T-s/a-2*x/b)*(a*b)/(a-b);
	return y<=s+eps;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s>>a>>b;
	if(a==0)                              // 人不能走, 车必须把两人都送到 B
	{
		cout<<fixed<<setprecision(6)<<3*s/b<<'\n';
		return 0;
	}
	f64 l=0,r=s/a;                        // l 不可行, r=s/a(全步行) 可行
	for(int i=0;i<200;++i)
	{
		f64 mid=(l+r)/2;
		if(check(mid))
			r=mid;
		else
			l=mid;
	}
	cout<<fixed<<setprecision(6)<<r<<'\n';
	return 0;
}
```

### 代码说明（对照 Part 4）

- `check(T)` 即第 2 步的两个一次方程 + `y*≤s` 判断（引理 2 的"取最小 `x` 最有利"）。
- `x` 的 `max/min` 截断对应第 4 步边界处理。
- 二分 200 次（浮点），`check` 真则 `r=mid`（可行 → 压小），与引理 3 的单调方向一致。
- `a==0` 分支是第 4 步"验证状态"里提到的除零兜底，输出 `3s/b`。
- 输出 `fixed<<setprecision(6)` 满足"保留 6 位小数"。
