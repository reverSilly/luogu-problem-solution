# P1589 [USACO05OPEN] 泥泞路

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

公路上有 $n$ 段泥泞区间 $[s_i,e_i]$，另有无限多块长度均为 $L$ 的木板。木板可以铺在公路的任意位置（可以互相重叠，也可以盖到不泥泞的地方），要求所有泥泞点都被至少一块木板覆盖，求最少用板数。

由于区间是连续的，覆盖条件按实数理解：$[s_i,e_i]$ 中每个点都要落在某块木板 $[b,b+L]$ 内。本题的最优解可以取整数端点，因此下文用整数坐标推理不失去一般性。

### 输入输出格式

- **输入格式**：第一行 $n,L$；随后 $n$ 行每行 $s_i,e_i$。
- **输出格式**：一行一个整数，最少木板数。
- **数据规模**：$n,L \le 10^4$，$s_i \le e_i \le 10^9$。

### 关键约束分析

1. $n \le 10^4$ 很小，$O(n\log n)$ 排序完全够用；坐标到 $10^9$，所以**不能**按坐标开数组或逐格模拟。
2. 泥泞段**无序且可能重叠、包含**，必须先按左端点排序，否则无法从左到右一次性扫描。
3. 答案数量级：总泥泞长度可达 $n \times 10^9 = 10^{13}$，当 $L=1$ 时答案也是 $10^{13}$ 量级，必须用 `long long`（`int` 必爆）。
4. 边界：$s=e$ 表示长度为零的"泥点"，贡献 $0$ 块板；一段被前一块板完全覆盖时不能重复计数。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：暴力长什么样，为什么不行

最直接的想法是把公路离散成单位格子，逐格找最左的未覆盖泥点，然后放板。这在坐标 $10^9$ 时既存不下也跑不完。但"从最左未覆盖点开始放"这个直觉是值得保留的——问题只在于如何跳过"整段已被覆盖"的部分。

### 第二步：最左未覆盖点决定的贪心

设当前所有泥泞点中，最靠左的尚未被覆盖的点是 $p$。任何可行解都必须有一块木板盖住 $p$，设这块板占 $[b,b+L]$，其中 $b \le p \le b+L$。

**引理 1（左端对齐不劣）**：把覆盖 $p$ 的那块板平移到 $[p,p+L]$，仍是可行解且用板数不变。

*证明*：平移后该板覆盖 $[p,p+L]$。原板覆盖 $[b,b+L]$，其中 $b\le p$。新板丢失的部分是 $[b,p)$，保留的部分是 $[p,b+L]$，新增的部分是 $(b+L,p+L]$。

- 丢失部分 $[b,p)$ 中不含任何未覆盖的泥泞点：$p$ 是**最左**的未覆盖泥泞点，故 $[b,p)$ 内的泥泞点（若有）都已被其他木板覆盖。
- 保留部分与原板相同，新增部分只会多覆盖。

其余木板不动，于是新方案覆盖的点集是原方案的超集，用板数不变，仍可行。$\square$

引理 1 说明：**总存在一个最优解，其中某块板左端恰好落在最左未覆盖点上**。这消除了"板该往左放多少"的自由度。

### 第三步：一次放满，把问题缩小

固定了第一块板从 $p$ 开始时，还要决定"这一轮放几块"。可以连续铺，因为只要并集能盖住 $[p,e]$，板之间怎么错开都无所谓——而"连续铺"恰好用最少的板覆盖最长的前缀。

**引理 2（连续铺砌最优）**：设 $[0,p)$ 已全部覆盖，要用长度为 $L$ 的板覆盖泥泞段 $[p,e]$，最少需要 $\lceil (e-p)/L\rceil$ 块。

*证明*：**下界**。任取一个用 $k$ 块板的可行方案，其并集必须包含 $[p,e]$，故并集总长度 $\ge e-p$；而 $k$ 块板的总长度至多 $kL$（重叠只会更少），于是 $kL \ge e-p$，即 $k \ge \lceil (e-p)/L\rceil$。**上界**。取 $k=\lceil (e-p)/L\rceil$，把 $k$ 块板首尾相接铺成 $[p,p+kL]$，由 $kL \ge e-p$ 得 $p+kL \ge e$，于是 $[p,e]\subseteq[p,p+kL]$，可行。两端夹逼即得最少块数。$\square$

于是处理一段泥泞 $[s,e]$ 时，若当前已覆盖到 `cur`：

- 若 $e \le \text{cur}$，整段已被覆盖，跳过；
- 否则从 $\text{st}=\max(s,\text{cur})$ 起连续铺 $\lceil (e-\text{st})/L \rceil$ 块，`cur` 更新为 $\text{st}+kL$。

### 第四步：为什么按左端点排序后一遍扫描就够

**引理 3（扫描不遗漏）**：按 $s_i$ 升序处理，任意时刻 `cur` 之前的泥泞点全部已被覆盖。

*证明*：对处理过的段数归纳。处理第 $i$ 段后，该段的 $[s_i,e_i]$ 被覆盖，且之前各段也已覆盖（归纳假设），`cur` 只增不减，故 `cur` 之前无未覆盖泥泞点。由于后续段的 $s_j \ge s_i$，其落在 `cur` 左侧的部分必然属于已处理区间并被覆盖，因此只需关心 $[\max(s_j,\text{cur}),e_j]$。$\square$

**定理**：上述贪心输出的板数等于最优解。

*证明*：由引理 1、2，每一步的决策都可扩展成某个最优解的前缀（用板数与覆盖右端都不劣），由引理 3 扫描覆盖了全部泥泞点，故贪心用板数不超过最优值；又贪心方案本身可行，故等于最优值。$\square$

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 覆盖问题里"最左未覆盖点"是关键抓手：任何方案都得盖它。
- `classic problem solution` — 交换论证（把板左端平移到最左未覆盖点）证明贪心选择安全。
- `reduce to easier problem` — 用"总长度下界 + 首尾相接构造"把"放几块"压成一次除法 $\lceil (e-\text{st})/L\rceil$。
- `sorting first` — 区间无序且相交，按左端点排序后左→右单遍扫描才成立。
- `classic problem solution` — 维护"已覆盖右端" `cur`，每段只补 $\lceil(e-\max(s,\text{cur}))/L\rceil$ 块。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $n$ | `n` | 泥泞段数 |
| $L$ | `L` | 每块木板长度 |
| $[s_i,e_i]$ | `a[i].s`, `a[i].e` | 第 $i$ 段泥泞区间，结构体 `seg` 的两个字段 |
| — | `a[mxn]` | 存所有区间的全局数组，读入后按 `s` 升序排序 |
| $\text{cur}$ | `cur` | 当前已铺木板覆盖到的最右坐标（右端，初值 $0$）；只增不减 |
| $\text{st}$ | `st` | 本段真正需要开始铺板的位置，$\max(s_i,\text{cur})$ |
| $k$ | `need` | 本段需要新增的木板数 $\lceil (e_i-\text{st})/L\rceil$ |
| $\text{ans}$ | `ans` | 累计木板数，`i64` 防溢出 |

### 算法步骤

1. 读入 `n,L` 与 $n$ 个区间，按左端点 `s` 升序排序。
2. 初始化 `cur=0`、`ans=0`。
3. 顺序扫描每个区间：若 `a[i].e<=cur` 则跳过；否则令 `st=max(a[i].s,cur)`，`need=(a[i].e-st+L-1)/L`，`ans+=need`，`cur=st+need*L`。
4. 输出 `ans`。

### 复杂度分析

- **时间复杂度**：排序 $\mathcal{O}(n\log n)$，扫描 $\mathcal{O}(n)$，合计 $\mathcal{O}(n\log n)$；本题 $n\le10^4$，实测瞬时完成。
- **空间复杂度**：$\mathcal{O}(n)$，仅一个区间数组。

### 正确性验证

引理 1 与引理 2 保证每步贪心都对应某个最优解；引理 3 保证扫描结束时所有泥泞点被覆盖；定理给出最优性。数值安全：`st`、`cur`、`need*L` 都在 $10^{13}$ 以内，用 `i64`；除法用 `(e-st+L-1)/L` 实现上取整，`e-st` 非负（否则前面已 `continue`），不会出现负数除法截断问题。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1589 [USACO05OPEN] 泥泞路
// https://www.luogu.com.cn/problem/P1589
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};

struct seg{int s,e;};
seg a[mxn];
int n,L;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>L;
	for(int i=0;i<n;++i)
		cin>>a[i].s>>a[i].e;
	sort(a,a+n,[](auto x,auto y){return x.s<y.s;});

	i64 ans=0,cur=0;            // cur: 已被木板覆盖到的位置(右开)
	for(int i=0;i<n;++i)
	{
		if(a[i].e<=cur)
			continue;           // 整段已被前面的木板免费覆盖
		i64 st=max<i64>(a[i].s,cur);
		i64 need=(a[i].e-st+L-1)/L;
		ans+=need;
		cur=st+need*L;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **不排序**：输入区间无序，直接扫描会把后面的板"浪费"在左边，答案偏大。必须按 `s` 排序。
2. **`need` 用下取整**：`(e-st)/L` 会少算一块，必须写 `(e-st+L-1)/L`。
3. **`cur` 与 `st` 的取舍**：`st` 要取 $\max(s_i,\text{cur})$，直接用 $s_i$ 会在重叠段上重复铺板。
4. **`ans` 用 `int`**：$L=1$ 且区间总长 $10^{13}$ 时溢出，必须 `i64`。
5. **忘记 `e<=cur` 的跳过**：包含关系（如 $[1,10]$ 与 $[2,3]$）会多算板数。
