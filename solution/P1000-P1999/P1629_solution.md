# P1629 邮递员送信

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

有 $n$ 个点、$m$ 条**有向**道路，边权是通行时间。邮局在 $1$ 号点，需要把 $n-1$ 件物品分别送到 $2,3,\dots,n$。他每次只能带一件物品，送到后必须返回邮局，最后也要回到邮局。求完成全部投递并返回的最少总时间。

### 输入输出格式

- **输入格式**：第一行 $n,m$；随后 $m$ 行 `u v w`，表示 $u\to v$ 有一条耗时 $w$ 的单向道路。
- **输出格式**：一行一个整数，最少总时间。
- **数据规模**：$n\le10^3$，$m\le10^5$，$1\le w\le10^4$，保证任意两点互相可达。

### 关键约束分析

1. $n\le10^3$、$m\le10^5$，边比较稀疏，单源最短路用堆优化 Dijkstra 是 $\mathcal{O}(m\log n)$，跑 $n$ 次也才 $10^8$ 级别；本题只需 $2$ 次。
2. 图是**有向**的，"去"和"回"的路径长度不同，不能只算一遍。
3. 答案上界：单次最短路 $\le(n-1)\times10^4\approx10^7$，共 $2(n-1)$ 段，总和 $\le2\times10^{10}$，**必须 64 位**。
4. 边界：$n=1$ 时没有物品要送，答案为 $0$（题面 $n$ 可为 $1$）；重边要取较小者（Dijkstra 本身会处理，因为松弛时取 min）。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：把"一趟一趟跑"拆开

题目说得很清楚：每次只能带一件物品，送完必须回邮局。这意味着一次投递形成一条回路 $1\to i\to 1$，各趟之间互不影响。

**引理 1（行程可加）**：设 $d(u,v)$ 为有向图上 $u$ 到 $v$ 的最短时间，则总时间的最小值为

$$\sum_{i=2}^{n}\big(d(1,i)+d(i,1)\big).$$

*证明*：**下界**：每一趟都必须从 $1$ 出发到 $i$ 再回到 $1$，其耗时 $\ge d(1,i)+d(i,1)$；总耗时是各趟之和，故不小于右端。**上界**：每一趟独立地按最短路走，由于每趟结束都回到 $1$，下一趟的起点仍是 $1$，前一趟的选择不改变后一趟的可选路径，所以这些最短路可以同时取到，和式可达。$\square$

于是问题化为：求 $1$ 到所有点的最短路，以及所有点到 $1$ 的最短路。

### 第二步：所有点到 $1$ 的最短路怎么做

$n$ 次 Dijkstra 是 $\mathcal{O}(nm\log n)$，$10^3\times10^5$ 不可接受。需要一个转化。

**引理 2（反向图）**：把每条边 $u\to v$ 反向成 $v\to u$、权不变，得到图 $G^{R}$。则 $G$ 中 $d(i,1)$ 等于 $G^{R}$ 中 $d^{R}(1,i)$。

*证明*：设 $G$ 中从 $i$ 到 $1$ 的最短路为 $i=x_0\to x_1\to\cdots\to x_k=1$。把这条路径倒过来看：$1=x_k\to x_{k-1}\to\cdots\to x_0=i$，其中每条边 $x_{j+1}\to x_j$ 在 $G^{R}$ 中恰好是 $x_j\to x_{j+1}$ 的反向边，故它是 $G^{R}$ 中一条 $1\to i$、权相同的路径，于是 $d^R(1,i)\le d(i,1)$。对 $G^R$ 再用一次同样的论证（$G$ 是 $G^R$ 的反向图）得 $d(i,1)\le d^R(1,i)$。两者相等。$\square$

所以只要在原图和反向图上各跑一次以 $1$ 为源的单源最短路。

### 第三步：Dijkstra 为什么正确

**引理 3（Dijkstra 的出队即最优）**：边权非负时，Dijkstra 每次取出当前未确定点中 `dis` 最小者 $u$，此时 `dis[u]` 已等于 $d(s,u)$。

*证明*：反设存在更短的 $s\to u$ 路径 $P$，其长度 $<dis[u]$。沿 $P$ 从 $s$ 出发，设 $y$ 是 $P$ 上第一个尚未确定的点，$x$ 是 $y$ 的前驱（已确定）。则

$$dis[y]\le dis[x]+w(x,y)=d(s,x)+w(x,y)\le |P|<dis[u],$$

其中第一个不等号来自松弛，第二个因为 $x$ 已确定，最后因为 $P$ 的其余部分权非负。这与 $u$ 是当前 `dis` 最小的未确定点矛盾。$\square$

实现上使用小根堆 + 惰性删除（出队时若已确定就跳过），复杂度 $\mathcal{O}((n+m)\log m)$。

顺带说明为什么不用 Floyd：$n=10^3$ 时 Floyd 是 $10^9$ 次松弛，且需要 $10^6$ 个 `i64`，既慢又占内存；而本题只关心两个源点的最短路，堆优化 Dijkstra 两次即可，是更贴合"单源、稀疏"这一数据特征的选择。

**定理**：两次 Dijkstra 的结果按引理 1 求和即为答案。

*证明*：引理 2 把"回程"转成反向图上的"去程"，引理 3 保证两次 Dijkstra 求出的都是真正的最短路，引理 1 给出总时间的表达式。$\square$

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 每次送完必须回邮局，一趟是独立回路，总时间可按趟相加。
- `reduce to easier problem` — 把"所有点到 1"化成"1 到所有点"，只需一次额外的最短路。
- `explore its property` — 路径反转是原图与反向图之间的双射，保证距离相等。
- `classic problem solution` — 堆优化 Dijkstra + 惰性删除，$\mathcal{O}(m\log n)$ 求单源最短路。
- `classic problem solution` — 反向建图，用同一个函数复用两遍。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $n$ | `n` | 点数 |
| $m$ | `m` | 边数 |
| $G$ | `g[u]` | 原图邻接表，元素 `{v,w}` |
| $G^{R}$ | `rg[u]` | 反向图邻接表，读入 $u\to v$ 时把 $v\to u$ 加入 |
| $d(1,i)$ | `dis[i]` | 原图上 $1$ 到 $i$ 的最短路，初值 `inf` |
| $d(i,1)$ | `rdis[i]` | 反向图上 $1$ 到 $i$ 的最短路，即原图 $i$ 到 $1$ |
| — | `vis[u]` | 该点是否已确定（出堆过一次） |
| — | `dij(s,gr,d)` | 通用 Dijkstra，参数为源点、邻接表指针、距离数组 |
| $\infty$ | `inf` | 哨兵 `1145141919810LL`，远大于任何真实距离 |
| 答案 | `ans` | $\sum_{i=2}^{n}(dis[i]+rdis[i])$，`i64` |

### 算法步骤

1. 读入 $n,m$，对每条边 `u v w` 执行 `--u;--v`，把 `{v,w}` 加入 `g[u]`、`{u,w}` 加入 `rg[v]`。
2. 调用 `dij(0,g,dis)`：以 $0$ 号点（原 $1$ 号）为源，在正向图上求最短路。
3. 调用 `dij(0,rg,rdis)`：在反向图上求最短路。
4. 累加 $i=1..n-1$ 的 `dis[i]+rdis[i]`，输出。

### 复杂度分析

- **时间复杂度**：两次 Dijkstra，$\mathcal{O}((n+m)\log m)$；$n=10^3,m=10^5$ 实测约 $0.01$ s。
- **空间复杂度**：$\mathcal{O}(n+m)$，两张邻接表共 $2m$ 条有向边。

### 正确性验证

引理 1 给出总时间的可加分解，引理 2 保证反向图与原图的回程距离相等，引理 3 保证 Dijkstra 的正确性。数值上单条最短路 $\le10^7$，总和 $\le2\times10^{10}$，`i64` 安全；`inf` 取 $1.1\times10^{12}$，大于任何真实距离且加法不会溢出 `i64`。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1629 邮递员送信
// https://www.luogu.com.cn/problem/P1629
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};
constexpr i64 inf{1145141919810LL};

int n,m;
vector<pair<int,i64>>g[mxn],rg[mxn];
i64 dis[mxn],rdis[mxn];
bool vis[mxn];

void dij(int s,vector<pair<int,i64>>*gr,i64*d)
{
	fill_n(d,mxn,inf);
	fill_n(vis,mxn,false);
	priority_queue<pair<i64,int>,vector<pair<i64,int>>,greater<>>Q;
	d[s]=0;
	Q.emplace(0,s);
	while(!Q.empty())
	{
		auto[dd,u]=Q.top();
		Q.pop();
		if(vis[u])
			continue;
		vis[u]=true;
		for(auto[v,w]:gr[u])
			if(d[v]>dd+w)
			{
				d[v]=dd+w;
				Q.emplace(d[v],v);
			}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<m;++i)
	{
		int u,v;
		i64 w;
		cin>>u>>v>>w;--u;--v;
		g[u].push_back({v,w});
		rg[v].push_back({u,w});          // 反向图：求所有点到 1 的最短路
	}
	dij(0,g,dis);
	dij(0,rg,rdis);
	i64 ans=0;
	for(int i=1;i<n;++i)
		ans+=dis[i]+rdis[i];
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **只跑一次最短路**：有向图上"去"与"回"不对称，必须再跑反向图；无向图才可以只跑一次乘 2。
2. **反向图方向写反**：读入 $u\to v$ 时应把 $u\to v$ 加入 `g`、把 $v\to u$ 加入 `rg`（因为 `rg` 表示"沿原边逆向走"）。
3. **`dis` 用 `int`**：单条最短路可达 $10^7$ 尚可，但总和 $2\times10^{10}$ 超 `int`，`ans` 必须 `i64`。
4. **`vis` 不重置**：`dij` 被调用两次，必须在函数内 `fill_n(vis,...)`，否则第二次所有点都被当成已确定。
5. **忘记惰性删除**：同一结点可能多次入堆，出堆时若 `vis[u]` 为真必须跳过，否则复杂度退化。
6. **下标**：内部 0-based，`--u;--v` 后 $1$ 号点变成 $0$ 号；累加时从 $i=1$ 开始（跳过邮局自己）。
