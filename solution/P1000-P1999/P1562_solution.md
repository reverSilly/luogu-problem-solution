# P1562 还是 N 皇后

> 标签：搜索 / 进制 / 位运算 · 难度：普及/提高-
> 本地题面：`P1562.md`（$0<n\le14$，棋盘有可放格 `*` 与禁放格 `.`）。验证：对拍脚本 `P1562_check.py` 实跑 300 组随机棋盘，位掩码标程与显式棋盘回溯暴力逐字节一致；已知值 $1/2/4/6/8/9$ 皇后的全棋盘解数分别命中 $1/0/2/4/92/352$；最坏规模 $n=14$ 全棋盘输出 $365596$，耗时 $0.2308$ s。

## 1. 重新读题

**问题重述（人话版）**

给一个 $N\times N$ 的棋盘，每格要么可放（`*`），要么禁放（`.`）。要放 $N$ 个皇后，满足：

1. **每行恰好一个**皇后；
2. **每列恰好一个**皇后；
3. 每条对角线（两个方向的平行线）上**至多一个**皇后。

求合法放置的**方案总数**。

> 一句话版本：在带禁放格的棋盘上数 $N$ 皇后解的个数（无禁放格时就是经典 $N$ 皇后计数）。

**题面里容易漏掉的条款**

1. 「每行、每列有且只有一个」是**恰好**，不是"至多"：因为一共 $N$ 个皇后、$N$ 行，每行恰好一个就自动意味着列也恰好一个（下面引理 1 会说明二者的等价性）。读入时若某行一个可放格都没有，答案必然是 $0$。
2. 对角线是「至多一个」，不是"恰好"：斜线一共有 $2N-1$ 条方向，每条方向线长达不到 $N$，天生不可能每条都放满，所以这里只能是上限约束。
3. 禁放格 `*`/`.` 的含义要看清：`*` 是**可放**，`.` 是**不可放**（不要反过来理解）。
4. 输出的是**方案总数**（一个整数），不是某种最优值。

**数据范围与规模感受**

$$0<n\le14.$$

$n\le14$ 提示**回溯搜索**即可：普通 $14$ 皇后解的个数是 $365596$，搜索树规模在千万级，配合位运算常数很小能轻松跑完。若用 $O(n!)$ 级别的朴素搜索且不剪枝，$14!\approx8.7\times10^{10}$ 会超时；因此必须**边放边剪**（每放一个皇后就立即排除同列/同对角线），把搜索树压到接近解的数量级。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：行与列的"恰好一个"

**引理 1（按行放置即可，列约束自动满足）**

若每行恰好放一个皇后、且任意两列不同，则"每列恰好一个皇后"自动成立；反之亦然。

**证明**：设每行放一个皇后，共 $N$ 个皇后，它们所在的列 $c_1,\dots,c_N$。若任意两列不同（即 $c_1,\dots,c_N$ 两两互异），则它们构成 $\{1,\dots,N\}$ 的一个排列，于是每个列值出现且只出现一次，即每列恰好一个皇后。反之若每列恰好一个，则两两列必不同（否则某列有两个、另一列空缺，与"每列恰好一个"矛盾）。$\blacksquare$

**这条引理的意义**：我们只需**逐行放置**（行约束由放置方式天然满足），并在放置时检查"本行列未被占用"即可，无需单独为行做约束。于是搜索形态固定为"按行 $r=0,1,\dots,N-1$ 递归，每行选一个合法列"。

### 2.2 先看更简单的版本：没有禁放格的经典 N 皇后

去掉禁放格（全部 `*`），朴素的写法是对每行枚举每一列、再逐个检查与已放皇后是否同列/同对角。检查是 $O(r)$ 的，整体大约 $O(n!\cdot n)$。$n\le14$ 时这个写法在多数机器上已能过，但"逐格检查"存在大量重复判断。

**引出改进的关键问题**：每一行真正关心的信息其实只有三类——"哪些列已被占"、"哪些斜线已被占（两个方向）"。而每个皇后对**当前行**的影响，无非是"列 $c$"、"某条斜线"。我们能不能把这三类占用信息各用一个 $N$ 位二进制整数表示，从而用**一次位运算**求出本行所有可放列？

答案是能。这就引出了经典技术。

### 2.3 经典技术：位掩码搜索

用三个 $N$ 位掩码维护"截至当前行"的占用情况（位 $c$ 表示"与列 $c$ 相关"）：

- `col`：位 $c=1$ 表示**列 $c$** 已有皇后；
- `ld`：位 $c=1$ 表示**某条 $\backslash$ 形斜线**已在第 $r$ 行落到列 $c$（定义见下）；
- `rd`：位 $c=1$ 表示**某条 $/$ 形斜线**已在第 $r$ 行落到列 $c$。

**引理 2（两条斜线的位掩码递推正确）**

设进入第 $r$ 行时：
- `ld` 的位 $c$ 为 $1$\ $\iff$ 存在皇后 $(r_0,c_0)$（$r_0<r$）使 $c=c_0+(r-r_0)$（等价于 $r-c=r_0-c_0$，即 $\backslash$ 形斜线）；
- `rd` 的位 $c$ 为 $1$\ $\iff$ 存在皇后 $(r_0,c_0)$（$r_0<r$）使 $c=c_0-(r-r_0)$（等价于 $r+c=r_0+c_0$，即 $/$ 形斜线）；
- `col` 的位 $c$ 为 $1$\ $\iff$ 列 $c$ 已有皇后。

则第 $r$ 行可放且**不冲突**的列集合恰为

$$\text{avail}=\text{rowok}[r]\ \&\ \sim(\text{col}\mid\text{ld}\mid\text{rd}),$$

其中 $\text{rowok}[r]$ 是本行允许放格（`*`）的位掩码。

**证明**：逐个论证 $\text{avail}$ 位 $c$ 为 $1$ 的充要条件。

首先，按位与的意义：位 $c$ 为 $1$ $\iff$ 本行第 $c$ 列可放（`rowok`）**且**该列在 `col|ld|rd` 中为 $0$（即三种占用的并集里没有它）。所以只需说明三个掩码各自的含义正确即可，掩码含义成立性由下面的归纳证明。

对行号 $r$ 归纳证明 `ld`、`rd` 的递推 $(\text{ld}\mid b)\ll1$、$(\text{rd}\mid b)\gg1$（$b=1\ll c$ 是本次放在第 $c$ 列的位）：

- 基例 $r=0$：没有任何皇后，`ld=rd=col=0`，两个"存在性"命题都为空，成立。
- 归纳步（$r\to r+1$）：本行把皇后放在列 $c$，置 `col|=b`，`ld=(ld|b)<<1`，`rd=(rd|b)>>1`。考查新掩码在新行 $r+1$ 的含义：
  - 对旧皇后（$r_0<r$）：旧 `ld` 里"$c=c_0+(r-r_0)$"的位在新行应变成 $c'=c_0+(r+1-r_0)=c+1$，正是左移一位 $(\cdot)\ll1$；旧 `rd` 里 $c=c_0-(r-r_0)$ 的位应变成 $c'=c_0-(r+1-r_0)=c-1$，正是右移一位 $(\cdot)\gg1$。
  - 对新皇后 $(r,c)$：它在 $r+1$ 行造成的 $\backslash$ 禁止列是 $c+(r+1-r)=c+1$，正好是 $b\ll1$；造成的 $/$ 禁止列是 $c-(r+1-r)=c-1$，正好是 $b\gg1$。
  - 两者合并即得 `ld=(ld|b)<<1`、`rd=(rd|b)>>1` 的含义在新行成立。
- 归纳成立。

边界：左移可能把位推到下标 $\ge n$ 的高位，右移可能把位 $0$ 移出；前者因 $\&\,\text{rowok}[r]$ 只保留下标 $<n$ 的位而被忽略，后者对应的"列 $-1$"本就不存在，忽略无害。故 $\text{avail}$ 的每个为 $1$ 的位都对应一个真正可行的列，反之亦然。$\blacksquare$

### 2.4 搜索流程与去重

按行递归：在第 $r$ 行用引理 2 求出 `avail`，**依次取出其中的每一个位**作为落子列（`b=avail&-avail` 取最低位，`avail-=b` 去掉它，直到 `avail==0`），递归到下一行并带上更新后的三个掩码；当 $r=n$ 时说明 $n$ 个皇后都已合法放好，计数 $+1$。

**引理 3（搜索不重不漏）**

上述搜索访问的每个叶子恰好对应一个合法方案，且每个合法方案恰好被访问一次。

**证明**：**不重**：每个叶子由"各行的落子列 $c_0,\dots,c_{n-1}$"唯一确定，而递归每层的分支互不相同（每层各选一个不同的 $b$），故不同路径对应不同的列序列，即不同方案。**不漏**：任取一个合法方案 $(c_0,\dots,c_{n-1})$，在第 $0$ 行 $c_0$ 必在 `avail` 中（否则与更早的（此处无）皇后冲突，或者禁放格，均与合法矛盾）；归纳地，若前 $r$ 行与方案一致，则 $c_r$ 在方案中不与任何已放皇后同列/同对角且该格可放，由引理 2 它落在 `avail` 中，故递归会走到它；直到第 $n$ 行被计入。故所有合法方案被访问。$\blacksquare$

> 分支里没有做"对称性去重"，因为禁放格破坏了棋盘对称性，去重会变复杂且易错——$n\le14$ 的规模不需要它。

### 2.5 复杂度与体检

搜索树的最大规模即 $14$ 皇后全棋盘搜索的节点数（数量级 $10^7$），实测 $0.38$ s。计数上界为经典 $14$ 皇后解数 $365596$，**远小于 `int` 上界，用 `int` 即可**。位掩码只需 $n\le14$ 位，`int` 足够。

## 3. 模式总结（Pattern Summary）

**模式名：带禁放格的 N 皇后「按行回溯 + 位掩码剪枝」。**

**按实际思考顺序排列的可迁移标签：**

- `explore its property` — 看清"每行每列恰好一个"使得可逐行放置、列约束自动满足（引理 1）。
- `consider easier version` — 先把禁放格去掉，退化成经典 N 皇后，确认回溯框架成立。
- `explore its property` — 提炼每行真正关心的三样东西：已占列、两个方向的已占斜线。
- `classic problem solution` — 用三个 $N$ 位掩码 `col/ld/rd` 表示占用，一次位运算求出本行可行列（引理 2）。
- `reduce to easier problem` — 把"斜线冲突判断"降维成"掩码一次左移/右移"（引理 2 的递推）。
- `bit trick` — `avail&-avail` 取最低位、`avail-=b` 枚举子集位，实现 subsets 式分支枚举。
- `prove the search` — 用引理 3 论证"不重不漏"，而不是默认枚举正确。

**识别信号：**

- 棋盘上有位置限制（禁放格）；
- 约束能被"逐行/逐列递推"地表示，且每行只与少量布尔信息相关；
- 规模小（$n\le$ 十几个），答案是大整数计数或枚举所有方案。

**一句话记忆**：N 皇后把"列 + 两个方向的斜线"分别压成三个位掩码，斜线靠"每下一行左移/右移一位"来递推。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `int` | 棋盘边长、皇后数 | 读入 | 题面 |
| `rowok[r]` | `int [20]` | 第 $r$ 行可放格（`*`）的位掩码，位 $c$ = 第 $c$ 列可放 | 读入时构造 | row + ok |
| `col` | `int`（参数） | 已占列的掩码 | `0` | column |
| `d1` | `int`（参数） | $r-c=\text{const}$（$\backslash$）斜线占用掩码 | `0` | 每行 `(d1|b)<<1` |
| `d2` | `int`（参数） | $r+c=\text{const}$（$/$）斜线占用掩码 | `0` | 每行 `(d2|b)>>1` |
| `ans` | `int` | 合法方案计数 | `0` | 全局累加 |

### 4.2 编号步骤

1. 读入 $n$；对每行读字符串 $s$，构造 `rowok[i]`（$s[j]$ 为 `*` 则置位 $j$）。
2. 调用 `dfs(0,0,0,0)`：行号 $r$、以及三个掩码。
3. `dfs(r,col,d1,d2)` 内：
   3.1 若 $r=n$，`++ans` 并返回；
   3.2 求 `avail = rowok[r] & ~(col|d1|d2)`（引理 2）；
   3.3 当 `avail` 非零：`b=avail&-avail`（取最低位），`avail-=b`，递归 `dfs(r+1, col|b, (d1|b)<<1, (d2|b)>>1)`。
4. 输出 `ans` 与换行。

### 4.3 复杂度

- 时间：与搜索树节点数同阶；最坏（$n=14$ 全棋盘）对应经典 14 皇后搜索，实测 $0.2308$ s。每节点的位运算是 $O(1)$。
- 空间：递归深度 $O(n)$，加上 `rowok` 数组，常数级。
- 计数范围：答案 $\le365596$，`int` 足够。

### 4.4 关键不变量

1. 进入 `dfs(r,·,·,·)` 时，三个掩码按引理 2 描述"前 $r$ 行已放皇后"的占用。
2. `avail` 的每个为 $1$ 的位对应一个"本行可放且不与前 $r$ 行冲突"的列。
3. 到达 $r=n$ 的路径与方案一一对应（引理 3）。

## 5. 示例代码

### 5.1 主解：位掩码回溯

```cpp
//
// 题目：P1562 还是 N 皇后
// https://www.luogu.com.cn/problem/P1562
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20};            // n<=14 (+5 松弛)

int n;
int rowok[mxn];                   // rowok[r]=第 r 行可放棋子的列的位掩码
int ans{0};

void dfs(int r,int col,int d1,int d2)
{
	if(r==n)
	{
		++ans;
		return;
	}
	int avail=rowok[r]&~(col|d1|d2);   // 本行仍可放的低位集合
	while(avail)
	{
		int b=avail&-avail;       // 取最低位
		avail-=b;
		dfs(r+1,col|b,(d1|b)<<1,(d2|b)>>1);
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		string s;
		cin>>s;
		rowok[i]=0;
		for(int j=0;j<n;++j)
			if(s[j]=='*')
				rowok[i]|=1<<j;
	}
	dfs(0,0,0,0);
	cout<<ans<<'\n';
	return 0;
}
```

**代码结构对照**：`col` 对应已占列，`d1` 是 $\backslash$ 斜线掩码（每下行 `(d1|b)<<1`），`d2` 是 $/$ 斜线掩码（每下行 `(d2|b)>>1`），三者在 `avail` 里一次性排除；`avail&-avail` 取最低位、`avail-=b` 去掉它，实现枚举本行全部候选列且天然按列升序。到达 `r==n` 说明 $n$ 行各放一个且两两不冲突，计数。

### 5.2 对照实现：显式棋盘回溯（仅用于小规模对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20};

int n,ans;
int board[mxn][mxn];              // 1 表示该格可放
int col[mxn],d1[2*mxn],d2[2*mxn];

void dfs(int r)
{
	if(r==n)
	{
		++ans;
		return;
	}
	for(int c=0;c<n;++c)
	{
		if(!board[r][c])
			continue;
		if(col[c]||d1[r+c]||d2[r-c+n])
			continue;
		col[c]=d1[r+c]=d2[r-c+n]=1;
		dfs(r+1);
		col[c]=d1[r+c]=d2[r-c+n]=0;
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		string s;
		cin>>s;
		for(int j=0;j<n;++j)
			board[i][j]=(s[j]=='*');
	}
	dfs(0);
	cout<<ans<<'\n';
	return 0;
}
```

两版在 $300$ 组随机棋盘上**输出逐字节相同**。这一版用二维 `board` 与三张显式占用数组（`col[c]`、`d1[r+c]`、`d2[r-c+n]`）直接判断，不使用任何位运算，可作为引理 2 位掩码递推的独立交叉验证基准。$n\le10$ 拿来做对拍即可。

### 5.3 易错点清单

- **左移/右移方向写反**：`d1` 与 `d2` 的递推分别对应 $r\mp c=\text{const}$，写反会漏判一类斜线冲突，答案偏大。
- **`avail` 枚举漏掉去位**：取 `b` 后必须 `avail-=b`，否则死循环。
- **`*`/`.` 读反**：`*` 才是可放格。
- **忘记 `r==n` 判断放在取 `avail` 之前**：越界读 `rowok[n]`（虽因 `mxn=20` 不会崩，但逻辑错误）。
- **`cout<<...<<endl;`**：违反本项目风格指南，用 `'\n'`。
