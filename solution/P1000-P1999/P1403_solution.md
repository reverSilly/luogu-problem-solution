## 1. 重新读题

**题面原样**：$f(N)$ 表示正数 $N$ 的**约数的个数**（题面例：$12$ 的约数是 $1,2,3,4,6,12$，故 $f(12)=6$）。给定 $n$，求
$$\sum_{i=1}^{n}f(i).$$
输入一行一个整数 $n$，输出一行一个整数表示答案。

**白话重述**：把 $1\sim n$ 每个数的约数个数**加起来**。要盯紧两处：
- 统计量是"**约数的个数**"（$f(12)=6$），**不是"约数之和"**（若按约数之和，$12$ 就是 $28$）；题面"统计每个正数 $N$ 的约数的个数，并以 $f(N)$ 来表示"已明确，最终要求的是这些**个数的总和**，是一个纯整数（不取模）。
- 求和范围是 $i=1..n$，**包含 $f(1)=1$**（$1$ 只有约数 $1$），这是唯一容易被漏掉/多算的边界项。

**数据范围**

| 量 | 范围 |
|---|---|
| $n$（题面记作 $N$） | $1\le n\le 10^{6}$ |
| 20% 档 | $n\le 5000$ |

分档在暗示什么：$n\le5000$ 时"逐个数枚举因子"只需 $\frac{n(n+1)}2=12\,502\,500\approx1.25\times10^{7}$ 次判定（§2.1 算账 (a)），拿 20 分很容易；满分档同一算法是 $5.0\times10^{11}$ 次，**"逐个数字数"这条路必须整体换掉**——这正是标签里"枚举"与"整除分块"要解决的问题。

## 2. 思维链（Chain-of-thought）

### 2.1 按定义暴力：先算清"枚举对象"的账

最朴素的做法：对每个 $m\in[1,n]$ 数清它有几个约数。

- (a) 内层扫 $d=1..m$：总判定次数 $\sum_{m=1}^{n}m=\frac{n(n+1)}2$。$n=5000$：$1.25\times10^{7}$（20 分稳）；$n=10^6$：$5.000005\times10^{11}$，按 $10^8$/秒的常识量级是 $\approx5\times10^{3}$ 秒，**不可行**。
- (b) 内层只扫到 $\sqrt m$（成对记 $(d,m/d)$）：$\sum_{m\le n}\lfloor\sqrt m\rfloor\le\sum_{m\le n}\sqrt m\le\int_0^n\sqrt x\,dx+\sqrt n=\frac23 n^{3/2}+\sqrt n$。$n=10^6$：$\frac23\times10^{9}+10^{3}\approx6.67\times10^{8}$，按 $10^8$/秒约 $7$ 秒量级（**只是操作数量的换算，非实测**），比 1 秒的常见时限差一个量级——**这条路仍然太慢**。

矛盾点很清楚：**枚举对象是"数字 $m$ × 它的候选因子"**，这个乘积规模本身就是 $\Theta(n^{3/2})$ 或 $\Theta(n^2)$。要快，必须换一个**总数少得多**的枚举对象。

### 2.2 换计数对象：把"每个数有几个因子"换成"每个因子管几个数"

$f(m)=\#\{d:d\mid m\}$ 是按 $m$ 分组数 $d$；反过来按 $d$ 分组数 $m$，$d$ 能整除的 $m\le n$ 恰是 $d,2d,\dots,\lfloor n/d\rfloor d$，共 $\lfloor n/d\rfloor$ 个。写成定理：

**定理 1（换序求和 / 双计数）** 对一切 $n\ge1$，
$$\sum_{i=1}^{n}f(i)=\sum_{d=1}^{n}\left\lfloor\frac nd\right\rfloor .$$

**证明**（完整双计数，不靠"交换求和显然"）
取有限集
$$\mathcal A=\{(d,m)\in\mathbb Z_{\ge1}^2:\ d\mid m,\ 1\le m\le n\}.$$
**先验证 $\mathcal A$ 与"因子对"一一对应**：映射 $\pi(d,m)=(d,\,m/d)$ 把 $\mathcal A$ 映到 $\mathcal B=\{(d,k)\in\mathbb Z_{\ge1}^2:\ dk\le n\}$。合法性：$d\mid m$ 使 $m/d\in\mathbb Z_{\ge1}$，且 $dk=m\le n$。逆映射 $\tau(d,k)=(d,\,dk)$：$d\mid dk$ 且 $1\le dk\le n$，故像落在 $\mathcal A$；$\tau(\pi(d,m))=(d,(m/d)\cdot d)=(d,m)$，$\pi(\tau(d,k))=(d,(dk)/d)=(d,k)$（$d\ne0$ 保证整除精确）。两者互逆，故 $\pi$ 是双射、$|\mathcal A|=|\mathcal B|$。

**按第二个坐标 $m$ 分组**：对固定 $m\in[1,n]$，该 fiber 是 $\{(d,m):d\mid m\}$（即 $d$ 遍历 $m$ 的全部正约数），元素数恰为 $f(m)$（按 $f$ 的定义）；$m>n$ 的 fiber 为空（$\mathcal A$ 的第二坐标被限制在 $\le n$）。这些 fiber 两两不交、并为 $\mathcal A$（划分性：每个元素的第二坐标唯一），故
$$|\mathcal A|=\sum_{m=1}^{n}f(m).$$
**按第一个坐标 $d$ 分组**：对固定 $d\ge1$，fiber 是 $\{(d,m):m\le n,\ d\mid m\}=\{(d,dk):1\le k\le n/d,\ k\in\mathbb Z\}$。映射 $m\mapsto k=m/d$ 是 fiber 到 $\{k\in\mathbb Z_{\ge1}:k\le n/d\}$ 的双射（合法性与互逆同上：$k$ 是整数且 $k\le n/d\Rightarrow k\le\lfloor n/d\rfloor$；反之 $1\le k\le\lfloor n/d\rfloor$ 给出 $dk\le d\lfloor n/d\rfloor\le n$）。而 $\{k\ge1:k\le x\}$ 的元素数按定义就是 $\lfloor x\rfloor$（$x<1$ 时为空、即 $0$）。故该 fiber 大小为 $\lfloor n/d\rfloor$；$d>n$ 时 $\lfloor n/d\rfloor=0$（空 fiber），所以 $d$ 只需跑到 $n$。同理划分得
$$|\mathcal A|=\sum_{d=1}^{n}\left\lfloor\frac nd\right\rfloor .$$
两个表达式都等于同一个有限集的基数 $|\mathcal A|$，故相等。$\blacksquare$

**同一个定理的"代数写法"（互验用）**：把 $f(m)$ 按定义展开成示性函数和，再用"每一项只含有限个非零项"换序（有限和可任意重排，无需收敛性讨论）：
$$\sum_{m=1}^{n}f(m)=\sum_{m=1}^{n}\ \sum_{d\ge1,\,d\mid m}1=\sum_{d=1}^{n}\ \sum_{m\le n,\,d\mid m}1=\sum_{d=1}^{n}\#\{m\le n:d\mid m\}=\sum_{d=1}^{n}\left\lfloor\frac nd\right\rfloor,$$
其中 $d>n$ 时内层为空（$d\mid m\Rightarrow d\le m\le n$，用 §2.3 里的"约数不超过自身"），故外层上限可以安全地写成 $n$；最后一个等号是"$m=dk,\ 1\le k\le\lfloor n/d\rfloor$"的双射（上面已证）。这条链与上面的双计数**是同一件事的两种语言**：示性函数换序=把 $\mathcal A$ 的两种投影写成一个累次和。本文正文用集合语言，因为它能把"$d>n$ 为什么可以不管""$m>n$ 为什么不在内"这两处边界逼出来。$\blacksquare$

**这一步的价值**：左边要先知道每个 $f(i)$（$\Theta(n^{3/2})$ 或 $O(n\log n)$ 的活），右边只是 $n$ 次整数除法，**完全不需要知道任何单个 $f(i)$**。工作量从"枚举因子对"降到"枚举因子本身"。

### 2.3 中间路线：倍数标记（它其实就是定理 1 的证明写成代码）

如果舍不得 $f$ 本身（比如题目改成要求 $\max f(i)$），标准做法是让每个 $d$ 去"给自己的倍数记一票"：

**引理 2（倍数标记的循环次数）** `for(d=1..n) for(m=d;m<=n;m+=d) ++f[m];` 的内层总执行次数 $=\sum_{d=1}^{n}\lfloor n/d\rfloor$，且跑完后 $f[m]$ 恰为 $m$ 的正约数个数。

**证明** 固定 $d$：内层取值 $m=d,2d,3d,\dots$ 直到 $\le n$，即 $m=kd,\ 1\le k\le\lfloor n/d\rfloor$（引理同上：$kd\le n\iff k\le n/d$，$k$ 整数故 $k\le\lfloor n/d\rfloor$；反向 $k\le\lfloor n/d\rfloor\Rightarrow kd\le d\lfloor n/d\rfloor\le n$）。故恰执行 $\lfloor n/d\rfloor$ 次，总和即所求。计数正确性：`++f[m]` 对 $m$ 被执行当且仅当"存在 $k\ge1$ 使 $m=kd$ 且 $d\in[1,n]$"，即 $d\mid m$；而 $m\le n$ 时 $m$ 的每个正约数 $d$ 都满足 $d\le m\le n$（**约数不超过自身**：$d\mid m$、$m=dk$、$k\ge1\Rightarrow d\le dk=m$），所以 $d$ 的上界 $n$ 没有漏掉任何约数。故最终 $f[m]=\#\{d:d\mid m\}=f(m)$。$\blacksquare$

**代价账**：$\sum_{d\le n}\lfloor n/d\rfloor\le\sum_{d\le n}\frac nd=n(1+\ln n)$（详见 §2.7 的积分估计）。$n=10^6$：$\le1.48\times10^{7}$ 次自增，可行（约 $0.15$ 秒量级的换算，非实测），比主式 (d) 的 $10^6$ 次除法多约 $15$ 倍，换来的是**每个 $f(i)$ 的显式值**。它与定理 1 的关系：这段代码把 $\mathcal A$ 的元素**逐个访问了一遍**，所以它的运行次数天然等于 $|\mathcal A|$，也就是答案本身——定理 1 是"给这段循环直接求和"，而主式是"只数不访问"。

**$n=6$ 的逐轮跟踪**（验证引理 2 的两件事：轮长度 $=\lfloor n/d\rfloor$、终值 $=f(m)$）：

| 轮 $d$ | 被自增的下标 $m$ | 次数 | 该轮后 $f[1..6]$ |
|---|---|---|---|
| 1 | 1,2,3,4,5,6 | 6 $=\lfloor6/1\rfloor$ | 1,1,1,1,1,1 |
| 2 | 2,4,6 | 3 $=\lfloor6/2\rfloor$ | 1,2,1,2,1,2 |
| 3 | 3,6 | 2 $=\lfloor6/3\rfloor$ | 1,2,2,2,1,3 |
| 4 | 4 | 1 $=\lfloor6/4\rfloor$ | 1,2,2,3,1,3 |
| 5 | 5 | 1 $=\lfloor6/5\rfloor$ | 1,2,2,3,2,3 |
| 6 | 6 | 1 $=\lfloor6/6\rfloor$ | 1,2,2,3,2,4 |

终值 $1,2,2,3,2,4$ **与题面表格 $f(1..6)$ 逐个相同**（这是题面自带的官方数据），总自增次数 $6+3+2+1+1+1=14$ 恰是 §4.3(0) 里 $S(6)=14$ ✓。注意 $d=4,5$ 两轮各只 1 次（$\lfloor6/4\rfloor=\lfloor6/5\rfloor=1$），这正是"$d>n/2$ 只影响自己"的体现，也是主式里那一片 $1$ 的来源。

### 2.4 还能更快吗：整除分块（引理 3）

主式里 $n$ 项中真正不同的值很少：$\lfloor n/d\rfloor$ 随 $d$ 递增而**单调不增**，而且一大段 $d$ 共用同一个值。

**引理 3（分块三性质）** 设 $l\ge1$，$q=\lfloor n/l\rfloor\ (\ge1)$，$r=\lfloor n/q\rfloor$。则
(i) $\forall d\in[l,r]:\lfloor n/d\rfloor=q$；(ii) $\lfloor n/(r+1)\rfloor<q$；(iii) 不同的值 $\lfloor n/d\rfloor$（$d=1..n$）的个数 $\le2\lceil\sqrt n\rceil$。

**证明** (i) $d\le r=\lfloor n/q\rfloor$ 且 $q\ge1$，两边乘 $q$：$dq\le q\lfloor n/q\rfloor\le q\cdot(n/q)=n$，故 $q\le n/d$；$q$ 是整数，"整数 $\le$ 实数 $\Rightarrow$ 整数 $\le$ 该实数的下取整"，得 $q\le\lfloor n/d\rfloor$。又 $d\ge l\Rightarrow n/d\le n/l\Rightarrow\lfloor n/d\rfloor\le\lfloor n/l\rfloor=q$（下取整保序：$\lfloor x\rfloor\le x\le y$ 且 $\lfloor y\rfloor$ 是 $\le y$ 的最大整数，故 $\lfloor x\rfloor\le\lfloor y\rfloor$）。两侧夹住即 $\lfloor n/d\rfloor=q$。
(ii) $r=\lfloor n/q\rfloor\Rightarrow r\le n/q<r+1\Rightarrow n/(r+1)<q$；$\lfloor n/(r+1)\rfloor\le n/(r+1)<q$ 且左边是整数，故 $\le q-1<q$。
(iii) 值分两类。$d\le\sqrt n$ 的 $d$ 至多 $\lceil\sqrt n\rceil$ 个，每个至多贡献一个新值；$d>\sqrt n$ 时 $\lfloor n/d\rfloor\le n/d<\sqrt n$，故这些值只能取自 $\{0,1,\dots,\lceil\sqrt n\rceil-1\}$（$\lfloor x\rfloor<x$，且 $x<\sqrt n\le\lceil\sqrt n\rceil$、$\lfloor x\rfloor$ 整数故 $\lfloor x\rfloor\le\lceil\sqrt n\rceil-1$），至多 $\lceil\sqrt n\rceil$ 个。合计 $\le2\lceil\sqrt n\rceil$。$\blacksquare$

于是
$$\sum_{d=1}^{n}\left\lfloor\frac nd\right\rfloor=\sum_{\text{块}[l,r]}(r-l+1)\cdot q,\qquad q=\left\lfloor\frac nl\right\rfloor,$$
（(i) 保证整块同值，(ii) 保证块在此结束、块之间不重叠不遗漏，$l=r+1$ 推进直到 $l>n$；$l=n$ 时 $q=1$、$r=n$，必然正常收尾。）

**复杂度对比算式**（$n=10^6$，按 $10^8$/秒的常识量级换算，**不是实测**）：

| 路线 | 式子 | 操作数 | 判定 |
|---|---|---|---|
| (a) 定义扫 $1..m$ | $\frac{n(n+1)}2$ | $5.0\times10^{11}$ | 仅 20% 档（$1.25\times10^{7}$）可行 |
| (b) 定义扫到 $\sqrt m$ | $\le\frac23 n^{3/2}+\sqrt n$ | $6.7\times10^{8}$ | 满分档超时约 $7$ 倍（换算值） |
| (c) 倍数标记（引理 2） | $\sum_d\lfloor n/d\rfloor\le n(1+\ln n)$ | $1.48\times10^{7}$ | 可行，且顺便给出每个 $f(i)$ |
| (d) **主式 $O(n)$**（定理 1） | $n$ 次除法 | $1.0\times10^{6}$ | **最优简单解，$\approx0.01$ 秒量级** |
| (e) (d)+分块（引理 3） | $2\lceil\sqrt n\rceil=2000$ 块 × 2 除法 | $\approx4\times10^{3}$ | 比 (d) 再快 $\approx250$ 倍 |
| (f) 双曲线恒等式（引理 4） | $t=\lfloor\sqrt n\rfloor=1000$ 次除法 | $\approx10^{3}$ | 与 (e) 同级、代码更短 |
| (g) 线性筛 $d(\cdot)$（积性） | $\le3n$ | $3\times10^{6}$ | 比 (d) 慢 3 倍，只在要单个 $f(i)$ 时有价值 |

**诚实的定位**：本题 $n\le10^6$，(d) 的 $10^6$ 次除法已远低于时限，**分块不是必需的**；它是标签"整除分块"指向的下一步，只有当 $n$ 大到 $10^{10}\sim10^{12}$（(d) 的 $n$ 次除法不可行）时才有实质意义。本文把 (e)(f) 都实现出来做互验（§5 `calc2`/`calc3`），三者结果必须逐位相同。

### 2.5 另一条 $O(\sqrt n)$ 路：双曲线对称化（引理 4）

把答案看成第一象限整点数：$S(n)=|\mathcal B|=|\{(d,k):d\ge1,k\ge1,dk\le n\}|$（§2.2 的双射）。设 $t=\lfloor\sqrt n\rfloor$，把 $\mathcal B$ 按"$d\le t$"与"$k\le t$"两块来看。

**引理 4（双曲线恒等式）** $S(n)=2\sum\limits_{d=1}^{t}\left\lfloor\dfrac nd\right\rfloor-t^{2}$，其中 $t=\lfloor\sqrt n\rfloor$。

**证明** 记 $A=\{(d,k)\in\mathcal B:d\le t\}$、$C=\{(d,k)\in\mathcal B:k\le t\}$，由对称交换 $\rho(d,k)=(k,d)$ 知 $|A|=|C|$。
- $|A|=\sum_{d=1}^{t}\lfloor n/d\rfloor$：固定 $d\le t$，$k$ 可取 $1..n/d$ 的整数共 $\lfloor n/d\rfloor$ 个（同 §2.2 的 fiber 论证），对 $d$ 求和（$A$ 按其第一坐标划分）。
- $\rho$ 是 $\mathcal B$ 上的双射（$\rho$ 自逆：$\rho(\rho(d,k))=(d,k)$；封闭性由 $dk\le n\iff kd\le n$ 给出），故 $|\mathcal B|=|A\cup C|=|A|+|C|-|A\cap C|=2|A|-|A\cap C|$（容斥，用到 $A\cup C=\mathcal B$）：任取 $(d,k)\in\mathcal B$，若 $d\le t$ 则在 $A$；若 $d>t$，由 $dk\le n$ 得 $k\le n/d$。而 $t=\lfloor\sqrt n\rfloor\Rightarrow t\le\sqrt n<t+1\Rightarrow n<(t+1)^2$；又 $d,k$ 是整数、$d>t$ 给 $d\ge t+1$，故 $k\le n/d\le n/(t+1)<t+1$，$k$ 为整数故 $k\le t$，即在 $C$。（这里**不能**把 $n/d$ 放大成 $n/t$：$d>t$ 只给 $d\ge t+1$，用 $n/t$ 会放进虚假的点——$n=12,t=3$ 时 $n/t=4$ 允许 $k=4$，而 $(d,k)=(3,4)$ 已在 $A$ 里、$(4,4)$ 因 $16>12$ 根本不在 $\mathcal B$。）
- $A\cap C=\{(d,k):1\le d\le t,\ 1\le k\le t,\ dk\le n\}$。而对一切 $d,k\le t$ 有 $dk\le t^2\le n$（因 $t\le\sqrt n\Rightarrow t^2\le n$），故 $dk\le n$ 这个约束**自动成立**，$A\cap C=[1,t]\times[1,t]$，元素数 $t^2$。
合并即得。$\blacksquare$

**自检 $n=12$**：$t=3$，$\sum_{d\le3}\lfloor12/d\rfloor=12+6+4=22$，$2\times22-9=35$，与按定义枚举（§4.3(0)）一致 ✓。$n=1$：$t=1$，$2\times1-1=1$ ✓。

### 2.6 若走"筛 $f$"路线：$d(\cdot)$ 的积性（引理 5，仅作说明）

**引理 5** 记 $d(m)=f(m)$。则 $d(p^{a})=a+1$；$\gcd(u,v)=1\Rightarrow d(uv)=d(u)d(v)$。

**证明** 第一式：$p^{a}$ 的约数必是 $p^{j}$ 形（若 $s\mid p^{a}$，$s$ 的任一素因子都整除 $p^{a}$、故只能是 $p$，所以 $s=p^{j}$，$0\le j\le a$），$j=0..a$ 共 $a+1$ 个，且互不相同。第二式：映射 $s\mapsto(\gcd(s,u),\gcd(s,v))$ 把 $uv$ 的约数集映到 $u$ 的约数集 $\times v$ 的约数集。良定义与双射：设 $s\mid uv$，令 $s_1=\gcd(s,u),s_2=\gcd(s,v)$，$\gcd(u,v)=1$ 故 $\gcd(s_1,s_2)=1$ 且 $s_1s_2\mid s$；再证 $s=s_1s_2$：逐素数比较指数，对素数 $q$，$v_q(s)\le v_q(uv)=v_q(u)+v_q(v)$，若 $q\mid u$ 则 $v_q(s)\le v_q(u)=v_q(s_1)$ 且 $v_q(s_2)=0$（$\gcd(u,v)=1$），若 $q\mid v$ 对称，若 $q\nmid uv$ 三者皆 $0$——总之 $v_q(s)=v_q(s_1)+v_q(s_2)$。反向：任取 $s_1\mid u,s_2\mid v$，$\gcd(s_1,s_2)=1$（$s_1,s_2$ 的素因子分别来自互素的 $u,v$）且 $s_1s_2\mid uv$，其 $\gcd$ 与 $u,v$ 分别还原为 $s_1,s_2$（若 $v_q(u)>0$ 则 $v_q(s_1)=v_q(s)$，另一侧 $v_q$ 为 $0$）。故双射，两边取元素数得 $d(uv)=d(u)d(v)$。$\blacksquare$

有了引理 5 就能线性筛 $d(\cdot)$（路线 (g)），但见 §2.4 的账：本题只要总和，**这条路比 (d) 慢且要多存两个数组**，故不进主代码。

### 2.7 溢出预算（决定 `int`/`i64`）

先给**双侧严格不等式**（只用 $\lfloor x\rfloor\le x$、$\lfloor x\rfloor>x-1$ 与调和数和积分的关系，不依赖任何渐近结论）：

上界：$1/x$ 在 $[d-1,d]$ 上 $\ge1/d$，故 $\sum_{d=2}^{n}\frac1d\le\sum_{d=2}^{n}\int_{d-1}^{d}x^{-1}dx=\ln n$，于是
$$S(n)=\sum_{d=1}^{n}\left\lfloor\frac nd\right\rfloor\le\sum_{d=1}^{n}\frac nd=n+n\sum_{d=2}^{n}\frac1d\le n\left(1+\ln n\right).$$
下界：$\lfloor x\rfloor>x-1$（下取整的定义 $x-1<\lfloor x\rfloor\le x$）给 $S(n)>\sum_{d=1}^{n}\left(\frac nd-1\right)=n\sum_{d=1}^{n}\frac1d-n$；又在 $[d,d+1]$ 上 $1/x\le1/d$，故 $\frac1d\ge\int_d^{d+1}x^{-1}dx$，对 $d=1..n$ 求和得 $\sum_{d=1}^{n}\frac1d\ge\ln(n+1)$。合起来
$$n\ln(n+1)-n<S(n)\le n(1+\ln n).$$
代入 $n=10^{6}$（$\ln(10^{6}+1)$ 与 $\ln10^{6}$ 差 $10^{-6}$ 量级，可视为 $13.8155$）：
$$1.28\times10^{7}<S(10^{6})\le1.48\times10^{7},$$
**两头都在八位数量级**，这就是"`S(n)$ 量级 $\approx n\ln n$"的显式含义（区间长度 $2\times10^{6}$，足够用于溢出判定）。

渐近式（仅用于给量级感，本文不证误差项）：$S(n)=n\ln n+(2\gamma-1)n+\Delta(n)$，$\gamma=0.5772\ldots$，$\Delta$ 是除数问题误差项。小算例验证它的量级：$n=12$ 时预测 $12\ln12+(2\gamma-1)\cdot12=12\times2.48491+1.85318=29.819+1.853=31.67$，真值 $35$（§4.3(0)），误差 $+3.3<2\sqrt{12}=6.9$；$n=20$ 预测 $20\times2.99573+3.089=59.91+3.09=63.0$，真值 $66$，误差 $+3.0<2\sqrt{20}=8.9$ ✓ 与 $O(\sqrt n)$ 相符。

**显式数值**（$n=10^{6}$，$\ln 10^{6}=6\ln10=6\times2.3025850930=13.815510558$）：

| 量 | 算式 | 数值 | 结论 |
|---|---|---|---|
| 单项 $\lfloor n/d\rfloor$ | $\le n$ | $1.0\times10^{6}$ | `int` 够 |
| 上界 $n(1+\ln n)$ | $10^{6}\times14.8155$ | $1.48\times10^{7}$ | 仅为 `int` 上限 $2.147483647\times10^{9}$ 的 $1/145$ |
| 渐近估计 $n\ln n+(2\gamma-1)n$ | $13\,815\,511+154\,431$ | $\approx1.40\times10^{7}$ | 同上，答案**是八位数**（$\approx1.4$ 千万量级） |
| 分块单块 $(r-l+1)q$ | 见下 | $\le n=10^{6}$ | `int` 够，但乘法仍写成 `(i64)` 以便 $n$ 放大 |
| `calc3` 中间量 $2\sum_{d\le t}\lfloor n/d\rfloor$ | $\le2n(1+\ln t)=2\times10^{6}\times(1+6.9078)$ | $\approx1.58\times10^{7}$ | `int` 够 |
| 若约束被抬到 $n=10^{12}$ | $n(1+\ln n)=10^{12}\times28.63$ | $2.86\times10^{13}$ | **必须 `i64`**（$<9.22\times10^{18}$） |

分块单块界证明：首块（$l=1$，$q=n$，$r=1$）项值恰为 $1\times n=n$。其余块 $l=\lfloor n/(q+1)\rfloor+1$、$r=\lfloor n/q\rfloor$，故 $r-l+1\le\frac nq-\left(\frac n{q+1}-1\right)=\frac n{q(q+1)}+1$（用 $r\le n/q$ 与 $l>n/(q+1)$），两边乘 $q$ 得 $(r-l+1)q\le\frac n{q+1}+q$。而当 $q\le n-1$ 时 $n\ge q+1\Rightarrow\frac n{q+1}\ge1\Rightarrow n-\frac n{q+1}=\frac{nq}{q+1}\ge q$，即 $\frac n{q+1}+q\le n$，故每块项 $\le n=10^{6}$。总之**任何一块的项都不超过 $n$**，`int` 绰绰有余；代码仍显式写 `(i64)(r-l+1)*q`，是因为 $n$ 放大后 $(r-l+1)$ 与 $q$ 各自都能到 $10^{9}$ 量级，先乘会炸。

**结论**：本题给定的 $n\le10^{6}$ 档，`int` 就够（约 $145$ 倍余量）；但 $n(1+\ln n)>2^{31}-1$ 的临界点在 $n\approx1.1\times10^{8}$（试 $n=1.1\times10^{8}$：$\ln n=18.516$，$n(1+\ln n)=2.15\times10^{9}$ 已越界），也就是说"约束被抄大一档就翻车"。累加量恰好是答案本身，**改成 `i64` 的代价是 0**（瓶颈是除法不是宽度），所以本文主代码全程 `i64` 累加、并在 §5 注明"这里 int 也够、但选 i64 的理由"。取整方向：$n,d$ 均正整数，C++ 的 `/` 向零取整，正数情形与 $\lfloor n/d\rfloor$ 完全一致；$d\in[1,n]$ 保证除数非零。

## 3. 模式总结（Pattern Summary）

- **explore its property / 先算账** — 定义暴力是 $\Theta(n^2)$（扫到 $m$）或 $\Theta(n^{3/2})$（扫到 $\sqrt m$）：$1.25\times10^{7}$ 能拿 20 分，$6.7\times10^{8}$ 在满分档过不了。
- **换计数对象（双计数 / 换序）** — 定理 1：$\sum_{i\le n}f(i)=\sum_{d\le n}\lfloor n/d\rfloor$，靠"因子对集合 $\mathcal A$ 按 $m$ 分组 = 按 $d$ 分组"，左边要算 $n$ 个 $f$，右边只要 $n$ 次除法。
- **同一证明的代码化（倍数标记）** — 引理 2：`for d: for m+=d: ++f[m]` 恰好访问 $\mathcal A$ 的每个元素一次，$n\ln n$ 次自增，换来每个 $f(i)$ 的显式值。
- **classic problem solution（整除分块）** — 引理 3：$\lfloor n/d\rfloor$ 只有 $\le2\lceil\sqrt n\rceil$ 个不同值，同值段合并成 $(r-l+1)q$，$10^{6}\to2\times10^{3}$。
- **对称化（双曲线恒等式）** — 引理 4：$S(n)=2\sum_{d\le\sqrt n}\lfloor n/d\rfloor-\lfloor\sqrt n\rfloor^{2}$，$10^{3}$ 次除法，比 $O(n)$ 更短、比 `sqrt` 浮点更稳（本文用 `t=(int)sqrt(n)` 后加两条整数校正）。
- **reduce to easier problem** — "求 $n$ 个约数个数"塌缩成"数一个二维整点区域"，问题从函数值层面转到计数层面。
- **classic problem solution（积性函数线性筛，备用路线）** — 引理 5：$d(p^{a})=a+1$、$\gcd(u,v)=1\Rightarrow d(uv)=d(u)d(v)$（按素因子指数逐位比较建立双射）；能 $O(n)$ 求出**每个** $f(i)$，但只求总和时比 (d) 慢、还要多开数组，本题弃用。
- **overflow guard** — $S(10^{6})\le1.48\times10^{7}$（`int` 余量 $\approx145$ 倍，临界 $n\approx1.1\times10^{8}$）；$n=10^{12}$ 时需 $2.86\times10^{13}$ → 必须 `i64`。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `n` | 题面上界 | `int`，输入，$1\le n\le10^{6}$ | 唯一输入 |
| `d` | 枚举的**约数值**（不是被除的数） | `int`，$1..n$ | 定理 1 的求和指标 |
| `q` | 当前块共用的值 $q=\lfloor n/l\rfloor$ | `int` | 引理 3 |
| `l`,`r` | 分块的块端点（闭区间） | `int`，`l=1` 起，`r=n/q`，`l=r+1` 推进 | 引理 3 |
| `t` | $\lfloor\sqrt n\rfloor$（双曲线法的正方形边长） | `int`，`sqrt` 初值 + 整数校正 | 引理 4 |
| `res` | 各 `calc*` 的累加结果 $S(n)$ | `i64`，$=0$ 起 | 答案（`int` 也够，见 §2.7） |
| `ans` | 主答案 `=calc()` | `i64`，全局 | 输出量 |

**下标约定**：本解法**全程 1-based**（$d,m$ 都是正整数上的数论变量，$\lfloor n/d\rfloor$ 与约数天然 1-based）。全文（`calc`/`calc2`/`calc3`/`brute`/验证表）均按此约定，无 0-based 转换点。

### 4.2 算法步骤

1. 读 `n`；`assert(1<=n&&n<=1000000)` 文档化输入合法性。
2. `calc()`：`for(d=1;d<=n;++d) res+=n/d;`——定理 1 的右端，$O(n)$，$10^{6}$ 次除法。
3. `calc2()`：整除分块（引理 3）：`q=n/l; r=n/q; res+=(r-l+1)*q; l=r+1;`，$\le2\lceil\sqrt n\rceil=2000$ 块。
4. `calc3()`：双曲线恒等式（引理 4）：整数校正出 $t=\lfloor\sqrt n\rfloor$，`res=2*sum_{d<=t} n/d - t*t`，$1000$ 次除法。
5. `brute()`：按定义数约数（$d\le\sqrt m$ 成对计数，$d^{2}=m$ 时只记 1 个），只作互验、$n\le2000$ 时才调用。
6. `assert` 三条互验：`ans==calc2()`、`ans==calc3()`，小 $n$ 再加 `ans==brute()`。
7. 输出 `ans`。

**复杂度算式**

- 时间：`calc` $n=10^{6}$ 次除法 + $10^{6}$ 次加法；`calc2` $\le2000$ 块、每块 2 次除法，$\approx4\times10^{3}$；`calc3` $t+2\le1002$ 次除法 + 2 次乘法；`brute`（若跑，$n\le2000$）$\le\frac23 n^{3/2}+\sqrt n\approx6.0\times10^{4}$ 次取模/比较。总计 $\approx1.0\times10^{6}$ 次除法 + 少量乘法，按 $10^{8}$/秒的常识量级换算 $\approx0.01$ 秒（**该数字是操作数量的换算，不是实测**，本环境禁止运行）。
- 空间：只用标量，$O(1)$（无任何数组，故也不存在"全局 `int` 数组默认 0 被当成可达状态"的移植坑）。

## 5. 示例代码（C++）

```cpp
// P1403 [AHOI2005] 约数研究
// sum_{i<=n} f(i) = sum_{d=1}^{n} floor(n/d)   (双计数换序)
// https://www.luogu.com.cn/problem/P1403
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int n;
i64 ans;

i64 calc()                     // 主解：换序后的 O(n) 除法累加
{
	i64 res=0;
	for(int d=1;d<=n;++d)
		res+=n/d;                // d 管着 floor(n/d) 个被它整除的数
	return res;
}

i64 calc2()                    // 整除分块版，与 calc 同值（互验用）
{
	i64 res=0;
	for(int l=1,r,q;l<=n;l=r+1)
	{
		q=n/l;r=n/q;             // [l,r] 上 floor(n/d) 恒等于 q
		res+=(i64)(r-l+1)*q;
	}
	return res;
}

i64 calc3()                    // 双曲线对称化：2*sum_{d<=t} floor(n/d) - t^2
{
	int t=(int)sqrt(n);          // 浮点初值，下面两条纯整数校正
	while((i64)(t+1)*(t+1)<=n)
		++t;
	while((i64)t*t>n)
		--t;
	i64 res=0;
	for(int d=1;d<=t;++d)
		res+=n/d;
	return res*2-(i64)t*t;       // 重叠块恰是 [1,t]x[1,t]，因 t^2<=n
}

i64 brute()                    // 按定义数约数，只给小 n 互验（O(n^1.5)）
{
	i64 res=0;
	for(int m=1;m<=n;++m)
		for(int d=1;(i64)d*d<=m;++d)
			if(m%d==0)
				res+=((i64)d*d==m)?1:2;   // d 与 m/d 成对，平方根只记一次
	return res;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	assert(1<=n&&n<=1000000);
	ans=calc();
	assert(ans==calc2());        // 分块与朴素必须逐位相同
	assert(ans==calc3());        // 双曲线式必须同值
	if(n<=2000)                  // 满分档别跑暴力，它要 6.7e8 次
		assert(ans==brute());
	// cerr<<ans<<' '<<calc2()<<' '<<calc3()<<'\n';
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`int` 够但用 `i64`**：§2.7 的预算显示 $S(10^{6})\le1.48\times10^{7}$（`int` 余量 $\approx145$ 倍，临界 $n\approx1.1\times10^{8}$），故本题**用 `int` 累加也不会错**；但答案与累加量同宽、换成 `i64` 的代价为 0（瓶颈是除法不是宽度），所以 `res/ans` 一律 `i64`，并把所有乘法显式提升：`(i64)(r-l+1)*q`（两个 `int` 因子，$n$ 放大后各自可到 $10^{9}$，先乘必炸）、`res*2-(i64)t*t`、`(i64)d*d`。
- **`calc3` 的 $t$ 校正**：`(int)sqrt(n)` 截断，且浮点可能少 1 或多 1；两条 `while` 用整数乘方把它夹回满足 $t\le\sqrt n<t+1$ 的唯一整数（引理 4 的前提，否则 $A\cap C$ 不再是整个 $[1,t]^{2}$、$t^{2}$ 减错）。校正后 $n=1$ 给 $t=1$（不进入任何 `while`：$4\le1$ 假、$1>1$ 假）✓。
- **`brute` 的判界与配对**：`for(int d=1;(i64)d*d<=m;++d)` 用乘法判界而不是 `d<=sqrt(m)`，避开浮点；`((i64)d*d==m)?1:2` 在平方数上只记 1 个（$m=4,9,16$ 给 $3,3,5$ ✓，§4.3(7) 逐轮跟踪）。
- **`calc2` 的推进**：`l=r+1` 与 $r=\lfloor n/q\rfloor$ 保证块不重不漏（引理 3 (i)(ii)）；$l=n$ 时 $q=1,r=n$ 必然收尾，循环不会死转（每轮 $r\ge l$，故 $l$ 严格递增）。
- **`assert` 作为文档化不变量**（规范 §13）：三条互验路径在本地开启、`NDEBUG` 下零开销；`brute()` 只在 $n\le2000$ 时参与，防止互验本身超时。
- 1-based 全程一致（§4.1），`'\n'`、Tab 缩进、运算符无空格、小写电报式函数名 `calc/calc2/calc3/brute`、`cin.tie/cout.tie/ios::sync_with_stdio` 顺序均按规范；本解法**无数组状态**，故不需要 `fill_n` 预置 INF。
