# P1899 魔法物品

## 1. 重新读题

### 1.1 问题重述（人话版）

你拥有 $N$ 件物品，初始有 $0$ 元钱。

- **普通物品**：只有一个价值 $P$，任何时候卖掉都能得到 $P$ 元。
- **魔法物品**：未鉴定时价值 $P_1$，鉴定后价值 $P_2$（$P_1<P_2$）。

鉴定一件魔法物品需要先花 $P_i$ 元买一个鉴定卷轴（卷轴用掉即消失）。只要此刻手里的现金 $\ge P_i$，就能买卷轴；买完立刻鉴定，然后可以按 $P_2$ 卖掉这件物品。也可以不鉴定，直接按 $P_1$ 卖掉。

最终必须把所有物品卖完，求结束时最多能有多少钱。

### 1.2 关键约束与规模暗示

- $N\le 1000$，普通物品 $P\le 10000$，魔法物品 $P_1<P_2\le 10000$。
- **卷轴价格 $P_i\le 5000$**，这是一个非常强的暗示：卷轴价格很小，很可能要拿它当 DP 的「容量」。如果 $P_i$ 能到 $10^9$，做法会完全不同。
- 总价值最多 $1000\times 10000=10^7$，答案在 `long long` 范围内绰绰有余（其实 `int` 也许够，但用 `long long` 稳）。
- 30% 数据 $N\le 50$ 提示存在指数/暴力做法；正解应当与 $N$ 成多项式、并且只依赖 $P_i$ 的小范围。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先做无脑的简化

普通物品没有任何选择：卖掉就得到 $P$，而且越早卖越好（钱只会帮助买卷轴，不会有害）。所以可以认为一开始就把所有普通物品卖掉，记初始现金

$$
O=\sum_{\text{普通物品}}P.
$$

魔法物品只有两种命运：原价卖 $P_1$，或者花 $P_i$ 鉴定后卖 $P_2$。

### 2.2 第一次尝试（错误）：把所有魔法物品先原价卖掉，再「买回来」鉴定

一个很自然但**错误**的模型是：既然鉴定后更值钱，那就先把所有魔法物品按 $P_1$ 卖掉凑钱，凑够卷轴钱后再把要鉴定的物品「买回来」鉴定。

我们用一个极小的反例戳破它：$P_i=10$，两件魔法物品都是 $(P_1,P_2)=(10,100)$。

- 错误模型：两件原价卖得 $20$，足够买卷轴；于是认为可以鉴定两件，得到 $20+2\times(100-10-10)=180$。
- 现实：你**只有卖掉的 20 元，两件物品都已经不在了**；你没有地方把物品买回来。真正能做的至多是：先卖一件得 $10$，花 $10$ 买卷轴，鉴定另一件卖 $100$，最终 $100$（或者卖第二件得 $10$、鉴定第一件，同样 $100$）。若直接两件都原价卖，只有 $20$。

错误的根源：**已经卖掉的物品不能为「它自己或别人」提供鉴定资格后再被鉴定**。用某件物品的 $P_1$ 去凑卷轴钱，就等于放弃了它的鉴定收益。这个「二选一」是本题的核心张力。

### 2.3 第二次尝试（也错误）：按某种顺序贪心

既然不能预支，另一种想法是：按 $P_1$ 从小到大（越便宜越容易留下）排序，依次处理，能鉴定就鉴定，否则原价卖。

反例：$P_i=10$，两件魔法物品

- $A=(P_1,P_2)=(12,100)$，差价 $\Delta_A=100-10-12=78$；
- $B=(P_1,P_2)=(6,100)$，差价 $\Delta_B=100-10-6=84$。

按 $P_1$ 升序会先处理 $B$：手里 $0<10$，只能把 $B$ 原价卖掉，得 $6$；再处理 $A$：手里 $6<10$，只能把 $A$ 原价卖掉，得 $12$，最终 $18$。

但最优策略是：先卖掉 **$A$**（它原价更高，得 $12$），手里有 $12\ge10$，买卷轴鉴定 **$B$** 并卖 $100$，最终 $12-10+100=102$。

也就是说：**为了凑出第一次鉴定的本钱，有时必须牺牲一件「更值钱、但鉴定收益较小」的物品**。不能简单地按 $P_1$ 排序后贪心。

### 2.4 关键观察：只需凑够「第一次」鉴定

仔细看上面的最优解，钱一旦够买第一个卷轴，后面就顺了。为什么？

对每件魔法物品定义

$$
\Delta_j=P_{2,j}-P_{i}-P_{1,j}.
$$

$\Delta_j$ 是「鉴定它」相对「原价卖它」的净收益。记一个策略中实际鉴定的魔法物品集合为 $S$。

**引理 1（只有 $\Delta_j>0$ 的物品值得鉴定）.** 若某件魔法物品 $\Delta_j\le 0$，则把它改为原价卖出不会使任何时刻的现金减少，也不会降低最终收益。

**证明.** 设原策略第一次涉及该物品时选择了鉴定。鉴定它的现金变化是 $-P_i+P_{2,j}$；原价卖出的变化是 $+P_{1,j}$。两者之差为

$$
P_{1,j}-(P_{2,j}-P_i)=-\Delta_j\ge 0.
$$

改为原价卖出后，该时刻及以后手里的现金只增不减，因此后续所有购买卷轴的条件仍然满足，最终收益不减。若该物品在策略中本来就没被鉴定，则无需改动。反复操作可得到所有被鉴定物品都满足 $\Delta_j>0$ 的策略。$\blacksquare$

所以只需考虑

$$
B=\{j:\Delta_j>0\}.
$$

**引理 2（第一次鉴定的资金条件）.** 设非空的鉴定集合为 $S\subseteq B$，并令

$$
F=O+\sum_{j\notin S}P_{1,j}
$$

为「把所有不鉴定的魔法物品都原价卖掉」后手里的钱。则：

1. 若 $F\ge P_i$，则 $S$ 中所有物品都能依次鉴定成功；
2. 若 $F<P_i$，则一件都无法鉴定。

**证明.**

1. 第一次鉴定：手里至少 $F\ge P_i$，可以买卷轴；鉴定并卖掉后，现金变为

$$
F-P_i+P_{2,j}=F+(P_{2,j}-P_i).
$$

由 $\Delta_j>0$ 得 $P_{2,j}-P_i=P_{1,j}+\Delta_j>0$，故现金严格增加，仍有 $\ge P_i$。以后每鉴定一件都同理，现金只增不减。因此全部可以完成。
2. 若 $F<P_i$：在任何鉴定发生之前，手里的钱最多就是 $F$（原价卖不鉴定物品所得；鉴定任何一件都需要先有 $P_i$，而第一件还没鉴定）。所以连第一件都买不起卷轴。$\blacksquare$

引理 2 把动态的「什么时候卖什么」压缩成了一个静态条件：**初始可用于鉴定的资金 $F$ 是否至少为 $P_i$**。

### 2.5 把选择写成「牺牲哪些物品」

设所有魔法物品原价卖掉的收益为

$$
\text{base}=O+\sum_{\text{魔法 }j}P_{1,j}.
$$

如果选择鉴定 $S$，最终收益为

$$
\text{base}+\sum_{j\in S}\Delta_j. \tag{1}
$$

令 $R=B\setminus S$ 为**被牺牲**（本可鉴定却选择原价卖掉）的性价比物品。由引理 2，$S\ne\varnothing$ 时需要的资金条件可以写成

$$
F=O+\underbrace{\sum_{j\notin B}P_{1,j}}_{A_{\text{nb}}}+\sum_{j\in R}P_{1,j}\ \ge\ P_i,
$$

即

$$
\sum_{j\in R}P_{1,j}\ \ge\ D:=P_i-O-A_{\text{nb}}. \tag{2}
$$

于是问题彻底变成一个**选择问题**：

> 从 $B$ 中选出一些物品作为牺牲品 $R$，使 $\sum_{R}P_{1,j}\ge D$，并让损失 $\sum_{R}\Delta_j$ 最小。

若 $D\le 0$，说明光靠普通物品和非性价比魔法物品的原价收入就够买第一个卷轴，无需牺牲任何 $B$ 中物品。若 $D>0$，则需要牺牲。

**引理 3（牺牲模型的正确性）.** 对任意 $R\subseteq B$ 满足 (2)，令 $S=B\setminus R$，按「卖掉 $R$ 与所有非 $B$ 魔法物品、鉴定 $S$」执行，是一个合法策略，最终收益为 $\text{base}+\sum_{B}\Delta_j-\sum_{R}\Delta_j$。反之，任何合法策略都对应某个满足 (2) 的 $R$（若其鉴定集合非空），且收益有同样形式。

**证明.** 正向：$R$ 与 $j\notin B$ 的原价收入加上 $O$ 恰为 $F\ge P_i$，由引理 2 可以完成 $S$ 的全部鉴定，收益由 (1) 得到。

反向：对任意合法策略，令 $S$ 为其实际鉴定的物品集合、$R=B\setminus S$。若 $S\ne\varnothing$，第一次鉴定之前不可能已经卖出 $S$ 中的任何物品（卖了就不能鉴定），所以当时现金最多为 $O+A_{\text{nb}}+\sum_{R}P_{1,j}=F$。既然第一件鉴定成功，必有 $F\ge P_i$，即 (2)。收益同样是 $\text{base}+\sum_S\Delta_j$。$\blacksquare$

### 2.6 背包：最小损失凑出 $D$

现在要解决：

$$
\min_{R\subseteq B}\ \sum_{j\in R}\Delta_j
\quad\text{s.t.}\quad \sum_{j\in R}P_{1,j}\ge D.
$$

这是典型的 0/1 背包（重量 $P_{1,j}$，价值 $\Delta_j$，要求重量**至少** $D$，最小化价值和）。容量上界只需到 $D$，而

$$
0\le D=P_i-O-A_{\text{nb}}\le P_i\le 5000,
$$

**这就是题目给 $P_i\le 5000$ 的真正用途**：状态数只有 $O(P_i)$，总复杂度 $O(NP_i)=5\times 10^6$。

具体地，令

$$
dp[s]=\text{已选牺牲品总重量（截断到 }D\text{）恰为 }s\text{ 时的最小损失}.
$$

初值 `dp[0]=0`，其余为无穷大。对每件 $j\in B$，按 $s$ 从 $D$ 到 $0$ 倒序转移：

$$
dp[\min(D,s+P_{1,j})]=\min\bigl(dp[\min(D,s+P_{1,j})],\ dp[s]+\Delta_j\bigr).
$$

**引理 4（截断背包的正确性）.** 上述 DP 结束后，$dp[D]$ 等于所有满足 $\sum_R P_{1,j}\ge D$ 的 $R$ 的 $\sum_R\Delta_j$ 最小值（若不存在这样的 $R$，则 $dp[D]$ 仍为无穷大）。

**证明.** 对处理的物品个数归纳。关键是把重量替换为 $\min(D,\cdot)$：两个集合若真实重量都 $\ge D$，它们的截断重量都等于 $D$，而目标只关心「是否达到 $D$」。对未达到 $D$ 的集合，截断值等于真实重量。因此「截断后重量为 $s$ 且 $s<D$」与「真实重量为 $s$」一一对应，「截断后重量为 $D$」与「真实重量 $\ge D$」对应。标准的 0/1 背包归纳表明 `dp[s]` 是前若干个物品中截断重量恰为 $s$ 的最小损失；倒序枚举保证每件物品至多用一次。于是 $dp[D]$ 正是所求最小值。$\blacksquare$

最终答案：

- 若 $D\le 0$：`ans = base + Σ_{B}Δ_j`；
- 否则若 $dp[D]$ 可达：`ans = base + Σ_B Δ_j - dp[D]`；
- 否则：一件也鉴定不了，`ans = base`。

> 为什么「否则」是 base？因为 $dp[D]$ 不可达意味着即使牺牲全部 $B$ 也凑不齐 $D$，由引理 2 任何非空鉴定集合都不可行，只能全部原价卖。
>
> 顺带一提，若唯一「可达」的 $R$ 就是 $B$ 本身，公式给出 `base + Σ_BΔ - Σ_BΔ = base`，与「全部原价卖」一致，自动正确。

### 2.7 失败尝试总结

1. **把「原价卖 + 买回鉴定」当成可行**：反例 $P_i=10$、两件 $(10,100)$，会算出 $180$，真实答案 $100$。
2. **按 $P_1$ 升序贪心「能鉴定就鉴定」**：反例 $A=(12,100)$、$B=(6,100)$，贪心得 $18$，最优 $102$。
3. **按 $P_2-P_1$ 或 $\Delta$ 排序贪心**：本题的选择是「为凑够第一次卷轴而牺牲谁」，是一个带下界约束的最小损失子集问题，没有简单的排序贪心；必须背包。
4. **对 $\Delta\le 0$ 的物品也考虑鉴定**：只会降低收益（引理 1），若把它们塞进背包反而可能选错。
5. **背包容量开到总价值 $10^7$**：$N\times10^7=10^{10}$ 超时；容量只需 $D\le P_i\le 5000$。
6. **忘记「$S=\varnothing$ 时无需凑钱」**：如果 $D>0$ 且不可达，答案应为 base，而不是无解或 0。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 普通物品可视为初始现金；魔法物品是「原价卖 $P_1$」或「花 $P_i$ 换 $P_2$」的二选一。
- **find a counterexample** — 「先卖再买回」和「按 $P_1$ 贪心」都被同一类反例击破：卖掉的物品不能再用作鉴定对象。
- **reduce to easier problem** — 只需凑够第一次卷轴费用，之后现金严格递增，后续鉴定自动可行。
- **reduce to a subset selection** — 将「鉴定集合」等价改写为「牺牲集合 $R$」，条件是 $\sum_R P_1\ge D$。
- **classic problem solution** — 0/1 背包：重量 $P_1$、价值 $\Delta$、下界 $D$，容量截断到 $D\le P_i\le 5000$。
- **careful with types & input** — 每行可能只有一个或两个整数，需按行解析；答案用 `long long`。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 物品数 | 读入 | |
| `cst` | `int` | 卷轴价格 $P_i$ | 读入 | cost |
| `ord` | `i64` | 普通物品价值总和 $O$ | 逐行累加 | ordinary |
| `all1` | `i64` | 所有魔法物品的 $P_1$ 之和 | 逐行累加 | all $P_1$ |
| `dead1` | `i64` | $\Delta\le0$ 的魔法物品的 $P_1$ 之和 $A_{\text{nb}}$ | 逐行累加 | dead $P_1$ |
| `extra` | `i64` | 所有 $\Delta>0$ 物品的 $\Delta$ 之和 $\sum_B\Delta$ | 逐行累加 | extra |
| `a[]` | `item [1005]` | 仅存 $\Delta>0$ 的物品：`{p1,delta}` | 读入时筛选 | beneficial items |
| `cnt` | `int` | $|B|$ | $0$ | |
| `base` | `i64` | `ord+all1`，全部原价卖的收益 | 计算 | |
| `need` | `i64` | $D=cst-ord-dead1$ | 计算 | deficit |
| `dp[s]` | `i64 [5005]` | 牺牲总重截断到 $s$ 的最小损失 | `dp[0]=0`，其余 `inf` | knapsack |
| `ans` | `i64` | 最终最大收益 | `base` | |

### 4.2 算法步骤

1. 读入 $n$ 与卷轴价 `cst`。
2. 逐行读入物品（`getline` 后按空格拆分，因为普通物品一行一个数、魔法物品一行两个数）：
   - 只有一个数 $P$：`ord += P`；
   - 有两个数 $P_1,P_2$：`all1 += P1`，计算 $\Delta=P_2-\texttt{cst}-P_1$；若 $\Delta>0$，加入 `a[cnt++]={P1,Δ}` 并 `extra+=Δ`；否则 `dead1 += P1`。
3. `base = ord + all1`。
4. `need = cst - ord - dead1`。
   - 若 `need<=0`：`ans = base + extra`（不需要牺牲，全部鉴定）。
   - 否则若 `cnt>0`：初始化 `dp[0]=0`、其余为 `inf`；对每件 `a[i]`，令 `s` 从 `need` 倒序到 $0$，若 `dp[s]` 有限，则 `ns=min(need,s+a[i].p1)`，用 `dp[s]+a[i].delta` 更新 `dp[ns]`。
     - 若 `dp[need]` 有限，`ans = base + extra - dp[need]`；
     - 否则 `ans = base`。
   - 否则（没有可鉴定物品）`ans = base`。
5. 输出 `ans`。

### 4.3 复杂度分析

- **时间**：读入与筛选 $O(N)$；背包 $O(|B|\cdot D)\le O(N\cdot P_i)\le 5\times 10^6$。
- **空间**：$O(N+D)$，`dp` 只有 $5005$ 个 `long long`。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};
constexpr int mxc{5005};
constexpr i64 inf{1145141919810LL};

struct item
{
	i64 p1,delta;
};

int n,cst,cnt;
item a[mxn];
i64 dp[mxc];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>cst;
	i64 ord{0},all1{0},dead1{0},extra{0};
	for(int i=0;i<n;++i)
	{
		string line;
		getline(cin>>ws,line);
		stringstream ss(line);
		int p1,p2{-1};
		ss>>p1;
		if(ss>>p2)
		{
			all1+=p1;
			i64 d=(i64)p2-cst-p1;
			if(d>0)
			{
				a[cnt++]={p1,d};
				extra+=d;
			}
			else
				dead1+=p1;
		}
		else
			ord+=p1;
	}
	i64 base=ord+all1;
	i64 ans=base;
	i64 need=(i64)cst-ord-dead1;
	if(need<=0)
		ans+=extra;
	else if(cnt>0)
	{
		fill_n(dp,mxc,inf);
		dp[0]=0;
		for(int i=0;i<cnt;++i)
			for(int s=(int)need;s>=0;--s)
				if(dp[s]<inf)
				{
					int ns=(int)min(need,s+a[i].p1);
					dp[ns]=min(dp[ns],dp[s]+a[i].delta);
				}
		if(dp[need]<inf)
			ans+=extra-dp[need];
	}
	cout<<ans<<'\n';
	return 0;
}
```
