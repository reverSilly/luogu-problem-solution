# P1807 最长路

> 难度：普及/提高- · 标签：动态规划 DP、图论、拓扑排序

## 1. 重新读题
### 1.1 问题重述（人话版）

有向图 \(n\) 个点、\(m\) 条边，点编号 \(1\) 到 \(n\)。每条边 \(u\to v\) 都满足 \(u<v\)，边权 \(w\) 可正可负可零。求 \(1\) 到 \(n\) 的一条简单路径，使其边权和最大。走不到就输出 \(-1\)。

### 1.2 关键约束与规模暗示

- \(1\le n\le 1500\)，\(0\le m\le 5\times 10^4\)，\(-10^5\le w\le 10^5\)。
- \(u<v\) 是免费的拓扑序：边只会往编号更大的点走，图里不可能有环，也不需要再跑一遍拓扑排序。
- 边权有负数。最长路不能把「没走到」初始化成 0，否则负权路径会被 0 吃掉，也会把根本走不到 \(n\) 的图错答成 0。走不到必须是 \(-\infty\)，最后才换成 \(-1\)。
- 一条路径最多 \(n-1\) 条边，绝对值和 \(<1.5\times 10^8\)，32 位整数够放答案，标程仍用 64 位，哨兵取 \(-10^{18}\)。
- \(n=1\) 时路径是空路径，权值 0，点 1 到达它自己。\(m=0\) 且 \(n>1\) 时输出 \(-1\)。

## 2. 思维链（Chain-of-thought）

**引理 1（编号顺序就是拓扑序）**

按 \(1,2,\ldots,n\) 的顺序处理点，每条边的起点都在终点之前被处理完。图无环。

**证明**：题面保证每条边 \(u\to v\) 有 \(u<v\)。所以不存在从大编号指向小编号的边，也不存在自环。任何环都至少含一条不增大编号的边（沿环走一圈编号不可能严格上升），与「每条边都严格增大编号」矛盾。因此按编号从小到大，处理到 \(u\) 时，所有能走到 \(u\) 的边的起点都已经处理过。\(\square\)

**引理 2（一次向前松弛得到最长路）**

令 \(dp[1]=0\)，其余点先设成 \(-\infty\)。按 \(u=1..n\) 扫描：若 \(dp[u]\) 仍是 \(-\infty\) 就跳过；否则对每条出边 \(u\to v\) 做 \(dp[v]=\max(dp[v],\,dp[u]+w)\)。结束时若 \(dp[n]\) 仍是 \(-\infty\) 输出 \(-1\)，否则输出 \(dp[n]\)。

**证明**：对点编号归纳「处理完 \(u\) 之前，\(dp[u]\) 已经等于 \(1\) 到 \(u\) 的最长路；走不到则保持 \(-\infty\)」。

- \(u=1\)：空路径权 0，没有入边（入边的起点更小，不存在）。成立。
- 考虑点 \(v\)。它的每条入边都来自某个 \(u<v\)。归纳假设：那些 \(u\) 的 \(dp[u]\) 在处理 \(u\) 时已经是最终值。处理 \(u\) 的时候若 \(dp[u]>-\infty\)，出边会用 \(dp[u]+w\) 更新 \(v\)；若 \(dp[u]=-\infty\)，从 1 走不到 \(u\)，这条入边不可能出现在任何 1 到 \(v\) 的路径上，跳过是对的。
- 任何一条 1 到 \(v\) 的路径都有一个最后一条边 \(u\to v\)，前面那段是 1 到 \(u\) 的路径，权值 \(\le dp[u]\)。所以路径权 \(\le dp[u]+w\le dp[v]\)（更新之后）。反过来 \(dp[v]\) 的每一次更新都对应一条真实路径。因此 \(dp[v]\) 既不超过最长路，也能被某一条路径取到。

\(v=n\) 时即所求。\(-\infty\) 表示没有任何更新发生，也就是没有路径，按规定输出 \(-1\)，而不是把负权答案误判成无解。\(\square\)

负权不会让「绕路」变长：无环图里最长路本来就是简单路径，DP 取的是最大而不是最小，负边只在没有更好选择时才会留下。例如 \(1\xrightarrow{-5}2\xrightarrow{-5}3\) 与直边 \(1\xrightarrow{-3}3\) 并存时，答案是 \(-3\) 不是 \(-1\)。

## 3. 模式总结（Pattern Summary）

- **explore its property** — \(u<v\) 把拓扑序直接写成点编号，环不存在。
- **classic problem solution** — DAG 最长路是按拓扑序的一次线性 DP。
- **watch the sentinel** — 不可达必须是 \(-\infty\)，输出前才换成 \(-1\)；\(n=1\) 的空路径权是 0。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| \(n,m\) | `int` | 点数、边数 | 读入 | 内部 0 下标，读入先 `--` |
| `g[u]` | `vector<edge>[1505]` | 出边 `(to,w)` | 空 | 只存原方向 |
| `dp[u]` | `i64[1505]` | 1 到该点的最长路 | `fill_n` 成 \(-10^{18}\)，再 `dp[0]=0` | 0 不是无穷 |
| `ninf` | `i64` | 不可达哨兵 | \(-(i64)1e18\) | 加上边权仍远小于任何真实路径 |

### 4.2 算法步骤

1. 读边，端点改成 0 下标后挂到 `g[u]`。重边全部保留，松弛时自然取最大。
2. `dp` 全部置 `ninf`，`dp[0]=0`。
3. 按编号从小到大松弛出边，源点不可达则跳过。
4. `dp[n-1]` 仍是 `ninf` 就输出 `-1`，否则输出它。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 时间 \(O(n+m)\)，空间 \(O(n+m)\)。
- 编译 warn=0。
- 样例 `2 1 / 1 2 1` 输出 `1`。
- 固定边界 9 组：\(n=1\)、\(m=0\)、全负权、负权与直边竞争、走不到 \(n\)、重边取最大，以及 400 组随机 DAG（\(n\le 8\)，\(m\le 16\)，权值 \([-20,20]\)）。暴力是把所有路径 DFS 枚举（\(u<v\) 保证无环）。共 410 组，随机段 6.563s，全部与标程一致。
- 满数据计时：\(n=1500\)，\(m=5\times 10^4\)，随机前进边与随机权，标程 0.022s，答案 `7999131`。

## 5. 示例代码
### 5.1 标程（`P1807.cpp`）

```cpp
//
// 题目：P1807 最长路
// https://www.luogu.com.cn/problem/P1807
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1505};
constexpr i64 ninf{-(i64)1e18};

struct edge
{
	int to,w;
};

int n,m;
vector<edge> g[mxn];
i64 dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<m;++i)
	{
		int u,v,w;
		cin>>u>>v>>w;
		--u;
		--v;
		g[u].push_back({v,w});
	}
	fill_n(dp,n,ninf);
	dp[0]=0;
	for(int u=0;u<n;++u)
	{
		if(dp[u]==ninf)
			continue;
		for(edge e:g[u])
			dp[e.to]=max(dp[e.to],dp[u]+e.w);
	}
	if(dp[n-1]==ninf)
		cout<<-1<<'\n';
	else
		cout<<dp[n-1]<<'\n';
	return 0;
}
```
