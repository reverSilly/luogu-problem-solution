# P1880 [NOI1995] 石子合并

## 1. 重新读题

### 1.1 问题重述（人话版）

$n$ 堆石子围成一个环，第 $i$ 堆有 $a_i$ 个石子。每次只能把**相邻**的两堆合并成一堆，得分等于新堆的石子数；合并 $n-1$ 次后只剩一堆。求总得分的最小值和最大值。

注意是环：第 $1$ 堆与第 $n$ 堆相邻，"相邻"在只剩两堆时仍然成立。

### 1.2 关键约束与规模暗示

- $1\le n\le 100$，$0\le a_i\le 20$。
- $n=100$ 允许 $O(n^3)$（$10^6$ 量级）甚至 $O(n^4)$，但不允许指数级的合并方案枚举（方案数是指数级的）。
- 区间 DP 的经典规模：$O(n^3)$ 的"枚举最后一次合并"。
- 答案是总和级别：$\sum a_i\le 2000$，每次合并得分 $\le$ 总和，总得分 $\le (n-1)\sum a_i\le 2\times10^5$，`int` 绰绰有余。

## 2. 思维链（Chain-of-thought）

### 2.1 先看合并过程的结构

把每次合并看成一个内部节点，两堆石子看成两个儿子。整个合并过程是一棵二叉树：叶子是原来的 $n$ 堆（沿环的顺序排列），内部节点对应一次合并，它的子树叶子并就是被合并出来的那一堆。

一次合并的得分 = 新堆的石子数 = 该内部节点子树的叶子权值和。把每个内部节点的子树和累加，等价于：**每个叶子 $i$ 的石子数 $a_i$ 被计入的次数 = 它在合并树中的深度**。这里把叶子深度定义为"它到根的边数"，它恰好等于该叶子参与的合并次数：每往上并一层，它的石子数就被加一次。

**引理 1（得分公式）**：对固定的合并树，总得分 $=\sum_{i} a_i\cdot \mathrm{dep}_i$。

**证明**：对合并树的节点归纳。单个叶子内部没有合并，得分 $0=a_i\cdot 0$（把叶子自身深度记为从它到根的距离）。设内部节点 $u$ 的两个儿子是 $L,R$，子树叶子并之和为 $S_u$。合并 $L,R$ 的代价是 $S_u$。递归地，$L$ 内部的总得分为 $\sum_{i\in L}a_i\cdot d_i^{L}$，其中 $d_i^{L}$ 是叶子 $i$ 在 $L$ 子树内的深度（到 $L$ 的距离）。整棵树的总得分 = $S_u+\sum_{i\in L}a_i d_i^L+\sum_{i\in R}a_i d_i^R$。而在整棵树里，叶子 $i\in L$ 的深度 $=d_i^L+1$，因此 $\sum_i a_i\,\mathrm{dep}_i=S_u+\sum_{i\in L}a_i d_i^L+\sum_{i\in R}a_i d_i^R$，与总得分相同。归纳成立。$\square$

这个引理本身不直接给算法，但它告诉我们：问题就是"给环上顺序固定的叶子选一棵二叉树，最小化/最大化带权叶深和"，而且代价可以按区间合并递推——这正是区间 DP 的形状。

### 2.2 先做简化版：把环拉直

**简化版**：石子排成一条**链**，每次合并相邻两堆，求最小/最大得分。

设 $g[l][r]$ 表示把链上区间 $[l,r]$ 合并成一堆的最小得分，$S(l,r)=\sum_{i=l}^{r}a_i$。

**引理 2（链的区间 DP）**：
$$g[l][r]=\min_{l\le k<r}\Bigl(g[l][k]+g[k+1][r]\Bigr)+S(l,r),\qquad g[l][l]=0.$$
最大值把 $\min$ 换成 $\max$ 同样成立。

**证明**：

- 下界方向：任取一个把 $[l,r]$ 合并成一堆的方案。它的最后一次合并把当前的两堆合成一堆，而这两堆各自对应一个连续的叶子区间——因为每次合并只合并相邻的堆，一堆石子永远是原序列的一个连续段。设最后合并的两段是 $[l,k]$ 与 $[k+1,r]$。最后这次合并贡献 $S(l,r)$；两段各自的内部方案分别是从 $[l,k]$、$[k+1,r]$ 出发的合法方案（合并在段内进行，互不影响），所以它们的得分分别 $\ge g[l][k]$、$\ge g[k+1][r]$。于是该方案总得分 $\ge g[l][k]+g[k+1][r]+S(l,r)\ge$ 引理右端。
- 上界方向：任取 $k$，取 $[l,k]$ 的最优方案与 $[k+1,r]$ 的最优方案，先分别合并成两堆，再合并这两堆。整个过程合法，总得分恰为 $g[l][k]+g[k+1][r]+S(l,r)$。所以 $g[l][r]\le$ 右端。

两方向合并得等号。最大值同理（不等式方向全部反过来，取 $\max$）。$\square$

归纳基础 $g[l][l]=0$（一堆不用合并）。按区间长度从小到大计算即可。

### 2.3 把环还原成"若干条链"

**引理 3（环 = 某个断口的链）**：对环形问题的任意一个合并方案，都存在一个"断口"，使得把环从该断口剪开拉直后，这个方案恰好是这条链上的一个合法合并方案，得分不变；反之，任意链方案在环上照做也是合法环方案。

**证明**：

- 环 → 链：考虑方案合并树的根（最后一次合并）。它把整个环分成两段连续的弧 $A$ 与 $B$（$A\cup B$ 是全部 $n$ 堆）。在环上 $A$ 与 $B$ 相邻的位置恰有两个，即两个"断口"。取其中一个断口，把环从这里剪开拉直：于是 $A$、$B$ 都变成链上的连续段。方案中所有除最后一次之外的合成都发生在 $A$ 内部或 $B$ 内部（因为每次合并的两堆在合并树中是兄弟，它们的叶子并是连续的弧，且不等于整个环），它们不会跨越剪开的那个断口；最后一次合并恰好把两段接上。因此整个方案在拉直后的链上步步合法，得分不变。
- 链 → 环：链上的相邻关系在环上都成立（链是环剪开得到的），把同一套合并顺序在环上执行即可，最后一步合并的两堆在环上仍然相邻。

所以环问题的最优值 = 对所有 $n$ 个断口（等价于所有长度为 $n$ 的链区间）取链问题最优值的 min/max。$\square$

实现上不需要真的枚举断口再做 $n$ 次 DP：把数组复制一遍成 $a_0,\dots,a_{2n-1}$，则"从 $l$ 开始的长 $n$ 的链"就是区间 $[l,l+n-1]$。一次 DP 求出所有长度 $\le n$ 的区间值，答案取 $\min/\max_{l=0}^{n-1} g[l][l+n-1]$。

### 2.4 为什么"最小"和"最大"要分开做

最小值用 $\min$ 转移；最大值用 $\max$ 转移。两者不能互相转化（例如最大值并没有"对称"的最小值问题），所以同步维护两个 DP 表。注意最大值**不能**用"每次合并当前最小的两堆"之类的贪心——环上的相邻限制让贪心失效；直接用同一套区间 DP 取 max 是正确且足够的。

### 2.5 复杂度

$2n$ 个位置，区间长度从 $2$ 到 $n$，每个区间枚举 $O(n)$ 个分割点：$O(n^3)$。$n=100$ 时约 $2\times10^6$ 次转移。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 合并过程是一棵叶子顺序固定的二叉树，总得分 $=\sum a_i\cdot\mathrm{dep}_i$。
- **consider easier version** — 先把环剪断，只做链上的石子合并。
- **classic problem solution** — 链上区间 DP：枚举最后一次合并的分割点，代价加上区间和。
- **reduce to easier problem** — 环的任一方案都是某个断口剪开后的链方案，故枚举 $n$ 个断口（复制数组）取极值。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| $n$ | `int` | 石子堆数 | 读入 | $\le100$ |
| `a[2n]` | `int [205]` | 环复制成两倍的链 | 读入后 `a[i+n]=a[i]` | doubled |
| `s[i]` | `int [205]` | 前缀和，$s[i]=\sum_{j<i}a_j$ | `s[0]=0` | prefix sum |
| `fmn[l][r]` | `int [205][205]` | 把 $[l,r]$ 合并成一堆的最小得分 | 长度 $1$ 为 $0$，其余 `inf` | min |
| `fmx[l][r]` | `int [205][205]` | 把 $[l,r]$ 合并成一堆的最大得分 | 长度 $1$ 为 $0$，其余 $0$ | max |

### 4.2 算法步骤

1. 读入 $n$ 与 $a_0,\dots,a_{n-1}$，令 `a[i+n]=a[i]`（$0\le i<n$），并预处理 `s[i+1]=s[i]+a[i]`（$0\le i<2n$）。
2. 初始化：对所有 $0\le i<2n$，`fmn[i][i]=fmx[i][i]=0`；`fmn` 其余位置填 `inf`。
3. 枚举区间长度 $len=2..n$，对每个左端点 $l$（满足 $l+len\le 2n$），令 $r=l+len-1$，区间和 $w=s[r+1]-s[l]$：
   - 枚举分割点 $k=l..r-1$，用 `fmn[l][k]+fmn[k+1][r]` 更新 `fmn[l][r]`，用 `fmx[l][k]+fmx[k+1][r]` 更新 `fmx[l][r]`；
   - 最后给两者都加上 $w$。
4. 答案：$\min_{l=0}^{n-1}\texttt{fmn}[l][l+n-1]$ 与 $\max_{l=0}^{n-1}\texttt{fmx}[l][l+n-1]$，分两行输出。

### 4.3 复杂度

- 时间 $O(n^3)$：区间数 $O(n^2)$（长度限制在 $n$ 以内），每区间转移 $O(n)$。
- 空间 $O(n^2)$：两张 $205\times205$ 的 `int` 表，约 $336$ KB。

## 5. 示例代码

```cpp
//
// 题目：P1880 [NOI1995] 石子合并
// https://www.luogu.com.cn/problem/P1880
// 自测：小数据全排列合并顺序对拍通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{205},inf{1145141919};

int n;
int a[mxn],s[mxn];
int fmn[mxn][mxn],fmx[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		a[i+n]=a[i];                // 断环成链，复制一倍
	}
	for(int i=0;i<2*n;++i)
		s[i+1]=s[i]+a[i];
	fill_n(&fmn[0][0],mxn*mxn,inf);
	for(int i=0;i<2*n;++i)
		fmn[i][i]=0;                // 一堆不需要合并
	for(int len=2;len<=n;++len)
		for(int l=0;l+len<=2*n;++l)
		{
			int r=l+len-1,w=s[r+1]-s[l];
			for(int k=l;k<r;++k)
			{
				fmn[l][r]=min(fmn[l][r],fmn[l][k]+fmn[k+1][r]);
				fmx[l][r]=max(fmx[l][r],fmx[l][k]+fmx[k+1][r]);
			}
			fmn[l][r]+=w;           // 最后一次合并的得分
			fmx[l][r]+=w;
		}
	int mn{inf},mx{0};
	for(int l=0;l<n;++l)
	{
		mn=min(mn,fmn[l][l+n-1]);
		mx=max(mx,fmx[l][l+n-1]);
	}
	cout<<mn<<'\n'<<mx<<'\n';
	return 0;
}
```
