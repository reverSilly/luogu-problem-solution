# P1120 [CERC 1995] 小木棍 — 完整题解

---

## 1. Re-read the problem

**题意重述**

乔治原来有若干根长度**完全相同**的原始木棍。他把每根原始木棍随意砍成若干段，每段长度不超过 $50$。现在他得到了 $n$ 根小木棍（$1\le n\le 65$），每根长度为 $a_i$。他忘记了原始木棍的根数和长度，只知道所有原始木棍长度相等。

给定 $n$ 和 $a_i$，求原始木棍的**最小可能长度**。

**输入输出样例**

```
输入：
9
5 2 1 5 2 1 5 2 1
输出：
6
```

解释：$5+1=6$ 凑一根，$5+1=6$ 凑一根，$5+1=6$ 凑一根，$2+2+2=6$ 凑一根，共 $4$ 根，每根长 $6$。无法得到更小的原始长度。

**约束条件**

- $n\le 65$，$a_i\le 50$。
- 搜索题，数据强度较高，必须引入多条强大的剪枝才能通过。

## 2. Chain-of-thought with full proofs

### 2.1 枚举长度

原始长度 $L$ 必须满足两个必要条件：

1. $L\ge \max a_i$——一根原始木棍至少能容纳最长的那个小段；
2. $L\mid \sum a_i$——原始木棍总长度等于小木棍总长度，根数为 $\dfrac{\sum a_i}{L}$。

因此只需从 $\max a_i$ 到 $\sum a_i$ 枚举 $L$，检查是否能拼出 $\dfrac{\sum a_i}{L}$ 根长度为 $L$ 的木棍，取第一个可行的 $L$ 即为最小答案。

复杂度：枚举量最大为 $\sum a_i\le 65\times 50=3250$，可以接受。瓶颈在「检查可行性」这一步。

### 2.2 DFS 框架

构造一个搜索过程：

```cpp
bool dfs(int done, int cur, int start);
```

- `done`：已经拼好的完整原始木棍的根数；
- `cur`：当前正在拼的这根原始木棍已经凑出的长度；
- `start`：从哪个下标开始尝试下一根小木棍（用于保证组合不重复）。

当 `cur == L` 时，这根拼完了，递归 `dfs(done+1, 0, 0)`。
当 `done == target` 时，所有原始木棍拼完，返回 `true`。

### 2.3 朴素 DFS 的致命缺陷

最坏情况下，$n=65$，状态空间是 $\Omega(2^{65})$，完全不可行。必须用**充分的剪枝**将指数级状态压缩到可接受范围。

### 2.4 剪枝 ①：降序排序

**断言**：将 $a_i$ 从大到小排序后搜索，状态数显著减少。

**证明**：大的木棍更难放置，分支更少。先放大木棍可以尽早触发矛盾，减少回溯。这是启发式搜索中"最约束优先"原则的直接应用。

### 2.5 剪枝 ②：等长跳过（去重）

**断言**：若一根长度为 $x$ 的小木棍在当前搜索位置尝试失败，则后续所有与之等长的小木棍在该位置也必然失败。

**证明**：所有长度为 $x$ 的小木棍是**完全对称**的——它们都没有被用过，长度相同，与当前状态的关系完全一样。如果一个失败了，换另一个等长的不会改变任何搜索状态，结果必然相同。因此可以直接跳过后续所有相同长度。

实现上排序后，DFS 循环内若 `a[i] == a[i-1] && !used[i-1]`，则 `continue`。

另一种等价写法是 DFS 失败后 `while (i+1 < n && a[i+1] == a[i]) ++i`。

### 2.6 剪枝 ③：空棍首段失败（最优性剪枝）

**断言**：若当前 `cur == 0`（即正在开始拼一根新原始木棍），选择了某根小木棍 $a_i$ 作为第一段后 DFS 失败，则直接返回 `false`，无需尝试其他小木棍作为第一段。

**证明**：

设当前剩余未使用的小木棍集合为 $S$。当 `cur == 0` 时，我们要从 $S$ 中选出一组拼成下一根长度为 $L$ 的原始木棍。选择 $a_i$ 作为第一段是最自然的做法——它是集合 $S$ 中未被使用的最大元素（因为排序降序，`start=0` 保证了这一点）。

假设 $a_i$ 作为第一段失败。如果存在另一种方案 T 也能拼出这根原始木棍，且其第一段 $a_j \ne a_i$，那么 $a_j < a_i$（因为 $a_i$ 是最大的）。交换论证：在方案 T 中，将 $a_i$ 与 $a_j$ 交换——$a_i$ 替换掉 $a_j$ 作为第一段，剩下的集合仍是 $S\setminus\{a_i\}$，长度更小，自由度更大，理应更易成功。但我们已经知道以 $a_i$ 打头不可能成功，所以交换后也不可能成功。因此不存在这样的方案 T，直接返回 `false`。

这是本题最强也是最重要的剪枝，能砍掉指数级的分支。

### 2.7 剪枝 ④：恰好填满后失败（最优性剪枝）

**断言**：若 `cur + a[i] == L`（即 $a_i$ 恰好填满当前原始木棍）但后续 DFS 失败，则直接返回 `false`，无需尝试其他组合来填满这根木棍。

**证明**：

设当前已拼长度 $cur$，剩余集合 $S$。$a_i$ 恰好填满，剩余集合变为 $S\setminus\{a_i\}$，要拼剩下的 $target-done-1$ 根完整木棍。假设存在另一种方案 T，它不用 $a_i$ 来填满当前木棍，而是用若干根更小的木棍拼成 $L-cur$，把 $a_i$ 留到后面再用。

那么在这方案 T 中，$a_i$ 出现在后面某根木棍里。设想交换：把 $a_i$ 拿到当前位置来填满，而把原来用来填满当前位置的那些小木棍放到 $a_i$ 原本的位置。交换后，每根木棍的长度总和不变，可行性不变。但这样一来，我们就得到了一组与 "$a_i$ 恰好填满当前位置" 等价且同样可行的解。这与 "$a_i$ 恰好填满后 DFS 失败" 矛盾。故不存在这样的方案 T，直接返回 `false`。

### 2.8 剪枝 ⑤：长度不可超 L（可行性）

DFS 循环中，如果 `cur + a[i] > L` 直接 `continue`，这是显然的。

### 2.9 剪枝总结

| # | 剪枝 | 类型 | 效果 |
|---|------|------|------|
| ① | 降序排序 | 启发式 | 减少分支因子 |
| ② | 等长跳过 | 对称性 | 避免等长重复搜索 |
| ③ | 空棍首段失败 | 最优性 | 最强剪枝，砍指数分支 |
| ④ | 恰好填满后失败 | 最优性 | 次强剪枝 |
| ⑤ | 长度限制 | 可行性 | 基础剪枝 |

实际上剪枝 ③ 已经足够将复杂度降到可接受范围，加上 ② 和 ④ 后可以通过官方数据。

## 3. Pattern summary

**题目类型**：可行性判定型搜索（Decision DFS）

**核心范式**：

1. **枚举答案**：利用整除性缩小枚举范围。
2. **DFS 构造**：逐根构造原始木棍，逐段添加小木棍。
3. **剪枝三板斧**：
   - *排序 + 去重*（降低分支系数）
   - *空棍首段失败*（组合最优性：最大元素必须属于本轮）
   - *恰好填满后失败*（组合最优性：能填满就用它填满）

**适用范围**：

- 木棍拼接 / 集合划分问题（Stick Problem 家族）
- 所有"将集合划分为若干等大的子集"的判定问题
- 一般性的组合构造型 DFS，当元素有大小关系时均可尝试"最大元素必属本轮"剪枝

**复杂度**：

- 理论最坏仍是指数，但实际运行极快（$n=65$ 时单次 DFS 分支数通常不到 $10^4$）。
- 总复杂度 $O(\sum a_i \times \text{DFS}(n))$，实际通过。

## 4. Real solution with notation glossary

### 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 小木棍个数 |
| $a_i$ | 第 $i$ 根小木棍的长度（排序后） |
| $S = \sum a_i$ | 总长度 |
| $L$ | 当前尝试的原始木棍长度 |
| $\mathit{target} = S/L$ | 需要拼出的原始木棍根数 |
| $\mathit{used}_i$ | 第 $i$ 根小木棍是否已被使用 |
| $done$ | 已拼好的完整原始木棍数 |
| $cur$ | 当前正在拼的原始木棍已累积长度 |

### 算法步骤

```
1. 读入 n, a[0..n-1]
2. 计算 S = sum(a)
3. 降序排序 a
4. 枚举 L 从 max(a) 到 S：
   若 S % L != 0: continue
   target = S / L
   重置 used 数组为 false
   若 dfs(0, 0, 0) 为 true: 输出 L 并结束
```

### DFS 伪代码

```
function dfs(done, cur, start):
    if done == target: return true
    if cur == L: return dfs(done+1, 0, 0)

    for i from start to n-1:
        if used[i] or cur + a[i] > L: continue
        if i > 0 && a[i] == a[i-1] && !used[i-1]: continue  // 剪枝②

        used[i] = true
        if dfs(done, cur + a[i], i+1): return true
        used[i] = false

        // 剪枝③：空棍首段失败
        if cur == 0: return false
        // 剪枝④：恰好填满后失败
        if cur + a[i] == L: return false

    return false
```

这里 `start` 参数保证我们只尝试下标递增的组合，避免产生排列重复（如 $[a_0,a_2]$ 和 $[a_2,a_0]$ 只尝试前者）。

注意剪枝③和④必须在 `used[i] = false` 之后、`for` 继续之前检查，因为它们是建立在"当前选择失败"这个事实上的推导。

## 5. Example code

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64 = long long;

constexpr int mxn{70};
int n, a[mxn], S, L, target;
bool used[mxn];

bool dfs(int done, int cur, int start)
{
	if (done == target)
		return true;
	if (cur == L)
		return dfs(done + 1, 0, 0);

	for (int i{start}; i < n; ++i)
	{
		if (used[i])
			continue;
		if (cur + a[i] > L)
			continue;
		// 剪枝②：等长跳过
		if (i > 0 && a[i] == a[i - 1] && !used[i - 1])
			continue;

		used[i] = true;
		if (dfs(done, cur + a[i], i + 1))
			return true;
		used[i] = false;

		// 剪枝③：空棍首段失败
		if (cur == 0)
			return false;
		// 剪枝④：恰好填满后失败
		if (cur + a[i] == L)
			return false;
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin >> n;
	S = 0;
	for (int i{0}; i < n; ++i)
	{
		cin >> a[i];
		S += a[i];
	}

	sort(a, a + n, greater<int>());

	for (L = a[0]; L <= S; ++L)
	{
		if (S % L != 0)
			continue;
		target = S / L;
		memset(used, 0, sizeof(used));
		if (dfs(0, 0, 0))
		{
			cout << L << '\n';
			return 0;
		}
	}
	return 0;
}
```

### 代码要点说明

| 部分 | 说明 |
|------|------|
| `sort(a, a + n, greater<int>())` | 降序排列，大木棍优先 |
| `memset(used, 0, sizeof(used))` | 每次枚举新 $L$ 时重置 |
| `i{start}` 而非 `i{0}` | 避免排列重复，保证组合有序 |
| `if (i > 0 && a[i] == a[i-1] && !used[i-1]) continue` | 等长跳过：前一根等长的未被使用，说明它在该位置已失败 |
| `if (cur == 0) return false` | 剪枝③，放在 `used[i] = false` 之后 |
| `if (cur + a[i] == L) return false` | 剪枝④，同上 |

**总结**：这道题是搜索剪枝的经典教材。排序 + 三条核心剪枝（等长跳过、空棍首段失败、恰好填满后失败）缺一不可。理解了这些剪枝的**完备性证明**（而非凭感觉加剪枝），才是真正掌握了这道题的精髓。
