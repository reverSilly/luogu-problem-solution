# P1850 [NOIP 2016 提高组] 换教室

## 1. 重新读题

### 1.1 问题重述（人话版）

一学期有 $n$ 个时间段。第 $i$ 个时间段有两门内容相同的课同时开：

- 牛牛默认在教室 $c_i$；
- 另一间可选教室是 $d_i$。

牛牛可以在学期开始前**一次性**提交至多 $m$ 份"换教室申请"，第 $i$ 份申请让他去 $d_i$。申请通过的概率是 $k_i$，且各申请**相互独立**；没通过就仍在 $c_i$。

注意：申请必须提前决定，**不能**根据前面申请的结果再决定后面申不申请。

学校有 $v$ 间教室、$e$ 条双向道路（有重边、自环）。每上完一节课，牛牛从这节课的实际教室走到下节课的实际教室，走**最短路**。

求：选择申请哪些时间段，使得"在教室间移动所耗费体力总和"的**期望**最小。输出保留两位小数。

### 1.2 关键约束与规模暗示

- $n\le 2000$，$m\le 2000$，$v\le 300$，$e\le 90000$。
- $v\le300$ 直接提示 Floyd 求全源最短路：$O(v^3)\approx2.7\times10^7$。
- $n,m\le2000$ 提示 $O(nm)$ 的 DP，状态里带"已经用了几次申请"和"上一段申没申请"。
- 图保证连通；边权 $\le100$，最短路 $\le299\times100=29900$。
- 概率是实数（至多 $3$ 位小数），用 `double` 足够；输出要求恰好两位小数。

## 2. 思维链（Chain-of-thought）

### 2.1 把"随机过程"拆成"决策 + 独立结果"

先写清楚哪些是"我们选的"，哪些是"随机的"：

- **决策**：$a_i\in\{0,1\}$ 表示是否为第 $i$ 个时间段提交申请，满足 $\sum a_i\le m$。
- **结果**：对每个 $i$，若 $a_i=1$，则 $X_i\sim \mathrm{Bernoulli}(k_i)$（$1$ 表示通过）；若 $a_i=0$，约定 $X_i=0$。不同 $i$ 的 $X_i$ 相互独立。
- **实际教室**：
  $$r_i=\begin{cases}d_i,&a_i=1\ \text{且}\ X_i=1,\\c_i,&\text{否则}.\end{cases}$$

总耗体力为

$$T=\sum_{i=1}^{n-1}D\big(r_{i-1},r_i\big),$$

其中 $D(u,v)$ 是教室 $u,v$ 之间的最短路长度。目标是 $\min_{\sum a_i\le m}\mathbb{E}[T]$。

### 2.2 引理 1：每一段都走最短路，问题只剩 $D$

**引理 1** 对任意固定的实际教室序列 $(r_0,\dots,r_{n-1})$，最小总耗体恰为 $\sum_{i=1}^{n-1}D(r_{i-1},r_i)$。

**证明**：各段之间的行走互相独立——第 $i$ 段的起点、终点固定为 $r_{i-1},r_i$，走法不影响之后的任何东西（每题之间没有时间约束，也没有"顺路"之类的要求）。因此每一段都独立地取最小值 $D(r_{i-1},r_i)$，总和最小。$\blacksquare$

于是先用 Floyd 求出所有 $D(u,v)$：

$$D(u,v)=\min_{\text{路径}}\sum w.$$

多条重边取最小值，自环不会改善最短路（边权为正），`D(u,u)=0`。

### 2.3 引理 2：线性性，把期望拆到每一段

**引理 2**

$$\mathbb{E}[T]=\sum_{i=1}^{n-1}\mathbb{E}\big[D(r_{i-1},r_i)\big].$$

**证明**：期望的线性性，对任意随机变量之和都成立，不需要独立性。$\blacksquare$

这一步把"整条链的期望"拆成了"每一段的期望"。接下来只需要算每一段的期望。

### 2.4 引理 3：每一段的期望只取决于两个相邻决策

**引理 3** $\mathbb{E}[D(r_{i-1},r_i)]$ 只由 $a_{i-1}$ 与 $a_i$ 决定，与其它决策、与 $r$ 的实际取值无关（后者已经被期望消掉）。

**证明**：$r_{i-1}$ 是 $(a_{i-1},X_{i-1})$ 的函数，$r_i$ 是 $(a_i,X_i)$ 的函数；$X_{i-1},X_i$ 相互独立，且与其它一切独立。所以 $(r_{i-1},r_i)$ 的联合分布只依赖 $(a_{i-1},a_i)$，期望自然只依赖它们。$\blacksquare$

把四种情况逐一展开（记 $k=k_{i-1}$，$k'=k_i$，$D_{uv}=D(u,v)$）：

| $a_{i-1}$ | $a_i$ | $\mathbb{E}[D(r_{i-1},r_i)]$ |
| :---: | :---: | :--- |
| $0$ | $0$ | $D(c_{i-1},c_i)$ |
| $1$ | $0$ | $k\,D(d_{i-1},c_i)+(1-k)\,D(c_{i-1},c_i)$ |
| $0$ | $1$ | $k'\,D(c_{i-1},d_i)+(1-k')\,D(c_{i-1},c_i)$ |
| $1$ | $1$ | $kk'D(d_{i-1},d_i)+k(1-k')D(d_{i-1},c_i)+(1-k)k'D(c_{i-1},d_i)+(1-k)(1-k')D(c_{i-1},c_i)$ |

第四行就是 $2\times2$ 四种独立结果分别乘概率；这正是独立性发挥作用的地方。

### 2.5 为什么状态要带"上一次申没申请"

现在系统已经是一个"按时间顺序做决策"的过程：

- 每做一个决策 $a_i$，就消耗 $0$ 或 $1$ 个申请名额；
- 从 $i-1$ 到 $i$ 的期望代价由 $(a_{i-1},a_i)$ 决定。

这是一个典型的分层决策问题。若只记"用了几个名额"，那么计算第 $i$ 段代价时不知道 $a_{i-1}$，无法选表；所以状态必须再带上 $a_{i-1}$。

**但不需要记"上一次申请有没有通过"**：通过与否是随机的，我们在转移里已经对 $X$ 取了期望（引理 3），下一步的分布只由决策决定。若把"通过/不通过"也放进状态，就变成在决策路径上再对随机结果分层，既多余又会把同一个决策重复计数。

### 2.6 状态与转移

定义（0-based，$i$ 表示已经处理到第 $i$ 个时间段）：

$$f[i][j][s]=\text{前 }i+1\text{ 个时间段、共申请 }j\text{ 次、且第 }i\text{ 段是否申请}=s\text{ 时的最小期望总耗体}.$$

初始（$i=0$，还没有任何移动代价）：

$$f[0][0][0]=0,\qquad f[0][1][1]=0,\qquad\text{其余}=+\infty.$$

转移（$i\ge1$）：

$$f[i][j][0]=\min\begin{cases}
f[i-1][j][0]+D(c_{i-1},c_i),\\
f[i-1][j][1]+k_{i-1}D(d_{i-1},c_i)+(1-k_{i-1})D(c_{i-1},c_i),
\end{cases}$$

$$f[i][j][1]=\min\begin{cases}
f[i-1][j-1][0]+k_iD(c_{i-1},d_i)+(1-k_i)D(c_{i-1},c_i),\\
f[i-1][j-1][1]+\ \big[kk'D(d_{i-1},d_i)+k(1-k')D(d_{i-1},c_i)+(1-k)k'D(c_{i-1},d_i)+(1-k)(1-k')D(c_{i-1},c_i)\big],
\end{cases}$$

其中第二式里 $k=k_{i-1},k'=k_i$。

答案

$$\min_{0\le j\le\min(m,n),\ s\in\{0,1\}}f[n-1][j][s].$$

### 2.7 引理 4：DP 正确性

**引理 4** 上述 DP 的答案等于原问题的最小期望。

**证明**：

- *每个决策向量都被覆盖*：给定任意满足 $\sum a_i\le m$ 的决策向量，沿时间顺序它对应一条状态路径 $(i,j,s)$（$j$ 是前缀中 $1$ 的个数，$s=a_i$）。由引理 2、3，
  $$\mathbb{E}[T]=\sum_{i=1}^{n-1}\big(\text{第 }i\text{ 段的四项代价}\big),$$
  而 DP 的每条转移恰好把对应的一项加进去。所以 $f[n-1][\sum a_i][a_{n-1}]\le\mathbb{E}[T]$，答案 $\le$ 最优值。
- *每个状态路径都对应一个决策向量*：反过来，DP 的每一次转移都选定了 $(a_{i-1},a_i)$，从初态到终态连起来就是一个合法的决策向量（$j$ 就是申请次数，$\le m$），其期望恰为 DP 累加的值。所以答案 $\ge$ 最优值。
- 两边夹逼，等号成立。$\blacksquare$

归纳叙述：对 $i$ 归纳，$f[i][j][s]$ 是"前 $i+1$ 段、申请 $j$ 次、$a_i=s$"的所有决策前缀的最小期望；转移按 $a_{i-1}\in\{0,1\}$ 分类，用引理 3 的代价表，取最小。基态 $i=0$ 只有第 $1$ 个时间段、没有任何移动，故 $f[0][0][0]=0$（不申请）与 $f[0][1][1]=0$（申请）都是对应状态下唯一的期望值，其余 $(j,s)$ 组合不可达。

### 2.8 边界与坑点

- $n=1$：不存在移动，答案 $0$（DP 循环不执行，初值即答案）。
- $m>n$：多出的名额没用，取 $m\leftarrow\min(m,n)$。
- $k_i=0$ 或 $1$：公式自动退化，无需特判。
- $v=1$ 或所有教室距离为 $0$：答案 $0$。
- Floyd 的无穷大不能太大：用 `int` 时 `INF+INF` 必须不溢出。取 `INF=10^9`，两倍 $2\times10^9<2^{31}-1$。若用 $1145141919$，两倍约 $2.29\times10^9$ 会溢出成负数。
- 重边取 `min`；自环对最短路无贡献（边权为正）。
- 输出 `fixed<<setprecision(2)`；题目保证四舍五入后的误差容限，`double` 足够。

**样例自检**：题面"样例 1 说明"其实隐含了输入 $v=2$、一条边 $1\!-\!2$ 权 $4$、$c=(1,2,1)$、$d=(2,1,2)$、$k=(0.8,0.2,0.5)$。用本代码跑这组数据得到 `2.80`，与题面最优值 $2.8$ 一致。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 决策提前定、结果独立，所以"随机"只影响每段的期望代价。
- **classic problem solution** — Floyd 求全源最短路，把"走路"压成 $D(u,v)$。
- **explore its property** — 期望的线性性，把总期望拆成每段期望之和。
- **explore its property** — 每段期望只依赖相邻两个"申请/不申请"决策（独立性 + 局部性）。
- **classic problem solution** — 状态机 DP：$f[i][j][s]$，$j$ 是已用名额，$s$ 是上一段是否申请。
- **classic problem solution** — 滚动两行，$O(nm)$。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n, m` | `int` | 时间段数、最多申请数 | 读入 | $m$ 会截到 $\min(m,n)$ |
| `v, e` | `int` | 教室数、道路数 | 读入 | — |
| `c[i], d[i]` | `int [2005]` | 默认/备选教室（0-based） | 读入后 `--` | classroom / destination |
| `k[i]` | `double [2005]` | 第 $i$ 段申请通过概率 | 读入 | — |
| `dis[u][v]` | `int [305][305]` | 最短路 | `dis[u][u]=0`，其余 `infdis` | distance |
| `f[j][s]` | `double [2005][2]` | 上一层的 $f[i-1][j][s]$ | 见 2.6 | former |
| `g[j][s]` | `double [2005][2]` | 当前层的 $f[i][j][s]$ | 每轮全 `inf` | current |
| `inf` | `double` | 期望用无穷 | $10^{18}$ | — |
| `infdis` | `int` | 距离用无穷 | $10^9$ | 防 `INF+INF` 溢出 |
| `ans` | `double` | 答案 | $+\infty$ | 输出 |

### 4.2 算法步骤

1. 读入 $n,m,v,e$；读入 $c,d$ 并转 0-based；读入 $k$。
2. 初始化 `dis`：对角线 $0$，其余 `infdis`；读边，重边取 `min`（正权自环不影响）。
3. Floyd：对 $t=0..v-1$，$i,j=0..v-1$，`dis[i][j]=min(dis[i][j],dis[i][t]+dis[t][j])`。
4. `m=min(m,n)`；`f` 全 `inf`，`f[0][0]=0`，若 $m\ge1$ 则 `f[1][1]=0`。
5. 对 $i=1..n-1$：
   1. `g` 全 `inf`；
   2. 对 $j=0..m$：
      - `g[j][0]` 由 `f[j][0]`、`f[j][1]` 转移（见 2.6 第一式）；
      - 若 $j\ge1$，`g[j][1]` 由 `f[j-1][0]`、`f[j-1][1]` 转移（见 2.6 第二式）；
   3. `f=g`。
6. `ans=min_{j≤m,s} f[j][s]`，按两位小数输出。

### 4.3 复杂度

- Floyd：$O(v^3)=2.7\times10^7$。
- DP：$O(nm)=4\times10^6$。
- 空间：`dis` 约 $0.37$ MB，`f/g` 约 $64$ KB。
- 实测：$n=m=2000,v=300$ 随机连通图约 $0.05$ s。

## 5. 示例代码

```cpp
//
// 题目：P1850 [NOIP 2016 提高组] 换教室
// https://www.luogu.com.cn/problem/P1850
// 本地自测通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005},mxv{305};
constexpr double inf{1e18};
constexpr int infdis{1'000'000'000};

int n,m,v,e;
int c[mxn],d[mxn];
double k[mxn];
int dis[mxv][mxv];
double f[mxn][2],g[mxn][2];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>v>>e;
	for(int i=0;i<n;++i)
	{
		cin>>c[i];
		--c[i];
	}
	for(int i=0;i<n;++i)
	{
		cin>>d[i];
		--d[i];
	}
	for(int i=0;i<n;++i)
		cin>>k[i];
	for(int i=0;i<v;++i)
		for(int j=0;j<v;++j)
			dis[i][j]=(i==j?0:infdis);
	for(int i=0,a,b,w;i<e;++i)
	{
		cin>>a>>b>>w;
		--a;--b;
		dis[a][b]=min(dis[a][b],w);
		dis[b][a]=min(dis[b][a],w);
	}
	for(int t=0;t<v;++t)
		for(int i=0;i<v;++i)
			for(int j=0;j<v;++j)
				dis[i][j]=min(dis[i][j],dis[i][t]+dis[t][j]);

	m=min(m,n);
	for(int j=0;j<=m;++j)
		f[j][0]=f[j][1]=inf;
	f[0][0]=0;
	if(m>=1)
		f[1][1]=0;
	for(int i=1;i<n;++i)
	{
		for(int j=0;j<=m;++j)
			g[j][0]=g[j][1]=inf;
		for(int j=0;j<=m;++j)
		{
			double best=inf;
			if(f[j][0]<inf/2)
				best=min(best,f[j][0]+dis[c[i-1]][c[i]]);
			if(f[j][1]<inf/2)
				best=min(best,f[j][1]+k[i-1]*dis[d[i-1]][c[i]]+(1-k[i-1])*dis[c[i-1]][c[i]]);
			g[j][0]=best;
			if(j>=1)
			{
				best=inf;
				if(f[j-1][0]<inf/2)
					best=min(best,f[j-1][0]+k[i]*dis[c[i-1]][d[i]]+(1-k[i])*dis[c[i-1]][c[i]]);
				if(f[j-1][1]<inf/2)
					best=min(best,f[j-1][1]
						+k[i-1]*k[i]*dis[d[i-1]][d[i]]
						+k[i-1]*(1-k[i])*dis[d[i-1]][c[i]]
						+(1-k[i-1])*k[i]*dis[c[i-1]][d[i]]
						+(1-k[i-1])*(1-k[i])*dis[c[i-1]][c[i]]);
				g[j][1]=best;
			}
		}
		for(int j=0;j<=m;++j)
		{
			f[j][0]=g[j][0];
			f[j][1]=g[j][1];
		}
	}
	double ans=inf;
	for(int j=0;j<=m;++j)
		ans=min(ans,min(f[j][0],f[j][1]));
	cout<<fixed<<setprecision(2)<<ans<<'\n';
	return 0;
}
```
