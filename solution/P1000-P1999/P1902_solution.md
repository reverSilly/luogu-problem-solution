# P1902 刺杀大使

## 1. 重新读题

### 1.1 问题重述（人话版）

有一个 $n\times m$ 的网格迷宫。第 $1$ 行的 $m$ 个房间是入口（伤害值都是 $0$）；第 $n$ 行的 $m$ 个房间放着 $m$ 个机关（伤害值也都是 $0$），必须**每一个**机关都打开。中间第 $2\sim n-1$ 行的每个房间都有激光，进入会受伤，第 $i$ 行第 $j$ 列伤害为 $p_{i,j}$。

可以派任意多个士兵，从任意入口进入，只能上下左右走。**一个士兵受到的伤害 = 他走过路径上所有房间伤害值的最大值**；整支部队的伤害 = 所有士兵伤害的最大值。求整支部队伤害的最小可能值。

### 1.2 关键约束与规模暗示

- $n,m\le 1000$，$p_{i,j}\le 1000$；网格最多 $10^6$ 个格子。
- 50% 数据 $n,m\le 100$，$100\%$ 数据 $n,m\le 1000$。
- $p_{i,j}\le 1000$ 是一个明显信号：**答案只可能是 $0\sim1000$ 中的某个值**，可以枚举/二分这个值。
- $n,m\le 1000$ 排除 $O((nm)^2)$；对 $10^6$ 个格子做十几次 BFS（约 $10^7$ 次操作）是可行的。
- 「所有人伤害最大值最小」是典型的**最小化最大值**，先想二分答案。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先把「多士兵」这层壳剥掉

题目允许任意多士兵，看似要把「每个机关都要有人到」当成多源多汇问题。但注意：

- 第 $n$ 行的 $m$ 个房间是一整排，伤害值全为 $0$，且相邻房间之间有门，**它们在网格里是连通的**；
- 所以只要有**一个**士兵到达了第 $n$ 行的任意一个房间，他就可以沿着第 $n$ 行走到其余 $m-1$ 个房间，把机关全部打开；
- 沿第 $n$ 行走不增加任何伤害（这些房间 $p=0$）。

也就是说，**一个士兵就够了**，问题等价于：找一条从第 $1$ 行某格到第 $n$ 行某格的路径，使路径上 $p$ 的最大值最小。多士兵不会带来任何好处，因为「取最大」的代价结构下，把多人的路径并起来不如让一人走通。

### 2.2 转化为判定问题

**引理 1**：设 $k$ 为非负整数。存在一种方案使整支部队伤害 $\le k$，当且仅当**只保留满足 $p_{i,j}\le k$ 的格子**时，第 $1$ 行的某个格子能到达第 $n$ 行的某个格子。

**证明**：

- $(\Rightarrow)$ 若方案总伤害 $\le k$，取其中到达过第 $n$ 行的某个士兵，他的路径上每个格子的 $p$ 都 $\le$ 他的伤害 $\le$ 总伤害 $\le k$。所以这条路径完全落在「$p\le k$」的子图里，两行连通。
- $(\Leftarrow)$ 若子图里有一条从第 $1$ 行到第 $n$ 行的路径，派一个士兵沿它走；他路上经过的格子都满足 $p\le k$，伤害 $\le k$。到达第 $n$ 行后沿第 $n$ 行走遍所有机关（这些格子 $p=0\le k$），总伤害仍 $\le k$。

注意：路径的第一格在第 $1$ 行、最后一格在第 $n$ 行，这两行 $p=0$，天然满足 $p\le k$。$\square$

于是「答案 $\le k$」可以 $O(nm)$ 用 BFS/DFS 判定。

### 2.3 二分答案

可行性关于 $k$ 单调：若 $k$ 可行，则 $k+1$ 保留的格子更多，当然也可行。所以对 $k\in[0,1000]$ 二分，判定用一次多源 BFS：把所有第 $1$ 行格子（$p=0$）入队，只走 $p\le k$ 且未访问的格子，一旦弹出第 $n$ 行的格子就返回可行。

为什么下界取 $0$ 而不是 $1$？当 $n=2$ 时第 $1$、$n$ 行直接相邻，全部格子 $p=0$，答案就是 $0$。若 $n=1$（入口即机关），答案同样是 $0$。二分的区间必须容纳 $0$。

### 2.4 一个容易写错的点

判定时不要把「必须遍历所有机关」再检查一遍：由 2.1 的论证，到达第 $n$ 行任意一格就已经足够。若强行要求「$m$ 个机关各自可达」，会因为第 $n$ 行内部连通而得到完全相同的判定结果，只是白白多写代码。

---

## 3. 模式总结（Pattern Summary）

- **explore its property** — 第 $n$ 行整排连通且 $p=0$，一个士兵即可打开全部机关，多士兵问题退化为单路径问题。
- **reduce to easier problem** — 「伤害最大值最小」转为判定「只走 $p\le k$ 的格子时两行是否连通」，可行性对 $k$ 单调。
- **classic problem solution** — 二分 $k$ + 多源 BFS 判定连通性。

---

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n,m` | `int` | 网格行数、列数 | 读入 | 维度 |
| `p[i][j]` | `int [1005][1005]` | 第 $i$ 行第 $j$ 列伤害 | 读入 | pain |
| `vis[i][j]` | `bool [1005][1005]` | 本次 BFS 是否访问 | 每次 `check` 重置为 `false` | visited |
| `que[]` | `int [1005*1005]` | BFS 队列，存格子编号 `x*m+y` | 空 | queue |
| `dx,dy` | `int [4]` | 四方向增量 | 固定 | direction |

### 4.2 算法步骤

1. 读入 $n,m$ 与 $p$ 矩阵。
2. 在 $[0,1000]$ 上二分答案 `lim`，调用 `check(lim)`：
   1. 清空 `vis`；
   2. 把第 $1$ 行全部 $m$ 个格子标记访问并入队；
   3. 标准 BFS：弹出 `(x,y)`，若 $x=n-1$ 立即返回 `true`；四邻居中未访问且 `p<=lim` 的入队；
   4. 队列空仍未到达第 $n$ 行则返回 `false`。
3. 输出二分得到的最小可行 `lim`。

### 4.3 复杂度分析

- **时间复杂度**：每次 `check` 为 $O(nm)$，二分约 $\log_2 1001\approx10$ 次，总 $O(nm\log 1000)$，约 $10^7$ 次操作。
- **空间复杂度**：$O(nm)$，约 $4$ MB（`p`）+ $1$ MB（`vis`）+ $4$ MB（队列）。

## 5. 示例代码

```cpp
//
// 题目：P1902 刺杀大使
// https://www.luogu.com.cn/problem/P1902
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,m;
int p[mxn][mxn];
bool vis[mxn][mxn];
int que[mxn*mxn];

constexpr int dx[4]{-1,1,0,0};
constexpr int dy[4]{0,0,-1,1};

bool check(int lim)
{
	fill_n(&vis[0][0],mxn*mxn,false);
	int head{0},tail{0};
	for(int j=0;j<m;++j)
	{
		vis[0][j]=true;
		que[tail++]=j;
	}
	while(head<tail)
	{
		int id=que[head++];
		int x=id/m,y=id%m;
		if(x==n-1)
			return true;
		for(int d=0;d<4;++d)
		{
			int nx=x+dx[d],ny=y+dy[d];
			if(nx<0||nx>=n||ny<0||ny>=m)
				continue;
			if(vis[nx][ny]||p[nx][ny]>lim)
				continue;
			vis[nx][ny]=true;
			que[tail++]=nx*m+ny;
		}
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			cin>>p[i][j];

	int lo{0},hi{1000};
	while(lo<hi)
	{
		int mid=(lo+hi)>>1;
		if(check(mid))
			hi=mid;
		else
			lo=mid+1;
	}
	cout<<lo<<'\n';
	return 0;
}
```
