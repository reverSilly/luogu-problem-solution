# P1444 [USACO1.3] 虫洞 wormhole

> 标签：图论 / USACO / 枚举 · 难度：普及/提高-

## 1. 重新读题

**问题重述（简化版）**

- 二维平面上 $n$ 个互不重合的点（虫洞），$n$ 为偶数。
- 把这 $n$ 个点两两配成 $n/2$ 对；进入某对中的任意一个，会从另一个出来，**方向不变（始终 $+x$）**。
- Bessie 永远沿 $+x$ 方向走，起点未知。
- 求：有多少种配对方案，**存在某个起点**，使 Bessie 从那里出发会陷入无限循环。

**关键条件逐句定位**

- "两两配对，形成 $n/2$ 对" —— 计数对象是**完美匹配**的个数，不是"是否存在"。
- "方向不变" —— 传送不改变速度方向，故轨迹单调向东。
- "$n$ 个虫洞出现在农场上…没有两个虫洞处于同一位置" —— 只保证点不重合，**不保证 $x$ 互异**（陷阱 3）。
- "Bessie 总是向 $x$ 正方向走" —— 例子里 $A(1,1),B(3,1)$、起点 $(2,1)$ 三点共线。

**数据范围与复杂度暗示**

| 项目 | 范围 | 暗示 |
|---|---|---|
| $n$ | $2\le n\le 12$，保证为偶数 | 允许指数级：$(n-1)!!$ 量级的全枚举 |
| $x,y$ | $0\le x,y\le 10^9$ | $<2^{31}-1$，只做大小比较即可 |
| 配对总数 | $(n-1)!!$，$n=12$ 时 $=10395$ | 每个方案可承受 $O(n^2)$ 判定 |
| 输出 | 一行整数 | **无精度要求**，不需要 `setprecision` |

**把题面每句话翻译成数学对象**

1. 「FJ 知道他的虫洞**两两配对**，形成 $\frac{n}{2}$ 对配对」（第 2 段）
   → 方案空间是 $\{1,\dots,n\}$ 的**完美匹配**（分成 $n/2$ 个二元子集）。要求的是**方案个数**，不是"是否存在"。
2. 「进入虫洞 $A$ 的任何物体将从虫洞 $B$ 出去，**方向不变**」（第 2 段）
   → 配对等价于一个无不动点的对合 $mate$：$mate(mate(i))=i$ 且 $mate(i)\ne i$；"方向不变"意味着速度向量恒为 $(+1,0)$，轨迹在 $x$ 轴上**永不倒退**。
3. 「$A(1,1)$ 和 $B(3,1)$，Bessie 从 $(2,1)$ 开始朝着 $x$ 正方向移动。Bessie 将进入虫洞 $B(3,1)$，从 $A(1,1)$ 出去，然后再次进入 $B$」（第 3 段）
   → 这句给出"下一个碰到的洞"的**定义**：从出口点向东，碰到的第一个洞。于是

   $$nxt(i)=\arg\min_{j}\{\,x_j: x_j>x_i\,\},\qquad \text{集合为空时 } nxt(i)=\varnothing.$$

   代人数值：$x_A=1$，东侧只有 $B(3)$，故 $nxt(A)=B$；$x_B=3$，东侧无洞，$nxt(B)=\varnothing$。
   她的轨迹写成状态转移就是 $A \xrightarrow{\;nxt\;} B \xrightarrow{\;mate\;} A$，即 $f(A)=mate(nxt(A))=mate(B)=A$，一步回到自身——这正是例子所说的"困在无限循环中"。
4. 「Bessie 总是向 $x$ 正方向走进来，虽然他不记得贝茜的当前位置」（第 4 段）+「计算有多少种配对方案，使得**存在一个位置**」（第 5 段）
   → 判定条件是**存在量词** $\exists$ 起点，而非 $\forall$ 起点；起点还要包含纵坐标，这引出 2.7 的读法辨析。
5. 「农场是一个二维平面，**没有两个虫洞处于同一位置**」（第 1 段）
   → 只保证点 $(x,y)$ 互异，**没有保证 $x$ 互异**，所以 $nxt$ 的 $\arg\min$ 可能不唯一（陷阱 3）。

**样例解释的反推（题面没有给出 Sample Input 块）**

第 44 行「将虫洞编号为 $1\sim 4$，然后通过将 $1,2$ 和 $3,4$ 匹配…从 $(0,0)$ 到 $(1,0)$ 之间的任意位置出发」与第 46 行「从 $3$ 进去，$1$ 出来，她会走向 $2$，然后被传送到 $4$，最后又回到 $3$」联立可解出四个 $x$ 坐标的**相对次序**：

- 「$1\to 3$ 配对」$\Rightarrow mate(1)=3$；「从 $1$ 出来会走向 $2$」$\Rightarrow nxt(1)=2$，故 $x_1<x_2$ 且 $2$ 是 $1$ 东侧最近的洞；
- 「$2\to 4$ 被传送」$\Rightarrow mate(2)=4$；「从 $4$ 又能回到 $3$」$\Rightarrow nxt(4)=3$，故 $x_4<x_3$；
- 「$1,2$ 与 $3,4$ 配对时从 $(0,0)$ 到 $(1,0)$ 之间出发会循环」$\Rightarrow$ 区间 $(x_1,x_2)$ 非空；解释直接把它写成 $(0,0)$ 与 $(1,0)$，据此取 $x_1=0,\;x_2=1$（再由 $nxt(1)=2$ 知 $x_3,x_4>1$）。

综上，与解释完全自洽的一组输入是 $1=(0,0),\,2=(1,0),\,3=(3,0),\,4=(2,0)$；换句话说，若按更常见的输入顺序 $(0,0),(1,0),(2,0),(3,0)$ 编号，则解释里的 $3,4$ 恰好被对调。**结论：解释声称"三种配对里恰有两种成环"，答案 $=2$，与编号方式无关。**

**陷阱清单**

1. 陷阱：题面编号 ≠ 按 $x$ 排序的下标；$nxt$ 必须按坐标重算，不能按编号猜测。
2. 陷阱：判定的是"**存在**一个起点"。把起点固定成"最西边"会漏解（见 2.3 反例）。
3. 陷阱：$x$ 允许相等。$x$ 相等时两洞在 $+x$ 方向互相不可达，$nxt$ 必须用**严格大于**。
4. 陷阱：$y$ 到底参与不参与？严格按"沿水平线走"则只有同 $y$ 的洞碰得到。本文主实现按主流"只看 $x$"，并在 2.7 给出不等价的反例与一行改法。
5. 陷阱：答案对**所有**完美匹配求和，不要乘 $2^{n/2}$，也不要漏掉"洞 $i$ 与 $nxt(i)$ 并不同对、但轨道仍绕成多步环"的方案（引理 4 的逆命题不成立，$6$ 洞反例见 2.2 末尾）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制 —— 传送把连续轨迹压成离散函数

先把几何放下，问："Bessie 的位置随时间怎样变化？"她只有两种行为：
(a) 沿 $+x$ 匀速走；(b) 在某个洞被传送，位置突变但方向不变。
中间过程（走了多远、多久）对"是否会无限循环"毫无影响，**只有事件的顺序有影响**。事件序列是

$$\text{出洞 } i \;\to\; \text{走进 } nxt(i) \;\to\; \text{从 } mate(nxt(i)) \text{ 出来} \;\to\; \cdots$$

于是把"**刚出洞的那一个洞的编号**"当成状态，轨迹就变成有限集合 $\{1,\dots,n\}$ 上的函数迭代。

**引理 1（状态转移良定）**
固定配对 $mate$。定义 $f(i)=mate(nxt(i))$（当 $nxt(i)=\varnothing$ 时记 $f(i)=\bot$，$\bot$ 表示"逃逸，不再有任何事件"）。则从"刚从洞 $i$ 出来"这一情形开始的整条轨迹被 $f$ 唯一决定，即依次为 $i,\,f(i),\,f(f(i)),\dots$，且一旦出现 $\bot$ 就永远不再进入任何洞。

**证明**：分三步。
(i) *出洞后的位置与方向确定*：由题面第 2 段"方向不变"，从洞 $i$ 出来时位置为 $(x_i,y_i)$、速度方向恒为 $(+1,0)$，因此她此后的行走轨迹是射线 $\{(x,y_i):x>x_i\}$（本文主实现把"向东能碰到"抽象为 $x_j>x_i$，见 2.7）。
(ii) *下一个事件唯一*：射线按 $x$ 单调增加，遇到的第一个洞的 $x$ 坐标必是 $\{x_j:x_j>x_i\}$ 的最小元，即 $nxt(i)$ 定义中的 $\arg\min$；若该集合为空则无下一个事件（$\bot$）。注意 $x_j>x_i$ 是**严格**的，所以 $i$ 自身与所有 $x$ 等于 $x_i$ 的洞都不可能被"向东"遇到，故 $nxt(i)\ne i$，事件确实向前推进而不是原地打转。
(iii) *递推闭合*：进入 $nxt(i)$ 后由题面第 2 段从 $mate(nxt(i))=f(i)$ 出来，回到 (i) 的情形。由 (ii) 的唯一性，整条轨道由 $f$ 的迭代唯一确定；到达 $\bot$ 时说明射线上再无任何洞，而 $x$ 严格单调增加，故之后不可能遇到任何洞。$\blacksquare$

**引理 2（$nxt[\cdot]$ 与配对方案无关）**
$nxt(i)$ 只依赖所有洞的坐标，不依赖 $mate$。故枚举全部 $(n-1)!!$ 个方案时 $nxt$ 只需预处理一次。

**证明**：$nxt(i)=\arg\min_j\{x_j:x_j>x_i\}$ 的量词只遍历坐标集合 $\{x_1,\dots,x_n\}$，表达式中不含 $mate$。配对改变时变动的只有 $f$ 的第二半 $mate\circ(\cdot)$。$\blacksquare$

**引理 3（循环起点存在 $\iff$ 函数图含环）**
固定 $mate$。"存在某个起点使 Bessie 无限循环" $\iff$ 有向图 $([n],\,i\to f(i))$ 中存在（有向）环。

**证明**：
($\Leftarrow$) 设环为 $i_1\to i_2\to\cdots\to i_k\to i_1$，即 $f(i_t)=i_{t+1}$（下标模 $k$）。取起点 $p$ 的横坐标满足 $x_{i_1}<x_p<x_{nxt(i_1)}$；纵坐标在读法 B 下取 $y_{i_1}$（此时 $y_{nxt(i_1)}=y_{i_1}$ 由 $nxt$ 的定义自动成立），在读法 A 下任意（因为 $nxt$ 不用 $y$）。由引理 1 的 (ii) 与 $\arg\min$ 的最小性，$p$ 向东碰到的第一个洞就是 $nxt(i_1)$：任何 $x\in(x_p,x_{nxt(i_1)})$ 上的洞都会满足 $x>x_{i_1}$ 且 $x<x_{nxt(i_1)}$，与 $nxt(i_1)$ 的定义矛盾。进入后从 $mate(nxt(i_1))=f(i_1)=i_2$ 出来，此后按环无限往复，且环上每步 $nxt$ 都存在（否则 $f$ 取值 $\bot$，不成环）。故起点 $p$ 合法，存在性得证。开区间非空由 $x_{i_1}<x_{nxt(i_1)}$（引理 1(ii) 的严格大于）保证。
($\Rightarrow$) 反设函数图无环。每个顶点出度至多 $1$，无环的有限功能图必然存在通向 $\bot$ 的路径，且图是一棵（些）反向往的树挂在 $\bot$ 上。任取起点 $p$，若从 $p$ 出发碰不到任何洞则早已逃逸；否则第一个碰到的洞记 $a$，进入后从 $mate(a)$ 出来，此后轨道即引理 1 中 $f$ 从 $mate(a)$ 开始的迭代。因图无环且顶点有限，迭代至多 $n$ 步必遇到 $\bot$（否则 $n+1$ 个状态两两不同，鸽巢原理矛盾）。遇 $\bot$ 后由引理 1(iii) 永不再进洞，轨迹有限，不循环。与"存在循环起点"矛盾。这一段证的是逆否命题："图无环 $\Rightarrow$ 不存在循环起点"，其逆否正是本方向要证的"存在循环起点 $\Rightarrow$ 图含环"。$\blacksquare$

> **机制小结**：几何被彻底消灭成"函数图判环"。剩下的只有两件事——**枚举所有完美匹配**，以及对每个匹配**判环**。

### 2.2 考虑简化版 —— 先吃掉 $n=2$

$n=2$ 时只有 $1$ 种配对（两洞必配在一起），所以答案只能是 $0$ 或 $1$，且完全由坐标决定。

**命题 1（$n=2$ 的完全分类）**
设两洞为 $A,B$。若 $x_A\ne x_B$，则唯一配对方案成环，答案 $=1$；若 $x_A=x_B$，答案 $=0$。

**证明**：
- 情形一 $x_A<x_B$：$nxt(A)=B$，$nxt(B)=\varnothing$。$f(A)=mate(nxt(A))=mate(B)=A$，即 $A$ 是环上的点，由引理 3 存在循环起点。给出具体起点：任取 $p=(x_0,y_A)$，$x_A<x_0<x_B$（区间非空因 $x_A<x_B$）。从 $p$ 向东第一个洞是 $B$，进入 $B$ 从 $A$ 出来，再向东又碰到 $B$……与题面第 3 段 $A(1,1),B(3,1)$、起点 $(2,1)$ 的例子一字不差。故成环。
- 情形二 $x_A>x_B$：对称，$f(B)=mate(nxt(B))=mate(A)=B$，同上成环（起点取两洞之间）。
- 情形三 $x_A=x_B$：两个集合 $\{j:x_j>x_A\}$、$\{j:x_j>x_B\}$ 都不含对方（$nxt$ 用**严格**大于），故 $nxt(A)=nxt(B)=\varnothing$，$f\equiv\bot$，任意起点至多进洞一次便逃逸；图无环，由引理 3 答案 $0$。$\blacksquare$

**引理 4（自环判据，充分条件）**
若存在洞 $i$ 使 $\{i,\,nxt(i)\}$ 恰好是 $mate$ 中的一对（即 $nxt(i)\ne\varnothing$ 且 $mate(i)=nxt(i)$），则 $f(i)=mate(nxt(i))=mate(mate(i))=i$，$i$ 是长度 $1$ 的环，方案必成环。

**证明**：按定义 $f(i)=mate(nxt(i))$；条件 $mate(i)=nxt(i)$ 与 $mate$ 是无不动点对合给出 $mate(nxt(i))=mate(mate(i))=i$。于是 $i\to i$ 构成长度 $1$ 的环，引理 3 的方向 ($\Leftarrow$) 立即给出结论。$\blacksquare$

**注意：引理 4 的逆命题不成立（成环不一定要相邻配对）**。具体小数据反例：$6$ 个洞按 $x$ 升序编号 $1..6$（$x_i=i$），配对取 $\{1,4\},\{2,5\},\{3,6\}$，**没有任何一对是相邻的**。逐点代入 $nxt(i)=i+1\,(i\le 5)$，$nxt(6)=\varnothing$：

| $i$ | $nxt(i)$ | $f(i)=mate(nxt(i))$ |
|---|---|---|
| 1 | 2 | $mate(2)=5$ |
| 5 | 6 | $mate(6)=3$ |
| 3 | 4 | $mate(4)=1$ |
| 2 | 3 | $mate(3)=6\to\bot$ |
| 4 | 5 | $mate(5)=2\to 6\to\bot$ |
| 6 | $\varnothing$ | $\bot$ |

$1\to 5\to 3\to 1$ 是长度 $3$ 的环，方案成环，却不含任何相邻对。所以**必须真的判环**，只数"相邻配对"会漏。

### 2.3 剖析"偷懒判据"为什么会失败

把题目读成 $n$ 步机器之后，很自然会想找一个"看一眼就知道"的判据。逐个试错。

**偷懒 1：只看"从最西边出发"的轨迹。**
反例（$4$ 洞共线，$x=1,2,3,4$，编号即 $x$ 序）：配对 $\{1,4\},\{2,3\}$。
从最西边出发：第一个碰到洞 $1$，从 $mate(1)=4$ 出来，$nxt(4)=\varnothing$，逃逸——看起来"不循环"。
但从 $x\in(2,3)$ 出发：进入 $3$，从 $mate(3)=2$ 出来，向东又碰到 $3$，再出来在 $2$……无限循环。
所以"最西起点不循环" $\not\Rightarrow$ "方案不成环"。题面第 5 段写的是 $\exists$ 位置，不是 $\forall$，也不是"某个特殊位置"。
（$n=2$ 的情形是这条反例的极端版：命题 1 说明唯一配对**必**成环，但成环的起点必须落在两洞**之间**，从最西边出发反而逃逸。）

**偷懒 2：只数"含有某对相邻洞 $(i,nxt(i))$ 成对"的方案。**
由引理 4，相邻对 $\Rightarrow$ 成环，所以这个判据不会误报（不多数）；但它**不充分**——2.2 表格末尾 $6$ 洞反例 $\{1,4\},\{2,5\},\{3,6\}$ 没有相邻对却有 $1\to5\to3\to1$ 的三元环，会被漏计。用具体数字看：若坐标就是 $x_i=i$，该方案按偷懒 2 得"不成环"，按引理 3 判环得"成环"，答案直接差 $1$。

**偷懒 3：用"$\forall$ 起点都循环"替代"$\exists$"。** 反例同偷懒 1 的方案 $\{1,4\},\{2,3\}$：起点取 $x>4$ 时永远碰不到洞，不循环。所以 $\forall$ 判据会把这个合法方案判成非法。

三者的共同病因：**成环是函数图 $([n],f)$ 的整体性质，不是某一条特殊轨道的性质**。正确的做法是穷举所有可能的"入口状态"——恰好只有 $n$ 个。

**引理 5（$n$ 步不死法则）**
固定 $mate$。函数图 $([n],f)$ 含环 $\iff$ 存在状态 $s$，使得 $s,f(s),f^2(s),\dots,f^{n-1}(s)$ 全部有定义（即连续 $n$ 步都不取到 $\bot$）。

**证明**：
($\Leftarrow$) 设存在这样的 $s$。则 $s,f(s),\dots,f^{n-1}(s)$ 是 $n$ 个值（都属于 $[n]$），再往前走一步得到 $f^{n}(s)$，它也是 $[n]$ 中的元素。$[n]$ 只有 $n$ 个元素，故 $n+1$ 项 $s,f(s),\dots,f^{n}(s)$ 中必有两项相等：$f^{a}(s)=f^{b}(s)$，$0\le a<b\le n$。取**间距 $b-a$ 最小**的那一对：由引理 1，$f$ 是函数（每个状态至多一个后继），若存在 $a\le c<d<b$ 使 $f^{c}(s)=f^{d}(s)$，则 $d-c<b-a$ 与最小性矛盾，故 $f^{a}(s),f^{a+1}(s),\dots,f^{b-1}(s)$ 两两不同；再由 $f$ 的确定性，$f^{a}(s)\to f^{a+1}(s)\to\cdots\to f^{b-1}(s)\to f^{b}(s)=f^{a}(s)$ 是长度 $b-a\ge1$ 的有向环。故图含环。
($\Rightarrow$) 设图含环 $C$，取 $s\in C$。环上每个点 $i$ 都满足 $f(i)$ 是环上另一点，特别地 $f(i)\ne\bot$；由归纳，对任意 $t\ge0$，$f^{t}(s)$ 仍在 $C$ 上且始终有定义。故连续走 $n$ 步（甚至任意多步）都不逃逸。$\blacksquare$

> 为什么步数恰好是 $n$：状态空间大小是 $n$，"$n+1$ 项必有重复"是鸽巢原理，$n-1$ 步不够（例如长度 $n$ 的 Hamilton 环，走 $n-1$ 步可以全是不同点而不暴露重复）；也不必须更多步，$n$ 步足以判定。这个 $O(n)$ 步的暴力代替了"DFS 找环 + 访问标记"，代码更短且不易错。

### 2.4 经典解法 —— 用"最小编号强制配对"枚举完美匹配

方案空间是 $\{1,\dots,n\}$ 的所有完美匹配。直接的做法（给洞 $1$ 选伴、再给洞 $2$ 选伴……按**顺序**枚举所有 $n!$ 排列再除以 $2^{n/2}\cdot(n/2)!$）容易重复计数，也麻烦。经典写法是**规范化每个匹配的表示**：

> 递归规则：在当前还未配对的洞中取**编号最小**的那个 $i$，枚举它的所有可能伙伴 $j>i$（$j$ 也取自未配对集合），配对后递归。

这样每个匹配对应**唯一**一条递归路径，不需要去重。

**引理 6（枚举计数 $=(n-1)!!$，且无重复无遗漏）**
设 $T(m)$ 为 $m$ 个元素的完美匹配个数（$m$ 偶）。上述递归恰好生成每个匹配一次，且 $T(m)=(m-1)\,T(m-2)$，$T(0)=1$，故 $T(m)=1\cdot3\cdot5\cdots(m-1)=(m-1)!!$。

**证明**：
- *递推式*：取编号最小的元素 $1$，它的伙伴可以是 $2,\dots,m$ 中任意一个，共 $m-1$ 种；一旦伙伴确定，剩下 $m-2$ 个元素自由配对，有 $T(m-2)$ 种。两步骤互不干扰且覆盖所有情况（每个匹配中 $1$ 必有唯一伙伴），故 $T(m)=(m-1)T(m-2)$。$T(0)=1$（空匹配唯一），$T(2)=1$ 与之吻合。
- *闭式*：展开 $T(m)=(m-1)(m-3)\cdots 3\cdot 1\cdot T(0)=(m-1)!!$。
- *无遗漏*：归纳。设 $M$ 是任一完美匹配，$i$ 是递归当前层未配对集合的最小元。$M$ 中 $i$ 的伙伴 $j$ 也必在未配对集合内（因为归纳假设已把 $M$ 中早先确定的对全部剥掉），且 $j>i$（$i$ 是最小元，$j\ne i$），故枚举循环会覆盖到 $j$ 这一步，递归继续 $M\setminus\{\{i,j\}\}$。
- *无重复*：反设同一匹配 $M$ 被两条不同路径生成，取两路径第一次分叉的那层，该层的最小未配对元 $i$ 相同（由已选对集合唯一决定），但两条路径给 $i$ 选了不同的伙伴 $j_1\ne j_2$。而 $M$ 中 $i$ 的伙伴唯一，故至多一个能扩成 $M$，矛盾。$\blacksquare$

**数值核对与代价**：$n=12$ 时 $T(12)=11\cdot9\cdot7\cdot5\cdot3\cdot1$，逐步代入 $11\times9=99$、$\times7=693$、$\times5=3465$、$\times3=10395$、$\times1=10395$。共 $10395$ 个叶子，每叶一次 `cyc()`（外层 $n$ 个起点、内层至多 $n$ 步 $=O(n^2)=144$），总 $\approx1.5\times10^6$；`build()` 仅 $144$。**$n\le12$ 的最坏情况就是这个数，不需要任何额外剪枝。**

### 2.5 归约到更简单问题

**归约 1：几何 → 序型。** 引理 1 里唯一用到坐标的是 $nxt$，而 $nxt$ 只用 $x_j>x_i$ 和 $\min$ 两种运算。

**引理 7（序型不变性）**
若两组数据 $\{x_i\}$ 与 $\{x_i'\}$ 满足"$x_i<x_j\iff x_i'<x_j'$ 且 $x_i=x_j\iff x_i'=x_j'$"（大小关系与相等关系完全一致），则对**每个**配对方案，两组数据的成环性相同，从而最终答案相同。

**证明**：由这个条件，对每个 $i$，集合 $\{j:x_j>x_i\}=\{j:x_j'>x_i'\}$ 相同；集合相等则其 $\min$ 元素按新下标看也相同（$\arg\min$ 只由该集合上的 $<$ 限制决定，而 $<$ 限制同构）。故 $nxt$ 表逐点一致。$f=mate\circ nxt$ 只由 $nxt$ 与 $mate$ 决定，同一个方案对应的 $mate$ 相同，故 $f$ 图同构，"含环"这一图性质相同；再由引理 3，成环性等价；求和亦相等。$\blacksquare$

> 直接推论：$4$ 个 $x$ 互异且共线的虫洞，无论坐标取 $(0,1,2,3)$ 还是 $(5,7,100,10^{9})$，答案都是同一个数。下一条引理把这个数算出来。

**归约 2：连续无限过程 → 有限图 → $n$ 步有界模拟。** 轨迹无限 $\xrightarrow{\text{引理 3}}$ 函数图含环 $\xrightarrow{\text{引理 5}}$ 存在存活 $n$ 步的起点。至此题目完全变成：枚举 $(n-1)!!$ 个对合 $mate$，对每个跑 $n^2$ 步。

**引理 8（$4$ 洞、$x$ 互异且共线时答案恒为 $2$）**
设 $4$ 个洞按 $x$ 升序为 $p_1,p_2,p_3,p_4$（$x$ 严格递增，且按题面主流读法只比 $x$）。三种完美匹配中恰两种成环，答案 $=2$。

**证明**：$nxt(p_i)=p_{i+1}\ (i=1,2,3)$，$nxt(p_4)=\varnothing$。逐一判定：
1. $\{p_1,p_2\},\{p_3,p_4\}$：$mate(p_1)=p_2=nxt(p_1)$，由引理 4（自环判据）成环。$\Rightarrow$ 计入。
2. $\{p_1,p_3\},\{p_2,p_4\}$：算全表 $f(p_i)=mate(nxt(p_i))$：
   $f(p_1)=mate(p_2)=p_4$；$f(p_2)=mate(p_3)=p_1$；$f(p_3)=mate(p_4)=p_2$；$f(p_4)=\bot$。
   四条轨道：$p_1\to p_4\to\bot$；$p_2\to p_1\to p_4\to\bot$；$p_3\to p_2\to p_1\to p_4\to\bot$。最长的一条只有 $3$ 次成功转移（$p_3\to p_2\to p_1\to p_4$，再一步遇 $\bot$），$3<n=4$，由引理 5 无环。$\Rightarrow$ 不计。
3. $\{p_1,p_4\},\{p_2,p_3\}$：$mate(p_2)=p_3=nxt(p_2)$，由引理 4 成环。$\Rightarrow$ 计入。

合计 $2$ 种。$\blacksquare$

> 这条引理同时解释了"样例解释里 $3,4$ 编号与输入顺序对调"这件事为什么不影响答案：引理 7 说答案只依赖序型与配对集合的**大小**，重编号只是给匹配换标签，三种匹配还是三种，成环的还是那两种。

### 2.6 溢出与实现细节的防护

- **坐标**：$0\le x,y\le 10^9<2^{31}-1=2147483647$，`int` 存得下。全流程只有 $x_j>x_i$、$x_j==x_{nxt[i]}$、$y_j<y_{nxt[i]}$ 三种**比较**，没有加减乘，因此不存在溢出路径。
- 即使写成差的形式 $x_j-x_i>0$，取值范围是 $[-10^9,10^9]$，仍在 `int` 内；但若改成比较欧氏距离平方 $(x_j-x_i)^2+(y_j-y_i)^2$，单项可达 $10^{18}$，`int` 必溢出，需要 `i64`（甚至 `__int128`）。**本题不需要**——只比 $x$ 大小即可，见引理 7。
- **答案**：上界 $T(12)=10395$，`int` 充裕，无取模。
- **递归深度**：`dfs` 最深 $n/2=6$ 层，栈无压力。
- **全局数组初值**：`nxt` 在 `build()` 里逐点显式赋 $-1$；`mate` 必须 `fill_n(mate,n,-1)`——全局 `int` 默认 $0$，而 $0$ 是合法下标，不初始化会把"洞 0"误当成已配对（这是"全局数组默认 0"陷阱的典型形态）。
- **哨兵**：$nxt[i]=-1$ 表示"东边无洞"，对应引理 1 的 $\bot$；代码里用 `!~nxt[i]` 判 $-1$（$\sim(-1)=0$），也可以直接写 `nxt[i]==-1`。

### 2.7 $y$ 的争议：两种读法辨析（本题唯一的真实歧义点）

题面说农场是**二维平面**，Bessie 沿 $+x$ 走且"方向不变"，那么严格物理化的读法是：

- **读法 A（主流，只看 $x$）**：$nxt(i)=\arg\min\{x_j:x_j>x_i\}$，与 $y$ 无关。
- **读法 B（同水平线才碰得到）**：$nxt(i)=\arg\min\{x_j:x_j>x_i \wedge y_j=y_i\}$。

**引理 9（两读法在一般二维数据上不等价）**
数据 $A=(0,0),B=(1,5),C=(2,0),D=(3,7)$（$n=4$）下，读法 A 的答案是 $2$，读法 B 的答案是 $1$。

**证明**：两种读法都要先算 $nxt$。$nxt$ 结果与配对无关（引理 2），故一张表用三次。
读法 A：$nxt(A)=B,\;nxt(B)=C,\;nxt(C)=D,\;nxt(D)=\varnothing$。三种匹配逐个算 $f(i)=mate(nxt(i))$，再按引理 5 看能否存活 $n=4$ 步：

| 方案 | $f$ 值 | 最长存活 | 成环 |
|---|---|---|---|
| $\{A,B\},\{C,D\}$ | $f(A)=mate(B)=A$ | $\infty$ | **是**（$A$ 自环） |
| $\{A,C\},\{B,D\}$ | $f(A)=mate(B)=D,\;f(D)=\bot$；$f(B)=mate(C)=A$；$f(C)=mate(D)=B$ | 轨道 $C\to B\to A\to D\to\bot$：$3$ 步 | 否 |
| $\{A,D\},\{B,C\}$ | $f(B)=mate(C)=B$ | $\infty$ | **是**（$B$ 自环） |

$\Rightarrow$ 答案 $=2$。

读法 B：同 $y$ 才可达。$A,C$ 同 $y=0$，$B$ 独占 $y=5$，$D$ 独占 $y=7$。故 $nxt(A)=C$，$nxt(C)=\varnothing$（$C$ 东边没有 $y=0$ 的洞），$nxt(B)=\varnothing$，$nxt(D)=\varnothing$。

| 方案 | $f$ 值 | 存活 | 成环 |
|---|---|---|---|
| $\{A,B\},\{C,D\}$ | $f(A)=mate(C)=D\to\bot$；其余点 $nxt=\varnothing$ | $\le1$ 步 | 否 |
| $\{A,C\},\{B,D\}$ | $f(A)=mate(C)=A$ | $\infty$ | **是**（$A$ 自环） |
| $\{A,D\},\{B,C\}$ | $f(A)=mate(nxt(A)=C)=mate(C)=B$，而 $nxt(B)=\varnothing$；$f(B)=f(C)=f(D)=\bot$ | $1$ 步 | 否 |

$\Rightarrow$ 答案 $=1$。两数不同，故两读法不等价。$\blacksquare$

**本文取读法 A，理由与代价**：

1. 题面给出的两个具体例子（$A(1,1),B(3,1)$ 与样例解释的四洞）**全部共线**，对 $y$ 不作任何区分，无法从题面判出读法 B；
2. 题面第 1 段只保证"没有两个虫洞处于同一位置"，若模型真是读法 B，$y$ 不同的洞在轨迹里等于"不存在"，题面理必要说明"同一水平线"，但它没有；加上这是 USACO Training Section 1.3 的老题，官方分析与绝大多数通过代码都把"下一个洞"按 $x$ 序（常写作 `next_on_right`）实现，判题输出即由此产生。

**代价声明（诚实）**：若判题数据中确实存在非共线的成环候选，读法 A 与 B 可能给出不同答案，本文无法在本地闭式验证（见 5 末尾"验证状态"）。切换到读法 B 的改动量是一行——`build()` 里把条件 `x[j]>x[i]` 换成 `x[j]>x[i]&&y[j]==y[i]`，其余全部逻辑（引理 1–6、枚举、判环）逐字不变，因为引理 3、5 只依赖"$nxt$ 是一个函数"而不依赖它怎么算。

**引理 10（共线时两读法一致）**
若所有洞 $y$ 相同，则读法 A 与读法 B 的 $nxt$ 表逐点相同。

**证明**：$y$ 全相等时约束 $y_j=y_i$ 恒真，故读法 B 的集合 $\{j:x_j>x_i\wedge y_j=y_i\}=\{j:x_j>x_i\}$ 即读法 A 的集合，$\arg\min$ 相同。$\blacksquare$

## 3. 模式总结（Pattern Summary）

按真实思考顺序，一条一个技巧，重复出现的同类步骤拆开列：

- 探索特殊机制 —— 用"刚出洞的编号"当状态，把连续几何运动压成有限集合上的函数迭代（方向不变是关键许可）。
- 消灭中间量 —— "走了多远"不影响结论，只保留事件序列，于是几何退化成一张 $nxt$ 表。
- 考虑简化版 —— 先解 $n=2$：唯一配对必成环，且成环起点只能落在两洞之间，这一步同时给出"起点存在性"的构造手法。
- 剖析偷懒判据失败 —— 把 $\exists$ 起点偷换成"最西起点/$\forall$ 起点"、把成环偷换成"含相邻对"，各配一个小反例，逼出"必须整体判环"。
- $n$ 步不死法则 —— 有限状态机上"能否无限存活" $\iff$ "能否存活 $|S|$ 步"（鸽巢原理），把无限问题变成有界模拟，省掉 DFS 找环。
- 对称性剪枝枚举 —— 每次强制"最小编号的未配对元素"配一个伙伴，正好数出 $(n-1)!!$ 个完美匹配，无重复无遗漏，免去去重与除法。
- 预处理与枚举解耦 —— 与方案无关的量（$nxt$）在枚举前算一次（引理 2）。
- 归约到更简单问题 —— 几何题 $\to$ 序型（引理 7）$\to$ 组合枚举 $\to$ 函数图判环，三层归约。
- 用闭式小结论校验 —— 先手算 $n=4$ 共线恒为 $2$（引理 8），作为整份代码的"锚点"。
- 溢出防护靠"只比较不算术" —— 意识到距离平方会到 $10^{18}$，从而刻意不引入任何算术。
- 全局数组哨兵必须显式初始化 —— `mate` 靠 `fill_n(...,-1)`，否则默认 $0$ 被当成合法下标。
- 读法歧义显式化 —— 把"$y$ 是否参与"写成单点可切换条件，并给出不等价反例与选择理由，而不是默默选一个。

## 4. 真实解法

### 4.1 符号表（每个符号存什么、怎么初始化）

| 符号 | 类型 | 存什么 | 初始化 | 一句记忆法 |
|---|---|---|---|---|
| `n` | `int` | 虫洞个数，$2\le n\le 12$ 偶数 | 读入 | — |
| `x[i],y[i]` | `int[mxn]` | 第 $i$ 个洞的坐标，$0$-based 下标 | 读入 | 只用于比较，永不参与算术 |
| `nxt[i]` | `int[mxn]` | 从洞 $i$ 出来向东**碰到的下一个洞**的下标；$-1$ 代表 $\bot$（逃逸） | `build()` 里逐点先置 $-1$ | next-on-right，与方案无关 |
| `mate[i]` | `int[mxn]` | 当前配对方案：$i$ 的伙伴下标；$-1$ = 未配对；递归中临时用 $mate[i]=i$ 作"已占用"占位 | `fill_n(mate,n,-1)` | match，一个无不动点对合（叶子处） |
| `ans` | `int` | 已成环的方案数 | 全局默认 $0$ | 累加器，上界 $10395$ |
| `rem` | `int`形参 | `dfs` 当前未配对个数 | 首调 `dfs(n)` | 到 $0$ 即一个完整方案 |
| `cur` | `int`局部 | `cyc()` 里轨道的当前状态 | 每轮 $=s$ | 模拟"刚从 cur 出来" |
| `alive` | `bool` | 该起点是否存活满 $n$ 步 | 每轮 $=true$ | 引理 5 的判据 |

`mxn{17}`：上界 $12$ 按"$+5$ 松弛"再往上取到 $17$，留出 $0$-based 与哨兵访问余量。

### 4.2 步骤

1. 读入 $n$ 与 $n$ 个坐标（洞编号 $0\dots n-1$，**不按 $x$ 重排**，因为 $nxt$ 自己会处理次序）。
2. `build()`：对每个 $i$ 扫描全部 $j$，取满足 $x_j>x_i$ 且 $(x_j, y_j)$ 字典序最小的 $j$ 作 $nxt[i]$；无解置 $-1$。（$O(n^2)$，只做一次，引理 2。）
3. `fill_n(mate,n,-1)`，调用 `dfs(n)` 枚举完美匹配：
   1. `rem==0`：方案完整，`ans+=cyc()`；
   2. 否则取最小 $i$ 使 `mate[i]==-1`，置 `mate[i]=i` 占位；
   3. 对每个 $j>i$ 且 `mate[j]==-1`：写 $mate[i]=j,\,mate[j]=i$，递归 `dfs(rem-2)`，回溯 `mate[j]=-1`（`mate[i]` 保持占位 $i$），循环结束后 `mate[i]=-1`。
4. `cyc()`：对每个起点状态 $s\in[0,n)$，令 $cur\leftarrow s$ 迭代 $n$ 次：若 $nxt[cur]==-1$ 判该起点失败；否则 $cur\leftarrow mate[nxt[cur]]$。某个起点走完 $n$ 次仍未失败即返回 `true`（引理 5）。
5. 输出 `ans`（整数，无精度设置）。

### 4.3 复杂度

- `build()`：$O(n^2)$。
- 方案数 $T(n)=(n-1)!!$（引理 6），每方案 `cyc()` 为 $O(n\cdot n)$（外层 $n$ 个起点，内层至多 $n$ 步，且命中 $\bot$ 提前 `break`）。
- 总计 $O\!\left(n^2+n^2\cdot(n-1)!!\right)$，$n=12$：$144\times10395\approx1.5\times10^6$ 次比较/赋值级操作。空间 $O(n)$。

### 4.4 正确性骨架（把引理串起来）

$$\text{题面"存在起点循环"}\underset{\text{引理 3}}{\iff}\text{图 }([n],f)\text{ 含环}\underset{\text{引理 5}}{\iff}\exists s:\text{存活 } n \text{ 步}\underset{\text{引理 1}}{\iff}《\texttt{cyc()} \texttt{返回 true}》$$

枚举侧：引理 6 保证 `dfs` 遍历的叶子与全部完美匹配**一一对应**，且每个叶子恰好调用一次 `cyc()`，故 `ans` $=$ 成环方案数，不重不漏。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;
using f64=double;

constexpr int mxn{17};                 // n<=12，+5 松弛约定
int n,x[mxn],y[mxn];
int nxt[mxn];                          // 从 i 出来再向东碰到的下一个虫洞，-1=碰不到
int mate[mxn];                         // 当前配对方案，-1=未配对
int ans=0;

void build()                           // nxt 只与坐标有关，算一次
{
	for(int i=0;i<n;++i)
	{
		nxt[i]=-1;
		for(int j=0;j<n;++j)
			if(x[j]>x[i]&&(!~nxt[i]||x[j]<x[nxt[i]]||(x[j]==x[nxt[i]]&&y[j]<y[nxt[i]])))
				nxt[i]=j;
		// cerr<<i<<' '<<nxt[i]<<'\n';	// 调试：打印 nxt 表（引理 2 说它与方案无关）
		// 严格读题（只有同一水平线才碰得到）时把上面条件改成 x[j]>x[i]&&y[j]==y[i]
	}
}

bool cyc()                             // 当前 mate[] 是否存在无限循环
{
	for(int s=0;s<n;++s)
	{
		int cur=s;
		bool alive=true;
		for(int step=0;step<n;++step)
		{
			if(nxt[cur]==-1)
			{
				alive=false;
				break;
			}
			cur=mate[nxt[cur]];         // 走到 nxt(cur) 并钻进去，从 mate 出来
		}
		if(alive)
			return true;                // n 步不死 => 必有环
	}
	return false;
}

void dfs(int rem)                      // rem=未配对个数
{
	if(!rem)
	{
		ans+=cyc();
		return;
	}
	int i=0;
	while(mate[i]!=-1)
		++i;                            // 最小未配对编号：去对称性
	mate[i]=i;                          // 占位，标记 i 已用
	for(int j=i+1;j<n;++j)
		if(mate[j]==-1)
		{
			mate[i]=j;
			mate[j]=i;
			dfs(rem-2);
			mate[i]=i;
			mate[j]=-1;
		}
	mate[i]=-1;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];
	fill_n(mate,n,-1);
	build();
	dfs(n);

	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **全局静态数组 + $0$-based**：`x,y,nxt,mate` 全全局；洞编号就是读入顺序，**不需要按 $x$ 排序**。主流写法"排序后令 $nxt(i)=i+1$"在 $x$ 并列时会把同 $x$ 的洞误当成可到达，本写法用严格 $x_j>x_i$ 扫全表，天然免疫（并列时按 $(x,y)$ 字典序最小取，保证确定性）。
- `mate[i]=i` 占位：递归中把"最小未配对点"标成已用，回溯时恢复；到叶子时 $mate$ 恰为无不动点对合。
- `ans+=cyc();` 用 `bool` 隐式转 `int`；`!~nxt[i]` 即 $nxt[i]==-1$（$\sim(-1)=0$），都是省字写法，写成 `if(cyc())++ans;` 与 `nxt[i]==-1` 更清楚但等价。
- `build()` 与 `dfs()` 解耦（引理 2）：坐标只用一次，枚举期间不再碰 $x,y$。
- 输出是整数，**不设 `setprecision`**（题面无精度要求）。
- 调试与切换：`// cerr<<i<<' '<<nxt[i]<<'\n';` 按习惯以注释保留，取消注释即可核对 $nxt$ 表；若采纳读法 B（2.7），把 `build()` 的条件改为 `x[j]>x[i]&&y[j]==y[i]`，其余一字不动。
