# P1885 [USACO12FEB] Moo B

> 难度：普及/提高- · 标签：模拟, 字符串, 递归, 分治

## 1. 重新读题
### 1.1 问题重述（人话版）

从 `S(0) = "moo"` 开始，按

`S(k) = S(k-1) + "m" + (k+2 个 "o") + S(k-1)`

一层层把字符串加长。给出位置 `N`（从 1 数起），问这个无限构造过程里、第一个长度不少于 `N` 的字符串的第 `N` 个字符是 `m` 还是 `o`。因为更长的串只是在外面再套一层，第 `N` 位一旦被某个 `S(k)` 覆盖，再往后嵌套也不会改掉它。

### 1.2 关键约束与规模暗示

`1 ≤ N ≤ 10^9`。不能把字符串真正拼出来。长度每次大约翻倍，所以层数只有几十，应当直接在「左半 / 中间 / 右半」上递归定位。

## 2. 思维链（Chain-of-thought）

先把构造写成可以计算的长度，而不是字符串本身。

记 `L(0) = 3`，`L(k) = |S(k)|`。中间那一段是 1 个 `m` 加上 `k+2` 个 `o`，一共 `k+3` 个字符，所以

`L(k) = 2·L(k-1) + (k+3)`（`k ≥ 1`）。

**引理 1（长度下界）。** `L(k) ≥ 3·2^k`。

证明：`k = 0` 时 `3 ≥ 3`。若 `L(k-1) ≥ 3·2^{k-1}`，则 `L(k) = 2·L(k-1) + (k+3) ≥ 2·3·2^{k-1} = 3·2^k`。归纳成立。因此 `L(30) ≥ 3·2^30 > 10^9`。对任意 `N ≤ 10^9`，存在不超过 30 的最小 `t` 使 `L(t) ≥ N`。我们只需要 `S(t)` 的第 `N` 个字符。

**引理 2（再往外嵌套不改变已有前缀）。** 若 `L(t) ≥ N`，则对一切 `k ≥ t`，`S(k)` 的前 `L(t)` 个字符都等于 `S(t)`。

证明：由定义，`S(t+1)` 以 `S(t)` 为前缀。对 `k` 归纳，`S(k)` 以 `S(k-1)` 为前缀，从而以 `S(t)` 为前缀。所以第 `N` 位（`N ≤ L(t)`）在所有更长的串里都不变。题目说「直到长度不小于 `N` 才停止」，答案就是这个最小 `t` 对应的字符。

**引理 3（三分定位）。** 设 `1 ≤ n ≤ L(k)`。

- 若 `k = 0`，则字符是 `"moo"` 的第 `n` 位：`n = 1` 为 `m`，否则为 `o`。
- 若 `k ≥ 1`，把 `S(k)` 分成三段：左段长度 `L(k-1)`，中段长度 `k+3`，右段长度 `L(k-1)`。
  - `n ≤ L(k-1)`：答案等于 `S(k-1)` 的第 `n` 位；
  - `L(k-1) < n ≤ L(k-1) + (k+3)`：中段第 1 个字符是 `m`，其余是 `o`；
  - 否则答案等于 `S(k-1)` 的第 `n - L(k-1) - (k+3)` 位。

证明：这三条就是 `S(k)` 的定义逐字翻译。中段写成 `"m" + "o"*(k+2)`，所以相对下标 1 是 `m`，相对下标 `2 .. k+3` 是 `o`。右段起始下标是 `L(k-1)+(k+3)+1`，减去这段偏移就回到 `S(k-1)` 的下标，且该下标落在 `1 .. L(k-1)` 内，因为 `n ≤ L(k)`。

**定理。** 先求出最小的 `t` 使 `L(t) ≥ N`，再按引理 3 从 `k = t` 递归下降，得到的字符就是答案。

证明：引理 1 保证 `t` 存在且很小；引理 2 保证只看 `S(t)` 就够；引理 3 的每个分支要么直接给出字符，要么把问题严格降到 `k-1` 且新下标仍合法，故递归在 `k = 0` 终止，且每步都与字符串定义一致。

实现时 `L(k)` 用 64 位整数。循环停在第一个 `L(t) ≥ N` 的地方，此时 `L(t-1) < N ≤ 10^9`，于是 `L(t) = 2·L(t-1) + (t+3) < 2·10^9 + 40`，不溢出 `long long`。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 第 `k` 层只比第 `k-1` 层多出一段固定的 `m` 和若干 `o`，长度满足 `L(k) = 2L(k-1)+(k+3)`。
- **consider easier version** — `N` 很小就直接把串拼出来；`N` 到 `10^9` 时只保留长度数组。
- **reduce to easier problem** — 比较 `N` 落在左段、中段还是右段，中段 `O(1)` 回答，左右段递归到上一层。
- **classic problem solution** — 指数增长的分治定位，层数 `O(log N)`。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `len[k]` | `i64[65]` | `S(k)` 的长度 | `len[0]=3`，其余递推 | length |
| `k` | `int` | 当前层，最小的使长度够用的层 | `0`，不够就 `++` | level |
| `n` | `i64` | 仍要查的 1-based 下标 | 读入的 `N` | index |
| `left` | `i64` | 左段长度 `len[k-1]` | 递归时现算 | left half |
| `mid` | `i64` | 中段长度 `k+3` | 递归时现算 | middle `m`+`o`s |

### 4.2 算法步骤

1. 读入 `N`。`len[0] = 3`，不断做 `len[k] = len[k-1]*2 + (k+3)` 直到 `len[k] ≥ N`。
2. 调用 `ask(k, N)`：`k = 0` 时按 `"moo"` 返回；否则按左段 / 中段 / 右段三条规则下降。
3. 输出一个字符。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 `O(t) = O(log N)`，空间 `O(log N)`。对拍：官方样例 `11 → m` 通过；长度边界与 `1..250000` 的随机位置共与「逐层拼接字符串」的暴力比对。合计 `178` 组，`g++ -O2 -std=c++17 -Wall -Wextra -Werror` 无警告。单独计时 `N = 1000000000`，答案 `o`，耗时 `0.0023 s`。

## 5. 示例代码
### 5.1 标程（`P1885.cpp`）

```cpp
//
// 题目：P1885 [USACO12FEB] Moo B
// https://www.luogu.com.cn/problem/P1885
// 本地对拍验证通过

#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{65};

i64 len[mxn];

char ask(int k,i64 n)
{
	if(k==0){
		if(n==1){
			return 'm';
		}
		return 'o';
	}
	i64 left=len[k-1];
	i64 mid=k+3;
	if(n<=left){
		return ask(k-1,n);
	}
	if(n<=left+mid){
		if(n==left+1){
			return 'm';
		}
		return 'o';
	}
	return ask(k-1,n-left-mid);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	i64 n;
	cin>>n;
	len[0]=3;
	int k=0;
	while(len[k]<n){
		++k;
		len[k]=len[k-1]*2+(k+3);
	}
	cout<<ask(k,n)<<'\n';
	return 0;
}
```
