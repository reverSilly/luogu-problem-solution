# P1826 猴子选大王数据再加强版

## 1. 重新读题

### 1.1 人话版

$n$ 只猴子围成一圈，顺时针编号 $1,2,\dots,n$。从第 $1$ 只开始，每次顺时针数恰好 $m$ 只猴子并让它出列，再从下一只猴子继续数，直到只剩一只，它成为大王。对每个 $n=a,a+1,\dots,b$ 分别求一次大王编号，统计每个编号当了多少次大王。输出：第一行最大的获胜次数，第二行所有达到该次数的编号（升序、空格分隔）。

### 1.2 关键约束与规模暗示

- $1\le a\le b\le10^6$，$m\le3000$。
- 有 $b-a+1$ 局游戏，每局都要一个答案。
- 如果对每个 $n$ 都用链表/数组模拟出列，单局 $O(nm)$，全体 $O(b^2m)$，完全不可行。
- $b\le10^6$ 且 $m$ 不大，提示存在**单局 $O(1)$ 递推**、$O(b)$ 扫完全部的做法。

---

## 2. 思维链（Chain-of-thought）

### 2.1 explore its property：先只考虑一局

先解决"给定 $n,m$，求大王"这个子问题。规则是标准约瑟夫环。

采用 **0 基编号**（$0,1,\dots,n-1$），设 $f(n)$ 为 $n$ 只猴子时获胜者的 0 基编号。

- 只剩 1 只时它一定获胜：$f(1)=0$。
- 从 $f(n-1)$ 推 $f(n)$：

第一步，从 0 号开始数，数到第 $m$ 只的编号是 $(m-1)\bmod n$，它出列。下一轮从编号 $m\bmod n$ 开始。

把剩下 $n-1$ 只猴子按"从 $m\bmod n$ 开始、顺时针"重新编号为 $0,1,\dots,n-2$。在这个新编号下，问题与"$n-1$ 只猴子、步长 $m$"完全相同，所以获胜者的新编号是 $f(n-1)$。

**引理 1（约瑟夫递推）**
$$
f(1)=0,\qquad f(n)=\bigl(f(n-1)+m\bigr)\bmod n\quad(n\ge2).
$$

**证明**：设新编号 $j$ 对应原编号
$$
\mathrm{pos}(j)=(s+j)\bmod n,\qquad s=m\bmod n .
$$
这确实是剩下 $n-1$ 只到原编号的一个双射：$j=0,\dots,n-2$ 遍历 $s,s+1,\dots,s+n-2$（模 $n$），恰好跳过被删掉的 $(m-1)\bmod n$（注意 $(s+n-1)\bmod n=(m+n-1)\bmod n=(m-1)\bmod n$）。新编号下的游戏与规模 $n-1$ 的原游戏逐步对应（人少了、起点变了，但"每次数 $m$ 个出列"的规则只依赖环形顺序），所以获胜者新编号为 $f(n-1)$。代回原编号得
$$
f(n)=\mathrm{pos}(f(n-1))=(m+f(n-1))\bmod n .
$$
$n=1$ 时没有出列，$f(1)=0$。$\blacksquare$

用题目样例的 $m=3$ 验证：$f(1)=0$；$f(2)=(0+3)\bmod2=1$；$f(3)=(1+3)\bmod3=1$；$f(4)=(1+3)\bmod4=0$；$f(5)=3$；$f(6)=0$；$f(7)=3$；$f(8)=6$；$f(9)=0$；$f(10)=3$。加一换成 1 基就是表中的 $1,2,2,1,4,1,4,7,1,4$，与题面一致。

### 2.2 一次扫完所有 $n$

**观察**：$f(n)$ 只依赖 $f(n-1)$ 和 $n$，从 $f(1)$ 开始逐步往后推即可。求 $[a,b]$ 内所有答案时，直接对 $n=1,2,\dots,b$ 递推，若 $n\ge a$ 就把 $f(n)+1$ 计入频次。

这样总共 $b$ 次 $O(1)$ 转移，$O(b)$。

### 2.3 统计与输出

用 `cnt[x]` 记录编号 $x$ 当大王的次数。扫完后取最大值 $mx$，第二行按 $x=1,\dots,b$ 升序输出所有 `cnt[x]==mx` 的 $x$。

**注意**：编号范围是 $1..n\subseteq1..b$，所以只需要开 $b+1$ 的数组；获胜次数最大为 $b-a+1\le10^6$，`int` 存得下。

---

## 3. 模式总结（Pattern Summary）

- **consider easier version** — 先只看一局：标准约瑟夫环。
- **explore its property** — 删掉第 $(m-1)\bmod n$ 只后，从 $m\bmod n$ 重新编号，规模 $n-1$ 的子问题与原问题同构。
- **classic problem solution** — 约瑟夫递推 $f(n)=(f(n-1)+m)\bmod n$，对 $n=1..b$ 线性扫一遍。
- **count and output** — 用频次数组统计，取最大值后升序输出。

---

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `a, b` | `int` | 需要计算的 $n$ 的区间 | 输入 | 区间 |
| `m` | `int` | 每次数的猴子数 | 输入 | step |
| `f` | `int` | 当前 $n$ 下的 0 基获胜编号 | $0$（对应 $n=1$） | Josephus |
| `cnt[x]` | `int [mxn]` | 编号 $x$ 当大王的次数 | 全 $0$ | count |
| `mx` | `int` | 最大获胜次数 | $0$ | max |

### 4.2 算法步骤

1. 读入 $a,b,m$。
2. `f=0`。
3. 对 $n=1,2,\dots,b$：
   - `f=(f+m)%n`；
   - 若 $n\ge a$，`++cnt[f+1]`。
4. 求 `mx=max(cnt[1..b])`，输出 `mx`。
5. 升序输出所有满足 `cnt[x]==mx` 的 $x$（空格分隔，行末换行）。

### 4.3 复杂度分析

- **时间复杂度**：$O(b)$，$b\le10^6$，常数极小。
- **空间复杂度**：$O(b)$（频次数组）。

## 5. 示例代码

```cpp
//
// 题目：P1826 猴子选大王数据再加强版
// https://www.luogu.com.cn/problem/P1826
// 与逐局模拟对拍通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005};

int a,b,m;
int cnt[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b>>m;
	int f=0;                       // f(n)：n 只猴子时 0 基获胜编号
	for(int n=1;n<=b;++n)
	{
		f=(f+m)%n;                 // n=1 时 (0+m)%1=0，仍是 f(1)=0
		if(n>=a)
			++cnt[f+1];
	}
	int mx=0;
	for(int i=1;i<=b;++i)
		mx=max(mx,cnt[i]);
	cout<<mx<<'\n';
	bool first=true;
	for(int i=1;i<=b;++i)
		if(cnt[i]==mx)
		{
			if(!first)
				cout<<' ';
			cout<<i;
			first=false;
		}
	cout<<'\n';
	return 0;
}
```
