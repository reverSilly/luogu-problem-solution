# P1849 [USACO12MAR] Tractor S

## 1. 重新读题

### 1.1 问题重述（人话版）

平面上有 $n$ 堆干草，坐标都是整点。拖拉机初始在整点 $(x_0,y_0)$，目标是回到原点 $(0,0)$。

- 拖拉机只能沿坐标轴方向移动（可以一次走若干整单位，但途中经过的每个整点都算"到达"）；
- 干草堆所在的点不能直接开进去；要进入某个有干草的点，必须先把那堆干草移走（每堆记一次）；
- 问最少移走多少堆干草。

### 1.2 关键约束与规模暗示

- $n\le 5\times10^4$，但所有坐标（起点、每堆干草）都满足 $1\le x,y\le 1000$。
- 坐标范围小、$n$ 大，说明"干草"只会在一个 $1000\times1000$ 的格点上重复/拥挤，而真正需要枚举的是**格点**，不是干草。
- 格点数约 $1001^2\approx10^6$。这暗示一个 $O(\text{格点数}\times4)$ 的图论最短路。
- 边权只会是 $0$ 或 $1$（进入空地花 $0$，进入干草花 $1$），这暗示 0-1 BFS。

---

## 2. 思维链（Chain-of-thought）

### 2.1 把"开车"翻译成"走格子"

拖拉机沿坐标轴走若干单位，实际经过的是一串**整点**：$(x,y)\to(x\pm1,y)$ 或 $(x,y\pm1)$，每步走一个单位。它不能"跨过"一个干草点而假装没经过——因为要沿轴连续移动，中间的点必须被占据。于是：

**建模**：在格点图上建图，每个整点是一个结点，四方向相邻连边。进入点 $v$ 的代价为

$$w(v)=\begin{cases}1,&v\text{ 上有干草},\\0,&v\text{ 为空地}.\end{cases}$$

答案 = 从 $(x_0,y_0)$ 到 $(0,0)$ 的最小代价路径。

**引理 1（模型等价）**

原问题的最优值等于上述格点图上的最短路长度。

**证明**：

- *任一合法行驶方案 → 一条格点路径*：把行驶轨迹按经过的整点依次列出，相邻整点四连通。方案中每移走一堆干草，恰好对应路径进入一个干草格一次（同一堆若被反复经过，只移走一次；但由于边权非负，最短路可以取无重复结点的简单路径，此时"进入次数 = 不同干草格数"）。
- *任一格点路径 → 一个合法行驶方案*：先把路径上所有干草格对应的干草移走，然后沿路径依次行驶即可，移走的堆数不超过路径进入干草格的次数。
- 因此二者的最小值相等。$\blacksquare$

### 2.2 为什么不是普通 BFS

如果只按"步数"做 BFS，会把"绕远但少移干草"的路排除掉。例如绕一大圈完全避开干草，步数很多但答案是 $0$；而直冲一步进入干草，步数少但答案是 $1$。所以必须按**代价**做最短路。

边权只有 $0/1$，用 **0-1 BFS**：代价 $0$ 的转移把结点压到队首，代价 $1$ 的压到队尾。

**引理 2（0-1 BFS 的正确性）**

用双端队列按上述规则维护，每次从队首取出结点并"定型"（不再更新），取出的距离是最终最短路。

**证明**：把双端队列看成 Dijkstra 的两个桶（距离 $d$ 和 $d+1$）。归纳假设：队首结点的距离是当前所有未定型结点中最小的。

- 若从队首 $u$ 走 $0$ 权边到 $v$，则 $dist(v)\le dist(u)$，压到队首不会破坏"从小到大"；
- 若走 $1$ 权边，则 $dist(v)\le dist(u)+1$，压到队尾也仍是当前的最大值；
- 由于 0 权压前、1 权压后，队列中的距离值至多相差 $1$，且单调不降，所以队首一定是全局最小的未定型距离。这正是 Dijkstra 的选择规则，故取出的距离是最终值。$\blacksquare$

### 2.3 搜索范围为什么可以取 $[0,1000]^2$

坐标轴 $x=0$ 与 $y=0$ 上没有任何干草（干草满足 $x,y\ge1$），并且它们一路通向原点——这是一条"免费高速"。

**引理 3（在 $[0,1000]^2$ 内搜就够）**

答案可以在只含格点 $0\le x,y\le1000$ 的图中求得。

**证明**（要点）：

1. 所有干草都在 $[1,1000]^2$ 内，盒子外面（$x>1000$ 或 $y>1000$ 或 $x<0$ 或 $y<0$）没有任何障碍。
2. 在无限格点图上，一个**有限**障碍集若能把起点与原点分开，则起点必被某个由干草组成的闭合环包围（平面分离定理：有限障碍只能围出有限个"洞"）。这样的环完全位于 $[1,1000]^2$ 内。
3. 因此无论走多远，要到达环外的原点，都必须**穿过**包围起点的每一层环，每穿过一层至少进入该层上的一个干草格，花费至少 $1$；而贴着环上某个干草格穿过去恰好花 $1$，这个下界可以达到。
4. 一旦穿出最外层环，就进入环外区域。由于所有环都不含 $x=0$ 或 $y=0$ 上的格子，矩形的这条自由的左边/下边始终位于环外，并且沿它可以不花代价走到原点。所以"穿出环之后"的部分完全可以在 $[0,1000]^2$ 内完成。

于是把任意一条越界路线中"在盒子外"的部分替换为"沿自由轴在盒子内走"，穿过环的层数不变、代价不增。故盒子内最短路 = 原问题最优值。$\blacksquare$

（实现上直接取 $C=1001$，下标 $0\dots1000$。）

### 2.4 具体流程

1. 读入 $n,x_0,y_0$，把每堆干草标进 `hay[x][y]=true`；
2. `dis` 全置 `inf`（全局数组默认是 $0$，**必须显式填**，否则 $0$ 会被当成可达的零代价状态）；
3. `dis[x0][y0]=0`，起点入队首；
4. 0-1 BFS：弹出队首，若已定型则跳过；否则定型，向四邻居扩展，代价为 `dis+ (hay?1:0)`，更优则更新并按权值压队首/队尾；
5. 输出 `dis[0][0]`。

### 2.5 失败尝试记录

- **按步数 BFS**：反例——干草围成一圈，绕外面走 $0$ 代价但步数多；按步数会选"穿墙"的路，答案错。
- **只把干草当结点建图**：会漏掉"在空地上任意转弯"的情形；格点图更直接。
- **忘记初始化 `dis`**：全局 `int` 默认 $0$，所有点都"可达且代价 $0$"，输出恒为 $0$。这是本风格文档特别强调的坑。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 连续沿轴行驶 = 在整点格上走四连通路径，进入干草格付 $1$。
- **consider easier version** — 若无干草，答案恒 $0$；困难在于"绕路换代价"。
- **classic problem solution** — 把问题化成 $0/1$ 边权网格图上的最短路。
- **classic problem solution** — 0-1 BFS（双端队列）$O(V+E)$。
- **explore its property** — 所有障碍在 $[1,1000]^2$ 内，自由坐标轴保证只需搜到 $1000$。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 干草堆数 | 读入 | $\le 5\times10^4$ |
| `sx, sy` | `int` | 拖拉机起点 | 读入 | start |
| `C` | `constexpr int` | 格点边长，取 $1001$ | $1001$ | 坐标 $0..1000$ |
| `hay[x][y]` | `bool [1001][1001]` | 该格是否有干草 | `false` | — |
| `dis[x][y]` | `int [1001][1001]` | 到该格的最小移草数 | 全 `inf` | distance |
| `vis[x][y]` | `bool [1001][1001]` | 是否已定型 | `false` | visited |
| `Q` | `deque<pair<int,int>>` | 0-1 BFS 双端队列 | 起点 | queue |
| `dx,dy` | `const int[4]` | 四方向 | — | — |

### 4.2 算法步骤

1. 读入 $n,sx,sy$；对每堆干草置 `hay[x][y]=true`。
2. `fill_n(&dis[0][0], C*C, inf)`，`dis[sx][sy]=0`，`Q.push_front({sx,sy})`。
3. 当队列非空：
   1. 取队首 $(x,y)$ 并弹出；若 `vis[x][y]` 则跳过；
   2. `vis[x][y]=true`；
   3. 对四个方向得到 $(nx,ny)$，越界则跳过；
   4. `nd=dis[x][y]+(hay[nx][ny]?1:0)`；若 `nd<dis[nx][ny]`，更新并按 `hay` 压队尾/队首。
4. 输出 `dis[0][0]`。

### 4.3 复杂度

- 结点数 $V=1001^2\approx1.0\times10^6$，边数 $E\approx4V$。
- 0-1 BFS 每个结点至多定型一次，摊还 $O(V+E)\approx4\times10^6$。
- 空间：`dis` 约 $4$ MB，`hay/vis` 各约 $1$ MB。

## 5. 示例代码

```cpp
//
// 题目：P1849 [USACO12MAR] Tractor S
// https://www.luogu.com.cn/problem/P1849
// 本地自测通过
#include<bits/stdc++.h>
using namespace std;

constexpr int C{1001};
constexpr int inf{1145141919};

int n,sx,sy;
bool hay[C][C];
int dis[C][C];
bool vis[C][C];
deque<pair<int,int>>Q;
const int dx[4]={1,-1,0,0},dy[4]={0,0,1,-1};

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>sx>>sy;
	for(int i=0,x,y;i<n;++i)
	{
		cin>>x>>y;
		hay[x][y]=true;
	}
	fill_n(&dis[0][0],C*C,inf);
	dis[sx][sy]=0;
	Q.push_front({sx,sy});
	while(!Q.empty())
	{
		auto[x,y]=Q.front();
		Q.pop_front();
		if(vis[x][y])
			continue;
		vis[x][y]=true;
		for(int d=0;d<4;++d)
		{
			int nx=x+dx[d],ny=y+dy[d];
			if(nx<0||nx>=C||ny<0||ny>=C)
				continue;
			int nd=dis[x][y]+(hay[nx][ny]?1:0);
			if(nd<dis[nx][ny])
			{
				dis[nx][ny]=nd;
				if(hay[nx][ny])
					Q.push_back({nx,ny});
				else
					Q.push_front({nx,ny});
			}
		}
	}
	cout<<dis[0][0]<<'\n';
	return 0;
}
```
