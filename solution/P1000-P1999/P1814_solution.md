# P1814 [ECNA 2001] 树的序号

## 1. 重新读题

二叉树按如下规则编号：

- 空树编号 $0$；只有根的树编号 $1$；
- 结点数少的树编号一定小于结点数多的树；
- 结点数相同时，按 $(L,R)$ 的字典序编号：$L,R$ 分别是左、右子树的编号。

给出 $n$（$1\le n\le5\times10^8$，多组数据，$n=0$ 结束），输出编号为 $n$ 的二叉树，格式为 `(L)X(R)`，某一侧为空则省略该侧的括号，例如只有左子树是 `(L)X`。

**规模暗示**：$n$ 高达 $5\times10^8$，不可能逐个枚举。但二叉树的个数（Catalan 数）增长极快：结点数不超过 $18$ 的二叉树总数就已超过 $5\times10^8$，所以答案的结点数 $m\le18$。这意味着「按结点数定位 + 按左右子树的块大小递归定位」就够了。

---

## 2. 思维链（Chain-of-thought）

### 2.1 数一数：$m$ 个结点的二叉树有多少棵

设 $C_m$ 为含 $m$ 个结点的二叉树棵数，约定 $C_0=1$（空树）。

**引理 1（Catalan 递推）**
$$C_m=\sum_{l=0}^{m-1}C_l\,C_{m-1-l},\qquad C_0=1.$$

**证明**：一棵 $m$ 个结点的二叉树由「根 + 左子树 + 右子树」唯一确定。设左子树有 $l$ 个结点（$0\le l\le m-1$），则右子树有 $m-1-l$ 个结点；左子树有 $C_l$ 种形状，右子树有 $C_{m-1-l}$ 种形状，且不同的 $(l,\text{左形状},\text{右形状})$ 给出不同的树。对所有 $l$ 求和即得递推。$\blacksquare$

由此可算出 $C_1=1,C_2=2,C_3=5,C_4=14,\dots$，并得到前缀和：

$$\mathrm{pre}[m]=\sum_{k=1}^{m}C_k .$$

数值（用于确认上界）：

| $m$ | $C_m$ | $\mathrm{pre}[m]$ |
| :---: | ---: | ---: |
| 15 | 9\,694\,845 | 13\,402\,696 |
| 16 | 35\,357\,670 | 48\,760\,366 |
| 17 | 129\,644\,790 | 178\,405\,156 |
| 18 | 477\,638\,700 | 656\,043\,856 |

$\mathrm{pre}[18]=656\,043\,856>5\times10^8$，所以 $m\le18$，`long long` 足够存下所有计数。

### 2.2 编号顺序到底长什么样

把「编号」记作 $\mathrm{idx}$。规则说：所有 $m$ 个结点的树排在所有 $m+1$ 个结点的树之前。因此**全局编号随结点数单调递增**：编号越小，树的结点数越少（或相同）。于是编号 $0$ 是空树，编号 $1$ 是唯一的 $1$ 结点树，编号 $2,3$ 是两棵 $2$ 结点树……

固定结点数 $m$。每棵树的编号由 $(L,R)$ 字典序决定。设左子树有 $l$ 个结点，则右子树有 $m-1-l$ 个结点。

**引理 2（块结构）**
把所有 $m$ 结点的树按编号排列，则它们被分成 $m$ 个连续块 $B_0,B_1,\dots,B_{m-1}$：

- $B_l$ 中所有树的左子树恰有 $l$ 个结点，右子树恰有 $m-1-l$ 个结点；
- $|B_l|=C_l\cdot C_{m-1-l}$；
- 块按 $l=0,1,\dots,m-1$ 的顺序排列；块内按「左子树编号升序，再右子树编号升序」排列。

**证明**：

先看 $B_l$ 里有多少对 $(L,R)$：左子树可取任意 $C_l$ 种形状，右子树可取任意 $C_{m-1-l}$ 种形状，两两组合都得到一棵不同的 $m$ 结点树，所以恰好 $C_lC_{m-1-l}$ 个。

再证这些块是连续且按 $l$ 升序排列的。比较两个合法的 $(L,R)$ 对：若 $L_1<L_2$，由于全局编号随结点数单调不减，$\mathrm{size}(L_1)\le\mathrm{size}(L_2)$，字典序先比较 $L$，所以 $L$ 小的整体在前。于是按 $L$ 从小到大扫过去，$L$ 的结点数 $l$ 只会不减；同一 $l$ 的所有 $L$（编号连续）配以同一套右子树编号，构成一个连续块；$l$ 递增就得到块 $B_0,B_1,\dots,B_{m-1}$。块内先比 $L$，$L$ 相同再比 $R$，即「$L$ 升序、再 $R$ 升序」。$\blacksquare$

块大小之和 $\sum_l C_lC_{m-1-l}=C_m$（引理 1），与总数吻合。

### 2.3 定位一棵树

1. **定位结点数 $m$**：找最小的 $m$ 使 $\mathrm{pre}[m]\ge n$。由全局编号 0 是空树，$m$ 结点树占据的编号区间是
   $$[\mathrm{pre}[m-1]+1,\ \mathrm{pre}[m]].$$
   于是它在 $m$ 结点树中的 0-based 名次为
   $$r=n-\mathrm{pre}[m-1]-1 .$$
2. **定位左子树大小 $l$**：依次令 $l=0,1,\dots,m-1$，若 $r\ge C_lC_{m-1-l}$ 就减去它并继续；否则 $l$ 就是答案，此时 $r$ 是块内名次。
3. **定位左右子树的名次**：块内是「$L$ 变化慢、$R$ 变化快」的行优先展开，所以
   $$L_{\text{local}}=\left\lfloor \frac{r}{C_{m-1-l}}\right\rfloor,\qquad
     R_{\text{local}}=r\bmod C_{m-1-l}.$$
   递归地用同样的方法构造左子树（$l$ 个结点、名次 $L_{\text{local}}$）和右子树（$m-1-l$ 个结点、名次 $R_{\text{local}}$）。$l=0$ 或 $m-1-l=0$ 时对应子树为空，直接省略。

**引理 3（递归正确）**
上述过程对每个 $1\le n\le\mathrm{pre}[18]$ 都返回一棵合法且唯一的树，且它正是编号 $n$ 的树。

**证明**：由引理 2，$r$ 落在唯一确定的块 $B_l$ 中，块内由行优先公式唯一确定 $(L_{\text{local}},R_{\text{local}})$；递归假设对更小结点数正确，则左右子树分别是块内该名次对应的唯一树；把根接上即唯一对应的 $m$ 结点树。归纳成立。$\blacksquare$

### 2.4 输出格式

递归拼串：

- $m=0$：空串（由调用者在括号里省略）；
- 左右都空：`X`；
- 只左空：`X(` + 右 + `)`；
- 只右空：`(` + 左 + `)X`；
- 都非空：`(` + 左 + `)X(` + 右 + `)`。

这与题面「`(L)X(R)`，一侧为空则省略」一致。

## 3. 模式总结（Pattern Summary）

- **count it** — $m$ 结点二叉树数满足 Catalan 递推（引理 1），$m\le18$。
- **explore its property** — 编号随结点数单调，因此固定 $m$ 后按 $(L,R)$ 字典序 = 先按左子树大小分连续块（引理 2）。
- **classic problem solution** — 用 Catalan 前缀和定位结点数，再用块大小 $C_lC_{m-1-l}$ 定位 $l$，块内行优先除法/取模定位左右子树名次。
- **recursion** — 对左右子树递归还原，按题面格式拼串。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `cat[i]` | `i64[30]` | $C_i$ | `cat[0]=1`，`cat[i]=cat[i-1]*(4i-2)/(i+1)` | Catalan |
| `pre[i]` | `i64[30]` | $\sum_{k=1}^{i}C_k$ | `pre[0]=0` | prefix |
| `n` | `i64` | 查询编号 | 逐行读入 | — |
| `m` | `int` | 树的结点数 | 最小的使 `pre[m]>=n` 者 | — |
| `r` | `i64` | 该结点数内的 0-based 名次 | `n-pre[m-1]-1` | rank |
| `l` | `int` | 左子树结点数 | 枚举 | left size |
| `rm` | `int` | 右子树结点数 | `m-1-l` | right size |
| `block` | `i64` | $C_l\cdot C_{rm}$ | 枚举时计算 | 块大小 |

### 4.2 算法步骤

1. 预计算 `cat[0..29]` 与 `pre[0..29]`。
2. 逐行读入 `n`，`n==0` 结束。
3. 找最小 `m` 使 `pre[m]>=n`；令 `r=n-pre[m-1]-1`。
4. 调用 `build(m,r)`：
   - 若 `m==0` 返回空串；
   - 对 `l=0..m-1`：`rm=m-1-l`，`block=cat[l]*cat[rm]`；若 `r>=block` 则 `r-=block` 继续；否则
     - `rl=r/cat[rm]`，`rr=r%cat[rm]`；
     - 递归 `build(l,rl)`、`build(rm,rr)`，按 2.4 的规则拼串并返回。
5. 输出该串。

### 4.3 复杂度

- 预处理 $O(30)$。
- 单次查询：定位 $m$ 与逐层分块共 $O(m)$ 层，每层拼串长度 $O(m)$，总计 $O(m^2)$；$m\le18$，可视为常数。
- 空间：递归深度与串长均为 $O(m)$。

## 5. 示例代码

```cpp
//
// 题目：P1814 [ECNA 2001] 树的序号
// https://www.luogu.com.cn/problem/P1814
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxm{30};

i64 cat[mxm],pre[mxm];

string build(int m,i64 r)
{
	if(m==0)
		return "";
	for(int l=0;l<m;++l)
	{
		int rm=m-1-l;
		i64 block=cat[l]*cat[rm];
		if(r>=block)
		{
			r-=block;
			continue;
		}
		i64 rl=r/cat[rm];
		i64 rr=r%cat[rm];
		string L=(l==0)?"":build(l,rl);
		string R=(rm==0)?"":build(rm,rr);
		if(L.empty()&&R.empty())
			return "X";
		if(L.empty())
			return "X("+R+")";
		if(R.empty())
			return "("+L+")X";
		return "("+L+")X("+R+")";
	}
	return "X";     // 不可达
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cat[0]=1;
	for(int i=1;i<mxm;++i)
		cat[i]=cat[i-1]*(4*i-2)/(i+1);
	pre[0]=0;
	for(int i=1;i<mxm;++i)
		pre[i]=pre[i-1]+cat[i];

	i64 n;
	while(cin>>n&&n)
	{
		int m=1;
		while(pre[m]<n)
			++m;
		i64 r=n-pre[m-1]-1;
		cout<<build(m,r)<<'\n';
	}
	return 0;
}
```
