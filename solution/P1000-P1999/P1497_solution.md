# P1497 木牛流马

> 标签：数学 · 难度：普及-

## 1. 重新读题

**本地题面（原文要点，逐条抄回）**

- 背景：$k$ 个木牛流马被放在一块大的 $n\times n$ 格子地板上，并且**都被染了色**。
- 缺陷（唯一的合法约束）："**两个不能在同一行或同一列**"。
- 输入：第一行 $n,k,h$（$n\le 20$，$h$ 为颜色的种数）；接下来 $h$ 行给出"每种颜色多少个"。
- 输出：合理布局情况**总数**。
- 提示一："不需要高精度"。
- 提示二："孔明规定在格子地板上**不能翻转**，也就是说如果两种布局在翻转后是一样的仍算两种"。

**问题重述（模型化）**

记第 $i$ 种颜色的个数为 $c_i$（$1\le i\le h$），题面语义要求 $\sum_{i=1}^{h}c_i=k$。

一个"布局"= 给 $n\times n$ 的每个格子指定一个颜色（或不放），使得

1. 颜色 $i$ 的格子恰有 $c_i$ 个（所有 $i$）；
2. 任意两个被占用的格子既不同行也不同列；
3. 空格子视为相同，同色木牛流马之间**不换标签**（染色板面上看不出区别）。

求满足 1、2 的板面染色方案数，且**不做**任何翻转/旋转等价类合并（提示二明确"翻转后一样仍算两种"）。

**读题分歧点（先声明，后面用论证裁决）**

| 分歧 | 读法 A | 读法 B | 本文取 |
|---|---|---|---|
| 同色的 $c$ 个是否可区分 | 不可区分（只看板面颜色） | 可区分（个体编号） | A |
| 翻转/旋转 | 不合并 | 合并（Burnside） | 不合并（题面明文） |
| $k$ 与 $\sum c_i$ 不一致 | 以 $k$ 为准 | 以 $\sum c_i$ 为准 | 判为 $0$（数据无此情形） |

**约束量级**：$n\le 20$、$k\le n$（下文引理 1 证明 $k>n$ 时无解）、$h$ 未给上界（合法数据里每种颜色至少 $1$ 个故 $h\le k\le20$，但允许 $c_i=0$ 的颜色，代码对此也安全，见 §2.7 C4）、$c_i\le n$。这是一个**极小数据规模的纯计数题**：不存在"算法复杂度瓶颈"，瓶颈全在**公式对不对**与**乘法会不会爆 long long**。

**样例情况**：本地题面**没有给出任何输入输出样例**，因此无法与官方答案对标；§4 的验证全部依赖手算枚举与自造边界用例（见 §4.5）。

## 2. 思维链（Chain-of-thought）

### 2.1 先把"合理"两个字抠清楚

第一反应是把 $n\times n$ 地板想成棋盘：一条"同一行"的限制 = 车的横向攻击线，一条"同一列"的限制 = 车的纵向攻击线。于是"两个不能在同一行或同一列"就是**国际象棋里 $k$ 个互不攻击的车**。这不是巧合，是本题的全部结构；染色只是给这些车加了一个"标签层"。

模型化以后，第一个要确认的是"这件事有没有可能做到"。

**引理 1（可行性上界）** 若 $k>n$，则合理布局数为 $0$。

**证明**：设存在一个合理布局。把"占用格子的行"记为映射 $f:\{$布局中的 $k$ 个木牛流马$\}\to\{1,\dots,n\}$，$f(x)=$ 木牛流马 $x$ 所在行号。由合法性条件，两个木牛流马不同行，即 $x\ne y\Rightarrow f(x)\ne f(y)$，故 $f$ 是**injective（单射）**。单射存在要求定义元数 $\le$ 值域元数，即 $k\le n$。逆否命题即：$k>n\Rightarrow$ 不存在合理布局，方案数为 $0$。同理，"列"也给出 $k\le n$。$\blacksquare$

> 这个引理在实现上的用处是：它给出一个**必须提前判掉**的分支，且它同时保证了计算过程中 $\binom{n-s}{t}$ 的下标不会非法（见 §4）。

**引理 2（占用的行/列必不重复，且数量恰为 $k$）** 任一合理布局恰好占据 $k$ 个不同的行与 $k$ 个不同的列。

**证明**：$k$ 个木牛流马两两不同行（合法性），故它们落在 $k$ 个互异的行上，行方向恰 $k$ 个；两两不同列同理。$\blacksquare$

引理 2 是后面"先选行、再选列、再配对"三段式拆法的依据：**行集合、列集合、以及行到列的双射**这三样东西合起来恰好决定了一组格子。

### 2.2 最省力特例：所有木牛流马同色

先完全不管颜色，只问"$n\times n$ 上放 $k$ 个互不攻击的（不可区分）车，有多少种摆法"。

**引理 3（无色的摆车数）** 记 $R(n,k)$ 为 $n\times n$ 棋盘上 $k$ 个两两不同行不同列的**无序**车的摆法数，则对 $0\le k\le n$ 有
$$R(n,k)=\binom{n}{k}^2 k!,$$
且 $k>n$ 时 $R(n,k)=0$。（约定 $R(n,0)=1$，即空布局。）

**证明**：分三步构造，并证明分解唯一。

*构造方向*：
1. 选被占用的行集合 $A\subseteq\{1,\dots,n\}$，$|A|=k$：$\binom{n}{k}$ 种；
2. 选被占用的列集合 $B$，$|B|=k$：$\binom{n}{k}$ 种；
3. 在 $A\times B$ 中选出一个"每行一个、每列一个"的格子集合，等价于给出一个双射 $\pi:A\to B$，占用格集为 $\{(a,\pi(a)):a\in A\}$：$k!$ 种。

这样得到的格集合显然两两不同行不同列，尺寸恰 $k$，是一个合法的无色布局。

*唯一性（不重不漏）*：反过来给定任一合法格集合 $S$（$|S|=k$），令 $A=\{a:\exists b,(a,b)\in S\}$、$B=\{b:\exists a,(a,b)\in S\}$。由引理 2 有 $|A|=|B|=k$；又 $S$ 中每行至多一个格子而共 $k$ 个格子，故每行**恰**一个格子，于是"把每行那个格子的列号赋给该行"给出良定义的 $\pi:A\to B$；每列恰一个格子保证 $\pi$ 是双射。因此 $(A,B,\pi)$ 由 $S$ 唯一决定，且构造把 $(A,B,\pi)$ 映回 $S$，两侧互逆成双射。

计数即三步相乘 $\binom{n}{k}^2 k!$。$k>n$ 时 $\binom{n}{k}=0$（亦即引理 1）。$k=0$ 时 $\binom{n}{0}^2\cdot 0!=1$，与空布局一致。$\blacksquare$

**手算校验（逐个列举）**

- $R(2,1)=\binom{2}{1}^2\cdot 1=4$：$2\times2$ 放 1 个车 = 4 个格子，对。
- $R(2,2)=\binom{2}{2}^2\cdot 2!=2$：只有两条对角线 $\{(1,1),(2,2)\}$、$\{(1,2),(2,1)\}$，对。
- $R(3,2)=\binom{3}{2}^2\cdot 2!=18$：换一种算法核对——第一个车有 $9$ 个格子；第二个车要避开与它同行的 $3$ 格、同列的 $3$ 格，这两组只重叠在"它自己那格"，故被禁 $3+3-1=5$ 格，可放 $9-5=4$ 格；于是**有序**对共 $9\times4=36$，每个无序格集合被数了 $2!=2$ 次，得 $36/2=18$，对。
- $R(3,3)=\binom{3}{3}^2\cdot 3!=6$：即 $3$ 阶置换矩阵个数 $3!=6$，对。

### 2.3 另一个极端：$k$ 个颜色各一个

再考虑最"多色"的一端：$h=k$，$c_1=\dots=c_k=1$，即 $k$ 个木牛流马颜色互不相同。

**引理 4（全异色）** 此时布局数 $F(n,k)=R(n,k)\cdot k!=\binom{n}{k}^2 (k!)^2=P(n,k)^2$，其中 $P(n,k)=\dfrac{n!}{(n-k)!}$ 为排列数。

**证明**：引理 3 的分解 $(A,B,\pi)$ 给出**位置集合** $S$。颜色互异时，给 $S$ 的 $k$ 个格子分配 $k$ 个不同颜色就是一个双射 $S\to\{$颜色集$\}$，共 $k!$ 种；不同双射给出不同板面（总有某格颜色不同）。反过来，任一全异色合法板面抹掉颜色就得到一个 $S$，故"抹颜色"映射的每根纤维大小恰为 $k!$，由乘法原理得 $R(n,k)\,k!$。

化简：$\binom{n}{k}^2(k!)^2=\left(\frac{n!}{k!(n-k)!}\right)^2(k!)^2=\left(\frac{n!}{(n-k)!}\right)^2=P(n,k)^2$。$\blacksquare$

$n=3,k=3$ 时 $P(3,3)^2=36$：$6$ 种置换矩阵 $\times$ $3!=6$ 种上色 $=36$，与 2.2 的 $R(3,3)=6$ 相容。

### 2.4 中间情形：除以 $\prod c_i!$ 到底对不对

现在有两端：同色 $\binom{n}{k}^2 k!$，全异色 $\binom{n}{k}^2 (k!)^2$。中间情形（给定多重集 $\{c_i\}$）的自然猜想是
$$F(n,k;\mathbf c)=\binom{n}{k}^2 k!\cdot\frac{k!}{\prod_{i=1}^{h}c_i!}=R(n,k)\times(\text{多重集合的排列数}).\tag{$\star$}$$

**猜想的动机（还不是证明）**：固定位置集合 $S$（$|S|=k$）后，"给 $S$ 染色且颜色 $i$ 恰用 $c_i$ 次"等于长度为 $k$、含 $c_i$ 个 $i$ 的序列数，即多项式系数 $\frac{k!}{\prod c_i!}$。两端分别对应 $\mathbf c=(k)$（该因子值 $1$）与 $\mathbf c=(1,\dots,1)$（值 $k!$），与 2.2、2.3 吻合。

但"吻合"只说明猜想没被两端否证。下面把它证成定理，并给出一个**具体反例说明一种会算错的拆法**。

**引理 5（分解的唯一性）** 把布局编码为 $\chi:\{1,\dots,n\}\times\{1,\dots,n\}\to\{0,1,\dots,h\}$（$0$ 表示空），合法条件为 $|\chi^{-1}(i)|=c_i$（$1\le i\le h$）且任意两个非零取值点不同行不同列。则
$$\chi\longmapsto\big(A,\,B,\,\pi,\,\chi|_{S}\big),\qquad S=\{(a,\pi(a)):a\in A\}$$
是"合法布局集"到"$\{$引理 3 的无色布局$\}\times\{$该 $S$ 上的多重染色$\}$"的双射。

**证明**：
- *良定义*：$\chi$ 合法，则非零格集合 $S$ 两两不同行不同列且 $|S|=\sum_i c_i=k$，故 $(A,B,\pi)$ 由引理 3 的存在唯一性决定；$\chi$ 在 $S$ 上的限制恰是一个含 $c_i$ 个 $i$ 的多重染色。
- *单射*：设 $\chi_1\ne\chi_2$，取 $(r_0,t_0)$ 使二者颜色不同。若 $(A,B,\pi)$ 已不同则像显然不同；否则 $S_1=S_2\ni(r_0,t_0)$，限制映射 $\chi|_S$ 不同，像仍不同。
- *满射*：任取无色布局 $(A,B,\pi)$ 与 $S$ 上的多重染色，令 $\chi$ 在 $S$ 上取染色值、其余格取 $0$。合法性逐条检查：不同行不同列由 $S$ 的位置结构保证；颜色 $i$ 的格数由多重染色的定义保证；非零格总数 $\sum_i c_i=k$ 自动成立。

三个方向都成立，故为双射，$(\star)$ 是定理。$\blacksquare$

化成便于估值的形式：
$$F(n,k;\mathbf c)=\frac{P(n,k)^2}{\prod_i c_i!}=\frac1{\prod_i c_i!}\left(\frac{n!}{(n-k)!}\right)^2.\tag{1}$$

**引理 6（整数性）** 对任何满足 $\sum_i c_i=k\le n$ 的 $\mathbf c$，$(1)$ 是整数。

**证明**：$\binom{n}{k}^2 k!$ 是整数（引理 3 的组合意义），$\frac{k!}{\prod c_i!}$ 是多项式系数亦整数（组合意义：把 $k$ 个有标号球放入 $h$ 个有标号盒子使第 $i$ 盒恰 $c_i$ 个，方案数即 $\frac{k!}{\prod c_i!}$，存在方案故为整数）。两者之积即 $(1)$，因为 $\frac{P(n,k)^2}{\prod c_i!}=\binom nk^2 k!\cdot\frac{k!}{\prod c_i!}$。$\blacksquare$

> 整数性带来一个实现分岔：按 $(1)$ 直接写代码要么先算 $P(n,k)^2$（可达 $5.9\times10^{36}$，反正得用宽类型），要么"一个一个除"。后者也**确实**是精确的（逐次除以 $c_i!$ 的部分商仍为整数，论证见 §4.4 坑位 3），但那是要额外证明的；下一条的 $(2)$ **天生不含除法**，逻辑上更省事，故取 $(2)$ 作实现形式。

**反例（$n=4,k=2$，具体小数据）**：真值
- $\mathbf c=(2)$：$R(4,2)\cdot\frac{2!}{2!}=72\cdot1=72$；
- $\mathbf c=(1,1)$：$R(4,2)\cdot\frac{2!}{1!1!}=72\cdot2=144$。

一种看似自然但**错误**的做法："先任选 $k$ 个格子 $\binom{n^2}{k}=\binom{16}{2}=120$，再乘颜色分配 $\frac{k!}{\prod c_i!}$"，得到 $120$ 与 $240$，两个都错。错因是 $\binom{16}{2}$ 里混进了同行/同列的非法格子对。逐条核对：$16$ 格选 $2$ 共 $120$ 组；非法组 $=$ 同行对数 $+$ 同列对数 $=\binom{4}{2}\times4+\binom{4}{2}\times4=24+24=48$；合法 $=120-48=72$ ✓ 恰等于引理 3 的 $R(4,2)=\binom42^2\cdot2!=36\cdot2=72$。这既否证了错误做法，也交叉验证了引理 3。

### 2.5 第二条路：按颜色逐种放置（望远镜消去）

$(\star)$ 已经够用，但它带除法。换一种**天生只做整数乘法**的拆法：按颜色编号顺序 $1,2,\dots,h$ 逐种放置，放第 $i$ 种颜色时，前 $s_{i-1}=c_1+\cdots+c_{i-1}$ 个行、列已经被更早的颜色占用。

**引理 7（逐色放置）** 记 $s_0=0$，$s_i=\sum_{j\le i}c_j$。则
$$F(n,k;\mathbf c)=\prod_{i=1}^{h}\left[\binom{n-s_{i-1}}{c_i}^{\!2} c_i!\right],\tag{2}$$
并且当 $s_h=k\le n$ 时它等于 $(1)$。

**证明**：

*第一步（组合意义）*。给定最终布局 $\chi$，按颜色把占用格集合分解成 $S=\chi^{-1}(1)\sqcup\cdots\sqcup\chi^{-1}(h)$。考察第 $i$ 步：$\chi^{-1}(i)$ 有 $c_i$ 个格子，两两不同行不同列，且不能与 $\bigcup_{j<i}\chi^{-1}(j)$ 共行共列。由引理 2，$\bigcup_{j<i}\chi^{-1}(j)$ 恰占 $s_{i-1}$ 个行与 $s_{i-1}$ 个列，所以第 $i$ 步的可选空间是"剩下的 $n-s_{i-1}$ 行 $\times$ 剩下的 $n-s_{i-1}$ 列"这个子棋盘，在其中放 $c_i$ 个同色无序车——正是引理 3 的 $R(n-s_{i-1},c_i)=\binom{n-s_{i-1}}{c_i}^2 c_i!$。各步独立（第 $i$ 步的可行选择数只通过 $s_{i-1}$ 依赖前面，不依赖具体形状，因为"删掉 $s$ 行 $s$ 列后的子棋盘与 $(n-s)\times(n-s)$ 棋盘在计数上同构"），乘法原理给出 $(2)$。

*第二步（反向唯一）*。反过来，任取一串合法的逐步放置，把第 $i$ 步的格子染成颜色 $i$：每种颜色 $i$ 恰 $c_i$ 个（构造即如此）；两两不同行不同列由"每步只从剩余行列中选"保证。故得到一个合法 $\chi$。且"先 $\chi$ 后分解、再逐步构造回去"显然回到 $\chi$；"先逐步构造、抹成 $\chi$、再分解回去"也回到原构造（每步的行集、列集与双射都能从最终板面上按颜色读出来）。两个方向互逆，$(2)$ 是被严格证明的等式而非启发。

*第三步（与 (1) 恒等，望远镜）*：
$$\binom{n-s_{i-1}}{c_i}=\frac{(n-s_{i-1})!}{c_i!\,(n-s_i)!}\ \Longrightarrow\ \binom{n-s_{i-1}}{c_i}^{\!2}c_i!=\frac{(n-s_{i-1})!^2}{c_i!\,(n-s_i)!^2}.$$
连乘并把阶乘项分拆：
$$\prod_{i=1}^{h}\frac{(n-s_{i-1})!^2}{(n-s_i)!^2}=\frac{(n-s_0)!^2}{(n-s_1)!^2}\cdot\frac{(n-s_1)!^2}{(n-s_2)!^2}\cdots\frac{(n-s_{h-1})!^2}{(n-s_h)!^2}=\frac{(n-s_0)!^2}{(n-s_h)!^2}=\frac{(n!)^2}{((n-k)!)^2},$$
中间每项分子与下一项分母完全相消（望远镜），故
$$\text{(2)}=\frac{(n!)^2}{((n-k)!)^2}\cdot\prod_{i=1}^h\frac1{c_i!}=\frac{P(n,k)^2}{\prod_i c_i!}=(1).\ \blacksquare$$

> (2) 是**最终实现形式**：每一项都是整数（有明确组合意义），从左到右累乘，全程无除法；望远镜结构顺带第二次证明了整数性（引理 6）。

**逐色放置的手算轨迹（$n=3,k=3,\mathbf c=(1,2)$）**：$s_0=0$：$\binom31^2\cdot1!=9$；$s_1=1$：$\binom22^2\cdot2!=1\cdot2=2$；积 $=18$。
- 用 (1) 校核：$P(3,3)^2/(1!\,2!)=36/2=18$ ✓；
- 用直接枚举校核：位置集合 $R(3,3)=6$ 个，每个集合上"1 红 2 蓝"的染色 $\frac{3!}{1!2!}=3$ 种，$6\times3=18$ ✓。
三路一致。

### 2.6 数值范围：为什么说"不需要高精度"

**引理 8（答案上界）** 在 $n\le20$ 下，任何合法输入的答数 $\le(20!)^2\approx5.919\times10^{36}$。

**证明**：由 (1)，$F=\dfrac{P(n,k)^2}{\prod c_i!}\le P(n,k)^2$，因分母 $\prod c_i!\ge1$。又 $P(n,k)=\prod_{j=0}^{k-1}(n-j)$，在 $0\le k\le n\le20$ 范围内：固定 $n$ 时 $P(n,k)$ 随 $k$ 不减（每多乘一个因子 $n-k\ge1$），固定 $k$ 时随 $n$ 不减（每个因子都不减），故最大值在 $k=n=20$ 取到，$P(20,20)=20!=2\,432\,902\,008\,176\,640\,000\approx2.433\times10^{18}$。于是 $F\le(20!)^2\approx5.919\times10^{36}$；等号在 $n=k=20$ 且所有 $c_i=1$（分母 $=1$）时达到，是**可达**上界而非松散估计。$\blacksquare$

对照整型范围：

| 类型 | 上限 | 是否够 |
|---|---|---|
| `int` | $2\cdot10^9$ | 否 |
| `long long` | $9.22\times10^{18}$ | 否（答案与中间量都可能超） |
| `__int128` | $1.70\times10^{38}$ | **够**，约为最坏答案的 $29$ 倍余量 |

中间量也要检查：(2) 的第 $i$ 项 $\binom{n-s_{i-1}}{c_i}^2 c_i!\le$ 累乘到该步的部分积 $\le$ 最终答案，因为各项 $\ge1$ 且累乘单调不减，所以**部分积永远不超过最终值**，只要用 `__int128` 存累乘结果就安全。但单项本身要防止在 `long long` 里先算出来再转型：例如 $\binom{20}{5}^2\cdot 15!=15504^2\times1.3077\times10^{12}\approx3.15\times10^{20}$ 已超 `long long`，故必须把**第一个乘数**就写成 `(__int128)`。

这正是题面"不需要高精度"的准确含义：不需要手写大整数/`string` 模拟，但**需要**比 `long long` 宽一档的 `__int128`。用 `long long` 会溢出 WA，写大整数类是过度设计。`__int128` 不能被 `cout<<` 直接输出，要自己按十进制逐位打（一个小递归）。

### 2.7 边界与分类清单（把"不重不漏"落到输入上）

| 编号 | 情形 | 处理 | 依据 |
|---|---|---|---|
| C1 | $k>n$ | 答 $0$ | 引理 1（单射/鸽笼） |
| C2 | 某个 $c_i>n$ | 必有 $\sum c_j>n$，归入 C1 | 引理 1 |
| C3 | $k=0$（$h=0$ 或所有 $c_i=0$） | 答 $1$（空布局） | 引理 3 约定 $R(n,0)=1$；(2) 为空积 $=1$ |
| C4 | 某个 $c_i=0$ | 该项 $\binom{m}{0}^2\cdot0!=1$，不改变答案 | (2) 逐项 |
| C5 | $\sum c_i\ne k$ | 题面自相矛盾，保守输出 $0$ | §1 分歧表第 3 行 |
| C6 | 翻转/旋转后相同 | **不合并**，仍算两种 | 题面提示二明文 |
| C7 | 同色个体互换 | 不产生新方案 | 引理 5（板面视角） |

C6 需要一个具体反例来压制"顺手 Burnside"的冲动。取 $n=2,k=1,h=1,c=(1)$：真值 $P(2,1)^2/1!=4$。
- 若把上下翻转（沿水平中线翻折）合并：$(1,1)\leftrightarrow(2,1)$、$(1,2)\leftrightarrow(2,2)$，答案塌成 $2$；
- 若再合并左右翻转（沿竖直中线翻折，$(1,1)\leftrightarrow(1,2)$）：四个格子进入同一轨道，继续塌成 $1$。

题面说"翻转后一样**仍算两种**"，所以 $4$ 正确，$2$ 与 $1$ 都是错读题。同理，$n=2,k=2,\mathbf c=(1,1)$ 的真值 $4$（两条对角线 $\times$ 每条 $2$ 种上色），若错误地按 $180^\circ$ 旋转合并，$\{(1,1)_A,(2,2)_B\}$ 会与其旋转像 $\{(2,2)_A,(1,1)_B\}$ 归并，得 $2$ 而不是 $4$——又是把题面明文否掉的合并。

C1/C2 在代码里的作用是**防止数组越界**：$\binom{n-s}{t}$ 的下标 $n-s$ 可能变负。实现中用"一旦发现 $s+t>n$ 就置不可行标志、不再访问组合数表"来同时满足 C1/C2 与越界安全。


## 3. 模式总结（Pattern Summary）

**模式名：非攻击车放置 + 多重着色（"选行—选列—配对—上色"四层分解）**

1. **"不同行且不同列" = 置换矩阵 = 部分置换（partial permutation）。**
   凡出现"两两不同行不同列/两两不共行共列/每行至多一个"这类约束，第一反应应该是：
   被占用行集 $A$、被占用列集 $B$、行到列的双射 $\pi$ —— 三步分解，答案 $\binom nk^{\!2}k!=P(n,k)\binom nk$。
   同一句话也解释了"为什么 $k>n$ 直接是 $0$"（引理 1 的单射论证）。

2. **带颜色/类型的计数：先数"形状"，再数"贴标签"。**
   形状层（哪些格子被占）与标签层（哪个格子是哪种颜色）可以**分离**，条件是标签只依赖格子而不引入新约束。
   于是答案 $=$ 形状数 $\times$ 多重排列数 $\frac{k!}{\prod c_i!}$。两端极端值（同色/全异色）用来快速自检。

3. **闭式里的除法：能免则免，改写成"按类逐种放置"的望远镜乘积。**
   $\frac{k!}{\prod c_i!}$ 作为整体是整数，但拆成逐步除法时要证明"每一步的部分商都整除"（见 §4.4 坑位 3 的 $m!\mid k!$ 论证）——这是一份额外的心智负担。
   免掉它的标准招：把对象按类别顺序放置，第 $i$ 类从剩余空间里选，得 $\prod_i\binom{\text{剩}}{c_i}^2 c_i!$，**每项都是一个具体子问题的方案数**，天生非负整数，望远镜消去后自动回到闭式。
   **"能写成纯乘积的组合恒等式优先"**——这是所有无模数计数题的通用保命招。

4. **题面里"不需要高精度"是范围提示，不是"int 够用"提示。**
   做法：先算答案的**可达上界**（引理 8 用极端输入代入），再对照类型上限表选 `__int128`；
   并且检查中间量与单项因子是否也超 `long long`（本题确实超），决定转型位置。
   `__int128` 需要手写十进制输出。

5. **"翻转/旋转仍算两种"= 明文禁止 Burnside/Pólya。**
   看到对称性描述要先判定它是"合并"还是"不合并"，方向搞反答案会差好几倍；
   不确定时用最小的 $n$（$2\times2$，$k=1$）手算两种读法的值，和题面措辞对号。

**可迁移题目族**：车多项式 / 部分置换计数（如"n 个车放 k 个互不攻击"）、多重集合排列、"带颜色限制"的棋盘放置、任何"答案是 $10^{19}\sim10^{38}$ 之间"的无模数计数。


## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 取值范围 | 在代码里 |
|---|---|---|---|
| $n$ | 地板边长 | $n\le 20$ | `n` |
| $k$ | 木牛流马总数 | $0\le k$（合法需 $k\le n$） | `k` |
| $h$ | 颜色种数 | 合法数据中 $0\le h\le k$；允许 $c_i=0$ | `h` |
| $c_i$ | 第 $i$ 种颜色的个数 | $0\le c_i\le n$，$\sum c_i=k$ | 循环变量 `t` |
| $s_i$ | 前 $i$ 种颜色的累计数 | $0=s_0\le s_1\le\cdots\le s_h=k$ | `s`（累加前缀） |
| $R(n,k)$ | 无色非攻击车摆法 | $\binom nk^2k!$ | 不单独出现 |
| $P(n,k)$ | 排列数 $n!/(n-k)!$ | $\le 20!\approx2.43\times10^{18}$ | 仅用于公式核对 |
| $F$ | 答案 | $\le(20!)^2\approx5.92\times10^{36}$ | `ans`（`__int128`） |
| $\binom ab$ | 组合数 | $0\le b\le a\le20$，$b>a$ 时视作 $0$ | `c[a][b]`（打表，未写格天然为 $0$） |
| $m!\ (m\le20)$ | 阶乘 | $\le 2.43\times10^{18}$ | `fac[m]`（`long long`） |
| 不可行标志 | C1/C2 触发 | $0/1$ | `bad` |

### 4.2 算法步骤（对应引理 7 的式 (2)）

1. **预处理组合数表**：杨辉三角 $c[i][j]=c[i-1][j-1]+c[i-1][j]$，边界 $c[i][0]=c[i][i]=1$，$i$ 到 $20$。最大元 $c[20][10]=184756$，`long long` 绰绰有余。下标越出三角形（$j>i$）的格子保持全局零初值，正好实现约定 $\binom ab=0\ (b>a)$。
2. **预处理阶乘表** `fac[0..20]`，`fac[20]` $=20!\approx2.43\times10^{18}$，仍在 `long long` 内。
3. **读入** $n,k,h$；置 `s=0`、`bad=0`、`ans=1`。
4. **逐种颜色循环** $i=1..h$，读入 $t=c_i$：
   1. 若 $s+t>n$ 则 `bad=1`（引理 1：行/列不够分），此后**跳过下面的乘法**，从而不会用负的 $n-s$ 去访问组合数表；但**仍继续读入**剩余行；
   2. 否则 `ans *= (__int128)c[n-s][t] * c[n-s][t] * fac[t]`，即乘上 $\binom{n-s_{i-1}}{c_i}^2 c_i!$；
   3. `s += t`。
5. **收尾判定**：若 `bad` 为真或 `s != k`（情形 C5）则 `ans = 0`。
6. **输出**：`printi128(ans)`，递归地把 `__int128` 按十进制逐位 `putchar`。

正确性：第 4 步每次乘的正是引理 7 连乘式的一个因子（此时剩余棋盘 $(n-s)\times(n-s)$），累乘到最后恰为 (2)，而引理 7 第三部分证明 (2)$=(1)$=引理 5 的布局数。第 5 步实现 C1/C2/C5。全流程只做整数乘法，无除法，故不存在"中间量不整除"的截断风险（引理 6 之后的注记）。

### 4.3 复杂度

- 时间：$O(n^2+h)=O(400+20)$，读入与乘法各 $O(1)$（`__int128` 乘 64 位常数在 GCC 下是两条 `imul`/`mul` 指令，视为 $O(1)$）。
- 空间：$O(n^2)$ 的组合数表 $25\times25\times8\approx5\,\text{KB}$ 加一个 $25\times8$ 阶乘表。
- 完全不构成瓶颈；本题的实际风险点只有"公式建模"与"位宽"两处。

### 4.4 实现坑位（都在这道题上真会踩）

1. **转型位置**：必须 `(__int128)c[n-s][t]*c[n-s][t]*fac[t]`，把转型放在**最左乘数**上。写成 `(__int128)(c[n-s][t]*c[n-s][t]*fac[t])` 是错的——括号内先在 `long long` 里算，例如 $n=20,s=0,t=15$ 时该项 $\binom{20}{5}^2\cdot15!\approx3.15\times10^{20}$ 已经溢出。
2. **不能用 `cout<<ans`**：`__int128` 无 `ostream` 重载，编译直接报错；只能手写十进制输出。
3. **闭式 (1) 的"逐步除"其实也是精确的，只是要多证一步**：设已经除过的颜色指标集为 $T$，$m=\sum_{i\in T}c_i\le k$，则
$$\frac{P(n,k)^2}{\prod_{i\in T}c_i!}=\underbrace{\frac{P(n,k)^2}{m!}}_{\in\mathbb Z}\times\underbrace{\frac{m!}{\prod_{i\in T}c_i!}}_{\in\mathbb Z}.$$
右二是多项式系数故整数；右一因为 $\frac{P(n,k)^2}{m!}=\binom{n}{k}^2\frac{(k!)^2}{m!}=\binom nk^2\,k!\cdot\frac{k!}{m!}$，而 $m\le k$ 保证 $m!\mid k!$。所以**任何顺序**的逐个除法都不截断，$(1)$ 同样是可实现的正确写法。
那本文为什么仍取 $(2)$？三条理由：① $(2)$ 每项自带组合意义（引理 7 的双射），完全不必动用上面这段整除论证，出错面更小；② $(2)$ 能边读输入边判定 C1/C2 并提前退出，$(1)$ 要等 $\sum c_i$ 汇总完才知道真正的 $k$；③ $(1)$ 必须先造出 $P(n,k)^2$ 这个可达 $37$ 位的中间量，**真正的坑**是"先在 `long long` 里算 $P(n,k)^2$ 再除"，V9/V10 给出了实测量级。分母 $\prod c_i!\le k!\le20!$（多项式系数 $\ge1$）本身不超 `long long`，"先把分母乘起来"不溢出，只是仍要用 `__int128` 做一次宽除法。
4. **`bad` 分支要"只跳过乘法、不跳过读入"**：$h$ 行必须全部读完，否则后续输入错乱（本题单组数据不至于 RE，但习惯要保留）。
5. **数组下标**：$n-s$ 可能为负（当 $s>n$），$t$ 可能 $>n$；`bad` 判断保证不访问非法下标。全局数组零初值让 $\binom{m}{t}\ (t>m)$ 自动为 $0$，但**不能**让 $m<0$。
6. **本题没有官方样例**（本地题面未给样例输入输出），所以无法用样例对标；下面 §4.5 是全部验证依据。同时未联网检索任何题解，公式、上界与边界处理均由本地题面推出。

### 4.6 如果没想到闭式：暴力/DP 路线，以及它为什么退化成 (2)

**暴力（只用来说明规模，$n\le4$ 才可行）**：按行扫描，每行"不放 / 放在第 $j$ 列并消耗某种尚有余量的颜色"，DFS 到底后计数。分支因子 $\le 1+n\cdot h=17$（$n=4,h=4$），深度 $n$，规模约 $17^4\approx8.4\times10^4$，手推得动；$n=20$ 完全不可行。暴力实现是按"哪个格子涂什么颜色"枚举的，天然不会重复计同色个体交换，与引理 5 的板面视角一致，所以它理应与 (2) 相等——这是**逻辑一致性检查**，不是本次执行过的实验（按任务禁令未编译未运行）。

**位掩码 DP**：`dp[r][mask][各颜色余量]`，$r\le20$、`mask` $2^{20}\approx10^6$、颜色余量维度 $\prod_i(c_i+1)$，状态数远超必要。但注意转移只依赖"还剩多少可用列" $n-s$，**不依赖具体是哪几列**（列之间完全对称，颜色同理），于是维度可以塌成两个标量："已被占用的行/列数"$s$ 与"当前颜色的个数 $t$"。塌完之后转移正好是
$$f(s,t)=\binom{n-s}{t}^{\!2}t!\cdot f(s+t,0),$$
与引理 7 的连乘 (2) 一字不差。**结论**：对本题，"想到闭式"与"想到 DP"是同一件事，差别只在写递归还是写循环；循环形态只需 $h$ 次乘法，故代码取循环。

**输出方式的选择**：`__int128` 无法直接 `cout`（无重载），也不该先压回 `long long`（答案可达 $5.9\times10^{36}$）。因此走 `printi128` 递归逐位 `putchar`。由于全程只用 C 风格输出、不用 `cout` 输出任何内容，`ios::sync_with_stdio(false)` 下不存在 C/C++ 流交错导致的乱序问题（呼应 §4.4 坑位 2）。

## 5. 示例代码

风格对照（依 `coding-style-guide.md`）：单一 `#include<bits/stdc++.h>`、无条件 `using namespace std;`、别名式 `using i64=long long;`、`constexpr int mxn{25}` 的"+5 松弛"尺寸、全局数组与全局 `ans`、`c`/`fac`/`bad` 电报式小写命名、Tab 缩进、运算符不加空格、单行小辅助函数 `printi128`、`cin.tie(nullptr)` 在前的固定顺序、输出用 `putchar`/`'\n'` 不出现 `endl`、保留注释掉的 `cerr` 调试行、文件尾以注释形式保留核对数据。

```cpp
// https://www.luogu.com.cn/problem/P1497
// 普及- / 数学：非攻击车放置 × 多重上色；逐色整数乘法（无除法）；答案可达 (20!)^2 => __int128
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{25};

i64 c[mxn][mxn],fac[mxn];

int n,k,h,s,bad;
__int128 ans=1;

void printi128(__int128 x)
{
	if(x<0)
		putchar('-'),x=-x;
	if(x>9)
		printi128(x/10);
	putchar(int('0'+x%10));
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	c[0][0]=1;
	for(int i=1;i<=20;++i)
	{
		c[i][0]=c[i][i]=1;
		for(int j=1;j<i;++j)
			c[i][j]=c[i-1][j-1]+c[i-1][j];	//三角形外保持0 => C(a,b)=0 (b>a)
	}
	fac[0]=1;
	for(int i=1;i<=20;++i)
		fac[i]=fac[i-1]*i;
	cin>>n>>k>>h;
	for(int i=1,t;i<=h;++i)
	{
		cin>>t;
		if(s+t>n)
			bad=1;	//引理1：行（列）不够分 => 无解，同时避免 n-s 为负越界
		if(!bad)
			ans*=(__int128)c[n-s][t]*c[n-s][t]*fac[t];	//逐色放置，全程只做整数乘法
		s+=t;
	}
	if(bad||s!=k)
		ans=0;	//s!=k：题面 k 与各颜色个数不自洽
	printi128(ans);
	// cerr<<s<<' '<<k<<' '<<bad<<'\n';
	return 0;
}

//本地题面无官方样例；下面是自造核对数据（输入 -> 期望输出，逐条手算见 §4.5）
//1 1 1 / 1          -> 1
//2 1 1 / 1          -> 4
//2 2 1 / 2          -> 2
//2 2 2 / 1 / 1      -> 4
//3 3 2 / 1 / 2      -> 18
//4 2 2 / 1 / 1      -> 144
//4 2 1 / 2          -> 72
//3 4 1 / 4          -> 0
//5 0 0              -> 1
//20 15 2 / 5 / 10   -> ≈9.4394e23（28844881920*32724551059200，超 long long）
//20 20 1 / 20       -> 2432902008176640000
//20 20 20 / 1×20    -> (20!)^2 ≈ 5.919e36
```
