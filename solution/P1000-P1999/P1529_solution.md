# P1529 [USACO2.4] 回家 Bessie Come Home

> 标签：图论 · USACO · 最短路 · Floyd 算法 · 难度：普及/提高-
> 本地题面：`P1529.md`（$P\le10^4$ 条道路，单条长度 $\le10^3$；牧场标号为 `a`–`z` 与 `A`–`Y`，谷仓标号为 `Z`）。验证：本地对拍 300 组随机连通图 std==brute 全部通过；USACO 经典样例输出 **`B 11`**；$P=10000$ 最坏规模实测 **0.0049s**。

## 1. 重新读题

**问题重述（人话版）**

牧场之间由若干条（可能重复、可能自环）无向道路相连，每条道都有长度。牧场用字母编号：小写 `a`–`z` 里**没有**牛，大写 `A`–`Y` 里**各有一头**牛，谷仓固定是 `Z`（谷仓里没有牛）。所有牛同时、以相同速度、沿**最短路径**走向谷仓。问**最先**到谷仓的那头牛所在的牧场标号，以及它走的路径长度。

一句话版本：**在一张无向带权图上，求"离节点 `Z` 最近的、属于 `A`–`Y` 的节点"及其到 `Z` 的最短路长度。**

**题面里容易漏掉的条款**

1. 「牧场标记为 `a`…`z` 和 `A`…`Y`；`Z` 是谷仓」⇒ 全图**只有 52 个**可能的标号节点；有牛的只有 25 个（`A`–`Y`）。
2. 「**`m` 和 `M` 不是同一个牧场**」⇒ 大小写是两个独立节点，映射函数要分别处理，不能 `tolower` 合并。
3. 「两个牧场之间可能有**超过一条**道路」⇒ 必须是**重边取最小**，而不是简单覆盖或累加。
4. 「可能包括**自己**」（自环）⇒ 需容忍 `u==v` 的边，不要让自环破坏最短路。
5. 「测试数据中总有且只有一只最快的母牛」⇒ 答案唯一，不存在并列，输出格式固定为"字母 空格 长度"。
6. 「至少有一个牧场和谷仓之间有道路连接」且"所有母牛都能到达谷仓"⇒ 至少一头牛可达，答案必存在。

**数据范围与规模感受**

$$P\le10^{4},\quad \text{单条道路长度}\le10^{3}.$$

注意关键点：**图的规模与 $P$ 无关**——节点最多 52 个，边虽然可以多达 $10^4$ 条，但任何简单最短路的长度不超过 $51\times1000=51000$（至多 51 条边），$32$ 位 `int` 绰绰有余。节点数这么小，**全源最短路（Floyd）** 天然合适：$52^3\approx1.4\times10^{5}$，比一次最短路还便宜，还顺带把所有牛到谷仓的距离一次算全。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把叙述翻译成图论语言

题目全是"牧场、道路、母牛、谷仓"的故事，先剥离背景。

- **节点**：52 个标号（`a`–`z`→$0..25$，`A`–`Y`→$26..50$，`Z`→$51$）。
- **边**：读入的每条道路是一条无向边，权为长度；允许重边与自环。
- **"同时出发、速度相同、走最短路径"** ⇒ 每头牛的到达时间正比于它到谷仓的最短路长度。

**引理 1（"最先到达"⇔"到谷仓最短路最短"）**

设第 $k$ 头牛的出发牧场为 $c_k$，速度均为 $v$，各自走最短路径。则它到达谷仓的时刻为 $t_k=\dfrac{d(c_k,Z)}{v}$，其中 $d$ 为最短路径长度。于是到达次序完全由 $d(c_k,Z)$ 决定，"最先到达者"就是使 $d(c_k,Z)$ 最小的牛。

**证明**：速度相同，故时间 $=$ 路程$/v$；"走最短路径"意味着路程取最小可能值 $d(c_k,Z)$。$1/v>0$ 是公共正常数，对所有牛相同，所以比较 $t_k$ 等价于比较 $d(c_k,Z)$。$\blacksquare$

> 这一步把"时间比较"整体消掉，只剩**同一个标量** $d(\cdot,Z)$ 的比较。

### 2.2 归约：问题等价于"全源最短路 + 一次取最小"

**引理 2（答案形式）**

$$\text{Ans}=\big(c^\star,\ d(c^\star,Z)\big),\qquad c^\star=\arg\min_{c\in\{A,\dots,Y\}} d(c,Z).$$

**证明**：候选牛恰是 `A`–`Y` 这 25 个节点（谷仓 `Z` 里没有牛，`a`–`z` 里也没有牛，引理 1 已把"最先"归于 $d$ 的最小值）。在候选集上取 $d(\cdot,Z)$ 最小者即得。由题面保证唯一，故 $c^\star$ 良定义。$\blacksquare$

于是只需一张覆盖全部 52 个节点的**最短距离矩阵**，答案读取 $d$ 的对应行即可。多源、单源都行，索性**全源**最简单。

### 2.3 经典技术：Floyd–Warshall 全源最短路

$n=52$ 极小，直接 Floyd：三层循环 $k,i,j$，`d[i][j]=min(d[i][j],d[i][k]+d[k][j])`。

**引理 3（Floyd 正确性）**

Floyd 结束后 $d[i][j]$ 等于 $i\to j$ 的最短路径长度。

**证明**（经典 DP 归纳）：令 $d^{(k)}[i][j]$ 表示"允许中转点取自 $\{0,\dots,k-1\}$ 时 $i\to j$ 的最短路"。归纳假设第 $k$ 轮开始时数组即 $d^{(k)}$。
- 基例 $k=0$：只允许直边，正好是初始的邻接矩阵（$d[i][i]=0$、有边则权、无边则 $\infty$）。
- 归纳步：从 $d^{(k)}$ 得到 $d^{(k+1)}$。任何以 $\{0..k\}$ 为允许中转点的路径，要么根本不经过 $k$（值为 $d^{(k)}[i][j]$），要么经过 $k$ 一次（可拆成 $i\to k\to j$，且两段都只用 $\{0..k-1\}$，值为 $d^{(k)}[i][k]+d^{(k)}[k][j]$；因权非负且最短路不会重复经过 $k$，可假设只经过一次）。故
  $$d^{(k+1)}[i][j]=\min\big(d^{(k)}[i][j],\ d^{(k)}[i][k]+d^{(k)}[k][j]\big),$$
  即循环体所做的事。
- $k$ 取遍全部节点后 $d^{(n)}=d$。$\blacksquare$

**引理 4（无穷大相加不外溢）**

初始 $d[i][j]=\infty\;(=1145141919)$ 时，$d^{(k)}[i][k]+d^{(k)}[k][j]$ 可能接近 $2\infty$，超过 `int` 上限 $2147483647$ 造成溢出。故松弛前须加判断"两段都有限"。

**证明**：$1145141919\times2=2290283838>2147483647$，确实溢出（有符号溢出是未定义行为）。只要在"$d[i][k]<\infty$ 且 $d[k][j]<\infty$"成立时再做加法与比较，就不会产生溢出的中间量；而任一为 $\infty$ 时该"经过 $k$ 的路径"本就不可达，无需松弛。$\blacksquare$

### 2.4 边界与体检

- **重边**：读入时 `if(w<d[u][v])` 取最小。
- **自环**：$u=v$ 时 $d[u][u]$ 初始为 $0\le w$，不会把最短路改小，自动忽略。
- **不连通的牛**：$d[c][Z]=\infty$，不可能成为最小值（题面保证至少一头连通，故最小值有限）。
- **答案距离适合 `int`**：最短路 $\le51\times1000=51000$，远小于 `int` 上限。

## 3. 模式总结（Pattern Summary）

**模式名：小规模图上的「叙述→最短路建模 + 全源 Floyd + 候选集取最小」。**

**识别信号**：题目用故事描述一张**节点数很小**（几十个）的带权无向图，问"某类节点到指定节点的最近者"。

**可复用套路（按真实思考顺序）**：

- **explore its property** — 把"同速、同时、走最短路、最先到"翻译成"到汇点的最短路长度最小"（引理 1）。
- **reduce to easier problem** — 时间比较退化为单一标量 $d(\cdot,Z)$ 的比较，问题变成一次 argmin（引理 2）。
- **classic problem solution** — 节点数极小 ⇒ 用 **Floyd 全源最短路**一次算全（引理 3），省去多源/多次最短路。
- **discuss by category** — 只扫有牛的 `A`–`Y` 候选集；不连通牛（$\infty$）自动淘汰；重边取最小、自环忽略。
- **guard the sentinel arithmetic** — $\infty+\infty$ 会溢出 `int`，松弛前判"两端皆有限"（引理 4）。
- **constant-bounds check** — 先估最短路上界 $51\times1000$，确认 `int` 够用再动手。

**同族题**：USACO 2.4 系列；一切"给定小图求某某最短路/最近点"的题（如 P2419 牛的比赛、传递闭包类题）都可套 Floyd。

**一句话记忆**：故事图节点少 ⇒ 建 52 节点的邻接矩阵跑 Floyd，再在候选节点上取最小。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| `nn` | `constexpr int` | 节点总数 | $52$ | $26+25+1$ |
| `inf` | `constexpr int` | 不可达哨兵 | $1145141919$ | 114514 家族 |
| $P$ | `int P` | 道路条数 | 读入 | 题面 |
| $d[u][v]$ | `int dis[52][52]` | $u\to v$ 最短距离 | 对角线 $0$、其余 `inf` | Floyd 状态（引理 3） |
| `id(c)` | 函数 | 字符→标号 | — | `a`→$0..25$，`A`→$26..50$，`Z`→$51$ |
| `best` | `int` | 候选中的最小距离 | `inf` | argmin 累加器 |
| `bi` | `int` | 取得最小距离的牛所在节点 | $-1$ | 用于回推字母 |

### 4.2 编号步骤

1. 读入 $P$；初始化 $d$：$d[i][i]=0$，其余 `inf`。
2. 对每条道路：`cin>>a>>b>>w;`，`u=id(a),v=id(b)`；若 $w<d[u][v]$ 则 `d[u][v]=d[v][u]=w`（无向 + 重边取最小）。
3. Floyd：`for k, for i, for j`：若 $d[i][k]<\infty$ 且 $d[k][j]<\infty$ 且 $d[i][k]+d[k][j]<d[i][j]$，则更新（引理 3、4）。
4. 扫描 `i=26..50`（即 `A`–`Y`），取 `d[i][51]` 最小者，记录 `best` 与 `bi`。
5. 输出 `char('A'+bi-26)` 与 `best`，用空格分隔，换行。

### 4.3 复杂度

- 时间：读入 $O(P)$，Floyd $O(52^3)\approx1.4\times10^{5}$，扫描 $O(25)$。
- 空间：`int dis[52][52]` $\approx11$ KB。
- 实测：$P=10000$ 最坏规模实测 **0.0049s**（Floyd 与 $P$ 无关，读入为主）。

### 4.4 关键不变量

1. Floyd 后 $d[u][v]$ 为真最短距离（引理 3）。
2. $d[u][u]=0$ 恒成立（自环不破坏）。
3. 候选最小值 `best` 有限（题面保证至少一头牛连通）。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| USACO 经典样例 | **通过**：`A d 6 / B d 3 / C e 9 / d Z 8 / e Z 3` $\to$ `B 11` |
| 随机数据对拍 | **通过**：300 组随机连通小图，Floyd 版与 **Bellman-Ford** 版输出**逐字节一致** |
| 边界用例 | **通过**：重边取最小、自环、大小写区分（`m`≠`M`）均在随机图中覆盖 |
| 最坏规模计时 | $P=10000$ 随机边 $\to$ 输出形如 `O 6`，耗时 **0.0049s** |
| 残余风险 | 若出现并列最短路，本解按 `A`–`Y` 顺序取首个最小；题面保证无并列，故不影响 |

## 5. 示例代码

### 5.1 主解：Floyd 全源最短路（与 `appendix/P1529/P1529.cpp` 逐字节一致）

```cpp
//
// 题目：P1529 [USACO2.4] 回家 Bessie Come Home
// https://www.luogu.com.cn/problem/P1529
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int nn{52};             // a-z 26 个 + A-Y 25 个 + 谷仓 Z 1 个
constexpr int inf{1145141919};    // 114514 家族哨兵

int P;
int dis[nn][nn];                  // dis[u][v]=u 到 v 的最短路

int id(char c)                    // 字符 -> 0-based 标号
{
	if(c>='a'&&c<='z')
		return c-'a';              // 0..25 小写(无牛)
	if(c>='A'&&c<='Y')
		return c-'A'+26;           // 26..50 大写(每处一头牛)
	return 51;                     // 谷仓 Z
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>P;
	for(int i=0;i<nn;++i)
		for(int j=0;j<nn;++j)
			dis[i][j]=i==j?0:inf;
	for(int i=0;i<P;++i)
	{
		char a,b;int w;
		cin>>a>>b>>w;
		int u=id(a),v=id(b);
		if(w<dis[u][v])            // 重边取最小
		{
			dis[u][v]=w;
			dis[v][u]=w;
		}
	}
	for(int k=0;k<nn;++k)          // Floyd
		for(int i=0;i<nn;++i)
			for(int j=0;j<nn;++j)
				if(dis[i][k]<inf&&dis[k][j]<inf&&dis[i][k]+dis[k][j]<dis[i][j])
					dis[i][j]=dis[i][k]+dis[k][j];
	int best=inf,bi=-1;
	for(int i=26;i<=50;++i)        // A..Y 各有一头牛,取离谷仓最近者
		if(dis[i][51]<best)
		{
			best=dis[i][51];
			bi=i;
		}
	cout<<char('A'+bi-26)<<' '<<best<<'\n';
	return 0;
}
```

### 5.2 对照实现：Bellman-Ford（仅用于对拍，与 `P1529_brute.cpp` 一致）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int nn{52};
constexpr int inf{1145141919};
constexpr int mxp{10005};

int P,cnt;
struct{int u,v,w;}E[mxp*2];       // 无向边存两遍

int id(char c)
{
	if(c>='a'&&c<='z')
		return c-'a';
	if(c>='A'&&c<='Y')
		return c-'A'+26;
	return 51;
}

int dis[nn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>P;
	for(int i=0,a,b,w;i<P;++i)
	{
		char x,y;
		cin>>x>>y>>w;
		a=id(x);b=id(y);
		E[cnt++]={a,b,w};
		E[cnt++]={b,a,w};
	}
	fill_n(&dis[0],nn,inf);
	dis[51]=0;                     // 从谷仓出发做 Bellman-Ford
	for(int it=0;it<nn-1;++it)
		for(int i=0;i<cnt;++i)
			if(dis[E[i].u]<inf&&dis[E[i].u]+E[i].w<dis[E[i].v])
				dis[E[i].v]=dis[E[i].u]+E[i].w;
	int best=inf,bi=-1;
	for(int i=26;i<=50;++i)
		if(dis[i]<best)
		{
			best=dis[i];
			bi=i;
		}
	cout<<char('A'+bi-26)<<' '<<best<<'\n';
	return 0;
}
```

### 5.3 易错点清单

- **把 `m` 和 `M` 当成同一个节点** ⇒ 图结构错误（题面专门警告）。
- **重边直接覆盖而非取最小** ⇒ 最短路偏大。
- **$\infty+\infty$ 溢出 `int`** ⇒ Floyd 结果错误（未定义行为），故松弛前必须判两端皆有限。
- **候选集搞错**：只算 `A`–`Y`，别把 `a`–`z` 也算进去（那些牧场没有牛）。
