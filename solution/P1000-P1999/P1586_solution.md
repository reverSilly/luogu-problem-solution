# P1586 四方定理

> 标签：动态规划 DP · 数学 · 枚举 · 背包 DP · 难度：普及/提高-
> 本地题面：`P1586.md`（$t\le100$，$1\le n\le32768=2^{15}$；洛谷时限 $1.00\text{s}$）。验证：`appendix/P1586/` 官方样例回归 $2003\to48$、边界批量与 $3100$ 组随机对拍全部 `std==brute`；最坏输入 $t=100$、$n=32768$ 耗时 $0.0076\text{s}$；全值域最大答案 $2224$（$n=32130$），`int` 安全。

## 1. 重新读题

**问题重述（人话版）**

给定正整数 $n$，统计把 $n$ 写成

$$n=a_1^2+a_2^2+\cdots+a_m^2$$

的方案总数，其中 $m$ 个条件全都要满足：

- 每个 $a_i$ 是**正整数**（不是 0，也不是负数——平方后反正一样，见条款 3）；
- 部件个数 $1\le m\le 4$（"不超过四个"）；
- **顺序无关**：$25=4^2+3^2$ 与 $25=3^2+4^2$ 视为一种方案；
- $a_i$ 之间**可以相等**：题面自己就给了 $25=1^2+2^2+2^2+4^2$（两个 $2^2$）。

输入有 $t$ 组询问（$t\le100$），每组一个 $n$，每组输出一个方案数。

> 一句话版本：**从面额集合 $\{1^2,2^2,3^2,\dots\}$ 里取 $1\sim4$ 枚硬币（同种面额可重复、先后无序），凑出和 $n$，问有多少种取法。**

**题面里容易漏掉的条款**

1. 「不超过**四个**整数的平方和」$\Rightarrow$ 部件数 $m\in\{1,2,3,4\}$，不是恰好 $4$。$25=5^2$ 只用了 $1$ 个部件，题面照样算一种方案。**这是"上界"而不是"精确值"**，后面 §2.5 会看到忘了它的后果。
2. 「$25=4^2+3^2$ 和 $25=3^2+4^2$ 视为**一种**方案」$\Rightarrow$ 数的是**多重集**（可重复、无序），不是排列。$25=1^2+2^2+2^2+4^2$ 里 $2^2$ 出现两次也印证了"可重复"。
3. 「整数」的平方：负整数平方与正整数平方相同，$0^2=0$ 对和有贡献为零。若把 $0$ 当合法部件，则 $25=5^2$、$25=5^2+0^2$、$25=5^2+0^2+0^2$ 会被数成三种方案，直接违反"$25=5^2$ 是一种方案"的朴素读法。$\Rightarrow$ **部件必须取正整数平方；"不足 4 项"靠"枚数从 1 数到 4"实现，而不是靠补 0。**（§2.6 给出具体反例）
4. $n\le32768=2^{15}$ $\Rightarrow$ $\sqrt{32768}\approx181.02$，$181^2=32761\le32768<182^2=33124$，所以任何部件底数 $\le181$——**面额集合只有 181 种**，这是本题能 DP 的前提。
5. 四方定理（拉格朗日四平方定理）保证任意正整数都能写成不超过四个整数的平方和 $\Rightarrow$ **答案永远 $\ge1$，不存在输出 $0$ 的情况**。这是一条免费的自检锚点：若某程序输出 $0$，必有 bug。
6. $t\le100$ 组询问、时限 $1.00\text{s}$ $\Rightarrow$ 不能每组询问各自暴力；但所有询问共享同一个值域 $[1,32768]$ $\Rightarrow$ **整体预处理一次，$O(1)$ 回答每组询问**。

**数据范围与规模感受**

$$t\le100,\qquad 1\le n\le32768,\qquad \sqrt n\le181 .$$

- 若每组询问现场做四重循环枚举，单组代价约 $1.46\times10^{7}$（§2.2 实测），$100$ 组合计约 $1.5\times10^{9}$，时限 $1.00\text{s}$ 下必 TLE。
- 若一次性把所有 $n\le32768$ 的答案全部预处理：四重枚举约 $1.46\times10^{7}$（实测 $0.01\text{s}$），背包 DP 约 $1.6\times10^{7}$（实测 $0.008\text{s}$）——都能过。真正卡死的是"每组单独算"，而不是"算一次"。
- 题面 Tags 明示「动态规划 DP / 枚举 / 背包 DP」$\Rightarrow$ 正解方向是**一次预处理的计数 DP**。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：一个"方案"到底是什么

先把"方案"翻译成数学对象。忽略顺序、允许重复、每项是正整数平方——这三条合起来正是一个**平方数多重集**。

**引理 1（方案 ↔ 平方数多重集）**

设 $\mathcal M(n)$ 为满足以下条件的多重集全体：

$$\mathcal M(n)=\Big\{\{a_1,\dots,a_m\}:1\le m\le4,\ a_i\in\mathbb Z_{>0},\ \sum_{i=1}^{m}a_i^2=n\Big\}.$$

则 $n$ 的方案总数 $=|\mathcal M(n)|$。

**证明**：

- 任一方案 $(a_1,\dots,a_m)$ 满足定义 $\mathcal M$ 的三个条件（正整数、$1\le m\le4$、平方和为 $n$），把它看成无序多重集 $M=\{a_1,\dots,a_m\}$，则 $M\in\mathcal M(n)$。
- 反之任一 $M\in\mathcal M(n)$，任取一个线性展开 $(a_1,\dots,a_m)$（多重集总可以写成序列），它就是一个满足题面全部条件的方案。
- 题面规定"顺序不同的写法视为一种方案"，即两个序列当且仅当对应的多重集相同时才被视为同一方案（排列不改变多重集；而由加法交换律，$\sum a_{\pi(i)}^2=\sum a_i^2$，所以"同一多重集的所有排列"确实都是合法写法，必须被合并成一种）。
- 两边是一一对应，故方案总数恰为 $|\mathcal M(n)|$。$\blacksquare$

由引理 1，再榨一条值域信息：

**引理 2（底数上界）**

$n\le32768$ 时，任意方案的每个部件 $a_i\le181$。

**证明**：$a_i^2\le\sum_j a_j^2=n\le32768$，故 $a_i\le\lfloor\sqrt{32768}\rfloor=181$（$181^2=32761\le32768<33124=182^2$）。$\blacksquare$

> 于是面额集合被封死为 $D=\{1^2,2^2,\dots,181^2\}$，共 181 种面额。问题变成：**从 $D$ 里取 $1\sim4$ 枚硬币（同面额可重复），凑出和 $n$。** 这是一个"无限硬币找零 + 币数上限 4"的计数问题。

### 2.2 失败 1：照定义四重循环——能算对，但算不完

读题后第一个冒出来的念头一定是直接按定义枚举：$a\le b\le c\le d$ 四重循环（补 0 处理不足 4 项），每找到一个 $\sum =n$ 就 $+1$。这是定义法，绝对正确，小 $n$ 秒过。

先算它的代价。设 $N=n$，满足 $0\le a\le b\le c\le d$ 且 $a^2+b^2+c^2+d^2\le N$ 的整点个数约为四维球内整点数的 $1/384$（每个卦限 $1/2^4$、排序 $1/4!$）：

$$\#\approx\frac{\pi^2N^2}{32\cdot 24}=\frac{\pi^2N^2}{768}.$$

代入 $N=32768$：$\approx1.46\times10^{7}$（实测枚举总量恰为 $14\,622\,332$ 个四元组）。一组就要 $1.46\times10^{7}$ 次操作，$t=100$ 组全上界就是 $\approx1.5\times10^{9}$，时限 $1.00\text{s}$ 下必挂。

**但这步不是白走的**，它留下两个关键信息：① 答案对**所有** $n\le N$ 可以**一趟枚举同时算完**（每个四元组的平方和唯一，往对应桶里 $+1$ 即可）；② $1.46\times10^{7}$ 一趟完全可接受。所以真正的出路不是"更聪明的枚举"，而是"**把枚举从每组询问挪到全局预处理**"。

不过这里选择不停在枚举：枚举量 $\Theta(N^2)$，且"至多 4 项"被焊死在循环层数里——哪天文面改成"至多 8 项"就得重写循环。而找零模型天然带一个"枚数"维度，把 4 变成参数，这正是下面要走的 DP。

### 2.3 失败 2：先写个最顺手的 DP——它数的是"排列"不是"方案"

多重集计数让人下意识想写递推。设 $g[j][c]$ 表示"和为 $j$、用 $c$ 个正整数平方"的方案数，最顺手的写法是枚举最后一个部件：

$$g[j][c]=\sum_{k^2\le j}g[j-k^2][c-1],\qquad g[0][0]=1 .$$

写好一跑，$n=25$ 输出多少不谈，先看 $n=10$：真实答案（手算）只有 $2$——$\{1^2,3^2\}$ 与 $\{1^2,1^2,2^2,2^2\}$；而这个 DP 给出 $8$。错在哪？

**引理 3（上述 $g$ 数的是有序分解数）**

$g[j][c]$ 等于满足 $b_1^2+\cdots+b_c^2=j$ 的**有序**正整数 $c$ 元组 $(b_1,\dots,b_c)$ 的个数。

**证明**（对 $c$ 归纳）：

- **基例** $c=0$：只有空元组，$g[0][0]=1$ 与之对应。
- **归纳步**：假设命题对 $c-1$ 成立。对 $c\ge1$，把有序 $c$ 元组按**首项** $b_1=k$ 分类：$k$ 取遍所有 $k^2\le j$ 的正整数 $k$，且 $k$ 不同则元组不同（首项不同），故各类互不相交。固定 $b_1=k$ 后，剩下的 $(b_2,\dots,b_c)$ 是一个和为 $j-k^2$ 的有序 $(c-1)$ 元组，由归纳假设其个数为 $g[j-k^2][c-1]$。求和即得 $g[j][c]=\sum_{k^2\le j}g[j-k^2][c-1]$，即该递推恰好在数有序分解。$\blacksquare$

**具体反例（$n=10$）**：有序分解中，$c=2$ 有 $(1,3),(3,1)$ 两个；$c=4$ 时 $(1,1,2,2)$ 的排列有 $\frac{4!}{2!\,2!}=6$ 个；合计 $2+6=8$。而引理 1 要求多重集：$\{1,3\}$ 是一个、$\{1,1,2,2\}$ 是一个，共 $2$。$8\ne2$，**差在一个"交换"**：$(1,3)$ 与 $(3,1)$ 在引理 3 的归纳里被算作两类（首项不同），在引理 1 里必须合并。

> **下一个想法是怎么冒出来的**：$g$ 错的根源是"枚举最后一个部件"不记录前面用过什么，导致同一组部件按不同顺序被反复构造。要数多重集，就得给构造过程强加一个**规范顺序**——例如"从小到大选面额"。这正是"找零"问题的标准做法：**按面额逐类决定取几枚**。

### 2.4 修正：按面额逐类处理的完全背包

把 181 种面额排成升序，依次决定每种面额取几枚（0 枚、1 枚、2 枚……）。这样每个多重集只可能被构造一次——它的"构造路径"就是它按面额分组的计数向量。

**引理 4（逐类处理的构造与多重集构成双射）**

记 $f_k[j][c]$ = 只用面额 $\{1^2,2^2,\dots,k^2\}$ 凑出和 $j$、恰好用 $c$ 枚硬币的**多重集**个数。则对 $k=181$，$f_{181}[j][c]=|\{\text{和为 }j\text{ 的 }c\text{ 枚多重集}\}|$；且它由转移

$$f_k[j][c]=f_{k-1}[j][c]+f_k[j-k^2][c-1]$$

算出。

**证明**：

- **双射部分**。设 $M$ 是只用 $\{1^2,\dots,k^2\}$ 的 $c$ 枚多重集。把 $M$ 中相同面额合并计数，唯一确定向量 $x=(x_1,\dots,x_k)$，其中 $x_i\ge0$ 表示面额 $i^2$ 在 $M$ 中出现几次，满足 $\sum_{i=1}^{k}x_i=c$ 且 $\sum_{i=1}^{k}x_i\cdot i^2=j$。"逐类处理"的 DP 正是按 $i=1,2,\dots,k$ 的顺序依次决定每个 $x_i$ 的取值——给定 $x$ 可以唯一回推一条 DP 决策路径，给定一条 DP 路径也可唯一还原 $x$ 与 $M$。故 DP 每接受一条路径就对应一个多重集，且同一个多重集不可能被接受两次（它的 $x$ 向量唯一）。所以 DP 计数恰为多重集数。
- **转移部分**。按 $M$ 是否含有面额 $k^2$ 分类：
  - *不含* $k^2$：$M$ 是只用 $\{1^2,\dots,(k-1)^2\}$ 的 $c$ 枚多重集，共 $f_{k-1}[j][c]$ 个；
  - *含至少一枚* $k^2$：从 $M$ 中**移除一枚** $k^2$，得到 $M'$——一个用 $\{1^2,\dots,k^2\}$（还可能再含 $k^2$）的 $(c-1)$ 枚多重集，和为 $j-k^2$。该操作是双射：逆操作"加回一枚 $k^2$"显然良构，且 remov-add 互逆。故此类共 $f_k[j-k^2][c-1]$ 个。
  - 两类无交叠（按"是否含 $k^2$"划分），相加即得转移式。$\blacksquare$

**引理 5（原地实现：$j$ 正序 = 完全背包）**

用一维数组原地做上述转移时，对每个 $k$ 必须**正序**枚举 $j$：

```cpp
for(int j=k*k;j<=N;++j)
	for(int c=1;c<=4;++c)
		f[j][c]+=f[j-k*k][c-1];
```

该写法结束后 $f[j][c]=f_{181}[j][c]$。

**证明**（对 $k$ 归纳）：进入第 $k$ 轮前，数组状态为 $f_{k-1}$（归纳假设；$k=1$ 时初始态 $f_0[0][0]=1$、其余 0，正是 $f_0$，因为"一种面额都不用"只有空集一种）。第 $k$ 轮要把 $f_{k-1}$ 就地升级成 $f_k$。对固定 $j$，执行 `f[j][c]+=f[j-k*k][c-1]` 要求加数是**本轮新值** $f_k[j-k^2][c-1]$。

- **正序**（$j$ 从小到大）：处理 $j$ 时，$j-k^2<j$ 已被本轮更新过，读到的正是 $f_k[j-k^2][c-1]$；而 $f[j][c]$ 里尚未被本轮动过的旧值恰是 $f_{k-1}[j][c]$（本轮对 $f[j][c]$ 的累积从它开始）。故 $f[j][c]\leftarrow f_{k-1}[j][c]+f_k[j-k^2][c-1]=f_k[j][c]$，符合引理 4 的转移式。由于 $c$ 维读的是**另一个 $j$ 位置**的值，$c$ 循环的顺序不影响正确性。
- **倒序**（反证）：若 $j$ 从大到小，处理 $j$ 时 $f[j-k^2][c-1]$ 存的还是旧值 $f_{k-1}[j-k^2][c-1]$，转移退化为 $f_k[j][c]=f_{k-1}[j][c]+f_{k-1}[j-k^2][c-1]$，即每种面额至多被取一枚——这是 **0-1 背包**，不是本题要的完全背包。**具体反例**：$n=2$ 的唯一方案是 $\{1^2,1^2\}$（同种面额取两枚）；倒序写法下 $f[2][2]=f_1[2][2]+f_1[2-1][1]=0+0=0$，答案会错成 $0$——连拉格朗日自检（§2.7）都过不了。

归纳 $k=1..181$ 全部完成，得 $f[j][c]=f_{181}[j][c]$。$\blacksquare$

> **顺带记住这组对照**：0-1 背包（每件物品至多一次）要**倒序**，完全背包（每种无限次）要**正序**——两个方向差一个"本轮新值"，这是本套路唯一的坑。

### 2.5 失败 3：忘了"不超过四个"——$n=5$ 数出 2

DP 框架搭好后，若贪图省事把"枚数"维度整个砍掉（只记录和，不记录用了几枚），$n=5$ 会输出 $2$：$\{1^2,2^2\}$ 与 $\{1^2,1^2,1^2,1^2,1^2\}$ 都被数到，第二种用了 $5$ 个部件，超出"不超过四个"。

**引理 6（枚数维度不可省）**

$\{1^2\times5\}$ 型分解（$n$ 个 $1^2$，$n>4$）在不带枚数维的 DP 中会被计入，但它不是合法方案。

**证明**：$\{1^2,\dots,1^2\}$（$m$ 个 $1^2$）是"只用面额 $1^2$ 的和为 $m$ 的多重集"，不带枚数维时 DP 必然接受它；但它的部件数 $m>4$，不满足引理 1 中 $1\le m\le4$ 的条件，故不是合法方案。取 $n=5$：不带枚数维时至少计入 $\{1,4\}$ 与 $\{1,1,1,1,1\}$ 共 2 种，而 $5$ 的真实答案为 $1$。$\blacksquare$

**结论**：必须保留 $c=1..4$ 的枚数维，且**只**对 $c\le4$ 累加答案。反之若题目是"恰好四个"（如另一些四方定理计数变体），公式里的下界就换成 $c=4$ 一项——所以 $c$ 维是直接对着题面条款设计的。

### 2.6 失败 4：把 $0^2$ 当成一种面额——$n=25$ 数出 8

"不足 4 项"是个很诱惑人的口子：既然可以不足 4 项，那把 $0^2=0$ 加进面额集合、统一按"恰好 4 枚"算，不是更方便？对 $n=25$ 一跑得到 $8$，真实答案是 $3$。

错误答案的 8 种取法是：

$$\{25\},\{0,25\},\{0,0,25\},\{0,0,0,25\},\{9,16\},\{0,9,16\},\{0,0,9,16\},\{1,4,4,16\}.$$

其中 $\{25\},\{0,25\},\{0,0,25\},\{0,0,0,25\}$ 本质是**同一个**方案 $25=5^2$（补几个 0 都不改变平方和），$\{9,16\},\{0,9,16\},\{0,0,9,16\}$ 本质是同一个方案 $25=3^2+4^2$。补 0 制造出了 $4$ 个和 $3$ 个"影子"，$1+2+3+4=8$（$1$ 个真·一部件、$3$ 个 $5^2$ 的影子、$3$ 个 $3^2+4^2$ 的影子、$1$ 个真·四部件）。

**引理 7（0 面额导致重复计数）**

若面额集合含 $0$，则对任意含 $z$ 个 0 的合法取法，同一正整数部件多重集会以 $z=0,1,\dots$ 多种 0 的填充数被分别计数。

**证明**：设 $M$ 是一个 $m\le4$ 枚正整数平方的多重集（$\sum=m$ 个平方值之和为 $n$）。含 0 面额时，$M\cup\{0\times z\}$（$z=0,1,\dots,4-m$）都是"恰好凑成 $n$ 的 $\le4$ 枚"取法，且 DP 按枚数与内容把它们视为不同解；但这些填充对应同一个题面方案（$0^2$ 不改变值）。故同一方案被计数 $5-m$ 次。取 $n=25,m=1$（$M=\{25\}$）：被计 $4$ 次；$m=2$（$M=\{9,16\}$）：被计 $3$ 次；$m=4$（$M=\{1,4,4,16\}$）：被计 $1$ 次。总数 $4+3+1=8$，而真实答案为 $3$（引理 1 下 $|\mathcal M(25)|=3$）。$\blacksquare$

**结论**：面额从 $1^2$ 起，**不取 0**；"不足 4 项"由"枚数 $c$ 从 1 到 4 求和"表达。补 0 只是 §2.2 里"把枚举循环统一成四层"的**计数工具**，在按面额分类的 DP 里反而制造影子解。

### 2.7 收尾：两顶"安全帽"

**引理 8（答案公式）**

$$ \mathrm{ans}(n)=\sum_{c=1}^{4}f_{181}[n][c]. $$

**证明**：由引理 1，方案是"$1\sim4$ 枚正整数平方、和为 $n$"的多重集；由引理 2，底数 $\le181$，即只用面额 $D$；由引理 4，$f_{181}[n][c]$ 恰数其中"恰好 $c$ 枚"的那些。按枚数分类互不相交，求和得 $\sum_{c=1}^4$。$\blacksquare$

**引理 9（答案恒正，可作断言）**

对一切 $n\ge1$，$\mathrm{ans}(n)\ge1$。

**证明**：这是拉格朗日四平方定理的内容——每个非负整数都是四个整数的平方和。$n\ge1$ 时其四平方和中不能全为 0，去掉其中的 0 项后得到一个 $1\sim4$ 项的正整数平方分解，由引理 1 它是一个方案。$\blacksquare$

（引理 9 不参与计算，只当自检：任何"输出 0"都说明程序有 bug。）

**状态体检**：

| 量 | 范围 | 上界 | `int` 够？ |
|---|---|---|---|
| $n$ | 题面 | $32768$ | 是 |
| 面额底数 $k$ | $1..181$ | $181$（$181^2=32761$） | 是 |
| 枚数 $c$ | $1..4$ | $4$ | 是 |
| $f[j][c]$ | 计数 | 最大实测 $2224$（远小于 $2^{31}$） | 是 |
| 数组尺寸 | $32768+5$ | `mxn{32773}`、`mxpart{5}` | — |

$f[j][c]$ 的理论上界也松松的：任意 $f[n][c]\le$「和为 $n$ 的排序四元组数」$\le1.46\times10^{7}<2^{31}$，全程无乘法累加项，`int` 安全。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 把"顺序无关 + 可重复 + 正整数平方"三条合成一句：方案 = 平方数**多重集**，且底数 $\le\lfloor\sqrt n\rfloor$（引理 1、2）。
- **explore its property** — "不超过四个"是部件数的**上界**条款；四方定理顺带送出"答案 $\ge1$"的自检锚点（引理 9）。
- **consider easier version** — 先按定义四重循环：能算对但 $\Theta(N^2)$ 且 $t$ 组询问爆炸；发现"一趟算完所有 $n$"是关键转折（§2.2）。
- **classic problem solution（递推）** — 裸写"枚举最后一个部件"的 DP，归纳证明它数的是**有序分解**（引理 3），$n=10$ 得 $8\ne2$。
- **reduce to easier problem** — 多重集 + 有限面额 + 凑和 = **无限硬币找零**（面额 $1^2..181^2$、容量 $n$、币数 $\le4$）。
- **classic problem solution（计数型完全背包）** — 按面额逐类处理 + $j$ 正序原地更新，构造路径与多重集双射（引理 4），正序=同面额可重复（引理 5）。
- **classic problem solution（对照记忆）** — 同框架改成"每类至多一枚"就是 0-1 背包、必须倒序；$n=2$ 的反例说明方向错了连唯一解都会丢（引理 5 反证）。
- **carry the count dimension** — "不超过 4"必须落成一枚独立的 $c$ 维状态，砍掉它 $n=5$ 就多解（引理 6）。
- **no free coins** — $0^2$ 不能进面额集合，"不足 4 项"用 $\sum_{c=1}^{4}$ 表达，补 0 会造影子解（引理 7）。
- **precompute once** — $t$ 组询问共享值域 $[1,32768]$，一次预处理 $O(1)$ 应答（§2.2 → §4）。
- **sanity checker** — 用拉格朗日定理断言答案永不为 0（引理 9）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $f[j][c]$ | `int[32773][5]` | 面额类枚举到当前类时，凑出和 $j$、**恰好用 $c$ 枚**硬币的多重集合数 | `f[0][0]=1`，其余 0（全局数组默认 0 恰合"除空集外无解"） | 完全背包的「面额 × 容量 × 枚数」；双射证明见引理 4 |
| $k$ | `int`（循环） | 当前加入的面额**底数**，面额为 $k^2$ | $1$ 递增到 $181$ | $181^2=32761\le32768<182^2$（引理 2） |
| $j$ | `int`（循环） | 当前容量（目标和） | 从 $k^2$ **升序**到数组上界 | 正序 = 同面额可取多次（引理 5） |
| $c$ | `int`（循环） | 硬币枚数（部件数） | $1..4$ | 条款 1"不超过四个" |
| $t,n$ | `int` | 询问组数 / 单次询问的 $n$ | 读入 | 题面 |

### 4.2 编号步骤

1. `f[0][0]=1`：空多重集（和为 0、0 枚）是 DP 唯一种子。
2. 对每个面额底数 $k=1..181$（面额 $k^2$）逐类加入：$j$ 从 $k^2$ **升序**扫到 `mxn-1`，$c=1..4$，执行 `f[j][c]+=f[j-k*k][c-1]`。此即引理 5 的完全背包原地转移；结束时 $f[j][c]=f_{181}[j][c]$（引理 4）。
3. 读入 $t$；对每个询问输出 `f[n][1]+f[n][2]+f[n][3]+f[n][4]`——$1\sim4$ 枚即"不超过四个"（引理 8）。

> $j$ 扫到 `mxn-1`（32772）比 $32768$ 多算 4 个位置，纯属数组边界的 +5 松弛，无副作用；$c$ 维循环读的是另一个 $j$ 位置，故 $c$ 的先后顺序不影响正确性（引理 5）。

### 4.3 复杂度

- 时间：预处理 $\sum_{k=1}^{181}4\cdot(32773-k^2)\approx1.58\times10^{7}$ 次加法；回答询问 $O(t)$。**实测最坏输入（$t=100$、全 $n=32768$）$0.0076\text{s}$**（时限 1.00s）。
- 空间：`f[32773][5]` 个 `int` $\approx655\,\text{KB}$，远低于 125 MB。

### 4.4 关键不变量

1. 处理完前 $k$ 类面额后，`f[j][c]` = 仅用 $\{1^2,\dots,k^2\}$ 凑出 $j$ 的 $c$ 枚**多重集**数（引理 4/5）。
2. `f[j][0]` 恒满足「$j=0$ 为 1、$j>0$ 为 0」：不用任何硬币只有空集一种。
3. $j$ 必须正序；倒序退化为 0-1 背包，会把 $\{1^2,1^2\}$ 这类重复面额解漏掉（引理 5 反证，$n=2\to0$）。
4. 答案 $=\sum_{c=1}^{4}f[n][c]$，且恒 $\ge1$（引理 8、9）；输出 0 即程序有 bug。

## 5. 示例代码

### 5.1 主解：计数型完全背包（按面额逐类 + 枚数维）

> 与 `appendix/P1586/P1586.cpp` **逐字节一致**。

```cpp
//
// 题目：P1586 四方定理
// https://www.luogu.com.cn/problem/P1586
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{32773};   // n<=32768 (+5 松弛)
constexpr int mxk{182};     // 底数上界:181^2=32761<=32768<182^2
constexpr int mxpart{5};    // 部件数 0..4

int f[mxn][mxpart];         // f[j][c]=面额类枚举到当前,和为 j 且恰好 c 枚的多重集合数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	f[0][0]=1;              // 空多重集合是 DP 唯一种子
	for(int k=1;k<mxk;++k)  // 面额 k^2 逐类加入;j 正序 -> 同面额可取多次(完全背包,非 0-1)
		for(int j=k*k;j<mxn;++j)
			for(int c=1;c<mxpart;++c)
				f[j][c]+=f[j-k*k][c-1];
	int t;
	cin>>t;
	while(t--)
	{
		int n;
		cin>>n;
		cout<<f[n][1]+f[n][2]+f[n][3]+f[n][4]<<'\n';   // 1~4 枚即"不超过四个"
	}
	return 0;
}

// 样例输入：
// 1
// 2003
```

**代码结构对照**：`f` 的第一维是容量（目标和 $j\le32768$），第二维是枚数（$c\le4$，引理 6 的"不超过四个"）；`k` 循环把 $1^2..181^2$ 逐类面额折进DP（引理 4 的双射构造），$j$ 正序保证同面额可取多次（引理 5）。注意本文件没有 `using i64`：最大计数仅 $2224$，全程 `int`（§2.7 体检表）。末尾保留了样例输入注释，便于本地回归。

### 5.2 对照实现：四重枚举暴力（仅用于小规模对拍）

见 `appendix/P1586/P1586_brute.cpp`：直接按引理 1 的定义，四重循环枚举所有 $0\le a\le b\le c\le d$ 且 $a^2+b^2+c^2+d^2\le N$ 的有序四元组（前导 0 表示不足 4 个部件），每个四元组往对应平方和的桶里 `++cnt[]`。它一条一趟算出所有 $n\le N$ 的答案，天然绕开了"顺序无关"的一切歧义——因为排序后每个多重集只出现一次。代价 $\Theta(N^2)$（$N=32768$ 时实测 $1.46\times10^{7}$ 个四元组、$0.01\text{s}$），所以它自己也能过本题，但拿它当**独立基准**再合适不过：与标程（背包）算法路径完全不同，任何一边的方向写反、维度漏掉、初始化遗漏，都会在逐字节比对中立刻暴露。$3100$ 组随机 + 边界批量全部一致。

### 5.3 易错点清单

- **`j` 循环写成倒序** $\Rightarrow$ 每种面额至多取一枚（0-1 背包），$n=2$ 的 $\{1^2,1^2\}$ 数不出，答案错成 $0$（引理 5 反证）。完全背包必须正序。
- **把 $0^2$ 加进面额** $\Rightarrow$ 补 0 制造影子解，$n=25$ 从 $3$ 虚增到 $8$（引理 7）。"不足 4 项"用 $\sum_{c=1}^{4}$，不是用 0 面额。
- **漏掉枚数维（以为 Lagrange 保证 4 项就只数 4 项或随便数）** $\Rightarrow$ 不限部件数时 $n=5$ 多出 $\{1^2\times5\}$，得 $2$ 而非 $1$（引理 6）。
- **按"有序分解"写 DP** $\Rightarrow$ 同一多重集按不同排列被多次计数，$n=10$ 得 $8$ 而非 $2$（引理 3）。
- **每组询问现场四重循环** $\Rightarrow$ $100\times1.46\times10^{7}\approx1.5\times10^{9}$，$1.00\text{s}$ 时限必 TLE（§2.2）；必须全局预处理一次。
- **把"不超过四个"读成"恰好四个"** $\Rightarrow$ 漏掉 $25=5^2$、$25=3^2+4^2$ 这类少部件方案；$n=25$ 从 $3$ 少成 $1$。
- **用 `endl`** $\Rightarrow$ 违反本项目风格指南，一律 `'\n'`。
