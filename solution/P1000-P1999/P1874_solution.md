# P1874 快速求和

> 难度：普及/提高- · 标签：动态规划 / 数字分段

## 1. 重新读题

### 1.1 问题重述（人话版）

给一个长度不超过 $40$ 的数字串 $s$，以及目标 $n$。可以在若干位置插入加号，把串切成几段，每段按十进制读成一个整数（前导 $0$ 不改变数值，$03$ 就是 $3$），再把这些整数加起来。求最少要插入多少个加号，才能使和等于 $n$；做不到就输出 $-1$。

加号个数 $=$ 段数 $-1$。一段都不切时，加号个数是 $0$。

### 1.2 关键约束与规模暗示

- $\operatorname{len}(s)\le 40$，$1\le n\le 10^5$。
- 因为和恰好是 $n$，任何一段的值一旦超过 $n$ 就不可能出现在可行方案里。所以一段里「有效数字」不会太长，但前导 $0$ 可以很长，必须按数值而不是按字符串长度剪枝。
- $40\times 10^5$ 量级的 DP 足够，不必搜索 $2^{39}$ 种子集；搜索只作为小长度的对照。

## 2. 思维链（Chain-of-thought）

### 2.1 一段数的值怎么算

设从下标 $i$ 到 $j$（含）的数字是 $d_i\ldots d_j$。它的值是

$$v=\sum_{t=0}^{j-i} d_{j-t}\cdot 10^t.$$

**引理 1（左到右累加等于这个值，前导 $0$ 自动被忽略）**。从 $val=0$ 开始，对 $k=i..j$ 做 $val\leftarrow val\cdot 10+d_k$，得到的就是 $v$。

**证明**。归纳：处理完前 $t$ 位后，$val$ 等于这 $t$ 位组成的整数。再添一位 $d$，新值是旧值乘 $10$ 加 $d$，与十进制定义一致。高位的 $0$ 使 $val$ 在那些步骤保持不变，所以 `03` 得到 $3$。$\square$

**引理 2（值一旦超过 $n$，再往后接数字只会更大或持平）**。$val$ 在接上新数字后满足 $val'\ge val$，并且若 $val>n$ 则之后永远 $>n$。

**证明**。$val'=val\cdot 10+d\ge val$。若 $val>0$，则 $val'\ge 10val>val$；若 $val=0$，则 $val'=d$。一旦 $val>n\ge 0$，必然已经 $val\ge 1$，此后严格变大。$\square$

因此枚举一段的右端点时，数值超过 $n$ 就可以停。

### 2.2 DP 状态

令 $dp[i][s]$ 为：用 $s$ 的前 $i$ 个字符组成若干段，数字和恰好是 $s$，所需的最少段数。达不到则为 $\infty$。

边界：$dp[0][0]=0$（一个字符都没用，和为 $0$，段数为 $0$）。注意目标 $n\ge 1$，这个状态不会被当成最终答案。

转移：若 $dp[i][s]$ 有限，则从 $i$ 再接一段到 $j$（$i\le j<\operatorname{len}$），值为 $v\le n$，且 $s+v\le n$ 时

$$dp[j+1][s+v]=\min(dp[j+1][s+v],\,dp[i][s]+1).$$

**引理 3（按位置从左到右计算是正确的）**。所有能转移到位置 $i$ 的段，其左端点都小于 $i$。因此当外层循环走到 $i$ 时，$dp[i][\*]$ 已经是最终值；本层只写位置 $>i$ 的状态，不会把还没算完的值拿去转移。

**证明**。段的右端点下标 $+1$ 严格大于左端点，所以位置图是 DAG，且按位置排序就是拓扑序。最短路在拓扑序上一次松弛即可得到全局最小段数。$\square$

答案是 $dp[\operatorname{len}][n]-1$；若该状态仍是 $\infty$，输出 $-1$。

### 2.3 暴力为什么可以剪枝

对照程序是 DFS：每次决定下一段的右端点。

**引理 4（数字和是和的下界）**。任意分段方案的数值和 $\ge$ 各位数字之和，等号当且仅当每一段至多含一个非零数字。

**证明**。一段 $d_k\ldots d_0$ 的值是 $\sum d_i 10^i\ge \sum d_i$，因为 $i>0$ 时 $10^i>1$，等号需要所有 $i>0$ 的 $d_i=0$。把各段加起来即得。$\square$

所以若「当前和 $+$ 剩余数字和 $>n$」，这条分支可以直接丢掉。另外段数已经不可能刷新当前最优时也丢掉。这两条剪枝和 DP 不是同一条算法，只在长度 $\le 14$ 的随机数据上对拍。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 段值超过 $n$ 必废；前导 $0$ 只是数值上的 $0$，按十进制累加即可。
- **consider easier version** — 小长度上 DFS 枚举切点，并用数字和做下界剪枝。
- **dp on prefix** — $dp[i][s]$ 表示前 $i$ 位凑出和 $s$ 的最少段数，答案减一就是加号数。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `s` | `string` | 数字串 | 读入 | source |
| `tar` | `int` | 目标和 $n$ | 读入 | target |
| `dp[i][s]` | `int [45][100005]` | 前 $i$ 位和为 $s$ 的最少段数 | `1145141919` | dp |
| `dp[0][0]` | `int` | 空前缀 | $0$ | 边界 |

### 4.2 算法步骤

1. 把 `dp[0..len][0..tar]` 填成无穷大，置 `dp[0][0]=0`。
2. 按左端点 $i$、当前和、右端点三重循环转移；段值用 64 位累加，超过 `tar` 就停止这一段的延长。
3. 输出 `dp[len][tar]-1`，不可达则 `-1`。

### 4.3 复杂度与验证状态

- **时间**：每个位置、每个和最多向后延长到段值超过 $n$，实践上远小于 $O(\operatorname{len}^2\cdot n)$。长度 $40$、$n=10^5$ 的随机串实测 $0.0585\text{ s}$。
- **空间**：$45\times 100005$ 个 `int`，约 $18\text{ MB}$。
- **沙箱对拍**：`g++ -O2 -std=c++17 -Wall -Wextra` 零警告。样例 `99999 / 45 → 4`，以及 `12→1`、`303 / 6 → 1`、`01 / 1 → 0` 等边界，加 $70$ 组长度 $\le 14$ 的随机数据，共 $86$ 组，与 DFS 暴力一致。另核过：`1` 重复 $40$ 次、目标和 $40$ 的答案是 $39$；前导 $39$ 个 $0$ 再加一个 `1`、目标和 $1$ 的答案是 $0$；`9` 重复 $40$ 次、目标和 $1$ 的答案是 $-1$。

## 5. 示例代码

### 5.1 标程（`P1874.cpp`）

```cpp
//
// 题目：P1874 快速求和
// https://www.luogu.com.cn/problem/P1874
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxl{45};
constexpr int mxv{100005};
constexpr int inf{1145141919};

int dp[mxl][mxv];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	string s;
	int tar;
	cin>>s>>tar;
	int len=(int)s.size();
	for(int i=0;i<=len;++i)
		fill_n(dp[i],tar+1,inf);
	dp[0][0]=0;
	for(int i=0;i<len;++i)
	{
		for(int sum=0;sum<=tar;++sum)
		{
			if(dp[i][sum]==inf)
				continue;
			i64 val=0;
			for(int j=i;j<len;++j)
			{
				val=val*10+(s[j]-'0');
				if(val>tar)
					break;
				int ns=sum+(int)val;
				if(ns>tar)
					break;
				dp[j+1][ns]=min(dp[j+1][ns],dp[i][sum]+1);
			}
		}
	}
	if(dp[len][tar]>=inf)
		cout<<-1<<'\n';
	else
		cout<<dp[len][tar]-1<<'\n';
	return 0;
}
```
