# P1900 [ICPC 1998 Mid-Central R] 自我数

> 难度：普及/提高- · 标签：数学, ICPC

## 1. 重新读题
### 1.1 问题重述（人话版）

定义 `d(n) = n + （n 的各位数字之和）`。`d(n)` 的一个「发生器」就是某个正整数 `g` 使得 `d(g) = 该数`。没有发生器的正整数叫做自我数。把所有自我数从小到大记成 `a_1, a_2, …`，已知 `a_1 = 1, a_2 = 3, a_3 = 5`，前 13 个是 `1,3,5,7,9,20,31,42,53,64,75,86,97`。

输入 `N, K` 和 `K` 个下标 `s_1 .. s_K`。输出两行：第一行是 `[1, N]` 里自我数的个数；第二行是 `a_{s_1} … a_{s_K}`，题目保证这些值都 `< N`。

### 1.2 关键约束与规模暗示

`1 ≤ N ≤ 10^7`，`1 ≤ K ≤ 5000`。`N` 到一千万，可以对每个 `g = 1 .. N` 算一次 `d(g)` 并打标记，总时间大约是 `N` 乘上位数，足够。需要把 `[1, N]` 里的自我数按顺序存下来，才能 `O(1)` 回答第 `s` 个。

## 2. 思维链（Chain-of-thought）

**引理 1（发生器一定更小）。** 对每个正整数 `g`，`d(g) ≥ g+1 > g`。

证明：`g ≥ 1` 至少有一位非零数字，各位之和 `≥ 1`，所以 `d(g) = g + （各位和） ≥ g+1`。

**引理 2（`[1, N]` 里的非自我数都会被扫到）。** `x ∈ [1, N]` 不是自我数，当且仅当存在 `g ∈ [1, N]` 使 `d(g) = x`。

证明：若 `d(g) = x`，由引理 1 有 `g < x`，又 `x ≤ N`，所以 `g ≤ N-1 ≤ N`。反过来，定义就是「存在某个正整数发生器」。因此只要对 `g = 1, 2, …, N` 都计算 `d(g)`，若 `d(g) ≤ N` 就把 `d(g)` 标成「有发生器」。循环结束时，没被标的 `i ∈ [1, N]` 就是自我数。注意 `g` 自己是不是自我数无关：非自我数仍然可以继续生成后面的数，所以每个 `g` 都要算，不能只从自我数出发却漏掉分支……实际上从自我数沿 `d` 往下走也能覆盖，但直接对所有 `g` 打标更不容易漏，证明就是上面这一段，不依赖链的合并。

**引理 3（顺序就是 `a_i`）。** 把未标记的数从小到大放进 `sf[1], sf[2], …`，则 `sf[i] = a_i`，且 `sf` 里 `≤ N` 的那些就是 `[1, N]` 中的全部自我数。个数就是第一行的答案。询问的 `a_s` 题目保证 `< N`，所以它一定已经在这个表里。

证明：自我数的定义与大小顺序都是全局的。`[1, N]` 里的自我数恰是全体自我数里那些 `≤ N` 的，按升序编号与 `a_i` 的前缀一致，直到某个 `a_i > N` 才超出。保证 `a_s < N` 意味着 `a_s ≤ N-1`，它被收进表内。`N = 100` 时表是前 13 个，其中第 14 个 `108 > 100` 不在范围内，与题面说明一致。

暴力用的是另一条判定：`x` 的发生器若存在，各位和至少 1、至多不超过 `9 × 位数 ≤ 81`（`N ≤ 10^7` 时甚至 `≤ 63`），所以只需要检查 `g ∈ [x-200, x-1]` 里有没有 `g + 数位和 = x`。这和打标筛是不同的实现，小范围内用来对拍。

## 3. 模式总结（Pattern Summary）

- **explore its property** — `d(g)` 严格大于 `g`，发生器一定出现在更小的数里。
- **classic problem solution** — 类似埃氏筛，每个 `g` 只标记自己的后继 `d(g)`。
- **defer reconstruction** — 先按顺序收集全部 `≤ N` 的自我数，再回答 `K` 个下标。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `bad[x]` | `bool[10000005]` | `x` 是否有发生器 | 全局 `false` | not self |
| `sf[i]` | `int[10000005]` | 第 `i` 个自我数，1-based | 扫描时 `++cnt` 写入 | self list |
| `cnt` | `int` | `[1, N]` 内自我数个数 | `0` | count |
| `n, k` | `int` | 上界和询问个数 | 读入 | N, K |

`bad` 约 10MB，`sf` 约 40MB，都在常规内存限制内。`d(g) ≤ N + 9·8`，只在 `≤ N` 时写 `bad`，不会越界。

### 4.2 算法步骤

1. 读入 `N, K`。对 `i = 1 .. N` 计算 `x = i + 数位和`，若 `x ≤ N` 则 `bad[x] = true`。
2. 再扫一遍，把 `bad[i] = false` 的 `i` 依次存进 `sf`。
3. 输出 `cnt`。再读入 `K` 个 `s`，按顺序输出 `sf[s]`，空格分隔，行末无多余空格。

输入里的整数可以用空格或换行隔开，`cin` 都能读。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 `O(N log N)`（数位和是 `O(log N)`，这里 `log` 是十进制位数），空间 `O(N)`。官方样例

`100 10 / 1 2 3 4 5 6 7 11 12 13` 输出

`13` 与 `1 3 5 7 9 20 31 75 86 97`，与暴力一致。

另有 `N = 1`、`N = 20`、`N = 97` 三组，15 组 `N ≤ 3000` 的随机下标，以及 `N = 10000` 和 `N = 100000` 上固定查询前若干个自我数，都与「只在 `x-200 .. x-1` 里找发生器」的暴力逐字节相同。最大数据 `N = 10^7, K = 5000`（下标只取 `1..13`，保证值 `< N`）标程耗时 `0.0721 s`，自我数个数 `977787`，抽到的前 13 个与题面列出的序列一致。合计 `22` 组，`-Wall -Wextra -Werror` 警告数为 0。

## 5. 示例代码
### 5.1 标程（`P1900.cpp`）

```cpp
//
// 题目：P1900 [ICPC 1998 Mid-Central R] 自我数
// https://www.luogu.com.cn/problem/P1900
// 本地对拍验证通过

#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10000005};

int n,k;
bool bad[mxn];
int sf[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>k;
	for(int i=1;i<=n;++i){
		int s=i,x=i;
		while(s){
			x+=s%10;
			s/=10;
		}
		if(x<=n){
			bad[x]=true;
		}
	}
	int cnt=0;
	for(int i=1;i<=n;++i){
		if(!bad[i]){
			sf[++cnt]=i;
		}
	}
	cout<<cnt<<'\n';
	for(int i=0;i<k;++i){
		int s;
		cin>>s;
		if(i){
			cout<<' ';
		}
		cout<<sf[s];
	}
	cout<<'\n';
	return 0;
}
```
