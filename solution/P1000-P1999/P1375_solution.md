# P1375 小猫

> 标签：数学 · Catalan 数 · 福建省历届夏令营 · 难度：普及/提高-

## 1. 重新读题

**问题重述（大白话）**

圆周上站着 $2n$ 只**互不相同**的小猫，位置固定、按顺时针编号 $1,2,\dots,2n$。要把它们**两两配对**，每对之间拉一根**绳子（弦）**，一共 $n$ 根。要求任意两根绳子**不能在圆内相交**（共端点不算相交）。问有多少种配对方案，答案对 $10^9+7$（记作 $p$，题面明确说它是质数）取模。

**先把题面钉死成可判定的条件（坑几乎全在这些口径上）**

| 条件 | 精确含义 | 后果 |
|---|---|---|
| $2n$ 只小猫站成一圈 | 点是**圆上凸位置**的、**有编号可区分**的 | 计数对象是"标号点的匹配"，**不除**旋转/翻折（不是 Burnside） |
| 两两绑住尾巴 | 完全匹配：每个点恰好用一次，共 $n$ 条弦 | 无"剩下没人绑"的方案 |
| 绳子是弦、不许交叉 | 两根弦的**内部**不相交 | 交叉性只由 4 个端点的圆周顺序决定（引理 1） |
| 只问方案数，不输出方案 | 计数题 | 可以用双射换对象计数 |
| 模 $10^9+7$，是质数 | 分母可用逆元 | $2n\le2\times10^5\ll p$，所有阶乘可逆 |

**约束与复杂度暗示**

| 量 | 范围 |
|---|---|
| $n$ | $1\le n\le 10^5$（$60\%$ 数据 $n\le100$） |
| 需要预处理的最大阶乘下标 | $2n\le 2\times10^5$ |
| 输入 / 输出量 | 一行一个整数 / 一行一个整数 |

- $60\%$ 只给到 $n\le100$：这是**递推** $O(n^2)$（或者用高精度硬算）能过的规模；$10^5$ 时 $n^2=10^{10}$ 必炸。**分档方式在暗示：正解是"$O(n)$ 预处理 + 一个闭式公式"**，也就是要把二次卷积降成一次组合数计算。
- 答案要取模，而 $n$ 远小于 $p$：说明出题人指望你用**阶乘 + 逆元**，而不是 Lucas 或高精度。
- 标签直接写了 `Catalan 数`，等于把结论名字告诉你了；但**"为什么是 Catalan"必须自己推出来**——下面 2.1~2.5 就是在把这个名字变成可证的事实，并且不依赖"我背过公式"。
- **题面没有样例**（本地文件里 Sample 一节是空的），所以第 4.3 节无法与官方样例对标，只能声明这一点，然后用"暴力枚举 + 两条独立公式互验"的手工推演代替；不存在"跑过样例"这回事。

## 2. 思维链（Chain-of-thought）

### 2.1 explore its property —— 一根弦什么时候和另一根相交？

先解决"怎么判定交叉"，因为它决定后面所有结构。

**引理 1（交叉 ⟺ 端点交错）**：设 $a<b$、$c<d$，四个端点互异。弦 $\{a,b\}$ 与弦 $\{c,d\}$ 在圆内相交 $\iff$ $a<c<b<d$ 或 $c<a<d<b$。

**证明**：弦 $\{a,b\}$ 把圆盘分成两个闭区域 $D_1,D_2$（弓形），且 $D_1\cap D_2=\{a,b\}$ 之间的那段弦；圆周上除 $a,b$ 外的点，按"顺时针从 $a$ 到 $b$ 的开弧 $A=(a,b)$"与"另一段开弧 $B$"分别落在 $D_1,D_2$ 的内部。
- *必要性*：若 $c,d$ 同属 $A$（或同属 $B$），则整条线段 $cd$ 落在同一个凸的弓形区域内，与弦 $\{a,b\}$ 的内部不相交。若 $c,d$ 分居两弧，线段 $cd$ 是连通的、又不能整个待在 $D_1\cup D_2$ 的某一半里，故必与 $D_1\cap D_2$ 相交，即与弦 $\{a,b\}$ 有公共点；这个公共点不可能是 $c$ 或 $d$（端点互异），也不可能是 $a$ 或 $b$（圆上不同点处于**凸位置**：一条直线与圆最多两个交点，故 $a$ 不可能落在弦 $cd$ 上），因此是**两弦内部**的交点 ⇒ 相交。
- *交错形式的等价*：在 $a<b,\;c<d$ 的前提下"$c,d$ 恰有一个落在开弧 $(a,b)$ 内"逐一讨论即可化简：$c\in(a,b),\,d\notin(a,b)\Rightarrow a<c<b<d$；$d\in(a,b),\,c\notin(a,b)\Rightarrow c<a<d<b$（此时 $c<b$ 又 $c\notin(a,b)$ 只能 $c<a$）。其余情形（$c<d<a$、$a<b<c<d$）两点同侧，不相交。$\blacksquare$

**关键推论**：交叉性**只依赖 4 个端点的圆周相对顺序**，与半径、角度都无关。以后把某段弧上的点"挪到一个小圆上重新画"不会改变谁和谁交叉——这就是 2.3 里"子问题计数只跟点数有关"的依据。

### 2.2 consider easier version —— 最小的几个 $n$ 硬数

$n=1$（2 点）：只能 $\{1,2\}$，**1** 种。

$n=2$（4 点）：全部匹配 $3!!=3$ 种：$\{12,34\},\{14,23\}$ 合法，$\{13,24\}$ 是 $1<2<3<4$ 型交错（引理 1）⇒ 交叉。**2** 种。

$n=3$（6 点）：全部匹配 $5!!=15$ 种。合法的是：$\{16,25,34\},\{16,23,45\},\{14,23,56\},\{12,36,45\},\{12,34,56\}$ —— **5** 种（其余 10 种含交叉）。

于是得到数列 $1,2,5,\dots$。第 $4$ 项不好硬枚举（$\binom{8}{2}$ 里挑 $4$ 根不相交的弦，共 $7!!=105$ 种匹配），但它会被 2.3 的递推自动给出：$f_4=14$。$1,2,5,14$ 正是 Catalan 数 $C_1,C_2,C_3,C_4$。不过"看着像"不是证明，下面把它推出来。

### 2.3 结构分解 —— 过定点的那根弦（最优子结构的雏形）

盯住 $1$ 号小猫的搭档 $k$。

**引理 2（奇偶）**：弦 $\{1,k\}$ 的非交叉完全匹配存在 $\Rightarrow$ $k$ 为偶数。
**证明**：$\{1,k\}$ 把剩下的点分成开弧 $A=(1,k)$（$k-2$ 个点）与 $B=(k,1)$（$2n-k$ 个点）。由引理 1，任何一端在 $A$、另一端在 $B$ 的弦都会与 $\{1,k\}$ 交叉，故除 $\{1,k\}$ 外每根弦的两端**同侧**，$A,B$ 各自内部被完美匹配 ⇒ $|A|,|B|$ 都是偶数 ⇒ $k$ 偶数。$\blacksquare$

记 $k=2i+2$，则 $|A|=2i$、$|B|=2(n-1-i)$，$i$ 可取 $0,1,\dots,n-1$。

**引理 3（递推 + 双射）**：设 $f_m$ = $2m$ 个圆周点的非交叉完全匹配数（$f_0=1$，空匹配），则
$$f_n=\sum_{i=0}^{n-1}f_i\,f_{n-1-i}.$$
**证明**：固定 $i$，考虑"$\{1,2i+2\}\in$ 匹配"的那些。定义限制映射：把匹配 $M$ 映为 $(M|_A,M|_B)$ = 落在 $A$、$B$ 内的弦集合。
- *良定义*：由引理 2 的论证，$M\setminus\{\{1,2i+2\}\}$ 的每根弦都在同侧，故确实是两个各自完整的匹配；它们显然也不交叉（子集）。
- *单射*：$(M|_A,M|_B)$ 加上弦 $\{1,2i+2\}$ 就恢复了 $M$。
- *满射*：任取 $A$ 上非交叉匹配 $P$、$B$ 上非交叉匹配 $Q$。$P$ 的所有弦画在弓形 $D_1$ 内、$Q$ 的画在 $D_2$ 内，$D_1\cap D_2=$ 弦 $\{1,2i+2\}$，所以 $P$ 与 $Q$ 之间、以及它们与 $\{1,2i+2\}$ 之间都不相交（后者由引理 1：$A$ 内的弦两端同侧）。合法 ⇒ 原像存在。
- *只依赖点数*：由 2.1 推论，$A$ 上的非交叉匹配数与"把 $A$ 的 $2i$ 个点按圆周顺序放到一个圆上"的情形一一对应，即为 $f_i$；$B$ 同理 $f_{n-1-i}$。
对 $i$ 求和（不同 $i$ 对应的匹配互不相交，因为 $1$ 的搭档唯一）即得递推。$\blacksquare$

到这一步，"计数"已经有了**最优子结构式的分解**：大问题被切成两个互不干扰的子问题，且切法只有"$1$ 的搭档是谁"这一个自由度。但递推是二次卷积，$n=10^5$ 不够快，得求闭式。

### 2.4 把 $f_n$ 换成更好数的对象 —— 匹配 ↔ 括号序列

先用一个括号论里的标准小事实，它后面要引用两次。

**断言 1（首次回归判据）**：设 $h(t)=$ 词的前 $t$ 个字符的净数（`(` 计 $+1$、`)` 计 $-1$，$h(0)=0$）。位置 $a$ 的 `(` 与位置 $b$ 的 `)` 是标准（栈）匹配的一对 $\iff$ $b$ 是**第一个**满足 $h(b)=h(a{-}1)$ 的位置（等价地：子串 $a{+}1..b{-}1$ 内 $h$ 始终 $>h(a{-}1)$，即该子串自身是个 Dyck 词，且 $b$ 处首次回落）。
**证明**：标准匹配的算法是"遇 `(` 压栈、遇 `)` 弹出栈顶配对"。$h(t)$ 恰好等于"读完前 $t$ 个字符后的栈内元素个数"，这是栈算法的显然不变量（每压入 $+1$、每弹出一 $-1$，且非法词只会被多弹出——在 Dyck 词里不会发生）。位置 $a$ 是 `(`，入栈后栈深 $h(a)=h(a{-}1)+1$，它位于栈底往上数第 $h(a{-}1)+1$ 个，也就是**最底下那个尚未闭合的 `(`**。它被弹出（即完成配对）的时刻，恰是栈深第一次回到 $h(a{-}1)$ 的时刻；栈深就是 $h$，所以该时刻就是最小的 $b>a$ 使 $h(b)=h(a{-}1)$。弹出它的那个 `)` 就在 $b$（因为只有 `)` 会让 $h$ 减小）。反之，若 $a{+}1..b{-}1$ 内 $h>h(a{-}1)$ 且 $h(b)=h(a{-}1)$，则按上一句 $b$ 就是 $a$ 的搭档位置。$\blacksquare$

**引理 4（双射）**：$2n$ 个圆周点的非交叉完全匹配与长度为 $2n$ 的合法括号序列（Dyck 词）一一对应。对应规则：把点 $1,2,\dots,2n$ 依次写符号，弦 $\{a,b\}$（$a<b$）在 $a$ 处写 `(`、在 $b$ 处写 `)`。
**证明**：
- *任何*完全匹配产出的词都是平衡的：`(` 与 `)` 各 $n$ 个；且任意前缀 $1..t$ 里 `(` 不少于 `)` —— 因为前缀内每个 `)` 的搭档 `(` 位置更靠前、也在前缀内。
- *非交叉 $\Rightarrow$ 标准括号匹配还原出原匹配*（这是关键一步，也是"单射"所在）。设弦 $\{a,b\}$（$a<b$）。先看区间 $(a,b)$：若某根弦恰有一端在 $(a,b)$ 内，由引理 1 它与 $\{a,b\}$ 交叉，矛盾；所以 $(a,b)$ 内的点成对被内部弦配走，$(a,b)$ 这个子串的净括号数为 $0$。再取 $a<s<b$，考察 $(a,s]$ 的净数：其中每个 `)` 的 `(` 若落在 $a$ 左侧，则该弦满足 $p<a<u$（$u\le s<b$），与引理 1 矛盾，故也在 $(a,b)$ 内 ⇒ $(a,s]$ 净数 $\ge0$。于是从 $a{+}1$ 到 $b{-}1$，相对 $a$ 处的平衡高度始终 $\ge 0$，即首次下降到 $h(a{-}1)$ 的位置只能是 $b$ —— 由**断言 1**，标准括号匹配正是把 $a$ 与 $b$ 配对。故匹配可由词唯一还原，映射单射。
- *满射*：任给一个 Dyck 词，做标准括号匹配。若得到两根弦 $a<b,\;c<d$ 满足 $a<c<b<d$，则由断言 1，$a$ 与 $b$ 配对 $\Rightarrow$ 子串 $a{+}1..b{-}1$ 是 Dyck 词、其内部每个 `(` 的搭档仍在该子串内（否则该子串的 $h$ 会下穿起点，与"$b$ 才是首次回归点"矛盾），于是 $c$ 的搭档必在 $b$ 左侧，与 $d>b$ 矛盾。故无交错 ⇒ 匹配非交叉，原像存在。$\blacksquare$

> 注意坑：**不能**只对"直线排列的点"讲这个双射就完事——圆上有个"接缝"（$2n$ 与 $1$ 之间）。引理 1 已经把交叉判据写成纯线性的 $a<c<b<d$ 形式，所以圆周序与编号序给出的交叉关系完全一致，双射成立。

### 2.5 经典计数：反射原理（闭式的证明）

Dyck 词好数吗？总数 $\binom{2n}{n}$ 好数，约束在前缀上，所以用"总数 $-$ 坏数"。沿用断言 1 的记号 $h(t)=$ 前 $t$ 个字符的净数（`(` 计 $+1$，`)` 计 $-1$，$h(0)=0$）：合法词 $\iff$ 对所有 $t$ 有 $h(t)\ge0$（且 $h(2n)=0$）；坏词 $=$ 平衡词里存在某个 $t$ 使 $h(t)=-1$。

**引理 5（反射原理）**：含 $n$ 个 `(`、$n$ 个 `)` 的坏词恰有 $\binom{2n}{n+1}$ 个。
**证明**：定义 $\varphi$：对坏词 $w$，取**首次**使 $h(t)=-1$ 的位置 $t$，把前缀 $w[1..t]$ 逐字符取反（`(`↔`)`），后缀 $w[t{+}1..2n]$ 不动。
- *像的形状*：前缀取反就是把前缀的部分和整体变号（对 $s\le t$，新的 $h'(s)=-h(s)$），于是 $h'(t)=-h(t)=+1$；总净数从 $h(2n)=0$ 变成 $0-2h(t)=+2$（改动了 $t$ 个字符，每个贡献变化 $\mp2$，共 $-2h(t)$）。故像是一个净数 $+2$ 的词，即含 $n+1$ 个 `(`、$n-1$ 个 `)`。
- *逆映射*：任给净数 $+2$ 的词 $v$（含 $n+1$ 个 `(`、$n-1$ 个 `)`），取**首次**使 $h_v(t)=+1$ 的位置 $t$（一定存在：$h_v(2n)=2\ge1$ 且 $h_v$ 每步只变 $\pm1$），同样翻转它的前缀 $1..t$。翻转后前缀部分和变号，故新词在 $t$ 处 $h'=-1$，而对 $s<t$ 有 $h_v(s)\le0\Rightarrow h'(s)\ge0$，即 $t$ 恰是新词**首次**触及 $-1$ 的位置，新词是坏词；总净数从 $+2$ 变为 $+2-2h_v(t)=0$，仍是平衡词 ✓。
- *对合*：$\varphi$ 只由"前缀 $1..t$"与"后缀 $t{+}1..2n$"两段决定，而上面已证两次操作里的 $t$ 是同一个位置（首次穿越点在新旧两词间保持），逐字符取反自逆，故 $\varphi\circ\varphi=\mathrm{id}$，映射是双射。
- *计数*：净数 $+2$ 的词只需在 $2n$ 个位置里选出 $n+1$ 个放 `(`，共 $\binom{2n}{n+1}$ 个（等价写法 $\binom{2n}{n-1}$，二者相等）。$\blacksquare$

> 走一遍 $n=3$。取坏词 $w$ 的字符依次为 `(` `)` `)` `(` `(` `)`，$h$ 依次为 $1,0,-1,0,1,0$，首次 $h=-1$ 在 $t=3$。翻转前缀三个字符 `(` `)` `)` → `)` `(` `(`，后缀不动，得像 $v$ 的字符 `)` `(` `(` `(` `(` `)`（$4$ 个 `(`、$2$ 个 `)`），其 $h_v$ 为 $-1,0,1,2,3,2$：首次到达 $+1$ 也正是 $t=3$ ✓，再翻一次前缀就还原成 $w$。全体 $\binom{6}{3}=20$ 个平衡词中坏词 $\binom{6}{4}=15$ 个，好词 $20-15=5$，与 2.2 的枚举个数吻合。

> 格路版翻译（同一个证明的另一种画法）：`(` 步 $(1,1)$、`)` 步 $(1,-1)$，坏路径 $\{从 (0,0)\ 到\ (2n,0)\}$ 关于直线 $y=-1$ 反射"首次触 $-1$ 之前的片段"，双射到"从 $(0,-2)$ 到 $(2n,0)$ 的一切路径"，后者 $= \binom{2n}{n+1}$。用词的形式写更不易出错，这里就以词为准。

于是
$$f_n=\binom{2n}{n}-\binom{2n}{n+1}.$$
最后一步纯代数：$\binom{2n}{n+1}=\binom{2n}{n}\cdot\frac{n}{n+1}$，故
$$f_n=\binom{2n}{n}\Big(1-\frac{n}{n+1}\Big)=\frac{1}{n+1}\binom{2n}{n}=C_n\ (\text{Catalan 数}).\quad\blacksquare$$

> 与 2.3 的闭环：$\frac{1}{n+1}\binom{2n}{n}$ 确实满足递推 $f_n=\sum f_if_{n-1-i}$（可用生成函数 $F=1+xF^2$ 验证），两条路互相印证，不必硬算那个二次卷积恒等式。

### 2.6 从闭式到实现

取 $\binom{2n}{n}-\binom{2n}{n+1}$ 而**不是** $\frac{1}{n+1}\binom{2n}{n}$：前者只用已经算好的组合数相减，**省掉一次额外逆元**；后者要 $n+1$ 的逆元（虽然也合法，因为 $n+1<p$）。$n\ge1\Rightarrow n+1\le 2n$，第二个组合数下标恒合法。

预处理 `fac[0..2n]`；`ifac[2n]=qpow(fac[2n],p-2)`（费马小定理，$p$ 质数、$p\nmid (2n)!$）后**倒推** `ifac[i-1]=ifac[i]*i%p`，全程只有 **一次** 快速幂。

复杂度 $O(n+\log p)$ 时间、$O(n)$ 空间；$n=10^5$ 时 $2n=2\times10^5$ 次乘法，远低于 $10^8$ 量级的时限预算。

### 2.7 口径确认 / 其它做法 / 坑点清单

- **"转一转算不算同一种？"** 不算。小猫是**有身份的个体**，它们站的位置已经定了：方案是"哪两只被一根绳子连起来"，即点集的一个匹配，点是**标号**的。检验：$n=2$ 时 $\{12,34\}$（两对相邻）与 $\{14,23\}$（另两对相邻）在旋转下互相等价，但它们是**不同的两只小猫组成的两对**，按题意必须都算，答案 $\binom{4}{2}-\binom{4}{3}=2$ 也确实是"标号计数"。若真要按旋转/翻折等价类计数，答案就不是 Catalan（要上 Burnside），也与本题标签不符。
- **"绳子能不能贴着圆周走、绕过别人？"** 不能：绳子是连接两条尾巴的弦，画成直线段最省——任何"绕路"的画法只会更容易和别的绳子相交，把弦拉直只会减少交叉，所以"存在不相交的画法"⟺"直线弦不相交"，而直线弦的交叉判据已由引理 1 完全刻画。（这也是为什么可以只讨论弦。）
- **$O(n^2)$ 递推**：直接按引理 3 卷积，模意义下整数运算，可拿 $60\%$（$n\le100$，约 $10^4$ 次乘加）；$n=10^5$ 时 $10^{10}$ 次乘加不可行。
- **乘式递推** $C_n=C_{n-1}\cdot\frac{4n-2}{n+1}$：同样 $O(n)$（配线性筛逆元也行），但它只能从闭式**反推**出来，双射里没有它的自然位置，且实现上要 $n$ 次乘法带 $(4n-2)$ 的中间量，不选。
- **生成函数路线**：由引理 3 的 $F=1+xF^2$ 解出 $F=\frac{1-\sqrt{1-4x}}{2x}$，再用广义二项式展开 $\sqrt{1-4x}$ 得到 $\frac{1}{n+1}\binom{2n}{n}$。这条路的代数量比引理 5 的反射原理大，而且"取哪个根"要论证，本题不采用，但**可以用来交叉验证闭式**。
- **整数除法陷阱**：$\frac{1}{n+1}\binom{2n}{n}$ 在**整数**里确实整除，但在模 $p$ 之后再除就不成立：必须先取逆元，或干脆用差式（两者在整数和模 $p$ 下都相等）。人工验证见 4.3 用例 8。
- **减法非负**：`(x-y+p)%p`；直接 `(x-y)%p` 在 C++ 里会得到负数（`-1 % p == -1`）。
- **溢出**：`int*int` 会先在 32 位里乘，$\sim10^{18}$ 必爆；两个乘数一律 `i64`（核算见 4.3 末）。
- **数组尺寸**：最大下标是 $2n$，`mxn` 要按 $2\times10^5$ 开（写成 $10^5+5$ 会越界，且越界读的是全局数组，未必当场崩，属于"静默 WA"）。
- **边界** $n=1$：$f_1=\binom{2}{1}-\binom{2}{2}=1$ ✓，代码里 `cmb(m,n+1)=cmb(2,2)` 不会越界（`y<=x` 检查也覆盖了假想的 $n=0$）。
- **Lucas / 高精度都不需要**：$2n\le2\times10^5\ll p=10^9+7$，阶乘模 $p$ 非零、可逆。若哪天 $n\ge p$ 或模数不是质数，这套工具全部失效，要换思路。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 弦交叉 ⟺ 端点交错 $a<c<b<d$（引理 1），于是交叉性只是圆周顺序的函数。
- **最小实例手玩** — $n=1,2,3,4$ 数出 $1,2,5,14$，认出 Catalan（2.2）。
- **consider easier version / 结构分解** — 定点 $1$ 的搭档必须是偶数位，把圈切成两个独立弓形（引理 2）。
- **双射 + 分档求和** — "搭档是谁"分类，得到 Catalan 递推 $f_n=\sum f_if_{n-1-i}$（引理 3）。
- **reduce to easier problem** — 非交叉匹配 ↔ Dyck 词：`(` 标弦的前端，标准括号匹配可还原（引理 4）。
- **classic problem solution（反射原理）** — 坏词对合反射到 $\binom{2n}{n+1}$，得闭式 $f_n=\binom{2n}{n}-\binom{2n}{n+1}=\frac1{n+1}\binom{2n}{n}$（引理 5）。
- **classic problem solution（阶乘 + 一次逆元）** — `fac`/`ifac` 线性预处理，$O(n+\log p)$（2.6）。
- **complexity / type audit** — 差式省一次逆元；`i64` 防 $10^{18}$；`mxn` 按 $2n$ 开；减 $p$ 防负。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n` | 小猫对数，$2n$ 只小猫 | `int`，输入，$1\le n\le10^5$ | 唯一输入 |
| `m` | $=2n$，阶乘要算到的下标 | `int` | 组合数上标 |
| `p` | 模数 $10^9+7$ | `constexpr i64` | 质数，可用费马逆 |
| `fac[i]` | $i!\bmod p$ | `i64`，`fac[0]=1` 起累乘 | $i\le 2\times10^5$ |
| `ifac[i]` | $(i!)^{-1}\bmod p$ | `i64`，`ifac[m]` 由 `qpow` 得，再倒推 | `ifac[i-1]=ifac[i]*i` |
| `cmb(x,y)` | $\binom{x}{y}\bmod p$，越界返 `0` | 函数 | 只被调用两次 |
| `ans` | $\binom{2n}{n}-\binom{2n}{n+1}\bmod p$ | `i64` | $=f_n=C_n$ |

### 4.2 算法步骤

1. 读 $n$，令 $m=2n$。
2. `fac[0]=1`；`for i=1..m`：`fac[i]=fac[i-1]*i%p`。
3. `ifac[m]=qpow(fac[m],p-2)`（$p\nmid m!$，因 $m<p$）；`for i=m..1`：`ifac[i-1]=ifac[i]*i%p`。
4. `ans=(cmb(m,n)-cmb(m,n+1)+p)%p`，输出。
5. $n=1$ 时 $m=2$，`cmb(2,2)=1` 合法；无特殊分支。

**复杂度**：时间 $O(n+\log p)$（$\approx2\times10^5$ 次取模乘 + $\approx30$ 次平方乘），空间 $O(n)$（两个 $2\times10^5$ 的 `i64` 数组，约 $3.2\ \text{MB}$）。

### 4.3 验证状态（**全部手工推演，未编译、未运行任何代码**）

> 环境无编译器；本任务纪律也禁止编译运行。题面**未提供样例**，故**无法与官方样例对标**——下面的验证依靠三条独立途径互校：(a) 2.2/2.3 的暴力枚举与小规模递推，(b) 引理 5 的闭式手算，(c) 代码执行轨迹逐步走查。

**用例 1：$n=1$（边界）** 闭式 $\binom{2}{1}-\binom{2}{2}=2-1=1$；枚举：2 点只有 $\{1,2\}$ ⇒ $1$ ✓。代码走查：`m=2`，`fac={1,1,2}`，`ifac[2]=inv(2)`、`ifac[1]=1`、`ifac[0]=1`；`cmb(2,1)=2`、`cmb(2,2)=1` ⇒ `ans=1` ✓。

**用例 2：$n=2$** 闭式 $\binom{4}{2}-\binom{4}{3}=6-4=2$；枚举全部匹配 $3!!=3$ 个，去掉交叉的 $\{13,24\}$（$1<2<3<4$ 交错）⇒ $2$ ✓；递推 $f_2=f_0f_1+f_1f_0=2$ ✓（三路一致）。

**用例 3：$n=3$** 闭式 $20-15=5$；暴力 $5!!=15$ 中非交叉的正是 2.2 列出的 $5$ 个 ✓；递推 $f_3=f_0f_2+f_1f_1+f_2f_0=2+1+2=5$ ✓。Dyck 词 $\frac{1}{4}\binom{6}{3}=5$ 个：`((()))`,`(()())`,`(())()`,`()(())`,`()()()` 依次对应 $\{16,25,34\},\{16,23,45\},\{14,23,56\},\{12,36,45\},\{12,34,56\}$ —— 与 2.2 的枚举**逐字相同**，说明引理 4 的双射在这里被真的走了一遍。

**用例 4：$n=4$** 闭式 $\binom{8}{4}-\binom{8}{5}=70-56=14$；递推 $f_4=f_0f_3+f_1f_2+f_2f_1+f_3f_0=5+2+2+5=14$ ✓。

**用例 5：$n=5$** 闭式 $\binom{10}{5}-\binom{10}{6}=252-210=42$；递推 $f_5=f_0f_4+f_1f_3+f_2f_2+f_3f_1+f_4f_0=14+5+4+5+14=42$ ✓；又 $C_5=\frac{1}{6}\binom{10}{5}=\frac{252}{6}=42$ ✓（三种算法互校，且这一步同时验证了"差式 $=$ 除式"那个代数恒等式）。

**用例 6：$n=10$** $C_{10}=\binom{20}{10}-\binom{20}{11}=184756-167960=16796$（$<p$，未触发取模；说明 $n$ 较小时公式给出的就是真值本身，取模只在 $n$ 大时才起作用）。

**用例 7（代码轨迹逐行走查，$n=3$）** `m=6`；`fac`: $1,1,2,6,24,120,720$；`ifac[6]=720^{-1}`，倒推 `ifac[5]=ifac[6]*6=720^{-1}*6=120^{-1}`（依 $1/(i-1)!=i/i!$）… 一路得 `ifac[0..6]={1,1,1/2,1/6,1/24,1/120,1/720}`（有理数写法，程序里全是模 $p$ 逆元，值小于 $p$ 不触发取模差异）。`cmb(6,3)=720/(6\cdot6)=720/36=20`、`cmb(6,4)=720/(24\cdot2)=720/48=15` ⇒ `ans=(20-15+p)%p=5` ✓ 与用例 3、与 2.2 手工枚举三方一致。

**用例 8（模运算专测 + 整数除法陷阱）** 取人工小模 $p'=7$、$n=3$：`fac mod 7` $=\{1,1,2,6,3,1,6\}$；`cmb(6,3)=fac6*ifac3*ifac3`，$6!\equiv6$，$3!\equiv6\Rightarrow(3!)^{-1}\equiv6$（$36\equiv1$）$\Rightarrow 6\cdot6\cdot6=216\equiv6$，与 $20\bmod 7=6$ ✓；`cmb(6,4)`：$4!\equiv3,(3)^{-1}\equiv5,(2)^{-1}\equiv4\Rightarrow6\cdot5\cdot4=120\equiv1$，与 $15\bmod7=1$ ✓；`ans=(6-1+7)%7=5` ✓（真值 $C_3=5$，$5\bmod 7=5$）。反面对照：若按"$\binom{6}{3}\bmod 7=6$，再整数除以 $4$"根本除不动（$4\nmid6$），必须走逆元 $4^{-1}\equiv2,\;6\cdot2=12\equiv5$ ✓ —— 这正是 2.7 的陷阱；而差式把"除"完全消掉了，所以最稳。

**边界**：$n=1$（最小）见用例 1；$n=10^5$ 时 $m=200000$ 落在数组容量 $200005$ 内 ✓，且 $200000<p$ ⇒ `fac` 无 $0$、逆元存在 ✓。真值规模 $\log_{10}C_{10^5}\approx 2\cdot10^5\log_{10}4-\log_{10}(10^5)\approx1.2\times10^5$ 位，**不可能**手算比对，故这里只做结构性核查（下标、可逆性、溢出），不声称验证过具体数字。

**溢出自检**：任一步取模乘形如 $u\cdot v$，$0\le u,v<p\Rightarrow uv<1.000000014\times10^{18}<2^{63}-1\approx9.22\times10^{18}$ ✓ 需 `i64`；若写成 `int`，$10^{18}$ 直接爆（$2^{31}-1\approx2.1\times10^{9}$）。`qpow` 里 `a*a%p` 同理；指数 `p-2` 也必须是 `i64`。取模后的差加 `p` 再 `%p`，结果落在 $[0,p)$，`i64` 足够。

## 5. 示例代码（C++）

```cpp
// P1375 小猫
// 圆周 2n 点的非交叉完全匹配 = Catalan 数
// C_n = C(2n,n)-C(2n,n+1)（差式写法：省掉对 n+1 单独求逆元）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{200005};              // 2n<=200000，+5 松弛
constexpr i64 p{1'000'000'007};

int n,m;
i64 fac[mxn],ifac[mxn];

i64 qpow(i64 a,i64 b)
{
	i64 res=1;
	for(;b;b>>=1,a=a*a%p)
		if(b&1)
			res=res*a%p;
	return res;
}
i64 cmb(int x,int y)
{
	if(y<0||y>x)
		return 0;
	return fac[x]*ifac[y]%p*ifac[x-y]%p;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	m=2*n;
	fac[0]=1;
	for(int i=1;i<=m;++i)
		fac[i]=fac[i-1]*i%p;
	ifac[m]=qpow(fac[m],p-2);           // m<p，费马逆可用；只做一次快速幂
	for(int i=m;i>=1;--i)
		ifac[i-1]=ifac[i]*i%p;          // 1/(i-1)! = i / i!

	i64 ans=(cmb(m,n)-cmb(m,n+1)+p)%p;  // +p 防负
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **只做一次 `qpow`**：`ifac[m]` 逆元 + 倒推，比"每个 $i$ 求逆"或"$\times(n+1)^{-1}$"更省；`ifac[i-1]=ifac[i]*i%p` 的推导一行：$\frac{1}{(i-1)!}=\frac{i}{i!}$。
- **`i64`  everywhere**：`fac/ifac/p/ans` 全 `i64`，杜绝 $10^{18}$ 中间量溢出；`n,m` 是下标，`int` 够。
- **0-based / 下标**：阶乘下标从 $0$ 开始是数学定义，不涉及"读入 $--$ 转换"；`mxn` 按 $2n$ 上界开。
- **`cmb` 的越界返 0** 只是保险：$n\ge1$ 时 $n+1\le 2n$ 恒成立，不会真走到 `return 0`。
- **无 INF 数组**：本解没有"不可达"状态，两个全局数组都被 $0..m$ 完整写入，不存在"全局默认 0 被当有效值"的移植陷阱。
