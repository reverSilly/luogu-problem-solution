# P1929 迷之阶梯

## 1. 重新读题

### 1.1 人话重述

有 $N$ 级台阶，高度严格递增为 $h_1<h_2<\cdots<h_N$。从第 $1$ 级出发，按下列规则移动，每次移动算一步：

1. **向上走一格**：如果第 $i+1$ 级的高度恰好比第 $i$ 级高 $1$（即 $h_{i+1}=h_i+1$），可以直接从 $i$ 登到 $i+1$。
2. **后退**：只要不在第 $1$ 级，就可以从当前第 $i$ 级退到第 $i-1$ 级。
3. **跳**：如果已经**连续后退了 $k$ 次**，现在位于第 $i$ 级，那么可以一次跳到任意高度不超过 $h_i+2^k$ 的台阶（跳完这次移动后，“连续后退次数”清零，因为跳不是后退）。

求从第 $1$ 级到第 $N$ 级的最少移动次数；到不了输出 $-1$。

$N\le200$，$h_i\le2^{31}-1$。

### 1.2 关键约束与规模暗示

- 高度可以到 $2^{31}-1$，但 $N$ 只有 $200$，状态应当建立在**台阶编号**而不是高度上。
- 连续后退次数 $k$ 最多到 $N-1$（从第 $i$ 级最多退 $i$ 次就到第 $1$ 级），并且 $2^{31}$ 已经超过所有可能的高度差，所以 $k$ 很大时跳跃范围“饱和”，可以把 $k$ 截断。
- 所有移动的代价都是 $1$，是典型的**无权图最短路**，用 BFS。

---

## 2. 思维链（Chain-of-thought）

### 2.1 把“连续后退次数”纳入状态

规则 1、2 只依赖当前台阶；规则 3 依赖“最近连续后退了多少次”。因此状态应定义为
$$
(i,k):\ \text{当前在第 }i\text{ 级，且已经连续后退了 }k\text{ 次}.
$$
起点是 $(1,0)$（1-based）。

三条规则对应三类转移，代价都为 $1$：

1. 若 $i<N$ 且 $h_{i+1}=h_i+1$，则 $(i,k)\to(i+1,0)$；
2. 若 $i>1$，则 $(i,k)\to(i-1,k+1)$；
3. 若 $k\ge1$，则对所有满足 $h_j\le h_i+2^k$ 的台阶 $j$，有 $(i,k)\to(j,0)$。

**引理 1（转移建模正确）**：

- 规则 1 的“登一步”不是后退，所以连续后退次数清零，转移到 $(i+1,0)$；
- 规则 2 是后退一次，所以 $k$ 加 $1$；
- 规则 3 的跳跃也不是后退，所以 $k$ 清零；跳跃范围恰好是高度上限 $h_i+2^k$。

因此上述三类转移与题面三条规则一一对应。$\blacksquare$

**引理 2（BFS 正确性）**：把所有合法状态与转移看成一张边权为 $1$ 的有向图，从 $(1,0)$ 出发。BFS 首次到达某状态时的距离就是最短移动次数，因此
$$
\min_{0\le k\le K_{\max}}\operatorname{dis}(N,k)
$$
就是答案（若全部不可达则为 $-1$）。

**证明**：BFS 按距离非降序扩展；边权均为 $1$，所以第一次访问即最短路。目标状态是任意 $k$ 的第 $N$ 级，故取所有 $k$ 的最小值。$\blacksquare$

### 2.2 为什么要截断 $k$

$h_i\le2^{31}-1$。对任意两个台阶 $i,j$，高度差
$$
h_j-h_i\le 2^{31}-1<2^{31}.
$$
所以当 $k\ge31$ 时，
$$
h_i+2^k\ge h_i+2^{31}>h_N\ge h_j,
$$
即从第 $i$ 级出发已经能跳到**任何**台阶。$k$ 再大不会扩大可达集合。

**引理 3（截断无害）**：令 $K_{\max}=32$。把任意 $k>K_{\max}$ 的状态按 $k=K_{\max}$ 处理，不改变任何状态的最短距离。

**证明**：跳跃范围只与 $2^k$ 有关，且当 $k\ge31$ 时该范围已经覆盖所有台阶。多后退几次只会增加移动次数，不会带来新的可达台阶，因此 $k>K_{\max}$ 的状态被 $k=K_{\max}$ 的状态支配。$\blacksquare$

于是状态数为 $N(K_{\max}+1)\le200\times33\approx6600$，完全可接受。

### 2.3 跳跃方向

题面第 3 条只说“跳到高度不超过 $h_i+2^k$ 的**任何**一步阶梯”，没有限制只能向上。因此实现中枚举所有满足高度条件的台阶 $j$（包括编号更小的）。

**注**：若限定只向上跳，答案不会改变。直观上，向下跳会把此前辛苦积累的 $k$ 清零，之后还要重新爬回来，不可能比“直接利用这个 $k$ 向上跳”更优；但为忠实于题面，代码允许任意方向的跳跃，这不影响正确性。

### 2.4 无解判定

如果 BFS 结束后所有 $\operatorname{dis}(N,k)$ 仍是 $+\infty$，说明第 $N$ 级不可达，输出 $-1$。例如 $N=2$，高度为 $1,10$：从第 1 级无法走 +1（$10\ne1+1$），也无法后退（已在第 1 级），$k=0$ 不能跳，故无解。

## 3. 模式总结（Pattern Summary）

- **state augmentation** — 把“连续后退次数” $k$ 加入状态，得到 $(i,k)$。
- **model the rules as unit edges** — 三条规则分别对应 $+1$、后退、跳跃，边权都为 $1$。
- **classic problem solution** — 无权图最短路用 BFS。
- **state space truncation** — $2^{31}$ 已覆盖所有高度差，$k$ 截断到常数，状态数 $O(32N)$。
- **reachability** — 目标不可达时输出 $-1$。

---

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| $N$ | `int` | 台阶数 | 读入 | 数量 |
| `h[i]` | `long long[205]` | 第 $i$ 级高度（0-based） | 读入 | height |
| `dis[i][k]` | `int[205][33]` | 到 $(i,k)$ 的最少移动数 | $+\infty$ | distance |
| `KMAX` | `int` | 连续后退次数上界 | $32$ | cap |
| `Q` | `deque<pair<int,int>>` | BFS 队列，存 $(i,k)$ | $(0,0)$ | queue |

### 4.2 算法步骤

1. 读入 $N$ 与高度数组。
2. 初始化 `dis` 全为 $+\infty$，令 `dis[0][0]=0`，把 $(0,0)$ 入队。
3. BFS：取出 $(i,k)$，令 $d=\operatorname{dis}[i][k]$，依次尝试：
   - 若 $i+1<N$ 且 $h_{i+1}=h_i+1$，松弛 $(i+1,0)$ 为 $d+1$；
   - 若 $i>0$，松弛 $(i-1,\min(K_{\max},k+1))$ 为 $d+1$；
   - 若 $k\ge1$，令 `lim=h[i]+(1LL<<k)`，对所有满足 $h_j\le\text{lim}$ 的 $j$，松弛 $(j,0)$ 为 $d+1$。
4. 答案为 $\min_k\operatorname{dis}[N-1][k]$；若仍为 $+\infty$ 输出 $-1$。

### 4.3 复杂度

- 状态数 $O(N\cdot K_{\max})$；每个状态至多枚举 $N$ 个跳跃目标，故时间 $O(N^2K_{\max})$。
- 空间 $O(NK_{\max})$。
- 对 $N\le200$，约 $2.6\times10^6$ 次操作。

## 5. 示例代码

```cpp
//
// 题目：P1929 迷之阶梯
// https://www.luogu.com.cn/problem/P1929
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{205};
constexpr int KMAX{32};
constexpr int inf{1145141919};

int n;
long long h[mxn];
int dis[mxn][KMAX+1];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>h[i];

	for(int i=0;i<n;++i)
		fill_n(dis[i],KMAX+1,inf);

	deque<pair<int,int>>Q;
	dis[0][0]=0;
	Q.push_back({0,0});
	while(!Q.empty())
	{
		auto[i,k]=Q.front();
		Q.pop_front();
		int d=dis[i][k];
		if(i+1<n&&h[i+1]==h[i]+1&&dis[i+1][0]>d+1)
		{
			dis[i+1][0]=d+1;
			Q.push_back({i+1,0});
		}
		if(i>0)
		{
			int nk=min(KMAX,k+1);
			if(dis[i-1][nk]>d+1)
			{
				dis[i-1][nk]=d+1;
				Q.push_back({i-1,nk});
			}
		}
		if(k>=1)
		{
			long long lim=h[i]+(1LL<<k);
			for(int j=0;j<n;++j)
			{
				if(h[j]>lim)continue;
				if(dis[j][0]>d+1)
				{
					dis[j][0]=d+1;
					Q.push_back({j,0});
				}
			}
		}
	}

	int ans=inf;
	for(int k=0;k<=KMAX;++k)
		ans=min(ans,dis[n-1][k]);
	cout<<(ans>=inf?-1:ans)<<'\n';
	return 0;
}
```
