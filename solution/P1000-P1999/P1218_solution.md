# P1218 特殊的质数肋骨 Superprime Rib — 题解

## Part 1 · 重述题意（Re-read）

用一句话重新描述这道题：

给定一个长度 $n$（$1 \le n \le 8$），找出所有**长度为 $n$ 的"右截断质数"**：一个 $n$ 位数 $d_1d_2\cdots d_n$ 满足

- 它本身是质数；
- 从**右边**依次去掉一位，剩下的 $d_1\cdots d_{n-1}$、$d_1\cdots d_{n-2}$、……、$d_1$ 也**全都是质数**；
- 注意 $1$ 不是质数。

要求按**升序**每行输出一个这样的数（题目原话是"按顺序输出"）。

**约束**：$1\le n\le 8$。范围极小，意味着任何"把候选枚举出来再筛"的暴力都跑不完（$10^8$ 太大），但"逐位生长 + 边长边筛"的搜索很小。这个范围本身就是提示：不要枚举全部 $n$ 位数，而是**只沿"每一步都是质数"的树枝往下长**。

**一个关键观察**（先点出来，后面证明）：一个数如果是质数，它的**个位只可能是 $2,3,5,7$**。因此除了"2、3、5、7"这四个一位质数之外，**任何合法长度 $n\ge 2$ 的右截断质数，个位都只能是 $1,3,7,9$**（奇数且不以 5 结尾）。这把每一位的候选从 10 个砍到 4 个。

## Part 2 · 思考链（Chain-of-thought）

### 2.1 先弄清"右截断"到底是什么意思

题目说"从右边开始依次取走肋骨，每次剩下的都是质数"。举例子 $7331$：
去掉最后一位 $\to 733$（质数）；再去掉 $\to 73$（质数）；再去掉 $\to 7$（质数）。

也就是说，若把这个数记作 $d_1d_2\cdots d_n$，要求的是**前缀** $d_1$、$d_1d_2$、$d_1\cdots d_3$、……、$d_1\cdots d_n$ 全为质数。

> 这里要小心别读反。"从右边取走" = 每次都砍掉**最末位** = 保留**左边的前缀**。所以约束落在**前缀**上。

由此立刻得到一个结构性结论：**一个合法的数，它的每一个前缀都必须是质数。**

### 2.2 考虑更简单的版本：先想"一位数"

$n=1$ 时，"前缀全质数"就退化成"$d_1$ 本身是质数"。所有一位解 = $\{2,3,5,7\}$。

这四个就是所有树枝的**根**。任何一个更长（$n\ge 2$）的合法数，它的**第一位**必须落在这四个里（因为它本身就是一个合法前缀，长度为 1 的质数）。

> 这就把"从哪长"定死了：根只有 2、3、5、7。

### 2.3 从根往下长：一位一位地长

假设我手里已经有一个**合法的前缀** $x$（$x$ 的每个前缀都是质数，特别地 $x$ 自己是质数）。我要把它延长成 $x'$，使得 $x'$ 也合法。

怎样延长？往**右边**拼一个新数字 $a$，得到 $x' = 10x + a$（$a\in\{0,1,\dots,9\}$）。

要让 $x'$ 合法，**唯一的新增要求**是什么？
- $x'$ 的前缀里，**除了最后一个**（即 $x'$ 本身）以外的前缀，都已经在"延长之前的 $x$"里被验证过是质数了；
- 唯一没被验证过的，就是 $x'$ 自己。

> 因此：**$x$ 合法 $\Rightarrow$ $10x+a$ 合法，当且仅当 $10x+a$ 是质数。**

这个"递推合法性"是本题的命门。它说明：**合法数恰好构成一棵以 $\{2,3,5,7\}$ 为根、边是"乘 10 再加一位"的树**；我们要做的只是在树里把所有**深度恰为 $n$** 的节点找出来。

#### 引理 1（合法性递推）
设 $x\ge 2$ 是一个正整数，且 $x$ 的每一个十进制前缀（包括 $x$ 自身）都是质数。对于任意数字 $a\in\{0,\dots,9\}$，记 $x'=10x+a$。则 $x'$ 的每一个十进制前缀都是质数，**当且仅当** $x'$ 本身是质数。

**证明**
设 $x$ 的十进制写法为 $d_1d_2\cdots d_k$（$k\ge 1$），则 $x'$ 的写法为 $d_1d_2\cdots d_k a$。
$x'$ 的全体前缀为：
$$d_1,\;d_1d_2,\;\dots,\;d_1\cdots d_k,\;d_1\cdots d_k a .$$
前 $k$ 个正是 $x$ 的前缀（最后一个是 $x$ 自身），由题设它们**全部**是质数。因此"$x'$ 的所有前缀都是质数"这一命题，与"$x'$ 自身是质数"是**等价**的（其余前缀恒为真）。$\blacksquare$

> 这同时给出"反方向"的必要性：若 $x'$ 合法而 $x$ 不合法（即 $x$ 自己不是质数），$x'$ 必然不合法。所以**不能跳过不合法的前缀**——树里不存在"父不合法、子合法"的边。这意味着我们**只从合法节点往下走**就绝不会漏解。

### 2.4 经典手法：DFS 逐位生长 + 试除判素

把 2.3 的递推写成搜索：从根 $\{2,3,5,7\}$ 出发，对每个当前合法节点 $x$，尝试所有 $a\in\{0..9\}$，只要 $10x+a$ 是质数就接受，并继续往下。当 $x$ 已经长到 $n$ 位时，记录它。

**判素怎么做？** $x$ 最大 $= 10^8-1$（8 位数）。判素用**试除法**（试到 $\sqrt{x}$）即可：

#### 引理 2（试除判素）
$M\ge 2$ 是质数 $\iff$ 不存在 $2\le i\le \lfloor\sqrt M\rfloor$ 使得 $i\mid M$。

**证明**
"$\Rightarrow$"方向：设 $M$ 是质数且存在 $2\le i\le \lfloor\sqrt M\rfloor$ 使 $i\mid M$。则 $M=ij$，$j=M/i\ge i\ge 2$，于是 $M$ 有真因子 $i$，与 $M$ 是质数矛盾。故不存在这样的 $i$。
"$\Leftarrow$"方向：设 $M$ 不是质数且 $M\ge 2$，则 $M$ 有真因子 $d$（$1<d<M$）。不妨设 $d\le \sqrt M$（若 $d>\sqrt M$，则另一因子 $M/d<\sqrt M$，取更小的那个）。取 $d$ 为 $M$ 的**最小**真因子，则 $d\le \sqrt M$（否则 $d$ 和 $M/d$ 都大于 $\sqrt M$，乘积超过 $M$，矛盾）。又 $d\ge 2$，故存在 $2\le i=d\le \lfloor\sqrt M\rfloor$ 使 $i\mid M$。$\blacksquare$

单次判素代价 $O(\sqrt M)\le O(10^4)$，对 $n\le 8$ 的搜索规模绰绰有余（见 2.7 的规模分析）。

### 2.5 剪枝：个位只能是 1/3/7/9

对 $n\ge 2$ 的节点，它本身必须是质数，所以它的**个位**只能是 $\{2,3,5,7\}$。
- 个位是 $2$：当且仅当这个数**就是** 2（一位数）；否则 $\ge 2$ 位且偶数 $\Rightarrow$ 合数。
- 个位是 $5$：同理，只有 5 本身合法。
- 个位是 $3$ 或 $7$：对任意位数都可能。

> 所以：除了根里的 2 和 5 这两个"例外"，**从根往下长时，每一位追加的数字 $a$ 只需要试 $\{1,3,7,9\}$** 即可（$a\in\{1,3,7,9\}$ 保证新数奇数且不被 5 整除）。把候选从 10 砍到 4，搜索树小近一半。

> 注意：这不是"必须"剪枝——不剪（试 0~9）也对，只是慢一倍；剪枝只是加速，**不影响正确性**（因为个位为偶数或 5 的多位数必为合数，引理 2 保证试除能识别）。

### 2.6 顺序问题：DFS 天然升序

题目要"按顺序输出"。我们的 DFS 是：**根按 2,3,5,7 递增**进入；对每个根，**追加位 $a$ 从 0 到 9 递增**尝试。

一个 $n$ 位数的十进制值，由高位到低位逐位决定。DFS 的展开顺序等价于"把每个 $n$ 位数看成它的数字序列，按字典序枚举"——而**数字序列的字典序恰等于数值的升序**（先比最高位，最高位相同再比次高位……）。

#### 引理 3（DFS 顺序 = 数值升序）
上述 DFS（根递增、每层追加位 $a$ 从 0 到 9 递增、且只沿合法节点下行）在深度 $n$ 处产出的数序列，是**严格升序**的。

**证明**
任取 DFS 先后产出的两个深度 $n$ 的数，记其数字序列为 $S=(s_1\cdots s_n)$、$T=(t_1\cdots t_n)$。设 $j$ 为第一个 $s_j\ne t_j$ 的位置（若不存在则两数相同，不可能先后都产出）。
DFS 的回溯性质保证：在同一深度被先后访问的两个节点，要么在**某个公共前缀**上分叉（分叉点上先访问的数字小），要么一个在前一个完全之后。具体到本 DFS：根层按 $s_1$ 递增访问；若 $s_1=t_1$，进入同一根的子树，子树内部又按 $s_2$ 递增访问……归纳地，在第一个分叉位置 $j$，先被访问的序列其第 $j$ 位数字严格更小，即 $s_j<t_j$。于是 $S$ 的数值 $< T$ 的数值（因为 $j$ 之前各位相同，$s_j<t_j$ 直接决定大小）。$\blacksquare$

> 因此**不需要**额外排序，DFS 产出的顺序直接就是答案顺序。若担心，最后再 `sort` 一遍也保险（O(k log k)，k 很小）。本解直接按 DFS 顺序输出。

### 2.7 规模分析（为什么能过）

最坏情况下，每个合法节点展开 4 个子（个位 $\{1,3,7,9\}$），深度 $n\le 8$。合法节点是质数前缀，密度受 $1/\ln x$ 控制，实际远小于 $4^n$。粗估：
- 深度 1：4 个
- 深度 8：整棵树节点总数 $\ll 4^8=65536$（因为绝大多数 $10x+a$ 是合数会被剪掉）。

每次判素 $O(\sqrt M)\approx 10^4$。总操作量 $\approx$（合法节点数 $\times$ 4 $\times$ $10^4$）$\ll 10^8$，毫秒级。✓ 轻松过。

（即便不剪枝、试 0~9，也只是常数倍，同样能过。剪枝是锦上添花。）

### 2.8 边界情形

- **$n=1$**：DFS 从根出发，根本身深度 1 就达到 $n$，直接输出 2,3,5,7。此时**不要**再尝试向下扩展。注意代码里要"深度 == $n$ 时先输出、再 return"，不能漏。
- **根 2 和根 5**：它们个位是 2/5，但本身是质数，是合法根。向下扩展时它们产生的多位数个位若为 2/5 会被判素筛掉，所以没问题。
- **$1$ 不是质数**：试除函数对 $M<2$ 返回 false，自动处理（虽然 DFS 根本不会生成 1，但保险）。
- **前导零**：DFS 不会产生前导零（根 $\ge 2$，后面只追加 0~9，高位永远非零）。所以"长度 $n$"严格指 $n$ 位。

### 2.9 把发现串成一句话

> 右截断质数 = 前缀全质数 $\Rightarrow$ 它们构成"根为 2,3,5,7、边为乘 10 加一位、只保留质数边"的一棵搜索树 $\Rightarrow$ DFS 逐位生长，每步试除判素，到深度 $n$ 输出；个位限定 $\{1,3,7,9\}$ 剪枝；DFS 展开天然升序，免排序。

## Part 3 · 套路小结（Pattern summary，按实际思考顺序）

- **探索机制** — "从右边取走" = 保留左边前缀，约束落在"每个前缀都是质数"。
- **考虑简单版本** — $n=1$ 退化为"一位质数"，定下根 = {2,3,5,7}。
- **经典问题解法** — 把"前缀全质数"看成树：节点=合法前缀，边=$x\to 10x+a$（仅当 $10x+a$ 质数）；DFS 逐位生长，引理 1 证明递推合法。
- **化简为更易问题** — 每次扩展只需判**新数一个**是否质数（旧前缀已验证），判素用试除法（引理 2，$O(\sqrt M)$）。
- **剪枝（同一手法两次使用）** — 个位必属 {2,3,5,7}；多位数里 2/5 个位必合数，故追加位只试 {1,3,7,9}，把 10 路砍成 4 路。
- **顺序保证** — 根递增 + 每层 $a$ 递增 ⇒ DFS 展开顺序 = 字典序 = 数值升序（引理 3），免排序。
- **边界核对** — $n=1$ 直接输出根；$1$ 非质数由试除自动排除；无前导零。

## Part 4 · 真正的解法（Real solution）

### 符号表（Notation glossary）

| 符号 | 含义 | 类型/初值 | 助记 |
|---|---|---|---|
| `n` | 目标位数 | `int`，读入 | 1~8 |
| `x` | 当前合法前缀（DFS 递归参数） | `int` | 递归栈里带，**不存表** |
| `d` | `x` 的当前位数（DFS 递归参数） | `int` | 1~n |
| `y` | 扩展后的候选前缀 $=10x+a$ | `int`，局部 | y=next |
| `a` | 追加位，$a\in\{1,3,7,9\}$（根层另含 2,5） | `int`，循环 | 个位候选 |
| `isPrime(M)` | $M$ 是否质数 | 函数 | 纯试除，见下 |

> 设计选择：**不存任何全局大数组**。合法性完全由 `isPrime` 在线决定，DFS 栈上的 `x` 就是全部状态。也不做质数表缓存——因为每个候选值 $10x+a$ 由唯一的父 $x$ 与唯一追加位 $a$ 决定，在整棵 DFS 里**只生成一次**，判一次即可，缓存无收益、徒增数组。

### 算法步骤（numbered）

1. **判素** `isPrime(M)`：实现引理 2 的试除。
   - `M < 2` 返回 `false`；`M == 2` 返回 `true`；`M` 为偶数返回 `false`；
   - 否则试除奇数 $i=3$ 起，$i\cdot i\le M$，命中即 `false`；否则 `true`。
   - 单次数 $O(\sqrt M)$；对 $M\le 10^8$ 即 $\le 10^4$ 次。
   - **不预处理、不缓存**：候选值唯一生成，无重复计算（见上）。

2. **DFS** `dfs(x, d)`：$x$ 为当前合法前缀，$d$ 为当前位数。
   - 若 `d == n`：输出 `x`，返回。
   - 否则：对每个候选追加位 $a\in\{1,3,7,9\}$（升序）：
     - 令 `y = 10*x + a`；
     - 若 `isPrime(y)` 为真，调用 `dfs(y, d+1)`。
   - 候选位升序（1,3,7,9），保证升序输出（引理 3）。

3. **起点**：`for r in {2,3,5,7}` 调 `dfs(r, 1)`。根已升序。
   - 根层 $n=1$ 时，`dfs(r,1)` 进入即 `d==n`，直接输出 $r$，正确覆盖 $n=1$。

4. **输出**：DFS 中 `cout<<x<<'\n'`，用 `'\n'`。

### 复杂度

- **时间**：设合法节点总数为 $T$（含根）。每个合法节点产生至多 4 次判素，每次 $O(\sqrt{10^n})=O(10^{n/2})$。故 $O\big(T\cdot 4\cdot 10^{n/2}\big)$。$n=8$ 时 $10^{n/2}=10^4$；$T\lesssim 10^4$ 量级（远小于 $4^8$），总 $\lesssim 4\times10^4\times10^4=4\times10^8$ 上界，但**实际**合法节点远少（质数密度 $\approx 1/\ln(10^8)\approx 1/18$，树被剧烈剪枝），实测毫秒级。
- **空间**：DFS 递归深度 $\le 8$，$O(n)$ 栈；无额外大数组。$O(n)$。

## Part 5 · 示例代码（C++）

```cpp
// P1218 特殊的质数肋骨 Superprime Rib
// https://www.luogu.com.cn/problem/P1218
// 右截断质数 = 每个前缀都是质数；DFS 逐位生长，试除判素，个位限定 {1,3,7,9}
#include<bits/stdc++.h>
using namespace std;

int n;

// 纯试除判素，O(sqrt(M))；每个候选值在 DFS 中唯一生成，无需缓存
bool isPrime(int M)
{
	if(M<2)
		return false;
	if(M==2)
		return true;
	if(M%2==0)
		return false;
	for(int i=3;i*i<=M;++i)
		if(M%i==0)
			return false;
	return true;
}

void dfs(int x,int d)
{
	if(d==n)
	{
		cout<<x<<'\n';
		return;
	}
	// 个位只能是 {1,3,7,9}（多位数里偶/5 个位必合数）；升序保证答案升序
	static const int dig[4]={1,3,7,9};
	for(int a:dig)
	{
		int y=10*x+a;
		if(isPrime(y))
			dfs(y,d+1);
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	// 根 = 一位质数，升序进入；n=1 时这里直接输出 2,3,5,7
	for(int r:vector<int>{2,3,5,7})
		dfs(r,1);

	return 0;
}
```

### 代码走查（对照算法步骤）

- `isPrime`：实现引理 2 的试除。`M==2`、偶数特判省掉一半试除。`i*i<=M` 避免开方。
- `dfs(x,d)`：`d==n` 先输出再返回（覆盖 $n=1$ 的根层）。候选位 `dig={1,3,7,9}` 升序；`y=10*x+a` 即"乘 10 加一位"；仅当 `isPrime(y)` 才递归——这正是引理 1 的递推合法性判据。
- `main`：根 `{2,3,5,7}` 升序，`dfs(r,1)` 从深度 1 起长。根升序 + 层内 `a` 升序 ⇒ 整体升序（引理 3）。
- 无额外全局大数组，状态只在递归栈；`'\n'` 换行；`cin.tie/ios` 按风格顺序。

### 为什么不用埃氏筛 / 预存 pr[]

- 筛到 $10^8$ 是 $O(N\ln\ln N)\approx 2.6\times10^8$，秒级边缘，且 $N=10^8$ 的 `bool` 表 $10^8$ 字节 $\approx 100$ MB，吃紧。
- DFS 实际访问的候选值极少（被质数密度剪枝），**按需试除**总运算量远低于全筛，且无大数组。**按需试除是本题在 $n\le 8$ 下最省内存与时间的选择。**
