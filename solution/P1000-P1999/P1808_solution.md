# P1808 单词分类

> 难度：普及- · 标签：字符串、排序

## 1. 重新读题
### 1.1 问题重述（人话版）

给 \(N\) 个只含大写字母的单词，每个长度不超过 100。两个单词算同一类，当且仅当 26 个字母各自出现的次数都相同（字母异位词）。问一共有几类。相同单词当然同类，输出的是类数不是单词数。

### 1.2 关键约束与规模暗示

- \(1\le N\le 10000\)，单词长度 \(L\le 100\)。\(O(N^2 L)\) 的两两比较大约 \(10^8\) 量级，能过但没必要；排序后丢进集合是 \(O(NL\log L+N\log N)\)。
- 只比次数，不比顺序，也不比单词在输入里的位置。
- 字母表只有 26 个大写字母，计数向量或者排序后的字符串都是这个多重集的规范形。

## 2. 思维链（Chain-of-thought）

**引理 1（同类 \(\Leftrightarrow\) 排序后的字符串相等）**

把一个单词里的字符按字典序排成非降序列，得到字符串 \(s^\*\)。两个单词同类，当且仅当它们的 \(s^\*\) 相同。

**证明**：字母出现次数相同，意味着两个单词是同一对字符多重集。一个有限多重集的非降排列是唯一的：最小字符必须排在最前，个数等于它的重数，然后对剩下的多重集递归。所以次数相同 \(\Rightarrow\) 排序结果相同。

反过来，排序不改变每个字符的个数，\(s^\*\) 相同 \(\Rightarrow\) 逐位相同 \(\Rightarrow\) 每个字符的个数相同。\(\square\)

因此类就是这些规范形的集合，类数就是集合的大小。重复单词会得到同一个规范形，`set` 只留一份，符合「分成几类」而不是「有几个不同的原始字符串」。

**引理 2（不用哈希也没有冲突）**

用有序集合存放规范形，相等判断是字符串全等，不存在哈希碰撞把不同的类并成一类、或把同类拆开。

**证明**：`set<string>` 的等价关系就是字典序比较下的相等，而字符串相等是字符序列的逐位相等。引理 1 已经把「同类」定义成规范形逐位相等，两者是同一个关系。\(\square\)

暴力程序不排序，而是给每个单词做长度 26 的计数，再和已经诞生的每一类的计数逐项比较。这和引理 1 是两种规范形（计数向量 / 排序串），对小 \(N\) 用来对拍。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 分类标准只看字母多重集，顺序是干扰项。
- **reduce to easier problem** — 排序把多重集收成唯一字符串。
- **classic problem solution** — 规范形丢进 `set`，输出集合大小。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| \(N\) | `int` | 单词个数 | 读入 | 循环 \(N\) 次 |
| `s` | `string` | 当前单词 | 读入后立刻排序 | 排序就地 |
| `bag` | `set<string>` | 已经出现的规范形 | 空 | 大小 = 类数 |

### 4.2 算法步骤

1. 读 \(N\)。
2. 读每个单词，`sort` 其字符，插入 `bag`。
3. 输出 `bag.size()`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 单次排序 \(O(L\log L)\)，\(L\le 100\)；集合插入 \(O(L\log N)\)。总和 \(O(N L\log L)\)。
- 编译 warn=0。
- 样例 `AABAC / CBAAA / AAABB` 输出 `2`。
- 6 组边界（单词、一对异位词、全相同、长度不同）加 200 组随机（\(N\le 80\)，一半是已有单词的打乱）。暴力用 26 维计数两两归类。共 207 组，随机段 4.057s。
- 满数据计时：\(N=10000\)、每个单词长度 100 的随机大写字母，标程 0.122s，答案 `10000`（长度 100 的随机串几乎不可能撞车）。

## 5. 示例代码
### 5.1 标程（`P1808.cpp`）

```cpp
//
// 题目：P1808 单词分类
// https://www.luogu.com.cn/problem/P1808
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

int n;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	set<string> bag;
	for(int i=0;i<n;++i)
	{
		string s;
		cin>>s;
		sort(s.begin(),s.end());
		bag.insert(s);
	}
	cout<<bag.size()<<'\n';
	return 0;
}
```
