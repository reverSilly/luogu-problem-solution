> 标签：数学 / 枚举 · 难度：普及- · 福建省历届夏令营

## 1. 重新读题

**题面原样**：对一个整数 $n$，若存在两个自然数 $x,y$，满足 $n=x^2-y^2$，则称 $n$ 是 Couple number。给出 $a,b$，求 $[a,b]$ 范围内有多少个 Couple number。

**白话重述**：把 $[-10^7,10^7]$ 内的整数排成一排，凡是能写成"两个平方数之差"的打个勾，问区间 $[a,b]$ 里有多少个勾。注意 $n$ **可以是负数、也可以是 0**（因为 $x<y$ 时差为负），所以不能只想正整数。

**约定（必须写死，否则判据不唯一）**：本文取 $0\in\mathbb{N}$，即 $x,y\ge 0$。这是我国现行教材与国家标准 GB/T 3102 的自然数约定，也是本题绝大多数写法所默认的。§2.7 会精确说明：若换成"$x,y\ge 1$"，判据只在 $\pm1,\pm4$ 这 4 个值上不同。

**数据范围**

| 量 | 范围 |
|---|---|
| $a,b$ | $-10^7\le a<b\le 10^7$ |
| 区间宽度 | $b-a\le 10^7$，即区间内整数个数 $b-a+1\le 10^7+1$ |

没有分档子任务，但"宽度 $\le10^7$"这个额外限制就是在暗示：**允许对区间内每个数做一次 $O(1)$ 判定**（共约 $10^7$ 次），因此不必须写 $O(1)$ 闭式；本文主代码按扫描写，闭式另附于 §5 供对照。题面未给时间限制数值。

## 2. 思维链（Chain-of-thought）

### 2.1 第一步：把"什么算 Couple number"写成精确判据

定义里有两个量词层次要分清：

$$n\text{ 是 Couple number}\iff\exists x\in\mathbb{N},\ \exists y\in\mathbb{N}:\ n=x^2-y^2.$$

所以**表示方式的数量毫不重要**，只要能找到一组 $(x,y)$ 就算。我们要做的不是"数表示"，而是"判定存在性"，再对区间内每个 $n$ 累加。

先把定义做最直接的代数变形（平方差恒等式）：

$$n=x^2-y^2=(x-y)(x+y).$$

记 $u=x-y$，$v=x+y$，则 $u,v\in\mathbb{Z}$，$uv=n$，并且

- $v-u=2y$ 是偶数，$v+u=2x$ 是偶数 $\Rightarrow$ $u\equiv v\pmod 2$（**同奇偶**）；
- $x\ge0\Rightarrow u+v\ge0$；$y\ge0\Rightarrow v-u\ge0$，即 $u\le v$。

反过来，给定一对整数 $(u,v)$ 满足 $uv=n$、同奇偶、$u\le v$、$u+v\ge0$，就能解回 $x,y$。写成引理：

**引理 1（因子化等价刻画）** 设 $n\in\mathbb{Z}$。则"$n$ 是 Couple number"等价于"存在 $u,v\in\mathbb{Z}$ 满足 $uv=n$，$u\equiv v\pmod2$，$u\le v$，$u+v\ge0$"。

**证明**

- $\Rightarrow$：取 $u=x-y$，$v=x+y$。$uv=x^2-y^2=n$；$v-u=2y$、$v+u=2x$ 均为偶数，故 $u,v$ 同奇偶；$y\ge0\Rightarrow u\le v$；$x\ge0\Rightarrow u+v\ge0$。
- $\Leftarrow$：由同奇偶知 $u+v$、$v-u$ 都是偶数，令 $x=\frac{u+v}{2}$，$y=\frac{v-u}{2}$，则 $x,y\in\mathbb{Z}$，且由 $u+v\ge0$ 得 $x\ge0$、由 $u\le v$ 得 $y\ge0$，即 $x,y\in\mathbb{N}$。代入：
$$x^2-y^2=(x-y)(x+y)=u\cdot v=n.\qquad\blacksquare$$

这一步很有用：它把"找一对平方数"换成"找一对**同奇偶**的因子"。

### 2.2 探索性质：模 4 的必要条件

先算平方数模 4 只能是什么。

**引理 2** 对任意整数 $t$，$t^2\bmod 4\in\{0,1\}$。

**证明**：$t$ 偶：$t=2k$，$t^2=4k^2\equiv0$。$t$ 奇：$t=2k+1$，$t^2=4k^2+4k+1=4k(k+1)+1\equiv1$。二选一即穷尽所有整数。$\blacksquare$

**引理 3（必要条件）** 若 $n$ 是 Couple number，则 $n\not\equiv2\pmod4$。

**证明**：$n=x^2-y^2$，由引理 2，$x^2,y^2\in\{0,1\}\pmod4$，差只可能是 $0-0=0$、$1-0=1$、$0-1\equiv3$、$1-1=0$，即 $n\bmod4\in\{0,1,3\}$，永远取不到 $2$。$\blacksquare$

（用引理 1 也能得到同一结论且更直观：$uv=n$ 同奇偶。两奇 $\Rightarrow n$ 奇；两偶 $\Rightarrow 4\mid n$。要 $n\equiv2\pmod4$ 必须"一奇一偶"，与同奇偶矛盾。）

于是"不是 Couple number"的候选全在模 4 余 2 的那一类里：$\{\dots,-6,-2,2,6,10,\dots\}$。剩下只需回答：另三类是否**全都**可以？

### 2.3 充分性：给两类各造一组显式解

**引理 4（奇数）** 设 $n$ 为奇数。取 $x=\left|\frac{n+1}{2}\right|$，$y=\left|\frac{n-1}{2}\right|$，则 $x,y\in\mathbb{N}$ 且 $x^2-y^2=n$。

**证明**：$n$ 奇 $\Rightarrow n\pm1$ 偶 $\Rightarrow \frac{n\pm1}{2}\in\mathbb{Z}$，取绝对值后是非负整数，故 $x,y\in\mathbb{N}$。绝对值不改变平方，故
$$x^2-y^2=\left(\frac{n+1}{2}\right)^2-\left(\frac{n-1}{2}\right)^2=\frac{(n+1)^2-(n-1)^2}{4}=\frac{4n}{4}=n.\qquad\blacksquare$$

**引理 5（4 的倍数）** 设 $4\mid n$，记 $k=\frac{n}{4}\in\mathbb{Z}$。取 $x=|k+1|$，$y=|k-1|$，则 $x,y\in\mathbb{N}$ 且 $x^2-y^2=n$。

**证明**：$k\in\mathbb{Z}\Rightarrow k+1,k-1\in\mathbb{Z}$，取绝对值后 $x=|k+1|\ge0$、$y=|k-1|\ge0$ 仍是整数，故 $x,y\in\mathbb{N}$。展开验恒等式
$$(k+1)^2-(k-1)^2=(k^2+2k+1)-(k^2-2k+1)=4k,$$
而绝对值不改变平方（$|t|^2=t^2$），故 $x^2-y^2=(k+1)^2-(k-1)^2=4k=n$。$\blacksquare$

注意两个构造都用了 $|\cdot|$，正是为了让**负 $n$** 也直接适用（平方后符号消失），所以不需要先证 $n>0$ 再镜像。顺带一个对称性也可以单独说明：

**引理 6（符号对称）** $n$ 是 Couple number $\iff$ $-n$ 是 Couple number。

**证明**：$n=x^2-y^2\Rightarrow -n=y^2-x^2$，把 $x,y$ 互换即可，二者都仍在 $\mathbb{N}$ 中。反向同理（再换回来）。$\blacksquare$

引理 6 说明判据必然关于 0 对称，而 $n\bmod4$ 的判据确实对称（$-2\equiv2\pmod4$），一致。

### 2.4 主定理

**定理（充要判据）** 设 $n\in\mathbb{Z}$，$\bar n$ 为 $n$ 模 4 的下取整余数（$\bar n\in\{0,1,2,3\}$）。则
$$n\text{ 是 Couple number}\iff \bar n\in\{0,1,3\}\iff n\not\equiv2\pmod4.$$

**证明**

- $\Leftarrow$（充分）：$\bar n\in\{1,3\}\Rightarrow n$ 奇，引理 4 给出解；$\bar n=0\Rightarrow 4\mid n$，引理 5 给出解。
- $\Rightarrow$（必要）：逆否命题即引理 3。$\blacksquare$

小表核对（左列按定义手工找解，右列用定理）：

| $n$ | 定义下的一组 $(x,y)$ | $\bar n$ | 定理结论 |
|---|---|---|---|
| $0$ | $(0,0)$ | 0 | 是 |
| $1$ | $(1,0)$ | 1 | 是 |
| $2$ | 因子 $1\times2$ 一奇一偶，无解 | 2 | 否 |
| $3$ | $(2,1)$ | 3 | 是 |
| $4$ | $(2,0)$ | 0 | 是 |
| $6$ | $1\times6,2\times3$ 均不同奇偶，无解 | 2 | 否 |
| $8$ | $(3,1)$ | 0 | 是 |
| $-2$ | 等价于 $y^2-x^2=2$，同上无解 | 2 | 否 |
| $-4$ | $(0,2)$ | 0 | 是 |
| $-12$ | $(2,4)$：$4-16$ | 0 | 是 |

### 2.5 为什么不能"枚举 $(x,y)$ 打表"

题目标签有"枚举"，很容易想到：枚举 $x,y$，把 $x^2-y^2$ 落到 $[a,b]$ 里打勾。这条路要算清两件事。

**其一，见证元可以很大。**

**引理 7（奇素数的见证元唯一）** 设 $p$ 为奇素数。则满足引理 1 四条（$uv=p$、同奇偶、$u\le v$、$u+v\ge0$）的整数对只有 $(u,v)=(1,p)$，从而 Couple 表示 $(x,y)$ 唯一，为 $x=\frac{p+1}{2}$，$y=\frac{p-1}{2}$。

**证明**：$uv=p$ 的整数因子对只有 $(1,p),(p,1),(-1,-p),(-p,-1)$。
- $(p,1)$：$u\le v$ 要求 $p\le1$，矛盾。
- $(-1,-p)$：$u+v=-(p+1)<0$，矛盾。
- $(-p,-1)$：$u+v<0$ 且 $u=-p>v=-1$ 也不满足 $u\le v$，矛盾。
- $(1,p)$：$1\le p$、$1+p$ 为偶（$p$ 奇 $\Rightarrow 1,p$ 同奇偶）✓ 唯一合法。
回代 $x=\frac{1+p}{2}$，$y=\frac{p-1}{2}$。$\blacksquare$

**推论**：任何"枚举 $0\le x,y\le B$ 并打勾"的做法，会漏掉所有满足 $B<\frac{p+1}{2}$（即 $p>2B-1$）的奇素数 $p$——因为引理 7 说明它只有那一组见证元，落在框外。取 $B=\lfloor\sqrt{10^7}\rfloor=3162$，则 $p>6323$ 全漏；取 $B=\lfloor\sqrt{2\times10^7}\rfloor=4472$，则 $p>8943$ 全漏。

**具体反例**：
- $p=6329$（针对 $B=3162$）。素性检验：$\sqrt{6329}<80$，逐一试除 $\le79$ 的 22 个素数，余数依次为 $2\!:\!2,\,3\!:\!2,\,5\!:\!4,\,7\!:\!1,\,11\!:\!4,\,13\!:\!11,\,17\!:\!5,\,19\!:\!2,\,23\!:\!4,\,29\!:\!7,\,31\!:\!5,\,37\!:\!2,\,41\!:\!15,\,43\!:\!8,\,47\!:\!31,\,53\!:\!22,\,59\!:\!16,\,61\!:\!46,\,67\!:\!31,\,71\!:\!10,\,73\!:\!51,\,79\!:\!9$，全部非零，故 6329 为素数。$6329=4\times1582+1\Rightarrow\bar n=1$，判据说是 Couple number；引理 7 给唯一解 $x=3165,y=3164$，验算 $3165^2-3164^2=(3165-3164)(3165+3164)=6329$ ✓，而 $3165>3162$，打表取不到。
- $p=8951$（针对 $B=4472$）。$\sqrt{8951}<95$，试除 $\le89$ 的 24 个素数，余数非零者为 $3\!:\!2,7\!:\!5,11\!:\!8,13\!:\!7,17\!:\!9,19\!:\!2,23\!:\!4,29\!:\!19,31\!:\!23,37\!:\!34,41\!:\!13,43\!:\!7,47\!:\!21,53\!:\!47,59\!:\!42,61\!:\!45,67\!:\!40,71\!:\!5,73\!:\!45,79\!:\!24,83\!:\!70,89\!:\!51$（$2,5$ 由末位 $1$ 直接排除），故 8951 为素数。$\bar n=3$，唯一解 $x=4476,y=4475$：$4476^2-4475^2=4476+4475=8951$ ✓，$4476>4472$。

**其二，即便把界开到够用也不划算。** 要覆盖全部 $n\le10^7$，需 $B\ge\frac{10^7+1}{2}\approx5\times10^6$，配对数 $(5\times10^6+1)^2>2.5\times10^{13}$，比 $10^8$/s 的量级高 5 个数量级；而 $x^2$ 本身也到 $2.5\times10^{13}$，`int` 会溢出（见 §2.8）。

**结论**：把"枚举"从 $(x,y)$ 空间挪到 $n$ 空间——枚举区间内的 $n$（至多 $10^7+1$ 个），每个用定理做 $O(1)$ 判定。这才是数据范围"$b-a\le10^7$"暗示的枚举。

### 2.6 计数：区间内模 4 余 2 的个数

答案是 $(b-a+1)$ 减去 $[a,b]$ 中满足 $n\equiv2\pmod4$ 的个数。

**朴素版**：直接扫一遍 $n=a..b$，累加判定为真的。求和上界 $\sum_{n=a}^{b}1=b-a+1\le 10^7+1$。

**闭式版（$O(1)$，可选）**：

**引理 8** 设 $m$ 为正整数，$r$ 为整数，$\lfloor\cdot\rfloor$ 为**下取整**。则
$$\#\{n\in[a,b]: n\equiv r\pmod m\}=\left\lfloor\frac{b-r}{m}\right\rfloor-\left\lfloor\frac{a-1-r}{m}\right\rfloor.$$

**证明** 分三步。

1. **化为整数 $q$ 的计数**：映射 $q\mapsto mq+r$ 是 $\mathbb{Z}$ 到同余类 $\{n:n\equiv r\pmod m\}$ 的双射（单射因 $m\ne0$，满射由同余定义）。故所求个数 $=\#\{q\in\mathbb{Z}: a\le mq+r\le b\}=\#\{q\in\mathbb{Z}:\frac{a-r}{m}\le q\le\frac{b-r}{m}\}$（除以正数 $m$ 不改不等号方向）。
2. **整数点计数公式**：对实数 $\alpha\le\beta$，$\#\{q\in\mathbb{Z}:\alpha\le q\le\beta\}=\lfloor\beta\rfloor-\lceil\alpha\rceil+1$（区间内整数恰为 $\lceil\alpha\rceil,\lceil\alpha\rceil+1,\dots,\lfloor\beta\rfloor$，首项不小于 $\alpha$、末项不大于 $\beta$，且其间所有整数都落在区间内）。
3. **天花板化地板**：断言对整数 $N$ 与正整数 $m$ 有 $\lceil N/m\rceil=\lfloor(N-1)/m\rfloor+1$。证：写 $N=mt+s$，$0\le s<m$（带余除法）。若 $s=0$，左 $=t$，右 $=\lfloor(mt-1)/m\rfloor+1=(t-1)+1=t$（因 $mt-1=m(t-1)+(m-1)$）。若 $s\ge1$，左 $=t+1$，右 $=\lfloor(mt+s-1)/m\rfloor+1=t+1$（因 $0\le s-1\le m-2<m$）。两情形均成立。

把 $\alpha=\frac{a-r}{m}$、$\beta=\frac{b-r}{m}$ 代入第 2 步，再用第 3 步（$N=a-r$）得
$$\lfloor\beta\rfloor-\lceil\alpha\rceil+1=\left\lfloor\frac{b-r}{m}\right\rfloor-\left(\left\lfloor\frac{a-1-r}{m}\right\rfloor+1\right)+1=\left\lfloor\frac{b-r}{m}\right\rfloor-\left\lfloor\frac{a-1-r}{m}\right\rfloor.\qquad\blacksquare$$

取 $m=4,r=2$：$\#\{\equiv2\}=\lfloor\frac{b-2}{4}\rfloor-\lfloor\frac{a-3}{4}\rfloor$，答案 $=b-a+1-$ 该项。

**坑（务必记住）**：C++ 的 `%` 和 `/` 是**向零取整**，不是下取整。于是 `-1%4==-1`、`-2%4==-2`，且 `-6/4==-1` 而 $\lfloor-6/4\rfloor=-2$。所以
- 判定版要先把余数归一化：`r=n%4; if(r<0) r+=4;` 再比 `r!=2`；
- 闭式版要写一个下取整除法 `flr`，不能直接 `x/4`。

### 2.7 约定敏感性（$0\in\mathbb{N}$ 与 $x,y\ge1$ 的差别）

**引理 9** 若把自然数定义为正整数（$x,y\ge1$），则 Couple 数集合恰好是 $\{n: n\not\equiv2\pmod4\}\setminus\{\pm1,\pm4\}$；即只有 $\pm1,\pm4$ 四个值改变身份。

**证明** 分"多出的四个必须被剔除"与"其余仍可表示"两半。

- $1$：$uv=1$ 的整数对有 $(1,1),(-1,-1)$，前者给 $x=1,y=0$，后者 $u+v=-2<0$ 不合法（引理 1 的四条），故 $n=1$ 在 $y\ge1$ 下无解。$-1$ 由引理 6 对称同理（唯一解是 $x=0,y=1$）。
- $4$：$uv=4$ 的因子对 $(1,4),(2,2),(4,1)$ 及其带负号版本中，同奇偶的只有 $(2,2)$ 与 $(-2,-2)$；前者给 $x=2,y=0$，后者 $u+v=-4<0$ 不合法，故 $n=4$ 需 $y=0$。$-4$ 由引理 6 同理。
- 其余 $\bar n\in\{0,1,3\}$ 都有 $x,y\ge1$ 的解：
  - $n$ 奇且 $n\ge3$：引理 4 的 $x=\frac{n+1}{2}\ge2$，$y=\frac{n-1}{2}\ge1$；$n\le-3$：则 $\frac{n+1}{2}\le-1\Rightarrow x=\left|\frac{n+1}{2}\right|\ge1$，$\frac{n-1}{2}\le-2\Rightarrow y\ge2$。
  - $4\mid n$ 且 $n\ge8$：引理 5 的 $k\ge2$，$x=k+1\ge3$，$y=k-1\ge1$；$n\le-8$：$k\le-2\Rightarrow x=|k+1|=-k-1\ge1$，$y=|k-1|=1-k\ge3$。
  - $n=0$：取 $x=y=1$，$1-1=0$ ✓。
$\blacksquare$

本文按 $x,y\ge0$ 写代码（判据 $n\not\equiv2\pmod4$）。由于题面无样例，**无法用官方数据验证该约定**；若提交后仅因边界 $\pm1,\pm4$ 落入区间而失配，改用引理 9 判据即可（在 `coup` 里加一行 `if(n==1||n==-1||n==4||n==-4) return false;`）。

## 3. 模式总结（Pattern Summary）

- **定义翻译** — 先把 $\exists x,y\in\mathbb{N}$ 写成精确判据，并钉死 $0\in\mathbb{N}$ 的约定（含 §2.7 的敏感性分析）。
- **explore its property** — 平方差因式分解 + 同奇偶：$(x,y)\leftrightarrow(u,v)$ 是双射（引理 1），把"平方差"变成"同奇偶因子对"。
- **necessary condition（模 4）** — 平方数模 4 只取 0/1 $\Rightarrow n\equiv2\pmod4$ 必不可表示（引理 2+3）。
- **constructive sufficiency** — 奇数用 $\left(\frac{n+1}{2}\right)^2-\left(\frac{n-1}{2}\right)^2=n$，$4\mid n$ 用 $(k+1)^2-(k-1)^2=4k$，绝对值处理负数（引理 4+5）。
- **symmetry check** — $n\leftrightarrow -n$ 只是交换 $x,y$（引理 6），用来交叉验证判据的对称性。
- **reduce to easier problem** — 计数化为"区间内模 4 余 2 的个数"，其余都算 Couple。
- **why brute force fails** — 奇素数的见证元唯一且 $x=\frac{p+1}{2}\approx5\times10^6$（引理 7 + 反例 $6329,8951$），$(x,y)$ 打表不可行；把枚举挪到 $n$ 空间（至多 $10^7+1$ 个）。
- **classic problem solution** — 区间同余计数闭式 $\lfloor\frac{b-r}{m}\rfloor-\lfloor\frac{a-1-r}{m}\rfloor$（引理 8）。
- **implementation pitfall** — C++ 的 `%`/`/` 向零取整：负数要先 `+4` 归一化，闭式要写下取整 `flr`。
- **overflow guard** — 平方量 $2.5\times10^{13}$ 超 `int`，一律 `i64`。

| `a`,`b` | 区间端点，题目原值 | `i64`，输入 | $-10^7\le a<b\le10^7$ |
| `mxv` | $\|n\|$ 上界 $=10^7+5$ | `constexpr i64{10000005}` | 只用于读入自检 `assert` |
| `coup(n)` | 判定 $n$ 是否 Couple（$n\bmod4\ne2$） | `bool` 函数 | 定理的正反两面 |
| `r` | $n\bmod4$ 的归一化余数 $\in\{0,1,2,3\}$ | `i64` 局部 | 负数先 `+=4` |
| `ans` | $[a,b]$ 内 Couple 个数 | `i64`，0 | $\le 10^7+1$ |
| `n` | 扫描变量 | `i64`，$a\to b$ | 直接用题目数值 |
| `flr(x)` | $\lfloor x/4\rfloor$（下取整） | `i64` 函数（闭式版） | $x<0$ 且非整倍时 $-1$ |

**下标约定**：本解法无数组、无 0/1-based 转换，全程使用题目原始整数值 $n\in[a,b]$。

### 4.2 算法步骤

1. 读入 `a,b`；`assert` 自检 $|a|,|b|\le$ `mxv`。
2. `ans=0`；`for(n=a;n<=b;++n)`：调 `coup(n)`，真则 `++ans`。
   - `coup`：`r=n%4; if(r<0) r+=4; return r!=2;`
3. 输出 `ans`。
4. （可选加速，同一判据）$O(1)$ 闭式：`cnt2=flr(b-2)-flr(a-3); ans=(b-a+1)-cnt2;`，其中 `flr(x)` 实现 $\lfloor x/4\rfloor$。

**复杂度算式**

- 时间：$\sum_{n=a}^{b}O(1)=O(b-a+1)$，其和的上界为 $\sum_{n=a}^{b}1=b-a+1\le 10^7+1$ 次判定；每次判定是 1 次取模 + 1 次比较（可能再加 1 次加法）+ 1 次比较 + 可能 1 次自增，故基本操作总数 $\le 5\times(10^7+1)\approx5\times10^7$。按 $10^8$ 次基本操作/秒的**常识量级估算**（本环境不可运行，未实测）应在常见 1s 时限内；闭式版为 $O(1)$，与区间宽度无关。
- 空间：$O(1)$，仅若干标量。

### 4.3 验证（全部手算，无编译器可用）

纪律：本环境无编译器，**禁止编译/运行**，故以下为纯手算核对，且**无法与官方答案对标**（题面未给样例）。

**(1) 按定义直接枚举小范围 $[0,20]$**。取 $x,y\le12$（够大以覆盖所需见证），其平方差落在 $[0,20]$ 的取值为
$$\{0,1,3,4,5,7,8,9,11,12,13,15,16,17,19,20\}\ (16\text{ 个}),$$
逐项见证：$0=0^2-0^2$，$1=1^2-0^2$，$3=2^2-1^2$，$4=2^2-0^2$，$5=3^2-2^2$，$7=4^2-3^2$，$8=3^2-1^2$，$9=3^2-0^2$，$11=6^2-5^2$，$12=4^2-2^2$，$13=7^2-6^2$，$15=4^2-1^2$，$16=4^2-0^2$，$17=9^2-8^2$，$19=10^2-9^2$，$20=6^2-4^2$（最大 $x=10\le12$）。
缺的 $2,6,10,14,18$ 恰是 $[0,20]$ 中全部 $\bar n=2$ 的数；它们不可表示由引理 3（必要条件）保证，另用引理 1 直查因子对：$2=1\times2$、$6\in\{1\times6,2\times3\}$、$10\in\{1\times10,2\times5\}$、$14\in\{1\times14,2\times7\}$、$18\in\{1\times18,2\times9,3\times6\}$，每对都是一奇一偶，无同奇偶解 ✓。故 $[0,20]$ 内 Couple 数 $=21-5=16$，与枚举完全一致。

**(1b) `coup` 在负数上的逐步跟踪**（验证归一化那一行）：
- $n=-2$：C++ 里 `-2%4` 得 `-2`，于是 `if(r<0)` 成立，归一化后 $r=-2+4=2$，`r!=2` 为假 $\Rightarrow$ 判"不是" ✓（定义：$y^2-x^2=2$ 无同奇偶因子对）。
- $n=-1$：$-1\%4=-1\Rightarrow r=3\Rightarrow$ 判"是" ✓（$0^2-1^2$）。
- $n=-4$：$-4\%4=0\Rightarrow r=0\Rightarrow$ 判"是" ✓（$0^2-2^2$）。
- $n=-3$：$-3\%4=-3\Rightarrow r=1\Rightarrow$ 判"是" ✓（$1^2-2^2$）。
若省掉 `if(r<0) r+=4;`，$n=-2$ 会得 $r=-2$，而 `-2!=2` 为真，被误判为 Couple，答案偏大——这是负数区间上最容易踩的坑。

**(2) 负端对称 $[-12,12]$**：$\bar n=2$ 的有 $-10,-6,-2,2,6,10$ 共 6 个 $\Rightarrow$ 预测 $25-6=19$。负数见证抽样：$-1=0^2-1^2$，$-4=0^2-2^2$，$-5=2^2-3^2$，$-8=1^2-3^2$，$-12=2^2-4^2$；不可能者 $-2,-6,-10$ 的因子对 $1\times2,2\times3,1\times10$ 全为一奇一偶。一致。

**(3) 自造例 $a=1,b=10$**：判据给出非 Couple $\{2,6,10\}$ $\Rightarrow$ `ans=7`；定义法逐个 $1=(1,0),3=(2,1),4=(2,0),5=(3,2),7=(4,3),8=(3,1),9=(3,0)$ 共 7 个。闭式：$\lfloor8/4\rfloor-\lfloor-2/4\rfloor=2-(-1)=3$，$10-3=7$。✓

**(4) 自造例 $a=-5,b=5$（跨 0 边界）**：$L=11$，非 Couple $\{-2,2\}$ $\Rightarrow$ `ans=9`（定义列举 $-5,-4,-3,-1,0,1,3,4,5$ 共 9）。闭式：$\lfloor3/4\rfloor-\lfloor-8/4\rfloor=0-(-2)=2$，$11-2=9$。✓

**(5) 自造例 $a=2,b=3$（最小宽度且含 $\bar n=2$）**：$L=2$，非 Couple $\{2\}$ $\Rightarrow$ `ans=1`。闭式：$\lfloor1/4\rfloor-\lfloor-1/4\rfloor=0-(-1)=1$，$2-1=1$。✓

**(6) 自造例 $a=-3,b=-2$（负端最小宽度）**：$-3$ 是（$(1,2)$），$-2$ 否 $\Rightarrow$ `ans=1`。闭式：$\lfloor-4/4\rfloor-\lfloor-6/4\rfloor=-1-(-2)=1$，$2-1=1$。✓（这例正是检验 `flr` 不能被 C++ 截断除法替代：`-6/4==-1` 会算成 0，得 `ans=2` 错误。）

**(7) 规模上界 $a=-10^7,b=10^7$**：$L=20000001$。判据：非 Couple 数为 $4q+2\in[-10^7,10^7]$，由 $-10^7\le4q+2\le10^7$ 得 $-2500000.5\le q\le2499999.5$，整数 $q\in[-2500000,2499999]$，共 $2499999-(-2500000)+1=5000000$ 个 $\Rightarrow$ `ans=20000001-5000000=15000001`。闭式核对：$\lfloor9999998/4\rfloor=2499999$，$\lfloor-10000003/4\rfloor=-2500001$（注意 $-10000003/4=-2500000.75$，下取整为 $-2500001$），差 $=5000000$ ✓。分块核对：$10^7\equiv0\pmod4$，区间从余 0 起、长度 $4\times5000000+1$，含 $5000000$ 个完整周期 + 1 个余 0 的尾巴，故余 2 者恰 $5000000$ 个 ✓。

**(7b) 宽度恰为上界 $a=0,b=10^7$（$b-a=10^7$）**：$L=10000001$；$4q+2\in[0,10^7]\Rightarrow q\in[0,2499999]$，共 $2500000$ 个 $\Rightarrow$ `ans=7500001`。闭式：$\lfloor9999998/4\rfloor-\lfloor-3/4\rfloor=2499999-(-1)=2500000$ ✓（这例检验 $a=0$ 时下界项不该是 0，而是 $-1$）。

**(8) 大见证元自检（说明为什么不能小范围打表）**：$n=9999999$（奇，$\bar n=3$）判为 Couple；引理 4 给 $x=5000000,y=4999999$，用 `i64` 验 $x^2-y^2=(x-y)(x+y)=1\times9999999$ ✓，而 $x^2=2.5\times10^{13}$ 已超 `int`，与 §2.8 一致。

**(9) 时间/空间自检算式**：$5\times(10^7+1)\approx5\times10^7$ 次基本操作 $<10^8$，$O(1)$ 空间，无数组越界风险（不开数组）。

### 4.4 不确定点

- 自然数是否含 0 无法用题面样例证实（题面无数值样例）；影响面仅 $\pm1,\pm4$，见引理 9 与特判方案。
- 时间限制未在题面给出；若极限 $10^7$ 扫描被判超时，改用 §4.2 步骤 4 的 $O(1)$ 闭式即可，判据不变。

## 5. 示例代码（C++）

```cpp
// P1348 Couple number
// 数论判据 n 是 Couple <=> n mod 4 != 2，再对 [a,b] 线性扫描计数
// https://www.luogu.com.cn/problem/P1348
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr i64 mxv{10000005};   // |n| 上界 10^7 +5 松弛；本题不开数组，仅用于读入自检

i64 a,b;

// 定理：n 可写成 x^2-y^2 (x,y∈N) 当且仅当 n mod 4 != 2
bool coup(i64 n)
{
	i64 r=n%4;          // C++ 的 % 向零取整，n<0 时 r 可能为 -1/-2/-3
	if(r<0)
		r+=4;           // 归一化到 {0,1,2,3}
	return r!=2;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b;
	assert(-mxv<=a&&a<=mxv&&-mxv<=b&&b<=mxv&&a<b);

	i64 ans=0;
	for(i64 n=a;n<=b;++n)     // 循环次数 = b-a+1 <= 10^7+1
		if(coup(n))
			++ans;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **无数组状态**：判据是纯算术的，$O(1)$ 空间即可，故没有 `mxn` 尺寸的静态数组；`constexpr` 常量 `mxv` 用来文档化 $|n|\le10^7$ 这一不变量（配合 `assert`，符合风格规范第 13 节）。
- **`coup` 的归一化**：这是全题最容易错的一行。`-2%4` 在 C++ 里是 `-2`，若直接写 `return n%4!=2;` 会把 $-2,-6,-10,\dots$ 误判为 Couple（正确结论：不是）。
- **`'\n'`、Tab 缩进、运算符无空格、小写电报式函数名**：按规范。

### 可选：$O(1)$ 闭式版（同一判据，供对照）

```cpp
// 下取整除法 flr(x)=floor(x/4)：C++ 的 x/4 是向零取整，负数非整倍时要 -1
i64 flr(i64 x)
{
	i64 q=x/4;
	if(x-q*4<0)      // 余数与 x 同号，故只在 x<0 且不整除时偏大
		--q;
	return q;
}

// [a,b] 中模 4 余 2 的个数 = floor((b-2)/4)-floor((a-3)/4)
i64 calc()
{
	i64 cnt2=flr(b-2)-flr(a-3);
	return b-a+1-cnt2;
}
```

两版在 §4.3 的例 (3)(4)(5)(6)(7)(7b) 上手算结果一致（7、9、1、1、15000001、7500001）；例 (6) 说明 `flr` 不可用 `x/4` 代替，例 (7b) 说明下界项在 $a=0$ 时是 $-1$ 而非 $0$。主代码用扫描版（判据唯一来源，少一处可错的除法），闭式版作为 $O(1)$ 备选。
