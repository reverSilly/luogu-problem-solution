# P1502 窗口的星星

> 标签：线段树 / 离散化 / 扫描线 · 难度：省选/NOI-

## 1. 重新读题

一句话：**给定 $n$ 个带权整点，求一个 $W\times H$ 的边平行矩形（边框上的点不算）最多能覆盖多少总权值。**

- 窗口可任意放置，位置**不要求整数**（题面没有任何整点位置的约束）。
- "金属边框"⇒ 覆盖判定是**严格不等式**：左下角 $(X,Y)$ 时，星星 $(x_i,y_i)$ 被看到当且仅当 $X<x_i<X+W$ 且 $Y<y_i<Y+H$。
- $0\le l_i\le 1000$（非负！这一点后面会用来把最优点"推"到格子内部）。

| 量 | 范围 | 备注 |
|---|---|---|
| $T$ | $\le 10$ | 多测，需清表 |
| $n$ | $\le 10^4$ | $O(n^2)$ 勉强、$O(n^3)$ 必死 |
| $W,H$ | $\le 10^6$ | 与坐标同数量级 |
| $x_i,y_i$ | $[0,2^{31})$ | 值域巨大 ⇒ 必须离散化 |
| $l_i$ | $\le 1000$ | 总和 $\le 10^7$ |

**输入输出格式细节**

- 第一行 $T$，每组数据一行 $n,W,H$，接 $n$ 行 $x_i,y_i,l_i$。
- 输出 "$T$ 个整数"——一行一个（见下文 Hint）。

**Hint 的两条信息**

1. "为了便于理解，输入样例中每组数据之间添加了空行，实际测试数据中并无空行。"
   —— 这是在提醒：**题面里的样例被人为插了空行**。用 `cin>>` 读整数天然跳过任意空白，所以这条对我们无影响；但若改用 `getchar`/逐行读（`getline`）就会被空行坑到。这是一条"读入方式"的坑，不是算法信息。
2. "小卡买的窗户框是金属做的，所以在边框上的不算在内。"
   —— 这是本题最容易做错的一句，它把覆盖判定从 $\le$ 变成 $<$（严格），并直接决定了后面离散化时**区间端点该怎么写**。

**关于样例**：本地题面 `P1502.md` 只有 Hint 提到"输入样例"，**并没有真正给出任何输入输出样例**，因此本文无法与官方答案对标；§5.1 用 4 组自造数据做纯手算验证（含轨迹），并逐格与"把窗口真的摆到某个位置去数星星"的暴力语义对照。

**外部提示与题面的关系**：题目标签为「线段树 / 离散化 / 扫描线」，与下文解法一致；题面正文没有任何"窗口必须放在整点位置"的约束，因此按**连续放置**理解（这也是 §2.6 那个坑的根源）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制：把"星星"翻译成"窗口左下角的区域"

先别急着想办法。先把题目的**判定条件**换成另一种说法，这是处理"固定尺寸窗口/雷达/井盖"类题目的第一反应。

窗口的位置完全由**左下角** $(X,Y)$ 决定（$2$ 个自由度）。星星 $i$ 被看见的条件是

$$X<x_i<X+W,\qquad Y<y_i<Y+H .$$

把不等式解成"关于 $X,Y$ 的条件"：

$$x_i-W<X<x_i,\qquad y_i-H<Y<y_i .$$

于是**视角翻转**成功：

> 星星 $i$ 不再是平面上的一个点，而是"参数平面（左下角 $(X,Y)$ 的平面）"上的一个**开矩形**
> $$R_i=(x_i-W,\;x_i)\times(y_i-H,\;y_i),$$
> 权值 $l_i$。放窗口 $=$ 在参数平面上选一个点 $(X,Y)$，看到的亮度总和 $=$ 包含该点的矩形的**带权深度**。

**问题重述**：给定 $n$ 个带非负权值的开矩形，求被覆盖权值最大的点。这就是经典的"最大带权矩形深度"。

参数平面被所有矩形的边切成了许多小块。所有竖直边在 $x$ 坐标 $\{x_i-W,\;x_i\}$ 上，所有水平边在 $\{y_i-H,\;y_i\}$ 上。

**引理 1（开矩形族在"格子"上恒定）**
把 $2n$ 个竖直边坐标去重排序记为 $a_0<a_1<\cdots<a_{p-1}$，水平边坐标记为 $b_0<\cdots<b_{q-1}$。对任意 $k$，开区间 $(a_k,a_{k+1})$ 内不含任何矩形的竖直边，故任一 $R_i$ 要么包含整个 $(a_k,a_{k+1})$ 在 $x$ 方向的投影，要么与它不交；$y$ 方向同理。因此对每个"格子" $G_{k,t}=(a_k,a_{k+1})\times(b_t,b_{t+1})$，覆盖它的矩形集合是**常数**。

**证明**：固定 $y$ 只看 $x$。对每个 $i$ 记 $\varphi_i(X)=[\,X\in(x_i-W,x_i)\,]$。$\varphi_i$ 只在 $X=x_i-W$ 与 $X=x_i$ 两处可能改变取值：若 $X_0\notin\{x_i-W,x_i\}$，取 $\varepsilon<\min(|X_0-(x_i-W)|,|X_0-x_i|)$，则 $(X_0-\varepsilon,X_0+\varepsilon)$ 内所有 $X$ 与 $X_0$ 同时属于或同时不属于 $(x_i-W,x_i)$。现取 $X,X'\in(a_k,a_{k+1})$，因 $(a_k,a_{k+1})$ 内不含任何 $a_j$ 而 $\{x_i-W,x_i\}\subseteq\{a_j\}$，故 $X,X'$ 之间没有 $\varphi_i$ 的跳变点，$\varphi_i(X)=\varphi_i(X')$。同理 $\psi_i(Y)=\psi_i(Y')$。两者独立，$(X,Y)\in R_i\iff(X',Y')\in R_i$，整个格子的覆盖集合相同。$\blacksquare$

（关键只有一条：**相邻两条竖直边之间的带是原子的**，任何矩形的左边或右边都不会从中间穿过。）

**引理 2（最优点可以取在格子内部）**
存在一个格子 $G_{k,t}$ 的内部点达到最大值。

**证明**：任取参数平面上一点 $(X,Y)$，把它"推进"格子内部且权值不减。
- 若 $X$ 本来就在某格子内部，则 $X'=X$。
- 若 $X$ 是某条竖直边 $a_j$（$j<p-1$）：取 $X'\in(a_j,a_{j+1})$。设矩形 $R_i$ 在 $x$ 方向覆盖 $a_j$，记其左右边 $u=x_i-W<v=x_i$，二者都属于 $\{a_0,\dots,a_{p-1}\}$。由 $u<a_j$ 且都是边界得 $u\le a_{j-1}<a_j$（否则 $u$ 落在 $(a_{j-1},a_j)$ 内部，与相邻矛盾）；由 $v>a_j$ 得 $v\ge a_{j+1}>X'$。于是 $u<X'<v$，即**向右挪进相邻格子不会丢失任何原本被覆盖的矩形**，覆盖集合只增不减。
- 若 $X=a_{p-1}$（最大边界）：$x_i>X$ 与"$x_i$ 是边界且 $a_{p-1}$ 最大"矛盾，故该竖线上无任何矩形覆盖，任取相邻格子内部都不劣。
- $Y$ 方向独立做同样操作得 $Y'$。

于是格子 $G$（含 $(X',Y')$ 的那个）的覆盖集合 $\supseteq$ 点 $(X,Y)$ 的覆盖集合。因 $l_i\ge 0$，格子内任意一点的权值和 $\ge$ 原点的权值和。对最优点用一次即得结论。$\blacksquare$

> **这一步为什么必须要求 $l_i\ge0$**：如果允许负权星星，"边界上不算"反而可能更优（站在边界可以把暗星排除掉）。题面 $0\le l_i$ 正好让"往格子里挪"永不劣化。数据范围里的这个下界不是随手写的。

于是原问题被化成一个**有限**问题：

$$\text{答案}=\max_{0\le k<p-1,\;0\le t<q-1}\ \sum_{i:\;G_{k,t}\subseteq R_i}l_i .$$

格子数上界：$(2n-1)^2\approx 4\times10^8$ —— 仍然太大，但已经从"无穷多个位置"降到"有限个候选"，这是第一个实质性进展。

### 2.2 简化版：把高度去掉，只看 $x$ 方向

先解一个明显更简单的问题：$n$ 个**开区间** $(u_i,v_i)$，每个带非负权 $l_i$，求数轴上一点被覆盖的权值和最大。

**做法**：把每个区间拆成两个事件 $(u_i,+l_i)$、$(v_i,-l_i)$，按坐标排序，从左往右累加 $cur$，边走边取 $\max$。复杂度 $O(n\log n)$（排序主导）。

**引理 3（一维扫描线正确性）**
上述扫描得到的最大值等于 $\max_X\sum_i l_i[X\in(u_i,v_i)]$。

**证明**：设去重排序后的端点为 $c_0<\cdots<c_{m-1}$。仿照引理 1，值函数 $f(X)=\sum_i l_i[X\in(u_i,v_i)]$ 在每个开区间 $(c_k,c_{k+1})$ 上恒定（每个 $[\cdot]$ 只在自己的端点处翻转），且由引理 2 的一维版本，最大值可在某个 $(c_k,c_{k+1})$ 内部取到（边界处覆盖的区间集合是右邻区间的子集）。扫描过程在"处理完坐标 $c_k$ 的所有事件"之后，$cur=\sum_{i:u_i\le c_k}l_i-\sum_{i:v_i\le c_k}l_i=\sum_{i:u_i\le c_k<v_i\text{ 且 }c_k\text{ 之后仍有效}}l_i$。严格核对：区间 $i$ 对 $cur$ 有贡献 $\iff$ 已处理它的事件 $u_i$（即 $u_i\le c_k$）且尚未处理 $v_i$（即 $v_i>c_k$）$\iff u_i\le c_k<v_i$。而对格子 $(c_k,c_{k+1})$ 内的 $X$，$X\in(u_i,v_i)\iff u_i\le c_k$ 且 $v_i\ge c_{k+1}>c_k$（同引理 2 的推导：$u_i,c_k$ 同为端点集元素，$u_i<X\Rightarrow u_i\le c_k$；$v_i>X\Rightarrow v_i\ge c_{k+1}$），故贡献集合完全一致，$cur$ 正好是 $f$ 在格子 $(c_k,c_{k+1})$ 上的取值。对所有格子取 $\max$ 即为全局最大。$\blacksquare$

> **一维版的收获**：①"事件 + 排序 + 扫描"是处理这类问题的骨架；②真正需要维护的不是一个标量 $cur$，而是**另一维上的函数**——因为二维里每个格子还带着一层 $y$。

回到二维。固定 $x$ 方向的格子 $k$，定义 $y$ 方向的"剖面"：

$$F_k(Y)=\sum_{i:\,\text{格子 }k\subseteq(x_i-W,x_i)}l_i\,[\,Y\in(y_i-H,y_i)\,].$$

要求的是 $\max_k\max_Y F_k(Y)$。由引理 1，当 $X$ 在格子 $k$ 内平移时，参与求和的 $i$ 的集合不变。

**关键观察（扫描线的可增量性）**
把 $k$ 从 $0$ 增到 $1$，$x$ 方向有效集合的变化**只有一批区间的进入与一批区间的离开**：$X$ 跨过竖直边 $a_j$ 时，恰好是"以 $a_j$ 为左边的矩形"加入、"以 $a_j$ 为右边的矩形"退出。也就是说，$F$ 的表达式在每一步只做若干个**"给 $y$ 区间 $(y_i-H,y_i)$ 整体加/减 $l_i$"** 的操作，而我们每一步都想知道 **$\max_Y F(Y)$**。

于是问题被压缩成一句话：

> **维护一个（离散化的）$y$ 轴数组，支持"区间加"和"全局最大值查询"，一共 $2n$ 次修改、$O(n)$ 次查询。**

这就是**线段树**的经典用途（区间加 + 区间 max），一维扫描线负责"降维"，线段树负责"另一维的最值"。

### 2.3 直接暴力为什么不行 —— 三条死路和它们各自的教训

有了"格子"这个有限候选集，先老实估一下朴素做法。

**死路 1：坐标值域上的二维前缀和。**
把星星按坐标铺进网格，$sum[x][y]$ 表示左下角在 $(x,y)$ 时的亮度，用 $\text{row}[x][y]$ 差分，然后前缀和 + 窗口查询。这在 $x,y\le 10^3$ 时是标准做法。但题面 $0\le x_i,y_i<2^{31}$，数组根本开不下（$2^{31}\times 2^{31}$）。
> 教训：**值域太大 → 必须离散化**。而离散化的正确姿势由引理 1 给出：不是"把出现的坐标点收集起来"，而是"收集**边界**，对**相邻边界之间的格子**建索引"。这个区别正是 §2.6 的坑。

**死路 2：枚举格子 + 每格暴力数星星。**
格子 $(2n-1)^2\approx 4\times10^8$ 个，每格再扫 $n=10^4$ 颗星星 $\Rightarrow 4\times10^{12}$ 次操作。就算只枚举"非空"格子也仍然是 $O(n^3)$ 量级，差 $4$ 个数量级以上。

**死路 3：只枚举 $x$ 格子，对每个 $x$ 格子重做一维扫描。**
$x$ 格子 $O(n)$ 个，每个内部对 $y$ 做一次 $O(n\log n)$ 的一维扫描线 $\Rightarrow O(n^2\log n)\approx 10^8\times 14\approx1.4\times10^9$，$T\le10$ 再乘十倍。仍然超时。
> 教训：这条死路**离正解最近**。它浪费在"每次重扫 $y$"上。而相邻两个 $x$ 格子的 $y$ 剖面只差几次区间加减（§2.2 末尾的观察）——**把这个"只差一点点"利用起来，就是扫描线 + 线段树**：把外层 $O(n)$ 次重做，变成 $O(n)$ 次 $O(\log n)$ 的增量更新。

### 2.4 贪心为什么不行 —— 一次具体的失败与它的根因

看到"最大值"，第一反应往往是贪心。试三条，全部构造小数据打穿。

**贪心 A：先选最亮的星星，把窗口贴着它放。**
反例（$n=4,W=3,H=1$）：

```
4 3 1
10 0 100
1 0 60
2 0 60
3 0 60
```

最亮星在 $(10,0)$，"贴着它放"得 $100$；而取 $X=0.5,Y=-0.5$，窗口 $(0.5,3.5)\times(-0.5,0.5)$ 含整数 $x\in\{1,2,3\}$、$y=0$，一次拿到 $180$。
> 贪心 A 失败：局部最亮 ≠ 全局最优（暗星抱团更值钱）；而且"贴着"这个词本身就有歧义——贴左框还是贴右框？边框上的还不算！

**贪心 B：先按"边缘分布"选最好的 $x$ 带（把每颗星的亮度全记到它能落入的 $x$ 位置上，取一维最大值），再在该带里选最好的 $y$ 段。**
这是把二维拆成两个一维的贪心，看起来非常合理（一维版本 §2.2 确实是对的）。反例（$n=4,W=5,H=5$）：

```
4 5 5
0 0 7
0 8 7
2 3 5
2 4 5
```

- $x$ 边缘：带 $x=0$ 总亮度 $7+7=14$，带 $x=2$ 总亮度 $5+5=10$ ⇒ 贪心选 $x$ 带 $0$。
- 在该带内选 $y$：$y=0$ 与 $y=8$ 相差 $8$，而高为 $5$ 的开窗口最多容纳整数跨度 $\le 4$（见 §2.6 引理 7），两星无法同框 ⇒ 贪心输出 $7$。
- 真实最优：$X=-0.5,Y=-0.5$，窗口 $( -0.5,4.5)\times(-0.5,4.5)$ 含整数 $x\in\{0,1,2,3,4\}$、$y\in\{0,1,2,3,4\}$，覆盖 $(0,0),(2,3),(2,4)$ ⇒ $7+5+5=17$。
- 手算确认 $17$ 是上界：四颗星同框需 $y$ 跨度 $\le4$，但 $y=0$ 与 $y=8$ 跨度 $8$ ⇒ 至多 $\{(0,0),(2,3),(2,4)\}=17$ 或 $\{(0,8),(2,4)\}=12$，取 $17$。

> 失败根因（一句话）：**"最大化边缘和"与"最大化联合和"不是一回事**。一维时边缘就是联合，所以一维贪心/扫描都对；二维时，把 $y$ 信息压扁成 $x$ 的标量会丢掉"哪些星能同时在高度方向共存"这个约束。要保住这个约束，就必须让 $y$ 方向的结构在扫描过程中**活着** —— 这正好是线段树的角色。
>
> 换句话说：贪心 B 的失败恰好告诉我们，扫描线上每个 $x$ 位置需要维护的对象是**一个关于 $y$ 的函数**（§2.2 的 $F_k(Y)$），而不是一个数。

### 2.5 经典解法：扫描线（外层）+ 离散化（$y$ 轴）+ 线段树（区间加 / 全局 max）

把 §2.2 末尾那句"维护一个支持区间加、全局最大值的数据结构"落实成代码，需要解决三件事：**格子怎么编号**、**事件按什么顺序处理**、**线段树怎么不写 push_down**。

**(a) 格子编号。**
收集 $y$ 方向的全部边界 $\{y_i-H,\;y_i\}_{i=1}^{n}$，排序去重得 $b_0<b_1<\cdots<b_{q-1}$（$q\le 2n$）。格子 $C_t=(b_t,b_{t+1})$，$t=0,\dots,q-2$，共 $q-1$ 个。

**引理 4（一个矩形的 $y$ 覆盖是一段连续格子下标，且恰为半开区间）**
$R_i$ 在 $y$ 方向覆盖的格子集合恰为 $\{C_t: \mathrm{idx}(y_i-H)\le t\le \mathrm{idx}(y_i)-1\}$，即下标半开区间 $[\,\mathrm{idx}(y_i-H),\ \mathrm{idx}(y_i)\,)$，其中 $\mathrm{idx}(\cdot)$ 是边界值在去重表中的下标。

**证明**：$C_t\subseteq(y_i-H,y_i)\iff b_t\ge y_i-H$ 且 $b_{t+1}\le y_i$。
- 必要性：若 $b_t<y_i-H$，则 $y_i-H$ 是严格落在 $(b_{t-1},b_{t+1})$ 内或等于某边界的值。$y_i-H$ 本身是边界（属于 $\{b_j\}$），$b_t<y_i-H$ 且 $C_t$ 与 $(y_i-H,y_i)$ 有交，则 $y_i-H\in(b_t,b_{t+1})$ 或 $y_i-H=b_{t'}$；前者与"$b_t,b_{t+1}$ 相邻、其间无边界"矛盾；后者给出 $t'>t$ 且 $b_{t'}=y_i-H\in C_t\cap(y_i-H,y_i)$，但 $C_t$ 是开区间不含 $b_{t'}$，故 $C_t$ 中被 $y_i-H$ 切掉左半的部分不被 $R_i$ 覆盖，与"格子是原子的、要么全盖要么不盖"（引理 1 的格版本）矛盾。
- 充分性：$b_t\ge y_i-H$ 且 $b_{t+1}\le y_i$ 时，$C_t=(b_t,b_{t+1})\subseteq[y_i-H,\,y_i]\supseteq$ 开区间包含关系成立（端点处 $b_t$ 若等于 $y_i-H$ 也不影响，因 $C_t$ 是开区间不含 $b_t$）。
把两个条件翻译成下标：$b_t\ge y_i-H\iff t\ge\mathrm{idx}(y_i-H)$；$b_{t+1}\le y_i\iff t+1\le\mathrm{idx}(y_i)$。$\blacksquare$

（同理对 $x$：$R_i$ 覆盖的 $x$ 格子下标是 $[\,\mathrm{idx}(x_i-W),\ \mathrm{idx}(x_i)\,)$。注意 $H\ge1\Rightarrow y_i-H<y_i\Rightarrow \mathrm{idx}(y_i-H)<\mathrm{idx}(y_i)$，所以这段格子**非空**，不会写出空区间。）

**(b) 事件顺序。**
每个星星产生两个 $x$ 事件：在下标 $\mathrm{idx}(x_i-W)$ 处"把 $y$ 区间 $[\mathrm{idx}(y_i-H),\mathrm{idx}(y_i))$ 加 $l_i$"，在下标 $\mathrm{idx}(x_i)$ 处"减 $l_i$"。按 $x$ 下标从小到大处理，**同一个下标上的一批事件全部处理完，然后查询一次全局最大值**。

**引理 5（"先批处理再查询"给出的正是右邻格子的剖面）**
处理完 $x$ 边界下标 $k$ 上的所有事件之后，线段树中格子 $C_t$ 的值等于剖面 $F_k$ 在格子 $(a_k,a_{k+1})\times C_t$ 上的权值和。

**证明**：星星 $i$ 对处理完 $k$ 后的 $C_t$ 有贡献 $\iff$ 它的 $+l_i$ 已生效（$\mathrm{idx}(x_i-W)\le k$）且 $-l_i$ 未生效（$\mathrm{idx}(x_i)>k$）$\iff \mathrm{idx}(x_i-W)\le k<\mathrm{idx}(x_i)$。另一方面，$X\in(a_k,a_{k+1})$ 时 $X\in(x_i-W,x_i)$：由引理 2 证明中的整段论证，$x_i-W\le a_k$（即 $\mathrm{idx}(x_i-W)\le k$）且 $x_i\ge a_{k+1}>a_k$（即 $\mathrm{idx}(x_i)\ge k+1$，即 $\mathrm{idx}(x_i)>k$）。反向同理：$\mathrm{idx}(x_i-W)\le k<\mathrm{idx}(x_i)$ 意味着 $x_i-W\le a_k<a_{k+1}\le x_i$，从而整个 $(a_k,a_{k+1})$ 落在开区间 $(x_i-W,x_i)$ 内（端点等号无害，因为格子是开区间）。两条件等价，$y$ 方向由引理 4 一致，故逐点相等。$\blacksquare$

> 注意这里"加减同批处理"不会有顺序问题：同一坐标 $a_k$ 上，**结束**（$v_i=a_k$）的矩形必须被移除，**开始**（$u_i=a_k$）的矩形必须被加入，两者对右邻格子 $(a_k,a_{k+1})$ 都是正确的最终状态。所以先加后减、先减后加都无所谓，只要**查询放在整批之后**。若把查询插在两个同坐标事件之间，就会读到"根本不存在的位置"（边框本身），得到偏小但无害的值；但**反过来**（边框上的星星被算进来）才会致命，见 §2.6。

**(c) 线段树：只查全局最大值，所以可以不 push_down。**
节点 $i$ 覆盖格子区间 $[l,r)$，维护

$$\mathit{tr}[i]=\text{该区间内格子的最大权值和},\qquad \mathit{tag}[i]=\text{覆盖整个 }[l,r)\text{ 但没往儿子传的加量}.$$

转移只有两条：整覆盖时 `tr[i]+=v, tag[i]+=v`；否则递归儿子后 `tr[i]=max(tr[ls],tr[rs])+tag[i]`。

**引理 6（不变式）**
任意时刻，对每个节点 $i$（区间 $[l,r)$）有
$$\mathit{tr}[i]=\max_{t\in[l,r)}\Big(\sum_{j:\ \text{已施加的更新 }j\text{ 的区间覆盖 }t}v_j\Big)=\max\big(\mathit{tr}[\mathit{ls}(i)],\ \mathit{tr}[\mathit{rs}(i)]\big)+\mathit{tag}[i].$$

**证明**（对每次更新的递归做归纳）：初始全 $0$，平凡成立。设执行一次 `add(L,R,v)`。
- 若 $[l,r)$ 与 $[L,R)$ 不交：不进入该节点，其 $tr,tag$ 均不变，子树内所有格子取值不变，等式仍成立。
- 若 $[L,R)\supseteq[l,r)$：该节点区间内**每个**格子的真实值都恰好增加 $v$，故 $\max$ 增加 $v$；代码 `tr[i]+=v,tag[i]+=v`，而两个儿子的 $tr$ 未变，右端 $\max(tr[ls],tr[rs])+tag[i]$ 也增加 $v$ ✓。
- 否则（部分相交）：$r-l\ge2$（叶子区间长度为 $1$，与 $[L,R)$ 要么不交要么被包含，因 $L,R,l,r$ 皆整数：相交即 $l\in[L,R-1]$，则 $L\le l$ 且 $r=l+1\le R$，落在上一分支），递归正确更新两个儿子的 $tr$（归纳假设），$tag[i]$ 未变，按定义重取 $\max$ 即得。$\blacksquare$

（这就是"区间加 + 区间 max"里最省事的写法：**因为只查全局 $\max$（永远取 $tr[0]$），从不做区间询问，所以 $tag$ 不需要下传。**）

### 2.6 $\pm1$ 陷阱：连续放置 vs "把窗口钉在整数位置"

写这题最常见的做法是"既然边框不算，那星星的 $x$ 只要满足 $x_i-W+1\le X\le x_i-1$（整数）"，然后把 $X$ 限制在整数上。**这一步在题面里没有依据**：题面只说"窗子大小固定、边与地面平行"，从未说左下角必须是整数坐标。

**引理 7（开窗口能罩住的整数横坐标恰好是跨度 $\le W-1$ 的整数区间）**
$\{x\in\mathbb Z: X<x<X+W\}$ 是一个整数区间，且其中最大元 $M$ 与最小元 $m$ 满足 $M-m\le W-1$；反过来，任意满足 $M-m\le W-1$ 的整数区间 $[m,M]$ 都有某个实数 $X$ 使窗口正好罩住它。

**证明**：
- 若 $m<M$ 都在窗口内：$m>X$ 且 $M<X+W\Rightarrow M-m<(X+W)-X=W$，$M-m$ 是整数 $\Rightarrow M-m\le W-1$。中间的 $x$（$m<x<M$）满足 $X<m<x<X+W$，也都在窗口内，故构成整数区间。
- 反过来给定 $m\le M$ 且 $M-m\le W-1$，要 $X<m$ 且 $X+W>M$，即 $X\in(M-W,\ m)$。该区间非空 $\iff M-W<m\iff M-m<W$，由上界成立 $\Rightarrow$ 取其中任一实数（例如 $X=m-\frac{W-(M-m)}{2}$，它确实 $<m$ 且 $+W>M$）。$\blacksquare$

**推论**：连续放置时，同一窗口能容纳的星星横坐标跨度可以达到 $W-1$；而"整数 $X$"版本里 $X+1\le x_i\le X+W-1$，跨度只有 $W-2$。**少了一格**，最值就可能偏小。

**反例（本解法与"$\pm1$ 整数版"结果不同的具体数据）**：$n=3,W=3,H=1$

```
3 3 1
2 0 5
3 0 1
4 0 5
```

- 连续口径：$X=1.5,Y=-0.5$，窗口 $(1.5,4.5)\times(-0.5,0.5)$ 含整数 $x\in\{2,3,4\}$、$y=0$，三颗星全进 ⇒ $5+1+5=11$。
- 整数口径（$X\in[x_i-W+1,x_i-1]$）：三颗星分别给出 $X\in[0,1]$、$[1,2]$、$[2,3]$，$X=1$ 时覆盖星 1、2 得 $6$，$X=2$ 时覆盖星 2、3 得 $6$ ⇒ 最大只有 $6$。
- 差距来源：整数 $X$ 时 $x=2$ 与 $x=4$ 跨度 $2=W-1$，正好落在整数锚定够不到的那一格。

所以本文一律采用**格子（相邻边界之间）**作为离散化单位，而不是"压缩后的坐标点"。这样 $\pm1$ 完全不需要思考：星星 $i$ 覆盖的格子就是下标半开区间 $[\mathrm{idx}(x_i-W),\mathrm{idx}(x_i))$（引理 4），写出来就是"左边界下标进、右边界下标出"。

> **口径声明**：若评测数据是按"整数锚定"口径出的，本解法会偏大；但题面没有任何整数化描述，且"窗子大小固定"的自然模型是连续矩形，故以题面为准采用连续口径。（这一句是应"外部提示与题面冲突时按题面"的要求写的。）

### 2.7 溢出与边界：先算数量级，再决定类型

**坐标（最容易出事的地方）**

- $0\le x_i,y_i<2^{31}$，即最大 $2147483647=2^{31}-1=$ `INT_MAX`，`int` **刚好**装得下。
- 需要算的是 $x_i-W$ 与 $y_i-H$：最小 $0-10^6=-10^6$，仍在 `int` 内。所以"**只用减法，不用加法**"是本题的保命写法。
- 危险动作：有些写法为了统一把星星转成"$[x_i,\ x_i+W]$"或"$x_i+W$"，$2^{31}-1+10^6=2148483647>$ `INT_MAX`，有符号溢出是未定义行为，负数还会把排序彻底打乱、`lower_bound` 越界。本文所有偏移一律取 $x_i-W$、$y_i-H$（向小方向偏），安全。
- 若嫌"刚好等于 `INT_MAX`"太悬，可以把坐标读进 `i64`；但注意这样 `xs[]/ys[]` 也要跟着变成 `i64` 数组。按上面的减法分析，`int` 是严格安全的，代码里保留 `int` 并在注释中标明"用 $x-W$ 而非 $x+W$"。

**权值和**

- $n\cdot\max l_i=10^4\times1000=10^7$，`int` 够；但 $T$ 组不清零就会累加爆炸，且线段树里 `tag` 的中间量也是同一量级，统一用 `i64`（`tr`、`tag`、`ans`）零成本防未来改动。

**必须手过一遍的边界情形**

| 情形 | 期望行为 | 为什么我们的实现没问题 |
|---|---|---|
| $n=1$ | 答案 $=l_1$（$W,H\ge1$ 时总能罩住这颗星，引理 7 逆命题） | 格子区间 $[\mathrm{idx}(x_1-W),\mathrm{idx}(x_1))$ 非空，事件一对，$\max$ 取到 $l_1$ |
| 全 $l_i=0$ | 答案 $0$ | $ans$ 初值 $0$，线段树全 $0$ |
| $W=1,H=1$ | 只能看见"同一整点"上的星星，答案 $=$ 同点最大总亮度 | 引理 7 给出跨度 $\le0$；$x_i-W\ne x_i$ 故格子仍存在，只是每个格子宽度为 $1$ 的开区间 |
| 多颗星完全同坐标 | 亮度相加 | 它们的矩形完全相同，事件下标相同，同批处理后 $\max$ 自然叠加 |
| $x_i=2^{31}-1$ | 正常 | 见上面的减法分析 |
| $T$ 组之间 | 必须清零 | `fill_n(tr,mxs,0);fill_n(tag,mxs,0);`（全局数组默认 $0$，但多测必须显式重置） |
| 输入有/无空行 | 无关 | `cin>>` 自动跳过空白 |

## 3. 模式总结（Pattern Summary）

按真实思考顺序，一条一个技术点，不合并：

- **探索特殊机制（视角翻转）** — "固定尺寸矩形最多罩住几个带权点" $\Longleftrightarrow$ "把每个点变成参数空间里的一个矩形，求最大带权深度"。凡是窗口/雷达/井盖/矩形覆盖，先做这个翻转。
- **探索特殊机制（严格不等式）** — "边框不算" $=$ 开矩形；开矩形不影响最值的可达性，因为权值非负，可以把最优点推进格子内部（引理 2）。**非负权是这类"取边界无关紧要"论证的开关。**
- **离散化（按边界切格子，不按点编号）** — 值域 $2^{31}$ 逼出离散化；正确单位是"相邻两条边界之间的格子"，于是一个矩形的作用域正好写成下标半开区间 $[\mathrm{idx}(L),\mathrm{idx}(R))$，$\pm1$ 自动消失。
- **考虑简化版（去掉一维）** — 一维"区间最大带权重叠"用"事件排序 + 累加 + 取 max"，$O(n\log n)$；它的价值是暴露出"二维时每个 $x$ 位置要维护的是关于 $y$ 的**函数**，不是一个数"。
- **剖析贪心失败（边缘 $\neq$ 联合）** — 先按 $x$ 边缘和选带、再在带内选 $y$ 段的贪心，在 4 颗星的小数据上把 $17$ 答成 $7$；把 $y$ 压成标量就丢掉了"高度方向能否共存"的约束。
- **经典解法（扫描线降维）** — 外层沿 $x$ 边界推进，一次跨过一条边只是"若干矩形的进/出"，于是维护量随事件增量更新；查询放在**同一下标的一批事件全部处理完之后**（引理 5）。
- **经典解法（线段树：区间加 + 全局最大值）** — 只查全局 max 就从不需要 `push_down`，`tr[i]=max(tr[ls],tr[rs])+tag[i]` 即可（引理 6），代码最短、最不容易写错。
- **归约** — 二维最大带权矩形深度 $\to$ $O(n)$ 个 $x$ 状态 $\to$ 每状态一次"区间加 + 全局 max" $\to$ $O(n\log n)$。
- **复杂度核对** — $n\le10^4$、$T\le10$：$2n$ 个事件、$2n-1$ 个 $y$ 格子，$O(Tn\log n)\approx10\times10^4\times15=1.5\times10^6$，加上排序也远未吃紧；$O(n^2)$ 级别的"每带重扫"就已经是 $10^9$，说明出题人预期的就是扫描线。
- **溢出防护** — 只做 $x_i-W$、$y_i-H$ 的减法（加法会超 `INT_MAX`）；权值统一 `i64`；多测 `fill_n` 清表。
- **口径校验** — 题面未约束窗口整数放置 $\Rightarrow$ 连续口径；$\pm1$ 整数版会少一格（反例 $W=3$、$x\in\{2,3,4\}$，$11$ vs $6$）。这类"题意口径"要显式写下来，不要靠默认。

## 4. 真实解法

### 4.1 符号表（代码里出现的每一个量）

| 符号 | 类型/尺寸 | 存什么 | 初始化 | 一句话记忆 |
|---|---|---|---|---|
| `T` | `int` | 数据组数 | 读入 | 多测循环 `while(T--)` |
| `n,W,H` | `int` | 星星数、窗口宽、高 | 每组读入 | $W,H\le10^6$ |
| `px[],py[],pl[]` | `int[mxn]` | 第 $i$ 颗星的 $x_i,y_i,l_i$（**保持原始值**，不提前减） | 读入 | p = point，pl = point light |
| `xs[]`,`cx` | `int[mxc]`,`int` | $x$ 方向全部边界 $x_i-W,x_i$ 排序去重后的表与长度 | 每组重新收集 | "竖直边表"，$cx\le2n$ |
| `ys[]`,`cy` | `int[mxc]`,`int` | $y$ 方向全部边界 $y_i-H,y_i$ 排序去重后的表与长度 | 每组重新收集 | "水平边表"，$cy\le2n$ |
| 格子（$y$） | 下标 $0\dots cy-2$ | 开区间 $(ys[t],ys[t+1])$ | — | 线段树的叶子；$cy-1\ge1$ |
| `tr[]`,`tag[]` | `i64[mxs]` | `tr[i]`：节点区间内格子的最大权值和；`tag[i]`：整覆盖该节点区间、未下传的加量 | `fill_n(...,mxs,0)` | tr=tree max，tag=懒加 |
| `Event{x,l,r,v}` | `Event[mxn*2]` | `x`：**压缩后的 $x$ 边界下标**；`[l,r)`：$y$ 格子下标半开区间；`v`：$\pm l_i$ | 每颗星两条 | 进入 $+l_i$、离开 $-l_i$ |
| `ls(i),rs(i)` | 函数 | $2i+1,\;2i+2$ | — | 根为 $0$，半开区间 |
| `sth(l,r,i,L,R,v)` | lambda | 给格子 $[L,R)$ 整体加 $v$，同时维护 $tr$ | — | 区间加，无 push_down |
| `ans` | `i64` | 各组答案 | $0$ | 权值非负，$0$ 是合法下界 |

`mxn{10005}`（$n\le10^4$ + 5 松弛）、`mxc{20005}`（$2n$ 个边界）、`mxs{mxc*4}`（线段树 $4N$ 惯例）。

### 4.2 编号步骤

1. **读入**：$n,W,H$，把 $n$ 颗星存进 `px/py/pl`，同时把 $x_i-W,x_i$ 塞进 `xs`，$y_i-H,y_i$ 塞进 `ys`（只用减法，见 §2.7）。
2. **离散化**：`sort` + `unique` 得到 `xs[0..cx-1]`、`ys[0..cy-1]`；线段树的定义域是 $cy-1$ 个 $y$ 格子，即半开区间 $[0,cy-1)$。
3. **清表**：`fill_n(tr,mxs,0);fill_n(tag,mxs,0);`（多测必需）。
4. **造事件**：对每颗星用 4 次 `lower_bound` 求下标
   $$xl{=}\,\mathrm{idx}(x_i-W),\ xr{=}\,\mathrm{idx}(x_i),\ yl{=}\,\mathrm{idx}(y_i-H),\ yr{=}\,\mathrm{idx}(y_i),$$
   生成 `(xl,yl,yr,+l_i)` 与 `(xr,yl,yr,-l_i)`（引理 4 保证 $yl<yr$，$xl<xr$）。
5. **排序**：`ev` 按 `x`（压缩下标）升序。
6. **扫描线**：`p=0` 起，取整段同 `x` 的 $[p,q)$，逐个调用 `sth(0,cy-1,0,ev[k].l,ev[k].r,ev[k].v)`；这一批处理完后 `ans=max(ans,tr[0])`（引理 5：此刻 $tr[0]$ 恰是右邻 $x$ 格子的剖面最大值），令 `p=q` 循环。
7. **输出**：`cout<<ans<<'\n';`，进入下一组。

### 4.3 复杂度

- 时间：离散化 $O(n\log n)$；事件 $2n$ 次排序 $O(n\log n)$；每个事件一次线段树区间加 $O(\log n)$ $\Rightarrow$ $O(n\log n)$ 每组，总计 $O(Tn\log n)$。代入 $T=10,n=10^4$：约 $10\times10^4\times(\log_2 2\times10^4{+}1)\approx3\times10^6$ 次基本操作，余量极大。
- 空间：`tr/tag` 各 $4\times20005$ 个 `i64` $\approx0.64$ MB，其余数组 $<1$ MB。

### 4.4 正确性小结

引理 1、2 把"无穷多个窗口位置"压缩成"有限个格子且最优可在格子内部取到"；引理 4 把每个格子的归属翻译成下标半开区间；引理 5 说明扫描线的批处理时序给出的正是右邻格子状态；引理 6 说明 `tr/tag` 写法在没有 `push_down` 时仍维护正确不变式。四者合起来 $\Rightarrow$ `ans` 等于题面定义的"能出现在窗口上的最大亮度和"。

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};            // n <= 1e4
constexpr int mxc{20005};            // 每维 <= 2n 个边界
constexpr int mxs{mxc*4};            // 线段树节点

int n,W,H;
int xs[mxc],ys[mxc];                 // 离散化后的边界表
int px[mxn],py[mxn],pl[mxn];         // 原始星星
i64 tr[mxs],tag[mxs];                // tr=区间内最大权, tag=本区间整覆盖的懒加

struct Event{int x,l,r;i64 v;}ev[mxn*2];    // x 为压缩后的边界下标

int ls(int i){return i*2+1;}
int rs(int i){return i*2+2;}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int T;
	cin>>T;
	while(T--)
	{
		cin>>n>>W>>H;
		int cx=0,cy=0;
		for(int i=0;i<n;++i)
		{
			cin>>px[i]>>py[i]>>pl[i];
			// 用 x-W 而不是 x+W，避免撞上 int 上界
			xs[cx++]=px[i]-W;xs[cx++]=px[i];
			ys[cy++]=py[i]-H;ys[cy++]=py[i];
		}
		sort(xs,xs+cx);cx=unique(xs,xs+cx)-xs;
		sort(ys,ys+cy);cy=unique(ys,ys+cy)-ys;
		fill_n(tr,mxs,0);fill_n(tag,mxs,0);

		int ec=0;
		for(int i=0;i<n;++i)
		{
			int xl=lower_bound(xs,xs+cx,px[i]-W)-xs;
			int xr=lower_bound(xs,xs+cx,px[i])-xs;
			int yl=lower_bound(ys,ys+cy,py[i]-H)-ys;
			int yr=lower_bound(ys,ys+cy,py[i])-ys;
			ev[ec++]={xl,yl,yr,(i64)pl[i]};      // 进入：格子 [xl,xr) 内该星星有效
			ev[ec++]={xr,yl,yr,-(i64)pl[i]};     // 离开
		}
		sort(ev,ev+ec,[](Event a,Event b){return a.x<b.x;});

		// 区间加 v 于格子 [L,R)，[l,r) 为当前节点区间，只查全局最大值 tr[0]
		function<void(int,int,int,int,int,i64)>sth{[&sth](int l,int r,int i,int L,int R,i64 v){
			if(R<=l||r<=L)
				return;
			if(L<=l&&r<=R)
				tr[i]+=v,tag[i]+=v;
			else
			{
				int mid=(l+r)>>1;
				sth(l,mid,ls(i),L,R,v);
				sth(mid,r,rs(i),L,R,v);
				tr[i]=max(tr[ls(i)],tr[rs(i)])+tag[i];
			}
		}};

		i64 ans=0;
		for(int p=0;p<ec;)
		{
			int q=p;
			while(q<ec&&ev[q].x==ev[p].x)
				++q;
			for(int k=p;k<q;++k)
				sth(0,cy-1,0,ev[k].l,ev[k].r,ev[k].v);
			ans=max(ans,tr[0]);        // 此时线段树 = 格子 (xs[p], xs[q 对应的下一个边界]) 的状态
			p=q;
		}
		cout<<ans<<'\n';
	}
	return 0;
}
```

### 5.1 手算验证（逐事件轨迹）

**验证方法**：对每组数据，①按 §4.2 的步骤把 `xs/ys/ev` 手推出来，②模拟扫描线批处理，③独立地"把窗口真的摆到某个位置去数星星"（即引理 7 的跨度判据：窗口内整数横坐标跨度 $\le W-1$、纵坐标跨度 $\le H-1$），比较两个数。
**没有编译运行，没有对拍**，以下全是手算。

---

$xs=[2,5]$（$cx=2$），$ys=[2,5]$（$cy=2$）$\Rightarrow$ 只有 $1$ 个 $y$ 格子（下标 $0$）。

| 处理的 $x$ 下标 | 该批操作 | $tr[0]$ | $ans$ |
|---|---|---|---|
| $0$ | $+7$ | $7$ | $7$ |
| $1$ | $-7$ | $0$ | $7$ |

输出 $7$。独立核对：$X=3.5,Y=3.5$，窗口 $(3.5,6.5)^2\ni(5,5)$（严格内部）✓；只有一颗星，上界也是 $7$ ✓。

### 5.2 代码里的三处坑点标注

1. `sth(0,cy-1,0,...)`：定义域是**格子数** $cy-1$，不是边界数 $cy$。写成 $cy$ 会多出一个不存在的"最右格子"，虽然不影响 $\max$（值恒为 $0$），但会让 $[0,cy)$ 上出现空转递归。
2. `ev[k].v` 存的是 $\pm l_i$ 的 `i64`，若用 `int` 存 $-l_i$ 再累加进 `i64` 也可以，但 $0\le l_i$ 意味着 $-l_i$ 只能是 $0$，写 `-(i64)pl[i]` 明确符号扩展。
3. 查询位置：`ans=max(ans,tr[0])` 必须在**整批同坐标事件之后**（用例 4 已演示差别）。
