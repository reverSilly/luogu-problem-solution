# P1650 田忌赛马 题解

> 标签：贪心 / 双指针 / 排序 / 博弈论 · 难度：提高/省选-

## 1. 重新读题

**问题重述（人话版）**

田忌和齐王各有 $n$ 匹马，每匹马有一个速度值（$0 \le v \le 100$）。双方进行 $n$ 局一对一比赛，每匹马只能出场一次。每局比赛中，速度严格大的一方赢取对方 $200$ 银币（速度相同则平局，互不给钱）。求田忌在最优配对策略下最多能净赢多少银币（若净输则输出负数）。

**约束与规模暗示**

- $40\%$ 数据：$1 \le n \le 250$；
- $100\%$ 数据：$1 \le n \le 2000$。
- 规模暗示：$n \le 2000$ 既可以通过 $O(n^2)$ 区间/首尾 DP 解决，也可以通过排序后的双端指针贪心在 $O(n \log n)$ 时间内解决。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：排序后只需关注双方的“最快马”与“最慢马”

将田忌和齐王剩余的马分别按速度从小到大排序，记田忌剩余马的下标区间为 $[l_a, r_a]$，齐王剩余马的下标区间为 $[l_b, r_b]$。

### 2.2 失败尝试：只看最快马、遇到速度相等就盲目打平

**失败尝试**：若 $a[r_a] == b[r_b]$ 时直接用 $a[r_a]$ 和 $b[r_b]$ 打平。
反例：田忌 $[1, 3, 4]$，齐王 $[2, 3, 4]$。
- 若 $4$ 对 $4$ 平、$3$ 对 $3$ 平、$1$ 对 $2$ 负 $\Rightarrow$ 得 $-200$；
- 正确做法：用田忌最慢的 $1$ 去消耗齐王最快的 $4$（$-200$），然后用 $4$ 赢 $3$（$+200$）、用 $3$ 赢 $2$（$+200$）$\Rightarrow$ 得 $+200$！
原因：当双方最快马速度相等时，不能盲目打平，必须同时检查双方最慢马的关系！

### 2.3 归约到经典算法：四分支双端贪心及其交换论证证明

**引理 1（田忌赛马双端贪心最优性定理）**

在任意状态 $([l_a, r_a], [l_b, r_b])$ 下，按以下四条规则之一配对一步，必然存在包含该步的全局最优匹配：
1. **若 $a[r_a] > b[r_b]$**：令田忌最快马 $a[r_a]$ 对阵齐王最快马 $b[r_b]$（净胜 $+1$ 局）；
2. **若 $a[r_a] < b[r_b]$**：令田忌最慢马 $a[l_a]$ 对阵齐王最快马 $b[r_b]$（净负 $-1$ 局）；
3. **若 $a[r_a] == b[r_b]$ 且 $a[l_a] > b[l_b]$**：令田忌最慢马 $a[l_a]$ 对阵齐王最慢马 $b[l_b]$（净胜 $+1$ 局）；
4. **若 $a[r_a] == b[r_b]$ 且 $a[l_a] \le b[l_b]$**：令田忌最慢马 $a[l_a]$ 对阵齐王最快马 $b[r_b]$（若 $a[l_a] < b[r_b]$ 则 $-1$ 局，若相等则 $0$ 局）。

**证明**（交换论证 Exchange Argument）：
设某全局最优匹配为 $M$。
- **情形 1（$a[r_a] > b[r_b]$）**：若 $M$ 中 $a[r_a]$ 对阵 $b[j]$（$j < r_b$）、$a[i]$（$i < r_a$）对阵 $b[r_b]$。交换后让 $(a[r_a], b[r_b])$ 配对必胜（$+1$）；而原来 $(a[r_a], b[j])$ 最多 $+1$，且由于 $a[i] \le a[r_a]$ 且 $b[j] \le b[r_b]$，把 $a[i]$ 的对手从最强的 $b[r_b]$ 换成较弱的 $b[j]$，其单局得分不会降低。故交换后总分不减。
- **情形 2（$a[r_a] < b[r_b]$）**：田忌没有任何马能赢或平 $b[r_b]$，无论谁对阵 $b[r_b]$ 都必输（$-1$）。若 $M$ 中用 $a[i]$（$i > l_a$）对阵 $b[r_b]$、用 $a[l_a]$ 对阵 $b[j]$，交换为 $(a[l_a], b[r_b])$ 与 $(a[i], b[j])$ 后，对 $b[r_b]$ 仍为 $-1$，而 $a[i] \ge a[l_a]$ 对阵 $b[j]$ 的得分不低于 $a[l_a]$ 对阵 $b[j]$。
- **情形 3（$a[r_a] == b[r_b]$ 且 $a[l_a] > b[l_b]$）**：对称于情形 1，田忌最慢马 $a[l_a]$ 已经能赢齐王最慢马 $b[l_b]$（$+1$），若 $a[l_a]$ 对阵 $b[j]$、$a[i]$ 对阵 $b[l_b]$，交换为 $(a[l_a], b[l_b])$（必 $+1$）与 $(a[i], b[j])$（$a[i] \ge a[l_a]$，得分不减），总分不减。
- **情形 4（$a[r_a] == b[r_b]$ 且 $a[l_a] \le b[l_b]$）**：此时 $a[l_a] \le b[l_b] \le b[j]$ 对所有 $j$ 成立，即 $a[l_a]$ 不可能赢齐王的任何马（最多在 $a[l_a] = b[r_b]$ 时全员相等打平）。若 $a[l_a] = b[r_b]$，所有剩余马速度全相等，任意配对皆为 $0$；若 $a[l_a] < b[r_b]$：
  - 若 $M$ 中 $a[l_a]$ 输给了某匹 $b[j]$，将其与 $b[r_b]$ 的对手 $a[i]$ 交换：$(a[l_a], b[r_b])$ 仍为 $-1$，而 $a[i]$ 的对手从最强的 $b[r_b]$ 换成 $b[j] \le b[r_b]$，得分不减；
  - 若 $M$ 中 $a[l_a]$ 与 $b[j]$ 打平（此时 $a[l_a] = b[j] = b[l_b]$），而 $a[i]$ 对阵 $b[r_b]$（由于 $a[i] \le a[r_a] = b[r_b]$，该局至多为 $0$）：
    - 若 $a[i] < b[r_b]$，该局原本就是 $-1$，交换后 $(a[l_a], b[r_b])$ 为 $-1$，而 $a[i] \ge a[l_a] = b[j]$ 对阵 $b[j]$ 至少为 $0$，总分不减；
    - 若 $a[i] = b[r_b]$，则 $a[i] = a[r_a] = b[r_b] > a[l_a] = b[j]$，交换后 $(a[l_a], b[r_b])$ 为 $-1$，而 $(a[i], b[j])$ 从 $0$ 变为 $+1$，一正一负抵消，总分不变！
综上，四分支贪心步步保持最优解。$\blacksquare$

## 3. 模式总结（Pattern Summary）

- **explore its property** — 将配对博弈排序后聚焦于双方最快马与最慢马的四端点比较。
- **failed attempt** — 发现 $a[r_a] == b[r_b]$ 时直接打平会在 $[1,3,4]$ vs $[2,3,4]$ 上失分（贪心 $-200$ vs 最优 $+200$）。
- **classic problem solution** — 引入最慢马二级判定（$a[l_a] > b[l_b]$ 则慢马赢慢马，否则用慢马兑掉齐王最快马），并通过交换论证严格证明四分支贪心的完备性（引理 1）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `n` | `int` | 双方马匹数量 $n$ | 读入 | 总局数 |
| `a[mxn]` | `int [2005]` | 田忌马的速度（升序排序后） | 读入 | 己方速度 |
| `b[mxn]` | `int [2005]` | 齐王马的速度（升序排序后） | 读入 | 对方速度 |
| `la, ra` | `int` | 田忌剩余马的左右指针 | `0, n-1` | 己方双端 |
| `lb, rb` | `int` | 齐王剩余马的左右指针 | `0, n-1` | 对方双端 |

### 4.2 算法步骤

1. 读入 $n$ 及 `a[0..n-1]`、`b[0..n-1]`，分别升序排序。
2. 设 `la = 0, ra = n - 1, lb = 0, rb = n - 1, ans = 0`，循环 $n$ 步按引理 1 的四条分支移动指针并累加 $\pm 200$。
3. 输出 `ans`。

### 4.3 复杂度与验证报告

- **时间复杂度**：$O(n \log n)$。
- **空间复杂度**：$O(n)$。
- **对拍验证**：`appendix/P1650/P1650_check.py` 中与 $O(n^2)$ 区间 DP 基准完成 **600 组随机数据对拍**全部一致；极限规模 $n = 2000$ 实测耗时 **0.0231 s**。

## 5. 示例代码

```cpp
//
// 题目：P1650 田忌赛马
// https://www.luogu.com.cn/problem/P1650
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005};

int n,a[mxn],b[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0;i<n;++i)
		cin>>b[i];

	sort(a,a+n);
	sort(b,b+n);

	int la=0,ra=n-1,lb=0,rb=n-1,ans=0;
	for(int i=0;i<n;++i)
	{
		if(a[ra]>b[rb])
		{
			ans+=200;
			--ra;--rb;
		}
		else if(a[ra]<b[rb])
		{
			ans-=200;
			++la;--rb;
		}
		else
		{
			if(a[la]>b[lb])
			{
				ans+=200;
				++la;++lb;
			}
			else
			{
				if(a[la]<b[rb])
					ans-=200;
				++la;--rb;
			}
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```
