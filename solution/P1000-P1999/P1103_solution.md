# P1103 书本整理 题解

---

## 1. 重读题目

有 $n$ 本书 $(1<n\le 100)$，每本书有高度 $h_i$ 和宽度 $w_i$，所有高度互不相同。

操作：
1. 先将所有书按高度升序排列（由于高度不重复，排序后顺序唯一确定）。
2. 从排好的序列中恰好拿掉 $k$ 本书 $(1\le k<n)$。

**不整齐度** 定义为：剩下书的序列中，**相邻两本书宽度差的绝对值之和**。

目标：最小化这个不整齐度。

关键约束：
- $n\le 100$，$w_i\le 200$，很小。
- $k$ 最小为 $1$，最大为 $n-1$。
- 输入为无序，第一步强制按高度排序。

---

## 2. 链式思考（含完整推导与证明）

### 2.1 模型转化

按高度升序排序后，书的顺序就固定了。拿走 $k$ 本，等价于从长度为 $n$ 的序列中**选出** $m=n-k$ 本书**保持原顺序**留下。

设排序后的宽度数组为 $w[0..n-1]$。问题变成：

> 从序列 $w$ 中选出一个长度为 $m$ 的子序列（保持下标递增），最小化相邻元素差的绝对值之和。

这是一个经典的**子序列 DP**。

### 2.2 状态定义

令：
$$
dp[i][j] = \text{从前 } i \text{ 本书（下标 }0..i-1\text{）中选出 } j \text{ 本，且第 } i-1 \text{ 本书（即最后一个下标）} \textbf{必选} \text{ 的最小不整齐度}
$$

其中 $1\le j\le i\le n$。

为什么"必选最后一个"？—— 因为相邻代价需要知道上一本选的是谁，所以必须记下最后选的那本书的位置。

### 2.3 转移方程

**初始情况**：$j=1$ 时，只选一本书，没有相邻对，代价为 $0$。
$$
dp[i][1] = 0 \qquad (i\ge 1)
$$

**一般情况**：$j\ge 2$。假设最后一本选的是 $i-1$，则倒数第二本必须是某个 $t-1$ 且 $t < i$，且从前 $t$ 本中选出了 $j-1$ 本（以 $t-1$ 结尾）。转移代价为：
$$
dp[i][j] = \min_{j-1\le t < i} \Bigl\{\; dp[t][j-1] + |w[i-1] - w[t-1]| \;\Bigr\}
$$

解释：
- $dp[t][j-1]$：前 $t$ 本中选 $j-1$ 本，以 $t-1$ 结尾的最优值。
- $|w[i-1] - w[t-1]|$：新增的相邻代价。
- $t$ 的范围 $[j-1, i-1]$ 是因为前 $t$ 本至少要有 $j-1$ 本书才能选出 $j-1$ 本。

### 2.4 答案形式

我们一共需要选出 $m = n-k$ 本书。最后一本书可以是下标 $m-1$ 到 $n-1$ 中的任意一本。所以答案为：
$$
\mathrm{ans} = \min_{m\le i\le n} dp[i][m]
$$

### 2.5 正确性证明

**最优子结构**：设 $S$ 是一个最优选择方案，共 $m$ 本，最后一本下标为 $i-1$（即第 $i$ 本书）。去掉最后一本，前 $m-1$ 本构成原问题的子问题（从前 $i-1$ 本中选 $m-1$ 本，以某个下标 $t-1$ 结尾）。若子问题不是最优的，则存在更优子方案替换后得到更优的 $S$，矛盾。

**无后效性**：$dp[i][j]$ 只依赖于 $j-1$ 层的 $dp[t][j-1]$ 值和宽度差，与更早的选择方式无关。

**正确性**：DP 枚举了所有可能的子序列末尾位置和长度，转移考虑了所有合法的前驱，因此一定能搜到全局最优解。

### 2.6 复杂度

- 状态数：$O(n^2)$
- 转移：枚举 $t$ 为 $O(n)$，总复杂度 $O(n^3)$
- $n\le 100$，$O(10^6)$ 次操作，完全可行。

### 2.7 优化讨论（非必须）

可将转移优化至 $O(n^2)$：注意到 $dp[i][j]$ 的转移是
$$
dp[i][j] = \min\Bigl(\; \min_{t} (dp[t][j-1] - w[t-1]),\; \min_{t} (dp[t][j-1] + w[t-1]) \;\Bigr) \pm w[i-1]
$$
取决于 $w[i-1]$ 与 $w[t-1]$ 的大小关系。在 $j-1$ 层扫描时维护两个前缀最小值即可 $O(1)$ 转移。但 $n$ 很小，本题不需要。

## 3. 模式总结

| 考点 | 说明 |
|------|------|
| **排序预处理** | 输入乱序，先按高度排序固定序列顺序 |
| **转化为子序列 DP** | 拿掉 $k$ 本 $\Leftrightarrow$ 保留 $m=n-k$ 本 |
| **区间/序列 DP** | 状态 $dp[i][j]$：前 $i$ 个中选 $j$ 个且以 $i$ 结尾 |
| **最小化相邻差绝对值和** | 转移时加上 $|w_i - w_t|$ |
| **$O(n^3)$ 在 $n\le 100$ 时可行** | 不需要花式优化 |

本题的思维链条：**乱序输入 → 按高度排序确定顺序 → 删除等价于选子序列 → 相邻代价须记最后一本位置 → 经典 DP**。

## 4. 正式解法（含符号表）

### 符号

| 符号 | 含义 |
|------|------|
| $n$ | 书本总数 |
| $k$ | 拿掉的书本数 |
| $m = n-k$ | 保留的书本数 |
| $h_i, w_i$ | 第 $i$ 本书的高度和宽度 |
| $w[0..n-1]$ | 按高度升序排序后的宽度数组 |
| $dp[i][j]$ | 前 $i$ 本中选 $j$ 本且第 $i$ 本必选的最小代价 |
| $\mathrm{ans}$ | 最终最小不整齐度 |

### 算法步骤

1. 读入 $n, k$ 和 $(h_i, w_i)$。
2. 按 $h_i$ 升序排序，提取宽度数组 $w$。
3. 令 $m = n - k$。
4. 初始化 $dp[i][1] = 0$（$1\le i\le n$）。
5. $j$ 从 $2$ 到 $m$ 枚举保留本数，$i$ 从 $j$ 到 $n$ 枚举末尾位置：
   $$
   dp[i][j] = \min_{j-1\le t < i} \bigl( dp[t][j-1] + |w[i-1] - w[t-1]| \bigr)
   $$
6. 答案为 $\displaystyle \min_{m\le i\le n} dp[i][m]$。

## 5. 示例代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

constexpr int mxn{105};
constexpr int inf{114514191};

struct Book
{
	int h, w;
} a[mxn];

int n, k, m;
int w[mxn];			// 按高度排序后的宽度
int dp[mxn][mxn];	// dp[i][j]: 前i本选j本, 第i本必选

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin >> n >> k;
	for (int i{0}; i < n; ++i)
	{
		cin >> a[i].h >> a[i].w;
	}

	// 按高度升序排序
	sort(a, a + n, [](const Book &x, const Book &y)
	{
		return x.h < y.h;
	});

	// 提取宽度
	for (int i{0}; i < n; ++i)
	{
		w[i] = a[i].w;
	}

	m = n - k;	// 保留本数

	// 初始化: 只选1本代价为0
	for (int i{1}; i <= n; ++i)
	{
		dp[i][1] = 0;
	}

	// DP
	for (int j{2}; j <= m; ++j)
	{
		for (int i{j}; i <= n; ++i)
		{
			dp[i][j] = inf;
			for (int t{j - 1}; t < i; ++t)
			{
				dp[i][j] = min(dp[i][j],
					dp[t][j - 1] + abs(w[i - 1] - w[t - 1]));
			}
		}
	}

	// 答案: 最后一本可以是第 m..n 本的任意一本
	int ans{inf};
	for (int i{m}; i <= n; ++i)
	{
		ans = min(ans, dp[i][m]);
	}
	cout << ans << '\n';

	return 0;
}
```
