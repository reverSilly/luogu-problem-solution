# P1432 倒水问题

> 标签：搜索 / Special Judge / O2 优化 · 难度：提高/省选-

## 1. 重新读题

**问题重述。** 两只壶 $A,B$，容量 $C_a\le C_b$，水龙头与下水道都无限。状态就是有序对 $(a,b)$（当前水量）。每步可选六个动作之一：

| 编号 | 文本 | 结果 |
|---|---|---|
| 1 | `fill A` | $(a,b)\to(C_a,b)$ |
| 2 | `fill B` | $(a,b)\to(a,C_b)$ |
| 3 | `empty A` | $(a,b)\to(0,b)$ |
| 4 | `empty B` | $(a,b)\to(a,0)$ |
| 5 | `pour B A` | 倒到"$A$ 满或 $B$ 空"：$(a,b)\to(a+d,\,b-d),\ d=\min(b,\,C_a-a)$ |
| 6 | `pour A B` | $(a,b)\to(a-d,\,b+d),\ d=\min(a,\,C_b-b)$ |

起点 $(0,0)$，终点是**任意**满足 $b=N$ 的状态（$a$ 不限），要求动作数最少。

**条件与目标。**

- 约束：$T\le 30$，$0<C_a\le C_b\le1000$，$N\le C_b$，$\gcd(C_a,C_b)=1$，题面明确"保证存在解"。
- 输出是一行：先一个整数 $a_i$（步数），后跟 $a_i$ 个操作编号，空格分隔。

**由数据范围读出的复杂度。** $C_a,C_b\le1000$ 意味着 $(a,b)$ 的暴力状态数是 $10^6$，乘 $T=30$ 是 $3\times10^7$ 级别——**可以接受**；而标签是"搜索"、又开了 O2，进一步暗示正解就是图搜索而不是数论公式。

**陷阱与边界（都要在代码里正确处理）。**

1. SPJ 双向惩罚："比答案差扣分，比答案优提示 UKE"。所以必须**恰好**最小步数，既不能多也不能少。
2. 倒水规则只给了"倒不满就停"的方向语义：$d=\min(\text{源壶现有},\text{目标壶空位})$，两头同时见底线。
3. $N=0$：题面只写 $N\le C_b$ 没写 $N>0$。$(0,0)$ 本身就是答案，应当输出 `0`（零个操作）。
4. $N=C_b$：一个动作 `fill B` 即可，步数 1。
5. 同层可能有多个 $b=N$ 的状态（如 $(0,N)$ 与 $(C_a,N)$），BFS 只会取先入队的那个，两者步数相同，SPJ 接受任意一种。
6. 空操作（如 $a=C_a$ 时再 `fill A`）必须跳过，否则前驱指向自己、回溯死循环。
7. **本地题面没有给出样例输入输出**，因此无法与官方答案对标，只能靠手算复刻（见 §4 验证状态）。
8. 题面 Background 提醒"输入输出已更改，不要直接提交原先的代码"——即老的"多行字符串输出"格式已作废，本解按当前的一行数字格式输出。


## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：状态空间其实小得离谱

状态 $(a,b)$，$0\le a\le C_a$，$0\le b\le C_b$，纸面上是 $10^6$ 个点。先别急着写 BFS，先问：**倒水这种"必须倒到见底线"的规则，到底允许出现哪些状态？**

**引理 1（边界闭包）.** 从 $(0,0)$ 出发，无论走多少步，到达的状态 $(a,b)$ 必满足
$$a\in\{0,C_a\}\ \text{或}\ b\in\{0,C_b\}.$$

**证明.** 逐个检查六个动作的像，与"当前状态长什么样"无关：

- `fill A` 的像满足 $a=C_a$；`empty A` 的像满足 $a=0$；
- `fill B` 的像满足 $b=C_b$；`empty B` 的像满足 $b=0$；
- `pour A B`：设倒出 $d=\min(a,\,C_b-b)$。若 $d=a$ 则新 $a'=a-d=0$；否则 $d=C_b-b$，新 $b'=b+d=C_b$。两者必居其一（$d$ 就是这两个数中的较小者），故像满足"$a'=0$ 或 $b'=C_b$"；
- `pour B A`：对称地，$d=\min(b,C_a-a)$，若 $d=b$ 则 $b'=0$，否则 $a'=C_a$。

于是**每个动作的像都落在边界集合里**。而起点 $(0,0)$ 满足 $a=0$，故对步数归纳：第 $0$ 步在边界内，若第 $k$ 步在边界内，第 $k+1$ 步是某个动作的像，仍在边界内。$\blacksquare$

> 注意：归纳假设其实没被用到——这正是"倒到见底线"这条规则的力量。任何一次操作都会把**至少一只**壶推到 0 或满。

**引理 2（可达状态数上界）.** 满足引理 1 条件的状态至多
$$|(a{=}0)|+|(a{=}C_a)|+|(b{=}0)|+|(b{=}C_b)|-4=(C_b{+}1)+(C_b{+}1)+(C_a{+}1)+(C_a{+}1)-4=2C_a+2C_b$$
个（减 4 是因为四个角 $(0,0),(0,C_b),(C_a,0),(C_a,C_b)$ 各被重复统计一次）。代入 $C_a,C_b\le1000$：**至多 4000 个点**，比 $10^6$ 缩小 250 倍。

**证明.** 上面四个集合分别有 $C_b+1,\,C_b+1,\,C_a+1,\,C_a+1$ 个元素（固定 $a$ 时 $b$ 自由、固定 $b$ 时 $a$ 自由）。同时属于其中两个集合的点恰是四个角：$a\in\{0,C_a\}$ 与 $b\in\{0,C_b\}$ 的组合共 $2\times2=4$ 个点，且每个角恰被计入两次（不可能被计到三次以上：一个点不可能同时满足三个底线条件，因为 $a=0$ 与 $a=C_a$ 矛盾——题面 $C_a>0$）。由容斥，并集大小为
$$2(C_b+1)+2(C_a+1)-4=2C_a+2C_b.\qquad\blacksquare$$

**引理 3（边界几乎全可达）.** 若 $\gcd(C_a,C_b)=1$，则除 $(0,0)$ 外的所有边界状态都从 $(0,0)$ 可达，即恰有 $2C_a+2C_b-1$ 个可达状态。

**证明.** 只需构造。规定"$A$ 空就灌满 $A$；$A$ 不空且 $B$ 未满就往 $B$ 倒；$B$ 满就清空 $B$"，这是一条确定的链。用 $b_i$ 表示第 $i$ 次 `pour A B` **完成注入后** $B$ 里的水量（即把"倒满 $B$ + 清空 $B$ + 把残留再倒进去"合并成一次净注入），每次净注入给系统带来 $C_a$ 的水，$B$ 装满一次就被倒掉 $C_b$，故
$$b_i\equiv iC_a\pmod{C_b},\qquad i=1,\dots,C_b.$$
因 $\gcd(C_a,C_b)=1$，$iC_a$ 模 $C_b$ 遍历全部剩余类（否则 $iC_a\equiv jC_a$ 且 $i>j$ 给出 $(i-j)C_a\equiv0$，$0<i-j<C_b$，与互质矛盾）。于是 $\{b_i\}=\{0,1,\dots,C_b-1\}$，即形如 $(0,r)$ 的状态（倒完后 $A$ 恰好空时的状态，$r$ 任取）全可达；紧接着 `fill A` 又给出全部 $(C_a,r)$，$r=0..C_b-1$，再加上某次倒满得到的 $(C_a,C_b)$。最后，链上每次 $B$ 满之后 `empty B` 给出 $(a,0)$，其中 $a$ 取遍 $1..C_a-1$（因为注入 $B$ 时 $B$ 的余量 $C_b-b$ 遍历 $1..C_b$，当它 $<C_a$ 时 $A$ 剩 $C_a-(C_b-b)$，遍历 $1..C_a-1$）。四类合起来正是 $\{a\in\{0,C_a\}\}\cup\{b\in\{0,C_b\}\}$ 去掉 $(0,0)$。$\blacksquare$

> 手算验证 $C_a=3,C_b=5$：链为 $(3,0)\!\to\!(0,3)\!\to\!(3,3)\!\to\!(1,5)\!\to\!(1,0)\!\to\!(0,1)\!\to\!(3,1)\!\to\!(0,4)\!\to\!(3,4)\!\to\!(2,5)\!\to\!(2,0)\!\to\!(0,2)\!\to\!(3,2)\!\to\!(0,5)\!\to\!(3,5)$，恰 $15=2\cdot3+2\cdot5-1$ 个点，是一个**环**。

**结论.** 我们要在一个 $\le 4000$ 点、每点 $\le6$ 出边的图上求最短路——搜索毫无压力。

### 2.2 简化版：只会"单向循环倒水"时该怎么办

先假装只会一种策略：**$A$ 空就灌满 $A$，$A$ 不空就往 $B$ 里倒，$B$ 满就清空 $B$**。这是 POJ 3414 式的"经典解法"。

设这条链上一共 `fill A` 了 $k$ 次、`empty B` 了 $e$ 次。

**引理 4（守恒式）.** 任意时刻 $B$ 中的水量满足
$$b=kC_a-eC_b-a,\qquad a\in[0,C_a],$$
即"进入系统的总水量 $kC_a$"减去"倒掉的总水量 $eC_b$"，剩下的分布在两壶里。

**证明.** 对操作数归纳。`fill A` 使 $a$ 变为 $C_a$，同时 $k$ 加 1，故 $kC_a$ 恰好增加 $C_a-a$，等于系统总水量的增量；`empty B` 使 $e$ 加 1、总水量减 $C_b$，等式两边同步减 $C_b$；`pour A B` 不改变 $a+b$ 也不改变 $k,e$。本链只用到这三种操作（`empty A`、`fill B`、`pour B A` 不出现），初始 $a=b=k=e=0$ 时等式成立，故每一步后仍成立，即 $a+b=kC_a-eC_b$。$\blacksquare$

**引理 5（步数公式）.** 记这条链上 `fill A` 用了 $k$ 次、`empty B` 用了 $e$ 次，则到"第 $k$ 次灌满后终于使 $b=N$"为止，链上的操作总数恰为
$$S_1=2(k+e),$$
其中 $k$ 是满足 $kC_a\equiv N+a\pmod{C_b}$（$a$ 为届时 $A$ 的水量，$0\le a\le C_a$）且 $kC_a\ge N+a$ 的最小正整数。

**证明.** 链上只出现三种操作。逐步看转移：$a=0$ 时唯一动作是 `fill A`（$k\mathrel{+}=1$）；$a>0$ 且 $b<C_b$ 时唯一动作是 `pour A B`；$b=C_b$ 且 $a>0$ 时唯一动作是 `empty B`（$e\mathrel{+}=1$）。因此 `pour A B` 只能紧跟在 `fill A` 之后（这次把 $A$ 倒空），或紧跟在 `empty B` 之后（这次把 $A$ 的残留送进 $B$）——即**每个 `fill A` 配一次"倒空 $A$ 型" `pour`，每个 `empty B` 配一次"承接残留型" `pour`**，且终点前不会有未配对的 `pour`（链是 `fill A`/`empty B` 与 `pour` 严格交替，且总是先 `fill A`）。故 `pour` 次数 $=k+e$，总数 $=k+e+(k+e)=2(k+e)$。同余式与不等式就是引理 4 的 $a+b=kC_a-eC_b$ 代入 $b=N$ 再移项，$\blacksquare$

> 用 $C_a=3,C_b=5,N=4$ 代入手算：$k=3,e=1$（链上第 3 次 `fill A`、第 1 次 `empty B`），$S_1=2(3+1)=8$，与 §2.1 末尾那条 15 状态环上 $(0,4)$ 的位置吻合。

**小结**：单向版本能解，但公式里那个"$a$＝终点时 $A$ 的余量"必须和 $k,e$ 联立枚举（$a$ 未知 → 同余式右边未知），写代码时极易漏掉 $a=C_a$ 那一支；互质保证了 $\bmod$ 遍历（引理 3），却保证不了计数优雅。

### 2.3 剖析贪心失败

**贪心 A：固定单向（永远 $A\to B$）。** 反例 $C_a=3,C_b=5,N=4$。

- $A\to B$ 链：`fill A`(1)$(3,0)$→`pour A B`(2)$(0,3)$→`fill A`(3)$(3,3)$→`pour A B`(4)$(1,5)$→`empty B`(5)$(1,0)$→`pour A B`(6)$(0,1)$→`fill A`(7)$(3,1)$→`pour A B`(8)$(0,4)$。**8 步。**
- 反向 $B\to A$ 链：`fill B`(1)$(0,5)$→`pour B A`(2)$(3,2)$→`empty A`(3)$(0,2)$→`pour B A`(4)$(2,0)$→`fill B`(5)$(2,5)$→`pour B A`(6)$(3,4)$。**6 步。**

两个都是合法解，方向不同差 2 步，所以"只选一个方向"必然不最优。**为什么方向会影响步数？** 由引理 4，$A\to B$ 方向要解 $kC_a\equiv N+a\pmod{C_b}$，$B\to A$ 方向要解 $mC_b\equiv N+a'\pmod{C_a}$：前者步数量级 $\sim 2C_b$、后者 $\sim 2C_a$，$C_a<C_b$ 时反向往往更快。这条直觉很有用，但它只是**启发式**，不是证明。

**贪心 B：每步选让 $|b-N|$ 最小的操作。** 同一组数据 $3/5/4$ 上它直接死循环：

$(0,0)$：`fill B` 使 $b=5$，$|5-4|=1$ 优于 `fill A`（$b=0$，差 4）→ 选 `fill B`，到 $(0,5)$。
$(0,5)$：`fill A` 得 $(3,5)$，$|b-4|=1$；`pour B A` 得 $(3,2)$，$|b-4|=2$；`empty B` 退回 $(0,0)$ 差 4 → 选 `fill A`，到 $(3,5)$。
$(3,5)$：**两壶皆满**，`pour A B` 与 `pour B A` 都倒不动（空操作），只剩 `empty A` 到 $(0,5)$、`empty B` 到 $(3,0)$。回到 $(0,5)$ 后又被 `fill A` 拉回 $(3,5)$，于是 $(0,5)\leftrightarrow(3,5)$ 无限振荡。

**失败模式（一般化）**：贪心 B 用"$b$ 离 $N$ 多近"当势函数，但 $b=C_b$（$B$ 满）与 $a=C_a$（$A$ 满）这两条底线状态里，倒水被"卡住"，局部最优的下一步把系统推进了**没有出口通向更小势值**的区域。这说明势函数必须带上"$a$"才可能修正——一旦要同时权衡 $a,b$，人脑枚举就爆炸了，正是搜索该上场的地方。

**修正贪心（POJ 3414 版）：两个方向各跑一遍取较小者。** 它在本组数据上给出 6，正确。但它仍是一个需要证明的命题：由引理 1/3，边界图除了那条 15 状态的大环之外**还有额外的弦**，例如 $(3,3)\xrightarrow{\texttt{fill B}}(3,5)$、$(3,3)\xrightarrow{\texttt{empty B}}(3,0)$ 都不在那条环的邻接关系里。混合使用弦的操作序列在结构上是允许的，"两方向之一最优"并不显然。我在 $C_a,C_b\le 5$ 的小数据上手算过 $(C_a,C_b)=(2,5),(3,5)$ 的全部 $N$（见 §4），没有找到反例；但要把它作为**精确最小值**提交给 SPJ（差一步扣分、优一步 UKE），我必须自己给出那个交换论证——而 BFS 的正确性是**免费**的。于是放弃公式，直接搜。

### 2.4 经典解法：无权图 BFS + 记录前驱

把每个边界状态当点，六个操作当六条**单位权**边，得到图 $G$。问题变成：$G$ 上从 $(0,0)$ 到集合 $\mathcal T=\{(a,N)\}$ 的最短路径。

**引理 6（入队即定距）.** 用 `dis[][]` 初值 `inf`、"发现即标记"（`dis` 一旦非 `inf` 就不再改写）的标准 BFS，则每个被标记的状态 $v$ 满足 `dis[v]`$=d(s,v)$。

**证明.** 分两向。

-（$\ge$）`dis[v]` 由某条真边 $(u,v)$ 置为 `dis[u]+1`。沿前驱链展开：前驱的 `dis` 严格更小且必已标记，故有限步内到达唯一 `dis`$=0$ 的点 $s$，于是存在一条 $s\to v$、长度恰为 `dis[v]` 的真实路径，得 $d(s,v)\le$ `dis[v]`。

-（$\le$）反设坏点（`dis[v]`$>d(s,v)$）存在，取**最早出队**的坏点 $v$，记 $t=d(s,v)$，取最短路 $s=p_0,p_1,\dots,p_t=v$。令 $j$ 为最小下标使 `dis[p_j]`$>j$：$j\ge1$（因 `dis[p_0]`$=0$），且 $j\le t$（取 $j=t$ 即坏点本身，故这样的 $j$ 存在）。由 $j$ 的最小性，`dis[p_{j-1}]`$\le j-1$；另一方面 $p_{j-1}$ 是长度 $t$ 的最短路的前缀，该前缀本身仍是从 $s$ 到 $p_{j-1}$ 的最短路（否则把它换回去会得到更短的 $s\to v$），即 $d(s,p_{j-1})=j-1$，结合（$\ge$）向得 $j-1\le$ `dis[p_{j-1}]`$\le j-1$，故 `dis[p_{j-1}]`$=j-1<$ `dis[v]`。由引理 7，$p_{j-1}$ 在 $v$ 之前出队；它出队时对边 $(p_{j-1},p_j)$ 做松弛：若 $p_j$ 当时未标记，则被置为 $\le j$；若已标记，则其标记值不晚于此刻、同样 $\le j$（因为 `dis` 一经写入不再改）。两种情形都与 `dis[p_j]`$>j$ 矛盾。$\blacksquare$

**引理 7（队列分层非降）.** BFS 运行中，队列里状态的 `dis` 值从左到右非降，且至多两种相邻值。

**证明.** 初始只有 `dis`$=0$ 的起点，命题成立。归纳：设某次出队前队列为非降且极差 $\le1$（值 $\ell$ 或 $\ell+1$），出队元素 `dis`$=\ell$（若队首为 $\ell$）时新入队元素都是 $\ell+1$，接在尾部，仍非降、极差 $\le1$；队首变成 $\ell+1$ 后同理。$\blacksquare$

**引理 8（提前终止正确）.** 在**出队**时判 $b=N$ 并立即停止，得到的 $u=$`qa[head],qb[head]` 满足 $d(s,u)=\min_{v\in\mathcal T}d(s,v)$。

**证明.** 由引理 7，出队序列的 `dis` 非降。设算法停在 $u\in\mathcal T$。若存在 $v\in\mathcal T$ 且 $d(s,v)<$ `dis[u]`，由引理 6 $v$ 的 `dis` 更早已确定，$v$ 会在 $u$ **之前**出队（非降序），届时算法就会停在 $v$，矛盾。故 $u$ 是目标集中距离最小者。$\blacksquare$

> 注：判定时机放在"出队"而不是"入队"，是为了少写一层——入队即判也正确（引理 6 保证首次发现的 $v\in\mathcal T$ 已是最小 `dis`），但出队判定让"起点本身满足 $N=0$"这一情况自动成立。

**引理 9（前驱回溯给出合法方案）.** 从终点沿 `pre` 逐步回退到 $(0,0)$，把记录的操作号逆序输出，得到一条真实可行的操作序列，长度恰为 `dis[终点]`。

**证明.** `pre[x][y]` 只在把 $(x,y)$ 从 $(pa,pb)$ 用操作 $op$ 扩展时写入，且 $(x,y)$ 此后再不被改写（引理 6 的一次性标记）。故 $(pa,pb)\xrightarrow{op}(x,y)$ 是 $G$ 的真边，逆推得到的链条是 $s\to\cdots\to$ 终点的一条路径；每退一步 `dis` 严格减 1（`dis[x][y]=dis[pa][pb]+1`），而 `dis[s]=0`，故步数 $=$ `dis[终点]`。$\blacksquare$

**复杂度。** 由引理 2，状态 $\le 2C_a+2C_b\le4000$，边 $\le 6\times4000=2.4\times10^4$；$T\le30$ 共 $\sim 7\times10^5$ 次松弛。数组清零按 $(C_a+1)(C_b+1)\le10^6$ 计，$30$ 组 $3\times10^7$，仍是"扫一遍数据"的量级。

### 2.5 归约到更简单的问题

整道题被压成两步归约：

1. **"最少操作数"** $\to$ **无权图单源最短路**（引理 6–9）：不再需要任何倒水专用知识，只要会 BFS。
2. **"输出方案"** $\to$ **前驱表回溯**（延迟重建）：搜索阶段只写 `pre`，重建在搜索结束后一次性完成，不影响最优性；因为 SPJ 只要求"任意一种最少方案"，无需在多个同层终点间挑字典序。

同时归约把"要不要证贪心最优"这个最难的人类负担甩掉了：BFS 的最小性由引理 8 无条件成立。

### 2.6 溢出与越界防护（写代码前先把账算完）

- **步数**：沿引理 3 那条大环走一圈就能到达任何状态，故最短步数 $\le$ 环长 $=2C_a+2C_b-1\le3999$；`int` 绰绰有余，`inf=1145141919` 与 `dis+1` 相加也不爆（$<2^{31}-1$）。
- **前驱位打包**：`pre=(a<<13)|(b<<3)|op`。需要 $a,b\le1000<2^{10}=1024$：$b$ 占 bit 3–12（10 位），$a$ 占 bit 13–22，`op`$\in[1,6]$ 占 bit 0–2。最大取值 $1000\cdot2^{13}+1023\cdot8+7\approx8.2\times10^6$，远小于 $2^{31}$，**有符号 `int` 左移不产生 UB**（未触及符号位）。解码用 `s&7`、`(s>>3)&1023`、`s>>13`，掩码 `1023` 必需，否则高位会污染 $b$。
- **队列容量**：`tail` 每个状态只入队一次（`dis` 查重），故 $\le(C_a+1)(C_b+1)\le1001\cdot1001\approx10^6$，数组开 `mxn*mxn` 正好覆盖；若只按引理 2 开 $4000$ 会在"边界之外仍被写 `dis`"时越界，故按整张网格留量更稳。
- **`dis` 必须逐行 `fill_n`**：全局 `int` 数组默认是 **0**，不填 `inf` 就等于"所有状态都已被访问过"，BFS 一步都走不出去，输出 `0` 和空方案——这是从 `vector` 版搬到全局数组时最容易踩的坑。
- **输出规模**：一行最多 $4001$ 个整数，`cout` 加 `' '` 逐个拼接即可，无需快输。

## 3. 模式总结（Pattern Summary）

- 探索特殊机制 — 把"倒到满/空才停"翻译成"每步后必有一只壶处于底线"，这是全题的钥匙。
- 状态空间收缩（容斥计数）— 边界闭包把 $10^6$ 个点砍成 $2C_a+2C_b$ 个，先估规模再选算法。
- 考虑简化版 — 先解"只会单向循环倒水"的版本，得到 $b\equiv kC_a\pmod{C_b}$ 的数论图像与守恒式 $a+b=kC_a-eC_b$。
- 反例击破贪心（第一次）— 单向贪心不最优：$3/5/4$ 上 $A\to B$ 要 8 步，$B\to A$ 只要 6 步。
- 反例击破贪心（第二次）— 势函数 $|b-N|$ 的逐步贪心会走进 $(C_a,C_b)$，倒水全变空操作，陷入 $(0,5)\leftrightarrow(3,5)$ 振荡。
- 经典解法替换 — "最少操作数"就是边权为 1 的单源最短路 → BFS；最优性由算法免费给出，不必替贪心补证明。
- 提前终止的正确性 — 出队时判目标（依赖队列按 `dis` 非降），省时间且自动覆盖 $N=0$ 这种零步答案。
- 延迟重建（前驱表）— 搜索期只写 `pre`，搜索完再回溯出方案；SPJ 只要求"任意一种"最优方案。
- 归约到更简单问题 — 倒水过程 ≡ 边界状态图上的路径问题，公式法 ≡ 数论同余，二者都被 BFS 吞掉。
- 全局数组防呆 — `dis` 必须 `fill_n(...,inf)`（默认 0 会被当成"已访问"）；位打包前逐位检查 $10+10+3$ 位仍在 `int` 内。


## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 初始化 | 记忆点 |
|---|---|---|---|
| `Ca,Cb,N` | 当前这组数据的容量与目标 | 每组重新读入 | 全局，供 `done()` 直接引用 |
| `dis[a][b]` | 从 $(0,0)$ 到状态 $(a,b)$ 的最少步数 | 每行 `fill_n(dis[i],Cb+1,inf)`；`dis[0][0]=0` | 同时也是 `vis`：非 `inf` 即已访问 |
| `pre[a][b]` | 把 $(a,b)$ 扩张出来时用的父状态与操作号，位打包 `(pa<<13)\|(pb<<3)\|op` | 无需清零（只读已写过的格子） | 只在建 `dis` 的那一行同时写 |
| `qa,qb` | 手写 BFS 队列（两个平行数组存 $a,b$） | `head=tail=0` 后压入 $(0,0)$ | `head` 出、`tail` 进，半开区间 `[head,tail)` |
| `stk`,`top` | 回溯栈，存逆序拿到的操作号 | `top=0`，用完自动归零 | 弹出顺序即正序方案 |
| `ta,tb` | 搜到的终点 $(a,N)$ | 出队命中时记录 | 打印长度用 `dis[ta][tb]` |
| `inf` | "不可达"哨兵 | `1145141919` | 加 1 仍不溢出 |
| `done(i)` | 判据 `qb[i]==N` | — | 只需 $B$ 达标，$A$ 任意 |

### 4.2 步骤

1. 读 $T$，对每组读 `Ca,Cb,N`。
2. 对 $i=0..C_a$ 执行 `fill_n(dis[i],Cb+1,inf)`：只清真正会用到的子矩形 $[0,C_a]\times[0,C_b]$。
3. `dis[0][0]=0`，把 $(0,0)$ 入队。
4. 循环：`head<tail` 且 `!done(head)` 时，取队首 $(a,b)$。
5. 对 $k=1..6$ 依 §1 的表算出 $(na,nb)$（`pour` 用 $d=\min(\text{源壶水},\text{目标壶空位})$）。
6. 若 $(na,nb)=(a,b)$（空操作）或 `dis[na][nb]!=inf`（已访问）则跳过；否则 `dis[na][nb]=dis[a][b]+1`、写 `pre[na][nb]`、入队。
7. 循环结束时 `head` 指向终点：`ta=qa[head],tb=qb[head]`（引理 8 保证 `dis[ta][tb]` 全局最小）。循环条件里 `head<tail` 永远先被 `!done(head)` 打破——引理 3 说明 $(0,N)$ 一定可达，队首必会碰到目标，因此不会读到未初始化的 `qa[head]`。
8. 从 $(ta,tb)$ 沿 `pre` 退到 $(0,0)$：每步 `stk[++top]=s&7`，再解出父 $(pb,pa)$；条件写成 `while(dis[x][y])`，因为 `dis[0][0]==0`。
9. 输出 `dis[ta][tb]`，再依次弹出 `stk`（逆序还原正序），空格分隔，`'\n'` 结尾。
10. $N=0$ 时第 4 步第一次判据即命中起点，回溯循环不执行，自然输出 `0`，无需特判。

### 4.3 复杂度

- 初始化 $O(C_aC_b)\le 10^6$；搜索 $O(6(2C_a+2C_b))\le 2.4\times10^4$（引理 2）；回溯与输出 $O(C_a+C_b)$。
- $T\le30$：总计 $\le 3\times10^7$ 次赋值 + $7\times10^5$ 次松弛，线性可过；空间 `dis`+`pre` 约 $2\times4\,\text{MB}$，队列与栈约 $3\times4\,\text{MB}$。

### 4.4 验证状态（全部手算，未编译未运行）

**本地题面没有样例，无法与官方答案对标**，以下用手工 BFS 分层复刻。

1. $C_a=3,C_b=5$：逐层展开得 $d_1=\{(3,0),(0,5)\}$，$d_2=\{(0,3),(3,5),(3,2)\}$，$d_3=\{(3,3),(0,2)\}$，$d_4=\{(1,5),(2,0)\}$，$d_5=\{(1,0),(2,5)\}$，$d_6=\{(0,1),(3,4)\}$，$d_7=\{(3,1),(0,4)\}$，$d_8=\varnothing$（16 个边界状态全部访问完，恰为 $2C_a+2C_b=16$，与引理 2/3 吻合）。读出答案：$N=0\!\to\!0,\ N=1\!\to\!6,\ N=2\!\to\!2,\ N=3\!\to\!2,\ N=4\!\to\!6,\ N=5\!\to\!1$。其中 $N=4$ 正是 §2.3 的例子：单向 $A\to B$ 的 8 步被 BFS 的 6 步击败。把这条最优路径 $(0,0)\xrightarrow{2}(0,5)\xrightarrow{5}(3,2)\xrightarrow{3}(0,2)\xrightarrow{5}(2,0)\xrightarrow{2}(2,5)\xrightarrow{5}(3,4)$ 与代码末尾注释的 `6 2 5 3 5 2 5` 对齐，逐一验算每次倒水量 $d=\min(\text{源壶},\text{目标壶空位})$，确认 $k=5$ 分支的 $na,nb$ 与操作语义（`pour B A`）一致、且回溯解码出的 $k$ 顺序正确（栈逆序打印后就是这串数字）。
2. $C_a=2,C_b=5$：$d_1=\{(2,0),(0,5)\}$，$d_2=\{(2,5),(0,2),(2,3)\}$，$d_3=\{(2,2),(0,3)\}$，$d_4=\{(0,4),(2,1)\}$，$d_5=\{(2,4),(0,1)\}$，$d_6=\{(1,5),(1,0)\}$，$d_7=\varnothing$$14=2C_a+2C_b$（含起点）全覆盖，与引理 2/3 的计数吻合）。答案 $N=1\!\to\!4,\ N=2\!\to\!2,\ N=3\!\to\!2,\ N=4\!\to\!4,\ N=5\!\to\!1$。与"两方向取小"的结果逐点一致（$N=1$：$B\to A$ 4 步 vs $A\to B$ 8 步），支持 §2.3 的猜想但不依赖它。
3. 自造边界 $C_a=1,C_b=3,N=2$：$d_1=\{(1,0),(0,3)\}$，$d_2$ 含 $(1,2)$（`fill B` 后 `pour B A` 倒 1）→ 输出 `2 2 5`。
4. 自造边界 $C_a=2,C_b=3,N=1$：$d_2\ni(2,1)$ → 2 步（`fill B`,`pour B A`）；1 步不可能（$d_1$ 里 $b\in\{0,3\}$）。
5. 自造边界 $C_a=C_b=1$（$\gcd=1$ 允许，且 $C_a\le C_b$ 取等时只能是这组）：$N=1\to$ `1 2`；$N=0\to$ `0`。倒水两向都是空操作，正好检验第 6 步的自环过滤。
6. 极端规模 $C_a=999,C_b=1000$（互质）：可达状态 $\le3998$、队列上界远小于 `mxn*mxn`，`fill_n` $999\times1001\approx10^6$ 次，确认不会 TLE/越界；步数上界 $2C_a+2C_b<4000$，`pre` 位打包 $<2^{23}$，均在 `int` 内。


## 5. 示例代码

```cpp
// https://www.luogu.com.cn/problem/P1432
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};                 // C_a,C_b<=1000，+5 松弛
constexpr int inf{1145141919};

int Ca,Cb,N;
int dis[mxn][mxn],pre[mxn][mxn];         // pre=(pa<<13)|(pb<<3)|op，兼作 vis
int qa[mxn*mxn],qb[mxn*mxn],stk[mxn*mxn],top=0;

bool done(int i){return qb[i]==N;}       // 只要求 B 达标，A 任意

void solve()
{
	cin>>Ca>>Cb>>N;
	for(int i=0;i<=Ca;++i)
		fill_n(dis[i],Cb+1,inf);          // 全局数组默认 0，不填 inf 就等于"全都访问过"
	int head=0,tail=0;
	qa[tail]=0;qb[tail++]=0;
	dis[0][0]=0;
	for(;head<tail&&!done(head);++head)
	{
		int a=qa[head],b=qb[head];
		for(int k=1,na,nb;k<=6;++k)
		{
			na=a;nb=b;
			if(k==1)
				na=Ca;                    // fill A
			if(k==2)
				nb=Cb;                    // fill B
			if(k==3)
				na=0;                     // empty A
			if(k==4)
				nb=0;                     // empty B
			if(k==5)
			{
				int d=min(b,Ca-a);        // pour B A：倒到 A 满或 B 空
				na=a+d;nb=b-d;
			}
			if(k==6)
			{
				int d=min(a,Cb-b);        // pour A B
				na=a-d;nb=b+d;
			}
			if((na==a&&nb==b)||dis[na][nb]!=inf)
				continue;                 // 空操作会让自己指自己，回溯时死循环
			dis[na][nb]=dis[a][b]+1;
			pre[na][nb]=(a<<13)|(b<<3)|k;
			qa[tail]=na;qb[tail++]=nb;
		}
	}
	int ta=qa[head],tb=qb[head];          // 出队命中，故 dis 全局最小
	int x=ta,y=tb;
	while(dis[x][y])
	{
		int s=pre[x][y];                  // 先存住，否则改 x 后高位取错
		stk[++top]=s&7;
		y=(s>>3)&1023;
		x=s>>13;
	}
	cout<<dis[ta][tb];
	while(top)
		cout<<' '<<stk[top--];
	cout<<'\n';
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	int T;
	cin>>T;
	while(T--)
		solve();
	return 0;
}

// 本地题面无样例；下面是手算用的自造校验数据（步数核对见 §4.4，序列只是"一种"最优解）
// 3
// 3 5 4      -> 6 2 5 3 5 2 5
// 2 5 1      -> 4 2 5 3 5
// 1 1 0      -> 0
```
