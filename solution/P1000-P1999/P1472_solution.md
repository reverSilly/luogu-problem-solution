# P1472 [USACO2.3] 奶牛家谱 Cow Pedigrees

> 标签：动态规划 DP / 树形数据结构 / 前缀和 · 难度：省选/NOI-

## 1. 重新读题

**问题重述（简化版）**

一棵二叉树，每个结点要么没有儿子（叶子），要么恰好有 2 个儿子，这种树叫**完满二叉树**（full / proper binary tree，注意不是"完美/perfect binary tree"）。问：

> 恰好含 $n$ 个结点、且**深度恰好**为 $k$ 的完满二叉树，共有多少种不同的形态？

- "深度"定义为结点到根的最长链上的结点数，**根的深度记为 1**（题面明示），因此一棵树的深度 = 最深结点的深度。
- "无标号"指结点上没有 $1..n$ 的标签，只比较**形状**；换一组标签不算新形态。
- 答案对 $9901$ 取模。

**约束与它暗示的复杂度**

| 量 | 范围 | 读出的信息 |
|---|---|---|
| $n$ | $3\le n<200$ | 状态第一维 $\approx 200$ |
| $k$ | $2\le k<100$ | 状态第二维 $\approx 100$ |
| 模数 | $9901$（不是 $10^9+7$） | 是 USACO 老题的味道；$9901$ 很小，乘积不会爆 `int`，但**累加**会 |

$n\cdot k\approx 2\times10^4$ 个状态，若每个状态转移是 $O(n)$，总量 $O(kn^2)\approx 2\times10^6$，完全够快。题面 tag「动态规划 + 树形数据结构 + 前缀和」正好对应：**树形（按子树分解）+ DP（二维状态）+ 前缀和（第 2.5 节会看到它到底指什么）**。

**关于样例的重要声明**

本地题面 `P1472.md` 只有 Description / Input Format / Output Format / Hint，**没有任何输入输出样例**，因此无法拿官方样例对标程序输出。本文的验证全部靠手算：小数据下把形态一一列举出来，与 DP 表逐格比对（见 §4 的"验证状态"）。

**一处必须挑明的歧义**：题面说"无标号完满二叉树……有多少种结构"。二叉树的定义里"左儿子 / 右儿子"是两个不同的位置，把一个结点的两棵子树左右对调，得到的是一棵**新的**二叉树（例如 $n=5$ 有两种：叶子在左、叶子在右）。本文按这一最标准的"二叉树形态"约定（即**有序**子树）来计数，它不需要除以任何数，也与 $n$ 个点全部形态数为 Catalan 数 $C_{(n-1)/2}$ 的教科书结论一致。若把两棵子树视为无序（只看"家谱图"的无根形状），只需把转移改成折半形式，第 2.6 节给出该变体的完整公式与证明，答案差在哪里一目了然。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：完满二叉树的结点数与深度被"卡死"了

拿到"完满二叉树"这个词，第一件事不是想 DP，而是先把**它到底能长什么样**问清楚。有两条立刻能拿到的硬约束，它们能帮我后面快速否掉一些状态、也能用来检验手算。

**引理 1（结点数必为奇数）** 若一棵完满二叉树存在，则其结点数 $n$ 为奇数。等价地，$n$ 为偶数时本题答案恒为 0。

*证明*（两种都做一遍，第二种用来交叉验证第一种）。

- 证法一（按结点数归纳）：$n=1$ 时是单个叶子，为奇数。设结论对所有结点数 $<n$ 的完满二叉树成立。若 $n\ge 3$，根有两个儿子，左子树含 $a$ 个结点、右子树含 $b$ 个结点，两棵子树自身也是完满二叉树且 $a+b=n-1$，且 $1\le a,b\le n-2<n$。由归纳假设 $a,b$ 都是奇数，于是 $n=1+a+b=1+\text{奇}+\text{奇}=\text{奇}$。$\blacksquare$
- 证法二（数边）：设内部结点（有儿子的）数为 $v$，叶子数为 $l$，则 $n=v+l$。每条边都由某个内部结点引出，且每个内部结点恰好引出 2 条边，故边数 $=2v$；又一棵 $n$ 结点的树恰有 $n-1$ 条边，于是 $2v=n-1$，即 $n=2v+1$ 为奇数，同时顺手得到 $v=\frac{n-1}{2}$、$l=n-v=\frac{n+1}{2}$。$\blacksquare$

两种证法都只用了"每个结点出度为 0 或 2"这一个条件，结论一致，可以放心把"偶数 $n$"这一整类输入判 0。证法二还给了一个后面要用的信息：**叶子数 $l=\frac{n+1}{2}$，内部结点数 $v=\frac{n-1}{2}$**，两者都被 $n$ 唯一决定（这也是为什么"深度 $\le d$"的上界会带出 $\frac{n+1}{2}$）。

**引理 2（深度的上下界）** 一棵有 $n$ 个结点的完满二叉树，其深度 $d$ 满足
$$\lceil \log_2 (n+1)\rceil \le d \le \frac{n+1}{2}.$$

*证明*

- **上界**：深度为 $d$ 的树，取一条到最深叶子的链，链上有 $d$ 个结点。链尾是叶子，链上其余 $d-1$ 个都是内部结点（它们有儿子）。每个内部结点出度恰为 2，其中一条边沿链向下，另一条边挂一个"额外儿子"，该额外儿子是一棵完满子树的根，至少含 1 个结点。不同内部结点的额外儿子互不相同（否则某个结点会有两个父亲，违反树的定义），且都不在链上，故这 $d-1$ 棵额外子树两两不交、也与链不交。于是 $n\ge d+(d-1)=2d-1$，解出 $d\le\frac{n+1}{2}$。
  等号能取到：构造"锯齿树"（也叫 caterpillar）——取一条长 $d$ 的链 $u_1\to u_2\to\cdots\to u_d$，让 $u_d$ 作叶子，$u_1,\dots,u_{d-1}$ 每个再额外挂一片叶子。此时每个 $u_t\ (t<d)$ 出度为 2（下一个链结点 + 额外叶子）、$u_d$ 出度 0、额外叶子出度 0，是完满二叉树，深度恰为 $d$，结点数 $=d+(d-1)=2d-1$，反解得 $d=\frac{n+1}{2}$。所以上界是**紧**的，并且对任意合法 $n$（奇数）该构造都存在。
- **下界**：深度为 $d$ 的树，第 $1,2,\dots,d$ 层每层最多 $2^{t-1}$ 个结点（第 1 层只有根），总结点数最多 $\sum_{t=1}^{d}2^{t-1}=2^{d}-1$，即等比求和。故 $n\le 2^d-1$，即 $2^d\ge n+1$，取对数得 $d\ge\log_2(n+1)$；$d$ 是整数所以 $d\ge\lceil\log_2(n+1)\rceil$。
  等号能取到当且仅当 $n+1$ 是 2 的幂（此时每层都塞满，就是完美二叉树）；否则下界只是"至少这么多"。$\blacksquare$

这两个界直接产出若干"送分"结论：

| 情况 | 结论 | 依据 |
|---|---|---|
| $n$ 偶数 | $0$ | 引理 1 |
| $k>\frac{n+1}{2}$ | $0$ | 引理 2 上界 |
| $k<\lceil\log_2(n+1)\rceil$ | $0$ | 引理 2 下界 |
| $n=2^m-1,\ k=m$ | 至少含完美树这 1 种 | 下界取等情况存在 |

例：$n=5,k=2$ —— 下界 $\lceil\log_2 6\rceil=3>2$，直接判 0，不需要任何 DP。这个预判很重要：它给了我一个"零成本"的参考答案，后面 DP 若在这格给出非 0 就说明我写错了。

### 2.2 简化版：先扔掉"深度恰好 $k$"

**做法**：先把"深度恰好 $k$"整个扔掉，只回答"$n$ 个结点的完满二叉树共有多少种形态"，记这个数为 $T(n)$。这是最自然的降维——少一个维度，问题立刻可枚举。

根的左子树有 $a$ 个结点，右子树就有 $n-1-a$ 个，$a$ 可以取 $1,2,\dots,n-2$。由引理 1，两棵子树也必须完满，所以 $a$ 与 $n-1-a$ 都得是奇数（偶数的那些分裂方式对 $T$ 的贡献是 0）。

**引理 3（形态数的分解递推）** 约定 $T(1)=1$，$T(\text{偶数})=0$，则对奇数 $n\ge 3$：
$$T(n)=\sum_{\substack{a\ \mathrm{odd}\\ 1\le a\le n-2}} T(a)\,T(n-1-a).$$

*证明*：构造一个双射。设 $\mathcal{A}_a$ 为 $a$ 个结点的完满二叉树集合，$\mathcal{B}_{n-1-a}$ 为 $n-1-a$ 个结点的完满二叉树集合。考虑映射
$$\varphi_a:\mathcal{A}_a\times\mathcal{B}_{n-1-a}\to\{n\text{ 个结点的完满二叉树}\},\quad (L,R)\mapsto \text{以 }L\text{ 为左子树、}R\text{ 为右子树的新树}.$$
- **良定义**：新树根出度为 2（正好挂 $L,R$），其余结点出度不变，故仍是完满二叉树，结点数 $=1+a+(n-1-a)=n$。
- **单射**：两棵不同的有序对 $(L,R)\ne(L',R')$，若 $a\ne a'$ 则结点分布不同；若 $a=a'$ 则左或右子树形状不同，还原时"取根的左子树/右子树"是确定的操作，故像不同。这里正是"左右儿子有序"约定的用武之地：$(L,R)$ 与 $(R,L)$（$L\ne R$）被算作两个不同的像。
- **满射**：任取一棵 $n$ 结点的完满二叉树 $X$（$n\ge3$），它的根必有恰好 2 个儿子，删除根即得左子树 $L$（$a$ 个结点）与右子树 $R$（$n-1-a$ 个结点），二者完满，且 $X=\varphi_a(L,R)$。$n=1$ 时 $X$ 是单叶，由 $T(1)=1$ 覆盖。
于是 $\{n\text{ 结点树}\}$ 被不重不漏地拆成 $\bigsqcup_a(\mathcal{A}_a\times\mathcal{B}_{n-1-a})$，两边取基数即得。$\blacksquare$

**手算小表**（$T(n)$ = 全部形态数，深度任意）

| $n$ | 1 | 3 | 5 | 7 | 9 | 11 | 13 |
|---|---|---|---|---|---|---|---|
| $T(n)$ | 1 | 1 | 2 | 5 | 14 | 42 | 132 |

例如 $T(5)=T(1)T(3)+T(3)T(1)=1+1=2$，两棵就是"叶子在左"与"叶子在右"；$T(7)=T(1)T(5)+T(3)T(3)+T(5)T(1)=2+1+2=5$。

**这带来一个有价值的副产品**：这张表就是 Catalan 数 $C_{(n-1)/2}$（$C_0=1,C_1=1,C_2=2,C_3=5,C_4=14,C_5=42,C_6=132$）。也就是说，本问题的"深度不限"版本恰好是经典 Catalan 计数。它给了我一个**独立于 DP 的校验基准**：任何二维 DP 表沿深度轴的总和必须回到这张表，§4 的验证会逐行用它。

### 2.3 直接按"恰好深度"转移 —— 失败剖析

现在把深度这一维加回来。最"省事"的想法是：仿照引理 3，直接把 $T$ 换成"深度恰好"的版本 $f[n][d]$，写成

$$f[n][d]\stackrel{?}{=}\sum_{a\ \mathrm{odd}} f[a][d-1]\,f[n-1-a][d-1].\tag{✗}$$

理由听上去很顺："树的深度比最深的子树多 1，所以两棵子树都得是深度 $d-1$。"

**反例（$n=7,d=3$）**：式 (✗) 给出
$$f[7][3]=f[1][2]f[5][2]+f[3][2]f[3][2]+f[5][2]f[1][2].$$
逐项手算：$f[1][2]=0$（单点树深度只能是 1）；$f[3][2]=1$（根挂两个叶子，深度恰好 2）；$f[5][2]=0$（引理 2 下界 $\lceil\log_2 6\rceil=3>2$）。于是 (✗) 给出 $0\cdot0+1\cdot1+0\cdot0=1$……看起来对了？

别急，再试 **$n=7,d=4$**：
$$f[7][4]\stackrel{✗}{=}f[1][3]f[5][3]+f[3][3]f[3][3]+f[5][3]f[1][3]=0\cdot2+0\cdot0+2\cdot0=0.$$
而真值不是 0。把 7 个点的全部 5 种形态（§2.2 的 $T(7)=5$）逐一列出并标深度：

| 编号 | 结构（左子树规模 / 右子树规模） | 深度 |
|---|---|---|
| ① | $1/5$，且 5 点子树是"叶在左" | $1+3=4$ |
| ② | $1/5$，且 5 点子树是"叶在右" | $1+3=4$ |
| ③ | $3/3$（两棵都是樱桃） | $1+2=3$ |
| ④ | $5/1$，且 5 点子树是"叶在左" | $1+3=4$ |
| ⑤ | $5/1$，且 5 点子树是"叶在右" | $1+3=4$ |

所以 $f[7][4]=4$，而 (✗) 给出 0 —— **式 (✗) 错，且是欠计数**。

**为什么错（根因剖析）**：一棵树的深度等于 $1+\max(\text{左子树深度},\text{右子树深度})$，取 $\max$ 意味着**只需要至少一侧达到 $d-1$，另一侧可以浅**。而 (✗) 把两侧都强制成 $d-1$，等于把条件从"或"写成了"且"：
$$\{\max=h\}=\{L=h,\ R\le h\}\ \cup\ \{R=h,\ L\le h\},$$
而 (✗) 只算了 $\{L=h,\ R=h\}$，是上面并集的一个真子集。上面 $n=7,d=4$ 的 4 种形态里，每一侧都是"一边深 3、另一边深 1"（①②④⑤），$\{L=3,R=3\}$ 一个都不在里面，所以得 0。$n=7,d=3$ 那次"碰巧对"是因为唯一形态 ③ 恰好左右同为 2，属于巧合，不能救这个式子。

**为什么"看起来顺"的想法必然会掉进这个坑**：乘积原理（$\#(A\times B)=\#A\cdot\#B$）要求两侧的选择**互相独立**，也就是各自被一个"上界型"约束限制。"深度恰好 $d-1$"是**等式约束**，两侧一旦用 $\max$ 关联起来就不独立了——一个 $\max$ 把两个变量耦合了。所以真正的出路不是去修补这个等式，而是**把等式约束换成上界约束**。

### 2.4 经典解法：把"恰好"换成"不超过"

**关键一步：把"恰好"换成"不超过"**。定义
$$g[i][d]=\#\{\text{含 }i\text{ 个结点、深度}\le d\text{ 的完满二叉树形态}\}\pmod{9901}.$$
"深度 $\le d$"对左右子树来说是**各自独立**的上界约束：整棵树深度 $\le d$ 当且仅当两棵子树深度都 $\le d-1$。等式约束耦合两侧，上界约束不耦合——这正是 2.3 节剖析出的病根，被这一换状态治好了。

**引理 4（转移递推）** 边界 $g[1][d]=1\ (\forall d\ge1)$，$g[\text{偶数}][d]=0$，$g[i][0]=0\ (i\ge1)$。对奇数 $i\ge3$、$d\ge2$：
$$g[i][d]=\sum_{\substack{a\ \mathrm{odd}\\ 1\le a\le i-2}} g[a][d-1]\cdot g[i-1-a][d-1].$$

*证明*：与引理 3 同族，仍用双射，只是加上深度。设 $\mathcal{G}_s^{(d)}=\{\text{深度}\le d\text{ 的 }s\text{ 结点完满二叉树}\}$。对每个奇数 $a\in[1,i-2]$，定义
$$\psi_a:\mathcal{G}_a^{(d-1)}\times\mathcal{G}_{i-1-a}^{(d-1)}\to\mathcal{G}_i^{(d)},\quad (L,R)\mapsto \text{以 }L,R\text{ 为左右子树的树}.$$
- **良定义**：新树深度 $=1+\max(\mathrm{dep}(L),\mathrm{dep}(R))\le 1+(d-1)=d$，结点数 $=i$，根出度 2、其余结点出度继承 $L,R$ 故仍为 0 或 2，因而是 $\mathcal{G}_i^{(d)}$ 的元素。
- **像的并覆盖全域**：任取 $X\in\mathcal{G}_i^{(d)}$。$i\ge3$ 故 $X$ 的根有左右儿子，删根得 $L,R$，结点数分别 $a,i-1-a$（$a$ 为奇数，由引理 1）。$\mathrm{dep}(L)=\mathrm{dep}(X)-1\le d-1$，$\mathrm{dep}(R)\le d-1$，故 $L\in\mathcal{G}_a^{(d-1)}$、$R\in\mathcal{G}_{i-1-a}^{(d-1)}$，且 $X=\psi_a(L,R)$。
- **不重不漏**：$\psi_a$ 是单射（删根还原 $(L,R)$ 是唯一操作），不同 $a$ 的像不相交（左子树结点数不同）。故诸像构成 $\mathcal{G}_i^{(d)}$ 的不交并。
- **边界核对**：$i=1$ 时树只有一个根结点，深度恰为 $1$；它对 $d\ge1$ 满足 $\le d$、对 $d=0$ 不满足，故 $g[1][d]=1$、$g[1][0]=0$，与定义一致。偶数 $i$ 由引理 1 集合为空，$g=0$。
两边取基数即得递推。$\blacksquare$

注意求和里 $a$ 跑遍**全部**奇数（不是只跑一半），因为左右有序，$(L,R)$ 与 $(R,L)$ 是两个元素——这保证了递推里**没有除法**，模 9901 下不须担心逆元。

**复杂度**：状态 $n\times k$，每个状态 $O(n)$ 个 $a$，总 $O(kn^2)\approx 2\times10^6$；循环顺序的要求是**外层 $d$ 必须从小到大递增**（第 $d$ 列只读第 $d-1$ 列，同列之内 $i$ 的先后随意），把 $d$ 放外层还让"上一列已完整算好"这个不变量一眼可见。

**手算一版小表**（$g[i][d]$，$i$ 奇数，$d=1..6$；由引理 4 逐格推）

| $i\backslash d$ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 1 | 1 | 1 | 1 | 1 | 1 | 1 |
| 3 | 0 | 1 | 1 | 1 | 1 | 1 |
| 5 | 0 | 0 | 2 | 2 | 2 | 2 |
| 7 | 0 | 0 | 1 | 5 | 5 | 5 |
| 9 | 0 | 0 | 0 | 6 | 14 | 14 |
| 11 | 0 | 0 | 0 | 6 | 26 | 42 |

抽查四格（每一项都用上一列的值）：$g[7][3]=g[3][2]g[3][2]=1$（$a=1,5$ 两项因 $g[5][2]=0$ 消失）；$g[7][4]=2g[1][3]g[5][3]+g[3][3]^2=2\cdot1\cdot2+1=5$；$g[9][4]=2g[1][3]g[7][3]+2g[3][3]g[5][3]=2+4=6$；$g[11][4]=2g[1][3]g[9][3]+2g[3][3]g[7][3]+g[5][3]^2=0+2+4=6$。
每行最终都稳定在 §2.2 的 $T(i)$ 上（$1,1,2,5,14,42$）——这正是引理 2 上界 "$d\ge\frac{i+1}{2}$ 时约束失效" 的体现，也说明表没算歪。

### 2.5 归约：$g$ 就是 $f$ 沿深度轴的前缀和

$f$（恰好）与 $g$（不超过）的关系是**包含关系明确的递推链**：
$$\mathcal{G}_i^{(d)}=\mathcal{F}_i^{(1)}\sqcup\mathcal{F}_i^{(2)}\sqcup\cdots\sqcup\mathcal{F}_i^{(d)}$$
其中 $\mathcal{F}_i^{(e)}$ 是"$i$ 结点、深度恰好 $e$"的树集合。这正是前缀和的形状。

**引理 5（差分即答案）** 对 $d\ge2$：$f[i][d]=g[i][d]-g[i][d-1]$。

*证明*：$\mathcal{F}_i^{(d)}=\mathcal{G}_i^{(d)}\setminus\mathcal{G}_i^{(d-1)}$。
- $\subseteq$：深度恰好 $d$ 的树当然深度 $\le d$；而深度 $=d>d-1$，故不属于 $\mathcal{G}_i^{(d-1)}$。
- $\supseteq$：取 $X\in\mathcal{G}_i^{(d)}\setminus\mathcal{G}_i^{(d-1)}$，则 $\mathrm{dep}(X)\le d$ 且 $\mathrm{dep}(X)\not\le d-1$，即 $\mathrm{dep}(X)>d-1$；深度是整数，故 $\mathrm{dep}(X)\ge d$，两头夹住得 $\mathrm{dep}(X)=d$，即 $X\in\mathcal{F}_i^{(d)}$。
又 $\mathcal{G}_i^{(d-1)}\subseteq\mathcal{G}_i^{(d)}$（$\le d-1$ 蕴含 $\le d$），有限集合做差得 $\#\mathcal{F}_i^{(d)}=\#\mathcal{G}_i^{(d)}-\#\mathcal{G}_i^{(d-1)}$。$\blacksquare$

因为整张 $g$ 表在模 9901 下存储，差分时必须处理负数：答案取 $(g[n][k]-g[n][k-1]+9901)\bmod 9901$。这里加一个 9901 就够，因为两个余数都在 $[0,9900]$，差在 $[-9900,9900]$，加 9901 后落在 $[1,19801]$，再取模即得非负代表。

**题面 tag「前缀和」的落点**：把深度轴看成下标，$g[i][\cdot]$ 恰是 $f[i][\cdot]$ 的前缀和 $g[i][d]=\sum_{e=1}^{d}f[i][e]$（引理 5 的求和形式），$f$ 是 $g$ 的差分。所以**"前缀和"这个 tag 不是指优化转移的手段，而是指"用前缀和状态替点状态、最后差分还原"这一换状态套路**。这个识别能反过来确认：本解法与出题人意图一致。

**独立交叉验证（不需要再写一份代码）**：$f$ 还有一条来路完全不同的公式——直接在"恰好"上做容斥。深度恰好 $d$ $\Leftrightarrow$ 两侧都 $\le d-1$，且至少一侧恰好 $d-1$：
$$f[i][d]=\sum_{\substack{a\ \mathrm{odd}\\1\le a\le i-2}}\Big(g[a][d-1]g[i-1-a][d-1]-g[a][d-2]\,g[i-1-a][d-2]\Big).$$
*证明*：对固定的 $a$，集合 $\mathcal{G}_a^{(d-1)}\times\mathcal{G}_{i-1-a}^{(d-1)}$ 通过 $\psi_a$ 双射到"深度 $\le d$ 且左子树规模 $=a$"的树；同样 $\mathcal{G}_a^{(d-2)}\times\mathcal{G}_{i-1-a}^{(d-2)}$ 双射到"深度 $\le d-1$ 且左子树规模 $=a$"的树。前者 $\supseteq$ 后者，做差得"深度恰好 $d$ 且左子树规模 $=a$"。再对各 $a$ 不交并（理由同引理 4 的"不重不漏"）。$\blacksquare$
这条式子和引理 5 是从两个不同角度推出来的，二者必须恒等——它等价于 $\sum_a(g_{d-1}g_{d-1}-g_{d-2}g_{d-2})=g[i][d]-g[i][d-1]$，即递推本身相减。用它验一格的算术见 §4 验证状态。

### 2.6 溢出防护、边界与"无序"变体

**溢出防护（逐项算数，不靠感觉）**

- **单个乘积**：DP 值始终先取模，故 $0\le g<9901$，乘积上界 $9900\times9900=98\,010\,000<2^{31}-1=2\,147\,483\,647$，`int` 相乘**不会**溢出；但这是"贴着上界"的安全，写法上一律把其中一个因子提成 `i64` 再乘，杜绝将来把模数改大（比如换成 $10^9+7$）时静默爆掉。
- **累加**：一次转移最多 $\frac{i-1}{2}\le 99$ 项。如果写成"先把乘积全加起来、最后取模"，上界是 $99\times98\,010\,000\approx9.7\times10^{9}>2^{31}$，**必然溢出**。所以采用"每项先 `%mod` 再累加"，此时部分和 $<99\times9901\approx9.8\times10^{5}$，怎么存都安全；我仍用 `i64 s` 累加，读代码时不必再验证这个上界。
- **差分为负**：见引理 5 后的处理，`+mod` 后再取模。
- **哨兵/清零**：风格规范特别提醒"全局 `int` 数组默认 0，从 `vector` 迁移时不可达状态必须 `fill_n(...,INF)`"。本题**故意不需要**：$g$ 表的"不可达"语义就是 $0$ 种方案（偶数规模、$d=0$ 层、深度超限），全局 0 初值恰好是正确答案，且递推只读 $d-1$ 层、只写 $d$ 层，不存在"旧值污染"。若把状态改成"最小可能深度"这类求极值的 DP，就必须 `fill_n(&dp[0][0],mxn*mxk,INF)`。

**边界自检清单**

| 输入 | 程序应输出 | 依据 |
|---|---|---|
| $n$ 偶数 | 0 | 递推从不写偶数行，$g$ 恒 0，差分 0 |
| $k>\frac{n+1}{2}$ | 0 | $g[n][k]=g[n][k-1]$（都已是全形态数），差分 0 |
| $k<\lceil\log_2(n+1)\rceil$ | 0 | $g[n][k]=g[n][k-1]=0$（第 2.4 表可见 $i=9,d\le3$ 全 0） |
| $n=3,k=2$ | 1 | 唯一樱桃树 |
| $k=2$（题面下界） | 只可能 $n=3$ 出 1，其余 0 | $d$ 从 2 起递推，$g[n][1]$ 只有 $n=1$ 为 1 |

**注：如果判题按"左右子树无序"统计**（把家谱图的形状当作无左右之分的树），本代码会在 $a\ne i-1-a$ 的分裂上多算一倍。此时正确递推是

**引理 6（折半式）** 设 $u[i][d]$ 为无序版本的"深度 $\le d$"计数。记同一列上的有序和 $S=\sum_{a\ \mathrm{odd}} u[a][d-1]\,u[i-1-a][d-1]$，中心项 $c=u[m][d-1]$（$m=\frac{i-1}{2}$；$m$ 为偶数时 $u[m][\cdot]=0$，公式自动退化）。则
$$U=\frac{S+c}{2}.$$

*证明*：无序树由"$\{L,R\}$ 这个（可重复的）二元多重集"唯一决定。按两侧规模是否相等分类。

- **规模不等**（$a\ne i-1-a$）：两侧规模不同，故 $L\ne R$ 自动成立；每个无序树对应有序对 $(L,R)$ 与 $(R,L)$ 恰好两个，$S$ 中把它们数了 2 次。设这类无序树数为 $P$，则 $S$ 中这部分贡献 $2P$，且它们各自应计 1 次。
- **规模相等**（$a=m$，此时 $i-1=2m$，$m$ 必为奇数才有非零项）：两侧都取自 $\mathcal{U}_m^{(d-1)}$（记其大小 $c=u[m][d-1]$），无序且允许相同，即"从 $c$ 棵树里可重复地选 2 棵"，数量为 $\binom{c+1}{2}=\frac{c(c+1)}{2}$。$S$ 中这一项是 $\#\mathcal{U}_m\times\#\mathcal{U}_m=c^2$（有序对，含 $c$ 个对角元素 $(L,L)$）。

故 $S=2P+c^2$，而 $U=P+\frac{c(c+1)}{2}$。代入：
$$\frac{S+c}{2}=\frac{2P+c^2+c}{2}=P+\frac{c(c+1)}{2}=U.\ \blacksquare$$

注意对角项是 $c$（**一次方**）而不是 $c^2$：这正是 $\frac{c(c+1)}{2}$（可重复选 2 棵）与 $\frac{c^2}{2}$ 的差别，随手写平方就会错，只是 $c\le1$ 的小格子上碰巧看不出。分歧要 $c\ge2$ 才暴露：取 $i=19$、$d$ 足够大（约束失效，$u$ 退化为"全部形态数"，即 Wedderburn–Etherington 数 $1,1,1,2,3,6,11,23,46$ 对应 $n=1,3,5,7,9,11,13,15,17$）。
$$S=2(u_1u_{17}+u_3u_{15}+u_5u_{13}+u_7u_{11})+u_9^2=2(46+23+11+12)+9=184+9=193,$$
$c=u_9=3$，正确值 $U=\frac{193+3}{2}=98$（$=u_{19}$，与 W-E 表吻合 ✓）；误用 $c^2=9$ 则得 $\frac{193+9}{2}=101$ ✗，差 3。

模 9901 下的除以 2 是**合法**的：真实整数 $S+c=2U$ 为偶数，而 $\gcd(2,9901)=1$，故 $U\equiv(S+c)\cdot 2^{-1}\pmod{9901}$，逆元 $2^{-1}=4951$（$2\times4951=9902\equiv1$）。**切忌**写成 `(S%mod+c%mod)/2`：取模后的余数可能为奇数，整数除法会丢掉半个模。正确写法是用 `inv2`，或把 $S+c$ 保持在模 $2\times9901$ 下再除。

本文按题面"二叉树结构"的标准有序约定实现，代码里没有任何除法，这也是选择该约定的实用理由：少一处逆元/奇偶陷阱。

## 3. 模式总结（Pattern Summary）

按我真实的思考顺序，一步一个标签（同类步骤出现两次就拆成两条）：

- **探索性质** —— 先榨干"每个结点出度 0 或 2"这一条：$n$ 必奇、叶子数 $\frac{n+1}{2}$、深度区间 $[\lceil\log_2(n+1)\rceil,\frac{n+1}{2}]$。它白送一批"答案为 0"的判据，成为后续手算基准。
- **考虑简化版** —— 删掉深度维度，只数形态，认出 $T(n)=\sum_a T(a)T(n-1-a)$（Catalan），确认"枚举左子树规模"是正确分解方向。
- **经典问题解法（一）** —— 树形 DP 的规模分解：把树的计数归结为"子树规模 + 子树形态数"的卷积型求和，用双射论证不重不漏（引理 3）。
- **剖析贪心/直觉失败** —— 直接套"恰好深度"转移 $f[a][d-1]f[i-1-a][d-1]$，在 $n=7,d=4$ 上得 0 而真值 4。定位病根：$\max$ 把两侧耦合，等式约束破坏乘积原理的独立性；(✗) 只覆盖 $\{L=h,R=h\}$ 这个真子集。
- **经典问题解法（二）** —— 换状态为**上界型**（"深度 $\le d$"），使左右子树条件解耦，转移成为两个独立集合的笛卡尔积计数（引理 4），且天然无除法。
- **归约到更简单的问题** —— 认出 $g$ 是 $f$ 沿深度轴的前缀和，最后一格差分还原答案（引理 5）；题面 tag「前缀和」正是这一步，而不是转移优化。
- **独立二次校验** —— 另用容斥公式 $f[i][d]=\sum_a(g_{d-1}g_{d-1}-g_{d-2}g_{d-2})$ 与 Catalan 总数 $\sum_d f[i][d]=T(i)$，从两条与 DP 无关的路复核同一张表。
- **模运算陷阱清单** —— 乘积上界 $9.8\times10^7$（`int` 勉强够，仍提 `i64`）、累加 $9.7\times10^9$（必须逐项取模）、差分为负（$+\text{mod}$）、若引入折半则必须用逆元 $4951$ 而非整数除。

**可复用的套路一句话**：*当"恰好"型状态因为 $\max/\min$ 耦合而无法相乘时，把它换成"不超过/至少"型上界状态，让子问题独立，最后用前缀和的逆运算（差分）还原"恰好"。*（同族技巧：求"最大值恰好为 $k$"的排列数 $\to$ "最大值 $\le k$" 相减；求"GCD 恰好为 $k$" $\to$ Möbius/容斥。）

## 4. 真实解法

### 4.1 符号表（代码里出现的每一个量）

| 符号 | 类型/尺寸 | 含义 | 初始化 | 一行记忆法 |
|---|---|---|---|---|
| `n,k` | `int` | 输入的结点数与**恰好**深度 | 由 `cin` | target |
| `mod` | `constexpr int{9901}` | 模数 | 常量 | 题给定 |
| `mxn,mxk` | `constexpr int{205},{105}` | 数组上界，$200/100$ 各 +5 松弛 | 常量 | "+5 松弛" |
| `g[i][d]` | `int g[205][105]` | **$i$ 个结点的完满二叉树中，深度 $\le d$ 的形态数**（已取模） | 全局 0；随后 `g[1][d]=1 (d\ge1)` | **g = "至多"（give-me-an-upper-bound）** |
| `s` | `i64` | 一层内累加的乘积和 | 每格前 `=0` | sum |
| `d` | `int` | 外层：当前深度上限 | 从 2 | depth 上限 |
| `i` | `int` | 中层：当前规模，只跑奇数 | 从 3、步长 2 | size |
| `a` | `int` | 内层：左子树规模（奇数，$1\le a\le i-2$） | 从 1、步长 2 | a-side |
| `i-1-a` | — | 右子树规模，自动为奇数且 $\ge1$ | — | b-side |
| `ans` | `int` | $(g[n][k]-g[n][k-1]+mod)\%mod$ | 计算得 | 差分 |

**为什么 0 初值是安全的**（对照风格规范的 `fill_n` 提醒）：`g` 的"未定义/不可达"语义就是 $0$ 种方案，`g[偶数][*]`、`g[*][0]` 保持 0 恰为正确值；递推只**读** $d-1$ 列、只**写** $d$ 列，单向无回环，因此不需要任何 `fill_n(...,INF)`。只有把状态换成求极值（如"最小深度"）时才必须预填 INF。

**为什么内层循环用 `i+=2`、`a+=2`**：由引理 1，偶数规模不可达；跳过它们把转移量减半，并且保证 `i-1-a` 也是奇数（奇 $-1-$ 奇 $=$ 奇），无需再判。

### 4.2 编号步骤

1. 读入 $n,k$。
2. 置 $g[1][d]\leftarrow1$，对 $d=1..k$（单结点树深度恰为 1，故对所有 $d\ge1$ 满足"深度 $\le d$"）。其余格保持 0，即"偶数规模 / $d=0$ 层"不可达。
3. `for d=2..k:`（上界从小到大；第 $d$ 列只依赖第 $d-1$ 列，不变量"**前 $d-1$ 列已全部正确**"在每次进入循环时成立）
4. `for i=3..n step 2:`（只处理奇数规模）
5. `s ← Σ_{a=1,3,5,...,i-2} (i64)g[a][d-1]*g[i-1-a][d-1] % mod`：枚举左子树规模 $a$，右子树规模被 $i-1-a$ 唯一决定；两侧子树各自独立地取"深度 $\le d-1$"的形态，用乘积原理，再对 $a$ 用加法原理（引理 4 的不交并）。
6. `g[i][d] ← s % mod`（累加已逐项取模，`s < 99*9901 ≈ 9.8e5`，不溢出）。
7. 输出 `ans ← (g[n][k]-g[n][k-1]+mod)%mod`（引理 5；$k\ge2$ 由题面保证，`g[n][k-1]` 一定在数组内且已算好）。

### 4.3 复杂度

- 时间：$\sum_{d=2}^{k}\sum_{i\ \mathrm{odd}}\frac{i-1}{2}$；精确计数为 $(k-1)\sum_{j=1}^{(n-1)/2}j=(k-1)\frac{m(m+1)}{2}$（$m=\frac{n-1}{2}$）。代 $n=199,k=99$：$98\times4950=485\,100$ 次乘加，约 $5\times10^{5}$，比 1 秒的额度低三个数量级，无需任何转移优化。
- 空间：`int g[205][105]` $=21\,525$ 个 `int` $=86\,100$ B $\approx 84$ KB；无递归，栈占用为 0。
- 若把 $g$ 换成"只保留前一列"的滚动数组，空间降到 $O(n)$（本题只有一次查询，差分所需的 $g[n][k-1]$ 正好是上一列，可以保住）；但全表更便于按 §2.4 的表逐格对算，故不省这一点内存。

```cpp
constexpr int mod{9901};

int n,k;
int g[mxn][mxk]; //g[i][d]:i 个结点、深度不超过 d 的完满二叉树形态数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int d=1;d<=k;++d)
		g[1][d]=1; //单点树深度为 1
	for(int d=2;d<=k;++d) //深度必须在外层：g[.][d] 只依赖 g[.][d-1]
		for(int i=3;i<=n;i+=2) //完满二叉树结点数必为奇数，偶数格永远保持 0
		{
			i64 s=0;
			for(int a=1;a<=i-2;a+=2) //左子树 a 个结点，右子树 i-1-a 个
				s+=(i64)g[a][d-1]*g[i-1-a][d-1]%mod;
			g[i][d]=(int)(s%mod);
		}
	int ans=(g[n][k]-g[n][k-1]+mod)%mod;
	cout<<ans<<'\n';
	return 0;
}
```

### 5.1 关键行的不变量与坑点

| 行 | 不变量 / 为什么这么写 | 写错的后果 |
|---|---|---|
| `for(int d=1;d<=k;++d) g[1][d]=1;` | 单点树深度 $=1$，故对所有 $d\ge1$ 有 $1\le d$ | 漏掉则所有含叶子子树的项归 0，整表全 0 |
| 外层 `d`、中层 `i` | 第 $d$ 列只读第 $d-1$ 列；`i` 的顺序可任意（同列内互不依赖） | 若把 `d` 放进内层，会读到尚未算出的 $g[\cdot][d-1]$，整表退化成 0 |
| `i+=2`、`a+=2` | 引理 1：偶数规模不可达；同时保证 $i-1-a$ 为奇数 | 写成 `++i` 也不会错（偶数格恒 0），但白跑一倍时间 |
| `a<=i-2` | 保证右子树 $i-1-a\ge1$，即两棵子树都非空 | 写成 `a<i-1` 会算进 $a=i-1$、右子树规模 0 的非法项（该项为 $g[i-1][d-1]\cdot g[0][d-1]=0$，恰好仍是 0，属"侥幸正确"，不该依赖） |
| `(i64)g[a][d-1]*g[i-1-a][d-1]%mod` | 先转 `i64` 再乘，杜绝日后换大模数时爆 `int` | 直接 `int*int` 在 $10^9+7$ 下静默溢出 |
| `s` 声明在 `i` 循环体内、每次 `=0` | 每格独立累加 | 若提到外层忘清，得到前缀和的卷积 |
| `(g[n][k]-g[n][k-1]+mod)%mod` | 引理 5 差分 + 负数修正；$k\ge2$ 由题面保证，`g[n][0]` 存在 | 少 `+mod` 时 C++ 的 `%` 会给出负数 |

### 5.2 变体：若按"左右子树无序"统计（考古层，保留备查）

把第 5 步的累加改成"有序和 $S$ + 中心项 $c$，再乘 $2$ 的逆元"（引理 6）。注意这里的表 $u$ 必须**自成体系**：右侧读的是上一列的**无序**值，不能与有序表混用。

```cpp
constexpr int inv2{4951}; //2*4951=9902≡1 (mod 9901)
...
	i64 s=0;
	for(int a=1;a<=i-2;a+=2)
		s+=(i64)u[a][d-1]*u[i-1-a][d-1]%mod;
	s%=mod;
	i64 c=u[(i-1)/2][d-1]; //中心项是一次方；(i-1)/2 为偶数时 u=0，自动退化
	u[i][d]=(int)((s+c)*inv2%mod);
```

自检（全用无序表 $u$）：$u[5][3]=\frac{2+0}{2}=1$（$S=2u_1u_3=2$，$m=2$ 偶 $\Rightarrow c=0$）；$u[7][3]=\frac{1+1}{2}=1$（$S=u_3u_3=1$，$c=u_3[2]=1$）；$u[7][4]=\frac{3+1}{2}=2$（$S=2u_1u_5+u_3u_3=2+1=3$，$c=u_3[3]=1$）。于是无序版 $f[5][3]=1-0=1$、$f[7][4]=2-1=1$，与"无左右之分的家谱形状"（Wedderburn–Etherington 数 $1,1,1,2,3,6,\dots$）一致 ✓。

再看**绝不能写 `(s+c)/2`** 的理由：设真实整数 $S+c=10000$（则 $U=5000$），代码里余下的是 $10000\bmod9901=99$，`99/2=49` 完全错；而 $99\times4951=490149$，$490149-9901\times49=490149-485149=5000$ ✓。原因：$S+c$ 为偶整数，$r\equiv2U\pmod{9901}$ 且 $2$ 可逆，故 $U\equiv r\cdot2^{-1}$。
