# P1723 高手过愚人节

## 1. 重新读题

给定 $n$（$1 \le n \le 10$）个字符串 $s_1, s_2, \dots, s_n$，每个字符串长度 $|s_i| \le 10^7$。对于每个字符串，求其**最长连续回文子串**的长度。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质与朴素中心扩展的瓶颈

回文串具有关于中心对称的性质。最直观的做法是枚举每个可能的回文中心，向左右两侧同步扩展，直到字符不相等为止。
这里有两个痛点：
1. **奇偶长度分裂**：奇数长度回文串的中心在字符上（如 `aba`），偶数长度回文串的中心在两个字符之间的空隙上（如 `abba`），分开写两套循环很容易漏掉边界；
2. **平方级退化**：在全 `a` 字符串 `aaaa...a` 上，每个中心都要扩展 $O(L)$ 次，总复杂度退化为 $\Theta(L^2)$，面对 $|s_i| \le 10^7$ 完全不可接受。

### 2.2 统一奇偶与回文对称复用：Manacher 算法（附完整证明）

先解决第一个痛点：在原串 $s$（长度 $L$）的相邻字符间及首尾两端都插入分隔符 `#`，并在最左端加上哨兵 `^`、最右端加上哨兵 `$`（三者均不出现在原串中），构造长度 $M = 2L + 3$ 的新串 $t$。例如 `aba` 变为 `^#a#b#a#$`，`abba` 变为 `^#a#b#b#a#$`。

**引理 1（分隔符变换下的半径-长度恒等式）**：对变换后的串 $t$，设 $p[i]$ 表示以位置 $i$（$1 \le i \le 2L+1$）为中心的最长回文子串向单侧延伸的**回文半径**（含中心自身，即 $t[i - p[i] + 1 \dots i + p[i] - 1]$ 为回文串，且 $t[i - p[i]] \ne t[i + p[i]]$）。则该回文串对应于原串 $s$ 中的回文子串长度恰好等于 $p[i] - 1$。

**证明**：
在串 $t$ 的回文子串 $t[i - p[i] + 1 \dots i + p[i] - 1]$ 中，由于 $t[i - p[i]]$ 与 $t[i + p[i]]$ 不相等，该极长回文串的左右两端点 $t[i - p[i] + 1]$ 与 $t[i + p[i] - 1]$ 必然都是 `#`（若两端点是原串字符，则再往外扩一格两侧都是 `#`，必然相等，与 $p[i]$ 极长矛盾）。
一段以 `#` 开头且以 `#` 结尾、长度为 $2p[i] - 1$ 的 `#`/字符交替串中，`#` 的个数比原串字符个数恰好多 $1$，且二者之和为 $2p[i] - 1$。设原串字符个数为 $k$，则 $k + (k + 1) = 2p[i] - 1 \implies k = p[i] - 1$。$\blacksquare$

接下来解决第二个痛点：如何利用已经算出的 $p[1 \dots i-1]$ 加速 $p[i]$ 的计算？

**引理 2（Manacher 对称镜像下界与 $\Theta(L)$ 线性复杂度）**：在从左到右计算 $p[i]$ 的过程中，维护已求出的所有回文区间中右端点最靠右的一个：记其中心为 $c$、右开边界为 $r = c + p[c]$。当计算新位置 $i > c$ 时，记 $i$ 关于 $c$ 的对称点为 $\text{mir} = 2c - i$。则：
1. 若 $i < r$，回文半径满足初值下界 $p[i] \ge \min(r - i,\, p[\text{mir}])$；在此初值基础上继续暴力向外扩展即可得到精确的 $p[i]$；
2. 整个算法中字符暴力扩展比较的总次数严格不超过 $2L + 2 = O(L)$。

**证明**：
1. **下界正确性**：当 $i < r$ 时，区间 $(2c - r,\, r)$ 关于中心 $c$ 严格对称。
   - 若 $p[\text{mir}] < r - i$，则以 $\text{mir}$ 为中心的极长回文串完全落在开区间 $(2c - r,\, r)$ 内部，由关于 $c$ 的整体翻转对称性，以 $i$ 为中心、半径为 $p[\text{mir}]$ 的子串与之完全镜像相等，且再往外扩一格的两端仍在 $(2c - r,\, r)$ 内，故必不相等，此时 $p[i] = p[\text{mir}]$；
   - 若 $p[\text{mir}] \ge r - i$，则以 $\text{mir}$ 为中心的回文串至少覆盖到左边界 $2c - r + 1$，经中心 $c$ 镜像翻转后，以 $i$ 为中心、半径为 $r - i$ 的子串（一直延伸到 $r - 1$）必然也是回文串，故 $p[i] \ge r - i$。
   两种情况合起来即 $p[i] \ge \min(r - i,\, p[\text{mir}])$。
2. **线性时间复杂度**：每当 `while(t[i + p[i]] == t[i - p[i]]) ++p[i];` 循环成功匹配一次，当前的 $i + p[i]$ 必定严格超过此前的最大右边界 $r$（因为若 $p[\text{mir}] < r - i$，由上文分析第一次比较就会失配退出；只有当初值达到 $r - i$ 时才可能继续扩展）。因此每次成功扩展都会使全局右边界 $r$ 严格加 $1$。由于 $r$ 从 $0$ 单调增加到至多 $2L + 2$，成功扩展的总次数 $\le 2L + 2$，而每个位置 $i$ 失配仅发生 $1$ 次，故总时间复杂度严格为 $\Theta(L)$。$\blacksquare$

---

## 3. 模式总结（Pattern Summary）

- **explore its property** — 利用回文串关于中心镜像对称的性质，避免重复比较已包含在更大回文串内的子串。
- **unify odd/even cases** — 插入分隔符 `#` 与首尾异字符哨兵 `^`, `$`，使原串回文长度统一等于新串回文半径减 $1$（引理 1）。
- **classic problem solution** — 维护最右回文边界 $(c, r)$，用对称点 $\text{mir} = 2c - i$ 给出 $p[i]$ 的初值 $\min(r - i, p[\text{mir}])$，实现 $\Theta(L)$ 线性求解（引理 2）。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 字符串组数 | 标准输入 | count |
| `s` | `char [10000005]` | 原始输入字符串 | 每组读入 | source string |
| `t` | `char [20000005]` | 插入 `^`, `#`, `$` 后的扩展串 | 长度 $2L+3$ | transformed string |
| `p[i]` | `int [20000005]` | 扩展串位置 $i$ 的最大回文半径 | Manacher 计算 | palindrome radius |
| `c, r` | `int` | 当前最右回文子串的中心与右开边界 $c+p[c]$ | `0, 0` | center / right |

### 4.2 算法步骤

1. 读入组数 $n$。对每组字符串 `s`（长度 `len`）：
2. 构造扩展串 `t`：`t[0] = '^'`，`t[1] = '#'`，随后依次填入 `s[i]` 与 `'#'`，末尾填 `t[m-1] = '$'`。
3. 初始化 `c = 0, r = 0, ans = 0`。
4. 遍历 `i = 1 .. m-2`：
   - 令 `p[i] = (r > i) ? min(r - i, p[2 * c - i]) : 1`；
   - 当 `t[i + p[i]] == t[i - p[i]]` 时循环令 `++p[i]`（有首尾哨兵 `^` 和 `$`，无需额外判越界）；
   - 若 `i + p[i] > r`，更新 `c = i, r = i + p[i]`；
   - 更新 `ans = max(ans, p[i] - 1)`。
5. 输出 `ans`。

### 4.3 复杂度分析

- **时间复杂度**：每组字符串耗时 $\Theta(|s_i|)$，总时间复杂度为 $\Theta(\sum_{i=1}^n |s_i|)$。
- **空间复杂度**：全局静态数组 `s, t, p` 复用，空间复杂度为 $\Theta(\max |s_i|)$（约 $110\text{ MB}$）。

## 5. 示例代码

```cpp
//
// 题目：P1723 高手过愚人节
// https://www.luogu.com.cn/problem/P1723
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20000005};

int n;
char s[mxn/2],t[mxn];
int p[mxn];

int solve_one()
{
	cin>>s;
	int len=strlen(s),m=0;
	t[m++]='^';
	t[m++]='#';
	for(int i=0;i<len;++i)
	{
		t[m++]=s[i];
		t[m++]='#';
	}
	t[m++]='$';

	int c=0,r=0,ans=0;
	for(int i=1;i<m-1;++i)
	{
		int mir=2*c-i;
		p[i]=(r>i)?min(r-i,p[mir]):1;
		while(t[i+p[i]]==t[i-p[i]])
			++p[i];
		if(i+p[i]>r)
		{
			c=i;
			r=i+p[i];
		}
		ans=max(ans,p[i]-1);
	}
	return ans;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	while(n--)
		cout<<solve_one()<<'\n';
	return 0;
}
```
