# P1577 切绳子

> 标签：二分 · Special Judge · 难度：普及/提高-
> 本地题面：`P1577.md`（$n,k\le10^4$，$L_i\le100000.00$，答案截断到小数点后 $2$ 位）。验证：`appendix/P1577/` 对拍 **4000 组**随机数据（小/中/全值域/极短绳四档）+ **13 个**边界用例 + 官方样例 `4 11 / 8.02 7.43 4.57 5.39`，标程、精确有理数暴力、Python 参考实现三方输出**逐字节一致**；另换 4 个种子追加 3000 组，0 不一致；最坏规模 $n=k=10^4$、$L_i$ 全 $100000.00$ 耗时约 $0.002\text{s}$。

## 1. 重新读题

**问题重述（人话版）**

有 $N$ 条绳子，长度分别 $L_1,\dots,L_N$（带 $2$ 位小数）。要切出 $K$ 条**一样长**的绳子，每根原绳可以切出若干段、零头丢弃。问每段最长能多长，答案**截断**到小数点后 $2$ 位。

> 一句话版本：**求最大的实数 $x$，使得 $\sum_i\lfloor L_i/x\rfloor\ge K$；输出 $\lfloor100x\rfloor/100$。**

**题面里容易漏掉的条款**

1. 「答案保留到小数点后 $2$ 位（**直接舍掉** $2$ 位后的小数）」——是**截断**不是四舍五入。官方样例正是活的教材：真实最优 $x^*=2.005$，输出 $2.00$ 而非 $2.01$。
2. 「误差不超过 $0.01$ 或者相对误差不超过 $1\%$」——SPJ 双保险，说明出题人预留给浮点做法一条活路；但截断是**单侧**语义，浮点那道活路并不好走（§2.2 有具体反例），本解法走精确路线，误差恒为 $0$，两项都过。
3. 「$0<L_i\le100000.00$」——长度**严格为正**（最小 $0.01$）且必为 $2$ 位小数。这条是「乘 $100$ 化整数」合法性的全部依据，也是读入方式的依据。
4. 「$0<n\le10000,\ 0<k\le10000$」——$K\ge1$，答案恒存在且为正（不存在"切不出"）；$n,K$ 同阶，暗示 $O(n\log)$ 或 $O(nK)$ 都可接受，而 $O(n\cdot\max L)$ 不行。
5. 输入只有**一组**数据（无多测）；第一行 $N,K$，接下来 $N$ 行每行一个长度。
6. 「切割出 $K$ 条长度相同的绳子」——每根原绳可贡献**多条**（$\lfloor L_i/x\rfloor$ 条），不要求绳子与绳子段一一对应；切割无损耗。

**数据范围与规模感受**

$$n,k\le10^4,\qquad L_i\le10^5.00\;(=10^7\text{ 分}).$$

判定一次「$x$ 是否可行」是 $O(n)$。若从小到大枚举答案 $d\in[1,10^7]$，总代价 $10^7\times10^4=10^{11}$，必挂；而 $x$ 的可行性关于 $x$ **单调**，二分只要 $\log_2 10^7\approx24$ 轮 $\Rightarrow$ $2.4\times10^5$ 次运算。另一个隐性上界：$d=1$ 时段数总和 $=\sum a_i\le10^4\times10^7=10^{11}$，**超出 `int`**，这是本题唯一的溢出点（§2.6）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把「切」翻译成一个函数

先 fix 每段长度 $x$。第 $i$ 根绳子能切出 $\lfloor L_i/x\rfloor$ 段，于是总段数

$$g(x)=\sum_{i=1}^{n}\Big\lfloor\frac{L_i}{x}\Big\rfloor,$$

问题就是：求最大的使 $g(x)\ge K$ 的 $x$。先看清 $g$ 的性质。

**引理 1（$g$ 单调不增，可行集是一个前缀区间）**

若 $x\le y$，则 $L_i/x\ge L_i/y$，取整后仍有 $\lfloor L_i/x\rfloor\ge\lfloor L_i/y\rfloor$，求和得 $g(x)\ge g(y)$。因此集合 $S=\{x:g(x)\ge K\}$ 满足：$x\in S$ 且 $x'\le x$ $\Rightarrow$ $g(x')\ge g(x)\ge K$ $\Rightarrow$ $x'\in S$，即 $S$ 对「变短」封闭；结合单调性，$S$ 必形如 $[0,x^*]$（$x^*=\max S$）。

**证明**：$\lfloor\cdot\rfloor$ 保序（$u\le v\Rightarrow\lfloor u\rfloor\le\lfloor v\rfloor$，因为 $\lfloor u\rfloor\le u\le v$ 而 $\lfloor u\rfloor$ 是整数且 $\le v$，故 $\lfloor u\rfloor\le\lfloor v\rfloor$）。逐项保序求和即得 $g$ 单调不增。封闭性：任取 $x'\le x$，由单调性 $g(x')\ge g(x)\ge K$。于是 $S$ 是一个区间：若 $x\in S$，则 $[0,x]\subseteq S$；所有可行 $x$ 的上确界 $x^*$ 存在（$g(x)\to+\infty$ 当 $x\to0^+$，见下），且 $S=[0,x^*]$ 或 $[0,x^*)$，二者必居其一。$\blacksquare$

> $g(x)\to+\infty$：对任意 $M$，取 $x\le\min_i L_i/M$，则每根绳子都出 $\ge M$ 段，$g(x)\ge nM\ge M$。所以 $x^*$ 存在。

**引理 2（$x^*$ 本身可行，且 $x^*$ 必是某个断点 $L_i/t$）**

设 $a_i=100L_i$（整数分，暂用长度单位叙述同理）。$g$ 是阶梯函数，只在断点集 $\{L_i/t:t\ge1\}$ 处变化，且在每个断点处**左连续**（函数值 = 左极限 = 较大的那个值）。

**证明**：

- **阶梯形状**：固定一项 $h(x)=\lfloor L/x\rfloor$。$h(x)=t\iff t\le L/x<t+1\iff L/(t+1)<x\le L/t$。所以 $h$ 在每个**左开右闭**区间 $\big(L/(t+1),\,L/t\big]$ 上恒等于 $t$；特别地，在断点 $x=L/t$ 处函数值就是 $t$，等于左极限——**左连续**。有限个左连续函数求和仍左连续。
- **$x^*$ 可行**：对任意 $x<x^*$ 有 $g(x)\ge K$（$x\in S$）。令 $x\nearrow x^*$，由左连续性 $g(x^*)=\lim_{x\nearrow x^*}g(x)\ge K$，故 $x^*\in S$。
- **$x^*$ 是断点**：反证。若 $x^*$ 不是断点，注意 $[x^*/2,2x^*]$ 内断点有限（$L_i/t\ge x^*/2\Rightarrow t\le 2L_i/x^*$ 只有有限个 $t$），故存在 $\delta>0$ 使 $(x^*-\delta,x^*+\delta)$ 内无断点，$g$ 在其上恒定。于是 $g(x^*+\delta/2)=g(x^*)\ge K$，即 $x^*+\delta/2\in S$，与 $x^*=\max S$ 矛盾。故 $x^*=L_i/t$ 对某个 $i$ 和整数 $t\ge1$。$\blacksquare$

> 引理 1 给出「可以二分」，引理 2 给出「答案长什么样、$x^*$ 摸得到」——后者是后面暴力基准的根基。

### 2.2 失败思路 1：浮点二分 + `printf("%.2f")`

最直觉的做法：对实数 $x$ 二分 $50\sim100$ 轮，直接 `printf("%.2f")`。它有两处会挂，各有具体反例：

**挂法 (a)：四舍五入 ≠ 截断。** 取 $n=1,K=3,L_1=2.00$。$x^*=2/3=0.6666\ldots$，题目定义的答案是截断的 `0.66`，而 `%.2f` 会打印出 `0.67`——与截断值恰好相差 $0.01$，踩在 SPJ 容差线上；就算这次侥幸被判过，它也不是题目要求的答案。

**挂法 (b)：整数分边界上的浮点抖动。** 取 $n=2,K=2,L_1=L_2=2.00$。$x^*=2.00$ **恰为整数分**。浮点二分收敛到的 $\hat x$ 与 $x^*$ 相差约 $1\ \mathrm{ulp}$：若写出的是「可行侧边界」$\hat x=1.9999999999999998$，截断 $\lfloor100\hat x\rfloor=199$，输出 `1.99`；若写的是另一侧边界则输出 `2.00`——**同一个算法换个输出变量就生死翻转**，而 $x^*$ 落在整数分上并非罕见：输入只有 $2$ 位小数时 $x^*=L_i/t$ 中 $100L_i/t$ 经常恰为整数。

**教训**：截断 $\lfloor100x\rfloor$ 在整数分边界**不连续**，而 `double` 只能把 $x$ 控制到约 $10^{-9}$，没有任何办法保证落在边界的正确一侧。只要题目要求截断，浮点路线本质上不可靠 $\Rightarrow$ 必须把答案**整数化**。

### 2.3 失败思路 2：直接枚举答案

既然断点形如 $L_i/t$（引理 2），那枚举所有断点、取最大可行者？断点总数上界 $\sum_i t_{\max}\approx\sum_i a_i\le10^{11}$，每个还要 $O(n)$ 判定，彻底没戏。退一步「枚举整数分 $d$ 从 $1$ 到 $10^7$」也是 $10^{11}$（§1 已算过账）。

> 但请注意：**单调性（引理 1）一直就在手里**。可行性对 $x$ 单调不增，意味着「最大的可行 $x$」正是二分答案的标准信号——根本不需要枚举。

### 2.4 关键简化：答案天然是「整数分」

输入保证 $2$ 位小数，乘 $100$ 得整数 $a_i$（单位：分）。现在猜一个强命题：

**引理 3（整数分还原论）**

设 $x^*$ 为最大可行实数长度，则题目要求的截断答案等于

$$\frac{1}{100}\max\big\{d\in\mathbb Z_{\ge1}:\textstyle\sum_i\lfloor a_i/d\rfloor\ge K\big\},$$

且当连 $d=1$ 都不可行时答案为 $0.00$。

**证明**：

- **换算**：每段长 $d$ 分（即 $d/100$）时，第 $i$ 根绳子出 $\big\lfloor L_i/(d/100)\big\rfloor=\lfloor a_i/d\rfloor$ 段（$a_i=100L_i$ 为整数），故「$d$ 分可行」$\iff\sum_i\lfloor a_i/d\rfloor\ge K$。
- **与 $x^*$ 对齐**：由引理 1，实数可行集 $=[0,x^*]$，故 $d$ 分可行 $\iff$ $d/100\le x^*$ $\iff$ $d\le100x^*$。于是最大可行整数分 $=\lfloor100x^*\rfloor$。
- **正是题意**：题目要求「保留到小数点后 $2$ 位、直接舍掉」，数学上就是 $\lfloor100x^*\rfloor/100$，与上式一致。
- **$0.00$ 的情形**：$d=1$ 可行 $\iff\sum_i a_i\ge K$（每根绳子切 $1$ 分长正好出 $a_i$ 段）；另一方面 $x^*\ge0.01$ $\iff$ $0.01$ 可行（引理 1）$\iff$ $\sum_i\lfloor100L_i\rfloor=\sum a_i\ge K$。两者等价，故 $\sum a_i<K$ 时 $\lfloor100x^*\rfloor=0$，答案 $0.00$。$\blacksquare$

> 这一步把实数问题**整体消掉**：从此只跟整数打交道，截断、边界、精度全部不是问题。这是全题唯一的"魔法"。

### 2.5 经典技术：整数二分答案

问题变成纯整数版：

$$\max\Big\{d:\sum_i\lfloor a_i/d\rfloor\ge K\Big\},\qquad d\in[1,\max_i a_i].$$

单调性由引理 1 直接继承（$d$ 越大每根出的段越少）。二分上界的取法：

**引理 4（$x^*\le\max_i L_i$）**

$K\ge1$。若 $x>\max_i L_i$，则每根绳子都短于一段，$\lfloor L_i/x\rfloor=0$，总数 $0<K$，不可行。

**证明**：$x>\max L_i\ge L_i$ 对每个 $i$ 成立 $\Rightarrow$ $L_i/x<1$ $\Rightarrow$ $\lfloor L_i/x\rfloor=0$（$L_i>0$）$\Rightarrow$ $g(x)=0<K$（$K\ge1$）。$\blacksquare$

于是 `hi=mx`（最长绳长）即可；`lo=1`，若 `ok(1)` 为假则由引理 3 知答案为 $0.00$，`ans` 的初值 $0$ 正好当哨兵。每轮判定 $O(n)$，共 $O(\log\max a_i)$ 轮。

### 2.6 写代码前的最后一次停顿：数据范围体检

| 量 | 上界 | `int` 够？ |
|---|---|---|
| $a_i$ | $10^7$（$100000.00$） | 够 |
| $\sum_i\lfloor a_i/d\rfloor$（$d=1$ 时 $=\sum a_i$） | $10^4\times10^7=10^{11}$ | **不够，必须 `i64`** |
| `mid=(lo+hi)/2` | $10^7$ | 够（仍统一 `i64`） |

**读入的安全性（为什么 `llround(x*100)` 精确）**：题面值 $v$ 满足 $2$ 位小数、$|v|<2^{17}$。`double` 记 $\mathrm{fl}(v)$，误差 $\le\mathrm{ulp}(v)/2\le2^{16-52}/2\approx7.3\times10^{-12}$；再乘 $100$：$\big|\mathrm{fl}(100\,\mathrm{fl}(v))-100v\big|\le100\times7.3\times10^{-12}+10^7\times2^{-53}\approx1.9\times10^{-9}\ll0.5$，故 `llround` 后恰好得到 $100v$。（若用 `float` 读则只有约 $7$ 位有效数字，$100000.00$ 的"分"位直接丢失，必错。）

**输出**：`ans` 是整数分，手工拆成 `ans/100`、`'.'`、`ans%100`（补前导零），全程不再过浮点。

### 2.7 暴力基准怎么造（对拍设计）

标程 = 整数二分。要一个**独立且绝对正确**的基准，最好的选择是把引理 2 落到代码：精确枚举 $x^*=a_i/t$。还剩一个问题——$t$ 枚举到多大？

**引理 5（最优断点的参数 $t\le K$）**

设 $x^*=a_i/t$（引理 2）。若 $t>K$，令 $x'=a_i/K$，则 $x'=a_i/K>a_i/t=x^*$，且第 $i$ 根绳子在 $x'$ 下能出 $\big\lfloor a_i/x'\big\rfloor=\lfloor a_i/(a_i/K)\rfloor=K$ 段，总数 $\ge K$，$x'$ 可行——与 $x^*$ 的最大性矛盾。

**证明**：即上文不等式链；唯一用到的事实是 $K\ge1$ 与 $x'$ 只让第 $i$ 根绳子出段就已够 $K$ 条。$\blacksquare$

所以暴力只需枚举 $t=1..K$，判定用**纯整数除法** $\lfloor a_jt/a_i\rfloor$（精确模拟 $\lfloor a_j/(a_i/t)\rfloor$，无浮点），最后取 $\lfloor x^*\rfloor$ 分。复杂度 $O(n\cdot K\cdot n)$，小规模（$n\le20,K\le60$）瞬间跑完。它与标程在四个层面互相独立：算法（枚举 vs 二分）、整数化假设（直接算实数最优再截断 vs 假设答案即整数分）、读入（字符串精确解析 vs `double`+`llround`）、输出逻辑。任一层出错，对拍立刻炸——事实是它对拍第一轮就抓住了暴力自己的一个单位 bug（见 §4.5）。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 把「每段长 $x$」翻译成 $g(x)=\sum\lfloor L_i/x\rfloor$，发现可行集对「变短」封闭（引理 1）。
- **consider easier version / 失败思路** — 先试浮点二分 + `printf`，被「截断 ≠ 四舍五入」与「整数分边界抖动」两面夹击（§2.2，两个具体反例），逼出整数化。
- **reduce to easier problem** — 输入 $2$ 位小数 $\Rightarrow$ 乘 $100$ 化整数分；答案 = 最大可行整数分（引理 3），实数与精度问题整体消掉。
- **classic problem solution（二分答案）** — 单调性 + $O(n)$ 判定，$\log$ 因子把 $10^{11}$ 的枚举砍到 $2.4\times10^5$（§2.5）。
- **count-the-accumulator（数据范围体检）** — 判定式里的段数之和上界 $10^{11}$，逼出 `i64`；这是本题唯一溢出点（§2.6）。
- **verify against exact rational brute** — 用「$x^*=a_i/t$ 精确枚举」（引理 2 + 引理 5）做独立基准，同时绕开二分、整数化假设与浮点读入（§2.7）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `int` | 绳子条数 | 读入 | 题面 $N$ |
| $k$ | `int` | 要切出的条数 | 读入 | 题面 $K$ |
| `a[i]` | `i64[mxn]` | 第 $i$ 根绳长，单位「分」（原长 $\times100$） | `llround(x*100)` | 整数化（引理 3） |
| `mx` | `i64` | 最长绳长（分） | $0$（全局默认） | 二分上界（引理 4） |
| `lo,hi` | `i64` | 二分的可行 / 不可行边界（分） | `1,mx` | 答案 $\in[1,\texttt{mx}]$ |
| `mid` | `i64` | 本轮试切长度（分） | `(lo+hi)>>1` | — |
| `ans` | `i64` | 已确认可行的最大分；$0$ = 凑不出 | $0$ | $0.00$ 的哨兵（引理 3） |
| `cnt` | `i64`（`ok` 内局部） | `mid` 之下累计段数 | $0$ | 上界 $10^{11}$，必须 `i64` |

### 4.2 编号步骤

1. 读入 $n,k$；逐根读 `double`，`a[i]=llround(x*100)` 转整数分，同时 `mx=max(mx,a[i])`。
2. `lo=1,hi=mx,ans=0`，进入二分。
3. `ok(mid)`：`cnt` 顺序累加 `a[i]/mid`，一旦 `cnt>=k` 立即返回 `true`（语义不变，只省后面的除法）；走完仍 `<k` 返回 `false`。
4. `ok(mid)` 为真 $\Rightarrow$ `ans=mid;lo=mid+1`（记录答案并向右探更长）；为假 $\Rightarrow$ `hi=mid-1`。
5. 输出 `ans/100`、`'.'`、`ans%100`（不足两位补前导 `'0'`）、`'\n'`；`ans=0` 时即输出 `0.00`。

### 4.3 复杂度

- 时间：$O\big(n\log_2\max_i a_i\big)\le10^4\times24\approx2.4\times10^5$ 次整除。
- 空间：一个 `i64` 数组，$10^4\times8\ \mathrm{B}=80\ \mathrm{KB}$。
- 实测（§4.5）：最坏规模约 $0.002\text{s}$（含进程启动）。

### 4.4 关键不变量

1. `ok(mid)` 为真 $\iff\sum_i\lfloor a_i/\texttt{mid}\rfloor\ge k$ $\iff$ `mid` 分可行（引理 3），与实数判定 $g(\texttt{mid}/100)\ge k$ 等价。
2. 二分全程 `[lo,hi]` 包裹所有未排除的可行分；`ans` 始终是已确认可行的最大分（或 $0$）。
3. `cnt` 用 `i64`：上界 $\sum a_i\le10^{11}$；提前退出只影响速度，不改变与 $k$ 的比较结果。
4. `mx>=1`（$L_i>0\Rightarrow a_i\ge1$）$\Rightarrow$ 二分区间非空；`ans=0` $\iff\sum a_i<k$ $\iff$ 输出 `0.00`。

| 残余风险 | 题面保证 $2$ 位小数；若测试数据出现 $\ge3$ 位小数，`llround` 会四舍五入到分，与「精确截断」可能差 $1$ 分。按题面不会出现 |

## 5. 示例代码

> 与 `appendix/P1577/P1577.cpp` **逐字节一致**。

```cpp
//
// 题目：P1577 切绳子
// https://www.luogu.com.cn/problem/P1577
//
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};        // n<=10000 (+5 松弛)

int n,k;
i64 a[mxn];                      // a[i]=第 i 条绳子的长度,单位:分(原长*100 取整)
i64 mx;                          // 最长绳长(分),二分的上界

// 判定:每根绳子切 d 分长,总共能否得到 k 条
bool ok(i64 d)
{
	i64 cnt=0;
	for(int i=0;i<n;++i)
	{
		cnt+=a[i]/d;
		if(cnt>=k)            // 够了就撤,省下后面的除法
			return true;
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>k;
	for(int i=0;i<n;++i)
	{
		double x;
		cin>>x;
		a[i]=llround(x*100);   // 2 位小数 -> 整数分;总误差 <2e-9,round 后精确
		mx=max(mx,a[i]);
	}
	i64 lo=1,hi=mx,ans=0;      // ans=0:连 1 分都切不出 k 条,答案即 0.00
	while(lo<=hi)
	{
		i64 mid=(lo+hi)>>1;
		if(ok(mid))
		{
			ans=mid;          // mid 可行,记录并向右探更长
			lo=mid+1;
		}
		else
			hi=mid-1;
	}
	cout<<ans/100<<'.';        // 手工拆成 X.XX,不再过浮点
	if(ans%100<10)
		cout<<'0';
	cout<<ans%100<<'\n';
	return 0;
}
```

**代码结构对照**：`a[]` 是引理 3 的整数分化；`ok()` 是引理 3 的判定式，`cnt` 的 `i64` 与提前退出对应 §2.6 的体检结论；`mx` 是引理 4 的二分上界；`ans=0` 是引理 3 中 $0.00$ 情形的哨兵；输出段手工拆分，对应 §2.6「不再过浮点」。

### 5.2 对照实现：精确有理数暴力（仅用于小规模对拍）

见 `appendix/P1577/P1577_brute.cpp`：读入用**字符串**精确解析成整数分（与标程的 `double` 读入独立），按引理 2 + 引理 5 枚举候选 $x^*=a_i/t$（$t=1..K$），用纯整数除法 $\lfloor a_jt/a_i\rfloor$ 判定可行，叉乘比较取最大，最后 $\lfloor x^*\rfloor$ 分即截断答案。$O(nKn)$，$n\le20,K\le60$ 内瞬间完成，**不可提交**。它与标程共享的只有「答案以整数分计量」这一题面定义，算法、读入、截断逻辑全部分离，是引理 3 的独立交叉验证。

### 5.3 易错点清单

- **`printf("%.2f")` 直接输出** $\Rightarrow$ 四舍五入而非截断，$x^*=2/3$ 时输出 `0.67`，应为 `0.66`（§2.2 挂法 a）。
- **`cnt` 用 `int`** $\Rightarrow$ $d=1$ 时 $\sum a_i$ 达 $10^{11}$，静默溢出 WA；这是本题最大坑（§2.6）。
- **读入后 `(int)(x*100)` 直接截断** $\Rightarrow$ `8.02` 的 double 表示可能小于 $8.02$，截断得 $801$；必须 `llround`（误差分析见 §2.6）。
- **用 `float` 读长度** $\Rightarrow$ 约 $7$ 位有效数字装不下 $100000.00$ 的分位，必错；必须 `double`。
- **枚举答案 $d\in[1,10^7]$** $\Rightarrow$ $10^{11}$ 次操作 TLE；必须二分（§2.3）。
- **误以为每根绳子只切一段** $\Rightarrow$ 第 $i$ 根应贡献 $\lfloor L_i/x\rfloor$ 段，要求和。
- **忘记答案可能为 `0.00`**（$\sum a_i<K$ 时 $x^*<0.01$）$\Rightarrow$ `ans` 初值 $0$ 正是为此准备的哨兵（引理 3）。
- **输出忘补前导零** $\Rightarrow$ `2.0` 而非 `2.00`（SPJ 一般容得了，但格式不齐）。
- **`hi` 不取 `mx` 而拍脑袋写更大值** $\Rightarrow$ 不错，只白跑几轮；`hi=mx` 是引理 4 保证的最紧上界。
