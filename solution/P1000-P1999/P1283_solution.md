# P1283 平板涂色 — 题解

## Part 1 — 重述题目

平板上有 $N \le 16$ 个互不重叠的轴对齐矩形，每个矩形有预定颜色 $C_i \in [1,20]$。

**涂色规则：** APM 持有每种颜色一把刷子。每次拿起颜色 $c$ 的刷子时，执行**连锁涂色**过程：

```
repeat:
    找出所有"可涂"且颜色为 c 的矩形（可涂 = 其上方紧邻矩形全部已涂）
    若不存在：停止
    将它们全部涂满（一次性涂完，不可只涂一部分）
```

**"紧邻上方"判定：** 矩形 $s$ 紧邻上方于矩形 $r$，当且仅当 $s$ 的底边恰好贴在 $r$ 的顶边上（$y$ 坐标相等），且两者在水平方向上有重叠区间。

**目标：** 求拿起刷子的最少总次数。

**样例：**

```
输入                          输出
7                             3
0 0 2 2 1
0 2 1 6 2
2 0 4 2 1
1 2 4 4 2
1 4 3 6 1
4 0 6 4 1
3 4 6 6 2
```

## Part 2 — 思维链（完整证明）

### 2.1 精确刻画几何机制——先弄清"紧邻上方"到底在做什么

**坐标约定。** 输入顺序为 $(y_1, x_1, y_2, x_2, c)$，分别是左上角的 $y$ 坐标、左上角的 $x$ 坐标、右下角的 $y$ 坐标、右下角的 $x$ 坐标、颜色。$y$ 轴向下增大。

**紧邻上方的几何条件。** 设矩形 $r$ 坐标为 $(yr1_r, xr1_r, yr2_r, xr2_r)$，矩形 $s$ 坐标为 $(yr1_s, xr1_s, yr2_s, xr2_s)$。$s$ 紧邻上方于 $r$ 当且仅当：

$$yr2_s = yr1_r \quad \wedge \quad xr1_r < xr2_s \quad \wedge \quad xr1_s < xr2_r$$

逐条解释：
- $yr2_s = yr1_r$：$s$ 的底边恰好贴在 $r$ 的顶边上（$y$ 轴向下，$s$ 在 $r$ 上方意味着 $yr2_s \le yr1_r$，相等才是"紧邻"）。
- $xr1_r < xr2_s$ 且 $xr1_s < xr2_r$：水平方向有重叠区间。

由于矩形互不重叠且 $yr2_s = yr1_r$，$s$ 不可能与 $r$ 有面积重叠（若水平重叠则 $s$ 会侵入 $r$ 内部），所以无需额外检查 $s$ 是否在 $r$ 上方——底边相等且互不重叠已隐含 $s$ 完全在 $r$ 上方。

**构建偏序关系。** 对每对矩形 $(r, s)$，若 $s$ 紧邻上方于 $r$，则记录依赖 $r \to s$（$r$ 依赖 $s$，即 $r$ 必须在 $s$ 涂完之后才能涂）。

**引理 0（DAG 性）.** 依赖关系构成有向无环图（DAG）。

**证明.** 设 $s$ 紧邻上方于 $r$，则 $yr2_s = yr1_r$。由于 $s$ 有正高度（$yr1_s < yr2_s$），$yr1_s < yr2_s = yr1_r$，即 $s$ 的 $y$ 坐标范围严格在 $r$ 上方。沿任意依赖链 $r_0 \to r_1 \to \cdots \to r_k$，有 $yr1_{r_{i+1}} < yr1_{r_i}$ 对每个 $i$ 成立（$r_{i+1}$ 在 $r_i$ 上方，$r_i$ 的顶边 $y$ 坐标严格大于 $r_{i+1}$ 的顶边 $y$ 坐标）。因此沿链 $yr1$ 严格递减，不可能回到起点，无环。$\square$

### 2.2 精确刻画连锁涂色——拿起刷子的完整效果

**涂色操作的精确定义。** 拿起颜色 $c$ 的刷子时，执行以下迭代过程：

$$\text{paint}(c, T): \quad T_0 = T,\; T_{k+1} = T_k \cup \{r \notin T_k \mid \text{deps}(r) \subseteq T_k,\; col(r) = c\}$$

重复直到 $T_{k+1} = T_k$（不再有新矩形被涂），返回最终 $T$。

**关键性质——每次转移是确定的。**

**引理 1（连锁确定性）.** 对于任意已涂集合 $T$ 和颜色 $c$，$\text{paint}(c, T)$ 的结果唯一确定，不存在选择。

**证明.** 迭代过程 $T_0, T_1, T_2, \ldots$ 中，$T_{k+1}$ 完全由 $T_k$ 和固定的依赖图、颜色分配决定：
- $\{r \notin T_k \mid \text{deps}(r) \subseteq T_k\}$ 由 $T_k$ 和固定依赖图唯一确定；
- 与 $C_c = \{r \mid col(r) = c\}$ 取交也是确定的；
- $T_{k+1} = T_k \cup S_k$ 是确定操作。

因此整个序列 $T_0, T_1, \ldots, T_m$（$T_m = T_{m-1}$ 时停止）唯一，最终结果唯一。$\square$

**"同时涂色"的含义。** 题目说"给所有颜色为 $C_i$ 且符合下面限制的矩形涂色"，且"每一个矩形必须立刻涂满，不能只涂一部分"。结合样例（答案 3 只能在连锁理解下达成），正确的理解是：拿起刷子后，连锁地涂完所有"在涂色过程中变为可涂"的同色矩形，直到没有新的同色可涂矩形为止。这不是一个选择——是涂色机制的强制要求。

### 2.3 考虑简化版本——去掉连锁

如果去掉连锁（每次拿起刷子只涂"当前"可涂的同色矩形，不连锁），问题变为：在 DAG 上寻找最优涂色顺序，使得颜色切换次数最少。这在一维链上可以贪心，但一般 DAG 上等价于带颜色约束的最短拓扑排序，是 NP-hard 的。

但 $N \le 16$ 这个约束强烈暗示**状态压缩**是正确方向——$2^{16} = 65536$ 种状态完全可以枚举。

### 2.4 状态充分性——只需记录"已涂集合"

**引理 2（状态充分性）.** 任意时刻的涂色状态完全由"已涂色矩形集合 $T$"决定，无需额外记录正在被涂色的矩形。

**证明.**

**(可涂集合由 $T$ 唯一确定.)** 矩形 $r \notin T$ 可涂，当且仅当 $\text{deps}(r) \subseteq T$。这里 $\text{deps}(r)$ 是 $r$ 的所有直接依赖（上方紧邻矩形）的集合，由固定依赖图决定。因此可涂集合 $\text{ready}(T) = \{r \notin T \mid \text{deps}(r) \subseteq T\}$ 完全由 $T$ 决定。

**(无中间态.)** 每个矩形必须一次性涂满（"不能只涂一部分"）。拿起刷子后，被涂的矩形立刻从"未涂"变为"已涂"，不存在"涂了一半"的中间状态。连锁涂色过程中，每一轮新涂的矩形也是立刻变成已涂。

**(连锁过程由 $(c, T)$ 唯一确定.)** 由引理 1，给定 $(c, T)$，连锁涂色的最终结果 $\text{paint}(c, T)$ 唯一确定。

综上，任意时刻的全部信息等价于已涂集合 $T$。$\square$

### 2.5 状态压缩 DP

**状态空间。** $T \subseteq [N]$，用 $N$ 位掩码表示，共 $2^N$ 种。

**状态转移。** 对每个状态 $T$ 和每种颜色 $c$（$C_c \ne \emptyset$）：
- 计算 $T' = \text{paint}(c, T)$
- 若 $T' \ne T$（有矩形被涂），则 $dp[T'] \le dp[T] + 1$

**初始与目标。** $dp[\emptyset] = 0$，答案为 $dp[\text{full}]$（full 为全集掩码）。

### 2.6 DP 正确性——最优子结构证明

**定理.** $dp[\text{full}]$ 等于拿起刷子的最少次数。

**证明.** 采用标准的最优子结构双向论证。

**($\le$ 方向——递推给出可行方案.)** 设 $dp[T] = k$，存在一个 $k$ 步方案涂完 $T$ 中所有矩形。在该方案之后，拿起颜色 $c$ 的刷子（其中 $\text{paint}(c, T) \ne T$），连锁涂色得到 $T' = \text{paint}(c, T)$。这给出 $T'$ 的一个 $k+1$ 步合法方案，故 $dp[T'] \le k + 1 = dp[T] + 1$。递推转移不会产生非法方案。

**($\ge$ 方向——递推不会漏掉最优解.)** 设最优方案共 $m$ 步，颜色序列为 $c_1, c_2, \ldots, c_m$。设 $T_0 = \emptyset$，$T_i = \text{paint}(c_i, T_{i-1})$（$i = 1, \ldots, m$），则 $T_m = \text{full}$。

对每个 $i$，$T_i = \text{paint}(c_i, T_{i-1})$ 是一次合法转移，且 $T_i \ne T_{i-1}$（否则该步无意义，矛盾最优性——可删去多余步骤）。由递推：

$$dp[T_i] \le dp[T_{i-1}] + 1$$

由 $dp[T_0] = dp[\emptyset] = 0$，归纳得 $dp[T_m] \le m$。即 $dp[\text{full}] \le m$。

由于 $m$ 是最优方案的步数，$m \le dp[\text{full}]$（$dp[\text{full}]$ 是最少步数，任何方案步数都不少于它）。因此 $dp[\text{full}] = m$，递推恰好达到最优值。$\square$

### 2.7 样例验证

**依赖关系构建。** 样例中 7 个矩形坐标如下（$y_1, x_1, y_2, x_2$, 颜色）：

| 矩形 | $yr1$ | $xr1$ | $yr2$ | $xr2$ | 颜色 |
|---|---|---|---|---|---|
| r0 | 0 | 0 | 2 | 2 | 1 |
| r1 | 0 | 2 | 1 | 6 | 2 |
| r2 | 2 | 0 | 4 | 2 | 1 |
| r3 | 1 | 2 | 4 | 4 | 2 |
| r4 | 1 | 4 | 3 | 6 | 1 |
| r5 | 4 | 0 | 6 | 4 | 1 |
| r6 | 3 | 4 | 6 | 6 | 2 |

逐个检查"紧邻上方"关系（$s$ 的底边 $yr2_s$ 等于 $r$ 的顶边 $yr1_r$，且水平重叠）：

- **r0**（$yr1 = 0$）：无矩形底边在 $y = 0$。→ $dep[r0] = \emptyset$
- **r1**（$yr1 = 0$）：同上。→ $dep[r1] = \emptyset$
- **r2**（$yr1 = 2$）：r0 底边 $yr2 = 2$，水平 $[0,2] \cap [0,2] = [0,2]$ 重叠。→ $dep[r2] = \{r0\}$
- **r3**（$yr1 = 1$）：r1 底边 $yr2 = 1$，水平 $[2,4] \cap [2,6] = [2,4]$ 重叠。→ $dep[r3] = \{r1\}$
- **r4**（$yr1 = 1$）：r1 底边 $yr2 = 1$，水平 $[4,6] \cap [2,6] = [4,6]$ 重叠。→ $dep[r4] = \{r1\}$
- **r5**（$yr1 = 4$）：r2 底边 $yr2 = 4$，水平 $[0,4] \cap [0,2] = [0,2]$ 重叠 ✓；r3 底边 $yr2 = 4$，水平 $[0,4] \cap [2,4] = [2,4]$ 重叠 ✓。→ $dep[r5] = \{r2, r3\}$
- **r6**（$yr1 = 3$）：r4 底边 $yr2 = 3$，水平 $[4,6] \cap [4,6] = [4,6]$ 重叠 ✓。→ $dep[r6] = \{r4\}$

**DP 追踪。** 颜色 1 矩形：$\{r0, r2, r4, r5\}$，颜色 2 矩形：$\{r1, r3, r6\}$。

**Step 1：$T = \emptyset$，拿颜色 2。**
- 轮 1：$\text{ready} = \{r0, r1\}$（无依赖的矩形）。$S = \text{ready} \cap C_2 = \{r1\}$。涂 r1。$T = \{r1\}$。
- 轮 2：$\text{ready} = \{r0, r3, r4\}$（r3 依赖 r1 已涂，r4 依赖 r1 已涂）。$S = \{r3\}$（r4 颜色 1）。涂 r3。$T = \{r1, r3\}$。
- 轮 3：$\text{ready} = \{r0, r4, r5\}$（r5 依赖 r2 未涂，但 r5 也依赖 r3 已涂——需全部依赖满足，r2 未涂故 r5 不可涂）。$S = \emptyset$。停止。
- $T' = \{r1, r3\}$。$dp[\{r1,r3\}] \le 1$。

**Step 2：$T = \{r1, r3\}$，拿颜色 1。**
- 轮 1：$\text{ready} = \{r0, r4, r5\}$（r0 无依赖 ✓，r4 依赖 r1 ✓，r5 依赖 r2 ✗ + r3 ✓ → r2 未涂故不可）。$S = \{r0, r4\}$。涂 r0, r4。$T = \{r0, r1, r3, r4\}$。
- 轮 2：$\text{ready} = \{r2, r5, r6\}$（r2 依赖 r0 ✓，r5 依赖 r2 ✗ + r3 ✓ → 不可，r6 依赖 r4 ✓）。$S = \{r2\}$（r5 不可，r6 颜色 2）。涂 r2。$T = \{r0, r1, r2, r3, r4\}$。
- 轮 3：$\text{ready} = \{r5, r6\}$。$S = \{r5\}$（r6 颜色 2）。涂 r5。$T = \{r0, r1, r2, r3, r4, r5\}$。
- 轮 4：$\text{ready} = \{r6\}$。$S = \emptyset$。停止。
- $T' = \{r0, r1, r2, r3, r4, r5\}$。$dp[\{r0,r1,r2,r3,r4,r5\}] \le 2$。

**Step 3：$T = \{r0, r1, r2, r3, r4, r5\}$，拿颜色 2。**
- 轮 1：$\text{ready} = \{r6\}$。$S = \{r6\}$。涂 r6。$T = \text{full}$。
- 轮 2：$\text{ready} = \emptyset$。$S = \emptyset$。停止。
- $T' = \text{full}$。$dp[\text{full}] \le 3$。

$dp[\text{full}] = 3$，与期望输出一致。✓

## Part 3 — 模式总结

- **探索特殊机制** — 精确刻画"紧邻上方"依赖关系（底边相等 + 水平重叠）和"连锁涂色"操作（拿起刷子后同色可涂矩形被迭代涂完）
- **考虑简化版本** — 去掉连锁则问题变为一般 DAG 上的最少颜色切换（NP-hard），$N \le 16$ 暗示状态压缩
- **证明连锁确定性** — 迭代过程每步由当前状态唯一确定，故 $\text{paint}(c, T)$ 是确定函数
- **证明状态充分性** — 可涂集合由已涂集合唯一确定，无中间态，故 $2^N$ 种状态完备
- **经典技巧：状态压缩 DP** — $dp[mask]$ = 涂完 $mask$ 的最少次数，正向递推，每状态枚举颜色做连锁转移
- **证明 DP 最优子结构** — $\le$（递推给出可行方案）+ $\ge$（最优方案对应递推路径）双向论证
- **延迟重建** — 只输出最少次数，不需要重建具体方案，省去 parent 数组

## Part 4 — 正式解法

### 符号表

| 符号 | 含义 | 类型 / 初值 | 助记 |
|---|---|---|---|
| $N$ | 矩形个数 | `int`, 读入, $1 \le N \le 16$ | — |
| $yr1[i], xr1[i], yr2[i], xr2[i]$ | 矩形 $i$ 的左上 $y,x$ 和右下 $y,x$ | `int[21]`, 读入 | 坐标 |
| $col[i]$ | 矩形 $i$ 的颜色 | `int[21]`, 读入, $1 \le col \le 20$ | 颜色编号 |
| $dep[i]$ | 矩形 $i$ 的依赖掩码（第 $j$ 位为 1 表示 $i$ 依赖 $j$） | `int[21]`, 预计算 | dep 掩码 |
| $cmask[c]$ | 颜色 $c$ 的矩形掩码（第 $i$ 位为 1 表示矩形 $i$ 颜色为 $c$） | `int[21]`, 预计算 | 颜色掩码 |
| $full$ | 全集掩码 $= (1 \ll N) - 1$ | `int`, 预计算 | 目标状态 |
| $dp[mask]$ | 涂完 $mask$ 中矩形所需最少刷子次数 | `int[65536]`, 初值 $1145141919$（inf） | DP 表 |

### 算法步骤

1. **读入：** 读 $N$，对 $i = 0, \ldots, N-1$ 读 $yr1[i], xr1[i], yr2[i], xr2[i], col[i]$。

2. **预计算依赖掩码：** 对每对 $(i, j)$（$i \ne j$），若 $yr2[j] = yr1[i]$ 且 $xr1[i] < xr2[j]$ 且 $xr1[j] < xr2[i]$，则 $dep[i] \mathrel{|}= 1 \ll j$。

3. **预计算颜色掩码：** 对 $c = 1, \ldots, 20$，$cmask[c] = \bigvee_{col[i] = c} (1 \ll i)$。

4. **DP 正向递推：**
   - $dp[0] = 0$，其余 $dp[mask] = \infty$。
   - 对 $mask$ 从 $0$ 到 $full$（按数值从小到大）：
     - 若 $dp[mask] = \infty$，跳过。
     - 对每种颜色 $c$（$cmask[c] \ne 0$）：
       - **连锁涂色：** $T \leftarrow mask$。repeat：
         - $S \leftarrow \emptyset$
         - 对 $r = 0, \ldots, N-1$：若 $T$ 中无 $r$，且 $dep[r] \& \sim T = 0$（依赖全满足），且 $cmask[c]$ 含 $r$，则 $S \mathrel{|}= 1 \ll r$。
         - 若 $S = \emptyset$，break。
         - $T \leftarrow T \cup S$。
       - 若 $T \ne mask$，$dp[T] \leftarrow \min(dp[T], dp[mask] + 1)$。

5. **输出：** $dp[full]$。

### 复杂度

- **时间：** $O(2^N \cdot C \cdot K \cdot N)$，其中 $C \le 20$ 为颜色数，$K \le N$ 为连锁轮数上界（每轮至少涂一个矩形，最多 $N$ 轮），$N$ 为每轮扫描矩形数。$N = 16$ 时约 $65536 \times 20 \times 16 \times 16 \approx 3.4 \times 10^8$ 次基本操作，C++ 中 1s 可过（常数极小）。
- **空间：** $O(2^N) = O(65536)$（$dp$ 表）+ $O(N + C)$（若干小数组）。

### 验证状态

- **样例验证：** 7 个矩形，依赖关系如 2.7 节分析，DP 追踪得到 $dp[\text{full}] = 3$，与期望输出一致。✓
- **边界 $N = 1$：** 一个矩形无依赖，$dp[1] = 1$（拿一次刷子）。✓
- **所有矩形同色且无依赖：** 一次连锁涂完，$dp[\text{full}] = 1$。✓
- **所有矩形同色但有依赖链：** 需要多步（每步涂掉依赖已满足的部分），DP 正确计数。✓

## Part 5 — 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{21};
constexpr int inf{1145141919};

int n;
int yr1[mxn],xr1[mxn],yr2[mxn],xr2[mxn],col[mxn];
int dep[mxn];
int cmask[21];
int dp[1<<16];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>yr1[i]>>xr1[i]>>yr2[i]>>xr2[i]>>col[i];

	// dep[i]: bit j = 1 means rectangle i depends on rectangle j (j is directly above i)
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			if(i!=j&&yr2[j]==yr1[i]&&xr1[i]<xr2[j]&&xr1[j]<xr2[i])
				dep[i]|=1<<j;

	for(int i=0;i<n;++i)
		cmask[col[i]]|=1<<i;

	int full=(1<<n)-1;
	fill_n(dp,1<<n,inf);
	dp[0]=0;

	for(int mask=0;mask<=full;++mask)
	{
		if(dp[mask]>=inf)
			continue;
		for(int c=1;c<=20;++c)
		{
			if(!cmask[c])
				continue;
			int T=mask;
			// chain painting: repeatedly paint all ready same-color rectangles
			bool changed=true;
			while(changed)
			{
				changed=false;
				for(int r=0;r<n;++r)
					if(!(T>>r&1)&&(dep[r]&~T)==0&&(cmask[c]>>r&1))
					{
						T|=1<<r;
						changed=true;
					}
			}
			if(T!=mask)
				dp[T]=min(dp[T],dp[mask]+1);
		}
	}

	cout<<dp[full]<<'\n';
	return 0;
}
```
