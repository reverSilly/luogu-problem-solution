# P1216 数字三角形 Number Triangles — Solution

## Part 1. Re-read the problem

给定一个 `r` 行的数字金字塔（第 `i` 行有 `i` 个整数，取值范围 `[0,100]`），从顶部出发，每一步只能走到正下方相邻的两个格子之一（左下或右下），到达底边为止。求一条路径经过数字之和的最大值。

- 行数 `r ∈ [1, 1000]`，每个数 `∈ [0, 100]`。
- 求最大路径和。

## Part 2. Chain-of-thought

**explore its property**
这是一棵完全二叉树的 DAG（有向无环图）。顶点 `(i,j)`（`0 ≤ j ≤ i`，`0` 基）只出边到 `(i+1, j)` 和 `(i+1, j+1)`。任何从顶到底的路径恰好经过 `r` 个顶点。要求顶→底路径的最大权值和。这种"局部转移只依赖下一层两个相邻格"的结构，天然暗示自底向上的 DP。

**consider easier version**
先不考虑"最大"，问：从顶点到 `(i, j)` 共有多少条路径？这是杨辉三角，`C(i, j)`。说明 `(i, j)` 的状态空间是"路径的集合"，规模指数爆炸——不可能枚举。但既然所有路径只从 `(i+1, j)` 和 `(i+1, j+1)` 两处进入 `(i, j)`，最优子结构成立：进入 `(i, j)` 的最优路径，必然是 `a[i][j]` 加上"从 `(i+1, j)` 出发到顶"或"从 `(i+1, j+1)` 出发到顶"的最优路径。

**lemma (最优子结构 / 子路径最优性)**
设 `OPT(i, j)` 为"从 `(i, j)` 出发到顶"的最大路径和（包含 `(i, j)` 本身）。对 `i = r-1`（底边）有 `OPT(r-1, j) = a[r-1][j]`（只有一种路径，就是自身）。对 `i < r-1`：

`OPT(i, j) = a[i][j] + max(OPT(i+1, j), OPT(i+1, j+1))`

**Proof.**
任取一条从 `(i, j)` 出发到顶的路径 `P`。`P` 的第二步必然落到 `(i+1, j)` 或 `(i+1, j+1)` 之一（规则）。不妨设 `P` 第二步落到 `(i+1, j)`（另一步对称）。则 `P` 经过的数字和 = `a[i][j]` + （`P` 去掉 `(i, j)` 后的剩余路径从 `(i+1, j)` 出发的和）≤ `a[i][j]` + `OPT(i+1, j)`。所以任何以 `(i+1, j)` 为第二步的路径，和 ≤ `a[i][j] + OPT(i+1, j)`。同样任何以 `(i+1, j+1)` 为第二步的路径，和 ≤ `a[i][j] + OPT(i+1, j+1)`。于是任意路径的和 ≤ `a[i][j] + max(OPT(i+1, j), OPT(i+1, j+1))`。

反之，构造性：若 `OPT(i+1, j) ≥ OPT(i+1, j+1)`，取 `(i+1, j)` 处达到 `OPT(i+1, j)` 的最优路径 `P*`（存在性由归纳法：底边平凡存在；归纳步中 `OPT(i+1, j)` 已被前序状态构造为可达），把 `(i, j)` 拼到 `P*` 前端，得到和 = `a[i][j] + OPT(i+1, j)` 的合法路径。`OPT(i+1, j+1)` 大的情况对称。所以 `OPT(i, j) ≥ a[i][j] + max(...)`。

两者合起来得等号。∎

**lemma (无后效性 / DAG 拓扑序)**
`OPT(i, j)` 只依赖 `OPT(i+1, j)` 和 `OPT(i+1, j+1)`，即只依赖"更下一层"的两个状态。按 `i` 从 `r-1` 递减到 `0` 计算，被依赖的状态一定先被算好。因此状态图是一张 DAG，拓扑序即"自底向上、每行内从左到右（或从右到左）"，可一次性线性递推。

**classic problem solution**
经典 DP。二维版本：`f[i][j] = a[i][j] + max(f[i+1][j], f[i+1][j+1])`，初值 `f[r-1][j] = a[r-1][j]`，答案 `f[0][0]`。`O(r^2)` 时间和空间，`r ≤ 1000` 完全够。

**reduce to easier problem**
`f[i][j]` 只依赖 `f[i+1][j]` 和 `f[i+1][j+1]`，即当前行 `i` 的状态只依赖下一行 `i+1`。空间可压成 1D。

**lemma (1D 原地更新可行且正确)**
设 1D 数组 `dp[j]` 在"开始处理第 `i` 行前"存储的是"从第 `i+1` 行各列出发到顶"的 `OPT(i+1, j)`。要计算 `OPT(i, j) = a[i][j] + max(dp[j], dp[j+1])`。若**从右向左**（`j = w-1` 递减到 `0`，其中 `w` 是第 `i` 行宽度）原地更新：

`for (j = w-1; j >= 0; --j)  dp[j] = a[i][j] + max(dp[j], dp[j+1]);`

**Proof.**
反证。假设某次更新时 `dp[j+1]` 已被覆写，那么覆写它的那次更新是 `dp[j+1] = a[i][j+1] + max(dp[j+1], dp[j+2])`，即它用了"旧"的 `dp[j+1]` 和 `dp[j+2]`。但 `dp[j+2]` 在更早之前就已经被覆写为 `OPT(i, j+2)` 了（因为是从右向左，下标 `j+2 > j+1` 先更新）。这就意味着 `dp[j+1]` 的新值用了 `dp[j+2]` 的新值（第 `i` 行），混入了不该有的信息，错误。

我们直接正向论证更清楚：从右向左更新时，处理 `dp[j]` 之前，已经更新过的下标是 `j+1, j+2, ..., w-1`（这些位置存放的已经是 `OPT(i, ·)`）。处理 `dp[j]` 本身之前还没更新，存放的仍是 `OPT(i+1, j)`（旧值）。而 `dp[j+1]` 呢？它已被更新为 `OPT(i, j+1)`（新值）。

——等一下，这不对。我们需要 `dp[j+1]` 是 `OPT(i+1, j+1)`（旧值），不是 `OPT(i, j+1)`。从右向左更新恰恰把 `dp[j+1]` 改成了新值，所以从右向左**错**。

重新检查方向：从左向右更新。处理 `dp[j]` 前，已经更新过的下标是 `0, 1, ..., j-1`。`dp[j]`（旧值 `OPT(i+1, j)`）未动，`dp[j+1]`（旧值 `OPT(i+1, j+1)`）也还没动（因为 `j+1 > j` 还没轮到）。所以 `dp[j] = a[i][j] + max(dp[j], dp[j+1])` 用的是两个旧值，正确。更新后 `dp[j]` 变成 `OPT(i, j)`。下一步 `dp[j+1]`：它用 `dp[j+1]`（旧 `OPT(i+1, j+1)`）和 `dp[j+2]`（旧 `OPT(i+1, j+2)`），`dp[j]` 已经变成新值，但 `dp[j]` 不在 `dp[j+1]` 的读取范围内（`dp[j+1]` 只读 `dp[j+1]` 和 `dp[j+2]`），所以不影响。

所以正确方向是**从左向右**。

修正结论：**从左向右**原地更新：

`for (j = 0; j < w; ++j)  dp[j] = a[i][j] + max(dp[j], dp[j+1]);`

其中 `w` 是第 `i` 行宽度（`0` 基行号 `i` 的行宽是 `r - i`）。

**Proof (正向，严格归纳).**
设第 `i` 行更新前不变量 `I(i, j)`：`dp[j] = OPT(i+1, j)`（对所有 `0 ≤ j ≤ w-1`，`w = r-i`）。

底：`i = r-1` 前，`dp[j] = a[r-1][j] = OPT(r-1, j)`，且此时 `OPT(i+1, ·)` 即 `OPT(r, ·)` 不存在（底边之下无状态）——更准确地说，底边本身没有"下一行"，直接 `dp[j] = a[r-1][j]` 即答案。归纳从 `i = r-2` 开始。

归纳步：假设处理到行 `i` 前，`dp[j] = OPT(i+1, j)` 对所有 `0 ≤ j ≤ w-1` 成立（`w = r-i`）。从左向右更新 `j = 0, 1, ..., w-1`。处理 `dp[j]` 时：
- `dp[j]` 还是旧值（本轮没改过它，因为 `j` 是本轮当前下标，之前只改了 `0, 1, ..., j-1`），即 `OPT(i+1, j)`。
- `dp[j+1]` 还没改过（因为 `j+1 > j` 还没轮到），即 `OPT(i+1, j+1)`。
- 所以新值 `dp[j] = a[i][j] + max(OPT(i+1, j), OPT(i+1, j+1)) = OPT(i, j)`（由 Part 2 第一个 lemma 的转移式）。

处理完 `j = w-1` 后，对所有 `0 ≤ j ≤ w-1` 有 `dp[j] = OPT(i, j)`，即行 `i` 的不变量。注意行 `i` 宽度 `w = r-i`，比行 `i+1` 的宽度 `w' = r-(i+1) = w-1` 大 1。行 `i` 比行 `i+1` 多一个最左元素（`j=0` 处多出来），所以行 `i` 的 `w` 个元素全部由行 `i+1` 的 `w-1` 个元素（旧值）和 `a[i][0..w-1]` 构造。`dp[w-1]` 在更新前是 `OPT(i+1, w-1)`——但行 `i+1` 只有 `w-1` 个元素，下标 `0..w-2`，下标 `w-1` 在行 `i+1` 不存在！

这是个边界问题：当行 `i` 比行 `i+1` 宽 1 时，`dp[w-1]`（旧值）不是 `OPT(i+1, w-1)`，而是上一轮（行 `i+1` 更新时）的 `dp[w-1]`。行 `i+1` 宽度 `w-1`，所以行 `i+1` 更新只写了 `dp[0..w-2]`，`dp[w-1]` 没被行 `i+1` 写过，是更早的行 `i+2` 的残留值。

更干净的写法：每行更新时只读 `dp[j]` 和 `dp[j+1]`，其中 `j` 从 `0` 到 `w-1`。`dp[w-1]` 在行 `i` 的更新中是被读还是被写？它被写：`dp[w-1] = a[i][w-1] + max(dp[w-1], dp[w])`。`dp[w]` 下标越界（行 `i` 宽度 `w`，下标 `0..w-1`）。

重新审视：第 `i` 行（`0` 基）有 `r - i` 个元素，下标 `0..r-i-1`。对每个 `j ∈ [0, r-i-1]`：`OPT(i, j) = a[i][j] + max(OPT(i+1, j), OPT(i+1, j+1))`。注意 `OPT(i+1, ·)` 定义在 `0 ≤ · ≤ r-(i+1)-1 = r-i-2`，即下标 `0..r-i-2`。所以对 `j = r-i-1`（行 `i` 最右元素），`OPT(i+1, j+1) = OPT(i+1, r-i)` 不存在！

回到二维版本的转移：第 `i` 行（`1` 基行号，宽度 `i`）的下标 `j ∈ [1, i]`。`f[i][j] = a[i][j] + max(f[i+1][j], f[i+1][j+1])`。这里 `f[i+1][j]` 和 `f[i+1][j+1]` 都在行 `i+1` 的有效范围 `[1, i+1]` 内。`j` 从 `1` 到 `i`，`j+1` 从 `2` 到 `i+1`，都合法。底边 `i = r`：`f[r][j] = a[r][j]`，`j ∈ [1, r]`。

转 `0` 基：行 `i`（`i ∈ [0, r-1]`，宽度 `r-i`），下标 `j ∈ [0, r-i-1]`。`f[i][j] = a[i][j] + max(f[i+1][j], f[i+1][j+1])`，对 `i ∈ [0, r-2]`。`i+1` 行宽度 `r-i-1`，下标 `0..r-i-2`。`j` 的范围是 `0..r-i-1`，`j+1` 的范围是 `1..r-i`。`f[i+1][j+1]` 要求 `j+1 ≤ r-i-2`，即 `j ≤ r-i-3`。当 `j = r-i-2` 时 `j+1 = r-i-1`，超出 `f[i+1][·]` 的范围 `[0, r-i-2]`。当 `j = r-i-1` 时 `j+1 = r-i`，同样超出。

所以 `0` 基下 `f[i][j]` 的转移对最右两列"越界"。这说明 `1` 基和 `0` 基的转移式在边界上必须重新核对。

回到 `1` 基：行 `i` 宽度 `i`，下标 `j ∈ [1, i]`。`f[i][j] = a[i][j] + max(f[i+1][j], f[i+1][j+1])`，`i ∈ [1, r-1]`。`i+1` 行宽度 `i+1`，下标 `1..i+1`。`j` 范围 `[1, i]`，`j+1` 范围 `[2, i+1]`，两者都在 `[1, i+1]` 内。边界安全。

所以 **1 基更干净**。代码里用 1 基，`a[i][j]` 是 `i ∈ [1, r]`，`j ∈ [1, i]`。`f[i][j]` 同。初值 `f[r][j] = a[r][j]`（`j ∈ [1, r]`）。转移 `f[i][j] = a[i][j] + max(f[i+1][j], f[i+1][j+1])`，`i ∈ [1, r-1]`，`j ∈ [1, i]`。答案 `f[1][1]`。

1D 空间优化（1 基）：`dp[j]` 在"行 `i` 更新前"存 `f[i+1][j]`（`j ∈ [1, i+1]`）。行 `i` 宽度 `i`，更新 `j = 1, 2, ..., i`（从左向右）。`dp[j]` 旧值 `f[i+1][j]`，`dp[j+1]` 旧值 `f[i+1][j+1]`。新值 `dp[j] = a[i][j] + max(dp[j], dp[j+1]) = f[i][j]`。更新完行 `i` 后 `dp[1..i]` = `f[i][1..i]`。`dp[i+1]` 是残留，但下一轮（行 `i-1`，宽度 `i-1`）只读 `dp[1..i]`（`j` 从 `1` 到 `i-1`，`j+1` 到 `i`），不读 `dp[i+1]`，所以残留无害。

底边初始化：行 `r` 宽度 `r`，`dp[j] = a[r][j]`，`j ∈ [1, r]`。然后 `i` 从 `r-1` 递减到 `1`：`for (j = 1; j <= i; ++j) dp[j] = a[i][j] + max(dp[j], dp[j+1]);`。答案 `dp[1]`。

**lemma (1D 1 基从左向右原地更新，归纳证明)**
不变量 `I(i)`：处理行 `i` 前，`dp[j] = f[i+1][j]`（`j ∈ [1, i+1]`）。底 `i = r`：`dp[j] = a[r][j] = f[r][j]`，`j ∈ [1, r]`，且 `i+1 = r+1` 不出现（底边无下一行，归纳从 `i = r-1` 起）。归纳步：设处理行 `i`（`i ≤ r-1`）前 `dp[j] = f[i+1][j]`（`j ∈ [1, i+1]`）。从左向右更新 `j = 1..i`：处理 `dp[j]` 时 `dp[j]` 未改（仍 `f[i+1][j]`），`dp[j+1]` 未改（仍 `f[i+1][j+1]`，因为 `j+1 > j` 还没轮到）。所以新值 `dp[j] = a[i][j] + max(f[i+1][j], f[i+1][j+1]) = f[i][j]`。处理完 `j = i` 后 `dp[1..i] = f[i][1..i]`。`dp[i+1]` 是上一轮的残留（`f[i+1][i+1]`），但下一轮 `i-1` 只读 `dp[1..i]`，不读 `dp[i+1]`，无害。归纳成立。

**lemma (答案正确性)**
处理完行 `1` 后 `dp[1] = f[1][1]`。而 `f[1][1]` 就是"从顶点 `(1,1)` 出发到底边的最大路径和"，由第一个 lemma 的转移式自底向上构造而来，等于全局最优。答案 `dp[1]`。∎

**complexity**
- 时间 `O(r^2)`：双重循环，第 `i` 行 `i` 次更新，合计 `r(r+1)/2 = O(r^2)`。
- 空间 `O(r)`：只保留 `dp[1..r]` 一个一维数组和当前行的 `a[i][1..i]`。
- 数值范围：最大和 `r × 100 ≤ 100000`，`int` 足够，无需 `long long`。

## Part 4. The real solution

**Notation**

- `r`：行数（`1 ≤ r ≤ 1000`），`int`，从输入读入。
- `a[i][j]`：二维数组（`i ∈ [1, r]`，`j ∈ [1, i]`），存金字塔第 `i` 行第 `j` 列的数字，`int`。读入时直接存入，`1` 基。初始化：全局零，但只用读入覆盖过的 `[1..r][1..i]` 区域。
- `dp[j]`：一维数组（`j ∈ [1, r]`），`int`。含义随 `i` 变化：处理行 `i` 之前，`dp[j] = f[i+1][j]`（`j ∈ [1, i+1]`）；处理行 `i` 之后，`dp[1..i] = f[i][1..i]`。`dp[i+1]` 是上一轮残留，不影响正确性（下一轮不读它）。
- `f[i][j]`：概念量（不是实际存储），"从 `(i,j)` 出发到底边的最大路径和"。`f[r][j] = a[r][j]`（`j ∈ [1, r]`）；`f[i][j] = a[i][j] + max(f[i+1][j], f[i+1][j+1])`（`i ∈ [1, r-1]`，`j ∈ [1, i]`）。最终 `dp[1]` 就是 `f[1][1]`。

**Algorithm**

1. 读入 `r`。
2. 对 `i = 1..r`，读入行 `i` 的 `i` 个整数到 `a[i][1..i]`。
3. 初始化：`for (j = 1; j ≤ r; ++j) dp[j] = a[r][j];`（底边 `f[r][j] = a[r][j]`）。
4. 对 `i = r-1` 递减到 `1`：对 `j = 1..i` 从左向右：`dp[j] = a[i][j] + max(dp[j], dp[j+1]);`
5. 输出 `dp[1]`（即 `f[1][1]`），换行。

**Complexity**
- 时间 `O(r^2)`，空间 `O(r^2)`（二维 `a` 数组；`dp` 是 `O(r)`）。
- 数值范围：最大和 `≤ 100000`，`int` 够。

**Verification status**
- 样例 `r=5`：金字塔
  ```
       7
      3 8
     8 1 0
    2 7 4 4
   4 5 2 6 5
  ```
  底边 `dp = [4,5,2,6,5]`（`j=1..5`）。
  `i=4`（行 `2 7 4 4`，宽度 4）：
  - `j=1`: `dp[1] = 2 + max(4,5) = 7`
  - `j=2`: `dp[2] = 7 + max(5,2) = 12`
  - `j=3`: `dp[3] = 4 + max(2,6) = 10`
  - `j=4`: `dp[4] = 4 + max(6,5) = 10`
  现在 `dp = [7,12,10,10,5]`（`dp[5]=5` 残留）。
  `i=3`（行 `8 1 0`，宽度 3）：
  - `j=1`: `dp[1] = 8 + max(7,12) = 20`
  - `j=2`: `dp[2] = 1 + max(12,10) = 13`
  - `j=3`: `dp[3] = 0 + max(10,10) = 10`
  现在 `dp = [20,13,10,10,5]`。
  `i=2`（行 `3 8`，宽度 2）：
  - `j=1`: `dp[1] = 3 + max(20,13) = 23`
  - `j=2`: `dp[2] = 8 + max(13,10) = 21`
  现在 `dp = [23,21,10,10,5]`。
  `i=1`（行 `7`，宽度 1）：
  - `j=1`: `dp[1] = 7 + max(23,21) = 30`
  答案 `dp[1] = 30`。

  题目样例描述路径 `7→3→8→7→5 = 30`，匹配。✓

  底边 `dp = [4,5,6]`。
  `i=2`（行 `2 3`）：`dp[1] = 2+max(4,5)=7`，`dp[2] = 3+max(5,6)=9`。`dp=[7,9,6]`。
  `i=1`（行 `1`）：`dp[1] = 1+max(7,9)=10`。
  答案 10。手工核对：路径 `1→3→6 = 10`，或 `1→2→5=8`，`1→2→4=7`，`1→3→5=9`。最大 10。✓

- 边界 `r=1`：金字塔只有一个数 `x`。`dp[1] = a[1][1] = x`，循环 `i` 从 `0` 递减到 `1` 不执行（`i = r-1 = 0 < 1`），输出 `dp[1] = x`。✓

## Part 5. Example code

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int r,a[mxn][mxn],dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>r;
	for(int i=1;i<=r;++i)
		for(int j=1;j<=i;++j)
			cin>>a[i][j];

	for(int j=1;j<=r;++j)
		dp[j]=a[r][j];
	for(int i=r-1;i>=1;--i)
		for(int j=1;j<=i;++j)
			dp[j]=a[i][j]+max(dp[j],dp[j+1]);

	cout<<dp[1]<<'\n';
	return 0;
}
```
