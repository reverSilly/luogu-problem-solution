# P1038 [NOIP 2003 提高组] 神经网络 题解

---

## 一、发现叙事

拿到这道题，首先映入眼帘的是一个「神经网络」模型——有向图、节点有状态和阈值、边有权重、分层传递信号。看起来复杂，但仔细读题，核心不过是一个公式：

$$C_i = \left(\sum\limits_{(j,i)\in E} W_{ji}C_j\right) - U_i$$

以及一个简单的规则：**当 $C_i > 0$ 时，神经元兴奋，向下一层发送信号**。

第一反应是模拟。但怎么模拟？直觉告诉我们需要一个「顺序」——每个神经元只依赖上一层的输出，所以图必然是 DAG（有向无环图）。对 DAG 做动态规划或按拓扑序递推，是再自然不过的想法。

再仔细看输入格式：输入层神经元的 $C_i$ 直接给出，而非输入层的神经元 $C_i$ 初始为 $0$。这意味着我们需要从输入层出发，沿着有向边一层层往下计算。这正是**拓扑排序**的典型应用场景。

于是核心思路浮出水面：

1. 拓扑排序确定节点的处理顺序；
2. 按拓扑序依次处理每个节点：如果 $C_u > 0$（兴奋），就把信号沿出边传播给后继；
3. 每个节点最终接收到的加权信号之和，减去其阈值 $U_i$，即为其状态 $C_i$；
4. 最后输出输出层（出度为 0）中 $C_i > 0$ 的节点。

这个思路直接、正确、高效。下面我们来严谨地推导它。

## 二、思维链（含完整证明）

### 2.1 图的性质

题目描述中有一个关键约束：**每层神经元只向下一层的神经元输出信息，只从上一层神经元接受信息**。这意味着神经网络是一张**分层有向图**，边只从低层指向高层，因此图中**不存在环**。换言之，输入保证这是一张 DAG。

> **引理 1**：神经网络的图结构是一个 DAG。
>
> *证明*：若存在环 $v_1\to v_2\to\cdots\to v_k\to v_1$，则层数关系导致 $layer(v_1) < layer(v_2) < \cdots < layer(v_k) < layer(v_1)$，矛盾。故无环。

### 2.2 状态递推公式

对于任意神经元 $i$，其最终状态由下式决定：

$$C_i = \left(\sum_{(j,i)\in E} W_{ji} \cdot C_j\right) - U_i$$

其中 $C_j$ 是前驱神经元 $j$ 的**最终状态**。这个公式有两个要点：

- **递推依赖**：$C_i$ 依赖于所有前驱的 $C_j$，因此必须按拓扑序从前往后计算；
- **阈值截断**：只有当 $C_i > 0$ 时，神经元 $i$ 才处于兴奋状态，才会向下一层传播信号。

### 2.3 初始状态的处理

输入格式告诉我们：对于输入层神经元，$C_i$ 直接给定；对于非输入层，$C_i = 0$。

但注意公式：即使 $C_i$ 初始为 $0$，在累加完所有前驱信号后，还要减去 $U_i$。所以我们不能简单地把非输入层的 $C_i$ 一直留在 $0$。

一种优雅的处理方式：**对于非输入层神经元，初始化 $C_i = -U_i$**。

为什么可以这么做？因为：

$$
C_i = (\text{来自前驱的加权和}) - U_i
    = \underbrace{(\text{来自前驱的加权和})}_{>0\text{时才可能兴奋}} + (-U_i)
$$

将 $-U_i$ 作为初始值，然后在拓扑递推过程中不断累加来自前驱的加权信号 $W_{ji}\cdot C_j$，最终 $C_i$ 的值就自然等于 $(\sum W_{ji}C_j) - U_i$，无需额外处理。

> **引理 2**：设非输入层神经元 $i$ 的初始值设为 $C_i^{(0)} = -U_i$，在拓扑序中依次累加所有前驱贡献 $W_{ji}C_j$，则最终的 $C_i$ 等于公式定义的 $(\sum W_{ji}C_j) - U_i$。
>
> *证明*：归纳法。设 $\text{pred}(i)$ 为 $i$ 的所有前驱，按拓扑序依次处理。当处理到 $i$ 时，所有 $j\in\text{pred}(i)$ 已处理完毕，$C_j$ 已确定。此时 $C_i = -U_i + \sum_{j\in\text{pred}(i)} W_{ji}C_j$，恰为公式结果。$\square$

### 2.4 传播条件

一个神经元 $i$ 只在 $C_i > 0$ 时才向下一层发送信号。这是因为题目规定：「当 $C_i$ 大于 $0$ 时，该神经元处于兴奋状态，否则就处于平静状态。当神经元处于兴奋状态时，下一秒它会向其他神经元传送信号，信号的强度为 $C_i$。」

所以我们在拓扑序中处理节点 $u$ 时，只需判断 `if (c[u] > 0)`，然后遍历其出边累加即可。

### 2.5 输出条件

最后只输出满足以下条件的神经元：

- 属于**输出层**（即出度为 $0$）；
- 最终状态 $C_i > 0$。

按照编号从小到大输出。如果没有这样的神经元，输出 `NULL`。

### 2.6 算法正确性证明

> **定理**：按拓扑序递推，非输入层节点初始化为 $-U_i$，兴奋节点传播信号，最终得到的 $C_i$ 就是题目要求的神经网络输出层状态。
>
> *证明*：对拓扑序归纳。
>
> - **基础情况**：输入层节点（拓扑序最前）。它们的 $C_i$ 由输入直接给定（$C_i \neq 0$），不设为 $-U_i$。这些节点如果 $C_i > 0$，就会向下一层传播，这符合题意。
>
> - **归纳步骤**：设拓扑序中前 $k-1$ 个节点的 $C$ 值均已正确计算。对于第 $k$ 个节点 $v$，其所有前驱均在前 $k-1$ 个中，因此 $C_v$ 已累加了所有来自前驱的加权信号，加上初始 $-U_v$（若非输入层），得到 $C_v = (\sum W_{jv}C_j) - U_v$，与公式一致。若 $C_v > 0$，则继续向下一层传播，符合题意。
>
> 由归纳法，所有节点的 $C$ 值均正确。$\square$

## 三、模式总结

| 关键点 | 说明 |
|--------|------|
| **DAG 递推** | 题目隐含分层结构和无环性质，天然适合拓扑排序 |
| **阈值预处理** | 非输入层节点初始化 $C_i = -U_i$，避免计算过程中额外处理阈值 |
| **兴奋传播** | 仅当 $C_i > 0$ 时才传递信号，信号强度为 $C_i$ |
| **输出层判定** | 出度为 $0$ 的节点属于输出层 |
| **负权边** | $W_{ji}$ 可能为负，因此累加时可能减少 $C_i$，这也是正常情况 |

**本题本质**：DAG 上的递推 / DP，转移方程 $C_v = C_v + W_{uv} \cdot C_u$（初值 $-U_v$），拓扑序保证无后效性。

## 四、解决方案

### 4.1 算法流程

1. **读入** $n, p$。
2. **初始化**：读入 $C_i$ 和 $U_i$。若 $C_i = 0$（非输入层），则置 $C_i = -U_i$。
3. **建图**：读入 $p$ 条有向边 $(u, v, w)$，存入邻接表，同时统计入度 $\text{indeg}[v]$ 和出度 $\text{outdeg}[u]$。
4. **拓扑排序**（Kahn 算法）：
   - 将所有入度为 $0$ 的节点入队；
   - 依次取出队首节点 $u$：
     - 若 $C_u > 0$，遍历 $u$ 的所有出边 $(u, v, w)$，令 $C_v \gets C_v + w \cdot C_u$；
     - 将 $v$ 的入度减 $1$，若入度变为 $0$，将 $v$ 入队。
5. **输出**：遍历所有节点，若 $\text{outdeg}[i] = 0$ 且 $C_i > 0$，输出 $i+1$ 和 $C_i$。若没有满足条件的节点，输出 `NULL`。

### 4.2 复杂度分析

- **时间复杂度**：$O(n + p)$，拓扑排序遍历所有节点和边一次。
- **空间复杂度**：$O(n + p)$，存储邻接表。

### 4.3 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 神经元总数 |
| $p$ | 有向边总数 |
| $C_i$ | 神经元 $i$ 的当前/最终状态 |
| $U_i$ | 神经元 $i$ 的阈值 |
| $W_{ji}$ | 边 $j\to i$ 的权值 |
| $\text{indeg}[i]$ | 节点 $i$ 的入度 |
| $\text{outdeg}[i]$ | 节点 $i$ 的出度 |

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};
constexpr int mxm{mxn*mxn};

struct{int v,w,nx;}E[mxm];
int H[mxn],cnt;
int n,p,c[mxn],u[mxn],indeg[mxn],outdeg[mxn];
int q[mxn],ql,qr;

void add(int a,int b,int w)
{
	E[cnt]={b,w,H[a]};
	H[a]=cnt++;
}

main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>p;
	for(int i=0;i<n;++i)
	{
		cin>>c[i]>>u[i];
		if(c[i]==0)
			c[i]=-u[i];
	}
	fill_n(H,n,-1);
	for(int i=0,a,b,w;i<p;++i)
	{
		cin>>a>>b>>w;--a;--b;
		add(a,b,w);
		++indeg[b];
		++outdeg[a];
	}

	for(int i=0;i<n;++i)
		if(indeg[i]==0)
			q[qr++]=i;

	while(ql<qr)
	{
		int u=q[ql++];
		if(c[u]>0)
		{
			for(int i=H[u];~i;i=E[i].nx)
			{
				int v=E[i].v,w=E[i].w;
				c[v]+=w*c[u];
			}
		}
		for(int i=H[u];~i;i=E[i].nx)
		{
			int v=E[i].v;
			if(--indeg[v]==0)
				q[qr++]=v;
		}
	}

	int flag=0;
	for(int i=0;i<n;++i)
		if(outdeg[i]==0&&c[i]>0)
		{
			cout<<i+1<<' '<<c[i]<<'\n';
			flag=1;
		}
	if(!flag)
		cout<<"NULL\n";

	return 0;
}
```

### 代码要点说明

- **邻接表**：链式前向星，`H[u]` 为头指针，`E[i]` 存储边 `{v, w, nx}`。
- **拓扑排序**：手写队列 `q[]`，下标 `ql`、`qr`。
- **阈值处理**：非输入层节点 `c[i] == 0` 时置为 `-u[i]`，此后递推自然完成 $(\sum W\cdot C) - U$ 的计算。
- **输出**：出度 $0$ 且 $c[i] > 0$ 的节点即为输出层兴奋神经元，编号转回 1-based 输出。
