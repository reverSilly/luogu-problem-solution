# P1079 [NOIP 2012 提高组] Vigenère 密码 题解

---

## 1. 重新审题

我们拿到一道加密解密模拟题。题目给出了 **Vigenère 密码** 的解密任务：

- **输入：** 密钥 $k$（长度 $\le 100$，仅大小写字母）和 **密文** $C$（长度 $\le 1000$，仅大小写字母）。
- **输出：** 对应的 **明文** $M$。
- **加密规则：**
  - 对于第 $i$ 位，$c_i = m_i \circledR k_i$。
  - $\circledR$ 运算 **忽略参与运算的字母的大小写**（即只关心字母的序号），但 **输出字母保持明文 $M$ 中的大小写形式**。
  - 当 $M$ 的长度超过 $k$ 时，将密钥 $k$ **重复使用**。

但题目给的是 **密文 $C$ 和密钥 $k$**，要求 **逆向求出明文 $M$**。也就是说我们不需要实现加密，而是实现 **解密**。

**样例验证：**

```
密钥 k = abc
明文 M = Helloworld
密文 C = Hfnlpyosnd
```

我们用加密验证一下关系：把字母映射到 $0..25$，$A/a=0,B/b=1,\dots,Z/z=25$。

| 位置 | 明文 M | m\_val | 密钥 k | k\_val | 加密 (m+k)%26 | 密文 C |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 0 | H(大写) | 7 | a | 0 | 7 | H(大写) |
| 1 | e(小写) | 4 | b | 1 | 5 | f(小写) |
| 2 | l | 11 | c | 2 | 13 | n |
| 3 | l | 11 | a | 0 | 11 | l |
| 4 | o | 14 | b | 1 | 15 | p |
| 5 | w | 22 | c | 2 | 24 | y |
| 6 | o | 14 | a | 0 | 14 | o |
| 7 | r | 17 | b | 1 | 18 | s |
| 8 | l | 11 | c | 2 | 13 | n |
| 9 | d | 3 | a | 0 | 3 | d |

与题目样例完全吻合。所以加密公式就是：

$$c_i = (m_i + k_i) \bmod 26$$

相应地，**解密公式** 为：

$$m_i = (c_i - k_i + 26) \bmod 26$$

其中 $+26$ 保证结果非负。

**大小写处理：** 加密时 $\circledR$ 忽略大小写（统一转大写计算），但密文 $C$ 保留了明文 $M$ 的大小写。因此解密时，我们可以直接保留密文 $C$ 字符的大小写形式作为明文字母的大小写。

---

## 2. 思维链与完整证明

### 2.1 加密映射的代数描述

记字母到整数的映射为 $\sigma: \{\mathrm{A..Z},\mathrm{a..z}\} \to \{0,1,\dots,25\}$，规则为：
- $\sigma(\mathrm{A})=\sigma(\mathrm{a})=0,\ \sigma(\mathrm{B})=\sigma(\mathrm{b})=1,\ \dots,\ \sigma(\mathrm{Z})=\sigma(\mathrm{z})=25$。

设 $u_i = \sigma(m_i),\; v_i = \sigma(k_i),\; w_i = \sigma(c_i)$。

题目所述的 $\circledR$ 运算等价于：

$$w_i = (u_i + v_i) \bmod 26$$

这是因为查 Vigenère 方阵：行索引为明文、列索引为密钥，交点正好是 $(行+列)\bmod 26$ 对应的字母。

### 2.2 解密推导

给定 $w_i$ 和 $v_i$，我们要求 $u_i$。由上式：

$$w_i \equiv u_i + v_i \pmod{26}$$

两边同时减去 $v_i$：

$$u_i \equiv w_i - v_i \pmod{26}$$

取模 26 下最小非负剩余：

$$u_i = (w_i - v_i + 26) \bmod 26$$

这就是解密公式。$+26$ 防止 C++ 的 `%` 对负数产生负结果。

### 2.3 大小写保持的证明

加密规则说：**输出字母保持明文 $M$ 中的大小写形式**。也就是说，若 $m_i$ 是大写，则 $c_i$ 也是大写；若 $m_i$ 是小写，则 $c_i$ 也是小写。

解密时，我们已知 $c_i$ 的大小写，而 $m_i$ 的大小写与之 **完全相同**（因为加密时大小写被原样保留到了 $c_i$）。所以解密时只需保留 $c_i$ 的大小写作为 $m_i$ 的大小写即可。

**证毕。**

### 2.4 密钥重复使用

当 $i \ge |k|$ 时，密钥索引取 $i \bmod |k|$。即：

$$v_i = \sigma(k_{i \bmod |k|})$$

### 2.5 算法步骤

1. 读入密钥 $k$ 和密文 $C$。
2. 将密钥 $k$ 全部转为大写（或全部转小写，因为运算忽略大小写），便于统一计算。
3. 遍历密文 $C$ 的每个字符 $c_i$：
   - 记录其大小写：`isupper(c_i)`。
   - 将 $c_i$ 转大写得到其数值 $w_i$。
   - 取 $v_i = \sigma(k_{i \bmod |k|})$（密钥统一大写，直接取数值）。
   - 计算 $u_i = (w_i - v_i + 26) \bmod 26$。
   - 将 $u_i$ 转回字母：按原 $c_i$ 的大小写，输出大写或小写字母。
4. 输出结果。

## 4. 正解实现（含符号表）

### 符号表

| 符号 | 含义 |
|:--|:--|
| $k$ | 密钥字符串 |
| $C$ | 密文字符串 |
| $M$ | 明文字符串（输出） |
| $\|\cdot\|$ | 字符串长度 |
| $\sigma(ch)$ | 将字母 $ch$ 映射到 $0..25$ |
| $\Sigma(ch)$ | 将数值 $0..25$ 映射到大写字母 |
| $u_i$ | 明文第 $i$ 位的数值 |
| $v_i$ | 密钥第 $i$ 位的数值 |
| $w_i$ | 密文第 $i$ 位的数值 |

### 代码实现（C++）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105}; // 密钥长度上限+5

char key[mxn];
string C;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin >> key >> C;
	int nk = (int)strlen(key);
	// 密钥统一转大写，后续计算直接取值
	for (int i{0}; i < nk; ++i)
		if (key[i] >= 'a')
			key[i] -= 32;

	for (int i{0}; i < (int)C.size(); ++i)
	{
		// 记录密文当前字符的大小写
		int up = (C[i] < 'a');
		// 统一转大写计算数值
		int w = toupper(C[i]) - 'A';
		// 密钥数值（已全大写）
		int v = key[i % nk] - 'A';
		// 解密公式
		int u = (w - v + 26) % 26;
		// 按原大小写输出
		if (up)
			cout << char(u + 'A');
		else
			cout << char(u + 'a');
	}
	cout << '\n';
}
```

## 5. 示例代码说明

> 以下是对代码中各部分与解题思路对应关系的说明，方便你在阅读或调试时快速定位。

### 5.1 头文件与全局配置

- `#include<bits/stdc++.h>`：包含了 C++ 标准库中的所有头文件，适合竞赛场景。
- `using namespace std;`：全局引入命名空间。
- `constexpr int mxn{105};`：密钥最大长度 100 + 5 的裕量，符合编码风格。
- 全局数组 `char key[mxn]` 和 `string C` 分别存储密钥和密文。

### 5.2 输入加速

```cpp
cin.tie(nullptr);
cout.tie(nullptr);
ios::sync_with_stdio(false);
```

三行顺序固定，解除 C++ 流与 C stdio 的绑定，提高 `cin`/`cout` 速度。

### 5.3 密钥预处理

```cpp
cin >> key >> C;
int nk = (int)strlen(key);
for (int i{0}; i < nk; ++i)
	if (key[i] >= 'a')
		key[i] -= 32;
```

读入密钥后，将所有小写字母转为大写。直接对 `char` 做 `ch -= 32`（因为 ASCII 中小写比对应大写大 32）。这样后续计算 `key[i] - 'A'` 时无需再判断大小写。

### 5.4 逐位解密

```cpp
for (int i{0}; i < (int)C.size(); ++i)
{
	int up = (C[i] < 'a');             // 1. 保留大小写标记
	int w  = toupper(C[i]) - 'A';      // 2. 密文字母转数值
	int v  = key[i % nk] - 'A';        // 3. 密钥（循环）转数值
	int u  = (w - v + 26) % 26;        // 4. 解密：u = (w - v) mod 26
	if (up)
		cout << char(u + 'A');
	else
		cout << char(u + 'a');
}
cout << '\n';
```

**关键点：**

- `C[i] < 'a'`：大写字母 ASCII < 'a'，小写字母 >= 'a'。因为密文仅含字母，所以这个判断等价于 `isupper(C[i])`。
- `toupper(C[i])`：不论原本大小写，统一转大写再减 `'A'`，得到 $0..25$。
- `i % nk`：密钥循环使用。
- `(w - v + 26) % 26`：解密公式。`+26` 后取模保证结果落在 $[0,25]$。
- 最后根据 `up` 决定输出大写还是小写字母。
- 末尾输出 `'\n'` 而非 `endl`，避免不必要的缓冲区刷新。

## 总结

本题是 NOIP 2012 提高组的第一题，属于 **古典密码模拟**。核心在于：

1. 理解 Vigenère 加密的代数本质：$c = (m+k)\bmod 26$。
2. 推导出解密公式：$m = (c - k + 26)\bmod 26$。
3. 正确处理大小写保留逻辑：解密结果的**大小写与密文一致**。
4. 密钥循环复用：下标取模。

该题不涉及复杂算法或数据结构，但需要对字符与数值的转换非常熟练，适合作为字符串模拟的入门练习。
