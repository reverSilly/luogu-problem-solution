# P1373 小 a 和 uim 之大逃离 —— 完整题解

> 标签：动态规划 DP / 递推 · 难度：提高/省选- · 答案对 $10^9+7$ 取余

## 1. 重新读题

**一句话版**：在 $n\times m$ 的矩阵里走**只能向右或向下**的单调路径；路径上第 $1,3,5,\dots$ 格的魔液被小 a 吸收，第 $2,4,6,\dots$ 格被 uim 吸收，**最后一步必须轮到 uim**（即路径的格子数必须是偶数）。魔瓶按容量把累计吸收量**回绕成余数**。问有多少条路径能让两人瓶内余数**相等**（一起活下来）。

**约束与暗示**

| 量 | 范围 | 暗示 |
|---|---|---|
| $n,m$ | $1\le n,m\le 800$ | 网格型 DP，行优先递推 |
| $k$ | $1\le k\le 15$ | 必须挂一维"余数"，$O(nmk)$ 正好 |
| 格值 | $0\sim k$ | 可能出现 $x=k$，与 $0$ 同余 → 读入就要取余 |
| 子任务 | $n,m\le10,k\le2$；$n,m\le100,k\le5$ | 余数维从小到大，正是 $O(nmk)$ 的阶梯 |
| 模数 | $10^9+7$ | 计数题，加法链全程取模 |

**口径**：本题求的是**方案数取模**，不是期望、不是概率，因此不涉及"期望满足线性方程组 + 高斯消元"那一套；本文的证明负担全在**取余语义**与**状态刻画的双射（不重不漏）**上。

**样例声明**：本地题面文件只给了"样例解释：四种方案是 $(1,1)\to(1,2)$、$(1,1)\to(2,1)$、$(1,2)\to(2,2)$、$(2,1)\to(2,2)$"，**没有附样例输入矩阵与输出数字**，所以无法与官方样例数值对标。不过这段解释本身给出两个硬信息：①方案按**格子序列**区分（不同的走法算不同方案）；②$2\times2$ 网格里只列 $4$ 条、全是 $2$ 格路径，没列 $(1,1)\to(1,2)\to(2,2)$ 这类 $3$ 格路径，正好印证"最后一步归 uim"⟺**格子数为偶数**。§4.3 算例 2 用 $k=2$、四格全 $1$ 补出一份自洽数据，手算递推得到的就是解释里那 $4$ 条。

## 2. 思维链——带完整证明

### 2.1 探索特殊机制 —— 魔瓶是取余器，路径奇偶决定归属

题面"魔瓶只有 $k$ 的容量，装了 $k+1$ 清空成零、装了 $k+2$ 只剩 $1$"要表达的是**超出容量就回绕**。这里有一个必须点明的读法分歧：

- **主流口径（本文采用）**：把回绕读成"瓶里存的量对容量取模"，即 $\bmod k$，余数落在 $[0,k-1]$；这样"魔液量 $0\sim k$"里的 $k$ 恰好与 $0$ 同档，是本题数据设计的自然配套（题面标签 $k\le15$ 也刚好对应余数维开 $k$ 档）。
- **字面口径**：容量 $k$ 意味着能装 $0\sim k$ 共 $k+1$ 个状态，到 $k+1$ 回零、到 $k+2$ 剩 $1$，这是**对 $k+1$ 取模**。

两者只是模数不同，下文所有推导都写成"$\bmod M$"（代码取 $M=k$；切换成字面口径只需把代码里的 $k$ 换成 $k+1$，`mxk` 仍够）。样例解释里那份 $2\times2$ 数据（四格等量、$k=2$）在两种口径下都给出 $4$，**无法用来区分**；能区分两者的最小算例是 $1\times2$、$k=2$、$\begin{smallmatrix}2&0\end{smallmatrix}$：$D=2$，$\bmod 2$ 判为平局（答案 $1$），$\bmod 3$ 判为不平（答案 $0$）。由于本环境禁止运行代码、题面又没有可用样例数值，**这一点无法就地验证**，本文按主流口径实现并把分歧如实标为**读法风险**，不作为结论。

**引理 1（瓶内余量 = 累计吸收量 $\bmod M$）** 设每次吸收的量为 $v_1,\dots,v_t$（$0\le v_i\le M$），累计 $T_s=\sum_{i\le s}v_i$，瓶内余量 $c_s$。则 $c_s\equiv T_s\pmod M$ 且 $c_s\in[0,M-1]$，即 $c_s=T_s\bmod M$。

**证明**：对 $s$ 归纳。$s=0$：空瓶 $c_0=0=T_0\bmod M$。设 $s-1$ 时成立，即 $c_{s-1}\equiv T_{s-1}$、$0\le c_{s-1}\le M-1$。第 $s$ 步往瓶里加 $v_s$，临时量 $c_{s-1}+v_s\le(M-1)+M=2M-1<2M$，所以**回绕规则至多触发一次**，触发后减去一整个周期 $M$，故新余数 $c_s$ 满足 $c_s\equiv c_{s-1}+v_s\equiv T_{s-1}+v_s=T_s\pmod M$，且仍在 $[0,M-1]$（"装了 $k+1$ 变 $0$、装了 $k+2$ 变 $1$"就是这个减一整个周期的口语说法）。$\blacksquare$

**引理 2（奇偶 ⟺ 归属）** 路径 $P=(c_1,\dots,c_L)$（$c_t$ 为第 $t$ 个格子）。"开始时小 a 吸收，下一步 uim，如此交替"给出：第 $t$ 格归小 a $\iff$ $t$ 为奇（对 $t$ 归纳：$t=1$ 归 a；$t$ 与 $t+1$ 归属相反）。要求"最后一步必须由 uim 吸收" $\iff$ 第 $L$ 格归 uim $\iff$ $L$ 为**偶数**。特别地 $L=1$（原地不动）不合法。$\blacksquare$

记 $A(P)=\sum_{t\ \mathrm{odd}}a_{c_t}$，$U(P)=\sum_{t\ \mathrm{even}}a_{c_t}$，**差** $D(P)=A(P)-U(P)$。

**引理 3（活命条件 = 差落在 $0$ 号同余类）** $c_a=c_u\iff D(P)\equiv0\pmod M$。
**证明**：$\Rightarrow$：两数相等当然同余。$\Leftarrow$：由引理 1，$c_a=A\bmod M$、$c_u=U\bmod M$；若 $A\equiv U\pmod M$，而 $[0,M-1]$ 中每个同余类**至多一个代表**（若 $u\ne v$ 且都在 $[0,M-1]$，则 $0<|u-v|<M$，$M\nmid(u-v)$），故 $c_a=c_u$。$\blacksquare$

于是原题被等价改写成：**数单调路径 $P$，满足格子数 $L$ 为偶数且 $D(P)\equiv0\pmod M$**。机制已被拆干净——剩下的只有"奇偶"和"差模 $M$"两维信息。

### 2.2 特例试探 —— 把余数机制彻底拆掉（$M=1$，即 $k=1$）

$k=1$ 时任何余数都是 $0$，引理 3 恒成立，问题退化为"数格子数为偶数的单调路径"。手玩 $2\times2$：偶数格路径只有 $2$ 格的那些（$4$ 格路径需要 $3$ 步，$2\times2$ 最多 $2$ 步），共 $4$ 条 → 答案 $4$。这一步确认了两件事：①**答案只从"偶数格"状态取**，所以奇偶这一维必须在状态里，不能靠最后乘个符号糊弄过去；②$3$ 格路径（如 $(1,1)\to(1,2)\to(2,2)$）虽然差 $D=1-1+1=1$，但**奇偶就判死了**，与 $M$ 取值无关。

再加回余数维：$1\times4$、全 $1$、$M=2$。偶数格路径 = $3$ 条 $2$ 格 + $1$ 条 $4$ 格，$2$ 格的 $D=0$ ✓，$4$ 格的 $D=1-1+1-1=0$ ✓ → 答案 $4$（§4.3 算例 3 用它核对"回绕"）。

**写 DP 之前，先把三个"看起来很对"的口径逐个否掉**——它们就是本题真正的失分点：

1. **"两个人的余数都必须是 $0$"**：错。引理 3 要的是**相等**，$c_a=c_u=2$ 同样是平局。判别算例：$2\times3$、$k=3$、全 $1$（§4.3 算例 4）。正确口径下 $7$ 条 $2$ 格（两瓶都是 $1$）与 $3$ 条 $4$ 格（两瓶都是 $2$）全合法 → $10$；若要求都为 $0$，答案变 $0$。手玩一遍就能自证。
2. **用 $|A-U|=0$ 当条件**：$|A-U|$ **不是可加量**——接一格后它可能变大也可能变小，取决于当前谁占优，于是 DP 还得把"谁占优"塞进状态，维度直接翻倍。而 $D=A-U\pmod M$ 是带符号的纯平移量（引理 5），一次加/减 $x$ 就够，这才是能挂进余数维的形式。
3. **"奇偶无所谓，反正两人交替对称"**：错两处。① 起点固定归小 a（题面"开始时小 a 用魔瓶吸收"），所以符号由**离起点的序号奇偶**决定，不是可以任意分配的；② 收尾必须是 uim，故只统计偶数格路径。判别算例：$1\times3$、$k=1$（所有余数都是 $0$，第 1、2 条口径失效，只剩奇偶在筛）。偶数格路径 = $2$ 条 $2$ 格；若不筛奇偶还会多算 $(1,1)\to(1,2)\to(1,3)$ 这条 $3$ 格路径 → 正确 $2$、错误 $3$。

### 2.3 归约到经典模型 —— DAG 上带余数维的路径计数

**先解决"状态里到底放什么"。** 最自然的想法是把两个瓶子的余数都记住：$(c_a,c_u)\in[0,M-1]^2$，共 $M^2$ 档。但 $800^2\cdot15^2\cdot2=2.88\times10^9$ 次操作必然超时，所以必须先证明"只记差"不是拍脑袋。

**引理 3.5（"只记差"是合法的状态商）** 令 $\delta(P)=D(P)\bmod M$。则
(i) 延伸一格后 $\delta$ 的新值只由 $(\delta(P),\,|P|\bmod 2,\,x)$ 决定；
(ii) 活命条件恰是 $\delta=0$；
(iii) 把"以 $(i,j)$ 结尾的路径"按 $(\,|P|\bmod 2,\ \delta(P)\,)$ 分类后，同类中的任何两条路径对**任何**相同的后续走法都保持同类，且成败判定相同。

**证明**：(i) 的完整推导见引理 5（本节先把它当"延伸一格只会把 $\delta$ 平移 $\pm x$"使用，引理 6 再把整套论证闭合）；右端不含 $c_a,c_u$ 的任何其它信息。(ii) 是引理 3 的改写。(iii) 对后续步数归纳：设 $P_1,P_2$ 同类（$|P_1|\equiv|P_2|\pmod 2$ 且 $\delta$ 相等），接同一格 $x$，由 (i) 得到相同的新奇偶（奇偶同时翻转）与相同的新 $\delta$（同加同减同一个 $x$），迭代任意步仍同类；再由 (ii) 判成败，两者同步。$\blacksquare$

(iii) 的严格含义就是"合并计数不丢信息"：把同类的一整批路径条数加在同一个格子里，后续每一步都把这一整批**一起**搬到同一个目标格子，等价于逐条搬完再求和。所以余数维只需 $M$ 档，$M^2$ 档是纯冗余。**长度为什么也能扔**：$|P|$ 在 (i) 里只以 $|P|\bmod2$ 的身份出现，没有任何转移或判定用到具体长度，故按奇偶商掉同样合法（反过来说，奇偶这一维**不能**扔——它决定新格加到谁头上，也是答案只取 $f_1$ 的理由）。

网格 + 只向右向下 = 有向无环图（DAG），"数路径 + 带一个沿路累加的量"就是最经典的**路径计数 DP 挂一维余数**。据此定义状态：

$$f_0[i][j][r]=\#\{\text{以 }(i,j)\text{ 结尾、格子数为奇数、}D\equiv r\pmod M\ \text{的单调路径}\},$$
$$f_1[i][j][r]=\#\{\text{同上但格子数为偶数}\},\qquad r\in[0,M-1].$$

下标 $0$ 读作"该小 a 收尾"，$1$ 读作"该 uim 收尾"。转移（$x=a_{i,j}$，前驱 $(i',j')\in\{(i,j-1),(i-1,j)\}$）：

$$f_0[i][j][x]\mathrel{+}=1,\qquad f_1[i][j][(r-x)\bmod M]\mathrel{+}=f_0[i'][j'][r],\qquad f_0[i][j][(r+x)\bmod M]\mathrel{+}=f_1[i'][j'][r].$$

**引理 4（状态划分：不重不漏）** 记 $\mathcal P(i,j)$ 为所有以 $(i,j)$ 结尾的单调路径集合，则
$$\mathcal P(i,j)=\{\text{单格路径 }(i,j)\}\ \dot\cup\ \{P\cdot(i,j):P\in\mathcal P(i,j-1)\}\ \dot\cup\ \{P\cdot(i,j):P\in\mathcal P(i-1,j)\},$$
其中 $j>0$ 时第二项才存在、$i>0$ 时第三项才存在，$\dot\cup$ 表示不交并，$P\cdot(i,j)$ 表示在 $P$ 末尾接上 $(i,j)$。

**证明**：
- **不漏**：任取 $P\in\mathcal P(i,j)$，若 $|P|=1$ 落在第一项；否则删去末格得到 $P'$，其终点是 $(i,j)$ 的上一个格子。因每步只向右或向下，这个上一步必是 $(i,j-1)$（末步向右）或 $(i-1,j)$（末步向下），且 $P'$ 仍单调，故 $P=P'\cdot(i,j)$ 落在第二或第三项。
- **不重**：三项的元素按"$|P|=1$"与"末步方向"这两个互相独立的判别法分开：单格路径没有末步；末步向右的路径 $\ne$ 末步向下的路径（末步不同）。另外第二项内部不会重复：映射 $P\mapsto P\cdot(i,j)$ 若 $P_1\cdot(i,j)=P_2\cdot(i,j)$，删末格即得 $P_1=P_2$，故它是**单射**；同理第三项内部单射。而 $P_1\cdot(i,j)$ 的终点前驱是 $(i,j-1)$、$P_2\cdot(i,j)$ 的是 $(i-1,j)$，两前驱不同故像集不交。
- 结合两点即得不交并分解，并且每项与对应前驱的路径集**双射**（逆映射就是"删末格"，单调性保证删完仍合法，接上 $(i,j)$ 又一定合法——$(i,j-1)\to(i,j)$、$(i-1,j)\to(i,j)$ 都是允许的一步）。$\blacksquare$

**引理 5（符号规则：接一格是加还是减）** 设 $P$ 的差为 $D(P)$、格子数为 $L$。则 $D(P\cdot(i,j))=D(P)+x$ 若 $L$ 为偶（新长度奇），$D(P\cdot(i,j))=D(P)-x$ 若 $L$ 为奇（新长度偶）。

**证明**：归属只由**从起点数过来的序号**决定（引理 2），在 $P$ 前面接不了东西、删末格也不改变前面各格的序号，故 $P$ 的奇偶号位置在新路径里完全一致，唯一的差别是新增的第 $L+1$ 格。$L$ 偶 $\Rightarrow$ $L+1$ 奇 $\Rightarrow$ 新格归小 a $\Rightarrow$ $A$ 增 $x$ $\Rightarrow$ $D$ 增 $x$；$L$ 奇 $\Rightarrow$ $L+1$ 偶 $\Rightarrow$ 新格归 uim $\Rightarrow$ $U$ 增 $x$ $\Rightarrow$ $D$ 减 $x$。$\blacksquare$

注意这条引理是本题最容易写反的地方：如果状态按"离终点还有多远"编号，符号就会整套反过来；我们按**离起点多远**编号，所以"奇数格 $\to$ 偶数格"这一步是**减**，"偶数格 $\to$ 奇数格"是**加**。

**引理 6（DP 正确性，对行优先序归纳）** 按 $(i,j)$ 行优先处理，则处理完 $(i,j)$ 后 $f_0[i][j][\cdot],f_1[i][j][\cdot]$ 恰为定义中的计数。

**证明**：行优先序 $(i,j)\prec(i',j')\iff i<i'$ 或（$i=i'$ 且 $j<j'$）是网格 DAG 的**拓扑序**：$(i-1,j)\prec(i,j)$、$(i,j-1)\prec(i,j)$，故两个前驱都已算完（这一步同时说明归纳假设可用）。对 $r$ 归纳于路径长度太粗，这里直接按引理 4 的不交并分解来算：以 $(i,j)$ 结尾、奇数格、$D\equiv r$ 的路径分成三类——单格路径（仅当 $r\equiv x$ 时存在，恰 $1$ 条，对应 $f_0[i][j][x]\mathrel{+}=1$）；由 $(i,j-1)$ 延伸来的；由 $(i-1,j)$ 延伸来的。后两类由引理 5 给出"奇前驱减 $x$ 变偶、偶前驱加 $x$ 变奇"的余数搬迁，且 $(r-x)\bmod M$、$(r+x)\bmod M$ 都是 $[0,M-1]$ 内的唯一代表（引理 1 末尾的唯一性），所以每类路径被计入**恰好一次**、不会串到别的 $r$ 档。三类相加即得定义值。$\blacksquare$

### 2.4 空间与顺序优化 —— 滚动两行 + 边算边结算

**引理 7（只需两行）** 计算第 $i$ 行只用第 $i$ 行自己（列方向）和第 $i-1$ 行的 $f$ 值，故用 $i\bmod 2$ 作行缓冲即可；且当第 $j$ 列的两个前驱转移都做完后，$f[i][j][\cdot][\cdot]$ 就是终值。

**证明**：写入口只有引理 4 的三类；读 $(i,j)$ 的只有 $(i,j+1)$（同一行，稍后）与 $(i+1,j)$（下一行，另一块缓冲）。因此第 $i$ 行结束时第 $i-2$ 行再也不会被读，两行滚动安全。第二个结论：任何写入 $(i,j)$ 的来源都在处理 $(i,j)$ 的那一轮循环里完成，之后没有代码再碰 $(i,j)$，故可当场把 $f_1[i][j][0]$ 累进答案。$\blacksquare$

**若不滚动的代价**：$2\cdot n\cdot m\cdot M$ 个 `int` $=2\cdot800\cdot800\cdot15\cdot4\,\mathrm{B}\approx76.8\,\mathrm{MB}$（按余数维开 $16$ 档则 $\approx82\,\mathrm{MB}$），是最常见的 MLE 坑；滚动后 $2\cdot2\cdot805\cdot20\cdot4\,\mathrm{B}\approx258\,\mathrm{KB}$。

### 2.5 答案聚合与取模/溢出预算

**引理 8（答案不重不漏）** 所求 $=\sum_{i,j}f_1[i][j][0]$。
**证明**：每条合法路径有**唯一**终点，故 $P\mapsto(\mathrm{end}(P),P)$ 是"合法路径集"到 $\bigsqcup_{i,j}\{$以 $(i,j)$ 结尾、偶数格、$D\equiv0$ 的路径$\}$ 的双射（引理 4 保证不交并，引理 2、3 保证条件就是活命条件）。求和即计数。$\blacksquare$

**复杂度**：时间 $O(nmM)$，常数是 $2$ 个前驱 $\times$ $2$ 个奇偶 $\times$ $M$ 档余数 $=4M$，$800^2\cdot60=3.84\times10^7$ 次模加，另加每行 $O(mM)$ 的清零；空间 $O(mM)$。

**溢出账**：`int` 下 $p=10^9+7$，一次加法两个加数都 $<p$，和 $<2p=2\,000\,000\,014<2^{31}-1=2\,147\,483\,647$，**不溢出**，故 `x+=v; if(x>=p)x-=p;` 一次比较即完成归约，不需要 `long long` 也不需要 `%`。代价是必须**每加一项就归约**：若把 $4$ 个前驱先加起来再取模，$4p>2^{31}$ 立刻翻负。

**取余的三个坑**：①负数：$r-x\in[-(M-1),M-1]$，一律 $(r-x+M)\bmod M$；②格值可能等于 $k$，$x\%=M$ 后变 $0$，否则余数维下标越界；③$M=1$（$k=1$）时所有 $\bmod$ 结果恒为 $0$，循环 $r<1$ 只跑一档，逻辑退化但不除零。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — "容量 + 回绕"= 取余器（引理 1），胜负条件压成"差 $\equiv0$"（引理 3）；同时把 $k$ 与 $k+1$ 两种模数读法标注清楚，并给出能区分两者的最小算例。
- **consider easier version** — 令 $M=1$ 剥掉余数，只剩"偶数格路径计数"，逼出"奇偶维必须在状态里"和"$L=1$/$L=3$ 都非法"。
- **reject wrong readings** — 三条错误口径（都为 $0$、用 $|A-U|$、忽略奇偶）各配一个可手玩的判别算例，先把失分点堵掉。
- **classic problem solution** — 单调网格 = DAG，路径计数 DP 挂一维余数（"路径数 + 沿路累加量"的标准配方）。
- **reduce to easier problem** — 引理 3.5 证明"记两个瓶 $\to$ 只记差"是合法状态商（$M^2\to M$，顺带扔掉长度），引理 4 用"删末格"把 $\mathcal P(i,j)$ 证成三分不交并。
- **sign discipline** — 引理 5：归属按**离起点的序号**定，故"奇 $\to$ 偶"是减 $x$、"偶 $\to$ 奇"是加 $x$，写反即全错。
- **topological order + rolling array** — 引理 6、7：行优先是拓扑序，只依赖上一行与左邻，$O(nmM)\to O(mM)$，并支持"处理完一格就地结算"。
- **aggregate with a bijection** — 引理 8：$\sum_{i,j}f_1[i][j][0]$ 计数不重不漏，靠的是"每条路径有唯一终点"。
- **modular bookkeeping** — 加一项就归约一次（$2p<2^{31}$，不用 `long long`），负余数先加 $M$，格值先 $\%M$。

## 4. 真实解法

### 4.1 符号表

| 符号 | 存什么 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n,m,k` | 行列与模数 $M=k$ | `int`，输入 | $n,m\le800$，$k\le15$ |
| `a[j]` | **当前行**各格的魔液，已 `%k` | `int a[mxm]`，逐行覆写 | 只用到本行，不必存整张图 |
| `f[2][2][mxm][mxk]` | `f[i&1][t][j][r]` $=f_t[i][j][r]$：以本行第 $j$ 列结尾、**格数奇偶** $t$（$0$=奇/小 a 收尾，$1$=偶/uim 收尾）、差 $\equiv r$ 的路径数 | 全局，每行开头把 $r<k$ 的清 $0$ | 两行滚动；$t$ = **最后一个格子归谁**（$0$=小 a、$1$=uim），亦即"下一步轮到谁"的反面 |
| `u,v` | 当前行缓冲 $=i\&1$、上一行缓冲 $=u\^1$ | 每行重算 | `u` 写、`v` 读 |
| `ans` | $\sum_{i,j}f_1[i][j][0]$ | 全局 `int`，默认 $0$ | 处理完一格就地累加 |
| `p` | $10^9+7$ | `constexpr` | 加一项归约一次 |
| `inc(x,v)` | `x+=v; if(x>=p)x-=p;` | 单行小函数 | 两项都 $<p$，一次减法够 |
| `mxn/mxm/mxk` | $805/805/20$ | 上界 +5 松弛 | 余数下标最大 $k-1=14$ |

下标约定：矩阵内部 **0-based**（读入即按 $i=0..n-1,\ j=0..m-1$ 处理，题面的 $(1,1)$ 对应代码 $(0,0)$），输出只有一个数，无需还原。

### 4.2 算法步骤

1. 读 $n,m,k$。
2. 对每行 $i=0..n-1$：读入该行 $m$ 个格值并立刻 `a[j]%=k`（§2.5 的坑 ②）；取缓冲 `u=i&1,v=u^1`；把 `f[u][t][j][r]`（$t<2,r<k$）清零（全局数组默认 $0$ 只保证第一次为 $0$，滚动复用必须显式清）。
3. 对该行每列 $j$：`x=a[j]`；`inc(f[u][0][j][x],1)` 放入单格起点（引理 4 第一项）。
4. 若 $j>0$：枚举 $r$ 做左邻转移 `f[u][0][j-1][r]→f[u][1][j][(r-x+k)%k]`、`f[u][1][j-1][r]→f[u][0][j][(r+x)%k]`（引理 4、5）。
5. 若 $i>0$：对上一行缓冲 `v` 做同样两条转移（上邻）。
6. 此时 `f[u][1][j][0]` 已收敛（引理 7），`inc(ans,f[u][1][j][0])`。
7. 全部行结束后输出 `ans`（引理 8）。

**复杂度**：$O(nmk)$ 时间（$\approx3.8\times10^7$ 次模加）+ $O(mk)$ 空间。**验证**：见 4.3，纯手算，未编译未运行。

### 4.3 验证状态（手工推演，未运行任何代码）

> 本环境无编译器；按用户要求没有创建 `.cpp/.in/gen` 文件，也没有对拍与得分数据，以下全是手算。**题面文件不含样例输入/输出，无法对标官方样例**（只在算例 2 里对齐"样例解释"列出的 $4$ 条方案形状）。下面的 `f0[r]=v`、`f1[r]=v` 表示某个格子的 $f_0[\cdot][\cdot][r]=v$、$f_1[\cdot][\cdot][r]=v$，只写非零的余数档；点的坐标在"解析枚举"一句里按**题面 1-based** 叙述，在 DP 手推里按**代码 0-based** 叙述，两者只差下标，不影响条数。

- **算例 1（$1\times2$，$k=2$，$\begin{smallmatrix}1&1\end{smallmatrix}$）**：偶数格路径只有 $(1,1)\to(1,2)$，$D=1-1=0$ ✓ → 期望 $1$。DP：格 1 起 `f0[1]=1`；格 2 起 `f0[1]=1`，左邻 `f0[1]→f1[(1-1)%2=0]+=1` → `f1[0]=1`；$\text{ans}=0+1=1$。**一致**。
- **算例 2（$2\times2$，$k=2$，四格全 $1$，对齐样例解释）**：偶数格路径只能是 $2$ 格（$4$ 格需 $3$ 步，本网格最多 $2$ 步），共 $4$ 条，每条 $D=0$ → 期望 $4$，正是解释里的 $(1,1)\to(1,2)$、$(1,1)\to(2,1)$、$(1,2)\to(2,2)$、$(2,1)\to(2,2)$。DP 手推：$(0,0)$: `f0[1]=1`；$(0,1)$: `f0[1]=1, f1[0]=1`；$(1,0)$: `f0[1]=1, f1[0]=1`；$(1,1)$: 起点 `f0[1]=1`，左邻 `f0[1]→f1[0]+1`、`f1[0]→f0[1]+1`，上邻 `f0[1]→f1[0]+1`、`f1[0]→f0[1]+1` → `f1[0]=2, f0[1]=3`。$\text{ans}=0+1+1+2=4$。**与样例解释完全一致**，且 $(1,1)\to(1,2)\to(2,2)$ 这类 $3$ 格路径落在 `f0` 里、不进答案，正是"最后一步必须归 uim"的体现。
- **算例 3（$1\times4$，$k=2$，全 $1$，检查回绕与 $4$ 格路径）**：解析枚举 = $3$ 条 $2$ 格（$D=1-1=0$ ✓）+ $1$ 条 $4$ 格（$D=1-1+1-1=0$ ✓）= $4$；$2$ 条 $3$ 格路径 $D=1$（奇数格，双重排除）。DP 逐格（只有左邻一个前驱）：格 1 `f0[1]=1, f1[0]=0`；格 2 `f0[1]=1, f1[0]=1`；格 3 `f0[1]=2, f1[0]=1`；格 4 `f0[1]=2, f1[0]=2`。$\text{ans}=0+1+1+2=4$。**一致**。（注意格 3 的 `f0[1]=2` 混着"$3$ 格路径 $D=1$"与"单格起点 $D=1$"两类，长度不同但同余数同奇偶，被合并计数——这正是 DP 能压成一维的原因，见 §2.3 后的讨论。）
- **算例 4（$2\times3$，$k=3$，全 $1$，非平凡模数）**：最大步数 $(2-1)+(3-1)=3$，偶数格路径只有 $2$ 格与 $4$ 格。$2$ 格：横向邻接 $2$ 行 $\times2=4$ 条 $+$ 纵向邻接 $1$ 组 $\times3$ 列 $=3$ 条，共 $7$ 条，$D=0$ ✓；$4$ 格：需 $2R+1D$，顺序 $RRD/RDR/DRR$ $3$ 条（起点只能是 $(1,1)$，$D$ 必须从第 1 行出发），$D=1-1+1-1=0\equiv0\pmod3$ ✓ → 期望 $10$。DP：$(0,0)\,f_0[1]{=}1$；$(0,1)\,f_0[1]{=}1,f_1[0]{=}1$；$(0,2)\,f_0[1]{=}2,f_1[0]{=}1$；$(1,0)\,f_0[1]{=}1,f_1[0]{=}1$；$(1,1)\,f_0[1]{=}3,f_1[0]{=}2$；$(1,2)\,f_0[1]{=}4,f_1[0]{=}5$。$\text{ans}=0+1+1+1+2+5=10$。**一致**。
- **算例 5（$2\times2$，$k=3$，$\begin{smallmatrix}1&2\\2&2\end{smallmatrix}$，非全等值 + 存在被拒绝的路径）**：$4$ 条 $2$ 格路径中 $(1,2)\to(2,2)$、$(2,1)\to(2,2)$ 是 $2$ vs $2$ ✓，另两条 $1$ vs $2$ ✗ → 期望 $2$。DP：$(0,0)$（$x{=}1$）$f_0[1]{=}1$；$(0,1)$（$x{=}2$）$f_0[2]{=}1,f_1[2]{=}1$（$f_0[1]\to f_1[(1-2+3)\%3=2]$）；$(1,0)$ 同上 $f_0[2]{=}1,f_1[2]{=}1$；$(1,1)$（$x{=}2$）起点 $f_0[2]{=}1$，左邻 $f_0[2]{=}1\to f_1[0]{+}=1$、$f_1[2]{=}1\to f_0[1]{+}=1$，上邻 $f_0[2]{=}1\to f_1[0]{+}=1$、$f_1[2]{=}1\to f_0[1]{+}=1$，故 $f_1[0]=2,f_0[1]=2,f_0[2]=1$。$\text{ans}=0+0+0+2=2$。**一致**，并验证负余数：$(1-2)=-1$ 被 $(r-x+k)\%k$ 正确搬到 $2$ 档。
- **算例 6（边界：$x=k$ 与 $k=1$）**：①$1\times2$、$k=2$、$\begin{smallmatrix}2&0\end{smallmatrix}$：$A=2,U=0$，$D=2\equiv0\pmod2$ ✓ → 期望 $1$；DP 里 `a[0]%=2` 使 $x=0$，格 1 `f0[0]=1`，格 2 起点 `f0[0]+=1`、左邻 `f0[0]→f1[0]=1` → $\text{ans}=1$。**一致**（若不先 `%k`，`f0[2]` 直接越界，且 $x=k$ 会被当成"$k$ 号档"而永远配不上 $0$ 档，答案偏小）。②$2\times2$、$k=1$：余数只有 $0$ 一档，答案 = 偶数格路径数 $=4$；DP 逐格 `f0` $=1,1,1,3$、`f1` $=0,1,1,2$，$\text{ans}=0+1+1+2=4$，与 §2.2 的手玩一致；`%1` 下标恒 $0$，不越界、不除零。
- **算例 7（$1\times3$，$k=1$，只剩奇偶在筛，核对 §2.2 第 3 条错误口径）**：解析：偶数格路径 = $2$ 条（$(1,1)\to(1,2)$、$(1,2)\to(1,3)$）；$1$ 格路径 $3$ 条非法（收尾不是 uim）、$3$ 格路径 $1$ 条非法（同理，尽管 $D\equiv0$）→ 期望 $2$，若漏掉奇偶会得 $3$。DP（$k=1$，只有 $0$ 档）：格 1 `f0=1,f1=0`；格 2 `f0=1,f1=1`；格 3 `f0=2,f1=1`；$\text{ans}=0+1+1=2$。**一致**。
- **上界/溢出自检**：不加模时答案的上界是"全部偶数格单调路径数" $\le\sum_{i,j}(\text{到 }(i,j)\text{ 的路径数})$，而路径数 $\le2^{n+m}$ 远超 $p$，所以全程模 $p$ 是必需的；由 §2.5 的账，`inc` 每次只加两个 $<p$ 的数，`int` 绝不溢出；`ans` 自身也走 `inc`，恒 $<p$。

### 4.4 顺手可查的变体（同一套引理覆盖）

| 变体 | 结论 | 依据 |
|---|---|---|
| 问"任意格子数"的路径（不要求 uim 收尾） | 把答案改成 $\sum f_1+f_0$ 在 $r=0$ 档，其余不变 | 引理 2 只影响取哪一维 |
| 允许四方向走 | DP 立刻失效（有环、路径可无限长），需换题 | 引理 4 的前驱二分依赖单调性 |
| 换成字面口径（模 $k+1$） | 只把代码里的 `%k`/循环界 $k$ 换成 $k+1$ | 引理 1、3 对任意 $M$ 成立 |
| $k$ 更大（如 $10^5$） | $O(nmk)$ 不可行，需另找结构（本题无此档） | 余数维是复杂度全部来源 |

## 5. 示例代码（C++）

```cpp
// P1373 小a和uim之大逃离
// 状态 f[行奇偶][格数奇偶][列][差mod k]，DAG路径计数 + 两行滚动
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{805},mxm{805},mxk{20};
constexpr int p{1'000'000'007};

int n,m,k,ans,a[mxm];
int f[2][2][mxm][mxk];        //f[i&1][t][j][r]：t=0 奇数格(小a收尾)，t=1 偶数格(uim收尾)

inline void inc(int&x,int v)
{
	x+=v;
	if(x>=p)
		x-=p;               //两个加数都 <p，和 <2p <2^31，一次减法就够
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>k;
	for(int i=0;i<n;++i)
	{
		for(int j=0;j<m;++j)
		{
			cin>>a[j];
			a[j]%=k;            //格值可达 k，必须折成 0..k-1，否则下标越界
		}
		int u=i&1,v=u^1;
		for(int j=0;j<m;++j)
			for(int t=0;t<2;++t)
				for(int r=0;r<k;++r)
					f[u][t][j][r]=0;        //滚动复用，必须显式清
		for(int j=0;j<m;++j)
		{
			int x=a[j];
			inc(f[u][0][j][x],1);           //以本格为唯一起点：1 格，差为 x
			if(j)
				for(int r=0;r<k;++r)
				{
					inc(f[u][1][j][(r-x+k)%k],f[u][0][j-1][r]);    //奇->偶：本格归 uim，差减
					inc(f[u][0][j][(r+x)%k],f[u][1][j-1][r]);      //偶->奇：本格归小a，差加
				}
			if(i)
				for(int r=0;r<k;++r)
				{
					inc(f[u][1][j][(r-x+k)%k],f[v][0][j][r]);
					inc(f[u][0][j][(r+x)%k],f[v][1][j][r]);
				}
			inc(ans,f[u][1][j][0]);         //偶数格且差为 0 -> 两瓶等量
		}
	}

	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **全局静态数组**：`f` 只开 $2\times2\times805\times20$ 个 `int`（$\approx258$ KB），`mxn/mxm/mxk` 按"上界 +5"；`a` 只存当前行，整张图不落盘。
- **两行滚动**：`u=i&1` 写、`v=u^1` 读；行首显式清零是因为全局数组只默认 $0$ 一次，滚动后必须自己擦（风格规范里的"迁移坑"）。
- **列内递推**：$(i,j)$ 只读 `f[u][*][j-1][*]` 与 `f[v][*][j][*]`，从不读 `f[u][*][j][*]`，因此同一轮里读写不冲突（引理 4 的前驱只有左与上）。
- **符号与负余数**：`(r-x+k)%k`、`(r+x)%k` 与引理 5 一一对应；`x` 已在读入时 `%k`。
- **就地结算**：`inc(ans,f[u][1][j][0])` 放在 $j$ 循环末尾，正确性由引理 7 的"此刻已是终值"给出，省掉一遍全表扫描。
- 换行用 `'\n'`、Tab 缩进、运算符两侧无空格、`cin.tie/cout.tie/ios::sync_with_stdio` 顺序固定，符合风格规范。
