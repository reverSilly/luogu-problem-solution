# P1621 集合

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给定区间 $[a,b]$ 内的所有整数，初始时每个整数自成一个集合。可以反复执行：取两个当前属于不同集合的整数 $u,v$，若它们存在一个**大于等于 $p$ 的公共质因数**，就把这两个集合合并。问操作无法继续时还剩多少个集合。

### 输入输出格式

- **输入格式**：一行三个整数 $a,b,p$。
- **输出格式**：一行一个整数，最终集合数。
- **数据规模**：$1\le a\le b\le10^5$，$2\le p\le b$；其中 $80\%$ 的数据 $b\le10^3$。

### 关键约束分析

1. 点数最多 $10^5$，点对最多 $5\times10^9$，**不能枚举点对**。$80\%$ 的 $b\le10^3$ 提示"小数据可以平方，满分必须换角度"。
2. 合并条件的载体是"公共质因数"，而质因数只有 $\pi(10^5)=9592$ 种，比点对少得多——这是一个强烈的信号：应当**按质因数组织合并**。
3. $1$ 没有任何质因数，永远不会被合并，必须能被正确计数（它自成一集合）。
4. $p$ 可以等于 $b$：此时只有质数 $p$ 本身能作为连接因子，而它在区间内若只有一个倍数（就是自己），不会产生任何合并。
5. 答案在 $[1,b-a+1]$ 内，`int` 足够。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：把过程翻译成图

把 $[a,b]$ 的每个整数当作一个点；若两个数存在 $\ge p$ 的公共质因数，就在它们之间连一条边。整个过程就是"沿着边不断合并"，因此最终的集合就是这张图的**连通块**。

**引理 1（最终集合 = 连通块）**：设 $G$ 以 $[a,b]$ 为点集、上述关系为边集，则操作终止时每个集合恰是 $G$ 的一个连通块。

*证明*：先证"同块必连通"：初始每个点自成一个集合，单点集按定义连通；每次合并两个集合是因为存在一条边连接它们内部的点，两个连通块加一条边后仍连通，故任何时刻每个集合都是 $G$ 中某个连通块的子集。再证"连通必同块"：设 $u,v$ 在同一连通块，取一条路径 $u=x_0,x_1,\dots,x_k=v$，对 $i$ 归纳可证 $x_i$ 与 $u$ 同集合：每步 $(x_i,x_{i+1})$ 是边，若二者当时不同集合就会被合并，故它们始终同集合。于是 $u,v$ 同集合。两者合起来即"集合 = 连通块"。$\square$

### 第二步：按质因数分组，避免枚举点对

一条边 $(u,v)$ 存在，等价于存在质数 $q\ge p$ 使 $q\mid u$ 且 $q\mid v$。也就是说，**同一条边一定"藏"在某个质数 $q$ 的倍数集合里**。于是对每个质数 $q\ge p$，把 $[a,b]$ 中所有 $q$ 的倍数"串成一串"就够了。

**引理 2（链式合并与全配对等价）**：固定质数 $q$，设它在 $[a,b]$ 中的倍数为 $m_1<m_2<\dots<m_k$。只做 $k-1$ 次合并 $(m_1,m_2),(m_2,m_3),\dots,(m_{k-1},m_k)$，与把 $\binom{k}{2}$ 对全部合并，得到的连通性完全相同。

*证明*：链式合并使 $m_1,\dots,m_k$ 全部落入同一集合，故任意一对 $m_i,m_j$ 都连通，效果不弱于全配对；而链上的每条边本身也是合法的合并依据（两端都被 $q$ 整除，$q\ge p$），所以不会引入额外的连通，效果也不强于全配对。两个方向的包含关系成立。$\square$

**引理 3（全局充分性）**：对所有质数 $q\in[p,b]$ 做上述链式合并后，得到的连通块与 $G$ 的连通块一致。

*证明*：两个方向分别验证。**（结果 ⊆ 关系图）**链上每条边都是 $G$ 的合法边（两端都被同一个 $q\ge p$ 整除），合并只能沿合法边进行，故结果中同集合的两点必在 $G$ 中连通。**（关系图 ⊆ 结果）**对 $G$ 的任意一条边 $(u,v)$，它由某个质数 $q\ge p$ 见证，而 $u,v$ 都是 $q$ 的倍数，由引理 2 它们在结果中已连通；于是 $G$ 的每条边都被结果"覆盖"，$G$ 的连通块不会被打散。双向包含即得两者一致。$\square$

### 第三步：筛出质数并估算代价

用埃氏筛求出 $[2,b]$ 的所有质数（顺带得到 `comp[]` 合数标记）。对每个 $q\ge p$，先算出区间内最小的倍数
$$\mathrm{st}=\left\lceil\frac{a}{q}\right\rceil q=\left\lfloor\frac{a+q-1}{q}\right\rfloor q,$$
若 $\mathrm{st}>b$ 说明 $q$ 在区间内没有倍数，跳过；否则从 $\mathrm{st}+q$ 起把每个倍数与 $\mathrm{st}$ 合并。

**引理 4（复杂度）**：上述过程的总合并次数不超过 $\sum_{q\le b}\left(\frac{b}{q}+1\right)=\mathcal{O}(b\log\log b)$。

*证明*：对质数 $q$，区间内倍数个数不超过 $b/q$，链式合并次数为其减一。求和得 $\sum_{q\le b}b/q+\pi(b)$。由梅滕斯定理 $\sum_{q\le b}1/q=\ln\ln b+O(1)$，故总和为 $\mathcal{O}(b\log\log b)$。$\square$

$b=10^5$ 时该量约为 $3\times10^5$ 次合并，非常轻。

### 第四步：统计答案

所有合并结束后，答案就是 `[a,b]` 中满足"自己是自己集合的根"的点的个数，即 `getrt(i)==i` 的 $i$ 的个数。注意必须在**全部合并完成之后**再统计，否则路径压缩还没把根统一。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 合并规则是一个等价关系的闭包，最终集合就是关系图的连通块。
- `consider easier version` — 先想"枚举点对 + gcd 判定"，立刻被 $5\times10^9$ 的规模否掉。
- `explore its property` — 边的载体是质因数，"同一质数的倍数必连通"把点对数量级降成质数级别。
- `classic problem solution` — 并查集维护连通块，路径压缩保证近似常数时间。
- `classic problem solution` — 埃氏筛求 $[2,b]$ 的质数与合数标记，顺带枚举每个质数的倍数。
- `reduce to easier problem` — 每个质数只需链式合并 $k-1$ 次，不必做 $\binom{k}{2}$ 次全配对。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $a,b$ | `a`,`b` | 区间左右端点 |
| $p$ | `p` | 公共质因数的下界 |
| 并查集父指针 | `f[x]` | 初值 `f[i]=i`，只对 $i\in[a,b]$ 初始化 |
| 查找函数 | `getrt(x)` | 带路径压缩的并查集查找 |
| 质数 | `i` | 埃氏筛中当前判定的数，`comp[i]` 为假即质数 |
| 合数标记 | `comp[x]` | `comp[x]=true` 表示 $x$ 是合数（被某个更小质数筛掉） |
| 最小倍数 | `st` | $\lceil a/i\rceil i$，即 $[a,b]$ 中最小的 $i$ 的倍数 |
| 枚举倍数 | `m` | 从 `st+i` 开始按步长 `i` 递增 |
| 端点根 | `u`,`v` | 待合并的两个集合的根 |
| 答案 | `ans` | 满足 `getrt(i)==i` 的 $i$ 的个数 |

### 算法步骤

1. 读入 $a,b,p$；对 $i\in[a,b]$ 置 `f[i]=i`。
2. 对 $i$ 从 $2$ 到 $b$：若 `comp[i]` 为真则跳过；否则 $i$ 是质数，先把 $i^2,i^2+i,\dots$（不超过 $b$）标记为合数。
3. 若 $i<p$，该质数不参与合并，继续下一个。
4. 计算 `st=((a+i-1)/i)*i`；若 `st>b` 则区间内没有倍数，跳过。
5. 对 `m=st+i, st+2i, ...`（不超过 $b$）：合并 `getrt(st)` 与 `getrt(m)`。
6. 全部结束后统计 $i\in[a,b]$ 中 `getrt(i)==i` 的个数并输出。

### 复杂度分析

- **时间复杂度**：筛法 $\mathcal{O}(b\log\log b)$；合并总量 $\mathcal{O}(b\log\log b)$，并查集近似 $\mathcal{O}(1)$；统计 $\mathcal{O}(b-a)$。总体 $\mathcal{O}(b\log\log b)$。
- **空间复杂度**：$\mathcal{O}(b)$，两个长度 $10^5$ 的数组（父指针与合数标记）。

### 正确性验证

引理 1 把问题化为连通块计数，引理 2 说明链式合并不改变连通性，引理 3 说明对所有质数做完链式合并后连通块与关系图完全一致，故第六步统计的根个数就是答案。数值上所有下标不超过 $10^5$，`i` 的平方用 `i64` 计算以避免 $i^2$ 在标记时溢出（虽然 $i\le10^5$ 时 $i^2\le10^{10}$ 已超 `int`，代码中显式写成 `(i64)i*i`）。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1621 集合
// https://www.luogu.com.cn/problem/P1621
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int a,b,p,ans;
int f[mxn];
bool comp[mxn];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b>>p;
	for(int i=a;i<=b;++i)
		f[i]=i;
	for(int i=2;i<=b;++i)
	{
		if(comp[i])
			continue;
		for(i64 j=(i64)i*i;j<=b;j+=i)   // i 是质数
			comp[j]=true;
		if(i<p)
			continue;
		int st=((a+i-1)/i)*i;           // [a,b] 中最小的 i 的倍数
		if(st>b)
			continue;
		for(int m=st+i;m<=b;m+=i)
		{
			int u=getrt(st),v=getrt(m);
			if(u!=v)
				f[u]=v;
		}
	}
	for(int i=a;i<=b;++i)
		if(getrt(i)==i)
			++ans;
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **`i*i` 溢出**：$10^5$ 的平方是 $10^{10}$，标记循环里的 `j` 必须用 `i64`（或直接判 `i<=b/i`）。
2. **`st` 的计算**：`(a+i-1)/i*i` 才是 $\ge a$ 的最小倍数，写成 `a/i*i` 会取到小于 $a$ 的倍数并越界修改 `f`。
3. **`f` 的初始化范围**：只需 $[a,b]$，但访问 `st+i` 等下标时都在 $[a,b]$ 内，故不会读到未初始化的 0。
4. **统计时机**：必须在所有合并结束后再数根；边合并边计数会重复。
5. **$i<p$ 仍要筛**：$i<p$ 的质数不能跳过筛法部分，否则 `comp[]` 不完整，后续会把合数当质数。
6. **$1$ 的处理**：$1$ 没有质因数，天然自成一集合，不需要特判，但要确保它被计入统计。
