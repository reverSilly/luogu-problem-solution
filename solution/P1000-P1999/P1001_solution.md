# P1001 A+B Problem — 题解

## 一、解题过程：人类思考叙事

拿到题目：输入两个整数 $a, b$，输出它们的和。

第一反应：这不是最简单的模拟题吗？直接读两个数加起来输出就行了。

但仔细看数据范围：$-10^9 \le a, b \le 10^9$。这意味着 $a+b$ 的取值范围是 $[-2 \cdot 10^9, 2 \cdot 10^9]$，刚好在 `int`（32位有符号，范围约 $\pm 2.1 \cdot 10^9$）的边界内。虽然理论上不会溢出，但题目提示里明确说了"Pascal 的 integer 会爆掉"，暗示数据可能接近边界。保险起见用 `int` 即可，因为 $2 \cdot 10^9 < 2^{31}-1 = 2147483647$。

再看题目提示："有负数哦"——说明需要考虑负数加法，但 C++ 的 `+` 运算符天然支持，不需要特殊处理。

还有一个坑："main 函数必须是 int 类型，返回值必须是 0"——这是 NOIP/CSP/NOI 的硬性要求，别忘了写 `return 0;`。

输出格式方面：不能有多余提示文字，只能输出结果本身。系统会忽略行尾空格和最后的多余换行。

结论：这是一道 O(1) 的纯模拟，没有任何算法技巧，核心就是"正确读入、正确输出"。

---

## 二、思维链：完整证明

**引理 1**：`int` 类型足以存储 $a+b$ 的结果，不会发生溢出。

*证明*：32位有符号整数的取值范围为 $[-2^{31}, 2^{31}-1] = [-2147483648, 2147483647]$。

由数据范围，$a, b \in [-10^9, 10^9]$，因此：
- $a+b$ 的最大值为 $10^9 + 10^9 = 2 \cdot 10^9 = 2000000000 < 2147483647 = 2^{31}-1$
- $a+b$ 的最小值为 $-10^9 + (-10^9) = -2 \cdot 10^9 = -2000000000 > -2147483648 = -2^{31}$

故 $a+b \in [-2\cdot 10^9, 2\cdot 10^9] \subset [-2^{31}, 2^{31}-1]$，不会溢出。证毕。

**引理 2**：C++ 的 `cin >> a >> b` 能够正确读取空格分隔的两个整数，包括负数。

*证明*：`operator>>` 对于 `int` 类型的标准行为是跳过前导空白字符（空格、制表符、换行），然后读取可选的符号位（`+` 或 `-`），接着读取十进制数字序列直到遇到非数字字符。题目保证输入是两个以空格分隔的整数，因此该操作能正确解析。证毕。

**引理 3**：本题的时间复杂度为 $O(1)$，空间复杂度为 $O(1)$。

*证明*：程序执行的操作序列为：读取两个整数（常数时间）、执行一次加法（常数时间）、输出结果（常数时间）。不依赖任何输入规模变量，使用固定数量的变量存储。故时间和空间均为 $O(1)$。证毕。

## 三、模式总结（按实际思考顺序）

1. **识别题型** → 模拟 / 基础 I/O
2. **检查数据范围** → $[-10^9, 10^9]$，确认 `int` 不溢出
3. **注意边界提示** → 负数支持（天然）、Pascal integer 溢出警告（C++ int 安全）
4. **确认输出格式** → 纯数字输出，无提示文字
5. **确认 main 规范** → `int main() {... return 0;}`
6. **编写代码** → 读入 → 加法 → 输出

## 四、解法说明

### 算法

读入两个整数 $a$ 和 $b$，计算 $s = a + b$，输出 $s$。

### 符号表

| 符号 | 含义 | 类型 |
|------|------|------|
| $a$ | 第一个输入整数 | `int` |
| $b$ | 第二个输入整数 | `int` |
| $s$ | 和 $a+b$ | `int`（隐式临时值） |

### 复杂度

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

### 代码行为

1. 初始化 I/O 加速（`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`）
2. 从标准输入读取 $a, b$
3. 直接输出 $a + b$ 的值
4. `return 0` 正常退出

---

## 五、示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int a,b;
	cin>>a>>b;
	cout<<a+b<<'\n';
	return 0;
}
```

### 代码说明

- 本题不需要数组、不需要 `mxn` 常量、不需要哨兵值，仅需要两个局部变量。
- I/O 加速三行按规范顺序排列：`cin.tie` → `cout.tie` → `ios::sync_with_stdio`。
- 换行使用 `'\n'` 而非 `endl`，避免不必要的缓冲区刷新。
- `main` 返回类型为 `int`，正常结束时 `return 0`，符合 NOI 赛制要求。
