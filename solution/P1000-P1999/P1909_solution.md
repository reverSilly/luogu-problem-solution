# P1909 [NOIP 2016 普及组] 买铅笔

## 1. 重新读题

P 老师要买**至少** $n$ 支铅笔。商店只有 $3$ 种包装，第 $i$ 种一包有 $c_i$ 支、卖 $p_i$ 元。包装不能拆开，而且题面强制"只买同一种包装"。问最少花多少钱。

### 关键约束与规模暗示

- $n,c_i,p_i\le 10000$，只有 $3$ 种包装。这个规模允许我们对每种包装单独计算再取最小，甚至不用任何循环优化。
- 最坏情况是 $c_i=1,p_i=10000,n=10000$，花费 $10^8$。虽然 $10^8<2^{31}$，但乘法习惯上用 `long long`，避免以后改数据范围时溢出。
- "整倍数"子任务提示：当 $n$ 是 $c_i$ 的倍数时恰好不用多买；一般情况要向上取整。

## 2. 思维链（Chain-of-thought）

### 2.1 先想"混合买"——被题面否掉

如果允许三种包装混着买，就是整数线性规划。但题面写得很清楚：**只买同一种包装**。所以三种包装互不影响，答案一定是三个"单独买某种包装"的花费中的最小值。问题被拆成三个互不相关的子问题。

（这也是一个容易读漏的点：如果按"单价最低就多买它"的贪心去混着买，会直接算错。）

### 2.2 单一包装：买几包？

固定第 $i$ 种包装，一包 $c_i$ 支、价格 $p_i$。设买 $k$ 包，则得到 $k\,c_i$ 支、花 $k\,p_i$ 元。

**引理 1（最少包数）**：设 $k^{*}=\left\lceil n/c_i\right\rceil$。则 $k\ge k^{*}$ 时 $k c_i\ge n$；$k<k^{*}$ 时 $k c_i<n$。即 $k^{*}$ 是唯一最小的可行包数。

**证明**：
- 由向上取整的定义，$k^{*}=\min\{k\in\mathbb Z_{\ge0}: k c_i\ge n\}$，所以 $k^{*}\ge$ 任何可行 $k$，且 $k^{*}$ 本身可行。
- 若 $k<k^{*}$，由最小值定义 $k c_i<n$，不够。
- 于是可行包数集合恰好是 $\{k^{*},k^{*}+1,\dots\}$。$\blacksquare$

**引理 2（买得越多越贵）**：$p_i>0$，故 $k\mapsto k p_i$ 严格递增。于是该包装下的最优花费就是 $k^{*} p_i$。

**证明**：$p_i\ge1$，对 $k_1<k_2$ 有 $k_2p_i-k_1p_i=(k_2-k_1)p_i>0$。结合引理 1，可行包数中最小者花费也最小。$\blacksquare$

### 2.3 为什么"单价最低"是错的（失败尝试）

一个很自然的贪心是：算出每种包装的单价 $p_i/c_i$，选单价最低的那种尽量买。样例就能把它打穿：

| 包装 | 数量 | 价格 | 单价 |
| :--- | :--- | :--- | :--- |
| 1 | 2 | 2 | 1 |
| 2 | 50 | 30 | 0.6 |
| 3 | 30 | 27 | 0.9 |

$n=57$ 时，单价最低的是 2 号包装，买 $2$ 包要 $60$ 元；而 3 号包装买 $2$ 包只要 $54$ 元。原因是"整包购买"带来的浪费不同：50 支装买 2 包浪费 43 支，30 支装只浪费 3 支。**单价只在"能整除、浪费可忽略"时才有意义**。

因此不能比较单价，只能老老实实对三种包装分别算"总价"，再取最小。这正是引理 1、2 给出的闭式答案。

### 2.4 汇总

$$\text{ans}=\min_{i=1,2,3}\left(\left\lceil\frac{n}{c_i}\right\rceil\cdot p_i\right).$$

代码里向上取整写成 `(n+cnt-1)/cnt`（整数除法），避免浮点误差。哨兵取一个远大于 $10^8$ 的数即可。

## 3. 模式总结（Pattern Summary）

- **explore its property** — "只能买同一种包装"把问题拆成三个互不影响的子问题。
- **explore its property** — 单一包装下可行包数是后缀集合，价格为正故最少的包最优（引理 1、2）。
- **exchange argument（反例）** — 单价贪心在"整包浪费"下失效，样例即反例。
- **classic problem solution** — 三次向上取整，取最小值。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 需要的铅笔数 | 读入 | 目标数量 |
| `cnt` | `i64` | 当前包装一包的支数 $c_i$ | 读入 | count per pack |
| `price` | `i64` | 当前包装一包的价格 $p_i$ | 读入 | price per pack |
| `packs` | `i64` | 该包装最少要买的包数 $\lceil n/c_i\rceil$ | 计算 | packs |
| `ans` | `i64` | 三种包装花费的最小值 | `1145141919810` | answer |

### 4.2 算法步骤

1. 读入 $n$。
2. 循环 $3$ 次读入 `cnt, price`：
   - `packs=(n+cnt-1)/cnt`（向上取整）；
   - `ans=min(ans,packs*price)`。
3. 输出 `ans`。

### 4.3 复杂度

- 时间 $O(1)$（固定 $3$ 次），空间 $O(1)$。
- 使用 `long long` 保存花费，最大 $10^8$，不会溢出。

## 5. 示例代码

```cpp
//
// 题目：P1909 [NOIP 2016 普及组] 买铅笔
// https://www.luogu.com.cn/problem/P1909
//
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	i64 ans{1145141919810};
	for(int i=0;i<3;++i)
	{
		i64 cnt,price;
		cin>>cnt>>price;
		i64 packs=(n+cnt-1)/cnt;
		ans=min(ans,packs*price);
	}
	cout<<ans<<'\n';
	return 0;
}
```
