# P1037 产生数 — 完整题解

## 一、发现历程：从样例到模型

### 1.1 初读题面

有整数 $n=234$，两条规则：

- $2\to5$
- $3\to6$

对每一位数字可以**任意次**应用规则，求能产生的不同整数个数。

手动枚举：

| 原数 | 规则应用情况 | 结果 |
|------|-------------|------|
| 234 | 都不变 | 234 |
| 234 | 百位 2→5 | 534 |
| 234 | 十位 3→6 | 264 |
| 234 | 百位 2→5，十位 3→6 | 564 |

恰好 $4$ 种。注意个位 $4$ 没有规则可变换，只能保持自身。

### 1.2 核心观察

**每位独立**：百位变成什么数字，与其他位无关。这是一个**乘法原理**模型——每位可选的变化数相乘，就是总数。

为什么独立？因为规则只作用在**一位数**上，不涉及进位、不进位、也不涉及相邻位的联合变换。每次变换只改一个数位，不同数位的变换互不干扰。

### 1.3 于是问题拆解为三步

1. 对每个数字 $d\in\{0..9\}$，求出它能变换成哪些数字（包括自身）；
2. 对 $n$ 的每一位，查表得到该位可以变成多少种数字，记作 $c_i$；
3. 计算 $\prod c_i$。

但这第三步会非常大——$n$ 最长 30 位，每个 $c_i$ 最大可达 10，$10^{30}$ 远超 64 位整数范围，需要高精度。

## 二、链式推理：每一环的证明

### 2.1 变换关系具有传递性

规则 $a\to b$ 表示可以从 $a$ 变成 $b$。如果同时有 $b\to c$，那么可以 $a\to b\to c$，即 $a$ 可以变成 $c$。

> **证明**：先对 $a$ 应用 $a\to b$，再对结果中的 $b$ 应用 $b\to c$，即得 $c$。由数学归纳法，任意长度的变换链等价于传递闭包。

因此，我们需要计算有向图 $G=(V=\{0..9\},E=\{(x_i,y_i)\})$ 的**传递闭包**。设 $r[i][j]=1$ 当且仅当 $i$ 可以通过零次或多次变换到达 $j$。

### 2.2 Floyd–Warshall 在 10 个点上的正确性

标准 Floyd 算法：

```
for k in 0..9:
    for i in 0..9:
        for j in 0..9:
            r[i][j] = r[i][j] or (r[i][k] and r[k][j])
```

$|V|=10$，三层循环 $10^3=1000$ 次操作，完全无关痛痒。

**正确性**：Floyd 的不变量是——第 $k$ 轮结束后，$r[i][j]$ 表示仅使用编号 $\le k$ 的中间节点能否从 $i$ 到 $j$。初始 $r[i][i]=1$（零次变换），每加一条规则 $r[x][y]=1$（一次变换）。最终 $k$ 跑满 $0..9$ 即得完整传递闭包。

### 2.3 乘法原理的严格论证

设 $n$ 有 $L$ 位，第 $t$ 位上的数字为 $d_t$。记 $S_t = \{j \mid r[d_t][j]=1\}$ 为第 $t$ 位能变成的数字集合。

任意一种最终整数，可以由每一位独立选择 $j_t\in S_t$ 得到。不同的选择序列 $(j_0,j_1,\dots,j_{L-1})$ 对应不同的整数（因为位数相同，每一位的值决定了一切）。

所以总种类数等于各个 $S_t$ 大小的乘积：

$$
\text{Ans} = \prod_{t=0}^{L-1} |S_t|.
$$

### 2.4 为何需要高精度

$L\le 30$（因为 $n<10^{30}$），每个 $|S_t|\le 10$，所以 $\text{Ans}\le 10^{30}$。

$10^{30} \approx 2^{100}$，远超 `unsigned long long` 的 $2^{64}$。必须手写高精度乘法。

### 2.5 边界与细节

- **规则右部不能为零**：$y_i\neq 0$。这意味着任何变换的目标都不能是 $0$，但 $0$ 作为**起点**是允许的（如果 $n$ 中有 $0$，它可以不变为自身）。
- **零次变换是允许的**：每位至少可以保持原数字，所以 $|S_t|\ge 1$。
- $n$ 以整数形式给出，但是长度可能达 30 位，必须按字符串读入。
- $k\le 15$ 很小，但传递闭包仍需要 Floyd。
- 结果只输出个数，不需要输出所有整数。

## 三、模式总结：这类题的本质

| 要素 | 本题 | 通用模式 |
|------|------|---------|
| 变换规则 | 一位数→一位数 | 小状态集上的转移 |
| 可变换任意次 | 需要传递闭包 | Floyd / BFS / DFS |
| 每位独立 | 乘法原理 | 各自计数后相乘 |
| 答案极大 | 高精度乘法 | 数组模拟竖式 |

> **一句话模式**：小图传递闭包 + 乘法原理 + 高精度 = 计数型数位变换问题。

## 四、正式解法与符号说明

### 4.1 符号表

| 符号 | 含义 |
|------|------|
| $s$ | 输入整数 $n$，按字符串读入（长度 $L\le 30$） |
| $k$ | 规则条数，$k\le 15$ |
| $d[i][j]$ | 有向图邻接矩阵 / 传递闭包，$d[i][j]=1$ 表示 $i$ 可变为 $j$ |
| $c[i]$ | 数字 $i$ 能变成的不同数字个数，$c[i]=\sum_{j=0}^9 d[i][j]$ |
| $\text{ans}[\ ]$ | 高精度数组，低位在前，存最终答案 |
| $L$ | $n$ 的位数 |
| $x_i,y_i$ | 第 $i$ 条规则：$x_i\to y_i$ |

### 4.2 算法步骤

1. **读入**：$s$ 为字符串，读入 $k$。
2. **建图**：初始化 $d[10][10]$ 全零，令 $d[i][i]=1$（自身可到达自身）。对每条规则 $(x,y)$，令 $d[x][y]=1$。
3. **传递闭包**：Floyd 三重循环，$d[i][j]\mid=d[i][k]\ \&\ d[k][j]$。
4. **计数**：对每个 $i\in[0,9]$，统计 $c[i]=\sum_{j=0}^9 d[i][j]$。
5. **高精度累乘**：
   - 初始化 `ans[0]=1`，长度 `len=1`。
   - 对 $s$ 的每一位 $ch$，令 $digit = ch-'0'$，将 $ans$ 乘以 $c[digit]$。
   - 高精度乘法的实现：每位乘以乘数，处理进位。
6. **输出**：从高位到低位输出 `ans` 数组。

### 4.3 复杂度分析

- 时间：Floyd $O(10^3)$ + 高精度乘法 $O(L\cdot \text{len})\le O(30\cdot 30)=O(900)$，完全可以忽略。
- 空间：$O(10^2 + \text{len})$，常数级别。

## 五、C++ 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;

string s;
int k,x,y;
int d[10][10];
int c[10];
int ans[114514],len;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s>>k;
	for(int i=0;i<10;++i)
		d[i][i]=1;
	for(int i=0;i<k;++i)
	{
		cin>>x>>y;
		d[x][y]=1;
	}

	for(int k=0;k<10;++k)
		for(int i=0;i<10;++i)
			for(int j=0;j<10;++j)
				if(d[i][k]&&d[k][j])
					d[i][j]=1;

	for(int i=0;i<10;++i)
		for(int j=0;j<10;++j)
			c[i]+=d[i][j];

	ans[0]=1;
	len=1;
	for(char ch:s)
	{
		int mul=c[ch-'0'];
		for(int i=0;i<len;++i)
			ans[i]*=mul;
		for(int i=0;i<len;++i)
		{
			ans[i+1]+=ans[i]/10;
			ans[i]%=10;
		}
		while(ans[len])
		{
			ans[len+1]+=ans[len]/10;
			ans[len]%=10;
			++len;
		}
	}

	for(int i=len-1;i>=0;--i)
		cout<<ans[i];
	cout<<'\n';

	return 0;
}
```

### 5.1 代码要点

- `d[i][i]=1`：每个数字可以不经过任何变换到达自身。
- Floyd 的 `if(d[i][k]&&d[k][j])` 写法比 `|=` 显式，逻辑更清晰。
- 高精度部分：先统一乘 `mul`，再统一处理进位。`while(ans[len])` 处理最高位溢出产生的新长度。
- 最大结果 $10^{30}$ 约 100 位二进制、30 位十进制，`ans[114514]` 绰绰有余。

### 5.2 验证样例

```
输入:
234 2
2 5
3 6

过程:
  d[2] = {2→自身, 2→5} → c[2]=2
  d[3] = {3→自身, 3→6} → c[3]=2
  d[4] = {4→自身}        → c[4]=1
  ans = 2 × 2 × 1 = 4

输出:
4
```

## 六、总结回顾

- **第一层**：认识到每位独立，使用乘法原理。
- **第二层**：需要传递闭包，Floyd 极小图轻松解决。
- **第三层**：答案过大，高精度乘法是必要环节。
- **陷阱**：规则右部不能为零但 $0$ 可出现在 $n$ 中；$n$ 按字符串读入而非整数；$k\le 15$ 但传递闭包仍不能忘记。

掌握这三层，P1037 便从"图论 + 高精度"的复合题，化简为每个环节都清晰可控的简单题。
