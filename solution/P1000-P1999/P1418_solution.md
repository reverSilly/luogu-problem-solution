# P1418 [TJOI2011] 构造矩阵

> 标签：网络流 / 贪心 / 二分图 b-匹配 · 难度：NOI/NOI+

## 1. 重新读题

**问题重述（简化版）**

要造一个 $n\times m$ 的 $01$ 矩阵 $A$，满足两组"计数约束"：

- 行约束：$\sum_{j=1}^{m}A_{i,j}=r_i$，对每个 $i=1..n$；
- 列约束：$\sum_{i=1}^{n}A_{i,j}=c_j$，对每个 $j=1..m$。

在所有满足约束的矩阵里，输出**字典序最小**的那一个。比较规则题面写明："先比较第一行，第一行相等再比较第二行"——即把矩阵按行优先展平成 $nm$ 个数字的序列做字典序比较。

**条件的隐含推论**

- 把两组约束相加都得 $\sum_{i,j}A_{i,j}$，故必有 $\sum_i r_i=\sum_j c_j$；不相等则**无解**。
- 又每格最多 $1$，故 $0\le r_i\le m$、$0\le c_j\le n$；超出同样无解。
- 题面输出格式只有"输出一个 $n\times m$ 的矩阵"，**没有任何无解输出说明**，因此判定数据保证有解（代码里用 `assert` 兜住，不额外分支）。

**数据范围**：$n,m\le 100$，于是格子数 $nm\le 10^4$，$1$ 的总数 $\le 10^4$。规模非常小，"每格做一次 $O(nm)$ 判定"这种 $O((nm)^2)=10^8$ 级别的算法是允许考虑的——这是本题最重要的提示。

**目标顺序与"小"的方向**：字典序里 $0<1$，所以"最小"意味着**尽量把 $1$ 往后（右下）推**，第一行第一列希望是 $0$。若某格在所有可行解里都只能是 $1$，那它就只能写 $1$。

**陷阱与边界**

1. 本地题面**没有样例输入输出**，无法与官方答案对标，本文的正确性只靠引理证明 + 手算小数据（见 §4 末尾）。
2. 输出分隔符题面未规定，按洛谷此类构造题惯例：每行 $m$ 个数字、空格隔开、行末换行。
3. 若题目实际按 $1<0$ 比较（极少数题会这么定义），本算法只需把逐格决策时的"偏好 $0$"改成"偏好 $1$"（即 `a[i][j]==0` 时也做一次交错路径判定）；本文严格按题面的标准数字序 $0<1$ 写。
4. 全零行/列（$r_i=0$ 或 $c_j=0$）必须正常输出，不能因为"没得选"而漏格。
5. $n=1$ 或 $m=1$ 时答案唯一，算法仍需给出不报错的结果。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：字典序把问题变成"逐格决策"

先把"字典序最小"翻译成可操作的语句。把矩阵按 $(1,1),(1,2),\dots,(1,m),(2,1),\dots$ 的顺序排成 $nm$ 个格子，记这个顺序为 $\prec$。两个矩阵的第一个不同格子决定了大小，数字小者胜。

**引理 1（逐格贪心正确性）**

设决策过程按 $\prec$ 顺序逐格填写，填第 $p$ 格时若存在某个可行解与已填前缀一致且第 $p$ 格为 $0$，就填 $0$，否则填 $1$。这样得到的矩阵是所有可行解中字典序最小的。

**证明**：记算法输出 $B$，设存在可行解 $C\prec_{lex}B$（比 $B$ 小）。取 $C$ 与 $B$ 第一个不同的格子 $p$，则 $C_p<B_p$，即 $B_p=1,C_p=0$，且 $C$ 的前 $p-1$ 格与 $B$ 完全相同。按引理 1 的规则，算法在格子 $p$ 填 $1$ 当且仅当"与已定前缀一致、且第 $p$ 格为 $0$ 的可行解不存在"。但 $C$ 正是这样一个可行解：它与算法在 $p$ 之前定下的前缀一致（前 $p-1$ 格相同），且 $C_p=0$，并且 $C$ 满足全部行列约束。矛盾。故不存在比 $B$ 更小的可行解，$B$ 字典序最小。$\blacksquare$

> 这个引理把"整体最优"拆成了 $nm$ 次"局部提问"：**固定前缀后，本格能否取 $0$？** 每次提问只需要一个判定器（oracle）。引理 1 不关心判定器怎么实现，因此问题彻底归约为：

**子问题（带禁位的可行性判定）**：给定哪些格子已被固定（含取值）、每行还差几个 $1$、每列还差几个 $1$，判断是否存在补全方案。

后面 §2.2–§2.5 全部在处理这个判定器。

### 2.2 简化版：先只判可行性（二分图度序列）

先丢掉字典序要求，只回答"给定的 $r,c$ 能不能造出来"。这是经典的**二分图度数序列**问题（二分 $b$-匹配）：左边 $n$ 个行点 $R_i$、右边 $m$ 个列点 $C_j$，格 $(i,j)$ 对应一条容量 $1$ 的边（$01$ 值即"这条边选不选"），行/列需求即每个点的度数上限。

建网络：

$$S \xrightarrow{\;r_i\;} R_i \xrightarrow{\;1\;} C_j \xrightarrow{\;c_j\;} T$$

**引理 2（可行 ⟺ 满流）**

存在满足 $r,c$ 的 $01$ 矩阵 $\iff$ 该网络的最大流值等于 $\sum_i r_i$（此时必有 $\sum_i r_i=\sum_j c_j$）。

**证明**：

($\Rightarrow$) 给定矩阵 $A$，令 $f(S,R_i)=r_i$、$f(R_i,C_j)=A_{i,j}$、$f(C_j,T)=c_j$。逐点验证守恒：$R_i$ 的入量 $=r_i$，出量 $=\sum_j A_{i,j}=r_i$ ✓；$C_j$ 的入量 $=\sum_i A_{i,j}=c_j$，出量 $=c_j$ ✓。所有边不超容（$A_{i,j}\in\{0,1\}$，边容量 $1$ ✓）。故这是值 $\sum_i r_i$ 的可行流。

($\Leftarrow$) 设最大流值 $=\sum_i r_i$。因为源点出边容量总和就是 $\sum_i r_i$，达到该值说明所有 $S\to R_i$ 边都饱和，即 $f(S,R_i)=r_i$；再由 $R_i$ 的守恒 $\sum_j f(R_i,C_j)=r_i$。同理汇点入边总容量 $\sum_j c_j\ge$ 流值 $=\sum_i r_i$，而每条 $C_j\to T$ 至多流 $c_j$、且这些边的流量和等于流值，故每条 $C_j\to T$ 也恰好饱和：$f(C_j,T)=c_j$，从而 $\sum_j c_j=\sum_i r_i$，且 $\sum_i f(R_i,C_j)=c_j$。

最后取整：Dinic/增广路算法每次沿路径推送的是路径最小剩余容量，初始容量全是整数，故推送过程中每条边流量恒为整数。于是 $f(R_i,C_j)\in\{0,1\}$（受容量 $1$ 限制）。令 $A_{i,j}=f(R_i,C_j)$ 即所求矩阵。$\blacksquare$

> **备注（另一个经典判定为什么不能用）**：Gale–Ryser 定理给出"$01$ 矩阵存在"的纯不等式判据：把 $r$ 降序排列后，可行 $\iff \sum r_i=\sum c_j$ 且对一切 $k$，$\sum_{a=1}^{k} r_{(a)}\le\sum_j\min(c_j,k)$。它的**必要**部分很好证：取度数最大的 $k$ 行，每列至多贡献 $\min(c_j,k)$ 个 $1$。但它是针对"所有格都允许"的完整实例的判据。我们 §2.1 的子问题里，当前行前半段的格子已被固定、后面的行不能再用某些格，出现**阶梯状禁位**，Gale–Ryser 不再适用。所以下文一律用流/匹配的语言。

### 2.3 朴素贪心失败：为什么"放最右"不行

有了引理 2，一个很自然的想法是跳过判定器，直接一行一行构造：

> **朴素贪心**：处理第 $i$ 行时，把 $r_i$ 个 $1$ 放到"剩余需求 $>0$"的**最靠右**的几列。

理由貌似很充分：$1$ 越靠右，这一行字典序越小。但它错了。

**反例（具体小数据）**：$n=2,\ m=4,\ r=(1,3),\ c=(2,1,1,0)$。

- 校验合法性：$\sum r=4=\sum c$，$r_i\le 4$，$c_j\le 2$ ✓。
- 朴素贪心：第 $1$ 行只需 $1$ 个 $1$，剩余需求 $>0$ 的列是 $1,2,3$，最右是列 $3$，于是第 $1$ 行写成 $0\,0\,1\,0$；列需求变成 $(2,1,0,0)$，只剩 $2$ 个正需求列，而第 $2$ 行需要 $3$ 个 $1$ —— **填不出来**。
- 真实答案：第 $1$ 行只能写 $1\,0\,0\,0$，第 $2$ 行 $1\,1\,1\,0$。手算穷举第 $1$ 行的 $4$ 种写法（$1000/0100/0010/0001$）：写 $0001$ 使列 $4$ 需求变 $-1$；写 $0010$ 使列需求 $(2,1,0,0)$，$2$ 个正列撑不起 $3$ 个 $1$；写 $0100$ 使列需求 $(2,0,1,0)$，同样只剩 $2$ 个正列；只有 $1000$ 留下 $(1,1,1,0)$，第 $2$ 行恰好 $1110$ ✓。所以字典序最小解是 $\begin{pmatrix}1&0&0&0\\1&1&1&0\end{pmatrix}$，第一行第一格必须是 $1$。

**失败模式剖析（交换论证视角）**：朴素贪心只检查了"$c_j>0$（这一列还能放）"，这是**本格能放 $1$** 的必要条件，但它破坏的是**别的行**的可行性：本行占用一列会让该列的剩余需求减 $1$，若某列需求因此归 $0$，后面那些"$r$ 很大"的行可用的列数就少了。也就是说，一个格取 $0$ 还是 $1$ 的真正约束是

$$\text{剩余各行在剩余正需求列上能摆得下}\iff \text{带禁位的实例仍然可行},$$

而不是任何单列的局部条件。**结论**：必须用精确判定器，不能靠启发式。引理 1 告诉我们只要判定器正确，逐格贪心就是最优的，问题回到"如何高效判定"。

最直白的做法是每格重建一次网络跑一次最大流：$10^4$ 次流，虽然大概率能过，但常数大且代码重复。下一节把它压缩成"一次流 + 增量重排"。

### 2.4 经典解法：一次流 + 残量网络重排

**关键想法**：引理 2 已经能给出一个可行解（一次 Dinic）。之后每决策一格，我们**不重建网络**，而是维护一个"见证指派" $a$：它在所有**活格**（还没决策的格）上取值 $0/1$，并满足

$$\text{行 } i \text{ 的活格中 } 1 \text{ 的个数}=\underbrace{r_i-\text{已锁定的 }1}_{=:\,rr_i},\qquad \text{列 } j \text{ 的活格中 } 1 \text{ 的个数}=rc_j .$$

活的 $01$ 指派 $a$ 本身就是"当前前缀可以补全"的**证据**（把锁定的格加上即可）。于是每格的决策变成：能不能**改造**出手里这个证据，使目标格为 $0$？

设当前格 $(i,j)$，$a_{i,j}=1$（若 $a_{i,j}=0$，本格直接锁 $0$，删掉这格，$a$ 仍是合法证据，什么也不用做）。先把 $(i,j)$ 从活格里删去并当作 $0$：此时第 $i$ 行少了一个 $1$、第 $j$ 列少了一个 $1$，两边各差 $1$ 个。要补齐，就得把某一个原本为 $0$ 的活格变成 $1$……但直接改会打乱另一边的计数，所以必须**成串地改**：

$$R_i \xrightarrow{\;0\text{格}\to 1\;} C_{v_1}\xrightarrow{\;1\text{格}\to 0\;} R_{u_1}\xrightarrow{\;0\to1\;} C_{v_2}\to\cdots\to R_{u_k}\xrightarrow{\;0\text{格}\to1\;} C_j$$

即一条**交错路径**：从行点出发走"当前的 $0$ 格"，到列点后走回去一条"当前的 $1$ 格"，如此交替，终点恰好是列 $j$。把路径上所有格子取反，$(i,j)$ 记为 $0$。

**引理 3（有交错路径 $\Rightarrow$ 本格可以取 $0$）**

若存在如上形式的交错路径（经过的格都是活格、互不重复），则按上述方式翻转并令 $a_{i,j}=0$ 后，$a$ 仍是合法的见证指派，即存在一个第 $(i,j)$ 格为 $0$ 的完整可行矩阵。

**证明**：逐点检查计数变化，记路径为 $R_i,C_{v_1},R_{u_1},C_{v_2},\dots,R_{u_k},C_j$，翻转使 $0$ 格变 $1$（贡献 $+1$）、$1$ 格变 $0$（贡献 $-1$），而 $(i,j)$ 由 $1$ 变 $0$（对行 $i$、列 $j$ 各贡献 $-1$）。

- 行 $R_i$：路径在 $R_i$ 处只关联第一条边 $(i,v_1)$（$0\to1$，$+1$），加上 $(i,j)$ 的 $-1$，净 $0$ ✓。
- 列 $C_j$：只关联最后一条边 $(u_k,j)$（$0\to1$，$+1$），加上 $(i,j)$ 的 $-1$，净 $0$ ✓。
- 中间列 $C_{v_t}$：入边 $(u_{t-1},v_t)$ 变 $1$（$+1$），出边 $(u_t,v_t)$ 变 $0$（$-1$），净 $0$ ✓（$v_1$ 同理，入边来自 $R_i$）。
- 中间行 $R_{u_t}$：入边 $(u_t,v_t)$ 变 $0$（$-1$），出边 $(u_t,v_{t+1})$ 变 $1$（$+1$），净 $0$ ✓。
- 其余格子未被触碰 ✓。

路径由 BFS 的前驱记录还原，每个点至多入队一次（`vr/vc` 判重），故路径是**简单**的；又因为一个格 $(u,v)$ 至多贡献一条有向边（$a_{u,v}=0$ 时是 $R_u\to C_v$，$a_{u,v}=1$ 时是 $C_v\to R_u$），简单路径上的格两两不同，不存在同一格被翻转两次的情况，值域 $\{0,1\}$ 保持 ✓。综上，行、列在活格中的 $1$ 数不变，即 $a$ 仍是满足 $rr,rc$ 的见证，且 $a_{i,j}=0$。$\blacksquare$

**引理 4（没有交错路径 $\Rightarrow$ 本格在所有可行解里都是 $1$）**

若删去 $(i,j)$ 后从 $R_i$ 到 $C_j$ 不存在交错路径，则任何与已锁定前缀相容、且第 $(i,j)$ 格为 $0$ 的可行矩阵都不存在；于是锁 $1$ 是唯一选择，不损失最优性。

**证明**：反证。设 $a^*$ 是这样矩阵在活格上的限制：$a^*$ 与见证 $a$ 有相同的锁定格取值，且在活格上满足同样的 $rr,rc$，并且 $a^*_{i,j}=0$。

把 $(i,j)$ 从两边都删掉（在 $a$ 里它是 $1$、在 $a^*$ 里它是 $0$，删掉后取值一致，不影响比较），只在剩下的活格上比较。构造有向图 $D$：对每个剩下活格 $(u,v)$，

- 若 $a_{u,v}=0,\ a^*_{u,v}=1$：加有向边 $R_u\to C_v$；
- 若 $a_{u,v}=1,\ a^*_{u,v}=0$：加有向边 $C_v\to R_u$；
- 两者相同则不加边。

于是 $R_u$ 的出度 $=a^*$ 在 $u$ 行的 $1$ 数 $-$ 公共 $1$ 数，入度 $=a$ 在 $u$ 行的 $1$ 数 $-$ 公共 $1$ 数，故 $\operatorname{out}(R_u)-\operatorname{in}(R_u)=\#a^*_u-\#a_u$。按计数：

- 行 $i$：$\#a_i=rr_i-1$（丢掉了 $(i,j)$ 那个 $1$），$\#a^*_i=rr_i$（$a^*_{i,j}=0$，它的 $rr_i$ 个 $1$ 全在剩下的活格里），差 $+1$；
- 其它行：$\#a_u=\#a^*_u=rr_u$，差 $0$；
- 列 $j$：同理 $\operatorname{in}(C_j)-\operatorname{out}(C_j)=+1$（注意列点的 $a^*$ 边是入边、$a$ 边是出边）；
- 其它列：差 $0$。

现在假设 $D$ 中没有从 $R_i$ 到 $C_j$ 的有向路径。令 $X$ 为 $D$ 中 $R_i$ 可达的点集，则 $C_j\notin X$，且 $X$ 对出边封闭（$X$ 内点的出边终点仍可达，故仍在 $X$ 内），所以 $D$ 中没有从 $X$ 指向外部的边。对 $X$ 求和：

$$\sum_{p\in X}\big(\operatorname{out}(p)-\operatorname{in}(p)\big)=\underbrace{(\text{从 }X\text{ 出去的边数})}_{0}-\underbrace{(\text{进入 }X\text{ 的边数})}_{\ge 0}\le 0 .$$

但按上面的逐点差值，和式 $=+1$（只有 $R_i$ 贡献 $+1$，$C_j\notin X$，其余点贡献 $0$），矛盾。故 $D$ 中存在从 $R_i$ 到 $C_j$ 的有向路径。再把这条路径翻译成格子语言：路径在行点处只能走 $R_u\to C_v$ 型边，即 $a$ 意义下的 $0$ 格；在列点处只能走 $C_v\to R_u$ 型边，即 $a$ 意义下的 $1$ 格——正是一条从 $R_i$ 到 $C_j$ 的交错路径。这与"判定的 BFS 找不到路径"矛盾（BFS 在有向图上求可达性，路径存在当且仅当可达）。$\blacksquare$

> 引理 3 + 引理 4 合起来给出**充要判据**：在维护见证指派的前提下，"本格可以取 $0$" $\iff$ "$a_{i,j}=0$，或 $a_{i,j}=1$ 且存在那条交错路径"。于是每格的决策既最优（引理 1）又不会破坏可行性（引理 3/4 保证锁 $0$ 后仍有见证，锁 $1$ 时所有解都是 $1$）。

### 2.5 归约到更简单问题：交错路径 = 残量增广路

把 §2.4 的语言翻回网络流，确认它**就是**一次增广，而且比"逐格重跑最大流"便宜得多。

见证指派 $a$ 对应网络里的一个满流 $f$：$f(S,R_i)=r_i$ 全部饱和、$f(C_j,T)=c_j$ 全部饱和、$f(R_i,C_j)=a_{i,j}$。删掉一个活格 $(i,j)$ 并把它的 $1$ 记成 $0$，等价于把这条边的流量撤掉：此时 $R_i$ 出现 $1$ 单位**过剩**、$C_j$ 出现 $1$ 单位**亏空**，其余点守恒。补回来就是在残量网络里找一条 $R_i\leadsto C_j$ 的有向路并推 $1$ 单位流量。

**引理 5（残量路径必然待在二分图内部）**

只要所有 $S\to R$ 边和所有 $C\to T$ 边都饱和，则 $S$ 在残量图中没有出边、$T$ 在残量图中没有入边；因此任何起点是行点、终点是列点的增广路径都不需要经过 $S$ 或 $T$。

**证明**：$S$ 的出边只有 $S\to R_k$，残量容量 $=r_k-f(S,R_k)=0$（饱和），故 $S$ 无出边——路径一旦到达 $S$ 就再也走不出去，$S$ 只能是起点，而我们的起点是行点，所以路径不含 $S$。同理 $T$ 的入边只有 $C_k\to T$，残量容量 $=c_k-f(C_k,T)=0$，故没有边能进入 $T$，$T$ 只能是终点，而我们的终点是列点 $C_j$，所以路径不含 $T$。$\blacksquare$

于是"在残量网络里找 $R_i\leadsto C_j$"完全等价于"在 $01$ 矩阵的活格上找那条交错路径"：行点出发的残量出边正是 $a_{u,v}=0$ 的格（前向边），列点出发的残量出边正是 $a_{u,v}=1$ 的格（后向边 $C_v\to R_u$）。实现时**不需要保存 $S,T$**，直接在二维数组上 BFS，翻转用 `pr/pc` 前驱还原（代码里的 `augp(si,tj)`）。

**锁 $1$ 的等价操作**：判定失败后本格必须是 $1$。流语言里要把这个 $1$ 永久固定：把边 $R_i\to C_j$ 连同它的两个残量方向一起删掉，并把 $S\to R_i$、$C_j\to T$ 的容量与流量**同时减 $1$**（这样两条边依然饱和、守恒依然成立，只是"欠账"少了一个）。矩阵语言里对应 `--rr[i]; --rc[j]; dead[i][j]=true;` —— 这正是代码中那一行的来源。锁 $0$ 则只需删边（容量已是 $1$、流量 $0$，删掉不影响守恒）。

**为什么不用"每格重跑一遍 Dinic"**：那要 $10^4$ 次建图+最大流；而这里只做 $1$ 次最大流，剩下 $10^4$ 次是 $O(nm)$ 的 BFS，且每次 BFS 命中即停。两种做法判定结果相同（都是引理 2 的满流判据），但增量版本把"流"的代价摊掉了，代码也更短——交错路径本质是**匈牙利算法在 $b$-匹配上的推广**。

**复杂度**：Dinic 在单位容量网络上的二分匹配型图上是 $O(E\sqrt V)$，这里 $E=O(nm),V=O(n+m)$，约 $10^4\times 15$；贪心阶段 $nm$ 格 $\times$ 每格 BFS $O(nm)$ = 最坏 $O((nm)^2)=10^8$ 次基本操作，实际上只有 $a_{i,j}=1$ 的格（共 $\sum r_i\le 10^4$ 个）需要 BFS，且多数 BFS 很早停止；内存 $O(nm)$。$n,m\le100$ 完全可接受。

### 2.6 溢出防护与实现细节（边界清点）

**会不会溢出**：$n,m\le100$ ⟹ $\sum r_i=\sum c_j\le 10^4$，单条边流量 $\le 100$，BFS/下标 $\le 10^4$。全部 $int$ 足够，无需 `i64`；代码仍按风格保留 `using i64=long long;` 以备扩展（若 $n,m$ 到 $10^3$，$\sum r$ 到 $10^6$ 仍安全；若要处理更大的数，只需把累加变量改成 `i64`）。

**数组尺寸（+5 松弛）**：`mxn{105}` 对应 $n,m\le100$；边池 `mxv{mxn*mxn*4}` 需容纳 $2(n+nm+m)\le 2(100+10000+100)=20400$ 条有向边，$105\cdot105\cdot4=44100$ ✓。点编号 $0..n-1$ 行、$n..n+m-1$ 列、$S=n+m$、$T=n+m+1$，$H/dis/cur$ 尺寸 `mxn*2+5=215\ge 202` ✓。

**必须显式初始化的地方（踩坑点）**：

1. 全局 `int H[]` 默认是 $0$，而前向星用 $-1$ 表示"无后继"，所以必须 `fill_n(H,n+m+2,-1)`，否则每个点的链表会串到边 $0$ 上，图直接错。
2. `dis[]` 是"未访问 $=\infty$"语义的数组，全局 `int` 默认 $0$ 会被当成距离 $0$ 的点，故 Dinic 每层 BFS 都要 `fill_n(dis,n+m+2,inf)`（风格指南的 INF 数组必须 `fill_n`）。
3. `vr/vc` 每次 BFS 前 `fill_n(...,0)`；`pr/pc` 只在对应点被访问时读，无需初始化。
4. `E[i^1]` 反边定址要求正反对连续存放（`addedge` 里两次 `ecnt++` 相邻）✓，因此 `ecnt` 必须从 $0$ 开始且不跳号。

**边界用例的行为**（详见 §4 的手算表）：$r_i=0$ 的行没有 $1$ 格可翻，全部走 `a=0 → 锁 0` 分支；$c_j=0$ 的列在残量图里既无入边 $1$ 格也走不通，BFS 自然失败/命中；$n=1$ 或 $m=1$ 时答案唯一（交错路径不存在），算法每格都判为"强制"，仍然正确；全零输入直接输出全零。

**无解输入**：题面保证有解，代码用 `assert(dinic()==sr&&sr==sc)` 兜住异常数据（洛谷默认不开 `NDEBUG`，assert 生效；正常数据不会触发）。

### 2.7 收尾检查：前缀封闭性 + 分规模的做法讨论

**引理 6（后续操作绝不改动已锁定的格）**

第 $p$ 格锁定后，之后所有翻转（`augp` 的路径取反）都只涉及读取顺序在 $p$ 之后的格。

**证明**：算法对每格只做两件事之一：把该格写死（$0$ 或 $1$）并置 `dead=true`；或在 `augp` 中翻转路径上的格。`augp` 的转移条件里显式检查 `!dead[u][v]`（行点出发）与 `!dead[w][v]`（列点后退），因此已锁定的格不可能成为路径上的边，其 `a` 值从此固定。又因为读取顺序是先 $(i,j)$ 后其右、其下所有格，被固定的恰是当前格之前的前缀。$\blacksquare$

这条引理是引理 1 能够"边算边定"的前提：若后面的重排会回头改前面的格，逐格贪心就没有意义了。它也解释了为什么锁 $1$ 时要顺手 `--rr[i],--rc[j]`——那个 $1$ 退出了活格计数，欠账必须同步下调，不变量才继续成立（§4.1 的不变量）。

**分规模讨论（如果数据范围变了怎么做）**

| 规模 | 可行做法 | 说明 |
|---|---|---|
| $n,m\le 4$（本文手算验证用的量级） | 直接字典序枚举所有 $\binom{m}{r_1}\cdots\binom{m}{r_n}$ 种行组合，取第一个满足列和的 | 用作正确性参照（本文没有运行，只手工穷举了 A–F 六组） |
| $n,m\le100$（本题） | 一次 Dinic + $nm$ 次交错路径 BFS，$O((nm)^2)$ | 本文实现 |
| $n,m\le100$、想省代码 | 每格重建网络跑一次满流判定，$10^4$ 次 Dinic | 判定结果与引理 3/4 完全等价（都是引理 2 的满流判据），只是常数大得多 |
| $n,m$ 到 $10^3$ 量级 | 需要把"逐格判定"换成"逐行判定"：一次给整行求字典序最小的可行行（对每个后缀位置做同样的交错 BFS），或用带禁位的 Gale–Ryser 型判据 | 本题不需要，仅作方向记录 |

## 3. 模式总结（Pattern Summary）

- **字典序 → 逐格决策 + 可行性预言机**：把"整体最小"换成"按读取顺序每格问一次'能不能取更小值'"，只要预言机精确，贪心即最优（引理 1 的标准交换/反证）。
- **简化版先解掉**：丢掉字典序，只判"行列和能否实现"，认出它是二分图度数序列 / $b$-匹配。
- **经典解法（网络流建模）**：$S\to R_i(r_i)\to C_j(1)\to T(c_j)$，整数最大流自动就是 $01$ 矩阵，容量 $1$ 的边直接当格子。
- **贪心失败剖析**：局部条件"这列还有需求"不等价于全局可行；一个格的选择会改变**别人**的可行域（反例 $r=(1,3),c=(2,1,1,0)$）。教训：构造题的贪心必须配精确判据。
- **经典解法（增量残量，不重算）**：算一次满流当"见证"，之后每格只问"能不能把这条边上的流量搬走"，即在残量图里找 $R_i\leadsto C_j$ 增广路，$10^4$ 次判定共享同一个流。
- **归约到更简单问题（残量路 → 交错路径）**：饱和的 $S$ 边/$T$ 边使残量路不可能经过源汇，于是网络流退化回 $01$ 矩阵上的"0 格前进 / 1 格后退"BFS（匈牙利算法的 $b$-匹配版），代码省掉动态图。
- **锁定技巧（固定答案位）**：判为强制 $1$ 时，删格的同时把行列的剩余需求各减 $1$，等价于把源汇边容量下调，保证不变量"活格里 $1$ 的个数 $=$ 还欠的个数"始终成立。
- **前缀封闭性验证**：任何"边算边定"的贪心都要单独证明后续操作不会回头改已定的位置（这里靠 `dead` 标记把翻转限制在之后的格，引理 6）。
- **双向证明充要条件**：路径存在 $\Rightarrow$ 能取 $0$（构造翻转）；能取 $0$ $\Rightarrow$ 路径存在（两个解的对称差 + 可达集出度入度求和）。判"不可能"必须靠后者。
- **分规模讨论**：$n,m\le100$ 允许 $O((nm)^2)$ 的逐格判定；若规模上一个量级就得把"逐格"升级成"逐行"，本题不必。
- **重复使用的同一技巧列两条**：交错路径 BFS 在"锁 $0$ 前的重排"和"初始构造"里是两件事（后者用 Dinic），不合并。
- **溢出防护**：先估 $\sum r_i\le 10^4$ 再决定用 $int$；顺带把全局数组的 $0$ 默认值坑（`H` 要 $-1$、`dis` 要 $\infty$）用 `fill_n` 补齐。
- **无样例时的自检手段**：手算穷举小数据（$n,m\le4$）+ 用引理 1 的"强制格"逻辑逐个推演，替代对拍。

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 初始化 | 记忆法 |
|---|---|---|---|
| `n,m` | 矩阵行列数 | 读入 | — |
| `r[i],c[j]` | 原始行/列需求 | 读入，同时累加 `sr,sc` | — |
| `S,T` | 源 $=n+m$、汇 $=n+m+1$ | 建图前赋值 | — |
| `E[],H[],ecnt` | 前向星边池 / 链头 / 边计数 | `fill_n(H,n+m+2,-1)`，`ecnt=0` | 反边 `E[i^1]` |
| `id[i][j]` | 格 $(i,j)$ 对应的**正向**边下标 | 建图时记录 | 读回答案用 |
| `dis[],cur[]` | Dinic 分层距离 / 当前弧 | 每轮 `fill_n(dis,...,inf)`、`memcpy` | — |
| `a[i][j]` | 当前见证指派的 $0/1$ 值；**已决策格即最终答案** | `a[i][j]=1-E[id[i][j]].w` | 残量 $0$ 即流量 $1$ |
| `dead[i][j]` | 该格是否已定（已从残量图删除） | 全局默认 $0$ | "dead = 不再参与交错路径" |
| `rr[i],rc[j]` | 该行/列在**活格**里还欠几个 $1$ | `rr=r`、`rc=c`；锁 $1$ 时各减 $1$ | 不变量：活格 $1$ 数 $=$ 欠账 |
| `vr[],vc[]` | 交错 BFS 中行点/列点是否已入队 | 每次 `fill_n(...,0)` | — |
| `pr[v]` | 到达列点 $v$ 的前驱**行**（经由 $0$ 格） | 访问时写 | path-row |
| `pc[u]` | 到达行点 $u$ 的前驱**列**（经由 $1$ 格） | 访问时写 | path-col |
| `qr[]` | 行点 BFS 队列（最多 $n$ 个行点） | — | queue-rows |

**核心不变量**（贯穿整个贪心）：任意时刻，把所有 `dead` 格按 `a` 的取值固定、活格按 `a` 的取值待定，就得到一个完整可行矩阵；并且对每个 $i,j$ 满足 $\sum_{\text{活格}(i,\ast)}a=rr_i$、$\sum_{\text{活格}(\ast,j)}a=rc_j$。初始由 Dinic 的满流给出，之后每步由引理 3/4 保证不被破坏。

### 4.2 编号步骤

1. 读入 $n,m,r,c$，累加 $sr,sc$。
2. 建三层网络：`addedge(S,i,r[i])`；对每格先 `id[i][j]=ecnt` 再 `addedge(i,n+j,1)`；最后 `addedge(n+j,T,c[j])`。建图前 `fill_n(H,n+m+2,-1)`。
3. `dinic()` 求最大流，`assert(dinic()==sr&&sr==sc)`（数据保证有解）。
4. 读回见证：`a[i][j]=1-E[id[i][j]].w`（单位边：残量 $0\Leftrightarrow$ 流量 $1$）；置 `rr[i]=r[i]`、`rc[j]=c[j]`。
5. 按行优先枚举每格 $(i,j)$：
   1. `dead[i][j]=true`（本格退出残量图）；
   2. 若 `a[i][j]==0`：答案即 $0$，直接 `continue`（欠账不变，不变量自动保持）；
   3. 否则调 `augp(i,j)`：在活格上从行点 $i$ 做交错 BFS（行点只走 $a=0$ 的格，列点只走 $a=1$ 的格），一旦命中列点 $j$ 就沿 `pr/pc` 回溯把路径取反并返回 `true`；
   4. `augp` 成功 $\Rightarrow$ `a[i][j]=0`（本格锁 $0$，行 $i$ 与列 $j$ 各在路径上补回一个 $1$）；
   5. `augp` 失败 $\Rightarrow$ 保留 `a[i][j]=1` 且 `--rr[i];--rc[j];`（强制 $1$，欠账各减 $1$）。
6. 输出 `a` 的 $n$ 行，每行 $m$ 个数以空格分隔、用 `'\n'` 换行。结束时 `rr,rc` 全为 $0$（活格集为空，由不变量得）。

### 4.3 复杂度

- 建图 $O(nm)$ 条边；Dinic 在单位容量的二分型网络上 $O(E\sqrt V)$，这里 $E=O(nm)=10^4$、$V=O(n+m)=200$。
- 贪心：$nm$ 格，每格至多一次交错 BFS，单次 $O(nm)$（每个点入队一次、每格至多被扫常数次）⟹ 最坏 $O\big((nm)^2\big)=10^8$；实际上只有 $a=1$ 的格（共 $\sum r_i\le10^4$ 个）需要 BFS，且命中即停。
- 内存：`a/dead/id` 各 $O(nm)$ 加边池 $O(nm)$，$<10\,\text{MB}$。

## 5. 示例代码

```cpp
// https://www.luogu.com.cn/problem/P1418  [TJOI2011] 构造矩阵
// Dinic 求出一个可行见证，再按行优先逐格用交错路径把 1 往后推，取字典序最小
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};
constexpr int mxv{mxn*mxn*4};            // 2*(n + n*m + m) <= 20400
constexpr int inf{1145141919};

int n,m,r[mxn],c[mxn];
int a[mxn][mxn];                         // current 0/1 assignment; decided cells hold the answer
bool dead[mxn][mxn];                     // cell removed from the residual graph
int rr[mxn],rc[mxn];                     // remaining 1s needed inside alive cells
int id[mxn][mxn];                        // edge index of cell (i,j)

struct{int v,w,nx;}E[mxv];
int H[mxn*2+5],ecnt,S,T;
void addedge(int u,int v,int w)
{
	E[ecnt]={v,w,H[u]};H[u]=ecnt++;
	E[ecnt]={u,0,H[v]};H[v]=ecnt++;
}

int dis[mxn*2+5],cur[mxn*2+5];
bool bfs_level()
{
	fill_n(dis,n+m+2,inf);
	dis[S]=0;
	queue<int>Q;
	Q.push(S);
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		for(int i=H[u];~i;i=E[i].nx)
			if(E[i].w&&dis[E[i].v]==inf)
			{
				dis[E[i].v]=dis[u]+1;
				Q.push(E[i].v);
			}
	}
	return dis[T]!=inf;
}
int dfs(int u,int f)
{
	if(u==T)
		return f;
	int res=0;
	for(int&i=cur[u];~i&&res<f;i=E[i].nx)
	{
		int v=E[i].v;
		if(E[i].w&&dis[v]==dis[u]+1)
		{
			int fl=dfs(v,min(f-res,E[i].w));
			E[i].w-=fl;
			E[i^1].w+=fl;
			res+=fl;
		}
	}
	return res;
}
int dinic()
{
	int flow=0;
	while(bfs_level())
	{
		memcpy(cur,H,sizeof(int)*(n+m+2));
		while(int aug=dfs(S,inf))
			flow+=aug;
	}
	return flow;
}

bool vr[mxn],vc[mxn];
int pr[mxn],pc[mxn],qr[mxn];             // alternating path row->col->row...
bool augp(int si,int tj)
{
	fill_n(vr,n,0);
	fill_n(vc,m,0);
	int qh=0,qt=0;
	qr[qt++]=si;
	vr[si]=true;
	while(qh<qt)
	{
		int u=qr[qh++];
		for(int v=0;v<m;++v)
		{
			if(vc[v]||dead[u][v]||a[u][v])
				continue;                // forward: only 0-cells
			vc[v]=true;
			pr[v]=u;
			if(v==tj)
			{
				int row=pr[tj],col=tj;
				while(true)
				{
					a[row][col]^=1;      // 0 -> 1
					if(row==si)
						break;
					col=pc[row];
					a[row][col]^=1;      // 1 -> 0
					row=pr[col];
				}
				return true;
			}
			for(int w=0;w<n;++w)
			{
				if(vr[w]||dead[w][v]||!a[w][v])
					continue;            // backward: only 1-cells
				vr[w]=true;
				pc[w]=v;
				qr[qt++]=w;
			}
		}
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	int sr=0,sc=0;
	for(int i=0;i<n;++i)
	{
		cin>>r[i];
		sr+=r[i];
	}
	for(int j=0;j<m;++j)
	{
		cin>>c[j];
		sc+=c[j];
	}
	S=n+m;T=n+m+1;
	fill_n(H,n+m+2,-1);
	for(int i=0;i<n;++i)
		addedge(S,i,r[i]);
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
		{
			id[i][j]=ecnt;
			addedge(i,n+j,1);
		}
	for(int j=0;j<m;++j)
		addedge(n+j,T,c[j]);
	assert(dinic()==sr&&sr==sc);         // data guarantees solvability
	for(int i=0;i<n;++i)
	{
		rr[i]=r[i];
		for(int j=0;j<m;++j)
			a[i][j]=1-E[id[i][j]].w;     // unit edge: residual 0 <=> flow 1
	}
	for(int j=0;j<m;++j)
		rc[j]=c[j];
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
		{
			dead[i][j]=true;
			if(!a[i][j])
				continue;                // 0 costs nothing
			if(augp(i,j))
				a[i][j]=0;               // rerouted, cell stays 0
			else
			{
				--rr[i];
				--rc[j];                 // forced 1, demand consumed
			}
			// cerr<<i<<' '<<j<<' '<<a[i][j]<<'\n';
		}
	for(int i=0;i<n;++i)
		assert(!rr[i]);                  // no alive cell left -> nothing owed
	for(int j=0;j<m;++j)
		assert(!rc[j]);
	for(int i=0;i<n;++i)
	{
		for(int j=0;j<m;++j)
			cout<<a[i][j]<<' ';
		cout<<'\n';
	}
	return 0;
}
```

> 代码里 `dead` 与 `a` 共用一份 `a`：已决策格的 `a` 值就是最终答案，交错翻转只碰 `!dead` 的格（引理 6），所以输出时直接整表打印。
