# P1617 爱与愁的一千个伤心的理由

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给定 $0\le n\le9999$，把 $n$ 用标准美式英语写出来：单词之间用空格分隔，二十一至九十九用连字符（如 `twenty-one`），行首不大写，行末不加句号。题面额外规定：**只有末两位不超过 $10$ 时才加 `and`**，且这种情形下不加连字符。

这是一个纯粹的输出格式题，难点全在"边界上到底加不加 `and`"以及"某个数位为零时省不省词"。

### 输入输出格式

- **输入格式**：一行一个整数 $n$。
- **输出格式**：一行，$n$ 的英文写法。
- **数据规模**：$n\le9999$。

### 关键约束分析

1. $n$ 最多四位，英文写法最多由"千位 + 百位 + 末两位"三段拼成，段数极少，可以按位硬分类。
2. 边界值密集：$0$（`zero`）、$10$（`ten`，不能写成 `one zero` 或 `ten-`）、$11\sim19$（不规则词）、$20$（`twenty`，不能带连字符）、$21$（`twenty-one`）、$100$（`one hundred`，末尾不能多出 `and`）、$1000$（`one thousand`）。
3. "末两位不超过 $10$"这个区间是**闭**的：$101$、$110$ 都加 `and`，而 $111$ 起就不加。把 $10$ 分错边是最常见的 WA。
4. 末两位为 $00$ 时（如 $100$、$1000$、$1200$）不产生任何词，自然也不会加 `and`。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：先看能不能"查表"

$0..9999$ 只有一万个数，理论上可以把答案全打表，但表有几万字符，既丑又容易错，且不能体现结构。更有价值的问题是：这些字符串有没有统一的构造规律？

把 $n$ 写成

$$n=1000\cdot th+100\cdot hu+tail,\qquad 0\le th,hu\le 9,\ 0\le tail\le 99 .$$

**引理 1（三段分解唯一）**：上述 $th,hu,tail$ 存在且唯一。

*证明*：由带余除法，$tail=n\bmod 100$、$q=\lfloor n/100\rfloor$ 唯一；再对 $q$ 取 $hu=q\bmod 10$、$th=\lfloor q/10\rfloor$。因 $n\le9999$，$q\le99$，故 $th,hu\in[0,9]$。唯一性由每步带余除法唯一性传递得到。$\square$

于是"写一个数"变成"写三个小段"，再用空格连起来。

### 第二步：把 1..99 彻底解决

末两位是唯一不规则的部分，按四种情况分类：

- $1\le x\le9$：直接查 `one..nine`；
- $10\le x\le19$：查 `ten..nineteen`（十三个不规则词整体记忆）；
- $x\in\{20,30,\dots,90\}$：查 `twenty..ninety`，不带连字符；
- 其余（$21\sim99$ 且非整十）：`tens[x/10]` + `-` + `ones[x%10]`。

**引理 2（1..99 的四类划分是完备且互斥的）**：任意 $x\in[1,99]$ 恰落入上述四类之一，且输出唯一。

*证明*：若 $x<10$ 落第一类；若 $10\le x<20$ 落第二类；若 $x\ge20$：$x\bmod10=0$ 落第三类，否则落第四类。四个条件两两互斥（区间互不相交、同区间内又按 $x\bmod10$ 是否为零二分），并集覆盖 $[1,99]$。每类内部由数组下标唯一确定词形，故输出唯一。$\square$

### 第三步：`and` 到底插在哪

题面给了两条互相印证的说明：

1. "仅在末两位 $\le10$ 时加 `and` 且没有连字符"；
2. "两个非零的数中间没零则不加 `and`"。

第 2 条的意思是：只有出现"零的空档"时才需要 `and` 来连接。观察三段结构，百位或千位写完后若直接跟末两位，中间是否出现过零：

- 末两位 $\in[11,99]$：末两位自己是一个整体词（`eleven`、`thirty-four`），它与前面的 `hundred` / `thousand` 之间没有零的空档，故不加 `and`——与第 1 条 $\le10$ 才加一致。
- 末两位 $\in[1,10]$：这正是"个位非零但十位为零"（或整体就是一个 teens 词）的情形，出现了零的空档，故加 `and`。

**引理 3（插入条件）**：设已经写出了千位或百位（即 `ans` 非空），则当且仅当 $tail\in[1,10]$ 时需要在 `tail` 前加 `and `。

*证明*：$tail\in[1,10]$ 时十位数字为 $0$ 而个位（或整个 $tail=10$）非零，前后两个非零部分之间隔着零，按第 2 条必须加 `and`；$tail\in[11,99]$ 时 $tail$ 作为整体紧接前一段，中间无零，按第 2 条不加。$tail=0$ 时根本没有后一段，无所谓加。反过来，若 $tail\in[1,10]$ 却不加 `and`，则与题面第 1 条直接冲突。$\square$

**引理 4（$10$ 必须归入加 `and` 的一侧）**：$tail=10$ 时输出必须形如 `one hundred and ten`。

*证明*：题面写的是"末两位 $\le10$"，闭区间包含 $10$；又因 `ten` 是单个词、内部不含连字符，同时满足"没有连字符"这半句。若把 $10$ 归到 $>10$ 一侧，则 $101$ 加 `and` 而 $110$ 不加，与题面的闭区间表述矛盾。$\square$

### 第四步：空串的特殊情况

若 $n=0$，三段全为零，拼接结果为空串，必须特判输出 `zero`。$n>0$ 时至少有一段非空，不会出现空输出。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 数位分段后，"写数"退化为"写三个小段再拼接"。
- `consider easier version` — 先只解决 $1..99$，把不规则词全部封进三张表。
- `classic problem solution` — 按"个位 / 十几 / 整十 / 带连字符"四类分别查表。
- `explore its property` — 把题面两句 `and` 规则翻译成"末两位是否落在 $[1,10]$"这一单一判据。
- `discuss by category` — 单独讨论全零（$n=0$）与末两位为 $00$ 两种退化情形。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $n$ | `n` | 待转换的整数，$0\le n\le9999$ |
| $th$ | `r/1000`（先算） | 千位数字，仅当 $n\ge1000$ 时输出 |
| $hu$ | `r/100`（取模后） | 百位数字，仅当非零时输出 |
| $tail$ | `r` | 处理完千位与百位后剩下的末两位 |
| 结果串 | `ans` | 逐步拼接的英文结果，初值为空串 |
| 个位表 | `dig[]` | `zero..nine`，下标即数字，`dig[0]` 仅供 $n=0$ 的兜底使用 |
| 十几表 | `tee[]` | `ten..nineteen`，下标为 $x-10$ |
| 整十表 | `ten[]` | 下标 $1..9$ 对应 `ten..ninety`，下标 $0,1$ 留空不用 |
| 两位数函数 | `w2(x)` | 返回 $x\in[1,99]$ 的英文写法（含连字符规则） |

### 算法步骤

1. 读入 $n$，令 `r=n`、`ans` 为空串。
2. 若 $r\ge1000$：`ans = dig[r/1000] + " thousand"`，然后 `r %= 1000`。
3. 若 $r\ge100$：`ans` 非空时先补一个空格，再拼 `dig[r/100] + " hundred"`，然后 `r %= 100`。
4. 若 $r>0$：若 `ans` 非空，按引理 3 决定补 `" and "`（$r\le10$）还是 `" "`（$r\ge11$）；再拼 `w2(r)`。
5. 若 `ans` 仍为空（即 $n=0$），令 `ans="zero"`。
6. 输出 `ans` 并换行。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}(1)$，最多拼接四段常量长度的字符串。
- **空间复杂度**：$\mathcal{O}(1)$，只用到三张常量表和长度不超过三十的 `ans`。

### 正确性验证

引理 1 保证三段分解唯一，引理 2 保证末两位的写法唯一且无遗漏，引理 3 与引理 4 保证 `and` 的插入位置与题面两条描述一致，第四步兜住 $n=0$ 的空串。四步拼接顺序（千 → 百 → 末两位）与英文语序一致，故输出即为所求。数值上不涉及任何算术，无溢出风险。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1617 爱与愁的一千个伤心的理由
// https://www.luogu.com.cn/problem/P1617
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

const char*dig[]{"zero","one","two","three","four","five","six","seven","eight","nine"};
const char*tee[]{"ten","eleven","twelve","thirteen","fourteen","fifteen","sixteen","seventeen","eighteen","nineteen"};
const char*ten[]{"","","twenty","thirty","forty","fifty","sixty","seventy","eighty","ninety"};

string w2(int x)                   // 1..99 的英文写法，21..99 用连字符
{
	if(x<10)
		return dig[x];
	if(x<20)
		return tee[x-10];
	if(x%10==0)
		return ten[x/10];
	return string(ten[x/10])+"-"+dig[x%10];
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	string ans;
	int r=n;
	if(r>=1000)
	{
		ans=string(dig[r/1000])+" thousand";
		r%=1000;
	}
	if(r>=100)
	{
		if(!ans.empty())
			ans+=" ";
		ans+=string(dig[r/100])+" hundred";
		r%=100;
	}
	if(r>0)
	{
		// 末两位不超过 10 才加 and，其余情况只留空格
		if(!ans.empty())
			ans+=(r<=10?" and ":" ");
		ans+=w2(r);
	}
	if(ans.empty())
		ans="zero";
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **$10$ 的分界**：`r<=10` 才是加 `and` 的一侧，写成 `r<10` 会让 $110$、$1010$ 之类少一个 `and`。
2. **$n=0$**：不特判会输出空行。
3. **`twenty` 不能带连字符**：整十必须走 `x%10==0` 分支。
4. **`hundred` / `thousand` 后的空格**：先补分隔空格再拼词，别漏掉 `one thousand two hundred` 中间那个空格。
5. **末两位为 $00$**：此时 `r==0`，完全跳过第 4 步，不能额外输出 `and`。
6. **`dig[0]`**：只在 $n=0$ 时应当体现 `zero`，但那是靠第 5 步兜底，不是靠千位/百位分支。
