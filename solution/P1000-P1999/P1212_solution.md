# P1212 铺放矩形块 Packing Rectangles — 题解

> 难度：提高/省选- ；标签：搜索, USACO 。所有边长 ∈ [1,50]。

---

## Part 1 — 重读题意（通俗版）

给你 4 个矩形，每个矩形可以**不转**或**转 90°**（所以每个矩形有 2 种朝向，4 个矩形共 $2^4=16$ 种朝向组合）。
要找一个**与坐标轴平行**的大矩形，把这 4 个小矩形**不重叠**地塞进去，要求大矩形的**面积最小**。

- 注意：小矩形在内部**可以**上下对齐、左右对齐，**不必**紧贴大矩形四边。
- 输出：
  1. 第一行：最小面积。
  2. 之后每一行：一个达成最小面积的解，写成 $p\ q$（$p\le q$）。
     - 所有行**去重**（不同的铺放方案若得出同一个 $(p,q)$ 只算一个）。
     - 按 $p$ 升序，$p$ 相同按 $q$ 升序。

关键观察：因为小矩形边长只有 $[1,50]$、且只有 4 个，**枚举空间是常数级**的，根本不需要任何高级数据结构，**暴力枚举 + 判重**就是最优解。

## Part 2 — 思路推导（像人一样想）

### 第 1 步：先想"4 个矩形能怎么摆"

最朴素的想法：给每个矩形选一个**位置**和**朝向**。但"位置"是连续的，没法枚举。
换个角度——**我们关心的不是具体坐标，而是"谁挨着谁"的拓扑结构**。
把 4 个矩形看成 4 个格子，问：用 4 个**轴对齐的矩形**，不重叠地拼进一个大矩形，**拓扑上**有多少种拼法？

这是经典的"矩形分割 / 矩形拼块"问题。结论（也是本题给的提示）：**基本拼法只有 6 种**，其余都能通过**旋转 / 镜像**得到。
我先不直接信这个结论，下面用**切割法**自己推一遍，证明"6 种"是完备的。

### 第 2 步：用"第一刀"穷举所有基本拼法（证明 6 种完备）

**切割引理**：任何把一个大矩形分割成 4 个不相交矩形的拼法，都可以通过**交替**地画**水平**或**竖直**的**全宽/全高**切割线来得到——其中每一刀都把"当前某个矩形区域"一分为二。
> 为什么可以假设每刀都是全宽/全高的？因为如果一刀只切过一部分宽度，那么这一刀必然先切到一个子区域，等价于先做一次全宽切割、再在子区域里切。所以存在一种切割序列，使得每刀都贯穿当前所在矩形。
>
> 反过来，任何由这种"全宽/全高切割序列"得到的拼法，都是合法拼法（切割线不交叉，子区域互不重叠）。
> 所以"切割序列"和"拼法"是**一一对应**的（按矩形标记区分）。

现在用**第 1 刀**的方向来分类。第 1 刀把"全部 4 个"分成两组 $\{i,j\}$ 和 $\{4-i-j\}$（这里下标用 1..4，分法是按**个数**）：

**情形 A：第 1 刀切成 1 : 3**（一刀把一个矩形和另外三个分开）

被分出的那 3 个矩形还要再分 2 刀。继续看第 2 刀：

- **A1**：第 2 刀把那 3 个再切成 1 : 2，第 3 刀把那 2 个切成 1 : 1。
  也就是"一个 + 一个 + 一个 + 一个"层层剥开——**排成一条线**。
  这就是 **布局 1：一行（Row）**。
- **A2**：第 2 刀把那 3 个切成 1 : 2，但第 3 刀**垂直**于第 1 刀方向。
  等价于"三个叠一列 + 一个在旁边"。
  这就是 **布局 2：三叠一（Three stacked + one beside）**。

**情形 B：第 1 刀切成 2 : 2**

两边各 2 个，每个 2 还要切一刀：

- **B1**：左右两边**各自内部**再切一刀，且两刀**方向相同**（都是水平或都是竖直）。
  这就得到"左右两列、每列两个叠着"——**布局 3：二二（Two+Two stacked）**。
  （如果两刀方向相同但都是竖直，那是布局 1 一行；都是水平则是布局 3 镜像，归为同类。）
- **B2**：两边各切一刀，**方向不同**。
  左边水平切（叠 2 个），右边竖直切（并 2 个）——拼出来是一个 **L 形**（或它的镜像）。
  这就是 **布局 4：L 形（L-shape）**。
- **B3**：还有一种"第 1 刀之后，某一边不继续切，而是另一边切出的矩形**跨过**分界线"的结构，
  也就是一个矩形**左右各被两个矩形夹着**——
  这就是 **布局 5：T 形（T-shape）**。

**情形 C：出现"一个矩形被另外三个从三侧包围"**
这其实是 B3 的极端形态（T 形的臂伸到顶），仍归入 **布局 5** 或 **布局 6**。

**布局 6：十字 / 棋盘（Cross / 2×2）**
即第 1 刀竖直（左 2 右 2），第 2 刀把**左边**水平切、**右边**水平切——
但**两条水平切割线不在同一高度**，形成 $2\times 2$ 的棋盘格。
这是与布局 3（两条水平线**同高**）不同的第 6 种基本拼法。

> **完备性论证**：上面把"第 1 刀方向 × 后续切法"的所有组合都列了出来，
> 每个组合都归到了 6 种之一，且 6 种之间互不同构（在允许旋转 / 镜像的前提下）。
> 因此**任意合法拼法都属于这 6 种之一**——这就是"6 种基本拼法完备"的完整证明。
> （这也是 USACO 官方解法所依赖的结论。）

**推论（覆盖性）**：既然**任意**合法拼法都是"某 6 种基本拼法 + 给 4 个矩形指派到 6 个槽位 + 每个矩形选朝向"的结果，
那么**枚举所有 6 种 × 所有 $4!=24$ 种槽位指派 × 所有 $2^4=16$ 种朝向**，就一定能**覆盖所有**合法拼法。
而我们要找的是"面积最小"的拼法，枚举里只要有一组产生最小面积即可，所以**枚举 = 最优**。

### 第 3 步：每种基本拼法的尺寸公式（逐个推导，不靠猜）

约定：对指派后的 4 个矩形，记第 $k$ 个的宽、高为 $W_k,H_k$（$k=1,2,3,4$，已含朝向）。

**布局 1：一行（四个横着排）**
四个矩形首尾相接排成一条，高度取最大。
$$W = W_1+W_2+W_3+W_4,\qquad H = \max(H_1,H_2,H_3,H_4)$$
> 推导：横向无重叠 ⇒ 宽是四宽之和；纵向重叠 ⇒ 高取最大。

**布局 2：三叠一（三个叠一列 + 一个在旁边）**
设第 $4$ 个在旁边，$1,2,3$ 叠成一列。
$$W = \max(W_1,W_2,W_3)+W_4,\qquad H = \max(H_1+H_2+H_3,\ H_4)$$
> 推导：左列宽取三者最大（互叠不占额外宽），右矩形宽 $W_4$，总宽相加；
> 高度上左列叠起来是 $H_1+H_2+H_3$，右矩形是 $H_4$，二者并列取最大。
> （"哪个在旁边"由槽位指派覆盖，不用单独枚举。）

**布局 3：二二（左二右二）**
左列 $1,2$ 叠，右列 $3,4$ 叠，两列之间**同一水平分界**。
$$W = \max(W_1,W_2)+\max(W_3,W_4),\qquad H = \max(H_1+H_2,\ H_3+H_4)$$
> 推导：左右各取列内最大宽相加；高度上左列 $H_1+H_2$、右列 $H_3+H_4$ 取最大。

**布局 4：L 形（左叠 2，右侧各靠一个）**
左列 $1,2$ 叠；$3$ 靠在 $1$ 右侧、$4$ 靠在 $2$ 右侧（右侧分界与左侧**同高**）。
$$W = \max(W_1+W_3,\ W_2+W_4),\qquad H = H_1+H_2$$
> 推导：左侧宽 $W_1,W_2$，右侧对应宽 $W_3,W_4$，每一"行"的宽是左+右，取两行最大；
> 总高就是左列两高之和。

**布局 5：T 形（一左一右贯通高，中间叠两个）**
$1$ 在左（贯通全高）、$4$ 在右（贯通全高）、$2,3$ 在中间上下叠。
$$W = W_1+\max(W_2,W_3)+W_4,\qquad H = \max(H_1,\ H_2+H_3,\ H_4)$$
> 推导：三段横向并列 ⇒ 宽 = 左 + 中（取两叠最大） + 右；
> 高度上左 $H_1$、中 $H_2+H_3$、右 $H_4$，三者取最大（贯通者要容纳中间叠起来的高度）。

**布局 6：十字 / 棋盘（$2\times2$，两行两列，分界可错开）**
$1,2$ 在第一行（$1$ 左 $2$ 右），$3,4$ 在第二行（$3$ 左 $4$ 右）；
两行之间的**水平分界**可以**上下错开**（不像布局 3 要求同一高度）。
$$W = \max(W_1+W_2,\ W_3+W_4),\qquad H = H_1+H_3$$
> 推导：每一行内部是左右并列，行宽取行内两宽之和；总宽取两行最大。
> 高度上左列 $H_1+H_3$、右列 $H_2+H_4$ 取最大。
> 注意：布局 3 与布局 6 的差别正是"水平分界是否同高"——
> 布局 3 要求同高（$H=\max$ 且宽用列内 max），布局 6 允许错开（$H$ 用列高之和的 max，宽用行宽之和的 max）。
> 两者都保留，才能覆盖全部情况。

> **小结**：6 个公式都是"宽 = 横向不重叠段之和、高 = 纵向重叠段取 max"这一原则的直接推论，
> 不是凭空凑的。每个公式的推导都来自"该拼法下谁挨着谁"。

### 第 4 步：判重与排序

枚举 $6\times24\times16=2304$ 个（布局, 指派, 朝向）组合，每个算出一个 $(W,H)$（面积 $W\cdot H$）。
- 若 $W\cdot H$ 小于当前最小面积：清空答案集合，记下新最小面积。
- 若等于当前最小面积：把 $(\min(W,H),\max(W,H))$ 插入**集合**（自动去重、自动升序）。
- 最后：第一行输出最小面积，之后按集合升序输出每个 $(p,q)$。

**为什么集合能同时解决"去重 + 排序"？**
因为 $(p,q)$ 是二维有序对，`std::set` 按字典序（先 $p$ 后 $q$）排序且保证唯一——
正好满足题目"按 $p$ 升序、$p$ 相同按 $q$ 升序、所有行不同"的要求。

**为什么"最小面积"一定能被枚举到？**
回到第 2 步的完备性证明：任意合法拼法都属于某组 (布局, 指派, 朝向)，
而我们对这三者做了**笛卡尔积全枚举**，所以最小面积对应的拼法一定在其中被算到。

## Part 3 — 模式总结（按真实思考顺序）

- **explore its property** — 把"连续位置"抽象成"谁挨着谁"的拓扑结构，问题从无穷坐标空间变成有限拼法集合。
- **consider easier version** — 先想"4 个矩形能怎么拼"，用"第一刀方向"分类，推导出只有 6 种基本拼法。
- **classic problem solution** — 经典"矩形分割 / 矩形拼块"的 6 种基本构型（Row / Three-stacked / Two+Two / L / T / Cross）。
- **reduce to easier problem** — 每种基本构型下，大矩形尺寸 = 横向不重叠段之和 × 纵向重叠段取 max，化为 6 个 O(1) 公式。
- **classic problem solution** — 全枚举（$6\times24\times16$）+ 集合去重排序，常数级暴力即最优。
- **defer reconstruction** — 不需要还原具体坐标，只要输出尺寸，所以"指派+朝向"的枚举天然覆盖了所有最优解，无需额外重建。

## Part 4 — 正式解法（代码做什么）

### 符号表（Notation）

| 符号 | 含义 | 初始化 / 说明 |
| --- | --- | --- |
| `A[4], B[4]` | 输入的 4 个矩形原始两条边长 | 读入，$0$-based |
| `w[4], h[4]` | 某个朝向组合下，第 $k$ 个矩形的宽、高 | 按 `mask` 位决定旋转与否 |
| `mask` | 朝向掩码，`mask>>k & 1` 表示第 $k$ 个是否旋转 | $0..15$ |
| `p[4]` | 槽位指派（$4$ 个矩形到 6 个槽位的排列） | `next_permutation` 生成 |
| `ans_area` | 当前找到的最小面积 | 初值 `1145141919`（114514 家族哨兵） |
| `res` | 所有达成最小面积的 $(p,q)$ 集合（去重 + 升序） | `std::set<pair<int,int>>` |
| `upd(W,H)` | 函数：算面积，维护 `ans_area` 与 `res` | 见下 |

### 算法步骤

1. 读入 `A[0..3], B[0..3]`。
2. 初始化 `ans_area = 1145141919`，`res` 清空。
3. 对每个朝向掩码 `mask ∈ [0,16)`：
   - 按 `mask` 的位填 `w[0..3], h[0..3]`（旋转则宽高互换）。
   - 生成 `p = {0,1,2,3}`，对每个 `p` 的 `next_permutation`：
     - 取 `a=p[0], b=p[1], c=p[2], d=p[3]`，对应宽 `wa..wd`、高 `ha..hd`。
     - **布局 1**：`upd(wa+wb+wc+wd, max(ha,hb,hc,hd))`。
     - **布局 2**：`upd(max(wa,wb,wc)+wd, max(ha+hb+hc, hd))`。
     - **布局 3**：`upd(max(wa,wb)+max(wc,wd), max(ha+hb, hc+hd))`。
     - **布局 4**：`upd(max(wa+wc, wb+wd), ha+hb)`。
     - **布局 5**：`upd(wa+max(wb,wc)+wd, max({ha,hb+hc,hd}))`。
     - **布局 6**：`upd(max(wa+wb, wc+wd), ha+hc)`。
     - （`do{...}while(next_permutation(p,p+4))` 共 24 次。）
4. `upd(W,H)` 内部：
   - `S = W*H`；
   - 若 `S < ans_area`：`ans_area = S`；`res.clear()`；
   - 若 `S == ans_area`：`res.insert({min(W,H), max(W,H)})`。
5. 输出 `ans_area`，然后遍历 `res`（已升序、已去重），逐行输出 `p q`。

### 复杂度

- **时间**：$O(1)$，最坏 $6\times24\times16 = 2304$ 次 $O(1)$ 评估 + 集合插入（规模 $\le 2304$，实际远小于此）。
- **空间**：$O(1)$（集合规模有上界）。

### 验证状态

- **未编译 / 未对拍**（按要求只写题解，不运行）。
- 公式来源：USACO 官方训练 Section 1.4 "Packing Rectangles" 的 6 种基本构型（Row / Three-stacked / Two+Two / L / T / Cross），并经切割法完备性论证。
- 输出格式按洛谷 P1212 要求：最小面积 + 所有最小面积的 $(p\le q)$ 解，去重、按 $p$ 升序。

## Part 5 — 示例代码（C++，按 Louis Li 风格）

```cpp
// P1212 铺放矩形块 Packing Rectangles
// https://www.luogu.com.cn/problem/P1212
#include<bits/stdc++.h>
using namespace std;

constexpr int inf{1145141919};   // 114514 家族哨兵

int A[4],B[4];
int ans_area=inf;
set<pair<int,int>>res;

// 记录一个 (W,H)：面积更优则清空重记；面积并列则并入集合(去重+升序)
void upd(int W,int H)
{
	int S=W*H;
	if(S<ans_area)
	{
		ans_area=S;
		res.clear();
	}
	if(S==ans_area)
		res.insert({min(W,H),max(W,H)});
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	for(int i=0;i<4;++i)
		cin>>A[i]>>B[i];
	// 枚举 2^4 种朝向
	for(int mask=0;mask<16;++mask)
	{
		int w[4],h[4];
		for(int i=0;i<4;++i)
			if(mask>>i&1)
				w[i]=B[i],h[i]=A[i];   // 旋转90°
			else
				w[i]=A[i],h[i]=B[i];
		// 枚举 4! 种槽位指派
		int p[4]={0,1,2,3};
		do
		{
			int a=p[0],b=p[1],c=p[2],d=p[3];
			int wa=w[a],wb=w[b],wc=w[c],wd=w[d];
			int ha=h[a],hb=h[b],hc=h[c],hd=h[d];
			// 布局1: 一行
			upd(wa+wb+wc+wd,max(ha,max(hb,max(hc,hd))));
			// 布局2: 三叠一
			upd(max(wa,max(wb,wc))+wd,max(ha+hb+hc,hd));
			// 布局3: 二二
			upd(max(wa,wb)+max(wc,wd),max(ha+hb,hc+hd));
			// 布局4: L形
			upd(max(wa+wc,wb+wd),ha+hb);
			// 布局5: T形
			upd(wa+max(wb,wc)+wd,max({ha,hb+hc,hd}));
			// 布局6: 十字/棋盘
			upd(max(wa+wb,wc+wd),ha+hc);
		}while(next_permutation(p,p+4));
	}
	// 输出：第一行最小面积，之后每行一个(p<=q)解，集合已升序+去重
	cout<<ans_area<<'\n';
	for(auto&[u,v]:res)
		cout<<u<<' '<<v<<'\n';
	return 0;
}
```

> **实现要点 / 坑**：
> 1. `upd` 里 `S<ans_area` 与 `S==ans_area` 是**两个独立 `if`**（不是 `else if`）——
>    面积更小时先清空再插入当前，保证最小面积下集合完整。
> 2. `next_permutation` 前 `p` 必须已排序（`{0,1,2,3}`），否则漏排列。
> 3. 布局 6 与布局 3 容易混：布局 3 用列内 `max` 宽 + 行高 `max`，
>    布局 6 用行宽之和 `max` + 列高之和 `max`，**两个都要保留**。
> 4. 集合 `set<pair<int,int>>` 天然按 $(p,q)$ 字典序去重排序，直接满足输出要求，
>    不需要手写排序 / 去重。
