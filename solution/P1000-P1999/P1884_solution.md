# P1884 [USACO12FEB] Overplanting S

## 1. 重新读题

### 1.1 问题重述（人话版）

平面上有 $N$ 个边平行于坐标轴的矩形。第 $i$ 个矩形用「左上角 $(x_1,y_1)$、右下角 $(x_2,y_2)$」描述（$Y$ 轴向上为正，所以 $y_1>y_2$）。求这 $N$ 个矩形覆盖的并集面积，被重复覆盖的区域只算一次。输出一个整数。

### 1.2 关键约束与规模暗示

- $N\le 1000$。把问题放大看：矩形边界只会出现在 $2N$ 条竖线和 $2N$ 条横线上，因此平面被切成至多 $(2N-1)^2\approx 4\times 10^6$ 个小格子。$O(N^2)$ 量级可行，$O(2^N)$ 的容斥绝无可能。
- 坐标满足 $|x|,|y|\le 10^8$。直接开大小为 $10^8$ 的二维数组不可能，必须压缩坐标；同时也说明任意两点的坐标差最大 $2\times 10^8$，一格面积可达 $4\times 10^{16}$，**面积必须用 `long long`**，而覆盖次数不超过 $N=1000$，用 `int` 足够。
- 输入给的是左上、右下，$y_1>y_2$。虽然按题面可直接用，但代码里统一取 $\min/\max$ 更稳，也顺便兼容坐标写反的情况。
- 输出是整数：所有格子边界都是整数坐标，每个被覆盖格子的宽高都是整数，故面积天然是整数，不存在浮点误差问题。

---

## 2. 思维链（Chain-of-thought）

### 2.1 第一次尝试：直接求和——被重叠打败

如果所有矩形互不相交，答案就是 $\sum (x_2-x_1)(y_1-y_2)$，一眼可做。但两个矩形只要有一块公共区域，直接相加就会把这块面积算两遍。

补救的第一反应是容斥：$|A\cup B|=|A|+|B|-|A\cap B|$，对 $N$ 个矩形枚举 $2^N$ 个子集做容斥。$N\le 1000$ 时 $2^{1000}$ 是天方夜谭，这条路封死。

### 2.2 探索性质：真正决定答案的只有「边界线」

放弃按矩形计数，改为按**平面上的点**计数：一个点被覆盖的充要条件是它落在至少一个矩形里。所有矩形的边都在以下 $4N$ 条直线上：

$$
x=x_1,\quad x=x_2,\quad y=y_1,\quad y=y_2\quad(1\le i\le N).
$$

于是得到一个关键直觉：**只要不跨过任何一条边界线，覆盖情况就不会变化**。整个平面被这些直线切成一张「棋盘」，同一个格子内部要么整块被覆盖，要么整块没被覆盖。这正是坐标压缩的用武之地。

### 2.3 引理 1（压缩单元内部覆盖状态恒定）

**引理 1.** 设所有出现过的 $x$ 坐标去重排序为 $x_0<x_1<\cdots<x_{cx-1}$，$y$ 坐标去重排序为 $y_0<\cdots<y_{cy-1}$。对任意 $0\le i<cx-1$、$0\le j<cy-1$，开格子

$$
U=(x_i,x_{i+1})\times(y_j,y_{j+1})
$$

内的所有点被同一个矩形集合覆盖。

**证明.** 固定一个矩形 $R=[X_l,X_r]\times[Y_b,Y_t]$（其中 $X_l,X_r$ 来自压缩后的 $x$ 坐标集合，$Y_b,Y_t$ 来自压缩后的 $y$ 坐标集合）。点 $(x,y)$ 被 $R$ 覆盖当且仅当

$$
X_l\le x\le X_r\quad\text{且}\quad Y_b\le y\le Y_t.
$$

假设存在 $P,Q\in U$，$R$ 覆盖 $P$ 但不覆盖 $Q$。在线段 $PQ$ 上把参数记为 $t\in[0,1]$，考虑四个关于 $t$ 的连续函数

$$
x(t)-X_l,\quad X_r-x(t),\quad y(t)-Y_b,\quad Y_t-y(t).
$$

$P$ 处四个值都 $\ge 0$，$Q$ 处至少一个为负。由连续性，这个函数必在某点 $t_0$ 处取 $0$，即该点的横坐标为 $X_l$ 或 $X_r$，或纵坐标为 $Y_b$ 或 $Y_t$。

另一方面，$U$ 是开格子，其 $x$ 坐标严格介于 $x_i$ 与 $x_{i+1}$ 之间，而 $X_l,X_r$ 都是某个 $x_k$，不可能落在这个开区间内部（否则 $x_i<x_k<x_{i+1}$，与相邻压缩坐标之间没有其它出现过的坐标矛盾）；$y$ 方向同理。矛盾。

因此 $U$ 内任意两点对 $R$ 的覆盖状态相同。对每个矩形都成立，故覆盖它们的矩形集合恒定。$\blacksquare$

> 说明：矩形本身是闭集，格子的边界线（即 $x=x_k$ 或 $y=y_k$）上可能有「刚好压线」的点。这些线是一维的，面积为 $0$，把它们划给相邻格子中的任意一个都不影响最终面积。下面的积分按半开格子处理，正是为了避免「重复计算边界」。

### 2.4 引理 2（并集面积 = 被覆盖格子面积之和）

**引理 2.** 把所有半开格子 $[x_i,x_{i+1})\times[y_j,y_{j+1})$（$0\le i<cx-1,\ 0\le j<cy-1$）中被至少一个矩形覆盖的格子面积相加，结果等于 $N$ 个矩形的并集面积。

**证明.** 这些半开格子两两不交，且并起来恰好是整个包围盒

$$
[x_0,x_{cx-1})\times[y_0,y_{cy-1})
$$

去掉有限条边界线后的部分。包围盒外的点不被任何矩形覆盖（所有矩形都在其中），而内部没被格子覆盖的点只可能落在那些边界线上，其并集是有限条线段，Lebesgue 测度为 $0$。面积是示性函数的积分，零测集不改变积分值。再由引理 1，每个格子要么全被覆盖、要么全不被覆盖，于是并集面积恰好是「被覆盖格子」的面积之和。$\blacksquare$

### 2.5 从「逐格覆盖」到「二维差分」

现在只剩一个问题：怎样快速求出每个格子被多少个矩形覆盖？

最朴素的做法是枚举每个矩形，把它覆盖的所有压缩格子都 $+1$。一个矩形最多覆盖 $(cx-1)(cy-1)\approx 4\times 10^6$ 个格子，$N$ 个矩形就是 $4\times 10^9$，太慢。

注意「矩形对所有格子加 $1$」是一个**矩形区域加**操作，用二维差分可以把单次操作降到 $O(1)$，最后统一做一次二维前缀和还原。

**引理 3（二维差分的正确性）.** 设矩形在压缩后的格子编号范围是 $lx\le i<rx$、$ly\le j<ry$。令

$$
D[lx][ly]\mathrel{+}=1,\quad D[rx][ly]\mathrel{-}=1,\quad D[lx][ry]\mathrel{-}=1,\quad D[rx][ry]\mathrel{+}=1.
$$

对所有矩形做完后求二维前缀和

$$
P[i][j]=\sum_{a\le i}\sum_{b\le j}D[a][b],
$$

则 $P[i][j]$ 等于覆盖格子 $(i,j)$ 的矩形个数。

**证明.** 由线性性，只需对单个矩形证明。一维的差分事实是：数组 $d$ 满足 $d[l]\mathrel{+}=1,d[r]\mathrel{-}=1$ 时，其前缀和在第 $i$ 位的值为

$$
[i\ge l]-[i\ge r]=\begin{cases}1,&l\le i<r,\\0,&\text{否则}.\end{cases}
$$

二维情况下，四个角上的更新可以写成两个一维更新的「张量积」：先在 $x$ 方向对每一行做 $+1/-1$，再在 $y$ 方向对每一列做 $+1/-1$。两次前缀和复合后得到

$$
P[i][j]=\bigl([i\ge lx]-[i\ge rx]\bigr)\bigl([j\ge ly]-[j\ge ry]\bigr),
$$

它恰好在 $lx\le i<rx$ 且 $ly\le j<ry$ 时等于 $1$，其余位置为 $0$。多个矩形相加即得覆盖次数。$\blacksquare$

### 2.6 收尾：逐格累加面积

还原出 $P[i][j]$ 后，若 $P[i][j]>0$，就把 $(x_{i+1}-x_i)(y_{j+1}-y_j)$ 累加进答案。注意 **判断的是 $>0$，而不是把面积乘上覆盖次数**——重复覆盖只算一次。

### 2.7 失败尝试与坑点记录

1. **直接按矩形求和**：重叠区域重复计数，两个相同矩形会得到两倍面积。
2. **容斥**：$2^N$ 不可行。
3. **开真实坐标网格**：坐标 $10^8$，内存爆掉；必须离散化。
4. **逐矩形暴力标记格子**：$O(N\cdot M^2)\approx 4\times 10^9$，超时；用二维差分。
5. **`int` 存面积**：$(2\times 10^8)^2=4\times 10^{16}$，会溢出，必须 `long long`。
6. **边界重复**：用半开格子 $[x_i,x_{i+1})$，每个边界只归属一侧，避免重复；由于边界面积为 $0$，这样处理不改变答案。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 覆盖情况只在跨过输入的矩形边界线时改变，平面被切成状态恒定的格子。
- **consider easier version** — 若坐标很小，直接开网格逐格标记再统计即可；难点只在坐标太大。
- **classic problem solution** — 对 $x,y$ 分别离散化，把矩形映射成长度为 $2N$ 的压缩网格。
- **classic problem solution** — 用二维差分做「矩形区域加 $1$」，一次二维前缀和还原每格覆盖次数。
- **careful with types** — 格数用 `int`，面积用 `long long`。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 矩形个数 | 读入 | $\le 1000$ |
| `xl[i], yl[i]` | `i64 [1005]` | 第 $i$ 个矩形归一化后的左、下边界 | 读入后取 $\min$ | low |
| `xr[i], yr[i]` | `i64 [1005]` | 第 $i$ 个矩形归一化后的右、上边界 | 读入后取 $\max$ | high |
| `xs[k], ys[k]` | `i64 [2010]` | 去重排序后的压缩坐标 | 由 $2n$ 个边界值排序去重 | coordinates |
| `cx, cy` | `int` | 压缩后 $x,y$ 坐标的个数 | `unique` 后长度 | counts |
| `df[i][j]` | `int [2010][2010]` | 二维差分数组，前缀和后变为格子覆盖次数 | 全 $0$ | difference |
| `ans` | `i64` | 并集面积 | $0$ | answer |

### 4.2 算法步骤

1. 读入 $N$ 个矩形的四个坐标，对每个矩形令 $xl=\min(x_1,x_2)$、$xr=\max(x_1,x_2)$、$yl=\min(y_1,y_2)$、$yr=\max(y_1,y_2)$，同时把 $xl,xr$ 放入 $xs$，$yl,yr$ 放入 $ys$。
2. 对 $xs,ys$ 排序并去重，得到压缩坐标表，长度分别记为 $cx,cy$。
3. 对每个矩形，用 `lower_bound` 求出 $lx,rx,ly,ry$，执行四次差分更新。
4. 在 $[0,cx)\times[0,cy)$ 上做标准二维前缀和还原 $df$。
5. 枚举所有格子 $0\le i<cx-1$、$0\le j<cy-1$，若 $df[i][j]>0$，累加 $(xs[i+1]-xs[i])\cdot(ys[j+1]-ys[j])$。
6. 输出 `ans`。

### 4.3 复杂度分析

- **时间**：排序 $O(N\log N)$；差分更新 $O(N\log N)$（每次 `lower_bound`）；二维前缀和 $O(c_xc_y)\le O(4N^2)$；总 $O(N^2)$，$N=1000$ 时约 $4\times 10^6$ 次操作。
- **空间**：压缩表 $O(N)$；差分数组 $O(c_xc_y)\le O(4N^2)$，约 $16$ MB。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};

int n;
i64 xl[mxn],yl[mxn],xr[mxn],yr[mxn];
i64 xs[mxn*2],ys[mxn*2];
int df[mxn*2][mxn*2];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>xl[i]>>yl[i]>>xr[i]>>yr[i];
		if(xl[i]>xr[i])
			swap(xl[i],xr[i]);
		if(yl[i]>yr[i])
			swap(yl[i],yr[i]);
		xs[i*2]=xl[i];xs[i*2+1]=xr[i];
		ys[i*2]=yl[i];ys[i*2+1]=yr[i];
	}
	sort(xs,xs+n*2);
	sort(ys,ys+n*2);
	int cx=unique(xs,xs+n*2)-xs;
	int cy=unique(ys,ys+n*2)-ys;
	for(int i=0;i<n;++i)
	{
		int lx=lower_bound(xs,xs+cx,xl[i])-xs;
		int rx=lower_bound(xs,xs+cx,xr[i])-xs;
		int ly=lower_bound(ys,ys+cy,yl[i])-ys;
		int ry=lower_bound(ys,ys+cy,yr[i])-ys;
		++df[lx][ly];
		--df[rx][ly];
		--df[lx][ry];
		++df[rx][ry];
	}
	i64 ans=0;
	for(int i=0;i<cx;++i)
		for(int j=0;j<cy;++j)
		{
			if(i)
				df[i][j]+=df[i-1][j];
			if(j)
				df[i][j]+=df[i][j-1];
			if(i&&j)
				df[i][j]-=df[i-1][j-1];
			if(i+1<cx&&j+1<cy&&df[i][j]>0)
				ans+=(xs[i+1]-xs[i])*(ys[j+1]-ys[j]);
		}
	cout<<ans<<'\n';
	return 0;
}
```
