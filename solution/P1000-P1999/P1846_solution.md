# P1846 [BalkanOI 2004] 游戏

## 1. 重新读题

### 1.1 问题重述（人话版）

有两个正整数数列 $A=(a_1,\dots,a_n)$，$B=(b_1,\dots,b_m)$。

一次操作：选正整数 $k_1,k_2$，从 $A$ 的**末尾**删掉 $k_1$ 个数，记它们的和为 $s_1$；从 $B$ 的末尾删掉 $k_2$ 个数，记和为 $s_2$。本次得分

$$(s_2-k_2)\,(s_1-k_1).$$

两个数列必须在同一次操作中一起被删空（不能一个先空）。求总得分的最小值。

### 1.2 关键约束与规模暗示

- $n,m\le 2000$，数列元素 $\le 1000$。
- "从末尾删"意味着若干次操作把 $A$ 从前往后切成若干**连续段**，把 $B$ 也切成同样多段，并且第 $k$ 段与第 $k$ 段配对（因为每次同时删各自的末尾）。
- 段数 $t$ 满足 $1\le t\le \min(n,m)$。
- $n,m=2000$ 排除了 $O(n^2m^2)$ 的朴素区间 DP（约 $1.6\times10^{13}$），目标应是 $O(nm)$ 或 $O(nm\log)$。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把 $(s-k)$ 拆到每个元素

先做一次纯粹的代数变形。设某一段 $A$ 的下标集合为 $L$，长度为 $k_1$，元素和为 $s_1$，则

$$s_1-k_1=\sum_{i\in L}a_i-\sum_{i\in L}1=\sum_{i\in L}(a_i-1).$$

同理 $s_2-k_2=\sum_{j\in R}(b_j-1)$。

令 $a'_i=a_i-1\ge 0$，$b'_j=b_j-1\ge 0$。于是问题完全等价于：

> 把 $A$ 切成 $t$ 个连续段、把 $B$ 切成 $t$ 个连续段（$1\le t\le\min(n,m)$），两边的段一一对应，
> 最小化
> $$\sum_{k=1}^{t}\Big(\sum_{i\in L_k}a'_i\Big)\Big(\sum_{j\in R_k}b'_j\Big).$$

元素的大小本身不再重要，重要的是**各段 $a'$ 之和**与**各段 $b'$ 之和**。记前缀和

$$P_i=\sum_{q\le i}a'_q,\qquad Q_j=\sum_{q\le j}b'_q,$$

它们都是**单调不降**的。

**引理 1（切分与配对等价）**

上述"切成同样多段并一一配对"的模型，与原始操作序列一一对应。

**证明**：给定操作序列，第 1 次操作取走的是 $A$ 末尾 $k_1^{(1)}$ 个，即最后一段；第 2 次取走的是剩余部分的末尾，即倒数第二段……反过来，给定从前往后的切分，按从后往前的顺序依次执行操作即可。两边的段数必然相同（最后一次操作同时清空两边）。得分逐段等于 $($段 $a'$ 和$)\times($对应段 $b'$ 和$)$。$\blacksquare$

### 2.2 考虑简化版：切得越碎越好吗？

先看一个自然猜测：**段数越多，乘积和越小**。理由是"拆开一个块"：

$$\Big(\sum a'\Big)\Big(\sum b'\Big)\ \longrightarrow\ \Big(\sum_{L_1}a'\Big)\Big(\sum_{R_1}b'\Big)+\Big(\sum_{L_2}a'\Big)\Big(\sum_{R_2}b'\Big).$$

**引理 2（拆块不增代价）**

设一个块被拆成两个非空块，两块的 $a'$ 和分别为 $x_1,x_2\ge0$，$b'$ 和分别为 $y_1,y_2\ge0$。则

$$x_1y_1+x_2y_2\le (x_1+x_2)(y_1+y_2).$$

**证明**：右边减左边 $=x_1y_2+x_2y_1\ge0$。$\blacksquare$

看起来"段数取满 $\min(n,m)$"最优？**并非如此**。反例：

$$A=(2,2,1)\Rightarrow a'=(1,1,0),\qquad B=(1,11,11)\Rightarrow b'=(0,10,10).$$

- 取 $t=3$（逐元素配对）：$1\cdot0+1\cdot10+0\cdot10=10$。
- 取 $t=2$：$A$ 切成 $[1,2]\mid[3]$，$B$ 切成 $[1]\mid[2,3]$，代价
  $$(1+1)\cdot0+0\cdot(10+10)=0.$$

$0<10$。**失败尝试的教训**：切碎确实不增代价，但前提是"两边都能在同一个位置继续切"；当一边的某个段只剩 $1$ 个元素时就无法再切，于是必须把另一边的某些元素"并"进来，可能把很大的 $b'$ 与很大的 $a'$ 强行绑在一起。因此段数不是越多越好，必须做真正的二维决策。

### 2.3 刻画最优解的形状

从引理 2 的证明可以得到一个更精确的观察。

**引理 3（最优解可假设：最后一个块的某一边长度为 1）**

在最优方案中，可以假设最后一个块（即 $(i',i]\times(j',j]$）满足 $i'=i-1$ 或 $j'=j-1$。

**证明**：取一个最优方案。若最后一个块满足 $i'\le i-2$ 且 $j'\le j-2$（两边长度都 $\ge2$），则 $(i-1,j-1)$ 是这个块内部的一个合法切点，可以把它拆成两个块：

$$[i',i-1]\times[j',j-1]\quad\text{和}\quad(i-1,i]\times(j-1,j].$$

由引理 2（取 $x_1=P_{i-1}-P_{i'}$，$x_2=a'_i$，$y_1=Q_{j-1}-Q_{j'}$，$y_2=b'_j$），拆分后总代价不增；而新的最后一块 $(i-1,i]\times(j-1,j]$ 两边长度都是 $1$，满足条件。$\blacksquare$

注意：**只能**保证"最后一块有一边长度为 1"，不能保证全局每块都是这样，也不能保证段数取满——这正是 2.2 反例仍然存在的原因。

### 2.4 建立 DP

定义

$$dp[i][j]=\text{把 }A[1..i]\text{ 与 }B[1..j]\text{ 切成同样多段、且最后一段恰好在 }(i,j)\text{ 结束时的最小代价}.$$

由引理 3，最后一块只有两种形态：

- **$A$ 侧长度为 $1$**：前驱为 $(i-1,j')$，$j'<j$。代价
  $$dp[i-1][j']+a'_i\,(Q_j-Q_{j'}).$$
- **$B$ 侧长度为 $1$**：前驱为 $(i',j-1)$，$i'<i$。代价
  $$dp[i'][j-1]+b'_j\,(P_i-P_{i'}).$$

于是

$$dp[i][j]=\min\left\{
\begin{aligned}
&\min_{0\le j'<j}\big(dp[i-1][j']+a'_i(Q_j-Q_{j'})\big),\\
&\min_{0\le i'<i}\big(dp[i'][j-1]+b'_j(P_i-P_{i'})\big).
\end{aligned}
\right.$$

边界：$dp[0][0]=0$，其余 $dp[0][j]=dp[i][0]=+\infty$。答案 $dp[n][m]$。

**引理 4（DP 正确）**

上述递推给出的 $dp[n][m]$ 等于原问题最小值。

**证明**：对 $i+j$ 归纳。

- *可行性*：递推中每一项都对应一个合法方案——前缀用 $dp$ 的最优切分，再接上最后一块；段数加一，两边都非空，合法。
- *最优性*：设 $(i,j)$ 的最优方案，由引理 3 可假设最后一块有一边长为 $1$。若 $A$ 侧长为 $1$，其前驱为 $(i-1,j')$，前缀部分代价 $\ge dp[i-1][j']$（归纳假设），故该方案代价 $\ge$ 第一项的某个候选；$B$ 侧同理。取 min 后 $dp[i][j]\le$ 最优值。结合可行性得等号。
- 归纳基：$dp[0][0]=0$ 对应空方案。$\blacksquare$

### 2.5 优化到 $O(nm)$

直接按上式做是 $O(nm(n+m))$。注意两项分别可以"提公因式"：

$$\min_{j'<j}\big(dp[i-1][j']-a'_iQ_{j'}\big)+a'_iQ_j,$$

$$\min_{i'<i}\big(dp[i'][j-1]-b'_jP_{i'}\big)+b'_jP_i.$$

**第一项**：固定行 $i$ 时 $a'_i$ 是常数。令 $j$ 从 $1$ 扫到 $m$，用一个滚动变量

$$mn1=\min_{j'<j}\big(dp[i-1][j']-a'_iQ_{j'}\big)$$

即可：算完 $dp[i][j]$ 后用 $dp[i-1][j]-a'_iQ_j$ 更新 $mn1$，供 $j+1$ 使用。每行 $O(m)$。

**第二项**：固定**目标列** $j$ 后，$b'_j$ 是常数；对每个 $j$ 维护

$$mn2[j]=\min_{i'<i}\big(dp[i'][j-1]-b'_jP_{i'}\big).$$

当第 $i$ 行算完 $dp[i][j]$ 后，用 $dp[i][j-1]-b'_jP_i$ 去更新 $mn2[j]$，供第 $i+1$ 行使用（$j-1$ 是同一行、已经算好的状态，所以按 $j$ 升序扫描即可）。

这样每个状态 $O(1)$，总时间 $O(nm)$。由于 $dp[i][\cdot]$ 只依赖 $dp[i-1][\cdot]$，滚动两行即可，空间 $O(m)$。

初始化：$mn2[1]=dp[0][0]=0$，$mn2[j]=+\infty\ (j\ge2)$——它表示 $i=1$ 时唯一合法的前驱是 $i'=0,j'=j-1$，且只有 $j=1$ 合法。

### 2.6 一个边界检查

$mn2$ 的更新用的是 $dp[i][j-1]$。这要求 $j-1\ge1$ 吗？不需要：$j=1$ 时 $dp[i][0]=+\infty$，更新后仍是 $+\infty$，正好表示"不能用一个空的 $B$ 前缀接最后一块"。代码里 `cur[0]=inf` 已保证。

## 3. 模式总结（Pattern Summary）

- **explore its property** — $(s-k)$ 逐元素拆成 $\sum(a_i-1)$，问题变成两序列切段后的乘积之和。
- **consider easier version** — 先猜"段越多越好"；用拆块不等式 $x_1y_1+x_2y_2\le(x_1+x_2)(y_1+y_2)$ 支持这个直觉。
- **find a counterexample** — 构造 $A=(2,2,1),B=(1,11,11)$，证明 $t=2$ 严格优于 $t=3$。
- **explore its property** — 最优解的最后一块必有一边长度为 $1$（内部切点拆分不增代价）。
- **classic problem solution** — 二维 DP，前驱是两个"矩形前缀 min"。
- **classic problem solution** — 提公因式后用滚动前缀最小值把转移降到 $O(1)$，总 $O(nm)$。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n, m` | `int` | 两数列长度 | 读入 | 维度 |
| `a[i]` | `i64 [2005]` | $a_i-1$（第一个数列平移后） | 读入后减 $1$ | $a'$ |
| `b[j]` | `i64 [2005]` | $b_j-1$ | 读入后减 $1$ | $b'$ |
| `P[i]` | `i64 [2005]` | $\sum_{q\le i}a_q$ | 前缀和 | prefix A |
| `Q[j]` | `i64 [2005]` | $\sum_{q\le j}b_q$ | 前缀和 | prefix B |
| `prv[j]` | `i64 [2005]` | 上一行的 $dp[i-1][j]$ | `prv[0]=0`，余 `inf` | previous |
| `cur[j]` | `i64 [2005]` | 当前行的 $dp[i][j]$ | `cur[0]=inf` | current |
| `mn1` | `i64` | $\min_{j'<j}(dp[i-1][j']-a_iQ_{j'})$ | 每行开始为 `prv[0]` | 行内滚动 |
| `mn2[j]` | `i64 [2005]` | $\min_{i'<i}(dp[i'][j-1]-b_jP_{i'})$ | `mn2[1]=0`，余 `inf` | 列累积 |

### 4.2 算法步骤

1. 读入 $n,m$；读入两数列并原地减 $1$。
2. 求前缀和 $P,Q$。
3. 初始化 `prv[0]=0`，`prv[1..m]=inf`；`mn2[1]=0`，`mn2[2..m]=inf`。
4. 对 $i=1..n$：
   1. `cur[0]=inf`，`mn1=prv[0]`；
   2. 对 $j=1..m$：
      - `cur[j]=min(a[i]*Q[j]+mn1, b[j]*P[i]+mn2[j])`；
      - `mn1=min(mn1, prv[j]-a[i]*Q[j])`；
      - `mn2[j]=min(mn2[j], cur[j-1]-b[j]*P[i])`；
   3. `prv=cur`。
5. 输出 `prv[m]`。

### 4.3 复杂度

- 时间 $O(nm)$（$n=m=2000$ 时 $4\times10^6$）。
- 空间 $O(n+m)$（滚动行）。

## 5. 示例代码

```cpp
//
// 题目：P1846 [BalkanOI 2004] 游戏
// https://www.luogu.com.cn/problem/P1846
// 本地自测通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005};
constexpr i64 inf{1'000'000'000'000'000'000LL};

int n,m;
i64 a[mxn],b[mxn],P[mxn],Q[mxn];
i64 prv[mxn],cur[mxn],mn2[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=1;i<=n;++i)
	{
		i64 x;
		cin>>x;
		a[i]=x-1;
	}
	for(int j=1;j<=m;++j)
	{
		i64 x;
		cin>>x;
		b[j]=x-1;
	}
	for(int i=1;i<=n;++i)
		P[i]=P[i-1]+a[i];
	for(int j=1;j<=m;++j)
		Q[j]=Q[j-1]+b[j];

	prv[0]=0;
	for(int j=1;j<=m;++j)
		prv[j]=inf;
	mn2[1]=0;
	for(int j=2;j<=m;++j)
		mn2[j]=inf;
	for(int i=1;i<=n;++i)
	{
		cur[0]=inf;
		i64 mn1=prv[0];
		for(int j=1;j<=m;++j)
		{
			i64 t1=a[i]*Q[j]+mn1;
			i64 t2=b[j]*P[i]+mn2[j];
			cur[j]=min(t1,t2);
			mn1=min(mn1,prv[j]-a[i]*Q[j]);
			mn2[j]=min(mn2[j],cur[j-1]-b[j]*P[i]);
		}
		for(int j=0;j<=m;++j)
			prv[j]=cur[j];
	}
	cout<<prv[m]<<'\n';
	return 0;
}
```
