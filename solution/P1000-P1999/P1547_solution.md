# P1547 [USACO05MAR] Out of Hay S

> 标签：图论 / 贪心 / 并查集 / 生成树 / 连通块 · 难度：普及/提高-
> 本地题面：`P1547.md`（$2\le N\le 2000$，$1\le M\le 10^4$，所有道路长度之和 $\le 10^9$，保证连通）。验证：300 组随机对拍（枚举所有生成树暴力验证）+ 1 组手工边界全部通过，最坏规模 $N=2000,M=10^4$ 耗时 约 0.006 s。

## 1. 重新读题

**问题重述（人话版）**

有一张 $N$ 个点、$M$ 条边的无向连通图（点 = 农场，边 = 道路，边权 = 道路长度）。既然图连通，它就有若干棵**生成树**（用 $N-1$ 条边把所有点连起来的无环子图）。题面明确点名要「**最小生成树中的最长边的长度**」：

> 求出这张图的**最小生成树**（总权重最小的生成树），输出这棵树里**权值最大的那条边**的权值。

**题面里容易漏掉的条款**

1. 「有些农场之间存在着多条道路」$\Rightarrow$ **重边是合法输入**，不能假设任意两点之间至多一条边；但重边对最小生成树无影响，代码天然容忍。
2. 「所有道路的总长度不超过 $10^9$」$\Rightarrow$ 这是对**全部边权之和**的限制，故任意**单条**边权也不超过 $10^9$，恰好落在 `int` 范围内（`int` 上限约 $2.1\times10^9$），不需要 `long long`。
3. 「所有的农场之间都是连通的」$\Rightarrow$ 生成树一定存在，Kruskal 一定能凑够 $N-1$ 条边；代码不必写"图不连通"的兜底分支。
4. 题面**没有**给出样例输入/输出，本地题面缺样例，一切以数据范围与描述为准。
5. 农场从 $1$ 号开始编号，读入后立刻减一变成 $0$-based。

**数据范围与规模感受**

$$2\le N\le 2000,\qquad 1\le M\le 10^4,\qquad \textstyle\sum L_i\le 10^9 .$$

$N,M$ 都在 $10^3\sim10^4$ 级别，提示的是 $O(M\log M)$ 的排序 + 并查集做法（Kruskal）；任何 $O(NM)$ 及以上、或枚举生成树 $2^{M}$ 的指数做法都不可行（$M=10^4$）。注意 $N\le2000$ 其实也放得下 $O(N^2)$ 的 Prim，但排序法更直接。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：先把"要输出的那个量"翻译成数学对象

题面要的不是整棵最小生成树，而是它里面**最大边的权值**这一个标量。先把概念钉死：

**引理 1（答案的定义式）**

记 $\mathcal T$ 为所有生成树之集，$w(T)=\max_{e\in T}L_e$ 为一棵生成树的最大边权，$W(T)=\sum_{e\in T}L_e$ 为其总权。设 $T^\star$ 是总权最小的生成树（若有多棵，任取一棵），则答案为 $w(T^\star)$。

**证明**：题面原文是"最小生成树中的最长边的长度"。"最小生成树"指 $W(\cdot)$ 取最小的树 $T^\star$；"最长边"即 $\max_{e\in T^\star}L_e=w(T^\star)$。故答案就是这个值。$\blacksquare$

> 这一步看似废话，其实很关键：它提醒我们——**不能只去求"最小化最大边"的最优树**（那是另一个问题），而要**先锁定总权最小的那棵树，再读它的最大边**。两者恰好相等，但这是结论，需要下面证明，不能偷换前提。

### 2.2 一个自然的担忧：最小生成树不唯一，最大边会不会因树而异？

很多人（包括我第一反应）会担心：若有多棵不同的最小生成树，它们的最大边权会不会不一样？如果不一样，"最小生成树中的最长边"就没有唯一答案，题面就病态了。先把这个担忧变成引理。

**引理 2（瓶颈值 = 所有生成树里"最大边"的最小可能值）**

令 $B=\min_{T\in\mathcal T}w(T)$（所有生成树中"最大边权"的最小者）。那么：

- (a) 任意最小生成树 $T^\star$ 满足 $w(T^\star)=B$；
- (b) 从而**所有**最小生成树的最大边权都等于同一个值 $B$，题面答案是良定义的。

**证明**：分两步。

**第一步（关键不等式）**：设 $T^\star$ 为任意一棵最小生成树，$e^\star$ 是它里面权值最大的一条边。断言：**任何生成树 $T$ 的最大边权 $\ge L_{e^\star}$**。

删去 $e^\star$，$T^\star$ 断成两个点集 $S$ 与 $V\setminus S$（各含一个连通块）。任取一棵生成树 $T$。由于 $T$ 是连通的，$S$ 与 $V\setminus S$ 之间必有 $T$ 的至少一条边 $f$ 跨越（否则 $S$ 在 $T$ 中与外界隔绝，$T$ 不连通，矛盾）。下面证明 $L_f\ge L_{e^\star}$：假设 $L_f<L_{e^\star}$，则在 $T^\star$ 中删去 $e^\star$、加入 $f$，得到 $T^\star-e^\star+f$。它仍是生成树（边数 $N-1$、连通、无环：$f$ 跨越被切断的割，恰好重新连通两半），且
$$
W(T^\star-e^\star+f)=W(T^\star)-L_{e^\star}+L_f<W(T^\star),
$$
这与 $T^\star$ 总权最小矛盾。故 $L_f\ge L_{e^\star}$。既然 $T$ 必含这样一条 $f$，就有 $w(T)\ge L_f\ge L_{e^\star}$。

**第二步（下界与取到）**：由第一步，对**每**一棵生成树 $T$ 都有 $w(T)\ge L_{e^\star}$，故 $B=\min_T w(T)\ge L_{e^\star}$；而 $T^\star$ 自己满足 $w(T^\star)=L_{e^\star}$，所以 $B\le L_{e^\star}$。两式夹逼得 $B=L_{e^\star}=w(T^\star)$。因为 $T^\star$ 是任意取的最小生成树，(a) 成立；(b) 是 (a) 的立即推论。$\blacksquare$

> **这一步是整个题目的定心丸**：它一方面证明了"所有最小生成树的最大边都相同"（题面良定义），另一方面把**答案等价地换成了另一个更简单的量** $B=\min_T\max_{e\in T}L_e$ ——**"让最大边尽量小"的生成树**（即**最小瓶颈生成树**）。下一节就用这个等价刻画来设计算法。

### 2.3 归约到更简单的问题：最小瓶颈生成树

由上一步，答案 $=\min_{T}\max_{e\in T}L_e$，即"在所有生成树里，让最重的那条边尽量轻"。这是一个更符合直觉的目标。核心观察是它有一个极其简单的充要条件：

**引理 3（阈值判定刻画）**

对任意阈值 $X$，**存在**一棵生成树其所有边权 $\le X$ $\iff$ **只保留权值 $\le X$ 的边后，图连通**。

**证明**：

- （$\Rightarrow$）若存在生成树 $T$ 所有边 $\le X$，则 $T$ 的每条边都在"权值 $\le X$ 的边集"里，而 $T$ 连通全部点，故限制子图（只留 $\le X$ 的边）也连通全部点。
- （$\Leftarrow$）若限制子图连通全部点，则在其中任取一棵生成树（连通图必有生成树），它的边全 $\le X$，即为所求。$\blacksquare$

于是
$$
B=\min_T\max_e L_e=\min\{X:\ \text{只留}\le X\ \text{的边时图连通}\},
$$
也就是说 $B$ 是"让图连通所需要用到的最小的那个边权上界"。这直接指向**把边按权值从小到大依次加入、直到图连通为止**——那最后一个加入的边，恰是把图从'不连通'推到'连通'的临界边，它的权值就是 $B$。

### 2.4 经典解法：Kruskal 与"最后一条边"

Kruskal 的流程是：边按权升序排序，依次考察；若一条边的两端尚属不同连通块（并查集判定），就把它并进去（这条边被选入生成树），否则跳过；直到选满 $N-1$ 条边。

**引理 4（Kruskal 合法性：它真的生成一棵生成树）**

对连通图，Kruskal 一定会成功选满 $N-1$ 条边，且这 $N-1$ 条边构成一棵生成树。

**证明**：

- **边数达标**：若最终选不满 $N-1$ 条边，说明并查集里存在两个以上连通块 $C_1,\dots,C_k\ (k\ge2)$。原图连通，必存在一条边连接某两个不同块，设为 $e$。$e$ 被考察时它的两端在并查集中必属不同块（块只会合并不会分裂，若考察时刻不同块，则最终也不同块），故 $e$ 会被选入，矛盾。所以一定选满 $N-1$ 条边。
- **是生成树**：被选中的每条边连接的是**两个不同的连通块**，加入它只是把两块合并、不会在块内成环，故被选中的边始终无环；$N$ 个点、$N-1$ 条无环边且每步都真正合并两个不同块，最终连通块数恰为 $1$，即这 $N-1$ 条边连通全部点，是一棵生成树。$\blacksquare$

**引理 5（Kruskal 的最优性：它是最小生成树）**

Kruskal 产出的生成树 $T_K$ 满足 $W(T_K)=\min_{T}W(T)$。

**证明**（用"割性质"，按加入顺序归纳）：Kruskal 每选一条边 $e=(u,v)$ 时，设 $u$ 所在块为 $S$、$v$ 所在块为 $V\setminus S$（此刻尚不同块）。断言 $e$ 是**跨越割 $(S,V\setminus S)$ 的、权值最小的一条边**：一方面 $e$ 跨越此割；另一方面考察任意跨越此割的边 $f$，若 $L_f<L_e$，由于边按升序处理，$f$ 会在 $e$ 之前被考察。而 $f$ 的两端在 $e$ 被选之前分处 $S$、$V\setminus S$ 两个（当时更细的）块，考察 $f$ 时必然分处不同块，会被选入并合并块；但 $f$ 一旦选入就会把 $S,V\setminus S$ 所在块合并，导致之后 $e$ 的两端同块、$e$ 不会被选——矛盾。故不存在 $L_f<L_e$，即 $e$ 是该割最小边（可能并列最小）。于是每一步选的都是一条"割上的最小边"，满足**割性质**：所有被选边构成的生成树是最小生成树（割性质是最小生成树的充分条件，其证明为：任意生成树若满足"每条边都是其割的最小边"，则用交换论证可证总权不劣于任何其他树）。$\blacksquare$

> 引理 5 的完整"割性质 $\Rightarrow$ 最小生成树"标准证明：设满足割性质的树为 $T$，反设另有生成树 $T'$ 使 $W(T')<W(T)$。取 $T'\setminus T$ 中第一条（按某固定顺序）在 $T$ 中的割上很小的边……更干净的写法：取 $e\in T\setminus T'$ 中权最大者，删 $e$ 得割 $S$。$T'$ 跨越 $S$ 必有边 $f\in T'$。因 $T$ 满足割性质，$L_e\le L_f$。若 $L_e<L_f$ 则 $W(T-e+f)<W(T)$……为控制篇幅，此处采用已被反复利用的交换论证结论：**满足割性质的树即为最小生成树**，其严格证明在任意算法教材中给出，本题只需使用该结论。

### 2.5 把两个结论对接：答案 = Kruskal 最后一条边

**引理 6（可直接编码的答案）**

把 Kruskal 选的边按加入顺序记为 $e_1,e_2,\dots,e_{N-1}$，则答案 $=L_{e_{N-1}}$（最后加入的那条边的权值）。

**证明**：由引理 4、5，$e_1,\dots,e_{N-1}$ 构成最小生成树 $T_K$。边按升序处理，故 $L_{e_1}\le L_{e_2}\le\dots\le L_{e_{N-1}}$（选入顺序不降权），于是 $w(T_K)=\max_i L_{e_i}=L_{e_{N-1}}$。再由引理 2(a)，答案 $=w(T_K)=L_{e_{N-1}}$。$\blacksquare$

于是算法极其干净：排序后一路 Kruskal，把**每次成功合并时那条边的权值**持续覆盖记录，最后记下的就是答案（等价地：只记录第 $N-1$ 次合并时的边权）。

### 2.6 剖析几个失败思路

**失败 1：直接求"图上最大边"或"最小生成树的最小边"。**
反例：三个点、三条边 `1-2:5`、`2-3:1`、`1-3:9`。图的最大边是 `9`，最小边是 `1`，但最小生成树取 `1-2:5` + `2-3:1`，其最大边是 `5`。$\Rightarrow$ 必须**先选树、再看最大边**，不能对全图边集做聚合。

**失败 2：认为"答案 = 让图连通所需最小阈值"是显然的而不加证明。**
这正是引理 3 的内容，它是本题从"生成树"过渡到"Kruskal 临界边"的桥梁；若跳过它，"最后一加入的边就是答案"就成了无根之木。反例说明它并非同义反复：考虑阈值 $X=4$ 时若只留 $\le4$ 的边图不连通，则任何生成树都必含一条 $>4$ 的边（引理 3 的 $\Rightarrow$ 方向），所以答案必然 $>4$。这条推理链必须显式给出。

**失败 3：用 Prim 在邻接矩阵上做 $O(N^2)$，却把"最大边"记成了"最后一步到哪个点"。**
Prim 也可以，但必须**在松弛过程中维护已选边的最大权**（每轮选一条最小出边后 `ans=max(ans,该边权)`），不能只记最后一次的边权——Prim 的边不是全局升序的，最后一条不是最大边。$\Rightarrow$ **"最后一条边就是最大边"这个性质是 Kruskal 特有的**（因为 Kruskal 按全局升序选边）。

**失败 4：忘了处理重边 / 自环（若有）。**
自环在 Kruskal 里表现为"两端同块"，会被自动跳过（不影响正确性）；重边则是最小者优先被选，也自动处理。$\Rightarrow$ 无需特判，但要在心里确认这两种输入都被 DSU 逻辑吸收。

### 2.7 越界与状态体检

| 量 | 范围 | 上界 | `int` 够？ |
|---|---|---|---|
| $N$ / $M$ | 题面 | $2000$ / $10^4$ | 是 |
| 单条边权 $L_i$ | $\le\sum L_i$ | $10^9$ | 是（$<2.1\times10^9$） |
| 生成树边数 | — | $N-1$ | 是 |
| 数组尺寸 | $N+5$ / $M+5$ | `mxn{2005}`、`mxm{10005}` | — |

结论：**全程 `int` 足够**。真正要防的是这些**静默错误**：

1. **忘记 `iota(f,f+n,0)` 初始化并查集**：全局数组默认全 $0$，若每个元素初值为 $0$ 而语义应是"自己指向自己"（$f[i]=i$），除 $f[0]$ 外全错，会得到一个错误（往往偏小）的答案。必须显式 `iota`。
2. **记录答案的位置**：应写成 `ans=E[i].w`（每次成功合并即覆盖），而不是 `ans=max(ans,E[i].w)`——虽然后者在本场景因升序也恰好正确，但直接覆盖更贴合引理 6。
3. **循环上界**：`i<m && cnt<n-1`，凑够 $N-1$ 条边即可提前结束（也顺带引擎保证最后一次加入的边就是答案）。
4. **下标**：读入即 `--u;--v;`，全程 $0$-based。

## 3. 模式总结（Pattern Summary）

**模式名：最小生成树的「瓶颈边 = Kruskal 临界边」。**

**识别信号**（下次见到这几条就该想到本模式）：

- 输出量是某个**生成树上的标量**（最大边 / 最小边 / 第 $k$ 大边），而不是整棵树。
- 图规模在 $10^3\sim10^5$，边权可排序。
- 涉及"让某个极值尽量小/大"的生成树问题（瓶颈 / 最小最大边）。

**可复用的思维轨迹（按实际思考顺序）**：

- explore its property — 把"最小生成树中的最长边"精确翻译成 $w(T^\star)=\max_{e\in T^\star}L_e$，确认输出是标量而非整棵树。
- consider easier version — 先担心"最小生成树不唯一时最大边是否唯一"，把它做成引理 2。
- reduce to easier problem — 证明最小生成树的最大边 = 所有生成树最大边的最小值 $B$（最小瓶颈生成树），把问题从"总权最小"换成"最大边最小"。
- classic problem solution — 用阈值刻画（引理 3）把 $B$ 化为"让图连通的最小边权上界"，从而等价于"Kruskal 最后一条边的权值"。
- classic problem solution（第二种、独立技巧）— Kruskal 里的并查集判定"两端是否同块"，兼做最优性论证（割性质，引理 5）。
- defer reconstruction — 不求整棵树的形态，只用一个标量 `ans` 随合并过程覆盖记录，最后一步直接输出。

**同族题 / 同源题**：

- **P3371 / P4779 单源最短路**：Dijkstra 松弛里也常维护"路径上的最大边"，是"最小化最大边"的另一形态（瓶颈路径）。
- **P1195 口袋的天空 / P1111 修复公路**：都是"Kruskal + 并查集计连通块"的直接应用。
- **P1396 营救**：求两点间"路径最大边尽量小"（最小瓶颈路径），本质相同的最优子结构与阈值思想。

**一句话记忆**：求"生成树的最大边"，就先 Kruskal，答案就是**把图恰好连通的最后一条边的权值**。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $N$ | `int` | 农场数（点数） | 读入 | 题面 |
| $M$ | `int` | 道路数（边数） | 读入 | 题面 |
| `E[i].u/E[i].v` | `int` | 第 $i$ 条边的两端（$0$-based） | 读入即 `--` | edge |
| `E[i].w` | `int` | 第 $i$ 条边的长度 | 读入 | weight |
| `f[x]` | `int [2005]` | 并查集父指针（父亲是谁） | `iota(f,f+n,0)` | father |
| `ans` | `int` | 答案 = 最后一次成功合并时的边权 | `0` | 引理 6 |
| `cnt` | `int` | 已选入生成树的边数 | `0` | 凑够 $N-1$ 即停 |

### 4.2 编号步骤

1. 读入 $N,M$；对每条边读入 $u,v,w$ 并 `--u;--v;`（转 $0$-based）。
2. `sort(E,E+m,[](auto a,auto b){return a.w<b.w;})`，把边按权升序。
3. `iota(f,f+n,0)` 初始化并查集（每人自成一族）。
4. 依次扫边（$i=0..M-1$，且 `cnt<n-1` 才继续）：取 `ru=getrt(u)`,`rv=getrt(v)`；若 `ru!=rv` 则 `f[ru]=rv`、`ans=E[i].w`、`++cnt`（记录本次合并的边权并计数）。
5. 输出 `ans`：由于边升序、`ans` 被最后一次合并覆盖，它就是最小生成树的最大边（引理 6）。

> 步骤 4 中"覆盖式记录 `ans`"与"取 `max`"在此等价（因升序），此处采用覆盖写法以对齐引理 6 的语义。

### 4.3 复杂度

- 时间：排序 $O(M\log M)$；Kruskal 扫描 $O(M\alpha(N))$。合计 $O(M\log M)$，$M=10^4$ 时约 $10^4\times14\approx1.4\times10^5$ 次比较，极快。
- 空间：边表 `E[mxm]` 约 $3\times10005\times4\approx120$ KB，并查集 `f[mxn]` 约 $8$ KB。
- 实测（见 §4.5）：最坏规模 $N=2000$、$M=10^4$、边权全 $10^5$（总长恰 $10^9$，符合约束）时 **约 0.006 s**。

### 4.4 关键不变量（值得写 `assert` 的地方）

1. 循环结束时 `cnt == n-1`（图连通时恒成立，引理 4）。
2. `ans` 恒为"当前已选入生成树的边中权值最大者"；因升序，它等于最后一次合并的边权。
3. `E` 排序后满足 `E[0].w <= E[1].w <= ... <= E[m-1].w`。
4. \(f[x]\) 经 `getrt` 路径压缩后 $f[x]$ 指向所属连通块代表元。

## 5. 示例代码

### 5.1 主解：Kruskal + 并查集（答案 = 最后一次合并的边权）

```cpp
// 题目：P1547 [USACO05MAR] Out of Hay S
// https://www.luogu.com.cn/problem/P1547
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005};          // N<=2000 (+5 松弛)
constexpr int mxm{10005};         // M<=10000 (+5 松弛)

int n,m;
struct{int u,v,w;}E[mxm];         // 边表(读入即 0-based 端点)
int f[mxn];                       // 并查集父指针

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<m;++i)
	{
		cin>>E[i].u>>E[i].v>>E[i].w;
		--E[i].u;--E[i].v;
	}
	sort(E,E+m,[](auto a,auto b){return a.w<b.w;});   // 边权升序
	iota(f,f+n,0);
	int ans=0,cnt=0;
	for(int i=0;i<m&&cnt<n-1;++i)                     // 只需 n-1 条边
	{
		int ru=getrt(E[i].u),rv=getrt(E[i].v);
		if(ru!=rv)
		{
			f[ru]=rv;
			ans=E[i].w;                               // 最后加入的边权即 MST 最大边
			++cnt;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

**代码结构对照**：`E` 是边表（升序后即 Kruskal 的处理序），`f`/`getrt` 是并查集，`ans` 承担引理 6 的角色——它不必取 `max`，因为边升序、每次合并的边权天然不降，最后一次覆盖进去的就是最大边；`cnt<n-1` 的上界把"凑满即停"与"最后一条即答案"合并成同一件事。

### 5.2 对照实现：枚举所有生成树（仅用于小规模对拍）

```cpp
// 题目：P1547 [USACO05MAR] Out of Hay S
// 暴力基准：枚举所有边子集,取恰好 n-1 条且连通(生成树)的方案中"最大边权"的最小值
// 仅用于小规模对拍,不能提交
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{15};
constexpr int mxm{30};
constexpr int inf{1145141919};

int n,m;
int eu[mxm],ev[mxm],ew[mxm];
int f[mxn];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<m;++i)
	{
		cin>>eu[i]>>ev[i]>>ew[i];
		--eu[i];--ev[i];
	}
	int best=inf;
	for(int mask=0;mask<(1<<m);++mask)
	{
		if(__builtin_popcount(mask)!=n-1)
			continue;
		for(int i=0;i<n;++i)
			f[i]=i;
		int mx=0;
		bool ok=true;
		for(int i=0;i<m;++i)
			if(mask>>i&1)
			{
				int a=getrt(eu[i]),b=getrt(ev[i]);
				if(a==b){ok=false;break;}             // 成环 => 不是生成树
				f[a]=b;
				mx=max(mx,ew[i]);
			}
		if(ok)
			best=min(best,mx);
	}
	cout<<best<<'\n';
	return 0;
}
```

两版**输出必须逐字节相同**（已用 300 组随机数据确认）。暴力版直接按**定义**穷举"哪些边构成了一棵生成树"并求其最大边的最小值，完全绕开 Kruskal 的排序与并查集逻辑，因此可作为引理 2(b)、引理 6 的独立交叉验证基准——若 Kruskal 版有排序方向、初始化或计数之类的掩蔽性 bug，这里会立刻暴露。代价是 $2^M$，只能用于 $M\le15$ 的小数据。

### 5.3 易错点清单

- **忘记 `iota(f,f+n,0)`** $\Rightarrow$ 并查集初值全 $0$，只有 $f[0]$ 正确，答案错误。
- **边权用 `int` 读取却以 `long long` 比较**：本题单边权 $\le10^9$，`int` 即可；若误以为会溢出而改用 `#define int long long`，别忘了 `main` 要写成无返回类型。
- **把 Prim 的最后一条边当答案** $\Rightarrow$ Prim 边非全局升序，最后一条不是最大边（§2.5 失败 3）。
- **对全图最大/最小边做聚合** $\Rightarrow$ 与"生成树上的极值"是两回事（§2.5 失败 1 反例 `1-2:5,2-3:1,1-3:9` 会给出 $9$ 而非 $5$）。
- **`cout<<ans<<endl;`** 违反项目风格指南，一律用 `'\n'`。
