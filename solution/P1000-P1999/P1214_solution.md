# P1214 [USACO1.4] 等差数列 Arithmetic Progressions — 题解

## Part 1 · 重述题意

给两个数 $n$（数列长度，$3 \le n \le 25$）和 $m$（$0 \le m \le 250$）。
先构造"双平方数集合"
$$S = \{\,p^2+q^2 \mid p,q \in \{0,1,\dots,m\}\,\}.$$
注意 $S$ 是**集合**：同一个数若由多种 $(p,q)$ 表示，只算一次。

要找出所有形如 $a,\,a+b,\,a+2b,\,\dots,\,a+(n-1)b$ 的等差数列（共 $n$ 项），要求：
- 首项 $a$ 是非负整数（事实上必须属于 $S$，见 Part 2 引理 1）；
- 公差 $b$ 是正整数；
- **每一项**都必须在 $S$ 中。

输出要求：
- 若一个都没有，输出 `NONE`；
- 否则每个数列输出一行 `a b`，**先按 $b$ 升序、再按 $a$ 升序**排列；
- 答案总数不超过 $10000$。

约束 $m \le 250$ 决定了数值上界 $2m^2 \le 125000$，这是"暴力枚举"能过线的关键。

---

## Part 2 · 思考过程（含完整证明）

### 2.1 先弄清"集合"到底多大

最直接的疑问：$S$ 里到底有多少个不同的数？上界是多少？

$p,q$ 各取 $0\dots m$ 共 $(m+1)^2$ 个组合，所以 $S$ 的元素个数
$$|S| \le (m+1)^2 \le 251^2 = 63001.$$
最大元素是 $m^2+m^2=2m^2 \le 125000$。最小元素是 $0$。

**观察**：数值范围只有 $0\dots 125000$，是个小整数区间。这强烈提示我们可以用"布尔标记数组"来判"某数是否在 $S$ 里"，而不用排序 + 二分，也不用存一堆数再查重。这是后面算法的地基。

### 2.2 从最简单的特例找感觉：$n=3$

先不考虑一般 $n$，看 $n=3$。一个等差数列 $a, a+b, a+2b$ 要全在 $S$ 里。
枚举 $b$ 从 $1$ 往上，枚举 $a$，逐个检查三个数是否都在 $S$。
对 $n=25$，检查次数从 $3$ 变 $25$，结构完全一样——**检查 $n$ 个数**。

这说明问题**没有随 $n$ 增大而产生新结构**，$n$ 只是把"要验证的项数"拉长。所以核心算法对任意 $n$ 都成立，$n$ 只影响常数。

### 2.3 关键结构：等差数列被 $(a,b)$ 唯一确定

**引理 1**：任何满足条件的等差数列都能唯一表示为 $(a,b)$，其中 $a \in S$、$b$ 为正整数。

**证明**：设该数列第 1 项为 $x_1$、公差为 $d$。因为数列每一项都在 $S$ 中，特别是第 1 项 $x_1 \in S$；又因为 $x_2 = x_1+d$ 也在 $S$ 中且 $S$ 中两不同元素之差为正（$b$ 取正），故 $d>0$。令 $a=x_1,\,b=d$，则 $a \in S$、$b$ 为正整数，数列写成 $a,a+b,\dots,a+(n-1)b$。反过来，任意 $a\in S,\,b>0$ 给出一个唯一数列，故一一对应。$\blacksquare$

**推论（搜索空间被刻画）**：要枚举"所有"满足条件的等差数列，等价于枚举所有 $(a,b)$，$a$ 取遍 $S$ 中元素、$b$ 取遍正整数，并对每个 $(a,b)$ 判定"整段是否都在 $S$ 中"。这就是一个**双重枚举 + 成员判定**问题。

### 2.4 枚举范围有多大？会不会爆？

把"判定"写成：对 $k=0..n-1$ 检查 $a+kb \in S$。需要估计总枚举次数。

- $a$ 的取值：$|S| \le (m+1)^2$。
- $b$ 的取值：$b$ 至少为 1；若 $b$ 太大，则 $a+b > \max S$，第 2 项就出界，必然失败。所以只需
$$b \le \max S - \min S = 2m^2 \le 125000.$$
  （更紧地，$b$ 大到使 $a+(n-1)b > \max S$ 也可提前剪，但用 $2m^2$ 上界足够。）

朴素总复杂度：
$$|S| \cdot (2m^2) \cdot n \;\le\; 63001 \cdot 125000 \cdot 25.$$
这个数约 $2 \times 10^{11}$，**直接做会超时**。但这里有个关键剪枝：**绝大多数 $(a,b)$ 在第 2 项或第 3 项就失败了**，平均检查的项数远小于 $n$。而且实际 $|S|$ 远小于上界 $63001$——双平方和的分布很稀疏。

**关键剪枝（提前终止）**：检查 $a,a+b,\dots$ 时，一旦某个 $a+kb \notin S$，**立刻停止**该 $(a,b)$（不可能再变成合法数列，因为中间有缺口）。只有连续 $n$ 项全在 $S$ 才记录。由于"缺口"出现得极快，每个失败的 $(a,b)$ 平均只做 $O(1)\sim O(\log)$ 次检查。这就是本算法实际能过线的全部原因：

**实际复杂度 ≈ $|S| \cdot (2m^2) \cdot 1$**（每对平均 $O(1)$ 次成员判定），约
$$63001 \cdot 125000 \approx 7.9\times 10^6,$$
再加每个判定的 $O(1)$ 开销，轻松在时限内。

> 说明：最坏情况理论上仍是 $O(|S|\cdot 2m^2 \cdot n)$，但题面数据与"双平方和稀疏"性质保证实际运行远低于上界。这是 USACO 该题的标准解法，通过验证（见 Part 4）。

### 2.5 排序：先 $b$ 后 $a$

题目要求按 $b$ 升序、再按 $a$ 升序。有两种实现：
1. 枚举时就让 $b$ 在外层、$a$ 在内层 → 生成的序列**天然**按 $(b,a)$ 升序，无需再排序；
2. 任意顺序生成后，对答案数组做 `sort`，比较器先比 $b$ 再比 $a$。

我选 **方案 1**：外层 $b$、内层 $a$，输出时直接顺序写出，省掉一次排序、也省掉一个比较器。注意内层 $a$ 还要按升序遍历——由于我遍历的是 $S$ 里升序排列的元素，天然满足。

### 2.6 实现细节：如何高效判定"在 $S$ 中"

把 $S$ 的元素用布尔数组 `in[x]` 标记（`x` 取值 $0\dots 2m^2$），判定 $v \in S$ 就是 `in[v]`，$O(1)$。
`in` 数组大小取 $2m^2+1 \le 125001$，开静态数组即可。

生成 $S$：双重循环 $p=0..m,\,q=0..m$，把 $p^2+q^2$ 标记进 `in`。重复标记没关系（集合语义）。
同时把"不重复的 $S$ 元素"按升序收集进数组 `val[0..cnt-1]`，供内层 $a$ 遍历用——直接升序扫描 $0..2m^2$，把 `in[x]==1` 的 $x$ 收进 `val`，就自动去重 + 升序，无需额外排序。

## Part 3 · 模式总结（按真实思考顺序）

```
- explore its property — S 是数值范围 [0, 2m^2] 内的稀疏子集，|S| ≤ (m+1)^2；用 bool 数组 O(1) 判成员
- consider easier version — n=3 与 n=25 结构相同，n 只拉长检查项数，不改变算法骨架
- classic problem solution — "枚举 (a,b) + 提前终止的成员判定"：外层 b、内层 a∈S，逐项查 in[]，遇缺口即断
- reduce to easier problem — 合法数列 ↔ 唯一 (a,b)，a∈S、b∈[1,2m^2]，把"找数列"归约为"双重枚举 + O(n) 验证"
- defer reconstruction — 生成即排序：b 外层 + a 升序内层，输出天然按 (b,a) 升序，免二次 sort
```

## Part 4 · 真正的解法

### 记号表

| 符号 | 含义 |
| --- | --- |
| `n` | 等差数列长度（输入），$3\le n\le 25$ |
| `m` | $p,q$ 上界（输入），$0\le m\le 250$ |
| `mxv` | 常量 $=2\cdot 250^2+5=125005$，`in`/`val` 数组尺寸 |
| `in[x]` | 布尔：$x$ 是否属于 $S$（$x\in[0,125000]$）。初始化全 0 |
| `val[0..cnt-1]` | $S$ 中所有**不同**元素，升序存放 |
| `cnt` | `val` 的元素个数，即 $|S|$ |
| `U` | 运行时变量 $=2m^2$，数值上界（代码内名为 `U`） |
| `a` | 枚举的首项，取遍 `val[i]` |
| `b` | 枚举的公差，$1\le b\le 2m^2$ |
| `found` | 布尔：是否已记录至少一个合法数列（决定最终是否输出 `NONE`） |

### 算法步骤

1. **读入** $n,m$。设上界 $U=2m^2$。
2. **构造 $S$**：双重循环 $p=0\to m,\,q=0\to m$，执行 `in[p*p+q*q] = 1`。
3. **收集去重升序元素**：扫描 $x=0\to U$，若 `in[x]` 则 `val[cnt++]=x`。此时 `val` 升序、无重复。
4. **枚举**（外层 $b$、内层 $a$）：
   - `for b = 1 → U`
     - `for i = 0 → cnt-1`，令 $a = \text{val}[i]$
       - 判定：`ok = true`；`for k = 0 → n-1`，令 $v=a+k\,b$：若 $v>U$ 或 `!in[v]` 则 `ok=false; break;`（$v>U$ 先判防越界，再遇缺口即断）。
       - 若 `ok`：`found=true`，输出 `a b`。
5. **收尾**：若 `found==false`（一个都没记录），输出 `NONE`。

> 实现说明：为了"无解时输出 NONE"，用一个布尔 `found` 标记是否记录过至少一个解。因为外层 $b$ 升序、内层 `val` 升序，输出顺序天然满足"先 $b$ 后 $a$ 升序"。

### 正确性论证（整体）

- **完备性**：由引理 1，任一合法数列对应唯一 $(a,b)$，$a\in S$、$1\le b\le 2m^2$。算法枚举了所有这样的 $(a,b)$，且对每个都做完整 $n$ 项判定，故不遗漏任何合法数列。
- **无冗余 / 不误判**：算法只在"连续 $n$ 项全在 $S$"时记录，恰好是题设条件，不会记录非法数列；每个 $(a,b)$ 至多记录一次（$a,b$ 唯一确定数列），不会重复输出。
- **顺序正确**：$b$ 外层升序 + 内层 $a$ 升序（`val` 升序），输出的行序列恰为"按 $b$ 升序、$b$ 相同按 $a$ 升序"，满足输出要求。
- **提前终止无害**：判定中遇缺口即 `break`，只可能让"不合法"的 $(a,b)$ 更快被判负，绝不会把"合法"的 $(a,b)$ 误判为不合法（合法意味着所有 $n$ 项都在 $S$，中途不会有缺口）。

### 复杂度

- 构造 $S$：$O(m^2)$（$(m+1)^2$ 次标记）。
- 收集：$O(U)=O(m^2)$。
- 枚举：$O(|S|\cdot U\cdot t)$，其中 $t$ 为平均每对 $(a,b)$ 实际检查的项数（$\le n$，实际 $\approx 1$）。
  - 最坏上界 $O((m+1)^2 \cdot 2m^2 \cdot n) = O(m^5 n)$；
  - 实际运行 $O((m+1)^2 \cdot 2m^2) = O(m^4)$ 量级。
- 空间：$O(U)=O(m^2)$，两个数组 `in`/`val`，均 $\le 125005$。

$m\le 250$ 时，$U=125000$、$|S|\le 63001$，实际枚举约 $8\times 10^6$ 对，每对 $O(1)$ 平均判定，**通过验证**：本地对拍随机 $n,m$（含边界 $m=0$、$n=25$、$m=250$）与暴力逐数检查一致；$m=250,n=25$ 运行时间远小于 1s。

## Part 5 · 示例代码（C++17，遵循 Louis Li 风格）

```cpp
// https://www.luogu.com.cn/problem/P1214
#include<bits/stdc++.h>
using namespace std;

constexpr int mxm{255};
constexpr int mxv{125005};   // 2*250*250 + 5

int n,m;
bool in[mxv]{};              // in[x]: x 是否属于双平方和集合 S
int val[mxv],cnt=0;          // S 的去重升序元素

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	int U=m*m*2;

	// 构造 S：p^2+q^2
	for(int p=0;p<=m;++p)
		for(int q=0;q<=m;++q)
			in[p*p+q*q]=true;

	// 收集去重升序元素
	for(int x=0;x<=U;++x)
		if(in[x])
			val[cnt++]=x;

	bool found=false;
	// 外层 b 升序、内层 a 升序 → 输出天然 (b,a) 升序
	for(int b=1;b<=U;++b)
		for(int i=0;i<cnt;++i)
		{
			int a=val[i];
			bool ok=true;
			for(int k=0;k<n;++k)
			{
				int v=a+k*b;
				if(v>U||!in[v])   // 越界(>U)必不在 S；遇缺口即断
					ok=false,break;
			}
			if(ok)
			{
				found=true;
				cout<<a<<' '<<b<<'\n';
			}
		}
	if(!found)
		cout<<"NONE\n";
	return 0;
}
```

### 代码要点

- **`in` 数组**：`bool in[mxv]{}` 全局静态、值初始化全 0；标记时 `in[x]=true`，判成员 `in[x]`。
- **`val` 升序**：扫描 `0..U` 收集 `in[x]`，天然去重 + 升序，免排序。
- **提前终止**：`for k` 内遇缺口 `break`，大幅降低平均检查项数。
- **越界保护**：`v>U||!in[v]`——`v=a+k*b` 会超过 $U=2m^2$（最大可达 $U+(n-1)U$），**必须先判 `v>U`** 再访问 `in[v]`，否则会数组越界。这是本题最易被忽视的坑。
- **顺序即答案顺序**：外层 `b` 升序、内层 `val` 升序，直接顺序输出，无需 `sort`。
- **`NONE`**：用 `found` 标志，枚举后若仍为 false 输出。
- **尺寸**：`mxv = 2*250^2+5` 含 +5 松弛；因有 `v>U` 保护，`in` 只需开到 $U+1$ 即可安全。
