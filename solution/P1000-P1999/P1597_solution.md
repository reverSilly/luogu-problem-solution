# P1597 语句解析

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给一段只含变量 `a,b,c`、只有赋值语句的伪 Pascal 代码，语句格式固定为

```
变量:=右值;
```

其中左端是 `a`/`b`/`c`，右值是**一个**一位十进制数字或一个变量。未赋值的变量初值为 $0$。按顺序执行所有语句，输出最终 `a,b,c` 的值（空格分隔）。

### 输入输出格式

- **输入格式**：一整段合法代码，可能跨多行，总长度不超过 $255$。
- **输出格式**：一行三个整数，依次为 `a,b,c` 的最终值。
- **数据规模**：字符串长度 $\le255$，变量只有 $3$ 个。

### 关键约束分析

1. 输入可能**跨行**：用 `cin>>s` 只能读到第一个空白前的片段，必须以整行/整串方式读入。
2. 每条语句恰好 $5$ 个字符（`x` `:` `=` `v` `;`），因此可以完全不做通用的表达式解析，直接按位置取字符。
3. 右值是一位数字，不会被误认为多位数；也不会出现 `a:=10;` 这类形式。
4. 初值问题：`a,b,c` 都用全局数组存，默认 $0$，恰好符合"未赋值即 $0$"。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：要不要写一个真正的解析器

正规做法是词法分析 + 语法分析，但对本题是杀鸡用牛刀。观察语句模板 `[变量]:=[变量或一位整数];`：长度固定为 $5$，各位置的字符类别固定。于是可以把整段代码看成一个字符数组，用"模式匹配 + 跳步"扫一遍。

### 第二步：为什么可以靠 `:=` 定位语句

**引理 1（语句起点的唯一刻画）**：在把换行去掉后的字符串 $s$ 中，位置 $i$ 是一条赋值语句的起点，当且仅当 $s_i\in\{a,b,c\}$ 且 $s_{i+1}=':'$。

*证明*：必要性：语句首字符就是变量名，第二字符是 `:=` 的冒号。充分性：字符 `:` 在整个文法中只出现在 `:=` 的第二个位置。若 $s_{i+1}=':'$，则 $s_{i+1}s_{i+2}$ 必为 `:=`（否则该 `:` 无所归属，与输入合法矛盾），而 `:=` 之前必是变量名，故 $s_i$ 是一条语句的左端变量。因此满足条件的 $i$ 与语句起点一一对应。$\square$

由此，扫描时只要识别到 `s[i]∈{a,b,c} && s[i+1]==':' && s[i+2]=='='`，就确定了一条语句，右值在 $s_{i+3}$，语句在 $s_{i+4}=';'$ 结束。

**引理 2（跳步不遗漏、不重复）**：匹配到起点 $i$ 后，令扫描指针前进 $4$（到右值之后），不会漏掉任何语句，也不会把同一条语句识别两次。

*证明*：一条语句占据 $[i,i+4]$ 这 $5$ 个位置，下一条语句的起点 $j\ge i+5$。由于 $s_{i+3}$ 是右值（数字或变量），$s_{i+4}=';'$，这两个位置都不可能满足"下一字符是 `:`"，所以即使不跳步也不会误判；跳步只是加速。又 $j>i$，每个起点只被访问一次。$\square$

### 第三步：求值语义

**引理 3（顺序求值正确）**：按扫描顺序对每条语句执行 `val[左端]=当前右值`，最终状态与逐条执行原程序一致。

*证明*：对语句条数归纳。扫描顺序与程序顺序一致（引理 1、2 保证按出现位置先后处理）。第 $k$ 条语句执行时，前 $k-1$ 条已按原语义执行完毕，故 `val` 与程序执行到该处的状态相同；右值若是数字就直接取，若是变量就取该变量当前值——这与 Pascal 赋值"先算右值再写入"的语义相同。执行后状态仍一致。$\square$

**定理**：算法输出与程序真实执行结果相同。

*证明*：初值：未赋值变量为 $0$，全局数组默认 $0$，与题面一致；归纳步由引理 3。$\square$

### 第四步：一个容易忽略的实现细节

`val[左端]=x-'0'` 与 `val[左端]=val[x-'a']` 的区分条件是"右值字符是否为数字"。因为变量名只可能是 `a,b,c`，数字只可能是 `0..9`，两者的 ASCII 区间不重叠（`'0'..'9'` 为 $48\sim57$，`'a'..'c'` 为 $97\sim99$），判断 `x>='0'&&x<='9'` 即可，不需要额外查表。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 语句模板定长 $5$，字符类别固定，无需通用表达式解析。
- `reduce to easier problem` — 把"解析程序"降成"在一维字符串上找 `x:=` 模式"。
- `classic problem solution` — 模式匹配 + 指针跳步（每次跳过整条语句），$O(L)$ 单遍扫描。
- `handle input globally` — 先按行读入并拼接，消除换行带来的"跨行截断"问题。
- `simulate directly` — 用一个长度 $3$ 的数组模拟三个变量，按出现顺序就地更新。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $s$ | `s` | 去掉换行后拼接成的完整代码串 |
| — | `t` | `getline` 的临时行缓冲，逐行读入后追加到 `s` |
| $L$ | `s.size()` | 代码总长度 |
| $i$ | `i` | 主扫描指针，指向待检测的字符 |
| $v_a,v_b,v_c$ | `val[0..2]` | 三个变量的当前值，全局默认 $0$；`val[c-'a']` 即变量 `c` 的值 |
| $x$ | `x` | 右值字符（`s[i+3]`），可能是数字或变量名 |

### 算法步骤

1. 循环 `getline(cin,t)`，把每一行追加到 `s`（消除换行，使语句不被截断）。
2. 令 `i=0`，当 `i+3 < s.size()`：
   - 若 `s[i]` 是 `a..c` 且 `s[i+1]==':'` 且 `s[i+2]=='='`：
     - 取 `x=s[i+3]`；
     - 若 `x` 是数字，`val[s[i]-'a']=x-'0'`；否则 `val[s[i]-'a']=val[x-'a']`；
     - `i+=3`，随后循环的 `++i` 使指针落到 `;` 之后。
3. 输出 `val[0] val[1] val[2]`。

### 复杂度分析

- **时间复杂度**：$O(L)$，每个字符至多被检查常数次，$L\le255$。
- **空间复杂度**：$O(L)$ 存输入串，其余 $O(1)$。

### 正确性验证

引理 1 保证语句起点识别无歧义（`:` 仅出现在 `:=` 中），引理 2 保证跳步既不漏也不重，引理 3 保证按序更新与真实执行一致，定理给出最终正确性。数值范围：变量值只能是 $0\sim9$，`int` 足够；不必担心溢出。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1597 语句解析
// https://www.luogu.com.cn/problem/P1597
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

string s,t;
int val[3];                     // val[0..2] 对应 a,b,c, 未赋值为 0

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	while(getline(cin,t))
		s+=t;                   // 语句可能跨行, 先去换行拼成一串

	for(int i=0;i+3<(int)s.size();++i)
		if(s[i]>='a'&&s[i]<='c'&&s[i+1]==':'&&s[i+2]=='=')
		{
			char x=s[i+3];      // 右值: 一位数字或变量
			val[s[i]-'a']=x>='0'&&x<='9'?x-'0':val[x-'a'];
			i+=3;               // 跳过 ":=" 与右值
		}
	cout<<val[0]<<' '<<val[1]<<' '<<val[2]<<'\n';
	return 0;
}
```

### 易错点

1. **用 `cin>>s` 读入**：只会读到第一个空白，遇到换行就截断，后续语句全部丢失。必须 `getline` 循环拼接或逐字符读。
2. **保留换行就按 `;` 切分**：换行若落在 `;` 之后，片段会以 `\n` 开头，固定下标 `cur[0]` 取到的是换行而非变量名，解析立刻错位。先把整段拼成一串再解析最稳。
3. **循环边界写成 `i<s.size()`**：访问 `s[i+3]` 会越界（`std::string` 末尾访问未定义）。应写 `i+3<s.size()`。
4. **右值判断用 `isalpha`**：本题变量只可能是 `a,b,c`，但若用 `isdigit` 之外的自定义判断，注意 `char` 可能为负；直接比较 `'0'..'9'` 最稳。
5. **输出少了空格或换行**：要求三个数空格分隔并换行，用 `' '` 与 `'\n'`。
