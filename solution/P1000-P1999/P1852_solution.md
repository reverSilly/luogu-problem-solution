# P1852 [国家集训队] 跳跳棋

## 1. 重新读题

### 1.1 问题重述（人话版）

数轴上有 3 颗棋子，位置互不相同（整数）。一次操作：

- 任选一颗棋子 $P$；
- 让它沿数轴**跳过恰好 1 颗**棋子 $Q$（即 $P$ 与落点之间只有 $Q$ 这一颗棋子）；
- 跳过之后 $P$ 与 $Q$ 的距离保持不变（落点 = $2Q-P$）。

给出初始三颗棋子的位置与目标三颗棋子的位置（棋子不可区分）。先判断能否到达，能则输出最少跳动次数。

### 1.2 关键约束与规模暗示

- 坐标绝对值 $\le 10^9$：**步数可能达到 $10^9$ 量级**（例如间距为 $(1,10^9)$ 时要一路"蹭"过去），逐步模拟必然超时，必须发现整体的代数结构。
- 只有 3 颗棋子、每次只能跨 1 颗，状态空间看似很小，但坐标范围极大——这是典型的"把巨大状态空间压成一棵树，再用 LCA 求距离"的题。
- 坐标可负，跳动后可能越出原区间，要用 64 位。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先把三种棋子的顺序固定

棋子不可区分，所以任何状态都可以排序写成

$$a<b<c,\qquad x=b-a>0,\quad y=c-b>0.$$

状态由三元组 $(a,b,c)$ 描述，也可以看成"锚点 $a$ + 间距对 $(x,y)$"。下面先研究间距怎么变。

### 2.2 逐个分析四种跳法（含"恰好跨 1 颗"的合法性）

**（1）$a$ 跳过 $b$**：落点 $2b-a=a+2x$。
从 $a$ 到落点之间，$b$ 一定在中间。$c$ 是否也在中间？比较 $c$ 与 $a+2x$：
$$a+2x<c\iff 2x<x+y\iff x<y.$$
所以：

- $x<y$：只有 $b$ 在中间，合法；新状态 $(b,\,a+2x,\,c)$，间距变为 $(x,\,y-x)$，跨度从 $x+y$ 降到 $y$。
- $x=y$：落点恰好是 $c$，与已有棋子重合，不合法。
- $x>y$：$c$ 也在中间，跨过了 2 颗，不合法。

**（2）$c$ 跳过 $b$**：落点 $2b-c=b-y$。同理，合法当且仅当 $x>y$。新状态 $(a,\,b-y,\,b)$，间距 $(x-y,\,y)$，跨度降到 $x$。

**（3）$b$ 跳过 $a$**：落点 $2a-b=a-x<a$。从落点到 $b$ 之间只有 $a$，永远合法。新状态 $(a-x,\,a,\,c)$，间距 $(x,\,x+y)$，跨度 **变大**。

**（4）$b$ 跳过 $c$**：落点 $2c-b=c+y>c$，永远合法。新状态 $(a,\,c,\,c+y)$，间距 $(x+y,\,y)$，跨度 **变大**。

**引理 1（内向跳法唯一）**

当 $x\ne y$ 时，恰好有一种跳法能减小跨度：$x<y$ 时是 $a$ 跳过 $b$，$x>y$ 时是 $c$ 跳过 $b$；当 $x=y$ 时没有任何减小跨度的跳法。

**证明**：由上面的分类，两种"中间棋子往外跳"（3)(4) 一定增大跨度；两种"外侧棋子往中间跳"中，(1) 仅在 $x<y$ 时合法且减小跨度，(2) 仅在 $x>y$ 时合法且减小跨度，两者互斥。$x=y$ 时两者都因落点重合而非法。$\blacksquare$

### 2.3 状态图是一棵树（每个状态至多一个"父亲"）

把"减小跨度"的跳法看成走向父亲。引理 1 说明父亲最多一个。反过来，"中间棋子往外跳"的两种跳法总是合法，给出两个儿子（间距 $(x,x+y)$ 与 $(x+y,y)$，锚点会相应平移）。

**引理 2（外向跳法给出反向边，且互逆）**

- 对状态 $(x,y)$，两种外向跳法分别得到 $(x,x+y)$ 与 $(x+y,y)$；
- 若 $S'$ 是 $S$ 的一个内向跳法结果，则从 $S'$ 出发存在一个外向跳法回到 $S$。

**证明**：第一句由 2.2 中 (3)(4) 的间距计算直接得到。第二句逐项验证：$x<y$ 时 $S=(a,a+x,a+x+y)$ 的内向跳法是 $(a+x,a+2x,a+x+y)$，其间距为 $(x,y-x)$ 且 $y-x>0$ 意味着第一段更短，此时它的外向跳法"中间棋子跳过左端"恰好回到 $a$；$x>y$ 时对称。$\blacksquare$

因此**忽略绝对位置**时，所有间距状态构成若干棵二叉树：根是 $x=y$ 的状态，父亲唯一，儿子至多两个。自然的问题：绝对位置怎么办？

### 2.4 绝对位置：不同"平移"之间不连通

跳动的落点 $2Q-P$ 与所有坐标是线性关系，所以**把三颗棋子整体平移 $\delta$，所有可达状态也整体平移 $\delta$**。于是：

- 两个状态若根三元组（含绝对位置）不同，就一定不连通；
- 反之，若根三元组相同，两者都能沿唯一的父亲链爬到同一个根，而每条边都可逆（引理 2），故互相可达。

**引理 3（可达性判据）**

两个状态互相可达，当且仅当它们"一路向内"收缩后得到的**根三元组完全相同**。

**证明**：

- *必要性*：把每个状态连向它唯一的父亲（若存在）。跨度 $c-a$ 是正整数，且沿父亲严格递减（$x<y$ 时新跨度 $y<x+y$，$x>y$ 时新跨度 $x<x+y$），故父亲链不可能成环，每条链终止于唯一根。对任意一条边 $\{u,v\}$，它要么是"$v$ 是 $u$ 的父亲"，要么是"$v$ 是 $u$ 的儿子"，两种情况下 $u,v$ 的根都相同。于是沿任意路径根保持不变，互相可达的两个状态根相同。
- *充分性*：两根相同意味着两者都能沿唯一的父亲链走到同一个根；而每条父亲边都有反向的外向边（引理 2），把两条父亲链反向拼接就是一条合法路径。$\blacksquare$

**反例（只比较间距的 $\gcd$ 是错的）**：$(1,2,3)$ 的间距 $(1,1)$，它本身就是根；$(0,1,2)$ 的间距也是 $(1,1)$，也是根。两者 $\gcd$ 相同，但根三元组不同，实际无解。这说明绝对位置必须一起比较。

顺便得到一个漂亮的推论：

**引理 4（根的间距）**

间距 $(x,y)$ 一直收缩，最终必为 $(g,g)$，其中 $g=\gcd(x,y)$。

**证明**：内向操作是"大的减去小的"（$(x,y)\to(x,y-x)$ 或 $(x-y,y)$），正是欧几里得减法；$\gcd$ 在操作下不变；终止时 $x=y$，故 $x=y=\gcd(x,y)$。$\blacksquare$

### 2.5 距离 = 树上距离

既然每个连通分量是一棵以根为顶点的树，最少跳动次数就是树上两点距离：

$$\mathrm{dist}(u,v)=\mathrm{dep}(u)+\mathrm{dep}(v)-2\,\mathrm{dep}(\mathrm{lca}(u,v)),$$

其中 $\mathrm{dep}$ 是到根的步数（只走内向边）。

### 2.6 加速：一次算多步

坐标可达 $10^9$，逐步爬根不可行。观察同一种内向操作可以连续做很多次，且每次操作固定。

**引理 5（批量跳跃）**

设当前间距为 $(x,y)$，锚点为 $a$。

- 若 $x<y$：可以连续做 $t=\left\lfloor\dfrac{y-1}{x}\right\rfloor$ 次"$a$ 跳过 $b$"。做完后
  $$\big(a+tx,\ a+(t+1)x,\ a+x+y\big),$$
  新间距为 $(x,\ y-tx)$，且 $1\le y-tx\le x$。
- 若 $x>y$：可以连续做 $t=\left\lfloor\dfrac{x-1}{y}\right\rfloor$ 次"$c$ 跳过 $b$"。做完后
  $$\big(a,\ a+x-ty,\ a+x-(t-1)y\big),$$
  新间距为 $(x-ty,\ y)$，且 $1\le x-ty\le y$。

**证明**（$x<y$ 情形，$x>y$ 对称）：

对 $t$ 归纳证明位置公式。$t=1$ 时由 2.2(1) 得 $(a+x,a+2x,a+x+y)$，成立。设 $t$ 步后为 $(a+tx,\ a+(t+1)x,\ a+x+y)$，间距为 $(x,\ y-tx)$；若 $y-tx>x$，则可以再做一次（仍属 $x'<y'$），新锚点为旧的中间点 $a+(t+1)x$，新中间点为 $2(a+(t+1)x)-(a+tx)=a+(t+2)x$，最右点 $a+x+y$ 不变，公式对 $t+1$ 成立。

步数上限：第 $t$ 次操作要求操作前间距的第二分量 $y-(t-1)x$ 严格大于第一分量 $x$，即 $y-tx>0$，故 $t\le\left\lfloor (y-1)/x\right\rfloor$；取等号时 $y-tx\in[1,x]$。若 $y-tx=x$，下一步就到达根（$x=y$）；若 $<x$，下一步该换成对称的操作。$\blacksquare$

有了批量跳跃，求深度只要 $O(\log V)$ 段（每段对应欧几里得算法的一次除法），求"爬 $k$ 步"的结果也只要 $O(\log V)$。

### 2.7 求 LCA

1. 先分别求深度 $d_1,d_2$；
2. 把较深的一个用"爬 $|d_1-d_2|$ 步"对齐（批量跳跃，可能再用一次不完整的批量）；
3. 若对齐后相等，LCA 就是该点，距离 $=|d_1-d_2|$；
4. 否则二分最小的 $k$，使得"两点各爬 $k$ 步后相等"。由于祖先链唯一，"爬 $k$ 步后相等"关于 $k$ **单调**（一旦相等，再各爬一步仍相等），二分合法；上界取 $\min(d_1,d_2)$（爬到根必相等）。

距离 $=|d_1-d_2|+2k$。

### 2.8 失败尝试记录

- **逐步模拟**：间距 $(1,10^9)$ 需要 $10^9$ 次操作，超时。
- **只判 $\gcd$ 是否相等**：见 2.4 的 $(1,2,3)$ 与 $(0,1,2)$ 反例，误判为可达。
- **把"根间距"相等当作可达**：同样错，因为根三元组还带绝对位置。
- **直接对答案二分**：判定"$\le k$ 步是否可达"并不好写；改成树上 LCA 后一切自然。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 排序后只用间距 $(x,y)$ 描述；分析四种跳法，发现"恰好跨 1 颗"恰好让两种跳法互斥。
- **explore its property** — 内向跳法唯一，外向跳法两种，且互为逆操作。
- **classic structure** — 状态图是二叉树森林，根为 $x=y$；根间距为 $\gcd$。
- **reduce to easier problem** — 可达性 = 根三元组相同；最少步数 = 树上距离。
- **explore its property** — 同一种内向操作可批量做，公式封闭（欧几里得加速）。
- **classic problem solution** — 加速爬根 + 对齐深度 + 二分求 LCA。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `tri{a,b,c}` | `struct{i64,i64,i64}` | 有序的三颗棋子位置 | — | triple |
| `x,y` | `i64`（局部） | 间距 $b-a$、$c-b$ | 每步计算 | gap |
| `norm(x,y,z)` | 函数 | 三数排序成 $a<b<c$ | — | normalize |
| `climb(s,k)` | 函数 | 从状态 $s$ 向内走至多 $k$ 步（到根自动停） | — | 爬 |
| `dep(s)` | 函数 | 到根的步数 | — | depth |
| `s,t` | `tri` | 起点、终点 | 读入 | source/target |
| `r1,r2` | `tri` | 两边的根 | `climb(...,1LL<<62)` | root |
| `d1,d2` | `i64` | 两边深度 | `dep` | — |
| `diff` | `i64` | 深度差 | $|d_1-d_2|$ | — |
| `ans` | `i64` | 最少跳动次数 | 计算 | 输出 |

### 4.2 算法步骤

1. 读入两组坐标，各自 `norm` 成有序三元组 $s,t$。
2. `r1=climb(s,INF)`，`r2=climb(t,INF)`（$INF$ 取 $2^{62}$ 足够）。若 `r1 != r2`，输出 `NO`。
3. `d1=dep(s)`，`d2=dep(t)`；把较深者爬 $|d_1-d_2|$ 步，记 `diff=|d1-d2|`。
4. 若两点已相等，`ans=diff`；否则在 $[1,\min(d_1,d_2)]$ 上二分最小的 $k$ 使
   `climb(u,k)==climb(v,k)`，`ans=diff+2k`。
5. 输出 `YES` 与 `ans`。

### 4.3 `climb` / `dep` 的实现要点

循环处理当前间距：

- $x=y$：已到根，结束；
- $x<y$：$t=\min(k,\lfloor(y-1)/x\rfloor)$，套引理 5 的位置公式，`k-=t`；
- $x>y$：$t=\min(k,\lfloor(x-1)/y\rfloor)$，套公式，`k-=t`。

`dep` 与 `climb` 相同，只是把 `k` 换成累加步数。

### 4.4 复杂度

- `climb` / `dep` 的循环次数是欧几里得算法的段数，$O(\log V)$，$V\le2\times10^9$。
- LCA 二分 $O(\log V)$ 轮，每轮两次 `climb`，总计 $O(\log^2 V)$（不到 $2000$ 次基本运算）。
- 空间 $O(1)$。

## 5. 示例代码

```cpp
//
// 题目：P1852 [国家集训队] 跳跳棋
// https://www.luogu.com.cn/problem/P1852
// 本地自测通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

struct tri
{
	i64 a,b,c;
};

tri norm(i64 x,i64 y,i64 z)
{
	if(x>y)
		swap(x,y);
	if(y>z)
		swap(y,z);
	if(x>y)
		swap(x,y);
	return {x,y,z};
}
bool eq(tri x,tri y)
{
	return x.a==y.a&&x.b==y.b&&x.c==y.c;
}

tri climb(tri s,i64 k)
{
	while(k>0)
	{
		i64 x=s.b-s.a,y=s.c-s.b;
		if(x==y)
			break;
		if(x<y)
		{
			i64 t=(y-1)/x;
			if(t>k)
				t=k;
			i64 na=s.a+t*x;
			i64 nc=s.a+x+y;
			s.a=na;
			s.b=na+x;
			s.c=nc;
			k-=t;
		}
		else
		{
			i64 t=(x-1)/y;
			if(t>k)
				t=k;
			s.b=s.a+(x-t*y);
			s.c=s.b+y;
			k-=t;
		}
	}
	return s;
}

i64 dep(tri s)
{
	i64 d=0;
	while(true)
	{
		i64 x=s.b-s.a,y=s.c-s.b;
		if(x==y)
			break;
		if(x<y)
		{
			i64 t=(y-1)/x;
			d+=t;
			i64 na=s.a+t*x;
			i64 nc=s.a+x+y;
			s.a=na;
			s.b=na+x;
			s.c=nc;
		}
		else
		{
			i64 t=(x-1)/y;
			d+=t;
			s.b=s.a+(x-t*y);
			s.c=s.b+y;
		}
	}
	return d;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	i64 x1,y1,z1,x2,y2,z2;
	cin>>x1>>y1>>z1;
	cin>>x2>>y2>>z2;
	tri s=norm(x1,y1,z1),t=norm(x2,y2,z2);
	tri r1=climb(s,1LL<<62),r2=climb(t,1LL<<62);
	if(!eq(r1,r2))
	{
		cout<<"NO\n";
		return 0;
	}
	i64 d1=dep(s),d2=dep(t);
	tri u=s,v=t;
	i64 diff=0;
	if(d1>d2)
	{
		diff=d1-d2;
		u=climb(u,diff);
	}
	else
	{
		diff=d2-d1;
		v=climb(v,diff);
	}
	i64 ans;
	if(eq(u,v))
		ans=diff;
	else
	{
		i64 dd=min(d1,d2);
		i64 lo=1,hi=dd;
		while(lo<hi)
		{
			i64 mid=(lo+hi)>>1;
			if(eq(climb(u,mid),climb(v,mid)))
				hi=mid;
			else
				lo=mid+1;
		}
		ans=diff+2*lo;
	}
	cout<<"YES\n"<<ans<<'\n';
	return 0;
}
```
