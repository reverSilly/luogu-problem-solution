# P1514 [NOIP 2010 提高组] 引水入城

> 标签：动态规划 DP / 搜索 / 贪心 / 广度优先搜索 BFS / 深度优先搜索 DFS · 难度：省选/NOI-
> 本地题面：`P1514.md`（$1\le N,M\le 500$，海拔 $h_{i,j}\le 10^6$）。本文所用两组官方样例取自洛谷原题页 P1514（见 §4.4）。

## 1. 重新读题

**问题重述（人话版）**

给定一个 $N$ 行 $M$ 列的网格，每个格子 $(r,c)$ 有一座海拔为 $h_{r,c}$ 的城市（0-based 行号 $0\dots N-1$，列号 $0\dots M-1$）。

- **水源起点**：只能在**第 $0$ 行**（最北行，毗邻湖泊）的若干座城市建造“蓄水厂”。
- **水流传播**：如果某座城市已有水利设施（蓄水厂或输水站），它的水可以流向与它**四连通相邻**且**海拔严格更低**（$h_{\text{邻}}<h_{\text{当前}}$）的城市，并在那里建输水站。
- **目标**：让**第 $N-1$ 行**（最南行，毗邻沙漠的干旱区）的全部 $M$ 座城市都能通水。
  - 若存在某些第 $N-1$ 行的城市无论在第 $0$ 行怎么建厂都无法通水，第一行输出 `0`，第二行输出第 $N-1$ 行中**不可能通水的城市数量**；
  - 若第 $N-1$ 行全部 $M$ 座城市都能通水，第一行输出 `1`，第二行输出**最少需要建造几座蓄水厂**。

> 一句话版本：**在网格高度严格递减构成的 DAG 上，先判第 $0$ 行能否到达第 $N-1$ 行全集；若能，求最少的第 $0$ 行源点数以覆盖第 $N-1$ 行全部顶点。**

**题面里容易漏掉的条款**（其中第 1、2 条是 NOIP 赛场上著名的 90 分坑点）

1. **测试点 #4 明文给出 $N=1$** $\Rightarrow$ 此时第 $0$ 行**同时也是**第 $N-1$ 行！建在 $(0,j)$ 的蓄水厂本身就已经使干旱区城市 $(0,j)$ 拥有了水利设施（故 $N=1$ 时必然第一行输出 `1`），并且水还能从 $(0,j)$ 继续向左右海拔严格更低的相邻城市流动！
2. **到达第 $N-1$ 行之后水不会停止流动** $\Rightarrow$ 第 $N-1$ 行的城市之间同样有公共边，水到达 $(N-1,c)$ 后仍可向 $(N-1,c\pm 1)$ 甚至向北流回 $(N-2,c)$ 再绕道流向其它底行城市！若在 DFS/BFS 到达 `r == n-1` 时直接 `return`，会漏掉底行横向扩散，直接 WA。
3. **相等海拔不能流水** $\Rightarrow$ 题面要求“比它海拔**更高**”，即严格不等式 $h_{\text{邻}}<h_{\text{当前}}$。

**数据范围与规模感受**

$$1\le N,M\le 500,\qquad 1\le h_{r,c}\le 10^6 .$$

网格点数 $V=NM\le 2.5\times 10^5$，有向边数 $E\le 4NM\le 10^6$。一般有向图上的“最少源点覆盖目标集”是经典的 **集合覆盖问题（Set Cover，NP-hard）**，$M\le 500$ 时 $2^M$ 子集穷举或状压 DP 完全不可行。这强烈暗示：**平面网格 + 严格递减水流一定赋予了可达集合某种特殊几何结构**——即每个顶行源点能覆盖的底行城市在全可达前提下必然是一段**连续区间**！

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：先解决第一问（可判定性）与 DAG 结构

把网格看成有向图 $G=(V,E)$：从 $u=(r,c)$ 向四连通邻居 $v=(nr,nc)$ 连有向边 $u\to v\iff h_u>h_v$。

**引理 1（水流图是有向无环图 DAG，且第一问等价于多源可达性）**

1. 图 $G$ 中不存在有向环；
2. 干旱区全部城市可通水 $\iff$ 从第 $0$ 行所有顶点 $\{0\}\times\{0,\dots,M-1\}$ 出发的可达顶点集包含 $\{N-1\}\times\{0,\dots,M-1\}$。

**证明**：

1. 沿任意有向路径 $u_0\to u_1\to\dots\to u_k$（$k\ge 1$），由连边条件有 $h_{u_0}>h_{u_1}>\dots>h_{u_k}$，故 $h_{u_0}>h_{u_k}\Rightarrow u_0\ne u_k$，不可能成环。
2. 若在第 $0$ 行全部 $M$ 座城市都建蓄水厂，则凡是存在某条从某个 $(0,j)$ 出发的路径能到达的底行城市都会通水；反之，连全建都无法到达的底行城市，在任何子集方案下更不可能通水。故只需从第 $0$ 行全部顶点出发做一次搜索，统计第 $N-1$ 行未访问顶点数 `miss`：`miss > 0` 即回答第一问 `0 / miss`；`miss == 0` 则进入第二问。$\blacksquare$

### 2.2 核心突破：为什么全可达时每个蓄水厂覆盖的底行城市必为连续区间？

如果某个顶行城市 $(0,j)$ 能流到的底行城市集合 $S_j\subseteq\{0,\dots,M-1\}$ 是“断断续续”的（例如能流到列 $1$ 和列 $4$，却流不到中间的列 $2$），那我们就只能做 NP-hard 的一般集合覆盖。但平面四连通网格禁止“两条路径凌空交叉而不共享顶点”！

**引理 2（平面网格四连通路径的交叉引理与区间连续性定理）**

假设第 $N-1$ 行的所有城市 $0,1,\dots,M-1$ 均可从第 $0$ 行某处到达（即 `miss == 0`）。则对任意第 $0$ 行城市 $(0,j)$，其可达的第 $N-1$ 行列下标集合

$$S_j=\big\{c\in\{0,\dots,M-1\}:\ (0,j)\leadsto (N-1,c)\big\}$$

要么为空集，要么是一个**连续整数闭区间** $[L_j,R_j]$（即不存在 $c_1<c^\ast<c_2$ 使得 $c_1,c_2\in S_j$ 而 $c^\ast\notin S_j$）。

**证明**（反证法 + 平面网格 Jordan 分离性质）：

假设存在某个 $(0,j)$ 以及 $0\le c_1<c^\ast<c_2<M$，使得 $(0,j)$ 能到达 $(N-1,c_1)$ 和 $(N-1,c_2)$，但**不能**到达 $(N-1,c^\ast)$。

1. 取一条从 $(0,j)$ 到 $(N-1,c_1)$ 的有向路径 $P_1$，以及一条从 $(0,j)$ 到 $(N-1,c_2)$ 的有向路径 $P_2$。
2. 在平面矩形区域 $[0,N-1]\times[0,M-1]$ 中，路径 $P_1$ 与 $P_2$ 从同一个顶行点 $(0,j)$ 出发，分别落在底边的 $(N-1,c_1)$ 与 $(N-1,c_2)$。于是折线 $P_1\cup P_2$ 与底边线段 $[c_1,c_2]$ 围成一个闭合区域 $\Omega$，而底行点 $(N-1,c^\ast)$（因 $c_1<c^\ast<c_2$）位于底边开线段 $(c_1,c_2)$ 上。
3. 因为全部底行城市均可从第 $0$ 行到达，必存在某个顶行城市 $(0,j^\ast)$ 以及一条从 $(0,j^\ast)$ 到 $(N-1,c^\ast)$ 的四连通有向路径 $Q$。
4. 由于网格移动仅限上下左右四连通（相邻两步的曼哈顿距离为 $1$，不存在斜角跨越），任何从上边界 $r=0$ 走到 $(N-1,c^\ast)$ 的四连通路径 $Q$，要么起点 $(0,j^\ast)$ 就是 $(0,j)$，要么在从区域外进入 $(N-1,c^\ast)$ 的途中**至少与边界 $P_1\cup P_2$ 共享一个网格顶点 $w=(r_w,c_w)$**。
5. 一旦 $Q$ 与 $P_1\cup P_2$ 共享顶点 $w$：因为 $(0,j)$ 可沿 $P_1$（或 $P_2$）到达 $w$，而 $w$ 可沿 $Q$ 的后缀到达 $(N-1,c^\ast)$，由有向图可达性的传递性（两段路径上的每一步本身都满足高度严格递减 $h_u>h_v$！），将两段路径在 $w$ 处拼接即得到一条从 $(0,j)$ 到 $(N-1,c^\ast)$ 的合法输水路径，得出 $c^\ast\in S_j$，与假设矛盾！$\blacksquare$

> **为什么引理 2 必须以“全体底行城市均可从第 $0$ 行到达（`miss == 0`）”为前提？**
> 如果中间的 $(N-1,c^\ast)$ 是一座孤立的高山（连第 $0$ 行任何点都流不到它），那么路径 $Q$ 根本不存在，$S_j$ 就真的会裂成两段！但题面恰好规定：一旦 `miss > 0`，只需输出 `0` 和 `miss`，**根本不需要求最少蓄水厂**；只有当 `miss == 0` 时才进入第二问，此时引理 2 的前提 $100\%$ 满足！这正是本题题目设计最精妙的闭环。

### 2.3 反复碰壁：三个常见错误写法与反例

**失败 1：对每个顶行点独立跑一次无记忆 DFS/BFS（或把 `vis` 清空 $M$ 次）之后，在 `r == n-1` 时直接 `return`。**

- 反例（底行横向流动）：
  ```text
  2 3
  9 1 1
  8 7 6
  ```
- 水从 $(0,0)=9$ 流到 $(1,0)=8$ 后，因为 $(0,1)=(0,2)=1$ 无法向南供水，$(1,1)=7$ 和 $(1,2)=6$ 必须依靠水在底行从 $(1,0)=8\to(1,1)=7\to(1,2)=6$ 横向流动！若在 `r == n-1` 时终止递归，会误判 $(1,1),(1,2)$ 不可达而输出 `0 / 2`，真实答案为 `1 / 1`。

**失败 2：未考虑 $N=1$（测试点 #4）的边界。**

- 反例：
  ```text
  1 5
  5 5 5 5 5
  ```
- 当 $N=1$ 时，进入 `dfs(0, j)` 时 `r == n-1` 立即成立！若只在扩展邻居 `nr == n-1` 时才更新 `lft/rgt` 区间，而在起点 `r == n-1` 处忘了初始化 `lft[r][c] = rgt[r][c] = c`，则会误以为没有任何底行城市被覆盖，输出 `0 / 5`（真实答案为 `1 / 5`）。

**失败 3：把 DAG 记忆化写成普通有环图 DFS，重复清空 `vis` 跑 $M$ 遍导致常数或复杂度退化。**

- 因为引理 1 已经证明水流图是 **DAG**，任意顶点 $u=(r,c)$ 能到达的底行最小列号 $\mathrm{lft}[u]$ 与最大列号 $\mathrm{rgt}[u]$ 是只依赖 $u$ 自身的纯函数：
  $$\mathrm{lft}[u]=\min\Big(\{c\mid r=N-1\}\cup\big\{\mathrm{lft}[v]\ \big|\ u\to v\big\}\Big),$$
  $$\mathrm{rgt}[u]=\max\Big(\{c\mid r=N-1\}\cup\big\{\mathrm{rgt}[v]\ \big|\ u\to v\big\}\Big).$$
- 只需全局维护一个 `vis[r][c]`，每个格子**全图只进一次 `dfs`**，即可在严格 $O(NM)$ 时间内算出所有顶行点的区间 $[\mathrm{lft}[0][j],\mathrm{rgt}[0][j]]$！

### 2.4 归约到经典算法：区间完全覆盖贪心（附完整证明）

当 `miss == 0` 时，由引理 2，每个能到达底行的顶行点 $j$ 对应闭区间 $I_j=[\mathrm{lft}[0][j],\mathrm{rgt}[0][j]]$，我们要从 $\{I_0,\dots,I_{M-1}\}$ 中选出最少的区间覆盖整段 $\{0,1,\dots,M-1\}$。

**贪心策略**：维护当前尚未被覆盖的最小列下标 `cur`（初值 $0$）。只要 `cur < M`，就在所有满足 $\mathrm{lft}[0][j]\le\text{cur}$ 的区间中选右端点最大者 $\text{mxr}=\max_{\mathrm{lft}[0][j]\le\text{cur}}\mathrm{rgt}[0][j]$，将答案加 $1$，并令 `cur = mxr + 1`。

**引理 3（区间覆盖贪心的最优性，交换论证）**

上述贪心策略一定能在有限步内停机，且选出的区间数 `ans` 等于覆盖 $\{0,\dots,M-1\}$ 的最小区间数。

**证明**：

- **有限步停机**：在每一步中，因为列 `cur` 本身可由第 $0$ 行某点到达（`miss == 0`），必存在某个 $j$ 使得 $\mathrm{lft}[0][j]\le\text{cur}\le\mathrm{rgt}[0][j]$，故 $\text{mxr}\ge\text{cur}$，每步 `cur` 至少增加 $1$，至多 $M$ 步后 $\text{cur}\ge M$ 停机。
- **最优性（交换论证）**：设贪心依次选出的区间为 $G_1,G_2,\dots,G_k$，其右端点依次为 $r_1<r_2<\dots<r_k$（其中 $r_k=M-1$）。任取一个合法最优覆盖方案 $\mathcal{OPT}=\{O_1,O_2,\dots,O_s\}$（$s\le k$），将其按左端点升序排列（若左端点相同则按右端点降序，并删去被其它区间包含的冗余区间），记 $O_i=[a_i,b_i]$。
  对 $i=1,2,\dots,s$ 归纳证明 $r_i\ge b_i$：
  - **基例 $i=1$**：$\mathcal{OPT}$ 必须覆盖列 $0$，故 $a_1\le 0$。而 $G_1$ 是在所有满足 $\mathrm{lft}\le 0$ 的区间中取右端点最大者，故 $r_1\ge b_1$。
  - **归纳步**：设 $r_{i-1}\ge b_{i-1}$。由于 $\mathcal{OPT}$ 覆盖了列 $b_{i-1}+1$，必有 $a_i\le b_{i-1}+1\le r_{i-1}+1$。而贪心第 $i$ 步是在所有满足 $\mathrm{lft}\le r_{i-1}+1$ 的区间中取右端点最大者，故 $O_i$ 也在第 $i$ 步的候选池中，从而 $r_i\ge b_i$。
  当 $i=s$ 时，$r_s\ge b_s=M-1$，说明贪心在第 $s$ 步或之前就已经达到 $\text{cur}=r_s+1\ge M$ 而停机，故 $k\le s$。又 $s$ 是最优解，故 $k=s$。$\blacksquare$

## 3. 模式总结（Pattern Summary）

按实际思考顺序列出本题的可迁移模式：

- **explore its property（高度单调 $\Rightarrow$ DAG）** — “向海拔严格更低处流动”消除了环路，使每个格子的可达集合满足无后效性的 DAG 递推（引理 1）。
- **topological invariant（平面四连通不交叉 $\Rightarrow$ 区间连续性）** — 利用平面网格路径必相交传递可达性的 Jordan 分离性质，证明在全可达前提下每个顶行源点的底行可达集必为连续区间（引理 2），将指数级 Set Cover 降维为区间覆盖。
- **classic problem solution（DAG 记忆化搜索）** — 用 `lft[r][c]` 和 `rgt[r][c]` 维护可达底行最小/最大列号，全图每个点只访问一次，$O(NM)$ 完成全部区间预处理。
- **boundary discipline（底行继续流动 + $N=1$ 基例）** — 在 `r == n-1` 处仅做初值注入 `lft = rgt = c` 而不提前 `return`，同时兼容 $N=1$ 与底行横向传水。
- **classic problem solution（区间完全覆盖贪心）** — 每次在左端点 $\le\text{cur}$ 的区间中取右端点最大者推进（引理 3），$O(M^2)$（或排序后 $O(M\log M)$）收尾。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| `n, m` | `int` | 网格行数 $N$、列数 $M$ | 读入 | $1\le n,m\le 500$ |
| `h[r][c]` | `int [505][505]` | 城市 $(r,c)$ 的海拔高度（0-based） | 读入 | $\le 10^6$ |
| `vis[r][c]` | `bool [505][505]` | 记忆化搜索访问标记（同时表示能否从第 $0$ 行流到） | 全 `false` | 引理 1 |
| `lft[r][c]` | `int [505][505]` | 从 $(r,c)$ 出发能流到的第 $n-1$ 行**最小列号** | `inf` (`1145141919`) | left bound |
| `rgt[r][c]` | `int [505][505]` | 从 $(r,c)$ 出发能流到的第 $n-1$ 行**最大列号** | `-inf` (`-1145141919`) | right bound |
| `miss` | `int` | 第 $n-1$ 行中 `vis[n-1][j] == false` 的城市数 | $0$ | 第一问计数 |
| `cur, ans` | `int` | 贪心覆盖当前待覆盖列号、已选蓄水厂数量 | `0, 0` | 引理 3 |

> **初始化铁律**：`lft` 取 `min` 必须显式 `fill_n` 为 `+inf`，`rgt` 取 `max` 必须显式 `fill_n` 为 `-inf`；因为 0-based 列号本身包含 $0$，若依赖全局数组默认 $0$，无法到达底行的死胡同分支会静默污染出假列号 $0$！

### 4.2 编号步骤

1. 读入 $n,m$ 与高度矩阵 `h[0..n-1][0..m-1]`。
2. 用 `fill_n` 将 `lft` 全填 `inf`、`rgt` 全填 `-inf`。
3. 对顶行每一列 $j=0\dots m-1$：若 `!vis[0][j]`，调用 `dfs(0, j)`：
   - 置 `vis[r][c] = true`；
   - 若 `r == n-1`，置 `lft[r][c] = c, rgt[r][c] = c`（**不 return**，继续尝试四邻域）；
   - 枚举四连通邻居 $(nr,nc)$：若在界内且 `h[nr][nc] < h[r][c]`，对未访问者递归 `dfs(nr, nc)`，再用 `lft[nr][nc]` 与 `rgt[nr][nc]` 松弛当前点的 `lft[r][c]` 与 `rgt[r][c]`。
4. 扫描底行 $j=0\dots m-1$，统计 `!vis[n-1][j]` 的个数 `miss`：
   - 若 `miss > 0`，输出 `0\n` 与 `miss\n` 并结束。
5. 当 `miss == 0` 时，令 `cur = 0, ans = 0`；当 `cur < m` 时循环：
   - 在所有满足 `lft[0][j] <= cur` 的 $j\in[0,m-1]$ 中取 `mxr = max(rgt[0][j])`；
   - `++ans; cur = mxr + 1;`。
6. 输出 `1\n` 与 `ans\n`。

### 4.3 复杂度

- **时间**：DAG 记忆化搜索中每个格子入栈 $1$ 次、每条边检查 $1$ 次，耗时 $O(NM)$；区间贪心至多 $M$ 轮，每轮扫 $M$ 个区间，耗时 $O(M^2)$。总时间复杂度 $O(NM+M^2)=O(NM)$，最大规模 $N=M=500$ 时仅约 $10^6$ 次基本操作。
- **空间**：`h, lft, rgt` 三个 `int[505][505]` 加 `vis[505][505]` 与递归栈，总空间约 $6\text{ MB}$，远低于 $128\text{ MB}$ 限制。

## 5. 示例代码

### 5.1 主解：DAG 记忆化维护可达区间 + 贪心覆盖

```cpp
//
// 题目：P1514 [NOIP 2010 提高组] 引水入城
// https://www.luogu.com.cn/problem/P1514
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{505};           // N,M<=500 (+5 松弛)
constexpr int inf{1145141919};    // 114514 家族哨兵
constexpr int dr[4]{-1,1,0,0};
constexpr int dc[4]{0,0,-1,1};

int n,m;
int h[mxn][mxn];
bool vis[mxn][mxn];
int lft[mxn][mxn],rgt[mxn][mxn];  // (r,c) 可达的底行区间 [lft, rgt] (0-based 列号)

void dfs(int r,int c)
{
	vis[r][c]=true;
	if(r==n-1)
		lft[r][c]=c,rgt[r][c]=c;  // 底行自身先作为基例;注意底行之间仍可继续向更低处流动!
	for(int d=0;d<4;++d)
	{
		int nr=r+dr[d],nc=c+dc[d];
		if(nr<0||nr>=n||nc<0||nc>=m||h[nr][nc]>=h[r][c])
			continue;
		if(!vis[nr][nc])
			dfs(nr,nc);
		lft[r][c]=min(lft[r][c],lft[nr][nc]);
		rgt[r][c]=max(rgt[r][c],rgt[nr][nc]);
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			cin>>h[i][j];

	fill_n(&lft[0][0],mxn*mxn,inf);
	fill_n(&rgt[0][0],mxn*mxn,-inf);

	for(int j=0;j<m;++j)
		if(!vis[0][j])
			dfs(0,j);

	int miss=0;
	for(int j=0;j<m;++j)
		if(!vis[n-1][j])
			++miss;
	if(miss>0)
	{
		cout<<0<<'\n'<<miss<<'\n';
		return 0;
	}

	// 全体底行可达 => 每个顶行点覆盖底行一个连续闭区间 [lft[0][j], rgt[0][j]], 贪心区间覆盖 [0, m-1]
	int cur=0,ans=0;
	while(cur<m)
	{
		int mxr=-1;
		for(int j=0;j<m;++j)
			if(lft[0][j]<=cur)
				mxr=max(mxr,rgt[0][j]);
		++ans;
		cur=mxr+1;
	}
	cout<<1<<'\n'<<ans<<'\n';
	return 0;
}
```

### 5.2 对照实现：逐源 BFS 位掩码 + $2^M$ 子集穷举（仅用于小规模对拍）

```cpp
//
// 题目：P1514 [NOIP 2010 提高组] 引水入城
// 暴力基准: 逐个顶行源点独立 BFS 求精确可达底行位掩码(不依赖区间连续性引理), 再 2^m 子集枚举最少蓄水厂
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};
constexpr int dr[4]{-1,1,0,0};
constexpr int dc[4]{0,0,-1,1};

int n,m;
int h[mxn][mxn];
bool vis[mxn][mxn];
int mask[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			cin>>h[i][j];

	int all=0;
	for(int s=0;s<m;++s)
	{
		fill_n(&vis[0][0],mxn*mxn,false);
		queue<pair<int,int>>Q;
		Q.push({0,s});
		vis[0][s]=true;
		while(!Q.empty())
		{
			auto[r,c]=Q.front();Q.pop();
			for(int d=0;d<4;++d)
			{
				int nr=r+dr[d],nc=c+dc[d];
				if(nr>=0&&nr<n&&nc>=0&&nc<m&&!vis[nr][nc]&&h[nr][nc]<h[r][c])
				{
					vis[nr][nc]=true;
					Q.push({nr,nc});
				}
			}
		}
		int msk=0;
		for(int j=0;j<m;++j)
			if(vis[n-1][j])
				msk|=(1<<j);
		mask[s]=msk;
		all|=msk;
	}

	int full=(1<<m)-1;
	if(all!=full)
	{
		int miss=m-__builtin_popcount(all);
		cout<<0<<'\n'<<miss<<'\n';
		return 0;
	}

	int ans=m;
	for(int sub=0;sub<(1<<m);++sub)
	{
		int cov=0;
		for(int j=0;j<m;++j)
			if(sub>>j&1)
				cov|=mask[j];
		if(cov==full)
			ans=min(ans,__builtin_popcount(sub));
	}
	cout<<1<<'\n'<<ans<<'\n';
	return 0;
}
```
