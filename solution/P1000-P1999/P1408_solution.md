## 1. 重新读题

**题面原样（逐字）**：一个数列有 $n$ 个数字，我们定义一种操作：我们可以将**相邻两个数字同时除以它们的一个公约数**，这个操作所花费的代价为**作为除数的这个公约数的值**。我们经过若干次这样操作，可以将原数列变为**相邻的数对都互质**的数列。问达成要求的**最小代价**。

**输入格式**：第一行一个正整数 $n$；接下来 $n$ 行，每行一个整数，依次表示数列中的每个数字 $A_1,A_2,\ldots,A_n$（**每个数单独一行**，不是同一行 $n$ 个数——用 `cin>>a[i]` 循环读入两种排布都兼容）。
**输出格式**：一个整数，即最小代价。**不要求输出操作方案**（只要求代价值，但下文 §4.3 仍要证明"这个代价对应的操作序列确实存在且合法"）。

**白话重述**：每次挑一条相邻边 $(i,i+1)$，把两个数**同时**除以它们的某个公因子 $d$（$d\ge 2$ 才有意义），花 $d$ 元；问最少花多少元，能使得每一条相邻边都变成互质对。被除之后数会变小，后面的公因子也跟着变——所以"操作顺序会影响可行性"，必须先把它翻译成不受顺序影响的语言（§2.1）。

**数据范围**

| 量 | 范围 |
|---|---|
| $n$ | $1\le n\le 10000$ |
| $A_i$ | $1\le A_i\le 2\times 10^{7}$ |
| 子任务 | 30% 数据 $n\le 20$；100% 如上 |

分档信息量：$n\le20$ 单独给 30%，说明出题人设想的低分做法是**与 $n$ 指数相关**的搜索（枚举边的操作方案 $2^{n-1}$ 之类），而满分做法必须把 $n=10^4$ 压成**每位置多项**；$A_i\le 2\times10^7$ 这个"不整不圆"的上界（$\sqrt{2\times10^7}\approx 4472.14$）是在提示：**要分解质因数**，且试除只需要筛到 $4473$。

## 2. 思维链（Chain-of-thought）

### 2.1 第一步：把"操作"翻译成指数的语言（explore its property）

记 $v_p(x)$ 为素数 $p$ 在 $x$ 中的指数（唯一分解 $x=\prod_p p^{v_p(x)}$）。操作"边 $t=(i,i+1)$ 上除以 $d$"的效果是

$$v_p(A_i)\leftarrow v_p(A_i)-v_p(d),\qquad v_p(A_{i+1})\leftarrow v_p(A_{i+1})-v_p(d)\quad(\forall p),$$

前提是对**每个** $p$ 都有 $v_p(d)\le \min\big(v_p(A_i),v_p(A_{i+1})\big)$（当前值），这正是"$d$ 是这两个数的公约数"的充要条件。

**判据 0（公约数的指数刻画，双向——上面那句"充要条件"的证明）** 正整数 $d$ 是 $x,y$ 的公约数 $\iff$ $\forall p:\ v_p(d)\le\min\big(v_p(x),v_p(y)\big)$。
**证明** $\Rightarrow$：$d\mid x$ 给出整数 $k\ge1$ 使 $x=kd$，由唯一分解 $v_p(x)=v_p(k)+v_p(d)\ge v_p(d)$；对 $y$ 同理。$\Leftarrow$：若每个 $p$ 都满足 $v_p(d)\le v_p(x)$，则 $x/d=\prod_p p^{\,v_p(x)-v_p(d)}$ 的每个指数为非负整数，故 $x/d$ 是整数即 $d\mid x$；对 $y$ 同理。两个方向都只用唯一分解，不依赖其它数论事实。$\blacksquare$

**判据 1（互质的素因子刻画，双向）** 对正整数 $x,y$：$\gcd(x,y)=1\iff\forall p:\min\big(v_p(x),v_p(y)\big)=0$。

**证明** $\Rightarrow$：若某 $p$ 使 $v_p(x)\ge1$ 且 $v_p(y)\ge1$，则 $p\mid x$ 且 $p\mid y$，于是 $p\mid\gcd(x,y)$，得 $\gcd(x,y)\ge p>1$，矛盾。$\Leftarrow$：反设 $g=\gcd(x,y)>1$，则 $g$ 有素因子 $p$（任何 $>1$ 的整数都有素因子：取 $g$ 的最小大于 1 的因子即素数），$p\mid g\mid x$ 且 $p\mid g\mid y$，故 $v_p(x)\ge1,v_p(y)\ge1$，与条件矛盾。$\blacksquare$

于是"目标状态"完全等价于一串**逐素数**的不等式；而"操作"是**同一条边上两个端点的指数同时减少**。关键观察：一次操作里 $d$ 的素因子分解把多个素数**捆在一起**收费，于是自然的第一个问题是——能不能拆开算？

### 2.2 可行性：题面那句"可以将原数列变为…"必须自己证

先证明目标可达（否则"最小代价"可能不存在）。

**引理 1（可行，构造性）** 对任意输入数列，存在有限次操作使所有相邻对互质。

**证明** 考虑过程："只要存在相邻边 $(i,i+1)$ 使 $\gcd(A_i,A_{i+1})>1$，就取该 $\gcd$ 的某个素因子 $p$，在这条边上做一次 $d=p$ 的操作。"每做一步，$\Sigma=\sum_{i=1}^{n}A_i$ **严格减小**：因为两个被除的数都至少减半（$A_i/2<A_i$，$A_i\ge 1$ 时 $A_i\ge2$ 才能被 $p$ 整除），故 $\Sigma$ 至少减 $1$；而 $\Sigma\ge n\ge1$ 恒为正整数（除以公约数仍得正整数），故过程**必在有限步内停止**（步数 $\le\Sigma_0-n\le 2\cdot10^7\cdot10^4$）。停止时不存在 $\gcd>1$ 的相邻边，即按判据 1 所有相邻对互质。$\blacksquare$

这个"任意选边"的贪心只证可达、不省钱，但它保证后面每个子问题的可行集非空。

### 2.3 代价可分性：一个素数一个素数地算（reduce to easier problem）

**引理 2（合并不更省，双向用的下界）** 设 $d=\prod_p p^{a_p}\;(a_p\ge0)$。则 $d\ge\sum_p a_p\cdot p$，且等号当且仅当 $d$ 是素数（$a_p=1$）或 $d=4=2^2$。

**证明** 先用两步预备事实。事实 (a)：对 $u,v\ge2$ 有 $uv\ge u+v$，因为 $uv-u-v=(u-1)(v-1)-1\ge 1\cdot1-1=0$；等号 $\iff (u-1)(v-1)=1\iff u=v=2$。事实 (b)：对 $k$ 个 $\ge2$ 的整数 $q_1,\ldots,q_k$，归纳得 $\prod q_j\ge\sum q_j$：$k=1$ 平凡；设 $\prod_{j\le k}q_j\ge\sum_{j\le k}q_j$，记 $S=\sum_{j\le k}q_j\ge2$，则 $\prod_{j\le k+1}q_j\ge S\cdot q_{k+1}=S+q_{k+1}+S(q_{k+1}-1)-q_{k+1}$，而 $S(q-1)\ge q$ 等价于 $S\ge\frac{q}{q-1}$，由 $q\ge2$ 知 $\frac{q}{q-1}\le2\le S$ 成立，故 $\prod_{j\le k+1}\ge S+q_{k+1}=\sum_{j\le k+1}q_j$。把 $d$ 写成 $a_p$ 个 $p$ 相乘的全体重列 $q_1,\ldots,q_K$（$K=\sum_p a_p$，每个 $q_j\ge2$），即得 $d=\prod_j q_j\ge\sum_j q_j=\sum_p a_p p$。
**等号刻画**：$K=1$ 时 $\prod=q_1=\sum$ 恒成立，对应 $d$ 是素数且 $a_p=1$。设 $K\ge2$，看归纳的最后一步，等号要求两处同时取等：(i) $\prod_{j\le K-1}q_j=\sum_{j\le K-1}q_j$；(ii) $S(q_K-1)=q_K$，即 $S=\frac{q_K}{q_K-1}$，其中 $S=\sum_{j\le K-1}q_j$。因 $S$ 是 $K-1\ge1$ 个 $\ge2$ 的数之和，$S\ge2$，而 $q\ge2$ 时 $\frac{q}{q-1}\le2$（等号仅 $q=2$），故 (ii) 只能 $q_K=2$ 且 $S=2$，后者又逼出 $K-1=1$ 且 $q_1=2$。于是 $K=2$、$q_1=q_2=2$，即 $d=4=2^2$（此时 (i) 是 $K=1$ 的平凡等号 ✓）。$K\ge3$ 时 $S\ge4>2\ge\frac{q_K}{q_K-1}$，(ii) 严格，故整体严格不等。两条合起来即"$d\ge\sum_p a_pp$，取等当且仅当 $d$ 为素数或 $d=4$"。$\blacksquare$

**定理 1（按素数分解，双向夹逼）** 原问题的最小代价 $=\sum_p(\text{只处理素数 }p\text{ 的最小代价})$，其中"$p$ 的代价"定义为 $p\cdot(\text{该素数上的最小总削权次数})$。

**证明** 记素数 $p$ 上的"削权次数"为：把所有操作里 $d$ 中含的 $p$ 的次数累加。
- **下界**（全局 $\ge$ 分组和）：任一合法操作序列，对每个素数 $p$ 统计 $f_t^{(p)}=$ 各次操作在边 $t$ 上对 $p$ 的削权之和。终值指数 $g_i(p)=e_i(p)-\sum_{t\ni i}f_t^{(p)}\ge0$（因为每次操作都合法，削不掉不存在的因子），且终态相邻互质 $\Rightarrow$ 由判据 1，$\forall t\ \min(g_t(p),g_{t+1}(p))=0$。故 $\{f^{(p)}\}$ 是该素数子问题的一个**可行方案**。由引理 2，每次操作代价 $d\ge\sum_p a_p p$，求和得
$$\text{总代价}\ge\sum_p p\sum_t f_t^{(p)}\ge\sum_p p\cdot F_p^{*},$$
其中 $F_p^{*}$ 是素数 $p$ 子问题的最优值。
- **上界**（分组和 $\ge$ 全局可达）：对每个 $p$ 取最优 $f^{(p)}$，执行"$f_t^{(p)}$ 次在边 $t$ 上 $d=p$ 的操作"（任意顺序）。合法性逐条验证见 §4.3 引理 9：由 $\sum_{t\ni i}f_t^{(p)}\le e_i(p)$，顶点 $i$ 一生最多被削掉它拥有的 $p$，故每次动手时两端都还留着 $p$，$d=p$ 确为公约数；总代价恰为 $\sum_p p F_p^{*}$。
两侧夹逼得等号。$\blacksquare$

**为什么"只用素数 $d$"就够**：引理 2 说明把 $d=p^2$ 换成两次 $d=p$ 代价同为 $2p=p^2$（$p=2$）或更省（$p\ge3$ 时 $p^2>2p$），把 $d=pq$ 换成 $d=p,d=q$ 代价从 $pq$ 降到 $p+q$。因此**存在一个最优解，所有操作的 $d$ 都是素数**——这就是"能拆开算"的确切含义。

从此刻起，题目变成：**对每个素数 $p$ 单独求 $F_p^{*}$，答案 $=\sum_p p\cdot F_p^{*}$**。

### 2.4 单个素数：run 结构、边界强制与恒等式

固定素数 $p$，记 $e_i=v_p(A_i)$。把 $\{i:e_i\ge1\}$ 在指标轴上分成若干**连续段（run）**。

**引理 3（run 之间互不相干，双向）** 若 $e_i=0$，则在边 $(i,i+1)$ 上对 $p$ 的削权 $f_i=0$；反之，$e_i,e_{i+1}\ge1$ 的边才可能有用。故 $F_p^{*}=\sum_{\text{run}}(\text{该 run 内的最小 }\textstyle\sum f)$。

**证明** $\ge$ 方向：边 $(i,i+1)$ 上能削 $p$ 的前提是 $p$ 同时整除两端当前值，特别地初始 $e_i\ge1$ 且 $e_{i+1}\ge1$；故 $e_i=0$ 或 $e_{i+1}=0$ 时该边对 $p$ 的削权恒为 $0$。这说明一条 run 的内外之间没有任何"通道"：run 内部的削权只能在 run 内部的边上发生，边界边（一端 $e=0$）必为 $0$，于是总目标 $\sum f$ 按 run 拆成互不重叠的块，各块独立取最优即可（$\le$ 方向：把各 run 的最优拼起来仍满足"边界边为 $0$"，是全局可行方案）。$\blacksquare$

设一段 run 为 $1..L$（重编号），指数 $e_1,\ldots,e_L\ge1$，边界 $f_0=f_L=0$（$f_t$ 是第 $t$ 条内部边的削权，$t=1..L-1$）。约束：

$$\text{(C1)}\ f_t\in\mathbb Z_{\ge0};\qquad \text{(C2)}\ f_{i-1}+f_i\le e_i\ \ \forall i;\qquad \text{(C3)}\ (e_i-f_{i-1}-f_i)(e_{i+1}-f_i-f_{i+1})=0\ \ \forall i.$$

(C3) 就是判据 1 在素数 $p$ 上的体现（记 $g_i=e_i-f_{i-1}-f_i$ 为终值指数，则每条边至少一端 $g=0$）。

**引理 4（恒等式：省钱 = 多留）** $2\sum_{t=1}^{L-1}f_t=\sum_{i=1}^{L}e_i-\sum_{i=1}^{L}g_i$。

**证明** 每条内部边 $t$ 恰是一个顶点的左边（顶点 $t+1$）和另一个顶点的右边（顶点 $t$），故 $\sum_{i=1}^{L}(f_{i-1}+f_i)=2\sum_{t=1}^{L-1}f_t$（$f_0=f_L=0$ 不贡献）。又 $g_i=e_i-(f_{i-1}+f_i)$，两式相减即得。$\blacksquare$

价值：$F=\sum f$ 最小 $\iff$ $\sum g$ 最大（$\sum e$ 是常数）。所以"最省"就是"尽量把 $p$ 留在数列里"，只是留下的位置必须两两不相邻——一个"带容量的独立集"味道。

**引理 5（run 恒可行）** 任意 $e_1..e_L\ge1$ 都存在满足 (C1)(C2)(C3) 的 $f$。

**证明** 在 run 上重复："若存在边 $t$ 使 $g_t\ge1$ 且 $g_{t+1}\ge1$，就在该边做 $f_t\mathrel{+}=1$"。每步 $\sum g$ 减 $2$，且 $g\ge0$（选的是两端都 $\ge1$ 的边，减 1 后仍 $\ge0$，即 (C2) 始终保持），故有限步停止；停止时不存在两端都正的边，即 (C3) 成立。$\blacksquare$

（对照：令所有 $g_i=0$ 未必可行——$L=2,e=(1,2)$ 时 $f_1=e_1=1$ 与 $f_1=e_2=2$ 冲突；故必须允许"留一部分"。）

**引理 5a（规模界：状态维有界，且留下的位置是独立集）** 对 run 的任一可行 $f$：

1. **"$g>0$ 的位置互不相邻"**：设 $\mathcal I=\{i:g_i\ge1\}$。若 $i,i+1\in\mathcal I$ 则 $(\text{C3})$ 被违反，故 $\mathcal I$ 是路径的独立集，$|\mathcal I|\le\lceil L/2\rceil$；反向地，独立性正是 (C3) 的等价说法：$\forall t:\ \min(g_t,g_{t+1})=0\iff\mathcal I$ 独立（把 (C3) 的"乘积为 $0$"逐项翻译成集合语言，双向显然）。
2. **每条边与每个顶点的削权都不超过 $24$**：由 (C2) 和 $f\ge0$ 得 $f_t\le e_{t+1}\le\max_i e_i$，而 $e_i=v_p(A_i)\le\log_2(2\times10^7)<25$（$2^{24}=16777216\le2\cdot10^7<2^{25}=33554432$），故 $f_t\in[0,24]$，$25$ 个状态就够（代码里的 `mxe{25}` 由此而来，不是拍脑袋）。
3. **削权总量与操作步数**：由引理 4，$2F=\sum e-\sum g\le\sum e$，故 $F\le\frac12\sum_{i}e_i\le 12L$，整段 run 的操作步数（每单位削权一步 $d=p$）$\le12L$；全数列的操作总数 $\le\frac12\sum_i\Omega(A_i)\le\frac12\cdot24n=1.2\times10^5$。
4. **数值范围不越界**：全程只做"除以当前值的因子"，故每一项始终是 $[1,A_i]$ 内的整数，$A_i\le 2\times10^7$ 保证 $v_p$ 与所有中间量都在 `int` 里。

这四点合起来就是"元素个数/范围的可行性"：状态维、操作数、数值范围都是**有界且可事先算出**的，DP 的数组尺寸与 `int/i64` 的选择由它们决定（§2.8、§4.5）。

### 2.5 平方自由特例：$e_i\equiv1$ 时的闭式（consider easier version）

若这段 run 的 $e_i$ 全为 $1$（例如 $A_i$ 无平方因子），则 (C2) 变成 $f_{i-1}+f_i\le1$：即 $f_t\in\{0,1\}$ 且**被选的边互不相邻**。此时 $g_i=1-f_{i-1}-f_i$，$g_i=0\iff$ 顶点 $i$ 与某条被选边相邻。(C3) 变成：每条边都要"自己或被选"或"邻边被选"——这正是**路径 $P_{L-1}$ 的边支配集**问题。

**引理 6（闭式）** 一段 run 的指数全为 $1$（长 $L$）时，$F^{*}=\left\lceil\frac{L-1}{3}\right\rceil$。

**先钉死等价形式。** 记"被选边集"$D=\{t:f_t=1\}$。因 $e_i\equiv1$：(C2) 说 $f_{i-1}+f_i\le1$，于是 $f_t\in\{0,1\}$ 且 **$D$ 中不含相邻的边**；$g_i=1-f_{i-1}-f_i$，故 $g_i=0\iff f_{i-1}=1$ 或 $f_i=1\iff$ **顶点 $i$ 与 $D$ 中某条边关联**。(C3)（每条边的至少一端 $g=0$）于是变成：

$$(\star)\quad \forall t\in\{1,\ldots,L-1\}:\ t\in D\ \ \text{或}\ \ t-1\in D\ \ \text{或}\ \ t+1\in D,$$

即 $D$ 是边序列 $P_{L-1}$（$m=L-1$ 个点的路径）的一个**支配集**，且额外要求**独立**（$D$ 无相邻点）。下面双向证明"$D\mapsto f$、$f\mapsto D$"是一一对应且保代价。

**引理 6a（一一对应，双向）** 满足 (C1)(C2)(C3) 的 $f\in\{0,1\}^{m}$ 与"$P_m$ 的独立支配集 $D$"一一对应，且 $\sum f=|D|$。
**证明** $f\mapsto D$：上面已推 $D=\{t:f_t=1\}$ 独立（(C2)）且满足 $(\star)$（(C3)）；反之 $D\mapsto f$（$f_t=1\iff t\in D$）时，独立性给出 $f_{i-1}+f_i\le1$（因为 $f_{i-1}=f_i=1$ 意味着 $i-1,i$ 两条**相邻**边同属 $D$，与独立矛盾），即 (C2)；$(\star)$ 给出每个 $t$ 有 $t-1\in D$ 或 $t\in D$（则 $g_t=0$）或 $t\in D$ 或 $t+1\in D$（则 $g_{t+1}=0$），即 (C3)；(C1) 由 $\{0,1\}$ 自动成立。两映射互逆显然。$\blacksquare$

**证明（闭式）**
- **下界 $F\ge\lceil m/3\rceil$**：一条被选边 $t$ 至多支配 $\{t-1,t,t+1\}$ 三条边，$|N(t)|\le3$；$m$ 条边全被支配，故 $3|D|\ge m$。（这里 $m=L-1$ 条边要"各自或邻边被选"，即每个 $t$ 必须落在某条被选边的 $\pm1$ 邻域内。）
- **上界 $F\le\lceil m/3\rceil$（显式构造 $D$，按 $m\bmod 3$ 分类，逐条验独立与支配）**：
 1. $m=3k$：$D=\{3j-1:1\le j\le k\}=\{2,5,\ldots,3k-1\}$。独立：相邻元素差 $3\ge2$ ✓。支配：$3j-1$ 覆盖 $\{3j-2,3j-1,3j\}$，$j=1..k$ 的覆盖区恰好无缝拼成 $[1,3k]$ ✓。$|D|=k=\lceil m/3\rceil$ ✓。
 2. $m=3k+1\ (k\ge0)$：$D=\{2,5,\ldots,3k-1\}\cup\{3k+1\}$（$k=0$ 时前一集为空，$D=\{1\}$）。独立：前集内部差 $3$；最后一跳 $(3k-1)\to(3k+1)$ 差 $2\ge2$ ✓。支配：前 $k$ 个元素覆盖 $[1,3k]$（$k=0$ 时为空覆盖），$3k+1$ 覆盖 $\{3k,3k+1\}$，并起来 $[1,3k+1]$ ✓（$k=0$：$D=\{1\}$ 覆盖 $\{1,2\}\supseteq[1,1]$ ✓）。$|D|=k+1=\lceil(3k+1)/3\rceil$ ✓。
 3. $m=3k+2\ (k\ge0)$：$D=\{2,5,\ldots,3k-1\}\cup\{3k+2\}$。独立：差 $3$ 与差 $3$ ✓（$3k-1\to3k+2$ 差 $3$）。支配：前集覆盖 $[1,3k]$，$3k+2$ 覆盖 $\{3k+1,3k+2\}$，并起来 $[1,3k+2]$ ✓（$k=0$：$D=\{2\}$ 覆盖 $[1,3]\supseteq[1,2]$ ✓）。$|D|=k+1=\lceil(3k+2)/3\rceil$ ✓。

 三种情形下 $D$ 都是 $P_m$ 的独立支配集且尺寸 $\lceil m/3\rceil$，由引理 6a 得到一个可行 $f$，其 $\sum f=\lceil m/3\rceil$。
两侧合起来 $F^{*}=\left\lceil\frac{L-1}{3}\right\rceil$。$\blacksquare$

数值直觉：$L=2,3,4\to1$；$L=5,6,7\to2$；$L=8,9,10\to3$。每多三个位置才多花一次。这条闭式给出了"如果数据是按粗模型出的，标准答案长什么样"。

### 2.6 指数 $\ge2$ 时闭式失效 → 必须 DP（dissect why）

反例 $A=(2,8,2)$（$n=3$，$p=2$，$e=(1,3,1)$）：闭式给 $1\times2=2$，而真实最小是 $4$。逐条查（§4.4(6) 穷举全部 $f$）：$F=1$ 只有 $(f_1,f_2)\in\{(1,0),(0,1)\}$，分别得 $g=(0,1,1)$、$g=(1,1,0)$，都留下一条坏边；$F=2$ 的 $(1,1)$ 给 $g=(0,0,0)$，合法。原因：**"留多少"变成数值问题**，$f_{i-1}+f_i\le e_i$ 不再是 $0/1$ 约束。

**先做两个可以完全手算的通式，用来给 DP 定标。**

**$L=2$（一条边）**：(C2) 给 $f_1\le e_1$ 且 $f_1\le e_2$；(C3) 给 $g_1=0$ 或 $g_2=0$，即 $f_1=e_1$ 或 $f_1=e_2$。于是 $f_1\in\{e_1,e_2\}\cap[0,\min(e_1,e_2)]=\{\min(e_1,e_2)\}$（若 $f_1=e_1\le\min$ 则 $e_1=\min$，另一支同理），**唯一最优** $F^{*}=\min(e_1,e_2)$；终态留给较大指数那一端 $|e_1-e_2|$，其外侧邻位 $e=0$ 故仍互质 ✓。

**$L=3$ 的通式**（数值核对见 §4.4(2)(6)）：

$$F^{*}(e_1,e_2,e_3)=\min\big(e_2,\;e_1+e_3\big).$$

(C3) 展开为 $(g_1=0\lor g_2=0)\land(g_2=0\lor g_3=0)$，恰两种互斥情形：

- **(a) $g_2=0$（清中间）**：需 $f_1+f_2=e_2$，另受端点约束 $f_1\le e_1$（顶点 1 的 (C2)）与 $f_2\le e_3$。存在非负分解 $\iff e_2\le e_1+e_3$：$\Rightarrow$ 是 $e_2=f_1+f_2\le e_1+e_3$；$\Leftarrow$ 取 $f_1=\min(e_1,e_2)$、$f_2=e_2-f_1$，则 $f_2\ge0$ 且 $f_2=e_2-\min(e_1,e_2)\le e_3$（因 $e_2-e_1\le e_3$ 正是条件）。此情形代价 $F=f_1+f_2=e_2$。
- **(b) $g_2>0$（两端全清）**：则必须 $g_1=g_3=0$，得 $f_1=e_1,f_2=e_3$，代价 $F=e_1+e_3$；而 $g_2=e_2-e_1-e_3\ge1$ 要求 $e_2>e_1+e_3$，反过来 $e_2>e_1+e_3$ 时取 $f_1=e_1,f_2=e_3$ 确实给出 $g_1=g_3=0$、$g_2>0$，(C2)(C3) 全满足。

两情形的可用条件 $e_2\le e_1+e_3$ 与 $e_2>e_1+e_3$ **互补且覆盖了全部**，故任一 $L=3$ 的 run 只有一个可行档位，其值恰是 $\min(e_2,e_1+e_3)$。$\blacksquare$

关键启示：最优方案里 $g_i$ **可以取中间值**，而决定 $f_i$ 的是"$f_{i-1}$ 已经占用了 $e_i$ 的多少"——所以**状态必须携带上一条边的削权 $f_{i-1}$**，纯粹的贪心/闭式不可能覆盖。

**DP（引理 7，状态与转移，双向正确性）** 按 run 内顶点从左到右，状态
$$dp[c][z]=\text{已固定 }f_1..f_{i-1},\ f_{i-1}=c,\ [g_{i-1}>0]=z\ \text{时的最小}\ \textstyle\sum_{t=1}^{i-1}f_t .$$
初值 $dp[0][0]=0$（虚拟顶点 $0$：$f_0=0,g_0=0$），其余 $+\infty$。转移（当前顶点指数 $e$）：要求 $c\le e$，记 $r=e-c$；
- $z=1$（左边留下了正的 $g$）：本点必须清零，$f_i=r$，新状态 $dp'[r][0]$；
- $z=0$：$f_i$ 可取 $0..r$ 任一值，$g_i=r-f_i$，新状态 $dp'[f_i][\,[f_i<r]\,]$。
终值 $\min_z dp[c=0][z]$（必须有 $f_L=0$）。

**证明** $\Rightarrow$：给定合法 $f$，逐点检查：$g_{i-1}>0$ 时 (C3) 强制 $g_i=0$，即 $f_i=e_i-f_{i-1}=r$，正是 $z=1$ 分支；否则 $f_i$ 只需满足 $0\le f_i\le r$（即 (C2)），$g_i=r-f_i$ 决定新 $z$，故 $f$ 沿 DP 有一条路径，代价 $\le\sum f$ 且末态 $f_L=0$。$\Leftarrow$：DP 的任一路径给出 $f_t\ge0$、$f_{i-1}+f_i=c+f_i\le e_i$（(C2)）、并且 $z=1$ 时强制 $g_i=0$、$z=0$ 时才允许 $g_i>0$（即不可能出现相邻两个 $g$ 都正，(C3)）；末态 $c=0$ 就是 $f_L=0$。故一一对应，最小值相同。$\blacksquare$

**状态为什么"只带 $(c,z)$ 就够"（无后效性的证明）** 设已经固定 $f_1..f_{i-1}$。对剩下的顶点 $i..L$，约束里凡是牵涉左边的只有三类：顶点 $i$ 的 (C2) 用到 $f_{i-1}$（即 $c$）；边 $(i-1,i)$ 的 (C3) 用到 $g_{i-1}$，而"$g_{i-1}$ 是否为正"只有两种后果——为正则强制 $g_i=0$、为零则无强制（用 $z$ 表示）；以及目标函数里 $\sum_{t<i}f_t$ 的具体分布只通过它的**和**进入代价，故用该和作为 $dp$ 值。因此两个可行前缀只要 $(c,z,\sum f)$ 相同，它们能延拓出的后缀集合与后缀代价完全一致 ⟹ 保留 $dp$ 最小值不丢最优（$\Rightarrow$ 由上述"后缀集合相同"，$\Leftarrow$ 由引理 7 的双向映射）。这也解释了为什么 $z$ 只需要 1 bit：$g_{i-1}$ 的**具体数值**对后面毫无影响（$e_{i-1}$ 已被 $f_{i-2}+f_{i-1}$ 结算完毕），只有"$>0$ 还是 $=0$"会改变下一条边的强制与否。

**复杂度（引理 8）** 顶点 $i$ 处的转移数 $=\sum_{c=0}^{e_i}(e_i-c+1)=\frac{(e_i+1)(e_i+2)}{2}$，$z$ 维至多 2 倍。故
$$T_{DP}=O\!\Big(\sum_{i=1}^{n}\sum_{p\mid A_i}(\log_p A_i)^2\Big).$$
单点数上界：目标是 $\max\sum_p(e_p+1)(e_p+2)$ s.t. $\prod p^{e_p}\le2\cdot10^7$。由于 $(e+1)(e+2)\approx e^2$ 而"指数预算"按 $\ln p$ 计价，把预算全砸在最小素数上最划算：$A=2^{24}=16777216$ 给 $25\times26=650$；$2^{22}\cdot3=12582912$ 给 $23\times24+2\times3=558$；$2^{21}\cdot3^2=18874368$ 给 $22\cdot23+3\cdot4=518$；$2^{20}\cdot3\cdot5=15728640$ 给 $21\cdot22+6+6=474$；$8$ 个不同小素数之积（全 $e=1$）给 $8\times6=48$。故**单个数的总转移量 $\le650$**，全数列 $\le650n=6.5\times10^6$；若只按"每次出现 $\le650$"粗估则是 $650\times8n=5.2\times10^7$，两者都远在 $10^8$/s 的常识量级之下。典型情形（多数 $e_p=1$）约 $48n\approx5\times10^5$。状态表只有 $2\times25\times2$ 个 `int`（滚动），内存 $O(1)$。

### 2.7 不走的路（算账）

- **(a) 线性筛最小质因子到 $2\times10^7$**：`int lpf[20000005]` 占 $8\times10^7$ B $\approx76$ MiB，常见 128 MiB 限制下与别的数组并存很紧；内层操作 $O(X)=2\times10^7$。改成"筛到 $\sqrt{2\times10^7}\approx4473$（$O(5\times10^3)$，几 KB）+ 逐数试除"，最坏 $10^4\times\pi(4473)=10^4\times600=6\times10^6$ 次取模，**时间与内存双赢**，且余因子 $>1$ 时必为**指数 1 的大素数**（否则它有 $\le\sqrt{2\times10^7}$ 的素因子已被除掉，见 §4.3 引理 10）。
- **(b) 全局最短路（对指数向量做 Dijkstra/记忆化搜索）**：状态是 $\prod_i(e_i+1)$，$n=10^4$ 时天文数字；只有 §1 提到的 $n\le20$ 档勉强能想象（$20$ 个数、每个指数 $\le24$ 仍是 $25^{20}$，实际只有限在小 $A_i$ 的搜索图里才可行），但它已被素数分解 + DP 完全覆盖，且不需要指数级时间。
- **(c) 直接枚举每条边的 $d$**：边 $n-1$ 条、每条 $d$ 可选全体公因子，是指数级；分解成"素数 $\times$ run $\times$ DP"后才多项。
- **(d) 最小割建模**：单素数、全 $e=1$ 时可以写成"选边覆盖"，但 $e\ge2$ 时约束 (C3) 是"乘积为 $0$"的非次模条件，不是一般的割能表达的；DP 更直接。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 用 $v_p$ 把"除以公约数"翻译成"一条边两端同时减同一个向量 $(v_p(d))_p$"，互质条件变成逐素数的 $\min=0$（判据 1，双向）。
- **feasibility first** — 引理 1：$\sum A_i$ 严格下降 $\Rightarrow$ 题面承诺的"能变成"成立，后续可行集非空。
- **reduce to easier problem** — 引理 2（$d\ge\sum a_pp$，等号刻画）+ 定理 1：全局最小 $=\sum_p pF_p^{*}$，素数之间彻底解耦。
- **考虑更简单版本 / 子任务** — $n\le20$ 的指数档提示"分解 + 局部化"；固定一个素数后先看结构。
- **explore its property（第二层）** — 引理 3：$e_i=0$ 的边强制 $f=0$，run 之间互不相干，问题缩到一段连续段上。
- **经典转化** — 引理 4：$2F=\sum e-\sum g$，"最小花费"变"最大保留"，即带容量的独立集。
- **closed form（平方自由特例）** — 引理 6：$e\equiv1$ 时等价于路径 $P_{L-1}$ 的**独立边支配集**，下界"一边管三边"、上界显式构造，得 $\lceil(L-1)/3\rceil$。
- **dissect the failure → generalize** — $A=(2,8,2)$ 否掉闭式；$L=3$ 通式 $\min(e_2,e_1+e_3)$ 暴露"$f_{i-1}$ 占用容量"这一记忆效应。
- **classic problem solution（第二个）** — 引理 7：路径 DP，状态 $=$（上一条边的削权 $c$，$g_{i-1}$ 是否为正），双向一一对应。
- **why sieve/globalsearch fails** — 大筛 $76$ MiB vs 试除 $6\times10^6$；全局状态 $\prod(e_i+1)$ 爆炸。
- **overflow guard** — $p\cdot F$ 到 $4.8\times10^{12}$，`ans` 必 `i64`；$F$ 本身 `int` 够。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 存什么 / 初值 | 类型 | 记忆点 |
|---|---|---|---|
| `n,a[mxn]` | 数列，$A_0..A_{n-1}$（**内部 0-based**） | `int` | $a[i]=1$ 时不产生任何出现 |
| `pri[mxp],pcnt,vis[mxp]` | 线性筛出的素数表，筛到 $5004\gg4473$ | `int`/`bool` | $\sqrt{2\times10^7}$ 即够试除 |
| `O[mxo]`=`{p,pos,e}` | 一次"出现"：素数 $p$ 在位置 `pos` 的指数 `e` | `struct occ` | 共 `ocnt` $\le 8n$ 条 |
| `cmp` | 先按 $p$ 再按 `pos` 升序 | 比较器 | 同素数聚在一起、位置递增 |
| `dp[2][mxe][2]` | 滚动层：$f_{i-1}=c$、$[g_{i-1}>0]=z$ 时的最小 $\sum f$ | `int`，`inf=1e9` | 未定义态必须先填 `inf`（全局数组默认 0！） |
| `calc(l,r)` | run `O[l..r]`（同 $p$、`pos` 连续）的最小 $F$ | `int` | 引理 7 的机器化 |
| `ans` | $\sum_p p\cdot F_p^{*}$ | `i64` | 上界 $10^{11}$ |

### 4.2 算法步骤

1. 读 $n$ 与 $a[0..n-1]$；线性筛 `sieve()` 得 `pri[0..pcnt)`。
2. 逐数试除分解：对 $j$ 满足 `pri[j]*pri[j]<=x`，若整除则数出指数 $e$ 并写入 `O[ocnt++]={pri[j],i,e}`；结束后 $x>1$ 补 `{x,i,1}`（引理 10）。
3. `sort(O,O+ocnt,cmp)`。
4. 扫描：同 $p$ 归为一组（下标区间 `[i,j)`），组内再按 `pos` 连续性切成 run `[l,r]`；每段做 `calc(l,r)`，`ans+=(i64)p*F`。
5. 输出 `ans`。

**复杂度**：筛 $O(5\cdot10^3)$；分解最坏 $6\times10^6$ 次取模；排序 $O(m\log m)\le8\cdot10^4\times17\approx1.4\times10^6$；DP $\le6.5\times10^6$（逐数界，粗界 $5.2\times10^7$，典型 $5\times10^5$，见引理 8）。合计 $\le10^7$ 量级基本操作（粗界 $10^8$），空间为 $O(m)$ 的出现表 + $O(1)$ 的状态表（$\approx1$ MB，见 §4.5）。

### 4.3 构造正确性的逐条验证

引理 9（操作方案存在且满足题面全部条件）把 §2.3 上界的四条逐条钉死：

**引理 9** 设对每个素数 $p$ 给出满足 run 约束 (C1)(C2)(C3) 的 $f^{(p)}$。则存在操作序列，其 (a) 每步合法、(b) 终态为整数列且每项 $\ge1$、(c) 所有相邻对互质、(d) 总代价 $=\sum_p p\sum_t f_t^{(p)}$。
**证明** 执行 $\sum_t f_t^{(p)}$ 次 $d=p$ 的操作（按任意顺序展开成一张操作表）。
(a) 考察某次作用在边 $(i,i+1)$ 的 $d=p$ 操作：动手之前，顶点 $i$ 上已消耗的 $p$ 次数 $\le$ 该顶点总消耗 $\sum_{t\ni i}f_t^{(p)}\le e_i(p)$（(C2) 求和），而本次操作是其总消耗中的**某一次**，故已消耗 $\le e_i(p)-1$，即当前 $v_p(A_i)\ge1$，同理 $v_p(A_{i+1})\ge1$，于是 $p\mid\gcd(A_i,A_{i+1})$，$d=p$ 确为公约数 ✓。
(b) 每步除以当前值的因子，商仍为整数且 $\ge1$（被除数 $\ge$ 除数 $\ge2$ 时商 $\ge1$；且由 (a) 的预算，绝不出现"除不尽"）✓。
(c) 终值指数 $g_i(p)=e_i(p)-\sum_{t\ni i}f_t^{(p)}\ge0$，(C3) 给出每条边至少一端 $g=0$，即 $\min(g_i(p),g_{i+1}(p))=0$ 对一切 $p$ 成立，由判据 1（双向）得 $\gcd(A_i',A_{i+1}')=1$ ✓。
(d) 每步代价恰为素数 $p$，步数 $\sum_t f_t^{(p)}$ ✓。$\blacksquare$

引理 10（试除后余因子是大素数，双向）：设 $x\le2\times10^7$，按递增素数 $q$ 反复除尽、循环条件为 $q^2\le x_{\text{当前值}}$，结束时余 $r$。若 $r>1$ 则 $r$ 为素数且 $v_r(\text{原}x)=1$。**证明** 若 $r$ 合，取 $r$ 的最小素因子 $q\le\sqrt r$，则 $q^2\le r\le x_{\text{当前值}}$，循环条件在 $q$ 处仍成立、$q$ 必被试到并整除 $r$，与"除尽后余 $r$"矛盾（代码里循环只跑到 `pri[j]*pri[j]>x` 就停，$q$ 在这之前 ✓）。若 $r$ 为素数但 $v_r\ge2$，则 $x_{\text{当前值}}=r^{v_r}\cdot1\ge r^2$，同样有 $r^2\le x_{\text{当前值}}$，$r$ 会被试到（$r\le\sqrt{2\times10^7}\le4473$，在素数表内），矛盾。故 $r$ 是素数且只出现一次。反向：$r$ 为素数且 $r\mid$ 原 $x$ 时当然贡献一次出现，指数由除法次数如实记录 ✓。$\blacksquare$

### 4.6 不确定点

- **无官方样例**：题面没有任何样例输入输出，无法对标，也无法判断"数据疑似有误"具体错在哪一档。本文的口径是"字面模型 + 指数敏感 DP"，并给出平方自由闭式作对照。
- 若评测数据/标准答案按"**每素数每边至多处理一次**"（即闭式 $p\lceil(L-1)/3\rceil$）生成，本文代码在含高次幂的数据上与标准答案**不同**（差例如 $(2,8,2)$）；反之若按字面模型生成，粗口径做法必 WA。这是该标注最可能的实质含义，也是本文选择字面模型并另证闭式的原因。
- 另一可能是"数据范围与题面不符"（如 $A_i$ 实际可达 $10^9$）：那只需把 `mxp` 提到 $\sqrt{10^9}=31623$ 量级、`mxe` 提到 30，模型与 DP 完全不变（引理 8、§2.8 的算式重新代入即可）。
- $n=1$ 时答案为 $0$（没有任何相邻对），题面没有排除它，代码路径：`ocnt` 有若干出现但每段 run 长 $1\Rightarrow F=0$ ✓。

## 5. 示例代码（C++）

```cpp
// P1408 互质数列 sequence
// 每次把相邻两数同除一个公约数 d 花费 d；使所有相邻对互质的最小代价
// 按素数拆分：答案 = sum_p p * (该素数各 run 上最小 sum f)   —— 见题解 §2.3/§2.6
// https://www.luogu.com.cn/problem/P1408
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};         // n<=10000 +5
constexpr int mxo{mxn*8+5};       // 出现总数 <= 8n：2*3*5*7*11*13*17*19<=2e7，再乘 23 就超
constexpr int mxp{5005};          // 只需素数到 sqrt(2e7)=4472.2，+5 松弛取 5005
constexpr int mxe{25};            // 指数上限：2^24<=2e7<2^25
constexpr int inf{1e9};

int n,a[mxn];
int pri[mxp],pcnt;
bool vis[mxp];
struct occ{int p,pos,e;};
occ O[mxo];
int ocnt;
int dp[2][mxe][2];                // 滚动层：dp[f_{i-1}][g_{i-1}>0]，初值必须填 inf

bool cmp(occ x,occ y)
{
	return x.p!=y.p?x.p<y.p:x.pos<y.pos;
}

void sieve()
{
	for(int i=2;i<mxp;++i)
	{
		if(!vis[i])
			pri[pcnt++]=i;
		for(int j=0;j<pcnt&&i*pri[j]<mxp;++j)   // mxp 很小，乘积不溢出
		{
			vis[i*pri[j]]=true;
			if(i%pri[j]==0)
				break;                          // 只由最小素因子生成一次
		}
	}
}

void factor(int x,int pos)
{
	for(int j=0;j<pcnt&&pri[j]*pri[j]<=x;++j)   // x<=2e7，pri[j]^2<=2.5e7，int 安全
		if(x%pri[j]==0)
		{
			int e=0;
			while(x%pri[j]==0)
				x/=pri[j],++e;
			O[ocnt++]={pri[j],pos,e};
		}
	if(x>1)
		O[ocnt++]={x,pos,1};                     // 余因子是大素数且指数 1（引理 10）
}

int calc(int l,int r)                          // O[l..r]：同一素数、位置连续的一段 run
{
	for(int c=0;c<mxe;++c)
		for(int z=0;z<2;++z)
			dp[0][c][z]=dp[1][c][z]=inf;         // 全局数组默认 0，必须先填 inf
	dp[0][0][0]=0;                               // 虚拟顶点 0：f_0=0，g_0=0
	int cur=0;
	for(int i=l;i<=r;++i)
	{
		int nxt=cur^1;
		for(int c=0;c<mxe;++c)
			for(int z=0;z<2;++z)
				dp[nxt][c][z]=inf;
		for(int c=0;c<mxe;++c)
			for(int z=0;z<2;++z)
			{
				if(dp[cur][c][z]>=inf)
					continue;
				int rem=O[i].e-c;                // 本点还能被"留下"多少
				if(rem<0)
					continue;                    // 左边削得比本点的指数还多，非法
				for(int f=(z?rem:0);f<=rem;++f)   // z=1 必须清零 => f=rem
				{
					int nz=(f<rem)?1:0;          // g_i=rem-f>0
					if(dp[cur][c][z]+f<dp[nxt][f][nz])
						dp[nxt][f][nz]=dp[cur][c][z]+f;
				}
			}
		cur=nxt;
	}
	int res=min(dp[cur][0][0],dp[cur][0][1]);        // 只接受末态 c=0，即边界强制 f_L=0
	assert(res<inf);                                // 引理 5：任何 run 都可行，不会全 inf
	return res;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	assert(1<=n&&n<mxn);
	sieve();
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		assert(1<=a[i]&&a[i]<=20000000);
		factor(a[i],i);
	}
	sort(O,O+ocnt,cmp);
	i64 ans=0;
	for(int i=0;i<ocnt;)
	{
		int j=i;
		while(j<ocnt&&O[j].p==O[i].p)
			++j;                                  // [i,j) 同一个素数，pos 升序
		for(int l=i;l<j;)
		{
			int r=l;
			while(r+1<j&&O[r+1].pos==O[r].pos+1)
				++r;
			ans+=(i64)O[l].p*calc(l,r);           // 先转 i64 再乘，见 §2.8
		}
		i=j;
	}
	// cerr<<ocnt<<' '<<ans<<'\n';
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **`dp` 必须显式填 `inf`**：全局 `int` 数组默认 0，而 0 在这里表示"可达且代价 0"，是典型的静默错误源，故每层都逐格填 `inf`（想省事也可以 `fill_n(&dp[nxt][0][0],mxe*2,inf);`）；`mxe=25`、$2\times25\times2=100$ 个 `int`，滚动复用。
- **`assert(res<inf)`**：把引理 5"任何 run 都可行"写成运行时不变量；若这里断言失败，说明 (C2) 的剪枝写错了，而不是题目无解。
- **`calc` 的 `for(int f=(z?rem:0);f<=rem;++f)`**：一个循环同时覆盖两种转移（`z=1` 时上下界都是 `rem`，只剩清零一条路），省掉分支且与引理 7 的转移一一对应。
- **`rem<0` 的剪枝**：$f_{i-1}>e_i$ 说明左端已把本点的 $p$ 削光，(C2) 被违反；这一剪枝同时保证 `nz` 的定义不越界。
- **末态只取 `c=0`**：即 $f_L=0$，对应引理 3 的"边界边对 $p$ 无贡献"；`z` 两个值都接受，因为 $L+1$ 位置的 $g$ 天生为 0。
- **`ans+=(i64)O[l].p*calc(l,r)`**：不加 `(i64)` 时 $2\times10^7\times2.4\times10^5$ 会先把 `int` 打爆（§2.8）。
- **0-based**：位置 `pos` 内部 0-based，run 判邻接用 `O[r+1].pos==O[r].pos+1`；不输出下标，故无还原步骤。
- **`pri[j]*pri[j]<=x`**：$x$ 在除的过程中不断变小，判界随之收紧，正确性由"素因子按递增顺序除尽 + 引理 10"保证。

### 可选：平方自由特例的闭式对照版（与 `calc` 互验，见引理 6）

```cpp
// 仅当整段 run 的指数都是 1 时，F = ceil((L-1)/3)；用它核对 calc 的输出
int calc2(int l,int r)
{
	for(int i=l;i<=r;++i)
		assert(O[i].e==1);
	int L=r-l+1;
	return (L-1+2)/3;                 // ceil((L-1)/3)
}
```

手算对照：$L=1..7$ 时两版同为 $0,1,1,1,2,2,2$（§4.4(1) 表）；$A=(2,8,2)$ 这类含高次幂的输入 `calc2` 有 `assert` 拦住，正好指出"闭式不适用"的位置。
