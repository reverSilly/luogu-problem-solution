# P1917 三子棋II

## 1. 重新读题

### 1.1 问题重述（人话版）

给一个 $3\times3$ 棋盘，`O` 是小 a，`X` 是 uim，`-` 为空。规则就是普通三子棋：横、竖、斜先连成三个者胜。小 a 先手，而且**他的第一子一定下在中心**。

现在棋局刚开始，棋盘上**不足 3 颗**棋子（$\le 3$ 颗）。问：按「双方都按最佳方案下」的前提，小 a 是必胜、必败，还是（双方都赢不了时）无法断定。第二行输出当前棋子数。

输出约定：

- 小 a 必胜 → `xiaoa will win.`
- 小 a 必败（即 uim 必胜）→ `uim will win.`
- 其余 → `Dont know.`

### 1.2 关键约束与规模暗示

- 棋盘只有 $9$ 格、状态数最多 $3^9=19683$（每格空/`O`/`X`），再乘「轮到谁走」也只有约 $4\times 10^4$ 个状态。
- 这种规模下，**完全搜索**是最自然、也最可靠的做法：$9$ 格、至多 $6$ 个空位的博弈树本来就小。
- 「无论对手怎么下，自己必胜」这句话是对**所有**对手着法的要求，不是「对手配合时能赢」。这是理解题意、判断 `Dont know` 含义的关键。
- 注意棋子数 $\le 3$，所以棋局一定还没结束（任何一方都不可能有三个子），但为了代码健壮，判定终局仍然要写。
- 小 a 先手，所以「轮到谁」由棋子数决定：设 `O` 有 $c_O$ 个、`X` 有 $c_X$ 个，则 $c_O=c_X$ 时轮到 `O`，$c_O=c_X+1$ 时轮到 `X`。

## 2. 思维链（Chain-of-thought）

### 2.1 先判断这是什么类型的问题

三子棋是**有限、无随机、完全信息、零和**的两人游戏。对这类游戏有一条基本定理：

**引理 1（结局的确定性）**：在有限无随机完全信息零和游戏中，每个局面都有确定的值：要么先手方（这里是小 a）有必胜策略，要么后手方有必胜策略，要么双方都有不败策略（和棋）。不存在「说不清」的局面。

**证明**（对剩余空格数归纳）：设剩余空格数为 $e$。
- $e=0$：局面已终局，值由是否成三决定，确定。
- 设 $e=k$ 时命题成立，考虑 $e=k+1$ 的局面，轮到玩家 $P$。$P$ 的每个合法着法都把孩子局面（$e=k$）交给对方，由归纳每个孩子都有确定值。若 $P$ 是小 a，只要存在一个值为「小 a 胜」的孩子，他选它即可获胜；否则所有孩子都是「uim 胜」或「和」，他最多只能求和或输，此时值由孩子的最优值确定。$P$ 是 uim 时对称。$\square$

所以题目的三种输出正好对应 minimax 值 $+1/0/-1$：题目里的 `Dont know.` 不是「信息不足」，而是「双方都按最佳方案下会下成和棋」。这是本题最容易误解的一点。

**引理 2（minimax 值与「无论对手怎么下都必胜」等价）**：设 $V(b,t)$ 为局面 $b$、轮到 $t$ 时的 minimax 值（小 a 视角）。则 $V=+1$ 当且仅当小 a 存在一种策略，使得**对对手的任意着法**最终都能赢。

**证明**：
- （$\Leftarrow$）若存在这样的策略，则在 minimax 递归中，小 a 每次都能选到一个子局面其值仍是 $+1$；而对手的任意着法都落在值 $+1$ 的孩子里（否则该策略会被该着法破坏）。归纳到终局，所有分支都是小 a 胜，故 $V=+1$。
- （$\Rightarrow$）若 $V=+1$，取「每步都走向值 $+1$ 的孩子」这一策略。轮到对手时，当前局面值为 $+1$，按 minimax 的定义（对手取 min），对手的**每个**合法着法得到的孩子的值都 $\ge +1$，即都为 $+1$；所以无论对手怎么走，局面值保持 $+1$，最终小 a 胜。$\square$

### 2.2 常见的错误思路：只数「现成的两连」

一个很自然的偷懒想法是：看看谁已经有两个子连成一线、第三格为空，谁就能马上赢；都没有就输出 `Dont know.`。

这个思路是**错的**，本题恰好有反例。取局面

```
-X-
-O-
---
```

即小 a 在中心 $(1,1)$、uim 在 $(0,1)$（上边中间），轮到小 a。此时**双方都没有两连**，按上面的偷懒判定会输出 `Dont know.`。但实际上小 a 必胜，走法如下：

1. 小 a 占角 $(0,0)$。此时小 a 在 $(0,0),(1,1)$，**威胁**主对角线 $(2,2)$，uim 必须堵 $(2,2)$（否则下一步小 a 直接三连）。
2. 小 a 再占 $(2,0)$。此时小 a 同时在两条线上各有两个子：
   - 第 $0$ 列：$(0,0),(2,0)$，空着 $(1,0)$；
   - 反对角线：$(2,0),(1,1)$，空着 $(0,2)$。
   
   uim 一步只能堵一条，小 a 下一步必成三。

这个例子说明：胜负可能在**好几步之后**才由「双威胁（fork）」决定，搜索深度必须足够，浅层启发式不可靠。代码里用完整 minimax 搜索，自动处理这类情况。

反过来，若 uim 的第一子下在角上（例如 `X--` / `-O-` / `---`），小 a 就没有必胜策略，结果是和棋——这也可以用搜索验证。两个例子一对比，说明答案对局面的细节非常敏感，必须精确计算。

**关于题面语义**：本文严格按题面的定义——「自己以最佳方案下棋，无论对手怎么下，自己必胜」——理解，即 $+1$；「不知道」只能对应「双方都按最佳方案下会成和」，即 $0$。如果把题意弱化成「只看一步之内能否成三」，上面这个反例就会给出不同答案，因此那种理解与题面文字不符。题面只保证棋子数 $<3$，这会让搜索树很小，但并不改变 minimax 的含义。

### 2.3 建模与状态

状态 =（棋盘，轮到谁）。棋盘用长度 $9$ 的数组，$0$ 空、$1$ 是小 a、$2$ 是 uim。把棋盘按三进制编码：

$$\text{code}(b)=\sum_{i=0}^{8} b_i\cdot 3^{i}\in[0,\,3^9-1].$$

由于三进制表示与棋盘一一对应（每格取值 $0/1/2$），编码不会冲突。再用 $\text{id}=\text{code}\cdot 2+t$ 区分轮到谁，$t\in\{0,1\}$ 分别表示小 a / uim 走。记忆化表大小 $2\cdot3^9=39366$，一个 `signed char` 就够（值域 $\{-1,0,1\}$，用 $-2$ 表示「未计算」）。

### 2.4 转移与正确性

设 `dfs(b,t)`：

1. 若棋盘上已有三连，返回该方获胜（小 a 胜 $+1$，uim 胜 $-1$）。
2. 若记忆化命中，直接返回。
3. 若没有空格，返回 $0$（和棋）。
4. 否则枚举所有空格 $i$，落子 $b_i=t+1$，递归得到 $v=\text{dfs}(b,t\oplus1)$，撤销落子。小 a 走时取 $\max$，uim 走时取 $\min$。
5. 存表返回。

**引理 3（`dfs` 返回的就是 minimax 值）**：对每个局面 $b$ 与轮次 $t$，`dfs(b,t)` 等于 §2.1 定义的 $V(b,t)$。

**证明**：对剩余空格数 $e$ 归纳。
- $e=0$ 或无路可走：返回值由终局判定，与定义一致；且记忆化表此时存的也是该值。
- 设 $e\le k$ 时成立。$e=k+1$ 时，每个孩子的值由归纳假设正确；小 a 取 $\max$、uim 取 $\min$，正是 $V$ 的定义。记忆化只在同一 $(b,t)$ 上复用，而 $V$ 只依赖 $(b,t)$，故缓存不会污染结果。$\square$

### 2.5 细节与坑

1. **轮次判定**：小 a 先手，故 $c_O=c_X$ 时轮到小 a，$c_O=c_X+1$ 时轮到 uim。题面保证棋子数 $\le 3$，正常输入一定满足这两种情形之一。
2. **首手中心**：若棋盘为空，小 a 的第一手按规则必须下中心。代码在「轮到小 a 且棋盘上还没有 `O`」时强制 `b[4]=1`，以保证与规则一致。（若输入中已有 `O`，说明中心那一手已经在输入里体现了，不需要再强制。）
3. **坐标约定**：用一维下标 $0..8$，第 $r$ 行第 $c$ 列为 $3r+c$。八条线固定列出即可。
4. **输出措辞**：句号是 `xiaoa will win.` 和 `uim will win.` 的一部分，`Dont know.` 没有撇号（是 `Dont` 不是 `Don't`），必须逐字符一致。
5. 棋子数按输入里非 `-` 的格子数统计。

### 2.6 复杂度

状态数 $\le 2\cdot3^9=39366$，每个状态枚举至多 $9$ 个着法，总操作量约 $3.5\times10^5$，时间与空间都远低于限制。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 有限无随机完全信息零和博弈，每个局面结局确定（引理 1）。
- **failed attempt** — 只检查「现成两连」的启发式会漏判多步后的双威胁；给出具体反例 `-X-/-O-/---`。
- **classic problem solution** — minimax + 三进制状态编码 + 记忆化搜索。
- **prove correctness** — 对空格数归纳证明 `dfs` 即博弈值；并证明「minimax 值 $=+1$」等价于「无论对手怎么下都必胜」。
- **handle rules** — 用棋子数确定轮次；空盘时首手强制中心。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `b[9]` | `int[9]` | 棋盘，$0$ 空、$1$ 为 `O`、$2$ 为 `X` | 读入 | board |
| `memo[]` | `signed char[19683*2]` | 记忆化，`-2` 未算，否则存 $\{-1,0,1\}$ | 全 `-2` | memo |
| `winner(a)` | 函数 | 返回成三的一方（$0/1/2$） | — | 终局判定 |
| `encode(a)` | 函数 | 棋盘三进制编码 | — | 状态压缩 |
| `dfs(a,turn)` | 函数 | 返回小 a 视角的博弈值 | — | minimax |
| `cnt` | `int` | 棋子数 | 统计 | count |
| `turn` | `int` | 当前轮次，$0$ 小 a、$1$ uim | 由 $c_O,c_X$ 决定 | turn |

### 4.2 算法步骤

1. 读入 $3\times3$ 棋盘到 `b`，统计棋子数 `cnt`。
2. `turn = (cnt % 2 == 0 ? 0 : 1)`（小 a 先手）。
3. 把 `memo` 全部置为 `-2`。
4. 调用 `dfs(b,turn)`，得到 $v$。
5. 按 $v=1/0/-1$ 输出三种字符串之一，再输出 `cnt`。

### 4.3 复杂度与验证状态

- **时间复杂度**：$O(3^9\cdot 9)$，约 $3.5\times10^5$。
- **空间复杂度**：$O(3^9)$ 的记忆化表。
- 编译 `g++ -std=c++17 -O2 -Wall -Wextra`，无警告。
- 自测：对「棋子数 $\le 3$、且 $c_O=c_X$ 或 $c_O=c_X+1$」的**全部**局面（连同四种棋子数档）与一份独立的 Python minimax 逐一对拍，答案全部一致。特别验证 `-X-/-O-/---` 输出 `xiaoa will win. 2`，`X--/-O-/---`（X 在角）输出 `Dont know. 2`。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxs{19683*2};
constexpr signed char unk{-2};

int b[9];          // 0 empty, 1 xiaoa(O), 2 uim(X)
signed char memo[mxs];
bool hasO;

int winner(int*a)
{
	static const int L[8][3]={{0,1,2},{3,4,5},{6,7,8},{0,3,6},{1,4,7},{2,5,8},{0,4,8},{2,4,6}};
	for(int k=0;k<8;++k)
	{
		int v=a[L[k][0]];
		if(v&&v==a[L[k][1]]&&v==a[L[k][2]])
			return v;
	}
	return 0;
}

int encode(int*a)
{
	int s=0;
	for(int i=0;i<9;++i)
		s=s*3+a[i];
	return s;
}

// 1 = xiaoa 必胜, 0 = 和, -1 = uim 必胜
int dfs(int*a,int turn)   // turn 0 = O 走, 1 = X 走
{
	int w=winner(a);
	if(w==1)
		return 1;
	if(w==2)
		return -1;
	int id=encode(a)*2+turn;
	if(memo[id]>unk)
		return memo[id];
	bool any=false;
	int res=(turn==0?-1:1);
	// 小 a 的第一手必在中心
	if(turn==0&&!hasO&&a[4]==0)
	{
		a[4]=1;
		int v=dfs(a,1);
		a[4]=0;
		memo[id]=v;
		return v;
	}
	for(int i=0;i<9;++i)
		if(a[i]==0)
		{
			any=true;
			a[i]=turn+1;
			int v=dfs(a,turn^1);
			a[i]=0;
			if(turn==0)
				res=max(res,v);
			else
				res=min(res,v);
		}
	if(!any)
		res=0;
	memo[id]=res;
	return res;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(int i=0;i<9;++i)
	{
		char c;
		cin>>c;
		b[i]=(c=='O'?1:(c=='X'?2:0));
		if(b[i]==1)
			hasO=true;
	}
	fill_n(memo,mxs,unk);
	int cnt=0;
	for(int i=0;i<9;++i)
		cnt+=(b[i]!=0);
	int turn=(cnt%2==0)?0:1;   // O 先手
	int v=dfs(b,turn);
	if(v==1)
		cout<<"xiaoa will win.\n";
	else if(v==-1)
		cout<<"uim will win.\n";
	else
		cout<<"Dont know.\n";
	cout<<cnt<<'\n';
	return 0;
}
```
