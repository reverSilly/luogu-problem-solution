# P1579 哥德巴赫猜想(升级版)

> 标签:数学 · 枚举 · 素数判断 · 难度:普及-
> 本地题面:`P1579.md`($9<n<20000$ 的正奇数,输出 $3$ 个质数使其和为 $n$;表示不唯一时第一个质数最小,若仍不唯一则第二个质数最小)。验证:`appendix/P1579/` 两轮对拍共 $8000$ 组随机(奇数 $n\in[11,1500]$)+ $80$ 组大随机($n\in[10001,19999]$)+ $24$ 个边界用例,标程与暴力基准输出逐字节一致;全部 $9995$ 个奇数 $n\in[11,19999]$ 全量扫描两轮,输出均合法且与无剪枝参考一致;官方样例 $2009\to 3\ 3\ 2003$ 通过;最坏规模 $n=19991$(实测内层迭代 $2277$ 次,全程最多)纯计算 $0.80\,\mu\text{s}/$ 次,端到端(含进程启动与筛法)中位数 $0.77\,\text{ms}$。

## 1. 重新读题

**问题重述(人话版)**

给定一个正奇数 $n$($9<n<20000$),找出 $3$ 个质数 $p_1,p_2,p_3$ 使得 $p_1+p_2+p_3=n$,并按题面规定的顺序输出。若一个 $n$ 有多种表示,必须先让 $p_1$ 尽量小;$p_1$ 相同的多种表示里,再让 $p_2$ 尽量小。

> 一句话版本:**在所有"三质数之和等于 $n$"的表示中,输出按 $(p_1,p_2)$ 字典序最小的那个**($p_3=n-p_1-p_2$ 被前两者唯一确定,所以题面没有对 $p_3$ 单独设 tie-break)。

**题面里容易漏掉的条款**

1. 「**需要特别说明的是 $1$ 不是质数**」是题面原文加粗句——这是本题埋得最深的坑:任何"$x<2$ 不特判"的判质写法都会把 $1$ 当质数。
2. 「$2$ 和 $11$ 都是质数」——$2$ 是唯一的偶质数,后面整个奇偶分析都建立在它身上。
3. 「如果表示方法不唯一,请输出第一个质数最小的方案……」——tie-break 只看前两个数,且是**字典序**;它和"把三个数排序后输出最小"恰好等价(引理 4),但理由不同,不能互相顶替。
4. 「仅有一行,包含一个正奇数 $n$,其中 $9<n<20000$」——严格不等:$n$ 最小是 $11$、最大是 $19999$;**单组输入、无多测**;输出「仅有一行」「相邻两个质数之间用一个空格隔开,最后一个质数后面没有空格」。
5. 题面从头到尾没有要求三个质数**互异**;官方样例 $2009=3+3+2003$ 自己就重复用了 $3$。互异是读者自己加戏,加上它 $n=11,13$ 直接无解(见 §2.7 失败 ③)。

**数据范围与规模感受**

$$9<n<20000,\quad n\text{ 为奇数}\quad(\text{共 }9995\text{ 个可能的 }n).$$

- 值域只有 $2\times10^4$:埃氏筛一遍约 $10^5$ 量级操作,之后判质 $O(1)$,这是白送的。
- 若对 $[2,n]$ 全部整数做双枚举:约 $n^2/2\approx2\times10^8$ 次迭代,带"命中即退"后实际远小于此,但理论上界卡在时限边缘。
- 若做三重枚举:约 $n^3\approx8\times10^{12}$ 次循环体,必挂(§2.2 失败 ①)。
- $20000$ 以内质数共 $\pi(20000)=2262$ 个(实测):把 $a,b$ 的枚举从"所有整数"换成"只枚举质数",枚举量再砍约 $100$ 倍。

## 2. 思维链(Chain-of-thought)

### 2.1 探索性质:先把"奇数和"按奇偶分好类

看到"三个质数之和是**奇数**",第一反应应该想奇偶。质数里唯一的偶数是 $2$,设三个数里 $2$ 的个数为 $t$:

| $t$ | 和的奇偶 | 可能等于奇数 $n$? |
|---|---|---|
| $0$(三奇) | 奇 | ✓ |
| $1$ | $2+\text{奇}+\text{奇}=$ 偶 | ✗ |
| $2$ | $2+2+\text{奇}=$ 奇 | ✓ |
| $3$ | $6$ | ✗ |

**引理 1(奇数 $n$ 的三质数表示只有两种奇偶形态)**

若 $n$ 为奇数且 $p+q+r=n$,则要么 $p,q,r$ 全为奇质数,要么其中恰有两个是 $2$。

**证明**:按上表对 $t$ 分类。$t=1$ 时和为偶数,$t=3$ 时和为 $6$ 是偶数,均与 $n$ 为奇数矛盾,故 $t\in\{0,2\}$;$t=0$ 即三者全奇,$t=2$ 即恰有两个 $2$。$\blacksquare$

**推论 1(第一个质数取 $2$ 的充要条件)**

把 $p_1$ 从小到大枚举时,$p_1=2$ 有解当且仅当 $n-4$ 是质数;有解时按字典序最小的方案就是 $(2,2,n-4)$。

**证明**:若 $p_1=2$,由引理 1 只剩 $t=2$ 这一种形态($t=0$ 不可能,因为 $2$ 是偶数),即 $p_2,p_3$ 中恰有一个是 $2$。若 $p_2=2$ 则 $p_3=n-4$;若 $p_3=2$ 则 $p_2=n-4$。两种情况都要求 $n-4$ 为质数($n\ge11$ 保证 $n-4\ge7>2$)。反过来,$n-4$ 为质数时 $(2,2,n-4)$ 确实是合法表示。字典序最小性:$p_2$ 的候选只有 $2$ 与 $n-4$,而 $2<n-4$,故最小方案为 $(2,2,n-4)$。$\blacksquare$

> 用推论 1 回看官方样例:$2009-4=2005=5\times401$ 不是质数,所以第一个质数不可能是 $2$,至少是 $3$——样例输出 $3\ 3\ 2003$ 与这个预判严丝合缝。这个性质不是解题必需,但它让学生第一次感受到:**枚举可以带着结构信息做,而不是裸扫**。

### 2.2 失败思路 ①:照定义写三重循环

最直白的"定义版":$a,b,c$ 各从 $2$ 枚举到 $n$,检查 $a+b+c=n$ 且三者皆质数。

**具体反例(规模意义)**:取最大的 $n=19999$,三层循环体要执行约 $19997^3\approx8\times10^{12}$ 次,按 $10^9$ 次/秒也要跑几个小时,而时限是 $1$ 秒。这不是"可能超时",是"必挂"。

但"定义版"并非一无是处:它是对拍时最可靠的 correctness oracle。最后的暴力基准(`P1579_brute.cpp`)就保留了它的全部精神——全枚举、显式按题面规则比较,只是砍掉了由和确定的那一维。

### 2.3 第一次简化:$c$ 根本不用枚举

盯住 $a+b+c=n$ 看一秒:$a,b$ 一旦定下来,$c$ 就被减出来了。

**引理 2($c$ 由 $(a,b)$ 唯一确定)**

对任意整数对 $(a,b)$,满足 $a+b+c=n$ 的整数 $c$ 有且仅有一个,即 $c=n-a-b$。

**证明**:方程 $a+b+c=n$ 是 $c$ 的一次方程,$c$ 的系数为 $1\neq0$,在整数范围内恒有唯一解 $c=n-a-b$。$\blacksquare$

引理 2 平凡到不好意思单独写成引理,但它是整个枚举的骨架:三重循环砍成双重,复杂度从 $O(n^3)$ 降到 $O(n^2)$。此时循环次数约 $2\times10^8$(最坏),在 C++ 里已经能跑完——但前提是判质够快,这就引出了下一个坑。

### 2.4 失败思路 ②:双环里每次试除判质

$O(n^2)$ 的循环,如果每次都用试除法判断 $a,b,c$ 三个数是不是质数,单次要约 $3\times\sqrt{n}/2\approx2\times10^2$ 次取模。

**具体反例(规模意义)**:$n=19999$ 时总取模次数约 $2\times10^8\times210\approx4\times10^{10}$,同样必挂。

**出路(经典技术:筛法)**:值域只有 $20000$,埃氏筛一遍 $O(mxn\log\log mxn)\approx10^5$ 次操作,之后判质是 $O(1)$ 的数组查表。顺手再做一件事:$a,b$ 只枚举质数($20000$ 以内共 $2262$ 个),枚举量再砍约 $100$ 倍——双循环的理论上界从 $2\times10^8$ 降到 $2262^2/2\approx2.6\times10^6$。

### 2.5 关键问题:按什么顺序枚举,"第一个命中"才等于题面要求?

现在循环骨架有了,但"找到第一个就输出"凭什么对?题面要的是 $(p_1,p_2)$ 字典序最小,枚举顺序必须和字典序对齐。

**引理 3(枚举序即字典序,首中即所求解)**

若 $a$ 按升序枚举质数,且对每个 $a$ 让 $b$ 按升序枚举质数,$c=n-a-b$,则第一个满足"$a,b,c$ 三者皆质数"的 $(a,b)$ 就是 $(p_1,p_2)$ 字典序最小的解。

**证明**:分两步。

- *枚举不重不漏*:每个 $(a,b)$ 质数对在该双层循环中被访问恰好一次(外层定 $a$,内层在该 $a$ 下把每个 $b$ 过一遍);由引理 2,每个 $(a,b)$ 只对应一个 $c$,故每个"三质数表示"至多被访问一次;而所有质数对又确实都会被访问到,故不漏。
- *首中最小*:设第一个命中为 $(a^*,b^*)$。反设存在字典序更小的合法解 $(a',b')$。若 $a'<a^*$:外层先扫过 $a'$ 才扫到 $a^*$,内层在 $a=a'$ 时会把 $b'$ 访问到并命中,与"$(a^*,b^*)$ 是第一个命中"矛盾。若 $a'=a^*$ 且 $b'<b^*$:同一个外层迭代的内层循环按 $b$ 升序执行,$b'$ 在 $b^*$ 之前被访问并命中,同样矛盾。$\blacksquare$

引理 3 有个重要副产品:它**不依赖** "$b\ge a$"之类的任何剪枝。最后就用这一点做了两把独立的尺子——暴力基准(全整数双环 + 显式字典序比较)与无剪枝参考实现($b$ 从 $2$ 起枚举),专门检验标程剪枝的合法性。

### 2.6 优化:交换论证告诉我们 $b$ 可以从 $a$ 起枚举

动机很具体:外层扫到 $a=1009$ 时,内层从 $b=2$ 开始要把 $2,3,5,\dots,1007$ 全部试一遍——这些 $b<a$ 的组合,直觉上"不可能"是字典序最小的解。把直觉变成定理:

**引理 4(字典序最小解自动有序)**

设 $(a,b,c)$ 是 $(p_1,p_2)$ 字典序最小的解,则 $a\le b\le c$。

**证明(交换论证)**:$(a,b,c)$ 的三个分量都是质数,它们任意重排后仍是合法表示(和不变、质数不变)。
- 若 $b<a$,则 $(b,a,c)$ 也是合法解,且首元素 $b<a$,字典序严格更小,与 $(a,b,c)$ 的最小性矛盾。
- 若 $c<b$,则 $(a,c,b)$ 也是合法解,首元素同为 $a$、次元素 $c<b$,字典序严格更小,同样矛盾。
故 $a\le b$ 且 $b\le c$。$\blacksquare$

**推论 2(内层从 $a$ 起枚举不丢解)**

把内层循环限制为"$b$ 只枚举 $\ge a$ 的质数",全局字典序最小解一定还能被找到。

**证明**:设全局字典序最小解为 $(a^*,b^*,c^*)$。
- 对外层 $a<a^*$:这些迭代里不存在任何合法解——否则该解首元素 $<a^*$,与 $a^*$ 的最小性矛盾。既然无解,内层从 $a$ 起还是从 $2$ 起都无所谓,剪掉的部分全是空转。
- 对外层 $a=a^*$:该 $a$ 下全部合法 $b$ 中最小的是 $b^*$(否则存在更小的合法 $b$,使 $(a^*,b)$ 成为更小的解)。由引理 4,$b^*\ge a^*$,故内层从 $a^*$ 起枚举不会跳过 $b^*$。
综上,限制后的枚举仍能命中 $(a^*,b^*)$。$\blacksquare$

### 2.7 失败思路 ③:自己给题目加"三个质数互异"

哥德巴赫猜想的叙述从不要求互异,但读者很容易脑补进去。一旦加上"$a,b,c$ 两两不同"的约束:

**具体反例**:$n=11$ 时全部表示为 $2+2+7$ 与 $3+3+5$;$n=13$ 时全部表示为 $3+3+7$($2+2+9$ 中 $9$ 非质数)。这两个 $n$ 的每个表示都含重复质数,互异约束下直接无解——程序会死循环或什么都不输出。而官方样例 $2009=3+3+2003$ 自己就重复用了 $3$。**判定依据只能是题面原文:题面只说"输出 $3$ 个质数",没有"不同"二字。**

### 2.8 失败思路 ④:枚举顺序对齐了 $a$,却对齐了 $c$

tie-break 说的是"第一个质数最小,然后第二个质数最小",所以内层必须枚举 **$b$**。如果顺手让内层枚举 $c$(即按 $(a,c)$ 字典序找解),三个数的和与质数性都对,但输出顺序不符合题面。

**具体反例**:$n=31$。正确输出是 $3\ 5\ 23$($a=2$ 时 $n-4=27$ 非质数,由推论 1 跳过;$a=3$ 时 $b=3\to c=25$ 非质数,$b=5\to c=23$ 是质数,命中)。若误按 $(a,c)$ 字典序:$a=3$ 时最小的合法 $c$ 是 $5$,对应 $b=23$,于是输出 $3\ 23\ 5$——三数之和仍是 $31$、仍全是质数,但第二个质数是 $23$ 而不是最小的 $5$,照样 WA。

### 2.9 失败思路 ⑤:$c<2$ 不 break,以及忘记"$1$ 不是质数"

这两个是编码层的坑,各有一个具体后果。

**(a) 缺 $c<2$ 的 break。** 内层 $b$ 升序 $\Rightarrow$ $c=n-a-b$ 降序,$c<2$ 之后永远不可能再合法,本应立刻 break;不 break 的话 $b$ 继续增大,$c$ 变 $0$、变负,直接造成越界访问。

**具体反例**:$n=13$ 的正确输出是 $3\ 3\ 7$。删掉 break 后实测:$a=2$ 时 $b=2,3,5,7$ 依次给出 $c=9,8,6,4$(皆合数),$b=11$ 给出 $c=0$(已被标记),$b=13$ 给出 $c=-2$——`np[-2]` 是负下标越界读,实测读到 $0$ 被当作"质数",输出 $2\ 13\ -2$。换一个环境这段 UB 可能直接段错误。**break 一行不是优化,是保命。**

**(b) 忘记标记 $1$。** 题面加粗"$1$ 不是质数",而埃氏筛天然只覆盖 $[2,mxn)$——`np[1]` 停留在默认值 `false`,含义是"$1$ 是质数"。一旦某个 $(a,b)$ 使 $c=1$ 且它恰好是首个命中,就会输出含 $1$ 的假解。

如实记录:把 $1$ 当质数后重跑全部 $9995$ 个奇数 $n$,**没有一组**答案发生变化(§4.5)——因为 $c=1$ 要求 $a+b=n-1$,而这种情形下 $(2,2,n-4)$ 或更早的命中总先出现,$c=1$ 排不到"首个"。但这只是本数据范围内的巧合,不是保证:题面白纸黑字加粗了这条,`np[1]=true` 一行就能堵死,没有理由不写。

## 3. 模式总结(Pattern Summary)

按真实思考顺序排列:

- **explore its property** — 按 $2$ 的个数把"三质数之和为奇数"分成"三奇"与"$2+2+$奇"两种形态,顺手得到"$p_1=2$ 有解 $\iff n-4$ 为质数"(引理 1、推论 1)。
- **consider easier version** — 先承认照定义写的三重循环(留作对拍的 correctness oracle),再观察 $c=n-a-b$ 砍掉一维(引理 2)。
- **classic problem solution(筛法)** — 值域 $2\times10^4$ 白送一个埃氏筛:判质 $O(1)$,枚举只用质数表($2262$ 个),双循环上界从 $2\times10^8$ 砍到 $2.6\times10^6$。
- **classic problem solution(字典序枚举)** — $a,b$ 按字典序升序枚举,"首个命中"恰好等于题面 tie-break 要求的解(引理 3);这也是暴力基准与无剪枝参考的共同基础。
- **reduce to easier problem** — 交换论证证明字典序最小解必满足 $a\le b\le c$(引理 4),内层从 $a$ 起枚举(推论 2)。
- **count-the-candidates** — 实测 $\pi(20000)=2262$、最坏内层迭代 $2277$ 次($n=19991$)、所有答案的首质数只取 $2$ 或 $3$,论证"筛法 + 双枚举"绰绰有余。
- **verify against a definition brute** — 全整数双环 + 显式字典序比较的暴力基准,外加一个不剪枝的首命中参考,从两个方向夹击标程。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| `mxn` | `constexpr int` | 筛法数组尺寸 $20005$ | 题面 $n<20000$,$+5$ 松弛 | 约束+5 |
| `np[i]` | `bool [mxn]` | `true` $\iff$ $i$ **不是**质数 | `np[0]=np[1]=true`,其余由筛填入 | n**p** = non-prime |
| `pr[i]` | `int [mxn]` | 第 $i$ 个质数($0$-based,升序) | 筛的过程中按序收集 | **pr** = prime |
| `cnt` | `int` | 质数个数,筛后 $=2262$ | $0$ | **cnt** = count |
| `n` | `int` | 输入的奇数 | 读入 | 题面 |
| `a` | `int`(外层局部) | 当前第一个质数 $=$ `pr[i]` | — | 每个外层迭代取一次 |
| `b` | `int`(内层局部) | 当前第二个质数 $=$ `pr[j]` | — | 每个内层迭代取一次 |
| `c` | `int`(内层局部) | 第三个质数 $=n-a-b$ | — | 由和确定,免掉第三重循环(引理 2) |
| `i`,`j` | `int` | 质数表下标 | `j` 从 `i` 起 | $b\ge a$(引理 4、推论 2) |

### 4.2 编号步骤

1. `np[0]=np[1]=true`:把 $0,1$ 预先标记为非质数——$1$ 不是质数是题面加粗条款,而埃氏筛从 $2$ 开始,不预标记就会留下 `np[1]==false`(意为质数)的隐患。
2. 埃氏筛遍历 `i∈[2,mxn)`:`np[i]` 为 `false` 说明 `i` 是质数,收进 `pr[cnt++]`,并把 `i` 的倍数 `2i,3i,…` 标记为非质数。
3. 读入 `n`。
4. 外层 `i` 升序,`a=pr[i]`;`a>n-4` 时停止——另外两个质数最小也是 $2+2$,$a$ 再大不可能凑出和,顺带堵掉内层空转。
5. 内层 `j` 从 `i` 起,`b=pr[j]`,算 `c=n-a-b`:
   - `c<2` 立即 `break`:$b$ 升则 $c$ 降,后面只会更小;同时杜绝 $c\le0$ 时的负下标越界(§2.9 反例:$n=13$ 缺此行实测输出 `2 13 -2`);
   - `!np[c]` 即 $c$ 是质数:由引理 3,这就是题面要的解,输出 `a b c`(空格分隔、`'\n'` 收尾)并结束。
6. 循环走完直接 `return 0`。由弱哥德巴赫猜想(任意大于 $5$ 的奇数都是三个质数之和,2013 年由 Helfgott 证明)以及 §4.5 的全量实测,范围内的 $n$ 必然在第 5 步命中,不需要"无解"分支。

> `c` 的取值域:$c=n-a-b\le n-4\le19995<\texttt{mxn}$,且第 5 步保证查询时 $c\ge2$,故 `np[c]` 永远不会越界。

### 4.3 复杂度

- 时间:筛 $O(mxn\log\log mxn)$,标记总数约 $5\times10^4$;双循环理论上界 $O(\pi(n)^2/2)\approx2.6\times10^6$(永不命中的极端),实测因"命中即退"最坏只有 $2277$ 次内层迭代($n=19991$);纯计算平均 $0.31\,\mu\text{s}/$ 个 $n$、最坏 $0.80\,\mu\text{s}$。
- 空间:`bool[mxn]` + `int[mxn]` 两个全局静态数组,约 $120$ KB,远低于 $125$ MB。

### 4.4 关键不变量

1. `np[x]` 为 `true` $\iff$ $x$ 非质数($x\in[0,\texttt{mxn})$);$0,1$ 在筛之前预先标记,筛只动 $\ge2$ 的部分。
2. 查询 `np[c]` 时恒有 $2\le c\le n-4<\texttt{mxn}$:`c<2` 即 break 保下界,$a,b\ge2$ 保上界。
3. 枚举序 $=(a,b)$ 字典序且不重不漏(引理 3);限制 $b\ge a$ 不丢全局最小解(推论 2)。二者合起来保证"首个命中 $=$ 题面所求解"。

## 5. 示例代码

> 与 `appendix/P1579/P1579.cpp` **逐字节一致**。

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20005};    // n<20000 (+5 松弛);c=n-a-b 最大只到 19995

bool np[mxn];                // np[i]=true 表示 i 非质数;0/1 一并标记(1 不是质数)
int pr[mxn],cnt;             // pr[]=升序质数表,cnt=质数个数(20000 内共 2262 个)

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	np[0]=np[1]=true;                             // 题面黑体:1 不是质数
	for(int i=2;i<mxn;++i)                        // 埃氏筛
		if(!np[i])
		{
			pr[cnt++]=i;
			for(int j=i*2;j<mxn;j+=i)
				np[j]=true;
		}
	int n;
	cin>>n;
	for(int i=0;i<cnt&&pr[i]<=n-4;++i)            // 另外两个质数最小 2+2,a 不能超过 n-4
	{
		int a=pr[i];
		for(int j=i;j<cnt;++j)                    // b>=a:字典序最小解必满足 a<=b<=c
		{
			int b=pr[j];
			int c=n-a-b;
			if(c<2)                               // b 升则 c 降,后续更小;同时防负下标越界
				break;
			if(!np[c])                            // c<=19995,不会越界
			{
				cout<<a<<' '<<b<<' '<<c<<'\n';
				return 0;
			}
		}
	}
	return 0;
}
```

### 5.2 对照实现:暴力基准(仅用于对拍)

见 `appendix/P1579/P1579_brute.cpp`:用试除法独立打质数表(不复用埃氏筛),然后对**一切整数** $a,b$(不只质数)做全扫描,每遇到合法三元组就按题面 tie-break 规则显式比较 `a<ba||(a==ba&&b<bb)`——它不靠"首个命中"这条性质,因此能独立检验标程的枚举顺序与 $b\ge a$ 剪枝。代价是 $O(n^2)$ 全扫描加 $O(n\sqrt n)$ 打表,$n=19999$ 时约 $0.3$ 秒,只能作基准、不能提交。

### 5.3 易错点清单

- **把 $1$ 当质数**:筛从 $2$ 开始,`np[1]` 默认 `false` 意为"是质数";题面加粗条款,必须 `np[1]=true`(§2.9)。
- **内层缺 `c<2` 的 break**:$n=13$ 实测输出 `2 13 -2`,负下标越界读(§2.9)。
- **误加"三质数互异"**:$n=11,13$ 的全部表示都含重复质数,加约束即无解(§2.7);官方样例 $2009=3+3+2003$ 就是重复的。
- **内层枚举 $c$ 而不是 $b$**:$n=31$ 会输出 `3 23 5` 而非 `3 5 23`,和与质数都对但 tie-break 错(§2.8)。
- **照定义写三重循环**:$n=19999$ 时约 $8\times10^{12}$ 次循环体,必挂(§2.2);先用引理 2 砍掉一维。
- **双环里试除判质**:约 $4\times10^{10}$ 次取模,必挂(§2.4);值域 $2\times10^4$ 应当先筛。
- **输出格式**:三个数之间一个空格、行尾无多余空格、单行输出;题面单组输入,不要画蛇添足加多测循环。
- **`cout<<...<<endl`**:违反本项目风格指南,一律 `'\n'`。
