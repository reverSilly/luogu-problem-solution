# P1384 幸运数与排列

> 标签：数学 · 福建省历届夏令营 · 难度：提高/省选-

## 1. 重新读题

**问题重述（大白话）**

- **幸运数**：十进制每一位都只有 `4` 或 `7` 的正整数，如 $4,7,44,47,744,4747$。
- 给定 $n,k$，考虑 $1..n$ 的**全体排列按字典序**排序，取第 $k$ 小的那个排列 $p$（1-based）。
- 统计：在排列 $p$ 中，**位置编号 $i$ 是幸运数、且该位置上的值 $p_i$ 也是幸运数**的个数。
- 若第 $k$ 小排列**不存在**（即 $k>n!$），输出 $-1$。

**约束与复杂度暗示**

| 量 | 范围 |
|---|---|
| $n$ | $1\le n\le 10^9$ |
| $k$ | $1\le k\le 10^9$ |
| $30\%$ | $n\le 8$（可暴力枚举全排列） |
| $60\%$ | $n\le 100$（仍远小于 $n!$） |
| $100\%$ | $n,k\le 10^9$ |

**关键观察（先钉死口径）**：$k\le 10^9$，而 $13!=6227020800>10^9\ge 12!$。也就是说无论 $n$ 多大，只要 $n\ge 13$，$n!$ 就天文数字地大于 $k$。于是"第 $k$ 个排列"只会在**末尾极小一段**（长度 $\le 13$）被打乱，前面几乎全是恒等。**整道题的算法核心就是把这段"活动区"找出来。**

**样例情况**：本地题面文件**没有给出样例的输入与输出数值**，`Hint` 只说明了两个样例对应的排列（样例 1 为 `1,2,3,4,6,7,5`；样例 2 为 `2,1,3,4`）。因此**无法与官方答案数值对标**；下文验证只做两件事：①用我们的结构引理**反推输入并复现**这两条排列，②自造小数据与暴力枚举逐位比对。

## 2. 思维链（Chain-of-thought）

### 2.1 explore its property —— 第 k 个排列长什么样

字典序第 $k$ 个排列的标准构造是**阶乘数制（factoradic）**：维护一个"已排序的候选值表" `avail`，从左到右逐位定值。

设当前要填第 $i$ 位（$1..n$），填完后还剩 $n-i$ 个位置，故固定第 $i$ 位后其后的排列数（一个"块"的大小）为 $(n-i)!$。若把剩下的候选值从小到大编号 $0,1,\dots$，则第 $i$ 位取"第 $\mathsf{idx}$ 小"的值，其中
$$\mathsf{idx}=\left\lfloor\frac{k-1}{(n-i)!}\right\rfloor,\qquad k\leftarrow (k-1)\bmod (n-i)!+1 .$$
（$k$ 始终表示"在当前块内是第几个"，1-based。）

**引理 1（前缀固定点）**：若 $(n-i)!\ge k$，则第 $i$ 位取到当前**最小**候选值，且更新后 $k$ **不变**。

> **证明**：条件 $(n-i)!\ge k\iff k-1<(n-i)!$，故 $\mathsf{idx}=\lfloor (k-1)/(n-i)!\rfloor=0$，取第 $0$ 小=最小候选。同时 $(k-1)\bmod (n-i)!=k-1$，于是新 $k=(k-1)+1=k$ 不变。$\blacksquare$

进一步，若前 $i-1$ 位都已取了"当时的最小候选"，那它们用的正好是 $1,2,\dots,i-1$，故第 $i$ 位的最小候选就是 $i$。归纳得：**从第 1 位开始，凡是 $(n-i)!\ge k$ 的位置，必有 $p_i=i$**，且 $k$ 一路保持不变。

### 2.2 consider easier version —— 活动区的大小

定义 $r_0=\min\{m\ge 1: m!\ge k\}$。因为 $k$ 在前缀恒定，满足 $(n-i)!\ge k$ 的位置恰为 $n-i\ge r_0$，即 $i\le n-r_0$。所以：

**引理 2（恒等前缀 + 活动尾部）**：当 $n\ge r_0$ 时，$p_1..p_{n-r_0}$ 是恒等（$p_i=i$），$k$ 原封不动传到第 $n-r_0+1$ 位；剩下的 $r_0$ 个位置 $n-r_0+1..n$ 上，恰好排着候选值集合 $\{n-r_0+1,\dots,n\}$，且这是对该 $r_0$ 元集合的**第 $k$ 个**字典序排列。

> **证明**：前半由引理 1 的归纳。$n-r_0$ 步后 $k$ 仍为原值、候选表 $=\{n-r_0+1..n\}$ 且 $|{可用}|=r_0$，其排列数 $r_0!\ge k$（$r_0$ 定义），故第 $k$ 个存在；对这段跑 factoradic 就等价于"在 $r_0$ 个有序值上求第 $k$ 排列"。$\blacksquare$

注意 $r_0\le 13$（因 $13!\ge 10^9\ge k$ 且 $r_0$ 是最小满足者）。**活动区至多 13 个元素**，可以逐位暴力展开。

### 2.3 存在性判据（输出 -1 的条件）

**引理 3**：第 $k$ 个排列存在 $\iff n!\ge k\iff n\ge r_0$。

> **证明**：$n\ge r_0\Rightarrow n!\ge r_0!\ge k$。反向：$n<r_0\Rightarrow n\le r_0-1\Rightarrow n!\le (r_0-1)!$，而 $r_0$ 的最小性给出 $(r_0-1)!<k$，故 $n!<k$，不存在。$\blacksquare$

这条判据极其重要：$n$ 可达 $10^9$，**绝不能真去算 $n!$**，只要把 $k$ 与递增阶乘比较，求出 $r_0$，再判 $n<r_0$ 即可。

### 2.4 答案的两段拆分

**引理 4（计数可分）**：答案 $=A_{\text{恒等}}+A_{\text{活动}}$，其中
$$A_{\text{恒等}}=\#\{\text{幸运数 } i: 1\le i\le n-r_0\},\qquad A_{\text{活动}}=\sum_{i=n-r_0+1}^{n}\big[\,i\text{ 幸运}\,\wedge\,p_i\text{ 幸运}\,\big].$$

> **证明**：恒等段 $p_i=i$，条件"$i$ 幸运 $\wedge$ $p_i$ 幸运"退化为"$i$ 幸运"，故贡献就是 $[1,n-r_0]$ 内幸运数个数。活动段逐位判定。两段位置不相交（$[1,n-r_0]$ 与 $[n-r_0+1,n]$），相加不重不漏。$n=r_0$ 时恒等段为空、$A_{\text{恒等}}=0$，仍成立。$\blacksquare$

### 2.5 幸运数计数与判定

$A_{\text{恒等}}$ 需要对任意 $X=n-r_0$（可高达 $10^9$）快速求 $[1,X]$ 内幸运数个数。

**引理 5（幸运数有限）**：$\le 10^9$ 的幸运数位数 $\le 9$（$10$ 位最小幸运数 $4444444444>10^9$），共 $\sum_{d=1}^{9}2^d=2^{10}-2=1022$ 个。

> **证明**：$d$ 位幸运数每位 $2$ 选（4/7），共 $2^d$ 个，且 $d$ 位最大 $77\cdots7\le 10^9\iff d\le 9$。求和 $\sum_{d=1}^{9}2^d=2^{10}-2=1022$。$\blacksquare$

于是用 DFS 枚举全部 $1022$ 个幸运数、排序，则 $A_{\text{恒等}}=$ 其中 $\le X$ 的个数，用 `upper_bound` 一次得到。$A_{\text{活动}}$ 里判定某值是否幸运用逐位取余 `islucky`（值可 $\le n\le10^9$）。

### 2.6 factoradic 展开活动段为什么"不重不漏"

引理 2 把问题归结为"对 $r_0$ 个升序候选值求第 $k$ 个字典序排列"，步骤 5 用的是经典 factoradic。必须证明它给出的排列既正确又唯一，否则活动段的逐位判定站不住脚。

**引理 6（按首位分块，字典序即分块序）**：设候选升序表 $A=(a_0<a_1<\dots<a_{m-1})$。把所有 $m!$ 个排列按字典序排列，则它们**先按首位分组**：首位为 $a_0$ 的 $ (m-1)!$ 个排最前，接着首位 $a_1$ 的 $(m-1)!$ 个……且**同一首位组内部**按"剩余 $m-1$ 个值的排列"的字典序递归有序。

> **证明**：字典序比较第一个不同位即定胜负。两排列若首位不同 $a_i<a_j$，则前者整体更小，故"首位越小整组越靠前"，每组大小 $=(m-1)!$（其余位置的全排列数）。若首位相同，则比较从第 $2$ 位开始，退化为"去掉该首位后剩余升序表"上的字典序比较，即同组内序与"剩余值排列"的字典序一致。递归到 $m=1$ 平凡。$\blacksquare$

**引理 7（factoradic 选择公式正确）**：对第 $k$ 个排列，首位取 $a_{\lfloor (k-1)/(m-1)!\rfloor}$，组内序号为 $k'=((k-1)\bmod (m-1)!)+1$，然后对剩余升序表递归求第 $k'$ 个。此过程产出**恰好**字典序第 $k$ 个排列。

> **证明**：由引理 6，第 $k$ 个落在"第 $\lfloor (k-1)/(m-1)!\rfloor$ 组"（每组 $(m-1)!$ 个，组号从 $0$ 起），组内是第 $(k-1)\bmod (m-1)!+1$ 个。首位即该组的固定首值 $a_{\mathsf{idx}}$；由引理 6 的"同组内序 $=$ 剩余表排列字典序"，对剩余升序表求第 $k'$ 个即正确续写。归纳 $m$ 即得整条排列。删除已选值使剩余表始终升序，故下标公式每步都成立，不重不漏。$\blacksquare$

> 说明：本解**不是贪心**（没有"局部最优选择"需要交换论证），而是把第 $k$ 排列的构造**等价改写**为"前缀恒等 + 末尾小段 factoradic"这一确定结构，引理 1–7 给出双向严格性等价，因此不存在"漏掉更优/更早的排列"的问题。

### 2.7 讨论其它做法 / 坑点清单

- **暴力枚举（仅 $30\%$，$n\le8$）**：`next_permutation` 数到第 $k$ 个再统计。$n=8$ 时 $8!=40320$ 可行；但 $n\le100$、$n\le10^9$ 全不可行——这正是要引理 2 的理由。
- **误算 $n!$**：$n$ 到 $10^9$，阶乘立刻爆 `i64`。判存在性**只用**引理 3 的 $n<r_0$，绝不计算 $n!$。
- **$r_0$ 上界**：$12!=479001600<10^9\le13!=6227020800$，故 $k\le10^9$ 时 $r_0\le13$；`fact` 只需到 $13$，累乘循环 `i<20` 已足够且不溢出。
- **边界 $n=r_0$**：恒等段 $n-r_0=0$，`countleq(0)=0`（`luckynums` 全 $\ge4$），全靠活动段，正确。
- **边界 $k=1$**：$r_0=1$，恒等段 $[1,n-1]$，活动段只剩位置 $n$、值 $n$；此时排列就是 $1..n$ 恒等排列，答案 $=$ 幸运数 $\le n$ 的个数（恒等段 $[1,n-1]$ 的幸运数 + 位置 $n$ 若幸运则值也幸运 $+1$），与"恒等排列中幸运位置数 $=\le n$ 幸运数个数"一致。
- **`gen` 的递归终止**：`cur*10+4/7` 单调增，`cur>lim` 即返回，不会无限；`cur=0` 时不入表（$0$ 非幸运数）。
- **`islucky` 对 0/负数**：显式 `x<=0 return false`，避免 $0$（空循环）被误判为幸运。
- **输出格式**：题目要一个整数，$-1$ 与答案都单独一行，用 `'\n'`。
- **无法对标官方**：本地文件缺样例输入/输出数值，4.4 全部为手算结构复现与自造例比对，未运行程序、未做随机对拍。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 用 factoradic 写出"第 $k$ 排列"的逐位构造，发现块大小 $(n-i)!$。
- **consider easier version** — 引理 1：$(n-i)!\ge k$ 时取最小候选且 $k$ 不变 → 前缀恒等。
- **reduce to easier problem** — 引理 2：只剩末尾 $r_0=\min\{m:m!\ge k\}\le 13$ 个位置需要真排。
- **classic problem solution（factoradic）** — 引理 6–7：活动段用阶乘数制逐位取 $\lfloor (k-1)/(len-1)!\rfloor$ 选值，证其不重不漏。
- **edge / existence** — 引理 3：$n<r_0\iff n!<k$ → 输出 $-1$，绕开计算巨大 $n!$。
- **counting decomposition** — 引理 4：恒等段贡献 $=$ 段内幸运数个数，活动段逐位判幸运。
- **precompute small set** — 引理 5：$\le10^9$ 幸运数仅 $1022$ 个，DFS 生成 + `upper_bound`。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n`,`k` | 输入 | `i64` | 均 $\le10^9$ |
| `r0` | 最小 $m$ 使 $m!\ge k$ | `int`，$1\le r_0\le 13$ | 活动区长度 |
| `fact[t]` | $t!$ | `i64` `fact[0..19]` | 仅用到 $\le 13!$ |
| `luckynums[]` | 全部 $\le10^9$ 幸运数（排序后） | `i64[mxl]`，`gen(0)` 生成 | 共 $1022$ 个 |
| `lcnt` | 幸运数个数 | `int` | $=1022$ |
| `avail[]` | 活动段候选值表 $\{n-r0+1..n\}$ | `i64[20]`，升序 | 每次取走一个并前移 |
| `kk` | 当前块内的 1-based 序号 | `i64`，初值 `k` | 随 factoradic 更新 |
| `ans` | 答案 | `i64` | 上界约 $1035$ |
| `lim` | $10^9$ | `constexpr i64` | 生成幸运数上界 |

### 4.2 算法步骤

1. `gen(0)` DFS 生成 `luckynums` 并 `sort`；预置 `fact[0..19]`。
2. 读入 $n,k$；令 `r0=1`，`while(fact[r0]<k)++r0`（最多到 $13$）。
3. 若 `n<r0`：输出 `-1` 结束（引理 3）。
4. `ans = countleq(n-r0)`，即 `upper_bound(luckynums, n-r0)`（引理 4 的恒等段）。
5. 填 `avail[i]=n-r0+1+i`（$i=0..r0-1$），`len=r0`，`kk=k`；对 $i=0..r0-1$：
   - `f=fact[len-1]`，`idx=(kk-1)/f`，`kk=(kk-1)%f+1`；
   - 位置 `pos=n-r0+1+i`，若 `islucky(pos)&&islucky(avail[idx])` 则 `++ans`；
   - 把 `avail[idx]` 从表中删除（其后元素整体前移），`--len`。
6. 输出 `ans`。

### 4.3 复杂度与溢出预算

- 时间：$O(r_0^2+L\log L)$，$L=1022$（生成为 $O(L)$，排序 $O(L\log L)\approx10^4$），$r_0\le13$ → $r_0^2\le169$。总体 $\ll10^5$，与 $n$ 无关。
- 空间：$O(L)$ 数组。
- 溢出：$13!=6.23\times10^9>2^{31}$，故阶乘与 $k$ 比较**必须 `i64`**；`fact[19]=1.2\times10^{17}<9.2\times10^{18}$（`i64` 上限）故只累乘到 $i<20$，$20!\approx2.4\times10^{18}$ 仍不溢出、$21!$ 才溢出。`pos`、`avail`、`kk`、`idx*f` 均在 $10^9$ 量级，用 `i64` 安全。`ans` 上界 $\le 1022+13<10^4$，`int` 足够，但统一 `i64` 以免与上面混算时降级。

### 4.4 验证状态（**全部手算，未运行任何代码；题面无输入输出，无法与官方答案对标**）

**样例结构复现**（用引理 2 反推输入，验证分解与 `Hint` 排列一致）：
- 样例 1：排列 `1,2,3,4,6,7,5`，恒等前缀长 $4\Rightarrow n-r_0=4$，活动区 `6,7,5$ 是 $\{5,6,7\}$ 的第 $4$ 个排列（`567,576,657,675`），故 $r_0=3,k=4,n=7$。答案：$A_{\text{恒等}}=$ 幸运数 $\le4$ 有 $\{4\}=1$；活动区位置 $5,6,7$ 中仅 $7$ 幸运，其值 $5$ 不幸运 → $A_{\text{活动}}=0$；$\text{ans}=1$。
- 样例 2：排列 `2,1,3,4`，$n=4$，$r_0=4$，$k=7$（前缀以 $2$ 开头的第一块 $\{2134,2143,\dots\}$ 的第 $1$ 个 = 全局第 $7$）。恒等段空。幸运位置仅 $4$，其值 $4$ 幸运 → $\text{ans}=1$。

**自造小例（与暴力枚举逐位核对）**：
- `n=3,k=1`：$r_0=1$，恒等段 $[1,2]$ 无幸运数，活动区 $p_3=3$ 不幸运 → $\text{ans}=0$；暴力排列 `123` 无幸运位置，✓。
- `n=4,k=1`：$r_0=1$，恒等 $[1,3]$ 无幸运，活动 $p_4=4$ 幸运 → $\text{ans}=1$；暴力 `1234` 位置4值4，✓。
- `n=4,k=3`：$r_0=3$，恒等 $[1]$，活动 $\{2,3,4\}$ 第 $3$ 排列 `324` → 全排列 `1,3,2,4`；幸运位置 $4$ 值 $4$ → $\text{ans}=1$；✓。
- `n=5,k=6`：$r_0=3$，活动 $\{3,4,5\}$ 第 $6$（末）排列 `5,4,3` → `1,2,5,4,3`；幸运位置 $4$ 值 $4$ → $\text{ans}=1$；✓。
- 边界 `n=3,k=7`：$7>3!=6$，$r_0=4>n$ → 输出 $-1$；✓。

## 5. 示例代码（C++）

```cpp
// P1384 幸运数与排列
// 第 k 排列：前缀恒等(块大小 (n-i)!>=k 时取最小候选且 k 不变)，只末尾 r0<=13 位真排
// 答案 = [1,n-r0] 内幸运数个数 + 活动段逐位判 (位置幸运 且 值幸运)
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxl{1030};              // 1e9 内幸运数 <= 2^10-2 = 1022 个
constexpr i64 lim{1000000000};        // n,k 上限

i64 n,k;
i64 fact[20];                         // 只用 fact[0..13]
i64 luckynums[mxl];
int lcnt=0;

bool islucky(i64 x)                   // x 的十进制每位是否为 4/7
{
	if(x<=0)
		return false;
	while(x)
	{
		int d=x%10;
		if(d!=4&&d!=7)
			return false;
		x/=10;
	}
	return true;
}

void gen(i64 cur)                     // DFS 枚举 <=lim 的幸运数
{
	if(cur>lim)
		return;
	if(cur>0)
		luckynums[lcnt++]=cur;
	gen(cur*10+4);
	gen(cur*10+7);
}

int countleq(i64 x)                   // [1,x] 中幸运数个数
{
	return upper_bound(luckynums,luckynums+lcnt,x)-luckynums;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	gen(0);
	sort(luckynums,luckynums+lcnt);
	fact[0]=1;
	for(int i=1;i<20;++i)
		fact[i]=fact[i-1]*i;            // fact[19]=1.2e17 仍在 i64 内

	cin>>n>>k;
	int r0=1;
	while(fact[r0]<k)                   // 最小的 m 使 m!>=k，最多到 13
		++r0;

	if(n<r0)                            // n! < k，第 k 排列不存在
	{
		cout<<-1<<'\n';
		return 0;
	}

	i64 ans=countleq(n-r0);             // 恒等段：位置=值，幸运位置即贡献

	i64 avail[20];                      // 活动段候选值 {n-r0+1 .. n}
	for(int i=0;i<r0;++i)
		avail[i]=n-r0+1+i;
	int len=r0;
	i64 kk=k;
	for(int i=0;i<r0;++i)
	{
		i64 f=fact[len-1];
		int idx=(kk-1)/f;
		kk=(kk-1)%f+1;
		i64 pos=n-r0+1+i;
		if(islucky(pos)&&islucky(avail[idx]))
			++ans;
		for(int j=idx;j<len-1;++j)      // 取走 avail[idx]，其后整体前移
			avail[j]=avail[j+1];
		--len;
	}

	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **不碰大 $n$**：全程只用 `r0<=13` 与幸运数表 $L=1022$，与 $n$ 的大小无关；判存在性只比 `n<r0`，从不计算 $n!$。
- **`i64`  everywhere**：$13!\approx6.2\times10^9>2^{31}$，故 `fact`、`kk`、`f`、`idx=(kk-1)/f` 涉及的中间量、`pos`/`avail`/`n`/`k` 均用 `i64`；`int idx` 因 $0\le idx\le len-1\le12$ 无碍。
- **删除即整体前移**：活动段取走 `avail[idx]` 后把 `idx+1..len-1` 前移一格（$O(r_0)$，共 $O(r_0^2)\le169$），保持"剩余候选升序"这一 factoradic 前提（引理 7）。比 STL `vector::erase` 更贴合全局静态数组风格，也无堆分配。
- **0-based 内部 + 显式换回 1-based**：`avail[i]=n-r0+1+i`、`pos=n-r0+1+i` 直接用题目 1-based 位置/值（幸运数定义本就 1-based，无需 $-1$），只在候选表下标上用 0-based。全文口径一致。
- **幸运数表**：`gen(0)` 递归产 $4,7,44,47,\dots$（$0$ 不入表），`sort` 后 `countleq` 借 `upper_bound` 得到 $[1,X]$ 计数（引理 5）。
- **无需 INF / `fill_n`**：本解无"不可达"状态，`luckynums` 由 `lcnt` 完整界定，`avail[20]`、`fact[20]` 均被显式写满后使用，不存在全局默认 0 被误当有效值的移植陷阱。
- **风格**：单 `#include<bits/stdc++.h>`+`using namespace std;`+`using i64=long long;`；`cin.tie/cout.tie/ios::sync_with_stdio` 顺序固定；输出 `'\n'` 不用 `endl`；Tab 缩进、运算符无空格、小写电报式函数名（`gen`/`countleq`/`islucky`）。
