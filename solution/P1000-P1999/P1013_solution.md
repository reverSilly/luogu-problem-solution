# P1013 [NOIP 1998 提高组] 进制位 题解

---

## 一、发现叙事

拿到这道题，第一反应是：这是一张"加法表"，每个字母代表一个数字，我们要把这些字母"解码"出来，同时推出这是几进制。

先看样例：

```
+   L   K   V   E
L   L   K   V   E
K   K   V   E   KL
V   V   E   KL  KK
E   E   KL  KK  KV
```

手动验证一下：如果把 L=0, K=1, V=2, E=3 代入，这确实是一张 4 进制加法表。

注意一个有趣的现象——**每一行的字符串长度分布**：

- 第一行 (L)：全部是单个字母 → 4 个单字母，0 个双字母
- 第二行 (K)：K, V, E, KL → 3 个单字母，1 个双字母
- 第三行 (V)：V, E, KL, KK → 2 个单字母，2 个双字母
- 第四行 (E)：E, KL, KK, KV → 1 个单字母，3 个双字母

行号（从 1 开始）与双字母个数：行 1→0, 行 2→1, 行 3→2, 行 4→3。恰好对应 L=0, K=1, V=2, E=3。

直觉开始形成：**双字母条目就是发生了"进位"的加法**。当两个一位数相加 ≥ 进制时，结果变成两位数（进位 + 本位）。而对于值为 `v` 的数字，它在加法表中会遇到恰好 `v` 个加法产生进位。

这种局部规律能不能推广成全局解法？我们需要论证它。

## 二、完整推理链

### 2.1 基本约定

加法表大小为 $n$，除去左上角 `+` 和首行/首列的字母标签，实际运算部分是 $(n-1) \times (n-1)$ 的格子。

首行（第 2 列到第 $n$ 列）给出了 $n-1$ 个不同的字母，首列（第 2 行到第 $n$ 行）也是如此，且顺序一致。

记这 $n-1$ 个字母的集合为 $\Sigma$，$|\Sigma| = n-1$。

### 2.2 进制数等于字母数

**断言 1**：该加法表对应的进制 $B = n-1$。

*证明*：在一个合法的 $B$ 进制加法表中，每一位数字的取值范围是 $0 \sim B-1$，共 $B$ 个不同的数字。不同的字母代表不同的数字，而题目恰好给出了 $n-1$ 个不同的字母。因此 $B = n-1$。$\square$

### 2.3 每个字母的值恰好等于其行中"双字母条目"的个数

**断言 2**：在合法的 $B$ 进制加法表中，代表数字 $v$ 的那一行（同时也是那一列），恰好有 $v$ 个条目是两位数（即发生了进位）。

*证明*：考虑值为 $v$ 的数字。它在表中与每个数字 $d \in [0, B-1]$ 相加：

$$
v + d = 
\begin{cases}
\text{一位数}, & v+d < B \\
\text{两位数}\; 1\cdot B + (v+d-B), & v+d \ge B
\end{cases}
$$

进位发生的条件是 $v + d \ge B$，即 $d \ge B - v$。由于 $d$ 的取值范围是 $0, 1, \dots, B-1$，满足 $d \ge B-v$ 的 $d$ 有：

$$
d = B-v,\; B-v+1,\; \dots,\; B-1
$$

共 $v$ 个不同的 $d$。因此恰好有 $v$ 次加法产生进位，对应 $v$ 个两位数的结果。$\square$

因此，算法第一步就是：对于每个字母（行），统计其行中长度 > 1 的字符串个数，这个数字就是该字母的数值。

### 2.4 检验完整表

仅靠上述计数不能保证表是合法的——一个随机填的表也可能恰好有每个行有对应数量的双字母条目。因此我们必须用得出的值去**验证整张表**：

- 设行标签字母 $a$ 的值为 $v_a$，列标签字母 $b$ 的值为 $v_b$
- 计算 $s = v_a + v_b$
- 若 $s < B$：结果应为单个字母，且该字母的值等于 $s$
- 若 $s \ge B$：结果应为两个字母，第一个字母（进位）的值恒为 $1$，第二个字母的值等于 $s - B$

如果每个格子都符合上述规则，则该表合法。

### 2.5 为什么进位一定是 $1$

当 $v_a, v_b < B$ 时，$v_a + v_b \le (B-1) + (B-1) = 2B-2 < 2B$，所以进位只能是 $0$ 或 $1$。当 $v_a + v_b \ge B$ 时，进位必定为 $1$。因此第一个字母一定代表数字 $1$。

### 2.6 合法性总结

综上，算法流程为：

1. 读入 $n$ 和加法表
2. 令 $B = n-1$
3. 对每个字母，统计其行中双字母条目个数作为其值
4. 检查所有值是否在 $[0, B-1]$ 范围内且互不重复
5. 用这些值验证整张加法表的每个格子
6. 若通过，则输出结果；否则输出 `ERROR!`

## 三、模式总结

### 3.1 核心模式：计数即赋值

这类问题的关键观察往往是**某个可计数特征直接对应数字本身**。在这里，进位次数 = 数值。类似的题目还有：

- **[P1087 FBI 树](https://www.luogu.com.cn/problem/P1087)**：统计区间内 `0` 和 `1` 的个数来判定节点类型
- **[P1308 统计单词数](https://www.luogu.com.cn/problem/P1308)**：统计匹配次数

### 3.2 通法：利用进位判定进制和数值

在加法表中，"结果字符串长度"是一个极为重要的特征：

| 特征 | 含义 |
|------|------|
| 长度为 1 | 无进位，结果为一位数 |
| 长度为 2 | 有进位，第一位是进位 1，第二位是本位 |

当题目中出现"字母代表数字的加法表"时，**位数 → 进位 → 数值** 的推理链几乎总是成立的。

### 3.3 检验比猜测更重要

竞赛中，"找规律 → 猜测 → 检验"是常用套路。猜出规律后一定要用**穷举验证**确保正确性。这道题中如果只做计数不检验，会被构造的反例卡掉。

### 3.4 类似题目

- [P1309 [NOIP 2011 普及组] 瑞士轮](https://www.luogu.com.cn/problem/P1309)——虽然是排序题，但也体现了"利用题目自身的结构特征简化问题"的思想
- [P1012 [NOIP 1998 提高组] 拼数](https://www.luogu.com.cn/problem/P1012)——同一年 NOIP 提高组的题目，同样是字符串 + 数字映射

## 四、正式解法

### 4.1 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 表格的行数（也是列数），$3 \le n \le 9$ |
| $B = n-1$ | 加法运算的进制 |
| $s_{i,j}$ | 表格第 $i$ 行第 $j$ 列的字符串，$0$-based 索引 |
| $\Sigma$ | 字母集合，$|\Sigma| = B$ |
| $v(c)$ | 字母 $c$ 所代表的数值 |
| $\text{len}(s)$ | 字符串 $s$ 的长度 |

### 4.2 算法步骤

```
Algorithm Solve(n, table[][])
1:  B ← n - 1
2:  for each row i from 1 to n-1:
3:      c ← table[i][0]               // 行标签字母
4:      cnt ← 0
5:      for each col j from 1 to n-1:
6:          if len(table[i][j]) > 1:
7:              cnt ← cnt + 1
8:      v[c] ← cnt
9:  // 检查数值范围与互异性
10: for each letter c:
11:     if v[c] < 0 or v[c] >= B or used[v[c]]:
12:         return ERROR
13:     used[v[c]] ← true
14: // 验证整张表
15: for i from 1 to n-1:
16:     for j from 1 to n-1:
17:         a ← v[table[i][0]]
18:         b ← v[table[0][j]]
19:         sum ← a + b
20:         res ← table[i][j]
21:         if sum < B:
22:             if len(res) ≠ 1 or v[res[0]] ≠ sum:
23:                 return ERROR
24:         else:
25:             if len(res) ≠ 2 or v[res[0]] ≠ 1 or v[res[1]] ≠ sum - B:
26:                 return ERROR
27: // 输出
28: for each letter c (按输入顺序):
29:     output "c=v[c]"
30: output B
31: return OK
```

### 4.3 正确性

- **完全性**：如果存在合法解，计数法一定给出正确赋值（见断言 2），且验证必定通过。
- **可靠性**：如果验证通过，每个格子都满足加法规则，必为合法加法表。
- 题目保证至多有一组解，因此找到即最优。

### 4.4 复杂度

- **时间复杂度**：$O(n^2)$，$n \le 9$，常数极小
- **空间复杂度**：$O(n^2)$ 用于存储表格字符串

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int n,base;
string s[11][11];
int val[256];

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			cin>>s[i][j];

	base=n-1;
	memset(val,-1,sizeof val);

	// 通过统计每行中长度为 2 的条目个数来确定字母的值
	for(int i=1;i<n;++i)
	{
		char c=s[i][0][0];
		int cnt=0;
		for(int j=1;j<n;++j)
			if(s[i][j].size()>1)
				++cnt;
		val[c]=cnt;
	}

	// 检查值是否在 [0,base) 范围内且互不重复
	bool used[11]{};
	for(int i=1;i<n;++i)
	{
		char c=s[i][0][0];
		int v=val[c];
		if(v<0||v>=base||used[v])
		{
			cout<<"ERROR!\n";
			return 0;
		}
		used[v]=true;
	}

	// 用已确定的值验证整张加法表
	for(int i=1;i<n;++i)
	{
		for(int j=1;j<n;++j)
		{
			int a=val[s[i][0][0]];
			int b=val[s[0][j][0]];
			int sum=a+b;
			string&t=s[i][j];

			if(sum<base)
			{
				if(t.size()!=1||val[t[0]]!=sum)
				{
					cout<<"ERROR!\n";
					return 0;
				}
			}
			else
			{
				int carry=sum/base; // 恒为 1
				int digit=sum%base;
				if(t.size()!=2||val[t[0]]!=carry||val[t[1]]!=digit)
				{
					cout<<"ERROR!\n";
					return 0;
				}
			}
		}
	}

	// 按输入顺序输出各字母的值
	for(int i=1;i<n;++i)
	{
		if(i>1)
			cout<<' ';
		cout<<s[i][0]<<'='<<val[s[i][0][0]];
	}
	cout<<'\n';
	cout<<base<<'\n';

	return 0;
}
```
