# P1368 工艺

> 标签：字符串（题面 tag 写 SAM，实际正解是**最小表示法**；题面 Background 直接指向 [P13270【模板】最小表示法](https://www.luogu.com.cn/problem/P13270)）· 难度：省选/NOI−

## 1. 重新读题

**问题重述（大白话版）**

有一排 $n$ 个方块，从左到右的瑕疵度是 $a_0,a_1,\dots,a_{n-1}$（题目保证是 $[0,30)$ 内的整数）。机器**只会一个动作**：把**最左边**的方块搬到**最右边**。这个动作可以做任意多次（包括 0 次）。问：这样能得到的"最漂亮"工艺品，从左到右的瑕疵度序列是什么。

比较漂亮的方法题目写得很明确：从头逐位比，第一次出现不同的位置上，**瑕疵度小的那个更漂亮**；若每一位都相同则"一样漂亮"。这正是整数序列上的**字典序**（小者为优）。

**四个必须抠清楚的口径（以本地题面为准）**

| 口径 | 题面依据 | 结论 |
|---|---|---|
| 环形还是线性？ | "长条工艺品"，输出"从左到右"的值 | 成品是**线性序列**，只是可通过搬动改变起点 |
| 能做什么操作？ | "只能把这个工艺品最左边的方块放到最右边" | 只做**循环左移 1 位**；做 $m$ 次 = 左移 $m$ 位。**不能翻转**、不能任意重排 |
| 比较口径 | 逐位比、瑕疵度小者优、全同则并列 | **字典序取最小**（不是最大、不是极差/和之类的整体指标） |
| 数据组数 / 输出 | "第一行一个整数 $n$"、"一行 $n$ 个整数" | **单组数据**；要输出**整个方案序列**，不是编号、不是计数 |

**约束**

| 量 | 范围 |
|---|---|
| $n$ | $1\le n\le 3\times10^5$（分档：$n\le1000$ 占 20%，$n\le10^4$ 占 40%） |
| $a_i$ | $0\le a_i<30$ 的整数（字母表极小，$<30$） |

**子任务给的暗示**：$n\le1000$ 时 $O(n^2)$ 枚举每个起点即可（约 $10^6$ 次比较），$n\le10^4$ 时 $O(n^2)=10^8$ 已经吃紧，$n\le3\times10^5$ 时 $n^2=9\times10^{10}$ 绝无可能 ⟹ 满分需要 $O(n)$（最小表示法）或至多 $O(n\log n)$（后缀排序/哈希 + 二分）的做法。

**样例声明（重要）**：本地题面文件 `P1368.md` **没有 Sample 块**，只有输入/输出格式说明，因此**无法对标官方样例**；第 4.3 节的所有验证都是**自造小例的手工推演**（含 $n=1$、全相等周期串、重叠消元等边界）。本环境无编译器，**未运行任何代码、未做随机对拍**。

## 2. 思维链（Chain-of-thought）

### 2.1 探索机制：可达状态恰好是 $n$ 个循环移位

把一次操作记作 $L$：$(x_0,x_1,\dots,x_{n-1})\mapsto(x_1,x_2,\dots,x_{n-1},x_0)$。

**引理 1（候选集合不重不漏）**：从 $a$ 出发做任意次操作能得到的序列集合，恰为
$$\mathcal R=\{\,R_p:\ p=0,1,\dots,n-1\,\},\qquad R_p=(a_p,a_{p+1},\dots,a_{p+n-1})\ \text{（下标模 }n\text{）}.$$
即"可达"= "循环移位"，一个不多一个不少。

**证明**：*（不漏 + 每步形状）* 对操作次数 $m$ 归纳证明"做 $m$ 次后第 $i$ 位是 $a_{(m+i)\bmod n}$"。$m=0$ 即 $a_i$，成立。设 $m$ 次后成立，则 $m+1$ 次后：新序列第 $i$ 位（$i<n-1$）是旧序列第 $i+1$ 位 $=a_{(m+i+1)\bmod n}=a_{((m+1)+i)\bmod n}$；新序列第 $n-1$ 位是被搬走的旧第 $0$ 位 $=a_{m\bmod n}$，而公式给出 $a_{((m+1)+(n-1))\bmod n}=a_{m\bmod n}$，一致。故 $m$ 次后就是 $R_{m\bmod n}$，取 $m=p\in[0,n-1]$ 即得每个 $R_p$ 都可达。
*（不多）* 若 $p\ne q$（都在 $[0,n)$ 内）则 $R_p\ne R_q$ 未必成立（周期串会相等），但它们**取值相同**，故对"最小值"毫无影响；而任意可达序列都等于某个 $R_{m\bmod n}$，所以候选集合就是 $\mathcal R$。
*（为什么不必另外讨论"翻转"）* 上面归纳证的是**精确等式**"$m$ 次操作后的序列 $=R_{m\bmod n}$"，可达集已被完全刻画，不需要再单独论证"翻转不可达"：翻转串 $(a_{n-1},\dots,a_0)$ 只有在本身等于某个 $R_p$ 时才可能等于一个可达序列，而那种情况下它已经包含在 $\mathcal R$ 里，取最小元时不会漏。操作 $L$ 保持"循环后继关系"（相邻对集合 $\{(x_i,x_{i+1}\bmod n)\}$ 在搬动前后完全相同，只是起点变了），这提供了几何直觉：搬动只能改起点、不能改绕行方向。故问题被严格化归为：

> **抽象问题**：给定长度 $n$ 的整数序列 $a$，求 $\arg\min_{p\in[0,n)} R_p$（字典序），并输出该 $R_p$。

**比较口径的形式化（把题目那段话翻译成符号）**：记 $R_x[d]=a_{(x+d)\bmod n}$（$0\le d<n$）。题目说"从头开始比较，第 $i$ 个位置不一样则瑕疵度小者更漂亮；全都一样则一样漂亮"，翻成符号就是：设 $\ell(x,y)=\min\{\,d:R_x[d]\ne R_y[d]\,\}$（不存在则记 $\ell=n$，表示两串全等），则
$$R_x\prec R_y\iff \ell(x,y)<n\ \text{且}\ R_x[\ell]<R_y[\ell];\qquad R_x\preceq R_y\iff R_x\prec R_y\ \text{或}\ \ell(x,y)=n.$$
$\prec$ 是严格全序（任意两个不同串可比、且不同时 $R_x\prec R_y$ 与 $R_y\prec R_x$——因为第一个不同位上只能一个小），$\preceq$ 把"逐位全等"判为并列，因此 $\mathcal R$ 上**最小元一定存在**（$\mathcal R$ 非空有限，$n\ge1$）；又因"平局 ⟺ 两串逐位相同"，**从哪个最小元出发输出都一样**，所以算法只需给出*某个*最小元的起点，不必担心 $\arg\min$ 不唯一（4.3 的 (3)(6)(8) 正是平局情形）。这就把题目严格写成"求最小表示的起点"。

这就是**循环序列的最小表示法**。下面先按子任务做简单版本。

### 2.2 简化版（对应 20% 分档）：枚举起点、逐个比

对每个 $p$ 与当前最优 $p^{*}$ 做字典序比较，最坏每次比 $n$ 位：
$$T(n)=O\big(n\cdot n\big)=n^2\ \text{次逐位比较}$$
$n=1000\Rightarrow10^6$（轻松），$n=10^4\Rightarrow10^8$（勉强且常数小才可能过），$n=3\times10^5\Rightarrow9\times10^{10}$（必 TLE）。
这个版本**必须写出来当作验证基准**（4.3 节我用手算的"暴力枚举"就是它）。

### 2.3 朴素慢在哪里：前缀相等被反复重比

若 $R_x$ 与 $R_y$ 前 $k$ 位相同，朴素做法比完一次，下一轮又从头比。极端如 $a=[1,1,\dots,1]$：每对候选都要比满 $n$ 位，$O(n^2)$ 走满。要快就必须把"比过的信息"存进指针：**两个候选比到第 $k$ 位失配时，能顺手淘汰一整段起点**——这就是最小表示法的核心。

**顺手检查一下题面的 $a_i<30$ 能不能救朴素法**（值域小是最容易被误当成"突破口"的条件）：最直观的想法是"先只保留第 1 位取全局最小值的那些起点，再看第 2 位筛掉一批，逐位细化"。但这一层筛选在 $a$ 全相等（或有周期）时**一个候选都筛不掉**：$n$ 个起点全部活到第 $n$ 位，仍是 $\Theta(n^2)$。所以值域 $<30$ 只保证"每格只有 30 种取值、一次逐位比较是 $O(1)$"，**不提供候选数的下降**；它真正的用处只有一个——保证比较用的差值 $t\in[-29,29]$ 绝不溢出（见 4.2 的溢出预算）。结论：必须靠 2.4 的结构性质来淘汰候选，而不是靠值域。

### 2.4 引理 2（失配消元：一次淘汰 $k+1$ 个起点）

设 $x,y\in[0,n)$，$x\ne y$，且已知
$$R_x[0..k-1]=R_y[0..k-1]\quad(\text{即前 }k\text{ 位逐位相等，}k=0\text{ 时视为空条件}),\qquad R_x[k]>R_y[k].$$
则对每个 $t\in[0,k]$ 都有 $R_{x+t}>R_{y+t}$（下标均模 $n$），从而 $x,x+1,\dots,x+k$ 这 $k+1$ 个起点**都不是最小表示的起点**。

**证明**：先把已知条件写成下标式：对每个 $d'\in[0,k-1]$，$a_{(x+d')\bmod n}=a_{(y+d')\bmod n}$（这是"$R_x[0..k-1]=R_y[0..k-1]$"的定义），并且 $a_{(x+k)\bmod n}>a_{(y+k)\bmod n}$。

固定 $t\in[0,k]$，比较 $R_{x+t}$ 与 $R_{y+t}$。
*（前 $k-t$ 位相等）* 任取 $d\in[0,k-t-1]$，令 $d'=t+d$，则 $d'\in[t,k-1]\subseteq[0,k-1]$，于是
$$R_{x+t}[d]=a_{(x+t+d)\bmod n}=a_{(x+d')\bmod n}=a_{(y+d')\bmod n}=a_{(y+t+d)\bmod n}=R_{y+t}[d].$$
*（下一位分胜负）* 第 $k-t$ 位：$R_{x+t}[k-t]=a_{(x+k)\bmod n}>a_{(y+k)\bmod n}=R_{y+t}[k-t]$（因为 $(x+t)+(k-t)=x+k$，模 $n$ 无影响）。
由字典序定义得 $R_{x+t}>R_{y+t}$（$t=k$ 时"前 $0$ 位相等"是空条件，结论直接由失配位给出，仍然成立）。
还须确认这次比较是**合法的对手比较**：$y+t$ 模 $n$ 后仍是 $[0,n)$ 中的整数，故 $R_{(y+t)\bmod n}$ 属于候选集 $\mathcal R$（引理 1）；且 $x+t\not\equiv y+t\pmod n$，否则 $x\equiv y\pmod n$，而 $|x-y|<n$ 与 $x\ne y$ 矛盾。因此 $R_{x+t}$ 严格大于另一个候选串，它不可能是最小元。$t$ 是 $[0,k]$ 中任意值，故 $x,x+1,\dots,x+k$ 这 $k+1$ 个起点全部淘汰。$\blacksquare$

> 关键提醒：**被淘汰的起点的"对手" $y+t$ 本身也可能正在被淘汰**（当窗口重叠时 $y+t$ 就落在 $[x,x+k]$ 里，见 4.3 的例 (7)）。这不影响证明，因为淘汰只需要"存在某个严格更小的候选"，不要求对手活下来；传递下去仍保证被淘汰者非最小。

### 2.5 引理 3（双指针算法：候选不重不漏）

算法维护 $i,j,k$，初值 $i=0,j=1,k=0$，每轮比较 $R_i[k]$ 与 $R_j[k]$：相等则 $k\leftarrow k+1$；否则设 $t=R_i[k]-R_j[k]$，若 $t>0$ 则 $i\leftarrow i+k+1$ 且若 $i\le j$ 再令 $i\leftarrow j+1$（$t<0$ 时对称地更新 $j$），随后 $k\leftarrow0$。

**引理 3（不变量）**：每一轮循环开始时，
(I1) $i\ne j$；
(I2) 任意满足 $0\le x<\max(i,j)$ 且 $x\notin\{i,j\}$ 的位置 $x$ 都已被引理 2 淘汰（即 $R_x$ 不是最小串）。

**证明**：记"淘汰集"为到当前为止被引理 2 判死的**位置**（模 $n$ 后的 $[0,n)$ 中的点）之集 $E$；引理 2 的可靠性保证 $E$ 中无最小起点，且 $E$ 随轮数单调增。对轮数归纳证 (I1)(I2)。

*(I1) $i\ne j$*：初值 $0\ne1$ ✓。设轮初 $i\ne j$。若本轮移动 $i$：先 $i\leftarrow i+k+1$，再（若 $i\le j$）$i\leftarrow j+1$。合并写作 $i'=\max(i+k+1,\,j+1)$，故 $i'>j$，特别 $i'\ne j$ ✓；移动 $j$ 时对称。

*(I2)*：设轮初 $M=\max(i,j)$，$E\supseteq[0,M)\setminus\{i,j\}$。本轮失配（$t>0$，移动 $i$），由引理 2 新淘汰余数段 $\{(i+\tau)\bmod n:\tau\in[0,k]\}$，其中凡是落在 $[i,\min(i+k,n-1)]$ 的**整数**位置都被淘汰（取 $\tau=x-i$ 即可，不需绕圈）；旧指针 $i$ 正是区间的第一个点（$\tau=0$），于是它这个"例外"也归入 $E$。新 $\max$ 记作 $M'$，需证 $[0,M')\setminus\{i',j\}\subseteq E$。分情形：

1. **$i>j$**：此时 $M=i$，且 $i+k+1\ge i+1>j$，故 $i'=i+k+1$（抬升分支不触发）、$M'=i'$。需补证 $x\in[M,M')=[i,\,i+k]$（且 $x<n$）被淘汰：取 $\tau=x-i\in[0,k]$，正是引理 2 的淘汰段 ✓。
2. **$i<j$ 且 $i+k+1>j$**：$M=j$，$i'=i+k+1$，$M'=i'$。需补证 $x\in[j,\,i+k]\setminus\{j\}$ 被淘汰：这样的 $x$ 满足 $j<x\le i+k$ 且 $x>j>i$，即 $x\in[i+1,i+k]$，取 $\tau=x-i\in[1,k]$ ✓。
3. **$i<j$ 且 $i+k+1\le j$**：$M=j$，抬升分支触发，$i'=j+1$，$M'=j+1$。需补证 $x\in[j,j+1)\setminus\{j\}=\varnothing$ ✓（$i$ 自己则属于本轮淘汰段）。**这一情形里指针从 $i+k+1$ 跳到 $j+1$，表面上"跨过"了 $[i+k+1,j)$ 这些位置而没有用引理 2 检验**——但它们都 $<M=j$ 且不等于 $i$、不等于 $j$，早已在归纳假设的 $E$ 里，所以没有漏掉任何可能的最小起点；这正是"不重不漏"里"不漏"的所在。

$t<0$ 时把 $i,j$ 对调，论证完全相同。故 (I2) 在下一轮成立。$\blacksquare$

**终止与答案**：循环因 $i\ge n$ 或 $j\ge n$（此时另一个仍 $<n$，因为上一轮它俩都 $<n$ 且每轮只动一个指针）或 $k\ge n$ 而停止。上面 (I2) 的归纳是**在"更新之后"的状态**上证的（$M'$ 允许 $\ge n$，此时只需对 $x<n$ 的位置要求被淘汰），所以它在退出时刻同样成立，可以直接用来论证答案。
- 若因 $i\ge n$（或 $j\ge n$）停止：设 $p$ 为真正最小起点。$p\notin E$（引理 2 只淘汰非最小者），且 $p<n\le\max(i,j)$，由 (I2) 得 $p\in\{i,j\}$；另一个 $\ge n$ 不可能是起点，故 $p=\min(i,j)$ ✓。
- 若因 $k\ge n$ 停止：见引理 4，同样有 $\min(i,j)$ 就是最小起点。

这两条合起来就是题目要求的**候选集合不重不漏**：不重 = 每轮淘汰的 $k+1$ 个点都被严格证明"存在更小的串"（引理 2），从不涉及最小元；不漏 = 退出时 $\max(i,j)$ 以下除双指针外全被判死，而 $\ge n$ 的那侧不是位置，故最小元只能是被留下的那个指针（引理 3 + 引理 4）。

### 2.6 引理 4（$k=n$ 退化：两指针指向同一个串，且它就是最小串）

**引理 4**：若比较进行到 $k=n$（即当前两个指针满足 $R_i$ 与 $R_j$ 的前 $n$ 位逐位全等），取 $i<j$（另一侧对称）则 $d=j-i$ 是 $a$ 的**循环周期**，且 $\min(i,j)=i$ 是最小起点。

**证明**：以下设 $i<j$（另一侧对称），$d=j-i\ge1$，$g=\gcd(d,n)$。

*(a) $d$ 是循环周期*：对任意位置 $z\in[0,n)$，取唯一的 $t\in[0,n)$ 使 $z\equiv i+t\pmod n$，则
$$a_{z}=a_{(i+t)\bmod n}=R_i[t]=R_j[t]=a_{(j+t)\bmod n}=a_{(z+d)\bmod n},$$
中间一步就是"$k$ 已比满 $n$ 位"的全部内容。故平移 $d$ 保持 $a$ 不变，进而 $R_z=R_{(z+d)\bmod n}$。

*(b) 于是 $g$ 也是周期，且 $x\equiv y\pmod g\Rightarrow R_x=R_y$*：反复用 (a) 得 $a_z=a_{(z+qd)\bmod n}$（任意整数 $q$：$q<0$ 时由 $a_{z}=a_{(z-d+d)\bmod n}=a_{(z-d)\bmod n}$ 可得）。由 Bézout 恒等式 $g=ud+vn$，故 $a_{(z+g)\bmod n}=a_{(z+ud)\bmod n}=a_z$（$vn$ 那一项模 $n$ 后消失），即 $g$ 是周期。对 $x\equiv y\pmod g$ 有 $y=x+wg$，而"$g$ 是周期"逐次套用 $|w|$ 遍给出 $a_{(u+wg)\bmod n}=a_{u\bmod n}$（对任意 $u$），于是逐位
$$R_x[t]=a_{(x+t)\bmod n}=a_{(x+t+wg)\bmod n}=a_{(y+t)\bmod n}=R_y[t],$$
两移位全等。

*(c) $i$ 是最小起点*：注意 $[i,i+d)=[i,j)\subseteq[0,n)$（因 $i+d=j<n$），是一段合法位置。设 $p$ 是任一最小起点。区间 $[i,i+d)$ 是 $d$ 个连续整数，而 $g\mid d$ 且 $1\le g\le d$，故 $d$ 个连续整数必然覆盖到每一个模 $g$ 剩余类（至少 $d/g\ge1$ 次）；取其中与 $p$ 同类的那个为 $p_0\in[i,i+d)$，它自然是合法位置。由 (b) $R_{p_0}=R_p$，所以 $p_0$ 也是最小起点，特别 $p_0\notin E$。又 $p_0<i+d=j=\max(i,j)$，由引理 3 的 (I2)，未被淘汰者必须属于 $\{i,j\}$；而 $j\notin[i,j)$，故 $p_0=i$。于是 $R_i$ 就是最小串，$\min(i,j)=i$ 给出的输出正确 ✓（此时 $R_i=R_j$，两个指针给出同一串，取小者无损）。$\blacksquare$

> 顺带说明：*(b)* 里"同剩余类 ⟹ 同串"也解释了为什么 (I2) 允许 $E$ 里塞进绕回 $n$ 之后的额外位置——淘汰只可能"多淘汰"，从不淘汰最小元，归纳始终安全。

### 2.7 引理 5（复杂度：循环次数 $\le3n-3$，故比较次数 $<3n$）

**证明**：取势函数 $\Phi=i+j+k$。每轮循环体恰好做**一次**下标比较（算 $t$）。
- 相等分支：$k\to k+1$，$\Phi$ 恰增 $1$；
- 失配分支：被移动的指针至少增 $k+1$（抬升分支只可能加更多），$k$ 归零，故 $\Phi\to\Phi+(k+1)-k=\Phi+1$ 或更多。

于是每轮 $\Phi$ 至少增 $1$。记第 $r$ 轮**开始时**的势为 $\Phi_r$，则 $\Phi_r\ge\Phi_1+(r-1)=1+(r-1)=r$（初值 $i=0,j=1,k=0$ 给 $\Phi_1=1$）。而"能进入第 $r$ 轮"要求循环守卫成立，即 $i\le n-1$、$j\le n-1$、$k\le n-1$，故 $\Phi_r\le3n-3$。两者合并得 $r\le3n-3$，即循环至多执行 $3n-3$ 轮、比较至多做 $3n-3$ 次（$n=1$ 时为 $0$ 轮，结论仍成立）。
总时间 $=$ 比较 $O(n)$ + 读入 $O(n)$ + 输出 $O(n)$ $=O(n)$；空间 $O(n)$（只用一个 $a$ 数组，见 4.2 的内存预算）。$\blacksquare$

### 2.8 备选做法与取舍

- **后缀数组/SAM（题面 tag）**：在 $T=a+a$（长 $2n$）上排序后缀，取"起点 $<n$ 的最小后缀"的前 $n$ 位。正确性：两个起点 $p,q<n$ 的串若不同，其长度 $n$ 前缀已决出顺序，与整后缀顺序一致；若相同则输出一样。$O(n\log n)$ 或 $O(n)$，但代码量与内存都远大于最小表示法。
- **哈希 + 二分 LCP 枚举**：$O(n\log n)$，有碰撞风险。
- **最小表示法**：$O(n)$、$\le3n$ 次比较、$O(n)$ 内存、约 15 行，且无需 64 位/取模大数。**选它**。

## 3. 模式总结（实际思考顺序）

- **explore its property** — 唯一操作"最左搬到最右"= 循环左移；引理 1 证明可达集恰为 $n$ 个移位 $R_p$，不含翻转。
- **translate the objective** — 题目的"漂亮"定义 = 整数序列字典序取最小 ⟹ 这是**最小表示法**模板题。
- **consider easier version / subtask** — $n\le1000$ 枚举起点逐个比，$O(n^2)$；同时充当验证基准。
- **dissect the bottleneck** — 朴素慢在"前缀相等被反复重比"（全 $1$ 串最坏 $\Theta(n^2)$）。
- **sanity check the side constraints** — 值域 $a_i<30$ 只送来 $O(1)$ 比较与不溢出，**不减少候选数**（逐位筛选在全等/周期串上一个都筛不掉），所以不能指望它把 $O(n^2)$ 降下来。
- **classic problem solution** — 双指针 + 失配整段消元（引理 2）：一次失配淘汰 $k+1$ 个起点，并把已比过的 $k$ 位信息留在指针里。
- **proof of completeness（不重不漏）** — 引理 3 的不变量 $\max(i,j)$ 以下除双指针外全被淘汰 + 引理 4 处理 $k=n$ 的周期退化，两者合起来证明返回 $\min(i,j)$ 恰为最小起点。
- **classic problem solution（第二处）** — 势函数 $\Phi=i+j+k$ 做摊还计数：每轮恰好一次比较且 $\Phi$ 至少加 1，得比较次数 $\le3n-3$（引理 5）。
- **alternative technique（备选）** — $a+a$ 上的后缀数组/SAM 或哈希+二分，$O(n\log n)$，被 $O(n)$ 的最小表示法取代。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n` | 方块数 | `int`，输入，$1\le n\le3\times10^5$ | — |
| `a[]` | 瑕疵度 $a_0..a_{n-1}$ | `int a[mxn]`，全局默认 0，读入填满 | 值 $<30$；下标一律模 `n` |
| `i` | 候选起点 1（被比对象） | `int`，初值 0 | "i 输就抬 i" |
| `j` | 候选起点 2 | `int`，初值 1 | $i\ne j$ 恒成立 (I1) |
| `k` | 当前已确认相等的位数（LCP 长度） | `int`，初值 0 | 失配后归 0；$k=n$ 即周期 |
| `t` | $R_i[k]-R_j[k]$ | `int`，每轮现算 | $t>0$ ⟹ `i` 方输；$t<0$ ⟹ `j` 方输 |
| `m` | 最小表示起点（答案位置） | `int`，全局 | = 引理 3 的 $\min(i,j)$ |
| `mxn` | 数组上界 $3\times10^5+5$ | `constexpr int mxn{300005}` | +5 松弛 |

> **下标约定**：全文与代码**一律 0-based**（$a_0..a_{n-1}$，起点 $m\in[0,n)$）。输入只给数值不给编号，无需 `--` 转换。比较 $R_i[k]$、$R_j[k]$ 在代码里写成 `a[(i+k)%n]`、`a[(j+k)%n]`。

### 4.2 算法步骤

1. 读 $n$ 与 $a_0..a_{n-1}$。
2. 置 `i=0,j=1,k=0`。当 `i<n && j<n && k<n` 反复做：
   `t=a[(i+k)%n]-a[(j+k)%n]`；
   若 `t==0` 则 `++k`；
   否则：`t>0` 时 `i=i+k+1`，再若 `i<=j` 则 `i=j+1`；`t<0` 时 `j=j+k+1`，再若 `j<=i` 则 `j=i+1`；最后 `k=0`。（引理 2 的整段消元 + (I1) 修复）
3. `m=min(i,j)`（引理 3、引理 4 保证它就是最小起点）。
4. 输出 $a[(m+0)\%n],\dots,a[(m+n-1)\%n]$，空格分隔、行末 `'\n'`。

**复杂度**：比较次数 $\le3n-3$（引理 5），加读入/输出，时间 $O(n)$；$n=3\times10^5$ 时约 $9\times10^5$ 次比较 + $3\times10^5$ 次取模运算，远低于常见 1s 时限的操作数量级（此处只做算式估算，**未实测耗时**）。空间 $O(n)$。

**溢出预算**（逐项给出最坏值，全部按 $n\le3\times10^5$ 核算）：

| 量 | 最坏取值 | 与 `int` 上限 $2.1\times10^9$ 比较 |
|---|---|---|
| 差值 `t` | $29-0=29$ 或 $0-29=-29$（值域 $[0,30)$） | 极小，安全 |
| 取模前的 `i+k`、`j+k` | 进入循环体才有比较，此时 $i,j,k\le n-1$，故 $\le2n-2=599998$ | 余量 $\sim3500$ 倍 |
| 指针更新后 `i+k+1` | $\le 2n-1=599999$；抬升分支至多 $j+1\le n$ | 安全 |
| 输出下标 `m+i` | $m\le n-1$、$i\le n-1$ ⟹ $\le2n-2$ | 安全 |

全程无连乘、无累加求和，最大中间量不超过 $6\times10^5$，**不需要 `long long`**；把 $n$ 误当成 $10^6$ 级别也不会溢出，但要改 `mxn`。

**内存预算**：`a[300005]` 个 `int` $=300005\times4\,\text{B}\approx1.14\,\text{MiB}$；另有 `n,m` 与 `minrep()` 内 4 个 `int` 标量（$<100\,\text{B}$）和 iostream 缓冲区，总占用 $\approx1.2\,\text{MiB}$，对常见 125 MiB 限制余量 100 倍。若改用"复制成 $2n$ 长数组以省掉 `%`"的写法，$2\times3\times10^5\times4\,\text{B}\approx2.29\,\text{MiB}$，同样安全。

**验证状态**：全部为**手工推演**（题面无样例 ⟹ 无法对标官方样例；见 4.3）。

### 4.3 手工验证

约定：`暴力` = 2.2 的枚举比较（人的逐位比较），`算法` = 4.2 的双指针迹线。记 $R_p$ 为起点 $p$ 的移位。

**(1) 边界 $n=1$**：$a=[7]$。`算法`：`j=1<n` 不成立，循环一次都不进，`m=min(0,1)=0` ⟹ 输出 `7`。`暴力`：唯一候选 `7` ✓。

**(2) 边界 $n=2$，需要搬一次**：$a=[2,1]$。`暴力`：$R_0=(2,1)$，$R_1=(1,2)$，最小 $R_1$ ⟹ `1 2`。`算法`：$i{=}0,j{=}1,k{=}0$：$t=a[0]-a[1]=1>0$ ⟹ $i=1\le j$ ⟹ $i=2$，$k=0$；$i<n$ 不成立退出，$m=\min(2,1)=1$ ⟹ `1 2` ✓。

**(3) 边界 $n=2$，全相等（周期退化）**：$a=[1,1]$。`算法`：$t=0$ 两次 ⟹ $k=2=n$ 退出，$m=\min(0,1)=0$ ⟹ `1 1`。`暴力`：$R_0=R_1=(1,1)$，取哪个都一样 ✓（引理 4 的情形）。

**(4) 一般 $n=5$，多轮消元**：$a=[3,1,2,1,2]$。
`暴力`：$R_0=(3,1,2,1,2)$，$R_1=(1,2,1,2,3)$，$R_2=(2,1,2,3,1)$，$R_3=(1,2,3,1,2)$，$R_4=(2,3,1,2,1)$；以 $1$ 开头的是 $R_1,R_3$，第 3 位 $1<3$ ⟹ 最小 $R_1$ ⟹ `1 2 1 2 3`。
`算法`：$(i,j,k)=(0,1,0)$：$t=3-1>0$ ⟹ $i=1\le j$ ⟹ $i=2$；$(2,1,0)$：$t=a[2]-a[1]=2-1>0$ ⟹ $i=3$；$(3,1,0)$：$1-1=0$ ⟹ $k=1$；$a[4]-a[2]=2-2=0$ ⟹ $k=2$；$a[0]-a[3]=3-1>0$ ⟹ $i=3+2+1=6\ge n$ 退出 ⟹ $m=\min(6,1)=1$ ✓。淘汰集逐轮为：$\{0\}$（$(0,1,0)$ 失配）、$\{2\}$（$(2,1,0)$ 失配）、$\{3,4,0\}$（$(3,1,k{=}2)$ 失配，整数段 $[3,5]$ 绕回成余数 $\{3,4,0\}$）并集 $=\{0,2,3,4\}$；$[0,\max(6,1))$ 内除指针 $1$ 之外全被判死，留下的 $1$ 恰是答案，与 (I2) 吻合 ✓。

**(5) 一般 $n=8$，包含 `j<=i` 抬升分支**：$a=[2,3,1,2,1,1,3,1]$。
`暴力`：$R_0=(2,3,1,2,1,1,3,1)$，$R_1=(3,1,2,1,1,3,1,2)$，$R_2=(1,2,1,1,3,1,2,3)$，$R_3=(2,1,1,3,1,2,3,1)$，$R_4=(1,1,3,1,2,3,1,2)$，$R_5=(1,3,1,2,3,1,2,1)$，$R_6=(3,1,2,3,1,2,1,1)$，$R_7=(1,2,3,1,2,1,1,3)$。以 $1$ 开头者 $R_2,R_4,R_5,R_7$；比第 2 位：$R_4$ 的 $1$ 最小 ⟹ 答案 $R_4$ ⟹ `1 1 3 1 2 3 1 2`。
`算法`：$(0,1,0)$：$2-3<0$ ⟹ $j=2$；$(0,2,0)$：$2-1>0$ ⟹ $i=1\le j=2$ ⟹ $i=3$；$(3,2,0)$：$2-1>0$ ⟹ $i=4$；$(4,2,0)$：$1-1=0$、$a[5]-a[3]=1-2<0$ ⟹ $j=2+1+1=4\le i=4$ ⟹ $j=5$；$(4,5,0)$：$1-1=0$、$a[5]-a[6]=1-3<0$ ⟹ $j=7$；$(4,7,0)$：$a[4]-a[7]=0$ ⟹ $k=1$；$a[5]-a[0]=1-2<0$ ⟹ $j=7+1+1=9\ge n$ 退出 ⟹ $m=\min(4,9)=4$ ✓。

**(6) 周期串 $n=6$（$k=n$ 退化，答案不唯一）**：$a=[2,1,1,2,1,1]$。
`暴力`：$R_1=(1,1,2,1,1,2)=R_4$，$R_2=(1,2,1,1,2,1)=R_5$，故最小串是 $(1,1,2,1,1,2)$，起点 $1$ 或 $4$（输出相同）。
`算法`：$(0,1,0)$：$2-1>0$ ⟹ $i=1\le1$ ⟹ $i=2$；$(2,1,0)$：$1-1=0$、$a[3]-a[2]=2-1>0$ ⟹ $i=4$；$(4,1,k)$：$a[4..]$ 与 $a[1..]$ 逐位 $1,1,2,1,1,2$ 全等 ⟹ $k$ 增至 $6$ 退出 ⟹ $m=\min(4,1)=1$ ⟹ `1 1 2 1 1 2` ✓（周期 $d=3$，正是引理 4：$R_1=R_4$，取小者输出无损）。

**(7) 重叠消元（被比对手自己也被淘汰）$n=5$**：$a=[1,1,1,2,0]$。
`暴力`：$R_0=(1,1,1,2,0)$，$R_1=(1,1,2,0,1)$，$R_2=(1,2,0,1,1)$，$R_3=(2,0,1,1,1)$，$R_4=(0,1,1,1,2)$ ⟹ 最小 $R_4$ ⟹ `0 1 1 1 2`。
`算法`：$(0,1,0)$：$0$、$0$ 连等 ⟹ $k=2$；$a[2]-a[3]=1-2<0$ ⟹ $j=1+2+1=4$。此处淘汰区间 $[j,j+k]=[1,3]$，其中 $1+t\ (t\ge1)$ 的对手 $0+t$ 也落在被淘汰区里（$t=1$：$R_2>R_1$），但 $R_1>R_0$ 传递保证 $2$ 非最小 ✓ 与 2.4 的提醒一致。$k=0$；$(0,4,0)$：$a[0]-a[4]=1-0>0$ ⟹ $i=1\le j=4$ ⟹ $i=5\ge n$ 退出 ⟹ $m=\min(5,4)=4$ ✓。

**(8) 边界 $a$ 全相等 $n=5$**：$a=[4,4,4,4,4]$。`暴力`：五个 $R_p$ 全等于 $(4,4,4,4,4)$。`算法`：$i=0,j=1$ 一路 $t=0$ 到 $k=n$ 退出，$m=0$ ⟹ 输出 `4 4 4 4 4` ✓。

**(9) 手算对照（防止实现退化成"只比前几位就判定"）**：仍用 (10) 的 $a=[1,1,2,1,1,3]$：$R_0=(1,1,2,1,1,3)$ 与 $R_3=(1,1,3,1,1,2)$ 的**前 2 位完全相同**，胜负在第 3 位才出现（$2<3$）。任何"比固定 $L$ 位就打平、任意取一个"的做法（例如只按前 2 位分桶再取最小下标）都可能输出 $(1,1,3,1,1,2)$，错。本算法只在**真的失配**（引理 2 的 $k$ 位）或**比满 $n$ 位全等**（引理 4）时才下结论，所以不会误杀 ✓。

**(10) 一般 $n=6$，最优就是"不搬"**：$a=[1,1,2,1,1,3]$。
`暴力`（$a=[1,1,2,1,1,3]$，逐个写出 $R_p$）：$R_0=(1,1,2,1,1,3)$，$R_1=(1,2,1,1,3,1)$，$R_2=(2,1,1,3,1,1)$，$R_3=(1,1,3,1,1,2)$，$R_4=(1,3,1,1,2,1)$，$R_5=(3,1,1,2,1,1)$。以 $1,1$ 开头的只有 $R_0,R_3$，第 3 位 $2<3$ ⟹ 最小 $R_0$ ⟹ 输出 `1 1 2 1 1 3`（一次都不搬）。
`算法`：$(0,1,0)$：$a[0]-a[1]=0$ ⟹ $k=1$；$a[1]-a[2]=1-2<0$ ⟹ $j=1+1+1=3$；$(0,3,0)$：$a[0]-a[3]=0$、$a[1]-a[4]=0$ ⟹ $k=2$；$a[2]-a[5]=2-3<0$ ⟹ $j=3+2+1=6\ge n$ 退出 ⟹ $m=\min(0,6)=0$ ✓。此例说明答案完全可能是 $0$，算法不偏爱非零起点。

**(11) 绕回读取消元的观察**：在 (6) 里 $i=4,j=1$ 那段的比较依次读 $a[(4+k)\%6]$ 与 $a[(1+k)\%6]$，$k=2$ 时 $(4+k)=6\ge n$ 已经**绕回**读 $a[0]$。若在某个 $k$ 处失配，引理 2 要淘汰的就是余数段 $\{(4+\tau)\bmod 6:\tau\in[0,k]\}$，同样合法（证明只用模 $n$ 下标）；代码里写成 `%n` 正是为此。引理 3 的 (I2) 只要求"整数位置段 $[i,\min(i+k,n-1)]$ 被淘汰"，绕回出去的那部分是**额外**淘汰，不影响归纳。

## 5. 示例代码（C++）

```cpp
// P1368 工艺 —— 循环左移能得到的最小字典序移位 = 最小表示法
// https://www.luogu.com.cn/problem/P1368
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{300005};

int n,m;
int a[mxn];

int minrep()
{
	int i=0,j=1,k=0;
	while(i<n&&j<n&&k<n)
	{
		int t=a[(i+k)%n]-a[(j+k)%n];
		if(!t)
			++k;
		else
		{
			if(t>0)
			{
				i=i+k+1;             // [i,i+k] 全部淘汰（引理 2）
				if(i<=j)
					i=j+1;           // 保持 i!=j；被跳过的 [i+k+1,j) 早已淘汰
			}
			else
			{
				j=j+k+1;
				if(j<=i)
					j=i+1;
			}
			k=0;
		}
	}
	return min(i,j);                 // 引理 3 / 引理 4：就是最小起点
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];

	m=minrep();
	for(int i=0;i<n;++i)
		cout<<a[(m+i)%n]<<(i==n-1?'\n':' ');
	return 0;
}
```

### 代码说明

- **`n==1` 无需特判**：`j=1<n` 立即为假，循环不进，`min(0,1)=0`（验证 (1)）。
- **`k=n` 的终止条件**写成 `k<n`：一旦比满 $n$ 位说明两移位全等，直接取 `min(i,j)`（引理 4），不必再比。
- **`min(i,j)` 一定 $<n$**：若因 $k=n$ 退出，两指针都还 $<n$；若因 $i\ge n$（或 $j\ge n$）退出，本轮只动了这一个指针，另一个在上一轮守卫下仍 $\le n-1$，故它才是 $\min$。两种情况下 `m` 都是合法起点，输出循环里的 `(m+i)%n` 不会越界（`m` 本身也从不 $\ge n$ 地被使用）。
- **不用 `long long`**：见 4.2 的溢出预算。
- **全局数组零初始化够用**：只读入 $[0,n)$ 再只读 $[0,n)$ 与模 $n$ 的合法下标，没有"未写先读"的状态，因此**不需要 `fill_n`**；若是多组数据版本，必须在每组开始重置 `m` 与重读 $a$（本题单组，无此风险）。
- **备选写法（同复杂度、常数更小）**：把 $a$ 复制成 `b[2n]`（`b[i]=a[i%n]`）后比较 `b[i+k]` 与 `b[j+k]`，省掉 `%`，代价是多 $1.14\,\text{MiB}$；引理与算法完全不变。
