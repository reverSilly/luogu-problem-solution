# P1421 小玉买文具

> 标签：模拟 · 难度：入门

## 1. 重新读题

**问题重述（简化版）**

一支签字笔 $1$ 元 $9$ 角，班主任给小玉 $a$ 元 $b$ 角，只买这一种笔，问最多能买几支。
输入一行两个整数 $a,b$；输出一行一个整数（支数）。

**约束与暗示**

| 量 | 范围 |
|---|---|
| 元的部分 $a$ | $0\le a\le 10^4$ |
| 角的部分 $b$ | $0\le b\le 9$ |
| 总额（折成角）$T=10a+b$ | $0\le T\le 100009$ |

$T$ 只有 $10^5$ 量级：**没有溢出风险，也不需要任何数据结构或循环优化**。本题难点全在"单位换算"与"取整口径"两件事上。

**计数口径（必须先钉死）**

1. 笔按**整支**买卖，支数 $k$ 是非负整数，不存在"买半支"。
2. 输出只有支数：不输出找零、不输出"还剩几角"。
3. 钱是**上限**不是目标：允许有剩余（剩得不足 $19$ 角就再买不动），所以答案是"总价不超过 $T$ 的最大整数 $k$"，是**下取整**而非上取整。
4. **题面不含样例**：`P1421.md` 只有描述 / 输入格式 / 输出格式 / 数据范围，没有 Sample 一节。因此**无法与官方答案对标**，§4.4 的验证全部是自造算例 + 手算，不声称对拍。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制 —— "元 / 角"双单位是本题唯一的坑

题面把金额拆成两个单位：笔价 $1$ 元 $9$ 角，钱数 $a$ 元 $b$ 角。两个单位混着比较大小是没有定义的：$2$ 元 $0$ 角和 $1$ 元 $9$ 角谁大？必须先把双方**换算到同一单位**。

**引理 1（单位缩放的保序与保整除）**：对非负整数 $T$ 与正整数 $c$，以"角"计的能买支数 $\left\lfloor T/c\right\rfloor$ 与以"元"计 $\left\lfloor (T/10)/(c/10)\right\rfloor$ 相等。

**证明**：有理数域里 $(T/10)/(c/10)=T/c$（分子分母同除 $10$，$10\ne0$），两个被取整的对象是**同一个实数**，$\lfloor\cdot\rfloor$ 是实数上的函数，故结果相同。$\blacksquare$

> 结论：换算本身不改变答案，**改变答案的是"换没换全"**。既然缩放不影响结果，就挑让所有量都成为整数的那个单位——角。用"元"就必须引入小数，而小数在机器里是二进制浮点，见 §2.4。

**引理 2（总额折角公式）**：$a$ 元 $b$ 角 $=10a+b$ 角。

**证明**：按货币定义 $1$ 元 $=10$ 角，故 $a$ 元 $=10a$ 角（$a$ 个 $10$ 角相加）；再加上零头的 $b$ 角，总额为 $10a+b$ 角。又 $0\le b\le 9$ 保证"元/角"拆分与十进制写法一致（$b$ 恰好是 $T$ 除以 $10$ 的余数），换算可逆、不歧义。$\blacksquare$

笔价同理：$1$ 元 $9$ 角 $=10\times 1+9=19$ 角。于是**原问题里再没有第二个单位**。

### 2.2 化简 —— 从"买东西"到"解一个不等式"

设买 $k$ 支。买 $k$ 支花 $19k$ 角，"买得起"就是 $19k\le T$；"尽量多"就是取满足它的最大整数 $k$。

**引理 3（可行支数集是一个下闭区间）**：集合 $S=\{k\in\mathbb{Z}:k\ge 0,\ 19k\le T\}$ 等于 $\{0,1,\dots,\lfloor T/19\rfloor\}$，故 $\max S=\lfloor T/19\rfloor$。

**证明**：$19>0$，实数中同除正数保序，$19k\le T\iff k\le T/19$。整数 $k$ 与实数 $x$ 有 $k\le x\iff k\le\lfloor x\rfloor$：($\Leftarrow$) 由 $\lfloor x\rfloor\le x$ 传递；($\Rightarrow$) 反设 $k\ge\lfloor x\rfloor+1$，则 $k>x$（因 $x<\lfloor x\rfloor+1\le k$），与 $k\le x$ 矛盾。于是 $S=\{k\in\mathbb{Z}:0\le k\le\lfloor T/19\rfloor\}$。$T\ge0\Rightarrow\lfloor T/19\rfloor\ge0$，集合非空、上界有限，最大元即 $\lfloor T/19\rfloor$。$\blacksquare$

这步把"模拟购买过程"彻底退化成一个**下取整**，也就是一次整数除法。

### 2.3 关键论证 —— 一支一支买（贪心）与整除必然一致

"模拟"标签暗示的写法是 while 循环扣钱。**引理 4（带余除数的唯一性）**：$T=19q+r,\ 0\le r<19$ 的 $(q,r)$ 唯一。**证明**：设另有 $T=19q'+r'$，则 $19(q-q')=r'-r$；而 $-19<r'-r<19$，其中唯一的 $19$ 的倍数是 $0$，故 $q=q'$ 进而 $r=r'$。$\blacksquare$

**引理 5（贪心结果 = 整除结果）**：从 $r_0=T$ 开始，每轮"若当前余额 $\ge19$ 就买一支、余额减 $19$"，结束时买到的支数 $k=\lfloor T/19\rfloor$。

**证明**：循环不变量是 $T=19k_i+r_i$ 且 $r_i\ge0$（每轮 $k$ 加 $1$、$r$ 减 $19$，等式两边同变，成立）。循环停时 $r_i<19$，即 $T=19k_i+r_i,\ 0\le r_i<19$，由引理 4 与带余除法的标准表示唯一，$k_i=q=\lfloor T/19\rfloor$。终止性：$r$ 每轮严格减 $19$ 且不下穿 $-19$，至多 $\lceil T/19\rceil+1$ 轮。$\blacksquare$

> 于是两种写法**可证等价**，那我们就选不需要循环、不可能写错退出条件的那一个：`T/19`。

**关于取整方向**：机器整数除法对 $T\ge0$ 是"向零取整"，而向零取整 $=$ 下取整（非负数）。$T=10a+b\ge0$ 由引理 6 保证。

**引理 6（$T$ 非负）**：$0\le a\le10^4,\ 0\le b\le9\Rightarrow T=10a+b\ge0$。**证明**：两个非负数之和非负，$10a\ge0$（$10>0,a\ge0$）、$b\ge0$。$\blacksquare$ 这条看着废话，但它正是"不必担心负数除法向零/向下之别"的**唯一凭据**。

### 2.4 讨论其它做法与易错写法

- **浮点路线（不采用）**：`ans=(a+b/10.0)/1.9`。$0.1$、$1.9$ 在二进制下都不是精确值，商在真值整点附近可能落在整数下侧而被 `floor` 少算 $1$。我**未运行程序、不声称某组数据一定算错**；正确说法是：整数路线有引理 3/5 的完整证明，浮点路线要靠"逐值误差上界"额外论证，代价更高、收益为零，故淘汰。
- **单位换算漏乘（典型错解）**：写 `(a+b)/19`。手算反例 $a=2,b=0$：真值 $T=20$ 角，$20/19=1$ 支余 $1$ 角；错解给 $(2+0)/19=0$。两者相差 $1$，可判错。
- **上取整（另一个典型错解）**：`ceil(T/19)` 会把"买不起"也当成答案，$T=18$（$a=1,b=8$）时给 $1$，而实际 $19>18$ 买不动，应为 $0$。
- **二分答案**：判定谓词 $f(k):19k\le T$ 对 $k$ 单调不增，二分最大真值 $k$，$O(\log T)$。正确但完全多余，可作为引理 3 的第三种印证。

### 2.5 结论

答案就是 $ \left\lfloor (10a+b)/19\right\rfloor $，$O(1)$ 一行，全整数。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 找到题目唯一的特殊机制：金额被拆成"元 / 角"两个单位，混合比较无定义。
- **unit scaling** — 引理 1：缩放到同一单位不改变支数，挑让一切变整数的单位（角）。
- **reduce to easier problem** — 引理 2 + 引理 3：把"买尽量多"压成一次下取整 $k=\lfloor T/19\rfloor$。
- **prove greedy = formula** — 引理 4/5：带余除法唯一性证明"一支一支扣"与整除同解，从而放心删掉循环。
- **check rounding direction** — 引理 6：先证 $T\ge0$，才敢把"向零取整"当"下取整"用。
- **consider alternative techniques** — 浮点 / 二分 / 循环模拟三种对照，浮点因不可证被淘汰（§2.4）。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 来源 | 备注 |
|---|---|---|---|
| `a` | 钱的"元"部分 | `int`，输入 | $0\le a\le10^4$ |
| `b` | 钱的"角"部分 | `int`，输入 | $0\le b\le9$ |
| `c` | 笔价（角） | `constexpr int c{19}` | $1$ 元 $9$ 角 $=19$ 角 |
| `t` | 总额（角） | `int`，`t=a*10+b` | $0\le t\le100009$ |
| `ans` | 最多支数 | `int`，`ans=t/c` | $0\le ans\le5263$ |

### 4.2 算法步骤

1. 读入 $a,b$。
2. 折角：$t=10a+b$（引理 2）。
3. 整除：$ans=\lfloor t/19\rfloor$，即 `ans=t/c`（引理 3；引理 6 保证取整方向）。
4. 输出 `ans`，换行用 `'\n'`。

**复杂度**：时间 $O(1)$（$2$ 次读、$1$ 乘 $1$ 加 $1$ 除）；空间 $O(1)$，无数组。

### 4.3 溢出预算

| 量 | 上界 | 相对 `int` 上限 $2^{31}-1=2147483647$ |
|---|---|---|
| `a*10` | $100000$ | 余量 $\approx 2.1\times10^{4}$ 倍 |
| `t` | $100009$ | 余量 $\approx 2.1\times10^{4}$ 倍 |
| `c*ans`（隐式回代校验） | $100009$ | 同上 |
| `ans` | $5263$ | — |

计算式：$\max t=10\times10^4+9=100009$；$\max ans=\lfloor100009/19\rfloor=5263$（因 $19\times5263=99997\le100009<100016=19\times5264$）。全程最大中间量 $100009\ll2^{31}$，`int` 绝对安全，**不需要 `long long`，也不需要 `#define int long long`**。

### 4.4 验证状态（全部手算，未运行任何代码）

> 本环境无编译器：没有运行、没有对拍、没有得分与耗时数据。题面**无样例**，故**无法与官方答案对标**；以下每条都给出可复核的手算过程。

**边界组 1（全零）** $a=0,b=0$：$t=0$，$\lfloor0/19\rfloor=0$。含义：没钱，买 $0$ 支，且 $19\times0=0\le0$、$19\times1=19>0$，最大整数确为 $0$。

**边界组 2（只差 1 角，卡在门槛下）** $a=1,b=8$：$t=18$，$18<19\Rightarrow ans=0$；错解 `ceil` 会给 $1$，与"买不起"矛盾，说明下取整正确。

**边界组 3（恰好整除）** $a=1,b=9$：$t=19$，$19/19=1$ 余 $0$，$ans=1$。这是"整除点"，若走浮点路线最危险；整数除法在此精确。

**边界组 4（上界）** $a=10^4,b=9$：$t=100009$，$19\times5263=99997$、$100009-99997=12<19$，$19\times5264=100016>100009$，故 $ans=5263$。

**边界组 5（$b$ 满、$a$ 满但零头不同）** $a=10^4,b=0$：$t=100000$，$19\times5263=99997\le100000$、$100000-99997=3<19$，$ans=5263$——与组 4 同支数，多出的 $9$ 角不足以多买一支，验证"余数被丢弃"的口径。

**与贪心交叉验证（引理 5）** $a=3,b=7$：$t=37$。一支一支扣：$37\to18\to-1$（第二次扣不动，因 $18<19$），买 $1$ 支停；整除 $37/19=1$ 余 $18$。两法同为 $1$，且余数 $18$ 恰是贪心停手时的余额，符合不变量 $t=19k+r$。

**单调性自检**：$t$ 增 $1$ 时 $ans$ 只可能不变或增 $1$（$\lfloor(t+1)/19\rfloor-\lfloor t/19\rfloor\in\{0,1\}$），因此 $a$ 固定、$b$ 从 $0$ 到 $9$ 时答案最多变一次，与"零头不足一支"的直觉一致。

**结论**：口径（下取整、只输出支数）、单位换算（$10a+b$ 与 $19$）、取整方向（$t\ge0$）三处均有证明或手算支撑；因无官方样例，**对标状态为"未对标"**。

## 5. 示例代码（C++）

```cpp
// P1421 小玉买文具
// 统一到角：总额 t=10a+b，笔价 c=19 角，答案 = t/c（整数除法即下取整）
#include<bits/stdc++.h>
using namespace std;

constexpr int c{19};      // 1元9角 = 19角

int a,b;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b;
	int t=a*10+b;         // 折成角：0<=t<=100009（引理2、引理6）
	int ans=t/c;          // t>=0，向零取整 == 下取整（引理3）
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **全局标量状态**：`a,b` 放全局；本题没有任何按规模开表的量，故**不声明 `mxn`**（风格规范 §5：简单题允许省略命名常量 / 裸尺寸）。
- **无 INF、无 `fill_n`**：不存在"全局默认 0 被当成有效值"的移植陷阱，这里如实说明。
- **全整数**：`a*10+b` 最大 $100009$，`int` 余量两万倍（§4.3），无需 `using i64=long long;`。
- **`c` 用 `constexpr`**：把"1 元 9 角"这唯一业务常量钉在一处，避免 $19$ 散落。
- **`'\n'`、运算符两侧无空格、Tab 缩进、`cin.tie/cout.tie/sync` 顺序固定**，符合规范 §10/§15。
