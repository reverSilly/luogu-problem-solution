# P1077 [NOIP 2012 普及组] 摆花 —— 完整题解

---

## 1. 重新读题

有 $n$ 种花（$1\le n\le 100$），要在门口摆一排共 $m$ 盆（$1\le m\le 100$）。第 $i$ 种花最多用 $a_i$ 盆（$0\le a_i\le 100$）。约束：

1. **同种花必须摆在一起**，形成连续的一段；
2. **不同种类的花必须按标号从小到大排列**，即第 1 种花的段在最左边，然后是第 2 种，……，第 $n$ 种在最右边。

求有多少种不同的摆花方案，结果对 $10^6+7$ 取模。

---

## 2. 思考链——带完整证明

### 2.1 模型转换

约束 1 和 2 联合起来意味着：一旦决定了每种花用多少盆，整个序列就被唯一确定了——只需要把第 $1$ 种的 $x_1$ 盆放在最左边，接着第 $2$ 种的 $x_2$ 盆，……，第 $n$ 种的 $x_n$ 盆放在最右边。

因此问题等价于：**求非负整数解 $(x_1,x_2,\dots,x_n)$ 的个数**，满足

$$
x_1+x_2+\cdots+x_n = m,\qquad 0\le x_i\le a_i.
$$

这是一个**带上限的整数拆分 / 有界组合计数**问题。

### 2.2 朴素 DP（无优化版本）

设 $dp[i][j]$ 表示只用前 $i$ 种花、总共 $j$ 盆的方案数。

考虑第 $i$ 种花取 $k$ 盆（$0\le k\le\min(a_i,j)$），则前 $i-1$ 种花的盆数为 $j-k$，由加法原理：

$$
dp[i][j] = \sum_{k=0}^{\min(a_i, j)} dp[i-1][j-k].
$$

边界：$dp[0][0]=1$（0 种花、0 盆，一种方案），$dp[0][j>0]=0$。

复杂度 $O(n\cdot m\cdot \max a_i) = O(100^3) = 10^6$，已经能过本题。但我们仍可以优化到 $O(nm)$。

### 2.3 前缀和优化

观察转移式：$dp[i][j]$ 是 $dp[i-1][j],dp[i-1][j-1],\dots,dp[i-1][j-a_i]$ 这 $a_i+1$ 个（或更少，若 $j<a_i$）值的和。

定义前缀和

$$
S[i-1][j] = \sum_{t=0}^{j} dp[i-1][t],
$$

则有

$$
dp[i][j] =
\begin{cases}
S[i-1][j], & j\le a_i,\\[4pt]
S[i-1][j] - S[i-1][j-a_i-1], & j > a_i.
\end{cases}
$$

证明：当 $j\le a_i$ 时，求和下界为 0，上界为 $j$，就是 $S[i-1][j]$ 的定义。当 $j>a_i$ 时，求和从 $t=j-a_i$ 到 $t=j$，即 $S[i-1][j] - S[i-1][j-a_i-1]$。

这样每层 $i$ 只需 $O(m)$ 计算前缀和、$O(m)$ 计算新 dp，总时间 $O(nm)=10^4$。

### 2.4 空间优化

注意到 $dp[i]$ 只依赖 $dp[i-1]$，可以滚动数组为 1D。用 `dp[j]` 表示当前层的 $j$ 盆方案数，每层从前一层的值计算。

### 2.5 正确性证明概要

- **可行性**：每个 $x_i$ 满足 $0\le x_i\le a_i$ 且总和为 $m$，对应一种合法的实物摆列，反之任何合法的摆列唯一对应一组这样的 $x_i$。双射成立。
- **最优子结构**：$dp[i][j]$ 的转移只依赖于 $dp[i-1][j-k]$，即去掉第 $i$ 种花后的子问题，无后效性。
- **答案**：$dp[n][m]$。

### 2.6 模运算

模数 $10^6+7$ 不是 `1e9+7` 而是 `1000007`。减法结果可能为负，需加模数再取模。

## 3. 模式总结

| 特征 | 模式 |
|------|------|
| 物品有上限，求凑出指定总量的方案数 | **有界背包 / 有界整数拆分** |
| 物品顺序固定、同类连续 | 转化为**组合计数**，忽略排列细节 |
| 每个物品的贡献是一个区间和 | **前缀和优化 DP**，去掉内层枚举 |
| $n,m\le 100$，$a_i\le 100$ | 朴素 $O(nm\max a_i)$ 也能过，但前缀和 $O(nm)$ 更优 |
| 模数 $10^6+7$ | 注意不是 $10^9+7$，减法取模要补正 |

**识别标志**："若干类物品，每类有数量上限，选出总和为定值，同类不可分隔、顺序固定" $\to$ 直接转为组合数问题 $\to$ 背包 DP 或生成函数。

## 4. 真正的解法——附带符号表

### 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 花的种类数 |
| $m$ | 需要摆放的总盆数 |
| $a_i$ | 第 $i$ 种花的最大可用盆数 |
| $dp[j]$ | 当前已考虑若干种花后，凑出 $j$ 盆的方案数 |
| $pref[j]$ | 当前 $dp$ 数组的前缀和，$\displaystyle\sum_{t=0}^{j} dp[t]$ |
| $\bmod$ | $10^6+7$ |

### 算法流程

1. 读入 $n,m$ 和 $a[0..n-1]$。
2. 初始化 $dp[0]=1$，其余为 $0$。
3. 对每种花 $i$：
   - 计算 $dp$ 的前缀和 `pref[0..m]`。
   - 新建临时数组 $ndp$，对每个 $j\in[0,m]$：
     $$
     ndp[j] \gets \bigl(pref[j] - (j>a_i ? pref[j-a_i-1] : 0)\bigr) \bmod{10^6+7}.
     $$
   - 将 $ndp$ 复制回 $dp$。
4. 输出 $dp[m]$。

### 边界处理

- $dp[0]=1$：0 种花、0 盆是合法的空方案。
- $j-a_i-1<0$ 时，不减任何值。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};
constexpr int mod{1000007};
int a[mxn], dp[mxn], pref[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n, m;
	cin >> n >> m;
	for (int i = 0; i < n; ++i)
	{
		cin >> a[i];
	}

	dp[0] = 1;	// 空方案

	for (int i = 0; i < n; ++i)
	{
		// 计算前缀和
		pref[0] = dp[0];
		for (int j = 1; j <= m; ++j)
		{
			pref[j] = (pref[j - 1] + dp[j]) % mod;
		}

		int ndp[mxn] = {0};
		for (int j = 0; j <= m; ++j)
		{
			ndp[j] = pref[j];
			if (j - a[i] - 1 >= 0)
			{
				ndp[j] = (ndp[j] - pref[j - a[i] - 1] + mod) % mod;
			}
		}

		memcpy(dp, ndp, sizeof(dp));
	}

	cout << dp[m] << '\n';
}
```

---

**复杂度**：时间 $O(nm)$，空间 $O(m)$。对于 $n,m\le 100$ 绰绰有余。
