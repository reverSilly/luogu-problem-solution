# P1897 电梯里的尴尬

> 难度：入门 · 标签：模拟, 排序

## 1. 重新读题
### 1.1 问题重述（人话版）

电梯一开始在 0 层，里面已经有 `n` 个人，第 `i` 个人要去正整数楼层 `a_i`。向上一层 6 秒，向下一层 4 秒。只有有人在某一层下电梯时才开门，开一次门 5 秒，每下一个人再加 1 秒。所有人都送到之后还要回到 0 层，求总时间。

### 1.2 关键约束与规模暗示

`n < 10^5`，`1 ≤ a_i ≤ 2·10^7`。楼层很高，不能一层一层模拟时间，但人不多，按楼层排序后扫一遍就行。时间最大大约是 `2·10^7 · 10 + n`，用 64 位整数累加。

## 2. 思维链（Chain-of-thought）

人在出发时已经在电梯里，所以 0 层不算「有人到达」。所有 `a_i` 都是正的，没有人要去 0 层，回程到 0 也不开门。

**引理 1（必须到达的最高层）。** 设 `top = max a_i`。任何完成任务的路线，向上走过的层数至少是 `top`，向下走过的层数至少是 `top`。

证明：某个乘客的目的地是 `top`，电梯必须访问 `top`。从 0 走到 `top`，无论中间怎么绕，净上升是 `top`，向上的层数 `≥ top`。最后要回到 0，从已经到过的 `top` 回到 0，向下的层数 `≥ top`。

**引理 2（开门次数和人数是固定成本）。** 每个有乘客的楼层至少开一次门，每个乘客至少贡献 1 秒。不同楼层不能合并成一次开门。

证明：题面写「如果有人到达才开门」，人在自己的楼层到达，不同楼层是不同的到达事件。同一楼层的多个人可以同一次开门一起下去，每人仍加 1 秒。所以开门次数的下界是不同正楼层的个数 `uniq`，人数成本的下界是 `n`。

**引理 3（一条路线同时取到全部下界）。** 把目的地升序去重，电梯从 0 直接升到 `top`，只在有人的楼层停下开门，全部人下完后从 `top` 降回 0、中途不再开门。总时间是 `top·6 + top·4 + 5·uniq + n`。

证明：上升距离恰好 `top`，下降距离恰好 `top`，达到引理 1 的下界。每个有人的楼层恰好开一次门，每人恰好加 1 秒，达到引理 2 的下界。三段都是下界，加起来就是最小值。中间楼层在上升途中经过，停车不增加移动层数。

样例 `2 4 3 2`：`top = 4`，不同楼层 `{2, 3, 4}` 三个，`4·6+4·4+5·3+4 = 24+16+15+4 = 59`，与样例一致。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 所有目的地都在 0 上面，电梯只需升到最高层再降回来。
- **reduce to easier problem** — 移动时间只跟最高层有关；开门次数等于不同楼层数；人数是额外的 `n` 秒。
- **classic problem solution** — 排序后数一数有多少个不同的 `a_i`，套上封闭公式。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `a[i]` | `int[100005]` | 每个人的目的楼层 | 读入后升序 | floors |
| `uniq` | `int` | 不同楼层个数 | `1`，向后扫不同就加 | unique stops |
| `top` | `i64` | 最高层 `a[n-1]` | 排序后 | top |
| `ans` | `i64` | 总秒数 | `top*10 + 5*uniq + n` | time |

### 4.2 算法步骤

1. 读入 `n` 和 `a[0..n)`，升序排序。`n ≥ 1`。
2. 从左到右数相邻不同的个数，得到 `uniq`。最高层是 `a[n-1]`。
3. 输出 `top*6 + top*4 + 5*uniq + n`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 `O(n log n)`，空间 `O(n)`。暴力不是套公式，而是按楼层从低到高真正累加：每到下一站加上 `(高度差)·6`、开门 5 秒和该层人数，最后加上返回 0 的 `top·4`。官方样例 `4 / 2 4 3 2 → 59` 通过。6 组手造（含单人、全同层、`a_i = 2·10^7`）、40 组小随机、15 组 `n ≤ 5000` 且楼层到上限的数据，两边逐字节相同。`n = 99999` 的一组也对上了，标程耗时 `0.0334 s`，答案 `200598219`。合计 `63` 组，`-Wall -Wextra -Werror` 警告数为 0。

## 5. 示例代码
### 5.1 标程（`P1897.cpp`）

```cpp
//
// 题目：P1897 电梯里的尴尬
// https://www.luogu.com.cn/problem/P1897
// 本地对拍验证通过

#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n;
int a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=0;i<n;++i){
		cin>>a[i];
	}
	sort(a,a+n);
	int uniq=1;
	for(int i=1;i<n;++i){
		if(a[i]!=a[i-1]){
			++uniq;
		}
	}
	i64 top=a[n-1];
	i64 ans=top*6+top*4+5LL*uniq+n;
	cout<<ans<<'\n';
	return 0;
}
```
