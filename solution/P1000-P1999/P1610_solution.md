# P1610 鸿山洞的灯

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

洞里有 $n$ 盏灯，位置 $p_i$ 互不相同。规则是：

> 若第 $i-1$ 盏与第 $i+1$ 盏的距离 $\le dist$，就可以关掉第 $i$ 盏。

也就是"两盏亮灯之间距离足够近时，夹在中间那盏可以关"。**离洞口最近与最远的两盏灯必须保持亮着**。
求最多能关掉多少盏。

### 输入输出格式

- **输入格式**：第一行 $n,dist$；第二行 $n$ 个互不相同的整数位置 $p_i$。
- **输出格式**：一行一个整数，最多能关掉的灯数。
- **数据规模**：$n\le10^5$，$dist$ 在 `int` 范围内；位置未给范围（可能为负）。

### 关键约束分析

1. 位置**没有说明已经有序**，必须自己排序——规则里说的"第 $i-1$ 盏"应理解为位置上相邻的那盏灯。
2. $n\le10^5$：$\mathcal{O}(n\log n)$ 排序 + $\mathcal{O}(n)$ 扫描是正解规模；$\mathcal{O}(n^2)$ 的"反复找可关的灯"会超时。
3. 位置可以是负数，前后两灯的差值要用 `long long` 存，避免 $p_{i+1}-p_i$ 在极端值下溢出。
4. 首尾两盏不能关：这既是题面要求，也避免了"关掉端点后边界怎么算"的讨论。
5. 关灯是**连锁**的：关掉一盏之后，它左右两盏亮灯会变成相邻关系，后续判断要用"当前最近的亮灯"，不是原始下标。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：把"关灯"翻译成"保留哪些灯"

关灯是动态过程，直接模拟"每一步关哪盏"会遇到"顺序不同结果不同"的麻烦。
换个角度：最终决定的是一个**保留集合** $S$，$0\in S$、$n-1\in S$（排序后下标），其余灯关掉。只要 $S$ 合法，关灯顺序总能安排出来。

那么 $S$ 合法的充要条件是什么？

**引理 1（可行性判据）**：$S$ 可行，当且仅当对 $S$ 中任意两个**相邻**元素 $a<b$ 满足：
$$b=a+1\quad\text{或}\quad p_b-p_a\le dist .$$

*证明*：
**必要性**：设 $a<b$ 是 $S$ 中相邻元素且 $b>a+1$，即中间有灯被关掉。考虑其中**最后一个**被关掉的灯 $x$。它被关掉的那一刻，$a$ 与 $x$ 之间、$x$ 与 $b$ 之间的灯都已经关完（$x$ 是最后一个，所以中间其余灯都不亮），于是 $x$ 当前左右相邻的亮灯恰好是 $a$ 与 $b$。按规则必须 $p_b-p_a\le dist$。

**充分性**：若所有相邻保留灯都满足上述条件，则把每个"区间" $(a,b)$ 内的灯按任意顺序逐个关掉。任取某一步要关的灯 $x\in(a,b)$，此刻它左右相邻的亮灯都落在 $[a,b]$ 内（因为 $(a,b)$ 内只有更少的灯还亮着），两者距离不超过 $p_b-p_a\le dist$，故这一步合法。全部关完即得到 $S$。$\square$

于是问题变成：**在"首尾必留"的约束下，选最少的保留灯，使相邻保留灯的间隔（有空隙时）不超过 $dist$。**

### 第二步：贪心——每次都跳到最远的可达灯

从左往右决定。设上一盏保留的灯是 $L$。为了让保留的灯尽量少，下一盏保留的灯应该取得**尽可能远**：只要下一盏候选灯 $j$ 满足 $p_j\le p_L+dist$，就可以把 $L$ 与 $j$ 之间的灯全关掉。取到最远的那个 $j$，再以它为新的 $L$ 继续。

这就是"区间覆盖/跳跃游戏"式的贪心。它的最优性：

**引理 2（贪心支配性）**：设贪心的保留灯下标依次为 $g_0=0<g_1<\dots<g_{|G|-1}=n-1$，任一可行保留集合的下标依次为 $s_0=0<s_1<\dots<s_{|S|-1}=n-1$。则对每个同时满足 $i<|G|$、$i<|S|$ 的 $i$，有 $g_i\ge s_i$。

*证明*：对 $i$ 归纳。$g_0=s_0=0$。
设 $g_i\ge s_i$，且 $i+1<|G|$、$i+1<|S|$。看 $s_{i+1}$：
- 若 $s_{i+1}=s_i+1$：贪心每步至少前进 $1$，故 $g_{i+1}\ge g_i+1\ge s_i+1=s_{i+1}$。
- 若 $s_{i+1}>s_i+1$：由引理 1 的必要性部分，$p_{s_{i+1}}-p_{s_i}\le dist$；又 $p_{s_i}\le p_{g_i}$（位置随下标递增），故 $p_{s_{i+1}}\le p_{g_i}+dist$，即 $s_{i+1}$ 是"相对 $g_i$ 可达"的候选。贪心取的 $g_{i+1}$ 是所有满足 $p_j\le p_{g_i}+dist$ 的最大下标（若这个最大下标已经是 $n-1$，贪心就停在那里，此时 $g_{i+1}=n-1\ge s_{i+1}$），所以 $g_{i+1}\ge s_{i+1}$。

归纳成立。$\square$

**定理**：贪心关掉的灯数最多。

*证明*：反设存在可行 $S$ 使 $|S|<|G|$。取 $i=|S|-1$，它满足 $i<|S|$ 与 $i<|G|$，由引理 2 得 $g_{|S|-1}\ge s_{|S|-1}=n-1$，故 $g_{|S|-1}=n-1$。由于下标严格递增、$n-1$ 已是最大下标，这说明贪心的第 $|S|-1$ 个（也就是最后一个）元素就是 $n-1$，即 $|G|=|S|$，矛盾。故对所有可行 $S$ 都有 $|G|\le|S|$，即贪心保留的最少、关掉的最多。$\square$

### 第三步：把贪心写成一行循环

维护"上一盏保留的灯" `lst`，从 $i=1$ 扫到 $n-2$：

- 若 `p[i+1]-p[lst] <= dist`：$i$ 可以关（关掉后 `lst` 与 `i+1` 仍满足条件），答案加一，`lst` 不变；
- 否则：$i$ 不能关（关掉它就会让 `lst` 与 `i+1` 的距离超过 $dist$），令 `lst=i`。

因为 $i+1$ 最多是 $n-1$（最后一盏，永远保留），循环到 $n-2$ 恰好不越界。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 关灯顺序无关紧要，最终只看"保留集合"，而集合的合法性只取决于相邻保留灯的距离。
- `consider easier version` — 去掉"连锁"因素后，这就是"用最少的点、间隔不超过 $dist$ 地跨过整条线段"的经典跳跃问题。
- `classic problem solution` — 从左往右贪心，每次跳到 $p_L+dist$ 以内最远的那盏灯，用交换/支配论证证明最优。
- `exchange argument` — 用"贪心第 $i$ 个保留灯的位置 $\ge$ 任意可行解第 $i$ 个"的支配性，直接推出保留数最少。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $n$ | `n` | 灯的数量 |
| $dist$ | `dist` | 安全距离阈值（`i64`，防止差值溢出） |
| $p_i$ | `p[i]` | 排序后的灯位置（`i64`） |
| $L$ | `lst` | 上一盏**保留下来的**灯的下标，初值 $0$ |
| 答案 | `ans` | 已关掉的灯数，初值 $0$ |
| $i$ | `i` | 当前尝试关掉的灯，范围 $[1,n-2]$ |

### 算法步骤

1. 读入 $n,dist$ 与所有 $p_i$，对 $p$ 升序排序。
2. 令 `lst=0`、`ans=0`。
3. 对 $i=1,2,\dots,n-2$：若 `p[i+1]-p[lst]<=dist`，则 `++ans`（关掉 $i$，`lst` 不动）；否则 `lst=i`（保留 $i$）。
4. 输出 `ans`。

### 复杂度分析

- **时间复杂度**：排序 $\mathcal{O}(n\log n)$，扫描 $\mathcal{O}(n)$，总计 $\mathcal{O}(n\log n)$。
- **空间复杂度**：$\mathcal{O}(n)$ 存位置。

### 正确性验证

- 引理 1 把动态关灯过程等价为静态集合条件，必要性用"最后一个被关掉的灯"论证，充分性给出显式关灯顺序。
- 引理 2 与定理给出贪心的最优性：贪心保留的灯在"第 $i$ 个"意义下总是最靠右，因此保留总数最少。
- 边界：$n=1,2$ 时循环不执行，答案 $0$（首尾必亮，无灯可关）；位置为负或差值很大时，差值在 `i64` 中计算，不会溢出。
- 首尾灯从不被写入 `lst` 以外的删除计数：循环只覆盖 $[1,n-2]$，即首尾永远保留。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1610 鸿山洞的灯
// https://www.luogu.com.cn/problem/P1610
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};                 // n<=1e5

int n,ans,lst;                             // lst: 上一盏保留下来的灯
i64 dist,p[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>dist;
	for(int i=0;i<n;++i)
		cin>>p[i];
	sort(p,p+n);

	for(int i=1;i<n-1;++i)                 // 第一盏与最后一盏必须亮
		if(p[i+1]-p[lst]<=dist)            // 关掉 i 后 lst 与 i+1 仍然够近
			++ans;
		else
			lst=i;                         // 关不掉, i 成为新的"最近亮灯"
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **忘记排序**：输入位置无序，不排序直接按输入下标套规则必错。
2. **用原始下标判断**：关掉若干灯后，"第 $i-1$ 盏"应是**当前最近的亮灯**（即 `lst`），而不是 `i-1`。用 `p[i+1]-p[i-1]<=dist` 会把"中间灯已被关掉、实际间距已超限"的情形误判为可关。
3. **把首尾关掉**：循环范围必须严格是 $[1,n-2]$。
4. **`p[i+1]-p[lst]` 用 `int`**：位置范围未给，极端值下差值可能溢出 `int`，统一 `i64`。
5. **答案为 $n$ 或 $n-1$**：至少首尾两盏必须留，答案上界是 $n-2$。
