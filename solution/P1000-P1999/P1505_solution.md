# P1505 [国家集训队] 旅游

> 标签：线段树 / 树链剖分 / 集训队互测 · 难度：NOI/NOI+

## 1. 重新读题

**问题重述（结构版）**

给一棵 $n$ 个点的**无根树**（题面说"任意两点间有且只有一条路径"，即 $n-1$ 条边的连通无环图），**边**带权 $w\in[-1000,1000]$（全程保证）。要求在线支持 5 种操作，每次操作要么改权、要么在一条简单路径上问统计量。

把五种操作按"改 / 问"分类，语义差别其实很大：

| 操作 | 参数 | 作用对象 | 语义 | 是否可逆 |
|---|---|---|---|---|
| `C i w` | 边序号 $i$，新权 $w$ | **单条边** | 赋值为 $w$（不是加、不是异或） | 需要旧值才能撤销 |
| `N u v` | 两端点 | $u\to v$ 路径上的**所有边** | 每条边权取相反数 | 自身即逆（做两次等于没做） |
| `SUM u v` | 两端点 | 路径上的边 | 求和 | — |
| `MAX u v` | 两端点 | 路径上的边 | 最大值 | — |
| `MIN u v` | 两端点 | 路径上的边 | 最小值 | — |

三个统计量恰好对应线段树节点里要存的三样东西；`N` 是**区间变换**，`C` 是**单点赋值**——所以本题不是"树剖模板 + 单点改"，而是"树剖 + 带懒标记的线段树"，难点全在 `N` 与 `MAX/MIN` 的相容性上。

**约束**

| 项 | 范围 |
|---|---|
| $n,m$ | 均 $\le 2\times10^5$ |
| 任一时刻边权 | $[-1000,1000]$（整数） |
| 点的编号 | $0\sim n-1$（题面明写） |
| 询问输出 | 一行一个整数 |

**编号约定与题面的一处歧义**

题面明确说了"点的编号为 $0\sim n-1$"，但对 `C i w` 的 $i$ 只写了"输入的第 $i$ 条边"。中文"第 $i$ 条"是序数词，按输入顺序从第 1 条数起，$n-1$ 条边对应 $i\in[1,n-1]$；点从 0 编号是题面**特意**声明的例外，没有理由把边也当成 0 基。因此本文按**边号 1 基**实现（读入循环 `for(int i=1;i<n;++i)`）。这是本地题面无法验证的点之一，在 §4 的"验证状态"里列为缺口；若真评测是 0 基，只需把 `eu/ev` 数组的下标整体平移，不影响任何思路。

**"路径上的边"这个措辞值得多想一拍**

树剖线段树的标准做法是维护**点**的序列，而这里问的是**边**。边不能直接进 `dfn` 序——`dfn` 是给点编号的。所以第一步必须回答"边权放在哪个点身上"，这决定了后面所有区间端点的开闭。见 §2.1。

**值域先算一遍（决定用 int 还是 long long）**

路径最多 $n-1=199999$ 条边，每条 $|w|\le 1000$，故 $|\text{SUM}|\le 199999000<2^{31}-1=2147483647$。余量约 7%，`int` 够用；`MAX/MIN` 更是 $[-1000,1000]$。所以本文全程 `int`，并且取 $inf=10^9>2\times10^8$，保证哨兵一定在所有真实值之外。

**样例情况**

**本地题面（`P1505.md`）没有给出任何输入输出样例**，只有数据范围与三条"加 hack 数据"的记录。因此本文**无法与官方答案对标**，所有验证只能靠手算：§4 给出 3 组自造数据 + 完整轨迹 + 期望值，并在 §2 各处用具体小数据反例卡住错误思路。

## 2. 思维链（Chain-of-thought）

### 2.1 边权怎么放进按点编号的数组

先把树**强制 rooted**：任选一个点当根，本文取编号最小的点 $0$。根选哪个不影响任何答案，因为路径与路径上的边权和、最值都跟"谁是根"无关；选根只是为了给边定向。

**引理 1（定向的唯一性）** 以 $0$ 为根后，每条边恰好连接一对父子：对边 $e=(u,v)$，必有 $fa[u]=v$ 或 $fa[v]=u$，且此时 $\lvert dep[u]-dep[v]\rvert=1$，"较深的端点"唯一确定。

**证明**：$u,v$ 相邻，故从根到 $v$ 的路径要么经过 $u$（此时 $fa[v]=u$，$dep[v]=dep[u]+1$），要么不经过 $u$（此时从根到 $u$ 的路径必经过 $v$——否则把边 $(u,v)$ 拼到两条根路径上会得到一条从根出发、既到 $u$ 又到 $v$ 而不经过对方的走法，与"树上两点路径唯一"矛盾；严格地说，树中删去 $e$ 分成两个连通块，含根的那一块的边界端点就是父端）。两种情形对称，故恰有一端更深，深度差为 1。$\blacksquare$

于是把边权"记在较深端点身上"：$\mathrm{wt}[x]=w(fa[x],x)$，根自己 $\mathrm{wt}[0]$ 无定义（本文填 $0$，并且下文会证明它永远不参与运算）。

**引理 2（边集与点集的双射）** 固定路径 $P(u,v)$，设 $a=\mathrm{LCA}(u,v)$。则映射 $e\in P(u,v)\map$ 该边的深端点是 $P(u,v)$ 上除 $a$ 以外所有点的集合 $\mathrm{Vert}(P(u,v))\setminus\{a\}$ 的双射。

**证明**：
- **满射**：取 $x\in \mathrm{Vert}(P(u,v)),x\ne a$。$x$ 在路径上且不是最近公共祖先，故 $x$ 在 $a$ 的下方（属于 $a\to u$ 或 $a\to v$ 两段中除去 $a$ 的部分），于是 $fa[x]$ 也在这条路径上且更靠近 $a$，边 $(fa[x],x)$ 就是 $P(u,v)$ 上以 $x$ 为深端的那条边。
- **单射**：每条边的深端点唯一（引理 1），不同边的深端点不同（一个点只有一个父边）。
- **不是满射的那一个点**：$a$ 自身对应的边是 $(fa[a],a)$，它在路径**外**（$fa[a]$ 在 $a$ 上方，不在 $u\to v 的路径上；$a=0$ 时该边根本不存在）。所以 $a$ 必须被排除。
- **两边条数核对**：$|P(u,v)|=dep[u]+dep[v]-2dep[a]$ 条边，$\mathrm{Vert}(P(u,v))$ 有 $dep[u]+dep[v]-2dep[a]+1$ 个点，去掉 $a$ 正好相等。$\blacksquare$

**反例（挂错端点会怎样）**：如果把边权"挂在较浅端点"，则路径 $P(u,v)$ 对应的是 $\mathrm{Vert}\setminus\{v$ 或 $u$ 中更深者$\}$，需要额外判断谁更深才能开对区间，`N` 操作时同样麻烦；更糟的是若**两个端点都挂**（有些同学为了省事），同一条边会被算两次：$n=3$，边 $0\!-\!1$ 权 $5$，$1\!-\!2$ 权 $7$，`SUM 0 2` 会得 $5+5+7=17$（真值 $12$）。单端点挂载 + 排除 LCA 是唯一干净的做法。

由此得到本题**区间端点的规则**：路径 $P(u,v)$ 对应 $\texttt{dfn}$ 上若干**闭区间之并再挖掉** $\texttt{dfn}[a]$。挖洞很麻烦，所以工程上改成"链内查 $[\texttt{dfn}[\text{浅}]+1,\ \texttt{dfn}[\text{深}]]$"，洞自然就不在了。这需要一点论证，见 §2.2。

### 2.2 哪个位置永远不该被碰

要把一条重链当成一段连续区间，先得证明它真的连续。

**引理 3（链的 dfn 连续性）** 设 $x$ 是某条重链的链头，则 $x$ 的链上的点在 `dfn` 序中恰成区间 $[\texttt{dfn}[x],\ \texttt{dfn}[x]+len)$，其中 $len$ 是链长；并且链上从 $x$ 向下的第 $k$ 个点 $y$ 满足 $\texttt{dfn}[y]=\texttt{dfn}[x]+k$。

**证明**：`dfs3` 的写法是"访问 $x$ → 立刻递归重儿子 → 最后统一处理轻儿子"。对链 $x=s_0,s_1,\dots,s_{len-1}$（$s_{i+1}=gs[s_i]$）归纳：处理 $s_i$ 时先给它分配当前时间戳，然后**唯一**的下一次 `dfs3` 调用就是 $s_{i+1}$（重儿子优先，轻儿子被推迟到函数末尾），所以 $\texttt{dfn}[s_{i+1}]=\texttt{dfn}[s_i]+1$。归纳到 $i=len-1$：$gs[s_{len-1}]=-1$，函数直接返回，之后才轮到轻儿子，各自形成新的链，都排在 $\texttt{dfn}[s_{len-1}]+1$ 之后。故链恰好占据连续的一段。$\blacksquare$

**引理 4（LCA 位置不被任何操作触碰）** 对 `walk` 产生的每一个半开区间 $[L,R)$，都有 $L\ge \texttt{dfn}[a]+1$，其中 $a=\mathrm{LCA}(u,v)$；特别地，区间不含 $\texttt{dfn}[a]$，也不含根的 $\texttt{dfn}[0]=0$。

**证明**：分两类区间。

1. **主循环里跳链产生的** $[\texttt{dfn}[top[x]],\ \texttt{dfn}[x]+1)$。`walk` 每次先比较 $dep[top[u]]$ 与 $dep[top[v]]$，只有"链头更深"的那一侧会被处理。断言：被处理时 $top[x]$ 必在 $a$ 的**严格下方**。反设 $top[x]$ 不在 $a$ 下方，即 $top[x]$ 是 $a$ 或 $a$ 的祖先，则链 $top[x]$ 同时经过 $a$；由于 $a$ 在 $u,v$ 到根的路径上，$x$ 那一支从 $a$ 出发是往 $u$ 或往 $v$ 走的，不妨设 $x=u$。此时 $v$ 与 $u$ 不同链（主循环条件 $top[u]\ne top[v]$），而 $a$ 在 $u$ 的链上，所以 $v$ 必在 $a$ 的某条**轻儿子**子树里（若在重儿子里就同链了），于是 $top[v]$ 是 $a$ 的真后代，$dep[top[v]]>dep[a]\ge dep[top[u]]$，`walk` 会交换 $u,v$ 并处理 $v$ 侧——矛盾。故反设不成立。既然整条被处理的链都在 $a$ 下方，$top[x]\ne a$ 且 $\texttt{dfn}[top[x]]>\texttt{dfn}[a]$（同链的点 $dfn$ 随深度单调增，这是引理 3 的直接推论；而 $top[x]$ 与 $a$ 不同链，$\texttt{dfn}[top[x]]$ 是某条链的起点且该链整体在 $a$ 子树内，必然落在 $\texttt{dfn}[a]+1$ 之后，因为 $a$ 的子树在 `dfn` 上也是一个包含 $a$ 之后所有后代时间的区间——先序性质）。
2. **收尾的同链区间** $[\texttt{dfn}[a]+1,\ \texttt{dfn}[\text{深者}]+1)$：左端点已经把 $a$ 挖掉了。若 $u=v$（$a=u=v$）则 $\texttt{dfn}[a]+1>\texttt{dfn}[a]$ 使条件 `dfn[u]+1<=dfn[v]` 为假，直接不产生区间。

取两类并集，$L\ge \texttt{dfn}[a]+1$ 成立。根的 $\texttt{dfn}$ 是 $0$（`dfs3(0,0)` 的第一个时间戳），若某区间含 $0$ 则 $L=0$，从而 $0\ge \texttt{dfn}[a]+1$，即 $\texttt{dfn}[a]\le -1$，不可能。$\blacksquare$

这条引理是**本题不被 hack 的关键**：它意味着 $\texttt{dfn}[a]$ 位置上存的值（可能是任意陈旧数、也可能是哨兵）永远不会被 `N` 翻转、也不会被 `SUM/MAX/MIN` 读出。所以我们可以放心地把根的 $wt$ 填 $0$，甚至不用管它。很多题解在这里用"把 $wt[a]$ 临时设成 $0/\pm inf$ 再恢复"的技巧，那是**多此一举且危险**的，§2.5 给出它被 hack 的具体过程。

另外注意：`N u v` 与 `SUM/MAX/MIN u v` 走的是**同一个** `walk`，所以"翻转不越界"和"查询不越界"是同一个证明，不需要单独论证第二遍。

### 2.3 取负之后 max 与 min 发生了什么

现在问题彻底退化成一维序列问题：数组 $A[0..n-1]$，支持区间取负、单点赋值、区间问 $\mathrm{sum},\mathrm{mx},\mathrm{mn}$。先看区间取负对这三个量的影响。

**引理 5（对偶性）** 设 $S=\{x_1,\dots,x_k\}$ 是非空多重集，$-S=\{-x:x\in S\}$。则
$$\sum(-S)=-\sum(S),\qquad \max(-S)=-\min(S),\qquad \min(-S)=-\max(S).$$

**证明**：第一条是分配律 $\sum_i(-x_i)=-\sum_i x_i$，有限归纳即可。第二条：令 $m=\min(S)$，则 $\forall i,\ x_i\ge m\Rightarrow -x_i\le -m$，故 $-m$ 是 $-S$ 的上界；又 $m\in S$（非空有限集必取到最值），对应的 $-m\in -S$ 达到该上界，故 $\max(-S)=-m=-\min(S)$。第三条把 $S$ 换成 $-S$（注意 $-(-S)=S$）即得 $\min(-S)=-\max(S)$。$\blacksquare$

**这条引理的实操含义**：`MAX` 与 `MIN` **不能各自独立维护**，它们是同一枚硬币的两面。线段树节点里 $mx$ 和 $mn$ 必须成对出现，翻转时同时更新：

```cpp
tr[i].mx=-tr[i].mx;  tr[i].mn=-tr[i].mn;  swap(tr[i].mx,tr[i].mn);
```

（先各自变号再交换，等价于 $\text{新}mx=-\text{旧}mn,\ \text{新}mn=-\text{旧}mx$。）

**反例 1（只存 mx）**：$A=[2,5]$，`N` 整段后真值 $A=[-2,-5]$，$\max=-2$。只存 $mx=5$ 的写法会算出 $-5$，错。要得到 $-2$ 就必须知道旧的 $\min=2$。

**反例 2（空集）**：引理 5 的前提是 $S$ 非空。若 $S=\varnothing$，约定 $\max=-\infty,\min=+\infty$，取负后按"$\max\leftarrow-\min$"会变成 $-(+\infty)=-\infty\to$ 再交换得 $+\infty$，恒等元被翻转破坏了——它不再代表空集。所以要么给节点带一个 `len` 字段并规定 `len==0` 时 `neg` 直接返回，要么保证空段永远不会被 `neg`。本文两处都做了：`node` 带 `len`，`add` 用 `len` 短路，`neg` 入口判 `!tr[i].len`。

**顺带**：为什么 $\mathrm{sum}$ 用线段树而不是树状数组？因为树上还要 `MAX/MIN`，而 $\max$ 对"区间取负"这个变换**没有可逆的差分结构**（`N` 之后再问 `MAX`，BIT 的前缀-差分框架完全帮不上忙），干脆三种统计量都用线段树统一处理，代码只写一棵树。

### 2.4 翻转能不能延迟

`N u v` 最坏覆盖整条链（$O(n)$ 条边），逐条改会 TLE（$m=2\times10^5$，$O(nm)=4\times10^{10}$）。必须懒。但懒标记能用的前提是"这个变换可以攒着不立即下传"。

**引理 6（对合性与交换群）** 记 $\sigma(x)=-x$。则 $\sigma\circ\sigma=\mathrm{id}$；并且 $\sigma$ 与"取和、取最大、取最小"这三个统计量的作用方式**只依赖 $\sigma$ 出现的次数的奇偶性**。形式地，对任意节点存储的三元组 $T=(\sum,\max,\min)$，定义
$$\hat\sigma(T)=(-\sum,\ -\min,\ -\max).$$
则 $\hat\sigma\circ\hat\sigma=\mathrm{id}$，且对任意区间 $I$，把 $I$ 内所有元素做 $k$ 次 $\sigma$ 后的三元组等于 $\hat\sigma^{\,k\bmod 2}(T_I)$。

**证明**：$\hat\sigma^2(\sum)=--\sum=\sum$；$\hat\sigma^2(\max)$：第一次 $\max\mapsto-\min$，第二次 $\mapsto-\;(-$旧的 $\max)=\max$（注意第二次作用时"旧的 $\min$"就是第一次产出的 $\max$ 分量……写清楚：设 $T=(s,p,q)$ 其中 $p=\max,q=\min$，$\hat\sigma(T)=(-s,-q,-p)$，再作用一次得 $(-(-s),-(-p),-(-q))=(s,p,q)$）。故对合。区间情形由引理 5 逐条应用：每作用一次 $\sigma$，新集合的 max 是旧 min 的相反数、新 min 是旧 max 的相反数，这正是 $\hat\sigma$ 的定义；对合性使 $k$ 次作用只由 $k\bmod 2$ 决定。$\blacksquare$

**于是懒标记可以只存一个 bool**（`flip`），而不是"乘 $-1$ 的幂次"或"加法偏移"。`neg(i)` 干两件事：立刻用 $\hat\sigma$ 改写本节点的三元组（保证**任何时刻**被查询的节点值都是当前真值），再把 `flip` 异或一次（欠孩子的账）。异或而非累加，正是引理 6 的推论。

**引理 7（懒标记不变式）** 任意时刻，对线段树的每个节点 $i$：$tr[i].sum/mx/mn$ 是"把 $i$ 管辖的整段叶子、按从根到 $i$ 路径上所有**未下传**的 `flip` 都作用完之后"的真实三元组；$tr[i].flip$ 表示"我的两个孩子还欠一次翻转"。

**证明**（对每次操作归纳）：建树时 `flip` 全 false 且值即原值，成立。`neg(i)` 只在两种情况下调用：(a) `cover` 命中"区间完全覆盖节点"，此时该节点管辖的所有叶子确实都要翻转一次，改写三元组正确，同时给尚未同步的孩子记账 `flip^=1`，不变式保持；(b) `push_down(i)` 中对孩子调用，此时把 $i$ 的欠款转嫁给两个孩子并清账，$i$ 自身的三元组不变（它早已是含账的真值），孩子的三元组按 $\hat\sigma$ 更新，两个孩子各自再欠一层，不变式保持。`push_up(i)` 在 $push_down$ 之后执行，此时 $i$ 的两个孩子的三元组都是真值（它们的欠款只往更深处，不影响本层聚合，因为求和/最值只依赖本层的存储值而本层存储值已含所有本层以上的作用），故 $i$ 的三元组也是真值。`rlet` 沿路径先 `push_down` 再改叶子最后 `push_up`，同上。`calc` 只做 `push_down` 不改值，不变式显然保持。$\blacksquare$

**反例（`C` 之前不 `push_down` 会怎样）** ——这是 2020.11.26 那组 hack 针对的典型错误。用 §4 用例 3 的数据：链 $0-1-2-3$，权 $1,2,3$，`dfn` 依次为 $0,1,2,3$，$A=[0,1,2,3]$。线段树（$[0,4)$ 为根）中 $[2,4)$ 是一个内部节点，两个叶子是 $[2,3)$ 与 $[3,4)$。

1. `N 1 3`：区间 $[2,4)$ **正好完全覆盖**内部节点 $[2,4)$，于是 `neg` 打在这个节点上：它的 $sum:5\to-5$，$mx:3\to-2$，$mn:2\to-3$，`flip=true`。**两个孩子存的仍是 $A[2]=2,\ A[3]=3$（陈旧）**。
2. `C 2 -9`：把边 2（点 $1,2$ 的边）设成 $-9$。错误写法不 `push_down` 就直接冲到叶子 $[2,3)$ 写 $-9$，然后 `push_up` 节点 $[2,4)$：$sum=-9+3=-6$，$mx=3$，$mn=-9$，**但它的 `flip` 还是 true**。
3. `MAX 0 3`：查询区间 $[1,4)$ 会把 $[2,4)$ 整段返回，拿到 $mx=3$（这一段**真实**的最大值应是 $-3$，因为边 3 的当前权是 $-3$）。于是整条查询输出 $3$，而真值是 $\max(1,-9,-3)=1$。错。

正确写法第 2 步先 `push_down([2,4))`：把两个孩子改成 $-2,-3$ 并各自 `flip=true`，节点 `flip` 清零；再覆盖叶子为 $-9$（覆盖即"当前值变成 $-9$，与之前的翻转历史无关"，同时把叶子的 `flip` 置 false）；`push_up` 得 $sum=-12,mx=-3,mn=-9$。第 3 步返回 $mx=\max(A[1]=1,\dots)=1$，与真值一致。

**叶子的 `flip` 位是垃圾吗？** 是的，但无害：叶子没有孩子，`push_down` 只在 `r-l!=1` 时被调用，所以叶子的 `flip` 永远不会被读取；`rlet` 覆盖叶子时顺手置 false 只是为了状态干净。写成 `tr[i]={v,v,v,1,false}` 一并解决。

### 2.5 为什么不能用哨兵占位

有一种看起来很省事的写法：反正 `walk` 的收尾区间容易把 $a$ 的位置带进来，那就给 $a$（尤其给根）的 $wt$ 填"恒等元"：`SUM` 需要 $0$、`MAX` 需要 $-\infty$、`MIN` 需要 $+\infty$，这样带上它也不影响结果。**这个写法在本题是错的**，因为本题有 `N`：恒等元对 $\sigma$ 不封闭。

**具体反例（小数据，可手算）**：$n=3$，边 $1:0\!-\!1$ 权 $5$，边 $2:1\!-\!2$ 权 $7$。以 $0$ 为根，$wt=[\underbrace{-114514}_{\text{根的 }MAX\text{ 哨兵}},5,7]$，`dfn` 为 $0,1,2$（一条重链）。

- `N 0 2`：若收尾区间写成 $[\texttt{dfn}[0],\texttt{dfn}[2]+1)=[0,3)$（忘了挖 $a$），则整段被 `neg`：$[-114514,5,7]\to[114514,-5,-7]$，且 max/min 互换后该段存的是 $mx=114514,\ mn=-5$。
- `MAX 0 1`：真实答案应为 $-5$（唯一的边 $0\!-\!1$ 现在权 $-5$）。哨兵写法返回 $114514$。**WA**。

根因：$\sigma(-\infty)=+\infty$，"什么都不影响"的占位值被 `N` 变成了"影响一切"的值。同理用 $0$ 占 `MAX` 的位也不行——$0$ 会盖掉全负路径的真实最大值：$wt=[*,\,-5]$（$n=2$，边权 $-5$），`MAX 0 1` 真值 $-5$，若把根的 $0$ 混进区间就输出 $0$。

**结论**：唯一安全的做法是从源头保证哨兵位置**根本不进区间**（引理 4），而不是指望它数值上无害。本文的 `walk` 用 `dfn[u]+1` 作左端点、并用 `dfn[u]+1<=dfn[v]` 处理空路径，正是引理 4 的实现；查询用的恒等元 $\{0,-inf,+inf,len=0\}$ 只在 `calc` 的"不相交"分支出现，它从不会被 `neg` 作用（`neg` 只作用于树上的真实节点），并且 `add` 先按 `len` 短路，连数值比较都不做，双保险。

**另一个常见坑（与哨兵无关但同源）**：把 `C i w` 理解为"第 $i$ 条边加 $w$"或"按输入顺序找第 $i$ 条**当前还存在**的边"。题面写的是"将输入的第 $i$ 条边权值**改为** $w$"，是绝对赋值，且"输入的第 $i$ 条"指静态输入序列的第 $i$ 行，与树的形态、与之前是否被 `N` 翻过都无关。所以实现里只需在 `eu[i],ev[i]` 里查端点、再取较深者做单点赋值；**不需要**维护一份"当前边权数组"（`N` 之后那份数组就会陈旧，反而引入 bug 风险）。

### 2.6 路径要拆成多少段

`walk` 的循环每轮处理一条链然后 $x\leftarrow fa[top[x]]$（跨过一条**轻边**）。段数决定单次操作的复杂度。

**引理 8（轻边数上界）** 从任意点到根的路径上，轻边（$e=(u,v)$，$v$ 是 $u$ 的非重儿子）至多 $\lfloor\log_2 n\rfloor$ 条。

**证明**：设 $v$ 是 $u$ 的轻儿子。由 $gs[u]$ 的定义，$sz[gs[u]]\ge sz[v]$（我们取"第一个最大值"当重儿子，并列时另一支仍满足 $\le$）。于是
$$sz[u]\ \ge\ 1+sz[gs[u]]+sz[v]\ \ge\ 1+2\,sz[v]\ >\ 2\,sz[v],$$
即跨过这条轻边往下走，子树规模**至少减半**；反过来，从下往上每跨一条轻边，所在子树规模严格翻倍以上。根的子树规模是 $n$，起点规模 $\ge 1$，故跨过的轻边数 $t$ 满足 $2^t\le n$，$t\le\log_2 n$。$\blacksquare$

**推论**：$u\to v$ 的路径被拆成的链段数 $\le 2(\log_2 n+1)$（两侧各到 LCA 一次）。$n\le2\times10^5$ 时 $\log_2 n<18$，段数上限约 $38$，实践中远小于此（$O(\log n)$ 只是最坏情形，平衡树上平均 $O(\log\log n)$ 级别）。每段在线段树上做一次 $O(\log n)$ 的区间操作，故**单次操作 $O(\log^2 n)$**。

**为什么用 $dep[top[\cdot]]$ 比较而不是 $dep[\cdot]$**：`walk` 必须每次挑"链头更深"的那一侧上跳，才能保证跳完的那条链整条都在 LCA 下方（引理 4 的第 1 类论证正好依赖这一点）。若改成比较 $dep[u],dep[v]$，会出现"当前处理的链跨过了 LCA"的情形，区间就要额外挖洞，回到 §2.5 的坑。

### 2.7 三个"边角情况"先想清楚再写代码

**(a) $u=v$ 的空路径。** 题面只说"询问 $u,v$ 节点之间边权最大值"，$u=v$ 时路径上**没有边**，`MAX/MIN` 在数学上无定义（空集的最值）。本地题面没有规定这种输入是否出现、该输出什么。本文的处理：`walk` 对 $u=v$ 不产生任何区间，`res.len==0`，`SUM` 输出 $0$（唯一合理值），`MAX/MIN` 也输出 $0$（只是"不崩、且与和一致"的约定）。这一条列进 §4 的缺口清单。

**(b) $n=1$ 的退化树。** 没有边，`dfs1(0,-1)` 只访问根，`gs[0]=-1`，`dfn[0]=0`；`ini(0,1,0)` 直接走 `r-l==1` 分支，不碰 `ls/rs`，无越界。任何询问都是 (a)。

**(c) 递归深度。** `dfs1/dfs3` 是纯递归，链状树（hack 数据很可能有）深度 $\Theta(n)=2\times10^5$。线段树的 `ini/cover/calc/rlet` 深度只有 $\lceil\log_2 n\rceil\le18$，不构成风险。树遍历若要更稳，可把 `dfs1` 改成显式栈两趟（先序算 `dep/fa/wt`，逆序累加 `sz/gs`），`dfs3` 也能展平；本文保持风格指南里"递归 + `fa` 参数"的写法，把风险与改法都在 §5 标注，**没有实测过是否真的会爆栈**（本次任务禁止编译运行）。

## 3. 模式总结（Pattern Summary）

### 模式 A：树上路径操作 $\Rightarrow$ 区间操作（重链剖分降维）

| 要素 | 本题的落点 |
|---|---|
| 降维工具 | `dfs1`（`sz/gs/dep/fa`）+ `dfs3`（`dfn/top`） |
| 关键不变式 | 一条重链 = `dfn` 上一段**连续**区间（引理 3） |
| 段数 | $O(\log n)$（引理 8，靠"$sz[fa]>2\,sz[轻儿子]$"） |
| 代价 | 单次操作 $O(\log^2 n)$，$m=2\times10^5$ 时约 $6\times10^7$ 次基本运算量级 |

**适用信号**：题目同时出现"路径上的统计量"和"修改"，且统计量**不可差分**（最值、带条件的计数、平方和等）→ 树剖 + 线段树。若只有"路径求和 + 子树求和 + 单点改"，树上差分 / LCA 前缀就够；若还要"换根、动态连边"，才升到 LCT。

### 模式 B：区间取负 + 区间最值 = 对偶量互换 + 0/1 懒标记

$$\text{节点状态}=(\mathrm{sum},\mathrm{mx},\mathrm{mn}),\qquad \hat\sigma:(s,p,q)\mapsto(-s,-q,-p),\qquad \text{tag}\in\{0,1\}\ (\text{异或合并})$$

这是"区间取负"家族的核心一句话：**$\mathrm{mx}$ 和 $\mathrm{mn}$ 必须同时存**，因为它们在 $\sigma$ 下互相转化（引理 5）。同一形状还覆盖这些变形：

| 变换 | 需要成对维护的量 | 标记类型 |
|---|---|---|
| 区间取负 | `mx ↔ mn` 互换后变号，`sum` 变号 | 0/1 异或（对合） |
| 区间加 $v$ | `sum += len·v`，`mx += v`，`mn += v` | 加法累积 |
| 区间赋值 | 三者全置为常量 | 覆盖（优先级最高） |
| 区间翻转（序列倒置） | `lmx/rmx` 互换（若维护"最大前缀/后缀"则更多） | 0/1 异或 |

**判据**：一个变换能懒下去 $\iff$ 它作用在**聚合值**上时，聚合值的新表达式只依赖旧聚合值（不需要逐元素信息）。取负对 `(sum,mx,mn)` 满足，对"第二大值"这类统计量就不满足。

### 模式 C：恒等元要带"参与元素个数"，别指望哨兵数值

- 只要懒标记会把"占位值"也变换（$\sigma(-\infty)=+\infty$），哨兵法就会崩（§2.5 反例）。
- 稳妥写法：节点里存 `len`，`add` 先按 `len==0` 短路，`neg` 入口拒绝 `len==0`。**空/非空是类型信息，不是数值信息**，不该用数值大小来编码。
- 更稳的做法是从区间端点上排除干扰位（引理 4），本文两条都做了。

### 迁移练习与对照

## 4. 真实解法

**一句话**：以 $0$ 为根做重链剖分，把每条边的权挂到它的**较深端点**上，于是"路径上的边"变成 `dfn` 上 $O(\log n)$ 段连续区间；再用一棵维护 $(\mathrm{sum},\mathrm{mx},\mathrm{mn})$ 三元组、带 $0/1$ 翻转懒标记的线段树处理区间取负与三类询问，`C` 是单点赋值（务必先 `push_down`）。

### 4.1 符号表

| 记号 | 类型 / 定义域 | 含义 | 由谁写入 |
|---|---|---|---|
| $n,m$ | $\le 2\times10^5$ | 点数、操作数 | `main` 读入 |
| `eu[i],ev[i]` | $i\in[1,n-1]$ | 输入第 $i$ 条边的两个端点（原样保存，不定向） | 读入循环 |
| `graph[x]` | `Edge{v,w,id}` 列表 | 邻接表，两个方向各存一次，`id` 是输入边号 | 读入循环 |
| $fa[x]$ | $[0,n)$，$fa[0]=-1$ | 以 $0$ 为根的父节点 | `dfs1` |
| $dep[x]$ | $[0,n)$ | 深度，$dep[0]=0$ | `dfs1` |
| $sz[x]$ | 正整数 | 子树大小 | `dfs1` |
| $gs[x]$ | 子节点或 $-1$ | 重儿子（$sz$ 最大者，并列取先遇到者） | `dfs1` |
| $wt[x]$ | $[-1000,1000]$ | **点 $x$ 的权 = 边 $(fa[x],x)$ 的权**；$wt[0]$ 无意义，填 $0$ | `dfs1` |
| $top[x]$ | 点编号 | 所在重链的链头 | `dfs3` |
| $dfn[x]$ | $[0,n)$ | 剖分后的序号（先序，重儿子优先） | `dfs3` |
| $rev[p]$ | $[0,n)$ | $dfn$ 的反函数，`rev[dfn[x]]=x` | `dfs3` |
| $A[p]$ | 隐含数组 $=wt[rev[p]]$ | 线段树维护的序列 | `ini` |
| $a$ （文中） | 点 | $\mathrm{LCA}(u,v)$ | — |
| `tr[i]` | $i\in[0,4n)$ | 线段树节点 `{sum,mx,mn,len,flip}` | `ini/push_up/neg` |
| `tr[i].len` | $[0,\text{段长}]$ | 该节点管辖的**叶子个数**（真实节点恒 $\ge1$；查询恒等元取 $0$） | `ini/push_up/add` |
| `tr[i].flip` | bool | 欠孩子一次翻转（引理 7） | `neg/push_down` |
| `inf` | $10^9$ | 哨兵幅度，$>2\times10^8\ge$ 任何真实 `sum`，也 $>1000\ge$ 任何真实 `mx/mn` | 常量 |
| $ls(i),rs(i)$ | $2i{+}1,2i{+}2$ | 儿子下标，根为 $0$ | 内联函数 |

区间一律**半开** $[L,R)$，与风格指南的 `sth` 模板一致。

### 4.2 编号步骤

**S1 读入与建图**：读 $n$；对 $i=1..n-1$ 读 $u,v,w$，存 `eu[i]=u,ev[i]=v`，双向 `push_back({v,w,i})` / `({u,w,i})`。点号已经是 $0$ 基，**不做 `--`**。

**S2 `dfs1(0,-1)`**：定 `fa/dep/sz/gs`，同时把边权交给深端 `wt[v]=w`。

**S3 `dfs3(0,0)`**：`top`/`dfn`/`rev`，重儿子优先递归（引理 3 由此成立）。

**S4 `ini(0,n,0)`**：按 `A[p]=wt[rev[p]]` 建线段树；叶节点 `{v,v,v,1,false}`，内部节点 `push_up`。$O(n)$。

**S5 主循环，按 `op[0]` 分派**：

- **S5a `C i w`**：$x\leftarrow$ `eu[i],ev[i]` 中 $dep$ 较大者（引理 1 保证唯一且恰是深端）；`rlet(0,n,0,dfn[x],w)`。`rlet` 每层先 `push_down` 再下降，回来 `push_up`（§2.4 反例要求的正是这一条）。$O(\log n)$。
- **S5b `N u v`**：`walk(u,v, cover)`。
- **S5c `SUM/MAX/MIN u v`**：`walk(u,v, calc+add)` 得聚合三元组 `res`；若 `res.len==0` 输出 $0$（§2.7(a)）；否则按 `op[1]` 是 `'U'/'A'/'I'` 分别输出 `res.sum/res.mx/res.mn`。

**S6 `walk(u,v,f)`（`N` 与三种询问共用，见 §3 自查清单第 4 条）**：

1. 当 $top[u]\ne top[v]$：若 $dep[top[u]]<dep[top[v]]$ 交换 $u,v$；调用 $f(\texttt{dfn}[top[u]],\ \texttt{dfn}[u]+1)$；令 $u\leftarrow fa[top[u]]$。
2. 同链后：若 $\texttt{dfn}[u]>\texttt{dfn}[v]$ 交换（使 $u$ 为浅者 $=a$）；若 $\texttt{dfn}[u]+1\le\texttt{dfn}[v]$ 调用 $f(\texttt{dfn}[u]+1,\ \texttt{dfn}[v]+1)$。

**S7 输出**：每个询问一行，用 `'\n'` 不用 `endl`。

### 4.3 正确性

按"降维 → 区间树 → 指令语义"三层各证一次。

**定理 1（降维保真）** 对任意 $u,v$，`walk(u,v,f)` 调用 $f$ 产生的半开区间族 $\{[L_k,R_k)\}$ 满足：把每个区间翻译成点集 $\bigcup_k\{rev[p]:p\in[L_k,R_k)\}$，该点集恰为路径 $P(u,v)$ 上所有边的**深端点集合**，且各区间互不相交、每个区间内所有点同属一条重链。

**证明**：
- *同链性*：主循环里传入的是 $[\texttt{dfn}[top[x]],\texttt{dfn}[x]]$ 这一段，两端点都在 $x$ 所在链上且 $\texttt{dfn}[top[x]]\le\texttt{dfn}[x]$；由引理 3，链的 `dfn` 连续且随深度递增，故这段区间里的每个 `rev` 都是链上从 $top[x]$ 到 $x$ 的点，同链。收尾的 $[\texttt{dfn}[u]+1,\texttt{dfn}[v]]$ 同理（$u,v$ 同链）。
- *不重*：主循环每轮把 $x$ 换成 $fa[top[x]]$，即跳到刚处理过的链头的父节点，之后 $x$ 及其所在链与刚处理的链**点不相交**（链是划分）。循环结束时 $u,v$ 同链，且两侧都已经走到"包含 $a$ 的那条链"上，收尾区间 $[\texttt{dfn}[a]+1,\texttt{dfn}[\text{深者}]]$ 只覆盖 $a$ 下方那段，与之前主循环处理过的段互不相交（那些段的链头都在 $a$ 下方且属于另一条链，因为一条链上的点 $dfn$ 连续且 $a$ 所在链的 $dfn$ 段包含 $\texttt{dfn}[a]$，其他链的 $dfn$ 段与之不相交）。
- *不漏*：$P(u,v)$ 被 $a$ 分成 $a\to u$ 与 $a\to v$ 两段。看 $a\to u$：`walk` 中每次处理"链头更深的一侧"，$u$ 侧的指针沿 $fa[top[\cdot]]$ 上跳，每次跳掉的正是"当前 $u$ 到其链头"这段路径（这段完全在 $P(u,v)$ 上，因为链头是 $u$ 的祖先且不超过 $a$——引理 4 第 1 类论证已证链头严格在 $a$ 下方）。当 $u$ 侧指针第一次落到 $a$ 所在链时，剩余未覆盖的部分恰是 $a$ 到该点的链内段，由收尾区间覆盖。$v$ 侧对称。
- *不多*：由引理 4，所有 $L_k\ge\texttt{dfn}[a]+1$，故 $a$ 自身（对应路径外的边 $(fa[a],a)$）不在并集中；同理根的 $dfn$ 位置 $0$ 不在任何区间内。$\blacksquare$

**定理 2（线段树保真）** 任意时刻，对每条边 $e$，其深端点 $x$ 满足 $wt[x]$ 等于 $e$ 的**当前**权值，且线段树中"只含 $x$ 的叶子"在把祖先欠款结算完后其 $\mathrm{sum}=\mathrm{mx}=\mathrm{mn}$ 等于 $wt[x]$；进而 `calc(0,n,0,L,R)` 返回的三元组等于 $\{A[L..R-1]\}$ 三者的真实统计量。

**证明**：对操作种类归纳。`ini` 显然成立。`cover`：只在"L/R 完全包住节点区间"时改写，改写方式 $\hat\sigma$ 由引理 5 保证对新集合成立，引理 6 保证多次翻转只依赖奇偶、可用 `flip` 异或累积；引理 7 保证"节点存的永远是含全部上层作用后的真值"，故 `calc` 整段返回时直接抄三元组是合法的。`rlet`：沿路 `push_down` 把欠款结算到孩子（引理 7 的 (b) 情形），叶子被赋成 $v$ 并清 `flip`，即"当前值 $=v$"，符合 `C` 的赋值语义；随后逐层 `push_up` 用真值孩子重算真值父亲。`calc` 自身只 `push_down` 不改值，返回前用 `add` 合并：`add` 对 `len==0` 短路，避免 §2.3 反例 2 的空集翻车；`len>0` 时两边都是真实区间，$\mathrm{sum}$ 可加、$\max/\min$ 可取二元最值，故合并正确。三种情况下 $wt$ 与逻辑权值始终同步（`C` 直接改写、`N` 通过线段树的 $\hat\sigma$ 改写，二者都不依赖任何"当前边权副本"数组）。$\blacksquare$

**定理 3（指令语义）** 每个操作分支的输出/副作用与题面一致。

**证明**：
- `C i w`：$i$ 是输入边号（1 基），`eu[i]/ev[i]` 是该边原始终点；由引理 1 深端点是 $dep$ 较大者，`rlet` 在 $\texttt{dfn}[x]$ 上绝对赋值 $w$，即"把输入第 $i$ 条边权改为 $w$"。定理 2 保证之后的询问看到新值。
- `N u v`：`walk` + `cover` 把路径上每条边的深端点位置各翻转一次，且不碰路径外位置（定理 1 的"不多"），即"路径上的边权取相反数"。
- `SUM/MAX/MIN u v`：由定理 1，被查询的叶子集合恰是路径的边集合；由定理 2，`res` 的三分量分别是该集合的和、最大、最小；`res.len` 是边数，故 `len==0` 当且仅当 $u=v$（路径无边），此时按 §2.7(a) 输出 $0$。$op[1]$ 区分 `SUM`('U')、`MAX`('A')、`MIN`('I')，三者互异且与 `C`/`N`（长度 1，走前两支）不冲突。$\blacksquare$

### 4.4 复杂度

| 阶段 | 时间 | 依据 |
|---|---|---|
| 建图 / `dfs1` / `dfs3` / `ini` | $O(n)$ | 每点、每条边常数次访问 |
| `C` | $O(\log n)$ | 一条根到叶的 `rlet` 路径，长 $\lceil\log_2 n\rceil+1$ |
| `N` / `SUM` / `MAX` / `MIN` | $O(\log^2 n)$ | 链段数 $O(\log n)$（引理 8）$\times$ 每段线段树 $O(\log n)$ |
| 总体 | $O(n+m\log^2 n)$ | 代入 $n,m\le2\times10^5$、$\log_2 n<18$：上界约 $m\cdot 38\cdot 18\approx1.4\times10^8$ 次"节点访问"量级，平均远低于此 |
| 空间 | $O(n)$ | `tr` 用 $4n$ 个 `node`，每节点 $4$ 个 `int` + $1$ 个 `bool`（$20$ B）≈ $16$ MB；$n$ 个 `vector` 及其 $2(n-1)$ 个 `Edge` ≈ $10$ MB |

`flip` 折进 `len` 的符号位可以省下一截内存与缓存行，但收益在本规模下无关紧要，本文取可读性。另外：$O(\log^2 n)$ 里外层是"最坏 $2\log n$ 段"，链状树只有 1 段，星形树每个叶子各自一条链但每条链只有 1 个点，两种极端下单次操作都接近 $O(\log n)$；真正逼近 $\log^2$ 的是"每层都有一条轻边"的平衡树。

**用例 3（4 点链：`N` 停在内部节点后接 `C`，检查 `push_down`；含脏 `flip` 叶子）**

输入 `4 / 0 1 1 / 1 2 2 / 2 3 3 / 15 / N 1 3 / C 2 -9 / SUM 0 3 / MAX 0 3 / MIN 0 3 / N 0 3 / SUM 0 3 / MAX 0 3 / MIN 0 3 / C 3 5 / SUM 0 3 / MIN 0 3 / SUM 1 2 / N 3 3 / MAX 0 3`。
剖分：整棵树只有一条重链，`dfn=[0,1,2,3]`，$A=[0,1,2,3]$。线段树节点：$[0,4)$ 为根，孩子 $[0,2)$ 与 $[2,4)$，叶子各自一个点。

手算轨迹：
1. `N 1 3` → 区间 $[2,4)$ **正好整段盖住**内部节点 $[2,4)$：`neg` 只打在该节点上（$sum:5\to-5$，$mx:3\to-2$，$mn:2\to-3$，`flip=true`），两个孩子 $[2,3),[3,4)$ 存的仍是 $2,3$（**陈旧**）。逻辑权值 $e_1=1,e_2=-2,e_3=-3$。
2. `C 2 -9` → `rlet` 到节点 $[2,4)$ 前必 `push_down`：孩子变 $-2,-3$ 且各自 `flip=true`，父 `flip=false`；再覆盖叶子 $[2,3)$ 为 $-9$ 且 `flip=false`。回卷 `push_up`：$[2,4)$ 得 $sum=-12,mx=-3,mn=-9$。逻辑 $e_1=1,e_2=-9,e_3=-3$。
3. `SUM 0 3` → 区间 $[1,4)$：$[1,2)$ 单点返回 $1$，$[2,4)$ 整段返回 $sum=-12$ → $1-12=-11$ ✓（$1-9-3=-11$）。
4. `MAX 0 3` → 区间 $[1,4)$：$[1,2)$ 的 $mx=1$、$[2,4)$ 的 $mx=-3$，合并取 $\max=1$ ✓（真值 $\max(1,-9,-3)=1$）。**若第 2 步漏掉 `push_down`，这里会返回 $3$**（§2.4 反例）。
5. `MIN 0 3` → $\min(1,-9)=-9$ ✓。
6. `N 0 3` → 区间 $[1,4)$：$[1,2)$ 叶子翻成 $-1$（`flip=true`），$[2,4)$ 整段翻：$sum:-12\to12$，$mx:-3\to$ 先 $3$ 再与 $mn$ 交换 $\to mx=9,mn=3$，`flip=true`。逻辑 $e_1=-1,e_2=9,e_3=3$。$[0,2)$ 的 $mx$ 因含根的 $0$ 而变成 $0$——**但它永远不会被整段返回**（引理 4），下一步可见。
7. `SUM 0 3` → $[1,2)$ 递归到叶子取 $-1$（绕开了 $[0,2)$ 里那个脏 $mx$），加 $[2,4)$ 的 $12$ → $11$ ✓（$-1+9+3=11$）。
8. `MAX 0 3` → $\max(-1,9)=9$ ✓；9. `MIN 0 3` → $\min(-1,3)=-1$ ✓。
10. `C 3 5` → 边 3 是 $(2,3)$，深端点 $3$，$\texttt{dfn}[3]=3$；`rlet` 到 $[2,4)$ 时先 `push_down`：叶子 $[2,3)$ 由 $-9$ 变 $9$（`flip` 置 true）、叶子 $[3,4)$ 由 $-3$ 变 $3$（`flip` 由 true 异或回 false），父 `flip=false`；再覆盖 $[3,4)$ 为 $5$。`push_up` 得 $[2,4)$ 的 $sum=14,mx=9,mn=5$。逻辑 $e_1=-1,e_2=9,e_3=5$ ✓（`C` 是绝对赋值，与历史翻转无关）。
11. `SUM 0 3` → $-1+9+5=13$ ✓；12. `MIN 0 3` → $-1$ ✓。
13. `SUM 1 2` → 区间 $[2,3)$ → 取叶子 $[2,3)$：存的 $9$（它的 `flip=true` 是永远不会被读的垃圾位，值本身已是真值）→ $9$ ✓（引理 7）。
14. `N 3 3` → $u=v$，不产生任何区间（`walk` 的 `dfn[u]+1<=dfn[v]` 判空），线段树不变。
15. `MAX 0 3` → 仍 $9$ ✓（证明 $u=v$ 的 `N` 没有误翻整棵树）。

期望输出：`-11 1 -9 11 9 -1 13 -1 9 9`。

**尚未验证的部分**：(i) 未经编译与运行，语法层面按风格指南手写，可能存在笔误；(ii) `C i w` 中边号的基（1 基 vs 0 基）无法本地确认；(iii) $u=v$ 时 `MAX/MIN` 应输出什么，题面未定义；(iv) 递归 `dfs1/dfs3` 在 $2\times10^5$ 链上的栈占用没有实测。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{200005};
constexpr int inf{1e9};

struct Edge{int v,w,id;};
vector<Edge>graph[mxn];
int n,m,eu[mxn],ev[mxn];
int dep[mxn],fa[mxn],sz[mxn],gs[mxn],top[mxn],dfn[mxn],rev[mxn],wt[mxn],tim;

struct node{int sum,mx,mn,len;bool flip;}tr[mxn*4];
int ls(int i){return i*2+1;}
int rs(int i){return i*2+2;}

node add(node a,node b)                 // 恒等元由 len 判定，不做数值比较
{
	if(!a.len)return b;
	if(!b.len)return a;
	return {a.sum+b.sum,max(a.mx,b.mx),min(a.mn,b.mn),a.len+b.len,false};
}
void push_up(int i)
{
	tr[i].sum=tr[ls(i)].sum+tr[rs(i)].sum;
	tr[i].mx=max(tr[ls(i)].mx,tr[rs(i)].mx);
	tr[i].mn=min(tr[ls(i)].mn,tr[rs(i)].mn);
	tr[i].len=tr[ls(i)].len+tr[rs(i)].len;
}
void neg(int i)                         // 整段取负：max/min 互换后一起变号
{
	if(!tr[i].len)return;
	tr[i].sum=-tr[i].sum;
	tr[i].mx=-tr[i].mx;
	tr[i].mn=-tr[i].mn;
	swap(tr[i].mx,tr[i].mn);
	tr[i].flip=!tr[i].flip;
}
void push_down(int i)
{
	if(!tr[i].flip)return;
	neg(ls(i));neg(rs(i));
	tr[i].flip=false;
}
void ini(int l,int r,int i)             // [l,r)
{
	tr[i].flip=false;
	if(r-l==1){int v=wt[rev[l]];tr[i]={v,v,v,1,false};return;}
	int mid=(l+r)>>1;
	ini(l,mid,ls(i));ini(mid,r,rs(i));
	push_up(i);
}
void rlet(int l,int r,int i,int p,int v)        // 单点赋值：先下传再覆盖
{
	if(r-l==1){tr[i]={v,v,v,1,false};return;}
	push_down(i);
	int mid=(l+r)>>1;
	if(p<mid)rlet(l,mid,ls(i),p,v);else rlet(mid,r,rs(i),p,v);
	push_up(i);
}
void cover(int l,int r,int i,int L,int R)       // [L,R) 取负
{
	if(R<=l||r<=L)return;
	if(L<=l&&r<=R){neg(i);return;}
	push_down(i);
	int mid=(l+r)>>1;
	cover(l,mid,ls(i),L,R);cover(mid,r,rs(i),L,R);
	push_up(i);
}
node calc(int l,int r,int i,int L,int R)        // [L,R) 查询
{
	if(R<=l||r<=L)return {0,-inf,inf,0,false};
	if(L<=l&&r<=R)return tr[i];
	push_down(i);
	int mid=(l+r)>>1;
	return add(calc(l,mid,ls(i),L,R),calc(mid,r,rs(i),L,R));
}

void dfs1(int x,int f)
{
	fa[x]=f;sz[x]=1;gs[x]=-1;
	for(auto[v,w,id]:graph[x])
		if(v!=f)
		{
			dep[v]=dep[x]+1;
			wt[v]=w;                    // 边权交给较深的那个端点保管
			dfs1(v,x);sz[x]+=sz[v];
			if(gs[x]==-1||sz[v]>sz[gs[x]])gs[x]=v;
		}
}
void dfs3(int x,int t)
{
	top[x]=t;
	rev[dfn[x]=tim++]=x;
	if(gs[x]==-1)return;
	dfs3(gs[x],t);
	for(auto[v,w,id]:graph[x])if(v!=fa[x]&&v!=gs[x])dfs3(v,v);
}
template<class F>
void walk(int u,int v,F f)              // 把 u-v 的边路径拆成 O(log n) 个半开区间
{
	while(top[u]!=top[v])
	{
		if(dep[top[u]]<dep[top[v]])swap(u,v);
		f(dfn[top[u]],dfn[u]+1);
		u=fa[top[u]];
	}
	if(dfn[u]>dfn[v])swap(u,v);
	if(dfn[u]+1<=dfn[v])f(dfn[u]+1,dfn[v]+1);   // dfn[u] 是 LCA，它的位置永不进入
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1,u,v,w;i<n;++i)
	{
		cin>>u>>v>>w;
		eu[i]=u;ev[i]=v;
		graph[u].push_back({v,w,i});
		graph[v].push_back({u,w,i});
	}
	dfs1(0,-1);
	dfs3(0,0);
	ini(0,n,0);
	// cerr<<"dfn:";for(int i=0;i<n;++i)cerr<<' '<<dfn[i];cerr<<'\n';

	cin>>m;
	for(int i=0,u,v;i<m;++i)
	{
		string op;
		cin>>op>>u>>v;
		if(op[0]=='C')                  // u=边编号，v=新权值
		{
			int x=dep[eu[u]]>dep[ev[u]]?eu[u]:ev[u];
			rlet(0,n,0,dfn[x],v);
		}
		else if(op[0]=='N')walk(u,v,[&](int L,int R){cover(0,n,0,L,R);});
		else
		{
			node res{0,-inf,inf,0,false};
			walk(u,v,[&](int L,int R){res=add(res,calc(0,n,0,L,R));});
			if(!res.len)cout<<0<<'\n';   // 空路径：本地题面未定义 MAX/MIN，按 0 输出
			else if(op[1]=='U')cout<<res.sum<<'\n';
			else if(op[1]=='A')cout<<res.mx<<'\n';
			else cout<<res.mn<<'\n';
		}
	}
	return 0;
}
```
