# P1350 车的放置

> 标签：动态规划 DP · 递推 · 组合数学 · 难度：普及/提高-

## 1. 重新读题

**棋盘长什么样（题面只有两张图，先把形状钉死）**

图中 $a,b,c,d$ 是各段的"格子数"。把棋盘看成上下两块拼接的阶梯形：

- **上半块**：$b$ 行，每行 $a$ 个可用格（宽 $a$、高 $b$）；
- **下半块**：$d$ 行，每行 $c$ 个可用格（宽 $c$、高 $d$）；
- 上半块叠在下半块的**一端**上，即上半块的那 $a$ 列**完整地包含在**下半块的那 $c$ 列里（图上的"台阶"就是多出来的 $c-a$ 列）。所以要满足 $a\le c$，且"上半某一列"与"下半同一列"是**同一根竖线**——这正是车的攻击会跨块发生的原因。
- 校验：$a=b=c=d=2$ 时 $c-a=0$，两块列数相同、上下对齐，于是棋盘退化成一个 $4\times2$ 的**完整矩形**（高 $b+d=4$、宽 $2$），与题面第二张图一致。

**规则（大白话）**

在若干格子里放 $k$ 个车，任意两个车**不能同一行、也不能同一列**。求方案数 $\bmod\ (10^5+3)$。

- 每一行最多放 1 个车（否则同行互相攻击）；
- 每一列最多放 1 个车；
- 车放在哪个格 = (行, 列) 一对，且不同车占不同行、不同列。

**约束与暗示**

| 量 | 范围 |
|---|---|
| $a,b,c,d,k$ | $0\le\cdot\le1000$ |
| 总行数 $b+d$ | $\le 2000$ |
| 模数 $p=10^5+3=100003$ | 固定 |
| 部分分 | $b=0$（只剩下半块矩形）；$a,b,c,d\le4$（可暴力/可枚举对照） |

- 总行数才 $\le2000$、$k\le1000$，$2000\times1000=2\times10^6$ 的二维 DP 直接可过，暗示正解就是"逐行递推"。
- $b=0$ 子任务等价于"在 $d\times c$ 矩形上放 $k$ 个互不攻击的车"，闭式解 $\binom{d}{k}\binom{c}{k}k!$，可拿来验算。

## 2. 思维链（Chain-of-thought）

### 2.1 explore its property —— 把"不攻击"翻译成"逐行放、列不能重用"

车只沿行、列攻击，"互不攻击"等价于**所有车两两不同行、两两不同列**。既然每行至多 1 车，最自然的看法是：

> 自上而下按行处理，每一行要么不放车，要么放 1 个车（放的话要挑一个**还没被占用**的列）。

这样"放 $k$ 个车"就变成"在若干行里挑 $k$ 行、每行各挑一个互不相同的列"。关键障碍是：不同行的"可用格数"不一样（上半 $a$、下半 $c$），而且一列一旦被某行的车占了，后面的行就不能再用它——**跨块也要算**（因为上半的列是下半列的子集，同一根竖线连通）。

### 2.2 consider easier version —— 先做完整矩形（$b=0$）

令 $b=0$，棋盘就是 $d\times c$ 矩形。按上面的逐行策略：处理到第 $i$ 行、此前已经放了 $j-1$ 个车时，被占用的列恰好有 $j-1$ 根，本行（若放车）可选列数 $=c-(j-1)$。于是

$$f[i][j]=f[i-1][j]+f[i-1][j-1]\cdot(c-(j-1)).$$

这已经给出正确答案（可展开成 $\binom{d}{j}(c)^{\underline{j}}=\binom{d}{j}\binom{c}{j}j!$，见 2.5 核对）。真正的难点是：现在 $c$ 变成了"当前行的宽度"，而上半、下半宽度不同。

### 2.3 引入阶梯：宽度随行改变

把棋盘分两段扫描：

- 第 $1..b$ 行（上半）行宽 $=a$；
- 第 $b+1..b+d$ 行（下半）行宽 $=c$。

转移形式完全照搬 2.2，只是"当前行宽"记作 $\text{wid}_i$：

$$f[i][j]=f[i-1][j]+f[i-1][j-1]\cdot(\text{wid}_i-(j-1)),\quad \text{wid}_i=\begin{cases}a,&i\le b\\ c,&i>b\end{cases}$$

但这里有**两个必须先想清楚的问题**，否则公式是蒙的：

1. 为什么转移里只数"已放车的个数 $j-1$"，而不需要知道**具体占了哪几列**？（"状态刻画是否充分"）
2. 为什么这样逐行乘、逐行加，能**不重不漏**？

下面正面证明，这是本题的考点。

### 2.4 引理（状态充分性：只数"个数"就够了）

> **引理 1（占用状态可由计数完全刻画）** 无论此前在哪些行、放了车、占了哪些列，只要总共放了 $t$ 个车，那么：
> - 若当前是**上半行**，本行的 $a$ 个可用格里有且仅有 $a-t$ 个的列未被占用；
> - 若当前是**下半行**，本行的 $c$ 个可用格里有且仅有 $c-t$ 个的列未被占用。
>
> 即"还能放的列数"**只取决于 $t$，与占了哪几列无关**。

**证明（双向包含）**

已放的 $t$ 个车分处 $t$ 个**不同列**（不攻击保证列互异），记这 $t$ 根列为集合 $B$，$|B|=t$。

- *下半行*：下半行的格子覆盖列集 $C_{lo}=\{1,\dots,c\}$。上半的列集是下半的子集（阶梯形状，$a\le c$ 且对齐），所以此前所有车的列都落在 $C_{lo}$ 内：上半车的列 $\subseteq\{1,\dots,a\}\subseteq C_{lo}$，下半车的列 $\subseteq C_{lo}$。故 $B\subseteq C_{lo}$，被本行"看得到而用不了"的列恰为 $|B|=t$ 根，剩余 $c-t$ 根。**与 $B$ 里具体是哪 $t$ 根无关**，只与 $|B|=t$ 有关。

- *上半行*：上半行覆盖列集 $C_{up}=\{1,\dots,a\}$。按自顶向下的顺序，走到某个上半行时，**此前只处理过上半行**（下半还没开始），所以 $B\subseteq C_{up}$，同理本行可选列 $=a-t$，仅依赖 $t$。$\blacksquare$

这条引理就是"为什么可以按顺序乘"的数学依据：每一行能放车的方法数是一个**只跟已放总数有关的确定乘子**，与被占列的身份无关，因此不需要把"哪些列被占"编进状态，只需 $(\text{行号},\ \text{已放个数})$。

> 反面验证：若上半的列**不是**下半列的子集（两块错位、有列只属于上半），那么一根"上半独占"的列被占后并不减少下半某行的可选列，此时 $c-t$ 就不再正确——引理 1 的"下半"分支会失效。这恰好解释了阶梯图里"上半必须落在下半宽度之内"这一形状前提的用意。

### 2.5 引理（不重不漏）

把 $f$ 的组合含义明确为：$f[i][j]=($ 只在前 $i$ 行放 $j$ 个互不攻击的车的方案数$)$。

> **引理 2（递推既不重也不漏）** 上述 $f[i][j]$ 满足 2.3 的递推，且第 $i$ 行的"放/不放"二分类构成一个划分。

**证明**

- *不漏*：任取前 $i$ 行、$j$ 个车的合法布局 $\sigma$。看第 $i$ 行：
  - 若第 $i$ 行为空，则 $\sigma$ 的其余部分正好是"前 $i-1$ 行放 $j$ 个车"的合法布局，被 $f[i-1][j]$ 计数；
  - 若第 $i$ 行有 1 个车（列 $x$），去掉它得到"前 $i-1$ 行放 $j-1$ 个车"的布局 $\sigma'$，且列 $x$ 不在 $\sigma'$ 占用的 $j-1$ 根列里。由引理 1，这样的 $x$ 恰有 $\text{wid}_i-(j-1)$ 个，每个 $x$ 与每个 $\sigma'$ 组合回一个 $\sigma$。被 $f[i-1][j-1]\cdot(\text{wid}_i-(j-1))$ 计数。
  两类互斥且覆盖所有 $\sigma$，故不漏不溢。

- *不重*：两个不同的计数来源产生不同布局。"不放"分支与"放"分支因第 $i$ 行是否有车而不同；同为"放"时，不同的 $\sigma'$ 或不同的 $x$ 至少在一格上不同。由归纳，每个 $f[i-1][\cdot]$ 内部也不重。故总方案数正是两类之和。$\blacksquare$

由此 $f[b+d][k]$ 即为所求（前 $b+d$ 行 = 全部行）。

**与矩形闭式解核对（回到 2.2 的易版本）** 全为下半行时展开递推：要放 $j$ 个车，先选出有车的 $j$ 行（$\binom{d}{j}$，来自每行"放/不放"的展开），再按行序逐个挑列，可选数依次 $c,c-1,\dots,c-j+1$（即 $(c)^{\underline{j}}$）。乘积

$$\binom{d}{j}\cdot(c)^{\underline{j}}=\binom{d}{j}\binom{c}{j}j!,$$

与"挑 $j$ 行 $\times$ 挑 $j$ 列 $\times$ 一一配对"的经典公式一致。这也说明：阶梯情形只是把 $c$ 换成逐行的 $\text{wid}_i$ 再累乘，逻辑不变。

### 2.6 乘子会不会变成负数？

转移里 $\text{wid}_i-(j-1)$ 看似可能为负。其实只有当 $f[i-1][j-1]$ 真为 0 时才会遇到 $j-1>\text{wid}_i$：

- 上半行阶段：$f[i-1][j-1]\ne0\Rightarrow j-1\le$ 已处理的可用列数 $\le a=\text{wid}_i$；
- 下半行阶段：$f[i-1][j-1]\ne0\Rightarrow j-1\le c=\text{wid}_i$（列互异、都在 $c$ 根列内）。

故"乘子为负"的那些项乘的都是 0。代码里再加一句 `j-1<wid` 的守卫（相等时乘子为 0，本就该跳过），把这条结论显式固化，杜绝任何负数混进取模。

### 2.7 其它思路 / 坑点清单

- **组合容斥思路**：可把方案看成"选行 $\times$ 选列 $\times$ 满射配对"，但对阶梯形要分"上半占了几列"再对下半做下降乘积，等价于把上面的 $f$ 沿列数展开，反而更繁。逐行 DP 是最省事的正解，且天然处理模。
- **模 $p=100003$ 是质数，但本题用不到逆元**：全程只有加法与乘法、没有除法，所以不需要 Lucas / 费米小定理。别把它想复杂。
- **形状前提**：务必确认 $a\le c$ 且上半列 ⊆ 下半列（引理 1 的命脉）。题图为阶梯，天然满足。
- **$k$ 超上限**：最多放 $\min(b+d,\ c)$ 个车（受行数与列数双重限制）。超过时答案 0，DP 自然给出 0（对应乘子守卫使各项归零）。题目虽保证"至少一种可行方案"，但 0 也要能正确输出。
- **$k=0$**：什么都不放，1 种。$f[i][0]\equiv1$，输出 1。
- **$b=0$ / $d=0$**：只扫下半 / 只扫上半，循环边界自动退化；$a=0$ 的上半行完全不可用，守卫使其乘子为 0（见 4.3 用例）。
- **取模时机**：每次累乘立刻 `%p`，中间量 $<p\cdot\max(a,c)$，不爆（溢出预算见 4.3）。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — "互不攻击" = 两两不同行且不同列，于是每行至多 1 车，可逐行扫描（2.1）。
- **consider easier version** — 先解 $b=0$ 的完整矩形，得到"第 $j$ 个车可选列 $=c-(j-1)$"的乘积式（2.2）。
- **generalize the width** — 阶梯形把固定 $c$ 换成逐行 $\text{wid}_i\in\{a,c\}$，转移形式不变（2.3）。
- **state-sufficiency lemma** — 证明"还能放几列"只由已放个数 $t$ 决定、与占了哪几列无关（依赖上半列 ⊆ 下半列），从而状态无需记住具体列（2.4，引理 1）。
- **no-overlap-no-omission（第 $i$ 行放/不放二分）** — 用"第 $i$ 行是否为空"做划分，归纳证明递推不重不漏（2.5，引理 2）。
- **cross-check with closed form** — 用 $\binom{d}{j}\binom{c}{j}j!$ 与 DP 展开互验，确认乘子就是下降阶乘（2.5）。
- **domain / sign audit** — 论证乘子 $\text{wid}_i-(j-1)\ge0$（否则乘的对象为 0），并加 `j-1<wid` 守卫（2.6）。
- **mod without inverses** — 只有加乘无除法，$p=100003$ 质数性用不上；每步取模（2.7、4.3）。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初值 | 记忆点 |
|---|---|---|---|
| `a,b,c,d` | 上半宽/高、下半宽/高 | `int`，输入 | 上半列 ⊆ 下半列，$a\le c$ |
| `k` | 要放的车数 | `int`，输入 | $\le1000$ |
| `wid_i` | 第 $i$ 行的可放列数 | $i\le b$ 取 $a$，否则取 $c$ | `wid=(i<=b?a:c)` |
| `f[i][j]` | 只在前 $i$ 行放 $j$ 个车的方案数 $\bmod p$ | `i64`，`f[0][0]=1` | 行号 1-based，$i=0$ 是空棋盘 |
| `p` | 模数 $10^5+3=100003$ | `constexpr` | 无除法，不需逆元 |

> 注：本题**没有"列下标"这种状态**（引理 1 说只需计数），因此不涉及 0/1-based 列转换；行号按图用 1-based，$f[0][j]$ 表示"一行都还没看"。

### 4.2 算法步骤

1. **读入** $a,b,c,d,k$。置 $f[0][0]=1$，其余 $f[0][\cdot]=0$（全局默认 0，正好）。
2. **逐行 $i=1..b+d$**：取当前行宽 `wid=(i<=b?a:c)`。
   - `f[i][0]=1`（一行不放任何车）。
   - 对 $j=1..k$：`f[i][j] = f[i-1][j] + f[i-1][j-1]*(wid-(j-1))`，其中当 `j-1>=wid` 时乘子按 0 处理（守卫 `j-1<wid`），结果 `%p`。
3. **输出** `f[b+d][k]`（已 $\bmod p$）。

**复杂度**：时间 $O((b+d)\cdot k)\le2000\times1000=2\times10^6$；空间 $O((b+d)\cdot k)$（滚动可降到 $O(k)$，这里行少不必省，写二维最直观）。

### 4.3 验证状态（**全部手工推演，未运行任何代码**）

> 本环境无编译器、禁止运行；题面无样例。以下每个用例都由"手算 DP + 独立暴力枚举/闭式解"两头对齐。

记棋盘列：上半的列是下半列集的子集。约定列以计数体现。

**用例 1（完整矩形 2×2，$a=c=2,b=d=1$，对照经典公式）** $k=2$：$\binom22\binom22 2!=2$。手算 DP：$f[0][0]=1$。行 1（wid=a=2）：$f[1][1]=1\cdot2=2$。行 2（wid=c=2）：$f[2][2]=f[1][1]\cdot(2-1)=2\cdot1=2$ ✓。$k=1$：$f[2][1]=f[1][1]+f[1][0]\cdot2=2+2=4=$ 格子数 ✓。

**用例 2（$b=0$ 纯矩形 $d\times c$）** $a=0,b=0,c=3,d=2,k=2$（上半不存在）。应 $=\binom22\binom32 2!=1\cdot3\cdot2=6$。DP 只有下半行 wid=3：行 1 $f[1][1]=3$；行 2 $f[2][2]=f[1][1]\cdot(3-1)=3\cdot2=6$ ✓。

**用例 3（阶梯，可全枚举）** $a=1,b=1,c=2,d=1,k=2$。上半行只有 1 格（在下半列集的某一根上）；下半行 2 格。放 2 车须占用两行的两列：上半车只能在那根共享列，下半车只能选下半**另一根**列 → 仅 **1** 种。DP：行 1 wid=1：$f[1][1]=1\cdot(1-0)=1$。行 2 wid=2：$f[2][2]=f[1][1]\cdot(2-1)=1\cdot1=1$ ✓。$k=1$：$f[2][1]=f[1][1]+f[1][0]\cdot2=1+2=3=$ 格子总数(1+2) ✓。

**用例 4（"某行完全不可用" $a=0$ + "放 0 车"）** $a=0,b=1,c=2,d=1,k=1$：上半行 $0$ 格（完全放不了），只下半行 2 格 → **2** 种。DP：行 1 wid=0，守卫使 $f[1][1]=0$，$f[1][0]=1$；行 2 wid=2：$f[2][1]=f[1][1]+f[1][0]\cdot2=0+2=2$ ✓。$k=0$ 任一棋盘：$f[\cdot][0]\equiv1$，输出 1 ✓（什么都不放是唯一方案）。

**用例 5（超上限 / 更大阶梯对照闭式）** $a=2,b=2,c=4,d=2,k=1$：$k=1$ 应等于格子总数 $=2\cdot2+4\cdot2=12$。DP：$f[1][1]=2$，$f[2][2]$ 不用；到 $f[2][1]=f[1][1]+f[1][0]\cdot2=2+2=4$（上半 4 格）；行 3 wid=4：$f[3][1]=4+1\cdot4=8$；行 4 wid=4：$f[4][1]=8+4=12$ ✓。$k$ 超过 $\min(b+d,c)=\min4,4=4$，如 $k=5$：下半行 $j=5$ 时 $j-1=4\ge\text{wid}=4$ 触发守卫、上半早已归零，$f[4][5]=0$ ✓（无法放 5 车）。

**溢出自检 / 取模预算**：真正方案数是排列级乘积，例如矩形 $\binom{d}{k}\binom{c}{k}k!\le(1000)^{\underline{k}}$ 可达天文数字，但 DP **每步先 `%p`**，故任一 $f[i][j]<p=100003$。唯一的大乘法是 `f[i-1][j-1]*(wid-(j-1))`，上界 $<100003\times1000\approx10^8$，加一项 $<p$ 再取模，全程 $<1.01\times10^8\ll2^{31}$。`int` 已够；示例代码仍用 `i64` 作乘子，纯属"多一层保险、免心智负担"，不改变结果。

## 5. 示例代码（C++）

```cpp
// P1350 车的放置
// 逐行放车：上半 b 行宽 a、下半 d 行宽 c，上半列集是下半列集的子集
// 第 j 个车在当前行的可选列数 = wid - (j-1)，只跟"已放几个"有关（见正文引理 1）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int p{100003};              // 模数 1e5+3
constexpr int mxr{2005},mxk{1005};    // 行数<=b+d<=2000, k<=1000, +5 松弛

int a,b,c,d,k;
i64 f[mxr][mxk];                      // f[i][j]: 前 i 行放 j 个车的方案数 mod p

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b>>c>>d>>k;
	f[0][0]=1;
	for(int i=1;i<=b+d;++i)
	{
		int wid=(i<=b?a:c);            // 当前行可放列数（上半 a / 下半 c）
		f[i][0]=1;                     // 一行都不放
		for(int j=1;j<=k;++j)
		{
			i64 add=0;
			if(j-1<wid)                // 还能占一列才放得下；否则乘子本应为 0
				add=f[i-1][j-1]*(wid-(j-1))%p;
			f[i][j]=(f[i-1][j]+add)%p;
		}
	}
	cout<<f[b+d][k]%p<<'\n';
	return 0;
}
```

### 代码说明

- **状态只有 $(\text{行},\text{个数})$ 两维**：对应引理 1"占用状态可由计数完全刻画"，全程不记录具体列，数组 `f[mxr][mxk]`（约 $2\times10^6$ 个 `i64`，16 MB 级）够用。
- **`wid=(i<=b?a:c)`**：一行代码体现阶梯形状，前 $b$ 行走上半、后 $d$ 行走下半，$b=0$ 时自动全是下半、$d=0$ 时自动全是上半。
- **守卫 `if(j-1<wid)`**：把 2.6 的"乘子非负"结论固化进代码，避免任何负数进入取模；相等时乘子为 0，跳过与乘 0 等价。
- **每步 `%p`**：中间乘法 $<10^8$（见 4.3 预算），`i64` 只是保险；无除法、不用逆元。
