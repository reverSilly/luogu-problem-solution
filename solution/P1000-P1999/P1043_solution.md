# P1043 [NOIP 2003 普及组] 数字游戏 — 题解

## 一、发现叙述

你面前有一圈整数，你要按顺序切成 m 段，每段求和再对 10 取模，把 m 个模数乘起来得到一个数 k。圈是环形的，可以从任意位置开始切；切的顺序必须沿着圆圈走，不能打乱原始序列。

小样例给了我们直觉。n=4, m=2，数字是 2, -1, 4, 3 围成一圈。最小值是 7（(2-1) mod 10 × (4+3) mod 10 = 1×7），最大值是 81（(2+4+3) mod 10 × (-1) mod 10 = 9×9）。

关键信息浮现了：

- **取模结果永远非负**：C++ 的 `%` 对负数会得负值，必须手工调整成 `(x%10+10)%10`。
- **环形**：需要破环成链，枚举起点。
- **乘法**：所有模数都在 0~9 之间，所以参与乘法的数都是非负的。这极大简化了最优子结构——最小值只需要取 min×min，最大值只需要取 max×max。

## 二、思维链（Chain of Thought，含完整证明）

### 2.1 环 → 链

环形序列的标准处理手法：把数组复制一份接在末尾，长度变成 2n。一个长度为 n 的窗口对应环上的一种"从某处断开"的方案。

```
原始环: a[0], a[1], ..., a[n-1]
展开后: a[0], a[1], ..., a[n-1], a[0], a[1], ..., a[n-1]
窗口 s: a[s], a[s+1], ..., a[s+n-1]   (0 ≤ s < n)
```

最终答案要在所有窗口上取全局最值。

### 2.2 区间 DP 状态设计

设我们正在处理连续子段 `[l, r)`（左闭右开），要把它切成 k 段。

定义：
- `dp_min[l][r][k]`：将 `[l, r)` 切为 k 段所得乘积的最小值。
- `dp_max[l][r][k]`：将 `[l, r)` 切为 k 段所得乘积的最大值。

基础情况 k=1：一整段不切，值就是区间和模 10。

$$dp\_min[l][r][1]=dp\_max[l][r][1]=\big((pre[r]-pre[l])\bmod 10+10\big)\bmod 10$$

其中 pre[i] 是展开后数组的前缀和（pre[0]=0, pre[i]=a[0..i-1] 之和）。

### 2.3 转移方程

对于 k>1，考虑第一刀切在哪。设第一段为 `[l, i)`（含 1 个元素以上），剩下 `[i, r)` 必须切为 k−1 段。

$$dp\_min[l][r][k]=\min_{l<i\le r-(k-1)}\big(dp[l][i][1]\times dp\_min[i][r][k-1]\big)$$
$$dp\_max[l][r][k]=\max_{l<i\le r-(k-1)}\big(dp[l][i][1]\times dp\_max[i][r][k-1]\big)$$

**为什么仅需 min×min 和 max×max？**

因为每个 `dp[·][·][1]`（即区间和模 10）的值域是 {0,1,...,9}，所有因子非负。非负数相乘时，最小乘积必然由最小的因子相乘得到，最大乘积必然由最大的因子相乘得到。无需像一般的 DP 那样同时考虑四种组合（min×min、min×max、max×min、max×max）。

**正确性证明（归纳）**：

- 基础：k=1 时直接计算，正确。
- 归纳步：假设对任意长度小于当前区间、任意 k'<k 的状态，dp_min 和 dp_max 已正确求出最小值与最大值。
- 对于当前状态 `[l, r), k`，任意一种合法划分方案的第一段必为某个 `[l, i)`（作为一整段不拆分），其后 `[i, r)` 分为 k−1 段。由归纳假设，`dp_min[i][r][k-1]` 是正确的该子问题最小值。又因 `dp[l][i][1]` 是非负常数，所以 `dp[l][i][1] × dp_min[i][r][k-1]` 是对应该切分点 i 的最小可能乘积。对 i 取全局 min 即得 `dp_min[l][r][k]`。max 同理。

### 2.4 复杂度

n ≤ 50，m ≤ 9，展开后长度 N = 2n ≤ 100。

- 状态数：O(N²·m) ≈ 100×100×9 = 9×10⁴
- 每个状态枚举切分点 i：O(N)
- 总复杂度 O(N³·m) ≈ 100³×9 = 9×10⁶，轻松通过。

### 2.5 边界与实现细节

- 切分点 i 必须满足：第一段至少有 1 个数（i > l），剩余段至少有 k−1 个数（r−i ≥ k−1 → i ≤ r−(k−1)）。
- 初始化：所有 k≥2 的状态赋为极大哨兵（最小值用 1145141919，最大值用 −1145141919）；k=1 的状态直接计算。
- 注意 C++ 负数取模：用 `(x%10+10)%10` 确保非负。
- 最后枚举起点 s∈[0, n)，取 `dp_min[s][s+n][m]` 和 `dp_max[s][s+n][m]` 的全局最值输出。

## 三、模式总结

| 特性 | 本题 |
|------|------|
| **序列结构** | 环形，破环成链（数组倍增） |
| **划分约束** | 顺序切割，m 段，每段非空 |
| **段内聚合** | 求和后对 10 取模（值域 0~9） |
| **段间合并** | 乘法（因子非负，min×min / max×max 即可） |
| **DP 范式** | 区间 DP，`dp[l][r][k]` 枚举首段右端点转移 |
| **复杂度** | O(n³·m)，n≤50, m≤9 |

这种"环形→倍增→区间 DP"的三板斧在 OI 中反复出现（石子合并、多边形三角剖分等）。取模非负的约束则简化了 min/max 的合并逻辑。

## 四、正解（含符号表）

### 符号说明

| 符号 | 含义 |
|------|------|
| n | 原始序列长度 |
| m | 需要切割的段数 |
| a[0..2n-1] | 展开后的序列（原序列复制两次） |
| pre[i] | 前缀和，pre[0]=0, pre[i]=∑_{j=0}^{i-1} a[j] |
| sum(l, r) | `((pre[r]-pre[l]) % 10 + 10) % 10`，区间和模 10 |
| dp_min[l][r][k] | 区间 [l, r) 切 k 段的最小乘积 |
| dp_max[l][r][k] | 区间 [l, r) 切 k 段的最大乘积 |

### 算法步骤

1. 读入 n, m 和 n 个数，构造展开数组 a[0..2n-1]（a[i+n] = a[i]）。
2. 计算前缀和 pre。
3. 初始化所有区间的 k=1 状态为 sum(l, r)；k≥2 状态为哨兵。
4. 区间 DP：按长度 len 从 2 到 n 枚举，对每个区间 `[l, r=l+len)` 和每个 k∈[2, min(m, len)]，枚举切分点 i（l+1 ≤ i ≤ r-(k-1)），按转移方程更新 dp_min 和 dp_max。
5. 枚举起点 s∈[0, n)，取全局最值输出。

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{55};

int n,m,a[mxn*2],pre[mxn*2];
int dpmn[mxn*2][mxn*2][15];
int dpmx[mxn*2][mxn*2][15];

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		a[i+n]=a[i];
	}
	for(int i=0;i<n*2;++i)
		pre[i+1]=pre[i]+a[i];

	auto mod10=[](int x){return(x%10+10)%10;};
	auto sum=[&](int l,int r){return mod10(pre[r]-pre[l]);};

	for(int l=0;l<n*2;++l)
		for(int r=l+1;r<=n*2;++r)
		{
			dpmn[l][r][1]=sum(l,r);
			dpmx[l][r][1]=sum(l,r);
			for(int k=2;k<=m;++k)
			{
				dpmn[l][r][k]=1145141919;
				dpmx[l][r][k]=-1145141919;
			}
		}

	for(int len=2;len<=n;++len)
		for(int l=0;l+len<=n*2;++l)
		{
			int r=l+len;
			for(int k=2;k<=m&&k<=len;++k)
				for(int i=l+1;i<r;++i)
				{
					if(i>r-(k-1))
						break;
					int v1=sum(l,i);
					dpmn[l][r][k]=min(dpmn[l][r][k],v1*dpmn[i][r][k-1]);
					dpmx[l][r][k]=max(dpmx[l][r][k],v1*dpmx[i][r][k-1]);
				}
		}

	int ansmn=1145141919,ansmx=-1145141919;
	for(int s=0;s<n;++s)
	{
		ansmn=min(ansmn,dpmn[s][s+n][m]);
		ansmx=max(ansmx,dpmx[s][s+n][m]);
	}

	cout<<ansmn<<'\n'<<ansmx<<'\n';
	return 0;
}
```
