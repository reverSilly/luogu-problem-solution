# P1159 排行榜 — 题解

## 第一部分：重新读题

**用大白话重新说一遍题目：**

有 N 首歌（1 ≤ N ≤ 100）。我们能看到"本周榜单"的排列顺序：第 1 行是本周第 1 名的歌，第 2 行是本周第 2 名的歌……以此类推。对每一首歌，我们还知道一个情报：跟上周相比，这首歌的排名是 **上升（UP）**、**下降（DOWN）**还是 **没变（SAME）**。

要求：根据这些情报，构造出"上周榜单"的一个可能排列。上周榜单就是输出 N 首歌的名字，第 i 行代表上周第 i 名。答案不唯一，只要满足所有歌的 UP/DOWN/SAME 情报即可，保证至少有一个解。

**约束条件速记：**
- N 最大只有 100，复杂度 $O(N)$ 都绰绰有余；
- 歌名是大写英文字母，长度 ≤ 100；
- 输出任意一个合法解即可（Special Judge）。

**输入输出格式：**
- 读入 N，然后 N 块，每块两行：`歌名` 和 `UP/DOWN/SAME`（顺序就是本周排行榜从第 1 名到第 N 名）。
- 输出上周榜单，第 i 行输出上周第 i 名的歌名。

## 第二部分：思考过程（像人一样一步步发现解法）

### 第 1 步：先想"无解长什么样"

每一首歌都告诉我们它上周相对于"本周位置 $i$"去了哪里：

- 状态是 `UP`：上周排名编号 **大于** $i$（排名数字越大 = 名次越靠后）；
- 状态是 `DOWN`：上周排名编号 **小于** $i$；
- 状态是 `SAME`：上周排名编号 **正好等于** $i$。

所以 `SAME` 的歌是最简单的——它在上周的位置被**钉死了**，谁都不能抢。

那么问题变成：剩下的歌（`UP` 和 `DOWN`）怎么填进剩下的空位？

### 第 2 步：先做个"更简单的问题"——只有 DOWN

假设所有歌都标着 `DOWN`（没有 `UP` 和 `SAME`）。任意一首在本周位置 $i$ 的 DOWN 歌，上周必须放到某个 $< i$ 的位置。

一种暴力做法是排序匹配，但这里有个更漂亮的贪心想法：

> 把本周榜单从 **左到右** 看，看到 DOWN 歌就把它放到**当前最靠左的空位**。

直觉是：越早出现的 DOWN 歌（$i$ 越小）越"赶时间"，因为留给它退让的空间越少（位置 $1,2,\dots,i-1$ 没多少空地方），所以应该优先满足它。这个直觉可以严格证明（见下面 Lemma 1 的完整证明）。

### 第 3 步：加入 UP 之后，对称思考

UP 的歌和 DOWN 完全对称——UP 要往右走，DOWN 要往左走。所以一个自然的猜测是：

> **DOWN 歌全部填进「最靠左」的一批空位，UP 歌全部填进「最靠右」的一批空位。**

也就是说，把所有空位按升序排好，前 $d$ 个空位（$d$ = 有 `DOWN` 状态的歌的数量）全部给 DOWN 歌，剩下的全部给 UP 歌。

这个方案有一个很漂亮的性质：**不管具体是哪只 DOWN 歌、哪只 UP 歌填哪个空位，只要数量对上，约束就一定满足**（证明见下面 Lemma 1 和 Lemma 2）。

### 第 4 步：为什么"最靠左"一定够 DOWN 用？（关键证明）

Lemma 1：设 DOWN 歌按本周位置升序为 $d_0 < d_1 < \dots < d_{k-1}$（$d_j$ 表示第 $j$ 只 DOWN 歌本周所在位置，0-based）。把空位也按升序排列为 $e_0 < e_1 < \dots < e_{m-1}$，其中 $m = k + l$（$l$ = UP 歌的数量）。

我们的方案是：DOWN 歌 $d_j$ 填 $e_j$。我们要证明在题目保证有解的前提下，一定有：

$$e_j < d_j \quad \text{对所有 } j = 0, 1, \dots, k-1$$

证明（反证法）：

设某个 $j$ 满足 $e_j \ge d_j$。这意味着升序空位中第 $j$ 个空位已经 ≥ 本周位置 $d_j$，也就是说在位置 $0, 1, \dots, d_j - 1$ 这些位置里，空位数量 $\le j$。

这 $d_j$ 个位置（即本周排名 $1$ 到 $d_j$ 之间的所有位置）里，除去 SAME 占掉的位置，只有 $\le j$ 个空位。但是本周在这 $d_j$ 个位置（编号 $0$ 到 $d_j-1$）里，一共有 $d_0, d_1, \dots, d_j$ 这 $j+1$ 只 DOWN 歌——它们全部都**必须**放到编号更小的空位里，即都**必须**放到位置 $\le d_j - 1$ 的范围内。而空位只有 $\le j$ 个，装不下 $j+1$ 只 DOWN 歌。

这与"至少存在一个解"矛盾。因此所有 $j$ 都有 $e_j < d_j$。∎

Lemma 2：设 UP 歌按本周位置升序为 $u_0 < u_1 < \dots < u_{l-1}$。我们的方案是 UP 歌 $u_i$ 填 $e_{k+i}$（即升序空位中从第 $k$ 个往右的每个空位）。

证明 $e_{k+i} > u_i$：

同样考虑位置 $e_{k+i}$。如果 $e_{k+i} \le u_i$，那么在位置 $\le u_i$ 的范围内，空位数量 $\ge k + i + 1$。这些空位中，前 $k$ 个被 DOWN 歌占用，那么留给 UP 歌的空位至少有 $(k+i+1) - k = i+1$ 个。

但本周位置 $\le u_i$ 的 UP 歌一共有 $i+1$ 只（$u_0, \dots, u_i$），它们都**必须**放到编号更大的位置（$\ge u_i + 1$），一个都不能放在 $\le u_i$ 的位置里。

所以留给 UP 歌的、位于 $> u_i$ 的空位必须 ≥ $(k+i+1) - k = i+1$ 个。于是 $\le u_i$ 的位置里最多只有 $(k+i+1) - (i+1) = k$ 个空位会被 DOWN 用掉……等等，这里要重新理清楚。

换个更清楚的说法：位置 $\le u_i$ 的范围内有 $k+i+1$ 个空位（因为 $e_{k+i} \le u_i$，且空位是升序排列，所以 $e_0, \dots, e_{k+i}$ 都在 $\le u_i$ 内）。DOWN 歌只占 $e_0, \dots, e_{k-1}$ 这 $k$ 个。但是**在任意合法解里**，这 $\le u_i$ 的范围必须装下至少 $k$ 只 DOWN 歌（本周在 $\le u_i$ 位置出现的所有 DOWN 歌都得往更小的位置跑；如果它们的数量超过 $k$……我们只需考虑最关键的矛盾）。

其实最干净的论证是：

- 位置 $\le u_i$ 范围内，有 $k+i+1$ 个空位（属于 $e_0, \dots, e_{k+i}$）。
- 但在这 $k+i+1$ 个位置里，至少要有 $k$ 个被 DOWN 歌占掉——不，数量未必是 $k$。更精确地说：本周在位置 $\le u_i$ 的 DOWN 歌全部需要占这块区域的空位。设这块区域里 DOWN 歌 $C_D$ 只、UP 歌 $C_U$ 只（$C_D + C_U + C_S = u_i + 1$，其中 $C_S$ 是 SAME 数）。
  - 这 $C_D$ 只 DOWN 歌全部得占到 $\le u_i$ 的空位（它们必须往更小的编号走）。
  - 这 $C_U$ 只 UP 歌全部**不能**占 $\le u_i$ 的空位（它们必须往更大的编号走）。
  - 所以 $\le u_i$ 的空位数量必须 ≥ $C_D$。
  - 若 $e_{k+i} \le u_i$，则 $\le u_i$ 的空位数量 ≥ $k+i+1 \ge C_D + i + 1 > C_D$。这个不等式本身不矛盾——空位多没问题。

不对，上面的论证方向反了。真正要证明的是某种"总量挤兑"。

正确版反证：若 $e_{k+i} \le u_i$，则 $e_0, \dots, e_{k+i}$ 全部 $\le u_i$，也就是说 $\le u_i$ 范围里有至少 $k+i+1$ 个空位。那么 $> u_i$ 的范围里空位最多只有 $m - (k+i+1) = l - i - 1$ 个。

但在合法解里，$> u_i$ 的范围必须提供至少 $l - i$ 个空位——因为本周位置 $\ge u_i$ 的 UP 歌（$u_i, u_{i+1}, \dots, u_{l-1}$，共 $l - i$ 只）都**必须**跑到 $> u_i$（其实是 $> $ 它们各自位置，而 $u_i$ 是这些里面最小的，所以它们的位置都 ≥ $u_i + 1$）的空位里，一个都不能留在 $\le u_i$。

于是 $> u_i$ 需要 ≥ $l-i$ 个空位，但只有 ≤ $l-i-1$ 个。矛盾。∎

> 注：上面两段是 Lemma 2 的严格版。为了让推导更顺，也可以直接对对称问题"榜单镜像 + UP/DOWN 互换"复用 Lemma 1 的证明——结论是一样的，这里就不重复了。

### 第 5 步：SAME 歌和剩下的细节

- 所有 `SAME` 歌直接落到它们此刻的编号位置，这个位置是**独占**的。
- 剩下的空位按升序排列，前 $d$ 个（$d$ = DOWN 歌数量）分给 DOWN 歌，剩下的分给 UP 歌。
- DOWN / UP 歌的具体匹配顺序：按它们**本周的位置编号升序**依次放进对应空位即可（Lemma 1/2 的证明要求按升序排序后 $e_j$ 与 $d_j$ 配对）。

**复杂度**：找空位 $O(N)$，排序 DOWN/UP 歌可以借助"输入顺序即本周排名顺序"直接就是升序，整体 $O(N)$（如果偷懒排序也是 $O(N \log N)$，N ≤ 100 无所谓）。

### 第 6 步：手动验证一个例子

题目样例（构造一个合理的）：

```
5
A UP
B DOWN
C SAME
D UP
E DOWN
```

本周榜单：第1名A(UP)、第2名B(DOWN)、第3名C(SAME)、第4名D(UP)、第5名E(DOWN)。

- SAME 钉死：第3名固定为 C。
- 空位：第1、2、4、5名（0-based：0,1,3,4）。
- DOWN 歌按本周位置升序：B(本周2)、E(本周5)。空位升序前 2 个是第1、2名。
  - B → 第1名（1 < 2 ✓）
  - E → 第2名（2 < 5 ✓）
- UP 歌按本周位置升序：A(本周1)、D(本周4)。剩余空位第4、5名。
  - A → 第4名（4 > 1 ✓）
  - D → 第5名（5 > 4 ✓）
- 上周榜单：B, E, C, A, D ✓

检验所有歌：
- A：上周第4，本周第1 → UP ✓
- B：上周第1，本周第2 → DOWN ✓
- C：上周第3，本周第3 → SAME ✓
- D：上周第5，本周第4 → UP ✓
- E：上周第2，本周第5 → DOWN ✓

完美。

## 第三部分：模式总结（按思考顺序）

1. **先固定最确定的** — `SAME` 的歌位置不变，直接用"钉死"法，把问题规模缩小到剩下来的独立歌上。
2. **看性质** — UP 需要更大的编号，DOWN 需要更小的编号，方向相反。
3. **贪心方向** — DOWN 歌抢"最左"空位，UP 歌抢"最右"空位；这个分配跟具体哪首歌去哪个空位无关，只要求数量各归各位。
4. **反证法证明** — 假设第 $j$ 个空位 ≥ 第 $j$ 只 DOWN 歌的当前位置，则前方空位不够装前排 DOWN 歌，矛盾，于是必有解时构造必合法；UP 侧对称同理。
5. **实现技巧** — 空位用数组存好，左右两个指针分别填 DOWN / UP；输入顺序即本周排名顺序，天然有序，无需额外排序。

## 第四部分：真正的解法（含符号表）

**符号表：**
| 符号 | 含义 |
|---|---|
| $N$ | 歌曲总数（榜单长度） |
| $s_i$ | 第 $i$ 首歌（$i$ 从 1 到 $N$，与本周榜单位置一致） |
| $sts_i$ | 第 $i$ 首歌的状态：`UP` / `DOWN` / `SAME` |
| $ans_i$ | 上周榜单第 $i$ 名的歌名（即答案数组） |
| $\text{empty}$ | 上周榜单中未被 SAME 歌占据的位置集合，升序排列 |
| $d, u$ | DOWN / UP 歌的数量 |
| $p_d, p_u$ | 两个指针，分别指向当前该放 DOWN / UP 歌的空位下标 |

**算法步骤：**

1. 读入 $N$，以及每首歌的歌名 $name_i$ 与状态 $sts_i$（$i = 1 \dots N$，顺序即本周排名）。
2. 初始化 $ans$ 数组为空。
3. 第一遍扫描：对每个 $i$，若 $sts_i = \text{SAME}$，令 $ans_i = name_i$；否则把 $i$ 记入空位列表 $\text{empty}$。
4. 统计 DOWN 歌数量 $d$。
5. 第二遍扫描（从左到右，即本周排名从小到大）：
   - 用一个指针 $p_d$ 指向 $\text{empty}$ 的起始位置；
   - 遇到 $sts_i = \text{DOWN}$ 的歌，把它放到 $ans[\text{empty}[p_d]]$，然后 $p_d$ 后移一格。
6. 第三遍扫描（从左到右）：
   - 用一个指针 $p_u$ 指向 $\text{empty}$ 中从 $d$ 开始的位置；
   - 遇到 $sts_i = \text{UP}$ 的歌，把它放到 $ans[\text{empty}[p_u]]$，然后 $p_u$ 后移一格。
7. 逐行输出 $ans_1 \dots ans_N$。

**为什么这样顺序放？** 第一遍把 SAME 钉死；第二步 DOWN 歌按本周位置升序放入最左空位；第三步 UP 歌放入剩下（更靠右）的空位。Lemma 1/2 保证每一步都合法。

**复杂度：** 时间 $O(N)$（三次线性扫描），空间 $O(N)$。

## 第五部分：C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n;
string name[mxn],sts[mxn],ans[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>name[i]>>sts[i];
		if(sts[i]=="SAME")
			ans[i]=name[i];
	}

	// DOWN 歌:按本周排名升序,放到最左侧的空位
	int p=0;
	for(int i=0;i<n;++i)
	{
		if(sts[i]!="DOWN")continue;
		while(ans[p]!="")
			++p;
		ans[p]=name[i];
	}

	// UP 歌:按本周排名升序(从右往左扫),放到最右侧的空位
	p=n-1;
	for(int i=n-1;i>=0;--i)
	{
		if(sts[i]!="UP")continue;
		while(ans[p]!="")
			--p;
		ans[p]=name[i];
	}

	for(int i=0;i<n;++i)
		cout<<ans[i]<<'\n';

	return 0;
}
```
