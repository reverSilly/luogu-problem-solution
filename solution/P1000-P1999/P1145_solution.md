# P1145 约瑟夫

## 1. 重述问题

2k 个人围成一圈，前 k 个是好人，后 k 个是坏人（编号 1..2k）。从好人 1 开始，每次数到 m 的人被杀，下一个人重新开始数。求最小的 m，使得所有 k 个坏人先被杀（即在任何好人被杀之前杀光所有坏人）。k < 14。

## 2. 推理链

### 2.1 问题本质

这是经典的约瑟夫问题的变体。约瑟夫问题：n 个人编号 0..n-1 围成一圈，从 0 开始每次报数到 m-1 的人出局。标准递归公式 `f(n,m) = (f(n-1,m)+m) % n` 可推出最后存活者的编号。

本题不同：我们不关心最后活着的人是谁，而是关心**前 k 次出局的人是否全是坏人**。

### 2.2 直接模拟

n = 2k ≤ 28，非常小。对每个候选 m，可以直接模拟约瑟夫杀人的过程，检查前 k 个被杀者是否全是坏人。

约瑟夫模拟方法：
- 用一个数组标记是否已出局
- 当前指针 pos，每次跳过剩余的人，数 m 个人（已出局的跳过），找到下一个被杀者
- 如果被杀者在 0..k-1（好人），则这个 m 无效
- 杀掉 k 个坏人后，如果全部在前 k 次内出局，则 m 合法

虽然 k < 14 极小，但 m 可以从 1 开始递增直到找到解。最坏情况下 m 可能达到几千或几万，但每次模拟 O(k²) 也完全可接受。

### 2.3 更高效的 O(k) 模拟

不需要维持整个数组。可以每次记录当前剩余人数和位置。

设总人数为 n = 2k，当前从 0 开始。

每次选择位置 `pos = (pos + m - 1) % rem`，其中 rem 是当前剩余人数。

被移除的人如果原始编号 < k（好人），则 m 无效。

问题是：**每次移除后，剩余人的编号会重新排列**。我们必须跟踪移除的是"好人"还是"坏人"，而不只是位置。

更好的方法：不模拟编号重排，直接维护一个布尔数组跟踪每个原始编号是否存活。

```cpp
// 模拟约瑟夫
bool alive[28];
fill_n(alive, 2*k, true);
int pos = 0; // 当前起始位置（相对于存活者列表中的索引）
int killed_bad = 0;
for (int step = 0; step < k; ++step) {
    // 找到第 m 个存活者
    int cnt = 0;
    while (true) {
        if (alive[pos]) {
            ++cnt;
            if (cnt == m) break;
        }
        pos = (pos + 1) % (2*k);
    }
    // pos 指向被杀死的人
    if (pos < k) return false; // 好人被杀了
    alive[pos] = false;
    killed_bad++;
    // 从下一个人开始
    while (!alive[pos]) pos = (pos + 1) % (2*k);
}
return true;
```

O(2k) 的每次寻找，k 次 = O(k²)。对 k < 14 来说完全足够。

### 2.4 预计算 + 打表

因为 k < 14，只有 13 个可能的输入，我们可以在代码中直接预计算所有答案并打表。也可以在代码里枚举 m 现场计算。

已知实际输出中，对于 k=1..13，答案依次为：2, 7, 5, 30, 169, 441, 1872, 7632, 1740, 93313, 459901, 1358657, 2504881。

### 2.5 剪枝

- m 至少为 k+1（因为第一轮杀的人编号 = (m-1)%2k，如果是好人即 < k 则 m 无效，所以 m-1 ≥ k，即 m ≥ k+1）
- m 也一定要 > 1（k≥2 时，m=1 会先杀好人 1 号）
- 实际从 k+1 开始枚举即可。

### 2.6 正确性证明

**引理 1**：m 的合法必要条件：第一次出局的人编号 ≥ k。

从 0 号（好人 1）开始，数 m 个人到位置 (m-1) % 2k。如果 (m-1) % 2k < k，则第一个就杀了好人，m 非法。因此 m 必须满足 (m-1) % (2k) ≥ k。

但这不是充分条件，因为后续轮的杀人过程复杂，必须模拟。

**引理 2**：模拟算法的正确性。

模拟直接根据约瑟夫问题的规则执行每次报数-杀人-重排列的过程，搜索空间中检查的是"前 k 个被杀的原始编号是否全 ≥ k"。如果模拟输出 true，则该 m 确实能先杀完 k 个坏人；如果 false，则不能。从最小 m 开始枚举，第一个合法的就是答案。□

## 3. 模式总结

- **经典约瑟夫模拟** — 环形报数杀人问题
- **枚举 m 暴力** — k ≤ 13，m 从小往大试，直接模拟检查
- **剪枝 m ≥ k+1** — 第一枪不能打好人
- **预计算打表**（可选）— 13 个固定答案可一次算完硬编码

## 4. 真实解法

### 符号表

| 符号 | 含义 |
|------|------|
| `k` | 好人和坏人各 k 个，总数 2k |
| `m` | 报数目标 |
| `alive[i]` | 原始编号 i 是否还活着 |
| `pos` | 当前计数起始位置（原始编号） |

### 算法步骤

1. 读入 k
2. 从 m = k+1 开始循环：
   - 初始化 `alive[0..2k-1] = true`
   - pos = 0
   - for step = 0..k-1：
     - 从 pos 开始数 m 个存活者，找到被杀者
     - 如果被杀者编号 < k：m 无效，跳出
     - 标记被杀者死亡
     - 将 pos 移动到下一个存活者
   - 如果成功经历了 k 次且都在坏人区间：输出 m，结束
3. 继续 m++

### 复杂度

O(答案 × k²)，k < 14 时极快。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int k;
bool alive[28];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>k;
	for(int m=k+1;;++m)
	{
		fill_n(alive,2*k,true);
		int pos=0,ok=1;
		for(int i=0;i<k;++i)
		{
			int cnt=0;
			while(1)
			{
				if(alive[pos])
				{
					++cnt;
					if(cnt==m)break;
				}
				pos=(pos+1)%(2*k);
			}
			if(pos<k)
			{
				ok=0;
				break;
			}
			alive[pos]=0;
			while(!alive[pos])
				pos=(pos+1)%(2*k);
		}
		if(ok)
		{
			cout<<m<<'\n';
			return 0;
		}
	}
}
```
