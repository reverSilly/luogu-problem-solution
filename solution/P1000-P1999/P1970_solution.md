# P1970 [NOIP 2013 提高组] 花匠

## 1. 重新读题

### 1.1 问题重述（人话版）

给出高度序列 $h_1..h_n$。删掉一些花（位置保持原相对顺序），留下 $g_1..g_m$，要求满足下面两条中至少一条：

- **条件 A**：$g_1<g_2>g_3<g_4>\cdots$（先升后降交替，偶数位置是「峰」）；
- **条件 B**：$g_1>g_2<g_3>g_4<\cdots$（先降后升交替，偶数位置是「谷」）。

求最多能留下多少株，即最长「摆动子序列」的长度。

注意 $m=1$ 时两条都满足，$m>1$ 时两条互斥（分别对应第一步向上/向下）。

### 1.2 关键约束与规模暗示

- $n\le 10^5$，$0\le h_i\le 10^6$，且**数据随机生成**（均匀分布）。
- $20\%$：$n\le 10$；$30\%$：$n\le 25$，可以枚举子集；$70\%$：$n\le 1000$，允许 $O(n^2)$ 的 DP。
- $100\%$：$n=10^5$，需要 $O(n)$ 或 $O(n\log n)$。
- 注意高度可以相等；相等的高度不能构成「严格上升/下降」的一步。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先去掉「相等」的干扰

条件里的不等号都是**严格**的，所以相邻两个被留下的高度相等是不允许的。

**引理 1（删除连续相等的元素不改变答案）**：把原序列中每一段连续相等的值压缩成一个数，得到 $c_1..c_m$（相邻 $c_i\ne c_{i+1}$），则最长摆动子序列长度不变。

**证明**：

- **压缩序列的摆动子序列能还原**：每个 $c_i$ 对应原序列中一个连续相等的「段」。按子序列顺序，从每段任取一个原位置，段与段在原序列中先后有序，取出的位置也递增。由于比较关系只依赖数值，还原后的序列与压缩序列逐项相等，仍然是摆动的。
- **原序列的摆动子序列能压缩**：把每个被选中的位置映射到它所在的段号。先说明同一个段里至多被选中一次：若同一段（数值全相等、位置连续）里选中了两个位置，那么这两个位置之间原序列的所有位置也都在该段内，数值全部相等；于是被选中的这段子序列中相邻两项（至少这两项之间）会出现相等，严格摆动不可能。因此段号互不相同、严格递增。映射后的数值恰是原来的数值，比较关系不变，仍是压缩序列的摆动子序列，长度相同。

两个方向都保持了长度，故最长长度相等。$\square$

于是可以假设相邻元素都不相等。

### 2.2 朴素 DP：$O(n^2)$

设 $u_i$ = 以位置 $i$ 结尾、最后一步是**上升**的最长摆动子序列长度；$d_i$ = 最后一步是**下降**的长度。单元素长度 $1$ 两种都算。

$$
u_i=1+\max\{d_j:\ j<i,\ c_j<c_i\},\qquad
d_i=1+\max\{u_j:\ j<i,\ c_j>c_i\}.
$$

这是 $O(n^2)$，能过 $70\%$ 的 $n\le1000$。但 $n=10^5$ 不够。

### 2.3 优化：只需要「前一个位置」

关键观察：在相邻不等的序列里，处理到 $i$ 时，最优值只可能由 $i-1$ 更新，或者原地继承。于是定义**前缀最优**：

- $U_i$：$c_1..c_i$ 中最长的、最后一步为上升（或长度为 $1$）的摆动子序列长度；
- $D_i$：同理，最后一步为下降（或长度为 $1$）。

这里和 2.2 的区别是：**不要求结尾正好在 $i$**，只要求整个子序列落在前缀 $i$ 内。这个改动让状态单调不减，转移才能只看 $i-1$。

**引理 2（转移）**：对 $i\ge2$，

$$
\begin{cases}
c_i>c_{i-1}: & U_i=\max(U_{i-1},\ D_{i-1}+1),\quad D_i=D_{i-1},\\[2mm]
c_i<c_{i-1}: & D_i=\max(D_{i-1},\ U_{i-1}+1),\quad U_i=U_{i-1}.
\end{cases}
$$

**证明**：只证 $c_i>c_{i-1}$ 的情形，另一种完全对称。

**（1）$D_i=D_{i-1}$。**
$D_i\ge D_{i-1}$ 显然（前缀变长）。反之，任取一条结尾为下降、落在前缀 $i$ 内的摆动子序列。
- 若它不使用 $c_i$，则落在前缀 $i-1$ 内，长度 $\le D_{i-1}$。
- 若它把 $c_i$ 作为最后一个元素且长度 $\ge2$，则最后一步是从某个 $c_j$ 下降到 $c_i$，即 $c_j>c_i$，$j<i$。因为 $c_i>c_{i-1}$，有 $c_j>c_{i-1}$；且 $j\ne i-1$（否则 $c_{i-1}<c_i$，是上升而非下降），故 $j\le i-2$。把最后一个元素 $c_i$ 换成 $c_{i-1}$：这一步仍是下降（$c_j>c_i>c_{i-1}$），序列长度不变且落在前缀 $i-1$ 内，所以长度 $\le D_{i-1}$。
- 若长度为 $1$（只有 $c_i$），则 $1\le D_{i-1}$。

故 $D_i\le D_{i-1}$，等号成立。

**（2）$U_i\le\max(U_{i-1},D_{i-1}+1)$。**
任取一条结尾为上升、落在前缀 $i$ 内的摆动子序列，长度 $L$。
- 若不用 $c_i$：$L\le U_{i-1}$。
- 若用 $c_i$ 作最后元素：若 $L=1$，则 $L\le U_{i-1}$（$U_{i-1}\ge1$）。否则最后一步从 $c_j$ 上升到 $c_i$，$c_j<c_i$，$j<i$，且去掉 $c_i$ 后的前缀序列以 $c_j$ 结尾、最后一步为下降（或长度为 $1$）。
  - $j=i-1$：前缀长度 $L-1\le D_{i-1}$，所以 $L\le D_{i-1}+1$。
  - $j\le i-2$：前缀长度为 $L-1$，结尾下降于 $c_j$。
    * 若 $L-1=1$（即 $L=2$）：$L\le D_{i-1}+1$。
    * 否则前缀的最后一步是从某个 $c_k$ 下降到 $c_j$，$c_k>c_j$。
      + 若 $c_j<c_{i-1}$：在「结尾于 $c_j$ 的下降序列」后接上 $c_{i-1}$，这一步是上升（$c_j<c_{i-1}$），得到一条结尾上升、长度为 $L$ 的序列，落在前缀 $i-1$ 内，故 $L\le U_{i-1}$。
      + 若 $c_j>c_{i-1}$：把前缀末尾的 $c_j$ 换成 $c_{i-1}$。因为 $c_k>c_j>c_{i-1}$，这一步仍是下降，得到长度为 $L-1$ 的下降结尾序列，落在前缀 $i-1$ 内，故 $L-1\le D_{i-1}$，即 $L\le D_{i-1}+1$。
      + 若 $c_j=c_{i-1}$：把 $c_j$ 换成 $c_{i-1}$（数值不变，位置合法），同理得到长度为 $L-1$ 的下降结尾序列，$L\le D_{i-1}+1$。

三种情况都归入 $U_{i-1}$ 或 $D_{i-1}+1$，故上界成立。

**（3）$U_i\ge\max(U_{i-1},D_{i-1}+1)$。**
$U_i\ge U_{i-1}$ 显然。对 $D_{i-1}+1$：取一条长度 $D_{i-1}$、结尾下降的序列 $S$（若 $D_{i-1}=1$ 就取单个元素）。
- 若 $S$ 的末值 $<c_i$：直接接上 $c_i$，得到上升结尾、长度 $D_{i-1}+1$。
- 若末值 $\ge c_i$：若 $S$ 只有一个元素，把它换成 $c_{i-1}$（因为 $c_i>c_{i-1}$，且单元素时没有前驱约束），再接 $c_i$，得到长度 $2=D_{i-1}+1$（此时 $D_{i-1}=1$）。
- 若 $S$ 长度 $\ge2$：设最后一步为 $c_k\to c_j$（$c_k>c_j\ge c_i>c_{i-1}$）。把末元素 $c_j$ 换成 $c_{i-1}$，由于 $c_k>c_{i-1}$，仍是下降结尾、长度不变，得到长度 $D_{i-1}$、末值 $c_{i-1}<c_i$ 的下降序列，再接 $c_i$ 变成上升，长度 $D_{i-1}+1$。

故 $U_i\ge D_{i-1}+1$。结合 (2) 得 $U_i=\max(U_{i-1},D_{i-1}+1)$。$\square$

### 2.4 去掉 $\max$：得到 $O(n)$ 贪心

**引理 3**：在引理 2 的转移中，上升时 $U_{i-1}\le D_{i-1}+1$，故 $U_i=D_{i-1}+1$；下降时对称地 $D_i=U_{i-1}+1$。

**证明**：对 $i$ 归纳证明不变量 $U_i\le D_i+1$ 与 $D_i\le U_i+1$。$i=1$ 时 $1\le2$。上升一步：$U_i=\max(U_{i-1},D_{i-1}+1)$。由 $D_i=D_{i-1}$ 与归纳假设 $U_{i-1}\le D_{i-1}+1=D_i+1$，得 $U_i\le D_i+1$；又 $D_i=D_{i-1}\le U_{i-1}+1\le U_i+1$。下降步对称。$\square$

于是只需维护两个数：

$$
\texttt{up}=U_i,\qquad \texttt{down}=D_i,
$$

每遇到一个上升步 `up=down+1`，每遇到下降步 `down=up+1`，相等步不动。答案是 $\max(\texttt{up},\texttt{down})$。

### 2.5 另一种刻画：数「拐点」

压缩后的序列由若干段**单调区间**拼成。每进入一个新单调段（方向改变一次），就多一个局部极值。可以验证

$$
\text{答案}=\begin{cases}
1, & m=1,\\
(\text{方向改变次数})+2, & m\ge2.
\end{cases}
$$

例如 $[5,1,2]$ 方向为「降、升」，改变 $1$ 次，答案 $1+2=3$，正是样例。这个刻画和 DP 是等价的：每次方向改变恰好让对应的 `up` 或 `down` 增加，最终最大值就是「段数 $+1$」。写代码时用 DP 更直接，也不怕相等元素。

### 2.6 坑点

- 相等元素：既不算上升也不算下降，直接跳过；不能写成 `up=down+1`。
- $n=1$：答案 $1$。
- 条件 A、B 只是「先升」或「先降」两种起点，DP 的 `max(up,down)` 同时覆盖。
- 答案最大为 $n$，`int` 足够。

---

## 3. 模式总结（Pattern Summary）

- **explore its property** — 条件 A/B 就是严格摆动的两种起点，问题是最长摆动子序列。
- **reduce to easier problem** — 先压缩连续相等元素，使相邻必不相等，答案不变。
- **state design** — 前缀最优的「结尾上升 / 结尾下降」两状态，避免 $O(n^2)$ 枚举前驱。
- **exchange argument** — 证明转移只需看 $i-1$：任何用到更早元素的最优解都能改写到 $i-1$ 附近。
- **classic problem solution** — 两变量滚动 DP，$O(n)$；等价于数单调段/拐点。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 花的株数 | 读入 | 规模 |
| `prv` | `int` | 上一个读入的高度 $h_{i-1}$ | 第一个 $h$ | previous |
| `h` | `int` | 当前高度 | 逐项读入 | height |
| `up` | `int` | 最长「结尾上升或长度 1」的摆动子序列长度 | $1$ | up |
| `down` | `int` | 最长「结尾下降或长度 1」的摆动子序列长度 | $1$ | down |
| `ans` | `int` | $\max(\texttt{up},\texttt{down})$ | — | answer |

### 4.2 算法步骤

1. 读入 $n$ 与 $h_1$，令 `prv=h_1`，`up=down=1`。
2. 对 $i=2..n$：读入 `h`。
   - 若 `h>prv`：`up=down+1`；
   - 若 `h<prv`：`down=up+1`；
   - 若相等：不做任何事。
   - 然后 `prv=h`。
3. 输出 `max(up,down)`。

### 4.3 复杂度分析

- **时间**：$O(n)$。
- **空间**：$O(1)$。

---

## 5. 示例代码

```cpp
//
// 题目：P1970 [NOIP 2013 提高组] 花匠
// https://www.luogu.com.cn/problem/P1970
#include<bits/stdc++.h>
using namespace std;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	int prv;
	cin>>prv;
	int up{1},down{1};
	for(int i=1,h;i<n;++i)
	{
		cin>>h;
		if(h>prv)
			up=down+1;
		else if(h<prv)
			down=up+1;
		prv=h;
	}
	cout<<max(up,down)<<'\n';
	return 0;
}
```
