## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制 —— "重复只算一个"把段的价值变成集合大小

记背诵词集合为 $T$（$|T|=D$，去重后的种数）。对 $0\le l\le r<m$，令

$$S(l,r)=\{w\in T:\ text[l..r]\text{ 中至少出现一次 }w\},\qquad v(l,r)=|S(l,r)|.$$

约定 $l>r$ 时 $S(l,r)=\varnothing$，$v=0$。

先看清 $v$ 和"窗口里有多少个背诵词"是两回事。拿主例（下文 4.3 沿用）$n=3$、$T=\{a,b,c\}$、文章 `a x b a c x b` 试几个段：段 $[3,4]$=`a c` 里有 2 个背诵词、$v=2$；段 $[0,4]$=`a x b a c` 里有 4 个背诵词（a 出现两次）但 $v=3$——**加词不一定涨 $v$，减词不一定掉 $v$**，$v$ 是个"集合大小"，不可加、不能靠前缀和差分。所以第一反应"统计段内背诵词个数最大"的方向是错的，要盯住**种类**。

$v$ 的两条单调性是后面一切的地基：

**引理 1（单调性）** 固定 $r$，$v(l,r)$ 关于 $l$ 不增；固定 $l$，$v(l,r)$ 关于 $r$ 不减。
**证明**：固定 $r$，$l\to l+1$ 相当于从段里拿掉 $\text{text}[l]$ 这一个位置，剩下位置的出现词集合是原来的子集，故 $S(l+1,r)\subseteq S(l,r)$，$v$ 不增。固定 $l$，$r\to r+1$ 多一个位置，$S(l,r)\subseteq S(l,r+1)$，$v$ 不减。$\blacksquare$

再记一个全程用得上的上界：$v(l,r)\le K$ 对一切 $l,r$ 成立。因为它数的是"出现过的背诵词种类"，任何段都是文章的一部分，种类不会超过全文出现过的种类数 $K$。下面多处"又 $v\le K$，故 $v=K$"都是这一句。

### 2.2 第一问直接塌缩 —— 最长段就是最优段

**引理 2（第 1 行的值）** $\max_{l,r} v(l,r)=v(0,m-1)=K$，其中 $K=|\{w\in T:\text{文章中出现过 }w\}|$。
**证明**：任取一段 $[l,r]$，$S(l,r)\subseteq S(0,m-1)$（一段是全文的子集），故 $v(l,r)\le v(0,m-1)$；而 $[0,m-1]$ 本身是合法的段（$l=0,r=m-1$），所以这个上界被取到。$v(0,m-1)$ 按定义就是"文章里出现过的背诵词种数" $K$。$\blacksquare$

这一步等于把"两问"拆成一问：第 1 行**根本不用窗口**，一趟全文统计即可；剩下的全部难度都压在"长度最小"上。顺手记下坑：$K\le D\le n\le1000$，三个数一般互不相等——背诵表有重复则 $D<n$；表里的词文章没出现则 $K<D$。主例里 $K=D=n=3$ 太巧合，边界 A（表 `a b`、文章 `a a a`）就有 $n=2,D=2,K=1$。若误用 $D$（或 $n$）当"要凑满的种数"，第二问的窗口永远凑不满，`while(now==K)` 永不成立，ans 停在初始哨兵值 $1145141919$，直接 WA。

### 2.3 朴素法与瓶颈 —— 第二问是"覆盖型最小窗口"

第二问重述：在 $\{[l,r]: v(l,r)=K\}$ 中求 $r-l+1$ 的最小值。朴素做：枚举 $l$，$r$ 从 $l$ 递增并维护 $\text{cnt}[\text{id}]$（该词在窗口内出现次数）与 $\text{now}=v(l,r)$，一旦 $\text{now}=K$ 更新答案并 break。每段 $O(1)$ 摊还、共 $O(m^2)$ 段。拿三档数据算账：

| 档 | $n,m$ | 朴素 $O(m^2)$ | 判定 |
|---|---|---|---|
| 30% | $50,500$ | $2.5\times10^5$ | 秒过 |
| 60% | $300,5000$ | $2.5\times10^7$ | 可过（无需优化） |
| 100% | $1000,10^5$ | $10^{10}$ | 超时 |

瓶颈很明确：**每个 $l$ 都从头重扫**，而 2.1 的单调性说明"$l$ 变大只会让 $v$ 变小"——上一次扫到哪儿，下一次接着扫就行，不必清零重来。这就是双指针的入口。

### 2.4 化简 —— 固定右端点，左端点该"贴多紧"

**引理 3（左端点的可行集是前缀区间，且最优左端点唯一）** 固定 $r$，设 $F_r=\{l\in[0,r]: v(l,r)=K\}$。则 $F_r$ 若非空，形如 $\{0,1,\dots,l^*(r)\}$，其中 $l^*(r)$ 是 $F_r$ 的最大元；且以 $r$ 为右端点的最短可行段**唯一**为 $[l^*(r),r]$。
**证明**：$v$ 关于 $l$ 不增（引理 1）$\Rightarrow$ $l$ 可行则任何更小的 $l'\le l$ 有 $v(l',r)\ge v(l,r)=K$，而 $v\le K$ 恒成立（$S\subseteq T$ 且只有 $K$ 种出现过），故 $v(l',r)=K$，即可行集向下封闭 $\Rightarrow$ 形如前缀区间。$l^*(r)$ 作为有限非空整数集的最大元唯一存在。长度 $r-l+1$ 关于 $l$ 严格递减 $\Rightarrow$ 右端点固定时最短即取 $l=l^*(r)$，唯一。$\blacksquare$

**操作序的唯一性（"删除"步骤没有歧义）**：从 $[l,r]$ 出发把左端点一格一格右移，每步判 $v$ 是否仍为 $K$；因为可行集是**连续前缀**，判定结果随 $l$ 一次翻转（先真后假、不会反复），所以"停在哪儿"由 $(r,\text{进入时的 }l)$ 完全决定：要么一路推到 $l^*(r)$，要么进来的 $l$ 已越过 $l^*(r)$（此时一步都不删）。删除次序本身就是 $l,l+1,l+2,\dots$ 的唯一升序序列，**不存在"先删哪个"的分支**，也就无从重复删同一个位置。这就是本算法"删除类操作"的确定性来源，下面 2.5、2.6 把"不重"（次数上界）与"不漏"（不丢最优段）分别证掉。

### 2.5 双指针合法吗 —— $l^*(r)$ 单调不减

**引理 4** $l^*(r)\le l^*(r+1)$（约定 $F_r=\varnothing$ 时 $l^*(r)=-1$，则 $-1\le l^*$ 自动成立）。
**证明**：若 $F_r=\varnothing$ 平凡。否则记 $l_0=l^*(r)$，有 $v(l_0,r)=K$。固定左端点右移右端点时 $v$ 不减（引理 1）：$v(l_0,r+1)\ge v(l_0,r)=K$，又 $v\le K$，故 $v(l_0,r+1)=K$，即 $l_0\in F_{r+1}$。而 $l^*(r+1)$ 是 $F_{r+1}$ 的最大元，故 $l^*(r+1)\ge l_0$。$\blacksquare$

反过来说：$r$ 前进时，"上一轮的 $l^*$"对新右端点仍然可行，所以左端点没有任何理由往回退——往回退只会让段更长（引理 3 里长度关于 $l$ 严格递减），不可能更优。

**引理 5（不重：操作次数）** 整趟执行中，右端进窗操作恰 $m$ 次，左端出窗操作总数 $\le m$，故窗口维护总量 $\le 2m$。
**证明**：外层 $r$ 从 $0$ 到 $m-1$ 逐 1 递增，每个下标进窗恰好一次，计 $m$ 次。$l$ 只在内层 `++l` 时增加（每次 $+1$），初值 $0$；`++l` 之前必有 $v(l,r)=K\ge1$（循环条件），即窗口非空、$l\le r\le m-1$，故 `++l` 后 $l\le m$，总增量 $\le m-0=m$，即每个位置**至多被删出窗口一次**（同一下标不可能被 $l$ 跨过两次，因为 $l$ 严格增）。$\blacksquare$

这同时给出时间下界意义上的"划算"：朴素法对每个 $l$ 重扫，累计可达 $\sum_l (m-l)=O(m^2)$；双指针把同一个位置的重复扫描彻底消掉。

### 2.6 正确性（"不漏"）—— 算法答案等于真最优

算法骨架：$l\leftarrow 0$，$\text{now}\leftarrow 0$；对 $r=0..m-1$：加入 $\text{id}[r]$ 并更新 now；然后 `while now==K`：用 $r-l+1$ 松弛 ans，删 $\text{id}[l]$ 出窗、更新 now、$l\leftarrow l+1$。

**引理 6（内层循环恰好算出 $l^*(r)$，且不评价空窗）** 设第 $r$ 轮进入内层时左端为 $l_{\text{in}}$、窗口为 $[l_{\text{in}},r]$。若 $v(l_{\text{in}},r)=K$，则循环结束时 $l=l^*(r)+1$，且被松弛过的左端点恰为 $\{l_{\text{in}},l_{\text{in}}+1,\dots,l^*(r)\}$，每个被松弛的段都满足 $v=K$ 且长度 $\ge1$。
**证明**：
- *可行性*：循环条件在进入循环体时判定 `now==K`，而 $\text{now}=v(l,r)$（不变量见本小节末），故每次松弛时 $v(l,r)=K$。
- *长度 $\ge1$*：反设某次进入循环体时 $l=r+1$，则窗口为空、$v=0$，与 $K\ge1$ 时"进入体需 $v=K$"矛盾。故 $l\le r$，$r-l+1\ge1$；同时 `id[l]` 的下标也在 $[0,m-1]$ 内，不越界。
- *停在哪*：$l$ 每次 $+1$，第一个使 $v(l,r)\ne K$ 的 $l$ 即 $l^*(r)+1$——由引理 3 的"可行集是前缀 $\{0..l^*\}$"，可行性关于 $l$ 是"一段真、之后恒假"，$l$ 逐 1 递增必先经历所有真值再撞上第一个假值而停；若从 $l_{\text{in}}>l^*(r)$ 起步，则一开始就假、循环体一次都不执行（结论退化为"无松弛"）。
- *覆盖范围*：$l_{\text{in}}\le l^*(r)$ 时，循环体的执行时刻 $l$ 取遍 $l_{\text{in}},l_{\text{in}}+1,\dots,l^*(r)$，中间无跳跃（每次只 $+1$）。$\blacksquare$

**引理 7（左端点位置）** 记第 $r$ 轮进入内层时的左端点为 $l_{\text{in}}(r)$（$l_{\text{in}}(0)=0$）。则对 $r\ge1$ 恒有 $l_{\text{in}}(r)\le l^*(r-1)+1$。
**证明**：对 $r$ 归纳。第 $r-1$ 轮内层跑完后的 $l$ 就是 $l_{\text{in}}(r)$，只有两种来历：
- 循环体执行过：由引理 6，结束时 $l=l^*(r-1)+1$，恰取等号 ✓。
- 循环体一次未执行：$l$ 保持不变，$l_{\text{in}}(r)=l_{\text{in}}(r-1)$。若 $r-1=0$，$l_{\text{in}}(r)=0\le l^*(0)+1$ ✓；否则由归纳假设 $l_{\text{in}}(r-1)\le l^*(r-2)+1$，再用引理 4 的 $l^*(r-2)\le l^*(r-1)$，得 $l_{\text{in}}(r)\le l^*(r-1)+1$ ✓。
两种情形都成立，归纳完成。$\blacksquare$

**引理 8（不漏：全局最短必在"$l^*$ 平台起点"被记录）** 记 $b(r)=r-l^*(r)+1$（$F_r\ne\varnothing$ 时），则 $\text{opt}=\min_r b(r)$，且 $\min_r b(r)$ 在某个"满足 $r=0$ 或 $l^*(r)>l^*(r-1)$"的右端点上取到；对这样的 $r$，第 $r$ 轮循环体必然执行并松弛到 $l=l^*(r)$，即 $b(r)$ 一定进过 ans。
**证明**：
- *$\text{opt}=\min_r b(r)$*：固定 $r$，右端点为 $r$ 的可行段中最短者是 $[l^*(r),r]$（引理 3），故 $\text{opt}=\min_{r}\min_{l\in F_r}(r-l+1)=\min_{r:F_r\ne\varnothing} b(r)$。又 $F_{m-1}\ne\varnothing$（全文可行），集合非空。
- *沿平台 $b$ 严格递增*：若 $l^*(r+1)=l^*(r)$（二者都 $\ge0$，即两侧可行集都非空），则 $b(r+1)=(r+1)-l^*(r+1)+1=b(r)+1>b(r)$。再由引理 4 的"不降"，同一取值 $L$ 的原像 $\{r:l^*(r)=L\}$ 必是**一段连续区间**（不降函数的等值集不可能断开：若 $r_1<r_2<r_3$ 且首尾都取 $L$，中间值被夹在 $L\le l^*(r_2)\le L$ 之间也只能是 $L$），称之为一座"平台"。上一条说明 $b$ 在平台上从左到右严格增，故 $\min b$ 一定落在某座平台的**左端点**。
- *平台左端点必被松弛*：设 $r^\dagger$ 是平台左端点，则 $r^\dagger=0$ 或 $l^*(r^\dagger-1)<l^*(r^\dagger)$（否则它左边同值、就不是左端点）。前者的 $l_{\text{in}}(0)=0\le l^*(0)$；后者由引理 7，$l_{\text{in}}(r^\dagger)\le l^*(r^\dagger-1)+1\le l^*(r^\dagger)$。两种情形都有 $l_{\text{in}}(r^\dagger)\le l^*(r^\dagger)$，即可行集 $\{0..l^*(r^\dagger)\}$ 包含 $l_{\text{in}}$，进入内层时 $\text{now}=v(l_{\text{in}},r^\dagger)=K$、循环体执行；再由引理 6 的覆盖范围，松弛的左端点取遍到 $l^*(r^\dagger)$，故 $b(r^\dagger)$ 被记入 ans。$\blacksquare$

（这条处理双指针最容易糊弄过去的缺口：$l$ 已经走过、在新右端点下"重新可行"的左端点，算法确实不再回头考虑。但"重新可行"只可能伴随 $l^*$ 增大，而 $l^*$ 增大时 $b$ 变小、$l$ 又一定停在可行区里，所以新的更短候选照样被记录；$l^*$ 不变（同一平台）时 $b$ 反而变大，本来就不可能是全局最优。两个方向合起来 = **不漏**。）

**引理 9（答案 $=$ 最优）** 设 $\text{ans}$ 为算法输出，$K\ge1$。则 $\text{ans}=\text{opt}$。
**证明**（双向夹）：
- $\text{ans}\ge\text{opt}$：由引理 6 的"可行性"，每个被松弛的段都满足 $v=K$，都是 $\text{opt}$ 定义域里的元素；$\text{ans}$ 是它们中最小的长度，故 $\text{ans}\ge\text{opt}$。
- $\text{ans}\le\text{opt}$：取引理 8 中使 $b(r^\dagger)=\text{opt}$ 的平台左端点 $r^\dagger$，该轮把 $b(r^\dagger)$ 松弛进 ans，故 $\text{ans}\le b(r^\dagger)=\text{opt}$。
两向合并 $\text{ans}=\text{opt}$。且 $\text{opt}\le b(m-1)=m-1-l^*(m-1)+1\le m\le10^5$，$\text{ans}$ 必被更新过，不会停在哨兵 $1145141919$。$\blacksquare$

**$\text{now}$ 不变量的证明**（不是"显然"，它正是"不漏"的账本）：断言 $\text{now}=\big|\{x\in[1,D]:\text{cnt}[x]>0\}\big|=v(l,r)$。
- *初始化*：$l=0,r=-1$（空窗）时 $\text{cnt}$ 全 0、$\text{now}=0$，$v=0$，成立。
- *进窗 $x=\text{id}[r]\ne0$*：$\text{cnt}[x]$ 从 $c$ 变 $c+1$。$S(l,r)$ 相对 $S(l,r-1)$ 只可能多一个 $x$，且"多"当且仅当 $c=0$；代码 `++cnt[x]==1` 恰好在 $c=0$ 时为真并 $\text{now}+1$。$\text{id}[r]=0$（不用背的词）根本不在 $T$ 中，对 $S$ 无贡献，代码用 `if(id&&...)` 跳过。
- *出窗 $x=\text{id}[l]\ne0$*：$\text{cnt}[x]$ 从 $c\ge1$ 变 $c-1$；$x$ 从 $S$ 中消失当且仅当 $c=1$（窗口里只有它一个 $x$），代码 `--cnt[x]==0` 恰在此时 $\text{now}-1$。
两类操作各改动一个 $\text{cnt}$、至多改动一次 $\text{now}$，与集合 $S$ 的变化严格同步，故对操作序列归纳，不变量恒成立。$\blacksquare$

### 2.7 字符串怎么办 —— 离散化成小整数（"哈希"标签）

词只含小写字母、长度 $\le 10$。把字符映射成 $1..26$，按 27 进制压成一个整数：

$$\text{enc}(c_0c_1\dots c_{t-1})=\sum_{i=0}^{t-1}(c_i-\texttt{'a'}+1)\cdot 27^{\,t-1-i}.$$

**引理 10（$\text{enc}$ 单射）** 不同字符串编码不同。
**证明**：编码的每个数位 $d_i\in[1,26]$，不含 0 位。若 $\text{enc}(A)=\text{enc}(B)$，把这个整数写成标准 27 进制表示——标准表示**唯一**且无前导 0，故 $A,B$ 的 27 进制数位序列完全相同；序列相同 ⇒ 位数（长度）相同、逐位相同 ⇒ 两串逐字符相同（$d\mapsto \texttt{'a'}+d-1$）。反言之 $A=B$。$\blacksquare$

（关键就是"不用 0 位"：若把 'a' 编码成 0，"a" 与 "aa"、以及任何带前导 0 的串就会撞车。）

有了单射，字符串比较变成 $O(1)$ 整数比较。背诵表：读入 $n$ 个 enc 值 → `sort` → `unique`（这一步顺手完成 2.2 的"列表内重复折叠"）得到 $D$ 个有序互异的 $w[0..D-1]$。文章第 $i$ 个词：`lower_bound` 命中则 $\text{id}=k+1$，否则 $\text{id}=0$ 表示"不用背"，$1..D$ 是下标 +1（0 留给"非背诵词"，这样 `if(id&&...)` 一句就能跳过它，且 $\text{cnt}$ 只需开 $D+1$ 格）。

替代方案：`unordered_map<string,int>` 期望 $O(1)$ 查询但退化到 $O(D)$（最坏 $10^5\times10^3=10^8$ 次字符串比较，不稳）；`map<string,int>` 稳但每次 $O(D\text{ 比较})\cdot O(\log n)$。排序 + 二分是 $O(n\log n+m\log n)$、纯静态数组、无退化风险，最贴本题规模。

**溢出预算**（决定类型）：
- $\text{enc}$：词长 $\le 10$，$\text{enc}<27^{10}=3^{30}=205\,891\,132\,094\,649\approx2.06\times10^{14}$，而 `i64` 上限 $2^{63}-1\approx9.22\times10^{18}$，余量 $4.5\times10^4$ 倍；即使词长写到 13 仍有 $27^{13}\approx4.05\times10^{18}<9.22\times10^{18}$，到 14 位（$\approx1.1\times10^{20}$）才溢出。⇒ 用 `i64`，`int` **不够**。
- 其余量：$K\le D\le n\le10^3$；$\text{cnt}[x]\le m\le10^5$；$\text{now}\le K\le10^3$；$r-l+1\le m\le10^5$；哨兵 `ans=1145141919<2^{31}-1=2\,147\,483\,647$。int 代码路径里只有 $+1/-1$ 与比较，**无乘法**，不可能溢出。

### 2.8 标签里的"二分" —— 另一条等价路线（以及为什么最后不用它）

把答案当成"长度 $\ell$"来二分。判定 $\text{check}(\ell)$：存在 $l$ 使 $v(l,l+\ell-1)=K$。

**引理 11（$\text{check}$ 对 $\ell$ 单调不增）** 若 $\text{check}(\ell)$ 真（$1\le\ell<m$），则 $\text{check}(\ell+1)$ 真。
**证明**：取可行段 $[l,l+\ell-1]$。因 $\ell<m$，$l+\ell\le m$ 与 $l\ge 1$ 中至少可扩一侧：若 $l+\ell<m$ 用 $[l,l+\ell]$，否则 $l\ge 1$ 用 $[l-1,l+\ell-1]$，两者长度都是 $\ell+1$，且都是原段的超段 ⇒ $v\ge v(\text{原})=K$，又 $\le K$，故 $=K$。$\blacksquare$

于是二分最小可行 $\ell$，每次 $\text{check}$ 用定长滑窗 $O(m)$ 维护 now ⇒ 总 $O(m\log m)\approx1.7\times10^6$，同样过。但它需要"窗口平移"的写法和二分边界口径（$[\ell,m]$ 区间内找最小可行），比 2.6 的双指针多一层，而且双指针已经把最优性证干净、复杂度还更优 $O(m)$，故实现取双指针；"二分"作为思路备用与交叉验证手段（4.3 用它复核）。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — "重复只算一个" ⇒ 段价值是**种数** $v(l,r)$，先证它对两端单调（引理 1），后面全部结论都从这一条长出来。
- **consider easier question（第一问）** — 单调性立刻给出"全文即最优段"，第 1 行退化成一次全文统计 $K$（引理 2）；顺带暴露 $K\le D\le n$ 的三层坑。
- **reduce to easier problem** — 第 2 行改写成经典"覆盖型最小窗口"：找最短连续段含满 $K$ 种。
- **explore its property（固定一端）** — 固定右端点时可行左端点集是**连续前缀**，最短段唯一 $[l^*(r),r]$（引理 3），删除操作序因此无歧义。
- **classic problem solution** — 滑动窗口/双指针：$l^*(r)$ 单调不减（引理 4）保证 $l$ 只前进，每词进窗恰一次、出窗至多一次（引理 5）⇒ $O(m)$。
- **prove 不重不漏** — 引理 6（内层循环恰算出 $l^*(r)$、不评价空窗）→ 引理 7（$l_{\text{in}}(r)\le l^*(r-1)+1$）→ 引理 8（"$l^*$ 平台"上 $b$ 严格增，故全局最短必落在平台左端点且那里循环必执行，堵死"不回头也算漏"的缺口）→ 引理 9（双向夹 $\text{ans}=\text{opt}$）。
- **classic problem solution（第二次：离散化）** — 字母表 $1..26$ 的 27 进制编码做**单射**哈希（引理 10），`sort+unique` 去重、`lower_bound` 得 id，纯静态数组零退化风险。
- **budget before coding** — 先算 enc $<27^{10}\approx2.06\times10^{14}$ ⇒ `i64`；其余量 $\le10^5$ ⇒ `int`；哨兵 $1145141919<2^{31}-1$。
- **alternative route kept as cross-check** — 对答案长度二分 + 定长滑窗判定（引理 11），$O(m\log m)$，用作手算互验与"二分"标签的对应实现。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n,m,D,K` | 表长、文章长、**去重后**背诵种数、**文章中出现过**的背诵种数（=第 1 行答案） | `int`，全局 0 | $K\le D\le n$ |
| `w[mxn]` | 背诵表编码值，已 `sort+unique`，$w[0..D-1]$ 升序互异 | `i64`，全局 0 | 27 进制、数位 1..26（引理 10） |
| `id[mxm]` | 文章第 $i$ 个词的字典 id：$1..D$ 命中，$0$ 不用背（**0-based**） | `int`，全局 0 | 查表用 `lower_bound` |
| `tot[mxn]` | 该 id 在**全文**出现次数（只为算 $K$，窗口不用） | `int`，全局 0 | `++tot[x]==1` 时 `++K` |
| `cnt[mxn]` | 该 id 在**当前窗口** $[l,r]$ 内出现次数 | `int`，全局 0 | 跨 0 才改 `now` |
| `now` | 当前窗口的种数 $v(l,r)$ | `int`=0 | 循环条件 `now==K` |
| `l,r,ans` | 左指针、右指针、最短覆盖段长度 | `ans=1145141919` | 答案是"单词个数" |

### 4.2 算法步骤

1. 读 $n$，逐个编码进 `w`；`sort(w,w+n)`；`D=unique(...)-w`（列表去重）。
2. 读 $m$，逐个 `enc`+`lower_bound` 得 `id[i]`；命中则 `if(++tot[id[i]]==1)++K;`。先输出 `K`（第 1 行，引理 2）。
3. **退化分支 $K=0$**：文章里一个背诵词都没有。此时"含满 0 种"的最短段按**空段**口径记长度 0（我们的选择），直接输出 `0`；若采用"段落必须非空"口径则答案恒为 1。题面未规定、又无样例可对标，取空段口径并显式短路——**必须短路**，否则 `while(now==K)` 在 $K=0$ 时永不退出（空窗仍满足 $0==0$，$l$ 一路冲出右边界）。
4. **双指针**：`for r=0..m-1`：先加 `id[r]`（跨 0 则 `++now`）；再 `while(now==K)`：`ans=min(ans,r-l+1)`，把 `id[l]` 移出窗口（由 1 变 0 则 `--now`），`++l`。正确性 = 引理 6（循环恰算出 $l^*(r)$）+ 引理 8（不漏）+ 引理 9（$\text{ans}=\text{opt}$）；$K\ge1$ 时循环内恒有 $l\le r$，故 `id[l]` 不越界（引理 6 的"长度 $\ge1$"条）。
5. 输出 `ans`（第 2 行）。$K\ge1$ 时 $[0,m-1]$ 可行，故 `ans` 一定被松弛过，不会停在哨兵值。
6. **复杂度**：字符编码 $O(m\cdot L)=10^5\times10=10^6$；`sort` $O(n\log_2 n)\approx10^3\times10=10^4$；$m$ 次 `lower_bound` $O(m\log_2 D)\le10^5\times10=10^6$；双指针 $\le 2m=2\times10^5$ 次 $O(1)$ 更新（引理 5 的操作计数）。合计 $\approx3\times10^6$ 次基本操作；空间 $O(m+n)$：`id` $100005\times4\text{B}\approx0.4\text{MB}$、`w/cnt/tot` $\approx20\text{KB}$，$<0.5\text{MB}$。

## 5. 示例代码（C++）

```cpp
// P1381 单词背诵
// 27 进制编码离散化 + 滑动窗口（双指针）求覆盖 K 种的最短连续段
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};        // n<=1000，字典侧（w/cnt/tot）
constexpr int mxm{100005};      // m<=1e5

int n,m,D,K;
i64 w[mxn];                     // 背诵表编码，sort+unique 后取前 D 个
int id[mxm],tot[mxn],cnt[mxn];  // id=0 表示该词不用背
int l,r,now,ans=1145141919;

i64 enc(const string&s)         // 数位 1..26 的 27 进制数：单射（引理 10）
{
	i64 v=0;
	for(char c:s)
		v=v*27+(c-'a'+1);
	return v;
}

int getid(i64 e)                // 命中返回 1..D，未命中返回 0
{
	int k=(int)(lower_bound(w,w+D,e)-w);
	return k<D&&w[k]==e?k+1:0;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	string s;
	for(int i=0;i<n;++i)
	{
		cin>>s;
		w[i]=enc(s);
	}
	sort(w,w+n);
	D=(int)(unique(w,w+n)-w);     // 表内重复折叠成一种

	cin>>m;
	for(int i=0;i<m;++i)
	{
		cin>>s;
		id[i]=getid(enc(s));
		if(id[i]&&++tot[id[i]]==1)
			++K;                  // 第 1 行：文章中出现过的种数（引理 2）
	}
	cout<<K<<'\n';

	if(K==0)                      // 空段口径：没有背诵词就输出 0，且必须短路
	{
		cout<<0<<'\n';
		return 0;
	}

	for(r=0;r<m;++r)              // 窗口 [l,r]，0-based
	{
		if(id[r]&&++cnt[id[r]]==1)
			++now;                // 只在跨 0 时改种数
		while(now==K)             // 能删就删：停在第一个不可行左端点 = l*(r)+1
		{
			if(r-l+1<ans)
				ans=r-l+1;
			if(id[l]&&--cnt[id[l]]==0)
				--now;
			++l;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **静态数组尺寸**：`mxn{1005}`（$n\le1000$ +5）、`mxm{100005}`（$m\le10^5$ +5）。全局 `int` 默认 0 正好是"未出现/空窗口"的合法初值，本题没有"需要预填 INF 的数组"，不存在 `vector`→数组迁移漏 `fill_n` 的坑；唯一的哨兵是 `ans=1145141919`，它 $>10^5$ 恒成立、又 $<2^{31}-1$ 不溢出。
- **`i64 enc`**：词长 $\le10$ ⇒ $\text{enc}<27^{10}\approx2.06\times10^{14}$，`int`（$2.1\times10^9$）装不下，必须 `i64`；累加式 $v=v\cdot27+d$ 的中间量始终 $<27^{10}$，同界。
- **`sort+unique` 代替哈希表**：$O(n\log n+m\log n)$ 且无退化风险；`unique` 顺手把背诵表的重复行折叠（2.7、边界 C）。
- **`id=0` 的妙用**：非背诵词参与**长度**（$r-l+1$ 数的是单词个数）但不参与**种数**，`if(id&&...)` 两个方向都跳过它，`cnt` 也不必为它开格。
- **`while(now==K)` 的循环体顺序**：**先松弛再删**，否则删过头的那一格（$l=l^*(r)+1$，不可行）会被记进答案，见 4.3"循环体顺序陷阱"（对应引理 6 的"被松弛集合恰为 $\{l_{\text{in}},..,l^*(r)\}$"）。$K\ge1$ 保证窗口非空、$l\le r$，`id[l]` 不越界。
- **格式**：Tab 缩进、运算符无空格、`'\n'` 不用 `endl`、`cin.tie/cout.tie/ios::sync_with_stdio` 顺序固定、内部全 0-based（`id[0..m-1]`，长度 $r-l+1$）、函数名小写电报式（`enc`、`getid`）。
