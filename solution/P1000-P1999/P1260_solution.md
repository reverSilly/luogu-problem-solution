# P1260 工程规划 — 题解

## Part 1 — 重新读题

**题目简述**：有 $n$ 个任务（$5 \le n \le 1000$），每个任务有一个起始时间 $T_i$（非负整数）。给出 $m$ 个约束（$5 \le m \le 5000$），形如 $T_i - T_j \le b$（$b \in (-100, 100)$）。求一组满足所有约束的 $T_1, T_2, \ldots, T_n$，要求 $\min_i T_i = 0$（即最早任务与工程同时开始）。若不存在这样的序列，输出 `NO SOLUTION`。

**关键约束**：
- $n \le 1000$，$m \le 5000$ — 图不大
- $b \in (-100, 100)$ — 边权范围很小
- $T_i$ 非负整数，且 $\min T_i = 0$
- Special Judge — 输出不唯一，只要满足约束即可

---

## Part 2 — 思维链（发现过程）

### 2.1 探索性质：不等式的方向

题目给的不等式形如 $T_i - T_j \le b$。我注意到这个形式非常特殊：它只涉及两个变量，且形式为「某变量减去另一变量 ≤ 常数」。这让我立刻联想到图论中的边：如果把每个 $T_i$ 看作一个节点，$T_i - T_j \le b$ 就是"从 $j$ 到 $i$ 的一条权值为 $b$ 的有向边"。

为什么？因为如果从 $j$ 走到 $i$ 的最短路径距离为 $d(j, i)$，那么 $T_i \le T_j + b$ 等价于 $T_i - T_j \le b$，而沿一条路径 $j = v_0, v_1, \ldots, v_k = i$ 上的约束传递：

$$T_{v_k} \le T_{v_{k-1}} + b_{k-1} \le T_{v_{k-2}} + b_{k-2} + b_{k-1} \le \cdots \le T_{v_0} + \sum_{r=0}^{k-1} b_r$$

也就是说，沿路径累积的边权给出了 $T_i$ 相对于 $T_j$ 的上界。最短路径给出的就是**最紧的上界**。

这告诉我：**整个问题可以建模为图上求最短路**，而 $T_i$ 就是从源点到 $i$ 的距离。

### 2.2 考虑更简单的版本：单个源点

如果只有源点 $S$，且从 $S$ 到每个 $i$ 的边权为 0（即 $T_i - T_S \le 0$），那么 $T_S$ 是唯一的自由变量。设 $T_S = 0$，则 $T_i$ 就是从 $S$ 到 $i$ 的最短路径距离。但这里有一个问题：如果图中存在负权环，则最短路径无下界（可以无限减小），对应到时间就是"任务时间可以无限提前"，这显然不合理。

**负权环 ↔ 无解**。这一点我下面给出完整证明。

**引理 1**：约束系统 $T_i - T_j \le b_{ij}$ 无解，当且仅当对应的有向图中存在负权环。

**证明**：

**（无解 ⇒ 负权环）**

假设无负权环，则对任意节点 $i$，从源点 $S$（设 $T_S = 0$）到 $i$ 的最短路径距离 $d_i$ 有限。设 $T_i = d_i$。

对任意边 $(j, i)$（权值 $b$）：由最短路的最优子结构，$d_i \le d_j + b$，即 $T_i - T_j \le b$。✓

同时 $d_i$ 非负吗？不一定——如果存在从 $S$ 出发到 $i$ 的负权路径，$d_i$ 可能为负。但此时设 $T_i = d_i$ 仍然满足所有约束。我们需要 $\min T_i = 0$ 且 $T_i \ge 0$。

**修正**：实际上，$T_i = d_i$ 可能为负。但我们可以平移：令 $T'_i = d_i - \min_k d_k$。平移不改变差值 $T'_i - T'_j = d_i - d_j$，所以所有约束仍满足。且 $\min T'_i = 0$。$T'_i \ge 0$。✓

所以无负权环时有解。

**（负权环 ⇒ 无解）**

设环为 $v_0 \to v_1 \to \cdots \to v_{k-1} \to v_0$，权值分别为 $b_0, b_1, \ldots, b_{k-1}$，且 $\sum_{r=0}^{k-1} b_r < 0$。

每个环上边 $(v_r, v_{r+1})$ 对应约束 $T_{v_{r+1}} - T_{v_r} \le b_r$（下标 mod $k$）。

将 $k$ 个不等式相加：

$$\sum_{r=0}^{k-1}(T_{v_{r+1}} - T_{v_r}) \le \sum_{r=0}^{k-1} b_r < 0$$

左边 = $(T_{v_1} - T_{v_0}) + (T_{v_2} - T_{v_1}) + \cdots + (T_{v_0} - T_{v_{k-1}}) = 0$（望远镜消去）。

所以 $0 < 0$，矛盾。故无解。✓

**引理 1 证毕。**

### 2.3 经典方法：差分约束 + Bellman-Ford

引理 1 把问题变成了：**检测图中是否存在负权环**。如果有，输出 `NO SOLUTION`；否则，求出从某个源点到所有节点的最短路径，平移后即为答案。

检测负权环的经典方法是 **Bellman-Ford**：

1. 设 $dist[i]$ 为从源点 $S$ 到 $i$ 的最短距离，初始化 $dist[S] = 0$，其余 $dist[i] = +\infty$。
2. 松弛 $n-1$ 轮：对每条边 $(u, v, w)$，若 $dist[u] + w < dist[v]$，则 $dist[v] = dist[u] + w$。
3. 第 $n$ 轮：若还能松弛，则存在负权环。

但这里有一个问题：**并非所有节点都能从 $S$ 到达**。对于不可达的节点，$dist[i]$ 仍为 $+\infty$，第 $n$ 轮的松弛检查无法检测它所在连通分量中的负权环。

### 2.4 解决不可达问题：加超级源点

**关键洞察**：如果图中任意位置存在负权环，那么整个约束系统无解（与源点选择无关）。为了检测所有可能的负权环，需要让源点能到达所有节点。

**方法**：引入超级源点 $S$，从 $S$ 向每个 $i$ 连一条权值为 0 的边 $S \to i$。这样从 $S$ 出发可以到达所有节点。

但这样做改变了原图：新增的边 $S \to i$ 对应约束 $T_i - T_S \le 0$，即 $T_i \le T_S$。如果我们设 $T_S = 0$，则 $T_i \le 0$，但这与"存在正时间"矛盾——比如原约束 $T_1 - T_2 \le 5$ 和 $T_2 - T_1 \le -3$（即 $T_2 < T_1$）要求 $T_1 > T_2$，而 $T_i \le 0$ 限制了上界但没限制下界……

等等，让我重新想。超级源点的边 $S \to i$（权 0）给出的约束是 $T_i \le T_S$。如果设 $T_S = 0$，则 $T_i \le 0$。但这只是**额外的约束**，不是原约束。我们只需要用这些边来检测负权环，不需要它们作为真正的约束。

**正确做法**：
- 用超级源点 $S$ 连 0 边到所有节点，仅用于**检测负权环**（Bellman-Ford 跑 $n+1$ 轮，第 $n+1$ 轮还能松弛则有负环）。
- 如果有解，$T_i$ 的值**不能**直接取从 $S$ 出发的最短路距离（因为 0 边给出了 $T_i \le T_S = 0$ 这个我们不需要的上界）。

**那 $T_i$ 到底怎么求？**

让我换一个思路。差分约束系统 $T_i - T_j \le b$ 等价于求一组 $T$ 使得所有 $T_i \le T_j + b$ 成立。这本质上是在求每个 $T_i$ 的**最大可行值**……不对，应该是最小化最大值还是什么？

实际上，差分约束的标准解法是：

> 建立图，约束 $T_i - T_j \le b$ 对应边 $j \to i$（权 $b$）。求从源点出发的最短路径 $d_i$，则 $T_i = d_i$ 满足所有约束。

这里的源点应该是**能到达所有节点的**。但如果不加超级源点，从任务 0 出发可能到不了某些节点。

让我换一种标准方法：**SPFA 检测负权环 + 求最短路**。

更标准的做法是：
1. 建图：约束 $T_i - T_j \le b$ → 边 $j \to i$，权 $b$。
2. 加超级源点 $S$，连 $S \to i$（权 0）对所有 $i$。
3. 从 $S$ 跑 Bellman-Ford / SPFA，检测负权环。
4. 如果有负权环 → `NO SOLUTION`。
5. 如果没有，$T_i = d_i$（从 $S$ 到 $i$ 的最短距离）。但 $d_i$ 可能为负（因为 0 边只给出 $d_i \le 0$，而负权边可能使 $d_i < 0$）。

等等，0 边 $S \to i$ 的权为 0，所以初始 $d_i \le 0$。如果存在负权路径 $S \to i \to \cdots \to j$，则 $d_j$ 可以为负。

但题目要求 $T_i \ge 0$ 且 $\min T_i = 0$。所以 $T_i = d_i$ 不直接可用（$d_i$ 可能为负）。

**解决方案：平移**。令 $T_i = d_i - \min_k d_k$。

**引理 2**：若图无负权环，$d_i$ 为从超级源点 $S$（$S \to i$ 权 0）到 $i$ 的最短路径距离，则 $T_i = d_i - \min_k d_k$ 满足所有原约束，且 $T_i \ge 0$，$\min_i T_i = 0$。

**证明**：

对任意原边 $(j, i)$（权 $b$）：由最短路最优子结构，$d_i \le d_j + b$。

所以 $T_i - T_j = (d_i - \min d) - (d_j - \min d) = d_i - d_j \le b$。✓

$T_i = d_i - \min_k d_k \ge d_i - d_i = 0$（因为 $\min_k d_k \le d_i$）。✓

存在 $k^* = \arg\min_k d_k$，则 $T_{k^*} = d_{k^*} - \min_k d_k = 0$。✓

**引理 2 证毕。**

### 2.5 算法选择：Bellman-Ford vs SPFA

$n \le 1000$，$m \le 5000$。加上超级源点的 $n$ 条 0 边，总边数 $\le 6000$。

- **Bellman-Ford**：$O(n \cdot m) = O(1000 \times 6000) = O(6 \times 10^6)$，非常快。
- **SPFA**：期望 $O(m)$，最坏 $O(nm)$。

这里 Bellman-Ford 的 $O(nm)$ 完全足够，且实现简单、无最坏情况风险。我选择 Bellman-Ford。

### 2.6 完整算法

1. 读入 $n, m$。
2. 建图：超级源点 $S = n$（0-based 下标），任务 $0, 1, \ldots, n-1$。
   - 每条约束 $T_i - T_j \le b$ → 边 $j \to i$，权 $b$。（0-based: $j-1 \to i-1$）
   - 超级源点 $S$ → 每个任务 $i$，权 0。
3. 初始化 $dist[S] = 0$，$dist[i] = +\infty$（对 $i \ne S$）。
4. 松弛 $n$ 轮（注意：现在有 $n+1$ 个节点，所以应松弛 $n$ 轮来检测负权环——$n$ 轮后第 $n+1$ 轮还能松弛则有负环）。

   等等，重新数一下节点数。超级源点 + $n$ 个任务 = $n+1$ 个节点。Bellman-Ford 需要松弛 $(n+1) - 1 = n$ 轮来确定最短路。如果第 $n+1$ 轮还能松弛，则有负权环。

   但标准做法是：松弛 $n$ 轮（因为 $n+1$ 个节点），然后检查第 $n+1$ 轮是否有更新。等价地，松弛 $n+1$ 轮，如果第 $n+1$ 轮有更新则有负环。

5. 如果检测到负权环 → 输出 `NO SOLUTION`。
6. 否则，$\min_d = \min_i dist[i]$（只对任务节点 $0$ 到 $n-1$ 取 min）。
7. 输出 $dist[i] - \min_d$（对 $i = 0, \ldots, n-1$）。

### 2.7 验证

**例**：$n = 3$，约束：
- $T_1 - T_2 \le 1$（边 $2 \to 1$，权 1）
- $T_2 - T_3 \le 2$（边 $3 \to 2$，权 2）
- $T_3 - T_1 \le -2$（边 $1 \to 3$，权 -2）

0-based：边 $1 \to 0$（权 1），$2 \to 1$（权 2），$0 \to 2$（权 -2）。

超级源点 $S = 3$：边 $3 \to 0$（0），$3 \to 1$（0），$3 \to 2$（0）。

初始化：$dist = [+\infty, +\infty, +\infty, 0]$（下标 0,1,2,3）。

第 1 轮松弛：
- $3 \to 0$（0）：$dist[0] = 0$
- $3 \to 1$（0）：$dist[1] = 0$
- $3 \to 2$（0）：$dist[2] = 0$
- $1 \to 0$（1）：$dist[1]+1 = 1 > 0 = dist[0]$，不更新
- $2 \to 1$（2）：$dist[2]+2 = 2 > 0 = dist[1]$，不更新
- $0 \to 2$（-2）：$dist[0]+(-2) = -2 < 0 = dist[2]$，更新 $dist[2] = -2$

第 2 轮：
- $0 \to 2$（-2）：$dist[0]+(-2) = -2 = dist[2]$，不更新
- 其他边不变

第 3 轮：无更新 → 无负权环。

$dist = [0, 0, -2]$（任务 0,1,2），$\min = -2$。

$T_0 = 0 - (-2) = 2$，$T_1 = 0 - (-2) = 2$，$T_2 = -2 - (-2) = 0$。

验证：
- $T_1 - T_2 = 2 - 0 = 2$，应 $\le 1$？**不满足！**

等等，我搞混了。让我重新看约束的建边方向。

约束 $T_i - T_j \le b$ 对应边 $j \to i$（权 $b$）。

$T_1 - T_2 \le 1$（1-based）→ 0-based：$T_0 - T_1 \le 1$ → 边 $1 \to 0$（权 1）。
$T_2 - T_3 \le 2$（1-based）→ 0-based：$T_1 - T_2 \le 2$ → 边 $2 \to 1$（权 2）。
$T_3 - T_1 \le -2$（1-based）→ 0-based：$T_2 - T_0 \le -2$ → 边 $0 \to 2$（权 -2）。

边：$1 \to 0$（1），$2 \to 1$（2），$0 \to 2$（-2）。

最短路从 $S=3$：
- $dist[3] = 0$
- $3 \to 0$（0）：$dist[0] = 0$
- $3 \to 1$（0）：$dist[1] = 0$
- $3 \to 2$（0）：$dist[2] = 0$

第 1 轮后：$dist = [0, 0, 0]$

再松弛原边：
- $1 \to 0$（1）：$0 + 1 = 1 > 0$，不更新
- $2 \to 1$（2）：$0 + 2 = 2 > 0$，不更新
- $0 \to 2$（-2）：$0 + (-2) = -2 < 0$，更新 $dist[2] = -2$

第 2 轮：
- $0 \to 2$（-2）：$0 + (-2) = -2 = dist[2]$，不更新
- 其他不更新

第 3 轮：无更新。

$dist = [0, 0, -2]$，$\min = -2$。

$T_0 = 2$，$T_1 = 2$，$T_2 = 0$。

验证 1-based 约束：
- $T_1 - T_2 = T_0 - T_1 = 2 - 2 = 0 \le 1$ ✓
- $T_2 - T_3 = T_1 - T_2 = 2 - 0 = 2 \le 2$ ✓
- $T_3 - T_1 = T_2 - T_0 = 0 - 2 = -2 \le -2$ ✓

$\min = 0$ ✓，全部 $\ge 0$ ✓。

完美！

再验证一个有负权环的例子：
- $T_1 - T_2 \le -1$（边 $1 \to 0$，权 -1）
- $T_2 - T_1 \le -1$（边 $0 \to 1$，权 -1）

环 $0 \to 1 \to 0$，权 $-1 + (-1) = -2 < 0$ → 负权环 → `NO SOLUTION`。

验证：$T_0 - T_1 \le -1$ 且 $T_1 - T_0 \le -1$，相加得 $0 \le -2$，矛盾。✓

## Part 3 — 模式总结

```
- explore its property — 不等式 T_i - T_j ≤ b 天然对应图边 j→i 权 b，沿路径的累积边权给出最紧上界
- consider easier version — 单源最短路：若源点可达所有节点，dist 即满足约束；负权环 ⟺ 无解
- classic problem solution — Bellman-Ford 检测负权环 + 求最短路，O(nm)
- reduce to easier problem — 不可达节点问题：加超级源点 S 连 0 边到所有节点，使所有节点可达
- classic problem solution — Bellman-Ford 在 n+1 个节点上跑 n+1 轮，第 n+1 轮有更新则为负权环
- defer reconstruction — 最短路 dist 可能为负，平移 T_i = dist[i] - min(dist) 得到非负且 min=0 的答案
```

## Part 4 — 正解（算法描述）

### 符号表

| 符号 | 含义 | 初始化 | 记忆助记 |
|------|------|--------|----------|
| $n, m$ | 任务数、约束数 | 输入 | |
| $S$ | 超级源点下标 $= n$ | 常量 | S=Super |
| $E[]$ | 边数组，每条边 $\{u, v, w\}$ 表示 $u \to v$ 权 $w$ | 逐条填入 | |
| $E[0..k-1]$ | $k$ 条边（含超级源点边） | | |
| $dist[i]$ | 从 $S$ 到 $i$ 的最短距离（Bellman-Ford 中间量） | $dist[S]=0$，其余 $=+\infty$ | dis=distance |
| $\infty$ | 哨兵值 $1145141919$ | | |
| $mind$ | $\min_{i=0}^{n-1} dist[i]$（仅任务节点） | 求完最短路后 | |
| $T_i$ | 任务 $i$ 的起始时间 $= dist[i] - mind$ | 输出时计算 | |

### 算法步骤

1. **读入** $n, m$。

2. **建图**：
   - 对每条约束 $T_i - T_j \le b$（1-based），建边 $j-1 \to i-1$，权 $b$。
   - 超级源点 $S = n$，对每个 $i \in [0, n-1]$，建边 $S \to i$，权 0。
   - 总边数 $k = m + n$。

3. **Bellman-Ford**：
   - 初始化 $dist[S] = 0$，$dist[i] = +\infty$（$i \ne S$）。
   - 松弛 $n$ 轮（$n+1$ 个节点，$n$ 轮足够确定最短路）：
     - 对每条边 $(u, v, w)$：若 $dist[u] + w < dist[v]$，则 $dist[v] = dist[u] + w$。
   - 第 $n+1$ 轮检测：对每条边 $(u, v, w)$，若 $dist[u] + w < dist[v]$，则存在负权环 → 输出 `NO SOLUTION`，结束。

4. **平移输出**：
   - $mind = \min_{i=0}^{n-1} dist[i]$。
   - 对 $i = 0, \ldots, n-1$，输出 $dist[i] - mind$。

### 复杂度

- 时间：$O(n \cdot (m + n)) = O(nm + n^2) \le O(1000 \times 6000) = O(6 \times 10^6)$
- 空间：$O(n + m)$

### 验证状态

- 手工验证了 2 个例子（有解/无解），均正确。
- 由于 Special Judge，输出不唯一，只要满足约束 + $\min T_i = 0$ + $T_i \ge 0$ 即可。

## Part 5 — 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};
constexpr int mxm{6005};
constexpr int inf{1145141919};

int n,m;
struct{int u,v,w;}E[mxm];
int k=0;
int dist[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	int S=n;

	for(int i=0,ii,jj,b;i<m;++i)
	{
		cin>>ii>>jj>>b;--ii;--jj;
		E[k++]={jj,ii,b};
	}
	for(int i=0;i<n;++i)
		E[k++]={S,i,0};

	dist[S]=0;
	for(int i=0;i<n;++i)
		dist[i]=inf;

	for(int r=0;r<n;++r)
	{
		bool up=false;
		for(int i=0;i<k;++i)
		{
			auto[u,v,w]=E[i];
			if(dist[u]!=inf&&dist[u]+w<dist[v])
			{
				dist[v]=dist[u]+w;
				up=true;
			}
		}
		if(!up)
			break;
	}

	bool neg=false;
	for(int i=0;i<k;++i)
	{
		auto[u,v,w]=E[i];
		if(dist[u]!=inf&&dist[u]+w<dist[v])
		{
			neg=true;
			break;
		}
	}

	if(neg)
	{
		cout<<"NO SOLUTION"<<'\n';
		return 0;
	}

	int mind=inf;
	for(int i=0;i<n;++i)
		mind=min(mind,dist[i]);

	for(int i=0;i<n;++i)
		cout<<dist[i]-mind<<'\n';

	return 0;
}
```
