# P1457 [IOI 1994 / USACO 2.1] 城堡 The Castle

> 标签：搜索 / 连通块 / 枚举 · 难度：普及/提高-

## 1. 重新读题

**问题重述（简化版）**

- 城堡被划成 $n$ 行 $m$ 列的单位正方形，四周一定有外墙。
- 每个单位给出一个 $0\sim 15$ 的数字，二进制位含义：**1=西墙，2=北墙，4=东墙，8=南墙**。
- 相邻两格之间若两边都没有墙，就可以互相走动；由此把整张图切成若干**房间**。
- 要求输出四行：房间数、最大房间大小、拆掉一面内部墙后能得到的最大房间大小、以及这面墙的编号（行、列、方位 `N`/`E`）。

**题面口径要点（后面逐条证明）**：① "房间大小" $=$ 房间内的**单位格数**，不是周长、不是墙长；
② 第四行用"南邻单位的北墙"或"西邻单位的东墙"表示，即横墙 $(r,c,\texttt{N})$（$r\ge2$）、竖墙 $(r,c,\texttt{E})$（$c\le m-1$）；
③ 平局规则：先最靠西，再最靠南，同一格北墙优先于东墙。

**坐标约定（全文统一）**：行号 $r$ 由**北**向**南**取 $1\sim n$（示意图左列的 `1 2 3 4`），列号 $c$ 由**西**向**东**取 $1\sim m$（示意图顶部的 `1..7`）；
于是"更靠西" $=$ 列号更小，"更靠南" $=$ 行号更大，输入的第 $i$ 行就是第 $i$ 行，没有任何旋转。

**输入顺序的坑**：第一行是 `m n`（**先列数、后行数**），随后 $n$ 行、每行 $m$ 个数字；
顺序写反就得到一座转置过的城堡，连题图都验不过。代码里必须 `cin>>m>>n;`。

**约束与复杂度提示**：$1\le n,m\le50$ ⇒ 格子总数 $\le2500$，每格数字 $0\sim15$；题面保证房间数 $\ge2$、且至少有一面墙可以拆走。
$2500$ 太小了：$O(nm)$、$O((nm)\log)$ 甚至 $O((nm)^2)\approx6.25\times10^6$ 都能过。
所以本题难点**不在复杂度，而在口径**——位掩码的方向含义、"大小"的定义、第四行的平局规则，这正是下面思维链的主线。

**输出四行的严格格式**：第 $1\sim3$ 行各是一个整数（房间数、最大房间格数、拆一面墙后能得到的最大房间格数）；
第 $4$ 行是 `行 列 方位`，方位为**单个**大写字母 `N` 或 `E`，每行一个答案，行末用 `'\n'`。
题面**不要求**小数位数，也**不要求**"字母升序输出"之类的排序（那是其他题型的套路），不要输出 `"North"`。

**本地题面无正式样例**：`P1457.md` 里没有 `【输入样例】/【输出样例】`，只有一幅带注解的 $4\times7$ 平面图，
以及两句文字断言："这个样例就有 5 个房间（大小分别为 $9,7,3,1,8$）"、"移去箭头所指的那面墙……形成的房间最大"。
因此**无法与官方答案对标**。验证方式：① 把示意图**反解成输入**，用题面自己断言的 $5$、$\{9,7,3,1,8\}$、箭头墙做交叉校验；② 自造 $3$ 组边界用例手算（见 §4.4）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制 —— 把"数字"翻译成"能不能走"

题面说：每个单位的数字是 $\{1,2,4,8\}$ 中"任意个"加起来得到的，$1$=西、$2$=北、$4$=东、$8$=南。
"任意个子集的和"这四个字就是**位掩码**的暗号：$1,2,4,8$ 正好是 $2^0,2^1,2^2,2^3$。

**引理 1（位判定）** 对任意 $d\in[0,15]$：$d$ 的 west/north/east/south 面有墙，分别等价于 `d&1`、`d&2`、`d&4`、`d&8` 非零。

**证明**：把 $d$ 写成二进制 $d=b_3b_2b_1b_0$，即 $d=\sum_{k=0}^{3}b_k2^k$，$b_k\in\{0,1\}$。
题面的数字是 $\{1,2,4,8\}=\{2^0,2^1,2^2,2^3\}$ 某个子集的元素之和，取子集 $S$ 时 $d=\sum_{k\in S}2^k$；
由二进制表示的唯一性，$b_k=1\iff k\in S$，即第 $k$ 位被选中 $\iff$ 对应方向有墙。
而 `d&(2^k)` 恰好只保留第 $k$ 位，故 `d&(2^k)`$\ne 0\iff b_k=1\iff$ 该方向有墙。
四个方向一一对应 $k=0$(西)$,1$(北)$,2$(东)$,3$(南)，命题成立。$\blacksquare$

**先别急着写代码：位的顺序必须校准。** 很多人下意识以为 $1,2,4,8$ 是"顺时针 北东南西"或"上右下左"，
本题却是 **西(1) → 北(2) → 东(4) → 南(8)**，一个"横竖横竖"的锯齿顺序。
拿题面的 $4\times 7$ 示意图抽查三格（示意图里 `#`=墙，`|`/`-`=通路）：

| 格子 | 图上四条边 | 期望数字 | 核对 |
|---|---|---|---|
| $(1,1)$ 左上角 | 左`#`、上`#`、下`#`、右`|`（通） | $1+2+8=11$ | 与反解出的第一格一致 ✓ |
| $(1,2)$ | 左通、上`#`、右`#`、下通 | $2+4=6$ | ✓ |
| $(1,6)$ | 左通、上`#`、右通、下`#` | $2+8=10$ | 注意**不是** $10=$ 西+北+南，而是北+南 |

第三格最要紧：$10$ 若被读成"西+北+南"，整张图会解出另一座城堡。
再反证一次位序：$(1,1)$ 的图上画法是"左墙、上墙、下墙、右开口"，只能编成 $1+2+8=11$；
若按"顺时针（北$1$东$2$南$4$西$8$）"解释，$11$ 就变成"北+东+南+…"，左上角会**没有西墙**，与图里的 `#` 矛盾。
所以**西 $=1$** 这套口径是被题图锁定、唯一可行的。

**引理 2（内部墙记两次，外墙记一次）** 两面相邻格子之间的墙，在输入里恰好出现两次（一侧记为东墙 $4$，另一侧记为西墙 $1$；上下相邻则记为南墙 $8$ 与北墙 $2$）；最外圈的墙只出现一次。

**证明**：设相邻格 $(r,c)$ 与 $(r,c+1)$。它们之间的墙是 $(r,c)$ 的**东**边、同时是 $(r,c+1)$ 的**西**边，
是同一条几何线段，题面明确"城堡内部的墙会被规定两次"，故两处都必须置位：$4\in a[r][c]$ 且 $1\in a[r][c+1]$。
反之，任何一次"东墙"置位 $a[r][c]\mathbin\&4\ne0$ 都唯一确定这条线段，也必然被 $(r,c+1)$ 的西墙记录，不会多记。
最外圈：$(r,m)$ 的东边是城堡边界，右边没有格子去记录它的西边，故只记一次；其余三面同理。$\blacksquare$

**推论（工程选择）**：判定两格之间能否通行，**只需查其中一格的对应位**即可。
我们的洪泛写成 `if(a[r][c]&wb[d]) → 不可走`，只读当前格；
拆墙枚举同理只读 `(r,c)` 的北位/东位。这样即使出题数据把冗余位写错，也不会影响结果，
同时避免"两边都查"时出现 `a[r][c]&4 && a[r][c+1]&1` 这种**与**（漏掉单边标注错误 → 误判有墙）或 `||`（误判无墙）的歧义写法。

### 2.2 口径校准 —— 统计的是"面积（格数）"，不是周长

题面里有两处容易被读成"长度"的描述，必须先把口径钉死：

- "一个这样的单位可以有 $0\sim4$ 面墙环绕" —— 这是**输入编码**，不是要输出的量；
- "大小分别为 $9,7,3,1,8$ 个单位" —— "**个单位**"说的是**单位正方形的个数**，即房间包含几格。

所以本题输出的是**面积（格数）**，压根不统计周长或边界边长，不存在"周长 $=$ 与外部相邻格数"还是"周长 $=$ 实际边长"这类口径分叉
（那种歧义出现在"岛屿周长"题里）。但**同类的计数口径风险依然存在**，写清楚：

> 房间大小 $=\lvert$该房间的格子集合$\rvert$，每格恰好计 $1$；不计内部通路、不计外墙边数、不计格子的周长贡献。

**建图（把城堡变成一张普通图）**：顶点集 $V=\{(r,c):1\le r\le n,\ 1\le c\le m\}$，$|V|=nm\le2500$；
边集 $E=\{\{u,v\}: u,v$ 四方向相邻且之间没有墙$\}$。

**引理 3（房间 = 连通块）** 题面意义的"房间"与图 $G=(V,E)$ 的连通块一一对应。

**证明**：在 $V$ 上定义关系 $u\sim v\iff$ 存在一条由 $E$ 中边首尾相接构成的路径 $u=x_0,x_1,\dots,x_t=v$。

- *自反*：取 $t=0$（长度为 $0$ 的路径），$u\sim u$。
- *对称*：路径反向仍是路径。注意这一步隐含**边的无向性**：$u\to v$ 无墙意味着 $v\to u$ 无墙。
  由引理 2，$(r,c)$ 与 $(r,c+1)$ 之间的同一条墙被记录两次（$4$ 与 $1$），
  所以"没墙"同样被记录两次：$4\notin a[r][c]\iff$ 该线段不是墙 $\iff 1\notin a[r][c+1]$。上下方向（$8$ 与 $2$）同理。故 $E$ 是无向边集。
- *传递*：$u\sim v$ 的路径接上 $v\sim w$ 的路径（去掉重复的 $v$）仍是合法路径。

故 $\sim$ 是等价关系，等价类把 $V$ 无重复无遗漏地划分。题面把房间描述为"被墙围出来的一整片格子、内部可自由走动"，
这正是**极大**等价类：若某片可互相走动的格子还构不成一个类，就仍有能走到它的格子没并进来。于是 房间集 $=$ 等价类集 $=$ 连通块集。$\blacksquare$

**引理 4（大小即块规模）** 房间大小 $=$ 对应连通块的顶点数，故"每个房间多大"就是"对每个连通块数顶点"，不需要任何别的几何量。
**证明**：由引理 3，房间就是那个等价类本身；"大小"口径是格数，格就是顶点，故大小 $=$ 等价类基数 $=$ 连通块规模。$\blacksquare$

**引理 5（每格恰好属于一个房间 ⇒ 只在未访问格启动就够了）**
**证明**：等价类有两条基本性质——①任一 $u$ 的类非空（含 $u$，由自反性）；
②若 $[u]\cap[v]\ne\varnothing$，取 $w$ 在交中，由对称与传递得 $u\sim w\sim v$，于是 $[u]=[v]$，即不同类两两不交。
因此反复"取一个未访问顶点、把它的整个类全标记"时，每个类恰好被启动一次：启动次数 $=$ 类数 $=$ 房间数；
也不会漏格（漏格所在类的第一个被扫到的格就会把整类覆盖）。$\blacksquare$

### 2.3 简化版 —— 先不管"拆墙"，只数房间与最大房间

把第四问（拆哪面墙）暂时砍掉，只剩引理 4 的机器活：**求所有连通块的规模**。这就是最标准的网格洪泛：
① 找一个未标记的格 $u$；② 从 $u$ 出发，"该方向没墙"就跨过去，走到的格全打同一编号 $k$；
③ 本次覆盖的格数即 $sz[k]$；④ $k\mathrel{+}=1$，回到 ① 直到没有未标记格。由引理 5，启动次数 $=$ 房间数。

**引理 6（洪泛的正确性）** 以"入队时立即打标记"实现的 BFS，第 $k$ 次洪泛出队并被计数的格子集合恰为 $[u]_G$。

**证明**：记队列为 $Q$，$S$ 为"已打标记"的格集合。

- *不越界（$S\subseteq[u]$）*：初始 $Q=[u]$，$u\in[u]$。设某步弹出 $x\in[u]$，向方向 $d$ 扩展 $y$：
  扩展的前提是 `a[x]&wb[d]==0`，即 $\{x,y\}\in E$，于是 $y\sim x$，由传递性 $y\in[u]$，故新入队的仍是 $[u]$ 中的格。
- *不漏（$[u]\subseteq S$）*：对 $y\in[u]$ 到 $u$ 的最短路径长度 $\ell$ 归纳。$\ell=0$ 时 $y=u$ 一开始就在队里；
  $\ell\ge1$ 时设路径 $u=x_0,\dots,x_\ell=y$，则 $x_{\ell-1}$ 到 $u$ 距离 $\ell-1$，由归纳假设曾入队，而每个入队的格最终都会出队，
  $x_{\ell-1}$ 出队时考察四个方向，朝 $y$ 的那个方向满足"无墙"且 $y$ 尚未标记（若早已标记则命题已成立），故 $y$ 必被入队。
- *恰好计一次*：标记时机在**入队**处（`id[y]=k` 与 `qr[qt]=y` 同一步完成）。同一个格可能被多条路径先后碰到，
  但第一次入队就带上标记，后续分支都因 `id[y]` 非零而跳过，故入队、出队各 $\le1$ 次，`++sz[k]` 次数 $=$ $|[u]|$。
  （若把标记推迟到**出队**时做，同一格会被多个邻居重复入队，`sz` 偏大——这是洪泛最常见的 bug。）$\blacksquare$

**防爆栈的取舍**：$n,m\le50$，最坏是一整条"贪吃蛇"房间，DFS 递归深度 $=nm=2500$；每层帧只放两三个 `int` 时约 $120$KB，默认栈扛得住。
但只要顺手在递归函数里开个局部数组、或日后把范围放大到 $500\times500$，就会立刻爆栈（且只在极端数据上段错误，极难查）。
本题 BFS 与 DFS 一样长，所以直接用**数组队列 BFS**（`qr/qc` + 下标 `qh/qt`），彻底与栈深无关。

**全局数组默认 $0$ 的妙用与陷阱**：`id[][]` 全局定义为 $0$，这里 $0$ 恰好代表"未访问"，编号从 $1$ 开始，
所以不必手写初始化；反之若某个数组的"未定义/不可达"要用 $+\infty$ 表示，全局默认 $0$ 会被当成合法值，必须显式 `fill_n`。

### 2.4 加回增量 —— "拆一面墙"到底改变了什么

题面原文："把一面**单独的**墙（指**两个单位间的墙**）拆掉以形成一个更大的房间。"
两个限定词各排掉一类候选："两个单位间" ⇒ **外墙不是候选**（只有一侧有单位，既不会合并房间，也没有合法描述符）；"一面" ⇒ 只加一条边，不做组合拆除。

**朴素做法（先老老实实写一遍）**：枚举每面内部墙，拆掉它、在改过的网格上重跑一次 §2.3 洪泛，取最大块。
墙数 $O(nm)$、每次洪泛 $O(nm)$，合计 $O((nm)^2)\le 2500^2=6.25\times10^6$ —— **本题数据下这是能过的**。
先拿到"笨但正确"的基准很值：后面所有聪明化简都拿它对照。

**引理 7（局部性：加一条边只影响两个连通块）** 设墙 $e$ 分隔相邻格 $u,v$，$G'=(V,E\cup\{e\})$。则

$$[u]_{G'}=[v]_{G'}=[u]_G\cup[v]_G,$$

且任何满足 $[x]_G\cap([u]_G\cup[v]_G)=\varnothing$ 的块在 $G'$ 中保持不变。

**证明**：
*包含 $\subseteq$*：取任意 $z\in[u]_{G'}$，取 $G'$ 中 $u$ 到 $z$ 的**最短**路径 $P$。$P$ 的边要么属于 $E$，要么就是新增的 $e=\{u,v\}$。
若 $P$ 用到两次 $e$，则其中夹着"离开 $\{u,v\}$ 后又走回另一个端点"的子段，删掉它可得更短路径，与最短矛盾，故 $e$ 至多用一次。

- 若 $P$ 不用 $e$：所有边属于 $E$，于是 $z\in[u]_G$。
- 若 $P$ 用 $e$：以 $e$ 把 $P$ 切成两段，前段是 $G$ 中 $u\leadsto e$ 的某端点，后段是 $G$ 中 $e$ 的另一端点 $\leadsto z$。
  $e$ 若是首边（前端点就是 $u$），后段即 $G$ 中 $v\leadsto z$，$z\in[v]_G$；
  $e$ 若不在首边，前段给出 $G$ 中 $u\leadsto v$，即 $v\in[u]_G$，而后段从 $u$ 出发到 $z$，故 $z\in[u]_G$。
  两种情形都有 $z\in[u]_G\cup[v]_G$，故 $[u]_{G'}\subseteq[u]_G\cup[v]_G$。

*包含 $\supseteq$*：$G\subseteq G'$（边只多不少），$u$ 到 $[u]_G$ 中各格的老路径在 $G'$ 里仍然成立，故 $[u]_G\subseteq[u]_{G'}$；
又 $u\mathbin{e}v$ 是 $G'$ 中的边，故 $v\in[u]_{G'}$，再由 $[v]_G$ 内可达性得 $[v]_G\subseteq[u]_{G'}$。于是 $[u]_G\cup[v]_G\subseteq[u]_{G'}$。

*其余块不变*：反设某 $x$（$x\notin[u]_G\cup[v]_G$）的块被放大，即存在 $y\in[x]_{G'}\setminus[x]_G$。
取 $G'$ 中 $x$ 到 $y$ 的最短路径，同上分析它必须用到 $e$，而 $e$ 之前那段是 $G$ 中 $x\leadsto u$ 或 $x\leadsto v$ 的路径，
与 $x\notin[u]_G\cup[v]_G$ 矛盾。$\blacksquare$

**直接推论（本题的算法化简）**：拆墙 $e=(u,v)$ 后新房间的大小只可能是

$$\text{new}(e)=\begin{cases}sz[u],& [u]_G=[v]_G\\ sz[u]+sz[v],& [u]_G\ne[v]_G\end{cases}$$

于是第三、四行化简成一句话：**在"两侧属于不同房间"的内部墙中，找 $sz$ 之和最大的那面。**
$O(nm)$ 枚举 + $O(1)$ 取值，不需要重跑洪泛。

**同块墙必须跳过（不是优化，是正确性）**：$[u]_G=[v]_G$ 时两格本就同一房间，拆墙只是"屋里多开个门洞"，规模仍是 $sz[u]$；
写成 `sz[x]+sz[y]` 等于把同一个房间数两遍。题图实测：$(2,1)$ 与 $(2,2)$ 之间有墙（$a[2][1]=7$ 含东位 $4$、$a[2][2]=9$ 含西位 $1$），
但两格同属那个 $9$ 格大房间 —— 不跳过得 $9+9=18$，被题面断言的 $16$ 直接证伪。

**引理 8（第三行必严格大于第二行，且候选非空）** 设最大房间为 $R$，则存在一面内部墙，拆掉后新房间大小 $\ge sz[R]+1$。

**证明**：取辅助图 $H=(V,F)$，$F$ 为**所有**四方向相邻格对（无视墙）。$H$ 连通：任取 $(r,c)$，向西走 $c-1$ 步到 $(r,1)$，
再向北走 $r-1$ 步到 $(1,1)$，故每格都连到 $(1,1)$。题面保证房间数 $\ge2$，故存在格 $q\notin R$；
取 $H$ 中 $p\in R$ 到 $q$ 的路径 $p=x_0,\dots,x_t=q$，设 $i$ 为第一个使 $x_i\notin R$ 的下标（$i\ge1$，因 $x_0\in R$）。
则 $x_{i-1}\in R$、$x_i\notin R$ 分属两个不同房间 $R,R'$；若它们之间无墙，则 $\{x_{i-1},x_i\}\in E$，由引理 3 应同块，矛盾——故**必有墙**。
两格都在网格内，此墙两侧都有单位，不是外墙，是合法候选。拆它得 $sz[R]+sz[R']\ge sz[R]+1>sz[R]$（每块至少含自身一格，故 $sz[R']\ge1$）。$\blacksquare$

由此：① 第三行严格大于第二行（不必担心"拆了反而更小"）；② 候选集非空，`best` 必被更新，初值只是哨兵；
③ 只需在"跨块墙"中取最大，不用把原有房间也塞进候选。

**两个看着很像、其实错的贪心**

*贪心 A：「最大房间 $+$ 次大房间」*——把答案写成两个最大 $sz$ 之和。
**反例就是题图**：大小 $9,7,3,1,8$，$9+8=17$，但 $9$ 格房间 $A$ 与 $8$ 格房间 $C$ **根本不相邻**
（$A$ 的四邻只有 $3$ 格的 $B$ 和 $7$ 格的 $E$，见 §4.4 洪泛轨迹），$17$ 不可实现，真实答案 $16=9+7$。
失败根源：合并要求"存在一面公共墙"，这是**可行性约束**，贪心 A 把它丢了。

*贪心 B：「让最大房间去吞掉它最好的邻居」*——固定 $R$，只在跨出 $R$ 的墙里挑最优。
**反例（自造 $n=1,m=12$，房间是长度 $4,1,1,3,3$ 的五段区间）**：

```plain
11 10 10 14 15 15 11 10 14 11 10 14
```

（逐位核对：第 1 格 $11=1+2+8$＝西/北/南有墙、东通；第 5 格 $15$＝四面全墙的孤立单间；第 9 格 $14=2+4+8$＝北/东/南有墙、西通。）
最大房间 $A$ 有 $4$ 格，唯一邻居是 $1$ 格的 $B$，贪心 B 给出 $4+1=5$（墙 `1 4 E`）；真正最优在两个 $3$ 格房间之间：$3+3=6$（墙 `1 9 E`）。
失败根源：目标 $\max(sz[x]+sz[y])$ 里**大数不一定和大数配对**，"极值必含最大元素"需要单调性或交换论证支撑，而跨块约束完全不提供。

**正确的思路（回到目标函数本身）**：目标就是对候选墙集合取 $\max$，集合大小才 $O(nm)\le2500$，**全枚举**即可；
贪心的价值只在于逼我们说出"必须面面都试"这句结论。

### 2.5 第四行的排序口径 —— 把中文平局规则变成可执行全序

第四问要的是"**哪面墙**"，而"最大合并"可能有多个解，题面给了三句话：

> 选择最佳的墙来推倒。有多解时选**最靠西**的，仍然有多解时选**最靠南**的。
> 同一格子**北边**的墙比**东边**的墙更优先。

**第一步：每面墙的唯一名字。** 题面规定用"该墙的**南邻**单位的北墙"表示横墙、"该墙的**西邻**单位的东墙"表示竖墙。
于是候选墙恰是两类描述符：

- $(r,c,\texttt{N})$：格 $(r,c)$ 的北墙，要求 $r\ge2$（否则是顶边外墙）；它分隔 $(r-1,c)$ 与 $(r,c)$；
- $(r,c,\texttt{E})$：格 $(r,c)$ 的东墙，要求 $c\le m-1$（否则是右边外墙）；它分隔 $(r,c)$ 与 $(r,c+1)$。

**引理 9（候选墙与描述符一一对应，且每面内部墙被枚举恰好一次）**

**证明**：令 $(r,c)$ 占据 $x\in[c-1,c],\ y\in[r-1,r]$（$y$ 向南增大），内部墙只有横、竖两种线段。

- 横内部墙必分隔某 $(r-1,c)$ 与 $(r,c)$（$2\le r\le n,\ 1\le c\le m$），它是 $(r,c)$ 的北边，故对应 $(r,c,\texttt{N})$；
  单射：同一线段 ⇒ 高度相同（$r-1=r'-1$）且横向区间相同（$[c-1,c]=[c'-1,c']$）⇒ $r=r',c=c'$。
- 竖内部墙同理对应 $(r,c,\texttt{E})$（$1\le c\le m-1$），单射同理。
- 两像集不相交：水平线段不可能是竖直线段。
- 计数闭合：横 $(n-1)m$ 面 + 竖 $n(m-1)$ 面 $=$ 内部墙总数，无遗漏无重复。$\blacksquare$

**第二步：把三句话落成键。** 直接按题面给的**描述符数字**取字典序最小：

$$\text{key}(r,c,d)=\bigl(c\uparrow,\ r\downarrow,\ d:\ \texttt{N}\prec\texttt{E}\bigr)$$

即"最靠西" $=$ 列号 $c$ 尽量小，"最靠南" $=$ 行号 $r$ 尽量大，第三句话 $=$ 前两键相同（同格两面墙）时**北墙**胜**东墙**。

**为什么取描述符读法而不是纯几何读法？** 几何读法把 $(r,c,\texttt{N})$ 的西端记作 $x=c-1$、$(r,c,\texttt{E})$ 记作 $x=c$，
于是"同格北墙更靠西"**自动成立**，题面第三句话就成了废话；而描述符读法下这两面的 $(c,r)$ 完全相同，**必须**靠第三句话定胜负。
按"题面每条信息都在补充歧义"的应试原则，取描述符读法。
（两种读法只在"两墙共顶点"的退化情形分歧，如 $(r,c,\texttt{E})$ 与 $(r+1,c+1,\texttt{N})$ 的几何西端、南端都相同；
在题面示意图数据上两者给出**同一个**答案，见下面的验算。）

**引理 10（三重循环以键序枚举，配合严格 `>` 即得所求墙）** 循环
`for c=1..m → for r=n..1 → 先查 N 墙再查 E 墙` 生成的序列恰是 key 的非减序。

**证明**：字典序的三个分量与三层循环一一对应。
外层 $c$ 从 $1$ 递增到 $m$：$c_1<c_2$ 时，所有描述符列为 $c_1$ 的墙先于列为 $c_2$ 的墙被访问（字典序第一分量决定块状划分）；
中层 $r$ 从 $n$ 递减到 $1$：固定 $c$ 内，行号大的（更南）先被访问，对应第二分量 $r\downarrow$；
内层把同一格的北墙检查放在东墙之前，对应第三分量 $\texttt{N}\prec\texttt{E}$。
由引理 9，每个候选墙出现且仅出现一次，故该序列是候选集上的一个**全序**，且与 key 序相同。
程序中用 `sz[x]+sz[y] > best`（严格大于）才更新：设 $M=\max_e \text{new}(e)$，
则第一次遇到达到 $M$ 的墙时把 `best` 置为 $M$ 并记下它，之后所有 $\text{new}(e)=M$ 的墙因不满足严格大于而无法覆盖它，
而 $\text{new}(e)<M$ 的更不可能覆盖。故最终留下的是 $\{e:\text{new}(e)=M\}$ 中**在全序里最靠前**者 $=$ key 最小者。$\blacksquare$

**用题图验算 tie-break**（完整洪泛见 §4）：能造出 $16$ 格的墙有三面——
$(4,1,\texttt{E})$（箭头那面）、$(4,2,\texttt{N})$、$(4,3,\texttt{N})$。
按 key 比较：$(4,1,\texttt{E})$ 列 $1$；$(4,2,\texttt{N})$ 列 $2$；$(4,3,\texttt{N})$ 列 $3$ ⇒ 列 $1$ 最小，胜出，输出 `4 1 E`。
纯几何读法下：$(4,1,\texttt{E})$ 的西端 $x=1$、南端 $y=4$，$(4,2,\texttt{N})$ 的西端 $x=1$、南端 $y=3$ ⇒ 西端打平、南端 $(4,1,\texttt{E})$ 更南，同样胜出。
**两种读法都落在箭头所指的墙上**，与题面"移去箭头所指的那面墙……形成的房间最大"吻合 ✓。

**自造平局用例**（$n=m=2$，四格全 $15$）：四面内部墙合并值都是 $2$，候选为 $(1,1,\texttt{E})$、$(2,1,\texttt{N})$、$(2,1,\texttt{E})$、$(2,2,\texttt{N})$。
key 序第一个是 $c=1,\ r=2,\ \texttt{N}$ ⇒ 期望输出 `2 1 N`。若把循环写成"行在外、列在内"（行优先），
就会先撞上 `1 1 E`，平局规则直接违反题面 —— 这是本题最常见的 WA 点之一。

### 2.6 溢出防护与退化边界

**数值上界（先算再决定类型）**：$a[r][c]\le15$；$sz[k]\le nm\le2500$；`sz[x]+sz[y]` $\le2500$（两块不相交，和仍是一块的规模上界）；房间数 $\le2500$。
全程**没有任何乘法**，`int` 余量巨大，不需要 `long long`，更不需要 `__int128`。这题的"溢出防护"其实是**下标与状态**的防护：

| 风险点 | 处理 | 不加会怎样 |
|---|---|---|
| `id[][]` 全局默认 $0$ | $0$ 约定"未访问"，编号从 $1$ 起 | 编号从 $0$ 起时 `!id[i][j]` 与"已访问"混淆，第一个房间进不去 |
| `sz[0]` 也是 $0$ | 越界读 `id[0][c]`/`id[r][m+1]` **静默返回 $0$**，不报错 | 外墙被当成候选，得到 $\text{sz}[\cdot]+0$ 的假合并值 |
| $r\ge2$、$c\le m-1$ 守卫 | 枚举墙时显式判 | 见下面"侥幸正确" |
| BFS 落点 | 先判墙位、再判越界、最后判 `id` | 数据若违反"四周必有外墙"，越界写坏 `id`，未定义行为 |
| `best` 初值 | 哨兵 `-114514`（负无穷家族） | 初值 $0$ 也能过，但哨兵能让"从未更新"一眼可辨 |

**"侥幸正确"必须避免**：删掉 $r\ge2$ 守卫后，第一行的顶边外墙会造出候选 $\text{sz}[x]+\text{sz}[0]=\text{sz}[x]$；
由引理 8 真实合并值恒 $>\max\text{sz}$，这些假候选最终都被真候选压掉，程序**碰巧**还对。
可一旦"至少 $2$ 个房间"的保证消失（单房间极端数据），假候选立刻成为答案，第四行输出非法的 `1 c N`。
用"碰巧对"去赌数据范围是我最不愿养成的习惯——写一行守卫成本几乎为零。

**退化边界清单（后面全部手算过）**：① $n=1$ 无横内部墙 ⇒ 只有 `E` 候选（用例 B）；
② $m=1$ 无竖内部墙 ⇒ 只有 `N` 候选（用例 C）；③ 每格全 $15$ ⇒ 房间数 $=nm$、$mx=1$、最优合并 $=2$（用例 D）；
④ 蛇形单间 ⇒ 最坏递归深度，已用 BFS 规避；⑤ 同块墙密集（题图就有）⇒ 靠 `x!=y` 处理。

### 2.7 归约：本题到底把什么化成了什么

$$\text{城堡输入}\xrightarrow[\text{引理1}]{\text{位掩码}\to\text{通行谓词}}\text{网格图 }G=(V,E)\xrightarrow[\text{引理3,4}]{\text{等价类}}\text{连通块+块大小}$$
$$\xrightarrow[\text{引理7}]{\text{拆墙}=\text{加一条边}}\max_{e\in\text{跨块内部墙}}\bigl(\text{sz}[\text{side}_1]+\text{sz}[\text{side}_2]\bigr)\xrightarrow[\text{引理9,10}]{\text{平局规则}}\text{字典序}(c\uparrow,r\downarrow,\texttt{N}\prec\texttt{E})$$

**另一种实现**：连通块也可用并查集——每格对每个"无墙"方向把两格 `getrt` 合并并按秩维护 `sz`，枚举墙时对两端 `getrt` 求和，
复杂度 $O(nm\alpha)$，完全等价。本题 $nm\le2500$，洪泛更好写、更难写错；但若数据涨到 $n,m\le2000$ 且追加"拆多面墙"的查询，并查集就是必经之路。

## 3. 模式总结（Pattern Summary）

按真实思考顺序，一个技巧一条，不合并：

- **探索特殊机制** — "任意个子集之和"就是位掩码：先用示意图抽查 3 个格子，钉死 西$1$/北$2$/东$4$/南$8$ 的锯齿顺序，再翻译成通行谓词 `!(a&wb[d])`。
- **口径校准（面积非周长）** — "大小 = 个单位"指**格数**；把"房间"严格写成可通行关系的等价类，才能名正言顺地"数格子"。
- **考虑简化版** — 剥掉"拆一面墙"这一问，只剩"数房间 + 最大房间"，直接落到网格洪泛；同时留下 $O((nm)^2)$ 的笨基准用于对照。
- **经典解法 1：洪泛求连通块** — 数组队列 BFS，`id` 兼任 visited 与块号，`sz[k]` 累加格数；**入队即标记即计数**防止重复计数，迭代代替深递归防爆栈。
- **加回增量** — 拆墙 $=$ 往图里加一条边；局部性引理（引理 7）证明"新房间 $=$ 墙两侧连通块之并"，于是重跑洪泛降成查表相加 $O(1)$。
- **反例剖析 1（贪心 A 失败）** — "最大 $+$ 次大 $sz$" 丢掉了"必须共墙"的可行性约束：题图 $9+8=17$ 不可实现。
- **反例剖析 2（贪心 B 失败）** — "让最大房间吞邻居" 假设了极值含最大元素，跨块配对不提供该性质：$1\times12$ 用例给出 $5$ vs 真实 $6$。
- **同结构去重（同块墙）** — 墙两侧同房间时合并值仍是 $sz$，绝不能写 `sz[x]+sz[y]`：题图会得 $18$，被题面断言的 $16$ 直接证伪。
- **经典解法 2：把题面平局规则写成扫描序** — 列↑、行↓、同格 N 先于 E 的三重循环 + **严格大于**才更新，等价于取 key 最小元；行优先扫描会 WA。
- **归约** — 城堡 $=$ 网格图；房间 $=$ 连通块；拆墙 $=$ 一次加边；答案 $=$ 跨块边的两端块大小之和的最大值 $+$ 字典序 tie-break。换并查集同样成立。

## 4. 真实解法

### 4.1 符号表（代码里出现的每一个状态）

| 符号 | 存什么 | 初值 / 约定 | 一句话记忆 |
|---|---|---|---|
| `m,n` | 列数、行数 | 读入顺序就是 `m` 在前 | "**先宽后高**" |
| `a[r][c]` | 格 $(r,c)$ 的墙位掩码，$r\in[1,n],c\in[1,m]$ | 输入给定，$0\sim15$ | `1西 2北 4东 8南` |
| `id[r][c]` | 格 $(r,c)$ 所属房间编号 $1..cnt$ | 全局默认 $0$ = "未访问" | 既当 visited 又当块号 |
| `sz[k]` | 编号 $k$ 的房间**格数** | 全局默认 $0$，洪泛中 `++` | 面积 = 格数 |
| `qr[],qc[]`,`qh,qt` | BFS 数组队列及其头尾下标 | 每次 `bfs()` 内 `qh=qt=0` | 容量 $nm$，一次调用内不重用 |
| `dr[],dc[],wb[]` | 四个方向的行/列增量与对应墙位 | `constexpr`，顺序 **西、东、北、南** | 三个表**同下标**，改一个必须改三个 |
| `cnt` | 房间数 $=$ 洪泛启动次数 | $0$ | 引理 5 |
| `mx` | 最大房间格数 | $0$（随后 $\max$ 覆盖） | 第二行答案 |
| `best,br,bc,bd` | 最优合并大小与其墙描述符（行、列、方位） | `best=-114514` 哨兵，`bd='N'` | 第三、四行答案 |

### 4.2 编号步骤

1. **读入**：`cin>>m>>n;` 然后 $n$ 行 $\times m$ 列读进 `a[][]`（步骤 1 的顺序坑已在 §1 说明）。
2. **洪泛求块**：行优先 `for i=1..n, j=1..m`，若 `!id[i][j]` 则 `bfs(i,j,++cnt)`。
3. **单块扩展**（`bfs`）：起点入队并立即 `id=sr,sc→k`；循环"弹出 $(r,c)$ → `++sz[k]` → 对 $d=0..3$，若 `!(a[r][c]&wb[d])` 且落点在范围内且 `id==0`，则标记并入队"。
4. **求最大房间**：`mx = max(mx, sz[k])`，$k=1..cnt$。
5. **枚举候选墙**（严格按引理 10 的键序）：外层 `c=1..m`（西→东），中层 `r=n..1`（南→北），同格内**先北墙后东墙**。
6. **两侧块号**：北墙用 `x=id[r][c],y=id[r-1][c]`；东墙用 `x=id[r][c],y=id[r][c+1]`。
7. **跳过同块**：`x==y` 直接忽略（引理 7 推论的第一分支）；否则算 `v=sz[x]+sz[y]`。
8. **严格更新**：`v>best` 才写回 `best,br,bc,bd`（$\to$ 平局保留更靠西、靠南、北墙先到的那一面）。
9. **输出**：`cnt`、`mx`、`best` 各占一行；第四行 `br bc bd`（`br`/`bc` 直接是题面要的 $1$-based 行、列，无需换算）。

### 4.3 复杂度

- 时间：洪泛 $O(nm)$（每格入队/出队各一次，出队做 $4$ 次常数判断）+ 求 `mx` $O(cnt)$ + 枚举墙 $O((n-1)m+n(m-1))=O(nm)$ $\Rightarrow$ 总计 $O(nm)$，$n,m\le50$ 时约 $2.5\times10^3$ 格、$10^4$ 次操作。
- 空间：`a`、`id` 各 $55\times55$ 的 `int`，`sz`/`qr`/`qc` 各 $3025$ 个 `int`，合计 $\approx 6\times10^4$ 字节量级，远低于限制。
- 无递归 ⇒ 栈占用与数据无关。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{55},mxm{55};            //n,m<=50，+5 松弛

int n,m;                                  //n 行 m 列（第一行先给 m 再给 n）
int a[mxn][mxm],id[mxn][mxm],sz[mxn*mxm];
int qr[mxn*mxm],qc[mxn*mxm];              //数组队列：避免深递归爆栈
constexpr int dr[4]{0,0,-1,1},dc[4]{-1,1,0,0},wb[4]{1,4,2,8};

//把 (sr,sc) 所在房间洪泛成编号 k，格数累加进 ::sz[k]
void bfs(int sr,int sc,int k)
{
	int qh=0,qt=0;
	qr[qt]=sr;qc[qt]=sc;id[sr][sc]=k;++qt;
	while(qh<qt)
	{
		int r=qr[qh],c=qc[qh];++qh;
		++sz[k];                           //出队即计数：每格至多入队一次
		for(int d=0;d<4;++d)
		{
			int nr=r+dr[d],nc=c+dc[d];
			if(a[r][c]&wb[d])continue;     //该方向有墙
			if(nr<1||nr>n||nc<1||nc>m)continue;   //外墙兜底，题面保证用不到
			if(id[nr][nc])continue;
			id[nr][nc]=k;qr[qt]=nr;qc[qt]=nc;++qt;
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int cnt=0,mx=0,best=-114514,br=0,bc=0;
	char bd='N';                           //best direction

	cin>>m>>n;
	for(int i=1;i<=n;++i)
		for(int j=1;j<=m;++j)
			cin>>a[i][j];                  //1 西 2 北 4 东 8 南

	for(int i=1;i<=n;++i)
		for(int j=1;j<=m;++j)
			if(!id[i][j])
				bfs(i,j,++cnt);
	for(int k=1;k<=cnt;++k)
		mx=max(mx,sz[k]);

	//枚举顺序：列 西->东，行 南->北，同格先北墙后东墙；严格更大才更新
	for(int c=1;c<=m;++c)
		for(int r=n;r>=1;--r)
		{
			if(r>1&&(a[r][c]&2))
			{
				int x=id[r][c],y=id[r-1][c];
				if(x!=y&&sz[x]+sz[y]>best)
					best=sz[x]+sz[y],br=r,bc=c,bd='N';
			}
			if(c<m&&(a[r][c]&4))
			{
				int x=id[r][c],y=id[r][c+1];
				if(x!=y&&sz[x]+sz[y]>best)
					best=sz[x]+sz[y],br=r,bc=c,bd='E';
			}
		}

	// cerr<<cnt<<' '<<mx<<' '<<best<<'\n';   //调试用，风格指南要求保留注释
	cout<<cnt<<'\n'<<mx<<'\n'<<best<<'\n';
	cout<<br<<' '<<bc<<' '<<bd<<'\n';
	return 0;
}
```

**与风格指南的一处有意偏离**：内部用 **1-based**（行 $1..n$、列 $1..m$）。理由是第四行答案本身就是题面的 $1$-based 行列号，
`br/bc` 可以直接输出、省掉 $\pm1$ 换算这个最易错的点；同时 `id[0][*]`、`id[*][0]` 的全局 $0$ 天然充当"越界即未访问"哨兵，
再配合 §2.6 的 $r>1$、$c<m$ 守卫，两种约定都不影响正确性。其余均按规范：`bits/stdc++.h`、全局数组、`constexpr ...{55}`、Tab 缩进、
运算符不加空格、`'\n'` 不用 `endl`、`cin.tie/cout.tie/ios::sync_with_stdio` 顺序、注释保留 `cerr` 调试行。
