# P1918 保龄球

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 个位置排成一列，第 $i$ 个位置有 $a_i$ 个瓶子，**各个位置的瓶子数两两不同**。现在有 $Q$ 次询问，每次给出一个目标数 $m$，要求输出「瓶子数恰好等于 $m$ 的位置编号」（$1$ 起），若不存在则输出 $0$。

### 1.2 关键约束与规模暗示

- $n,Q\le 10^5$，$a_i,m\le 10^9$。
- $10^5\times 10^5=10^{10}$，逐询问扫描全部位置必然超时，必须把「查找」做得比 $O(n)$ 快。
- **「各个位置的瓶子数不同」是这道题的关键条件**：它保证对于给定的 $m$，满足 $a_i=m$ 的位置至多一个，于是答案唯一，题目不会产生歧义。如果允许重复，题目就得规定输出哪个位置，而题面并没有规定——这反过来说明必须利用「互不相同」。
- $a_i\le 10^9$ 用 `int` 存足够；编号从 $1$ 开始，输出时要注意加一。

## 2. 思维链（Chain-of-thought）

### 2.1 问题的本质是「精确查找」

抛开背景，这题就是：维护一个「值 → 下标」的映射，回答 $Q$ 次「值等于 $m$ 的下标是多少」。

因为值两两不同，映射是**单射**，每个 $m$ 的答案唯一。于是问题没有贪心、没有 DP，唯一的矛盾是「如何快速判断某值在不在、若在则下标是几」。

### 2.2 直接做为什么不行

对每次询问扫描 $n$ 个位置：最坏 $10^{10}$ 次比较。虽然比较很便宜，但 $10^{10}$ 已经远超 1 秒能做的量级（约 $10^8\sim10^9$ 次简单操作），必然 TLE。这正是 $50\%$ 数据（$n,Q\le 1000$，$10^6$ 次）能过、$100\%$ 过不了的分水岭。

### 2.3 两条出路

**出路一：哈希表**。边读边把 $a_i$ 映射到下标，询问 $O(1)$ 平均。总 $O(n+Q)$。

**出路二：排序 + 二分**。把 $(a_i,i)$ 按 $a_i$ 升序排序，询问时在有序数组上二分找第一个 $\ge m$ 的位置，判断是否恰好等于 $m$。总 $O(n\log n+Q\log n)$。

两条都可行。选排序的理由是：

1. 复杂度是**确定的** $O((n+Q)\log n)$，不依赖哈希的抗碰撞质量；
2. 有序性还能顺手回答「不存在」——二分结束时若指针对应值不等于 $m$，就说明整个数组里没有 $m$；
3. 常数小，代码短。

**引理（二分查找的正确性）**：设排好序的数组为 $b_0\le b_1\le\cdots\le b_{n-1}$。令 $p$ 为最小的满足 $b_p\ge m$ 的下标（若不存在则 $p=n$）。则「存在 $i$ 使 $b_i=m$」当且仅当 $p<n$ 且 $b_p=m$。

**证明**：
- 若 $p<n$ 且 $b_p=m$，取 $i=p$ 即存在。
- 反之若存在 $b_i=m$，由 $p$ 的最小性 $p\le i$；又 $b$ 单调不减，$b_p\le b_i=m$，结合 $b_p\ge m$ 得 $b_p=m$，且 $p\le i<n$。$\square$

### 2.4 边界

- 询问值比所有 $a_i$ 都大：二分返回 $p=n$，输出 $0$。
- 询问值比所有 $a_i$ 都小：$p=0$，若 $b_0\ne m$ 输出 $0$。
- $a_i$ 与 $m$ 都可以到 $10^9$，但都在 `int` 范围内，不需要 `long long`；下标也在 $10^5$ 内。
- 输入说「第四行至文件末尾」每次询问一行，同时又给了 $Q$。稳妥起见按 $Q$ 次读入；数据若因换行/空格不同，`cin>>` 也会自动跳过空白，不受影响。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 瓶子数两两不同 $\Rightarrow$ 答案唯一，问题退化为「精确查找」。
- **failed attempt** — 逐询问扫描是 $O(nQ)=10^{10}$。
- **reduce to easier problem** — 把「值→下标」建成有序表，查询变成二分。
- **classic problem solution** — 按值排序后 `lower_bound`，用相等性判存在。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 位置数 | 读入 | 维度 |
| `a[i]` | `pair<int,int>[100005]` | `(瓶子数, 原下标)` | 读入，下标存 $0$ 起 | array |
| `q` | `int` | 询问次数 | 读入 | query |
| `x` | `int` | 当前询问的 $m$ | 读入 | 临时 |
| `l,r` | `int` | 二分区间 $[l,r)$ | $0,n$ | 半开区间 |

### 4.2 算法步骤

1. 读入 $n$ 和 $n$ 个 $a_i$，把 `a[i]={值,i}`（$i$ 为 $0$ 起下标）。
2. 对 `a[0..n-1]` 按 `first` 升序排序（`pair` 默认比较，`second` 只在值相等时起作用，而值互不相同，不影响）。
3. 读入 $Q$；对每个询问 $m$：
   - 在半开区间 $[0,n)$ 上二分出第一个 `a[mid].first >= m` 的位置 $l$；
   - 若 $l<n$ 且 `a[l].first==m`，输出 `a[l].second+1`（还原成 $1$ 起）；
   - 否则输出 $0$。
4. 每个答案单独一行。

### 4.3 复杂度与验证状态

- **时间复杂度**：排序 $O(n\log n)$，每个询问 $O(\log n)$，总计 $O(n\log n+Q\log n)$。
- **空间复杂度**：$O(n)$。
- 编译 `g++ -std=c++17 -O2 -Wall -Wextra`，无警告。
- 自测：$n=3$、$a=\{3,1,2\}$，询问 $1,3,4$ 输出 `2 1 0`；另用 200 组随机数据与 $O(nQ)$ 暴力对拍全部一致。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n,q;
pair<int,int> a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i].first;
		a[i].second=i;      // 0-based 下标，输出时 +1
	}
	sort(a,a+n);
	cin>>q;
	for(int i=0,x;i<q;++i)
	{
		cin>>x;
		int l=0,r=n;
		while(l<r)
		{
			int mid=(l+r)>>1;
			if(a[mid].first<x)
				l=mid+1;
			else
				r=mid;
		}
		if(l<n&&a[l].first==x)
			cout<<a[l].second+1<<'\n';
		else
			cout<<0<<'\n';
	}
	return 0;
}
```
