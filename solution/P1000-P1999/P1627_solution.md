# P1627 [CQOI2009] 中位数

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给出 $1,2,\dots,n$ 的一个排列和一个数 $b$（$b$ 一定在排列中）。统计有多少个**长度为奇数**的连续子段，其**中位数**（排序后位于正中间的那个数）恰好等于 $b$。

### 输入输出格式

- **输入格式**：第一行 $n,b$；第二行 $n$ 个整数，是 $1..n$ 的一个排列。
- **输出格式**：一行一个整数，表示答案。
- **数据规模**：$n\le10^5$（$30\%$ 数据 $n\le100$，$60\%$ 数据 $n\le1000$）。

### 关键约束分析

1. $n\le10^5$，枚举所有 $O(n^2)$ 个子段再排序是 $O(n^3\log n)$，只能过 $30\%$；正解必须是 $O(n)$ 或 $O(n\log n)$。
2. 排列保证每个数只出现一次，特别地 $b$ 唯一——这使得"中位数是 $b$"可以等价为计数条件。
3. 答案最大约为 $n^2/4\approx2.5\times10^9$，**超过 `int`**，必须用 `long long`。
4. 边界：$n=1$ 时只有长度为 $1$ 的子段，答案 $1$；$b$ 在端点时一侧没有元素，计数数组必须有"空前缀"这一项。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：中位数只看"比它大的有几个、小的有几个"

长度为奇数的子段，中位数是排序后第 $(len+1)/2$ 小的元素。如果子段含有 $b$：

**引理 1（中位数的等价刻画）**：设子段长度为奇数且包含 $b$，则其中位数为 $b$ 当且仅当子段中"大于 $b$ 的元素个数"等于"小于 $b$ 的元素个数"。

*证明*：设大于、等于、小于 $b$ 的元素个数分别为 $g,e,l$，$e=1$（$b$ 唯一），$g+l+1=len$。

若 $g=l=k$，则 $len=2k+1$，排序后第 $k+1$ 个元素之前恰有 $k$ 个元素 $<b$，故第 $k+1$ 个就是 $b$，中位数为 $b$。

反过来，若中位数为 $b$，则排序后 $b$ 位于第 $(len+1)/2$ 位，它前面恰有 $(len-1)/2$ 个元素，全部 $<b$（因为 $b$ 唯一，没有别的等于 $b$ 的元素），故 $l=(len-1)/2$，同理 $g=(len-1)/2$，两者相等。$\square$

推论：满足条件的子段长度自动是奇数，所以"长度为奇数"这个条件可以与"$g=l$"合并，不必单独处理。

### 第二步：把"大小比较"换成 $\pm1$ 的求和

构造函数

$$v_i=\begin{cases}+1,&a_i>b\\0,&a_i=b\\-1,&a_i<b\end{cases}$$

则子段 $[l,r]$ 中"大于的个数减小于的个数"恰为 $\sum_{i=l}^{r}v_i$。由引理 1，**中位数为 $b$ 且包含 $b$ 的奇数长子段 $\iff$ 该子段和为 $0$**。

### 第三步：前缀和把"子段和"变成"两点相等"

**引理 2**：设 $pre[0]=0$，$pre[i+1]=pre[i]+v_i$，则 $\sum_{i=l}^{r}v_i=pre[r+1]-pre[l]$，于是子段和为 $0$ 当且仅当 $pre[r+1]=pre[l]$。

*证明*：望远镜求和。$\square$

设 $b$ 的位置为 $pos$（$v_{pos}=0$）。任何包含 $pos$ 的子段 $[l,r]$ 满足 $l\le pos\le r$，即 $l\in[0,pos]$、$r+1\in[pos+1,n]$。

**引理 3（参数化的双射）**：映射 $(l,r)\mapsto(l,\,r+1)$ 是从"包含 $pos$ 的子段集合"到 $[0,pos]\times[pos+1,n]$ 的双射。

*证明*：给定子段唯一确定 $l$ 与 $r+1$；给定 $(l,q)\in[0,pos]\times[pos+1,n]$，取 $r=q-1$，则 $l\le pos\le q-1=r$，唯一确定一个包含 $pos$ 的子段。两个方向互逆。$\square$

于是问题变成：统计有多少对 $(l,q)$ 满足 $l\in[0,pos]$、$q\in[pos+1,n]$、$pre[l]=pre[q]$。

### 第四步：按前缀和的值分类计数

**引理 4（直方图计数）**：设 $c_L[x]$ 为 $\{pre[l]:0\le l\le pos\}$ 中值 $x$ 的出现次数，$c_R[x]$ 为 $\{pre[q]:pos+1\le q\le n\}$ 中值 $x$ 的出现次数，则答案

$$\sum_x c_L[x]\cdot c_R[x].$$

*证明*：由引理 3，每一对合法 $(l,q)$ 恰被数一次；固定 $x$，选择 $l$ 有 $c_L[x]$ 种、选择 $q$ 有 $c_R[x]$ 种，由乘法原理贡献 $c_L[x]c_R[x]$；不同的 $x$ 对应不同的事件，由加法原理求和。$\square$

注意 $l=pos$ 与 $q=pos+1$ 都被包含，分别对应"子段左端就是 $b$"和"子段右端就是 $b$"，所以长度 $1$ 的子段 $\{b\}$ 也被正确计入（$pre[pos]=pre[pos+1]$）。

### 第五步：实现细节

$pre$ 的取值范围是 $[-n,n]$，用一个长度 $2n+1$ 的计数数组、下标加 $n$ 平移即可，避免 `map`。整体 $O(n)$。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 含 $b$ 的奇数段中位数为 $b$ $\iff$ 大于与小于 $b$ 的个数相等。
- `reduce to easier problem` — 用 $+1/0/-1$ 赋值，把"个数相等"变成"子段和为 $0$"。
- `classic problem solution` — 前缀和把子段条件转成两点函数值相等。
- `classic problem solution` — 两侧分别统计前缀和出现次数，用乘法原理配对。
- `explore its property` — 条件本身蕴含偶数长度不可能成立，可省掉奇偶性判断。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $n$ | `n` | 排列长度 |
| $b$ | `b` | 目标中位数 |
| $a_i$ | `a[i]` | 输入的排列，0-based |
| $pos$ | `pos` | $b$ 所在下标；读入时记录，初值 $-1$ |
| $v_i$ | `v[i]` | $a_i$ 相对 $b$ 的符号：$+1/0/-1$ |
| $pre[i]$ | `pre[i]` | 前缀和，`pre[0]=0`，`pre[i+1]=pre[i]+v[i]` |
| $c_L$ | `cl[]` | 左半前缀和计数，下标 $pre[l]+n$ |
| $c_R$ | `cr[]` | 右半前缀和计数，下标 $pre[q]+n$ |
| 答案 | `ans` | $\sum_x cl[x]\cdot cr[x]$，`i64` |

### 算法步骤

1. 读入 $n,b$ 与排列，顺带记录 `pos`（$a_{pos}=b$）。
2. 计算 `v[i]=(a[i]>b)-(a[i]<b)`，再算 `pre`。
3. 对 $l=0..pos$ 执行 `++cl[pre[l]+n]`；对 $q=pos+1..n$ 执行 `++cr[pre[q]+n]`。
4. 对每个下标 $x\in[0,2n]$ 累加 `ans+=(i64)cl[x]*cr[x]`。
5. 输出 `ans`。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}(n)$，四趟线性扫描；$n=10^5$ 实测 $<0.01$ s。
- **空间复杂度**：$\mathcal{O}(n)$，`pre` 与两个长度 $2n+1$ 的计数数组。

### 正确性验证

引理 1 把中位数条件等价为"大于/小于个数相等"，引理 2 把它化为前缀和相等，引理 3 保证 $(l,q)$ 与子段一一对应（不漏 $l=pos$ 或 $q=pos+1$ 的退化情形），引理 4 完成计数。数值上单个 $cl[x]\le n$，乘积 $\le10^{10}$，用 `i64` 累加安全；`pre` 与 `+n` 平移后的下标落在 $[0,2n]$，数组开 `2*mxn` 足够。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1627 [CQOI2009] 中位数
// https://www.luogu.com.cn/problem/P1627
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n,b,a[mxn],v[mxn],pre[mxn];
int cl[mxn*2],cr[mxn*2];                // 前缀和计数，下标平移 n

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>b;
	int pos=-1;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		if(a[i]==b)
			pos=i;
	}
	for(int i=0;i<n;++i)
		v[i]=(a[i]>b)-(a[i]<b);         // 大于 b 记 +1，小于记 -1，b 记 0
	for(int i=0;i<n;++i)
		pre[i+1]=pre[i]+v[i];
	for(int l=0;l<=pos;++l)
		++cl[pre[l]+n];
	for(int q=pos+1;q<=n;++q)
		++cr[pre[q]+n];
	i64 ans=0;
	for(int x=0;x<=2*n;++x)
		ans+=(i64)cl[x]*cr[x];
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **忘记含 $b$ 的前提**：本算法只统计包含 $pos$ 的段；不含 $b$ 的段中位数不可能是 $b$，但若把左右范围写成 $[0,n]$ 就会重复/越界计数。
2. **左右范围写错**：左边取 $l\in[0,pos]$、右边取 $q\in[pos+1,n]$，两段不能重叠也不能漏掉 $l=pos$ 或 $q=pos+1$。
3. **答案用 `int`**：$n=10^5$ 时答案可达 $2.5\times10^9$，必须 `long long`。
4. **计数数组下标越界**：$pre\in[-n,n]$，平移 $n$ 后范围 $[0,2n]$，数组长度要 $2n+1$。
5. **额外判奇偶**：由引理 1 等价性，和为 $0$ 的段长度自动为奇数，多写一个判断只会引入错误。
