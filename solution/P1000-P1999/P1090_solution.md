# P1090 [NOIP 2004 提高组] 合并果子

---

## 一、重读题目

**问题重述**：有 $n$ 堆果子，每堆有 $a_i$ 个果子（每个果子重量为 $1$）。每次操作可以选择 **任意两堆** 合并成一堆，消耗的体力值等于两堆重量之和。经过 $n-1$ 次合并后只剩一堆。求最小总体力消耗。

**数据范围**：$n \le 10^4$，$a_i \le 2\times 10^4$，答案在 $32$ 位有符号整数范围内。

**示例**：$n=3,\ a=[1,2,9]$。先合并 $1,2$（消耗 $3$），再合并 $3,9$（消耗 $12$），总消耗 $15$，可以证明这是最小值。

---

## 二、完整推理链

### 2.1 问题建模——合并树

每次合并两堆 → $n-1$ 次合并后剩一堆。可以将合并过程表示为一棵 **二叉树**（合并树）：

- $n$ 个叶子结点 = 原始 $n$ 堆果子
- 每个内部结点 = 一次合并产生的新堆
- 根结点 = 最终的一堆

叶子结点的权值 = $a_i$，内部结点的权值 = 其两子结点权值之和。

总消耗 = 所有内部结点的权值之和。

对于任意叶子结点 $i$，设其在树中的深度为 $d_i$（根深度为 $0$，叶子到根的路径上的内部结点数），则它对总消耗的贡献为 $a_i \times d_i$：

> **证明**：叶子 $i$ 每向上合并一层，它的重量就被加进一个内部结点一次。一路上升 $d_i$ 层，共被累加 $d_i$ 次。因此总消耗 $=\sum a_i \cdot d_i$。

这就是经典的 **加权外部路径长度**（Weighted External Path Length）问题。

### 2.2 最优策略——贪心选择

**贪心策略**：每一步都选择当前 **重量最小的两堆** 进行合并。

#### 正确性证明（交换论证法）

设 $a_1 \le a_2 \le \cdots \le a_n$。

**引理 1**：存在一棵最优合并树，使得深度最大的两个叶子是 $a_1$ 和 $a_2$（即最小的两个元素在树的最底层）。

> **证明**：任取一棵最优树，设深度最大的叶子为 $x$ 和 $y$。  
> 若 $x \neq a_1$，则 $a_1$ 的深度 $\le$ $x$ 的深度（因为 $x$ 是最深的）。  
> 交换 $a_1$ 与 $x$ 的位置：新树的消耗变化量  
> $\Delta = (a_1 d_x + x d_{a_1}) - (x d_x + a_1 d_{a_1}) = (a_1 - x)(d_x - d_{a_1}) \le 0$。  
> 因为 $a_1 \le x$ 且 $d_x \ge d_{a_1}$，所以 $\Delta \le 0$，交换后不会更差。同理可证 $a_2$。  
> 因此存在最优树使 $a_1, a_2$ 处于最深层且互为兄弟。

**引理 2**：在最优树中，$a_1$ 和 $a_2$ 必然在第一步被合并。

> 由引理 1，$a_1$ 和 $a_2$ 是兄弟叶子，它们在同一个内部结点处合并。如果没有在第一步合并它们，可以先执行其他合并，但最终的合并树结构不变。由于我们只关心最终合并树的结构而非合并顺序，总存在一种最优顺序使得第一步合并 $a_1, a_2$。若某个顺序没有先合并它们，可以重排合并次序而不改变最终树形——因为 $a_1,a_2$ 的合并独立于其他元素，提至第一步不影响其他合并。

**归纳步骤**：

1. 将 $a_1, a_2$ 合并为 $a_1 + a_2$，消耗体力 $a_1 + a_2$。
2. 将 $a_1 + a_2$ 放回集合，问题规模降为 $n-1$。
3. 对剩下的 $n-1$ 堆重复以上过程。

由引理 2，这一步是最优的；由归纳假设，后续步骤也是最优的。因此贪心策略全局最优。

**时间复杂度**：$O(n \log n)$，使用优先队列（最小堆）每次取出两个最小值再压入合并结果，共 $n-1$ 次操作。

## 三、模式总结

| 方面 | 内容 |
|------|------|
| **所属范式** | 贪心 — 哈夫曼编码 / 最优合并模式 |
| **核心思想** | 每次选最小的两个合并，等价于构建一棵带权路径长度最小的二叉树 |
| **识别特征** | 两两合并、合并代价为两元素之和、最小化总代价 → 直接联想 Huffman |
| **典型变体** | 石子合并（区间 DP，限制相邻合并）、多路归并、K 叉 Huffman（配合补零） |
| **数据结构** | 优先队列（最小堆），$n$ 较大时使用 `std::priority_queue`（$O(n \log n)$） |
| **加强版** | [P6033](https://www.luogu.com.cn/problem/P6033) $n \le 10^7$，需桶排序 + 双队列优化至 $O(n)$ |

## 四、正式解法

### 算法流程

```
1. 读入 n 和数组 a[0..n-1]
2. 将所有 a[i] 压入最小堆
3. ans = 0
4. 重复 n-1 次：
     x = 堆顶（最小），弹出
     y = 堆顶（次小），弹出
     z = x + y
     ans += z
     将 z 压入堆
5. 输出 ans
```

### 复杂度

- 时间：$O(n \log n)$，其中 $n \le 10^4$，完全可过。
- 空间：$O(n)$。

### 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 果子种类数 |
| $a_i$ | 第 $i$ 种果子的数目 |
| $d_i$ | 叶子 $i$ 在合并树中的深度（根深度为 $0$） |
| $ans$ | 最小体力消耗总值 |

## 五、示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64 = long long;

constexpr int mxn{10005};
int n;
priority_queue<int, vector<int>, greater<int>> pq;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin >> n;
	for (int i = 0; i < n; ++i)
	{
		int x;
		cin >> x;
		pq.push(x);
	}

	i64 ans = 0;
	while (pq.size() > 1)
	{
		int x = pq.top(); pq.pop();
		int y = pq.top(); pq.pop();
		int z = x + y;
		ans += z;
		pq.push(z);
	}

	cout << ans << '\n';
	return 0;
}
```

### 代码要点说明

- 使用 `greater<int>` 作为比较器实现最小堆
- `pq.size() > 1` 作为循环条件，恰好执行 $n-1$ 次
- $ans$ 用 `i64`（`long long`）防止中间结果溢出（虽然题目保证小于 $2^{31}$，但用 `i64` 是安全习惯）
- 注意题目保证答案在 $32$ 位有符号整数范围内，因此 `int` 也可行

**本题核心口诀**：*合并果子选最小，哈夫曼树总不差。优先队列来维护，$n \log n$ 过万家。*
