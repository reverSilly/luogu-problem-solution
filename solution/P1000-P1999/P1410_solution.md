# P1410 子序列

> 标签：动态规划 DP / 二分图染色 / 背包 · 难度：省选/NOI-（福建省历届夏令营）

## 1. 重新读题

**问题重述（简化版）**

给一个长度为 $N$（$N$ 为偶数）的序列 $a_1..a_N$。把所有下标分成两堆 $A,B$，要求 $|A|=|B|=N/2$，并且把 $A$ 的下标从小到大排好后读出的值**严格**递增，$B$ 同理。问这样的分法存不存在。输入若干行、每行一组：先给 $N$ 再给 $N$ 个数，读到文件尾结束；存在输出 `Yes!`，否则 `No!`（感叹号是题面口径，不是笔误）。

**约束与暗示**

| 量 | 范围 |
|---|---|
| $N$ | 子任务一 $N\le20$；子任务二 $N\le100$；子任务三 $N\le2000$；$N$ 为偶数 |
| 行数 | 共三组数据，每组数据行数 $\le50$ |
| 元素值 | $0\le a_i\le 10^9$ |
| 输出 | 每行一个 `Yes!` / `No!`，不输出方案 |

$N\le20$ 正好是"每个下标选 $A$ 或 $B$"的 $2^{20}\approx10^6$ 暴力（2.2 会算准），说明官方允许的起点是指数的；$N\le2000$ 掐死指数和 $O(N^3)$，指向 $O(N^2)$（$2000^2=4\times10^6$）再乘 50 行的额度。标签只写了"动态规划 DP"，没有写图论——但本题的 DP 恰好长在一张图（连通块）上，2.6、2.8 会说明为什么这个 DP 省不掉。

**口径（先钉死）**

1. "子序列"保持原下标的相对顺序；"划分"= 两堆不相交、并起来是全部 $N$ 个下标，且**各自恰好 $N/2$ 个**。
2. **严格**递增：相等值不能同堆（$\ge$ 就是冲突，不只是 $>$）。
3. 本题不是"最长上升子序列"的长度题，也不是"前半升后半降"的 bitonic 变体。后两者都是"挑一个子序列，使它自身满足某个形状/最长"，元素可以不覆盖全部；本题要求**两个互补的子序列各自单调且各占一半**，所以 $\text{LIS}+\text{LDS}$ 那套 $O(N\log N)$ 模板、以及"峰值拆分不重不漏"的讨论在这里都不适用——真正的对象是"下标集合的 2-划分"。
4. 值域 $10^9$ 只做比较、不参与算术。

**下标约定**：正文与题面一致按 $1$-based（$i=1..N$）叙述；代码内部一律 $0$-based（$i=0..n-1$），把 $a_i$ 存进 `a[i-1]`。因为所有判定只用到下标之间的**大小关系**（谁在前谁在后），整体平移不改变任何边的存在性，两套编号严格等价。

## 2. 思维链（Chain-of-thought）

### 2.1 先摸清"一堆里允许出现什么"——把全局要求压成一对一对的局部判据

**引理 1（堆内相邻判据）** 设 $S=\{i_1<i_2<\cdots<i_t\}$。则 $(a_{i_1},\dots,a_{i_t})$ 严格递增 $\iff$ 对每个 $1\le r<t$ 都有 $a_{i_r}<a_{i_{r+1}}$。

**证明**：（$\Rightarrow$）严格递增定义就是逐位 $a_{i_r}<a_{i_{r+1}}$。（$\Leftarrow$）对 $r$ 归纳：$r=1$ 即假设；设 $a_{i_1}<\cdots<a_{i_r}$，由 $a_{i_r}<a_{i_{r+1}}$ 与实数序的传递性得 $a_{i_r}<a_{i_{r+1}}$ 且前面每一项都 $<a_{i_{r+1}}$，故逐位都严格增。$\blacksquare$

这一步的价值：合法的 $S$ 只由"相邻两项"这一种局部约束决定，与 $S$ 有多长、中间跳了多少下标无关。

**引理 2（坏点对刻画）** 对 $i<j$，记"坏点对"为满足 $a_i\ge a_j$ 的 $(i,j)$。则 $S$ 严格递增 $\iff$ $S$ 内不含任何坏点对。

**证明**：把 $S$ 写成 $i_1<\cdots<i_t$。$(\Rightarrow)$ 若 $S$ 严格递增而其中 $i_p<i_q$（$p<q$）是坏点对，则 $a_{i_p}\ge a_{i_q}$，但由引理 1 与传递性 $a_{i_p}<a_{i_q}$，矛盾。$(\Leftarrow)$ 若 $S$ 无坏点对，则对相邻的 $i_r<i_{r+1}$，"$a_{i_r}\ge a_{i_{r+1}}$"不成立，即 $a_{i_r}<a_{i_{r+1}}$，由引理 1 得 $S$ 严格递增。$\blacksquare$

于是"两条互补严格递增子序列"翻译成纯下标语言：**给每个下标染两种颜色之一，使任何坏点对的两端不同色**（各色的大小还要各占一半，先放一放）。

### 2.2 子任务一：$2^N$ 暴力，顺便看清 LIS 模板为什么不通用

枚举掩码 $\textit{mask}\in[0,2^N)$，$\textit{popcount}(\textit{mask})=N/2$ 时检查 `mask` 与 `~mask` 是否都严格递增。代价
$$2^{20}\times 2\times 20\approx 4.2\times10^{7}$$
（$2^{20}=1048576$ 个掩码，每个最多两趟各 $N=20$ 格）——$N\le20$ 完全可过，这就是子任务一的部分分。$N=100$ 时 $2^{100}\approx1.3\times10^{30}$，$N=2000$ 更不用说，**必须换掉"枚举子集"这个视角**。

顺带把"LIS 模板为什么不通用"说透，因为这是本题最容易踩的读题陷阱。LIS（以及它的"前半升后半降"bitonic 变体、"两条不交上升子序列最长"那类双序列 DP）求的都是**某一个子序列的长度或形状**，元素可以不被覆盖，也不要求两半等长；本题要的是**下标集的一个 $N/2$-$N/2$ 划分**，两者在三个方向上都不对接：

- **覆盖方向**：$\text{LIS}$ 长不代表剩下的元素能塞进第二条递增子序列。$a=[4,1,2,3]$（$N=4$）有 $\text{LIS}=3$（$1,2,3$），但剩下那个 $4$ 无论跟谁都构成坏点对，答案仍是 `No!`（2.6 反例 1 逐个穷举验证）。
- **等长方向**：即使能覆盖，两半也可能天生不平，见 2.6 两个反例。
- **形状方向**：bitonic 变体的"峰"是**一个**序列内部的先升后降，这里两个序列各自**只有升**，没有峰可言，所以"按峰值拆分、证明不重不漏"那一套论证在这里没有对应的对象；本题真正需要"不重不漏"论证的拆分是**按连通块拆**（引理 8、10）。

倒是有两个 LIS 味道的事实后面会当"快速否决"用：一是引理 4（有长 $3$ 非增子序列 ⟹ 一定 `No!`），二是它的反向构造（2.9 注记的双堆贪心）。前者能一眼否掉例 2、7、8，但**它不是充分条件**，所以不能只靠它。

### 2.3 把坏点对画成图，DP 的舞台才出现

**构造** 图 $G$：顶点 $1..N$，$(i,j)$（$i<j$）连边 $\iff a_i\ge a_j$。

**引理 3（等价性）** 存在 $N/2$-$N/2$ 的合法划分 $\iff$ $G$ 有一个真二染色，其中某个颜色类恰含 $N/2$ 个顶点。

**证明**：给定合法划分 $(A,B)$，若某条边的两端同属 $A$，则该边两端是 $A$ 中的坏点对，与引理 2 矛盾；$B$ 同理，故按 $A/B$ 染色是 $G$ 的真二染色，且 $|A|=N/2$。（$\Leftarrow$）反过来给定真二染色 $(R,\bar R)$，$R$ 中任意两点都非边（否则同色相邻违反真染色），由引理 2 知 $R$ 严格递增；若 $|R|=N/2$，则 $|\bar R|=N-N/2=N/2$，$\bar R$ 同理严格递增，即得合法划分。$\blacksquare$

"真二染色"（proper 2-coloring）= 每条边两端异色。到这一步，"$a$ 的数值"这个概念已经消失，只剩图 $G$ 的结构。

### 2.4 $G$ 的两个局部事实：三角形与区间性

**引理 4（三体 obstruction）** 若存在 $i<j<k$ 使 $a_i\ge a_j\ge a_k$（长 $3$ 的非增子序列），则 $G$ 无真二染色。

**证明**：由 $\ge$ 的传递性 $a_i\ge a_k$，故 $(i,j),(j,k),(i,k)$ 三条边全在 $G$ 中，即三角形。三角形内三个顶点两两相邻，任意两个都不同色，需要 $3$ 种颜色，二染色不存在。$\blacksquare$

逆命题"$G$ 非二分 $\Rightarrow$ 必有长 $3$ 非增子序列"在本解法里**不需要**（我们直接用染色算法判定，见 2.5），留作 2.9 的注记。

**引理 5（区间性）** 若 $(i,k)$ 是 $G$ 的边（$i<k$），则任一 $j\in(i,k)$ 必与 $i$ 或 $k$ 相邻；进而 $G$ 的每个连通块都是一段**连续下标区间**。

**证明**：设 $j$ 与 $i,k$ 都无边。$i<j$ 无边 $\iff\neg(a_i\ge a_j)\iff a_i<a_j$；$j<k$ 无边 $\iff a_j<a_k$。链起来得 $a_i<a_j<a_k$，与边 $(i,k)$ 的条件 $a_k\le a_i$ 矛盾，故 $j$ 与 $i$ 或 $k$ 相邻（从而 $j$ 属于该边所在的连通块）。
再设连通块 $C$ 含 $i<k$，取 $C$ 中路径 $v_0=i,v_1,\dots,v_t=k$。对每条边 $(v_{r-1},v_r)$，由上一段，$\min$ 与 $\max$ 之间的所有下标都在 $C$ 内；这些区间首尾相接（第 $r$ 个区间含 $v_r$，第 $r+1$ 个也含 $v_r$），并集覆盖整个 $[i,k]$，故 $[i,k]\subseteq C$。取 $i,k$ 为 $C$ 的最小、最大元即得 $C=[i,k]$。$\blacksquare$

区间性立刻给出"跳过 $v<s$"这个扫描下界的**严格**理由（代码里 `for(int v=s;...)`）：按 $s=0,1,2,\dots$ 的顺序只对**未染色**的 $s$ 开新块，则 $s$ 所在连通块不含任何 $v<s$。反设有 $v<s$ 与 $s$ 同块：$v$ 必早已被染（$s$ 是第一个未染的下标），设它是在以 $s'\le v$ 为源的那次 BFS 里被染的；那次 BFS 按引理 6(i) 把 $v$ 的**整个**连通块染完，而 $s$ 与 $v$ 同块，故 $s$ 那时就已被染，与"$s$ 未染"矛盾。所以 $v<s$ 与本块无边，跳过它们既不漏染、也不漏判冲突，只省常数（平均近一半扫描）。

### 2.5 先解决"能不能染色"：隐式图上的 BFS 二染色

不建邻接表（$G$ 最多 $\binom{N}{2}\approx2\times10^6$ 条边，且下面例子的完全二分图真有 $10^6$ 条边），直接在"由 $\ge$ 判据决定的隐式图"上做 BFS：

**引理 6（BFS 染色的正确性）** 从任一未染 $s$ 出发，每次弹出 $u$ 就扫遍本块可能的邻点并（未染则染反色入队、已染则核对异色），则该过程（i）恰好染完 $s$ 所在的连通块；（ii）若报告冲突，则 $G$ 无真二染色；（iii）若不报冲突，则得到的染色是真的。

**证明**：先备一个只用一次的常识：**若图里有一条长度为奇数的闭合行走** $v_0,v_1,\dots,v_L=v_0$（每对相邻点连边，允许重复过点），**则真二染色不存在**。因为真染色沿每条边必须翻转颜色，走 $L$ 步得 $c(v_L)=c(v_0)$（$L$ 偶）或 $1-c(v_0)$（$L$ 奇），$L$ 奇时与 $v_L=v_0$ 矛盾。（用"行走"而不是"圈"，就省掉了"奇闭行走含奇圈"这一步化简。）

(i)（不越界）只有沿边才能被染，故本块染出的点都在 $s$ 的连通分量 $C$ 内。（染得全）对 $x\in C$ 取最短路 $s=v_0,v_1,\dots,v_d=x$，对 $r$ 归纳：$v_0=s$ 手工染；设 $v_{r-1}$ 曾被弹出，弹出时扫描覆盖到与它有边的 $v_r$，$v_r$ 未染即被染、已染即已处理，故 $x$ 终被染。（"入队者必被弹出"只在 $ok$ 保持为真时需要，中途退出时 (i) 已无用。）

(ii) 冲突即存在同色边 $(u,v)$。记 $d(v)$ 为 $s$ 到 $v$ 的真实最短距离。**断言：代码给的 $col(v)\equiv d(v)\pmod 2$**（$col(s)=0=d(s)$）。对入队次序归纳：设 $v$ 由被弹出的 $u$ 首次染上，则 $d(v)\le d(u)+1$；若 $d(v)\le d(u)-1$，取 $v$ 某条最短路上前驱 $w$，$d(w)=d(v)-1\le d(u)-2$，而 BFS 的弹出顺序按 $d$ 不减（入队时 $d$ 只增 $1$、同层先到先出），故 $w$ 比 $u$ 更早弹出，$w$ 弹出时扫到未染的邻点 $v$ 就会先把它染掉，与"首次由 $u$ 染"矛盾。于是 $d(v)=d(u)+1$，$col(v)=col(u)\oplus1\equiv d(u)+1\equiv d(v)\pmod2$。
现 $col(u)=col(v)$ 给出 $d(u)\equiv d(v)\pmod 2$；又 $(u,v)$ 是边，故 $|d(u)-d(v)|\le1$，奇偶相同只可能是 $d(u)=d(v)$ 或相差 $2$：
- $d(u)=d(v)=k$：取两条最短路，设**最后一个**公共点为 $w$（$s$ 是公共点，故存在），$d(w)=j$。$w$ 到 $u$、$w$ 到 $v$ 的两段各长 $k-j$ 且除 $w$ 外不相交（否则有更靠后的公共点），加边 $(u,v)$ 得长 $2(k-j)+1$ 的奇闭合行走。
- $d(v)=d(u)+2$：$s\to u$ 最短路（$d(u)$）+ 边 $(u,v)$ + $v\to s$ 沿其最短路（$d(u)+2$）= 长 $2d(u)+3$ 的奇闭合行走。

两种都落入上面的常识，故真二染色不存在。

(iii) 若不报冲突：每条边 $(u,v)$ 的两端都会被染（(i)），$u$ 弹出时一定扫到 $v$，那一刻两端都已染色，核对分支保证异色；故所有边异色，即真染色。$\blacksquare$

顺带在这次 BFS 里数出该块两种颜色的顶点数 $p,q$（弹出时 `++cs[col[u]]`，每点恰好弹出一次）。

**为什么不用"先算最长非增子序列（LNIS）再决定"**：LNIS $\le2$ 确实等价于"$G$ 可二染色"（2.9 注记给构造），$O(N\log N)$ 就能判"可行性"这半边；但它**只回答存在性**，不给出解空间的结构。而本题的答案要求的是"存在**平衡**的染色"，我们必须知道所有染色的大小分布（下一节），所以要么像现在这样用 BFS 顺手把块与 $(p,q)$ 都算出来（$O(N^2)$，$N\le2000$ 完全够），要么 LNIS 判可行后再跑一遍染色拿 $(p_c,q_c)$——后者并没有更简单，还得多引一个定理。同理，"双堆贪心"（每次放进堆顶最大且仍 $<a_i$ 的那堆）能构造出**一种**染色，但它只有一点，凑不出"所有可能的大小"。

### 2.6 卡点：平衡约束不是"顺手就能凑平"的

如果只要"能染上色"，到 2.5 就结束了。但题面要 $N/2$-$N/2$。直觉上有两种错误想法：

- **错误想法 A**："只要能染成两色，多的那边挪几个到另一边就平衡了。" 拿反例 1 试一下就断：染色是 $\{1\}\mid\{2,3,4\}$（值 $4$ / 值 $1,2,3$），要挪一个到只剩 $1$ 个的那边得到 $2$-$2$。挪下标 $2$（值 $1$）过去，新堆是 $\{1,2\}$，值 $4,1$，**降**了；挪 $3$ 得 $\{1,3\}=(4,2)$ 降；挪 $4$ 得 $\{1,4\}=(4,3)$ 降，三个挪法全坏——因为下标 $1$ 的值 $4$ 恰好是这三个元素的公共坏点对邻居。一般地，把 $v$ 挪到对面要求 $v$ 与对面**每个**点都不是坏点对，而当前染色只保证 $v$ 与**本面**每个点都不是坏点对，没有理由自动成立。所以"挪"这条路必须逐点验证，验证到底就是重解一遍整个染色问题——不如直接刻画全部染色（2.7）。
- **错误想法 B**："先按任意贪心染，若不平衡就说明无解。" 贪心只给出一种染色，解空间可能还有别的染色。反例是例 10（$N=8$，$a=[4,1,2,3,8,5,6,7]$）：它有两个块，若把两块按"块内大小 $(1,3)$"直接接成一条链来染（即错误地以为整张图只有一种二分法），会得到 $2$-$6$ 的不平衡；实际上两块可以**各自**换色，凑出 $4$-$4$。可见"某一次染色的大小"不代表"所有染色的大小"。

**反例 1（$N=4$，$a=[4,1,2,3]$）**：坏点对 $(1,2),(1,3),(1,4)$（$4$ 不小于后面每个），星形 $K_{1,3}$，连通块唯一，二染色只有 $\{1\}\mid\{2,3,4\}$ 及其互换，两半大小恒为 $1$ 和 $3$。$N/2=2$ 取不到 ⟹ `No!`。手算穷举 $\binom42=6$ 个候选 $A$：$\{1,2\},\{1,3\},\{1,4\}$ 都含 $1$ 与某个更小的后继、自身不递增；$\{2,3\}(=1,2)$ 递增但补集 $\{1,4\}(=4,3)$ 不递增；$\{2,4\}(=1,3)$ 对而补集 $\{1,3\}(=4,2)$ 错；$\{3,4\}(=2,3)$ 对而补集 $\{1,2\}(=4,1)$ 错。全部失败 ⟹ 确为 `No!`，与图论判定一致。
所以**存在二染色但不存在平衡二染色**，"能否染色"与"能否平衡"是两个独立条件。

**反例 2（$N=6$，$a=[4,1,2,3,6,5]$）**：两个块，$(p,q)$ 分别为 $(1,3)$ 与 $(1,1)$。可行的某色大小只有 $1+1=2$ 或 $3+1=4$，永远凑不到 $N/2=3$ ⟹ `No!`（2.7 会证明"只有这两种"，故这不是漏看）。

也就是说，平衡问题本质是"**每个块各自决定把哪一份给 $A$**"的组合选择，是个背包/子集和，不是贪心。

### 2.7 解空间的结构：每块恰好两种染色

**引理 7（连通块染色唯一）** 连通图 $H$ 若有真二染色，则其真二染色在"交换两色"意义下唯一。

**证明**：设 $c,c'$ 是 $H$ 的两个真二染色。把 $c'$ 整体换色（$c'\leftarrow 1-c'$，仍真）使 $c'(v_0)=c(v_0)$，$v_0$ 任取。令 $W=\{v: c(v)=c'(v)\}\ne\varnothing$。对任意 $u\in W$ 与边 $(u,w)$：$c(w)\ne c(u)=c'(u)\ne c'(w)$，而颜色只有两个，故 $c(w)=c'(w)$，即 $w\in W$。于是 $W$ 在连通图里对"沿边走"封闭，$W=V(H)$，故 $c=c'$。$\blacksquare$

**引理 8（全局染色 = 各块独立换色）** 设 $G$ 的连通块为 $C_1..C_t$，第 $c$ 块在某固定染色下两色类大小为 $(p_c,q_c)$（孤立点记 $(1,0)$）。则 $G$ 的真二染色 $\{R,\bar R\}$ 与"每块选 $p_c$ 还是 $q_c$ 给 $R$"的选择族一一对应（模去整体换色），特别地
$$\big\{|R|:\ (R,\bar R)\ \text{是真二染色}\big\}=\Big\{\sum_{c=1}^{t}s_c:\ s_c\in\{p_c,q_c\}\Big\}.$$

**证明**：不同块之间没有边（否则同一块），故限制在每个块上都是真染色，且各块的选择互不干扰 ⟹ 任意独立组合都给出全局真染色（$\supseteq$）。反过来，任一全局真染色在每个块上的限制是真染色，由引理 7 只能是该块二分法的两种之一（模换色），且孤立点块的两种就是"点在 $R$"($1$) 与"点在 $\bar R$"($0$) ⟹ 大小必属 $\{p_c,q_c\}$（$\subseteq$）。两侧合起来即等式。$\blacksquare$

这一步同时回答了"为什么不重不漏"：块的划分是**唯一**的（连通块是图的不变量），每块的可选项也是**唯一**的两个（引理 7），所以"染色集合"被不重不漏地分解成 $t$ 个独立的二选一；后面的 DP 求的是**可达性集合**，同一大小被多条路径命中也只记 $1$，不会重复计数、也不会漏掉任何染色。

### 2.8 平衡：在块序列上做 0/1 型背包

**DP 定义** $f[i][j]=1$ ⟺ 用前 $i$ 个块、能让某指定颜色（记"红"）恰好拿到 $j$ 个顶点。
**边界** $f[0][0]=1$，$f[0][j>0]=0$（空图只有 $0$ 个红点这一种事实）。
**转移** $f[i][j]=f[i-1][j-p_i]\ \lor\ f[i-1][j-q_i]$。

代码只留一层：把 $f[i-1][*]$ 存成 bitset $dp$，则 $f[i][*]$ 就是 $(dp\,{\ll}\,p_i)\,|\,(dp\,{\ll}\,q_i)$，滚动覆盖 $dp$（$p_i=0$ 的孤立点块移位量为 $0$，等价于"不选它也计入可达"，见例 4）。越界的 $j-p_i<0$ 在 bitset 里自然为 $0$，不必特判。

**引理 9（DP 的正确性）** 对每个 $i$，$f[i][j]=1\iff j\in\{\sum_{c\le i}s_c:s_c\in\{p_c,q_c\}\}$。

**证明**：对 $i$ 归纳。$i=0$：右侧只有空和 $=0$，与 $f[0][0]=1$、其余 $0$ 一致。归纳步，两个方向分别证：
（右侧 $\Rightarrow$ $f[i][j]=1$）把和式写成 $j=s_i+j'$，其中 $j'$ 是前 $i-1$ 块某一选择的和，由归纳假设 $f[i-1][j']=1$；而 $s_i$ 只有 $p_i,q_i$ 两种取值，故 $j'=j-p_i$ 或 $j-q_i$，转移的相应一支成立，$f[i][j]=1$。
（$f[i][j]=1\Rightarrow$ 右侧）转移是"或"，故 $f[i-1][j-p_i]$ 与 $f[i-1][j-q_i]$ 至少一个成立（越界的下标视为 $0$，不可能成立，因为 $f[i-1][\cdot]$ 只在合法下标上被置 $1$）；设成立的是 $f[i-1][j-s_i]$，由归纳假设 $j-s_i$ 是前 $i-1$ 块的某个允许和，于是 $j=(j-s_i)+s_i$ 就是右侧的表示。$\blacksquare$

**答案** $f[t][N/2]$（且前面 BFS 未报冲突）。若 $j=N/2$ 可达，则另一色自动 $N-N/2=N/2$（$N$ 为偶数）⟺ 两堆各一半，由引理 3 即合法划分。

**引理 10（状态完备、转移不重不漏）** 上面这个 DP 精确刻画"所有平衡性可行的划分"，即：
(a) **完备**：对每个真二染色 $(R,\bar R)$，$f[t][|R|]=1$；(b) **可靠**：$f[t][j]=1$ 时确实存在某个真二染色使 $|R|=j$；(c) **不重复计数**：多个染色凑出同一个 $j$ 时只记一个可达状态，不影响正确性，且 DP 从不把"跨块混搭出非法染色"记成可达。

**证明**：(a) 由引理 8，$|R|=\sum_c s_c$，$s_c\in\{p_c,q_c\}$；对 $i$ 归纳（引理 9）即 $f[t][|R|]=1$。(b) 引理 9 的反方向给出选择 $s_c$，再按引理 8 的"每块独立换色"把它拼成全局真染色（块间无边，故拼接不产生新的同色边），$|R|=\sum s_c=j$。(c) DP 的每一位是 `bool`（可达性），$f[i][j]$ 由或运算得到，天然幂等：同一 $j$ 被多条选择命中只记 $1$，既不会把方案数当作判定条件，也不会因为多条路径而误判。而"非法混搭"在转移里根本不存在：第 $i$ 步只有 $p_i,q_i$ 两个选项，对应引理 8 里第 $i$ 块仅有的两种染法（引理 7 保证没有第三种），所以任何一条 DP 路径都对应一个真实的全局染色。$\blacksquare$

（对照一下：本题**不是**"按峰值拆分"那种需要证明"每个峰只被算一次"的计数题——我们不数方案数，只判可达性；需要"不重不漏"论证的是**按连通块拆分**，其依据正是引理 7（块内二选一唯一）+ 引理 8（块间独立），已在 (c) 里逐条闭合。）

等价改写（挺有用）：记 $d_c=p_c-q_c$，由 $s_c=\frac{p_c+q_c}{2}+\varepsilon_c\frac{d_c}{2}$（$\varepsilon_c=\pm1$ 表示这块换不换色）得
$$\sum_c s_c=\frac{N+\sum_c\varepsilon_c d_c}{2},$$
故"凑出 $N/2$" $\iff$ $\sum_c\varepsilon_c d_c=0$——**只有不平衡的块（$d_c\ne0$）才需要提供自由度**，$p_c=q_c$ 的块怎么选都不影响平衡，可以完全无视。顺便看清 $N$ 为偶数用在哪里：$\sum_c d_c=N-2\sum_c q_c\equiv N\pmod 2$，而 $\sum_c\varepsilon_cd_c\equiv\sum_cd_c\pmod2$，所以 $\sum\varepsilon_cd_c=0$ 的必要条件"和为偶"正是靠 $N$ 偶数自动满足；但"和为偶"只是必要条件：2.6 反例 1 的 $d=(-2)$、反例 2 的 $d=(-2,0)$ 都是偶数却照样不能平衡，还得做背包才知道。

### 2.9 落地与代价，以及一些注记

- 隐式 BFS：弹出 $n$ 次 × 每次扫描 $O(n)$ ⟹ $O(n^2)$，无邻接表内存开销（邻接表版最坏要存 $\approx2\times10^6$ 条边、多测试还要清空）。
- 背包：$t\le n$ 个块、$j\le N/2$，朴素 $O(nt/2)\le2\times10^6$；用 `bitset` 一次做两次移位、按机器字并行，$t\times2\times\lceil2005/64\rceil=2000\times2\times32=1.28\times10^5$ 次字操作，直接省一个多数量级，写起来还更短。
- 注记（关于 2.4 逆命题的完整版本）：事实上"$G$ 可二染色 $\iff$ 不存在长 $3$ 的非增子序列"。$\Leftarrow$ 的反面已由引理 4 证完；$\Rightarrow$ 是经典定理（Dilworth 在序列偏序上的特例，也即 patience sorting 的对偶形式）："把序列划分成最少条严格上升子序列，所需条数恰等于最长非增子序列的长度"，构造算法是"每次把 $a_i$ 放进堆顶 $<a_i$ 且堆顶最大的那一堆"；其正确性证明要给新开堆的元素记一个前驱指针（指向当时低一号堆的堆顶，值 $\ge$ 新元素、位置更靠前），沿指针回溯即得一条长 $=$ 堆数的非增子序列。**本题不需要它**（BFS 自带判定，见 2.5），所以这里只标出处不展开。它的意义在于：$N$ 若远大于 $2000$，"可否染色"这半边能 $O(N\log N)$ 解决，而"平衡"那半边（引理 10 的 $\sum\varepsilon_cd_c=0$）仍是背包，$O(N^2/64)$ 也到 $\approx6\times10^8$ 字操作，得再挖块结构才行——本题 $N\le2000$ 不必。

### 2.10 按数据范围分发解法

| 子任务 | 规模 | 可行做法 | 算式 |
|---|---|---|---|
| 一（$30\%$） | $N\le20$ | 直接 $2^N$ 枚举掩码（§5 校验器），不需任何理论 | $2^{20}\times40\approx4.2\times10^7$ |
| 二（$30\%$） | $N\le100$ | 本解法（隐式 BFS + bitset 背包），甚至 $O(N^3)$ 布尔 Floyd 式染色传递也够 | $100^2=10^4$ / 组 |
| 三（$40\%$） | $N\le2000$，行数 $\le50$ | 只有本解法这个量级：BFS $N^2$、DP $N^2/64$ | $\le4\times10^6+2\times10^5$ / 组 |

换句话说：从子任务一到子任务三，"枚举对象"从**子集**（$2^N$）降到**块的两色选择**（$2^t$ 但被背包压成 $N^2/64$），而"冲突判定"从逐对检查降到一次 $O(N^2)$ 染色扫描——这正是 2.3 建图带来的收益。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 合法堆的约束只由"相邻两项"$<$ 决定（引理 1），进而是"堆内无坏点对"（引理 2）。
- **brute force + cost counting** — $2^{20}\times40\approx4.2\times10^7$ 可过子任务一，$2^{100}$ 起崩溃；并看清 LIS/bitonic 模板不解决"覆盖全部 + 各占一半"。
- **reduce to easier problem** — 把数值序列换成坏点对图 $G$，问题变为"真二染色 + 颜色类大小"（引理 3）。
- **classic problem solution（二分图 BFS 染色）** — 在隐式图上 $O(N^2)$ BFS 二染色，冲突即无解（引理 6），顺带数出每块两色的大小。
- **dissect the failure of greedy** — 平衡约束不能靠挪动或贪心补齐：反例 $[4,1,2,3]$、$[4,1,2,3,6,5]$ 是"可染色但不可平衡"。
- **classic problem solution（连通块分解 + 背包）** — 连通块二染色唯一（引理 7）⟹ 染色空间 = 每块二选一（引理 8）⟹ 子集和 DP（引理 9），`bitset` 加速。
- **structure lemma for a free speedup** — 连通块是下标区间（引理 5），于是内层扫描从 $s$ 起步、且不建显式邻接表。
- **two-sided DP proof** — 引理 9 双向归纳 + 引理 10 的"完备 / 可靠 / 不重复"：证明 $f[t][j]$ 恰是"某色能拿 $j$ 个点"的可达集，把"按块拆分不重不漏"闭合到引理 7、8 上（本题没有"峰值"可拆）。
- **consider subtasks explicitly** — $N\le20$ 掩码暴力、$N\le100$ 与 $N\le2000$ 同一套 $O(N^2)$+bitset（2.10 表）。
- **verify by hand against brute force** — 12 组自造例（含 $N=2$、全相等、严格递减、可染不可平、完全二分图、$N=2000$ 规模界）逐条与 $2^N$ 暴力手算对照。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n,m` | 序列长度、每堆目标大小 $m=N/2$ | `int`，每组输入 | $n$ 偶，$0\le n\le2000$ |
| `a[i]` | 第 $i$ 个元素（$0$-based） | `int a[mxn]`，每组读 $n$ 个 | 只比较不运算，$10^9<2^{31}$ |
| `bad(u,v)` | $u,v$ 是否为坏点对（$G$ 中是否连边） | 函数，把下标排序后比 `a[u]>=a[v]` | 相等也算边（严格递增）|
| `col[i]` | $i$ 的颜色 | `int col[mxn]`，每组 `fill_n(col,n,-1)` | $-1$ 未染，$0/1$ 两色；**必须显式填 $-1$** |
| `que[],qh,qt` | 本块 BFS 队列 | `int que[mxn]`，每块置 $qh=qt=0$ | 每点只入队一次（入队前就染色） |
| `cs[2]` | 本块两色的顶点数 $p,q$ | `int cs[2]`，每块 `cs[0]=cs[1]=0` | 弹出时 `++cs[col[u]]` |
| `dp` | `dp[j]`=前若干块能否让红色恰 $j$ 点 | `bitset<mxn>`，每组 `reset()` 后 `dp[0]=1` | 转移 `dp=(dp<<p)|(dp<<q)` |
| `tot` | 已染完的顶点数 | `int`，每组 $=0$，每块 `tot+=qt` | 与 $n$ 比对做自检 |
| `ok` | 至今未发现同色边 | `bool`，每组 $=1$ | $0$  ⟹ 直接 `No!` |

### 4.2 算法步骤

1. **读入**（EOF 驱动）`cin>>n`，再读 `a[0..n-1]`；置 $m=n>>1$、`fill_n(col,n,-1)`、`ok=true`、`tot=0`、`dp.reset(); dp[0]=1`。
2. **按 $s=0..n-1$ 扫块**：`col[s]!=-1` 则跳过（该点已在本块或以前的块里）；否则以 $s$ 为源做一次隐式图 BFS：
   染 `col[s]=0` 入队；弹出 $u$ 时 `++cs[col[u]]`，并从 $v=s$ 扫到 $n-1$（引理 5 保证 $v<s$ 与本块无边），凡 `bad(u,v)`：未染则染反色入队，已染且同色则 `ok=false` 并跳出（引理 6）。
3. **块结算**：本块无冲突则 `dp=(dp<<cs[0])|(dp<<cs[1])`（引理 8、9：本块给红色 $cs[0]$ 或 $cs[1]$ 个点，二者择一），`tot+=qt`。
4. **输出** `ok && tot==n && dp[m]` 时 `Yes!\n`，否则 `No!\n`。$tot==n$ 在 $ok$ 时自动成立（每个块都染满），留作自检。

### 4.3 复杂度、资源与溢出预算（静态算式，非实测）

- **时间**：BFS 每点弹出一次，每次扫描 $\le n$ 个 $v$ ⟹ $\le n^2=2000^2=4\times10^6$ 次 `bad()`（每次约 $2$ 次数组读 $+1$ 次比较 $+1$ 次分支 $\approx4$ 个基本操作，即 $\approx1.6\times10^7$）；背包 bitset：$t\le n$ 个块，每块 $2$ 次移位 $+1$ 次或，位长 $2005$ bit $=\lceil2005/64\rceil=32$ 字 ⟹ $\le2000\times3\times32=1.9\times10^5$ 字操作。单组最坏 $\approx1.6\times10^7$ 基本操作，一份数据 $\le50$ 组 ⟹ $\le8\times10^8$。**量级就是题面 $N\le2000$ 对应的 $O(N^2)$**（$50\times4\times10^6=2\times10^8$ 次 `bad()`），处在常见 $10^8\sim10^9$ 基本操作/秒的额度边上，靠三个常数手段压：① 内层从 $v=s$ 起扫（引理 5，已写进代码，平均省掉近一半扫描）；② 一出冲突立刻整组退出（例 2、7、8 这类"不可能"实例通常在头几次弹出就否决）；③ 时限真紧就把邻接关系存 `bitset<mxn> adj[mxn]`（$2005\times2005$ bit $=501\ \text{KiB}$），核对同色边用 `(adj[u]&c0).any()` 按 $32$ 字并行，扫描量降 $64$ 倍。**为什么不能把 $O(N^2)$ 当成"随便用"**：$N$ 若上到 $2\times10^5$，$N^2=4\times10^{10}$ 直接爆；那时"可否染色"这半边有 $O(N\log N)$ 路（2.9 注记的 patience sorting 定理），但"平衡"那半边是引理 10 的 $\sum_c\varepsilon_cd_c=0$（本质子集和），bitset 也要 $N\times N/64\approx6\times10^8$ 字操作，必须再挖连通块的结构（例如证明 $d_c$ 只有少数取值）才行——本题 $N\le2000$，不需要。
- **内存**：`a`+`col`+`que` $=3\times2005\times4=24060$ B，`cs,tot,m,n` 等 $\approx30$ B，两个 `bitset<2005>` $=2\times256$ B，合计 $\approx25$ KiB，占 $128$ MiB 的 $\approx0.019\%$。
- **溢出预算（逐项）**：值域 $a_i\le10^9<2^{31}-1=2147483647$，全程只做 $\ge$ 比较、**无加减乘**，故 `int` 安全；下标与计数 $\le n\le2000$；$cs[0]+cs[1]\le n$；`dp` 的下标只会到达 $\sum$ 已处理块大小 $\le n=2000<\texttt{mxn}=2005$，移位不会丢有效位（丢掉的是本就到不了的 $\ge2005$ 位）；$m=n>>1\le1000$。全程无需 `i64`。

| 11 | 8 | `5 1 2 3 4 8 6 7` | $(1,4),(1,2)$ | $\{2,3,5,6\}$ | 4 | **No!** | 见下方详算 ✘ |
| 12 | 2000 | 前一半 $1001..2000$，后一半 $1..1000$ | $(1000,1000)$ | $\{1000\}$ | 1000 | Yes! | 两半各取一堆，均严格递增 ✔ |

**例 5 详算（$N=4$，$a=[4,1,2,3]$，最小组合规模下"能染色、不能平衡"）** 边集 $\{(1,2),(1,3),(1,4)\}$，星形、连通、无奇圈 ⟹ BFS 从 $s=1$ 染 `col[1]=0`，弹出 $1$ 时把 $2,3,4$ 染成 $1$，$cs=(1,3)$；再弹出 $2,3,4$ 时它们的唯一邻点是 $1$（异色）⟹ 无冲突、$tot=4=n$。`dp` 从 $dp[0]=1$ 变为 $\{1,3\}$，$m=2$ 处为 $0$ ⟹ `No!`。暴力侧 $\binom{4}{2}=6$ 个候选已在 2.6 逐个核过，两侧一致。

**例 6 详算（$N=6$）** 块 1：$s=1$，弹出 $1$ 发现邻点 $2,3,4$（$4\ge1,2,3$）、对 $5,6$ 无边（$4<6,4<5$）；弹出 $2$ 时 $a_2=1$ 不小于任何后继、与 $1$ 已异色；弹出 $3,4$ 同理 ⟹ $cs=(1,3)$，$dp\to\{1,3\}$。块 2：$s=5$，边 $(5,6)$（$6\ge5$）⟹ $cs=(1,1)$，$dp\to\{2,4\}$。$m=3$ 不可达 ⟹ `No!`。暴力侧：$1$ 必须与 $2,3,4$ 全部分开、$5$ 与 $6$ 分开 ⟹ 每堆大小只能是 $1+1=2$ 或 $3+1=4$，$20$ 个三元子集无一可行 ✘。

**例 11 详算（$N=8$，$a=[5,1,2,3,4,8,6,7]$，"块分解 = 穷举"的独立复核）**
边集逐个数：$(1,2),(1,3),(1,4),(1,5)$（$5\ge1,2,3,4$）、$(6,7),(6,8)$（$8\ge6,7$）；$(1,6),(1,7),(1,8)$ 都不是边（$5<8,6,7$），$\{2,3,4,5\}$ 内 $1<2<3<4$ 无边、$\{7,8\}$ 内 $6<7$ 无边、$\{2..5\}$ 到 $\{6,7,8\}$ 值都更小也无边。故两块 $[1,5]$、$[6,8]$，$(p,q)=(1,4)$ 与 $(1,2)$，DP 可达 $|R|\in\{1+1,1+2,4+1,4+2\}=\{2,3,5,6\}$，$m=4$ 不在其中 ⟹ `No!`。
暴力侧按"大小为 $4$ 的子集"完整分类穷举（等价于 $\binom84=70$ 个候选的压缩版）：
- 若 $1\in A$：边 $(1,2),(1,3),(1,4),(1,5)$ 逼 $2,3,4,5\notin A$，于是 $A\subseteq\{1,6,7,8\}$，要满 $4$ 个只能 $A=\{1,6,7,8\}$，值 $5,8,6,7$ —— $8>6$ 破坏严格递增（正是边 $(6,7)$ 两端同色），✘。
- 若 $1\notin A$：同上逼条件使 $2,3,4,5$ 全在 $A$，$A=\{2,3,4,5\}$ 已满 $4$ 个，于是 $B=\{1,6,7,8\}$ 同样含边 $(6,7)$，✘。
两支都灭 ⟹ 确为 `No!`。顺带把**存在**的合法划分也算出来：$2$-$6$（$A=\{1,6\}=(5,8)$ ✔、$B=\{2,3,4,5,7,8\}=(1,2,3,4,6,7)$ ✔）与 $3$-$5$（$A=\{1,7,8\}=(5,6,7)$ ✔、$B=\{2,3,4,5,6\}=(1,2,3,4,8)$ ✔）及其互换，四种染色的某色大小恰为 $\{2,3,5,6\}$，**与 DP 可达集逐项相同**——这一例专门检查了"我没有把可达集想当然地算成 $\{1..7\}$"。

**例 3 详算（$N=4$，$a=[3,1,4,2]$，非平凡的 $(2,2)$ 单块）** 边集：$(1,2)$（$3\ge1$）、$(1,4)$（$3\ge2$）、$(3,4)$（$4\ge2$）；$(1,3)$（$3<4$）、$(2,3)$（$1<4$）、$(2,4)$（$1<2$）都无。BFS：$s=1$，`col[1]=0`；弹出 $1$ → 扫到 $2,4$ 未染且相邻，染成 $1$ 入队；弹出 $2$（值 $1$）无新邻点；弹出 $4$（值 $2$）扫到 $3$：$bad(3,4)$ 为真 ⟹ `col[3]=col[4]^1=0`；弹出 $3$（值 $4$）扫 $1,2$ 非邻、扫 $4$ 异色 ✔。无冲突，$cs=(2,2)$（$0$ 色是 $1,3$；$1$ 色是 $2,4$），$tot=4$。`dp` 由 $\{0\}$ 变 $\{2\}$，$m=2$ ✔ ⟹ `Yes!`，划分即 $A=\{1,3\}=(3,4)$、$B=\{2,4\}=(1,2)$。这一例专门检查了"块不是靠相邻下降对串起来的"：路径 $2-1-4-3$ 里下标 $3$ 是靠边 $(3,4)$ 才并入第一块的，若只看看相邻下降对（$3>1$、$4>2$）会误判成两块 $(1,1)+(1,1)$，$d_c$ 与块数都错。

**例 9 详算（$N=6$，$a=[1,1,2,2,3,3]$，相等值边界）** 边只可能是等值对 $(1,2),(3,4),(5,6)$（跨值严格增）。三块各 $cs=(1,1)$，`dp` 依次 $\{0\}\to\{1\}\to\{2\}\to\{3\}$（两个移位量相同，或运算不扩集），$m=3$ ✔ ⟹ `Yes!`，划分 $A=\{1,3,5\}=(1,2,3)$、$B=\{2,4,6\}=(1,2,3)$。检查了"$\ge$ 而非 $>$"（相等必分家）与"每块强制贡献 $1$ 个"的 DP 行为。

**例 12 详算（$N=2000$，前一半 $1001,1002,\dots,2000$、后一半 $1,2,\dots,1000$）** 两半内部各自递增、跨半元素一律"前者 $>$ 后者" ⟹ $G=K_{1000,1000}$，单个块、$cs=(1000,1000)$。BFS 弹出 $1$ 时把后一半 $1000$ 个点染成 $1$ 入队；再弹出这 $1000$ 个点时各自扫到前一半的 $0$ 色点（异色 ✔）。扫描量 $2000\times2000=4\times10^6$ 次 `bad()`，正是 4.3 的最坏情形；`dp` 由 $\{0\}$ 变 $\{1000\}$，$m=1000$ ✔ ⟹ `Yes!`，划分就是前后两半本身，均严格递增 ✔。这一例既是最坏时间的形状，也检查了 $10^6$ 条边不建邻接表照样能过。

**边界自检**：例 1（$N=2$、含相等）验证 $m=1$ 与"相等连边"；例 8（全相等，$K_4$）与例 2（严格递减，含三角形）验证引理 6(ii) 的冲突分支确实会走到底（$K_4$ 里 $s=1$ 弹 $1$ 把 $2,3,4$ 染成 $1$，弹 $2$ 时看到 $3$ 同色 ⟹ 冲突；严格递减例同理在第 $2$ 个点弹出时撞上）；例 4（全递增、$n$ 个 $(1,0)$ 块）验证 $cs=(1,0)$ 时 `dp<<0` 仍等于 $dp$、可达集扩成整段 $\{0..n\}$。多组数据的复位自检：`col` 必须 `fill_n(col,n,-1)`（$0$ 是合法颜色，全局默认 $0$ 会被当成"已染成 $0$ 色"，引理 6 的第 (i) 条立刻失真）、`dp.reset()`、`cs/tot/ok` 每块或每组重置。

**验证结论**：$12$ 组自造（含 $N=2$、$N=4$、$N=6$、$N=8$、全相等、全递减、全递增、"可染色但不可平衡"$\times3$、单块 $(2,2)$、完全二分图、$N=2000$ 规模界）全部手算，算法列（BFS 块分解 + bitset 可达集）与暴力列（逐个候选手工验算或完整分类穷举）**全部一致**；其中例 5、6、11 是"图可二染色但平衡不可达"的只有"图 + 背包"才判对的类型，例 3、9、11、12 另给了逐步详算。未发现与引理 3/6/8/9/10 相冲突的情形。因环境无编译器：**未编译、未运行、未对拍，不声称任何得分或实测耗时**（4.3 的数字全是静态算式）。

## 5. 示例代码（C++）

```cpp
// P1410 子序列
// 坏点对图(相等也连边)二染色 + 按连通块做"这给红的点数"背包，凑 N/2
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005};              // n<=2000，+5 松弛

int n,m;
int a[mxn];                           // 值<=1e9<2^31，只比较不运算
int col[mxn],que[mxn],cs[2],tot;      // col:-1未染/0/1；que:块内队列；cs:块内两色点数
bitset<mxn> dp;                       // dp[j]: 已处理的块能否让红色恰好 j 个点
bool ok;

bool bad(int u,int v)                 // u,v 是否连边（同色必破坏严格递增）
{
	if(u>v)
		swap(u,v);
	return a[u]>=a[v];                // 相等也连边：严格递增不容相等同列
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	while(cin>>n)                       // 若干行，EOF 结束
	{
		for(int i=0;i<n;++i)
			cin>>a[i];
		m=n>>1;
		fill_n(col,n,-1);               // 不能靠全局默认0：0 是合法颜色
		ok=true;
		tot=0;
		dp.reset();
		dp[0]=1;
		for(int s=0;s<n&&ok;++s)
		{
			if(col[s]!=-1)
				continue;               // 已在本块/前块
			int qh=0,qt=0;
			cs[0]=cs[1]=0;
			que[qt++]=s;
			col[s]=0;
			while(qh<qt&&ok)
			{
				int u=que[qh++];
				++cs[col[u]];           // 每点恰好入队一次、弹出一次
				for(int v=s;v<n;++v)    // 连通块是区间(引理5)：v<s 与本块无边
				{
					if(v==u||!bad(u,v))
						continue;
					if(col[v]==-1)
					{
						col[v]=col[u]^1;
						que[qt++]=v;
					}
					else if(col[v]==col[u])
					{
						ok=false;       // 同色相邻：奇圈，真二染色不存在(引理6)
						break;
					}
				}
			}
			if(!ok)
				break;
			// 本块只能整块换色：给红色 cs[0] 个或 cs[1] 个(引理8)
			dp=(dp<<cs[0])|(dp<<cs[1]);
			tot+=qt;
		}
		cout<<((ok&&tot==n&&dp[m])?"Yes!\n":"No!\n");
	}
	return 0;
}
```

### 代码说明

- **全局静态数组 + `constexpr int mxn{2005}`**（$2000+5$），`bitset<mxn>` 同尺寸；不用 `vector` 存状态。
- **`fill_n(col,n,-1)` 是必须的**：本题"未染色"语义的数组若留默认 $0$，$0$ 恰是合法颜色，BFS 会把每个点都当成"已染成 $0$ 色"，块分解与冲突判定同时失真。`cs` 每块、`dp` 每组都显式重置（多组数据、EOF 驱动）。
- **引理即代码**：`bad()` = 引理 2 的 $\ge$；`for(int v=s;...)` 的下界 = 引理 5 的区间性；`else if(col[v]==col[u]) ok=false` = 引理 6(ii)；`dp=(dp<<cs[0])|(dp<<cs[1])` = 引理 8、9 的二选一背包。
- **输出严格照题面**：`Yes!` / `No!` 带感叹号、用 `'\n'` 不用 `endl`；`cin.tie/cout.tie/sync_with_stdio` 顺序固定；运算符两侧无空格、Tab 缩进、小写电报式命名。
- **溢出**：只比较不运算，`int` 全程够用，无需 `using i64=long long;`。

### 备选实现（$2^N$ 暴力校验器，仅 $N\le20$，用于手算对照）

```cpp
// 校验器：枚举每个下标进A还是B，两半都要"恰 n/2 个且严格递增"
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};                // 只在 n<=20 时用

int n,m;
int a[mxn];

bool isinc(int mask)                  // mask 内的下标按顺序读出的值是否严格递增
{
	int pre=-1;
	for(int i=0;i<n;++i)
		if((mask>>i)&1)
		{
			if(pre!=-1&&a[pre]>=a[i])
				return false;
			pre=i;
		}
	return true;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	while(cin>>n)
	{
		m=n>>1;
		for(int i=0;i<n;++i)
			cin>>a[i];
		bool ok=false;
		for(int mask=0;mask<(1<<n)&&!ok;++mask)
			if(__builtin_popcount(mask)==m)
				if(isinc(mask)&&isinc(((1<<n)-1)^mask))
					ok=true;
		cout<<(ok?"Yes!\n":"No!\n");
	}
	return 0;
}
```

两版语义等价（正解 $O(N^2+N^2/64)$，暴力 $O(2^N N)$）；暴力版是 §4.4 手算对照所用的定义，也是 $N\le20$ 子任务的部分分写法。
