# P1409 骰子

> 标签：动态规划 DP / 数学 / 递推 · 难度：省选/NOI-（福建省历届夏令营）

## 1. 重新读题

**问题重述（简化版）**

$n$ 个人排成一列，你是第 $m$ 个。每一轮让**队首**那人掷一次骰子：

- 掷到 $1$：**队首那人获胜**，游戏结束；
- 掷到 $2,4,6$：队首那人走到**队尾**（人数不变，其他人整体前移一位）；
- 掷到 $3,5$：队首那人**出队**（人数 $-1$）。

另外有一条终止规则：**队列里只剩一个人时，这个人直接获胜**。求你获胜的概率，输出实数、精确到小数点后 $9$ 位。

**约束与子任务（提示复杂度）**

| 数据范围 | 规模 | 暗示 |
|---|---|---|
| 30% | $0<m\le n\le10$ | 状态只有 $\frac{n(n+1)}2=55$ 个，允许"列方程组硬解"级别的笨办法 |
| 100% | $0<m\le n\le1000$ | 状态 $\frac{n(n+1)}2=500500\approx5\times10^5$ 个，$O(n^2)$ 递推正好卡在 $10^6$ 量级 |

两个从题面读出的关键事实（后文全部依赖它们）：

1. 规则**只跟"队首"和"你排第几"有关**，跟每个人是谁无关；
2. 输出是**实数**，不是取模整数——所以本题没有模数，也就没有 `constexpr int p{...}`（见 §4.3 的取模预算）。

## 2. 思维链（Chain-of-thought）

### 2.1 先钉死概率模型：样本空间与等可能性

把整局游戏看成一个**无限序列** $\omega=(r_1,r_2,r_3,\dots)$，$r_t\in\{1,2,3,4,5,6\}$ 是第 $t$ 轮的骰面。样本空间 $\Omega=\{1,\dots,6\}^{\mathbb N}$，取乘积测度：每次掷骰六个面**等可能**（均匀骰子，题面口径见 §口径风险），单面概率 $\frac16$，不同轮相互独立。题面里三类结果对应的面集是

$$A_1=\{1\},\quad A_2=\{2,4,6\},\quad A_3=\{3,5\},$$

$|A_1|=1,|A_2|=3,|A_3|=2$，三者两两不交且 $A_1\sqcup A_2\sqcup A_3=\{1,\dots,6\}$。由**有限计数**（等可能基本事件：概率 $=$ 有利面数 / 总面数）与有限可加性

$$P(A_1)=\frac16,\qquad P(A_2)=\frac36=\frac12,\qquad P(A_3)=\frac26=\frac13,\qquad \frac16+\frac12+\frac13=1.\tag{2.1}$$

游戏进程是 $\omega$ 的某个前缀的确定性函数，"你获胜"是 $\Omega$ 的一个事件，其概率即所求。

**引理 1（几乎必然终止）** $P(\text{游戏永不结束})=0$。

**证明**：若游戏永不结束，则它对每一轮都还在进行，于是每一轮的队首都不会掷出 $1$（掷出 $1$ 就有人获胜、游戏立刻结束）。故"永不结束"被包含在事件"$r_1,\dots,r_T$ 全部 $\ne1$"里，而对任意 $T$ 该事件概率为 $\left(\frac56\right)^{T}$（各轮独立、每轮避开 $1$ 的概率 $\frac56$）。令 $T\to\infty$ 得 $P(\text{永不结束})\le\lim_T\left(\frac56\right)^T=0$。$\blacksquare$

这条引理保证"最终有人获胜"是概率 $1$ 的事件，后面写方程时不必担心"无限拖延"留下的漏项。

### 2.2 状态压缩：只需要两个数

设你在长为 $k$ 的队列中**从队首数第 $i$ 位**（$1\le i\le k$），记

$$f(i,k)=\text{此状态下你最终获胜的概率}.$$

**引理 2（状态可归约到 $(i,k)$）** $f(i,k)$ 只依赖 $(i,k)$，与队列里其他人的**身份、姓名、排列次序**都无关。

**证明**：取两个队列状态 $S,S'$，长度都是 $k$，而你都在第 $i$ 位。则存在一个只置换"非你玩家"的双射 $\pi$ 把 $S$ 变成 $S'$。规则对每个非你玩家完全相同（都只看队首、都按 (2.1) 的同一分布掷骰），所以把 $S$ 上由序列 $\omega$ 驱动的全过程，用 $\pi$ 逐点改名，就得到 $S'$ 上由**同一个** $\omega$ 驱动的全过程：每一步的三类结果归属一致，人数变化一致，你的位移一致。因此"$S$ 中你获胜"与"$S'$ 中你获胜"在同一个 $\omega$ 下同时发生——两个事件在乘积测度下相同，概率相等。$\blacksquare$

这就是本题的核心结构性观察：**"别人是谁"是假信息**。下面只需算 $f$。

### 2.3 一步分解：把方程写出来

**引理 3（一步递推关系）** 记 $x=f(1,k)$，则

$$f(1,k)=\frac16+\frac12\,f(k,k)\qquad(k\ge2),\tag{2.2}$$
$$f(i,k)=\frac12\,f(i-1,k)+\frac13\,f(i-1,k-1)\qquad(2\le i\le k),\tag{2.3}$$
$$f(1,1)=1.\tag{2.4}$$

**证明**：对第一次掷骰的三类结果（$A_1,A_2,A_3$ 两两不交、并为全集）用**全概率公式**，逐类看状态怎么变。

- $i\ge2$：队首不是你。$A_1$（$\frac16$）→ 队首获胜，游戏结束，你输，贡献 $0$；$A_2$（$\frac12$）→ 队首去队尾，你前移一位、长度不变，进入 $(i-1,k)$；$A_3$（$\frac13$）→ 队首出队，你前移一位、长度减一，进入 $(i-1,k-1)$。三类的条件概率分别乘以 (2.1) 的权重相加即 (2.3)。
- $i=1$：队首是你。$A_1$ → 你当场获胜，记 $1$；$A_2$ → 你走到队尾，成为第 $k$ 位，进入 $(k,k)$；$A_3$ → 你出队，永不获胜，记 $0$。故 $f(1,k)=\frac16\cdot1+\frac12 f(k,k)+\frac13\cdot0$，即 (2.2)。
- $k=1$：队列里只有你，题面"仅剩一人则该人获胜"直接判你胜，$f(1,1)=1$。

每一步的"进入新状态"是精确的：$A_2,A_3$ 之后剩下的过程只由**平移后的序列** $(r_2,r_3,\dots)$ 决定，而它与原序列同分布（独立性），所以新状态下的胜率仍是同一个 $f(\cdot,\cdot)$。$\blacksquare$

### 2.4 撞墙：同一列里有个环

按 $k$ 从小到大递推的想法很自然，但 (2.2) 把 $f(1,k)$ 指回 $f(k,k)$，而 (2.3) 又要 $f(k,k)\leftarrow f(k-1,k)\leftarrow\cdots\leftarrow f(1,k)$：**第 $k$ 列的 $k$ 个未知数互相咬成一个环**，不能直接顺序填表。

最笨的办法（也就是 30% 子任务能拿分的办法）：把全部 $\frac{n(n+1)}2$ 个 $f(i,k)$ 当未知数，高斯消元。$n=10$ 时 $55$ 个未知数、$\frac23\cdot55^3\approx1.1\times10^5$ 次运算、增广矩阵 $55\times56$ 个 `double`，毫无压力；但 $n=1000$ 时未知数 $500500$ 个，消元要 $\frac23(5\times10^5)^3\approx8\times10^{16}$ 次运算，稠密矩阵还要 $\frac12(5\times10^5)^2\times8\approx10^{12}$ B 内存——**时间和内存双双爆掉，这条路只够写 30 分版本**（而且 $5\times10^5$ 维浮点消元的累积误差也远大于 $10^{-9}$）。

先看 $k=2$ 时环怎么解（手工，两变量）：由 (2.2)(2.3)

$$f(1,2)=\frac16+\frac12 f(2,2),\qquad f(2,2)=\frac12 f(1,2)+\frac13 f(1,1)=\frac12 f(1,2)+\frac13.$$

代回：$f(1,2)=\frac16+\frac14 f(1,2)+\frac16\Rightarrow\frac34 f(1,2)=\frac13\Rightarrow f(1,2)=\frac49$，$f(2,2)=\frac59$。

注意结构：**除了 $i=1$ 那一条，其余每条都是"前一项的 $\frac12$ 加上一个已知量"**。$k=2$ 的环之所以好解，是因为 $f(2,2)$ 关于 $f(1,2)$ 是**一次**的。这个"一次"可以推广。

### 2.5 破环：把整列写成未知数 $x$ 的一次函数

固定 $k\ge2$，令 $x=f(1,k)$，$b_t=f(t,k-1)$（上一列，已知），$a_i=f(i,k)$。则

$$a_1=x,\qquad a_i=\frac12 a_{i-1}+\frac13 b_{i-1}\ (2\le i\le k).\tag{2.5}$$

**引理 4（仿射表示）** 对每个 $i$ 存在 $\alpha_i,\beta_i$ 使 $a_i=\alpha_i x+\beta_i$，且

$$\alpha_1=1,\ \beta_1=0,\qquad \alpha_i=\frac{\alpha_{i-1}}2,\ \ \beta_i=\frac{\beta_{i-1}}2+\frac{b_{i-1}}3,$$
$$\alpha_i=2^{-(i-1)},\qquad \beta_i=\frac13\sum_{t=1}^{i-1}2^{-(i-1-t)}\,b_t=\frac13\sum_{t=1}^{i-1}2^{\,t-i+1}b_t. \tag{2.6}$$

**证明**：对 $i$ 归纳。$i=1$ 时 $\alpha_1 x+\beta_1=x=a_1$。设 $a_{i-1}=\alpha_{i-1}x+\beta_{i-1}$，代入 (2.5) 右端得 $\frac{\alpha_{i-1}}2x+\left(\frac{\beta_{i-1}}2+\frac{b_{i-1}}3\right)$，仍是 $x$ 的一次函数，系数即递推式，归纳成立。闭式：$\alpha_i=2^{-(i-1)}$ 由 $\alpha$ 每次减半直接展开；$\beta$ 把递推式反复代入自身，第 $t$ 项 $b_t$ 从位置 $t$ 传到位置 $i$ 要经过 $i-1-t$ 次"$\div2$"，故系数为 $\frac13\cdot2^{-(i-1-t)}=\frac13\,2^{t-i+1}$，求和即 (2.6)。$\blacksquare$

**引理 5（闭合方程与分母非零）** 把 $a_k=\alpha_k x+\beta_k$ 代入 (2.2)：

$$x=\frac16+\frac12\left(\alpha_k x+\beta_k\right)\ \Longrightarrow\ x\left(1-\frac{\alpha_k}2\right)=\frac16+\frac{\beta_k}2 .$$

由 $\alpha_k=2^{-(k-1)}$，系数 $1-\frac{\alpha_k}2=1-2^{-k}\ge 1-\frac14=\frac34>0$（$k\ge2$），可除，得

$$\boxed{\;f(1,k)=x=\frac{\frac16+\frac12\beta_k}{1-2^{-k}}\;}\tag{2.7}$$

求出 $x$ 后用 $a_i=\alpha_i x+\beta_i$ **正向**填出整列，第 $k$ 列 $O(k)$。

**引理 6（唯一性：算出来的就是真概率）** 满足 (2.2)(2.3)(2.4) 的数组是唯一的，因此它必等于真实胜率。

**证明**：对 $k$ 归纳。(2.4) 定死第 1 列。设第 $k-1$ 列被唯一确定，则 $b_1,\dots,b_{k-1}$ 是确定的数，$\beta_k$ 由 (2.6) 唯一算出；引理 5 说 $1-2^{-k}\ne0$，故 (2.7) 给出**唯一**的 $x$；再由 $a_i=\alpha_ix+\beta_i$ 唯一确定第 $k$ 列每一元。归纳完成。真实胜率数组满足同一方程组（引理 3，其中"永不终止"那部分由引理 1 是零概率事件、对概率无贡献），于是二者相等。$\blacksquare$

### 2.6 一个免费的自检：每列和为 1

**引理 7（归一化）** $\sum_{i=1}^{k}f(i,k)=1$ 对一切 $k\ge1$ 成立。

**证明**：固定长度为 $k$ 的队列。对每个位置 $i$，"排在第 $i$ 位的人获胜"的概率按引理 2 正是 $f(i,k)$（把"你"换成第 $i$ 位那个人，规则与骰子分布都不变）。这些事件**两两不交**：游戏在有人获胜的那一刻立即结束，不可能有第二个获胜者；它们**并为全集**：由引理 1，游戏几乎必然结束，而结束的两种方式（掷出 $1$、只剩一人）都产生唯一一个获胜者。故由可加性 $\sum_{i=1}^k f(i,k)=P(\text{有人获胜})=1$。$\blacksquare$

手算：$k=2$：$\frac49+\frac59=1$ ✓；$k=3$：$\frac{64+60+65}{189}=1$ ✓；$k=4$：$\frac{160+144+132+131}{567}=\frac{567}{567}=1$ ✓。这个不变式可以当程序的逐列断言用。

**顺带的定性结论**：排位与胜率**不单调**。$k=3$ 时 $(0.3386,\,0.3175,\,0.3439)$，末位最强；$k=4$ 时 $(0.2822,\,0.2540,\,0.2328,\,0.2310)$，首位最强。原因在 (2.3)：站队首既有机会 $\frac16$ 直接赢，也有机会 $\frac13$ 把自己送走；站在别人后面只享受"前人 $\frac13$ 出队"的红利。队伍越短，"直接赢"的那 $\frac16$ 越值钱。

### 2.7 一条完全独立的算路（用来验，不用来算）

上面的 DP 是"解方程"。为了检验它没有把模型写错，需要一条**直接对骰面序列求和**的路——相当于手能算的暴力枚举。

把每轮掷骰分成两种：**旋转**（掷到 $2,4,6$，只挪位置）与**有效事件**（掷到 $1,3,5$，改变人数或结束游戏）。

**引理 8（相位分解）** 记 $R$ 为从当前时刻起、到第一次出现有效事件为止的旋转次数，则

$$P(R=r)=2^{-(r+1)}\quad(r=0,1,2,\dots),\qquad P(\text{该有效事件是}"1"\text{面}")=\frac13,\quad P(\text{是}"3,5"\text{面})=\frac23. \tag{2.8}$$

**证明**：$R=r$ 意思是前 $r$ 轮骰面都落在 $\{2,4,6\}$、第 $r+1$ 轮落在 $\{1,3,5\}$。长度为 $r+1$ 的前缀共 $6^{r+1}$ 个，每个等概率 $6^{-(r+1)}$（乘积测度、六个面等可能）；满足条件的可取前 $r$ 位各 $3$ 种、末位 $3$ 种，共 $3^{r+1}$ 个。故 $P(R=r)=\dfrac{3^{r+1}}{6^{r+1}}=2^{-(r+1)}$。第二句：该有效事件的面是 $\{1,3,5\}$ 中**等可能的一个面**（前 $r$ 轮的取法对三类完全对称，每个三元前缀后面接 $1$、接 $3$、接 $5$ 各给出同样多的序列），故"$1$"占 $1$ 个面、"$3$ 或 $5$"占 $2$ 个面，概率分别 $\frac13$、$\frac23$。另外"永远旋转"的概率 $=\lim_m 2^{-m}=0$，所以 $\{R=r\}_{r\ge0}$ 几乎必然划分样本空间，(2.8) 的求和不漏质量。$\blacksquare$

有了 (2.8)，就可以**绕开 $f(1,k)$ 的环**：$r$ 次旋转把你从第 $p$ 位挪到

$$q=((p-1-r)\bmod k)+1,$$

因为每次旋转你前移一位、第 $1$ 位旋转后到第 $k$ 位（与引理 3 证明里的位移规则一致）。若 $q=1$ 则有效事件轮到你："$1$"→你胜（记 $1$），"$3,5$"→你出队（记 $0$）；若 $q\ge2$ 则"$1$"→你输，"$3,5$"→那人出队，你进入 $(q-1,\,k-1)$。于是

$$f(p,k)=\sum_{r\ge0}2^{-(r+1)}\left[\,[q=1]\cdot\frac13+[q\ge2]\cdot\frac23\,f(q-1,k-1)\right],\tag{2.9}$$

其中 $[\cdot]$ 是指示函数（条件真时取 $1$，假时取 $0$）。**注意 (2.9) 的右端只含第 $k-1$ 列**，没有环——这正是它能当独立校验的原因。

**用它手算 $k=2$**（$2^{-(r+1)}$ 按 $r$ 奇偶分组，几何级数）：

$$\sum_{r\ \text{even}}2^{-(r+1)}=\frac{\frac12}{1-\frac14}=\frac23,\qquad \sum_{r\ \text{odd}}2^{-(r+1)}=\frac{\frac14}{1-\frac14}=\frac13 .$$

- $p=1$：$r$ 偶 $\Rightarrow q=1\Rightarrow$ 括号 $=\frac13$；$r$ 奇 $\Rightarrow q=2\Rightarrow$ 括号 $=\frac23 f(1,1)=\frac23$。
  $$f(1,2)=\frac23\cdot\frac13+\frac13\cdot\frac23=\frac29+\frac29=\frac49 .$$
- $p=2$：$r$ 偶 $\Rightarrow q=2\Rightarrow$ 括号 $=\frac23 f(1,1)=\frac23$；$r$ 奇 $\Rightarrow q=1\Rightarrow$ 括号 $=\frac13$。
  $$f(2,2)=\frac23\cdot\frac23+\frac13\cdot\frac13=\frac49+\frac19=\frac59 .$$

与 §2.4 解环的结果 $\frac49,\frac59$ **完全一致** ✓（两条路的方程形式不同：一条解二元线性方程组、一条求无穷级数）。

**用它手算 $k=3$**（用已知的 $f(1,2)=\frac49,f(2,2)=\frac59$）。按 $r\bmod 3$ 分组，公比 $2^{-3}=\frac18$：

$$\sum_{r\equiv0}2^{-(r+1)}=\frac{1/2}{1-1/8}=\frac47,\quad \sum_{r\equiv1}2^{-(r+1)}=\frac{1/4}{7/8}=\frac27,\quad \sum_{r\equiv2}2^{-(r+1)}=\frac{1/8}{7/8}=\frac17,$$

三者之和 $\frac47+\frac27+\frac17=1$ ✓（印证引理 8 不漏质量）。

- $p=1$：$q$ 依次为 $1,3,2$。$f(1,3)=\frac47\cdot\frac13+\frac27\cdot\frac23f(2,2)+\frac17\cdot\frac23f(1,2)=\frac47\cdot\frac13+\frac27\cdot\frac{10}{27}+\frac17\cdot\frac8{27}=\frac{36+20+8}{189}=\frac{64}{189}$ ✓
- $p=2$：$q$ 依次为 $2,1,3$。$f(2,3)=\frac47\cdot\frac23f(1,2)+\frac27\cdot\frac13+\frac17\cdot\frac23f(2,2)=\frac{32}{189}+\frac{18}{189}+\frac{10}{189}=\frac{60}{189}=\frac{20}{63}$ ✓
- $p=3$：$q$ 依次为 $3,2,1$。$f(3,3)=\frac47\cdot\frac{10}{27}+\frac27\cdot\frac8{27}+\frac17\cdot\frac13=\frac{40+16+9}{189}=\frac{65}{189}$ ✓

三个值与 §2.5 逐列递推算出的 $\frac{64}{189},\frac{60}{189},\frac{65}{189}$ **逐个吻合**，且相加为 $1$（引理 7）。这条独立路线说明：状态归约（引理 2）、一步方程（引理 3）、仿射解环（引理 4、5）三处都没写错。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 三种骰面结果只改动"你在第几位 + 队伍长度"两个数；先用置换双射证明"别人是谁"是假信息（引理 2）。
- **classic problem solution（全概率一步分解）** — 对第一次掷骰按 $A_1,A_2,A_3$ 分三类，写出 $f(i,k)$ 的方程（引理 3）。
- **consider subtask / dead end** — 顺序填表撞环：$f(1,k)\to f(k,k)\to\cdots\to f(1,k)$；整体高斯消元 $\sim8\times10^{16}$ 次运算，只能拿 30 分。
- **classic problem solution（仿射待定系数解环）** — 同列内除首元外都是"乘 $\frac12$ 加已知量"，故每元对未知数 $x$ 一次；沿列递推 $(\alpha,\beta)$，用 (2.7) 一次闭合解出 $x$（引理 4+5）。
- **reduce to easier problem** — 问题降为逐列两趟扫描，$O(k)$ 一列，$O(n^2)$ 全部，内存可滚动到 $O(n)$。
- **uniqueness by induction** — 分母 $1-2^{-k}\ge\frac34\ne0$ 使每列解唯一，从而"方程的解"＝"真概率"（引理 6）。
- **invariant cross-check** — $\sum_i f(i,k)=1$（唯一胜者＋a.s. 终止）作逐列自检（引理 7）。
- **brute force by direct summation** — 把"连续旋转"打包成相位，用几何级数直接对骰面序列求和 (2.9)，它不含环、可独立复核第 2、3 列（引理 8）。
- **edge & budget** — $k=1$ 边界 $f(1,1)=1$；值域 $[0,1]$ 无溢出；精确有理数会爆到 $10^{477}$ 量级，故走 `double`，误差预算 $\le4\times10^{-12}$（§4.3）。

|---|---|---|---|
| `n` | 初始人数 | `int`，输入，$\le1000$ | 列上界 |
| `m` | 你初始排第 $m$ 位（题面 1-based） | `int`，输入，$\le n$ | 答案下标，全程 1-based（见 §代码说明） |
| `dp[k][i]` | $f(i,k)$：队里 $k$ 人、你在第 $i$ 位时你的胜率 | `double dp[mxn][mxn]`，`dp[1][1]=1.0`，其余逐列填 | 第一维是**长度**，第二维是**排位** |
| `al[i]` | $\alpha_i=2^{-(i-1)}$：本列第 $i$ 元对 $x$ 的斜率 | `double al[mxn]`，每列 `al[1]=1.0` | 每次 $\div2$ |
| `be[i]` | $\beta_i$：本列第 $i$ 元的截距 | `double be[mxn]`，每列 `be[1]=0.0` | $\beta_i=\beta_{i-1}/2+dp[k-1][i-1]/3$ |
| `x` | $f(1,k)$，本列未知数 | 局部 `double`，由 (2.7) 算出 | 环的解 |

### 4.2 算法步骤

1. **读入** $n,m$。
2. **边界**：`dp[1][1]=1.0`（只剩你，题面直接判胜）。
3. **逐列 $k=2..n$**：
   1. `al[1]=1; be[1]=0;`，对 $i=2..k$ 递推 `al[i]=al[i-1]/2; be[i]=be[i-1]/2+dp[k-1][i-1]/3;`（引理 4，$b_{i-1}=dp[k-1][i-1]$，下标 $i-1\le k-1$ 合法）。
   2. `x=(1.0/6.0+be[k]/2.0)/(1.0-al[k]/2.0);` 即 (2.7)，此时 $al[k]=2^{-(k-1)}$，分母 $=1-2^{-k}\ge\frac34$。
   3. `dp[k][1]=x;` 再对 $i=2..k$ 回填 `dp[k][i]=al[i]*x+be[i];`。
4. **输出** `dp[n][m]`，`fixed<<setprecision(9)`。

**复杂度**：第 3 步内部两趟各 $k-1$ 次循环，总运算量

$$\sum_{k=2}^{n}2(k-1)=n(n-1)\le 999000\approx10^6\ \text{次},$$

时间 $O(n^2)$；空间 $O(n^2)$（`double dp[1005][1005]` $=8.08\times10^6$ B $\approx7.7$ MiB，另加两个系数数组各 $8$ KB）。若内存紧张，$dp$ 只需上一列，可换滚动数组降到 $O(n)$（$16$ KB），代码里保留全表以便调试。

### 4.3 溢出、取模与精度预算

- **取模**：题面要求输出**实数**，任何取模都会破坏答案，故不定义 `constexpr int p{...}`（规范里它是"按需"项）。
- **为什么必须浮点**：若走精确有理数，(2.6) 里 $\beta_k$ 的公共分母含 $3^{k}$ 与 $2^{k}$，(2.7) 的分母还带来 $2^k-1$ 的因子；$k=1000$ 时 $3^{1000}\approx10^{477}$、$2^{1000}\approx10^{301}$，`i64` 上限 $9.22\times10^{18}$、`__int128` 上限 $\sim10^{38}$ 都被远远超过——必须上大整数，性价比极低。
- **浮点不会溢出**：$0\le f\le1$（概率），$\alpha,\beta\in[0,1]$，中间量全在 $[0,1]$。
- **下溢**：$\alpha_{1000}=2^{-999}\approx1.9\times10^{-301}$，仍在 `double` 规格化范围（最小正规数 $\approx2.2\times10^{-308}$）内；即使下溢成 $0$，只是把分母 $1-2^{-k}$ 变成 $1$，相对误差 $<10^{-300}$，无害。
- **舍入误差**：`double` 尾数 $53$ 位，机器精度 $u=2^{-53}\approx1.1\times10^{-16}$，所有量级 $\le1$，故每次运算的绝对误差 $\le u$。一个本列元素 $\approx4$ 次舍入，一列新引入误差 $L_k\le4ku$（$k=1000$ 时 $\le4.4\times10^{-13}$）。跨列传播是**压缩**的：由 (2.6)(2.7)，$b_t=f(t,k-1)$ 对 $x_k$ 的灵敏度
  $$\frac{\partial x_k}{\partial b_t}=\frac{\frac16\,2^{\,t-k+1}}{1-2^{-k}},\qquad \sum_{t=1}^{k-1}\frac{\partial x_k}{\partial b_t}<\frac{\frac13}{\frac34}=\frac49,$$
  （用了 $\sum_{t=1}^{k-1}2^{t-k+1}=\sum_{j=0}^{k-2}2^{-j}<2$，以及 $1-2^{-k}\ge\frac34$）；对本列其它元 $a_i=\alpha_ix+\beta_i$，$\alpha_i=2^{1-i}\le\frac12$ 而 $\sum_t\frac{\partial\beta_i}{\partial b_t}=\frac13\sum_{j=0}^{i-2}2^{-j}<\frac23$，合计 $<\frac29+\frac23=\frac89$。取最坏因子 $\frac89$ 累加几何级数：
  $$E_n\le\sum_{j=2}^{n}\left(\frac89\right)^{n-j}4ju=4nu\sum_{m\ge0}\left(\frac89\right)^m=36nu\le36\times10^3\times1.1\times10^{-16}\approx4\times10^{-12},$$
  比 $9$ 位小数四舍五入所需的 $5\times10^{-10}$ 还小约 $125$ 倍，`double` 足够（想更保险可换 `long double`，$u$ 降到 $10^{-19}$ 量级，输出不变）。

## 5. 示例代码（C++）

```cpp
// P1409 骰子  概率DP + 同列仿射解环
// https://www.luogu.com.cn/problem/P1409
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};         // n<=1000 +5

double dp[mxn][mxn];             // dp[k][i]:队里k人、你在第i位的胜率
double al[mxn],be[mxn];          // 本列 a[i]=al[i]*x+be[i]

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m;
	cin>>n>>m;

	dp[1][1]=1.0;                  // k=1:只剩你,题面直接判胜
	for(int k=2;k<=n;++k)
	{
		al[1]=1.0;
		be[1]=0.0;                 // a[1]=x
		for(int i=2;i<=k;++i)      // 斜率每次减半,截距吸收上一列
		{
			al[i]=al[i-1]/2.0;
			be[i]=be[i-1]/2.0+dp[k-1][i-1]/3.0;
		}
		double x=(1.0/6.0+be[k]/2.0)/(1.0-al[k]/2.0);   // 闭合方程(2.7)
		dp[k][1]=x;
		for(int i=2;i<=k;++i)
			dp[k][i]=al[i]*x+be[i];
	}
	// cerr<<dp[n][m]<<'\n';
	cout<<fixed<<setprecision(9)<<dp[n][m]<<'\n';
	return 0;
}
```

### 代码说明

- **下标口径**：$i$ 是"第几位"、$k$ 是"人数"，二者在题面里天然 1-based，且**不需要输出下标**，故全文 1-based，不做 `--m` 转换（规范允许：无输出下标风险时保持与题面一致，最不容易错）。
- **不越界**：第 $k$ 列只读 `dp[k-1][i-1]`（$i\le k$ ⟹ $i-1\le k-1$），$i>k$ 的表元从不被读，`double` 全局数组默认的 $0$ 不会被误用，故无需 `fill_n`（无 INF 语义）。
- **`constexpr int p{...}` 缺失是有意的**：本题输出实数，无模数。
- **`1.0/6.0` 而非 `1/6`**：`1/6` 是整数除法 $=0$，会把"队首直接获胜"的 $\frac16$ 抹成 $0$，是本题最典型的坑。

### 口径风险

题面有四处没写死、但会影响答案的语义，本文取值如下并给出理由：

1. **骰子均匀**：题面只说"骰子"，未写"六面等可能"。全文的 $\frac16,\frac12,\frac13$（(2.1)）与引理 8 的面计数都建立在均匀假设上；若有偏，题目数据无从确定，故排除该读法。
2. **$n=1$ 时是否立刻判胜**：本文取"是"，即 $f(1,1)=1$（(2.4)）。反证另一种读法：若 $n=1$ 还要掷骰，则掷出 $3,5$ 会让你出队、队列变 $0$ 人，此时"仅剩一人则该人获胜"永远不成立、游戏无获胜者，题目在该口径下无定义。故终止检查必然在掷骰之前生效；同一口径也用于 (2.3) 中 $k=2,i=2$ 掷出 $3,5$ 后"剩你一人判胜"这一步，两处必须一致，否则 $f(\cdot,2)$ 会整体偏掉。
3. **有人获胜即停止**：否则"获胜"没有意义，而且引理 7 的"获胜者唯一"、(2.2) 里 $A_1$ 直接记 $1$ 都依赖它。
4. **"排到队尾"的方向**：掷 $2,4,6$ 时队首那人**离开队首、加到队尾**，其余人整体前移一位、长度不变（§2.2 与引理 8 里 $q=((p-1-r)\bmod k)+1$ 的来源）。若读成"其他人后移"，位移方向相反，(2.3) 第一项的下标会全错——上表 $f(1,2)=\frac49<f(2,2)=\frac59$ 这类可比的大小关系可用来定位这类笔误。

**输出格式**：`fixed<<setprecision(9)` 打印恰好 $9$ 位小数，符合"精确到小数点后 $9$ 位"。
