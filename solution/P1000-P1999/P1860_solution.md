# P1860 新魔法药水

## 1. 重新读题

### 1.1 问题重述（人话版）

商店里有 $N$ 种药水，第 $i$ 种的**售价**为 $b_i$（买进花 $b_i$），**回收价**为 $s_i$（卖出得 $s_i$）。小 $S$ 一开始有 $V$ 元钱，还知道 $M$ 个魔法配方，每个配方形如“把若干种药水各 $1$ 份合成为另一种药水 $1$ 份”。

他一天之内**最多使用 $K$ 次魔法**。问：通过“买药水 → 用魔法合成 → 卖药水”，一天最多能赚多少钱？

关键限制：**卖药水得到的钱不能立刻再拿去投资**。也就是说，一天里所有“买”的总花费不能超过初始的 $V$；“卖”只发生在最后结算，不能滚动使用。

### 1.2 关键约束与规模暗示

- $N\le 60$，$M\le 240$，$V\le 1000$，$K\le 30$。
- $V,K$ 都不大，天然指向**以“钱”和“魔法次数”为两维的背包 DP**。
- 配方可能嵌套（用魔法造出来的药水又能当原料）、也可能成环，因此“获得一种药水的最小成本”要在**次数有限**的前提下递推，不能简单跑一次最短路。
- $K\le 30$ 很小，可以按次数分层，枚举原料各用多少次。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把一天的操作画成“森林”

把每一次魔法看成图上的一个结点：它消耗若干“原料单位”，产出 $1$ 个“成品单位”。于是一天里所有操作加上买入、卖出，构成若干棵树：

- 每棵树的**叶子**是直接买进来的药水；
- 每个**内部结点**是一次魔法操作；
- 每棵树的**根**是最后被卖掉的药水。

同一棵树里，每个内部结点消耗其孩子，产出交给父亲（或作为根卖出）。不同树之间不共享任何药水单位。

**引理 1（森林模型）**：任意一个合法的一日方案，都对应一个森林：内部结点数 = 使用的魔法次数 $\le K$；叶子购买总花费 $\le V$；收益 = $\sum_{\text{根}} s_{\text{root}}-\sum_{\text{叶子}} b_{\text{leaf}}$。反之，任意这样的森林都能按后序执行魔法，得到一个合法方案，收益相同。

**证明**：

- **方案 → 森林**：对每个被合成出来的药水单位，建一个内部结点，记录它用的配方；其原料单位若是买的，就是叶子，若是合成的，就是其孩子结点；最终没有被继续使用、而是被卖掉的单位作为根。每个单位在方案里只被购买或合成一次、只被消耗或卖掉一次，所以这些结点构成互不相交的树（每棵树根唯一、每个结点最多一个父亲），内部结点数正是魔法次数。购买总花费即叶子权值和，收益即根售价和减叶子买价和。
- **森林 → 方案**：按后序（先叶子后根）执行每个内部结点的魔法即可，此时原料都已就位；所有叶子在开始时一次性买入，总花费 $\le V$，符合“卖出所得不能再投资”的约束。$\blacksquare$

### 2.2 把“子树”压缩成成本表

森林模型里，唯一重要的问题是：**用不超过 $t$ 次魔法、花最少的钱，弄到 $1$ 份药水 $i$**。定义

$$
c[i][t]=\text{获得 1 份药水 }i\text{ 所需的最小购买花费，魔法次数不超过 }t.
$$

约定 $c[i][t]=+\infty$ 表示做不到。

- $t=0$：只能直接买，$c[i][0]=b_i$。
- $t\ge1$：要么不使用新的魔法（仍为 $c[i][t-1]$），要么最后一步使用某个“产出 $i$”的配方：配方的每种原料 $j$ 各需要 $1$ 份，可以分别用不超过 $t_j$ 次魔法获得，总次数满足 $1+\sum t_j\le t$，花费为 $\sum c[j][t_j]$。

**引理 2（成本递推）**：
$$
c[i][t]=\min\Bigl(c[i][t-1],\ \min_{\text{配方 }r\text{ 产出 }i}\ \min_{\substack{\sum_j t_j\le t-1\\ t_j\ge0}}\sum_{\text{原料 }j\text{ of }r} c[j][t_j]\Bigr).
$$

**证明**：对 $t$ 归纳，同时说明两点。

1. **可行方案的代价不低于右式**：任取一个用 $\le t$ 次魔法得到 $i$ 的最优方案。若一次魔法都不用，代价 $\ge c[i][t-1]$（归纳假设 $c[i][t-1]$ 是 $t-1$ 次以内的最小代价）。否则看产出这个 $i$ 的**最后一次**魔法，它使用配方 $r$，其每个原料单位 $j$ 各自对应一棵使用 $\le t_j$ 次魔法的子树，且 $1+\sum t_j\le t$；按归纳假设，该原料实际花费不低于 $c[j][t_j]$，故总花费不低于右式中对应项。
2. **右式的值可达**：若取 $c[i][t-1]$，由归纳假设可达；若取某个配方 $r$ 和一组 $t_j$，对每个原料按 $c[j][t_j]$ 的最优方案独立构造，再用一次魔法执行 $r$，总次数 $1+\sum t_j\le t$，花费恰为 $\sum c[j][t_j]$。可行。

因此右式既是最优值的下界，又可取到，等式成立。$\blacksquare$

### 2.3 按次数分层，天然无环

**引理 3（计算顺序）**：$c[\cdot][t]$ 只依赖 $c[\cdot][0..t-1]$。因此从 $t=0$ 到 $K$ 依次计算，不会出现循环依赖。

**证明**：引理 2 的右式中，第一项是 $t-1$；第二项中每个原料的次数 $t_j\le\sum t_j\le t-1$。所有引用都在更小的次数层。$\blacksquare$

这也是为什么不能直接套“最短路”：最短路允许无限次合成，而这里次数是有限资源，必须把次数当成 DP 的一维。

### 2.4 从成本表到最终背包

有了 $c[i][t]$，每“卖出一份药水 $i$、并且为它花费至多 $t$ 次魔法”就是一个物品：

- 花费（购买成本）$c[i][t]$；
- 收益（卖出收入减购买成本）$s_i-c[i][t]$；
- 占用魔法次数至多 $t$。

不同的树互不共享药水，所以可以**任意多次**选择这些物品，只要总次数 $\le K$、总购买花费 $\le V$。

**引理 4（最终背包正确性）**：一日最大收益等于下述完全背包问题的最优值：
$$
\max\ \sum_{\text{选中的物品}} \bigl(s_i-c[i][t]\bigr)
\quad\text{s.t.}\quad \sum t\le K,\ \ \sum c[i][t]\le V .
$$

**证明**：

- 任一森林的每棵根树对应一个物品 $(i,t)$（$i$ 为根药水，$t$ 为该树内部结点数上界），约束与目标完全一致，故背包最优值 $\ge$ 森林最优收益。
- 反之，背包中每个物品都能按引理 2 的可达性构造出一棵真实子树；不同物品的树彼此独立、叶子购买互不重复，合在一起就是合法森林，收益等于背包目标值。故背包最优值 $\le$ 森林最优收益。

两者相等。$\blacksquare$

只保留正收益的物品即可（负收益选了只会变差），并把 $t=0$（直接买进再卖出）也作为一个物品，自动涵盖“不做魔法、赚差价”的情况。

### 2.5 一个“看起来更简单但会错”的想法

有人会先无限次松弛求出“无限魔法下的最小成本”，再做背包。这在本腔题里是错的：若先用 $1$ 次魔法把 $A$ 变成 $B$（成本按 $A$ 算），再把 $B$ 当原料用一次魔法变成 $C$，实际用了 $2$ 次魔法；而“无限成本表”会把第二条配方的成本记成 $B$ 的无限成本，相当于漏数了一次魔法。次数是硬约束，必须保留。

**反例（极简）**：$A$ 买价 $5$，$B$ 卖价 $20$，$C$ 卖价 $100$；配方 $A\to B$、$B\to C$，$K=1$。无限成本下 $c[B]=5$，于是“先 $A\to B$ 再 $B\to C$”看起来只花 $5$ 元做一次配方 $B\to C$ 就得到 $100$；但真正执行需要 $2$ 次魔法。若直接按“每个配方成本 $5$”做背包，会算出 $\ge 95$ 的收益，而 $K=1$ 时最优只能做 $A\to B$ 或直接买 $A$（$B\to C$ 无 $B$ 可用），收益远小于它。按次数分层的 $c[i][t]$ 才能正确区分。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 把操作序列看成森林：叶子买入、内部结点是魔法、根卖出。
- **reduce to easier problem** — 单棵树只关心“用至多 $t$ 次魔法获得一份药水的最小花费” $c[i][t]$。
- **classic problem solution** — 以魔法次数分层做 min-plus 背包，得到成本递推；次数递增保证无环。
- **find counterexample** — 用 $A\to B\to C$、$K=1$ 说明“无限次最小成本”会漏数魔法次数。
- **classic problem solution** — 把每个 $(药水,次数上限)$ 看成可重复选择的物品，做“次数 + 钱”二维完全背包。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `N,M,V,K` | `int` | 药水数 / 配方数 / 初始钱 / 魔法上限 | 读入 | 维度 |
| `buy[i]` | `int [65]` | 售价（买入价） | 读入 | buy |
| `sell[i]` | `int [65]` | 回收价（卖出价） | 读入 | sell |
| `prod[r]` | `int [245]` | 第 $r$ 个配方的成品 | 读入后 $-1$ | product |
| `ci[r]` | `int [245]` | 第 $r$ 个配方的原料个数 | 读入 | count |
| `ing[r][j]` | `int [245][105]` | 第 $r$ 个配方的第 $j$ 个原料 | 读入后 $-1$ | ingredient |
| `c[i][t]` | `i64 [65][35]` | 用至多 $t$ 次魔法获得 1 份 $i$ 的最小购买花费 | `c[i][0]=buy[i]`，其余 `INF` | cost |
| `g[s]` | `i64 [35]` | 某配方原料合计用至多 $s$ 次魔法的最小花费 | 0 / `INF` | group |
| `ng[s]` | `i64 [35]` | min-plus 卷积的临时数组 | —— | next group |
| `dp[k][v]` | `i64 [35][1005]` | 用至多 $k$ 次魔法、总购买花费至多 $v$ 的最大收益 | 0 | 最终背包 |

### 4.2 算法步骤

1. 读入 $N,M,V,K$；读入每种药水的 `buy,sell`；读入 $M$ 个配方（成品、原料数、原料列表），全部转 0-based。
2. 初始化 $c[i][0]=buy[i]$，其余 $t>0$ 置 `INF`。
3. 对 $t=1..K$：
   - 先令 $c[i][t]=c[i][t-1]$；
   - 对每个配方 $r$（成品 $p$）：
     - 令预算 $B=t-1$；初始化 $g[0]=0$，$g[1..B]=\text{INF}$；
     - 对配方中每个原料 $j$：用 $g$ 与 $c[j][0..B]$ 做 min-plus 卷积得 `ng`，再令 $g=ng$；
     - 若 $g[B]<\text{INF}$，用 $g[B]$ 更新 $c[p][t]$。
4. 初始化 `dp` 全 $0$。
5. 对 $k=0..K$，$v=0..V$，对每种药水 $i$ 和每个 $t\le k$：
   - 若 $c[i][t]<\text{INF}$ 且 $s_i-c[i][t]>0$ 且 $c[i][t]\le v$：
     $$\text{dp}[k][v]=\max\bigl(\text{dp}[k][v],\ \text{dp}[k-t][v-c[i][t]]+s_i-c[i][t]\bigr).$$
6. 输出 `dp[K][V]`。

### 4.3 复杂度分析

- 成本表：$\sum_{t=1}^{K}M\cdot L\cdot t^2=O(MLK^3)$，其中 $L$ 为配方原料数的上界；$K=30$ 时约 $1.4\times10^8$。
- 最终背包：$O(NVK^2)$，约 $5.4\times10^7$。
- 空间：$O(NK+KV)$，均可忽略。

## 5. 示例代码

```cpp
//
// 题目：P1860 新魔法药水
// https://www.luogu.com.cn/problem/P1860
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{65};
constexpr int mxm{245};
constexpr int mxk{35};
constexpr int mxv{1005};
constexpr i64 INF{1145141919810LL};

int N,M,V,K;
i64 buy[mxn],sell[mxn];
int prod[mxm],ci[mxm],ing[mxm][105];
i64 c[mxn][mxk];
i64 g[mxk],ng[mxk];
i64 dp[mxk][mxv];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>N>>M>>V>>K;
	for(int i=0;i<N;++i)
		cin>>buy[i]>>sell[i];

	for(int r=0;r<M;++r)
	{
		cin>>prod[r]>>ci[r];
		--prod[r];
		for(int j=0;j<ci[r];++j)
		{
			cin>>ing[r][j];
			--ing[r][j];
		}
	}

	for(int i=0;i<N;++i)
	{
		c[i][0]=buy[i];
		for(int t=1;t<=K;++t)
			c[i][t]=INF;
	}

	// 按魔法次数分层；每层只用 <=t-1 层的数据，天然无环
	for(int t=1;t<=K;++t)
	{
		for(int i=0;i<N;++i)
			c[i][t]=c[i][t-1];

		int B=t-1;
		for(int r=0;r<M;++r)
		{
			g[0]=0;
			for(int s=1;s<=B;++s)
				g[s]=INF;

			for(int j=0;j<ci[r];++j)
			{
				int id=ing[r][j];
				for(int s=0;s<=B;++s)
					ng[s]=INF;
				for(int s=0;s<=B;++s)
					for(int u=0;u<=s;++u)
						if(g[s-u]<INF&&c[id][u]<INF)
							ng[s]=min(ng[s],g[s-u]+c[id][u]);
				for(int s=0;s<=B;++s)
					g[s]=ng[s];
			}

			int p=prod[r];
			if(g[B]<INF)
				c[p][t]=min(c[p][t],g[B]);
		}
	}

	// dp[k][v]：至多 k 次魔法、至多花 v 元的最大收益
	for(int k=0;k<=K;++k)
		for(int v=0;v<=V;++v)
		{
			// 继承“少用一次魔法 / 少花一点钱”的较优解
			if(k>0)
				dp[k][v]=max(dp[k][v],dp[k-1][v]);
			if(v>0)
				dp[k][v]=max(dp[k][v],dp[k][v-1]);

			for(int i=0;i<N;++i)
				for(int t=0;t<=k;++t)
				{
					i64 cost=c[i][t];
					if(cost>=INF||cost>v)
						continue;
					i64 gain=sell[i]-cost;
					if(gain<=0)
						continue;
					dp[k][v]=max(dp[k][v],dp[k-t][v-cost]+gain);
				}
		}

	cout<<dp[K][V]<<'\n';
	return 0;
}
```
