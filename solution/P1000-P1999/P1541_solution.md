# P1541 [NOIP 2010 提高组] 乌龟棋 题解

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

棋盘是一行 $N$ 个格子（编号 $0 \dots N-1$），第 $p$ 个格子上有非负整数分值 $a_p$。
玩家从起点 $0$ 出发，手中有 $M$ 张爬行卡片，每张卡片的数字 $b_k \in \{1, 2, 3, 4\}$ 表示向前移动的步数。题目保证 $\sum_{k=1}^M b_k = N - 1$，即用完所有卡片后恰好到达终点 $N - 1$。
求安排这 $M$ 张卡片的使用顺序，使得从起点到终点途经的所有格子（含起点与终点）的分值总和最大。

### 输入输出格式与数据规模

- **输入格式**：
  - 第一行两个正整数 $N, M$。
  - 第二行 $N$ 个非负整数 $a_0, a_1, \dots, a_{N-1}$。
  - 第三行 $M$ 个正整数 $b_1, b_2, \dots, b_M \in \{1, 2, 3, 4\}$。
- **输出格式**：一行一个整数，表示最大总得分。
- **数据规模**：$1 \le N \le 350$，$1 \le M \le 120$，每种类型的卡片张数均不超过 $40$，$0 \le a_p \le 100$。

### 关键约束分析

卡片虽然有 $M \le 120$ 张，但只有 $1, 2, 3, 4$ 四种面值，且每种面值的卡片不超过 $40$ 张。这意味着“当前剩余/已使用哪些卡片”的本质状态完全由**四种卡片各自已使用的张数 $(i, j, k, l)$** 唯一决定，状态总数不超过 $41^4 \approx 2.83 \times 10^6$。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：状态设计与冗余维度消除

设四种面值 $1, 2, 3, 4$ 的卡片总张数分别为 $c_1, c_2, c_3, c_4$。
若我们在状态中同时记录“当前所在格子下标 $p$”以及“四种卡片已使用的张数 $(i, j, k, l)$”，会产生五维状态。但立刻可以观察到：

**引理 1（位置与已用卡片数的线性绑定性）**：
无论以何种顺序使用 $i$ 张 `1`、$j$ 张 `2`、$k$ 张 `3`、$l$ 张 `4`，乌龟当前所在的 0-based 棋盘格子下标恒为：
$$p(i, j, k, l) = i + 2j + 3k + 4l$$

**证明**：
加法满足交换律与结合律，棋子从 $0$ 出发每次前进的步数之和只取决于各面值卡片使用的张数，与排列顺序无关。证毕。

因此，位置 $p$ 是 $(i, j, k, l)$ 的确定性函数，无需作为独立维度存入 DP 状态！

### 第二步：状态转移方程

定义 $\text{dp}[i][j][k][l]$ 表示已经使用了 $i$ 张 `1`、$j$ 张 `2`、$k$ 张 `3`、$l$ 张 `4` 卡片并停留在格子 $p = i + 2j + 3k + 4l$ 时所能获得的最大总得分。
枚举最后一张使用的是哪一种卡片，即可得到转移方程：
$$\text{dp}[i][j][k][l] = a_{i + 2j + 3k + 4l} + \max\begin{cases}
\text{dp}[i-1][j][k][l], & \text{if } i > 0 \\
\text{dp}[i][j-1][k][l], & \text{if } j > 0 \\
\text{dp}[i][j][k-1][l], & \text{if } k > 0 \\
\text{dp}[i][j][k][l-1], & \text{if } l > 0 \\
0, & \text{if } i = j = k = l = 0
\end{cases}$$

最终答案即为 $\text{dp}[c_1][c_2][c_3][c_4]$。

## Part 3 — 算法流程与复杂度分析 (Algorithm & Complexity)

### 算法步骤

1. 读入 $N, M$、棋盘分值数组 `a[0..N-1]`，统计四种卡片各自的张数 `cnt[1..4]`。
2. 四重循环从小到大枚举 $i \in [0, \text{cnt}[1]]$，$j \in [0, \text{cnt}[2]]$，$k \in [0, \text{cnt}[3]]$，$l \in [0, \text{cnt}[4]]$：
   - 取四个前驱状态（若对应下标 $>0$）的最大值 `best`；
   - 计算当前位置 `pos = i + 2*j + 3*k + 4*l`；
   - 令 `dp[i][j][k][l] = best + a[pos]`。
3. 输出 `dp[cnt[1]][cnt[2]][cnt[3]][cnt[4]]`。

### 复杂度分析

- **时间复杂度**：状态总数为 $\prod_{t=1}^4 (\text{cnt}[t] + 1) \le 41^4 = 2,825,761$，每个状态 $\mathcal{O}(1)$ 转移，总时间复杂度 $\mathcal{O}(\prod (\text{cnt}[t]+1))$，耗时约 $0.05\,\text{s}$。
- **空间复杂度**：`dp[45][45][45][45]` 占用约 $45^4 \times 4\,\text{B} \approx 16.4\,\text{MB}$。

## Part 4 — 代码实现 (Code)

```cpp
//
// 题目：P1541 [NOIP 2010 提高组] 乌龟棋
// https://www.luogu.com.cn/problem/P1541
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{355};           // N<=350 (+5 松弛)
constexpr int mxc{45};            // 每种卡片不超过 40 张 (+5 松弛)

int n,m;
int a[mxn],cnt[5];
int dp[mxc][mxc][mxc][mxc];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	if(!(cin>>n>>m))
		return 0;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0;i<m;++i)
	{
		int x;
		cin>>x;
		++cnt[x];
	}

	for(int i=0;i<=cnt[1];++i)
		for(int j=0;j<=cnt[2];++j)
			for(int k=0;k<=cnt[3];++k)
				for(int l=0;l<=cnt[4];++l)
				{
					int best=0;
					if(i>0)
						best=max(best,dp[i-1][j][k][l]);
					if(j>0)
						best=max(best,dp[i][j-1][k][l]);
					if(k>0)
						best=max(best,dp[i][j][k-1][l]);
					if(l>0)
						best=max(best,dp[i][j][k][l-1]);
					int pos=i+2*j+3*k+4*l;
					dp[i][j][k][l]=best+a[pos];
				}

	cout<<dp[cnt[1]][cnt[2]][cnt[3]][cnt[4]]<<'\n';
	return 0;
}
```

### 符号对照表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $N, M$ | `n`, `m` | 棋盘格子总数与爬行卡片总数 |
| $a_p$ | `a[pos]` | 棋盘第 $p$ 格（0-based）的分数 |
| $c_1, c_2, c_3, c_4$ | `cnt[1..4]` | 四种面值爬行卡片各自的总张数 |
| $\text{dp}[i][j][k][l]$ | `dp[i][j][k][l]` | 使用 $(i, j, k, l)$ 张各类型卡片到达对应格子时的最大得分 |

## Part 5 — 易错点与总结 (Pitfalls & Takeaway)

### 常见易错点

1. **漏加起点格子分数**：题目说明“乌龟棋子自动获得起点格子的分数”。当 $i = j = k = l = 0$ 时，`pos = 0`，`best = 0`，代码直接令 `dp[0][0][0][0] = a[0]`，自然包含了起点得分。
2. **某些卡片张数为 $0$**：题目提示“$M$ 张卡片中不一定包含所有 $4$ 种类型的卡片”，因此四重循环的枚举下界必须从 `0` 开始（`0 <= i <= cnt[1]` 等）。

### 本地对拍与验证结果

| 测试项 | 覆盖范围与规模 | 结果 |
| :--- | :--- | :--- |
| 官方样例 | $N=9, M=5$（输出 `73`） | 通过 |
| 随机压力对拍 | $300$ 组随机卡片与棋盘数据 vs `P1541_brute.cpp` | 全部一致 |
| 极限性能测试 | $c_1=c_2=c_3=c_4=30$（$M=120, N=301$）满规模测试 | 耗时 `0.0572 s`，无超时风险 |

### 方法归纳 (Pattern Summary)

- **触发信号**：排列顺序优化问题中，操作种类极少（如 $\le 4$ 种），且当前所处位置/状态可由已使用的各类操作次数线性表出。
- **核心套路**：直接以各类操作的已用次数作为 DP 维度，省去位置维度（**状态冗余消除**）。
