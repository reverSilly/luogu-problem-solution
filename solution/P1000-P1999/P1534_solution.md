# P1534 不高兴的津津（升级版）

> 标签：模拟 · 难度：入门
> 本地题面：`P1534.md`（$n\le 3000$，每天上学时间、上课时间各 $\le 8$，两者之和 $\le 16$）。
> 验证：`appendix/P1534/` 对拍 300 组随机用例 + 官方样例 + 最坏 $n=3000$（答案 $36012000$，耗时 $0.0058$ s）全部 PASS。

## 1. 重新读题

**问题重述（人话版）**

津津第 $t$ 天要上 $a_t+b_t$ 小时的课（$a_t$ 为上学时间，$b_t$ 为课外补习班时间）。题面规定了"不高兴程度"的**递推**算法，而不是当天独立计算：

> 用**昨天**的不高兴程度，加上**今天上课总时间**，再**减去 8**，得到的数就是**今天**的不高兴程度。

而要求的输出是：

> 这 $n$ 天**过后的不高兴程度和**。

**题面里容易踩的坑（逐条点名）**

1. **"和" 是逐日累加，不是最后一天的值。** 题目明说是"$n$ 天过后的不高兴程度**和**"。很多人只输出最后一天（第 $n$ 天）的不高兴程度，直接错。样例恰好能把这两者区分开（见 §2.4）。
2. **"昨天" 对第 1 天而言是 $0$。** 题面没有给出第 0 天的数据，唯一自然的初值就是"连续过程的起点不高兴程度 $=0$"。
3. **不高兴程度不是"上课超没超过 8 小时"的开关，而是带符号的连续累加量。** 原文"上得越久就会越不高兴"，且递推是加减法，因此它可以是负数——**低于 8 小时会给出负贡献，且这个负值全部带到明天，绝不在 0 处截断**。题面特意强调"假设津津不会因为其它事不高兴"，正是为了排除"心情在 0 处复位"的读法。
4. **答案可以是负数，也可能很大。** 每天增量 $d_t\in[-8,8]$，"和"的极值约为 $\pm 8\cdot\frac{3000\cdot3001}{2}\approx\pm 3.6\times10^7$，`int` 装得下，但用 `long long` 更稳妥。
5. **没有任何分支/无解情况。** 全程只有一条确定的递推链，不需要比较、不需要判定，属于纯模拟。

**数据范围与规模感受**

$$1\le n\le 3000,\qquad 0\le a_t,b_t\le 8,\qquad a_t+b_t\le 16 .$$

$n$ 只有 $3000$，任意 $O(n)$ 甚至 $O(n^2)$ 都可过；本题的目标不是压复杂度，而是**把递推与求和的关系写对**。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"持续到第二天"翻译成一阶递推

先只盯住一句话：*"用昨天不高兴程度加上今天上课总时间减去 8 后得到的数作为今天不高兴程度"*。设 $m_t$ 为第 $t$ 天结束后的不高兴程度，$d_t=a_t+b_t-8$ 为今天的"净增量"。这句话就是

$$m_t = m_{t-1}+d_t,\qquad m_0=0 .$$

**引理 1（递推展开为前缀和）**

对任意 $t\ge1$，有 $m_t=\sum_{k=1}^{t}d_k$。

**证明**（对 $t$ 归纳）：
- 基例 $t=1$：$m_1=m_0+d_1=0+d_1=\sum_{k=1}^{1}d_k$。✓
- 归纳步：设 $m_{t-1}=\sum_{k=1}^{t-1}d_k$，则
  $$m_t=m_{t-1}+d_t=\Big(\sum_{k=1}^{t-1}d_k\Big)+d_t=\sum_{k=1}^{t}d_k .$$
  归纳完成。$\blacksquare$

> 这条引理的意义：它把"一天天往下滚"的递推**一次性解耦**了——第 $t$ 天的程度只由前 $t$ 天各自的净增量决定，不依赖其它天的边界处理。

### 2.2 归约：把"先递推再求和"换成"按贡献次数加权"

现在处理输出量。设答案 $A=\sum_{t=1}^{n}m_t$。直接把引理 1 代进去。

**引理 2（求和换序：每条 $d_k$ 恰好被计 $n-k+1$ 次）**

$$A=\sum_{t=1}^{n}m_t=\sum_{t=1}^{n}\sum_{k=1}^{t}d_k=\sum_{k=1}^{n}(n-k+1)\,d_k .$$

**证明**：在上面的二重和里，把**求和次序交换**（这是有限双指针求和的标准换序，对所有项做的是同一组加法，不改变和值）。固定 $k$，它出现在所有满足 $t\ge k$ 的内层和里，$t$ 可取 $k,k+1,\dots,n$ 共 $n-k+1$ 个值，因此 $d_k$ 在总和里恰好被累加 $n-k+1$ 次，即 $\sum_{t\ge k}d_k=(n-k+1)d_k$。对 $k=1..n$ 累加即得结论。$\blacksquare$

> 这条引理给出两个等价的实现路径，也正好对应"标程 / 暴力"两种代码：
> - **路径 A（标程）**：模拟滚动——`cur+=d_t; ans+=cur;`，每轮把当前 $m_t$ 加进总和。它其实就是在按 $t$ 的顺序累加 $m_t=\sum_{k\le t}d_k$。
> - **路径 B（暴力基准）**：先求前缀和 $S_t=\sum_{k\le t}(a_k+b_k)$，则 $m_t=S_t-8t$，再对 $t$ 累加。它绕开了"逐日滚动"这个状态，直接把"和"写成闭式求和，是对引理 1、2 的独立验证。

### 2.3 为什么不能"在 0 处掐断"

一个常见误读是：把"不高兴"理解成布尔状态或非负量，于是每当 $m_t<0$ 就重置为 $0$。

**引理 3（禁止截断）**

若把递推改成 $m'_t=\max(0,\,m'_{t-1}+d_t)$，则一般 $A'=\sum m'_t\ne A$；本题必须用未截断的 $m_t$。

**证明（用官方样例给出反例即证）**：官方样例 $n=7$，日程 $(5,3),(6,2),(7,2),(5,3),(5,4),(0,4),(0,6)$，故 $d_t=(0,0,1,0,1,-4,-2)$。
- 未截断：$m=(0,0,1,1,2,-2,-4)$，$A=-2$。（与官方输出 $-2$ 一致，见 §2.4）
- 截断版：$m'=(0,0,1,1,2,0,0)$，$A'=4\ne -2$。
两者不等，故截断版必错。$\blacksquare$

### 2.4 用官方样例消除"和 vs 最终值"的歧义

官方样例：输入

```
7
5 3
6 2
7 2
5 3
5 4
0 4
0 6
```

期望输出 `-2`。手推：

| 天数 $t$ | $a_t+b_t$ | $d_t$ | $m_t$（累计） | $\sum_{s\le t}m_s$ |
|---|---|---|---|---|
| 1 | 8 | 0 | 0 | 0 |
| 2 | 8 | 0 | 0 | 0 |
| 3 | 9 | 1 | 1 | 1 |
| 4 | 8 | 0 | 1 | 2 |
| 5 | 9 | 1 | 2 | 4 |
| 6 | 4 | −4 | −2 | 2 |
| 7 | 6 | −2 | −4 | **−2** |

- 若输出**逐日和**：$-2$ ✓（与官方一致）。
- 若输出**最后一天值**：$-4$ ✗。

**结论：输出的是逐日累加和，且允许中间与最终都出现负数。** 这一步同时确认了 §1 的两个坑（"和"、不截断）。

### 2.5 边界与溢出体检

- $n=1$：$A=m_1=d_1$；题面允许，代码 $n$ 次循环自然处理。
- 极值：全 $(8,8)$ 时 $A=8\sum_{t=1}^{3000}t=8\times 4501500=36012000$（实测见 §4.3）；全 $(0,0)$ 时为 $-36012000$。二者都在 `int` 范围内，但代码用 `i64` 兜底。

## 3. 模式总结（Pattern Summary）

**模式名：一阶递推序列的「逐日累加 + 求和换序」。**

按实际思考顺序排列：

- **explore its property** — 把"不高兴会持续到第二天"读成一阶线性递推 $m_t=m_{t-1}+d_t$，$m_0=0$。
- **reduce to easier problem** — 用归纳把递推展开为前缀和 $m_t=\sum_{k\le t}d_k$（引理 1），消去递推这一层。
- **change the order of summation** — 对 $\sum_t m_t$ 做求和换序，得到 $\sum_k(n-k+1)d_k$（引理 2），使"和为输出"这件事有闭式解释。
- **use the official sample to disambiguate** — 用样例把"和"与"最终值"、"带符号"与"截断到 0"两组歧义一次性锁死（§2.4、引理 3）。
- **forbid illegal clamping** — 明确心情量可为负，不可在 0 处重置（引理 3 反例）。
- **simulate directly** — 既然递推天然 $O(n)$，直接顺序模拟即可，不需要任何数据结构。

**一句话记忆**：递推出一串带符号的数，答案问"和"，就边递推边累加；注意样例会告诉你是否截断、是否求和。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `int` | 天数 | 读入 | 题面 |
| `a`,`b` | `int`（循环内） | 当天上学时长 / 课外补习时长 | 读入 | 题面 |
| $d_t$ | 表达式 `a+b-8` | 第 $t$ 天的净增量 | — | 引理 1 |
| `cur` | `i64` | **今天**的不高兴程度 $m_t$ | `0` | "current mood"，即递推状态 |
| `ans` | `i64` | 逐日程度之和 $A=\sum_t m_t$ | `0` | 最终输出 |

### 4.2 编号步骤

1. `cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`（固定顺序），读入 $n$。
2. 初始化 `cur=0, ans=0`（对应 $m_0=0$）。
3. 对 $t=0..n-1$（0-based 循环变量）：
   3.1 读入当天的 `a,b`。
   3.2 `cur += a+b-8;`（实现 $m_t=m_{t-1}+d_t$，引理 1）。
   3.3 `ans += cur;`（把 $m_t$ 计入总和，引理 2）。
4. 输出 `ans`，`'\n'` 结尾。

### 4.3 复杂度与验证状态

- 时间 $O(n)$，空间 $O(1)$。
- **官方样例**：`7 / 5 3 / 6 2 / 7 2 / 5 3 / 5 4 / 0 4 / 0 6` $\to -2$ ✓。
- **随机对拍**：$300$ 组随机用例（$n\in[1,3000]$，每天两数 $\in[0,8]$），标程（滚动累加）与暴力（前缀和闭式）输出**逐字节一致** ✓。
- **边界**：`n=1, 0 0` $\to -8$；`n=1, 8 8` $\to 8$ ✓。
- **最坏规模计时**：$n=3000$、每天 `8 8` $\to 36012000$，耗时 **$0.0058$ s**。
- 残余风险：无（逻辑是确定的纯模拟）；唯一需要人为守住的是"用 `'\n'` 而非 `endl`"等风格项。

## 5. 示例代码

### 5.1 主解：逐日滚动累加（标程）

```cpp
//
// 题目：P1534 不高兴的津津（升级版）
// https://www.luogu.com.cn/problem/P1534
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	i64 cur{0},ans{0};        // cur=今天的不高兴程度, ans=逐日程度之和
	for(int i=0,a,b;i<n;++i)
	{
		cin>>a>>b;
		cur+=a+b-8;           // 今天 = 昨天 + 今日上课总时长 - 8
		ans+=cur;             // 把今天的程度计入总和
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 5.2 对照实现：前缀和闭式（仅用于对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

// 独立基准：用前缀和直接展开 mood_i = (sum_{k<=i}(a_k+b_k)) - 8*i
// 与标程的"滚动累加"是不同的代码路径，但数学等价。
int main()
{
	int n;
	cin>>n;
	vector<i64> pre(n+1,0);
	for(int i=1,a,b;i<=n;++i)
	{
		cin>>a>>b;
		pre[i]=pre[i-1]+a+b;
	}
	i64 ans=0;
	for(int i=1;i<=n;++i)
		ans+=pre[i]-8LL*i;
	cout<<ans<<'\n';
	return 0;
}
```

两版输出**逐字节相同**（已用 $300$ 组随机数据与官方样例确认）。暴力版的独立价值在于它完全不使用"昨日心情"这个状态量：它把 $m_t$ 写成前缀和减去常数，若标程的递推有初始化/累加次序之类掩蔽性错误，这里会立刻暴露。

### 5.3 易错点清单

- **只输出最后一天** $\Rightarrow$ 样例会给出 $-4$，而正确值是 $-2$。
- **在 0 处截断心情** $\Rightarrow$ 样例给出 $4$，错（引理 3）。
- **把"和"误读成"平均"或"最大值"** $\Rightarrow$ 语义错误，题面无此要求。
- **`cout<<ans<<endl;`** 违反本项目风格，一律用 `'\n'`。
