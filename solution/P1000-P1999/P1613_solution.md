# P1613 跑路

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给一张 $n$ 个点、$m$ 条边的**有向图**，每条边长 $1$ 千米。
小 A 的跑路器每秒钟可以跑 $2^k$ 千米（$k$ 为非负整数，每秒可自选）。
他每秒都在图上沿着边走，**每秒走过的总长必须是 $2$ 的幂**，求从 $1$ 号点到 $n$ 号点的最少秒数。

换个说法：把一条长度为 $L$ 的行走切成若干段，第 $i$ 段长度是 $2^{k_i}$，秒数就是段数。

### 输入输出格式

- **输入格式**：第一行 $n,m$；随后 $m$ 行，每行 $u,v$ 表示一条 $u\to v$ 的有向边。
- **输出格式**：一行一个整数，最少秒数。
- **数据规模**：$2\le n\le50$，$m\le10^4$，最优解路径长度 $\le2^{31}-1$，保证 $1$ 可达 $n$。

### 关键约束分析

1. $n\le50$ 极小，$\mathcal{O}(n^3)$ 甚至 $\mathcal{O}(n^3\log V)$ 都完全放得下（$50^3=1.25\times10^5$），所以可以放心用 Floyd / 矩阵式倍增。
2. 路径长度可达 $2^{31}-1$，但**点数只有 $50$**，说明最优解一定大量依赖"绕圈"和"一次性长跳"，不能按长度 DP（状态装不下 $2^{31}$）。
3. 输入可能有**自环**（样例解释里就出现了 $1\to1$）与重边，自环正好是"凑长度"的工具，必须当作合法边处理。
4. 边权为 $1$ 意味着"走 $2^k$ 条边"就是"长度 $2^k$"，秒与边数的对应关系非常干净。
5. 长度上界 $2^{31}-1$ 提示最高只需 $k\le30$，倍增层数取 $31\sim32$ 即可。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：暴力为什么不行

最直接的想法是"按长度 DP"：$g[L][v]$ 表示走 $L$ 条边能否到 $v$。但 $L$ 可达 $2^{31}$，数组开不下；而且每一秒的跨度不是 $1$，是按 $2$ 的幂跳的，状态还得记"这一秒已经走了多少"，更不可能。

换个问法：**到底什么决定了秒数？** 是"把整条行走切成几段 2 的幂"。所以关键信息不是"走了多长"，而是"从 $i$ 到 $j$ 是否存在一条长度恰好 $2^k$ 的行走"。

### 第二步：倍增预处理"恰好 $2^k$ 步可达"

**定义**：$f_k(i,j)=1$ 表示存在一条从 $i$ 到 $j$、长度**恰好** $2^k$ 的行走（允许重复经过点）。

**引理 1（倍增递推）**：$f_k(i,j)=1$ 当且仅当存在 $t$ 使 $f_{k-1}(i,t)=f_{k-1}(t,j)=1$。

*证明*：长度 $2^k$ 的行走可以在第 $2^{k-1}$ 步处切开，前半段是从 $i$ 到某个 $t$ 的长度 $2^{k-1}$ 行走，后半段是从 $t$ 到 $j$ 的同长行走。反过来，两段长度 $2^{k-1}$ 的行走首尾相接，就是一条长度 $2^k$ 的行走。$\square$

这个递推就是"布尔矩阵乘法"，$\mathcal{O}(n^3\log V)$ 一次算完全部层。

### 第三步：把"一秒"抽象成一条边

现在构造一张新图 $G'$：若存在 $k$ 使 $f_k(i,j)=1$，就在 $G'$ 中连一条 $i\to j$ 的边，权为 $1$ 秒。

**引理 2（方案与路径的对应）**：原问题的一个合法方案，与 $G'$ 中从 $1$ 到 $n$ 的一条路径一一对应，且方案的秒数等于路径的边数。

*证明*：
（方案 $\to$ 路径）方案的每一秒是一段长度 $2^k$ 的行走，由定义 $f_k$ 为真，故对应 $G'$ 的一条边；把这些边串起来就是从 $1$ 到 $n$ 的路径，边数即秒数。
（路径 $\to$ 方案）$G'$ 的每条边都有某个 $k$ 及对应的长度 $2^k$ 行走，把路径上各边对应的行走依次拼接，就是一条合法方案，秒数等于边数。$\square$

**引理 3（答案 = 最短路）**：答案是 $G'$ 中 $1\to n$ 的最短路边数。

*证明*：由引理 2，方案集合与路径集合一一对应且秒数 = 边数，故最小秒数 = 最短路边数。$\square$

所以只要求 $G'$ 的最短路。$G'$ 边权全为 $1$，用 Floyd（或 BFS）都行；因为 $n$ 小、点可能重复、直接 Floyd 最省事。

**（对拍暴力所用的等价刻画）** 对一条长度固定的行走而言，把它切成 $t$ 段等价于把 $L$ 写成 $t$ 个 $2$ 的幂之和；而 $L$ 能写成 $t$ 个 $2$ 的幂之和，当且仅当 $\operatorname{popcount}(L)\le t\le L$。所以这条行走最少需要 $\operatorname{popcount}(L)$ 秒，答案也等于
$$\min\{\operatorname{popcount}(L)\mid \text{存在一条从 }1\text{ 到 }n\text{ 的长度为 }L\text{ 的行走}\}.$$
这条刻画与"倍增 + 最短路"是两条完全独立的思路，Part 5 的随机对拍就用它当暴力。

### 第四步：为什么"恰好 $2^k$ 步"必须允许绕圈

**引理 4（绕圈是必要的）**：只考虑简单路径会得到错误答案。

*证明（反例）*：设图为 $1\to1$（自环）、$1\to2$、$2\to3$、$3\to4$。从 $1$ 到 $4$ 的简单路径长度是 $3$，需要 $2+1$ 两秒；而行走 $1\to1\to2\to3\to4$ 长度 $4=2^2$，只要一秒。$\square$

这正是题面样例解释里写"$1\to1\to2\to3\to4$，总路径长度为 $4$ 千米，直接使用一次跑路器即可"的原因。倍增递推天然允许重复点（它就是"关系复合"，不检查访问标记），所以自动覆盖了这种情形。

### 第五步：层数与上界

**引理 5（层数足够）**：只需 $k\le30$。

*证明*：任一段长度 $2^k\le$ 总长 $\le2^{31}-1<2^{31}$，故 $k\le30$。取 $k=0..31$（多算一层 $2^{31}$ 不影响正确性，因为那样长度的行走根本不存在）。$\square$

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 一秒 = 长度恰为 $2^k$ 的行走，问题的原子单位是"恰好 $2^k$ 步可达"。
- `consider easier version` — 若每步只能走 $1$ 条边，答案就是普通最短路；本题只是把"步"换成 $2$ 的幂。
- `classic problem solution` — 倍增/布尔矩阵快速幂求出 $f_k(i,j)$，把"一秒能到哪"预处理成一张稀疏的"秒图"。
- `reduce to easier problem` — 在秒图上跑 Floyd 求最短路，把"带幂次跳跃的最短路"降成"单位边权最短路"。
- `allow repeated vertices` — 用关系复合（不用 vis）而不是简单路径，才能覆盖"绕圈凑长度"的情形。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $n,m$ | `n,m` | 点数、边数 |
| $f_k(i,j)$ | `f[k][i][j]` | $i$ 能否走**恰好** $2^k$ 条边到 $j$，`bool`，初值全 `false`，输入边置 `f[0][u][v]=true` |
| $G'$ 的边权 | `dis[i][j]` | 秒图上的距离（`int`），初值 `inf`、对角线 $0$；存在 $f_k(i,j)$ 时置 $1$ |
| $k$ | `k` | 倍增层数，$0..31$ |
| — | `t` | 倍增复合的中间点 |
| — | `u,v` | 读入的边端点（已 `--`，$0$ 基） |

### 算法步骤

1. 读入 $n,m$；`dis` 初始化为 `inf`，`dis[i][i]=0`。
2. 读每条边 $(u,v)$：`f[0][u][v]=true`，`dis[u][v]=min(dis[u][v],1)`（自环时保留 `dis[u][u]=0`）。
3. 对 $k=1..31$：三重枚举 $i,t,j$，若 `f[k-1][i][t] && f[k-1][t][j]` 则 `f[k][i][j]=true`。
4. 对每个 $k,i,j$，若 `f[k][i][j]` 则 `dis[i][j]=min(dis[i][j],1)`。
5. Floyd：`dis[i][j]=min(dis[i][j],dis[i][k]+dis[k][j])`。
6. 输出 `dis[0][n-1]`。

### 复杂度分析

- **时间复杂度**：倍增 $\mathcal{O}(32n^3)$，合并秒图 $\mathcal{O}(32n^3)$（可并入上一步），Floyd $\mathcal{O}(n^3)$；$n=50$ 时总计约 $4\times10^6$。
- **空间复杂度**：$\mathcal{O}(32n^2)$ 的 `bool` 表（约 $80$ KB）+ $\mathcal{O}(n^2)$ 距离矩阵。

### 正确性验证

- 引理 1 给出 $f_k$ 的精确递推，无需任何"路径简单"的假设。
- 引理 2、3 把"最少秒数"严格翻译成秒图最短路，Floyd 在这个单位边权图上正确。
- 引理 4 说明必须允许重复点，代码中没有任何访问标记，符合要求。
- 引理 5 说明 $32$ 层足够；即使某层全空也不影响结果。
- 数值范围：`dis` 最大约 $31$，`inf` 取 $10^9$，`dis[i][k]+dis[k][j]` 最大 $2\times10^9<2^{31}-1$，不溢出。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1613 跑路
// https://www.luogu.com.cn/problem/P1613
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{55},lg{32};        // n<=50, 2^30 足够覆盖 2^31-1
constexpr int inf{1'000'000'000};

int n,m;
bool f[lg][mxn][mxn];                // f[k][i][j]: i 走恰好 2^k 条边可达 j
int dis[mxn][mxn];                   // 以"秒"为单位的最短路

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
	{
		fill_n(dis[i],n,inf);
		dis[i][i]=0;
	}
	for(int i=0,u,v;i<m;++i)
	{
		cin>>u>>v;
		--u;--v;
		f[0][u][v]=true;
		dis[u][v]=min(dis[u][v],1);   // 自环时不要破坏 dis[i][i]=0
	}
	for(int k=1;k<lg;++k)
		for(int i=0;i<n;++i)
			for(int t=0;t<n;++t)
				if(f[k-1][i][t])
					for(int j=0;j<n;++j)
						if(f[k-1][t][j])
							f[k][i][j]=true;
	for(int k=0;k<lg;++k)
		for(int i=0;i<n;++i)
			for(int j=0;j<n;++j)
				if(f[k][i][j])
					dis[i][j]=min(dis[i][j],1);
	for(int k=0;k<n;++k)
		for(int i=0;i<n;++i)
			for(int j=0;j<n;++j)
				if(dis[i][k]+dis[k][j]<dis[i][j])
					dis[i][j]=dis[i][k]+dis[k][j];

	cout<<dis[0][n-1]<<'\n';
	return 0;
}
```

### 易错点

1. **把"恰好 $2^k$ 步"写成"至多"**：若允许"至多"，$f_{k}$ 的递推会把长度不是 $2^k$ 的行走也算进来，答案偏小。必须严格"恰好"。
2. **忘记自环**：样例就依赖 $1\to1$，读边时不能因为 $u=v$ 跳过；同时注意 `dis[u][v]=min(dis[u][v],1)` 而不是直接赋值，否则 `dis[i][i]` 会被写成 $1$。
3. **层数不够**：$k$ 只取到 $20$ 时，长度 $2^{25}$ 的跳法识别不出来，答案偏大。
4. **在 $f$ 上跑 Floyd 而不建秒图**：必须在"存在某个 $k$"后才加权为 $1$ 的边，再对秒图做最短路。
5. **用 BFS 直接扫原图**：原图边权是"步长"，不是"秒"，直接 BFS 求的是边数而非秒数。
