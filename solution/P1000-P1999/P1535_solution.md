# P1535 [USACO08MAR] Cow Travelling S

> 标签：动态规划 DP · 记忆化搜索 · USACO · 难度：普及/提高-
> 本地题面：`P1535.md`（$2\le N,M\le 100$，$0<T\le 15$，网格含 `*` 障碍，起点/终点由最后一行给出）。
> 验证：`appendix/P1535/` 对拍 300 组随机用例 + 官方样例 + 边界 + 最坏 $100\times100$ 全平地 $T=15$（耗时 $0.0050$ s）全部 PASS。

## 1. 重新读题

**问题重述（人话版）**

在 $N\times M$ 的网格里，`. ` 是能走的地、`*` 是树（不能走）。奶牛从 $(R_1,C_1)$ 出发，**每一秒必须水平或竖直走一格**（不许原地不动），全程恰好走 $T$ 秒，中途不能踩到树、不能出界。问：**恰好 $T$ 秒后落在 $(R_2,C_2)$ 的不同走法有多少条？**

**题面里容易漏掉的条款**

1. **"每一秒必走且必动"** $\Rightarrow$ 不存在"停在原地观望"的转移，每步一定是四邻之一。这决定了递推里**不能有任何"自环"**项。
2. **"$T$ 秒内是否经过"不重要，只看第 $T$ 秒在哪** $\Rightarrow$ 计数对象是"长度恰为 $T$ 的行走序列"，允许中途反复经过同一格（往返是合法的）。
3. **$\ast$ 是硬障碍** $\Rightarrow$ 任何时刻都不能把树格当作落脚点，起点/终点按题意也都是活的草地。
4. **计数会很大** $\Rightarrow$ 中途"绕圈"多，但上界只有 $4^T\le 4^{15}\approx1.07\times10^9$，用 `int` 也够（本实现为稳妥用 `long long`）。

**数据范围与规模感受**

$$2\le N,M\le 100,\qquad 0<T\le 15 .$$

$T$ 极小是本题的题眼：它提示我们把"出发到现在过了几秒"当作 DP 的一维，做 $T+1$ 层的**分层网格 DP**，复杂度 $O(NMT)$，最大 $100\times100\times15=1.5\times10^5$ 量级，完全宽裕；而"枚举所有路径"是 $O(4^T)$，$T=15$ 时必挂，只能当小数据基准。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"数路径"变成"数状态"

先问：路径的"身份"由什么决定？由**每一秒站在哪个格子**这一串序列决定。于是最自然的入手点是给每个"中间时刻"配上位置。

**引理 1（必须移动 $\Rightarrow$ 只依赖四邻）**

任意合法方案在第 $s$ 秒（$1\le s\le T$）的位置 $(i,j)$ 与第 $s-1$ 秒的位置 $(i',j')$ 必满足 $|i-i'|+|j-j'|=1$，且 $(i,j)$ 可走、在界内。

**证明**：题面规定"每一秒内，奶牛会水平或垂直地移动 1 单位距离"，即每秒位移的曼哈顿长度恰为 1，故 $|i-i'|+|j-j'|=1$；又"不会在某秒内停在上一秒所在的点"排除了 $0$ 位移，综合得恰好 1。落点必须可走、在界内由"不能走到树"与"不会走出草地"直接给出。$\blacksquare$

> 这条把"连续行走"彻底离散化：一条路径 = 一个满足"相邻两秒曼哈顿距离恰 1"的时间序列。接下来只要数这样的序列即可。

### 2.2 一个更简单的版本：无障碍会怎样

先把障碍拿掉，得到全平地的简化版，看看能捞出什么不变式。

**引理 2（奇偶不变式）**

任意时刻 $s$，位置 $(i,j)$ 的可达性受奇偶限制：若 $(|i-R_1|+|j-C_1|)\not\equiv s\pmod 2$，则第 $s$ 秒**不可能**到达 $(i,j)$。

**证明**：每移动一格，坐标和的奇偶性 $i+j$ 必翻转（因为恰有一维 $\pm1$）。从出发位置起，走 $s$ 步后 $\operatorname{parity}(i+j)=\operatorname{parity}(R_1+C_1)+s\bmod 2$。而曼哈顿距离 $|i-R_1|+|j-C_1|$ 与 $i+j-(R_1+C_1)$ 同奇偶，故若 $(|i-R_1|+|j-C_1|)$ 与 $s$ 奇偶不同，则该状态不可达。$\blacksquare$

> 这条既是**自检**（结果里若出现奇偶不符处非 0 必是 bug），也可做**剪枝**。注意它只是必要条件，不是充分条件（还有 $T$ 要 $\ge$ 曼哈顿距离这一类下界约束，见 §2.5 失败 2）。本题数据小，DP 本身已足够，奇偶只用来验证。

### 2.3 经典归约：分层网格 DP（或等价的记忆化搜索）

现在把障碍加回来。既然路径由"逐秒位置"构成，就让状态 = (第几秒, 在哪个格子)。

定义 $\mathrm{cnt}[s][i][j]$ = "恰好 $s$ 秒后位于 $(i,j)$ 的合法方案数"。

**引理 3（递推式）**

$$\mathrm{cnt}[s][i][j]=\sum_{(i',j')\sim(i,j)} \mathrm{cnt}[s-1][i'][j'],$$

其中求和遍历 $(i,j)$ 的、可走且在界内的四邻格 $(i',j')$；基例 $\mathrm{cnt}[0][R_1][C_1]=1$，其余为 $0$。

**证明**：建立映射 $f$：把"$s$ 秒后在 $(i,j)$ 的合法方案"对应到"$s-1$ 秒后在某个四邻 $(i',j')$ 的合法方案中去掉第 $s$ 步"。由引理 1，最后一步的来路 $(i',j')$ 是一格"可走且在界内的四邻"，故 $f$ 的像落在可枚举的邻格里，且**逆映射**存在：给定 $s-1$ 秒末在 $(i',j')$ 的方案，若 $(i,j)$ 是可走且在界内的邻格，则追加一步 $i'\to i$ 得到一条 $s$ 秒末在 $(i,j)$ 的合法方案（该步合法：位移恰 1；终点可走）。因此这是 $s$ 秒方案集合与"邻格来源方案集合"之间的**双射**，对来源邻格求和即得。此外两个不同的邻格来源不可能产生同一条 $s$ 秒方案（最后一步不同），故求和无重复计数。$\blacksquare$

> 这与经典的"网格路径计数"完全同构，只是多了一维时间，且"不重不漏"由**最后一步的双射**保证。

### 2.4 一个必须守住的实现细节：分层必须用两个数组

`cnt` 的转移里，右端全部是第 $s-1$ 层的值，左端是第 $s$ 层的值。如果只用一个二维数组 `cur` 原地更新，会发生"同一秒内连续移动多次"的错误。

**引理 4（单数组原地更新会多算）**

设无阻碍的 $1\times$ 直线（可走向左右两个邻格，端点按界理解）。若在**同一层**里"读一个格子就把它的值加进邻格"地原地推进，则会把"一秒走多格"的序列也计入，得到偏大的错误方案数。

**证明（举最小反例）**：取三个格子 $0,1,2$（相当于 $1$ 维，$T=2$，起点 $0$）。真实的长 2 行走方案到 $2$ 的只有 $0\to1\to2$ 一条，故 $\mathrm{cnt}[2][2]=1$。
- 原地一层处理：初始 `cur[0]=1`。处理格子 $0$ 时把 `cur[1]+=cur[0]=1`（此刻 `cur[1]=1` 已属**新层**）；接着处理格子 $1$，此时读到的是刚被改过的 `cur[1]=1`，于是 `cur[2]+=1`，也把 `cur[1]` 反向加到 `cur[0]`。结果 `cur[2]` 变成 1 甚至更多，而且这一"层"里 $0\to1\to2$ 的移动被当作**一秒**内完成，等价于让奶牛一秒瞬移多格。$\blacksquare$
- 正确做法：用 `nxt` 记录本层结果、每层开头 `nxt` 清零，处理完把 `nxt` 拷回 `cur`（或直接 3 维 `cnt[s][i][j]`）。本题只要两层滚动即可。

> 这与背包里"内层方向写错会变成完全背包"是同一类坑：**读旧值、写新值**时必须把两个时刻分开。

### 2.5 剖析失败思路

**失败 1：丢转移（只走右/下）或允许停留。** 题面要求四方向、"必动"。若只留两个方向，等价于把可行路径集砍掉一半以上；若加"停留"转移，则会在 $\mathrm{cnt}$ 里凭空多出"原地不动"的路径（违反引理 1，样例中绕过树的唯一路径会因此被算成很多条）。
**失败 2：只做奇偶剪枝当判据。** 引理 2 只是**必要**条件。反例：取 $2\times2$ 全平地、$T=1$、起点 $(1,1)$、终点 $(2,2)$：$(2,2)$ 的曼哈顿距离为 $2$，与 $T=1$ 奇偶不符，输出 $0$（实测确实为 $0$）；但如果反过来只看"奇偶相符就可达"也不对——例如终点被切短了距离却撞树，DP 给出 $0$ 才是对的。**结论：奇偶只用于验证/剪枝，不能当作计数判据。**

### 2.6 边界与溢出体检

- $T$ 最小为 1，最大 15；$N,M\ge2$，不存在退化成一维的情形。
- $r_1,c_1,r_2,c_2$ 读入是 1-based，内部立即 `--` 成 0-based。
- 计数上界 $4^{T}\le4^{15}<2^{31}$，`i64` 稳。

## 3. 模式总结（Pattern Summary）

**模式名：带"必动"约束的分层网格路径计数。**

按实际思考顺序：

- **explore its property** — 路径身份 = 逐秒位置序列；"每步必动"等价于相邻两秒曼哈顿距离恰 1（引理 1）。
- **consider easier version** — 去掉障碍看可达性，得到奇偶不变式（引理 2），但它只是必要条件。
- **classic problem solution** — 就地平网格一样按"时间"分层做 DP：$\mathrm{cnt}[s][i][j]=$ 四邻上一层之和；或等价的记忆化搜索（引理 3）。
- **prove by bijection** — 用"最后一步的双射"证明递推不重不漏（引理 3）。
- **enforce the 'must move' constraint structurally** — 递推里只给四邻、**不设自环项**，从而天然满足"必动"。
- **layer separation** — 用两层滚动数组，禁止同层原地更新（引理 4 反例）。
- **use an invariant for verification** — 奇偶不变式（引理 2）用作结果自检/剪枝，而非判据。

**一句话记忆**：数"恰好 T 步的走法"，就按时间滚 $T$ 层，每层用上一层四邻求和，别在同一层里原地改。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| `n`,`m` | `int` | 网格行数、列数 | 读入 | 题面 $N,M$ |
| `t` | `int` | 秒数 $T$ | 读入 | 题面 |
| `g[i][j]` | `char[mxn][mxn]` | 地形：`.` 可走 / `*` 树 | 读入 | 0-based 行列 |
| `r1`,`c1`,`r2`,`c2` | `int` | 起点、终点（**0-based**） | 读入后 `--` | 题面 1-based 转换 |
| `cur[i][j]` | `i64[mxn][mxn]` | 第 $s$ 秒位于 $(i,j)$ 的方案数（当前层） | 仅 `cur[r1][c1]=1` | current layer |
| `nxt[i][j]` | `i64[mxn][mxn]` | 第 $s+1$ 秒的方案数（下一层临时） | 每层开头清零 | next layer |
| `dx`,`dy` | `int[4]` | 四方向增量 | 常量 `{-1,1,0,0}`/`{0,0,-1,1}` | direction |

### 4.2 编号步骤

1. `cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`；读入 `n,m,t` 与网格。
2. 读入 `r1,c1,r2,c2` 并 `--` 转成 0-based。
3. `cur[r1][c1]=1`（第 0 秒方案数）。
4. 对 $s=0..t-1$：
   4.1 把 `nxt` 全部清 `0`（引理 4，换层必须清零）。
   4.2 枚举每个有值的 `cur[i][j]`，对四个邻格 $(ni,nj)$：若在界内且 `g[ni][nj]!='*'`，则 `nxt[ni][nj]+=cur[i][j]`（引理 3，只到四邻＝必动）。
   4.3 把 `nxt` 拷回 `cur`。
5. 输出 `cur[r2][c2]`。

### 4.3 复杂度与验证状态

- 时间 $O(NMT)$；空间 $O(NM)$（两个二维数组）。
- **官方样例**：`4 5 6 / ...*. / ...*. / ..... / ..... / 1 3 1 5` $\to 1$ ✓。
- **随机对拍**：$300$ 组（$N,M\in[2,5]$，$T\in[1,7]$，含随机树、随机起终点）标程与 $O(4^T)$ 暴力 DFS **逐字节一致** ✓。
- **边界**：`2 2 1` 相邻一步 $\to 1$；`2 2 1` 对角（奇偶不符）$\to 0$；终点被树占 $\to 0$ ✓。
- **最坏规模计时**：$100\times100$ 全平地、$T=15$、$(1,1)\to(100,100)$（距离 $198>15$）$\to 0$，耗时 **$0.0050$ s**。
- 残余风险：若官方数据把树放在起点上，本实现仍会从起点起步（按题意起点为平地，不会发生）。

## 5. 示例代码

### 5.1 主解：分层网格 DP（标程）

```cpp
//
// 题目：P1535 [USACO08MAR] Cow Travelling S
// https://www.luogu.com.cn/problem/P1535
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};           // 行列 <=100 (+5 松弛)

int n,m,t;
char g[mxn][mxn];
i64 cur[mxn][mxn],nxt[mxn][mxn];
int dx[4]{-1,1,0,0},dy[4]{0,0,-1,1};

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>t;
	for(int i=0;i<n;++i)
		cin>>g[i];
	int r1,c1,r2,c2;
	cin>>r1>>c1>>r2>>c2;
	--r1;--c1;--r2;--c2;

	cur[r1][c1]=1;                 // 第 0 秒只在起点,方案数 1
	for(int s=0;s<t;++s)
	{
		for(int i=0;i<n;++i)
			for(int j=0;j<m;++j)
				nxt[i][j]=0;       // 换一秒必须清零,避免残留
		for(int i=0;i<n;++i)
			for(int j=0;j<m;++j)
			{
				if(!cur[i][j])
					continue;
				for(int d=0;d<4;++d)
				{
					int ni=i+dx[d],nj=j+dy[d];
					if(ni<0||ni>=n||nj<0||nj>=m||g[ni][nj]=='*')
						continue;
					nxt[ni][nj]+=cur[i][j];   // 每一步必移动:转移到四邻格
				}
			}
		for(int i=0;i<n;++i)
			for(int j=0;j<m;++j)
				cur[i][j]=nxt[i][j];
	}
	cout<<cur[r2][c2]<<'\n';       // 恰好 T 秒后落在终点的方案数
	return 0;
}
```

### 5.2 对照实现：$O(4^T)$ 暴力 DFS（仅用于对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

// 独立基准：直接枚举所有长度为 T 的行走序列(每步必动),数落在终点的条数。
int n,m,t,r2,c2;
char g[105][105];
i64 ans;
int dx[4]{-1,1,0,0},dy[4]{0,0,-1,1};

void dfs(int i,int j,int s)
{
	if(s==t)
	{
		if(i==r2&&j==c2)
			++ans;
		return;
	}
	for(int d=0;d<4;++d)
	{
		int ni=i+dx[d],nj=j+dy[d];
		if(ni<0||ni>=n||nj<0||nj>=m||g[ni][nj]=='*')
			continue;
		dfs(ni,nj,s+1);
	}
}

int main()
{
	cin>>n>>m>>t;
	for(int i=0;i<n;++i)
		cin>>g[i];
	int r1,c1;
	cin>>r1>>c1>>r2>>c2;
	--r1;--c1;--r2;--c2;
	dfs(r1,c1,0);
	cout<<ans<<'\n';
	return 0;
}
```

两版**输出逐字节相同**（$300$ 组随机 + 官方样例确认）。暴力版绕开了"分层 DP"的全部实现约定（无滚动、无清层、无方向数组复用），因此若标程在分层层数、清零或方向上有掩蔽性 bug，会立刻暴露；代价是 $O(4^T)$，$T\le7$ 才跑得动。

### 5.3 易错点清单

- **同一层里原地更新** $\Rightarrow$ 多算"一秒瞬移多格"的路径（引理 4）。
- **换层忘清零 `nxt`** $\Rightarrow$ 上一层残留被计入本层，答案偏大。
- **加了"停留"转移** $\Rightarrow$ 违反"必动"，答案偏大；题面明确不允许。
- **只走两个方向** $\Rightarrow$ 漏解。
- **起终点 1-based 忘 `--`** $\Rightarrow$ 越界或错位。
- **把奇偶不变式当判据** $\Rightarrow$ 它只是必要条件（§2.5 失败 2）。
- **`endl` 换行** $\Rightarrow$ 违反风格，用 `'\n'`。
