# P1941 [NOIP 2014 提高组] 飞扬的小鸟

## 1. 重新读题

### 1.1 问题重述（人话版）

小鸟从最左边 $x=0$ 出发，初始高度可以任取 $1\sim m$ 中的整数，点击次数为 $0$。之后它一格一格向右飞：从横坐标 $i$ 飞到 $i+1$ 时，

- 要么**点击若干次**（每次上升 $x_i$，可以点很多次，效果叠加，但高度到 $m$ 就封顶），点 $k\ge 1$ 次花 $k$ 次点击；
- 要么**一次都不点**，高度下降 $y_i$。

过程中高度必须满足 $1\le h\le m$：高度为 $0$ 或撞到管道都算失败。管道在横坐标 $p$ 处，缝隙是开区间 $(l,h)$，也就是**只有 $l<h'<h$ 的高度能穿过**（$h'=l$ 或 $h'=h$ 都算撞管）。

能飞到 $x=n$ 就成功，输出 `1` 和最少点击数；否则输出 `0` 和最多穿过的管道数。

### 1.2 关键约束与规模暗示

- $n\le 10^4$，$m\le 1000$，$k<n$，$0<x,y<m$，$0<p<n$，$l+1<h$。
- 状态空间是 $O(nm)=10^7$。这强烈暗示正解是 $O(nm)$ 的 DP。
- 若对每个状态再枚举「这一次点了几下」，复杂度变成 $O(nm^2)=10^{10}$，必死。所以必须把「点击次数」这一维用背包的技巧压掉。
- 30%/50% 的子任务保证最优解每次最多点 $3$ 下，那是在给「枚举点击数」的暴力留活路；满分数据取消了这个保证，正是逼你发现上升其实是无界背包。

## 2. 思维链（Chain-of-thought）

### 2.1 先把游戏翻译成一张分层图

把「横坐标 $i$、高度 $h$」看成一个状态 $(i,h)$，$i=0,1,\dots,n$，$h=1,\dots,m$。从 $(i,h)$ 到下一列 $(i+1,\cdot)$ 只有两类出边：

- **上升边**：对任意 $k\ge 1$，走到 $\bigl(i+1,\ \min(m,h+kx_i)\bigr)$，代价 $k$；
- **下降边**：走到 $(i+1,\ h-y_i)$，代价 $0$，且要求 $h-y_i\ge 1$。

管道在横坐标 $p$ 上相当于把第 $p$ 层里 $h\le l$ 或 $h\ge h_{\text{pipe}}$ 的状态全部删掉。起点集合是 $\{(0,h):1\le h\le m\}$，代价都是 $0$。

**引理 1（最优子结构）**：设 $f_i(h)$ 表示到达状态 $(i,h)$ 的最小点击数，则
$$
f_{i+1}(h)=\min\Bigl(\ \min_{k\ge 1}\{f_i(h')+k:\ \min(m,h'+kx_i)=h\},\ \ f_i(h+y_i)\ \Bigr),
$$
其中第二项在 $h+y_i>m$ 时不存在，之后再把不合法高度置为 $+\infty$。

**证明**：任何一条到达 $(i+1,h)$ 的路径，最后一步要么是若干次点击、要么是不点击，二者必居其一，且此前的历史只影响「从 $(i,h')$ 出发时的代价」。把历史部分换成最小值 $f_i(h')$ 不会变差，故上式取到最优。不同路径的点击序列可以逐段拼接，拼接后仍然合法，说明该递推不会漏掉任何可行方案；反过来每一项都对应一条真实路径，也不会算多。$\square$

于是问题变成：按 $i$ 逐层递推，每层做一次「上升（无界）+ 下降（一次）」的转移。

### 2.2 先写暴力，看到瓶颈

最直接地照抄引理 1：对每个目标高度 $h$，枚举 $h'$ 与点击数 $k$。由于 $kx_i$ 至多把高度推到 $m$，$k\le \lceil m/x_i\rceil\le m$，所以单层是 $O(m^2)$，总共 $O(nm^2)$。$n=10^4,m=1000$ 时是 $10^{10}$，超时。

暴力的浪费在于：从同一个 $h'$ 出发，「点 $k$ 下」和「点 $k+1$ 下」之间只差一次点击，却被当成两个独立选项反复枚举。这正是**完全背包**（每种物品可用无限次，每次代价相同）的形状。

### 2.3 上升部分 = 完全背包

先只考虑上升，定义 $up(h)$ 为「本层结束时高度为 $h$，且这一步至少点了一次」的最小点击代价。那么

$$
up(h)=\min\bigl(f_i(h-x_i),\ up(h-x_i)\bigr)+1\qquad(h<m),
$$

直观上：要么这一步是**第一次**点击（从本层的 $f_i(h-x_i)$ 出发），要么前面已经点过（从 $up(h-x_i)$ 再点一下）。对 $h=m$ 还要考虑「一步从任意 $h'\ge m-x_i$ 直接顶到 $m$」。

**引理 2（按高度升序做一次扫描即得 $up$）**：执行

```
for h = 1..m:
    if f_i(h) 有限:  up[min(m,h+x_i)] = min(up[min(m,h+x_i)], f_i(h)+1)
    if up(h)  有限:  up[min(m,h+x_i)] = min(up[min(m,h+x_i)], up(h)+1)
```

（$up$ 初值全为 $+\infty$）后，$up(h)$ 恰为「本层结束高度为 $h$ 且至少点一次」的最小代价。

**证明**：对目标高度 $h$ 归纳，同时注意上升只会把高度变大（或封顶到 $m$），所以所有对 $up(h)$ 的贡献都来自更小的高度。

- 若 $h<m$：能一步到达 $h$ 的前驱高度只能是 $h-x_i$（若 $h-x_i\ge 1$）。循环走到 $h-x_i$ 时，已经把 $\min(f_i(h-x_i),up(h-x_i))+1$ 写进 $up(h)$；由归纳假设，$up(h-x_i)$ 已是「至少点过一次到 $h-x_i$」的最优值，而 $f_i(h-x_i)$ 是「还没点」的最优值，两者取 $\min$ 再加一，正好覆盖「第一次点」与「继续点」两种情形。没有别的前驱。
- 若 $h=m$：前驱是任意 $h'\ge m-x_i$（含 $h'=m$ 的原地封顶）。每个这样的 $h'$ 在循环中都被处理，并把它到 $m$ 的一条候选写进 $up(m)$；反过来每个写入 $up(m)$ 的值都对应真实的一次点击。取最小即最优。
- 循环顺序保证了处理 $h'$ 时 $up(h')$ 已定稿（它只依赖更小的下标），因此不会用未完成的值。

$\square$

**为什么不能把 $f_i$ 直接拷进 $up$ 再统一松弛？** 如果把 $up$ 初始化成 $f_i$，那么 $up(h)$ 会混入「本层还没点过、高度仍是 $h$」的非法语义；再对它做 `up[h+x]` 相当于「在原地先待着再点」，虽然对上升本身结果碰巧相同，但一旦和下降混在一起就会出错（见引理 3）。所以这里坚持 $up$ 单独开数组、初值 $+\infty$。

### 2.4 下降只能一次，且不能和上升混用

**引理 3（下降必须独立计算，不能进入无界背包）**：一步之内，点击与不点击是互斥的；因此下降后的状态不能继续参与本层的上升松弛。

**证明**：题面规定每个单位时间「如果点击屏幕，小鸟就会上升 $x$；如果不点击屏幕，小鸟就会下降 $y$」。这两件事是同一个单位时间内的两个互斥分支，不存在「先掉下去再点一下」或「先点再掉」的合法动作。若把下降结果写进同一个被上升松弛使用的数组，程序就会允许一条边「下降 $y$ 再上升 $x$」（花费 $1$），而这条边在真实规则里不存在。$\square$

所以下降单独算：
$$
down(h)=f_i(h+y_i)\quad(h+y_i\le m),
$$
再取 $g(h)=\min(up(h),down(h))$ 作为本层结束状态。

### 2.5 封顶、死亡与管道

- **封顶**：从高度 $h'$ 点一下到 $\min(m,h'+x_i)$，是因为高度到 $m$ 之后「无法再上升」，继续点也停在 $m$。这正好用 $\min$ 表达；封顶后再点一次是 $up(m)+1$，只会更差，不会影响最小值。
- **死亡**：下降要求 $h+y_i\le m$ 且落点 $h\ge 1$。落点 $0$ 直接不生成状态；上升永远不会到 $0$。
- **管道**：第 $p$ 层过滤时，把 $h\le l$ 或 $h\ge h_{\text{pipe}}$ 的状态设为 $+\infty$。

**引理 4（管道过滤的正确性）**：过滤后剩下的状态恰好是「能穿过该管道缝隙」的状态。

**证明**：管道缝隙是开区间 $(l,h_{\text{pipe}})$，题面说高度等于边界也算碰到管道。故合法高度集合为 $\{h:l<h<h_{\text{pipe}}\}$，其补集正是 $h\le l$ 或 $h\ge h_{\text{pipe}}$。逐个置 $+\infty$ 就等价于只保留合法集合。$\square$

### 2.6 失败时怎么数「最多通过的管道」

从 $x=0$ 开始逐层推进。如果某一层 $i+1$ 过滤后所有高度都是 $+\infty$，说明小鸟死在到达 $x=i+1$ 之前（或撞在 $i+1$ 的管道上），它能穿过的管道只能是横坐标 $\le i$ 的那些。

**引理 5（失败计数）**：若第一次在 $x=i+1$ 处全部状态不可达，则答案为「横坐标 $\le i$ 的管道个数」。

**证明**：能到达 $x=i+1$ 是穿过位置 $i+1$ 管道的必要条件（管道就在 $x=i+1$，必须经过该横坐标）。既然 $x=i+1$ 不可达，位置 $i+1$ 及其右侧的管道都必然没被穿过。而所有横坐标 $\le i$ 的管道，在小鸟到达 $x=i$ 时已经全部经过（每一层都做过合法性过滤，能活到 $x=i$ 就说明每一层都穿过了），所以这些管道都被成功穿过。因此最大通过数恰为前者。$\square$

实现上维护一个 `passed` 计数器：每成功完成一层、且该层有管道，就 `++passed`。

### 2.7 复杂度

每层对高度做常数次线性扫描，$O(m)$；共 $n$ 层，时间 $O(nm)$，空间 $O(m+n)$（管道数组按横坐标存）。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 把「点击/不点击」翻译成分层图上两类边，状态 $(i,h)$。
- **consider easier version** — 先不管管道与封顶，得到 $f_{i+1}$ 的递推式。
- **fail the naive way** — 枚举点击次数 $k$ 得 $O(nm^2)$，瓶颈是 $k$ 与 $k+1$ 只差一次点击。
- **classic problem solution** — 上升是一个完全背包，按高度升序扫描一次即可，$O(m)$。
- **explore its property** — 下降与上升互斥，必须单独算 $down$，不能混进背包数组。
- **classic problem solution** — 逐层过滤管道区间；第一次全灭时用已过管道数作为失败答案。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n,m,k` | `int` | 界面长度、高度、管道数 | 读入 | 规模 |
| `x[i]` | `int [10005]` | 在横坐标 $i$ 点击一次上升量 | 读入 | up |
| `y[i]` | `int [10005]` | 在横坐标 $i$ 不点击下降量 | 读入 | down |
| `low[p]` | `int [10005]` | 位置 $p$ 管道下边沿 $l$；无管道为 $0$ | 0 | 缝隙下界 |
| `high[p]` | `int [10005]` | 位置 $p$ 管道上边沿；无管道为 $m+1$ | $m+1$ | 缝隙上界 |
| `has[p]` | `bool [10005]` | 位置 $p$ 是否有管道 | false | 存在标记 |
| `f[h]` | `int [1005]` | 到达当前层高度 $h$ 的最小点击数 | 第 0 层全 0 | from |
| `up[h]` | `int [1005]` | 本层「至少点一次」到达 $h$ 的最小代价 | $+\infty$ | rise |
| `dn[h]` | `int [1005]` | 本层「不点击」到达 $h$ 的最小代价 | $+\infty$ | fall |
| `g[h]` | `int [1005]` | 本层合并并过滤后的状态 | — | next |
| `passed` | `int` | 已成功穿过的管道数 | 0 | 失败答案 |

### 4.2 算法步骤

1. 读入 $n,m,k$ 与所有 $x_i,y_i$；把 `low[0..n]` 置 $0$、`high[0..n]` 置 $m+1$、`has` 置 false，再读入 $k$ 个管道填入 `low/high/has`。
2. 初始 $f[h]=0\ (1\le h\le m)$，表示 $x=0$ 处任意高度、$0$ 次点击。
3. 对 $i=0,1,\dots,n-1$：
   1. `up`、`dn` 全部置 $+\infty$。
   2. 按 $h=1\to m$ 升序：若 `f[h]` 有限，松弛 `up[min(m,h+x[i])]←f[h]+1`；若 `up[h]` 有限，松弛 `up[min(m,h+x[i])]←up[h]+1`；若 `h+y[i]≤m`，令 `dn[h]=f[h+y[i]]`。
   3. 令 $p=i+1$，对每个 $h$：$g[h]=\min(up[h],dn[h])$，若 $h\le low[p]$ 或 $h\ge high[p]$ 则置 $+\infty$。
   4. 若所有 $g[h]=+\infty$：输出 `0` 与 `passed`，结束。
   5. 否则若 `has[p]` 为真，`++passed`；再把 $g$ 拷回 $f$。
4. 全部 $n$ 层完成：输出 `1` 与 $\min_{1\le h\le m} f[h]$。

### 4.3 复杂度分析

- **时间**：每层 $O(m)$，共 $n$ 层，$O(nm)\le 10^7$。
- **空间**：$O(m+n)$，四个高度数组加若干 $n$ 长数组。

## 5. 示例代码

```cpp
//
// 题目：P1941 [NOIP 2014 提高组] 飞扬的小鸟
// https://www.luogu.com.cn/problem/P1941
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005},mxm{1005};
constexpr int inf{1145141919};

int n,m,k;
int x[mxn],y[mxn];
int low[mxn],high[mxn];
bool has[mxn];
int f[mxm],g[mxm],up[mxm],dn[mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>k;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];

	for(int i=0;i<=n;++i)
	{
		low[i]=0;
		high[i]=m+1;
	}
	for(int i=0,p,l,h;i<k;++i)
	{
		cin>>p>>l>>h;
		low[p]=l;
		high[p]=h;
		has[p]=true;
	}

	for(int h=1;h<=m;++h)
		f[h]=0;
	int passed{0};

	for(int i=0;i<n;++i)
	{
		fill_n(up,m+1,inf);
		fill_n(dn,m+1,inf);

		for(int h=1;h<=m;++h)
		{
			int nh=min(m,h+x[i]);
			if(f[h]<inf)
				up[nh]=min(up[nh],f[h]+1);
			if(up[h]<inf)
				up[nh]=min(up[nh],up[h]+1);
			if(h+y[i]<=m)
				dn[h]=f[h+y[i]];
		}

		int p=i+1;
		bool alive{false};
		for(int h=1;h<=m;++h)
		{
			int v=min(up[h],dn[h]);
			if(h<=low[p]||h>=high[p])
				v=inf;
			g[h]=v;
			if(v<inf)
				alive=true;
		}

		if(!alive)
		{
			cout<<0<<'\n'<<passed<<'\n';
			return 0;
		}
		if(has[p])
			++passed;
		copy(g+1,g+m+1,f+1);
	}

	int ans{inf};
	for(int h=1;h<=m;++h)
		ans=min(ans,f[h]);
	cout<<1<<'\n'<<ans<<'\n';
	return 0;
}
```
