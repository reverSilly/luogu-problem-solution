# P1003 [NOIP 2011 提高组] 铺地毯 · 题解

## 1. 解题思路——像人一样思考

### 1.1 先看题在说什么

题目描述了一个经典的"地毯覆盖"场景。有 $n$ 张矩形地毯，按编号从小到大的顺序铺上去（后铺的盖住先铺的）。最后问某个点 $(x,y)$ 最上面那张地毯的编号。

这不就是盖被子嘛——你一层一层往上叠，最后盖在最上面的那层才是你实际摸到的。

### 1.2 从最朴素的想法出发

最直接的想法：模拟铺地毯的过程。每次铺一张地毯，就把这块矩形区域内所有点的"当前最上面地毯编号"更新。最后查 $(x,y)$。

但问题是——坐标范围是 $0 \le a,b,g,k \le 10^5$，矩形面积可达 $10^{10}$，显然不可能开这么大数组。

我们立刻意识到：**不需要保留整张图的信息**，因为只查询一个点。

### 1.3 关键观察：只需要回答一个点

题目**只问一个点** $(x,y)$ 被哪张地毯覆盖。那根本不需要知道其他任何位置的信息。

对于每张地毯，我们只需要判断它是否覆盖了 $(x,y)$。判断方法很简单：

地毯 $i$ 左下角 $(a_i, b_i)$，$x$ 方向长度 $g_i$，$y$ 方向长度 $k_i$。它覆盖的区域是：
$$
a_i \le x \le a_i + g_i \quad \text{且} \quad b_i \le y \le b_i + k_i
$$

注意边界也算被覆盖（题目明确说了"矩形地毯边界和四个顶点上的点也算被覆盖"），所以是闭区间。

### 1.4 后铺的优先

地毯是按 $1$ 到 $n$ 的顺序铺的。后铺的盖住先铺的，所以对于同一个点，**编号更大的地毯如果覆盖了这个点，就一定是更上面的**。

因此，最上面的地毯一定是 **所有覆盖了 $(x,y)$ 的地毯中编号最大的那张**。

### 1.5 算法呼之欲出

我们从 $n$ 到 $1$ 倒着遍历地毯，第一个覆盖了 $(x,y)$ 的地毯就是答案。如果全部遍历完都没有覆盖到，输出 $-1$。

复杂度 $O(n)$，$n \le 10^4$，绰绰有余。

### 1.6 为什么这题是"普及-"

因为这题不需要任何算法知识，只需要：
1. 读懂题意，理解后铺覆盖先铺
2. 意识到只查一个点，只需逐张判断
3. 会写坐标范围判断

本质上就是一个**倒序枚举 + 条件判断**的模拟题，没有任何弯弯绕绕。

### 1.7 会不会有坑？

有人说要小心边界条件为闭区间——题目说了边界也算覆盖，所以是 `<=` 而不是 `<`，别写错了就行。此外 $n$ 可以为 $0$，此时直接输出 $-1$。没了。

## 2. 链式推理（Chain-of-Thought）

### Step 1：理解覆盖关系

地毯 $i$ 覆盖区域为矩形 $R_i = [a_i, a_i+g_i] \times [b_i, b_i+k_i]$。

> **Lemma 1（覆盖判断）**：点 $P=(x,y)$ 被地毯 $i$ 覆盖当且仅当 $a_i \le x \le a_i+g_i$ 且 $b_i \le y \le b_i+k_i$。
>
> **证明**：地毯是轴对齐矩形，左下角 $(a_i,b_i)$，$x$ 方向长度 $g_i$，$y$ 方向长度 $k_i$，所以 $x$ 坐标范围是 $[a_i, a_i+g_i]$，$y$ 坐标范围是 $[b_i, b_i+k_i]$。点被覆盖当且仅当其两个坐标都在对应区间内。题目明确边界和顶点也算，故闭区间成立。■

### Step 2：后铺优先规则

地毯按 $1,2,\dots,n$ 依次铺设，后铺的在上层。

> **Lemma 2（顶层判定）**：设 $S = \{i \mid 1 \le i \le n,\; P \in R_i\}$ 为所有覆盖 $P$ 的地毯编号集合，则 $P$ 处最上层地毯的编号为 $\max S$（若 $S = \varnothing$，则无覆盖，输出 $-1$）。
>
> **证明**：铺设顺序与编号顺序一致，编号更大的地毯铺设时间更晚。对于任意两张覆盖了 $P$ 的地毯 $i < j$，$j$ 在 $i$ 之后铺设，因此 $j$ 覆盖在 $i$ 之上。所以 $P$ 处的可见地毯是编号最大的那张。■

### Step 3：算法设计

由 Lemma 2 直接得到算法：

**输入**：$n$，数组 $\{(a_i,b_i,g_i,k_i)\}_{i=1}^n$，查询点 $(x,y)$。
**输出**：$\max\{i \mid P \in R_i\}$ 或 $-1$。

**正确性**：由 Lemma 1 和 Lemma 2 保证。遍历所有地毯检查条件，取满足条件的最大编号即为答案。

### Step 4：复杂度分析

- 时间：$O(n)$，每张地毯常数时间检查。
- 空间：$O(1)$ 额外空间（或 $O(n)$ 存储输入）。

因为 $n \le 10^4$，$O(n)$ 足够在 1ms 内通过。

## 3. 模式总结

| 模式 | 说明 |
|------|------|
| **倒序判断** | 后铺覆盖先铺 → 从后往前找第一个满足条件的，必然是顶层 |
| **条件覆盖判定** | 轴对齐矩形包含点判定，闭区间四则比较 |
| **单点查询无需建图** | 只有一个查询点时，不用维护全局状态，每张地毯独立判断即可 |

## 4. 真正的解法

### 符号约定

| 符号 | 含义 |
|------|------|
| $n$ | 地毯张数 |
| $a_i, b_i$ | 第 $i$ 张地毯左下角坐标 |
| $g_i, k_i$ | 第 $i$ 张地毯 $x$ 方向长度、$y$ 方向长度 |
| $x, y$ | 查询点坐标 |

### 算法步骤

1. 读入 $n$。
2. 读入 $n$ 行，每行四个整数 $a_i, b_i, g_i, k_i$，存入数组。
3. 读入 $x, y$。
4. 初始化答案 $ans \gets -1$。
5. 从 $i = n$ 到 $1$ 倒序遍历：
   - 若 $a_i \le x \le a_i+g_i$ 且 $b_i \le y \le b_i + k_i$，则令 $ans \gets i$ 并跳出循环。
6. 输出 $ans$。

### 复杂度

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$（存储输入）或 $O(1)$（边读边判，但本题顺序要求先读入所有）

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};
int a[mxn],b[mxn],g[mxn],k[mxn];

int main(){
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;cin>>n;
	for(int i=1;i<=n;++i)
		cin>>a[i]>>b[i]>>g[i]>>k[i];
	int x,y;cin>>x>>y;

	int ans=-1;
	for(int i=n;i>=1;--i){
		if(a[i]<=x&&x<=a[i]+g[i]&&b[i]<=y&&y<=b[i]+k[i]){
			ans=i;
			break;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```
