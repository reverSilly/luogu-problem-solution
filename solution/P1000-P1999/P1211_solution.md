# P1211 [USACO1.3] 牛式 Prime Cryptarithm — 题解

## Part 1 — 重述题目

给定一个数字集合 $S$（$n$ 个互不相同的 $1\sim9$ 的数字），问有多少种方式把下面的乘法竖式中的 `*` 全部替换成 $S$ 中的数字，使得竖式严格成立：

```
    ***
×   **
----------
    ***
   ***
----------
   ****
```

约束：
- 每个 `*` 必须替换为 $S$ 中的数字（同一数字可重复使用）。
- 第一个数（被乘数）必须是 3 位数，第二个数（乘数）必须是 2 位数。
- 第一个部分积（被乘数 × 乘数个位）必须是 3 位数。
- 第二个部分积（被乘数 × 乘数十位）必须是 3 位数。
- 最终乘积（被乘数 × 乘数）必须是 4 位数。
- 所有数字均在 $S$ 中（即 $1\sim9$，不含 $0$，所以不存在首位为 $0$ 的问题）。

数据范围：$1 \le n \le 9$，$a_i \in [1,9]$ 且互不重复。

输出：满足条件的牛式数量。

## Part 2 — 思维链

### 2.1 探索性质：竖式结构

先把竖式展开。设被乘数为 $A$（3 位），乘数为 $B$（2 位），$B$ 的十位为 $b_1$、个位为 $b_0$。

竖式中的 4 个条件等价于：
- $A \in [100, 999]$（3 位，自动满足因为数字不含 0）
- $B \in [10, 99]$（2 位，同上）
- $p_1 = A \cdot b_0 \in [100, 999]$（第一部分积 3 位）
- $p_2 = A \cdot b_1 \in [100, 999]$（第二部分积 3 位）
- $T = A \cdot B \in [1000, 9999]$（总积 4 位）
- 上述 4 个整数的每一位数字都属于 $S$

注意：由于 $S$ 中不含 0，$A$ 的每一位、$B$ 的每一位、$p_1$ 的每一位、$p_2$ 的每一位、$T$ 的每一位都自然不为 0，无需额外判断"首位非 0"。

### 2.2 简化版本：如果只看 A 和 B 的合法性

先看"哪些 $A$ 和 $B$ 的各位数字都在 $S$ 中"。

- $A$ 是 3 位数，每位 $\in S$：共 $|S|^3$ 种可能。
- $B$ 是 2 位数，每位 $\in S$：共 $|S|^2$ 种可能。

最坏情况 $|S| = 9$，则 $A$ 有 $729$ 种，$B$ 有 $81$ 种，$(A,B)$ 对最多 $729 \times 81 = 59049$ 种。

### 2.3 经典做法：直接枚举 + 校验

既然 $(A,B)$ 的候选对最多只有 $59049$ 个，而对每一对只需要做常数次整数运算和数位检查，完全可以暴力枚举。

**枚举策略**：双重循环，外层枚举 $A$（$|S|^3$ 种），内层枚举 $B$（$|S|^2$ 种），共 $|S|^5$ 次迭代（最坏 $9^5 = 59049$）。

对每对 $(A, B)$，提取 $b_0 = B \bmod 10$、$b_1 = B \div 10$，然后检查：

1. $p_1 = A \times b_0$ 是否为 3 位数，且各位 $\in S$
2. $p_2 = A \times b_1$ 是否为 3 位数，且各位 $\in S$
3. $T = A \times B$ 是否为 4 位数，且各位 $\in S$

三项全过则答案 +1。

### 2.4 证明：枚举正确性

**引理 1**（完备性）：算法枚举到的每一个合法牛式。

证明：设存在一个合法牛式，其被乘数为 $A^*$，乘数为 $B^*$。由题设，$A^*$ 的每一位 $\in S$，$B^*$ 的每一位 $\in S$。枚举过程遍历了所有"各位 $\in S$"的 3 位数 $A$ 和 2 位数 $B$，因此必然遍历到 $(A^*, B^*)$。$\square$

**引理 2**（无伪阳性）：算法计数的每一个 $(A,B)$ 确实对应一个合法牛式。

证明：设算法对某个 $(A,B)$ 计入了答案。由算法逻辑：
- $A$ 的各位 $\in S$（由枚举方式保证）
- $B$ 的各位 $\in S$（由枚举方式保证）
- $p_1 = A \cdot b_0$ 是 3 位数且各位 $\in S$
- $p_2 = A \cdot b_1$ 是 3 位数且各位 $\in S$
- $T = A \cdot B$ 是 4 位数且各位 $\in S$

这正是牛式的全部条件。因此 $(A,B)$ 构成一个合法牛式。$\square$

**引理 3**（无重复计数）：每个合法牛式恰好被计数一次。

证明：一个合法牛式由唯一的 $(A,B)$ 确定。枚举中每个 $(A,B)$ 恰好出现一次。由引理 1 和引理 2，恰好被计数一次。$\square$

### 2.5 证明：数位检查函数正确

定义函数 $\text{digits\_in\_S}(x, k)$：判断正整数 $x$ 是否恰好有 $k$ 位，且每一位都在 $S$ 中。

实现方式：反复对 10 取模取位，共取 $k$ 次，每取一位检查是否在 $S$ 中；若取到 $k$ 次后 $x$ 仍非 0，则说明位数超过 $k$，返回假。若取到 $k$ 次时 $x$ 已为 0（即不足 $k$ 位），也返回假。

**引理 4**：$\text{digits\_in\_S}(x, k)$ 返回真当且仅当 $x$ 恰好 $k$ 位且每位 $\in S$。

证明：
- 若 $x$ 恰好 $k$ 位且每位 $\in S$：取 $k$ 次后 $x$ 恰好变为 0，每一步检查均通过，返回真。
- 若 $x$ 超过 $k$ 位：取 $k$ 次后 $x > 0$，函数返回假。
- 若 $x$ 不足 $k$ 位：在某次取位时 $x$ 已为 0，取出的"位"为 0，而 $0 \notin S$（$S \subseteq [1,9]$），返回假。
- 若某位 $\notin S$：对应步骤检查失败，返回假。
$\square$

### 2.6 复杂度

- 枚举对数：$|S|^5$，最坏 $9^5 = 59049$。
- 每对检查：3 次数位检查，每次检查 $O(\text{位数}) = O(1)$（最多 4 位）。
- 总时间：$O(|S|^5 \cdot 1) = O(1)$（常数上界 $59049 \times 12 \approx 7 \times 10^5$ 次操作）。
- 空间：$O(1)$。

## Part 3 — 模式总结

- **探索性质** — 竖式展开为 5 个整数条件（$A$、$B$、$p_1$、$p_2$、$T$ 的位数与数字集合约束），且因 $S$ 不含 0 而无需处理首位为零。
- **简化版本** — 若只看 $A$ 和 $B$ 各位 $\in S$，候选为 $|S|^3 \times |S|^2$ 对。
- **经典做法** — 暴力枚举所有候选 $(A,B)$ 对，逐对做常数时间的数位校验，$O(|S|^5)$。
- **数位检查** — 反复取模取位，同时校验位数与数字集合归属，$O(\text{位数})$。

## Part 4 — 实际解法

### 符号表

| 符号 | 含义 | 初始化 | 记忆 |
|------|------|--------|------|
| `n` | 可用数字的个数 | 读入 | 数字集大小 |
| `a[i]` | 第 $i$ 个可用数字（$i=0..n-1$） | 读入 | 数字集 |
| `ok[d]` | 布尔数组，`ok[d]` 为真表示数字 $d$ 在 $S$ 中 | 全假，读入后置真 | 数字合法性 |
| `ans` | 答案（牛式数量） | 0 | 累加器 |
| `A` | 被乘数（3 位） | 枚举 | 外层循环变量 |
| `B` | 乘数（2 位） | 枚举 | 内层循环变量 |

### 算法步骤

1. **读入** $n$ 和 $n$ 个数字，填入 `ok[1..9]`。
2. **三重循环枚举 $A$**：$a_2, a_1, a_0 \in S$，$A = 100a_2 + 10a_1 + a_0$。
3. **二重循环枚举 $B$**：$b_1, b_0 \in S$，$B = 10b_1 + b_0$。
4. **校验 $p_1$**：计算 $p_1 = A \times b_0$，检查 $p_1$ 是否为 3 位数且各位 $\in S$。
5. **校验 $p_2$**：计算 $p_2 = A \times b_1$，检查 $p_2$ 是否为 3 位数且各位 $\in S$。
6. **校验 $T$**：计算 $T = A \times B$，检查 $T$ 是否为 4 位数且各位 $\in S$。
7. 若 4、5、6 全部通过，`ans++`。
8. 输出 `ans`。

辅助函数 $\text{check}(x, k)$：判断 $x$ 恰好 $k$ 位且每位 $\in S$。

### 复杂度

- 时间：$O(|S|^5 \cdot 1)$，最坏约 $6 \times 10^4$ 次校验，每次 $O(1)$。
- 空间：$O(1)$。

### 验证状态

样例：$n=1$，$S=\{2\}$，唯一候选 $A=222$，$B=22$，$p_1=444$（3 位，各位 2 ✓），$p_2=444$（3 位 ✓），$T=4884$（4 位 ✓）→ $ans=1$。

## Part 5 — 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int n,a[9],ok[10];

bool check(int x,int k)
{
	for(int i=0;i<k;++i)
	{
		int d=x%10;
		if(!ok[d])
			return false;
		x/=10;
	}
	return x==0;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		ok[a[i]]=1;
	}

	int ans=0;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			for(int k=0;k<n;++k)
			{
				int A=100*a[i]+10*a[j]+a[k];
				for(int p=0;p<n;++p)
					for(int q=0;q<n;++q)
					{
						int b1=a[p],b0=a[q];
						int B=10*b1+b0;
						int p1=A*b0;
						int p2=A*b1;
						int T=A*B;
						if(check(p1,3)&&check(p2,3)&&check(T,4))
							++ans;
					}
			}

	cout<<ans<<'\n';
	return 0;
}
```
