# P1292 倒酒 — 题解

## Part 1: 重新读题

### 简化版描述

- 有两只无刻度酒杯：A 杯容量 $a$ ml，B 杯容量 $b$ ml，满足 $a \ge b$（输入保证 $0 < b \le a \le 10^9$）。
- 有一个无限大（且无限酒）的酒桶。
- 只允许三种倒酒操作：
  1. 把酒桶里的酒倒入 B 杯（直到 B 杯满，即 B 变 $b$）；
  2. 把 A 杯里的酒倒回酒桶（直到 A 杯空，即 A 变 $0$）；
  3. 把 B 杯里的酒倒入 A 杯（直到 B 空 **或** A 满，二者谁先到就停）。
- 每次倒酒必须倒满或倒空。
- 目标：经过若干次倾倒，使 **A 杯中剩下的酒的体积尽可能小（但 $> 0$）**。
- 输出：
  - 第一行：最小可达到的正体积 $c$。
  - 第二行：$P_a$（把 A 杯的酒倒出/倒空的次数）和 $P_b$（把酒桶的酒倒入 B 杯的次数）。
  - 若有多组 $(P_a, P_b)$ 满足要求，输出 $P_a$ 最小的；$P_a$ 相同时输出 $P_b$ 最小的。

### 约束

| 数据范围 | 约束 | 暗示 |
|---------|------|------|
| 100% | $0 < b \le a \le 10^9$ | 必须 $O(\log)$，扩展欧几里德 |

关键观察：操作 1 是唯一"产生酒"的操作，操作 2 是唯一"消灭酒"的操作，操作 3 只在两杯之间搬运。

---

## Part 2: 思维链（发现过程）

### 第一步：探索机制 — 操作 3 是"搬运"，不改变总量

先看清三种操作对 **(A 杯酒量, B 杯酒量, 桶中酒量)** 三元组的影响。设状态为 $(x, y)$，$x$ 为 A 杯酒量，$y$ 为 B 杯酒量（桶无限大，不计入）。

| 操作 | 前置条件 | 效果 |
|------|---------|------|
| 1（桶→B） | $y < b$ | $y \leftarrow b$ |
| 2（A→桶） | $x > 0$ | $x \leftarrow 0$ |
| 3（B→A） | $y > 0$ 且 $x < a$ | $t = \min(y, a-x)$；$x \leftarrow x+t,\; y \leftarrow y-t$ |

**关键观察**：操作 3 只在 A、B 之间搬酒，**不改变** $x + y$（两杯总量）。操作 1 使 $x+y$ 增加 $b-y$（恰好填满 B）。操作 2 使 $x+y$ 减少 $x$（清空 A）。

进一步观察：操作 1 之后 B 一定满（$y=b$），操作 2 之后 A 一定空（$x=0$）。操作 3 之后，**要么 B 空、要么 A 满**（$y=0$ 或 $x=a$）。

**推论 1**：任何时刻，状态一定落在以下"角点"之一：

- B 满（$y = b$），此时 $x \in \{0, 1, \ldots, a\}$ 但 $x < a$ 才能继续操作 3；
- B 空（$y = 0$），此时 $x \in \{0, 1, \ldots, a\}$；
- A 满（$x = a$），此时 $y \in \{0, 1, \ldots, b\}$。

**推论 2（不变量）**：设 $d = \gcd(a, b)$。初始状态 $(0, 0)$，$x + y = 0 \equiv 0 \pmod d$。每次操作：
- 操作 1：$x+y$ 增加 $b-y$。注意 $y$ 本身是 $d$ 的倍数（归纳：初始 $y=0$；操作 1 后 $y=b$ 是 $d$ 的倍数；操作 3 后 $y$ 减少 $\min(y, a-x)$，而 $a-x$ 也是 $d$ 的倍数——因为 $a$ 是 $d$ 的倍数且 $x$ 是 $d$ 的倍数——所以 $\min(y, a-x)$ 也是 $d$ 的倍数；操作 2 不改 $y$）。所以 $x+y$ 的变化量是 $d$ 的倍数，$x+y$ 始终 $\equiv 0 \pmod d$。
- 操作 2：$x+y$ 减少 $x$，$x$ 是 $d$ 的倍数，故 $x+y$ 变化量是 $d$ 的倍数。
- 操作 3：$x+y$ 不变。

所以 **$x \equiv 0 \pmod d$ 且 $y \equiv 0 \pmod d$ 始终成立**（因为 $x + y \equiv 0 \pmod d$ 且 $x \le a$、$y \le b$ 都是 $d$ 的倍数——更严格地，$x$ 和 $y$ 各自都是 $d$ 的倍数，由归纳：初始 $x=y=0$；操作 1 不改 $x$、$y$ 变 $b$（$d$ 的倍数）；操作 2 $x$ 变 $0$（$d$ 的倍数）；操作 3 $x \leftarrow x + \min(y, a-x)$，$x$、$y$、$a-x$ 都是 $d$ 的倍数，故 $x+t$ 是 $d$ 的倍数，$y-t$ 也是 $d$ 的倍数）。

**所以 A 杯中酒量始终是 $d = \gcd(a,b)$ 的倍数**。因此 A 杯中可达到的**正**体积最小为 $d$。

### 第二步：证明下界可达 — $d$ 一定能在 A 杯中达到

由 Bezout 定理，存在整数 $u, v$ 使得 $a \cdot u + b \cdot v = d$。特别地，$b \cdot v \equiv d \pmod a$（取 $v$ 使 $b \cdot v \bmod a = d$）。

考虑这样的过程：重复"操作 1（桶→B）+ 操作 3（B→A，必要时穿插操作 2 清 A）"，每次操作 1 向系统注入 $b$ 体积的酒（因为操作 1 总是把 B 从当前状态填满到 $b$；如果 B 之前是空的则注入 $b$，如果 B 之前还有 $y' < b$ 则注入 $b - y'$）。

更精确地，我们只跟踪 **A 杯中的酒量 $x$**。注意：
- 操作 1 不改 $x$（只改 $y$）。
- 操作 2 把 $x$ 归零。
- 操作 3 把 $\min(y, a-x)$ 从 B 搬到 A。

**关键简化**：观察一个"标准倒酒循环"。我们从 $(0,0)$ 出发，目标是让 A 中留下 $d$。考虑如下策略：

1. 操作 1：B 满，$y = b$，$x = 0$。
2. 操作 3：把 B 倒入 A。若 $b \le a$（已知），则 $x = b$，$y = 0$。
   - 若 $b = a$：$x = a$（A 满），$y = 0$。此时 $d = b = a$，A 中酒量 $a = d$，已达成。
   - 若 $b < a$：$x = b < a$，$y = 0$。
3. 若 $y = 0$ 且 $x < a$：操作 1 再填 B。回到第 2 步。
4. 若操作 3 时 A 已快满（$a - x < y$），则操作 3 后 A 满（$x = a$），B 剩 $y' = y - (a-x) > 0$。此时需要操作 2 清空 A（$x = 0$），然后操作 3 把 B 中剩余 $y'$ 倒入 A（$x = y'$，$y = 0$）。

**这个过程的数学模型**：每完成一次"操作 1"（B 从空变满），A 杯中**累计**注入 $b$ 体积（因为 B 每次都是从 0 被填满）。A 杯容量 $a$，每满一次就倒掉（操作 2）。所以 A 杯中酒量随"操作 1 次数 $k$"的演化是：

$$
x_k = (k \cdot b) \bmod a
$$

**证明**：用数学归纳。
- 基础 $k = 0$：$x_0 = 0 = 0 \cdot b \bmod a$。$\checkmark$
- 归纳：设操作 $k$ 次后 $x_k = (k \cdot b) \bmod a$。第 $k+1$ 次操作 1 前，B 必须为空（$y = 0$）才能操作 1（否则操作 1 只会"补满"，不增加总量——但根据推论 1，操作 1 后 B 一定满；操作 3 后要么 B 空要么 A 满；若 A 满则操作 2 清 A 后 B 可能还有余，再操作 3 把 B 余量倒入 A 使 B 空）。

  更严格地，"操作 1 次数" $k$ 增加 1 当且仅当 B 从 0 被填满到 $b$，此时系统净注入 $b$ 体积。A 杯中酒量的变化：注入 $b$ 后，若 $x_{k} + b < a$，则 $x_{k+1} = x_k + b$；若 $x_k + b \ge a$，则 A 满（$x = a$），操作 2 清 A（$x = 0$），B 余 $x_k + b - a$，操作 3 把 B 余量倒入 A，$x_{k+1} = x_k + b - a$。

  两种情况合并：$x_{k+1} = x_k + b - a \cdot \lfloor (x_k + b) / a \rfloor = (x_k + b) \bmod a = ((k+1) \cdot b) \bmod a$。$\checkmark$

  这里用到 $x_k = (k \cdot b) \bmod a$，所以 $x_k + b \equiv (k+1) b \pmod a$，且 $0 \le x_k < a$，故 $x_k + b < a + b \le 2a$（因为 $b \le a$），所以 $\lfloor (x_k + b) / a \rfloor \in \{0, 1\}$，结论成立。

因此，**A 杯中可达到的正酒量集合** $= \{ (k \cdot b) \bmod a : k \ge 1,\; (k \cdot b) \bmod a > 0 \}$。

### 第三步：求最小正体积 — 数论结论

集合 $\{ (k \cdot b) \bmod a : k \ge 1 \} \setminus \{0\}$ 的最小正元素就是 $\gcd(a, b)$。

**证明**：设 $d = \gcd(a, b)$。
- 由第一步的不变量，$(k \cdot b) \bmod a$ 始终是 $d$ 的倍数，故集合中所有元素 $\ge d$（正元素）。
- 由 Bezout，存在 $k_0$ 使 $k_0 \cdot b \equiv d \pmod a$（取 $k_0$ 为 $b/d$ 模 $a/d$ 的逆元，则 $k_0 \cdot (b/d) \equiv 1 \pmod{a/d}$，即 $k_0 b \equiv d \pmod a$）。故 $d$ 在集合中。
- 所以最小正元素 $= d$。$\blacksquare$

**结论**：$c = \gcd(a, b)$。

### 第四步：求最小的 $P_b$（操作 1 次数）

设 $P_b = k$。我们要 $k \cdot b \equiv d \pmod a$，其中 $d = \gcd(a, b)$。

两边除以 $d$：$k \cdot (b/d) \equiv 1 \pmod{a/d}$。

设 $A = a/d$，$B = b/d$（$\gcd(A, B) = 1$）。求 $k$ 满足：

$$
k \cdot B \equiv 1 \pmod A
$$

即 $k$ 是 $B$ 模 $A$ 的**乘法逆元**。由扩展欧几里德，存在整数 $x, y$ 使 $B \cdot x + A \cdot y = 1$，则 $x \bmod A$ 就是逆元。

**最小正解**：$k \equiv x \pmod A$，最小正解为：

$$
k = ((x \bmod A) + A - 1) \bmod A + 1 \in \{1, 2, \ldots, A\}
$$

（注意 $k$ 必须 $\ge 1$，因为 $k = 0$ 时 $x = 0$ 不是正体积。逆元 $x \bmod A \in \{0, 1, \ldots, A-1\}$，但 $x \bmod A = 0$ 当且仅当 $A \mid x$，即 $A \mid (1 - Bx')$ 对某个解 $x'$，这要求 $A = 1$。若 $A = 1$（即 $a = d$，亦即 $b = a$），则 $k = 1$ 即可（一次操作 1 使 A 满 $= a = d$）。一般地 $A \ge 1$，逆元 $x \bmod A \in [0, A-1]$，最小正 $k \in [1, A]$。）

**所以 $P_b = k$**，其中 $k$ 是 $B = b/d$ 模 $A = a/d$ 的乘法逆元（取 $[1, A]$ 中的代表）。

### 第五步：求 $P_a$（操作 2 次数）

操作 2 是"清空 A"，每次清空 A 意味着 A 从满（$x = a$）变为空（$x = 0$）。A 满当且仅当操作 3 把 B 倒入 A 时 A 恰好被填满。

**关键观察**：每次操作 2（清 A）对应 A 中累计注入了 $a$ 体积的酒（A 从 0 涨到 $a$ 再清空）。总注入量 $= k \cdot b$（$k$ 次操作 1，每次注入 $b$）。最终 A 中剩余 $d$ 体积。所以被清空走的总量 $= k \cdot b - d$。每次操作 2 清空 $a$ 体积，故：

$$
P_a = \frac{k \cdot b - d}{a}
$$

**验证**：$k \cdot b \equiv d \pmod a$，所以 $k \cdot b - d$ 是 $a$ 的倍数，$P_a$ 是整数。$\checkmark$

**为什么 $P_a$ 在 $P_b$ 确定后也唯一？** 因为 $P_a = (k \cdot b - d) / a$ 是 $k$ 的确定性函数。题目要求"$P_a$ 最小，其次 $P_b$ 最小"。我们取 $k \in [1, A]$ 中的最小正解（即逆元的 $[1, A]$ 代表），这同时让 $P_a = (k \cdot b - d) / a$ 最小（因为 $P_a$ 随 $k$ 单调递增：$P_a(k) = (k \cdot b - d) / a$，$b > 0$ 故严格递增）。

等等，需要确认：题目说"$P_a$ 最小的一个；$P_a$ 相同时 $P_b$ 最小的一个"。$P_a$ 是 $k$ 的严格增函数（$k \mapsto (kb - d)/a$），所以 $P_a$ 最小 $\iff$ $k$ 最小。$k$ 的最小正解唯一（$[1, A]$ 中只有一个满足 $kB \equiv 1 \pmod A$ 的 $k$）。所以 $(P_a, P_b)$ 唯一确定。$\blacksquare$

### 第六步：用扩展欧几里德求逆元

扩展欧几里德 `exgcd(B, A, x, y)` 返回 $\gcd(B, A)$ 及满足 $Bx + Ay = \gcd(B,A) = 1$ 的 $x, y$。

$x$ 就是 $B$ 模 $A$ 的逆元（可能为负或 $|x| > A$），调整到 $[1, A]$：

$$
k = ((x \bmod A) + A - 1) \bmod A + 1
$$

特殊情况 $A = 1$（$a = d$，即 $a = b$）：此时 $B = 1$，$1 \cdot k \equiv 1 \pmod 1$ 对任意 $k$ 成立，最小正 $k = 1$。公式 $((x \bmod 1) + 1 - 1) \bmod 1 + 1 = (0 + 0) \bmod 1 + 1 = 0 + 1 = 1$。$\checkmark$

### 第七步：样例验证

样例：$a = 5, b = 3$（推测，因为样例解释有 6 步操作，最终 A 中剩 1）。

- $d = \gcd(5, 3) = 1$。$c = 1$。
- $A = 5, B = 3$。求 $3k \equiv 1 \pmod 5$。$3 \cdot 2 = 6 \equiv 1 \pmod 5$，所以 $k = 2$。
- $P_b = 2$。
- $P_a = (2 \cdot 3 - 1) / 5 = 5/5 = 1$。
- 输出：`1`，`1 2`。

**对照样例解释的 6 步操作**：
1. 桶→B：$y = 3, x = 0$。（操作 1，$P_b = 1$）
2. B→A：$t = \min(3, 5-0) = 3$，$x = 3, y = 0$。（操作 3）
3. 桶→B：$y = 3, x = 3$。（操作 1，$P_b = 2$）
4. B→A：$t = \min(3, 5-3) = 2$，$x = 5, y = 1$。（操作 3，A 满）
5. A→桶：$x = 0, y = 1$。（操作 2，$P_a = 1$）
6. B→A：$t = \min(1, 5-0) = 1$，$x = 1, y = 0$。（操作 3）

最终 $x = 1 = d$。$P_a = 1$，$P_b = 2$。$\checkmark$

### 第八步：边界情况

- **$a = b$**：$d = a = b$，$A = 1$，$k = 1$，$P_a = (1 \cdot b - a) / a = (a - a)/a = 0$，$P_b = 1$。
  - 但题目要求 $c > 0$，且 $P_a, P_b$ 应该都是操作次数。$P_a = 0$ 意味着一次都没清空 A，合理（一次操作 1 + 一次操作 3 后 A 满 $= a = d$，不需要清空）。
  - 输出：$c = a$，$P_a = 0$，$P_b = 1$。
  - 等等，题目说 $P_a$ 是"从 A 杯中倒出酒的次数"。如果 A 没倒出过，$P_a = 0$。但题目要求 $c > 0$，没说 $P_a > 0$。所以 $P_a = 0$ 合法。
  - 实际上 $a = b$ 时，一次操作 1（B 满 $= b = a$）+ 一次操作 3（B→A，A 满 $= a$），A 中 $= a = d$。$P_b = 1$，$P_a = 0$。
  - 但更简单：$a = b$ 时 $d = a$，A 中最大就是 $a$，最小正体积 $= a$。$k = 1$ 次操作 1 后 A 中 $= b = a = d$（因为操作 3 把 B 全部倒入 A，$b = a$ 刚好填满 A）。$P_a = 0$。

- **$b \mid a$**：$d = b$，$A = a/b$，$B = 1$。$1 \cdot k \equiv 1 \pmod{a/b}$，最小正 $k = 1$。$P_a = (1 \cdot b - b) / a = 0$，$P_b = 1$。
  - 验证：一次操作 1（B 满 $= b$）+ 一次操作 3（B→A，$x = b$），A 中 $= b = d$。$P_a = 0$，$P_b = 1$。$\checkmark$

- **$a = 10^9, b = 1$**：$d = 1$，$A = 10^9$，$B = 1$。$1 \cdot k \equiv 1 \pmod{10^9}$，$k = 1$。$P_a = (1 - 1)/10^9 = 0$，$P_b = 1$。
  - 验证：一次操作 1（B 满 $= 1$）+ 一次操作 3（B→A，$x = 1$），A 中 $= 1 = d$。$\checkmark$

- **$a = 10^9, b = 10^9 - 1$**（互质）：$d = 1$，$A = 10^9$，$B = 10^9 - 1$。求 $(10^9 - 1) k \equiv 1 \pmod{10^9}$。$-k \equiv 1 \pmod{10^9}$，$k \equiv -1 \equiv 10^9 - 1 \pmod{10^9}$。$k = 10^9 - 1$。
  - $P_a = ((10^9 - 1)(10^9 - 1) - 1) / 10^9 = (10^{18} - 2 \cdot 10^9 + 1 - 1) / 10^9 = (10^{18} - 2 \cdot 10^9) / 10^9 = 10^9 - 2$。
  - $P_b = 10^9 - 1$。
  - 注意 $k \cdot b$ 可能达到 $(10^9 - 1)^2 \approx 10^{18}$，**超过 32 位 int，需要 `long long`**。

### 第九步：溢出处理

$a, b \le 10^9$，$k \le A = a/d \le 10^9$。$k \cdot b \le 10^9 \cdot 10^9 = 10^{18}$，**需要 `long long`**（`int` 最大约 $2.1 \times 10^9$）。

扩展欧几里德中间量 $x, y$ 的绝对值 $\le \max(A, B) \le 10^9$，$B \cdot x + A \cdot y = 1$，中间量 $B \cdot x \le 10^{18}$，也需要 `long long`。

### 第十步：复杂度

- 扩展欧几里德：$O(\log \min(A, B)) = O(\log 10^9) \approx 30$ 次迭代。
- 总时间：$O(\log a)$，常数极小。
- 总空间：$O(1)$。

## Part 3: 模式总结

```
- explore its property — 操作3只搬运不改变总量；A杯酒量始终是 gcd(a,b) 的倍数
- consider easier version — 只跟踪 A 杯酒量 x，操作1每次注入 b，操作2每次清空 a
- classic problem solution — x_k = (k·b) mod a，最小正元素 = gcd(a,b)（Bezout 定理）
- reduce to easier problem — 求 k·b ≡ d (mod a) 的最小正 k，化为 (b/d)·k ≡ 1 (mod a/d)
- classic problem solution — 扩展欧几里德求乘法逆元，调整到 [1, a/d]
- defer reconstruction — P_a = (k·b - d) / a 由 k 唯一确定，随 k 单调递增
```

## Part 4: 实际解法

### 符号表

| 符号 | 含义 | 初始化 / 类型 |
|------|------|--------------|
| `a`, `b` | A 杯、B 杯容量（$a \ge b \ge 1$） | `i64`，读入 |
| `d` | $\gcd(a, b)$，即答案 $c$ | `i64`，`std::gcd` |
| `A` | $a / d$（简化后的模数） | `i64` |
| `B` | $b / d$（简化后的系数） | `i64` |
| `x`, `y` | 扩展欧几里德中间变量，满足 $B x + A y = 1$ | `i64`，`exgcd` 返回 |
| `k` | $P_b$，最小正解 $\in [1, A]$ | `i64`，$((x \bmod A) + A - 1) \bmod A + 1$ |
| `pa` | $P_a = (k \cdot b - d) / a$ | `i64` |

### 算法步骤

1. **读入** $a, b$（`i64`）。
2. **求 $d$**：$d = \gcd(a, b)$（`std::gcd`）。
3. **求 $A, B$**：$A = a / d$，$B = b / d$。
4. **求逆元**：调用 `exgcd(B, A, x, y)` 得 $B x + A y = 1$ 的解 $(x, y)$。
5. **调整 $k$**：$k = ((x \bmod A) + A - 1) \bmod A + 1$（保证 $k \in [1, A]$）。
   - 特判 $A = 1$：$k = 1$（公式也自动给出 1，无需特判）。
6. **求 $P_a$**：$P_a = (k \cdot b - d) / a$。
7. **输出**：第一行 $d$；第二行 $P_a$ 和 $P_b = k$。

### 复杂度

- 时间：$O(\log \min(a, b))$（扩展欧几里德）。
- 空间：$O(1)$。

### 验证状态

- 样例 $a = 5, b = 3$：$d = 1$，$A = 5, B = 3$，$3x + 5y = 1 \Rightarrow x = 2, y = -1$，$k = ((2 \bmod 5) + 4) \bmod 5 + 1 = (2+4) \bmod 5 + 1 = 1 + 1 = 2$。$P_a = (2 \cdot 3 - 1)/5 = 1$。输出 `1` / `1 2`。$\checkmark$
- $a = b$：$d = a$，$A = 1, B = 1$，$x = 1, y = 0$，$k = ((1 \bmod 1) + 0) \bmod 1 + 1 = 0 + 1 = 1$。$P_a = (1 \cdot a - a)/a = 0$。输出 $a$ / `0 1`。$\checkmark$
- $b \mid a$（$b < a$）：$d = b$，$A = a/b, B = 1$，$1 \cdot x + A \cdot y = 1 \Rightarrow x = 1, y = 0$，$k = ((1 \bmod A) + A - 1) \bmod A + 1$。若 $A > 1$：$k = (1 + A - 1) \bmod A + 1 = 0 + 1 = 1$。$P_a = (b - b)/a = 0$。输出 $b$ / `0 1`。$\checkmark$
- 大数 $a = 10^9, b = 10^9 - 1$：$d = 1$，$k = 10^9 - 1$，$P_a = 10^9 - 2$。需 `long long`。$\checkmark$
- 未编译运行（按题目要求）。

## Part 5: 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

// 扩展欧几里德：返回 gcd(a,b)，并求出 x,y 使 a*x+b*y=gcd(a,b)
i64 exgcd(i64 a,i64 b,i64&x,i64&y)
{
	if(b==0)
	{
		x=1;y=0;
		return a;
	}
	i64 g=exgcd(b,a%b,y,x);
	y-=y/a*b;
	return g;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	i64 a,b;
	cin>>a>>b;

	i64 d=gcd(a,b);
	i64 A=a/d,B=b/d;

	i64 x,y;
	exgcd(B,A,x,y);   // B*x + A*y = 1
	// x 是 B 模 A 的逆元（可能为负或超出范围）
	i64 k=((x%A)+A-1)%A+1;   // 调整到 [1, A]

	i64 pa=(k*b-d)/a;
	i64 pb=k;

	cout<<d<<'\n';
	cout<<pa<<' '<<pb<<'\n';

	return 0;
}
```

### 代码说明

- `exgcd(a, b, x, y)`：标准递归扩展欧几里德。基础情形 $b = 0$ 时 $x = 1, y = 0$（$a \cdot 1 + 0 \cdot 0 = a$）。递归 $g = \gcd(b, a \% b)$，利用 $a = (a/b) \cdot b + (a \% b)$ 回代更新 $x, y$。
- `gcd(a, b)`：C++17 标准库 `std::gcd`（`<numeric>`，已被 `<bits/stdc++.h>` 包含）。
- `k = ((x%A)+A-1)%A+1`：把 $x$ 调整到 $[1, A]$。$(x \bmod A) \in [0, A-1]$（C++ 中负数取模可能为负，先 $+A$ 再 $\bmod A$ 保证非负），再 $+A-1$ 后 $\bmod A$ 把 $0$ 映射到 $A-1$（即 $k = A$ 而非 $0$），最后 $+1$ 把 $[0, A-1]$ 映射到 $[1, A]$。
- `pa = (k*b-d)/a`：由 $k \cdot b \equiv d \pmod a$ 保证整除。
- 所有变量用 `i64`（`long long`），避免 $k \cdot b$ 溢出（最大约 $10^{18}$）。
