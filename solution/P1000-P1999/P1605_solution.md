# P1605 迷宫

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

有一个 $N\times M$ 的方格迷宫，其中有 $T$ 个障碍格不可通过。给定起点 $(SX,SY)$ 与终点 $(FX,FY)$，
每一步可以上下左右移动一格，**每个格子最多经过一次**，求从起点到终点的不同方案数。

"不同方案"指不同的格子序列（路径），而不是不同的步数或不同的方向串——但由于方向唯一决定格子序列，
两者其实一一对应。题目不要求最短路，只要求计数。

### 输入输出格式

- **输入格式**：第一行 $N,M,T$；第二行 $SX,SY,FX,FY$；接下来 $T$ 行每行一个障碍坐标。
- **输出格式**：一行，方案总数。
- **数据规模**：$1\le N,M\le5$，$1\le T\le10$，坐标均在网格内，**保证起点无障碍**。

### 关键约束分析

1. **格子数最多 $25$**：这是典型的"搜索规模上限"，路径数虽然可达上万，但搜索树完全跑得动。
2. **每格最多一次**：这是"自回避路径（self-avoiding walk）"计数，不能简单用 DP 做（因为状态需要记住访问集合）。
3. **不是最短路**：不能用 BFS 层数计数；一条路径可以绕远路。
4. **边界陷阱**：起点等于终点时方案数应为 $1$（原地不动）；起点必须一开始就标记为已访问，否则路径会绕回起点。
5. **障碍可能重复给出**：用 `bool` 标记可以自然去重。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：先判断能不能 DP

如果是"只能向右/向下"，那是经典网格 DP（如 P1002 过河卒）。但本题四个方向都能走，
一条路径可能先向右再折回左边，**无法按坐标顺序确定状态**：要判断某格能不能走，必须知道它是否已在当前路径上。
于是状态里必须带"已访问集合"，而 $2^{25}$ 太大，DP 不可行。

### 第二步：既然状态不可压，就直接枚举路径

$25$ 个格子的规模下，"枚举所有自回避路径"是可以接受的：虽然上界是 $4^{24}$，但受"不能重复经过"和"障碍"约束，
实际搜索树规模远小于此（最坏的空 $5\times5$ 网格上，从角到角的方案数也只有 $8512$ 量级）。

**引理 1（方案 ↔ 终止于终点的自回避路径）**：一个方案与一条"起点出发、终点结束、内部格子互不相同且都不含终点之外的重复"的格子序列一一对应；
等价地，一条满足"每格至多访问一次、不经过障碍、最后一步落在终点"的序列就是一个方案。

*证明*：方案的定义就是一条满足约束的行走序列：从起点出发、四方向移动、每格至多一次、不经过障碍、终止于终点。
把这条序列的格子按顺序写出即得所说的序列，反之亦然。两条不同方案对应不同的格子序列，故是一一对应。$\square$

### 第三步：DFS 的两个关键决定

**引理 2（到达终点立即计数并返回是正确的）**：在 DFS 中，一旦当前格是终点就 `++ans` 并 `return`（不再从终点继续扩展），
这样统计到的恰好是所有终止于终点的自回避路径，每条一次。

*证明*：设某条合法路径 $P=(p_0=S,\dots,p_k=F)$。DFS 沿 $p_0,p_1,\dots,p_k$ 前进时，每步都满足"在界内、非障碍、未被访问"，
故必然到达 $p_k$ 并被计数一次。反过来，被计数的每条路径都由合法移动构成且终点为 $F$，故是合法方案。
"不唯一"只可能发生在同一个格子序列被 DFS 走两次，但 DFS 的走法由"每步选哪个方向"唯一决定，同一序列只有一种走法。$\square$

若在终点处继续扩展会怎样？会枚举出"经过终点后又离开"的序列，它们不以终点结束，不是方案；
而标程的暴力对照版本（`P1605_brute.cpp`）正是"到终点继续扩展、靠末格是否为终点计数"，
两者结果相同，因为它只在末格恰好是终点时才计数，等价于把长路径按"第一次到达终点"的前缀截断。引理 2 的写法更省时间。

**引理 3（回溯标记保证不重不漏）**：进入格子时置 `vis=1`、退出时置 `vis=0`，
则 DFS 遍历到的"根到当前结点的路径"恰好是所有从起点出发的自回避路径前缀，每个前缀一次。

*证明*：对路径长度归纳。长度 $0$：只有起点，且 `vis[sx][sy]=1` 保证不会再次进入。
设所有长度 $\le L$ 的前缀都恰好被访问一次；长度 $L+1$ 的前缀由某个长度 $L$ 的前缀 $Q$ 加上一个新格子 $q$ 得到。
在 DFS 处理 $Q$ 的末尾时，`vis` 恰好标记着 $Q$ 中的格子，故 $q$ 可进入当且仅当"在界内、非障碍、不在 $Q$ 中"，
即 $Q+q$ 是自回避前缀；此时递归进入并访问一次。返回后恢复 `vis`，保证其它分支不受影响。$\square$

### 第四步：起点与终点的两个边界

**引理 4（起点即终点）**：若 $(SX,SY)=(FX,FY)$，答案为 $1$。

*证明*：空路径（不移动）满足"从起点出发、终点结束、每格至多一次、不经过障碍"，是一个合法方案；
任何非空路径都会再次经过起点，违反"每格最多经过一次"。故恰有 $1$ 个方案。$\square$

标程在 `main` 里先置 `vis[sx][sy]=true` 再调用 `dfs`，而 `dfs` 的第一行就判终点，因此该情形自然输出 $1$。

**定理**：上述 DFS 输出的 `ans` 等于方案总数。

*证明*：由引理 3，DFS 不重不漏地枚举了所有自回避前缀；由引理 2，其中终点为 $F$ 的那些被计数且只计一次；
由引理 1，这些与方案一一对应；引理 4 覆盖退化情形。$\square$

### 第五步：复杂度

搜索树的结点数等于"从起点出发的自回避路径前缀数"，每个结点扩展 $4$ 个方向。
上界是 $4^{NM-1}$，但 $NM\le25$ 且受自回避约束，实际规模很小：空 $5\times5$ 网格上从角出发的全部自回避前缀只有 $153745$ 个，毫秒级完成。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 四方向 + 每格一次 ⇒ 状态必须带访问集合，无法用坐标 DP。
- `consider easier version` — 若是"只能右下"就是网格 DP（P1002）；本题失去了这个单调性。
- `classic problem solution` — 自回避路径计数：DFS + 访问标记 + 回溯。
- `prove termination condition` — 到达终点即计数并返回，需证明不会漏计也不会重复计。
- `handle boundary` — 起点先标记（防止绕回）、起点即终点输出 $1$。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $N,M$ | `n`, `m` | 网格行数、列数 |
| $T$ | `t` | 障碍个数 |
| $S$ | `sx`, `sy` | 起点坐标（$1$ 基） |
| $F$ | `fx`, `fy` | 终点坐标（$1$ 基） |
| — | `block[x][y]` | 是否为障碍，`true` 表示不可走 |
| — | `vis[x][y]` | 是否在当前路径上（DFS 栈内），回溯时清除 |
| — | `ans` | 方案计数 |
| — | `dx[4]`, `dy[4]` | 四个方向的增量：下、上、右、左 |
| — | `nx`, `ny` | 由当前格推出的一步落点 |
| — | `i`, `k` | 读障碍的计数、枚举方向的循环变量 |
| — | `dfs(x,y)` | 以 $(x,y)$ 为当前格的深度优先搜索 |

### 算法步骤

1. 读入 $N,M,T$ 与起点、终点；读 $T$ 个障碍并置 `block=1`。
2. `vis[sx][sy]=true`（起点必须在路径上，且不能被再次进入）。
3. 调用 `dfs(sx,sy)`：
   - 若 `(x,y)==(fx,fy)`：`++ans` 并返回；
   - 否则枚举四个方向，若目标格在界内、非障碍、未访问，则置 `vis=1`、递归、回溯置 `vis=0`。
4. 输出 `ans`。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}(\#\text{自回避前缀} \times 4)$，上界 $\mathcal{O}(4^{NM})$，$NM\le25$；空 $5\times5$ 网格上实测只有 $153745$ 个前缀结点，毫秒级完成。
- **空间复杂度**：$\mathcal{O}(NM)$ 的标记数组 + $\mathcal{O}(NM)$ 的递归栈（深度 $\le25$）。

### 正确性验证

引理 1 建立方案与路径的一一对应；引理 2 说明"终点即停"不重不漏；引理 3 说明回溯标记保证每个自回避前缀恰好访问一次；
引理 4 处理起点即终点；定理给出整体正确性。计数上界为 $5\times5$ 网格的全部自回避路径数，`int` 足够。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1605 迷宫
// https://www.luogu.com.cn/problem/P1605
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10};            // N,M<=5 (+5 松弛)

int n,m,t,sx,sy,fx,fy,ans;
bool block[mxn][mxn],vis[mxn][mxn];
constexpr int dx[4]{1,-1,0,0};
constexpr int dy[4]{0,0,1,-1};

void dfs(int x,int y)
{
	if(x==fx&&y==fy)              // 到达终点即得一种方案, 不再从终点继续扩展
	{
		++ans;
		return;
	}
	for(int k=0;k<4;++k)
	{
		int nx=x+dx[k],ny=y+dy[k];
		if(nx<1||nx>n||ny<1||ny>m||block[nx][ny]||vis[nx][ny])
			continue;
		vis[nx][ny]=true;
		dfs(nx,ny);
		vis[nx][ny]=false;
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>t>>sx>>sy>>fx>>fy;
	for(int i=0,x,y;i<t;++i)
	{
		cin>>x>>y;
		block[x][y]=true;
	}

	vis[sx][sy]=true;             // 每个格子最多经过一次, 起点先打标记
	dfs(sx,sy);
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **忘记标记起点**：路径会从相邻格走回起点，方案数虚高。
2. **忘记回溯**：`vis` 不清零会让其它分支误以为格子已被占用，方案数虚低。
3. **到达终点后继续扩展**：会把"经过终点再离开"的序列当成新方案，导致答案偏大。
4. **起点即终点**：不特殊处理可能输出 $0$；标程因"先标记再判终点"自然输出 $1$。
5. **障碍重复或障碍在起点**：前者用 `bool` 自然去重；后者题面保证不会出现，但若出现应输出 $0$。

### 本地验证结果

题面归档无样例段，使用手造小网格（$1\times1$、$2\times2$、空 $5\times5$）核对，并与"枚举全部自回避路径、不截断"的暴力（`P1605_brute.cpp`）对拍。

| 测试项 | 覆盖范围 | 结果 |
| :--- | :--- | :--- |
| 手工用例 | $1\times1$ 起终点重合 $\Rightarrow1$；$2\times2$ 对角 $\Rightarrow2$；空 $5\times5$ 从 $(1,1)$ 到 $(5,5)$ $\Rightarrow8512$ | 通过（与暴力一致） |
| `P1605_check.py` 随机对拍 | $150$ 组：$N,M\le4$，随机起点/终点、$0\sim10$ 个随机障碍，含退化成单行/单列的情形 | $150$ 组全部一致 |
| 障碍对比 | 同一网格加/不加障碍，方案数单调不增 | 通过 |
