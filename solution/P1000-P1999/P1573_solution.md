# P1573 栈的操作

> 标签：数学 · 递推 · 洛谷原创 · 栈 · 难度：暂未评级（灰）
> 本地题面：`P1573.md`（$n\le 2\times 10^9$，仅一行一个整数 $n$，答案对 $10^6+7$ 取模）。验证：`appendix/P1573/` 对拍 300 组随机 $n\in[1,8]$ + 逐点 $n=1\ldots10$ 全部 `std==brute`（BFS 穷举状态），$n=2\times10^9$ 时标程耗时 $0.005\text{s}$。

## 1. 重新读题

**问题重述（人话版）**

有 $4$ 个栈，编号 $1,2,3,4$。前三者初始为空，第四个栈**从栈顶到栈底**恰好是 $1,2,3,\ldots,n$（即栈顶是最小的 $1$，栈底是最大的 $n$）。

唯一允许的操作是「弹出并压入」：把某个栈 $A$ 的栈顶元素 $x$ 弹出，马上压入另一个栈 $B$，但要满足

- 规则 1：$A$ 非空；
- 规则 2：$B$ 为空，或者 $x$ **比 $B$ 的栈顶更小**。

问：把第四个栈里的 $n$ 个元素**全部**搬进第一个栈，最少需要多少次操作？答案 $\bmod (10^6+7)$。

> 一句话版本：**把一整摞从 1 到 n 的「塔」从一个栈搬到另一个栈，中途可借用另外两个空栈，每次只能搬最顶上的一块，且不允许把大块压到小块上，求最少步数。**

**题面里容易漏掉的条款**

1. 「从栈顶到栈底分别为 $1,2,\ldots,n$」$\Rightarrow$ 第四个栈的**栈顶是 $1$**（最小），栈底是 $n$。因为规则 2 只允许把小元素往栈顶压，下面用引理 1 会证明：任何时刻每个栈从栈顶到栈底都严格递增。
2. 「全部移到第一个栈」$\Rightarrow$ 最终第一个栈里装着 $1..n$ 全部元素。由强制递增的不变量，它从栈顶到栈底也只能是 $1,2,\ldots,n$——**和第四个栈的初始排列一模一样**（顺序没有被翻转）。
3. 规则 2 说的是「$x$ 比 $B$ 栈顶小」$\Rightarrow$ 这等价于「只能把元素放到空栈、或放到比它大的元素之上」，即经典的「大盘不许压小盘」。
4. $n$ 可到 $2\times10^9$，答案要取模 $\Rightarrow$ 一定存在一个 $O(\log n)$ 级别的**封闭公式**，任何模拟或递推都不可行。
5. 题面备注「本题因证明难度极高，做题难度低」$\Rightarrow$ 公式好写，但它的**最优性证明**是本题最重的部分（下界即著名的 Frame–Stewart 定理在 4 柱时的结论），我们在 §2 中把「构造（上界）」证到底，把「下界」作为定理引用并说明其地位。

**数据范围与规模感受**

$$1\le n\le 2\times10^9,\qquad \text{subtask：}30\%\ n\le 8,\quad 60\%\ n\le 60,\quad 100\%\ n\le 2\times10^9 .$$

$30\%$ 的 $n\le8$ 是给我们写暴力对拍用的：状态数 $4^n\le4^8=65536$，随 $n$ 增大很快爆炸，所以正解必须走公式。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：规则 2 到底锁死了什么

**引理 1（不变量：每栈自顶向下严格递增）**

在任何一个可达的配置中，每个栈从栈顶到栈底都是**严格递增**的数字序列。

**证明**（对操作次数归纳）：

- **初始**：栈 $1,2,3$ 为空（空序列满足），栈 $4$ 是 $1,2,\ldots,n$，自顶向下正是严格递增。✓
- **归纳步**：设当前某栈 $A$ 自顶向下递增，其栈顶记为 $x$（$x$ 是 $A$ 的最小元素）。
  - 弹出后：$A$ 去掉最小的 $x$，剩下的子序列仍递增。✓
  - 压入栈 $B$：由规则 2，$B$ 为空或 $x<B$ 的原栈顶 $y$。若 $B$ 为空，新的 $B$ 只有 $x$，递增；若非空，新的 $B$ 自顶向下是 $x$ 后接原来的递增序列，且 $x<y=$ 其后继，故整体仍严格递增。✓
- 归纳完成。$\blacksquare$

**引理 2（状态只由「分配」决定）**

一个配置被唯一地描述为「把 $1,\ldots,n$ 各分到 $4$ 个栈之一」。因此可达状态总数不超过 $4^n$。

**证明**：给定每个元素所属的栈，由引理 1，每个栈内的元素顺序被强制为递增（栈顶最小、栈底最大），没有额外自由度，配置唯一确定。元素分配方式共 $4^n$ 种，故可达状态不超过 $4^n$。$\blacksquare$

> 引理 2 是我们能做暴力对拍的根据：状态可用四进制数编码（第 $i$ 位是元素 $i$ 所在的栈号），$4^n$ 个状态随手 BFS。

### 2.2 认出模型：这其实就是「四柱汉诺塔」

把操作规则和经典汉诺塔对照：

| 汉诺塔（Hanoi） | 本题 |
|---|---|
| 一次只能移动某柱最顶上的一个盘 | 弹出栈 $A$ 的栈顶 |
| 大盘不许压在小盘上（即只能放到空柱或更大的盘上） | 规则 2：$B$ 空或 $x$ 比 $B$ 栈顶小 |
| 初始：$n$ 个盘按大小叠成一个塔（小的在上） | 栈 $4$：$1,2,\ldots,n$ 自顶向下（小的在上） |
| 目标：把整个塔挪到另一根柱 | 全部挪进栈 $1$ |

四条一一对应，因此

> **本题 = 用 $4$ 根柱子（栈 1 是目标柱、栈 4 是起始柱、栈 2/3 是辅助柱）移动 $n$ 个盘的「四柱汉诺塔」（Reve's puzzle），求最少步数 $M(n)$。**

这一步是整道题的钥匙：一旦认出是四柱汉诺塔，就可以直接搬用它的经典结论。

### 2.3 先做更简单的版本：三柱汉诺塔到底要几步

**引理 3（三柱汉诺塔最少步数 $=2^n-1$）**

若只能用 $3$ 个栈（起始、目标、$1$ 个辅助），把 $n$ 个元素整体从起始栈搬到目标栈，最少步数恰为 $2^n-1$。

**上界（可做到 $2^n-1$）**：经典递归算法——先把上面 $n-1$ 个搬到辅助柱（$2^{n-1}-1$ 步），把最大的搬到目标柱（$1$ 步），再把 $n-1$ 个搬回目标柱（$2^{n-1}-1$ 步）。设步数 $T(n)$，则 $T(n)=2T(n-1)+1$，$T(0)=0$，解得 $T(n)=2^n-1$。

**下界（做不到更少）**：记最大的元素为 $n$。关键观察：**$n$ 只能被压到空栈上**——因为任何非空栈的栈顶都小于 $n$（栈里全是比它小的元素），规则 2 不允许把 $n$ 压上去。于是：

- 考虑 $n$ 的**第一次移动**。要移动 $n$，它所在栈必须只有它一个元素（它是栈底，上面不能压任何东西，否则先得把它们挪走），而目标栈必须为空。
- 此刻另外两个栈里装着全部 $n-1$ 个小元素，且目标栈为空 $\Rightarrow$ 这 $n-1$ 个小元素**全部堆在同一个栈**上。（若它们分散在两个栈上，则两栈都非空，$n$ 无处可去。）
- 有两种情形：
  - **(i) 小元素全堆在「第三个栈」上，目标栈空**：$n$ 直接搬到目标栈。在这之前，$n-1$ 个小元素已被整批从起始栈搬到第三栈，这 $n-1$ 个元素的搬运（$n$ 始终原地不动，且任何小元素都可以压在 $n$ 上面，故它们的可移动性与「空柱三柱」完全一致）至少需要 $T(n-1)$ 步；在这之后，还需要把这 $n-1$ 个从第三栈整批搬到目标栈（压到 $n$ 上面），又至少 $T(n-1)$ 步。合计 $\ge 2T(n-1)+1$。
  - **(ii) 小元素全堆在目标栈上**：$n$ 只能先搬到第三栈。之后 $n$ 要到达目标栈，目标栈必须清空，即小元素须从目标栈整批搬回起始栈（$\ge T(n-1)$ 步），再让 $n$ 搬到目标栈（$1$ 步），最后把小元素从起始栈整批搬到目标栈（$\ge T(n-1)$ 步）；再加上一开始把小元素整批堆到目标栈的 $\ge T(n-1)$ 步，总计 $\ge 3T(n-1)+2\ge 2T(n-1)+1$。
- 两种情形都有 $T(n)\ge 2T(n-1)+1$。与上界合并得 $T(n)=2^n-1$。$\blacksquare$

### 2.4 推广到四柱：Frame–Stewart 递归

四柱比三柱多一根辅助柱，多出来的好处是：**搬「最大的若干块」时可以占一根空柱，把剩下的更小块先寄存到别处**。策略如下（记 $M(n)$ 为四柱搬 $n$ 个元素的最少步数）：

1. 把**最小的 $n-k$ 个**元素从起始栈搬到某辅助栈（此时 $4$ 根柱子都可用，代价 $M(n-k)$）；
2. 把**最大的 $k$ 个**元素从起始栈搬到目标栈——此时寄存小元素的那根柱被占，只剩 $3$ 根可用，代价 $2^k-1$（引理 3）；
3. 把寄存的 $n-k$ 个元素搬回目标栈，压到第 $n-k+1$ 号元素上（此时 $4$ 根柱子又都可用，代价 $M(n-k)$）。

于是得到经典递归

$$\boxed{\,M(0)=0,\qquad M(n)=\min_{1\le k\le n}\Big[\,2\,M(n-k)+2^{k}-1\,\Big].\,}$$

**上界：闭式恰好可取到。**

设 $T_t=\dfrac{t(t+1)}2$，对给定 $n\ge1$ 取唯一的 $b$ 使 $T_{b-1}<n\le T_b$（约定 $T_0=0$），令 $s=n-T_{b-1}\in[1,b]$。定义

$$g(n)=\big(b+s-2\big)\,2^{\,b-1}+1 .$$

**引理 4（$g$ 是递归的一个合法取值，且是上界）**

对所有 $n\ge1$，在上式递归中取 $k=b$（即用「三柱搬最大的 $b$ 个」），有 $2\,g(n-b)+2^{b}-1=g(n)$；从而 $M(n)\le g(n)$。

**证明**：只需验上述等式，分两种情形（记 $h=n-b$）：

- **$s=1$**：此时 $h=n-b=T_{b-1}+1-b=T_{b-2}$（用到恒等式 $T_{b-1}-b=T_{b-2}-1$，把 $s=1$ 代回）。$T_{b-2}$ 落在第 $b-2$ 段（$T_{b-3}<T_{b-2}\le T_{b-2}$），且它在第 $b-2$ 段中的偏移为 $T_{b-2}-T_{b-3}=b-2$，故
  $$g(h)=\big((b-2)+(b-2)-2\big)2^{\,b-3}+1=(2b-6)\,2^{\,b-3}+1=(b-3)\,2^{\,b-2}+1 .$$
  于是 $2g(h)+2^b-1=2(b-3)2^{b-2}+2^b+1=(b-3)2^{b-1}+2^{b-1}+1=(b-1)2^{b-1}+1$。而 $s=1$ 时 $g(n)=(b+1-2)2^{b-1}+1=(b-1)2^{b-1}+1$，相等。✓
- **$s\ge2$**：此时 $h=n-b$ 落在第 $b-1$ 段（因为 $T_{b-2}<h\le T_{b-1}-1<T_{b-1}$），它在第 $b-1$ 段中的偏移为 $h-T_{b-2}=(T_{b-1}+s-b)-T_{b-2}=(b-1)+s-b=s-1$。故
  $$g(h)=\big((b-1)+(s-1)-2\big)2^{\,b-2}+1=(b+s-4)\,2^{\,b-2}+1 .$$
  于是 $2g(h)+2^b-1=2(b+s-4)2^{b-2}+2^b+1=(b+s-4)2^{b-1}+2^{b-1}+1=(b+s-2)2^{b-1}+1=g(n)$。✓

再由强归纳：$g(0)=0=M(0)$，且若 $g(m)$ 对一切 $m<n$ 都可由某策略达成，则取 $k=b$ 的三步策略第 1、3 步各用 $g(n-b)$ 步、第 2 步用 $2^b-1$ 步（引理 3），合计 $2g(n-b)+2^b-1=g(n)$ 步，故 $g(n)$ 可由策略达成，$M(n)\le g(n)$。$\blacksquare$

> 直观地说：$b$ 增长得「尽量慢」（每段长度是 $b$），对应「尽量少地动用三柱段」，这正是 Frame–Stewart 的贪心选择。

### 2.5 下界：为什么不可能更快（定理引用）

**定理（Frame–Stewart 猜想在 4 柱时成立；Bousch 2014 给出严格证明）**

对任意 $n$，四柱汉诺塔的最少步数满足 $M(n)\ge g(n)$，即上界策略就是最优的，因此 $M(n)=g(n)$。

**为什么它难、以及我们如何面对它**：下界要说明「不存在任何巧妙的穿插调度能比三步式策略更快」。证明的核心思路与引理 3 的两情形分析一脉相承——盯住**最大元素 $n$ 的移动**：$n$ 只能搬进空栈（任何非空栈顶都小于它），所以每次搬 $n$ 都强制其余 $n-1$ 个小元素「整批让路」，把问题切分成若干段独立的「多柱搬运子问题」；再对所有可能的切分点做极值分析即可得到递归给出的那个下界。4 柱情形的完整论证（Bousch, *La quatrième tour de Hanoï*, 2014）篇幅很长，属研究级结论，本文按定理引用，不再展开其全部技术细节。

**我们做的独立验证**：对 $n=1,\ldots,10$ 用引理 2 的状态编码做**穷举 BFS** 求精确最少步数，与公式 $g(n)$ 逐点比对，**全部一致**（见 §4.5）。这至少在可达规模上以实验方式佐证了该定理。

### 2.6 把闭式再化简，便于 $O(1)$ 编码

用 $t=b-1$、$r=s-1$ 改写。由 $T_{b-1}<n\le T_b$ 得 $T_t\le n-1<T_{t+1}$（这里 $T_t\le n-1$ 且 $t$ 最大），即

$$t=\max\{\,t:\;T_t\le n-1\,\},\qquad r=(n-1)-T_t\in[0,\,t],\qquad M(n)=(t+r)\,2^{t}+1 .$$

验证：$n=4\Rightarrow m=3,\,t=2,\,r=0\Rightarrow M=2\cdot4+1=9$；$n=11\Rightarrow m=10,\,t=4,\,r=0\Rightarrow M=4\cdot16+1=65$；$n=15\Rightarrow m=14,\,t=4,\,r=4\Rightarrow M=8\cdot16+1=129$。与经典四柱汉诺塔数列 $1,3,5,9,13,17,25,33,41,49,65,81,97,113,129,\ldots$ 吻合。

### 2.7 取模与边界（写代码前的最后一次停顿）

- $t$ 满足 $T_t\le n-1\le2\times10^9$，故 $t=\Theta(\sqrt n)\le63245$，$t+r$ 更小（$r\le t$），用 `i64` 绝对够；$2^t$ 用快速幂模 $10^6+7$。注意 $10^6+7=1000007$，只做乘法取模，不依赖它是素数。
- $n=1$：$m=0,t=0,r=0\Rightarrow M=1$（正确：直接搬 $1$）。
- 求 $t$ 时用 `sqrt` 估算可能差 $1$，必须用两个 `while` 修正（先上顶再下压），避免浮点误差。
- $t(t+1)/2$ 与 $n$ 同量级，乘法用 `__int128` 或 `i64` 防溢出（$t\le63245$ 时 $t(t+1)/2\approx2\times10^9$，`i64` 足够，但 `__int128` 更稳）。

## 3. 模式总结（Pattern Summary）

按真实思考顺序，可迁移的标签：

- **explore its property** — 规则 2 把每个栈都锁成「自顶向下严格递增」，于是状态只由「元素分配到哪个栈」决定（引理 1、2），给出 $4^n$ 的暴力状态空间。
- **classic problem solution（识别模型）** — 对照汉诺塔四条规则，认出这是四柱汉诺塔 / Reve's puzzle，直接搬用其经典结论。
- **consider easier version** — 先解三柱汉诺塔，得到 $2^n-1$（引理 3），并顺手得到「最大元素只能进空栈」这一将在下界反复使用的结构事实。
- **generalize the easier version** — 把三柱的「最大元素让路」结构推广：三步式策略（小批存辅助柱、大批用三柱、再搬回）得到 Frame–Stewart 递归。
- **classic problem solution（递归→闭式）** — 对递归做极值分析，解出「分段闭式」$g(n)$（引理 4）。
- **prove the upper bound by induction** — 证明构造策略恰好花 $g(n)$ 步（引理 4 的全部证明）。
- **cite the hard lower bound** — 最优性即 Frame–Stewart 定理（4 柱情形，Bousch 2014），按定理引用。
- **verify by exhaustive search** — 用引理 2 的四进制状态编码做 BFS，在小 $n$ 上实验佐证定理。
- **O(1) closed form + modular exponentiation** — 用 $\sqrt n$ 定位分段、快速幂取模，$O(\log n)$。
- **guard floating-point sqrt** — 浮点估算的 $t$ 必须用 `while` 修正到精确值。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `i64` | 元素个数 | 读入 | 题面 |
| $m$ | `i64` | $n-1$ | $n-1$ | 定位分段用 $n-1$ 而非 $n$ |
| $t$ | `i64` | 最大的满足 $T_t\le n-1$ 的整数 | `sqrt` 估算后 `while` 修正 | $T_t=t(t+1)/2$，分段下标 |
| $T_t$ | `i64` | 三角数 $t(t+1)/2$ | 由 $t$ 算出 | 第 $t$ 段的右端点 |
| $r$ | `i64` | $(n-1)-T_t\in[0,t]$ | $m-T_t$ | 段内偏移 |
| $mod$ | `i64` | 取模常数 $10^6+7$ | `1000007` | 题面 |
| $ans$ | `i64` | $(t+r)\,2^t+1 \bmod mod$ | 计算 | 闭式 $g(n)$ 的取模 |

### 4.2 编号步骤

1. 读入 $n$；令 $m=n-1$。
2. 求 $t$：先置 $t=\left\lfloor\dfrac{\sqrt{8m+1}-1}{2}\right\rfloor$（浮点估算），再用 `while` 上顶、下压修正到 $T_t\le m<T_{t+1}$ 的精确值（用 `__int128` 比较防溢出）。
3. 令 $T_t=t(t+1)/2$，$r=m-T_t$。
4. 计算 $ans=\big((t+r)\bmod mod\big)\times \text{qpow}(2,t)\bmod mod\;+\;1$，再对 $mod$ 取一次模，输出。

> qpow 为标准快速幂 $O(\log t)$；$t=O(\sqrt n)$，整体 $O(\log n)$。

### 4.3 复杂度

- 时间：$O(\log n)$（快速幂）；求 $t$ 的浮点与修正为 $O(1)$。
- 空间：$O(1)$，无数组。

### 4.4 关键不变量

1. 全程 $t$ 必须精确满足 $T_t\le n-1<T_{t+1}$，浮点估算的偏差由两个 `while` 兜底。
2. 闭式只在 $m\ge0$（即 $n\ge1$）成立；$n=1$ 落到 $t=0,r=0$，得 $1$，正确。

| 逐点扫描 | **通过**：$n=1,\ldots,10$ 全部一致（覆盖了分段跳变 $t\to t+1$ 的所有边界） |
| 最坏规模计时 | $n=2\times10^9$ $\to$ 输出 $863060$，耗时 **$0.0052$ s** |
| 残余风险 | ① 下界（最优性）依赖 Frame–Stewart 定理，本文按定理引用而非完整自证；② 若评测机 `sqrt` 对极大值精度异常，靠 `while` 修正仍安全 |

## 5. 示例代码

> 与 `appendix/P1573/P1573.cpp` **逐字节一致**。

```cpp
//
// 题目：P1573 栈的操作
// https://www.luogu.com.cn/problem/P1573
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr i64 mod{1000007};   // 1e6+7

i64 qpow(i64 a,i64 b,i64 c=mod)
{
	i64 res=1;
	for(;b;b>>=1,a=a*a%c)
		if(b&1)
			res=res*a%c;
	return res;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	i64 n;
	cin>>n;
	// 设 t=max{t:t(t+1)/2<=n-1},r=(n-1)-t(t+1)/2,答案=(t+r)*2^t+1
	i64 m=n-1;
	i64 t=(i64)((sqrt((double)(8*m+1))-1)/2);
	while((__int128)(t+1)*(t+2)/2<=m)   // 浮点修正:上顶
		++t;
	while(t>0&&(__int128)t*(t+1)/2>m)   // 浮点修正:下压
		--t;
	i64 Tt=t*(t+1)/2;
	i64 r=m-Tt;
	i64 ans=(((t+r)%mod)*qpow(2,t)%mod+1)%mod;
	cout<<ans<<'\n';
	return 0;
}
```

### 5.2 对照实现：$4^n$ 状态 BFS（仅用于小 $n$ 对拍）

见 `appendix/P1573/P1573_brute.cpp`：用引理 2 把每个元素所在的栈号编进四进制数（第 $i$ 位 = 元素 $i$ 所在栈），从「全部在栈 $3$」BFS 到「全部在栈 $0$」。每步枚举「某栈的栈顶（该栈编号最小的元素）搬到另一空栈 / 搬到大元素之上」。$n\le10$ 时可跑，输出与闭式完全一致。

### 5.3 易错点清单

- **浮点 `sqrt` 直接当答案** $\Rightarrow$ 大 $n$ 时可能差 $1$，必须 `while` 修正（§4.4 第 1 条）。
- **用 $n$ 而非 $n-1$ 定位分段** $\Rightarrow$ $t$ 偏大、公式整段错位。
- **忘记取模 / 忘记对 $+1$ 也取模** $\Rightarrow$ 溢出或答案越界。
- **把「移到第一个栈」误解成要求把顺序翻转** $\Rightarrow$ 引理 1 强制最终排列仍是 $1,2,\ldots,n$，无翻转。
- **以为 $30\%$ 的 $n\le8$ 能用暴力过** $\Rightarrow$ $4^n$ 很快爆炸，全数据必须走公式。
