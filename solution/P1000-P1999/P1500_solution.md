# P1500 [CTSC2000] 丘比特的烦恼

> 标签：二分图带权匹配（KM） / 计算几何判定 / 字符串解析 · 难度：NOI+

## 1. 重新读题

**问题重述** 平面上 $2n$ 个人，前 $n$ 个男子 $M_1..M_n$、后 $n$ 个女子 $F_1..F_n$，各带整数坐标。丘比特选出 $n$ 对"男—女"每对射一箭，要求**每人恰被射中一次**（这是完美匹配，不是最大匹配，更不是"随便配几对"）；一对 $(M_i,F_j)$ 可射当且仅当同时满足两条几何限制：(射程) $\lvert P_iQ_j\rvert\le k$、(遮挡) 线段 $P_iQ_j$ 上没有**其他任何人**。目标是被射中的对的缘分之和最大。

缘分是"点对"属性，与几何无关：$p\le 255$ 的正整数，**未描述的一对默认缘分为 $1$**（不是 $0$，这条最容易读漏）。

**约束（本地题面全部信息）**

| 项 | 范围 | 出处 |
|---|---|---|
| $n$ | $1\le n\le 30$ | Hint |
| $p$ | 正整数，$\le 255$ | 输入格式 |
| 姓名 | 长度 $<20$，仅字母，忽略大小写 | 输入格式 |
| $k$、坐标 | 题面只说"正整数 / 一对整数"，**未给上界** | 输入格式 |
| 缘分行数 | 到 `End` 为止，每对至多描述一次 | 输入格式 |

$n\le30$ 这个量级本身就是解法提示：它大到否定"枚举排列 / 子集 DP"（§2.2 算过账），又小到让 $O(n^3)\sim O(n^4)$ 的 KM 秒杀。

**三处题面歧义与本文取舍**（外部提示与题面冲突时一律按本地题面，并在文中标注）

1. **信息行顺序**：题面先说"由姓名和位置两部分组成"，又给出"格式为 `x y Name`"，两句自相矛盾。→ 以显式格式串 `x y Name` 为准；代码用"首 token 是否字母"顺带兼容 `Name x y`（姓名只含字母、坐标必以数字或 `-` 开头，词法上完全可分，兼容零成本）。
2. **无解怎么办**：输出"仅一个正整数"，题面没有任何"No Solution"之类的说法（部分外部代码带该分支，**与本地题面冲突，按题面不实现**）→ 认定数据保证存在合法完美匹配，代码仅保留 `ans<0` 的自检语义（§2.6）。
3. **闭线段端点重合**：与端点坐标重合的第三人算不算"在线上"？→ 闭线段 + 按下标排除两端，即重合者视为遮挡（题面"线段上有别人"按字面成立；完全重合的坐标本是病态输入，两种约定几乎不改答案）。

本地题面**没有样例，无法与官方答案对标**，验证全靠 §4.4 的 5 组手算轨迹。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制：这道题的"合法边"是静态的

先把两个限制翻译成可判定的式子。设男子 $M_i$ 坐标 $A=(x_1,y_1)$，女子 $F_j$ 坐标 $B=(x_2,y_2)$，第三人 $C=(x_3,y_3)$。

- 射程：$\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}\le k$。
- 遮挡：$C$ 在线段 $AB$ 上。共线用叉积 $(B-A)\times(C-A)=0$，落在线段内用"坐标夹在两端之间"。

**引理 1（边集的独立性）**
一对 $(M_i,F_j)$ 是否可射，只由 $M_i,F_j$ 与其余 $2n-2$ 个人的**坐标**决定，与匹配方案的其他部分无关。因此全体可射对构成的二分图 $G$ 可以在读入后一次性算出。

**证明**：射程条件是两点距离与 $k$ 的比较，只涉及 $i,j$。遮挡条件的量词是"线段 $AB$ 上是否存在别人"，被检查的对象是输入给出的 $2n$ 个**固定点**，不含任何匹配信息：即对每个 $l\notin\{i,j\}$，判断 $C_l$ 是否共线且夹在中间，这些都是 $O(1)$ 的整数谓词。两条限制都不依赖"其他人配给了谁"，故可射性是点对 $(i,j)$ 的二元谓词，$E=\{(i,j): \text{可射}(i,j)\}$ 是固定的。$\blacksquare$

> 引理 1 看着平淡，其实是本题**从"几何题"降级为"图论题"的那一步**。反面更能说明问题：若题面还要求"箭不能交叉"，遮挡/相交就依赖整个方案（两条线段是否相交是配对之间的性质），无法先固定边集，问题会难得多（带约束的一般图匹配）。题面**只**禁止线段上"有人"，没禁止线段相交——两张弓的箭可以随便交叉。确认这个差别比记算法更重要。

遮挡判定的等价性要单独证明，否则后面用矩形夹逼会心虚。

**引理 2（共线 + 夹逼 $=$ 在闭线段上）** $C$ 在闭线段 $AB$ 上，当且仅当

$$(x_2-x_1)(y_3-y_1)=(y_2-y_1)(x_3-x_1)\ \wedge\ \min(x_1,x_2)\le x_3\le\max(x_1,x_2)\ \wedge\ \min(y_1,y_2)\le y_3\le\max(y_1,y_2).$$

**证明**：（$\Rightarrow$）$C=A+\lambda(B-A)$，$\lambda\in[0,1]$，代入叉积得 $(x_2-x_1)\lambda(y_2-y_1)-(y_2-y_1)\lambda(x_2-x_1)=0$；$x_3,y_3$ 是端点坐标的凸组合，必在两者之间。
（$\Leftarrow$）记 $u=B-A,\,v=C-A$，叉积为 0 即 $u_xv_y=u_yv_x$。若 $u\ne\mathbf0$，取非零分量（设 $u_x\ne0$）令 $\lambda=v_x/u_x$，则 $v_y=u_yv_x/u_x=\lambda u_y$ 且 $\lambda u_x=v_x$，故 $v=\lambda u$，即 $C=A+\lambda(B-A)$；再由 $x_3$ 夹在 $x_1,x_2$ 之间得 $|\lambda|\le1$ 且分子分母同号使 $\lambda\ge0$，于是 $\lambda\in[0,1]$，$C$ 在闭线段上（$u_x=0$ 时改用 $y$ 分量同理，夹逼条件对 $y$ 也成立）。若 $u=\mathbf0$（$A,B$ 重合）：叉积恒 0，夹逼化为 $x_3=x_1$ 且 $y_3=y_1$，即 $C=A=B$，而单点集 $\{A\}$ 正是退化线段，结论仍成立。$\blacksquare$

**引理 3（射程用整数平方比较，不用 `sqrt`）** $d\le k\iff (x_1-x_2)^2+(y_1-y_2)^2\le k^2$，两边皆整数。

**证明**：$d\ge0$，$t\mapsto t^2$ 在 $[0,+\infty)$ 严格单调，故 $d\le k\iff d^2\le k^2$；而 $d^2$ 是整数运算，无舍入。$\blacksquare$

> 写成 `sqrt(dx*dx+dy*dy)<=k` 会在"$d$ 恰等于 $k$"的边界上翻车：$A=(0,0),B=(6,8),k=10$ 真值恰为 $10$，**应判可射**，浮点却可能算出 $10.000000000000002$。整数平方比较从根上消灭这类错误（§4.4 用例 A 就是这条边界）。

### 2.2 简化版：先在小 $n$ 上把问题想透

**$n=1$**：只有一对，可射就输出缘分值（未描述则 $1$），不可射就无解。这一层告诉我：输出的是**缘分之和**而不是对数，且默认值 $1$ 意味着合法答案 $\ge n$。

**$n=2$**：只有 $2!=2$ 种配法，可枚举。我把 $n=2$ 的所有情形在草稿纸上过了一遍，发现关键现象：**一个对能不能要，取决于另一对怎么选**（每人只能用一次），所以"逐个取最大"天然不成立——这正是 2.3 节反例的病根。$n=3$ 有 $6$ 种，仍可枚举。

**一般 $n$ 的两条朴素账**：枚举排列 $n!=30!\approx2.65\times10^{32}$；子集 DP $dp[S][i]$ 要 $n\cdot2^n\approx3.2\times10^{10}$ 次转移、$2^{30}$ 个 `int`（约 $4\ \text{GB}$）。两条都不可行，而且题面没有任何 $n$ 更小的子任务提示可以蒙混。

于是方向被夹死：**必须是关于 $n$ 的多项式算法**，而结构是"二分图 $+$ 每点度恰为 1 $+$ 权和最大"。这三个关键词直接指向**二分图最大权完美匹配**（KM / Hungarian）。$n=30$ 时 $O(n^4)=8.1\times10^5$，几何预处理 $O(n^3)$（$n^2$ 对、每对扫 $2n$ 人），都轻到不必优化。

### 2.3 剖析贪心失败：局部最优会锁死全局最优

最自然的猜想是：**把所有可射对按缘分从大到小排序，依次取"双方都还没配对"的对**。这在带权匹配里叫贪心（也叫"最大边优先"）。给一个彻底的反例。

**反例 1（纯权值分歧，几何全部放行）**

取 $n=2$，$k=5$，四个人坐标（保证任意男女连线段上都没有第三人，且两两距离 $\le\sqrt{18}<5$）：

```
M1=(0,0)  M2=(0,3)  F1=(3,0)  F2=(3,3)
```

逐条核查遮挡（$k=5$，四条线段方向如下，其余三人叉积均非 0）：$M_1F_1$ 方向 $(3,0)$，$M_2,F_2$ 的 $y=3$ 给叉积 $9$；$M_1F_2$ 方向 $(3,3)$，$M_2$ 给 $9$、$F_1$ 给 $-9$；$M_2F_1$ 方向 $(3,-3)$，$M_1$ 给 $-9$、$F_2$ 给 $9$；$M_2F_2$ 方向 $(3,0)$，$M_1,F_1$ 的 $y=0$ 但 $x$ 处叉积 $-9$。最远距离 $\sqrt{18}<5$。故四条边**全部合法**，图是 $K_{2,2}$，缘分取 $w=[[\,10,9],[9,1\,]]$（无未描述项）。

- 贪心：先取 $M_1F_1$（10），剩下 $M_2,F_2$ 只能互配 $1$，总 $11$。
- 最优：$M_1F_2+M_2F_1=9+9=18$。**贪心错得明明白白。**

**引理 4（贪心的近似比恰为 $2$，且该界紧）** 记"按边权降序、双方未占用就取"为 $\text{GRE}$，最优完美匹配为 $\text{OPT}$，权值全为正。则 $\text{OPT}\le2\,\text{GRE}$，且存在合法实例使比值任意接近 $2$。

**证明（上界）** 矩阵完备时贪心每步都能取到边，取出的 $n$ 条边构成完美匹配 $G$（§2.6）。给 $\text{OPT}$ 的每条边 $e'$ 指派"责任边"$e^*(e')$：$G$ 中与 $e'$ 共享至少一个端点、且在降序处理中**最早被考虑**的那条。
- *$e^*$ 不早于 $e'$ 被处理*：$e'$ 未被接受，说明轮到它时它的某个端点已被某条已接受的边占用，那条边比 $e'$ 更早处理、且与 $e'$ 共享端点，故这样的边存在，最早的 $e^*$ 满足 $w(e^*)\ge w(e')$（降序）。
- *每根 $e\in G$ 至多接两条 $e'$*：$\text{OPT}$ 是匹配，与 $e=\{u,v\}$ 共享端点的 $\text{OPT}$ 边只能在 $u$ 处一条、$v$ 处一条。

于是 $\text{OPT}=\sum_{e'}w(e')\le\sum_{e\in G}\sum_{e^*(e')=e}w(e)\le\sum_{e\in G}2w(e)=2\,\text{GRE}$，第一个不等号用 $w(e')\le w(e^*(e'))$，第二个用"至多两条"。

**证明（紧性）** 取 $n=3$，六点放在抛物线 $y=x^2$ 上：$M_1=(0,0),M_2=(1,1),M_3=(2,4)$，$F_1=(3,9),F_2=(4,16),F_3=(5,25)$，$k=26$。直线与抛物线至多两交点，故**无三点共线** → 遮挡条件全体通过；最远一对 $M_1F_3$ 有 $25+625=650\le676=k^2$ → 射程也全体通过，图是 $K_{3,3}$。令 $w(M_1,F_1)=w(M_1,F_2)=w(M_2,F_1)=B$，其余 $=1$。
- 贪心：$B$ 档三边并列，**任何固定的并列打破规则**都可由重命名顶点让 $M_1F_1$ 排在最前；接受它之后 $M_1F_2,M_2F_1$ 端点被占作废，$M_2,M_3$ 各取一条权 $1$ 边，$\text{GRE}=B+2$。
- 完美匹配 $\{M_1F_2,M_2F_1,M_3F_3\}$ 合法，$\text{OPT}\ge2B+1$，比值 $\frac{2B+1}{B+2}\to2$。本题 $B\le255$，取 $B=255$ 得 $\text{GRE}=257,\text{OPT}=511$，比值 $1.988\ldots$。$\blacksquare$

> 病灶不是"顺序选错了"，而是贪心无法处理"**每条边的取舍同时占用两个顶点的配额**"这种耦合约束——对偶顶标正是为此而生。而本题要精确整数，连"差 2 倍"都不可接受。

还有一个更隐蔽的失败模式：**几何遮挡能让"缘分最高的对"根本不合法**。

**反例 2（遮挡否决大边）**

$n=2$，$k=10$，$M_1=(0,0),M_2=(1,0),F_1=(2,0),F_2=(0,5)$，缘分行只给 `M1 F1 255`，其余默认 $1$。逐边判定：

- $M_1F_1$：线段 $\{(x,0):0\le x\le2\}$，$M_2=(1,0)$ 共线（方向 $(2,0)$，叉积 $2\cdot0-0\cdot1=0$）且夹在中间 → **禁止**，哪怕它缘分 $255$。
- $M_1F_2$：$\{(0,y):0\le y\le5\}$，$M_2,F_1$ 的 $x>0$ → 合法。
- $M_2F_1$：$\{(x,0):1\le x\le2\}$，$M_1,F_2$ 的 $x=0$ 不在闭区间内（共线但夹逼失败）→ 合法。
- $M_2F_2$：方向 $(-1,5)$，$M_1$ 叉积 $5$、$F_1$ 叉积 $-5$，均不共线 → 合法。

于是**只有一条**不含禁止边的完美匹配 $M_1F_2+M_2F_1$，答案 $=1+1=2$；任何"先取 255"的做法直接给出非法方案。**结论：候选边必须先过几何过滤，再谈权值顺序。**

### 2.4 归约：这是一个指派问题（assignment problem）

模型完全清楚了。决策变量 $x[i][j]\in\{0,1\}$ 表示"$M_i$ 与 $F_j$ 被射中"，则

$$\max\sum_{i,j}w[i][j]\,x[i][j]\quad\text{s.t.}\quad \sum_j x[i][j]=1\ (\forall i),\ \ \sum_i x[i][j]=1\ (\forall j),\ \ x\in\{0,1\}.$$

其中 $w[i][j]$ 取缘分还是取"禁止"，由 §2.1 的谓词决定。**这就是带权二分图完美匹配 / 指派问题**，两条常规出路：

1. **KM（Kuhn–Munkres）**：顶标 + 相等子图 + 增广路，$O(n^3)\sim O(n^4)$，代码约 40 行，$n=30$ 秒杀。
2. **最小费用最大流**：源→男（容量 1 费用 0）、女→汇（同）、合法男女边（容量 1 费用 $-p$），跑 SPFA 版 MCMF 并检查流量是否 $=n$。同样够快，但代码量与出错率高得多。

选 KM。但 KM 有一个**使用前提必须先处理**，否则写出来是死循环而不是 WA——见 §2.6。顺带一提，指派问题的 LP 约束矩阵全单模，LP 松弛的顶点自动取整数，其对偶正是"给每个顶点一个价格 $\ell$，使 $\ell_i+m_j\ge w[i][j]$ 且总价最小"；**KM 的顶标就是这个对偶解**，这不是巧合，而是 §2.5 全部证明的骨架。

### 2.5 经典解法：KM —— 用"顶标"把权值问题变成 0-1 问题

**定义（可行顶标 / 相等子图）** 给每个顶点一个数：男子 $lx[i]$、女子 $ly[j]$。若对所有 $i,j$ 有 $lx[i]+ly[j]\ge w[i][j]$，称 $(lx,ly)$ **可行**；相等子图 $E_q=\{(i,j):lx[i]+ly[j]=w[i][j]\}$。初始取 $lx[i]=\max_j w[i][j]$、$ly[j]=0$，则 $lx[i]+ly[j]=\max_{j'}w[i][j']\ge w[i][j]$ 恒成立 ✓（这也是"矩阵必须完备"的第一个理由：$\max$ 必须取得到，见 §2.6）。

**引理 5（弱对偶）** 若 $(lx,ly)$ 可行、$M$ 是**完美**匹配，则 $\sum_{(i,j)\in M}w[i][j]\le\sum_i lx[i]+\sum_j ly[j]$。

**证明**：逐边用可行性得 $\sum_M w\le\sum_M(lx[i]+ly[j])$。右端按顶点数：$M$ 完美 $\Rightarrow$ 每个男子、每个女子都恰作为一条边的端点出现**一次**，故 $\sum_M(lx[i]+ly[j])=\sum_i lx[i]+\sum_j ly[j]$。$\blacksquare$

> "完美"二字不可省：若 $M$ 只是普通匹配，未匹配的顶点不出现在右端，而本题禁止边会让标号取**负值**（§2.6），"部分和 $\le$ 全和"就不再成立。条件必须点名——这正是"跳步"与"完整证明"的差别。

**引理 6（互补松弛 $=$ 最优判据）** 若完美匹配 $M$ 的全部边都在相等子图里，则 $M$ 是最大权完美匹配。

**证明**：由假设 $\sum_M w=\sum_M(lx[i]+ly[j])=\sum_i lx[i]+\sum_j ly[j]$；对任意完美匹配 $M'$，引理 5 给 $\sum_{M'}w\le\sum_i lx[i]+\sum_j ly[j]=\sum_M w$，故 $M$ 最优。$\blacksquare$

于是"求最大权完美匹配"被换成"**调整顶标，直到相等子图里出现完美匹配**"。

**引理 7（调整保持可行，且严格放大相等子图）** 设 $(lx,ly)$ 可行，$S,T$ 是某次**失败**增广搜索访问到的男子集、女子集。取 $d=\min\{lx[u]+ly[v]-w[u][v]:u\in S,\,v\notin T\}$，令 $lx[u]-=d\,(u\in S)$、$ly[v]+=d\,(v\in T)$，则调整后仍可行。

**证明**：先证 $d$ 良定、$d\ge0$。① $\{v:v\notin T\}$ 非空：搜索中除根 $i$ 外，$S$ 里每个男子都是通过"它当前匹配到的女子"进树的，故 $T\ni v\mapsto mt[v]\in S\setminus\{i\}$ 是单射（失败的搜索里被访问的女子必已匹配，否则当场就增广成功），于是 $|T|\le|S|-1\le n-1<n$。② $u\in S,v\notin T$ 时 $lx[u]+ly[v]-w[u][v]\ge0$（可行性；它也不等于 $0$，否则 $v$ 早被访问）。故 $d\ge0$ 且对**所有**这类点对成立 $d\le lx[u]+ly[v]-w[u][v]$。

再按 $(u\in S?,v\in T?)$ 四类检查约束 $lx[u]+ly[v]\ge w[u][v]$：$S\times T$ 变化 $-d+d=0$（不变 ✓）；$S\times\bar T$ 变化 $-d$，由上式 $d\le lx+ly-w$ 知调整后仍 $\ge w$ ✓；$\bar S\times T$ 变化 $+d$（变松 ✓）；$\bar S\times\bar T$ 变化 $0$ ✓。四类覆盖全部点对，故可行。又取到 $d$ 的那对 $(u^*,v^*)$（有限集合上最小必取得）调整后满足 $lx[u^*]+ly[v^*]=w[u^*][v^*]$，即它**新进入相等子图**；而 $S\times T$ 内原有相等边一条不丢（第一类变化为 0）。$\blacksquare$

**引理 8（终止性：每个根至多失败 $n$ 次）** 按引理 7 反复"搜索—调整"，固定根 $i$ 的失败搜索次数 $\le n$。

**证明**：记第 $r$ 次失败的访问集为 $S_r,T_r$；第 $r+1$ 次搜索从同一个根出发，访问集是相等子图中从根可达的**极大**集合。对 $S_r$ 按搜索树层次归纳：根 $i\in S_{r+1}$；若 $u\in S_r$ 已属于 $S_{r+1}$，树中从 $u$ 指向的每条相等边 $(u,v)$ 满足 $v\in T_r$ 且（引理 7 第一类）调整后仍相等，故 $v\in T_{r+1}$；若 $v\in T_r$，其匹配边把它带回 $mt[v]\in S_r$，同样被递归访问。故旧树整体保留，$S_r\cup T_r\subseteq S_{r+1}\cup T_{r+1}$。再由引理 7 末句，新相等边 $(u^*,v^*)$ 的 $u^*\in S_{r+1}$ 而 $v^*\notin T_r$，搜索会访问它，故 $|T_{r+1}|\ge|T_r|+1$。$|T|\le n$，故失败次数 $\le n$。$\blacksquare$

**引理 9（算法正确）** 过程结束时 $mt[\cdot]$ 给出最大权完美匹配。

**证明**：外层每轮为当前**未匹配**的男子 $i$ 增广成功一次（前面的轮次只动已匹配男子，$i$ 此刻自由），$n$ 轮后 $n$ 个男子两两不同地匹配到 $n$ 个女子，得完美匹配 $M$。剩下要确认引理 6 的前提在**结束时**仍成立：增广放入的匹配边当时满足 $lx[u]+ly[v]=w[u][v]$，后续调整会不会让它退出相等子图？关键观察：对任意匹配边 $(u,v)$，$v$ 被访问当且仅当 $u$ 通过这条匹配边被访问，即 $v\in T\iff(mt[v]=u\in S\setminus\{\text{根}\})$；而根在当前增广中是自由男子，不携带匹配边入树。所以匹配边只会落在"两端同属 $S,T$"（变化 $-d+d=0$）或"两端同属树外"（变化 $0$）两类里，$lx+ly$ **恒不变**；"单边进树"的另两类对匹配边不可能发生。故每条匹配边自进入匹配起一直在相等子图中，$M\subseteq E_q$，由引理 6 得 $M$ 最优。$\blacksquare$

> "匹配边不会单边进树"是 KM 证明里最常被一句"显然"糊掉的地方，写清楚它，引理 6 的前提才真的在算法结束时成立。

**复杂度**：外层 $n$ 轮；每轮失败 $\le n$ 次（引理 8）；每次 `aug` 至多访问 $n$ 个男子、各扫 $n$ 个女子 $=O(n^2)$；每次调整 $O(n)$。合计 $O(n^4)$，$n=30$ 时 $8.1\times10^5$。若在调整间**不重置** $vis$ 并让 $slack$ 随 $d$ 递减可到经典 $O(n^3)$；本题规模不需要，而"每轮重算 slack"的写法恰好与引理 7、8 的论证一一对应，更好证明。

### 2.6 关键工程决策：禁止边不能"删掉"，要压成 $-M$

先记录一个真实会踩的坑。设 $G$ 只含合法边，把 $w$ 初始化为"合法取缘分、非法不存在"。那么：

- 初始顶标 $lx[i]=\max_{j:(i,j)\in E}w[i][j]$，若某男子**一条合法边都没有**，$\max$ 取不到（$lx[i]$ 只能是 $-\infty$ 或垃圾值）。
- 更致命的是引理 7 里的 $d$：若存在 $u\in S$ 而 $v\notin T$ **之间没有合法边**，$lx[u]+ly[v]-w[u][v]$ 这个量根本没有定义。代码里通常把不存在的边写成 $-\infty$，于是 $d=+\infty$，$lx$ 全变成 $-\infty$，`while(true)` 永远退不出——**死循环，不是 WA**。

所以：**权值矩阵必须完备**（$n\times n$ 全填数）。禁止边给它一个足够小的常数 $-M$：

**引理 10（哨兵取值）** 设 $M=10^6$，令非法边 $w[i][j]=-M$，合法边 $w[i][j]=p[i][j]\in[1,255]$。若存在全合法的完美匹配，则 $w$ 上的最大权完美匹配必然不含任何非法边。

**证明**：任一含 $\ge1$ 条非法边的完美匹配，权值 $\le-M+(n-1)\cdot255=-10^6+29\cdot255=-992605$；任一全合法完美匹配权值 $\ge n\cdot1=30$。$-992605<30$，故含非法边的匹配永不最优。$\blacksquare$

**为什么 $M$ 不取 $10^{18}$？** KM 全程要做 $lx+ly-w$ 与 $\pm d$ 的加减。取哨兵 $-\mathrm{BIG}$ 时单步 $t$ 可达 $2\,\mathrm{BIG}$，而 $ly$ 每轮调整加 $d\le2\,\mathrm{BIG}$，一轮增广最多 $n$ 次调整，故 $|ly|$ 最坏可达 $2n\,\mathrm{BIG}$；$\mathrm{BIG}=10^{18}$ 时这是 $6\times10^{19}$，早在 $9.22\times10^{18}$ 之外，溢出成负数后顶标"越调越大"，行为完全不可预测。通用原则是：**哨兵要比答案量级大得多，又要比类型容量小得多**。$M=10^6$ 相对上界 $30\cdot255=7650$ 大一百多倍，相对 $9.22\times10^{18}$ 小一万七千倍，两头都安全。

**顶标数值界**（说明 `int` 存 $w$、`i64` 存标号绰绰有余）：记 $D=\sum_i lx[i]+\sum_j ly[j]$。每次调整改变 $-|S|d+|T|d=-(|S|-|T|)d$，由引理 7 的 $|T|\le|S|-1$ 知 $D$ 严格不增；初值 $D\le n\max w\le7650$（某行全为 $-M$ 时 $D$ 可为负，但下界 $-30M=-3\times10^7$）。又 $ly$ 单调不减、$lx$ 单调不增且 $lx[i]\ge-M$（$lx$ 只会降到让某条边相等，而 $w\ge-M$），故 $ly[j]\le D_{\text{初}}-\sum_i lx[i]\le7650+3\times10^7$。所有标号落在 $|\cdot|\lesssim4\times10^7$，`int` 都够，用 `i64` 只是把"以后把 $M$ 调大"的风险消掉。

**无解检测**：题面保证有解（§1 取舍 2），代码保留自检语义——若 $ans<0$，说明最优匹配里含 $-M$ 边，即几何上不存在合法完美匹配；题面没规定这种输出，程序直接把负数打出去当本地调试信号（§4.4 用例 D）。

### 2.7 溢出与精度防护（三道防线）

**防线 1：距离平方比较，且在 `__int128` 里乘。** 代码写 `(__int128)dx*dx+(__int128)dy*dy>(__int128)k*k`。两个易错点：`dx*dx+dy*dy<=k*k` 全程在 `int` 里算，$2^{31}$ 立刻爆；`(i64)(k*k)` 的括号里仍是 `int` 乘法，$k\ge46341$ 就溢出——**强转必须发生在乘之前**。题面未给坐标范围：按 $|coord|\le10^9$ 估，平方和 $\le8\times10^{18}$ 勉强在 `i64` 内，但坐标取满 32 位时差可达 $4.3\times10^9$，平方 $1.8\times10^{19}$ 直接越界，所以两处几何乘法统一用 `__int128`（风格规范明确允许裸用 `__int128` 作中间量），代价仅 $n^2=900$ 次 128 位乘法，免费。

**防线 2：共线用叉积等式，不用斜率、不用 `double`。** 斜率式要讨论分母为 0；叉积式 $(x_2-x_1)(y_3-y_1)=(y_2-y_1)(x_3-x_1)$ 是纯整数等式，退化情形 $A=B$ 已由引理 2 单独覆盖，不需要 `eps`。

**防线 3：KM 的减法不碰 `unsigned`，$t,d,slack$ 同类型。** `t=lx[u]+ly[v]-w[u][v]` 中 `int` 的 `w` 被提升为 `i64`，禁止边取负也无符号问题；若把 $t$ 存成 `int`，它可达 $lx+ly+M\approx4\times10^7$，`int` 侥幸够但 $M$ 一改就炸，故代码里 $lx,ly,slack,d,t$ 一律 `i64`。答案本身 $\le30\times255=7650$ 不会溢出，但为与负哨兵共存，`ans` 也 `i64`。

### 2.8 输入解析的坑（2000 年的老题，坑比算法多）

1. **信息行顺序**：按 §1 取舍 1，读三个 token 后看首字符——字母打头是 `Name x y`，数字/`-` 打头是 `x y Name`。`isalpha` 前必须 `(unsigned char)` 转换，否则负 `char` 是 UB。
2. **姓名忽略大小写**：所有姓名（信息行与缘分行两端）统一 `low()` 归一后再比对；漏掉这步，`Alice` 与 `ALICE` 会被当两个人，缘分全丢。`tolower` 同样要 `unsigned char`。
3. **`End` 判停**：用 `while(cin>>A&&A!="End")` 再读 `B,p`，比 `while(cin>>A>>B>>p)` 稳（后者遇到 `End` 会在 `B,p` 上读入失败值继续跑循环体）。`End` 只出现在行首，故它只会落在 $A$ 的位置。
4. **未描述的一对缘分 $=1$ 而不是 $0$**：先把 `af` 全填 1 再用输入覆盖。填 0 会同时改小合法边权与某些行的 $\max$ 初值（$lx$ 变了），答案数值直接错——这是"读题不细就 WA"的教科书案例。
5. **缘分行可能是同性别**：题面只说"Name1 Name2 为有缘人"，没保证一男一女。查下标后把 $\ge n$ 的那个 `swap` 到后面，只有"一男一女"才写 `af[男][女-n]`，否则丢弃（同性别 pair 对本匹配无意义）。见 §4.4 用例 E。
6. **重名**：题面未保证姓名唯一，但缘分表按姓名索引，真重名则输入本身有歧义。按"数据保证唯一"处理（`id()` 返回首个匹配），并在 §4.4 缺口里挂账。

## 3. 模式总结（Pattern Summary）

**本题的套路是四段式：几何谓词 → 权值矩阵 → 指派模型 → KM。**

| 段 | 做什么 | 关键判据 | 出错代价 |
|---|---|---|---|
| ① 过滤 | 把"能不能射"化成 $n^2$ 个布尔值 | 平方距离 + 叉积共线 + 矩形夹逼（引理 2、3） | 用 `sqrt`/斜率 → 边界数据 WA |
| ② 建矩阵 | $w[i][j]=$ 缘分（默认 1）或哨兵 $-M$ | 矩阵**必须完备**（§2.6） | 删边 → KM 死循环 TLE |
| ③ 建模 | 认出"带权二分图完美匹配" | 每人恰一次 $+$ 权和最大 $+$ 无交叉限制 | 误当普通最大匹配（可以不配满）→ 答案错 |
| ④ 求解 | KM，$O(n^4)$，$n\le30$ | 顶标可行性是全部证明的支点 | `slack` 与 `vis` 重置口径不一致 → 证明失效 |

**什么时候该想到 KM？** 三条同时成立就是指派问题：(1) 两套等规模对象（男/女、工人/任务、机器/作业）；(2) 一对一且**必须配满**；(3) 目标权和最大或最小。规模落在 $n\le30\sim500$ 这个"比状压小、比贪心复杂"的区间，是 KM / 费用流的典型 signal。

**最小权版本**：KM 是最大权版，求最小权时常令 $w:=C-w$（$C$ 取足够大常数）转成最大权，或直接对偶取负；本题天然最大权，不需转换。

**同类题清单（按结构归类）**

- 模板类：`P6577`【模板】二分图最大最优匹配（题号凭印象，未联网核对；$n$ 更大，需要严格 $O(n^3)$ 的 KM 或费用流）。
- 镜像类：把 $p$ 换成代价就是最小权指派，用 $C-w$ 转换。
- 几何过滤类：一切"视线可见性 / 两点之间有无障碍"，共同点是**共线用叉积等式、区间用夹逼**，绝不引入浮点。
- 老题解析类：`End` 结尾、姓名索引、大小写不敏感，范式是"先归一再查表，先读 token 再判停"。

**可复用检查表**

1. 题面的限制是"点对"性质还是"方案"性质？前者能预处理成边（引理 1），后者不能直接建图。
2. 算法要不要"完备矩阵 / 全点参与"？要就用哨兵补全，并证明哨兵够大又不爆（引理 10）。
3. 有没有取等边界（距离恰为 $k$、点恰在线段端点）？有就上整数判据并单独证明退化情形（引理 2）。
4. 对偶证书在哪？KM 结束时 $\sum lx+\sum ly$ 就是答案的上界证书，可手算核对最优性（§4.4 用例 B 正是这么验证的）。

### 4.2 编号步骤

- **S1 读入全局**：`k`、`n`。
- **S2 读 $2n$ 行个人信息**：三个 token；按首字符是不是字母决定 `Name x y` 还是 `x y Name`（§2.8-1），坐标入 `px,py`，姓名 `low()` 后入 `nm`。
- **S3 缘分矩阵初始化**：`af[i][j]=1`（§2.8-4）。
- **S4 读缘分流水直到 `End`**：`while(cin>>A&&A!="End")` 后 `cin>>B>>p`；`id(low(A)),id(low(B))` 查下标，查不到就跳过；必要时 `swap` 成"男在前"，只有一男一女才写 `af[男][女-n]=p`（§2.8-5）。
- **S5 几何过滤建权值矩阵**：对每个 $(i,j)$，`shootable(i,n+j)` 判定——先平方距离 $\le k^2$（`__int128`，§2.7-1），再对 $l=0..2n-1$ 用 `onSeg(l,a,b)`（叉积共线 + 矩形夹逼，按下标排除两端，引理 2）；合法取 `af`，非法取 `bad`。**这一步就是引理 1 的落地**。
- **S6 初始化顶标**：`lx[i]=max_j w[i][j]`，`ly[j]=0`，`mt[j]=-1`。可行性由 §2.5 定义处一句话验证（矩阵完备保证 $\max$ 取得到）。
- **S7 KM 主循环**：对每个男子 $i$：反复"清空 $S,T$、清空 `slack` → `aug(i)` → 若失败则取 $d=\min_{j\notin T}slack[j]$ → $lx[S]\mathrel{-}=d,\ ly[T]\mathrel{+}=d$"直到增广成功。$d$ 良定（引理 7：$|T|\le|S|-1<n$），失败次数 $\le n$（引理 8），每轮 $O(n^2)$。
- **S8 汇总输出**：`ans = Σ_j w[mt[j]][j]`，打印 `ans`。若 `ans<0`，等价于"最优匹配含哨兵边"，即几何上无合法完美匹配（题面保证不发生，§1 取舍 2）。

| 阶段 | 复杂度 | $n=30$ 上界 |
|---|---|---|
| 姓名查找 `id` | $O(n)$ 每次，共 $O(\text{行数}\cdot n)$ | 线性，行数无界但受输入文件大小限制 |
| S5 几何过滤 | $O(n^2\cdot 2n)=O(n^3)$ | $5.4\times10^4$ 次判定 |
| S7 KM（重置版） | $O(n\cdot n\cdot n^2)=O(n^4)$ | $8.1\times10^5$ |
| 空间 | $O(n^2)$ 矩阵 + $O(n)$ 标号 | $2\times35^2$ 个 `int` |

内存占用不到 $20\ \text{KB}$，时间对 $n=30$ 而言微不足道；因此**不需要**把 KM 优化到 $O(n^3)$（不重置 `vis`、`slack` 随 $d$ 递减的写法），保留可证明性的朴素版更划算。

  S6/S7：$lx=[1],ly=[0]$。$i=0$：`aug(0)`：$v=0$，$t=1+0-1=0$ → $mt[0]=0$，成功，一次通过。
  S8：$ans=w[0][0]=1$ ✓（满足下界 $n\cdot1=1$）。

- **用例 B（$n=2$，贪心反例，完整 KM 轨迹）** — 期望 `18`（贪心只会给 11）
  输入：`5 / 2 / 0 0 M1 / 0 3 M2 / 3 0 F1 / 3 3 F2 / M1 F1 10 / M1 F2 9 / M2 F1 9 / M2 F2 1 / End`，权值矩阵 $w=\begin{pmatrix}10&9\\9&1\end{pmatrix}$（几何四条边全合法，§2.3 已逐条叉积验证）。
  初值：$lx=[10,9]$，$ly=[0,0]$，$mt=[-1,-1]$。
  $i=0$：`aug(0)` 扫 $v=0$：$t=10+0-10=0$ → $mt[0]=0$，成功。
  $i=1$：
  - 第 1 次 `aug(1)`：$v=0$：$t=9+0-9=0$ → $visy[0]=1$，$mt[0]=0$ → 递归 `aug(0)`：$v=0$ 已访问跳过；$v=1$：$t=10+0-9=1\ne0$ → $slack[1]=1$；返回 false。回到 `aug(1)` 的 $v=1$：$t=9+0-1=8$ → $slack[1]=\min(1,8)=1$；返回 false。
    失败，$S=\{0,1\},T=\{0\}$，$d=slack[1]=1$（$|T|=1\le|S|-1$ ✓ 引理 7）。
  - 调整：$lx=[9,8]$，$ly=[1,0]$。
  - 第 2 次 `aug(1)`（$vis$、$slack$ 全部重置）：$v=0$：$t=8+1-9=0$ → $visy[0]=1$ → 递归 `aug(0)`：$v=1$：$t=9+0-9=0$ → $visy[1]=1$，$mt[1]<0$ → $mt[1]=0$ 返回 true → $mt[0]=1$ 返回 true，成功。
  结果 $mt=[1,0]$：$F_1\!\leftarrow\!M_2,\ F_2\!\leftarrow\!M_1$，$ans=w[1][0]+w[0][1]=9+9=18$ ✓。
  **最优性证书**：$\sum lx+\sum ly=9+8+1+0=18=ans$，与引理 5、6 的弱对偶吻合；且逐点核对可行性 $10\ge10,\ 9\ge9,\ 9\ge9,\ 8\ge1$ 全部成立 ✓。这一步是我在没有官方样例的情况下确认答案的**主要手段**。

- **用例 C（$n=2$，遮挡否决最大边）** — 期望 `2`
  输入：`10 / 2 / 0 0 M1 / 1 0 M2 / 2 0 F1 / 0 5 F2 / M1 F1 255 / End`。
  S5：$M_1F_1$：$l=M_2$ 时叉积 $(2)(0)-(0)(1)=0$ 且 $x=1\in[0,2],y=0\in[0,0]$ → **被遮挡**，$w[0][0]=bad=-10^6$；$M_1F_2$（另两人 $M_2,F_1$ 处叉积 $-5,-10$，非 0）、$M_2F_1$（$M_1$ 处叉积 $0$ 但 $x=0\notin[1,2]$，夹逼失败；$F_2$ 处叉积非 0）、$M_2F_2$（$M_1,F_1$ 处叉积 $5,-5$）均合法，$w=\begin{pmatrix}-10^6&1\\1&1\end{pmatrix}$。
  S6：$lx=[1,1]$（第一行 $\max$ 取到 $1$，不是 $-10^6$）。
  S7：$i=0$：$v=0$：$t=1+0+10^6=1000001\to slack[0]=1000001$；$v=1$：$t=0$ → $mt[1]=0$ 成功（$slack$ 被丢弃，不需要调整）。
  $i=1$：$v=0$：$t=1+0-1=0$ → $mt[0]=1$ 成功。
  S8：$ans=w[1][0]+w[0][1]=1+1=2$ ✓。若按"缘分降序贪心"会选到非法的 $M_1F_1$，本题据此说明 S5 必须在前。

- **用例 D（$n=1$，射程不足 → 无解自检）** — 期望程序打出负数
  输入：`9 / 1 / 0 0 M1 / 6 8 F1 / End`。$100>81$ → 非法，$w[0][0]=-10^6$，$lx[0]=-10^6$，$t=-10^6+0+10^6=0$ 直接匹配，$ans=-10^6<0$ → 触发 §2.6 的无解信号。题面保证不出现，但本地拿它验证"哨兵不会假装成功"。

- **用例 E（解析混合场景）** — 期望 `11`
  输入：`5 / 2 / M1 0 0 / M2 0 3 / f1 3 0 / F2 3 3 / M1 F1 10 / m1 f2 9 / M2 M1 77 / End`。
  S2：首 token 是字母 → 走 `Name x y` 分支，坐标取后两个 token ✓。S4：`M1 F1 10`→$af[0][0]=10$；`m1 f2 9`→归一后 $af[0][1]=9$ ✓ 大小写无关；`M2 M1 77`→$i=1,j=0$ 都在男侧，`i>=n&&j<n` 为假不 swap，`i<n&&j>=n` 为假 → **丢弃** ✓。
  $w=\begin{pmatrix}10&9\\1&1\end{pmatrix}$，$lx=[10,1]$。
  $i=0$：$t(0,0)=0$ → $mt[0]=0$。
  $i=1$：$v=0$：$t=1+0-1=0$ → $visy[0]=1$ → 递归 `aug(0)`：$v=1$：$t=10+0-9=1$ → $slack[1]=1$，返回 false；回到 $v=1$：$t=1+0-1=0$ → $visy[1]=1$，$mt[1]<0$ → $mt[1]=1$，返回 true。**一次搜索即成功，无需调整顶标**。
  $ans=w[0][0]+w[1][1]=10+1=11$ ✓（枚举两个完美匹配 $10+1=11$ 与 $9+1=10$，确为最优）。

2. "闭线段含端点重合者视为遮挡"（§1 取舍 3）与"重名不存在"（§2.8-6）是**约定**而非题面明文，若判题数据恰好涉及，结论可能不同。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{35};            // n<=30，男女各占一维
constexpr int bad{-1000000};        // 不可射边的权值哨兵，见 §2.6
constexpr i64 INF{1000000000000000000LL};

int k,n;
int px[2*mxn],py[2*mxn];        // 2n 个人的坐标，前 n 男后 n 女
string nm[2*mxn];                // 姓名一律归一为小写
int af[mxn][mxn],w[mxn][mxn];    // 缘分矩阵 / KM 真正使用的权值
i64 lx[mxn],ly[mxn],slack[mxn];    // 顶标与松弛量
int mt[mxn];                    // mt[女]=配到的男，-1 表示自由
bool visx[mxn],visy[mxn];

string low(string s){for(char&c:s)c=tolower((unsigned char)c);return s;}
int id(const string& s){for(int i=0;i<2*n;++i)if(nm[i]==s)return i;return -1;}

bool onSeg(int l,int a,int b)    // 第 l 个人是否落在线段 ab 上（闭区间）
{
	if(l==a||l==b)
		return false;
	i64 x1=px[a],y1=py[a],x2=px[b],y2=py[b],x3=px[l],y3=py[l];
	if((__int128)(x2-x1)*(y3-y1)!=(__int128)(y2-y1)*(x3-x1))
		return false;
	return min(x1,x2)<=x3&&x3<=max(x1,x2)&&min(y1,y2)<=y3&&y3<=max(y1,y2);
}

bool shootable(int a,int b)
{
	i64 dx=(i64)px[a]-px[b],dy=(i64)py[a]-py[b];
	if((__int128)dx*dx+(__int128)dy*dy>(__int128)k*k)
		return false;
	for(int l=0;l<2*n;++l)
		if(onSeg(l,a,b))
			return false;
	return true;
}

bool aug(int u)                    // 在相等子图里找增广路
{
	visx[u]=true;
	for(int v=0;v<n;++v)
		if(!visy[v])
		{
			i64 t=lx[u]+ly[v]-w[u][v];
			if(t==0)
			{
				visy[v]=true;
				if(mt[v]<0||aug(mt[v]))
				{
					mt[v]=u;
					return true;
				}
			}
			else
				slack[v]=min(slack[v],t);
		}
	return false;
}

int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	cin>>k>>n;
	for(int i=0;i<2*n;++i)
	{
		string s1,s2,s3;
		cin>>s1>>s2>>s3;
		// 题面格式 x y Name；姓名只含字母，据此顺带兼容 Name x y
		if(isalpha((unsigned char)s1[0]))
		{
			px[i]=stoi(s2);py[i]=stoi(s3);nm[i]=low(s1);
		}
		else
		{
			px[i]=stoi(s1);py[i]=stoi(s2);nm[i]=low(s3);
		}
	}
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			af[i][j]=1;            // 未被描述即缘分 1
	string A,B;
	int p;
	while(cin>>A&&A!="End")
	{
		cin>>B>>p;
		int i=id(low(A)),j=id(low(B));
		if(i<0||j<0)
			continue;
		if(i>=n&&j<n)
			swap(i,j);
		if(i<n&&j>=n)
			af[i][j-n]=p;            // 只有一男一女才进矩阵
	}
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			w[i][j]=shootable(i,n+j)?af[i][j]:bad;

	for(int i=0;i<n;++i)
		lx[i]=*max_element(w[i],w[i]+n);
	fill_n(ly,n,0LL);
	fill_n(mt,n,-1);
	for(int i=0;i<n;++i)
		while(true)
		{
			fill_n(visx,n,false);
			fill_n(visy,n,false);
			fill_n(slack,n,INF);
			if(aug(i))
				break;
			i64 d=INF;
			for(int v=0;v<n;++v)
				if(!visy[v])
					d=min(d,slack[v]);
			// notice: 每轮重算 slack，故这里不再做 slack[v]-=d
			for(int u=0;u<n;++u)
				if(visx[u])
					lx[u]-=d;
			for(int v=0;v<n;++v)
				if(visy[v])
					ly[v]+=d;
		}

	i64 ans=0;
	for(int v=0;v<n;++v)
		ans+=w[mt[v]][v];
	cout<<ans<<'\n';                // 若数据无解则 ans<0，见 §2.6
	return 0;
}
```

### 5.1 代码与证明的对应关系

| 代码段 | 对应 | 备注 |
|---|---|---|
| `onSeg` | 引理 2 | 先按下标排除两端，再叉积、再夹逼；`__int128` 防乘爆 |
| `shootable` | 引理 3 + §2.7 防线 1 | 平方比较，`(__int128)k*k` 先转后乘 |
| `w[i][j]=shootable?af:bad` | §2.6 引理 10 | 矩阵完备性在这里保证，不是"删边" |
| `lx[i]=*max_element(w[i],w[i]+n)` | §2.5 初值可行性 | 行最大，$ly=0$ |
| `aug` | 相等子图上的增广路 | $t==0$ 才走，否则更新 `slack` |
| 每轮 `fill_n(visx/visy/slack)` | 引理 7、8 的 $S,T,d$ | "整棵树重算"正是引理 8 单调性论证的口径 |
| `ans=Σ w[mt[v]][v]` | 引理 6 | 也可核对 `Σlx+Σly`，两者应相等（用例 B 验证过） |

### 5.2 风格对照（按 `coding-style-guide.md`）

`#include<bits/stdc++.h>` 单头 ✓；`using namespace std;` 紧跟其后 ✓；`using i64=long long;` 别名式（不写 `typedef`、不缩写 `ll`）✓；全局静态数组 + `constexpr int mxn{35}`（上界 $+5$ 松弛约定）✓；`constexpr int bad{-1000000}` 花括号常量 ✓；INF 用 `fill_n(slack,n,INF)` 重置 ✓；缩进 Tab ✓；运算符不加空格（`lx[u]-=d`、`min(x1,x2)<=x3`）✓；输出用 `'\n'` 不用 `endl` ✓；`ios::sync_with_stdio(false); cin.tie(nullptr);` 按本任务要求的顺序书写——风格指南 §10 的既有写法是 `cin.tie` 在前，两者在任何 I/O 之前生效故等价，此处从任务要求 ✓；一行小函数（`low`/`id`）整体单行 ✓；关键坑点留稀疏行内注释（`// notice: 每轮重算 slack`）✓；不 `new`、不 `reserve`、不建公共库，几何与 KM 全部本文件手写 ✓。

命名上把匹配数组写成 `mt[]` 而不是 `match[]`，避免与 `<regex>` 里的 `std::match_results` 等名字及 POSIX `match` 抢作用域；`aug`（增广）符合指南"电报式小写函数名"的习惯。
