# P1954 [NOI2010] 航空管制

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 个航班，只有一条跑道，所以要给它们排一个**排列**（起飞序列）。第 $v$ 个航班排在排列的第几个位置，叫它的**起飞序号** $pos(v)$。有两类限制：

- **最晚起飞时间**：$pos(v)\le k_v$，即航班 $v$ 不能排得太靠后（$k_v$ 是位置上限，不是「第 $k_v$ 分钟」）。
- **相对顺序**：给出 $m$ 条 $(a,b)$，要求 $pos(a)<pos(b)$，即 $a$ 必须先于 $b$。

题面保证**至少存在一个合法排列**。要求输出两行：

1. 任意一个合法排列；
2. 对每个航班 $i$，它在**所有合法排列**中可能取到的最小起飞序号。

### 1.2 关键约束与规模暗示

- $n\le 2\times10^3$，$m\le10^4$。
- $30\%$ 数据 $n\le10$：可以直接枚举 $n!$ 个排列，或者 $O(n!)$ 暴力。
- $60\%$ 数据 $n\le500$：允许 $O(n^3)$ 左右。
- $100\%$ 数据 $n\le2000$：**大约 $O(n^2)$ 到 $O(n^2\log n)$** 是甜点区；若每个航班单独做一遍 $O(n^2)$ 的扫描，总量 $O(n^3)$ 就危险，提示我们要用堆做到「每个 $i$ 一遍 $O((n+m)\log n)$」。
- 样例 2 的说明尤其重要：「航班 $1,2,3$ 都必须在前 $3$ 个起飞，所以 $4,5$ 最早只能第 $4$ 个」。这说明**最晚起飞时间限制也会把别的航班往后挤**，第二问不能只用图上的「祖先个数」来算。

## 2. 思维链（Chain-of-thought）

### 2.1 把题面翻译成图论

把每个航班看成点，$(a,b)$ 看成有向边 $a\to b$（$a$ 必须在 $b$ 前面）。

- 一个起飞序列就是一个排列，且必须是一个**拓扑序**（所有边从前指向后）。
- 条件 $pos(v)\le k_v$ 是一个「截止位置」。
- 于是问题变成：在 DAG 上找一个满足「每个点 $v$ 排在位置 $\le k_v$」的拓扑序；并求每个点在所有合法拓扑序中的最小位置。

### 2.2 第一问：为什么从后往前排

从前往后排（每次选入度为 $0$ 的点）会很难受：一个点现在能选，不代表选它安全，可能把某个 $k$ 很小的点挤到后面超时。

换个方向：**先决定最后一个位置**。位置 $n$ 上能放谁？

1. 它必须没有「还没排的后继」——否则它的某个后继必须排在它后面，可后面已经没有位置了。也就是说，放在位置 $p$ 的点必须是当前**出度为 $0$** 的点（所有后继都已经排在比 $p$ 更靠后的位置）。
2. 它的截止位置必须够大：$k_v\ge p$。

把「所有后继都已经排好」的点叫**可用点**。于是反向过程是：

> 令 $p=n,n-1,\dots,1$。在所有可用点中，放一个满足 $k_v\ge p$ 的点到位置 $p$。

问题：这样随便选真的不会把局面搞坏吗？这需要一个关键的「安全选择」引理。

### 2.3 关键引理：任何合法的可用选择都是安全的

**引理 1（安全选择引理）**
假设我们已经排好了位置 $p+1,\dots,n$ 的一个后缀，并且这个后缀满足：

- 每个已排航班的截止位置都 $\ge$ 它所在的位置；
- 后缀内部的相对顺序合法（每条边的两端若都在后缀里，则方向与位置一致）；

并且这个后缀**可以被扩充成一个完整的合法起飞序列**。设 $v$ 是一个当前可用点（$v$ 的所有后继都已在后缀里），且 $k_v\ge p$。那么把 $v$ 放到位置 $p$，得到的后缀仍然可以被扩充成完整合法序列。

**证明**：
设 $\sigma$ 是任一与当前后缀一致的完整合法序列（由「可扩充」假设存在）。记 $v$ 在 $\sigma$ 中的位置为 $q$。因为 $v$ 不在已固定的后缀（位置 $>p$）里，所以 $q\le p$。若 $q=p$，什么也不用做。

否则 $q<p$。构造 $\sigma'$：把 $v$ 从位置 $q$ 挪到位置 $p$，原来位置 $q+1,q+2,\dots,p$ 上的航班依次**前移一格**。逐项检查：

1. **相对顺序**：
   - $v$ 的每个后继都在已固定的后缀里（位置 $>p$），所以 $v$ 放到位置 $p$ 后仍然排在所有后继之前，不违反任何以 $v$ 为起点的边。
   - 对任意被前移的航班 $x$（原来在位置 $r\in(q,p]$，新位置 $r-1$）：$x$ 的前驱原本在它前面。若某个前驱 $y$ 原来在位置 $\le q$，那么 $y$ 不后移，仍在 $x$ 前面；若 $y$ 原来在 $(q,r)$，它也被前移，且仍在 $x$ 前面。唯一需要小心的是 $y=v$：但 $v$ 的后继全在位置 $>p$，而 $x$ 的位置 $\le p$，所以 $v$ 不可能是 $x$ 的前驱。因此 $x$ 的所有前驱仍在它前面。
   - $x$ 的后继：若原本在位置 $\le p$ 且不是 $v$，则一起前移，相对次序不变；若原本在位置 $>p$，仍在 $x$ 后面；若是 $v$，则 $v$ 挪到了位置 $p$，而 $x$ 的最终位置 $\le p-1<p$，所以 $x$ 仍在 $v$ 前面。合法。
2. **截止位置**：被前移的航班位置变小，$k\ge$ 原位置 $>$ 新位置，仍然满足；$v$ 在位置 $p$，由假设 $k_v\ge p$。

所以 $\sigma'$ 是完整合法序列，并且它的位置 $p..n$ 与新后缀一致。引理成立。$\square$

**推论 1**：第一问的反向贪心不会失败。初始整个实例可扩充（题面保证有合法序列）。每一步，若当前后缀可扩充，则扩充序列中位置 $p$ 上的航班一定是可用点，且由合法性 $k\ge p$，所以「可用的合法点」非空。由引理 1，放入其中任意一个后仍可扩充。归纳到 $p=1$，得到完整合法序列。

这也说明实现里「取 $k$ 最大的可用点」只是一个方便的选法，正确性并不依赖这个偏序（引理对**任意**合法可用点成立）。用堆取最大只是让代码稳定、好写。

### 2.4 第二问：先想一个笨办法

要求航班 $i$ 的最小可能位置。最直接的想法是**二分答案**：

> 判定「$i$ 能否排在位置 $\le t$」：把 $i$ 的截止位置临时改成 $t$，用第一问的反向贪心（或直接判可行）跑一遍。

可行性关于 $t$ 单调（$t$ 变大只是放宽限制），所以可以二分。每次判定 $O((n+m)\log n)$，二分 $O(\log n)$，再对 $n$ 个 $i$ 各做一次，总
$$
O\bigl(n\log n\cdot(n+m)\log n\bigr)\approx 2000\times11\times12000\times11\approx 3\times10^9,
$$
太慢了。

注意到：判定「$i\le t$」和「尽量把 $i$ 往后推」是同一件事的两面。与其二分 $t$，不如**在反向过程中尽量晚地放 $i$**，一次就求出最小的 $t$。

### 2.5 第二问的算法

固定 $i$，执行：

> 令 $p=n,n-1,\dots,1$。记当前可用点集为 $A_p$（所有后继都已排在 $>p$ 的点）。
> - 若 $A_p\setminus\{i\}$ 中存在 $k_v\ge p$ 的点，就选一个（实现取 $k$ 最大者）放到位置 $p$；
> - 否则（没有可用的非 $i$ 合法点），把 $i$ 放到位置 $p$，**答案就是 $p$**，停止。

直觉：位置越靠后越「难填」（要求 $k\ge p$），所以把别的航班尽量塞到后面，$i$ 就会被挤到尽可能靠前。下面严格证明。

### 2.6 下界：$i$ 不可能比算法给出的 $p^*$ 更早

记算法在位置 $p^*$ 放下 $i$。反设存在合法序列 $\sigma$，使 $pos(i)=t<p^*$。我们要推出矛盾。

**归纳构造**：对 $p=n,n-1,\dots,p^*$，构造合法序列 $\sigma_p$，满足：

- (a) $\sigma_p$ 合法；
- (b) $\sigma_p$ 的位置 $p+1,\dots,n$ 与算法的放置**逐位相同**；
- (c) $pos_{\sigma_p}(i)<p$。

**初始**：取 $\sigma_n=\sigma$。因为 $t<p^*\le n$，所以 $t<n$，(c) 成立；(a) 是假设；(b) 位置 $n+1..n$ 为空。成立。

**归纳步**（从 $\sigma_p$ 到 $\sigma_{p-1}$）：算法在第 $p$ 步放的是非 $i$ 的点（因为 $p>p^*$，还没到停止点），记它为 $v$，且 $k_v\ge p$、$v$ 可用。

看 $\sigma_p$ 的位置 $p$ 上的航班 $u$。由 (c) $pos(i)<p$，所以 $u\ne i$。$u$ 的所有后继都在位置 $>p$，而这些位置与算法一致，所以 $u$ 在第 $p$ 步是**可用点**；又 $\sigma_p$ 合法，故 $k_u\ge p$。这就是「算法第 $p$ 步确实有可用的非 $i$ 合法点」的体现。

设 $v$ 在 $\sigma_p$ 中位于 $q$。$v$ 不在已固定后缀中，故 $q\le p$；位置 $p$ 是 $u\ne v$，故 $q\le p-1$。

现在做与引理 1 完全相同的搬运：把 $v$ 从 $q$ 挪到 $p$，位置 $q+1,\dots,p$ 依次前移一格，得到 $\sigma_{p-1}$。引理 1 的检查逐字适用（$v$ 可用意味着其后继都在固定的后缀里；被前移的航班位置变小），所以它合法，且位置 $p..n$ 与算法一致，(b) 成立。

最后看 $i$ 的位置 $t$（注意 $i\ne v$）：

- 若 $t<q$：$i$ 不动，$t<q\le p-1$，即 $t\le p-2$；
- 若 $t>q$：$i$ 前移一格变成 $t-1$；由于位置 $p$ 上是 $u\ne i$，有 $t\ne p$，故 $t\le p-1$，于是 $t-1\le p-2$。

两种情况都有 $pos_{\sigma'}(i)<p-1$，即 (c) 对 $\sigma_{p-1}$ 成立。归纳完成。

归纳到 $p=p^*$：得到合法序列 $\sigma_{p^*}$，满足 $pos(i)<p^*$，且位置 $p^*+1,\dots,n$ 与算法一致。

现在看 $\sigma_{p^*}$ 的位置 $p^*$ 上的航班 $u$。由 $pos(i)<p^*$ 得 $u\ne i$。$u$ 的所有后继都在位置 $>p^*$（与算法一致的后缀里），所以 $u$ 在算法第 $p^*$ 步是可用点；$\sigma_{p^*}$ 合法又给出 $k_u\ge p^*$。这与「算法在第 $p^*$ 步没有任何可用的非 $i$ 合法点，只好放 $i$」矛盾。

所以 $t<p^*$ 不存在，即 $pos(i)\ge p^*$。$\square$

**边界情形 $p^*=n$**：算法第一步（位置 $n$）就放了 $i$，说明第 $n$ 步没有可用的非 $i$ 合法点。此时 $i$ 必须是可用点（否则算法无点可放），且 $k_i\ge n$，所以 $k_i=n$；而其它**所有**汇点（出度为 $0$ 的点，位置 $n$ 的候选只能是汇点）都满足 $k<n$，不能放在位置 $n$。因此任何合法序列的第 $n$ 位都只能是 $i$，下界 $pos(i)\ge n$ 直接成立。

### 2.7 上界：算法给出的 $p^*$ 真的能达到

算法在位置 $n,n-1,\dots,p^*+1$ 的每一步选的都是「可用且 $k\ge$ 位置」的点，所以每一步都满足引理 1 的前提。初始实例有合法序列（可扩充），故由引理 1 归纳，放完这些点后后缀**仍然可扩充**。

在位置 $p^*$，算法放 $i$：这要求 $i$ 可用且 $k_i\ge p^*$。若不然，当前后缀就无点可放，与「后缀仍可扩充」矛盾（扩充序列中位置 $p^*$ 的点必然可用且合法，而所有可用的非 $i$ 点都已不合法，只能是 $i$）。所以 $i$ 在 $p^*$ 是合法的，加上后缀可扩充，存在以 $i$ 为位置 $p^*$ 的完整合法序列。

于是 $pos(i)\le p^*$，结合下界得
$$
\min pos(i)=p^*.
$$

### 2.8 实现要点与坑

- **边的方向**：$a$ 必须先于 $b$，存反图 `rev[b].push_back(a)`，并用 `outdeg[a]++` 记录「$a$ 有多少个后继」。反向排到 $u$ 时，把 $u$ 从它所有前驱的「未排后继数」里减掉，减到 $0$ 就入堆。
- **合法性是 $k_v\ge p$ 而不是 $\le$**：因为 $p$ 是从 $n$ 往下走的，$k_v$ 是位置上限。
- 堆按 $k$ 大根：第一问直接取堆顶；第二问若堆顶是 $i$，就看第二大的（代码里弹出 $i$ 暂存、看下一个，若下一个仍合法则把 $i$ 放回堆）。
- 第二问要对每个 $i$ 重新复制一份 `outdeg` 并清空堆，$O(n+m)$ 重置。
- 题面保证有解，因此不会出现「一个合法点都没有」的情况；代码里保留了一个兜底分支，正常数据不会触发。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 起飞序列 = 拓扑序，$k_i$ 是位置上限。
- **reverse thinking** — 正着选点难判安全性，改成从最后一个位置往前填。
- **classic problem solution** — 反向拓扑排序：只考虑出度为 $0$ 的可用点，并检查 $k\ge$ 当前位置。
- **exchange argument** — 安全选择引理：任意合法的可用选择都不破坏「可扩充性」。
- **reduce to easier problem** — 第二问先想「二分 + 判定可行」，但太慢。
- **exchange argument** — 把「二分」换成「尽量晚放 $i$」：反向归纳证明 $i$ 不能更早，再用安全引理证明 $p^*$ 可达。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n,m` | `int` | 航班数、限制数 | 读入 | 规模 |
| `k[i]` | `int [mxn]` | 航班 $i$ 的位置上限 | 读入 | deadline |
| `rev[v]` | `vector<int> [mxn]` | 反图：$v$ 的所有前驱 | 空 | reverse edge |
| `outdeg[i]` | `int [mxn]` | $i$ 的后继个数（原始值） | 0 | 出度 |
| `od[i]` | `int [mxn]` | 本次模拟中 $i$ 尚未排定的后继个数 | 每次拷贝 | 动态出度 |
| `Q` | `priority_queue<pair<int,int>>` | 以 $(k_v,v)$ 为键的大根堆，堆顶是 $k$ 最大的可用点 | 空 | 候选集 |
| `ans1[p-1]` | `int [mxn]` | 第一问位置 $p$ 上的航班（0-based 存） | — | 序列 |
| `ans2[i]` | `int [mxn]` | 第二问航班 $i$ 的最小起飞序号 | — | 答案 |
| `p` | `int` | 当前要填的位置，$n\to1$ | $n$ | position |

### 4.2 算法步骤

1. 读入 $n,m$、$k$ 与所有边 $(a,b)$；建立 `rev[b].push_back(a)`，并 `++outdeg[a]`。
2. **第一问**：
   1. `od = outdeg`，把所有 `od[v]==0` 的点以 $(k_v,v)$ 入堆。
   2. 对 $p=n,n-1,\dots,1$：弹出堆顶 $u$，令 `ans1[p-1]=u`；对每个 $w\in rev[u]$ 执行 `--od[w]`，若变为 $0$ 则入堆。
3. **第二问**：对每个 $i=0..n-1$：
   1. 重置 `od = outdeg`，清空堆，把所有汇点入堆。
   2. 对 $p=n,n-1,\dots,1$：
      - 弹出堆顶 $(k_u,u)$。
      - 若 $u\ne i$：若 $k_u\ge p$，把 $u$ 放到位置 $p$（更新其前驱的出度），否则（理论上不会发生）记答案为 $p$ 并跳出。
      - 若 $u=i$：若堆空，答案为 $p$ 并跳出；否则再弹一个 $(k_v,v)$：若 $k_v\ge p$，把 $i$ 放回堆、把 $v$ 放到位置 $p$；若 $k_v<p$，说明没有可用的非 $i$ 合法点，答案为 $p$ 并跳出。
      - 一旦放下 $i$ 就停止。
4. 输出第一问序列（每个数 $+1$），再输出第二问的 `ans2`。

### 4.3 复杂度分析

- 第一问：每个点入堆、出堆各一次，每条边被处理一次，共 $O((n+m)\log n)$。
- 第二问：对每个 $i$ 做一遍上述过程，$O\bigl(n(n+m)\log n\bigr)$。$n=2000,m=10^4$ 时约为 $2\times10^8$ 次基本操作，实测 $0.45$ 秒。
- 空间 $O(n+m)$（反图 + 若干长度 $n$ 的数组）。

## 5. 示例代码

```cpp
//
// 题目：P1954 [NOI2010] 航空管制
// https://www.luogu.com.cn/problem/P1954
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005},mxm{10005};

int n,m;
int k[mxn],outdeg[mxn],od[mxn];
vector<int>rev[mxn];
int ans1[mxn],ans2[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>k[i];
	for(int i=0,a,b;i<m;++i)
	{
		cin>>a>>b;--a;--b;
		rev[b].push_back(a);      //a must be before b
		++outdeg[a];
	}

	memcpy(od,outdeg,sizeof(int)*n);
	priority_queue<pair<int,int>>Q;
	for(int v=0;v<n;++v)
		if(od[v]==0)
			Q.push({k[v],v});
	for(int p=n;p>=1;--p)
	{
		auto[_,u]=Q.top();Q.pop();
		ans1[p-1]=u;
		for(int v:rev[u])
			if(--od[v]==0)
				Q.push({k[v],v});
	}

	for(int i=0;i<n;++i)
	{
		memcpy(od,outdeg,sizeof(int)*n);
		while(!Q.empty())
			Q.pop();
		for(int v=0;v<n;++v)
			if(od[v]==0)
				Q.push({k[v],v});
		int res{-1};
		for(int p=n;p>=1;--p)
		{
			auto[ku,u]=Q.top();Q.pop();
			if(u==i)
			{
				if(Q.empty())
				{
					res=p;
					break;
				}
				auto[kv,v]=Q.top();Q.pop();
				if(kv>=p)
				{
					Q.push({ku,i});
					for(int w:rev[v])
						if(--od[w]==0)
							Q.push({k[w],w});
				}
				else
				{
					res=p;
					break;
				}
			}
			else if(ku>=p)
			{
				for(int w:rev[u])
					if(--od[w]==0)
						Q.push({k[w],w});
			}
			else
			{
				res=p;
				break;
			}
		}
		ans2[i]=res;
	}

	for(int i=0;i<n;++i)
		cout<<ans1[i]+1<<' ';
	cout<<'\n';
	for(int i=0;i<n;++i)
		cout<<ans2[i]<<' ';
	cout<<'\n';
	return 0;
}
```
