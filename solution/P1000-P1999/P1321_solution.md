# P1321 单词覆盖还原

> 标签：模拟 / 字符串 / 洛谷原创 · 难度：入门

## 1. 重新读题

**问题重述（大白话版）**

有一条长 $l$ 的纸带，一开始每个格子都是一个句号 `.`。然后按顺序做若干次"贴纸"：每次挑一个起点，把 `boy`（占 3 格）或 `girl`（占 4 格）整词逐格贴上去；贴到的格子被新字母盖住，没贴到的格子保持原样，后贴的会盖掉先贴的。做完之后保证：**每个贴上去的词都还至少露出一个字母**（没被后来的词全部盖掉）。

现在只给你最后看到的这行字符串，问：`boy` 贴了几次、`girl` 贴了几次（分别输出两行）。

**从题面里必须抠清楚的三件事**

1. **输入是"最终结果串"，不是操作序列。** 没有任何"第几次贴在哪个位置"的信息，只有 $l$ 个格子的最终字符。所以必须从结果串反推操作次数。
2. **`.` 与非 `.` 的语义不对称。** 每次粘贴只往格子里写字母，从不写 `.`，所以字母一旦写上就永远回不去：$s_i=\texttt{.}\iff$ 格子 $i$ **从未被任何一次粘贴覆盖**；$s_i$ 是字母 $\iff$ 它是"**最后一次**覆盖 $i$ 的那个词在该偏移处的字母"。
3. **要统计的量是"操作次数"，不是"字符串里出现了几个单词"。** 一个词可以被盖得只剩一个字母，甚至只剩首/尾字母，那一次粘贴仍然要算数；而一个词如果三个（四个）字母全露着，也只能算**一次**。

**约束**

| 量 | 范围 |
|---|---|
| 串长 $l$ | $3\le l\le 255$ |
| 字符集 | 仅 $\texttt{.bgilory}$（恰好 $=$ `.` + `boy` 的 3 个字母 + `girl` 的 4 个字母） |
| 操作 | 保证"每个词至少 1 个字符未被覆盖" |

**约束给的暗示**：$l\le 255$ 小到可以随便暴力，$O(l)$、$O(l^2)$、$O(l^3)$ 都能过，说明本题**不考算法与复杂度，只考"覆盖机制的还原条件写对没有"**。标签"模拟 + 字符串"也印证：要的是逐格检查的判定式。字符集正好只含这 7 个字母不是巧合——它是本题能被唯一还原的关键（见引理 1）。

**样例说明**：本地题面文件 `P1321.md` **没有 Sample 块**（只给了描述、输入输出格式和 Hint）。因此第 4.3 节的验证方式改为：自己按题意**构造**操作序列 → 逐格手算模拟出结果串 → 再用推导出的公式反推计数，两边比对（等价于对拍，但**全部手工完成**）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索机制：把"逐格覆盖"写成一条公式

设结果串 $s=s_0s_1\cdots s_{l-1}$，操作序列 $O_1,\dots,O_K$，第 $t$ 次操作是"把词 $w_t\in\{\texttt{boy},\texttt{girl}\}$ 贴在起点 $p_t$"，覆盖区间 $[p_t,\,p_t+|w_t|-1]$，逐格写入 $w_t$ 的字母。贴词必须**完整落在纸带内**，即 $0\le p_t\le l-|w_t|$（题面"把这个单词贴到这个字符串中"的自然理解，也是所有数据遵循的规则；起点范围因此是 $[0,l-|w|]$）。

于是每个格子的最终字符是

$$
s_i=\begin{cases}
w_{t^*}[\,i-p_{t^*}\,], & t^*=\max\{t:\ i\in[p_t,\,p_t+|w_t|-1]\}\ \text{存在},\\[2pt]
\texttt{.}, & \text{不存在}.
\end{cases}
$$

读法：**格子只记得最后碰它的那次操作**；没人碰过就还是 `.`（`.` 不可能由覆盖产生，见 1 的第 2 条）。

题面那句"最终，每个单词至少有一个字符没有被覆盖"形式化就是

$$
\forall t\ \exists d\in[0,|w_t|-1]:\ \forall t'>t,\ \ p_t+d\notin[p_{t'},\,p_{t'}+|w_{t'}|-1].\tag{$\star$}
$$

即每次操作都存在一个"幸存格"，它在之后没被任何更晚的操作碰到。

### 2.2 关键发现：单个字母就是完整的"坐标签名"

先把字符集摆出来：

$$
\texttt{boy}=\{\texttt b,\texttt o,\texttt y\},\qquad \texttt{girl}=\{\texttt g,\texttt i,\texttt r,\texttt l\}.
$$

两条性质立即可以逐字母查表验证：

* (A) **词内字母互不重复**：$\texttt b,\texttt o,\texttt y$ 两两不同，$\texttt g,\texttt i,\texttt r,\texttt l$ 两两不同；
* (B) **两词字母集不相交**：$\{\texttt b,\texttt o,\texttt y\}\cap\{\texttt g,\texttt i,\texttt r,\texttt l\}=\varnothing$。

(A)+(B) ⟹ 映射"字母 $\to$ (所属词, 在词中的偏移)"是**单射**：

$$
\texttt b\mapsto(\text{boy},0),\ \texttt o\mapsto(\text{boy},1),\ \texttt y\mapsto(\text{boy},2),\
\texttt g\mapsto(\text{girl},0),\ \texttt i\mapsto(\text{girl},1),\ \texttt r\mapsto(\text{girl},2),\ \texttt l\mapsto(\text{girl},3).
$$

把它代入 2.1 的公式：若 $s_i=c\ne\texttt{.}$，记 $c\mapsto(w,d)$，则写出 $c$ 的那次操作必是"$w$ 贴在起点 $p=i-d$"。**也就是说，结果串里任何一个字母都独立完整地报出了"是哪一次操作写的我"——不需要做任何子串搜索、不需要回溯匹配。**

于是定义核心概念：

> **见证（attest）**：称起点 $p$ 被结果串 $s$ 关于词 $w$ **见证**，若 $w$ 的某个偏移上的字母在 $s$ 里还露着：
> $$\mathrm{Att}_w(p)\iff \bigvee_{d=0}^{|w|-1}\bigl(p+d<l\ \wedge\ s[p+d]=w[d]\bigr).$$

### 2.3 引理 1（见证 ⟺ 该次粘贴存在）

**引理 1**：设 $s$ 由满足 $(\star)$ 的合法操作序列生成。则序列中存在一次"$w$ 贴在起点 $p$"（此时 $0\le p\le l-|w|$）$\iff$ $\mathrm{Att}_w(p)$ 成立。

**证明**：

*（⟸，有签名就有操作）* 设 $\mathrm{Att}_w(p)$ 成立，取满足 $s[p+d]=w[d]$ 的某个 $d$。令 $t^*$ 为最后一次覆盖格子 $p+d$ 的操作（它存在，因为 $s[p+d]$ 是字母而非 `.`）。由 2.1 的公式 $s[p+d]=w_{t^*}[(p+d)-p_{t^*}]$。左边等于 $w[d]$，是 $w$ 的一个字母；由 (B) 它不可能同时是另一个词的字母，故 $w_{t^*}=w$；再由 (A)（词内字母不重复，同一个字母只出现在唯一偏移上）它的偏移必相等：$(p+d)-p_{t^*}=d$，解出 $p_{t^*}=p$。即序列里存在"$w$ 贴在 $p$"这一次操作。✓

*（⟹，有操作就留签名）* 设第 $t$ 次操作是"$w$ 贴在 $p$"。由 $(\star)$ 取它的幸存偏移 $d$：$p+d$ 不被任何 $t'>t$ 覆盖，故"最后一次覆盖 $p+d$ 的操作"就是 $t$ 本身（$t$ 显然覆盖 $p+d$），由 2.1 的公式 $s[p+d]=w[d]$，$\mathrm{Att}_w(p)$ 成立。✓

*（关于 $p+d<l$）* 由"贴词落在串内"，操作覆盖的格子的下标都在 $[0,l-1]$，故取到的 $p+d$ 自动合法。$\blacksquare$

> 引理 1 的两个方向各自依赖不同的性质：**⟸ 用"字母互异 + 两词不相交"（签名可反解）**，**⟹ 用保证条件 $(\star)$（操作必留签名）**。少任何一条，方法就失效（⟹ 的失效见引理 3 与 4.3 的 (7)，⟸ 的失效见 2.7 末的"推广"）。

### 2.4 引理 2（同一个词不会两次贴在同一个起点）

**引理 2**：合法序列中，若两次操作都是"$w$ 贴在 $p$"，则这两次是同一次操作。

**证明**（反证）：设 $t_1<t_2$ 都是"$w$ 贴在 $p$"。同词同起点 ⟹ 覆盖区间相同，都是 $[p,\,p+|w|-1]$。于是 $t_1$ 覆盖的**每一个**格子都被更晚的 $t_2$ 覆盖，即 $t_1$ 不存在未被覆盖的字符，与 $(\star)$ 矛盾。$\blacksquare$

### 2.5 定理：答案 $=$ 被见证起点的个数

记

$$
B=\{p\in[0,l-3]:\ s[p]=\texttt b\ \vee\ s[p+1]=\texttt o\ \vee\ s[p+2]=\texttt y\},\quad
G=\{p\in[0,l-4]:\ s[p]=\texttt g\ \vee\ s[p+1]=\texttt i\ \vee\ s[p+2]=\texttt r\ \vee\ s[p+3]=\texttt l\}.
$$

**定理**：boy 的粘贴次数 $=|B|$，girl 的粘贴次数 $=|G|$。

**证明**：由引理 1，$p\in B\iff$ 序列中存在"boy 贴在 $p$"（$p$ 跑遍 $[0,l-3]=[0,l-|\texttt{boy}|]$，正是合法起点范围）。序列中所有 boy 操作构成的集合，按引理 2 其起点两两不同，故"boy 操作次数" $=$ "boy 起点集合的基数" $=|B|$。girl 完全同理（$[0,l-4]=[0,l-|\texttt{girl}|]$）。$\blacksquare$

**定理顺带证明了两件事**：

1. **答案由结果串唯一决定**——题目能问"贴了几个"的前提；我们因此**不需要**还原真正的操作顺序，只要能数出起点集合。
2. 计数天然是"**对起点去重**"的：一个词露出 1 个还是 3 个字母，都只贡献集合里的同一个元素。

### 2.6 简化版与两个朴素做法的下场

（叙事顺序说明：2.2 的"字母签名"在读懂题面、写下 2.1 的公式后几乎是立刻浮现的，所以证明先行；本节回头做"无覆盖"简化版检验，并用两个最常见的朴素做法的反例确认这条公式不是巧合、而是把两种错误同时修掉的唯一做法。）

**简化版（从未发生覆盖）**：各词互不相交，每个词的字母全部露出，$p$ 会被 3（4）个字母同时见证；$|B|$ 仍只算一次。此时 $B$ 恰是"boy 作为子串出现的位置集合"，公式**退化成朴素的找子串**——这是公式的必要自检。

自检手算 $s=$ `"boy.girl"`（$l=8$，构造：boy@0、girl@4，无重叠）：

* $B$：$p{=}0$: $s[0]=\texttt b$ ✓；$p{=}1$: $s[1]{=}\texttt o\ne\texttt b$、$s[2]{=}\texttt y\ne\texttt o$、$s[3]{=}\texttt{.}\ne\texttt y$ ✗；$p{=}2$: $\texttt y,\texttt{.},\texttt g$ 全不对位 ✗；$p{=}3$: $\texttt{.},\texttt g,\texttt i$ ✗；$p{=}4$: $\texttt g,\texttt i,\texttt r$ ✗；$p{=}5$: $\texttt i,\texttt r,\texttt l$ ✗。$B=\{0\}$。
* $G$：$p{=}0$: $\texttt b,\texttt o,\texttt y,\texttt{.}$ ✗；$p{=}1$: $\texttt o,\texttt y,\texttt{.},\texttt g$ ✗；$p{=}2$: $\texttt y,\texttt{.},\texttt g,\texttt i$ ✗；$p{=}3$: $\texttt{.},\texttt g,\texttt i,\texttt r$ ✗；$p{=}4$: $s[4]=\texttt g$ ✓。$G=\{4\}$。
* 结果 $(1,1)$ ✓ 与构造一致。

**注意 $p=3$ 那个窗口 `".gi"`**：里面确实出现了 girl 的字母 $\texttt g,\texttt i$，但它们不在 boy 的偏移位置上（$s[4]$ 是 $\texttt g$ 而不是 $\texttt o$），所以不会误判成 boy。这正是"必须**按偏移对齐**比较"的意义：引理 1 的 ⟸ 方向靠的就是"偏移能反解"，判据不能写成"窗口里含有 b/o/y 之一"。

**尝试 A（数字母个数）**：$\#\texttt b+\#\texttt o+\#\texttt y$。反例 $s=$ `"boy"`（真值 1）：得 $1+1+1=3$。**错因：一个词的多条签名被重复计数。**

**尝试 B（找子串 `boy` 出现次数）**：反例：$l=4$，依次 boy@0、boy@1。逐格模拟：`....` → boy@0 写 $0,1,2$ → `boy.` → boy@1 写 $1,2,3=\texttt b,\texttt o,\texttt y$ → `"bboy"`。真值 2，而子串 "boy" 只出现在 $p=1$ 一处 → 得 1。**错因：先贴的词被盖得只剩 'b'（"签名残缺"），不再以完整子串形式存在。**（同一个串用尝试 A 数得 $\#\texttt b=2,\#\texttt o=1,\#\texttt y=1$ 共 4，又过头。）

两个失败模式恰好互补：**A 要"去重"，B 要"允许任一偏移单独作证"**。合起来正好是定理的 $\mathrm{Att}$ 判定 —— 这不是巧合，而是"集合 $B$"的定义本身。

### 2.7 保证条件 $(\star)$ 不能省，以及"只剩一个字母"的极端例子

**引理 3（保证条件 $(\star)$ 不可省）**：若去掉 $(\star)$，结论就不成立——存在两个产生**同一个**结果串的操作序列，它们的 boy/girl 次数不同，于是"贴了几次"不再是 $s$ 的函数，题目无解。

**证明**：给出实例。取 $l=4$。

* 序列 $X$：只做一次操作 girl@0，结果串 `girl`；girl 次数 1、boy 次数 0。
* 序列 $Y$：先 boy@0，再 girl@0。girl 的覆盖区间 $[0,3]$ 真包含 boy 的 $[0,2]$，故 boy 的 3 个格子全被后贴的盖掉，结果串同样是 `girl`；boy 次数 1、girl 次数 1。

$X,Y$ 结果串相同而答案不同 ⟹ 任何只看结果串的算法都不可能给出正确答案。题面用 $(\star)$ 恰好排除这种"完全被后贴词覆盖"的操作（$Y$ 里的 boy 违反 $(\star)$），因此本题数据中不会出现；这也解释了 2.3 里 ⟸ ⟹ 两个方向各自的分工——**⟹ 方向完全依赖 $(\star)$**。$\blacksquare$

顺带说明引理 2 也不是多余的：它排除的是"同词同起点贴两次"（$l=4$ 时 boy@0、boy@0 → 结果 `boy.`，真值 2 但公式只给 1），同样由 $(\star)$ 保证不会发生。

**极端例子（起点只由最后一个字母见证）**：$l=6$，依次 boy@2、boy@1。逐格模拟：

| 步骤 | idx0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 初始 | `.` | `.` | `.` | `.` | `.` | `.` |
| boy@2 | `.` | `.` | `b` | `o` | `y` | `.` |
| boy@1 | `.` | `b` | `o` | `y` | `y` | `.` |

$s=$ `".boyy."`。boy@2 的两个签名格（idx2,3）被后来的 boy@1 盖掉，只剩 idx4 的 `y`；它的起点 $2$ 仍由 $s[4]=\texttt y$（偏移 2）唯一反解出来 ✓。手推：$B$ 中 $p{=}1$: $s[1]=\texttt b$ ✓；$p{=}2$: $s[2]{=}\texttt o\ne\texttt b$、$s[3]{=}\texttt y\ne\texttt o$、$s[4]=\texttt y$ ✓；$p{=}0$: $\texttt{.},\texttt b,\texttt o$ 全不对位 ✗；$p{=}3$: $\texttt y,\texttt y,\texttt{.}$ ✗ ⟹ $|B|=2$ ✓；$G=\varnothing$（$s$ 里不含任何 girl 的字母）✓。而"找子串"在 `".boyy."` 里只找到 1 处 "boy"（$p=1$）→ 又漏一次，印证 2.6 的尝试 B。

**推广（也是引理 1 的逆否用法）**：如果换成有重复字母的词（比如 `"aab"`），性质 (A) 破坏——看到 `'a'` 无法确定偏移 0 还是 1，⟸ 方向就只给出"起点是 $i$ 或 $i-1$ 之一"，产生假阳性，本题的方法不再充分。可见"boy / girl 字母互异且不相交、字符集只有 `.bgilory`"是出题人为了让**单格字母 = 完整签名**而做的设计。

### 2.8 引理 4：网上常见的"逐字母贪心"与起点窗口版等价

很多 AC 代码按字母扫描并"看左边同词的字母是否已被数过"：

$$
\text{cnt}_{\text{boy}}=\sum_i\Bigl([s_i=\texttt b]+[s_i=\texttt o\wedge s_{i-1}\ne\texttt b]+[s_i=\texttt y\wedge s_{i-1}\ne\texttt o\wedge s_{i-2}\ne\texttt b]\Bigr)
$$

（每个指示项还要求"隐含起点合法"：字母 $c$ 在偏移 $d$ 处 ⟹ 起点 $p=i-d$ 必须满足 $0\le p\le l-|w|$，即 $i\ge d$ 且 $i-d\le l-|w|$；不满足的项恒取 $0$。这样写连非法数据都能安全处理，见引理 4 的边界段。）

**引理 4**：对合法数据，上式 $=|B|$；girl 同理（多一项 $[s_i=\texttt l\wedge s_{i-1}\ne\texttt r\wedge s_{i-2}\ne\texttt i\wedge s_{i-3}\ne\texttt g]$）。

**证明**：固定起点 $p$，记 $D_p=\{d\in[0,|w|-1]:\ s[p+d]=w[d]\}$（见证偏移集）。三项对 $|B|$ 的贡献可以逐条翻译成"谁第一个作证"：

* $s_i=\texttt b$ 命中 $\iff p=i$ 且 $0\in D_p$；
* $s_i=\texttt o\wedge s_{i-1}\ne\texttt b$ 命中 $\iff p=i-1$、$1\in D_p$ 且 $0\notin D_p$（$s_{i-1}\ne\texttt b$ 正是 $0\notin D_p$）；
* $s_i=\texttt y\wedge s_{i-1}\ne\texttt o\wedge s_{i-2}\ne\texttt b$ 命中 $\iff p=i-2$、$2\in D_p$ 且 $1\notin D_p$、$0\notin D_p$。

对固定的 $p$ 求和：若 $0\in D_p$ 贡献 1（后两项被条件挡掉）；否则若 $1\in D_p$ 贡献 1（第三项被 $s_{i-1}\ne\texttt o$ 挡掉）；否则由 $p\in B$ 即 $D_p\ne\varnothing$ 必有 $2\in D_p$，前两项为 0、第三项为 1。三种情形都恰好 1；$p\notin B$（$D_p=\varnothing$）时三项全 0。故总和 $=\sum_p[|D_p|>0]=|B|$。

边界：字母出现在"放不下整词"的位置（如 $i<2$ 的 `y`、$i>l-3$ 的 `b`）在合法数据中根本不会发生——$s_0=\texttt o$ 要求起点 $-1$，$s_{l-1}=\texttt b$ 要求起点 $l-1>l-3$，都与 $0\le p\le l-|w|$ 矛盾，故这些"假想项"恒为 0，不影响等式。给指示项统一加上"起点合法"守卫之后，两种写法对**任意**输入串（哪怕不来自真实粘贴过程）结果都相同，因为双方统计的都是同一个集合 $B$（$\subseteq[0,l-|w|]$）。girl 的论证逐字相同（把 $|w|$ 换成 4）。$\blacksquare$

**实现取舍**：

* **起点窗口版**（定理原样）：`for p: Att_w(p)` —— 代码就是定理的公式，天然不会数重，无需越界特判，$O(l\cdot|w|)=O(l)$。
* **逐字母 + 标记数组版**：按 2.2 的表把每个字母反解成起点 $p=i-d$，配上"起点合法"守卫和 `used[]` 去重 —— 按定义就是 $|B|$，和窗口版同解，只是多两个数组和一层判断。
* **逐字母贪心版**（引理 4 的公式，流传最广）：$O(l)$ 一遍扫完、$O(1)$ 空间，但条件串里少写一个 $s_{i-2}\ne\texttt b$ 就会把同一起点数两次，越界还要逐个挡，调试成本最高。

$l\le255$，快慢毫无差别，而本题错的全是"判定条件"，所以**选起点窗口版**：让代码和定理长得一样。

## 3. 模式总结（实际思考顺序）

- **explore its property** — 把"逐格覆盖"写成公式：$s_i$ 由最后一次盖住 $i$ 的操作决定；且 `.` ⟺ 从未被盖（写字母是不可逆操作）。
- **characterize the encoding** — 词内字母互异 (A) + 两词字母集不相交 (B) ⟹ 单个字母唯一反解出 (词, 偏移, 起点)，无需任何搜索匹配。
- **consider easier version** — 无覆盖时"起点集合 $B$"退化成子串出现位置集合，用作公式自检（`boy.girl` → 1,1）。
- **counterexample hunt** — 数字母在 `"boy"` 上过计（3 vs 1）；找子串在 `"bboy"`（2 vs 1）、`".boyy."`（2 vs 1）、`"gigirl"`（2 vs 1）上漏计；两个失败模式互补，定位到"去重 + 任一偏移作证"。
- **classic problem solution** — 集合计数 / 双射论证：引理 1（见证 ⟺ 存在）+ 引理 2（同词不同起点）⟹ 答案 $=$ 被见证起点数 $|B|,|G|$，$O(l)$ 扫窗口。
- **constraint audit** — 保证条件 $(\star)$ 与"贴词必须整词落在串内"分别撑起 ⟹ 与 ⟸；`"girl"`（boy 被完全盖）说明 $(\star)$ 不可省，起点范围 $[0,l-|w|]$ 说明循环上界为何是 $p+|w|\le l$。
- **equivalence proof（写法归一）** — 引理 4 证明"逐字母贪心"与"逐起点窗口"等价（每个 $p$ 的三个指示项恰好命中一次），据此选窗口版。
- **generality check** — 换成含重复字母的词（如 `"aab"`）签名反解失效，方法不再充分：字符集 `.bgilory` 是题目设计的核心。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `s[]` | 结果串 $s_0..s_{l-1}$ | `char s[mxn]`，全局默认 0，`cin>>s` 填入（自动补 `\0`） | 只含 `.bgilory` |
| `l` | 串长 $\|s\|$ | `int`，`l=strlen(s)`，$3\le l\le255$ | 起点范围由它决定 |
| $w$（`"boy"`/`"girl"`） | 被检查的词，$w[0..|w|-1]$ | 字面量 `const char*`，靠 `\0` 终止 | 长度 3 / 4 |
| $\mathrm{Att}_w(p)$（`seen(p,w)`） | 起点 $p$ 是否被 $w$ **见证**：$\bigvee_d s[p+d]==w[d]$ | 函数，返回 `bool`，不改状态 | "任一偏移的字母还露着" |
| `ansb` | boy 次数 $=\|B\|$ | `int`，从 0 累加 | 第一行输出 |
| `ansg` | girl 次数 $=\|G\|$ | `int`，从 0 累加 | 第二行输出 |
| `mxn` | 数组上界 $=255+5$ | `constexpr int mxn{260}` | +5 松弛（$255$ 个字符 + 结尾 `\0` $=256\le$ 260） |

> **下标约定**：内部一律 **0-based**，$p$ 就是"词的第一个字母所在格子"，与题面的"贴在字符串中某个位置"一致，无需 `--` 转换。

### 4.2 算法步骤

1. **读入** 一行字符串到 `s`（无空格，`cin>>s`），算出长度 `l`。
2. **数 boy**：`for p=0; p+3<=l; ++p`，若 `seen(p,"boy")`（即 $s[p]=\texttt b\vee s[p+1]=\texttt o\vee s[p+2]=\texttt y$）则 `++ansb`。`p+3<=l` 就是"整词必须落在串内"给出的合法起点上界 $p\le l-3$（定理中的 $B$）。
3. **数 girl**：`for p=0; p+4<=l; ++p`，若 $s[p]=\texttt g\vee s[p+1]=\texttt i\vee s[p+2]=\texttt r\vee s[p+3]=\texttt l$ 则 `++ansg`。
4. **输出** `ansb`、`ansg`，各占一行（题面要求两行两个整数）。

`seen` 的内层只跑 $|w|\le4$ 次比较，且**短路即停**（找到一个露着的字母就返回），不做任何回溯/匹配。

**复杂度**

* 时间：$O(l\cdot|w|_{\max})=O(l)$，$l\le255$ → 约 $(253+252)\times4\approx2\times10^3$ 次字符比较，远小于任何时限。
* 空间：$O(l)$（只存串，$260\,\text{B}$）；无 DP 表、无图、无容器。

**验证状态**：**手工验证**（本环境无编译器，未运行任何代码、未做随机对拍）——题面无样例，故自构造 8 组操作序列，逐格模拟出结果串，再手算 $B,G$ 并用引理 4 的贪心式独立复算，三种写法互验，全部一致；详见 4.3。

### 4.3 手工验证

约定：每组先按 2.1 的"最后一次写者"规则逐格模拟出 $s$（这是真值来源），再手算 $B,G$。

**(1) 无重叠（= 2.6 自检）** 构造 boy@0、girl@4（$l=8$）→ $s=$ `"boy.girl"`。$B=\{0\}$、$G=\{4\}$ → **(1,1)** ✓（逐项列表见 2.6）。

**(2) 部分重叠 · 同词** 构造 boy@0、boy@1（$l=4$）→ $s=$ `"bboy"`。
$B$：$p{=}0$: $s[0]=\texttt b$ ✓；$p{=}1$: $s[1]=\texttt b$ ✓ ⟹ $|B|=2$。$G$：唯一窗口 $p{=}0$ 比对 $(\texttt b,\texttt b,\texttt o,\texttt y)$ vs $(\texttt g,\texttt i,\texttt r,\texttt l)$ 全 ✗ ⟹ $|G|=0$。**(2,0)** ✓（子串法给 1，见 2.6 尝试 B）。

**(3) 完全重叠 · 异词（girl 只剩尾字母）** 构造 girl@0、boy@0（$l=4$）→ `girl` 后 `boy` 盖住 idx0..2 → $s=$ `"boyl"`。
$B$：$p{=}0$: $s[0]=\texttt b$ ✓ ⟹ 1。$G$：$p{=}0$: $s[0]{=}\texttt b\ne\texttt g$、$s[1]{=}\texttt o\ne\texttt i$、$s[2]{=}\texttt y\ne\texttt r$、$s[3]=\texttt l$ ✓ ⟹ 1。**(1,1)** ✓ —— 被盖掉 3 个字母的 girl 靠**偏移 3 的一个 `l`** 就被找回，这正是引理 1 的 ⟹ 方向。

**(4) 只剩 `y` 作证（= 2.7 的极端例）** 构造 boy@2、boy@1（$l=6$）→ $s=$ `".boyy."`。$B=\{1,2\}$、$G=\varnothing$ → **(2,0)** ✓（手算过程见 2.7）。

**(5) 交错混合** 构造 boy@0、girl@2、boy@4（$l=7$）：`.......` → boy@0 `boy....` → girl@2 写 idx2..5=`g,i,r,l` → `"bogirl."` → boy@4 写 idx4..6=`b,o,y` → $s=$ `"bogiboy"`。
$B$：$p{=}0$ ✓($s[0]=\texttt b$)；$p{=}1$: $(\texttt o,\texttt g,\texttt i)$ 需 $(\texttt b,\texttt o,\texttt y)$ ✗；$p{=}2$: $(\texttt g,\texttt i,\texttt b)$ ✗；$p{=}3$: $(\texttt i,\texttt b,\texttt o)$ ✗；$p{=}4$ ✓($s[4]=\texttt b$) ⟹ $|B|=2$。
$G$：$p{=}0$: $(\texttt b,\texttt o,\texttt g,\texttt i)$ vs $(\texttt g,\texttt i,\texttt r,\texttt l)$ ✗；$p{=}1$: $(\texttt o,\texttt g,\texttt i,\texttt b)$ ✗；$p{=}2$ ✓($s[2]=\texttt g$)；$p{=}3$: $(\texttt i,\texttt b,\texttt o,\texttt y)$ ✗ ⟹ $|G|=1$。**(2,1)** ✓
合法性核对（确认这组数据满足 $(\star)$）：boy@0 之后 idx0,1 再没被动过（girl@2 从 idx2 起，boy@4 从 idx4 起）⟹ 有幸存格 ✓；girl@2 写 idx2..5，之后只有 boy@4 覆盖了它的 idx4,5，故 idx2=`g`、idx3=`i` 仍露着 ✓；boy@4 三格全露 ✓。

**(6) girl 部分重叠** 构造 girl@0、girl@2（$l=6$）→ `girl..` → 再写 idx2..5=`g,i,r,l` → $s=$ `"gigirl"`。
$G$：$p{=}0$ ✓($s[0]=\texttt g$)；$p{=}1$: $(\texttt i,\texttt g,\texttt i,\texttt r)$ 需 $(\texttt g,\texttt i,\texttt r,\texttt l)$ ✗；$p{=}2$ ✓($s[2]=\texttt g$) ⟹ $|G|=2$。$B$：四个窗口 $(\texttt g,\texttt i,\texttt g)$、$(\texttt i,\texttt g,\texttt i)$、$(\texttt g,\texttt i,\texttt r)$、$(\texttt i,\texttt r,\texttt l)$ 与 $(\texttt b,\texttt o,\texttt y)$ 全不对位 ⟹ $|B|=0$。**(0,2)** ✓（子串法只找到 1 个 "girl"）。

**(7) 非法输入对照（说明 $(\star)$ 不可省）** 构造 boy@0、girl@0（$l=4$）→ girl 完全盖住 boy → $s=$ `"girl"`。公式给 $(0,1)$，而真实粘贴是 $(1,1)$。**该串违反题面保证**（boy 无任何未覆盖字符），且与"只贴一次 girl"的结果串无法区分 ⟹ 数据不会出现；若出现则问题本身无解。✓ 与 2.7 的论证一致。

**(8) 退化边界**：$l=3$ 的最小串。
* $s=$ `"boy"`（只贴 boy@0）：$B=\{0\}$（$p$ 只能取 0，$s[0]=\texttt b$ ✓），$G=\varnothing$（$p+4\le3$ 无解，循环不执行）→ **(1,0)** ✓。
* $s=$ `"..."`（0 次操作 / 未贴任何字母）：所有 $s[p+d]$ 都是 `.`，与任何字母不等 ⟹ **(0,0)** ✓。注意此时 $\mathrm{Att}$ 判定天然为假，代码无需特判"全句号"；但严格按题面"多次把单词贴上"它可能不是合法输入，这里只作为公式的边界自检。

**(9) 三种写法互验**：主写法（窗口版 $|B|$）已在 (1)–(8) 逐项手算；标记数组版（第 5 节备选代码）按定义就是"$|B|$ 逐个认领起点"，与主写法同源；下面再用引理 4 的"逐字母 + 看左边同词前一字母"贪心式独立复算一遍（这一版最容易写错，用它互验最有价值）。

* $s=$ `"bboy"`：$i{=}0$ `b` +1；$i{=}1$ `b` +1；$i{=}2$ `o` 但 $s_1=\texttt b$ ⟹ 跳过；$i{=}3$ `y` 但 $s_2=\texttt o$ ⟹ 跳过 ⟹ **2** $=|B|$ ✓。
* $s=$ `".boyy."`：$i{=}1$ `b` +1；$i{=}2$ `o`（左边是 `b`）跳过；$i{=}3$ `y`（左边 `o`）跳过；$i{=}4$ `y`：$s_3=\texttt y\ne\texttt o$ 且 $s_2=\texttt o\ne\texttt b$ ⟹ +1 ⟹ **2** ✓（说明"只剩 `y` 作证"时贪心也确实能认出来）。
* $s=$ `"bogiboy"`：boy 侧 $i{=}0$ `b` +1、$i{=}1$ `o`（左 `b`）跳、$i{=}4$ `b` +1、$i{=}5$ `o`（左 `b`）跳、$i{=}6$ `y`（左 `o`）跳 ⟹ 2 ✓；girl 侧 $i{=}2$ `g` +1、$i{=}3$ `i`（左 `g`）跳 ⟹ 1 ✓。
* $s=$ `"boyl"`：girl 侧 $i{=}3$ `l`：$s_2=\texttt y\ne\texttt r$、$s_1=\texttt o\ne\texttt i$、$s_0=\texttt b\ne\texttt g$ ⟹ +1 ⟹ 1 ✓（boy 侧 $i{=}0$ `b` +1，$i{=}1$ `o` 左 `b` 跳，$i{=}2$ `y` 左 `o` 跳 ⟹ 1 ✓）。
* $s=$ `"gigirl"`：girl 侧 $i{=}0$ `g` +1、$i{=}1$ `i`（左 `g`）跳、$i{=}2$ `g` +1、$i{=}3$ `i`（左 `g`）跳、$i{=}4$ `r`（左 `i`）跳、$i{=}5$ `l`（左 `r`）跳 ⟹ **2** ✓；boy 侧不含 b/o/y ⟹ 0 ✓。

**结论**：9 组手工推演（无重叠 / 同词部分重叠 / 异词完全重叠 / 只剩尾字母作证 / 交错混合 / girl 部分重叠 / 非法输入对照 / $l=3$ 与全句号退化 / 三种写法互验）全部与引理 1、2、3、4 及定理的结论一致，未发现反例。正确性依据是**证明**而非实验：本环境无编译器，未运行任何代码、未做随机对拍。

## 5. 示例代码（C++）

```cpp
// P1321 单词覆盖还原
// https://www.luogu.com.cn/problem/P1321
// 答案 = 被"见证"的起点个数：字母互异 => 单个字母即可反解出(词,起点)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{260};                 // l<=255，+5 松弛（含结尾 '\0'）

char s[mxn];

bool seen(int p,const char*w)           // Att_w(p)：某个偏移上的字母还露着
{
	for(int i=0;w[i];++i)
		if(s[p+i]==w[i])
			return true;
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	int l=strlen(s),ansb=0,ansg=0;
	for(int p=0;p+3<=l;++p)              // 整词必须落在串内 => p<=l-3
		if(seen(p,"boy"))
			++ansb;
	for(int p=0;p+4<=l;++p)
		if(seen(p,"girl"))
			++ansg;

	cout<<ansb<<'\n'<<ansg<<'\n';
	return 0;
}
```

### 代码说明

- **`seen` 就是定理里的 $\mathrm{Att}_w(p)$**：`for(int i=0;w[i];++i)` 靠字面量的 `'\0'` 终止，词长不需要写死；命中即 `return true`，对应"任一偏移作证即可"。
- **循环上界 `p+3<=l` / `p+4<=l`**：等价于 $p\in[0,l-|w|]$，既是"贴词必须整词落在串内"，也保证 `s[p+i]` 永不越界（最大访问 `s[l-1]`），因此不需要任何边界特判。$l<4$ 时 girl 循环自然不执行（$l\ge3$ 已由数据保证）。
- **去重是"免费"的**：外层枚举的是**起点**，同一个 boy 露出 3 个字母也只被访问一次 —— 不会出现 2.6 尝试 A 的过计。
- **`.` 的处理**：`s[p+i]=='.'` 与任何字母都不相等，等价于"该格从未被覆盖，不为此起点作证"，无需显式判点。
- **移植坑对照**：全局 `char s[mxn]` 默认 0，`cin>>s` 只填前 $l$ 格，其余保持 `'\0'`；本解法只读 $[0,l-1]$，且没有需要预置 INF 的状态，故不需要 `fill_n`。若改成**多组数据**版本，必须在每组开始前 `ansb=ansg=0;`（若复用 `s` 还要保证被新串覆盖，最省事是声明为局部 `string`）。

### 备选写法（把 2.2 的"字母 → (词, 偏移)"表原样写成代码）

主写法枚举起点、内部比对偏移；下面这版反过来——枚举字母、反解起点、**用标记数组去重**，它按定义就是 $|B|$ 与 $|G|$，因此与主写法必然同解。

```cpp
	bool usedb[mxn],usedg[mxn];     // 全局 bool 默认 false，正好是"该起点尚未被认领"
	int l=strlen(s),ansb=0,ansg=0;
	for(int i=0;i<l;++i)
	{
		int p=-114514;               // 由字母反解出的起点；哨兵表示"不是 boy 的签名"
		if(s[i]=='b')
			p=i;
		else if(s[i]=='o')
			p=i-1;
		else if(s[i]=='y')
			p=i-2;
		if(p!=-114514)
		{
			if(p>=0&&p+3<=l&&!usedb[p])   // 起点必须放得下整词（防非法串的越界签名）
				usedb[p]=true,++ansb;
			continue;
		}
		p=-114514;
		if(s[i]=='g')
			p=i;
		else if(s[i]=='i')
			p=i-1;
		else if(s[i]=='r')
			p=i-2;
		else if(s[i]=='l')
			p=i-3;
		if(p!=-114514&&p>=0&&p+4<=l&&!usedg[p])
			usedg[p]=true,++ansg;
	}
```

> **两个坑**：**(a)** `usedb/usedg` 是"去重"的全部来源，漏掉标记就会把 2.6 的尝试 A（数字母）搬回来；**(b)** `p>=0&&p+len<=l` 这两个守卫在合法数据上恒真（引理 4 边界段），但少了它们，遇到不来自真实粘贴过程的串就会读越界字母/写越界数组。至于流传更广的"看左边同词前一字母是否已被数过"式贪心（引理 4 的公式），与本版等价，但少写一个前置检查就重算、且必须逐个处理 $i-1,i-2,i-3$ 越界，可读性最差，这里不采用。

> **复杂度复核**：$O(l)$ 时间、$O(l)$ 空间，$l\le255$；答案 $\le l$（起点互不相同），`int` 足够，无溢出风险。
