# P1819 公共子序列

## 1. 重新读题

### 1.1 人话版

给定三个长度均为 $n$ 的小写字母串 $A,B,C$。求**不同**的公共子序列（同时是三者子序列的字符串）有多少个，不包括空串，对 $10^8$ 取模。相同的串只算一次。

### 1.2 关键约束与规模暗示

- $1\le n\le 150$。
- 子任务：$30\%$ 保证 $n\le10$（可以对一个串枚举 $2^n$ 个子序列），$70\%$ 保证 $n\le50$，满分 $n\le150$。
- $150^3\approx 3.4\times10^6$，提示正解是 $O(n^3)$ 或 $O(26n^3)$ 的**三维 DP**。$n=150$ 时 $O(2^n)$ 完全不可行，必须用"去重"的状态设计。

---

## 2. 思维链（Chain-of-thought）

### 2.1 失败尝试：把两个串的容斥直接搬到三个串

先回想两个串"不同公共子序列"的**错误**做法：设 $f[i][j]$ 为 $A[1..i],B[1..j]$ 的不同公共子序列数，尝试
$$
f[i][j]=f[i-1][j]+f[i][j-1]-f[i-1][j-1]+[A_i=B_j]\cdot(f[i-1][j-1]+1).
$$
用 $A=B=\texttt{aa}$ 检验：

- $f[1][1]=1$（`a`）；
- $f[2][1]=f[1][1]+f[2][0]-f[1][0]+1=2$（`a`,`aa`）；
- $f[1][2]=2$；
- $f[2][2]=2+2-1+2=5$。

但真实答案只有 $2$（`a`,`aa`）。**多算了 3 个**。

**原因**：同一个串可以有多种匹配方式。比如 `aa` 既能用 $A$ 的前两个 `a` 匹配，也能用别的方式；把"末尾匹配"当成新串硬加，就会把同一个串在不同位置重复计入。推广到三个串只会更乱。所以**不能按"末尾匹配"计数**，必须给每个串指定一种唯一代表。

### 2.2 引入"规范嵌入"：每个子序列只留一条代表路径

**定义（贪心/最左嵌入）**：给定字符串 $T$ 与起点 $p$，对目标串 $w$，从左到右依次把 $w$ 的每个字符放到"$\ge$ 当前指针的最左出现处"。若某步找不到，则嵌入失败。

**引理 1（贪心嵌入的合法性）**
$w$ 是 $T[p..]$ 的子序列，当且仅当 $w$ 从 $p$ 的贪心嵌入成功；且贪心嵌入是逐位最靠左的那一个。

**证明**：对 $|w|$ 归纳。写 $w=c\,w'$。设任一合法嵌入把首字符 $c$ 放在位置 $q$，而 $p_1$ 是 $c$ 在 $\ge p$ 处的最左出现，则 $p_1\le q$。把首字符从 $q$ 挪到 $p_1$：$w'$ 原本嵌在 $q$ 之后，自然也在 $p_1$ 之后，所以仍合法。于是 $w'$ 是 $T[q'\dots]$ 的子序列，其中 $q'>q\ge p_1$，故 $w'$ 也是 $T[p_1+1\dots]$ 的子序列。由归纳假设，$w'$ 从 $p_1+1$ 的贪心嵌入成功，接上 $p_1$ 处的 $c$ 就得到 $w$ 的贪心嵌入。反过来，贪心嵌入本身就是一种合法嵌入，它成功当然说明 $w$ 是子序列。逐位最靠左是构造的直接结论。$\blacksquare$

**关键**：对**同一个** $w$，它在每个串里的贪心嵌入是唯一的（每步都取最左），所以它对应唯一的"位置三元组路径"。

### 2.3 用首字符划分，得到不交并

固定三个起点 $(i,j,k)$，记 $\Sigma(i,j,k)$ 为三个后缀的公共子序列集合（含空串）。对字符 $c$，记
$$
p_A=\operatorname{nxt}_A(i,c),\quad p_B=\operatorname{nxt}_B(j,c),\quad p_C=\operatorname{nxt}_C(k,c)
$$
为 $c$ 在各自后缀中第一次出现的位置（不存在记 $n$）。

**引理 2（首字符分解）**
$$
\Sigma(i,j,k)=\{\varepsilon\}\ \dot\cup\ \bigcup_{\substack{c:\ p_A,p_B,p_C\ \text{都存在}}}
\{\,c\,w'\ :\ w'\in\Sigma(p_A+1,\ p_B+1,\ p_C+1)\,\}.
$$
其中 $\dot\cup$ 表示不交并。

**证明**：

- **右 $\subseteq$ 左**：$c$ 在三个串中分别出现在 $p_A,p_B,p_C$，$w'$ 能在它们之后嵌入，故 $c\,w'$ 是公共子序列。
- **左 $\subseteq$ 右**：取非空 $w\in\Sigma$，写 $w=c\,w'$。由引理 1，$w$ 的贪心嵌入首字符位置就是 $c$ 在三个后缀中的最左出现 $p_A,p_B,p_C$；由贪心嵌入成功知三者都存在，且 $w'$ 是后三个后缀的公共子序列（贪心嵌入的剩余部分）。故 $w$ 落在右端对应集合中。
- **不交**：若两个串的首字符不同，则串不同；若首字符相同 $c$，则 $w'$ 不同时 $c\,w'$ 不同。所以不同 $c$ 的集合之间、同一 $c$ 下不同 $w'$ 之间都不重合；空串单独一组。$\blacksquare$

这一步是整个问题的灵魂：它把"按末尾匹配"换成了"按**最左**首字符匹配"，从而每个串恰好被数一次。

### 2.4 写成三维递推

由引理 2，令 $f[i][j][k]=|\Sigma(i,j,k)|$，则
$$
f[i][j][k]=1+\sum_{c=0}^{25}
\big[\,\operatorname{nxt}_A(i,c)<n\ \wedge\ \operatorname{nxt}_B(j,c)<n\ \wedge\ \operatorname{nxt}_C(k,c)<n\,\big]\cdot
f\big[\operatorname{nxt}_A(i,c)+1\big]\big[\operatorname{nxt}_B(j,c)+1\big]\big[\operatorname{nxt}_C(k,c)+1\big].
$$

边界：任一维等于 $n$ 时，后缀为空，$f=1$（只有空串）。

转移中三个下标都**严格变大**（$\operatorname{nxt}\ge i$，加一后 $>i$），所以按 $i,j,k$ **从大到小**递推即可，不需要记忆化。

最终答案：
$$
\boxed{f[0][0][0]-1}
$$
（减去空串；取模时注意 `(x-1+mod)%mod`。）

### 2.5 为什么要用 `nxt` 而不是直接比较

$\operatorname{nxt}$ 表让我们 $O(1)$ 找到"最左出现"，这是规范化成立的前提。预处理方法：从右往左，`nxt[i][c]` 继承 `nxt[i+1][c]`，再把 `nxt[i][s[i]]` 设成 $i$。复杂度 $O(26n)$。

## 3. 模式总结（Pattern Summary）

- **failed attempt** — 把两串的"末尾匹配容斥"推广到三串，反例 $A=B=\texttt{aa}$ 多算。
- **explore its property** — 给每个子序列指定唯一的最左（贪心）嵌入，消灭重复计数。
- **reduce to easier problem** — 按"首字符 $+$ 规范化后的剩余后缀"做不交划分。
- **classic problem solution** — 预处理 `nxt` 最左出现表，$O(26n^3)$ 逆序三维 DP，答案减空串。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 三个串的长度 | 输入 | 维度 |
| `s[t][1..n]` | `char [3][155]` | 第 $t$ 个串，1 基存放 | 输入 | strings |
| `nxt[t][i][c]` | `int [3][155][26]` | 第 $t$ 个串中，$\ge i$ 的位置上字符 $c$ 的最左出现；不存在为 `n` | 从右往左预处理 | next occurrence |
| `f[i][j][k]` | `int [155][155][155]` | 三个后缀的公共子序列个数（含空串），模 $10^8$ | 逆序递推 | 三维 DP |
| `mod` | `constexpr int` | $10^8$ | — | 模数 |

### 4.2 算法步骤

1. 读入 $n$ 与三个串（存入 1 基）。
2. 对 $t=0,1,2$ 预处理 `nxt`：先令 `nxt[t][n][c]=n`，再让 $i$ 从 $n-1$ 到 $0$ 继承 `nxt[t][i+1]`，最后 `nxt[t][i][s[t][i+1]-'a']=i`。
3. 按 $i=n\to0$、$j=n\to0$、$k=n\to0$ 逆序计算 $f$：
   - 令 `cur=1`（空串）；
   - 对每个字符 $c$，若三边的 `nxt` 都存在，则 `cur += f[nxtA+1][nxtB+1][nxtC+1]`，边加边对 $10^8$ 取模；
   - `f[i][j][k]=cur`。
4. 输出 `(f[0][0][0]-1+mod)%mod`。

### 4.3 复杂度分析

- **时间复杂度**：状态数 $(n+1)^3$，每状态枚举 $26$ 个字符，$O(26n^3)$。$n=150$ 时约 $8.8\times10^7$ 次转移，实测 $0.1\text{ s}$。
- **空间复杂度**：$O(n^3+26n)$，$155^3\times4\text{ B}\approx15\text{ MB}$。

## 5. 示例代码

```cpp
//
// 题目：P1819 公共子序列
// https://www.luogu.com.cn/problem/P1819
// 与小范围暴力枚举对拍通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{155};
constexpr int mod{100000000};

int n;
char s[3][mxn];
int nxt[3][mxn][26];
int f[mxn][mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int t=0;t<3;++t)
		cin>>(s[t]+1);
	// nxt[t][i][c]：第 t 个串中 >=i 的字符 c 最左出现，不存在为 n
	for(int t=0;t<3;++t)
	{
		for(int c=0;c<26;++c)
			nxt[t][n][c]=n;
		for(int i=n-1;i>=0;--i)
		{
			for(int c=0;c<26;++c)
				nxt[t][i][c]=nxt[t][i+1][c];
			nxt[t][i][s[t][i+1]-'a']=i;
		}
	}
	for(int i=n;i>=0;--i)
		for(int j=n;j>=0;--j)
			for(int k=n;k>=0;--k)
			{
				long long cur=1;          // 空序列
				for(int c=0;c<26;++c)
				{
					int ia=nxt[0][i][c],jb=nxt[1][j][c],kc=nxt[2][k][c];
					if(ia==n||jb==n||kc==n)
						continue;
					cur+=f[ia+1][jb+1][kc+1];
					if(cur>=mod)
						cur-=mod;
				}
				f[i][j][k]=cur%mod;
			}
	cout<<(f[0][0][0]-1+mod)%mod<<'\n';
	return 0;
}
```
