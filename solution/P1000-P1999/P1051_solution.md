# P1051 [NOIP 2005 提高组] 谁拿了最多奖学金 题解

## 一、题目大意

给定 $N$ 名学生的个人信息，每名学生有**五项奖学金**的评选资格。只要满足某奖学金的条件即可获得该奖学金（人数不限，可兼得）。需要找出：

1. 获得奖金总额最高的学生姓名（若并列，取输入中最早出现的）；
2. 该学生的奖金总额；
3. 所有学生奖金总额的总和。

五类奖学金条件如下：

| 奖学金 | 金额 | 期末平均成绩 | 班级评议成绩 | 其他条件 |
| --- | --- | --- | --- | --- |
| 院士奖学金 | 8000 | $>80$ | — | 发表论文 $\ge 1$ 篇 |
| 五四奖学金 | 4000 | $>85$ | $>80$ | — |
| 成绩优秀奖 | 2000 | $>90$ | — | — |
| 西部奖学金 | 1000 | $>85$ | — | 西部省份学生 |
| 班级贡献奖 | 850 | — | $>80$ | 学生干部 |

数据范围：$1 \le N \le 100$，成绩、论文数均为整数。

---

## 二、解题思路

本题是纯粹的**模拟**，无需任何高级算法。只需逐行读入学生信息，对每个学生依次判断五项条件，累加奖学金，同时维护全局最大值与总和即可。

设计要点：

- **结构体或直接处理**：由于 $N \le 100$，可以边读边算，也可以先存入数组再统一处理。两种做法均可，本题解采用**结构体数组存储**后统一处理的方式，更清晰。
- **并列处理**：题目要求"奖金最多且最早出现"；因此维护最大值时，仅当**严格大于**当前最大值时才更新答案，相等时不更新，自然保留了最早出现者。
- **数据类型**：每名学生的奖学金最多为 $8000+4000+2000+1000+850 = 15850$，$N=100$ 时总和最多约 $1.58\times 10^6$，`int` 足够。

## 三、代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;

struct Student
{
    string name;
    int avg;       // 期末平均成绩
    int cls;       // 班级评议成绩
    char cadre;    // 是否学生干部 Y/N
    char west;     // 是否西部省份 Y/N
    int papers;    // 论文数
};

int main()
{
    cin.tie(nullptr);
    ios::sync_with_stdio(false);

    int n;
    cin >> n;

    vector<Student> stu(n);
    for(int i = 0; i < n; ++i)
    {
        cin >> stu[i].name >> stu[i].avg >> stu[i].cls
            >> stu[i].cadre >> stu[i].west >> stu[i].papers;
    }

    int total = 0;           // 所有学生奖学金总和
    int mx = -1;             // 最高奖学金金额
    string winner;           // 获得最高奖学金的学生姓名

    for(int i = 0; i < n; ++i)
    {
        int cur = 0;
        auto &s = stu[i];

        if(s.avg > 80 && s.papers >= 1)
            cur += 8000;
        if(s.avg > 85 && s.cls > 80)
            cur += 4000;
        if(s.avg > 90)
            cur += 2000;
        if(s.avg > 85 && s.west == 'Y')
            cur += 1000;
        if(s.cls > 80 && s.cadre == 'Y')
            cur += 850;

        total += cur;

        if(cur > mx)
        {
            mx = cur;
            winner = s.name;
        }
    }

    cout << winner << '\n';
    cout << mx << '\n';
    cout << total << '\n';

    return 0;
}
```

---

## 四、复杂度分析

- **时间复杂度**：$O(N)$。每个学生只需常数次判断。
- **空间复杂度**：$O(N)$，用于存储学生信息。若边读边算则可优化为 $O(1)$。

---

## 五、注意事项

1. **条件中的严格不等号**：题目中 $>80$、$>85$、$>90$ 均为**严格大于**，不含等于。例如平均分恰好 $80$ 分不能获得院士奖学金。
2. **论文数条件**：院士奖学金要求论文数 $\ge 1$，注意是 $\ge$ 而非 $>$，即 $1$ 篇即可。
3. **并列名次**：更新最大值时使用 `if(cur > mx)` 而非 `if(cur >= mx)`，这样当出现并列时不会覆盖已记录的名字，自然保留了最早出现的学生。
4. **输入格式**：姓名中不包含空格，可直接用 `cin >> string` 读取。
5. **初始化**：`mx` 初始化为 $-1$ 或 $0$ 均可，因为每名学生的奖学金一定非负，首次判断一定会被更新。
