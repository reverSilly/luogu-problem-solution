# P1255 数楼梯

## 1. 重读题目

楼梯有 $N$ 阶，上楼时每一步要么走 1 阶，要么走 2 阶。问有多少种不同的走法能走完全部 $N$ 阶。

- 输入：一个整数 $N$。
- 输出：走法总数（一个十进制整数，可能很长）。
- 约束：$1 \le N \le 5000$。
- 子任务：$N \le 50$ 占 60%，$N \le 5000$ 占 100%。

## 2. 思维链（按真实思考顺序）

### 2.1 先算几个小值

先把 $N$ 很小的情况手算出来，看看有没有规律。

- $N=1$：只能走 1。共 $1$ 种。
- $N=2$：$(1,1)$ 或 $(2)$。共 $2$ 种。
- $N=3$：枚举所有由 1 和 2 组成、和为 3 的序列：
  - $(1,1,1)$
  - $(1,2)$
  - $(2,1)$

  共 $3$ 种。
- $N=4$：枚举：
  - $(1,1,1,1)$
  - $(1,1,2)$
  - $(1,2,1)$
  - $(2,1,1)$
  - $(2,2)$

  共 $5$ 种。

序列是 $1,2,3,5,\ldots$。这看起来很像斐波那契数列。

### 2.2 找递推关系

设 $f(n)$ 为走完 $n$ 阶的走法数。考虑**最后一步**：

- 若最后一步是 1 阶，则之前的 $n-1$ 阶有 $f(n-1)$ 种走法；
- 若最后一步是 2 阶，则之前的 $n-2$ 阶有 $f(n-2)$ 种走法。

这两类情况按最后一步的大小划分，互斥且覆盖所有走法，所以：

$$f(n)=f(n-1)+f(n-2) \quad (n\ge 3)$$

初值：$f(1)=1$，$f(2)=2$。

注意这里的初值跟标准斐波那契（$F_1=F_2=1$）不同，所以 $f(n)$ 实际上等于标准斐波那契 $F_{n+1}$：

- $F_1=1, F_2=1, F_3=2, F_4=3, F_5=5$；
- $f(1)=F_2=1$，$f(2)=F_3=2$，$f(3)=F_4=3$，$f(4)=F_5=5$。

对 $n=1,2$ 直接验证初值匹配，对 $n\ge 3$ 两边都满足相同的二阶线性递推 $x(n)=x(n-1)+x(n-2)$，所以对所有 $n\ge 1$ 都有 $f(n)=F_{n+1}$。

### 2.3 规模估算：需要高精度

$F_{n+1}$ 大约以 $\varphi^n$ 增长，$\varphi=(1+\sqrt5)/2\approx1.618$。

当 $n=5000$ 时，$\varphi^{5000}$ 的量级是 $10^{5000\cdot\log_{10}\varphi}\approx10^{5000\cdot0.209}\approx10^{1045}$。

也就是说答案有大约 $1045$ 位十进制数。64 位整数最多约 $19$ 位，远远不够。所以**必须用高精度加法**。

### 2.4 算法定型

从 $f(1),f(2)$ 开始，用高精度加法一路算到 $f(N)$，时间复杂度 $O(N\cdot L)$（$L$ 是位数），空间 $O(L)$。

## 3. 模式总结

- **手算小值找规律** — 列出 $N=1,2,3,4$ 的走法数，识别出 $1,2,3,5$ 的斐波那契特征。
- **按最后一步分类递推** — 用"最后一步是 1 阶还是 2 阶"做互斥划分，得到 $f(n)=f(n-1)+f(n-2)$。
- **估计数值规模** — $\varphi^{5000}\approx10^{1045}$，判断 64 位不够，必须高精度。
- **递推 + 高精度** — 线性递推直接滚动数组，加法用高精度十进制数组实现。

## 4. 真实解法

### 记号表

| 符号 | 含义 |
| :--- | :--- |
| $N$ | 楼梯阶数，$1\le N\le 5000$ |
| `a`, `b`, `c` | 高精度十进制数，下标 0 为个位（little-endian），`len` 为有效位数 |
| `mxn` | $N$ 的上界 $5000$ |
| `mxl` | 位数上界，取 $11000$（$\varphi^{5000}$ 约 $1045$ 位，留足余量） |
| `f1`, `f2` | 滚动状态：$f1$ 存 $f(k-1)$，$f2$ 存 $f(k)$，逐步推进 |

高精度数用一个 `struct Big` 表示：`int d[mxl]`（$d[0]$ 是个位），`int len`（有效位数）。加法按位相加进位。

### 算法步骤

1. 读入 $N$。
2. 特判：若 $N=1$，直接输出 $1$；若 $N=2$，直接输出 $2$。
3. 令 $f1=\text{Big}(1)$（$f(1)$），$f2=\text{Big}(2)$（$f(2)$）。
4. 从 $k=3$ 到 $N$：
   - $c = f1 + f2$（高精度加法，逐位相加并处理进位）；
   - $f1 \leftarrow f2$，$f2 \leftarrow c$。
5. 输出 $f2$（高位到低位，跳过前导零）。

### 复杂度

- 时间：$O(N\cdot L)$，$L$ 为最大位数 $\approx 1100$，共约 $5\cdot10^6$ 次加法，足够快。
- 空间：$O(L)$，三个高精度数。

### 验证状态

- $N=1$ → $1$；$N=2$ → $2$；$N=3$ → $3$；$N=4$ → $5$；$N=5$ → $8$，与手算一致。
- 递推 $f(n)=f(n-1)+f(n-2)$ 对所有 $n\ge 3$ 成立（最后一步分类，互斥且完备）。
- 高精度加法：进位处理 $d[i]\ge 10$ 时 $d[i]\mathrel{-}=10$ 并向上传，末位若产生新位则 $len$ 增加，正确。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{5005};
constexpr int mxl{11000};

struct Big
{
	int d[mxl]{};
	int len=1;
	Big(int v=0)
	{
		while(v)
		{
			d[len++]=v%10;
			v/=10;
		}
	}
};

Big add(Big a,Big b)
{
	Big c{};
	int carry=0;
	for(int i=0;i<max(a.len,b.len)||carry;++i)
	{
		int s=carry;
		if(i<a.len)s+=a.d[i];
		if(i<b.len)s+=b.d[i];
		c.d[i]=s%10;
		carry=s/10;
		c.len=i+1;
	}
	return c;
}

void print(Big a)
{
	for(int i=a.len-1;i>=0;--i)
		cout<<a.d[i];
	cout<<'\n';
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	if(n==1)
	{
		cout<<1<<'\n';
		return 0;
	}
	if(n==2)
	{
		cout<<2<<'\n';
		return 0;
	}
	Big f1{1},f2{2},c;
	for(int k=3;k<=n;++k)
	{
		c=add(f1,f2);
		f1=f2;
		f2=c;
	}
	print(f2);
	return 0;
}
```
