## 1. 重新读题

**问题重述（简化版）**

全集 $U=\{1,2,\dots,n\}$。把它拆成两个子集 $A,B$，要求

$$A\cap B=\varnothing,\qquad A\cup B=U,\qquad \sum_{x\in A}x=\sum_{y\in B}y$$

求满足条件的拆法数。题面明确：**交换 $A,B$ 的位置算同一种**，即我们数的是**无序对** $\{A,B\}$。

**等价的单边表述**：记 $S=\sum_{i=1}^{n}i=\dfrac{n(n+1)}{2}$。因为 $B=U\setminus A$，所以

$$\sum_{x\in A}x=\sum_{y\in U\setminus A}y\iff 2\sum_{x\in A}x=S\iff \sum_{x\in A}x=\frac{S}{2}$$

也就是说：**"等和划分"完全等价于"选一个子集，使其元素和恰为 $S/2$"**，只是最后要把"子集"折成"无序对"。这一步是整个题的翻译工作，后面全部推理都建立在它之上。

| $S=\frac{n(n+1)}{2}$ | $780$ |

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制 —— 和的奇偶性把一半输入直接判死

先把"等和"这件事拆开看。若 $A\cup B=U$、$A\cap B=\varnothing$ 且 $\sum A=\sum B$，则

$$S=\sum_{i=1}^{n}i=\sum A+\sum B=2\sum A$$

**引理 1（必要条件）** 若存在等和划分，则 $S$ 为偶数。

**证明**：由上式 $S=2\sum A$，右端是 2 的倍数，故 $S$ 为偶数。$\blacksquare$

**引理 2（$S$ 何时为偶）** $\dfrac{n(n+1)}{2}$ 为偶数 $\iff$ $4\mid n(n+1)$ $\iff$ $n\equiv 0$ 或 $3\pmod 4$。

**证明**：

1. $\frac{n(n+1)}{2}$ 为偶 $\iff$ 存在整数 $m$ 使 $\frac{n(n+1)}{2}=2m$ $\iff$ $n(n+1)=4m$ $\iff$ $4\mid n(n+1)$。
2. $n$ 与 $n+1$ 一奇一偶（连续整数必不同奇偶），故 $n(n+1)$ 中"因子 2 的个数"完全由那个偶数提供。
3. 若那个偶数被 $4$ 整除，即 $4\mid n$（此时 $n$ 是偶数，$n\equiv 0\pmod 4$）或 $4\mid(n+1)$（此时 $n+1$ 是偶数，$n\equiv 3\pmod 4$），则 $4\mid n(n+1)$。
4. 反之若 $n\equiv 1\pmod 4$，则 $n$ 奇、$n+1\equiv 2\pmod 4$ 只含一个因子 2，乘积只含一个因子 2，$4\nmid n(n+1)$；若 $n\equiv 2\pmod 4$，则 $n\equiv 2\pmod 4$ 只含一个因子 2、$n+1$ 为奇数，同样 $4\nmid n(n+1)$。

   综合 2–4 得 $4\mid n(n+1)\iff n\equiv 0,3\pmod 4$。$\blacksquare$

于是 $n\equiv 1,2\pmod 4$（即 $n=1,2,5,6,9,10,\dots$）答案必为 $0$。这是**第一道剪枝**，§2.6 会补上它的充分性（偶数情形一定至少有 1 种），保证剪掉的确实全是零解、没有误杀。

**如果偷懒不做这个剪枝会怎样？** 因为 C++ 里 `S/2` 对奇数会向下取整，程序会去数"和为 $\lfloor S/2\rfloor$ 的子集"，那批子集与本题毫无关系，但它们的个数不是 0。反例（手算，集合都可列举）：

| $n$ | $S$ | 正确的整除判定 | 不判奇偶时程序去数的目标 $t=\lfloor S/2\rfloor$ | 和为 $t$ 的子集 | 不判奇偶输出 | 正确答案 |
|---|---|---|---|---|---|---|
| $5$ | $15$ | 奇 → 应输出 0 | $7$ | $\{2,5\},\{3,4\},\{1,2,4\}$ 共 3 个 | $\lfloor 3/2\rfloor=1$ | $0$ |
| $6$ | $21$ | 奇 → 应输出 0 | $10$ | $\{4,6\},\{1,3,6\},\{1,4,5\},\{2,3,5\},\{1,2,3,4\}$ 共 5 个 | $\lfloor 5/2\rfloor=2$ | $0$ |

$n=6$ 那 5 个子集逐个验：$4+6=10$、$1+3+6=10$、$1+4+5=10$、$2+3+5=10$、$1+2+3+4=10$；再确认没有漏。按子集大小分类：一元需 $10\notin\{1..6\}$ → 0；二元 $a<b\le6$、$a+b=10$ → 只有 $(4,6)$（$(5,5)$ 元素重复，$(3,7)$ 越界）→ 1；三元 $a<b<c\le6$、和 10 → $c=6$ 时 $a+b=4$ 给 $(1,3)$；$c=5$ 时 $a+b=5$ 给 $(1,4),(2,3)$ → 共 3；四元最小 $1+2+3+4=10$ → 1；五元最小 $15>10$ → 0。合计 $0+1+3+1+0=5$ ✓。

### 2.3 剖析两个错误猜想 —— "个数相等"与"不用去重"

**猜想 A（贪心式的直觉）**：两个子集元素个数也该相等，于是答案 $=\dfrac{1}{2}\binom{n}{n/2}$ 之类。

被打死的方式有两个，而且第一个就写在题面里：

- 题面 $n=7$ 的四种划分，两边大小分别是 $3|4$、$3|4$、$3|4$、$4|3$——**没有一种**两边个数相等。所以"等和"根本推不出"等个数"，猜想 A 的前提就是假的。
- 数值反例 $n=4$：真值 1（和为 5 的子集只有 $\{1,4\}$ 与 $\{2,3\}$，见 §2.2 的 $f_4(5)=2$，折半后 1 种）。按猜想 A 会得到 $\binom{4}{2}/2=3$，多出 2。多出来的是哪两个？$\binom{4}{2}$ 数的是"任取 2 个"：$\{1,2\}=3,\{1,3\}=4,\{1,4\}=5,\{2,3\}=5,\{2,4\}=6,\{3,4\}=7$，只有 $\{1,4\},\{2,3\}$ 凑到 5，另外 4 个根本不等和——"个数相等"约束的是**基数**，题目约束的是**加权和**，两个不同的量。

**猜想 B（漏掉无序对）**：直接输出 $f_n(S/2)$。

- 反例 $n=3$：$f_3(3)=2$，而题面明说"**唯一一种**分法"，输出 2 直接与题面冲突。原因是 $\{3\}$ 与 $\{1,2\}$ 是同一次划分的两种写法。

**猜想 C（把它当最值题来贪心）**：本题是**计数**，不是"最少组数/最长串"那种判定+构造。计数题没有"贪心取大的"这条出路，只有"不重不漏"两条腿：先按可重/不可重分类做加法，再处理对称性去重。想清楚这点，路线就只剩"背包计数 + 补集配对去重"。

### 2.4 去重的严格证明 —— 补集映射是无不动点的对合

设 $\mathcal{F}=\{A\subseteq U:\ \sum_{x\in A}x=S/2\}$（只在 $S$ 为偶数时有意义）。定义 $\varphi(A)=U\setminus A$。

**引理 3（$\varphi$ 是 $\mathcal{F}$ 上的无不动点对合）**

1. 封闭性：若 $A\in\mathcal{F}$，则 $\sum(U\setminus A)=S-\sum A=S-S/2=S/2$，故 $\varphi(A)\in\mathcal{F}$。
2. 对合性：$\varphi(\varphi(A))=U\setminus(U\setminus A)=A$。
3. 无不动点：设 $A=\varphi(A)=U\setminus A$。取元素 $n\in U$（$n\ge1$，故 $U$ 非空）。若 $n\in A$，由 $A=U\setminus A$ 得 $n\in U\setminus A$，与补集定义矛盾；若 $n\notin A$，则 $n\in U\setminus A=A$，同样矛盾。故满足 $A=\varphi(A)$ 的 $A$ 不存在。（本质：$A=A^c\Rightarrow U=A\cup A^c=\varnothing$，与 $n\ge1$ 矛盾。）

**定理 1（$\dfrac{|\mathcal{F}|}{2}$ 就是答案，且整除）**

$\varphi$ 把 $\mathcal{F}$ 划分成若干个二元轨道 $\{A,\varphi(A)\}$：由引理 3 的第 2 条（对合）与第 3 条（无不动点），每个轨道恰含 2 个**不同**元素；任意两个轨道不交——若 $\{A,\varphi(A)\}$ 与 $\{B,\varphi(B)\}$ 相交，不妨设 $B=\varphi(A)$，则 $\varphi(B)=\varphi(\varphi(A))=A$，两轨道其实是同一个。于是

- $|\mathcal{F}|$ 是偶数：每个 $A\in\mathcal{F}$ 都落在自己的轨道 $\{A,\varphi(A)\}$ 里（覆盖），轨道两两不交（上面已证），而 $\mathcal{F}$ 有限（$|\mathcal{F}|\le2^n$），于是 $\mathcal{F}$ 是若干两两不交的二元集的**不交并**，$|\mathcal{F}|=2\times$（轨道数）。因此 $|\mathcal{F}|/2$ 是**整数**，写 `ans/2` 或 `ans>>1` 都不会因截断而出错（这一点必须证明，否则"整除"只是经验）；
- 轨道与合法划分之间是双射：
  - *划分 → 轨道*：给定划分 $\{A,B\}$，$\sum A=\sum B$ 且 $\sum A+\sum B=S$，故 $\sum A=S/2$，即 $A\in\mathcal{F}$ 且 $B=\varphi(A)$，它落在某个轨道里。把同一个划分写成 $\{B,A\}$，得到轨道 $\{\varphi(A),A\}$，是同一个轨道，所以映射**与顺序无关（良定义）**——这正是题面"交换算同一种"的数学化身。
  - *轨道 → 划分*：给定轨道 $\{A,\varphi(A)\}$，$A\cap\varphi(A)=\varnothing$、$A\cup\varphi(A)=U$、两边和都是 $S/2$（封闭性），故它就是一个合法划分。
  - *互逆*：把两个构造复合一次——划分 $\{A,B\}$ → 轨道 $\{A,B\}$ → 划分 $\{A,U\setminus A\}=\{A,B\}$，回到原划分；轨道 $\{A,\varphi(A)\}$ → 划分 $\{A,\varphi(A)\}$ → 轨道 $\{A,\varphi(A)\}$，回到原轨道。两个方向都还原，故为双射。

  因此 答案 $=\dfrac{|\mathcal{F}|}{2}=\dfrac{f_n(S/2)}{2}$。$\blacksquare$

**引理 4（"钉住一个元素"是更稳的去重方式）** 任取定 $p\in U$，则每个轨道 $\{A,\varphi(A)\}$ 中**恰有一个**集合含 $p$。

**证明**：按补集定义 $p\in U\setminus A\iff p\notin A$，所以 $A$ 与 $\varphi(A)$ 至多一个含 $p$；又二者必居其一（$p$ 要么在 $A$ 里要么不在，不在就在 $\varphi(A)$ 里），所以至少一个含 $p$。合起来"恰好一个"。（这里"轨道的两个成员互异"由引理 3 第 3 条保证，因此"$A$ 与 $\varphi(A)$"确实是两个不同集合，"恰有一个"才有内容。）$\blacksquare$

**推论 5** 答案 $=\#\{A\in\mathcal{F}:n\in A\}=f_{n-1}\!\left(\dfrac{S}{2}-n\right)$（把 $n$ 拿走，剩下在 $\{1,\dots,n-1\}$ 中凑 $S/2-n$，去/加 $n$ 是双射）。

**为什么这步不只是"省一次除法"**，三个后面要用到的好处：

1. 结果天生是整数，不必先算出 $|\mathcal{F}|$——那正是本题最大的中间量，§2.7 会看到它有把 `int` 撑爆的风险；
2. 目标值从 $S/2$ 降到 $S/2-n$，DP 长度与循环次数都变小（$n=39$：$390\to351$）；
3. 元素循环只做 $n-1$ 轮，且"最大元素已被占用"这个不变量在证明"不重不漏"时特别好用（引理 4 就是它）。

用 $n=7$ 校验推论 5：$f_6(14-7)=f_6(7)=4$ ✓ 正好是答案 4（§2.2 表里 $f_6(7)=f_5(7)+f_5(1)=3+1=4$，对应的四个子集是 $\{1,6\},\{2,5\},\{3,4\},\{1,2,4\}$，各自加上 7 就是题面列的四个含 7 的集合 $\{1,6,7\},\{2,5,7\},\{3,4,7\},\{1,2,4,7\}$——**一一对应，逐个对上**）。

### 2.5 经典解法 —— 计数型 01 背包（滚动 + 倒序）

$f_n(t)$ 的递推就是**01 背包方案数**，也是生成函数系数。

**引理 6（递推式正确）** 对 $n\ge1$、$t\ge0$：$f_n(t)=f_{n-1}(t)+f_{n-1}(t-n)$，规定自变量 $<0$ 时函数值为 $0$；边界 $f_0(0)=1$，$f_0(t)=0$（$t>0$）。

**证明**：把"和为 $t$ 的 $\{1,\dots,n\}$ 子集"按**是否含元素 $n$** 分成两类。

- 不含 $n$：它就是 $\{1,\dots,n-1\}$ 中和为 $t$ 的子集，$f_{n-1}(t)$ 个。
- 含 $n$：去掉 $n$ 得到 $\{1,\dots,n-1\}$ 中和为 $t-n$ 的子集；反向，任一和为 $t-n$ 的子集添上 $n$ 就和为 $t$。这两个操作互逆（去 $n$ 再补回、补 $n$ 再删去都是原样），是双射，故 $f_{n-1}(t-n)$ 个；$t-n<0$ 时该类为空，记 0，与规定一致。

两类互斥（含 $n$ 与不含 $n$ 不能同时成立）且并为全部（任何子集必居其一），故计数相加。边界：$\{1,\dots,0\}=\varnothing$，只有空集，和为 0，故 $f_0(0)=1$、$f_0(t>0)=0$。$\blacksquare$

**生成函数视角（解释标签"递推/背包 DP"）**：$\prod_{k=1}^{n}(1+x^k)$ 里第 $k$ 个因子选 $1$ 或 $x^k$，恰好对应"不取 $k$/取 $k$"，展开后 $x^t$ 的系数就是 $f_n(t)$。本题要的是 $x^{S/2}$ 系数的一半，或（钉住 $n$ 后）$\prod_{k=1}^{n-1}(1+x^k)$ 的 $x^{S/2-n}$ 系数。这也自然给出标签里的"折半搜索"：把乘积劈成两截分别枚举（§2.8）。

**滚动数组与倒序遍历的必要性**：一维 `dp[j]` 表示"当前轮次下和为 $j$ 的子集数"。转移要读的 `dp[j-k]` 必须是**上一轮**（还没考虑元素 $k$ 时）的值。

**引理 7（倒序才等价于 01 背包）** 外层枚举元素 $k$、内层 $j$ 从 $t_{\max}$ 递减到 $k$ 时，第 $k$ 轮结束后 `dp[j]`$=f_k(j)$ 对所有 $0\le j\le t_{\max}$ 成立。若内层正序，`dp` 变成"每个元素可无限次使用"的完全背包方案数，偏大。

**证明（倒序正确）**：对 $k$ 归纳。设第 $k-1$ 轮末 `dp[x]`$=f_{k-1}(x)$（$k=1$ 时即边界 `dp[0]=1`、其余 0，与 $f_0$ 一致）。第 $k$ 轮按 $j=t_{\max},t_{\max}-1,\dots,k$ 执行 `dp[j]+=dp[j-k]`：

- 执行到 $j$ 时，因为我们是**从大到小**走的，比 $j$ 小的下标（含 $j-k$）本轮尚未被写过，读到的仍是第 $k-1$ 轮的值 $f_{k-1}(j-k)$；而 `dp[j]` 自身本轮也尚未被写过（$j$ 是当前最大值），值 $f_{k-1}(j)$。故写入后 `dp[j]`$=f_{k-1}(j)+f_{k-1}(j-k)=f_k(j)$（引理 6）。
- $j<k$ 不进内层，`dp[j]` 保持 $f_{k-1}(j)$；而 $f_k(j)=f_{k-1}(j)+f_{k-1}(j-k)=f_{k-1}(j)+0=f_{k-1}(j)$，一致。

归纳完成。$\blacksquare$

**证明（正序错误）**：正序时 $j-k<j$ 已在本轮被更新成 $f_k(j-k)$，于是 `dp[j]` 累加了"元素 $k$ 用 1 次、2 次、……"的情形，数的是可重复选取的方案。

小数据反例（$n=3$，$t_{\max}=3$，倒序 / 正序逐步轨迹）：

| 步骤 | 正序 `dp[0..3]` | 倒序 `dp[0..3]` |
|---|---|---|
| 初值 | `1 0 0 0` | `1 0 0 0` |
| $k=1$ 后 | `1 1 1 1` | `1 1 0 0` |
| $k=2$ 后 | `1 1 2 2` | `1 1 1 1` |
| $k=3$ 后 | `1 1 2 3` | `1 1 1 2` |

倒序末态 `dp[3]=2`$=f_3(3)$ ✓（$\{3\},\{1,2\}$）。正序 `dp[3]=3`，多出的一种是 $1+1+1$（元素 1 用了三次），本题不存在这种子集。

顺带一个更阴险的现象：正序得 3，`>>1` 后得 1，**恰好**等于 $n=3$ 的真值——错误写法在这个例子上蒙对了。要抓它得换 $n=7$：正序数的是"用 $1..7$ 可重复地凑 14"（即把 14 分拆成不超过 7 的部分），$\{7,7\}$、$\{6,6,2\}$、$\{1^{14}\}$ 这类"同一元素用多次"的方案全被算进去，数量远大于 $f_7(14)=8$，`>>1` 后不可能等于 4（这里不需要它的精确值，只要确定它 $>8$ 即可，上面三个例子已是合法的分拆而都不是子集）。**教训：验证必须覆盖多组 $n$，单例通过不算通过。**

**记忆化搜索写法（标签的另一条路）**：`g(k,rem)` = 用 $\{1..k\}$ 凑 `rem` 的方案数，`g(k,rem)=g(k-1,rem)+g(k-1,rem-k)`，`g(0,0)=1`，`rem<0` 返 0，状态数 $n\cdot t\le 39\cdot390$。它与 2D 版 $f$ 是同一张表的两种填法（自顶向下 vs 自底向上），结论完全等价；本风格优先用全局数组递推，避免递归开销。

### 2.6 逐条盘查剪枝：会不会误杀合法方案

代码里一共砍了五刀，每一刀都要单独证明"砍掉的部分里不可能藏着答案"。

**刀 1：$S$ 为奇数直接输出 0。** 必要性由引理 1 给出（$S=2\sum A$）。这条刀只可能"多杀"如果存在奇数 $S$ 却有解的情形，引理 1 说明不存在。

**刀 1 的反面（充分性）：$S$ 为偶数时答案 $\ge1$，绝不能顺手把偶数情形也判 0。**

**引理 8（连续整数可凑出任意目标）** 对任意 $n\ge1$ 与任意整数 $t\in\left[0,\frac{n(n+1)}{2}\right]$，存在 $A\subseteq\{1,\dots,n\}$ 使 $\sum A=t$。

**证明**：对 $n$ 归纳，记 $S_n=\frac{n(n+1)}{2}$。

- 基：$n=1$，$t\in\{0,1\}$：$t=0$ 取 $A=\varnothing$，$t=1$ 取 $A=\{1\}$。$n=2$，$t\in\{0,1,2,3\}$：$\varnothing,\{1\},\{2\},\{1,2\}$。
- 归纳步（$n\ge3$）：设结论对 $n-1$ 成立。给定 $t\in[0,S_n]$。
  - 若 $t\le S_{n-1}$：不用元素 $n$，由归纳假设在 $\{1,\dots,n-1\}$ 中可凑出 $t$。
  - 若 $t>S_{n-1}$：取 $n$，需再用 $\{1,\dots,n-1\}$ 凑 $t-n$。检查 $t-n$ 落在 $[0,S_{n-1}]$：上界 $t-n\le S_n-n=S_{n-1}$ ✓；下界 $t>S_{n-1}=\frac{n(n-1)}{2}$，而 $n\ge3$ 时 $\frac{n(n-1)}{2}\ge n$（等价于 $n-1\ge2$，即 $n\ge3$ ✓），故 $t>n\Rightarrow t-n>0$ ✓。于是归纳假设给出 $A'\subseteq\{1,\dots,n-1\}$ 使 $\sum A'=t-n$，取 $A=A'\cup\{n\}$。

  两情形覆盖全部 $t$，归纳完成。$\blacksquare$

**推论 9（偶数情形必有色）** $S$ 为偶数且 $n\ge1$ 时答案 $\ge1$：$t=S/2\in[0,S]$，由引理 8 有 $A$ 使 $\sum A=S/2$；又 $S/2\ge1$（$n\equiv0,3\pmod4$ 且 $S$ 偶时最小是 $n=3$，$S/2=3$），故 $A\ne\varnothing$；$A\ne U$（否则 $\sum A=S\ne S/2$，因 $S>0$），故补集也非空。于是 $\{A,U\setminus A\}$ 是合法划分。$\blacksquare$

合起来：**答案 $\ge1\iff n\equiv0,3\pmod4$**。所以"判可行"只需一次取模；"计数"才需要 DP。

**刀 2：循环与查询只覆盖 $[0,t]$（而不是 $[0,S/2]$ 或 $[0,S]$）。**

**引理 10（截断上界不丢状态）** 用倒序 DP 计算 $f_{n-1}(t)$ 时，转移树中出现过的每一个第二维取值都 $\le t$。

**证明**：$f_{n-1}(t)$ 递归展开只会问 $t-t_1-t_2-\cdots$（各 $t_i$ 是被选中的元素，全为正整数），即任何被问到的子问题的目标都是 $t$ 减去若干个正整数，故 $\le t$。等价的组合说法：和为 $j\le t$ 的子集，其任何部分子集的和 $\le j\le t$（元素全正，部分和不超过总和），所以构造它时永远不需要超过 $t$ 的中间和。$\blacksquare$

用引理 6 的递推看也一样：`dp[j]` 只读 `dp[j-k]`，$j\le t\Rightarrow j-k\le t$，需要的下标全在数组内。所以把**有意义的区间**限制在 $[0,t]$ 不会误杀。代码里数组按最坏情况定长（`mxs`$=522$）只是图省事、少一次算上界；引理 10 保证的是"真要裁到 $t+1$ 也一个解都不丢"，即这个上界不是蒙来的安全余量，而是可证的截断点。

**刀 3：内层循环下界 `j>=k`。** 被跳过的 $j<k$ 对应 $f_k(j)=f_{k-1}(j)+f_{k-1}(j-k)$ 中 $j-k<0$ 的项，按引理 6 的规定该项为 $0$，即"含 $k$ 且和为 $j<k$"的子集不存在。跳过 = 加 0，不误杀。

**刀 4：外层只跑到 `k<n`（元素 $n$ 不进 DP）。** 由推论 5，答案本身就等于"$n$ 已在集合里"的计数，$n$ 的角色是钉代表元，不再参与组合。这条刀的合法性完全来自引理 4 的"恰好一个"，不是近似。

**刀 5：`if(half<n)` 这个"先比后转"的防御分支。** 记 $t=\frac{S}{2}-n=\frac{n(n+1)}{4}-n=\frac{n(n-3)}{4}$。走到这一支时 $S$ 已确认为偶，故 $n\equiv0$ 或 $3\pmod4$。$n=3\Rightarrow t=0$；$n\ge4\Rightarrow n-3\ge1\Rightarrow t>0$。$n\equiv0,3\pmod4$ 里没有 $n=1,2$（$1\equiv1$、$2\equiv2$）。所以 $t\ge0$ 恒成立，这一支**永不触发**，纯防御。之所以把比较放在 `static_cast<int>` **之前**（用 `i64` 的 `half<n` 判，而不是转成 `int` 后判 `t<0`），是因为 `i64`→`int` 的窄化在"值超出 `int` 表示范围"时是实现定义行为：我不想让一个边界判断的正确性依赖"截断恰好保号"这条平台性质。用宽的 `i64` 直接比，逻辑上不依赖任何平台细节。保留它并在注释里写清"恒不触发"，否则读者会以为它在处理某种真实边界。

### 2.7 溢出防护 —— 这题真正的坑不在思路而在类型

**先给严格上界（保证 i64 一定够）**：任何 `dp[j]` 都是"$\{1,\dots,n-1\}$ 的某类子集个数"，不超过子集总数 $2^{n-1}\le 2^{38}=274877906944\approx2.75\times10^{11}$；若不钉元素则不超过 $2^{39}\approx5.50\times10^{11}$。而 `i64`（`long long`）能装到 $9.22\times10^{18}$。故 **i64 无溢出，这是可证的**。

**再问 int 够不够（会爆在哪）**：如果走"$f_n(S/2)$ 再除 2"的写法，最大的中间量恰好就是被除的那个数 $|\mathcal{F}|=2\times$答案。用局部中心极限估计（**注意：这是估的，不是手算精确值**；本文禁止编译运行，不给 $n=39$ 的精确数字）：

- 若每个元素独立以 $\frac12$ 概率入选，$X=\sum_k k\,b_k$，$\mathbb{E}X=S/2=390$，$\operatorname{Var}X=\frac14\sum_{k=1}^{39}k^2=\frac14\cdot\frac{39\cdot40\cdot79}{6}=\frac14\cdot20540=5135$，$\sigma\approx71.66$。
- $P(X=390)\approx\frac{1}{\sigma\sqrt{2\pi}}=\frac{1}{71.66\times2.5066}\approx5.57\times10^{-3}$。
- 于是 $|\mathcal{F}|\approx5.57\times10^{-3}\times2^{39}\approx3.06\times10^{9}$，答案 $\approx1.53\times10^{9}$。

对照 `int` 上限 $2^{31}-1=2147483647\approx2.147\times10^{9}$：$3.06\times10^{9}$ 比它大出约四成。按 32 位补码回绕，$3.06\times10^{9}-2^{32}\approx-1.23\times10^{9}$ 变成**负数**，`>>1` 后输出负值，判题直接 WA——这类"思路全对、类型写错"的失分在这题非常典型。

那钉住 $n$ 以后 int 够吗？此时最大量级是 $f_{38}(351)\approx\frac{2^{38}}{68.96\sqrt{2\pi}}\approx1.59\times10^{9}$（同一套估算，$\sigma^2=\frac14\cdot\frac{38\cdot39\cdot77}{6}=4754.75$），刚好塞进 int，但只剩约 26% 余量，而且题面一旦把 $n$ 放宽到 40 就翻车。**结论：所有计数状态一律 `i64`，代价为零；不要拿"这题估计不会爆"当依据。**

其余几处类型细节：

1. $S$ 用 `i64` 算：`1ll*n*(n+1)/2`。$n\le39$ 时 `n*(n+1)=1560` 用 int 也够，但写成 `1ll*` 是为"题面放宽时不炸"，且避免 $n(n+1)$ 先溢出再除 2 的经典错误。
2. `t` 可以回到 `int`（$\le390$），但要**先比后转**：先用 `i64` 判 `half<n`（刀 5），再 `static_cast<int>(half-n)`。反过来说，`i64`→`int` 的窄化只在值超出 `int` 范围时才是实现定义的，与其论证"负号会不会被保住"，不如把边界判断留在宽类型里做。
3. 奇偶判定用 `S&1` 而不是 `S%2==1`：`i64` 非负时两者等价，`&1` 少一次除法，也更贴合"我在检查最低二进制位"的本意。
4. 输出是 `i64`，`cout` 直接支持，不需要手写打印；换行用 `'\n'`。

### 2.8 归约到更容易的问题 —— 折半搜索（标签指定的第二条路）

背包 DP 已经把问题归约成"数系数"。但标签里写了 meet in the middle，我想确认它到底能不能做、以及做到什么程度，因为它是"$S/2$ 很大但 $n$ 很小"那一类变题的唯一出路。

**做法**：$L=\{1,\dots,mid\}$，$R=\{mid+1,\dots,n\}$，$mid=\lfloor n/2\rfloor$。枚举 $L$ 的全部 $2^{mid}$ 个子集和存进 `Lsum`，枚举 $R$ 的全部 $2^{n-mid}$ 个子集和存进 `Rsum`；把 `Rsum` 排序，对每个 `Lsum[i]` 用 `equal_range` 数出等于 $S/2-$`Lsum[i]` 的个数，累加得 $|\mathcal{F}|$，最后 `>>1`。

**引理 11（拆分的无重无漏）** 映射 $A\mapsto(A\cap L,\ A\cap R)$ 是"$U$ 的子集"到"$L$ 的子集 $\times$ $R$ 的子集"的双射，且 $\sum A=\sum(A\cap L)+\sum(A\cap R)$。

**证明**：逆映射取并：$(A_1,A_2)\mapsto A_1\cup A_2$。因为 $L\cap R=\varnothing$，$A_1\cup A_2$ 的两个部分不会互相干扰；$(A_1\cup A_2)\cap L=A_1\cap L=A_1$（$A_1\subseteq L$），同理对 $R$，所以"先拆再并"还原。另一方向，$A\cap L$ 与 $A\cap R$ 的并不含公共元素且恰为 $A$（每个 $x\in A$ 必属 $L$ 或 $R$ 之一），所以"先并再拆"也还原。和的可加性来自 $A_1\cap A_2=\varnothing$。$\blacksquare$

由引理 11，$|\mathcal{F}|=\sum_{A_1\subseteq L}\#\{A_2\subseteq R:\ \sum A_2=S/2-\sum A_1\}$，这正是"对每个 `Lsum[i]` 在 `Rsum` 里二分查个数"。**注意这里必须数重数**：`Rsum` 里相同的值会出现多次（不同子集同和）。

**反例（把 `Rsum`/`Lsum` 去重会怎样）**：$n=7$，$mid=3$，`Lsum`$=[0,1,2,3,3,4,5,6]$，其中 $3$ 出现两次（$\{3\}$ 与 $\{1,2\}$）。若先 `sort`+`unique` 把 `Lsum` 变成 $\{0,1,2,3,4,5,6\}$，值 $3$ 那一档只贡献一次命中（$2$ 次而不是 $4$ 次），总数从 $8$ 变 $6$，`>>1` 得 $3$，而真值 $4$。

**手算完整轨迹（$n=7$）**：目标 $S/2=14$，`Rsum`（$R=\{4,5,6,7\}$，16 个，已排序）$=[0,4,5,6,7,9,10,11,11,12,13,15,16,17,18,22]$。

| `Lsum[i]` | 来源子集 | 需要 `Rsum` 中的值 | 命中次数 |
|---|---|---|---|
| 0 | $\varnothing$ | 14 | 0 |
| 1 | $\{1\}$ | 13 | 1（$\{6,7\}$） |
| 2 | $\{2\}$ | 12 | 1（$\{5,7\}$） |
| 3 | $\{3\}$ | 11 | 2（$\{4,7\},\{5,6\}$） |
| 3 | $\{1,2\}$ | 11 | 2（同上） |
| 4 | $\{1,3\}$ | 10 | 1（$\{4,6\}$） |
| 5 | $\{2,3\}$ | 9 | 1（$\{4,5\}$） |
| 6 | $\{1,2,3\}$ | 8 | 0 |

合计 $0+1+1+2+2+1+1+0=8=|\mathcal{F}|$，`>>1` $=4$ ✓ 与题面一致（也与 §2.2 的 $f_7(14)=8$ 一致，两条独立路径互验）。

**折半的剪枝同样不能误杀**：它其实一条都不剪——完整枚举 $2^{n}$ 拆分成的两半，靠引理 11 保证不重不漏；唯一"像剪枝"的决定是只算到 $S/2$（$>S/2$ 的子集和不可能参与配对，因为另一半的和非负），这条的证法与引理 10 相同（元素全正，部分和 $\le$ 总和）。$|\mathcal{F}|$ 仍须按定理 1 折半，且必须先完整累加再 `>>1`（累加量 $\approx3.06\times10^9$，又一次要求 `i64`，见 §2.7）。

**代价对比（$n=39$）**：

| 方案 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 背包计数（钉 $n$） | $39\times351\approx1.4\times10^{4}$ 次加法 | $O(S)$，$522\times8\,\text{B}\approx4.2\,\text{KB}$ | 目标只随 $n^2$ 增长，$n$ 放宽一档也不慌 |
| 折半搜索 | $2^{19}+2^{20}\approx1.6\times10^{6}$ 枚举 + $2^{20}\log$ 排序，约 $2\times10^{7}$ | 两个 $10^6$ 级数组 | 比 DP 慢约三个数量级 |

所以在本题数据范围（$n\le39$，$S/2\le390$）下 **DP 是正解**，折半只是标签给的备选。两者的规模随 $n$ 的变化方向相反：DP 是 $O(n^3)$（目标 $\sim n^2/4$），折半是 $O(2^{n/2})$。$n=100$ 时 DP 约 $100\times2525\approx2.5\times10^{5}$ 次加法仍轻松，折半要 $2^{50}$ 直接死；$n$ 若变成"$30$ 个**任意**给定的数、目标 $\sim10^{9}$"，DP 的数组开不下，折半 $2^{15}$ 反而是唯一出路——那才是 meet in the middle 的主场，也是这题标签的由来。

### 2.9 变体分类讨论 —— 同一套性质还能榨出什么

**(a) 只要判定"能不能分"**：由引理 1、2（必要性）与推论 9（充分性），答案 $\ge1\iff n\equiv0,3\pmod4$。$O(1)$，不需要 DP。

**(b) 要输出一个具体划分（构造）**：引理 8 的归纳其实给出一个贪心——**从大到小，够放就放**：

> $r\leftarrow S/2$；for $k=n$ downto $1$：若 $k\le r$ 则把 $k$ 放入 $A$，$r\leftarrow r-k$。

**引理 12（贪心必成）** 处理完每个 $k$ 后始终有 $0\le r\le S_k$（$S_k=\frac{k(k+1)}{2}$，$S_0=0$），故结束时 $r=0$，$A$ 恰凑出 $S/2$。

**证明**：进入第 $k$ 步前设 $r\le S_k$。

- 若 $r\ge k$：取走 $k$，$r'=r-k\le S_k-k=S_{k-1}$，且 $r'\ge0$。
- 若 $r<k$：跳过，$r'=r\le k-1$。当 $k\ge2$ 时 $S_{k-1}=\frac{k(k-1)}{2}\ge k-1$（等价于 $k\ge2$ ✓），故 $r'\le S_{k-1}$；当 $k=1$ 时 $r<1$ 且 $r\ge0$ 给出 $r=0=S_0$。

两种情形都把不变量从 $k$ 推到 $k-1$。初值检查（进入 $k=n$ 那一步前需要 $0\le r\le S_n$）：$r=S/2\ge0$ 因 $S\ge1$；$S/2\le S_n=S$ 等价于 $0\le S/2$，同样由 $S\ge1>0$ 成立（$S=\frac{n(n+1)}{2}$，$n\ge1$ 时 $S\ge1$）。故不变量起得住，一路推到 $k=0$：$r\le S_0=0$ 且 $r\ge0$，得 $r=0$。$\blacksquare$

这条贪心产生的是"**colex 序最大**"的那个集合（尽量拿大数），不是字典序最小。例：$n=7$，$r=14$ → 取 7（$r=7$）→ 取 6（$r=1$）→ 跳 5,4,3,2 → 取 1，得 $A=\{1,6,7\}$，正好是题面第一个划分 ✓。

**(c) 要字典序最小的划分**：先把无序对规范成有序——**规定含元素 $1$ 的那一侧叫 $A$**（引理 4 的同一手法：$1$ 恰属于 $A,\varphi(A)$ 之一，故规范代表存在且唯一）。$A$ 定了 $B=U\setminus A$ 也定了，所以只需在"$1\in A$、$\sum A=S/2$"的集合里让 $A$ 的升序序列字典序最小。

做法：需要**后缀可行性表** `can[k][r]` = "用 $\{k,k+1,\dots,n\}$ 能否凑出 $r$"（布尔背包，`can[k][r]=can[k+1][r] or can[k+1][r-k]`），然后从 $k=1$ 到 $n$ 依次决定：先强制 $1\in A$；对 $k\ge2$，若 `can[k+1][r-k]` 成立就取 $k$（$r\leftarrow r-k$），否则跳过。

**引理 13（该贪心给出字典序最小）** 设两个合法集合 $A,B$（都含 $1$、和都是 $S/2$）在 $<k$ 的元素上取法相同，$A$ 含 $k$ 而 $B$ 不含，则 $A$ 的升序序列字典序小于 $B$。

**证明**：把 $A,B$ 写成升序序列 $a_1<a_2<\cdots$ 与 $b_1<b_2<\cdots$。两者小于 $k$ 的元素组成的前缀完全相同，记为 $P$。$A$ 的下一个元素正是 $k$。$B$ 的下一个元素若存在，必 $>k$（$B$ 不含 $k$，且 $<k$ 的都已在 $P$ 里），于是这一位上 $k<\,$`next(B)`，$A$ 更小。若 $B$ 没有下一个元素（$B=P$），则 $B\subsetneq A$，从而 $\sum B<\sum A$（$A$ 多出正元素 $k$），与两者都等于 $S/2$ 矛盾，故此情形不可能出现。$\blacksquare$

所以"能取小就取小"是**正确的**（前提是 `can` 表保证剩下的仍可完成），而 (b) 里"能取大就取大"给出的是另一个序（colex）。两者别混：**贪心方向由要优化的序决定**，而可行性判断（`can` 表 / 引理 8 的界）在任何方向上都不可省——省掉就会走进"取完之后凑不出来"的死路。$n=7$ 的完整手算轨迹（目标 $14$，强制 $1\in A$）：

| $k$ | 当前余额 $r$ | 试探"取 $k$"后的余额 | `can[k+1][·]` | 决定 |
|---|---|---|---|---|
| 1 | 14 | — | — | 强制取，$r=13$ |
| 2 | 13 | $11$ | $\{3,4,5,6,7\}$ 凑 11：$4+7$ ✓ | 取，$r=11$ |
| 3 | 11 | $8$ | $\{4..7\}$ 凑 8：单数无 8，$4+5=9>8$ → ✗ | 跳过 |
| 4 | 11 | $7$ | $\{5,6,7\}$ 凑 7：$\{7\}$ ✓ | 取，$r=7$ |
| 5 | 7 | $2$ | $\{6,7\}$ 凑 2 ✗ | 跳过 |
| 6 | 7 | $1$ | $\{7\}$ 凑 1 ✗ | 跳过 |
| 7 | 7 | $0$ | 空集凑 0 ✓ | 取，$r=0$ |

得 $A=\{1,2,4,7\}$（和 $14$ ✓），正是题面第 4 种划分的含 1 侧；三个含 1 的候选 $\{1,6,7\}$、$\{1,3,4,6\}$、$\{1,2,4,7\}$ 的升序序列比较，$\{1,2,4,7\}$ 确实字典序最小 ✓。

**(d) 只要答案 $\bmod\,p$**：同一 DP 边加边取模即可。此时"除 2"要注意：$|\mathcal{F}|$ 在整数上是偶数（定理 1），所以 $(|\mathcal{F}|\bmod p)\times \text{inv}(2)\bmod p$ 等于 $(|\mathcal{F}|/2)\bmod p$——整数的除法与模可交换，因为 $2\cdot\frac{|\mathcal{F}|}{2}=|\mathcal{F}|$ 在模 $p$（$p$ 为奇素数）的同态下保持。但用推论 5 的"钉住 $n$"写法根本不需要除法，最省心。

**(e) $n$ 很大（例如 $n\le10^{5}$）**：$S/2$ 到 $\approx2.5\times10^{9}$，背包数组开不下、折半更不可能，只能回到生成函数 $\prod_{k\ge1}(1+x^k)$ 的系数（"分拆成互异部分"的计数），用五边形数型恒等式一类工具——已超出本题范围，但值得知道标签里"递推"二字的来源。

## 3. 模式总结（Pattern Summary）

按我实际的思考顺序，一条一个技术点：

- **探索特殊机制（和的倍率）** — 由 $\sum A=\sum B$ 与 $A\cup B=U$ 得 $S=2\sum A$，一刀把 $n\equiv1,2\pmod4$ 全判 0；不判就用 $n=5,6$ 的反例看它输出假答案。
- **考虑简化版（小 $n$ 手算）** — 先建 $f_n(t)$ 递推表把 $n\le8$ 全算净，用"行和 $=2^n$、关于 $S/2$ 对称"两个自检抓出错（我确实抓错一次 $f_6(10)$）。
- **剖析错误猜想** — "两边个数相等"≠"两边和相等"（题面 $n=7$ 本身就是 $3|4$）；$\binom{n}{n/2}/2$ 在 $n=4$ 上给 3 而真值 1。
- **对称性去重（无不动点对合）** — 先数有序/子集，再折半；折半前必须证明 $\varphi(A)=U\setminus A$ 封闭、对合、无不动点，从而"整除"是定理而不是运气。
- **钉住一个元素当代表元** — 每个轨道恰有一个含 $n$ 的集合，于是答案 $=f_{n-1}(S/2-n)$：把除法从算法里删掉，同时把最大中间量减半。
- **经典问题解法（计数型 01 背包 / 生成函数系数）** — $f_n(t)=f_{n-1}(t)+f_{n-1}(t-n)$ 就是 $\prod(1+x^k)$ 的系数递推。
- **滚动数组 + 倒序不变量** — 倒序才能保证读到的是"上一轮"值；正序变完全背包（$n=3,t=3$ 时 $3\ne2$，且 `>>1` 后蒙对，说明单例不足以验错）。
- **逐条盘查剪枝（界不误杀）** — 截断到 $t$、下界 $j\ge k$、外层 $k<n$、防御分支 `half<n`：每条各给一个"被砍掉的部分不可能含解"的证明；存在性由"任意 $t\le S$ 可凑"的归纳补齐。
- **溢出防护** — 严格上界 $2^n$ 保证 i64 够；量级估计说明 $|\mathcal{F}|\approx3\times10^9$ 会把 `int` 打回负数。
- **折半搜索（备选路径）** — 拆 $L,R$ 的双射保证不重不漏，`equal_range` **数重数**（去重会少算，$n=7$ 上得 3 而非 4）；本题比 DP 慢约三个数量级。
- **判定/构造变体** — 判定只需 $n\bmod4$；构造要"能取就取"的贪心 + 界证明（colex 最大）；要字典序最小则换成**后缀可行性表** `can[k][r]` 决定每一位，方向换了但可行性检查不能换。

## 4. 真实解法

### 4.1 符号表（代码里每一个量）

| 符号 | 含义 | 类型 / 取值 | 初始化与记忆点 |
|---|---|---|---|
| $U$ | 全集 $\{1,\dots,n\}$ | 概念 | — |
| $n$ | 题面输入 | `int`，$1\le n\le39$ | `cin>>n` |
| $S$ | $\frac{n(n+1)}{2}$，全集总和 | `i64`，$\le780$ | `1ll*n*(n+1)/2`，先升位再乘，防 $n(n+1)$ 溢出 |
| `half` | $S/2$，"每一侧该有的和" | `i64`，$\le390$ | 保持宽类型，边界比较在它上面做（刀 5） |
| $t$ | 目标和 $=S/2-n$ | `int`，$\le390$ | "把最大元素 $n$ 钉进集合后还差的**余**额"（remainder） |
| `dp[j]` | 第 $k$ 轮结束时 $=f_k(j)$：用 $\{1,\dots,k\}$ 凑出 $j$ 的子集数 | `i64[mxs]`，$0\le j\le t$ | 全局默认全 0，再 `dp[0]=1`（空集凑 0，恰好一种） |
| `mxn{45}` | 元素数上界 $+5$ | `constexpr int` | 本解法只用它推出 `mxs` |
| `mxs{mxn*(mxn+1)/4+5}`=522 | `dp` 长度，$\ge S/2$ 的最大值 $390$ | `constexpr int` | 虚高，绝不越界；引理 10 说明开到 $t$ 已足够 |
| $k$ | 外层：当前考虑的元素 | `int`，$1..n-1$ | $n$ 本身不进 DP（推论 5） |
| $j$ | 内层：当前余额 | `int`，$t..k$ | **从大到小**（引理 7） |

### 4.2 步骤

1. 读入 $n$。
2. 算 $S\leftarrow\frac{n(n+1)}{2}$（`i64`）。
3. 若 `S&1`：输出 `0`，结束。依据＝引理 1＋引理 2（$n\equiv1,2\pmod4$ 时无解），且由推论 9 知反向不会漏解。
4. 令 `half=S/2`（`i64`）。若 `half<n` 输出 `0`（防御分支，刀 5 证明恒不触发）；否则 $t\leftarrow$ `static_cast<int>(half-n)`——**先在 `i64` 上比，再窄化**，不把边界判断寄托在截断行为上。
5. `dp[0]=1`（其余为全局 0）。不变量初值：第 0 轮 `dp[j]`$=f_0(j)$。
6. 对 $k=1,2,\dots,n-1$：对 $j=t,t-1,\dots,k$：`dp[j]+=dp[j-k]`。每轮结束维持 `dp[j]`$=f_k(j)$（引理 7；跳过的 $j<k$ 由刀 3 说明与 $f_k(j)=f_{k-1}(j)$ 一致）。
7. 输出 `dp[t]`$=f_{n-1}(S/2-n)$，它就是答案（定理 1＋引理 4＋推论 5：轨道 $\{A,U\setminus A\}$ 与"含 $n$ 且和为 $S/2$"的集合一一对应）。全程无除法，结果自动是整数。

### 4.3 复杂度

- 时间 $O(n\cdot t)=O(n\cdot S)=O(n^3)$，内层执行次数 $\sum_{k=1}^{n-1}\max(0,t-k+1)$；$n=39$ 时 $t=351$，上界 $39\times351=13689$，实际 $\sum_{k=1}^{38}(352-k)=38\times352-\frac{38\cdot39}{2}=13376-741=12635$ 次 `i64` 加法。
- 空间 $O(t)$：`dp` 占 $522\times8\,\text{B}\approx4.2\,\text{KB}$。
- 折半备选版：$O(2^{n/2}\cdot n)$ 枚举 $+\,O(2^{n/2}\log)$ 排序，$n=39$ 时 $\sim2\times10^{7}$，空间 $O(2^{n/2})$。

## 5. 示例代码

### 5.1 主解法：01 背包计数 + 固定最大元素

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{45};              // n<=39，+5 松弛
constexpr int mxs{mxn*(mxn+1)/4+5}; // dp 长度：S/2=n(n+1)/4，按 mxn 推出来=522

int n;
i64 dp[mxs];                        // dp[j]=用 1..n-1 里的数凑出 j 的子集数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	i64 S=1ll*n*(n+1)/2;
	if(S&1)                         // 刀 1：奇数和绝无等和划分（引理 1、2）
	{
		cout<<0<<'\n';
		return 0;
	}
	i64 half=S/2;                   // 保持宽类型，边界判断不依赖窄化行为
	if(half<n)                      // 防御分支：S 为偶数时恒不触发（见 §2.6 刀 5）
	{
		cout<<0<<'\n';
		return 0;
	}
	int t=static_cast<int>(half-n); // 把 n 钉死在左集合后还差的余额（先比后转）
	dp[0]=1;                        // 空集凑 0，恰一种；其余全局 0
	for(int k=1;k<n;++k)            // 只枚举 1..n-1（n 已被"占用"，见推论 5）
		for(int j=t;j>=k;--j)       // 倒序：读到的 dp[j-k] 仍是上一轮（引理 7）
			dp[j]+=dp[j-k];
	cout<<dp[t]<<'\n';              // =f_{n-1}(S/2-n)，天生是整数，无需除 2
	return 0;
}
```

### 5.2 备选：折半搜索（题面标签指定的一条路）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxe{(1<<20)+5};       // n=39,mid=19 时右半有 2^(39-19)=2^20 个子集和

int n,mid;
i64 S,ans;
i64 Lsum[mxe],Rsum[mxe];            // 左右两半各自的子集和（保留重复值！）
int cntL=0,cntR=0;

void dfs(int l,int r,i64 sum,i64*arr,int&cnt)   // 枚举值域 [l,r) 的所有子集和
{
	if(l==r)
	{
		arr[cnt++]=sum;
		return;
	}
	dfs(l+1,r,sum,arr,cnt);                       // 不取 l
	dfs(l+1,r,sum+l,arr,cnt);                     // 取 l
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	S=1ll*n*(n+1)/2;
	if(S&1)
	{
		cout<<0<<'\n';
		return 0;
	}
	mid=n/2;
	dfs(1,mid+1,0,Lsum,cntL);                     // 左半：1..mid
	dfs(mid+1,n+1,0,Rsum,cntR);                   // 右半：mid+1..n
	sort(Rsum,Rsum+cntR);
	for(int i=0;i<cntL;++i)
	{
		auto p=equal_range(Rsum,Rsum+cntR,S/2-Lsum[i]);
		ans+=p.second-p.first;                    // 子集和会重复，必须数区间长度
	}
	cout<<(ans>>1)<<'\n';                         // ans=|F| 约 3e9，务必是 i64（§2.7）
	return 0;
}
```

两版数组尺寸都只按题面的 $n\le39$ 定：主解法 `mxs`$=522>S/2|_{\max}=390$，折半版 `mxe`$=2^{20}+5\ge 2^{n-\lfloor n/2\rfloor}|_{\max}=2^{20}$。**若题面放宽 $n$**：主解法只需把 `mxn` 抬高、`mxs` 仍写成 `mxn*(mxn+1)/4+5`（$n=10^3$ 时长度 $\sim2.5\times10^{5}$、$n=10^4$ 时 $\sim2.5\times10^{7}$，内存与 $O(n^3)$ 时间同时变紧）；折半版每加 2 个元素就多一倍枚举量，$n=50$ 就是 $2^{25}$，$n=60$ 直接不可用。所以本题的正解是背包计数，折半只用来对答案（§2.8 的 $n=7$ 轨迹与 §2.2 的 $f_7(14)=8$ 正是这样互验的）。
