# P1881 [USACO12FEB] 绳子对折 B

> 难度：普及- · 标签：枚举 / 对称 / 差分回文

## 1. 重新读题

### 1.1 问题重述（人话版）

绳子长度是整数 $L$，上面有 $N$ 个结，位置两两不同，而且两个端点 $0$ 和 $L$ 一定是结。选一个折点（不能是两个端点），把绳子对折。较短那一半上的每个结，都要和较长那一半上正对着的位置同时是结。较长那一半多出来的结没关系。问有多少个这样的折点。样例里 $L=10$、结在 $0,2,4,6,10$，答案是 $4$，折点为 $1,2,3,8$。

### 1.2 关键约束与规模暗示

- $N\le 100$，$L\le 10000$。对每个候选折点扫一遍所有结是 $O(NL)$，足够。
- 折点可以在结上，也可以在两个整数之间。样例的 $1$ 和 $3$ 就是整数点但不是结，$8$ 在 $6$ 和 $10$ 之间。
- 输入的结不保证有序。

## 2. 思维链（Chain-of-thought）

### 2.1 折点只可能是整数或半整数

把位置都乘 $2$。原折点 $f$ 变成整数 $p=2f$，原结 $a$ 变成 $x=2a$。绳子长度变成 $2L$。

**引理 1（候选折点是 $1,2,\ldots,2L-1$）**。若 $f\in(0,L)$ 是合法折点，则 $2f$ 是整数。因此把倍长之后的每个整数点都试一遍，不会漏掉半整数，也不会引入四分之一这类位置。

**证明**。端点 $0$ 和 $L$ 都是结，而且都是整数。

- 若 $f\le L/2$，则左端 $0$ 落在重叠区内，它的对称点是 $2f$，并且 $2f\le L$，所以 $2f$ 必须是一个结。结的位置是整数，故 $2f$ 是整数。
- 若 $f\ge L/2$，则右端 $L$ 落在重叠区内，它的对称点是 $2f-L$。$L$ 是整数，对称点必须是结从而是整数，所以 $2f$ 也是整数。

$f=0$ 和 $f=L$ 被题面排除，对应 $p=0$ 和 $p=2L$，循环不到它们。$\square$

### 2.2 只检查结的对称点

在倍长坐标里，折点是 $p$，位置 $x$ 的对称点是 $y=2p-x$。重叠区就是 $x$ 和 $y$ 都落在 $[0,2L]$ 里的那些点。

**引理 2（充要条件）**。折点 $p$ 合法，当且仅当：对每一个结 $x$，若 $y=2p-x$ 仍在 $[0,2L]$ 内，则 $y$ 也是结。

**证明**。重叠区内的位置成对出现 $(x,2p-x)$。一对里只要有一个是结，另一个也必须是结，否则对折后结对上了空位。把这句话用在每一个结上，就覆盖了「结对上空位」的所有情况。两个都不是结的位置不用管。若某个结的对称点跑出了绳子，说明它落在较长那一半多出来的部分，题面允许。反过来，若条件成立，则重叠区内每个结的对面也是结，折叠合法。$\square$

较长一侧的多余结不会被误判：它们的对称点在绳外，`continue` 掉。折在结上时，该结的对称点是自己，`kn[x]` 为真，允许。

这一判据对每个 $p$ 扫 $N$ 个结，总时间 $O(NL)$。直接在倍长坐标的每个位置上比 `bool` 数组会变成 $O(L^2)$，没有必要。

### 2.3 另一条算法：差分回文

把结排序成 $0=x_0<\cdots<x_{N-1}=L$，令间隙 $g_i=x_{i+1}-x_i$。从左端开始对折，重叠段的间隙序列必须是回文：偶数长度的回文对应折在某个结上，奇数长度对应折在某段间隙的中点。从右端开始对折则是后缀回文。整段间隙序列如果是回文，中点折法会被前缀和后缀各数一次，所以后缀从下标 $1$ 而不是 $0$ 开始数，避免把中点算两次。

这条算法和引理 2 的扫描不是同一个过程。$N\le 100$ 时它也覆盖全部数据，沙箱里用它做对照。样例间隙是 $2,2,2,4$：前缀回文 $[2]$、$[2,2]$、$[2,2,2]$ 和后缀回文 $[4]$ 共 $4$ 个，与样例一致。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 端点一定是结，所以合法折点的两倍是整数；乘 $2$ 后只枚举整数点。
- **symmetry** — 重叠区内每个结的对称位置也必须是结，绳外的对称点忽略。
- **consider easier version** — 把相邻结的间隙数组拿去数前缀/后缀回文，作为另一份实现。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `L` | `int` | 倍长后的绳子长度 | 读入后 $\times 2$ | length |
| `kn[x]` | `bool [20005]` | 倍长坐标 $x$ 是否有结 | `false` | knot |
| `xs[i]` | `int [105]` | 倍长后的结位置 | 读入 $\times 2$ | positions |
| `p` | `int` | 当前倍长折点 | $1..L-1$ | fold |

### 4.2 算法步骤

1. 读入 $N,L$，把 $L$ 和每个结的位置乘 $2$，打进 `kn`。
2. 对 $p=1..2L-1$，检查每个结的对称点：在绳上就要求 `kn` 为真。
3. 通过的 $p$ 计数，输出。

### 4.3 复杂度与验证状态

- **时间**：$O(NL)$，$N\le 100$，$L\le 10000$，约 $2\times 10^6$ 次检查。
- **空间**：$O(L)$。
- **沙箱对拍**：`g++ -O2 -std=c++17 -Wall -Wextra` 零警告。样例输出 `4`。另有端点绳、中点折、以及 $80$ 组 $L\le 10000$、$N\le 100$ 的随机结，共 $84$ 组，与差分回文计数一致。最大数据 $N=100$、$L=10000$ 标程耗时 $0.0115\text{ s}$。

## 5. 示例代码

### 5.1 标程（`P1881.cpp`）

```cpp
//
// 题目：P1881 [USACO12FEB] 绳子对折 B
// https://www.luogu.com.cn/problem/P1881
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20005};

bool kn[mxn];
int xs[105],n,L;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>L;
	L*=2;
	for(int i=0;i<n;++i)
	{
		int x;
		cin>>x;
		x*=2;
		xs[i]=x;
		kn[x]=true;
	}
	int ans=0;
	for(int p=1;p<L;++p)
	{
		bool ok=true;
		for(int i=0;i<n;++i)
		{
			int y=p*2-xs[i];
			if(y<0||y>L)
				continue;
			if(!kn[y])
			{
				ok=false;
				break;
			}
		}
		ans+=ok;
	}
	cout<<ans<<'\n';
	return 0;
}
```
