# P1921 赌博游戏

> 本题在洛谷题面中带有「**数据有误**」标记。本文按题面写下的概率模型给出可运行的解法，并在文中明确这一背景与全部假设。

## 1. 重新读题

### 1.1 问题重述（人话版）

赌场有 $N$ 个（可能被灌铅的）骰子，每个骰子有 $Q$ 种点数。规则是：

- 第 $1$ 次游戏用第 $i$ 个骰子的概率是 $\pi(i)$；
- 若第 $t$ 次用了第 $i$ 个骰子，则它掷出点数 $j$ 的概率是 $A(i,j)$；
- 第 $t$ 次用完第 $i$ 个骰子后，第 $t+1$ 次改用第 $j$ 个骰子的概率是 $B(i,j)$。

现在观察到 $M$ 次游戏的点数序列 $O(1),O(2),\ldots,O(M)$，但不知道每次用的是哪个骰子。求「恰好出现这个观测序列」的概率，保留 $4$ 位小数。

### 1.2 关键约束与规模暗示

- $M\le1000$，$N,Q\le50$。$N^M$ 是天文数字，绝不可能枚举「每次用了哪个骰子」这条隐藏状态链。
- $M\cdot N^2\le2.5\times10^6$：这正好是「按时间递推、每次在 $N$ 个状态上做 $N^2$ 转移」的量级，强烈暗示这是一个**随时间推进的 DP**（隐马尔可夫模型的前向算法）。
- 答案要 $4$ 位小数；概率可能小到 $10^{-1000}$ 量级，浮点会下溢。但下溢到 $0$ 与「真值小于 $5\times10^{-5}$ 时输出 `0.0000`」在 $4$ 位小数下是同一件事，这一点要在文中论证清楚。
- 矩阵/向量的「概率转移特征」在题面被明确保证（行和为 $1$ 等），但题面的「数据有误」标记说明实际数据未必满足，见 §2.5。

## 2. 思维链（Chain-of-thought）

### 2.1 形式化：把所有隐藏路径的概率加起来

设第 $t$ 次使用的骰子为随机变量 $S_t\in\{1,\ldots,N\}$。观测序列的概率是

$$P\bigl(O_1,\ldots,O_M\bigr)=\sum_{s_1=1}^{N}\cdots\sum_{s_M=1}^{N}\pi(s_1)\prod_{t=1}^{M}A(s_t,O_t)\prod_{t=1}^{M-1}B(s_t,s_{t+1}).$$

直接算有 $N^M$ 项，$50^{1000}$ 完全不可能。

### 2.2 关键观察：按时间「合并同类项」

上面这个和虽然项数爆炸，但**结构是链式的**：每个 $s_t$ 只和 $s_{t-1},s_{t+1}$ 相邻耦合。对这样的链状求和，标准手段是「从左往右扫描，把已确定的前缀信息压成一个长度为 $N$ 的向量」。

定义

$$f_t(i)=P\bigl(O_1,\ldots,O_t,\;S_t=i\bigr),\qquad 1\le i\le N,$$

即「前 $t$ 次观测恰好是给定序列，且第 $t$ 次用的是骰子 $i$」的联合概率。

### 2.3 递推公式及其证明

**引理（前向递推）**：对 $t\ge1$，

$$f_1(i)=\pi(i)\,A(i,O_1),$$
$$f_{t+1}(j)=A(j,O_{t+1})\sum_{i=1}^{N}f_t(i)\,B(i,j).$$

**证明**：第一式是初始分布与第一次掷骰的联合概率，直接由模型定义得到。

对第二式，用全概率公式按 $S_t$ 分类，并用两次条件化：

$$
\begin{aligned}
f_{t+1}(j)
&=P\bigl(O_1,\ldots,O_{t+1},\,S_{t+1}=j\bigr)\\
&=P\bigl(O_1,\ldots,O_t,\,S_{t+1}=j\bigr)\cdot P\bigl(O_{t+1}\mid O_1,\ldots,O_t,\,S_{t+1}=j\bigr).
\end{aligned}
$$

- 第二个因子：模型规定「第 $t+1$ 次用骰子 $j$ 时掷出 $O_{t+1}$ 的概率」只由 $j$ 与 $O_{t+1}$ 决定，与更早的历史无关，故等于 $A(j,O_{t+1})$。
- 第一个因子：再对 $S_t$ 用全概率公式，

$$P\bigl(O_1,\ldots,O_t,S_{t+1}=j\bigr)=\sum_{i=1}^{N}P\bigl(O_1,\ldots,O_t,S_t=i\bigr)\,P\bigl(S_{t+1}=j\mid O_1,\ldots,O_t,S_t=i\bigr).$$

由马尔可夫性，下一颗骰子只依赖当前骰子，故条件概率为 $B(i,j)$。把 $P(O_1,\ldots,O_t,S_t=i)=f_t(i)$ 代入即得。$\square$

最后，对 $S_M$ 再用一次全概率公式：

$$P(O_1,\ldots,O_M)=\sum_{i=1}^{N}f_M(i).$$

这就是答案。每一步只有 $O(N^2)$ 次乘加，总共 $O(MN^2)$。

### 2.4 数值下溢：为什么可以放心用浮点

$M=1000$ 时真实概率可能是 $10^{-1000}$，`double` 在 $10^{-308}$ 就下溢成 $0$。需要说明下溢不会影响 $4$ 位小数的输出。

**引理（下溢无害）**：若在某一时刻某个 $f_t(i)$ 下溢为 $0$，则它对最终答案的真实贡献小于 $10^{-4900}$（`long double` 的下溢阈值量级），因此答案的 $4$ 位小数不变。

**证明**：最终答案按路径分解，经过「第 $t$ 次处于状态 $i$」的所有路径的总概率为

$$f_t(i)\cdot P\bigl(O_{t+1},\ldots,O_M\mid S_t=i,\ O_1..O_t\bigr)\le f_t(i),$$

因为条件概率 $\le1$。若 $f_t(i)$ 下溢，说明它的真值小于浮点最小非零数，故这部分贡献也小于该数，远小于 $5\times10^{-5}$。$\square$

同时，所有量非负，累加不会产生抵消；每步只做「乘」与「加」，`long double` 的相对误差 $10^{-19}$ 再乘上最多 $M$ 步，也远小于 $10^{-5}$。所以用 `long double` 做 DP 是安全的。

### 2.5 关于「数据有误」：本文的假设

题面标题带「数据有误」标记，即官方数据本身不可靠（典型情况：概率矩阵的行没有归一化、行数/列数与描述不符、行内元素个数与换行错位等）。在这种前提下不可能「对上官方答案」，我们能做的是**严格实现题面写下的数学模型**。本文假设：

1. **下标约定**：$A(i,j)$、$\pi(i)$ 的行列按「第 $i$ 行第 $j$ 列」行优先读入；观测值 $O_t$ 是 $1$ 起的点数，取值 $[1,Q]$，代码用 `O[t]-1` 取列。
2. **输入按空白分隔**：忽略换行位置，把所有数按顺序读入。这样即使题面的「第几行」与实际换行不一致（数据有误的常见形态），读入也不受影响。
3. **不做归一化、不做截断**：即使给定的 $A,B,\pi$ 行和不为 $1$，也照公式原样计算乘积。这是对「概率」二字最直接的字面解释；如果强行归一化，反而会引入题面没有规定的额外操作。
4. 若数据中途缺失，`cin` 失败后对应变量保持 $0$，程序仍会正常输出 `0.0000` 而不会崩溃。

这些假设在「数据有误」的背景下是唯一能自洽的选择；本文的正确性结论也仅针对这个模型，而不是针对不可靠的官方数据。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 答案是 $N^M$ 条隐藏状态路径的概率之和，路径呈链状耦合。
- **reduce to easier problem** — 按时间合并同类项：用一个长度 $N$ 的向量表示「前缀观测 + 当前骰子」的联合概率。
- **classic problem solution** — 隐马尔可夫模型的前向算法（forward algorithm），$O(MN^2)$。
- **prove correctness** — 全概率公式 + 马尔可夫性，逐步推出递推式。
- **numerical argument** — 下溢项的贡献被自身概率上界控制，不影响 $4$ 位小数。
- **state assumptions** — 题面「数据有误」，明确 1 起下标、空白分隔读入、不做归一化。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `N,M,Q` | `int` | 骰子数、游戏次数、点数种数 | 读入 | 维度 |
| `pi[i]` | `long double[55]` | 初始用第 $i$ 个骰子的概率 | 读入 | initial |
| `A[i][j]` | `long double[55][55]` | 骰子 $i$ 掷出点数 $j+1$ 的概率 | 读入 | emit |
| `B[i][j]` | `long double[55][55]` | 从骰子 $i$ 换到 $j$ 的概率 | 读入 | transit |
| `O[t]` | `int[1005]` | 第 $t$ 次观测点数（$1$ 起） | 读入 | observation |
| `f[i]` | `long double[55]` | $f_t(i)$，前一时刻的前向概率 | 由 $\pi\cdot A$ 初始化 | forward |
| `g[i]` | `long double[55]` | $f_{t+1}(i)$ 的暂存 | 每轮重算 | next |

### 4.2 算法步骤

1. 读入 $N,M,Q$、$\pi$、$A$（$N$ 行 $\times Q$ 列）、$B$（$N$ 行 $\times N$ 列）、$M$ 个观测值。
2. 初始化：对 $i=0..N-1$，`f[i] = pi[i] * A[i][O[0]-1]`。
3. 对 $t=1..M-1$：令 `o=O[t]-1`；对每个 $j$，先算 `s = Σ_i f[i]*B[i][j]`（$i$ 从 $0$ 到 $N-1$），再令 `g[j] = s*A[j][o]`；最后令 `f[j]=g[j]`。
4. 输出 `Σ_i f[i]`，保留 $4$ 位小数。

### 4.3 复杂度与验证状态

- **时间复杂度**：$O(MN^2)\le1000\times2500=2.5\times10^6$。
- **空间复杂度**：$O(N^2+QN+M)$。
- 编译 `g++ -std=c++17 -O2 -Wall -Wextra`，无警告。
- 自测：$N=1,Q=2,M=1,\pi=1,A=(0.5,0.5)$ 观测 $1$，输出 `0.5000`；$N=2,M=2$ 且 $A$ 为置换矩阵、$B$ 为交换矩阵时，输出 `0.5000`（与手算唯一可行路径一致）；$N=2,M=3$ 的 $8$ 条路径手算总和 $0.099375$，程序输出 `0.0994`；$0.9^{90}=7.6\times10^{-5}$ 的情形输出 `0.0001`（正确四舍五入）；$0.5^{1000}\approx10^{-301}$ 的情形输出 `0.0000`。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{55};

int N,M,Qn;
long double pi[mxn];
long double A[mxn][mxn];
long double B[mxn][mxn];
long double f[mxn],g[mxn];
int O[1005];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>N>>M>>Qn;
	for(int i=0;i<N;++i)
		cin>>pi[i];
	for(int i=0;i<N;++i)
		for(int j=0;j<Qn;++j)
			cin>>A[i][j];
	for(int i=0;i<N;++i)
		for(int j=0;j<N;++j)
			cin>>B[i][j];
	for(int i=0;i<M;++i)
		cin>>O[i];

	for(int i=0;i<N;++i)
		f[i]=pi[i]*A[i][O[0]-1];
	for(int t=1;t<M;++t)
	{
		int o=O[t]-1;
		for(int j=0;j<N;++j)
		{
			long double s=0;
			for(int i=0;i<N;++i)
				s+=f[i]*B[i][j];
			g[j]=s*A[j][o];
		}
		for(int j=0;j<N;++j)
			f[j]=g[j];
	}
	long double ans=0;
	for(int i=0;i<N;++i)
		ans+=f[i];
	printf("%.4Lf\n",ans);
	return 0;
}
```
