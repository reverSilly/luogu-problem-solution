# P1356 [NEERC 1999] 数列的整除性

> 标签：动态规划 DP / 数学（同余） · 难度：提高/省选- · 多组数据 $M\le 20$

## 1. 重新读题

**问题重述（大白话）**

给 $n$ 个整数 $a_1,\dots,a_n$（可正可负可零）。**每个数都必须用上**，只在相邻两数中间填一个 `+` 或 `-`，于是得到形如
$$a_1\pm a_2\pm a_3\pm\cdots\pm a_n$$
的表达式——注意**首项 $a_1$ 前面没有符号位，恒取正**。$n-1$ 个符号位共 $2^{n-1}$ 种填法，只要**存在一种填法**算出的值能被 $k$ 整除，就称该数列能被 $k$ 整除。每组数据输出 `Divisible` 或 `Not divisible`。

**口径钉死（题面证据，不是猜）**

| 问题 | 结论 | 依据 |
|---|---|---|
| 能否"跳过某个数不用"？ | **不能**，$n$ 个数全用 | 样例解释把 $17,5,-21,15$ 的表达式列成**恰好 8 个**，$8=2^{4-1}$；若"每个数可选 $+/-$/不用"则有 $3^4=81$ 种，数目对不上 |
| 首项符号能否取负？ | **不能**，$a_1$ 前无符号位 | 同上，$2^{n-1}$（不是 $2^n$）；题面"每两个整数中间"即 $n-1$ 个空位 |
| 要输出方案吗？ | **不输出**，只输出判定字符串 | 输出格式仅两词，$M$ 行 |
| 有"空选择"退化吗？ | **没有**（见 2.2 引理 0） | 空和 $=0$ 会被任何 $k$ 整除，题目恒真，与"能被 7 整除但不能被 5 整除"矛盾 |
| 负数、$k$、$n$ 范围 | $2\le k\le 100$，$1\le n\le 10^4$，$\lvert a_i\rvert\le 10^4$，$1\le M\le 20$ | 数据规模与约定 |

**复杂度暗示**：$n=10^4$ 时 $2^{n-1}$ 枚举天文数字，必须把"值"压缩成"值 $\bmod k$"。状态只有 $k\le 100$ 个，$n\cdot k=10^6$/组，$M\cdot n\cdot k\le 2\times10^7$，正好是一遍 DP 的量级——这也是标签"DP + 数学"的出处。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制 —— 符号只改变"值"，不改变"用哪些数"

表达式值 $=a_1+\sum_{j\ge 2}s_ja_j,\ s_j\in\{+1,-1\}$。三个立刻能看出的性质：

1. **加法交换律 ⇒ 位置不重要**，只有"谁是首项"看着重要（它被迫取正）——这条 2.5 会用引理 3 处理掉。
2. **判定只看 $\bmod k$**：$k\mid V$ 的定义是 $V\equiv 0\pmod k$，与 $V$ 的具体大小无关；$s_j$ 只贡献 $\pm a_j$。
3. 样例反证"只看全加值"走不通：$n=4,k=7$ 时全加值 $17+5+(-21)+15=16$ 不被 $7$ 整除，而 $17+5+(-21)-15=-14$ 被整除 —— 必须真正处理符号组合的存在性；但反过来"$k=5$ 时 8 个值全不被整除"又说明**不能**只挑一个特例蒙，必须穷尽（这正是 DP 的活）。

### 2.2 口径检验 —— "一个都不选"合法吗？（引理 0）

**引理 0** 若允许"不选任何数"或"只选若干个数"，则判定问题恒为真、失去意义；故题面口径必为"全部数都用"。
**证明**：空选择之和为 $0$，而任意 $k\ge 2$ 有 $k\mid 0$（$0=k\cdot 0$），故"存在被 $k$ 整除的值"恒成立，所有答案都是 `Divisible`。题面明确说"该数列能被 $7$ 整除，但不能被 $5$ 整除"，两者矛盾。故本题不存在"选取若干/最长长度"的语义，是**纯存在性判定**：不需要长度维度、不需要方案回溯、状态值只需两个（可达/不可达）。$\blacksquare$

（这一步把我最初"最长可整除子序列"的直觉否掉了：**题面就是插符号问题**。2.6 引理 4 第 3 条保留一段变体对照，因为那里的哨兵坑正是本题最容易被写错的反面教材。）

### 2.3 只看余数为何不丢信息 —— 状态完备性（引理 1）

**引理 1（前缀只看余数是完备的）** 设 $i<n$。若两种符号填法 $\sigma,\tau$ 作用在前 $i$ 项上得到的值满足 $V_\sigma\equiv V_\tau\pmod k$，则把它们各自向后扩展成完整表达式所能达到的**终值余数集合完全相同**。
**证明**：任意完整表达式的值可写成 $V_\sigma+T$ 或 $V_\tau+T$，其中 $T=\sum_{j>i}s_ja_j$ 只由后缀符号决定、与前缀填法无关。记后缀可达值集合 $\mathcal T$（不依赖 $\sigma,\tau$），则前缀 $\sigma$ 的终值余数集 $=\{V_\sigma+t\bmod k:t\in\mathcal T\}$，前缀 $\tau$ 的同理。由 $V_\sigma\equiv V_\tau\pmod k$ 得两集合逐项相等。故"余数相同"⇒"未来等价"，把同一余数下的多种前缀填法合并成一个状态**不丢失任何与目标 $0$ 相关的信息**。$\blacksquare$

**反证版（最优子结构 / 无漏判）** 若存在完整填法使终值 $\equiv 0$，但 DP 报不可达，则矛盾。
**证明**：取该填法，记前缀余数 $r_i=V_i\bmod k$（$V_i$ 是前 $i$ 项部分和）。$r_1=a_1\bmod k$ 由初始化标记为真。设 $r_i$ 已被标记为真；完整填法在第 $i+1$ 项的符号为 $s_{i+1}$，则 $r_{i+1}\equiv r_i+s_{i+1}a_{i+1}$，正是转移中的某一条（引理 2 的"不漏"），故 $r_{i+1}$ 也被标记。归纳至 $i=n$ 得 $r_n=0$ 被标记，与"DP 报不可达"矛盾。$\blacksquare$

### 2.4 转移：不重不漏（引理 2）

定义 $R_i=\{x\bmod k:\exists$ 前 $i$ 项的填法使值为 $x\}$（这里 $\bmod k$ 取**非负**代表，$0\le r<k$，即代码里的 `norm`），$b_i$ 为 $a_i$ 的非负余数。转移：
$$R_{i+1}=\{(r+b_{i+1})\bmod k,\ (r-b_{i+1})\bmod k:r\in R_i\}.$$
**证明（双向包含）**：
- **不漏**（$R_{i+1}$ 的每个余数都被生成）：取前 $i+1$ 项任一填法，值 $V=V'+s\,a_{i+1}$，$s\in\{+1,-1\}$，$V'$ 是前 $i$ 项按同一填法的值。$V'\bmod k\in R_i$，故 $V\bmod k$ 落在右式的两个分支之一。
- **不重（不产生伪状态）**：右式每个余数都来自某个 $r\in R_i$，由 $R_i$ 的定义存在见证填法；给它追加符号 $s=+$（对应 $r+b$）或 $s=-$（对应 $r-b$）即得真实可达的前 $i+1$ 项填法。故右式 $\subseteq R_{i+1}$。
- **两条分支相撞无害**：当 $b_{i+1}\equiv 0$（或 $2b_{i+1}\equiv 0\pmod k$）时两分支相同。状态是**集合**（代码里是 `bool`），写入语义是"或"，幂等：重复写 `true` 不改变集合，所以不需要判重、也不影响正确性。
由双向包含得 $R_{i+1}$ 的等式。剩下基础情形要说清，不能跳：$i=1$ 时**没有符号位可填**（符号位是"$n-1$ 个中间空"，前缀长 $1$ 时空数为 $0$），表达式唯一、值恰为 $a_1$，所以真实可达集就是单元素集 $\{b_1\}$——这既是归纳起点，也说明初始化只能写**一个** `true`（写 `dp[0][0]=true` 或多写几个都是错的）。对 $i$ 归纳即得"DP 行内容 $=$ 真实可达余数集"。$\blacksquare$

于是答案 $=\,[\,0\in R_n\,]$。基础情形 $n=1$：$R_1=\{b_1\}$，判定 $\iff k\mid a_1$，与"表达式只有 $a_1$ 本身"完全一致，无特判。

### 2.5 首项被迫取正怎么办 —— 对称性引理（引理 3）

**引理 3** 令 $S=\{\sum_{j\ge 2}s_ja_j\bmod k\}$ 为后缀符号和集合。则 $0\in a_1+S\iff 0\in -a_1+S$。即"**首项符号固定为正**"（真实口径，$R_n=a_1+S$）与"**首项符号也可任取**"（$R_n^{\text{free}}=(a_1+S)\cup(-a_1+S)$）两种写法，对目标余数 $0$ 的**判定结果**相同。
**证明**（按"$\iff$ 两个方向 + 收口"写，不跳步）：
- **第一步：$S=-S$（取负封闭）**。任取 $t=\sum_{j\ge2}s_ja_j\in S$，把所有 $s_j$ 同时取反仍是合法符号串（符号位本来就能任意放），得 $-t=\sum_{j\ge2}(-s_j)a_j\in S$。反过来 $-S\subseteq S$ 同理（再取反一次即复原），故 $S=-S$，且取负是 $S$ 上的对合双射。
- **第二步（$\Rightarrow$）**：设 $0\in a_1+S$，即存在 $s\in S$ 使 $a_1+s\equiv 0\pmod k$。两边取负（保持等价，因为 $k\mid x\iff k\mid -x$）得 $-a_1+(-s)\equiv 0$；由第一步 $-s\in S$，故 $0\in -a_1+S$。
- **第三步（$\Leftarrow$）**：与第二步完全同形（把 $a_1$ 换成 $-a_1$，取负两次复原），故亦成立。
- **收口**：自由符号版可达集 $R_n^{\text{free}}=(a_1+S)\cup(-a_1+S)$，于是
  $$0\in R_n^{\text{free}}\iff 0\in a_1+S\ \text{或}\ 0\in -a_1+S\iff 0\in a_1+S,$$
  最后一步用了第二、三步（两支等价）。即"要不要给首项也放开符号"对 $0$ 的判定**毫无影响**。$\blacksquare$
**推论（判定与顺序无关，但集合与顺序有关）** 判定结果只依赖数列的**多重集**：由引理 3，无论指定哪个元素当"被迫取正的首项"，$0$ 的可达性都等价于 $R_n^{\text{free}}$ 里 $0$ 的可达性；而 $R_n^{\text{free}}=\{\pm a_1\pm\cdots\pm a_n\}$ 与顺序无关——理由要说全：加法交换律使同一组符号赋值在置换后给出**同一个值**，且"每个位置独立取 $\pm$"这一约束只依赖位置个数 $n$、不依赖哪个元素占哪个位置，故两版本的赋值集合一一对应。
实用面：这给了一条免费自查——**把输入倒序/排序后重跑，输出的字符串必须不变**；但**不要**据此以为可达余数集合本身也不变（4.3 第 9 条给出了集合确实变了的实例），也别拿它当算法（判据仍要 DP）。$\blacksquare$

### 2.6 两个坑：负数取模 与 "不可达"怎么编码（引理 4）

`c++` 的 `/` 向零截断，故 `-10%7 == -3`（数学余数是 $4$）。若直接把 `b=a[i]%k` 送进转移：`(r+b)%k` 可能为**负**，于是 `dp[...][-1]` 越界写（未定义行为，可能静默污染别的数组），同时正确余数 $6$ 被漏标。例：$k=7$、$a=[2,-3]$，正确 $R_2=\{(2+4)\%7=6,(2-4+7)\%7=5\}$，答案 `Not divisible`；不取模的写法算出 $r+b=-1$ 越界、$r-b=5$ 恰好碰对，最终 $R_2$ 里的 $6$ 丢失。**修法**：入口处一次归一 $b\leftarrow((a\bmod k)+k)\bmod k\in[0,k)$，此后两条分支 $(r+b)\%k$ 与 $(r-b+k)\%k$ 的括号内都落在 $[0,2k)$，一次 `%k` 必回 $[0,k)$。$\blacksquare$

（顺带说明：$b$ 归一后，"不归一"的写法即使侥幸不出负数，也只是**运气好**——见 4.3 第 6 条，$r-b$ 分支碰巧对了、$r+b$ 分支越界，判定结果恰好没被影响，但那是 UB，不能依赖。）

**引理 4（下标闭合 + `false` 编码"不可达"的合法边界）** 三条子结论：

1. **下标闭合**：若读入的 $r\in[0,k)$ 且 $b\in[0,k)$，则两条分支写出的下标都在 $[0,k)$。
   **证明**：$0\le r+b\le(k-1)+(k-1)=2k-2$，故 $(r+b)\%k\in[0,k)$；$r-b+k$ 的最小值 $=0-(k-1)+k=1$、最大值 $=(k-1)-0+k=2k-1$，同样落在 $[1,2k-1]\subset[0,2k)$，取模后 $\in[0,k)$。$\blacksquare$（注意这里**必须** $b\ge 0$，否则下界为负——这正是本小节上半段"负数取模"论证的形式化。）
2. **`bool` 编码的正确性**：记行号 $row(j)=(j-1)\&1$（第 5 节代码的循环变量是 $0$-based，所以那里写成"`dp[i\&1]$ 存 $R_{i+1}$"，两者一致：$i=0$ 时 $row(1)=0$）。不变量：$\texttt{dp}[row(j)][r]=\texttt{true}\iff r\in R_j$，**成立当且仅当每行在被写之前是空集**。
   **证明**：归纳。基础：清空后仅写 `dp[0][b_1]=true`，第 0 行 $=\{b_1\}=R_1$，第 1 行为空（不会被读）。归纳步：设第 $pre$ 行恰为 $R_i$；第 $cur$ 行若已清空，则本轮只由 $R_i$ 的元素质地生成 $\{r\pm b\}$，由引理 2 双向包含得 $R_{i+1}$；若**未**清空，则该行的最终内容 $=R_{i+1}\cup E$，$E$ 是残留集合，$E\supseteq\varnothing$ 且只会带来"多标 `true`"。由于所有写都是单调的 `=true`（无撤销、无计数），失败模式只有"假阳性（误报可达）"，绝不会漏标。故漏清只会把 `Not divisible` 误成 `Divisible`，反向错误不可能出现——这也解释了 4.3 两个反例都朝同一个方向翻车。$\blacksquare$
3. **"$f[i][0]=0$ 的合法性边界"**：本题状态是**集合成员**，没有"长度"维度，`false` 就是"不可达"，与全局默认 $0$ 语义一致，因此**不需要** $-1$/`neginf` 负哨兵；但"一致"不等于"可以不清"——默认 $0$ 只对**程序启动后的第一组第一次**成立（第 2 条）。反例见 4.3 第 7、8 条。
   对照变体：若状态是 $f[i][r]=$ "前 $i$ 项中**选取若干**使和 $\equiv r$ 的最大长度"，则 $f[i][0]=0$ 是**真合法**状态（选 $0$ 个数，空和 $=0$，长度 $0$），此时"默认 $0$"与"不可达"两种语义撞在同一个数上，必须显式 `fill_n(...,-1)`（或 `neginf`）才能区分。而"空和合法"这一条本身在本题是**禁止**的（引理 0），所以本题不能借用那套语义。$\blacksquare$

### 2.7 若题目要求输出方案（引理 5，本题不需要但补全）

**引理 5（`prv` 回溯可还原合法符号串）** 把数组扩成 $n$ 行（不滚动），并令 $\mathrm{prv}[i+1][r']=(r,s)$ 记录"$r'$ 由第 $i$ 行的 $r$ 经符号 $s\in\{+1,-1\}$ 转移而来"（每个状态只在**首次**变为 `true` 时写入，此后不覆盖）。则从 $(n,0)$ 出发沿 $\mathrm{prv}$ 逐步回到第 $1$ 行，可解出一个终值 $\equiv 0\pmod k$ 的合法填法。
**证明**：
- **每条链边都对应真实扩展**：$\mathrm{prv}$ 只可能在"$\texttt{dp}[i][r]=\texttt{true}$ 且 $\texttt{dp}[i+1][r']$ 由它写入"的时刻被赋值，故 $r'\equiv r+s\,a_{i+1}$ 且 $r$ 有见证填法 $A_i$；把 $s$ 添到 $A_i$ 末尾即得 $A_{i+1}$，其值 $\equiv r'$。由引理 4 第 1 条，$r'\in[0,k)$，记录不会串位。
- **链条终止**：每走一步行号严格减 $1$，$n$ 步内必到第 $1$ 行；第 $1$ 行只有唯一状态 $b_1$（初始化），它正是"$a_1$ 单独立成式"的合法前缀，链条在此自然结束，无需额外终止条件。
- **终点余数为 $0$**：回溯起点选的是 $r'_n=0$，逐层满足上式，故最终填法的值 $V$ 满足 $V\equiv 0\pmod k$，即 $k\mid V$，合法。
- **只存一条前驱够不够**：够。因为目标是存在性判定下的**任一**方案，任一见证都合格；后到的转移即使"更好"也无从比较（集合无权重），"首次写入不覆盖"给出良定义的前驱树，且每个被标 `true` 的状态都有前驱（除 $i=1$），故不会出现断链。（注：若目标是"最长/最优"型，就必须按更优覆盖，且要用引理 4 第 3 条的负哨兵；本题不属此型。）$\blacksquare$

滚动数组会抹掉历史行，因此**判定用滚动、回溯用 $n$ 行**：$n\cdot k\le 10^6$ 个 `bool` + 前驱，约 $2\,\text{MB}$ 量级，完全放得下，但代码更啰嗦；题面不要求方案，故第 5 节不实现。

### 2.8 独立校验用的必要条件（引理 6）

**引理 6** 记全加值 $V_0=\sum_{j=1}^n a_j$，$g=\gcd(2a_2,2a_3,\dots,2a_n,k)$（$n=1$ 时取 $g=k$）。若数列能被 $k$ 整除，则 $g\mid V_0$。此条件**必要而不充分**。
**证明**：
- *等式*：设负号位置集合 $T\subseteq\{2,\dots,n\}$，则任一表达式的值 $V=V_0-2\sum_{j\in T}a_j$（把 $+$ 翻成 $-$ 就是减 $2a_j$）。
- *必要性*：$g$ 整除每个 $2a_j$，故 $g\mid 2\sum_{j\in T}a_j$，由等式得 $V\equiv V_0\pmod g$；若 $k\mid V$，又 $g\mid k$，则 $g\mid V$，即 $V\equiv 0\pmod g$。两式合并得 $V_0\equiv 0\pmod g$，亦即 $g\mid V_0$。（注意别写成"$g\mid V$ 恒成立"——只有 $V_0\equiv V$ 模 $g$ 同余，$g$ 未必整除 $V$。）
- *不充分*：取 $n=2,k=100,a=2,6$。$V_0=8$，$g=\gcd(12,100)=4$，$4\mid 8$ 条件通过；但两个表达式的值是 $2+6=8$ 与 $2-6=-4$，都不被 $100$ 整除 ⇒ `Not divisible`。原因是 $T$ 只能在有限个 $\{a_j\}$ 里挑，$\sum_{j\in T}2a_j$ 只能取有限个值，"同余类整除"信息不足以刻画它（这正是 DP 必须存在、不能只看 $\gcd$ 的理由）。
- *$n=1$ 口径*：$g=k$，条件退化为 $k\mid a_1$，与真实判定完全一致 ✓。$\blacksquare$

### 2.9 收尾：容量、优化与变体对照

- **规模**：$n\cdot k\le 10^4\times 100=10^6$ 状态/组，转移 $O(1)$；$M\le 20$ 总计 $2\times10^7$，一遍扫即可，无需任何数据结构。
- **滚动数组**：$R_{i+1}$ 只依赖 $R_i$，两行 $2\times k$ 足够。代价是丢掉回溯能力（本题不需要方案，见引理 5）。
- **bitset 加速（可选，第 5 节不用）**：把位图放进 `bitset<2*mxk>`（只用低 $k$ 位），则 $R\to R\pm b$ 就是两次循环移位取并：$g=\big((f\ll b)\mid(f\gg(k-b))\big)\mid\big((f\gg b)\mid(f\ll(k-b))\big)$，再 `g &= (bitset 低 k 位全 1)` 掩掉噪声位（$b=0$ 时 $\gg k$ 自然为 $0$，退化正确）。代价降到 $O(nk/64)$，但 $k\le 100$ 时本题 $2\times10^7$ 已远快于时限，移位拼接还多两处易错点（掩码、$k-b$ 与 $b$ 的对称），**收益不抵风险，不写**。
- **$O(k)$ 内存即可**：判定时连 $a$ 都可以边读边处理（首项特殊、其余按引理 3 用"全自由符号"版本），但保留 `a[mxn]` 更直观，$10^4\times 4\,\text{B}=40\,\text{KB}$ 级别，不值得为省它牺牲可读性。
- **哨兵坑（反面教材，详见引理 4 第 3 条）**：本题是 `bool` 可达集，`false` 就是"不可达"，**不需要**负哨兵；但若换成"选取若干求最大长度"那类变体，$0$ 既表示"长度 $0$ 可达"又会被全局默认当成初值，必须 `fill_n(...,-1)`。两种语义不要混。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 表达式值 $=a_1+\sum_{j\ge2}s_ja_j$：符号位只有 $n-1$ 个、判定只看 $\bmod k$、加法可交换（"位置重要吗"这条要等引理 3 才敢下结论）。
- **口径核对（用样例计数反证）** — 样例给出 $8=2^{n-1}$ 个表达式，$\ne 3^n$，排除"可选子序列/可不选"读法；空选取使判定恒真（引理 0），也排除之 → 问题定性为**存在性判定**，无长度维度、无方案输出。
- **state-completeness proof** — 引理 1：同余 ⇒ 未来可达集相同，故压缩到 $k$ 个剩余类不丢信息；再配一个反证版（沿真实填法的前缀余数归纳）保证"存在解 ⇒ DP 必标出"，不漏判。
- **classic problem solution** — 前缀余数可达集布尔 DP，转移"末项取 $+$ / 取 $-$"两条；引理 2 证双向包含（不重不漏），并说明两条分支相撞（$b=0$）对集合语义无害。
- **reduce to easier problem** — 引理 3 用 $S=-S$ 的对称性把"首项被迫取正"这个别扭口径化掉：它与"全自由符号"在余数 $0$ 上等价，顺带得到"判定与顺序无关"的免费自查手段。
- **modular-normalization discipline** — $((a\%k)+k)\%k$ 一次归一 + 引理 4 第 1 条的下标闭合论证（$[0,2k)$ 一次取模必回 $[0,k)$），堵住 C++ 负余数越界。
- **encoding-choice audit（不可达怎么编码）** — 引理 4 第 2、3 条：`bool` 的 `false` 就是不可达（无需负哨兵），但只有"写前为空"时不变量才成立，且失败只会单向假阳性；变体（最长长度）才需要 $-1$/`neginf`。
- **rolling array + explicit fill_n** — 两行滚动省内存，代价是每组、每轮都必须显式清零，4.3 第 7、8 条各给一组会误报 `Divisible` 的具体数据。
- **backtracking remark** — 若题面改成要输出符号串，按引理 5 存 $n$ 行 $+\ \mathrm{prv}$（首次写入不覆盖）即可回溯，并给出"链终止于 $R_1=\{b_1\}$"的良定义论证。
- **independent invariant check** — 引理 6 的 $\gcd(2a_2..2a_n,k)\mid V_0$ 判据（必要非充分，$n=1$ 时自动变充要）作为第二条独立算路，用来手算复核 DP 的小例。
- **verify against the problem's own enumeration** — 把 $R_n$ 与题面列出的 $8$ 个表达式值**逐元素**比对（不只比"含不含 $0$"）；这条严格检查推翻了我初稿"可达集也是排列不变量"的错误推广（4.3 第 9 条）。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `M` | 数据组数 | `int` | $\le 20$，`while(M--)` |
| `n,k` | 每组：项数、除数 | `int` | $n\le10^4$，$2\le k\le100$ |
| `a[i]` | 原始数列，**0-based** | `int`，每组读入覆盖 | 有负数，故必须归一化 |
| $b_i$ / 代码 `b` | $a_i\bmod k\in[0,k)$ | 计算量 | `norm(a[i],k)`，只做一次 |
| $R_i$ / 代码 `dp[2][mxk]` | 前 $i$ 项全用后的可达余数集（`dp[i&1][r]` = "余数 $r$ 可达"） | `bool`，**每组 `fill_n` 全清 + 每轮清 `dp[cur]`** | 行 $0$ 先存 $R_1$；`false` 即不可达（引理 4） |
| `cur,pre` | 滚动两行下标：`cur=i&1`、`pre=cur^1`（即 $(i\&1)\oplus 1$） | 循环内量 | 两行交替，$pre$ 存 $R_i$、$cur$ 生成 $R_{i+1}$ |
| `last` | 终行 $(n-1)\&1$ | 计算量（代码里直接内联在 `cout`） | 答案 `dp[last][0]`；$n=1$ 时为 $0$，即初始化那一行 |

数组尺寸 `mxn{10005},mxk{105}`（约束 $+5$ 裕量）。

### 4.2 算法步骤

1. 读 $M$；对每组读 $n,k$ 与 $a_0..a_{n-1}$。
2. `fill_n(&dp[0][0],2*mxk,false)` 清两行（引理 4：不可达 $=$ `false`；多组间必须清）。
3. 初始化 $R_1$：`dp[0][norm(a[0],k)]=true`（首项无符号位，见 2.2/2.4）。
4. 对 $i=1..n-1$：`cur=i&1,pre=cur^1,b=norm(a[i],k)`；`fill_n(dp[cur],mxk,false)`；对 $r=0..k-1$ 若 `dp[pre][r]` 则 `dp[cur][(r+b)%k]=dp[cur][(r-b+k)%k]=true`（引理 2；$b=0$ 时两分支重合无害）。
5. 输出 `dp[(n-1)&1][0] ? "Divisible" : "Not divisible"`，`'\n'` 换行。
6. **复杂度**：每组 $n\cdot k\le 10^4\times 100=10^6$ 次状态访问、$\le 2\times10^6$ 次写；$M\le20$ 总 $\le 2\times10^7$，远小于 $10^8$ 量级每秒预算。空间 $O(n+k)$。
7. **`int` 上界核对**：归一后 $b,r<k\le100$ ⇒ $r+b\le198$、$r-b+k\le199$，加法不接近 $2^{31}$；即便退回"整表达式值"旧写法，$|\sum\pm a_j|\le 10^4\times10^4=10^8<2^{31}-1$ 也仍安全（但我们不这么做）。$2^{n-1}$ 只出现在论证里，绝不参与运算。

### 4.3 验证状态（全部手算，未运行任何代码）

1. **主例 $k=7$，$a=17,5,-21,15$**：归一 $b=[3,5,0,1]$。

5. **无解 + 奇偶不变量交叉验证**：$n=3,k=2,a=1,1,1$ ⇒ $R_1=\{1\}$，$R_2=\{(1{+}1)\%2=0,(1{-}1{+}2)\%2=0\}=\{0\}$，$R_3=\{1\}$ ⇒ `Not divisible`。枚举 $1\pm1\pm1\in\{3,1,1,-1\}$ 全奇 ✓。再用引理 6 复核：$V_0=3$，$g=\gcd(2a_2,2a_3,k)=\gcd(2,2,2)=2\nmid 3$ ⇒ 必要条件直接把答案排除，两条独立路子同结论 ✓。

8. **引理 4 的反例（漏清组间 → 跨组污染）**：第 1 组 $n=4,k=2,a=1,1,2,2$（正确 $R_4=\{0\}$ ⇒ `Divisible`，$R_3$ 写在行 $0$、其内容 $\{0\}$）；紧接第 2 组 $n=1,k=2,a=1$，正确应 `Not divisible`，但因 $n=1$ 时循环体不执行、行 $0$ 从未被清，读到上一组残留的 `dp[0][0]=true` ⇒ 误报 ✗。**每组开头必须整体 `fill_n`**。
9. **顺序无关自查（引理 3 推论，含一处我自己算错的更正）**：把主例倒过来 $a=15,-21,5,17$（$k=7$），归一 $b=[1,0,5,3]$：$R_1=\{1\}$ → $R_2=\{1\}$（$b=0$）→ $R_3=\{(1{+}5)\%7=6,(1{-}5{+}7)\%7=3\}=\{3,6\}$ → $R_4=\{6{+}3,6{-}3,3{+}3,3{-}3{+}7\}\%7=\{2,3,6,0\}$，含 $0$ ⇒ 仍 `Divisible` ✓，判定与正序一致。

10. **$k=1$ 越界鲁棒性（数据不出现，$k\ge2$）**：若真输入 $k=1$，`norm` 里 `%1` 与 `for(r<k)` 都安全（$k\ne0$，无除零），恒有 $R_i=\{0\}$ ⇒ 恒 `Divisible`，与"$1$ 整除一切"一致，仅当 $k=0$ 才会炸（题面排除）。
11. **自由符号版 vs 固定首项版（验证引理 3 的"$\supseteq$ 真包含"）**：主例（正序）若把 $a_1=17$ 的符号也放开，即 $\pm3\pm5\pm0\pm1\pmod 7$，可列出 $2,0,6,4,3,1,0,5$ —— 得集合 $\{0,1,2,3,4,5,6\}$，比固定首项的 $\{0,2,4,6\}$ 多出 $1,3,5$。故两版可达集**确有差别**，而 $0$ 的归属同为"真"，与引理 3 完全吻合（不是"两版等价到集合级"，只是"$0$  membership 等价"）。

## 5. 示例代码（C++）

```cpp
// P1356 [NEERC 1999] 数列的整除性
// 前缀余数可达集 DP（全用数列 + 插 +/-），两行滚动
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005},mxk{105};

int n,k,a[mxn];
bool dp[2][mxk];        // dp[i&1][r]: 前 i+1 项全用后余数 r 是否可达

int norm(int x,int m){return ((x%m)+m)%m;}   // 负数安全，落到 [0,m)

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int M;
	cin>>M;
	while(M--)
	{
		cin>>n>>k;
		for(int i=0;i<n;++i)
			cin>>a[i];
		fill_n(&dp[0][0],2*mxk,false);   // 组间必须清，false=不可达
		dp[0][norm(a[0],k)]=true;        // 首项没有符号位
		for(int i=1;i<n;++i)
		{
			int cur=i&1,pre=cur^1,b=norm(a[i],k);
			fill_n(dp[cur],mxk,false);   // 轮间也必须清（见 4.3 反例）
			for(int r=0;r<k;++r)
				if(dp[pre][r])
				{
					dp[cur][(r+b)%k]=true;
					dp[cur][(r-b+k)%k]=true;   // b<k ⇒ 括号内∈(0,2k)
				}
		}
		cout<<(dp[(n-1)&1][0]?"Divisible":"Not divisible")<<'\n';
	}
	return 0;
}
```

### 代码说明

- **`dp` 是 `bool` 可达集，不是"最大长度"**：所以 `false`(0) 与"不可达"同义（引理 4），不需要 $-1$/`neginf` 负哨兵；但**必须**显式 `fill_n` 两次（组间、轮间），4.3 第 7、8 条给出了漏清时的具体误判数据。
- **`norm` 一次到位**：在写入前把 $a_i$ 归一到 $[0,k)$，此后 `(r+b)%k`、`(r-b+k)%k` 的自变量都在 $[0,2k)$，取模后必落回 $[0,k)$（引理 4），杜绝负下标越界。
- **两条分支**对应末项符号 $+/-$，$b=0$ 时重合，`bool` 写两次幂等无害（引理 2）。
- **$n=1$ 无需特判**：循环体不执行，终行 $(n-1)\&1=0$ 恰是初始化那一行。
- **首项固定正号**由 2.4 的基础情形保证；若改用"全自由符号"写法（`dp[0][0]=true` 起、对 $n$ 项都做 $\pm$），由引理 3 判定结果不变，但那种写法里"$R_0=\{0\}$"必须是空和恒等式而不是"长度 $0$"，别再叠一层最长语义。
- 风格：`bits/stdc++.h` 单头、全局静态数组、`mxn/mxk` 取约束 $+5$、`cin.tie→cout.tie→sync_with_stdio` 固定顺序、`'\n'`、Tab 缩进、运算符无空格、内部 0-based。
