# P1033 [NOIP 2002 提高组] 自由落体 — 题解

---

## 一、「啊？自由落体和车有什么关系」— 从发现的视角重新描述

Title: 自由落体

第一眼看到这题，最有意思的地方在于：**天上掉的是小球，地上跑的是小车，它们同时开始动，你要数小车能接住多少个球**。听起来像是一个模拟题？但仔细一想——球在水平方向是不动的（自由落体只有竖直运动），车在水平方向匀速往前开——那小球能不能被接住，其实只取决于**球落在车顶高度的那一瞬间，车有没有恰好经过它的正下方**。

也就是说，这不是一个随时间演变的"追逐"问题，而是一个**几何重叠**问题：球竖直下落到车顶高度需要固定的一段时间，在这段时间里车开了一段距离；球继续下落到地面之前，只要车身的水平投影覆盖了球的水平位置，球就能被接住。

## 二、「从物理到数学」— 完整的推导链

### 2.1 符号约定

| 符号 | 含义 | 范围 |
| --- | --- | --- |
| $H$ | 天花板高度（球初始高度） | $[1,10^5]$ |
| $n$ | 小球个数，位于 $0,1,\dots,n-1$ | $[1,10^5]$ |
| $L$ | 小车长度 | $[1,10^5]$ |
| $K$ | 小车高度 | $[1,10^5]$ |
| $S_1$ | 小车距原点的初始距离 | $[1,10^5]$ |
| $V$ | 小车速度 | $[1,10^5]$ |
| $g$ | 重力加速度，固定为 $10$ | $10$ |
| $d=\frac12 g t^2$ | 自由落体下落距离 | — |

### 2.2 时间窗口：球什么时候能被接住？

球从天花板（高度 $H$）静止释放，自由落体。

- **球到达车顶高度** $K$（即下落 $H-K$）所需时间：

$$
t_1=\sqrt{\frac{2(H-K)}{g}}=\sqrt{\frac{H-K}{5}}
$$

当 $H\le K$ 时，球一开始就已经在车顶高度或以下，取 $t_1=0$。

- **球落到地面**（下落 $H$）所需时间：

$$
t_2=\sqrt{\frac{2H}{g}}=\sqrt{\frac{H}{5}}
$$

因此，球能被接住的**时间窗口**是 $[t_1,\,t_2]$。

### 2.3 空间范围：车在时间窗口内覆盖了哪些位置？

小车初始位置是：它的左端（靠近原点的一端）在 $S_1$，右端在 $S_1+L$。它以速度 $V$ 向右匀速运动。

在任意时刻 $t$，小车覆盖的水平区间为：

$$
[\,S_1+Vt,\;S_1+Vt+L\,]
$$

球在水平方向不做运动，始终保持在它的初始位置 $x\;(0\le x\le n-1)$。

因此，球 $x$ 能被接住的充要条件是：

$$
\exists\,t\in[t_1,t_2]\quad\text{使得}\quad x\in[\,S_1+Vt,\;S_1+Vt+L\,]
$$

### 2.4 合并区间：一个简洁的不等式

由于 $V>0$，小车匀速右移，左端点 $S_1+Vt$ 在 $[t_1,t_2]$ 上是 $t$ 的增函数。

因此，在时间窗口 $[t_1,t_2]$ 内，小车覆盖的所有水平位置的**并集**就是：

$$
\big[\,S_1+Vt_1,\;S_1+Vt_2+L\,\big]
$$

验证一下：左端点取 $t_1$ 时的最小左边界，右端点取 $t_2$ 时的最大右边界。区间内的每一个位置，都存在某个 $t\in[t_1,t_2]$ 使它被覆盖。

所以球的水平位置 $x$ 只需满足：

$$
S_1+Vt_1\;\le\;x\;\le\;S_1+L+Vt_2
$$

### 2.5 误差容限

题目要求：**当小球距小车的距离 $\le 0.0001$ 时，即认为小球被小车接受**。这意味着球可以"差一点点"就碰到车——我们把区间两边各放宽 $0.0001$。

$$
S_1+Vt_1-0.0001\;\le\;x\;\le\;S_1+L+Vt_2+0.0001
$$

### 2.6 取整与边界裁剪

$x$ 是整数（球的编号），且必须在 $[0,n-1]$ 内。

- 最小的可行位置：$l=\big\lceil S_1+Vt_1-0.0001\big\rceil$，裁到 $[0,n-1]$
- 最大的可行位置：$r=\big\lfloor S_1+L+Vt_2+0.0001\big\rfloor$，裁到 $[0,n-1]$

答案：

$$
\text{ans}=\max\big(0,\;r-l+1\big)
$$

## 三、「跳出物理看本质」— 核心模式总结

把这道题抽象出来，其实是一个**一维区间覆盖**问题：

1. 有一个**移动的接收窗口**（小车），窗口大小固定 $L$，匀速右移，窗口覆盖的区间为 $[S_1+Vt,\;S_1+Vt+L]$。
2. 有一组**固定位置的点**（小球）。
3. 接收窗口只在某段时间窗口 $[t_1,t_2]$ 内有效。
4. 点与窗口的距离容差为 $\varepsilon=0.0001$。

**关键技巧**：不要随时间去"模拟"每个球——把时间窗口内窗口覆盖的**所有位置取并集**，得到一个静态的大区间，然后检查哪些点落在这个区间里。这是**运动学问题静态化**的经典思路。

类似问题模式：匀速移动的收集器 + 固定位置的物品 + 时间窗口 → 求区间内的点数。

## 四、「说人话」— 正解的一句话总结

1. 算球落到车顶的时间 $t_1$，落到地面的时间 $t_2$。
2. 算这段时间里小车覆盖的水平区间 $[\,S_1+Vt_1-0.0001,\;S_1+L+Vt_2+0.0001\,]$。
3. 数这个区间里有多少个整数位置在 $[0,n-1]$ 内。

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	double H,S1,V,L,K;
	int n;
	cin>>H>>S1>>V>>L>>K>>n;

	double t1=sqrt(max(0.0,H-K)/5.0);
	double t2=sqrt(H/5.0);

	double left=S1+V*t1-0.0001;
	double right=S1+L+V*t2+0.0001;

	int l=ceil(left-1e-12);
	int r=floor(right+1e-12);

	if(l<0)
		l=0;
	if(r>n-1)
		r=n-1;

	int ans=r-l+1;
	if(ans<0)
		ans=0;
	cout<<ans<<'\n';

	return 0;
}
```

### 代码说明

- `max(0.0,H-K)`：处理 $H\le K$ 时 $t_1=0$ 的情况，避免对负数开平方。
- `left` 和 `right` 直接用 `double` 计算，最后加上极小修正值 `1e-12` 克服浮点舍入误差（防止 `2.0000000000001` 被 `floor` 截成 $2$ 而不是 $3$ 等）。
- 使用 `cmath` 中的 `ceil` 和 `floor`（已由 `bits/stdc++.h` 包含）。
- 答案类型为 `int`（$n\le 10^5$，结果不会溢出）。

---

### 样例验证

假设 $H=100,\;S_1=0,\;V=1,\;L=10,\;K=10,\;n=100$：

- $t_1=\sqrt{(100-10)/5}=\sqrt{18}\approx4.2426$
- $t_2=\sqrt{100/5}=\sqrt{20}\approx4.4721$
- $left\approx0+4.2426-0.0001=4.2425$
- $right\approx0+10+4.4721+0.0001=14.4722$
- $l=5,\;r=14$，答案 $=10$。

**总结一句话**：因为小车匀速运动和自由落体都可以解析求解，这道题本质上是 O(1) 的区间计数，不需要任何循环或模拟。
