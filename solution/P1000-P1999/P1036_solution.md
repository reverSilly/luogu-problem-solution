# P1036 [NOIP 2002 普及组] 选数 题解

## 一、发现之旅

——"从 n 个数里选 k 个，和为素数的方案有多少种？"

第一次看到这个问题，直觉是"枚举所有组合，逐个判断"。但有两个疑虑挥之不去：一是组合数会不会太多、枚举不完？二是素数判断怎么写才够快？

先看数据范围：$n\le 20$，最坏情况 $n=20,k=10$，组合数 $\binom{20}{10}=184756$——连二十万都不到。对每个组合做一个 $O(\sqrt{S})$ 的素数测试，$S$ 最大值约 $5\times10^6\times19\approx 9.5\times10^7$，开平方不到一万。$184756\times 10000\approx 1.8\times 10^9$，看着好像有点大？

但实际远没那么糟。组合数在 $k$ 接近 $n/2$ 时确实达到峰值，可 $k$ 很小或很大时组合数急剧下降。更重要的是，大部分和会在远小于最大值时就提前被筛掉——大多数整数都不是素数，试除法在前几轮就能返回结果。加上 $n\le20$ 这个紧约束，暴力枚举在任意当代 OJ 上都能轻松跑进 10ms。

于是核心就清晰了：**枚举组合 + 素数判定**。前者用 DFS 按顺序选数避免重复，后者用试除法或预筛。

这便是本题的全部——不绕弯子，朴实直接。

---

## 二、思路推导

### 2.1 枚举所有组合

从 $n$ 个元素中选出 $k$ 个，要求**无序**（组合而非排列）。标准做法是 DFS，维护三个状态：

- 当前选到了第几个数（下标 `i`）
- 已经选了多少个数（`cnt`）
- 当前已选数的和（`sum`）

关键约束：**每层只从当前下标之后开始选**，保证按原序选数，不会产生重复组合。

```
dfs(i, cnt, sum)
    if cnt == k
        if is_prime(sum)
            ++ans
        return
    if i == n
        return
    // 选 x[i]
    dfs(i + 1, cnt + 1, sum + x[i])
    // 不选 x[i]
    dfs(i + 1, cnt, sum)
```

这是最直观的"选/不选"写法，但会遍历全部 $2^n$ 个子集，$n=20$ 时 $2^{20}=1,048,576$，完全可行。也可以剪枝：若剩余数 $n-i$ 不够凑满 $k$ 则提前返回。

### 2.2 素数判定

试除法：对整数 $S$，从 $2$ 试除到 $\lfloor\sqrt{S}\rfloor$，若均不能整除则为素数。

证明：若 $S$ 有因子 $d$，则 $S/d$ 也是因子，且至少有一个 $\le \sqrt{S}$。因此只需检查到 $\sqrt{S}$ 即可。

$1$ 特判为非素数。

由于 $S\le 9.5\times10^7$，$\sqrt{S}\le 10^4$，试除代价极低。也可用埃氏筛预先生成 $[2,10^4]$ 素数表加速，但对本题非必要。

### 2.3 复杂度分析

- 枚举：$O(2^n)$，$n\le20$ 时约 $10^6$ 状态
- 素数判断：每次 $O(\sqrt{S})\approx O(10^4)$
- 总复杂度：$O(2^n\sqrt{S})\approx 10^{10}$ 是上界分析，实际远小于此，因为：
  - 只有 $k$ 个被选中的分支才会调用素数判断（约 $\binom{n}{k}$ 次）
  - 多数和不是素数，试除法很快返回

## 三、模式总结

本题是**组合枚举 + 素数判定**的经典入门题，蕴含两个可泛化的模式：

| 模式 | 适用场景 | 变体 |
|------|---------|------|
| **DFS 组合枚举** | $n$ 选 $k$，无序子集 | 可重选（允许重复元素）、带权约束（和不超过某值）、子集和问题 |
| **试除法素数判定** | 单个数、值域 $\le 10^{12}$ | Miller–Rabin（大数）、埃氏筛/线筛（批量）、预处理素数表加速 |

DFS 选数的核心技巧是**传递起始下标**，保证按序枚举、不重不漏。这是所有组合类搜索的基础。

## 四、完整解法

### 符号约定

| 符号 | 含义 |
|------|------|
| $n$ | 整数个数 |
| $k$ | 需要选择的个数 |
| $x_i$ | 第 $i$ 个整数，$0\le i<n$ |
| $S$ | 当前已选数的和 |
| $\text{ans}$ | 和为素数的方案总数 |

### 算法流程

1. 读入 $n,k$ 和数组 $x[0..n-1]$
2. 调用 `dfs(0,0,0)` 开始搜索
   - 参数：当前下标 `i`，已选个数 `cnt`，当前和 `sum`
   - 若 `cnt == k`：检查 `is_prime(sum)`，是则 `++ans`
   - 若 `i == n`：返回
   - 否则分支：
     - 选 $x_i$：`dfs(i+1, cnt+1, sum+x[i])`
     - 不选 $x_i$：`dfs(i+1, cnt, sum)`
3. 输出 `ans`

### 素数判定 `is_prime(x)`

- 若 $x<2$：返回 `false`
- 枚举 $d$ 从 $2$ 到 $\sqrt{x}$：
  - 若 $x\bmod d = 0$：返回 `false`
- 返回 `true`

也可预先生成 $[2,10^4]$ 的素数表，用素数试除加速，但非必须。

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};

int n,k,x[mxn],ans;

bool is_prime(int x)
{
	if(x<2)
		return 0;
	for(int d=2;d*d<=x;++d)
		if(x%d==0)
			return 0;
	return 1;
}

void dfs(int i,int cnt,int sum)
{
	if(cnt==k)
	{
		if(is_prime(sum))
			++ans;
		return;
	}
	if(i==n)
		return;
	dfs(i+1,cnt+1,sum+x[i]);
	dfs(i+1,cnt,sum);
}

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int i=0;i<n;++i)
		cin>>x[i];

	dfs(0,0,0);

	cout<<ans<<'\n';
	return 0;
}
```
