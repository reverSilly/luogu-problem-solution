# P1369 矩形

> 标签：贪心 / 前缀和 · 难度：普及/提高-

## 1. 重新读题

**大白话版本**

平面上给 $n$ 个整点，要放一个**边与坐标轴平行**的矩形，数它**四条边围成的框线**上有多少个点（角上算、边上算、正中间的点不算），把这个数最大化，输出这个最大值。

**先把题面的坑钉死（逐字以题面为准）**

## 2. 思维链（Chain-of-thought）

### 2.1 第一步：先把"边界上"变成一个不重不漏的式子

矩形 $Q=[x_1,x_2]\times[y_1,y_2]$（整数边，$x_1<x_2,\;y_1<y_2$）的内部是 $\{x_1<x<x_2,\;y_1<y<y_2\}$，边界 $\partial Q$ 就是 $Q$ 去掉内部。对格点而言：

**引理 1（边界格点的不交划分）** 整数矩形 $\partial Q$ 里的整点恰分成两块不交的点集：
$$\text{竖块}=\{x\in\{x_1,x_2\},\;y_1\le y\le y_2\},\qquad
\text{横块}=\{y\in\{y_1,y_2\},\;x_1<x<x_2\}.$$

**证明**：设整点 $p=(u,v)\in\partial Q$。由 $\partial Q=Q\setminus Q^\circ$，$p\in Q$ 故 $x_1\le u\le x_2,\;y_1\le v\le y_2$；且 $p\notin Q^\circ$，即"$x_1<u<x_2$ 且 $y_1<v<y_2$"为假，故 $u\in\{x_1,x_2\}$ 或 $v\in\{y_1,y_2\}$（对合取式取德摩根律：$\neg(A\land B)=\neg A\lor\neg B$，而整数 $u$ 满足 $\neg(x_1<u<x_2)\iff u\in\{x_1,x_2\}$，因为在 $x_1\le u\le x_2$ 里 $u$ 只可能是端点）。所以 $p$ 落在竖块或横块里，**穷尽**成立。
**互斥**：任一整数 $u\in[x_1,x_2]$ 必满足"$u\in\{x_1,x_2\}$"与"$x_1<u<x_2$"中的**恰一个**（这是实数序的三分律在整数上的限制，两者既不同时成立也不同时不成立）。于是竖块要求 $u\in\{x_1,x_2\}$，横块要求它的否定，两块交集为空。特别地，角点 $(x_1,y_1)$ 的 $u=x_1$ 只属于竖块，**不会**被横块重复计入（横块把 $x=x_1,x_2$ 排除了）——这正是"角只算一次"的来源。$\blacksquare$

有了它，计数就写成（$c(u,v)$ 表示坐标 $(u,v)$ 处的点数，重复点 $\ge 2$）
$$\mathrm{cnt}(x_1,x_2,y_1,y_2)=\sum_{y=y_1}^{y_2}\big(c(x_1,y)+c(x_2,y)\big)+\sum_{x=x_1+1}^{x_2-1}\big(c(x,y_1)+c(x,y_2)\big).$$

### 2.2 朴素暴力及其真实代价

最直接的写法：四重循环枚举 $x_1<x_2,\;y_1<y_2$，每个矩形把 $n$ 个点逐个判"是否在边界上"（判据由引理 1 给出：$u\in\{x_1,x_2\}$ 且 $y_1\le v\le y_2$，或 $v\in\{y_1,y_2\}$ 且 $x_1<u<x_2$，全是整数比较）。矩形数 $\binom{100}{2}^2=24\,502\,500$，乘 $n=300$ 得 $7.4\times10^9$ 次判定——不可接受；$n\le30$ 时也是 $7.4\times10^8$，偏慢。⇒ 有两个可下手的方向：**(1) 减少矩形个数**（候选线压缩，$n\le30$ 的子任务吃这一招，见 2.4）；**(2) 减少单个矩形的成本**（前缀和做到 $O(1)$，见 2.5）。$n$ 大而值域小时，(2) 才是主线——但 (1) 的证明工具（"空边可以外推"）正是理解本题几何条件的关键，所以先把 2.3 的反例讲透。

### 2.3 一个会被打穿的"贪心直觉"：四条边都该过点吗？

直觉：既然目标是"边界上点最多"，那就把每条边往有点的方向推、推到正好压住点为止，于是"只需枚举过某个点的竖线/横线"，候选从 $100$ 条缩到 $\le n$ 条。**先停住，这个直觉是错的，而且错得很彻底。**

**反例 1** 三点 $(3,3),(3,4),(3,5)$（$n=3$，全部在同一竖线上）。不同 $x$ 值只有一个（$x=3$），"两条过点的竖线"根本选不出来；若退而允许 $x_1=x_2$ 就成了线段（不是矩形）。正解是把 $x=3$ 当一条竖边、另一条竖边取任意一条**空的**竖线（$x=4$ 或 $x=2$），高度取满 $[3,5]$，三点全在左边界上 ⇒ 答案 $3$。

**引理 2（夹紧到整数格框）** 对任意允许边坐标为实数、允许退化的矩形区域 $Q=[a,b]\times[c,d]$（$a\le b,\;c\le d$），存在满足
$$1\le x_1<x_2\le100,\qquad 1\le y_1<y_2\le100$$
的整数矩形 $Q'$，使 $\partial Q\cap P\subseteq\partial Q'\cap P$（点集**包含**，不只是数量比较）。因此最优解可以在"四条线都取 $[1,100]$ 内整数"里找。

**证明**（三步，每步都只增加边界点、不减少）：

*（a）取整盒。* 令 $L=\lceil a\rceil,R=\lfloor b\rfloor,B=\lceil c\rceil,T=\lfloor d\rfloor$，整盒 $M=[L,R]\times[B,T]$。**若某维 $L>R$**：任一整点 $p=(u,v)\in Q$ 都要满足 $a\le u\le b$ 且 $u$ 为整数，故 $L\le u\le R$，与 $L>R$ 矛盾 ⇒ $\partial Q\cap\mathbb Z^2=\varnothing$，包含式左边是空集、自动成立，下面只讨论各维都非空的情形。另须说明 $\partial Q=Q\setminus Q^\circ$ 在退化时仍按引理 1 的方式理解：$a=b$（或 $c=d$）时"$a<u<b$"对一切点为假 ⇒ $Q^\circ=\varnothing$ ⇒ $\partial Q=Q$，此时下面"$u=a$ 或 $u=b$"的分支也照样成立（两者同时成立）。设 $p=(u,v)\in\partial Q$ 是整点：$p\in Q$ 给 $u\in[L,R]$, $v\in[B,T]$；$p\notin Q^\circ$ 给 $u=a$ 或 $u=b$ 或 $v=c$ 或 $v=d$（引理 1 证明里的德摩根步骤对实数区间同样成立：$\neg(a<u<b\land c<v<d)\Rightarrow$ 至少一个不成立，而 $\neg(a<u<b)$ 在 $a\le u\le b$ 下给出 $u=a$ 或 $u=b$）。若 $u=a$，因 $u$ 是整数故 $a$ 是整数，$L=\lceil a\rceil=a=u$，于是 $u=L$ ⇒ $p$ 在 $M$ 的左边界上；$u=b$ 同理给 $u=R$；$v=c,v=d$ 同理给 $v=B$ 或 $v=T$。四种情形都说明 $p\in\partial M$。故 $\partial Q\cap\mathbb Z^2\subseteq\partial M\cap\mathbb Z^2$。

*（b）裁进值域。* 令 $L^*=\max(L,1),R^*=\min(R,100),B^*=\max(B,1),T^*=\min(T,100)$，得 $M^*=[L^*,R^*]\times[B^*,T^*]$。若 $L^*>R^*$（或 $B^*>T^*$）：题目点 $p=(u,v)\in Q$ 必须同时满足 $u\in[L,R]$ 与 $u\in[1,100]$（点的坐标由题面保证在 $[1,100]$ 内），即 $u\in[L^*,R^*]=\varnothing$ ⇒ $Q$ 内根本没有题目点，$\partial Q\cap P=\varnothing$，随便取 $Q'=[1,2]\times[1,2]$ 即可，结论成立。否则设 $p=(u,v)\in\partial Q\cap P$：由 (a) $u\in[L,R]$，又 $1\le u\le100$，故 $u\in[L^*,R^*]$，$v$ 同理。若 $p$ 是靠左/右边界（$u=L$ 或 $u=R$）：$u\ge1$ 且 $u=L$ 时 $L^*=L=u$；$u\le100$ 且 $u=R$ 时 $R^*=R=u$ ⇒ $u\in\{L^*,R^*\}$ ⇒ $p\in\partial M^*$。$v$ 的两个情形同理。所以 $\partial Q\cap P\subseteq\partial M^*\cap P$。

*（c）把退化撑开。* 若 $L^*<R^*$ 且 $B^*<T^*$，$Q'=M^*$ 完成。否则：
 - $L^*=R^*=u_0$ 且 $B^*<T^*$（竖线段 $\{u_0\}\times[B^*,T^*]$）：取 $u_2=u_0+1$（若 $u_0<100$）或 $u_2=u_0-1$（若 $u_0=100$）。$u_2\ne u_0$ 一定存在，因为值域 $[1,100]$ 含 $100\ge2$ 个数。令 $Q'=[\min(u_0,u_2),\max(u_0,u_2)]\times[B^*,T^*]$，则线段 $\{u_0\}\times[B^*,T^*]$ 恰是 $Q'$ 的左边界（$u_2=u_0+1$ 时）或右边界（$u_2=u_0-1$ 时）⇒ 点一个不丢。
 - $B^*=T^*=v_0$ 且 $L^*<R^*$（横线段）：完全对称，把 $v_0$ 撑成 $[v_0,v_0\pm1]$（$v_0<100$ 取 $+1$，$v_0=100$ 取 $-1$，同样靠 $100\ge2$ 保证可行），线段成为新盒的一条横边。
 - $L^*=R^*=u_0$ 且 $B^*=T^*=v_0$（单点）：$Q'=[u_0,u_0\pm1]\times[v_0,v_0\pm1]$，该点成为角 ⇒ 不丢（此时 $\partial Q\cap P$ 只可能落在 $M^*$ 这一个格点上）。
 三种撑开都保持 $Q'\subseteq[1,100]^2$ 且 $x_1<x_2,y_1<y_2$。$\blacksquare$

> 反例 1 正是引理 2 的 (c) 步：允许"空边"不是权宜，而是**必须**——所以候选线只能取满值域 $[1,100]$，不能只取"过点的线"。这也解释了为什么正解的复杂度只跟值域 $V$ 有关、跟 $n$ 无关。

### 2.4 但"过点线"救得回来：加两条边界线就够（$40\%$ 子任务的正解）

引理 2 只告诉我们"整数边够用"，还留了一个可利用的余量：**空边可以一路推到值域端点**。

**推论 1（候选线只有三类）** 存在最优矩形，其每条边的坐标 $\in\{1,\,100\}\cup\{\text{某个点的 }x\text{（或 }y\text{）坐标}\}$。

**证明**：取引理 2 给出的最优整数矩形 $R=[x_1,x_2]\times[y_1,y_2]$。只看左边 $x=x_1$：
- 若它压着至少一个点 $p$，则 $x_1=p_x$，属于第二类 ✔。
- 若它一个点都不压（空边），改 $R'=[1,x_2]\times[y_1,y_2]$。先确认它仍是真矩形：$x_2>x_1\ge1$ 且 $x_2$ 是整数 ⇒ $x_2\ge2>1$ ✔。再证 $\partial R\cap P\subseteq\partial R'\cap P$：取 $q\in\partial R\cap P$，$q$ 不在左边（左边空），故 $q$ 在右边（$q_x=x_2,\;y_1\le q_y\le y_2$）或在上/下边（$q_y\in\{y_1,y_2\},\;x_1<q_x<x_2$）。前者在 $R'$ 里仍是右边 ✔；后者因所有点 $q_x\ge1$，故 $1\le q_x<x_2$，在 $R'$ 里仍属上/下边 ✔。于是 $\mathrm{cnt}(R')\ge\mathrm{cnt}(R)$，而 $R'$ 的左边坐标是 $1$，属第一类 ✔。
右边、下边、上边把上面论证左右/上下镜像即可（右边空 ⇒ 推到 $100$：需 $x_1<100$，由 $x_1<x_2\le100$ 且 $x_1$ 是整数得 $x_1\le99$ ✔）。
**逐步累积的合法性**（不是"显然"，要说清）：依次处理四条边，每次只动一条边、其余三条坐标不变。由上面证到的 $\partial R\cap P\subseteq\partial R'\cap P$，此前已经"落定"的边界点在新矩形里仍是边界点，所以第 $i$ 步不会破坏第 $i-1$ 步的成果；又由上面两条不等式（$1<x_2$ 与 $x_1<100$，纵坐标同理），每一步之后仍有 $x_1<x_2,\;y_1<y_2$，矩形始终非退化。四步之后每条边的坐标都属于 $\{1,100\}\cup\{\text{某个点的坐标}\}$，且计数不减 ⇒ 它仍是最优解 ✔。$\blacksquare$

注意推论 1 还顺带给出一个**尺寸上限**：候选线坐标都在 $[1,100]$ 里，所以候选线数永远 $\le 100$，与 $n$ 无关。

有了推论 1，$n\le30$ 的 $40\%$ 分就有一条完全够用的路：候选竖线取 $\{1,100\}\cup\{p_{i,x}\}$（$\le32$ 条）、候选横线同理，四重循环枚举 $x_1<x_2,\;y_1<y_2$（$\le\binom{32}{2}^2=496^2=246016$ 个矩形），每个矩形把 $n$ 个点按引理 1 的判据（$u\in\{x_1,x_2\}\lor v\in\{y_1,y_2\}$ 再配区间）逐个判定：$246016\times30\approx7.4\times10^6$ 次判定 ✔ 可过。**这比"过点线"版本只多花两条线，却把反例 1 修好了。**

但 $n=300$ 时这条路的瓶颈换了位置：候选线被值域卡在 $100$ 条 ⇒ 矩形数 $\binom{100}{2}^2=2.45\times10^7$，乘上每个矩形 $O(n)=300$ 的逐点判定又是 2.2 里那个 $7.4\times10^9$。⇒ 枚举对象已经对（整条值域），要动的变成**单矩形计数**。这就是下一节的入口。

### 2.5 前缀和：把单个矩形的计数降到 $O(1)$

把 $c$ 存成二维数组 `cnt[x][y]`（重复点靠 `++` 累积），再开两个一维方向的前缀：
$$\mathrm{rg}[x][y]=\sum_{t=1}^{y}c(x,t)\quad(\text{第 }x\text{ 行前缀}),\qquad
\mathrm{cg}[x][y]=\sum_{t=1}^{x}c(t,y)\quad(\text{第 }y\text{ 列前缀}).$$
对固定的竖线对 $(x_1,x_2)$ 记
$$g(y)=c(x_1,y)+c(x_2,y),\qquad G(y)=\mathrm{rg}[x_1][y]+\mathrm{rg}[x_2][y]=\sum_{t=1}^{y}g(t),$$
$$f(y)=\sum_{x=x_1+1}^{x_2-1}c(x,y)=\mathrm{cg}[x_2-1][y]-\mathrm{cg}[x_1][y].$$

**引理 3（用 $f,G$ 重写边界计数）** $x_1<x_2,\;y_1<y_2$ 时
$$\mathrm{cnt}(x_1,x_2,y_1,y_2)=\big(G(y_2)-G(y_1-1)\big)+f(y_1)+f(y_2),$$
并约定 $G(0)=0$（$y_1=1$ 时右端第二项求和为空）。

**证明**：由引理 1 的不交划分，竖块贡献 $\sum_{y=y_1}^{y_2}(c(x_1,y)+c(x_2,y))=\sum_{y=y_1}^{y_2}g(y)=G(y_2)-G(y_1-1)$（前缀和的差分恒等式，$\sum_{y=y_1}^{y_2}g(y)=\sum_{t=1}^{y_2}g(t)-\sum_{t=1}^{y_1-1}g(t)$，逐项相减即得，且 $y_1=1$ 时第二式为空前缀 $=0=G(0)$）。横块贡献 $\sum_{x=x_1+1}^{x_2-1}(c(x,y_1)+c(x,y_2))$；因为 $y_1<y_2$ 两个指标不同，可拆成两个和式 $f(y_1)+f(y_2)$（有限和可按第二指标的取值分组）。两式相加即得。$\blacksquare$

这一步已经把复杂度做到 $O(V^4)=2.45\times10^7$：四重循环、每步两次 $O(1)$ 查表。这是可以过的第一版正解，也是后面所有优化的**参照物**。

### 2.6 关键一跳：固定竖线对后，目标对 $y_1,y_2$ **可分**

把引理 3 的右端重组：
$$\big(G(y_2)-G(y_1-1)\big)+f(y_1)+f(y_2)=\underbrace{\big(f(y_1)-G(y_1-1)\big)}_{A(y_1)}+\underbrace{\big(f(y_2)+G(y_2)\big)}_{B(y_2)} .$$

**引理 4（可分性）** 固定 $(x_1,x_2)$ 后，$\mathrm{cnt}(x_1,x_2,y_1,y_2)=A(y_1)+B(y_2)$，其中 $A,B$ 只依赖各自的指标。

**证明**：纯代数移项——$-G(y_1-1)$ 归给 $A$、$+G(y_2)$ 归给 $B$，$f$ 项天然分属两端，和不变。注意 $A$ 里**不含** $y_2$、$B$ 里**不含** $y_1$，这才是"可分"的含义（对比：若横块写成 $f(y_1)+f(y_2)+G(y_2)-G(y_1-1)$ 之外的交叉项如 $G(y_2-y_1)$ 就不能分）。$\blacksquare$

**引理 5（顺序约束下的前缀最优）** 设 $A,B$ 是 $[1,V]$ 上任意整数函数，则
$$\max_{1\le y_1<y_2\le V}\big(A(y_1)+B(y_2)\big)=\max_{y_2=2}^{V}\Big(B(y_2)+\max_{1\le y_1\le y_2-1}A(y_1)\Big),$$
且内层 $\max_{y_1\le y_2-1}A(y_1)$ 可由 $y_2$ 从小到大扫描增量维护（每步只需并入新候选 $y_1=y_2-1$）。

**证明**：右边的集合 $\{(y_1,y_2):y_1<y_2\}$ 按 $y_2$ 分组是不交并：$\bigsqcup_{y_2=2}^{V}\{y_1:1\le y_1\le y_2-1\}\times\{y_2\}$。对固定的 $y_2$，$B(y_2)$ 是常数，故 $\max_{y_1<y_2}(A(y_1)+B(y_2))=B(y_2)+\max_{y_1<y_2}A(y_1)$（$y_2\ge2$ 保证内层集合非空，最大值存在）。再对各组取最大即得整体最大。增量维护的正确性：记 $M_k=\max_{1\le y_1\le k}A(y_1)$，则 $M_k=\max(M_{k-1},A(k))$、$M_1=A(1)$，扫描时"先并入 $y_1=y_2-1$ 再算 $y_2$"恰好给出 $M_{y_2-1}=\max_{y_1<y_2}A(y_1)$。$\blacksquare$

> 结构上它就是"低买高卖"：$A(y_1)$ 是买入收益、$B(y_2)$ 是卖出收益，$y_1<y_2$ 是顺序约束，一个前缀最大值搞定。于是
> $$O(V^4)\;\longrightarrow\;O(V^3),\qquad 2.45\times10^7\to 4.9\times10^5\ \text{次 }O(1)\text{ 更新}.$$

> 对称性交代：本题 $x,y$ 值域同为 $V=100$，所以"固定两条竖线、扫描两条横线"与反过来做完全等价。一般矩形值域为 $V_x\times V_y$ 时，本算法是 $O(V_x^2V_y)$（枚举线对的那一维被平方），因此**应当把被平方的一维选成较小的值域**，取 $\min(V_x^2V_y,\;V_y^2V_x)$；写成代码时只要把 `x/y` 换个角色即可，证明一字不改。

### 2.7 精度与溢出预算：本题可以零误差

**(a) 为什么完全不需要 `eps`。** 所有几何判断都是"整数是否等于另一整数"或"整数是否落在整数闭区间里"（引理 1/2 的划分与夹紧、$f,G$ 的查表），**无除法、无开方、无浮点**，因此与理想实数模型逐位一致。**注意引理 2 的 $\lceil a\rceil,\lfloor b\rfloor$ 只出现在证明里**，代码从不计算取整——代码直接枚举 $[1,100]$ 的整数四元组，取整的存在性由引理 2 保证，这是"证明里用实数、实现里用整数"的标准套路。反面对照：若题目改成**斜放**矩形，边界归属就得写叉积 $\mathrm{cross}=(x_b-x_a)(y_c-y_a)-(y_b-y_a)(x_c-x_a)$（纯整数、仍零误差）与平方量比长度（避免 `sqrt`）；本题因边平行坐标轴，叉积退化成坐标区间比较，所以更简单。

**(b) 溢出预算（将坐标上界代入）。** 记值域上界 $V=100$、点数 $n\le300$。
- `cnt` $\le n=300$；`rg`,`cg` 是计数前缀和，$\le n=300$；$f,G,A,B$ 都是"若干互不重叠的格点上点数之和"或其差，$|A(y)|,|B(y)|\le 2n=600$（$A=f-G_{\text{prev}}$ 两项各自 $\le n$ 且符号相反时绝对值 $\le n$，放宽记 $\le 2n$）。
- 关键：**最终每次相加都是某个真实矩形的边界点数**，$A(y_1)+B(y_2)=\mathrm{cnt}(\cdot)\in[0,n]=[0,300]$（引理 3/4），所以不存在"中间量比结果大得多"的经典溢出隐患。
- `int` 上限 $2^{31}-1=2\,147\,483\,647$，相对 $2n=600$ 余量约 $3.6\times10^6$ 倍；哨兵参与运算时 $-1145141919+600=-1145141319>-2^{31}=-2147483648$，**不下溢**（本题哨兵实际不会参与加法，见 4.2 步骤 4）。⇒ 全程 `int`，不需要 `using i64=long long;`，也无 `1LL*` 提升需求（**本题完全没有乘法**）。
- 换档规则（诚实外推，非本题需求）。本题**只有加减与 `max`**，所以风险只来自"计数上界"：一般地 $2n\le2^{31}-1$ 即 $n\le1.07\times10^9$ 时 `int` 仍安全，再大就上 `i64`。
  作为对照，若把题目改成**斜放**矩形、边界归属要用叉积 $\mathrm{cross}(U,W)=U_xW_y-U_yW_x$ 或比长度要用平方量，就得按坐标上界 $M$ 预算：$|\Delta x|,|\Delta y|\le2M$，故 $|\mathrm{cross}|\le2(2M)^2=8M^2$、$|\vec{UV}|^2\le2(2M)^2=8M^2$（两者同一个界）。$8M^2\le2^{31}-1\Rightarrow M\le16383$（$M=2^{14}=16384$ 恰好越界）；$8M^2\le2^{63}-1\Rightarrow M\le\sqrt{(2^{63}-1)/8}\approx1.07\times10^9$（$M=2^{30}$ 恰好越界）；$M\ge10^{10}$ 才需要 `__int128`。本题 $M=100$ 时 $8M^2=8\times10^4$，即使真写叉积也离 `int` 上限差 $2.7\times10^4$ 倍——**但本题不需要叉积**，见 (a)：边平行坐标轴使"点是否在该边上"退化为两次整数等式 + 一次整数区间包含，比叉积更省且同样零误差。

**(c) 数组与内存预算。** 三张 `int cnt/rg/cg [105][105]` $\approx 3\times 11025\times4\,\mathrm{B}\approx 132\,\mathrm{KB}$，远低于常见 $128\,\mathrm{MB}$。

### 2.8 边界情况清单（逐条都有出处）

1. 重复点同坐标 ⇒ `cnt++` 而非赋值（题面未禁止）；引理 1 的划分对多重集同样成立（每个点是独立个体，同坐标不合并）。
2. 三点共线/全部共线 ⇒ 必须允许**空边**（反例 1，引理 2(c)）。
3. 只有 $1$ 个点 ⇒ 取把它当角的 $[x,x\pm1]\times[y,y\pm1]$，答案 $1$（引理 2(c) 第三分支；4.3 例 1）。
4. 点贴在值域边缘（$x=100$ 或 $y=1$）⇒ 撑开方向要翻向内侧（引理 2(c) 的 $u_0=100$ 分支；4.3 例 6）。
5. 矩形内部有点 ⇒ 不计（引理 1 的 $Q\setminus Q^\circ$；4.3 例 2/例 7）。
6. $x_2=x_1+1$（相邻竖线）⇒ $f\equiv0$、第二求和为空，公式仍成立（引理 3 证明里"$y_1=1$ 空前缀 $=0$"的同一论证）。
7. 强制 $x_1<x_2,y_1<y_2$ 不使答案变小 ⇒ 引理 6。

**引理 6（非退化要求不损失最优值）** 设 $V\ge2$。允许退化矩形（$x_1\le x_2,\;y_1\le y_2$）时的最大边界点数 $=$ 要求非退化时的最大值。

**证明**：记允许退化时的最大值为 $D$、强制非退化时为 $N$，证两头。
- $D\ge N$：任何满足 $x_1<x_2,\;y_1<y_2$ 的矩形同时满足 $x_1\le x_2,\;y_1\le y_2$，即"非退化可行集 $\subseteq$ 退化可行集"，在更大的集合上取最大值不可能更小。
- $D\le N$：取达到 $D$ 的退化整数盒 $Q=[u_1,u_2]\times[v_1,v_2]$（坐标都是 $[1,100]$ 内整数）。先说清它的边界是什么：引理 1 证明里的内部条件"$u_1<u<u_2$"在 $u_1=u_2$（或 $v_1=v_2$）时**对任何点都不成立**，所以 $Q^\circ=\varnothing$，$\partial Q=Q\setminus Q^\circ=Q$ 就是那个线段/单点本身。分情形：
  (i) $u_1<u_2$ 且 $v_1<v_2$：本就非退化，$N\ge D$ 与上一条合并即等号。
  (ii) $u_1=u_2=u_0$、$v_1<v_2$（竖线段）：值域宽 $100\ge2$ ⇒ $u_0<100$ 时可取 $u_2'=u_0+1$，否则 $u_0=100$ 取 $u_2'=99$；令 $Q'=[\min(u_0,u_2'),\max(u_0,u_2')]\times[v_1,v_2]$，它是非退化整数盒，且 $\{u_0\}\times[v_1,v_2]$ 恰是 $Q'$ 的一条竖边 ⇒ $\partial Q\cap P\subseteq\partial Q'\cap P$ ⇒ $N\ge\mathrm{cnt}(Q')\ge\mathrm{cnt}(Q)=D$。
  (iii) $v_1=v_2=v_0$、$u_1<u_2$（横线段）：(ii) 的字母改名，把 $v_0$ 撑成 $[v_0,v_0\pm1]$，线段成为一条横边。
  (iv) $u_1=u_2,\;v_1=v_2$（单点盒）：两个方向同时撑开，该点成为 $Q'$ 的角 ⇒ $\partial Q\cap P=\varnothing$ 或 $\{p:\text{该坐标的点}\}\subseteq\partial Q'\cap P$，同上。
  四种情形都造出非退化整数 $Q'$ 使 $\mathrm{cnt}(Q')\ge D$ ⇒ $N\ge D$。
综上 $N=D$，即"要求面积严格正"不会让答案变小；代码只枚举 $x_1<x_2,\;y_1<y_2$ 是安全的。$\blacksquare$

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 先把"边界上"压成不重不漏的两块：竖边闭段 + 横边去角（引理 1），角只算一次由划分保证。
- **cost of the naive brute** — 候选矩形只有 $\binom{V}{2}^2$ 个，瓶颈在每个矩形的 $O(n)$ 判定；值域 $V=100\ll n$ 是"按值域枚举"的信号。
- **dissect the failure of a greedy** — 用三点共线反例打穿"每条边都过点"的直觉 ⇒ 空边必须允许 ⇒ 枚举对象是整条值域，不是过点线（引理 2 的 (c) 步）。
- **prove the search space is enough** — 夹紧引理：取整盒 $\to$ 裁进 $[1,100]$ $\to$ 撑开退化，三步都只增不减，所以整数四元组枚举**完备**（引理 2）。
- **salvage the compressed candidate set (subtask)** — 推论 1：空边可外推到 $1/100$ ⇒ 候选线缩到 $\{1,100\}\cup\{\text{点坐标}\}$，$n\le30$ 时 $7.4\times10^6$ 过 $40\%$；$n=300$ 时逐点判定仍要 $7.4\times10^9$ ⇒ 换攻"单矩形成本"。
- **classic problem solution（前缀和）** — 行前缀 `rg` + 列前缀 `cg`，把单矩形计数降到 $O(1)$，得 $O(V^4)=2.45\times10^7$ 的第一版（引理 3）。
- **reduce to easier problem（分离变量）** — 固定竖线对后目标变成 $A(y_1)+B(y_2)$，二维枚举塌成一维（引理 4）。
- **classic problem solution（前缀最优/"低买高卖"）** — 顺序约束 $y_1<y_2$ 下用扫描 + `best` 增量，$O(V^4)\to O(V^3)$（引理 5）。
- **numeric / overflow budget** — 全整数、无乘法、无 `eps`；把 $V=100,n=300$ 代进 $|A|,|B|\le2n=600$，`int` 余量 $3.6\times10^6$ 倍，哨兵 $-1145141919$ 不溢。

## 4. 真实解法（Real Solution）

### 4.1 符号表（Notation Glossary）

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `V{100}`, `mxv{V+5}` | 坐标值域上界、数组尺寸（+5 松弛，同时给下标 $0$ 留位） | `constexpr int` | 值域比 $n$ 小 ⇒ 枚举值域 |
| `n` | 点数 | `int` | 只在读入时用 |
| `cnt[mxv][mxv]` | $c(x,y)$：坐标 $(x,y)$ 上的点数（重复点累加） | 全局 `int`，读入 `++cnt[x][y]` | **不是** bool，别写成 `=1` |
| `rg[mxv][mxv]` | $\mathrm{rg}[x][y]=\sum_{t\le y}c(x,t)$：第 $x$ 行沿 $y$ 的前缀 | 全局，递推 `rg[x][y]=rg[x][y-1]+cnt[x][y]` | "row group"，**行**前缀 ⇒ 处理**竖边** |
| `cg[mxv][mxv]` | $\mathrm{cg}[x][y]=\sum_{t\le x}c(t,y)$：第 $y$ 列沿 $x$ 的前缀 | 全局，递推 `cg[x][y]=cg[x-1][y]+cnt[x][y]` | "column group"，**列**前缀 ⇒ 处理**横边** |
| `cside(x1,x2,y)` | $G(y)=\mathrm{rg}[x_1][y]+\mathrm{rg}[x_2][y]$：两条竖边上"行号 $\le y$"的点数 | `int` 函数 | $G(0)=0$ 由全局零初始化给出（坑自查见 5） |
| `cmid(x1,x2,y)` | $f(y)=\mathrm{cg}[x_2-1][y]-\mathrm{cg}[x_1][y]$：两条竖线**之间**（开）第 $y$ 行的点数 | `int` 函数 | 减到 $x_1$ 不含 ⇒ 恰好 $x_1+1..x_2-1$ |
| `best` | 当前竖线对下 $\max_{y_1<y_2}A(y_1)=\max_{y_1<y_2}\big(f(y_1)-G(y_1-1)\big)$ | `int`，每个 $(x_1,x_2)$ 重置为 `-1145141919` | 前缀最大值，"低买" |
| `ans` | 全局最大边界点数 | `int`，$0$ 起步（计数非负 + 候选非空，见 4.2 步 5） | 输出即答案 |

### 4.2 算法步骤

1. **读入** $n$ 与 $n$ 个点，`++cnt[x][y]`（坐标原样作下标；见下面"下标约定"）。
2. **建两张前缀**：按行、列各做一次递推，$O(V^2)$。约定下标 $0$ 的整行/整列为 $0$（全局数组天然为 $0$），于是 $G(y_1-1)$ 在 $y_1=1$ 时自动是 $0$，与引理 3 的约定一致。
3. **枚举竖线对** $1\le x_1<x_2\le V$（$\binom{V}{2}=4950$ 对）。每对重置 `best` 为哨兵。
4. **按 $y_2=2..V$ 扫描**：先并入新候选 $y_1=y_2-1$，即 `best=max(best,cmid(x1,x2,y2-1)-cside(x1,x2,y2-2))`（引理 5 的 $M_k$ 递推；哨兵在此立刻被真实值覆盖，**不参与**后续加法），再 `ans=max(ans,best+cmid(x1,x2,y2)+cside(x1,x2,y2))`，它就是引理 4 的 $A(y_1)+B(y_2)$ 在 $y_1<y_2$ 下的最优。
5. **输出** `ans`。非空性：$V=100\ge2$ ⇒ 至少存在一个整数矩形（如 $[1,2]\times[1,2]$），且计数恒 $\ge0$ ⇒ `ans` 从 $0$ 起步是合法下界（不是"未初始化 0 被当答案"的陷阱；需要哨兵语义的只有 `best`，已按 4 显式重置）。

**复杂度**：时间 $O(n+V^2+V^3)$，$V=100$ 时内层更新约 $4950\times99\approx4.9\times10^5$ 次、每次 $O(1)$；空间 $O(V^2)$。这是**理论计数**，非实测（本环境未运行任何代码，见 4.3）。

**手算要用的上界事实（引理 1 的直接推论，用来证明"不可能更多"）** 若 $\partial R\supseteq S$，则因 $\partial R\subseteq R$ 有 $R\supseteq S$，故
$$x_1\le\min_{p\in S}p_x,\quad x_2\ge\max_{p\in S}p_x,\quad y_1\le\min_{p\in S}p_y,\quad y_2\ge\max_{p\in S}p_y .$$
于是若某 $q\in S$ 满足"存在 $p_1,p_3\in S$ 使 $p_{1,x}<q_x$ 且 $p_{3,y}<q_y$，并存在 $p_2,p_4\in S$ 使 $q_x<p_{2,x}$ 且 $q_y<p_{4,y}$"，则 $x_1\le p_{1,x}<q_x<p_{2,x}\le x_2$ 且 $y_1\le p_{3,y}<q_y<p_{4,y}\le y_2$，由引理 1 它既不在竖块（$q_x\notin\{x_1,x_2\}$）也不在横块（$q_y\notin\{y_1,y_2\}$）⇒ $q$ 是严格内点、**上不了边界**；想让它上边界就必须把某条边内收到它之外，从而放弃一整行或一整列的点。下面例 2、例 7 用它卡上界。

**例 1（$n=1$，$(5,5)$ → 期望 $1$）**
`cnt[5][5]=1`，$\mathrm{rg}[5][y]=1\,(y\ge5)$、其余行为 $0$；$\mathrm{cg}[x][5]=1\,(x\ge5)$。
走 $(x_1,x_2)=(5,6)$：$f(y)=\mathrm{cg}[5][y]-\mathrm{cg}[5][y]=0$（相邻竖线，中间列为空 ⇒ 引理 3 的空和）；$G(y)=\mathrm{rg}[5][y]+\mathrm{rg}[6][y]$，$G(4)=0,G(5)=1,G(6)=1$。
$y_2=6$ 时 best $=\max_{y_1\le5}\big(f(y_1)-G(y_1-1)\big)\ge f(5)-G(4)=0-0=0$，$B(6)=f(6)+G(6)=0+1=1$ ⇒ 候选值 $0+1=1$ ⇒ `ans` $\ge1$ ✔。
按定义复核：矩形 $[5,6]\times[5,6]$ 的左下角恰是 $(5,5)$ ⇒ 边界上 $1$ 个点 ✔；点总共只有 $1$ 个 ⇒ 上界也是 $1$ ⇒ 答案 $=1$ ✔。

**例 2（四点成方 + 中心点 → 期望 $4$，检验"内部的点不计"）**
点 $(1,1),(3,1),(1,3),(3,3)$ 与 $(2,2)$，$n=5$。
$(x_1,x_2)=(1,3)$：$f(y)=\mathrm{cg}[2][y]-\mathrm{cg}[1][y]=c(2,y)$ ⇒ $f(1)=0,f(2)=1,f(3)=0$。
$G(y)=\mathrm{rg}[1][y]+\mathrm{rg}[3][y]$：第 $1$ 行有 $(1,1),(1,3)$ ⇒ $\mathrm{rg}[1][1]=1,\mathrm{rg}[1][2]=1,\mathrm{rg}[1][3]=2$，第 $3$ 行同理 ⇒ $G(1)=2,G(2)=2,G(3)=4,G(0)=0$。
逐步扫描（引理 5 的"先并入 $y_1=y_2-1$，再算 $y_2$"）：
- $y_2=2$：并入 $y_1=1$，$A(1)=f(1)-G(0)=0-0=0$ ⇒ best$=0$；$B(2)=f(2)+G(2)=1+2=3$ ⇒ 值 $3$。定义复核 $[1,3]\times[1,2]$：竖块 $x=1$（行 $1..2$）给 $(1,1)$、$x=3$ 给 $(3,1)$，横块中间列 $x=2$ 在 $y=1$ 为 $0$、在 $y=2$ 给 $(2,2)$ ⇒ $3$ ✔ 一致。
- $y_2=3$：并入 $y_1=2$，$A(2)=f(2)-G(1)=1-2=-1$ ⇒ best 仍 $0$；$B(3)=f(3)+G(3)=0+4=4$ ⇒ 值 $4$。定义复核 $[1,3]\times[1,3]$：四个角在竖块里各计一次（横块排除了 $x=1,3$ ⇒ 不重计）⇒ $4$ ✔。
- 若硬要让 $(2,2)$ 上边界：$[1,3]\times[2,3]$ 得 $A(2)+B(3)=-1+4=3$ ✔（两角 + 中心），与手数 $3$ 一致。
上界 $4$（反证）：若答案 $\ge5$，而总共只有 $5$ 个点，就必须五个点**全**在边界上，即 $\partial R\supseteq S$。把"上界事实"用 $q=(2,2)$、$p_1=(1,3),p_2=(3,3)$（给 $1=p_{1,x}<q_x=2<3=p_{2,x}$）、$p_3=(3,1),p_4=(3,3)$（给 $1=p_{3,y}<q_y=2<3=p_{4,y}$）代进去，四个不等式全部成立 ⇒ $q$ 是 $R$ 的严格内点、不可能属于 $\partial R$，矛盾 ⇒ 达不到 $5$。$4$ 已由代码路径取得，∴ 答案 $=4$ ✔。

**例 3（水平共线四点 → 期望 $4$，检验"空横边"合法）**
点 $(1,1),(2,1),(3,1),(4,1)$。
$(x_1,x_2)=(1,4)$：$f(y)=\mathrm{cg}[3][y]-\mathrm{cg}[1][y]=c(2,y)+c(3,y)$ ⇒ $f(1)=2$，$f(y\ge2)=0$。$G(y)=\mathrm{rg}[1][y]+\mathrm{rg}[4][y]$ ⇒ $G(0)=0$，$G(1)=2$，$G(y\ge1)=2$。
$y_2=2$：并入 $y_1=1$，$A(1)=f(1)-G(0)=2-0=2$ ⇒ best$=2$；$B(2)=f(2)+G(2)=0+2=2$ ⇒ 值 $4$ ✔。
定义复核 $[1,4]\times[1,2]$：$(1,1),(4,1)$ 属竖块、$(2,1),(3,1)$ 属横块中间列 $x=2,3$ 在 $y=1$ 上 ⇒ $4$；上边 $y=2$ 是**空边**，一个点也不压 ✔。⇒ 答案 $4=n$（共线也能全收，只要允许空边）。

**例 4（重复点 → 期望 $3$，检验 `cnt++` 而非 `=1`）**
点 $(2,2),(2,2),(9,9)$，$n=3$。$\mathrm{cnt}[2][2]=2$、$\mathrm{cnt}[9][9]=1$。
$(x_1,x_2)=(2,9)$：$f(y)=\mathrm{cg}[8][y]-\mathrm{cg}[2][y]=0$（第 $3..8$ 列无点）。$G(y)=\mathrm{rg}[2][y]+\mathrm{rg}[9][y]$：$\mathrm{rg}[2][1]=0,\mathrm{rg}[2][2]=2,\mathrm{rg}[9][2]=0$ ⇒ $G(1)=0,G(2)=2$；$\mathrm{rg}[9][9]=1$ ⇒ $G(9)=2+1=3$。
$A(1)=f(1)-G(0)=0$ ⇒ best$\ge0$；到 $y_2=9$：$B(9)=f(9)+G(9)=0+3=3$ ⇒ 值 $3$ ✔。
定义复核 $[2,9]\times[1,9]$：左竖边 $x=2$、行 $1..9$ 上压着**同一坐标的两个点**（引理 1 的划分按"点"分而非按"坐标"分，故各计 $1$ 次）$=2$，右竖边 $(9,9)=1$ ⇒ $3$ ✔ ⇒ 答案 $3=n$ ✔。

**例 5（竖直共线三点 = 反例 1 → 期望 $3$，专门检验"必须允许空边"）**
点 $(3,3),(3,4),(3,5)$。
$(x_1,x_2)=(3,4)$：$f(y)=\mathrm{cg}[3][y]-\mathrm{cg}[3][y]=0$（$x_2-1=x_1$ ⇒ 空前缀相减，恒 $0$ ✔）。$G(y)=\mathrm{rg}[3][y]+\mathrm{rg}[4][y]$，$\mathrm{rg}[4]\equiv0$，$\mathrm{rg}[3][2]=0,\mathrm{rg}[3][3]=1,\mathrm{rg}[3][4]=2,\mathrm{rg}[3][5]=3$ ⇒ $G(2)=0,G(3)=1,G(5)=3$。
$A(3)=f(3)-G(2)=0-0=0$；$B(5)=f(5)+G(5)=0+3=3$ ⇒ 值 $3$ ✔。
定义复核 $[3,4]\times[3,5]$：左竖边 $x=3$ 行 $3,4,5$ 收齐 $3$ 个点，**右竖边 $x=4$ 是空边** ⇒ $3=n$ ✔。
**反面验证（说明"只枚举过点线"为什么必错）**：若候选竖线只允许取点的 $x$ 值，集合是 $\{3\}$，$\binom{1}{2}=0$ ⇒ 一个合法矩形都凑不出，程序要么输出 $0$ 要么越界；按推论 1 补上 $\{1,100\}$ 后候选变成 $\{1,3,100\}$，取 $[1,3]\times[3,5]$（左空右满）同样得 $3$ ✔ —— 与代码同值。⇒ 这个例子既证明"空边必需"，也证明"补两条边界线"确实修好了直觉版暴力。

**例 6（点贴在值域边缘 $x=100,y=100$ → 期望 $3$，检查最大下标与 $x_2-1$）**
点 $(100,1),(100,100),(50,100)$。
$(x_1,x_2)=(50,100)$：$f(y)=\mathrm{cg}[99][y]-\mathrm{cg}[50][y]$。$y=1$：$\mathrm{cg}[99][1]=0$、$\mathrm{cg}[50][1]=0$ ⇒ $f(1)=0$；$y=100$：$\mathrm{cg}[99][100]=1$（第 $50$ 列那个点被 $\le 99$ 收到）、$\mathrm{cg}[50][100]=1$ ⇒ $f(100)=0$ ✔（第 $51..99$ 列确实无点，减到 $x_1=50$ 正好把它排掉）。
$G(y)=\mathrm{rg}[50][y]+\mathrm{rg}[100][y]$：$G(0)=0$；$G(1)=0+1=1$（$\mathrm{rg}[100][1]=1$ 即 $(100,1)$）；$G(100)=1+2=3$（$\mathrm{rg}[50][100]=1$ 即 $(50,100)$，$\mathrm{rg}[100][100]=2$）。
$A(1)=f(1)-G(0)=0$ ⇒ best$\ge0$；$B(100)=f(100)+G(100)=3$ ⇒ 值 $3$ ✔。
定义复核 $[50,100]\times[1,100]$：左竖边 $(50,100)$ $1$ 个、右竖边 $(100,1),(100,100)$ $2$ 个、中间列 $51..99$ 在 $y=1,100$ 上无点 ⇒ $3=n$ ✔。
**下标自检**：$x_2=100$ 用到 `cg[x2-1]` $=\mathrm{cg}[99]$ ✔，$y_2=100$ 用到 `rg[*][100]` ✔（`mxv=105` 覆盖 $0..104$）；$y_2=2$ 用到 `cside(...,0)` 即 `rg[*][0]`，全局零初始化恰是"空前缀 $G(0)=0$" ✔ —— 这里的 $0$ 是**有语义**的合法值，不是"未初始化被误当成数据"。

**例 7（十字形 $3\times3$ 网格九点 → 期望 $8$，内部点不计 + 卡上界）**
点 $\{1,3,5\}\times\{1,3,5\}$，$n=9$。
$(x_1,x_2)=(1,5)$：$f(y)=\mathrm{cg}[4][y]-\mathrm{cg}[1][y]=c(2,y)+c(3,y)+c(4,y)=c(3,y)$ ⇒ $f(1)=f(3)=f(5)=1$，其余 $0$。
$G(y)=\mathrm{rg}[1][y]+\mathrm{rg}[5][y]$：$\mathrm{rg}[1][1]=1,\mathrm{rg}[1][2]=1,\mathrm{rg}[1][3]=2,\mathrm{rg}[1][4]=2,\mathrm{rg}[1][5]=3$（第 $5$ 行同）⇒ $G(1)=2,G(2)=2,G(3)=4,G(4)=4,G(5)=6$。
$A(y_1)=f(y_1)-G(y_1-1)$：$A(1)=1-0=1$、$A(2)=0-2=-2$、$A(3)=1-2=-1$、$A(4)=0-4=-4$ ⇒ 扫到 $y_2=5$ 时 best$=\max(1,-2,-1,-4)=1$（在 $y_1=1$ 取得，满足 $y_1<y_2$ ✔ 引理 5）。
$B(5)=f(5)+G(5)=1+6=7$ ⇒ 值 $1+7=8$ ✔。
定义复核 $[1,5]\times[1,5]$：竖块 $x=1$ 三行 $3$ 点 $+\;x=5$ 三行 $3$ 点 $=6$；横块中间列 $2,3,4$ 在 $y=1$ 有 $(3,1)$、在 $y=5$ 有 $(3,5)$ $=2$ ⇒ 共 $8$，中心 $(3,3)$ 落在 $Q^\circ$ 不计 ✔。
上界 $8$（反证 + 更 sharp 的一半）：要超过 $8$ 就必须达到 $9$，即九个点全在边界上。把"上界事实"用 $q=(3,3)$、$p_1=(1,1),p_2=(5,5)$（$1<3<5$ 给 $x$）、$p_3=(1,1),p_4=(5,5)$（$1<3<5$ 给 $y$）代入 ⇒ $q$ 只能是严格内点，矛盾，故 $\le9-1=8$ ✔。顺带把"想让 $q$ 上边界"这一支也堵死：若 $(3,3)\in\partial R$，则 $3\in\{x_1,x_2\}$ 或 $3\in\{y_1,y_2\}$。设 $x_1=3$，则 $x=1$ 那一列的三个点满足 $u<x_1$ ⇒ 全在 $R$ 外 ⇒ 至多 $6$ 个；$x_2=3,y_1=3,y_2=3$ 三种同理（各丢掉一整列/一整行）⇒ 这一支最好情况也只有 $6<8$。∴ 答案 $=8$ ✔。

**例 8（算术 / 哨兵 / 极端分布自检，不对应输出值）**
- **不溢出**：单次 `ans=max(ans,best+cmid+cside)` 里的和恰等于某个真实矩形的边界点数（引理 3、4），故 $\in[0,n]=[0,300]$；即使放宽到 $|A|+|B|\le 3n=900$，与 `int` 上限 $2^{31}-1$ 相差 $2.4\times10^{6}$ 倍 ✔。
- **哨兵不污染**：`best` 初值 $-1145141919$ 在内层 $y_2=2$ 的第一件事就是被 $\max$ 覆盖成真实值 $A(1)=f(1)-G(0)\ge -n\ge -300$，因此从不与 $B$ 相加；即使相加，$-1145141919+900=-1145141019>-2^{31}=-2147483648$ ⇒ 不下溢 ✔。
- **极端分布**：$n=300$ 全部挤在同一坐标 $(5,5)$ ⇒ $\mathrm{cnt}[5][5]=300$，$G$ 至多 $300$、$f=0$，矩形 $[5,6]\times[5,6]$ 以该坐标为角 ⇒ 答案 $300$ ✔（验证"重复点全收"）。
- **候选非空**：$V=100\ge2$ ⇒ 至少存在 $(x_1,x_2)=(1,2),(y_1,y_2)=(1,2)$，故 `ans` 从 $0$ 起步取 $\max$ 时**一定**会被非负真实值更新，不存在"输出未参与运算的 $0$"的空集风险 ✔。
- **理论运算量**（只是计数，不是实测）：$\binom{100}{2}=4950$ 对竖线 $\times\,99$ 步扫描 $\times\,O(1)$ 查表与两次 $\max$ $\approx 2.4\times10^{6}$ 次基本操作；外加读入 $O(n)$ 与前缀 $O(V^2)=10^4$。

**与 $O(V^4)$ 第一版的交叉核对（同样是手算，非运行）**：例 2、例 6、例 7 三个数据里，把 $A(y_1)+B(y_2)$ 直接展开成 $\sum_{y=y_1}^{y_2}g(y)+f(y_1)+f(y_2)$ 与"逐点判 $u\in\{x_1,x_2\}\lor v\in\{y_1,y_2\}$"三种写法各算一遍，结果分别都是 $4/3/8$ ✔ —— 说明引理 3 的公式与引理 4 的重组没有引入偏差（这一核对不依赖任何程序执行）。

## 5. 示例代码（C++）

```cpp
// P1369 矩形
// 枚举整数边 x1<x2, y1<y2（引理 2 保证完备）；行前缀 cside + 列前缀 cmid 做 O(1) 计数（引理 3）
// 固定竖线对后 cnt = A(y1)+B(y2) 可分（引理 4），前缀最优扫描 O(V^3)（引理 5）
#include<bits/stdc++.h>
using namespace std;

constexpr int V{100};          //坐标值域上界
constexpr int mxv{V+5};        //+5 松弛，下标 0 留给空前缀

int n,cnt[mxv][mxv],rg[mxv][mxv],cg[mxv][mxv];

//G(y)=rg[x1][y]+rg[x2][y]：两竖边上"行号<=y"的点数
int cside(int x1,int x2,int y){return rg[x1][y]+rg[x2][y];}
//f(y)=cg[x2-1][y]-cg[x1][y]：两竖线之间(开)第 y 行的点数
int cmid(int x1,int x2,int y){return cg[x2-1][y]-cg[x1][y];}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0,x,y;i<n;++i)
	{
		cin>>x>>y;
		++cnt[x][y];              //允许重复点：累加而非赋值
	}
	for(int x=1;x<=V;++x)
		for(int y=1;y<=V;++y)
		{
			rg[x][y]=rg[x][y-1]+cnt[x][y];
			cg[x][y]=cg[x-1][y]+cnt[x][y];
		}

	int ans=0;
	for(int x1=1;x1<V;++x1)
		for(int x2=x1+1;x2<=V;++x2)
		{
			int best=-1145141919; //max_{y1<y2}(cmid(y1)-cside(y1-1))，增量维护
			for(int y2=2;y2<=V;++y2)
			{
				best=max(best,cmid(x1,x2,y2-1)-cside(x1,x2,y2-2));
				ans=max(ans,best+cmid(x1,x2,y2)+cside(x1,x2,y2));
			}
		}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **下标约定**（与全文一致）：$x,y$ 维**按题目坐标原样 1-based**（坐标本身就是 $1..100$ 的标签，改成 0-based 反而破坏"值域"这个语义），下标 $0$ 只作**空前缀**使用（`rg[*][0]=cg[0][*]=0`，由全局零初始化保证，见引理 3 约定 $G(0)=0$）；**点的循环** `for(int i=0,x,y;i<n;++i)` 是 0-based。读入的坐标**不做** `--` 转换，输出的是答案数值而非位置，也无需 `+1`。
- **全局静态数组** `int cnt/rg/cg[mxv][mxv]`，`constexpr int mxv{V+5}`；无容器、无 `new`；`'\n'` 换行、无 `endl`；`cin.tie/cout.tie/ios::sync_with_stdio` 固定顺序。
- **移植坑自查**：全局 `int` 默认 $0$。这里 $0$ 有两类用途——(i) `cnt` 的空白格点确实该是 $0$ ✔；(ii) `rg/cg` 的第 $0$ 行/列必须是空前缀 $0$ ✔ 恰好满足；(iii) 唯一需要"不可达 = $-\infty$"语义的 `best` **显式**填了哨兵 `-1145141919`，不依赖默认值 ✔（若漏掉这一步，`best` 会被当成 $0$ 从而低估或错配，属典型陷阱）。
- **类型**：由 2.7(b) 的预算 $|A|,|B|\le2n=600$ 且相加即真实计数 $\le n$，`int` 严格安全，故**不**引入 `using i64=long long;`；本题代码**没有任何乘法**，不需要 `1LL*` 提升。
- **零浮点**：无 `double`、无 `eps`、无取整运算——引理 2 的 $\lceil\cdot\rceil/\lfloor\cdot\rfloor$ 只在证明里出现，代码只枚举整数边（2.7(a)）。
- **验证口径**：结论全部来自 4.3 的 $8$ 组手算（单点 / 方框含中心 / 水平共线 / 重复点 / 竖直共线即反例 1 / 贴值域边缘 / 十字九点 / 算术与哨兵自检），并额外用 $3$ 个例子把 $A(y_1)+B(y_2)$ 与引理 3 的求和式、与逐点判定做过**手算三方交叉核对**；**没有**运行程序、**没有**随机对拍；又因本地题面无样例，**无法**与官方样例对标。
