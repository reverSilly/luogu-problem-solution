## 1. 重新读题

**问题重述（大白话）**

有一个 $m$ 种字符的键盘。随机独立、均匀地按 $n$ 下，得到长度为 $n$ 的串 $S$（一共 $m^n$ 种等可能）。

定义 $\text{dist}(S)=$ $S$ 的**非空本质不同子串**个数（"本质不同" = 长度不同或某个位置字符不同；同一个子串出现多次只算 1 个）。

求

$$E=\frac{1}{m^n}\sum_{S\in[m]^n}\text{dist}(S)\pmod{10^9+7}$$

题面给的例子：`abaa` 的不同子串是 `a`、`b`、`ab`、`ba`、`aa`、`aba`、`baa`、`abaa` 共 8 个，即 $\text{dist}(\texttt{abaa})=8$（后面 2.2 节会看到 $\frac{4\cdot5}{2}=10$ 个出现位置减去 2 次重复）。

**约束与子任务（提示复杂度）**

| 子任务 | 分值 | 范围 | 暗示 |
|---|---|---|---|
| 1 | 10 | $n,m\le7$ | $m^n\le7^7\approx8\times10^5$，可直接枚举所有文章 |
| 2 | 20 | $n\le5$ | $m$ 已经可以到 $5\times10^6$，不能枚举串，只能枚举"结构" |
| 3 | 20 | $n\le10$ | $2^{10}$、$B_{10}=115975$ 级别的枚举可接受 |
| 4 | 50 | $n\le20$，$m\le5\times10^6$ | $B_{20}\approx5.2\times10^{13}$（划分型枚举死路），$2^{20}\approx10^6$（子集型枚举可行） |

**复杂度暗示的读法**

- 子任务 1 → 2 → 3 → 4 是 $n$ 的台阶式增长，而 $m$ 从一开始就"随便多大"：**答案关于 $m$ 只能是 $O(\text{poly}(n))$ 次模运算**（幂、逆元），绝不能出现 $m$ 的多项式级别枚举量。
- $n\le20$ 这个数很关键：它恰好是 $O(n^2 2^n)$ / $O(n 2^n)$ 能过的上限，也是 Bell 数（划分/模式枚举）必然爆炸的下限。⇒ 正确方向应当是**"枚举 $[1,n]$ 的子集 + 容斥"**，而不是枚举串的相等模式。
- 标签里的 NTT（结论前置，完整论证见 2.9）：本解法（2.1–2.8）已被证明在 $n\le20$ 下**覆盖全部子任务（满分）**，推导全程不出现卷积；并且 $10^9+7$ 满足 $v_2(p-1)=1$（$p-1=2\times500000003$，$500000003$ 为奇数），长度 $\ge4$ 的数论变换**就地根本做不了**——"标签 ⇒ 官方解法必须含就地 NTT"在该数据范围下被直接排除。NTT 唯一合理的来源（更大 $n$ 的簇生成函数推广）在 2.9 给出判定与验证路径。

## 2. 思维链（Chain-of-thought）

### 2.1 第一步：期望能不能拆开？（线性性）

最直接的写法是

$$E=\frac1{m^n}\sum_{s:\,1\le|s|\le n}\#\{S\in[m]^n: s \text{ 是 } S \text{ 的子串}\}$$

即"对每个候选内容串 $s$ 数它出现在多少篇文章里"。候选串有 $m+m^2+\cdots+m^n$ 个，$m=5\times10^6$ 时完全不可能枚举。**此路先记下，不急着放弃**：它的问题在于把"出现次数"这种全局性质压在了一个具体串上。

自然的替换：把求和顺序换回来——不要"对每个内容数它出现在哪些串"，而是"对每个串/每个位置，数它新带来了哪些内容"。这正是下面 2.2 的机制。

### 2.2 探索机制：用"最左出现"给子串去重

一个串 $S$ 的**出现位置**有 $\frac{n(n+1)}2$ 个（$(i,L)$ 表示 $S[i..i+L-1]$），但本质不同的内容少得多。差别就在于"某个内容在更靠前的位置出现过"。

记 $\operatorname{lcp}(p,q)$ 为后缀 $S[p..n]$ 与 $S[q..n]$ 的最长公共前缀长度，并定义

$$M_i=\max_{1\le j<i}\operatorname{lcp}(j,i),\qquad M_1=0.$$

**引理 1（去重恒等式）**

$$\text{dist}(S)=\sum_{i=1}^{n}\bigl[(n-i+1)-M_i\bigr].$$

**证明**：位置 $i$ 能取到的长度是 $L=1,\ldots,n-i+1$，不同长度给出不同内容的子串（长度已不同），故位置 $i$ 上一共 $\text{total}_i=n-i+1$ 个内容。断言：

$$\{\,L:\ S[i..i+L-1]\ \text{在某个}\ j<i\ \text{处也出现}\,\}=\{1,2,\ldots,M_i\}.$$

- "$\subseteq$"：若 $S[i..i+L-1]$ 在 $j<i$ 处出现，即 $S[j..j+L-1]=S[i..i+L-1]$，则 $\operatorname{lcp}(j,i)\ge L$，从而 $M_i\ge\operatorname{lcp}(j,i)\ge L$。
- "$\supseteq$"：若 $L\le M_i$，取达到最大值的 $j^{*}$（$\operatorname{lcp}(j^{*},i)=M_i$），则 $S[j^{*}..j^{*}+M_i-1]=S[i..i+M_i-1]$，其前 $L$ 个字符给出 $S[j^{*}..j^{*}+L-1]=S[i..i+L-1]$，即该内容在 $j^{*}<i$ 处出现过。（注意 $j^{*}+M_i-1\le n$ 是 $\operatorname{lcp}$ 定义保证的，所以这段确实在串内。）

于是位置 $i$ 上"**新**内容（此前没在任何更左位置出现过）"的个数 $=(n-i+1)-M_i$：由上面的双向集合等式，长度 $L$ 给出新内容 $\iff L>M_i$，即 $L\in\{M_i+1,\ldots,n-i+1\}$。

再将"逐位置新内容数之和"与"本质不同内容数"严格对成双射。记 $\mathcal{P}=\{(i,L): M_i<L\le n-i+1\}$（引理 1 的右边正是 $|\mathcal{P}|$），定义 $\phi:\mathcal{P}\to\{$本质不同内容$\}$，$\phi(i,L)=S[i..i+L-1]$：

- **满射**：任取内容 $u$，设其最左出现起点为 $i^{*}$。若 $|u|\le M_{i^{*}}$，则 $M_{i^{*}}\ge1$（因 $|u|\ge1$），故 $i^{*}\ge2$ 且达到最大值的 $j^{*}<i^{*}$ 存在，由 "$\supseteq$" 方向（$u$ 的长度-$|u|$ 前缀即 $u$ 自身）知 $u$ 在 $j^{*}$ 处也出现，与"最左"矛盾。故 $|u|>M_{i^{*}}$，$(i^{*},|u|)\in\mathcal{P}$ 且 $\phi(i^{*},|u|)=u$。
- **单射**：设 $(i,L),(i',L')\in\mathcal{P}$ 且 $\phi(i,L)=\phi(i',L')$。内容本质相同迫使 $L=L'$；若 $i\ne i'$ 不妨 $i<i'$，则位置 $i'$ 的长度-$L$ 子串在更左起点 $i$ 出现过，由 "$\subseteq$" 方向 $L\le M_{i'}$，与 $(i',L)\in\mathcal{P}$（要求 $L>M_{i'}$）矛盾。故 $i=i'$。

双向都成立，$\text{dist}(S)=|\mathcal{P}|=\sum_{i=1}^{n}\#[L: M_i<L\le n-i+1]=\sum_{i=1}^{n}[(n-i+1)-M_i]$。$\blacksquare$

**现场核对**（题面的 `abaa`，$n=4$）：
$M_1=0$；$M_2=\operatorname{lcp}(\texttt{baa},\texttt{abaa})=0$；$M_3=\max(\operatorname{lcp}(\texttt{aa},\texttt{abaa})=1,\operatorname{lcp}(\texttt{aa},\texttt{baa})=0)=1$；$M_4=\max(\operatorname{lcp}(\texttt a,\texttt{abaa})=1,0,1)=1$。
$\text{dist}=4+3+(2-1)+(1-1)=8$ ✓ 与题面完全一致（也解释了 10 个位置里为什么少了 2）。

### 2.3 加上期望：尾和公式

引理 1 里唯一随机的量是 $M_i$，且它只取 $0\ldots n-i+1$ 的整数值。

**引理 2（尾和）** 对取非负整数值且 $M\le K$ 的随机变量，$E[M]=\sum_{L=1}^{K}\Pr(M\ge L)$。

**证明**：$\sum_{L=1}^{K}\Pr(M\ge L)=\sum_{L=1}^{K}\sum_{t\ge L}\Pr(M=t)=\sum_{t=1}^{K}t\,\Pr(M=t)=E[M]$（交换求和次序，$t$ 被 $L=1..t$ 计 $t$ 次）。$\blacksquare$

由期望线性性 + 引理 1 + 引理 2：

$$\boxed{\;E=\frac{n(n+1)}2-\sum_{i=1}^{n}\sum_{L=1}^{n-i+1}q(i,L),\qquad q(i,L):=\Pr(M_i\ge L).\;}$$

**交换合法性的说明**（一次讲清，后文不再重复）：$M_i$ 只取有限集 $\{0,1,\ldots,n-i+1\}$ 中的值，外层又只有 $n$ 个位置，所以 2.2+2.3 的每一步都只是**有限重和的重排**——期望的线性性不要求任何独立性，"非负整数值 + 有限支撑"保证尾和展开成立；这里既没有无穷级数的收敛问题，也没有交换极限的问题（引理 2 证明中交换 $\sum_L\sum_t$ 时两者均为有限指标集）。

到这里问题彻底变成"算若干个概率"。剩下的困难：$M_i\ge L$ 是一个**存在性**（至少有一个更早的位置匹配）事件，事件之间有重叠、有依赖，不能直接相乘。

### 2.4 单个"等式约束"事件的概率：图的秩

记 $A_{i,L,j}$ 表示事件 "$S[j..j+L-1]=S[i..i+L-1]$"（其中 $j<i$）。它是 $L$ 个逐位等式

$$S_{j+t}=S_{i+t},\qquad t=0,1,\ldots,L-1.\tag{$\ast$}_j$$

**引理 3** 设 $T\subseteq[1,i-1]$ 非空，$V_T=[\min T,\ i+L-1]\cap\mathbb Z$。在 $V_T$ 上建图 $G_{T,L}$，边集为 $\bigcup_{j\in T}\{(j+t,\ i+t):0\le t\le L-1\}$。若 $v_T=|V_T|=i+L-\min T$，$c_T$ 为其连通块数，$r_T=v_T-c_T$，则

$$\Pr\Bigl(\bigcap_{j\in T}A_{i,L,j}\Bigr)=m^{-r_T}.$$

**证明**：
1. **顶点集就是 $V_T$**：每条边两端都在 $V_T$ 内（$j+t\ge\min T$，且 $j+t\le(i-1)+L-1<i+L-1$；$i+t\le i+L-1$）。位置 $<\min T$ 或 $>i+L-1$ 的字符不出现在任何约束里，独立自由。
2. **满足约束的赋值数**：条件"$S$ 满足 $(\ast)_j,\ \forall j\in T$" 纯粹是坐标间的相等关系，等价于"$S$ 在图 $G_{T,L}$ 的每个连通块上取常数"。$V_T$ 内有 $c_T$ 个块，$[1,n]\setminus V_T$ 内 $n-v_T$ 个位置各自独立，故合法 $S$ 数 $=m^{c_T+n-v_T}$。除以总数 $m^n$ 得 $m^{-(v_T-c_T)}=m^{-r_T}$。$\blacksquare$

注意 $r_T$ 正是这些等式的**独立约束个数**：按任意顺序加入边，每加入一条连接两个不同连通块的边，$c$ 减 1，$v$ 不变，故 $r$ 增 1；连边的边不改变 $r$。所以

$$r_T=\text{（并查集上"成功合并"的次数）}.$$

这是一个非常实用的等价刻画：**不必数点数、不必数连通块，只要在跑并查集时统计成功次数**。与实现对齐还差一小步：代码（2.8/§5）把并查集在**整个 $[1,\,i+L-1]$** 上初始化，比 $V_T=[\min T,\,i+L-1]$ 多出 $1,\ldots,\min T-1$ 这 $\min T-1$ 个点——它们不挨任何边、全是孤立块，对 $v$ 与 $c$ 的贡献相同、在 $r=v-c$ 中恰好抵消，所以"成功合并次数"仍然精确等于 $r_T$（与引理 3 证明第 2 步"在 $[1,n]$ 上直接数合法赋值"的口径完全一致）。

另外 $T\ne\emptyset$ 时 $1\le r_T\le n-1$：下界——取 $j=\max T\le i-1$，边 $(j,i)$（$t=0$）两端不同（$j\ne i$），图至少有一条真边，$c_T\le v_T-1$；上界——$r_T=v_T-c_T\le v_T-1\le i+L-2\le n-1$。⇒ **容斥式里不会出现 $m^0$ 项**，最终答案必形如 $E=\frac{n(n+1)}2-\sum_{k=1}^{n-1}a_km^{-k}$，$a_k\in\mathbb{Z}$（2.9-B 将说明这正是"无需卷积"的结构原因）。

### 2.5 容斥：严格写出 $\sum$ 形式并证明等价（"至少"与"恰好"）

**引理 4（容斥式）** 固定 $(i,L)$，$n\ge i+L-1$。则

$$q(i,L)=\Pr(M_i\ge L)=\sum_{\emptyset\ne T\subseteq[1,i-1]}(-1)^{|T|+1}\,m^{-r(T,L)}
=\sum_{k=1}^{i-1}(-1)^{k+1}\!\!\sum_{1\le j_1<\cdots<j_k\le i-1}\!\!m^{-r(\{j_1,\ldots,j_k\},L)}.$$

**证明**：
1. **事件等式**：$M_i\ge L\iff\exists j<i:\operatorname{lcp}(j,i)\ge L\iff\exists j<i:S[j..j+L-1]=S[i..i+L-1]\iff\omega\in\bigcup_{j=1}^{i-1}A_{i,L,j}$。
   （$\operatorname{lcp}$ 无定义/不足 $L$ 长的位置不贡献：$\operatorname{lcp}(j,i)\le\min(n-j+1,n-i+1)$，$j<i$ 时右端 $\le n-i+1$，与 $L\le n-i+1$ 一致，无越界。）
2. **经典容斥**：对有限事件族，$\Pr(\bigcup_j A_j)=\sum_{\emptyset\ne T}(-1)^{|T|+1}\Pr(\bigcap_{j\in T}A_j)$。按权重验证：设样本点 $\omega$ 恰好属于 $t\,(t\ge1)$ 个 $A_j$，则它在右端的总贡献为 $\sum_{k=1}^{t}(-1)^{k+1}\binom tk=(-1)^{1}\bigl[(1-1)^{t}-1\bigr]=1$，等于它在左端 $\Pr(\cup)$ 中的贡献 1；$t=0$ 时贡献 0。逐项相等 ⇒ 概率相等。
3. 再把引理 3 的 $m^{-r(T,L)}$ 代入即得所写 $\sum$ 形式。$\blacksquare$

**"至少 / 恰好"辨析（坑点）**：
- 这里用的是 $M_i\ge L$（**至少**有 $L$ 长重复），对应的容斥是"并集概率"，系数 $(-1)^{|T|+1}$，权重 $1$。
- 若换去数"恰好有 $k$ 个更左位置匹配"，则需要 $\sum_k$ 加权容斥，反而更复杂。**选"至少"是因为尾和公式（引理 2）天生只关心 $\{M\ge L\}$。** 两处一旦混用会符号全错。
- **边界**：$i=1$ 时 $[1,i-1]=\emptyset$，$q(1,L)=0$，与 $M_1=0$ 一致；$T=\emptyset$ 不参与（它的概率是 $m^0=1$，正是权重验证里被 $-1$ 抵消掉的那一项）；$L$ 的上界是 $n-i+1$（超过就没子串了）。

### 2.6 回到 2.1 的困境：枚举量到底多大

引理 4 需要对每个 $(i,L)$ 枚举 $2^{i-1}$ 个子集。总评估次数

$$\sum_{i=1}^{n}(n-i+1)\,2^{i-1}=2^{n+1}-n-2.$$

**证明**：令 $k=n-i+1$，和式 $=\sum_{k=1}^n k\,2^{n-k}=2^n\sum_{k=1}^n k2^{-k}$，而 $\sum_{k=1}^{n}k y^{k}=y\frac{1-(n+1)y^{n}+ny^{n+1}}{(1-y)^2}$；代入 $y=\tfrac12$：$\sum_{k=1}^n k2^{-k}=2-(n+2)2^{-n}$，故原和 $=2^{n+1}-(n+2)$。
自检：$n=1$: $1$；$n=2$: $2\cdot1+1\cdot2=4=2^3-4$ ✓；$n=3$: $3+4+4=11=16-5$ ✓。$\blacksquare$

$n=20$ 时精确为 $2^{21}-22=2{,}097{,}130$ 个叶子（$\approx2.1\times10^6$）——完全可行。**这也解释了子任务的台阶 $5\to10\to20$ 就是 $2^n$ 的台阶**，而 2.1 里"按内容串分组"的做法需要枚举 Bell 数 $B_L$ 个相等模式（$B_{20}\approx5\times10^{13}$），是标签里"枚举"的陷阱分支。

于是：$E$ 只需 $m^{-1},\ldots,m^{-(n-1)}$ 这些幂次（$1\le r_T\le n-1$，见 2.4），用 $m^{p-2}\bmod p$ 求一次逆再递推即可，$O(n)$ 预处理。

### 2.7 秩 $r(T,L)$ 的真实结构：为什么必须"并查集"，闭式不存在

一开始我试图给 $r(T,L)$ 找闭式，最自然的猜测是"$G_{T,L}$ 的连通块就是区间 $V_T$ 按 $g=\gcd\{\,i-j:j\in T\,\}$ 分的剩余类"，即 $c_T=g,\ r_T=v_T-g$。**反例（纸面画出）**：取 $i=5,L=2,T=\{1,2\}$（需 $n\ge6$），距离集 $D=\{4,3\}$，$g=1$，$V_T=[1,6]$；边为 $j=1$ 给出的 $(1,5),(2,6)$ 与 $j=2$ 给出的 $(2,5),(3,6)$。这 4 条边连成 $\{1,2,3,5,6\}$，而**位置 4 从未被任何边触及**，是孤立点 ⇒ $c_T=2\ne g=1$，$r_T=6-2=4$。原因：边 $(x,x+d)$ 只在窗口 $x\in[\min T,\ \min T+L-1]$ 内存在，剩余类在窗口两端会断裂，中间还可能留下"空洞"。

再举一个说明"边会冗余（$r_T<|T|L$）"的例子：$i=4,L=3,T=\{1,2\}$（$n\ge6$），6 条边 $(1,4),(2,5),(3,6),(2,4),(3,5),(4,6)$，链 $1\!\sim\!4\!\sim\!2\!\sim\!5\!\sim\!3\!\sim\!6$ 把 $V_T=[1,6]$ 全部连通 ⇒ $r_T=5=|T|L-1$，最后一条 $(4,6)$ 冗余。

⇒ 结论：不猜闭式，老老实实用并查集数"成功合并"次数（引理 3 的推论）；这样连 $v_T,c_T$ 都不必显式算。

### 2.8 实现层面的加速：子集 DFS + 可回滚并查集

朴素做法：对每个子集 $T$ 新建并查集、加 $|T|\cdot L$ 条边。合并调用次数（利用 $\sum_{T\subseteq[i-1]}|T|=(i-1)2^{i-2}$ 与 $\sum_{L=1}^{n-i+1}L=\binom{n-i+2}{2}$）

$$W(n)=\sum_{i=1}^{n}(i-1)\,2^{i-2}\binom{n-i+2}{2}\;\xrightarrow{\;n=20\;}\;33{,}554{,}710\approx3.4\times10^{7}$$

（逐项：$i=20:4{,}980{,}736$，$i=19:7{,}077{,}888$，$i=18:6{,}684{,}672$，$i=17:5{,}242{,}880$，$i=16:3{,}686{,}400$，$i\le15$ 合计 $5{,}882{,}134$）。每次合并含两次 `find`（按 size 合并，深度 $\le\lceil\log_2 20\rceil=5$），所以朴素版约 $10^8$ 级基本运算——**大概率也能过，但没多少余量**（这是操作计数，运行时间未实测）。

改进：固定 $(i,L)$，按 $j=i-1,i-2,\ldots,1$ 的顺序做"选/不选"的二分 DFS。到某个"选 $j$"的分支时，只需在该节点**新加 $L$ 条边** $(j+t,i+t)$，返回时回滚（记住栈顶 `pre` 与 `cur_rk` 的旧值即可，撤销 $fa[x]=x,\ sz[y]-=sz[x]$；$x$ 挂到 $y$ 之后不再是根、其 $sz[x]$ 不会再被改动——只有根的 `sz` 会变——故严格可逆）。因为每次**成功**合并都会使 $r$ 增 1，而 $r\le v_T-1\le n-1$，一条根到叶的路径上栈深 $\le n-1=19$。

精确计数：固定 $(i,L)$，DFS 中"选 $j$"结点（即执行合并处）共 $\sum_{j=1}^{i-1}2^{i-1-j}=2^{i-1}-1$ 个（`dfs(j)` 恰被调用 $2^{i-1-j}$ 次），每个触发 $L$ 次 `unite`，故

$$U(n)=\sum_{i=1}^{n}\bigl(2^{i-1}-1\bigr)\binom{n-i+2}{2}\;\xrightarrow{\;n=20\;}\;4{,}192{,}510$$

（逐项：$i=20:524{,}287$，$i=19:786{,}429$，$i=18:786{,}426$，$i=17:655{,}350$，$i=16:491{,}505$，$i\le15$ 合计 $948{,}513$；把 $2^{i-1}-1$ 放大成 $2^{i-1}$ 得宽松上界 $5{,}732{,}510$——旧稿把公式写成 $2^{i-1}$ 却报出 $4.2\times10^6$，两者相差 $1.5\times10^6$，现以本行为准）。叶子（$O(1)$ 累加）共 $L(n)=2^{n+1}-n-2=2{,}097{,}130$；DFS 总结点数 $\sum_i(n-i+1)(2^i-1)=4{,}194{,}050$；**回滚弹栈次数 $\le$ 入栈次数 $\le$ 成功合并次数 $\le U(n)$**——回滚代价在此逐项核过，**没有被低估**。

汇总 $n=20$ 的总步数：$4.19\times10^6$ 次 `unite`（每次两条 find 链、最坏 $2\times5$ 步、典型均摊 $\approx2$ 步）+ $4.2\times10^6$ 个结点的进出、快照与弹栈 + $2.1\times10^6$ 次叶子累加 ⇒ 典型 $\approx2\times10^7$、最坏上界 $\le8\times10^7$ 次基本运算，对任何常见时限余量充足，**无需再改造算法**（真要省常数可交换 $i,L$ 循环顺序或做记忆化，均无必要）。

> 注意这只是**同一 $O(n^22^n)$ 复杂度下的常数优化**（朴素 $3.36\times10^7\to4.19\times10^6$，约省 $\langle|T|\rangle\approx8$ 倍），不是数量级的改进，asymptotics 完全一样。

### 2.9 标签裁决：本解法即满分；NTT 在 $n\le20$ 既不需要也无处可施（最终结论）

本节给出三个带证明的结论，取代旧稿"无法解释标签"的缺口陈述——缺口不在解法，而在标签与本数据范围的对应关系，下面把它钉死。

**结论 A（满分判定）** 引理 1–4 对一切 $1\le n\le20$、$1\le m\le5\times10^6$ 是纯恒等变形链（无近似、无启发式剪枝、无"依经验成立"的环节）；2.8 在最坏输入 $n=20$ 上逐项数得：`unite` 调用 $4{,}192{,}510$、叶子 $2{,}097{,}130$、DFS 结点 $4{,}194{,}050$、弹栈 $\le4{,}192{,}510$、find 深度 $\le5$，总基本步数典型 $\approx2\times10^7$、最坏上界 $\le8\times10^7$，对任何常见时限有至少一个数量级的余量；空间 $O(n)$。⇒ **覆盖全部四个子任务，判定为满分解。** 旧稿"怀疑自己的做法不是官方解法"不构成扣分依据：满分只要求"对给定范围正确且够快"，二者均已证明；解法是否与出题人草稿雷同不影响判分。

**结论 B（$n\le20$ 下无需卷积，且"就地 NTT"可证不可能）**

1. **正向——答案的结构里没有可卷对象。** 由引理 4，每个子集 $T$ 只按 $(-1)^{|T|+1}$ 给 $m^{-r(T,L)}$ 记一票，把所有 $(i,L,T)$ 按秩归类即得
$$E=\frac{n(n+1)}2-\sum_{k=1}^{n-1}a_km^{-k},\qquad a_k=\!\!\!\sum_{\substack{2\le i\le n,\ 1\le L\le n-i+1\\ \emptyset\ne T\subseteq[1,i-1]\\ r(T,L)=k}}\!\!\!(-1)^{|T|+1}\in\mathbb{Z},$$
   其中 $1\le r_T\le n-1$ 见 2.4。整个算法 = $2.1\times10^6$ 次"子集→秩"查表计数 + 末尾 $n-1$ 次乘加，**全过程不存在任何 $\sum_j b_jc_{k-j}$ 型求和**，没有可供变换加速的中间量。（自检：4.3 第 1、3 条的一般 $m$ 闭式 $E=3-m^{-1}$（$n=2$）、$E=6-3m^{-1}$（$n=3$）就是这张 $a_k$ 表的小规模退化，且都与按定义穷举吻合。）
2. **反向——就算想卷，本模数也卷不动。** 长度 $2^t$ 的数论变换要求 $\mathbb{F}_p^\times$ 含 $2^t$ 阶元，即 $2^t\mid p-1$。这里 $p-1=10^9+6=2\times500000003$ 且 $500000003$ 为奇数，$v_2(p-1)=1$，只容得下 $t\le1$（原根 $g=5$ 只能给出 $\omega=g^{(p-1)/2}=-1$），**连长度 4 的 NTT 都构造不出来**。任何真依赖长卷积的实现都必须换装：三模 NTT（如 $998244353=119\cdot2^{23}+1$、$1004535809=479\cdot2^{21}+1$、$469762049=7\cdot2^{26}+1$，卷积系数绝对值小于三模之积时可经 CRT 精确还原）或拆系数 FFT。给一个总步数 $2\times10^7$ 的查表问题背这套机器，与题目给定的 $n\le20$ 互相矛盾。
3. **题目设置自证。** subtask 台阶 $n,m\le7$（按文章枚举）$/\,n\le5/\,n\le10/\,n\le20$ 恰好卡在"$m^n\to2^n$ 的指数枚举"由易到难的临界点上；没有任何一个台阶落在"必须把 $2^n$ 压成 $\mathrm{poly}(n)$"的 $n\ge500$ 量级。若官方题解真有卷积，它服务的是本公式的推广版（见结论 C），而不是题给范围。

**结论 C（标签的合理出处：更大 $n$ 的簇生成函数推广；方向性判定）** 观察 2.5 的子集和 $\sum_T(-1)^{|T|+1}m^{-r(T,L)}$：$T$ 中相邻（或间距 $<L$）的位置经长度-$L$ 窗口传递相等、合并成"簇"，秩按簇分解且簇权重只依赖形状（跨度、到 $i$ 的距离）；"子集 $\leftrightarrow$ 一串近似不相邻的簇"的带权计数是标准序列构造，生成函数下化为簇权重多项式的乘法与求逆（Goulden–Jackson cluster method 的同款结构）。沿这条路，$2^{i-1}$ 可被压成关于 $n$ 的多项式开销，卷积出现、NTT 归位——这是标签最自洽的来源。**此段为方向性判断（猜想级），本节算法不依赖它**；若要检验：对 $n\le12$ 把簇生成函数算出的 $q(i,L)$ 与 2.6 的子集枚举逐 $(i,L)$ 对拍即可判真伪。

**最终结论：** P1316 在题给范围（$n\le20$）的满分解 = 最左去重 + 尾和 + 子集容斥 + 可回滚并查集，$O(n^22^n)$ 时间 / $O(n)$ 空间。标签中的 NTT 对应的是结论 C 的推广方向，在 $n\le20$、$p=10^9+7$ 下既无用武之地（B.1）也无法就地使用（B.2）——"用不上 NTT"不是本解法的缺口，而是题目数据范围与标签之间的错位，现已论证完毕。

### 2.10 退化情形与边界

- $m=1$：只有一篇文章 $a^n$，$\text{dist}=n$（所有新内容都由 $i=1$ 提供，$M_1=0$）。公式上：$i\ge2$ 时 $\Pr(M_i\ge L)\equiv1$（$q(i,L)=\sum_{T\ne\emptyset}(-1)^{|T|+1}=1$），$i=1$ 时 $q(1,L)=0$，故 $E=\frac{n(n+1)}2-\sum_{i=2}^{n}(n-i+1)=\frac{n(n+1)}2-\left(\frac{n(n+1)}2-n\right)=n$ ✓。代码里 `inv=1`，`pw[k]=1`（例如 $q(3,1)=2m^{-1}-m^{-2}\big|_{m=1}=2-1=1$）。
- $m\to\infty$：$q(i,L)=O(m^{-1})\to0$，$E\to\frac{n(n+1)}2$（所有子串互不相同）✓。
- $n=1$：双重循环不执行，$E=1$ ✓。
- $i+L-1\le n$ 是内层循环条件，保证 $S[i..i+L-1]$ 存在。
- 溢出与互素：$m\le5\times10^6<p=10^9+7$ 且 $p$ 为素数 ⇒ $\gcd(m,p)=1$，逆元存在（费马小定理，`qpow(m,p-2)` 合法）；$a\cdot b\bmod p$ 用 `i64`（积 $<10^{18}<9.2\times10^{18}$）；容斥和累加绝对值 $\le2{,}097{,}130\times10^9<2.1\times10^{15}$，**全程不取模也不会溢出 `i64`**，最后一次 `tot%p` 修正即可。

## 3. 模式总结（Pattern Summary）

按**实际思考顺序**：

- **reduce to easier problem（换求和顺序）** — "对内容数串"变成 $m+m^2+\cdots$ 无法枚举 ⇒ 改成"对位置数新内容"（2.1）。
- **explore its property** — 用"最左出现"给子串去重，得到 $\text{dist}(S)=\sum_i[(n-i+1)-M_i]$，其中 $M_i=\max_{j<i}\operatorname{lcp}(j,i)$，关键是 $\{L:\text{早在位置 }i\text{ 出现过}\}=\{1..M_i\}$（引理 1）。
- **classic problem solution** — 期望线性性 + 尾和公式 $E[M]=\sum_L\Pr(M\ge L)$，把"最大值"换成"至少"型概率（引理 2）。
- **explore its property** — 单个逐位相等约束组 $=$ 图上连通块，概率 $=m^{-r}$，$r=v-c=$ 并查集成功合并次数（引理 3）。
- **classic problem solution** — 对"存在更早匹配"的并集做容斥，系数 $(-1)^{|T|+1}$，与"至少/恰好"严格对齐；$T=\emptyset$ 排除（引理 4）。
- **complexity audit** — 枚举量 $\sum_i(n-i+1)2^{i-1}=2^{n+1}-n-2$，$n\le20$ ⇒ 精确 $2{,}097{,}130$ 个叶子，正好对上子任务台阶 $5/10/20$（2.6）。
- **counterexample before abstraction** — 想给 $r(T,L)$ 找 "$\gcd$ 剩余类" 闭式，被 $i=5,L=2,T=\{1,2\}$（孤立点 4）与 $i=4,L=3,T=\{1,2\}$（冗余边）两个纸面反例否掉 ⇒ 只用并查集数合并（2.7）。
- **classic problem solution（第二次，不同技术）** — 子集 DFS + **可回滚并查集**："选 $j$"结点只有 $2^{i-1}-1$ 个、各加 $L$ 条边、按栈顶回滚，把 $O(|T|L)$ 摊成 $O(L)$，$n=20$ 时精确合并次数 $33{,}554{,}710\to4{,}192{,}510$，弹栈 $\le$ 合并次数，总步数典型 $\approx2\times10^7$（2.8，纯常数优化，回滚代价已逐项核对）。
- **closing verdict（对标签的最终裁决，取代旧稿的 gap report）** — 答案恒在 $\mathbb{Z}[m^{-1}]_{<n}$ 中，$n\le20$ 时"子集→秩"查表已证满分；卷积既无可用武之地（和式中不存在 $\sum_jb_jc_{k-j}$ 结构）、就地也做不动（$v_2(10^9+7-1)=1$，长度 4 的 NTT 都需要三模 + CRT），标签只能对应更大 $n$ 的簇生成函数推广（结论 C，猜想级并给出对拍验证路径）（2.9）。

### 4.2 算法步骤

1. 读入 $n,m$；`inv=qpow(m,p-2)`；预处理 `pw[0..n]`。`tot=0`。
2. 对 $i=2..n$（$i=1$ 时 $M_1\equiv0$，跳过）：
   对 $L=1..n-i+1$（写成 `i+L-1<=n`）：
   1) 初始化并查集 $fa[x]=x,\ sz[x]=1$（$x=1..i+L-1$），`top=0, cur_cnt=0, cur_rk=0`。
   2) `dfs(i-1)`：按 $j$ 从大到小二分叉枚举 $T\subseteq[1,i-1]$。
      - `dfs(j)`：先走"不选 $j$"分支 `dfs(j-1)`；再走"选 $j$"分支——备份 `pre=top, rk=cur_rk`，`++cur_cnt`，对 $t=0..L-1$ 执行 `unite(j+t, i+t)`，递归 `dfs(j-1)`，回滚到 `pre`（`fa[x]=x; sz[y]-=sz[x]`）并 `cur_rk=rk, --cur_cnt`。
      - `dfs(0)`（叶子）：若 `cur_cnt>0`，`tot += (cur_cnt&1 ? pw[cur_rk] : -pw[cur_rk])`。
3. `tot%=p; if(tot<0) tot+=p;`；`ans=((i64)n*(n+1)/2-tot%p+p)%p`；输出。

**正确性**：步骤 2.2.2 的叶子枚举恰好遍历所有 $T\subseteq[1,i-1]$，`cur_rk` 按引理 3 的推论等于 $r(T,L)$（且 $|T|\ge1$ 时 `cur_rk` $\ge|T|\ge1$：按 $j$ 从大到小处理时，新选的 $j$ 是尚未被任何边触及的单点，边 $(j,i)$ 必定合并成功），符号按引理 4；步骤 3 就是 2.3 方框里的恒等式。

**复杂度（精确账见 2.8）**：
- 时间 $O\!\left(\sum_i 2^{i}(n-i+1)^2\right)=O(n^2 2^n)$。$n=20$ 的逐项操作数：`unite` 调用 $4{,}192{,}510$、叶子累加 $2{,}097{,}130$、DFS 结点 $4{,}194{,}050$、弹栈 $\le4{,}192{,}510$、find 深度 $\le5$ ⇒ 总基本步数典型 $\approx2\times10^7$、最坏上界 $\le8\times10^7$（运行时间未实测，此处为操作计数），余量充足 ⇒ **满分解成立**。
- 空间 $O(n)$（并查集 + 撤销栈 + `pw`），`mxn=25`。

7. **并查集 + 回滚的手工 trace**（$(i,L)=(3,2)$，$n\ge4$；"选 $j$"分支执行 $(j+t,\,3+t)$，$t=0,1$，即边 $(j,3)$ 与 $(j+1,4)$）：
   - `dfs(2)` 的"不选 2"→ `dfs(1)`：不选 ⇒ 叶子 `cnt=0` 跳过；选 1 ⇒ `unite(1,3)`,`unite(2,4)` 均成功，`rk=2` ⇒ $T=\{1\}$ 贡献 $+m^{-2}$。
   - `dfs(2)` 的"选 2"⇒ `unite(2,3)`,`unite(3,4)` 均成功，`rk=2`；再进 `dfs(1)`：不选 ⇒ $T=\{2\}$（`cnt=1,rk=2`）贡献 $+m^{-2}$；选 1 ⇒ `unite(1,3)` 成功（`rk=3`）、`unite(2,4)` 失败（$\{1,2,3,4\}$ 已连通）⇒ $T=\{1,2\}$（`cnt=2,rk=3`）贡献 $-m^{-3}$。
   - 回溯时 `while(top>pre)` 只撤销本层新增的那一次成功合并，`cur_rk` 用快照恢复 ⇒ 与"重建并查集"结果一致。
   合计 $q(3,2)=2m^{-2}-m^{-3}$，与第 5 条里独立手算的 $q(3,2)$ 相同 ✓；同时用引理 3 校验：$T=\{1,2\}$ 时 $v_T=3+2-1=4$、$c_T=1$、$r_T=3$ ✓ 与 `rk` 一致。
8. **$r(T,L)$ 无闭式的反例**（2.7，纸面画图核对）：$i=5,L=2,T=\{1,2\}$，边 $(1,5),(2,6),(2,5),(3,6)$ 连成 $\{1,2,3,5,6\}$ 与孤立点 $\{4\}$ ⇒ $c=2,r=4$，而 $\gcd\{4,3\}=1$ 的"剩余类"猜测会给出 $c=1,r=5$ ✗；$i=4,L=3,T=\{1,2\}$ 的 6 条边全连通 ⇒ $r=5<6=|T|L$（有冗余边）。两个反例共同确认：必须用并查集数成功合并 ✓。
9. **引理 3 的独立复核（不经并查集、按定义直接数赋值）**——本解法不含卷积，真正需要核对的是"秩 = 独立约束数"，下列两例分别覆盖"无冗余边"与"有冗余边"：(a) $i=4,L=1,T=\{1,2,3\}$：事件 "$s_4=s_1=s_2=s_3$"，合法串数 $m\cdot m^{n-3}$，概率 $m^{-3}$；并查集给 $r=3$ ✓。(b) $i=3,L=2,T=\{1,2\}$（第 7 条的情形）：联立 $s_1=s_3,\ s_2=s_4$（来自 $j=1$）与 $s_2=s_3,\ s_3=s_4$（来自 $j=2$）⇒ 四点全等，概率 $m\cdot m^{n-4}/m^n=m^{-3}$；并查集给 $r_T=4-1=3$ ✓——事件涉及 4 个位置却只有 3 条独立约束，正是"$r_T\ne|T|L$"的活例。第 5 条的 $q(4,1)$（星形边 $(1,4),(2,4),(3,4)$，$|T|=1,2,3\Rightarrow r=1,2,3$）也按同一口径复核过。
10. **溢出与量级自检**：叶子数 $2^{21}-22=2{,}097{,}130$，`tot` 绝对值 $\le2{,}097{,}130\times10^9<2.1\times10^{15}$（`i64` 上限 $9.2\times10^{18}$，安全）；`stk*` 深度 $\le19$、`pw` 下标 $\le19$（`mxn=25` 安全）；`unite` 调用精确 $4{,}192{,}510$、DFS 结点 $4{,}194{,}050$、弹栈 $\le4{,}192{,}510$，find 深度 $\le5$ ⇒ 总步数典型 $\approx2\times10^7$（最坏上界 $\le8\times10^7$），量级远低于常见时限。**运行时间未实测**（按要求不能运行），这只是操作计数。

## 5. 示例代码（C++）

```cpp
// P1316 Mivik 写书
// 期望不同子串数：最左出现去重 + 尾和 + 子集容斥 + 可回滚并查集（满分，O(n^2·2^n)，n=20 约 2e7 步）
// https://www.luogu.com.cn/problem/P1316
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{25};                  // n<=20, +5 松弛
constexpr int p{1'000'000'007};         // 只做模逆，不用 NTT（p-1 只含 1 个因子 2）

int n,m;
i64 pw[mxn];                            // pw[k]=m^{-k}
int fa[mxn],sz[mxn];                    // 并查集：按 size 合并，无路径压缩（要回滚）
int stkx[mxn],stky[mxn];                // 一条根到叶路径上成功合并<=n-1 次
int top;
int cur_i,cur_L;                        // 当前考察的 (i,L)
int cur_cnt,cur_rk;                     // |T| 与 r(T,L)=成功合并次数
i64 tot;                                // sum q(i,L)，模前累加（叶子<=2,097,130 项、|pw|<p ⇒ <2.1e15，i64 不溢出）

i64 qpow(i64 a,i64 b)
{
	i64 r=1;
	for(;b;b>>=1,a=a*a%p)
		if(b&1)
			r=r*a%p;
	return r;
}

int getfa(int x)
{
	while(fa[x]!=x)
		x=fa[x];
	return x;
}

void unite(int x,int y)                 // 一次成功合并 <=> r 增 1（引理 3 推论）
{
	x=getfa(x);y=getfa(y);
	if(x==y)
		return;
	if(sz[x]>sz[y])
		swap(x,y);
	fa[x]=y;sz[y]+=sz[x];
	stkx[++top]=x;stky[top]=y;
	++cur_rk;
}

void dfs(int j)                         // 枚举 T 里 j..1 的归属，j 从大到小
{
	if(!j)
	{
		if(!cur_cnt)
			return;                     // 空集不参与容斥
		i64 t=pw[cur_rk];
		tot+=(cur_cnt&1?t:-t);          // (-1)^{|T|+1} m^{-r(T)}
		return;
	}
	dfs(j-1);                           // 不选 j
	int pre=top,rk=cur_rk;
	++cur_cnt;
	for(int t=0;t<cur_L;++t)
		unite(j+t,cur_i+t);             // 约束 S_{j+t}=S_{i+t}
	dfs(j-1);                           // 选 j
	while(top>pre)
	{
		int x=stkx[top],y=stky[top--];
		fa[x]=x;sz[y]-=sz[x];           // x 非根后 sz[x] 再未被改（只有根改 sz），可逆
	}
	cur_rk=rk;
	--cur_cnt;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	i64 inv=qpow(m,p-2);
	pw[0]=1;
	for(int k=1;k<=n;++k)
		pw[k]=pw[k-1]*inv%p;

	for(int i=2;i<=n;++i)               // i=1 时 M_1=0
	{
		for(int L=1;i+L-1<=n;++L)
		{
			cur_i=i;cur_L=L;top=0;cur_cnt=0;cur_rk=0;
			for(int x=1;x<=i+L-1;++x)
				fa[x]=x,sz[x]=1;
			dfs(i-1);
		}
	}

	tot%=p;
	if(tot<0)
		tot+=p;
	i64 ans=((i64)n*(n+1)/2-tot%p+p)%p;
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **全局静态数组**：`pw/fa/sz/stkx/stky` 全部全局，尺寸 `mxn=25`（$n\le20$ 的 +5 松弛）；并查集在每个 $(i,L)$ 开始时**显式重置** `fa[x]=x,sz[x]=1`（移植坑：全局数组默认值是 0，不重置就等于 `fa[x]=0` 全连到 0 号点，静默出错）。
- **可回滚 DSU**：不能用路径压缩（压缩后无法廉价撤销），只按 size 合并，`find` 深度 $\le\lceil\log_2 n\rceil$；撤销栈只记 `(x,y)`，靠 `sz[y]-=sz[x]` 复原。
- **`cur_rk` 就是 $r(T,L)$**：叶子处不需要数点数/连通块，`pw[cur_rk]` 直接给出 $\Pr(\cap_{j\in T}A_{i,L,j})$。
- **`cur_cnt` 奇偶决定符号**：$(-1)^{|T|+1}$，`cnt` 为奇 → 正。空集跳过（它的概率是 $m^0=1$，属于容斥推导中被抵消的项）。
- **取模策略**：中间量 `tot` 是带符号整数，绝对值 $\le2.1\times10^{15}$（`i64` 安全），只在最后统一 `tot%p` 并修正为 `[0,p)`。
- **`m<p`**：$m\le5\times10^6<10^9+7$，$\gcd(m,p)=1$，`qpow(m,p-2)` 合法。

> **复杂度复核（精确）**：`unite` 调用 $\sum_i(2^{i-1}-1)\binom{n-i+2}{2}\big|_{n=20}=4{,}192{,}510$（"选 $j$"结点 $2^{i-1}-1$ 个、每个 $L$ 条边再对 $L$ 求和，推导见 2.8），叶子 $\sum_i(n-i+1)2^{i-1}=2^{n+1}-n-2\big|_{n=20}=2{,}097{,}130$，DFS 结点 $4{,}194{,}050$，弹栈 $\le$ 合并次数；find 深度 $\le5$ ⇒ 整体 $O(n^22^n)$，$n=20$ 时典型 $\approx2\times10^7$ 次基本运算（最坏上界 $\le8\times10^7$）；空间 $O(n)$。
