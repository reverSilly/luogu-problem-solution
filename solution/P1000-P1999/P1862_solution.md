# P1862 输油管道问题

> 难度：普及- · 标签：模拟, 数学, 枚举, 排序

## 1. 重新读题
### 1.1 问题重述（人话版）

主管道是一条东西向的水平线，高度记为 $p$。第 $i$ 口油井在 $(x_i,y_i)$，连到主管道的最短管道是竖直的，长度 $|y_i-p|$。$x_i$ 完全不影响长度。求一个 $p$，使 $\sum_i |y_i-p|$ 最小，输出这个最小和。

### 1.2 关键约束与规模暗示

$1\le n\le 10000$，坐标在 $[-10^4,10^4]$。和最大约 $n\cdot 2\cdot 10^4=2\cdot 10^8$，用 64 位更稳。$n$ 已到 $10^4$，把每条整数高度都枚举一遍是 $O(n\cdot 2\cdot 10^4)$，能过但不是标程；排序取中位数是 $O(n\log n)$。

## 2. 思维链（Chain-of-thought）

**引理 1（丢掉横坐标）。** 最优长度只与 $y$ 有关。

证明：东西向主管道到点 $(x,y)$ 的竖直距离是 $|y-p|$，式子里没有 $x$。$\blacksquare$

**引理 2（最优高度是中位数）。** 把 $y$ 排成 $y_1\le y_2\le\cdots\le y_n$。令 $p=y_{\lfloor n/2\rfloor+1}$（1-based 的中间；0-based 下标就是 `n/2`，奇数取唯一中间，偶数取靠右的那个中间）。则 $p$ 使绝对偏差和最小。

证明：把油井按 $y$ 从左到右看成数轴上的点。若 $p$ 左边有 $L$ 个点、右边有 $R$ 个点，把 $p$ 向右挪 $\varepsilon$（中间不跨过任何点）时，和的变化是 $\varepsilon(L-R)$：左边每个点的距离增加 $\varepsilon$，右边每个减少 $\varepsilon$。

- 若 $L<R$，变化为负，应向右移；
- 若 $L>R$，应向左移；
- 若 $L=R$，移动不改变和，整段都最优。

停下来的位置满足左边个数与右边个数相差不超过 $1$，也就是中位数。$n$ 为奇数时只能停在中间那个点上，否则两侧个数不等。$n$ 为偶数时，两个中间点以及它们之间的任意位置，$L=R$，和相同；取靠右的中间点 $y_{n/2}$（0-based）落在这段里，和仍是最优。把 $p$ 移过一个点时，该点从一侧算到另一侧，$L,R$ 的比较方向不会让已经平衡的位置变得更好。$\blacksquare$

**引理 3（和的计算）。** 最优值就是 $\sum_i |y_i-p|$，不必再在别的高度试。

证明：引理 2 已经说明这个 $p$ 最优，直接代入定义即可。$\blacksquare$

## 3. 模式总结（Pattern Summary）

- **drop the useless coordinate** — 东西向管道只看南北坐标
- **move and count both sides** — 高度平移时，变化量由左右点数之差决定
- **stop at the median** — 左右点数平衡的位置是中位数
- **even case is a whole segment** — 偶数时两个中位点之间任意高度和相同
- **sum after one sort** — 排序一次再扫绝对值

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `n` | `int` | 油井数 | 读入 | |
| `y[10005]` | `int` | 南北坐标 | 读入 | 横坐标读完即丢 |
| `mid` | `int` | 中位数 `y[n/2]` | 排序后 | 0-based 靠右中位 |
| `ans` | `i64` | 长度和 | $0$ | 防溢出 |

### 4.2 算法步骤

1. 读 $n$ 行，只保存 $y$。
2. 升序排序，取 `y[n/2]`。
3. 累加绝对值并输出。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 $O(n\log n)$，空间 $O(n)$。

`g++ -O2 -std=c++17 -Wall -Wextra` 无警告。暴力不使用中位数结论：在 $[\min y,\max y]$ 的每个整数高度上重新求和，取最小。对拍含官方样例（双方 `6`）、单井、两端 $\pm 10^4$、全部 $y$ 相同、偶数个点，以及随机小范围数据。结果：

- `53 tests OK`
- 最大数据 $n=10000$、$x,y$ 在 $[-10^4,10^4]$ 随机，标程墙钟 `0.029074s`，该组输出 `50582143`

## 5. 示例代码
### 5.1 标程（`P1862.cpp`）

```cpp
//
// 题目：P1862 输油管道问题
// https://www.luogu.com.cn/problem/P1862
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};

int n;
int y[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		int x;
		cin>>x>>y[i];
	}
	sort(y,y+n);
	int mid=y[n/2];
	i64 ans=0;
	for(int i=0;i<n;++i)
		ans+=abs(y[i]-mid);
	cout<<ans<<'\n';
	return 0;
}
```
