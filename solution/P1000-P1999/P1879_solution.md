# P1879 [USACO06NOV] Corn Fields G

## 1. 重新读题

### 1.1 问题重述（人话版）

有一个 $m$ 行 $n$ 列的方格牧场，每格是 $0$（贫瘠，不能种）或 $1$（肥沃，可以种）。选若干格种草，要求：

1. 只能种在 $1$ 格上；
2. 任意两块草地不能有公共边（上下左右都不相邻）。

求合法种植方案数，对 $10^8$ 取模。一格都不种也算一种方案。

### 1.2 关键约束与规模暗示

- $1\le m\le 12$，$1\le n\le 12$。格子总数最多 $144$，但单行只有 $12$ 格 → 每行用 $2^n\le 4096$ 个掩码表示，这是最自然的状压维度。
- 相邻约束是"局部"的：同一行内左右相邻、相邻两行同列。冲突只发生在相邻行之间，不含隔行约束。
- 模数 $10^8$ 不是质数，不能除法，但这里只有加法乘法，直接取模即可。

## 2. 思维链（Chain-of-thought）

### 2.1 抓住约束的"局部性"

"两块草地不能有公共边"这句话，把全部约束拆成了两类：

- 同一行内：掩码 $s$ 不能有相邻的两个 $1$，即 $s\ \&\ (s\ll 1)=0$；
- 相邻两行：同列不能同时为 $1$，即 $s_i\ \&\ s_{i-1}=0$。

除此之外没有别的约束——隔行之间共用顶点不算公共边。这一点是状压可行性的关键，否则状态要记录两行。

### 2.2 把"方案"编码成"掩码序列"

设第 $i$ 行（$0$ 起）的种植掩码为 $s_i$，$s_i$ 的第 $j$ 位为 $1$ 表示第 $j$ 列种了草。记第 $i$ 行的肥沃掩码为 $a_i$。

**引理 1（编码一一对应）**：种植方案与掩码序列 $(s_0,\dots,s_{m-1})$ 构成双射，且方案合法当且仅当

$$s_i\subseteq a_i,\qquad s_i\ \&\ (s_i\ll1)=0,\qquad s_i\ \&\ s_{i-1}=0\quad(1\le i<m).$$

**证明**：

- 编码：一个方案每个格子的种/不种正好决定 $s_i$ 的每一位，所以方案 → 序列是单射；给定序列，逐格还原方案，是满射。故为双射。
- 必要性：$s_i\not\subseteq a_i$ 意味着在某块贫瘠地种了草，违反条件 1。$s_i$ 有相邻的两个 $1$ 意味着同一行有两个左右相邻的草地，违反条件 2。$s_i\ \&\ s_{i-1}\ne0$ 意味着某个 $j$ 有 $s_i$ 与 $s_{i-1}$ 的第 $j$ 位同时为 $1$，即第 $i-1$ 行与第 $i$ 行的第 $j$ 列上下相邻，违反条件 2。
- 充分性：任意两块草地若有公共边，只可能是"同一行左右相邻"或"相邻行同列相邻"（因为格子的边只有上下左右四种方向）。前者被第二个条件排除，后者被第三个条件排除。条件 1 保证不种在贫瘠地。故合法。$\square$

### 2.3 逐行 DP

有了引理 1，约束只发生在相邻两行，就可以逐行动态规划：

$$dp[i][s]=\text{前 }i+1\text{ 行合法、且第 }i\text{ 行掩码为 }s\text{ 的方案数}.$$

转移时枚举上一行的掩码 $t$：

$$dp[i][s]=\sum_{\substack{t\subseteq a_{i-1}\\ t\ \&\ (t\ll1)=0\\ s\ \&\ t=0}} dp[i-1][t].$$

**引理 2（DP 正确性）**：$dp[i][s]$ 恰好等于"前 $i+1$ 行合法且第 $i$ 行掩码为 $s$"的方案数。

**证明**：对 $i$ 归纳。

- $i=0$：只需 $s\subseteq a_0$ 且 $s$ 无相邻 $1$，此时赋 $1$，否则 $0$；这正好是该行所有合法配置。
- 归纳步：任何一个"前 $i+1$ 行合法、第 $i$ 行为 $s$"的方案，去掉第 $i$ 行后是"前 $i$ 行合法、第 $i-1$ 行为某个 $t$"的方案，并且由引理 1 的约束必有 $t\subseteq a_{i-1}$、$t$ 无相邻 $1$、$s\ \&\ t=0$；反过来，任何满足这些条件的 $t$ 与 $s$ 拼起来就合法。所以每个 $t$ 贡献 $dp[i-1][t]$ 个方案，且不同 $t$ 对应的方案（去掉第 $i$ 行后第 $i-1$ 行不同）不重复，求和即得。$\square$

### 2.4 减少枚举量

朴素做法对每行枚举 $4096^2\approx1.7\times10^7$ 对掩码，$12$ 行就是 $2\times10^8$，虽然可能卡过去，但完全没必要：行内合法的掩码（无相邻 $1$）只有 $F_{n+2}$ 个，$n=12$ 时是 $F_{14}=377$。把合法掩码预先筛到 `vm[]` 里，每行只枚举 $377^2\approx1.4\times10^5$ 对，$12$ 行约 $1.7\times10^6$。

而且 $s\subseteq a_i$ 的检查和 $s\ \&\ t=0$ 的检查都是 $O(1)$ 位运算。

### 2.5 答案与边界

- 答案 $=\sum_{s}dp[m-1][s]$，因为最后一行可以是任何合法掩码。
- 全 $0$ 掩码一定在合法掩码里，所以"整片荒废"的方案被自动统计。
- 取模在每次加法后做，模数是 $10^8$（注意不是 $10^9+7$）。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 约束只有"同行相邻"与"相邻行同列"两类，可拆成局部约束。
- **encode by bitmask** — 一行的种植状态编码成 $n$ 位掩码，方案 ↔ 掩码序列双向对应。
- **classic problem solution** — 逐行状压 DP，$dp[i][s]$ 由上一行互不相交的掩码转移。
- **prune the state space** — 只枚举行内无相邻 $1$ 的 Fibonacci 个合法掩码，去掉 $90\%$ 的无用状态。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| $m,n$ | `int` | 行数、列数 | 读入 | 维度 |
| `a[i]` | `int [15]` | 第 $i$ 行的肥沃掩码（第 $j$ 位 $=1$ 表示可种） | 读入时置位 | available |
| `vm[]` | `int [4096]` | 所有行内合法的掩码（无相邻 $1$） | 预处理 | valid masks |
| `vn` | `int` | `vm` 的长度 | $0$ | 计数 |
| `dp[i][s]` | `int [15][4096]` | 前 $i+1$ 行合法、第 $i$ 行掩码为 $s$ 的方案数 | $0$ | ways |

### 4.2 算法步骤

1. 读入 $m,n$，把每行的肥沃状态压成掩码 `a[i]`。
2. 枚举 $s\in[0,2^n)$，把满足 `!(s&(s<<1))` 的 $s$ 存入 `vm`。
3. 初始化第 $0$ 行：对每个合法 $s$，若 `(s&a[0])==s`，令 `dp[0][s]=1`。
4. 对 $i=1..m-1$：对每个合法 $s$（要求 `(s&a[i])==s`），枚举合法 $t$，若 `!(s&t)`，则 `dp[i][s]=(dp[i][s]+dp[i-1][t])%p`。
5. 输出 $\sum_s dp[m-1][s]\bmod p$。

### 4.3 复杂度

- 时间 $O(m\cdot V^2)$，其中 $V$ 是行内合法掩码数，$V\le377$；预处理 $O(2^n)$。最坏约 $2\times10^6$ 次转移。
- 空间 $O(m\cdot 2^n)$，约 $15\times4096$ 个 `int`，$250$ KB 量级。

## 5. 示例代码

```cpp
//
// 题目：P1879 [USACO06NOV] Corn Fields G
// https://www.luogu.com.cn/problem/P1879
// 自测：小数据枚举对拍通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{15},mxm{1<<12};
constexpr int p{100000000};

int m,n;
int a[mxn];
int vm[mxm],vn;
int dp[mxn][mxm];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n;
	for(int i=0;i<m;++i)
		for(int j=0,x;j<n;++j)
		{
			cin>>x;
			if(x)
				a[i]|=1<<j;
		}
	int full=1<<n;
	for(int s=0;s<full;++s)
		if(!(s&(s<<1)))
			vm[vn++]=s;                 // 行内合法：没有左右相邻的 1
	for(int i=0;i<vn;++i)
		if((vm[i]&a[0])==vm[i])
			dp[0][vm[i]]=1;
	for(int i=1;i<m;++i)
		for(int j=0;j<vn;++j)
		{
			int s=vm[j];
			if((s&a[i])!=s)
				continue;
			for(int k=0;k<vn;++k)
				if(!(s&vm[k]))
					dp[i][s]=(dp[i][s]+dp[i-1][vm[k]])%p;
		}
	int ans=0;
	for(int j=0;j<vn;++j)
		ans=(ans+dp[m-1][vm[j]])%p;
	cout<<ans<<'\n';
	return 0;
}
```
