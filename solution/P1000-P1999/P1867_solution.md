# P1867 【Mc生存】经验值

> 难度：入门 · 标签：模拟, 洛谷原创

## 1. 重新读题
### 1.1 问题重述（人话版）

生命初始 $10$，等级初始 $0$，经验初始 $0$。共 $n$ 次操作，每次先付出 $x$ 点生命（$x$ 可以是小数，也可以是负数，负数表示回血），再获得非负整数经验 $a$。

- 扣血（或加血）之后如果生命 $\le 0$，立刻死亡：这次经验不算，后面的操作全部作废。
- 生命超过 $10$ 就截成 $10$。
- 从 $0$ 级开始，升到下一级需要 $2^{当前等级}$ 点经验：第 $0$ 级升 $1$ 级要 $1$，再往上是 $2,4,8,\ldots$。

输出最终等级和升完这些级之后剩下的经验。

### 1.2 关键约束与规模暗示

$1\le n\le 20$，数据很弱，但坑在顺序：先结算生命，死亡则 `break`，不能 `continue` 到后面去回血。样例 `5.5 15` 再 `4.5 24`：生命变成 $0$，第二段经验作废，只剩 $15$ 点经验，即 $4$ 级 $0$ 经验。$x$ 用浮点，$a$ 用整数。

## 2. 思维链（Chain-of-thought）

**引理 1（有效前缀）。** 设操作按输入顺序为 $(x_1,a_1),\ldots,(x_n,a_n)$。从 $hp=10$ 起依次做 $hp\leftarrow hp-x_i$。令 $t$ 是最小的使 $hp\le 0$ 的下标；若不存在则 $t=n+1$。有效经验是 $\sum_{i<t}a_i$，并且每个未死亡的 $i$ 在加经验之前把 $hp$ 截到 $10$。

证明：题面写明先算付出的生命，小于等于 $0$ 则本次及以下操作无效。回血是 $x$ 为负、$hp-x$ 变大，上限 $10$ 在活着的时候才应用。死亡那一次的 $a$ 不加。$\blacksquare$

**引理 2（等级）。** 设有效经验为 $E$。升到 $L$ 级一共消耗 $1+2+\cdots+2^{L-1}=2^L-1$。最大的 $L$ 满足 $2^L-1\le E$，剩下的经验是 $E-(2^L-1)$。

证明：每一级的门槛正好是下一项 2 的幂，且门槛只增不减，所以从小到大减，能减几次就是几级。等比求和给出闭式。$E=15$ 时 $2^4-1=15$，剩下 $0$，对应题面的 $4$ 级 $0$ 点；$E=39$ 时 $2^5-1=31$，剩下 $8$，对应 $5$ 级 $8$ 点。$E=0$ 时一级都升不了。$\blacksquare$

标程用逐级扣减实现引理 2；暴力用 $L=\lfloor\log_2(E+1)\rfloor$ 直接算同一闭式。两者在对拍里比对。

## 3. 模式总结（Pattern Summary）

- **pay life before exp** — 先改生命，再决定这次经验算不算
- **death stops the suffix** — 生命 $\le 0$ 就结束，不是跳过这一条
- **cap at ten only if alive** — 回血上限 $10$
- **thresholds are powers of two** — 第 $L$ 级门槛总和是 $2^L-1$
- **subtract until cannot** — 逐次减 $1,2,4,\ldots$ 得到等级和剩余

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `n` | `int` | 操作数 | 读入 | $\le 20$ |
| `hp` | `double` | 当前生命 | $10$ | 可被小数扣 |
| `exp` | `i64` | 有效经验 | $0$ | 死亡后不再加 |
| `lv` | `int` | 等级 | $0$ | |
| `need` | `i64` | 下一级所需 | $1$ | 每次左移一位 |

### 4.2 算法步骤

1. $hp=10$，$exp=0$。
2. 对每次操作读 $x,a$，令 $hp-=x$。若 $hp\le 0$ 则停止。若 $hp>10$ 则 $hp=10$。然后 $exp+=a$。
3. 当 $exp\ge need$ 时减去 `need`，等级加一，`need` 翻倍。
4. 输出等级和剩余经验。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 $O(n+\log E)$，空间 $O(1)$。

`g++ -O2 -std=c++17 -Wall -Wextra` 无警告。暴力用 $\lfloor\log_2(E+1)\rfloor$ 算等级，生命结算与标程相同但分开写。对拍含官方样例（双方 `4 0`）、一击死亡、回血封顶、$E=0,1,2,3,31,32$，以及 $80$ 组 $n\le 20$ 的随机（$x$ 含小数和负数）。结果：

- `95 tests OK`
- 单独一次 $n\le 20$ 的标程进程墙钟 `0.007966s`（含启动；运算本身可忽略）

## 5. 示例代码
### 5.1 标程（`P1867.cpp`）

```cpp
//
// 题目：P1867 【Mc生存】经验值
// https://www.luogu.com.cn/problem/P1867
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	double hp=10;
	i64 exp=0;
	for(int i=0;i<n;++i)
	{
		double x;
		i64 a;
		cin>>x>>a;
		hp-=x;
		if(hp<=0)
			break;
		if(hp>10)
			hp=10;
		exp+=a;
	}
	int lv=0;
	i64 need=1;
	while(exp>=need)
	{
		exp-=need;
		++lv;
		need<<=1;
	}
	cout<<lv<<' '<<exp<<'\n';
	return 0;
}
```
