# P1598 [USACO03FEB] 垂直柱状图 Vertical Histogram

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给定四行大写字母（每行不超过 $100$ 个字符，行内允许出现空格），统计 $26$ 个大写字母各自出现的总次数，
再把这些次数画成一张竖直柱状图：字母 `A` 到 `Z` 各占一列，列高等于该字母的出现次数，
每一层高度用一个 `*` 表示；图形最下方补一行 `A B C ... Z` 作为列标签。

输出时按"从最高层到第 $1$ 层"的顺序逐行打印，每行由空格与 `*` 组成；任何一行末尾都不允许多余空格，也不允许空行。

### 输入输出格式

- **输入格式**：恰好四行字符，内容为大写字母（原题数据中可能夹有空格，因此必须整行读入）。
- **输出格式**：先输出 $\max_i cnt_i$ 行星号图（自上而下），再输出一行 `A B C D ... Z`。
- **数据规模**：四行，每行长度 $\le 100$，字母表只有 $26$ 列，因此最大列高 $\le 400$。

### 关键约束分析

1. 输入是"四行文本"而不是"四个单词"。若用 `cin>>s` 按空白切分，行内空格会被跳过、空行会直接消失，计数随之出错，必须用 `getline` 整行读。
2. 输出是逐字符对齐的格式题：第 $i$ 列（$0$ 基）的星号必须落在第 $2i$ 个字符位置上，才能和最后一行的第 $i$ 个字母对齐，所以"一格"固定宽 $2$（`* ` 或 `  `）。
3. 行末空格必须删掉，且删掉后不能出现空行（这一点需要证明，见引理 3）。
4. 行数由最大计数决定，与 $26$ 无关；计数为 $0$ 的字母整列都不出现。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：先把"一列"这件事想清楚

先想暴力：把 $26$ 个计数求出来，然后对每一层 $k$、每一列 $i$，判断"此处该不该画星"。
这里没有任何搜索或最优化的成分，唯一要想清楚的是"第 $k$ 层的第 $i$ 列到底画不画"。
直觉是：一列的高度就是该字母的计数，所以"第 $k$ 层有星"应当等价于"计数不少于 $k$"。
把直觉写成命题就是引理 1。

**引理 1（层次判据）**：设字母 $c$ 的计数为 $cnt_c$，则第 $k$ 层（$1 \le k$）第 $c$ 列画 `*` 当且仅当 $cnt_c \ge k$。

*证明*：柱状图的语义是"列高等于计数"，即该列恰好由从下往上连续的 $cnt_c$ 个格子填满、其余格子留空。
第 $k$ 层是这个自下而上序列中的第 $k$ 个格子，它被填满当且仅当 $k \le cnt_c$。$\square$

### 第二步：为什么各列可以独立决定

如果每列的图形会互相影响，就必须整张图一起考虑。但观察输出格式：字符只出现在固定的格位上，格位之间互不重叠。

**引理 2（列独立）**：整个图形第 $k$ 行的内容，等于把 $26$ 个"该列在第 $k$ 层的格位"按列号顺序拼接起来的结果，与其它行、其它列的取值无关。

*证明*：每个格位由（行号 $k$，列号 $i$）唯一确定，并且在输出串中占据两个字符的位置 $[2i, 2i+1]$。
不同格位对应的字符区间互不相交，因此任意一个格位的取值只由 $(k,i)$ 决定，把这 $26$ 个格位拼接即得整行。
由引理 1，$(k,i)$ 的取值只依赖 $cnt_i$ 与 $k$，故各列互不影响。$\square$

有了引理 1、2，算法已经确定为"双重循环遍历 (层, 列)"。

### 第三步：对齐与裁剪——格式题真正的坑

最后一行的标签是 `A B C ... Z`，字母 `A+i` 落在下标 $2i$ 处；而星号图第 $i$ 列的格子若写成 `* `（两个字符）也就落在下标 $2i$ 与 $2i+1$，二者自动对齐。

**引理 3（裁剪尾空格安全）**：把一行末尾的空格全部删掉，不会改变任何 `*` 的位置，也不会让这一行变成空行。

*证明*：裁剪只删除行尾字符，行内所有非空格字符的下标不变，故对齐关系不变，前半句成立。
对后半句：该行对应层号 $k \le mx = \max_i cnt_i$，由最大值的定义存在某一列 $i_0$ 使 $cnt_{i_0} = mx \ge k$，
由引理 1 该列在这一层画 `*`，于是本行至少有一个 `*`；裁剪只删空格，`*` 不会被删掉，故本行非空。$\square$

引理 3 说明了"先按 $2$ 字符一格无脑拼接、再从右往左删空格"这一写法的正确性：它既满足"行末无多余空格"，又不会误删内容、不会产生空行。

### 第四步：把结论拼成算法

1. 读四行，累计每个字母的出现次数；
2. 求最大计数 $mx$；
3. 对 $k = mx, mx-1, \dots, 1$ 逐行拼接并裁剪；
4. 输出字母表行。

**定理**：上述算法输出的图形与题意要求的柱状图逐字符相同。

*证明*：星号部分：由引理 1 每个格位取值正确，由引理 2 拼接顺序正确（列号从小到大），由引理 3 裁剪不改变可见内容且不产生空行，
行序为 $mx$ 递减到 $1$，与"从上往下"一致。标签部分：字母按 `A` 到 `Z` 顺序、单空格分隔、末尾无空格，
与题面"最后一行由空格和字母组成"的要求一致。$\square$

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 柱状图的每一列只由该字母的计数决定，与其它列完全解耦。
- `reduce to easier problem` — 把"画图"降成"对每个格位回答 $cnt_i \ge k$ 是否成立"。
- `classic problem solution` — 计数数组 + 双层循环（层 × 列）直接输出，$\mathcal{O}(26 \cdot mx)$。
- `handle input globally` — 必须整行读入，按空白切词会丢掉行内空格与空行。
- `handle formatting` — 固定宽度单元格保证列对齐，再裁掉行尾空格，避免"多余空格"和"空行"两类格式错误。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $cnt_c$ | `cnt[c-'A']` | 字母 $c$ 在四行中出现的总次数，全局数组默认 $0$，读入时自增 |
| $s$ | `s` | 行缓冲（`char s[mxn]`），每次用 `cin.getline` 读入一整行，读入后逐字符扫描 |
| $mx$ | `mx` | 最大列高 $\max_i cnt_i$，即星号图的行数 |
| $k$ | `k` | 当前输出的层号，从 `mx` 递减到 $1$ |
| $i$ | `i` | 列号（$0$ 对应 `A`，$25$ 对应 `Z`），也用作四行输入的行计数 |
| $row$ | `row` | 当前行的临时字符串，先按每格 $2$ 字符拼接，再裁掉尾部空格 |
| — | `mxn` | 行缓冲容量，取 $100+5$ |

### 算法步骤

1. 循环四次调用 `cin.getline(s,mxn)`，对读到的每个字符：若落在 `'A'..'Z'` 则 `++cnt[s[j]-'A']`。行内空格与空行被自然忽略。
2. 扫描 `cnt[0..25]` 求 `mx`。
3. 对 `k = mx downto 1`：对 `i = 0..25` 追加 `cnt[i]>=k ? "* " : "  "`，再用 `while` 从尾部删空格，输出该行。
4. 输出 `A B C ... Z`（字母之间单个空格，末尾不加空格），最后换行。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}(L + 26 \cdot mx)$，其中 $L \le 400$ 为输入总字符数，$mx \le 400$；即常数级，最大约 $10^4$ 次操作。
- **空间复杂度**：$\mathcal{O}(1)$，只有长度 $26$ 的计数数组与长度 $105$ 的行缓冲。

### 正确性验证

引理 1 保证每个格位的星号判据正确，引理 2 保证按列拼接即为整行，引理 3 保证裁剪不改变内容且不产生空行，
最后由定理给出整体正确性。数值上只有 $0 \sim 400$ 的计数，`int` 足够，不存在溢出与精度问题。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1598 [USACO03FEB] 垂直柱状图 Vertical Histogram
// https://www.luogu.com.cn/problem/P1598
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};           // 每行不超过 100 字符 (+5 松弛)

int cnt[26];                     // cnt[c]: 字母 c 在四行中出现的次数
char s[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(int i=0;i<4;++i)
	{
		cin.getline(s,mxn);       // 必须整行读, 行内可能有空格
		for(int j=0;s[j];++j)
			if(s[j]>='A'&&s[j]<='Z')
				++cnt[s[j]-'A'];
	}

	int mx=0;
	for(int i=0;i<26;++i)
		mx=max(mx,cnt[i]);

	for(int k=mx;k>=1;--k)        // 第 k 层, 从最高层往下画
	{
		string row;
		for(int i=0;i<26;++i)
			row+=(cnt[i]>=k?"* ":"  ");
		while(!row.empty()&&row.back()==' ')   // 行末不留多余空格
			row.pop_back();
		cout<<row<<'\n';
	}

	for(int i=0;i<26;++i)         // 最后一行字母表, 用单个空格分隔
	{
		cout<<char('A'+i);
		if(i<25)
			cout<<' ';
	}
	cout<<'\n';
	return 0;
}
```

### 易错点

1. **用 `cin>>s` 读入**：按空白切分，行内空格丢失、空行直接消失，计数全错。必须 `getline`。
2. **行末留空格**：直接输出 `"  "` 格而不裁剪，会触发格式错误；必须在每行末尾删空格。
3. **行数写成固定 26**：行数应为最大计数，而不是字母个数；反之，也不能只输出到"最高非零列"。
4. **裁剪把整行删空**：若误判层数（例如 $k$ 用到 $mx+1$）就会出现空行，层号上界必须是 $mx$。
5. **字母表行末尾加空格**：`A B C ... Z ` 末尾多一个空格同样会被判错。
