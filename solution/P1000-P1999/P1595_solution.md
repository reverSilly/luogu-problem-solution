# P1595 信封问题

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

有 $n$ 封信与 $n$ 个信封一一对应。求把 $n$ 封信全部装进信封、且**每封信都不在自己的信封里**的装法数。这就是经典的"错排"（derangement）计数 $D_n$。

### 输入输出格式

- **输入格式**：一行一个整数 $n$。
- **输出格式**：一行一个整数，表示错排方案数。
- **数据规模**：$1\le n\le20$。

### 关键约束分析

1. $n\le20$ 时 $20!\approx2.43\times10^{18}$，仍在 `long long` 范围内（上限约 $9.22\times10^{18}$），所以只需 64 位整数、无需高精度。$D_{20}=895014631192902121$，验证这一点是选型的关键。
2. $n\le20$ 也可以状压 DP（$O(n2^n)$），但没必要；递推 $O(n)$ 更短更稳。
3. 边界：$n=1$ 无解，答案为 $0$；$n=2$ 只有一种交换，答案为 $1$。这两个初值不写对，递推从第一步就崩。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：为什么不能枚举排列

$20!$ 约 $2.4\times10^{18}$，枚举不可能。但 $n$ 很小，说明出题人期望的是**指数级以下的递推/DP**，而不是组合数公式的复杂推导。

### 第二步：盯住"1 号信去哪"

错排的对称结构很强，先固定 1 号信的去向：它不能进 1 号信封，只能进 $j$ 号信封，$j\in\{2,\dots,n\}$，共 $n-1$ 种选择。

接下来按"$j$ 号信是否进 1 号信封"分类，这是唯一会影响后续结构的信息。

**引理 1（错排递推）**：对 $n\ge3$，$D_n=(n-1)\left(D_{n-1}+D_{n-2}\right)$。

*证明*：固定 1 号信进入 $j$ 号信封（$n-1$ 种）。

**情形 A：$j$ 号信进入 1 号信封。** 此时 1 号与 $j$ 号信、1 号与 $j$ 号信封已经互相配对完毕，剩下的 $n-2$ 封信 $\{2,\dots,n\}\setminus\{j\}$ 要装进剩下的 $n-2$ 个信封，且每封信都不能进自己的信封（因为其他限制都没被解除）。这恰是一个规模 $n-2$ 的错排，方案数 $D_{n-2}$。

**情形 B：$j$ 号信不进入 1 号信封。** 此时剩下的 $n-1$ 封信 $\{2,\dots,n\}\setminus\{j\}$ 要装进剩下的 $n-1$ 个信封 $\{1,\dots,n\}\setminus\{j\}$，约束是：除 $j$ 号信以外每封信都不能进自己的信封，且 $j$ 号信不能进 1 号信封。

建立双射：把"1 号信封"重新命名为"$j$ 号信专属的信封"。于是这 $n-1$ 封信与 $n-1$ 个信封重新一一对应（$j$ 号信对应 1 号信封，其余信对应自己的信封），而全部约束恰好变成"每封信都不进自己的信封"——正是一个规模 $n-1$ 的错排。由于这是一次纯粹的改名（信封集合与信件集合同时置换），方案数不变，为 $D_{n-1}$。

两类情形按"$j$ 号信是否进 1 号信封"划分，互斥且穷尽；对 $j$ 的 $n-1$ 种选择求和，由加法与乘法原理得 $D_n=(n-1)(D_{n-1}+D_{n-2})$。$\square$

**引理 2（初值）**：$D_1=0$，$D_2=1$，并约定 $D_0=1$。

*证明*：$n=1$ 时唯一的排列把信 1 放进信封 1，是固定点，故 $D_1=0$。$n=2$ 时排列 $(2,1)$ 无固定点、$(1,2)$ 有两个固定点，故 $D_2=1$。$D_0=1$ 是空排列的唯一方案数，作为递推的哨兵（也保证 $n=2$ 时 $D_2=1\cdot(D_1+D_0)=1$ 成立）。$\square$

**定理**：按 $D_0=1,D_1=0$ 与引理 1 递推到 $n$，得到的 $D_n$ 就是答案。

*证明*：对 $n$ 归纳。$n\le2$ 由引理 2 直接成立；设 $n-1,n-2$ 时成立，则 $D_n=(n-1)(D_{n-1}+D_{n-2})$ 由引理 1 给出正确值。$\square$

### 第三步：数值范围检查

**引理 3（不溢出）**：$D_n\le n!$，故 $n\le20$ 时 $D_n\le20!\approx2.43\times10^{18}<2^{63}-1$。

*证明*：错排是所有 $n!$ 个排列的子集，故 $D_n\le n!$。而 $20!=2432902008176640000<9223372036854775807$。递推中的中间量 $(n-1)(D_{n-1}+D_{n-2})=D_n$ 本身也在范围内。$\square$

### 第四步：另一种验证视角

容斥原理给出 $D_n=\sum_{k=0}^{n}(-1)^k\binom{n}{k}(n-k)!=\sum_{k=0}^{n}(-1)^k\dfrac{n!}{k!}$。它与递推完全独立，正好可以用作对拍真值。

## Part 3 — 模式总结 (Pattern Summary)

- `consider easier version` — 先算 $n=1,2$ 的平凡情形，得到初值 $D_1=0,D_2=1$。
- `explore its property` — 固定 1 号信的去向，再按"对应信是否回来"二分，结构立刻收敛成更小规模。
- `prove by bijection` — 情形 B 通过"重命名信封"把带禁位的排列双射成标准错排。
- `classic problem solution` — 线性递推 $D_n=(n-1)(D_{n-1}+D_{n-2})$，$O(n)$ 时间。
- `bound check` — 用 $D_n\le n!$ 与 $20!<2^{63}-1$ 论证 `long long` 足够。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $n$ | `n` | 信封（信件）数 |
| $D_i$ | `d[i]` | 规模 $i$ 的错排数；`d[0]=1`、`d[1]=0` 为初值，其余由递推填充 |
| $i$ | `i` | 递推的循环变量，从 $2$ 到 $n$ |

### 算法步骤

1. 读入 `n`。
2. 置 `d[0]=1`、`d[1]=0`。
3. 对 `i=2..n`：`d[i]=(i-1)*(d[i-1]+d[i-2])`。
4. 输出 `d[n]`。

### 复杂度分析

- **时间复杂度**：$O(n)$，$n\le20$，即 $19$ 次乘加。
- **空间复杂度**：$O(n)$；实际上只需保留前两项，可降到 $O(1)$，但本题保留整个表更方便核对。

### 正确性验证

引理 1 给出递推，引理 2 给出初值，定理用归纳保证结果正确；引理 3 保证 $n\le20$ 时所有中间量都在 `long long` 内。代码中 `d` 为全局数组，默认零初始化，但 `d[0]`、`d[1]` 被显式赋值，不依赖默认值。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1595 信封问题
// https://www.luogu.com.cn/problem/P1595
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{25};

i64 d[mxn];                     // d[i]: i 封信全部装错的方案数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	d[0]=1;
	d[1]=0;
	for(int i=2;i<=n;++i)
		d[i]=(i-1)*(d[i-1]+d[i-2]);
	cout<<d[n]<<'\n';
	return 0;
}
```

### 易错点

1. **`d[0]` 忘了设成 $1$**：全局数组默认 $0$，则 $D_2=1\cdot(0+0)=0$，后面全错。
2. **`d[1]` 设成 $1$**：$D_1$ 应为 $0$（只有"信 1 进信封 1"这一种装法，且是固定点）。
3. **用 `int`**：$D_{20}=8.95\times10^{17}$，`int` 严重溢出，必须 `i64`。
4. **递推方向写反**：系数是 $i-1$，不是 $i$；错误写法 $i(D_{i-1}+D_{i-2})$ 会把答案放大。
5. **`n=1` 越界**：`d[1]` 已初始化，循环不执行，输出 $0$，正确；若把初值只写到 `d[1]=0` 而漏 `d[0]`，则 `n>=2` 出错。
