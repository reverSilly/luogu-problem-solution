# P1272 重建道路 — 题解

## Part 1 · 重新读题

一棵 $N$ 个节点的树，根为 1 号节点（0-based 即 0 号）。输入给出 $N-1$ 条边（每条边以"父节点 子节点"格式给出，但树是无向的——砍边不区分方向）。

**求**：破坏最少的边，使得破坏后图中**存在**一个连通块恰好包含 $P$ 个节点。

约束：$1 \le N \le 150$，$1 \le P \le N$。

---

## Part 2 · 思维链（发现过程）

### 第 1 步：探索性质

砍 $k$ 条边把树分成恰好 $k+1$ 个连通块。题目要求"分离出"恰含 $P$ 个节点的连通块，即破坏后图中有一个连通块大小恰为 $P$。

### 第 2 步：刻画连通块的结构

考虑破坏后任意一个连通块 $S$（$S$ 是该连通块的节点集）。$S$ 在树中有一个**唯一的最高节点** $u$，定义为 $S$ 中深度最小的节点（根深度为 0）。

**性质 1**：$S \subseteq \text{子树}(u)$，且 $u \in S$。

*证明*：$u$ 是 $S$ 中深度最小的节点。$S$ 是连通块，故 $S$ 中任意两节点在 $S$ 内连通。取 $w \in S$，$w$ 与 $u$ 在 $S$ 内连通。树中 $w$ 到 $u$ 有唯一路径 $P_{w,u}$，$P_{w,u}$ 上所有节点必须在 $S$ 中（否则 $S$ 不连通）。由于 $u$ 深度最小，$P_{w,u}$ 从 $w$ 沿祖先方向走到 $u$，故 $P_{w,u}$ 上所有节点都是 $u$ 的子孙或 $u$ 本身。所以 $S \subseteq \text{子树}(u)$。又 $u \in S$ 由 $u$ 的定义。$\blacksquare$

**性质 2**：对 $u$ 的每个孩子 $v$，$S \cap \text{子树}(v)$ 要么是空，要么包含 $v$。

*证明*：设 $S \cap \text{子树}(v) \neq \varnothing$ 但不含 $v$。取 $w \in S \cap \text{子树}(v)$。$w$ 是 $v$ 的子孙（$w \in \text{子树}(v)$ 且 $w \neq v$，因为 $v \notin S$）。树中 $w$ 到 $u$ 的唯一路径为 $w \to \cdots \to v \to u$，其中 $v$ 在 $w$ 与 $u$ 之间。$S$ 连通 $\Rightarrow$ $w$ 与 $u$ 在 $S$ 内连通 $\Rightarrow$ 路径上所有节点在 $S$ 中 $\Rightarrow$ $v \in S$。与"不含 $v$"矛盾。$\blacksquare$

由性质 2，$S$ 的结构完全由"$u$ 的每个孩子 $v$ 在 $S$ 中保留几个节点"决定：

- 若 $S \cap \text{子树}(v) = \varnothing$，则边 $(u,v)$ 被砍，花费 1；
- 若 $|S \cap \text{子树}(v)| = k > 0$，则 $S \cap \text{子树}(v)$ 是一个含 $v$ 的连通块，$v$ 子树内部需要砍 $dp[v][k]$ 条边，边 $(u,v)$ 不砍，花费 $dp[v][k]$。

### 第 3 步：引出树形背包

**定义**：$dp[u][j]$ = 在 $u$ 的子树中，保留恰好 $j$ 个节点形成连通块（该连通块包含 $u$），需要砍掉 $u$ 子树**内部**边的最少数。

- $j \ge 1$：连通块含 $u$。
- $j = 0$：$u$ 子树中 0 个节点保留（$u$ 整棵子树被分离出去），$u$ 子树内部砍 0 条边。$dp[u][0] = 0$。

**初始化**：$dp[u][1] = 0$（只保留 $u$ 自己，尚未处理任何孩子，花费 0）。

**转移**（分组背包，每个孩子**必须**选一个 $k_v$）：

$$dp[u][j] = \min_{\substack{k_1+\cdots+k_d=j-1 \\ 0 \le k_i \le sz[v_i]}} \sum_{i=1}^{d}\big(k_i=0\ ?\ 1\ :\ dp[v_i][k_i]\big)$$

其中 $v_1,\ldots,v_d$ 是 $u$ 的所有孩子。

**实现**：用临时数组 $dp2$ 做分组背包（每组必选一个）：

```
dp[u][1] = 0, sz[u] = 1
for each child v of u:
    fill dp2[u][1..sz[u]+sz[v]] with inf
    for j from 1 to sz[u]:
        for k from 0 to sz[v]:
            dp2[u][j+k] = min(dp2[u][j+k], dp[u][j] + (k==0 ? 1 : dp[v][k]))
    dp[u][1..sz[u]+sz[v]] = dp2[u][1..sz[u]+sz[v]]
    sz[u] += sz[v]
```

> **为什么不能用 0/1 背包的降序原地更新？**
>
> 降序原地更新时，$k=0$ 产生 $dp[u][j] = \min(dp[u][j],\ dp[u][j]+1) = dp[u][j]$，旧值被保留，砍边花费 1 永远不被计入。具体地：假设 $u$ 有一个叶子孩子 $v$，$dp[u][1]$ 初始为 0（未处理任何孩子）。处理 $v$ 时 $k=0$ 应产生"砍 $(u,v)$ 边"的花费 1，即 $dp[u][1]$ 应变为 1，但 $\min(0, 0+1)=0$ 保留了旧值 0，砍边花费被吞掉。
>
> 必须用临时数组，让每个 $j$ 值只被"当前孩子"更新一次，避免旧状态污染新状态。

### 第 4 步：求答案

枚举连通块 $S$ 的最高节点 $u$（$S$ 恰含 $P$ 个节点 $\Leftrightarrow$ $P \le sz[u]$）：

- 若 $u$ 是根（$u=0$）：$S$ 与 $u$ 的祖先断开不需要额外砍边（根无父）。总砍边数 $= dp[u][P]$。
- 若 $u$ 不是根：必须砍边 $(u, \text{parent}(u))$ 使 $S$ 与 $u$ 的祖先断开。总砍边数 $= dp[u][P] + 1$。

$$\text{ans} = \min_{u:\ sz[u]\ge P}\ \big(dp[u][P] + [u\ne 0]\big)$$

### 第 5 步：正确性证明

**定理**：上述算法返回的答案等于"破坏最少边使图中存在恰含 $P$ 个节点的连通块"的最小边数。

*证明*：

**充分性**（算法给出的值是可行解的上界）：

对任意 $u$ 满足 $sz[u] \ge P$，$dp[u][P]$ 对应一种具体的边砍法：在 $u$ 子树内砍 $dp[u][P]$ 条边 + 砍 $(u,\text{parent}(u))$ 边（若 $u \ne 0$）。砍完后，$u$ 子树中保留的 $P$ 个节点形成连通块 $S$，且 $S$ 与 $u$ 的祖先断开（因为 $(u,\text{parent}(u))$ 被砍）。$S$ 恰含 $P$ 个节点。故算法给出的每个候选值都对应一个可行解。$\square$

**必要性**（任何可行解的边数 $\ge$ 算法给出的值）：

设最优解砍了 $m$ 条边，产生了恰含 $P$ 个节点的连通块 $S^*$。设 $u^*$ 是 $S^*$ 的最高节点。

- 由性质 1，$S^* \subseteq \text{子树}(u^*)$，$u^* \in S^*$。由性质 2，$S^*$ 对应 $u^*$ 的某个孩子分配方案 $(k_1,\ldots,k_d)$，满足 $\sum k_i = P-1$，$S^*$ 内部砍掉的边数 $\ge dp[u^*][P]$（$dp$ 是所有方案的最小值）。
- 若 $u^* \ne 0$：$S^*$ 是破坏后的连通块，故 $S^*$ 与 $u^*$ 的祖先不连通。$u^*$ 与其父的唯一通路是边 $(u^*,\text{parent}(u^*))$，该边必须被砍，贡献 1 条边。故 $m \ge dp[u^*][P] + 1$。
- 若 $u^* = 0$：根无父边，$m \ge dp[0][P]$。

两种情形都有 $m \ge dp[u^*][P] + [u^*\ne 0] \ge \text{ans}$（$\text{ans}$ 取所有 $u$ 的最小值，$u^*$ 是其中一个候选）。

结合充分性与必要性，$\text{ans} = m$。$\blacksquare$

### 复杂度

- **时间**：$O(n^2)$。树形背包中，节点 $u$ 处理孩子 $v$ 的代价为 $O(sz[u]\cdot sz[v])$，所有边的贡献之和 $\le n^2/4$（标准树形背包复杂度界）。
- **空间**：$O(n^2)$（$dp$ 和 $dp2$ 数组）。

## Part 3 · 模式总结

- **探索性质** — 砍 $k$ 条边 $\to$ $k+1$ 个连通块；每个连通块有唯一最高节点
- **刻画结构** — 最高节点的每个孩子在 $S$ 中要么全收要么全不收（性质 2 的连通性约束）
- **引出树形背包** — $dp[u][j]$ 保留 $j$ 个节点（含 $u$）砍 $u$ 子树内部边最少数
- **分组背包转移** — 每个孩子必选 $k_v \in [0, sz[v]]$；$k=0$ 砍边花费 1，$k>0$ 花费 $dp[v][k]$；用临时数组（不能用降序原地更新，$k=0$ 时 $\min$ 会吞掉砍边花费）
- **枚举最高节点求答案** — $\text{ans} = \min_u(dp[u][P] + [u\ne\text{root}])$
- **正确性** — 充分性（构造可行解）+ 必要性（最优解对应某个 $u$ 的分配方案）

## Part 4 · 真正解法

### 符号表

| 符号 | 含义 |
|------|------|
| $n, p$ | 节点数、目标连通块大小 |
| $ch[u]$ | $u$ 的邻居列表（无向图，`vector<int>` 数组） |
| $sz[u]$ | $u$ 子树的节点数（dfs 后计算） |
| $dp[u][j]$ | $u$ 子树中保留 $j$ 个节点（含 $u$，$j\ge 1$）形成连通块，砍 $u$ 子树内部边的最少数。初始化为 $\infty$，dfs 中 $dp[u][1]$ 设为 0 |
| $dp2[u][j]$ | 分组背包的临时数组，每次处理一个孩子前清零为 $\infty$ |
| $fa$ | dfs 的父节点参数，$-1$ 表示根 |
| $\infty$ | 哨兵值 $1145141919$ |

**记忆口诀**：$dp$ = 保留多少节点，花多少内部边；$dp2$ = 背包临时状态。

### 算法步骤

1. **读入**：读 $n, p$；读 $N-1$ 条边（父 子），建无向图 $ch$。下标 0-based（读入时 $--u;\ --v$）。
2. **初始化**：$dp[i][*]$ 和 $dp2[i][*]$ 全部填 $\infty$。
3. **dfs(0, -1)**：后序遍历，对每个节点 $u$：
   - $sz[u] = 1$，$dp[u][1] = 0$
   - 对每个孩子 $v$（$ch[u]$ 中 $\ne fa$ 的节点）：
     - 递归 dfs(v, u)
     - 清零 $dp2[u][1 \ldots sz[u]+sz[v]]$ 为 $\infty$
     - 背包转移：$dp2[u][j+k] = \min(dp2[u][j+k],\ dp[u][j] + (k ? dp[v][k] : 1))$
     - 复制 $dp[u] \leftarrow dp2[u]$，$sz[u] \mathrel{+}= sz[v]$
4. **求答案**：$\text{ans} = \min_{u:\ sz[u]\ge p} (dp[u][p] + (u ? 1 : 0))$
5. **输出** $\text{ans}$

### 复杂度

- 时间 $O(n^2)$，空间 $O(n^2)$
- $n \le 150$，$n^2 = 22500$，极快

### 验证状态

未编译验证。手工推演：

- $n=2, p=1$：树 0-1。$dp[1][1]=0$；$dp[0][1]=1$（砍 0-1 边），$dp[0][2]=0$（不砍）。$\text{ans} = \min(1+0, 0+1) = 1$。✓（砍 1 条边分离出 1 个节点）
- $n=2, p=2$：$\text{ans} = dp[0][2] = 0$。✓（不砍边，整树连通）
- $p=n$：只有 $u=0$ 满足 $sz[u]\ge n$，$\text{ans} = dp[0][n] = 0$。✓（整树即连通块，不砍边）
- 样例 $n=8, p=5$：推演得 $dp[0][5]=1$，$\text{ans}=1$。✓

## Part 5 · 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{155};
constexpr int inf{1145141919};

int n,p,sz[mxn],dp[mxn][mxn],dp2[mxn][mxn];
vector<int>ch[mxn];

void dfs(int u,int fa)
{
	sz[u]=1;
	dp[u][1]=0;
	for(int v:ch[u])
		if(v!=fa)
		{
			dfs(v,u);
			// 分组背包：每个孩子必选一个 k，不能用降序原地更新
			for(int j=1;j<=sz[u]+sz[v];++j)
				dp2[u][j]=inf;
			for(int j=1;j<=sz[u];++j)
				for(int k=0;k<=sz[v];++k)
					dp2[u][j+k]=min(dp2[u][j+k],dp[u][j]+(k?dp[v][k]:1));
			for(int j=1;j<=sz[u]+sz[v];++j)
				dp[u][j]=dp2[u][j];
			sz[u]+=sz[v];
		}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>p;
	for(int i=1,u,v;i<n;++i)
	{
		cin>>u>>v;--u;--v;
		ch[u].push_back(v);
		ch[v].push_back(u);
	}

	for(int i=0;i<n;++i)
		fill_n(dp[i],n+1,inf);
	for(int i=0;i<n;++i)
		fill_n(dp2[i],n+1,inf);

	dfs(0,-1);

	int ans=inf;
	for(int i=0;i<n;++i)
		if(sz[i]>=p)
			ans=min(ans,dp[i][p]+(i?1:0));
	cout<<ans<<'\n';
	return 0;
}
```
