# P1842 [USACO05NOV] 奶牛玩杂技

> 难度：普及/提高- · 标签：贪心，USACO

## 1. 重新读题
### 1.1 问题重述（人话版）
$N$ 头牛叠成一摞。牛 $i$ 体重 $W_i$、力量 $S_i$。她的压扁指数 $=$ 她上面所有牛的体重之和 $-$ 她自己的力量（可以是负数）。这一摞的总压扁指数是所有牛里最大的那个压扁指数。求一种上下顺序，使这个最大值最小。

### 1.2 关键约束与规模暗示
$N\le 5\times 10^4$，所以 $O(N\log N)$ 排序可以，$O(N!)$ 只够 $N\le 7$ 左右对拍。$W_i\le 10^4$，体重和最大约 $5\times 10^8$；$S_i\le 10^9$，压扁指数可能是很大的负数。答案要用 64 位整数，而且初值不能设成 0。

## 2. 思维链（Chain-of-thought）
只看两头相邻的牛，试着交换她们，看最大值会不会变好。这是发现排序键的办法。

设某一段上面已经压了总重 $U$，紧挨着的两头是 $P$ 在上、$Q$ 在下，其余牛不动。交换只影响这两头的压扁指数：

- 交换前：$P$ 为 $U-S_P$，$Q$ 为 $U+W_P-S_Q$；
- 交换后：$Q$ 为 $U-S_Q$，$P$ 为 $U+W_Q-S_P$。

**引理 1**：若 $W_P+S_P>W_Q+S_Q$，则交换后这两头的压扁指数都严格小于交换前 $Q$ 的压扁指数。因此这两头的最大值不会变大，其它牛完全不变，整摞的最大值不会变大。

证明：交换前 $Q$ 的值是 $U+W_P-S_Q$。交换后 $P$ 的值是 $U+W_Q-S_P$。两者相减：

$$
(U+W_P-S_Q)-(U+W_Q-S_P)=(W_P+S_P)-(W_Q+S_Q)>0.
$$

所以交换后 $P$ 的指数 $<$ 交换前 $Q$ 的指数。交换后 $Q$ 的指数是 $U-S_Q$，而交换前 $Q$ 是 $U+W_P-S_Q$，因为 $W_P\ge 1$，前者更小。于是交换后两个数都 $<$ 交换前的 $\max(P,Q)$（这个 max 至少是 $Q$ 的那个数）。其它位置的「上面体重」没变，指数不变。整摞最大值不会上升。$\square$

**引理 2**：存在一个最优顺序，从上到下 $W_i+S_i$ 非严格递增。

证明：取任意最优顺序。只要有相邻逆序对 $W_P+S_P>W_Q+S_Q$（$P$ 在 $Q$ 上面），引理 1 允许交换，最大值不升，仍然最优。每次交换减少逆序数，有限步后得到从上到下按 $W+S$ 非降的最优顺序。相等时交换不改变引理 1 里那个差（差为 0，最大值同样不升），所以相等的牛谁上谁下都行。$\square$

**定理**：把牛按 $W_i+S_i$ 从小到大排序，从上到下叠好，算出来的最大压扁指数就是答案。

证明：由引理 2，最优解可以选成这个顺序（相等时任意 tie-break 都还能保持最优）。标程按这个顺序做一遍，得到的最大值等于该最优顺序的总压扁指数。$\square$

注意最上面那头的指数是 $0-S_i$，可能是整个答案（下面的牛力量更大、指数更负）。所以 `ans` 要初始化成很小的数，不能初始化成 0。样例三头牛的 $W+S$ 分别是 $13,7,6$，排序后从上到下是 $(W,S)=(3,3),(2,5),(10,3)$，指数依次为 $-3,-2,2$，最大值 $2$，与样例一致。

暴力对 $N\le 7$ 枚举全部排列，每个排列 $O(N)$ 算最大压扁指数再取最小。这是定义本身，不使用排序键，用来确认交换论证没有把负数情况算错。

## 3. 模式总结（Pattern Summary）
- **explore its property** — 总指标是「最大压扁指数」，只关心最惨的那一头。
- **consider easier version** — 先只看相邻两头，写出交换前后的四个数。
- **classic problem solution** — 逆序就交换且最大值不升，所以按 $W+S$ 从轻到重、自上而下排序。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `c[i].w, c[i].s` | `int`，共 `50005` | 体重、力量 | 读入 | cow |
| `above` | `i64` | 当前这头上面的体重和 | 0 | above |
| `ans` | `i64` | 最大压扁指数 | $-10^{18}$ | answer |

$W+S\le 10^9+10^4$，放进 32 位有符号整数不会溢出，排序键直接相加。

### 4.2 算法步骤
1. 读入 $N$ 头牛，按 $w+s$ 升序排序。排序后的顺序就是从上到下。
2. `above=0`。对每头牛，用 `above-s` 更新 `ans`，然后 `above+=w`。
3. 输出 `ans`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）
时间 $O(N\log N)$，空间 $O(N)$。`g++ -O2 -std=c++17 -Wall -Wextra -Werror` 无警告。与全排列暴力对拍 127 组（含样例答案 `2`，以及 $N=1,W=5,S=10$ 时期望 `-10`；$N\le 7$，力量取到 $10^9$），checker 墙钟 3.070s。最大数据 $N=5\times 10^4$ 随机，标程 0.012s。

## 5. 示例代码
### 5.1 标程（`P1842.cpp`）

```cpp
//
// 题目：P1842 [USACO05NOV] 奶牛玩杂技
// https://www.luogu.com.cn/problem/P1842
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{50005};

struct cow
{
	int w,s;
}c[mxn];

bool cmp(cow a,cow b)
{
	return a.w+a.s<b.w+b.s;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	int n;
	cin>>n;
	for(int i=0;i<n;++i)
		cin>>c[i].w>>c[i].s;
	sort(c,c+n,cmp);
	i64 above=0,ans=-(i64)1e18;
	for(int i=0;i<n;++i)
	{
		ans=max(ans,above-c[i].s);
		above+=c[i].w;
	}
	cout<<ans<<'\n';
	return 0;
}
```
