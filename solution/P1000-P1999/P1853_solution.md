# P1853 [NWERC 2004] 投资的最大效益

> 难度：普及/提高- · 标签：背包 DP，完全背包

## 1. 重新读题
### 1.1 问题重述（人话版）
约翰有本金 $s$，要投资 $n$ 年。有 $d$ 种债券，第 $i$ 种每买一份占用本金 $a_i$，这一年支付利息 $b_i$。同一年可以买很多份，只要占用的本金之和不超过当年的总资产。本金没有被花掉，年底总资产变成「原来的总资产 $+$ 利息」，下一年可以全部重新分配。求 $n$ 年后的最大总资产。

样例 $s=10000,n=4$，债券 $(4000,400)$ 与 $(3000,250)$。最优是第一年利息 $900$ 得到 $10900$，第二年仍是 $900$ 得到 $11800$，第三年 $1050$ 得到 $12850$，第四年 $1200$ 得到 $14050$。

### 1.2 关键约束与规模暗示
$s\le 10^6$，$2\le n\le 40$，$d\le 10$，$a_i$ 是 $1000$ 的倍数且 $a_i\le 10^4$，$b_i$ 不超过 $a_i$ 的 $10\%$。利息最多是本金的 $10\%$，所以 $40$ 年后总资产不超过

$$
s_{0}=10^6,\qquad s_{k+1}=s_k+\left\lfloor\frac{s_k}{1000}\right\rfloor\cdot 100,
$$

算出来是 $45244600$。若按「原始金额」做完全背包，容量大约 $4.5\times 10^7$，再乘 $40$ 年，会超时也会开不下数组。必须利用「$a_i$ 都是 $1000$ 的倍数」。

## 2. 思维链（Chain-of-thought）
**引理 1**：某一年在总资产 $S$ 下能拿到的最大利息，等于在容量 $\lfloor S/1000\rfloor$ 上、物品重量 $a_i/1000$、价值 $b_i$ 的完全背包最优值。年末资产是 $S$ 加上这个利息。

证明：一份债券占用 $a_i$，而每个 $a_i$ 都是 $1000$ 的倍数，所以任何购买方案占用的本金是 $1000$ 的倍数，不能动用 $S\bmod 1000$ 这点零头。能用的单位个数就是 $\lfloor S/1000\rfloor$。每种债券可以买任意非负份数，正是完全背包。利息是各份 $b_i$ 之和，本金在年底全部还在，所以新资产 $=S+\text{利息}$。题面允许每年卖掉重买，因此下一年只保留这个新的 $S$，不保留去年的购买方案。$\square$

**引理 2**：债券集合不随年份变化，所以「容量为 $c$ 个千元单位时的最大利息」$f(c)$ 每年相同，只算一次即可。$b_i\ge 1$，因此 $f$ 随 $c$ 不降，当年应取 $f(\lfloor S/1000\rfloor)$，而不是强迫把容量用满到某一个特定物品上。

证明：完全背包的物品与容量上限无关，只和有哪些物品有关。标准转移

$$
f(j)=\max\bigl(f(j),\, f(j-w_i)+b_i\bigr),\qquad j\ge w_i,
$$

正序循环时 $f(j-w_i)$ 已经可以含有多份第 $i$ 种，得到的是「总重量不超过 $j$」的最大价值（少买一份总是被 $\max$ 保留，因为价值非负，空方案是 $0$）。所以查 $f(\lfloor S/1000\rfloor)$ 就是引理 1 的最优利息。$\square$

**引理 3**：每千元单位的利息最多 $100$（因为 $b_i\le a_i/10$，而 $a_i/1000$ 份千元对应的利息 $\le 100\cdot(a_i/1000)$）。因此 $\lfloor S/1000\rfloor$ 在 $40$ 年内不会超过 $45244$。数组开到 $50005$ 覆盖全部年份，不必按年把容量开到 $4.5\times 10^7$。

证明：对任意方案，利息 $\le \sum (a_i/10)\cdot c_i=(1/10)\sum a_i c_i\le S/10$，而且由于占用必须是千元的倍数，更紧的上界是 $\lfloor S/1000\rfloor\cdot 100$。从 $S=10^6$ 迭代 $40$ 次 $S\leftarrow S+\lfloor S/1000\rfloor\cdot 100$，得到 $45244600$，对应容量 $45244<50005$。实际 $b_i$ 不会比这个上界更赚，所以真实容量更小，数组够用。$\square$

**定理**：先对所有 $c\le 45244$ 求出 $f(c)$，然后重复 $n$ 年 $S\leftarrow S+f(\lfloor S/1000\rfloor)$，$S$ 就是 $n$ 年后的最大总资产。

证明：对年份归纳。第 1 年之前资产是输入的 $s$，引理 1、2 给出最大利息。归纳假设第 $k$ 年开始时 $S$ 已经是前 $k-1$ 年的最优资产，则这一年的最大利息仍然只取决于这个 $S$，引理 1 的背包与历史购买无关。$n$ 年之后即为所求。引理 3 保证查表不越界。$\square$

样例容量序列：$\lfloor 10000/1000\rfloor=10$。一份 $(4,400)$ 与两份 $(3,250)$ 的价值 $900$，两份 $(4,400)$ 只有 $800$，所以 $f(10)\ge 900$。一年后至少 $10900$。按标程跑满 4 年得到 $14050$，与样例和题面叙述一致。另有一个手算：只有债券 $(1000,100)$、$s=1000$、$n=2$，每年利息 $100$，答案 $1200$。

暴力不建 $f$ 数组。每年对每种债券枚举购买份数，深搜所有可行组合，取最大利息。$d\le 3$、本金几千、每件至少 $1000$ 时分支很少。它枚举的是引理 1 的同一个整数可行域，所以和小容量完全背包最优值相同。全数据 $d=10,s=10^6$ 不能这么搜，只用来对小数据。

不能把「每年对当前 $S$ 做一遍容量为 $S$ 的朴素完全背包」当标程：$S$ 会涨到 $4\times 10^7$，40 年的转移次数远超时限。除以 $1000$ 之后只剩大约 $4.5\times 10^4$ 个容量，而且只做一次背包。

## 3. 模式总结（Pattern Summary）
- **explore its property** — 本金不消耗，每年只是把利息加回去再重新分配；零头 $S\bmod 1000$ 买不了任何债券。
- **reduce to easier problem** — 重量全部除以 $1000$，一年的决策变成容量 $\lfloor S/1000\rfloor$ 的完全背包。
- **classic problem solution** — 物品不变，$f(c)$ 算一次，然后逐年 $S\leftarrow S+f(\lfloor S/1000\rfloor)$。
- **discuss by category** — 小数据用枚举份数的深搜对拍；全数据靠 $10\%$ 利率证明容量 $\le 45244$，避免按原始金额开数组。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `money` | `i64` | 当前总资产 | 输入的 $s$ | capital |
| `yr` | `int` | 年数 $n$ | 读入 | years |
| `d` | `int` | 债券种数 | 读入 | kinds |
| `w[i]` | `int` | $a_i/1000$ | 读入后除以 1000 | weight |
| `v[i]` | `int` | 年利息 $b_i$ | 读入 | value |
| `f[j]` | `int[50005]` | 容量 $j$ 个千元单位的最大利息 | 全局 0 | knapsack |

### 4.2 算法步骤
1. 读入每种债券，`w[i]/=1000`。
2. 对每种债券，`j` 从 `w[i]` 正序扫到 `50004`，用 `f[j-w[i]]+v[i]` 更新 `f[j]`。
3. 重复 `yr` 年：`money += f[money/1000]`。
4. 输出 `money`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）
背包 $O(d\cdot 5\times 10^4)=O(5\times 10^5)$，每年只做一次数组查询，总时间可以忽略年数。空间 $O(5\times 10^4)$。`g++ -O2 -std=c++17 -Wall -Wextra -Werror` 无警告。与「按份数深搜」对拍 55 组（含样例 `14050`、手算 `1000` 元两年得 `1200`；$d\le 3$、本金 $\le 8000$、年数 $\le 4$），checker 墙钟 2.701s。最大数据 $s=10^6,n=40,d=10$，且含债券 $(1000,100)$，标程 0.002s，答案 `45244600`，与引理 3 的利率上界重合（此时每年都能把全部千元单位按 $10\%$ 投满）。

## 5. 示例代码
### 5.1 标程（`P1853.cpp`）

```cpp
//
// 题目：P1853 [NWERC 2004] 投资的最大效益
// https://www.luogu.com.cn/problem/P1853
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxc{50005};
constexpr int mxd{15};

int d,w[mxd],v[mxd],f[mxc];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	i64 money;
	int yr;
	cin>>money>>yr>>d;
	for(int i=0;i<d;++i)
	{
		cin>>w[i]>>v[i];
		w[i]/=1000;
	}
	for(int i=0;i<d;++i)
	{
		for(int j=w[i];j<mxc;++j)
		{
			int nv=f[j-w[i]]+v[i];
			if(nv>f[j])
				f[j]=nv;
		}
	}
	for(int y=0;y<yr;++y)
	{
		int cap=(int)(money/1000);
		money+=f[cap];
	}
	cout<<money<<'\n';
	return 0;
}
```
