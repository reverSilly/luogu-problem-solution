# P1412 经营与开发

> 标签：动态规划 DP / 贪心 · 难度：普及/提高- · 福建省历届夏令营

## 1. 重新读题

**问题重述（简化版）**

飞船按固定顺序飞过 $n$ 个星球，钻头能力值记为 $p$，进入第 $1$ 个星球时 $p=w$。对每个星球，舰长独立地决定"动手"或"跳过"：

| 星球类型 | 参数 | 动手的收益 | 动手后 $p$ 的变化 |
|---|---|---|---|
| 1 资源型 | 矿物量 $a_i$ | $+a_i\times p$ | $p\leftarrow p\times(1-0.01k)$ |
| 2 维修型 | 维护费 $b_i$ | $-b_i\times p$ | $p\leftarrow p\times(1+0.01c)$ |

跳过则收益为 $0$、$p$ 不变。**目标**：最大化 $\sum(\text{收支})$。注意"金钱可以透支"，所以过程中间账户余额没有任何下限约束，只剩纯粹的最大化问题。

**输入输出**：第一行四个整数 $n,k,c,w$；随后 $n$ 行每行 `type x`（`type=1` 时 $x=a_i$，`type=2` 时 $x=b_i$）。输出一个保留 2 位小数的实数。

**数据范围与子任务（提示复杂度）**

| 数据范围 | 规模 / 特殊值 | 暗示 |
|---|---|---|
| 30% | $n\le 100$ | 允许 $O(n^3)$ 的多维状态前缀 DP |
| 另 20% | $n\le 1000,\ k=100$ | $d=1-0.01k=0$，能力值"一次性" |
| 100% | $n\le 10^5$，$0\le k,c,w,a_i,b_i\le100$，答案 $\le 10^9$ | 必须 $O(n)$，且值域极小、结果有界 |

值域 $\le 100$ 却要求 $n\le10^5$，说明"枚举 $p$ 的具体数值"绝无出路；"答案 $\le10^9$"则是后面精度分析的救命条件。

**陷阱与边界**

1. $w=0$：$p$ 只能被乘，永远回不到正数，所有收支都是 $0$，答案恰为 $0.00$。
2. $k=0$：$d=1$，开采**无代价**，所有资源型星球必采。
3. $c=0$：$u=1$，维修花钱买不到任何提升（$b>0$ 时必不修，$b=0$ 时修不修等价）。
4. $k=100$：$d=0$，一次开采把 $p$ 永久清零，此后再无任何收益。
5. $a_i=0$ 或 $b_i=0$：边界决策，容易被"严格大于"写错而少答案（本题取等不影响最大值）。
6. 维修后 $p$ **可以超过** $w$，不能想当然地给 $p$ 加上限。
7. $n=1$：全场只有一个决策，是检验转移式子最短的试纸。
8. 本地题面**没有样例**，无法与官方答案对标，只能用自造数据手算校验。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：$p$ 只被"乘"，从不被"加"

先把两个乘数起名字，后面不再写百分号：

$$d=1-0.01k\in[0,1]\quad(\text{损耗系数}),\qquad u=1+0.01c\in[1,2]\quad(\text{修复系数}).$$

设我按顺序选了若干个星球去"动手"，第 $t$ 次动手前能力值是 $p_t$。每次动手只可能给 $p$ 乘一个 $d$ 或一个 $u$，而"跳过"什么都不做，于是

**引理 1（$p$ 的闭式表达）**：任何时候 $p=w\,d^{m}\,u^{r}$，其中 $m$ 是此前已开采的星球数、$r$ 是此前已维修的星球数。特别地 $p\ge 0$ 恒成立。

**证明**：对处理过的星球个数做归纳。基例：进入第 1 个星球前 $m=r=0$，$p=w\cdot d^0u^0=w$，成立。归纳步：设当前 $p=w d^m u^r$。跳过时 $(m,r)$ 不变，$p$ 不变，命题保持；开采时 $(m,r)\to(m+1,r)$ 且 $p\to p\cdot d=w d^{m+1}u^{r}$；维修时 $(m,r)\to(m,r+1)$ 且 $p\to p\cdot u=w d^{m}u^{r+1}$。三种情况都把指数同步加到闭式里，故命题保持。又 $w\ge0$、$d\ge0$、$u\ge0$，三者之积非负，故 $p\ge0$。$\blacksquare$

**引理 2（一笔收支的展开式）**：若第 $i$ 个星球被选中动手，其结算金额是 $\pm x_i\cdot w\,d^{m_i}u^{r_i}$，其中 $m_i,r_i$ 是**在它之前**被开采/维修的星球个数，$x_i$ 为 $a_i$（符号取 $+$）或 $b_i$（符号取 $-$）。

**证明**：直接由引理 1，第 $i$ 个星球动手时刻的能力值就是 $w d^{m_i}u^{r_i}$，而题面定义收支为 $x_i\times p$。$\blacksquare$

**关键观察（齐次结构的萌芽）**：引理 2 里，$i$ 这个星球贡献的金额 = $\big(x_i\,d^{m_i}u^{r_i}\big)\cdot w$。括号内**只和"选哪些星球、按什么顺序"有关，与 $w$ 无关**。也就是说：把初始能力 $w$ 换成 $2w$，每一个固定决策方案的总金额恰好翻倍——因为每个 $p$ 都翻倍、每笔收支都按 $p$ 线性结算。

> 这个"方案值 $\propto$ 起始 $p$"的事实，是后面把连续状态消掉的唯一支点；先记住它，但先别用，因为我需要 $p$ 是"任意非负实数"而非只有起点一个值。

还要注意一个反面事实：$d^{m}u^{r}$ 中 $(m,r)$ 可达 $O(n^2)$ 种，而 $m_i,r_i$ 的历史又依赖"前 $i-1$ 个星球选了哪些"，所以**决策数多达 $2^n$**。这解释了为什么必须找结构而不是搜索。

### 2.2 简化版：把某个参数钉死

**版本 A：$c=0$（不许维修，只允许开采）**。此时 $u=1$，维修型星球动手是"纯付钱换不变的能力"，必不划算。问题退化成：选一个开采子集 $S$，最大化 $w\sum_{i\in S}a_i d^{|S\cap[1,i-1]|}$。

**引理 3（$c=0,\ k=0$ 时全采最优）**：若同时 $k=0$（$d=1$），则最优方案是"开采所有资源型星球，跳过所有维修型星球"，答案 $=w\sum_{\mathrm{type}_i=1}a_i$。

**证明**：$d=1$ 时开采不改变 $p$（$p\equiv w$），由引理 2 每个被开采的星球独立贡献 $a_i w\ge0$，贡献之间不再耦合（指数恒为 $0$）。所以采与不采是"加 $a_iw$ 或加 $0$"的逐点比较，全部取大者即最优。维修型动手贡献 $-b_iw\le0$ 且对 $p$ 无影响（$u=1$），一律跳过。$\blacksquare$

这个特例告诉我们：**耦合完全来自"乘数不等于 1"**。$d=1$ 时问题可分离、贪心显然成立；$d<1$ 时开采之间互相拖累。

**版本 B：$k=100$（对应第二个子任务）**，此时 $d=0$。

**引理 4（$d=0$ 时最多一次有效开采）**：若开采过至少一个星球，则此后 $p=0$，之后任何动作的收支都是 $0$。因此总额只由**第一个**被开采的星球以及它之前的维修决策决定。

**证明**：由引理 1，开采一次后 $m\ge1$，$p=w d^{m}u^{r}=w\cdot 0\cdot u^{r}=0$。此后维修把 $0$ 乘成 $0\cdot u=0$，开采把 $0$ 乘成 $0\cdot d=0$，故 $p$ 永久为 $0$；再由引理 2，每笔后续收支都是 $\pm x_i\cdot 0=0$。$\blacksquare$

于是 $k=100$ 时可以"枚举第一次开采落在哪个星球 $i$"：总额形如 $a_i\cdot(\text{在 }i\text{ 之前若干次维修后的 }p)-(\text{这些维修的花费})$。可见**即使钉死 $k$，"维修链值不值"仍需判断**，简化版并没有直接给出答案，只是暴露出：真正难的是"某次动作对后续 $p$ 的影响值多少钱"。

**版本 C：不钉参数，硬做前缀 DP（对应 30% 的 $n\le100$）**

由引理 1，处理完某前缀后 $p$ 的**数值只由 $(m,r)$ 决定**，与"具体选了哪几个"无关。于是设 $g[m][r]=$ 处理完前 $i$ 个星球、共开采 $m$ 次、维修 $r$ 次时的最大金额，转移就是"跳过 / 动手"两条分支。状态数 $O(n^2)$，但每加入一个星球都要重刷一张 $O(i^2)$ 的表，总计 $O(n^3)$：$n=100$ 时约 $10^6$ 可行，$n=10^5$ 时 $10^{15}$ 完全不可行。

> 卡点在这里：$p$ 的取值只有 $O(n^2)$ 个，看似不多，却必须把"前缀"这一维留在状态里，钱与位置搅在一起。**能不能干脆不看前缀、只看后缀？能不能不把 $p$ 当状态？** 这是 2.4 的入口。

### 2.3 剖析贪心失败

先说一个限制：路线是"按既定路线依次飞过"，**星球顺序不可交换**，能选的只有"每个星球动不动手"。所以常规的"交换相邻两个动作看谁优"的改动型贪心根本无从下手——这一点必须先承认。

**贪心 G1（眼前为正就干）**：`type=1 且 a_i>0 就开采，type=2 一律不修`。
数据：$n=2,k=100,c=0,w=1$，星球依次为 $(1,1)$、$(1,100)$。

- G1 的结果：开采星球 1 得 $1\times1=1$，$p\leftarrow1\times0=0$；开采星球 2 得 $100\times0=0$。合计 $1$。
- 更好的方案：跳过星球 1（保住 $p=1$），开采星球 2 得 $100\times1=100$。合计 $100$。
- G1 亏掉 $99$。**病因**：它把"$a_i>0$"当成收益为正的依据，却忘了开采真正的代价是把**后面所有星球的结算倍率**乘上 $d$。

**贪心 G2（只挖最大的那一个）**："$d=0$ 时按引理 4 最多挖一个，那就挑 $a_i$ 最大的"。
数据：$n=2,k=50,c=0,w=1$，星球 $(1,1)$、$(1,1)$。

- G2 的结果：只挖一个，得 $1\times1=1$。
- 两个都挖：$1\times1+1\times0.5=1.5>1$。
- **病因**：$d$ 只是**部分**损耗，损耗到 0 才"作废"，$d\in(0,1)$ 时多挖几次的边际收益仍然为正。G2 将 $k=100$ 的直觉错误地推广到 $k<100$。

**贪心 G3（倒序扫描，"后面没星球了，随便损耗"）**：从最后一个星球往前看，觉得"越靠后的动作越不影响别人，所以 $a_i>0$ 就采"。
用 2.3 里 G1 的同一组数据倒序走一遍：星球 2 采（贡献 $100$），轮到星球 1 时按 G3 也采（贡献 $1$），但采星球 1 会把 $p$ 清零，而**被清零的 $p$ 正是刚才已经决定要用的星球 2 的倍率**——损失 $100$。
- **病因**：动作 $i$ 的代价落在**它之后**的星球上；倒序扫描时那些星球"已经定好了"，贪心看不到这份负债。

**三个反例的共同缺口**：每个动作都会以"乘性"方式改变同一个量 $p$，而 $p$ 的价值取决于**后面还有哪些星球会被它影响**。要正确决策，只缺一个数字：

> **此刻的 1 点能力值，在未来一共值多少钱？** 记这个"单价"为 $f$，则开采星球 $i$ 的净账是
> $a_i$ （立刻拿到，按当前 $p$ 折算）$-$ $(1-d)f$ （被损耗掉的那部分能力按单价折价）。

这正是 2.4 的转移式，$f$ 会被证明恰好等于"后缀最优值 $\div$ 当前 $p$"。

### 2.4 经典解法：后缀 DP + 齐次性提系数

**定义**：$V_i(p)\equiv$ 从第 $i$ 个星球开始（$1\le i\le n+1$）、进入第 $i$ 个星球时能力值为 $p$，之后采用最优决策能获得的**最大净收入**。约定 $V_{n+1}(p)\equiv0$（没有星球了）。原问题是求 $V_1(w)$。

状态里 $p$ 是连续量，本来没法存。但 2.1 的"方案值 $\propto$ 起始 $p$"暗示：$V_i$ 可能是 $p$ 的一次齐次函数。

**引理 5（齐次性 / 值函数是过原点的直线）**：对一切 $i$ 和 $p\ge0$，$V_i(p)=p\cdot V_i(1)$。记 $f_i\equiv V_i(1)$，则 $V_i(p)=p f_i$。

**证明**（对 $i$ 从大到小归纳）：

*基例*：$i=n+1$。$V_{n+1}(p)=0=p\cdot0=p\,V_{n+1}(1)$，成立。

*归纳步*：设对 $i+1$ 已证 $V_{i+1}(q)=q f_{i+1}$ 对所有 $q\ge0$ 成立。在第 $i$ 个星球只有两种选择：

1. **跳过**：金额 $+0$，$p$ 不变仍为 $p$，后缀最优值 $=V_{i+1}(p)=p f_{i+1}$（用归纳假设）。
2. **动手**：设该类星球的金额为 $s_i p$（资源型 $s_i=+a_i$，维修型 $s_i=-b_i$），倍率 $t_i$（资源型 $t_i=d$，维修型 $t_i=u$）。动手后能力为 $t_i p\ge0$（因 $t_i\ge0,\,p\ge0$），故可用归纳假设：后缀值 $=V_{i+1}(t_i p)=t_i p f_{i+1}$，合计 $s_i p+t_i p f_{i+1}$。

取两者较大：
$$V_i(p)=\max\big(p f_{i+1},\; s_i p+t_i p f_{i+1}\big)=\max\big(p\cdot f_{i+1},\; p\cdot(s_i+t_i f_{i+1})\big).$$
由 $p\ge0$，$\max(pA,pB)=p\max(A,B)$ 成立（若 $p=0$ 两边都是 $0$；若 $p>0$ 两边同除 $p$ 不改变大小关系）。于是
$$V_i(p)=p\cdot\max\big(f_{i+1},\; s_i+t_i f_{i+1}\big).$$
定义 $f_i\equiv\max\big(f_{i+1},\,s_i+t_if_{i+1}\big)$。再把上面这条推导里的 $p$ 换成 $1$（$1>0$，满足推导用到的每一个前提），得到 $V_i(1)=1\cdot\max(f_{i+1},s_i+t_if_{i+1})=f_i$，所以 $V_i(p)=p\,f_i=p\,V_i(1)$。归纳步完成。$\blacksquare$

**引理 6（转移式，本体的 DP）**：$f_{n+1}=0$，且倒序地

$$f_i=\begin{cases}\max\big(f_{i+1},\;a_i+d\,f_{i+1}\big),&\mathrm{type}_i=1\\[2mm]\max\big(f_{i+1},\;-b_i+u\,f_{i+1}\big),&\mathrm{type}_i=2\end{cases}$$

答案 $=V_1(w)=w f_1$。

**证明**：把 $p=1$ 代入引理 5 推导过程中的 $V_i(p)=\max(pf_{i+1},\,s_ip+t_ipf_{i+1})$ 即得 $f_i=\max(f_{i+1},\,s_i+t_if_{i+1})$，代回 $s_i,t_i$ 的定义即两类式子。答案由引理 5 取 $i=1,p=w$。$\blacksquare$

**引理 7（阈值型决策 / 影子价格解释）**：记 $f_{i+1}$ 为"1 点能力值在未来值 $f_{i+1}$ 元"。则

- 资源型星球 $i$ 应当开采 $\iff a_i\ge 0.01k\cdot f_{i+1}$；
- 维修型星球 $i$ 应当维修 $\iff b_i\le 0.01c\cdot f_{i+1}$。

**证明**：资源型：开采优于跳过 $\iff a_i+d f_{i+1}\ge f_{i+1}\iff a_i\ge(1-d)f_{i+1}$。而 $1-d=1-(1-0.01k)=0.01k$，代入即得第一个等价式（$k=0$ 时右端为 $0$，而 $a_i\ge0$，恒开采，与引理 3 一致）。维修型：维修优于跳过 $\iff -b_i+uf_{i+1}\ge f_{i+1}\iff b_i\le(u-1)f_{i+1}=0.01c\,f_{i+1}$。两式都是把 $\max$ 的两个候选做差后移项得到，等价性由加减常数不改变不等号方向保证。$\blacksquare$

引理 7 的经济学读法：开采要付出 $(1-d)$ 份能力，这份能力按未来单价 $f_{i+1}$ 计价后才和 $a_i$ 可比；维修是用 $b_i$ 元"买" $(u-1)$ 份能力，只有买价低于单价才划算。这恰好补上 2.3 里三个贪心共同缺失的那一项。

### 2.5 归约到更简单的问题

到此，原题被归约成一个**一维标量递推**：从 $f\leftarrow0$ 出发，倒序执行 $n$ 次"$f\leftarrow\max(f,\ \pm x_i+\mathrm{mul}_i f)$"。这已经没有"选择子集"的组合味道，只剩一次函数取 max，和"汇率换汇"式的递推同构。

**引理 8（$f$ 单调有界，可用滚动标量）**：$f_1\ge f_2\ge\cdots\ge f_n\ge f_{n+1}=0$，特别地所有 $f_i\ge0$ 且 $f_1=\max_i f_i$；因为 $f_i$ 只用到 $f_{i+1}$，整个 DP 只需一个变量。

**证明**：由引理 6，$f_i=\max(f_{i+1},\,\cdot)\ge f_{i+1}$，倒序对 $i=n,n-1,\dots,1$ 逐条应用即得 $f_1\ge f_2\ge\cdots\ge f_{n+1}=0$。非负性：$f_{n+1}=0\ge0$，且若 $f_{i+1}\ge0$ 则 $f_i\ge f_{i+1}\ge0$。"$f_i$ 只依赖 $f_{i+1}$"说明状态可以滚动成一个标量（内存 $O(1)$），但因为要倒序处理，输入的 $n$ 对 `(type,x)` 必须先存下来，总内存 $O(n)$。$\blacksquare$

**引理 9（与两个简化版的一致性检验）**

- 取 $k=100$（$d=0$）：资源型转移变成 $f_i=\max(f_{i+1},\,a_i)$，即"后缀最大值"；若全场只有资源型星球，$f_1=\max_i a_i$，答案 $=w\max_i a_i$，与引理 4"最多一次有效开采、挑 $a$ 最大的那个"完全吻合。
- 取 $c=0$（$u=1$）：维修型转移变成 $f_i=\max(f_{i+1},\,f_{i+1}-b_i)=f_{i+1}$（$b_i\ge0$），维修永不改变 $f$，与"维修纯亏"一致；$b_i=0$ 时两候选相等，取不取都不影响最大值，所以实现里写 $\max$ 或写"严格 $>$ 才更新"都正确。

这两条一致性说明递推没有把边界情形算反，是"公式对不对"的第一道免费检查。

**为什么倒序而不是正序**：动作 $i$ 的代价落在**它之后**的星球上，正序时那些星球还没决定，代价无法计价；倒序时后缀已经合并成单价 $f_{i+1}$，代价 $(1-d)f_{i+1}$ 立即可量化。这就是 2.3 里 G3 失败而 2.4 成功的根本原因。

### 2.6 溢出与精度防护

**引理 10（$w\ge1$ 时数值有界，不会溢出）**：若 $w\ge1$，则 $f_1=\dfrac{\text{答案}}{w}\le 10^9$，且所有 $f_i\le f_1$，因此递推全程落在 `double`/`long double` 的安全区。

**证明**：题面保证答案 $\le10^9$，由引理 6 答案 $=wf_1$，故 $f_1\le10^9/w\le10^9$。再由引理 8 的 $f_i\le f_1$，每个中间量都不超过 $10^9$，远在 $10^{300}$ 量级的浮点上界之下。$\blacksquare$

**引理 11（$w=0$ 时 $f$ 可以指数爆炸，必须特判）**：存在合法数据使 $f_1$ 超出 `long double` 表示范围，而答案本身是 $0$。

**证明（构造）**：$n=10^5$，$k=0$（$d=1$），$c=100$（$u=2$），$w=0$；前 $99999$ 个星球全是 $(2,0)$（免费维修），最后一个是 $(1,1)$。倒序递推：$f_{10^5+1}=0$，$f_{10^5}=\max(0,1+1\cdot0)=1$；此后每个免费维修星球给出 $f_i=\max(f_{i+1},-0+2f_{i+1})=2f_{i+1}$（因 $f_{i+1}\ge0$），连乘 $99999$ 次得 $f_1=2^{99999}\approx10^{30102}$，超过 $80$ 位浮点约 $1.19\times10^{4932}$ 的上界，得到 `inf`。而 $w=0$ 时由引理 1 恒有 $p=0$，每笔收支都是 $x\cdot0=0$，真实答案 $=0.00$；若不特判就会算成 $0\cdot\mathrm{inf}=\mathrm{NaN}$，输出成一堆问号。$\blacksquare$

处理办法：$w=0$ 直接输出 `0.00`（等价地，也可以对 $f$ 加上限截断，但特判最省事也最不易错）。注意 $w\ge1$ 时由引理 10 绝对安全，两种情况合起来覆盖全部取值。

**精度**：输出要求保留 2 位小数，所以最终误差必须明显小于 $5\times10^{-3}$，否则四舍五入的末位会错。递推每步是"一次乘法 + 一次加法 + 一次取 max"，单步舍入误差不超过结果的一个 ulp；用"$f_i\le10^9$、共 $10^5$ 步、误差全部同号相加、且 $w\le100$"这套**极端最坏界**（实际远没这么坏，它假设每步都舍到最大且方向一致）估计：

- `long double`（GCC/x86 下是 x87 双扩展精度，$64$ 位有效位）：单步 $\mathrm{ulp}(10^9)\approx10^9\cdot2^{-63}\approx1.1\times10^{-10}$，$10^5$ 步累积 $\approx1.1\times10^{-5}$，乘 $w$ 后 $\approx1.1\times10^{-3}<5\times10^{-3}$，通过，且留约 $4$ 个数量级余量。
- `double`（$53$ 位有效位）：同一套界放大 $2^{11}=2048$ 倍，$\approx2\times10^{1}$，最坏界直接越过容差（多数真实数据仍会 AC，但没必要赌；另外个别编译器里 `long double` 退化成 `double`，洛谷的 GCC 不会）。

故代码统一用 `long double`，并把系数写成 `0.01L` 让乘法在长精度里完成；绝不能用 `pow(d,m)` 之类先算幂再乘 $w$ 的正序式子（既丢精度又有溢出风险）。

**静态数组的初值坑**：本题没有任何"不可达 $=+\infty/-\infty$"语义的数组——唯一的 DP 初值 $f_{n+1}=0$，恰好就是全局 `long double f{}` 的零初始化值，语义正确；`ty[]`、`a[]` 下标 $\ge n$ 的位置虽然也是 $0$，但倒序循环从 $n-1$ 起，永不触碰。风格规范里"INF 数组必须 `fill_n`"的要求在这里没有对象可施，若日后改成"正序 + 不可达 $=-\infty$"的写法，才需要 `fill_n(f,f+mxn,-inf)` 显式铺底，否则 $0$ 会被当成合法的"收益 0"状态而悄悄吞掉更优解。

## 3. 模式总结（Pattern Summary）

按真实思考顺序排列，一个技巧一条，重复出现的步骤拆开写：

- **精确刻画特殊机制** — "只乘不加"的 $p=w\,d^{m}u^{r}$：把易变状态写成两个计数器的函数，一眼看出所有收支对 $p$ 线性。
- **考虑简化版（钉死参数）** — 令 $c=0$ 去掉维修耦合；令 $k=100$ 使 $d=0$，得到"最多一次有效开采"这样的强结论。
- **考虑简化版（限制子任务规模）** — 用 30% 的 $n\le100$ 逼出"前缀 DP 状态 $(m,r)$"这一暴力解，$O(n^3)$，作为正确性参照物。
- **剖析贪心失败（三个反例，逐条诊断）** — 正序"眼前为正就干"、"$d<1$ 也能连挖"、"倒序贪心看不到已定后缀的负债"；归纳出共同缺口＝缺少"1 点能力的单价"。
- **顺序不可交换 → 只能选子集** — 路线固定，放弃交换论证，改找可加结构。
- **齐次性提系数（核心一次）** — 值函数 $V_i(p)=p\,V_i(1)$，用"后向归纳 + $\max(pA,pB)=p\max(A,B)$（$p\ge0$）"证明，把连续状态压成一个标量。
- **后缀 DP（倒序递推）** — 代价落在未来，所以从未来往回算；单价 $f_{i+1}$ 让每步只剩一次比较。
- **归约到更简单问题** — 原题 → 仿射取 max 的一维标量递推 $f\leftarrow\max(f,\,s+tf)$。
- **影子价格 / 阈值决策解读** — 开采 iff $a_i\ge0.01k f_{i+1}$，维修 iff $b_i\le0.01c f_{i+1}$；把 $\max$ 变成可读的经济账，顺便接回贪心。
- **状态滚动 + 单调性证明有界** — $f_i\ge f_{i+1}\ge0$ 同时给出"内存 $O(1)$"与"数值上界 $f_1\le10^9/w$"。
- **退化角分类讨论** — $w=0$、$k=0$、$c=0$、$k=100$、$a_i=0$、$b_i=0$ 各自能被递推式自然吞掉，但要逐个验证方向没写反。
- **溢出防护（浮点版）** — 找出"$f$ 无界而答案有界"的构造（$w=0$ + 免费维修链）并特判；按 ulp 步数累积选 `long double`。
- **与简化版做一致性检验** — 代回 $k=100$ 应得后缀 $\max a_i$，代回 $c=0$ 应得"维修不改变 $f$"，免费验证公式。

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 初值 / 约定 | 一句话记忆 |
|---|---|---|---|
| $n,k,c,w$ | 星球数、损耗百分比、修复百分比、初始能力值 | 输入 | 题面四元组 |
| $d=1-0.01k$ | 开采后的能力倍率，$d\in[0,1]$ | 由 $k$ 算出，`const long double` | Damage（损耗） |
| $u=1+0.01c$ | 维修后的能力倍率，$u\in[1,2]$ | 由 $c$ 算出 | Upgrade（升级） |
| `ty[i]` | 第 $i$ 个星球类型（1 资源 / 2 维修），代码 0-based | 输入 | t**y**pe |
| `a[i]` | 该星球的金额参数：`ty=1` 时是 $a_i$，`ty=2` 时是 $b_i$ | 输入 | **a**mount |
| $V_i(p)$ | 数学量：从星球 $i$ 起、当前能力为 $p$ 的未来最大净收入 | $V_{n+1}\equiv0$ | **V**alue |
| $f$（$=f_i$） | 程序里滚动的那一个标量：$f_i=V_i(1)$，即"进入第 $i$ 个星球时 1 点能力值的未来单价" | $f\leftarrow0$（即 $f_{n+1}=0$，全局零初始化恰好正确） | 影子**价**格 |
| $\mathrm{mul}_i$ | 该星球动手后的倍率：$d$ 或 $u$ | — | **mul**tiplier |
| $s_i$ | 该星球动手的即时金额（$p=1$ 口径）：$+a_i$ 或 $-b_i$ | — | **s**ettle |

### 4.2 步骤

1. 读入 $n,k,c,w$，把 $n$ 行 `type x` 原样存入 `ty[]`、`a[]`（必须存：递推要倒序）。
2. 若 $w==0$：由引理 1 能力恒为 $0$，答案必为 $0.00$，直接输出并返回（同时避开引理 11 的 `inf` 陷阱）。
3. 计算 $d=1-0.01\mathtt{L}\,k$、$u=1+0.01\mathtt{L}\,c$，令 $f\leftarrow0$（对应 $f_{n+1}$）。
4. 倒序 $i=n-1\to0$ 执行 $f\leftarrow\max\big(f,\ \pm\,$`a[i]`$+\mathrm{mul}_i f\big)$：`ty=1` 取 $+$`a[i]` 与 $d$，`ty=2` 取 $-$`a[i]` 与 $u$（右侧的 $f$ 是旧的 $f_{i+1}$，赋值后变成 $f_i$）。
5. 输出 `fixed<<setprecision(2)` 下的 $f\cdot w$，换行用 `'\n'`。

### 4.3 复杂度

- 时间：$O(n)$，一次倒序扫描，每步常数次浮点运算；$n=10^5$ 时约 $10^5$ 次操作。
- 空间：$O(n)$（存输入），DP 本体 $O(1)$（引理 8 保证可滚动）。
- 与子任务对照：$n\le100$、$n\le1000,k=100$、$n\le10^5$ 全部被同一个 $O(n)$ 解覆盖；30% 分也可以用 2.2 的 $O(n^3)$ 前缀 DP 对拍（本环境禁止运行，故未实跑）。

## 5. 示例代码

```cpp
// https://www.luogu.com.cn/problem/P1412
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};	// 1e5 + 5 松弛

int n,k,c,w;
int ty[mxn],a[mxn];	// ty=1: a[i]=a_i（矿物量）; ty=2: a[i]=b_i（维护费）

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k>>c>>w;
	for(int i=0;i<n;++i)
		cin>>ty[i]>>a[i];	// 倒序 DP，必须先存下全部星球

	if(w==0)	// p 只能被乘，永远回不到正数：所有收支都是 0
	{		// 顺手躲开"自由维修链让 f 爆成 inf，再乘 0 得 NaN"
		cout<<fixed<<setprecision(2)<<0.0<<'\n';
		return 0;
	}

	const long double d{1-0.01L*k},u{1+0.01L*c};
	long double f{};	// f_i=V_i(1)="1 点能力值的未来单价"，f_{n+1}=0
	// 无 INF 语义数组：全局零初值恰好等于 base case，无需 fill_n
	for(int i=n-1;i>=0;--i)
	{
		if(ty[i]==1)
			f=max(f,a[i]+d*f);	// 开采：先结 a[i]*p，之后 p*=d
		else
			f=max(f,-a[i]+u*f);	// 维修：先付 b[i]*p，之后 p*=u
		// 决策等价于 a[i]>=0.01k*f(旧) / b[i]<=0.01c*f(旧)
	}

	cout<<fixed<<setprecision(2)<<f*w<<'\n';	// 答案=V_1(w)=w*f_1
	return 0;
}
```
