# P1101 单词方阵  题解

---

## 1. 重读题目

给定一个 $n \times n$ 的字母方阵，需要在其中找出所有"连续摆放"的单词 `yizhong`。关键约束：

- 单词沿着 **8 个方向之一** 摆放（上、下、左、右、左上、右上、左下、右下）
- 同一个单词在摆放过程中 **方向不变**（直线）
- 单词之间 **可以交叉**，即不同单词可以共用字母
- 输出时，**不属于任何单词的字母**替换为 `*`，属于某单词的字母保留原样
- $n \in [7, 100]$

本质：在二维网格中搜索所有与给定模式串匹配的直线段，方向为 8 连通。

---

## 2. 思考链（Chain-of-Thought）与完整证明

### 2.1 暴力枚举的可行性

网格大小 $n \le 100$，最大 $100 \times 100 = 10^4$ 个格子。对于每个格子作为起点，向 8 个方向延伸 7 步（单词长度），检查是否匹配 `yizhong`。最坏情况：

$$n^2 \times 8 \times 7 \approx 10^4 \times 56 = 5.6 \times 10^5$$

完全可行，无需任何剪枝优化。

### 2.2 重叠的处理

题目允许单词交叉，意味着一个字母可能属于多个单词。对于每个字母，只要它被 **至少一个** 单词覆盖，就应该保留原样，否则输出 `*`。

一种策略：

1. 开辟一个标记数组 `vis[i][j]`，初始化为 0（表示不属于任何单词）
2. 每次找到一个完整的 `yizhong`，就把对应 7 个位置的标记置为 1
3. 最终遍历整个矩阵，`vis[i][j] == 1` 则输出原字母，否则输出 `*`

由于标记只会从 0 变为 1，且不同单词的标记操作之间互不干扰（取或运算），该策略正确。

### 2.3 方向定义

8 个方向用方向向量表示。约定 $(i, j)$ 为行索引、列索引，$i$ 向下递增，$j$ 向右递增：

| 方向 | $dx$ | $dy$ |
|------|------|------|
| 上 | -1 | 0 |
| 下 | 1 | 0 |
| 左 | 0 | -1 |
| 右 | 0 | 1 |
| 左上 | -1 | -1 |
| 右上 | -1 | 1 |
| 左下 | 1 | -1 |
| 右下 | 1 | 1 |

### 2.4 正确性证明

**引理 1**：每个合法的单词摆放对应唯一一个起点和一个方向。

证明：单词沿直线摆放，方向不变。取第 0 个字符的位置为起点，方向为摆放方向。该二元组 $(起点, 方向)$ 与单词的一一对应是显然的。

**引理 2**：按起点→方向枚举不会遗漏任何单词。

证明：由引理 1，任意合法单词对应唯一 $(起点, 方向)$。枚举所有 $(i, j, dir)$ 三元组即覆盖所有可能。当 $n \le 100$ 时，枚举数量有限，且每次检查 $O(7)$ 步，总复杂度 $O(8 \cdot 7 \cdot n^2) = O(n^2)$。

**定理**：上述标记算法输出正确。

证明：每个被标记为 1 的位置必属于某个单词（因为只有找到完整匹配才标记）；每个属于某单词的位置必被标记为 1（因为该单词对应某 $(起点, 方向)$ 枚举会触发标记）。因此标记集合恰好等于所有单词覆盖的位置集合，输出正确。

### 2.5 边界条件

方向延伸时，需检查：

$$0 \le i + k \cdot dx < n, \quad 0 \le j + k \cdot dy < n, \quad k = 0 \dots 6$$

若任何一步越界，则该方向的匹配失败。

## 3. 模式总结

| 项目 | 内容 |
|------|------|
| **问题类型** | 二维网格模式匹配 |
| **核心范式** | 枚举起点 + 枚举方向 + 线性扫描 |
| **状态设计** | `ans[i][j]`：0/1 表示是否属于某单词 |
| **方向处理** | 预定义方向数组，统一循环 |
| **复杂度** | $O(n^2)$ 时间，$O(n^2)$ 空间 |
| **边界检查** | 每步检查坐标越界 |
| **关键技巧** | 标记法处理重叠；方向数组简化代码 |

## 4. 正式解法

### 算法流程

```
输入 n, 矩阵 a[n][n]
初始化标记数组 vis[n][n] = {0}
定义常量单词 s = "yizhong", 长度 L = 7
定义方向数组 dx[8], dy[8]

for i = 0 to n-1:
    for j = 0 to n-1:
        for d = 0 to 7:
            // 检查第 0 步是否越界（其实不需要，因为起点一定合法）
            flag = true
            for k = 0 to 6:
                计算 nx = i + k*dx[d], ny = j + k*dy[d]
                if 越界 或 a[nx][ny] != s[k]:
                    flag = false; break
            if flag:
                for k = 0 to 6:
                    vis[i + k*dx[d]][j + k*dy[d]] = 1

for i = 0 to n-1:
    for j = 0 to n-1:
        输出 vis[i][j] ? a[i][j] : '*'
```

### 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 矩阵边长 |
| $a[i][j]$ | 输入字母矩阵 |
| $vis[i][j]$ | 标记数组，1 表示保留原字母 |
| $s$ | 模式串 `"yizhong"` |
| $L$ | 模式串长度 7 |
| $dx[d], dy[d]$ | 第 $d$ 个方向的行、列偏移 |
| $flag$ | 当前方向是否匹配成功 |

## 5. 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};
const string s = "yizhong";
const int L = 7;

int n;
char a[mxn][mxn];
bool vis[mxn][mxn];

int dx[8] = {-1, 1, 0, 0, -1, -1, 1, 1};
int dy[8] = {0, 0, -1, 1, -1, 1, -1, 1};

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin >> n;
	for (int i = 0; i < n; ++i)
		cin >> a[i];

	for (int i = 0; i < n; ++i)
	{
		for (int j = 0; j < n; ++j)
		{
			for (int d = 0; d < 8; ++d)
			{
				int ok = 1;
				for (int k = 0; k < L; ++k)
				{
					int ni = i + k * dx[d];
					int nj = j + k * dy[d];
					if (ni < 0 || ni >= n || nj < 0 || nj >= n
						|| a[ni][nj] != s[k])
					{
						ok = 0;
						break;
					}
				}
				if (ok)
				{
					for (int k = 0; k < L; ++k)
						vis[i + k * dx[d]][j + k * dy[d]] = 1;
				}
			}
		}
	}

	for (int i = 0; i < n; ++i)
	{
		for (int j = 0; j < n; ++j)
			cout << (vis[i][j] ? a[i][j] : '*');
		cout << '\n';
	}

	return 0;
}
```
