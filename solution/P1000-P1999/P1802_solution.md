# P1802 5 倍经验日

> 难度：普及- · 标签：动态规划 DP、背包 DP

## 1. 重新读题
### 1.1 问题重述（人话版）

有 \(x\) 颗药，要打 \(n\) 个好友。对第 \(i\) 个好友：药不够 \(use_i\) 颗就一定输，拿经验 \(lose_i\)，而且已经喂进去的药作废；药至少 \(use_i\) 颗就赢，拿经验 \(win_i\)。每颗药只能用在一个人身上。求能拿到的最大经验 \(s\)，输出 \(5s\)。

### 1.2 关键约束与规模暗示

- \(0\le n,x\le 10^3\)，\(0<lose_i\le win_i\le 10^6\)，\(0\le use_i\le 10^3\)。\(n=0\) 或 \(x=0\) 都合法。
- \(lose_i>0\)：放弃一个人（经验 0）不如认输。所以最优策略会跟每个人都打。
- 经验总和最大约 \(10^3\times 10^6=10^9\)，再乘 5 是 \(5\times 10^9\)，超过 32 位整数，必须用 64 位。
- \(n,x\le 1000\) 指向 \(O(nx)\) 的 0-1 背包，二维和一维都可以。

## 2. 思维链（Chain-of-thought）

**引理 1（药只会被用成 0 颗或恰好 \(use_i\) 颗）**

存在一组最优分配，使得每个人得到的药数只有两种可能：0，或者恰好 \(use_i\)（且此时 \(use_i\) 不超过剩余药量）。

**证明**：取任意一种分配。若某人分到 \(t\) 颗且 \(0<t<use_i\)，题面规定这场必输，经验仍是 \(lose_i\)，但这 \(t\) 颗药被浪费。把这 \(t\) 颗收回、改成 0 颗，他的经验不变，全局可用的药不减，其它人的药数不变，总经验不降。所以带「半吊子用药」的方案都能改成不更差、且没有半吊子的方案。

若某人分到 \(t>use_i\)，题面只要求「至少 \(use_i\)」即可获胜，多出来的 \(t-use_i\) 颗对这场经验没有额外贡献。收回多余的部分，经验不变、药不减。\(\square\)

**引理 2（每个人都必须打，认输也比跳过强）**

最优方案里每个人都会被打：要么 0 药认输拿 \(lose_i\)，要么恰好 \(use_i\) 药获胜拿 \(win_i\)。

**证明**：\(lose_i>0\)。跳过这个人得到 0，比认输少。引理 1 已经排除了其它用药量。\(\square\)

于是每个人是一件 0-1 物品：不选 = 付 0 药拿 \(lose_i\)；选 = 付 \(use_i\) 药拿 \(win_i\)。所有人恰好选一种。这和「先把所有 \(lose_i\) 加进底，再决定要不要花 \(use_i\) 把差额 \(win_i-lose_i\) 补上」是同一件事，下面直接在容量上做转移。

**引理 3（一维倒序背包得到容量 \(x\) 下的最大经验）**

设 \(dp[j]\) 表示只用前若干个人、药的容量恰好是预算 \(j\)（允许剩下药不用）时的最大经验。初始全 0（还没打人）。处理第 \(i\) 个人时，按 \(j\) 从 \(x\) 降到 0：

- 若 \(j\ge use_i\)，\(dp[j]\leftarrow \max(dp[j]+lose_i,\; dp[j-use_i]+win_i)\)；
- 否则只能认输，\(dp[j]\leftarrow dp[j]+lose_i\)。

处理完 \(n\) 个人后 \(dp[x]\) 就是最大经验 \(s\)。

**证明**：对人数 \(i\) 归纳。\(i=0\) 时经验 0，成立。

假设处理完前 \(i-1\) 个人时，\(dp[j]\) 是容量 \(j\) 下的最优。现在加入第 \(i\) 个人，倒序保证等式右边读到的仍是「还没算这个人」的旧值（\(use_i=0\) 时 \(j-use_i=j\)，读的也是本轮赋值前的旧 \(dp[j]\)，不会用到刚写下的新值）。

容量 \(j\) 的方案只有两类，由引理 1、2 穷尽：

- 认输：药数不变，经验比旧 \(dp[j]\) 多 \(lose_i\)；
- 获胜：仅当 \(j\ge use_i\)，药预算从 \(j-use_i\) 转移过来，经验是旧 \(dp[j-use_i]\) 加 \(win_i\)。

两类取最大，就是容量 \(j\) 在 \(i\) 个人下的最优。归纳完成。

最终答案乘 5，是题面要求输出 \(5s\)，不是背包里再乘。\(\square\)

\(use_i=0\) 时两类同时合法，\(\max(dp[j]+lose_i,\,dp[j]+win_i)=dp[j]+win_i\)，因为 \(win_i\ge lose_i\)。免费的胜利一定要拿，转移没有写错。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 药不够就只拿失败经验，所以半吊子用药被「改成 0 颗」严格支配。
- **reduce to easier problem** — 每个人变成「认输 / 花恰好 \(use_i\) 获胜」二选一，所有人都会打。
- **classic problem solution** — 倒序 0-1 背包，容量是药，价值是经验；最后再乘 5。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| \(n,x\) | `int` | 人数、药数 | 读入 | 容量上界 \(x\) |
| `lose,win,use` | `int[1005]` | 失败经验、胜利经验、所需药 | 读入，下标 1…\(n\) | `win>=lose` |
| `dp[j]` | `i64[1005]` | 容量 \(j\) 的最大经验（尚未乘 5） | 全局 0 | 倒序刷新 |
| \(s\) | `i64` | `dp[x]` | — | 输出 `dp[x]*5` |

### 4.2 算法步骤

1. 读 \(n,x\) 和 \(n\) 行三元组。
2. 对每个 \(i=1\ldots n\)，\(j\) 从 \(x\) 降到 0，按引理 3 更新 `dp[j]`。
3. 输出 `dp[x]*5`。\(n=0\) 时循环不执行，输出 0。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 时间 \(O(nx)\)，空间 \(O(x)\)。\(n=x=1000\) 时约 \(10^6\) 次转移。
- 编译 `g++ -O2 -std=c++17 -Wall -Wextra`，warn=0。
- 样例 `6 8` 及题面六行数据，标程与暴搜都输出 `1060`。
- 边界 7 组（\(n=0\)、\(x=0\)、\(use=0\)、药永远不够、`win=lose`）加随机 300 组（\(n\le 16\)，暴搜枚举「每人 0 药或恰好 `use` 药」）。共 308 组，随机段 5.982s。
- 满数据计时：\(n=x=1000\)，经验在合法范围内随机，标程 0.016s，答案 `2454570860`。

## 5. 示例代码
### 5.1 标程（`P1802.cpp`）

```cpp
//
// 题目：P1802 5 倍经验日
// https://www.luogu.com.cn/problem/P1802
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};

int n,x;
int lose[mxn],win[mxn],use[mxn];
i64 dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>x;
	for(int i=1;i<=n;++i)
		cin>>lose[i]>>win[i]>>use[i];
	for(int i=1;i<=n;++i)
	{
		for(int j=x;j>=0;--j)
		{
			if(j>=use[i])
				dp[j]=max(dp[j]+lose[i],dp[j-use[i]]+win[i]);
			else
				dp[j]+=lose[i];
		}
	}
	cout<<dp[x]*5<<'\n';
	return 0;
}
```
