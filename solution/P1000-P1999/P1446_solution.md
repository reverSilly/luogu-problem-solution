# P1446 [HNOI2008] 卡牌 Cards

> 标签：动态规划 DP / 数学 / 置换 / 逆元 / Burnside 引理 · 难度：NOI+

## 1. 重新读题

**问题重述**

- 一排 $n$ 张牌，$n=S_r+S_b+S_g$，用红/蓝/绿三色染色，且颜色数量**精确**规定：红 $S_r$ 张、蓝 $S_b$ 张、绿 $S_g$ 张。
- 给定 $m$ 种洗牌法，第 $i$ 种是一个 $1\sim n$ 的排列 $X$，含义：新第 $i$ 位 = 原第 $X_i$ 位的牌。
- 两种染色方案视为**相同** ⟺ 其中一种经过**任意多次**（可重复使用同一种）洗牌变成另一种。
- 求本质不同的方案数 $\bmod P$，保证 $P$ 为质数。

**输入输出**

- 第一行 $5$ 个整数 $S_r,S_b,S_g,m,P$；接下来 $m$ 行，每行 $n$ 个整数构成 $1\sim n$ 的排列 $X_1..X_n$。
- 输出一行：本质不同染色方案数 $\bmod P$。

**题面中的两条"保证"**

- 保证 A："任意多次洗牌都可用这 $m$ 种洗牌法中的一种代替" —— 想表达**封闭性**。
- 保证 B："对每种洗牌法，都存在一种洗牌法使得能回到原状态" —— 想表达**存在逆元**。
- 这两条保证的唯一作用是：让要求的群 $G$ 大小 $\le m+1$，从而能**枚举群元素**。若没有它们，$|G|$ 可达 $n!$ 级，Burnside 求和根本写不完。细节与坑见 §2.7。

**数据范围**

| 量 | 范围 | 推论 |
|---|---|---|
| $m$ | $\le 60$ | 群元素个数 $\le 61$，可以逐个枚举 |
| $P$ | $m+1<P<100$，质数 | $P\ge 3$；$\gcd(|G|,P)=1$，逆元存在 |
| $\max\{S_r,S_b,S_g\}$ | $\le 20$ | $n=S_r+S_b+S_g\le 60$ |
| 环个数 $c$ | $\le n\le 60$ | DP 状态 $c\cdot(S_r+1)(S_b+1)\le 60\cdot 21\cdot 21\approx 2.6\times 10^4$ |

**陷阱与边界（先记下，第 2 节逐条论证）**

1. 不是"方案数除以 $n!$"，也不是"方案数除以 $m$" —— 分母是**群阶** $|G|$。本地题面 Hint 隐含答案为 $2$，用它校准分母（§2.7）。
2. 洗牌只重排位置、不改颜色，所以每个轨道内的方案颜色计数相同，"精确 $S_r,S_b,S_g$"这一约束与群的作用是**兼容**的（§2.5 引理 5 会用到）。
3. 恒等置换不一定出现在 $m$ 行里，必须自己补一项，否则 Burnside 少算一项（§2.7，代码里 `has_id` 分支）。
4. 置换方向：题面"$i$ 位变为原来的 $X_i$ 位"给出的映射与"位置的真实移动"互为逆置换，但**逆置换与原置换环长集合相同**，故不影响 $\mathrm{fix}$（§2.5 引理 6）。
5. $P<100$：所有中间量都在 $10^4$ 内，`int` 绰绰有余；但 DP 每步仍要取模，避免累加溢出与"最后一次性取模"的隐患（§2.8）。
6. $S_r,S_b,S_g$ 可为 $0$：DP 的红/蓝循环上限为 $0$ 时要能自然退化为"全绿"（§5 验证 3）。
7. $m=0$ 是允许的（题面只写 $m\le 60$，未给下界）：此时 $G=\{\mathrm{id}\}$，答案应为多重排列数（§2.2、§5 验证 4）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：等价关系的真实结构

先把语言翻译成符号。设位置集合 $\{1,\dots,n\}$。一个**染色**就是函数 $f:\{1..n\}\to\{R,B,G\}$ 且满足数量约束

$$|f^{-1}(R)|=S_r,\quad |f^{-1}(B)|=S_b,\quad |f^{-1}(G)|=S_g.$$

把所有满足约束的染色集合记作 $X$。一行洗牌法是一个排列 $\pi$，作用在 $X$ 上：$(\pi f)(i)=f(X_i)$。题面说"两种染色相同 ⟺ 其中一种可通过**任意多次**洗牌变成另一种"，即

$$f\sim h\iff \exists\, k\ge 0,\ \exists\,\pi_1,\dots,\pi_k\in S\ (=m\ \text{种洗牌法}),\quad h=\pi_k\cdots\pi_1 f .$$

**引理 1（$\sim$ 就是群作用的轨道关系）**

令 $G=\langle S\rangle$ 为 $S$ 在 $S_n$ 中生成的置换群（含 $k=0$ 的空乘积，即恒等置换 $\mathrm{id}$）。则 $f\sim h\iff \exists g\in G,\ h=g\,f$，而这是 $X$ 上的一个等价关系，其等价类正是轨道 $\{gf:g\in G\}$。

**证明**：
- $(\Rightarrow)$：$k=0$ 时 $h=f=\mathrm{id}\,f$，而 $\mathrm{id}\in G$；$k\ge 1$ 时 $h$ 是 $k$ 个生成元的复合，按生成群定义属于 $G$。
- $(\Leftarrow)$：$G$ 中每个元素都是生成元的有限复合，把这段复合当作"洗若干次牌"即可。
- 等价关系三条：自反（$\mathrm{id}\in G$，$f=\mathrm{id}f$）；对称（$h=gf\Rightarrow g^{-1}h=f$，$g^{-1}\in G$）；传递（$h=gf,\ l=kh\Rightarrow l=(kg)f$，$kg\in G$）。$\blacksquare$

**结论**：题目要求的就是轨道数 $|X/G|$。**只要看到"通过若干次操作互相到达算同一种"，就应该条件反射到"数轨道"**，而数轨道的标准武器是 Burnside 引理（§2.4）。$X$ 有限（$|X|=\binom{n}{S_r,S_b,S_g}$），故每个轨道与稳定子都有限，后续所有计数不会发散。

### 2.2 简化版：$m=0$（完全不洗牌）

没有任何洗牌法时 $G=\{\mathrm{id}\}$，$|\mathrm{Orb}|$ 就是 $|X|$：

$$|X|=\binom{n}{S_r,S_b,S_g}=\frac{n!}{S_r!\,S_b!\,S_g!}.$$

**引理 2（不洗牌时的答案）** 上式成立。

**证明**：双向夹逼式计数。设 $Y$ 为"把 $n$ 个**有标号**的位置划分成三个有标号盒子（红盒 $S_r$ 个、蓝盒 $S_b$ 个、绿盒 $S_g$ 个）"的方案集合。

- 先选红：$\binom{n}{S_r}$ 种；再在剩下 $n-S_r$ 个里选蓝：$\binom{n-S_r}{S_b}$ 种；绿位置被唯一确定。故 $|Y|=\binom{n}{S_r}\binom{n-S_r}{S_b}=\frac{n!}{S_r!S_b!S_g!}$。
- 另一方面，$Y$ 与 $X$ 之间是双射：一个染色 $f$ 恰好给出三个位置集合 $(f^{-1}(R),f^{-1}(B),f^{-1}(G))$；反过来一个划分唯一确定每个位置的颜色。故 $|X|=|Y|$。$\blacksquare$

数值感受：$S_r=S_b=S_g=1$ 时 $|X|=\frac{3!}{1!1!1!}=6$，正是题面 Hint 里那 $6$ 个串 `RGB RBG GRB GBR BRG BGR`。**这一步的作用**：给出"分母基线"——$|G|=1$ 时公式必须还原出 $6$，任何解法若在此不还原 $|X|$，就是分母取错了。

### 2.3 剖析朴素做法为什么失败

拿到 Hint 数据（$S_r=S_b=S_g=1$，$m=2$，两行为 `2 3 1` 与 `3 1 2`）时，最容易犯的三种错误：

**错误 A：$|X|/2$（除以洗牌法种数）**。$6/2=3$。但 Hint 明确说"有 $2$ 种本质上不同的染色法"。错在哪：轨道大小不是常数 $2$，而是 $|G|/|\mathrm{Stab}(f)|$，$\mathrm{Stab}(f)$ 可大可小。

**具体小数据反例（说明轨道大小不均）**：取 $S_r=2,S_b=1,S_g=0$，$n=3$，群 $G=\{\mathrm{id},(12)\}$（即一行 `2 1 3`）。三个染色 `RRg, RgR, gRR`（$g$ 表示绿）中：
- `RRg` 在 $(12)$ 下不变 $\Rightarrow$ 它的轨道是 $\{$`RRg`$\}$，大小 $1$；
- `RgR` 与 `gRR` 互相交换 $\Rightarrow$ 另一个轨道大小 $2$。

轨道大小 $1$ 和 $2$ 混在一起，$3/2$ 根本不是整数；正确轨道数是 $2$。这直接否决了"总数除以某个固定数"的所有变体。

**错误 B：只枚举 $m$ 个给定置换、除以 $m$**。本题 Hint 数据下给出 $\mathrm{fix}(\texttt{231})+\mathrm{fix}(\texttt{312})=0+0=0$，除 $2$ 得 $0$，与 $2$ 差更远——因为**漏了恒等置换这一项**。$\mathrm{id}$ 的不动点最多（全部 $6$ 个），漏掉它就漏掉主项。

**错误 C：把"能否洗成"当成可贪心的判定**。有人想"每次只用一次洗牌，比较字典序最小的代表"。反例仍是 $G=\{\mathrm{id},(12)\}$ 与 `RgR`：它的"一次洗牌"邻居只有 `gRR` 和自身，字典序最小代表是 `gRR`；而 `RRg` 的邻居是自身，最小代表 `RRg`；此时看起来还行。但若群是 `231`、`312` 生成的 $3$ 阶循环群，`RGB` 的轨道是 $\{$`RGB`,`GBR`,`BRG`$\}$，必须允许"多次复合"才能看到整个轨道，一次洗牌看不全 —— 轨道必须用**群**而非**生成元集合**来定义。

**小结**：必须用"能数轨道"的定理，而不是"能除"的直觉。

### 2.4 经典解法：Burnside 引理

记 $\mathrm{fix}(g)=|\{f\in X:gf=f\}|$（被 $g$ 固定的染色数）。

**引理 3（轨道—稳定子定理）** 对任意 $f\in X$，$|\mathrm{Orb}(f)|\cdot|\mathrm{Stab}(f)|=|G|$，其中 $\mathrm{Stab}(f)=\{g\in G:gf=f\}$。

**证明**：构造双射。定义 $\varphi:G\to \mathrm{Orb}(f)$，$\varphi(g)=gf$。
- $\varphi$ 是满射：由轨道定义，轨道中每个元素都写成 $gf$。
- 对任意 $h\in \mathrm{Orb}(f)$，考察原像集 $\varphi^{-1}(h)=\{g:gf=h\}$。取定一个 $g_0$ 使 $g_0f=h$（满射保证存在），则
 $$g\in\varphi^{-1}(h)\iff gf=h=g_0f\iff g_0^{-1}gf=f\iff g_0^{-1}g\in\mathrm{Stab}(f)\iff g\in g_0\,\mathrm{Stab}(f).$$
 反之若 $g=g_0s$，$s\in\mathrm{Stab}(f)$，则 $gf=g_0(sf)=g_0f=h$。故 $\varphi^{-1}(h)=g_0\mathrm{Stab}(f)$，其大小等于 $|\mathrm{Stab}(f)|$（左乘 $g_0$ 是 $G$ 到自身的双射，$s\mapsto g_0s$ 单：$g_0s_1=g_0s_2\Rightarrow s_1=s_2$）。
- 于是 $|G|=\sum_{h\in\mathrm{Orb}(f)}|\varphi^{-1}(h)|=|\mathrm{Orb}(f)|\cdot|\mathrm{Stab}(f)|$。$\blacksquare$

**引理 4（Burnside）** 轨道数
$$|X/G|=\frac{1}{|G|}\sum_{g\in G}\mathrm{fix}(g).$$

**证明（双重计数，不依赖任何"显然"）**：考虑集合
$$T=\{(g,f)\in G\times X: gf=f\}$$
并对其元素数**两次**。

- **按 $g$ 先枚举（第一重夹逼）**：固定 $g$，满足 $gf=f$ 的 $f$ 恰有 $\mathrm{fix}(g)$ 个，故 $|T|=\sum_{g\in G}\mathrm{fix}(g)$。
- **按 $f$ 先枚举**：固定 $f$，满足 $gf=f$ 的 $g$ 恰是 $\mathrm{Stab}(f)$，故 $|T|=\sum_{f\in X}|\mathrm{Stab}(f)|$。用引理 3 把 $|\mathrm{Stab}(f)|=|G|/|\mathrm{Orb}(f)|$ 代入：
 $$|T|=|G|\sum_{f\in X}\frac{1}{|\mathrm{Orb}(f)|}.$$
 现在按轨道分组求和：同一个轨道 $\mathcal O$ 内的每个 $f$ 都有 $|\mathrm{Orb}(f)|=|\mathcal O|$（轨道作为集合相同），且 $\mathcal O$ 恰含 $|\mathcal O|$ 个 $f$，于是该轨道对求和的贡献为 $|\mathcal O|\cdot\frac{1}{|\mathcal O|}=1$。故 $\sum_{f\in X}\frac{1}{|\mathrm{Orb}(f)|}=|\{\text{轨道}\}|=|X/G|$。
- 两个表达式相等：$\sum_{g}\mathrm{fix}(g)=|G|\cdot|X/G|$，两边除以 $|G|$ 即得。$\blacksquare$

**代入本题**：我们要算的就是 $|X/G|$，于是问题变成"**对每个群元素 $g$，数它固定多少种染色**"。这正好是可以 DP 的东西（§2.5）。

> 注意：引理 4 里除法在整数范围内一定除得尽（因为左边确实是轨道数）。后面在 $\bmod P$ 意义下做除法要额外小心，见 §2.8。

### 2.5 剖析 $\mathrm{fix}(g)$：环上的染色

**引理 5** 设 $g$ 的循环分解（作为位置置换）的环为 $C_1,\dots,C_c$，环长依次 $l_1,\dots,l_c$（$\sum l_i=n$）。则
$$gf=f\iff \forall t,\ \forall i,j\in C_t:\ f(i)=f(j),$$
即"每个环内部同色"。

**证明（双向）**：
- $(\Leftarrow)$：若每个环内同色，任取位置 $i$，设 $i$ 在环 $C_t$ 中。$g$ 把 $i$ 送到同一环内的某个位置，故 $f(gi)=f(i)$，即 $(gf)(i)=f(i)$ 对所有 $i$ 成立，$gf=f$。
- $(\Rightarrow)$：设 $gf=f$，即 $\forall i,\ f(gi)=f(i)$。取环 $C_t=\{i,g i,g^2 i,\dots,g^{l_t-1}i\}$，对任意 $j=g^k i\in C_t$，用归纳（对 $k$）：$k=0$ 时 $f(j)=f(i)$ 显然；$k\to k+1$ 时 $f(g^{k+1}i)=f(g\cdot g^k i)=f(g^k i)=f(i)$（第二个等号用 $\forall$ 那一条作用在位置 $g^k i$ 上）。故环上每个位置的颜色都等于 $f(i)$。$\blacksquare$

**引理 6（方向约定不影响答案）** 题面的读法"新第 $i$ 位 = 原第 $X_i$ 位的牌"给出的映射是 $i\mapsto X_i$；把它当作置换 $g$ 或当作 $g^{-1}$ 来分解环，$\mathrm{fix}$ 的值相同。

**证明**：先确认作用式：新位置 $i$ 上的颜色是原位置 $X_i$ 的颜色，即 $(gf)(i)=f(X_i)$。令 $h:i\mapsto X_i$，则 $gf=f\iff \forall i,\ f(X_i)=f(i)\iff \forall i,\ f\circ h=f$。而 $h$ 与 $h^{-1}$ 有相同的环分解（只是每个环的遍历方向相反：$h$ 的环 $(a_1a_2\dots a_k)$ 对应 $h^{-1}$ 的环 $(a_k\dots a_2a_1)$，元素集合完全一致）。由引理 5，$\mathrm{fix}$ 只依赖"环的集合划分与环长"，故 $h$ 与 $h^{-1}$ 给出同一个 $\mathrm{fix}$ 值。$\blacksquare$

**结论**：$\mathrm{fix}(g)$ 只依赖 $g$ 的**轮换类型**（cycle type），不依赖具体编号。代码里我们就直接按 $i\to a[id][i]$ 走环、记录环长（引理 6 保证这样偷懒合法）。

于是 $\mathrm{fix}(g)$ 变成一个纯粹的小整数问题：

> 给定 $l_1..l_c$，把每个环染 $R/B/G$ 之一，要求被染 $R$ 的环长之和 $=S_r$、$B$ 的 $=S_b$、$G$ 的 $=S_g$，问方案数。

**引理 7（无解的快速判据）** 若当前置换有一个环长 $l_t>\max\{S_r,S_b,S_g\}$，则 $\mathrm{fix}(g)=0$。

**证明**：该环只能染红、蓝、绿之一（引理 5 强制整环同色）。染红则红总量 $\ge l_t>S_r$，与"红恰为 $S_r$"矛盾；染蓝、染绿同理（$l_t$ 严格大于三个配额，故三个都不满足）。三个分支全部不可行，方案数为 $0$。$\blacksquare$

直接推论：Hint 数据里 `231` 是单个 $3$ 环，而 $\max\{S_r,S_b,S_g\}=1<3$，故 $\mathrm{fix}=0$，与 §5 验证 1 的 DP 轨迹一致。

### 2.6 环染色计数：三维压二维的 DP

最直接的状态是 $dp[c][i][j][k]$：前 $c$ 个环，用了 $i$ 红 $j$ 蓝 $k$ 绿。但 $i+j+k$ 必须等于前 $c$ 个环的长度和 $\mathrm{pre}[c]=\sum_{t\le c}l_t$，所以 **$k$ 是冗余维度**。

**引理 8（降维合法性）** 处理完前 $c$ 个环后，若红色总量为 $i$、蓝色总量为 $j$，则绿色总量被唯一确定为 $\mathrm{pre}[c]-i-j$。

**证明**：前 $c$ 个环的每个位置必须且只能染一种颜色，故 $i+j+k=\sum_{t=1}^{c}l_t=\mathrm{pre}[c]$。给定 $i,j$ 时 $k$ 由等式解出，且解唯一。反之，任何合法的 $(i,j)$ 也必然满足 $0\le k=\mathrm{pre}[c]-i-j\le S_g$，这个不等式就是我们唯一需要显式检查的绿色约束。$\blacksquare$

于是写成 $dp[c][i][j]$，转移三种选择（本环染红/蓝/绿）：

$$
\begin{aligned}
dp[c][i+l_c][j]&\mathrel{+}=dp[c-1][i][j] && (i+l_c\le S_r)\\
dp[c][i][j+l_c]&\mathrel{+}=dp[c-1][i][j] && (j+l_c\le S_b)\\
dp[c][i][j]&\mathrel{+}=dp[c-1][i][j] && (\mathrm{pre}[c]-i-j\le S_g)
\end{aligned}
$$

初值 $dp[0][0][0]=1$，答案 $\mathrm{fix}(g)=dp[c][S_r][S_b]$（此时 $\mathrm{pre}[c]=n$，绿色数 $=n-S_r-S_b=S_g$，恰好自动满足，无需再查）。

**引理 9（DP 正确性）** 按上述转移算出的 $dp[c][i][j]$ 等于"给前 $c$ 个环染色，使红总量 $i$、蓝总量 $j$（从而绿总量 $\mathrm{pre}[c]-i-j$，且全程 $\le S_g$）"的方案数。

**证明（对 $c$ 归纳）**：
- $c=0$：唯一的"空染色"给出 $i=j=0$，$dp[0][0][0]=1$，其余 $dp[0][i][j]=0$（数组清零保证），与事实一致。
- 归纳步：任一前 $c$ 个环的合法染色，第 $c$ 个环的颜色只有 $3$ 种，去掉第 $c$ 个环后得到唯一的"前 $c-1$ 个环"染色。这把方案集合按第 $c$ 环的颜色划分成**两两不交**的三块：
  - 第 $c$ 环染红：去掉它后红总量 $i-l_c$，方案数由归纳假设为 $dp[c-1][i-l_c][j]$；且必须 $i-l_c\ge 0$，即代码里的 $i+l_c\le S_r$ 方向的界检查。
  - 染蓝：同理 $dp[c-1][i][j-l_c]$。
  - 染绿：$dp[c-1][i][j]$，且新绿色数 $\mathrm{pre}[c]-i-j\le S_g$ 必须成立（旧的绿色数 $=\mathrm{pre}[c-1]-i-j\le \mathrm{pre}[c]-i-j$ 已自动 $\le S_g$，故只需检查新值）。另外绿色数不会为负：归纳保证可达状态满足 $i+j\le\mathrm{pre}[c-1]$，于是 $\mathrm{pre}[c]-i-j\ge l_c>0$；代码里 $i+j>\mathrm{pre}[c-1]$ 的格子恒为 $0$，被 `if(!v)` 直接跳过，不会产生非法转移。
  - 三块相加即转移式，且不会出现"绿色在中途超了 $S_g$ 后来又缩回来"的情况，因为绿色量随 $c$ 单调不降。$\blacksquare$

**复杂度**：单个置换 $O(c\cdot(S_r+1)(S_b+1))\le 60\cdot 21\cdot 21\approx 2.6\times 10^4$；总共 $|G|\le 61$ 个置换，约 $1.6\times 10^6$ 次操作，远小于时限。

**代码里的两个细节**：
1. 第一维**保留环序号 $c$** 而不用滚动数组，从结构上杜绝同一环被用两次（滚动数组必须倒序循环，更易错）；`dp` 按编译期常量开成 $70\times25\times25\approx4.4\times10^4$ 个 `int`，每个置换开始前用 `fill_n(&dp[0][0][0], mxt*mxs*mxs, 0)` 全量清零，避免漏清。
2. `if(!v) continue;` 只是剪枝（$P<100$ 时 $0$ 很多），不影响正确性。

### 2.7 归约到更简单的问题：分母到底是谁

分母是 $|G|$，我们必须把 $|G|$ 弄准。题面给了两条保证（封闭性、存在逆元），先看它们字面上说什么。

**引理 10（字面保证 ⟹ 恒等置换已在 $m$ 行中）** 若 $S$（$m$ 个给定排列）对复合封闭，且每个元素在 $S$ 中有逆元，则 $\mathrm{id}\in S$，从而 $(S,\circ)$ 本身就是群，$|G|=|S|=m$。

**证明**：取任意 $\sigma\in S$。由"存在逆元"，有 $\tau\in S$ 使 $\sigma\tau$ 相当于不洗牌，即 $\sigma\tau=\mathrm{id}$（作为置换相等）。$\sigma\tau$ 是 $S$ 中两元素的复合，由封闭性它必须等于 $S$ 中某一行，故 $\mathrm{id}\in S$。（备选论证：$\sigma$ 是有限集合上的置换，其阶 $k\ge 1$ 满足 $\sigma^k=\mathrm{id}$，把 $\sigma^k$ 看作"$k$ 次洗牌"，封闭性要求它等于 $S$ 中某一行。）
再由结合律（置换复合天然满足）、单位元存在（刚证）、逆元存在（保证 B）得 $(S,\circ)$ 是群，且题面说 $m$ 种洗牌法"不同"，故 $|S|=m$。$\blacksquare$

**但 Hint 的数据违反引理 10 的前提**：Hint 描述的那组数据里 $m=2$，两行是 `2 3 1` 与 `3 1 2`，二者互逆，它们的复合是恒等排列 `1 2 3`，而 `1 2 3` **没有出现在这两行里**。也就是说：出题人的"封闭"是**不严格**的，他想表达的其实是"除了不洗牌这个平凡操作以外，任意多次洗牌的结果都落在这 $m$ 行里"。（按任务要求：一切以本地题面为准，此处题面保证与题面 Hint 冲突，本文按 Hint 的实现含义处理并在文中注明。）

**用 Hint 校准**（这一步是决定性的，两种分母算出的结果不同）：

| 假设 | 求和项 | 分母 | 结果 | 与 Hint 的 $2$ |
|---|---|---|---|---|
| $|G|=m=2$（只用给出的两行） | $\mathrm{fix}(\texttt{231})+\mathrm{fix}(\texttt{312})=0+0$ | $2$ | $0$ | ✗ |
| 给出的两行 $+\mathrm{id}$，分母按 $m=2$ | $6+0+0=6$（漏分母一致性） | $2$ | $3$ | ✗ |
| $G=S\cup\{\mathrm{id}\}$，$|G|=m+1=3$ | $6+0+0$ | $3$ | $2$ | ✓ |

**结论 / 采用的约定**：把 $G$ 取为 $S\cup\{\mathrm{id}\}$，$|G|=$ 不同元素个数（表中第二行的错误写法正是"恒等只加到分子、不加到分母"，很多同学的 WA 就来自这里）。题面约束 $m+1<P$ 正是为了让这个分母在模 $P$ 下可逆（若只可能除以 $m$，出题人写 $m<P$ 就够了，不必多要一个 $+1$）——这是约定与题面互相印证的旁证。

**代码里的防御**：先扫一遍 $m$ 行看有没有恒等置换。
- 有（数据真按引理 10 字面满足）：$|G|=m$，不补行，分母 $m$。
- 没有（Hint 那组数据，以及大概率所有官方数据）：补一行恒等，$|G|=m+1$，分母 $m+1$。

这样两种"出题人可能的本意"都能给出正确的 Burnside 值，且绝不会把 $\mathrm{id}$ 数两次。$n\le 60$、$m\le 60$，判断恒等只需 $O(mn)$，代价可忽略。

**保证一旦被破坏会怎样（反面例子，说明为什么不能自作聪明）**：$S_r=S_b=S_g=1$，$m=1$，唯一一行 `2 3 1`。此时真实群 $\langle S\rangle=\{\mathrm{id},\texttt{231},\texttt{312}\}$ 阶为 $3$，正确答案 $\frac{6+0+0}{3}=2$；而我们的公式只能算出 $\frac{6+0}{2}=3$（模 $101$ 下 $6\cdot 51=306\equiv 3$）。可见本题**必须**依赖"群元素个数 $\le m+1$"这一保证，不能靠补全生成群（一般 $|G|$ 可达 $60!$，无法枚举）。

### 2.8 溢出与取模防护

Burnside 给出的是整数 $\frac{1}{|G|}\sum_g\mathrm{fix}(g)$，但我们在 $\bmod P$ 下运算，"除法"必须换成乘逆元。

**引理 11（模意义下除法合法）** 设 $P$ 为质数，$1\le t\le 61<P$。则 $t^{P-2}\bmod P$ 是 $t$ 在 $\mathbb{Z}_P$ 中的乘法逆元，即 $t\cdot t^{P-2}\equiv 1\pmod P$。

**证明**：由费马小定理，对 $\gcd(t,P)=1$ 有 $t^{P-1}\equiv 1\pmod P$。题面保证 $P$ 是质数且 $P>m+1\ge t$，故 $P\nmid t$，即 $\gcd(t,P)=1$，费马小定理适用。$t^{P-1}=t\cdot t^{P-2}\equiv 1$，所以 $t^{P-2}$ 就是 $t$ 的逆元；逆元的唯一性由"$t$ 可消去（$\gcd(t,P)=1$）"保证：若 $ta\equiv tb$，则 $t(a-b)\equiv 0$，域中无零因子，得 $a\equiv b$。$\blacksquare$

（费马小定理本身：$\{t,2t,\dots,(P-1)t\}$ 模 $P$ 后是 $\{1,\dots,P-1\}$ 的一个排列——若 $at\equiv bt$，$1\le a,b\le P-1$，由上面消去律得 $a\equiv b$，即 $a=b$，共 $P-1$ 个互不同余的非零剩余，故构成排列。两集合乘积相等：$t^{P-1}(P-1)!\equiv (P-1)!\pmod P$，而 $(P-1)!\not\equiv 0$，消去即得 $t^{P-1}\equiv 1$。）

**引理 12（先取模再除，与先除再取模等价）** 设整数 $A$ 可被 $t$ 整除（本题 $A=\sum_g\mathrm{fix}(g)$，$t=|G|$，由引理 4 保证整除）。则
$$\frac{A}{t}\bmod P\ \equiv\ (A\bmod P)\cdot(t^{-1}\bmod P)\pmod P .$$

**证明**：记 $q=A/t\in\mathbb{Z}$，则 $A=qt$。两边模 $P$：$A\bmod P\equiv qt\bmod P$。右乘 $t^{-1}$（引理 11 提供）得 $(A\bmod P)\,t^{-1}\equiv q\,t\,t^{-1}\equiv q\pmod P$。左边正是代码算出的值，右边是所需的 $\frac{A}{t}\bmod P$。$\blacksquare$

**溢出账本**（本题 $P<100$ 很宽松，但把量级写清是习惯）：`dp` 值 $<P<100$；`dp[...]+v` 与 `ans+calc(id)` 均 $<2P<200$ 且加完立刻取模；`qpow` 里 `x*x`、`r*x` $<(P-1)^2<10^4$——`int` 全都够，仍按风格用 `i64` 写快速幂，避免换到大模数时踩坑；环长与前缀和 $\le n\le 60$。

真正的隐患不在数值溢出，而在**两处逻辑溢出**：
1. 绿色维度靠 $\mathrm{pre}[c]-i-j$ 推出来，如果忘记检查 $\le S_g$，会统计出"绿色超额"的假方案（引理 9 的第三块划分条件）。
2. 恒等置换漏加或多加（§2.7），分子分母不一致。

## 3. 模式总结（Pattern Summary）

按思考顺序，一个技巧一条，重复出现的技巧拆开写：

1. **"互相可达算同一种"** → 识别为群作用的轨道计数（§2.1）。
2. **先解最简情形**（$m=0$）→ 拿到基线值 $|X|=\binom{n}{S_r,S_b,S_g}$，用来校验分母（§2.2）。
3. **怀疑"除以常数"** → 构造轨道大小不均的反例（§2.3 的 $G=\{\mathrm{id},(12)\}$，轨道大小 $1$ 与 $2$ 并存）。
4. **数轨道** → Burnside 引理：轨道数 $=\frac{1}{|G|}\sum\mathrm{fix}(g)$（§2.4，双重计数证明）。
5. **轨道—稳定子定理** → 用"$g\mapsto gf$ 的原像是稳定子的左陪集"证明 $|\mathrm{Orb}||\mathrm{Stab}|=|G|$（引理 3，也常单独出题）。
6. **置换的不动点** → 环分解 + "环内同色"（引理 5）：把位置级约束降为环级约束。
7. **只依赖轮换类型** → 置换与其逆同环型，方向约定可随便选（引理 6）。
8. **环上带数量限制染色** → 分组计数 DP（每个环必须整体染一色，本质是"三选一的多维背包"，§2.6）。
9. **DP 降维** → 被强制的守恒式（$i+j+k=\mathrm{pre}[c]$）可以把一维省掉，只显式检查剩余那一维的上界（引理 8）。
10. **背包式 DP 防重复使用** → 第一维保留"环序号"而不是滚动数组，从结构上杜绝同一环被选两次。
11. **模 $P$ 下的除法** → 分母 $|G|<P$ 且 $P$ 质数 ⟹ 费马小定理 $t^{P-2}$（§2.8，含整除性等价证明）。
12. **题面保证与样例冲突** → 以样例（Hint）为准校准实现，把两种解释都写成防御分支（§2.7）。
13. **约束里的"多余 $+1$"是线索** → $m+1<P$ 暗示分母是 $m+1$。
14. **小模数 + 小数据** → 逐次取模，量级账本写清楚，风险放在"逻辑溢出"（漏查绿色上界）而不是数值溢出。

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 取值范围 |
|---|---|---|
| $S_r,S_b,S_g$ | 三种颜色的**精确**张数 | $\le 20$，可为 $0$ |
| $n$ | $S_r+S_b+S_g$，牌的张数 | $\le 60$ |
| $m$ | 题面给出的洗牌法种数 | $\le 60$ |
| $P$ | 质数模数 | $m+1<P<100$ |
| $S$ / $G$ | 给定排列集合 / 实际用于 Burnside 的群 $=S\cup\{\mathrm{id}\}$（若 $\mathrm{id}\notin S$） | $|G|=t\in\{m,m+1\}$ |
| $a[i][j]$ | 第 $i$ 种洗牌法的排列，新位置 $j$ 取原位置 $a[i][j]$ | $1\le a[i][j]\le n$ |
| $c,\;l_1..l_c$ | 当前置换的环数、各环长 | $c\le n$，$\sum l_i=n$ |
| $\mathrm{pre}[x]$ | $\sum_{i\le x}l_i$，前 $x$ 个环覆盖的位置数 | $\le n$ |
| $dp[c][i][j]$ | 前 $c$ 个环染色，红共 $i$、蓝共 $j$（绿 $=\mathrm{pre}[c]-i-j$）的方案数 | $\bmod P$ |
| $t$ | 代码里累计的群元素个数（分母） | $\le 61$ |

### 4.2 步骤

1. 读入 $S_r,S_b,S_g,m,P$，令 $n=S_r+S_b+S_g$；读入 $m$ 行排列到 $a[1..m][1..n]$。
2. 扫 $m$ 行，记录 $has\_id$：是否存在某行满足 $\forall j,\ a[i][j]=j$。
3. 若 $\neg has\_id$：把恒等排列写入 $a[m+1]$，此时待枚举的置换总数为 $m+1$；否则为 $m$。
4. 对每个待枚举的置换 $g$（编号 $\mathit{id}$）：
   1. 环分解：`fill_n(vis, n+1, false)`；对每个未访问的 $i$ 沿 $cur\to a[\mathit{id}][cur]$ 走到底，记录环长 $\mathit{len}[{++cyc}]$。
   2. 前缀和 $\mathrm{pre}[0..cyc]$。
   3. 清零 $dp$，置 $dp[0][0][0]=1$。
   4. 逐环转移三种染法，带界检查 $i+l_c\le S_r$、$j+l_c\le S_b$、$\mathrm{pre}[c]-i-j\le S_g$，每次加法后立即 $\bmod P$。
   5. $\mathrm{fix}(g)=dp[cyc][S_r][S_b]$，累加进 $ans$ 并取模。
5. $ans = ans\cdot t^{P-2}\bmod P$（$t$ 即 $|G|$）。
6. 输出 $ans$ 与 `'\n'`。

### 4.3 复杂度

- 环分解 $O(n)$ 每置换；每个置换的 DP $O(c\,(S_r+1)(S_b+1))$，最坏 $60\times21\times21\approx2.6\times10^4$。
- 总计 $O(t\cdot c\cdot S_r\cdot S_b)$，$t\le61$ ⟹ 约 $1.6\times10^6$ 次常数级操作；空间 $dp$ 数组 $70\times25\times25$ 个 `int` ≈ 172 KB，全局静态，无栈风险。

### 4.4 验证状态

- **官方样例对标**：本地题面 `P1446.md` 无 Sample 段落，只有 Hint 一句"有 $2$ 种本质上不同的染色法"，由它可读出 $S_r=S_b=S_g=1$、$m=2$、两行 `2 3 1` 与 `3 1 2`，但**题面没给模数取值**，故记为"本地题面无完整样例，无法与官方答案逐字对标"，只以 Hint 的结论 $2$ 作对标值；手算复现见 §5 验证 1，**结果一致**。
- 另有 $4$ 组自造边界数据（$S_g=0$、$S_r=S_b=0$、$m=0$、恒等置换直接出现在输入中），逐状态列出 DP 轨迹，见 §5 验证 2–5。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{65};      //n=Sr+Sb+Sg<=60
constexpr int mxs{25};      //max{Sr,Sb,Sg}<=20
constexpr int mxt{70};      //洗牌法数 m+1<=61

int sr,sb,sg,m,P,n;
int a[mxt][mxn];            //a[i][j]:第 i 种洗牌法把位置 j 换成原来的 a[i][j]
int len[mxn],pre[mxn],cyc;
int dp[mxt][mxs][mxs];
bool vis[mxn];

i64 qpow(i64 x,i64 b,i64 mod)
{
	i64 r=1%mod;
	for(;b;b>>=1,x=x*x%mod)
		if(b&1)
			r=r*x%mod;
	return r;
}

bool is_id(int id)
{
	for(int i=1;i<=n;++i)
		if(a[id][i]!=i)
			return false;
	return true;
}

int calc(int id)            //当前置换的不动点个数
{
	cyc=0;
	fill_n(vis,n+1,false);
	for(int i=1;i<=n;++i)
	{
		if(vis[i])
			continue;
		int cur=i,cnt=0;
		while(!vis[cur])
		{
			vis[cur]=true;
			++cnt;
			cur=a[id][cur];
		}
		len[++cyc]=cnt;
	}
	pre[0]=0;
	for(int c=1;c<=cyc;++c)
		pre[c]=pre[c-1]+len[c];
	fill_n(&dp[0][0][0],mxt*mxs*mxs,0);
	dp[0][0][0]=1;
	for(int c=1;c<=cyc;++c)
		for(int i=0;i<=sr;++i)
			for(int j=0;j<=sb;++j)
			{
				int v=dp[c-1][i][j];
				if(!v)
					continue;
				if(i+len[c]<=sr)                       //本环染红
					dp[c][i+len[c]][j]=(dp[c][i+len[c]][j]+v)%P;
				if(j+len[c]<=sb)                       //本环染蓝
					dp[c][i][j+len[c]]=(dp[c][i][j+len[c]]+v)%P;
				if(pre[c]-i-j<=sg)                     //本环染绿,绿色数=pre[c]-i-j
					dp[c][i][j]=(dp[c][i][j]+v)%P;
			}
	return dp[cyc][sr][sb];
}

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>sr>>sb>>sg>>m>>P;
	n=sr+sb+sg;
	for(int i=1;i<=m;++i)
		for(int j=1;j<=n;++j)
			cin>>a[i][j];
	int ans=0,t=0;
	bool has_id=false;
	for(int i=1;i<=m;++i)
		if(is_id(i))
			has_id=true;
	for(int i=1;i<=m;++i)
	{
		ans=(ans+calc(i))%P;
		++t;
	}
	if(!has_id)                //恒等置换必须自己补上,否则 Burnside 少一项
	{
		for(int i=1;i<=n;++i)
			a[m+1][i]=i;
		ans=(ans+calc(m+1))%P;
		++t;
	}
	ans=ans*qpow(t,P-2,P)%P;
	cout<<ans<<'\n';
	return 0;
}
```
