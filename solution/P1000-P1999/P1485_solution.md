# P1485 火枪打怪

> 标签：线性数据结构 / 二分 · 难度：提高/省选-
> 本地题面：`P1485.md`（**无样例**，故本文所有验证均为手算）

## 1. 重新读题

$n$ 只怪物排成一排，第 $i$ 只血量 $m_i$。给定子弹数 $k$，求**最小正整数**威力 $p$，使得"在任意位置上发射共 $k$ 发威力均为 $p$ 的子弹"能把所有怪物打死。

规则细节（逐条按题面抠）：

- 子弹落在第 $i$ 只：$i$ 本人掉 $p$ 血；**只向左溅射**，第 $j<i$ 掉 $\max(0,\,p-(i-j)^2)$。
- 血量 **小于 0** 才算死 $\Rightarrow$ 每只怪需要累计伤害 $\ge m_i+1$（整数），不是 $\ge m_i$。
- 尸体不消失、位置不变 $\Rightarrow$ 可以对已死的怪继续开枪（落点是"坐标"而非"活怪"）。
- $k$ 发子弹威力全部相同，等于待求的 $p$。

**形式化**（下文一律 0-based，与代码一致；题面是 1-based）：记需求 $R_j=m_j+1$，落点计数向量 $c\in\mathbb{Z}_{\ge0}^n$，

$$D_j(c)=\sum_{i=j}^{n-1} c_i\,\max\!\big(0,\;p-(i-j)^2\big),\qquad \mathrm{check}(p)\iff \min\Big\{\textstyle\sum_i c_i\ \Big|\ \forall j:\ D_j(c)\ge R_j\Big\}\le k$$

**三处容易读错的细节**

1. "血量小于 $0$ 时死亡"是**严格**小于，所以伤害阈值是 $m_i+1$。若按 $D_i\ge m_i$ 判定，会在 $m_i$ 恰好吃满时整片 WA（$p\mid m_i$ 的数据尤其密集）。
2. 溅射**只向左**（题面 "$j<i$"）。因此最右只怪 $n-1$ 只能被落在 $n-1$ 的子弹打到——这是整道题贪心方向的来源。
3. 落点是**位置**，尸体不消失。贪心过程中"已经死透的怪"仍可作落点，不必为它保留名额。

数据范围：$n\le 5\times10^5$，$k\le 5\times10^5$，$1\le m_i\le 10^{10}$；30% 有 $n\le 300$。子任务只给两档（$300$ → $5\times10^5$），跨度 $10^3$ 倍，说明单次判定必须近线性；若每次判定带 $\log n$（$5\times10^5\times19\times38\approx3.6\times10^8$ 次运算）按量级估算很危险。

**值域与答案量级**：$p$ 下界 1；上界见 §2.6 引理 F，可达 $(n-1)^2+\max m+1\approx 2.6\times10^{11}$，$\Rightarrow$ $p$、伤害、子弹计数都必须 `long long`。


## 2. 思维链（Chain-of-thought）

### 2.1 溅射的形状

落点 $i$ 对 $j\le i$ 的伤害只依赖距离 $t=i-j\ge 0$：

$$w_t=p-t^2\ \text{（取 } \max 0\text{）},\qquad w_0=p,\ w_1=p-1,\ w_2=p-4,\dots$$

**性质 1（溅射半径）** $w_t>0\iff t^2<p\iff t\le r$，其中 $r=\big\lfloor\sqrt{p-1}\,\big\rfloor$。

**证明**：$p,t$ 均为整数，$t^2$ 为整数，故 $p-t^2>0\iff p-t^2\ge1\iff t^2\le p-1\iff t\le\sqrt{p-1}$；$t$ 是整数，$t\le\sqrt{p-1}\iff t\le\lfloor\sqrt{p-1}\rfloor$。$\blacksquare$

于是 $D_j$ 其实是**局部**量：只由 $c_j,c_{j+1},\dots,c_{j+r}$ 决定，更右的子弹贡献 0。

**性质 2（越远越亏）** $w_0>p>w_1>w_2>\cdots>w_r>0$，即 $t\ge 1$ 时 $w_t\le p-1<p$。

**证明**：$w_t-w_{t+1}=(p-t^2)-(p-(t+1)^2)=2t+1\ge1>0$，严格递增地衰减；且 $w_1=p-1$。$\blacksquare$

**性质 3（一发子弹最多能"顺带"多少）** 一颗子弹对左侧（$t\ge1$）的总溅射量 $\sum_{t=1}^{\min(r,\,i)}(p-t^2)\le r(p-1)\le\sqrt p\cdot p=p^{3/2}$（左侧至多 $r$ 项、每项 $\le w_1=p-1$；再用 $r=\lfloor\sqrt{p-1}\rfloor<\sqrt p$）。这在 $p\sim2.6\times10^{11}$ 时是 $10^{17}$ 量级——提醒我们伤害累加值必须走 64 位（§2.8）。

**先做一遍极小规模的穷举手感**（$n=2,\ p=3,\ R=(2,2)$，0-based）：

| 落点方案 | $D_1$ | $D_0$ | 可行 | 子弹数 |
|---|---|---|---|---|
| 1 发在 1 | $3$ | $3-1=2$ | ✅ | 1 |
| 1 发在 0 | 0 | $3$ | ❌（怪 1 没死）| 1 |
| 2 发在 0 | 0 | 6 | ❌ | 2 |

关键观察：**落点越靠右，越能"一石多鸟"；但要弄死最右那只，只有落在它自己身上这一条路。**

### 2.2 简化版：先砍掉溅射

**退化 A（$r=0$，即 $p=1$）**：$w_0=1$、无溅射，问题退化为"每只怪要吃 $m_i+1$ 发"，$\mathrm{check}(1)\iff\sum_i(m_i+1)\le k$。$\Rightarrow$ 无溅射版是"逐点独立求和"，一眼可判。

**退化 B（$k\ge n$）**：$p=\max_i m_i+1$ 时每只怪发 1 发即可，$\mathrm{check}$ 平凡为真。$\Rightarrow$ 真正棘手的是 $k<n$，即"名额不够，必须靠溅射分摊"。

**退化 C（$k=1$）**：唯一的子弹必须落在最右怪 $n-1$（引理 B：$n-1$ 只能被自己吃到），于是 $\mathrm{check}(p)\iff\forall j:\ p-(n-1-j)^2\ge m_j+1$，即 $p\ge\max_j\big(m_j+1+(n-1-j)^2\big)$。
手算 $n=3,\ m=(1,1,1)$：先写出 $\max(1+4,1+1,1+0)=5$？**漏了 $+1$**——$j=0$ 时 $(n-1-j)^2=4$、$R_0=2$，要求 $p\ge6$；$j=1$：$p\ge2+1=3$；$j=2$：$p\ge2$。$\Rightarrow$ 答案 $6$（这个数在 §4.4 的 T3 里用作手算轨迹核对）。

**退化 C 的启示**：$k=1$ 时答案是 $(n-1)^2$ 量级 —— 这直接预告了 §2.6 的二分上界（引理 F）。

### 2.3 把"最优化 $p$"改成"判定 $p$"

固定 $p$，设落在位置 $i$ 的子弹数为 $c_i\ (\ge 0,\ \text{整数})$，则位置 $j$ 受到的总伤害

$$D_j=\sum_{i\ge j} c_i\,\max\!\big(0,\,p-(i-j)^2\big)$$

判定问题 $\mathrm{check}(p)$：是否存在 $\sum_i c_i\le k$ 使所有 $D_j\ge R_j=m_j+1$。

**引理 A（"$\le k$" 与 "$=k$" 等价）** 若存在 $c$ 满足 $\sum_i c_i\le k$ 且全部打死，则一定存在恰好 $k$ 发的方案。

**证明**：把剩余的 $k-\sum_i c_i$ 发子弹**全部**补到位置 $0$ 上。$D_0$ 只增不减，$D_j\ (j\ge1)$ 完全不受影响（子弹只向左溅射，落在 $0$ 上不波及任何右侧位置）。故所有不等式仍成立。$\blacksquare$

所以后文一律用"$\le k$"来判定，少一个方向的边界讨论。

**为什么要归约成判定**：原问题是"最小 $p$ 使某整数规划可行"。$p$ 固定后 $\{c_i\}$ 的耦合只发生在长度 $r+1$ 的窗口内（性质 1），结构远比"同时选 $p$ 和 $c$"简单；能不能二分，取决于 $\mathrm{check}$ 的单调性 —— 放到 §2.6 证明。

### 2.4 从右往左贪心（先猜，后证）

**为什么方向必须是"从右往左"**：位置 $i$ 的子弹只影响 $\le i$ 的位置。所以站在 $j$ 时，所有 $i>j$ 的 $c_i$ 已经定死，而 $c_j$ **不可能**再帮到任何 $>j$ 的怪，即"$j$ 的伤害缺口只能由 $c_j$ 来补"——这是无后效性的来源。

**贪心方案 G**（$j$ 从 $n-1$ 递减到 $0$）：

$$g_j=\max\!\Big(0,\ \Big\lceil \frac{R_j-\sum_{i>j} g_i\max(0,p-(i-j)^2)}{p}\Big\rceil\Big),\qquad \text{cost}(p)=\sum_j g_j$$

**引理 B（最右端的强制性）** 任何可行的 $c$ 都满足 $c_{n-1}\ge g_{n-1}=\lceil R_{n-1}/p\rceil$。

**证明**：$D_{n-1}=\sum_{i\ge n-1}c_i\max(0,p-(i-(n-1))^2)$ 里只有 $i=n-1$ 一项（$i>n-1$ 不存在），系数是 $p-0^2=p$。故 $D_{n-1}=c_{n-1}p\ge R_{n-1}\Rightarrow c_{n-1}\ge\lceil R_{n-1}/p\rceil=g_{n-1}$。$\blacksquare$

这解释了"最右怪只能用落在它自己身上的子弹打"这条直觉，也说明贪心的第一步没有自由度。

### 2.5 贪心的可疑之处与反例

猜出 G 之后必须先怀疑它。三个疑问：

**(Q1) 方向选错会怎样？** 试"从左往右、在当前怪身上补枪"的对称贪心 G'。反例：$n=2,\ k=1,\ m=(1,1)$，$p=3$（即 §2.1 表格那个实例）。
- G'：先看怪 0，缺口 $R_0=2$，在位置 0 补 $\lceil2/3\rceil=1$ 发（$D_0=3\ge2$ ✓）；再看怪 1，$D_1=0<2$，在位置 1 再补 1 发 ⇒ cost $=2>k=1$ ⇒ G' 判"不可行"。
- G（右起）：怪 1 补 $\lceil2/3\rceil=1$ 发，溅射给怪 0 是 $p-1=2$，恰好 $D_0=2\ge R_0$ ⇒ cost $=1\le k$ ✓。

⇒ 同一个实例 G' 比 G 多花 1 发。**左起贪心错在"在 $j$ 身上补枪对 $>j$ 毫无帮助"，浪费；右起则每一发都顺手把左侧也打了。**

**(Q2) "均摊/按比例"式做法会失败。** 反例：$n=2,\ p=5,\ k=3,\ m=(9,5)$，即 $R=(10,6)$。
- 天真做法（位置 1 放 1 发、位置 0 放 2 发）：$D_1=1\cdot5=5<6$ ⇒ 怪 1 不死 ❌。
- G：$g_1=\lceil6/5\rceil=2$，$D_1=10\ge6$ ✓；$D_0$ 从右侧得 $2w_1=2\cdot4=8$，缺口 $10-8=2$，$g_0=\lceil2/5\rceil=1$；cost $=3\le k$ ✓，且 $D_0=1\cdot5+8=13\ge10$ ✓。

⇒ 说明"伤害必须先在右端凑够整数发"，任何非整份的拆分都会漏掉最右端。

**(Q3) 最关键的一条：右端"多塞几发"会不会更省总子弹？** 贪心在每个位置只用"最少必要发数"，但多塞一发在 $j+1$ 会给 $j$ 送 $w_1=p-1$ 的伤害。若"1 发换 1 发"不划算、"$t$ 发换 $<t$ 发"更不划算，则贪心最优。先算一个小实例看是不是**只会打平**：$n=2,\ p=5,\ R=(5,1)$。
- G：$g_1=\lceil 1/5\rceil=1$（$D_1=5\ge1$），溅射 $D_0=4$，缺口 $5-4=1$，$g_0=\lceil 1/5\rceil=1$ ⇒ cost $2$。
- 另一方案：$c_1=2,\ c_0=0$：$D_1=10$，$D_0=8\ge5$ ⇒ cost $2$。**打平，没更省。**
原因即性质 2：右移一发的效率是 $p-1<p$，"打折"的。但要成为证明，还需下面的**修剪交换论证**。

**引理 C（左移不减伤）** 把一发子弹从位置 $q\ge1$ 移到 $q-1$：位置 $q-1$ 的伤害从 $w_1=p-1$ 变为 $w_0=p$（$+1$）；任意 $j<q-1$ 的伤害从 $w_{q-j}$ 变为 $w_{q-1-j}\ (\ge w_{q-j})$；位置 $q$ 的伤害减少 $p$。除 $q$ 以外**所有位置伤害不降**。

**证明**：对 $j\le q-1$，新距离 $t'=(q-1)-j=(q-j)-1=t-1$，由性质 2（已证 $w_t-w_{t+1}=2t+1>0$）得 $w_{t-1}\ge w_t$；$t=0$（即 $j=q-1$）时 $w_1=p-1\le p=w_0$。位置 $q$：原来吃 $w_0=p$，移到 $q-1$ 后 $q$ 吃 $0$（子弹不向右溅射），故恰减 $p$。$\blacksquare$

**引理 D（修剪交换论证：$\text{cost}(p)$ 全局最小）** 设 $g$ 为贪心 G 的输出，则对任意可行 $c$ 有 $\sum_i c_i\ge\sum_i g_i$。

**证明**：从右往左逐位"修剪"。构造序列 $c^{(n)}=c$；对 $j=n-1,n-2,\dots,0$，令 $c^{(j)}$ 为把 $c^{(j+1)}$ 的第 $j$ 位改成 $g_j$、其余不动的向量。

*可行性保持*：归纳假设 $c^{(j+1)}$ 对所有位置可行，且在 $i>j$ 上 $c^{(j+1)}_i=g_i$（前 $n-1-j$ 步已修剪）。
- 位置 $j$：其伤害为 $c^{(j+1)}_j\cdot p+D_j^{>}$，其中 $D_j^{>}=\sum_{i>j}g_i\max(0,p-(i-j)^2)$ 正是贪心看到的溅射量。
  $c^{(j+1)}$ 可行 $\Rightarrow c^{(j+1)}_j p+D_j^{>}\ge R_j\Rightarrow c^{(j+1)}_j\ge\lceil (R_j-D_j^{>})/p\rceil$；
  而 $g_j=\max(0,\lceil (R_j-D_j^{>})/p\rceil)$。因 $c^{(j+1)}_j\ge0$ 恒成立，两种情形都有 $c^{(j+1)}_j\ge g_j$。
  修剪后位置 $j$ 的伤害是 $g_jp+D_j^{>}$：若 $R_j-D_j^{>}>0$ 则 $g_j=\lceil (R_j-D_j^{>})/p\rceil$，$g_jp\ge R_j-D_j^{>}$ ✓；
  若 $R_j-D_j^{>}\le0$ 则 $g_j=0$，$g_jp+D_j^{>}=D_j^{>}\ge R_j$ ✓。故 $c^{(j)}$ 在位置 $j$ 仍可行。
- 位置 $i>j$：$c^{(j)}$ 与 $c^{(j+1)}$ 在这些位置上的取值相同，且位置 $i$ 的伤害只依赖 $c_{\ge i}$（子弹不向右溅射），
  而 $c_{\ge i}$ 未被改动 ⇒ 可行性保持。
- 位置 $i<j$：$c^{(j)}_j=g_j\le c^{(j+1)}_j$，只会**减小**左侧伤害，但它们在后续步骤（修剪 $j-1,\dots,0$ 时）
  会被重新补足，故此处不需要成立；最终每个位置都在"它自己那一步"被保证。

*计数单调不增*：每步把第 $j$ 位从 $c^{(j+1)}_j$ 换成 $\le$ 它的 $g_j$，其余不变，故
$\sum_i c^{(j)}_i\le\sum_i c^{(j+1)}_i$。链起来：$\sum_i g_i=\sum_i c^{(0)}_i\le\sum_i c^{(n)}_i=\sum_i c_i$。

*末步收敛*：$c^{(0)}$ 的第 $0$ 位已被设为 $g_0$，且位置 0 可行；所有位置 $0..n-1$ 都在各自步骤被保证 ⇒ $c^{(0)}=g$ 可行。$\blacksquare$

> **对 Q3 的定量直觉**：在 $j+1$ 多塞 $t$ 发给 $j$ 带来 $t(p-1)$ 伤害，至多换回 $\lceil t(p-1)/p\rceil\le t$ 发 $c_j$ 的节省
> （等号可取到，见上面的小实例），即"往右多塞"最多打平；严格结论由引理 D 的修剪论证给出。

于是

$$\boxed{\ \mathrm{check}(p)=\big[\text{cost}(p)=\textstyle\sum_j g_j\le k\big]\ }$$

### 2.6 单调性与二分

**引理 E（$\mathrm{check}$ 关于 $p$ 单调）** 若 $\mathrm{check}(p)$ 为真，则 $\mathrm{check}(p+1)$ 为真。

**证明**：取使 $\mathrm{check}(p)$ 成立的落点计数 $c$（$\sum_i c_i\le k$）。对每个位置 $j$，新伤害 $D_j'=\sum_{i\ge j}c_i\max(0,(p+1)-(i-j)^2)$。逐项比较：固定 $t=i-j\ge0$，函数 $q\mapsto\max(0,q-t^2)$ 关于 $q$ 单调不减（$q_1<q_2$ 时，若 $\max(0,q_1-t^2)=0$ 结论平凡；否则 $q_1-t^2>0\Rightarrow q_2-t^2>q_1-t^2\ge0$）。故每项 $c_i\max(0,(p+1)-t^2)\ge c_i\max(0,p-t^2)$，求和得 $D_j'\ge D_j\ge R_j$；子弹数 $\sum_i c_i\le k$ 未变 ⇒ $\mathrm{check}(p+1)$ 为真。$\blacksquare$

（这里用"沿用同一个 $c$"直接比较，比去分析 $\text{cost}(p)$ 的单调性省事；$\text{cost}(p)$ 单调不增可由引理 D+E 立刻得到，不必单独证。）

**下界** $l=1$：$p$ 是正整数，$p=1$ 是最小候选（此时完全无溅射）。

**上界（引理 F）** 令 $M=\max_i m_i$，$p_0=(n-1)^2+M+1$，则 $\mathrm{check}(p_0)$ 为真（用 1 发）。

**证明**：在位置 $n-1$ 打 1 发。位置 $j$ 吃到的伤害是 $\max(0,p_0-(n-1-j)^2)$。因为 $0\le n-1-j\le n-1$，有 $(n-1-j)^2\le(n-1)^2$，于是 $p_0-(n-1-j)^2\ge(n-1)^2+M+1-(n-1)^2=M+1\ge m_j+1=R_j$（用 $M\ge m_j$）。
括号内非负，故 $\max(0,\cdot)$ 可直接去掉。所有怪一发全打死，子弹数 $1\le k$（题面 $k$ 为正整数）⇒ $\mathrm{check}(p_0)$ 为真。$\blacksquare$

数值上界：$(n-1)^2+M+1\le(5\times10^5)^2+10^{10}+1=2.6\times10^{11}$，$\log_2\approx38$ 次判定。

**二分骨架**（求最小可行 $p$，闭区间下界型）：

```cpp
for(i64 l=1,r=p0;l<r;)
{
	i64 mid=(l+r)>>1;
	if(check(mid)) r=mid; else l=mid+1;
}
```

正确性：不变式"$r$ 始终可行、$l-1$ 始终不可行"。$l<r$ 时 $mid=\lfloor(l+r)/2\rfloor<r$，
可行则把 $r$ 收到 $mid$（$mid$ 可行），不可行则 $l=mid+1$（$mid$ 不可行 ⇒ $l-1\le mid$ 不可行，不变式保住）。
终止 $l=r$，由不变式 $l$ 可行且 $l-1$ 不可行 ⇒ $l$ 是最小可行 $p$。$mid$ 处 $l+r\le 5.2\times10^{11}$ 不爆 `i64`。

### 2.7 溅射的快速计算

**朴素 check：$O(nr)$，太慢。** 贪心每步要算 $D_j^{>}=\sum_{t=1}^{\min(r,\,n-1-j)} g_{j+t}(p-t^2)$，逐项循环长度 $r$。二分中段 $p\sim1.3\times10^{11}$ 时 $r\sim3.6\times10^5$，单次判定就是 $5\times10^5\times3.6\times10^5\approx1.8\times10^{11}$ 次运算 —— 完全不可接受（只有 30% 的 $n\le300$ 允许这种 $O(n^2)$ 级别）。

**结构观察：相邻两列的求和窗口只差"一次平移"。** 扫描过程中维护三个窗口矩（相对**当前列** $j$ 的距离 $d=i-j$）：$S_j=\sum_{i\in W_j}g_i,\ T_j=\sum_{i\in W_j}g_i d_i,\ U_j=\sum_{i\in W_j}g_i d_i^2$，其中 $W_j=\{i:1\le i-j\le r\}$。

则 $D_j^{>}=pS_j-U_j$（把 $\max(0,p-d^2)$ 的 $\max$ 去掉是合法的：窗口内 $d\le r\Rightarrow p-d^2\ge1>0$；窗口外按定义贡献 0）。

**引理 G（平移递推）** 已知 $(S_j,T_j,U_j)$（窗口 $W_j$ 内距离 $d=i-j$），则对下一列 $j-1$：

1. 全体距离 $+1$：$T\leftarrow T+S$，$U\leftarrow U+2T_{\text{old}}+S$；
2. 掉出 $i=j+r$（它现在距离 $r+1$）：$S,T,U$ 各减去 $g_{j+r}\cdot\{1,\ r{+}1,\ (r{+}1)^2\}$；
3. 进入 $i=j$（距离 $1$）：$S,T,U$ 各加上 $g_j\cdot\{1,\ 1,\ 1\}$。

结果恰为 $(S_{j-1},T_{j-1},U_{j-1})$，其中 $W_{j-1}=\{i:1\le i-(j-1)\le r\}=\{j,\dots,\min(n-1,j+r-1)\}$。

**证明**：
1. 每个成员距离从 $d$ 变 $d+1$：$\sum g_i(d+1)=T+S$；$\sum g_i(d+1)^2=\sum g_i(d^2+2d+1)=U+2T_{\text{old}}+S$。必须先更新 $U$ 再更新 $T$，代码里写成 `Q+=2*X+S; X+=S;` 即顺序正确（$U$ 那行用的还是旧 $T$）。
2. 平移后原成员占据距离 $2,\dots,r+1$，而 $W_{j-1}$ 只允许距离 $\le r$，故唯一多出来的是距离 $r+1$ 的 $i=j+r$；它属于旧窗口当且仅当 $j+r\le n-1$（否则该位置不存在），此时 $g_{j+r}$ 已在更早的迭代确定，可直接减掉。
3. $W_{j-1}$ 比"旧窗口平移后"多出 $i=j$（距离 $1$），$g_j$ 刚在本轮确定，加入。三步后集合恰为 $\{j,\dots,\min(n-1,j+r-1)\}=W_{j-1}$，且距离都相对 $j-1$ 记录，故递推成立。$\blacksquare$

**边界情形 $r=0$（即 $p=1$）**：此时 $W_j$ 应为空，但第 3 步会加入距离 $1>r$ 的元素。处理方式：代码把半径钳成 $r'=\max(1,r)$。多出的距离 $1$ 元素系数 $p-1^2=0$，对 $D=pS-U$ 的贡献是 $1\cdot g-1\cdot g=0$，**结果仍正确**；下一轮它到达距离 $2=r'+1$ 立刻被第 2 步剔除。（也可写 `if(r>=1)` 保护，两者等价；钳位少一个分支。）

**每步 $O(1)$ ⇒ 单次判定 $O(n)$，总 $O(n\log((n^2+\max m)))$。**

**数据结构选型比较**（题面标签是"线性数据结构 + 二分"，这里说明为什么**不需要**更重的结构）：

| 方案 | 单次 check | 总计 | 评价 |
|---|---|---|---|
| 逐项窗口（朴素） | $O(nr)$ | $O(nr\log V)$ | 明显超时代数 |
| 3 棵 BIT（存 $\sum g_i,\sum ig_i,\sum i^2g_i$，按绝对下标查询区间 $[j+1,j+r]$） | $O(n\log n)$ | $\approx3.5\times10^8$ | 量级上太危险：每次查询要 3 棵树 $\times$ 2 个前缀，常数大 |
| 线段树（区间矩 + 懒标记） | $O(n\log n)$ | 同上 | 本题没有"任意区间查询/区间修改"需求，纯浪费 |
| **滑窗 + 三矩递推（本解法）** | $O(n)$ | $\approx1.9\times10^7$ | 查询窗口是"每次右移一格"的特殊情形，递推即可 |
| Splay / Treap（第 $k$ 大、区间翻转） | —— | —— | 不涉及：既无动态序统计也无区间赋值，只有定长滑窗 |

（表中的总计列是**操作数量的量级估算**，不是实测耗时。）

**等价写法（绝对下标版）**：令 $A=\sum g_i i^2,\ B=\sum g_i i,\ S=\sum g_i$ 在 $[j+1,j+r]$ 上，则
$\sum g_i(i-j)^2=A-2jB+j^2S$，故 $D_j^{>}=pS-(A-2jB+j^2S)$。恒等式来自
$(i-j)^2=i^2-2ij+j^2$ 逐项展开后按 $\sum$ 线性拆。两版数值范围相同；本文代码选距离版，
因为它不需要在每一步乘 $j^2$（$j^2S$ 单项可到 $1.25\times10^{17}$，虽不爆但更接近上限）。

### 2.8 溢出防护

逐项把最坏值算清楚（$n,k\le5\times10^5$，$M\le10^{10}$，$p\le p_0\approx2.6\times10^{11}$，$r\le\sqrt{p_0}\approx5.1\times10^5$）：

| 量 | 最坏量级 | 结论 |
|---|---|---|
| $p$，$p_0=(n-1)^2+M+1$ | $2.6\times10^{11}$ | `int` 直接爆（$2.1\times10^9$）⇒ **必须 `i64`** |
| $(n-1)*(n-1)$ 若两边都是 `int` | $2.5\times10^{11}$ | 先爆再转，需写成 `(i64)(n-1)*(n-1)` |
| $S=\sum g_i$（窗口内） | $\le k=5\times10^5$ | 见下方"提前退出"论证 |
| $U\le S\cdot r^2<k\cdot p$ | $1.3\times10^{17}$ | 安全（$\ll9.2\times10^{18}$） |
| $pS$ | $1.3\times10^{17}$ | 安全 |
| $g_{j+r}(r+1)^2$（剔除项） | $\le5\times10^5\times2.6\times10^{11}=1.3\times10^{17}$ | 安全；但**乘序**要保证先转 `i64`（`c[]` 本身是 `i64` 即可） |
| $D_j^{>}$ 可能 $\gg R_j$ | $1.3\times10^{17}$ | `need=m[j]+1-D` 可负到 $-1.3\times10^{17}$，仍在 `i64` 内 |
| $(need+p-1)$ | $10^{11}+2.6\times10^{11}$ | 安全 |
| `mid=(l+r)>>1` | $5.2\times10^{11}$ | 安全，且优于 `(l+r)/2` 的写法一致性 |

**为什么 $S\le k$ 一定成立（关键的提前退出）**：单步 $g_j$ 在没有提前退出时可达
$\lceil(m_j+1)/1\rceil\approx10^{11}$（$p=1$ 时），若让它进窗口，$U$ 会变成 $10^{11}\times2.6\times10^{11}=2.6\times10^{22}$ **爆表**。
代码里 `use+=cj; if(use>k) return false;` **排在** `c[j]=cj` 和窗口更新**之前**，
因此一旦 $>k$ 立刻结束，进入窗口的累计子弹恒 $\le k$。⇒ 所有矩都受 $k$ 控制，无需 `__int128`。

**$r$ 的整数平方根**：`sqrtl` 有浮点误差，用两次 `while` 校正（代码 `isqrt`）：
先取近似 $r_0$，再 `while((r+1)^2<=x)++r;` `while(r^2>x)--r;` 把 $r$ 夹到 $\lfloor\sqrt x\rfloor$。
循环次数量级为误差（通常 0~1 次），且 $(r+1)^2\le2.6\times10^{11}$ 不爆 `i64`。

**$\max(0,\cdot)$ 的正确性**：窗口内 $d\le r\Rightarrow d^2\le p-1\Rightarrow p-d^2\ge1$，所以 $D=pS-U$ 恒 $\ge0$ 且不含"负溅射"，
不需要在求和里再取 $\max$；半径外的元素已被第 2 步精确剔除。若忘记钳位/剔除，就会出现 $p-d^2<0$ 被当成伤害**扣掉**的假阴性。

**归约链条（收束）**：

$$\text{最小 }p\ \xrightarrow[\text{引理 E,F}]{\text{单调+可行上界}}\ \text{二分 }p\ \xrightarrow[\text{引理 D}]{\text{贪心最优}}\ \text{cost}(p)=\textstyle\sum g_j\le k\ \xrightarrow[\text{引理 G}]{O(1)\text{ 递推}}\ \text{滑窗三矩}$$

## 3. 模式总结

**模式 1：单调参数 + 判定归约（二分答案）**
"求最小 $p$ 使某方案存在"，且"$p$ 变大只会更容易"（引理 E 的标准证法：**沿用同一个方案**逐项比较）。识别信号：目标是最小/最大整数、答案值域可达 $10^{11}$、存在"给定了 $p$ 就好办"的结构。
上界要**自己构造一个显式可行方案**（这里是 1 发落在最右怪，引理 F），不要拍脑袋写 `1e18`——上界越松，二分次数越多，且 check 里更容易先溢出。

**模式 2：单向作用 ⇒ 从"只能被自己救"的那端开始贪**
影响域是"只向左"（半平面耦合）时，把变量按影响方向排序，从最右（最受限、自由度最小）往左扫，每一步的决策**不可被后续决策替代**，于是"局部最省 = 全局最省"。
证明模板 = **修剪交换论证**（引理 D）：任取可行解，从右往左把每位改成贪心值，每步 (i) 不减总子弹数、(ii) 保持已扫过位置的可行性。该模板适用于一切"后缀/前缀耦合"的覆盖型贪心（区间选点、炮塔覆盖、P1314 式阈值覆盖等）。

**模式 3：$\sum c_i f(i-j)$（$f$ 是 $d$ 的多项式截断）⇒ 滑窗 + 低阶矩**
核 $f(d)=p-d^2$ 在 $d\le r$ 上是距离的**二次多项式**，所以只需保存窗口内的 $0,1,2$ 阶矩；窗口每步平移一格时用 $(d+1)^2=d^2+2d+1$ 做 $O(1)$ 递推（引理 G）。推广：核是 $t$ 次多项式 → 存 $t+1$ 个矩；核非多项式（指数、任意函数）→ 退回 BIT/线段树 $O(\log n)$ 或分段处理。

**模式 4：用"提前退出"把中间量压回安全范围**
计数 $S\le k$ 不是自然成立的，是靠 `if(use>k) return false;` 的位置（先判后加）换来的——溢出防护里"**语句顺序即不变式**"是很常见的一类技巧。

**易错点清单**

1. 死亡条件是血量**严格** $<0$ ⇒ 需求 $R_j=m_j+1$，不是 $m_j$。
2. 溅射只在左侧；$r=\lfloor\sqrt{p-1}\rfloor$ 而不是 $\lfloor\sqrt p\rfloor$（$p$ 为完全平方数时差 1）。
3. $p=1$ 时 $r=0$：滑窗要钳成 $1$ 或加分支，否则窗口与"半径"不一致（本解法靠系数恰好为 0 兜住）。
4. 递推顺序必须"先 $U\mathrel{+}=2T+S$ 再 $T\mathrel{+}=S$"。
5. `(i64)(n-1)*(n-1)`：先乘后转会丢高位。
6. 二分求最小值取 $mid=(l+r)/2$ 且 `check(mid)? r=mid : l=mid+1`；写成 $(l+r+1)/2$ 会死循环。

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 类型 | 取值范围（本解） |
|---|---|---|---|
| `n` | 怪物数 | `int` | $\le5\times10^5$ |
| `k` | 子弹数上限 | `int` | $\le5\times10^5$（比较时隐式转 `i64`） |
| `m[j]` | 第 $j$ 只（0-based）血量 $m_j$ | `i64` | $\le10^{10}$ |
| `R_j` | 需求伤害 $m_j+1$ | 表达式 | $\le10^{10}+1$ |
| `p` | 二分中的威力值 | `i64` | $[1,\ (n-1)^2+M+1]$ |
| `M` = `mx` | $\max_i m_i$ | `i64` | $\le10^{10}$ |
| `r` | 溅射半径 $\max(1,\lfloor\sqrt{p-1}\rfloor)$ | `i64` | $\le5.1\times10^5$ |
| `c[j]` | 贪心决定落在位置 $j$ 的子弹数 $g_j$ | `i64` | $\le k$（靠提前退出保证） |
| `S` | 窗口 $W_j$ 内 $\sum c_i$ | `i64` | $\le k$ |
| `X` | 窗口内 $\sum c_i d_i$（$d_i=i-j$） | `i64` | $\le kr\approx2.6\times10^{11}$ |
| `Q` | 窗口内 $\sum c_i d_i^2$ | `i64` | $\le kr^2\approx1.3\times10^{17}$ |
| `D` | 右侧溅射来的伤害 $pS-Q$ | `i64` | $\le pS\approx1.3\times10^{17}$ |
| `use` | 已用子弹总数 $\sum g_j$ | `i64` | 判定结束 $\le k$；越界即刻返回 |
| `l`,`r`(二分) | 答案区间 $[l,r]$（$r$ 恒可行） | `i64` | — |

> 外层二分的 `r`（区间右端点）与 `check` 里的半径 `r` 同名但不同作用域：`check` 是独立函数，各自用局部量，安全。

### 4.2 编号步骤

1. 读入 $n,k$ 与 $m[0..n-1]$，同时求 $M=\max m_i$。
2. 设 $l=1$，$r=(n-1)^2+M+1$（引理 F：$r$ 可行）。
3. 当 $l<r$：取 $mid=\lfloor(l+r)/2\rfloor$；执行步骤 4 的判定；可行则 $r\leftarrow mid$，否则 $l\leftarrow mid+1$。
4. **判定 $\mathrm{check}(p)$**：
   1. $r\leftarrow\max(1,\lfloor\sqrt{p-1}\rfloor)$（`isqrt` + 两次 `while` 校正）。
   2. 初始化 $S=X=Q=use=0$（空窗口，对应 $j=n-1$ 时 $W_{n-1}=\varnothing$）。
   3. $j$ 从 $n-1$ 递减到 $0$：
      - $D\leftarrow pS-Q$；$\mathit{need}\leftarrow m_j+1-D$；
      - $c_j\leftarrow(\mathit{need}>0\,?\ \lceil \mathit{need}/p\rceil\,:\,0)$，即 $(need+p-1)/p$；
      - $use\leftarrow use+c_j$；**若 $use>k$ 立刻返回 false**（先判后用，是 $S\le k$ 不变式的一部分）；
      - 递推窗口到 $j-1$：$Q\leftarrow Q+2X+S$；$X\leftarrow X+S$；
        若 $j+r\le n-1$ 则减去 $c_{j+r}$ 的 $\{1,r+1,(r+1)^2\}$ 贡献；最后加上 $c_j$ 的 $\{1,1,1\}$ 贡献。
   4. 循环结束返回 true。
5. 输出 $l$。

### 4.3 复杂度

- 判定：$O(n)$（每步常数次 `i64` 加减乘）。
- 二分：$\lceil\log_2((n-1)^2+M+1)\rceil\le38$ 次。
- 总计 $O(n\log(n^2+\max m))$，$n=5\times10^5$ 时约 $1.9\times10^7$ 步（量级估算）；
  空间 $O(n)$（$m[],c[]$ 各 $5\times10^5$ 个 `i64`，约 8 MB）。

$j=0$：$D=0$，$c_0=2$，$use=6\le6$ → true ✓。$p\ge1$ 恒成立 ⇒ 答案 1 ✓。
同实例 $k=5$：$\mathrm{check}(1)$ 得 $use=6>5$ false；$\mathrm{check}(2)$（$r=1$）：$c_2=1$；$j=1$：$D=1$，$c_1=1$，$use=2$；
递推后剔除 $c_2$ 加入 $c_1$ 得 $S=X=Q=1$；$j=0$：$D=2-1=1$，$c_0=1$，$use=3\le5$ → true ⇒ 答案 2 ✓。

**T7（上界取到最紧 + 溢出边界）：$n=5\times10^5,k=1,m\equiv1$ ⇒ 期望 $(n-1)^2+2=249999000003$**
$M=1$，$r_{hi}=(n-1)^2+2=249999000003$ 恰等于期望答案，故二分右端点必须开到 $2.6\times10^{11}$，`int` 会直接爆。
$\mathrm{check}(249999000002)$：$r=\max(1,\lfloor\sqrt{249999000001}\rfloor)=\max(1,499999)=499999$；
$j=n-1$：$need=2$，$c=1$，$use=1$；$S=X=Q=1$；此后每步 $need\le0$，$c_j=0$，矩按 $d\mapsto d+1$ 递增。
到 $j=0$ 时位置 $n-1$ 的距离 $=n-1=499999=r$（尚未被剔除，剔除条件是 $j+r\le n-1$ 即 $j=0$ 之后才执行），
$Q=499999^2=249999000001$，$D=249999000002-249999000001=1<R_0=2$ ⇒ $c_0=1$，$use=2>k$ → false ✓。
$\mathrm{check}(249999000003)$：$D=2\ge2$ ⇒ $use=1$ → true ✓。答案 $249999000003$ ✓。
（这一组同时验证了 $r$ 的"平方数边界"：$p-1=499999^2$ 是完全平方数，$\lfloor\sqrt{p-1}\rfloor$ 必须正好取到 $499999$，
若误用 $\lfloor\sqrt p\rfloor$ 或浮点误差未校正，$j=0$ 会把它当"半径外"剔除，$D$ 变 0，出现假阴性。）

**验证覆盖度自评**：单点、双向、$p=1$ 退化、$r=0$ 钳位、答案在下界/上界、$m+1$ 边界、$r$ 的完全平方边界、
$2.6\times10^{11}$ 量级 —— 均已手算；未覆盖的是"多轮二分迭代过程中 $c[]$ 被反复覆盖"这一点
（逻辑上 $c[j+r]$ 只在本轮已扫描过的位置被读，且每轮 $check$ 都会重写 $c[]$ 的全部 $n$ 项，故不会读到上一轮的残值）。

## 5. 示例代码

```cpp
// https://www.luogu.com.cn/problem/P1485
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{500005};

int n,k;
i64 m[mxn],c[mxn];

i64 isqrt(i64 x)     // floor(sqrt(x))，x>=0
{
	i64 r=sqrtl(x);
	while((r+1)*(r+1)<=x)
		++r;
	while(r*r>x)
		--r;
	return r;
}

bool check(i64 p)
{
	i64 r=max<i64>(1,isqrt(p-1));    // 溅射半径；r=0 时钳成 1，系数恰为 0，无害
	i64 S=0,X=0,Q=0,use=0;           // 窗口内 0 阶/1 阶/2 阶矩
	for(int j=n-1;j>=0;--j)
	{
		i64 D=p*S-Q;                 // 右侧子弹溅到 j 的总伤害
		i64 need=m[j]+1-D;
		i64 cj=need>0?(need+p-1)/p:0;
		use+=cj;
		if(use>k)
			return false;
		c[j]=cj;                     // 补给 j 自己：对 >j 的怪毫无影响
		Q+=2*X+S;                    // 换到列 j-1：窗口内所有距离 +1
		X+=S;
		if(j+r<=n-1)                 // 距 j-1 恰为 r+1 的子弹掉出窗口
		{
			S-=c[j+r];
			X-=c[j+r]*(r+1);
			Q-=c[j+r]*(r+1)*(r+1);
		}
		S+=cj;                       // 位置 j 以距离 1 进入下一窗口
		X+=cj;
		Q+=cj;
	}
	return true;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	i64 mx=0;
	for(int i=0;i<n;++i)
	{
		cin>>m[i];
		mx=max(mx,m[i]);
	}

	i64 l=1,r=(i64)(n-1)*(n-1)+mx+1; // 上界：1 发落在最右怪即可全灭
	for(;l<r;)
	{
		i64 mid=(l+r)>>1;
		if(check(mid))
			r=mid;
		else
			l=mid+1;
	}
	cout<<l<<'\n';
	return 0;
}

// 1 1 / 10            -> 11
// 2 1 / 1 1           -> 3
// 3 1 / 1 1 1         -> 6
// 2 3 / 9 5           -> 4
// 3 6 / 1 1 1         -> 1
```
