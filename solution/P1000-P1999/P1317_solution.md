# P1317 低洼地

> 标签：模拟 / 洛谷原创 · 难度：入门

## 1. 重新读题

**问题重述（大白话版）**

给你一排整数 $a_0,a_1,\dots,a_{n-1}$，把它们看成地平线的高度：第 $i$ 个点的标高 $a_i$，相邻两点用直线段连起来，形成一条折线。问：这条折线下面一共有**几处**能存住水的坑（低洼地）？

"能存住水"用大白话说就是：从某处开始**一直往下走**，走到一个最低的地方，然后**一直往上走**，中间这段"先降后升"的谷形就是一处低洼地。

两个必须抠清楚的细节（本题的坑几乎全在这里）：

1. **平台（相邻等高）怎么处理**：$a_i=a_{i+1}$ 时折线是水平的。一整段等高的"平地"只能算**一个**位置，不能因为它有好几个点就被数好几次；反过来，谷底是平的（比如 $\dots,2,1,1,1,2,\dots$）也仍然是**一处**低洼地。
2. **边界算不算**：题目保证 $a_0=a_{n-1}=0$，且 $0\le a_i\le 1000$。最左、最右两个点只有一边有陆地，水会从外侧流走，所以**首尾永远不能当谷底**；同样，只朝一个方向倾斜的"半边的坑"也不算。

**约束**

| 量 | 范围 |
|---|---|
| $n$ | $3\le n\le 10000$ |
| 高度 $a_i$ | $0\le a_i\le 1000$，整数 |
| 端点 | $a_0=a_{n-1}=0$（保证） |

输出一个整数：低洼地数目。

> **输入输出格式严格比对（以本地题面为准）**：第 1 行仅一个整数 $n$，第 2 行按顺序给出 $n$ 个高度——**不是**"若干个以 0 结尾的整数"、也不是"不给 $n$ 读到 EOF"之类变体；输出**只有一个计数**，**不要求输出方案**（不必指出是哪些坑）。故读入只需 `cin>>n` 后循环读 $n$ 个数（`>>` 对空格/换行不敏感，两行格式无需特殊处理）。

**约束给的暗示**：$n\le 10^4$ 极小，$O(n\log n)$ 甚至 $O(n^2)$ 都过得去，说明本题**不考算法，只考"把定义写成代码时对不对"**。标签"模拟"也印证：需要的是逐点扫描 + 正确的判定条件。

**样例说明**：题面文件里没有独立的 Sample 块，题图给的序列 $[0,1,0,2,1,2,0,0,2,0]$ 就是唯一样例。按题图（三块水面）它对应 **3**。第 4 节会手算复现这个 3。

## 2. 思维链（Chain-of-thought）

### 2.1 探索机制：把"积水"翻译成折线的形状语言

折线上相邻两点连成水平/上升/下降的线段，所以整条折线可以拆成一串**单调段**：

$$\text{上升段}\mid\text{水平段}\mid\text{下降段}$$

一处"能积水的坑"必须同时具备：谷底左边有一段陆地把它兜住，右边也有一段陆地把它兜住，并且这两段都比谷底高。于是形状上就是

$$\underbrace{\searrow\searrow\cdots\searrow}_{\text{下降相（非空）}}\ \bullet\ \underbrace{\nearrow\nearrow\cdots\nearrow}_{\text{上升相（非空）}}$$

**中间那个 $\bullet$ 就是谷底**。用一句判定式概括：

> **判定条件（目标形态）**：低洼地 $=$ 折线中"先下降、后上升"的**极大**一段（下降相与上升相都非空；相内允许出现水平台阶，但一旦出现上升就不允许再下降）。每段只数一次：段内的水平平台不额外产生新的段，相邻两段共用的山头也不额外产生新的段。

"极大"这两个字很关键：$[0,1,0,2,1,2,0,0,2,0]$ 里第三个坑是 $2,0,0,2$，它是极大段；如果允许非极大，光"取其中三个点"就能造出无数段，计数就无意义了。所以"极大"= **计数不重不漏** 的保证。

### 2.2 简化版：假设没有平台（相邻永不相等）

先把"平台"这个机制剥掉，假设序列满足 $a_i\ne a_{i+1}$ 对所有 $i$。此时每个内点 $1\le i\le n-2$ 与左右邻居的比较只剩"高/低"两种结果，"先降后升"就等价于

$$a_i<a_{i-1}\ \text{且}\ a_i<a_{i+1}$$

即**严格局部最小值**。而且每个严格局部最小值恰好对应一个极大段（往左扩到不再下降、往右扩到不再上升），一一对应（这一句的完整证明就是下面的引理 2），所以：

$$\text{无平台时}\quad \text{答案}=\#\{i\in[1,n-2]:a_i<a_{i-1}\land a_i<a_{i+1}\}$$

一行循环搞定。**这个简化版就是最终算法的骨架**，剩下唯一要处理的是平台。

### 2.3 把机制加回来：两个"偷懒"的做法都被反例打脸

**尝试 A（严格比较直接用原数组）**：数 $a_i<a_{i-1}\land a_i<a_{i+1}$。
在样例上手算：$a=[0,1,0,2,1,2,0,0,2,0]$，内点逐个检查

| $i$ | $a_{i-1},a_i,a_{i+1}$ | 严格小于两边？ |
|---|---|---|
| 1 | 0,1,0 | 否 |
| 2 | 1,**0**,2 | **是** |
| 3 | 0,2,1 | 否 |
| 4 | 2,**1**,2 | **是** |
| 5 | 1,2,0 | 否 |
| 6 | 2,**0**,0 | 否（$0<0$ 不成立） |
| 7 | 0,**0**,2 | 否（$0<0$ 不成立） |
| 8 | 0,2,0 | 否 |

得 2，比正确答案 3 少 1 —— **谷底是平台时一个都数不到**（$0,0$ 两个点互相"卡住"严格不等号）。

**尝试 B（放宽成 $\le$，并要求至少一边严格）**：$a_i\le a_{i-1}\land a_i\le a_{i+1}\land(a_i<a_{i-1}\lor a_i<a_{i+1})$。
样例上第 6、7 位（$0,0$ 平台的两个"边点"）同时被判是，于是 $i=2,4,6,7$ 全中，得 **4**（比 3 多 1，多的正是那段被数两次的平底）。换更干净的 $[0,1,0,0,0,1,0]$（一个平底长坑）：$i=2$（左边严格）、$i=4$（右边严格）都满足，$i=3$ 两边都不严格不满足 → 得 2，而真值是 1，**一处坑被数成两处**。再把平台拉长 $[0,1,0,0,0,0,1,0]$ 仍得 2：多算的量固定为 1，与平台长度无关。可见 $\le$ 这种放宽本质上修不掉尝试 A 的错误。

**结论**：严格版对平台**漏算**，非严格版对平台**重算**。根源是同一句话——**一段平台在"形状"上只应该有一个身份**。于是自然的修法不是继续调不等号，而是**先把平台合并成一个点**。

### 2.4 引理 1（压平台的等价性）：合并相邻等高不改变低洼地集合

**压缩序列的定义**：从左到右扫描 $a$，每当出现与前一个保留值不同的 $a_i$ 就写入 $b$：

$$b_0=a_0,\qquad b_k=\text{第 }k\text{ 个"等高段"的高度}$$

形式化：把 $[0,n-1]$ 按 $a_i=a_j$ 的"相邻传递闭包"划分成极大连通块（等高段）$I_0,I_1,\dots,I_{m-1}$（它们按顺序铺满 $[0,n-1]$），令 $b_k=a_{i}$（任一 $i\in I_k$）。于是：

- (P1) $b$ 相邻元素**必不相等**：$b_k\ne b_{k+1}$（否则 $I_k,I_{k+1}$ 应合并）；
- (P2) $b_0=a_0=0,\ b_{m-1}=a_{n-1}=0$；
- (P3) 原序列每个位置属于唯一等高段，段与段之间是"升/降"关系，没有第三种。

**引理 1**：$a$ 的低洼地（按 2.1 的定义："先降后升的极大段"，其中降/升允许中间夹水平平台，平台整体算一步）的集合，与 $b$ 的"先严格降后严格升的极大段"集合之间存在保持左右顺序的双射。特别地两者个数相等。

**证明**：

*（准备工作：等高段是原子）* 由 (P1)，$b$ 上不存在水平段，"下降/上升"就是 $b$ 上相邻元素比较的结果；$a$ 上一段连续位置覆盖的等高段是 $I_p,I_{p+1},\dots,I_q$，其高度序列恰为 $b_p,b_{p+1},\dots,b_q$。所以 $a$ 上任意连续区间的**升降模式**只由它覆盖的等高段指标区间 $[p,q]$ 决定，与段内长度无关。

*（极大段的端点必落在等高段边界上）* 设 $[u,v]$ 是 $a$ 的一处极大"（弱）降后（弱）升"段。若 $u$ 不是它所在等高段的首位置，则 $a_{u-1}=a_u$，把段向左扩一位仍是"弱降后弱升"（下降相只是多一个等高台阶），与极大性矛盾；故 $u$ 是某等高段的首位置。$v$ 同理是某等高段的末位置。于是 $a$ 的极大段恰好是若干个**完整**等高段的并：$[u,v]=\bigcup_{k=L}^{R}I_k$。

*（弱降 $\to$ 严降）* 在该段内，任意相邻两个等高段高度不等（P1），故"弱降"就是"严降"：$b_L>b_{L+1}>\cdots>b_t$，$b_t<b_{t+1}<\cdots<b_R$，其中 $t$ 是谷底所在等高段指标。谷底位置集合 $=\{i\in[u,v]:a_i=\min a_{[u,v]}\}$ 是一段连续位置且全等高，因而包含在某个等高段里；又它是整个段的最小值所在，只能是 $I_t$（$I_t$ 完整地取到最小值）。

*（单射：谷底指标 $t$ 决定一切）* 设 $C=[u,v]=\bigcup_{k=L}^{R}I_k$ 为 $a$ 的一处低洼地，谷底等高段指标 $t$。下降相非空（定义要求"先降"）⟹ $L\le t-1$ ⟹ $b_{t-1}>b_t$；上升相非空 ⟹ $R\ge t+1$ ⟹ $b_{t+1}>b_t$。故 $t\in V$（$b$ 的严格局部最小），映射 $C\mapsto t$ 有定义。

若两处低洼地 $C_1=[u_1,v_1],C_2=[u_2,v_2]$ 有同一谷底 $t$，不妨 $u_1\le u_2$（则 $v_2\le v_1$ 或 $v_1\le v_2$ 皆可）。因为二者都以 $t$ 为转折点：在 $I_t$ 左侧二者都弱降、右侧都弱升，故并区间 $[\min(u_1,u_2),\max(v_1,v_2)]$ 上 $a$ 仍"先弱降后弱升"且转折点仍是 $I_t$（左侧整体弱降、右侧整体弱升，由两段各自单调可逐项推出）。这与 $C_1,C_2$ 的**极大性**矛盾，除非二者相同。故 $C\mapsto t$ 单射。

*（满射）* 设 $t\in V$。在 $b$ 上从 $t$ 出发：向左沿连续严格下降一直走，即令 $L$ 为满足 $b_L>b_{L+1}>\cdots>b_t$ 的最小指标；向右沿连续严格上升一直走，令 $R$ 为满足 $b_t<b_{t+1}<\cdots<b_R$ 的最大指标。这样的 $L,R$ 存在且唯一：$j=t-1,t-2,\dots$ 一旦遇到 $b_{j-1}<b_j$ 或触到 $0$ 就停，每步指标严格减小故必终止（$R$ 同理）。于是 $[L,R]$ 在 $b$ 上"先严格降后严格升"、转折点为 $t$（又 $t\in V$ 给出 $\sigma_{t-1}=-1$、$\sigma_t=+1$，故 $L\le t-1$ 且 $R\ge t+1$：两相都非空）。它还极大：设 $[L',R']\supseteq[L,R]$（严格包含）也形如"先降后升"，转折点 $t'$。若 $t'<t$，则 $[t',R']$ 需严格升，但 $[t',t]\subseteq[L,R]$ 严格降，矛盾；$t'>t$ 同理矛盾；故 $t'=t$，从而左扩需 $b_{L-1}>b_L$，与 $L$ 的取法（$L=0$ 或 $b_{L-1}<b_L$）矛盾，右扩同理。把它翻回 $a$：$[u,v]=\bigcup_{k=L}^{R}I_k$ 连续、$a$ 在其上弱降后弱升；再由前面"极大段端点落在等高段边界上"的论证，$[u,v]$ 在 $a$ 上也不能再扩（能扩一位就能扩到整段等高段，等价于 $b$ 上能左/右扩），故它是 $a$ 的低洼地且映射到 $t$。

*（互逆）* 两个构造都以"谷底等高段指标"为唯一自由度，复合后回到自身。故低洼地集合与 $V$ 之间存在保序双射，个数相等。$\blacksquare$

> **引理 1 的作用**：把"平台怎么算"这个含糊问题彻底变成机械操作——**先合并相等相邻项，之后只用严格不等号**。之后所有讨论都在 $b$ 上做，而 $b$ 相邻元素必不等，再没有第三种情况。

### 2.5 引理 2（谷底 ⟺ 局部最小 ⟺ 变号点）

设 $b$ 长 $m$，定义差分符号 $\sigma_k=\operatorname{sign}(b_{k+1}-b_k)\in\{+1,-1\}$（$k=0..m-2$，由 (P1) 恒不为 0）。

**引理 2**：下列三个集合等势（实为同一对象的三种说法）：

1. $b$ 的"先严格降后严格升"极大段；
2. 指标集 $V=\{t\in[1,m-2]:b_t<b_{t-1}\land b_t<b_{t+1}\}$（内部严格局部最小值）；
3. 指标集 $T=\{k\in[0,m-3]:\sigma_k=-1\land\sigma_{k+1}=+1\}$（"降后升"的变号点）。

**证明**：

*(2) $\Leftrightarrow$ (3)*：$\sigma_k=-1\iff b_{k+1}<b_k$，$\sigma_{k+1}=+1\iff b_{k+2}>b_{k+1}$。令 $t=k+1$ 即得 $b_t<b_{t-1}\land b_t<b_{t+1}$，$k=t-1$；$k\in[0,m-3]\iff t\in[1,m-2]$。一一对应。

*(2) $\Rightarrow$ (1)*：给定 $t\in V$。令
$$L=\min\{\,j\in[0,t]:\ \sigma_j=\sigma_{j+1}=\cdots=\sigma_{t-1}=-1\,\},\qquad R=\max\{\,j\in[t,m-1]:\ \sigma_t=\sigma_{t+1}=\cdots=\sigma_{j-1}=+1\,\}.$$
存在性：$t\in V$ 给出 $\sigma_{t-1}=-1$，故 $j=t-1$ 属于第一个集合（其条件退化为单个 $\sigma_{t-1}=-1$），取下最小值即 $L\le t-1<t$；同理 $\sigma_t=+1$ 使 $j=t+1$ 属于第二个集合，故 $R\ge t+1>t$。由构造，$\sigma_L=\cdots=\sigma_{t-1}=-1$ 使 $b_L>b_{L+1}>\cdots>b_t$，$\sigma_t=\cdots=\sigma_{R-1}=+1$ 使 $b_t<b_{t+1}<\cdots<b_R$，且 $L,R$ 取极值保证 $(L=0$ 或 $\sigma_{L-1}=+1)$、$(R=m-1$ 或 $\sigma_R=-1)$。于是 $[L,R]$ 是"先严格降后严格升"段，且两相均非空。

极大性用反证：设 $[L',R']\supsetneq[L,R]$ 也是"先严格降后严格升"段，转折点 $t'$。若 $t'<t$，则 $[t',R']$ 上应严格升，但 $[t',t]\subseteq[L,R]$ 上严格降，矛盾；$t'>t$ 对称矛盾；故 $t'=t$。于是 $[L',t]$ 严格降，特别地（当 $L'<L$ 时，$L-1\in[L',t-1]$）有 $b_{L-1}>b_L$，与 $\sigma_{L-1}=+1$（即 $b_{L-1}<b_L$）矛盾；右端同理。故 $[L,R]$ 极大。（$L=0$ 或 $R=m-1$ 时对应方向本就无法再扩，结论不变。）

*(1) $\Rightarrow$ (2) 且不重*：设 $[L,R]$ 是任一极大"先严格降后严格升"段，转折点 $t$ 满足 $\sigma_L=\cdots=\sigma_{t-1}=-1$、$\sigma_t=\cdots=\sigma_{R-1}=+1$，于是 $b_t<b_{t-1}$ 且 $b_t<b_{t+1}$，即 $t\in V$（且 $L\le t-1<t+1\le R$ 说明 $t$ 是内点）。若同一 $[L,R]$ 有两个转折 $t_1<t_2$：以 $t_1$ 为转折点则上升相覆盖 $[t_1,R]$，得 $\sigma_{t_2-1}=+1$；以 $t_2$ 为转折点则下降相覆盖 $[L,t_2]$，得 $\sigma_{t_2-1}=-1$；同一位置 $\sigma_{t_2-1}$（注意 $t_1\le t_2-1\le R-1$）不可能既是 $+1$ 又是 $-1$，矛盾，故转折点唯一。再设两个不同的 $t_1,t_2\in V$ 按上式生成的极大段相同，则该段有两个转折点，与刚证的唯一性矛盾。故 $t\mapsto[L_t,R_t]$ 是双射。$\blacksquare$

由引理 1 + 引理 2：

$$\boxed{\ \text{答案}=\#\{k:\ \sigma_k=-1\ \text{且}\ \sigma_{k+1}=+1\}=\#\{t\in[1,m-2]:b_t<b_{t-1}\ \text{且}\ b_t<b_{t+1}\}\ }$$

**引理 3（谷底真能存水，"看着像坑其实漏了"的情况不存在）**：记
$$M_L(t)=\max_{0\le j\le t}b_j,\qquad M_R(t)=\max_{t\le j\le m-1}b_j,$$
则位置 $t$ 处能保持的水深上界是 $W_t-b_t$，其中 $W_t=\min(M_L(t),M_R(t))$；并且对 $t\in V$
$$W_t-b_t\ \ge\ \min(b_{t-1},b_{t+1})-b_t\ >\ 0.$$

**证明**：折线是连续曲线，"在 $t$ 处存住水深 $d>0$"意思是存在水位 $h=b_t+d$，使从 $t$ 沿地形向左、向右都先遇到高度 $>h$ 的陆地（水无法越过），即
$$\exists\, j_L<t:\ b_{j_L}>h,\qquad \exists\, j_R>t:\ b_{j_R}>h \tag{$*$}$$
（若 $(*)$ 不成立，比如左侧任意高的墙都不存在，则对任何 $h>b_t$，区间 $[0,t]$ 上所有高度 $\le h$，$t$ 处的水会沿这条不高于水面的通道一路流到左端 $b_0=0$ 之外，存不住。）

- 由 $(*)$ 立得 $M_L(t)\ge b_{j_L}>h$ 且 $M_R(t)\ge b_{j_R}>h$，故 $h<W_t$，于是水深 $d=h-b_t<W_t-b_t$，即 $W_t-b_t$ 是上界。
- 反之取任意 $h\in(b_t,W_t)$：由 $h<W_t\le M_L(t)$ 存在 $j_L\in[0,t]$ 使 $b_{j_L}=M_L(t)>h$；又 $b_t<h$ 故 $j_L\ne t$，即 $j_L<t$；右侧同理有 $j_R>t$。$(*)$ 成立，水深 $h-b_t>0$ 可存。综上，可存水深恰为区间 $(0,\,W_t-b_t)$ 内的值：$W_t-b_t$ 本身是**上确界**——取 $h=W_t$ 时，实现 $\min$ 的那一侧（$M_L$ 或 $M_R$ 等于 $W_t$ 者）已无严格高于水面的堤，$(*)$ 失败，故严格约定下端点取不到；若改用"水面齐平堤顶即算拦住"的宽松约定，多的也只是这一个端点。**约定之争不影响"是否存在某个 $d>0$ 可存"**，因而对计数毫无影响；本题只用到：$W_t>b_t\Rightarrow$ 存在可存的 $d>0$。
- 最后 $t\in V\Rightarrow t\in[1,m-2]$，故 $j_L=t-1$ 与 $j_R=t+1$ 都存在，$M_L(t)\ge b_{t-1}>b_t$、$M_R(t)\ge b_{t+1}>b_t$，两式取 $\min$ 即得不等式。$\blacksquare$

> 这说明"数谷底"与"数能积水的地方"在本题**完全一致**：每一个 $V$ 中的 $t$ 都严格能存住水（引理 3），而非 $V$ 的位置不是某处极大坑的底（引理 2）。

**引理 4（首尾与退化情形：边界一条都不漏）**

(a) 若 $m=1$（全部等高，由 (P2) 只能全为 0），答案为 0。
(b) 在题目保证（$a_0=a_{n-1}=0$，$a_i\ge0$）下 $m=2$ 不可能出现。
(c) 若 $m\ge3$，则 $\sigma_0=+1$ 且 $\sigma_{m-2}=-1$。因此按引理 2 的 (3)（$-1\to+1$ 变号）统计时**天然不会碰到首尾**，无需边界特判；反之，若把判定改写成"给 $b$ 补两个 $+\infty$ 哨兵再数 $b_k\le$ 两边"，$b_0=b_{m-1}=0$ 会被误判成谷底，**必须**显式把循环范围限制在 $[1,m-2]$。

**证明**：
(a) $m=1$ 时 $b$ 只有一个元素，$V$ 的区间 $[1,m-2]=[1,-1]$ 为空。地形是全平地面，水往任意方向都流走，0 处洼地，符合。
(b) $m=2$ 意味着 $b=[b_0,b_1]$，(P2) 给 $b_0=b_1=0$，与 (P1) 的 $b_0\ne b_1$ 矛盾。
(c) $m\ge2$ 时 $b_0=0$ 且 $b_1\ne0$；由 $a_i\ge0$ 得 $b_1>0$，故 $\sigma_0=\operatorname{sign}(b_1-b_0)=+1$。同理 $b_{m-1}=0,\ b_{m-2}\ne0,\ b_{m-2}>0$，故 $\sigma_{m-2}=\operatorname{sign}(b_{m-1}-b_{m-2})=-1$。
于是变号点 $k$（要求 $\sigma_k=-1$ 且 $\sigma_{k+1}=+1$）既不能是 $k=0$（那里 $\sigma_0=+1$），也不能是 $k=m-2$（那里 $\sigma_{m-2}=-1$），故 $k\in[0,m-3]$ 内取值，对应谷底 $t=k+1$ 落在内部 $[1,m-2]$：首尾两个等高段**永远**不是谷底。**几何解释**：折线两端都落在标高 0（基准面）上，最外侧必然是"从 0 起爬坡"和"最后降回 0"，因此真正的坑不可能贴着图的端点。$\blacksquare$

> 顺带一个自检恒等式：$\sigma$ 序列以 $+1$ 开头、以 $-1$ 结尾，所以 $+1\to-1$（山头）次数比 $-1\to+1$（谷底）次数恰多 1，即**山比坑多一个**。样例：3 个坑 ⟹ 4 个山。手算时可用来快速验错。

**引理 5（一次扫描的变号计数器与数谷底完全等价）**：按 $i=1..n-1$ 顺序扫原数组，维护 `down`（"自上次计数以来出现过下降"），遇 $a_i<a_{i-1}$ 置 `down=true`，遇 $a_i>a_{i-1}$ 且 `down` 则 `++ans; down=false`，遇相等什么都不做，其结果与 $b$ 上数局部最小值相同。

**证明**：分两步。

*(i) 扫描看到的符号就是 $\sigma$*：把 $a$ 的相邻差 $d_i=a_i-a_{i-1}$（$i=1..n-1$）按 $i$ 增序排列。段内（等高段内部）的 $d_i=0$；每两个相邻等高段之间恰有一个非零差，其值为 $b_{k+1}-b_k$（因为它连接 $I_k$ 的末位置与 $I_{k+1}$ 的首位置，这两位置相邻）。所以"跳过零后的非零差序列"按顺序正是 $b_{k+1}-b_k$，即符号序列正是 $\sigma_0,\sigma_1,\dots,\sigma_{m-2}$。状态机里 `x==p` 什么都不做，就是跳过零，故它读到的符号流就是 $\sigma$。

*(ii) 不变量*：对 $j\ge1$，处理 $\sigma_j$ **之前** `down` 的值等于命题"$\sigma_{j-1}=-1$"。归纳：$j=1$ 时由引理 4(b)(c)，$m\ge2$ 即迫使 $m\ge3$ 且 $\sigma_0=+1$（若 $m\le1$ 则根本没有 $\sigma$，状态机也不触发），`down` 初值为假且 $+1$ 不置位，故处理后 `down` 为假 $=[\sigma_0=-1]$ ✓。递推：设对 $j$ 成立，处理 $\sigma_j$ 时若 $\sigma_j=-1$ 则 `down` 被置真；若 $\sigma_j=+1$ 则要么触发计数并清零、要么本来就是假，两种情形处理后 `down` 皆为假。即处理后 `down` $=[\sigma_j=-1]$，也就是命题对 $j+1$ 成立 ✓。

由 (ii)，在 $\sigma_j=+1$ 处触发计数 $\iff$ `down` 为真 $\iff\sigma_{j-1}=-1$，即触发位置集合正好是 $\{j-1:\sigma_{j-1}=-1\land\sigma_j=+1\}=T$，每个变号点触发一次且仅一次，不漏不重。故 `ans` $=|T|\overset{\text{引理 2}}{=}|V|=$ 低洼地数。$\blacksquare$

### 2.6 两种实现取向的比较

- **压缩数组法**：真的把 $b$ 建出来，再一行 for 数局部最小。**优点**：代码就是引理 2 的 (2) 式，证明直接落到代码上，几乎不可能写错边界。**代价**：$O(n)$ 额外空间（$n\le10^4$，可忽略）。
- **状态机法**（引理 5）：$O(1)$ 空间，一次读入即可判，但要小心"清零 `down`"这个动作——漏掉就会把 2.3 的重算错误以另一种形式带回来。

$n\le10^4$ 下空间毫无压力，而本题错的全是"判定条件"，所以**选压缩数组法**：让代码和引理长得一样。

## 3. 模式总结（实际思考顺序）

- **explore its property** — 把"可能积水"翻成折线的形状语言：先严格降、后严格升的**极大**段；"极大"是计数不重不漏的来源。
- **consider easier version** — 先假设无相邻等高，此时洼地数 $=$ 内部严格局部最小值数，一行循环即可（这是最终骨架）。
- **counterexample hunt（反例排查）** — 把简化版直接套到原数组：严格 $<$ 对平底平台**漏算**（样例只出 2）；放宽成 $\le$ 对平台**重算**（$[0,1,0,0,0,1,0]$ 出 2）。两个反例定位到"平台必须整体当一个点"。
- **reduce to easier problem** — 引理 1：先合并相邻等高（压缩成 $b$），把含平台的地形化归到无平台情形，并证明低洼地集合的双射不变。
- **classic problem solution** — 差分符号变号计数：引理 2 把"极大降后升段 / 局部最小 / $-1\to+1$ 变号"三者合一，$O(n)$ 一次扫描出答案。
- **boundary audit（边界体检）** — 引理 3/4：$a_0=a_{n-1}=0$ 且 $a_i\ge0$ ⟹ $\sigma_0=+1,\sigma_{m-2}=-1$，谷底必在内部；$m=1$ 退化为全平答 0，$m=2$ 不可能出现；附带"山比坑多一个"自检恒等式。
- **alternative technique（备选）** — 引理 5 的 $O(1)$ 空间状态机（`down` 标记 + 计数后清零），作为压缩数组法的等价实现。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n` | 高度数据个数 | `int`，输入，$3\le n\le10^4$ | 题面保证 $n\ge3$，$n=1,2$ 的输入不存在，无需为其写代码分支 |
| `a[]` | 原始高度 $a_0..a_{n-1}$ | `int a[mxn]`，全局默认 0，边读边填 | 首尾必为 0 |
| `b[]` | 压缩序列：合并相邻等高后的高度 $b_0..b_{m-1}$ | `int b[mxn]`，全局默认 0，只读已写位置 | $b_k\ne b_{k+1}$ 恒成立 |
| `m` | 压缩后长度（引理 4：只能是 $1$ 或 $\ge3$，取不到 $2$） | `int`，全局默认 0，即"当前 $b$ 的元素个数" | 同时充当写入下标 |
| `ans` | 低洼地数目 $=|V|$ | `int`，全局默认 0（即尚未计数），扫描时累加 | 谷底个数 |
| `mxn` | 数组上界 $=10000+5$ | `constexpr int mxn{10005}` | +5 松弛 |

> **下标约定**：内部一律 **0-based**（$a_i$ 与 $b_k$ 都从 0 开始）。本题输入只给数值不给位置编号，没有 1-based 输入需要 `--` 转换，保持 0-based 与引理叙述完全一致。

### 4.2 算法步骤

1. **读入** $n$，然后 $n$ 个高度；每读到一个 $x$ 立刻做压缩：若 `m==0 || x!=b[m-1]` 则 `b[m++]=x`（等高段只留第一个点，引理 1）。$a$ 数组可选保留（代码里顺手存一份，便于自查）。
2. **数谷底**：`for k=1; k<=m-2; ++k`，若 `b[k]<b[k-1] && b[k]<b[k+1]` 则 `++ans`（引理 2 的 (2) 式）。循环边界即 $[1,m-2]$，$m\le2$ 时循环体自然不执行，无需特判。
3. **输出** `ans`。
4. **（可选）$O(1)$ 空间写法**：把 1、2 合并成引理 5 的状态机：`if(x<p)down=1; else if(x>p&&down){++ans;down=0;} p=x;`（$p$ 是上一个读入值，平台内部值相同，所以"跳过相等"就等于在压缩序列 $\sigma$ 上走）。与步骤 1+2 结果相同（引理 5 已证）。

**复杂度**

- 时间：$O(n)$（一次读入压缩 + 一次线性扫描）。$n\le10^4$，$2\times10^4$ 次操作量级，远低于时限。
- 空间：$O(n)$（`a`、`b` 两个全局数组，各 $10005\times4\,\text{B}\approx40\,\text{KB}$）。

## 5. 示例代码（C++）

**本节第一个代码块是正解**（压缩数组法，即 4.2 步骤 1–3，提交用它）；本节末尾的 $O(1)$ 空间状态机是**备选等价实现**（等价性已在引理 5 证明），它整体替代"读入 + 计数"，与正解二选一、不可叠加。

```cpp
// P1317 低洼地
// 压缩相邻等高(平台) + 数严格局部最小值
// https://www.luogu.com.cn/problem/P1317
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int n,m;
int a[mxn],b[mxn];
int ans;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		if(m==0||a[i]!=b[m-1])   // 等高段只留一个代表：平台整体算一个点
			b[m++]=a[i];
	}

	for(int k=1;k<m-1;++k)       // 谷底必在压缩序列内部，m<=2 时自然不循环
		if(b[k]<b[k-1]&&b[k]<b[k+1])
			++ans;

	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **压缩与读入合并**：`b` 由"与前一个保留值不同才写入"生成，$O(n)$ 一遍完成引理 1；`m` 同时是当前长度和写入下标（全局 `int` 默认 0，正好是空序列，无需初始化）。判定式 `m==0||a[i]!=b[m-1]` 把 `m==0` 写在前面，靠 `||` 的短路避免首个元素读 `b[-1]` 越界。`ans` 放全局（默认 0，符合个人风格库"ans 尽量全局"的惯例），main 内不再重复声明。
- **判定行**：`b[k]<b[k-1]&&b[k]<b[k+1]` 就是引理 2 的 (2) 式。因为 `b` 相邻必不等，严格号已经足够，不必写 `<=`，也就不存在 2.3 里的漏算/重算。
- **边界**：循环 `k=1;k<m-1;++k` 覆盖 $[1,m-2]$；引理 4 保证不会因为"漏了首尾"而错——首尾本来就不可能是谷底（$a_0=a_{n-1}=0$、$a_i\ge0$）。
- **移植坑对照**：这里所有全局数组都按"写入过才可读"的方式使用，没有需要预置 INF 的状态，故不需要 `fill_n`；若改成"多组数据"版本，必须在每组开始前把 `m` 归零（`m=0;`），否则上一组的 `b` 会污染这一组。
- **$O(1)$ 空间备选写法**（引理 5 已证与正解等价，只是要记得计数后把标记清零）。**注意：它是"读入 + 计数"的完整替代品，自带 `cin>>x` 循环**——使用它时必须整段替换上面主代码中"读 $n$ 个数并压缩 + 数谷底"两部分，**不能与主代码叠加**（否则数据会被读两遍）：

```cpp
	int ans=0,p=0;
	bool down=false;          // 自上次计数以来是否出现过下降
	for(int i=0;i<n;++i)
	{
		int x;cin>>x;
		if(i)
		{
			if(x<p)
				down=true;
			else if(x>p&&down)
			{
				++ans;
				down=false;   // 漏掉这行会把一个坑数成多个
			}
		}
		p=x;
	}
```

> **复杂度复核**：$O(n)$ 时间、$O(n)$ 空间，$n\le10^4$；答案 $<n\le10^4$（谷底是互不相同的等高段指标），`int` 绰绰有余，无溢出风险。
