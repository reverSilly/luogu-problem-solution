# P1428 小鱼比可爱

> 标签：模拟 · 难度：入门

## 1. 重新读题

**问题重述（白话版）**

$n$ 只鱼从左到右排成一排，第 $i$ 只鱼的可爱度为整数 $a_i$（越大越可爱，**允许相等**）。所有鱼头朝左，于是第 $i$ 只鱼只能看到它**左边的** $i-1$ 只鱼。每只鱼心里在数：**在我能看到的范围里，有多少只鱼的可爱度严格小于我？** 我们要替每只鱼算出这个数。

把这句话翻译成数学式，就是（$1$-based 表述）：

$$ans_i=\#\{j\mid 1\le j<i\ \text{且}\ a_j<a_i\}$$

按输出顺序 $i=1,2,\dots,n$ 逐只打印 $ans_i$。注意 $i=1$ 时左边没有任何鱼，集合为空，故 $ans_1=0$。

**输入 / 输出格式**

- 输入：第一行一个正整数 $n$；第二行 $n$ 个非负整数，空格分隔，依次是从左到右的 $a_i$。
- 输出：**一行**，$n$ 个整数，**空格分隔**，依次对应每只鱼的答案。**顺序不能乱**，就是原始排列顺序。

**数据范围**

| 量 | 范围 |
|---|---|
| $n$ | $1\le n\le 100$ |
| $a_i$ | $0\le a_i\le 10$（非负、且上界只有 10） |

范围极小：$n^2\le 10^4$，$O(n^2)$ 朴素扫描毫无压力；值域 $a_i\in[0,10]$ 只有 11 个取值，为后面的"值域计数"优化埋下伏笔。

**陷阱与边界（逐条确认）**

1. **严格小于还是小于等于**：题面说"有多少只鱼**不如**自己可爱"，"不如"是严格差于，即 $a_j<a_i$，**相等不算**。若错写成 $\le$，则两只一样可爱的鱼会互相计入，答案偏大。
2. **$a_i$ 可以为 $0$**：可爱度最小的鱼左边没人比它更小，答案必为 $0$（对 $a_i=0$，$\{j:a_j<0\}=\varnothing$，因为所有 $a_j\ge0$）。
3. **第一只鱼恒为 $0$**：没有左侧，空集合计数为 $0$。代码里内层循环 $j<i$ 天然处理。
4. **可重复值**：题面明示"任意两只鱼的可爱程度可能一样"，所以不能假设 $a$ 是排列，不能依赖去重。
5. **输出分隔符**：整数之间一个空格，行尾换行；末尾**多打空格**在洛谷一般不判错，但稳妥起见最后一个数后不加空格。
6. **本地题面无样例**：随题下发的 `P1428.md` 未附带样例，故本文**无法与官方样例输出对标**，改为自造边界用例并手算验证（见 §4.3）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：答案只依赖左侧多重集合

先把特殊机制讲清楚。鱼头朝左，第 $i$ 只鱼看不见右边，因此它的内心计数与 $a_{i+1},\dots,a_n$ **完全无关**。

**引理 1（局部性 / 前缀依赖）**
第 $i$ 只鱼的答案只由前缀 $\{a_1,\dots,a_{i-1}\}$ 组成的**多重集合**（含重数）与 $a_i$ 决定：
$$ans_i=\#\{j<i\mid a_j<a_i\}.$$
特别地，把左侧这些鱼任意重排，$ans_i$ 不变。

**证明**：按定义，$ans_i$ 是对 $j\in\{1,\dots,i-1\}$ 中满足 $a_j<a_i$ 的 $j$ 计数。右侧下标 $j>i$ 从不进入这个计数，故 $a_{i+1..n}$ 无关。又"满足 $a_j<a_i$ 的 $j$ 的个数"等于把多重集合 $\{a_1,\dots,a_{i-1}\}$ 里严格小于 $a_i$ 的元素数出来，只取决于每个值出现几次（重数），与这些元素在左侧的先后位置无关。所以对左侧做置换后计数不变。$\blacksquare$

这条性质给了两个方向：其一，可以**从左到右增量**处理——扫到 $i$ 时把 $a_1..a_{i-1}$ 的信息累积好，用它回答 $ans_i$，再把 $a_i$ 并入（这是 §2.4 值域计数的依据）；其二，也允许每只鱼独立地直接数左边（这是 §2.3 朴素做法的依据）。

一个直接推论先记下：

**引理 2（下界与平凡零）** 恒有 $0\le ans_i\le i-1$。且若 $a_i=0$ 则 $ans_i=0$；若 $a_i=\max\limits_{j<i}a_j$ 且左侧无与 $a_i$ 相等者达到，$ans_i$ 仍只数严格更小者，故当 $a_i$ 大于等于左侧全部时 $ans_i=i-1$。

**证明**：左侧只有 $i-1$ 个元素，计数上限即 $i-1$，下限是空集为 $0$。当 $a_i=0$：条件 $a_j<0$ 与 $a_j\ge0$ 矛盾，计数集为空，$ans_i=0$。当 $a_i\ge\max_{j<i}a_j$ 时，每个 $j<i$ 都满足 $a_j\le a_i$；若再要求不存在 $a_j=a_i$（即 $a_i$ 严格大于左侧每个），则 $a_j<a_i$ 对全部 $j$ 成立，$ans_i=i-1$。$\blacksquare$

### 2.2 简化版：先看全相等与单调排列

碰到没思路的题，先代入几组"退化"数据看清答案的形状，是最省力的探路方式。

**（a）全相等** $a=[5,5,5,5]$。每只鱼左边所有鱼都**等于**它，不满足 $a_j<a_i$，故
$$ans=[0,0,0,0].$$
这印证了"严格小于"——若误写成 $\le$，这里会算出 $[0,1,2,3]$，与正确直觉相悖。全相等是**区分 $<$ 与 $\le$ 的关键判别用例**。

**（b）严格递增** $a=[1,2,3,4]$。第 $i$ 只鱼左边全部严格更小，故 $ans_i=i-1$：
$$ans=[0,1,2,3].$$

**（c）严格递减** $a=[4,3,2,1]$。第 $i$ 只鱼左边全部严格更大（$a_j>a_i$），无一满足 $a_j<a_i$：
$$ans=[0,0,0,0].$$
递增与递减一起，把"答案随左侧比它小的个数变化"的上下界 $(0\ \text{到}\ i-1)$ 拉满。

**（d）含 0** $a=[0,1,0]$。$ans_1=0$；$a_2=1$ 左边有 $0<1$，计 $1$；$a_3=0$ 左边 $a_1=0,a_2=1$ 都不 $<0$，计 $0$。得 $ans=[0,1,0]$，与引理 2 的 $a_i=0\Rightarrow ans_i=0$ 一致。

这些特例告诉我们：答案只由"左侧比自己小的个数"驱动，不涉及任何全局比较或选择，本质上是一串**独立的前缀计数**问题。于是自然先写最直接的算法。

### 2.3 朴素做法：双重循环直接计数

引理 1 说每只鱼的答案就是"数左边比自己小的"，于是最老实的写法是：外层枚举当前鱼 $i$，内层枚举左侧每个 $j<i$，遇到 $a_j<a_i$ 就 $+1$。

伪码（0-based）：

```
for i = 0 .. n-1:
    c = 0
    for j = 0 .. i-1:
        if a[j] < a[i]: c = c + 1
    ans[i] = c
```

**引理 3（朴素法正确性）**
上述双重循环对每个 $i$ 输出 $ans_i=\#\{j<i:a_j<a_i\}$。

**证明**：固定 $i$。内层 `for j=0..i-1` 恰好遍历所有满足 $0\le j<i$ 的下标各一次（0-based 下 `j<i` 就是"左侧"）。`c` 从 $0$ 起，每当 $a_j<a_i$ 自增 $1$，故循环结束时 `c` 恰为"使 $a_j<a_i$ 成立的 $j$ 的个数"，正是 §1 的定义式（换成 0-based 记号）。把 `c` 存入 `ans[i]` 即所求。每个 $i$ 相互独立执行，故全部答案正确。$\blacksquare$

**复杂度**：比较次数 $\sum_{i=0}^{n-1} i=\frac{n(n-1)}{2}=O(n^2)$，空间 $O(n)$。当 $n\le100$ 时最多约 $4950$ 次比较，瞬间完成。这就是本题"模拟"标签的标准解法，也是我在 §5 采用的**主代码**。

朴素法不需要任何额外数据结构，几乎不可能写错，是入门题的首选。但它每只鱼都从头重扫左侧，存在明显重复：处理 $i$ 与处理 $i+1$ 时对同一批 $a_j$ 的比较被算了两次。下一节顺着"能否少扫"想优化。

### 2.4 优化：值域计数 + 前缀

**动机**：朴素法把同一批 $a_j$ 反复比较。由引理 1，答案只取决于左侧的**多重集合**，而多重集合可以压缩成"每个值出现几次"。值域又极小（$a_i\in[0,10]$，共 $V=11$ 个取值），于是维护计数数组最划算。

**做法**：设 $cnt[v]$ = 已经扫过（在当前鱼左侧）的、可爱度恰为 $v$ 的鱼数。从左往右扫，处理鱼 $i$ 时：
$$ans_i=\sum_{v=0}^{a_i-1}cnt[v]\qquad(\text{随后执行 }cnt[a_i]\texttt{++} ).$$

**引理 4（计数式与朴素式相等）**
扫到鱼 $i$（尚未把 $a_i$ 并入 $cnt$）时，$\sum_{v=0}^{a_i-1}cnt[v]=\#\{j<i:a_j<a_i\}$。

**证明**：此刻 $cnt[v]=\#\{j<i:a_j=v\}$（归纳：初值全 $0$ 时对 $i=1$ 左侧为空成立；每步只把 $cnt[a_i]$ 加一，保持"$cnt[v]$ 等于左侧取值为 $v$ 的个数"这一不变量）。左侧满足 $a_j<a_i$ 的鱼，按取值 $v\in\{0,1,\dots,a_i-1\}$ 分类，各类互不相交且恰有 $cnt[v]$ 个，故总数 $=\sum_{v=0}^{a_i-1}cnt[v]$。当 $a_i=0$ 时求和上下限空，值为 $0$，与引理 2 一致。$\blacksquare$

**复杂度**：每只鱼做 $O(a_i)\le O(V)$ 次加法加一次自增，总计 $O(nV)=O(11n)$；若把 $\sum_{v<a_i}cnt[v]$ 再用一棵值域树状数组（Fenwick）维护，则单次查询降到 $O(\log V)$，整体 $O(n\log V)$。本题 $V=11$ 常数极小，直接线性求和即可，无需树状数组。

这条优化在 $n$ 很大、$a_i$ 有界时才显著（例如 $n\le10^6,a_i\le1000$）。本题 $n\le100$，两种做法都在毫秒级，取哪一个纯属工程偏好——见 §4。

### 2.5 溢出防护与数据选择

逐项核算最坏量级，确认类型够用：

- **答案上界**：$ans_i\le i-1\le n-1\le99$，远小于 `int`（$\approx2\times10^9$）。
- **计数数组**：$cnt[v]\le n\le100$，`int` 足够。
- **求和 $\sum_{v<a_i}cnt[v]$**：至多 $n$ 项、每项 $\le n$，$\le n^2=10^4$，`int` 足够。
- **内层累加变量 `c`**：$\le n\le100$。

结论：全程 `int` 即可，**无需 `long long`**。代码里 `using i64=long long;` 仅是风格模板的固定一行，本题并未真正使用 64 位；留着不影响正确性。若日后把 $n$ 放大到 $10^5\sim10^6$ 量级且仍用 $O(nV)$ 计数，答案单项上界是 $i-1\le10^6$，`int` 仍够；只有再叠加"输出所有 $ans_i$ 之和"这类全局累加（$\le\frac{n(n-1)}{2}$，$n=10^6$ 时 $\approx5\times10^{11}>2^{31}$）才需要 `i64`。本题不触及。

## 3. 模式总结（Pattern Summary）

按真实思考顺序列出短标签，一技巧一条：

- 探索性质（局部性）— 用引理 1 把"看左边"翻译成"答案只依赖左侧多重集合"，排除右侧干扰。
- 考虑简化版 — 代入全相等 / 严格递增 / 严格递减 / 含 0 四组退化数据，暴露"严格小于"语义与 $0\le ans_i\le i-1$ 上下界。
- 边界判别用例 — 用"全相等"专门区分 $<$ 与 $\le$，防止把相等计入。
- 朴素实现（直接计数）— 双重循环按定义硬算，$O(n^2)$，最稳、最好验证。
- 剖析重复 — 发现相邻两只鱼重复比较同一批左侧元素，萌生"缓存左侧信息"的想法。
- 归约到更简单问题 — 把"数左侧比自己小的个数"归约成"对值域 $[0,a_i)$ 求出现次数之和"。
- 计数优化（值域压缩）— 用 $cnt[v]$ 记录每个值出现次数，答案 $=\sum_{v<a_i}cnt[v]$，降到 $O(nV)$。
- 经典数据结构（可选）— 值域再大时用 Fenwick 把单次查询压到 $O(\log V)$（本题不需要）。
- 溢出核算 — 逐项估 $ans_i\le n$、和 $\le n^2$，确认 `int` 够用，无需 64 位。

## 4. 真实解法

本题有两条并列可行路线，先都给出，再说明取哪条。

### 4.1 记号表（两种解法共用）

| 记号 | 类型 | 含义 | 初始化 |
|---|---|---|---|
| $n$ | `int` | 鱼的只数，$1\le n\le100$ | 读入 |
| $a[i]$ | `int[]` | 第 $i$ 只鱼可爱度（**0-based**，$0\le i<n$，$0\le a[i]\le10$） | 读入 |
| $ans[i]$ | `int[]` | 第 $i$ 只鱼的答案 $\#\{j<i:a[j]<a[i]\}$ | 全局数组默认 $0$，逐位写入 |
| $cnt[v]$ | `int[]` | （仅解法 B）已扫过、取值为 $v$ 的鱼数，$0\le v\le10$ | 全局默认 $0$ |
| $V$ | 常数 | 值域大小 $=11$（$0..10$） | — |

### 4.2 解法 A（朴素 $O(n^2)$，**主代码**）与解法 B（值域计数 $O(nV)$）

**解法 A — 双重循环**：见引理 3。步骤：
1. 读 $n$，读 $a[0..n-1]$。
2. `for i=0..n-1`：`c=0`；`for j=0..i-1`：若 `a[j]<a[i]` 则 `c++`；`ans[i]=c`。
3. 按 $i=0..n-1$ 顺序打印 $ans$，数间一个空格、行尾换行。

**解法 B — 值域计数**：见引理 4。步骤：
1. 读 $n$ 与 $a$；$cnt[0..10]$ 清零。
2. `for i=0..n-1`：`s=0`；`for v=0..a[i]-1`：`s+=cnt[v]`；`ans[i]=s`；`cnt[a[i]]++`。
3. 顺序打印 $ans$。

**复杂度对照**：

| 解法 | 时间 | 空间 | 代码量 |
|---|---|---|---|
| A 朴素 | $O(n^2)=O(10^4)$ | $O(n)$ | 最短 |
| B 计数 | $O(nV)=O(11n)$ | $O(n+V)$ | 略长 |

**取哪一个及原因**：本题 $n\le100$，两法都远在时限内；**主代码取解法 A**，理由是按定义直写、最贴合"模拟"标签、最不易写错、也最方便手算对拍验证。解法 B 只作为"当 $n$ 放大、$a_i$ 有界时"的推广思路保留（其完整代码见 §5.2，逻辑独立可单独提交）。

### 4.3 验证状态（全部手算，禁用编译/运行/联网）

> **重要声明**：本地 `P1428.md` 未附样例，**无法与官方样例答案对标**。以下均以自造用例，按解法 A 的定义逐步手算，并顺手用解法 B 交叉复核，两法结果一致。

**用例 1（最小规模 $n=1$）**：$a=[7]$。左侧无鱼，$ans=[0]$。输出 `0`。

**用例 2（全相等，验严格小于）**：$a=[5,5,5,5]$。每只左边都等于它，无严格小者，$ans=[0,0,0,0]$。若误用 $\le$ 会得到 $[0,1,2,3]$，故此项是 $< $ 与 $\le$ 的判别器。

**用例 3（含 0 + 混合，主力用例）**：$a=[1,3,2,7,5,4,6,8]$，逐步手算：
- $i=0,a=1$：左侧空 $\to 0$。
- $i=1,a=3$：$\{1\}$ 中 $1<3$ $\to 1$。
- $i=2,a=2$：$\{1,3\}$ 中 $1<2$ 而 $3\not<2$ $\to 1$。
- $i=3,a=7$：$\{1,3,2\}$ 全 $<7$ $\to 3$。
- $i=4,a=5$：$\{1,3,2,7\}$ 中 $1,3,2<5$、$7\not<5$ $\to 3$。
- $i=5,a=4$：$\{1,3,2,7,5\}$ 中 $1,3,2<4$、$7,5\not<4$ $\to 3$。
- $i=6,a=6$：$\{1,3,2,7,5,4\}$ 中 $1,3,2,5,4<6$、$7\not<6$ $\to 5$。
- $i=7,a=8$：左侧 $7$ 个全 $<8$ $\to 7$。

得 $ans=[0,1,1,3,3,3,5,7]$，输出 `0 1 1 3 3 3 5 7`。
用解法 B 复核末位 $i=6,a=6$：此时 $cnt[1]=cnt[2]=cnt[3]=cnt[4]=cnt[5]=1,cnt[7]=cnt[8]$ 未并入，$\sum_{v=0}^{5}cnt[v]=cnt[1]+..+cnt[5]=5$，与解法 A 的 $5$ 一致。$\checkmark$

**用例 4（严格递减，验下界恒 0）**：$a=[3,2,1,0]$。每只左边全部更大，$ans=[0,0,0,0]$。

四组覆盖了 $n=1$、全相等、含 0、严格单调、值域上界 $8/10$ 等边界；解法 A 与 B 交叉核对结果一致。**未做程序化对拍**（按禁令不编译运行），正确性由引理 3、引理 4 的证明与上述手算共同支撑。

## 5. 示例代码

### 5.1 主代码（解法 A：朴素双重循环）

严格遵循风格指南：`bits/stdc++.h` 唯一头文件、`using i64=long long;`（本题虽用不到）、全局静态数组、`constexpr int mxn{...}`（$100+5$ 松弛）、Tab 缩进、运算符两侧无空格、`'\n'` 换行、`cin.tie→cout.tie→sync` 固定顺序、内部 0-based。

```cpp
// https://www.luogu.com.cn/problem/P1428
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};

int n,a[mxn],ans[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0;i<n;++i)
	{
		int c=0;
		for(int j=0;j<i;++j)
			if(a[j]<a[i])          // 严格小于，相等不计
				++c;
		ans[i]=c;
	}
	for(int i=0;i<n;++i)
	{
		if(i)
			cout<<' ';
		cout<<ans[i];
	}
	cout<<'\n';
	return 0;
}
```

### 5.2 备选代码（解法 B：值域计数 $O(nV)$）

仅当 $n$ 很大、$a_i$ 有界时优于解法 A；本题规模下二者皆可，逻辑独立、可单独提交。

```cpp
// https://www.luogu.com.cn/problem/P1428
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};
constexpr int mxv{15};            // 值域 0..10，+5 松弛

int n,a[mxn],ans[mxn],cnt[mxv];   // cnt[v]=左侧取值 v 的鱼数，全局默认 0

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0;i<n;++i)
	{
		int s=0;
		for(int v=0;v<a[i];++v)   // a[i]==0 时循环不执行，s=0
			s+=cnt[v];
		ans[i]=s;
		++cnt[a[i]];             // 并入当前鱼，供后续使用
	}
	for(int i=0;i<n;++i)
	{
		if(i)
			cout<<' ';
		cout<<ans[i];
	}
	cout<<'\n';
	return 0;
}
```
