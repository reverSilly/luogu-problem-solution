# P1604 B进制星球

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给定进制 $B\ (2\le B\le36)$ 与两个 $B$ 进制正整数（数字位取自 $0\sim9$ 与 $A\sim Z$，其中 $A$ 表示 $10$，…，$Z$ 表示 $35$），
求它们的和，并按 $B$ 进制输出（大写字母）。

### 输入输出格式

- **输入格式**：三行，第一行十进制整数 $B$；后两行各一个 $B$ 进制数。
- **输出格式**：一行，一个 $B$ 进制数，表示两数之和。
- **数据规模**：$2\le B\le36$，两个数的长度 $1\le n,m\le2000$。

### 关键约束分析

1. **长度 $2000$**：和十进制高精度加法一样，$B^{2000}$ 远超任何内置类型，必须按位模拟。
2. **进制不固定**：进位阈值是 $B$ 而不是 $10$，每一位的"和"要先转到数值域再转回字符域。
3. **字符与数值的双向映射**：$0\sim9$ 与 $A\sim Z$ 两段不连续（`'9'` 与 `'A'` 之间隔着若干标点），不能用 `c-'0'` 一把梭。
4. **前导零**：输入保证是正整数，理论上无前导零，但结果可能出现前导零（例如 $1+(-)$ 之类不会，主要来自 `0+0`），输出前需要统一处理。
5. **输出大小写**：题目要求 $B$ 进制数的字母位，按惯例输出大写，小写会被判错。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：从十进制高精度加法迁移

$B=10$ 时这就是 P1601。那里的核心是"反转成低位在前、逐位相加、维护进位"。
把 $10$ 换成 $B$ 即可，但要检查两件事：**进位是否仍不超过 $1$**，以及**字符如何换成数值**。

**引理 1（进位不超过 $1$）**：设本位两个数字 $x,y\in[0,B-1]$，进位 $c\in\{0,1\}$，则 $t=x+y+c$ 满足 $t\le 2B-1<2B$，
故本位为 $t\bmod B$，新进位为 $\lfloor t/B\rfloor\in\{0,1\}$。

*证明*：$x+y+c \le (B-1)+(B-1)+1 = 2B-1$，除以 $B$ 的商至多为 $1$（因为 $2B-1<2B$），且非负，故进位只能取 $0$ 或 $1$。
取模与整除是确定函数，本位与新进位唯一。$\square$

引理 1 说明"一个进位变量"就够，与十进制完全同构，代码只需把 $10$ 换成 $B$。

### 第二步：字符与数值的映射

**引理 2（映射是双射）**：定义 $\mathrm{val}(c)=c-\texttt{'0'}$（当 $c$ 是数字）或 $c-\texttt{'A'}+10$（当 $c$ 是大写字母），
$\mathrm{dig}(v)=v+\texttt{'0'}$（$v<10$）或 $v+\texttt{'A'}-10$（$v\ge10$），则对任意合法位字符 $c$ 有 $\mathrm{dig}(\mathrm{val}(c))=c$，对任意 $v\in[0,B-1]$ 有 $\mathrm{val}(\mathrm{dig}(v))=v$。

*证明*：$c$ 是数字时 $c\in[\texttt{'0'},\texttt{'9'}]$，$\mathrm{val}(c)=c-\texttt{'0'}\in[0,9]$，回代得 $c-\texttt{'0'}+\texttt{'0'}=c$；
$c$ 是字母时 $\mathrm{val}(c)=c-\texttt{'A'}+10\in[10,35]$，回代得 $(c-\texttt{'A'}+10)+\texttt{'A'}-10=c$。
反向同理。两个分支的像集 $[0,9]$ 与 $[10,35]$ 不相交，故映射无歧义。$\square$

有了引理 2，逐位加法就变成"字符 → 数值 → 相加 → 字符"的循环。

### 第三步：长度与最终进位

**引理 3（结果长度上界）**：两数之和的 $B$ 进制位数不超过 $\max(n,m)+1$。

*证明*：两数分别小于 $B^{n}$ 与 $B^{m}$，其和小于 $2B^{\max}$，而 $2\le B$ 给出 $2B^{\max}\le B^{\max+1}$，故位数至多 $\max+1$。$\square$

与 P1601 一样，把循环条件写成 `i>=0||j>=0||carry` 就能自动补出最高位，不需要按引理 3 预分配长度。

### 第四步：输出规范化

**引理 4（去前导零）**：结果串去掉前导 `0` 后若为空则输出 `0`，否则输出剩余部分，得到的是和的标准 $B$ 进制写法。

*证明*：前导零不改变数值，故剩余部分数值不变；标准写法要求最高位非零（$0$ 本身例外），
去掉前导零后最高位非零或整体为空（此时和为 $0$），符合标准写法。$\square$

**定理**：算法输出的 $B$ 进制串与两数之和的标准 $B$ 进制表示逐字符相同。

*证明*：由引理 1 每位计算正确且进位正确，由引理 2 字符与数值互换无损，由引理 3 不丢最高位，
由引理 4 输出格式合法。$\square$

### 第五步：实现方式的选择

- 用 `string` 追加低位结果再 `reverse`，避免头插的 $O(L^2)$；
- `val`/`dig` 写成两个小函数，逻辑集中在映射上；
- 去前导零用"找第一个非零下标 + `substr`"。

## Part 3 — 模式总结 (Pattern Summary)

- `reduce to easier problem` — 把 $B$ 进制加法化归成"十进制竖式"的同构版本，只是把 $10$ 换成 $B$。
- `explore its property` — 进位仍只有 $0/1$ 两种，因为 $2B-1<2B$。
- `classic problem solution` — 反转后逐位相加 + 单进位变量，$\mathcal{O}(n+m)$。
- `handle encoding` — 字符与数值双向映射（数字段与字母段分开处理）。
- `normalize output` — 统一去前导零并处理全零，输出大写字母。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $B$ | `B` | 进制，$2\le B\le36$ |
| $a,b$ | `a`, `b` | 两个输入串（高位在前） |
| $i,j$ | `i`, `j` | 从末尾向前扫描的下标，$-1$ 表示该数处理完 |
| $c_i$ | `carry` | 进入本位的进位，取值 $0/1$，初值 $0$ |
| $x,y$ | `x`, `y` | 本位数值，由 `val()` 从字符转换而来（越界取 $0$） |
| $t$ | `t` | 本位和 $x+y+carry$，范围 $[0,2B-1]$ |
| $R$ | `sum_` | 结果串，低位在前追加，最后反转 |
| $p$ | `p` | 反转后第一个非零位下标 |
| $\mathrm{val}$ | `val(c)` | 位字符 → 数值 |
| $\mathrm{dig}$ | `dig(v)` | 数值 → 位字符（大写字母） |

### 算法步骤

1. 读入 $B$、`a`、`b`。
2. 令 `i=a.size()-1`，`j=b.size()-1`，`carry=0`；当 `i>=0||j>=0||carry` 时：
   `x = i>=0 ? val(a[i--]) : 0`，`y = j>=0 ? val(b[j--]) : 0`，`t=x+y+carry`，`sum_+=dig(t%B)`，`carry=t/B`。
3. `reverse(sum_)`。
4. 跳过前导 `0`（至少保留一位），输出 `substr(p)`。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}(\max(n,m))$，$n,m\le2000$，每位常数次操作；`reverse` 与 `substr` 也是线性。
- **空间复杂度**：$\mathcal{O}(n+m)$，只存两个输入串与一个结果串。

### 正确性验证

引理 1 保证逐位加法的进位规则正确且不会进 $2$；引理 2 保证字符与数值互换无损；引理 3 保证不丢最高位；
引理 4 保证输出格式合法；定理给出整体正确性。
数值范围：$t\le 2\times36-1=71$，`int` 足够；无浮点、无溢出。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1604 B进制星球
// https://www.luogu.com.cn/problem/P1604
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005};          // n,m<=2000 (+5 松弛)

int B;
string a,b,sum_;

int val(char c)
{
	if(c>='0'&&c<='9')
		return c-'0';
	return c-'A'+10;
}

char dig(int v)
{
	if(v<10)
		return char('0'+v);
	return char('A'+v-10);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>B>>a>>b;

	int i=a.size()-1,j=b.size()-1,carry=0;
	while(i>=0||j>=0||carry)         // 低位在前逐位相加
	{
		int x=i>=0?val(a[i--]):0;
		int y=j>=0?val(b[j--]):0;
		int t=x+y+carry;
		sum_+=dig(t%B);
		carry=t/B;
	}
	reverse(sum_.begin(),sum_.end());

	size_t p=0;                      // 去掉前导零, 至少保留一位
	while(p+1<sum_.size()&&sum_[p]=='0')
		++p;
	cout<<sum_.substr(p)<<'\n';
	return 0;
}
```

### 易错点

1. **把进位阈值写成 $10$**：必须用 $B$；否则 $B\ne10$ 时结果全错。
2. **字符映射用 `c-'0'` 处理字母**：`'A'-'0'` 是 $17$ 而不是 $10$，必须先判段。
3. **输出小写字母**：题面给的是大写字母位，输出也应大写。
4. **忘记末尾进位**：循环条件漏 `carry` 会丢掉最高位（如 `B` 进制下 `ZZ+1`）。
5. **`0+0` 输出空串**：去前导零时必须至少保留一位。
6. **`B` 与字符串用同一个变量名**：会把进制覆盖掉，读入顺序要固定为 `cin>>B>>a>>b`。

### 本地验证结果

题面归档无样例段，使用小手算用例（如 $B=16$ 的 `F+F=1E`、$B=2$ 的 `1+1=10`、$B=36$ 的 `Z+1=10`），并与"转成 $10^9$ 基大整数再转回 $B$ 进制"的暴力（`P1604_brute.cpp`）对拍。

| 规模边界 | $n=m=2000$（$B=16$ 全 `F`、$B=2$ 全 `1`、$B=36$ 全 `Z`） | 通过，长度增长一位正确 |
