# P1928 外星密码

## 1. 重新读题

### 1.1 问题重述（人话版）

外星人的压缩规则是：把连续重复的若干份相同子串 $\texttt{X}$ 写成 $\texttt{[DX]}$，其中 $D$ 是 $1\sim99$ 的整数。例如 $\texttt{CBCBCBCB}$ 可以写成 $\texttt{[4CB]}$，也可以写成 $\texttt{[2[2CB]]}$。给定一个这样的压缩串，把它完整展开后输出。

### 1.2 关键约束与规模暗示

- 展开后的长度不超过 $20000$，压缩最多十重。
- 压缩串只含数字、大写字母、`[`、`]`。
- 展开长度只有 $2\times10^4$，说明**不必**设计线性复杂度的精巧算法，直接按结构递归展开即可；真正要小心的是括号嵌套与两位数的重复次数。
- “最多十重”意味着递归深度最多 $10$，不可能爆栈。

## 2. 思维链（Chain-of-thought）

### 2.1 看清结构：这是一个递归的语言

先别急着写代码，先精确描述压缩串的语法。一个“块”是下面两种东西的任意拼接：

1. 一个大写字母；
2. `[` $D$ 一个块 `]`，表示把这个块重复 $D$ 次。

这里的关键点是：**重复的对象是一个完整的块**，而不是一串字符。例如 `[2[2CB]]` 中，外层重复的是“已经被内层展开后的 $\texttt{CBCB}$”，所以必须先算出内层，再乘以外层的次数。

于是最自然的做法是写一个递归下降解析器：

```text
parse():
    res = ""
    while 还有字符:
        若当前是 ']'：返回 res        // 本层块结束
        若当前是 '['：
            跳过 '['
            读入整数 D（可能是一位也可能是两位）
            inner = parse()           // 递归展开到匹配的 ']'
            跳过 ']'
            res += inner 重复 D 次
        否则（大写字母）：
            res += 当前字符，指针后移
    return res
```

### 2.2 为什么不能用“反复字符串替换”

一个很自然的失败尝试是：每次在串里找形如 `[数字字母]` 的最内层模式，替换成展开结果，循环直到没有方括号。这个做法能过部分数据，但有两个坑：

- 内层展开后可能又和外层拼成新的可替换模式，需要反复扫描，最坏会退化成 $O(L^2)$；
- 找“最内层”时要处理括号匹配，而 `D` 还可能是两位数，正则式的模式并不只是 `[数字字母]`。

递归下降一次扫描就解决了这两点：读到 `[` 就先递归把内部彻底展开，再把结果整体重复。

### 2.3 正确性证明

**引理 1（`parse` 的语义）**：设调用 `parse` 时指针位于某个块的开头，且该块在字符串中一直延伸到第一个“与本层匹配的” `]` 之前（若本层是顶层则延伸到串尾）。则 `parse` 返回的正是这个块展开后的字符串，并且返回时指针恰好停在这个匹配的 `]` 上（顶层则停在串尾）。

**证明**：对块的嵌套层数做归纳。

- 若块内没有 `[`，则块只由若干大写字母组成，循环逐个追加，显然返回正确，且遇到 `]` 或串尾停止。
- 若块内含有 `[`，设遇到的第一个 `[` 开始一个重复段。读完 `D` 后，`parse` 递归处理的正是这个 `[` 所对应的那个块的内容；由归纳假设，内层返回的内容正确，且指针停在内层匹配的 `]` 上。跳过它后，`inner` 重复 $D$ 次即为该段的展开结果。段与段之间是直接拼接，所以外层 `res` 正确。外层遇到自己的 `]` 时返回，指针停在该 `]` 上。

由于每次递归都深入一层括号，最多十层，归纳有终点。$\blacksquare$

**引理 2（多位数必须整体读入）**：重复次数 $D$ 可以是一位或两位，必须连续读完所有数字再开始递归。

**证明**：题面给出 $1\le D\le99$。若只读一位，则 `[12AB]` 会把 $12$ 读成 $1$，随后把字符 `2` 当作块内容，展开结果多出一个 `2`，与定义不符。$\blacksquare$

### 2.4 复杂度

设最终展开长度为 $L\le20000$，嵌套深度为 $d\le10$。

- 时间：每个输出字符在它经过的每一层括号处被复制一次，总代价 $O(L\cdot d)\le2\times10^5$。
- 空间：递归栈深度 $O(d)$，各层中途保存的串总长度 $O(L\cdot d)$，同样不超过 $2\times10^5$ 个字符。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 压缩规则定义了“块”的递归语法，重复作用于整个已展开的块。
- **consider easier version** — 若没有嵌套，只需遇到 `[D` 后复制到 `]`；嵌套迫使我们用递归先算内层。
- **classic problem solution** — 递归下降解析：函数返回一个块的展开结果，遇 `]` 返回。
- **pitfall** — $D$ 可能是两位数；`]` 是“本层结束”的哨兵，不应被外层消费两次。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `s` | `string` | 输入的压缩串 | `cin>>s` | source |
| `p` | `int` | 当前扫描位置（全局） | $0$ | pointer |
| `parse()` | 返回 `string` | 展开从 `p` 开始的一个块，停在匹配的 `]` 或串尾 | — | 递归主体 |
| `d` | `int` | 当前重复次数 | 读到 `[` 后解析 | digit |
| `inner` | `string` | 内层块的展开结果 | 递归返回值 | 内层 |
| `res` | `string` | 本层拼接结果 | `""` | result |

### 4.2 算法步骤

1. 读入字符串 `s`，令 `p=0`。
2. 调用 `parse()`：
   1. 若 `p` 越界或 `s[p]==']'`，返回当前 `res`（本层结束）。
   2. 若 `s[p]=='['`：`++p`；连续读数字得到 `d`；`inner=parse()`；`++p` 跳过 `]`；把 `inner` 追加 $d$ 次到 `res`。
   3. 否则 `s[p]` 是大写字母，直接追加并 `++p`。
3. 输出 `parse()` 的结果。

### 4.3 复杂度分析

- 时间 $O(L\cdot d)$，其中 $L\le20000$，$d\le10$。
- 空间 $O(L\cdot d)$（字符串暂存）加 $O(d)$ 递归栈。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

string s;
int p;

string parse()
{
	string res;
	while(p<(int)s.size())
	{
		char c=s[p];
		if(c==']')
			return res;
		if(c=='[')
		{
			++p;
			int d=0;
			while(p<(int)s.size()&&s[p]>='0'&&s[p]<='9')
				d=d*10+(s[p++]-'0');
			string inner=parse();
			++p;              // skip ']'
			for(int i=0;i<d;++i)
				res+=inner;
		}
		else
		{
			res+=c;
			++p;
		}
	}
	return res;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	cout<<parse()<<'\n';
	return 0;
}
```
