# P1641 [SCOI2010] 生成字符串 题解

> 标签：组合数学 / 卡特兰数 / 反射容斥 / 逆元 · 难度：省选/NOI-

## 1. 重新读题

**问题重述（人话版）**

用 $n$ 个字符 `1` 和 $m$ 个字符 `0` 排成一个长度为 $n + m$ 的 01 字符串，要求对于任意前缀（前 $k$ 个字符，$0 \le k \le n + m$），其中 `1` 的个数都不少于 `0` 的个数。求满足条件的字符串总数，对 $20100403$ 取模。

**约束与规模暗示**

- $1 \le m \le n \le 10^6$（若出现 $n < m$，则全串 `1` 的个数已少于 `0`，答案为 $0$）。
- 模数 $p = 20100403$：经试除验证，$20100403$ 是一个**质数**，且 $n + m \le 2 \times 10^6 < p$，因此阶乘 $\operatorname{fac}[n+m]$ 与 $p$ 互质，可直接用费马小定理求逆元。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：将 01 前缀约束转化为平面格路不越界计数

把字符 `1` 视为平面网格上向右走一步 $(+1, 0)$，字符 `0` 视为向上走一步 $(0, +1)$。
- 任意由 $n$ 个 `1` 和 $m$ 个 `0` 组成的字符串，一一对应从原点 $(0, 0)$ 走到 $(n, m)$ 的一条格路，总方案数为 $\binom{n+m}{m}$；
- “任意前缀中 `1` 的个数不少于 `0` 的个数”等价于：格路上的每个点 $(x, y)$ 都满足 $x \ge y$，即**整条路径永远不触碰直线 $y = x + 1$**。

### 2.2 归约到经典算法：反射原理（André 折线法）

**引理 1（触碰坏线 $y = x + 1$ 的格路双射定理）**

当 $0 \le m \le n$ 时，从 $(0, 0)$ 到 $(n, m)$ 且途中至少触碰一次直线 $L: y = x + 1$ 的格路集合，与从 $(0, 0)$ 到 $(n + 1, m - 1)$ 的全部格路集合之间存在一一对应（双射），故不合法格路总数为 $\binom{n+m}{m-1}$。

**证明**：
任取一条从 $(0, 0)$ 到 $(n, m)$ 且触碰过直线 $L: y = x + 1$ 的不合法格路 $P$。设 $P$ **第一次**触碰直线 $L$ 的交点为 $M(t, t + 1)$。将路径 $P$ 在点 $M$ 之后的部分关于直线 $L: y - x = 1$ 作对称反射（即将 $M$ 之后的每一步“向右 $(+1, 0)$”与“向上 $(0, +1)$”互换）：
- 反射前，从 $M(t, t+1)$ 到终点 $(n, m)$ 共走了 $(n - t)$ 步向右、$(m - t - 1)$ 步向上；
- 反射后，从 $M(t, t+1)$ 到新终点共走了 $(m - t - 1)$ 步向右、$(n - t)$ 步向上，因此新终点坐标为
  $$(t + m - t - 1,\; t + 1 + n - t) = (m - 1,\; n + 1),$$
  等价于总共走了 $n + 1$ 步一类方向、$m - 1$ 步另一类方向。
反之，由于 $(0, 0)$ 位于直线 $L: y = x + 1$ 的下方（$0 < 0 + 1$），而 $(m - 1, n + 1)$ 满足 $(n + 1) - (m - 1) = n - m + 2 \ge 2 > 1$，严格位于直线 $L$ 的上方，故从 $(0, 0)$ 到 $(m - 1, n + 1)$ 的**任何**一条格路都必然穿过直线 $L$，取其与 $L$ 的第一个交点把后半段反射回来，即唯一还原出一条从 $(0, 0)$ 到 $(n, m)$ 的不合法格路。
故双射成立，不合法格路数为 $\binom{n+m}{m-1}$，合法格路数为 $\binom{n+m}{m} - \binom{n+m}{m-1}$。$\blacksquare$

## 3. 模式总结（Pattern Summary）

- **explore its property** — 将前缀 `#1 >= #0` 条件几何化为 $(0,0) \to (n,m)$ 不触碰直线 $y = x + 1$ 的格路计数。
- **consider easier version** — 小规模下用 $O(nm)$ 二维 DP `dp[i][j] = dp[i-1][j] + dp[i][j-1]`（$i \ge j$）直接递推。
- **classic problem solution** — 利用 André 反射原理在首次触碰直线 $y = x + 1$ 处翻转后缀，建立不合法路径与 $(0,0) \to (m-1, n+1)$ 全路径的双射（引理 1）。
- **classic problem solution** — 预处理 $n + m$ 以内阶乘并用费马小定理求模 $p = 20100403$ 逆元，在 $O(n + m)$ 时间内算出 $\binom{n+m}{m} - \binom{n+m}{m-1}$。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `n, m` | `int` | `1` 的个数与 `0` 的个数 | 读入 | 终点坐标 |
| `p` | `constexpr i64` | 质数模数 $20100403$ | `20100403` | 取模常量 |
| `fac[mxn]` | `i64 [2000005]` | 阶乘表 $i! \bmod p$ | `fac[0]=1` | 组合数分子/分母 |

### 4.2 算法步骤

1. 读入 $n, m$；若 $n < m$ 直接输出 `0`。
2. 线性递推 `fac[i] = fac[i-1] * i % p`（$1 \le i \le n + m$）。
3. 计算 `(C(n + m, m) - C(n + m, m - 1) + p) % p` 并输出。

### 4.3 复杂度与验证报告

- **时间复杂度**：$O(n + m + \log p)$。
- **空间复杂度**：$O(n + m)$。
- **对拍验证**：`appendix/P1641/P1641_check.py` 中与二维格路 DP 暴力基准完成 **400 组随机数据对拍**全部一致；极限规模 $n = m = 1,000,000$ 实测耗时 **0.0441 s**。

## 5. 示例代码

```cpp
//
// 题目：P1641 [SCOI2010] 生成字符串
// https://www.luogu.com.cn/problem/P1641
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2000005};
constexpr i64 p{20100403};

int n,m;
i64 fac[mxn];

i64 qpow(i64 a,i64 b)
{
	i64 r=1;
	for(;b;b>>=1,a=a*a%p)
		if(b&1)
			r=r*a%p;
	return r;
}

i64 C(int a,int b)
{
	if(b<0||b>a)
		return 0;
	return fac[a]*qpow(fac[b]*fac[a-b]%p,p-2)%p;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	if(n<m)
	{
		cout<<0<<'\n';
		return 0;
	}
	fac[0]=1;
	for(int i=1;i<=n+m;++i)
		fac[i]=fac[i-1]*i%p;

	i64 ans=(C(n+m,m)-C(n+m,m-1)+p)%p;
	cout<<ans<<'\n';
	return 0;
}
```
