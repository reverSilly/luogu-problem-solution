# P1518 [USACO2.4] 两只塔姆沃斯牛 The Tamworth Two

> 标签：模拟 / USACO · 难度：普及/提高-
> 本地题面：`P1518.md`（$10\times 10$ 网格，一个 `F`、一个 `C`，初始均朝北）。验证：`appendix/P1518/` 中官方样例（答案 $49$）+ 400 组随机地图对拍 + 永不相遇最坏规模计时，std 与暴力逐字节一致。

## 1. 重新读题

**问题重述（人话版）**

在一个 $10\times 10$ 的网格上，每格有四种可能：空地 `.`、障碍 `*`、**两头牛（总在一起，记为一个单位）** `C`、农夫 John `F`。保证恰有一个 `F` 与一个 `C`，且它们起始不在同一格。

两个单位（John 与"牛"）**同时**按如下规则行动：**每分钟**，若它当前朝向的正前方那格是空地，就前进一步；否则（前方是障碍、或前方越出地图边界——**边界也算障碍**）这一分钟原地不动、并顺时针转 $90^\circ$。两者最初都朝**正北（上）**。

若某分钟**末**两个单位位于同一格，则抓捕结束，输出经过的分钟数；若永远抓不到，输出 $0$。

> 关键细节：两个单位是**同时**移动的；若它们只是"穿过对方"（交换彼此的位置）而在某一分钟末并未同格，则**不算相遇**。

**题面里容易漏掉的条款**

1. 「地图边沿也是障碍」$\Rightarrow$ 判定前方是否可走时必须把越界当成撞墙，进而原地右转。
2. 「每次（每分钟）Farmer John 和两头牛的移动是同时的」$\Rightarrow$ 要先算出两者本分钟后各自的新状态，**再**统一比较位置；不能先移动一个再判断。
3. 「穿过对方但没有在同一格相遇，不认为相遇」$\Rightarrow$ 判定条件就是**分钟末两单位坐标相等**，交换位置不触发。
4. 「如果 John 和牛永远不会相遇，输出 $0$」$\Rightarrow$ 必须能判断"永不相遇"并终止；由于系统是有限状态且确定性，迟早会进入循环。

**数据范围与规模感受**

网格固定 $10\times10$。每个单位的"状态" = 位置（$100$ 种）$\times$ 朝向（$4$ 种）$=400$ 种；两个单位合计 $400\times400=160000$ 种。这个有限的、很小的状态数就是本题"最多模拟多久"的天然上界——超过它必然重复。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：每个单位都是"前进/右转"的确定性自动机

先只盯一个单位。它的行为完全由"当前坐标 + 当前朝向"决定：给定这两者，下一分钟发生什么（前进一格，还是原地右转）是**唯一确定**的。我们把它写成一个函数：

$$\text{step}(r,c,d):\quad (r',c',d')=\begin{cases}(r+dr_d,\ c+dc_d,\ d),&\text{前方可走}\\ (r,\ c,\ (d+1)\bmod 4),&\text{前方不可走}\end{cases}$$

其中 $dr,dc$ 是按朝向取的单位位移。可走的定义是"目标格在地图内**且**不是 `*`"。

**引理 1（确定性）**

$step$ 是良定义的纯函数：相同的 $(r,c,d)$ 永远产生相同的 $(r',c',d')$。

**证明**：$step$ 的右端只依赖输入 $(r,c,d)$ 与固定的地图，没有任何随机或外部状态；"前方可走"是一个关于 $(r,c,d)$ 的确定命题。故它是纯函数。$\blacksquare$

### 2.2 考虑简化版：只有一个目标时怎么判"永不相遇"

设想只有 John 一个目标（或只追踪一个自动机）。那就是一条由 $step$ 生成的轨迹。**引理 1 说轨迹是确定的**，所以只要轨迹进入一个已经出现过的状态，后面就会无限重复。这说明"永不相遇"的判定本质上是"轨迹成环"，与目标个数无关。

### 2.3 归约：把"整局"压成一个有限状态

两个单位同时运动，所以整局的状态是

$$S_t=(\underbrace{r_J,c_J,d_J}_{\text{John 的状态}},\ \underbrace{r_C,c_C,d_C}_{\text{牛的状态}}).$$

**引理 2（整局是确定性有限自动机，状态数 $\le160000$）**

给定 $S_t$，$S_{t+1}$ 唯一确定；且 $S_t$ 的取值范围至多 $100\cdot4\cdot100\cdot4=160000$ 种。

**证明**：$S_{t+1}$ 由对两个分量各自施加 $step$ 得到（引理 1 保证 $step$ 确定），故 $S_{t+1}$ 由 $S_t$ 唯一确定。取值范围：每个单位的位置 $10\times10=100$ 种、朝向 $4$ 种，独立组合得 $400\times400=160000$。$\blacksquare$

**引理 3（状态重现 $\Rightarrow$ 永不相遇）**

若存在 $t_1<t_2$ 使 $S_{t_1}=S_{t_2}$，且在第 $t_1..t_2-1$ 分钟的每一个分钟末都没有相遇，则之后**永远**不会相遇。

**证明**：由引理 2 的确定性，从同一状态 $S_{t_1}=S_{t_2}$ 出发，其后的状态序列逐项完全相同（对 $t\ge0$ 有 $S_{t_2+t}=S_{t_1+t}$）。也就是说第 $t_2$ 分钟之后的演化是第 $t_1$ 分钟之后演化的**逐字复制**。既然第 $t_1..t_2-1$ 分钟段内没有相遇，复制出来的后续段同样没有相遇；由周期重复，之后所有时刻都不会相遇。$\blacksquare$

> 结合抽屉原理：状态只有 $160000$ 种，若一直不相遇，那么在 $t\le160000$ 之内必有一次状态重现（第 $160001$ 个状态必然与前面某个相同）。因此模拟最多 $160000$ 分钟就一定能给出结论——这是"终止性"的保证。

### 2.4 经典技术：状态去重 + 逐分钟模拟

用一个大小 $160000$ 的布尔数组 `vis[state]`，每分钟开头检查当前状态是否出现过：出现过 $\Rightarrow$ 依引理 3 输出 $0$ 并结束；否则标记，然后让两者各 `step` 一次、时间 $+1$，再比较坐标。

### 2.5 相遇判定：为什么"穿过"不算

**引理 4（判定条件恰为"分钟末同格"）**

按上述流程，当且仅当两个单位在某分钟末位于同一格时，输出才被置为该分钟数。

**证明**：代码在每个分钟末执行一次 `if(jr==cr&&jc==cc)`。若它们交换位置（John 从 $A$ 到 $B$、牛从 $B$ 到 $A$），则分钟后 John 在 $B$、牛在 $A$，坐标不等，条件为假——符合题面"穿过不算相遇"。若它们进入同一格（无论此前在哪），坐标相等，条件为真——符合"某分钟末在某格子相遇"。故判定与题面一致。$\blacksquare$

### 2.6 状态编码与终止

把状态编码成一个整数即可索引数组：`state = ((jr*10+jc)*4+jd)*400 + (cr*10+cc)*4+cd`，取值范围 $[0,160000)$。

- 时间上界：循环至多执行 $160000$ 次（之后必重现）$\Rightarrow$ 一定终止。
- 数组 `vis[160005]` 一次性够用；全局 `bool` 默认 `false`。

## 3. 模式总结（Pattern Summary）

**模式名：确定性多智能体模拟的「状态去重 + 逐分钟推进」。**

**识别信号**：两个（或多个）单位在固定网格上按确定性规则同时运动；问首次相遇时间或"永不"。

**可复用套路（按实际思考顺序）**：

- **explore its property** — 每个单位都是"前方可走则前进、否则右转"的确定性自动机（引理 1）。
- **consider easier version** — 先只追一个自动机，发现"永不"判定 = 轨迹成环。
- **reduce to easier problem** — 把整局压成"二者状态的有序对"，得到 $\le160000$ 个全局状态（引理 2）。
- **classic problem solution** — 用 `vis` 数组做状态去重，逐分钟模拟（引理 3 保证截断正确）。
- **detect cycle by pigeonhole** — 状态有限且确定 $\Rightarrow$ 模拟不超过状态总数即可判"永不"。
- **careful simultaneity** — 先算双方新状态再比较，"穿身而过"因末态不同而不触发（引理 4）。

**一句话记忆**：把两个确定性移动者拼成一个有限状态机，用去重模拟到相遇或成环。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| `g[mxn][mxn]` | `char[12][12]` | 地图（`.` 空、`*` 障碍、`C` 牛、`F` John） | 读入 | 题面 |
| `dr[4],dc[4]` | `int[4]` | 四朝向位移，下标 $0$北大、$1$东、$2$南、$3$西 | 常量 | 朝向表 |
| `jr,jc,jd` | `int` | John 的行、列、朝向 | 读入 `F` 位置，`jd=0` | — |
| `cr,cc,cd` | `int` | 牛的行、列、朝向 | 读入 `C` 位置，`cd=0` | — |
| `vis[mxst]` | `bool[160005]` | 全局状态是否已访问 | 全 `false` | 状态去重（引理 3） |
| `t` | `int` | 已过去的分钟数 | $0$ | 答案 |

### 4.2 编号步骤

1. 读入 $10\times10$ 地图；记录 `F`、`C` 坐标；`jd=cd=0`（都朝北）。
2. 令 `t=0`，进入无限循环：
   2.1 编码当前状态 `st=((jr*10+jc)*4+jd)*400+(cr*10+cc)*4+cd`。
   2.2 若 `vis[st]` 为真 $\Rightarrow$ 输出 `0` 并结束（引理 3）。
   2.3 `vis[st]=true`；对 John 与牛各执行 `step`；`++t`。
   2.4 若 `jr==cr&&jc==cc` $\Rightarrow$ 输出 `t` 并结束（引理 4）。
3. `step` 内部：算目标格 $(nr,nc)$；越界或为 `*` 则 `d=(d+1)%4`，否则移动。

### 4.3 复杂度

- 时间：每次模拟 $O(1)$，最多 $160000$ 分钟，即 $O(160000)$。
- 空间：`char[12][12]` + `bool[160005]`，约 $160$ KB。
- 实测（§4.5）：随机地图中最坏（永不相遇）用例 0 分钟内退出，耗时 **$0.0061$ s**。

### 4.4 关键不变量（值得写 `assert` 的地方）

1. 任意时刻两单位都在地图内（`step` 保证不越界）。
2. `vis` 中被标记的状态对应一次"未相遇"的分钟末。
3. 循环必在 $\le160000$ 次内结束（引理 2 的抽屉原理）。
4. 相遇只由"分钟末坐标相等"判定（引理 4）。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 官方样例 | **通过**：题面地图 $\Rightarrow$ 输出 $49$（std 与暴力一致） |
| 随机对拍 | **通过**：$400$ 组随机地图（障碍密度 $\{0,0.1,0.2,0.35,0.5\}$，`F`/`C` 位置随机且不同），std（状态去重）与暴力（固定上限 $200000$、不做去重）输出逐字节一致 |
| 最坏规模计时 | 随机搜索到一个"永不相遇"的地图，std 输出 $0$，耗时 **$0.0061$ s** |
| 残余风险 | 暴力上限取 $200000>160000$ 是安全的（引理 2 的抽屉原理）；若数据地图超过 $10\times10$，需同时放大 `vis` 尺寸与暴力上限（按题面固定 $10\times10$，不会发生） |

## 5. 示例代码

### 5.1 主解：状态去重 + 逐分钟模拟
```cpp
// 题目：P1518 [USACO2.4] 两只塔姆沃斯牛 The Tamworth Two
// https://www.luogu.com.cn/problem/P1518
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{12};
constexpr int mxst{160005};               // (100 格 * 4 向)^2 = 160000 (+5 松弛)

const int dr[4]={-1,0,1,0},dc[4]={0,1,0,-1};   // 0北 1东 2南 3西

char g[mxn][mxn];
bool vis[mxst];                           // 全局默认 false

void step(int&r,int&c,int&d)              // 前进一分钟(原地改写 r,c,d)
{
	int nr=r+dr[d],nc=c+dc[d];
	if(nr<0||nr>=10||nc<0||nc>=10||g[nr][nc]=='*')
		d=(d+1)%4;                        // 前方受阻(边界也算障碍):原地右转
	else
		r=nr,c=nc;                        // 否则前进一步
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int jr=0,jc=0,cr=0,cc=0;
	for(int i=0;i<10;++i)
		for(int j=0;j<10;++j)
		{
			cin>>g[i][j];
			if(g[i][j]=='F')
				jr=i,jc=j;
			if(g[i][j]=='C')
				cr=i,cc=j;
		}
	int jd=0,cd=0;                        // 两者最初都朝北
	int t=0;
	for(;;)
	{
		int st=(jr*10+jc)*4+jd;           // John 位置(100)+方向(4)
		st=st*400+(cr*10+cc)*4+cd;        // 拼上牛的状态 => 160000 种
		if(vis[st])                       // 状态重现 => 进入循环,永不相遇
		{
			cout<<0<<'\n';
			return 0;
		}
		vis[st]=true;
		step(jr,jc,jd);
		step(cr,cc,cd);
		++t;
		if(jr==cr&&jc==cc)                // 分钟末同格 => 抓住
		{
			cout<<t<<'\n';
			return 0;
		}
	}
}
```

### 5.2 对照实现：固定上限模拟（仅用于对拍）
```cpp
// P1518 暴力基准：不做状态判重, 直接模拟足够多的分钟数
#include<bits/stdc++.h>
using namespace std;

const int dr[4]={-1,0,1,0},dc[4]={0,1,0,-1};
char g[12][12];

void step(int&r,int&c,int&d)
{
	int nr=r+dr[d],nc=c+dc[d];
	if(nr<0||nr>=10||nc<0||nc>=10||g[nr][nc]=='*')
		d=(d+1)%4;
	else
		r=nr,c=nc;
}

int main()
{
	int jr=0,jc=0,cr=0,cc=0;
	for(int i=0;i<10;++i)
		for(int j=0;j<10;++j)
		{
			cin>>g[i][j];
			if(g[i][j]=='F')
				jr=i,jc=j;
			if(g[i][j]=='C')
				cr=i,cc=j;
		}
	int jd=0,cd=0,t=0;
	while(t<200000)                       // 状态数上限 160000, 足够
	{
		step(jr,jc,jd);
		step(cr,cc,cd);
		++t;
		if(jr==cr&&jc==cc)
		{
			cout<<t<<'\n';
			return 0;
		}
	}
	cout<<0<<'\n';
	return 0;
}
```

两版输出必须逐字节相同（已用 $400$ 组随机数据 + 官方样例确认）。暴力版**不用状态去重**，而是靠一个足够大的时间上限兜底，是引理 3"状态重现即永不"的独立交叉验证。

### 5.3 易错点清单

- **先动一个再判断** $\Rightarrow$ 破坏"同时移动"，可能把"穿身而过"误判成相遇。
- **边界未当作障碍** $\Rightarrow$ 会让单位走出地图，坐标越界。
- **顺时针方向搞反**（写成 `(d+3)%4`）$\Rightarrow$ 轨迹完全错误。注意朝向表按北→东→南→西递增即为顺时针。
- **不做状态去重** $\Rightarrow$ 永不相遇时会死循环（暴力版用时间上限规避，提交版必须用 `vis`）。
- **相遇判定放在分钟初**（移动前）$\Rightarrow$ 差一分钟，样例就给不出 $49$。
