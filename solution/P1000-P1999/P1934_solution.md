# P1934 封印

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 层封印排成一列，第 $i$ 层的坚固值为 $a_i$。有两种破除方式：

1. **单独**打破第 $i$ 层：消耗 $a_i\cdot n^2$。
2. 选 $i<j$，一次打破第 $i$ 到第 $j$ 层的**所有**封印：消耗
   $$
   (a_i+a_j)\cdot(a_i+a_{i+1}+\cdots+a_j),
   $$
   但必须满足 $a_i+a_j\le t$。

求把所有 $n$ 层都破除的最小总消耗。

### 1.2 关键约束与规模暗示

- $n\le1000$，$a_i,t\le20000$。
- 单独的代价里带着 $n^2$（最大 $10^6$），所以“单独破”通常很贵，多层的组合方式才是主角。
- $n\le1000$ 允许 $O(n^2)$ 的区间 DP；若 $n$ 到 $10^5$ 就需要优化，但这里不需要。
- 所有代价都是正数且最大约 $8\times10^{14}$，必须开 `long long`。

## 2. 思维链（Chain-of-thought）

### 2.1 先想清楚：操作之间是什么关系？

这是本题最容易含糊的一步。题意是“打破第 $i$ 层到第 $j$ 层之间的**所有封印**”。一次操作会把这段连续的封印全部打掉。打掉之后，原来的封印串被切成了左边一段和右边一段，中间出现了一个“空洞”。

**引理 1（操作区间构成一个划分）**

在任何一个合法方案中，所有操作所覆盖的层集合两两不交，并且并起来恰好是 $\{1,\dots,n\}$。因此方案等价于把 $[1,n]$ 划分成若干连续段，每段用一次操作（单层操作也是一种段）。

**证明**：

- 每个操作覆盖的是一段连续区间。
- 假设有两个操作区间 $I,J$ 有交集。由于操作只能对“尚未被打破的封印”进行（已经破掉的层不再是封印，操作区间也不可能跨过一个空洞去包含它），第二个操作执行时，$I\cap J$ 中的层已经被第一个操作打掉，不可能是“封印”，矛盾。
- 所以区间两两不交。又因为最终所有层都要被打破，这些不交的区间之并必须覆盖 $[1,n]$。有限个两两不交、并覆盖整条线的区间，就是 $[1,n]$ 的一个划分。$\blacksquare$

> 这一步不能想当然。如果允许“跨过已破层再破一次”，答案会不同：例如 $n=3,t=12,a=(6,1,1)$，划分方案最小是 $[1,3]$ 的 $7\times8=56$，而“$[1,2]$ 再 $[2,3]$”只需 $7\times7+2\times2=53$。题面说的是“打破所有封印”，已被打破的层无法再被“打破”，所以重叠方案不合法，划分模型才是对的。

### 2.2 划分之后：线性 DP

既然是一个划分，就按“最后一段”来划分子问题。

设 $f_i$ 表示把前 $i$ 层全部破除的最小消耗，$S_i=\sum_{k=1}^{i}a_k$（前缀和）。

最后一段是 $[j,i]$：

- 若 $j=i$，这一段单独打破，代价 $a_i n^2$，前驱是 $f_{i-1}$。
- 若 $j<i$，需要 $a_j+a_i\le t$，代价 $(a_j+a_i)(S_i-S_{j-1})$，前驱是 $f_{j-1}$。

于是
$$
f_i=\min\Bigl(f_{i-1}+a_i n^2,\ \min_{\substack{1\le j<i\\ a_j+a_i\le t}}\bigl(f_{j-1}+(a_j+a_i)(S_i-S_{j-1})\bigr)\Bigr).
$$

**引理 2（转移的完备性与最优性）**

上面的递推给出的是最小总消耗。

**证明**：对 $i$ 归纳。

- 任意一个把前 $i$ 层划分的方案，看它的最后一段 $[j,i]$。如果 $j=i$，剩下的是前 $i-1$ 层的方案，代价至少 $f_{i-1}$，总代价至少 $f_{i-1}+a_i n^2$；如果 $j<i$，由引理 1 的合法性它必须满足 $a_j+a_i\le t$，剩下的前 $j-1$ 层方案代价至少 $f_{j-1}$，总代价至少括号中的那一项。故 $f_i$ 是下界。
- 反过来，对每个转移取到最优的前驱方案，再接上最后一段，就得到一个合法方案，其代价恰好等于转移值。故下界可取到。

归纳成立。$\blacksquare$

### 2.3 边界与溢出

- $n=1$：没有 $i<j$ 的越行术，只能单独破，答案 $a_1\cdot1^2=a_1$。
- 单段代价最大 $(20000+20000)\times(20000\times1000)=8\times10^{11}$；最多 $1000$ 段，总上界 $8\times10^{14}$，`long long` 足够。
- 前缀和也只需 `long long`（最大 $2\times10^7$，其实 `int` 也够，但统一用 `long long` 更省心）。

### 2.4 复杂度

- 枚举 $i$ 与 $j$，$O(n^2)$，$n\le1000$ 时约 $5\times10^5$ 次转移。
- 空间 $O(n)$。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 已破的层会形成空洞，后续操作不能跨过，因此操作区间是 $[1,n]$ 的一个划分。
- **consider easier version** — 若能自由重叠，问题会变成区间覆盖，答案可能不同；划分模型把问题压成序列分段。
- **classic problem solution** — 前缀和 + “以最后一段为决策”的线性划分 DP，$O(n^2)$。
- **pitfall** — 单层打破不受 $a_i+a_j\le t$ 的限制；代价要开 `long long`。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n,t` | `int` / `i64` | 层数、端点和的限制 | 读入 | — |
| `a[i]` | `i64[1005]` | 第 $i+1$ 层坚固值（0-based） | 读入 | hardness |
| `pre[i]` | `i64[1005]` | $a_0+\cdots+a_{i-1}$ | `pre[0]=0` | prefix |
| `dp[i]` | `i64[1005]` | 破除前 $i$ 层的最小消耗 | `dp[0]=0` | DP |

### 4.2 算法步骤

1. 读入 $n,t$ 与 $a_0,\dots,a_{n-1}$，计算前缀和 `pre[i+1]=pre[i]+a[i]`。
2. 对 $i=1\dots n$：
   1. 先令 `dp[i]=dp[i-1]+a[i-1]*n*n`（最后一段只有第 $i$ 层）。
   2. 枚举 $j=0\dots i-2$：若 `a[j]+a[i-1]<=t`，用
      `dp[j]+(a[j]+a[i-1])*(pre[i]-pre[j])`
      更新 `dp[i]`。
3. 输出 `dp[n]`。

### 4.3 复杂度分析

- 时间 $O(n^2)$，$n\le1000$ 时约 $5\times10^5$ 次转移。
- 空间 $O(n)$。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};

int n;
i64 t;
i64 a[mxn],pre[mxn],dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>t;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		pre[i+1]=pre[i]+a[i];
	}

	for(int i=1;i<=n;++i)
	{
		dp[i]=dp[i-1]+a[i-1]*(i64)n*n;
		for(int j=0;j<i-1;++j)
			if(a[j]+a[i-1]<=t)
				dp[i]=min(dp[i],dp[j]+(a[j]+a[i-1])*(pre[i]-pre[j]));
	}
	cout<<dp[n]<<'\n';
	return 0;
}
```
