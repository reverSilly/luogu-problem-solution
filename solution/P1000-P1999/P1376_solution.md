# P1376 [USACO05MAR] Yogurt factory 机器工厂

> 标签：贪心 · 难度：普及-

## 1. 重新读题

**问题重述（大白话）**

小 T 的工厂连续开工 $N$ 周。第 $i$ 周**现造**一台机器要 $C_i$ 元；造好没卖掉的机器进仓库，**每存放一整周**交 $S$ 元保养费（$S$ 是常数，与周次、台数单价无关）。第 $i$ 周必须交付 $Y_i$ 台，货源可以是"本周刚造的"或"仓库里更早造的"。求 $N$ 周做完全部订单的**最小总代价**。

**需要钉死的口径（逐条查过题面）**

| 量 | 范围 / 口径 |
|---|---|
| $N$ | $1\le N\le 10^4$ |
| $C_i$ | $1\le C_i\le 5000$ |
| $S$ | $1\le S\le 100$，全周统一、不随行情变 |
| $Y_i$ | $0\le Y_i\le 10^4$，**可以为 0**（该周不交货，但存货照样一周周计保养费） |
| 库存容量 | **题面没有给任何上限**——仓库想堆多少堆多少 |
| 单周产量 | **同样没有上限**——第 $j$ 周想造多少台造多少台 |
| 固定开工费 | **没有**：造 1 台和造 1 万台只有台数差，没有"开一次工"的额外费用 |
| 时间方向 | 第 $j$ 周只能为第 $i\ge j$ 周备货；**未来的低价周补不了过去已经欠的货** |
| 文件 I/O | 题面**未要求** `freopen`，标准输入输出即可 |
| 输出 | 单个整数，不取模 ⇒ 必须先估上界（见 2.7） |

**复杂度暗示**：tag 只有"贪心"，$N\le 10^4$ 非常宽松（$O(N^2)$ 的每周回扫约 $5\times10^7$ 次运算，勉强跑得动），说明考点不在数据结构，而在**建模口径 + 溢出**两件事。真正需要小心的是"保养费如何累加"和"答案会不会爆 `int`"。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制 —— "保养费"到底数几周

第 $j$ 周造、第 $i$ 周交（$j\le i$）的一台机器，在仓库里度过的周是 $j,\,j+1,\dots,i-1$ 这 $i-j$ 段，所以它的总成本是

$$f(j,i)=C_j+S\cdot(i-j),\qquad f(j,j)=C_j\ (\text{现造现交，零保养}).$$

这个式子是全题地基，后面每一步都从它出发。两个易错点先记下：① 中间遇到 $Y=0$ 的周**不中断**计费，费用只看 $i-j$；② $S$ 是**每周**收一次，不是"入仓一次性"，所以跨度越长越贵，这决定了"存货"不能无限延伸。

### 2.2 化简 —— 把每台机器拆开决策（本题最关键一步）

设 $x_{j,i}\ge 0$ 为"第 $j$ 周造、第 $i$ 周交"的台数（$j\le i$）。总代价与约束写成

$$\min \sum_{j\le i}x_{j,i}\,f(j,i)\quad\text{s.t.}\quad \sum_{j\le i}x_{j,i}=Y_i\ \ (\forall i).$$

关键：**除了"第 $i$ 周凑够 $Y_i$ 台"，各周之间没有任何耦合约束**（无容量上限、无产能上限、无开工费），可行域是 $N$ 个互相独立的单纯形之积，可以逐周取最优。

**引理 A（单位独立；下界可达）** 最优总代价 $=\sum_{i=1}^{N}Y_i\,g_i$，其中 $g_i=\min_{1\le j\le i}f(j,i)$。

**证明**：
- *下界*：第 $i$ 周的任意一台货来自某个 $j\le i$，成本 $\ge g_i$；$Y_i$ 台合计 $\ge Y_ig_i$。对 $i$ 求和，任何方案代价 $\ge\sum_i Y_ig_i$。
- *可达*：对每个 $i$ 独立取 $j_i=\arg\min_{j\le i}f(j,i)$，令 $x_{j_i,i}=Y_i$、其余 $x_{\cdot,i}=0$。此方案每行 $x$ 只服务一个 $i$，不占用任何"共享资源"（第 $j$ 周的产量可任意大、仓库可无限堆），故 $\sum_{j}x_{j,i}=Y_i$ 自动成立、方案合法；代价恰为 $\sum_i Y_ig_i$。
- 上下界重合，$\blacksquare$

（这一步把"批量决策"彻底降级成"逐周查一个最小值"，也解释了为什么题面没给库存容量：一旦有上限，可达性论证立刻失效——见 2.6。）

先把"看起来必须成批"的直觉打掉。反例式思考：如果第 2 周和第 3 周都从第 1 周拿货，就要在第 1 周多造一台、多存一周；如果只有第 3 周从第 1 周拿货，成本并不受第 2 周选择的影响——因为**仓库不会满、车间不会停**，两台货的存放费各自按自己的跨度算，互不打折也不互相占用。所以"这一批造几台"根本不是需要整体决定的量：造 $k$ 台的代价 $=kC_j$ 是**线性**的，线性成本下批量可以随意拆分与合并。这就是上面引理 A 能把问题降维的全部依据。

### 2.3 递推 —— $g_i$ 的滚动最小值

$g_i$ 朴素算法是每周回扫全部历史周（$O(N^2)$）。展开 $g_i$ 与 $g_{i-1}$：

$$g_i=\min\Big(C_i,\ \min_{j\le i-1}\big(C_j+S(i-j)\big)\Big)=\min\Big(C_i,\ \min_{j\le i-1}\big(C_j+S(i-1-j)\big)+S\Big)=\min\big(C_i,\ g_{i-1}+S\big).$$

**引理 B** $g_1=C_1$，$g_i=\min(C_i,\,g_{i-1}+S)\ (i\ge2)$。

**证明**：把 $\min_{j\le i}$ 按 $j=i$ 与 $j\le i-1$ 分成两块。$j=i$ 那块 $f(i,i)=C_i$。$j\le i-1$ 那块里 $f(j,i)=C_j+S(i-j)=\big(C_j+S(i-1-j)\big)+S=f(j,i-1)+S$，括号对 $j$ 取最小即 $g_{i-1}$，加常数 $S$ 可与 $\min$ 交换，故等于 $g_{i-1}+S$。两块取小即递推式。$i=1$ 时第二块为空集，$g_1=C_1$。$\blacksquare$

含义一句话：**"再多存一周的存货价" 与 "本周现造价" 二者取小**，扫一遍即可，$O(N)$ 时间、$O(1)$ 额外状态。

拿 4.3 的第 4 号例 $S=7,\ C=[100,1,50],\ Y=[5,0,5]$ 走一遍状态（下表 1-based 周序，代码里是 0-based，仅差一个下标偏移）：

| 周 $i$ | $C_i$ | $g_{i-1}+S$ | $g_i=\min$ | 本周结算 $g_iY_i$ | $\text{ans}$ |
|---|---|---|---|---|---|
| 1 | 100 | —（无前序周，$g_0$ 视为哨兵） | 100 | 500 | 500 |
| 2 | 1 | $107$ | 1 | 0 | 500 |
| 3 | 50 | $8$ | 8 | 40 | **540** |

第 3 行的 $g_2+S=8<50$ 说明"第 2 周造的货存到第 3 周"比第 3 周现产便宜 42 元/台，链条不断；第 2 行 $g_1+S=107>C_2=1$ 说明第 2 周必须换批（当场造），旧货链断开。

### 2.4 贪心卡壳与打通 —— 三个错直觉（各配反例）

- **错法 1（只看上周原价）**：用 $g_i'=\min(C_i,C_{i-1}+S)$。反例 $S=5,\ C=[10,100,100],\ Y=[0,0,1]$：正解 $g_3=10+5\cdot2=20$（第 1 周造两台成本链），错法给 $\min(100,105)=100$。**病因**：$C_{i-1}$ 自己可能已经是"存货价"，必须传播**有效价** $g$ 而非原价 $C$。
- **错法 2（找到历史最便宜就一路存货）**：反例 $S=5,\ C=[10,12],\ Y=[1,1]$：一路存货 $10+15=25$，本周现造 $10+12=22$。**边界不等式**：只有 $C_j+S(i-j)<C_i$ 才值得存，差价被每周 $S$ 的累积吃光时立刻断开——这正是引理 B 里 $\min$ 取到 $C_i$ 的那支。
- **错法 3（等未来的便宜周）**：反例 $S=5,\ C=[100,1],\ Y=[1,1]$：第 1 周的货只能第 1 周造，答案 $101$，不是 $1+1=2$。方向性约束 $j\le i$ 不可逆。

### 2.5 批量视角 —— "每批生产向前覆盖一段需求"

引理 A 的逐台最优可以翻译成"批量"语言，这也是题解里最常见的贪心表述，必须证明它和引理 A 等价。

**定义**：称第 $a$ 周是**换批周**，若 $a=1$ 或 $C_a<g_{a-1}+S$。相邻两个换批周之间（含左不含右）的区间称为一个**批块** $[a,b]$。

**引理 C（批块结构）** 设 $[a,b]$ 为一个批块，则 (1) $\forall t\in[a,b]:\ g_t=C_a+S(t-a)$；(2) 存在最优方案：第 $a$ 周一次造 $\sum_{t=a}^{b}Y_t$ 台，第 $t$ 周交 $Y_t$ 台、其余继续存到下周；(3) 第 $a$ 周不能服务 $t<a$ 的周。

**证明**：
- (1) 归纳。$t=a$：换批周定义给 $g_a=C_a$。设 $t\in[a,b)$ 有 $g_t=C_a+S(t-a)$；$t+1\le b$ 说明 $t+1$ 不是换批周，即 $C_{t+1}\ge g_t+S$，由引理 B $g_{t+1}=\min(C_{t+1},g_t+S)=g_t+S=C_a+S(t+1-a)$。$\blacksquare$
- (2) 由引理 A，第 $t$ 周的 $Y_t$ 台每台至少要花 $g_t$；而 (1) 说明在第 $a$ 周造它恰好只要 $f(a,t)=C_a+S(t-a)=g_t$，取到下界。方案把 $[a,b]$ 的全部需求压在源头周 $a$ 造，产量与存货量都无上限（第 1 节口径表），故可行；代价 $=\sum_{t=a}^{b}Y_ig_i$，与引理 A 的下界相同，因而整体最优。$\blacksquare$
- (3) 交付只能由**不晚于自己**的周供货（$j\le t$），故源头 $a$ 覆盖不到 $t<a$ 的需求：批块不可能"跳选"更早或更晚的周，只能是一段以 $a$ 为左端的连续区间；$b$ 之后一旦出现 $C<b$ 链价的周，(1) 的归纳前提失效，块自然结束。$\blacksquare$

**引理 D（交换论证：不依赖引理 A，直接证明"批贪心"最优）** 考虑贪心方案 $G$："顺序扫周，遇到 $C_i<g_{i-1}+S$ 就开新批（本批从 $i$ 周起供），否则把上一批的链延到 $i$ 周"。任取一个"把需求切成若干连续段、每段在段首一次性造完"的方案 $A$，则 $\mathrm{cost}(A)\ge\mathrm{cost}(G)$。

**证明**：记 $h_j(t)=C_j+S(t-j)$（"$j$ 周造、$t$ 周交"的单价），$A$ 与 $G$ 的段起点序列分别记为 $\{a_k\}$ 与 $\{b_k\}$，两者首个起点都是 $1$（第 1 周之前无法备货）。取**最后一个**使得 $a_k=b_k$ 的 $k$，考察该共同段起点 $a$ 之后的第一处分歧：

- **情形 1：$A$ 比 $G$ 晚断段**（$A$ 这一批覆盖到了 $b_{k+1}$ 及以后）。$G$ 在 $b_{k+1}$ 开新批，条件就是
$$C_{b_{k+1}}<g_{b_{k+1}-1}+S=\big(C_a+S(b_{k+1}-1-a)\big)+S=h_a(b_{k+1}),$$
（最后一个等号用引理 C(1)：$G$ 的本批链价等于 $h_a(\cdot)$）。两端同加 $S(t-b_{k+1})$ 得 $\forall t\ge b_{k+1}:\ h_{b_{k+1}}(t)<h_a(t)$。于是把 $A$ 中"$a$ 这批供 $t\ge b_{k+1}$ 的周"的台数全部改由 $b_{k+1}$ 周自产，每台严格降价，方案仍合法（段依旧连续、起点单调），$\mathrm{cost}$ 下降。
- **情形 2：$A$ 比 $G$ 早断段**（$A$ 在某个 $a'<b_{k+1}$ 处自开了一批）。$G$ 没在此断段，即 $C_{a'}\ge g_{a'-1}+S=h_a(a')$。同加 $S(t-a')$ 得 $\forall t\ge a':\ h_a(t)\le h_{a'}(t)$。把 $A$ 中第 $a'$ 批所覆盖各周的货**并回** $a$ 这批（$a$ 批的跨度延长到那些 $t$），每台成本不增，代价 $\mathrm{cost}$ 不升，而 $A$ 与 $G$ 的公共前缀段数 $+1$。

两类替换都保持"$j\le t$"与"分段连续"这两个合法性条件，且只用"产量/库存无上限"来保证 $a$ 批能多背若干台、能多存若干周（这正是题面口径，也是交换能被执行的全部理由）。终止性：取二元势 $(\text{公共前缀段数},\ \text{A 在 }b_{k+1}\text{ 之前的多余起点数})$ 按字典序比较——情形 1 让第一项 $+1$；情形 2 让第二项 $-1$（并回一次就消掉一个多余起点，消到 $A$ 的下一个起点正好是 $b_{k+1}$ 时又回到情形 1，第一项 $+1$）。两项分别 $\le N$ 且只增不减，故有限步内 $A$ 被改造成 $G$，而每一步代价都**不增**，即 $\mathrm{cost}(G)\le\mathrm{cost}(A)$。$\blacksquare$

（情形 1、2 的判据是同一个**不等式**：存货延一周，只有当差价 $C_t-\big(C_j+S(t-1-j)\big)$ 为正时才断批；差价被累积保养费 $S$ 吃平（$=0$）或反超（$<0$）时分别对应 tie 与必须断批。写代码时统一用 `min` 即自动覆盖三种情况。）

**并列情形（tie）**：若某周 $C_t=g_{t-1}+S$，两支相等，"存货"与"现造"两方案代价**完全相同**（例 $S=3,\ C=[5,8],\ Y=[4,6]$：存货口径 $5\cdot10+3\cdot6=68$，现造口径 $20+48=68$）。代码里 `min(g+s,(i64)c[i])` 在并列时保留存货链（`std::min` 仅在第二参更小时才取第二参），批块边界与手推约定必须一致，否则会误判成"两个不同方案"——数值上永远只差结构、不差代价。

**边界情形清单**（都是上面证明里用到的条件，缺一个贪心就得重做）：

1. **库存容量上限**：题面**未给**，故引理 A 的"可达"与引理 D 的"并回 $a$ 批"都成立。若加上限 $K$，$A$ 的可行域不再按周分裂（同一段批的存量要受 $K$ 卡），$G$ 甚至可能直接不可行。例如 $N=3,S=1,C=[1,4,4],Y=[0,4,4]$：无上限时 $g=[1,2,3]$、$\mathrm{cost}=20$，其方案要求第 1 周造 8 台、周末库存 $8$；一旦 $K=4$ 该方案非法，只能把后段改回 $C=4$ 的现产（如可行方案 $4\cdot1+4\cdot1_{\text{存}}+4\cdot4+4\cdot1_{\text{存}}=28$），最优值变大且需按带容量运输/费用流重算——本题不涉及，但必须确认题面真的没这条。
2. **$S=0$ 退化**（题面 $S\ge1$，仅作校验）：$g_i=\min(g_{i-1},C_i)$ 退化为前缀最小值，"第 1 周的货存到第 $N$ 周不花钱"，与直觉一致。
3. **$Y_i=0$ 的周**：不进入 $\mathrm{cost}$ 的求和（$g_iY_i=0$），但**进入链条**——库存照旧每周交保养费，链条不断（2.1 易错点①，4.3 第 3/4 号例）。
4. **批块右端**：最后一个批块延伸到第 $N$ 周后没有需求要交，多余的存货对代价无贡献，故不存在"要不要留期末库存"的歧义。


### 2.6 DP 视角与"容量上限"会怎样

若把批块强行写成 DP：$dp_i=\min_{j\le i}\big(dp_{j-1}+(C_j+S(i-j))\cdot(P_i-P_{j-1})\big)$，其中 $P$ 是 $Y$ 的前缀和、$dp_0=0$，复杂度 $O(N^2)$（$N=10^4$ 时约 $5\times10^7$ 次转移）——本题跑得动，但明显不如 $O(N)$。更重要的是：**DP 的最优值就等于引理 A 的 $\sum Y_ig_i$**，因为逐台取 $g_i$ 的分配本来就是合法方案（引理 A 的可达性），DP 拿不到更低值；而且 DP 的转移里 $(C_j+S(i-j))(P_i-P_{j-1})$ 可达 $10^6\times10^8$ 量级，中间值必须 `i64`（见 2.7）。所以下一步不该写 DP，而该问"DP 什么时候才必要"：

- **加固定开工费**（Wagner–Whitin 型）：每台独立决策不再成立，必须"成批"，$O(N)$ 贪心失效，此时 DP 是唯一正确做法。
- **加库存容量上限 $K$**：$\sum_{t>j}x_{j,t}$ 型约束会跨周耦合，引理 A 的"可达"一步失效，批块必须被 $K$ 截断，问题退化为带容量的运输/费用流。
- 本题两者都**没有**（第 1 节口径表），这就是它只挂"贪心"标签、难度"普及-"的全部原因。

### 2.7 溢出预算（决定 `int` / `i64`）

- 总台数 $\sum_{i=1}^{N}Y_i\le 10^4\times10^4=10^8$。
- 有效单价 $g_i\le C_i\le 5000$（引理 B 里 $g_i$ 永远 $\le C_i$），故答案上界 $\le 5000\times10^8=5\times10^8$，**数学上压得住 `int`**（$2^{31}-1\approx2.1\times10^9$，裕量仅 $4.3$ 倍）。
- 但两种合法写法会爆：① 回扫式 $C_j+S(i-j)$ 的单项上界是 $5000+100\times9999=1{,}004{,}900$，乘 $Y_i=10^4$ 得 $1.0\times10^{10}$，**一周的量就超 `int`**；② DP/前缀和版 $dp$ 值可达 $10^8\times10^6=10^{14}$。
- 结论：累加器与单价一律 `i64`，`ans`、`g` 用 `i64`，输入数组仍用 `int`。零成本换绝对安全。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 把"保养费"翻译成 $f(j,i)=C_j+S(i-j)$，跨度 $i-j$ 计费、$Y=0$ 的周不断线。
- **reduce to easier problem** — 无容量、无产能、无开工费 ⇒ 可行域按周分裂，**每台机器独立选源头**（引理 A），批量问题降级为逐周查最小。
- **classic problem solution** — 滚动最小值：$\min$ 与加常数可交换 ⇒ $g_i=\min(C_i,g_{i-1}+S)$，一遍扫 $O(N)$（引理 B）。
- **greedy got stuck → dissect why** — 三个反例定位错误贪心：传播原价而非有效价 / 忽略累积保养费的不等式 / 违反 $j\le i$ 的方向性。
- **reconstruct by blocks** — 把逐台最优翻回"每批向前覆盖一段需求"，证明批块起点即换批周、块内单价线性上升（引理 C）。
- **prove by exchange argument** — 引理 D：对"分段方案"类做两类交换（晚断段→改由新批自产、早断段→并回原批），势函数=公共段数，有限步归一到贪心且代价单调不增；交换的合法性恰好消费"无库存上限"这条口径。
- **boundary enumeration** — 逐条钉死贪心依赖的条件：库存容量上限（题面无；一旦有则交换失效）、$S=0$ 退化、$Y_i=0$ 的周、期末库存，并把断批判据写成差价不等式与 tie 约定。
- **know when the shortcut dies** — 对照 DP/网络流：加开工费或库存上限后贪心失效，故本题结构恰好是"可分离"的最松版本。
- **budget the answer first** — 上界 $5\times10^8$ 勉强进 `int`，但中间量 $1.0\times10^{10}$ 必爆 ⇒ 累加器 `i64`。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n,s` | 周数 $N$、单位周保养费 $S$ | `int` | 题面 $1\le n\le10^4$，$1\le s\le100$ |
| `c[i]` | 第 $i$ 周现造单价 $C_i$，**0-based** | `int` 全局数组，默认 0 | 内部周序 $0..n-1$，全文一致（公式里的 $i-j$ 与 0/1-based 无关） |
| `y[i]` | 第 $i$ 周需求量 $Y_i$ | `int` 全局数组，可为 0 | $0\le y[i]\le10^4$ |
| `g` | **有效单价**：$\min_{j\le i}\big(C_j+S(i-j)\big)$ | `i64`，初值 `1e18` | 首周 `min(1e18+s, c[0])` 必落 `c[0]`，省掉特判；`1e18+100` 不溢出 |
| `ans` | 累计最小代价 $\sum g_iY_i$ | `i64`，初值 `0` | 上界 $5\times10^8$（2.7） |

数组尺寸 `mxn{10005}`（$10^4$ + 5 松弛）。`c`、`y` 无"INF 语义"，全局默认 0 即正确，不需 `fill_n`。

### 4.2 算法步骤

1. **读入** $n,s$，再读 $n$ 行 $C_i,Y_i$ 到 `c[]`、`y[]`（0-based）。
2. **一遍扫滚动单价**：`g=min(g+s,(i64)c[i])` —— 引理 B 的两支：存进来再放一周 vs 本周现产。取到第二支（$c[i]<g+s$）即"换批"，与引理 C 的定义、引理 D 的断批判据是同一件事。
3. **结算本周**：`ans+=g*y[i]` —— 引理 A 的逐周独立，本周 $y[i]$ 台全按 $g$ 计（台数无关，因为生产与仓储成本都是线性的）。
4. **输出** `ans`。
5. **复杂度**：时间 $O(N)$、空间 $O(N)$（存输入）；去掉数组边读边算可 $O(1)$ 额外空间。$N=10^4$ 时 $O(N^2)$ 回扫约 $5\times10^7$ 次乘加（$\sum_i i$）、DP 同阶，都能跑但慢于本解且更易溢出。
6. **溢出**：`ans`、`g` 为 `i64`（2.7）；答案真值上界 $5\times10^8$，中间量最大 $1.0\times10^{10}$（回扫式），故 `int` 只能守住答案守不住过程，一律走 `i64`。

## 5. 示例代码（C++）

```cpp
// P1376 [USACO05MAR] Yogurt factory 机器工厂
// 一遍扫：有效单价 g=min(上周 g+S, 本周 C_i)，每周需求按 g 结算
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};        // N<=1e4，+5 松弛

int n,s;
int c[mxn],y[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>s;
	for(int i=0;i<n;++i)
		cin>>c[i]>>y[i];

	i64 ans=0,g=1e18;            // 有效单价；1e18 保证第 0 周必取 c[0]，免特判
	for(int i=0;i<n;++i)
	{
		g=min(g+s,(i64)c[i]);    // 存货再放一周 vs 本周现产（引理 B）
		ans+=g*y[i];             // 单位独立（引理 A）：本周 y[i] 台全按 g 计
	}
	cout<<ans<<'\n';
	return 0;
}

// 暴力互验版（O(n^2) 回扫，注释保留，本环境未运行）：
// i64 calc2(){i64 r=0;for(int i=0;i<n;++i){i64 m=1e18;
//	for(int j=0;j<=i;++j)m=min(m,(i64)c[j]+(i64)s*(i-j));r+=m*y[i];}return r;}
```

### 代码说明

- **`g=min(g+s,(i64)c[i])`** 就是引理 B；`g+s` 中 `g` 是 `i64`，故整个式子是 `i64`，`min` 两支同型，不会退回 `int` 比较（写 `min(g+s,c[i])` 也靠 `g+s` 推导到 `i64`，但显式 `(i64)c[i]` 更保险）。
- **`ans+=g*y[i]`**：`g` 已是 `i64`，`y[i]` 自动提升；单项上界 $5100\times10^4\approx5.1\times10^7$ 与累加 $5\times10^8$ 都远离 `i64` 上限。
- **边读边算也合法**（本题无回溯需要），但按"全局静态数组 + `mxn{...}+5`"的写法约定先存 `c[]`、`y[]`，顺带让注释里的暴力版可直接对拍。
- **`c`/`y` 全局默认 0**：无"不可达=INF"语义，不存在漏 `fill_n` 的坑；`g` 的 `1e18` 是纯哨兵，只被用一次就被覆盖。
- 格式：`#include<bits/stdc++.h>`、`using namespace std;`、`cin.tie/cout.tie/ios::sync_with_stdio` 固定顺序、`'\n'` 不用 `endl`、运算符不加空格、Tab 缩进、内部 0-based。
