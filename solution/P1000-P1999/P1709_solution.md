# P1709 [SEERC 2003 / USACO5.5] 隐藏口令 Hidden Password

## 1. 重新读题

给定一个长度为 $N$（$1 \le N \le 5 \times 10^6$）的小写字母字符串 $S$（输入中每 $72$ 个字符可能包含换行符）。将 $S$ 首尾相接视为环状字符串，对于每个起点 $i \in \{0, 1, \dots, N-1\}$，顺时针读取 $N$ 个字符得到循环移位串
$$S_i = S[i \dots N-1] + S[0 \dots i-1].$$
要求在所有 $N$ 个循环移位串中找出**字典序最小**的那一个；若字典序最小的循环移位串有多个（即原串存在周期），输出其中**最小的起始下标 $i$**（0-based，对应题面“1-based 位置减 $1$”）。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质与朴素解法碰壁

最直接的想法是：用两个指针 $i, j$ 维护当前候选最优起点 $i$ 和挑战者起点 $j$，逐字符比较 $S_i$ 与 $S_j$ 的最长公共前缀长度 $k$（$0 \le k < N$）：
- 若 $S[(i+k)\bmod N] = S[(j+k)\bmod N]$，则 `++k` 继续比下一位；
- 若出现不同字符，假设 $S[(i+k)\bmod N] > S[(j+k)\bmod N]$，说明 $S_i$ 比 $S_j$ 大，$i$ 被淘汰。

**失败尝试：淘汰 $i$ 时只令 `++i`（或令 $i = j, j = j+1$），重新从 $k=0$ 开始比。**

- 反例：$S = \texttt{aaaa}\dots\texttt{aaab}$（前 $N-1$ 个全为 `a`，最后一个为 `b`）。每次比较都要走完 $O(N)$ 个 `a` 才发现末尾不同，随后只把指针挪动 $1$ 步，总比较次数退化为 $\Theta(N^2)$，在 $N = 5 \times 10^6$ 下必然超时。

### 2.2 关键跳跃性质：一次淘汰整段区间（附完整证明）

为什么在发现 $S[(i+k)\bmod N] > S[(j+k)\bmod N]$ 时，我们不仅能淘汰起点 $i$，还能把 $i, i+1, \dots, i+k$ 这 **$k+1$ 个起点一次性全部淘汰**？

**引理 1（循环串最小表示法的区间跳过引理）**：设对于两个起点 $i, j$ 及某个非负整数 $k < N$，满足：
1. 对一切 $0 \le t < k$，有 $S[(i+t)\bmod N] = S[(j+t)\bmod N]$（即 $S_i$ 与 $S_j$ 的前 $k$ 个字符完全相同）；
2. 在第 $k$ 位上有 $S[(i+k)\bmod N] > S[(j+k)\bmod N]$。

则对于任意偏移量 $d \in \{0, 1, \dots, k\}$，起点 $i+d$ 对应的循环串 $S_{(i+d)\bmod N}$ 的字典序**严格大于** $S_{(j+d)\bmod N}$，因此区间 $[i, i+k]$ 内的所有下标都不可能是严格最优（或最小下标最优）的起点。

**证明**：
任取 $d \in \{0, 1, \dots, k\}$，比较两个循环移位串 $S_{(i+d)\bmod N}$ 与 $S_{(j+d)\bmod N}$ 的前缀（长度为 $k - d + 1$）：
- 对任意位置 $0 \le r < k - d$，令 $t = d + r$，则 $0 \le t < k$。由条件 1，两串的第 $r$ 个字符分别为 $S[(i+t)\bmod N]$ 与 $S[(j+t)\bmod N]$，二者完全相等；
- 在第 $r = k - d$ 个字符处，两串的字符分别为 $S[(i+k)\bmod N]$ 与 $S[(j+k)\bmod N]$。由条件 2，前者严格大于后者。
因此，$S_{(i+d)\bmod N}$ 与 $S_{(j+d)\bmod N}$ 在第 $k-d$ 位首次出现差异，且 $S_{(i+d)\bmod N} > S_{(j+d)\bmod N}$。这证明了 $[i, i+k]$ 中的任何一个起点都被对应的 $j+d$ 严格击败，故可以直接将 $i$ 推进至 $i + k + 1$！对称地，若 $S[(i+k)\bmod N] < S[(j+k)\bmod N]$，则可将 $j$ 直接推进至 $j + k + 1$。$\blacksquare$

**引理 2（算法终止性与最小下标保证 + 线性复杂度）**：初始化 $i=0, j=1, k=0$，按上述规则维护 $i \ne j$（若跳转后 $i=j$ 则令 `++j`）。当 $i \ge N$ 或 $j \ge N$ 或 $k = N$ 时循环终止，此时 $\min(i, j)$ 即为所求的最小口令下标，且总时间复杂度为 $\Theta(N)$。

**证明**：
1. **正确性**：在循环的每一步中，凡是被跳过的所有下标 $< \max(i, j)$（除当前保留的 $\min(i, j)$ 外），均已由引理 1 证明存在另一个严格更优的循环串（或者因 $i=j$ 重复而合流）。
   - 若因 $i \ge N$ 或 $j \ge N$ 终止，则 $[0, N-1]$ 中除 $\min(i, j)$ 以外的所有起点均已被严格击败，故 $\min(i, j)$ 是唯一可能的最优起点。
   - 若因 $k = N$ 终止，说明 $S_i = S_j$（原串具有周期 $|i-j|$），且所有 $< \min(i, j)$ 的起点均已被严格击败，而 $\min(i, j)$ 是最早出现的达到最小字典序的起点，故返回 $\min(i, j)$ 满足“取最小下标”的要求。
2. **线性时间复杂度**：定义势函数 $\Phi = i + j + k$。
   - 当字符相等分支触发时，$k$ 增加 $1$，$i+j$ 不变；
   - 当字符不等分支触发时，$i$ 或 $j$ 至少增加 $k+1$，随后 $k$ 清零，故 $i + j$ 严格增加至少 $k+1 \ge 1$。
   由于 $i < N, j < N$ 时 $i+j \le 2N$，所有“字符不等”分支中累加的 $\sum (k+1) \le 2N$，而“字符相等”分支的总执行次数至多等于 $\sum k + N \le 3N$。因此整个 `while` 循环最多执行 $3N$ 步，时间复杂度严格为 $\Theta(N)$。$\blacksquare$

## 3. 模式总结（Pattern Summary）

- **explore its property** — 将“环状展开排序取首项位置减 $1$”转化为求循环字符串的最小表示法起点下标（0-based）。
- **failed attempt（逐位回退比较）** — 匹配失败后只令指针 $+1$ 会在全相同前缀（如 `aaaa...ab`）上退化到 $\Theta(N^2)$。
- **prove interval skipping** — 利用公共前缀长度 $k$ 证明 $[i, i+k]$ 内任意起点 $i+d$ 均被 $j+d$ 在第 $k-d$ 位严格击败（引理 1）。
- **classic problem solution** — 双指针最小表示法（$i=0, j=1, k=0$），以势函数 $i+j$ 单调递增保证 $\Theta(N)$ 时间复杂度（引理 2）。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 字符串长度 $N$ | 标准输入 | length |
| `s[idx]` | `char [mxn]` | 过滤掉空白/换行后的原始字符序列 | 逐字符 `cin >> ch` 读满 $n$ 个 | string |
| `i, j` | `int` | 最小表示法的两个候选起点下标 | `i = 0, j = 1` | two pointers |
| `k` | `int` | 当前 $S_i$ 与 $S_j$ 已匹配的公共前缀长度 | `0` | matched length |

### 4.2 算法步骤

1. 读入 $N$；循环使用 `cin >> ch`（自动跳过换行符与空格）读入恰好 $N$ 个字符存入 `s[0 .. N-1]`。
2. 初始化 `i = 0, j = 1, k = 0`。
3. 当 `i < n && j < n && k < n` 时循环：
   - 比较 `a = s[(i + k) % n]` 与 `b = s[(j + k) % n]`；
   - 若 `a == b`，令 `++k`；
   - 若 `a > b`，令 `i = i + k + 1`；若 `a < b`，令 `j = j + k + 1`；
   - 若更新后 `i == j`，令 `++j`；并将 `k` 重置为 `0`。
4. 输出 `min(i, j)`。

### 4.3 复杂度分析

- **时间复杂度**：由引理 2，指针 $i + j$ 单调递增且不超过 $2N$，总比较次数不超过 $3N$，时间复杂度为 $\Theta(N)$。
- **空间复杂度**：仅用一个长度为 $N$ 的字符数组 `s`，空间复杂度为 $\Theta(N)$（约 $5\text{ MB}$）。

## 5. 示例代码

```cpp
//
// 题目：P1709 [SEERC 2003 / USACO5.5] 隐藏口令 Hidden Password
// https://www.luogu.com.cn/problem/P1709
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{5000005};

int n;
char s[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	int idx=0;
	while(idx<n)
	{
		char ch;
		cin>>ch;
		s[idx++]=ch;
	}

	int i=0,j=1,k=0;
	while(i<n&&j<n&&k<n)
	{
		char a=s[(i+k)%n],b=s[(j+k)%n];
		if(a==b)
			++k;
		else
		{
			if(a>b)
				i=i+k+1;
			else
				j=j+k+1;
			if(i==j)
				++j;
			k=0;
		}
	}
	cout<<min(i,j)<<'\n';
	return 0;
}
```
