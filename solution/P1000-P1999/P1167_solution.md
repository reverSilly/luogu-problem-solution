# P1167 刷题

## 1. 重新读题

小 A 从"当前时间"到"竞赛时间"中间的一切时间都在刷题（24 小时不停）。他面前有 N 道题，第 `i` 道必须一次做完、不能中断，需要 `a[i]` 分钟（`N ≤ 5000`，`a[i] ≤ 10000`）。问：竞赛前他最多能做多少道题？

两个时刻以 `yyyy-mm-dd-hh:MM` 的格式给出（24 小时制，年份 `0000`~`9999`，考虑闰年）。

输出一个整数：最多能做的题目数。

拆开看，这题就两块：

1. 算清楚两时刻之间总共有多少分钟可用（难点：闰年）；
2. 用这个分钟数去"装"题目，使数量最多（经典贪心）。

---

## 2. 心路历程

### 第一步：一旦有了总分钟数，就是纯贪心

设可用总分钟数为 `T`。问题变成：

> 每个物品耗时 `a[i]`，总容量是 `T`，最多能装多少个物品？

直觉是：**先做耗时短的**。把 `a` 从小到大排序后一路累加，直到放不下为止。为什么一定对？

> **引理**（前 k 小之和最小）：设排序后 `a[0] ≤ a[1] ≤ ... ≤ a[n-1]`，记 `S(k) = a[0]+...+a[k-1]`。任意挑出 k 道题，它们的总耗时一定 ≥ S(k)。
> **证明**：任意 k 道题里按耗时从小到大排是 `b[0] ≤ ... ≤ b[k-1]`。对每个位置 `i` 必有 `b[i] ≥ a[i]`（否则第 i 小的数来自前 i+1 个位置之外，就有超过 k-1 个数 ≤ b[i]，矛盾）。逐项相加即得结论。∎

> **定理**（贪心最优）：假设存在一个方案能做完 k 道题，由引理，前 k 小的题总耗时 ≤ 该方案的耗时 ≤ T，所以前 k 小的题也一定做得完。因此"能做完的最多题数"恰等于贪心一路吃进去的个数。∎

### 第二步：真正的难点是"两个时刻相距多少分钟"

不能直接当字符串减，要按「年 → 月 → 日 → 时 → 分」一层层转成一个**单调递增的整数**：

- 把每个时刻都换算成"距 `0000-01-01 00:00` 的总分钟数"；
- 两个数相减，就是中间的分钟数（锚点相同，差值不受锚点选择影响）。

换算步骤：

1. 统计 `[0, y)` 年共多少天：`365 * y + 闰年个数`；
2. 统计本年 `[1, m)` 月共多少天（2 月按是否闰年 +1）；
3. 再加 `d-1` 天；
4. 总天数 `* 1440 + h * 60 + mi`。

**闰年规则**（格里高利历，题目保证"历法与现在一样"）：

> `y` 是闰年 ⟺ `y % 400 == 0`，或 `(y % 4 == 0 && y % 100 != 0)`。

注意 `0000` 能被 400 整除，所以它是闰年（2 月 29 天）。只要乘式统一，这个特殊性不会影响差值。

### 第三步：日期串读进来

`2007-06-23-02:00` 这类串分解很稳：

```cpp
cin>>y>>c1>>m>>c2>>d>>c3>>h>>c4>>mi;   // c1..c4 都是单个 char，吃掉分隔符
```

## 3. 模式总结（按思考顺序）

- **日期差 → 锚点归一**：两个时刻各自转成"到固定锚点的总分钟数"，再做差；
- **闰年**：`y%400==0 || (y%4==0 && y%100!=0)`，`0000` 年也是闰年；
- **最大数量贪心**：排序后从小到大尽量取；
- **贪心证明**：前 k 小之和 ≤ 任意 k 个数之和（逐位比较 / 交换论证）；
- **32 位不够用**：跨 10000 年的分钟数约为 5.26×10⁹，必须 `long long`。

---

## 4. 真正的解法（含记号对照表）

| 记号 | 含义 |
|---|---|
| `n` | 题目数量 |
| `a[i]` | 第 i 题需要的时间（分钟） |
| `y, m, d, h, mi` | 从日期串解析出的年 / 月 / 日 / 时 / 分 |
| `mon[13]` | 平年每月天数表（下标 1~12） |
| `toMin(...)` | 把一个时刻折算成"距 `0000-01-01 00:00` 的分钟数" |
| `T` | `考试分钟数 − 当前分钟数`，即有效刷题时间 |
| `ans` | 答案：最多做题数 |

算法步骤：

1. 读入 `n` 与 `n` 个 `a[i]`。
2. 定义 `toMin(y,m,d,h,mi)`：
   - 先累加 `[0,y)` 年天数：`365*y + y/4 - y/100 + y/400 + 1`（`+1` 是计入闰年 0000）；
   - 再累加本年 `[1,m)` 月天数（`m > 2` 时给 2 月补闰日）；
   - 再加 `d-1`；
   - 最终返回 `天*1440 + h*60 + mi`。
3. `T = toMin(考试) − toMin(当前)`；若 `T < 0`，置 `T = 0`。
4. 对 `a` 升序排序。
5. 贪心计数：`for i: if (T >= a[i]) { T -= a[i]; ans++; } else break;`
6. 输出 `ans`。

复杂度：排序 `O(n log n)`，日期换算 `O(y) ≤ 20000` 次循环（完全足够；也可用公式算到 O(1)）。

## 5. 示例代码（C++17，Luogu O2 通过）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{5005};
int n,a[mxn];
int mon[13]={0,31,28,31,30,31,30,31,31,30,31,30,31};

bool leap(int y)
{
	return (y%4==0&&y%100!=0)||y%400==0;
}

i64 toMin(int y,int m,int d,int h,int mi)
{
	// 统计 [0,y) 年的天数（含闰年）：365*y + y/4 - y/100 + y/400 + 1
	// 最后的 +1 计入闰年 0000
	i64 days=365LL*y+y/4-y/100+y/400+1;
	for(int i=1;i<m;++i)
	{
		days+=mon[i];
		if(i==2&&leap(y))days++; // 本年已过完 2 月时补一天
	}
	days+=d-1;
	return days*1440+h*60+mi;
}

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=0;i<n;++i)cin>>a[i];
	int y,m,d,h,mi;
	char c;
	// 格式 yyyy-mm-dd-hh:MM，用字符吃掉分隔符
	cin>>y>>c>>m>>c>>d>>c>>h>>c>>mi;
	i64 s=toMin(y,m,d,h,mi);
	cin>>y>>c>>m>>c>>d>>c>>h>>c>>mi;
	i64 e=toMin(y,m,d,h,mi);
	i64 t=e-s;
	if(t<0)t=0;
	sort(a,a+n);
	int ans=0;
	for(int i=0;i<n;++i)
	{
		if(t<a[i])break;
		t-=a[i];
		++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```

## 5.5 正确性验证 / 边界

- `T` 最大约 `5.26e9`，用 `long long` 不会溢出；逐题累减也不会。
- 临界情况：当前时间等于考试时间 → `T=0`，答案 0。
- 闰年横跨验证：2000-02-28 → 2000-03-01 差 2 天；0000-01-01 → 0001-01-01 差 366 天。
- 贪心正确性见第 2 步的引理与定理（前 k 小总和 ≤ 任意 k 个总和，故取到最多数量）。
