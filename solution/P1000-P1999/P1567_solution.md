# P1567 统计天数

> 标签：模拟 · 难度：入门
> 本地题面：`P1567.md`（$1\le N\le 10^6$，每天最高气温 $0\le a_i\le 10^9$）。
> 验证：`appendix/P1567/P1567_check.py` —— 官方样例输出 `5` 通过；400 组随机小规模用例标程与暴力逐字节一致；最坏 $N=10^6$ 严格上升数据答案 $1000000$，耗时 $0.054$ s。

## 1. 重新读题

**问题重述（人话版）**

有连续 $N$ 天的最高气温，第 $i$ 天的气温是 $a_i$。要从这段气温序列里找出一段**连续的天数**（一段连续下标区间 $[l,r]$），要求在这段区间里气温**一天比一天高**（即 $a_l<a_{l+1}<\dots<a_r$），使得这段区间的**天数最多**。输出这个最大天数。

> 一句话版本：**求最长的"严格递增连续子段"的长度**。

**题面里容易漏掉的条款**

1. 「最高气温一直上升」$\Rightarrow$ 相邻两天必须**严格**上升（$a_i>a_{i-1}$）。若两天**相等**，上升就中断（不能算作上升）。
2. 「最长连续天数」$\Rightarrow$ 答案是这段上升区间**包含的天数**，也就是区间长度 $r-l+1$，而不是"上升的次数"。长度为 $1$ 的区间里没有任何一对相邻天，但题目问的是"天数"，**单独一天也算一段长度 $1$ 的（平凡的）上升段**，所以 $N\ge1$ 时答案恒 $\ge1$。
3. $N=1$ 时，只有一天，答案就是 $1$。代码里初值必须取 $1$，不能取 $0$。
4. 气温可以取 $0$，也可以取 $10^9$，量级差异大但都只做相邻比较，不参与运算；只有比大小，所以**用 `int` 存就足够**。

**数据范围与规模感受**

$$1\le N\le 10^6,\qquad 0\le a_i\le 10^9 .$$

$N$ 到 $10^6$，提示正解应当是 $O(N)$ 的**一遍线性扫描**。任何 $O(N^2)$（比如枚举每个左端点向右暴力延伸）在最坏情况下是 $10^{12}$，必然超时；而 $O(N\log N)$ 也可接受但没必要。数据里单个数到 $10^9$ 是 `int` 上限内、但为稳妥仍可留 32 位即可（不涉及相加）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"上升"翻译成区间性质

先把题目唯一操作——"找一段上升的天数"——翻译成数学语言。定义：

- **合法区间**：连续下标 $[l,r]$（$0\le l\le r\le N-1$）满足 $a_l<a_{l+1}<\dots<a_r$；
- 区间**价值**：$\text{val}(l,r)=r-l+1$（包含的天数）。
- 答案：$\max\{\text{val}(l,r):[l,r]\text{ 合法}\}$。

**引理 1（合法区间族 = 极大上升段的全部子区间）**

把序列按"相邻是否严格上升"切成若干**极大上升段**：一条极大上升段是满足 $a_{s}<a_{s+1}<\dots<a_{t}$ 且**无法再向两端延长**（即 $s=0$ 或 $a_{s-1}\ge a_s$，且 $t=N-1$ 或 $a_t\ge a_{t+1}$）的区间 $[s,t]$。则合法区间恰好是这些极大上升段的全部子区间。

**证明**：
- （极大段的子区间合法）若 $[l,r]\subseteq[s,t]$ 且 $[s,t]$ 内相邻全部严格上升，则 $[l,r]$ 内相邻也全部严格上升（子区间的每一对相邻仍是原段内的相邻），故合法。
- （合法区间落于某个极大段内）设 $[l,r]$ 合法。向上延伸：只要 $l>0$ 且 $a_{l-1}<a_l$ 就把左端左移。由于 $a_l<a_{l+1}<\dots<a_r$ 均为严格上升，且每步只需检查左边界之外的相邻关系，可以把左端一直延到不能再延（$l'=0$ 或 $a_{l'-1}\ge a_{l'}$）而不破坏合法性；同理把右端延到 $r'$（$r'=N-1$ 或 $a_{r'}\ge a_{r'+1}$）。得到的 $[l',r']$ 即极大上升段，且 $[l,r]\subseteq[l',r']$。
- 两条合并：合法区间族恰为各极大上升段的所有子区间。$\blacksquare$

**引理 2（答案 = 最长极大上升段的长度）**

设各极大上升段长度（天数）为 $L_1,L_2,\dots,L_k$，则 $\text{Ans}=\max_j L_j$。

**证明**：由引理 1，任何合法区间都是某个极大段 $[s_j,t_j]$ 的子区间，其长度 $\le L_j=t_j-s_j+1\le\max_j L_j$，故 $\text{Ans}\le\max_j L_j$。反之取 $j^*=\arg\max_j L_j$，极大段 $[s_{j^*},t_{j^*}]$ 自身合法，价值恰为 $L_{j^*}=\max_j L_j$，故 $\text{Ans}\ge\max_j L_j$。两端夹逼得相等。$\blacksquare$

> 这条引理是本题的全部：**无需考虑"子区间"，只要算出每条极大上升段的长度取最大即可**。于是问题退化成一遍扫描。

### 2.2 一遍扫描怎么维护

设 $\text{cnt}_i$ = "以第 $i$ 天结尾的极大上升段长度"。因为同一极大段内每天结尾的 $\text{cnt}$ 依次递增 $1$，而极大段的长度就是它最右端那天的 $\text{cnt}$，故答案 = $\max_i\text{cnt}_i$。

**引理 3（$\text{cnt}$ 的线性递推正确）**

令 $\text{cnt}_0=1$，对 $i\ge1$：若 $a_i>a_{i-1}$ 则 $\text{cnt}_i=\text{cnt}_{i-1}+1$，否则 $\text{cnt}_i=1$。则 $\text{cnt}_i$ 恰为以第 $i$ 天结尾的极大上升段长度。

**证明**（对 $i$ 归纳）：
- 基例 $i=0$：只有一个元素，以其结尾的极大段就是 $[0,0]$，长度 $1=\text{cnt}_0$。✓
- 归纳步：假设 $\text{cnt}_{i-1}$ 是以 $i-1$ 结尾的极大段 $[s,i-1]$ 的长度。
  - 若 $a_i>a_{i-1}$：则 $i$ 落在同一个极大段 $[s,i]$ 内（因为段内 $a_{i-1}<a_i$ 使其继续延伸，且左边界 $s$ 由 $i-1$ 决定，不受 $i$ 影响），长度 $\text{cnt}_{i-1}+1$。✓
  - 若 $a_i\le a_{i-1}$：则 $a_{i-1}$ 到 $a_i$ 不再上升，以 $i$ 结尾的极大段只能从 $i$ 本身开始，长度 $1$。✓
- 归纳完成。$\blacksquare$

由引理 2、引理 3，答案为 $\max_i \text{cnt}_i$，一遍 $O(N)$ 扫描即可，边更新边取 `max`。**边界陷阱**：$N=1$ 时循环体不进，答案初值必须为 $1$（对应引理 3 的基例）。

### 2.3 剖析失败思路

**失败 1：把"上升"读成"非下降"（允许相等）。**
若把条件写成 $a_i\ge a_{i-1}$，遇到 `5 5` 就会把相等也算进一段，答案偏大。反例：`1 1 2`。严格版答案是 $2$（段 `1 2`）；非严格版会得到 $3$（把 `1 1 2` 整段算入）。$\Rightarrow$ 关系符必须是**严格** $>$。

**失败 2：答案是"上升的次数"而不是"天数"。**
若把答案定义成"递增的间隔数"，则 `1 2 3` 会输出 $2$（两次上升），而题目要的是 $3$ 天。**天数 = 上升次数 + 1**，所以在同一段内要累加天数。

**失败 3：初值为 $0$。**
当 $N=1$ 或整段严格下降时，若剥夺了"单天算 1 段"的概念、把初值写成 $0$，答案会错。由引理 3 基例，$\text{cnt}_0=1$ 是必须的。

### 2.4 复杂度与溢出体检

- 时间：$O(N)$ 一遍扫描，$N\le10^6$，约 $10^6$ 次比较。
- 空间：一个 `int[N+5]` 数组，约 $4$ MB。
- 溢出：只做相邻比较与长度累加（$\text{cnt}\le N\le10^6$），全程 `int` 足够，无溢出。

## 3. 模式总结（Pattern Summary）

**模式名：相邻差序列的「一遍线性扫描」。**

**识别信号**：题目问"最长的一段满足相邻元素满足某种单调关系（递增 / 递减 / 交替）"，且长度以"元素个数"计。

1. **explore its property** — 把"一直上升"翻译成区间性质，证明合法区间族 = 极大上升段的全体子区间（引理 1），从而只需关心"极大段的长度"（引理 2）。
2. **classic problem solution（第一次：一次递推）** — 维护"以当前元素结尾的极大段长度" $\text{cnt}$，用相邻比较做 $O(1)$ 转移（引理 3），答案取所有 $\text{cnt}$ 的最大值。
3. **boundary discipline** — 严格比较（相等即中断）；单元素也算长度 $1$ 的段，故初值为 $1$。
4. **same shape, different data** — 同一份"长度计数"骨架也用于"最长连续指定字符/最长连续相同段"等题，只是把比较换成"是否同类"。

**一句话记忆**：相邻是否满足条件 → 满足就 `cnt++`，不满足就 `cnt=1`，全程取最大。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $N$ / `n` | `int` | 天数 | 读入 | 题面 |
| `a[i]` | `int [1000005]` | 第 $i$ 天最高气温（0-based） | 读入 | 题面 |
| `cnt` | `int` | 以**当前天**结尾的极大上升段长度 | $1$ | 引理 3 的 $\text{cnt}_i$ |
| `ans` | `int` | 目前见到的最长上升段天数 | $1$ | 引理 2 的 $\max_j L_j$ |

### 4.2 编号步骤

1. 读入 $n$ 与 $a_0,\dots,a_{n-1}$。
2. 令 `ans=1, cnt=1`（单天即长度 $1$ 的段，见 §2.1 引理 2 与 §2.3 失败 3）。
3. 对 $i=1..n-1$：若 `a[i]>a[i-1]` 则 `++cnt`，否则 `cnt=1`；随后 `ans=max(ans,cnt)`。
4. 输出 `ans`。

### 4.3 复杂度

- 时间：$O(N)$。
- 空间：$O(N)$（存气温）+ $O(1)$ 附加。
- 实测（见 §4.5）：$N=10^6$ 严格上升时 $0.054$ s，输出 $1000000$。

### 4.4 关键不变量

1. `cnt` 恒等于"以第 $i-1$（刚处理过的那天）结尾的极大上升段长度"，非负且 $\ge1$。
2. `ans` 单调不减，$\ge1$，最终等于所有极大上升段长度的最大值。
3. 判定严格性：`a[i]>a[i-1]` 中出现 `>=` 即错（见 §2.3 失败 1）。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 官方样例回归 | **通过**：`10` / `1 2 3 2 4 5 6 8 5 9` → `5` |
| 随机数据对拍 | **通过**：$400$ 组随机用例（$n\in[1,200]$，气温 $\in[0,20]$，含大量相等/下降），线性扫描版与 $O(n^2)$ 区间穷举版逐字节一致 |
| 最坏规模计时 | $N=10^6$ 严格上升 → 输出 $1000000$，耗时 **$0.054$ s** |
| 残余风险 | 若把比较写成非严格 `>=`，或把 `cnt` 初值写成 $0$，会在全相等/全下降数据上给出错误答案，已在 §2.3、§4.4 标注 |

## 5. 示例代码

### 5.1 主解：一遍线性扫描

```cpp
//
// 题目：P1567 统计天数
// https://www.luogu.com.cn/problem/P1567
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005};       // N<=1e6 (+5 松弛)

int n,a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	int ans=1,cnt=1;              // 单天也算长度 1 的上升段
	for(int i=1;i<n;++i)
	{
		if(a[i]>a[i-1])
			++cnt;
		else
			cnt=1;
		ans=max(ans,cnt);
	}
	cout<<ans<<'\n';
	return 0;
}
```

**代码结构对照**：`cnt` 是引理 3 的递推量，`ans` 是引理 2 的答案；`a[i]>a[i-1]` 采用严格比较，相等即把 `cnt` 归 $1$；初值全取 $1$ 覆盖 $N=1$ 与全下降两种边界。

### 5.2 对照实现：$O(n^2)$ 区间穷举（仅用于小规模对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005};

int n,a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	int ans=1;
	for(int l=0;l<n;++l)          // 枚举起点,向右延伸严格上升段
	{
		int r=l;
		while(r+1<n&&a[r+1]>a[r])
			++r;
		ans=max(ans,r-l+1);
	}
	cout<<ans<<'\n';
	return 0;
}
```

两版输出逐字节相同（已用 $400$ 组随机数据确认）。这一版直接按引理 1 的定义枚举"每个左端点的极大上升段"，不依赖任何递推，可作为递推实现的独立交叉验证。$O(n^2)$ 仅 $n\le$ 数百时可跑。

### 5.3 易错点清单

- **比较写成 `>=`** $\Rightarrow$ 相等被当作上升，答案偏大（§2.3 失败 1 的 `1 1 2` 反例）。
- **初值取 $0$** $\Rightarrow$ $N=1$ 或全下降时答案错（应为 $1$）。
- **答案存成"上升次数"** $\Rightarrow$ 少 $1$（§2.3 失败 2）。
- **用 `endl`** 违反本项目风格指南，一律用 `'\n'`。
