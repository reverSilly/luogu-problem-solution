# P1519 [USACO2.4] 穿越栅栏 Overfencing

> 标签：搜索 / USACO · 难度：普及/提高-
> 本地题面：`P1519.md`（$W\le 38,\ H\le 100$；网格共 $2H+1$ 行、$2W+1$ 列，边界上有两个出口）。验证：`appendix/P1519/` 中官方样例（答案 $9$）+ 350 组随机完美迷宫对拍 + 最坏规模 $38\times100$ 计时，std 与暴力逐字节一致。

## 1. 重新读题

**问题重述（人话版）**

有一个由栅栏构成的迷宫（保证是"完美的"：任意一点都能走出迷宫）。迷宫宽 $W$、高 $H$，用 $2H+1$ 行、每行 $2W+1$ 个字符的"字符画"表示：

- 每个**格子（房间）**位于**奇数行、奇数列**（如 $1$-based 的 $(1,1),(1,3),\dots$）；
- 栅栏"柱子" `+` 出现在偶数行、偶数列；
- 水平栅栏 `-` 出现在偶数行、奇数列；
- 垂直栅栏 `|` 出现在奇数行、偶数列；
- 空格 `' '` 表示可通行的通道/格子。

迷宫边界上留有**恰好两个**出口（边界处的空格）。牛只能水平或垂直移动一格（不斜走）。**每移动到一个新格子算一步，包括走出迷宫的那一步**。

要求：对迷宫里的每一个格子，算出"以最优方式走到最近的出口所需的步数"，再取这些数中的**最大值**输出——即那个"最糟糕的格子"需要多少步。

> 一句话版本：**在迷宫的格子图上求"每个点到最近出口"的最短路，取其中的最大值。**

**题面里容易漏掉的条款**

1. 「包括移出迷宫的那一步」$\Rightarrow$ 一个格子到出口的步数 = 走到出口旁所花步数 **再 $+1$**（最后那步是跨出迷宫）。
2. 「最糟糕的那一个点」$\Rightarrow$ 最终输出的是**所有格子的最小值中的最大值**（min-max），不是某个格子的距离，也不是最小值。
3. 「每个迷宫只有两个出口」$\Rightarrow$ 出口恰好两个，但不必假设它们在哪个方向；四个边界都要扫描。
4. 输入行可能带**行尾空格**（样例第 $6$ 行 `| |     |  ` 末尾就有两个空格）$\Rightarrow$ 读入必须保留空格并按行宽补全，否则会误判墙/通道。

**数据范围与规模感受**

$$1\le W\le38,\qquad 1\le H\le100 .$$

网格规模最大 $(2\cdot100+1)\times(2\cdot38+1)=201\times77\approx1.55\times10^4$ 个字符；格子数 $100\times38=3800$。这提示 $O(\text{格子数})$ 的多源 BFS 即可，甚至 $O(\text{格子数}^2)$ 也仅约 $1.4\times10^7$，两者都在限制内。空间只需同量级的网格与距离数组。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把字符画抽象成格子图

字符画里，"空格"既出现在房间中心（奇数行奇数列），又出现在它两侧的通道（例如水平相邻两个房间之间的那个奇数列、偶数行位置——恰是 `-` 应该在的地方，若是空格则说明此处是通道）。所以要先把"格子之间能不能走"讲清楚。

**引理 1（相邻判定）**

两个房间（同在奇数行或同在奇数列、且相邻，相距 $2$ 格）之间可以互相通行，当且仅当它们之间那个字符位置是空格 `' '`。具体地：

- 房间 $(r,c)$ 与 $(r-2,c)$（向上）：当且仅当 $g[r-1][c]=='\ ' $；
- 与 $(r+2,c)$（向下）：$g[r+1][c]=='\ '$；
- 与 $(r,c-2)$（向左）：$g[r][c-1]=='\ '$；
- 与 $(r,c+2)$（向右）：$g[r][c+1]=='\ '$。

**证明**：栅栏画法的定义是：每两个相邻房间之间、以及每个房间与迷宫外部之间，都有一个"墙位"字符。水平相邻房间的墙位在它们中间那一列的上一行/中间位置（即 $(r,c\pm1)$，位于奇数行、偶数列，本应是 `|`）；竖直相邻房间的墙位在 $(r\pm1,c)$（偶数行、奇数列，本应是 `-`）。当该位置是 `-` 或 `|` 时为墙、不可通行；是 `' '` 时墙被打开、可通行。故判定条件就是把该墙位字符与空格比较。$\blacksquare$

> 这一步把二维字符画降维成一张"房间 $\to$ 四邻"的图，后面按常规图论处理即可。

### 2.2 考虑简化版：只有一个出口

若迷宫只有一个出口，问题就是"单源最短路"：从出口旁出发 BFS，求出每个格子到它的距离取最大。这一步提示：**本题的核心是"多到一的距离"，出口个数只影响源点个数**。

### 2.3 归约：两个出口 → 引入"外部"虚拟源

**引理 2（"走出迷宫的那一步" $\Rightarrow$ 外部距离为 $0$ 的虚拟源）**

想象在迷宫外增加一个虚拟点 "OUT"，令 $dis(\text{OUT})=0$。任一出口（边界上的空格）都把 OUT 与其内侧的那个房间相连，且该边代价为 $1$（跨出/跨入迷宫的那一步）。则每个房间的搜索距离恰为"到最近出口的最少步数（含跨出那步）"。

**证明**：从房间到最近出口的最短路 = 若干次"房间→房间"移动（每次 $1$ 步）加上最后"房间→OUT"的一步。把它拆成"房间→房间"段与"末端跨出步"：OUT 到该内侧房间的边恰表示末端那一步、代价 $1$，而房间之间边代价 $1$。于是"房间 $u$ 到 OUT "的最短距离与题面的步数定义逐项对应。又因为 OUT 连的是**所有**出口，所以对 $u$ 而言取的是"到最近出口"的最短者。$\blacksquare$

于是把"每个出口的内侧房间"作为多源 BFS 的起点、**初始距离置 $1$**（已经包含了跨出那一步），就得到所有房间的距离。

**引理 3（多源 BFS 的源点是"出口内侧房间"，初始距离 $1$）**

对每个边界出口 `X`，与其相邻的房间 $u_X$ 令 $dis(u_X)=1$ 并入队；其余房间初始为未访问。然后标准 BFS（每次移动到相邻房间距离 $+1$）。结束时 $dis(u)$ 即 $u$ 到最近出口的步数（含跨出步）。

**证明**：这是引理 2 虚拟源 BFS 的"消去 OUT"等价写法——OUT 与其邻居 $u_X$ 之间边权 $1$，从 OUT 出发给 $u_X$ 赋距离 $1$ 正是把 OUT 的贡献 "折叠" 进源点初值；此后 BFS 在房间图上展开。由标准 BFS 正确性，得到的就是从虚拟源到各点的最短距离。$\blacksquare$

### 2.4 经典技术：多源 BFS（就地把所有出口当起点）

构造队列，把"出口内侧房间"全部入队、距离 $1$。之后逐层扩展：弹出 $(r,c)$，对其四个可能的相邻房间，若墙位是空格且未访问，则赋 `dis=dis[r][c]+1` 入队。由于边权恒 $1$，BFS 的层次展开即最短距离。

### 2.5 出口识别与步数口径的交叉验证

**引理 4（出口识别）**

出口恰是**边界行/列上的空格**：上边界 $g[0][c]=='\ '$（$c$ 奇）、下边界 $g[R-1][c]=='\ '$、左边界 $g[r][0]=='\ '$、右边界 $g[r][C-1]=='\ '$（$r$ 奇）。其相邻房间即内侧格。

**证明**：栅栏定义下，边界上"本应是墙"的位置只出现在这些坐标；是墙则是 `-`/`|`，被打开（成为出口）则是空格。故扫描上述位置中的空格即得全部出口；样例中恰有 $2$ 个（下边界 $c=3$ 与右边界 $r=5$）。$\blacksquare$

**口径核对**：用题面样例（$W=5,H=3$）验证。左下角房间 $(5,1)$ 的最近出口是右边界那个：路径 $(5,1)\to(3,1)\to(3,3)\to(1,3)\to(1,5)\to(1,7)\to(1,9)\to(3,9)\to(5,9)$，再跨出一步，共 $9$ 步；它正是全场距离最大者，故输出 $9$，与官方一致。（注意若把"跨出那一步"漏算，会得到 $8$，与样例不符。）

### 2.6 剖析失败思路

**失败 1：把距离定义成"房间到房间"的步数，不含跨出那步。**
则样例答案为 $8$，而官方是 $9$ $\Rightarrow$ 必须把出口内侧房间初始距离置 $1$（引理 3），而不是 $0$。

**失败 2：`cin>>` 读整行导致空格被跳过。**
若用 `cin>>字符串` 读每一行，行首/行内空格会被当作分隔符吃掉、行尾空格会丢失，整张字符画错位。$\Rightarrow$ 必须用 `getline` 且对短行补空格。

**失败 3：只从一个出口做单源 BFS。**
一个出口的 BFS 会让靠近另一个出口的格子距离偏大。$\Rightarrow$ 必须把两个出口都作为源（多源）。

**失败 4：把最大值写成最小值。**
题目要"最糟糕的点"，即**先取到出口的最近距离、再取这些距离的最大值**。$\Rightarrow$ 最后是 `ans=max(ans,dis[cell])`。

## 3. 模式总结（Pattern Summary）

**模式名：字符迷宫的「格子图化 → 多源 BFS 求 min-max」。**

**识别信号**：给一张"墙/通道"字符画，要求"某点到若干目标的最短距离"的极值；目标是边界上的开口。

**可复用套路（按实际思考顺序）**：

- **explore its property** — 把字符画抽象成"房间（奇/奇）+ 墙位字符"的格子图，相邻判定 = 中间墙位是否空格（引理 1）。
- **consider easier version** — 先解"单出口"的单源 BFS，看出问题核心是"多到一"的距离。
- **reduce to easier problem** — 用"距离 $0$ 的外部虚拟源"统一表达两个出口，折叠成源点初始距离 $1$（引理 2、3）。
- **classic problem solution** — 多源 BFS 求每格到最近出口的最短距离。
- **merge maxima** — 先对每格取"到最近出口的距离"，再对所有格取最大值（min-max）。
- **handle ragged input** — 用 `getline` 读满行宽并对短行补空格，保住通道信息。

**一句话记忆**：迷宫画成格子图，两个出口当多源，BFS 一遍，答案 = 各格最小距离中的最大者（记得 +1 的出迷宫那步）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $W,H$ | `int` | 迷宫格子宽、高 | 读入 | 题面 |
| $R,C$ | `int` | 字符画行数 $2H+1$、列数 $2W+1$ | 计算 | 题面 |
| `g[mxn][mxm]` | `char[210][90]` | 字符画（含 `+ - \|` 与空格） | `getline` 读入并补空格 | 题面 |
| `dis[mxn][mxm]` | `int[210][90]` | 房间走出迷宫所需步数，`-1`=未访问 | `memset(-1)` | 最短距离（引理 3） |
| `qr,qc` | `int[mxn*mxm]` | BFS 队列的行、列 | 空 | 手写队列 |
| `hd,tl` | `int` | 队首、队尾指针 | $0$ | — |
| `ans` | `int` | 所有房间距离的最大值 | $0$ | min-max 的 max 部分 |

### 4.2 编号步骤

1. 读 $W,H$；令 $R=2H+1,\ C=2W+1$。
2. `getline` 吃掉首行行末；随后逐行 `getline` 读入，`while(l.size()<C) l+=' '` 补足行宽，写入 `g`。
3. `memset(dis,-1)`。
4. 扫描四条边界上的空格（引理 4）：
   - 上：`g[0][c]==' '` $\Rightarrow$ 把房间 $(1,c)$ 以距离 $1$ 入队；
   - 下：`g[R-1][c]==' '` $\Rightarrow$ 房间 $(R-2,c)$ 距离 $1$；
   - 左：`g[r][0]==' '` $\Rightarrow$ 房间 $(r,1)$ 距离 $1$；
   - 右：`g[r][C-1]==' '` $\Rightarrow$ 房间 $(r,C-2)$ 距离 $1$。
5. 多源 BFS：弹出 $(r,c)$，对四个相邻房间（引理 1 的墙位判定）若未访问则 `dis=dis[r][c]+1` 入队。
6. 对每个房间取 `ans=max(ans,dis[room])`，输出 `ans`。

### 4.3 复杂度

- 时间：每个房间至多入队/出队一次，四条出边，$O(R\cdot C)=O(201\cdot77)\approx1.5\times10^4$。
- 空间：`char[210][90]` + `int[210][90]` + 队列 `int[18900]`，约 $95$ KB（另有 `dis` 的 $4$ 字节整数约 $76$ KB），总量远低于 $125$ MB。
- 实测（§4.5）：最坏 $38\times100$ 迷宫输出 $855$，耗时 **$0.0050$ s**。

### 4.4 关键不变量（值得写 `assert` 的地方）

1. `dis[room]>=1` 对所有可达房间成立（源点初值 $1$）。
2. BFS 队列中元素按距离单调不减（标准 BFS 层次序）。
3. 每个房间恰被赋值一次（`dis<0` 才入队）。
4. `ans` 是 max-min 的值；若迷宫完美则所有房间都有有限距离。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 官方样例 | **通过**：$W=5,H=3$ 样例（含行尾空格）$\Rightarrow$ 输出 $9$（std 与暴力一致；已核对"含跨出那步"） |
| 随机对拍 | **通过**：$350$ 组随机**完美迷宫**（随机 DFS 生成连通迷宫，再随机打两个边界出口，$W,H\in[1,7]$），std（多源 BFS）与暴力（逐格单源 BFS）输出逐字节一致 |
| 最坏规模计时 | $W=38,H=100$ 随机完美迷宫 $\Rightarrow$ 输出 $855$，耗时 **$0.0050$ s** |
| 残余风险 | 若测试数据把行尾空格裁掉且该行右端本应是墙 `|`，则"补空格"会误造一个出口；按 USACO 原数据行宽固定，不会发生。另：若迷宫非"完美"（存在不可达房间），`dis` 保持 $-1$ 会使该房不贡献 `ans`，按题面保证不会出现 |

## 5. 示例代码

### 5.1 主解：建格子图 + 多源 BFS
```cpp
// 题目：P1519 [USACO2.4] 穿越栅栏 Overfencing
// https://www.luogu.com.cn/problem/P1519
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{210};                // 2*100+1 = 201 (+5 松弛)
constexpr int mxm{90};                 // 2*38+1  = 77  (+5 松弛)

int W,H,R,C;
char g[mxn][mxm];
int dis[mxn][mxm];                     // 当前格走出迷宫所需步数, -1=未访问
int qr[mxn*mxm],qc[mxn*mxm];
int hd,tl;

void push(int r,int c,int d)           // 未访问过才入队
{
	if(dis[r][c]<0)
	{
		dis[r][c]=d;
		qr[tl]=r;qc[tl]=c;++tl;
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>W>>H;
	R=2*H+1;C=2*W+1;
	{
		string tmp;
		getline(cin,tmp);              // 吃掉第一行行末
	}
	for(int i=0;i<R;++i)
	{
		string l;
		getline(cin,l);
		while((int)l.size()<C)
			l+=' ';                    // 行尾空白可能被截断,右侧补空格
		for(int j=0;j<C;++j)
			g[i][j]=l[j];
	}
	memset(dis,-1,sizeof(int)*mxn*mxm);

	// 四段边界上的空格即出口, 其内侧格子一步即可走出
	for(int c=1;c<C-1;c+=2)
	{
		if(g[0][c]==' ')
			push(1,c,1);
		if(g[R-1][c]==' ')
			push(R-2,c,1);
	}
	for(int r=1;r<R-1;r+=2)
	{
		if(g[r][0]==' ')
			push(r,1,1);
		if(g[r][C-1]==' ')
			push(r,C-2,1);
	}

	while(hd<tl)                       // 多源 BFS: 距离 = 到最近出口步数
	{
		int r=qr[hd],c=qc[hd];++hd;
		int d=dis[r][c];
		if(r>=2&&g[r-1][c]==' ')
			push(r-2,c,d+1);
		if(r+2<=R-2&&g[r+1][c]==' ')
			push(r+2,c,d+1);
		if(c>=2&&g[r][c-1]==' ')
			push(r,c-2,d+1);
		if(c+2<=C-2&&g[r][c+1]==' ')
			push(r,c+2,d+1);
	}

	int ans=0;
	for(int r=1;r<=R-2;r+=2)
		for(int c=1;c<=C-2;c+=2)
			ans=max(ans,dis[r][c]);    // 最"糟糕"的点
	cout<<ans<<'\n';
	return 0;
}
```

### 5.2 对照实现：逐格单源 BFS（仅用于对拍）
```cpp
// P1519 暴力基准：对每个格子单独 BFS 找最近出口, 再取最大
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{210},mxm{90};
int W,H,R,C;
char g[mxn][mxm];
bool vis[mxn][mxm];
int qr[mxn*mxm],qc[mxn*mxm];

bool isExitAdj(int r,int c)            // 该格能否一步走出迷宫
{
	if(r==1&&g[0][c]==' ')
		return true;
	if(r==R-2&&g[R-1][c]==' ')
		return true;
	if(c==1&&g[r][0]==' ')
		return true;
	if(c==C-2&&g[r][C-1]==' ')
		return true;
	return false;
}

int bfs(int sr,int sc)                 // 从 (sr,sc) 出发走出迷宫的最少步数
{
	memset(vis,0,sizeof(vis));
	int hd=0,tl=0,d=0;
	qr[tl]=sr;qc[tl]=sc;++tl;vis[sr][sc]=true;
	while(hd<tl)
	{
		int lvl=tl;
		for(;hd<lvl;++hd)
		{
			int r=qr[hd],c=qc[hd];
			if(isExitAdj(r,c))
				return d+1;            // 再走一步出迷宫
			if(r>=2&&g[r-1][c]==' '&&!vis[r-2][c]){vis[r-2][c]=true;qr[tl]=r-2;qc[tl]=c;++tl;}
			if(r+2<=R-2&&g[r+1][c]==' '&&!vis[r+2][c]){vis[r+2][c]=true;qr[tl]=r+2;qc[tl]=c;++tl;}
			if(c>=2&&g[r][c-1]==' '&&!vis[r][c-2]){vis[r][c-2]=true;qr[tl]=r;qc[tl]=c-2;++tl;}
			if(c+2<=C-2&&g[r][c+1]==' '&&!vis[r][c+2]){vis[r][c+2]=true;qr[tl]=r;qc[tl]=c+2;++tl;}
		}
		++d;
	}
	return 1<<30;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>W>>H;
	R=2*H+1;C=2*W+1;
	{
		string tmp;
		getline(cin,tmp);
	}
	for(int i=0;i<R;++i)
	{
		string l;
		getline(cin,l);
		while((int)l.size()<C)
			l+=' ';
		for(int j=0;j<C;++j)
			g[i][j]=l[j];
	}
	int ans=0;
	for(int r=1;r<=R-2;r+=2)
		for(int c=1;c<=C-2;c+=2)
			ans=max(ans,bfs(r,c));
	cout<<ans<<'\n';
	return 0;
}
```

两版输出必须逐字节相同（已用 $350$ 组随机完美迷宫 + 官方样例确认）。暴力版**对每个格子单独 BFS**、完全不依赖"多源"这一技巧，是主解最短路口径的独立交叉验证基准，代价是 $O(\text{格子数}^2)$，仅在小迷宫上跑。

### 5.3 易错点清单

- **`cin>>` 读行** $\Rightarrow$ 空格被跳过导致字符画错位；必须 `getline` 并对短行补空格。
- **出口内侧房间初始距离置 $0$** $\Rightarrow$ 漏掉"跨出迷宫那一步"，样例会得 $8$ 而非 $9$。
- **单源 BFS**（只用一个出口）$\Rightarrow$ 部分格子距离偏大。
- **把 `ans` 写成最小值** $\Rightarrow$ 题目要的是"最糟糕的点"（min 之后取 max）。
- **墙位判定写错方向**（例如向上查 `g[r+1][c]`）$\Rightarrow$ 通道/墙完全错位。
