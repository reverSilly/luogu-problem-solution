# P1061 Jam 的计数法 — 题解

---

## 一、发现叙事

拿到这道题，首先需要理解 Jam 计数法的三个约束：

1. **固定宽度**：每个 Jam 数字都由恰好 $w$ 个字母组成。
2. **严格递增**：从左到右字母严格递增，不允许重复。
3. **字母范围**：只能使用第 $s$ 到第 $t$ 个小写字母（$1=\texttt a,2=\texttt b,\dots,26=\texttt z$）。

例如 $s=2,t=10,w=5$，可用字母为 $\texttt{b,c,d,e,f,g,h,i,j}$，一个合法的 Jam 数字如 $\texttt{bdfij}$。题目要求输出给定 Jam 数字之后的 5 个后继（如果存在）。

---

**第一步：建立映射。**

字母与自然数一一对应：第 $i$ 个字母对应数字 $i-1$（0-based）。于是区间 $[s,t]$ 变为 $[s-1,t-1]$，Jam 数字就是一个长度为 $w$ 的**严格递增整数序列**，每个数在 $[s-1,t-1]$ 内。

例如 $\texttt{bdfij}$ 变成 $[1,3,5,8,9]$。

---

**第二步：意识到它是组合。**

从 $t-s+1$ 个可用字母中选出 $w$ 个，再按递增序排列 —— 这正是**组合**的定义。每个 Jam 数字对应一个 $w$ 元组合。题目要求的"下一个 Jam 数字"，就是**按字典序的下一个组合**。

组合的字典序后继有经典算法（"next combination"），这正是解题核心。

---

**第三步：发现算法。**

对于组合 $a_0<a_1<\dots<a_{w-1}$，从最右侧开始检查每个位置：

- 位置 $i$ 能取到的最大值是 $t-1-(w-1-i)$（因为后面需要 $w-1-i$ 个更大的数）。
- 如果 $a_i$ 还没到最大值，就把它加 1，然后把 $i$ 之后的所有位置填成尽可能小的递增序列（即 $a_i+1,\,a_i+2,\,\dots$）。
- 如果 $a_i$ 已到最大值，继续向左移动。

这就是组合数学中的 **next_combination** 算法，时间复杂度 $O(w)$，完全满足 $w\le 25$ 的规模。

---

**第四步：验证样例。**

$s=2,t=10,w=5$，0-based 为 $s'=1,t'=9$，当前组合 $[1,3,5,8,9]$。

从右向左：
- $i=4$：最大值为 $9-(0)=9$，$a_4=9$ 已达上限 → 左移。
- $i=3$：最大值为 $9-(1)=8$，$a_3=8$ 已达上限 → 左移。
- $i=2$：最大值为 $9-(2)=7$，$a_2=5<7$ → 加 1 得 $6$，后续填 $6+1=7,\,7+1=8$。
- 结果 $[1,3,6,7,8]$ → 映射回字母 $\texttt{bdghi}$。

与题目给出的 $\texttt{bdghi}$ 一致。

## 二、思维链与完整证明

### 2.1 形式化定义

设字母全集为 $\Sigma=\{\texttt a,\texttt b,\dots,\texttt z\}$，映射 $f(c)=c-\texttt a$ 将字母映到整数 $0\sim25$。

给定参数 $s,t,w$，定义可用集合 $A=\{x\in\mathbb Z\mid s-1\le x\le t-1\}$，$|A|=t-s+1$。

一个 **Jam 数字** 是严格递增序列 $(a_0,a_1,\dots,a_{w-1})$，满足：
$$
\forall i,\; a_i\in A,\qquad a_0<a_1<\dots<a_{w-1}.
$$

**引理 1（最大可能值）** 对于位置 $i$（$0\le i<w$），$a_i$ 的最大可能值为
$$
\max_i = (t-1) - (w-1-i).
$$

*证明*：$a_i$ 之后还有 $w-1-i$ 个位置，每个位置至少比前一个大 $1$。若 $a_i > \max_i$，即使 $a_{i+1},a_{i+2},\dots$ 取到尽可能小的值（$a_i+1,a_i+2,\dots$），最后一个元素也会超过 $t-1$，矛盾。因此 $a_i\le\max_i$，且上界是可达的（取 $a_j = a_i + (j-i)$ 即可）。∎

### 2.2 后继的定义与唯一性

**定义** 对于 Jam 数字 $A=(a_0,\dots,a_{w-1})$，它的**后继**（如果存在）是满足以下条件的 Jam 数字 $B=(b_0,\dots,b_{w-1})$：
1. $A<B$（字典序，即存在 $k$ 使得 $b_k>a_k$ 且 $\forall j<k,\;b_j=a_j$）；
2. 不存在 Jam 数字 $C$ 使得 $A<C<B$。

**定理 1（后继的存在条件）** $A$ 存在后继当且仅当 $A\neq (\max_0,\max_1,\dots,\max_{w-1})$，即 $A$ 不是最后一个组合。

*证明*：组合的字典序全序性质。最大组合为 $((t-1)-(w-1),\,(t-1)-(w-2),\,\dots,\,(t-1))$。任何不等于该组合的序列都可通过下述算法得到后继。∎

### 2.3 后继构造算法

**算法**（next combination）：

1. 从 $i=w-1$ 向下遍历到 $0$：
   - 若 $a_i < \max_i$，则：
     - $b_i \gets a_i + 1$；
     - 对于 $j=i+1,\dots,w-1$，$b_j \gets b_{j-1} + 1$；
     - 对于 $j< i$，$b_j \gets a_j$。
     - 输出 $B$ 并终止。
   - 否则继续向左。
2. 若遍历完毕仍未找到，则 $A$ 无后继。

**定理 2（算法正确性）** 上述算法输出的 $B$ 是 $A$ 的后继。

*证明*：分三部分论证。

**(a) 合法性**：$b_i = a_i+1 \le \max_i$ 保证了 $b_i$ 在允许范围内，且对后续位置 $j>i$，$b_j = b_{j-1}+1$ 构成了以 $b_i+1$ 起始的连续递增序列。由于 $b_{w-1} = b_i + (w-1-i) \le \max_i + (w-1-i) = t-1$，所有元素在 $A$ 内。严格递增性由构造保证。

**(b) 字典序大于 $A$**：$b_i > a_i$，且对 $j<i$ 有 $b_j=a_j$，故 $A<B$。

**(c) 不存在中间元素**：假设存在 $C$ 使 $A<C<B$。设 $k$ 为 $C$ 与 $A$ 第一个不同的位置。若 $k<i$，则 $c_k>a_k=b_k$，但 $C$ 在 $k$ 后的元素最小值是 $c_k+1$，而 $b_k=a_k$，且 $B$ 在 $k$ 后的元素已经是可能的最小值（保持递增），从而 $B<C$，矛盾。若 $k=i$，则 $a_i < c_i < b_i$，但 $b_i=a_i+1$，整数之间不存在第三个整数，矛盾。若 $k>i$，则 $c_i=b_i$ 且 $c_k>b_k$；但 $b_k$ 是 $b_i$ 之后能取到的最小值（$b_{i+1}=b_i+1,\dots$），因此 $c_k$ 只能更大，同样导致 $B<C$。综上，不存在这样的 $C$。∎

### 2.4 复杂度

每次寻找后继最多扫描 $w$ 个位置，填充后续位置也最多 $w$ 步。单次 $O(w)$，总输出不超过 5 个后继，复杂度 $O(5w) = O(w)$。$w\le 25$，极其充裕。

## 三、模式总结

| 条目 | 内容 |
|------|------|
| **问题类型** | 组合的字典序后继生成 |
| **核心模型** | 从 $n$ 个元素中选 $w$ 个的组合，按字典序枚举 |
| **算法** | next_combination：从右向左找第一个未达上限的位置 $i$，$a_i$ 自增 1，后续重置为最小递增序列 |
| **判定上界** | 位置 $i$ 的上界 = $t-1-(w-1-i)$ |
| **输出限制** | 最多 5 个后继，不存在则停止 |
| **关键词** | 严格递增、组合后继、贪心构造 |

## 四、解法与符号表

### 符号表

| 符号 | 含义 |
|------|------|
| $s$ | 最小字母序号（1-based） |
| $t$ | 最大字母序号（1-based） |
| $w$ | Jam 数字的宽度（字母个数） |
| $A$ | 输入 Jam 数字，映射为 0-based 整数数组 $a[0..w-1]$ |
| $a_i$ | 第 $i$ 个位置的值（0-based） |
| $\max_i$ | 位置 $i$ 可取的**最大值**，$\max_i = (t-1) - (w-1-i)$ |
| $B$ | 后继 Jam 数字 |
| $\texttt{char}(x)$ | 将整数 $x$ 映射回字母 $x+\texttt a$ |

### 完整解法

**步骤 1：读入与预处理**

读入 $s,t,w$ 及字符串 $str$，将 $str$ 的每个字符 $c$ 转为整数 $a_i = c - \texttt a$。

**步骤 2：循环生成后继**

重复最多 5 次：

1. 从 $i=w-1$ 向 $0$ 扫描，寻找第一个满足 $a_i < (t-1)-(w-1-i)$ 的位置。
2. 若未找到，终止循环（无更多后继）。
3. 否则：
   - $a_i \gets a_i + 1$；
   - 对 $j=i+1,\dots,w-1$，$a_j \gets a_{j-1}+1$；
   - 将 $a$ 转回字母并输出。

**步骤 3：边界**

- 输入保证合法，无需验证。
- 最多输出 5 行，不足 5 个则输出所有存在的后继。

## 五、C++ 代码

```cpp
//
// Created by Louis Li on 2024/1/30.
//
// https://www.luogu.com.cn/problem/P1061
// LUOGU_RID: 123456789

#include<bits/stdc++.h>
using namespace std;

int s,t,w,a[30];
string str;

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s>>t>>w>>str;
	--s;--t;
	for(int i=0;i<w;++i)
		a[i]=str[i]-'a';
	for(int k=0;k<5;++k)
	{
		int pos=-1;
		for(int i=w-1;i>=0;--i)
		{
			if(a[i]<t-(w-1-i))
			{
				pos=i;
				break;
			}
		}
		if(pos==-1)
			break;
		++a[pos];
		for(int i=pos+1;i<w;++i)
			a[i]=a[i-1]+1;
		for(int i=0;i<w;++i)
			cout<<char(a[i]+'a');
		cout<<'\n';
	}
	return 0;
}
```
