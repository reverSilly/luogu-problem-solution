# P1333 瑞瑞的木棍

> 标签：字符串 · 图论 · 并查集 · 欧拉回路 · 哈希 hashing · 字典树 Trie · 福建省历届夏令营 | 难度：提高/省选-

## 1. 重新读题

**问题重述（简化版）**

瑞瑞有若干根木棍，每根木棍的**两端**各染了一种颜色（颜色名是小写英文单词）。要把**所有**木棍首尾相接摆成**一条线**（不是圈），要求相邻两根木棍相接触的那两个端点颜色相同。木棍可以任意翻转、任意调序。问是否存在这样的摆法。

题面给的例子：两根木棍分别是 `red`/`blue` 与 `red`/`yellow`，摆成 `blue --- red | red --- yellow`。注意第一根木棍被**翻转**了（输入顺序是 red、blue，摆出来是 blue 在左），所以木棍两端是**无序对**。

**输入输出**

| 项 | 内容 |
|---|---|
| 输入 | **若干行**，每行两个单词，没有给行数 $n$，只能读到 EOF |
| 单词 | 全小写字母，长度 $\le 10$ |
| 规模 | 木棍**最多** $250000$ 根 |
| 输出 | 能拼 → `Possible`；不能 → `Impossible`（逐字照抄，首字母大写、其余小写，无标点） |

**约束与暗示**

| 量 | 上界 | 备注 |
|---|---|---|
| 木棍数 $m$ | $2.5\times10^5$ | 端点出现次数 $2m\le5\times10^5$ |
| 不同颜色数 $V$ | $\le\min(2m,\;26+26^2+\cdots+26^{10})=5\times10^5$ | 直接决定数组尺寸 |
| 单词长度 $L$ | $10$ | 字符集大小 $26$ → 可作定进位制编码 |
| 单点最大度数 | $2m=5\times10^5$ | `int` 足够 |

本题**只判定存在性、不输出方案、不计数**，所以没有"答案累加"会溢出；唯一需要 64 位的地方是**字符串编码**（见 §2.6）。

## 2. 思维链

### 2.1 探索特殊机制 —— 把"摆成一条线"写成形式陈述

先把"摆法"这个物理动作翻译清楚，否则后面的等价证明没有对象。

**定义 1（摆法）** 给每根木棍 $i$ 指定左右两端颜色 $(l_i,r_i)$，其中 $\{l_i,r_i\}=\{p_i,q_i\}$（即允许翻转，两端无序），再给木棍的一个排列 $\pi$，使得
$$\forall\,1\le k<m:\quad r_{\pi_k}=l_{\pi_{k+1}} .$$
"接触的两端颜色相同"就是这个相邻等式；线两端的两个自由端点**不加任何约束**。

**定义 2（欧拉通路）** 构造图 $G=(V,E)$：$V$ = **出现过**的颜色，$E$ = 木棍（多重边，允许 $p_i=q_i$ 的自环）。$G$ 的一条**欧拉通路**是点序列与边序列交错
$$v_0,e_1,v_1,e_2,\;v_2,\;\dots,\;e_m,v_m$$
它必须同时满足三件事，一件都不能少：

1. **边的有序序列**：$e_1,\dots,e_m$ 是 $E$ 排成的一个**序列**（有先后，对应木棍在线上的左右次序）；
2. **相邻边共端点**：每条 $e_k$ 的两个端点恰是 $v_{k-1}$ 与 $v_k$，于是 $e_k$ 与 $e_{k+1}$ 共享顶点 $v_k$ —— 这就是"相接触的两端颜色相同"的图论写法；
3. **每边恰用一次**：$e_1,\dots,e_m$ 互不相同且**恰为** $E$ 的全部边（每根木棍都要摆上，也只摆一次；即使两根木棍颜色完全相同，它们是不同的物理对象，是两条不同的平行边）。

点 $v_i$ **允许重复**（同一个颜色可以在一条线上出现多次），这也是为什么"点数很少、边数很多"的输入照样可能有解。

**引理 1（摆法 ⟺ 欧拉通路）** $G$ 存在满足定义 1 的摆法 $\iff$ $G$ 存在欧拉通路。

**证明：**
- **$\Rightarrow$**：按摆法顺序令 $e_k$ 为第 $k$ 根木棍（即编号 $\pi_k$ 的那根），取 $v_0=l_{\pi_1}$、$v_k=r_{\pi_k}\ (1\le k\le m)$。条件 1 由排列 $\pi$ 给出。对 $1\le k\le m-1$，定义 1 说 $r_{\pi_k}=l_{\pi_{k+1}}$，即 $v_k$ 同时是 $e_k$ 的右端与 $e_{k+1}$ 的左端，故 $e_k$ 连 $v_{k-1},v_k$、$e_{k+1}$ 连 $v_k,v_{k+1}$，条件 2 成立；$e_1$ 的两端是 $l_{\pi_1}=v_0$ 与 $r_{\pi_1}=v_1$，同样吻合。条件 3 就是"$\pi$ 是 $1..m$ 的排列"。自环（$p_i=q_i$）时 $v_{k-1}=v_k$，仍是合法的一条边（同一顶点进出，占该顶点 2 个度）。
- **$\Leftarrow$**：给定欧拉通路，把边序列 $e_1..e_m$ 作为木棍的摆放顺序 $\pi$，并令木棍 $e_k$ 的左端 $=v_{k-1}$、右端 $=v_k$（即"按通路方向定向 = 选择是否翻转"，与定义 1 的无序端点相容，因为 $\{l,r\}=\{v_{k-1},v_k\}=\{p_{\pi_k},q_{\pi_k}\}$）。于是 $r_{\pi_k}=v_k$ 恰为 $e_{k+1}$ 的左端 $l_{\pi_{k+1}}$，定义 1 成立。$\blacksquare$

这一步把一道"字符串 + 木棍"的题**彻底塌缩**成图论判定题。之后字符串只剩下"怎么给颜色编号"的工程问题（§2.6）。

### 2.2 特例手玩 —— 判定条件长什么样

| 摆法 | 度数 | 结果 |
|---|---|---|
| 一根 `red blue` | red 1, blue 1 | Possible（一根本身就是一条线） |
| `red blue` + `blue red` | red 2, blue 2 | Possible：`red|blue` 接 `blue|red` |
| 星：`a b`,`a c`,`a d`,`a e` | a 4；b c d e 各 1 | **Impossible**：4 个奇度点 |
| `a b` + `c d`,`c d` | a 1,b 1,c 2,d 2 | 奇度点 2 个，但**分属两块** → Impossible |
| 一根 `red red` | red 2 | Possible（自环度算 2） |

一线串珠只有**两个自由端头**，所以"露单边的颜色"最多两个 —— 这一直是直观；但直观不严格，2.3 给出严格必要条件，2.4 给出充分性。

### 2.3 必要条件

**引理 2** 若 $G$ 有欧拉通路 $v_0,e_1,\dots,e_m,v_m$，则 (a) 奇度顶点数为 $0$ 或 $2$；(b) 所有非孤立顶点属于同一连通块。

**证明：**
(a) 对顶点 $x$，统计点序列中 $x$ 的每次出现 $v_i=x$ 对 $\deg(x)$ 的贡献：第 $i$ 次出现"消耗"边 $e_i$（若 $i\ge1$）与边 $e_{i+1}$（若 $i\le m-1$）。因为每条边恰用一次，把这些贡献加起来恰是把 $x$ 的每条关联边数一次（自环时 $v_{i-1}=v_i=x$ 的两个位置各计 1，合计 2，与自环贡献 2 一致），故
$$\deg(x)=\sum_{i:\,v_i=x}\big(\mathbf 1[i\ge1]+\mathbf 1[i\le m-1]\big).$$
中间出现（$1\le i\le m-1$）每次贡献 $2$；只有 $i=0$ 与 $i=m$ 各贡献 $1$。若 $v_0\ne v_m$，则 $\deg(v_0)$ 与 $\deg(v_m)$ 为奇、其余为偶 → 奇度点恰 $2$ 个；若 $v_0=v_m$，则这两个 $1$ 落在同一个点上凑成偶 → 奇度点 $0$ 个。
（独立性检查：奇度点个数必为偶，由握手引理 $\sum_x\deg(x)=2m$ 为偶，所以绝不会出现"$1$ 个或 $3$ 个奇度点"。）
(b) 非孤立顶点就是某条边的端点，而该边出现在通路中，于是 $x$ 出现在点序列 $v_0..v_m$ 里；点序列上相邻两点之间有边相连，故 $v_0..v_m$ 中出现的点两两经由这些边连通 → 全部非孤立顶点在同一连通块。$\blacksquare$

### 2.4 充分性

**引理 3（回路版，核心）** 若 $G$ 的所有顶点度数为偶，且所有非孤立顶点连通，则 $G$ 有欧拉回路。

**证明（对边数 $m$ 归纳 + Hierholzer 拼接）：**
- $m=0$：空序列即欧拉回路（此时"非孤立顶点连通"是空真，约定平凡成立）。
- **贪心闭迹存在性**：$m\ge1$ 时任取一个度数 $>0$ 的点 $s$，从 $s$ 出发**不走重复边**地走下去，因边数有限，过程必在有限步停止。断言：停止点只能是 $s$。反设停在 $u\ne s$，此时本次是"经一条新边进入 $u$"，故在 $u$ 处已用掉的关联边数 $=2t+1$（$t$ 为之前经过 $u$ 的次数；每次"经过"用掉进出两条，最后一次进入只记 1 条）。但 $\deg(u)$ 为偶，于是还剩 $\deg(u)-(2t+1)\ge1$ 条未用边可离开 —— 与"停在 $u$"矛盾。（自环同样成立：经过自环时该顶点被进出各计一次，"进入 $u$ 后已用边数为奇"仍成立。）故得到一条**闭迹** $C$（起点终点同为 $s$、边不重复）。
- **剩余图仍全偶**：把 $C$ 的边集删掉得 $G'$。$C$ 每经过 $x$ 一次就消耗 $x$ 的 $2$ 条关联边，故 $\deg_{G'}(x)=\deg_G(x)-2\cdot(\#\text{经过次数})$ 仍为偶。
- **每个含边块都碰到 $C$**：设 $H$ 是 $G'$ 的一个含边连通块。取 $H$ 中 $\deg_{G'}>0$ 的点 $z$，则 $\deg_G(z)>0$，即 $z$ 在 $G$ 中非孤立，由连通性假设 $z$ 与 $C$ 上某点在 $G$ 中相连。取该路径，离开 $V(H)$ 的第一条边不在 $G'$ 中（否则它的另一端也在 $H$ 里），故它属于 $C$，于是 $C$ 经过 $H$ 的某个顶点 $x$。
- **归纳拼接**：$H$ 的边数 $\le m-|E(C)|\le m-1<m$，$H$ 非孤立部分连通且全偶，由归纳假设 $H$ 有欧拉回路 $C_H$，且它是闭的，故可从 $x$ 开始写。沿 $C$ 走，**第一次到达 $x$ 时**把 $C_H$ 整段插入（$x$ 出发回到 $x$），继续走完 $C$。各 $H$ 边集互不相交、插入后仍是"边不重复的闭迹"，且每条边要么在 $C$ 中、要么在某块的 $C_H$ 中 → 用满 $m$ 条边。$G'$ 的含边块数有限，插入过程有限终止。所得即 $G$ 的欧拉回路。$\blacksquare$

**引理 4（回路可剪成通路）** 若 $G$ 有欧拉回路，则 $G$ 有欧拉通路。
**证明**：回路是 $v_0,e_1,\dots,e_m,v_m$ 且 $v_m=v_0$。定义 2 只要求"边不重复且覆盖全部边"，不要求 $v_0\ne v_m$，所以直接把这条回路当通路看（等价地：把最后一项 $v_m$ 截去，得到 $v_0,e_1,\dots,e_m,v_{m-1}$，边集不变仍覆盖所有边）。物理上就是"把圈上某根木棍的位置当成线的一端剪开"，摆法照样满足定义 1。$\blacksquare$

**定理（充要条件）** $G$ 有欧拉通路 $\iff$ 非孤立顶点全在同一连通块，且奇度顶点数 $\in\{0,2\}$。
**证明**：必要性即引理 2。充分性分情况：
- $0$ 个奇度点：引理 3 给欧拉回路，引理 4 剪成通路。
- $2$ 个奇度点 $s,t$：新加一条辅助边 $f^*=(s,t)$（可以是与已有边平行的重边）。$s,t$ 度数各 $+1$ 变偶，其余点不变，故图仍全偶；非孤立顶点集合不变、连通性不变。引理 3 给出含 $f^*$ 的欧拉回路。在该回路中找到 $f^*$，**把 $f^*$ 删去并从断口剪开**：回路 $v_0,f^*,v_1,\dots,v_{m}=v_0$ 中设 $f^*$ 位于 $v_j\to v_{j+1}$，则从 $v_{j+1}$ 起绕回一圈到 $v_j$ 结束，得到 $G-f^*$ 中覆盖全部 $m$ 条边的 $v_{j+1},\dots,v_j$，即欧拉通路。
两个分支都构造成功。$\blacksquare$

**充分性证明里的三处"不能省"**

1. **贪心过程一定停得下来**：每步消耗一条新边，边集有限，故至多 $m$ 步必停；"只能停在 $s$"用的是 $\deg(u)$ 为**偶数**，如果图中有奇度点这一步就失效（可能停在奇度点）——这恰好解释了为什么"至多 2 个奇度点"是硬要求。
2. **归纳假设能用到 $H$ 上**：需要 $H$ 满足同样的两条前提——全偶（已证）、非孤立部分连通（$H$ 本身是连通块，去掉其中的孤立点后仍连通，因为 $H$ 里凡 $\deg_{G'}>0$ 的点都在某个含边块中）。且 $|E(H)|\le m-|E(C)|\le m-1<m$（$m\ge1$ 时闭迹 $C$ 至少含 1 条边），严格变小，归纳有限终止。
3. **拼接不破坏"边不重复"**：各 $H$ 的边集互不相交、也都与 $C$ 不交，插入的 $C_H$ 是闭的（从 $x$ 出发回到 $x$），所以插入后仍是一条合法的迹，只是变长了。

**两条条件互相独立（各给一个反例）**

| 只满足奇偶、不满足连通 | 只满足连通、不满足奇偶 |
|---|---|
| `a b`,`a b`,`c d`,`c d` → 四个点度数全是 2，`odd=0`，却是两块 → 无解 | 星 `a b`,`a c`,`a d`,`a e` → 连通，但 `odd=4` → 无解 |

所以判定必须**两条都查**，代码里第 4 步先按根分裂即退出、最后再看 `odd`，顺序无所谓但缺一不可。

**"所有边在同一连通块" vs "所有非孤立顶点在同一连通块"**：两者等价。$\Rightarrow$：边的端点当然在边所在的块里；$\Leftarrow$：若全部非孤立顶点在一块，则每条边的两端都在这一块，特别地任意两条边通过这一块内的路径可达。之所以要说"**非孤立**"，是因为标准连通性要求所有顶点可达，而未出现的颜色 / 出现但没边的颜色（在我们的模型里不存在，但固定顶点域的实现里存在）会把图凭空拆成多块。判定定理的陈述与本代码实现统一采用"非孤立顶点"口径。

### 2.5 退化情形的约定（必须写清楚，否则代码会自相矛盾）

- **$m=0$（空输入）**：没有木棍就没有"线"要拼，奇度点 $0$ 个、非孤立顶点集为空 → 判 `Possible`（空摆法平凡满足定义 1 的 $\forall$ 条件，因为该条件在 $m<2$ 时无约束）。题面"最多 $250000$ 根"未排除 $0$，程序按 `Possible` 走。
- **孤立顶点**：颜色 $c$ 若在输入里**从未出现**，它压根不是 $G$ 的顶点，既不贡献度数也不构成连通块。§2.6 的编号方案里"顶点 = 出现过的字符串"由构造保证，这个坑自动填平；但如果用固定表（比如 26 个字母）当顶点域，就会凭空多出 24 个单点连通块，把答案错判成 `Impossible`。
- **自环（`red red`）**：度数 $+2$、奇偶性不变、不构成新的连通性需求。代码里体现为 $u=v$ 时执行两次 `++deg`。
- **重边**：两根端点颜色完全相同的木棍是平行边，对奇偶性与连通性都是幂等的（第二次 `merge` 直接返回）。

### 2.6 字符串 → 顶点编号

$V\le5\times10^5$，必须把单词映成 $0..V-1$。

**为什么不能直接开数组**：颜色全集 $\sum_{l=1}^{10}26^l=26\frac{26^{10}-1}{25}\approx1.47\times10^{14}$，任何"用字符串本身当下标"的裸数组都不可行，必须有一个字典（discretization / hash / Trie）。

**方案对比（这里 $m=2.5\times10^5$，$V\le5\times10^5$，$L\le10$）**

| 方案 | 时间 | 空间 | 冲突问题 | 结论 |
|---|---|---|---|---|
| `map<string,int>` | $O(VL\log V)\approx5\!\times\!10^5\!\cdot\!10\!\cdot\!19\approx10^8$ 次字符比较 | RB 树节点 $\approx48$B + SSO 串 $\approx32$B → $\sim40$MB | 无（精确比较） | 能过但最慢 |
| `unordered_map<string,int>` | 期望 $O(VL)$，最坏 $O(V^2L)$ | 桶 + 节点 $\sim30$MB | 桶冲突需拉链/再哈希；对抗数据可退化 | 要 `reserve`，仍有风险 |
| 手写哈希（模 $2^{64}$ 滚动哈希 + 开放寻址） | 期望 $O(VL)$ | $\sim2^{21}$ 槽 × 16B $\approx33$MB | **有冲突**：开放寻址必须比较原串（只存哈希不够），否则不同色被并成同色 | 需论证 |
| 字典树 Trie | $O(VL)$ | 见下 | 无损 | 内存尴尬 |
| **27 进制单射码 + 排序离散化** | $O(VL+V\log V)\approx10^7$ | $\sim14$MB | **零冲突**（编码本身单射）+ 离散化用精确相等 | 采用 |

**Trie 的节点上界核算**（标签里有它，值得算清楚为什么不用）：每个不同颜色对应一条根到结点的不同路径，结点总数
$$1+\sum_{v\in V}(\text{该串贡献的新结点数})\le 1+\sum_{v\in V}|s_v|\le 1+L\cdot V\le 1+10\times5\times10^5=5\times10^6+1$$
（更紧的上界是"每个长度一层各 $26^l$"，但受 $V\le5\times10^5$ 限制时 $5\times10^6+1$ 才是决定性的）。若每结点存 `int ch[26]`：$5\times10^6\times26\times4\,\text{B}=5.2\times10^8\,\text{B}\approx500$MB，**远超常规限制**；改左儿子右兄弟（每边存 `ch/to/nx`）约 $20+20+20+5\approx65$MB 可塞，但查询退化成 $O(26L)$。本题只需要"字符串→编号"，不需要公共前缀查询，Trie 的结构优势用不上 → 放弃。

**单射编码（本题的"可证无冲突"方案）**：令
$$K(s)=\sum_{j=0}^{|s|-1} d_j\,27^{|s|-1-j},\qquad d_j=s[j]-\texttt{'a'}+1\in[1,26].$$
- **单射性证明**：设 $K(s)=K(t)=N$，$|s|=a,|t|=b$。
  - *主证（位值唯一性）*：$K(s)$ 正是 $N$ 的 $27$ 进制展开，且首位 $d_0\in[1,26]$ **非零**——而"标准 $B$ 进制展开"的定义就要求首位非零，$N$ 的标准展开唯一，故 $(d_0,\dots,d_{a-1})$ 由 $N$ 唯一决定，于是 $a=b$ 且逐位相同，$s=t$。这里数码取 $1..26$ 而不是 $0..25$ 的全部意义就在于"首位必非零 ⟹ 长度由数值唯一决定"。
  - *校验（区间不交）*：长度 $l$ 的码值范围是 $\big[\sum_{j=0}^{l-1}27^{j},\;26\sum_{j=0}^{l-1}27^{j}\big]=\big[\tfrac{27^{l}-1}{26},\;27^{l}-1\big]$。相邻两档满足 $\min(l{+}1)=\tfrac{27^{l+1}-1}{26}>\tfrac{27^{l+1}-27^{l}}{26}=27^{l}>27^{l}-1=\max(l)$，故 $1..10$ 各长度的取值区间两两不交，与主证一致。
  - $\blacksquare$
  关键点：**数码必须从 $1$ 起**。若按常规 $\texttt{'a'}\to0$ 做 26 进制，则 `a`→$0$、`aa`→$0\cdot26+0=0$ 撞码，不同颜色被并成一个顶点（§4.3 算例 7 给出这种 bug 造成的真实误判）。
- **溢出核算**：最大码值 $=\sum_{j=0}^{9}26\cdot27^{j}=27^{10}-1=3^{30}-1=205\,891\,132\,094\,648\approx2.06\times10^{14}$，而 $\texttt{i64}$ 上界 $2^{63}-1\approx9.22\times10^{18}$，余量约 $4.5\times10^{4}$ 倍。递推 `h=h*27+d` 的中间量单调不减且不超过最终值，故**任何一步都不溢出**，$\texttt{int}$ 则必然溢出（$2\times10^{14}\gg2\times10^{9}$）——这就是本题唯一需要 `i64` 的地方。
- 码值域 $\sim10^{14}$ 仍不能直接开数组，所以再**排序去重离散化**：把 $2m$ 个码排序、`unique`，颜色编号 $=\operatorname{lower\_bound}$ 的位置。这一步用的是整数的精确相等，**不可能引入新的冲突**，因此整条"字符串→编号"链路是无损的。

**如果改用哈希，必须回答的两个问题**（这也是本文不选它的原因）：

1. **桶冲突（数据结构层面）**：无论**拉链**（每桶挂一条链表，冲突就追加，查询时逐条比较）还是**开放寻址**（线性/二次探测，冲突就找下一个空槽，删除要留"墓碑"标记），都必须**在槽里保存原串（或完整的码）并做精确相等比较**。只比"$h\bmod B$"就认定同色是错的——不同字符串被并成同一顶点会同时改变度数的奇偶分组与连通块划分，得到的答案可以朝任意一侧翻错。期望 $O(1)$ 还要求 $B\gg V$（取 $B=2^{21}\approx2V$）并 `reserve`，否则退化到 $O(V)$ / 桶。
2. **码冲突（函数层面）**：滚动哈希如 $h=\sum d_jP^j\bmod 2^{64}$ 只有 $2^{64}$ 个像，而定义域 $\approx1.47\times10^{14}$ 虽小于 $2^{64}$，但 $P$ 取偶数时低位全为 $0$（信息直接丢失）、$P$ 取奇数时长度差 $\le9$ 的串仍可能同余，**没有单射性证明**，必须回到问题 1 做精确比较兜底。相比之下 27 进制编码的"数码非零 + 长度由数值区间决定"两段论证是**可证的单射**，问题 2 被彻底消掉，只剩问题 1 中"整数排序去重"这种绝对可靠的精确比较。

**读入方式**：因为输入没有行数，$m$ 只能在读的过程中确定；`while(cin>>a>>b)` 在 EOF 时 `cin` 进入失败态并退出循环，此时 `m` 即边数。注意**不要**先 `cin>>m` 再循环 $m$ 次——题面没有那个数，读了会把第一根木棍的颜色当成 $m$（`char[]` 读到 `int` 直接失败），全线崩掉。

### 2.7 连通性与并查集

判定定理要"非孤立顶点在同一连通块"。三种实现：BFS/DFS 需邻接表（$2m$ 个 `int` $\approx4$MB，可行）；DSU 只需 $O(V)$ 空间且边来一条合一条，与读入天然融合 → 取 **DSU**。做法：`merge(u,v)` 每条边一次，最后扫 $i=0..V-1$，跳过 $\deg=0$ 的点，比较 `getrt(i)` 是否都等于第一个记录的根。**"跳过未出现的颜色"就是本题最经典的坑**（见 §2.5），而在我们的编号方案里 $0..V-1$ 全部出现过，所以那个 `if(!deg[i]) continue;` 属于"防御性冗余"——但**必须保留**：一旦哪天顶点域换成固定表，少了它就错，而且它恰好把定理的陈述原样抄进代码。

**DSU 的实现细节（不是"显然"）**：若用裸的 `f[getrt(u)]=getrt(v)`，输入形如 `a1 a2 / a2 a3 / a3 a4 / …` 的长链会让 $f$ 退化成一条长度 $V$ 的单向链，最后统一 `getrt` 时递归深度可达 $5\times10^5$ → 爆栈风险。所以加**按大小合并**（`sz[]`），树高被压到 $O(\log V)\le19$，路径压缩下总复杂度 $O(m\alpha)$ 且递归安全。

**为什么"扫一遍根相同"就是定理里的连通性条件**：DSU 的不变量是"两点同根 $\iff$ 已读入的边把它们连在某块里"（合并按边逐条执行，正确性由连通性的传递闭包定义直接给出）。于是"$\forall i,\deg[i]>0: \operatorname{getrt}(i)=rt$"与"所有非孤立顶点在同一连通块"逐字对应，只需取第一个非孤立点的根当 `rt`。若 $\deg[i]=0$ 的点被混进这个循环，它的根是它自己（`iota` 初始化后没被任何边合并过），必然与 `rt` 不等 → 假报错，这正是 §4.3 算例 4 的对照实验。

**自环与重边对 DSU 无害**：`merge(u,u)` 里 `rx==ry` 立即返回，不会污染 `sz`；重边第二次合并同样直接返回，`sz[ry]` 不会重复累加（若写成先 `f[rx]=ry; sz[ry]+=sz[rx]` 再判 `rx==ry`，重边就会把块大小算错，虽然不影响本题判定，但会毁掉"按大小合并"的树高保证）。

**判定的最后一步可以写成 `odd<=2`**：由握手引理 $\sum_x\deg(x)=2m$ 为偶，奇度点个数必为偶（引理 2 已用），故 `odd` 只可能是 $0,2,4,\dots$，`odd<=2` 与 `odd==0||odd==2` 等价。代码里保留显式两值写法，是为了把定理的结论**照抄**进程序，避免依赖"奇偶性一定成对"这一隐性推理。

**规模与类型核算（本题唯一 64 位来源）**

| 量 | 上界 | 类型 | 若不处理 |
|---|---|---|---|
| 颜色码 $K(s)$ | $27^{10}-1\approx2.06\times10^{14}$ | **必须 `i64`** | `int` 溢出 → 不同色撞码 → 结论任意错 |
| 颜色数 $V$ | $5\times10^5$ | `int` | `mxv{500005}` 恰好够 |
| 度数 $\deg[x]$ | $5\times10^5$ | `int` | 富余 |
| `odd`, `m` | $5\times10^5$, $2.5\times10^5$ | `int` | 富余 |
| 输出 | 一个布尔 | — | 无累加、无取模 |

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 备注 |
|---|---|---|---|
| `m` | 木棍根数（边数） | `int`，全局默认 0，EOF 计数 | $\le2.5\times10^5$ |
| `ea[i],eb[i]` | 第 $i$ 根木棍两端的**颜色码** | `i64` 数组，读入时填 | $2\times250005\times8$B=4MB |
| `key[]` | 所有 $2m$ 个码的排序去重表 | `i64`，`sort`+`unique` | `key[0..tot-1]` 即颜色全集 |
| `tot` | 出现过的颜色数 $=V$ | `int`，`unique` 返回值 | 顶点编号 0-based |
| `deg[x]` | 颜色 $x$ 的度数（自环 +2） | `int`，`fill_n(deg,tot,0)` | 奇偶决定 `odd` |
| `f[x]` | DSU 父指针 | `int`，`iota(f,f+tot,0)` | 必须显式初始化成自己 |
| `sz[x]` | 根所在块大小（按大小合并用） | `int`，`fill_n(sz,tot,1)` | 保证树高 $O(\log V)$ |
| `odd` | 奇度顶点计数 | `int`，起 0 | 判定 $\in\{0,2\}$ |
| `rt` | 第一个非孤立点的根，代表"这一块" | `int`，初值 `unset=-114514` | 负哨兵，绝不与合法根 $0..V-1$ 撞 |
| `a[16],b[16]` | 读入单词缓冲 | 局部 `char` | 长度 $\le10$，16 有余量 |

### 4.2 算法步骤

1. **EOF 读入**：`while(cin>>a>>b)`，每根木棍立即 `enc` 成两个 `i64` 存入 `ea[m],eb[m]`，`++m`。
2. **离散化**：把 $2m$ 个码灌进 `key`，`sort` 后 `unique`，`tot` = 颜色数；`iota(f)`、`fill_n(sz,1)`、`fill_n(deg,0)`。
3. **建树**：对每根木棍 $i$，两次 `lower_bound` 得 $u,v$；`++deg[u];++deg[v];`（$u=v$ 时自然 +2）；`merge(u,v)`（按大小合并 + 路径压缩）。
4. **判定**：扫 $i=0..tot-1$，`deg[i]==0` 则 `continue`（只看出现过的顶点）；`deg[i]&1` 则 `++odd`；`rt` 未设则记下 `getrt(i)`，否则要求 `getrt(i)==rt`，不等就立即 `Impossible` 退出。
5. **输出**：`odd==0||odd==2 ? "Possible" : "Impossible"`。

**复杂度**：时间 $O(mL+m\log m)$（排序 $10^6$ 个数 $\approx2\times10^7$ 次比较，`lower_bound` $5\times10^5\cdot19\approx10^7$，DSU $O(m\alpha)$），总约 $3\times10^7$ 基本运算；空间 $O(m)$：$ea,eb$ 4MB + $key$ 4MB + $deg,f,sz$ 6MB $\approx14$MB。**验证状态**：仅手算 7 组自造算例（§4.3），未运行程序、未对拍。

> 题面文件无样例，**无法与官方答案对标**；本环境无编译器，按用户要求未创建 `.cpp/.in`、未运行、未对拍。以下全是手算。

- **算例 1（单根）** `red blue`：码 {red,blue} → $V=2$，$\deg=[1,1]$，`odd=2`，`merge` 后同根 → **Possible**。物理上显然成立，与定理一致。
- **算例 2（两根成环，0 个奇度点）** `red blue` / `blue red`：$\deg[\text{red}]=2$，$\deg[\text{blue}]=2$ → `odd=0`，同一连通块 → **Possible**。摆出来 `red|blue`—`blue|red`，接触端都是 blue ✓。印证引理 4"回路能剪成通路"。
- **算例 3（4 个奇度点，连通）** `a b`,`a c`,`a d`,`a e`：$\deg[a]=4$ 偶，$b,c,d,e$ 各 $1$ → `odd=4>2` → **Impossible**。与"一条线只有两个自由端头"的直觉吻合。
- **算例 4（含未出现的颜色 + 真断开）** `a b`,`c d`,`c d`：$\deg[a]=1,\deg[b]=1,\deg[c]=2,\deg[d]=2$ → `odd=2` 看似合格，但 `merge` 给出两块（根不同）→ **Impossible**。对照实验：若把顶点域固定成 26 个字母且不跳过 $\deg=0$ 的点，则**算例 1 都会被误判**为 `Impossible`（凭空多出 24 个单点块）——这就是 §2.5 那个坑的量化后果。
- **算例 5（同名不同位置复用 + 自环）** `red blue`,`blue red`,`red red`：$\deg[\text{red}]=1{+}1{+}2=4$，$\deg[\text{blue}]=1{+}1=2$ → `odd=0`、$V=2$ 且两点同块 → **Possible**。显式摆法（欧拉通路 棍1→棍2→棍3，点序列 $red,blue,red,red$）：`red|blue` — `blue|red` — `red|red`，两个接触处分别是 blue/blue 与 red/red ✓，自由端 red 与 red 无需相同。本例验证同一颜色名在**不同行的左右两端**都被并成同一个顶点（`red` 出现在棍1 左、棍2 右、棍3 两端），且自环确实 $+2$。
- **算例 6（$m=1$ 自环，退化）** `red red`：$\deg[\text{red}]=2$ → `odd=0`，$V=1$ 单点即连通 → **Possible**（一根两端同色的木棍本身就是一条合法线）。
- **算例 7（"数码必须从 1 起"的反证）** `a x`,`aa y`：正确编码下 $\deg$ 全为 $1$ → `odd=4` 且两块 → **Impossible**。若误用 'a'→0 的 26 进制，则 `a` 与 `aa` 同为码 $0$ 被并成一个顶点 $A$：$\deg[A]=2,\deg[x]=1,\deg[y]=1$ → `odd=2`、连通 → 输出 **Possible（错）**。这条反例证明 §2.6 的单射性论证不是形式主义。
- **溢出/规模自检**：$V\le2m\le5\times10^5$ → `mxv{500005}` 够用；$\deg\le2m=5\times10^5$ 用 `int` 富余；`odd`$\le V$；只有 $K(s)\le2.06\times10^{14}$ 需要 `i64`。答案本身只是一个布尔判定，无累加量。

## 5. 示例代码（C++）

```cpp
// P1333 瑞瑞的木棍
// 木棍=无向边、颜色=顶点：能拼成一条线 == 存在欧拉通路 == 奇度点数∈{0,2} 且非孤立点同块
// 字符串用 27 进制单射编码（数码 1..26），再排序离散化；DSU 按大小合并
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxe{250005};            //木棍数上界 250000+5
constexpr int mxv{500005};            //颜色数上界 2*250000+5
constexpr int unset{-114514};         //哨兵：尚未记录代表根

int m,deg[mxv],f[mxv],sz[mxv];
i64 ea[mxe],eb[mxe],key[mxv];

i64 enc(char*s)                    //h=h*27+d，d∈[1,26] -> 单射，最大 27^10-1≈2.06e14
{
	i64 h=0;
	for(;*s;++s)
		h=h*27+*s-'a'+1;
	return h;
}

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

void merge(int x,int y)
{
	int rx=getrt(x),ry=getrt(y);
	if(rx==ry)
		return;
	if(sz[rx]>sz[ry])                //按大小合并，树高 O(log V)，长链输入不爆栈
		swap(rx,ry);
	f[rx]=ry;sz[ry]+=sz[rx];
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	char a[16],b[16];
	while(cin>>a>>b)                 //行数未知，EOF 驱动
	{
		ea[m]=enc(a);eb[m]=enc(b);
		++m;
	}

	int tot=0;
	for(int i=0;i<m;++i)
	{
		key[tot++]=ea[i];
		key[tot++]=eb[i];
	}
	sort(key,key+tot);
	tot=unique(key,key+tot)-key;     //编号 0..tot-1 恰好就是"出现过的颜色"

	iota(f,f+tot,0);
	fill_n(sz,tot,1);
	fill_n(deg,tot,0);
	for(int i=0;i<m;++i)
	{
		int u=lower_bound(key,key+tot,ea[i])-key;
		int v=lower_bound(key,key+tot,eb[i])-key;
		++deg[u];++deg[v];           //u==v 的同色木棍（自环）恰好 +2
		merge(u,v);
	}

	int odd=0,rt=unset;
	for(int i=0;i<tot;++i)
	{
		if(!deg[i])                  //未出现的颜色不是顶点，不参与连通块计数
			continue;
		if(deg[i]&1)
			++odd;
		if(rt==unset)
			rt=getrt(i);
		else if(getrt(i)!=rt)
		{
			cout<<"Impossible\n";
			return 0;
		}
	}
	cout<<(odd==0||odd==2?"Possible\n":"Impossible\n");
	return 0;
}
```

**代码要点**

- 全局静态数组 + `constexpr` 尺寸（上界 +5）；`f` 必须 `iota` 成自己，`sz` 必须 `fill_n(...,1)`，靠全局默认 0 会直接崩。
- `'\n'` 收尾，无 `endl`；`enc/merge/getrt` 全小写电报式；顶点编号内部 0-based（离散化天然如此）。
- 输出串逐字照抄题面：`Possible` / `Impossible`。
- 若哪天要真的输出摆法，引理 3 的证明就是 Hierholzer 的实现蓝图：存邻接表 + `iter[]` 当前弧，栈上走环再拼接，$O(m)$ 得到通路。
