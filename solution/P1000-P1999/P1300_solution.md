# P1300 [NOISG 2002] 城市街道交通费系统 — 题解

## 1. 重述问题

给定 $h \times w$ 的网格地图（$4 \le h,w \le 30$），每格是障碍物 `.` 或可通行道路 `#`，另有起点（`E`/`W`/`N`/`S`，标记起始朝向）和终点 `F`。最外层一圈全为障碍。

汽车沿道路行驶，**直行免费**；每**左转一次**花 1，每**右转一次**花 5；**调头**花 10，且**仅当直行、左转、右转都无路可走时**才允许调头。

求从起点到终点花费最少的路径的总费用。数据保证存在可达路径。

注意：费用只跟"转弯次数"有关，与走了多少格无关（直行不花钱）。

---

## 2. 思维链（学生视角的发现过程）

### 2.1 探索特殊机制：调头到底什么时候能触发？

"只有当前进、左转、右转都无路可走的时候，调头才是允许的"——这句话很关键。我画一张图来理解。

汽车当前在某格、朝某个方向。考虑它周围 4 个相邻格（前、左、右、后）。"前、左、右无路"意味着前方、左方、右方三个格子都是障碍物（或边界）。由于最外圈是障碍，地图内部的一个可通行格，它的左/右/前/后最多有 4 个邻居。

- 若前方是障碍、左方是障碍、右方是障碍，那只有"后方"可能通行。此时汽车"只能倒车回去"，而倒车不是"调头后再前进"——题目说的"调头"指的是**把车头转 180°**，让车头指向后方，然后（下一状态）向前开。
- 但注意：调头只是改变朝向，**不移动**。所以触发条件应理解为"当前朝向前方无路、左转目标方向无路、右转目标方向无路"，三者同时为障碍时才允许把朝向翻转为相反方向（花 10）。

关键观察：在正常的十字路口（至少 3 个方向可走），左转和右转至少有一个可用，因此**调头不会触发**。只有在**死胡同（一条路走到头，仅后方可走）**里，才会触发调头。

### 2.2 考虑简化版本：完全忽略调头

先不管调头，只允许直行（0 费）、左转（1 费）、右转（5 费）。

- 直行免费意味着：一旦选定一个朝向，沿着这条路一直走到头（或走到需要转弯的岔路口），不花一分钱。
- 费用完全来自"在某个节点选择左转还是右转"的决策。
- 这本质上是一个**带权最短路径问题**：每个状态是"位置 + 朝向"，边权是 0/1/5。

但有个坑：**边权为 0**（直行）。BFS 不能直接用（BFS 要求所有边权相等）。0/1 BFS 也不够（有 5）。**必须用 Dijkstra**。

### 2.3 识别经典技术：Dijkstra 在"位置×朝向"状态图上

状态空间：每个可通行格最多 4 个朝向 → 最多 $30 \times 30 \times 4 = 3600$ 个状态。极小。

从一个状态 $(r,c,d)$（位置 + 朝向 $d$）出发的转移：
- **直行**：若前方 $(r+\Delta_r[d],\, c+\Delta_c[d])$ 可通行，则到 $(r',c',d)$，代价 0。
- **左转**：左朝向 $d_L$，若左方可通行，到 $(r',c',d_L)$，代价 1。
- **右转**：右朝向 $d_R$，若右方可通行，到 $(r',c',d_R)$，代价 5。
- **调头**：仅当前、左、右都不可通行时，允许朝相反方向，代价 10。

这就是标准的 Dijkstra。

### 2.4 关键引理与证明

**引理 1（状态充分性）**：在任意可通行格上，汽车的完整信息仅由"朝向"决定；"来路"不影响未来费用。

*证明*：费用函数仅依赖"本次转向的角度"（直/左/右/调头），与历史路径无关。在给定位置和朝向的情况下，未来所有可选动作及其费用完全确定（取决于该格周围 4 邻的可通行性，这是地图的固有属性）。因此"位置 + 朝向"是充分的马尔可夫状态。∎

**引理 2（调头仅发生在死胡同）**：若某可通行格的前方、左方、右方中至少有一个可通行，则调头操作不会在该格被触发。

*证明*：调头的触发条件是"前、左、右**都**无路可走"。若三者中至少一个可走，条件不满足，调头被禁止。故调头仅在"前、左、右全为障碍（或边界）"时触发，即该格仅后方可能通行——死胡同。∎

**引理 3（调头的可达性与必要性）**：在地图最外圈全为障碍、且存在可行路径的前提下，若一条从起点到终点的最优路径经过某个死胡同，则它在该死胡同的尽头必须调头才能折返。

*证明*：死胡同尽头格的前/左/右均为障碍，仅后方（来路）可通行。汽车到达此格时，直行（前方）、左转（左方）、右转（右方）均不可行，唯一合法动作是调头（花 10），随后沿来路返回。故经过死胡同的最优路径必然包含一次调头。∎

**引理 4（Dijkstra 在此图上正确）**：状态图的所有边权 $\in\{0,1,5,10\}\ge 0$，Dijkstra 算法在含非负边权的图上给出最短路。

*证明*：Dijkstra 的经典正确性。归纳地，每次从未确定集合中取出距离最小的节点 $u$，$u$ 的最终距离已确定（因为任何经未确定节点的替代路径只会更大，边权非负）。0 权边不影响该论证（0 不改变"替代路径不会更短"的结论）。∎

**引理 5（答案 = 所有"到达 F 格的任一朝向"状态中的最小距离）**：汽车到达终点格 $F$ 即算到达终点，无论其朝向为何。

*证明*：题目要求"到达终点"，不限制到达时的朝向。故终点 $F$ 格上 4 个朝向状态的最小距离即为答案。∎

### 2.5 完整算法（含调头）

虽然由引理 2 知道调头只在死胡同发生，但为**完整正确**，我在转移中仍保留调头分支：在状态 $(r,c,d)$，若前、左、右均不可通行且后方可通行，则加一条到 $(r,c,\text{opp}(d))$ 代价 10 的边。

（注：严格读题，调头后汽车仍在原格、朝向相反。下一步可直行（即沿来路返回）。这与"倒车"等价，但用"调头+直行"建模更贴合题意。实际上，由于调头后直行方向=原朝向后方的格子，与"直接倒车"结果相同，两种建模等价。我采用"调头改朝向"的建模。）

### 2.6 验证样例

样例一解释：直行后左转 3 次，最后右转 → $1\times 3 + 5 = 8$。若右转 2 次 → $5\times 2=10$。最优 8。算法会在状态图上找到 8。

样例二解释：最优 7 = "立刻左转(1) + 直行 + 第一个岔路口左转(1) + 右转(5)" = $1+1+5=7$。算法能找到 7。

## 3. 模式总结（按实际思考顺序）

- **探索特殊机制** — 调头触发条件极严（前/左/右全堵），仅在死胡同发生；正常路网不调头。
- **考虑简化版本** — 忽略调头，问题变为"位置×朝向"状态图上的非负边权最短路。
- **识别经典技术** — 边权含 0，BFS 不适用，Dijkstra 适用（状态数仅 3600，极小）。
- **定义状态** — 状态 = (行, 列, 朝向)，4 个朝向，转移 = 直(0)/左(1)/右(5)/调头(10)。
- **保留边界情况** — 虽调头罕发，仍在转移中保留，保证死胡同场景正确。
- **答案提取** — 取终点格 4 个朝向状态的最小距离。

## 4. 真正的解法（代码做了什么）

### 符号表（notion glossary）

| 符号 | 含义 | 初始化 |
|---|---|---|
| $h,w$ | 地图高/宽 | 读入 |
| `grid[r][c]` | 字符网格，`#`/`.`/`E`/`W`/`N`/`S`/`F` | 读入 |
| $sr,sc,sd$ | 起点行/列/朝向 | 读入时定位 |
| $fr,fc$ | 终点行/列 | 读入时定位 |
| 朝向编码 | $0=$北, $1=$东, $2=$南, $3=$西 | — |
| `dx[4],dy[4]` | 各朝行的位移：北(-1,0) 东(0,1) 南(1,0) 西(0,-1) | 常量 |
| `dis[r][c][d]` | 到达 (r,c) 且朝向 d 的最小费用 | $1145141919$（INF） |
| `ok(r,c)` | 格 (r,c) 是否可通行（非 `.`） | 查 `grid` |

记忆口诀：**NEDW = 0,1,2,3**（North-East-South-West）；`dis` 末维是朝向。

### 算法步骤

1. 读入 $h,w$ 和网格，定位起点 $(sr,sc,sd)$ 和终点 $(fr,fc)$。
2. 初始化 `dis[h+2][w+2][4]` 全为 INF。
3. `dis[sr][sc][sd] = 0`；将 $(sr,sc,sd,0)$ 入优先队列（小根堆，按费用）。
4. 循环取堆顶 $(r,c,d,cost)$：
   - 若 $cost > dis[r][c][d]$，跳过（过期条目）。
   - 若 $(r,c)$ 是终点，可记录答案（但最终取 4 朝向最小，故不必在此早退——实际可早退，但取 4 朝向 min 更稳妥；此处选择继续跑到终点 4 态都定，或直接在最后取 min）。
   - 生成 4 类转移（对"直行/左转/右转"，需目标格可通行；对"调头"，需前/左/右全不可通行且后方可通行）：
     - **直行**：目标 $(r+dx[d], c+dy[d])$，朝向不变，权 0。
     - **左转**：目标朝向 $(d+3)\%4$，目标格 $(r+dx[(d+3)\%4], c+dy[(d+3)\%4])$，权 1。
     - **右转**：目标朝向 $(d+1)\%4$，目标格 $(r+dx[(d+1)\%4], c+dy[(d+1)\%4])$，权 5。
     - **调头**：目标朝向 $(d+2)\%4$，仅当直行/左转/右转的目标格都不可通行、且调头目标格可通行时，权 10。
   - 对每条可行转移：若 $cost+w < dis[r'][c'][d']$，更新并入堆。
5. 答案 = $\min_d dis[fr][fc][d]$，输出。

### 复杂度

- 状态数：$h \times w \times 4 \le 3600$。
- 每状态至多 4 条转移 → 边数 $\le 14400$。
- Dijkstra：$O(E \log V) \le 14400 \times \log 3600 \approx 1.8\times 10^5$，极快。
- 空间：$dis$ 数组 $32\times32\times4$ int，可忽略。

### 验证状态

- 样例一：算法应输出 8（左转3次+右转1次 = $3\times1+5=8$）。
- 样例二：算法应输出 7（左1+左1+右5）。
- 死胡同场景：调头分支覆盖，保证折返路径被计算（花 10）。
- 最外圈全障碍 → 边界格不可通行，`ok()` 自然排除，无需特判。
- 状态数极小（3600），无 TLE 风险；INF 取 $1145141919$ 远大于任何真实费用（最大可能费用：每步最多 10，步数远小于 3600，总费用 < 40000）。

## 5. 示例代码（C++）

```cpp
// https://www.luogu.com.cn/problem/P1300
// P1300 城市街道交通费系统
// Dijkstra on (row, col, dir) state graph.
// dir: 0=N 1=E 2=S 3=W; cost: straight=0 left=1 right=5 U-turn=10

#include<bits/stdc++.h>
using namespace std;

constexpr int mxh{35},mxw{35};          // h,w <= 30, +5 slack
constexpr int inf{1145141919};          // 远大于任何真实费用

int h,w;
char grid[mxh][mxw];
int sr,sc,sd,fr,fc;
int dx[4]={-1,0,1,0};                   // N E S W
int dy[4]={0,1,0,-1};
int dis[mxh][mxw][4];

bool ok(int r,int c){
	if(r<0||c<0||r>=h||c>=w)
		return 0;
	return grid[r][c]!='.';
}

// 从 (r,c) 朝 d 出发，看方向 nd 的相邻格是否可通行
bool can(int r,int c,int nd){
	return ok(r+dx[nd],c+dy[nd]);
}

void dij()
{
	for(int r=0;r<h;++r)
		for(int c=0;c<w;++c)
			for(int d=0;d<4;++d)
				dis[r][c][d]=inf;

	priority_queue<tuple<int,int,int,int>,vector<tuple<int,int,int,int>>,greater<>>Q;
	dis[sr][sc][sd]=0;
	Q.emplace(0,sr,sc,sd);

	while(!Q.empty())
	{
		auto[cost,r,c,d]=Q.top();Q.pop();
		if(cost>dis[r][c][d])
			continue;

		// 直行：权 0
		int nf=d;
		if(can(r,c,nf))
		{
			int nr=r+dx[nf],nc=c+dy[nf];
			if(cost<dis[nr][nc][nf])
			{
				dis[nr][nc][nf]=cost;
				Q.emplace(cost,nr,nc,nf);
			}
		}

		// 左转：权 1
		nf=(d+3)%4;
		if(can(r,c,nf))
		{
			int nr=r+dx[nf],nc=c+dy[nf];
			if(cost+1<dis[nr][nc][nf])
			{
				dis[nr][nc][nf]=cost+1;
				Q.emplace(cost+1,nr,nc,nf);
			}
		}

		// 右转：权 5
		nf=(d+1)%4;
		if(can(r,c,nf))
		{
			int nr=r+dx[nf],nc=c+dy[nf];
			if(cost+5<dis[nr][nc][nf])
			{
				dis[nr][nc][nf]=cost+5;
				Q.emplace(cost+5,nr,nc,nf);
			}
		}

		// 调头：权 10，仅当前/左/右全不可通行且后方(调头朝向)可通行
		nf=(d+2)%4;
		if(!can(r,c,d)&&!can(r,c,(d+3)%4)&&!can(r,c,(d+1)%4)&&can(r,c,nf))
		{
			int nr=r+dx[nf],nc=c+dy[nf];
			if(cost+10<dis[nr][nc][nf])
			{
				dis[nr][nc][nf]=cost+10;
				Q.emplace(cost+10,nr,nc,nf);
			}
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>h>>w;
	for(int r=0;r<h;++r)
	{
		string s;
		cin>>s;
		for(int c=0;c<w;++c)
		{
			grid[r][c]=s[c];
			if(grid[r][c]=='E'){sr=r;sc=c;sd=1;grid[r][c]='#';}
			else if(grid[r][c]=='W'){sr=r;sc=c;sd=3;grid[r][c]='#';}
			else if(grid[r][c]=='N'){sr=r;sc=c;sd=0;grid[r][c]='#';}
			else if(grid[r][c]=='S'){sr=r;sc=c;sd=2;grid[r][c]='#';}
			else if(grid[r][c]=='F'){fr=r;fc=c;}
		}
	}

	dij();

	int ans=inf;
	for(int d=0;d<4;++d)
		ans=min(ans,dis[fr][fc][d]);

	cout<<ans<<'\n';
	return 0;
}
```

### 代码要点说明

- **状态**：`(row, col, dir)`，`dir` 编码 N=0,E=1,S=2,W=3。
- **`dis` 初始化**：全填 `inf`（全局数组默认是 0，**必须显式填 INF**，否则 0 会被当成可达零费用——这是本风格指南特别强调的坑）。
- **调头条件**：`!can(d) && !can(left) && !can(right) && can(opp)`——前三者全堵、后方通，才允许。这精确对应题意"前/左/右都无路才调头"。
- **早退**：未做（直接跑完 Dijkstra 取 4 朝向 min），状态数极小，无性能损失，逻辑更简单。
- **起点处理**：读入时把 `E/W/N/S` 改成 `#`（可通行），并记录起始朝向。
- **`can` 函数**：统一判断"从 (r,c) 朝 nd 走一步是否落在可通行格"，边界由 `ok` 的 `r<0||r>=h` 等排除（最外圈本是障碍，双重保险）。
