# P1858 多人背包

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $K$ 个人、$N$ 种物品，每个人背包容量都是 $V$。第 $i$ 种物品体积 $w_i$、价值 $v_i$，每个背包里每种物品**最多放一件**（不同背包之间互相独立）。

要求每个人背包的**总体积恰好等于** $V$，且任意两个人的物品清单不能完全相同。问在满足这些条件时，所有背包里物品的总价值最大是多少。

等价地说：求出 01 背包在“体积恰好为 $V$”约束下的**前 $K$ 优方案**（不同方案按物品集合区分，允许价值相同），输出这 $K$ 个方案的价值之和。

### 1.2 关键约束与规模暗示

- $K\le 50,\ V\le 5000,\ N\le 200$。
- 若只求最优解，就是 $O(NV)$ 的 01 背包；这里要求前 $K$ 优，每个容量状态需要保留 $K$ 个候选值，总复杂度 $O(NVK)$。
- 最大运算量约 $200\times5000\times50=5\times10^7$，一维 DP 加手写归并即可。
- “体积恰好为 $V$”决定了初值：只有 $dp[0]$ 合法，其余为负无穷，而不是全部为 $0$（全部为 $0$ 会把“不满”也当合法）。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把“前 K 优”变成一个状态

标准 01 背包中，$dp[j]$ 表示容量为 $j$ 时的最大价值。现在一个 $dp[j]$ 不够，因为第 $2$ 到第 $K$ 优的方案后面也可能加上同一件物品，变成某个更大容量的第若干优方案。

于是把状态升级为：$dp[j][1..K]$ 表示**体积恰好为 $j$** 的所有可行方案中，价值从大到小排前 $K$ 的 $K$ 个值（不足 $K$ 个的位置填负无穷）。

关键问题是：这样只保留前 $K$ 个，会不会丢掉某个真正的全局前 $K$ 方案？

**引理 1（截断引理）**：考虑在已处理的前 $i$ 件物品上做决策。若有某个方案价值为 $x$，且 $x$ 在 $dp[j]$ 中排在第 $K$ 名之后，那么它与任何后续物品组合后，都不可能进入最终某个容量的前 $K$ 名。

**证明**：对某个固定容量 $j$，设 $dp[j]$ 中的值降序为 $a_1\ge a_2\ge\cdots$。设该方案值为 $a_t\ (t>K)$。之后所有物品的选择对“使用同一后续选择”的所有方案是**同一个加量**：即若两个方案都选择同样的一组后续物品，它们的价值都加上同一个数 $S$。考虑所有用同一组后续物品 $S$ 形成的方案：它们相对大小不变，$a_t+S\le a_K+S$，而 $a_K+S$ 已经是一个合法方案的价值。同时还有 $K-1$ 个 $a_1+S,\dots,a_{K-1}+S$ 排在它前面（或相等）。因此在“该组后续物品 $S$”这一分支里，$a_t+S$ 至少被 $K$ 个可行方案压住或打平，不可能进入全局前 $K$（打平时取任意 $K$ 个即可，和不变）。对不同 $S$ 分支，各自至多贡献自己的前 $K$ 名，全局前 $K$ 也只需各分支前 $K$。$\blacksquare$

### 2.2 转移：两个有序表的归并

处理第 $i$ 件物品（体积 $w$、价值 $v$）时，容量 $j$ 的最优方案分两类：

- **不选**这件物品：候选集合就是旧的 $dp[j]$；
- **选**这件物品：价值为（旧的 $dp[j-w]$ 中每个方案）$+v$。

因为 $dp[j]$ 与 $dp[j-w]$ 都已经是降序的前 $K$ 名，两类候选各自有序。把它们**归并**并取前 $K$ 名即可。

**引理 2（归并正确性）**：$dp[j]$ 的新前 $K$ 名，等于 $\{dp[j]\text{ 旧值}\}\cup\{dp[j-w]\text{ 旧值}+v\}$ 中最大的 $K$ 个。

**证明**：任意一个用到第 $i$ 件物品的方案，去掉这件物品后是前 $i-1$ 件物品在容量 $j-w$ 上的一个可行方案；反之任意这样的方案加上物品就是合法方案（体积刚好补齐）。故“选”类候选集恰为旧 $dp[j-w]$ 全体平移 $v$；“不选”类恰为旧 $dp[j]$ 全体。两集合的并的前 $K$ 大，只需各自的前 $K$ 大参与归并：若某集合中第 $K$ 名之后的元素 $x$ 入选了并集前 $K$，则同集合中至少有 $K$ 个元素不小于 $x$，矛盾。$\blacksquare$

### 2.3 遍历顺序：为什么容量要倒序

与 01 背包一样，容量 $j$ 必须**从大到小**枚举。若正序，$dp[j-w]$ 可能已经在本轮被第 $i$ 件物品更新过，等于允许同一件物品被选多次，变成完全背包。

**引理 3（倒序的必要性）**：正序遍历时，存在输入使答案被高估。

**证明（反例）**：$V=2$，一件物品 $w=1,v=1$，$K=1$。正序：$dp[1]$ 由 $dp[0]$ 更新为 $1$；再算 $dp[2]$ 时用已更新的 $dp[1]=1$，得到 $2$，等于把同一件物品用了两次。倒序时 $dp[2]$ 先由 $dp[1]=-\infty$ 更新（失败），$dp[1]$ 才由 $dp[0]=0$ 更新为 $1$，答案 $dp[2]$ 非法。$\blacksquare$

### 2.4 初值与“恰好”

**引理 4**：若要求体积恰好为 $j$，初始只能是 $dp[0][1]=0$，其余全部 $-\infty$。

**证明**：$-\infty$ 表示“不可达”，任何 $-\infty$ 加上有限值仍是 $-\infty$，不会污染；若把其余初值设为 $0$，则空方案会被当作所有容量的合法方案，$dp[V]$ 会退化为“至多 $V$”的答案。$\blacksquare$

### 2.5 最终答案

所有 $K$ 个人对应 $K$ 个互不相同的方案，因此答案就是 $dp[V]$ 中前 $K$ 个合法值之和。若数据保证至少存在 $K$ 个方案，则恰好取满 $K$ 个；实现时跳过 $-\infty$ 以防越界。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 前 $K$ 优可以按容量状态截断保存，每个状态只留 $K$ 个值。
- **classic problem solution** — 01 背包的“选/不选”两类候选各自有序，归并取前 $K$。
- **exchange/dominance argument** — 第 $K$ 名之后的方案无论怎么加后续物品都进不了前 $K$（截断引理）。
- **classic problem solution** — 容量倒序遍历保证每件物品只用一次。
- **initialization discipline** — “恰好装满”用 $-\infty$ 作不可达标记，只有 $dp[0][0]=0$。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `K,V,N` | `int` | 人数 / 容量 / 物品种数 | 读入 | 维度 |
| `w[i],v[i]` | `int [205]` | 第 $i$ 种物品体积、价值 | 读入 | weight / value |
| `dp[j][k]` | `int [5005][55]` | 体积恰为 $j$ 的第 $k$ 优方案价值（降序） | 只有 `dp[0][0]=0`，其余 `-inf` | K-best |
| `tmp[55]` | `int` | 归并临时数组 | 每轮清零为 `-inf` | merge buffer |
| `ans` | `i64` | 前 $K$ 优价值之和 | 0 | 输出 |

### 4.2 算法步骤

1. 读入 $K,V,N$ 及 $N$ 件物品。
2. 把 `dp` 全部填 `-inf`，`dp[0][0]=0`。
3. 对每件物品 $(w,v)$：
   - 对 $j=V$ 从大到小，且 $j\ge w$：
     - 用双指针归并 `dp[j]` 与 `dp[j-w]+v`（后者逐项加 $v$），把前 $K$ 大写入 `tmp`；
     - 把 `tmp` 拷回 `dp[j]`。
4. 累加 `dp[V][0..K-1]` 中不等于 `-inf` 的值，输出。

### 4.3 复杂度分析

- 时间：$O(NVK)$，最大约 $5\times10^7$。
- 空间：$O(VK)$，约 $5005\times55$ 个 `int`。

## 5. 示例代码

```cpp
//
// 题目：P1858 多人背包
// https://www.luogu.com.cn/problem/P1858
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{205};
constexpr int mxv{5005};
constexpr int mxk{55};
constexpr int ninf{-1145141919};

int K,V,N;
int w[mxn],v[mxn];
int dp[mxv][mxk];
int tmp[mxk];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>K>>V>>N;
	for(int i=0;i<N;++i)
		cin>>w[i]>>v[i];

	for(int j=0;j<=V;++j)
		fill_n(dp[j],K,ninf);
	dp[0][0]=0;

	for(int i=0;i<N;++i)
	{
		for(int j=V;j>=w[i];--j)
		{
			fill_n(tmp,K,ninf);
			int a{0},b{0},t{0};
			// a 指向 dp[j]（不选），b 指向 dp[j-w]（选，加 v[i]）
			while(t<K&&(a<K||b<K))
			{
				int x=(a<K?dp[j][a]:ninf);
				int y=(b<K&&dp[j-w[i]][b]>ninf?dp[j-w[i]][b]+v[i]:ninf);
				if(x>=y)
				{
					tmp[t++]=x;
					++a;
				}
				else
				{
					tmp[t++]=y;
					++b;
				}
			}
			copy_n(tmp,K,dp[j]);
		}
	}

	i64 ans{0};
	for(int k=0;k<K;++k)
		if(dp[V][k]>ninf/2)
			ans+=dp[V][k];
	cout<<ans<<'\n';
	return 0;
}
```
