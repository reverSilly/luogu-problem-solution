# P1876 开灯

> 难度：入门 · 标签：因数个数 / 完全平方数

## 1. 重新读题

### 1.1 问题重述（人话版）

灯 $1..N$ 一开始全是关的。第 $k$ 个人把所有编号是 $k$ 的倍数的灯拨一次（开变关，关变开），$k$ 从 $1$ 走到 $N$。问最后哪些灯还亮着。

### 1.2 关键约束与规模暗示

- $1\le N\le 2^{40}$。$2^{40}=1099511627776$，放得进 64 位有符号整数，但绝对不能开数组模拟。
- 亮着的灯的个数大约是 $\sqrt N\le 2^{20}$，输出大约一百万个数，这是输出量，不是算法量。
- 背景已经暗示：想通了代码会很短。

## 2. 思维链（Chain-of-thought）

### 2.1 每盏灯被拨几次

**引理 1**。灯 $i$ 被拨动的次数等于 $i$ 的正因数个数。

**证明**。第 $k$ 个人拨动灯 $i$，当且仅当 $k\mid i$。$k$ 的范围是 $1..N$，而 $i\le N$，所以 $i$ 的每个正因数都会恰好来拨一次，其他 $k$ 不会。$\square$

灯初始是关的，拨奇数次后是开的。所以答案是 $[1,N]$ 中因数个数为奇数的那些 $i$。

### 2.2 因数个数为奇数的数就是完全平方数

**引理 2**。正整数 $i$ 的正因数个数为奇数，当且仅当 $i$ 是完全平方数。

**证明**。因数可以配成 $(d,i/d)$。若 $d\neq i/d$，这一对是两个不同的因数。若 $i$ 不是平方，则不存在 $d=i/d$，所有因数都成对出现，个数为偶数。若 $i=k^2$，则 $d=k$ 自己和自己配成一对，这一位只算一个因数，其余仍成对，总数为奇数。$\square$

因此答案就是所有 $k^2\le N$ 的 $k^2$，从小到大。

### 2.3 循环时不要让 $k\cdot k$ 溢出

$N\le 2^{40}$ 时 $k\le 2^{20}$，$k^2$ 仍在 `long long` 里。写成 `for(i64 i=1;i<=n/i;++i)` 更稳：用除法判断 $i^2\le n$，不先做可能溢出的乘法。$i$ 从 $1$ 开始，$n/i$ 有定义。

当 $i^2=n$ 时 $i=n/i$，这一项会被输出，然后 $i$ 再增大就退出。所以 $N$ 本身是平方数时不会漏。

暴力对照不去找平方数，而是对 $N\le 8\times 10^4$（数组开到 $2\times 10^6$）做经典模拟：第 $p$ 个人给 $p,2p,3p,\ldots$ 的计数加一，最后输出计数为奇数的编号。这和「直接打印平方」不是同一段代码。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 灯 $i$ 被拨的次数 $=$ 因数个数，亮着当且仅当这个次数是奇数。
- **number theory** — 因数成对，只有平方数会多出一个配对自己的因数。
- **consider easier version** — 小 $N$ 用倍数翻转计数，拿来对拍。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `i64` | 灯的数量兼轮数 | 读入 | N |
| `i` | `i64` | 当前根 | 从 $1$ 增加 | root |
| `fst` | `bool` | 是否还没输出过数 | `true` | first |

### 4.2 算法步骤

1. 读入 $N$。
2. $i=1,2,3,\ldots$，只要 $i\le N/i$，就输出 $i\cdot i$，数与数之间一个空格。
3. 最后换行。$N\ge 1$ 时至少有 $1$，不会输出空行。

### 4.3 复杂度与验证状态

- **时间**：$O(\sqrt N)$，只花在输出上。
- **空间**：$O(1)$。
- **沙箱对拍**：`g++ -O2 -std=c++17 -Wall -Wextra` 零警告。样例 $N=5$ 输出 `1 4`。共 $71$ 组（含 $1$、完全平方边界、$N=99991$ 以及 $N\le 8\times 10^4$ 的随机）与倍数计数暴力逐字符一致。$N=2^{40}$ 标程耗时 $0.2861\text{ s}$，输出与按 $k^2$ 在 Python 里生成的序列一致。

## 5. 示例代码

### 5.1 标程（`P1876.cpp`）

```cpp
//
// 题目：P1876 开灯
// https://www.luogu.com.cn/problem/P1876
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	i64 n;
	cin>>n;
	bool fst=true;
	for(i64 i=1;i<=n/i;++i)
	{
		if(!fst)
			cout<<' ';
		fst=false;
		cout<<i*i;
	}
	cout<<'\n';
	return 0;
}
```
