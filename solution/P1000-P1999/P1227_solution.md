# P1227 [JSOI2008] 完美的对称 — 题解

## Part 1 · 重述题意

给定 $n$ 个互不相同的整点 $P_i=(x_i,y_i)$（$1\le n\le 20000$，$|x_i|,|y_i|\le 10^5$）。

问：是否存在一个点 $S$，使得点集 $\{P_1,\dots,P_n\}$ 关于 $S$ 中心对称？

- "关于 $S$ 中心对称" 的定义：对集合中任一点 $A$，其像点 $A'=2S-A$（即 $S$ 是线段 $AA'$ 的中点）也必须在集合中，且像点集合等于原集合。
- 若存在，输出 $S$ 的坐标（四舍五入保留一位小数），格式为 `V.I.P.  should  stay  at (x,y).`。
- 若不存在，输出 `This is a dangerous situation!`。

**关键约束回顾：**

| 量 | 范围 |
|---|---|
| $n$ | $1\le n\le 20000$ |
| $x_i,y_i$ | $-10^5\le x_i,y_i\le 10^5$（整数） |
| 任意两点 | 互不相同 |
| 点可与中心重合 | 允许 |

## Part 2 · 思维链（发现叙事）

### 2.1 探索性质：中心对称到底意味着什么？

先抛开"求中心"，只看"验证一个 $S$ 是否为中心"。

定义：$S$ 是点集 $X$ 的中心 $\iff$ 对 $X$ 中每个点 $A$，像点 $A'=2S-A$ 也在 $X$ 中，且像点集合 $=\!X$（集合相等）。

由于所有点互异，映射 $A\mapsto 2S-A$ 是 $X$ 上的一个**对合**（involution）：应用两次回到自身（$2S-(2S-A)=A$）。所以"像点集合等于 $X$" 等价于 "每个点的像点仍在 $X$ 中"——对合在有限集上是双射，只要良定义就是双射。

> **性质 1（对合闭包）：** $S$ 是中心 $\iff$ 对每个 $A\in X$，$2S-A\in X$。

这把"求 $S$"的问题暂时放一边，先看看能不能**缩小 $S$ 的候选范围**。

### 2.2 简化版：如果能直接算出 $S$，问题就变成验证

直觉：对称中心应该和"所有点的平均位置"有关。试着把所有点加起来。

设 $X=\{P_1,\dots,P_n\}$，$S$ 是中心。则 $X$ 的像集 $\{2S-P_1,\dots,2S-P_n\}=X$（集合相等）。两边求坐标和：

$$\sum_{i=1}^n (2S-P_i) \;=\; \sum_{i=1}^n P_i$$

左边 $= 2nS - \sum P_i$，所以：

$$2nS - \sum P_i = \sum P_i \quad\Longrightarrow\quad 2nS = 2\sum P_i \quad\Longrightarrow\quad S = \frac{1}{n}\sum_{i=1}^n P_i$$

> **引理 1（重心性质）：** 若 $S$ 是点集 $X$ 的中心，则 $S=\dfrac{1}{n}\sum_{i=1}^n P_i$（即 $S$ 必为重心）。

**证明：** 如上推导。像集等于原集 $\Rightarrow$ 坐标和相等 $\Rightarrow$ $2nS-\sum P_i=\sum P_i$ $\Rightarrow$ $S=(1/n)\sum P_i$。$\blacksquare$

这一步极其关键：**中心（若存在）被唯一确定为重心**。我们甚至不需要"猜" $S$，直接算出来就行。

### 2.3 唯一性：由引理 1 立得

> **引理 2（唯一性）：** 若中心存在，则唯一。

**证明：** 由引理 1，任何中心都必须等于 $(1/n)\sum P_i$，这是一个确定的点。所以至多一个中心。$\blacksquare$

于是整个问题的结构变成了：

1. 算出候选中心 $S^*=(\bar{x},\bar{y})=(\frac{\sum x_i}{n},\frac{\sum y_i}{n})$。
2. 验证 $S^*$ 是否真的是中心（即是否满足性质 1）。
3. 若是，输出 $S^*$；若否，输出危险信息。

### 2.4 整数障碍：候选中心的坐标可能不是整数

$S^*$ 的坐标是 $\bar{x}=\frac{s_x}{n}$，$s_x=\sum x_i$。$s_x$ 是整数，$n$ 是整数，但 $\bar{x}$ 不一定是整数。

而每个点的像点 $2S^*-P_i$ 的坐标是：

$$2\bar{x}-x_i = \frac{2s_x}{n}-x_i = \frac{2s_x-nx_i}{n}$$

由于 $x_i$ 是整数，$\frac{2s_x-nx_i}{n}$ 是整数 $\iff$ $\frac{2s_x}{n}$ 是整数 $\iff$ $n\mid 2s_x$。

> **引理 3（整除条件）：** 若 $S^*$ 是中心，则 $n\mid 2s_x$ 且 $n\mid 2s_y$。

**证明：** 对任意 $P_i=(x_i,y_i)\in X$，其像点 $P_i'=(\frac{2s_x}{n}-x_i,\frac{2s_y}{n}-y_i)$ 必须在 $X$ 中，故坐标必须是整数。因为 $x_i$ 是整数，$\frac{2s_x}{n}-x_i$ 是整数 $\iff$ $\frac{2s_x}{n}$ 是整数 $\iff$ $n\mid 2s_x$。$y$ 方向同理。$\blacksquare$

**推论：** 若 $n\nmid 2s_x$ 或 $n\nmid 2s_y$，直接判定无中心，无需再做任何检查。

当整除条件成立时，令 $c_x=\frac{2s_x}{n}$，$c_y=\frac{2s_y}{n}$（均为整数），则像点公式简化为：

$$P_i' = (c_x - x_i,\; c_y - y_i)$$

这是一个**整数坐标**的映射，非常干净。

### 2.5 闭包检查：转化为集合成员查询

> **引理 4（闭包判定）：** 设 $c_x=2s_x/n$，$c_y=2s_y/n$ 均为整数（即引理 3 条件成立）。则 $S^*=(s_x/n,s_y/n)$ 是中心 $\iff$ 对每个 $P_i=(x_i,y_i)$，点 $(c_x-x_i,c_y-y_i)$ 也在点集中。

**证明：**
- （$\Rightarrow$）若 $S^*$ 是中心，由性质 1，每个 $P_i$ 的像点 $2S^*-P_i=(c_x-x_i,c_y-y_i)$ 必在 $X$ 中。
- （$\Leftarrow$）若对每个 $P_i$，$(c_x-x_i,c_y-y_i)\in X$，则映射 $f:X\to X$，$f(x_i,y_i)=(c_x-x_i,c_y-y_i)$ 良定义。验证 $f$ 是对合：$f(f(x_i,y_i))=f(c_x-x_i,c_y-y_i)=(c_x-(c_x-x_i),c_y-(c_y-y_i))=(x_i,y_i)$。对合在有限集上是双射，所以像集 $=X$。又 $f$ 正是关于 $S^*$ 的中心对称（$2S^*=(c_x,c_y)$，$f(P)=2S^*-P$）。故 $S^*$ 是中心。$\blacksquare$

**算法核心：** 把点集放入哈希/平衡结构，对每个点做一次成员查询，$O(n)$ 次。

**特殊情况（$n$ 为奇数）：** 对合在奇数集上必有一个不动点。不动点 $P^*$ 满足 $P^*=f(P^*)$，即 $P^*=(c_x/2,c_y/2)=(s_x/n,s_y/n)=S^*$。所以 $S^*$ 本身必须在点集中。我们的闭包检查自动覆盖此情况：若 $S^*\in X$，则 $f(S^*)=S^*$，查询通过；若 $S^*\notin X$，则 $S^*$ 的像点 $=S^*$ 不在 $X$ 中——但等等，$S^*$ 不在 $X$ 中，我们不会去查 $S^*$ 的像点。

让我更仔细地想：$n$ 为奇数时，$n\mid 2s_x$ 意味着 $n\mid s_x$（因为 $\gcd(n,2)=1$），所以 $s_x/n$ 是整数，$S^*$ 是整点。闭包检查对 $X$ 中每个点 $P_i$ 查 $(c_x-x_i,c_y-y_i)$ 是否在 $X$ 中。如果 $S^*\notin X$，那么 $X$ 中所有点都成对出现（$P_i$ 和 $f(P_i)$ 不同），但 $n$ 是奇数，奇数个元素无法两两配对，矛盾——必有一个 $P_i$ 使得 $f(P_i)\notin X$，检查失败。所以闭包检查对奇数 $n$ 也是完备的。$\blacksquare$

### 2.6 输出舍入：避免浮点误差

需要输出 $S^*=(s_x/n,s_y/n)$ 四舍五入到一位小数。

直接用浮点 `sx/n` 再 `setprecision(1)` 有精度风险（$s_x$ 可达 $2\times10^9$，除以 $n$ 后的二进制表示可能恰好落在舍入边界上）。

**整数舍入法：** 设 $v=s_x\cdot 10$（$|v|\le 2\times10^{10}$，$i64$ 安全）。求 $t=\text{round}(v/n)$（四舍五入到整数）。则答案为 $t/10$，一位小数。

对 $v\ge 0$：$t=(v+n/2)/n$（整数除法，实现"半数入"）。
对 $v<0$：取 $t=-\text{round}(|v|/n)=-(|v|+n/2)/n$（四舍五入方向远离零，符合中文"四舍五入"）。

输出时：若 $t=0$ 则不打印负号（避免 $-0.0$）；否则打印 `sign` + $|t|/10$ + `.` + $|t|\bmod 10$。

## Part 3 · 模式总结

按实际思考顺序：

- **探索性质** — 中心对称 = 对合闭包：$S$ 是中心 $\iff$ 每个点的像点 $2S-P$ 仍在集合中。
- **考虑简化版** — 若已知 $S$，问题只剩验证；但能否直接算出 $S$？把所有点坐标相加 → 重心。
- **经典技巧（重心唯一性）** — 像集 = 原集 $\Rightarrow$ 坐标和相等 $\Rightarrow$ $S=(1/n)\sum P_i$，中心被唯一确定。
- **整数障碍分析** — 像点坐标 $\frac{2s_x}{n}-x_i$ 必须是整数 $\Rightarrow$ 必要条件 $n\mid 2s_x$、$n\mid 2s_y$；不满足则直接判无中心。
- **归约为集合查询** — 满足整除条件后，像点 = $(c_x-x_i,c_y-y_i)$（整数坐标），闭包检查 = 对每个点做一次集合成员查询。
- **经典技巧（哈希/平衡树成员查询）** — $O(n)$ 次查询，总 $O(n\log n)$。
- **整数舍入输出** — 避免浮点误差，用 $t=\text{round}(10s_x/n)$ 的整数算术实现四舍五入到一位小数。

## Part 4 · 正式解法

### 4.1 符号表

| 符号 | 类型 | 含义 | 初始化 |
|---|---|---|---|
| `n` | `int` | 点的个数 | 读入 |
| `xs[i]` | `i64` | 第 $i$ 个点的 $x$ 坐标（$0$-based） | 读入 |
| `ys[i]` | `i64` | 第 $i$ 个点的 $y$ 坐标（$0$-based） | 读入 |
| `sx` | `i64` | $\sum_i x_i$（$x$ 坐标和） | $0$，累加 |
| `sy` | `i64` | $\sum_i y_i$（$y$ 坐标和） | $0$，累加 |
| `S` | `set<pair<i64,i64>>` | 点集（用于成员查询） | 逐个插入 |
| `cx` | `i64$ | $2s_x/n$（像点公式的 $x$ 常数项） | 计算 |
| `cy` | `i64$ | $2s_y/n$（像点公式的 $y$ 常数项） | 计算 |

**记忆助记：** `c` = center-doubled（$2S$ 的坐标），像点 $= (c_x - x,\; c_y - y)$。

### 4.2 算法步骤

1. **读入** $n$ 个点，累加 $s_x$、$s_y$，将每个点插入集合 $S$。
2. **整除检查**：若 $2s_x \bmod n\ne 0$ 或 $2s_y \bmod n\ne 0$，输出 `This is a dangerous situation!`，结束。
3. **计算像点常数**：$c_x=2s_x/n$，$c_y=2s_y/n$（此时均为整数）。
4. **闭包检查**：对每个点 $(x_i,y_i)$，查询 $(c_x-x_i,\;c_y-y_i)$ 是否在 $S$ 中。若任一查询失败，输出危险信息，结束。
5. **整数舍入输出**：
   - 对 $s_x$、$s_y$ 各执行：$v=10\cdot s$；$\text{sgn}=\text{sign}(v)$；$t=\lfloor(|v|+n/2)/n\rfloor$。
   - 输出 `V.I.P.  should  stay  at (` + $\text{fmt}(t_x)$ + `,` + $\text{fmt}(t_y)$ + `).`，其中 $\text{fmt}(t)$ 输出 $\text{sign}$ + $t/10$ + `.` + $t\bmod 10$（$t=0$ 时省略负号）。

### 4.3 复杂度

- **时间**：$O(n\log n)$（$n$ 次集合插入 + $n$ 次查询，红黑树 $\log n$）。
- **空间**：$O(n)$（集合存储 $n$ 个点）。

### 4.4 验证状态

- $n=1$：单点，$c_x=2x_0$，像点 $=(2x_0-x_0,\cdot)=(x_0,\cdot)$，查询通过，输出该点。✓
- $n=2$：两点 $(a,b),(c,d)$，$c_x=a+c$，像点互换，查询通过，输出中点。✓
- 奇数 $n$ 且中心不在集合中：闭包检查必失败（奇数个元素无法两两配对）。✓
- 整除不满足：提前退出，不做闭包检查。✓

## Part 5 · C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{20005};

int n;
i64 xs[mxn],ys[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	i64 sx=0,sy=0;
	set<pair<i64,i64>>P;
	for(int i=0;i<n;++i)
	{
		cin>>xs[i]>>ys[i];
		sx+=xs[i];
		sy+=ys[i];
		P.insert({xs[i],ys[i]});
	}

	if(2*sx%n||2*sy%n)
	{
		cout<<"This is a dangerous situation!"<<'\n';
		return 0;
	}

	i64 cx=2*sx/n,cy=2*sy/n;
	for(int i=0;i<n;++i)
	{
		if(!P.count({cx-xs[i],cy-ys[i]}))
		{
			cout<<"This is a dangerous situation!"<<'\n';
			return 0;
		}
	}

	auto fmt=[&](i64 s)
	{
		i64 v=s*10;
		int sgn=1;
		if(v<0)
		{
			sgn=-1;
			v=-v;
		}
		i64 t=(v+n/2)/n;
		if(sgn<0&&t>0)
			cout<<'-';
		cout<<t/10<<'.'<<t%10;
	};
	cout<<"V.I.P.  should  stay  at (";
	fmt(sx);
	cout<<",";
	fmt(sy);
	cout<<")."<<'\n';
	return 0;
}
```

**代码要点说明：**

- `i64` = `long long`，防止 $2s_x$（可达 $4\times10^9$）和 $10s_x$（可达 $2\times10^{10}$）溢出 `int`。
- `set<pair<i64,i64>>` 做成员查询，$O(\log n)$ 每次，总 $O(n\log n)$，$n=20000$ 下极快。
- 整数舍入：`(v + n/2) / n` 对非负 $v$ 实现四舍五入（半数入）；负数取绝对值后同样处理，再补负号。$t=0$ 时不打印负号（避免 $-0.0$）。
- 输出格式严格匹配：`V.I.P.` 后两空格、`should` 后两空格、`stay` 后两空格、`at (` 后跟坐标、`)`.结尾。
