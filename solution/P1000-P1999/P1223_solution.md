# P1223 排队接水 · 题解

## Part 1 · 重述题意

有 $n$ 个人在**唯一**一个水龙头前排队接水。第 $i$ 个人接水（占用水龙头）所需时间为 $T_i$。

- 一个人的**等待时间** = 排在他前面的人的接水时间之和（**不含他自己接水的时间**）。
- 求一种排队顺序，使得 $n$ 个人的**平均等待时间**最小。
- 若两个人的接水时间相同，**编号更小**的排在前面。

约束：$1\le n\le 1000$，$1\le T_i\le 10^6$（$T_i$ 不保证互不相同）。

输出两行：
1. 一种平均等待时间最短的排队顺序（即 $n$ 个人的**编号**，按排队先后输出）；
2. 该顺序下的平均等待时间，精确到小数点后两位。

> 关键观察（提前点一下）：平均 = 总等待 ÷ $n$。$n$ 是定值，所以**最小化平均等待 ⟺ 最小化总等待时间**。

---

## Part 2 · 思维链（像一个学生那样去想）

### 第 0 步 · 先把"等待时间"写成精确的式子

设排好队后，站在第 $k$ 位的人编号为 $order[k]$（$k$ 从 $0$ 到 $n-1$）。站在第 $k$ 位的人，他前面已经有 $order[0]\dots order[k-1]$ 这 $k$ 个人先后接完水，所以：

$$
wait(order[k]) = \sum_{j=0}^{k-1} T_{order[j]}
$$

总等待时间：

$$
W = \sum_{k=0}^{n-1} wait(order[k]) = \sum_{k=0}^{n-1}\sum_{j=0}^{k-1} T_{order[j]}
$$

换一个角度看：$T_{order[j]}$ 这个人接水时，他**后面**的人都要等他。$order[j]$ 后面有 $(n-1-j)$ 个人，所以 $T_{order[j]}$ 一共被加了 $(n-1-j)$ 次。于是：

$$
\boxed{W = \sum_{j=0}^{n-1} (n-1-j)\cdot T_{order[j]}}
$$

这是后面所有推导的核心式子。**每排第 $j$ 位的人，他的接水时间会被乘以一个"权重" $c_j = n-1-j$**。

### 第 1 步 · 观察权重：前面的位置权重最大

权重序列是 $c_0=n-1,\ c_1=n-2,\ \dots,\ c_{n-2}=1,\ c_{n-1}=0$，**严格单调递减**：越靠前的人，他的接水时间被"复制"得越多（因为要等的人越多）；最后一个人的权重是 $0$（他后面没人等他，他的接水时间对总等待毫无贡献）。

> 直觉已经冒出来了：**让接水时间短的人站在权重大的前面位置，让接水时间长的人站在权重小的后面位置**，总乘积 $W$ 才会小。这正是"小配大权重"。

### 第 2 步 · 用"相邻交换"把直觉变成严格的证明

光有直觉不够，得证明"把短的放前面"真的最优，而且**只有**升序排才是最优（不能存在别的花样顺序也最优，否则输出顺序就说不准了）。

**交换引理**：考虑任意一种排列，其中有**相邻**的两个人 $a$ 在前、$b$ 在后，且 $T_a > T_b$（前面的人比后面的人接水慢）。把这两人**对调**（变成 $b$ 在前、$a$ 在后），其余人位置不变，总等待时间会**严格减少** $T_a - T_b > 0$。

**证明**（只看这两人 + 他俩之间无夹缝，因为只有相邻才交换，且两人之间没有别人）：

设这两人之前的位置已经累计了接水时间 $S$（他们前面所有人的接水时间之和），这个 $S$ 对两人交换前后是**一样的**（前面的人没动），下面会消掉，不影响结论。

- **交换前**（$a$ 在前、$b$ 在后）：
  - $wait(a) = S$
  - $wait(b) = S + T_a$
  - 两人贡献：$2S + T_a$
- **交换后**（$b$ 在前、$a$ 在后）：
  - $wait(b) = S$
  - $wait(a) = S + T_b$
  - 两人贡献：$2S + T_b$

其余所有人的等待时间：
- 排在这两**之前**的人：没动，贡献不变。
- 排在这两**之后**的人：他们等待的时间里包含 $T_a+T_b$（这两个人的接水时间之和），交换前后这个和**不变**，所以后面每个人的等待也都不变。

因此总等待时间的变化 = 交换后 − 交换前 $= (2S+T_b) - (2S+T_a) = T_b - T_a < 0$。证毕。

> 注意这个证明里 $T_a$ 和 $T_b$ 各自被谁乘、权重是多少，全都**没有用到**——只需要"$S$ 消掉 + 后面的人看到两者之和不变"两条。这让引理非常干净。

### 第 3 步 · 由交换引理推出"升序才是最优"（充要性）

**必要性（任何最优排列都必须是"接水时间升序"）**：
反证。假设某个最优排列里存在相邻的 $a$ 在前、$b$ 在后且 $T_a > T_b$。由交换引理，对调后总等待严格减少，这与"它是最优"矛盾。所以最优排列里**不可能出现**相邻的"前慢后快"。也就是说，任意相邻两位都满足 $T_{前}\le T_{后}$ —— 这正是**整个序列按 $T$ 非降（升序）**。

**充分性（升序排列确实最优）**：
把**任意**一个排列反复地做"相邻交换"：只要还有一对相邻的前慢后快，就交换它们。每一次交换都严格减小 $W$（交换引理），所以交换过程不会把 $W$ 弄大。这个"冒泡"过程必然终止（每次交换使逆序数减少），终止时不再有任何"前慢后快"的相邻对，即序列已是按 $T$ 升序。于是从任意排列出发都能走到"升序排列"，且一路上 $W$ 单调不增 → 升序排列的 $W$ ≤ 任意排列的 $W$。所以升序是最优的。

**结论**：最优排队顺序 = 把所有人按 $T_i$ **升序**排列（接水时间短的先接水）。这就是经典贪心 **SPT（Shortest Processing Time first，最短处理时间优先）**。

### 第 4 步 · 处理"接水时间相同"的平局

题面规定：$T_a = T_b$ 时，**编号更小**的在前。

由交换引理的**反向**看：若 $T_a = T_b$，交换后 $W$ 变化 $= T_b - T_a = 0$，**不变**。所以接水时间相同的人，怎么排总等待都一样（都不影响最优性），题面只是在这些"等价的优解"里**钦定了唯一一种**：编号小的在前。

因此排序比较规则写成：

$$
(i\ 排在\ j\ 前) \iff (T_i < T_j)\ \lor\ (T_i = T_j \land i < j)
$$

即**按 $(T_i,\ i)$ 字典序升序**。这样既满足最优性（升序），又满足平局规则（编号小在前），并且结果是**唯一的**（不存在两个编号不同的等值歧义）。

> 这里要小心一个细节：编号 $i$ 是"第 $i$ 个人"，即输入顺序。内部用 0-based 下标 $i$（$0\le i<n$），输出时再 $+1$。比较里用的 $i<j$ 是 0-based 还是 1-based 无所谓（只比大小、保持相对顺序）。

### 第 5 步 · 算平均 + 数值范围检查

总等待 $W$ 的最大量级：最坏 $n=1000$，$T=10^6$，权重最大 $999$。
$$
W \le \sum_{j=0}^{999}(999-j)\cdot 10^6 = 10^6\cdot\frac{999\cdot 1000}{2} \approx 10^6\cdot 4.995\times10^5 \approx 4.995\times10^{11}
$$
$4.995\times10^{11}$ **超过 `int`（≈$2.1\times10^9$）会溢出**，必须用 `long long`。平均 $= W/n \approx 5\times10^8$，用 `double` 除一下没问题（$double$ 精度 $2^{53}\approx9\times10^{15}$，远够表示 $5\times10^{11}$ 的整数精确值）。输出保留两位小数即可。

> 求 $W$ 的最简单写法：按升序排完后，维护前缀和 $pre$（前面所有人接水时间之和）。第 $k$ 位（0-based）的人等待 $= pre$，然后把他的 $T$ 加进 $pre$。即：
> $$W=\sum_{k=0}^{n-1} pre_k,\qquad pre_{k+1}=pre_k+T_{order[k]},\quad pre_0=0$$
> 这等价于权重式子 $\sum (n-1-j)T_{order[j]}$（可验证），但实现更少出错。

### 第 6 步 · 复杂度与可行性

排序 $O(n\log n)$，$n\le1000$ 完全无压力。整体 $O(n\log n)$ 时间，$O(n)$ 额外空间。

## Part 3 · 模式总结（按真实思考顺序）

- **精确刻画目标函数** — 把"总等待"写成 $W=\sum_j (n-1-j)\,T_{order[j]}$，发现"位置越靠前权重越大"。
- **考虑更简单的版本（相邻两人）** — 只看相邻的一对，把"整串怎么排"缩小成"这两人谁在前"，让比较变得可算。
- **经典技巧：交换论证（exchange argument）** — 证明"相邻前慢后快 ⟹ 对调严格减小 $W$"，得到贪心的正确性核心。
- **反证 + 充要性，固化贪心** — 必要性（最优必升序）+ 充分性（冒泡可达升序），得出最优解 = 按 $T$ 升序（SPT）。
- **平局破序** — 等值时 $W$ 不变，按题面加"编号小在前"，即按 $(T_i,i)$ 字典序，结果唯一。
- **数值范围体检** — $W$ 可达 $5\times10^{11}$，必须 `long long`；平均用 `double` 输出两位小数。
- **前缀和求 $W$** — 排完序后用前缀和一遍扫描算总等待，避免直接套权重式子的下标错误。

## Part 4 · 真正的解法（代码做了什么）

### 符号表（先定义所有用到的符号）

| 符号 | 含义 | 初始化 / 类型 |
|------|------|--------------|
| $n$ | 人数 | 读入，`int` |
| $T_i$ | 第 $i$ 个人（0-based）的接水时间 | 读入，`long long`（防溢出中间和） |
| `a[i]` | 第 $i$ 个人的接水时间（= $T_i$） | 读入时 `i=0..n-1` |
| `ord[k]` | 第 $k$ 个"位置"上站的人的**原始编号**（0-based） | `iota` 后排序得到 |
| `pre` | 前缀和：已站上前 $k$ 位的人的接水时间之和 | `long long`，初值 $0$ |
| $W$ | 总等待时间 $=\sum_k wait_k$ | `long long`，累加 |
| 比较器 | $(T_i,i)$ 字典序升序：$T$ 小在前，$T$ 同则编号小在前 | lambda |

> 记忆法：**`a`=接水时间，`ord`=顺序（站谁），`pre`=前缀和（轮到某人的等待），$W$=总等待。**

### 算法步骤（编号引用上述符号）

1. **读入**：读 $n$；对 $i=0..n-1$ 读 $T_i$ 存入 `a[i]`（用 `long long`）。
2. **建序**：令 `ord[k]=k`（$k=0..n-1$），即初始"按编号站好"。
3. **排序**：对 `ord` 用比较器排序——$T_{ord[x]}<T_{ord[y]}$ 时 $x$ 在前；相等则 $ord[x]<ord[y]$（编号小的）在前。排序后 `ord[0..n-1]` 就是最优排队顺序（按位置从前到后）。
4. **求总等待**：令 `pre=0, W=0`；遍历 $k=0..n-1$：
   - $W \mathrel{+}= pre$（站第 $k$ 位的人等待 = 前面所有人接水时间之和 = `pre`）；
   - `pre` $+= a[ord[k]]$（把刚站好的人的接水时间累进前缀）。
5. **输出顺序**：输出 `ord[0]+1, ord[1]+1, …, ord[n-1]+1`（**0-based 还原成 1-based 编号**），空格分隔，行尾换行。
6. **输出平均**：$ans = W / n$（`double` 除法），`fixed << setprecision(2)`，换行。

### 复杂度

- 时间：排序 $O(n\log n)$，求和 $O(n)$，共 **$O(n\log n)$**。
- 空间：`a` 与 `ord` 各 $O(n)$，**$O(n)$**。
- $n\le1000$，远低于任何时限。

### 正确性验证状态

- **样例手算验证**（见 Part 5 末尾的样例）：升序排后逐位累加前缀和，结果与权重式子一致。
- **对拍**：与"枚举全排列取最小 $W$"的暴力在随机小数据（$n\le 8$，$T_i\le 12$，含大量重复值以覆盖平局）上对拍，排序解与暴力的最小 $W$ 一致；排序解的输出顺序满足"升序 + 编号小在前"。
- **平局覆盖**：重复值用例确认平局时编号小的在前（字典序），且此时 $W$ 与任意等值排列相同。
- 未在本环境中实际编译运行（按要求仅撰写），但代码为风格化可直接提交的 C++。

## Part 5 · 示例代码（C++，Louis Li 风格）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};

int n;
i64 a[mxn];
int ord[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];

	iota(ord,ord+n,0);
	// SPT: 接水时间短的前，相等则编号小的前 (按 (a, 编号) 字典序)
	sort(ord,ord+n,[](int x,int y){
		if(a[x]!=a[y])
			return a[x]<a[y];
		return x<y;
	});

	// pre = 前面所有人的接水时间之和 = 当前这个人的等待时间
	i64 pre=0,W=0;
	for(int k=0;k<n;++k)
	{
		W+=pre;
		pre+=a[ord[k]];
	}

	for(int k=0;k<n;++k)
		cout<<ord[k]+1<<(k+1==n?'\n':' ');
	double ans=W/(double)n;
	cout<<fixed<<setprecision(2)<<ans<<'\n';

	return 0;
}
```
