# P1140 相似基因 — 完整题解

---

## 1. Re-read the problem

我们有两种碱基 `A, C, G, T`，以及一个空碱基 `-`（gap）。给定两个长度不超过 100 的基因序列（只含 A/C/G/T），我们可以在任意位置插入任意数量的 gap，使两个序列变得等长，然后按位配对。每对字符的得分由一张 5×5 的对称表给出（见原题，gap-gap 不计分）。总相似度就是所有配对得分之和。

我们可以自由选择 gap 的插入方式和插入数量，目标是**最大化**这个总分。输出这个最大值。

本质上就是全局序列比对（Global Sequence Alignment），也就是经典的 **Needleman–Wunsch** 算法。

---

## 2. Chain-of-thought

### 2.1 把问题转化为 DP

假设我们有两个序列：

```
s1 = A G T G A T G    (长度 n1 = 7)
s2 = G T T A G        (长度 n2 = 5)
```

我们可以在中间插入 `-` 来对齐。对齐过程中的任意一步，我们的目光聚焦在两个序列的**前缀**上：已经处理完了 s1 的前 i 个字符和 s2 的前 j 个字符，剩下的还没有对齐。

**Lemma 1（无后效性）**：对齐 s1[1..i] 和 s2[1..j] 的最优得分，与后续字符如何对齐无关。前缀的配对已经固定为某个最佳方案，后续决策只需要在此基础上进行。

证明：总得分 = 配对得分之和，每个配对只依赖于当前两个字符，不依赖于前后顺序。所以前缀的决策不影响后缀的可选配对及其得分。因此可以用 DP 无后效性。

### 2.2 状态定义

令 `dp[i][j]` = s1 的前 i 个字符与 s2 的前 j 个字符**已经全部配完**（允许插入 gap）所能得到的最大相似度。

换句话说，我们考虑的是两个序列的**前缀**的全局对齐。最后答案就是 `dp[n1][n2]`。

### 2.3 转移方程推导

考虑 dp[i][j] 的最后一个配对（即当前正在看的最后一个位置），有三种可能的情况：

**情况 A**：s1[i] 和 s2[j] 直接配对（都不作为 gap）：

```
s1: ... A
s2: ... T
得分 = dp[i-1][j-1] + score(s1[i], s2[j])
```

**情况 B**：s1[i] 与 gap 配对，s2[j] 留到后面（即 s2[j] 还没有被处理？不对——我们定义 dp[i][j] 是前缀已经全部配完，所以不能留着 j 不处理）。

正确理解方式：dp[i][j] 意味着我们已经处理了 s1 的 i 个**真实字符**和 s2 的 j 个**真实字符**。两个序列等长，所以总长度是某个值 L（L ≥ max(i,j)）。多出来的那些位置全部是 gap。

那么「最后一个配对」有两种理解：最后一个对应列放的什么字符。

更准确的转移：

1. s1[i] 配 s2[j] → 前驱是 dp[i-1][j-1]
2. s1[i] 配 gap → s1 的这个真实字符消耗掉了，但 s2 这边用了一个 gap 来对齐，所以 s2 的真实字符并未消耗 → 前驱是 dp[i-1][j]（s1 的第 i 个字符被用掉，s2 的真实字符一个都没用）
3. gap 配 s2[j] → 对称地，前驱是 dp[i][j-1]

**Lemma 2（转移完备性）**：上述三种情况覆盖了所有可能的全局对齐中最后一列的配对方式。

证明：在一个全局对齐的最后（最右边）一列，两种可能性：
- 这一列不是 gap vs gap（gap-gap 不计分且不会出现在最优解中，因为删掉这一列总得分不变或更高），所以要么两个都是真实字符，要么一个真实一个 gap。
- 若两个都是真实字符，则 s1 消耗一个、s2 消耗一个 → case 1。
- 若 s1 真实、s2 为 gap → s1 消耗一个、s2 不消耗 → case 2。
- 若 s2 真实、s1 为 gap → s2 消耗一个、s1 不消耗 → case 3。

所以：

```
dp[i][j] = max(
    dp[i-1][j-1] + w(s1[i], s2[j]),    // 两个真实碱基对齐
    dp[i-1][j]   + w(s1[i], '-'),       // s1[i] 与 gap 对齐
    dp[i][j-1]   + w('-', s2[j])        // s2[j] 与 gap 对齐
)
```

### 2.4 边界条件

dp[0][0] = 0：两个空前缀对齐，得分 0。

dp[i][0]：s1 的前 i 个字符全部与 gap 对齐 → dp[i][0] = dp[i-1][0] + w(s1[i], '-')

dp[0][j]：对称地，dp[0][j] = dp[0][j-1] + w('-', s2[j])

### 2.5 时间复杂度

O(n1 × n2)，两重循环。n ≤ 100，所以最多 10⁴ 规模，非常小。

### 2.6 正确性证明总结

- **最优子结构**：dp[i][j] 的值由 dp[i-1][j-1]、dp[i-1][j]、dp[i][j-1] 三个更小子问题的解转移而来，每个子问题本身是某个前缀的全局最优对齐。如果子问题不是最优，则整个方案不可能最优（否则可以替换子问题得到更优解）。
- **无后效性**：当前决策只关心前缀长度，不关心具体 gap 分布，未来决策不受 gap 具体位置影响。
- **转移完备性**：所有最后一列的配对方式被三类情况全覆盖。

因此该 DP 正确计算出最大相似度。

## 3. Pattern summary

| 步骤 | 关键词 | 说明 |
|------|--------|------|
| 1 | **识别模型** | 两序列对齐，允许插入 gap，最大化总分 → 全局序列比对 DP |
| 2 | **状态** | `dp[i][j]` = 前缀 s1[1..i] 和 s2[1..j] 全局对齐的最大得分 |
| 3 | **转移三叉** | 取三种可能的最大值：两真配 / 左真右 gap / 左 gap 右真 |
| 4 | **边界** | 单边全部配 gap 递推 |
| 5 | **打表** | 128 大小数组映射字符 → 索引，5×5 得分表 |
| 6 | **答案** | `dp[n1][n2]` |

## 4. Real solution

### 符号表

| 符号 | 含义 |
|------|------|
| `s1`, `s2` | 输入的两个基因序列（0 基索引） |
| `n1`, `n2` | 两序列长度 |
| `dp[i][j]` | s1 的前 i 个字符与 s2 的前 j 个字符全局对齐的最大相似度 |
| `idx[c]` | 字符 c 映射到 0..4 的整数（A=0, C=1, G=2, T=3, -=4） |
| `sim[a][b]` | 5×5 得分表，sim[a][b] = 字符 a 与字符 b 配对的得分 |

### 代码逻辑

1. 读入两个序列的 n1, s1, n2, s2
2. 建立字符到 0..4 的映射表 idx
3. 硬编码 5×5 得分表 sim
4. 初始化 dp 数组为极小值（-INF）
5. 设置边界：dp[0][0] = 0，dp[i][0] 和 dp[0][j] 单向 gap 递推
6. 两重循环 i=1..n1, j=1..n2，按转移方程填表
7. 输出 dp[n1][n2]

### 注意

- 下标使用 0 基存储但 DP 使用 1 基索引，取字符时用 s1[i-1] 即可
- gap-gap 在表中是 `*`（不计分），但我们的转移不会出现 gap-gap 配对，所以不需要这个值
- INF 取一个很小的数，比如 -10⁹

## 5. Example code (C++)

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};

int n1, n2;
char s1[mxn], s2[mxn];
int dp[mxn][mxn];

int idx[128];
int sim[5][5];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	// 字符映射表
	idx['A']=0; idx['C']=1; idx['G']=2; idx['T']=3; idx['-']=4;

	// 相似度表
	sim[0][0]=5;  sim[0][1]=-1; sim[0][2]=-2; sim[0][3]=-1; sim[0][4]=-3;
	sim[1][0]=-1; sim[1][1]=5;  sim[1][2]=-3; sim[1][3]=-2; sim[1][4]=-4;
	sim[2][0]=-2; sim[2][1]=-3; sim[2][2]=5;  sim[2][3]=-2; sim[2][4]=-2;
	sim[3][0]=-1; sim[3][1]=-2; sim[3][2]=-2; sim[3][3]=5;  sim[3][4]=-1;
	sim[4][0]=-3; sim[4][1]=-4; sim[4][2]=-2; sim[4][3]=-1; /*gap-gap 不用*/

	cin>>n1>>(s1+1)>>n2>>(s2+1);

	// 将 s1/s2 转为索引（1 基存储）
	for(int i=1; i<=n1; ++i) s1[i]=idx[s1[i]];
	for(int j=1; j<=n2; ++j) s2[j]=idx[s2[j]];

	// 初始化 dp 为极小值
	fill_n(&dp[0][0], mxn*mxn, -0x3f3f3f3f);
	dp[0][0]=0;

	// 边界：单边全部对齐 gap
	for(int i=1; i<=n1; ++i) dp[i][0]=dp[i-1][0]+sim[s1[i]][4];
	for(int j=1; j<=n2; ++j) dp[0][j]=dp[0][j-1]+sim[4][s2[j]];

	for(int i=1; i<=n1; ++i)
	{
		for(int j=1; j<=n2; ++j)
		{
			dp[i][j]=max({
				dp[i-1][j-1]+sim[s1[i]][s2[j]],
				dp[i-1][j]  +sim[s1[i]][4],
				dp[i][j-1]  +sim[4][s2[j]]
			});
		}
	}

	cout<<dp[n1][n2]<<'\n';
	return 0;
}
```
