# P1914 小书童——凯撒密码

## 1. 重新读题

### 1.1 问题重述（人话版）

给定一个只由小写字母组成、长度不超过 $50$ 的原文串，以及整数 $n$（$1\le n\le 26$），把每个字母在字母表中**向后**移动 $n$ 位，`z` 的下一位绕回 `a`，输出得到的密码串。

### 1.2 关键约束与规模暗示

- 串长 $\le 50$，$n\le 26$：这是纯模拟题，任何 $O(\text{长度})$ 的做法都可以，不需要任何数据结构。
- 「`z` 的下一个字母是 `a`」说明字母表是一个长度为 $26$ 的**循环**，位移要在模 $26$ 意义下做。
- 只需要逐字符变换，不涉及字母频率、替换表等额外结构。

## 2. 思维链（Chain-of-thought）

### 2.1 把字母变成数

字母 `a`…`z` 和下标的对应关系是天然的：令 `id(c) = c - 'a'`，则 `id` 取值 $0..25$。

「向后移动 $n$ 位」就是对下标做加法；「`z` 之后是 `a`」就是把结果对 $26$ 取模：

$$\text{new}(c)=\text{char}\bigl(\text{'a'} + (\text{id}(c)+n)\bmod 26\bigr).$$

### 2.2 为什么取模一定对

**命题**：上面的映射对每个小写字母输出仍是小写字母，且当 `id(c)+n ≤ 25` 时它就是普通的向后移动 $n$ 位，当 `id(c)+n ≥ 26` 时正好绕回字母表开头。

**证明**：`id(c) ∈ [0,25]`，`n ∈ [0,25]`（若 $n=26$ 可先对 $26$ 取模化为 $0$），故 `id(c)+n ∈ [0,50]`，模 $26$ 后仍在 $[0,25]$，加上 `'a'` 后一定是小写字母。若 `id(c)+n ≤ 25`，模 $26$ 不改变结果，就是向后 $n$ 位；若 `id(c)+n ≥ 26`，则实际输出下标为 `id(c)+n-26`，即从 `z` 之后从 `a` 重新开始数$n$ 位。$\square$

换句话说，这个变换就是循环群 $\mathbb{Z}_{26}$ 上的平移 $x\mapsto x+n$，而平移是双射，所以不同的原文一定得到不同的密码（本题无需用到，但可以确认规则自洽）。

### 2.3 需要小心的地方

1. **读入方式**：第一行是整数 $n$，第二行是串。用 `cin>>n>>s` 即可，因为串内不含空格。
2. **`n` 可能等于 $26$**：此时应先 `n%=26`，否则虽然结果也对（`id+26` 模 $26$ 还是 `id`），但显式取模更清楚，也避免以后把 $n$ 范围改大时出错。
3. **不要用 `char` 直接加 $n$ 而不取模**：`'z'+1` 会变成 `'{'`，得到非字母。
4. **输出不要多空格**：逐字符输出后补一个换行。

数据规模这么小，没有更「高级」的算法可谈；把上面四点在代码里落实即可。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 字母表是长度 $26$ 的循环，位移是 $\mathbb{Z}_{26}$ 上的平移。
- **small-scale simulation** — 逐字符把 `c-'a'` 加 $n$ 再模 $26$ 还原成字符。
- **pitfall** — `z` 之后要绕回 `a`；`n` 先对 $26$ 取模。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 位移量 | 读入后 `n%=26` | shift |
| `s` | `string` | 原文 | 读入 | source |

### 4.2 算法步骤

1. 读入 $n$ 与 `s`，令 `n%=26`。
2. 从左到右遍历 `s` 的每个字符 `c`，输出 `char('a'+(c-'a'+n)%26)`。
3. 输出换行。

### 4.3 复杂度与验证状态

- **时间复杂度**：$O(|s|)$，$|s|\le 50$。
- **空间复杂度**：$O(|s|)$（存输入串）。
- 编译 `g++ -std=c++17 -O2 -Wall -Wextra`，无警告。
- 自测：`n=1, s="abc"` 得 `bcd`；`n=26, s="zzz"` 得 `zzz`；`n=13, s="mn"` 得 `za`（`m→z`，`n` 绕回 `a`）。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int n;
string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>s;
	n%=26;
	for(char c:s)
		cout<<char('a'+(c-'a'+n)%26);
	cout<<'\n';
	return 0;
}
```
