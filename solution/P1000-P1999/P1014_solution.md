# P1014 Cantor 表 题解

---

## 一、发现之旅：从 Z 字形中找规律

打开题目，看到的是一张无限延伸的表格：

```
1/1  1/2  1/3  1/4  1/5  …
2/1  2/2  2/3  2/4  …
3/1  3/2  3/3  …
4/1  4/2  …
5/1  …
```

Cantor 用一种巧妙的 **Z 字形（蛇形）** 走法遍历这张表，给每个有理数一个编号：

```
1: 1/1
2: 1/2
3: 2/1
4: 3/1
5: 2/2
6: 1/3
7: 1/4
8: 2/3
9: 3/2
10: 4/1
11: 5/1
12: 4/2
13: 3/3
14: 2/4
15: 1/5
⋮
```

拿到这个问题，N 最大可以到 $10^7$，显然不能真的模拟走路——必须找到数学规律。

我们盯着这些分数，把它们按 **对角线** 分组：

| 对角线编号 | 元素                                   | 个数  | 分子 + 分母 |
|-------|---------------------------------------|------|-----------|
| 1     | `1/1`                                 | 1    | 2         |
| 2     | `1/2, 2/1`                            | 2    | 3         |
| 3     | `3/1, 2/2, 1/3`                       | 3    | 4         |
| 4     | `1/4, 2/3, 3/2, 4/1`                  | 4    | 5         |
| 5     | `5/1, 4/2, 3/3, 2/4, 1/5`             | 5    | 6         |
| 6     | `1/6, 2/5, 3/4, 4/3, 5/2, 6/1`        | 6    | 7         |
| ⋮     | ⋮                                     | ⋮    | ⋮         |

规律清晰浮现：

- 第 k 条对角线恰有 **k 个元素**。
- 对角线上每个分数的 **分子 + 分母 = k + 1**（一个定值）。
- **Z 字形的方向交替变化**：
    - 偶数对角线（k 为偶）：分子 **递增** `1,2,…,k`，分母 **递减** `k,…,2,1`。
    - 奇数对角线（k 为奇且 k>1）：分子 **递减** `k,…,2,1`，分母 **递增** `1,2,…,k`。
    - k=1 时只有一个元素，两种规则等价。

有了这个结构，问题转化为两步：找到第 N 项位于哪条对角线，再确定它在该对角线上的位置。

## 二、思维链：从编号到分数的完整推导

### 2.1 定位对角线

前 k 条对角线总共包含的元素个数是等差数列和：

$$
S_k = 1 + 2 + \cdots + k = \frac{k(k+1)}{2}
$$

给定 N，我们要找最小的 k 使得 $S_k \ge N$。也就是解不等式：

$$
\frac{k(k+1)}{2} \ge N \quad\Longrightarrow\quad k^2 + k - 2N \ge 0
$$

二次函数 $f(k) = k^2 + k - 2N$ 的判别式 $\Delta = 1 + 8N$，正根为：

$$
k = \left\lceil \frac{-1 + \sqrt{1 + 8N}}{2} \right\rceil
$$

**证明**：$f(k)$ 在 $k > 0$ 时单调递增。$k_0 = \frac{-1 + \sqrt{1 + 8N}}{2}$ 是 $f(k) = 0$ 的正根。对任意整数 $k$，若 $k < k_0$ 则 $f(k) < 0$ 即 $S_k < N$；若 $k \ge k_0$ 则 $f(k) \ge 0$ 即 $S_k \ge N$。因此最小的满足条件的整数 k 就是 $\lceil k_0 \rceil$。

为了防止浮点误差，代码里通常用 **循环累减** 的方式来替代开方——这也是更稳健的做法。

### 2.2 确定对角线的偏移位置

前 $k-1$ 条对角线有 $S_{k-1} = (k-1)k/2$ 个元素。第 N 项在第 k 条对角线上的 **偏移量**（从 1 开始计数）为：

$$
p = N - S_{k-1}
$$

其中 $1 \le p \le k$。

### 2.3 由奇偶性计算分子分母

第 k 条对角线上的分数满足 **分子 + 分母 = k + 1**。Z 字形方向由 k 的奇偶性决定：

- **k 为偶数**：分子递增方向。该对角线上第 $p$ 个分数的分子为 $p$，分母为 $k+1-p$。
- **k 为奇数**：分子递减方向。该对角线上第 $p$ 个分数的分子为 $k+1-p$，分母为 $p$。

统一写成：

$$
\begin{cases}
\text{分子} = p,\ \text{分母} = k + 1 - p &\text{if } k \text{ 为偶}\\[4pt]
\text{分子} = k + 1 - p,\ \text{分母} = p &\text{if } k \text{ 为奇}
\end{cases}
$$

**正确性验证**（取前面几个 N 逐一检验）：

| N | k  | p  | k 奇偶 | 分子 | 分母 | 结果   | 与原序列一致？ |
|---|----|----|--------|----|----|--------|----------|
| 1 | 1  | 1  | 奇   | 1  | 1  | 1/1    | ✓ |
| 2 | 2  | 1  | 偶   | 1  | 2  | 1/2    | ✓ |
| 3 | 2  | 2  | 偶   | 2  | 1  | 2/1    | ✓ |
| 4 | 3  | 1  | 奇   | 3  | 1  | 3/1    | ✓ |
| 5 | 3  | 2  | 奇   | 2  | 2  | 2/2    | ✓ |
| 6 | 3  | 3  | 奇   | 1  | 3  | 1/3    | ✓ |
| 7 | 4  | 1  | 偶   | 1  | 4  | 1/4    | ✓ |
| 8 | 4  | 2  | 偶   | 2  | 3  | 2/3    | ✓ |
| 9 | 4  | 3  | 偶   | 3  | 2  | 3/2    | ✓ |
| 10| 4  | 4  | 偶   | 4  | 1  | 4/1    | ✓ |

全部通过。思路正确。

## 三、模式概括

Cantor 表的 Z 字形遍历存在三个核心规律：

1. **对角线分组**：第 k 条对角线有 k 个元素，所有分子 + 分母 = k + 1。
2. **方向交替**：偶数对角线分子递增、分母递减；奇数对角线分子递减、分母递增。
3. **定位公式**：第 N 项位于第 $k = \lceil (\sqrt{1+8N}-1)/2 \rceil$ 条对角线的第 $p = N - k(k-1)/2$ 位，按奇偶性代入分子分母公式即可。

这三句话本身就是算法的全部。

## 四、正式解法与符号表

### 符号约定

| 符号 | 含义                              |
|----|----------------------------------|
| $N$ | 输入的编号，$1 \le N \le 10^7$        |
| $k$ | 第 N 项所在的对角线编号（从 1 开始）          |
| $p$ | 在第 k 条对角线上的偏移位置（从 1 开始）        |
| $S_k$ | 前 k 条对角线的元素总数，$S_k = k(k+1)/2$ |
| $a$ | 输出的分子                            |
| $b$ | 输出的分母                            |

### 算法步骤

1. **读入** $N$。
2. **找对角线**：从 $k = 1$ 开始，将 $N$ 依次减去 $1,2,3,\ldots$，直到 $N$ 不大于当前剩余值。
   - 等价实现：维护一个累加变量 $S$，每次递增 $k$ 并累加，当 $S \ge N$ 时停止。
   - 退出循环时，$k$ 已自增到正确值，$p = N$（因为一直在减）。
3. **计算分数**：
   - 若 $k$ 为偶数：$a = p,\ b = k+1-p$。
   - 若 $k$ 为奇数：$a = k+1-p,\ b = p$。
4. **输出** `a/b`。

### 复杂度分析

- **时间复杂度**：$O(\sqrt{N})$。$k$ 满足 $k(k+1)/2 \ge N$，所以 $k \approx \sqrt{2N}$，当 $N=10^7$ 时 $k \approx 4472$，循环开销极小。
- **空间复杂度**：$O(1)$，只用了常数个变量。

### OI 常见误区

1. **不要直接模拟遍历**：$N$ 可达 $10^7$，逐个生成分数需要 $O(N)$ 时间和空间，不可行。
2. **浮点开方要谨慎**：用 `sqrt` 计算 $k$ 时可能存在浮点误差，导致 $k$ 少 1。相比之下，减法的循环方式绝对精确且速度足够快。
3. **偏移 p 的起始值**：p 从 1 开始计数，不是从 0。

## 五、C++ 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;

	// 找到第 N 项所在的对角线 k
	// 每轮: n -= k (减去对角线上元素个数), 直到 n <= k
	int k=0;
	for(int sum=0;sum<n;++k)
		sum+=k;
	// 退出循环时: k 已自增到正确对角线编号
	// n 保存了对角线上的偏移位置 p
	// 注意: 循环结束时 sum >= original_n, n 已被减到 "剩余值"
	// 需要重新计算偏移... 更精确地实现如下:

	int i;
	for(i=1;;++i)
	{
		if(n<=i)
			break;
		n-=i;
	}
	// 此时 i 是所在对角线编号, n 是偏移 p

	int a,b;
	if(i%2==0)          // 偶数对角线: 分子递增
		a=n,b=i+1-n;
	else                // 奇数对角线: 分子递减
		a=i+1-n,b=n;

	cout<<a<<'/'<<b<<'\n';
	return 0;
}
```

**关键代码段说明**：

- 第 $12$–$19$ 行：用逐次减法确定对角线编号。`n` 每次减去当前对角线的长度 `i`，当 `n <= i` 时说明第 N 项落在这一条对角线上。退出时 `i` 就是对角线编号 `k`, 剩余的 `n` 就是偏移量 `p`。
- 第 $23$–$26$ 行：按奇偶性分配分子分母。

### 拓展思考

上述实现用 $O(\sqrt{N})$ 的循环定位，对 $N=10^7$ 只需约 $4472$ 次迭代，任何测评机都能秒过。如果追求极致常数，也可以用公式 $k = \lceil (\sqrt{1+8N} - 1)/2 \rceil$ 一步到位：

```cpp
int k=ceil((sqrt(1+8.0*n)-1)/2);
int p=n-k*(k-1)/2;
```

但需注意浮点误差——做题时 `O(sqrt(N))` 循环法已经足够优雅。

---

*本题的核心思想是将无限二维表编码为一维编号——通过**对角线分组**与**奇偶方向**两个视角，将遍历问题转化为直角坐标系上的代数计算。这也是 Cantor 证明"有理数可数"这一伟大发现的算法实现。*
