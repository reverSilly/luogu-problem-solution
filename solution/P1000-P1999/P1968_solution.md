# P1968 美元汇率

## 1. 重新读题

### 1.1 问题重述（人话版）

戴维一开始有 $100$ 美元。接下来的 $N$ 天，第 $i$ 天的汇率是 $A_i$，含义是：

$$
100\text{ 美元}\ \longleftrightarrow\ A_i\text{ 马克}.
$$

也就是说，**美元换马克**按 $1$ 美元 $=A_i/100$ 马克，**马克换美元**按 $1$ 马克 $=100/A_i$ 美元。每天他可以在当天汇率下自由兑换（可以只换一部分，也可以不换）。最后一天结束之前，他必须把所有钱换回美元。求最终最多能有多少美元（保留两位小数）。

题意补充：题目只要求「最后一天结束之前」全部换回美元，所以第 $N$ 天的汇率也可以使用。

### 1.2 关键约束与规模暗示

- $N\le 100$，$A_i\le 1000$。规模极小，$O(N^2)$ 甚至指数级在小数据上都能过，说明本题重点不在优化，而在**状态设计**。
- Special Judge，误差容忍 $0.05$ 美元，所以用 `double` 足够，不必高精度。
- 汇率每天只有一个值，同一天内来回兑换的净倍率是
  $$
  \frac{A_i}{100}\cdot\frac{100}{A_i}=1,
  $$
  所以同一天内「先换过去再换回来」不赚不亏，不会带来额外收益。
- 输出两位小数，注意四舍五入误差；SPJ 要求 $0.05$ 内，一般 `printf("%.2f")` 即可。

## 2. 思维链（Chain-of-thought）

### 2.1 先试试「贪心：低买高卖」

直觉上，应该在某天汇率低（美元值钱、能换很多马克，即 $A_i$ 大？要小心方向）时用美元换马克，在马克贵的时候换回美元。

把「持有美元」和「持有马克」看作两种状态。由于同一天来回兑换净倍率为 $1$，一天之内做多次兑换没有意义；真正要做的是**决定在哪些天把钱从一种货币换成另一种**。

最朴素的想法：枚举所有「买入—卖出」的配对，取最大收益。但手数、持有时间、能否连续多次换手都不明确，容易漏情况。我们改用**动态规划**，把「今天结束时最多有多少钱」这个量作为状态。

### 2.2 状态的选取

设：

- `usd[i]`：第 $i$ 天结束（已处理完第 $i$ 天的兑换）后，**全部持有美元**时最多有多少美元；
- `mk[i]`：第 $i$ 天结束后，**全部持有马克**时最多有多少马克。

初始：`usd[0]=100`，`mk[0]=0`（第 0 天，即还没开始）。

**转移**（第 $i$ 天汇率 $A_i$）：

$$
\begin{aligned}
\texttt{usd}[i]&=\max\Big(\texttt{usd}[i-1],\ \texttt{mk}[i-1]\cdot\frac{100}{A_i}\Big),\\
\texttt{mk}[i]&=\max\Big(\texttt{mk}[i-1],\ \texttt{usd}[i-1]\cdot\frac{A_i}{100}\Big).
\end{aligned}
$$

含义：

- 今天结束时全持美元，要么昨天就全持美元、今天不换；要么昨天全持马克、今天按 $100/A_i$ 全部换成美元。
- 今天结束时全持马克，对称。
- 也允许「昨天持美元、今天换成马克后再换回来」，但净倍率 $1$，不会超过不换，所以不列入转移也不影响最优值。

**引理 1（两种纯状态足够）**：存在一个最优策略，使得每天结束时戴维只持有一种货币。

**证明**：先证一个单步事实。设某天开始时持有 $u$ 美元与 $m$ 马克，当天汇率为 $A$。若按比例 $t\in[0,1]$ 把一部分美元换成马克（其余不动），当天结束时美元数为 $u(1-t)$、马克数为 $m+utA/100$。这是两个纯状态

$$
P_0=(u,\ m+uA/100)\quad(t=1),\qquad P_1=(u,\ m)\quad(t=0)
$$

的凸组合。反过来，把马克换成美元也一样。因此**任意混合操作后的状态都是两个极端状态的凸组合**。

再看最终美元价值函数 $F(u,m)$：它是「在之后所有天按某种策略操作，最终能得到的美元数」的最大值。对固定的后续策略，最终美元数是 $(u,m)$ 的**线性函数**；$F$ 是这些线性函数的上确界，因而是**凸函数**，且显然是一次齐次的（钱翻倍，结果翻倍）。于是对任意凸组合 $(u_t,m_t)=tP_0+(1-t)P_1$，

$$
F(u_t,m_t)\le tF(P_0)+(1-t)F(P_1)\le\max\{F(P_0),F(P_1)\},
$$

即混合状态的最优值不超过两个纯状态中最优值较大的那个。所以总可以替换成纯状态而不变差。

对天数做归纳：从最后一天倒推，每天结束时的最优状态可以取纯状态；于是整个最优策略每天结束都只持有一种货币。$\square$

> 直白地说：任何「一半美元一半马克」的混合状态，其最终美元价值不会超过「全美元」与「全马克」两种纯策略中较好的那个，所以只需维护两个纯状态。

这个引理是本题 DP 正确性的核心：如果允许任意比例，状态会变成连续统；正是因为线性 + 无摩擦，两个极值状态就够。

### 2.3 DP 为什么不需要更多状态

有人会担心：某天结束时持有美元，但「这些美元是之前从马克换来的」和「本来就是美元」会不会影响后续？不会，因为后续兑换只取决于**当前持有量和当天汇率**，与历史路径无关。所以 `usd[i]` 只需记录最大值，无需记录来源。这就是 DP 的「无后效性」。

### 2.4 边界与坑点

1. **最后必须换回美元**：答案取 `usd[N]`，不能取 `max(usd[N], mk[N]*100/A_N)` 之类——转移里第 $N$ 天已经把「换成美元」算进去了。
2. **第 1 天就能换**：初始 `mk[0]=0`，第 1 天转移 `mk[1]=max(0,100*A_1/100)=A_1`，即 $100$ 美元能换 $A_1$ 马克，正确。
3. **方向不要搞反**：题目是「$100$ 美元可以买 $A$ 马克」，所以美元→马克乘 $A/100$；马克→美元乘 $100/A$。
4. **同一天先换出再换回**净倍率 $1$，不会产生额外收益，因此转移中只考虑「从昨天状态换一次」。
5. **精度**：用 `double`，输出 `fixed << setprecision(2)`；SPJ 允许 $0.05$ 误差。不要用 `float`，$N$ 虽小但连续乘除仍可能积累误差。
6. `A_i` 是自然数且 $1\le A_i\le1000$，不会除以 $0$。

### 2.5 用样例验算

样例说明给出的操作序列：

- 第 1 天：$100$ 美元 $\to400$ 马克，说明 $A_1=400$；
- 第 2 天：$400$ 马克 $\to133.3333$ 美元，说明 $A_2=300$；
- 第 3 天：$133.3333$ 美元 $\to666.6666$ 马克，说明 $A_3=500$；
- 第 5 天：$666.6666$ 马克 $\to266.6666$ 美元，说明 $A_5=250$。

用 DP 走一遍（第 4 天数据不影响结论）：

| 天 | $A_i$ | `usd` | `mk` |
| :-- | :-- | :-- | :-- |
| 0 | — | 100 | 0 |
| 1 | 400 | 100 | 400 |
| 2 | 300 | 133.33 | 400 |
| 3 | 500 | 133.33 | 666.67 |
| 4 | 不交易 | 133.33 | 666.67 |
| 5 | 250 | 266.67 | 666.67 |

最终 $266.67$，与样例一致。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 同一天来回兑换净倍率为 $1$，只需考虑一天换一次。
- **state design** — 每天结束只可能「全美元」或「全马克」，两种状态。
- **prove state sufficiency** — 最终价值函数凸且一次齐次，混合状态不优于两个纯状态，故只需两状态。
- **classic problem solution** — 两状态 DP，逐天转移，$O(N)$。
- **boundary** — 最后必须换回美元，答案取美元状态；注意汇率方向与精度。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `N` | `int` | 天数 | 读入 | 规模 |
| `A` | `int` | 当天的汇率（$100$ 美元换 $A$ 马克） | 逐行读入 | 汇率 |
| `usd` | `double` | 当前全部持美元时的最大美元数 | $100$ | 美元状态 |
| `mk` | `double` | 当前全部持马克时的最大马克数 | $0$ | 马克状态 |
| `nu`, `nm` | `double` | 当天转移后的新状态 | — | new |

### 4.2 算法步骤

1. `usd=100`，`mk=0`。
2. 对 $i=1..N$：读入 $A$；计算
   - `nu = max(usd, mk*100.0/A)`；
   - `nm = max(mk, usd*A/100.0)`；
   - 注意两式必须用**旧**的 `usd,mk`，所以先算 `nu,nm` 再赋值。
3. 输出 `usd`，保留两位小数。

### 4.3 复杂度分析

- **时间**：$O(N)$。
- **空间**：$O(1)$。

## 5. 示例代码

```cpp
//
// 题目：P1968 [CHCI 2001 Regional Competition Seniors] 美元汇率
// https://www.luogu.com.cn/problem/P1968
#include<bits/stdc++.h>
using namespace std;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	double usd{100},mk{0};
	for(int i=0,a;i<n;++i)
	{
		cin>>a;
		double nu{max(usd,mk*100.0/a)};
		double nm{max(mk,usd*a/100.0)};
		usd=nu;
		mk=nm;
	}
	cout<<fixed<<setprecision(2)<<usd<<'\n';
	return 0;
}
```
