# P1647 锁 题解

> 标签：分治 / 位运算 / 递归构造 / 数学规律 · 难度：省选/NOI-

## 1. 重新读题

**问题重述（人话版）**

给定正整数 $N$ 和 $K$（$1 \le N \le 50$，$1 \le K \le 2^N$）。按如下规则生成 $0 \sim 2^N - 1$ 的排列 $S_N[0 \dots 2^N - 1]$：
1. 首项 $S_N[0] = 0$，且 $0 \sim 2^N - 1$ 每个数恰好出现一次；
2. 相邻两项的二进制表示之间，只能将前一项的**若干个 `0` 同时变为 `1`**，或者将前一项的**若干个 `1` 同时变为 `0`**（二者必居其一，不能同时既有 $0 \to 1$ 又有 $1 \to 0$）；
3. 在每一步由前一项生成后一项时，在满足前两条的前提下**贪心选择数值最小**的未访问数。

求该序列前 $K$ 项 $\max_{0 \le i < K} S_N[i]$ 的最大值，输出其 $N$ 位二进制表示（含前导零）。

**约束与规模暗示**

- $1 \le N \le 50$，$1 \le K \le 2^N$。
- 规模暗示：$2^{50} \approx 1.12 \times 10^{15}$，必须用 `unsigned long long`（`u64`）存储下标与数值；且不可能逐项模拟，必须发现序列 $S_N$ 的分治自相似结构，在 $O(N^2)$ 或 $O(N)$ 时间内直接定位最大值。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：打出小规模表，观察半区循环右移现象

先按题意写出暴力贪心生成程序，打印 $N = 1, 2, 3, 4$ 的序列：
- $S_1 = [0, 1]$
- $S_2 = [0, 1, \quad 3, 2] = [0, 1] \;\|\; (2 + [1, 0])$
- $S_3 = [0, 1, 3, 2, \quad 6, 4, 5, 7] = S_2 \;\|\; (4 + [2, 0, 1, 3])$
- $S_4 = S_3 \;\|\; (8 + [7, 0, 1, 3, 2, 6, 4, 5])$

观察每个序列的后半部分（减去最高位权值 $2^{b-1}$ 后）：
- $S_2$ 后半部分：$[1, 0]$，恰为 $S_1 = [0, 1]$ **循环右移 1 位**！
- $S_3$ 后半部分：$[2, 0, 1, 3]$，恰为 $S_2 = [0, 1, 3, 2]$ **循环右移 1 位**！
- $S_4$ 后半部分：$[7, 0, 1, 3, 2, 6, 4, 5]$，恰为 $S_3 = [0, 1, 3, 2, 6, 4, 5, 7]$ **循环右移 1 位**！

### 2.2 严格证明半区循环右移定理与 $O(N^2)$ 最大值递归

**引理 1（半区循环右移定理）**

对于任意 $b \ge 1$，长度为 $2^b$ 的贪心序列 $S_b$ 满足：
1. 前半部分 $S_b[0 \dots 2^{b-1} - 1] = S_{b-1}[0 \dots 2^{b-1} - 1]$；
2. 后半部分（对每个元素减去 $2^{b-1}$ 后）等于 $S_{b-1}$ 向右循环移位 $1$ 位的序列，即：
   $$S_b[2^{b-1}] = 2^{b-1} + S_{b-1}[2^{b-1} - 1], \qquad S_b[2^{b-1} + t] = 2^{b-1} + S_{b-1}[t - 1] \quad (1 \le t \le 2^{b-1} - 1).$$

**证明**（对 $b$ 归纳）：
$b = 1, 2$ 已直接验证成立。设对 $b - 1$（$b \ge 2$）成立，且记 $u = S_{b-1}[2^{b-1} - 1] > 0$ 为 $S_{b-1}$ 的末尾元素。
1. 在前 $2^{b-1}$ 步中，由于候选池 $[0, 2^{b-1} - 1]$ 内部已存在完整合法的哈密顿路径 $S_{b-1}$，且其中所有元素均严格小于 $[2^{b-1}, 2^b - 1]$ 中的任何元素，贪心规则在前 $2^{b-1}$ 步必然完整走完 $S_{b-1}$，停在末尾元素 $u = S_{b-1}[2^{b-1} - 1]$。
2. 第 $2^{b-1}$ 步（0-based 下标 $2^{b-1}$）必须从 $u < 2^{b-1}$ 进入最高位为 $1$ 的半区 $[2^{b-1}, 2^b - 1]$。因为第 $b - 1$ 位必须从 $0$ 变为 $1$，此次转移只能是“若干个 $0$ 变为 $1$”。要使新数最小，应只把第 $b - 1$ 位从 $0$ 变为 $1$、其余为 $0$ 的位保持为 $0$，故必选 $2^{b-1} + u$，即 $S_b[2^{b-1}] = 2^{b-1} + S_{b-1}[2^{b-1} - 1]$。
3. 紧接着从 $2^{b-1} + u$ 出发，在后半区 $[2^{b-1}, 2^b - 1]$ 内移动时，最高位 $2^{b-1}$ 恒为 $1$（不再翻转），故两数之间的异或差 `diff` 在第 $b - 1$ 位为 $0$，合法转移条件在减去 $2^{b-1}$ 后与 $[0, 2^{b-1} - 1]$ 完全同构！
   由于 $u > 0$，从 $2^{b-1} + u$ 将低 $b - 1$ 位中的所有 $1$ 同时翻转为 $0$，即可一步直达后半区的最小元 $2^{b-1} + 0 = 2^{b-1} + S_{b-1}[0]$。
4. 从 $2^{b-1} + 0$ 开始，后半区剩余未访问的元素集合恰为 $\{2^{b-1} + x \mid x \in [0, 2^{b-1} - 1] \setminus \{0, u\}\}$。因为被提前访问的 $u = S_{b-1}[2^{b-1} - 1]$ 原本在 $S_{b-1}$ 的**最末尾**，所以在 $S_{b-1}$ 的前 $2^{b-1} - 2$ 步选择 $S_{b-1}[1], S_{b-1}[2], \dots, S_{b-1}[2^{b-1} - 2]$ 时，每一步的目标元都仍在剩余未访问集合中且仍是最小合法后继。因此后续路径逐项等于 $2^{b-1} + S_{b-1}[t - 1]$（$1 \le t \le 2^{b-1} - 1$）。归纳成立。$\blacksquare$

**引理 2（单点求值与前缀最大值的 $O(N)$ 递归式）**

由引理 1：
1. 对任意 $i \ge 2$，令 $p = 2^{\lfloor \log_2 i \rfloor}$，则 $S[i] = p + S[(i - p - 1) \bmod p]$；
2. 记 $\operatorname{solve\_max}(b, K) = \max_{0 \le i < K} S_b[i]$（$1 \le K \le 2^b$）：
   - 若 $K = 2^b$，前 $2^b$ 项遍历了 $[0, 2^b - 1]$，最大值为 $2^b - 1$；
   - 若 $K \le 2^{b-1}$，最大值为 $\operatorname{solve\_max}(b - 1, K)$；
   - 若 $2^{b-1} < K < 2^b$，记 $\text{rem} = K - 2^{b-1}$，由于后半区所有元素 $\ge 2^{b-1} >$ 前半区所有元素，最大值必在后半区的前 $\text{rem}$ 项中取到，而这 $\text{rem}$ 项正是 $2^{b-1} + S[2^{b-1} - 1]$ 以及（当 $\text{rem} \ge 2$ 时）$2^{b-1} + S_{b-1}[0 \dots \text{rem} - 2]$，故：
     $$\operatorname{solve\_max}(b, K) = 2^{b-1} + \max\big(S[2^{b-1} - 1],\; \operatorname{solve\_max}(b - 1, \text{rem} - 1)\big).$$

**证明**：
由引理 1 的分段表达式直接取 $\max$ 即得。每次递归 `b` 减 $1$，且最多调用一次 `get_s`（耗时 $O(b)$），故总时间复杂度为 $O(N^2)$。$\blacksquare$

## 3. 模式总结（Pattern Summary）

- **explore its property** — 通过小规模打表发现 $S_b$ 的后半区减去 $2^{b-1}$ 后恒等于 $S_{b-1}$ 循环右移 $1$ 位。
- **prove the recurrence** — 利用末尾元素 $u = S_{b-1}[2^{b-1}-1]$ 一步归零的性质证明半区循环右移定理（引理 1）。
- **reduce to easier problem** — 将前 $K$ 项最大值分解为后半区首项 $S[2^{b-1}-1]$ 与前半区前缀 $\operatorname{solve\_max}(b-1, K-2^{b-1}-1)$ 的二路取大（引理 2）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `n` | `int` | 二进制位数 $N \le 50$ | 读入 | 位数 |
| `k` | `u64` | 前缀长度 $K \le 2^N$ | 读入 | 项数 |
| `get_s(i)` | 函数 `u64(u64)` | 求序列第 $i$ 项（0-based）的值 | — | 单点求值 |
| `solve_max(b, rem_k)` | 函数 `u64(int, u64)` | 求 $S_b$ 前 `rem_k` 项的最大值 | — | 分治前缀最大 |

### 4.2 算法步骤

1. 读入 $N, K$。
2. 调用 `ans = solve_max(N, K)`。
3. 从高位 $i = N - 1$ 到 $0$ 依次输出 `(ans >> i) & 1`。

### 4.3 复杂度与验证报告

- **时间复杂度**：$O(N^2)$（$N \le 50$ 时至多 $2500$ 次位运算）。
- **空间复杂度**：$O(N)$（递归栈深度）。
- **对拍验证**：`appendix/P1647/P1647_check.py` 中对 $N \in [1, 9]$ 的全部 $1022$ 组 $(N, K)$ 与贪心模拟暴力基准进行了**全量穷举对拍**，100% 吻合；极限规模 $N = 50$ 实测耗时 **0.0154 s**。

## 5. 示例代码

```cpp
//
// 题目：P1647 锁
// https://www.luogu.com.cn/problem/P1647
// AC
#include<bits/stdc++.h>
using namespace std;
using u64=unsigned long long;

int n;
u64 k;

u64 get_s(u64 i)
{
	if(i<=1)
		return i;
	int b=__lg(i);
	u64 p=1ULL<<b;
	u64 ni=(i==p)?(p-1):(i-p-1);
	return p+get_s(ni);
}

u64 solve_max(int b,u64 rem_k)
{
	if(rem_k==(1ULL<<b))
		return (1ULL<<b)-1;
	if(b==1)
		return rem_k==1?0:1;
	u64 half=1ULL<<(b-1);
	if(rem_k<=half)
		return solve_max(b-1,rem_k);
	u64 rem=rem_k-half;
	u64 cand=get_s(half-1);
	if(rem>=2)
		cand=max(cand,solve_max(b-1,rem-1));
	return half+cand;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	u64 ans=solve_max(n,k);
	for(int i=n-1;i>=0;--i)
		cout<<((ans>>i)&1);
	cout<<'\n';
	return 0;
}
```
