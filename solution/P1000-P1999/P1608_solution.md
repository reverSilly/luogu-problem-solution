# P1608 路径统计

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给一张 $N$ 个点、$E$ 条**有向**边的图，边 $(I,J)$ 的花费为 $C$。求从 $1$ 号点到 $N$ 号点的**最少花费**，以及花费等于最少花费的路径条数。
两条最短路不同，当且仅当它们经过的**点编号序列**不同。
若 $N$ 号点不可达，输出 `No answer`。

### 输入输出格式

- **输入格式**：第一行 $N,E$；随后 $E$ 行，每行 $I,J,C$。**边信息可能重复**（同一个 $(I,J)$ 出现多次），但保证 $I\ne J$。
- **输出格式**：一行两个数"最少花费 路径条数"；不可达则输出 `No answer`。
- **数据规模**：$1\le N\le2000$，$0\le E\le N(N-1)$，$1\le C\le 10$；保证最短路条数 $\le 2^{30}$。

### 关键约束分析

1. **重边**：题面明说"边信息可能会重复"。若直接往邻接表里塞两条 $(u,v)$，同一条点序列会被算成两条路径（也可能被算成两条代价不同的边），必须对每个点对只保留**最小花费**的那条边。
2. $E$ 可达 $N(N-1)\approx4\times10^6$，而 $C\ge1$ 使最短路是简单路径，点数又只有 $2000$：用**邻接矩阵 + $\mathcal{O}(N^2)$ 的 Dijkstra** 既能顺手去重，又比堆优化在稠密图上更省常数。
3. 条数上界 $2^{30}$ 贴着 `int` 上限，累加时若再乘上别的量会溢出，用 `long long` 存计数最稳。
4. 不可达时不能输出 $0$ 条，要输出 `No answer`（注意大小写与空格：只有一个词）。
5. $N=1$ 时起点即终点，最短路长度为 $0$、条数为 $1$（空路径），需要单独处理。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：先解决"最短路长度"

$C\ge1$ 保证没有零环与负权，最短路模型干净。$N\le2000$、$E$ 可能到 $4\times10^6$，是典型稠密图。
堆优化 Dijkstra 是 $\mathcal{O}(E\log N)$，在这里约 $4\times10^7$ 次操作；而邻接矩阵 + 朴素 Dijkstra 是 $\mathcal{O}(N^2)=4\times10^6$，反而更快，而且天然把重边"合并"了——矩阵里每个格子只存最小值。

### 第二步：路径条数怎么算

先回忆一个不起眼但要命的事实：

**引理 1（重边合并引理）**：设同一对 $(u,v)$ 有多条边，花费分别为 $c_1\le c_2\le\dots$。则任意一条包含子路径 $(u\to v)$ 的最短路，用 $c_1$ 替换掉其它花费后仍然是一条合法路径，且花费不增；而题目只按点序列区分路径。因此只保留 $c_1$ 不会改变答案。

*证明*：路径的花费是各边花费之和，$C\ge0$ 保证替换后花费不超过原花费；若原路径是最短路，替换后花费 $\le$ 最短路长，只能取等号。点序列完全没变，故条数不变。同一点序列即使对应多条同花费的边，也只能算一条路径，因此保留一条 $c_1$ 既不漏也不重。$\square$

于是把图压成矩阵 $w[u][v]$（无边为 $\infty$，$w[u][u]=0$），问题只剩"在简单图上求最短路 + 计数"。

### 第三步：计数为什么能跟着 Dijkstra 一起做

**引理 2（Dijkstra 的定序性）**：设 $S$ 为已确定最短路的点集，每次从 $V\setminus S$ 中取 $dis$ 最小者 $u$ 加入 $S$，则 $dis[u]$ 已是 $1\to u$ 的真实最短路长。

*证明*：设真实最短路长为 $d(u)<dis[u]$。取该最短路上第一个不在 $S$ 中的点 $x$，则 $x$ 的前驱 $y\in S$，且 $d(u)\ge d(x)=dis[y]+w[y][x]\ge dis[x]$（松弛后 $dis[x]$ 不会大于此值）。又 $u$ 是当前 $dis$ 最小的未确定点，故 $dis[u]\le dis[x]$。于是 $d(u)\ge dis[x]\ge dis[u]$，与 $d(u)<dis[u]$ 矛盾。$\square$

**引理 3（计数递推）**：设 $f[v]$ 为 $1\to v$ 的最短路条数。当 $u$ 被确定、并用边 $(u,v)$ 松弛时：
- 若 $dis[u]+w[u][v]<dis[v]$，则 $dis[v]\gets dis[u]+w[u][v]$，$f[v]\gets f[u]$；
- 若相等，则 $f[v]\gets f[v]+f[u]$。

按此规则处理完整张图后，$f[v]$ 恰为最短路条数。

*证明*：对点的**定序**（被取出加入 $S$ 的先后）归纳。归纳假设：已被确定的点 $x$ 的 $f[x]$ 都正确。由引理 2，$dis[u]$ 最终确定。任取 $v$ 的一条最短路，其最后一条边必为某个 $(u,v)$ 且 $u$ 在 $v$ 之前被确定（因为 $dis[u]=dis[v]-w[u][v]<dis[v]$，$C\ge1$ 保证严格小）。于是 $v$ 的最短路 = 某个满足 $dis[u]+w[u][v]=dis[v]$ 的 $u$ 的最短路再接上边 $(u,v)$，且不同的 $u$ 对应不同的点序列（末边不同），同一个 $u$ 内部由归纳假设计数正确；这正是递推式所加的项。$\square$

注意递推中"只统计满足 $dis[u]+w[u][v]=dis[v]$ 的前驱"，这等价于在所有最短路上做一次拓扑累加——而 $C\ge1$ 保证最短路图无环，所以不会自我累加。

### 第四步：把两个引理拼起来

**定理**：邻接矩阵取最小值 + 朴素 Dijkstra + 上述计数递推，输出的 $(dis[N],f[N])$ 正确。

*证明*：引理 1 说明矩阵化不改变答案；引理 2 说明 $dis$ 正确；引理 3 说明 $f$ 正确。$\square$

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 题目只按点序列区分路径，因此同一对点的多条边中只有最小花费那条有意义。
- `reduce to easier problem` — 用邻接矩阵把重边合并，问题退化为"简单图最短路 + 计数"。
- `classic problem solution` — 稠密图用朴素 Dijkstra（$\mathcal{O}(N^2)$）代替堆优化，顺便完成重边去重。
- `count along the shortest-path DAG` — 松弛时"更短就重置计数、等长就累加"，把计数挂在最短路 DAG 的拓扑顺序上。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $N,E$ | `n,m` | 点数、输入边数（注意题面把边数记作 $E$） |
| $w[u][v]$ | `w[u][v]` | 邻接矩阵，存 $(u,v)$ 的最小花费；无边为 `inf`，$w[i][i]=0$ |
| $dis[v]$ | `dis[v]` | $1\to v$ 的最短路长，初值 `inf`，`dis[0]=0` |
| $f[v]$ | `cnt[v]` | $1\to v$ 的最短路条数（`i64`），初值 $0$，`cnt[0]=1` |
| $S$ | `vis[v]` | 该点最短路是否已确定，初值 `false` |
| $u$ | `u` | 本轮取出的、$dis$ 最小的未确定点（无则 `-1` 结束） |
| — | `nd` | 松弛候选值 `dis[u]+w[u][v]` |

### 算法步骤

1. 读入 $N,E$，把矩阵初始化为 `inf`、对角线置 $0$。
2. 逐条读边，`--u;--v;` 后执行 `w[u][v]=min(w[u][v],c)`（跳过 $u=v$ 的自环），完成重边合并。
3. 特判 $N=1$：输出 `0 1`。
4. `dis[0]=0, cnt[0]=1`；循环 $N$ 次：在 `!vis` 且 `dis<inf` 的点中取 $dis$ 最小者 $u$（取不到则 `break`），标记 `vis[u]=true`；对每个 `!vis[v] && w[u][v]<inf` 做引理 3 的松弛。
5. 若 `dis[n-1]>=inf` 输出 `No answer`，否则输出 `dis[n-1]` 与 `cnt[n-1]`。

### 复杂度分析

- **时间复杂度**：读入 $\mathcal{O}(E)$；选点 $\mathcal{O}(N^2)$；松弛 $\mathcal{O}(N^2)$；总计 $\mathcal{O}(N^2+E)$，$N=2000$ 时约 $4\times10^6$。
- **空间复杂度**：$\mathcal{O}(N^2)$（矩阵约 $16$ MB），其余 $\mathcal{O}(N)$。

### 正确性验证

- 引理 1 保证去重安全（这是本题最容易被忽略的一步，也是最常见的 WA 原因）。
- 引理 2 保证 Dijkstra 的定序正确（$C\ge1$ 使边权为正，前提成立）。
- 引理 3 保证计数在"最短路 DAG 的拓扑序"上累加，不漏不重。
- 数值范围：$dis\le (N-1)\cdot10\approx2\times10^4$，`int` 够；条数 $\le2^{30}$ 用 `i64` 累加绝对安全；`inf` 取 $10^9$，`dis[u]+w[u][v]` 最多 $10^9+10$，不会溢出。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1608 路径统计
// https://www.luogu.com.cn/problem/P1608
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005};                  // N<=2000
constexpr int inf{1'000'000'000};

int n,m;
int w[mxn][mxn];                          // 邻接矩阵, 重边取最小
int dis[mxn];                             // 最短路长度
i64 cnt[mxn];                             // 最短路条数
bool vis[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
	{
		fill_n(w[i],n,inf);
		w[i][i]=0;
	}
	for(int i=0,u,v,c;i<m;++i)
	{
		cin>>u>>v>>c;
		--u;--v;
		if(u!=v)
			w[u][v]=min(w[u][v],c);       // 重边只保留最小花费, 否则同一路径会被重复计数
	}
	if(n==1)
	{
		cout<<"0 1\n";
		return 0;
	}
	fill_n(dis,n,inf);
	fill_n(cnt,n,0);
	dis[0]=0;
	cnt[0]=1;
	for(int it=0;it<n;++it)
	{
		int u=-1;
		for(int i=0;i<n;++i)
			if(!vis[i]&&dis[i]<inf&&(u==-1||dis[i]<dis[u]))
				u=i;
		if(u==-1)
			break;
		vis[u]=true;
		for(int v=0;v<n;++v)
		{
			if(vis[v]||v==u||w[u][v]>=inf)
				continue;
			int nd=dis[u]+w[u][v];
			if(nd<dis[v])
			{
				dis[v]=nd;
				cnt[v]=cnt[u];
			}
			else if(nd==dis[v])
				cnt[v]+=cnt[u];
		}
	}
	if(dis[n-1]>=inf)
		cout<<"No answer\n";
	else
		cout<<dis[n-1]<<' '<<cnt[n-1]<<'\n';
	return 0;
}
```

### 易错点

1. **不去重边**：直接建邻接表，同一条点序列会被多条平行边重复计数，答案偏大。必须 `w[u][v]=min(w[u][v],c)`。
2. **自环**：若输入出现 $u=v$，`w[u][u]` 被写成 $1$ 会污染对角线；代码里跳过 $u=v$，且松弛时跳过 $v=u$。
3. **松弛到已确定的点**：`vis[v]` 的点再被"等长累加"会重复计数，必须跳过。
4. **`No answer` 拼写**：是一个词、只有首字母大写，不能写成 `No Answer` / `Noanswer`。
5. **输出空格**：两个数之间一个空格，行末不要多余空格。
6. **条数用 `int`**：上界 $2^{30}$ 已贴近上限，若题目数据在中间过程还有进项就会溢出，统一 `i64` 更省心。
