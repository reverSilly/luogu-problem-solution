# P1071 潜伏者 题解

## 一、重述题意

给定三个长度在 $1\sim 100$ 的大写字母字符串：

- $S_1$：截获的一条加密信息
- $S_2$：$S_1$ 对应的原始明文
- $T$：需要翻译的另一条加密信息

已知加密规则是一个**单射替换密码**（双射限制：明文到密文是单射，密文到明文也是单射，即每个字母唯一对应一个密字，不同字母不同密字，密字可以与原字母相同）。

任务：
1. 从 $S_1,S_2$ 的对应关系中推断完整的 $26$ 个字母的映射表。
2. 用映射表解密 $T$。

**失败条件**：
- **情况 2**：存在某个大写字母在 $S_2$ 中从未出现 → 无法确定其密字。
- **情况 3**：映射关系自相矛盾：
  - 同一个明文对应两个不同密文（$S_1[i]\neq S_1[j]$ 但 $S_2[i]=S_2[j]$）。
  - 两个不同明文对应同一个密文（$S_2[i]\neq S_2[j]$ 但 $S_1[i]=S_1[j]$）。

## 二、推演过程

### Step 1 — 提取已知约束

题面给了三条编码规则：

> **规则 1**：加密前后都由大写字母构成。
> **规则 2**：每个字母有唯一对应的密字。
> **规则 3**：不同字母对应不同密字。

规则 2 + 规则 3 等价于说：映射 $f:\Sigma\to\Sigma$（$\Sigma=\{\mathtt{A..Z}\}$）是一个**置换**（双射）。注意 $f$ 可以存在不动点（密字等于原字母），这不妨碍双射性。

### Step 2 — 扫描已知对，构造映射

我们遍历 $i=0\ldots |S_1|-1$，记 $p=S_2[i]$（明文），$c=S_1[i]$（密文），这条信息告诉我们 $f(p)=c$。

用两个数组维护双向映射：

- `enc[ch]`：明文 $ch$ 的加密结果 $f(ch)$，初始为 `-1`（未定义）。
- `dec[ch]`：密文 $ch$ 的解密结果 $f^{-1}(ch)$，初始为 `-1`。

**Lemma 1**（矛盾判定 1）：若 $enc[p]$ 已定义且 $enc[p]\neq c$，则规则 2 被违反（同一明文两个不同密字）→ Failed。

**Proof**：题面规则 2 要求每个明文唯一对应一个密字。若扫描过程中发现 $enc[p]$ 已存在且不等于当前 $c$，则 $p$ 同时映射到两个不同密字，矛盾。下标 $3$ 情形。

**Lemma 2**（矛盾判定 2）：若 $dec[c]$ 已定义且 $dec[c]\neq p$，则规则 3 被违反（不同明文对应相同密字）→ Failed。

**Proof**：规则 3 要求不同字母不同密字，即 $f$ 是单射，等价于 $f^{-1}$ 也是函数。$dec[c]$ 已存在且不等于当前 $p$ 说明两个不同明文映射到同一密字，矛盾。样例一即是此情况（ABA 与 XYZ → A 和 B 都映射到 A）。

### Step 3 — 检查覆盖性

扫描结束后，检查是否 $26$ 个字母全部在原信息中出现过：

**Lemma 3**（覆盖性判定）：若 $\exists\,ch\in\Sigma$ 使得 $enc[ch]==-1$，则无法唯一确定 $f(ch)$，输出 Failed。

**Proof**：规则要求每个字母都有密字，且我们的映射表必须能解密任意大写字母。若某个字母从未在原信息中出现，我们没有任何信息推断它的密字。样例二即是此情况。

### Lemma 4（覆盖性与双射的关系）

一个自然的问题是：如果 $26$ 个字母全部出现，且没有发生矛盾，是否自动保证了双射？

**Proof**：若 $S_2$ 覆盖了所有 $26$ 个字母，则 $enc$ 是定义在全集 $\Sigma$ 上的函数。由于 $|enc| = |\Sigma| = 26$，且扫描过程中 $enc$ 和 $dec$ 没有冲突，实际上 $enc$ 和 $dec$ 互为反函数，构成一个置换。这是因为 $enc$ 的像集大小恰好也是 $26$（不可能更小，否则会有两个明文映射到同一密文，即矛盾情形 2）。所以覆盖性 + 无矛盾 $\implies$ 双射已完全确定。

### Step 4 — 翻译

有了完整的 $f^{-1}$（即 `dec` 数组），我们逐字符翻译 $T$：

$ans_i = dec[T[i]]$

直接拼接输出即可。

## 三、模式总结

| 模式 | 要点 |
|------|------|
| **单射替换密码** | 双射限制：两个方向的映射都必须唯一；用两个数组分别维护正向和反向 |
| **扫描建表 + 矛盾检测** | 遍历已知对，发现冲突立即失败 |
| **覆盖性检查** | 所有 $26$ 个字母必须都有映射，缺一个就失败 |
| **翻译** | 用已建立的反向映射表逐字符解码 |

思考顺序：读题 → 提取双射约束 → 正向 + 反向数组 → 逐对扫描 → 冲突检测 → 覆盖性检测 → 翻译输出。

## 四、具体解法

### 数据结构

- `enc[26]`：`enc[x] = y` 表示明文 $x$ 加密为密文 $y$，$-1$ 表示未知。
- `dec[26]`：`dec[y] = x` 表示密文 $y$ 解密为明文 $x$，$-1$ 表示未知。

符号约定：

| 符号 | 含义 |
|------|------|
| $S_1$ | 输入的加密信息 |
| $S_2$ | 对应的原信息（明文） |
| $T$ | 待翻译的加密信息 |
| $p$ | 当前扫描到的明文 $(S_2[i])$ |
| $c$ | 当前扫描到的密文 $(S_1[i])$ |
| $enc[\,\cdot\,]$ | 明文到密文的映射表 |
| $dec[\,\cdot\,]$ | 密文到明文的映射表 |

### 算法步骤

```
1. 读入 S1, S2, T
2. 初始化 enc 和 dec 为 -1
3. 遍历 i = 0..|S1|-1:
   p = S2[i] - 'A', c = S1[i] - 'A'
   if enc[p] != -1 && enc[p] != c → Failed (矛盾1)
   if dec[c] != -1 && dec[c] != p → Failed (矛盾2)
   enc[p] = c, dec[c] = p
4. 遍历 ch = 0..25:
   if enc[ch] == -1 → Failed (未覆盖)
5. 遍历 i = 0..|T|-1:
   输出 dec[T[i]-'A'] + 'A'
```

**复杂度**：$O(n + 26)$，其中 $n$ 为字符串长度。

## 五、示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

string s1,s2,t;
int enc[26],dec[26];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s1>>s2>>t;
	fill_n(enc,26,-1);
	fill_n(dec,26,-1);
	for(int i=0;i<s1.size();++i)
	{
		int p=s2[i]-'A',c=s1[i]-'A';
		if(enc[p]!=-1&&enc[p]!=c){cout<<"Failed\n";return 0;}
		if(dec[c]!=-1&&dec[c]!=p){cout<<"Failed\n";return 0;}
		enc[p]=c;dec[c]=p;
	}
	for(int i=0;i<26;++i)
		if(enc[i]==-1){cout<<"Failed\n";return 0;}
	for(char ch:t)
		cout<<char(dec[ch-'A']+'A');
	cout<<'\n';
	return 0;
}
```
