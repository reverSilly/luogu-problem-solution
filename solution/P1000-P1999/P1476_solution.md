# P1476 休息中的小呆

> 标签：图论 · 难度：普及/提高- · 模型：AOV 网 / 关键路径（DAG 双向最长路 DP）

## 1. 重新读题

**一句话重述**：给出 $n$ 个"剧情结束点"和 $m$ 条"剧情"，每条剧情是有向带权边 $i\to j$（耗时 $k$），含义是"必须完成这条耗时 $k$ 的剧情，才能到达结束点 $j$"。不同分支可同时进行。求看完所有剧情所需的**最少时间**，以及所有**可能被经过的剧情结束点**（升序）。

**原文里可用的三句关键信息**

1. "**不同的分支剧情是可以同时进行的**" —— 允许并行，总时间**不是**各剧情耗时之和，而是"最长的串行链条"。
2. "**某些剧情必须要在一些特定的剧情结束后才能继续发展**" + "从 $i$ 必须完成耗时 $k$ 的剧情才能到达 $j$" —— 这是**前驱约束**：$i$ 先发生、$j$ 后发生，中间隔着耗时 $k$。
3. "小呆决定要**看到所有的分支剧情——完成所有的任务**" —— 每条边都**必须被走一次**（不是选一条路走到底）。

**形式化模型（AOV 网 / 关键路径）**

- 顶点集合 $V$：剧情结束点，编号满足 $1\le\text{编号}\le 100$。边集合 $E$：$m$ 条剧情，$e=(u,v,w)$ 表示"$u$ 发生后花 $w$ 时间播这段剧情，然后 $v$ 发生"。
- 记结束点 $v$ 的发生时刻为 $t_v$、剧情 $e$ 的完成时刻为 $s_e$，约束是
  $$s_{(u,v,w)}\ge t_u+w,\qquad t_v=\max_{(u,v,\_)\in E}s_{(u,v,\_)}\ (v\text{ 有入边}),\qquad t_v=0\ (v\text{ 无入边}).$$
  第二式读作：**要"到达" $v$，得把通往 $v$ 的所有剧情都完成**（汇合点是"等待"语义而非"任选一条"）。这是本模型唯一需要主观选择的一句，也是全题最关键的语义选择，§2.3 直觉 5 会把另一条路摊开比较。
- 目标：最小化 makespan $\max_{e\in E}s_e$（全部剧情放完的时刻），并给出"可能被经过"的 $v$ 集合。

**数据范围 → 复杂度预算**

| 量 | 上界 | 推出的松弛 |
|---|---|---|
| $n$ | $99$ | 点数极小，$O(n^2)$、$O(nm)$ 都随便 |
| $m$ | $120$ | 边数多于点数，允许多重边 |
| 编号 $i,j$ | $100$ | 数组开到 $105$ 够用（`mxn{105}`） |
| $k$ | $1000$ | 单条剧情耗时；链长上界见 §2.6 |

规模这么小，说明考点不是"优化"而是**建模 + 输出集合的正确刻画**（本地题面记录 $1537/3357\approx46\%$ 通过，正印证：思路对但点集算错就 WA）。

**题面留下的坑（后面逐条处理）**

- 本地题面**没有样例**，无法与官方答案对标（§4.6 用自造数据 + 手算轨迹验证）。
- 三元组顺序未明确：行文是"从 $i$ … 耗时 $k$ … 到达 $j$"（$i,k,j$），但竞赛惯例是 `起点 终点 权`。本文按 `i j k` 实现，§2.1 末尾说明如何判别与替换。
- 输出格式未明确（换行/分隔符）。本文按"第一行时间，第二行升序点、空格分隔"实现。
- 编号上界 $100$ 与 $n<100$ 不一致：编号可能不被 $1..n$ 覆盖，代码用"出现过"标记而非 $1..n$ 循环。

**"所有可能的剧情结束点"到底指什么（三种候选读法）**

- 读法 A：**所有度数非零的点**。每条剧情都要放一遍，则每个出现在边上的点必然被到达，于是该集合与"最少时间"完全无关，第二问退化为一行 `for` —— 不像出题意图。**排除**。
- 读法 B：**某一条**决定总时间的最长链上的点。最长链常有多条，"哪一条"不唯一，而题目说"所有**可能**的"。**接近但不完整**。
- 读法 C：**所有"在某条最长（关键）链上"的点的并集**，升序输出。"可能"正好对应"无法判定究竟哪条链卡住总时间，所以每条都算可能"。**采用**，§2.4 引理 9 给出可判定刻画 $f[v]+g[v]=T$ 并证明双向包含。

> 读法 A 是 C 的松弛（关键集合 $\subseteq$ 非孤立点集合），B 是 C 的特例（最长链唯一时两者一致）；三者只在"存在并列最长链或有非关键分支"时才差别 —— 这正是 46% 通过率的来源。

## 2. 思维链（Chain-of-thought）

### 2.1 先把"必须…才能…"翻译成约束：这是一张有向图

拿到题我先做的不是想算法，而是**把文字里的对象数清楚**：

- 对象 1：剧情结束点。"从 $i$ … 才能**到达** $j$" 里的"到达"说明 $i,j$ 是**状态/事件**，不是活动本身。
- 对象 2：剧情。"完成一个**耗费时间为 $k$** 的剧情"说明耗时挂在**转移**上、不挂在点上，所以 $k$ 是**边权**，不是点权 —— 这一步直接排除了"点权前缀和"那一类做法。
- 对象 3：$m$ 行每行一条转移，方向明确（$i$ 在前、$j$ 在后），**不是**无向边。

于是结构是"带权有向图 $G=(V,E)$"。接着问自己：**"同时进行"在数学上是什么？**
答：两条**没有先后约束**的剧情可以同一时刻各播各的，所以"某个点什么时候发生"由"**所有**必须先于它完成的剧情里最晚的那个"决定 —— 是 $\max$，不是 $\sum$。这个想法很朴素，但它把题目从"求和"推到"求最长"，是全题的第一次转折。

**引理 1（题面未指定源汇，图可不连通，编号可能超出 $n$）**

不能假定"源点是 $1$、汇点是 $n$"，必须允许多个入度 $0$ 的起点、多个出度 $0$ 的终点、多个互不相连的分支。

**证明**：这不是性质而是"题面没有给出约束"。逐条检查输入格式：第一行只给 $n$（点数），第二行只给 $m$（边数），随后 $m$ 行只给边，**没有任何一行**给出起点或终点编号；输出格式只说"所有可能的剧情结束点"，没说"从某点出发"。既然题面未声明，"源点是 $1$"就属于**擅自加强条件**，可构造反例数据（$n=4$、只有 $3\to4$ 与 $1\to2$ 两条边）。同理，数据范围写 $0<i,j\le100$ 而 $0<n<100$，两者不一致，编号是否一定 $\le n$ 也无保证。故算法必须对"多源、多汇、可不连通、编号超出 $n$"都成立。$\blacksquare$

该引理的实际作用：DP 初值取"空集 $\max=0$"（无入边的点时刻为 $0$），答案取**全体点的最大值**而非某个指定汇点的值；扫描范围按"出现过的编号"而非 $1..n$（§4.1 的 `exist`）。

**关于三元组顺序的处理**：本文取 `i j k`（起点、终点、权）。判别方法（拿到真实数据时）：若某组数据第 2、3 列中有一列恒 $\le100$ 而另一列常出现 $>100$ 的值，则 $\le100$ 的那列是编号、另一列是权；两列都 $\le100$ 时无法靠值域区分，只能靠方向性检验（把 $i,j$ 与 $k$ 互换读入，看输出是否出现"耗时大于上界"或"点集为空"等不合理解）。若确认是 `i k j`，代码里只需把读入行改成 `cin>>u>>w>>v;`，其余一字不动 —— 这是**一处改动、全局生效**的结构，正是把它单独写成一行的好处。

### 2.2 简化版：先看三个最小的图，把手算结果当"标尺"

我不急着写代码，先解三个最小实例，用来事后检验算法。

**实例 1（一条链）** $1\xrightarrow{3}2\xrightarrow{4}3$，$n=3,m=2$。链上每条剧情都受前一条约束，无法并行，时间 $=3+4=7$，三个点都"可能经过"。

**实例 2（扇出/星）** $1\xrightarrow{3}2,\;1\xrightarrow{5}3$，$n=3,m=2$。两条剧情从已到达的 $1$ 出发**可同时播**，$t_2=3,t_3=5$，全部放完 $=\max(3,5)=5$。这里 $\sum=8$ 与 $\max=5$ 第一次分家，说明"求和"直觉从第二步就错；卡住总时间的是 $1\to3$。

**实例 3（先分后合/菱形）** $1\to2(2),\;1\to3(3),\;2\to4(5),\;3\to4(1)$，$n=4,m=4$。按"汇合点等所有入边"：$t_2=2,\;t_3=3,\;t_4=\max(2+5,\,3+1)=7$，时间 $=7$。两条入边中 $2\to4$（完成于 $7$）卡住了 $4$，$3\to4$（完成于 $4$）有 $3$ 的空闲。

**引理 2（三个实例暴露的通用形状）**

"最早可能到达各结束点的时刻"由递推
$$t_v=\begin{cases}0 & \text{入度为 }0\\ \max_{(u,v,w)\in E}\,(t_u+w) & \text{否则}\end{cases}$$
唯一确定，且 $\max_v t_v$ 就是用满并行时完成全部剧情最早的时刻。

**证明**：良定义性：无环时按拓扑序处理，$t_v$ 只依赖入边，归纳即得唯一解（严格写出见 §2.4 引理 5）。
下界：任一合法调度中，沿任意有向路径 $v_0\to\cdots\to v_p$，由 $t_{v_r}\ge s_{(v_{r-1},v_r,w_r)}\ge t_{v_{r-1}}+w_r$ 逐段累加得 $t_{v_p}\ge\sum_r w_r$，故 makespan $\ge$ 最长路径长度 $L$。
上界：把每条剧情 $(u,v,w)$ 排在 $[t_u,t_u+w]$（$t$ 取递推值），约束 $t_v\ge t_u+w$ 恰由递推保证，于是全部剧情在 $\max_v t_v=L$ 之前放完（$t$ 的最大值在最长路终点取到，故等号成立）。
下界与上界相同，故最小 makespan $=L$。$\blacksquare$

> 注意实例 3 里 $1\to3\to4$ 只到 $4$ 却仍然"被经过"——它不是关键链。这已经暗示第二问不是"所有点"。

### 2.3 剖析会失败的直觉（每个都用具体小数据打脸）

**直觉 1："要把 $m$ 条剧情全看一遍，所以时间 $=\sum w$。"**
反例（实例 2）：$1\to2(3),\;1\to3(5)$，和为 $8$；但两条剧情共用已到达的 $1$，题面明说"可同时进行"，同时开播后 $5\ne8$。**错在没把"并行"计入模型。**

**直觉 2："并行之后就是最长的那条边。"**
反例（实例 1）：$1\to2(3),\;2\to3(4)$，最长单边 $=4$；但 $2\to3$ 必须在 $1\to2$ 之后，串行相加 $=7>4$。**错在忽略"边的先后约束会传递成链"**，正确的是最长**路径**而非最长**边**。

**直觉 3："先求一条最长路径，路径上的点就是要输出的点。"**
反例：$1\to2(4),\;2\to4(4),\;1\to3(4),\;3\to4(4)$，$n=4,m=4$。两条链都是 $8$，$T=8$；回溯 `fa[]` 只记住"最后更新它的那条边"，只会输出 $\{1,2,4\}$ 或 $\{1,3,4\}$，而按读法 C 应输出 $\{1,2,3,4\}$。**错在把"并集"当成"某一条"**：必须是逐点**判定式**，不能靠单链回溯。

**直觉 4："$v$ 在关键链上 $\iff$ $f[v]=T$ 或 $g[v]=T$。"**
反例还是实例 3（$T=7$，关键链 $1\text{-}2\text{-}4$）：中间点 $2$ 满足 $f[2]=2$、$g[2]=5$，两者都**不等于** $7$，但 $2$ 确实在关键链上。正确条件是 $f[v]+g[v]=T$。**错在只用"一头"的信息** —— 这个反例直接决定了后面 DP 必须做**两遍**。

**直觉 5（语义层面的分歧，必须表态）："到达 $v$ 只需完成它的某一条入边，所以 $t_v=\min_{(u,v,w)}(t_u+w)$。"**
这是一个**自洽的另一套模型**（"通关只需找到一条能看全所有边的走法"），不能靠反例否定，只能靠题面语义选择。分歧数据：$1\to2(1),\;3\to2(100),\;2\to4(5)$。

- $\max$ 语义（本文采用）：$t_2=\max(1,100)=100$，$t_4=100+5=105$，$T=105$。
- $\min$ 语义：$t_2=\min(1,100)=1$，$t_4=6$，再取全部边完成时刻的最大值 $\max(1,100,6)=100$，$T=100$。

**本文选 $\max$ 语义的理由（引理 3）**：题面"**某些剧情必须要在一些特定的剧情结束后才能继续发展**"＋"**完成所有的任务**"。设 $v$ 有两条入边，若"任选其一即算到达"，另一条入边播放完回到 $v$ 时**无法再触发 $v$ 之后的任何新剧情**（$v$ 早已"到达"过），这条分支就成了死路，与"看完所有分支"矛盾；而"结束点"作为**状态汇合点**、"事件在所有先行活动完成后才发生"正是关键路径 AOE 网的标准语义。此外 $\min$ 语义下一条边的完成时刻可晚于其头节点的"到达时刻"，"经过"关系不再沿路径单调，第二问将失去 $f[v]+g[v]=T$ 这样干净的刻画。故本文按 $\max$ 实现；若判题用另一套语义，改动见 §4.5。

### 2.4 经典解法：关键路径 + "双向最长路相等"判定

直觉 4 之后形状已清楚：**要两遍 DP**（顺着时间一遍、逆着时间一遍），再用 $f[v]+g[v]=T$ 判定点是否在关键链上。下面把每个断言证完。

**记号（全文固定）**

- $G=(V,E)$，边 $(u,v,w)$，$w\ge1$；$V$ 取"在至少一条边中出现过的编号"（引理 1 的推论）。
- $P=v_0\to\cdots\to v_p$ 是有向路径，$\ell(P)=\sum_{r=1}^{p}w(v_{r-1},v_r)$，$p=0$（单点）时 $\ell(P)=0$。
- $f[v]=\max\{\ell(P):P$ 以 $v$ 结尾$\}$，$g[v]=\max\{\ell(P):P$ 以 $v$ 开头$\}$（都含单点路径，故 $\ge0$）。
- $L=\max\{\ell(P):P$ 是 $G$ 中的有向路径$\}$，$T=\max_v(f[v]+g[v])$。

**引理 4（数据必须无环，否则题目无解）**

若 $G$ 含有向环 $v_0\to v_1\to\cdots\to v_0$（各边权 $\ge1$），则不存在任何合法调度。

**证明**：合法调度给出各点时刻 $t_v$。沿环逐条边用约束 $t_{v_r}\ge t_{v_{r-1}}+w_r$（下标模环长），首尾相接累加得 $t_{v_0}\ge t_{v_0}+\sum_r w_r>t_{v_0}$，矛盾（$\sum_r w_r\ge$ 环长 $\ge1>0$）。故"存在合法调度"蕴含"无环"；题面要求"完成整个游戏"，即默认合法调度存在，所以输入是有向无环图。$\blacksquare$

（附带好处：DAG 中路径不重复顶点，最长路是良好且有限的对象 —— §2.6 的上界估计正用这一点。）

**引理 5（$f$ 的递推正确，可按拓扑序计算）**

设 $G$ 为 DAG，则 $f[v]=\max\big(\{0\}\cup\{f[u]+w:(u,v,w)\in E\}\big)$，且按拓扑序处理时算出的值等于真值。

**证明**：
"$f[v]\le$ 右端"：任取以 $v$ 结尾的路径 $P$。单点时 $\ell(P)=0\le$ 右端；否则 $P$ 的最后一条边是 $(u,v,w)$，前缀 $P'$ 以 $u$ 结尾，$\ell(P)=\ell(P')+w\le f[u]+w\le$ 右端。对全体 $P$ 取最大即得。
"$f[v]\ge$ 右端"：右端取最大的项若是 $0$，对应单点路径，可达；若是某条 $(u,v,w)$ 的 $f[u]+w$，由 $f[u]$ 定义存在以 $u$ 结尾的路径 $Q$ 使 $\ell(Q)=f[u]$（DAG 中路径有限条，$\max$ 必被取到），把 $(u,v,w)$ 接在 $Q$ 后面即以 $v$ 结尾、长度 $f[u]+w$，故 $f[v]\ge f[u]+w$。
"拓扑序时已确定"：对 $v$ 在拓扑序中的位置归纳。基例入度 $0$：右端只剩 $\{0\}$，$f[v]=0$，与"$v$ 只能由单点路径结尾"一致。归纳步：$v$ 的所有前驱 $u$ 排在 $v$ 之前，其 $f[u]$ 已按归纳假设等于真值，故代入递推式算出的正是真值。$\blacksquare$

**引理 6（$g$ 的递推正确，可按逆拓扑序计算）**

$g[v]=\max\big(\{0\}\cup\{w+g[u]:(v,u,w)\in E\}\big)$，按拓扑序**逆序**处理时值正确。

**证明**：与引理 5 对称（每条边反向、路径反向）。
"$g[v]\le$ 右端"：以 $v$ 开头的路径 $P$ 若单点则长 $0$；否则第一条边 $(v,u,w)$，后缀 $P'$ 以 $u$ 开头，$\ell(P)=w+\ell(P')\le w+g[u]$。
"$g[v]\ge$ 右端"：右端最大项若来自 $(v,u,w)$，取以 $u$ 开头、长 $g[u]$ 的路径 $Q$（存在性同上），把 $(v,u,w)$ 接在前面得长度 $w+g[u]$ 的以 $v$ 开头路径。
"逆序时已确定"：逆拓扑序中 $v$ 的后继 $u$ 先被处理，逆序位置归纳，基例出度 $0$ 的点 $g=0$（确无出边可走）。$\blacksquare$

**引理 7（拼接引理：DAG 里 $f[v]+g[v]$ 一定可实现为一条路径）**

对每个 $v$，存在经过 $v$ 的有向路径 $P$ 使 $\ell(P)=f[v]+g[v]$；特别地 $f[v]+g[v]\le L$。

**证明**：取以 $v$ 结尾的 $Q$ 使 $\ell(Q)=f[v]$、以 $v$ 开头的 $R$ 使 $\ell(R)=g[v]$（存在性：DAG 中路径只有有限条，有限集上的 $\max$ 必被取到）。
断言：$Q$ 与 $R$ 除 $v$ 外无公共顶点。**反证**：设 $x\ne v$ 同时在两者上。$Q$ 从起点走到 $v$ 途中经过 $x$，故有有向路径 $x\rightsquigarrow v$；$R$ 从 $v$ 出发经过 $x$，故有 $v\rightsquigarrow x$。两者相接得 $x\rightsquigarrow v\rightsquigarrow x$，是一条长度 $\ge1$ 的有向闭路径，与无环矛盾。
于是 $P=Q\to R$ 在 $v$ 处拼接后**不重复顶点**（即真正的路径），$\ell(P)=f[v]+g[v]\le L$（按 $L$ 的定义）。$\blacksquare$

> **这是"必须有向无环"真正被用到的地方**：若有环，$Q,R$ 可能共享顶点而拼不成简单路径，判定式失真（虽然此时按引理 4 整个问题已无解）。

**引理 8（$T=L$，且 $\max_v f[v]=\max_v g[v]=L$）**

**证明**：
- $T\le L$：由引理 7 每个 $f[v]+g[v]\le L$，取最大仍 $\le L$。
- $L\le T$：取达到 $L$ 的路径 $P=v_0\to\cdots\to v_p$。$P$ 本身就是"以 $v_0$ 开头"的路径，故 $g[v_0]\ge\ell(P)=L$，又 $f[v_0]\ge0$，于是 $T\ge f[v_0]+g[v_0]\ge L$（**不需要**假设 $v_0$ 是源点，路径起点是谁都无所谓）。
- $\max_v f[v]=L$：每个 $f[v]\le L$（定义域是路径集合）；$P$ 的终点 $v_p$ 满足 $f[v_p]\ge L$。同理 $\max_v g[v]=L$（用起点 $v_0$）。
- 顺带结论：**取到 $\max f$ 的点必然 $g=0$** —— 若 $g[x]>0$ 则有出边 $(x,y,w)$，$f[y]\ge f[x]+w>f[x]=L$，与 $\max f=L$ 矛盾。故 $\max_v f[v]$ 与 $\max_v(f[v]+g[v])$ 是同一个数，代码用后者。$\blacksquare$

**引理 9（核心刻画：$v$ 在某条最长路上 $\iff$ $f[v]+g[v]=T$）**

**证明（双向）**：
- $(\Leftarrow)$：设 $f[v]+g[v]=T=L$。引理 7 给出经过 $v$ 且长 $f[v]+g[v]=L$ 的路径，它就是一条最长路，故 $v$ 在某条最长路上。
- $(\Rightarrow)$：设 $v$ 在某条最长路 $P=v_0\to\cdots\to v_p$ 上，$v=v_i$。记 $\alpha=\ell(v_0\to\cdots\to v_i)$、$\beta=\ell(v_i\to\cdots\to v_p)$，则 $\alpha+\beta=\ell(P)=L$。由定义 $\alpha\le f[v]$、$\beta\le g[v]$，故 $f[v]+g[v]\ge\alpha+\beta=L=T$；又引理 7 给 $f[v]+g[v]\le L$。两边夹得 $f[v]+g[v]=L=T$，且同时得到 $\alpha=f[v],\ \beta=g[v]$ —— 即**最长路在关键点处的前/后缀本身也必须是最优的**，这就是"关键路径无冗余"。$\blacksquare$

由引理 9，"属于至少一条最长路"与一个**只含 $v$ 自身两个数**的等式等价，因此可逐点独立判断，无需枚举路径或记录前驱：直觉 3 与直觉 4 的错误就此被排除。

### 2.5 执行顺序是否影响答案：最终状态的唯一刻画

本题是"传播/并发"类（完成一条剧情解锁后继），所以必须回答：**小呆按某种顺序推进剧情，答案会不会随顺序而变？**
这里给出"引爆顺序 $\leftrightarrow$ 最终状态"的等价刻画。
**定义（调度/顺序）**：把 $m$ 条剧情排成一个合法序列（每条排在它所有前驱剧情之后），并规定各条的开始时刻。

**引理 10（最终状态唯一，与顺序无关）**

设 $G$ 为 DAG，则 (1) 任意合法调度中 $t_v\ge f[v]$ 对所有 $v$ 成立；(2) "最早开始"调度（剧情一解锁就开播）给出 $t_v=f[v]$；(3) 于是所有最早开始调度的 makespan 都等于 $L$，**与剧情被安排的先后顺序无关**，最终状态（向量 $(t_v)_v$）由图结构唯一决定。

**证明**：
(1) 对 $v$ 在拓扑序中的位置归纳。基例入度 $0$：无任何入边约束，模型定义 $t_v=0=f[v]$。归纳步：设 $v$ 的每个前驱 $u$ 已满足 $t_u\ge f[u]$，则按模型 $t_v=\max_{(u,v,w)}(t_u+w)\ge\max_{(u,v,w)}(f[u]+w)=f[v]$，最后一步等号正是引理 5 的递推式。
(2) 最早开始调度里每条 $(u,v,w)$ 在 $t_u$ 开播、$t_u+w$ 完成，$t_v$ 就是所有入边完成时刻的最大值 —— 与引理 5 的递推是**同一组方程**，按拓扑序归纳得 $t_v=f[v]$。
(3) makespan $=\max_v t_v=\max_v f[v]=L$（引理 8）。顺序无关的根源：$v$ 处是 $\max$ 聚合，而 $\max$ 可交换、可结合，任意排列对同一集合求最大值结果相同。$\blacksquare$

**若顺序真的相关怎么办**：假如题面再加一句"同一时刻只能播放一段剧情"（资源 $=1$），makespan 变成排序型调度问题，开始时刻不再都能提前，$t_v$ 依赖安排顺序，上面 (2)(3) 全部失效。此时正确做法是**在状态空间里搜索顺序**：状态 = 已完成的剧情集合（$m\le120$，$2^{120}$ 不可行），故只有 $m$ 很小（$\le20$）时才可用状压 BFS/DP 枚举。本题**明确写了"不同的分支剧情是可以同时进行的"**，无需搜索顺序，直接取 $L$ —— 这也解释了为什么 $n,m$ 这么小却只要 $O(n+m)$ 级算法。

### 2.6 归约链与溢出防护

**归约链（每步都是等价替换，不是放缩）**

$$\text{原题}\;\overset{\text{引理 2}}{\Longleftrightarrow}\;\text{AOV 网的 makespan}\;\overset{\text{引理 4}}{\Longleftrightarrow}\;\text{带权 DAG 最长路 }L\;\overset{\text{引理 5,6}}{\Longleftrightarrow}\;\text{拓扑序两遍 DP}\;\overset{\text{引理 8}}{\Longleftrightarrow}\;T=\max_v(f+g)\;\overset{\text{引理 9}}{\Longleftrightarrow}\;\{v:f[v]+g[v]=T\}.$$

所以第一问与第二问共用同一组 $f,g$，代码里没有任何"另算一遍"的分支。

**数值上界（证明 `int` 足够，不需要 `long long`）**

**引理 11（$T\le 99000$）**

**证明**：由引理 4，$G$ 无环，故最长路是**简单路径**（不重复顶点：若某顶点重复出现，则两次出现之间的子段是一条有向闭路径，含环，矛盾）。编号满足 $1\le\text{编号}\le100$，故 $|V|\le100$，简单路径至多 $100$ 个点、$99$ 条边；每边权 $k\le1000$，于是 $L=T\le99\times1000=99000$。DP 中出现的最大中间量是 $f[u]+w\le99000+1000=10^5$（事实上每个 $f[u]+w$ 都参与某个 $f[v]$ 的 $\max$，已被上界覆盖，$10^5$ 是宽松估计）。而 $10^5\ll2^{31}-1=2\,147\,483\,647$，余量约两万倍，`int` 安全。$\blacksquare$

反面检查：**若** $k$ 的上界是 $10^9$（看错题或数据加强），$99\times10^9\approx10^{11}$ 会**爆 `int`**，须按风格指南加 `using i64=long long;` 并把 `f`,`g`,`T` 改成 `i64`。本题不需要，故 §5 保持 `int`，不写多余的 64 位。

**哨兵值陷阱（本题最容易"顺手写错"的地方）**：$f,g$ 的定义是 $\max$ 且**天然含长度 $0$ 的空路径**，合法初值是 $0$，**不是** $\pm\infty$。若把最短路模板里的 `fill_n(dis,n,1145141919)` 搬来当 $f$ 的初值，`f[v]=max(f[v],f[u]+w)` 会让整表停在哨兵上，$T$ 变成 $2\times10^9$ 级、点集判定全盘皆错，而且这种错在小程序上"看起来有输出"，肉眼难发现。只有把 $f[v]$ 重新定义成"必须至少走一条边"时才需要 $-\infty$，但那样又会漏掉关键链端点，所以本题**必须**保留 $0$ 初值 —— 引理 8 里"$\max f$ 的点必然 $g=0$"正依赖这个约定。

**多重边与自环**

- 多重边 $u\to v$（不同 $w$）：邻接表自然保留两条，$\max$ 递推自动取较优；拓扑排序的入度按条数累加、也按条数递减，两者一致不会算错，引理 5 的递推式对所有入边取 $\max$ 仍成立。
- 自环 $u\to u$：按引理 4 使题目无解。§5 代码用"拓扑序长度 $<$ 出现过的点数"检测到该情况，未进入拓扑序的点 $f,g$ 保持 $0$，并被 `f>0||g>0` 排除在答案外。本地题面对此类数据没有任何承诺（见 §4.6 的已知缺口）。

## 3. 模式总结（Pattern Summary）

**模式名：AOV 关键路径（带权 DAG 最长路）+ "双向 DP 值相等"判定元素是否在最优链上。**

### 3.1 题面信号词 → 技术对照

| 题面里出现的措辞 | 立刻想到 | 本题对应 |
|---|---|---|
| "必须完成 A 之后才能开始/到达 B" | 有向前驱约束 → DAG | $i\to j$ |
| "可以同时/并行进行" | 取 $\max$ 不取 $\sum$；makespan $=$ 最长链 | 分支并行 |
| "至少需要多少时间（做完整件事）" | 关键路径长度 / DAG 最长路 | $T=L$ |
| 权挂在"过程/任务/剧情"上而非状态上 | 边权，不是点权 | $k$ 是边权 |
| 没给起点终点、没说连通 | 多源多汇、可分组件；初值 $0$、全局 $\max$ | 引理 1 |
| "所有可能的 X（升序输出）" | 求"某类最优结构的**并集**"，需要**逐点独立判定式** | $f[v]+g[v]=T$ |
| 需要"在第 $i$ 个位置/元素上是否影响答案" | 前缀最优 $+$ 后缀最优 $=$ 全局最优 | 双向 DP |

### 3.2 通用套路（可迁移的三步骤）

1. **把"最少时间"翻译成最长路**：只要允许并行且存在串行链，答案天然是"最长链"；"最长"在 DAG 上用拓扑序 DP，在链/环这类线性结构上退化成前缀和或尺取。
2. **双向 DP**：正向 $f$（从任意源到 $v$ 的最优）、反向 $g$（从 $v$ 到任意汇的最优）。遍历两遍、代价 $\times2$，换来"逐点可判"。
3. **用等式判元素归属**："元素在某条最优结构上" $\iff f[v]+g[v]=T$。同一套路在其他题里换了外衣：
   - 最短路版：$dist_s[v]+dist_v[t]=dist_s[t]$ $\Rightarrow$ $v$ 在某条最短路上；
   - 树形版：$down[v]+up[v]=$ 直径 $\Rightarrow$ $v$ 在某条直径上；
   - LIS 版：$pre[i]+suf[i]-1=|LIS|$ $\Rightarrow$ $a_i$ 可出现在某个最长上升子序列中。
   **共同前提**：能把"前缀最优"与"后缀最优"在 $v$ 处拼成一条合法结构。DAG 上这个前提靠**无环**（引理 7 的反证）；一般图上不成立（需先取出最短路 DAG 之类的无环骨架再判）。

### 3.3 与"传播/引爆"类题目的分野

本题常被误当成"爆炸传播"型（做完一条解锁后继，像点燃链条）。区分标准：

- **聚合是 $\max$（等待所有前驱）且求全局最长链** → 关键路径型，$O(n+m)$ DP，顺序无关（引理 10）。
- **聚合是 $\mathrm{OR}$（任一前驱即可点燃）且求"能否到达/覆盖"** → 传播闭包型，答案与引爆顺序可能相关，需要 BFS/传递闭包（$O(nm/64)$ bitset）或状压搜索"最少点火次数"。
- **资源受限（同时只能做一件）** → 调度型，顺序相关，$m$ 小则状压 DP，$m$ 大则只能贪心 + 交换论证。

题面"可以同时进行"把本题钉在第一类。以后看到"必须…才能…"再加上"同时"，第一件事是确认聚合是 $\max$ 还是 $\mathrm{OR}$。

### 3.4 踩坑清单（按致死率排序）

1. **第二问只输出一条链的点**（回溯前驱）→ 有并列最优链时漏点；必须用判定式（直觉 3）。
2. **用 $f[v]=T$ 或 $g[v]=T$ 判关键点** → 漏掉所有中间点（直觉 4）。
3. **把 $f$ 初值写成 $\pm\infty$/哨兵** → 全表报废（§2.6 哨兵陷阱）。
4. **假定源点是 $1$、汇点是 $n$** → 多源/多汇数据直接 WA（引理 1）。
5. **按 $1..n$ 循环而不是按"出现过的编号"循环** → $i,j\le100$ 与 $n<100$ 不一致时漏点。
6. **忘了 $g$ 只在无环时才"可拼"** → 数据含环时输出"看似合理"的错答案，应先做拓扑序长度检测。
7. **输出格式**：本地题面未规定分隔符，空格/换行需按 OJ 实际要求调整（本文第二行空格分隔、无行尾多余空格）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型/尺寸 | 含义 | 初值 | 更新规则 | 依据 |
|---|---|---|---|---|---|
| `n` | `int` | 结束点总数（题面第一行） | 读入 | 只读；代码不依赖它循环 | 引理 1 |
| `m` | `int` | 剧情条数（题面第二行） | 读入 | 只读 | — |
| `graph[u]` | `vector<pair<int,int>>[mxn]` | $u$ 的出边表，元素 $(v,w)$ | 空 | `push_back({v,w})` | — |
| `exist[v]` | `bool[mxn]` | 编号 $v$ 是否在某条边中出现过 | `false` | 读边时 `exist[u]=exist[v]=true` | 引理 1（编号可超 $n$） |
| `deg[v]` | `int[mxn]` | 拓扑排序用的**剩余**入度（Kahn 会把它减到 $0$） | 读边 `++deg[v]` | `if(0==--deg[v]) Q.push(v)` | 拓扑排序 |
| `ord` | `vector<int>` | 拓扑序 | 空 | `ord.push_back(u)` | 引理 5 |
| `f[v]` | `int[mxn]` | 以 $v$ 结尾的最长路长 $=$ $v$ 最早发生时刻 | $0$（空路径） | 拓扑序：`f[v]=max(f[v],f[u]+w)` | 引理 5 |
| `g[v]` | `int[mxn]` | 以 $v$ 开头的最长路长 $=$ 从 $v$ 起还需多久 | $0$ | 逆拓扑序：`g[u]=max(g[u],w+g[v])` | 引理 6 |
| `T` | `int` | 关键路径长度 $=$ 最少总时间 | $0$ | `T=max(T,f[v]+g[v])` | 引理 8 |
| `ans` | `vector<int>` | 升序的关键结束点集合 | 空 | `exist[v]&&f[v]+g[v]==T&&(f[v]>0||g[v]>0)` | 引理 9 |
| `mxn` | `constexpr int{105}` | 编号上界 $100$ + 5 松弛 | — | — | 数据范围 |

### 4.2 编号步骤

1. 读 $n,m$；读 $m$ 条三元组（按 `起点 终点 权` = `i j k` 解释），建邻接表、累加 `deg`、置 `exist`。
2. Kahn 拓扑排序：把所有 `exist` 且 `deg==0` 的编号入队；弹队时写入 `ord`，并对其每条出边 `--deg`，减到 $0$ 入队。
3. **环检测（防御性）**：若 `ord.size()` $<$ 出现过的编号数，说明图中有环，与"存在合法调度"矛盾（引理 4）；
   本地题面未承诺此类数据，程序不特殊处理，剩余的点 $f,g$ 保持 $0$ 且被 `f>0||g>0` 条件排除在 `ans` 之外。
4. 正向 DP：按 `ord` 顺序松弛 $f[v]\leftarrow\max(f[v],\,f[u]+w)$。
5. 反向 DP：按 `ord` **逆序**松弛 $g[u]\leftarrow\max(g[u],\,w+g[v])$。
6. 求 $T=\max_v(f[v]+g[v])$（扫 $1..mxn{-}1$；由引理 8 与 $\max_v f[v]$ 等价，取哪个都行）。
7. 按编号升序扫一遍，收集满足 §4.1 中 `ans` 判定的编号；升序性质由"按编号递增扫描"直接保证，无需排序。
8. 输出 `T` 换行，再输出 `ans`（空格分隔、行尾换行）。

### 4.3 正确性小结

**定理**：若输入是合法剧情流程（§1 模型下存在合法调度），§5 程序输出的 $T$ 等于完成全部剧情所需的最少时间，`ans` 恰好等于"在某条决定总时间的最长链上出现过的结束点"集合（升序、无重复）。

**证明**：
(i) 由引理 4，$G$ 是 DAG，故步骤 2 的 `ord` 包含全部 `exist` 顶点：Kahn 取不出某剩余点当且仅当剩余子图中每点入度始终 $\ge1$，于是从任一点出发可沿入边无限回溯，有限集合必重复顶点，重复段构成环，与无环矛盾。
(ii) 步骤 4、5 由引理 5、6 得到真实的 $f,g$。
(iii) 步骤 6 由引理 8 得 $T=L$；再由引理 2 的下界与上界双向，$L$ 就是最少时间。
(iv) 步骤 7 由引理 9 得 `ans` $=\{v:v$ 在某条最长路上$\}$；`exist` 排除从未出现的编号，$f>0\lor g>0$ 排除 $T=0$ 的退化命中（$T\ge1$ 时该条件恒真，因为 $f[v]+g[v]=T\ge1$ 必有一边为正）。升序与无重复由"对 $v$ 递增扫描、每个 $v$ 至多入一次"保证。
(v) 步骤 8 只是格式输出。故程序正确。$\blacksquare$

### 4.4 复杂度

- 时间：建图 $O(m)$；拓扑排序 $O(|V|+m)$；两遍 DP 各 $O(|V|+m)$；求 $T$、收集 `ans`、输出各 $O(mxn)$。合计 $O(mxn+m)=O(105+120)$，实际约 $10^2$ 次基本操作，远低于任何时限。
- 空间：邻接表 $O(mxn+m)$，`deg/f/g/exist` 四个 $O(mxn)$ 数组，总量 $<10\,\text{KB}$。
- 若数据加强到 $n,m\le10^6$：本算法仍线性；只有当第二问改成"最长链条数"时才需要额外计数与取模。

### 4.5 语义开关（若判题采用另一套到达语义）

§2.3 直觉 5 的分歧只影响**一行**代码：

- 到达时刻聚合：正向 `f[v]=max(f[v],f[u]+w)` 换成 `min`，初值改为"源点 $0$、其余 $+\infty$"（风格指南写法：`fill_n(f,mxn,1145141919)` 后把入度 $0$ 的点置 $0$）。
- 反向同理换 `min`；$T$ 不再等于 $\max(f+g)$，而要改回"所有边的完成时刻最大值"，判据相应改为"$v$ 在某条达成该最大完成时刻的最短到达链上"。
- **本文实现并保持 $\max$（关键路径）语义**，理由见 §2.3；本地题面无样例，无法用数据裁决这一分歧，不确定项登记在 §4.6。

**用例 5（$\max$ 与 $\min$ 语义分歧数据）** `n=4,m=3`：`1 2 1`、`3 2 100`、`2 4 5`。

**用例 6（规模上界，闭式手算）** $n=99$，$m=98$，边 $i\to i{+}1$ 权 $1000$（$i=1..98$）。
链是唯一的拓扑序，归纳：$f_i=1000(i-1)$（$f_1=0$；$f_{i+1}=\max(0,f_i+1000)=1000i$）。
反向归纳：$g_i=1000(99-i)$（$g_{99}=0$）。于是 $f_i+g_i=1000(i-1)+1000(99-i)=98000$ 与 $i$ 无关

中间量最大值 $f_{98}+w=97000+1000=98000$，若编号能用到 $100$（题面允许 $i,j\le100$）则为 $99\times1000=99000$，

## 5. 示例代码

```cpp
// https://www.luogu.com.cn/problem/P1476
// 休息中的小呆：AOV 关键路径，拓扑序两遍 DP + f[v]+g[v]==T 判关键结束点

#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};                 // 结束点编号 <=100，+5 松弛

int n,m;                                // n 只用于消费输入：扫描按 exist 进行（引理 1）
int deg[mxn],f[mxn],g[mxn];             // deg: 拓扑排序用的剩余入度; f/g: 双向最长路
bool exist[mxn];                        // 该编号是否在任何剧情中出现过
vector<pair<int,int>>graph[mxn];        // (v,w)

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,u,v,w;i<m;++i)
	{
		cin>>u>>v>>w;                     // 剧情 u -> v，耗时 w（按 `i j k` 读入）
		graph[u].push_back({v,w});
		++deg[v];
		exist[u]=exist[v]=true;
		// cerr<<u<<' '<<v<<' '<<w<<'\n';
	}

	vector<int>ord;
	queue<int>Q;
	for(int v=1;v<mxn;++v)
		if(exist[v]&&!deg[v])
			Q.push(v);
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		ord.push_back(u);
		for(auto[v,w]:graph[u])
			if(0==--deg[v])
				Q.push(v);
	}
	// ord.size() < 出现过的点数 <=> 有环 <=> 前驱约束自相矛盾（引理 4，此类数据题目无解）

	for(int u:ord)                        // 拓扑序：f[v] = v 最早发生时刻（引理 5）
		for(auto[v,w]:graph[u])
			f[v]=max(f[v],f[u]+w);        // 初值必须是 0（空路径），不是 INF：见 §2.6 哨兵陷阱
	for(int i=(int)ord.size()-1;i>=0;--i) // 逆拓扑序：g[u] = 从 u 起还要多久（引理 6）
	{
		int u=ord[i];
		for(auto[v,w]:graph[u])
			g[u]=max(g[u],w+g[v]);
	}

	int T=0;
	for(int v=1;v<mxn;++v)
		T=max(T,f[v]+g[v]);               // 关键路径长度 = 最少总时间（引理 8）

	vector<int>ans;
	for(int v=1;v<mxn;++v)
		if(exist[v]&&f[v]+g[v]==T&&(f[v]>0||g[v]>0))   // 引理 9 的判定式 + 退化兜底
			ans.push_back(v);             // 按编号递增扫描，天然升序且无重复

	cout<<T<<'\n';
	for(int i=0;i<(int)ans.size();++i)
	{
		if(i)
			cout<<' ';
		cout<<ans[i];
	}
	cout<<'\n';
	return 0;
}

// 本地题面无样例，以下为 §4.6 手算验证用的自造数据（输入 -> 期望输出）：
// 2 / 1 / 1 2 5                       ->  5 \n 1 2
// 4 / 4 / 1 2 2 / 1 3 3 / 2 4 5 / 3 4 1  ->  7 \n 1 2 4
// 4 / 4 / 1 2 4 / 2 4 4 / 1 3 4 / 3 4 4  ->  8 \n 1 2 3 4
```
