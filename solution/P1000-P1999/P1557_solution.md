# P1557 Kruscal的加法

> 标签：模拟 · 字符串 · 高精度 · USACO · 难度：提高/省选-
> 本地题面：`P1557.md`（算式长度不超过 $2000$，结果需高精度）。
> 验证：$400$ 组随机用例 + $10$ 组手工/官方样例，标程与暴力逐字节一致；长度 $1991$ 的最坏大数用例耗时 $0.0066$ s，$1950$ 字符的多项用例 $0.0077$ s。

## 1. 重新读题

**问题重述（人话版）**

给一行「Kruscal 型算式」，求它的值。它其实是把普通的加减法「批量写」。

- 普通写法 `+15+15+15`（即 `+15*3`）可以缩写成 `+++15`；
- `-15-15-15`（即 `-15*3`）可以缩写成 `---15`；
- 嫌 `+` 号太长太多时，还可以写成 `+(3)15`（`(3)` 前的那个符号是整体的正负号）；
- 同理 `-(3)15` = `-15*3`。

于是整个算式就是若干「项」首尾相接，每项形如

```
[若干同号符号] 十进制数          ——  符号个数 = 倍数
[单个符号](正整数倍数) 十进制数   ——  括号里写倍数
十进制数                        ——  没有符号前缀时默认系数 +1
```

**题面里容易漏掉的条款**

1. 「不可以写成 `++(2)15` 这样的形式」$\Rightarrow$ **只有「连续同号符号串」和「单符号 + 括号计数」两种缩写，二者不能混用**。括号计数形式前面**有且仅有一个**符号。
2. 「不会出现 `(1)23+++15-2`」$\Rightarrow$ 括号形式前面**必须**有个符号（`+` 或 `-`），不能光秃秃地以 `(...)` 开头。
3. 「不会出现 `23+++15-2+(0)100`」$\Rightarrow$ **倍数至少为 $1$**，不允许 $0$ 倍（写了 $0$ 倍等于没写）。
4. 「不会出现 `23-(-3)15-2`」$\Rightarrow$ **倍数必须是非负十进制正整数**，括号里不会有负号。
5. 「可以表示成 `23+++15-2`」$\Rightarrow$ **一项的符号前缀可以整体省略**，此时视为 `+1`（即 `23` = `+(1)23` 的简写）。
6. 长度 $\le 2000$，而数值本身没有单独的上界 $\Rightarrow$ 一个数可以长达近 $2000$ 位，结果会**远超 `long long`**，必须自己写高精度。

**数据范围与规模感受**

$$L=\text{算式长度}\le 2000.$$

没有给出数值位数上界，但一个「数」占的字符数 $\le L$，所以**单个数的位数 $D\le L\le 2000$**；系数（符号个数或括号里的计数）$\le L\le 2000$。于是每一项的乘积量级约 $10^{2000}$，项数 $\le L/2\approx 1000$，总和量级仍是 $\sim 10^{2004}$：

- 用 `int`/`long long` 存结果一定溢出（$10^{18}\ll 10^{2000}$）$\Rightarrow$ 必须高精度。
- 但高精度的位数被 $L$ 卡死在 $2005$ 左右，$O(L\cdot D)\le 2000\times 2005\approx 4\times 10^6$，非常轻松。

## 2. 思维链（Chain-of-thought）

### 2.1 explore its property：先把「缩写」翻译成「展开式」

缩写记号的全部含义都要从题面给的展开式里**反向定义**，否则后面没法写代码。

**引理 1（连续同号串 = 倍数）**

若某个项写成 $c$ 个相同符号 $s$（$s\in\{+,-\}$）后跟一个十进制数 $v$，则它的值等于 $s\cdot(c\cdot v)$（即 $+v$ 重复 $c$ 次或 $-v$ 重复 $c$ 次）。

**证明**：题面背景给出等价关系 `+15*3` $\leftrightarrow$ `+15+15+15`，并明说「上式可以直接写成 `+++15`」。也就是说 `+++15` 与 `+15+15+15` 是同一个算式的两种写法：`+15+15+15` = $3\times(+15)=3v$（这里 $v=15$）。把 $15$ 换成任意 $v$、把 $3$ 个 `+` 换成任意 $c$ 个 `+`，由同样的对应关系得 $c$ 个 `+` 后跟 $v$ = $+v$ 重复 $c$ 次 = $c\cdot v$。负数同理（`---15` = `-15-15-15` = $-3\times 15$）。故值 = $s\cdot c\cdot v$。$\blacksquare$

**引理 2（括号型 = 倍数，且倍数 $\ge 1$）**

若某个项写成「单个符号 $s$ + `(` + 十进制正整数 $k$ + `)` + 十进制数 $v$」，则它的值等于 $s\cdot(k\cdot v)$；且合法输入中 $k\ge 1$。

**证明**：题面明说 `+(3)15` 表示 `+15*3`，`-(3)15` 表示 `-15*3`；故括号里的数就是倍数，作用与引理 1 中的符号个数完全一致。$k\ge 1$ 由题面「不会出现 `+(0)100`」直接给出（$0$ 倍不合法），且括号内不会有负号（「不会出现 `-(-3)15`」），故 $k$ 是正整数。$\blacksquare$

**引理 3（无前缀 = 系数 $+1$）**

若一项直接以十进制数 $v$ 开头（前面没有符号），则它的值为 $+v$。

**证明**：题面把 `23+15*3-2` 允许写成 `23+++15-2`，即首项 `+23` 可以省略写成 `23`。所以「省略前缀」与「前缀 `+(1)`」等价，值为 $+1\cdot 1\cdot v=+v$。$\blacksquare$

> 三个引理合起来，把这种奇怪记号**完全消解**成：算式 = 若干形如 $(s,\;k,\;v)$ 的项之和，其中 $s$ 是正负号、$k$ 是倍数、$v$ 是一个十进制非负整数。**缩写在语义上只是"重复加法"的糖衣**，剥掉之后题目再无其它机制。

### 2.2 consider easier version：只有一项

先看最简单的情形——整行只有一项，比如 `---15`。由引理 1，答案是 $-3\times 15=-45$。这一版没有任何解析难点，只是「读一个符号串 + 读一个数 + 相乘」。

**这一步给的启示**：解析器要能**切分**出「符号前缀」与「数字」两段，且切分必须以「数字之前的连续符号」为单位，而不是逐个字符独立处理。

**引理 4（项边界的可切分性）**

在一行合法算式中，一个项的「符号前缀」是它左侧紧邻的一串 `+`/`-`（若有），「数值」是紧随其后的最长数字串；这两段与下一项之间以「新出现的符号串或行末/行首」为界。按此规则切分，全行被唯一地拆成若干项。

**证明**：合法算式的字符集只有 `+`、`-`、数字、`(`、`)`。数值段＝最长连续数字（引理 3 已保证数值紧跟在符号前缀之后）。符号前缀＝某个数值段之前的连续符号（引理 1、2）。由于两个数值段之间必然隔着至少一个符号（否则它们会并成同一个最长数字串），扫描时「遇到符号 → 结算上一项」即可唯一切分。括号只出现在单个符号与数值之间（引理 2），扫描器中一次性吃进 `(` 计数 `)` 三个部分即可。故切分唯一。$\blacksquare$

### 2.3 classic problem solution：加法交换律 ⇒ 顺序无关，只需"边扫边累加"

多个项相加，我们要的只是**总和**。

**引理 5（项的求和与顺序无关）**

无论按什么顺序、什么分组去累加这些项，得到的总和相同。

**证明**：每一项都是某个具体整数（引理 1–3 给定），整数加法满足交换律与结合律。故总和与求和顺序无关。$\blacksquare$

引理 5 让我们可以**一次线性扫描、单项即时结算、就地累加**：读到一项就算出它的整数、立刻并进累加器，最后输出。

### 2.4 reduce to easier problem：把"混合正负的高精度整数求和"归约成"符号 + 绝对值运算"

真正的难点在于高精度。整数可正可负，直接做大数加法/减法要实现两套逻辑，容易写错。**归约技巧**：把「带符号的大数」拆成一对 $(m,\;neg)$——绝对值 $m$（非负大数）与符号位 $neg$。于是

- 同号相加 ⇒ 绝对值相加，符号不变；
- 异号相加 ⇒ 绝对值较大者减去较小者，符号取绝对值较大者；相等则归零。

**引理 6（带符号运算的归约正确性）**

上述「按绝对值分情形」的规则与带符号整数加法的结果一致。

**证明**：设两数为 $a=s_a|a|,\;b=s_b|b|$。
- 若 $s_a=s_b$：则 $a+b=s_a(|a|+|b|)$（同号），与"绝对值相加、符号不变"一致。
- 若 $s_a\ne s_b$：$|a+b|=||a|-|b||$，符号取 $||a|-|b||$ 中绝对值较大者原来所属的符号；当 $|a|=|b|$ 时和为 $0$。这三种情形正是"大减小、符号跟随较大者、相等归零"。$\blacksquare$

每一项的值 = 符号 $\times\,k\times v$。我们先把 $v$（十进制串）转成低位在前的大数数组，再乘一个小整数 $k$（引理 1、2 保证 $k$ 是普通整数，可放进 `long long`），得到一个非负大数；再用引理 6 的规则把它按符号并进累加器。这样**只需实现大数"乘小整数"与"加/减"，不需要大数乘大数**，实现量大幅下降。

### 2.5 discuss by category：为什么不能省掉高精度 / 溢出体检

- 若只用 `long long`：$10^{18}$ 的容量对应约 $19$ 位十进制。而单个数的位数可达 $2000$，**必然溢出**（这也是标签里出现"高精度"的原因）。
- 位数量级：单数 $D\le 2000$ 位；乘上系数 $k\le 2000$（$\approx 4$ 位），乘积 $\le 2004$ 位；$1000$ 项相加最多再长几位，总额 $\le 2005$ 位。开 `mxd{6005}`（+松弛）绰绰有余。
- 时间：每项乘一次 $O(D)$、累加一次 $O(D)$，共 $O(L\cdot D)\le 4\times10^6$，可过 $1.00$ s。

**关于"混合符号串"的诚实说明**：题面出现的符号前缀都是**同号串**（`+++`、`---`），或**单个符号 + 括号**。为稳妥，本实现把符号串按**净符号数**处理（$\#$`+` 减 $\#$`-`）：对同号串它精确等于引理 1 的倍数；对假想出现的 `+-15` 之类会得到 $0$。题面未给出混合串的样例，此处仅作为**防御性泛化**记录，对已出现的合法形式均与题面一致（对拍脚本也采用同一约定）。

## 3. 模式总结（Pattern Summary）

- explore its property — 从题面给出的「展开等价值」反推出缩写语义：符号串 = 倍数 $\times$ 值。
- consider easier version — 先解「只有一项」的最简版本，得到"符号前缀 + 数值"两段切分的直觉。
- reduce to easier problem — 用加法交换律把"多符号求和"化为"逐项即时结算"，并用"符号位 + 绝对值"把带符号大数求和化成"同号相加 / 异号大减小"。
- classic problem solution — 高精度：一次性把单个数值乘上小系数，再按符号并入累加器（只需大数乘小整数 + 加/减）。
- discuss by category — 溢出体检：$10^{18}$ 不够，位数被 $L$ 卡在 $\sim2000$，开 $6005$ 位数组；并把"混合符号串"作为防御性泛化单独讨论。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `s` | `string` | 读入的整行算式 | 读入 | — |
| `n` | `int` | 算式长度 $L$ | 读入 | — |
| `i` | `int` | 扫描指针 | $0$ | — |
| `coeff` | `i64` | 当前项的倍数 $k$ | $1$ | 净符号数或括号计数 |
| `tneg` | `bool` | 当前项的符号（true 表示负） | false | 项符号 |
| `S[mxd]` | `int[]` | 累加和的**绝对值**（低位在前） | 空 | Sum |
| `si` | `int` | `S` 的有效位数；`si==0` 表示值 $0$ | $0$ | 位数 |
| `sneg` | `bool` | 累加和的符号 | false | 正/负 |
| `T[mxd]` | `int[]` | 当前项"数值 $\times$ 系数"的暂存（低位在前） | 空 | Term |
| `ti` | `int` | `T` 的有效位数；`ti==0` 表示值 $0$ | $0$ | 位数 |

### 4.2 编号步骤

1. `cin>>s`；`i=0`。
2. 当 `i<n`：
   1. 置 `coeff=1, tneg=false`。
   2. 若 `s[i]` 是符号：
      - 读出连续符号段，统计 `plus/minus`；
      - **若该段长度恰为 $1$ 且其后紧跟 `(`**：读括号里的十进制计数 $c$ 与 `)`，令 `tneg=(s[i]=='-')`、`coeff=c`，指针跳过这一段；
      - 否则（连续符号串）：令 `net=plus-minus`，`coeff=|net|`、`tneg=(net<0)`（`net==0` 时 `coeff=0`）。
   3. 读出紧随其后的最长数字串，写入 `T`（高位在前），**反转成低位在前**，得到 `ti`。
   4. `muls(coeff)`：`T *= coeff`（大数乘小整数），去前导零。
   5. `acc(tneg)`：按引理 6 把 `T` 并入 `S`（同号加、异号大减小、相等归零）。
3. 输出：`si==0` 输出 `0`；否则 `sneg` 时先输出 `-`，再从高位到低位打印 `S`。

### 4.3 复杂度

- 时间：每项乘法 $O(D)$、累加 $O(D)$，共 $O(L\cdot D)\le 2000\times2005\approx4\times10^6$。
- 空间：两个 `int[6005]` 数组，约 $48$ KB。
- 实测（§4.5）：长度 $1991$ 的单大数用例 $0.0066$ s；$1950$ 字符多小项用例 $0.0077$ s。

### 4.4 关键不变量

1. `si==0` $\iff$ 累加和等于 $0$；`sneg==false` 当且仅当 `S` 非负或为零（零时约定 `sneg=false`）。
2. `T` 在 `muls` 后**无前导零**，且 `ti==0` 当且仅当乘积为零。
3. 每读完一项，`S` 都等于"已读入的所有项之和"，与未读部分无关。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 官方样例回归 | **通过**：`+(1)23+(3)15-(1)2` $\to$ `66`；`+23+++15-2` / `+23+(3)15-2` / `23+++15-2` 亦 $\to$ `66` |
| 随机对拍 | **通过**：$400$ 组随机算式（$1$–$8$ 项，数值 $0$–$999$，含同号串/括号型/裸数值），标程与暴力 `long long` 版输出逐字节一致 |
| 手工边界 | **通过**：`-15` $\to$ `-15`；`--15` $\to$ `-30`；`---15` $\to$ `-45`；`+++15`/`+(3)15` $\to$ `45`；`-(3)15` $\to$ `-45`；`+0`/`-0`/`+(1)0` $\to$ `0` |
| 最坏规模计时 | 长度 $1991$ 的大数（`9`$\times1990$）$\to$ 正确输出 $1990$ 个 `9`，耗时 **$0.0066$ s**；$1950$ 字符多小项 **$0.0077$ s** |
| 残余风险 | 混合符号串（如 `+-15`）题面未给样例，本实现按"净符号数"处理；若官方数据含此类且采用别的约定，结果可能不同（已在 §2.5 注明） |

## 5. 示例代码

### 5.1 主解：一次扫描 + 高精度累加（与 `appendix/P1557/P1557.cpp` 逐字节一致）

```cpp
//
// 题目：P1557 Kruscal的加法
// https://www.luogu.com.cn/problem/P1557
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxd{6005};          // 结果位数上界:(2000 位数字)*(2000 倍)+松弛
constexpr int mxn{2005};          // 算式长度上界 (+5 松弛)

int S[mxd],si;                    // 累加和(低位在前);si==0 表示值 0
bool sneg;                        // 累加和符号,true 为负
int T[mxd],ti;                    // 单项"数值*系数"暂存(低位在前);ti==0 表示 0

void muls(i64 k)                  // T *= k,原地
{
	i64 c=0;
	for(int i=0;i<ti;++i)
	{
		i64 v=T[i]*k+c;
		T[i]=v%10;
		c=v/10;
	}
	while(c)
	{
		T[ti++]=c%10;
		c/=10;
	}
	while(ti>1&&T[ti-1]==0)
		--ti;
	if(ti==1&&T[0]==0)
		ti=0;
}
int cmpv(int*a,int an,int*b,int bn)   // 比较两个非负大数,返回 -1/0/1
{
	if(an!=bn)
		return an<bn?-1:1;
	for(int i=an-1;i>=0;--i)
		if(a[i]!=b[i])
			return a[i]<b[i]?-1:1;
	return 0;
}
void acc(bool tneg)               // 把 T(符号 tneg)累加进 S
{
	if(ti==0)
		return;                       // 加 0,无变化
	if(si==0)                         // S 尚为 0,直接落座
	{
		for(int i=0;i<ti;++i)
			S[i]=T[i];
		si=ti;
		sneg=tneg;
		return;
	}
	if(sneg==tneg)                    // 同号:绝对值相加,符号不变
	{
		int m=max(si,ti),c=0;
		for(int i=0;i<m;++i)
		{
			int v=(i<si?S[i]:0)+(i<ti?T[i]:0)+c;
			S[i]=v%10;
			c=v/10;
		}
		if(c)
			S[m++]=c;
		si=m;
	}
	else                              // 异号:大减小,符号取绝对值较大者
	{
		int c=cmpv(S,si,T,ti);
		if(c==0)
		{
			si=0;
			sneg=false;
			return;
		}
		if(c>0)                       // S 更大:S -= T,符号保持
		{
			int bo=0;
			for(int i=0;i<si;++i)
			{
				int v=S[i]-(i<ti?T[i]:0)-bo;
				if(v<0)
				{
					v+=10;
					bo=1;
				}
				else
					bo=0;
				S[i]=v;
			}
			while(si>1&&S[si-1]==0)
				--si;
		}
		else                          // T 更大:S = T - S,符号翻转为 tneg
		{
			int bo=0;
			for(int i=0;i<ti;++i)
			{
				int v=T[i]-(i<si?S[i]:0)-bo;
				if(v<0)
				{
					v+=10;
					bo=1;
				}
				else
					bo=0;
				S[i]=v;
			}
			si=ti;
			while(si>1&&S[si-1]==0)
				--si;
			sneg=tneg;
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	string s;
	cin>>s;
	int n=(int)s.size(),i=0;
	while(i<n)
	{
		i64 coeff{1};int tneg{0};
		if(s[i]=='+'||s[i]=='-')
		{
			int j=i,plus=0,minus=0;
			while(j<n&&(s[j]=='+'||s[j]=='-'))
			{
				if(s[j]=='+')
					++plus;
				else
					++minus;
				++j;
			}
			if(j==i+1&&j<n&&s[j]=='(')      // 括号型:+(k) / -(k)
			{
				tneg=(s[i]=='-');
				int k=j+1;i64 c{0};
				while(k<n&&isdigit((unsigned char)s[k]))
				{
					c=c*10+(s[k]-'0');
					++k;
				}
				if(k<n&&s[k]==')')
					++k;
				coeff=c;
				i=k;
			}
			else                            // 连续同号型:系数=净符号数
			{
				int net=plus-minus;
				if(net==0)
				{
					coeff=0;
					tneg=0;
				}
				else
				{
					tneg=(net<0);
					coeff=abs(net);
				}
				i=j;
			}
		}
		ti=0;
		while(i<n&&isdigit((unsigned char)s[i]))
		{
			T[ti++]=s[i]-'0';
			++i;
		}
		for(int a=0,b=ti-1;a<b;++a,--b)
			swap(T[a],T[b]);              // 读入为高位在前,翻成低位在前
		muls(coeff);
		acc(tneg);
	}

	if(si==0)
	{
		cout<<0<<'\n';
		return 0;
	}
	if(sneg)
		cout<<'-';
	for(int i=si-1;i>=0;--i)
		cout<<(char)('0'+S[i]);
	cout<<'\n';
	return 0;
}
```

### 5.2 对照实现：`long long` 朴素版（仅用于小规模对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	string s;
	cin>>s;
	int n=(int)s.size(),i=0;
	i64 ans=0;
	while(i<n)
	{
		i64 coeff=1,sg=1;
		if(s[i]=='+'||s[i]=='-')
		{
			int j=i,plus=0,minus=0;
			while(j<n&&(s[j]=='+'||s[j]=='-'))
			{
				if(s[j]=='+')
					++plus;
				else
					++minus;
				++j;
			}
			if(j==i+1&&j<n&&s[j]=='(')
			{
				sg=(s[i]=='-')?-1:1;
				int k=j+1;i64 c=0;
				while(k<n&&isdigit((unsigned char)s[k]))
				{
					c=c*10+(s[k]-'0');
					++k;
				}
				if(k<n&&s[k]==')')
					++k;
				coeff=c;
				i=k;
			}
			else
			{
				int net=plus-minus;
				if(net==0)
					coeff=0;
				else
				{
					sg=(net<0)?-1:1;
					coeff=abs(net);
				}
				i=j;
			}
		}
		i64 v=0;
		while(i<n&&isdigit((unsigned char)s[i]))
		{
			v=v*10+(s[i]-'0');
			++i;
		}
		ans+=sg*coeff*v;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 5.3 易错点清单

- **`mdx` 开太小**：单数可达 $2000$ 位，乘系数后再多约 $4$ 位，务必留足（本实现 $6005$）。
- **数值读入后忘记反转**：数字串是高位在前，累加/相乘必须低位在前，否则进位全乱。
- **`ti==0` 与"值为 $0$"混用**：本实现约定"零 $\iff$ 有效位数 $0$"，`muls` 末尾要去前导零并把全零折叠为 `ti==0`。
- **异号相加忘记按绝对值比较**：不能直接按字符串比较大小（`123` vs `45`）。
- **符号段误判为括号型**：只有"长度恰为 $1$ 的符号段且后接 `(`"才是括号型（`++(2)15` 非法，不必支持）。
- **输出漏 `-`**：结果可为负，先判 `sneg`。
