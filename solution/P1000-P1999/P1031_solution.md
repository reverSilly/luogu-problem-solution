# P1031 均分纸牌 · 题解

---

## 一、发现之旅：从具体例子看本质

题目给了我们一个直白的场景——有 N 堆牌，总数能被 N 整除，每次只能把一堆的牌移到**相邻**的堆上，问最少移动次数。

来看例子：`9, 8, 17, 6`，平均值是 10。

手玩一下：
1. 第三堆有 17 张，比平均数多 7。拿 4 张给第四堆 → `9, 8, 13, 10`
2. 第三堆还剩 13 张，多 3 张，给第二堆 → `9, 11, 10, 10`
3. 第二堆有 11 张，多 1 张，给第一堆 → `10, 10, 10, 10`

3 次完成。为什么不是从第一堆开始移？为什么不能跳着移？

观察移动路径：**每一张牌都沿着数轴从左向右（或从右向左）移动**。移动规则是"只能给相邻堆"，这意味着每张牌的移动路径是一条连续的线段。如果一个堆的牌最终要流到另一个堆去，它必须经过中间的所有堆。

这个观察直接引向了核心思想：**牌的流动是单调的**。我们不需要关心"哪张牌去了哪里"，只需关心每个位置上净流出了多少张牌。

再换一个视角：把每个堆与平均值的差看作"负债"或"盈余"。
- 第一堆欠 1 张（-1）
- 第二堆欠 2 张（-2）
- 第三堆多 7 张（+7）
- 第四堆欠 4 张（-4）

把手拉手的负债和盈余从左到右"传递"下去：
- 位置 0 欠 1 张，需要从右边借 → 向右传递 1 张的债务
- 位置 1 本来欠 2 张，又接了左边 1 张的债务，共欠 3 张 → 继续向右传递
- 位置 2 本来多 7 张，接了 3 张债务后还多 4 张 → 向右传递 4 张
- 位置 3 本来欠 4 张，收到 4 张后刚好平衡

每次"传递"就是一次移动。所以答案是 **3**，恰好等于传递的次数。

是不是每次传递都一定对应一次移动？是的，因为传递的本质就是把牌从一个堆搬到相邻堆——这对每个非平衡的位置正好需要一次操作。

## 二、完整推理：从朴素想法到贪心正确性

### 2.1 问题形式化

记第 $i$ 堆初始牌数为 $a_i\ (1\le i\le N)$，总牌数 $S=\sum a_i$，平均值 $\bar a=S/N$。

目标：经过若干次相邻移动，使所有 $a_i'=\bar a$，最小化移动次数。

### 2.2 为什么相邻移动限制了方向

核心限制：牌不能"跳堆"。从堆 $i$ 拿走的牌只能去 $i-1$ 或 $i+1$。

这意味着，如果把数轴上的牌流看作一个**流量网络**：相邻堆之间有一条无向边，牌沿边走。最终每堆的净流量必须恰好抵消其与平均值的偏差。

设 $x_i$ 为从堆 $i$ 流向堆 $i+1$ 的牌数（$1\le i<N$），正数表示从左到右，负数表示从右到左。那么对堆 $i$，其净流入为 $x_{i-1}-x_i$（定义 $x_0=x_N=0$），于是：

$$a_i + (x_{i-1} - x_i) = \bar a \implies x_i - x_{i-1} = a_i - \bar a$$

这是标准的差分方程。递推得：

$$x_i = \sum_{j=1}^{i} (a_j - \bar a)$$

$i$ 从 $1$ 到 $N-1$ 有定义，且 $x_N = \sum_{j=1}^{N} (a_j - \bar a) = 0$ 自动满足。

**每次移动对应一张牌走过一条边**。如果 $x_i>0$，必须有 $|x_i|$ 张牌从 $i$ 走向 $i+1$；每次移动只能搬若干张牌走一条边，所以至少需要 $|x_i|$ 次移动来覆蓋这个流量。

但这里有一个关键：**我们允许一次移动搬任意多张牌**。比如从第三堆拿 4 张给第四堆，这算 1 次移动，不是 4 次。

所以，移动次数不取决于 $|x_i|$ 的大小，而取决于 $x_i$ **是否为零**。对于每个 $i$：
- 如果 $x_i=0$，堆 $i$ 和堆 $i+1$ 之间不需要发生任何移动。
- 如果 $x_i\neq 0$，至少需要 1 次移动来传递这些牌（因为可以一次搬完）。

于是最少移动次数的下界就是 $\#\{i\mid 1\le i<N,\ x_i\neq 0\}$。

### 2.3 贪心构造达到下界

怎么达到这个下界？从左到右扫描：

1. 如果当前堆 $i$ 恰好是平均值，跳过。
2. 如果当前堆 $i$ 不是平均值，把差额 $a_i-\bar a$ 全部移给下一堆（允许负值，即从下一堆借牌），移动次数加 1。

正确性证明：
- 归纳基础：处理完前 $i$ 堆后，前 $i$ 堆都达到了平均值。
- 归纳步骤：假设前 $i-1$ 堆已平衡，第 $i$ 堆有差额 $d = a_i - \bar a$。如果 $d=0$，无需操作。如果 $d\neq 0$，必须通过 $i\to i+1$ 或 $i+1\to i$ 的边来调节，1 次移动即可完成，且因为 $x_i$ 正是这个差额的累积，$x_i\neq 0$ 当且仅当此时需要移动。
- 最终，由于总数是 $N$ 的倍数，第 $N$ 堆自动平衡。

因此贪心构造恰好需要 $\#\{i\mid 1\le i<N,\ \sum_{j=1}^{i}(a_j-\bar a)\neq 0\}$ 次移动，达到下界，故为最优解。

### 2.4 另一种等价视角：前缀和判零

定义 $b_i = a_i - \bar a$，$p_i = \sum_{j=1}^{i} b_j$。答案就是 $p_1,p_2,\ldots,p_{N-1}$ 中非零项的个数。

这是因为 $p_i>0$ 意味着前 $i$ 堆整体有盈余，需要向右输送；$p_i<0$ 意味着前 $i$ 堆整体有亏空，需要从右边借入。无论正负，都需要一次移动来「传递」这个不平衡。

## 三、模式提炼

> **均分纸牌问题 = 一维相邻传递的零和均衡**

解决这类问题的通用框架：

1. **计算目标值**：$\text{target} = \text{sum} / N$。
2. **定义差额数组**：每个位置与目标的差值。
3. **从左到右扫描**，维护累计差额：
   - 累计差额为零 → 当前位置之前已经平衡，无需跨过此边移动。
   - 累计差额非零 → 必须在当前位置和下一位置之间发生一次移动。
4. **答案** = 累计差额非零的次数（前 $N-1$ 个位置）。

这个模式适用于所有**一维相邻传递**的均衡问题，不管牌的数值多大，不管 N 多大（$N\le 100$ 这个约束甚至完全用不上——$O(N)$ 即可解决）。如果有环（环形均分纸牌），则需要先断环，但差分方程的本质不变。

## 四、正式解法与符号说明

### 符号表

| 符号 | 含义 |
|------|------|
| $N$ | 纸牌堆数 |
| $a_i$ | 第 $i$ 堆初始牌数（$0\le i<N$） |
| $\displaystyle \text{avg}$ | $\frac{1}{N}\sum a_i$，每堆的目标牌数 |
| $b_i$ | $= a_i - \text{avg}$，差额（可为负） |
| $p_i$ | $\displaystyle \sum_{j=0}^{i} b_j$，前缀累计差额 |
| $\text{ans}$ | 最少移动次数 |

### 算法描述

```
1. 读入 N 和 a[0..N-1]
2. 计算 avg = sum(a) / N
3. ans = 0, carry = 0
4. for i = 0 to N-2:
       carry += a[i] - avg
       if carry != 0:
           ans += 1
5. 输出 ans
```

### 复杂度

- 时间复杂度：$O(N)$
- 空间复杂度：$O(1)$（仅需常数额外空间）
- 完全线性，无需排序、无需建图、无需任何高级数据结构。

### 正确性要点

- 因为总牌数是 $N$ 的倍数，故 $\text{avg}$ 为整数
- 在 $i=N-1$ 时，$\text{carry}=\sum (a_i-\text{avg})=0$ 自动成立，无需检查
- 每次移动搬的牌数任意，所以 1 次移动可以清零所有差额，这是「非零即计一次」的合理性基础

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};
int a[mxn];

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	int sum=0;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		sum+=a[i];
	}
	int avg=sum/n;
	int ans=0,carry=0;
	for(int i=0;i<n-1;++i)
	{
		carry+=a[i]-avg;
		if(carry!=0)
			++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```

代码说明：
- 全局数组 `a` 按 "mxn + 5" 惯例开，本题 $N\le 100$ 所以 105 绰绰有余
- 读入时同时累加 `sum`，一次循环完成
- `carry` 就是累计差额 $p_i$，非零时计入答案
- 最后输出 `ans`，换行用 `'\n'` 而不是 `endl`
