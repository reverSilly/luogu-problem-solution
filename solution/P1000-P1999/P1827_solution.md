# P1827 [USACO3.4] 美国血统 American Heritage

> 难度：普及- · 标签：树, 递归, 构造, USACO

## 1. 重新读题

### 1.1 问题重述（人话版）

一棵二叉树，每个结点是一个互不相同的字母，结点不超过 $26$ 个。给你这棵树的**中序**和**前序**，输出**后序**。空树不会出现；单结点是合法的。

中序是「左、根、右」，前序是「根、左、右」，后序是「左、右、根」。

### 1.2 关键约束与规模暗示

- 长度 $\le 26$，递归深度和任何 $O(n^2)$ 的找根都没问题。
- 字母唯一，所以根在中序里的位置可以由下标数组 $O(1)$ 查到，不必每次线性扫描。
- 样例中序 `ABEDFCHG`、前序 `CBADEFGH`，后序 `AEFDBHGC`。题面那棵树：根 `C`，左子树是 `B`（左 `A`，右 `D`，`D` 的左右是 `E,F`），右子树是 `G`（左 `H`）。

## 2. 思维链（Chain-of-thought）

两种遍历之所以能还原树，是因为它们把同一棵树切成同一对子树。

**引理 1（前序首字符是根，中序被根切开）**

设前序字符串为 $P$，中序为 $I$，长度都是 $n\ge 1$。$P_0$ 是整棵树的根 $r$。设 $r$ 在 $I$ 中的下标是 $k$，则

- $I[0..k)$ 与 $P[1..k]$ 分别是左子树的中序和前序；
- $I[k+1..n)$ 与 $P[k+1..n)$ 分别是右子树的中序和前序。

左子树结点数是 $k$（若中序从 $0$ 计，且当前区间左端是 $0$；一般地，左子树大小是 $k-il$）。

**证明**：前序的定义是先访问根，再完整访问左子树，再完整访问右子树，所以 $P_0=r$，紧接着的一段长度等于左子树大小，再之后是右子树。中序是完整左子树、然后根、然后完整右子树，所以根左侧那段的长度就是左子树大小，右侧是右子树。两段里面的结点集合相同，而且子树自己的前序/中序仍然保持「根在前序首位、根在中序中间」的形式，因此可以递归。字母互异保证 $k$ 唯一，切分不会有第二种根。$\blacksquare$

**引理 2（先递归左右、再输出根，得到的就是后序）**

在引理 1 的递归里，处理完左区间、再处理完右区间、最后输出当前根。输出串是后序。

**证明**：对结点数归纳。空区间输出空串。非空时，由归纳，左区间的输出是左子树的后序，右区间的输出是右子树的后序，最后写上根。这正是后序的定义。每个结点作为且仅作为自己那一层的根被输出一次，所以不重不漏。$\blacksquare$

因此不必先把指针树建出来再遍历。暴力对拍故意走另一条路：用同样的切分把左右儿子下标写进数组，最后再单独做一次后序遍历。两条路径的输出必须相同，并且还要等于直接在随机树上做的后序。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 前序第一个字符是根，它把中序切成左右两段，两段长度同时切分前序（引理 1）。
- **classic problem solution** — 先左后右再输出根，归纳即后序（引理 2）。
- **consider easier version** — 单结点时中序=前序=后序；左链、右链是区间退化成空的边界，随机对拍里每种长度都覆盖了。
- **boundary discipline** — 用 `pos[字符]=中序下标`，$O(1)$ 找根；下标是 $0$ 的字符不能靠全局 $0$ 碰运气，要显式写入。

## 4. 真实解法

### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `ino,pre` | `string` | 中序、前序 | 读入 | in-order / pre-order |
| `pos` | `int [128]` | 字符在中序中的下标 | 按 `ino` 填 | 找根 |
| `il,ir` | `int` | 当前子树的中序闭区间 | 初始 `[0,n-1]` | in 的左右 |
| `pl` | `int` | 当前子树前序的左端 | 初始 $0$ | pre 的左 |
| `llen` | `int` | 左子树结点数 | `pos[根]-il` | left length |

### 4.2 算法步骤

1. 读入两行串，把每个中序字符的位置写入 `pos`。
2. `dfs(il,ir,pl)`：若 `il>ir` 返回。根是 `pre[pl]`，在中序的位置是 `k=pos[根]`，左子树长度 `k-il`。
3. 递归左：中序 `[il,k-1]`，前序从 `pl+1` 开始。递归右：中序 `[k+1,ir]`，前序从 `pl+1+llen` 开始。
4. 递归返回后输出根。最后补一个换行。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 每个结点输出一次，找根 $O(1)$，时间 $O(n)$，空间 $O(n)$（递归栈）。
- 编译：`g++ -O2 -std=c++17 -Wall -Wextra -Werror`，无警告。
- 样例输出 `AEFDBHGC`，标程与「显式建树再后序」一致。
- 对每个长度 $1..26$ 生成一棵随机树、一条左链、一条右链，再加 $200$ 棵随机字母的随机形状树。中序/前序由树直接导出，后序同时对比标程、建树暴力和 Python 递归。共 $279$ 组一致，耗时 $1.38$ s。
- 合计 `279 tests OK`。本题 $n\le 26$，没有单独的「最大规模计时」档，最长的用例已含在上述 $26$ 个字母的链和随机树里。

## 5. 示例代码

### 5.1 标程（`P1827.cpp`）

```cpp
//
// 题目：P1827 [USACO3.4] 美国血统 American Heritage
// https://www.luogu.com.cn/problem/P1827
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

string ino,pre;
int pos[128];

void dfs(int il,int ir,int pl)
{
	if(il>ir)
		return;
	int k=pos[(unsigned char)pre[pl]];
	int llen=k-il;
	dfs(il,k-1,pl+1);
	dfs(k+1,ir,pl+1+llen);
	cout<<pre[pl];
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>ino>>pre;
	int n=(int)ino.size();
	for(int i=0;i<n;++i)
		pos[(unsigned char)ino[i]]=i;
	dfs(0,n-1,0);
	cout<<'\n';
	return 0;
}
```
