# P1961 [JOI 2007 Final] 最轻的天平

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $N$ 个天平，编号 $1\sim N$。第 $i$ 个天平横杆支点到左端、右端的长度分别为 $P_i,Q_i$。左端挂的东西用 $R_i$ 描述：$R_i=0$ 表示挂一个**物品**，$R_i>0$ 表示挂第 $R_i$ 个**天平**；右端同理，用 $B_i$ 描述。

天平平衡的条件是
$$
\text{左端总重量}\times P_i=\text{右端总重量}\times Q_i .
$$
挂在某一侧的天平，它的“总重量”就是那个天平子树里所有物品重量之和。每个 $0$ 代表一个可以自由决定重量（正整数）的物品。输入保证这些天平连成一个整体（可以看成以某个最上方天平为根的树）。求能让所有天平同时平衡时，**所有物品重量之和的最小值**。

### 1.2 关键约束与规模暗示

- $N\le 100$，非常小，$O(N^2)$ 甚至指数级搜索都可能有希望，但正解是 $O(N\log V)$ 的递归。
- 只给了样例说明的图，没有具体样例数值；因此必须从“平衡”这一物理关系本身推公式。
- 题目保证“最优构造方案下每个天平两边的重力乘力臂之和不超过 `int` 范围”，说明答案与中间量可以用 64 位整数安全计算（代码里仍用 `long long`，并把 `lcm` 用 `__int128` 防溢出）。
- 结构是“整体”（连通），每个天平的两个端点要么是物品、要么是另一个天平，所以整体一定是一棵有根树：恰好有一个天平不是任何天平的孩子，它就是根。

## 2. 思维链（Chain-of-thought）

### 2.1 先明确“挂在一边的天平贡献多少重量”

一个天平连同它下面的所有东西，作为一个整体挂在父天平的某一端。它对该端的“重量”就是**它子树内所有物品重量之和**（支点、横杆自重忽略，题目只讨论物品）。

因此，可以对每个天平 $v$ 定义一个量：

> $A(v)$：在 $v$ 子树内部所有天平都平衡的前提下，$v$ 子树内物品总重量的最小值。

但父天平可能要求 $v$ 这一侧的总重量是某个特定整数，不一定是 $A(v)$；所以只知道最小值还不够，还要知道“哪些总重量是可达的”。

### 2.2 关键观察：可达的总重量恰好是最小值的整数倍

**引理 1（伸缩不变性）**：把某个天平子树内所有物品重量同时乘以正整数 $t$，该子树内所有平衡等式仍然成立，且子树总重量乘以 $t$。

**证明**：子树内每个平衡等式都是“左端总重 $\times P=$ 右端总重 $\times Q$”。所有物品重量乘以 $t$ 后，每个天平两侧的总重量都乘以 $t$，等式两边同时乘以 $t$，仍然相等。子树总重量是各物品重量之和，自然也乘以 $t$。$\square$

**引理 2（整除判定）**：设 $A,q$ 为正整数，$g=\gcd(A,q)$，则
$$
A\mid qc\iff \frac{A}{g}\mid c .
$$

**证明**：令 $A=ga,\ q=gb$，其中 $\gcd(a,b)=1$。则
$$
A\mid qc\iff ga\mid gbc\iff a\mid bc .
$$
由于 $\gcd(a,b)=1$，由欧几里得引理（若 $a\mid bc$ 且 $\gcd(a,b)=1$，则 $a\mid c$）得 $a\mid c$。反方向显然。$\square$

下面我们用结构归纳法同时证明：对每个天平 $v$，其子树可达的总重量集合恰为
$$
\{\,k\cdot A(v)\mid k=1,2,3,\dots\,\}.
$$

**基础（一侧是物品）**：一个物品的重量可以取任意正整数，最小为 $1$，可达集合就是 $\{1,2,3,\dots\}$，即 $A=1$ 的整数倍。

**归纳步**：考虑天平 $v$。左、右两端各自的“结构”已经满足归纳假设：

- 若某端是物品，记该端的基准为 $1$（重量可取任意正整数倍）；
- 若某端是天平 $u$，记该端基准为 $A(u)$（该端总重量必须是 $A(u)$ 的正整数倍）。

设左端基准为 $A_L$，右端基准为 $A_R$。记左端总重量为 $a$、右端为 $b$。需要
$$
aP=bQ,\qquad A_L\mid a,\qquad A_R\mid b .
$$
令 $g=\gcd(P,Q)$，$P=gp$，$Q=gq$，则 $\gcd(p,q)=1$，条件 $aP=bQ$ 化为
$$
ap=bq .
$$
由 $\gcd(p,q)=1$ 得 $q\mid a$ 且 $p\mid b$。于是存在正整数 $c$ 使
$$
a=qc,\qquad b=pc,
$$
并且同一个 $c$ 同时控制两边（把 $a=qc,b=pc$ 代回 $ap=bq$ 得 $qcp=pcq$，恒成立；反过来 $q\mid a,p\mid b$ 也保证能写成同一个 $c$）。

还需满足整除约束：
$$
A_L\mid qc,\qquad A_R\mid pc .
$$
由引理 2，
$$
\frac{A_L}{\gcd(A_L,q)}\mid c,\qquad \frac{A_R}{\gcd(A_R,p)}\mid c .
$$
所以可行的 $c$ 恰好是
$$
c_{\min}=\operatorname{lcm}\!\left(\frac{A_L}{\gcd(A_L,q)},\ \frac{A_R}{\gcd(A_R,p)}\right)
$$
的正整数倍。此时
$$
A(v)=a+b=c_{\min}(p+q).
$$
由引理 1，把所有物品同时放大 $k$ 倍，总重量就变成 $k\cdot A(v)$，因此可达总重量确实是 $A(v)$ 的全部正整数倍；另一方面上式说明任何可行方案的总重量都是 $A(v)$ 的整数倍。归纳完成。$\square$

### 2.3 边界与“物品基准为 1”是否合理

- 物品重量没有上界，最小值是 $1$，可达集合是全体正整数，正是“$1$ 的整数倍”。所以把物品端的基准记成 $A=1$ 完全统一。
- 物品必须真实存在且重量为正，因此 $c_{\min}\ge 1$，$A(v)\ge 2$（每个天平至少挂两个东西）。
- 若 $P,Q$ 有公因子，$p=P/g,\ q=Q/g$ 先把比例约到最简，避免把最小解算大。
- 由引理 2 的推导，$q\mid a$、$p\mid b$ 是必要且充分的（在 $\gcd(p,q)=1$ 下），所以取最小 $c$ 后得到的 $a,b$ 一定都是正整数，构造合法。

### 2.4 自底向上计算

输入是一棵树，从根开始 DFS 即可：先递归求左右两端的基准（物品返回 $1$，天平返回 $A(u)$），再用上面的公式合并。

**根怎么找？** 记录每个天平是否作为别人的孩子出现过，唯一没有出现过的那一个就是根。题目保证“构成一个整体”，所以根存在且唯一；DFS 深度不超过 $N\le 100$。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 挂在一边的天平，其贡献等于子树内物品总重量；平衡式是齐次的。
- **explore its property** — 所有可达总重量是最小值的整数倍（伸缩不变性）。
- **reduce to easier problem** — 把“比例约束 + 整除约束”化成 $a=qc,b=pc$ 的单参数问题。
- **number theory lemma** — $A\mid qc\iff A/\gcd(A,q)\mid c$。
- **classic problem solution** — 树上自底向上递归，用 $\gcd,\operatorname{lcm}$ 合并。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 天平数 | 读入 | $\le 100$ |
| `P[i], Q[i]` | `int [105]` | 左、右力臂 | 读入 | arm |
| `L[i], R[i]` | `int [105]` | 左、右挂的东西（0=物品，否则为天平编号） | 读入 | left/right |
| `ischild[i]` | `bool [105]` | 天平 $i$ 是否作为孩子出现 | false | 找根 |
| `A(v)` | `i64` | $v$ 子树的最小总重量 | 递归 | answer of subtree |

### 4.2 算法步骤

1. 读入 $N$ 个天平，标记 `ischild[L[i]]`、`ischild[R[i]]`（非 $0$ 时）。
2. 找到唯一满足 `!ischild[root]` 的 `root`。
3. 写递归 `dfs(x)`：
   1. 若 `x==0`（物品端），返回 $1$；
   2. 递归得到 `al=dfs(L[x])`、`ar=dfs(R[x])`；
   3. 令 `g=gcd(P[x],Q[x])`，`p=P[x]/g`，`q=Q[x]/g`；
   4. `cl=al/gcd(al,q)`，`cr=ar/gcd(ar,p)`，`c=lcm(cl,cr)`；
   5. 返回 `c*(p+q)`。
4. 输出 `dfs(root)`。

### 4.3 复杂度分析

- 时间：每个天平访问一次，每层做常数次 `gcd`，$O(N\log V)$，其中 $V$ 为数值大小；$N\le100$ 时瞬时完成。
- 空间：$O(N)$（递归栈与数组）。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};

int n;
int P[mxn],Q[mxn],L[mxn],R[mxn];
bool ischild[mxn];

i64 gcdll(i64 a,i64 b){return b?gcdll(b,a%b):a;}

i64 dfs(int x)
{
	if(x==0)
		return 1;                 // 物品端：最小重量 1，可达为任意正整数倍
	i64 al=dfs(L[x]),ar=dfs(R[x]);
	i64 g=gcdll(P[x],Q[x]);
	i64 p=P[x]/g,q=Q[x]/g;
	i64 cl=al/gcdll(al,q),cr=ar/gcdll(ar,p);
	i64 c=(i64)((__int128)cl/gcdll(cl,cr)*cr);   // lcm，__int128 防溢出
	return c*(p+q);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)
	{
		cin>>P[i]>>Q[i]>>L[i]>>R[i];
		if(L[i])
			ischild[L[i]]=true;
		if(R[i])
			ischild[R[i]]=true;
	}
	int root{1};
	for(int i=1;i<=n;++i)
		if(!ischild[i])
		{
			root=i;
			break;
		}
	cout<<dfs(root)<<'\n';
	return 0;
}
```
