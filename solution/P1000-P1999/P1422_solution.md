# P1422 小玉家的电费

> 标签：分段计费 / 模拟 / 浮点输出 · 难度：入门

## 1. 重新读题

**问题重述（简化版）**：输入月用电总量 $n$（单位：千瓦时，正整数，$n\le 10000$）。按闽价电 [2006]27 号规定的三档阶梯电价，计算小玉家应缴电费（单位：元），输出保留到小数点后 $1$ 位。

**三档规则（题面原文逐条拆解）**：

| 档位 | 适用的用电量区间（千瓦时） | 单价（元/千瓦时） |
|---|---|---|
| 一档 | $1\sim 150$（即"150 及以下部分"） | $0.4463$ |
| 二档 | $151\sim 400$ | $0.4663$ |
| 三档 | $401$ 及以上 | $0.5663$ |

关键措辞：每一档后面都跟着"**……的部分**按每千瓦时……执行"，"部分"二字意味着这是**分段累进**计价——把总度数切成最多三段，各段乘各段单价再相加；而不是"总度数落在哪档就整单按那档单价"。

**目标**：求 $cost(n)$，输出形如 `xx.x`（元，1 位小数）。

**数据范围**：仅一个整数 $n\in[1,10000]$，无多测、无副任务，是纯 $O(1)$ 算术 + 格式化输出。

**陷阱与边界**：
1. 档端点归属：题面写"150 及以下"、"$151\sim400$"、"$401$ 及以上"。故 $150$ 归一档、$400$ 归二档、$401$ 归三档；不存在"既属上档又属下档"的重复计价。
2. 空段处理：$n<150$ 时二、三档长度为 $0$；$n<400$ 时三档长度为 $0$。负长度必须夹回 $0$，不能出现 $b=n-150<0$ 直接乘单价。
3. 输出精度：只保留 1 位小数（题面明确"保留到小数点后 $1$ 位"），不是 2 位、不是 4 位。
4. 题面无样例：本地题面**未提供输入输出样例**，因此**无法与官方答案对标**；下文验证只能依靠按规则手算的自造用例。

## 2. 思维链（Chain-of-thought）

### 2.1 探索机制——分段累进

**先精确刻画"每档只对部分计价"这个特殊机制**。把总度数 $n$ 想象成一根数轴上从 $1$ 到 $n$ 的线段，按两个分界点 $150$、$400$ 把它切成三段：

- 一段长度 $a$：数轴上 $[1,150]$ 这段与 $[1,n]$ 的交集长度；
- 二段长度 $b$：数轴上 $[151,400]$ 这段与 $[1,n]$ 的交集长度；
- 三段长度 $c$：数轴上 $[401,+\infty)$ 这段与 $[1,n]$ 的交集长度。

**引理 1（长度守恒）**：$a+b+c=n$。

证明：三段区间 $[1,150]$、$[151,400]$、$[401,+\infty)$ 两两不相交，且并集恰为 $[1,+\infty)\supseteq[1,n]$。它们与 $[1,n]$ 的交集也两两不相交、并集为 $[1,n]$，故长度之和 $=|[1,n]|=n$。$\blacksquare$

这一步排除了一个常见误读：若把"整单按最高档"当真，则 $n=401$ 应得 $401\times0.5663$；但按题面"401 及以上**的部分**"，只有第 401 度这一度按 $0.5663$，前 400 度仍按低档。引理 1 保证切段后每一度恰好被计入一次，既不漏也不重。

### 2.2 简化版——先做只有一档的情形

**剥掉分段机制**：假设只有一档单价 $p$，则 $cost=p\cdot n$，纯线性，一步到位。

**再逐段加回机制**：三档 = 把 $[1,n]$ 按分界点切开，每段各自套用"单档线性公式"再求和：

$$cost(n)=0.4463\,a+0.4663\,b+0.5663\,c.$$

这个简化版的启示：复杂之处全在"算出 $a,b,c$ 三个长度"，一旦长度算对，剩下就是三次乘法两次加法。于是问题从"计价"降级为"求交集长度"。

### 2.3 剖析边界——把 $a,b,c$ 写成闭式并证明

把"交集长度"翻译成 `min/max` 表达式（注意 $a$ 因 $n\ge1$ 自然 $\ge0$ 无须夹下界，$b$ 上限 $250=400-150$，$c$ 无上限）：

$$a=\min(n,150),\qquad b=\max(0,\ \min(n-150,250)),\qquad c=\max(0,\ n-400).$$

**引理 2（$a$ 闭式正确）**：$a=\min(n,150)$ 等于 $[1,150]\cap[1,n]$ 的长度。

证明（按 $n$ 与 150 分类）：
- 若 $n\le150$：$[1,n]\subseteq[1,150]$，交集 $=[1,n]$，长度 $n=\min(n,150)$。
- 若 $n>150$：交集 $=[1,150]$，长度 $150=\min(n,150)$。

两类都成立。$\blacksquare$

**引理 3（$b$ 闭式正确）**：$b=\max(0,\min(n-150,250))$ 等于 $[151,400]\cap[1,n]$ 的长度。

证明（按 $n$ 与 $150,400$ 分三类）：
- 若 $n\le150$：$[151,400]$ 与 $[1,n]$ 无交，长度 $0$；闭式 $n-150\le0\Rightarrow\min(n-150,250)\le0\Rightarrow\max(0,\cdot)=0$。一致。
- 若 $151\le n\le400$：交集 $=[151,n]$，长度 $n-150$；闭式 $0<n-150\le250\Rightarrow\min(n-150,250)=n-150\Rightarrow b=n-150$。一致。
- 若 $n>400$：交集 $=[151,400]$，长度 $400-150=250$；闭式 $n-150>250\Rightarrow\min=250\Rightarrow b=250$。一致。

三种情形逐项对齐。$\blacksquare$

**引理 4（$c$ 闭式正确）**：$c=\max(0,n-400)$ 等于 $[401,+\infty)\cap[1,n]$ 的长度。

证明：有交当且仅当 $n\ge401$，此时交集 $=[401,n]$，长度 $n-400$，闭式 $\max(0,n-400)=n-400$。若 $n\le400$ 无交长度 $0$，闭式 $n-400\le0\Rightarrow c=0$。一致。$\blacksquare$

**引理 5（档端点归属，回应"陷阱 1"）**：题面把 $150$ 判给一档、$400$ 判给二档、$401$ 判给三档。闭式在这三个切换点取值恰好：
- $n=150$：$a=150,b=0,c=0$（二档尚未启动，因 $b=\max(0,\min(0,250))=0$）。
- $n=400$：$a=150,b=250,c=0$（三档尚未启动，因 $c=\max(0,0)=0$）。
- $n=401$：$a=150,b=250,c=1$（三档恰启动 1 度）。

即"部分"切分在端点既不重叠也不遗漏，被引理 1 的 $a+b+c=n$ 双向夹逼。$\blacksquare$

### 2.4 经典解法——"每段长度 × 每段单价"求和

由引理 1（守恒）与引理 2–4（闭式），把分段累进压成一行求和：

$$cost(n)=0.4463\,\min(n,150)+0.4663\,\max(0,\min(n-150,250))+0.5663\,\max(0,n-400).$$

这是阶梯电价的标准建模：用夹取函数把"分段"写进闭式，避免对 $n$ 的所有区间逐条 `if/else` 枚举。

### 2.5 归约到更简单的问题

整题归约为"3 次 `min/max` + 3 次乘法 + 2 次加法 + 1 次格式化输出"，本质是 2.2 单档线性公式 $p\cdot n$ 在三个独立子段上各调用一次后求和。时间 $O(1)$，无循环、无数组。

### 2.6 溢出与精度防护

- **数值上界**：$n\le10000$，最贵近似全按三档 $cost<10000\times0.5663=5663$ 元，量级 $\le10^4$，远离任何溢出。
- **为何用 `double` 而非 `float`**：$double$ 有约 15~16 位十进制有效数字，整数部分占 4 位后小数余量充足，绝对舍入误差 $\ll10^{-11}$，远小于第 1 位小数的半单位 $5\times10^{-2}$；`float` 仅 ~7 位有效，小数余量不足，1 位小数可能被末位误差带偏。故用 `double`。
- **平局（$.x5$）分析**：三单价均 4 位小数，$cost$ 精确值至多 4 位小数，其后 4 位数字模 $1000$ 为 $(463a+663(b+c))\bmod1000$；要出现"恰 $.x5000$"需该余数 $=500$。手算覆盖三档的 $n\in\{1,10,150,151,250,400,401,999,1000,10000\}$ 均未触发，故 `fixed<<setprecision(1)` 与整数四舍五入结果一致。为与风格指南浮点输出惯例统一，代码取 `cout<<fixed<<setprecision(1)`。

## 3. 模式总结（Pattern Summary）
- explore its property — 把"分段累进"读成数轴 $[1,n]$ 与三档区间的交集长度之和（引理 1），拒绝"整单换档"误读。
- consider easier version — 剥成单档线性 $cost=p\cdot n$（2.2），再把分界加回，得"每段长度 × 每段单价"求和式。
- discuss by boundary — 用夹取函数写 $a=\min(n,150)$、$b=\max(0,\min(n-150,250))$、$c=\max(0,n-400)$（引理 2–4），空段自动夹回 $0$。
- consider easier version（复用）— 端点 $150/400/401$ 逐一取等，确认既不重叠也不遗漏（引理 5）。
- reduce to easier problem — 整题降级为 3 次 `min/max`+算术的 $O(1)$ 闭式（2.5）。
- classic problem solution — 阶梯电价的标准建模：夹取闭式替代 `if/else` 枚举（2.4）。
- precision guard — `double`（非 `float`）保 1 位小数，并分析 $.x5$ 平局不会触发（2.6）。

## 4. 真实解法（Real Solution）

### 4.1 符号表（Notation Glossary）

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n` | 月用电总量（千瓦时） | `int`，输入 | $1\le n\le10000$ |
| `t1,t2` | 档分界 150、400 | `constexpr int` | 一档$\le t1$，二档$151\sim t2$，三档$>t2$ |
| `p1,p2,p3` | 三档单价 | `constexpr double` | $0.4463,0.4663,0.5663$ |
| `a` | 一档 $[1,150]$ 的计价度数 | `int`，`=clamp(n,1,t1)` | $\min(n,150)$（$n\ge1$ 故下界取 1） |
| `b` | 二档 $[151,400]$ 的计价度数 | `int`，`=clamp(n-t1,0,t2-t1)` | $\max(0,\min(n-150,250))$ |
| `c` | 三档 $[401,+\infty)$ 的计价度数 | `int`，`=max(0,n-t2)` | $\max(0,n-400)$ |
| `ans` | 应缴电费（元） | `double`，`=a*p1+b*p2+c*p3` | 三段之和 |

> **辅助函数**：`std::clamp(x,lo,hi)`（C++17）即 $\max(\text{lo},\min(x,\text{hi}))$；本题无数组，仅以上标量。

> **不变量**：$a+b+c=n$（引理 1），且 $a\le150,\ b\le250$。$n\le150$ 时 $b=c=0$；$n\le400$ 时 $c=0$。

### 4.2 算法步骤（Numbered Steps）

1. **读入** $n$。
2. **算三段长度**：$a=\texttt{clamp}(n,1,150)$；$b=\texttt{clamp}(n-150,0,250)$；$c=\max(0,n-400)$。
3. **求和计价**：$ans=a\cdot0.4463+b\cdot0.4663+c\cdot0.5663$（`double`）。
4. **格式化输出**：`cout<<fixed<<setprecision(1)<<ans<<'\n'`，严格 1 位小数（题面"保留到小数点后 1 位"）。

### 4.3 复杂度

- 时间 $O(1)$：常数次 `min/max`、3 次乘法、2 次加法。
- 空间 $O(1)$：仅 `n,a,b,c,ans` 几个标量，无数组（故无 `fill_n` 需求）。

## 5. 示例代码（C++17）

```cpp
// P1422 小玉家的电费
// 分段累进计费：三段夹取长度 × 各段单价求和
// https://www.luogu.com.cn/problem/P1422
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int t1{150},t2{400};         // 档分界：一档<=150，二档151~400，三档>=401
constexpr double p1{0.4463},p2{0.4663},p3{0.5663};   // 三档单价

int n;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	// 三段计价度数（引理 2-4）：a+b+c=n
	int a=clamp(n,1,t1);               // min(n,150)，n>=1 故下界取 1
	int b=clamp(n-t1,0,t2-t1);         // max(0,min(n-150,250))
	int c=max(0,n-t2);                 // max(0,n-400)
	double ans=a*p1+b*p2+c*p3;
	cout<<fixed<<setprecision(1)<<ans<<'\n';   // 题面要求：保留 1 位小数
	return 0;
}
```

### 代码说明

- **风格**：`#include<bits/stdc++.h>` 单头文件；`using i64=long long;` 备而不用（本题无大整数）；Tab 缩进；运算符两侧无空格；`'\n'` 不用 `endl`；`cin.tie→cout.tie→ios::sync_with_stdio` 固定顺序。
- **无数组**：本题 $O(1)$ 纯标量，故没有全局静态数组，也就无 `mxn` 与 `fill_n` 需求（该规则仅对"用数组存不可达状态"生效）。
- **`clamp`/`max` 对应引理 2–4**：`a=clamp(n,1,150)`、`b=clamp(n-150,0,250)`、`c=max(0,n-400)` 三行即是思维链中三条闭式，天然处理空段（夹回 0）。
- **精度**：用 `double`（非 `float`），`setprecision(1)` 与题面"保留到小数点后 1 位"逐字对应，单位"元"由题意隐含、不额外打印货币符号。
- **无副作用**：仅读入 $n$、输出 $ans$，不触碰任何文件、不修改工程配置。
