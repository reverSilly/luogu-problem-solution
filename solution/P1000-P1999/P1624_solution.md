# P1624 [ECNA 2005] 单词缩写

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

先给出 $N$ 个"无效单词"（小写）。之后每个询问给一个**缩写串** $A$（全大写）和一个**全称**（一行若干空格分隔的单词）。全称中凡是与某个无效单词相同的词整词忽略，剩下的都是"有效单词"。

一个**解释方法**是：给 $A$ 的每个字母在大写意义下指定全称中一个**字母相同**的位置，要求：

1. 位置按 $A$ 的顺序**严格递增**（缩写必须是全称的子序列）；
2. 恰好按这个顺序扫过全称，且每个**有效单词**至少被指定一个位置。

问解释方法的个数；一个都没有则缩写不合法。输出形如 `ABC can be formed in 3 ways` 或 `ABC is not a valid abbreviation`。

### 输入输出格式

- **输入格式**：第一行 $N$；随后 $N$ 行无效单词；之后若干询问，每行"缩写 + 全称"，读到缩写为 `LASTCASE` 结束。
- **输出格式**：每个询问一行，`缩写 can be formed in i ways` 或 `缩写 is not a valid abbreviation`。
- **数据规模**：$N\le100$，每行长度 $\le150$，询问 $\le20$，方案数 $\le10^9$。

### 关键约束分析

1. 行长 $\le150$，缩写长度 $L$ 与单词长度都很小，$\mathcal{O}(L^2\cdot\text{总长})$ 级别的 DP 完全够用。
2. 方案数 $\le10^9$ 仍贴边 `int`，用 `long long` 更稳（中间量相加可能短暂越界 `int`）。
3. 大小写：缩写全大写、全称大小写混杂，比较时必须统一；无效单词表是小写，判定忽略时要转小写。
4. 边界：全称单词数少于"必须覆盖"的需求时答案为 $0$（不合法），输出不能是 `0 ways`。
5. 询问数量没有给出，必须用 `while(cin>>abbr)` 读到 `LASTCASE`；每行后用 `getline` 取剩余部分，行尾可能带 `\r`，需要裁剪。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：把"解释方法"翻译成一个纯粹的序列问题

先不管单词边界：把全称中所有**有效单词**的字符按顺序摊平成一串 $c_1c_2\cdots c_M$（记录每个字符属于哪个单词）。那么"给每个缩写字母指定一个位置且顺序递增"就等价于：在摊平串中选一个**严格递增的下标序列** $p_1<\dots<p_L$，使得 $\mathrm{upper}(c_{p_k})=A_k$。

**引理 1（摊平双射）**：解释方法与上述满足条件的位置序列一一对应。

*证明*：给定一个解释方法，每个缩写字母的位置是确定的，按字母顺序排列即得递增序列（条件 1 就是顺序要求）；不同解释方法至少有某个字母位置不同，得到的序列也不同，故映射是单射。反过来，给定序列，把第 $k$ 个位置指定给 $A_k$ 就得到一个解释方法，且这是正向映射的逆，故为满射。$\square$

有了引理 1，"每个有效单词至少被指定一次"就变成"每个单词区间内至少有一个被选中的下标"。

### 第二步：为什么不能简单地数子序列

若没有"每个有效单词至少一次"的约束，答案就是经典的子序列计数 $\mathcal{O}(ML)$。约束把问题变成"带覆盖要求的子序列计数"：一个位置序列可能漏掉某个单词，必须排除。这正是需要加一维状态（当前处理到哪个单词、当前单词是否已经开始贡献）的原因。

### 第三步：按单词分段做 DP

由于选择的顺序与单词顺序一致，可以把序列切成若干段，第 $i$ 段落在第 $i$ 个有效单词内。于是定义

$$dp[j]=\text{处理完前若干个有效单词后，用掉 }A\text{ 的前 }j\text{ 个字母，且每个已处理单词都至少被用一次的方案数}.$$

初始 $dp[0]=1$，其余 $0$。

**引理 2（单词语义）**：对当前单词 $W$，新的 $dp'[j]$ 只统计"A 的第 $j'$ 到第 $j-1$ 个字母被放进 $W$（$j'<j$，段非空）"的方案。

*证明*：由引理 1，位置序列按单词天然分段；第 $i$ 段非空当且仅当第 $i$ 个有效单词被覆盖至少一次。段与段之间由"前一段用掉前 $j'$ 个字母"衔接，故只需枚举段尾 $j$ 并把 $dp[j']$ 乘上"$A[j'..j)$ 在 $W$ 中作为子序列的嵌入数"。$\square$

### 第四步：把"所有段的嵌入数"压成一次扫描

直接按引理 2 枚举 $(j',j)$ 需要先算一个 $\mathcal{O}(|W|L^2)$ 的二维表，再与 $dp$ 卷积。注意到两件事可以合并：

**引理 3（单词内转移）**：设当前单词为 $W$，从左到右扫描其字符 $c$，对 $j$ 从 $L$ 到 $1$ **倒序**更新

$$cur[j]\mathrel{+}=\big[c=A_j\big]\cdot\big(cur[j-1]+dp[j-1]\big).$$

扫描结束后 $cur[j]$ 恰为"本单词贡献一段非空、共消耗前 $j$ 个字母"的方案数。

*证明*：对 $W$ 已扫描的前缀长度归纳。$cur[j-1]$ 项表示本单词此前已经贡献过字母（段长 $\ge1$），现在再接一个；$dp[j-1]$ 项表示本单词此前没贡献过，当前字符是段首。二者按"段长是否为 $1$"分类，互斥且穷尽，故递推完备。倒序枚举 $j$ 保证更新 $cur[j]$ 时用到的 $cur[j-1]$ 还是**上一个字符**处理完的值，这样一个字符不会被同一段用两次；同时字符从左到右扫描，保证段内下标递增。$\square$

这一步把每个单词的代价从 $\mathcal{O}(|W|L^2)$ 降到 $\mathcal{O}(|W|L)$。

### 第五步：每个有效单词都必须贡献，所以状态不能"继承"

**引理 4（必须用 $cur$ 覆盖 $dp$）**：处理完单词 $W$ 后应令 $dp\leftarrow cur$，而**不是** $dp\leftarrow dp+cur$。

*证明*：若保留 $dp$ 的旧值，等价于允许某个有效单词贡献 $0$ 个字母；引理 2 已说明段的非空性与"单词被覆盖"等价，所以这种方案违反了题意中"每个有效单词至少有一个字符出现在缩写中"。故旧值必须丢弃。$\square$

反过来，无效单词被整词跳过：它既不消耗字母，也不要求被覆盖，$dp$ 原样保留。

### 第六步：答案与合法性

扫描完所有单词后，$dp[L]$ 就是"用完全部 $L$ 个字母且所有有效单词都覆盖"的方案数。为 $0$ 说明不存在解释方法，输出不合法；否则输出该数。

**定理**：上述 DP 结束时 $dp[L]$ 等于题目所求解释方法数。

*证明*：引理 1 建立了解释方法与位置序列的双射；引理 2 说明按单词分段枚举不重不漏；引理 3 在每个单词内正确统计了所有非空段；引理 4 保证了覆盖约束。四者合起来，$dp[L]$ 统计的正是全部合法位置序列。$\square$

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 解释方法就是"全称中的递增位置序列"，单词边界只是给序列分了段。
- `reduce to easier problem` — 去掉"每词至少一次"后退化为经典子序列计数，说明难点只在覆盖约束。
- `classic problem solution` — 以"已用缩写前缀长度"为状态的子序列计数 DP，逐词推进。
- `explore its property` — 段非空 $\Leftrightarrow$ 单词被覆盖，因此新状态必须完全覆盖旧状态。
- `classic problem solution` — 把"枚举段 + 卷积"压成一次字符扫描 + 倒序更新，$\mathcal{O}(|W|L)$。
- `consider easier version` — 无效单词直接整词跳过，等价于把它们从全称中删掉。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $N$ | `n` | 无效单词个数 |
| $\mathcal{B}$ | `bad` | 无效单词集合（`set<string>`，全小写） |
| $A$ | `ab` | 当前询问的缩写串 |
| $L$ | `L` | 缩写长度 `ab.size()` |
| $dp[j]$ | `dp[j]` | 处理完此前所有有效单词、用掉 $A$ 前 $j$ 个字母的方案数，初值 `dp[0]=1` |
| $cur[j]$ | `cur[j]` | 当前单词贡献一段非空子序列、用掉前 $j$ 个字母的方案数，每词开始前清零 |
| 全称 | `ph` | `getline` 读入后 `trim` 的整行文本 |
| 单词 | `w` | `istringstream` 逐个切出的词 |
| 小写词 | `low` | `w` 转小写，用于查 `bad` |
| 字符 | `u` | `w` 中字符转大写后与 `ab[j-1]` 比较 |
| 读入行 | `line` | `getline` 的缓冲区；缩写行剩余为空时再读一行 |

### 算法步骤

1. 读入 $N$ 与 $N$ 个无效单词存入 `bad`；`getline` 吃掉行尾换行。
2. 循环 `cin>>ab`，遇到 `LASTCASE` 结束；用 `getline` 取本行剩余部分作为全称（若为空则继续读下一行，兼容"缩写在上一行、全称在下一行"的格式），`trim` 掉 `\r`、空格、制表符。
3. 初始化 `dp[0]=1`，其余为 $0$。
4. 对全称中每个词：转小写查 `bad`，命中则跳过；否则清零 `cur`，从左到右扫字符，对 $j=L\to1$ 做 `cur[j]+=cur[j-1]+dp[j-1]`（当字符匹配），扫完把 `cur` 整体写回 `dp`。
5. 输出：`dp[L]>0` 时打印方案数，否则打印不合法。

### 复杂度分析

- **时间复杂度**：每个询问 $\mathcal{O}\big(L\cdot\sum_{W}|W|\big)\le\mathcal{O}(L\cdot150)$，即约 $2.2\times10^4$ 次加法，$20$ 个询问合计 $<5\times10^5$。
- **空间复杂度**：$\mathcal{O}(L+|\mathcal{B}|\cdot\text{词长})$，即两个长度 $155$ 的数组加一张忽略表。

### 正确性验证

引理 1 保证"位置序列"与"解释方法"等价；引理 3 保证单词内所有非空段都被正确计数且不重复使用字符；引理 4 保证覆盖约束；定理完成归纳。数值上方案数 $\le10^9$，中间量 `cur[j]+dp[j-1]` 至多 $2\times10^9$，`long long` 不会溢出。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1624 [ECNA 2005] 单词缩写
// https://www.luogu.com.cn/problem/P1624
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{155};

int n;
set<string>bad;
string ab;
i64 dp[mxn],cur[mxn];                    // dp[j]:前若干个有效单词用掉缩写前 j 个字母的方案数

string trim(const string&s)
{
	int l=0,r=(int)s.size()-1;
	while(l<=r&&(s[l]==' '||s[l]=='\t'||s[l]=='\r'))
		++l;
	while(r>=l&&(s[r]==' '||s[r]=='\t'||s[r]=='\r'))
		--r;
	if(l>r)
		return "";
	return s.substr(l,r-l+1);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		string s;
		cin>>s;
		bad.insert(s);
	}
	string line;
	getline(cin,line);
	while(cin>>ab)
	{
		if(ab=="LASTCASE")
			break;
		string ph;
		getline(cin,line);
		ph=trim(line);
		while(ph.empty())
		{
			if(!getline(cin,line))
				break;
			ph=trim(line);
		}
		int L=ab.size();
		fill(dp,dp+L+1,0);
		dp[0]=1;
		istringstream is(ph);
		string w;
		while(is>>w)
		{
			string low;
			for(char c:w)
				low+=(char)tolower(c);
			if(bad.count(low))
				continue;                       // 无效单词整词跳过
			fill(cur,cur+L+1,0);
			for(char c:w)
			{
				char u=(char)toupper(c);
				for(int j=L;j>=1;--j)
					if(u==ab[j-1])
						cur[j]+=cur[j-1]+dp[j-1];   // 接在本词内 / 本词开头
			}
			for(int j=0;j<=L;++j)
				dp[j]=cur[j];                   // 每个有效单词至少要贡献一个字母
		}
		if(dp[L]>0)
			cout<<ab<<" can be formed in "<<dp[L]<<" ways\n";
		else
			cout<<ab<<" is not a valid abbreviation\n";
	}
	return 0;
}
```

### 易错点

1. **`dp` 与 `cur` 相加**：写了 `dp[j]+=cur[j]` 就等于允许有效单词不贡献字母，答案会偏大。必须是 `dp=cur`。
2. **正序枚举 $j$**：正序会让同一个字符被重复使用，方案数暴增。必须 $j$ 从 $L$ 到 $1$ 倒序。
3. **大小写**：缩写是大写、词是小写，字符比较前必须 `toupper`；无效单词表是小写，查表前必须 `tolower`。
4. **忽略判定用了原始词**：若全称里写的是 `The`，不转小写就匹配不到小写的 `the`。
5. **读入格式**：`cin>>ab` 不消费换行，紧接着的 `getline` 会读到空串；本实现用"空则再读一行"兜底，同时 `trim` 掉 `\r`。
6. **不合法也要输出完整句式**：`... is not a valid abbreviation`，不能只输出 `0`。
