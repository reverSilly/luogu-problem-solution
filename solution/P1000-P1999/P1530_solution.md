# P1530 [USACO2.4] 分数化小数 Fractions to Decimals

> 标签：模拟 · 数学 · USACO · 难度：普及/提高-
> 本地题面：`P1530.md`（$1\le N,D\le10^5$；循环节用圆括号表示；整数写作 `x.0`；结果长度 $>76$ 时每行输出 $76$ 个字符，输入/输出均为一组）。验证：本地对拍 300 组随机/边界用例 std==brute 全部通过；手工样例 $45/56\to0.803(571428)$、$41/333\to0.(123)$、$1/3\to0.(3)$ 均吻合；最坏 $1/99991$ 输出 50656 字符，实测 **0.0060s**。

## 1. 重新读题

**问题重述（人话版）**

给一组 $N,D$，把分数 $\dfrac ND$ 写成十进制小数：

- 整数部分就是 $\lfloor N/D\rfloor$；其后接小数点和一个**小数部分**。
- 若小数部分为**有限**的，直接写出来；若**无限循环**，把**循环节**（最短的重复片段）用一对圆括号括起来，例如 $1/3=0.(3)$、$41/333=0.(123)$。
- 若结果是整数，写作 $\texttt{x.0}$（小数点后补一个 $0$）。
- 若整条输出串长度 $>76$，则每 $76$ 个字符换一行。

一句话版本：**用长除法展开 $N/D$，检测循环节并加括号，最后按 76 字符换行输出。**

**题面里容易漏掉的条款**

1. 「**整数 $x$ 写成 $x.0$**」⇒ 整除时（含 $N/D$ 恰为整数）必须补 `.0`，不能只输出整数，也不能输出 `x.`。
2. 「循环节放在一对**圆括号**中」⇒ 括号只包住循环体，循环体前的非循环前缀留在括号外（如 $0.803(571428)$）。
3. 「结果长度大于 **$76$**，每行输出 $76$ 个字符」⇒ 换行是**硬切 $76$ 字符**，不是按词、也不在括号处断行；短结果不换行。
4. $N,D\ge1$，没有 $D=0$；但 $N$ 可能小于 $D$（整数部分为 $0$）。
5. 输出可能很长（循环节最长约 $D$ 位），需要确认输出规模上界。

**数据范围与规模感受**

$$1\le N,D\le10^{5}.$$

循环节的周期在"余数取值"上不超过 $D$ 种，故小数位数不超过 $O(D)=10^{5}$ 级别；输出总长也在 $10^{5}$ 量级。于是逐位模拟、用"余数 → 首次出现位置"的数组检测循环即可，时间空间都 $O(D)$。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"小数展开"写成递推

$N/D$ 的十进制展开就是整数除法：先取整数部分，然后不断"余数乘 10 再除以 $D$"。

**引理 1（长除法递推）**

令 $r_0=N\bmod D$。定义

$$r_k=(10\,r_{k-1})\bmod D,\qquad d_k=\left\lfloor\frac{10\,r_{k-1}}{D}\right\rfloor\quad(k\ge1).$$

则 $N/D=\lfloor N/D\rfloor+\sum_{k\ge1}d_k\cdot10^{-k}$，且每一位小数 $d_k$ 由 $r_{k-1}$ 唯一决定，$r_k$ 亦由 $r_{k-1}$ 唯一决定。

**证明**：对任意 $k$，把 $N/D$ 的小数部分写成 $r_{k-1}/D$ 的形式（这是长除法的不变量：截到第 $k-1$ 位后，剩余值是 $r_{k-1}/D$）。将 $r_{k-1}/D$ 乘 $10$ 得 $10r_{k-1}/D$，其整数部分即下一位小数 $d_k$，小数部分对应的新余数为 $10r_{k-1}-d_kD=(10r_{k-1})\bmod D=r_k$。归纳即得递推成立，且每一步状态只由前一步余数决定。$\blacksquare$

> 关键推论：**小数位的取值完全由"当前余数"决定**，这为下面用"余数重复"检测循环埋下伏笔。

### 2.2 什么时候有限、什么时候循环

**引理 2（有限 ⇔ 约分后分母只含因子 $2,5$）**

设 $g=\gcd(N,D)$，$b=D/g$。则 $N/D$ 的十进制展开**有限**，当且仅当 $b=2^p5^q$（即 $b$ 不含 $2,5$ 之外的质因子）；此时小数位数不超过 $\max(p,q)\le\lceil\log_2 D\rceil$。

**证明**：
- （$\Leftarrow$）若 $b=2^p5^q$，取 $t=\max(p,q)$。则 $10^t=2^t5^t$ 被 $2^p5^q=b$ 整除（因 $t\ge p$ 且 $t\ge q$）。于是 $N/D=\dfrac{a}{b}$（$a=N/g$ 为整数）$=\dfrac{a\cdot(10^t/b)}{10^t}$，分子是整数，写成 $t$ 位（可含末尾零）的小数即终止，位数 $\le t$。
- （$\Rightarrow$）若展开在第 $t$ 位终止，则 $N/D=\dfrac{M}{10^t}$（$M$ 为整数），约分后 $b\mid 10^t=2^t5^t$，故 $b$ 的质因子只能是 $2,5$。$\blacksquare$

对应到长除法：这正是"某个 $r_k=0$"的情形（余数归零，其后恒为 $0$）。

**引理 3（非终止时，首次重复的余数必在 $D$ 步内出现）**

若所有 $r_k\ne0$，则 $r_1,r_2,\dots$ 取值均落在 $\{1,\dots,D-1\}$ 这个含 $D-1$ 个元素的集合中。由抽屉原理，$r_1,\dots,r_D$ 这 $D$ 个余数里必有两个相等。因此循环节长度 $L\le D$，且**首个重复必然在 $D$ 步数字之内产生**；位数只需模拟到出现重复即可。

**证明**：$r_k\in\{1,\dots,D-1\}$（模 $D$ 非零），除去标号的 $D-1$ 个取值放 $D$ 个物体必有碰撞。首个碰撞的下标差即为周期上界。$\blacksquare$

### 2.3 循环节的起点与括号

**引理 4（首次重复所指的位置正是循环节起点）**

设首次重复为 $r_i=r_j$（$i<j$，且取**最小**的 $i$，再取对应最小 $j$）。则位数 $d_{i+1},d_{i+2},\dots$ 从下标 $i+1$ 起严格周期（周期 $L=j-i$），而 $d_1,\dots,d_i$ 不含循环。

**证明**：
- 周期性：因 $r_k$ 由 $r_{k-1}$ 唯一决定（引理 1），从 $r_i=r_j$ 出发两条轨道完全重合，故 $r_{i+s}=r_{j+s}$ 对所有 $s\ge0$，对应小数位 $d_{i+1+s}=d_{j+1+s}$，周期 $L=j-i$。
- 循环前不重复：取**最小**的 $i$。若存在 $i'<i$ 与某 $j'>i'$ 使 $r_{i'}=r_{j'}$，则会更早发现重复，与 $i$ 最小矛盾。因此 $r_1,\dots,r_i$ 两两不同、且此后不再出现（否则又构成一次更早可见的重复），故前 $i$ 位属于"非循环前缀"。$\blacksquare$

于是输出结构为

$$\underbrace{\lfloor N/D\rfloor}_{整数}\ \texttt{.}\ \underbrace{d_1\cdots d_i}_{非循环前缀}\ \texttt{(}\,\underbrace{d_{i+1}\cdots d_{i+L}}_{循环节}\,\texttt{)} .$$

**引理 5（括号放置正确性）**：若第 $k$ 位数字对应的余数 $r_k$ 首次出现在位置 $i$（即以 $r_k$ 为键在"首次出现表"里查到下标 $i$，且此时已确认它是重复），则循环起点是 $d_{i+1}$。括号加在 $d_1..d_i$ 之后、把 $d_{i+1}..$ 全部括起。由引理 4，括号内恰好是一个完整周期，且不含多余的前缀数字。$\blacksquare$

### 2.4 实现要点：状态规模与边界

- **循环检测数据结构**：因为余数取值在 $[0,D)$，直接开 `int pos[D+5]`（初始化 $-1$），$O(1)$ 查表；无需哈希。$D\le10^5$ 数组完全够。
- **停止条件**：`while(rem && pos[rem]==-1)`——余数为 $0$（终止）或余数已出现（循环）就停。
- **整除补零**：若 `rem` 一开始就是 $0$，小数串为空，需要补一个 `"0"` 得到 `x.0`。
- **换行**：对整条串按步长 $76$ 切片输出。
- **上界确认**：位数 $\le D$，`pos` 数组开到 $D+5$；`s` 长度也在 $D$ 量级。

### 2.5 剖析失败思路

**失败 1：把循环节前的每个前缀也塞进括号。** 例：$45/56$ 若把 $8$ 也放进括号得 `0.(803571428)`，错；正确是 `0.803(571428)`（引理 4）。

**失败 2：整除时不补 `.0`。** $4/2$ 输出 `2.` 或 `2`，均错，应为 `2.0`。

**失败 3：余数重复时用的是"当前余数"的下标**，即把循环标记记错了一位（应记"首次出现"位置，而非"本次出现"位置）。反例：$1/3$，若用本次下标，会把循环起点整体后移，括号位置错误。

**失败 4：按 76 字符换行时在 `\n` 之外还插别的分隔**，或短输出也强行换行。

## 3. 模式总结（Pattern Summary）

**模式名：长除法模拟的「余数轨迹 + 首次出现表检测循环」。**

**识别信号**：把有理数写成分数小数、检测并输出循环节，或任何"有限状态确定性迭代找周期"的题。

**可复用套路（按真实思考顺序）**：

- **explore its property** — 把小数展开写成 $r_k=(10r_{k-1})\bmod D$ 的确定性递推（引理 1）。
- **consider easier version** — 先解决"终止不终止"的判定：约分后分母只含因子 $2,5$ 才终止（引理 2）。
- **classic problem solution** — 用**抽屉原理**给出"首个重复在 $D$ 步内出现"的界，从而确定模拟规模上限（引理 3）。
- **reduce to easier problem** — "找循环节"归约为"在确定性映射的余数序列里找首次重复"（引理 4）。
- **classic problem solution(第二次，独立技巧)** — 用**数组/哈希做首次出现表** $O(1)$ 查重，把寻找周期降到 $O(D)$；余数取值域小则直接开数组。
- **defer reconstruction** — 先记下停止时的余数，事后据其"首次出现下标"才插入括号，而非边跑边拼（引理 5）。
- **format last** — 逻辑跑完得到纯串后再统一按 76 字符换行。

**同族题**：USACO 2.4 Fractions；十进制循环节相关（如 $(10^k-1)$ 因子、循环小数转分数）。

**一句话记忆**：分数化小数 = 长除法记余数；余数归零则终止，余数重复则括号，取"首次出现位置"定循环起点。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $N,D$ | `int n,d` | 分子 / 分母 | 读入 | 题面 |
| `ip` | `int` | 整数部分 $\lfloor N/D\rfloor$ | $N/D$ | 输出前缀 |
| `rem` | `int` | 当前余数 | $N\bmod D$ | 长除法核心状态（引理 1） |
| $s$ | `string` | 小数数字串（未加括号） | 空 | 逐位追加 $d_k$ |
| `pos[r]` | `int [100005]` | 余数 $r$ 首次出现时在 $s$ 中的下标 | 全 $-1$ | 首次出现表（引理 3–5） |
| `st` | `int`（局部） | 循环节起点下标 | `pos[rem]` | $s$ 中 $[st]$ 处开始是循环 |
| `full` | `string` | 完整输出串 | 拼装 | 最后按 76 换行 |

### 4.2 编号步骤

1. 读入 $N,D$；`ip=N/D`，`rem=N%D`；`fill_n(pos,-1)`。
2. 循环：当 `rem != 0` 且 `pos[rem]==-1`：
   - `pos[rem]=s.size()`（记录首次出现位置）；
   - `rem*=10`；`s.push_back('0'+rem/D)`；`rem%=d`。
3. 若 `rem==0`（有限小数）：若 `s` 为空则置 `s="0"`；`full=to_string(ip)+"."+s`。
4. 否则（循环）：`st=pos[rem]`；`full=to_string(ip)+"."+s.substr(0,st)+"("+s.substr(st)+")"`。
5. 按 `i=0,76,152,...` 输出 `full.substr(i,76)`，每段一行。

### 4.3 复杂度

- 时间：位数 $\le D$，每步 $O(1)$，总计 $O(D)\le10^{5}$；拼接与换行 $O(|full|)$。
- 空间：`int pos[100005]` $\approx400$ KB，`string` $O(D)$。
- 实测：$1/99991$ 输出 50656 字符，耗时 **0.0060s**；$1/97$ 输出恰为 76 字符 + 24 字符两行。

### 4.4 关键不变量

1. 进入第 $k$ 轮时 `rem`$=r_{k-1}$，`s` 长度 $=k-1$。
2. `pos[rem]` 记录的是该余数**首次**出现的位置，停止时的 `pos[rem]` 即循环起点。
3. 停止后 `rem==0` 表示有限小数；否则为循环。

### 4.5 验证状态小结

|---|---|
| 手工样例 | **通过**：`1 3`→`0.(3)`、`41 333`→`0.(123)`、`2 1`→`2.0`、`45 56`→`0.803(571428)`、`1 6`→`0.1(6)`、`22 7`→`3.(142857)` |

## 5. 示例代码

### 5.1 主解：长除法 + 首次出现表（与 `appendix/P1530/P1530.cpp` 逐字节一致）

```cpp
//
// 题目：P1530 [USACO2.4] 分数化小数 Fractions to Decimals
// https://www.luogu.com.cn/problem/P1530
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};        // 余数 < D <= 1e5 (+5 松弛)

int n,d;
int pos[mxn];                     // pos[r]=余数 r 首次出现时的小数位下标, -1 表示未出现

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>d;
	int ip=n/d,rem=n%d;           // 整数部分 / 首个余数
	string s;                     // 小数数字串(先不含括号)
	fill_n(&pos[0],mxn,-1);
	while(rem&&pos[rem]==-1)      // 余数为 0 或余数重复则停
	{
		pos[rem]=s.size();
		rem*=10;
		s.push_back(char('0'+rem/d));
		rem%=d;
	}
	string full;
	if(rem==0)                    // 有限小数
	{
		if(s.empty())
			s="0";                // 整除:整数 x 写作 x.0
		full=to_string(ip)+"."+s;
	}
	else                          // 无限循环小数:在循环节起点插括号
	{
		int st=pos[rem];
		full=to_string(ip)+"."+s.substr(0,st)+"("+s.substr(st)+")";
	}
	for(int i=0;i<(int)full.size();i+=76)
		cout<<full.substr(i,76)<<'\n';
	return 0;
}
```

### 5.2 对照实现：先多生成几位再线性找重复（仅用于对拍，与 `P1530_brute.cpp` 一致）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{200005};

int n,d;
int rems[mxn];                    // 余数序列
char digs[mxn];                   // 对应小数位

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>d;
	int ip=n/d,r=n%d;
	string full=to_string(ip)+".";
	if(r==0)
	{
		full+="0";
		cout<<full<<'\n';
		return 0;
	}
	int lim=2*d+10,len=0,cur=r;    // 生成足够多位的数字
	while(len<lim&&cur!=0)
	{
		rems[len]=cur;
		cur*=10;
		digs[len]=char('0'+cur/d);
		cur%=d;
		len++;
	}
	if(cur==0)                    // 有限小数
	{
		for(int i=0;i<len;++i)
			full+=digs[i];
	}
	else                          // 早先出现过的余数即循环节起点(线性扫描)
	{
		int st=-1,per=-1;
		for(int i=0;i<len&&st==-1;++i)
			for(int j=i+1;j<len;++j)
				if(rems[i]==rems[j])
				{
					st=i;per=j-i;break;
				}
		for(int i=0;i<st;++i)
			full+=digs[i];
		full+='(';
		for(int i=st;i<st+per;++i)
			full+=digs[i];
		full+=')';
	}
	for(int i=0;i<(int)full.size();i+=76)
		cout<<full.substr(i,76)<<'\n';
	return 0;
}
```

### 5.3 易错点清单

- **整除不补 `.0`** ⇒ 输出 `2.`/`2`，均错。
- **括号括错前缀** ⇒ 循环起点须取"首次出现的余数位置"，不是"本次余数位置"。
- **忘记初始化 `pos` 为 $-1$** ⇒ 全局默认 $0$，会被误当作"位置 $0$ 已出现"，循环检测错乱。
- **`rem` 已为 $0$ 时仍进循环** ⇒ 多输出无意义位；用 `while(rem&&...)` 短路。
- **换行写成 `endl`** ⇒ 违反风格且低效，用 `'\n'`。
