# P1969 [NOIP 2013 提高组] 积木大赛

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 个位置，初始高度全为 $0$，目标高度为 $h_1..h_n$。每次操作选一个**连续区间** $[l,r]$，把区间内所有位置的高度 $+1$。问达到目标高度的最少操作次数。

注意：操作只能加不能减，且必须是一段连续的区间。

### 1.2 关键约束与规模暗示

- $n\le 10^5$，$0\le h_i\le 10^4$。
- $30\%$：$n\le 10$，可以搜索/状压；$70\%$：$n\le 1000$，$O(n^2)$ 的区间 DP 可行；$100\%$ 必须 $O(n)$ 或 $O(n\log n)$。
- 答案最大约为 $n\cdot\max h_i=10^9$，在 `int` 范围内，但用 `long long` 更保险。
- $h_i$ 可以为 $0$，即某些位置不需要建。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先看小例子，猜答案形式

手算几个例子：

- $h=[2]$：显然 $2$ 次（两次 $[1,1]$）。
- $h=[1,2]$：可以先 $[1,2]$ 再 $[2,2]$，共 $2$ 次。答案 $=1+(2-1)=2$。
- $h=[2,1]$：先 $[1,2]$ 再 $[1,1]$，共 $2$ 次。答案 $=2+\max(0,1-2)=2$。
- $h=[3,1,3]$：可以先 $[1,3]$ 一次，再在两端各补两次，共 $1+2+2=5$ 次。答案 $=3+0+2=5$。
- $h=[2,3,1]$：先 $[1,2]$ 两次、$[2,2]$ 一次、$[1,1]$？更优：$[1,3]$ 一次、$[1,2]$ 一次、$[2,2]$ 一次，共 $3$。答案 $=2+(3-2)+0=3$。

看起来答案是

$$
h_1+\sum_{i=2}^{n}\max(0,\ h_i-h_{i-1}).
$$

等价地，令 $h_0=0$，答案为 $\sum_{i=1}^{n}\max(0,h_i-h_{i-1})$。

### 2.2 为什么「上升量」是下界：差分记账

定义差分

$$
d_i=h_i-h_{i-1}\qquad(1\le i\le n),\qquad h_0=0,
$$

再补一个 $d_{n+1}=h_{n+1}-h_n$，其中 $h_{n+1}=0$（把「收尾」也记账）。

一次操作 $[l,r]$ 对差分数组的影响非常干净：

- 位置 $l$ 处高度比左边多 $1$，所以 $d_l$ 增加 $1$；
- 位置 $r+1$ 处高度比左边少 $1$，所以 $d_{r+1}$ 减少 $1$；
- 中间的位置左右都 $+1$，差分不变。

也就是说，**每次操作恰好给某一个 $d_l$ 加 $1$，给某一个 $d_{r+1}$ 减 $1$**。

**引理 1（下界）**：任何合法方案的操作次数 $T\ge\sum_{i=1}^{n}\max(0,d_i)$。

**证明**：最终差分数组中，若 $d_i>0$，那么在所有操作结束后 $d_i$ 的净增量是 $d_i$（初始全 $0$）。每次操作最多让某一个 $d$ 位置增加 $1$（就是它自己的左端点），所以为了让 $d_i$ 达到正值 $d_i$，至少有 $d_i$ 次操作的左端点等于 $i$。不同的 $i$ 对应的操作互不重合（一次操作只有一个左端点），于是

$$
T\ge\sum_{i:\ d_i>0}d_i=\sum_{i=1}^{n}\max(0,d_i).
$$

这里 $i$ 到 $n$ 即可，因为 $d_{n+1}\le 0$（$h_{n+1}=0\le h_n$）。$\square$

### 2.3 构造达到下界的方案

**引理 2（上界）**：存在恰好 $\sum_{i=1}^{n}\max(0,d_i)$ 次操作的合法方案。

**证明**（构造 + 不变量）：从左到右处理位置 $1..n$，维护当前「正在进行中」的区间数 $c$，并维护这些区间的起点（它们会在某个位置结束）。

- 初始 $c=0$，$h_0=0$。
- 处理位置 $i$ 时，当前活跃区间数应满足 $c=h_{i-1}$（归纳假设）。
  - 若 $h_i>h_{i-1}$：新开 $h_i-h_{i-1}$ 个区间，起点都设为 $i$，$c$ 变为 $h_i$。
  - 若 $h_i<h_{i-1}$：结束 $h_{i-1}-h_i$ 个活跃区间，终点设为 $i-1$，$c$ 变为 $h_i$。
  - 若相等：不动。
- 处理完 $n$ 后，把剩余 $c=h_n$ 个区间全部在 $n$ 结束。

归纳不变量：处理完位置 $i$ 后，活跃区间数 $=h_i$，且这些区间覆盖位置 $i$ 恰好 $h_i$ 次。于是每个位置的覆盖次数等于目标高度。每次「新开」对应答案式中的一项 $\max(0,h_i-h_{i-1})$，总开区间数正是 $\sum\max(0,d_i)$；每个开出的区间最终都恰好关闭一次，所以总操作数等于该和。所有操作都是合法的连续区间。$\square$

由引理 1、2，最少操作次数就是

$$
\boxed{\ \sum_{i=1}^{n}\max(0,\ h_i-h_{i-1})\ },\qquad h_0=0.
$$

### 2.4 另一种理解：把「高度剖面」切成水平层

把目标高度画成柱状图。每个操作相当于在某一个水平层上选一段连续的单位格子填上。对于相邻两列，高度从 $h_{i-1}$ 涨到 $h_i$ 时，多出来的 $h_i-h_{i-1}$ 个格子必须由**新的区间**开始覆盖；而高度下降时，上面的层自然结束，不需要新操作。所以「所有上升量之和」既是下界也可构造。

### 2.5 坑点

- `h_0` 要当成 $0$，所以第一项是 $h_1$，不要漏。
- 高度可以相等，差为 $0$，不贡献答案。
- 高度可以为 $0$，不影响公式。
- 答案约 $10^9$，`int` 边缘，用 `long long`。

---

## 3. 模式总结（Pattern Summary）

- **explore its property** — 区间 $+1$ 在差分数组上表现为「左端点 $+1$、右端点后一位 $-1$」。
- **lower bound** — 每个正差分至少需要一个以该位置为左端点的操作。
- **constructive matching** — 按高度上升量开区间、下降量关区间，恰好达到下界。
- **reduce to formula** — 答案 $=\sum\max(0,h_i-h_{i-1})$，$O(n)$ 扫描。

---

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 积木宽度 | 读入 | 规模 |
| `h` | `int` | 当前读入的高度 | 逐项读入 | height |
| `prv` | `int` | 前一个位置的高度 $h_{i-1}$ | $0$ | previous |
| `ans` | `i64` | 最少操作次数 | $0$ | answer |

### 4.2 算法步骤

1. `prv=0`，`ans=0`。
2. 对 $i=1..n$：读入 `h`；若 `h>prv`，`ans+=h-prv`；然后 `prv=h`。
3. 输出 `ans`。

### 4.3 复杂度分析

- **时间**：$O(n)$。
- **空间**：$O(1)$（边读边算）。

---

## 5. 示例代码

```cpp
//
// 题目：P1969 [NOIP 2013 提高组] 积木大赛
// https://www.luogu.com.cn/problem/P1969
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	int prv{0};
	i64 ans{0};
	for(int i=0,h;i<n;++i)
	{
		cin>>h;
		if(h>prv)
			ans+=h-prv;
		prv=h;
	}
	cout<<ans<<'\n';
	return 0;
}
```
