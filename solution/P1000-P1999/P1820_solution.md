# P1820 麻将 加强加强版

## 1. 重新读题

### 1.1 人话版

有 $n$ 种数牌，编号 $1,2,\dots,n$，每种牌都有**无穷多张**。小 A 手上有 $k$ 张牌（可以重复）。

和牌的定义：手牌能恰好分成「若干组面子」$+$「恰好一组雀头」：

- **雀头**：两张相同的牌；
- **刻子**：三张相同的牌；
- **顺子**：三张序数连续的牌 $i,i+1,i+2$（$1$ 与 $n$ 不算相邻）；
- 刻子和顺子统称**面子**。

现在问：往手牌里**再加一张** $t$（$t\in[1,n]$）后可以「和牌」的那些 $t$ 有哪些。升序输出；一张都不听则输出 `QAQ`。

### 1.2 关键约束与规模暗示

- $1\le a_i\le n\le k\le 2\times10^5$。
- 捆绑子任务：$k\le16$（可指数搜索）、$k\le400$、$k\le10^3$、$k\le3\times10^4$、$k\le2\times10^5$。这是典型的"先想指数/平方，再优化到线性"的梯度。
- $n\le 2\times10^5$，而需要检查的候选牌有 $n$ 种。如果每种候选都做一次 $O(n)$ 的判定，总复杂度 $O(n^2)=4\times10^{10}$，必超时。正解必须做到**每个候选 $O(1)$ 判定**。

---

## 2. 思维链（Chain-of-thought）

### 2.1 explore its property：把"和牌"翻译成计数方程

只有一种数牌，顺子只可能是 $i,i+1,i+2$。设：

- $c_i$：手牌中第 $i$ 种牌的张数；
- $s_i$：以 $i$ 为起点的**顺子**个数（$s_i=0$ 当 $i$ 不在合理范围）；
- $t_i$：第 $i$ 种牌的**刻子**个数。

那么"每种牌恰好用完"给出
$$
c_i=s_{i-2}+s_{i-1}+s_i+3t_i\qquad(\text{越界下标视为 }0).
$$

**引理 1（方程即和牌）**
存在非负整数 $s_i,t_i$ 满足上式，当且仅当这副手牌能分成若干组面子。

**证明**：

- **必要性**：任给一种面子划分，按定义统计每个位置作为"顺子起点"的次数 $s_i$、作为"刻子"的次数 $t_i$，第 $i$ 种牌只可能被"起点为 $i-2,i-1,i$ 的顺子各用一次"以及"$t_i$ 个刻子各用三次"，于是方程成立。
- **充分性**：给定满足方程的非负整数解，取 $t_i$ 个刻子 $(i,i,i)$ 与 $s_i$ 个顺子 $(i,i+1,i+2)$ 构成面子的多重集。第 $i$ 种牌被面子总共使用的次数恰为 $s_{i-2}+s_{i-1}+s_i+3t_i=c_i$，与手牌完全一致，所以是一种合法划分。$\blacksquare$

雀头的处理：选中某个位置 $p$ 后，先在 $c_p$ 里**扣掉 2 张**，再对剩下的牌做上面的面子分解。

### 2.2 consider subtask：为什么不能对每个 $t$ 做 DP

有了方程 2.1，一个自然的判定是"从左到右确定 $s_i$"。但若每个候选 $t$ 都重新扫一遍 $O(n)$，总复杂度 $O(n^2)$。$k\le400$ 时 $O(n^2)$ 还能过，$k\le2\times10^5$ 就死了。要利用"**加一张牌只改变一个位置的 $c_t$**"这个事实。

### 2.3 explore its property：顺子个数可以压到 $0,1,2$

**引理 2（$s_i\le 2$ 的规范化）**
若某组解中 $s_i\ge 3$，可以把其中 $3$ 个"从 $i$ 开始的顺子"换成"$i$ 处一个刻子 $+$ $i+1$ 处一个刻子 $+$ $i+2$ 处一个刻子"。这两种做法消耗的牌完全一样：
$$
3\times\{i,i+1,i+2\}=\{i,i,i\}\cup\{i+1,i+1,i+1\}\cup\{i+2,i+2,i+2\}.
$$
所以仍然合法，而 $s_i$ 减少了 $3$。反复操作，就能让所有 $s_i\in\{0,1,2\}$，且雀头位置不变。

**证明**：每次替换只是把 9 张牌重新分组成 3 个刻子，逐位置的用牌数不变，因此方程依然成立、划分依然合法；$s_i$ 每次减 $3$ 且保持非负，必在有限步后落到 $\{0,1,2\}$。$\blacksquare$

于是**只考虑每个 $s_i\in\{0,1,2\}$** 就足够。

### 2.4 转移是唯一的

从左往右处理位置 $i$。假设已经确定了 $s_{i-2}=a,\ s_{i-1}=b$（由引理 2，$a,b\in\{0,1,2\}$），并且已经决定雀头是否用过（`used`）。设本位置可用于面子的张数为 $q$（等于 $c_i$，若雀头放在这里则等于 $c_i-2$），则
$$
q=a+b+s_i+3t_i,\qquad s_i,t_i\ge0.
$$

**引理 3（余数唯一确定转移）**
在 $s_i\in\{0,1,2\}$ 的限制下，$s_i$ 只能是
$$
s_i=(q-a-b)\bmod 3,
$$
并且可行当且仅当 $q-a-b\ge s_i$（此时 $t_i=(q-a-b-s_i)/3$）。

**证明**：由方程，$s_i\equiv q-a-b\pmod 3$，且 $s_i\ge0$。在 $\{0,1,2\}$ 中同余类恰好只有一个代表，就是 $(q-a-b)\bmod 3$。剩余的张数 $q-a-b-s_i$ 必须是非负且被 $3$ 整除的，由同余它自动被 $3$ 整除，只需 $q-a-b-s_i\ge0$，即 $s_i\le q-a-b$。$\blacksquare$

所以对每个进入状态，最多只有两个出口（雀头放/不放），且 $s_i$ 是算出来的、不用枚举。

### 2.5 雀头用 `used` 标记

在某个位置 $i$ 放雀头，就是把可用张数从 $c_i$ 改成 $c_i-2$（要求 $c_i\ge2$），并把 `used` 置 $1$；之后只能走"不放雀头"的分支。最后要求 `used=1`（恰好一组雀头）。

### 2.6 边界：补两个空位置挡住越界顺子

以 $0$ 基编号，牌为 $0,1,\dots,n-1$。若允许 $s_{n-1}>0$，顺子 $n-1,n,n+1$ 就越界了。处理办法：在末尾追加两个"张数为 $0$"的位置 $n$ 和 $n+1$，并把它们也纳入 DP。

**引理 4（边界自动清零）**
令 $c_n=c_{n+1}=0$ 并继续转移，则最终进入状态 $(s_n,s_{n+1})$ 必须为 $(0,0)$；而这一要求自动强制所有越界顺子为 $0$。

**证明**：在位置 $n$，$c_n=0$，而方程是 $0=c_n=s_{n-2}+s_{n-1}+s_n+3t_n$。右边全是非负数且 $t_n\ge0$，故 $s_{n-2}=s_{n-1}=s_n=0$（即所有起点 $\ge n-2$ 的顺子都被清零）。同理位置 $n+1$ 给出 $s_{n-1}=s_n=s_{n+1}=0$。于是最终状态必为 $(0,0)$，反过来 $(0,0)$ 也确实不会产生越界顺子。$\blacksquare$

### 2.7 核心优化：前缀可达性 $\times$ 后缀可行性

**观察**：转移在位置 $i$ 只依赖 `c[i]` 和进入状态；与其它位置无关。

**引理 5（加一张牌只影响一个转移）**
把 $c_t$ 改成 $c_t+1$ 后：

- 位置 $0..t-1$ 的所有转移**逐字不变**，因此从初始状态 $(0,0,\text{unused})$ 出发，到达"处理 $t$ 之前"的可达状态集合 `rea[t]` 不变；
- 位置 $t+1..n+1$ 的所有转移也不变，因此"从某个进入状态能否走完"的判定 `suf[t+1]` 不变；
- 唯一需要重新计算的，是位置 $t$ 上、用新张数 $c_t+1$ 的那一次转移。

**证明**：由 2.4，位置 $i$ 的转移是函数 $\text{下一步}=\mathrm{step}(c_i,\ \text{进入状态})$，与其它 $c_j$ 无关。前缀可达性是对 $i=0..t-1$ 反复作用 $\mathrm{step}(c_i,\cdot)$ 得到的，后缀可行性是对 $i=n+1..t+1$ 反复作用得到的；这些 $c_i$ 都没变，故不变。$\blacksquare$

于是：

1. 正着做一遍，得到 `rea[i][a][b][f]`：处理位置 $i$ 之前，状态 $(s_{i-2},s_{i-1},f)$ 是否可达；
2. 倒着做一遍，得到 `suf[i][a][b][f]`：从位置 $i$ 开始、进入状态为 $(s_{i-2},s_{i-1},f)$ 时，能否一路走到 $(0,0,\text{used})$；
3. 对每个候选 $t$：枚举 `rea[t]` 里为真的进入状态，用 $c_t+1$ 走一次 `step`，看出口状态是否满足 `suf[t+1]`。任一成立则 $t$ 是听牌。

状态只有 $3\times3\times2=18$ 种，所以每张候选牌 $O(18\times2)=O(1)$。

**引理 6（判定充要）**
加上 $t$ 后能和牌 $\iff$ 存在 `rea[t]` 中的进入状态，经位置 $t$（张数 $c_t+1$）转移后得到出口状态 $v$，且 `suf[t+1][v]=true`。

**证明**：和牌 $\iff$ 存在一组满足引理 1 的 $(s_i,t_i)$ 与一个雀头位置 $\iff$ 存在一条从初始状态到最终 $(0,0,\text{used})$ 的合法状态路径（引理 2、3 保证路径与解一一对应：给定路径能反推每步的 $s_i$ 和 $t_i$，反之给定解能按 2.4 走出路径）$\iff$ 路径在位置 $t$ 处断开，前段属于 `rea[t]`、后段属于 `suf[t+1]`。$\blacksquare$

### 2.8 一个快速筛掉的情况

一张牌共 $k+1$ 张，必须是 $3M+2$ 张才有资格和牌。若 $k+1\not\equiv 2\pmod 3$（即 $k\not\equiv1\pmod3$），必然 QAQ。DP 自身也会给出空答案，但先判一下更省事，也便于理解。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 用 $c_i=s_{i-2}+s_{i-1}+s_i+3t_i$ 把"和牌"变成整数方程。
- **consider subtask / failed attempt** — 每个候选做一遍 $O(n)$ DP，$O(n^2)$ 过不了满数据。
- **explore its property** — 3 个顺子换 3 个刻子，把 $s_i$ 压到 $\{0,1,2\}$。
- **explore its property** — 余数唯一确定 $s_i$，转移确定；雀头用一个 `used` 标记。
- **explore its property** — 末尾补两个 $0$ 张位置自动禁止越界顺子。
- **classic problem solution** — 前缀可达集 + 后缀可行性拼装，每个候选 $O(1)$。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n,k` | `int` | 牌的种类数、手牌张数 | 输入 | 维度 |
| `c[i]` | `int [mxn]` | 第 $i$ 种牌的张数（$0$ 基，$i=0..n-1$；$i\ge n$ 视为 $0$） | 读入时 `--x; ++c[x]` | count |
| `s` 下标 | 概念量 | $s_i=$ 以 $i$ 为起点的顺子数，恒在 $\{0,1,2\}$（引理 2） | 由转移确定 | run start |
| `rea[i][a][b][f]` | `char [mxn][3][3][2]` | 处理位置 $i$ **之前**，$s_{i-2}=a,\ s_{i-1}=b$、雀头是否已用 $=f$ 是否可达 | `rea[0][0][0][0]=1` | reachable |
| `suf[i][a][b][f]` | `char [mxn][3][3][2]` | 从位置 $i$ 开始、进入状态 $(a,b,f)$ 能否走到合法终点 $(0,0,1)$ | `suf[n+2][0][0][1]=1` | suffix feasible |
| `trans(...)` | 辅助函数 | 给定张数 `cc` 与进入状态，产出最多 2 个出口状态 | — | transition |

### 4.2 算法步骤

1. 读入 $n,k$ 与 $k$ 张牌，转成 $0$ 基并累加 `c[x]`。
2. **正向**：`rea[0][0][0][0]=1`。对 $i=0,1,\dots,n+1$：
   - 令 `cc = (i<n ? c[i] : 0)`；
   - 对每个 `rea[i][a][b][f]=1` 的状态，调用 `trans(cc,a,b,f)` 得到出口 $(b,s_i,f')$，置 `rea[i+1][b][s_i][f']=1`。
3. **逆向**：`suf[n+2][0][0][1]=1`。对 $i=n+1,\dots,0$：
   - `cc = (i<n ? c[i] : 0)`；
   - 对每个 $(a,b,f)$，若 `trans(cc,a,b,f)` 有出口 $v$ 使 `suf[i+1][v]=1`，则 `suf[i][a][b][f]=1`。
   （逆向用**原始** `c`，因为后缀部分不受候选牌影响。）
4. **逐候选**：对 $t=0..n-1$，令 `cc=c[t]+1`。枚举所有 `rea[t][a][b][f]=1`，对其出口 $v$ 检查 `suf[t+1][v]`；只要有一次成立，就把 $t+1$ 加入答案（循环 $t$ 升序，故答案天然升序）。
5. 答案为空输出 `QAQ`，否则按空格分隔输出。

`trans(cc,a,b,used)` 的内部逻辑（引理 3）：

- 若 `used=1`：只能不放雀头，`r=cc-a-b`，若 $r\ge0$ 且 $s=r\bmod3\le r$，产出 $(b,s,1)$；
- 若 `used=0`：除上面的"不放雀头"出口 $(b,s,0)$ 外，还尝试"此处放雀头"：`r=cc-2-a-b`，若 $r\ge0$ 且 $s=r\bmod3\le r$，产出 $(b,s,1)$。

### 4.3 复杂度分析

- **时间复杂度**：正/逆向各扫 $n+2$ 个位置、每位置 $18$ 个状态、每状态至多 $2$ 条边，$O(n)$；逐候选 $n\times18\times2$，$O(n)$。总计 $O(n)$，常数约 $100$。
- **空间复杂度**：两个 `char` 数组各约 $18(n+2)$ 字节，$O(n)$，$n=2\times10^5$ 时约 $7\text{ MB}$。

## 5. 示例代码

```cpp
//
// 题目：P1820 麻将 加强加强版
// https://www.luogu.com.cn/problem/P1820
// 与小范围指数的分解搜索对拍通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{200005};

int n,k;
int c[mxn];
char rea[mxn][3][3][2];      // 处理位置 i 之前的可达状态
char suf[mxn][3][3][2];      // 从位置 i 开始能否走完

// 给定可用张数 cc 与进入状态 (a,b,used)，枚举出口状态
inline void trans(int cc,int a,int b,int used,int out[][3],int&cnt)
{
	cnt=0;
	if(used)
	{
		int r=cc-a-b;
		if(r>=0)
		{
			int s=r%3;
			if(s<=r)
			{
				out[cnt][0]=b;out[cnt][1]=s;out[cnt][2]=1;++cnt;
			}
		}
	}
	else
	{
		int r=cc-a-b;             // 不在本位放雀头
		if(r>=0)
		{
			int s=r%3;
			if(s<=r)
			{
				out[cnt][0]=b;out[cnt][1]=s;out[cnt][2]=0;++cnt;
			}
		}
		r=cc-2-a-b;               // 在本位放雀头
		if(r>=0)
		{
			int s=r%3;
			if(s<=r)
			{
				out[cnt][0]=b;out[cnt][1]=s;out[cnt][2]=1;++cnt;
			}
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k;
	for(int i=0;i<k;++i)
	{
		int x;
		cin>>x;--x;
		++c[x];
	}
	int out[4][3],cnt;
	rea[0][0][0][0]=1;
	for(int i=0;i<=n+1;++i)
	{
		int cc=(i<n?c[i]:0);
		for(int a=0;a<3;++a)
			for(int b=0;b<3;++b)
				for(int f=0;f<2;++f)
					if(rea[i][a][b][f])
					{
						trans(cc,a,b,f,out,cnt);
						for(int z=0;z<cnt;++z)
							rea[i+1][out[z][0]][out[z][1]][out[z][2]]=1;
					}
	}
	suf[n+2][0][0][1]=1;
	for(int i=n+1;i>=0;--i)
	{
		int cc=(i<n?c[i]:0);
		for(int a=0;a<3;++a)
			for(int b=0;b<3;++b)
				for(int f=0;f<2;++f)
				{
					trans(cc,a,b,f,out,cnt);
					for(int z=0;z<cnt;++z)
						if(suf[i+1][out[z][0]][out[z][1]][out[z][2]])
							suf[i][a][b][f]=1;
				}
	}
	vector<int>ans;
	for(int t=0;t<n;++t)
	{
		int cc=c[t]+1;                 // 只改这一个位置
		bool ok=false;
		for(int a=0;a<3&&!ok;++a)
			for(int b=0;b<3&&!ok;++b)
				for(int f=0;f<2&&!ok;++f)
					if(rea[t][a][b][f])
					{
						trans(cc,a,b,f,out,cnt);
						for(int z=0;z<cnt;++z)
							if(suf[t+1][out[z][0]][out[z][1]][out[z][2]])
							{
								ok=true;
								break;
							}
					}
		if(ok)
			ans.push_back(t+1);
	}
	if(ans.empty())
		cout<<"QAQ"<<'\n';
	else
	{
		for(size_t i=0;i<ans.size();++i)
			cout<<ans[i]<<(i+1==ans.size()?'\n':' ');
	}
	return 0;
}
```
