# P1558 色板游戏

> 标签：线段树 · 颜色段均摊（珂朵莉树 ODT）· 位运算 · 难度：提高/省选-
> 本地题面：`P1558.md`（$L\le 10^5$，$T\le 30$，$O\le 10^5$）。
> 验证：$400$ 组随机用例 + $5$ 组手工用例，标程与暴力逐字节一致；最坏 $L=10^5,T=30,O=10^5$ 耗时 $0.0537$ s。

## 1. 重新读题

**问题重述（人话版）**

一块长度 $L$ 的色板，分成 $L$ 个格子，编号 $1,\dots,L$，一开始整块都是 $1$ 号色。颜料共 $T$ 种（编号 $1,\dots,T$）。两种操作：

- `C A B C`：把 $A$ 号到 $B$ 号格子（含两端）**全部**涂成颜色 $C$（区间赋值）；
- `P A B`：询问 $A$ 号到 $B$ 号格子里**出现过的不同颜色种数**（区间数颜色种类）。

$A,B$ 不保证 $A\le B$，需自行交换。

**题面里容易漏掉的条款**

1. 「可能 $A>B$，需要你交换」$\Rightarrow$ 读入后先 `if(A>B) swap(A,B)`，否则区间为空或反着取会错。
2. 「一共有 $T$ 种颜料」且 $T\le 30$ $\Rightarrow$ **颜色种数极少**，这是本题能"位运算压位"的关键信号。
3. 「$C$ 操作是涂满整个区间」$\Rightarrow$ 是**区间覆盖**（赋值），不是"只涂某几格"，天然适合懒标记。
4. 「输出一个整数」$\Rightarrow$ 每个查询一行，不是每块一行。

**数据范围与规模感受**

$$L\le 10^5,\qquad T\le 30,\qquad O\le 10^5.$$

每次操作若暴力扫区间，最坏 $O(L)$，总 $O(O\cdot L)=10^{10}$，会在 $1.00$ s 里超时。因此**必须用能 $O(\log L)$ 处理区间赋值与区间查询的结构**——线段树。而 $T\le 30$ 恰好塞进一个 32 位整数，于是"数颜色种类"可以被压成"按位或 + 数 $1$"。

## 2. 思维链（Chain-of-thought）

### 2.1 explore its property：两个操作各是什么类型

- `C A B C` 是**区间赋值**：把 $[A,B]$ 内的颜色全部改成同一个值。它的显著特征是"一改就是整段统一"，非常适合懒标记（标记一段统一颜色，等到需要细分时再下传）。
- `P A B` 是**区间统计**：统计 $[A,B]$ 内出现的不同颜色种类。注意它不是求和、不是求最值，而是"种类数"——这决定了它不能简单地把子区间答案相加。

**引理 1（区间查询的"合并"不是加法）**

若把 $[A,B]$ 拆成两个不交子区间 $[A,M]$ 与 $[M+1,B]$，则整体颜色种类数 = 左右两段并集后的种类数，**而不是**左右种类数之和。

**证明**：设左段出现的颜色集合为 $S_1$，右段为 $S_2$。整体颜色集合 $S=S_1\cup S_2$，故 $|S|=|S_1\cup S_2|$。当 $S_1\cap S_2\ne\varnothing$ 时 $|S_1\cup S_2|<|S_1|+|S_2|$，直接相加会把两段都出现的颜色重复计数。故合并规则必须是"并集"。$\blacksquare$

> 这条引理否定了"线段树维护一个整数 cnt 然后子树求和"的天真做法，逼我们要为每个节点保存"该节点区间里出现过哪些颜色"这个**集合**（而不是它的基数）。

### 2.2 consider easier version：先看 $T$ 很小的情形

如果 $T$ 极小（比如 $T=1$），答案恒为 $1$；$T=2$ 时也只需知道"两种色是否都出现过"。这提示：只要能用极少量的状态表示"哪些颜色出现过"，问题就简单了。

**引理 2（位掩码表示颜色集合，且 $T\le30$ 装得下）**

用一个整数的第 $c$ 位（$0$ 起）表示"颜色 $c+1$ 是否出现过"，则该整数完整刻画了颜色集合；两个区间的颜色集合的并 = 两掩码按位或；颜色种类数 = 掩码中 $1$ 的个数（popcount）。又 $T\le30<32$，一个 32 位 `int` 足够。

**证明**：位掩码与集合的标准一一对应——位置 $c$ 为 $1$ $\iff$ 集合含元素 $c$。集合并对应按位或（两掩码任一位为 $1$ 即并集含该颜色）。种类数即集合大小即 $1$ 的个数。位数上界：需 $T\le30$ 位，占第 $0..29$ 位，最高位权 $2^{29}<2^{31}$，故普通 `int` 不溢出（且非负）。$\blacksquare$
（清注意：正是因为 $T\le30$ 才敢用 `int`；若 $T$ 可达 $64$ 就要换 `unsigned long long`。）

### 2.3 classic problem solution：带懒标记的线段树

由引理 1、2，节点只需存一个掩码 `seg[i]`（它覆盖区间内出现过的颜色集合）；由"区间赋值"的性质，节点再存一个懒标记 `tag[i]` = "整段被统一涂成的颜色"（`-1` 表示没有统一覆盖）。

**引理 3（懒标记下传的正确性）**

若节点 `i` 的 `tag[i]` 记录着"它的整段被统一涂成某颜色"，则把 `seg/…` 直接替换为该颜色的单点掩码、并把该标记传给两个子节点后，整棵子树的状态与"真的逐格涂色"完全一致。

**证明**：`tag[i]` 非空 $\iff$ 自上次下传后，整个 $[l,r)$ 被某次 `C` 操作覆盖成了同一颜色 $t$（因为任何更早的、再往里的修改都会被这次覆盖抹掉）。于是该段任意位置都是颜色 $t$，故该段的颜色集合就是单元素集 $\{t\}$，掩码为 `1<<t`；对子节点而言，它们同样"整段都是 $t$"，继承标记 `tag=t` 正确。如此递归下传，（若后续要对子段做不完备覆盖）子段的回答与真实逐格状态相同。$\blacksquare$

**引理 4（区间赋值/查询的分解正确性）**

线段树按半开区间 $[l,r)$ 递归分解查询/修改区间 $[L,R)$：完全被包含的节点直接作答（`seg` 或置色+打标记）；完全不相交的节点返回单位元（查询返回 $0$、修改直接返回）；部分相交则 `push_down` 后递归两侧，再用"或"合并。递归结束后根到叶的每个位置恰好被处理一次。

**证明**：标准线段树区间分解保证：查询/修改区间被不相交的树节点完整划分（每个被覆盖的叶子恰属于其中一个被选中节点）。被完全包含的节点一律用整段信息作答（引理 2、3 已证整段信息正确），故结果等于逐格/逐段处理的并集结果。$\blacksquare$

### 2.4 reduce to easier problem：把"数颜色种类"归约为"OR 再 popcount"

合并上式（引理 1、2）直接给出：**查询返回值 = 被选中节点掩码的按位或；答案 = 该或值的 popcount**。于是"区间数颜色"这个乍看棘手的问题，归约成了"区间按位或 + 一次 `__builtin_popcount`"。

### 2.5 discuss by category：边界处理

- 下标：题目 $1$ 起，内部统一 $0$ 起；区间 $[A,B]$ 映射到半开 $[A-1,B)$（即 `--a; --b;` 后用 `[a, b+1)`）。
- `A>B`：先交换。
- $L$ 可能为 $1$：线段树根节点区间 $[0,1)$，叶子；$[l,r)$ 的叶子判据是 `r-l==1`，不会死循环。
- 初值全部颜色 $1$：建树时每个节点掩码置 `1`（第 $0$ 位），`tag=-1`。
- 懒标记：全局 `int` 数组默认为 $0$，会与"颜色 $0$（即 $1$ 号色）"混淆，故 **`tag` 的"无标记"必须用 `-1` 显式表示**（建树时置 `-1`）。

## 3. 模式总结（Pattern Summary）

- explore its property — 识别两操作本质：`C` 是区间赋值、`P` 是区间"种类计数"，且种类计数**不能简单相加**（引理 1）。
- consider easier version — 把"种类"这种看似非数值的量，抽象成"颜色集合"，先想清楚 $T$ 很小时的想法。
- classic problem solution — 用带懒标记的线段树支撑区间赋值 + 区间查询（`tag` 记录整段统一色）。
- reduce to easier problem — 集合 → 位掩码（$T\le30$ 挤进 `int`），"种类数" $\to$ 区间按位或 $\to$ popcount；合并规则由"加法"改成"并"。
- discuss by category — 下标 0 起、`A>B` 交换、`tag` 无标记用 `-1`（避免与颜色 $0$ 撞车）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `L,T,O` | `int` | 板长 / 颜色数 / 操作数 | 读入 | — |
| `seg[i]` | `int[4*mxn]` | 节点 $i$ 覆盖区间内出现过的颜色掩码（颜色 $c$ 占第 $c$ 位，$0$ 起） | 建树时 `1` | Seg |
| `tag[i]` | `int[4*mxn]` | 懒标记：整段被统一涂的颜色（$0$ 起），**`-1` 表示无** | 建树时 `-1` | Tag |
| `ls(i)`/`rs(i)` | 函数 | 左/右子节点下标 `2i+1`/`2i+2` | — | — |
| `build` | 函数 | 建树，半开区间 $[l,r)$，根下标 $0$ | — | — |
| `push_down` | 函数 | 把 `tag[i]` 下传（引理 3） | — | — |
| `upd` | 函数 | 区间赋值（引理 4） | — | — |
| `qry` | 函数 | 区间掩码 OR（引理 1、2、4） | — | — |

### 4.2 编号步骤

1. `cin>>L>>T>>O`；`build(0,L,0)`（每个节点 `seg=1`、`tag=-1`）。
2. 对每个操作：
   - 读字符 `ch`；
   - 若 `ch=='C'`：读 `a,b,c`，`--a,--b,--c`，若 `a>b` 交换，调用 `upd(a,b+1,c,0,L,0)`；
   - 否则：读 `a,b`，`--a,--b`，若 `a>b` 交换，输出 `__builtin_popcount((unsigned)qry(a,b+1,0,L,0))`。
3. 查询输出每行一个整数。

### 4.3 复杂度

- 时间：每次操作 $O(\log L)$，总 $O(O\log L)$；实测最坏规模 $0.0537$ s。
- 空间：两个 `int[4\cdot100005]`，约 $3.2$ MB。

### 4.4 关键不变量

1. `seg[i]` 的第 $c$ 位为 $1$ $\iff$ 节点 $i$ 的区间内出现颜色 $c+1$。
2. `tag[i]>=0` $\Rightarrow$ 该段整段同色 `tag[i]`，且 `seg[i] == 1<<tag[i]`。
3. 查询返回值 = 目标区间颜色集合的掩码，popcount 即答案。

### 4.5 验证状态小结

| 随机对拍 | **通过**：$400$ 组随机（$L\le20,T\le5,O\le25$），标程与暴力（数组模拟）逐字节一致 |
| 手工边界 | **通过**：$L=1$ 查询 `1`；单次整段涂色后种类 `1`；两段涂两色后种类 `2`；`C 4 1 2`（$A>B$）交换后正确 |

## 5. 示例代码

### 5.1 主解：线段树 + 位掩码（与 `appendix/P1558/P1558.cpp` 逐字节一致）

```cpp
//
// 题目：P1558 色板游戏
// https://www.luogu.com.cn/problem/P1558
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};        // L,O <= 1e5 (+5 松弛)

int L,T,O;
int seg[mxn*4];                   // 每段"出现过的颜色集合"的位掩码(0-based 颜色占第 c 位)
int tag[mxn*4];                   // 懒标记:整段统一涂的颜色(0-based),-1 表示无

int ls(int i){return i*2+1;}
int rs(int i){return i*2+2;}

void build(int l,int r,int i)
{
	seg[i]=1;                     // 初值整块都是 1 号色 => 第 0 位
	tag[i]=-1;
	if(r-l==1)
		return;
	int mid=(l+r)>>1;
	build(l,mid,ls(i));
	build(mid,r,rs(i));
}
void push_down(int i)
{
	if(tag[i]<0)
		return;
	int t=tag[i];
	seg[ls(i)]=seg[rs(i)]=1<<t;
	tag[ls(i)]=tag[rs(i)]=t;
	tag[i]=-1;
}
void upd(int Lq,int Rq,int c,int l,int r,int i)
{
	if(Rq<=l||r<=Lq)
		return;
	if(Lq<=l&&r<=Rq)              // [l,r) 被完全覆盖:整段改色
	{
		seg[i]=1<<c;
		tag[i]=c;
		return;
	}
	push_down(i);
	int mid=(l+r)>>1;
	upd(Lq,Rq,c,l,mid,ls(i));
	upd(Lq,Rq,c,mid,r,rs(i));
	seg[i]=seg[ls(i)]|seg[rs(i)];
}
int qry(int Lq,int Rq,int l,int r,int i)
{
	if(Rq<=l||r<=Lq)
		return 0;
	if(Lq<=l&&r<=Rq)
		return seg[i];
	push_down(i);
	int mid=(l+r)>>1;
	return qry(Lq,Rq,l,mid,ls(i))|qry(Lq,Rq,mid,r,rs(i));
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>L>>T>>O;
	build(0,L,0);
	for(int i=0,op,a,b,c;i<O;++i)
	{
		char ch;
		cin>>ch;
		if(ch=='C')
		{
			cin>>a>>b>>c;
			--a;--b;--c;
			if(a>b)
				swap(a,b);
			upd(a,b+1,c,0,L,0);
		}
		else
		{
			cin>>a>>b;
			--a;--b;
			if(a>b)
				swap(a,b);
			cout<<__builtin_popcount((unsigned)qry(a,b+1,0,L,0))<<'\n';
		}
	}
	return 0;
}
```

### 5.2 对照实现：数组暴力（仅用于小规模对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;

// 小数据朴素基准:直接维护颜色数组,区间暴力涂色 / 区间暴力数颜色
int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	int L,T,O;
	cin>>L>>T>>O;
	vector<int> col(L,1);          // 初始全为 1 号色
	for(int i=0;i<O;++i)
	{
		char ch;
		cin>>ch;
		int a,b,c;
		if(ch=='C')
		{
			cin>>a>>b>>c;
			--a;--b;
			if(a>b)
				swap(a,b);
			for(int j=a;j<=b;++j)
				col[j]=c;
		}
		else
		{
			cin>>a>>b;
			--a;--b;
			if(a>b)
				swap(a,b);
			bool has[35]={};
			int cnt=0;
			for(int j=a;j<=b;++j)
				if(!has[col[j]])
				{
					has[col[j]]=1;
					++cnt;
				}
			cout<<cnt<<'\n';
		}
	}
	return 0;
}
```

### 5.3 易错点清单

- **合并用加法而非并集**：`seg[i]=seg[ls]+seg[rs]` 是错的，必须用 `|`（引理 1）。
- **`tag` 无标记用 $0$**：全局默认 $0$ 会与颜色 $0$（1 号色）冲突，本实现用 `-1` 表示无标记，建树时显式置 `-1`。
- **`push_down` 后未清标记**：下传后必须 `tag[i]=-1`，否则会重复下传、覆盖子节点的后续修改。
- **忘记 `A>B` 交换**、或区间映射时漏掉 `b+1`（半开区间右端）。
- **`T` 超过 $30$**：若题目放宽到 $>30$，`int` 掩码会溢出，需换更宽的整数类型。
