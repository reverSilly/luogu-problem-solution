# P1591 阶乘数码

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给定 $n$ 和数码 $a$（$0\le a\le 9$），求 $n!$ 的十进制表示中数字 $a$ 出现的次数。$n\le1000$，多组数据。

$1000!$ 约有 $2568$ 位十进制数字，远超 `long long`（约 $19$ 位），所以必须自己实现大整数。

### 输入输出格式

- **输入格式**：第一行 $t$（$t\le10$）；随后 $t$ 行每行 $n$ 与 $a$。
- **输出格式**：每组输出一行，$a$ 在 $n!$ 中出现的次数。
- **数据规模**：$t\le10$，$n\le1000$，$0\le a\le9$。

### 关键约束分析

1. 结果位数 $\approx2568$，必须高精度；用 `int` 存阶乘会立刻溢出。
2. 单次乘法中"某一位 $\times i+$ 进位"的最大值约为 $9\times1000+1000$，仍在 `int` 内，因此**不需要** `long long` 数组，但要确保进位变量足够宽。
3. 多组数据：高精度数组 `d` 与长度 `len` 必须在每组开头重新初始化为 $1$，否则上一组的阶乘会污染下一组。
4. 边界：$n=1$ 时 $n!=1$；$a=0$ 时要统计数字 $0$ 的总出现次数（不只是末尾连续的 $0$）：$1000!$ 中数字 $0$ 共出现 $472$ 次，而末尾连续 $0$ 只有 $249$ 个。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：为什么不能直接用内置类型

$20! \approx 2.43\times10^{18}$ 已经是 `unsigned long long` 的极限，而 $1000!$ 有 $2568$ 位。于是只能"自己存十进制位"，也就是把大整数拆成一个数组。

### 第二步：怎样把"乘以 $i$"做得便宜

如果实现通用的高精度乘法（$O(\text{位数}^2)$ 每位相乘），$n$ 次乘法总代价 $O(n\cdot L^2)$，虽然本题也能过，但没必要。注意到每次只是**乘以一个不超过 $1000$ 的小整数**，可以逐位乘、逐位进位，$O(L)$ 完成一次。

**引理 1（逐位乘法不丢位）**：设当前大整数以十进制、低位在前的数组 $d_0..d_{L-1}$ 表示，$1\le x\le1000$。从低位到高位执行 $v=d_k\cdot x+\text{carry}$，写回 $d_k=v\bmod 10$、$\text{carry}=\lfloor v/10\rfloor$，最后把剩余 `carry` 继续拆位追加，得到的结果恰为原数乘 $x$。

*证明*：设原数为 $N=\sum d_k10^k$。执行到第 $k$ 位后，低 $k$ 位已经等于 $Nx$ 的低 $k$ 位（模 $10^k$ 意义下相同），且 `carry` 等于 $\lfloor Nx/10^{k+1}\rfloor$ 中尚未写入的部分。这是标准竖式乘法的归纳：初始 `carry=0` 时，$d_0x=v_0$，写回 $v_0\bmod10$ 正是 $Nx$ 的个位，`carry` 是十位以上部分；第 $k$ 步同理。处理完所有位后，`carry` 中剩余的正是 $Nx$ 的高位，逐位 `%10` 追加即可。$\square$

**引理 2（数值不溢出）**：上述过程中 $v\le 9\times1000+1000=10000$，`int` 足够。

*证明*：$d_k\le9$，$x\le1000$，而进位满足 $\text{carry}\le\lfloor(9\cdot1000+999)/10\rfloor=999<1000$（对 $x\le1000$ 归纳：每一步 `carry` 不超过 $\lfloor(9x+999)/10\rfloor\le999$）。故 $v\le9000+999<10000$。$\square$

### 第三步：数组要开多大

**引理 3（位数上界）**：$1000!$ 的位数不超过 $2570$。

*证明*：位数 $=\lfloor\log_{10}(n!)\rfloor+1\le\log_{10}(n!)+1$。由 $\log_{10}$ 单调递增，

$$\log_{10}(n!)=\sum_{k=2}^{n}\log_{10}k\le\int_{1}^{n}\log_{10}x\,\mathrm{d}x+\log_{10}n=\frac{n\ln n-n+1}{\ln10}+\log_{10}n.$$

取 $n=1000$：$\frac{1000\times6.907755-999}{2.302585}+3\approx2569.2$，故位数 $\le2570$。$\square$

于是把数组开到 $3000$（约束上界再加松弛）即可安全容纳所有 $n\le1000$ 的阶乘。

### 第四步：统计

阶乘算完后，数组里存的就是完整的十进制表示（无前导零，因为 $n!\ge1$），直接线性扫描统计等于 $a$ 的位即可。不需要转成字符串。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 结果有 $2568$ 位，内置类型必然溢出，锁定"数组存十进制位"的高精度。
- `explore its property` — 乘数只是 $n\le1000$ 的小整数，可退化成一趟 $O(L)$ 的竖式乘法，不必写通用高精度乘法。
- `prove bound first` — 先用积分估计位数上界（$2570$），再决定数组尺寸，避免越界。
- `classic problem solution` — 低位在前 + 进位变量，逐位乘、最后拆剩余进位。
- `brute-force validation` — 用 Python 的 `math.factorial` 作为独立真值源对拍。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $t$ | `t` | 数据组数 |
| $n$ | `n` | 阶乘的自变量 |
| $a$ | `a` | 待统计的数码 |
| $d_k$ | `d[k]` | 大整数第 $k$ 位（$10^k$ 位），低位在前；每组开始时 `d[0]=1`、其余由 `len` 屏蔽 |
| $L$ | `len` | 当前有效位数 |
| $\text{carry}$ | `carry` | 竖式乘法进位，初值 $0$ |
| $\text{cnt}$ | `cnt` | 统计到的 $a$ 的个数 |

### 算法步骤

1. 读入 `t`。
2. 每组读入 `n,a`；置 `d[0]=1`、`len=1`（即 $1!$ 的表示）。
3. 对 $i=2,3,\dots,n$ 调用 `mul(i)`：逐位 `v=d[k]*i+carry`，写回 `d[k]=v%10`、`carry=v/10`；循环结束后 `while(carry)` 把剩余进位逐位追加，同时 `++len`。
4. 扫描 `d[0..len)`，统计 `d[k]==a` 的个数并输出。

### 复杂度分析

- **时间复杂度**：第 $i$ 次乘法 $O(\text{digits}(i!))$，总计 $O\!\left(\sum_{i\le n}\text{digits}(i!)\right)=O(n\cdot\text{digits}(n!))\approx2.6\times10^6$；$t\le10$ 时约 $2.6\times10^7$，实测远快于时限。
- **空间复杂度**：$O(\text{digits}(n!))$，即一个长度 $3000$ 的静态数组。

### 正确性验证

引理 1 保证每次 `mul` 得到正确的 $i!$，对 $i$ 归纳即得 `d[0..len)` 最终等于 $n!$；引理 2 保证中间量不溢出；引理 3 保证 `len` 不会越界（$1000!$ 仅 $2568$ 位，数组 $3000$）。最后线性扫描统计，与"$a$ 出现次数"定义一致。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1591 阶乘数码
// https://www.luogu.com.cn/problem/P1591
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{3000};        // 1000! 只有 2568 位

int d[mxn],len;

void mul(int x)
{
	int carry=0;
	for(int i=0;i<len;++i)
	{
		int v=d[i]*x+carry;
		d[i]=v%10;
		carry=v/10;
	}
	while(carry)
	{
		d[len++]=carry%10;      // 进位可能不止一位
		carry/=10;
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int t;
	cin>>t;
	while(t--)
	{
		int n,a;
		cin>>n>>a;
		d[0]=1;                 // 多测重新初始化
		len=1;
		for(int i=2;i<=n;++i)
			mul(i);
		int cnt=0;
		for(int i=0;i<len;++i)
			if(d[i]==a)
				++cnt;
		cout<<cnt<<'\n';
	}
	return 0;
}
```

### 易错点

1. **多测不清空**：`d` 与 `len` 是全局的，若不清零，第二组会把第一组的位数和数字混进来，答案偏大。
2. **把剩余进位只加一位**：`carry` 可能 $\ge10$（如 $999\times1000$），必须用 `while` 循环拆成多位。
3. **数组开小**：按 $1000$ 开数组必越界；要按位数上界（$2570$）再留松弛。
4. **$n=1$ 的特判**：循环 `for(i=2;i<=n)` 不执行，`d` 仍是 $\{1\}$，统计结果正确（$a=1$ 时为 $1$）。若在循环内做初始化反而会错。
5. **`a` 用字符读入**：输入是整数 $a$，不是字符，用 `int` 读，比较时与 `d[i]`（`int`）直接比。
