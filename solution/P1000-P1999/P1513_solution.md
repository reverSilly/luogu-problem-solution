# P1513 绕钉子的长绳子

> 标签：模拟 · 难度：普及-
> 本地题面：`P1513.md`（$1\le N\le100$，坐标绝对值 $\le100$，$R$ 为实数；精度到小数点后两位）。验证：官方样例 `14.28`；300 组随机凸多边形对拍全过；最坏 $N=100$ 约 $0.005$ s。

## 1. 重新读题

**问题重述（人话版）**

平面上有 $N$ 根半径都为 $R$ 的圆柱形钉子。它们的**中心按逆时针顺序**给出，且这些中心恰好构成一个**凸多边形**（即每根钉子都是凸包的顶点）。用一条绳子把所有钉子**从外面**围一圈绷紧（绳子本身粗细忽略），求绳子的长度，保留两位小数。

> 一句话版本：给一个逆时针的凸多边形顶点序列与公共半径 $R$，求"外切于此多边形各顶点圆的绷紧绳长"。

**题面里容易漏掉的条款**

1. 「所有钉子组成一个**凸**多边形」$\Rightarrow$ 每个中心都是凸包顶点，绳子会**贴着每一根钉子**绕，不会跳过任何一根——这保证了下面"逐段求和"的合法性。
2. 「按**逆时针**顺序给出」$\Rightarrow$ 相邻给出的两点之间确实是一条外沿的边；如果顺序被打乱，逐段求和会得到自交的折线，结果就错了。
3. 「绳子直径忽略不计」$\Rightarrow$ 绳子是一条理想曲线，长度 = 直线段长度 + 圆弧长度，没有额外厚度修正。
4. 「精确到小数点后 2 位」$\Rightarrow$ 用浮点累加后 `fixed` + `setprecision(2)` 输出；答案一般含 $\pi$，是超越数，取两位小数即可。

**数据范围与规模感受**

$$1\le N\le100,\qquad \text{坐标}\in[-100,100],\qquad R\ \text{为实数} .$$

$N$ 只有 $10^2$ 量级，任何 $O(N)$ 或 $O(N^2)$ 的几何写法都绰绰有余。真正的"考点"不是复杂度，而是**能否把绳子长度正确地分解成"若干直线段 + 若干圆弧"**——即能否推出下面的两条引理。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：绳子由"直线段"和"圆弧"拼成

绳子绷紧绕在外侧，它必然由两部分组成：在两根相邻钉子之间是**两圆的公切线段**（直线），在每根钉子处是一段**贴合圆周的圆弧**。绕行一周后回到起点。

设钉子中心按逆时针为 $P_0,P_1,\dots,P_{N-1}$（下标按模 $N$ 理解）。下面分别算清"直线段"和"圆弧"各有多长。

### 2.2 引理 1：两相邻钉子间的直线段长 = 中心距

**引理 1**

相邻两根钉子 $A=P_i$、$B=P_{i+1}$ 之间的那段绳（外切线）长度等于它们中心的距离 $\lvert AB\rvert$。

**证明**：取这两根钉子外侧的公切线，它与圆 $A$ 相切于 $T_A$、与圆 $B$ 相切于 $T_B$。由"半径 $\perp$ 切线"：
$$AT_A\perp T_AT_B,\qquad BT_B\perp T_AT_B ,$$
故 $AT_A$ 与 $BT_B$ 都垂直于同一条直线 $T_AT_B$，于是**二者平行**；又两圆半径相等，$\lvert AT_A\rvert=\lvert BT_B\rvert=R$。在四边形 $A\,T_A\,T_B\,B$ 中，$AT_A\parallel BT_B$ 且等长，且 $\angle AT_AT_B=\angle BT_BT_A=90^\circ$，即它有两组对边分别平行（$AT_A\parallel BT_B$，且 $T_AT_B$ 显然与其自身重合方向平行于 $AB$ 的偏移——严格地说，由 $AT_A\parallel BT_B$ 与 $\lvert AT_A\rvert=\lvert BT_B\rvert$ 直接得到 $A\,T_A\,T_B\,B$ 是平行四边形，其内角又为 $90^\circ$，故为矩形）。因此对边相等：
$$\lvert T_AT_B\rvert=\lvert AB\rvert .$$
即直线段长 = 中心距。$\blacksquare$

> 直观版：等半径两圆的外切线，就是"把中心的连线沿垂直方向平移 $R$"，所以切线段的长度与中心连线一样长。

### 2.3 引理 2：所有圆弧之和 = $2\pi R$

**引理 2**

绳子在每个钉子处转过的总角度之和为 $2\pi$，故所有圆弧长度之和为 $R\cdot 2\pi=2\pi R$。

**证明**：分两步。

**第一步（圆弧的圆心角 = 该顶点的外角）**：一条绷紧的绳子在钉子 $P_i$ 处"贴"着的这段圆弧，其两端分别与相邻两段直线相切；由"半径 $\perp$ 切线"，圆弧两端对应的两条半径分别垂直于 $(i-1\to i)$ 段与 $(i\to i+1)$ 段。于是**圆弧的圆心角**恰等于这两条相邻直线段方向的夹角，也就是多边形在该顶点的**外角** $\theta_i=\pi-(\text{内角}_i)$。

**第二步（凸 $n$ 边形外角和为 $2\pi$）**：任何凸 $n$ 边形的内角和为 $(n-2)\pi$（从某一顶点向其余顶点连 $n-3$ 条对角线，把多边形剖成 $n-2$ 个三角形，每个内角和 $\pi$，全体三角形内角和 $=$ 多边形内角和）。于是外角和
$$\sum_{i=0}^{N-1}\theta_i=\sum_{i=0}^{N-1}\big(\pi-\text{内角}_i\big)=N\pi-\sum_i\text{内角}_i=N\pi-(N-2)\pi=2\pi .$$

由半径相同，圆弧总长 $=\sum_i R\theta_i=R\sum_i\theta_i=2\pi R$。$\blacksquare$

> 注意半径相同这一步是必需的：正因为 $R$ 对所有钉子一样，才能把 $R$ 提到求和号外，直接与外角和相乘。若各钉半径不同，就得逐段累加 $R_i\theta_i$。

### 2.4 一次归约：绳长 = 凸多边形周长 + $2\pi R$

**引理 3**

绳子总长 $=\Big(\sum_{i=0}^{N-1}\lvert P_iP_{i+1}\rvert\Big)+2\pi R$（下标模 $N$）。

**证明**：绳子的直线段恰对应每一条相邻中心连线（引理 1），绕行一周经过 $N$ 条边各一次且只一次（因为各中心都是凸包顶点、绳子贴着每根钉走），故直线段总长 $=$ 凸多边形周长 $\sum_i\lvert P_iP_{i+1}\rvert$；圆弧总长由引理 2 为 $2\pi R$；两部分相加即得。$\blacksquare$

### 2.5 退化与边界情形

**引理 4（$N=1,2$ 也对）**

- $N=1$：无相邻边，周长记 $0$，绳长 $=2\pi R$（绳子就是绕单根钉子的一圈圆周）。公式仍成立。
- $N=2$：中心"多边形"退化成一条线段；按循环求和得周长 $=2\lvert P_0P_1\rvert$（同一条边被访问两次），每个顶点处的圆弧圆心角为 $\pi$，两段合计 $2\pi R$，即绳长 $=2\lvert P_0P_1\rvert+2\pi R$（两条公切线 + 两个半圆）。公式仍成立。

**证明**：$N=1$ 时求和项 $\lvert P_0P_0\rvert=0$，绳长 $=0+2\pi R$，与"绕一根钉子一圈"一致；$N=2$ 时循环求和得 $\lvert P_0P_1\rvert+\lvert P_1P_0\rvert=2\lvert P_0P_1\rvert$，弧由引理 2 仍为 $2\pi R$，与"两条切线加两个半圆"一致。$\blacksquare$

> 结论：**同一份公式 $(\sum\text{相邻中心距})+2\pi R$ 同时覆盖 $N\ge1$**，代码里不需要为 $N=1$ 开特例（循环求和对 $N=1$ 自然给出 $0$）。

### 2.6 经典技术：模拟（直接套公式）

这是一道纯模拟/几何计算题：读入坐标，按定义累加相邻中心距离（`hypot`），再加上 $2\pi R$（$\pi$ 用 `acos(-1.0)` 取全精度），`fixed` + `setprecision(2)` 输出。

**复杂度**：时间 $O(N)$，空间 $O(N)$ 存坐标。

### 2.7 坑点与体检

1. **必须按输入顺序（逆时针）相邻求和**，不能先排序再求和（那样坐标顺序被打乱，虽然凸包排序后结果也应一致，但直接按给出顺序求周长才是题面的边）。
2. **$\pi$ 用 `acos(-1.0)` 或 `2*acos(-1.0)`**，不要手写 `3.14`（精度不够两位小数）。
3. **`hypot(dx,dy)` 而非 `sqrt(dx*dx+dy*dy)`**：`hypot` 自带溢出/下溢保护，且对等长的负方向坐标给出与正方向完全一致的位结果（依赖这一点，本文的对拍才逐字节相等）。
4. **输出格式**：`cout<<fixed<<setprecision(2)`；浮点是超越数，两位小数由题目规定。
5. **$N=1$ 无需特判**（引理 4），但若有人写成"至少两条边"就会越界，需注意循环用模运算而非"从 $0$ 到 $N-2$"。

## 3. 模式总结（Pattern Summary）

按真实思考顺序排列，每条一行：

- explore its property — 把绷紧的绳子拆成"公切直线段 + 贴圆圆弧"，按绕行一周分解。
- classic problem solution（几何恒等）— 用"半径 $\perp$ 切线"证明等半径两圆公切线长 = 中心距（引理 1）。
- classic problem solution（角度求和）— 用"半径 $\perp$ 切线 + 凸多边形内角和 $(n-2)\pi$"证明圆弧总和 $=2\pi R$（引理 2）。
- reduce to easier problem — 把绳长化归为"凸多边形周长 + $2\pi R$"这一定式（引理 3）。
- constant extraction — 半径相同才允许把 $R$ 提到角度和之外（引理 2 的关键条件）。
- degeneracy coverage — 用同一公式覆盖 $N=1,2$ 的退化多边形（引理 4）。
- simulation implementation — `hypot` 逐边求和 + `2*acos(-1.0)*R`，两位小数输出。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| `n` | `int` | 钉子数 $N$ | 读入 | 题面 |
| `R` | `double` | 钉子半径 | 读入 | 题面 |
| `x[i],y[i]` | `double [105]` | 第 $i$ 个钉子中心坐标（按输入序，0-based） | 读入 | 题面 |
| `per` | `double` | 相邻中心距之和（凸多边形周长） | $0$，循环累加 | 引理 3 |
| `ans` | `double` | 绳长 $=per+2\pi R$ | `per+2*acos(-1.0)*R` | 引理 3 |

### 4.2 编号步骤

1. 读入 `n`、`R`，再读 $n$ 组 `x[i],y[i]`。
2. `per=0`；对 $i=0..n-1$，令 $j=(i+1)\bmod n$，`per+=hypot(x[i]-x[j],y[i]-y[j])`。
3. `ans=per+2*acos(-1.0)*R`。
4. `cout<<fixed<<setprecision(2)<<ans<<'\n';`。

### 4.3 复杂度

- 时间：$O(N)\le100$ 次 `hypot` 与一次乘法。
- 空间：两个 $105$ 的 `double` 数组，约 $1.7$ KB。
- 实测（见 §4.5）：$N=100$ 圆上取点约 $0.005$ s（含进程启动）。

### 4.4 关键不变量

1. `per` = 按输入序循环相邻的欧氏距离之和（凸多边形周长）。
2. 输出 $=per+2\pi R$，其中 $2\pi R$ 来自引理 2 的外角和 $2\pi$。
3. 对所有 $N\ge1$ 一致成立（引理 4）。

## 5. 示例代码

### 5.1 主解：周长 + $2\pi R$（与 `appendix/P1513/P1513.cpp` 逐字节一致）

```cpp
//
// 题目：P1513 绕钉子的长绳子
// https://www.luogu.com.cn/problem/P1513
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};   // N<=100 (+5 松弛)

int n;
double R;
double x[mxn],y[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>R;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];

	double per=0;                    // 相邻钉子中心连线的总长 = 直线段总长
	for(int i=0;i<n;++i)
	{
		int j=(i+1)%n;
		per+=hypot(x[i]-x[j],y[i]-y[j]);
	}
	double ans=per+2*acos(-1.0)*R;   // 凸多边形外角和为 2π => 圆弧总长 2πR
	cout<<fixed<<setprecision(2)<<ans<<'\n';
	return 0;
}
```

**代码结构对照**：循环里的 `hypot(x[i]-x[j],y[i]-y[j])` 是引理 1 的直线段；`2*acos(-1.0)*R` 是引理 2 的圆弧；两者相加是引理 3。`%n` 保证 $N=1$ 时也安全（引理 4）。

### 5.2 对照实现：按几何定义逐段累加的模拟（仅用于对拍）

```cpp
//
// 题目：P1513 绕钉子的长绳子 (暴力基准)
// https://www.luogu.com.cn/problem/P1513
// 仅用于对拍: 按几何定义逐段累加(公切线段 + 每个钉子处的圆弧), 不套用 2πR 闭式
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n;
double R;
double x[mxn],y[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>R;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i];

	if(n==1)                 // 只有一根钉子: 绳子就是一圈圆周
	{
		cout<<fixed<<setprecision(2)<<2*acos(-1.0)*R<<'\n';
		return 0;
	}

	double straight=0,arc=0;
	for(int i=0;i<n;++i)
	{
		int p=(i-1+n)%n,q=(i+1)%n;
		double inx=x[i]-x[p],iny=y[i]-y[p];
		double oux=x[q]-x[i],ouy=y[q]-y[i];
		straight+=hypot(oux,ouy);       // 等半径圆的公切线长 = 中心距
		double cr=inx*ouy-iny*oux;      // 逆时针转过的外角
		double dt=inx*oux+iny*ouy;
		double tr=atan2(cr,dt);         // 共线退化时 atan2 可能给出 -π(带符号零), 需归正
		if(tr<0)
			tr+=2*acos(-1.0);
		arc+=R*tr;
	}
	double ans=straight+arc;
	cout<<fixed<<setprecision(2)<<ans<<'\n';
	return 0;
}
```

两版输出**逐字节相同**（$300$ 组随机数据确认）。暴力不套用"外角和 $=2\pi$"的闭式，而是对每个钉子用 `atan2` 真算转角、累加 $R\cdot\theta$，独立验证了引理 2。**注意**：$N=2$ 或存在共线顶点时，`cross` 会出现带符号零，`atan2(-0.0,-x)` 返回 $-\pi$，需用 `if(tr<0) tr+=2π` 归正，否则两处 $\pm\pi$ 相互抵消、圆弧被算成 $0$——这正是本地对拍时踩到的坑。

### 5.3 易错点清单

- **用 `3.14` 手写 $\pi$** $\Rightarrow$ 精度不够，两位小数会错。
- **忘记加圆弧项** $\Rightarrow$ 只算周长，答案偏小（差 $2\pi R$）。
- **`endl` 替代 `'\n'`** $\Rightarrow$ 违反项目风格。
- **未处理 $N=1$** $\Rightarrow$ 若写成"假设 $N\ge2$"的相邻求和会越界或无意义（用 `%n` 即可自然覆盖）。
- **（对拍暴力）共线顶点 `atan2` 符号零** $\Rightarrow$ 圆弧被抵消成 $0$（§5.2 注释，本项目实测踩过）。
