# P1599 [USACO09MAR] 结算日 Payback B

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

数轴上有 $N$ 头奶牛，第 $i$ 头站在坐标 $i$。奶牛 $i$ 与贝西的债务关系是 $D_i$：$D_i>0$ 表示奶牛欠贝西 $D_i$ 元，
$D_i<0$ 表示贝西欠奶牛 $|D_i|$ 元。题面保证 $\sum D_i > 0$（朋友欠她的更多）。

贝西从坐标 $0$ 出发，初始没有钱。她沿数轴行走，**走到某头奶牛身边**才能做交易：
欠她钱的奶牛她可以随时收全款；她欠钱的奶牛，只有当手上的钱不少于欠款时才能一次性还清。
她必须收齐所有债权、还清所有债务，并且**最后停在坐标 $N$**（最后一头奶牛处）。求最小总行走距离。

### 输入输出格式

- **输入格式**：第一行 $N$，随后 $N$ 行每行一个整数 $D_i$（$-1000 \le D_i \le 1000$，$D_i \ne 0$）。
- **输出格式**：一行一个整数，表示最小行走距离（单位：米）。
- **数据规模**：$1 \le N \le 10^5$，$|D_i| \le 1000$，故 $|\sum D_i| \le 10^8$，答案 $\le 3N$。

### 关键约束分析

1. **终点固定为 $N$**：这不是"收完钱就停"，否则可以用更短的路线。固定终点让"净向右位移"恒为 $N$，这是后面所有距离公式的基础。
2. **交易必须到达现场**：不能在远处转账，因此"有钱"只是必要条件，还得人在那头奶牛旁边。
3. **必须一次性还清**：不允许还一部分，因此每笔欠款是一个不可分割的操作，需要一次"钱够"的时刻。
4. 前缀和可能为负，用 `int` 存前缀和虽然够（$10^8$），但习惯上仍用 64 位更稳。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：先把"走了多远"换个说法

在数轴上从 $0$ 走到 $N$，若把每次向左的步数加起来记作 $L$，那么向右的总步数必然是 $N+L$（因为净位移是 $N$），
总距离就是 $N + 2L$。于是问题从"最小化总距离"变成**最小化向左走的总长度** $L$。
这一步很关键：它把"来回折返"的几何问题变成了"每条边被向左穿越多少次"的计数问题——
把数轴切成边 $(0,1),(1,2),\dots,(N-1,N)$，$L$ 就是所有边向左穿越次数之和。

### 第二步：什么样的边*必须*被向左穿越

直觉上，"缺钱"的时候贝西只能先往右收钱，再退回来还。把"缺钱"精确化就是前缀和：

$$S_i = \sum_{k=1}^{i} D_k .$$

**引理 1（下界）**：若 $i<N$ 且 $S_i<0$，则边 $(i,i+1)$ 至少被向左穿越一次。因此 $L \ge \#\{i<N: S_i<0\}$。

*证明*：考虑贝西**最后一次**处在坐标 $\le i$ 的时刻 $t$（这样的时刻存在，因为出发点 $0 \le i$；之后她终将走到 $N>i$）。
从 $t$ 之后她再也不会回到 $\le i$，所以 $1..i$ 这些奶牛必须在 $t$ 之前或就在 $t$ 时刻全部结算完毕，
否则永远没有机会结算，与"还清所有债务"矛盾。

记 $t$ 时刻贝西手上现金为 $c$，其中来自 $1..i$ 的净贡献恰为 $S_i$，于是
$c = S_i + (\text{在 } i \text{ 右侧已结算的奶牛净贡献})$。现金恒非负，即 $c \ge 0$。
若右侧一头牛都没结算过，则 $c = S_i < 0$，矛盾。故在 $t$ 之前她到过某个坐标 $>i$；
而 $t$ 时刻她在 $\le i$，这一去一回必然至少一次向左跨过边 $(i,i+1)$。$\square$

不同的 $i$ 对应不同的边，所以这些"必须向左"的边互不重复，$L$ 的下界是可加的。

### 第三步：能不能恰好达到下界

下界只说了"每条负前缀和的边至少向左一次"。如果某次折返顺带穿过了好几条这样的边，它们被一次性满足；
但如果折返穿越了**前缀和非负**的边，就浪费了。所以要设计一种"只踩负边折返"的策略。

**构造（贪心）**：一路向右走。遇到 $D_i<0$ 而现金不够时，把这笔债"挂账"，继续向右。
当手上的现金 $c$ 已经不少于当前挂账总额 $U$ 时，**退回最左边那笔挂账的奶牛**，
沿途经过挂账奶牛就结清（钱一定够，因为 $c \ge U$），结清后再向右继续。
到达 $N$ 时现金为 $S_N + U > U$（因 $S_N>0$），所以必然触发最后一次退回，全部债务结清，最后再走到 $N$ 收尾。

**引理 2（贪心只穿越负前缀和的边）**：设某次折返从坐标 $a$ 退回最左挂账点 $b$，则对每个 $i \in [b, a-1]$ 都有 $S_i<0$；
并且这些边此后都不会再被向左穿越。

*证明*：先看 $S_b<0$：$b$ 被挂账说明当时现金 $c_b < |D_b|$，而
$S_b = c_b - U_b$（$c_b$ 为现金，$U_b \ge 0$ 为当时挂账总额，且 $U_b \ge |D_b|$），
故 $S_b \le c_b - |D_b| < 0$。

再看中间位置。出发折返的充要条件是"现金 $\ge$ 挂账总额"，而退回途中尚未开始结清，
所以在 $[b, a-1]$ 上任意位置 $i$ 都有 $c_i < U_i$。又所有 $<b$ 的债都已结清，故 $U_i = U$（挂账总额不变），
并且同样有 $S_i = c_i - U_i < 0$。第一部分得证。

再看"不会重复"。折返结束后，$1..a$ 的奶牛全部结清，此后 $U_i = 0$ 对所有 $i \le a$ 恒成立
（新的挂账只可能发生在 $>a$ 的位置，因为贝西之后只向右走到 $a$ 以外）。而现金恒 $\ge 0 = U_i$，
不满足"$c_i<U_i$"这一折返条件，故边 $(i,i+1)$（$i<a$）不会再被向左穿越。$\square$

于是贪心的 $L$ 恰好等于负前缀和的边数，与引理 1 的下界吻合。

**定理**：最小总距离为 $N + 2\cdot\#\{i: 1 \le i < N,\ S_i<0\}$。

*证明*：总距离 $= N+2L$（第一步）；$L$ 的下界由引理 1 给出，且被引理 2 的贪心达到，故取下界即最优。
注意 $i=N$ 时 $S_N>0$，不会贡献计数，所以"$i<N$"与"$i\le N$"写法等价，代码中直接对整个前缀判断即可。$\square$

### 第四步：边界与实现

- $N=1$：只需从 $0$ 走到 $1$，答案 $1$，代码中 `ans=n` 初值直接给出。
- 全部 $D_i>0$：所有前缀和为正，答案就是 $N$。
- 第 $i$ 头奶牛的前缀和恰好为 $0$：不算负，不需要折返（此时正好够还，不必先往右收钱）。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 总距离可写成 $N+2L$，问题化为"最小化向左总长度"。
- `reduce to easier problem` — 把折返问题离散成"每条边被向左穿越几次"的计数问题。
- `prove a lower bound first` — 用"最后一次离开前缀"论证负前缀和的边必须被向左穿越。
- `constructive matching` — 用"钱够就退回最左挂账点"的贪心构造出恰好达到下界的走法。
- `classic problem solution` — 前缀和一遍扫描，$\mathcal{O}(N)$，无需模拟行走过程。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $N$ | `n` | 奶牛数量（也是终点坐标） |
| $D_i$ | `d[i]` | 第 $i$ 头奶牛的债务，正数表示她欠贝西 |
| $S_i$ | `pre` | 前缀和 $\sum_{k\le i} D_k$，用 `i64` 累加，初值 $0$ |
| $L$ | — | 向左行走的总长度（不显式存储，体现在 `ans` 的增量里） |
| $N+2L$ | `ans` | 答案，初值 `n`，每发现一条负前缀和的边就 `+=2` |
| $i$ | `i` | 扫描下标，从 $1$ 到 $n$ |

### 算法步骤

1. 读入 $n$，令 `ans=n`（净位移部分），`pre=0`。
2. 对 $i=1..n$：读入 `d[i]`，`pre+=d[i]`；若 `pre<0`，则 `ans+=2`。
3. 输出 `ans`。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}(N)$，每个 $D_i$ 只做一次加法与一次比较。
- **空间复杂度**：$\mathcal{O}(N)$ 存 $D_i$（其实可以边读边算，降到 $\mathcal{O}(1)$；为保持"全局静态数组"风格保留数组）。

### 正确性验证

引理 1 给出 $L$ 的下界，引理 2 证明贪心恰好达到该下界且不重复穿越，定理把二者合成最终公式。
数值范围：$|S_i| \le 10^8$，`i64` 足够；答案 $\le 3N = 3\times10^5$，`int` 也放得下，但统一用 `i64` 累加前缀和更稳妥。

与朴素模拟的关系：引理 2 的贪心需要显式模拟"退回—结清—再前进"，但既然只关心边的穿越次数，而穿越次数已经由前缀和完全决定，
就可以跳过模拟，直接数负前缀和。这个"跳过模拟"的正确性完全依赖引理 2。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1599 [USACO09MAR] 结算日 Payback B
// https://www.luogu.com.cn/problem/P1599
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};       // N<=100000 (+5 松弛)

int n,d[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	int ans=n;                   // 一路向右走到最后一头奶牛: 基础距离 N
	i64 pre=0;                   // 前缀收支和
	for(int i=1;i<=n;++i)
	{
		cin>>d[i];
		pre+=d[i];
		if(pre<0)                // 前缀和 <0 的边 (i,i+1) 必须被向左穿越一次
			ans+=2;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **忘记"必须在最后一头奶牛处结束"**：若按"收完就停"计算，会漏掉最后的向右位移，答案偏小。
2. **符号搞反**：$D_i$ 是"奶牛欠贝西"为正；若把负号含义弄反，前缀和的符号全错。
3. **只数"余额变负的次数"而不看前缀和**：判断依据是前缀和 $S_i<0$，不是单次 $D_i<0$。
4. **前缀和为 $0$ 也算负**：$S_i=0$ 表示到此处刚好够还，不需要折返，必须是严格小于。
5. **用 `int` 存前缀和的溢出风险**：本题 $|S_i|\le 10^8$ 尚可，但换成更大的 $|D_i|$ 就会溢出，统一 `i64` 更安全。
