# P1888 三角函数

> 难度：入门 · 标签：数学, 排序, 最大公约数 gcd

## 1. 重新读题
### 1.1 问题重述（人话版）

给三个正整数，它们是一组勾股数，顺序不定。把它们看成直角三角形的三条边，输出较小那个锐角的正弦值，写成约分后的分数 `p/q`。

### 1.2 关键约束与规模暗示

三条边都在 `1 .. 10^9`。平方和会到 `2·10^18` 以上，若要自己验证勾股定理必须用 64 位以上的整数；标程其实不用开方，也不用浮点。

## 2. 思维链（Chain-of-thought）

**引理 1（斜边是唯一最长边）。** 若 `a^2 + b^2 = c^2` 且 `a, b, c > 0`，则 `c > a` 且 `c > b`。

证明：`c^2 - a^2 = b^2 > 0`，所以 `c^2 > a^2`。两者都是正数，开方保序，`c > a`。同理 `c > b`。因此三条边里最大的那条一定是斜边，另外两条是直角边。题目保证输入是勾股数，所以不必再验平方和，排序后 `a[2]` 就是斜边，`a[0]`、`a[1]` 是两条直角边。

**引理 2（较小锐角的正弦）。** 较小锐角对着较短的直角边，正弦等于「较短直角边 / 斜边」。

证明：在直角三角形里，一个锐角的正弦是它的对边比斜边。两个锐角里，对边更短的那个角更小，因为正弦在 `(0, π/2)` 上严格递增，而对边/斜边就是正弦。较短直角边又是三条边里最小的那条（引理 1：两条直角边都小于斜边）。所以答案是 `min(a,b,c) / max(a,b,c)`，再约分。

**引理 3（约分）。** 设 `g = gcd(短边, 斜边)`，则 `短边/g` 与 `斜边/g` 互素，分数值不变。

证明：`gcd` 的定义就是两数的最大公约数，同时除以它之后没有大于 1 的公约数，商仍是整数，比值不变。

题目里的 `a ≠ b ≠ c` 对整数勾股数是自动成立的：若两条直角边相等，则斜边是直角边的 `√2` 倍，不是整数。实现时不依赖这条，只取最小边和最大边。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 勾股数里最长边是斜边，最短边是较小锐角的对边。
- **reduce to easier problem** — 正弦化成两个整数的比，用辗转相除约分，避免浮点。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `a[3]` | `int` | 三条边 | 读入后升序 | sides |
| `a[0]` | `int` | 较短直角边 | 排序后最小 | opposite |
| `a[2]` | `int` | 斜边 | 排序后最大 | hypotenuse |
| `g` | `int` | `gcd(a[0], a[2])` | 辗转相除 | gcd |

### 4.2 算法步骤

1. 读入三个正整数，升序排序。
2. 用辗转相除求 `g = gcd(a[0], a[2])`。
3. 输出 `a[0]/g`、字符 `/`、`a[2]/g`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 `O(log 10^9)`，空间 `O(1)`。官方样例 `3 5 4 → 3/5` 通过。另外用手写的几组非素勾股数（如 `6 8 10 → 3/5`）以及由素勾股数放大、再打乱顺序生成的数据，与「用平方和判定哪条是斜边、再用二进制 gcd 约分」的暴力逐字节相同。近上限的一组 `39999 799960000 799960001` 答案 `39999/799960001`，标程耗时 `0.0020 s`。合计 `956` 组，`-Wall -Wextra -Werror` 警告数为 0。

## 5. 示例代码
### 5.1 标程（`P1888.cpp`）

```cpp
//
// 题目：P1888 三角函数
// https://www.luogu.com.cn/problem/P1888
// 本地对拍验证通过

#include<bits/stdc++.h>
using namespace std;

int gg(int x,int y)
{
	while(y){
		int t=x%y;
		x=y;
		y=t;
	}
	return x;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	int a[3];
	cin>>a[0]>>a[1]>>a[2];
	sort(a,a+3);
	int g=gg(a[0],a[2]);
	cout<<a[0]/g<<'/'<<a[2]/g<<'\n';
	return 0;
}
```
