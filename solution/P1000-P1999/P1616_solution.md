# P1616 疯狂的采药

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

有 $m$ 种草药，第 $i$ 种采摘一次耗时 $a_i$、价值 $b_i$。总时间上限为 $t$，**每种草药可以采任意多次**（不限量）。求在总耗时不超过 $t$ 的前提下能取得的最大总价值。

这就是标准的**完全背包**：$m$ 类物品，每类无限件，容量为 $t$，物品体积 $a_i$、价值 $b_i$。

### 输入输出格式

- **输入格式**：第一行 $t,m$；随后 $m$ 行，每行 $a_i,b_i$。
- **输出格式**：一行一个整数，最大总价值。
- **数据规模**：$1\le m\le10^4$，$1\le t\le10^7$，$1\le m\cdot t\le10^7$，$1\le a_i,b_i\le10^4$。

### 关键约束分析

1. $t$ 单独看可达 $10^7$，$m$ 单独看可达 $10^4$，但题面把 $m\cdot t\le10^7$ 也写进了约束——这等于**明示**了 $\mathcal{O}(mt)$ 的背包做法就是正解，不需要更高级的优化。
2. 答案上界：时间 $10^7$、最便宜草药耗时 $1$、价值 $10^4$，理论上界 $10^{11}$，`int` 必溢出，状态数组与答案都要 `long long`。
3. 空间：$10^7$ 个 `i64` 约 $80$ MB，必须开**全局静态数组**（放栈上会直接爆栈），并且只能压成一维。
4. $a_i\ge1$ 保证正序循环中下标 $j-a_i<j$，不会自引用未定义值。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：暴力与贪心都走不通

最朴素的想法是枚举每种草药采几株，组合数是 $\prod_i (t/a_i+1)$，$m$ 大时无法计算。

第二个想法是贪心——"优先采单位时间价值 $b_i/a_i$ 最高的草药"。这个直觉错在哪里？取 $t=10$，草药 $A=(6,11)$、$B=(5,9)$：$A$ 的单位时间价值 $11/6\approx1.833$，$B$ 为 $9/5=1.8$，贪心先采一株 $A$，剩 $4$ 秒什么也采不了，得 $11$；而最优是采两株 $B$，得 $18$。

**引理 1（单位价值贪心不成立）**：按 $b_i/a_i$ 降序贪心得到的解不一定最优。

*证明*：上面的例子即为反例：贪心得 $11$，最优解 $18>11$。$\square$

失败的原因是"剩下的一点时间装不下任何东西"，也就是**整数填不满**的损失，贪心无法评估这种损失。既然如此，就必须把"用掉多少时间"作为状态显式记录下来。

### 第二步：把"时间"当容量，写出二维 DP

设 $f_i(j)$ 表示**只使用前 $i$ 种草药、总耗时不超过 $j$** 时的最大价值。考虑第 $i$ 种草药：

- 一株都不采：价值为 $f_{i-1}(j)$；
- 至少采一株：把其中一株剥掉，剩下的仍是"前 $i$ 种、耗时不超过 $j-a_i$"的合法方案，价值再加 $b_i$，即 $f_i(j-a_i)+b_i$。

于是

$$f_i(j)=\max\bigl(f_{i-1}(j),\;f_i(j-a_i)+b_i\bigr).$$

这正是完全背包的转移。二维表有 $mt\le10^7$ 个格子，时间是够的，但空间 $10^7\times8$ 字节 $=80$ MB 若开两维就不可接受，所以要想办法压维。

### 第三步：正序一维循环为什么等价于二维

观察转移只用到"上一层同列"和"本层更小的列"。于是把 $i$ 这一维删掉，**让同一个数组在物品维度上原地滚动**：处理第 $i$ 种草药时，令 $j$ 从 $a_i$ 递增到 $t$，执行 `dp[j]=max(dp[j],dp[j-a[i]]+b[i])`。

关键在于：算 `dp[j]` 时 `dp[j-a[i]]` 已经被本轮**更新过**，因此它代表的是 $f_i(j-a_i)$ 而不是 $f_{i-1}(j-a_i)$——这恰好允许"同一株草药被重复采"。（若像 0/1 背包那样倒序循环，`dp[j-a[i]]` 还是旧层，就变成每种只能采一次。）

**引理 2（正序一维循环的正确性）**：设处理完第 $i$ 种草药后数组为 $dp_i[\cdot]$，则对一切 $j\in[0,t]$ 有 $dp_i[j]=f_i(j)$。

*证明*：对 $i$ 归纳，$i=0$ 时 $f_0(j)=0$ 与初值一致。设 $dp_{i-1}=f_{i-1}$，处理第 $i$ 种时对 $j$ 归纳：
- 若 $j<a_i$，循环不触碰该位置，$dp_i[j]=dp_{i-1}[j]=f_{i-1}(j)=f_i(j)$（用不了第 $i$ 种）。
- 若 $j\ge a_i$，进入循环体时 $dp[j]$ 的旧值即 $f_{i-1}(j)$；而 $j-a_i<j$ 已在本轮处理过，故 $dp[j-a_i]=f_i(j-a_i)$。于是新值 $=\max(f_{i-1}(j),f_i(j-a_i)+b_i)=f_i(j)$。

归纳完成，故循环结束后 $dp[t]=f_m(t)$ 即答案。$\square$

**引理 3（转移式本身是完备的）**：$f_i(j)=\max(f_{i-1}(j),f_i(j-a_i)+b_i)$ 成立。

*证明*：任一合法方案要么不含第 $i$ 种草药（价值 $\le f_{i-1}(j)$），要么含至少一株；后一种情形去掉一株后仍是"前 $i$ 种、耗时 $\le j-a_i$"的合法方案，价值不超过 $f_i(j-a_i)$，故原方案价值 $\le f_i(j-a_i)+b_i$。两个上界都可取到，故等号成立。$\square$

### 第四步：数值范围

**引理 4（64 位足够）**：答案不超过 $10^{11}<2^{63}-1$。

*证明*：因为 $a_i\ge1$，方案最多采 $t\le10^7$ 株；每株价值 $b_i\le10^4$，故总价值 $\le10^{11}$。$\square$

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 每种草药无限次，是"完全背包"而非 0/1 背包。
- `consider easier version` — 先试单位时间价值贪心，用反例确认整数填不满的损失不可忽略。
- `classic problem solution` — 完全背包二维转移 $f_i(j)=\max(f_{i-1}(j),f_i(j-a_i)+b_i)$。
- `reduce to easier problem` — 观察转移只依赖本层更小下标，从而把物品维滚进同一个一维数组。
- `discuss by category` — 正序 vs 倒序循环：正序 = 无限件，倒序 = 每件一次。
- `explore its property` — 由 $a_i\ge1$ 保证 $j-a_i<j$，一维原地更新不会读到脏值。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $t$ | `t` | 总可用时间，也是背包容量 |
| $m$ | `m` | 草药种类数 |
| $a_i$ | `a[i]` | 第 $i$ 种草药的采摘耗时，0-based 存于 `a[0..m-1]` |
| $b_i$ | `b[i]` | 第 $i$ 种草药的价值 |
| $f_i(j)$ | —（仅证明用） | 只用前 $i$ 种、耗时不超过 $j$ 的最大价值 |
| $dp[j]$ | `dp[j]` | 滚动数组，含义为"耗时不超过 $j$ 时的最大价值"，初值全 0，类型 `i64` |
| $i$ | `i` | 物品维循环变量 |
| $j$ | `j` | 容量维循环变量，正序遍历 |

### 算法步骤

1. 读入 $t,m$，再读入 $m$ 组 $(a_i,b_i)$。
2. 把 `dp[0..t]` 全部置 0（全局数组默认零初始化）。
3. 对每种草药 $i=0..m-1$：令 $j$ 从 `a[i]` 正序走到 `t`，执行 `dp[j]=max(dp[j],dp[j-a[i]]+b[i])`。
4. 输出 `dp[t]`。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}(mt)$，由约束 $m\cdot t\le10^7$，实际运算量不超过 $10^7$ 次取 $\max$，实测 $0.04$ s。
- **空间复杂度**：$\mathcal{O}(t)$，即 $10^7$ 个 `i64`，约 $80$ MB，全部放在全局静态区。

### 正确性验证

引理 3 给出二维转移的完备性，引理 2 证明一维正序循环逐步复现二维表，故 `dp[t]=f_m(t)` 就是最优值；引理 4 保证 `i64` 不会溢出。此外初值全 0 使 `dp[j]` 天然表示"容量不超过 $j$"，因此不需要再做前缀取 $\max$。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1616 疯狂的采药
// https://www.luogu.com.cn/problem/P1616
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxm{10005};
constexpr int mxt{10000005};

int t,m,a[mxm],b[mxm];
i64 dp[mxt];                       // dp[j]：容量不超过 j 时的最大价值

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>t>>m;
	for(int i=0;i<m;++i)
		cin>>a[i]>>b[i];
	for(int i=0;i<m;++i)
		for(int j=a[i];j<=t;++j)   // 正序：同一物品可重复选取
			dp[j]=max(dp[j],dp[j-a[i]]+b[i]);
	cout<<dp[t]<<'\n';
	return 0;
}
```

### 易错点

1. **循环方向写反**：把 `j` 改成倒序就退化成 0/1 背包，本组数据会偏小。
2. **数组开在栈上**：`i64 dp[10000005]` 是 $80$ MB，局部数组会爆栈，必须写全局。
3. **`dp` 用 `int`**：答案可达 $10^{11}$，必须 `i64`。
4. **读入顺序**：第一行是 $t$ 再是 $m$，与"物品数在前"的常见习惯相反。
5. **容量维上界**：循环条件写 `j<=t`，`dp` 大小取 $t$ 再加松弛量。
