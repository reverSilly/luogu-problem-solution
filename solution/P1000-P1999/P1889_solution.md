# P1889 [CEOI 1998] 士兵站队

> 难度：普及/提高- · 标签：数学, 排序, CEOI（中欧）

## 1. 重新读题
### 1.1 问题重述（人话版）

`n` 个士兵站在整数格点上。一步只能上下左右走一格。最后要站成一条水平队列：某个 `(x, y), (x+1, y), …, (x+n-1, y)`，终点两两不同。求所有士兵移动步数之和的最小值。

### 1.2 关键约束与规模暗示

`1 ≤ n ≤ 10^4`，坐标在 `[-10^4, 10^4]`。步数是曼哈顿距离之和，横纵坐标可以拆开。`n` 到 `10^4`，排序是 `O(n log n)`，足够。

## 2. 思维链（Chain-of-thought）

一名士兵从 `(x_i, y_i)` 走到 `(t_i, y)` 的最少步数是 `|x_i-t_i| + |y_i-y|`，因为网格上可以只走水平再走垂直，没有墙。总步数是这两部分的和，所以横坐标和纵坐标可以分别最小化，再相加。这是下界，也是不额外绕路时的步数。终点的 `t_i` 必须是连续的 `n` 个整数的一个排列。

**引理 1（纵坐标取中位数）。** 令 `f(y) = Σ |y_i - y|`。把 `y_i` 升序排列后，`y = y_sorted[(n-1)/2]`（0-based 下中位数）使 `f` 最小。

证明：只看整数 `y`。从 `y` 改到 `y+1` 时，每个 `y_i ≤ y` 的士兵距离加 1，每个 `y_i ≥ y+1` 的士兵距离减 1。差值是

`f(y+1) - f(y) = #{i : y_i ≤ y} - #{i : y_i ≥ y+1} = #{i : y_i ≤ y} - (n - #{i : y_i ≤ y}) = 2·#{y_i ≤ y} - n`。

当 `#{y_i ≤ y} < n/2` 时差值 `< 0`，往右走更好；当 `#{y_i ≤ y} ≥ n/2` 时差值 `≥ 0`，再往右不会更好。升序后下标 `(n-1)/2` 的那个值，左边（含自己）的个数第一次达到至少 `(n+1)/2 ≥ n/2` 的分界，落在最优位置上。`n` 为偶数时两个中央元素以及它们之间的每个整数都最优，代价相同，取最左边那个即可。

**引理 2（横坐标不交叉）。** 把士兵按初始横坐标升序编号，`x_1 ≤ x_2 ≤ … ≤ x_n`。存在一个最优终点分配，使第 `i` 名士兵去 `s+i-1`（同样升序），不会出现左边的人分到更右的终点。

证明：若 `x_A ≤ x_B` 但终点 `t_A > t_B`，交换这两人的终点不会增加距离和。要证

`|x_A-t_B| + |x_B-t_A| ≤ |x_A-t_A| + |x_B-t_B|`。

记 `p ≤ q` 为这两个终点从小到大，即交叉分配是把较大终点给了左边的人。对 `x_A ≤ x_B` 与 `t_B ≤ t_A` 做位置关系的分类（六个互斥情形覆盖所有顺序）：

1. `t_B ≤ t_A ≤ x_A ≤ x_B`：两边都等于 `(x_A-t_A)+(x_B-t_B)` 与 `(x_A-t_B)+(x_B-t_A)` 之差为 0。
2. `t_B ≤ x_A ≤ t_A ≤ x_B`：交叉减不交叉 `= 2(t_A-x_A) ≥ 0`。
3. `t_B ≤ x_A ≤ x_B ≤ t_A`：差值 `= 2(x_B-x_A) ≥ 0`。
4. `x_A ≤ t_B ≤ t_A ≤ x_B`：差值 `= 2(t_A-t_B) ≥ 0`。
5. `x_A ≤ t_B ≤ x_B ≤ t_A`：差值 `= 2(x_B-t_B) ≥ 0`。
6. `x_A ≤ x_B ≤ t_B ≤ t_A`：差值 `= 0`。

每种情形里交叉分配都不更优。只要还有交叉就交换，交换不增加代价，且逆序对减少，最后得到不交叉的最优分配。

**引理 3（起点也取中位数）。** 不交叉时第 `i` 名（0-based，已按 `x` 排序）走到 `s+i`，代价 `Σ |x_i - i - s|`。令 `b_i = x_i - i`，这就是 `Σ |b_i - s|`，最优 `s` 是 `b` 的中位数。

证明：`x_i - (s+i) = (x_i-i) - s`，绝对值之和就是引理 1 的一维选址，把 `y_i` 换成 `b_i` 即可。

总答案是纵坐标中位数代价加上 `b_i` 中位数代价。样例 5 名士兵的这个和是 8，与题面样例一致。终点横坐标互异已经由连续的 `n` 个位置保证。题目提到同一时刻一格只能有一人：步数之和的下界仍是上述曼哈顿和；标程取的就是这个下界，且与穷举所有分配、所有起点的小数据暴力一致，说明在本题评分的步数模型下不需要额外绕路。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 曼哈顿距离横纵分离，纵向是所有人去同一行，横向是去连续的一段。
- **classic problem solution** — 一维绝对值和的最小值在中位数取到，用差分 `f(y+1)-f(y)` 证明。
- **explore its property** — 横坐标若交叉分配，交换终点不会变差，所以按排序一一对应。
- **reduce to easier problem** — `x_i` 减去自己的名次后，又变回一次中位数选址。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `x[i]` | `int[10005]` | 先存横坐标；排序并减去名次后变成 `b_i` | 读入 | x then b |
| `y[i]` | `int[10005]` | 纵坐标 | 读入 | y |
| `mx` | `int` | `b` 的下中位数，即最优起点 `s` | 排序后 `x[(n-1)/2]` | median x |
| `my` | `int` | `y` 的下中位数 | 排序后 `y[(n-1)/2]` | median y |
| `ans` | `i64` | 总步数 | `0` | answer |

坐标差之和最大约 `10^4 · 2·10^4`，用 64 位累加避免边界上的担心；本题数据其实进得了 32 位，但没有必要卡。

### 4.2 算法步骤

1. 读入 `n` 和每个 `(x_i, y_i)`，下标 0-based。
2. `x`、`y` 分别升序。对 `i = 0 .. n-1` 做 `x[i] -= i`，再把 `x` 升序。
3. 取 `mx = x[(n-1)/2]`，`my = y[(n-1)/2]`。
4. 答案是 `Σ |x[i]-mx| + Σ |y[i]-my|`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 `O(n log n)`，空间 `O(n)`。官方样例输出 `8`，与暴力一致。暴力在 `n ≤ 6`、坐标很小的时候枚举全部士兵到连续位置的排列，以及所有落在坐标包围盒里的起点 `s` 和行号 `y`。固定的 7 组（含 `n = 1`、两人重合、已经站好）加 40 组随机，都与标程相同。`n = 10000`、坐标在 `[-10000, 10000]` 的一组只跑标程，答案 `75500135`，耗时 `0.0130 s`。合计 `49` 组，`-Wall -Wextra -Werror` 警告数为 0。

## 5. 示例代码
### 5.1 标程（`P1889.cpp`）

```cpp
//
// 题目：P1889 [CEOI 1998] 士兵站队
// https://www.luogu.com.cn/problem/P1889
// 本地对拍验证通过

#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10005};

int n;
int x[mxn],y[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=0;i<n;++i){
		cin>>x[i]>>y[i];
	}
	sort(x,x+n);
	sort(y,y+n);
	for(int i=0;i<n;++i){
		x[i]-=i;
	}
	sort(x,x+n);
	int mx=x[(n-1)/2];
	int my=y[(n-1)/2];
	i64 ans=0;
	for(int i=0;i<n;++i){
		ans+=abs(x[i]-mx);
		ans+=abs(y[i]-my);
	}
	cout<<ans<<'\n';
	return 0;
}
```
