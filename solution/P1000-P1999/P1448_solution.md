# P1448 [NOI1998] 围巾裁剪

> 标签：模拟 / 动态规划 DP · 难度：省选/NOI-

## 1. 重新读题

- 形状：边长 $N$ 的正三角形，被分成 $N^2$ 个面积为 $1$ 的单位小三角形；从上往下共 $N$ 行，第 $X$ 行有 $2X-1$ 个单元，坐标 $(X,Y)$，$1\le Y\le 2X-1$。
- 方向：$Y$ 为奇数是 $\Delta$（正立），$Y$ 为偶数是 $\nabla$（倒立）——由"第二行 3 个单元里 2 个 $\Delta$、1 个 $\nabla$"唯一确定。
- 目标：选出两块**正立**子三角形（形状与原围巾相同，只能 $\Delta$ 朝向），各自内部无被咬单元，沿单元边界裁，两块互不重叠，面积和最大。
- 边长 $k$ 的正立三角形面积 $=k^2$（样例解释里 $4+9=13$ 即 $k=2$ 与 $k=3$）。
- 数据范围：$1\le N\le 100$，$0\le M\le N^2-2$。
- **题面内部不一致**：输入格式写 $1\le M\le N^2-2$，数据范围写 $0\le M\le N^2-2$。按题面以数据范围为准（允许 $M=0$），程序不依赖 $M$ 的下界。
- 陷阱与边界见 §1.2。

### 1.1 把题面翻译成数学语言

围巾的 $N^2$ 个单元构成一个三角网格。用题面的 $(X,Y)$ 坐标：

| 行 $X$ | 单元数 | $\Delta$（$Y$ 奇） | $\nabla$（$Y$ 偶） |
|---|---|---|---|
| 1 | 1 | $Y=1$ | 无 |
| 2 | 3 | $Y=1,3$ | $Y=2$ |
| 3 | 5 | $Y=1,3,5$ | $Y=2,4$ |
| $X$ | $2X-1$ | $X$ 个 | $X-1$ 个 |

几何上相邻关系（后面反复要用，先在这里钉死）：

- 同一行内 $Y,Y+1$ 左右相邻，每行左端是 $\Delta$、右端也是 $\Delta$。
- $(X,2a-1)$（$\Delta$）的**正下方**是 $(X+1,2a)$（$\nabla$）：两者共用一条水平边。
- 于是"顶上一个 $\Delta$ + 它下面那一行的 $\Delta\nabla\Delta$"正好拼成边长 $2$ 的正立三角形，面积 $4$。

剪裁条件重述：选两个三元组 $(p,y,k)$（顶点行、顶点列、边长），$y$ 必须为奇数（正立），两块都不能含被咬单元，且**两块不能有公共单元**（同一块丝绸上裁出两块，物理上必须不重叠），最大化 $k_1^2+k_2^2$。

**关于条件 1 的一处读法（本文采用的解释）**：倒立的正三角形在纯几何意义下也与原图"相似"，但题面把"形状完全相同"与原图的坐标体系（第 $X$ 行 $2X-1$ 格、左右端都是 $\Delta$）绑定叙述，示例粗线的两块也都是正立、面积 $4$ 与 $9$。因此本文按"**两块都必须正立（顶角朝上）**"求解，这也是本题通行解法。若允许倒立块，不相交判据与面积可行性都要重做——这一歧义在 §4.4 里作为缺口登记。

### 1.2 陷阱与边界

1. **$M$ 的下界冲突**：输入格式 $1\le M$，数据范围 $0\le M$。以数据范围为准（$M=0$ 合法），代码里 $m=0$ 时循环自然不执行。
2. **$\nabla$ 单元不能单独成围巾**：条件 1 要求"形状与原围巾完全相同"，只能是正立的。所以"剩下的干净单元数 $\ge 2$"并不保证有解。
3. **$M\le N^2-2$ 不保证两块可裁**：例如 $N=2,M=2$，咬掉 $(1,1),(2,1)$，只剩 $\nabla(2,2)$ 与 $\Delta(2,3)$，只能裁出 $1$ 块。官方数据有解，本实现此时输出 $0$（不会输出错误的大值）。
4. **面积不是底乘高**：题目把单位三角形面积定义为 $1$，所以边长 $k$ 的子三角形面积就是 $k^2$（$1+3+5+\cdots$）。
5. **贪心必错**：先裁最大块再裁次大块，见 §2.3 反例。
6. **"水平线一刀切"也必错**：见 §2.4 反例，必须考虑三个方向。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：一个正立子三角形长什么样

先把"正立子三角形"用 $(X,Y)$ 写清楚，否则后面什么都证不了。

**引理 1（行区间刻画）**
以 $(p,y)$ 为顶角单元（$y$ 奇，即 $\Delta$）、边长为 $k$ 的正立三角形，恰好是如下 $k^2$ 个单元：

$$T(p,y,k)=\{(X,Y):\ p\le X\le p+k-1,\ \ y\le Y\le y+2(X-p)\},$$

即第 $p+t$ 行（$t=0,\dots,k-1$）占连续 $2t+1$ 列 $[y,\,y+2t]$，左右端点都是 $\Delta$。

**证明**（四段，把"双向夹逼"做实，不用"显然"）。

*(i) 用 Cartesian 坐标把"相邻/正下方"钉死。* 设深度 $d$ 为到大三角形顶点的行高倍数，顶点取 $x=0$。大三角形在深度 $d$ 的截面是 $[-d/2,\,d/2]$（长 $d$）。第 $X$ 行就是深度区间 $[X-1,X]$，其中

$$\Delta(X,Y)\ \text{的底边}=\Big[\tfrac{Y-X}{2},\tfrac{Y-X+1}{2}\Big]\ \text{位于深度}\ X;\qquad \nabla(X,Y)\ \text{的顶边}=\Big[\tfrac{Y-X-1}{2},\tfrac{Y-X}{2}\Big]\ \text{位于深度}\ X-1.$$

（这两式就是把行底边/顶边按单位段编号再换元的结果，代 $Y=2i-1$、$Y=2j$ 即得。）由此立刻读出两件事：

> **$\Delta(X,Y)$ 的底边与 $\nabla(X+1,Y+1)$ 的顶边是深度 $X$ 上的同一段** ⟹ 二者共边，即"$\Delta(X,Y)$ 正下方是 $\nabla(X+1,Y+1)$"；而该 $\nabla$ 同行的左邻是 $\Delta(X+1,Y)$、右邻是 $\Delta(X+1,Y+2)$。
> 合起来：**$\Delta(X,Y)$ 的"正下方三兄弟"是 $(X+1,Y),(X+1,Y+1),(X+1,Y+2)$。**

*(ii) 剪裁线只能是三条格线族，故子三角形被三个整数参数决定。* 条件 3 要求沿单元边界下刀，边界所在的直线恰是三个格线族：水平线 $d\in\mathbb Z$；平行左边 $x=-d/2+\alpha$；平行右边 $x=d/2-\beta$。深度 $d$ 处的格点横坐标是 $-d/2+$ 整数，故"边经过格点"等价于 $\alpha,\beta\in\mathbb Z$。正立三角形的顶顶点是左右两边的交点，落在整深度 $d_0$ 上要求 $d_0=\alpha+\beta$；底边在 $d_1>d_0$，边长 $k=d_1-d_0$。于是子三角形就是

$$S=\{(x,d):\ d_0\le d\le d_1,\ -d/2+\alpha\le x\le d/2-\beta\},\qquad \text{顶角单元所在行 }p=d_0+1 .$$

*(iii) 逐行数单元（这是引理的全部内容与唯一非平凡处）。* 记 $y:=2\alpha+1$（奇数），并把 $\beta=d_0-\alpha=(p-1)-\frac{y-1}{2}$ 即 $2\beta=2p-1-y$ 代入下面两界。

- $\Delta(X,Y)$ 落在 $S$ 内 $\iff$ $p\le X\le d_1$ 且其底边含于深度 $X$ 的截面：
 左界 $\frac{Y-X}{2}\ge-\frac X2+\alpha\iff Y\ge 2\alpha$，因 $Y$ 奇、$2\alpha$ 偶 $\iff Y\ge y$；
 右界 $\frac{Y-X+1}{2}\le\frac X2-\beta\iff Y\le 2X-2\beta-1=y+2(X-p)$。
 故第 $X$ 行的 $\Delta$ 列是 $y,\,y+2,\,\dots,\,y+2(X-p)$。
- $\nabla(X,Y)$ 落在 $S$ 内 $\iff$ $p+1\le X\le d_1$ 且其顶边含于深度 $X-1$ 的截面：
 左界 $\frac{Y-X-1}{2}\ge-\frac{X-1}{2}+\alpha\iff Y\ge 2\alpha+2=y+1$；
 右界 $\frac{Y-X}{2}\le\frac{X-1}{2}-\beta\iff Y\le y+2(X-p)$，因 $Y$ 偶、右边为奇 $\iff Y\le y+2(X-p)-1$。
 故第 $X$ 行的 $\nabla$ 列是 $y+1,\,y+3,\,\dots,\,y+2(X-p)-1$（$X=p$ 时为空集 ✓ 顶行确实只有一个单元）。

两类并起来恰是**连续整数列** $[y,\ y+2(X-p)]$，共 $2(X-p)+1$ 个，左右端都是 $\Delta$ ✓。顶行 $X=p$ 给出 $\{y\}$，即顶角单元 $(p,y)$，$y$ 为奇 ✓。$d_1=p+k-1$ ⟹ 行号 $p,\dots,p+k-1$ 共 $k$ 行。这就证明了 $T(p,y,k)$ 的表示式（两个方向都证了：$S$ 的单元集 $\subseteq$ 由 $(p,y,k)$ 写出的区间集，且反过来给定 $(p,y,k)$ 按 (ii) 取 $\alpha=(y-1)/2$、$\beta=p-1-\alpha$、$d_1=p+k-1$ 就还原出同一个 $S$）。$\blacksquare$ 细节：$\alpha\in\mathbb Z$ 要求 $y$ 奇 ✓，$\beta\in\mathbb Z$ 要求 $2p-1-y$ 偶 ✓（$y$ 奇 ⟹ $2p-1-y$ 偶 ✓），所以"$y$ 必须是奇数"也在这里被证明而不是被假设。

*(iv) 计数与越界。* $\sum_{t=0}^{k-1}(2t+1)=k^2$ ✓ 即面积。网格合法性：底行右端 $y+2(k-1)\le(2p-1)+2k-2=2(p+k-1)-1$ 恰是第 $p+k-1$ 行的最后一列 ⟹ 只要顶角本身合法（$y\le 2p-1$）且 $p+k-1\le N$，整个 $T$ 自动落在围巾内，**无需额外的左右越界检查**；左端 $y\ge 1$ 也自动成立。$\blacksquare$

> 引理 1 的副产品很关键：**"顶点合法 + 底行不超过 $N$" ⟺ 三角形在围巾内**。这就是 §2.2 的递推只管"往下长"的原因。

### 2.2 简化版：只裁一块围巾

先做减法：如果只要一块，问题就是"最大的无蛀洞正立子三角形"。这一步是整个解法的地基。

**记号**：$R(x,y,k)=\{(X,Y):x\le X\le x+k-1,\ y\le Y\le y+2(X-x)\}$，即引理 1 的 $T$ 但**不要求 $y$ 是奇数**。称 $R$ 为"干净"指其中不含被咬单元。

为什么要故意丢掉奇偶限制？因为下面这个分解会出现"偏移 1"的子块，它的顶点列可能为偶数：

**引理 2（三叉分解）**
对任意整数 $x\ge 1$、$y$、$k\ge 2$（区域都限制在围巾内）：

$$R(x,y,k)=\{(x,y)\}\ \cup\ R(x+1,y,k-1)\ \cup\ R(x+1,y+1,k-1)\ \cup\ R(x+1,y+2,k-1).$$

**证明**：两边都是"逐行的区间并"，逐行证相等。固定行 $X=x+t$，$0\le t\le k-1$。
左边在该行的截面：$t=0$ 时 $\{y\}$；$t\ge 1$ 时 $[y,\,y+2t]$。
右边在该行的截面：$\{(x,y)\}$ 只在 $t=0$ 出现；三个子区域在 $x+1+t'=x+t$（即 $t'=t-1\ge 0$）行的截面分别是
$R(x+1,y,k-1):\ [y,\,y+2(t-1)]=[y,y+2t-2]$，
$R(x+1,y+1,k-1):\ [y+1,\,y+2t-1]$，
$R(x+1,y+2,k-1):\ [y+2,\,y+2t]$。
当 $t=0$：只有左边的 $\{(x,y)\}$ 有内容，右边三个区域都不含第 $x$ 行，截面并 $=\{y\}$ ✓。
当 $t\ge 1$：三个区间的并 —— 第一、二个相接（第一个上界 $y+2t-2$、第二个下界 $y+1$，需 $y+1\le y+2t-1$ ⟺ $t\ge 1$ ✓）；第二、三个相接（第二个上界 $y+2t-1$、第三个下界 $y+2$ ✓）。故并为 $[y,\,y+2t]$ ✓。
反向包含也成立：三个子区域都含在 $R(x,y,k)$ 内（它们的行范围 $[x+1,x+k-1]$、列上界最大 $y+2t$、下界最小 $y$），加上 $\{(x,y)\}$ 恰是左边的第 $x$ 行截面。两边逐行截面相等 ⟹ 集合相等。$\blacksquare$

**引理 3（单块 DP）**
$$s[x][y]=\max\{k\ge 0:\ k\le N-x+1\ \wedge\ R(x,y,k)\ \text{干净}\},\qquad
s[x][y]=\begin{cases}0,&(x,y)\text{ 被咬},\\ 1+\min\big(s[x+1][y],\,s[x+1][y+1],\,s[x+1][y+2]\big),&\text{否则}.\end{cases}$$

**证明**：$(x,y)$ 被咬时 $R(x,y,1)$ 已不干净，$s=0$ ✓。否则 $R(x,y,k)$ 干净 $\iff$ $k=1$，或（$k\ge 2$ 且引理 2 右侧四块全干净）$\iff$（$k\ge2$ 且三个子区域各含 $k-1$ 行且都干净）——$\{(x,y)\}$ 干净已设。由 $s$ 的定义，三个子区域都干净且行内合法 $\iff$ $\min(s[x+1][y],s[x+1][y+1],s[x+1][y+2])\ge k-1$。所以"$k$ 可达"⟺"$k\le 1+\min(\cdot)$"，取最大即得递推式。行界 $k\le N-x+1$ 也自动满足：第 $x+1$ 行以外（$x=N$）三个子状态都是越界值 $0$（全局数组默认 $0$），递推给 $s[N][y]=1$ ✓，故 $s[x][y]\le N-x+1$。$\blacksquare$

**回到真围巾**：由引理 1，"以 $(p,y)$（$y$ 奇）为顶角、边长 $k$ 的干净三角形" $\iff$ $R(p,y,k)$ 干净 $\iff$ $s[p][y]\ge k$。所以

$$\text{所有可裁的一块围巾}=\{(p,y,k):\ p\le N,\ y\in\{1,3,\dots,2p-1\},\ 1\le k\le s[p][y]\},\quad \text{面积}=k^2.$$

$y$ 偶数的 $s$ 值只是为了让引理 2 的中间项有定义而存在的**辅助状态**，绝不能拿去当围巾枚举（这也是最容易写错的地方：枚举时步长必须 $+2$ 从 $1$ 开始）。

复杂度：状态 $O(N^2)$（第 $x$ 行 $2x-1$ 个），转移 $O(1)$ → 单块部分 $O(N^2)$。候选三角形总数 $\sum_{p=1}^{N}p\cdot(N-p+1)=\binom{N+2}{3}\approx 1.7\times10^5$（$N=100$）。

### 2.3 剖析"贪心"为什么失败

有了单块 DP，最自然的想法是：**先取最大的一块，剩下的区域里再取最大的一块**。用具体数据把它推翻。

**反例 1**：$N=3$，$M=0$（整块围巾完好）。
最大块是 $k=3$、面积 $9$，它占满全部 $9$ 个单元，第二块只能裁出面积 $0$ —— 但题目要求**两块**。真正的最优是 $k=2$（面积 $4$，占第 1–2 行）配第 3 行任意一个 $\Delta$（面积 $1$），得 $5$。贪心的"$9+0$"根本不是合法解；若实现成"取最大再取次大"就会输出 $9$。

**反例 2**：$N=2$，$M=0$。最大块 $k=2$ 面积 $4$ 又占满全部单元；两块必须都是 $k=1$，答案 $1+1=2$。

**失败模式的共性**：一块的"收益"是 $k^2$，而它对其它块的"伤害"是通过**覆盖**实现的，覆盖范围随行号按 $2t+1$ 增长。取最大块时，收益按 $k^2$ 增加，但它同时封死了与自己行区间/列区间相交的一切位置；而面积函数是**凸的**（$k^2$），"最大块 + 0"与"次大块 + 次次大块"的大小关系完全取决于剩余可用空间，没有局部可加的判据。用交换论证也救不回来：设最优两块为 $(k_1,k_2)$、贪心取 $K>k_1$，$K$ 与 $k_2$ 完全可能重叠，无法像区间调度那样把 $K$ 换成 $k_1$。

结论：**两块必须作为一个整体来枚举/比较**，贪心（以及"先固定第一块再求第二块"的朴素 $O(\#tri^2)$ 双枚举，$1.7\times10^5$ 的两两组合约 $3\times10^{10}$，也太大）都需要新的结构性质才能推进。于是下一步去问：两个正立三角形不相交，究竟意味着什么？

### 2.4 两块不相交到底意味着什么

**直觉猜想**：两块既然不相交，那它们一定被某条水平网格线（第 $t$ 行与第 $t+1$ 行之间）分开，于是一层循环枚举切口即可。

**反例（推翻水平线猜想）**：$N=5$，把除以下 $5$ 个单元以外的全部单元都咬掉：
$$(4,3),\ (5,3),\ (5,4),\ (5,5),\ (5,7)\qquad(M=25-5=20\le N^2-2=23).$$
前 $4$ 个正好组成 $A=T(4,3,2)$（顶角 $(4,3)$、边长 $2$，面积 $4$）；$(5,7)$ 是单个 $\Delta$，即 $B=T(5,7,1)$（面积 $1$）。$A\cap B=\varnothing$ ✓。
但 $A$ 占第 4–5 行、$B$ 占第 5 行，行区间相交 ⟹ **没有任何水平线能把它们分开**；只枚举水平切口时，本例最好只能取到 $1+1=2$（例如 $\Delta(4,3)$ 单格配第 5 行某个单格），而真答案是 $4+1=5$。

问题出在：三角形有三个方向的边，"分开"这件事也应该允许沿三个方向。下面把它做成定理。

**记号**：给每个单元配三个数

$$X\ (\text{行号}),\qquad Y\ (\text{列号}),\qquad c=Y-2X .$$

对一个三角形 $T(p,y,k)$ 记

$$b=p+k-1\ (\text{底行}),\quad l=y\ (\text{最小列}),\quad r=y-2p\ (\text{最大 }c),$$

并由引理 1 可得六个极值：$\min X=p,\ \max X=b,\ \min Y=l,\ \max Y=l+2(b-p)=2b+r,\ \min c=l-2b,\ \max c=r$（$\max Y=2b+r$ 用了 $p=(l-r)/2$）。
（注意 $p=(l-r)/2$，且对任何单元恒有 $c=Y-2X\le(2X-1)-2X=-1$，即 $r\le -1$，后面要用。）

**引理 4（三半平面表示）**
$$T(p,y,k)=\{(X,Y)\ \text{是围巾的单元}:\ X\le b,\ Y\ge l,\ c\le r\}.$$

**证明**：双向包含。
$\subseteq$：行范围 $\le b$ ✓；引理 1 给 $Y\ge y=l$ ✓；$c=Y-2X\le(y+2(X-p))-2X=y-2p=r$ ✓。
$\supseteq$：设单元 $(X,Y)$ 满足 $X\le b,\ Y\ge l,\ Y-2X\le r$。
先证 $X\ge p$：若 $X\le p-1$，则 $Y\le r+2X=(y-2p)+2X\le y-2p+2p-2=y-2<l$，与 $Y\ge l$ 矛盾 ✓。
再引理 1 的条件：第 $X$ 行需要 $l\le Y\le y+2(X-p)$；左边就是 $Y\ge l$ ✓，右边就是 $Y-2X\le y-2p=r$ ✓。行范围 $p\le X\le b$ ✓。故 $(X,Y)\in T$。$\blacksquare$

**定理（三族分离 = 不相交）**
设 $A=T(p_A,y_A,k_A)$、$B=T(p_B,y_B,k_B)$ 是围巾内的两个正立三角形。则

$$A\cap B=\varnothing\iff\text{下面三组判据至少有一组成立：}$$

| 族 | 直线方向 | 判据（$A$ 在"$-$"侧） | 对称情形（$B$ 在"$-$"侧） |
|---|---|---|---|
| $X$ | 水平线 | $b_A<p_B$ | $b_B<p_A$ |
| $Y$ | 平行于左边（$Y=$ 常数） | $2b_A+r_A<l_B$ | $2b_B+r_B<l_A$ |
| $c$ | 平行于右边（$Y-2X=$ 常数） | $r_A<l_B-2b_B$ | $r_B<l_A-2b_A$ |

表中每条形如"$A$ 的某方向最大值 $< B$ 的该方向最小值"，即一条垂直于该方向的网格线把两块严格夹开：$A$ 的行全 $\le b_A<p_B\le B$ 的行；$A$ 的列全 $\le\max Y_A=2b_A+r_A<l_B\le B$ 的列；$A$ 的 $c$ 全 $\le r_A<l_B-2b_B=\min c_B\le B$ 的 $c$。

**证明（$\Leftarrow$）**：以 $b_A<p_B$ 为例。任一 $(X,Y)\in A$ 有 $X\le b_A$，任一 $(X,Y)\in B$ 有 $X\ge p_B>b_A$，同一单元不可能满足两者，故 $A\cap B=\varnothing$。
$2b_A+r_A<l_B$ 同理：$A$ 中 $Y\le 2b_A+r_A$（引理 4 后的极值表），$B$ 中 $Y\ge l_B$，列号互斥。
$r_A<l_B-2b_B$ 同理：$A$ 中 $c\le r_A$，$B$ 中 $c\ge l_B-2b_B$，$c$ 值互斥。三式结构完全一致。$\blacksquare$

**证明（$\Rightarrow$）**：反用引理 4。$A\cap B=\{(X,Y):X\le b^*,\,Y\ge l^*,\,c\le r^*\}$，其中
$$b^*=\min(b_A,b_B),\quad l^*=\max(l_A,l_B),\quad r^*=\min(r_A,r_B).$$
记该区域为 $\Phi$；$A\cap B=\varnothing$ 即 $\Phi=\varnothing$。两个同型区域的交仍是同型区域（三条约束取交集即得），这是本定理成立的根本原因。

**$\Phi$ 非空的判据**：$\Phi\neq\varnothing\iff\exists$ 整数 $X$，$1\le X\le\min(b^*,N)$，使第 $X$ 行的可行列区间 $[\max(l^*,1),\ \min(2X-1,\ r^*+2X)]$ 非空。
真实三角形有 $1\le b^*\le N$、$l^*\ge1$，故 $X$ 上界就是 $b^*$；区间非空要求 $l^*\le 2X-1$ 且 $l^*\le r^*+2X$，即
$$X\ge\frac{l^*+1}{2}\qquad\text{且}\qquad X\ge\frac{l^*-r^*}{2}.$$
于是
$$\Phi=\varnothing\iff b^*<\Big\lceil\frac{l^*+1}{2}\Big\rceil\ \ \text{或}\ \ b^*<\Big\lceil\frac{l^*-r^*}{2}\Big\rceil,$$
（$b^*\ge1$ 已保证"$1$"那一界不会致空。）再化为整数不等式：对整数 $v$，$b^*<\lceil v/2\rceil\Rightarrow b^*\le\lceil v/2\rceil-1$，故 $v$ 偶时 $2b^*\le v-2$、$v$ 奇时 $2b^*\le v-1$，两种情形都有

$$\text{(I)}\ 2b^*\le l^*,\qquad\qquad\text{(II)}\ 2b^*+r^*<l^*.$$

分离判据在 $A,B$ 互换下对称，故不妨设 $b^*=b_A$（否则改名）。按 $l^*,r^*$ 的来源分六个子情形：

1. **(I) 且 $l^*=l_A$**：$2b_A\le l_A$。但 $l_A=y_A\le 2p_A-1$（顶角合法）且 $p_A\le b_A$，得 $l_A\le 2b_A-1$，与 $2b_A\le l_A$ 矛盾 ⟹ **不可能发生**。
2. **(I) 且 $l^*=l_B$**：$A$ 的最大列 $=2b_A+r_A\le 2b_A-1$（$r_A\le-1$ 恒成立，见前面极值表的注）$\le l^*-1=l_B-1<l_B=B$ 的最小列 ⟹ **$Y$ 族分开** ✓。
3. **(II) 且 $r^*=r_A,\ l^*=l_A$**：$2b_A+r_A<l_A\iff 2b_A<l_A-r_A=2p_A\iff b_A<p_A$ ⟹ **不可能发生**。
4. **(II) 且 $r^*=r_A,\ l^*=l_B$**：$2b_A+r_A<l_B$ 正是"$A$ 的最大列 $<B$ 的最小列" ⟹ **$Y$ 族分开** ✓。
5. **(II) 且 $r^*=r_B,\ l^*=l_B$**：$2b_A+r_B<l_B\iff 2b_A<l_B-r_B=2p_B\iff b_A<p_B$ ⟹ **$X$ 族分开** ✓。
6. **(II) 且 $r^*=r_B,\ l^*=l_A$**：$2b_A+r_B<l_A\iff r_B<l_A-2b_A$，即"$B$ 的最大 $c$ $<A$ 的最小 $c$" ⟹ **$c$ 族分开** ✓。

六个子情形要么自相矛盾，要么直接给出某一族的严格分离；$\Rightarrow$ 得证。$\blacksquare$

**回头看反例**：$A=T(4,3,2)$：$p_A=4,\,y_A=l_A=3,\,b_A=5,\,r_A=3-8=-5$；$B=T(5,7,1)$：$p_B=b_B=5,\,l_B=7,\,r_B=7-10=-3$。
$A$ 的列区间 $[3,5]$、$B$ 的列区间 $[7,7]$，判据 $2b_A+r_A=10-5=5<7=l_B$ ✓ 落在子情形 4，被**平行于左边**的线分开。这就是"只枚举水平线必然漏解"的机制性解释。
（再核对另两族：$X$ 族 $b_A=5\not<p_B=5$ 且 $b_B=5\not<p_A=4$ ⟹ 分不开；$c$ 族 $r_A=-5<\min c_B=-3$ ⟹ 也分得开。所以本例是"$Y$、$c$ 可行、$X$ 不可行"，§2.8 的测试 4 才是"只有 $c$ 族可行"的极端例子。）

> 一句话总结：**"两块不重叠"这件二维的事，等价于"在三个固定方向之一上互不遮挡"这件一维的事。**

### 2.5 归约到更简单的问题：三个一维"分段取最优"

定理给了等价的**可判**条件，现在把它变成算法。固定一族（方向），每个三角形在这族上有两个数：

$$\min(v)=\text{该三角形在这族坐标上的最小值},\qquad \max(v)=\text{最大值}.$$

- $X$ 族：$\min=p$（顶行），$\max=b$（底行）。
- $Y$ 族：$\min=l=y$，$\max=2b+r=y+2(k-1)$。
- $c$ 族：$\min=l-2b=y-2b$，$\max=r=y-2p$。

被这族线分开的两块 $A,B$ 满足 $\max_A<\min_B$ 或 $\max_B<\min_A$；两者关于 $A,B$ 对称，所以只需考虑"一个 $A$、一个 $B$"，切口 $t$ 取遍：

$$\text{cut}(t)=\Big(\max_{A}\ \text{area}(A)\ \text{s.t.}\ \max(v_A)\le t\Big)+\Big(\max_{B}\ \text{area}(B)\ \text{s.t.}\ \min(v_B)\ge t+1\Big),$$

且要求两个 $\max$ 都**真的取到了三角形**（值 $>0$）。前一项对 $t$ 单调不减 $\to$ 前缀最大值；后一项单调不增 $\to$ 后缀最大值。于是：

**引理 5（归约正确性）**
$$\text{ans}=\max_{\text{族}\in\{X,Y,c\}}\ \max_{t}\ \text{cut}(t).$$

**证明**：
$\ge$：任取一族与切口 $t$，设两侧各至少有一个三角形。记前缀最大值由 $A$ 达到（$\max(v_A)\le t$），后缀最大值由 $B$ 达到（$\min(v_B)\ge t+1$）。则 $\max(v_A)\le t<\min(v_B)$，于是 $A\ne B$（任一三角形都有 $\min\le\max$，不可能同时满足 $\max\le t<\min$），并且"$A$ 在该族坐标上整体小于 $B$"正是定理表格最左列的判据，故 $A\cap B=\varnothing$，$(A,B)$ 是合法裁法，面积和 $=\text{cut}(t)$。
$\le$：取最优裁法 $(A^*,B^*)$，$A^*\cap B^*=\varnothing$，由定理（$\Rightarrow$ 方向）存在一族把两者分开。若给出的是"$A^*$ 在该族更小"，取 $t=\max(v_{A^*})$，则 $A^*$ 进前缀集合、$B^*$（其 $\min\ge t+1$）进后缀集合，前缀最大值 $\ge\text{area}(A^*)$、后缀最大值 $\ge\text{area}(B^*)$，故 $\text{cut}(t)\ge\text{area}(A^*)+\text{area}(B^*)=\text{ans}$；若是"$B^*$ 更小"则把 $A^*,B^*$ 互换角色，同样的 $t$ 起作用（$\text{cut}(t)$ 对 $A,B$ 对称，因为它是两个独立集合上的 $\max$ 之和）。$\blacksquare$

> 注意 $\text{cut}(t)$ 里两个 $\max$ 是**独立**取的，所以程序无须记录"哪两块"，只要各自 $\text{area}$ 之和最优即可；合法性由"$\max(v_A)\le t<\min(v_B)$"这条线担保。

**实现形态**（详细编号步骤见 §4.2，代码见 §5）：开两个桶数组 `hi[]`、`lo[]`（初值 $0$）→ 三重循环枚举所有干净三角形 $(p,y,k)$（$p=1..N$、$y=1,3,\dots,2p-1$、$k=1..s[p][y]$，面积 $k^2$），按族算出 $(\min,\max)$ 并更新两个桶（$c$ 族整体 $+2N$ 平移使下标非负）→ `hi` 前缀 $\max$、`lo` 后缀 $\max$ → 枚举切口 $t$，两侧都非 $0$ 时更新答案。

候选总数 $\binom{N+2}{3}=171700$（$N=100$），乘 $3$ 族约 $5\times10^5$ 次 $O(1)$ 操作；三族合并 $O(N)$。总复杂度 $O(N^3)$ 时间、$O(N^2)$ 空间，$N=100$ 时远在限额内。

**为什么不能用"每个切口只留最大块"以外的信息？** 因为 $\text{cut}(t)$ 只依赖每侧的**单个**最大值：两块之间除了"被 $t$ 分开"再无约束，所以 $A$ 的选择与 $B$ 的选择独立，$\max$ 可分配。这是归约后问题变平凡的真正原因（对比：若约束是"两块相邻"就不能拆开）。

### 2.6 溢出防护与实现陷阱

**数值上界（逐项算，不靠感觉）**：$N\le100\Rightarrow k\le100\Rightarrow k^2\le10^4$；两块之和 $\le 2\times10^4<2^{31}$。$s[x][y]\le N$、下标 $\le 2N=200$，全部 `int` 安全，无需 `i64`（代码仍按风格指南留着 `using i64=long long;`，本题不用）。
真正的溢出风险只在一个地方：若把面积写成 $k\cdot k\cdot 3$ 之类的中间量才有风险，这里没有。

**陷阱清单**：

1. **全局数组默认 $0$ 是"对"的，但要想清楚**。`s`、`hi`、`lo` 都以 $0$ 为初值：$s=0$ 表示"该顶点无干净区域"、`hi/lo` 的 $0$ 表示"这一侧还没有任何三角形"。$0$ 恰是 $\max$ 的单位元（真实面积 $\ge1$），所以不用 `fill_n` 赋 INF。反之，若把"无解"编码成 $0$ 又直接 `ans=max(ans,hi[t]+lo[t+1])`，就会出现"一块也没裁到却算进答案"的错误——因此必须写成 `if(hi[t]&&lo[t+1])`，即**两侧都必须是真实三角形**。
2. **DP 的第 $N+1$ 行**。递推要读 `s[x+1][*]`；$x=N$ 时读到第 $N+1$ 行，靠"全局数组越界行仍为 $0$"来封顶，因此数组必须开到 `mxn=105`（$N+2$ 足够，$+5$ 松弛），且**绝不能**把越界行预置成非 $0$。
3. **列下标越界**。`s[x+1][y+2]` 最大为 $y=2x-1$ 时的 $2x+1$，$x=N$ 时 $=2N+1\le201$；`mxv=2*mxn+5=215` 覆盖 ✓。
4. **枚举步长**。顶角只能是奇列：`for(int y=1;y<=2*p-1;y+=2)`。写成 `++y` 会把 $\nabla$ 当成围巾，答案偏大（错误样例见 §2.8 测试 5 的对照）。
5. **$c$ 的下标平移**。$c=Y-2X\in[1-2N,\,-1]$，整体 $+2N$ 后落在 $[1,\,2N-1]$，与前缀/后缀循环范围 `1..2*n` 一致；$X,Y$ 两族本身已在 $[1,2N-1]$ 内，平移对 $t$ 的枚举范围没有影响（三族统一用同一个 $t$ 循环）。
6. **前缀/后缀方向别搞反**：`hi` 按 $\max$ 分桶后要求 $\max\le t$ → 沿下标**递增**方向做前缀 $\max$；`lo` 按 $\min$ 分桶后要求 $\min\ge t+1$ → 沿下标**递减**方向做后缀 $\max$。
7. **$M=0$ 时第二行仍要读**。`cin>>n>>m` 后循环 $m$ 次，$m=0$ 不进入 ✓。
8. **无解数据的输出**：按 §1.2 第 3 条，若不存在合法两块，`ans` 保持 $0$。官方数据保证有解（$M\le N^2-2$ 且实际出题保证），不做额外处理。

### 2.7 按规模分类：其它做法与它们的失效点

**(a) 暴力配对（理论上可作为"标准答案"）**：枚举两块 $(p,y,k)$ 与 $(p',y',k')$，用 §2.4 推导中的非空判据 $O(1)$ 判交：

$$A\cap B\ne\varnothing\iff b^*\ge\max\Big(1,\Big\lceil\frac{l^*+1}{2}\Big\rceil,\Big\lceil\frac{l^*-r^*}{2}\Big\rceil\Big).$$

候选数 $\binom{N+2}{3}$：$N=15$ 时 $680$ 个（$4.6\times10^5$ 对）秒出；$N=20$ 时 $1540$ 个（$2.4\times10^6$ 对）可跑；$N=50$ 时 $19600$ 个（$3.8\times10^8$ 对）开始吃紧；$N=100$ 时 $171700$ 个（$2.9\times10^{10}$ 对）必然超时。
它是 $O(N^6)$，只能覆盖小数据。**本文未运行任何程序，所以 (a) 只作为"若有条件应如何对拍"的方案列出，不作为验证结论。**

**(b) 只枚举水平切口**（复杂度也是 $O(N^3)$，但把三族退化成一族）：被 §2.8 的测试 1 直接打穿 —— $N=2$、两块都在第二行，水平线分不开，(b) 输出 $0$，正确答案是 $2$；测试 4 则是"水平线 + 平行左边都不够、只有 $c$ 族能分"的例子（(b) 得 $5$，真答案 $8$）。注意 (b) 的错法在实现上和正解只差一层循环方向，是最隐蔽的 WA。

**(c) 本文正解**：三族各做一遍"分桶 + 前缀/后缀 $\max$"，$O(N^3)$ 时间、$O(N^2)$ 空间，$N=100$ 时约 $5\times10^5$ 次 $O(1)$ 操作。

**(d) 若要压常数**：一次枚举同时更新 $6$ 个桶（三族的 `hi/lo`），把三重循环从 $3$ 遍减到 $1$ 遍；`fill_n` 也从 $6$ 次减到 $6$ 次（不变）。

**(e) 若 $N$ 变大（例如 $2000$）**：枚举所有三角形本身就是 $O(N^3)$ 的瓶颈，能否压到 $O(N^2)$ 取决于"同一顶点的不同 $k$ 是否都要入桶"。
$c$ 族：$\max=r=y-2p$ **与 $k$ 无关**，同一顶点的所有 $k$ 落进同一个 `hi[r]` 桶，只需保留最大面积 $s[p][y]^2$；$\min=l-2b$ 随 $k$ 递减，最坏仍是 $O(N^3)$。
$X,Y$ 族：$\max$ 随 $k$ 严格递增（$b=p+k-1$、$y+2(k-1)$），面积也随 $k$ 递增，中间每个 $k$ 都服务一段不同的切口 $t$，**无法只留端点**。
所以 $O(N^3)$ 在本题规模是合适且够用的，写解时把这条边界说清即可，不必过度优化。

## 3. 模式总结（Pattern Summary）

按真实思考顺序，一条一个技巧，重复出现的同类步骤拆开写：

- 探索性质 — 把"正立子三角形"翻译成"第 $p+t$ 行占连续列 $[y,y+2t]$"，并证明"顶点合法 $+\ b\le N$ ⟹ 整个三角形在图内"。
- 建立相邻关系表 — 先把 $\Delta(X,Y)$ 下方三兄弟 $(X+1,Y),(X+1,Y+1),(X+1,Y+2)$ 钉死，后面所有分解都靠它。
- 简化版 — 剥掉"两块"，先解"只裁一块"。
- 扩大状态定义域 — 把 $R(x,y,k)$ 的 $y$ 放开到奇偶都行，好让"偏移 1"的子块有状态可依；枚举时再收回只取奇列。
- 经典解法（DP）— 三叉分解 + 逐层递推 $s=1+\min(\text{下三兄弟})$，$O(N^2)$ 求出所有最大干净三角形。
- 剖析贪心失败 — 用 $N=3,M=0$、$N=2,M=0$ 说明"先取最大块"会得到非法解。
- 剖析双枚举失败 — 候选 $\binom{N+2}{3}$ 个，两两配对 $O(N^6)$ 太大，说明需要结构性质而非硬枚举。
- 反例否证直觉 — 用 $N=5$ 的具体两块推翻"不相交必被水平线分开"。
- 半平面（固定方向族）表示 — 三角形写成三个方向的区间约束之交 $\{X\le b,Y\ge l,c\le r\}$，把形状信息压缩成 3 个数。
- 归约（交集封闭性）— 两个同型区域的交仍是同型区域，于是"不相交"变成"一个三元组区域为空"。
- 定理证明（枚举子情形 + 自相矛盾排除）— 空区域的两种成因各推出一个方向的严格分离，4/6 子情形可行、2 个自相矛盾。
- 经典解法（分桶 + 前缀/后缀最大值）— 每个方向族上把"两块被线分开"写成 $\max(v_A)\le t<\min(v_B)$，桶 $\to$ 前缀/后缀 $\max$ 求两段最优。
- 重复应用同一技巧 — 上述"分桶 + 前缀/后缀"对 $X,Y,c$ 三族**各做一遍**（三次独立过程，不是一个过程三个副产品），再取最大。
- 归约到更简单问题 — 二维裁剪问题 $\to$ 3 个一维分割点问题。
- 哨兵/单位元检查 — $0$ 既是"不存在"也是 $\max$ 的单位元，但相加前必须两侧都 $>0$，否则会把"只裁一块"当成合法答案。
- 下标平移 — 出现负坐标族（$c\in[1-2N,-1]$）时整体 $+2N$ 以便用数组下标，且不改变分割语义。
- 手算验证 — 无官方样例时，用自造小数据复刻 DP 表与桶轨迹，并专门造"唯一 $c$ 族可分"与"无合法两块"两种边界。

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 初始化 / 取值范围 |
|---|---|---|
| `n`,`m` | 题面的 $N$（边长＝行数）与 $M$（被咬单元数） | 读入；$1\le n\le100$，$0\le m\le n^2-2$ |
| $(X,Y)$ | 单元坐标：行 $1..n$，列 $1..2X-1$；$Y$ 奇为 $\Delta$、偶为 $\nabla$ | 读入原样，**不**转 0-based（题面坐标本身就是 $1$-based，转了反而容易错，见 §4.4） |
| `bad[x][y]` | 单元 $(x,y)$ 是否被咬 | 全局默认 `false`；读入置 `true` |
| $T(p,y,k)$ / 三角形 | 顶角 $(p,y)$（$y$ 奇）、边长 $k$ 的正立块，第 $p+t$ 行占 $[y,y+2t]$，面积 $k^2$ | $1\le k\le s[p][y]$ |
| $R(x,y,k)$ | 同上形状但 $y$ 可奇可偶，纯几何区域（辅助定义） | $k\le n-x+1$ |
| `s[x][y]` | 最大的 $k$ 使 $R(x,y,k)$ 全干净且不出围巾；**只有 $y$ 为奇数时它才等于"以 $(x,y)$ 为顶角的最大围巾边长"** | 全局默认 $0$；$x=n+1$ 行保持 $0$ 充当"越界封顶"；$0\le s\le n+1-x$ |
| $b=p+k-1$ | 三角形底行（$\max X$） | $p..n$ |
| $l=y$ | 最小列（$\min Y$） | $1..2n-1$（奇） |
| $r=y-2p$ | 最大 $c$，$c\le-1$ 恒成立 | $1-2n..-1$ |
| `fam` | 方向族编号：$0=X$（水平线）、$1=Y$（平行左边）、$2=c=Y-2X$（平行右边） | $0..2$ |
| `mn`,`mx` | 当前三角形在 `fam` 族坐标上的最小/最大值（$c$ 族已整体 $+2n$ 平移） | $1..2n-1$ |
| `hi[v]` | 暂存"$\max$ 恰为 $v$"的三角形最大面积；做完前缀 $\max$ 后 = "$\max\le v$ 的三角形最大面积"，$0$ 表示不存在 | 每族开始前 `fill_n(hi,mxv,0)` |
| `lo[v]` | 暂存"$\min$ 恰为 $v$"的最大面积；做完后缀 $\max$ 后 = "$\min\ge v$ 的最大面积"，$0$ 表示不存在 | 同上 `fill_n` |
| $t$ | 切口（族坐标阈值）：左块 $\max\le t$、右块 $\min\ge t+1$ | $1..2n-1$ |
| `ans` | 目前最好的两块面积和 | $0$ 起 |

助记：`hi` = "high end 不越过 $t$"（前缀），`lo` = "low end 不低于 $t+1$"（后缀）；`s` = side（边长）。

### 4.2 步骤

1. 读入 $n,m$ 与 $m$ 个被咬坐标，置 `bad[x][y]=true`。
2. **自底向上算单块 DP**：`for x=n..1`，`for y=1..2x-1`：`s[x][y]=bad[x][y]?0:1+min({s[x+1][y],s[x+1][y+1],s[x+1][y+2]})`（引理 2、3；第 $n+1$ 行全 $0$ 自动封顶）。
3. 令 `ans=0`。对 `fam=0,1,2` 各执行 4–7（三次独立过程）：
4. `fill_n(hi,mxv,0)`、`fill_n(lo,mxv,0)`。
5. **枚举所有干净三角形** $(p,y,k)$：$p=1..n$，$y=1,3,\dots,2p-1$，$k=1..s[p][y]$；面积 `area=k*k`；按族算
 $\text{fam0}:(\max,\min)=(b,\,p)$，$\text{fam1}:(y+2(k-1),\,y)$，$\text{fam2}:(y-2p+2n,\,y-2b+2n)$；
 更新 `hi[mx]`、`lo[mn]`。
6. `hi` 沿下标递增做前缀 $\max$；`lo` 沿下标递减做后缀 $\max$。
7. 枚举 $t=1..2n-1$：仅当 `hi[t]` 与 `lo[t+1]` **都非 $0$** 时 `ans=max(ans,hi[t]+lo[t+1])`。
8. 输出 `ans`。

### 4.3 复杂度与正确性

- 时间：DP $O(N^2)$；第 5 步 $\sum_p p\cdot s[p][\cdot]\le\binom{N+2}{3}=O(N^3)$（$N=100$ 时 $171700$），乘 $3$ 族；第 6–7 步 $O(N)$。合计 $O(N^3)$。
- 空间：`bad`、`s` 各 $O(N^2)$（$105\times215$ 的 `int` 约 $88$ KB，`bool` 另 $22$ KB），`hi`、`lo` $O(N)$。
- 正确性：单块枚举完整（引理 1 + 引理 3）；配对的合法性与完备性由 §2.4 定理（双向）保证；$\text{cut}(t)$ 的正确性由引理 5 保证。

## 5. 示例代码

C++17，按 `coding-style-guide.md`：`#include<bits/stdc++.h>` 单头、`using namespace std;` 紧跟、`using i64=long long;`、全局静态数组、`constexpr int mxn{...}`（$+5$ 松弛）、Tab 缩进、运算符两侧不空格、换行用 `'\n'`、`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);` 固定顺序（指南 §10 明确 `cin.tie` 在前）、每族开始前对桶数组 `fill_n(...,0)` 显式重置（多阶段复用同一全局数组，不依赖"上一次留下的值"）。

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};            // N<=100, +5 slack
constexpr int mxv{2*mxn+5};        // column / shifted c index, <=2N+1

int n,m;
bool bad[mxn][mxv];                // bad[x][y]: unit (x,y) has been bitten
int s[mxn][mxv];                   // s[x][y]: max side of clean region R(x,y,*)
int hi[mxv],lo[mxv];               // best area bucketed by max / min key of one family

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,x,y;i<m;++i)
	{
		cin>>x>>y;
		bad[x][y]=true;
	}

	//bottom-up DP, row n+1 stays 0 and works as the "cannot grow" sentinel
	//notice s is defined for every y; only y odd gives a real scarf
	for(int x=n;x>=1;--x)
		for(int y=1;y<=2*x-1;++y)
			s[x][y]=bad[x][y]?0:1+min({s[x+1][y],s[x+1][y+1],s[x+1][y+2]});

	int ans=0;
	//family 0:X(horizontal) 1:Y(parallel to left side) 2:c=Y-2X(parallel to right side)
	//two pieces are disjoint iff one family separates them
	for(int fam=0;fam<3;++fam)
	{
		fill_n(hi,mxv,0);
		fill_n(lo,mxv,0);
		for(int p=1;p<=n;++p)
			for(int y=1;y<=2*p-1;y+=2)            //odd y only, +=2 is not +=1
				for(int k=1;k<=s[p][y];++k)
				{
					int b=p+k-1,area=k*k,mn,mx;
					if(fam==0)
					{
						mx=b;
						mn=p;
					}
					if(fam==1)
					{
						mx=y+2*(k-1);
						mn=y;
					}
					if(fam==2)                     //c in [1-2n,-1], shift by 2n
					{
						mx=y-2*p+2*n;
						mn=y-2*b+2*n;
					}
					hi[mx]=max(hi[mx],area);
					lo[mn]=max(lo[mn],area);
					// cerr<<fam<<' '<<p<<' '<<y<<' '<<k<<' '<<mn<<' '<<mx<<'\n';
				}
		for(int i=1;i<2*n;++i)
			hi[i]=max(hi[i],hi[i-1]);             //hi[t]: best area with max<=t
		for(int i=2*n-1;i>=1;--i)
			lo[i]=max(lo[i],lo[i+1]);             //lo[t]: best area with min>=t
		for(int t=1;t<2*n;++t)
			if(hi[t]&&lo[t+1])                    //both sides must hold a real piece
				ans=max(ans,hi[t]+lo[t+1]);
	}

	cout<<ans<<'\n';
	return 0;
}
```
