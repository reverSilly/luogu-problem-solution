# P1963 [NOI2009] 变换序列

## 1. 重新读题

### 1.1 问题重述（人话版）

给定 $N$ 和每个 $i$ 的“距离”$D_i$。要构造一个排列 $T_0,T_1,\dots,T_{N-1}$（即 $T$ 是 $0\sim N-1$ 的一个排列，每个数恰好出现一次），满足对每个 $i$，
$$
D(i,T_i)=D_i,\qquad D(x,y)=\min\{|x-y|,\ N-|x-y|\}.
$$
若有多解，输出字典序最小的 $T$；无解输出 `No Answer`。

### 1.2 关键约束与规模暗示

- $N\le 10^4$。$30\%$ 数据 $N\le 50$、$60\%$ 数据 $N\le 500$，这几档可以承受指数/高次多项式；满档需要 $O(N^2)$ 左右。
- 每个 $i$ 的候选值最多只有两个：在长度为 $N$ 的环上，与 $i$ 环形距离为 $D_i$ 的点正是
$$
(i+D_i)\bmod N,\qquad (i-D_i)\bmod N .
$$
  这就是“左边度数 $\le 2$”的二分图，是本题所有结构性质的来源。
- “$T$ 是排列”意味着左侧 $N$ 个位置与右侧 $N$ 个值之间要建立**完美匹配**。于是本题是二分图匹配 + 字典序最小。
- 若 $D_i=0$，或 $N$ 为偶数且 $D_i=N/2$，两个候选重合，退化为度数 $1$。

---

## 2. 思维链（Chain-of-thought）

### 2.1 把问题翻译成二分图完美匹配

建二分图：左部是位置 $i\in\{0,\dots,N-1\}$，右部是取值 $v\in\{0,\dots,N-1\}$。若 $v$ 是 $i$ 的合法候选，就连边 $i-v$。

**引理 1**：一个序列 $T$ 是满足距离条件的合法变换，当且仅当边集 $\{(i,T_i)\}$ 是该二分图的一个完美匹配。

**证明**：

- （$\Rightarrow$）每个 $i$ 有 $T_i$ 是它的候选，故 $(i,T_i)$ 是边；$T$ 是排列说明不同的 $i$ 对应不同的 $T_i$，且 $N$ 个值正好用满，所以每个左点、每个右点都恰好被一条边覆盖，是完美匹配。
- （$\Leftarrow$）完美匹配给每个左点 $i$ 唯一匹配的右点，令 $T_i$ 为它；边存在保证 $D(i,T_i)=D_i$；完美匹配中右点互不相同，故 $T_i$ 两两不同，是排列。$\square$

问题于是变成：**求字典序最小的完美匹配**；不存在完美匹配则输出 `No Answer`。

### 2.2 先判存在性：任意找一个完美匹配

先不管字典序，随便找一个完美匹配即可。用匈牙利（Kuhn）算法：从某个左点出发，在“交替路”上寻找增广路；找到就翻转，匹配数加一。

为了让“找不到就说明无解”这件事有严格保证，我们**按 $i=N-1,N-2,\dots,0$ 的倒序**依次增广。

**引理 2（倒序增广不会误判无解）**：若图中存在完美匹配，则倒序对每个左点增广时都一定能找到增广路；若某一步失败，则图中不存在完美匹配。

**证明**：

先陈述并证明要用到的方向：**若在某个子图里匹配 $M_1$ 的边数少于匹配 $M_2$，则 $M_1\triangle M_2$ 中存在一条关于 $M_1$ 的增广路。**
把 $M_1\triangle M_2$ 分解成若干条交替路和交替偶环（同一个顶点的两条关联边分别来自 $M_1,M_2$，度不超过 $2$）。由于 $|M_2|>|M_1|$，至少有一条交替路含 $M_2$ 边比 $M_1$ 边多一条。这样一条路的两端只能是 $M_1$ 未匹配的点，且首尾边都来自 $M_2$；沿它翻转就能把 $M_1$ 增大一条边，它正是关于 $M_1$ 的增广路。

现在归纳。设处理到 $i$ 之前，当前匹配 $M$ 已经饱和了左点 $\{i+1,\dots,N-1\}$（这正是倒序逐步建立的不变式）。

- 若全图有完美匹配 $M^*$，把 $M^*$ 限制在“左点 $\{i,\dots,N-1\}$ 与全部右点”这个子图上，它仍然是一个匹配，并且比 $M$ 多饱和一个左点 $i$，因此边数更多。由上一段，$M\triangle M^*$ 中存在关于 $M$ 的增广路。又因为 $M$ 已饱和 $\{i+1,\dots,N-1\}$，这条增广路的左端点只能是 $i$（其余左点都已被 $M$ 匹配），于是从 $i$ 出发的增广搜索必然成功。
- 反过来，如果算法对全部 $N$ 个左点都成功，就得到了饱和所有左点的匹配，也就是完美匹配；所以只要有任何一步失败，就不存在完美匹配。

$\square$

这段倒序增广只是“找任意完美匹配”，与字典序无关；但它同时给出了无解的判定。

### 2.3 字典序最小：逐位贪心 + 残量网络判定

字典序最小意味着**优先决定下标小的位置**。于是从 $i=0$ 到 $N-1$ 依次处理：在保证“前面的选择都固定不变”的前提下，把 $T_i$ 改成尽可能小的候选值。

难点是：改了 $T_i$ 之后，原来占用这个值的左点要另找位置，而且不能影响已经固定的前缀。我们把这一步写成一次“残量网络上的增广”。

设当前维护的匹配 $M$ 是一个完美匹配，并且已经满足 $M(j)=T^*_j$（$j<i$，$T^*$ 是正在构造的答案前缀）。令
$$
cur=M(i),\qquad v<cur \text{ 是 } i \text{ 的一个候选}.
$$
因为 $M$ 是完美匹配，右点 $v$ 一定被某个左点占用，记
$$
j=M^{-1}(v).
$$

**引理 3（可行性判定）**：存在一个完美匹配 $C$，满足
$$
C(j)=T^*_j\ (j<i),\qquad C(i)=v,
$$
当且仅当下述“残量网络”中存在一条从 $j$ 到 $cur$ 的交替路：

> 把左点 $0,1,\dots,i$ 全部“冻结”（它们的匹配边不许再动，$i$ 已固定为 $v$），只允许左点 $i+1,\dots,N-1$ 重新匹配。先把 $i$ 与 $cur$、$j$ 与 $v$ 解绑，再把 $i$ 匹配到 $v$；于是 $cur$ 成为唯一的自由右点、$j$ 成为唯一未匹配的左点。从 $j$ 出发，沿“非匹配边—匹配边—非匹配边—……”走，若能到达自由右点 $cur$，就翻转这条路上的所有边。

**证明**：

（$\Leftarrow$）若存在这样一条增广路，翻转它：$j$ 及路上每个被顶替的左点都重新匹配，最后 $cur$ 被匹配；$i$ 已匹配到 $v$；左点 $\le i$ 中只有 $i$ 的边被改动。于是得到一个完美匹配 $C$，且前缀 $0\sim i-1$ 原封不动、$C(i)=v$。

（$\Rightarrow$）若存在这样的 $C$。考虑 $M$ 与 $C$ 的对称差。两者都是完美匹配，所以对称差分解成若干个交替偶环。对任意左点 $j<i$，已有 $M(j)=C(j)=T^*_j$，这条边在对称差中不出现，故含 $i$ 的那个交替环里不会出现 $<i$ 的左点。该环包含 $i$：它从 $i$ 出发有一条 $M$ 边 $i-cur$，还有一条 $C$ 边 $i-v$。删去左点 $i$ 及其两条入射边后，剩下一条从右点 $v$ 到右点 $cur$ 的交替路；而 $v$ 在 $M$ 中匹配到 $j$，因此从 $j$ 出发、沿这条交替路的“左—右—左—……”方向，就得到一条从 $j$ 到 $cur$ 的交替路。路上除 $i$ 外的左点都来自那个环，因此都 $>i$，正好落在允许重排的范围内。$\square$

如果 $j<i$（即 $v$ 已被一个更靠前、已固定的位置占用），那么 $v$ 不可能再给 $i$ 用（否则破坏了字典序已确定的前缀），直接跳过这个候选。

DFS 从 $j$ 出发，枚举 $j$ 的每条边 $j-w$：若 $w$ 是自由右点（只能是 $cur$）则成功；否则 $w$ 被某左点 $l$ 占用，若 $l>i$ 就递归尝试把 $l$ 改到别处，若 $l\le i$ 则这条边被冻结、不能用。对右点打访问标记保证每个点只访问一次，因此 DFS 穷尽了所有可达情形，**找得到路当且仅当引理 3 的路存在**。

### 2.4 贪心为什么给出字典序最小

**引理 4（逐位贪心正确）**：按 $i=0,1,\dots,N-1$ 处理，第 $i$ 步在所有候选中取“能保持前缀固定并完成完美匹配”的最小值，最终得到的就是字典序最小的完美匹配。

**证明**（对 $i$ 归纳）：设 $T^*$ 是真正的字典序最小解。归纳假设当前匹配 $M$ 已满足 $M(j)=T^*_j$（$j<i$），即前缀已经和最优解一致。

由字典序的定义，$T^*_i$ 恰好是“在固定前缀 $T^*_0..T^*_{i-1}$ 后，能让整个图仍有完美匹配的最小候选值”。当前匹配 $M$ 本身就是一个完美匹配，所以至少 $cur=M(i)$ 是可行的，最小可行值不超过 $cur$。我们按升序尝试候选 $v<cur$，引理 3 精确判定 $v$ 是否可行；取第一个可行的 $v$（若都不可行就保留 $cur$），就是 $T^*_i$。更新后的匹配仍是完美匹配且前缀扩展到 $i$ 都与 $T^*$ 一致。归纳成立，处理完所有位置后 $M=T^*$。$\square$

### 2.5 复杂度

- 初始倒序匈牙利：每轮一次 $O(N)$（左点度数 $\le2$，边数 $O(N)$）的 DFS，共 $O(N^2)$。
- 贪心：每个位置最多试 $2$ 个候选，每个候选一次 $O(N)$ 的交替路 DFS，共 $O(N^2)$。
- 总计 $O(N^2)$，$N=10^4$ 时约 $10^8$ 级别的朴素操作，实测运行极快；空间 $O(N)$。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 每个位置只有 $\pm D_i$ 两个候选，是左度 $\le2$ 的二分图。
- **reduce to easier problem** — “合法变换”等价于“完美匹配”。
- **classic problem solution** — 倒序匈牙利求任意完美匹配，同时判定无解（Berge 增广路）。
- **defer reconstruction / greedy by position** — 按字典序从前往后逐位确定。
- **residual network** — 固定前缀，把允许重排的左点看作残量网络，判定候选是否可行。
- **exchange / symmetric difference** — 用两个完美匹配的对称差分解证明增广路判定的充要性。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 序列长度 | 读入 | $\le 10^4$ |
| `g[i]` | `vector<int> [10005]` | 位置 $i$ 的候选值，升序 | 构造 | graph |
| `matchL[i]` | `int [10005]` | 左点 $i$ 当前匹配的右点 | $-1$ | match left |
| `matchR[v]` | `int [10005]` | 右点 $v$ 当前匹配的左点 | $-1$ | match right |
| `seen[v]` | `bool [10005]` | 本轮 DFS 中右点是否访问过 | false | visited |
| `blockid` | `int` | 冻结边界：左点 $\le blockid$ 不许动 | 当前 $i$ | frozen block |
| `cur` | `int` | 当前 $T_i$ | `matchL[i]` | current |
| `j` | `int` | 候选 $v$ 当前占用的左点 | `matchR[v]` | displaced |

### 4.2 算法步骤

1. 读入 $N$ 与 $D_i$，计算两个候选 $a=(i+D_i)\bmod N$、$b=(i-D_i)\bmod N$，去重后升序存入 `g[i]`。
2. **判存在性 / 初始完美匹配**：`matchL=matchR=-1`；对 $i=N-1$ 递减到 $0$，清空 `seen` 后调用 `kuhn(i)`。若某次失败，输出 `No Answer` 并结束。
3. **逐位贪心**：对 $i=0$ 到 $N-1$：
   1. `cur=matchL[i]`，`blockid=i`；
   2. 按升序遍历 `g[i]` 中满足 $v<cur$ 的候选：
      1. `j=matchR[v]`；若 `j<i`，该值属于已冻结前缀，跳过；
      2. 解绑 $i$ 与 $cur$、$j$ 与 $v$，再令 $i$ 匹配 $v$；
      3. 清空 `seen`，调用 `aug(j)`：若成功（找到 $j\to cur$ 的交替路），本位置确定，跳出候选循环；
      4. 否则回滚：$i$ 匹配回 $cur$、$j$ 匹配回 $v$，继续下一个候选。
   3. 所有更小候选都不行时保持 $cur$。
4. 输出 `matchL[0..N-1]`，空格分隔。

其中 `aug(u)` 在“左点 $>blockid$ 才可动、右点 $cur$ 为唯一自由点”的残量网络上做 DFS；`kuhn(u)` 是标准的匈牙利增广。

### 4.3 复杂度分析

- 时间：初始 $N$ 次 DFS，贪心每位置 $\le2$ 次 DFS，每次 $O(N+E)=O(N)$（$E\le2N$），总计 $O(N^2)$。
- 空间：邻接表 $O(N)$、匹配数组与访问数组 $O(N)$，总计 $O(N)$。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int n;
vector<int>g[mxn];
int matchL[mxn],matchR[mxn];
bool seen[mxn];
int blockid;

bool aug(int u)
{
	for(int v:g[u])
	{
		if(seen[v])
			continue;
		seen[v]=true;
		if(matchR[v]==-1)
		{
			matchL[u]=v;matchR[v]=u;
			return true;
		}
		int l=matchR[v];
		if(l<=blockid)          // 前缀与 i 已冻结
			continue;
		if(aug(l))
		{
			matchL[u]=v;matchR[v]=u;
			return true;
		}
	}
	return false;
}

bool kuhn(int u)
{
	for(int v:g[u])
	{
		if(seen[v])
			continue;
		seen[v]=true;
		if(matchR[v]==-1||kuhn(matchR[v]))
		{
			matchR[v]=u;matchL[u]=v;
			return true;
		}
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0,d;i<n;++i)
	{
		cin>>d;
		int a=(i+d)%n,b=(i-d%n+n)%n;
		if(a!=b)
			g[i].push_back(a),g[i].push_back(b);
		else
			g[i].push_back(a);
		sort(g[i].begin(),g[i].end());
	}
	for(int i=0;i<n;++i)
		matchL[i]=matchR[i]=-1;
	for(int i=n-1;i>=0;--i)     // 倒序增广：先拿到任意完美匹配，同时判无解
	{
		fill_n(seen,n,false);
		if(!kuhn(i))
		{
			cout<<"No Answer\n";
			return 0;
		}
	}
	for(int i=0;i<n;++i)        // 逐位确定字典序最小
	{
		int cur=matchL[i];
		blockid=i;
		for(int v:g[i])
		{
			if(v>=cur)
				break;
			int j=matchR[v];
			if(j<i)
				continue;
			matchL[i]=-1;matchR[cur]=-1;
			matchL[j]=-1;matchR[v]=-1;
			matchL[i]=v;matchR[v]=i;
			fill_n(seen,n,false);
			if(aug(j))
				break;
			matchL[i]=cur;matchR[cur]=i;
			matchL[j]=v;matchR[v]=j;
		}
	}
	for(int i=0;i<n;++i)
	{
		cout<<matchL[i];
		if(i+1<n)
			cout<<' ';
	}
	cout<<'\n';
	return 0;
}
```
