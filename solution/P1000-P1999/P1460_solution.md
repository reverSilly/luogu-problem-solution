# P1460 [USACO2.1] 健康的荷斯坦奶牛 Healthy Holsteins

> 标签：搜索 / DFS / BFS / 状态压缩 · 难度：普及-

## 1. 重新读题

**问题重述（形式化）**

- 有 $v$ 种维他命，每天最低需求向量 $a=(a_1,\dots,a_v)$，$a_j\in[1,1000]$。
- 有 $g$ 种饲料，第 $i$ 种是向量 $c_i=(c_{i,1},\dots,c_{i,v})$，$c_{i,j}\in[1,1000]$。
- **每种饲料最多用一次**（这是"0-1 选择"而不是"完全背包"式可重复使用）。
- 选下标集 $S\subseteq\{1,\dots,g\}$，其供给向量为 $\sum_{i\in S}c_i$。

求满足

$$\forall j\in[1,v]:\ \sum_{i\in S}c_{i,j}\ \ge\ a_j$$

的 $S$ 中 $|S|$ 最小者；并列时输出**编号升序列表的字典序最小**者。输出格式：先 $p=|S|$，再按从小到大输出 $p$ 个编号，同一行空格分隔。

**数据范围**

| 量 | 上界 | 由此得到的粗算 |
|---|---|---|
| $v$（维他命种数） | $25$ | 单次可行性判定内层 $O(v)$ |
| $g$（饲料种数） | $15$ | 子集总数 $2^{15}=32768$ |
| 每个整数值 | $1000$ | 单维供给和最大 $15\times1000=15000$ |

**题面给的三条关键信息，逐条消化**

1. "数据保证存在解"：由引理 1（下节）全集合 $\{1,\dots,g\}$ 可行，故 $best$ 必被赋值，无须无解分支。
2. "每种饲料最多只能使用一次"：状态是子集而非多重计数 → 位掩码 / 组合枚举，规模仅 $2^g$。
3. "输入的所有整数在 $[1,1000]$"：$a_j\ge1$ 使空集供给 $0<a_j$ **必不可行**，枚举从 $m=1$ 起；$g\le15$ 使答案 $p\le15$；$c_{i,j}\ge1$ 是下节单调性的全部来源。

**"字典序最小"的精确含义（坑点，§2.5 会证明判定式）**：题面说"如果有多个解，输出饲料序号最小的（即字典序最小）"，而输出又要求"按从小到大排列"，于是每个解唯一对应一个**严格递增**的长度 $p$ 序列，比较对象是这个序列。例如 $p=2$ 时 $\{1,4\}$ 优于 $\{2,3\}$（首位 $1<2$）。它**不是**掩码数值序，§2.5 会把两种序精确区分。

**题目类别说明**：本题属"搜索 + 组合优化"，不含几何，故"旋转 + 向量平移"类的三次旋转合成顺序 / 矩阵形式 / 二分半径单调性等检查项对本题不适用；本文对"精确形式"的要求落在 §2.5 的字典序判定引理与 §4 的复杂度、手算验证上。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：可行族的向上封闭性

先看"加饲料"这个动作对可行性的影响，这是唯一免费的结构性信息。

**引理 1（向上封闭 / 单调性）**
若 $S$ 可行且 $S\subseteq T\subseteq\{1,\dots,g\}$，则 $T$ 可行。

**证明**：可行性要求对每个 $j$ 有 $\sum_{i\in S}c_{i,j}\ge a_j$。因为题面保证"输入的所有整数在 $[1,1000]$"，故 $c_{i,j}\ge 1>0$。于是

$$\sum_{i\in T}c_{i,j}=\sum_{i\in S}c_{i,j}+\sum_{i\in T\setminus S}c_{i,j}\ \ge\ \sum_{i\in S}c_{i,j}\ \ge\ a_j$$

对每个 $j$ 都成立，故 $T$ 可行。$\blacksquare$

注意证明里 $c_{i,j}>0$ 用到了题面的下界 $1$。若允许负数（例如"某种饲料反而破坏维他命"），引理 1 立刻失效，整题会从"子集枚举 + 单调剪枝"变成带负权的整数规划。**读题时把 $[1,1000]$ 的下界读成"非负性"，是本题性质的来源。**

**结论 A**：可行集族 $\mathcal F=\{S:\textstyle\sum_{i\in S}c_i\ge a\}$ 是偏集族 $(2^{[g]},\subseteq)$ 上的**向上闭集（滤子 / upset）**：一旦进入 $\mathcal F$，沿 $\subseteq$ 方向怎么走都不出去。于是"最小饲料种数"问题等价于：

$$p^\*=\min\{|S|:S\in\mathcal F\}=\min\{p:\ \mathcal F\cap\binom{[g]}{p}\ne\varnothing\}$$

即**按基数分层**，从 $p=0$ 往上找，第一个非空层就是答案层——这立刻给出算法骨架（§2.4）。

**但有一个陷阱要先拆掉**：向上闭族里有两个不同的"最小"——按**包含**极小（$S\in\mathcal F$ 且去掉任一元素后不可行，inclusion-minimal）与按**基数**最小（$|S|=p^\*$）。引理 2 说明两者不重合，于是"DFS 里一满足就停"这类不分层的搜索可能给出包含极小但基数更大的解。

**引理 2（包含极小元可以比最优解大）**
存在实例，其某个包含极小可行集的基数严格大于 $p^\*$。

**证明（构造）**：$v=2$，$a=(10,10)$，$g=3$，$c_1=(10,10)$，$c_2=(6,6)$，$c_3=(6,6)$。
- $\{1\}$ 可行（恰好 $=(10,10)$），且 $\varnothing$ 不可行，故 $\{1\}$ 是包含极小元，基数 $1$。
- $\{2,3\}$ 供给 $(12,12)\ge(10,10)$ 可行；去掉 $2$ 剩 $(6,6)$ 不可行，去掉 $3$ 同理，故 $\{2,3\}$ **也是**包含极小元，基数 $2>p^\*=1$。$\blacksquare$

可见"极小"不唯一、也不同尺寸，**只有按基数分层才能锁死最优性**，这将 §2.4 的做法固定在"分层枚举"而不是"走到叶子就算"。

### 2.2 简化版：$v=1$ 时的闭式解

把多维砍成一维：只有一种维他命，需求 $a$，饲料含量 $x_1,\dots,x_g>0$，每种最多用一次。问题变成"选最少的数使和 $\ge a$"。

把 $x$ 降序排列，记排列后为 $b_1\ge b_2\ge\cdots\ge b_g$（$b$ 是 $x$ 的一个排列），前缀和 $B_k=\sum_{t=1}^{k}b_t$，约定 $B_0=0$。

**引理 3（$k$ 元子集和的上界 = 前 $k$ 大之和）**
对任意 $k$ 元下标集 $S$（$1\le k\le g$），有 $\sum_{i\in S}x_i\le B_k$。

**证明**：把 $S$ 中的值降序记为 $s_1\ge s_2\ge\cdots\ge s_k$，逐个证明 $s_m\le b_m$（$m=1,\dots,k$）。
反设存在最小的 $m$ 使 $s_m>b_m$。因为 $b$ 已降序，下标 $t\ge m$ 处有 $b_t\le b_m$，所以整个多重集 $\{b_1,\dots,b_g\}=\{x_1,\dots,x_g\}$ 中**严格大于** $b_m$ 的元素至多 $m-1$ 个（只能来自 $b_1,\dots,b_{m-1}$）。
但 $s_1\ge s_2\ge\cdots\ge s_m>b_m$ 给出了 $S$ 中 $m$ 个严格大于 $b_m$ 的元素，而 $S$ 的元素都取自同一个多重集，矛盾。
故 $s_m\le b_m$ 对所有 $m$ 成立，求和得 $\sum_{i\in S}x_i=\sum_{m=1}^{k}s_m\le\sum_{m=1}^{k}b_m=B_k$。$\blacksquare$

**定理 1（$v=1$ 的闭式解）**
$$p^\*=\min\{k\in[0,g]:B_k\ge a\}\stackrel{\text{记}}{=}k_0 .$$

**证明**：由"数据保证存在解"有某 $S$ 可行，再用引理 1（向上封闭，对 $v=1$ 同样适用）取 $T=$ 全集合得 $B_g=\sum_{i=1}^{g}x_i\ge a$，故集合非空、$k_0$ 良定义；又 $a\ge1>B_0$，故 $k_0\ge1$。
- **$p^\*\le k_0$**：取那 $k_0$ 袋（含量为 $b_1,\dots,b_{k_0}$ 者），供给和恰为 $B_{k_0}\ge a$，是大小为 $k_0$ 的可行集。
- **$p^\*\ge k_0$**：反设存在可行集 $S$ 使 $|S|=k<k_0$。由 $k_0$ 的最小性 $B_k<a$；由引理 3，$\sum_{i\in S}x_i\le B_k<a$，与 $S$ 可行矛盾。
两向合并得 $p^\*=k_0$。$\blacksquare$

也就是说：$v=1$ 时"每次挑当前含量最大的一袋"这种贪心是对的——因为第 $k$ 步挑满 $k$ 袋所能达到的最大和恰是 $B_k$，一旦 $B_k$ 达标，$k$ 就是最小可能值。

**但这个简化版已经暴露一个输出层面的问题。** 取 $a=10$，$g=4$，$x=(4,3,6,6)$：降序 $b=(6,6,4,3)$，$B=(6,12,\dots)$，故 $p^\*=2$。逐一检验 $2$ 元子集：$\{1,3\}=4+6=10$ ✓、$\{1,4\}=10$ ✓、$\{3,4\}=12$ ✓、$\{1,2\}=7$ ✗、$\{2,3\}=9$ ✗、$\{2,4\}=9$ ✗。字典序最小的可行集是 $\{1,3\}$，而"挑最大两袋"的贪心前缀给出 $\{3,4\}$。
**教训**：贪心至多能给出正确的**基数** $p^\*$，给不出正确的**代表元**；字典序要求我们必须显式比较候选，而不是"取第一个碰到的可行集"。这为 §2.5 埋下问题。

### 2.3 剖析贪心失败

§2.2 的贪心在 $v\ge2$ 时全线崩溃。下面用**一组具体小数据**把三种"看起来很合理"的贪心逐个打死，这组数据同时成为 §4.5 的手算用例 1。

**反例数据 G**：$v=2$，$a=(10,10)$，$g=3$，$c_1=(10,1),\ c_2=(6,6),\ c_3=(1,10)$。
先把真相算出来（枚举全部 $2^3=8$ 个子集）：

| $S$ | 供给 $\sum c_i$ | 可行? | $S$ | 供给 $\sum c_i$ | 可行? |
|---|---|---|---|---|---|
| $\varnothing$ | $(0,0)$ | 否 | $\{1,2\}$ | $(16,7)$ | 否（$7<10$） |
| $\{1\}$ | $(10,1)$ | 否（$1<10$） | $\{1,3\}$ | $(11,11)$ | **是** |
| $\{2\}$ | $(6,6)$ | 否 | $\{2,3\}$ | $(7,16)$ | 否（$7<10$） |
| $\{3\}$ | $(1,10)$ | 否（$1<10$） | $\{1,2,3\}$ | $(17,17)$ | 是（更大） |

故 $p^\*=2$，**唯一**最优解 $\{1,3\}$，正确答案 `2 1 3`。

**贪心 A（按每袋总量降序取前缀）**：总量 $11,12,11$ → 先取 $\{2\}$ 得 $(6,6)$ 不可行；再加 $\{1\}$ 得 $(16,7)$ 仍不可行；再加 $\{3\}$ 得 $(17,17)$ 才可行 → **3 袋，比最优多 1 袋（+50%）**。
**贪心 B（每步最大化被缺口截断的贡献 $g(i)=\sum_j\min(c_{i,j},r_j)$，$r$ 为当前缺口）**：第 1 步 $r=(10,10)$，$g(1)=10+1=11$、$g(2)=6+6=12$、$g(3)=1+10=11$ → 取袋 $2$，$r\leftarrow(4,4)$；第 2 步 $g(1)=\min(10,4)+\min(1,4)=5$，$g(3)=\min(1,4)+\min(10,4)=5$ 并列取袋 $1$，$r\leftarrow(0,3)$；第 3 步只剩袋 $3$（$\min(1,0)+\min(10,3)=3$）→ **3 袋，又错**。
**贪心 C（列优先：先挑最缺维度，再挑该维贡献最大的袋）**：两维相对缺口并列 $1.0$，取第 1 维 → 该维最大是袋 $1$（$10$），$r=(0,9)$；只剩第 2 维 → 剩余候选中袋 $2$ 的 $6>1$，取之，$r=(0,3)$；再取袋 $3$ → **3 袋，又错**。

**为什么必然错（结构原因，不是运气）**：$c_2=(6,6)$ **不属于任何基数最小可行集**（表里基数最小的可行集只有 $\{1,3\}$），贪心的**第一步**就走进死路：$\{2\}$ 扩不成任何 $2$ 袋可行集。贪心正确性需要"每步选择都能扩展成某个全局最优解"（贪心选择性质 + 交换性质），而本题可行族只有向上封闭性（引理 1）、毫无交换性：$\{1,3\}$ 与 $\{2\}$ 都"看起来不错"，却不能把 $2$ 换进 $\{1,3\}$ 的某一格保持可行。把维度当元素、每袋在某维"能否独自填满缺口"当子集，本题即**最小集合覆盖 / 多重覆盖**的特例，精确贪心只存在于 $P=NP$。

**再来一组（不同陷阱，即 §4.5 用例 2）**：$v=2$，$a=(10,10)$，$g=4$，$c=(6,6),(10,1),(1,10),(1,1)$。贪心 B 第 1 步 $g(1)=12$ 最大取袋 $1$，$r=(4,4)$；第 2 步 $g(2)=g(3)=5$ 并列取袋 $2$，$r=(0,3)$；第 3 步取袋 $3$ → $3$ 袋。真相：$2$ 袋可行集只有 $\{2,3\}=(11,11)$ → $p^\*=2$，正确输出 `2 2 3`。

**结论 B（放弃贪心）**：$g\le15\Rightarrow 2^g=32768$，全枚举约 $1.3\times10^{7}$ 次整数运算，比"设计贪心 + 证明 + 发现反例 + 修补"便宜得多。**搜索空间只有 $3\times10^4$ 个点时，精确性应当靠穷举拿到。** 这就是本题标签是"搜索"而不是"贪心"的原因。

### 2.4 经典解法：按规模枚举

结论 B 把我们推向"精确穷举"，引理 1/2 则规定穷举**必须按基数分层**。三条等价路线：

- **路线一（位掩码全枚举 + 显式比较）**：枚举 $m\in[1,2^g)$，bit $i$ = "选第 $i+1$ 号饲料"，对可行 $m$ 按"先基数、后字典序"更新最优。
- **路线二（分层组合 DFS）**：外层 $p=1,2,\dots,g$，内层只枚举大小为 $p$ 的组合，首个可行组合即答案并退出。
- **路线三（逐层 BFS）**：状态是子集，$\varnothing$ 为源点，转移"再添加一袋"，层号即基数；首次弹出可行集时层号就是 $p^\*$。

**引理 4（分层穷举的正确性）**
设 $\mathcal F_p=\mathcal F\cap\binom{[g]}{p}$，$p_0=\min\{p:\mathcal F_p\ne\varnothing\}$。则 $p_0=p^\*$，且 $\mathcal F_{p^\*}$ 中字典序最小者就是题目要求的输出。

**证明**：若存在 $S\in\mathcal F$ 使 $|S|<p_0$，则 $\mathcal F_{|S|}\ne\varnothing$，与 $p_0$ 最小性矛盾，故所有可行 $S$ 满足 $|S|\ge p_0$；取 $S\in\mathcal F_{p_0}$（非空由定义保证）得 $p^\*\le p_0$。两向合并 $p_0=p^\*$。
并列部分：所有最优候选恰是 $\mathcal F_{p^\*}$ 的元素，基数同为 $p^\*$ 故排序后的升序序列两两不同；$\mathcal F_{p^\*}$ 是非空有限集而字典序是全序，故存在唯一最小元，题面要求输出的正是它。$\blacksquare$

**引理 5（路线二/三的前提：生成顺序 = 字典序）**
若 $p$ 元组合由 $\text{dfs}(\text{start},\text{lim})$ 生成，每层用 `for(i=start..g-lim)` **从小到大**试、且下一层只允许更大的下标，则同层内的访问顺序就是升序序列的字典序。

**证明**：对 $\text{lim}$ 归纳。$\text{lim}=0$ 时只剩一个序列，平凡成立。设对 $\text{lim}-1$ 成立。已选前缀固定时，兄弟分支按 $i_1<i_2$ 的先后被访问；$i_1$ 子树内任一序列与 $i_2$ 子树内任一序列，前 $|\text{prefix}|$ 项相同，第 $|\text{prefix}|{+}1$ 项分别是 $i_1,i_2$，故前者字典序更小——符合"第一处差异定序"的定义；子树内部顺序由归纳假设给出。两者拼接即整体为字典序。$\blacksquare$

由此路线二/三"第一个碰到的可行解就是答案"合法；反之把 `for` 改成**从大到小**试，或像路线一那样直接吃掩码数值序（= colex，见 §2.5），都会立刻得到错误算法。**生成顺序 → 字典序**这一环不能凭直觉省略。

**剪枝（均可证不改变答案）**
1. **判定短路**：$ok(m)$ 一旦发现某维不足立即 `return false`——约束之间是 $\land$ 语义，缺一即全局不可行，无须算完剩余维。
2. **基数上界**：路线一中 `popcount(m)>popcount(best)` 直接跳过；路线二首个可行层出现后不再进入更高层。
3. **增量和维护**（把 $O(2^g vg)$ 降到 $O(2^g v)$）：记 $\text{low}(m)=m\&-m$，则 $sum[m][j]=sum[m\oplus\text{low}(m)][j]+c_{\text{bit}(\text{low}(m)),j}$；由 $m\oplus\text{low}(m)<m$ 可按 $m$ 递增递推，正确性是求和的结合律。代价 $2^{15}\times25$ 个 `int`（约 $3.2$ MB）。本题 $1.3\times10^{7}$ 已经足够快，故主代码保留朴素版，把清晰放在微优化前面。

### 2.5 归约与字典序细节

**(a) 归约：为什么本题只能穷举。** 把每袋饲料在第 $j$ 维上"能否独自填满需求"看成集合 $A_i=\{j:c_{i,j}\ge a_j\}$，则"$\bigcup_{i\in S}A_i=[v]$ 且 $|S|$ 最小"正是**最小集合覆盖**；把 $c_{i,j}\ge a_j$ 放宽成"贡献量"就是**多重覆盖**。集合覆盖是经典 NP-hard 问题，所以任何多项式时间的精确贪心/DP 都不该指望（§2.3 的三个贪心全灭不是巧合）。题面把 $g$ 压到 $15$，就是在说："指数算法是本题的**正解**而不是保底方案。" 归约的价值是**定性**的：它告诉我们不必再找更聪明的多项式做法，只需把 $2^{15}$ 的穷举写对——写对的关键恰恰在字典序，见 (b)。

**(b) 掩码数值序 ≠ 字典序（这是本题最常见的 WA 点）。** 先把两种顺序精确刻画。

**引理 6（掩码数值序 = 余字典序 colex）**
设 $S\ne T$，$|S|=|T|$，$d=\max\{i:\ \mathbb 1[i\in S]\ne\mathbb 1[i\in T]\}$ 为最大差异位。则 $\mathrm{mask}(S)<\mathrm{mask}(T)\iff d\in T$（即最大差异位属于 $T$、不属于 $S$）。

**证明**：记 $\Delta=\mathrm{mask}(S)-\mathrm{mask}(T)=\sum_{i}(\mathbb 1[i\in S]-\mathbb 1[i\in T])2^{i-1}$。差异位集合非空，$d$ 是其中最大者，把和拆成 $i=d$ 项与 $i<d$ 项：
- 若 $d\in S\setminus T$，则该项为 $+2^{d-1}$，其余项的绝对值之和至多 $\sum_{i<d}2^{i-1}=2^{d-1}-1<2^{d-1}$，故 $\Delta>0$。
- 若 $d\in T\setminus S$，同理 $\Delta<0$。
两种情形都说明 $\Delta$ 的符号完全由最大差异位的归属决定，即 $\mathrm{mask}(S)<\mathrm{mask}(T)\iff d\in T$。$\blacksquare$

**引理 7（字典序由最小差异位决定）**
设 $S\ne T$，$|S|=|T|$，$t=\min\{i:\mathbb 1[i\in S]\ne\mathbb 1[i\in T]\}$。则 $S$ 的升序列表字典序小于 $T$ $\iff$ $t\in S$。

**证明**：令 $k=|\{i<t:i\in S\}|=|\{i<t:i\in T\}|$（小于 $t$ 的位置上两者特征向量相同，故共有 $k$ 个相同元素）。把两者升序排列为 $s_1<\cdots<s_p$ 与 $u_1<\cdots<u_p$，则 $s_1,\dots,s_k$ 恰是那 $k$ 个公共的、小于 $t$ 的元素，按升序排后的前 $k$ 项，故 $s_i=u_i$（$i\le k$）。
- 若 $t\in S$ 且 $t\notin T$：$s_{k+1}=t$（$S$ 中下一个最小元素就是 $t$，因为没有更小的未被匹配元素）；而 $u_{k+1}>t$（$T$ 在 $\le t$ 处已无元素可选）。故第一处不同是 $s_{k+1}=t<u_{k+1}$，$S$ 字典序更小。
- 若 $t\in T\setminus S$：对称地 $u_{k+1}=t<s_{k+1}$，$T$ 更小。
两方向合起来即 $\blacksquare$

引理 6 与引理 7 的差别就是"**最大**差异位"与"**最小**差异位"，二者不等价。反例（即 §4.5 用例 3）：$v=1$，$a=10$，$g=4$，$x=(4,5,5,6)$。$2$ 袋可行集为 $\{1,4\}=10$、$\{2,3\}=10$、$\{2,4\}=11$、$\{3,4\}=11$（$1$ 袋最大 $6<10$ 不可行），字典序最小是 $\{1,4\}$，正确答案 `2 1 4`；而掩码 $6,9,10,12$ 分别对应 $\{2,3\},\{1,4\},\{2,4\},\{3,4\}$——**按 $m$ 递增"取第一个可行"会拿到 $\{2,3\}$ 并输出 `2 2 3`，错**。`for(m=1..)` 给的是 colex 序，题面要的是 lex 序。

**判定式与它的正确性**。路线一要么改用组合生成（引理 5），要么在 colex 序上**显式**做 lex 比较。代码里的 `lexless` 就是后者：

**引理 8（`lexless` 正确）**
等基数掩码 $m,\text{cur}$ 满足：$m$ 字典序更小 $\iff$ $m\,\&\,(d\&-d)\ne0$，其中 $d=m\oplus\text{cur}$。

**证明**：$d$ 的第 $i$ 位为 $1$ 当且仅当位置 $i{+}1$ 是两者的差异位（0-based 位 $i$ 对应饲料编号 $i{+}1$）。$d\&-d$ 只保留 $d$ 的最低置位，即**最小**差异位 $t$（二进制补码性质：$-d=\sim d+1$，加法使最低置位以下全为 $0$、该位保持 $1$）。于是 $m\,\&\,(d\&-d)\ne0\iff t\in m$，由引理 7 等价于 $m$ 的升序列表字典序更小。$\blacksquare$

**注意前提"等基数"**：若基数不同，$k$（公共前缀长度）论证不再成立（例如 $\{1,2,3\}$ 与 $\{1\}$），所以代码里必须先比 `popcount` 相等再调用 `lexless`——顺序写反就是 bug。

**(c) 输出侧的"免费"字典序**：一旦锁定最优掩码 $best$，按 $i=0..g-1$ 递增打印 $i+1$ 天然就是"编号从小到大排列"（§1 的输出要求），无须额外排序。

### 2.6 溢出防护

逐项算出本题所有数值的最坏值再决定类型，而不是无脑 `long long`。

| 量 | 表达式 | 最坏值 | 溢出 `int`? |
|---|---|---|---|
| 单维供给和 $s$ | $\sum_{i\in S}c_{i,j}$，$|S|\le15$，$c\le1000$ | $15000$ | 否（余量 $\sim10^5$ 倍） |
| 需求 $a_j$ / 掩码 $m$ / 枚举上界 $2^g$ | 题面上界 | $1000/32767/32768$ | 否 |
| $d\&-d$ | $0<d<2^{15}$ | $2^{14}$ | 否，$-d$ 亦不越界 |
| 输出 | 至多 $1+15=16$ 个整数 | — | 否 |

结论：`int` 全程够用，不需要 `i64`/`__int128`。真正的三个坑与算术溢出无关，而是**位操作语义**：

1. **$-1$ 哨兵喂给 `__builtin_popcount`**：`__builtin_popcount((unsigned)-1)==32`。必须让 $best==-1$ 分支先短路（示例代码用 `if/else if` 的求值顺序显式保证，而非塞进一条 `a||b&&c` 长表达式）。更稳的替代是初始化为"必不可行的基数 $g+1$ + 掩码 $0$"；本文保留 $-1$ 版并在注释里点明顺序依赖。
2. **移位优先级**：`if(m>>i&1)` 依赖 `>>` 优先于 `&`（C++ 中成立），别误写成把枚举上界与位测试混在一起的 `if(m&(1<<g))`；若哪天 $g$ 上界变 $31$，`1<<g` 是 UB 需换 `1u<<g`，本题 $g\le15$ 无须改动。
3. **值域防御**：把 $[1,1000]$ 换成 $[1,10^9]$ 后 $s$ 最坏值 $1.5\times10^{10}>2^{31}$，此时只需把 `ok()` 的累加量改 `i64`（`using i64=long long;` + `i64 s=0;`），其余逻辑不动。**溢出结论要随值域重算，不能照抄模板。**

## 3. 模式总结（Pattern Summary）

**母题模式：小 $n$ 的 0-1 选择 + 单调（向上闭）可行族 + "最少数量 + 字典序最小"的并列要求。**

| 识别信号（题面原话） | 抽出的结构 | 应对手段 |
|---|---|---|
| "每种最多只能使用一次"，可选种数 $n\le20$ | 解空间 $2^n$ 的子集 | 位掩码枚举 / 子集树 DFS |
| "使……种数最少"，且每项贡献为**正** | 向上闭族（滤子）→ 基数分层 | 按 $p=1,2,\dots$ 分层，首个可行层即答案层（引理 4） |
| "多个解输出字典序最小" | 并列候选需二次比较 | 显式 lex 比较（引理 8 的 `d&-d`）或按 lex 序生成（引理 5） |
| "$v$ 个约束全部要满足" | 约束间是 $\land$ | 判定一维不足立即 `return false` |
| "数据保证存在解" | 无需无解分支 | 哨兵 $best$ 必被赋值 |

**分界与同族**：若 $n$ 涨到 $10^5$，同一套"向上闭 + 最小基数"就是 NP-hard 的集合覆盖（只有 $\ln n$ 近似贪心），§2.5(a) 的归约即此分界；$n\le20$ 时精确做法反而是最省事的。需要"最少件数 + 方案编号最小"的搜索题都适用"迭代深度 + 深度内按编号升序生成"这一对组合。

**三条纪律（对应本文踩过的坑）**：① 别把掩码数值序（colex）当字典序，见 §4.5 用例 3；② 先比基数再比字典序，颠倒顺序会让引理 8 的前提失效；③ 正贡献才换来单调性，题面一旦允许 $0$/负贡献，引理 1 失效、分层失去正确性，必须重证。

## 4. 真实解法

采用 §2.4 的**路线一（位掩码全枚举 + 基数优先 + `d&-d` 字典序比较）**，因为它逻辑最短、不需要递归、比较规则被引理 8 完全证明；文末另附路线二的分层 DFS 作为交叉实现。

### 4.1 符号表

| 记号 | 类型 | 含义 | 上下界 |
|---|---|---|---|
| $v$ | `int` | 维他命种数（题面第一行） | $[1,25]$ |
| $g$ | `int` | 饲料种数（题面第三行） | $[1,15]$ |
| `need[j]` | `int[30]` | $a_j$，第 $j{+}1$ 种维他命最低需求量，$j$ 为 0-based | $[1,1000]$ |
| `f[i][j]` | `int[20][30]` | $c_{i+1,\,j+1}$，第 $i{+}1$ 号饲料的第 $j{+}1$ 维含量 | $[1,1000]$ |
| $m$ | `int` | 枚举中的掩码，bit $i$ = 是否选第 $i{+}1$ 号饲料 | $[1,2^g)$ |
| `best` | `int` | 当前最优掩码；$-1$ = 尚未找到任何可行解（哨兵） | $\{-1\}\cup[1,2^g)$ |
| $s$ | `int` | $ok()$ 内某维的累加供给量 | $[0,15000]$ |
| $d$ | `int` | $m\oplus best$，差异位集合 | $(0,2^g)$ |
| $p$ | `int` | 输出答案的饲料种数 $=\text{popcount}(best)$ | $[1,15]$ |

内部一律 0-based（饲料编号 $i$ ↔ bit $i{-}1$ ↔ 输出 $i$），输出时加回 $1$。

### 4.2 编号步骤

1. **读入**：$v$ → `need[0..v-1]` → $g$ → `f[0..g-1][0..v-1]`。行与维的对应严格按题面"第 $n$ 行表示编号为 $n$ 饲料包含的各种维他命的量"，即外层循环是饲料 $i$、内层是维他命 $j$（读反会静默改变题意，因为矩阵非方阵时 $v\ne g$）。
2. **枚举**：$m$ 从 $1$ 递增到 $2^g-1$。跳过 $m=0$（空集必不可行，§1 第 3 条）。
3. **可行性判定 $ok(m)$**：对每个 $j\in[0,v)$ 累加 $s=\sum_{i:\,\text{bit }i=1}f[i][j]$；若 $s<need[j]$ 立即 `return false`（引理 1 的短路合法性：约束间是 $\land$）。全部通过返回 `true`。
4. **更新最优**：仅当 `best==-1`（首个可行解，`if/else if` 顺序保护 `popcount(-1)`，§2.6 第 1 点）、或 $\text{popcount}(m)<\text{popcount}(best)$（基数更优，引理 4）、或 $\text{popcount}(m)=\text{popcount}(best)$ 且 `lexless(m,best)`（引理 8）时令 `best=m`。
5. **`lexless(m,cur)`**：$d=m\oplus cur$，返回 `m&(d&-d)!=0`（$d\&-d$ 取最小差异位；引理 7 保证"最小差异位属于 $m$"等价于 $m$ 字典序更小，前提基数相等）。
6. **输出**：先打印 $p=\text{popcount}(best)$，再按 $i=0..g{-}1$ 递增打印 `best` 的置位对应编号 $i{+}1$（前缀空格分隔），最后 `'\n'`。递增打印即"编号从小到大"，同时是输出序列的字典序规范化。

### 4.3 复杂度

- **时间**：$O(2^g\cdot v\cdot g)$。代入上界 $2^{15}\times25\times15=12\,288\,000$ 次内层加法/比较，加上 $32768$ 次 $O(1)$ 的最优更新，量级 $1.3\times10^{7}$，远低于常见 $10^8$ 时限线；`ok()` 的短路（步骤 3）让常数进一步下降（多数掩码在前几维即被判否）。
- **空间**：$O(g\cdot v)$ 的输入表（$\le15\times25=375$ 个 `int`）加若干标量，$<4$ KB。
- **可优化到** $O(2^g\cdot v)$（§2.4 剪枝 3 的增量和），代价是 $2^{15}\times25=819\,200$ 个 `int` $\approx3.28$ MB；本题无必要，故不写入主代码。

### 4.4 正确性小结（引理接成一条链）

引理 1 给出向上封闭性使"按基数分层"有意义，引理 2 说明省掉分层会错；步骤 2 遍历 $[1,2^g)$ 与全部非空子集一一对应（空集因 $a_j\ge1$ 必不可行，跳出不失解），故**无漏解**；对枚举次序归纳可得不变量"$best$ 始终是已扫过可行集中按（基数，字典序）二元组最小者"——基数分支由引理 4 保证最优层，`lexless` 分支由引理 6+7+8 保证同层内严格实现字典序（调用前显式检验 `popcount` 相等，即引理 8 的前提）；步骤 6 的 $i$ 递增打印给出升序编号列。故输出 $p=p^\*$，编号列表是 $\mathcal F_{p^\*}$ 的字典序最小元。$\blacksquare$

## 5. 示例代码

### 5.1 主实现：位掩码全枚举 + 基数优先 + `d&-d` 字典序（对应 §4.2 步骤 1–6）

```cpp
// https://www.luogu.com.cn/problem/P1460
#include<bits/stdc++.h>
using namespace std;

constexpr int mxv{30},mxg{20};
int v,g,need[mxv],f[mxg][mxv];

// 掩码 m 选中的饲料合集是否满足全部维他命
bool ok(int m)
{
	for(int j=0;j<v;++j)
	{
		int s=0;
		for(int i=0;i<g;++i)
			if(m>>i&1)
				s+=f[i][j];
		if(s<need[j])
			return false;
	}
	return true;
}

// popcount 相同的前提下，m 的升序编号列表是否字典序小于 cur
bool lexless(int m,int cur)
{
	int d=m^cur;
	return m&(d&-d);                                    // 最小差异位属于 m 即为真（引理 7、8）
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>v;
	for(int j=0;j<v;++j)
		cin>>need[j];
	cin>>g;
	for(int i=0;i<g;++i)
		for(int j=0;j<v;++j)
			cin>>f[i][j];

	int best=-1;
	for(int m=1;m<(1<<g);++m)
	{
		if(!ok(m))
			continue;
		if(best==-1)                                  // 首个可行解；if/else if 的求值顺序挡住 popcount(-1)
			best=m;
		else if(__builtin_popcount((unsigned)m)<__builtin_popcount((unsigned)best))
			best=m;                                   // 基数更优（引理 4）
		else if(__builtin_popcount((unsigned)m)==__builtin_popcount((unsigned)best)&&lexless(m,best))
			best=m;                                   // 同基数取字典序（引理 8）
	}

	cout<<__builtin_popcount((unsigned)best);         // 题面输出整数，无精度要求
	for(int i=0;i<g;++i)
		if(best>>i&1)
			cout<<' '<<i+1;
	cout<<'\n';
	return 0;
}
```

**风格对照说明（逐条核对本文件的写法）**
`#include<bits/stdc++.h>` + `using namespace std;`；全局静态数组、`constexpr int mxv{30},mxg{20}`（上界 + 松弛）；`main` 内顺序 `cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);`；Tab 缩进；运算符不加空格（`m>>i&1`、`i+1`、`d&-d`）；换行用 `'\n'` 不用 `endl`；内部 0-based、输出时 `+1`；辅助函数为全局一行/几行小函数（`ok`、`lexless`）并保留注释形式的坑点标记。本题**没有任何浮点量**，故按风格指南"别名按需"的原则不定义 `using f64=double;`，也不需要 `fixed/setprecision`（输出格式在题面里是纯整数）；若值域变化需要 64 位，则按 §2.6 第 3 点引入 `using i64=long long;`。

### 5.2 交叉实现：分层组合 DFS（走 §2.4 路线二，靠引理 5 免掉比较函数）

思路：外层枚举目标基数 $p=1,2,\dots,g$；内层用"下一元素从 $start$ 递增"的递归生成 $p$ 元组合，生成顺序即字典序（引理 5），因此**第一个**可行组合就是答案，直接 `exit(0)`，无须 `lexless`。

```cpp
// https://www.luogu.com.cn/problem/P1460   交叉实现（与 5.1 二选一提交）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxv{30},mxg{20};
int v,g,need[mxv],f[mxg][mxv],seq[mxg],dep;

bool ok()                                             // 校验 seq[0..dep) 这 dep 袋
{
	for(int j=0;j<v;++j)
	{
		int s=0;
		for(int k=0;k<dep;++k)s+=f[seq[k]][j];
		if(s<need[j])
			return false;
	}
	return true;
}

// 还需 lim 袋，只允许选 >=start 的下标；i<=g-lim 保证后面凑得够
void dfs(int start,int lim)
{
	if(lim==0)
	{
		if(!ok())
			return;
		cout<<dep;
		for(int k=0;k<dep;++k)
			cout<<' '<<seq[k]+1;
		cout<<'\n';
		exit(0);
	}
	for(int i=start;i<=g-lim;++i)
	{
		seq[dep++]=i;
		dfs(i+1,lim-1);
		--dep;
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>v;
	for(int j=0;j<v;++j)
		cin>>need[j];
	cin>>g;
	for(int i=0;i<g;++i)
		for(int j=0;j<v;++j)
			cin>>f[i][j];
	for(int p=1;p<=g;++p)                              // 外层即基数分层
		dfs(0,p);
	return 0;
}
```

三个细节必须先证后用：
- `i<=g-lim`：还要 $lim$ 袋而 $[i,g-1]$ 只有 $g-i$ 个位置，$g-i<lim$ 时必然凑不满，故上界**不遗漏也不空转**；同时它保证 `seq` 严格递增，是引理 5 成立的载体。
- `exit(0)`：合法性来自引理 4（外层 $p$ 递增 ⇒ 首个可行层的 $p=p^\*$）+ 引理 5（同层首个 ⇒ 字典序最小）；缺任一条件即退化成错误算法（§2.1 引理 2、§2.5 用例 3 是两个反证素材）。
- 全局 `dep` 靠 `seq[dep++]=i` 与 `--dep` 严格配对，保证每次 $dfs(0,p)$ 返回时 $dep$ 归 $0$；若把深度同时写在参数与全局两处，$ok()$ 会读到脏值——本实现唯一易错点。
