# P1603 斯诺登的密码

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给定一个含 $6$ 个单词的英文句子（以 `.` 结尾，句首大小写不限）。按下列步骤求出"密码"：

1. 找出句中所有能表示数字的单词，把它们换成数值 $v$（$0\le v\le 20$）。除 `zero`…`twenty` 外，`a`/`another`/`first` 记作 $1$，`both`/`second` 记作 $2$，`third` 记作 $3$；
2. 每个 $v$ 取 $v^2 \bmod 100$，写成**两位**（不足两位补前导零，如 $0\to\texttt{00}$，$5\to\texttt{25}$，$19\to\texttt{61}$）；
3. 把这些两位块按任意顺序首尾相接，得到一个长为 $2n$ 的数字串；
4. 删掉整个串的前导零，剩下的数就是密码；若没有任何数字词，输出 `0`；若全部块都是 `00`，同样输出 `0`；
5. 求所有排列中数值最小的那个。

### 输入输出格式

- **输入格式**：一行，一个含 $6$ 个单词的句子，总字符数（含空格）不超过 $1000$。
- **输出格式**：一行，一个整数（即最小密码）。
- **数据规模**：单词数固定为 $6$，所以数字块数 $n\le6$，块的所有排列至多 $6!=720$ 种。

### 关键约束分析

1. **块必须补成两位**：$1\to\texttt{01}$ 而不是 `1`。如果把块当普通整数直接拼接，`01` 会退化成 `1`，位数不一致，后面"等长比较"的所有结论都会失效。
2. **前导零是整体删的**：`00`、`01`、`04`、`09` 都可能贡献前导零，因此"最小"不能简单理解为"升序拼接"。
3. **全零的退化**：所有块都是 `00` 时，删完前导零得到空串，必须输出 `0`。
4. **大小写与标点**：句号要剥掉；句首单词可能大写，比较前统一转小写。
5. $n\le6$ 很小，暴力枚举排列也可行，但排序有 $\mathcal{O}(n\log n)$ 的严格最优性结论。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：建模成"块 + 拼接"

先完成前三步转换：句子 → 数值序列 → 两位块序列 $B_1,\dots,B_n$（每个块是长度为 $2$ 的字符串）。
剩下的是一个纯组合问题：**把等长的块重新排列后拼接，使得到的数最小**（再删前导零）。

### 第二步：为什么等长让问题变简单

**引理 1（等长拼接的字典序 = 数值序）**：所有块长度都是 $2$，任意排列拼接得到的串长度都是 $2n$，
因此"数值最小"等价于"字典序最小"（删前导零之前）。

*证明*：两个长度为 $2n$ 的十进制串比较数值，与逐字符比较字典序的结果一致（长度相同的十进制串，字典序即数值序）。
而任意排列的拼接长度都是 $2n$，故问题化为求字典序最小的拼接。$\square$

**引理 2（升序拼接字典序最小）**：把块按字典序升序排列后拼接，得到的串 $S$ 是全部排列中字典序最小的。

*证明*：用交换论证。设某个排列中存在**相邻**两块 $x,y$ 且 $x>y$（字典序）。
只交换这两块，前缀与后缀都不变，只需要比较中间两段：交换前是 $xy$，交换后是 $yx$。
两者长度相同（都是 $4$），且都以 $x$（或 $y$）开头；因为 $x>y$，所以 $yx<xy$（首个不同位置出现在前两块之内）。
故交换后整体字典序严格变小。于是任何"不是升序"的排列都可以通过有限次相邻交换变小，
升序排列无法再被变小，即它是唯一的字典序最小者。$\square$

### 第三步：前导零会破坏"升序最优"吗

会。反例：块集合 $\{\texttt{00},\texttt{04},\texttt{25}\}$。升序拼接 $S=\texttt{000425}$，删零得 $425$；
而排列 $\texttt{002504}$ 删零得 $2504$，比 $425$ 大；但排列 $\texttt{040025}$ 删零得 $40025$，也更大。
这个例子看起来升序仍然赢，但必须证明，因为删零会让"长度"变化，长度更短的数一定更小。

**引理 3（升序使前导零最多）**：设 $z$ 为 `00` 块的个数，$A$ 为其余块（非 `00`）。记 $\mathrm{lz}(P)$ 为排列 $P$ 拼接后前导零的个数，
则对任意排列 $P$ 有 $\mathrm{lz}(P)\le \mathrm{lz}(S)$，其中 $S$ 是升序拼接。

*证明*：任意排列的前导零只能来自两部分：开头连续的若干 `00` 块（每个贡献 $2$ 个零），
以及紧随其后的第一个非零块（最多贡献 $1$ 个零，因为块长只有 $2$）。
第一部分至多 $z$ 块，故 $\mathrm{lz}(P)\le 2z+1$。

再看 $S$：它把 $z$ 个 `00` 全部放在最前面，之后是 $A$ 的升序。若 $A$ 中存在以 `0` 开头的块，
那么这些块只能是 $\texttt{01},\texttt{04},\texttt{09}$（因为 $v^2<10$ 只对应 $v\le3$），而它们也是 $A$ 中最小的三个块，
故升序时 $A$ 的第一个块就以 `0` 开头，$\mathrm{lz}(S)=2z+1$，取到上界；
若 $A$ 中不存在以 `0` 开头的块，则 $\mathrm{lz}(S)=2z$，此时任何排列的非零块也都不以 `0` 开头，$\mathrm{lz}(P)\le 2z$。两种情形都有 $\mathrm{lz}(P)\le\mathrm{lz}(S)$。$\square$

**引理 4（升序在删零后仍最小）**：设 $S$ 为升序拼接、$P$ 为任意排列，则删零后的数满足 $\mathrm{val}(S)\le\mathrm{val}(P)$。

*证明*：由引理 3，$\mathrm{lz}(P)\le \mathrm{lz}(S)$，故删零后 $\mathrm{len}(P')=2n-\mathrm{lz}(P)\ge 2n-\mathrm{lz}(S)=\mathrm{len}(S')$。
若长度严格更大，则 $S'$ 位数更少，$S'<P'$。
若长度相同，则 $\mathrm{lz}(P)=\mathrm{lz}(S)$，两条串的前 $\mathrm{lz}$ 位全为 `0`，
于是删零不改变两个串在首个不同位置上的先后关系；而由引理 2，$S\le P$（字典序），故 $S'\le P'$。$\square$

**定理**：把两位块升序排列后拼接、再删前导零（删空则输出 `0`），即为最小密码。

*证明*：由引理 4，升序排列在删零后仍不大于任何排列；输出格式由引理 4 的构造与"全零输出 `0`"的特判保证。$\square$

### 第四步：为什么"排序"能替代枚举

$n\le6$ 时枚举 $720$ 种排列完全可行，但对拍中可以看到排序版本与之逐组一致。
更重要的是排序版本给出了一个**结构性结论**：不需要搜索，只需把块排序。这也解释了为什么这道"看起来要枚举"的题实际是道排序题。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 所有块等长 $2$，于是"数值最小"退化为"字典序最小"。
- `reduce to easier problem` — 把"任意排列拼接"降成"等长串的拼接排序"这个经典问题。
- `classic problem solution` — 等长串拼接：升序排序即字典序最小，交换论证可证。
- `handle the extra twist` — 前导零会改变长度，需要额外证明"升序同时让前导零最多"。
- `discuss by category` — 分"$A$ 中是否存在以 `0` 开头的块"两种情况证明前导零上界可达。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $v$ | `mp[w]` / `it->second` | 单词对应的数值，$0\le v\le 20$ |
| — | `mp` | `map<string,int>`，英文单词到数值的映射表（含 $21$ 个正规词与 $6$ 个非正规词） |
| — | `num[21]` | 正规词表 `zero`…`twenty`，用于批量建表 |
| $B$ | `blk` | 两位块序列，存的是 $v^2\bmod 100$ 的**整数**值，排序时按数值即可（等价于按两位串排序） |
| — | `line` | 整行输入 |
| — | `c` | 当前扫描到的字符（字母则入 `w`，否则触发一次切词） |
| — | `w` | 切词缓冲，逐字符累积字母并转小写 |
| — | `it` | `mp.find(w)` 的迭代器，命中则取 `it->second` 作为 $v$ |
| $S'$ | `ans` | 升序拼接后的完整数字串（含前导零） |
| $p$ | `p` | 第一个非零位的下标，用于删前导零 |

### 算法步骤

1. 建映射表：`zero`…`twenty` 对应 $0..20$；`a`/`another`/`first`$\to1$，`both`/`second`$\to2$，`third`$\to3$。
2. `getline` 读入整行，逐字符扫描：字母则小写后追加到 `w`；遇到非字母且 `w` 非空则查表，命中就 `blk.push_back(v*v%100)` 并清空 `w`（句号因此被自动丢弃）。
3. 对 `blk` 升序排序。
4. 依次把每个块写成两位（`v/10` 与 `v%10`）追加到 `ans`。
5. 跳过 `ans` 的前导零；若全是零则输出 `0`，否则输出 `ans.substr(p)`。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}(L + n\log n + 2n)$，$L\le1000$ 为句子长度，$n\le6$；实际是常数级。
- **空间复杂度**：$\mathcal{O}(L)$，句子、映射表与块序列。

### 正确性验证

引理 1 把数值比较化为字典序比较；引理 2 用相邻交换证明升序拼接字典序最小；引理 3 证明升序同时最大化前导零个数；
引理 4 把两者合成"删零后仍最小"；定理给出最终正确性。
数值范围：块值 $<100$，$n\le6$，拼接串长 $\le12$，用字符串处理不存在溢出。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1603 斯诺登的密码
// https://www.luogu.com.cn/problem/P1603
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};          // 整句字符数 <=1000 (+5 松弛)

map<string,int> mp;               // 英文单词 -> 数值
string line,w;
vector<int> blk;                  // 每个数字平方模 100 后的两位块

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	const char* num[21]={"zero","one","two","three","four","five","six","seven","eight",
		"nine","ten","eleven","twelve","thirteen","fourteen","fifteen","sixteen",
		"seventeen","eighteen","nineteen","twenty"};
	for(int i=0;i<=20;++i)
		mp[num[i]]=i;
	mp["a"]=1;mp["another"]=1;mp["first"]=1;   // 非正规写法
	mp["both"]=2;mp["second"]=2;
	mp["third"]=3;

	getline(cin,line);
	for(size_t i=0;i<=line.size();++i)   // 按非字母字符切词, 顺带丢掉句号
	{
		char c=i<line.size()?line[i]:' ';
		if(isalpha((unsigned char)c))
			w+=char(tolower((unsigned char)c));
		else if(!w.empty())
		{
			auto it=mp.find(w);
			if(it!=mp.end())
				blk.push_back(it->second*it->second%100);
			w.clear();
		}
	}

	sort(blk.begin(),blk.end());      // 等长两位块, 升序拼接即为最小

	string ans;
	for(int v:blk)
	{
		ans+=char('0'+v/10);
		ans+=char('0'+v%10);
	}
	size_t p=0;                      // 去掉整个串的前导零
	while(p<ans.size()&&ans[p]=='0')
		++p;
	if(p==ans.size())
		cout<<0<<'\n';           // 全为 00 时答案为 0
	else
		cout<<ans.substr(p)<<'\n';
	return 0;
}
```

### 易错点

1. **不补前导零**：把 $4$ 直接拼成 `4` 而不是 `04`，位宽不一致，排序与拼接全错。
2. **漏掉非正规写法**：`a`/`both`/`another`/`first`/`second`/`third` 这 $6$ 个词必须映射，否则少块。
3. **忘记删句号**：`zero.` 与 `zero` 不等，最后一个词会失配。代码里"非字母即切词"同时解决了句号。
4. **全 `00` 时输出空行**：删零后必须判空并输出 `0`。
5. **句首大写**：`A` 与 `a` 需要统一大小写后再查表。
6. **误以为"最小 = 升序"是免费的**：删前导零让长度可变，必须额外证明（引理 3、4），否则可能被 $\{\texttt{00},\texttt{04},\texttt{09},\dots\}$ 这类数据打穿。

### 本地验证结果

题面归档无样例段，使用"句首大写""全零""只有 6 个 `twenty`"等手造数据，并与"枚举 $6!$ 全排列取最小"的暴力（`P1603_brute.cpp`）对拍。
