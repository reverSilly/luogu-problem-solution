# P1362 兔子数

> 标签：搜索 / 数学 · 难度：普及/提高-

## 1. 重新读题

**问题重述（简化版）**

记 $S(N)$ 为 $N$ 的十进制各位数字之和（例如 $S(484)=16$，$S(22)=4$）。若正整数 $x$ 满足
$$S(x\cdot x)=S(x)\cdot S(x),$$
就称 $x$ 为**兔子数**（题面给的例子：$22$ 是，因为 $S(484)=16=S(22)^2$）。
输入一行两个整数 $L,R$，输出区间 $[L,R]$ 内兔子数的个数（一行一个整数）。

**约束与暗示**

| 量 | 范围 |
|---|---|
| $L,R$ | $1\le L\le R\le 10^9$ |
| 位数 | $x\le 10^9$，至多 $10$ 位（$10^9$ 本身是 `1000000000`） |
| $x^2$ | $\le 10^{18}$，可用 64 位整数存 |

两点值得注意：

1. **题面没有任何样例**（只有定义、输入格式、输出格式和一句数据范围）。因此本文的所有数字都只能靠手算核对，**无法与官方答案对标**，详见 §4.4。
2. 区间长度最坏 $10^9$，但**只有 $10$ 个数位**，而标签是"搜索 + 数学"——这暗示：先用数学把兔子数结构钉死，再对极小的候选空间做搜索（DFS 枚举），而不是对区间扫。

## 2. 思维链（Chain-of-thought）

### 2.1 先摸清 $S$ 这个函数脾气：模 9 与"进位亏空"

**引理 1（数字和的模 9 不变性）** 对任意非负整数 $n$，$S(n)\equiv n\pmod 9$。

**证明**：设 $n=\sum_{k=0}^{m}d_k10^k$，$0\le d_k\le 9$。因为 $10\equiv 1\pmod 9$，所以 $10^k\equiv 1\pmod 9$，于是
$$n=\sum_{k=0}^{m}d_k10^k\equiv\sum_{k=0}^{m}d_k=S(n)\pmod 9.\qquad\blacksquare$$

用它先得到一个**恒成立的事实**：$S(x^2)\equiv x^2\pmod 9$，且 $S(x)^2\equiv x^2\pmod 9$（把引理 1 用于 $n=x$ 再平方即可），所以
$$S(x^2)-S(x)^2\equiv 0\pmod 9 .$$
即两边的差**永远是 9 的倍数**——兔子数方程"差一点"也只差 9 的整数倍。手算三个非兔子数验证：$x=4$：$S(16)=7$，$S(4)^2=16$，差 $9$；$x=14$：$S(196)=16$，$S(14)^2=25$，差 $9$；$x=18$：$S(324)=9$，$S(18)^2=81$，差 $72=9\times 8$。这个"9 的倍数"是哪来的？答案就是**进位**：十进制加法每发生一次进位，数字和恰好少 $9$（$10$ 换成 $1$）。

**引理 2（两数相加的进位恒等式）** 对非负整数 $u,v$，设竖式加法 $u+v$ 共进位 $\kappa$ 次，则
$$S(u)+S(v)=S(u+v)+9\kappa,\qquad\text{故 } S(u+v)\le S(u)+S(v),$$
等号成立当且仅当 $\kappa=0$（即逐位相加一次都不进位）。

**证明**：把 $u,v$ 的高位补 0 对齐，记第 $i$ 位为 $u_i,v_i$。竖式加法是：$c_0=0$，对 $i=0,1,2,\dots$ 令
$$t_i=u_i+v_i+c_i,\qquad d_i=t_i-10c_{i+1},\qquad c_{i+1}=\lfloor t_i/10\rfloor\in\{0,1\}.$$
$c_{i+1}=1$ 正是"第 $i$ 位向第 $i+1$ 位进了一次位"，故 $\kappa=\sum_{i\ge 1}c_i$。
- **过程会停止**：取 $M$ 大到 $u,v$ 在 $M$ 位以上全为 $0$。若某步 $c_i=1$ 而 $u_i=v_i=0$，则 $t_i=1$、$d_i=1$、$c_{i+1}=0$，进位链立刻断掉；此后所有 $t_i=0$。所以只有有限多个 $c_i$ 非零，$\kappa=\sum_{i\ge1}c_i$ 是有限整数。
- **竖式输出确为 $u+v$ 的十进制表示**（这保证 $\sum_i d_i=S(u+v)$）：由 $t_i=u_i+v_i+c_i$ 得 $u_i+v_i=t_i-c_i$；又 $t_i=d_i+10c_{i+1}$（$d_i$ 的定义式移项）。逐项乘 $10^i$ 求和，和式只有有限多项非零，可自由移位重排：
$$u+v=\sum_i(u_i+v_i)10^i=\sum_i(t_i-c_i)10^i=\sum_i d_i10^i+\underbrace{10\sum_i c_{i+1}10^i}_{\sum_{i\ge1}c_i10^i}-\sum_i c_i10^i=\sum_i d_i10^i,$$
末式两处相等是因为 $c_0=0$ 使 $\sum_i c_i10^i=\sum_{i\ge1}c_i10^i$。而 $0\le d_i\le 9$（$t_i\le19$ 时 $d_i=t_i-10\le9$，$t_i\le9$ 时 $d_i=t_i\ge0$），故 $\sum_i d_i10^i$ 就是 $u+v$ 的十进制展开，$\sum_i d_i=S(u+v)$。
- **不带权的计数**：把上面 $u_i+v_i=t_i-c_i=d_i+10c_{i+1}-c_i$ 直接对 $i$ 求和（不乘 $10^i$）：
$$S(u)+S(v)=\sum_i(u_i+v_i)=\sum_i d_i+10\sum_i c_{i+1}-\sum_i c_i=S(u+v)+10\kappa-\kappa=S(u+v)+9\kappa,\qquad\blacksquare$$
其中 $\sum_i c_{i+1}=\sum_{i\ge1}c_i=\kappa$（$c_0=0$），$\sum_i c_i=\kappa$。由 $\kappa\ge0$ 得 $S(u+v)\le S(u)+S(v)$，且等号 $\iff\kappa=0$。

> 结论：**"数字和可加"当且仅当"加法不进位"**，且每次进位扣掉 $9$——与 §2.1 开头观测到的 $9$ 的倍数对上。

### 2.2 把兔子数判据钉死成"乘法完全无进位"

把 $x$ 写成 $x=\sum_{i=0}^{m-1}a_i10^i$，$0\le a_i\le 9$，$a_{m-1}\ne 0$（**本文数字位与列号一律 0-based，$a_0$ 是个位**）。乘法 $x\cdot x$ 的"原始列和"是
$$C_j=\sum_{\substack{0\le i,i'\le m-1\\ i+i'=j}}a_ia_{i'},\qquad j=0,1,\dots,2m-2,$$
即竖式乘法里第 $j$ 列（权重 $10^j$）先累加、尚未处理进位时的值。恒等式
$$x^2=\sum_{i,i'}a_ia_{i'}10^{i+i'}=\sum_{j=0}^{2m-2}C_j10^j\tag{$\ast$}$$
是纯代数重排（把 $i+i'=j$ 的项归到同一列），每项非负，故 $C_j\ge 0$，且 $C_0=a_0^2$、$C_{2m-2}=a_{m-1}^2>0$。

**引理 3（兔子数 = 乘法无进位）** $x$ 是兔子数 $\iff$ 对所有 $j$ 都有 $C_j\le 9$。

**证明**：分两步夹逼。

- **(上界链)** 记 $T_j=C_j10^j$。把引理 2 的 $S(p+q)\le S(p)+S(q)$ 对项数归纳（$1$ 项时取等；设 $q$ 项成立，则 $S(\sum_{j\le q}T_j)\le S(\sum_{j<q}T_j)+S(T_q)\le\sum_{j\le q}S(T_j)$），取 $q=2m-2$ 得
$$S(x^2)=S\Big(\sum_j T_j\Big)\le\sum_j S(T_j)=\sum_j S(C_j),\tag{P1}$$
最后一步用了 $S(c\cdot10^j)=S(c)$（补零不改变数字和）。又对任意整数 $n\ge0$ 有 $S(n)\le n$，且等号当且仅当 $n\le9$：$0\le n\le9$ 时 $n$ 本身就是一位数，$S(n)=n$；$n\ge10$ 时设 $n=\sum_k d_k10^k$，则必存在 $k\ge1$ 使 $d_k\ge1$，该项满足 $d_k10^k\ge 2d_k>d_k$，而其余项 $d_{k'}10^{k'}\ge d_{k'}$，求和得 $n>S(n)$。从而
$$\sum_j S(C_j)\le\sum_j C_j=\sum_{i,i'}a_ia_{i'}=\Big(\sum_i a_i\Big)^2=S(x)^2.\tag{P2}$$
（$\sum_jC_j=\sum_{i,i'}a_ia_{i'}$ 是($\ast$) 的展开式按列合并后再令 $10^j\to1$；$\sum_{i,i'}a_ia_{i'}=(\sum_ia_i)^2$ 是乘法分配律。）合并 (P1)(P2)：**$S(x^2)\le S(x)^2$ 对一切 $x$ 恒成立**，所以兔子数判据只能是"少算了多少"，不存在 $S(x^2)>S(x)^2$。

- **($\Leftarrow$)** 若所有 $C_j\le 9$，则($\ast$) 右端 $\sum_jC_j10^j$ 的每一位都 $\le9$，是一个合法十进制展开（有限项、最高位 $C_{2m-2}=a_{m-1}^2\ge1$ 非零），由十进制表示的唯一性，$x^2$ 的各位数字恰为 $C_0,C_1,\dots$，故 $S(x^2)=\sum_jC_j=S(x)^2$（用了 (P2) 中等号已成立：所有 $C_j\le9\Rightarrow S(C_j)=C_j$），即 $x$ 是兔子数。

- **($\Rightarrow$)** 若 $S(x^2)=S(x)^2$，则 (P1) 亏空 $\Delta_1=\sum_jS(C_j)-S(x^2)\ge0$ 与 (P2) 亏空 $\Delta_2=\sum_jC_j-\sum_jS(C_j)\ge0$ 之和 $\Delta_1+\Delta_2=S(x)^2-S(x^2)=0$，故 $\Delta_1=\Delta_2=0$。由 $\Delta_2=0$ 得每个 $C_j-S(C_j)=0$（各项非负，逐项为零），再由上面刻画 "$S(n)=n\iff n\le9$" 得 $C_j\le9$ 对一切 $j$ 成立。$\blacksquare$

**引理 4（亏空恰为 9 的倍数，并给出其组合意义）** 设 $\kappa''$ 为把 $T_0,T_1,\dots,T_{2m-2}$ 逐列累加时产生的进位总次数，则
$$S(x)^2-S(x^2)=\underbrace{\sum_j\big(C_j-S(C_j)\big)}_{\ge0,\ \text{每项都是 }9\text{ 的倍数}}+9\kappa''.$$

**证明**：左边 $=\big(S(x)^2-\sum_jS(C_j)\big)+\big(\sum_jS(C_j)-S(x^2)\big)=\Delta_2+\Delta_1$（依 (P1)(P2) 的定义）。
- $\Delta_2=\sum_j(C_j-S(C_j))$：由引理 1，$C_j\equiv S(C_j)\pmod9$，故每项是 $9$ 的倍数；又 $S(C_j)\le C_j$（上面已证），故每项 $\ge0$。
- $\Delta_1=9\kappa''$：对 $S(\sum_jT_j)$ 与 $\sum_jS(T_j)$ 用引理 2 的归纳版本——每合并一项就按 $S(A+B)=S(A)+S(B)-9\kappa_{A,B}$ 记一笔亏空，累加即得总亏空 $=9\sum\kappa_{A,B}=9\kappa''$。$\blacksquare$

> 检验：$x=18$ 时 $C_0=64,\ C_1=16,\ C_2=1$，$\sum C_j=81$；$64-10=54$、$16-7=9$、$1-1=0$，(P2) 亏 $63$；$10+7+1=18$ 而 $S(324)=9$，(P1) 亏 $9$；合计 $72=9\times 8$，与 §2.1 手算完全吻合。

### 2.3 结构推论：每一位只能是 $0,1,2,3$

**引理 5** 若 $x$ 是兔子数，则它的每个十进制数字 $a_i\in\{0,1,2,3\}$。

**证明**：列 $j=2i$ 的和里包含 $i+i'=2i$ 的项 $(i,i')=(i,i)$，即 $C_{2i}\ge a_i^2$（其余项非负）。由引理 3，$9\ge C_{2i}\ge a_i^2$，故 $a_i\le 3$（$a_i$ 非负整数）。$\blacksquare$

> 与引理 5 相映成趣的是**数字和方向**的上界：若 $x\le10^9$ 是兔子数，则 $x^2\le10^{18}$，粗略地 $S(x^2)\le9\times19=171$（精确些：$\le10^{18}$ 的数里 $19$ 位的只有 $10^{18}$ 本身，$S=1$，故 $S(x^2)\le18\times9=162$）。由 $S(x)^2=S(x^2)$ 得 $S(x)\le13$（因 $14^2=196>171$；用 $162$ 则 $S(x)\le12$，因 $13^2=169>162$）。引理 5 只给到 $S(x)\le3\times10=30$，这条更紧，但它是"事后"过滤（可用来核对输出是否离谱），对搜索规模并无帮助——规模靠的是**逐位**上界 $a_i\le3$：它把候选从 $10^9$ 量级的整数压到 $4^9=262144$ 个（§2.4）。

**引理 6（逆命题不成立）** 数字全 $\le 3$ 并不能保证是兔子数。

**证明**：取 $x=23$：$a_0=3,a_1=2$，$C_1=a_0a_1+a_1a_0=12>9$，由引理 3 不是兔子数。实际核对：$23^2=529$，$S=16$，而 $S(23)^2=25$，$16\ne25$。（对照 $x=13$：$a_0=3,a_1=1$，$C_0=9,\ C_1=6,\ C_2=1$ 均 $\le9$，于是 $13^2=169$，$S(169)=16=S(13)^2$ **是**兔子数。$13$ 与 $23$ 的差别只在十位数字：$13$ 的最大列 $C_0=3^2=9$ 刚好顶到上限，$23$ 的交叉列 $C_1=2\cdot3\cdot2=12$ 越界。可见"数字大小"与"数字搭配"共同决定成败，判据只能回到引理 3，不能只看每一位。）$\blacksquare$

### 2.4 规模对比：为什么必须搜索候选而不是扫区间

- **扫区间（暴力）**：最坏 $R-L+1=10^9$ 个 $x$，每个算 $S(x)$（$\le10$ 次除模）与 $S(x^2)$（$\le19$ 次除模），约 $2.9\times10^{10}$ 次除法级运算——不可接受。
- **枚举候选（引理 5 的功劳）**：数字全在 $\{0,1,2,3\}$、且 $\le R\le10^9$ 的正整数个数
$$\sum_{d=1}^{9}3\cdot4^{d-1}+1=3\cdot\frac{4^9-1}{4-1}+1=(4^9-1)+1=4^9=262144,$$
（$d$ 位：首位 $3$ 种、其余每位 $4$ 种；$d=10$ 且 $\le10^9$ 只有 $10^9$ 本身。）于是最多 $262144$ 次判据检查，每次 $\le 29$ 次除模：
$$262144\times 29\approx 7.6\times10^6,$$
加上排序 $262144\times\log_2 262144=262144\times18\approx4.7\times10^6$ 次比较与 $2\lceil\log_2 262144\rceil=36$ 步二分，总量约 $1.3\times10^7$ 次基本运算。相比暴力 $2.9\times10^{10}$ 缩小约 $2200$ 倍——这就是"数学（引理 5）圈定空间 + 搜索（DFS 枚举）逐个验证"的由来。

### 2.5 枚举怎么做：按位 DFS + 生成集完备性

**引理 7（DFS 生成的集合恰好是候选集）** 从 $x=0$ 出发，对每个已生成的 $x$ 依次尝试后缀一位数字 $d\in\{0,1,2,3\}$ 得到 $y=10x+d$，仅当 $y>0$ 且 $y\le R$ 时递归，则递归访问过的 $y$ 的集合恰为 $\{x:1\le x\le R,\ \text{每位}\le 3\}$，且每个恰好访问一次。

**证明**：
- **不漏**：设 $x$ 满足条件，其十进制数字串（高位在左）为 $a_{m-1}a_{m-2}\dots a_0$，$a_{m-1}\in\{1,2,3\}$、$a_{m-1}\ne0$、各 $a_i\le3$、$m\le10$。取它的高位前缀 $p_k=\overline{a_{m-1}\dots a_{m-k}}$（$k=0,\dots,m$，$p_0=0$、$p_m=x$）。递推地 $p_k=10p_{k-1}+a_{m-k}$，且 $p_k$ 是 $x$ 截去低 $m-k$ 位所得，故 $0\le p_k\le x\le R$；$k\ge1$ 时 $p_k\ge a_{m-1}\ge1>0$。于是 DFS 沿这条路径的每一步 $y=p_k$ 都同时满足 $y>0$ 与 $y\le R$，不会被剪掉，最终 $p_m=x$ 被访问。
- **不重**：每个被访问的正整数对应唯一的"无前导零数字串"路径（首步 $d\in\{1,2,3\}$，之后可用 $d=0$；$x=0$ 且 $d=0$ 被 $y>0$ 排除），而数字串 $\to$ 数值是单射，故每个候选只访问一次。
- **终止 / 有限**：沿递归 $y=10x+d\ge 10x>x$ 对 $x\ge1$ 成立（$x=0$ 只出现在根，其子 $y\ge1$），值严格递增且恒 $\le R$，位数每步加 $1$，深度 $\le\lfloor\log_{10}R\rfloor+1\le10$，故递归必终止。
- **剪枝合法性**：若 $y>R$，则 $y$ 的任何延伸 $10y+d\ge10y>y>R$，都不可能落在 $[L,R]$，剪掉不损失任何候选。
- **根 $x=0$ 不入表**：$0$ 不是正整数，且 $S(0\cdot0)=0=0\cdot0$ 会被定义式误判为"成立"，故 `dfs` 里显式要求 `x>0` 才记录（这是必须写的一笔）。$\blacksquare$

有了完备候选集，对每个 $x$ 直接用**定义式**判定 `sd(x*x)==sd(x)*sd(x)`。这里刻意不用"手写列和 $C_j\le9$"：引理 3 说两者等价，但定义式只要一个 $10^{18}$ 级别的乘法加两遍数字和，代码 $6$ 行、不需要维护列的下标；而手写列和要正确算出 $2m-1$ 个 $C_j$（含 $i\ne i'$ 的两次交叉项），多一个易错点。**判据选定义式，搜索空间靠引理 5**，两边各出一次力。

访问顺序（前序）示意，$R=10^9$ 时：$0\to1\to10\to100\to\cdots\to10^8\to10^9$（一路取 $d=0$）；$10^9$ 的四个孩子都是 $10^{10}+d>R$，全被剪；回溯到 $10^8$，其孩子 $10^9+d$ 中只有 $d=0$ 合法（已访问过）而 $d=1,2,3$ 均 $>R$，也剪；再回溯到 $10^7$，$d=1$ 给 $100000001\le R$，于是继续下钻……可见"数字 $\le3$"与"值 $\le R$"两个条件互相牵制：$10$ 位数里只有 $10^9$ 本身合法，$9$ 位及更短的都合法，被访问的正整数恰是 §2.4 算出的 $262144$ 个（另有根 $x=0$ 一次，不入表）。

**定理（算法正确性）** 设 `rab` 为程序产出的升序表，则对任意 $1\le L\le R\le10^9$，`hi-lo` 恰为 $[L,R]$ 内兔子数个数。

**证明**：
1. **表的内容**：由引理 7，DFS 访问的正整数集合 $A=\{x:1\le x\le R,\ \forall i,\ a_i\le3\}$，且每个至多被记录一次。程序把 $x\in A$ 入表当且仅当定义式 $S(x^2)=S(x)^2$ 成立。故表 $=\{x\in A:x\text{ 是兔子数}\}$。
2. **不漏**：设 $x$ 是 $[L,R]$ 内兔子数。$x\le R$ 且由引理 5 每位 $\le3$，故 $x\in A$；定义式即兔子数定义，故 $x$ 入表。
3. **不杂**：表中每个 $x$ 都满足 $x\in A\Rightarrow 1\le x\le R$，且满足定义式，故都是兔子数。
4. **计数**：表升序，`lo` 是第一个 $\ge L$ 的位置、`hi` 是第一个 $>R$ 的位置，故 `rab[lo..hi)` 恰是满足 $L\le x\le R$ 的表元素，个数 $=\text{hi}-\text{lo}$。（`lower_bound` 给"第一个不小于值"、`upper_bound` 给"第一个大于值"，其前提"区间已按比较序排好"由 §4.2 步骤 3 的 `sort` 提供；区间 $[\,\text{rab},\text{rab}+\text{cnt})$ 左闭右开，故 $[-,-)$ 相减直接是元素个数，不重不漏。）
5. **数组不越界**：表长 $K\le|A|\le 262144<\texttt{mxn}=262149$（§2.4 计数），故 `rab[cnt++]` 不会写出界。$\blacksquare$

### 2.6 其它可行做法（同一结论的不同实现）

- **纯暴力扫 $[L,R]$**：$O\big((R-L+1)\cdot D\big)$（每个 $x$ 提位 $\le10+19=29$ 次），本题最坏 $10^9\times29\approx2.9\times10^{10}$ 不可接受；只有在区间长度 $\le10^6$ 的弱数据下够用，可当"纸上核对"的参照（本文未运行任何程序，核对全部手算，见 §4.4）。
- **逐位 DP**：难点在于列和 $C_j=\sum_{i+i'=j}a_ia_{i'}$ 同时依赖低位与高位，按位从高位推进时无法当场确定 $C_j\le9$（$C_{m-1}$ 这类"中间列"要等低位数字全部定下才算得出），需要把"待定列的部分和"塞进状态，状态设计远比直接枚举 $4^9=262144$ 个候选复杂，收益不高，故不采用。
- **在 DFS 内部就用列和剪枝**：每追加一位数字，就有若干"只涉及已确定高位"的列被最终确定（例如首位 $a_{m-1}$ 定下后 $C_{2m-2}=a_{m-1}^2$ 已定；再定 $a_{m-2}$ 后 $C_{2m-3}=2a_{m-1}a_{m-2}$ 已定），这些列一旦 $>9$ 便可立即回溯（如 $a_{m-1}=3$ 时 $C_{2m-3}=6a_{m-2}\le9$ 逼出 $a_{m-2}\le1$）。这能把 $2.6\times10^5$ 再降一个量级。但代码要维护"已确定列"的增量、回溯时撤销，正确性风险明显变大；本文候选只有 $2.6\times10^5$，用"全枚举 + 定义式判定"更稳。

## 3. 模式总结（Pattern Summary，按实际思考顺序）

- **explore its property** — $S(n)\equiv n\pmod 9$：判据两边之差必为 $9$ 的倍数（引理 1）。
- **find the source of the gap** — 竖式加法每进位一次数字和少 $9$，$S(u+v)=S(u)+S(v)-9\kappa$（引理 2）。
- **reduce to easier problem** — 把判据翻译成"乘法 $x\times x$ 所有原始列和 $C_j\le 9$"，即完全无进位（引理 3）。
- **structural corollary** — 由 $C_{2i}\ge a_i^2$ 得每一位 $a_i\le3$，候选空间被压缩到 $4^9=262144$（引理 5、§2.4）。
- **classic problem solution** — 按位 DFS 枚举候选（搜索标签），逐个用定义式 $S(x^2)=S(x)^2$ 验证，收集兔子数。
- **classic problem solution（第二处不同技术）** — 生成与查询解耦：兔子数表排序后 `lower_bound/upper_bound` 做差分计数，把"区间有多少个"变成"两次二分"（数学/二分）。
- **counterexample discipline** — 数字 $\le3$ 只是必要条件不是充分条件（$23$ 反例，引理 6），所以必须真验证而非只看数字。
- **prove completeness then count** — 引理 7 证明 DFS 访问集"不重不漏"，再靠排序 + 二分把"区间计数"变成两次边界查找，五步串成正确性定理（§2.5 定理）。
- **consider alternative techniques** — 扫区间暴力 / 逐位 DP / DFS 内列和剪枝，三条备选各带"为什么不选"的理由（§2.6），正解取"全枚举 + 定义式判定"。

## 4. 真实解法（Real Solution）

### 4.1 符号表（Notation Glossary）

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `L,R` | 查询区间端点 | `i64`，输入 | $1\le L\le R\le 10^9$ |
| `a_i` | $x$ 的第 $i$ 位数字，$a_0$ 为个位 | 文中记号，**0-based** | 兔子数 $\Rightarrow a_i\le3$ |
| `C_j` | 乘法 $x\cdot x$ 的第 $j$ 列原始列和 | 文中记号，0-based | 判据：所有 $C_j\le9$ |
| `sd(x)` | $S(x)$，十进制数字和 | 函数，`i64(i64)` | 循环 `x/=10` 累加 `x%10` |
| `israb(x)` | 定义式判据 `sd(x*x)==sd(x)*sd(x)` | 函数，`bool(i64)` | 等价于引理 3 |
| `dfs(x)` | 枚举以 $x$ 为前缀、数字 $\le3$ 的候选 | 函数，`void(i64)` | 后继 $10x+d,\ d\in[0,3]$ |
| `rab[]` | 已确认的兔子数，升序 | `i64 rab[mxn]`，全局默认 0 | 只由 `rab[0..cnt-1]` 访问 |
| `cnt` | `rab` 中元素个数 | `int`，全局初值 0 | $\le 262144$ |
| `lo,hi` | 下标：`rab[lo..hi-1]` 落在 $[L,R]$ | `i64`（指针差） | $ans=hi-lo$ |

> **下标约定**：全文（含证明）数字位与列号都 **0-based**（个位是 $a_0$、列 $C_0$）；数组 `rab` 亦 0-based。无需偏移转换。

### 4.2 算法步骤（Numbered Steps）

1. **读入** `L,R`。
2. **DFS 枚举候选**：`dfs(0)`；在 `dfs(x)` 中先判 `x>0 && israb(x)`，成立则 `rab[cnt++]=x`；再对 `d=0..3` 计算 `y=x*10+d`，若 `y>0 && y<=R` 递归 `dfs(y)`。由引理 7，访问集恰为"数字全 $\le3$ 且 $\le R$ 的正整数"，每个一次；兔子数全在此集合中（引理 5）。
3. **排序**：`sort(rab,rab+cnt)`（DFS 是前序，天然无序）。
4. **二分计数**：`lo=lower_bound(rab,rab+cnt,L)-rab`（第一个 $\ge L$），`hi=upper_bound(rab,rab+cnt,R)-rab`（第一个 $>R$），答案 `hi-lo`。
5. **输出** `hi-lo<<'\n'`。

步骤 1~5 的完整正确性论证（不漏、不杂、计数、数组不越界四点）见 §2.5 末尾的**定理**；下面 §4.3 处理数值安全，§4.4 处理验证。

**复杂度**（记 $D=\lfloor\log_{10}R\rfloor+1\le10$ 为 $R$ 的位数，$M$ 为候选数、$K$ 为兔子数）：由 §2.4 的精确计数（用 $R\le10^9$，而不是宽松的 $4^{D}-1$），$M\le 4^9=262144$，$K\le M$。
- 时间：$O(M\cdot D+K\log K)$。逐项：DFS 访问 $M\le262144$ 个候选（引理 7），每个 `israb` 提位 $\le10+19=29$ 次除模 $\Rightarrow\le 7.6\times10^6$；排序 $K\log_2K\le 262144\times18\approx4.7\times10^6$ 次比较；两次二分 $2\lceil\log_2 262144\rceil=36$ 步。合计 $\approx1.3\times10^7$ 次基本运算（对比 §2.4 暴力扫区间的 $\approx2.9\times10^{10}$，缩小约 $2200$ 倍）。
- 空间：$O(K)$，`rab` 数组 $262149\times8\,\text{B}=2\,097\,192\,\text{B}\approx2.1\,\text{MB}$。

## 5. 示例代码（C++）

```cpp
// P1362 兔子数
// 兔子数 <=> x*x 的乘法完全无进位 <=> 每位数字 <=3 且各列和 <=9
// 于是只需 DFS 枚举「数字属于{0,1,2,3}、值 <=R」的候选(至多 4^9=262144 个)，
// 逐个按定义 S(x*x)==S(x)*S(x) 判定，排序后二分统计 [L,R] 内的个数。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{262144+5};   // 候选数上界 4^9=262144，+5 松弛

i64 L,R;
i64 rab[mxn];   // 兔子数表，升序；只访问 [0,cnt)
int cnt=0;

i64 sd(i64 x)
{
	i64 s=0;
	for(;x;x/=10)
		s+=x%10;
	return s;
}

bool israb(i64 x)
{
	return sd(x*x)==sd(x)*sd(x);   // x<=1e9 => x*x<=1e18 < 9.22e18，i64 安全
}

void dfs(i64 x)   // x 的十进制各位都 <=3
{
	if(x>0&&israb(x))
		rab[cnt++]=x;
	for(i64 d=0;d<=3;++d)
	{
		i64 y=x*10+d;   // 注意 y 可达 1e10，必须 i64
		if(y>0&&y<=R)
			dfs(y);
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>L>>R;
	dfs(0);
	sort(rab,rab+cnt);
	i64 lo=lower_bound(rab,rab+cnt,L)-rab;   // 第一个 >=L
	i64 hi=upper_bound(rab,rab+cnt,R)-rab;   // 第一个 >R
	cout<<hi-lo<<'\n';
	return 0;
}
```

### 代码说明

- **全局静态数组** + `constexpr int mxn{262144+5}`（候选上界 $+5$ 松弛），`rab` 存 `i64`，`cnt` 计数；无 `vector` 状态。
- **无需 `fill_n`**：`rab` 的有效区是 `[0,cnt)`，由 `cnt` 精确界定，不存在"全局默认 0 被当成有效值/无穷大"的移植陷阱；本题也没有 INF 数组，如实说明。
- **`i64` 三处必要**：`x*x`（$\le10^{18}$）、DFS 里的 `x*10+d`（$\le10^{10}$）、`sd` 的参数（$x^2$ 需 64 位）。`int` 在这三处都会溢出，见 §4.3。
- **0-based 内部下标**：`rab[0..cnt-1]`；数字位 $a_0$ 为个位，与证明一致；输出的是计数，不涉及"还原编号"。
- **终止性**：`dfs` 只在 `y>0` 时递归，而 `y=10x+d>x`（$y>0$），严格递增且有上界 $R$，深度 $\le10$，无重复（引理 7）。
- **`hi` 恒等于 `cnt` 但保留 `upper_bound`**：因为生成时已用 `y<=R` 剪枝，表内不会有超过 $R$ 的数，`hi` 事实上 $=$`cnt`；仍写 `upper_bound(...,R)` 是把"区间口径"显式写出来——若日后去掉剪枝或改成"生成到 $10^9$ 打表"，这行不必改动，而 `hi-lo` 仍然是对的（§2.5 定理第 4 条只依赖升序与左闭右开）。
- **数组越界有预算**：`cnt` $\le$ 候选数 $\le 262144<\texttt{mxn}$（§2.4 的等比求和），故 `rab[cnt++]` 安全，不需要动态容器。
- **风格**：`#include<bits/stdc++.h>`、`using namespace std;`、`cin.tie/cout.tie/ios::sync_with_stdio` 固定顺序、`'\n'` 不用 `endl`、Tab 缩进、运算符无空格、小写电报式函数名 `sd/israb/dfs`。
