# P1847 轰炸II

> 难度：普及- · 标签：模拟

## 1. 重新读题
### 1.1 问题重述（人话版）
发生了 $M$ 次轰炸，第 $i$ 次（从 1 开始数）炸一个四边都与坐标轴平行的矩形，输入给的是两个对角：左上 $(x_1,y_1)$ 和右下 $(x_2,y_2)$。之后给 $N$ 个关键点。对每个点回答有没有被炸到；炸到的话，中了几次，以及最后一次是第几轮。

### 1.2 关键约束与规模暗示
$M,N\le 2000$，所以对每个点把 $M$ 个矩形都看一遍是 $4\times 10^6$，足够。坐标范围到 $2^{32}-1$，比 32 位有符号整数大，必须用 64 位（或无符号 32 位）存坐标。第一行的顺序是 $M$ 然后 $N$，不是 $N$ 然后 $M$。

## 2. 思维链（Chain-of-thought）
**引理 1**：点 $(x,y)$ 落在以 $(x_1,y_1)$、$(x_2,y_2)$ 为对角的轴对齐矩形里，当且仅当 $x$ 介于两个横坐标之间（含端点），$y$ 介于两个纵坐标之间（含端点）。

证明：轴对齐矩形就是这两个横坐标、两个纵坐标画出的闭矩形。闭矩形的点集正是

$$
\{(x,y)\mid \min(x_1,x_2)\le x\le \max(x_1,x_2),\; \min(y_1,y_2)\le y\le \max(y_1,y_2)\}.
$$

题面举例 `1 3 7 10` 表示从 $(1,3)$ 到 $(7,10)$，端点包含在内，否则角上的点会漏计。输入若把两个角写反，取 min/max 以后还是同一个矩形，不改变点集。$\square$

**引理 2**：点被炸的次数等于覆盖它的矩形个数；最后一轮等于这些矩形里最大的输入序号（从 1 开始）。没被覆盖则答案是 `NO`。

证明：每次轰炸独立计数，题面要的就是「被炸了几次」和「最后一次是第几轮」。输入顺序就是轮次。沿轮次从小到大扫描，每次命中就把计数加 1、并把「最后一轮」改成当前轮，结束时留下的就是最大轮次。计数为 0 表示从未命中。$\square$

**定理**：$O(MN)$ 逐点扫描矩形，按引理 1 判断、按引理 2 统计，输出与题意一致。

证明：每个点、每个矩形恰好判断一次，判断条件是引理 1，汇总方式是引理 2。$M,N\le 2000$ 时运算量约 $4\times 10^6$。$\square$

标程是「点在外层、矩形在内层」，命中时顺手记下轮次。暴力是「矩形在外层、点在内层」，用数组累加 `cnt` 和 `last`。循环方向不同，由引理 2 两者数的是同一个集合，答案相同。坐标用 `long long`，样例里的点 $(11,11)$ 不在 $[1,10]\times[1,10]$ 内，输出 `NO`。

## 3. 模式总结（Pattern Summary）
- **explore its property** — 矩形轴对齐，包含关系就是两边坐标各自夹在两端点之间，而且端点算炸到。
- **consider subtask** — $M,N\le 2000$，双重循环就是完整解，不必上扫描线。
- **classic problem solution** — 按轮次扫，计数加一，最后一轮取最大编号。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `m,n` | `int` | 轰炸次数、关键点数 | 读入，$m$ 在前 | bombs / points |
| `r[i]` | `rec[2005]` | 第 $i$ 个矩形，坐标已排成 $x_1\le x_2,y_1\le y_2$ | 读入后交换 | rectangle |
| `cnt,last` | `int` | 当前点的命中次数、最后轮次 | 0 | count |
| `hit` | 函数 | 引理 1 | — | inside |

坐标类型是 `i64`。

### 4.2 算法步骤
1. 读 $m,n$ 和 $m$ 个矩形，必要时交换坐标使左端 $\le$ 右端、下端 $\le$ 上端。
2. 对每个关键点 $(x,y)$，扫全部矩形。命中则 `++cnt`，`last=j+1`。
3. `cnt==0` 输出 `NO`，否则输出 `YES cnt last`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）
时间 $O(MN)$，空间 $O(M)$。`g++ -O2 -std=c++17 -Wall -Wextra -Werror` 无警告。与「轮次在外层」的另一重循环对拍 65 组（含样例 `NO`，手算的两轮轰炸 `YES 1 1 / YES 2 2 / NO`，以及坐标 $2^{32}-1$、对角写反的数据），checker 墙钟 2.731s。最大数据 $M=N=2000$、坐标取满 $1..2^{32}-1$，两边一起 0.056s 且输出一致。

## 5. 示例代码
### 5.1 标程（`P1847.cpp`）

```cpp
//
// 题目：P1847 轰炸II
// https://www.luogu.com.cn/problem/P1847
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{2005};

struct rec
{
	i64 x1,y1,x2,y2;
}r[mxn];

int m,n;

bool hit(int i,i64 x,i64 y)
{
	return r[i].x1<=x&&x<=r[i].x2&&r[i].y1<=y&&y<=r[i].y2;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>m>>n;
	for(int i=0;i<m;++i)
	{
		cin>>r[i].x1>>r[i].y1>>r[i].x2>>r[i].y2;
		if(r[i].x1>r[i].x2)
			swap(r[i].x1,r[i].x2);
		if(r[i].y1>r[i].y2)
			swap(r[i].y1,r[i].y2);
	}
	for(int i=0;i<n;++i)
	{
		i64 x,y;
		cin>>x>>y;
		int cnt=0,last=0;
		for(int j=0;j<m;++j)
		{
			if(hit(j,x,y))
			{
				++cnt;
				last=j+1;
			}
		}
		if(cnt==0)
			cout<<"NO\n";
		else
			cout<<"YES "<<cnt<<' '<<last<<'\n';
	}
	return 0;
}
```
