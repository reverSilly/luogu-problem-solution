# P1018 乘积最大 题解

---

## 一、发现之旅——从例子到问题本质

题面给出一个长 `N` 的数字串，允许插入 `K` 个乘号，将其切成 `K+1` 段，要求最大化这 `K+1` 个数的乘积。

先看小例子：数字串 `"312"`，`N=3`，`K=1`。只有两种拆分方式：

- `3 × 12 = 36`
- `31 × 2 = 62`

后者更优。这个例子告诉我们：**乘积的大小不仅取决于数字本身，还取决于乘号的位置**——把大的数字往后放还是往前放，结果天差地别。

当 `N` 更大、`K` 更多时，显然无法枚举所有可能。我们需要找到一种系统性的方法，从"小规模"递推到"大规模"。

---

## 二、链式思考——从暴力到 DP 的完整推导

### 2.1 暴力搜索视角

一个最直接的想法是：**搜索乘号的位置**。

假设我们已知前 `i` 个数字中放了 `j` 个乘号的最优解（最大乘积），那么要得到前 `i+1` 个数字中放 `j` 个乘号的解，可以枚举第 `j` 个乘号的位置。

但这里有一个关键问题：**乘积不具有"独立子问题最优"的直观保证**。也就是说，前 `i` 个数字中使乘积最大的放法，是否一定能作为全局最优的前缀？这需要证明。

### 2.2 最优子结构证明

**定义**：设 `f(i,j)` 表示数字串的前 `i` 个字符（下标 `0..i-1`）中插入 `j` 个乘号，能得到的最大乘积。

**断言**：`f(i,j)` 具有最优子结构。

**证明**（反证法）：

假设前 `i` 个数字、`j` 个乘号的最优方案中，最后一个乘号放在位置 `p`（即乘号在第 `p` 个字符之后、第 `p+1` 个字符之前，`0 ≤ p < i-1`）。那么该方案将前 `i` 个数字分成两部分：

- 左边：前 `p+1` 个数字，内含 `j-1` 个乘号 → 它们的乘积记为 `L`
- 右边：第 `p+1` 到第 `i-1` 个数字（不含乘号）→ 视为一个整数 `R`

于是 `f(i,j) = L × R`。

如果存在另一种左边的拆分方案，使得左边乘积 `L' > L`，那么用 `L'` 代替 `L` 会得到 `L' × R > L × R = f(i,j)`，与 `f(i,j)` 的最优性矛盾。

因此，左边必须是前 `p+1` 个数字中用 `j-1` 个乘号的最优解，即 `f(p+1, j-1)`。

**最优子结构得证。**

### 2.3 状态转移方程

由上述证明，我们可以写出递推式：

```
f(i,0) = num(0, i-1)          // 不加乘号，整个前缀就是一个数
f(i,j) = max_{j ≤ p < i}  [ f(p, j-1) × num(p, i-1) ]   // j ≥ 1
```

其中 `num(l, r)` 表示数字串从 `l` 到 `r`（闭区间）构成的整数。

**边界**：
- `i` 的取值范围：`1 ≤ i ≤ N`
- `j` 的取值范围：`0 ≤ j ≤ K`，且 `j < i`（因为 `j` 个乘号至少需要 `j+1` 个数字）
- `f(i,j)` 仅在 `i ≥ j+1` 时有定义

最终答案：`f(N, K)`。

### 2.4 高精度的必要性

题目中 `N ≤ 40`。虽然 `N` 看起来不大，但乘积可能非常大。考虑最坏情况：

- `K+1` 个非负整数，它们的数字位数之和为 `N`
- 每个部分最大不超过 `10^{len} - 1`
- 乘积 ≤ `(10^{len_1}-1) × ... × (10^{len_{K+1}}-1) < 10^{len_1 + ... + len_{K+1}} = 10^N`

也就是说乘积的位数不超过 `N = 40` 位。40 位十进制数远超 `long long`（约 19 位）的表示能力，必须使用**高精度整数**。

我选择用**字符串**（每位一个 `char`）来表示大整数，并手动实现乘法与比较。

## 三、模式总结——何时使用此类 DP

这类问题属于**区间划分型 DP**，有鲜明的特征：

| 特征 | 本题对应 |
|------|----------|
| 线性序列 | 长度为 N 的数字串 |
| 插入 K 个分隔符 | K 个乘号 |
| 每段独立计算贡献 | 每段数字作为因子 |
| 总贡献是各段贡献的运算结果 | 乘积分段相乘 |
| 求最优值 | 最大乘积 |

更一般地，凡是"在长度为 N 的序列中插入 K 个分隔符，使得各段的某个函数值（和/积/最大值等）整体最优"的问题，都可以考虑类似的 DP 框架：

```
dp[i][j] = optimize over split point p of combine(dp[p][j-1], segment(p,i))
```

常见变体：
- **乘积最大**（本题）：`combine = ×`
- **加法最大**：`combine = +`
- **分割成回文串**：`combine = 1`（是否回文）

## 四、完整解法与符号说明

### 符号

| 符号 | 含义 |
|------|------|
| `N` | 数字串长度 |
| `K` | 乘号个数 |
| `s` | 输入的数字串，`s[0..N-1]` |
| `dp[i][j]` | 前 `i` 个字符中放 `j` 个乘号的最大乘积（字符串表示） |
| `substr(l, len)` | 从 `s[l]` 开始长度为 `len` 的子串 |
| `mul(a, b)` | 两个非负整数（字符串表示）的乘积 |
| `cmp(a, b)` | 比较两个字符串表示的非负整数的大小 |

### DP 流程（配合图示）

```
状态空间：
   j=0    j=1    j=2   ...   j=K
i=1  o
i=2  o      o
i=3  o      o      o
...  ...    ...    ...
i=N  o      o      o     ...   o

箭头表示转移依赖：
  dp[i][j]  ←──  dp[p][j-1] × s[p..i-1]   对于 j ≤ p < i
```

**步骤**：

1. **初始化**：`dp[i][0] = s[0..i-1]`（整段作为一个数）
2. **递推**：对 `j = 1..K`，对 `i = j+1..N`：
   - 枚举分割点 `p = j..i-1`
   - `candidate = mul(dp[p][j-1], s.substr(p, i-p))`
   - 若 `candidate` 大于当前 `dp[i][j]`，则更新
3. **输出**：`dp[N][K]`

### 高精度乘法细节

字符串 `A` 和 `B` 相乘：
1. 将 `A`、`B` 从最低位到最高位存入 `vector<int>`（倒序方便进位）
2. 开一个 `len(A)+len(B)` 大小的结果数组 `C`
3. 三重循环：`C[i+j] += A[i] × B[j]`
4. 统一处理进位：`C[i+1] += C[i] / 10, C[i] %= 10`
5. 去除前导零（实际是去除 LSD 数组的尾部零）
6. 倒序输出为字符串

### 高精度比较细节

比较两个字符串表示的非负整数 `A` 和 `B`：
1. 先去除前导零
2. 长度不同时，长度长者大
3. 长度相同时，字典序大者大（因为已去除前导零）

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{45};
int n,k;
string s;
string dp[mxn][7];

string mul(string a,string b)
{
	vector<int>va,vb;
	for(int i=a.size()-1;i>=0;--i)
		va.push_back(a[i]-'0');
	for(int i=b.size()-1;i>=0;--i)
		vb.push_back(b[i]-'0');
	vector<int>vc(va.size()+vb.size(),0);
	for(int i=0;i<(int)va.size();++i)
		for(int j=0;j<(int)vb.size();++j)
			vc[i+j]+=va[i]*vb[j];
	for(int i=0;i<(int)vc.size();++i)
		if(vc[i]>=10)
		{
			vc[i+1]+=vc[i]/10;
			vc[i]%=10;
		}
	while(vc.size()>1&&vc.back()==0)
		vc.pop_back();
	string c;
	for(int i=vc.size()-1;i>=0;--i)
		c.push_back(vc[i]+'0');
	return c;
}

bool cmp(string a,string b)
{
	int i=0,j=0;
	while(i+1<(int)a.size()&&a[i]=='0')
		++i;
	while(j+1<(int)b.size()&&b[j]=='0')
		++j;
	a=a.substr(i);
	b=b.substr(j);
	if(a.size()!=b.size())
		return a.size()>b.size();
	return a>b;
}

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>k>>s;
	for(int i=1;i<=n;++i)
		dp[i][0]=s.substr(0,i);
	for(int j=1;j<=k;++j)
		for(int i=j+1;i<=n;++i)
			for(int p=j;p<i;++p)
			{
				string cur=mul(dp[p][j-1],s.substr(p,i-p));
				if(dp[i][j].empty()||cmp(cur,dp[i][j]))
					dp[i][j]=cur;
			}
	cout<<dp[n][k]<<'\n';
	return 0;
}
```

## 复杂度分析

| 维度 | 值 |
|------|-----|
| 状态数 | `O(NK)`，最多 `40 × 6 = 240` |
| 每状态转移 | 枚举 `O(N)` 个分割点 |
| 每次乘法 | 高精度乘法 `O(N²)`，最多 `40² = 1600` 次运算 |
| 总复杂度 | `O(K × N² × N²) = O(K·N⁴)` |
| 代入上限 | `6 × 40⁴ = 15,360,000`，约 1.5×10⁷ 次操作，完全可过 |

空间复杂度：`O(NK × N)`，即 `O(N²K)`，约 `240 × 40 ≈ 9600` 个字符，微不足道。

## 易错点

1. **下标细节**：`dp[i][j]` 中的 `i` 表示**前 `i` 个字符**（下标 `0..i-1`），不是从 `0` 到 `i`。这在写循环时容易混淆，建议统一用"前缀长度"而非"结束下标"。
2. **高精度比较的前导零**：虽然乘法结果没有前导零，但 `dp[i][0]` 直接从原始字符串截取，可能包含前导零。比较时必须先去除。
3. **乘号数量约束**：`j` 个乘号至少需要 `j+1` 个数字，所以 `i` 从 `j+1` 开始枚举，`p` 从 `j` 开始。
4. **空串处理**：`dp[i][j]` 初始为空，首轮赋值直接写入，后续用 `cmp` 比较。
