# P1870 公交车

> 难度：普及- · 标签：模拟

## 1. 重新读题
### 1.1 问题重述（人话版）

$n$ 辆车从同一起点开往相距 $d$ 米的终点。第 $i$ 辆在时刻 $t_i$ 出发，出发时速度是 $0$，加速度不超过 $a$，速度不超过 $v_i$，可以瞬间把加速度改成允许范围内的任意值，也可以瞬间减速。车不能超车：一旦追上前车，就并排开到终点，同时到达。每辆车都想尽早到。求每辆车的到达时刻，绝对或相对误差不超过 $10^{-4}$。

### 1.2 关键约束与规模暗示

$1\le n\le 10^5$，$1\le a,d\le 10^6$，$t$ 严格递增且不超过 $10^6$，$1\le v_i\le 10^6$。不能逐时刻模拟。先算每辆车单独开的最优时间，再和前一辆的到达时刻取 $\max$，整体 $O(n)$。

## 2. 思维链（Chain-of-thought）

**引理 1（单车最优）。** 没有前车时，最优策略是以加速度 $a$ 一直加到 $\min(v_i,\sqrt{2ad})$，若中途速度顶到 $v_i$ 就改成匀速。行驶时间
$$
T(v)=\begin{cases}
\sqrt{2d/a}, & v^2/(2a)\ge d,\\
v/a+(d-v^2/(2a))/v, & \text{否则.}
\end{cases}
$$
到达时刻是 $t_i+T(v_i)$。

证明：加速度恒为正时，尽早把速度拉高，后面每一段路都更快，任何中途减速或减小加速度都会让同一位置的时刻变晚。速度上限是 $v$，所以加到 $v$ 后不能再加。加速阶段路程是 $v^2/(2a)$，时间是 $v/a$；这段已经超过 $d$ 时，解 $\tfrac12 at^2=d$ 得第一式。否则剩下的路以速度 $v$ 匀速。终点不要求速度为 $0$，所以不必提前刹车。$\blacksquare$

**引理 2（不能超车时到达时刻单调）。** 记第 $i$ 辆单独开的到达时刻为 $s_i=t_i+T(v_i)$，实际到达时刻 $A_i$。则 $A_1=s_1$，且
$$
A_i=\max(A_{i-1},s_i).
$$

证明：后车不能超过前车，追上之后只能并排，所以 $A_i\ge A_{i-1}$。没有任何限制时最早是 $s_i$，限制只会让它更晚或不变，所以 $A_i\ge s_i$。于是 $A_i\ge\max(A_{i-1},s_i)$。

再证这个下界够得到。所有车的加速度上限都是同一个 $a$，速度曲线在达到各自 $v$ 之前斜率同为 $a$。设前车上限 $v_1$、后车 $v_2$，后车出发更晚。

- 若 $s_i\ge A_{i-1}$，后车按引理 1 单开不会在终点前被挡住。反证：若在路程 $s<d$ 处追上，那时后车的期望速度已经不低于前车（否则还在后车加速、前车已开得更久，同加速度下前车速度更高，后车碰不上）。追上之后后车仍想开得不比前车慢，若不受阻会更早到终点，于是 $s_i<A_{i-1}$，与 $s_i\ge A_{i-1}$ 矛盾。所以这条单开轨迹全程合法，$A_i=s_i$。
- 若 $s_i<A_{i-1}$，后车单开会更早到。它在终点前必与前车轨迹相交（前车在 $A_{i-1}$ 才到终点，后车单开更早到达同一终点，由位置的连续性，存在更早的相遇点）。相遇后并排，到达时刻被抬到 $A_{i-1}$。$\blacksquare$

样例 $n=3,a=10,d=10000$，三辆 $(0,10),(5,11),(1000,1)$：第一辆加速 $1$ 秒走 $5$ 米，再匀速 $999.5$ 秒，到达 $1000.5$；第二辆单开更早，被抬到 $1000.5$；第三辆单开到达 $11000.05$，追不上。另一样例 $a=2,d=26,t=28,v=29$ 全程在加速，$\sqrt{26}+28=33.0990195136$。

## 3. 模式总结（Pattern Summary）

- **solve one bus in closed form** — 先加速再可能匀速，二次方程或两段路程
- **no braking at the finish** — 终点速度不必是 $0$
- **cannot arrive before the bus ahead** — 实际到达时刻不低于前车
- **cannot arrive before the free time** — 也不低于单开时间
- **the max of the two is tight** — 追得上就并排，追不上就单开

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `n` | `int` | 车辆数 | 读入 | $\le 10^5$ |
| `ac,d` | `double` | 加速度、路程 | 读入 | 题面 $a,d$ |
| `pre` | `double` | 前一辆的到达时刻 | $0$ | 滚动的 $A_{i-1}$ |
| `ans[100005]` | `double` | 每辆的到达时刻 | 计算后 | 先算完再输出 |

### 4.2 算法步骤

1. 读 $n,a,d$。
2. 对每辆车算引理 1 的 $s_i$，令当前到达为 $\max(s_i,pre)$，再更新 `pre`。
3. 以 `fixed` 和 $10$ 位小数输出。绝对误差远小于 $10^{-4}$。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 $O(n)$，空间 $O(n)$。

`g++ -O2 -std=c++17 -Wall -Wextra` 无警告。暴力对单车时间做 $120$ 次二分（加速/匀速路程函数），再同样与前车取 $\max$，和闭式不是同一段代码。比较用绝对误差 $10^{-4}$（也接受相对误差 $10^{-4}$）。两个官方样例：

- `1000.5000000000`、`1000.5000000000`、`11000.0500000000`
- `33.0990195136`

另有 $40$ 组随机。最大数据 $n=10^5,a=d=10^6$ 标程与暴力都算过。结果：

- `47 tests OK`
- 最大数据标程墙钟 `0.272760s`

## 5. 示例代码
### 5.1 标程（`P1870.cpp`）

```cpp
//
// 题目：P1870 公交车
// https://www.luogu.com.cn/problem/P1870
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n;
double ac,d;
double ans[mxn];

double solo(double v)
{
	double tacc=v/ac;
	double sacc=v*v/(2.0*ac);
	if(sacc>=d)
		return sqrt(2.0*d/ac);
	return tacc+(d-sacc)/v;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cout<<fixed<<setprecision(10);

	cin>>n>>ac>>d;
	double pre=0;
	for(int i=0;i<n;++i)
	{
		double t,v;
		cin>>t>>v;
		double cur=t+solo(v);
		if(cur<pre)
			cur=pre;
		pre=cur;
		ans[i]=cur;
	}
	for(int i=0;i<n;++i)
		cout<<ans[i]<<'\n';
	return 0;
}
```
