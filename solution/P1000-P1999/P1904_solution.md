# P1904 天际线

## 1. 重新读题

### 1.1 问题重述（人话版）

给若干栋建筑 $(L_i,H_i,R_i)$，表示这栋楼盖在横坐标区间 $[L_i,R_i)$ 上、高度为 $H_i$（$L_i$ 是左边界，$R_i$ 是右边界，右端**不包含**）。所有建筑共享同一条水平地面。

把这些建筑的并集看成一块「实体」，求它的**上轮廓线**。输出方式是：按 $x$ 从小到大，每当地面以上的高度发生变化，就输出一个折点 $(x,\text{新高度})$。写成一行就是交替的 $x_1,y_1,x_2,y_2,\dots$，其中 $y$ 是该 $x$ 处的轮廓高度。

样例中给出的 `(1,11,5),(2,6,7),(3,13,9),...` 对应输出

```
1 11 3 13 9 0 12 7 16 3 19 18 22 3 23 13 29 0
```

### 1.2 关键约束与规模暗示

- 所有坐标都是**小于 $10^4$ 的正整数**（即 $1\sim 9999$），建筑数不超过 $5000$。
- 坐标值域极小（$<10^4$），这强烈暗示可以**直接开一个长度为 $10^4$ 的高度数组**，逐格维护最大高度。
- 最坏代价：$5000\times 10^4=5\times 10^7$ 次取 max，在 C++ 中可以轻松跑过。
- 输出的是「折点」而不是每一格，因此最后要扫描一遍数组，只在高度变化处输出。
- 输入没有给出建筑数量，需要**读到文件结束**（`while(cin>>L>>H>>R)`）。

---

## 2. 思维链（Chain-of-thought）

### 2.1 直接刻画轮廓高度

轮廓在某个横坐标 $x$ 处的高度，就是覆盖 $x$ 的所有建筑高度的最大值：

$$
H(x)=\max\{H_i:\ L_i\le x<R_i\},
$$

若没有建筑覆盖 $x$ 则 $H(x)=0$。

**引理 1**：按上面的 $H(x)$ 定义，只要依次输出所有满足 $H(x)\ne H(x-1)$ 的 $(x,H(x))$（约定 $H(-1)=0$，并额外处理最大右端点之后的 $0$），就恰好得到题面要求的折点序列。

**证明**：

- 轮廓线是分段常值函数，只有在某栋楼开始（$L_i$）或结束（$R_i$）时高度才可能改变。因此「高度发生变化的位置」正好是折点的 $x$ 坐标。
- 每段常值段的左端点处输出「新高度」，就描述了整条轮廓：两个折点之间轮廓是高度为前一个 $y$ 的水平线段。
- 第一段从最左建筑左端开始，之前 $H=0$，所以第一个变化点一定是某栋楼的左端点，输出其高度；最后一段结束后高度回到 $0$，在最大右端点处 $H=0$，也会触发一次变化（因为此前 $H>0$），输出终点 $(x_{\max},0)$。这与样例末尾 `29 0` 一致。$\square$

### 2.2 为什么可以暴力逐格

坐标都 $<10^4$，把 $x=0,1,\dots,9999$ 的高度数组 `h[]` 开出来。对每栋楼 $(L,H,R)$，在 `x=L..R-1` 上执行 `h[x]=max(h[x],H)`。

然后从左到右扫一遍，`prv` 记录上一格高度，遇到 `h[x]!=prv` 就输出。

总操作数 $\le 5000\times 10^4=5\times 10^7$，完全不虚。这个题不需要线段树；线段树/离散化是更通用的做法，但在这里是杀鸡用牛刀。

### 2.3 两个边界细节

1. **右端开区间**：样例中楼 $(3,13,9)$ 覆盖 $x=3,\dots,8$，在 $x=9$ 处高度变为 $0$，输出 `9 0`。所以循环必须写 `x<R` 而不是 `x<=R`。
2. **扫描范围**：要扫到「最大右端点」这一格。因为该格本身不被任何楼覆盖（$H=0$），在这里会触发「高度从正变 $0$」的变化，从而输出最后的 $(R_{\max},0)$。若只扫到 $R_{\max}-1$，就会漏掉收尾的 $0$。
3. **输出分隔**：数字之间用一个空格隔开，第一个数字前、最后一个数字后都不要多余空格。

### 2.4 更一般的做法（仅作对照）

如果坐标值域很大，就需要离散化：把每个 $L_i,R_i$ 收集起来排序，用「区间赋值取 max」的线段树维护每段的高度，再扫描相邻段。本题坐标 $<10^4$，直接开桶即可，没必要引入线段树。

---

## 3. 模式总结（Pattern Summary）

- **explore its property** — 轮廓在 $x$ 处的高度 = 覆盖该点的所有建筑高度的最大值，轮廓是分段常值函数。
- **reduce to easier problem** — 坐标值域只有 $10^4$，把「区间取 max」退化为直接逐格取 max 的数组。
- **defer reconstruction** — 先建好整张高度表，最后再从左到右找高度变化的折点输出。

---

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `h[x]` | `int [10005]` | 横坐标 $x$ 处的轮廓高度 | 全部 0 | height |
| `L,H,R` | `int` | 当前读入的建筑左端、高度、右端 | 读入 | building |
| `mxr` | `int` | 所有建筑右端点的最大值 | 0 | max right |
| `prv` | `int` | 扫描时上一格的高度 | 0 | previous |
| `first` | `bool` | 是否还没输出过任何数（控制空格） | `true` | 输出格式 |

### 4.2 算法步骤

1. 循环 `while(cin>>L>>H>>R)` 读入每栋楼；对 `x=L..R-1` 执行 `h[x]=max(h[x],H)`；更新 `mxr=max(mxr,R)`。
2. `prv=0`，`first=true`；对 `x=0..mxr`：
   - 若 `h[x]!=prv`：若不是第一个输出则先输出一个空格；输出 `x` 和 `h[x]`（中间一个空格）；令 `prv=h[x]`。
3. 输出换行。

### 4.3 复杂度分析

- **时间复杂度**：建表 $O(\sum(R_i-L_i))\le 5\times10^7$；扫描 $O(10^4)$。总体可视为 $O(B\cdot X)$，$B\le5000$，$X<10^4$。
- **空间复杂度**：$O(10^4)$，即一个高度数组。

## 5. 示例代码

```cpp
//
// 题目：P1904 天际线
// https://www.luogu.com.cn/problem/P1904
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};

int h[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int L,H,R,mxr{0};
	while(cin>>L>>H>>R)
	{
		for(int x=L;x<R;++x)
			h[x]=max(h[x],H);
		mxr=max(mxr,R);
	}

	int prv{0};
	bool first{true};
	for(int x=0;x<=mxr;++x)
	{
		if(h[x]!=prv)
		{
			if(!first)
				cout<<' ';
			cout<<x<<' '<<h[x];
			first=false;
			prv=h[x];
		}
	}
	cout<<'\n';
	return 0;
}
```
