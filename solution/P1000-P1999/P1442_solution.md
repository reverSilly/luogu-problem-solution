# P1442 铁球落地

> 标签：动态规划 / 线段树（区间赋值 + 单点查询）/ 离散化 / 最短路(DAG) · 难度：省选/NOI-

## 1. 重新读题

**问题重述（白话版）**

- 平面上有 $n$ 个**水平开线段**（平台）：第 $i$ 个在高度 $h_i$ 上，横坐标范围 $(l_i,r_i)$，端点 $(l_i,h_i),(r_i,h_i)$ **不属于**平台本身。
- 球是一个质点，初始在 $(x_0,y_0)$。
- 球下方没有平台时，竖直下落，速度 $1$ 单位/秒。
- 球落到某平台后，只能选择**向左**或**向右**滚，速度 $1$ 单位/秒；滚到该平台的那个端点就立刻离开平台开始下落（题面明确"不需要滚动至下一个格子"）。
- **每一次**下落竖直距离不能超过 $h$（超过就摔碎）。
- 地面是 $y=0$ 的无限宽直线，落地即结束。
- 求最早落地时间。

**目标函数的构成**：总时间 $=\sum(\text{每段竖直下落距离})+\sum(\text{每段水平滚动距离})$，是整数；决策只在"落到某平台上"的瞬间发生（选左或选右），中途无别的操作 —— 典型的**序贯决策**问题。

**数据范围（决定了目标复杂度）**

| 量 | 范围 | 推论 |
|---|---|---|
| $n$ | $\le 10^5$ | $O(n^2)$ 一定 TLE；需 $O(n\log n)$ |
| $x_0,y_0,h,h_i,l_i,r_i$ | $\le 10^9$，$l_i<r_i$ | 坐标必须**离散化**；中间量必须 64 位 |
| 所有 $h_i$ | 互不相同 | "按高度排序"是**唯一**确定的拓扑序，无并列歧义 |
| $i\ne j$ | $l_i\ne r_j$ | 排除"$x$ 恰好等于别人端点"这一类歧义（但 $x=l_i$ 仍要按开线段处理） |
| 答案 | $\le 10^9$，保证有解 | 输出可用 `int`，但计算过程中不可行的分支要能表达"无穷大" |

**陷阱与边界（先列，后文逐条证明/处理）**

1. **开线段**：判断"平台 $j$ 能否接住 $x$ 处的下落"必须用严格不等式 $l_j<x<r_j$；$x=l_j$ 或 $x=r_j$ 都接不住。题图"小球在 $(9,9)$ 处已经开始下落"正是在说：滚到端点即离开，**不必**滚到端点之外的下一个整数格。
2. **不能跳过**：$x$ 正下方**第一个**（最高的）平台若距离 $>h$，这条路就碎，**不能**由更低的平台来接（引理 3）。这是本题最容易写错的一点：很多人把它写成"$x$ 下方所有 $Y-h_j\le h$ 的平台中任选"。
3. **$h$ 限制是"每一段"**，不是累计下落高度；总下落可以远超 $h$。
4. **状态必须带落点**：`f[i]=从平台 i 到地面的最短时间`不成立，滚动距离依赖具体落点 $x$（引理 4 给反例，引理 5 给正确的拆分方式）。
5. **横向滚动也计时间**，速度同为 1 单位/秒，所以"绕远路但下方有平台"和"就近滚到端点直接落地"必须放在一起比较，不能只看下落。
6. **题面两个 $h$**：最大下落高度 $h$ 与平台高度 $h_i$ 同名，本文分别记作 `lim` 与 $ht_i$ / 代码里 `lim` / `ht[i]`。
7. **高于起点的平台永不参与**（球不能往上飞）；按高度递增处理时它们排在起点之后，自动被排除。
8. **退化情形**：若存在平台满足 $ht_j=y_0$ 且 $l_j<x_0<r_j$，球初始就"贴在"该平台上。题面未说明，本文取"下落距离 $0$ 也算落到它"这一读法（两种读法互不支配，见 §2.7），做法是把虚平台排在同高度真实平台**之后**处理（见 §4.2 步骤 3）。
9. **本地题面没有样例**（`P1442.md` 只有 Description / Input / Output / 数据范围），因此**无法与官方答案对标**；本文只用 5 组自造数据做完整手算轨迹验证（§4.4），并逐条与"直接枚举策略"的结果比对。
10. 题面 tags 里同时给了「线段树」与「颜色段均摊（珂朵莉树 ODT）」：二者都能做同一件事（区间赋值 + 单点查询）。本文选**线段树**，因为它给出最坏情况 $O(n\log n)$；ODT 在此题的赋值序列（按高度递增）下同样均摊良好，但依赖数据顺序，不作保证。

## 2. 思维链（Chain-of-thought）

### 2.1 探索机制：一次"落 → 滚 → 落"到底发生了什么

先把物理过程翻译成纯坐标语言。球只有两种运动：**竖直下落**（$x$ 不变）和**水平滚动**（$y$ 不变，在某平台内部）。于是"球在哪些 $x$ 处下落"是第一件要说清楚的事。

**引理 1（下落线只有有限条）**
整个过程中所有竖直下落都发生在
$$x\in S=\{x_0\}\cup\{l_i:1\le i\le n\}\cup\{r_i:1\le i\le n\}$$
上，$|S|\le 2n+1$。

**证明**：对下落的次数做归纳。
- 第 1 次下落从初始位置出发，$x=x_0\in S$。
- 设某次下落的 $x=c\in S$。球若被平台 $j$ 接住，接下来只会沿平台 $j$ 滚到 $l_j$ 或 $r_j$，然后从该**端点**离开平台开始下一次下落，下一次下落的 $x$ 是 $l_j$ 或 $r_j$，仍属于 $S$。
- 若球直接落地，过程结束，不再产生下落线。
故每一条下落线都能写成"从 $x_0$ 出发，每步把 $x$ 换成某个平台的端点"，归纳即得所有下落线的 $x$ 都在 $S$ 中。$\blacksquare$

> 这条引理是**离散化**的依据：只需要关心 $S$ 中这些竖直线。

**引理 2（谁接住我 = 严格包含我 + 最高的那个）**
球从 $(c,Y)$ 由静止开始下落，设
$$A(c,Y)=\{j:\;l_j<c<r_j,\;ht_j<Y\}.$$
- 若 $A(c,Y)\ne\varnothing$，接住球的是其中 $ht$ **最大**的平台 $j^\ast$，下落距离为 $Y-ht_{j^\ast}$，落点是平台 $j^\ast$ 上的 $(c,ht_{j^\ast})$。
- 若 $A(c,Y)=\varnothing$，球直接落到地面，下落距离 $Y$。

**证明**：球在 $Y'\in(0,Y)$ 高度处的位置恒为 $(c,Y')$。
- ($\Rightarrow$) 平台是水平的开线段，质点要"落到平台上"，必须存在 $j$ 与 $Y'$ 使 $Y'=ht_j$ 且 $l_j<c<r_j$。取所有这样的 $j$ 中 $ht$ 最大者 $j^\ast$：当 $ht_{j^\ast}<Y'<Y$ 时 $(c,Y')$ 不在任何平台上（否则该平台的 $ht>ht_{j^\ast}$，与极大性矛盾），所以球一路上自由下落直到 $Y'=ht_{j^\ast}$，此刻 $(c,ht_{j^\ast})$ 落在平台 $j^\ast$ 的开线段内（$l_j<c<r_j$ 已验证），故被 $j^\ast$ 接住。
- ($\Rightarrow$ 地面情形) 若 $A(c,Y)=\varnothing$，则任意 $Y'\in(0,Y)$、任意平台 $j$ 都不满足"$ht_j=Y'$ 且 $l_j<c<r_j$"，故全程不受阻挡，一直落到 $y=0$。
- ($\Leftarrow$ 唯一性) 反过来，任何把球接住的平台都必须满足 $l_j<c<r_j$ 且 $ht_j<Y$，即必须属于 $A(c,Y)$；而球自上而下先碰到最高的那个，因此不可能是别的平台。$\blacksquare$

这里 $l_j<c<r_j$ 用**严格**不等式，正是"平台是开线段"的直接后果；$ht_j<Y$ 也是严格的（同一高度上没有"下方"可言；$ht_j=Y$ 只可能出现在起点与某平台同高的退化情形，见 §2.7）。本文后面写 $A(c,ht_i)$ 时 $Y$ 取 $ht_i$ 或 $y_0$（虚平台），二者统记为 $Y$。

**引理 3（不可跳过：碎就是碎）**
若引理 2 给出的 $j^\ast$ 满足 $Y-ht_{j^\ast}>lim$，则该下落**必然摔碎**；不存在"让 $j^\ast$ 不接住、继续下落给更矮的平台接"的选择。若 $A(c,Y)=\varnothing$ 且 $Y>lim$，同样必碎。

**证明**：由引理 2，球在 $(c,ht_{j^\ast})$ 处一定与平台 $j^\ast$ 相遇（该平台确实存在于 $c$ 的正下方且开线段包含 $c$）。相遇后球只有两种命运：落在平台上，或者题面所说"落下的高度超过 $h$"即碎。因为相遇时的下落距离已是 $Y-ht_{j^\ast}>lim$，碎在最前面发生，之后的任何平台都来不及参与。玩家唯一的自由度是"落到平台后往哪边滚"，没有"穿透平台"的选项。$\blacksquare$

> **机制小结**：一条下落线由 $(c,Y)\mapsto$ 平台 $j^\ast$（或地面）完全确定，是**函数**而非选择；唯一的自由度是每次落地后的**左右方向**。所以本题是"在一张隐含的有向图上选路"。

### 2.2 简化版：先把 $O(n^2)$ 暴力写对

暂不管 $n\le 10^5$，先假设 $n\le 500$，直接按引理 2 扫描所有平台找 $j^\ast$。

定义两个"从空中开始"的函数：

- $\text{Fall}(c,Y)$：球在 $(c,Y)$ 处开始下落到最终落地的最短时间；不可行记 $+\infty$。
- $\text{On}(j,x)$：球已经落在平台 $j$ 上的横坐标 $x$ 处（$l_j<x<r_j$），到最终落地的最短时间。

按引理 2、3 直接翻译：

$$\text{Fall}(c,Y)=\begin{cases}Y & A(c,Y)=\varnothing,\;Y\le lim\\ +\infty & A(c,Y)=\varnothing,\;Y>lim\\ (Y-ht_{j^\ast})+\text{On}(j^\ast,c) & A(c,Y)\ne\varnothing,\;Y-ht_{j^\ast}\le lim\\ +\infty & A(c,Y)\ne\varnothing,\;Y-ht_{j^\ast}>lim\end{cases}$$

$$\text{On}(j,x)=\min\big(\text{Fall}(l_j,ht_j)+(x-l_j),\;\;\text{Fall}(r_j,ht_j)+(r_j-x)\big)$$

答案就是 $\text{Fall}(x_0,y_0)$。

**这两条式子互相递归吗？** 不。$\text{On}(j,x)$ 只调用 $Y=ht_j$ 的 $\text{Fall}$；而 $\text{Fall}(c,ht_j)$ 里接住者 $j'$ 满足 $ht_{j'}<ht_j$（严格），所以只会走向**更矮**的平台。以"当前高度"为度量，递归严格下降，必然终止；base 是"下方没有平台"（$\text{Fall}$ 直接给出 $Y$ 或 $+\infty$）。

> 这就是"最短路"标签的来源：状态是"一条下落线"，边是"滚到左/右端点"或"落到下一个平台"，图按高度分层且边只向下，所以它是 **DAG**，最短路 = 按高度拓扑序做 DP，不需要 Dijkstra。

暴力实现：每次 $\text{Fall}$ 扫全部平台求 $j^\ast$，代价 $O(n)$。若直接记忆化所有 $(c,Y)$ 组合（$c\in S$，$Y$ 为某平台高度）会得到 $O(n^2)$ 个状态、$O(n^3)$ 时间；但用 2.3 的观察（只需每个平台的**两个端点**）可以把状态降到 $2n$ 个，总时间 $O(n^2)$ —— $n=500$ 可过，$n=10^5$ 差两个数量级，必须加速。加速的关键在 2.3 与 2.5。

### 2.3 状态设计：为什么 `f[i]` 不够，而"两个端点代价"够

**引理 4（$f[i]$ 不能省略落点 $x$）**
不存在"只依赖平台编号"的 $f[i]$ 能代替 $\text{On}(i,x)$，因为 $\text{On}(i,x)$ 真的随 $x$ 变化。

**证明（构造性反例）**：取 $lim=10^9$（相当于不设限），平台 $M$：$ht=10,\;l=1,\;r=11$；其下方无平台，于是 $\text{Fall}(1,10)=\text{Fall}(11,10)=10$，此时
- 落点 $x=2$（可以是某条更高平台的端点落下来的位置）：$\text{On}=\min(1+10,\;9+10)=11$；
- 落点 $x=6$（接近平台正中）：$\text{On}=\min(5+10,\;5+10)=15$。

$11\ne 15$，同一个平台在两个不同落点上的剩余代价相差 $4$，所以把 $\text{On}(M,x)$ 压成一个与 $x$ 无关的常数一定是错的。
（更本质地说：左右两支之差 $[(x-l_i)+L_i]-[(r_i-x)+R_i]=2x-(l_i+r_i)+(L_i-R_i)$ 随 $x$ 以斜率 $2$ 变化，会改变 $\arg\min$；丢掉 $x$ 就是丢掉方向信息。）$\blacksquare$

**引理 5（端点代价分解 —— 本题的核心技巧）**
定义两个**与落点无关**的量：
$$L_i=\text{Fall}(l_i,ht_i),\qquad R_i=\text{Fall}(r_i,ht_i).$$
则对任意落点 $x\in(l_i,r_i)$ 有
$$\text{On}(i,x)=\min\big((x-l_i)+L_i,\;(r_i-x)+R_i\big). \tag{$\ast$}$$
也就是说：平台 $i$ 的全部信息恰好压缩成两个数 $L_i,R_i$，落点的影响只剩"滚到端点的距离"这一项线性修正。

**证明（双向夹逼）**
- ($\ge$) 任一可行策略落到平台 $i$ 后，第一件且唯一能做的事是决定方向。若选左，它必须滚动 $x-l_i$（速度 1；开线段 $(l_i,r_i)$ 内部没有端点，所以中途不会提前掉落，必须一直滚到 $l_i$），到达 $l_i$ 后离开平台，剩下的过程恰是"从 $(l_i,ht_i)$ 开始下落"，最优值为 $L_i$，故该策略总代价 $\ge (x-l_i)+L_i$。选右同理 $\ge (r_i-x)+R_i$。取较小即得 $\text{On}(i,x)\ge$ 右式。
- ($\le$) 反过来，"$(\ast)$ 右式取到的那个分支"是可以真正执行的策略：设左支较小，就先向左滚 $x-l_i$ 秒到达端点，然后按达到 $L_i$ 的最优下落方案继续。它此后与 $L_i$ 的定义完全同域（同一个 $(c,Y)=(l_i,ht_i)$），故总时间 $=(x-l_i)+L_i$。右支对称。于是 $\text{On}(i,x)\le$ 右式。

两侧合起来即 $(\ast)$。$\blacksquare$

**引理 6（高度序 = 拓扑序，无后效性）**
$L_i$（以及 $R_i$）只依赖满足 $ht_j<ht_i$ 的平台的 $L_j,R_j$，以及"下方无平台"这一 base。

**证明**：由引理 5，$L_i=\text{Fall}(l_i,ht_i)$。用引理 2 展开，令 $j^\ast$ 为 $A(l_i,ht_i)$ 中最高者。
- 若 $A(l_i,ht_i)=\varnothing$：$L_i=ht_i$（当 $ht_i\le lim$）否则 $+\infty$，不含任何平台状态。
- 否则由引理 2、3、5：
$$L_i=\begin{cases}(ht_i-ht_{j^\ast})+\min\big((l_i-l_{j^\ast})+L_{j^\ast},\;(r_{j^\ast}-l_i)+R_{j^\ast}\big) & ht_i-ht_{j^\ast}\le lim\\[2mm] +\infty & ht_i-ht_{j^\ast}>lim\end{cases}$$
而 $A(l_i,ht_i)$ 的定义要求 $ht_{j^\ast}<ht_i$（严格），故右端只出现**更矮**平台的 $L,R$。以 $ht$ 为秩做归纳即得"按高度递增顺序计算"合法。$\blacksquare$

于是：**把平台按高度从小到大排序后依次算 $L_i,R_i$，一次线性扫描就够了。**
剩下唯一的问题是"怎么快速找到 $j^\ast$"，即：对每个端点 $c\in\{l_i,r_i\}$，求 $ht_j<ht_i$ 且 $l_j<c<r_j$ 中 $ht$ 最大者 —— 这是 2.5 的内容。

### 2.4 贪心剖析：两种"看起来很对"的方向选择都错

DP 出来之前，最自然的想法是"落到平台后当场决定往哪边滚"。逐个打掉。

**贪心 A（滚到较近的端点）**：错。反例 = §4.4 用例 4（$lim=10$，A$=(15,10,30)$、B$=(9,25,40)$，起点 $(12,20)$）：球落 $5$ 到 A 的 $x=12$，近端是左端（距离 $2$），但 $x=10$ 下方**没有平台**，要下落 $15>lim$ → **摔碎**；只能滚 $18$ 到右端 $x=30$，下落 $6$ 到 B，再滚 $5$ 到 $x=25$，下落 $9$ 落地，最优 $5+18+6+5+9=43$，贪心 A 直接不可行。

**贪心 B（往"下一步代价最小"的那边滚）**：错，而且错得隐蔽。反例 = §4.4 用例 3（$lim=20$，A$=(20,10,30)$、B$=(19,25,35)$、C$=(18,20,40)$，起点 $(24,25)$）：球落 $5$ 到 A 的 $x=24$。
- 往左滚 $14$ 到 $x=10$：下方无平台 → 下落 $20\le lim$ → 分支代价 $14+20=34$。
- 往右滚 $6$ 到 $x=30$：只下落 $1$ 就碰到 B —— "这一步只花 $7$"，远小于 $34$，贪心 B 选右。
但右支的真实代价是 $6+1+5+1+5+18=36$（滚 $6$ → 落 $1$ 到 B → 滚 $5$ 到 $x=25$ → 落 $1$ 到 C → 滚 $5$ 到 $x=20$ → 落 $18$ 地面），总 $5+36=41$；左支只要 $5+34=39$。**第一步便宜的路线整体更贵。**

**为什么 exchange argument 救不回来？** 落到平台 $i$ 之后，"往哪边滚"决定了**下一条下落线的 $x$**，而不同 $x$ 下方的遮挡结构（引理 2 的 $j^\ast$）完全不同；把两条支路在第一个分叉处交换，会同时改变后面**所有**段的下落距离与可行性，代价差的符号不固定。故本题不满足贪心替换性质。

> **关于"加权合并 / 倒水"类贪心**：写作规范要求"若属该类问题须证明 Huffman/单调性贪心最优"。本题**不属于**该类：没有"按权重合并两堆"或"在容器间倒水"的结构；高度的单调性只用于给出拓扑序（引理 6），给不出决策规则。因此这里既不需要、也不可能给出 Huffman 式贪心证明；上面两组反例正是"任何局部最优方向规则都失效"的证据，正确做法是把方向选择留在 DP 里（引理 5）。

**那么需要的结构强度是什么？** 引理 6 说明状态数是 $2n$（每个平台两个端点代价），转移是 $O(1)$，唯一开销是"找 $j^\ast$"。暴力找法是 $O(n)$ 扫描 → 总 $O(n^2)=10^{10}$，必然 TLE。把"找 $j^\ast$"降到 $O(\log n)$ 就得到 $O(n\log n)\approx 1.7\times 10^6$，这是本题的自然下界（要读入并排序 $n$ 个平台，$\Omega(n\log n)$ 本身不可避免）。

### 2.5 归约到更简单的问题：给 $x$ 轴"染色"

**先把问题重述成一个纯粹的数据结构题。**
把平台按高度**递增**排序，依次处理。处理到平台 $i$ 时，所有比 $i$ 矮的平台都已经"画"到一条 $x$ 轴上：平台 $j$ 把它的开线段 $(l_j,r_j)$ 覆盖的竖线染成颜色 $j$；因为后来者更高，**后染的颜色覆盖先染的颜色**。

**引理 7（染色正确性）**
按高度递增依次用"$j$ 把 $(l_j,r_j)$ 内的所有下落线染成 $j$"的方式更新后，处理平台 $i$ 之前查询任一竖线 $c$，返回的颜色 $j$ 恰是 $A(c,ht_i)$ 中最高者；若返回"无色"则 $A(c,ht_i)=\varnothing$。

**证明（双向夹逼）**
- 记"已插入"的平台集合为 $P_i=\{j:\;$在排序序列里排在当前对象之前$\}$。对真实平台 $i$，因所有 $ht$ 互不相同，恰好 $P_i=\{j:ht_j<ht_i\}$；对虚平台 $n$，$P_n=\{j:ht_j<y_0\}\cup\{j:ht_j=y_0\}$（同高真实平台排在前面，见 §2.7）。下面的论证只用"插入次序 = 高度次序"这一性质，两种情况同式。
- ($j\in A$ 且最高) 若返回 $j\ne$ 空，说明 $j$ 曾在某个时刻把 $c$ 染成自己，即 $l_j<c<r_j$；又 $j$ 已插入，故 $ht_j\le ht_i$（等号只在虚平台同高时出现，即 §2.7 的读法 I），于是 $j\in A(c,ht_i)$。设 $k\in A(c,ht_i)$ 是其中最高者，需证 $j=k$。$k$ 也在 $P_i$ 中并已插入，且 $l_k<c<r_k$，所以 $k$ 也染过 $c$。在 $j,k$ 两者对 $c$ 的最后一次染色中，谁更晚？因为"后染覆盖先染"，返回者 $j$ 的对 $c$ 的最后一次染色不早于 $k$ 的，故 $ht_j\ge ht_k$（插入次序即高度次序）。而 $k$ 是 $A(c,ht_i)$ 中最高者且 $j\in A(c,ht_i)$，得 $ht_j\le ht_k$。两式合并 $ht_j=ht_k$。而虚平台从不被染色（它的开线段为空），所以 $j,k$ 都是真实平台；真实平台的 $ht$ 互不相同，故 $j=k$。
- ($A=\varnothing$) 若返回空，说明没有任何已插入平台把 $c$ 染过色，即不存在 $j\in P_i$ 满足 $l_j<c<r_j$，也就是 $A(c,ht_i)=\varnothing$。反过来若 $A(c,ht_i)\ne\varnothing$，其中最高的平台一定染过 $c$，由上一段 $j$ 必存在。$\blacksquare$

于是查询接口只剩两个原语：**区间赋值**（插入平台 $i$：把 $(l_i,r_i)$ 染成 $i$）与**单点查询**（求 $j^\ast$：查 $c=l_i$ / $c=r_i$），每次 $O(\log n)$。两种实现都行：
- **线段树 + 懒标记赋值**（本文采用）：最坏情况 $O(n\log n)$，共 $3n+3$ 次原语调用。
- **ODT / 珂朵莉树（颜色段均摊）**：`map<左端点,颜色>` + split + `erase(it++)`；题面标签给的正是这条路，但其均摊分析依赖赋值序列，本题没有保证，故不采用。

**引理 8（离散化不改变答案）**
取 $S$（引理 1 的坐标集合）排序去重后得到 $X_0<X_1<\dots<X_{m-1}$。只在 $S$ 上做查询、并且把平台 $i$ 的染色范围取为 $\{p: l_i<X_p<r_i\}$，则引理 7 的结论在每一个 $c\in S$ 上都成立。

**证明**：染色集合的改动只会影响 $c\notin S$ 的颜色，而引理 1 保证任何一次下落的 $x$ 都在 $S$ 中，从不查询 $c\notin S$。对 $c\in S$：平台 $j$ 把 $c$ 染色 $\iff l_j<c<r_j$，与"实数轴版"的染色条件完全一致（都是严格包含）；"后染覆盖先染"的次序也不受影响。故两个模型在 $S$ 上的返回值逐点相同。$\blacksquare$

**严格包含的边界处理**（这是最细的坑）：在有序数组 $X$ 上
$$\text{left}=\texttt{upper\_bound}(X,l_i)\quad(\text{第一个}>l_i),\qquad \text{right}=\texttt{lower\_bound}(X,r_i)\quad(\text{第一个}\ge r_i),$$
染色区间取半开 $[\text{left},\text{right})$，正好是 $\{p:l_i<X_p<r_i\}$。
- 用 `upper_bound` 而不是 `lower_bound` 是因为 $X_p=l_i$ 这个点**不该**被 $i$ 染色（$i$ 的左端点不是 $i$ 的一部分）；
- 用 `lower_bound(r_i)` 做右边界（半开）同理排除了 $X_p=r_i$；
- 题面保证 $i\ne j\Rightarrow l_i\ne r_j$，而 $l_i=l_j$、$r_i=r_j$ 仍可能出现，上面的严格处理对这两种重合同样正确：共享左端点 $l$ 的两个平台都不覆盖 $x=l$，球从 $x=l$ 处下落会穿过它们继续往下。

**起点怎么办：加一个"虚平台"**
把起点 $(x_0,y_0)$ 看成一个高度为 $y_0$、开线段为 $(x_0,x_0)=\varnothing$ 的**零长度平台**（编号 $n$）。
- 它的左右端点都是 $x_0$，所以 $L_n=R_n=\text{Fall}(x_0,y_0)$，正好就是答案；
- 它的开线段为空，故**永远不会**接到任何东西（染色区间为空，见上面 `upper_bound/lower_bound` 的推导：$\text{left}>\text{right}$ 时跳过），不会污染其它查询。
这样"起点"与"平台端点"共用同一段转移代码，不需要单独分支。

### 2.6 溢出与哨兵防护

1. **中间量必须 64 位**：单段滚动可达 $10^9$，路径长度可达 $n$ 段，DP 值上界约 $2\times10^5\times10^9=2\times10^{14}$，远超 `int`；虽然题目保证答案 $\le10^9$，但**不可行分支的伪值**和**非最优分支**都可能很大，必须用 `i64`。
2. **inf 的选取**：取 $inf=2^{60}\approx1.15\times10^{18}$。要求 (a) 严格大于任何有限可行代价（$\le 2\times10^{14}$）；(b) 累加 $n$ 次仍不溢出（每次加 $\le 3\times10^9$，$10^5$ 次共 $\le 3\times10^{14}$，$2^{60}+3\times10^{14}<9.2\times10^{18}$ ✓）。若用题解常见的 `1145141919810`（$\approx1.1\times10^{12}$）作 inf，则它比某些**真实可行**代价（最大 $\sim2\times10^{14}$）还小，`min` 会把"不可行"当成"很便宜"选中 —— 虽然此题答案保证 $\le10^9$ 使得最终输出侥幸不受影响，但推理链不干净，故不用。
3. **全局数组默认是 0，不是 $-\infty/+inf$**：`tag[]` 的 0 恰好被用作"此处还没有平台"的合法哨兵，因此平台编号必须**整体 +1** 存储（`id+1`），取回时 $-1$（`ask` 里 `return tag[i]-1;`）。写成 `tag[i]=id` 会让 0 号平台被当成"无平台"，直接错。
4. `X[]`、`ht/lf/rt` 也一律用 `i64`：坐标本身 $\le10^9$ 存 `int` 够用，但 $x_p-l_j+L_j$ 这类混合式里 $L_j$ 是 `i64`，坐标用 `int` 会依赖隐式提升，`upper_bound` 的类型也要额外写模板参数；统一 `i64` 最省事。
5. 递归深度：线段树 $O(\log m)\approx 18$，安全；`ask` 里带 `push` 会修改树，但只是把整段赋值下推，不改变任何点的语义。
6. **`let` 的空区间要跳过**：`a<b` 才调用 `let`。虚平台 $l=r=x_0$ 时 `upper_bound(x0) > lower_bound(x0)`，自动跳过 —— 这正是"零长度开线段谁也接不住"的实现。
7. **`push` 不能把 0 当"清空"下发**：`tag[i]==0` 的含义是"本节点没有整段赋值记录"，此时必须让子节点保留各自的历史；若写成无条件 `tag[ls]=tag[rs]=tag[i]`，会把已经染好的矮平台整片擦成"无色"，答案会莫名变小。这是与"赋值 + 清空"型懒标记最大的区别。

### 2.7 题面没说清的一个退化情形：起点恰好与某平台同高

若存在平台 $k$ 使 $ht_k=y_0$ 且 $l_k<x_0<r_k$，球初始就"贴在"平台 $k$ 上。题面只说"落到某个平台上后可选择左右滚"，没规定 $y=ht_k$ 时算不算"落到"。两种读法：

- **读法 I（下落距离 $0$ 也算落到）**：球立刻获得在 $k$ 上滚动的权利，代价 $\text{On}(k,x_0)$。
- **读法 II（必须真下落，即要求 $ht_k<y_0$）**：球穿过 $k$ 继续下落到更矮的平台或地面。

两种读法互不支配：读法 I 多了一个"能滚"的自由度，但读法 II 保住 $x_0$ 这条竖线直落到底。本文实现**读法 I** —— 排序时把虚平台排在同高度的真实平台**之后**（比较器 `return a<b;`，$n$ 是最大编号），于是 $k$ 已插入、能在 $x_0$ 处接住球，且 $ht_n-ht_k=0\le lim$ 通过检验。理由是它更符合"平台是实体、球是质点、$y$ 坐标相等即接触"的几何直觉。
**本地题面无样例，无法与官方答案对标**，所以这条读法差异无法验证；若要切换成读法 II，只把同高时的比较器改成 `return a>b;` 即可（其余代码不变）。真实数据里 $y_0$ 等于某平台高度的概率极低，一般不影响判题结果。

## 3. 模式总结（Pattern Summary）

按真实思考顺序，一条一个技巧（重复用到的技巧拆成多条）：

- explore property — 先把"落/滚"翻译成坐标：下落只发生在 $\{x_0\}\cup\{l_i,r_i\}$ 这些竖直线上，接住者是**严格包含**该线的**最高**平台（引理 1、2）。
- explore property（约束侧）— 碎就是碎，**不可跳过**第一遮挡平台：把"可行边"限定为"距离 $\le lim$ 的第一格"（引理 3）。
- easier version — 先用 $n\le 500$ 的 $\text{Fall}/\text{On}$ 双函数暴力写出转移，确认它按高度严格下降、有 base。
- reduce to graph — 认出 $\text{Fall}\to\text{On}\to\text{Fall}$ 是**按高度分层的 DAG**，最短路 = 拓扑序 DP，不需要 Dijkstra（尽管标签写了最短路）。
- state compression（去落点）— 证明 $f[i]$ 单独不够（引理 4 的反例），再把 $\text{On}(i,x)$ 拆成 $\min(x-l_i+L_i,\;r_i-x+R_i)$：落点信息以线性项形式保留，常数只有 $L_i,R_i$ 两个（引理 5，双向夹逼）。
- topological order — 转移只指向更矮的平台，所以"高度递增"就是现成的拓扑序（引理 6）。
- greedy dissection — 用两组具体小数据打掉"近端贪心"与"第一步代价最小贪心"，确认本题无贪心替换性质；同时说明它**不是**加权合并/倒水型问题，不存在 Huffman 式可证贪心。
- classic structure（区间赋值 + 单点查询）— 遮挡关系等价于"按高度递增给 $x$ 轴染色，后染覆盖先染"，用线段树懒标记（或 ODT）把 $O(n)$ 扫描降到 $O(\log n)$（引理 7）。
- discretization — 查询点集合有限（引理 1），故只保留这些点；开线段的严格包含靠 `upper_bound / lower_bound` 取半开区间实现（引理 8）。
- sentinel trick — 全局 `tag[]` 默认 0 当"无平台"，平台编号整体 $+1$ 存；`push` 只在 `tag!=0` 时下发，不能把 0 当清空。
- uniform trick（虚平台）— 起点写成"高度 $y_0$、开线段为空"的零长度平台，让答案与端点走同一段转移代码，省掉特判。
- overflow guard — $inf=2^{60}$：既要大于一切有限代价（$\le 2\times10^{14}$），又要能累加 $n$ 次不溢出。

## 4. 真实解法

### 4.1 符号表

| 记号 / 变量 | 含义 | 初始化 / 备注 |
|---|---|---|
| $lim$ | 题面的最大下落高度 $h$（**每**一段） | 读入；代码里叫 `lim` 以免与平台高度 $ht$ 混名 |
| $ht_i,l_i,r_i$ / `ht[],lf[],rt[]` | 第 $i$ 个平台的高度与左右端点 | $i\in[0,n-1]$ 读入；$i=n$ 是虚平台 |
| 虚平台 $n$ | 起点：$ht_n=y_0,\;l_n=r_n=x_0$ | 开线段 $(x_0,x_0)=\varnothing$，谁也接不住 |
| $A(c,Y)$ | $\{j:l_j<c<r_j,\;ht_j<Y\}$ | 只在证明里出现，代码不显式构造 |
| $j^\ast$ | $A(c,Y)$ 中最高者 | 线段树单点查询的结果 `j`；$-1\equiv A=\varnothing$ |
| $L_i,R_i$ / `L[],R[]` | **从 $i$ 的左/右端点离开后**到落地的最短时间，即 $\text{Fall}(l_i,ht_i)$、$\text{Fall}(r_i,ht_i)$ | 全局数组默认 0，但**处理顺序保证使用前必已赋值**（引理 6） |
| $\text{On}(i,x)$ | 已落在 $i$ 上横坐标 $x$ 处到落地的最短时间 | 不占存储，用 $(\ast)$ 现算 |
| $S,X,m$ / `X[],cntM` | 所有端点与 $x_0$ 排序去重后的坐标数组，$m=$ `cntM` $\le 2n+1$ | 下标 0-based，`X[]` 存 `i64` |
| `ord[]` | 按 $(ht,\text{同高次序})$ 递增的平台编号 | `iota` 后 `sort` |
| `tag[]` | 线段树区间赋值标记：**存 $i+1$**，0 表示"此段尚无平台" | 全局 0 初始化即为"无平台"，无需 `fill` |
| `let / ask` | 区间赋值 / 单点查询，半开区间 `[l,r)`，根下标 0，叶子判据 `r-l==1` | `ask` 返回编号或 $-1$ |
| $inf$ | 不可行标记 | $2^{60}$ |

**答案**：$\min(L_n,R_n)$（虚平台左右端点同为 $x_0$，二者其实相等）。

### 4.2 步骤

1. **读入 + 建离散化数组**：读 $n,lim$、$x_0,y_0$、$n$ 个平台；把每个 $l_i,r_i$ 与 $x_0$ 塞进 `X[]`。
2. **追加虚平台**：$ht_n=y_0,\;l_n=r_n=x_0$，并把 $x_0$ 计入 `X[]`；`sort` + `unique` 得 `cntM` 个坐标。
3. **定拓扑序**：`ord` 按 `ht` 递增排序；同高时真实平台在前、虚平台在后（编号最大），实现 §2.7 的读法 I。这一步保证：轮到某对象时，树里恰好是"当前高度以下（含同高真实平台）"的全部平台。
4. **按 `ord` 依次处理每个平台 $i$**：
   1. **先查后染**（顺序不能反，否则会被自己染色干扰）。
   2. 对 $s=0$（左端点）与 $s=1$（右端点）：令 $x_p$ 为该端点横坐标，`p = lower_bound(X,x_p)`，`j = ask(0,0,cntM,p)`。
      - `j == -1`：$res=(ht_i\le lim)?\,ht_i:inf$（直接落地）。
      - $ht_i-ht_j>lim$：$res=inf$（引理 3，碎，不可跳过）。
      - 否则：$res=(ht_i-ht_j)+\min(x_p-l_j+L_j,\;r_j-x_p+R_j)$（引理 2 + 引理 5）。
      存入 `L[i]` / `R[i]`。
   3. **染色**：`a = upper_bound(X,lf[i])`，`b = lower_bound(X,rt[i])`；若 `a<b` 则 `let(0,0,cntM,a,b,i+1)`（引理 7、8；虚平台此处自动为空）。
5. **输出** `min(L[n],R[n])`。

### 4.3 复杂度

- 排序 $O(n\log n)$；`X` 去重 $O(n\log n)$。
- 每个平台 2 次 `ask` + 1 次 `let` + 常数次 `lower/upper_bound`，均 $O(\log n)$ → 共 $O(n\log n)$，$n=10^5$ 时约 $2\times10^5\times 17\approx 3.4\times10^6$ 次基本操作（外加线段树递归常数），完全够。
- 空间：`tag[mxn*8]`（$1.6\times10^6$ 个 `int` ≈ 6.4 MB）+ `X/ht/lf/rt/L/R` ≈ $10^7$ 字节，$O(n)$。
- 递归深度 $O(\log m)$，无栈溢出风险。

枚举：从 $(5,12)$ 只能被 $ht=9$ 的 A 接住（$12-9=3$）。左滚 $4$ 到 $x=1$：下方无平台 → 落 $9$ → $3+4+9=16$；右滚 $15$ 到 $x=20$ → $3+15+9=27$。B 在 A 之下且完全被 A 遮住，$x=1,20$ 都不在 B 内，永远用不上。最优 **16**。
DP：$X=\{1,3,5,7,20\}$。① B($ht4$)：两端 `ask` 皆 $-1$ → $L_1=R_1=4$；染 $(3,7)$ 内 $\{5\}$ → `tag[2]=2`。② A($ht9$)：`ask(0)=-1`→$L_0=9$；`ask(4)=-1`→$R_0=9$；染 $(1,20)$ 内 $\{3,5,7\}$ → `tag[1..3]=1`（覆盖掉 B 在 idx2 的颜色 ✓）。③ 虚($12$)：`ask(2)=0`（读到 A，说明覆盖生效），$12-9=3$ → $\min(5\text{-}1\text{+}9,\;20\text{-}5\text{+}9)=13$ → $3+13=16$ ✓

**用例 4：打掉"滚到近端"的贪心（近端必碎）**
```
2 10
12 20
15 10 30
9 25 40
```
枚举：落 $20-15=5$ 到 A 的 $x=12$。左端 $x=10$ 距离仅 $2$，但下方无平台 → 要落 $15>lim=10$，**碎**，不可跳过（引理 3）。右端 $x=30$ 距离 $18$，落 $6$ 到 B$=(9,25,40)$，在 B 的 $x=30$：向左 $5\to25$ 落 $9$ = $14$、向右 $10\to40$ 落 $9$ = $19$ → 取 $14$。右支 $18+6+14=38$，总 $5+38=\mathbf{43}$。
DP：$X=\{10,12,25,30,40\}$（0..4）。① B：两端 `ask=-1` → $L_1=R_1=9$（$9\le10$）；染 $(25,40)$ → idx3 ← 2。② A：`ask(0)=-1` 且 $15>10$ → $L_0=inf$；`ask(3)=B`，$15-9=6\le10$ → $6+\min(5\text{+}9,\;10\text{+}9)=20=R_0$；染 $(10,30)$ → idx1,2 ← 1。③ 虚($20$)：`ask(1)=A`，$20-15=5$ → $\min(12\text{-}10\text{+}inf,\;30\text{-}12\text{+}20)=\min(inf,38)=38$ → $5+38=43$ ✓（$inf$ 参与 $\min$ 时不溢出、也不被误选）

**用例 5：起点下方根本没有平台（空染色区间 + base 分支）**
```
1 10
5 8
7 20 30
```
枚举：$x_0=5$ 不在 $(20,30)$ 内，球直接落地，$8\le lim$ → **8**。
DP：$X=\{5,20,30\}$。① 平台 0($ht7$)：$L_0=R_0=7$；染 $(20,30)$：`upper_bound(20)=idx2(30)`，`lower_bound(30)=idx2` → $a=b=2$，`a<b` 不成立 ⇒ **跳过染色**（引理 8 的正确行为：没有任何下落线穿过它）。② 虚($8$)：`ask(0)`（$x_0=5$，idx0）$=-1$ → $8\le10$ → $L_1=8$ ✓

**边界检查清单（手算确认）**
- **开线段 vs 闭线段**（题面保证 $l_i\ne r_j(i\ne j)$，所以唯一可能的重合是 $l_i=l_j$ / $r_i=r_j$，必须严格排除）。手算数据：$lim=6$，起点 $(20,15)$，$i=(10,10,30)$、$j=(5,10,25)$（与 $i$ 共享左端点 $10$）、$k=(4,28,50)$。
  - 正确（严格包含）：球落 $15-10=5$ 到 $i$ 的 $x=20$。左端 $x=10$：$j$ 的开线段 $(10,25)$ **不含** $10$，$k$ 也不含 ⇒ 下方无平台 ⇒ 要落 $10>lim$ ⇒ $L_i=inf$。右端 $x=30$：$k$ 含 $30$ ⇒ 落 $6\le lim$ 到 $k$，$L_k=R_k=4$ ⇒ $\text{On}_k(30)=\min(2+4,20+4)=6$ ⇒ $R_i=6+6=12$。$\text{On}_i(20)=\min(10+inf,\;10+12)=22$，答案 $5+22=\mathbf{27}$。
  - 错按闭区间：$j$ 会在 $x=10$ 处"接住"球 ⇒ $L_i=(10-5)+\min(0+5,\dots)=10$ ⇒ $\text{On}_i(20)=\min(10+10,22)=20$ ⇒ 输出 $25$，**偏小**且这条路物理上会碎球。
  - 用例 3 里 $x=30$ 查得 B 而不是 A（$30$ 是 A 的右端点），也是同一条严格性在起作用。
- **不可跳过第一遮挡平台**：用例 4 左端 $x=10$ 下方无平台，$ht_A=15>lim=10$。正确行为是 $L_A=inf$；若忘记引理 3（不做 $>lim$ 判定，把碎球当成还能继续落地），左支会被误认为合法解 $2+15=17$，总 $5+17=22$，比真值 $43$ 小一大截 —— 这正是"答案偏小的 WA"。反过来把"$x$ 下方任选一个能接住的平台"写进代码也一样错（本数据 $x=10$ 下方本来就没平台，两种错误表现相同）。
- **`inf` 参与运算**：用例 4 的 $12-10+inf$ 与 $38$ 取 $\min$ 得 $38$，说明 $inf$ 既不会被误选也不会溢出（$2^{60}+10^9\ll 9.2\times10^{18}$）。

## 5. 示例代码

C++17，遵循个人风格规范（`bits/stdc++.h`、`using i64=long long;`、全局静态数组、`constexpr` 尺寸、Tab 缩进、运算符两侧无空格、`'\n'`、`cin.tie/cout.tie/ios::sync_with_stdio` 固定顺序）。线段树按惯用的 `sth` 风格写成全局函数（`let`/`ask`/`push`），半开区间 `[l,r)`、根下标 0、叶子判据 `r-l==1`。

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{200005};          // n<=1e5，虚点占第 n 个；+5 松弛
constexpr i64 inf{1ll<<60};         // 必须远大于任何有限代价(<=1e14)，且能累加 n 次不溢出

int n,cntM;                         // cntM：离散化后横坐标个数
i64 lim;                            // 单次下落最大高度 h
i64 ht[mxn],lf[mxn],rt[mxn];        // 平台高度/左右端点；第 n 个是"起点虚平台"
i64 X[mxn*3];                       // 所有端点 + x0
int ord[mxn];                       // 按高度递增的平台编号
int tag[mxn*8];                     // 线段树区间赋值：值=编号+1，0 表示"此处无平台"
i64 L[mxn],R[mxn];                  // 从左/右端点离开该平台后到地面的最短时间

int ls(int i){return i*2+1;}
int rs(int i){return i*2+2;}

void push(int i)
{
	if(tag[i])
	{
		tag[ls(i)]=tag[rs(i)]=tag[i];
		tag[i]=0;
	}
}
//[l,r)，把 [ql,qr) 染成 v
void let(int i,int l,int r,int ql,int qr,int v)
{
	if(qr<=l||r<=ql)
		return;
	if(ql<=l&&r<=qr)
	{
		tag[i]=v;
		return;
	}
	push(i);
	int mid=(l+r)>>1;
	let(ls(i),l,mid,ql,qr,v);
	let(rs(i),mid,r,ql,qr,v);
}
//单点查询：坐标下标 x 处当前接住它的平台编号，-1 表示没有
int ask(int i,int l,int r,int x)
{
	if(r-l==1)
		return tag[i]-1;
	push(i);
	int mid=(l+r)>>1;
	if(x<mid)
		return ask(ls(i),l,mid,x);
	return ask(rs(i),mid,r,x);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>lim;
	i64 x0,y0;
	cin>>x0>>y0;
	for(int i=0;i<n;++i)
	{
		cin>>ht[i]>>lf[i]>>rt[i];
		X[cntM++]=lf[i];
		X[cntM++]=rt[i];
	}
	ht[n]=y0,lf[n]=rt[n]=x0;         // 虚平台：长度为 0 的开线段，谁也接不住
	X[cntM++]=x0;
	sort(X,X+cntM);
	cntM=unique(X,X+cntM)-X;
	iota(ord,ord+n+1,0);
	sort(ord,ord+n+1,[](int a,int b){
		if(ht[a]!=ht[b])
			return ht[a]<ht[b];
		return a<b;                   // 同高时虚平台(id=n)排最后，让它能被同高真实平台接住
	});
	for(int k=0;k<=n;++k)
	{
		int id=ord[k];
		for(int s=0;s<2;++s)          // s=0 从左端点离开，s=1 从右端点离开
		{
			i64 xp=s?rt[id]:lf[id];
			int p=lower_bound(X,X+cntM,xp)-X;
			int j=ask(0,0,cntM,p);
			i64 res;
			if(j==-1)                 // 正下方无平台 ⇒ 直接落地
				res=(ht[id]<=lim)?ht[id]:inf;
			else if(ht[id]-ht[j]>lim) // 第一段就摔碎，且不能跳过 j
				res=inf;
			else
				res=ht[id]-ht[j]+min(xp-lf[j]+L[j],rt[j]-xp+R[j]);
			if(s)
				R[id]=res;
			else
				L[id]=res;
		}
		//把 (lf[id],rt[id]) 内的下落线染成 id，遮住更矮的平台
		int a=upper_bound(X,X+cntM,lf[id])-X;
		int b=lower_bound(X,X+cntM,rt[id])-X;
		if(a<b)
			let(0,0,cntM,a,b,id+1);
	}
	cout<<min(L[n],R[n])<<'\n';
	return 0;
}
```
