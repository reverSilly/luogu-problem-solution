# P1435 [IOI 2000] 回文字串

> 标签：动态规划 DP / 区间 DP · 难度：普及/提高-

## 1. 重新读题

- 给定字符串 $s$，长度 $l$（$0<l\le 1000$），**只能插入**字符（不能删除、不能修改、不能重排），求把 $s$ 变成回文串的**最少插入数**。区分大小写。
- 题面给的例子：`Ab3bd` 插 $2$ 个字符可成 `dAb3bAd` 或 `Adb3bdA`，插少于 $2$ 个不行。

**条件 / 目标 / 范围**

| 项目 | 内容 |
|---|---|
| 输入 | 一行一个字符串，无空格（故 `cin>>s` 足够） |
| 操作 | 仅"在任意位置插入任意字符"，原字符的**相对顺序不可改变** |
| 目标 | 结果串是回文：$\forall i,\ P[i]=P[N+1-i]$，$N$ 为结果串长度 |
| 优化量 | 插入的字符个数 $k=N-l$ 最小 |
| 范围 | $0<l\le 1000$，无子任务分档 |

范围 $l\le 1000$ 是重要信号：$O(l^2)$（$10^6$）刚好，$O(l^3)$（$10^9$）必然超时，$O(2^l)$ 更不必谈。所以最终算法必须"每个子问题 $O(1)$ 转移、子问题数 $O(l^2)$"，这正是区间 DP 的形状。

- 核心归约（本节只给结论：下界在 §2.1 引理 2，上界在 §2.2 引理 4，合并成定理）：
$$\text{答案}=l-\operatorname{LPS}(s)$$
  其中 $\operatorname{LPS}(s)$ 是 $s$ 的**最长回文子序列**长度。
- 等价说法：最少插入数 = 最少删除数（删掉不属于回文子序列的那些字符）= $l-\operatorname{LCS}(s,\operatorname{rev}(s))$（引理 9）。
- 陷阱与边界：
  - "**子序列**"不是"子串"：原有字符的相对顺序必须保持，但配对的两个字符**不必相邻**。`Ab3bd` 的最优解靠的是位置 $2$ 与位置 $4$ 的两个 `b` 配对（中间隔着 `3`），而不是任何相邻子串。
  - 插入的字符可以是**任意**字符，不要求在原串出现过；因此插入数只受"原字符能否两两嵌套配对"限制，不受字符集限制。
  - **区分大小写**：`A` 与 `a` 是不同的字符，`Ab3bd` 中的 `b3b` 能用，但 `A` 只能与另一个 `A` 配。
  - $l=1$ 时答案为 $0$；已经是回文（如 `aba`、`aaaa`）时答案为 $0$；$l=2$ 且两字符不等时答案为 $1$（如 `ab`→`aba`）。
  - 极端最坏答案：串中所有字符两两互不相同时，$\operatorname{LPS}=1$，答案 $=l-1=999$，不会超过 $l-1$。
  - 本地题面**没有**独立的样例输入/输出块（只有正文里的 `Ab3bd` 说明），因此**无法与官方答案对标**，只能用题面内嵌例子 + 自造小数据手算验证。

## 2. 思维链（Chain-of-thought）

> 路线：插入的**结构**是什么（§2.1，得下界）→ 换成删除这个简易版并回填增量（§2.2，得上界与核心归约）→ 贪心能做到哪一步、哪一步崩（§2.3）→ 崩掉的那一步变成区间 DP（§2.4）→ 再归约成 LCS 换取第二套实现（§2.5）→ 数值/内存/初值安全检查（§2.6）。

### 2.1 探索特殊机制 —— "插入"到底在结构上做了什么

先不想算法，先把"插入 $k$ 个字符得到回文"这件事翻译成 combinatorics。

设原串 $s$ 长 $n$（本节起统一用 $n$ 表示题面的 $l$），插入 $k$ 个字符后得到回文 $P$，$|P|=N=n+k$。给 $P$ 的每个位置打标记：**M**（这个字符来自原串，保持原有先后次序）或 **U**（这是插进去的字符）。则 $|\text{M}|=n,\ |\text{U}|=k$，并且**M 位置上的字符按从左到右读出来正好就是 $s$**（这是"只插入"的唯一约束）。

记镜像映射 $\rho(i)=N+1-i$，回文条件即 $\forall i,\ P[i]=P[\rho(i)]$。

**引理 1（原字符的配对是嵌套不交叉的）**
令 $G=\{i\in \text{M}: \rho(i)\in \text{M}\}$，即"与另一个**原**字符互为镜像"的那些原字符。把 $G$ 中位置按从小到大排成 $g_1<g_2<\cdots<g_m$，则 $m$ 为奇数时中间那个是自身镜像，且对每个 $j$ 有 $g_j+g_{m+1-j}=N+1$，从而
$$s[g_j\text{ 在原串中对应的那个字符}]=s[g_{m+1-j}\text{ 对应的字符}].$$
也就是说，$G$ 里的原字符在 $s$ 中构成一个**回文子序列**，长度 $m$。

**证明**：
- 先证 $G$ 对 $\rho$ 封闭：取 $i\in G$，由定义 $\rho(i)\in\text{M}$；再对 $\rho(i)$ 用一次 $\rho$ 得 $\rho(\rho(i))=i\in\text{M}$，故 $\rho(i)\in G$。✓
- 再证 $\rho$ 在 $G$ 上就是"倒序"：$i<j\Rightarrow \rho(i)>\rho(j)$（$\rho$ 严格递减）。所以 $G$ 排序后 $\rho(g_1)>\rho(g_2)>\cdots>\rho(g_m)$，即 $\{\rho(g_j)\}$ 逆序排列；而 $\rho$ 是 $G$ 上的双射（封闭 + 对合），故 $\rho(g_j)=g_{m+1-j}$。特别地 $g_j=g_{m+1-j}$ 只可能发生在唯一的中间元素上（此时 $2g_j=N+1$，即 $g_j$ 是正中央位置）。
- 字符相等：M 位置上的字符按位置序就是 $s$ 的字符序，所以"$g_j$ 位置的字符"= "$s$ 中第 $j'$ 个字符"（$j'$ 是 $g_j$ 在 M 中的名次）。由回文性 $P[g_j]=P[\rho(g_j)]=P[g_{m+1-j}]$，故 $s$ 中对应位置（名次 $j'_1<j'_2<\cdots<j'_m$，因为 $g$ 递增且 M 名次与位置同序）满足 $s[j'_t]=s[j'_{m+1-t}]$，且 $j'_1<j'_2<\cdots<j'_m$。这正是"回文子序列"的定义。$\blacksquare$

> 直觉图：把 $P$ 写出来，用线连每个 $i\in G$ 到 $\rho(i)$。这些线都在 $P$ 的"中轴"上镜像对称，两条线不可能交叉（交叉就破坏 $\rho$ 递减性），所以是**一整套括号嵌套**；被这些括号罩住的原字符读出来必然是回文。

**引理 2（下界：任何方案都要 $k\ge n-\operatorname{LPS}(s)$）**

**证明**：考察"落单"的原字符 $B=\text{M}\setminus G=\{i\in\text{M}:\rho(i)\in\text{U}\}$，即它的镜像位置上是插入的字符。
- $\rho$ 限制在 $B$ 上 injective（$\rho$ 本身是对合故单射）且 $\rho(B)\subseteq\text{U}$，所以 $|B|\le|\text{U}|=k$。
- 于是引理 1 中的 $m=|G|=n-|B|\ge n-k$，即存在长度 $\ge n-k$ 的回文子序列：$\operatorname{LPS}(s)\ge m\ge n-k$。
- 移项：$k\ge n-\operatorname{LPS}(s)$。$\blacksquare$

这一步不需要任何 DP，纯计数：**"插入的字符只能救场，不能成双"** —— 每个插入字符至多帮一个原字符"配对到镜像"，所以插 $k$ 个最多让 $k$ 个原字符落单，剩下的 $n-k$ 个原字符必须自己组回文。

### 2.2 简化版 —— 先把"插入"换成"删除"，再补回增量

下界 $k\ge n-\operatorname{LPS}(s)$ 已经到手，但它可能只是"看起来很漂亮"：也许实际需要的插入比这个数多。为了判断，先解一个更容易的问题：**只许删除**，把 $s$ 删成回文，最少删几个？

删除版本几乎是白送的：留下的字符自动是一个回文子序列，所以"删 $d$ 个"等价于"存在长度 $n-d$ 的回文子序列"，最优删除数 $=n-\operatorname{LPS}(s)$，与下界的表达式**一模一样**。这不是巧合，它提示：

> 猜想：$\text{最少插入数}=n-\operatorname{LPS}(s)$，即插入和删除在"回文化"这件事上花费相同。

要证它，只需证上界 $k\le n-\operatorname{LPS}(s)$（构造出恰好插这么多的方案）。而构造要用 $\operatorname{LPS}$ 的一条递推性质，先把它证清楚。

**引理 3（$\operatorname{LPS}$ 的"两端"递推）** 记 $t=t[1..m]$，约定 $\operatorname{LPS}(\varnothing)=0$。
- (a) 若 $m\ge2$ 且 $t[1]=t[m]$，则 $\operatorname{LPS}(t)=\operatorname{LPS}(t[2..m-1])+2$；
- (b) 若 $m\ge2$ 且 $t[1]\ne t[m]$，则 $\operatorname{LPS}(t)=\max\big(\operatorname{LPS}(t[1..m-1]),\ \operatorname{LPS}(t[2..m])\big)$。

**证明 (a)**：
- "$\ge$"：取 $t[2..m-1]$ 的一个最长回文子序列 $Q$（长度 $\operatorname{LPS}(t[2..m-1])$），把位置 $1$ 和位置 $m$ 的字符（同为 $t[1]$）分别贴在 $Q$ 的首尾，仍是回文子序列（$1$ 小于 $Q$ 的所有位置，$m$ 大于所有位置），故 $\operatorname{LPS}(t)\ge\operatorname{LPS}(t[2..m-1])+2$。
- "$\le$"：设 $Q$ 是 $t$ 的任一最长回文子序列，长度 $L$。$Q$ 用到的位置集合记 $T$。分三种情况：
  1. $1,m\in T$：那么去掉这两个位置后剩下的仍是 $t[2..m-1]$ 中的回文子序列，长度 $L-2$，故 $L-2\le\operatorname{LPS}(t[2..m-1])$。
  2. 恰有一个属于 $T$，不妨 $1\in T,\ m\notin T$（另一种对称）。此时 $Q$ 的最后一个字符与第一个字符相等，都等于 $t[1]$；设 $Q$ 的最后一个字符所在位置为 $p$，则 $p\le m-1$。把 $Q$ 的最后一个字符改放到位置 $m$：因为 $t[m]=t[1]=t[p]$，字符不变；因为 $m>p\ge$（$Q$ 中间所有位置），位置仍严格递增；得到的 $Q'$ 是合法回文子序列，长度仍 $L$，且 $1,m\in T'$。于是归约到情况 1：$L\le\operatorname{LPS}(t[2..m-1])+2$。
     （$L=1$ 时 $Q$ 只有位置 $1$：此时 $1\le 2\le\operatorname{LPS}(t[2..m-1])+2$，因为任何串的 $\operatorname{LPS}\ge0$，不等式直接成立，无需上述搬移。）
  3. $1,m\notin T$：$Q$ 完全落在 $t[2..m-1]$ 中，$L\le\operatorname{LPS}(t[2..m-1])\le\operatorname{LPS}(t[2..m-1])+2$。
  三种情况都给出 $L\le\operatorname{LPS}(t[2..m-1])+2$，取 $Q$ 最优即得 "$\le$"。$\blacksquare$
- 顺带得到 $m=1$ 时 $\operatorname{LPS}=1$（单字符本身就是回文）。

**证明 (b)**：
- "$\ge$"：$t[1..m-1]$ 与 $t[2..m]$ 都是 $t$ 的子串，它们的回文子序列当然也是 $t$ 的回文子序列（位置集合不变，仍递增），故 $\operatorname{LPS}(t)$ 不小于两者之一，即不小于最大值。
- "$\le$"：设 $Q$ 是 $t$ 的最长回文子序列，用到位置集合 $T$。**断言 $1$ 与 $m$ 至多属于其一**：若 $1,m\in T$，由于 $1$ 是最小位置、$m$ 是最大位置，它们在 $Q$ 中分别扮演首字符和尾字符，而回文首尾必须相等，即要求 $t[1]=t[m]$，与条件矛盾。故 $Q$ 要么不用位置 $1$（则 $Q$ 完整地是 $t[2..m]$ 的回文子序列，$|Q|\le\operatorname{LPS}(t[2..m])$），要么不用位置 $m$（则 $|Q|\le\operatorname{LPS}(t[1..m-1])$）。总之 $L\le\max(\cdot,\cdot)$。$\blacksquare$

**引理 4（上界：$k\le n-\operatorname{LPS}(s)$）** 对 $n$ 做强归纳。

**证明**：
- 基：$n\le1$ 时 $s$ 本身是回文，插入 $0=n-\operatorname{LPS}(s)$ 个即可（$n=1$ 时 $\operatorname{LPS}=1$；$n=0$ 时 $\operatorname{LPS}=0$，题面 $n>0$ 用不到后者）。
- 归纳，$n\ge2$，$s[1]=s[n]$：由归纳假设，$s[2..n-1]$ 可用 $k'\le(n-2)-\operatorname{LPS}(s[2..n-1])$ 次插入变成回文 $P'$。现在把 $s[1]$（已是最左）与 $s[n]$（已是最右）当作最外层括号保留，只在 $P'$ 内部做那些插入，得到 $s[1]\,P'\,s[n]$。它是回文（首尾同字符，中间是回文），且包含 $s$ 为子序列，插入数 $=k'\le(n-2)-\operatorname{LPS}(s[2..n-1])$。由引理 3(a)，$\operatorname{LPS}(s[2..n-1])=\operatorname{LPS}(s)-2$，代入得 $k'\le n-\operatorname{LPS}(s)$。✓
- 归纳，$n\ge2$，$s[1]\ne s[n]$：先说一个操作事实——**永远可以花 $1$ 次插入"消耗掉"某一个端点**：想在最右边插入一个 $s[1]$ 的复制，则最左字符 $s[1]$ 与这个新复制配成一对，中间剩下的正好是 $s[2..n]$；于是
$$k\le 1+\min\big(k(s[2..n]),\ k(s[1..n-1])\big)$$
 （右边两项分别对应"补左端字符到最右"与"补右端字符到最左"）。由归纳假设 $k(s[2..n])\le(n-1)-\operatorname{LPS}(s[2..n])$ 等，代入：
$$k\le n-\max\big(\operatorname{LPS}(s[2..n]),\operatorname{LPS}(s[1..n-1])\big)=n-\operatorname{LPS}(s)$$
 最后一步用了引理 3(b)。✓
- 归纳完成。$\blacksquare$

**定理（核心归约）** 最少插入数 $=n-\operatorname{LPS}(s)$。
**证明**：引理 2 给下界，引理 4 给上界，两向夹逼。$\blacksquare$

**推论** 最少插入数 $=$ 最少删除数。二者都等于 $n-\operatorname{LPS}(s)$。（注意这只是"数量相等"，不是说两个操作互相等价。）

### 2.3 剖析贪心的失败 —— 从"数频率"到"双指针"

**第一个（错误）直觉：字符频率**。做回文排列（"可以把字符串重排成回文吗"那类题）的经验是"最多一个字符出现奇数次"。于是猜想"插入数 $=\max(0,\text{奇数频率字符数}-1)$"。
反例：`aac`。频率 `a:2, c:1`，奇数频率字符只有 `c` 一个，公式给出 $\max(0,1-1)=0$，即"不用插就已经回文"。但 $0$ 次插入意味着 `aac` 自己是回文，而 $P[1]=\texttt{a}\ne\texttt{c}=P[3]$，矛盾。真值是 $1$：在最前面插入一个 `c` 得 `caac`，`caac` 反转仍是 `caac`，是回文；用归约核对 $\operatorname{LPS}(\texttt{aac})=2$（子序列 `aa`），$3-2=1$ ✓。
**失败原因**：频率法只回答"能否**重排**成回文"，本题**禁止重排**，顺序才是难点。这也再次印证归约：决定答案的是"最长的**保序**回文子序列"，而不是计数。

**第二个直觉：双指针贪心**。$l\leftarrow1,\ r\leftarrow n$，每次看 $s[l],s[r]$：
- 若相等就同时收缩（当作配好的一对）；
- 若不等就"补一边"，$l\mathrel{+}=1$ 或 $r\mathrel{-}=1$。

**引理 5（"相等就配对"这一步是安全的）** 当 $s[l]=s[r]$ 时，存在最优解让 $l,r$ 互为镜像。
**证明**：由定理，最优值只由 $\operatorname{LPS}$ 决定。引理 3(a) 说 $\operatorname{LPS}(s[l..r])=\operatorname{LPS}(s[l+1..r-1])+2$，且其证明中"情况 2 的搬移"保证了**存在**一个最长回文子序列同时使用 $l$ 和 $r$。于是 $f[l][r]=(r-l+1)-\operatorname{LPS}(s[l..r])=(r-l+1)-2-\operatorname{LPS}(s[l+1..r-1])=f[l+1][r-1]$：两端字符不花插入，直接配对。$\blacksquare$

**引理 6（"不等时随便挑一边"是不安全的）** 反例：`abac`（$n=4$）。
- 若贪心"总是补左端字符到最右、然后丢掉 $l$"（即收缩 $l\mathrel{+}=1$）：$l=1,r=4$，`a`≠`c` → 花费 $1$，进入 `bac`；`b`≠`c` → 花费 $1$，进入 `ac`；`a`≠`c` → 花费 $1$，进入 `c`（长度 1）停。总计 $3$。
- 最优：只在最左边插入一个 `c`，得 `cabac`，回文，花费 $1$。
- 用归约核对：$\operatorname{LPS}(\texttt{abac})=3$（子序列 `aba`，位置 $1,2,3$），$4-3=1$ ✓；而贪心的 $3$ 意味着只有 $4-3=1$ 个原字符能互相配对，其余 $3$ 个各需要一个插入字符来顶替自己的镜像位，比留下长度 $3$ 的回文子序列整整差 $2$ 次插入。
**失败模式**：$s[l]$ 与 $s[r]$ 不等时，两边"谁更值得保留"取决于**内部**还能配出多少，这是一个全局信息，局部无法判断。本例中左端 `a` 在内部有搭档（位置 3），右端 `c` 没有搭档，所以该牺牲的是 `c` 而不是 `a`；贪心看不见这一点。$\blacksquare$

**出路**：不等的情况把两种选择都算出来取小 —— 局部决策一旦需要"都试"，就是 DP 的信号。

### 2.4 经典解法 —— 区间 DP

定理已经把问题变成"求 $\operatorname{LPS}$"。$\operatorname{LPS}$ 的递推（引理 3）是按"两端"展开的，天然对应**区间 DP**：子问题 = 一段连续子串，转移只看更短的区间。

直接把 $f[l][r]=(r-l+1)-\operatorname{LPS}(s[l..r])$ 代入引理 3，得到本解法的递推。

**引理 7（$f$ 的递推）** 对 $0$-based 的 $s$，$0\le l\le r<n$：
$$f[l][r]=\begin{cases}0,&l\ge r\\[2pt] f[l+1][r-1],&s[l]=s[r]\\[2pt] 1+\min\big(f[l+1][r],\ f[l][r-1]\big),&s[l]\ne s[r]\end{cases}$$

**证明**：
- $l=r$：单字符已回文，$f[l][l]=1-1=0$。
- $s[l]=s[r]$（$l<r$）：由引理 3(a)，$\operatorname{LPS}(s[l..r])=\operatorname{LPS}(s[l+1..r-1])+2$，故
$$f[l][r]=(r-l+1)-\big(\operatorname{LPS}(s[l+1..r-1])+2\big)=(r-l-1)-\operatorname{LPS}(s[l+1..r-1])=f[l+1][r-1].$$
 （$r=l+1$ 时右边是 $f[l+1][l]$，即"空区间"，定义为 $0$；两字符相同直接成对，确实插 $0$ 个。✓）
- $s[l]\ne s[r]$：由引理 3(b)，$\operatorname{LPS}(s[l..r])=\max(\operatorname{LPS}(s[l+1..r]),\operatorname{LPS}(s[l..r-1]))$。于是
$$f[l][r]=(r-l+1)-\max(\cdots)=1+\min\big((r-l)-\operatorname{LPS}(s[l+1..r]),\ (r-l)-\operatorname{LPS}(s[l..r-1])\big)=1+\min(f[l+1][r],f[l][r-1]).$$
 （$\max(a,b)=-\min(-a,-b)$ 那一步：$(r-l+1)-\max(A,B)=\min((r-l+1)-A,(r-l+1)-B)$。）$\blacksquare$

**可操作解读**（帮助记忆，不是新证明）：$s[l]\ne s[r]$ 时，要么在最右端补一个 $s[l]$ 的复制（于是 $l$ 有了搭档，剩下要处理 $s[l+1..r]$），要么在最左端补一个 $s[r]$ 的复制（剩下 $s[l..r-1]$），各花 $1$；$s[l]=s[r]$ 时它俩互为搭档、$0$ 花费，中间自理。这与引理 4 归纳证明里用的操作完全一致。

**递推顺序**：$f[l][r]$ 依赖 $f[l+1][r-1]$（长度 $-2$）、$f[l+1][r]$ 与 $f[l][r-1]$（长度 $-1$），全部是**更短**的区间。因此按区间长度 `len` 从小到大枚举即可；同一 `len` 内 `l` 的顺序无所谓，因为同长度的区间互不依赖。

**为什么不用把 $f[l+1][r-1]$ 也塞进 $\min$**：有些写法会写 $f[l][r]=\min\big(f[l+1][r-1],\ 1+\min(f[l+1][r],f[l][r-1])\big)$。当 $s[l]=s[r]$ 时引理 3(a) 已经证明 $f[l+1][r-1]$ 就是最优值，多加一项不会变坏，但也毫无用处。

**引理 8（多写的 $\min$ 分支不会更小，因而两种写法同解）** 若 $s[l]=s[r]$（$l<r$），则
$$1+\min\big(f[l+1][r],\ f[l][r-1]\big)\ \ge\ f[l+1][r-1].$$

**证明**：先用一条独立事实：**给一个串末尾添一个字符，$\operatorname{LPS}$ 至多增加 $2$**。
设 $u$ 长 $m$，$Q$ 是 $u\cdot c$ 的最长回文子序列，用位置 $q_1<\cdots<q_L$。若 $q_L\ne m+1$（没用上新字符），则 $L\le\operatorname{LPS}(u)$。若 $q_L=m+1$：因 $m+1$ 是最大位置，它在 $Q$ 中充当最后一个字符；回文首尾相等，故 $Q$ 的第一个字符（位置 $q_1$）的字符也等于 $c$，且 $q_1\le m$；当 $L=1$ 时 $1\le\operatorname{LPS}(u)+2$ 成立（$\operatorname{LPS}(u)\ge0$）；当 $L\ge2$ 时把 $Q$ 的首尾两个字符同时去掉，得到长度 $L-2$ 的回文，其位置全部 $\le m$（因为 $q_2<\cdots<q_{L-1}<q_L=m+1$），故 $L-2\le\operatorname{LPS}(u)$，即 $L\le\operatorname{LPS}(u)+2$。该界是紧的：$u=\texttt{ab}$ 时 $\operatorname{LPS}=1$，$u\cdot\texttt{a}=\texttt{aba}$ 时 $\operatorname{LPS}=3$，正好差 $2$。✓

现在回到 $s[l]=s[r]$。由上面这条事实（分别把 $s[r]$、$s[l]$ 看作"新加的那个字符"）：
$$\operatorname{LPS}(s[l+1..r])\le\operatorname{LPS}(s[l+1..r-1])+2,\qquad \operatorname{LPS}(s[l..r-1])\le\operatorname{LPS}(s[l+1..r-1])+2.$$
代入 $f=\text{长度}-\operatorname{LPS}$，记 $A=\operatorname{LPS}(s[l+1..r-1])$，区间 $[l+1,r]$ 与 $[l,r-1]$ 长度都是 $r-l$：
$$f[l+1][r]=(r-l)-\operatorname{LPS}(s[l+1..r])\ge(r-l)-(A+2)=\big((r-l-1)-A\big)-1=f[l+1][r-1]-1,$$
同理 $f[l][r-1]\ge f[l+1][r-1]-1$。两式取 $\min$ 再 $+1$ 即得 $1+\min(f[l+1][r],f[l][r-1])\ge f[l+1][r-1]$。$\blacksquare$

### 2.5 归约到更简单的问题 —— $\operatorname{LPS}(s)=\operatorname{LCS}(s,\operatorname{rev}(s))$

$\operatorname{LPS}$ 会让人自然联想到一个更经典的题目：**最长公共子序列** LCS。把 $s$ 反转成 $r=\operatorname{rev}(s)$，则"$s$ 里的一段回文"看起来就是"$s$ 与 $r$ 的公共子序列"。

**引理 9** 对任意串 $s$（长 $n$），$\operatorname{LPS}(s)=\operatorname{LCS}(s,\operatorname{rev}(s))$。

**证明**：记 $L=\operatorname{LCS}(s,r)$。
- "$L\ge\operatorname{LPS}(s)$"：回文子序列 $Q$ 作为 $s$ 的子序列，把它的字符序列反转还是 $Q$ 自身（回文），而 $Q$ 反转后正是 $r$ 的一个子序列（子序列反转 = 在反转串中按对应位置取）。所以 $Q$ 同时是 $s$ 与 $r$ 的公共子序列，$L\ge|Q|$，取 $Q$ 最优即得。✓
- "$L\le\operatorname{LPS}(s)$"：这是唯一要小心的一步，因为**任意一个 LCS 未必是回文**（见下面的坑），所以不能"取一个 LCS 说它是回文"。正确做法：从 LCS 的**匹配位置对**里造出一个（可能不同的）回文子序列，长度不少于 $L$。
  设 LCS 的 $L$ 个匹配为 $s[i_k]=r[j_k]$，其中 $i_1<\cdots<i_L$，$j_1<\cdots<j_L$。令 $p_k=n+1-j_k$（把 $r$ 中的位置翻译回 $s$ 中的镜像位置），则 $s[p_k]=r[j_k]=s[i_k]$，且 $p_1>p_2>\cdots>p_L$（$j$ 递增 ⟹ $p$ 递减）。
  考察差 $i_k-p_k=i_k+j_k-(n+1)$：$i_k$ 与 $j_k$ 都随 $k$ 严格递增，所以 $i_k-p_k$ 随 $k$ **严格递增**。于是下标集合被切成三段（可能有空段）：
  $$\text{左段 }\{k:i_k<p_k\},\quad\text{中心 }\{k:i_k=p_k\},\quad\text{右段 }\{k:i_k>p_k\}.$$
  因为 $i_k-p_k$ 严格递增，这三个集合恰好是下标 $1..L$ 的一个前缀、至多一个点、一个后缀。记 $\kappa=|\text{左段}|$，$c\in\{0,1\}=|\text{中心}|$，$\mu=|\text{右段}|$，则 $\kappa+c+\mu=L$。
  - **左段造回文**：把左段写成 $k=1,\dots,\kappa$（它是前缀）。位置序列
    $$i_1<i_2<\cdots<i_\kappa<p_\kappa<p_{\kappa-1}<\cdots<p_1$$
    严格递增（$i$ 递增；$i_\kappa<p_\kappa$；$p$ 递减）。若还有中心（$c=1$，其位置 $i_{\kappa+1}=p_{\kappa+1}$）则插在正中。字符上第 $t$ 位与第 $2\kappa+1-t$ 位分别取自 $i_t$ 与 $p_t$，而 $s[i_t]=s[p_t]$，故读出的字符串是 $a_1a_2\cdots a_\kappa\,a_\kappa\cdots a_2 a_1$（中心情形中间多一个字符）—— 回文，长度 $2\kappa+c$。
    （还要说明 $i$ 与 $p$ 两组位置互不重合：对 $k\le\kappa$ 有 $p_k\ge p_\kappa>i_\kappa\ge i_k$，故所有 $p$ 都严格大于所有 $i$。✓）
  - **右段造回文**：对称地，右段是 $k=\kappa+c+1,\dots,L$，每个都满足 $p_k<i_k$。用位置序列
    $$p_{L}<p_{L-1}<\cdots<p_{\kappa+c+1}<i_{\kappa+c+1}<\cdots<i_{L}$$
    （$p$ 递减 ⟹ 倒着排才递增；$i$ 递增；衔接处由 $p_{\kappa+c+1}<i_{\kappa+c+1}$ 保证）同样得到一个回文子序列，长度 $2\mu+c$。
    （两组不重合：对右段任意 $k,k'$ 有 $p_k\le p_{\kappa+c+1}<i_{\kappa+c+1}\le i_{k'}$。）
  - 两段长度取大者：若 $2\kappa+c<L=\kappa+c+\mu$，则 $\kappa<\mu$，从而 $2\mu+c>\kappa+\mu+c=L$。总之
    $$\max(2\kappa+c,\ 2\mu+c)\ \ge\ L,$$
    所以 $\operatorname{LPS}(s)\ge L$。✓
  两个方向合起来即 $\operatorname{LPS}(s)=L$。$\blacksquare$

**坑（必须知道）**：引理 9 只说**长度**相等，**不**说"任取一个 LCS 就是回文"。反例：$s=\texttt{abcab}$，$\operatorname{rev}(s)=\texttt{bacba}$。`bca` 是两者的公共子序列（在 `abcab` 中取位置 $2,3,4$；在 `bacba` 中取位置 $1,3,5$），长度 $3=\operatorname{LCS}$，但 `bca` 不是回文。若用"取 LCS 字符串再当答案"的错误思路，就会得到无意义结果；只有把 LCS 当作**计数工具**（求长度）才是合法的。

**由 LCS 得到的第二套实现**：$\operatorname{LCS}$ 是教科书递推 $c[i][j]=[s_i=t_j]\cdot(c[i-1][j-1]+1)+(1-[s_i=t_j])\cdot\max(c[i-1][j],c[i][j-1])$，$O(n^2)$ 时间和空间，答案仍是 $n-c[n][n]$。它的价值：（1）与本解法的区间 DP **互为验证**（两套独立递推给同一个数）；（2）数据范围若给到 $n\le 5000$ 而内存吃紧，LCS 只需一行滚动数组（$O(n)$ 空间），而区间 DP 的 $f$ 表本质需要 $O(n^2)$（对角线滚动也可以，见 §2.6）。

### 2.6 溢出、内存与实现防护

逐项检查"$O(n^2)$ 到底有多大"：

| 项目 | 上界估算 | 结论 |
|---|---|---|
| $f$ 的值 | $f[l][r]\le(r-l)\le n-1\le 999$（每个字符最多被"牺牲"一次；由定理 $f=len-\operatorname{LPS}\le len-1$） | $\texttt{int}$ 绰绰有余，不需要 `long long`，也没有任何加法会溢出（单次转移只 $+1$） |
| DP 表 | $1005\times1005\times4\,\text{B}\approx4.04\,\text{MB}$ | 全局静态数组放 BSS 段，通常内存限制 $\ge128\,\text{MB}$，安全 |
| 时间 | $\sum_{len=2}^{n}(n-len+1)=\frac{(n-1)n}{2}\approx5\times10^5$ 次转移 | 远小于 $10^8$，$O(n^2)$ 直接过 |
| 若 $n$ 到 $10^4$ | 表 $10^8$ 个 $\texttt{int}=400\,\text{MB}$ | 会 MLE；此时应改用滚动数组或 LCS 一行滚动（见下） |

三个实现陷阱：

1. **全局数组的 0 初值恰好是我们想要的**。本题"未定义/不可达"的状态就是空区间 $l>r$，其值应为 $0$，而全局 `int f[mxn][mxn]` 天生全 $0$，所以**不需要** `fill`。反过来说，如果把 $f$ 改成 `vector` 或写成"求最长"型 DP，$0$ 就会被误当作合法答案 —— 迁移代码时必须重新检查每个哨兵。（这里唯一要留意的是 `len==2` 且 `s[l]==s[r]` 时会读 `f[l+1][l]`，即"跨界的空区间"，靠 $0$ 初值给出正确答案 $0$，逻辑上等价于"两字符相同无需插入"。）✓
2. **递推顺序**：`len` 必须从小到大；若误用 `for(int l=0;l<n;++l) for(int r=l;r<n;++r)`（按行枚举），`f[l+1][r-1]` 与 `f[l+1][r]` 还没算出来（$l+1$ 那一行在后面），会读到 $0$ 而给出错误的小答案。用"按长度枚举"最不容易错。
3. **读入**：题面保证输入是一个不含空格的串且 $n>0$，`cin>>s` 正确；若担心平台存在空行，`while(cin>>s)` 只处理第一个 token 也可，但本题不需要 `getline`。$n=0$ 的输入不会出现，但代码里 `n?f[0][n-1]:0` 给了兜底，避免 `f[0][-1]` 这种越界读。

**空间优化版（可选）**：$f[l][r]$ 只依赖长度 $len-1$ 与 $len-2$ 的对角线，因此可用两条一维数组 `g0[]`（长度 $len-1$ 的对角线：`g0[l]=f[l][l+len-2]`）和 `g1[]`（$len-2$）滚动，$O(n)$ 空间：
$$f[l][r]=\begin{cases}\mathit{prevPrev}[l+1] & s[l]=s[r]\\ 1+\min(\mathit{prev}[l+1],\ \mathit{prev}[l]) & \text{否则}\end{cases}$$
其中 `prev[l]=f[l][r-1]`、`prev[l+1]=f[l+1][r]`、`prevPrev[l+1]=f[l+1][r-1]`。本题 $n\le1000$ 用不到，保留二维最清楚、最不容易写错；主解法给二维版。

## 3. 模式总结（Pattern Summary）

按真实思考顺序，一条一个技巧；同一类技巧用到两次就拆成两条。

- **给操作打标记，翻译成结构** — 把结果串字符标成 M（原串）/U（插入），"只插入"就等价于"M 按位置序读出恰好是 $s$"；一切后续推理都从这个标记开始。
- **数镜像的落单者** — 每个插入字符至多替一个原字符"顶掉镜像位"，于是 $\ge n-k$ 个原字符必须自成回文 ⟹ 下界 $k\ge n-\operatorname{LPS}$。
- **先解更简单的孪生问题** — 把"插入"换成"删除"，删除版一眼是 $n-\operatorname{LPS}$；两版数值相同这一现象直接给出猜想。
- **强归纳构造上界** — 想证"插 $n-\operatorname{LPS}$ 个就够"，不要给闭式方案，而是对长度归纳：等端套壳 / 不等端花 $1$ 次牺牲一个端点。
- **分类讨论（第一次）：按两端字符是否相等** — 用它把 $\operatorname{LPS}$ 拆成 $+2$（等端）与 $\max$（不等端）两种递推，这是全题的枢纽引理。
- **反例定位贪心的失效边界** — 频率法被 `aac` 击穿（顺序被忽略），"不等端任选一边"被 `abac` 击穿（$3$ vs $1$）；由此确认"哪一步可以贪、哪一步必须 DP"。
- **分类讨论（第二次）：按 DP 转移的分支** — 同一刀切法直接变成代码里的 `if(s[l]==s[r]) … else …`，即"证明的分支 = 程序的分支"。
- **经典解法：区间 DP，按区间长度枚举** — 子问题 = 连续子串，转移只依赖更短区间，$O(n^2)$；长度枚举天然保证拓扑序，无需记忆化。
- **归约到更经典的问题（LCS）** — $\operatorname{LPS}(s)=\operatorname{LCS}(s,\operatorname{rev}(s))$，用"匹配对按 $i_k-p_k$ 符号切三段"证明；顺便得到第二套独立实现。
- **警惕"长度相等 $\ne$ 对象相等"** — LCS 与 LPS 只是长度相等，LCS 串本身可以不回文（`abcab` 的 LCS `bca`），归约只能拿来算数，不能拿来构造。
- **数值/内存/初值三查** — 值域 $\le n-1$（不用 `long long`）、表 $4\,\text{MB}$（全局数组放 BSS）、$0$ 初值恰好承担"空区间"定义（不需 `fill`，但换写法就必须重查哨兵）。
- **对拍意识（此处只能手算）** — 两套独立递推（区间 DP 与 LCS）互为交叉验证；本环境禁编译，故退化为手算表格核对。

## 4. 真实解法

**符号表**

| 符号 | 含义 | 初始化 / 约定 |
|---|---|---|
| $s,\ n$ | 输入串与其长度（代码用 `n` 表示题面的 $l$），**0-based** | $1\le n\le1000$；`cin>>s` 后 `n=(int)s.size()` |
| $f[l][r]$ | 把闭区间子串 $s[l..r]$ 变成回文所需的**最少插入数** | 全局数组默认全 $0$；$l\ge r$（单字符或空区间）定义为 $0$ |
| `len` | 枚举区间长度 $=r-l+1$，从 $2$ 到 $n$ | 保证拓扑序：所有转移都指向更小的 `len` |
| $\operatorname{LPS}(t)$ | 串 $t$ 的最长回文子序列长度 | 只出现在证明里，代码不计算它 |
| $\rho(i)$ | 结果回文 $P$ 中位置 $i$ 的镜像 $N+1-i$ | 只在 §2.1 的 M/U 标记论证中使用 |
| $i_k,j_k,p_k$ | §2.5 中 LCS 的第 $k$ 对匹配位置，$p_k=n+1-j_k$ | 只在引理 9 证明中使用 |

一句话记忆：**两端相同就"白赚"（外层括号成对，问题缩进内部），两端不同就花 $1$ 牺牲一个端点，牺牲哪一端交给 $\min$。**

**编号步骤**

1. 读入 $s$，$n\leftarrow|s|$。
2. 全局 `int f[mxn][mxn]` 自动清零；这一步同时建立两个基例：$f[i][i]=0$，以及"空区间 $f[l+1][l]=0$"。
3. 外层 `for(int len=2;len<=n;++len)`，内层 `for(int l=0;l+len-1<n;++l)`，令 `r=l+len-1`。
4. 转移：`s[l]==s[r]` ⟹ `f[l][r]=f[l+1][r-1]`（引理 7 第二支）；否则 `f[l][r]=min(f[l+1][r],f[l][r-1])+1`（引理 7 第三支）。
5. 输出 `n?f[0][n-1]:0`，其值即 $f[0][n-1]=n-\operatorname{LPS}(s)$（定理）。

**复杂度**：时间 $O(n^2)$，共 $\frac{(n-1)n}{2}\le499500$ 次 $O(1)$ 转移；空间 $O(n^2)$，`mxn{1005}`（$+5$ 松弛约定）对应 $4.04\,\text{MB}$ 静态数组。$f$ 值域 $\le n-1=999$，`int` 不会溢出。

**验证状态**：**仅手算，未编译、未运行、未对拍**（任务硬性禁止）。核对清单：题面内嵌例 `Ab3bd`→$2$ ✓；自造边界 `a`→$0$、`ab`→$1$、`aac`→$1$、`abac`→$1$、`aaaa`→$0$、`abcab`→$2$；其中 `abac`、`abcab`、`Ab3bd` 给出完整 DP 表逐格核算（见 §5 末"手算验证"）。本地题面**没有**独立的样例输入/输出块，因此无法与官方答案对标，只能靠上述手算 + 与 LCS 递推的等价性（引理 9）交叉验证。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,f[mxn][mxn];
string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>s;
	n=(int)s.size();
	// f[l][r]=把 s[l..r] 变成回文的最少插入数；l>=r 视为空区间，值 0（全局初值已给）
	for(int len=2;len<=n;++len)
		for(int l=0;l+len-1<n;++l)
		{
			int r=l+len-1;
			if(s[l]==s[r])
				f[l][r]=f[l+1][r-1];
			else
				f[l][r]=min(f[l+1][r],f[l][r-1])+1;
		}
	cout<<(n?f[0][n-1]:0)<<'\n';
	return 0;
}
```

**手算验证 1 —— 题面内嵌例 `Ab3bd`（$n=5$，0-based：`A b 3 b d`）**

| len | 区间 | 判定 | 计算 | $f$ |
|---|---|---|---|---|
| 1 | 每个单字符 | — | 基例 | $0$ |
| 2 | `[0,1]` `A`≠`b` | else | $\min(f[1][1],f[0][0])+1=\min(0,0)+1$ | $1$ |
| 2 | `[1,2]` `b`≠`3` | else | $\min(0,0)+1$ | $1$ |
| 2 | `[2,3]` `3`≠`b` | else | $\min(0,0)+1$ | $1$ |
| 2 | `[3,4]` `b`≠`d` | else | $\min(0,0)+1$ | $1$ |
| 3 | `[0,2]` `A`≠`3` | else | $\min(f[1][2],f[0][1])+1=\min(1,1)+1$ | $2$ |
| 3 | `[1,3]` `b`=`b` | if | $f[2][2]=0$ | $0$ |
| 3 | `[2,4]` `3`≠`d` | else | $\min(f[3][4],f[2][3])+1=\min(1,1)+1$ | $2$ |
| 4 | `[0,3]` `A`≠`b` | else | $\min(f[1][3],f[0][2])+1=\min(0,2)+1$ | $1$ |
| 4 | `[1,4]` `b`≠`d` | else | $\min(f[2][4],f[1][3])+1=\min(2,0)+1$ | $1$ |
| 5 | `[0,4]` `A`≠`d` | else | $\min(f[1][4],f[0][3])+1=\min(1,1)+1$ | $\mathbf{2}$ |

输出 $2$，与题面"插入 $2$ 个字符可以变成 `dAb3bAd` 或 `Adb3bdA`，插少于 $2$ 个不行"完全一致 ✓。
用归约复核：$\operatorname{LPS}(\texttt{Ab3bd})=3$（子序列 `b3b`，位置 $1,2,3$），$5-3=2$ ✓。

**手算验证 2 —— `abac`（$n=4$：`a b a c`，用于 §2.3 的贪心反例）**

| len | 区间 | 判定 | $f$ |
|---|---|---|---|
| 2 | `[0,1]` `a`≠`b` | else $\min(0,0)+1$ | $1$ |
| 2 | `[1,2]` `b`≠`a` | else | $1$ |
| 2 | `[2,3]` `a`≠`c` | else | $1$ |
| 3 | `[0,2]` `a`=`a` | if $f[1][1]$ | $0$ |
| 3 | `[1,3]` `b`≠`c` | else $\min(f[2][3],f[1][2])+1=\min(1,1)+1$ | $2$ |
| 4 | `[0,3]` `a`≠`c` | else $\min(f[1][3],f[0][2])+1=\min(2,0)+1$ | $\mathbf{1}$ |

对比 §2.3 中"无脑牺牲左端"的贪心结果 $3$：DP 在第 4 行选了 $\min$ 的另一侧（牺牲右端 `c`），得 $1$，对应解 `cabac` ✓。$\operatorname{LPS}=3$（`aba`），$4-3=1$ ✓。

**手算验证 3 —— `abcab`（$n=5$：`a b c a b`，同时也是 §2.5"LCS 串未必回文"的例子）**

| len | 区间 | 判定 | $f$ |
|---|---|---|---|
| 1 | 各单字符 | 基例 | $0$ |
| 2 | `[0,1]`/`[1,2]`/`[2,3]`/`[3,4]` 两端都不等 | else $\min(0,0)+1$ | 全 $1$ |
| 3 | `[0,2]` `a`≠`c` | else $\min(f[1][2],f[0][1])+1=\min(1,1)+1$ | $2$ |
| 3 | `[1,3]` `b`≠`a` | else $\min(1,1)+1$ | $2$ |
| 3 | `[2,4]` `c`≠`b` | else $\min(1,1)+1$ | $2$ |
| 4 | `[0,3]` `a`=`a` | if $f[1][2]$ | $1$ |
| 4 | `[1,4]` `b`=`b` | if $f[2][3]$ | $1$ |
| 5 | `[0,4]` `a`≠`b` | else $\min(f[1][4],f[0][3])+1=\min(1,1)+1$ | $\mathbf{2}$ |

归约复核：$\operatorname{LPS}=3$（`aba` 取位置 $0,1,3$；`aca` 取 $0,2,3$），$5-3=2$ ✓。LCS 复核：$\operatorname{rev}(s)=\texttt{bacba}$，$\operatorname{LCS}=3$（例如 `bca`，不是回文），$5-3=2$ ✓ —— 两套彼此独立的递推给出同一个数，构成人工交叉验证。

**边界用例（逐一手算）**

| 输入 | $n$ | DP 要点 | 输出 | 检验点 |
|---|---|---|---|---|
| `a` | $1$ | `len` 循环 $2..1$ 不执行，直接读 $f[0][0]=0$ | $0$ | 最短合法输入、循环上下界 |
| `ab` | $2$ | $f[0][1]=\min(f[1][1],f[0][0])+1=1$ | $1$ | 最少"必须插"的情形（`aba`） |
| `aa` | $2$ | `a`=`a` ⟹ $f[0][1]=f[1][0]$，即跨界空区间 | $0$ | 全局 $0$ 初值承担空区间定义 |
| `aac` | $3$ | $f[0][1]=0$（`aa`），$f[1][2]=1$，$f[0][2]=\min(1,0)+1$ | $1$ | 频率贪心在此错判 $0$；正解 `caac` |
| `aaaa` | $4$ | 每步都走 if 支，$f[0][3]=f[1][2]=0$ | $0$ | 已回文、if 支链式收缩 |
| `abA` | $3$ | $f[0][1]=1,f[1][2]=1,f[0][2]=\min(1,1)+1$ | $2$ | **区分大小写**：`A` 与 `a` 不可配对 |
| 最长最坏串 | $1000$ | 所有字符两两不等时 $\operatorname{LPS}=1$ | $999$ | 值域上界 $\le n-1$，`int` 足够 |

**备选实现（LCS 版，引理 9 的直接落实，可用来与主解法互验）**

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,c[mxn][mxn];
string s,t;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>s;
	n=(int)s.size();
	t=s;
	reverse(t.begin(),t.end());
	// c[i][j]=s 的前 i 个字符与 t 的前 j 个字符的 LCS 长度；0 初值 = 空前缀，无需 fill
	for(int i=1;i<=n;++i)
		for(int j=1;j<=n;++j)
			c[i][j]=(s[i-1]==t[j-1]?c[i-1][j-1]+1:max(c[i-1][j],c[i][j-1]));
	cout<<n-c[n][n]<<'\n';
	return 0;
}
```

注意：此版本只输出**长度**差，绝不能把求得的某个 LCS 字符串当作答案回文串使用（见 §2.5 的坑）。
