# P1837 [NEERC 2005] 单人纸牌

> 难度：省选/NOI- · 标签：状压 DP、概率 DP

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $9$ 叠牌，每叠 $4$ 张，共 $36$ 张，每叠从堆底到堆顶给出。每次操作：从**两叠不同的牌堆**的顶上各取一张牌，要求这两张牌**牌面（点数）相同**，然后把它们一起拿走。若所有牌都能被拿走则获胜。

George 的策略是：在当前所有合法的取法中**等概率随机**选一种。求最后获胜的概率，精确到小数点后 $6$ 位。

注意「牌面相同」只看点数，不看花色：例如黑桃 K 和红桃 K 可以一起拿走。花色只用于区分牌，不参与判定。

### 1.2 关键约束与规模暗示

- 牌的总数只有 $36$，分成 $9$ 叠、每叠 $4$ 张。每一叠在任何时刻的状态只能是「还剩 $0/1/2/3/4$ 张」。
- 因此整个游戏的局面数是 $5^9=1\,953\,125$，这是一个刚好可以全部存下来的大小（`double` 数组约 $15.6\text{ MB}$）。
- 每次操作恰好拿走两张牌，所以局面一定从「总牌数多」走向「总牌数少」，不存在环——这是能直接 DP 的根本原因。
- 输出要求 $6$ 位小数，`double` 精度足够。

## 2. 思维链（Chain-of-thought）

### 2.1 什么信息决定了未来

先问：给定当前局面，未来还和什么有关？

每一叠牌的顺序是固定的（输入给定），而且我们永远从**顶上**拿牌。所以只要知道第 $i$ 叠「还剩几张」，就能唯一确定它当前的顶牌（就是输入中该叠从底往上数第 $c_i$ 张）。花色不影响任何判定。于是：

**引理 1（局面压缩）**：一个局面可以被向量 $(c_0,c_1,\dots,c_8)$ 完全描述，其中 $c_i\in\{0,1,2,3,4\}$ 是第 $i$ 叠剩余的牌数。两个牌数向量相同的历史，对未来的胜率贡献完全相同。

**证明**：未来的每一步只依赖两件事：哪些叠非空、以及每个非空叠的顶牌点数。顶牌由该叠的固定牌序与剩余张数唯一确定；点数又只取决于输入。因此牌数向量相同的两个局面，可用的操作集合与操作后的牌数向量完全相同。由归纳（对剩余总牌数）可知胜率相同。$\blacksquare$

由此局面总数只有 $5^9$，可以用一个整数编码：把 $c_i$ 看成五进制数第 $i$ 位，

$$
\text{code}=\sum_{i=0}^{8}c_i\cdot 5^{i}.
$$

初始局面是每个 $c_i=4$，编码为 $5^9-1=1\,953\,124$。

### 2.2 一步分析：随机策略下的递推

设 $f(s)$ 为从局面 $s$ 出发最终获胜的概率。若 $s$ 中所有叠都为空，则已经获胜，$f=1$。否则设当前有 $k$ 种合法取法，第 $t$ 种取法之后的局面是 $s_t$。因为 George 等概率选一种，

$$
f(s)=\frac{1}{k}\sum_{t=1}^{k}f(s_t).
$$

若 $k=0$（还有牌但没有任何两叠顶牌相同），则必输，$f(s)=0$。

**引理 2（递推正确）**：上面的 $f$ 满足题意的获胜概率。

**证明**：对剩余总牌数 $T$ 做归纳。$T=0$ 时 $f=1$，正确。设 $T>0$ 时所有更小总牌数的局面 $f$ 都正确，则从 $s$ 出发第一步以 $1/k$ 的概率走到 $s_t$（每种合法取法等概率，正是题设策略），之后继续按同一随机策略进行，胜率为 $f(s_t)$。由全概率公式得 $f(s)=\frac1k\sum f(s_t)$。$k=0$ 时无法行动，必输。$\blacksquare$

### 2.3 无环性：可以按编码递增顺序递推

每次操作把两个不同的 $c_i,c_j$ 各减 $1$，所以新的编码为

$$
\text{code}'=\text{code}-5^{i}-5^{j}<\text{code}.
$$

于是所有转移都指向**更小**的编码。这意味着不必递归记忆化，直接令 `code` 从 $1$ 到 $5^9-1$ 递增，依次计算 `dp[code]` 即可——计算 `dp[code]` 时它依赖的所有 `dp[code']` 都已经算好。

### 2.4 枚举合法取法

对当前局面解码出 $c_0,\dots,c_8$。枚举无序对 $i<j$：

- 若 $c_i=0$ 或 $c_j=0$，这对叠里至少有一叠没有牌，不能取；
- 否则两叠顶牌分别是 `rk[i][c_i-1]` 与 `rk[j][c_j-1]`，只有点数相同才合法。

合法则累加 `dp[code-5^i-5^j]`，并让计数器加一。最后 `dp[code] = cnt ? sum/cnt : 0`。

> **失败尝试的极简反例**：如果错误地按「花色 + 点数」一起比较，那么例子里的 `KS` 与 `KH` 就不能配对，题目给出的 $5$ 种取法会变成 $0$ 种，胜率直接算成 $0$。所以必须只比较点数。

### 2.5 边界与精度

- 初始就没有任何合法取法：`dp[5^9-1]=0`，输出 `0.000000`。
- 概率只会做加法和除以不超过 $\binom92=36$ 的整数，误差在 $10^{-15}$ 量级累积，输出 $6$ 位小数稳妥。
- 使用 `fixed << setprecision(6)`，注意四舍五入由输出格式完成。

### 2.6 复杂度

状态数 $5^9$，每个状态枚举 $\binom92=36$ 对叠，故时间 $O(5^9\cdot36)\approx7\times10^7$ 次基本操作；空间 $O(5^9)$ 个 `double`，约 $15.6\text{ MB}$。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 只有「每叠剩余张数」影响未来，局面压缩成五进制向量（引理 1）。
- **reduce to easier problem** — 把随机过程写成「等概率转移到后继局面」的期望/概率递推（引理 2）。
- **explore its property** — 每次取牌使编码严格减小，所以状态图是 DAG，可按编码递增顺序迭代而非递归。
- **classic problem solution** — 枚举所有无序叠对，检查顶牌点数是否相同，累加后继概率并除以合法取法数。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `rk[i][j]` | `char [9][4]` | 第 $i$ 叠从底往上第 $j$ 张牌的点数（字符串首字符） | 读入 | rank |
| `pw5[k]` | `int [10]` | $5^k$ | `pw5[0]=1` | 五进制位权 |
| `dp[code]` | `double [1953130]` | 局面 `code` 的获胜概率 | `dp[0]=1`，其余待算 | 概率表 |
| `c[i]` | `int [9]` | 当前局面第 $i$ 叠剩余牌数 | 由 `code` 解码 | counts |
| `cnt` | `int` | 当前局面的合法取法数 | $0$ | 分母 |
| `sum` | `double` | 所有后继局面的胜率之和 | $0$ | 分子 |

### 4.2 算法步骤

1. 预处理 `pw5[0..9]`。
2. 读入 $9\times4$ 个字符串，取首字符存入 `rk[i][j]`（$j=0$ 是堆底，$j=3$ 是堆顶）。
3. `dp[0]=1`。
4. 对 `code=1..5^9-1`：
   1. 五进制解码出 `c[0..8]`；
   2. `sum=0, cnt=0`；
   3. 枚举 $0\le i<j<9$，若 `c[i]>0 && c[j]>0 && rk[i][c[i]-1]==rk[j][c[j]-1]`，则 `++cnt`，`sum += dp[code-pw5[i]-pw5[j]]`；
   4. `dp[code] = cnt ? sum/cnt : 0`。
5. 输出 `dp[5^9-1]`，保留 6 位小数。

### 4.3 复杂度

- 时间：$O(5^9\cdot 9^2)$，约 $7\times10^7$ 次操作。
- 空间：$O(5^9)$ 个 `double`，约 $15.6\text{ MB}$。

## 5. 示例代码

```cpp
//
// 题目：P1837 [NEERC 2005] 单人纸牌
// https://www.luogu.com.cn/problem/P1837
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1953130};

char rk[9][4];
int pw5[10];
double dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	pw5[0]=1;
	for(int i=1;i<10;++i)
		pw5[i]=pw5[i-1]*5;
	for(int i=0;i<9;++i)
	{
		for(int j=0;j<4;++j)
		{
			string s;
			cin>>s;
			rk[i][j]=s[0];
		}
	}
	int tot=pw5[9];
	dp[0]=1.0;
	int c[9];
	for(int code=1;code<tot;++code)
	{
		int x=code;
		for(int i=0;i<9;++i)
		{
			c[i]=x%5;
			x/=5;
		}
		double sum{0.0};
		int cnt{0};
		for(int i=0;i<9;++i)
		{
			if(c[i]==0)
				continue;
			for(int j=i+1;j<9;++j)
			{
				if(c[j]==0)
					continue;
				if(rk[i][c[i]-1]!=rk[j][c[j]-1])
					continue;
				++cnt;
				sum+=dp[code-pw5[i]-pw5[j]];
			}
		}
		dp[code]=cnt?sum/cnt:0.0;
	}
	cout<<fixed<<setprecision(6)<<dp[tot-1]<<'\n';
	return 0;
}
```
