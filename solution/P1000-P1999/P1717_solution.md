# P1717 钓鱼

## 1. 重新读题

一条水平路边从左到右排列着 $n$ 个鱼塘（$2 \le n \le 25$），总空余时间为 $H$ 小时（$1 \le H \le 16$）。由于所有钓鱼与赶路的时间单位均为 $5$ 分钟，我们将总时间换算为 $T = 12 H$ 个单位时间片（$12 \le T \le 192$）。

从 $1$ 号湖出发，只能向右走，从第 $i$ 个湖走到第 $i+1$ 个湖需要消耗 $t_i$ 个时间片。在第 $i$ 个湖钓鱼的第 $1$ 个时间片可钓到 $f_i$ 条鱼，此后在该湖每多钓 $1$ 个时间片，单次钓鱼量比上一次减少 $d_i$（若减至 $\le 0$ 则后续收益为 $0$）。求在 $T$ 个时间片内最多能钓到多少条鱼。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：“走在路上”与“停下钓鱼”可以拆开吗？

如果直接在时间轴上做模拟，每到一个湖既可以选择“再钓 $5$ 分钟”，也可以选择“花 $t_i$ 时间片走到下一个湖”，行走决策与钓鱼决策纠缠在一起。

但仔细观察题面规则：
1. **行走方向单调**：只能从左往右走，绝不走回头路；
2. **钓鱼收益与时刻无关**：在第 $i$ 个湖钓 $c_i$ 个时间片，获得的鱼量只取决于 $c_i$（即前 $c_i$ 项等差数列之和），与**什么时候**到达第 $i$ 个湖毫无关系！

**引理 1（固定最远终点后的行走开销定值性）**：设整个行程到达的最靠右的鱼塘编号为 $k \in \{1, 2, \dots, n\}$。则无论中间在各个鱼塘如何分配钓鱼时间，花在走路上的总时间片恒等于
$$W(k) = \sum_{i=1}^{k-1} t_i,$$
且剩余可供在鱼塘 $\{1, 2, \dots, k\}$ 中自由分配的钓鱼总时间片恒为 $R(k) = 12 H - W(k)$。

**证明**：
因为从 $1$ 号湖出发且只能向右走，要访问 $\{1, \dots, k\}$ 中的若干鱼塘并最终停在 $k$ 号湖，路径必须且只需依次经过路段 $1 \to 2, 2 \to 3, \dots, (k-1) \to k$ 各恰好一次，总路程耗时必为 $W(k) = \sum_{i=1}^{k-1} t_i$。反过来，若任意给定各鱼塘的钓鱼次数 $c_1, \dots, c_k \ge 0$ 满足 $\sum_{i=1}^k c_i \le 12 H - W(k)$，只需按顺序在到达第 $i$ 个湖时连续钓 $c_i$ 次再走向 $i+1$，即可在总时间 $12 H$ 内合法实现该方案。$\blacksquare$

### 2.2 固定最远终点 $k$ 后的贪心选择（附完整证明）

由引理 1，只要外层枚举最远到达的鱼塘 $k \in \{1, \dots, n\}$，子问题就完全脱离了“走路”：
> 有 $k$ 个鱼塘，第 $i$ 个鱼塘的第 $j$ 次垂钓（$j \ge 1$）收益为 $v_{i,j} = \max(0,\, f_i - (j-1)d_i)$。从中选出至多 $R(k)$ 次垂钓（每个鱼塘必须从 $j=1$ 开始按顺序选），求最大总收益。

**引理 2（边际收益递减下的全局前 $R$ 大贪心）**：在固定 $k$ 的子问题中，每次从 $\{1, \dots, k\}$ 中挑选当前下一次垂钓收益 $\text{cur}[i]$ 最大的鱼塘（若最大收益 $\le 0$ 则提前停止）钓一次，重复至多 $R(k)$ 次，所得总收益必为全局最优。

**证明**：
因为 $d_i \ge 0$，对每个鱼塘 $i$，其各次垂钓的边际收益序列 $v_{i,1} \ge v_{i,2} \ge v_{i,3} \ge \dots \ge 0$ 单调不增。
因此，“对每个鱼塘 $i$ 必须先选前 $j-1$ 次才能选第 $j$ 次”这一前缀约束，在从所有二元组集合 $\mathcal{U} = \{(i, j) : 1 \le i \le k, 1 \le j \le R(k), v_{i,j} > 0\}$ 中直接挑出权值最大的前 $m = \min(|\mathcal{U}|, R(k))$ 个元素时**自动满足**（若 $(i, j)$ 入选而 $(i, j-1)$ 未入选，因 $v_{i,j-1} \ge v_{i,j}$，用 $(i, j-1)$ 替换 $(i, j)$ 权值和不减）。
由于任意合法方案最多选 $R(k)$ 次且只能选正权项，其总和不可能超过 $\mathcal{U}$ 中前 $m$ 大元素之和；而每次取当前各鱼塘队首最大值的贪心过程恰好依次取出了 $\mathcal{U}$ 中权值最大的前 $m$ 个元素，故贪心解必为最优。$\blacksquare$

---

## 3. 模式总结（Pattern Summary）

- **explore its property** — 识别出单向行走耗时只由最远到达的鱼塘 $k$ 决定，且各鱼塘钓鱼收益与到达时刻无关（引理 1）。
- **enumerate boundary to decouple** — 外层枚举最远到达的鱼塘 $k \in [1, n]$，扣除路程耗时 $W(k)$，把原问题化归为静态多序列选取问题。
- **classic problem solution** — 利用每个鱼塘单次收益随次数单调递减（凹性），每次贪心选取当前剩余收益最大的鱼塘（引理 2）。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n, h` | `int` | 鱼塘数 $n$ 与小时数 $H$ | 标准输入 | 维度 |
| `f[i], d[i]` | `int [mxn]` | 第 $i$ 个湖初始收益与递减量（0-based） | 标准输入 | fish / decrease |
| `t[i]` | `int [mxn]` | 从湖 $i$ 走到 $i+1$ 所需的时间片数 | 标准输入 | travel time |
| `cur[i]` | `int [mxn]` | 枚举终点 $k$ 时，湖 $i$ 当前下一次能钓到的鱼数 | 重置为 `f[i]` | current yield |
| `ans` | `int` | 所有终点 $k$ 下的最大总钓鱼量 | `0` | answer |

### 4.2 算法步骤

1. 读入 $n, H$ 及数组 $f, d, t$，令总时间片 `tot = h * 12`，`walk = 0`，`ans = 0`。
2. 枚举最远到达的鱼塘下标 `k = 0 .. n-1`：
   - 若 `k > 0`，累加路程耗时 `walk += t[k - 1]`；
   - 计算剩余钓鱼时间片 `rem = tot - walk`；若 `rem <= 0` 则后续更远的鱼塘也无法到达，`break`；
   - 将 `cur[0 .. k]` 初始化为 `f[0 .. k]`，`sum = 0`；
   - 循环至多 `rem` 次：在 `0 .. k` 中找出 `cur[best]` 最大的鱼塘 `best`；若 `cur[best] <= 0` 则 `break`；否则令 `sum += cur[best]`，并更新 `cur[best] = max(0, cur[best] - d[best])`；
   - 用 `sum` 更新 `ans = max(ans, sum)`。
3. 输出 `ans`。

### 4.3 复杂度分析

- **时间复杂度**：外层枚举 $n$ 个终点，内层最多执行 $T = 12 H$ 步，每步扫描 $k \le n$ 个鱼塘（由于 $n \le 25$，直接线性扫描比堆操作常数更小），总时间复杂度为 $O(n^2 H) \le 25^2 \times 192 \approx 1.2 \times 10^5$ 次操作，耗时 $< 1\text{ ms}$。
- **空间复杂度**：仅使用长度为 $n$ 的一维数组，空间复杂度为 $O(n)$。

## 5. 示例代码

```cpp
//
// 题目：P1717 钓鱼
// https://www.luogu.com.cn/problem/P1717
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{30};

int n,h;
int f[mxn],d[mxn],t[mxn],cur[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>h;
	for(int i=0;i<n;++i)
		cin>>f[i];
	for(int i=0;i<n;++i)
		cin>>d[i];
	for(int i=0;i<n-1;++i)
		cin>>t[i];

	int tot=h*12,walk=0,ans=0;
	for(int k=0;k<n;++k)
	{
		if(k>0)
			walk+=t[k-1];
		int rem=tot-walk;
		if(rem<=0)
			break;
		for(int i=0;i<=k;++i)
			cur[i]=f[i];
		int sum=0;
		for(int step=0;step<rem;++step)
		{
			int best=0;
			for(int i=1;i<=k;++i)
				if(cur[i]>cur[best])
					best=i;
			if(cur[best]<=0)
				break;
			sum+=cur[best];
			cur[best]=max(0,cur[best]-d[best]);
		}
		ans=max(ans,sum);
	}
	cout<<ans<<'\n';
	return 0;
}
```
