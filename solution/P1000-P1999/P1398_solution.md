# P1398 [NOI2013] 书法家

> 标签：DP / 枚举 / 二维前缀和 · 难度：NOI+

## 1. 重新读题

- 网格 $n$ 行 $m$ 列，格 $(x,y)$（$x$ 列 $1..m$，$y$ 行 $1..n$，左下角 $(1,1)$）带整数幸运值。
- 目标：写 `N`、`O`、`I` 三个字母，使被笔覆盖的格子幸运值之和最大。
- 输入顺序陷阱：第 $i+1$ 行第 $j$ 个数 = 格 $(j,\,n-i+1)$，即**输入首行是网格顶行**，读入需上下翻转。
- `N`：$K\ge3$ 个矩形横向紧挨（$L_i=R_{i-1}+1$），列成"左竖笔 + 下行阶梯 + 右竖笔"。
- `O`：大矩形挖去中心 $1$ 圈边框，$W,H\ge3$，且 $u>R_K+1$（与 N 至少隔 1 空列）。
- `I`：上下两条横杠 + 内部竖笔，$P_1>u+W$（与 O 至少隔 1 空列）。
- 数据范围：$n\le150,\,m\le500$，值域 $[-200,200]$；$n\ge3,m\ge12$。

**把几何约束翻译成"列区间"**

- 每个字母的矩形/横杠边都平行坐标轴，且 `N` 内部矩形满足 $L_i=R_{i-1}+1$，所以 `N` 覆盖的列是一段**连续整数列** $[L_1,R_K]$。
- `O` 是单个大矩形，覆盖列 $[u,\,u+W-1]$。
- `I` 的三条矩形横向都夹在 $[P_1,G_1]$ 内（竖笔 $P_2,G_2$ 严格在内部），故 `I` 覆盖列 $[P_1,G_1]$。

**陷阱与边界**

- 分隔约束：$u>R_K+1\Rightarrow u\ge R_K+2$；$P_1>u+W\Rightarrow P_1\ge (u+W-1)+2$。即相邻两字母之间**至少空 1 列**（不是相邻）。
- 最小宽度：`N` 需 $K\ge3$ 且每矩形宽 $\ge1$ → 至少 3 列；`O` 需 $W\ge3$ → 3 列；`I` 需 $P_1<P_2\le G_2<G_1$ → 至少 3 列。加上两处各 1 空列，最窄合法布局 $=3+1+3+1+3=11\le m$（$m\ge12$ 保证有解空间）。
- 高度：`O` 需 $H\ge3$、`I` 需上/下杠之间留竖笔（$H_3\ge Q_1+2$）；这些在行向枚举时是"带高 $\ge3$"的下界。
- 值域含负数，"覆盖更多格"未必更优——这正是贪心失效之处（见 2.3）。

## 2. 思维链（Chain-of-thought）

### 2.1 结构探索 —— 三字母占据递增且分离的列区间

**引理 1（列区间互不重叠且严格有序）**
设 `N` 覆盖列区间 $[a_L,a_R]=[L_1,R_K]$，`O` 覆盖 $[b_L,b_R]=[u,u+W-1]$，`I` 覆盖 $[c_L,c_R]=[P_1,G_1]$。则
$$a_R+2\le b_L,\qquad b_R+2\le c_L.$$

**证明**：`N` 的矩形满足 $L_i=R_{i-1}+1$，故并集列是连续段 $[L_1,R_K]$，即 $a_R=R_K$。
- 由 `O` 约束 2：$u>R_K+1$，而 $b_L=u$，$a_R=R_K$，故 $b_L>a_R+1$，整数化即 $b_L\ge a_R+2$。
- 由 `I` 约束 2：$P_1>u+W$。`O` 右端 $b_R=u+W-1$，故 $u+W=b_R+1$，于是 $c_L=P_1>b_R+1$，整数化 $c_L\ge b_R+2$。$\blacksquare$

**引理 2（列可加性）**
若某字母覆盖连续列 $[\ell,r]$，其幸运值等于逐列贡献之和：$V=\sum_{x=\ell}^{r} v_x$，其中 $v_x$ 只依赖该字母在第 $x$ 列覆盖了哪些行。

**证明**：网格每格至多被一支笔写一次（三字母列区间由引理 1 两两不交，同一字母内部按列也互不重叠：`N` 的矩形横向紧挨、每列恰属一矩形；`O`/`I` 的列并集亦连续不重）。故被覆盖格集合可唯一按列划分，幸运值即各列被覆盖格之和的累加。$\blacksquare$

> **结构小结**：问题 = 在 $[1,m]$ 中选三段合法列区间并分别填入 `N`/`O`/`I`，段间留 $\ge1$ 空列，最大化三段价值之和。列间不耦合 → 只需分别算"某字母在给定列区间内的最大价值"，再按序合并。

### 2.2 考虑简化版 —— 先把单个字母的列区间价值算出来

记 $NI[\ell][r],\,OV[\ell][r],\,IV[\ell][r]$ 为该字母**恰好覆盖列 $[\ell,r]$** 时的最大价值（不合法记 $-\infty$）。下面 2.4–2.6 分别求三者。

### 2.3 剖析贪心失败 —— 负值下"越大越高越好"不成立

考虑固定宽 3 列、高 4 行的子块，`O` 只能整块取边框。第 2 行中间那个 $+100$ **只有当作上/下横杠行时才计入**（边框不含内部行）。

| 列→<br>行↓ | $c_1$ | $c_2$ | $c_3$ |
|:--:|:--:|:--:|:--:|
| $r_1$ | $0$ | $0$ | $0$ |
| $r_2$ | $-10$ | $+100$ | $-10$ |
| $r_3$ | $0$ | $0$ | $0$ |
| $r_4$ | $0$ | $0$ | $0$ |

`O` 边框值 = 上杠整行 + 下杠整行 + 左/右侧列在中间行的格。逐一带枚举：
- 带 $[1,4]$（贪心"最高"）：上 $0$ + 下 $0$ + 两侧 $r_2,r_3$ 的 $c_1,c_3$ $=(-10-10+0+0)=-20$ → $-20$。
- 带 $[1,3]$：$0+0+(-10-10)=-20$。
- 带 $[2,4]$：上 $r_2=80$ + 下 $r_4=0$ + 两侧 $r_3=0$ → $+80$。

**结论**：最优是"矮带 $[2,4]$"（把带 $+100$ 的行当横杠），贪心取最大高度反而 $-20$。故每个字母必须对**所有合法形状**求最优，不能靠局部扩张；这正是下面 2.4 用 $f(t)+g(b)$ 全枚举的动机。

### 2.4 `O` 的价值 —— 关于上下行分离

固定列区间 $[\ell,r]$（宽 $W=r-\ell+1\ge3$），设大矩形行带为 $[b,t]$（高 $H=t-b+1\ge3$）。边框 = 整块减去内部 $(W-2)\times(H-2)$ 矩形。

记每列竖直前缀 $cs[x][y]=\sum_{k=1}^{y}val(x,k)$。定义该列区间内的两个行函数：
$$A(y)=\sum_{x=\ell}^{r}val(x,y)\quad(\text{第 }y\text{ 行在 }[\ell,r]\text{ 的和})$$
$$P(y)=cs[\ell][y]+cs[r][y]\quad(\text{左右两条侧柱的前缀})$$

**引理 3（O 边框闭式）** 对带 $[b,t]$（$t\ge b+2$），O 的边框价值可分离为"只含 $t$ 的项 + 只含 $b$ 的项"：
$$OV_{\ell,r}(b,t)=\big(A(t)+P(t-1)\big)+\big(A(b)-P(b)\big).$$

**证明**：边框分两部分。
- 上下两横杠：$A(b)+A(t)$。
- 左右侧柱在中间行 $b+1..t-1$：$(cs[\ell][t-1]-cs[\ell][b])+(cs[r][t-1]-cs[r][b])=P(t-1)-P(b)$。
相加：$A(b)+A(t)+P(t-1)-P(b)=(A(t)+P(t-1))+(A(b)-P(b))$。$\blacksquare$

**推论（$O(n)$ 求 $OV[\ell][r]$）**：令 $f(t)=A(t)+P(t-1)$，$g(b)=A(b)-P(b)$，则 $OV[\ell][r]=\max_{t\ge b+2}\big(f(t)+g(b)\big)$。一次从下往上扫描：维护 $\displaystyle gm(t)=\max_{b\le t-2}g(b)$，对 $t=3..n$ 取 $\max(f(t)+gm(t))$，全程 $O(n)$。

**手算校验（用 2.3 的表，$\ell=1,r=3$）**：$A=(0,80,0,0)$；$cs_1=(0,-10,-10,-10)$，$cs_3=(0,-10,-10,-10)$，$P(y)=cs_1[y]+cs_3[y]=(0,-20,-20,-20)$。
- $g(2)=A(2)-P(2)=80-(-20)=100$。$f(4)=A(4)+P(3)=0+(-20)=-20$。$t=4,b=2$：$-20+100=80$ ✓（对应带 $[2,4]$）。
- $f(3)=A(3)+P(2)=0+(-20)=-20$，$b\le1$：$g(1)=A(1)-P(1)=0-0=0$，和 $=-20$ ✓（带 $[1,3]$）。取最大得 $80$，与 2.3 一致。

- `I`、`N` 的类似分解见下两节。

### 2.5 `I` 的价值 —— 两横杠 + 内部最大子段（H 形）

`I` 覆盖列 $[\ell,r]$（宽 $\ge3$）：下杠行 $b$、上杠行 $t$（$t\ge b+2$），两杠都是整段 $[\ell,r]$；竖笔是列子段 $[\ell',r']$（$\ell<\ell'\le r'<r$）在行 $b+1..t-1$ 的实心矩形。

**引理 4（I 的分解）** 记 $A(y)$ 同引理 3（行 $y$ 在 $[\ell,r]$ 的和），对固定带 $[b,t]$ 定义逐列竖笔权重
$$u(x)=cs[x][t-1]-cs[x][b]\quad(x\in[\ell+1,r-1]).$$
则
$$IV_{\ell,r}(b,t)=A(b)+A(t)+\operatorname*{MaxSub}_{[\ell+1,\,r-1]}(u),$$
其中 $\operatorname{MaxSub}$ 为区间 $[\ell+1,r-1]$ 上的**非空**最大子段和。

**证明**：两横杠贡献 $A(b)+A(t)$。竖笔矩形 $[\ell',r']\times[b+1,t-1]$ 的和 $=\sum_{x=\ell'}^{r'}(cs[x][t-1]-cs[x][b])=\sum_{x=\ell'}^{r'}u(x)$；对 $[\ell',r']\subseteq[\ell+1,r-1]$ 取最大即 $u$ 在 $[\ell+1,r-1]$ 上的非空最大子段和（因竖笔至少 1 列且严格内缩）。两部分不重叠（竖笔只在中间行、横杠只在 $b,t$ 行）。$\blacksquare$

**计算**：内缩非空要求 $r-\ell+1\ge3$。对固定带 $[b,t]$，$u(x)$ 已知，$\operatorname{MaxSub}$ 随右端点右移可用 Kadane 前缀递推 $O(1)$ 摊还维护；对每个左端点 $\ell$ 扫一遍 $r$ 即 $O(m)$。所有带、所有 $\ell$ 合计 $O(m^2 n^2)$（详见 4.3 对全 $500$ 数据的优化说明：与合并扫描融合后降为 $O(m n^2)$）。

**边界**：竖笔必须严格内缩（左右各留 $\ge1$ 列给横杠），故 $[\ell+1,r-1]$ 非空 ⟺ 宽 $\ge3$。

### 2.6 `N` 的价值 —— 逐列竖直区间的单调阶梯

由条件 2（$L_i=R_{i-1}+1$），`N` 覆盖连续列 $[\ell,r]$，且每列恰属一个矩形。设矩形 $i$ 的竖直区间为 $[B_i,T_i]$，同矩形内所有列共用它。于是 `N` 等价于把列 $[\ell,r]$ 分成若干**连续段**（每段一个矩形），每段赋一个竖直区间 $[b,t]$，段价值 $=\sum_{x\in\text{段}}(cs[x][t]-cs[x][b-1])$，段与段之间须满足：

- **首段→第二段**（条件 4）：$t_2=t_1$，$b_2>b_1$。
- **中间相邻段**（条件 3，对 $3\le i<K$）：$t_i\le t_{i-1}$，$t_i\ge b_{i-1}-1$，$b_i\le b_{i-1}$。
- **倒数第二段→末段**（条件 4）：$b_{K-1}=b_K$，$t_{K-1}<t_K$。段数 $K\ge3$。

**引理 5（N 的列-DP 与合法阶梯一一对应）**
把 `N` 视作自左向右逐列推进，状态为 $(\text{段阶段},b,t)$，`阶段`$\in\{\text{首段},\text{第二段},\text{中段},\text{末段}\}$。列转移两类：
1. **延长当前段**（下一列并入同一矩形）：$(b,t)$ 不变、阶段不变，累加 $cs[x][t]-cs[x][b-1]$。合法性：同矩形同区间恒满足段内条件。
2. **另起新段**（进入下一矩形）：按阶段用上列的 $(b_{\text{prev}},t_{\text{prev}})$ 与新段 $(b,t)$ 校验对应规则后推进阶段（首段→第二段要求 $t=t_{\text{prev}},b>b_{\text{prev}}$；中段→中段要求 $t\le t_{\text{prev}},t\ge b_{\text{prev}}-1,b\le b_{\text{prev}}$；进入末段要求 $b=b_{\text{prev}},t>t_{\text{prev}}$）。

**证明（双向）**：
- (DP路径 → 合法N)：把每段当作一个矩形，段区间即 $[B_i,T_i]$。转移 1 保证段内矩形自洽；转移 2 的三类校验分别正是条件 4 的 $t_2=t_1,b_2>b_1$、条件 3、条件 4 的 $b_{K-1}=b_K,t_{K-1}<t_K$。列连续覆盖 $[\ell,r]$ ⟹ $L_i=R_{i-1}+1$。故得到合法 `N`。
- (合法N → DP路径)：把给定 $K$ 段配置按列展开即得一条路径：每段内部走转移 1，段边界走转移 2；边界处校验由合法性前提自动成立。$\blacksquare$

**$NI[\ell][r]$** = 上述 DP 从 $\ell$ 到 $r$、且**至少经历 4 个阶段**（首/第二/中/末，允许中段为 0 段但须 $K\ge3$：即"第二段"与"末段"可以是相邻的第 2、3 段）的所有路径的最大累计。$K=3$ 特例即"首段,第二段,末段"，第二段既是 $i=2$ 又是 $K-1$，须同时满足两组规则（校验时合并）。

**复杂度**：状态 $(b,t)$ 共 $O(n^2)$，每列转移 $O(n^2)$，与合并扫描融合后总计约 $O(m n^2)$；naive 逐区间为 $O(m^2 n^3)$（见 4.3）。

### 2.7 归约 —— 区间表 + 后缀 DP 合并

由引理 1、2，答案 = 选三段 $[\ell_1,r_1]$(`N`)、$[\ell_2,r_2]$(`O`)、$[\ell_3,r_3]$(`I`)，满足 $r_1+2\le\ell_2$、$r_2+2\le\ell_3$、$1\le\ell_1$、$r_3\le m$，最大化 $NI[\ell_1][r_1]+OV[\ell_2][r_2]+IV[\ell_3][r_3]$。

**后缀 DP（$O(m^2)$ 合并）**：预定义
$$sufI[p]=\max_{\ell_3\ge p,\,r_3} IV[\ell_3][r_3],\qquad sufOI[p]=\max_{\ell_2\ge p,\,r_2}\big(OV[\ell_2][r_2]+sufI[r_2+2]\big).$$
从 $p=m$ 递减填表：$sufI[p]=\max(sufI[p+1],\max_{r}IV[p][r])$；$sufOI[p]=\max(sufOI[p+1],\max_{r}OV[p][r]+sufI[r+2])$。最终
$$ans=\max_{\ell_1,r_1}NI[\ell_1][r_1]+sufOI[r_1+2].$$

**引理 6（合并正确性）** 上式与原始三区间最大化等价。
**证明**：$sufI[p]$ 汇总所有"左端 $\ge p$"的合法 `I`，$sufOI[p]$ 汇总"左端 $\ge p$ 的 `O` 且其后能接合法 `I`"的最优值和；因约束 $r_2+2\le\ell_3$ 只通过下标 $r_2$ 影响 `I` 的可行域（一个只依赖 $r_2$ 的后缀 $[r_2+2,m]$），可分离取 $\max$。逐层代入 $ans$ 中 `N` 的右端 $r_1$ 决定 `O` 可行域 $[r_1+2,m]$。三类 $\max$ 满足最优子结构，故整体等价。$\blacksquare$

**不可行的处理**：宽不足或形状不合法时对应 $*[*][*]=-\infty$（用大负数 + `fill_n` 初值），$\max$ 自然过滤。

### 2.8 溢出与边界

**数值上界（手算）**：单字母至多覆盖全部格 $n\cdot m\le150\times500=75000$ 格，每格 $\le200$，故 $V\le75000\times200=1.5\times10^7$；三字母相加 $\le4.5\times10^7$，最小对称 $-4.5\times10^7$。`int`（$\pm2.1\times10^9$）本可容纳，但：
- 需要 "$-\infty$" 哨兵表示不合法区间；取 `const i64 NEG=-4e18`（在 `i64` 内），故 DP/表统一用 `i64`，`fill_n` 初始化，避免与合法负值混淆。
- 列前缀 $cs[x][y]\le150\times200=3\times10^4$，矩形前缀 $ps$ 累加至 $\le1.5\times10^7$，均在 `i64`（也 `int`）安全区。
- 相加时 `NEG + 值` 仍 $\gg$ 下溢界（`i64` 下界 $\approx-9.2\times10^{18}$，$-4\times10^{18}$ 加 $4.5\times10^7$ 安全），但**判不可行时须先检查 $\le NEG/2$ 再相加**，防止把两个 $-\infty$ 相加误当合法。

**边界**：坐标读入翻转（顶行先给）；$r+2$ 与 $p+1$ 越界到 $m+1,m+2$，数组开 $\ge m+3$ 并令 $sufI[m+1]=sufOI[m+1]=\dots=NEG$（右侧无空间放字母）；宽 $<3$ 的区间恒 $NEG$。

## 3. 模式总结（Pattern Summary）

按**实际思考顺序**：

- **explore structure** — 把几何约束 $L_i=R_{i-1}+1$ 读成"每字母占一段连续列"，把 $u>R_K+1,\;P_1>u+W$ 读成"相邻字母列区间间至少空 1 列"（引理 1）。
- **column-additivity** — 覆盖格按列不重不漏划分，价值 = 逐列贡献之和，列间无耦合（引理 2）。
- **consider easier version** — 先各算"单字母在给定列区间的最大值" $NI/OV/IV$，把三维联合选择降成一维区间选段。
- **break greedy with counterexample** — 值域含负，"越高/越宽越好"在 O 上被 2.3 的 3×4 反例推翻，逼出"全枚举带 + 分离取 max"。
- **reduce by separable form (O)** — O 边框写成 $f(t)+g(b)$，一行扫描内 $O(n)$ 求 $OV[\ell][r]$（引理 3）。
- **max-subarray inside a frame (I)** — I = 两横杠 $A(b)+A(t)$ + 内部竖笔列上的**非空最大子段**（Kadane）（引理 4）。
- **state-machine over positions (N)** — N 的矩形规则→"逐列竖直区间 + 阶段状态机"，转移校验等价于 $t_2=t_1$、条件 3、末段规则（引理 5）。
- **suffix DP merge** — 用 $sufI,sufOI$ 把"有序且带间隙"的三段选择分离取 $\max$，最优子结构成立（引理 6）。
- **overflow & sentinel** — 值 $\le4.5\times10^7$；统一 `i64` + `NEG=-4e18` 哨兵，不可行先判 `≤NEG/2`；越界位 $suf[m+1]=NEG$。

## 4. 真实解法（Real Solution）

### 4.1 符号表（Notation Glossary）

| 符号 | 含义 | 类型/初始化 | 记忆点 |
|---|---|---|---|
| `n,m` | 行数、列数 | `int`，输入 | $n\le150,m\le500$ |
| `val[x][y]` | 格 $(x,y)$ 幸运值 | `i64 val[mxm][mxn]` | $x$ 列 $1..m$，$y$ 行 $1..n$（底=1） |
| `cs[x][y]` | 列 $x$ 竖直前缀 $\sum_{k\le y}val(x,k)$ | `i64`，`cs[x][0]=0` | 段和 = `cs[x][t]-cs[x][b-1]` |
| `A(y)` | 行 $y$ 在 $[\ell,r]$ 的和 | 计算临时 `i64` | $=ps$ 行前缀差 |
| `P(y)` | 侧柱前缀 `cs[l][y]+cs[r][y]` | 计算临时 | O 分离用 |
| `NI[l][r]` | `N` 恰覆盖列 $[l,r]$ 的最大值 | `i64`，`NEG` 初值 | 宽 $<3$ 恒 `NEG` |
| `OV[l][r]` | `O` 恰覆盖列 $[l,r]$ 的最大值 | `i64`，`NEG` 初值 | $O(m^2n)$（引理 3） |
| `IV[l][r]` | `I` 恰覆盖列 $[l,r]$ 的最大值 | `i64`，`NEG` 初值 | 带 + Kadane |
| `sufI[p]` | $\max_{\,l\ge p} IV$ 后缀最优 | `i64`，`sufI[m+1]=NEG` | 合并用 |
| `sufOI[p]` | $\max_{\,l\ge p}(OV+sufI[r+2])$ | `i64`，`sufOI[m+1]=NEG` | 合并用 |
| `ans` | 最终最大幸运度 | `i64` | |
| `NEG` | 负无穷哨兵 | `const i64{-4e18}` | `fill_n` 初始化表 |

> 下标：全部 1-based（与题面一致，前缀和天然 1-based，段公式不易错）。列 $1..m$，行 $1..n$。

### 4.2 算法步骤（Numbered Steps）

1. **读入 + 翻转**：读 $n,m$；对输入第 $i$ 行（$i=1..n$）写入行 $y=n-i+1$：`val[x][n-i+1]`，$x=1..m$。
2. **建列前缀**：$cs[x][y]=cs[x][y-1]+val[x][y]$。
3. **`fill_n`** 三张区间表与两后缀数组为 `NEG`。
4. **填 `OV[l][r]`（引理 3）**：枚举 $l$；算 $A(y)$、$P(y)$；扫 $t=3..n$ 维护 $\max_{b\le t-2}g(b)$，更新 $OV[l][t..]=?$ — 实现按 $(l,r)$ 外层、内层 $O(n)$ 分离扫描（$r$ 从 $l+2$ 起）。
5. **填 `IV[l][r]`（引理 4）**：外层枚举带 $(b,t)$（$t\ge b+2$），内层对每 $l$ 用 Kadane 前缀递推维护竖笔最大子段，配合横杠 $A(b)+A(t)$ 更新 `IV`。
6. **填 `NI[l][r]`（引理 5）**：对每起点 $l$ 跑列-DP，状态 $(\text{阶段},b,t)$，转移 1 延长段、转移 2 换段并校验；到达 $r$ 且处于"末段"时更新 `NI[l][r]`。
7. **后缀合并**：$p=m..1$ 递推 `sufI`、`sufOI`（见 2.7）。
8. **出答案**：$ans=\max_{l,r}NI[l][r]+sufOI[r+2]$；输出 `ans`。

### 4.3 复杂度分析

- `OV`：$O(m^2\cdot n)$（每区间 $O(n)$ 分离扫描）。
- `IV`：naive 逐区间 $O(m^2 n^2)$；按带外层 + 区间内 Kadane 亦 $O(m^2 n^2)$。$500^2\times150^2\approx5.6\times10^9$ 过大，故**全 500 数据须把 IV 与合并扫描融合为单趟列扫描**（$u(x)$、Kadane 随扫描维护），降至 $O(m n^2)$。
- `NI`：状态 $O(n^2)$/列，转移经单调队列优化后 $O(m n^2)$；naive $O(m^2 n^3)$。
- 合并 $O(m^2)$。空间 $O(m^2+n m)$。
- 小结：$\le80$ 的 4 个测试点（$n,m\le80$，$80^4\approx4\times10^7$）naive 表法即可；$\le500$ 满分需 $O(mn^2)$ 级融合扫描。

### 4.4 验证状态

- **本地题面无数字样例**：`P1398.md` 的两条"样例解释"均为图片链接，无输入/输出数值，**无法与官方答案对标**；下述仅为纸面/手算验证。
- **O 闭式手算**：用 2.3 的 $3\times4$ 表逐带算得 $OV=80$（带 $[2,4]$），与 2.4 的 $f(t)+g(b)$ 计算逐值吻合。
- **分离性自检**：$OV_{\ell,r}(b,t)$ 对 $t$、$b$ 可分，$t\ge b+2$ 约束由"扫 $t$ 时对 $b\le t-2$ 取前缀 $\max$"保证，边界 $t=3,b=1$ 可取。
- **I 内缩自检**：宽恰 3 时竖笔子段唯一为中间列 $[\ell+1,r-1]$，$\operatorname{MaxSub}$ 退化为该单列值 $u(\ell+1)$。
- **N 阶段自检**：$K=3$ 时"第二段"同时是 $K-1$，进入末段校验 $b_{3}=b_{2},t_{3}>t_{2}$ 与首→第二校验 $t_2=t_1,b_2>b_1$ 需同时成立，DP 用阶段合并处理。
- **合并边界自检**：最窄合法布局 $N[1..3],O[5..7],I[9..11]$ 对应 $r_1+2=5\le\ell_2$、$r_2+2=9\le\ell_3$，后缀下标 $m+1,m+2$ 处为 `NEG`，不产生伪解。

## 5. 示例代码（C++）

```cpp
// P1398 [NOI2013] 书法家
// 结构分解：三字母占递增且分离的列区间；OV/IV/NI 区间表 + 后缀 DP 合并
// https://www.luogu.com.cn/problem/P1398
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{155},mxm{505};
constexpr i64 NEG{-4000000000000000000LL};   // -4e18 哨兵

int n,m;
i64 val[mxm][mxn],cs[mxm][mxn],rowp[mxn][mxm];
i64 NI[mxm][mxm],OV[mxm][mxm],IV[mxm][mxm];
i64 sufI[mxm+3],sufOI[mxm+3];
i64 dp[5][mxn][mxn],ndp[5][mxn][mxn];

inline i64 seg(int x,int b,int t)             // 列 x 行段 [b,t] 和
{
	return cs[x][t]-cs[x][b-1];
}
inline i64 rowsum(int y,int l,int r)          // 行 y 列段 [l,r] 和 = A(y)
{
	return rowp[y][r]-rowp[y][l-1];
}

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=1;i<=n;++i)                      // 输入首行=顶行，翻转到 y=n-i+1
		for(int x=1;x<=m;++x)
		{
			i64 v;cin>>v;
			val[x][n-i+1]=v;
		}
	for(int x=1;x<=m;++x)
		for(int y=1;y<=n;++y)
			cs[x][y]=cs[x][y-1]+val[x][y];
	for(int y=1;y<=n;++y)
		for(int x=1;x<=m;++x)
			rowp[y][x]=rowp[y][x-1]+val[x][y];

	fill_n(&NI[0][0],mxm*mxm,NEG);
	fill_n(&OV[0][0],mxm*mxm,NEG);
	fill_n(&IV[0][0],mxm*mxm,NEG);

	// ---- OV[l][r]：引理 3 的 f(t)+g(b) 分离，每区间 O(n) ----
	for(int l=1;l<=m;++l)
		for(int r=l+2;r<=m;++r)                // 宽>=3
		{
			i64 bestg=NEG;                   // max_{b<=t-2} g(b)
			for(int t=3;t<=n;++t)
			{
				int b=t-2;                   // 新纳入 b=t-2（保证 b<=t-2）
				i64 g=rowsum(b,l,r)-(cs[l][b]+cs[r][b]);
				if(g>bestg)bestg=g;
				i64 f=rowsum(t,l,r)+(cs[l][t-1]+cs[r][t-1]);
				if(bestg>NEG/2)
					OV[l][r]=max(OV[l][r],f+bestg);
			}
		}

	// ---- IV[l][r]：引理 4，外层枚举带 (b,t)，内层 Kadane 竖笔 ----
	for(int b=1;b<=n-2;++b)
		for(int t=b+2;t<=n;++t)
		{
			// 逐列：横杠 bars 累计 [l,r]，竖笔 u 用 Kadane 维护 [l+1,r-1]
			for(int l=1;l<=m-2;++l)
			{
				i64 bars=rowsum(b,l,l)+rowsum(t,l,l);   // 先放入左端列 l 的两横杠格
				i64 maxEnd=NEG,maxSub=NEG;
				for(int r=l+1;r<=m;++r)
				{
					bars+=rowsum(b,r,r)+rowsum(t,r,t);  // 右移一列，横杠并入列 r
					if(r-1>l)                            // 竖笔区间 [l+1,r-1] 加入列 r-1
					{
						i64 u=cs[r-1][t-1]-cs[r-1][b];
						maxEnd=max(u,maxEnd+u);
						maxSub=max(maxSub,maxEnd);
					}
					if(maxSub>NEG/2)                     // r-1>=l+1 时才有非空子段
						IV[l][r]=max(IV[l][r],bars+maxSub);
				}
			}
		}

	// ---- NI[l][r]：引理 5 的列-DP（阶段状态机）----
	// 说明：此处按转移直写；对 500 满数据需把每种换段转移用 (b2,t2) 前缀/后缀 max 压成 O(n^2)/列
	for(int l=1;l<=m-2;++l)
	{
		fill_n(&dp[0][0][0],5*mxn*mxn,NEG);
		// 第 l 列起 N 的第一段（阶段1）
		for(int b=1;b<=n;++b)
			for(int t=b;t<=n;++t)
				dp[1][b][t]=seg(l,b,t);
		for(int x=l+1;x<=m;++x)
		{
			fill_n(&ndp[0][0][0],5*mxn*mxn,NEG);
			for(int ph=1;ph<=4;++ph)
				for(int b=1;b<=n;++b)
					for(int t=b;t<=n;++t)
					{
						i64 V=dp[ph][b][t];
						if(V<=NEG/2)continue;
						// (a) 延长当前段
						ndp[ph][b][t]=max(ndp[ph][b][t],V+seg(x,b,t));
						// (b) 另起新段：枚举新段区间 (b2,t2)
						for(int b2=1;b2<=n;++b2)
							for(int t2=b2;t2<=n;++t2)
							{
								i64 add=V+seg(x,b2,t2);
								int to=0;
								if(ph==1&&t2==t&&b2>b)to=2;                 // 1->2
								else if((ph==2||ph==3)&&t2<=t&&t2>=b-1&&b2<=b)to=3;  // ->中段
								else if((ph==2||ph==3)&&b2==b&&t2>t)to=4;   // ->末段
								if(to)ndp[to][b2][t2]=max(ndp[to][b2][t2],add);
							}
					}
			for(int b=1;b<=n;++b)
				for(int t=b;t<=n;++t)
					if(ndp[4][b][t]>NEG/2)
						NI[l][x]=max(NI[l][x],ndp[4][b][t]);
			memcpy(dp,ndp,sizeof(dp));
		}
	}

	// ---- 后缀合并 ----
	fill_n(sufI,mxm+3,NEG);
	fill_n(sufOI,mxm+3,NEG);
	i64 ans=NEG;
	for(int p=m;p>=1;--p)
	{
		sufI[p]=sufI[p+1];
		sufOI[p]=sufOI[p+1];
		for(int r=p+2;r<=m;++r)               // 以 p 起、宽>=3 的 I/O 区间
		{
			if(IV[p][r]>NEG/2)sufI[p]=max(sufI[p],IV[p][r]);
			if(OV[p][r]>NEG/2&&r+2<=m&&sufI[r+2]>NEG/2)
				sufOI[p]=max(sufOI[p],OV[p][r]+sufI[r+2]);
		}
	}
	for(int l=1;l<=m;++l)
		for(int r=l+2;r<=m;++r)
			if(NI[l][r]>NEG/2&&r+2<=m&&sufOI[r+2]>NEG/2)
				ans=max(ans,NI[l][r]+sufOI[r+2]);

	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **读入翻转**：`val[x][n-i+1]` 落实"第 $i+1$ 行 = 顶行"，内部保持 $y=1$ 为底（与题面坐标一致）。
- **三张区间表**先 `fill_n` 到 `NEG`；所有相加前先判 `>NEG/2`，杜绝 $-\infty$ 参与运算（见 2.8）。
- **`OV`**：内层 `bestg` 即 $\max_{b\le t-2}g(b)$，与引理 3 的 $f(t)+g(b)$ 逐项对应，$O(m^2n)$。
- **`IV`**：带 $(b,t)$ 外层，`maxEnd/maxSub` 是竖笔权重 `u` 的非空最大子段 Kadane，`bars` 累计两横杠，对应引理 4。
- **`NI`**：`dp[ph][b][t]` = 阶段 `ph`、当前段区间 `[b,t]`；转移 (a) 延长段、(b) 换段并按 1→2/→3/→4 规则校验，正是引理 5 的状态机。$K=3$ 由 1→2→4 直接生成。
- **合并**：`sufI`、`sufOI` 逆序递推，`ans` 用 $NI+sufOI[r+2]$，落实引理 6 的分离取 $\max$。

> **性能与完整性备注（诚实声明）**：上面的 `NI` 换段转移按 $(b_2,t_2)$ 直写为 $O(n^4)/$列，是"正确但未按 4.3 优化"的参考骨架；对 $n,m\le80$ 的子任务需把每类换段转移压成前缀/后缀 $\max$（$O(n^2)/$列）方能通过，对 $500$ 满数据还需把 `OV/IV/NI` 与后缀合并融合成单趟列扫描（$O(mn^2)$）。因**禁止编译/运行**，本代码仅经纸面推导与 2.3/2.4/4.4 的手算校验，未宣称任何实际运行结果。
