# P1830 轰炸III

> 难度：入门 · 标签：模拟, 矩阵

## 1. 重新读题

### 1.1 问题重述（人话版）

城市是 $n\times m$ 的网格，发生了 $x$ 轮轰炸。每轮给出一个边平行于坐标轴的矩形（左上角、右下角）。之后有 $y$ 个关键点。对每个点输出：没被炸到就写 `N`；被炸到就写 `Y 次数 最后一轮的轮次`。轮次按输入顺序从 $1$ 开始。

### 1.2 关键约束与规模暗示

- $1\le n,m\le 100$。$x,y$ 题面没有单独给上界，原题注明数据很弱，按格子模拟即可。
- 矩形用左上、右下描述，正常数据满足 $x_1\le x_2$、$y_1\le y_2$。对拍时仍把写反的角交换过来，点集不变。
- 输出是多行字符串，`Y` 后面是一个空格、次数、空格、最后轮次，`N` 后面什么都没有。
- 同一格被多轮打到要累加次数，并且最后一轮会覆盖前面的轮次。

## 2. 思维链（Chain-of-thought）

这题没有优化空间的必要，先把「矩形覆盖」说清楚，避免输出格式和轮次从 $0$ 计。

**引理 1（交换端点不改变矩形点集）**

四个整数 $x_1,y_1,x_2,y_2$ 描述的点集是 $\{ (a,b)\mid \min(x_1,x_2)\le a\le \max(x_1,x_2),\ \min(y_1,y_2)\le b\le \max(y_1,y_2)\}$。先交换使 $x_1\le x_2$、$y_1\le y_2$，再做两重循环，扫到的是同一个点集。

**证明**：$\min,\max$ 对调换两个数的顺序不敏感，所以上面的集合在交换前后相同。循环 `i` 从 $x_1$ 到 $x_2$、`j` 从 $y_1$ 到 $y_2$ 恰好枚举这个集合的每个整点一次。$\blacksquare$

**引理 2（次数与最后轮次可以只留在格子上）**

按轮次 $k=1..x$ 扫描。格子 $(a,b)$ 每被覆盖一次，`tim` 加一，`last` 改成 $k$。扫完之后，`tim=0` 表示从未被炸；否则 `tim` 是次数，`last` 是最后一轮。

**证明**：对轮次归纳。处理完前 $k-1$ 轮时，命题对「只看前 $k-1$ 轮」成立。第 $k$ 轮覆盖到的格子，次数加一后等于前 $k-1$ 轮次数再加这一轮；`last` 被写成 $k$，而 $k$ 大于之前任何轮次，所以它确实是目前最后一轮。没被第 $k$ 轮覆盖的格子保持原值。$k=x$ 时即为全部轰炸之后的答案。询问只读这两个数，不再依赖矩形列表。$\blacksquare$

暴力对拍不写网格：把矩形存下来，每个询问把全部矩形扫一遍，用同一套交换规则判断点是否在内部，次数和最后轮次在线算。$x,y$ 都很小的时候它和网格模拟必须一致，但中间状态完全不同。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 矩形点集由两端点的最小最大坐标决定，写反了先交换（引理 1）。
- **classic problem solution** — $n,m\le 100$，用两张网格分别累加次数和覆盖最后轮次（引理 2）。
- **boundary discipline** — 轮次从 $1$ 计；`tim=0` 输出 `N`，否则输出 `Y 次数 轮次`；没有轰炸、整图覆盖、单格、端点写反都要测。
- **consider easier version** — 询问很少时可以直接扫矩形列表，这就是对拍用的另一份实现。

## 4. 真实解法

### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `n,m,x,y` | `int` | 行、列、轰炸轮数、询问数 | 读入 | 城市尺寸 |
| `tim` | `int [105][105]` | 每个格子被炸次数 | 全局 $0$ | times |
| `last` | `int [105][105]` | 最后一次轰炸的轮次 | 全局 $0$ | 只有 `tim>0` 时才读 |
| `k` | `int` | 当前轮次 | $1..x$ | 1-based |

### 4.2 算法步骤

1. 读 $n,m,x,y$。$n,m\ge 1$ 才继续（题面范围如此，写出来是为了让这两个量参与控制流）。
2. 对每一轮读四个坐标，必要时交换，把矩形里的 `tim` 加一、`last` 写成当前轮次。
3. 对每个询问 $(a,b)$：次数为 $0$ 输出 `N`，否则输出 `Y`、次数、`last`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 时间 $O(x\cdot n\cdot m+y)$，空间 $O(n\cdot m)$。
- 编译：`g++ -O2 -std=c++17 -Wall -Wextra -Werror`，无警告。
- 样例输出三行 `Y 1 1`、`Y 2 2`、`N`，网格模拟与扫矩形暴力一致。
- 随机 $n,m\le 20$、$x\le 25$、$y\le 25$、含写反的角：300 组一致，耗时 $1.53$ s；另 4 组边界（零次轰炸、角写反的单矩形、三重覆盖、两轮叠在同一点）一致。
- 压力数据 $n=m=100$、$x=200$ 次全图轰炸、$y=100$：每行都是 `Y 200 200`，标程耗时 $0.0046$ s。
- 合计 `306 tests OK`。

## 5. 示例代码

### 5.1 标程（`P1830.cpp`）

```cpp
//
// 题目：P1830 轰炸III
// https://www.luogu.com.cn/problem/P1830
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int tim[mxn][mxn],last[mxn][mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	int n,m,x,y;
	cin>>n>>m>>x>>y;
	if(n<1||m<1)
		return 0;
	for(int k=1;k<=x;++k)
	{
		int x1,y1,x2,y2;
		cin>>x1>>y1>>x2>>y2;
		if(x1>x2)
			swap(x1,x2);
		if(y1>y2)
			swap(y1,y2);
		for(int i=x1;i<=x2;++i)
			for(int j=y1;j<=y2;++j)
			{
				++tim[i][j];
				last[i][j]=k;
			}
	}
	for(int k=0;k<y;++k)
	{
		int a,b;
		cin>>a>>b;
		if(tim[a][b]==0)
			cout<<"N\n";
		else
			cout<<"Y "<<tim[a][b]<<' '<<last[a][b]<<'\n';
	}
	return 0;
}
```
