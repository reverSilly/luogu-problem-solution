# P1370 Charlie 的云笔记序列

> 标签：动态规划 DP / 递推 · 难度：省选/NOI-

## 1. 重新读题

**问题重述（大白话）**

给定长度为 $n$ 的整数序列 $a$。对每个子段 $a[l:r]$（$1\le l\le r\le n$），$F(l,r)$ 表示 $a[l:r]$ 的**本质不同子序列个数**，空序列也计一个。求
$$\sum_{1\le l\le r\le n} F(l,r)\pmod{998244353}.$$
"本质不同"= 长度不同，或存在某位值不同（即按值序列去重，不看选取的下标方案）。

**约束与需要钉死的口径（以题面为准）**

| 量 | 范围 / 口径 |
|---|---|
| $n$ | $1\le n\le 10^5$；子任务 $10,100,1000$ |
| $a_i$ | $100\%$ 数据 $\lvert a_i\rvert\le 10^9$（有负数、值域大，必须离散化）；$50\%$ 数据 $0\le a_i\le 10^5$ |
| 模数 | $P=998244353$（质数），最终答案取模 |
| 求和范围 | **全部**满足 $1\le l\le r\le n$ 的子段，共 $\frac{n(n+1)}2$ 个，无额外条件、无多组数据 |
| $F$ 口径 | 含空序列，故 $F(l,l)=2$（空 + $[a_l]$）恒成立 |

**复杂度暗示**：段数 $\sim \frac{n^2}{2}=5\times10^9$，逐段跑"本质不同子序列"递推（每段 $O(\text{len})$）是 $O(n^2)\sim10^{10}$，$50\%$（$n\le1000$）才允许。要过 $n=10^5$ 必须**对所有起点 $l$ 同时推进**，把 $O(n^2)$ 压成 $O(n\log n)$（离散化排序）+ $O(n)$ 递推。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制 —— 单个子段的"本质不同子序列"怎么算

先固定左端点 $l$，令 $D_l[r]=$ 本质不同子序列数（含空）$=F(l,r)$，规定空段 $D_l[k]=1\ (k<l)$，$D_l[l-1]=1$。

设 $p[r]$ 为 $a[r]$ 上一次出现的位置（$<r$ 的最大下标使 $a[p[r]]=a[r]$，不存在记 $0$）。

**引理 1（段内递推）** 对 $r\ge l$，
$$D_l[r]=2D_l[r-1]-[p[r]\ge l]\cdot D_l[p[r]-1].$$
**证明**：把 $a[l:r]$ 的本质不同子序列分成两类：(A) 不含 $a_r$ 的，恰为 $a[l:r-1]$ 的全部本质不同子序列，$D_l[r-1]$ 个；(B) 含 $a_r$ 的，每个形如 $t+[a_r]$，其中 $t$ 取遍 $a[l:r-1]$ 的本质不同子序列，故 (B) 也有 $D_l[r-1]$ 个。总并集 $A\cup B$：由容斥 $|A|+|B|-|A\cap B|$，只需数 $A\cap B$——既是 $a[l:r-1]$ 的子序列、又"以 $a_r$ 结尾"的序列 $u$。$u$ 结尾为 $a_r$；若它又是 $a[l:r-1]$ 的子序列，则末位 $a_r$ 可匹配到 $r$ 之前最后一次出现 $p[r]$（必须 $p[r]\ge l$ 才在段内），于是 $u=t'+[a_r]$，$t'$ 是 $a[l:p[r]-1]$ 的子序列。反向：$a[l:p[r]-1]$ 的任一子序列把 $a_r$ 配到位置 $p[r]$ 也得到 $A\cap B$ 中的元素，且映射为双射。故 $|A\cap B|=D_l[p[r]-1]$（当 $p[r]\ge l$），否则 $p[r]<l$ 时 $A\cap B=\varnothing$。代入即得。$\blacksquare$

这就是标签里"本质不同子序列"的经典 $O(\text{len})$ 递推，单段可用。

### 2.2 卡壳 —— 逐段做太慢，能否对 $l$ 求和一起推进

直接对每个 $l$ 跑引理 1 是 $O(n^2)$。观察求和式
$$\text{Ans}=\sum_{r=1}^n\ \underbrace{\sum_{l=1}^r D_l[r]}_{=:A_r}.$$
**关键状态设计**：定义 $A_r=\sum_{l=1}^r D_l[r]$（即"以 $r$ 收尾的所有 $F(l,r)$ 之和"）。若能建立 $A_r$ 只依赖更早的 $A$ 的递推，就把 $O(n^2)$ 降成 $O(n)$。

**引理 2（求和递推）** 记 $A_0=0$，则
$$A_r=\begin{cases}2+2A_{r-1}, & p[r]=0,\\[2pt] 1+2A_{r-1}-A_{p[r]-1}, & p[r]\ge1.\end{cases}$$
**证明**：把 $A_r=\sum_{l=1}^r D_l[r]$ 拆开，$l=r$ 项 $D_r[r]=2$，$l\le r-1$ 项用引理 1：
$$A_r=2+\sum_{l=1}^{r-1}\bigl(2D_l[r-1]-[p[r]\ge l]D_l[p[r]-1]\bigr)=2+2A_{r-1}-\sum_{l=1}^{r-1}[p[r]\ge l]D_l[p[r]-1].$$
指示 $[p[r]\ge l]$ 说明仅 $l=1..p[r]$（当 $p[r]\ge1$）贡献减法，且把上限放宽到 $l=p[r]$（此时 $l=p[r]\le r-1$）不影响：
$$\sum_{l=1}^{p[r]}D_l[p[r]-1]=\Bigl(\sum_{l=1}^{p[r]-1}D_l[p[r]-1]\Bigr)+D_{p[r]}[p[r]-1]=A_{p[r]-1}+1,$$
其中 $D_{p[r]}[p[r]-1]=1$（空段）。故 $p[r]\ge1$ 时 $A_r=2+2A_{r-1}-(A_{p[r]-1}+1)=1+2A_{r-1}-A_{p[r]-1}$。若 $p[r]=0$，减法对一切 $l$ 为零（首现，任何段都没有更早的 $a_r$），$A_r=2+2A_{r-1}$。$\blacksquare$

**为何覆盖全部合法方案（最优子结构等价说明）**：$A_r$ 是"右端点为 $r$ 的所有子段"的和，引理 2 只用两类信息——$A_{r-1}$（把 $a_r$ 追加进每个以 $r-1$ 收尾的子段）和 $A_{p[r]-1}$（扣掉因 $a_r$ 与上次出现重复而多算的部分）。这两项恰好把引理 1 的"翻倍-回退"逐字转移到求和层，没有遗漏任何 $l$：每个 $l$ 在两个求和号里各出现一次，且 $D_l[p[r]-1]$ 只在 $l\le p[r]$ 参与减法，与引理 1 指示函数一致。所以 $A_r$ 递推 $\iff$ 逐段引理 1 递推的和，二者等价。$\blacksquare$

> **统一写法（可选）**：若约定 $A_{-1}=-1$，则 $p[r]=0$ 分支 $2+2A_{r-1}$ 恰等于 $1+2A_{r-1}-A_{p[r]-1}$（因 $-A_{-1}=+1$），两支合并为一条 $A_r=1+2A_{r-1}-A_{p[r]-1}$。但下标 $-1$ 不便入数组，代码仍按 $p[r]$ 是否为 0 分两支，逻辑与统一式等价。

### 2.3 收尾：$p[r]$ 与离散化

$p[r]$ 需要"上次出现位置"，用哈希/离散化的 `last[]`：读入并离散化值域（$|a_i|\le10^9$ 且有负数，不能直接开数组），扫描时 `last[id]` 即 $p[r]$，随后更新为 $r$。全局默认 0 正好表示"未出现"。最终 $\text{Ans}=\sum_{r=1}^n A_r\bmod P$。总时间 $O(n\log n)$（排序），空间 $O(n)$。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 先固定左端点，导出"本质不同子序列"单段递推引理 1（容斥/双射证明重叠恰为 $D_l[p-1]$）。
- **naive approach got stuck → dissect why** — 逐段跑引理 1 是 $O(n^2)$ 超时；症结在"每个 $l$ 独立推进"，于是把"对 $l$ 求和"升格为新状态一起推进。
- **classic problem solution** — 状态设计 $A_r=\sum_{l\le r}F(l,r)$：把逐段线性递推**整体求和**，用空段约定 $D_l[k]=1\,(k<l)$ 补齐 $l=p[r]$ 项。
- **reduce to easier problem** — 引理 2 把 $A_r$ 归约为仅依赖 $A_{r-1},A_{p[r]-1}$ 的 $O(1)$ 递推，$O(n^2)\to O(n)$。
- **estimate first, then size arrays** — 值域 $10^9$ 需离散化 + `last[]`；模 $P$ 下用 `i64` 防溢出。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n,a[1..n]` | 输入序列（1-based） | `i64` | 值可负、达 $10^9$ |
| `p` | $a[r]$ 上次出现位置，0=首现 | `int` | 由 `last[id]` 读出 |
| `last[id]` | 离散化后每个值的最近出现下标 | `int`，全局默认 0 | 正好等于"未出现"=0 |
| `A[0..n]` | $A_r=\sum_{l=1}^r F(l,r)$ | `i64`，`A[0]=0` | 求和层递推，全程 $[0,P)$ |
| `ans` | $\sum_r A_r$ | `i64`，0 起 | 每步取模 |
| `P` | $998244353$ | `constexpr i64` | |

**位置约定**：本文与代码**一律 1-based**（递推自然带 $A_0,A_{p[r]-1}$，比 0-based 更贴合公式），全文一致。

### 4.2 算法步骤

1. 读入 $n$ 与 $a[1..n]$，同时收集到 `v`；排序去重得离散化表，`id=lower_bound(...)`。
2. 扫描 $r=1..n$：`p=last[id]; last[id]=r`。
3. 按引理 2：`p==0 ? A[r]=(2+2A[r-1])%P : A[r]=(1+2A[r-1]-A[p-1])%P` 再规范到 $[0,P)$。
4. `ans=(ans+A[r])%P`；输出 `ans`。

### 4.3 复杂度与溢出预算

- 时间：排序 $O(n\log n)$ + 主循环 $O(n)$，$n=10^5$ 时约 $2\times10^6$ 次基本操作，远低于时限；朴素逐段 $O(n^2)\sim10^{10}$ 会 TLE。
- 空间：$O(n)$ 数组（`a,A,last,v`），远小于限制。
- 溢出：所有量在模 $P$ 下存储。中间 $2A_{r-1}\le2(P-1)\approx2.0\times10^9$，`1+2A-A[p-1]` 落在 $(-P,\,2P)$，均在 `i64`（$\le9.2\times10^{18}$）内，且用 `long long` 避免 `int` 边界风险；`ans` 每步取模，恒 $<P$。离散化用 `lower_bound` 于 `i64` 向量，比较无溢出。

- **局部口径核对**：题面 $a=[1,9,9,8,0,3,2,1]$ 断言 $F(1,3)=6$（段 $[1,9,9]$ 的子序列 $[],[1],[9],[1,9],[9,9],[1,9,9]$）。用引理 1 复核（起点 $l=1$）：$D_1[0]=1$；$a_1=1$ 首现 $\Rightarrow D_1[1]=2$；$a_2=9$ 首现 $\Rightarrow D_1[2]=2\cdot2=4$；$a_3=9$ 上次在 $p=2\ge1\Rightarrow D_1[3]=2D_1[2]-D_1[1]=8-2=6$ ✓，与题面一致。

- **多重出现边界 $[1,2,2,1]$**：DP $A_1=2,A_2=6,A_3=1+12-A_1=11,A_4=1+22-A_0=23$，ans=42；手算 $A_3=6+3+2=11$、$A_4=11+6+4+2=23$ ✓✓。

## 5. 示例代码（C++）

```cpp
// P1370 Charlie 的云笔记序列
// 对"以 r 收尾的所有子段"求和 A_r，得 O(n) 线性递推（引理 2）
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};            // n<=1e5 +5
constexpr i64 P{998244353};

int n;
i64 a[mxn],A[mxn];                    // A[r]=sum_l F(l,r)，1-based；A[0]=0
int last[mxn];                        // 值(离散化后)->上次位置，0=未出现

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	vector<i64>v;
	for(int i=1;i<=n;++i)
	{
		cin>>a[i];
		v.push_back(a[i]);
	}
	sort(v.begin(),v.end());
	v.erase(unique(v.begin(),v.end()),v.end());

	i64 ans=0;
	for(int i=1;i<=n;++i)
	{
		int id=lower_bound(v.begin(),v.end(),a[i])-v.begin();
		int p=last[id];               // 上一次出现位置(1-based)，0 表示首现
		last[id]=i;
		if(p==0)
			A[i]=(2+2*A[i-1])%P;
		else
			A[i]=((1+2*A[i-1]-A[p-1])%P+P)%P;  // 规范到 [0,P)
		ans=(ans+A[i])%P;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 代码说明

- **全局静态数组**：`a,A,last` 尺寸 `mxn{100005}`；`last` 默认 0 即"未出现"，无需 `fill_n`（本题无 INF 数组，规避漏填坑）。
- **1-based**：`A[p-1]` 当 $p=1$ 落到 `A[0]`（全局默认 0），与引理 2 的 $A_{p[r]-1}$ 一致；`A[0]=0` 是求和基。
- **取模**：负数用 `(x%P+P)%P` 修正；`2*A` 与 `ans` 均在 `i64` 安全范围（4.3）。
- **离散化**：`v` 排序去重后 `lower_bound` 求 `id`，兼容负数与 $10^9$ 值域。
