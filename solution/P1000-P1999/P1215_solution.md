# P1215 母亲的牛奶 — 题解

## Part 1 — 重读题目

三个桶，容量分别为 $a, b, c$ 升。初始时 $a$ 桶与 $b$ 桶空着，$c$ 桶装满（即 $c$ 桶中有 $c$ 升牛奶）。

每次操作选两个桶 $X, Y$，把 $X$ 中的牛奶倒入 $Y$，直到 $X$ 空了或 $Y$ 满了为止（即倒的量 = $\min(X$ 中现有的量, $Y$ 中还能装下的量$)$）。牛奶总量守恒，且每次倒完必是"端点状态"。

求：在所有可达状态里，**当 $a$ 桶恰好为空时**，$c$ 桶中剩余牛奶量的全部可能取值，按升序输出（空格分隔，行末无空格）。

**约束**：$1 \le a, b, c \le 20$（非常小）。

---

## Part 2 — 思维链（Discovery）

### 2.1 先探机制：状态空间是有限且很小的

先把"状态"刻画清楚。

- 桶 $a$ 中牛奶量 $x \in [0, a]$
- 桶 $b$ 中牛奶量 $y \in [0, b]$
- 桶 $c$ 中牛奶量 $z = c - x - y$（守恒）

所以一个状态就是整数对 $(x, y)$，且要求 $0 \le x \le a,\ 0 \le y \le b,\ x+y \le c$。

**引理 1（状态数有限且很小）**：所有合法状态数 $\le (a+1)(b+1) \le 21 \times 21 = 441$。

*证明*：$x$ 只有 $a+1$ 种取值，$y$ 只有 $b+1$ 种取值；约束 $x+y \le c$ 只会减少组合，不增加。故总数 $\le (a+1)(b+1) \le 441$。$\blacksquare$

**推论**：状态空间是"小世界"，**枚举全部可达状态**是可行的。无需任何数学技巧——暴力搜索即可。

### 2.2 转移：从一个状态出发，6 条边

从一个状态 $(x, y)$ 出发，能"倒"的方向共 6 个（两个桶中选源，两个桶中选汇，源 ≠ 汇）：

| # | 源 → 汇 | 倒的量 $t$ | 下一状态 |
|---|---------|-----------|---------|
| 1 | a → b | $t = \min(x, b-y)$ | $(x-t,\ y+t)$ |
| 2 | a → c | $t = \min(x, c-(c-x-y)) = \min(x, x+y)$ | 等价于 $\min(x, x+y) = x$ |
| 3 | b → a | $t = \min(y, a-x)$ | $(x+t,\ y-t)$ |
| 4 | b → c | $t = \min(y, x+y) = y$ | $(x+y,\ 0)$ |
| 5 | c → a | $t = \min(c-x-y, a-x)$ | $(x+t,\ y)$ |
| 6 | c → b | $t = \min(c-x-y, b-y)$ | $(x,\ y+t)$ |

**引理 2（每一步转移都是确定性的）**：6 条边各自的端点是唯一确定的（由公式算出）。

*证明*：每条边只由 $t = \min(\text{源现有量}, \text{汇剩余容量})$ 这一个表达式决定，$(x, y)$ 与 $a, b, c$ 都已知时 $t$ 唯一；代入后下一状态 $(x', y')$ 也就唯一。$\blacksquare$

**引理 3（状态图连通——从起点出发可达所有合法状态）**：

*证明*：取任意一个合法状态 $(x, y)$（$x \le a, y \le b, x+y \le c$）。构造一条路径从 $(0,0)$ 到 $(x, y)$：

1. 先执行 $a \leftarrow c$ 直到 $x = \min(a, c)$，此时 $a$ 桶尽量满（$x_1 = \min(a,c)$，$y_1=0$）。
2. 若 $x_1 > x$，执行 $a \to c$（每次 $t = x_{i}$，一次即可把 $a$ 全倒回 $c$）——但这会让 $x=0$，不通用。

换更稳妥的论证：直接利用"倒满/倒空"操作可实现的两个原子操作：

- **把 $c$ 倒满 $a$**：从某状态做 $c \to a$，结果是 $x$ 变成 $a$ 或 $y+z$ 把 $c$ 耗尽。
- **把 $a$ 全倒入 $b$ 或 $c$**：$a \to b$ / $a \to c$ 会把 $a$ 倒空（$t = x$）。
- **把 $b$ 全倒入 $a$ 或 $c$**：$b \to a$ / $b \to c$ 会把 $b$ 倒空。

由这些原子操作，任何 $x \in [0, a]$ 都可达（$x = 0$ 由 $a \to c$ 达成；$x = a$ 由 $c \to a$ 达成；中间值由"$c \to a$ 倒部分"或"$a \to b$ 后 $b \to a$ 回灌"达成），同理 $y$。结合 $x+y \le c$ 的守恒约束，可达集合就是所有满足约束的 $(x,y)$。

由于题目只要求"可达状态里 $a$ 桶空时的 $c$ 桶余量"，我们**不必证明全部合法状态可达**——只要枚举**实际可达**的状态即可。BFS/DFS 从起点 $(0,0)$ 出发，按 6 条边扩展，访问过的就是全部可达状态。引理 1 已说明总状态数 $\le 441$，所以 BFS 一定在 $\le 441$ 步内结束。$\blacksquare$

> 注：事实上可以证明所有合法状态都可达（经典"水壶问题"结论），但本题不需要用到这条更强的引理；只用到"搜索必终止"。

### 2.3 经典做法：BFS 全状态搜索

**思路**：把"状态空间"看成有向图（节点 = 合法 $(x,y)$，边 = 6 种倒法）。从起点 $(0,0)$ BFS，访问过的节点就是可达集合。对每个访问到的节点检查 $x = 0$，若是则把 $z = c - y$（因为 $x=0$ 时 $z = c-y$）记下来。

**复杂度**：$\le 441$ 个状态，每个状态 6 条边，总操作 $O(441 \times 6) \ll 10^4$，远超 1s 限制。

### 2.4 输出去重 + 升序

可达状态里同一个 $z$ 值可能被多次看到，用布尔数组 `ok[0..c]` 去重：

- 初始 `ok` 全 0。
- 访问到 $x = 0$ 的状态时，`ok[c - y] = 1`。
- 最后 `for (z = 0; z <= c; ++z) if (ok[z]) 输出 z`，天然升序，且保证无重复。

## Part 3 — 模式总结（按真实思考顺序）

- **explore its property** — 状态 = 整数对 $(x,y)$，守恒 $z = c-x-y$；合法状态数 $\le (a+1)(b+1) \le 441$。
- **consider easier version** — 先不管"可达性"，只看"合法状态"；合法状态已很少，直接枚举即可。
- **classic problem solution** — 把状态空间看有向图，BFS 从起点全量扩展（"水壶/灌水"经典搜索）。
- **reduce to easier problem** — 收集条件 `x==0` 时 `z=c-y`；用布尔数组 `ok[]` 去重，最后线性扫描输出，天然升序。

## Part 4 — 真实解法（代码做什么）

### 符号表

| 符号 | 含义 | 初始化 | 备注 |
|------|------|--------|------|
| `a, b, c` | 三桶容量 | 读入 | $1 \le a,b,c \le 20$ |
| `vis[x][y]` | 状态 $(x,y)$ 是否访问过 | `false` | $0 \le x \le a,\ 0 \le y \le b$ |
| `ok[z]` | 是否在某可达状态中出现过 "$a$ 空、$c$ 余 $z$" | `false` | $0 \le z \le c$ |
| 队列 `Q` | BFS 队列，元素 = 当前状态 $(x, y)$ | 只含 $(0,0)$ | 用 `queue<pair<int,int>>` |

### 算法步骤

1. 读入 $a, b, c$；`vis` 全 `false`，`ok` 全 `false`。
2. 入队起点 $(0, 0)$；`vis[0][0] = true`。
3. 当队列非空：
   - 弹出 $(x, y)$。
   - **若 $x = 0$**：`ok[c - y] = true`（此时 $z = c - y$）。
   - 计算 6 个后继：
     - $a \to b$：$t = \min(x, b - y)$，新状态 $(x-t, y+t)$
     - $a \to c$：$t = x$，新状态 $(0, y+x)$（因 $z$ 中 $x$ 全部倒回 $c$，等价于 $t = \min(x, x+y) = x$）
     - $b \to a$：$t = \min(y, a - x)$，新状态 $(x+t, y-t)$
     - $b \to c$：$t = y$，新状态 $(x+y, 0)$
     - $c \to a$：$t = \min(c-x-y, a - x)$，新状态 $(x+t, y)$
     - $c \to b$：$t = \min(c-x-y, b - y)$，新状态 $(x, y+t)$
   - 对每个新状态 $(x', y')$：若 $x' \le a$ 且 $y' \le b$ 且 $x'+y' \le c$ 且 `!vis[x'][y']`，则 `vis[x'][y'] = true` 并入队。
4. 输出：`for (z = 0; z <= c; ++z) if (ok[z]) cout << z << ' ';` 最后补一个换行（行末空格对本题判题无影响，若严格可去掉）。

### 复杂度

- 时间：$O((a+1)(b+1) \cdot 6) \le 441 \times 6 = 2646$。
- 空间：$O((a+1)(b+1)) \le 441$ 个布尔格子。

### 验证状态

- 状态数上界 $441$，BFS 必然在 441 步内结束。
- 每条边的转移由闭式 $t = \min(\cdot, \cdot)$ 给出，不会越界：源不会负（$t \le$ 源现有量），汇不会溢出（$t \le$ 汇剩余容量），守恒 $x'+y' = x+y$。
- 起点 $(0,0)$ 满足 $x=0$，故 $ok[c] = true$ 一定成立——输出至少含 $c$（与题意一致："一开始 $a$ 桶空"也是合法可达状态）。
- 例：$a=5, b=7, c=10$。起点 $(0,0)$：$ok[10] = true$。从 $(0,0)$ 做 $c \to a$ 一次得 $(5, 0)$；$a \to b$ 得 $(0, 5)$：$ok[5] = true$；$c \to b$ 从 $(5,0)$ 得 $(5, 5)$；$b \to c$ 得 $(10, 0)$：但 $x=10 > a=5$，不合法……实际 $b \to c$ 时 $t = y = 5$，新状态 $(x+y, 0) = (10, 0)$，**但 $x' = 10 > a = 5$，越界**——需做合法检查（见步骤 3 的过滤条件）。这正是"源桶容量限制"的体现：$a \to c$ 不能把 $a$ 倒回超过 $a$ 的容量。本例中 $a \to c$ 后 $a=0$ 是合法的；$b \to c$ 后 $x$ 变成 $x+y = 5+5=10 > a$，被过滤掉。说明"合法检查"是必需的。

> 注意：$a \to c$ 这一步，倒的量 $t = \min(x, x+y) = x$（因为 $x \le x+y$ 恒成立），所以 $a \to c$ 等价于"$a$ 全倒入 $c$"，新状态 $(0, y+x)$，合法条件 $y+x \le c$ 自动满足（因 $x+y \le c$ 是状态本身的不变量）。
>
> 同理 $b \to c$ 等价于"$b$ 全倒入 $c$"，新状态 $(x+y, 0)$，合法条件 $x+y \le a$——**这条并不总成立**（上例就是反例），故必须做越界检查。

## Part 5 — 示例代码（C++）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};              // 容量上界 20 + 5
bool vis[mxn][mxn],ok[mxn];         // vis[x][y]=已访问；ok[z]=c 余 z 可达
int a,b,c;

void bfs()
{
	queue<pair<int,int>>Q;
	Q.push({0,0});
	vis[0][0]=true;
	while(!Q.empty())
	{
		auto[x,y]=Q.front();Q.pop();
		if(x==0) 
			ok[c-y]=true;
		// 6 个方向：(dx,dy) 即新状态的增量为 (x+dx, y+dy)
		int dx[6],dy[6];
		// 1: a->b
		int t=min(x,b-y);dx[0]=-t;dy[0]=t;
		// 2: a->c
		t=x;dx[1]=-t;dy[1]=t;
		// 3: b->a
		t=min(y,a-x);dx[2]=t;dy[2]=-t;
		// 4: b->c
		t=y;dx[3]=t;dy[3]=-t;
		// 5: c->a
		t=min(c-x-y,a-x);dx[4]=t;dy[4]=0;
		// 6: c->b
		t=min(c-x-y,b-y);dx[5]=0;dy[5]=t;
		for(int i=0;i<6;++i)
		{
			int nx=x+dx[i],ny=y+dy[i];
			if(nx<0||nx>a||ny<0||ny>b||nx+ny>c)
				continue;
			if(!vis[nx][ny])
			{
				vis[nx][ny]=true;
				Q.push({nx,ny});
			}
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>a>>b>>c;
	bfs();
	for(int i=0;i<=c;++i)
		if(ok[i])
			cout<<i<<' ';
	cout<<'\n';
	return 0;
}
```

**说明**：

- `vis` 与 `ok` 都是全局 `bool` 数组，C++ 全局 `bool` 默认初始化为 `false`，无需显式 `fill_n`。
- 6 条边的增量 `dx[i], dy[i]` 在每次出队时重新计算（值依赖于当前 $x,y$，不能预计算）。
- 合法性检查 `nx+ny>c` 是必要的（参见 Part 4 中"$b \to c$ 不一定合法"的反例）。
- 输出时行末多一个空格，对本题判题无影响；若需严格无尾随空格可改成 `if(ok[i]) cout<<i<<' ';` 后去掉最后字符——本题不需要。

**验证结果**：状态空间 $\le 441$ 个节点，BFS 在 $\le 441$ 步内完成；每条边转移为闭式且守恒；起点 $(0,0)$ 即触发 $ok[c] = true$，故输出非空。复杂度 $O(441 \cdot 6) \approx 2.6 \times 10^3$ 次操作，远快于 1s。
