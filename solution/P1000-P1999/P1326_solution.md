# P1326 足球

> 标签：数学 / 计分还原 · 难度：普及/提高- · 福建省历届夏令营

## 1. 重新读题

**问题重述（大白话）**

你踢 $N$ 场比赛。第 $i$ 场你进 $a_i$ 球、失 $b_i$ 球，$a_i,b_i$ 都是**非负整数**，并且

$$\sum_{i=0}^{N-1}a_i=S,\qquad \sum_{i=0}^{N-1}b_i=T$$

（下面统一 $0$-based 编号：$i=0\dots N-1$）。计分就是中超规则：

$$a_i>b_i\ (\text{胜})\Rightarrow 3\ \text{分},\qquad a_i=b_i\ (\text{平})\Rightarrow 1\ \text{分},\qquad a_i<b_i\ (\text{负})\Rightarrow 0\ \text{分}.$$

现在 $S,T,N$ 给定，但**每场的比分没给**。问：在所有合法的比分分配方案里，总积分**最大**可能是多少、**最小**可能是多少。

**必须钉死的四条口径（不看清就会套错题模板）**

1. **不是"积分榜可行性"问题**。这里只有你这一支球队，第 $i$ 场只关心你自身的 $(a_i,b_i)$；不同场次之间**没有互相约束**（不需要"对手的积分/净胜球也自洽"）。所以本题**不输出 Yes/No**，也**不做构造、不做计数**。
2. **"单循环/双循环"在本题不出现**：题面说的"$N$ 轮比赛"就是"你一共踢 $N$ 场"，一轮对应一场，没有"每队 $2(N-1)$ 场"之类的赛程结构，也不需要保证对手侧的比分自洽（第 $i$ 场你进 $a_i$ 失 $b_i$，只要求 $a_i,b_i\ge0$ 为整数）。全文按 $N$ 场处理，编号 $i=0\dots N-1$。
3. **输出是两个整数：先最大得分，后最小得分**，每行一组。
4. **可行性恒成立**：任意 $S,T,N$（$N\ge1$，$S,T\ge0$）都能构造出至少一种分配（例如一场 $(S,0)$ 吃掉所有进球、另一场 $(0,T)$ 吃掉所有失球，正式结论见 §2.2 引理 1），所以不存在"无解"分支。

**约束与复杂度暗示**

| 量 | 范围 |
|---|---|
| $S$（总进球） | $0\le S\le 10^9$ |
| $T$（总失球） | $0\le T\le 10^9$ |
| $N$（场数） | $1\le N\le 10^9$ |
| 组数 | 每个测试点 $\le 3\times 10^4$ 组，**EOF 结束，没给组数** |

三个量都是 $10^9$，组数 $3\times10^4$：任何"按场次 DP""按球数 DP""网络流还原比分"都直接死，只能是 **每组 $O(1)$ 的闭合公式**。这正是"数学"标签的意思：把 $\max/\min$ 化成几个 $\min$ 的表达式。

另一个硬性暗示：**答案会爆 `int`**。最大得分可达 $3N=3\times10^9>2^{31}-1$，所以 $S,T,N$ 与所有中间量、输出量都必须用 `long long`。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制：每场只由"符号"决定，资源才是矛盾所在

第 $i$ 场得分只依赖 $a_i-b_i$ 的**符号**，不依赖大小。于是先分类计数：设

$$w=\#\{\text{胜}\},\quad d=\#\{\text{平}\},\quad l=\#\{\text{负}\},\qquad w+d+l=N,$$

总积分

$$P=3w+d=3w+(N-w-l)=N+2w-l. \tag{$\star$}$$

$(\star)$ 说明两件事：**只有 $(w,l)$ 重要（$d$ 由 $N-w-l$ 决定）**，以及**胜场和败场的"单价"不一样**——固定 $N$ 时，把一场平局改成胜局赚 $2$ 分（$3-1$），改成负局只亏 $1$ 分（$0-1$）。即 $w$ 的权重是 $l$ 的两倍，这个不对称性后面直接决定最大/最小值的形状。

但 $w,l$ 不能随便取，因为进球和失球是**两种独立的资源**：$S$ 个进球、$T$ 个失球必须全部"分配掉"。逐类看每类场次的**最低资源消耗**：

- 胜场：$a_i\ge b_i+1\ge1$ → 至少要**吃掉 1 个进球**；失球 $b_i$ 可以任意大，但每多 1 个 $b_i$ 就得配套更多 $a_i$。
- 平场：$a_i=b_i$ → 进球必须**成对**消耗（1 进 1 失），特别地 $(0,0)$ 是**零成本**的平场，还白送 1 分。
- 负场：$b_i\ge a_i+1\ge1$ → 至少要**吃掉 1 个失球**；$a_i$ 可以任意大但要配套失球。

**关键观察（多余的球往哪儿塞）**：想让某一场的比分同时变大而**不改变符号**，只有"两边同时加 $k$"这一种做法（平场就是这样）；想**单方面**塞进球，只能塞进胜场的 $a_i$；想**单方面**塞失球，只能塞进负场的 $b_i$。这就是全部的门道：$S$ 的"溢出"必须由胜场吸收，$T$ 的"溢出"必须由负场吸收，平场只能等量吸收。

### 2.2 化简：把"是否存在比分分配"压成关于 $(w,l)$ 的判据

有了上面的资源视角，自然要问：**给定 $(w,l)$，什么时候真的存在一组非负整数比分？** 这就是主引理。

**引理 1（可行性四分类）** 设 $w,d,l\ge0$，$w+d+l=N$。存在非负整数 $\{(a_i,b_i)\}$ 使 $\sum a_i=S,\ \sum b_i=T$ 且恰有 $w$ 胜 $d$ 平 $l$ 负，当且仅当下列四条之一成立：

| 情形 | 条件 |
|---|---|
| (I) $w\ge1$ 且 $l\ge1$ | $S\ge w$ 且 $T\ge l$ |
| (II) $w\ge1,\ l=0$ | $S-T\ge w$ |
| (III) $w=0,\ l\ge1$ | $T-S\ge l$ |
| (IV) $w=l=0$ | $S=T$ |

**证明。**

*必要性*：

- (I)：胜场 $a_i>b_i\ge0\Rightarrow a_i\ge1$，故 $S\ge\sum_{\text{胜}}a_i\ge w$；负场 $b_i>a_i\ge0\Rightarrow b_i\ge1$，故 $T\ge\sum_{\text{负}}b_i\ge l$。
- (II)：胜场 $a_i-b_i\ge1$，平场 $a_i-b_i=0$，求和 $S-T=\sum(a_i-b_i)\ge w$。
- (III)：与 (II) 对称（把 $a,b$ 互换即把胜负互换）：$T-S=\sum_{\text{负}}(b_i-a_i)\ge l$。
- (IV)：全部 $a_i=b_i$，求和得 $S=T$。

*充分性（逐情形给出显式比分）*：把场次按类型排好，按下表赋值即可，其余未列出的场次一律取 $(0,0)$（平场，合法）。

- (I)：胜场 $0$ 取 $(S-w+1,\,0)$，胜场 $1\dots w-1$ 取 $(1,0)$；负场 $0$ 取 $(0,\,T-l+1)$，负场 $1\dots l-1$ 取 $(0,1)$。
  校验：$\sum a=(S-w+1)+(w-1)=S$，$\sum b=(T-l+1)+(l-1)=T$。胜场 $0$ 需 $S-w+1>0$，由 $S\ge w$ 得 $S-w+1\ge1>0$ ✓；负场 $0$ 需 $T-l+1>0$，由 $T\ge l$ ✓。因为 $w\ge1,l\ge1$，这两场都存在 ✓。
- (II)：胜场 $0$ 取 $(S-w+1,\,T)$，胜场 $1\dots w-1$ 取 $(1,0)$。
  $\sum a=S,\ \sum b=T$ ✓。要 $S-w+1>T$：由 $S-T\ge w$ 得 $S-w\ge T$，故 $S-w+1\ge T+1>T$ ✓；且 $S-w+1\ge T+1\ge1$ ✓。（注意这里**把全部失球压进同一个胜场**，所以不需要平场存在，$d=0$ 也对。）
- (III)：对称地，负场 $0$ 取 $(S,\,T-l+1)$，负场 $1\dots l-1$ 取 $(0,1)$；需 $T-l+1>S$，由 $T-S\ge l$ 得 $T-l\ge S$，故 $T-l+1\ge S+1>S$ ✓。
- (IV)：平场 $0$ 取 $(S,S)$，其余 $(0,0)$；条件 $S=T$ 保证 $\sum b=T$ ✓。$\blacksquare$

> 引理 1 的价值：它证明了"想有多少胜场就能有多少"，唯一的天花板是 $S\ge w$（胜场要球）与 $T\ge l$（负场要失球），而且**只要胜、负两类场次同时存在**就再没有别的限制；一旦某类场次为 $0$，就多出"$S-T\ge w$"这种全局净胜球条件。

### 2.3 最大化：败场只需 0 或 1 场

最大化 $P=N+2w-l$。按 $l$ 分族：

- **$l=0$ 族**（不含负场，用 (II)/(IV)）：$w\le\min(N,S-T)$ 且要求 $S\ge T$（$S=T$ 时 $w=0$ 由 (IV) 给出 $P=N$）。$P$ 随 $w$ 增，取最大 $w$：
  $$A=N+2\min(N,\ S-T),\qquad(\text{当 }S\ge T,\ \text{否则该族不可行}).$$
  可达性即引理 1 (II) 的构造（把 $T$ 全压进一个胜场）。
- **$l\ge1$ 族**：$w\le\min(N-l,S)$（且 $w\ge1$，(I) 要求 $T\ge l$），故
  $$P\le g(l):=N-l+2\min(N-l,S).$$
  $N-l$ 与 $\min(N-l,S)$ 都关于 $l$ **不增**，故 $g(l)\le g(1)$：败场开到 2 场、3 场绝不会比 1 场更好——因为一场负场就能把**全部** $T$ 失球吃掉（$(0,T)$），多开败场只是白扔场次。于是
  $$B=N-1+2\min(N-1,\ S),\qquad(\text{当 }T\ge1).$$
  （$T\ge1$ 是 (I) 中 $l=1\le T$ 的要求。若 $S=0$ 则 $\min(N-1,S)=0$，$B=N-1$，对应 (III) 里 $w=0,l=1,d=N-1$ 的构造，值一致。）

综合：任何方案 $P\le\max(A,B)$，而 $A,B$ 各自可达，故 $P_{max}=\max(A,B)$。两族至少一个可行（$T=0\Rightarrow S\ge T$ 用 $A$；$T\ge1$ 用 $B$）。

### 2.4 最小化：胜场只需 0 或 1 场

现在要**压低** $P=N+2w-l$。直觉是"尽量多输"，但两件事互相拉扯：$l$ 的上限被失球卡住（每场负至少吃 1 个失球，$l\le T$），而**任何一场胜局值 2 分权重**，比一场负局的 1 分更贵，所以最优必然贴着 $w$ 的下界。严格说法见下面分族：$w\ge1$ 的**全部**情形被同一个下界 $C$ 卡住、且 $C$ 在 $w=1$ 处取到，因此 $w\ge2$ 根本不用考虑（"把两场胜改成两场负"确实能降分，但要用掉 $T$ 的额度，是否划算由 $C$ 的推导一次说清，不必做交换论证）。下面用引理 1 严格分族。

- **$w=0$ 族**（(III)/(IV)）：$P=N-l$，$l\le\min(N,T-S)$，要求 $T\ge S$。取最大 $l$：
  $$D=N-\min(N,\ T-S),\qquad(\text{当 }T\ge S).$$
  直观读法：$(0,0)$ 平场免费，所以先用"一场败吃掉 $T-S$ 的净失球差额"，剩下的场次全是免费平场。
- **$w\ge1$ 族**：
  - 若 $l=0$（(II)）：$P=N+2w\ge N+2$（此时 $S>T$ 才有解）。
  - 若 $l\ge1$（(I)）：$w\ge1$、$l\le\min(N-w,T)\le\min(N-1,T)$，故 $P=N+2w-l\ge N+2-\min(N-1,T)$。

  两类下界的最小值就是
  $$C=N+2-\min(N-1,\ T),\qquad(\text{当 }S\ge1),$$
  取 $w=1$、$l=\min(N-1,T)$。$T=0$ 时 $\min(N-1,T)=0$，$C=N+2$ 正好落回 $l=0$ 情形（一场胜吃掉全部 $S$ 个进球，其余 $(0,0)$ 平），公式统一，无需分支。可达性由 (I)（$T\ge1$）或 (II)（$T=0$）的构造直接给出。

综合：$P_{min}=\min(C\,[S\ge1],\ D\,[T\ge S])$；$S=0$ 时 $T\ge S$ 必成立，故 $D$ 总在。

### 2.5 四个候选的可达性（把上界/下界变成"等号成立"）

上面只证明了 $P_{max}\le\max(A,B)$、$P_{min}\ge\min(C,D)$；要成为答案，还必须给出**恰好取到该值**的比分表（否则只是松弛）。逐个核对守卫条件与引理 1 的分支：

| 候选 | 守卫 | 取的 $(w,l,d)$ | 用引理 1 的哪条 | 校验（为什么守卫就够了） |
|---|---|---|---|---|
| $A=N+2\min(N,S-T)$ | $S\ge T$ | $w=\min(N,S-T),\ l=0,\ d=N-w$ | $w\ge1$ 用 (II)；$w=0$ 用 (IV) | (II) 要 $S-T\ge w$：$w\le S-T$ ✓。$w=0$ 意味着 $\min(N,S-T)=0$，即 $S=T$（因守卫 $S\ge T$），(IV) 要求 $S=T$ ✓，$P=N$ ✓ |
| $B=N-1+2\min(N-1,S)$ | $T\ge1$ | $w=\min(N-1,S),\ l=1,\ d=N-1-w$ | $w\ge1$ 用 (I)；$w=0$ 用 (III) | (I) 要 $S\ge w,\ T\ge l=1$ ✓，$w+l\le N$ ✓。$w=0$ 即 $S=0$，$B=N-1$，(III) 要 $T-S=T\ge l=1$ ✓（守卫给了 $T\ge1$） |
| $C=N+2-\min(N-1,T)$ | $S\ge1$ | $w=1,\ l=\min(N-1,T),\ d=N-1-l$ | $l\ge1$ 用 (I)；$l=0$ 用 (II) | (I) 要 $S\ge w=1$ ✓（守卫）、$T\ge l$ ✓（因 $l\le T$）。$l=0$ 即 $T=0$，$C=N+2$，(II) 要 $S-T=S\ge1=w$ ✓ |
| $D=N-\min(N,T-S)$ | $T\ge S$ | $l=\min(N,T-S),\ w=0,\ d=N-l$ | $l\ge1$ 用 (III)；$l=0$ 用 (IV) | (III) 要 $T-S\ge l$ ✓（因 $l\le T-S$）。$l=0$ 即 $T=S$（守卫下），(IV) 要 $S=T$ ✓，$P=N$ ✓ |

四行都成立 ⇒ $P_{max}=\max(A,B)$ 与 $P_{min}=\min(C,D)$ 是**紧的**（不只是界），并且每格右列顺带证明了"守卫条件至少有一个成立"：$T=0$ 时 $S\ge T$ 使 $A$ 可用、$T\ge1$ 时 $B$ 可用；$S=0$ 时 $T\ge S$ 使 $D$ 可用、$S\ge1$ 时 $C$ 可用。所以代码里 `res` 一定会被更新，不会返回哨兵。

### 2.6 三个"看起来很对"的错思路（手算反例）

1. **"先尽量胜，剩下的场次全记平局"**：即认为 $w=\min(N,S)$，$P_{max}=3w+(N-w)$。取 $N=2,S=1,T=1$：它给 $P=3\cdot1+1=4$。但两场要同时满足 $\sum a=1,\sum b=1$：若一场是 $(1,0)$ 胜，剩下一场只能 $(0,1)$ 负（不是平局），真实 $P_{max}=3$（§4.4 表已穷举）。**错在把失球当成了免费资源**——$(0,0)$ 平场吞不下失球。
2. **"答案只取决于净胜球 $S-T$"**：取 $N=2$，$(S,T)=(1,0)$ 与 $(2,1)$，净胜球都是 $1$。前者 $P_{min}=4$（只能 $(1,0)+(0,0)$），后者 $P_{min}=3$（$(2,0)+(0,1)$）。**同一个 $S-T$ 给出不同答案**，所以 $T$ 必须单独出现在公式里（这正是 $B,C$ 两族用 $\min(\cdot,S)$、$\min(\cdot,T)$ 而不是 $\min(\cdot,S-T)$ 的原因）。
3. **"最大最小互补：$P_{max}+P_{min}=3N$"**：$N=2,S=1,T=1$ 给 $3+2=5\ne 6$。把 $a,b$ 互换（$S\leftrightarrow T$）确实把"胜"变"负"，但得分函数 $3w+d$ 在换像下变成 $3l+d$，而 $3l+d$ 与 $3N-(3w+d)=2d+3l$ 不相等 ⇒ **对偶并不成立**，所以最小值必须独立推导（§2.4），不能由最大值取补。

### 2.7 类型与实现细节

$3N\le 3\times10^9$、$S,T\le10^9$：全部用 `i64`。哨兵用 $\pm1145141919810$（114514 家族，$>3\times10^9$ 且远小于 $9.22\times10^{18}$），避免"用 $0$ 初始化最大值"时把不可行族当成 $0$ 分的坑（例如 $P_{max}$ 的真实值可以为 $0$）。EOF 驱动 `while(cin>>S>>T>>N)`。

## 3. 模式总结（Pattern Summary，按实际思考顺序）

- **explore its property** — 得分只看 $a_i-b_i$ 的符号，于是 $P=N+2w-l$，$w,l$ 才是真变量（$d$ 被 $N-w-l$ 吸收）。
- **translate resource into constraints** — 胜场至少吃 1 进球、负场至少吃 1 失球、平场只能等量吃球且 $(0,0)$ 免费；多余进球只能进胜场、多余失球只能进负场。
- **classic problem solution（可行性判定 → 显式构造）** — 对 $(w,l)$ 四分类给出充要条件与构造（引理 1），把"是否存在比分"彻底闭合。
- **reduce to easier problem** — 原问题降维成"在引理 1 的可行域上最大化/最小化线性式 $N+2w-l$"。
- **consider extreme / boundary value（最大化）** — 一场负场就能吞掉全部失球 ⇒ 败场数只需考虑 $l\in\{0,1\}$，$g(l)$ 单调不增给出证明。
- **consider extreme / boundary value（最小化）** — $l$ 的上界被 $T$ 卡住、$w$ 的权重更大 ⇒ 最优点贴 $w$ 的下界，只需试 $w\in\{0,1\}$；分族后 $w\ge1$ 全体共享同一下界 $C$，故 $w\ge2$ 无需考虑。
- **prove tightness (constructive)** — 上界/下界只是松弛，必须为 $A,B,C,D$ 各写出一张"恰好取到"的比分表（§2.5），顺带证明守卫条件至少命中一个（否则代码会返回哨兵）。
- **refute plausible wrong turns by hand** — 用 $N=2,S=T=1$ 打掉"剩下的场全记平局"，用 $(1,0)$ vs $(2,1)$ 打掉"只看净胜球"，用 $3+2\ne6$ 打掉"最大最小互补"（§2.6）。
- **merge formulas by construction** — $T=0$、$S=0$、$S=T$ 等退化情形用构造式统一进同一个 $\min$ 表达式，避免写分支。
- **careful about integer range** — $3N=3\times10^9$ 爆 `int`，全程 `i64`；不可行族用 $\pm1145141919810$ 哨兵而不是 $0$。

## 4. 真实解法（Real Solution）

### 4.1 符号表（Notation Glossary）

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `S` | 总进球 $\sum a_i$ | `i64`，输入第 1 个 | $0\le S\le10^9$ |
| `T` | 总失球 $\sum b_i$ | `i64`，输入第 2 个 | $0\le T\le10^9$ |
| `N` | 比赛场数 | `i64`，输入第 3 个 | $1\le N\le10^9$，$w+d+l=N$ |
| `A` | "$l=0$（无败场）"族的最优分 $N+2\min(N,S-T)$ | `i64`，仅当 $S\ge T$ 有效 | 失球全压进一个胜场，故只受净胜球 $S-T$ 限制 |
| `B` | "$l=1$（恰一场败吞掉全部失球）"族的最优分 $N-1+2\min(N-1,S)$ | `i64`，仅当 $T\ge1$ 有效 | 胜场数上限是 $\min(N-1,S)$ |
| `C` | "$w=1$（只留一场胜）"族的最优分 $N+2-\min(N-1,T)$ | `i64`，仅当 $S\ge1$ 有效 | 败场越多越好，上限 $\min(N-1,T)$ |
| `D` | "$w=0$（无胜场）"族的最优分 $N-\min(N,T-S)$ | `i64`，仅当 $T\ge S$ 有效 | 只有免费平场 $(0,0)$ 与败场 |
| `res` | 当前族的最值 | 初始化为 $\mp1145141919810$ | $-$ 号配 $\max$，$+$ 号配 $\min$ |

**没有数组、没有状态表**：本题是纯闭合公式，$O(1)$/组。$0$-based 只出现在推导里（$i=0\dots N-1$），代码里根本没有场次下标。

### 4.2 算法步骤（Numbered Steps）

1. **循环读入**直到 EOF：`while(cin>>S>>T>>N)`。
2. **算最大值**（`calcmax`）：$res=-1145141919810$；若 $S\ge T$ 则用 $A=N+2\min(N,S-T)$ 更新 $\max$；若 $T\ge1$ 则用 $B=N-1+2\min(N-1,S)$ 更新 $\max$。
3. **算最小值**（`calcmin`）：$res=1145141919810$；若 $T\ge S$ 则用 $D=N-\min(N,T-S)$ 更新 $\min$；若 $S\ge1$ 则用 $C=N+2-\min(N-1,T)$ 更新 $\min$。
4. **输出** `最大 最小`，用 `'\n'` 换行。顺序**先 max 后 min**（题面口径）。

**复杂度**：每组时间 $O(1)$（若干次 $\min/\max$ 与算术），空间 $O(1)$；总计 $O(Q)$，$Q\le3\times10^4$。

**(3) 大数/溢出边界（纯手算）**

- $S=T=N=10^9$：max $=\max(A=10^9+0,\ B=10^9-1+2(10^9-1)=3\cdot10^9-3)=2999999997$；配置 $(1,0)^{\times(10^9-2)}+(2,0)+(0,10^9)$：进球 $(10^9-2)+2=10^9$ ✓，失球 $10^9$ ✓，得分 $3(10^9-1)=2999999997$ ✓。**必须 `long long`**。
- 同组 min $=\min(C=10^9+2-\min(10^9-1,10^9)=3,\ D=10^9)=3$；配置 $(10^9,0)$ 一胜 + $10^9-1$ 场负分担 $T=10^9$：$(0,2)+(0,1)^{\times(10^9-2)}$，失球 $2+10^9-2=10^9$ ✓，得分 $3$ ✓。
- $S=0,T=0,N=10^9$：max $=A=10^9$，min $=D=10^9$，唯一比分全 $0$-$0$ ✓。

**(4) 结构性自检（不需要程序的三条）**

1. **区间界**：$P_{min}\le P_{max}$ 在 §4.4(1) 的 16 行里逐格成立；且由公式直接可读 $N-1\le P_{max}\le 3N$（$T=0$ 时 $A\ge N$，$T\ge1$ 时 $B\ge N-1$）、$0\le P_{min}\le N+2$（$D\le N$、$C\le N+2$）——$N=2$ 的手算表里 max 取到 $\{1,2,3,4,6\}$、min 取到 $\{0,1,2,3,4\}$，全部落在 $[N-1,3N]=[1,6]$ 与 $[0,N+2]=[0,4]$ 内 ✓。
2. **改变 $N$ 的一致性自检**：把一套 $N$ 场方案追加一场 $(0,0)$ 平局，就得到一套 $N+1$ 场方案、分值恰好 $+1$，于是必然有 $P_{max}(N+1)\ge P_{max}(N)+1$（最大值不差于这个具体方案）与 $P_{min}(N+1)\le P_{min}(N)+1$（最小值不大于它）。再用闭式核对"两者关于 $N$ 单调不降"：$C=N+2-\min(N-1,T)$ 在 $T\le N-1$ 时随 $N$ 增 $1$、在 $T\ge N$ 时恒为 $3$；$D=N-\min(N,T-S)$ 在 $T-S<N$ 时随 $N$ 增 $1$、在 $T-S\ge N$ 时恒为 $0$；$A,B$ 中 $N$ 与 $\min(N,\cdot)$ 同向变化 ⇒ 不降 ✓。手算两组：$S=1,T=0$ 时 min 对 $N=1,2,3$ 为 $3,4,5$（$=N+2$，取等，且此时 max 与之相等：$(1,0)+(0,0)^{N-1}$）；$S=0,T=5$ 时 min 对 $N=1..6$ 为 $0,0,0,0,0,1$（$=N-\min(N,5)$）——"只能输球"的极端下多出来的空场确实不再白送 1 分，正好卡在 $P_{min}(N+1)\le P_{min}(N)+1$ 这一侧 ✓。
3. **$S\leftrightarrow T$ 只对"胜/负场数"对偶，不对"得分"对偶**：把 $(S,T)$ 换成 $(T,S)$ 并把每场 $(a_i,b_i)$ 换成 $(b_i,a_i)$，合法方案一一对应且胜↔负、平↔平，故恒有 $w_{max}(S,T,N)=l_{max}(T,S,N)$。手算核对：$N=2,S=3,T=0$ 时 $w_{max}=2$（$(2,0)+(1,0)$），而 $N=2,S=0,T=3$ 时 $l_{max}=2$（$(0,2)+(0,1)$）✓。但得分是 $N+2w-l$，互换后变成 $N+2l-w$，**不是互补关系**，所以 $P_{min}$ 不能用 $3N-P_{max}$ 推出来，必须像 §2.4 那样独立分族。数字上也看得出不对称：$N=2,S=3,T=0$ 的 $P_{max}=6$，$N=2,S=0,T=3$ 的 $P_{max}=1$ —— 进球能造 3 分胜场，失球只能造 0 分负场。

**验证结论**：$N=1$ 解析全对、$N=2$ 的 $4\times4=16$ 格穷举逐格吻合、$N=3$ 五组抽查（含"两候选翻盘"与 $S=0/T=0$ 边界）一致、$10^9$ 边界手算无溢出、三条结构性自检通过。**未发现反例**。但要如实说明：以上全是手算与证明，**没有运行程序、没有随机对拍**，故信心来自引理 1 的充要性证明而非实验；若判题仍有出入，最可能的位置是输出顺序（先 max 后 min）与题面口径（例如把 $N$ 理解成"轮数/对手数"从而要求跨场自洽），而非公式本身。

## 5. 示例代码（C++）

```cpp
// P1326 足球
// P = 3w+d = N+2w-l；max = max(l=0 族 A, l=1 族 B)，min = min(w=0 族 D, w=1 族 C)
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 S,T,N;

i64 calcmax()
{
	i64 res=-1145141919810;   //不可行族必须给 -inf，真实答案可以是 0
	if(S>=T)                  //l=0：无败场，多余失球全压进同一个胜场，只受净胜球限制
		res=max(res,N+2*min(N,S-T));
	if(T>=1)                  //l=1：一场 (0,T) 吃掉全部失球，其余场次尽量胜（上限 min(N-1,S)）
		res=max(res,N-1+2*min(N-1,S));
	return res;
}

i64 calcmin()
{
	i64 res=1145141919810;
	if(T>=S)                  //w=0：(0,0) 平场零成本，败场数上限 min(N,T-S)
		res=min(res,N-min(N,T-S));
	if(S>=1)                  //w=1：只留一场胜，败场数上限 min(N-1,T)；T=0 时退化为 N+2
		res=min(res,N+2-min(N-1,T));
	return res;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	while(cin>>S>>T>>N)       //多组数据，EOF 结束，无组数
		cout<<calcmax()<<' '<<calcmin()<<'\n';
	return 0;
}
```

### 代码说明

- **`bits/stdc++.h` + `using namespace std;` + `using i64=long long;`**，无其它头文件、无 `#define int long long`（用别名式，符合新代码约定）。
- **`min/max` 全部作用在 `i64` 上**：`N-1`、`S-T` 等都是 `i64`，不会先按 `int` 截断。
- **函数名小写电报式**（`calcmax`/`calcmin`），读全局 `S,T,N`，无参数。
- **运算符两侧不加空格、Tab 缩进、`'\n'` 换行、`ios` 三件套顺序固定、`return 0;` 收尾**，符合风格规范；注释只标不变量（哪个族对应哪个构造）与坑点（$-\infty$ 哨兵、$T=0$ 退化）。
- **没有 `constexpr int mxn{...}`、没有全局数组**：本题 $O(1)$/组，状态只有三个标量 $S,T,N$，按"$mxn$ 按需"的规定不硬造数组；需要哨兵的是标量 `res`，已按 $\pm1145141919810$ 显式赋初值（若将来改成"多组先读入再离线"，才需要开 `i64 Ans[mxn]` 并注意全局 `i64` 默认 0 不能当"未计算"标记，得 `fill_n(Ans,q,1145141919810)`）。
- **代码只存在于本 md 中**：按用户要求，本次没有在工作区创建 `.cpp`、`gen.cpp`、`*.in` 等任何文件，也没有编译或运行。
- **`S-T`/`T-S` 的写法**：因为有 `if(S>=T)` / `if(T>=S)` 的外层守卫，差值必非负，不需要 `abs`，也不会有负数除法/取模之类的隐患。
