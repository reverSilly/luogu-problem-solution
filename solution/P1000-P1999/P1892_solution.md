# P1892 [BalticOI 2003] 团伙 (Day 2)

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 个人，给出 $m$ 条关系，每条是「$p$ 和 $q$ 是朋友」或「$p$ 和 $q$ 是敌人」。已知两条规则：

- 朋友的朋友是朋友；
- 敌人的敌人是朋友。

要把人划分成若干个团体，朋友必须在同一个团体，每个人只属于一个团体。求**最多**可能的团体数。没有直接关系的人之间不作任何额外限制。

### 1.2 关键约束与规模暗示

- $n\le 1000$，$m\le 5000$。这个规模允许 $O(n^2)$ 甚至 $O(n^2\log n)$ 的做法，也允许对每个人保留一份「敌人列表」。
- 答案要求「最多」，说明凡是规则**没有强制**合并的两个人，都应该分到不同团体。
- 输入可能有重边、孤立点；这些都不影响算法。
- 关键难点只有一处：如何准确表达「敌人的敌人是朋友」这条非等价关系。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先只看朋友：一个并查集

如果没有敌人关系，问题就是「朋友关系把 $n$ 个人分成几个连通块」，答案是连通块个数。朋友关系天然是等价关系（自反、对称、传递），用一个并查集即可。

敌人的存在打破了这个简单图景：敌人之间必须分开，而「敌人的敌人」又要合并。注意「敌人」本身不是等价关系，不能直接把它也塞进另一个并查集。

### 2.2 探索性质：同一个人所有敌人两两是朋友

把 $p$ 的所有已知敌人记为集合 $E(p)$。取 $u,v\in E(p)$，即 $u$ 是 $p$ 的敌人、$v$ 是 $p$ 的敌人。由「敌人的敌人是朋友」，$u$ 与 $v$ 是朋友。

**引理 1.** 对任意人 $p$，$E(p)$ 中任意两人都被强制为朋友，即 $E(p)$ 在「朋友闭包」下是一个团（完全图）。

**证明.** 任取 $u,v\in E(p)$。关系「$u$ 是 $p$ 的敌人」与「$v$ 是 $p$ 的敌人」说明 $p$ 同时是 $u$ 和 $v$ 的敌人。把规则「敌人的敌人是朋友」作用在 $p$ 上：$u$ 的敌人 $p$，$p$ 的敌人 $v$，故 $u,v$ 是朋友。$\blacksquare$

这条引理是整道题的钥匙：**我们不需要记录「$p$ 的每个敌人和谁是什么关系」，只需要把所有敌人并到同一个集合里**。于是一个人 $p$ 的所有敌人可以共用一个「敌人槽位」。

### 2.3 自然的建模：$2n$ 个结点的并查集

开 $2n$ 个结点：

- $0,1,\dots,n-1$：第 $i$ 个结点代表人 $i$；
- $n,1+n,\dots,2n-1$：第 $i+n$ 个结点表示「$i$ 的敌人集合」这个槽位（不是某个人）。

处理关系：

- `F p q`：朋友，直接 `union(p,q)`；
- `E p q`：敌人。$p$ 是 $q$ 的敌人，把 $p$ 并入 $q$ 的敌人槽位：`union(p,q+n)`；对称地 `union(q,p+n)`。

为什么这样能表达「敌人的敌人是朋友」？因为 $q$ 的所有敌人（包括 $p$ 和之前出现过的敌人）都被并进了同一个槽位 $q+n$，于是它们两两处于同一集合，即被当作朋友。这正好是引理 1。

### 2.4 引理 2（并查集语义的正确性）

为了严格说明，先定义一个关系：令 $\equiv$ 是满足下面两条的**最小等价关系**：

1. 对每条朋友关系 $(p,q)$，有 $p\equiv q$；
2. 对每个人 $x$，$E(x)$ 中所有人在 $\equiv$ 下两两等价（即 $E(x)$ 是一个团）。

这个 $\equiv$ 就是题目规则所强制的全部「朋友」关系（再取传递闭包）。下面的引理说明并查集恰好算出它。

**引理 2.** 处理完所有关系后，对人 $i,j$，$i$ 与 $j$ 在并查集中同属一个连通块，当且仅当 $i\equiv j$。

**证明.** 记第 $x+n$ 号结点的连通块为 $C_x$。

先证**可靠性**（同块 $\Rightarrow$ 朋友）：对并查集的合并次数归纳，证明不变式：

> (a) 若两人 $u,v$ 在同一连通块，则 $u\equiv v$；
> (b) 对每个人 $x$，$E(x)$ 中所有人都与结点 $x+n$ 在同一连通块。

- 初始时没有边，每个人自成一个连通块，块内只有一个人，故 (a) 成立；又 $E(x)=\varnothing$，(b) 作为全称命题在空集上为真。
- 处理 `F p q` 时，把 $p$ 的块与 $q$ 的块合并。由归纳假设，两个块内的人各自两两 $\equiv$；而新关系给出 $p\equiv q$，由 $\equiv$ 的传递性，合并后块内任意两人仍 $\equiv$。不变式 (a) 保持；(b) 不受影响。
- 处理 `E p q` 时，先 `union(p,q+n)`。由不变式 (b)，$E(q)$ 中所有人都在 $q+n$ 所在块内，因而两两 $\equiv$；由新关系 $p\in E(q)$ 以及引理 1，$p$ 与 $E(q)$ 中每个人 $\equiv$。所以把 $p$ 并入该块后，块内任意两人仍 $\equiv$，不变式 (a) 保持；同时新关系使 (b) 在 $q$ 处继续成立。另一条 `union(q,p+n)` 完全对称。
- 归纳完成。

再证**完备性**（朋友 $\Rightarrow$ 同块）：$\equiv$ 由两类生成元产生：朋友边、以及每个 $E(x)$ 的团边。

- 朋友边直接由 `union(p,q)` 实现；
- 对每个 $x$ 和任意 $u,v\in E(x)$：处理 `E u x` 时执行了 `union(u,x+n)`，处理 `E v x` 时执行了 `union(v,x+n)`，所以 $u,v$ 都与 $x+n$ 同块，从而 $u,v$ 同块。

因此所有生成元的两端点都在同一块中；并查集的「同块」关系是传递的（它是等价关系），故它包含 $\equiv$ 的传递闭包，即 $i\equiv j\Rightarrow$ 同块。

两个方向合起来即为所求。$\blacksquare$

### 2.5 为什么答案是「连通块个数」

**引理 3.** 最大团体数等于 $\equiv$ 的等价类个数。

**证明.**

- 任一团体必须是等价类的并：若两人在同一等价类，则由 $\equiv$ 的定义（题设规则的传递闭包）他们是朋友，必须在同一团体。
- 反过来，把每个等价类单独作为一个团体是合法的：类内都是朋友；不同类之间即使有敌人关系，也分在不同团体里，不违反「敌人要分开」；而题目的规则没有强制两个不同类合并（否则它们在 $\equiv$ 下就同类了）。
- 于是团体数 $\le$ 等价类个数，且可以取等。

$\blacksquare$

> 若数据自相矛盾（例如某个类里同时含有互为敌人的两人），则「每类一个团体」会把敌人放进同一团体。这种输入不满足题设关系的可满足性；在合法的测试数据中不会出现。即使出现，并查集仍给出唯一自然的划分。

### 2.6 实现上的一个真实坑：根结点可能落在「敌人槽位」

如果只统计「`find(i)==i` 的人数」，会出错。反例：$n=2$，只有一条 `E 1 2`。

- `union(0,3)` 使 `f[0]=3`；
- `union(1,2)` 使 `f[1]=2`。

此时 `find(0)=3`、`find(1)=2`，没有一个 $i$ 的根是自己，直接数自根会得到 $0$，而正确答案是 $2$（两人互为敌人，各成一团）。

正确做法是：对 $i=0\dots n-1$ 求 `find(i)`，用一个 `vis` 数组统计**不同根值的个数**。根的编号最大到 $2n-1$，所以 `vis` 开到 $2n$。

### 2.7 失败尝试记录

1. **只用朋友并查集**：忽略「敌人的敌人是朋友」，样例式的关系会少合并。
2. **把敌人也当作等价关系直接 `union(p,q)`**：会把必须分开的两人强行放进同一团，答案偏小。
3. **只保留一个敌人 `e[p]` 但忘记把新敌人与旧敌人合并**：会漏掉引理 1 的团合并。
4. **统计自根**：如上所述，根可能落在槽位，答案偏小。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 同一个人所有敌人两两是朋友（敌人的敌人是朋友）。
- **reduce to easier problem** — 用一个「敌人槽位」代替整张敌人关系图。
- **classic problem solution** — 开 $2n$ 个结点的并查集：朋友直接并，敌人交叉并到对方槽位。
- **prove invariant** — 归纳证明「同块 $\Rightarrow$ 朋友」与「敌人集合 $\Rightarrow$ 同槽位」。
- **count carefully** — 根可能在槽位上，必须统计不同的 `find` 值而不是自根。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 人数 | 读入 | |
| `m` | `int` | 关系条数 | 读入 | |
| `f[x]` | `int [2010]` | 并查集父指针，共 $2n$ 个结点 | `f[x]=x` | father |
| `vis[x]` | `bool [2010]` | 某个根是否已被统计 | `false` | visited |
| `op` | `char` | `F` 或 `E` | 读入 | operation |
| `p,q` | `int` | 关系两端（内部转为 $0$-based） | 读入后 `--` | |
| `ans` | `int` | 不同连通块数 | $0$ | answer |

### 4.2 算法步骤

1. 读入 $n,m$，初始化 `f[i]=i`，范围 $0\le i<2n$。
2. 逐条处理关系，读入时把人编号转为 $0$-based：
   - 若 `op=='F'`：`uni(p,q)`；
   - 若 `op=='E'`：`uni(p,q+n)` 与 `uni(q,p+n)`。
3. 对每个人 $i\in[0,n)$，求 $r=\text{getrt}(i)$；若 `vis[r]` 为假，则置真并令 `ans` 加一。
4. 输出 `ans`。

### 4.3 复杂度分析

- **时间**：每条关系 $O(\alpha(2n))$；统计 $O(n\alpha(2n))$。总 $O((n+m)\alpha(n))$。
- **空间**：并查集与访问标记各 $O(n)$。

---

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int f[mxn*2];
bool vis[mxn*2];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

void uni(int a,int b)
{
	int ra=getrt(a),rb=getrt(b);
	if(ra!=rb)
		f[ra]=rb;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m;
	cin>>n>>m;
	for(int i=0;i<2*n;++i)
		f[i]=i;
	for(int i=0;i<m;++i)
	{
		char op;
		int p,q;
		cin>>op>>p>>q;--p;--q;
		if(op=='F')
			uni(p,q);
		else
		{
			uni(p,q+n);
			uni(q,p+n);
		}
	}
	int ans=0;
	for(int i=0;i<n;++i)
	{
		int r=getrt(i);
		if(!vis[r])
		{
			vis[r]=true;
			++ans;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```
