# P1171 售货员的难题 题解

## 一、重述题意（Re-read the problem）

售货员从村庄 $1$ 出发，要恰好经过每个村庄一次，最后返回村庄 $1$。

输入是一张 $n$ 个点的**有向完全图**（$i\to j$ 与 $j\to i$ 的边权一般不同），边权矩阵 $s_{i,j}$ 给出 $i$ 到 $j$ 的单向路程。

求从 $1$ 出发、恰好经过每个点一次、最终回到 $1$ 的最小总路程（即**有向旅行商问题 TSP**）。

- 数据范围：$2\le n\le 20$，$1\le s_{i,j}<10^3$。
- 答案类型：所有边权为正，总路程不超过 $(n+1)\times 10^3 \approx 21000$，用 `int` 足够。

---

## 二、思维过程（Chain-of-thought）

### Step 1：先猜一个朴素算法，看它为什么不行

最朴素的思路是枚举所有排列：第一个点是 $1$ 固定，剩下 $n-1$ 个点的排列数为
$(n-1)!$。当 $n=20$ 时 $(n-1)!\approx 1.2\times 10^{17}$，完全不可行。因此必须放弃"枚举排列"。

### Step 2：提出一般化思想——"用状态记录已经走过哪些点"

排列为什么会爆炸？因为做决策时，我们只知道"当前在哪"。为了能转移下去，我们真正需要的信息只有两条：

1. **当前最后停在了哪个村庄**（用于计算下一步的边权）；
2. **哪些村庄已经访问过了**（确保每个村庄只访问一次，且不重不漏）。

对于第 2 条，20 个村庄只有"去过/没去过"两种状态，正好可以用一个 $n$ 位二进制数 `mask` 表示。所谓**状态压缩**（bitmask DP），就是把"去过哪些点"这个集合压进一个整数里。

这里有一个关键引理：

> **引理（转移最优性引理）**：设两条路径 $A$、$B$ 都从 $1$ 出发，访问的点集完全相同（都是 $M$），且结尾都是同一个点 $u$。那么两者当中总里程更短的那一条，可以在任何后续决策中永远替代另一个，且不影响最优性。

证明（反证法）：假设我们使用了更长的 $B$ 作为子路径，且完整方案 $B+$ 后续路径是全局最优的。把子路径换成更短的 $A$ 之后，访问点集和终点都与原来完全一致，所以后续路径依然合法可行（每个村庄依然恰好访问一次，依然能回到 $1$），而总里程变小了，这与 $B+$ 后续路径是全局最优矛盾。故只需在每个 $(M,u)$ 上保留最小里程一条路径。∎

正是这个引理保证"按点集+终点做 DP"是正确的，不会丢失最优解。这也是 TSP 类问题能用状压 DP 的根本原因。

### Step 3：形式化 DP 状态

定义：

- $dp[mask][u]$：从 $1$ 出发，恰好访问过点集 $mask$ 中的所有点（$mask$ 恒含 $1$ 号点），最后停在 $u$（$u \in mask$）的**最小总路程**。
- $n\le 20 \Rightarrow 2^{20}\times 20 \approx 2\times 10^7$ 个状态，每个状态转移最多枚举 $n$ 个没去过的点，总复杂度 $O(n^2 2^n)\approx 4\times 10^8$，在 $n=20$ 时是可行的（且可以通过只枚举 mask 里的点进一步优化）。

初始化：

$$
dp[1][0]=0
$$

（内部用 0-based 下标，村庄 $1$ 记为 $0$，即只有 `mask = 1`、停在 $0$ 号点时里程为 0，其余状态全部为 $+\infty$。）

### Step 4：转移方程

对于当前状态 $dp[mask][u]$，枚举一个还没有被访问过的点 $v$（$mask$ 的第 $v$ 位为 0），从 $u$ 走到 $v$，边权为 $s_{u,v}$：

$$
dp[mask \cup \{v\}][v] =
\begin{cases}
\min\big(dp[mask \cup \{v\}][v],\ dp[mask][u] + s_{u,v}\big) & u \in mask,\ v\notin mask
\end{cases}
$$

写成代码里的形式（记 `nmask = mask | (1<<v)`）：

```
dp[nmask][v] = min(dp[nmask][v], dp[mask][u] + s[u][v]);
```

**转移正确性证明**：

我们需要证明：如果 $dp[mask][u]$ 已经等于"访问 $mask$ 且终点为 $u$ 的最小里程"（归纳假设），那么上述转移计算出的 $dp[nmask][v]$ 就是"访问 $nmask$ 且终点为 $v$ 的最小里程"。

- （下界）设任意一条访问 $nmask$、终点为 $v$ 的合法路径 $P$。$P$ 去掉最后一段 $u\to v$（其中 $u$ 是倒数第二个点）后，是一条访问 $mask=nmask\setminus\{v\}$、终点为 $u$ 的合法路径。由归纳假设它的里程 $\ge dp[mask][u]$，因此 $\text{len}(P)=$ 前段 $+s_{u,v}\ge dp[mask][u]+s_{u,v}\ge dp[nmask][v]$。这说明 $dp[nmask][v]$ 是任何合法路径长度的下界；
- （可达性）由归纳假设，存在一条访问 $mask$、终点为 $u$ 的路径，其里程恰好等于 $dp[mask][u]$；再接上 $u\to v$ 这一段，就得到一条访问 $nmask$、终点为 $v$ 的路径，里程为 $dp[mask][u]+s_{u,v}$，所以这个值被 $dp[nmask][v]$ 覆盖，即它是可达的。

综上，$dp[nmask][v]=\min\{\text{所有访问 }nmask\text{ 且终点为 }v\text{ 的路径长度}\}$。由归纳法，对所有状态成立。∎

### Step 5：答案如何得到

题目要求**回到村庄 1**。所以最终答案：

$$
\text{ans} = \min_{u \neq 0}\Big(dp[\texttt{fullmask}][u] + s[u][0]\Big)
$$

其中 $\texttt{fullmask} = 2^n-1$。

证明：任何合法回路都是由一条"访问所有点、终点为 $u\neq 1$"的路径再补上最后一段 $u\to 1$ 组成（反之任何这样的组合都给出合法回路）。因此最小回路就是 $\min_u\big(dp[\texttt{fullmask}][u]+s[u][0]\big)$。∎

### Step 6：为什么不考虑"回路内部方向"的歧义？

因为图是**有向**的，回路的起点固定为村庄 $1$，所以每个回路恰好对应唯一的一列顶点顺序，不存在重复计数的问题。即使图是无向的，这种做法也能正确求最小值（会重复枚举正反两个方向，但取 $\min$ 不受影响）。

## 三、套路总结（Pattern Summary）

1. **TSP / 哈密顿回路问题**，$n\le 20\sim 25$ 时，第一直觉就是 `O(n²·2ⁿ)` 的**状压 DP（Held–Karp 算法）**。
2. 状态设计固定套路：
   - 一维：**当前已访问集合**（二进制掩码）；
   - 二维：**当前所在点**；
   - 答案往往需要再补一条"回到起点"的边。
3. **优化小技巧**：
   - 每个点只对应一个比特位，遍历 `mask` 时直接 `for(int v=0; v<n; ++v) if(!((mask>>v)&1))` 这样的跳跃枚举；
   - 如果 $n$ 再大一点（$n\ge 21$），要转用 meet-in-the-middle / 分支定界 / 近似算法。
4. **证明套路**：
   - 转移最优性引理（"子路径只取决于点集和终点"）；
   - 归纳法证明 DP 值 = 真实最优值；
   - 答案的合成：回路 = 路径 + 最后一条回到起点的边。

## 四、正解详解（The Real Solution）

### 记号表（Notation Glossary）

| 记号          | 含义                                    |
| ------------- | --------------------------------------- |
| $n$           | 村庄数量                                |
| $s[i][j]$     | 从村庄 $i$ 到村庄 $j$ 的边权（0-based 存图） |
| $mask$        | $n$ 位二进制数，第 $k$ 位为 1 表示第 $k$ 号村庄已被访问过 |
| $fullmask$    | $2^n-1$，所有村庄都被访问过的掩码       |
| $dp[mask][u]$ | 从村庄 1 出发，访问点集恰为 $mask$，最后停在 $u$ 的最小里程 |
| $u,v$         | 枚举的当前终点与下一个要去的村庄         |
| $nmask$       | $mask$ 加入 $v$ 后的新掩码               |

### 算法步骤

1. **建图**：读入 $n$ 和 $s[0..n-1][0..n-1]$。
2. **初始化**：把 $dp$ 全部填为无穷大；置 $dp[1][0]=0$。
3. **枚举掩码** `mask = 1; mask < fullmask+1; ++mask`：
   - 如果 `mask` 不含 1 号村庄（即第 0 位为 0），跳过（因为从 1 出发不可能经过不包含 1 的点集）；
   - 枚举 $u$，若 $u$ 不在 `mask` 中则跳过；
   - 枚举 $v$，若 $v$ 在 `mask` 中则跳过；
   - 执行松弛：`dp[mask|1<<v][v] = min(dp[mask|1<<v][v], dp[mask][u]+s[u][v])`。
4. **求答案**：`ans = min_u( dp[fullmask][u] + s[u][0] )`，其中 $u$ 从 1 到 $n-1$。
5. 输出 `ans`。

### 复杂度分析

- 状态数 $2^n \cdot n$；
- 每个状态转移最多枚举 $n$ 个 $u$ × $n$ 个 $v$，但代码实现里枚举 $u$, $v$ 时都要求属于/不属于掩码，实际运行的常数比 $O(n^2 2^n)$ 的理论上界小。
- 时间复杂度 $O(n^2 2^n)$，空间复杂度 $O(n 2^n)$。
- 当 $n=20$ 时约 $4\times 10^8$ 次内层操作，C++ 下配合简单的位运算可以轻松通过（本题时限重开过，实测朴素状压写法没有问题）。

## 五、代码（Solution Code）

核心要点：

- 遵循编码风格规范：`#include<bits/stdc++.h>`，全局静态数组，`constexpr int mxn{20}`，0-based 建图，内部用 `1<<v` 做位运算。
- 注意 $dp$ 是全局 `int` 数组，**不会自动初始化为无穷大**，必须手动 `memset`。
- 只访问含村庄 1 的掩码，减少约一半无用状态。

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{20};
constexpr int inf{0x3f3f3f3f};

int n;
int s[mxn][mxn];
int dp[1<<mxn][mxn];        // dp[mask][u]: 从 1 出发，访问点集为 mask，最后停在 u 的最短里程

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			cin>>s[i][j];

	if(n==1)
	{
		cout<<0<<'\n';
		return 0;
	}

	memset(dp,0x3f,sizeof(dp));

	dp[1][0]=0;             // 只访问了村庄 1(编号 0)，里程为 0

	int fullmask=(1<<n)-1;

	for(int mask=1;mask<=fullmask;++mask)
	{
		if(!(mask&1))       // 掩码必须包含村庄 1，否则不合法
			continue;

		for(int u=0;u<n;++u)
		{
			if(!(mask&(1<<u)))      // u 必须在当前掩码中
				continue;

			if(dp[mask][u]==inf)    // 状态不可达
				continue;

			for(int v=0;v<n;++v)
			{
				if(mask&(1<<v))     // v 必须未被访问
					continue;

				int nmask=mask|(1<<v);
				int val=dp[mask][u]+s[u][v];
				if(val<dp[nmask][v])
					dp[nmask][v]=val;
			}
		}
	}

	int ans=inf;
	for(int u=1;u<n;++u)
		ans=min(ans,dp[fullmask][u]+s[u][0]);

	cout<<ans<<'\n';
	return 0;
}
```

### 代码关键点（自检）

- `dp[1][0] = 0`：起点村庄 $1$（0-based 下标 $0$）。
- `memset(dp,0x3f,sizeof(dp))`：将数组置为 $0x3f3f3f3f$，这是常用的"无穷大"，用于比较最小值不会溢出。
- 循环里的 `mask & 1` 剪枝：从村庄 1 出发的合法路径，访问点集必然包含村庄 1，否则不可达，直接跳过。
- 最后输出前别忘了补上 `s[u][0]`（返回村庄 1 的那一段费用）。
