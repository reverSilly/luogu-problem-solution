# P1806 跑步

> 难度：普及/提高- · 标签：动态规划 DP、组合数学

## 1. 重新读题
### 1.1 问题重述（人话版）

要把 \(n\) 圈拆成**至少两段**，每段是正整数圈数，而且每一段都比上一段多。开始之前相当于跑了 0 圈。问有多少种拆法。

### 1.2 关键约束与规模暗示

- \(5\le n\le 500\)。方案数不是指数级的枚举对象，但也不是小到能手算；\(n=212\) 的样例答案是 \(995645335\)，\(n=500\) 的答案是 \(732986521245023\)，超过 \(2^{31}-1\)，用 64 位整数足够（最高位不到 \(2^{50}\)）。
- 「比上次多」是严格递增，所以每一段的圈数互不相同，顺序也被唯一确定：只能从小到大跑。
- 至少两段，单独的「一次跑完 \(n\) 圈」不算。

## 2. 思维链（Chain-of-thought）

**引理 1（方案 \(\Leftrightarrow\) 元素互异、至少两项、和为 \(n\) 的正整数集合）**

每种合法跑法对应 \(\{1,2,\ldots,n\}\) 的一个子集 \(S\)，\(|S|\ge 2\) 且 \(\sum S=n\)；每个这样的子集也只对应一种跑法。

**证明**：跑法是正整数序列 \(x_1<x_2<\cdots<x_k\)，\(k\ge 2\)，\(\sum x_i=n\)。严格递增推出元素互异，每个 \(x_i\ge 1\)，并且 \(x_k\le n-x_1\le n-1<n\)，当然每个 \(x_i\le n\)，所以 \(\{x_i\}\subseteq\{1,\ldots,n\}\)。

反过来，一个和为 \(n\)、大小至少 2 的子集只有一种从小到大的写法，而题目要求后一段必须比前一段多，所以这个顺序是唯一被允许的顺序，不能再乘排列数。\(\square\)

**引理 2（减掉的那个 1 就是子集 \(\{n\}\)）**

\(\{1,\ldots,n\}\) 中和恰好为 \(n\) 的子集里，大小为 1 的只有 \(\{n\}\) 一个；空集的和是 0，不是 \(n\)。因此方案数 \(=\)（和为 \(n\) 的子集个数）\(-1\)。

**证明**：单元素子集 \(\{x\}\) 的和是 \(x\)，等于 \(n\) 只能是 \(x=n\)。大小为 0 的子集只有空集。引理 1 要求 \(|S|\ge 2\)，所以从全部子集计数里减去这一个即可。\(\square\)

**引理 3（0-1 计数背包）**

令 \(f[s]\) 为用 \(\{1,\ldots,n\}\) 里的数、每个最多用一次、和为 \(s\) 的方案数，\(f[0]=1\)（空集）。按数 \(i=1\) 到 \(n\) 依次考虑，并且对 \(s\) 从 \(n\) 降到 \(i\) 做 \(f[s]\mathrel{+}=f[s-i]\)。结束后 \(f[n]-1\) 就是答案。

**证明**：归纳「处理完 \(1..k\) 之后，\(f[s]\) 等于 \(\{1..k\}\) 的子集中和为 \(s\) 的个数」。

- \(k=0\)：只有空集，\(f[0]=1\)，其余为 0（全局数组）。
- 加入 \(k\) 时倒序：计算新的 \(f[s]\) 时，\(f[s-k]\) 还是「不含 \(k\)」的旧值，因为下标 \(s-k<s\)，而循环正在从大往小走，较小下标还没被本轮写过。不含 \(k\) 的子集数是旧 \(f[s]\)，含 \(k\) 的子集数是旧 \(f[s-k]\)（先取一个和为 \(s-k\) 的、元素都 \(<k\) 的子集，再放入 \(k\)）。两者相加就是新的子集数。倒序也保证 \(k\) 不会被加两次。

\(k=n\) 时 \(f[n]\) 就是引理 2 里的子集个数，减 1 得到方案数。\(\square\)

同一递推可以写成二维：\(f[k][s]=f[k-1][s]+[s\ge k]\,f[k-1][s-k]\)，含义是「只用前 \(k\) 个数」。暴力程序用的是这一份，和标程的滚动数组是同一个计数，用来对拍，不是另一套公式硬凑出来的相同代码。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 严格变多 \(\Rightarrow\) 每段圈数是一个集合，顺序被排序唯一化。
- **reduce to easier problem** — 方案数 = 和为 \(n\) 的互异正整数子集数，再减去单段 \(\{n\}\)。
- **classic problem solution** — 倒序 0-1 计数背包，\(f[0]=1\)，答案 \(f[n]-1\)。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| \(n\) | `int` | 总圈数 | 读入 | \(5..500\) |
| `f[s]` | `i64[505]` | 和为 \(s\) 的子集数 | `f[0]=1`，其余全局 0 | 减 1 才是答案 |
| \(i\) | `int` | 当前考虑的圈数 | \(1..n\) | 每个数用一次 |
| \(j\) | `int` | 倒序的和 | \(n\) 降到 \(i\) | 防止重复使用 \(i\) |

### 4.2 算法步骤

1. 读 \(n\)，`f[0]=1`。
2. 对 \(i=1..n\)，对 \(j=n..i\) 递减，`f[j]+=f[j-i]`。
3. 输出 `f[n]-1`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 时间 \(O(n^2)\)，空间 \(O(n)\)。\(n=500\) 只有 \(1.25\times 10^5\) 次加法。
- 编译 warn=0。
- 样例 \(n=212\) 输出 `995645335`，与二维 DP 一致。
- \(n\) 从 5 到 500 逐个与二维 DP 对拍，共 497 组（含样例单独回归 1 组），总耗时 8.351s（含进程启动）。单次 \(n=500\) 标程 0.004s，答案 `732986521245023`。

## 5. 示例代码
### 5.1 标程（`P1806.cpp`）

```cpp
//
// 题目：P1806 跑步
// https://www.luogu.com.cn/problem/P1806
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{505};

i64 f[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n;
	cin>>n;
	f[0]=1;
	for(int i=1;i<=n;++i)
		for(int j=n;j>=i;--j)
			f[j]+=f[j-i];
	cout<<f[n]-1<<'\n';
	return 0;
}
```
