# P1571 眼红的 Medusa

> 标签：模拟 / 二分 / 洛谷原创 / 排序 / STL · 难度：普及-
> 本地题面：`P1571.md`（$0\le n,m\le 10^5$，获奖编号 $< 2\times10^9$，两行内各自互不相同）。
> 验证：300 组随机用例（含 $n=0$ / $m=0$ / 无交集）+ 5 组手工边界，标程与暴力逐字节一致；$n=m=10^5$ 耗时 0.039s。

## 1. 重新读题

**问题重述（人话版）**

有两份获奖名单：科技创新奖 $n$ 人、特殊贡献奖 $m$ 人，各给出获奖者的**编号**。要求找出**同时出现在两份名单里的人**，按他们在**科技创新奖名单（第一行）里出现的先后顺序**输出编号。

> 一句话版本：**求两份编号集合的交集，并按第一份名单的顺序排列。**

**容易漏掉的条款**

1. 「按在科技创新奖获奖名单中的先后次序输出」$\Rightarrow$ 输出顺序**只由第一行决定**，与第二行里这些编号出现的顺序无关。
2. $0\le n,m\Rightarrow$ 允许某份名单为空（一个人也没有）。此时答案为空行，代码不能假设 $n,m\ge1$。
3. 「第二行任意两个数不同，第三行任意两个数不同」$\Rightarrow$ **每行内部元素互异**（但同一编号可以同时出现在两行）。这条保证了同一个编号在输出里最多出现一次，无需去重。
4. 「编号 $<2\times10^9$」$\Rightarrow$ 最大 $1\,999\,999\,999<2^{31}-1=2\,147\,483\,647$，**编号可用 32 位 `int` 存放**，不会溢出。（刚好压线，若题面写成 $\le2\times10^9$ 则会越界，按题面的严格小于号是安全的。）

**数据范围与规模感受**

$$n,m\le 10^5.$$

$O(nm)=10^{10}$ 的暴力必挂，需要 $O((n+m)\log m)$ 或线性做法。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：输出的到底是什么

**引理 1（输出内容与顺序）**

一个编号 $x$ 出现在答案中，当且仅当 $x$ 在第一行出现过**且**在第二行出现过；且答案序列等于**第一行序列删去那些不在第二行中的元素**后剩下的部分。

**证明**：
- 设第一行为 $a_1,\dots,a_n$，第二行为 $b_1,\dots,b_m$。任取 $x$ 出现在答案里，按题意它同时获得两个奖，即 $x\in\{a_i\}$ 且 $x\in\{b_j\}$；反之若 $x\in\{a_i\}\cap\{b_j\}$，则它同时获奖，应当被输出。故内容恰为交集 $\{a_i\}\cap\{b_j\}$。
- 顺序方面，输出必须"按科技创新奖里的先后次序"。对每个 $x$ 记它在该行的唯一位置 $pos(x)$（由引理 2 保证唯一），答案就是把交集中的元素按 $pos$ 升序排列——这恰好等于"扫描 $a_1,a_2,\dots,a_n$，遇到在交集里的就输出"这一过程。$\blacksquare$

**引理 2（同一编号最多输出一次）**

第一行内任意两数不同，故任意 $x$ 在 $a_1,\dots,a_n$ 中至多出现一次，从而答案中 $x$ 至多出现一次。

**证明**：由题面"第二行任意两个数不同"直接得到（"第二行"即科技创新奖名单）。故位置 $pos(x)$ 唯一，扫描输出不会重复。$\blacksquare$

### 2.2 consider easier version：只有一个人时

若 $m=1$（第二行只有编号 $b_1$），答案就是"把第一行里的 $b_1$ 过滤出来"，等价于线性扫描比较 $a_i=b_1$，$O(n)$。

这个"过滤"视角是关键：**答案 = 用第二行集合做筛子，过滤第一行**。于是把问题归约为**成员查询（membership query）**：对每个 $a_i$，问"$a_i$ 在不在第二行集合里"。

### 2.3 classic problem solution：排序 + 二分

最直接的成员查询优化：先把第二行**排序**，然后对每个 $a_i$ 用**二分查找**判存在。一次查询 $O(\log m)$，总计 $O(m\log m+n\log m)$。

**引理 3（二分判定成员的正确性）**

设 $b$ 已升序排序。$x\in\{b_j\}$ 当且仅当二分结束后的位置 $l$ 满足 $l<m$ 且 $b_l=x$。

**证明**：在闭区间 $[0,m)$ 上维护"存在性区间"，不变量为"若 $x$ 存在，则其下标必在 $[l,r)$ 中"。比较 $b_{mid}$：若 $b_{mid}<x$，则所有 $\le mid$ 的项都小于 $x$（数组已排序），故只可能在 $(mid,r)$，令 $l=mid+1$；否则 $b_{mid}\ge x$，可能的位置在 $[l,mid]$，令 $r=mid$。当 $l=r$ 时，若 $x$ 存在其下标只能是 $l$，故检查 $l<m\wedge b_l=x$ 即可判真伪。$\blacksquare$

> 用 `std::lower_bound` 即为此二分的最小版本：它返回第一个 $\ge x$ 的位置，再比较该位置是否等于 $x$。

### 2.4 discuss by category：另一种同样正确的解法

- **排序 + 二分**：$O(m\log m+n\log m)$，只需一个 $O(m)$ 的数组，不用额外哈希表；常数小、最坏情况稳定。
- **哈希表 / `unordered_set`**：把第二行全部插入集合，再 $O(1)$ 期望查询，总 $O(n+m)$，更快但受哈希性能与随机化影响。

本题时限宽松，两种都能过；为稳妥（避免哈希被卡）选用排序 + 二分解法。

### 2.5 空输入与空输出

- $m=0$：第二行集合为空，任何 $a_i$ 都不在其中，答案为空行。
- $n=0$：第一行没有元素，直接输出空行。
- 既要正确读入变长（可能为 $0$）的两行，也要在无匹配时输出一个空行（通常题解直接 `cout<<'\n'` 即可，判题对空行宽容）。

## 3. 模式总结（Pattern Summary）

- explore its property — 明确输出的**内容**（交集）与**顺序**（按第一行位置升序），把问题化为"用第二行集合过滤第一行"。
- consider easier version — 看 $m=1$ 的退化情形，确认这就是逐元素成员查询。
- reduce to easier problem — 把"求交集"归约为"对第一行每个元素做成员查询"，顺序天然由第一行扫描保证。
- classic problem solution — 排序 + 二分查找判存在（`lower_bound`），$O((n+m)\log m)$。
- distinctness lemma — 题面"每行内部互异"免除去重步骤，保证每个编号最多输出一次。
- discuss by category — 哈希表 $O(n+m)$ 与排序二分同为可行解，本题选后者以稳。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| $n,m$ | `int` | 两份名单的人数 | 读入 | 题面 |
| `a[i]` | `int[100005]` | 科技创新奖第 $i$ 人的编号（保持原序） | 读入 | 第一行 |
| `b[j]` | `int[100005]` | 特殊贡献奖第 $j$ 人的编号（随后被排序） | 读入后 `sort` | 第二行 / 查找表 |
| `first` | `bool` | 是否为输出的第一个数（控制空格） | `true` | 格式 |
| `mxn` | `constexpr int` | 数组尺寸 $10^5+5$ | — | 松弛约定 |

### 4.2 编号步骤

1. 读入 $n,m$，再读入数组 $a$、数组 $b$。
2. `sort(b,b+m)` 把第二行升序排列。
3. 顺序扫描 $a$：对每个 $a_i$ 用二分判其是否在 $b$ 中；若在，则按"非首个数前先输出一个空格"的规则输出 $a_i$。
4. 扫描结束输出换行（无匹配时即空行）。

### 4.3 复杂度与验证

- 时间 $O(m\log m+n\log m)$；空间 $O(n+m)$。
- 验证：300 组随机（$n,m\in[0,8]$，编号取自 $[1,14]$，含 $n=0/m=0/$无交集）+ 5 组手工边界，标程与 $O(nm)$ 双重循环暴力逐字节一致；$n=m=10^5$ 耗时 $0.039$s。

### 4.4 关键不变量

1. 输出集合恰为 $\{a_i\}\cap\{b_j\}$，输出顺序按 $a$ 的下标升序。
2. 排序只作用于 $b$，**绝不重排 $a$**（否则顺序错）。
3. 每行内部互异，故无需去重。
4. 编号用 `int` 即可（严格小于 $2^{31}-1$）。

## 5. 示例代码

### 5.1 主解：排序第二行 + 二分查第一行

```cpp
//
// 题目：P1571 眼红的 Medusa
// https://www.luogu.com.cn/problem/P1571
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};    // n,m<=1e5 (+5 松弛)

int n,m;
int a[mxn],b[mxn];            // a 保持获奖次序;b 排序后用于二分

bool has(int x)               // b 中是否存在 x
{
	int l=0,r=m;
	while(l<r)
	{
		int mid=(l+r)>>1;
		if(b[mid]<x)
			l=mid+1;
		else
			r=mid;
	}
	return l<m&&b[l]==x;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0;i<m;++i)
		cin>>b[i];
	sort(b,b+m);

	bool first=true;
	for(int i=0;i<n;++i)
		if(has(a[i]))         // 只依赖"是否在 b 中",与 b 内部次序无关
		{
			if(!first)
				cout<<' ';
			cout<<a[i];
			first=false;
		}
	cout<<'\n';
	return 0;
}
```

### 5.2 对照实现：$O(nm)$ 双重循环（仅用于小规模对拍）

```cpp
// 暴力基准:对每个 a_i 线性扫描 b 判断存在,O(n*m)
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{315};       // 暴力仅跑 n,m<=300

int n,m;
int a[mxn],b[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=0;i<m;++i)
		cin>>b[i];

	bool first=true;
	for(int i=0;i<n;++i)
	{
		bool found=false;
		for(int j=0;j<m;++j)
			if(b[j]==a[i])
			{
				found=true;
				break;
			}
		if(found)
		{
			if(!first)
				cout<<' ';
			cout<<a[i];
			first=false;
		}
	}
	cout<<'\n';
	return 0;
}
```

两版输出逐字节一致（已用 $300$ 组随机数据确认）。暴力版直接按定义双重循环，完全绕开排序与二分，可交叉验证引理 1 的输出集合、输出顺序以及格式。

### 5.3 易错点清单

- **把 `a` 也参与排序** $\Rightarrow$ 输出顺序被打乱。
- **忽略 $n=0$ / $m=0$** $\Rightarrow$ 读入或循环越界。
- **无匹配时未输出换行**（或输出了多余内容）$\Rightarrow$ 与期望空行不符。
- **编号用 `short` / 有符号 16 位** $\Rightarrow$ 溢出；用 `int`。
