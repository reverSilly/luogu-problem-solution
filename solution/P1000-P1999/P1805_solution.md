# P1805 关灯

## 1. 重新读题

有 $n$ 盏灯排成一行，初始状态由 $O_1,\dots,O_n\in\{0,1\}$ 给出（$1$ 表示亮）。每一步只能改变一盏灯的状态，合法操作只有两类：

- 任意时刻都可以改变第 $1$ 盏灯；
- 若第 $1,2,\dots,k-1$ 盏灯全灭、且第 $k$ 盏灯亮着，则可以改变第 $k+1$ 盏灯（$k\ge1$，$k+1\le n$）。

求把所有灯都变成 $0$ 的最少步数。

**规模暗示**：$n\le 1000$。状态总数 $2^n$ 无法枚举；但 $n=1000$ 意味着答案本身可以有约 $2^{1000}$ 那么大（约 $302$ 位十进制数），所以这题真正需要的是「高精度 + 一个只跟每一位有关的递推」——数据范围里写着 $40\%$ 时 $n\le30$，$70\%$ 时 $n\le300$，正是给「能用 `int` / 只能用高精度」两级做区分。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先把操作翻译成「状态图」

把状态看成一个 01 串 $x=(x_1,\dots,x_n)$。操作是对某一个分量取反。设 $m$ 为最小的满足 $x_m=1$ 的下标（不存在则记 $m=\infty$）。

**引理 1（每个状态最多两条出边，且第二条唯一）**
在状态 $x$ 下：
1. 取反 $x_1$ 永远合法；
2. 对 $j\ge2$，取反 $x_j$ 合法当且仅当 $j=m+1$（且 $m+1\le n$）。

**证明**：
取反 $x_j$（$j=k+1\ge2$）的条件是 $x_1=\cdots=x_{j-2}=0$ 且 $x_{j-1}=1$。
- 若 $j-1<m$，则 $x_{j-1}=0$，条件不成立；
- 若 $j-1>m$，则 $x_m=1$ 落在 $x_1,\dots,x_{j-2}$ 中，前缀不全为 $0$，条件不成立；
- 若 $j-1=m$，由 $m$ 的最小性有 $x_1=\cdots=x_{m-1}=0$，又 $x_m=1$，条件恰好成立。

所以合法的 $j\ge2$ 至多一个，就是 $j=m+1$。$\blacksquare$

于是状态图最大度数为 $2$：每个状态只能「动最高位 $x_1$」或者「动第一盏亮灯的下一个位置」。

### 2.2 猜一个哈密顿路径：把 $n$ 位状态递归地拼起来

度数 $\le2$ 的图是若干条链/环。如果所有 $2^n$ 个状态能被一条链串起来，那么这条链就是全图，任意两状态的距离就等于它们在链上的下标之差。手玩 $n=3$ 时从 $000$ 出发只能走：

$$000\to100\to110\to010\to011\to111\to101\to001$$

（每次都是「取反 $x_1$」或「取反第一盏亮灯的下一位」。）观察这串状态的第 $3$ 位：前 $4$ 个是 $0$，后 $4$ 个是 $1$；再看前两位，它们是

$$00,10,11,01\quad\text{和}\quad 01,11,10,00,$$

后者正好是前者倒过来！这提示递归构造。

**构造**：设 $S_k$ 是全部 $2^k$ 个 $k$ 位 01 串的一个排列，按如下方式定义：

- $S_1=(0,\;1)$；
- $S_n=(s,0)_{s\in S_{n-1}}$ 拼接 $(s,1)_{s\in \mathrm{reverse}(S_{n-1})}$。

（$(s,b)$ 表示前 $n-1$ 位是 $s$、第 $n$ 位是 $b$。）

**引理 2（$S_n$ 是一条合法的哈密顿路径）**
$S_n$ 含有 $2^n$ 个互不相同的状态，且相邻两个状态恰好相差一组合法操作。

**证明**（对 $n$ 归纳）：

*互不相同*：前一半第 $n$ 位为 $0$、后一半为 $1$，各自内部由归纳假设互不相同，故整体互不相同；数量为 $2^{n-1}+2^{n-1}=2^n$。

*相邻合法*，分三种位置讨论：

1. **两个都在前一半**：前缀 $s$ 在 $S_{n-1}$ 中相邻，由归纳假设只需改动前 $n-1$ 位中的某一位（取反 $x_1$，或取反第一盏亮灯的下一位，位置 $\le n-1$）。这些操作的条件只涉及前 $n-1$ 位，第 $n$ 位为 $0$ 不影响，故在原 $n$ 位系统中同样合法。
2. **两个都在后一半**：前缀在 $\mathrm{reverse}(S_{n-1})$ 中相邻，等价于在 $S_{n-1}$ 中相邻；同 1 处理，第 $n$ 位保持 $1$ 不影响 legality。
3. **跨越接缝**：前一半最后一个状态的前缀是 $S_{n-1}$ 的最后一个状态，后一半第一个状态的前缀是 $\mathrm{reverse}(S_{n-1})$ 的第一个状态，二者是同一个前缀 $p$，故两状态只在第 $n$ 位不同（$0\leftrightarrow1$）。下面求 $p$。

   先看 $S_k$ 的结构：$S_k$ 的第一个状态恒为全 $0$；最后一个状态递归地是 $(S_{k-1}$ 的第一个状态 $,1)=(0^{k-1},1)$，即「只有第 $k$ 位为 $1$」。于是接缝处

   $$p=S_{n-1}\text{ 的最后状态}=(0^{n-2},1),$$

   即两状态为 $(0^{n-2},1,0)$ 与 $(0^{n-2},1,1)$。它们相差第 $n$ 位；取反第 $n$ 位的条件是 $x_1=\cdots=x_{n-2}=0$ 且 $x_{n-1}=1$，恰好成立。合法。

$\blacksquare$

**引理 3（原状态图就是这条链）**
状态图恰为 $S_n$ 这条链，任意状态 $x$ 到 $0^n$ 的最少步数等于 $x$ 在 $S_n$ 中的下标。

**证明**：引理 2 给出了一条经过全部 $2^n$ 个顶点的路径，故图连通。由引理 1 每个顶点度数 $\le2$。路径上的内部顶点已有两条路径边占据全部度数；两个端点 $0^n$ 与 $(0^{n-1},1)$ 的度数也各为 $1$（$0^n$ 没有亮灯，只能动第 $1$ 位；$(0^{n-1},1)$ 的第一盏亮灯是第 $n$ 盏，动第 $n+1$ 位越界，也只能动第 $1$ 位）。因此图中没有多余边，整张图就是这条链。在一条链上两点距离即下标之差。$\square$

### 2.3 由链的结构推出下标的递推

设 $\mathrm{idx}_n(x)$ 为 $x$ 在 $S_n$ 中的下标（从 $0$ 开始）。由 $S_n$ 的构造：

- 若 $x_n=0$，$x$ 落在前一半，$\mathrm{idx}_n(x)=\mathrm{idx}_{n-1}(x_1\ldots x_{n-1})$；
- 若 $x_n=1$，$x$ 落在后一半的第 $r$ 个（$r$ 为 $x_1\ldots x_{n-1}$ 在 $\mathrm{reverse}(S_{n-1})$ 中的下标），而 $\mathrm{reverse}(S_{n-1})$ 中下标 $r$ 对应 $S_{n-1}$ 中下标 $2^{n-1}-1-r$，故

$$\mathrm{idx}_n(x)=2^{n-1}+r=2^{n-1}+2^{n-1}-1-\mathrm{idx}_{n-1}(x_1\ldots x_{n-1})=2^n-1-\mathrm{idx}_{n-1}(x_1\ldots x_{n-1}).$$

把两种情形写成一行：

$$\mathrm{idx}_n(x)=
\begin{cases}
\mathrm{idx}_{n-1}(x_1\ldots x_{n-1}), & x_n=0,\\[2pt]
2^n-1-\mathrm{idx}_{n-1}(x_1\ldots x_{n-1}), & x_n=1.
\end{cases}\tag{1}$$

**引理 4（从低位递推到高位的闭式）**
设 $c_0=0$，对 $i=1,2,\dots,n$ 令

$$c_i=\begin{cases}c_{i-1},&x_i=0,\\ 2^i-1-c_{i-1},&x_i=1.\end{cases}$$

则 $c_i=\mathrm{idx}_i(x_1\ldots x_i)$，特别地答案 $=c_n$。

**证明**：对 $i$ 归纳。$i=0$ 时 $\mathrm{idx}_0(\varnothing)=0=c_0$。设 $c_{i-1}=\mathrm{idx}_{i-1}(x_1\ldots x_{i-1})$，则 $c_i$ 的定义式与式 (1) 在 $n=i$ 时完全一致，故 $c_i=\mathrm{idx}_i(\cdot)$。$\blacksquare$

注意式 (1) 本来是「由高位往低位」定义的，但因为每一步只依赖前一个下标 $c_{i-1}$，把它改写成按 $i=1\to n$ 的顺序推进完全等价——这正是程序要做的。

### 2.4 高精度

$n\le1000$，$c_n<2^{1000}$，必须高精度。维护 $P_i=2^i-1$：由 $P_i=2P_{i-1}+1$ 逐个生成。若 $x_i=1$，执行 $c_i=P_i-c_{i-1}$。

**引理 5（减法不会出负数）** $0\le c_i\le P_i$。
**证明**：$i=0$ 时 $c_0=0=P_0$。若 $x_i=0$，$c_i=c_{i-1}\le P_{i-1}\le P_i$；若 $x_i=1$，$c_i=P_i-c_{i-1}\le P_i$ 且 $c_i\ge0$。$\blacksquare$

于是用十进制数组实现「$\times2+1$」和「大减大」即可，最后倒序输出。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 把操作翻译成 01 状态图；指出每个状态的出边 $\le2$ 且「非第 $1$ 位的那条出边」唯一（引理 1）。
- **find a Hamiltonian path** — 手玩 $n=3$ 发现状态序列的第二维是 $0\ldots0\,1\ldots1$、前缀先正序后逆序，递归构造 $S_n$（引理 2）。
- **reduce to easier problem** — 度 $\le2$ 且存在哈密顿路径 $\Rightarrow$ 全图就是一条链，距离 = 下标差（引理 3）。
- **derive recurrence** — 由链的递归结构得到 $\mathrm{idx}_n$ 的递推，再改写成从低位到高位的闭式（引理 4）。
- **big integer** — 只需「$\times2+1$」与「大数相减」，$O(n^2)$ 位运算（引理 5）。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 灯数 | 读入 | — |
| `a[i]` | `int[1005]` | $O_i$，第 $i$ 盏灯初始状态（1-based） | 读入 | on/off |
| `pw[]` | `int[1005]` | $P_i=2^i-1$ 的十进制数，**低位在前** | `0`（$P_0$） | power |
| `pc` | `int` | `pw` 的位数 | `1` | power count |
| `cu[]` | `int[1005]` | 当前 $c_i$ 的十进制数，低位在前 | `0` | current |
| `cc` | `int` | `cu` 的位数（无前导零） | `1` | current count |

### 4.2 算法步骤

1. 读入 $n$ 与 $a_1\dots a_n$。
2. 初始化 `pw={0}`、`pc=1`、`cu={0}`、`cc=1`。
3. 对 $i=1\dots n$：
   - `mul2add1()`：令 `pw = 2*pw+1`（十进制逐位乘加，处理进位）；
   - 若 `a[i]==1`：`subcur()`：令 `cu = pw - cu`（逐位减，处理借位），并去掉高位前导零。
4. 从 `cc-1` 到 $0$ 倒序输出 `cu`，换行。

### 4.3 复杂度

- 时间：每步高精度操作 $O(\text{位数})=O(n)$，共 $n$ 步，$O(n^2)\le10^6$ 次个位运算。
- 空间：两个长度 $O(n)$ 的数组，$O(n)$。

## 5. 示例代码

```cpp
//
// 题目：P1805 关灯
// https://www.luogu.com.cn/problem/P1805
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n;
int a[mxn];
int pw[mxn],pc{1};   // 2^i-1，十进制低位在前
int cu[mxn],cc{1};   // 当前序号 c_i

void mul2add1()      // pw = 2*pw+1
{
	int carry=1;
	for(int j=0;j<pc;++j)
	{
		int t=pw[j]*2+carry;
		pw[j]=t%10;
		carry=t/10;
	}
	while(carry)
	{
		pw[pc++]=carry%10;
		carry/=10;
	}
}

void subcur()        // cu = pw-cu，保证 pw>=cu
{
	int borrow{0};
	for(int j=0;j<pc;++j)
	{
		int t=pw[j]-cu[j]-borrow;
		if(t<0)
		{
			t+=10;
			borrow=1;
		}
		else
			borrow=0;
		cu[j]=t;
	}
	cc=pc;
	while(cc>1&&cu[cc-1]==0)
		--cc;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)
		cin>>a[i];

	pw[0]=0;pc=1;
	for(int i=1;i<=n;++i)
	{
		mul2add1();
		if(a[i])
			subcur();
	}
	for(int j=cc-1;j>=0;--j)
		cout<<cu[j];
	cout<<'\n';
	return 0;
}
```
