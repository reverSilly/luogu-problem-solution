# P1546 [USACO3.1] 最短网络 Agri-Net

> 标签：图论 · 生成树 · 并查集 · 贪心 · USACO · 难度：普及/提高-
> 本地题面：`P1546.md`（$3\le N\le 100$，两两距离 $\le 10^5$，输入为 $N\times N$ 邻接矩阵，行内会在 80 字符处折行）。
> 验证：官方样例（$N=4$ 矩阵）$\to 28$；400 组随机对拍 std(Kruskal)==brute(Prim)；最坏规模 $N=100$ 稠密图耗时 $0.0060$ s。

## 1. 重新读题

**问题重述（人话版）**

有 $N$ 个农场，编号 $1..N$。给出一个 $N\times N$ 的矩阵 $d$，$d_{i,j}$ 表示农场 $i$ 与农场 $j$ 之间铺设光纤的费用（对角线 $d_{i,i}=0$）。要选出一批"光纤线路"把所有农场连成**一个整体**（任意两农场之间可经它们互通），并使所选线路的**总费用最小**，输出这个最小总费用。

> 一句话版本：**在一个带权完全图上求最小生成树（MST）的总权值**。

**题面里容易漏掉的条款**

1. 「每两个农场间的距离不会超过 $10^5$」$\Rightarrow$ 边权为正且不大，MST 唯一性不要求、只需总权最小。
2. 「实际上，由于每行 $80$ 个字符的限制，因此，某些行会紧接着另一些行」$\Rightarrow$ **不能在读取时按"一行一个"来解析**。正确做法是用 `cin>>` 逐个 token 读，空白（空格/换行）由输入流自动跳过；若按整行读入再切分，遇到折行就会读飞。
3. 「对角线将会是 $0$」$\Rightarrow$ 自环权为 $0$，但 MST 不需要自环，故建图时跳过 $i=j$。
4. 「必须找出能连接所有农场」$\Rightarrow$ 生成树必须**连通全部** $N$ 个顶点，即恰好选 $N-1$ 条边。

**数据范围与规模感受**

$$3\le N\le 100,\qquad \text{边权}\le 10^5 .$$

完全图边数 $E=\frac{N(N-1)}{2}\le 4950$。任何 $O(N^2)$ 或 $O(E\log E)$ 的算法都远远够用：$4950\log 4950$ 只有几万次操作。这是一道纯粹的最小生成树模板题，难点只在读入和「别把对称边/自环重复加入」。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把「连通 + 最小花费」翻译成图论语言

建图：顶点 = 农场；对每对 $i\ne j$ 连一条无向边，权 $=d_{i,j}$。题目要求选出一组边，使所有顶点连通、且边权和最小。这正是**最小生成树**的定义。

**引理 1（最优解必是生成树）**

在完全图上，总权最小的"连通全部顶点"的方案，必定恰含 $N-1$ 条边，且构成一棵树。

**证明**：

- 任取一个连通全部顶点的边集 $S$。
  - 若 $S$ 含环：把环上任意一条边删去，连通性不变（环上其余边仍能把环上各点连通，环外部分不受影响），且边权非负（$d_{i,j}\ge 0$ 由距离语义，题面数据均为正），故总权不会变大。
  - 反复删环，总能得到无环的连通边集，即一棵**生成树** $T\subseteq S$，且 $\text{cost}(T)\le\text{cost}(S)$。
- 因此对任意方案 $S$，存在生成树 $T$ 使其花费不超过 $S$。取 $S$ 为最优方案，得最优花费 $\ge$ 某棵生成树的花费；反过来任何生成树都是合法方案。故最优解必是一棵生成树，且生成树恰有 $N-1$ 条边（树的定义：连通且无环）。$\blacksquare$

> 这一步把关，确立了"求 MST"这一目标就是原问题，不多不少。

### 2.2 经典技术：Kruskal 贪心与割性质

MST 有成熟的贪心算法。选 Kruskal（按边权升序，能加就加，若两端不在同一集合则合并）最简单，且天然用并查集（DSU）维护连通性。

**引理 2（Kruskal 正确性：割性质）**

把边按权非降排序 $e_1,e_2,\dots$，依次尝试：若 $e_k$ 的两端点当前属于不同的连通分量，则把 $e_k$ 加入答案并合并两个分量，否则跳过。结果的总权是所有生成树中最小的。

**证明**（用"割性质 / 交换论证"）：

称一条边"安全"，若它属于某个 MST。我们证明：按上述过程每加一条边，它都是安全的，于是最终得到的森林可扩充为 MST；且当加满 $N-1$ 条边时森林已连通，就是一棵 MST。只需证一条引理：

**（割性质）** 设把顶点划分成两个非空集合 $(A,B)$（一个"割"），$e$ 是**横跨该割的所有边中权最小**的一条（权相等时任取一条），则 $e$ 属于某棵 MST。

> 证明：取任意一棵 MST $T$。若 $e\in T$ 则完成。否则 $T\cup\{e\}$ 含唯一环 $C$，$C$ 中必有一条横跨同一割 $(A,B)$ 的边 $e'\ne e$（因为环必须两次跨越割才能回到出发侧）。由 $e$ 是割上最小边，$w(e)\le w(e')$。令 $T'=T-\{e'\}+\{e\}$：$T'$ 仍连通且边数不变，故仍是生成树，且 $w(T')=w(T)-w(e')+w(e)\le w(T)$。由 $T$ 是最小，$w(T')\ge w(T)$，故 $w(e)=w(e')$、$w(T')=w(T)$，$T'$ 也是 MST 且含 $e$。得证。$\blacksquare$

**回到 Kruskal**：设某一步中，$e_k$ 是"当前所有**未被处理**的边里权最小者"，且它的两端在现有森林中分属不同分量 $C_1,C_2$。取割 $(A,B)=(C_1,\,$其余所有点$)$。此刻 $e_k$ 是所有横跨该割且尚未处理的边中权最小的（因为边已按权升序排列，$e_k$ 是全局剩余最小，自然也是割上剩余最小）；而已被跳过的边全部"两端同分量"故不横跨该割，已加入的边……不会使 $e_k$ 两端同分量（假设它两端恰好异分量）。用割性质（在其时刻的诸边中，$e_k$ 是割上权最小的一类，等权情形也可同样完成交换），$e_k$ 可扩充进某 MST。故每步的贪心选择都是安全的，Kruskal 得到 MST。$\blacksquare$

> 这样说略带抽象，但本质就是教科书结论：**Kruskal 每次加入的是"当前使两端点尚未连通、且权重最小"的边，属于某棵 MST**。故总权最小。

### 2.3 剖析失败思路

**失败 1：按行读入矩阵。**

题面明确会折行，若用 `getline`/逐行切分静态解析，第 80 字符处会断句，导致矩阵错位。**正解**：`cin>>` 逐 token 读入即可，空白由流自动跳过；本题用 `cin` 配合 `ios::sync_with_stdio(false)` 足够快。

**失败 2：把对称边当成两条不同的边，或加入自环。**

若对每个 $(i,j)$ 都建边（$i,j$ 全体），会重复加入 $d_{i,j}$ 与 $d_{j,i}$ 两条平行边，并加入自环 $d_{i,i}=0$。平行边不影响正确性（DSU 会跳过第二条），但会让 $E$ 翻倍；自环权 $0$ 若被当作有效边加入，会白占一条边进答案（权 $0$ 但并非真实连接），须跳过 $i=j$。**正解**：只取 $i<j$ 的上三角。

**失败 3：忘记 `used==n-1` 提前收工。**

MST 只需 $N-1$ 条边，满 $N-1$ 条后即可 `break`。本题 $E$ 很小，不提前结束也不影响结果，但这是通用 MST 的规范写法。

### 2.4 越界与状态体检

| 量 | 范围 | 上界 | 数组尺寸 |
|---|---|---|---|
| 顶点数 $N$ | $3\le N\le 100$ | $100$ | `mxn{105}` |
| 边数 $E=N(N-1)/2$ | $\le 4950$ | $4950$ | `mxm{10005}` |
| 边权 | $\le 10^5$ | $10^5$ | 单条 `int` 足够 |
| 总权 | $\le (N-1)\cdot10^5$ | $\approx10^7$ | `int` 足够（$<2^{31}$） |

结论：全程 `int` 足够。要防的是**读入折行**（§2.3 失败 1）与**重复/自环边**（失败 2）。

## 3. 模式总结（Pattern Summary）

**模式名：最小生成树 —— 「排序 + 并查集」的 Kruskal。**

按真实思考顺序排列的可迁移标签：

- **reduce to easier problem** — 用引理 1（删环不增代价）把"连通且代价最小"这个一般图问题精确等价成"求最小生成树"，锁定目标。
- **explore its property** — 把"选路网"识别为"带权完全图上的边选择"，看清只需 $N-1$ 条边、自环与对称边可跳过。
- **classic problem solution** — 用 MST 贪心：按边权升序扫描，DSU 判连通，能连就取。
- **prove greedy by cut property** — 用割性质 + 交换论证证明 Kruskal 每步选择安全，得到正确性（引理 2）。
- **read input as tokens** — 折行矩阵必须用 token 流读取（§2.3 失败 1）。
- **avoid duplicate edges** — 只建上三角，跳过自环与对称重复边（§2.3 失败 2）。

**同族题 / 同源题**：

- **P3366【模板】最小生成树**：同一算法的模板题（稀疏图，多用于 Kruskal + DSU 或 Prim + 堆）。
- **P1195 口袋的天空**：把 MST 改成"恰好 $k$ 个连通块"，是 Kruskal 的变体。
- **P1661 扩散 / P1265 公路修建 / P1547 Out of Hay**：都是稠密图 Prim 或 Kruskal 的同类。
- **稠密图 Prim 版本**：当 $N$ 小、边多（如本题 $N\le100$）时，$O(N^2)$ 的 Prim 甚至比 Kruskal 更省事——这正是本题暴力基准采用它的原因。

**一句话记忆**：**"连通所有点、总代价最小" = 最小生成树；Kruskal = 排序 + 并查集；矩阵输入用 token 读。**

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $N$ | `int`（全局 `n`） | 农场数 | 读入 | 题面 |
| `g[i][j]` | `int[mxn][mxn]` | 邻接矩阵，$g_{i,j}=$ 农场 $i$ 到 $j$ 的费用 | 逐 token 读入 | 0-based |
| `e` | `struct{int u,v,w;}[mxm]` | 边集，第 $k$ 条边 $(u,v)$ 权 $w$ | 只填上三角 | 供排序 |
| `f` | `int[mxn]` | DSU 父指针 | `iota(f,f+n,0)` | 并查集 |
| `cnt` | `int` | 已收集的边数 | $0$ | $\le N(N-1)/2$ |
| `ans` | `int` | MST 总权（答案） | $0$ | 累加被选边 |
| `used` | `int` | 已选入 MST 的边数 | $0$ | 达 $N-1$ 即停 |

### 4.2 编号步骤

1. 读入 $N$；用 `cin>>g[i][j]` 逐 token 读入 $N\times N$ 矩阵（自动跨折行）。
2. `cnt=0`；对 $0\le i<j<N$：`e[cnt++]={i,j,g[i][j]}`，只取上三角。
3. `sort(e,e+cnt,[](auto a,auto b){return a.w<b.w;});`（按权升序，引理 2 的前提）。
4. `iota(f,f+n,0);` 初始化 DSU，每个点自成一个分量。
5. `ans=used=0`；扫描排序后的边：若 `getrt(u)!=getrt(v)` 则合并 `f[ru]=rv`、`ans+=w`、`++used`；当 `used==n-1` 或边扫完即停。
6. 输出 `ans`。

### 4.3 复杂度

- 时间：建图 $O(N^2)$；排序 $O(E\log E)\le O(4950\log 4950)$；DSU 合并近似 $O(E\alpha)$。合计约 $6\times10^4$ 次操作。
- 空间：矩阵 `int[105][105]` 约 $44$ KB，边集约 $60$ KB。
- 实测（见 §4.5）：最坏 $N=100$ 稠密图 $0.0060$ s。

### 4.4 关键不变量

1. 排序后扫描到第 $k$ 条边时，前 $k-1$ 条里"被选中的边"在 DSU 中恰好构成一片森林。
2. `used` 等于当前森林的边数；`used==n-1` 时森林连通成一棵树（MST）。
3. 邻接矩阵只读一遍、只建上三角，故 `e[]` 不含自环、不含对称重复边。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 官方样例回归 | **通过**：$N=4$ 矩阵 $\to 28$ |
| 随机数据对拍 | **通过**：400 组随机用例（$N\in[3,25]$，权值规模 $10/100/1000/10^5$ 四档），Kruskal 与稠密 Prim 输出**逐字节一致** |
| 边界用例 | **通过**：折行矩阵由 token 读取天然处理（样例即折行）；对称与自环由只取上三角规避 |
| 最坏规模计时 | $N=100$ 稠密完全图 $\to 0.0060$ s |
| 残余风险 | 若用按行解析读矩阵，遇折行会错位（§2.3 失败 1）；若把全部 $(i,j)$ 都建边，会多出平行边与自环 |

## 5. 示例代码

### 5.1 主解：Kruskal + 并查集

```cpp
//
// 题目：P1546 [USACO3.1] 最短网络 Agri-Net
// https://www.luogu.com.cn/problem/P1546
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};           // N<=100 (+5 松弛)
constexpr int mxm{10005};         // 边数 N*(N-1)/2 <=4950 (+5 松弛)

int n;
int g[mxn][mxn];                  // 邻接矩阵:g[i][j]=农场 i 到 j 的距离
struct{int u,v,w;}e[mxm];         // 边集:(u,v) 与权值 w
int f[mxn];                       // DSU 父指针
int cnt=0;                        // 边数

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			cin>>g[i][j];

	for(int i=0;i<n;++i)          // 只取上三角,避免重复边与自环
		for(int j=i+1;j<n;++j)
			e[cnt++]={i,j,g[i][j]};

	sort(e,e+cnt,[](auto a,auto b){return a.w<b.w;});  // 按边权升序
	iota(f,f+n,0);

	int ans=0,used=0;             // used=已合并的边数,达 n-1 即连通
	for(int i=0;i<cnt&&used<n-1;++i)
	{
		int ru=getrt(e[i].u),rv=getrt(e[i].v);
		if(ru!=rv)
		{
			f[ru]=rv;
			ans+=e[i].w;
			++used;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

**代码结构对照**：`e[]` 是引理 2 排序的对象（只取上三角，半径 `mxm` 足够容纳 $4950$ 条边）；`f/getrt` 是 DSU，维护"当前森林的分量"；`used<n-1` 保证加满生成树的 $N-1$ 条边即停。矩阵用 `cin>>` 逐 token 读，天然处理题面的 80 字符折行。

### 5.2 对照实现：稠密 Prim（仅用于对拍）

```cpp
// 朴素暴力:稠密 Prim (O(n^2)),与 Kruskal 相互独立
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};
constexpr int inf{1145141919};    // 114514 家族哨兵

int n;
int g[mxn][mxn];
bool vis[mxn];
int dis[mxn];                     // dis[i]=i 到当前生成树的最小边权

int main()
{
	if(!(cin>>n))
		return 0;
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			cin>>g[i][j];

	for(int i=0;i<n;++i)
		dis[i]=inf;
	dis[0]=0;                     // 以农场 0 为根开始
	int ans=0;
	for(int it=0;it<n;++it)
	{
		int u=-1;
		for(int i=0;i<n;++i)
			if(!vis[i]&&(u==-1||dis[i]<dis[u]))
				u=i;
		vis[u]=true;
		ans+=dis[u];
		for(int v=0;v<n;++v)
			if(!vis[v]&&g[u][v]<dis[v])
				dis[v]=g[u][v];
	}
	cout<<ans<<'\n';
	return 0;
}
```

两版**输出必须逐字节相同**（已用 $400$ 组随机数据确认）。Prim 从点集角度贪心（每次取"距树最近的点"），Kruskal 从边角度贪心（每次取最小可连边），两者是 MST 的两条独立路径，互为交叉验证：若有排序方向、DSU 合并、下标之类的 bug，会立刻被另一版暴露。

### 5.3 易错点清单

- **按行读矩阵**：遇到 80 字符折行会错位（§2.3 失败 1）——必须用 token 流。
- **建全部 $(i,j)$ 边**：多出对称平行边与自环，导致边集翻倍甚至误选权 $0$ 自环。
- **边排序方向写反**（降序）：Kruskal 变成"最大生成树"，答案错误。
- **`used` 判断漏写**：不提前结束通常不影响正确性，但要保证 DSU 合并正确。
- **`getrt` 忘记路径压缩**：大数据下可能退化；本题规模下无碍，但按规范写路径压缩。
- **`cout<<ans<<endl;`**：违反本项目风格指南，一律用 `'\n'`。
