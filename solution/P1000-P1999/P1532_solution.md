# P1532 卡布列克圆舞曲

> 标签：模拟 · 难度：普及/提高-
> 本地题面：`P1532.md`（多行输入直到 EOF，每行一个起始整数 $n<2^{31}$；对固定位数 $K$ 反复做卡布列克变换，输出进入的循环节）。验证：本地对拍 300 组随机/边界用例 std==brute 全部通过；官方样例 `4321→6174`、`54321→82962 75933 63954 61974` 均吻合；最坏 50000 行 $\times$ 10 位数实测 **0.1125s**。

## 1. 重新读题

**问题重述（人话版）**

对每个输入的起始整数 $n$，反复做如下操作：把 $n$ 的各位数字**重新排序**，分别拼成一个最大的数和一个最小的数，再把两者**相减**。因为 $n$ 的**位数 $K$ 固定**（"差不够四位数时补零"，即差值不足 $K$ 位时补前导零再进入下一轮），这个变换是一个从"$K$ 位数字串"到自身的确定性函数。任何起点最终都会落进一个**循环**。要求输出这个循环，即"**循环节**"——从**第一次重复出现的那个数**开始，按出现顺序用空格分隔。

例如 $54321$（$K=5$）的轨迹是 $54321\to41976\to82962\to75933\to63954\to61974\to\boxed{82962}$，$82962$ 首次出现于第 2 步，故循环节为 $82962,75933,63954,61974$。

**题面里容易漏掉的条款**

1. 「如果 **$K$ 位数**也照此办理」+「差不够四位时**补零**」⇒ **位数 $K$ 全程固定**，$K$ 取输入 $n$ 的十进制位数；每轮结果都当作 $K$ 位串（不足则左补 `0`）再排序。**$K$ 绝不能随当前数字位数变化。**
2. 「**若干行**」⇒ 输入到 EOF，多组数据。
3. 「每行为**对应整数**的循环节」⇒ **只输出循环节**，不含进入循环之前的"预周期"数字。
4. 输出数字之间用**空格**分隔。
5. $n<2^{31}$ ⇒ $n$ 最多 10 位；但最长可达 $9999999999>2^{31}$ 的**中间值**（10 位降序数），存储要用 64 位。

**数据范围与规模感受**

$n<2^{31}$，即位数 $K\le10$。状态空间是"$K$ 位数字串"，大小 $\le10^{10}$，但由于起点只有有限个且变换确定，实际轨迹与循环都很短（$K\le10$ 时循环长度通常在几十以内）。逐值模拟、用哈希表记"首次出现位置"即可，单个数秒解，多组数据也轻松。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把操作抽象成一个函数

**引理 1（$K$ 固定 + 补零后的变换是良定义的函数）**

设 $K$ 为给定位数。把一个非负整数 $x$ 的十进制表示左补 `0` 至 $K$ 位，得到数字多重集 $S(x)$。令 $M=\max$ 排列（降序拼数）、$m=\min$ 排列（升序拼数），定义

$$f_K(x)=M-m.$$

则 $f_K$ 是从 $\{0,\dots,10^K-1\}$（视作 $K$ 位串）到自身的**良定义函数**：$0\le f_K(x)<10^K$，且 $f_K(x)$ 的值只由 $x$ 的 $K$ 位数字（含补零）决定。

**证明**：
- 相同数字多重集下，降序拼数 $M$ 是这些数字能拼出的最大值，升序拼数 $m$ 是最小值（相邻交换论证：任何非降序序列交换一对逆序位置可增大数值，故降序最大、升序最小）。
- $M\ge m$，故 $f_K(x)\ge0$；又 $M<10^K$ 且 $m\ge0$，故 $f_K(x)<10^K$。结果不足 $K$ 位时左补零即仍落在该集合内。
- 值由数字多重集（即补零后的 $K$ 位）唯一决定，故是良定义函数。$\blacksquare$

> 关键点：**补零是在函数定义里的**——做 $M,m$ 时用的是补零后的 $K$ 位串。例如 $K=4$ 时 $999$（3 位）要当作 `0999`，得 $M=9990,m=999,f=8991$。若省略补零就会算错。

### 2.2 归约：找循环 ⇒ 在确定性函数上找轨道周期

**引理 2（轨道必然进入循环）**

从任意起点 $v_0=n$ 出发，$v_{t+1}=f_K(v_t)$。则序列 $v_0,v_1,\dots$ 必在有限步后进入周期。

**证明**：函数定义域 $\{0,\dots,10^K-1\}$ 是**有限集**（大小 $10^K$）。在这 $10^K$ 个取值上取 $v_0,\dots,v_{10^K}$ 共 $10^K+1$ 个项，由抽屉原理必有两个相等，设 $v_i=v_j\ (i<j)$。因 $f_K$ 是确定性函数，两条轨道自 $i,j$ 起完全重合，故 $t\ge i$ 后以 $L=j-i$ 为周期。$\blacksquare$

**引理 3（首次重复的值即循环起点）**

在轨道中取**首次**出现重复的位置：最小的 $i$ 及对应的 $j>i$ 使 $v_i=v_j$。则循环节恰为 $v_i,v_{i+1},\dots,v_{j-1}$，而 $v_0,\dots,v_{i-1}$ 是"预周期"，不属于循环节。

**证明**：
- 周期性：$v_{i}=v_{j}$ 且 $f_K$ 确定 ⇒ $v_{i+s}=v_{j+s}\ \forall s\ge0$，故从 $i$ 起每 $L=j-i$ 步重复，$v_i..v_{j-1}$ 是一个周期。
- 最小性：取最小的 $i$ 使某 $v_{i}=v_{j}(j>i)$。若 $i'\ (<i)$ 处的值之后再出现，则会得到更小的 $i$，矛盾；故 $v_0..v_{i-1}$ 两两不同且此后不再出现，确为预周期。
- 于是从 $v_i$ 起进入循环，循环节为 $v_i..v_{j-1}$。$\blacksquare$

> 这与上题（P1530）"首次重复的余数位置即循环起点"是同一套论证，只是把"余数序列"换成了"值序列"。

### 2.3 数值与实现体检

- **位数 $K$**：由 $n$ 的十进制位数确定；$n=0$ 视作 $1$ 位（$K=1$）。
- **64 位存储**：$K=10$ 时 $M\le9999999999$，超过 `int` 上限 $2147483647$，必须用 `long long`（`i64`）。
- **数字拆分**：既可按模 $10$ 逐位取出（`c[i]=v%10`），也可用字符串补零后取位；两法等价（引理 1），本解标程用前者、暴力用后者，互相独立验证。
- **循环检测**：把"值 → 首次出现下标"存进 `unordered_map`，走到已出现值即停。
- **输出**：从首次重复值开始打印到轨道末尾，空格分隔。

### 2.4 剖析失败思路

**失败 1：不固定位数 $K$（每轮用当前数字位数）。** 这是本题最大的坑。反例：$n=100000$（$K=6$）若按当前位数，$100000\to100000-1=99999$（5 位），之后按 5 位走，得到的是**另一个**循环；按题面固定 $K=6$，$99999$ 应补成 `099999`，两侧不同。**判定依据**：题面明文"$K$ 位数照此办理""差不够四位时补零"，故位数必须固定为输入位数。

**失败 2：用 32 位 `int` 存降序数。** $K=10$、各位全 $9$ 时 $M=9999999999>2^{31}-1$，溢出为负，答案错误。

**失败 3：把预周期数字也一起输出。** 例如输出 $54321,41976,82962,\dots$ 全轨迹，而题面只要循环节 $82962,75933,63954,61974$。

**失败 4：输出顺序从"重复发生处"而非"首次出现处"开始。** 必须从 `pos[v]`（首次出现下标）开始，才对得上样例。

## 3. 模式总结（Pattern Summary）

**模式名：确定性迭代的「函数轨道 + 首次出现表找循环节」。**

**识别信号**：题目给出一个"对数字/状态反复施加同一变换"的过程，问最终循环（圆舞曲 / 循环节 / 周期）。

**可复用套路（按真实思考顺序）**：

- **explore its property** — 把过程抽象成良定义函数 $f_K$，确认结果仍在同一状态域内、且只由"输入的数字多重集"决定（引理 1）。
- **consider easier version** — 先把"位宽固定 + 补零"这一处理单独钉死，避免位宽漂移（失败 1 的反例）。
- **classic problem solution** — 用**抽屉原理**证明有限状态下的确定性迭代必循环，给出模拟步数上界（引理 2）。
- **reduce to easier problem** — "找循环节"归约为"在值序列里找首次重复"（引理 3）。
- **classic problem solution(第二次，独立技巧)** — 用**哈希表（或数组）记首次出现位置**做 $O(1)$ 查重，并从"首次出现下标"起输出。
- **defer reconstruction** — 先把整条轨道存下来，停止后再据首次重复下标裁剪输出（而非边跑边输出）。
- **integer-width check** — 先估状态最大值（$K$ 位降序数可达 $10^K-1$），据此选 `i64` 而非 `int`。

**同族题**：AT_abc192_c Kaprekar Number（同类变换，问第 $K$ 项）；罗马数字/数字重排类的模拟题；任何"有限状态确定性迭代的循环检测"。

**一句话记忆**：反复做同一个数字变换 ⇒ 状态有限必成环；用哈希记"首次出现位置"，从那里起打印即循环节。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `i64 n` | 当前行的起始整数 | 读入 | 题面（多行、EOF） |
| $K$ | `int k` | 固定位宽 = 起始 $n$ 的十进制位数 | 由 $n$ 算 | 题面"$K$ 位数" |
| `c[12]` | `int[12]` | 当前值补零后的 $K$ 个数字 | 每轮拆位 | 数字缓冲区 |
| `step(v,k)` | 函数 | 降序拼数 $-$ 升序拼数 $=f_K(v)$ | — | 引理 1 |
| `pos` | `unordered_map<i64,int>` | 值 → 首次出现下标 | 空 | 首次出现表（引理 3） |
| `seq` | `vector<i64>` | 轨道 $v_0,v_1,\dots$ | 空 | 逐值追加 |
| `st` | `int` | 循环节起点下标 | `pos[v]` | 输出自 `st` 起 |

### 4.2 编号步骤

1. `while(cin>>n)`：逐行读入（EOF 结束）。
2. 求位宽 $k$：`for(i64 t=n;t;t/=10)++k;`，若 $k=0$（即 $n=0$）置 $k=1$。
3. 初始化 `pos` 空、`seq` 空、`v=n`。
4. 循环：当 `!pos.count(v)`：`pos[v]=seq.size(); seq.push_back(v); v=step(v,k);`（走到重复值停）。
5. `st=pos[v]`；从 $i=st$ 到 `seq.size()-1` 输出 `seq[i]`，用空格分隔，行末换行。

### 4.3 复杂度

- 时间：每个数模拟到首次重复，步数 $=$ 预周期 $+$ 循环长，实践上很小（$K\le10$）；单步 $O(K\log K)$（排序 $K$ 个数字）。
- 空间：`seq`/`pos` 规模为轨道长度，很小。
- 实测：50000 行 10 位数共 **0.1125s**。

### 4.4 关键不变量

1. `seq` 内值互不相同（一旦就要重复即停）。
2. `pos[v]` 为 $v$ 的**首次**出现下标。
3. $k$ 自始至终等于起始数的位数（失败 1 的防线）。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 官方样例 | **通过**：`4321`→`6174`；`54321`→`82962 75933 63954 61974` |
| 随机数据对拍 | **通过**：300 组（每用例 1–5 行，位数 1–10，含各位相同的数）与"字符串补零 + 线性查找重复"的暴力**逐字节一致** |
| 边界用例 | **通过**：`1111`→`0`、`0`→`0`、`1`→`0` |
| 最坏规模计时 | 50000 行 $\times$ 10 位数，耗时 **0.1125s** |
| 残余风险 | 循环节内的数字按**整数值**输出（不补前导零）；除 $K=2$ 等少数情形循环含小于 $10^{K-1}$ 的数外，样例与常见循环均无歧义。本地题面未附录多组样例，若判题要求保留前导零需另行调整（已用暴力交叉验证当前语义自洽） |

## 5. 示例代码

### 5.1 主解：哈希首次出现表 + 从循环起点输出（与 `appendix/P1532/P1532.cpp` 逐字节一致）

```cpp
//
// 题目：P1532 卡布列克圆舞曲
// https://www.luogu.com.cn/problem/P1532
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 step(i64 v,int k)             // 一次卡布列克变换,固定 k 位宽(前导补零)
{
	int c[12]{};
	for(int i=0;i<k;++i)
	{
		c[i]=int(v%10);
		v/=10;
	}
	sort(c,c+k);
	i64 mx=0,mn=0;
	for(int i=0;i<k;++i)
	{
		mn=mn*10+c[i];            // 升序拼成的较小数
		mx=mx*10+c[k-1-i];        // 降序拼成的较大数
	}
	return mx-mn;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	i64 n;
	while(cin>>n)                 // 多行直到 EOF
	{
		int k=0;
		for(i64 t=n;t;t/=10)
			++k;
		if(k==0)
			k=1;                  // 0 视作 1 位数
		unordered_map<i64,int>pos; // 值 -> 首次出现位置
		vector<i64>seq;
		i64 v=n;
		while(!pos.count(v))      // 走到重复值即进入循环
		{
			pos[v]=int(seq.size());
			seq.push_back(v);
			v=step(v,k);
		}
		int st=pos[v];            // 循环节从该值首次出现处开始
		for(int i=st;i<(int)seq.size();++i)
			cout<<seq[i]<<(i+1<(int)seq.size()?' ':'\n');
	}
	return 0;
}
```

### 5.2 对照实现：字符串补零 + 线性查重（仅用于对拍，与 `P1532_brute.cpp` 一致）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 step(i64 v,int k)             // 用字符串补零,与标程的取模法互相独立
{
	string s=to_string(v);
	while((int)s.size()<k)
		s='0'+s;
	string a=s,b=s;
	sort(a.begin(),a.end());          // 升序 -> 较小数
	sort(b.rbegin(),b.rend());        // 降序 -> 较大数
	return stoll(b)-stoll(a);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	i64 n;
	while(cin>>n)
	{
		string s=to_string(n);
		int k=max(1,(int)s.size());
		vector<i64>seq;
		i64 v=n;
		while(true)                   // 线性查找是否出现过
		{
			bool found=false;
			for(i64 x:seq)
				if(x==v)
				{
					found=true;break;
				}
			if(found)
				break;
			seq.push_back(v);
			v=step(v,k);
		}
		int st=0;
		for(int i=0;i<(int)seq.size();++i)
			if(seq[i]==v)
			{
				st=i;break;
			}
		for(int i=st;i<(int)seq.size();++i)
			cout<<seq[i]<<(i+1<(int)seq.size()?' ':'\n');
	}
	return 0;
}
```

### 5.3 易错点清单

- **位数 $K$ 不固定**（随当前数字位数变化）⇒ 得到错误的循环（失败 1 反例）。
- **`int` 存 10 位降序数** ⇒ 溢出为负，答案错（必须 `i64`）。
- **输出整条轨道而非从首次重复处裁剪** ⇒ 多出预周期数字。
- **从"重复发生处"而非"首次出现处"开始** ⇒ 循环节偏移一位。
- **读入用单次 `cin>>n`** ⇒ 多行数据只用第一行；须 `while(cin>>n)`。
