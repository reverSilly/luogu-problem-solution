# P1896 [SCOI2005] 互不侵犯

## 1. 重新读题

### 1.1 问题重述（人话版）

在 $N\times N$ 的棋盘上放 $K$ 个国王。国王会攻击它周围八格（上下左右 + 四个斜角）。要求任意两个国王互不攻击，求方案数。

### 1.2 关键约束与规模暗示

- $N\le 9$，$K\le N^2\le 81$。
- $N\le 9$ 强烈暗示对**一行**做状态压缩：一行的状态是一个 $N$ 位二进制数，最多 $2^9=512$ 种。
- 攻击只发生在同一行相邻格、以及相邻两行之间（竖直或斜着）。因此可以按行 DP，状态只与上一行有关。
- 方案数可能很大（$N=9$ 时有的 $K$ 对应答案达到 $10^{10}$ 量级），必须用 `long long`。
- $K$ 可能为 $0$（一种方案：什么都不放），也可能大到根本放不下（答案为 $0$）。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：攻击的局部性

国王的攻击范围只跨一行：同一行内左右相邻；相邻两行之间同列、左上、右上、左下、右下。

这带来一个关键性质：**一旦确定了每一行的摆法，合法性只需逐对检查相邻两行**。因为任意两个国王若在同一行，检查行内相邻；若在相邻两行，检查行间冲突；若行距 $\ge 2$，纵坐标差至少 $2$，国王最多攻击相邻的一行，故不可能互相攻击。

于是问题变成：给每行选一个「行状态」，使得相邻行状态兼容，且所有行状态中 $1$ 的个数之和恰为 $K$。

### 2.2 引理 1（行内合法状态）

把一行的摆法编码为整数 $s\in[0,2^N)$，第 $c$ 位为 $1$ 表示第 $c$ 列放国王。

**引理 1.** 行内没有互相攻击的国王，当且仅当 $s\ \&\ (s\ll 1)=0$。

**证明.** 同一行的两个国王若互相攻击，只能是左右相邻，即存在列 $c$ 使 $s$ 的第 $c$ 位和第 $c+1$ 位同时为 $1$。而 $s\ll 1$ 的第 $c$ 位恰为 $s$ 的第 $c-1$ 位，故 $s\ \&\ (s\ll 1)\ne 0$ 等价于存在这样的相邻两列。取反即得结论。$\blacksquare$

所有满足条件的 $s$ 称为合法状态，个数不超过 $2^N\le 512$（实际 $N=9$ 时为 $89$，即斐波那契数 $F_{11}$）。

### 2.3 引理 2（行间兼容条件）

设上一行状态为 $s$、下一行状态为 $t$。

**引理 2.** 两行之间没有任何互相攻击的国王，当且仅当同时满足：

$$
s\ \&\ t=0,\qquad (s\ll 1)\ \&\ t=0,\qquad (t\ll 1)\ \&\ s=0.
$$

**证明.**

- 若 $s\ \&\ t\ne 0$：存在同列 $c$ 两行都放国王，上下相邻，互相攻击。
- 若 $(s\ll 1)\ \&\ t\ne 0$：存在列 $c$ 使 $s$ 的第 $c-1$ 位与 $t$ 的第 $c$ 位同时为 $1$，即斜对角相邻，互相攻击。
- 若 $(t\ll 1)\ \&\ s\ne 0$：对称地，存在 $t$ 的第 $c-1$ 位与 $s$ 的第 $c$ 位同时为 $1$，斜对角相邻，互相攻击。

以上说明三个条件都是必要的。反过来，若两行之间存在攻击，攻击只可能来自「同列」「列差 $1$」两种情形（行距为 $1$），它们分别被上述三个条件覆盖（列差 $1$ 的两个方向分别对应后两式）。所以条件也是充分的。$\blacksquare$

> 位运算细节：`s<<1` 会使最高位溢出到第 $N$ 位之外，但 $t$ 只有低 $N$ 位为 $1$，与它按位与不受影响，因此无需额外截断。

### 2.4 DP 的定义与转移

定义

$$
dp[s][k]=\text{已经摆完若干行、最后一行状态为 }s\text{、共用 }k\text{ 个国王的方案数}.
$$

- **初始化（第 $1$ 行）**：对所有合法状态 $s$，`dp[s][cnt(s)] = 1`，其中 `cnt(s)` 是 $s$ 中 $1$ 的个数。
- **转移（第 $r$ 行，$r\ge 2$）**：枚举上一行合法状态 $s$ 与当前行合法状态 $t$，若 `ok(s,t)` 成立（引理 2），则

$$
ndp[t][k+\mathrm{cnt}(t)]\mathrel{+}=dp[s][k].
$$

- **答案**：$\sum_{s\text{ 合法}}dp[s][K]$。

### 2.5 引理 3（DP 正确性）

**引理 3.** 按上述方式转移，处理完 $N$ 行后 $dp[s][k]$ 恰好等于「前 $N$ 行状态依次为某个序列，末行状态为 $s$，共放 $k$ 个国王，且所有相邻行兼容」的方案数。

**证明.** 对行数 $r$ 归纳。

- $r=1$：只有一行，方案由该行状态 $s$ 唯一决定，国王数为 $\mathrm{cnt}(s)$，初始化正确。
- 设 $r-1$ 行时命题成立。考虑 $r$ 行、末行状态 $t$、总数 $k$。设倒数第二行状态为 $s$，则前 $r-1$ 行是一个合法的 $(r-1)$ 行摆法，总数 $k-\mathrm{cnt}(t)$，由归纳假设被 $dp[s][k-\mathrm{cnt}(t)]$ 计数。整个 $r$ 行摆法合法当且仅当「前 $r-1$ 行合法」且「$s,t$ 兼容」（引理 2；行距 $\ge2$ 的行不可能互相攻击）。转移恰好枚举所有 $s$ 并检查兼容性，且每个摆法被且仅被其倒数第二行状态唯一确定，故不重不漏。
- 归纳完成。

最后对末行状态求和，即得所有 $N$ 行合法摆法数。$\blacksquare$

### 2.6 失败尝试记录

1. **直接枚举 $2^{N^2}$ 个格子集合**：$N=9$ 时 $2^{81}$，完全不可行。
2. **只压行内合法性、不检查斜对角**：会多算。必须同时检查 `(s<<1)&t` 与 `(t<<1)&s`。
3. **把状态数当成 $2^N$ 而没筛合法状态**：也能过（$N\le9$），但预筛合法状态更快，且逻辑更清晰。
4. **`K` 超过当前行数能放的最大值仍然循环**：不影响正确性（这些位置永远为 $0$），但可以在初始化时只对 `cnt[s]<=K` 置位。
5. **用 `int` 存方案数**：$N=9$ 的答案可达 $5\times10^{10}$ 以上，必须 `long long`。
6. **多行 DP 忘记清空 `ndp`**：会串行累加。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 攻击只影响同一行与相邻行，行距 $\ge2$ 无约束。
- **state compression** — 用 $N$ 位二进制表示一行的摆法，先筛掉行内相邻的非法状态。
- **prove compatibility lemma** — 三个位运算条件恰好刻画相邻两行的全部八邻域冲突。
- **classic problem solution** — 按行 DP：`dp[末行状态][已用国王数]`，逐行枚举兼容状态转移。
- **careful with types** — 方案数用 `long long`，$K=0$ 与无解都要自然处理。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 棋盘边长 | 读入 | |
| `K` | `int` | 国王总数 | 读入 | |
| `valid[]` | `int [1<<9]` | 所有行内合法的状态 | 枚举 $s$ 且 `!(s&(s<<1))` | valid masks |
| `nvalid` | `int` | 合法状态个数 | $0$ | |
| `cnt[s]` | `int [1<<9]` | 状态 $s$ 中 $1$ 的个数（国王数） | `__builtin_popcount` | count |
| `dp[s][k]` | `i64 [1<<9][86]` | 处理到当前行、末行状态 $s$、共 $k$ 个国王的方案数 | 第 $1$ 行初始化 | DP |
| `ndp[s][k]` | `i64 [1<<9][86]` | 下一行的滚动数组 | 每行清 $0$ | next DP |
| `ok(s,t)` | 函数，返回 `bool` | 相邻两行是否兼容 | 引理 2 的三条件 | |
| `ans` | `i64` | 答案 | $0$ | |

### 4.2 算法步骤

1. 读入 $N,K$。枚举 $s\in[0,2^N)$，若 `!(s&(s<<1))` 则加入 `valid`，并计算 `cnt[s]`。
2. 初始化：对每个合法状态 $s$，若 `cnt[s]<=K`，令 `dp[s][cnt[s]]=1`。
3. 对行 $r=2\dots N$：
   1. `memset(ndp,0)`；
   2. 枚举上一行合法状态 $s$ 与当前行合法状态 $t$；
   3. 若 `ok(s,t)`，令 `add=cnt[t]`，对所有 `k+add<=K` 执行 `ndp[t][k+add]+=dp[s][k]`；
   4. 把 `ndp` 拷回 `dp`。
4. 答案 `ans = Σ_{s 合法} dp[s][K]`，输出。

### 4.3 复杂度分析

- **状态数**：$V\le 2^N\le 512$（$N=9$ 时实际 $V=89$）。
- **时间**：$O(N\cdot V^2\cdot K)$。最粗估 $9\times 512^2\times 81\approx 1.9\times 10^8$，实际因 $V=89$ 只有约 $9\times 89^2\times 81\approx 5.8\times 10^6$，非常快。
- **空间**：$O(VK)$，两个滚动数组，约 $0.7$ MB。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{10};
constexpr int mxst{1<<9};

int n,K;
int cnt[mxst];
i64 dp[mxst][mxn*mxn+5],ndp[mxst][mxn*mxn+5];
int valid[mxst],nvalid;

bool ok(int s,int t)
{
	return !(s&t)&&!((s<<1)&t)&&!((t<<1)&s);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>K;
	int full=1<<n;
	for(int s=0;s<full;++s)
		if(!(s&(s<<1)))
		{
			valid[nvalid++]=s;
			cnt[s]=__builtin_popcount((unsigned)s);
		}
	for(int i=0;i<nvalid;++i)
	{
		int s=valid[i];
		if(cnt[s]<=K)
			dp[s][cnt[s]]=1;
	}
	for(int r=1;r<n;++r)
	{
		memset(ndp,0,sizeof(ndp));
		for(int i=0;i<nvalid;++i)
		{
			int s=valid[i];
			for(int j=0;j<nvalid;++j)
			{
				int t=valid[j];
				if(!ok(s,t))
					continue;
				int add=cnt[t];
				for(int k=0;k+add<=K;++k)
					if(dp[s][k])
						ndp[t][k+add]+=dp[s][k];
			}
		}
		memcpy(dp,ndp,sizeof(dp));
	}
	i64 ans=0;
	for(int i=0;i<nvalid;++i)
		ans+=dp[valid[i]][K];
	cout<<ans<<'\n';
	return 0;
}
```
