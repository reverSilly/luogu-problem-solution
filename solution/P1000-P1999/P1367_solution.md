# P1367 蚂蚁

> 标签：模拟 · 碰撞等价于穿透 · 排序 | 难度：普及/提高-

## 1. 重新读题

**问题重述（简化版）**

无限长木棍上有 $n$ 只蚂蚁。第 $i$ 只（**输入编号即身份，身份是可区分的**）初始位置 $a_i$（两两不同）、朝向 $b_i\in\{+1,-1\}$，速度恒为每秒 $1$ 个单位。两只蚂蚁在同一时刻到达同一位置就**同时掉头**，掉头本身耗时 $0$。求 $t$ 秒后每只**编号**蚂蚁的位置与朝向；若某只蚂蚁恰好在 $t$ 这个时刻处于相撞状态，朝向输出 $0$。

| 项 | 内容 |
|---|---|
| 输入 | 一行 $n,t$；随后 $n$ 行，每行 $a_i,b_i$（$b_i=1$ 朝右，$-1$ 朝左）。**只有一组数据** |
| 输出 | $n$ 行，第 $i$ 行是编号 $i$ 的蚂蚁在 $t$ 秒后的位置与朝向（$-1/0/1$） |
| 位置范围 | $\lvert a_i\rvert\le 2\times10^6$，$n\le10^5$，$0\le t\le10^5$ |
| 子任务 | $40\%:n\le100$；$80\%:n\le10^4,\,t\le1000$；$100\%$ 见上 |

**三个必须抠清楚的点**

1. **身份可区分**：第 $i$ 行输出的是"编号 $i$ 那只"，不是"从左数第 $i$ 只"。题面**没有**"蚂蚁彼此不可区分"这类话，反而逐编号要求输出，所以本题是"身份可区分"版本；那个"身份不可区分、只问 $t$ 秒后位置集合"的经典版本只要把 $a_i+b_it$ 排序输出即可，本题**不能**这样偷懒（§2.2 有具体反例），必须额外解决"哪只蚂蚁占哪个位置、朝哪个方向"。
2. **朝向可以是 $0$**：判据就是"$t$ 时刻恰好有两只蚂蚁撞在一起"，不是"曾经撞过"，也不是"以后会撞"。
3. **单组数据**：读完 $n$ 行就结束，没有多组、没有 EOF 驱动。

**约束与暗示**

| 量 | 上界 | 类型 | 备注 |
|---|---|---|---|
| $n$ | $10^5$ | `int` | 数组 $O(n)$ |
| $t$ | $10^5$ | `int` | 与 $n$ 同阶 ⇒ $O(nt)$ 不可接受 |
| $a_i+b_it$ | $2\times10^6+10^5=2.1\times10^6$ | `int` 够 | 距 $2^{31}-1$ 有 $\approx10^3$ 倍余量 |
| 同一位置同时的蚂蚁数 | $2$ | — | 引理 3 证明，不是"显然" |

## 2. 思维链

### 2.1 先把"相遇即掉头"翻译成世界线语言

木棍无限长 ⇒ 没有边界反弹，只有蚂蚁之间的相遇。把每只蚂蚁的运动画在"位置-时间"平面（横轴位置、纵轴时间）上：不掉头时是一条斜率 $\pm1$ 的直线段；一次掉头就是这条折线在该点**折返**（斜率取反）。于是"相遇即掉头"= 两条世界线相触后各自沿对方的来路返回，**它们从不相交，只是碰到一下再分开**。这个图景是后面所有证明的对象。

### 2.2 朴素做法：两处会失败的地方与一个错误直觉

子任务先给方向：$40\%$ 的 $n\le100$ 允许"$逐事件模拟、每次枚举所有对找最早碰撞$"的 $O(n^2\cdot\#\text{碰撞})$ 写法；$80\%$ 的 $n\le10^4,t\le1000$ 允许 $nt\le10^7$ 的逐秒模拟；$100\%$ 两者都爆。所以"模拟"这个标签是**部分分**的提示，不是正解。

**(a) 逐秒模拟的复杂度**：全量 $nt=10^5\times10^5=10^{10}$，直接超时。

**(b) 逐秒模拟还有个隐藏坑**：撞的时刻可以是半整数。$a=0(+1)$ 与 $a=3(-1)$ 在 $t=1.5$、位置 $1.5$ 相遇——只在整数位置网格上"每秒走一步再看谁重合"的写法会**完全漏掉**这次碰撞，得到错误身份分配。要做对必须把坐标整体翻倍（$a\to2a$、每秒位移变 $\pm2$），这样所有相遇位置都落在整数格上、每秒一步即可判等；或者改成"事件排序"模拟，实现代价与出错概率都上升。

**(c) "身份直接代入"是错的**。反例：$n=2,t=2$，$(a_1,b_1)=(0,+1)$、$(a_2,b_2)=(3,-1)$。真实过程：两蚁在 $t=1.5$ 位置 $1.5$ 相撞掉头，编号 1 改向左、编号 2 改向右；$t=2$ 时编号 1 在位置 $1$ 朝 $-1$、编号 2 在位置 $2$ 朝 $+1$。而"直接代入"给编号 1 位置 $2$ 朝 $+1$、编号 2 位置 $1$ 朝 $-1$——**位置集合碰巧对了，身份与朝向全反**。

(b)(c) 合起来说明：位置集合有规律（值得证明），真正难的是"身份怎么分配"。§2.3 就把这两件事拆开处理。

### 2.3 核心引理：碰撞等价于互相穿过

把 $n$ 只蚂蚁换成 $n$ 只**虚拟蚂蚁**（幽灵）$G_i$：$G_i$ 从 $a_i$ 出发、永远以速度 $b_i$ 直行、互相穿过，$s$ 时刻位置
$$g_i(s)=a_i+b_is .$$
每只 $G_i$ 的世界线是直线 $L_i$。

**引理 1（位置多重集不变）** 对任意时刻 $s\ge0$，真实蚂蚁的位置**多重集**等于虚拟蚂蚁的位置多重集：
$$\{\!\!\{\,x_{A_1}(s),\dots,x_{A_n}(s)\,\}\!\!\}=\{\!\!\{\,g_1(s),\dots,g_n(s)\,\}\!\!\} .$$

**证明（世界线折返双射）：**

1. **相触点的结构**：$L_i$ 与 $L_j$（$i\ne j$）相交 $\iff b_i\ne b_j$ 且 $s^*=\frac{|a_i-a_j|}{2}>0$。$b_i=b_j$ 时两线平行且不重合（$a_i\ne a_j$，题面保证），**永不相交**；$b_i\ne b_j$ 时斜率相反，**恰相交一次**。所以任一相触点 $P=(x^*,s^*)$ 处恰有 $2$ 条线穿过：一条 $\nearrow$（速度 $+1$）、一条 $\swarrow$（速度 $-1$），且 $x^*=\frac{a_i+a_j}2$。过 $P$ 的四条半支为：$\nearrow$ 入（$s<s^*$ 那段）、$\nearrow$ 出（$s>s^*$ 那段）、$\swarrow$ 入、$\swarrow$ 出。
2. **折返配对 = 把线串成折线**：在 $P$ 处规定"入 $\nearrow$ 接 出 $\swarrow$"、"入 $\swarrow$ 接 出 $\nearrow$"，即每条半支到达 $P$ 后按原路折回。这个配对是四条半支上的**无不动点对合**，所以：沿任意一条线从 $s=0$ 出发，每到一处相触点就被确定地送到另一条线上，向前、向后都唯一，且不会走进无限循环（时间单调、相触点只有有限个），最终回到 $s=0$ 的某个端点。于是 $n$ 条直线被重新割串成**恰 $n$ 条折线** $\Gamma_1,\dots,\Gamma_n$（端点数守恒：每条折线在 $s=0$ 有且只有一个端点，$n$ 条折线占满 $n$ 个端点，构成端点集到折线集的双射）。
3. **折线就是真实轨迹**：沿 $\Gamma$ 读出的运动是"以速度 $\pm1$ 匀速走，到相触点与另一条折线同时到达同一位置、然后双方斜率取反"——这正是题面的掉头规则。反过来，真实过程是**确定性**的：给定 $s$ 时刻各蚁位置与朝向，$s$ 之后哪两只先相遇、在哪一点相遇都可算出（比较所有"左者 $\nearrow$、右者 $\swarrow$"的对的到达时刻 $\frac{a_j-a_i}{2}$ 取最小），且由第 1 步同位置不可能有第三只参与、同时刻的多处碰撞涉及的蚂蚁对互不相交（否则某条折线要在同一时刻位于两个位置），因此各次掉头互不干扰。规则相同 + 初始状态相同 + 解唯一 ⇒ 折线集合与真实世界线集合**相同**，从而每个时刻的位置多重集相等。$\blacksquare$

**注（为什么这一步不是同义反复）**：第 2 步构造的对象是"穿透线被重新串起来"，第 3 步才是"串起来的东西满足掉头规则"。若不明确第 1 步"三线共点不可能"，折返配对在三点共点处就不是对合（三条线六条半支，谁接谁没有唯一规则），整个双射会失效——这正是本引理最需要写清楚的地方。

**引理 2（顺序不变量 / 身份的双射）** 把蚂蚁按初始位置从小到大排得"秩" $\operatorname{rk}(i)\in\{0,\dots,n-1\}$。则对任意 $s\ge0$，真实蚂蚁位置从小到大排序后，第 $k$ 小的位置属于秩为 $k$ 的那只蚂蚁。

**证明：** 由引理 1，真实世界线就是折线 $\Gamma_1,\dots,\Gamma_n$，且 $\Gamma$ 在 $s=0$ 的端点与 $a_i$ 一一对应（第 2 步端点双射）。

**断言**：任意两条折线不穿过彼此。证明分两小步。设 $\Gamma,\Gamma'$ 是两条不同折线，差 $d(s)=x_\Gamma(s)-x_{\Gamma'}(s)$ 分段线性故连续，零点恰是二者相触的时刻（至多有限个，因为相触时刻集 $\subseteq$ 虚拟线交点时刻集，$\le\binom n2$）。

1. **相邻两零点之间符号不变**：$d$ 在不含零点的开区间上连取不变号，显然。
2. **穿过一个零点也不变号**：设 $s_0$ 是二者的一次相触、位置 $x^*$。按第 2 步的折返配对，两条线在此"各自原路折回"，故必有一条是"从左来"（来向斜率 $+1$、去向 $-1$），另一条是"从右来"（$-1\to+1$）；记前者 $L$、后者 $R$，$\{L,R\}=\{\Gamma,\Gamma'\}$。取 $\epsilon$ 小于两侧最近的其它相触时刻距离，则
$$s\in(s_0-\epsilon,s_0):\;x_L=x^*-(s_0-s)<x^*<x^*+(s_0-s)=x_R;\qquad s\in(s_0,s_0+\epsilon):\;x_L=x^*-(s-s_0)<x^*<x^*+(s-s_0)=x_R .$$
即**同一条**折线 $L$ 在相触前后都在左、$R$ 都在右，$x_L-x_R=-2|s-s_0|<0$ 两侧同号。所以 $d$ 在 $s_0$ 左右符号相同。

由 1、2，$d$ 的符号在整个 $[0,\infty)$ 上（除去零点）恒定。反设 $x_\Gamma(s_1)<x_{\Gamma'}(s_1)$ 而 $x_\Gamma(s_2)>x_{\Gamma'}(s_2)$（$s_1<s_2$），则 $d(s_1)<0<d(s_2)$，符号改变，矛盾。故断言成立：**折线只相触、不相穿**，且"谁在左"这件事一经确定就永远不变。

由断言，"$\Gamma$ 在 $\Gamma'$ 左边"这一关系对时间恒成立，因此从左到右读折线的顺序与 $s=0$ 时的顺序完全一致；而 $s=0$ 时位置两两不同（题面），按 $a$ 的名次就是按 $0$ 时刻位置的名次。故任意 $s$ 时刻第 $k$ 小的位置属于初始名次为 $k$ 的那只。$\blacksquare$

**等价说法（身份标签视角，便于记忆与写模拟）**：把"编号"想成一张可以撕下来重贴的标签。让所有蚂蚁**直接互相穿过**（虚拟模型），但在两蚁相遇的瞬间**交换它们身上的标签**而不是交换运动方向。两个模型逐时刻给出**完全相同的带标签点集**：相遇前，自左而来的点携标签 $A$ 右行、自右而来的点携标签 $B$ 左行；穿过之后，继续右行的那个点是"自左而来"的那一个，把标签换到**对方**身上就意味着 $A$ 现在挂在**左行**的点上、$B$ 挂在右行的点上 —— 即 $A$ 从此向左走、$B$ 从此向右走，与掉头模型里"$A$ 掉头变左行、$B$ 掉头变右行"一字不差。而在虚拟模型里点从不交换左右次序（只是彼此穿过），所以"标签落在哪个名次格上"从 $s=0$ 起就不会再变：标签 $\operatorname{rk}=k$ 永远停在位置第 $k$ 小的格子里。这正是引理 2 的另一套语言，也是代码里 `rk[]` 这张表的含义。

**两引理合并即正解骨架**：$t$ 秒后秩 $k$ 的位置 $=$ 把所有 $g_i(t)=a_i+b_it$ 从小到大排序后的第 $k$ 个。身份问题彻底消解成"两次排序 + 名次映射"；引理 2 就是把"编号 $\to$ 位置下标"钉死的那张双射表。

### 2.4 朝向：秩与斜率的同步置换

光有位置还不够，本题还要输出朝向，而且允许 $0$。这一步比位置更容易写错，所以单独证明。

**引理 3（同一时空点至多 2 只蚂蚁）** 任意时刻，处于同一位置的蚂蚁至多 $2$ 只；若恰 $2$ 只，二者朝向必分别为 $+1$ 与 $-1$。

**证明：**
- **虚拟侧**：设 $n$ 条线中有两条同速（都 $+1$ 或都 $-1$）过 $(x,s)$，则 $a=x-s$（或 $a=x+s$）被两只蚂蚁同时取到，与"$a_i$ 两两不同"矛盾。故过任一时空点的线至多一 $\nearrow$ 一 $\swarrow$，即 $\le2$ 条，且为 $2$ 条时速度相反。
- **真实侧**：由引理 1，任意时刻真实位置的多重集与虚拟位置的多重集**完全相同**。若三只真实蚂蚁同处 $x$，则该多重集含 $x$ 三次，于是有三条虚拟线过 $(x,s)$，与上一段的"$\le2$ 条"矛盾。故真实侧同样至多 $2$ 只。
- **恰两只时速度必相反**：设 $s$ 时刻恰有两只同位 $x$。相触时刻集有限（引理 1 第 1 步），故可取 $\epsilon>0$ 使 $[s-\epsilon,s)$ 内无任何相触，于是这两只在 $[s-\epsilon,s)$ 上各自匀速，斜率记 $v_1,v_2\in\{+1,-1\}$，位置为 $x-(s-\sigma)v_1$、$x-(s-\sigma)v_2$（$\sigma\in(0,\epsilon]$）。若 $v_1=v_2$ 则二者在 $[s-\epsilon,s)$ 上**恒同位**，这与"$[s-\epsilon,s)$ 内无相触"矛盾。故 $v_1\ne v_2$，即一只自左撞来（$+1$）、一只自右撞来（$-1$）——这正是"相遇即掉头"在真实模型里总能执行、且折返配对不产生歧义的物理依据。

**注**：本引理虚拟侧的证明只用到"$a_i$ 两两不同"，独立成立；真实侧直接引用引理 1 的多重集相等，不循环。它是引理 1 第 2 步"折返配对是无不动点对合"的前提（三点共点时六条半支谁接谁没有唯一规则），也是引理 4 归纳中"各秩对互不相邻"的依据，同时保证代码里"同值组大小 $>1$ 判 $0$"永远面对的是恰好 $2$ 个成员。

**引理 4（方向 = 同秩虚拟蚂蚁的速度；同位则为 $0$）** 把所有相触（掉头）时刻从小到大记为 $s_1<s_2<\dots<s_m$；由引理 1，真实相触时刻集与虚拟线相交时刻集相同，故 $m\le\binom n2$ 有限、归纳良基。若 $s\notin\{s_1,\dots,s_m\}$，把虚拟蚂蚁按 $g_i(s)$ 升序排，第 $k$ 位的速度记 $v_k(s)$，则真实蚂蚁中秩 $k$ 的那只在 $s$ 时刻的朝向就是 $v_k(s)$。若 $s=t=s_j$，则参与该次碰撞的两个秩的朝向都记为 $0$（题面"正在转向中"）。

**证明（对 $j$ 归纳）：**
- **基**：$0<s<s_1$ 无任何掉头、也无任何线相交，真实蚂蚁位置就是 $a_i+b_is$、朝向 $b_i$；虚拟侧因无交点，按 $g(s)$ 排序与按 $a$ 排序是同一个排列，故第 $k$ 位就是秩 $k$ 的那条线，$v_k(s)=b_{\text{秩 }k}$，逐位吻合。
- **步**：设在 $(s_j,s_{j+1})$ 上结论成立。$s_{j+1}$ 时刻发生 $\rho\ge1$ 次碰撞。由引理 3 每次恰 $2$ 只同位；由"一只蚂蚁同一时刻只有一个位置"，这 $\rho$ 对蚂蚁两两不交，从而涉及的秩对 $\{k,k+1\}$ 互异且不相邻（碰撞必发生在相邻秩之间：二者同位即为位置第 $k$、第 $k+1$，由引理 2 的序保性）。取其中一对 $(k,k+1)$：
  - **真实侧**：两只掉头 ⇒ 秩 $k$ 的速度由 $+1$ 变 $-1$、秩 $k+1$ 由 $-1$ 变 $+1$，即 $v$ 表这两格的值互换。
  - **虚拟侧**：这两只所在的线恰在此刻相交（点集相同，引理 1），相交前 $\nearrow$ 线在左、$\swarrow$ 线在右；相交后左右互换 ⇒ 排序时这两条线在第 $k,k+1$ 两格上对调，同样是"两格值互换"。
  - 两侧执行**同一个相邻对换**，其余秩不受影响；$\rho$ 个对换涉及的格两两不同，故可交换次序、同时刻不冲突。于是 $(s_{j+1},s_{j+2})$ 上结论仍成立。
- 相触时刻集有限且良序，归纳覆盖所有区间；$s=t$ 落在某 $s_j$ 时，该对两格按定义输出 $0$。$\blacksquare$

**$0$ 的判据为什么与秩表自洽**：$t=s_j$ 时，第 $k$ 格与第 $k+1$ 格的 $g$ 值相同（就是那个碰撞位置），我们的做法是"同值组整体置 $0$"。以下三点同时成立才算严格：① 组内两只确实正在相撞（$t$ 是相触时刻 $\iff$ 有两条虚拟线在 $t$ 相交 $\iff$ 某两个 $g_i(t)$ 相等；引理 1 保证点集一致）；② 组外的秩不受影响（同值组大小只可能是 $2$，不同组位置不同，引理 3）；③ 组内两格的**先后顺序无所谓**（位置相同、朝向都取 $0$，两格输出完全一样）。第③点解释了"为什么同值组必须输出 $0$ 而不能输出 $b$"：引理 4 的归纳在 $s=t$ 这一瞬间本来就断掉了（$v_k,v_{k+1}$ 正在被交换，哪个归 $k$ 没有定义），而题面用"正在转向中 $=0$"恰好把这个自由度封成唯一答案。**若题面是不掉头而是穿过，就没有这个自由度**——这也是"身份不可区分、只问位置集合"的经典版本能用同一骨架却完全不需要 $0$ 的原因。

**一个必须排除的错误直觉**：有人会写"编号 $i$ 的朝向就是它自己那条虚拟线的 $b_i$"。错，反例见 §2.2(c)：编号 1 在 $t=2$ 时朝 $-1$，而它的虚拟线斜率是 $b_1=+1$。正确的对应是**按名次取速度**（秩 $k$ 查第 $k$ 格），不是按编号。

### 2.5 退化情形清单（逐条给出判据与推导）

| 情形 | 结论 / 处理 | 依据 |
|---|---|---|
| $t$ 恰是某次碰撞时刻 | 参与的两只位置相同、朝向都取 $0$ | 引理 4 补充定义 + 同值组判据 |
| 三只及以上同位 | **不可能** | 引理 3（本质是"$a_i$ 两两不同"） |
| 同值组内两格速度相同 | **不可能**：$a_i+b_it=a_j+b_jt$ 且 $b_i=b_j$ $\Rightarrow$ $a_i=a_j$ | 引理 3 虚拟侧 |
| 同一时刻多处碰撞 | 涉及蚂蚁两两不交、秩对互异，排序天然处理，$\rho$ 个对换可交换 | 引理 3 + 引理 4 归纳步 |
| $t=0$ | $g_i=a_i$ 两两不同 ⇒ 无 $0$，输出即 $a_i,b_i$ | 引理 4 基例 |
| $n=1$（或全体同向） | 无碰撞，逐只输出 $a_i+b_it,\ b_i$ | 同速线不相交 |
| 迎面一对、初始间距为**奇数** | 相遇时刻 $\frac{\text{间距}}2$ 是半整数、位置也是半整数 ⇒ 任何整数 $t$ 都不同位 ⇒ **永不输出 $0$**；两次排序自动给出掉头后的身份 | 见下行推导 |
| 整数时刻出现 $0$ 的条件 | $g_i=g_j$（$i<j$，$b_i=+1,b_j=-1$）$\iff a_j-a_i=2t$，右边恒偶 ⇒ 只有偶间距、且恰在 $t$ 秒撞上才出 $0$ | $a_i+t=a_j-t$ 移项 |
| 位置会不会是非整数 | 不会：折线每段形如 $a\pm s$，$t\in\mathbb Z$ ⇒ 位置整数（与"半整数处折返"自洽，如 §4.3 算例 2） | 引理 1 的折线表达 |
| 输入 $a_i$ 乱序、有负坐标 | 排序即离散化名次，与输入顺序无关；`int` 带符号处理 $-2\times10^6$ | §2.6 步骤 2 |
| 秩表与输出表的对应 | 第 $i$ 行输出用 `rk[i]`（$0$-based），**不是** `i` 本身 | 引理 2 |

### 2.6 落地：两次排序 + 名次映射

1. 读入时立刻算 $g_i=a_i+b_it$。
2. 按 $a$ 排序 → 得到秩表 `rk[id]=名次`。
3. 按 $g$ 排序（同值再按 $b$，只为确定性）→ 第 $k$ 项给出秩 $k$ 的位置与速度候选。
4. 线性扫同值组：组大小 $>1$ 则组内全部朝向 $0$，否则朝向 $=b$。
5. 按输入编号输出 `pos[rk[i]] , dir[rk[i]]`。

**溢出预算**：唯一算术量 $g_i=a_i+b_it$，$\lvert g_i\rvert\le2\times10^6+10^5=2.1\times10^6$，而 $\texttt{int}$ 上界 $2\,147\,483\,647\approx2.1\times10^9$，余量 $\approx1022$ 倍；中间量 $b_it$ 绝对值 $\le10^5$ 更早满足。全过程只有比较、无累加、无乘法放大 ⇒ `int` 足够，**本题不需要 `using i64=long long;`**。

**复杂度算式**：排序 $2\cdot n\log_2 n$ 次比较，$n=10^5$、$\log_2 10^5\approx16.6$ $\Rightarrow$ $\approx3.3\times10^6$；线性扫描与输出各 $O(n)=10^5$。总计 $\approx3.5\times10^6$ 基本运算，远低于常见 $10^8$ 量级时限预算；对比朴素模拟 $nt=10^{10}$。空间 $O(n)$：两份 `ant`(16B) 数组 $\approx3.2$MB + `rk,pos,dir` $\approx1.2$MB $\approx4.4$MB。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 把"相遇即掉头"画成时空平面上的折线：相触后各自折返，两线只碰不穿。
- **consider easier version** — 先逐秒模拟（$80\%$ 部分分），同时发现"半整数碰撞"这个模拟本身的坑。
- **counterexample hunting** — 用 $n=2,t=2$、间距 $3$ 的反例证明"身份直接代入 $a_i+b_it$"错在身份与朝向，而位置多重集没错。
- **classic problem solution（第 1 次）** — 碰撞等价于穿透 + 身份按秩序保号（引理 1、2 的折返对合与不相交证明）。
- **degeneracy characterization** — 同速线永不交 ⇒ 任一时空点至多 2 条线 ⇒ 无三线共点、无"两只同速同位"（引理 3）。
- **classic problem solution（第 2 次）** — 对碰撞时刻归纳、两侧执行同一相邻对换，得到"秩↔速度"同步置换，从而朝向同表可查（引理 4）。
- **reduce to easier problem** — 问题塌缩成"两次排序 + 名次映射 + 同值组判 $0$"，$O(n\log n)$。
- **boundary bookkeeping** — $t=0$、$n=1$、奇间距、同时多处碰撞、整数时刻出现 $0$ 的偶数判据。

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 备注 |
|---|---|---|---|
| `n,t` | 蚂蚁数、时间 | `int`，读入 | $n\le10^5$，$t\le10^5$ |
| `ant{a,b,g,id}` | 原始位置 / 原始朝向 / 穿透假设下 $t$ 秒位置 $a+b\cdot t$ / 输入编号 | 结构体，读入即算 `g` | `id` 用于还原身份 |
| `p[mxn]` | $n$ 只蚂蚁的表 | 读入填充 | 随后被按 `a` 排序 |
| `q[mxn]` | `p` 的副本 | `copy(p,p+n,q)` | 随后被按 `g` 排序 |
| `rk[id]` | 编号 `id` 的蚂蚁的**秩**（按初始位置的名次，0-based） | 排 `p` 后写 | 引理 2：秩永不改变 |
| `pos[k],dir[k]` | 秩 $k$ 在 $t$ 秒后的位置、朝向 | 扫 `q` 时写 | `dir=0` ⟺ 恰在相撞 |
| `mxn` | 数组上界 | `constexpr int{100005}` | $10^5+5$ |

### 4.2 算法步骤

1. 读 $n,t$；对 $i=0..n-1$ 读 $a_i,b_i$，置 `p[i]={a,b,a+b*t,i}`。
2. `sort(p,p+n, 按 a 升序)`；令 `rk[p[k].id]=k`（引理 2 保证这就是 $t$ 秒后的名次）。
3. `copy(p,p+n,q)`；`sort(q,q+n, 按 g 升序、同值按 b 升序)`。
4. 双指针扫 `q` 的同 `g` 值组 $[l,r)$：`pos[k]=q[k].g`；`dir[k]=(r-l>1?0:q[k].b)`（引理 3、4）。
5. 对 $i=0..n-1$：`k=rk[i]`，输出 `pos[k]` 与 `dir[k]`。

**复杂度**：时间 $O(n\log n)$（$\approx3.5\times10^6$ 次操作），空间 $O(n)$（$\approx4.4$MB）。**验证状态**：仅 §4.3 手算 7 组算例，未运行程序、未对拍。

### 4.3 验证状态（手工推演，未运行任何代码）

> 题面无样例 ⇒ **无法与官方答案对标**；下列为自造算例**手算**，其中 6 组含退化情形；全程未编译、未运行、未对拍。每组先手算真实过程，再按 §4.2 五步走一遍，两侧必须逐字一致。

1. **迎面、偶间距、正好相撞于 $t$（退化：同值组）**：$n=2,t=2$，$(0,+1),(4,-1)$。$g=\{2,2\}$，同值组大小 $2$ ⇒ 秩 0、1 都取位置 $2$、朝向 $0$。真实：两蚁在 $t=2$ 于位置 $2$ 相遇、正在转向 ✓。**应输出** `2 0` / `2 0`。
2. **迎面、奇间距（退化：半整数碰撞，$0$ 不该出现）**：$n=2,t=2$，$(0,+1),(3,-1)$。$g_1=0+2=2$、$g_2=3-2=1$，排序 $[(1,-1),(2,+1)]$，无同值 ⇒ 秩 0（编号 1，$a=0$）位置 $1$ 朝 $-1$；秩 1（编号 2）位置 $2$ 朝 $+1$。**应输出** `1 -1` / `2 1`。真实：$t=1.5$ 在 $1.5$ 掉头，之后编号 1 向左走 $0.5$ 到 $1$、编号 2 向右走 $0.5$ 到 $2$ ✓（此例正是 §2.2(c) 的反例：少了"走秩"就会两只都错）。
3. **三只、两次先后碰撞（链式，非退化基线）**：$n=3,t=4$，$(0,+1),(4,-1),(7,-1)$。$g=\{4,0,3\}$，排序 $[(0,-1),(3,-1),(4,+1)]$，秩即初始名次（$0<4<7$）⇒ 编号 1 位置 $0$ 朝 $-1$；编号 2 位置 $3$ 朝 $-1$；编号 3 位置 $4$ 朝 $+1$。**应输出** `0 -1` / `3 -1` / `4 1`。真实：$t=2$ 时 1、2 在 $2$ 相撞（1 变左、2 变右）；$t=3.5$ 时 2、3 在 $3.5$ 相撞（2 变左、3 变右）；$t=4$：1 在 $2-2=0$ ✓，2 在 $3.5-0.5=3$ ✓，3 在 $3.5+0.5=4$ ✓。
4. **同值组的秩歧义（关键退化：组内两格速度相反）**：$n=3,t=2$，$(0,+1),(2,+1),(4,-1)$。$g=\{2,4,2\}$，排序 $[(2,-1),(2,+1),(4,+1)]$，前两位同值 ⇒ 秩 0、1 位置 $2$、朝向都 $0$；秩 2 位置 $4$ 朝 $+1$。**应输出** `2 0` / `2 0` / `4 1`。真实：$t=1$ 时 2、3 在 $3$ 相撞（2 变左、3 变右）；$t=2$ 时 1、2 在 $2$ 相撞 ⇒ 位置 $2,2,4$、朝向 $0,0,+1$ ✓。此例说明"同值组一律判 $0$"如何同时消掉排序歧义（$-1$ 与 $+1$ 谁排前都一样）与身份歧义。
5. **同一时刻两处独立碰撞（退化：$\rho=2$）**：$n=4,t=1$，$(0,+1),(2,-1),(6,+1),(8,-1)$。$g=\{1,1,7,7\}$ ⇒ 两个同值组，四格朝向全 $0$，位置 $1,1,7,7$。**应输出** `1 0` / `1 0` / `7 0` / `7 0`。真实 ✓。同一输入取 $t=2$：$g=\{2,0,8,6\}$，排序 $[(0,-1),(2,+1),(6,-1),(8,+1)]$，无同值 ⇒ 输出 `0 -1` / `2 1` / `6 -1` / `8 1`，与"两对各自掉头后散开"（1 左行、2 右行、3 左行、4 右行）逐只一致 ✓。
6. **$t=0$ 退化（含输入乱序、负坐标）**：$n=2,t=0$，$(5,-1),(-3,+1)$。$g=\{5,-3\}$，无同值；名次：编号 1（$a=5$）秩 1，编号 2（$a=-3$）秩 0。**应输出** `5 -1` / `-3 1` ✓（$t=0$ 必为恒等，是引理 4 基例的直接检验）。
7. **$n=1$ 与溢出边界**：$n=1$，$(a,b)=(-2\,000\,000,-1)$，$t=100\,000$ ⇒ $g=-2\,100\,000$，秩 0 唯一、无同值 ⇒ **应输出** `-2100000 -1`。$\lvert g\rvert=2.1\times10^6$ 与 $\texttt{int}$ 上界 $2.1\times10^9$ 对比，确认 §2.6 的溢出预算；$n=1$ 不可能碰撞，恒不产生 $0$ ✓。

## 5. 示例代码（C++）

```cpp
// P1367 蚂蚁
// 碰撞 == 互相穿过（世界线折返对合）+ 秩序不变量 => 位置/朝向都由"按 g=a+b*t 排序"的名次表查
// 同一位置有两只 <=> 这一瞬间正在相撞 <=> 朝向 0
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};                //n<=1e5 +5

struct ant
{
	int a,b,g,id;
};

int n,t;
ant p[mxn],q[mxn];
int rk[mxn],pos[mxn],dir[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>t;
	for(int i=0;i<n;++i)
	{
		cin>>p[i].a>>p[i].b;
		p[i].g=p[i].a+p[i].b*t;            //穿透假设下 t 秒后的位置，|g|<=2.1e6
		p[i].id=i;
	}

	sort(p,p+n,[](const ant&x,const ant&y){return x.a<y.a;});
	for(int k=0;k<n;++k)
		rk[p[k].id]=k;                       //引理 2：秩从 t=0 到 t 都不变

	copy(p,p+n,q);
	sort(q,q+n,[](const ant&x,const ant&y){return x.g!=y.g?x.g<y.g:x.b<y.b;});

	for(int l=0,r;l<n;l=r)                   //按同位置分组，至多 2 只一组（引理 3）
	{
		r=l+1;
		while(r<n&&q[r].g==q[l].g)
			++r;
		for(int k=l;k<r;++k)
		{
			pos[k]=q[k].g;
			dir[k]=r-l>1?0:q[k].b;           //组大小>1 <=> t 瞬间正在相撞
		}
	}

	for(int i=0;i<n;++i)
	{
		int k=rk[i];
		cout<<pos[k]<<' '<<dir[k]<<'\n';     //按输入编号还原身份
	}
	return 0;
}
```

**代码要点**

- 全局静态数组 + `constexpr int mxn{100005}`（上界 +5）；排序比较器写成 lambda；`cin.tie/cout.tie/ios::sync_with_stdio` 顺序固定；`'\n'` 收尾、不用 `endl`；运算符不加空格、缩进用 Tab。
- 内部**全 0-based**：`id` 取读入序号 $0\dots n-1$，秩 $k$ 也 0-based，最后按 $i=0\dots n-1$ 顺序输出，正好对应题面第 $i+1$ 行，因此**不需要 ±1 转换**。
- 两份数组 `p,q` 各自排序、互不覆盖：`p` 提供"按 $a$ 的名次表 `rk`"，`q` 提供"按 $g$ 的位置/速度表"，两者共用同一个下标空间 $0\dots n-1$，这就是引理 2 的直接翻译。
- 分组扫描用 `while(r<n&&q[r].g==q[l].g)` 双指针而非 `upper_bound`：一次线性扫描完成，且判据写成"组大小 $>1$"而不是"与邻居相等"，即使题面哪天允许三只同位也不会失效。
- 若去掉 `rk[]` 而直接按 `i` 输出 `q[i]`，得到的正是 §2.2(c) 的错误答案；这张表是本题唯一的"身份陷阱"，自查时优先核对它。
