# P1713 麦当劳叔叔的难题

## 1. 重新读题

在一个 $n \times n$（$2 \le n \le 10$）的方格矩阵中，有 $m$（$0 \le m \le 100$）个障碍格不可通行。起点位于矩阵的**左下角** $(n, 1)$，终点（大门）位于**右上角** $(1, n)$。

每秒钟可以向上、下、左、右移动一格，且**每个格子最多只能经过一次**（即只能走简单路径）。定义“最聪明的小朋友”走的是从起点到终点的**最短简单路径**，“最不聪明的小朋友”走的是从起点到终点的**最长简单路径**。求最长简单路径与最短简单路径的到达时间之差。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：最短路与最长路的本质差异，以及坐标翻转技巧

首先明确“到达时间差”的代数表达式：每走一步耗时 $1$ 秒，若一条简单路径经过了 $L$ 个格子，则移动步数（耗时）为 $L - 1$。设最长简单路径包含 $L_{\max}$ 个格子、最短简单路径包含 $L_{\min}$ 个格子，则最大时间差为
$$(L_{\max} - 1) - (L_{\min} - 1) = L_{\max} - L_{\min}.$$

把问题一分为二：
1. **求最短路 $L_{\min}$**：边权全为 $1$ 的网格最短路径天然是简单路径（若有环，删去环后路径更短），直接跑一次 $O(n^2)$ 的 BFS 即可求出 $L_{\min}$。
2. **求最长简单路径 $L_{\max}$**：无向图最长简单路径是 NP-hard 问题，但本题 $n \le 10$，网格宽度极小！这正是**轮廓线插头 DP（Plug DP）**的标准舞台。

在写插头 DP 前，先做一个极其省心的几何变换：
原题起点在左下角 $(n, 1)$、终点在右上角 $(1, n)$。如果我们把整个矩阵**上下翻转**，即令新行号 $r = n - x$、新列号 $c = y - 1$（0-based），那么：
- 网格的上下左右相邻关系完全保持不变（图同构）；
- 原左下角起点 $(n, 1)$ 变成了**左上角第一个格子 $(0, 0)$**；
- 原右上角终点 $(1, n)$ 变成了**右下角最后一个格子 $(n-1, n-1)$**！

### 2.2 为什么把起点移到 $(0, 0)$、终点移到 $(n-1, n-1)$ 能大幅简化插头 DP？

在一般的网格简单路径插头 DP 中，因为起点和终点可能出现在网格中间，轮廓线上可能同时存在 $0, 1, 2$ 个“单端独立插头”（一端连着起点或终点、另一端悬在轮廓线上），不仅要区分常规括号插头 `(` / `)`，还要处理两个独立插头中途相撞提前闭合的非法情况。

但经过上下翻转后，**起点 $(0, 0)$ 是逐行逐列扫描的第一个格子，终点 $(n-1, n-1)$ 是扫描的最后一个格子**！

**引理 1（单独立插头不变量）**：将起点置于 $(0, 0)$、终点置于 $(n-1, n-1)$ 后，在任意中间时刻（已处理完 $(0, 0)$、尚未处理 $(n-1, n-1)$），轮廓线上的非空插头由**至多一个**与 $(0, 0)$ 相连的“独立插头”（编码为 `3`）以及若干对相互匹配的“括号插头”（左括号编码为 `1`、右括号编码为 `2`）组成；且一旦独立插头 `3` 消失，路径就永远无法延伸到 $(n-1, n-1)$，因此合法状态在中间时刻**恒有恰好一个 `3` 插头**。

**证明**：
把轮廓线看作已扫描区域 $S$ 与未扫描区域 $\bar{S}$ 的分割线。在最终的 $(0, 0) \to (n-1, n-1)$ 简单路径 $P$ 中，将其限制在已扫描子图 $S$ 上，会断裂成若干条互不相交的简单路径段：
- 包含起点 $(0, 0)$ 的那一段：一端固定在 $(0, 0) \in S$，另一端必须穿过轮廓线进入 $\bar{S}$（因为终点 $(n-1, n-1) \in \bar{S}$），故它在轮廓线上恰好产生**唯一一个**度数为 $1$ 的插头（记为 `3`）；
- 其余不包含 $(0, 0)$ 的路径段：两端都必须穿过轮廓线进入 $\bar{S}$。由于平面网格上的路径互不交叉，这些成对端点的配对关系满足非交叉括号序，可唯一编码为左括号 `1`（左端）与右括号 `2`（右端）。
因此，任何中间轮廓线状态都恰好含有一个 `3` 插头和若干对匹配的 `(1, 2)` 括号插头。$\blacksquare$

### 2.3 完整插头转移分类与证明

设当前处理格子 $(i, j)$，其左插头（轮廓线第 $j$ 位）为 $p_1 \in \{0, 1, 2, 3\}$，上插头（轮廓线第 $j+1$ 位）为 $p_2 \in \{0, 1, 2, 3\}$。先将轮廓线第 $j, j+1$ 位清零得到基准状态 `base`。

**引理 2（逐格状态转移完备性）**：
1. **障碍格 `blk[i][j] == true`**：不能有插头进入该格，故仅当 $p_1 = 0 \land p_2 = 0$ 时合法，新状态为 `base`，格数不变。
2. **起点 $(0, 0)$**：必有 $p_1 = p_2 = 0$，起点度数为 $1$，发出独立插头 `3` 向右（第 $1$ 位设为 `3`）或向下（第 $0$ 位设为 `3`），格数 $+1$。
3. **终点 $(n-1, n-1)$**：必须吸收唯一剩下的独立插头 `3` 且其余轮廓线全为 $0$，即 $(p_1, p_2) \in \{(3, 0), (0, 3)\}$ 且 `base == 0`，格数 $+1$ 后更新全局答案 `ans`。
4. **普通可通行格 $(i, j)$**：
   - **不经过该格**：仅当 $p_1 = 0 \land p_2 = 0$ 时可选，状态保持 `base`，格数不变；
   - **新建一段折线**（$p_1 = 0 \land p_2 = 0$）：经过该格并向右下发出新括号对，下插头设 `1`、右插头设 `2`，格数 $+1$；
   - **延续单个插头**（$p_1 = 0 \oplus p_2 = 0$，设非零者为 $p = p_1 + p_2$）：将该插头导向下方（第 $j$ 位设 $p$）或右方（第 $j+1$ 位设 $p$），格数 $+1$；
   - **合并两个插头**（$p_1 > 0 \land p_2 > 0$）：
     - 若 $(p_1, p_2) = (1, 1)$：两个左括号合并，对应的两个右括号中靠左的那一个（从 $j+1$ 向右匹配找到的 `2`）变成外层左括号 `1`；
     - 若 $(p_1, p_2) = (2, 2)$：两个右括号合并，对应的两个左括号中靠右的那一个（从 $j$ 向左匹配找到的 `1`）变成外层右括号 `2`；
     - 若 $(p_1, p_2) = (2, 1)$：前一段的右端与后一段的左端拼接，直接消去两个插头（状态变为 `base`），不改变其余括号配对；
     - 若 $(p_1, p_2) = (1, 2)$：同一括号对的两端在中间格闭合会形成孤立环，非法，直接舍弃；
     - 若 $\{p_1, p_2\} = \{3, 1\}$ 或 $\{3, 2\}$：独立插头 `3` 与某段括号路径的一端拼接，则该括号路径的另一端（通过括号匹配找到的位置 $k$）继承独立插头属性，变为 `3`！

**证明**：以上各分支按格子 $(i, j)$ 在路径中的度数（起点/终点度数 $1$，内部经过格度数 $2$，不经过格度数 $0$）穷尽了所有合法局部连接方式，且在合并两段路径时精确维护了轮廓线端点的连通配对关系与引理 1 的不变量。$\blacksquare$

## 3. 模式总结（Pattern Summary）

- **explore its property** — 将最大到达时间差化简为最长简单路径格数 $L_{\max}$ 与最短路格数 $L_{\min}$ 之差。
- **coordinate reflection** — 通过上下翻转 $r = n - x, c = y - 1$ 将左下角起点、右上角终点同构映射为首格 $(0, 0)$ 与末格 $(n-1, n-1)$。
- **reduce state space** — 利用首尾端点位置证明轮廓线上始终恰有一个独立插头 `3` 和若干配对括号 `(1, 2)`（引理 1）。
- **classic problem solution** — 用 BFS 求 $L_{\min}$，用四进制轮廓线插头 DP 求 $L_{\max}$（引理 2）。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n, m` | `int` | 矩阵边长与障碍数量 | 标准输入 | 维度 |
| `blk[r][c]` | `bool [mxn][mxn]` | 上下翻转后格子 $(r, c)$ 是否为障碍 | 读入 $(x,y)$ 置 `blk[n-x][y-1]=1` | blocked |
| `dis[r][c]` | `int [mxn][mxn]` | 从 $(0, 0)$ 到 $(r, c)$ 的最短路格数 | 初值 `inf`，`dis[0][0]=1` | BFS distance |
| `cur, nxt` | `unordered_map<int,int>` | 插头 DP 的滚动哈希表：`mask -> 最大格数` | `cur[0] = 0` | plug DP tables |

### 4.2 算法步骤

1. 读入 $n, m$；每读入一个障碍 $(x, y)$，令 `blk[n - x][y - 1] = true`。
2. 调用 `bfs_min()`：从 $(0, 0)$ 运行四连通 BFS，返回到达 $(n-1, n-1)$ 的最短格数 `mn`。
3. 调用 `plug_max()`：
   - 用 $2(n+1)$ 位二进制数（每 $2$ 位表示一个四进制插头：`0` 空、`1` 左括号、`2` 右括号、`3` 起点连通端）表示轮廓线状态；
   - 换行时将所有满足最高位 `getp(mask, n) == 0` 的状态左移 $2$ 位（`mask << 2`）；
   - 按引理 2 枚举每个格子 $(i, j)$ 的状态转移，在 $(n-1, n-1)$ 处收集最大格数 `mx`。
4. 输出 `mx - mn`。

### 4.3 复杂度分析

- **时间复杂度**：当 $n \le 10$ 时，合法的含单个 `3` 与配对括号的轮廓线状态数每格不超过 $3000$ 个，总状态转移次数约 $10^5$ 量级，耗时 $< 10\text{ ms}$。
- **空间复杂度**：滚动哈希表最多存放数千个状态，空间复杂度为 $O(|S|)$（$< 1\text{ MB}$）。

## 5. 示例代码

```cpp
//
// 题目：P1713 麦当劳叔叔的难题
// https://www.luogu.com.cn/problem/P1713
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{12};
constexpr int inf{1145141919};

int n,m;
bool blk[mxn][mxn];
int dis[mxn][mxn];

int getp(int mask,int i){return (mask>>(i*2))&3;}
int setp(int mask,int i,int v){return (mask&~(3<<(i*2)))|(v<<(i*2));}

int find_match(int mask,int i,int dir)
{
	int bal=0;
	for(int k=i;;k+=dir)
	{
		int p=getp(mask,k);
		if(p==1)++bal;
		else if(p==2)--bal;
		if(bal==0)return k;
	}
}

int bfs_min()
{
	for(int i=0;i<n;++i)
		for(int j=0;j<n;++j)
			dis[i][j]=inf;
	queue<pair<int,int>>Q;
	dis[0][0]=1;
	Q.push({0,0});
	const int dx[4]={-1,1,0,0},dy[4]={0,0,-1,1};
	while(!Q.empty())
	{
		auto[x,y]=Q.front();Q.pop();
		for(int d=0;d<4;++d)
		{
			int nx=x+dx[d],ny=y+dy[d];
			if(nx>=0&&nx<n&&ny>=0&&ny<n&&!blk[nx][ny]&&dis[nx][ny]==inf)
			{
				dis[nx][ny]=dis[x][y]+1;
				Q.push({nx,ny});
			}
		}
	}
	return dis[n-1][n-1];
}

int plug_max()
{
	unordered_map<int,int>cur,nxt;
	cur[0]=0;
	int ans=-inf;
	for(int i=0;i<n;++i)
	{
		nxt.clear();
		for(auto[mask,val]:cur)
			if(getp(mask,n)==0)
			{
				int nmask=mask<<2;
				auto it=nxt.find(nmask);
				if(it==nxt.end()||val>it->second)
					nxt[nmask]=val;
			}
		cur.swap(nxt);

		for(int j=0;j<n;++j)
		{
			nxt.clear();
			auto upd=[&](int msk,int v){
				auto it=nxt.find(msk);
				if(it==nxt.end()||v>it->second)
					nxt[msk]=v;
			};
			for(auto[mask,val]:cur)
			{
				int p1=getp(mask,j),p2=getp(mask,j+1);
				int base=setp(setp(mask,j,0),j+1,0);
				if(blk[i][j])
				{
					if(p1==0&&p2==0)
						upd(base,val);
					continue;
				}
				if(i==0&&j==0)
				{
					if(p1==0&&p2==0)
					{
						upd(setp(base,j,3),val+1);
						upd(setp(base,j+1,3),val+1);
					}
					continue;
				}
				if(i==n-1&&j==n-1)
				{
					if((p1==3&&p2==0)||(p1==0&&p2==3))
						if(base==0)
							ans=max(ans,val+1);
					continue;
				}
				if(p1==0&&p2==0)
				{
					upd(base,val);
					upd(setp(setp(base,j,1),j+1,2),val+1);
				}
				else if(p1==0||p2==0)
				{
					int p=p1+p2;
					upd(setp(base,j,p),val+1);
					upd(setp(base,j+1,p),val+1);
				}
				else if(p1==1&&p2==1)
				{
					int k=find_match(mask,j+1,1);
					upd(setp(base,k,1),val+1);
				}
				else if(p1==2&&p2==2)
				{
					int k=find_match(mask,j,-1);
					upd(setp(base,k,2),val+1);
				}
				else if(p1==2&&p2==1)
				{
					upd(base,val+1);
				}
				else if(p1==3&&(p2==1||p2==2))
				{
					int k=find_match(mask,j+1,p2==1?1:-1);
					upd(setp(base,k,3),val+1);
				}
				else if(p2==3&&(p1==1||p1==2))
				{
					int k=find_match(mask,j,p1==1?1:-1);
					upd(setp(base,k,3),val+1);
				}
			}
			cur.swap(nxt);
		}
	}
	return ans;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,x,y;i<m;++i)
	{
		cin>>x>>y;
		blk[n-x][y-1]=true;
	}
	int mn=bfs_min();
	int mx=plug_max();
	cout<<mx-mn<<'\n';
	return 0;
}
```
