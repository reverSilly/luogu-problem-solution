# P1565 牛宫

> 标签：贪心 / 二分 / 前缀和 / 单调栈 · 难度：省选/NOI-
> 本地题面：`P1565.md`（$1\le N,M\le200$，$-2\times10^9\le a_{i,j}\le16315$）。
> 验证：`appendix/P1565/P1565_check.py` —— 官方样例输出 `4` 通过；350 组随机小规模用例标程与暴力逐字节一致；最坏 $N=M=200$ 耗时 $0.037$ s，全正数据答案 $40000$。

## 1. 重新读题

**问题重述（人话版）**

给定一个 $N\times M$ 的整数矩阵 $a$（每个格子是"海拔"）。要选出一块**非空的、边与网格对齐的矩形子矩阵**，使得这块矩形内所有格子的**平均海拔严格大于 $0$**（海平面为 $0$），并且这块矩形的**面积（格子数）尽量大**。输出这个最大面积；若不存在任何满足条件的非空矩形，输出 $0$。

> 一句话版本：**求面积最大的"元素和 $>0$"的子矩阵。**

**题面里容易漏掉的条款**

1. 「平均海拔在海平面之上」$\Rightarrow$ 平均 $>0$ 是**严格**不等式。面积恒为正数，所以"平均 $>0$"与"元素和 $>0$"等价（§2.1 引理 1）。写成"和 $\ge0$"会多算入和为 $0$ 的矩形，面积偏大。
2. 面积是**格子数**，即（行数 $\times$ 列数），不是行数或列数单独。
3. 允许输出 $0$：若矩阵里连一个正数格子都没有（例如全 $\le0$），任何子矩阵的和都 $\le0$，答案为 $0$。
4. 海拔可以低到 $-2\times10^9$，**列和、前缀和会到 $\pm10^{11}\sim10^{13}$ 量级**，必须用 $64$ 位整数（§2.6）。

**数据范围与规模感受**

$$1\le N,M\le 200,\qquad -2\times10^9\le a_{i,j}\le16315 .$$

行列都只有 $200$，提示"枚举上下边界"的 $O(N^2)$ 层数是可接受的（$40000$）；但**上下边界枚举后剩下的"找最大宽度"绝不能是 $O(M^2)$**，否则总复杂度 $O(N^2M^2)=200^2\cdot200^2\approx1.6\times10^9$ 会超时。把内层做到 $O(M\log M)$ 或 $O(M)$ 才是正解方向。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：先把"平均 $>0$"翻译成"和 $>0$"

设所选矩形含 $k$ 个格子（$k\ge1$），格子海拔之和为 $\Sigma$。

**引理 1（平均 $>0$ $\iff$ 和 $>0$）**

$\dfrac{\Sigma}{k}>0\iff\Sigma>0$。

**证明**：面积 $k\ge1>0$。在不等式两边同乘正数 $k$ 不改变不等号方向：$\dfrac{\Sigma}{k}>0\iff k\cdot\dfrac{\Sigma}{k}>0\iff\Sigma>0$。$\blacksquare$

> 这条引理把"平均值"这个除法彻底去掉了：题目只剩一个**纯加法**的目标——**和为正**。所有麻烦都源于格子可以是负数，使得"和为正"这件事不再是"格子都为正"。

### 2.2 考虑一维简化版（先解最简单的情形）

把矩阵砍成一行，问题变成：

> **一维版**：给定长度 $M$ 的数组 $c_0,\dots,c_{M-1}$，求**最长的连续子数组** $[l,r)$，使得 $\sum_{t=l}^{r-1}c_t>0$，返回其长度。

**为什么要先看一维版**：二维的"矩形"其实只是"某几行 + 某几列"。只要固定住"选哪些行"，每一列就只剩一个**列和**，整个矩形问题立刻坍缩成一维的"最长正和连续区间"。所以先攻克一维，再谈怎么把二维压成一维。

### 2.3 归约：枚举上下边界，把二维压成一维

固定选取的行区间为第 $top$ 行到第 $bot$ 行（$0\le top\le bot\le N-1$，行数 $h=bot-top+1$）。对每一列 $j$ 定义**列和**

$$c_j=\sum_{i=top}^{bot}a_{i,j}.$$

那么一个矩形（行区间固定为 $[top,bot]$、列区间为 $[l,r)$）的元素和恰好是 $\sum_{j=l}^{r-1}c_j$。于是：

**引理 2（全局最优 = 各"行区间"最优横切后取最大面积）**

对所有行区间 $[top,bot]$ 令

$$\text{bestWidth}(top,bot)=\max\{r-l:\ 0\le l<r\le M,\ \textstyle\sum_{j=l}^{r-1}c_j>0\},$$

则答案

$$\text{Ans}=\max_{0\le top\le bot\le N-1}\ \big(h\cdot\text{bestWidth}(top,bot)\big),\qquad h=bot-top+1 .$$

**证明**：
- 任何非空矩形都有唯一确定的行区间 $[top,bot]$ 与列区间 $[l,r)$。若它的和 $>0$，则在这段行区间下，列区间 $[l,r)$ 是一个合法的"正和连续区间"，其长度 $r-l\le\text{bestWidth}(top,bot)$，故矩形面积 $h(r-l)\le h\cdot\text{bestWidth}$，取遍所有矩形得 $\text{Ans}\le\max_{top,bot}h\cdot\text{bestWidth}$。
- 反过来，给定 $[top,bot]$ 与取到最优宽度的列区间，就构成一个合法矩形（和 $>0$），面积 $h\cdot\text{bestWidth}$，故 $\text{Ans}\ge\max_{top,bot}h\cdot\text{bestWidth}$。
- 两端夹逼得相等。$\blacksquare$

行区间的枚举可以用**增量维护**列和：固定 $top$，令 $bot$ 从 $top$ 递增，每加一行就把该行各列的值累加进 $c_j$，避免重复求和。共 $O(N^2)$ 次"加一行"，每次 $O(M)$，累加部分 $O(N^2M)=8\times10^6$。

### 2.4 一维版的正解：前缀和 + 严格递减单调栈 + 二分

现在解决 §2.2 的一维版。定义前缀和

$$P_0=0,\qquad P_k=\sum_{j=0}^{k-1}c_j\ (1\le k\le M),$$

则列区间 $[l,r)$ 的和 $=P_r-P_l$，条件"和 $>0$"即 $P_r>P_l$，长度为 $r-l$。问题化为：

$$\max\{r-l:\ 0\le l<r\le M,\ P_r>P_l\}.$$

**引理 3（固定右端 $r$ 时，最优左端是"满足 $P_l<P_r$ 的最小下标 $l$"）**

固定 $r$，令 $l^*(r)=\min\{l:0\le l<r,\ P_l<P_r\}$（若不存在则无可行区间）。则对任意可行的 $l$ 有 $r-l\le r-l^*(r)$。

**证明**：由 $l^*(r)$ 是满足条件的**最小**下标，任何可行 $l$ 都 $\ge l^*(r)$，故 $r-l\le r-l^*(r)$。且 $l^*(r)$ 本身可行，取到等号。$\blacksquare$

于是只需对每个 $r\le M$ 快速求出 $l^*(r)$。

**引理 4（最优左端必是"严格前缀最小"的下标）**

称下标 $l$ 是**严格前缀最小**，若 $P_l<P_{l'}$ 对所有 $0\le l'<l$ 成立。则引理 3 给出的 $l^*(r)$ 一定是严格前缀最小的下标。

**证明**：设 $l=l^*(r)$。对任意 $l'<l$：由 $l^*(r)$ 的最小性，$l'$ 不满足条件，即 $P_{l'}\ge P_r$；又 $P_l<P_r$。合并得 $P_{l'}\ge P_r>P_l$，即 $P_l<P_{l'}$。这对所有 $l'<l$ 成立，故 $l$ 是严格前缀最小下标。$\blacksquare$

**引理 5（严格前缀最小的候选集合可增量维护，且其"值随下标严格递减"）**

按下标 $0,1,\dots,r-1$ 逐个扫描，维护一个**下标栈** $\text{stk}$：初始压入 $0$；当处理到下标 $k$ 时，若 $P_k<P_{\text{stk 栈顶}}$ 则把 $k$ 入栈。则该栈恰好按**下标递增**存放 $0..r-1$ 中的全部严格前缀最小下标，同时这些下标对应的 $P$ 值**严格递减**。

**证明**：
- （入栈者皆严格前缀最小）归纳。$0$ 无更小下标，平凡成立。设处理到 $k$ 时栈存放了 $0..k-1$ 的全部严格前缀最小下标且值严格递减，则栈顶即 $\min_{l'<k}P_{l'}$。若 $P_k<\text{栈顶}$，则 $P_k<\min_{l'<k}P_{l'}\le P_{l'}$ 对所有 $l'<k$，故 $k$ 是严格前缀最小；若不小于栈顶，则存在 $l'<k$ 使 $P_{l'}\le P_k$，$k$ 不是严格前缀最小，不入栈。
- （无遗漏）反设某严格前缀最小下标 $k$ 未被压入。则入栈判定 $P_k<\min_{l'<k}P_{l'}$ 失败，即存在 $l'<k$ 使 $P_{l'}\le P_k$，与"严格前缀最小"矛盾。故无遗漏。
- （值严格递减）由入栈条件 $P_k<$（当时栈顶值），故新压入的值严格小于前一栈顶值，栈内值随下标递增而严格递减。$\blacksquare$

**引理 6（二分求 $l^*(r)$）**

在处理 $r$ 之前，栈中恰是 $0..r-1$ 的严格前缀最小下标，值严格递减。设目标值 $P_r$。由于栈内值严格递减，"$P_{\text{stk}[mid]}<P_r$"这一命题在 $mid$ 上呈现"先假后真"的单调性，可二分出**第一个满足它的位置**，其对应下标即 $l^*(r)$（由引理 4，$l^*(r)$ 在栈中；又因栈下标递增，第一个满足者就是最小下标者）。

**证明**：栈内值随下标严格递减，即 $P_{\text{stk}[0]}>P_{\text{stk}[1]}>\dots>P_{\text{stk}[tp-1]}$。对固定阈值 $P_r$，条件 $P_{\text{stk}[mid]}<P_r$ 在 $mid$ 上先是假（左侧值大）后为真（右侧值小），且一旦为真其后恒真，故存在唯一分界点，二分可定位"第一个真"的位置。引理 4 保证 $l^*(r)$ 是严格前缀最小、因而在栈内；栈下标递增意味着"栈中满足条件的最小下标"就是 $l^*(r)$。取长度 $r-l^*(r)$ 即可。$\blacksquare$

扫描每个 $r$ 时：先二分得到 $l^*(r)$ 更新 `best`，再按"$P_r<$ 栈顶值"决定是否把 $r$ 压栈。整个过程每个 $r$ 花 $O(\log M)$。

### 2.5 剖析失败思路

**失败 1：直接四重循环枚举子矩阵。**
枚举四边 $top,bot,l,r$ 是 $O(N^2M^2)\approx1.6\times10^9$，加上常数与取和，必然超时。这是本题最"顺理成章"却不可行的写法。$\Rightarrow$ 必须先把二维压成一维（引理 2）。

**失败 2：一维里用滑动窗口（双指针）。**
滑动窗口成立的前提是"窗口某个性质随端点单调"，但"窗口和 $>0$"随着引入负数**不再单调**。反例：数组 $[-1,3,-3]$。
- 正确：正和子数组有 $[3]$（长 $1$）与 $[-1,3]$（和 $2>0$，长 $2$），最长长度为 $2$；
- 若从 $l=0$ 出发"窗口和 $\le0$ 就把左端右移、一旦非正就重置"，会先遇到 $-1$ 直接放弃，得到错误的 $1$ 甚至 $0$。
$\Rightarrow$ 负数让窗口和失去单调性，必须回到**前缀和 + 单调栈/二分**。

**失败 3：只维护"目前最小的前缀值"而不维护其下标（或固定在"栈底"取 $l$）。**
我们要的是"满足 $P_l<P_r$ 的**最小下标** $l$"，而不是"值最小的前缀所在下标"（后者可能是很靠右的位置，使 $r-l$ 很小甚至为负）。二者只有在前缀值递增场景才巧合一致。$\Rightarrow$ 必须用**下标栈 + 二分**精确定位。

**失败 4：把"和 $>0$"写成"和 $\ge0$"。**
平均严格 $>0$ 对应和**严格** $>0$（引理 1）。写成 $\ge0$ 会把"和恰为 $0$"的矩形也算进去，面积虚增。栈的入栈条件与二分的比较都必须用**严格** $<$ / $>$。

**失败 5：用 `int` 存列和 / 前缀和。**
一列 $200$ 个格子、每格低至 $-2\times10^9$，列和可达 $-4\times10^{11}$；前缀再累加 $200$ 列可达 $\pm8\times10^{13}$，远超 `int`。$\Rightarrow$ 一律用 `i64`（§2.6）。

### 2.6 越界与状态体检

| 量 | 范围 | 上界 | `int` 够？ |
|---|---|---|---|
| $N,M$ | 题面给定 | $200$ | 是 |
| $a_{i,j}$ | 题面给定 | $\pm2\times10^9$ | 否（`int` 边缘） |
| 列和 $c_j$ | 一列 $\le200$ 格 | $\pm4\times10^{11}$ | 否 |
| 前缀和 $P_k$ | $M$ 列累加 | $\pm8\times10^{13}$ | 否 |
| 面积 $h\cdot\text{best}$ | $\le200\cdot200$ | $40000$ | 是 |

结论：**凡涉及海拔的累加一律 `i64`**；面积、下标、栈用 `int` 即可。数组尺寸 `mxh{mxn}` 复用，前缀与列和只需长度 $M+5$，故 `mxn{205}` 一个尺寸足矣。

## 3. 模式总结（Pattern Summary）

**模式名：最大面积"正和子矩阵" = 「行区间枚举」降维 + 「前缀和 + 严格递减单调栈 + 二分」求最长正和区间。**

**识别信号**：要求在矩阵里找面积最大的子矩形，满足某种**可加量**（和 / 平均）的正负约束；行列规模都是 $10^2$ 级。

1. **explore its property** — 把"平均 $>0$"化为纯加法条件"和 $>0$"（引理 1），确认目标是**和为正**。
2. **consider easier version** — 先解一维版："最长正和连续子数组"。
3. **reduce to easier problem** — 枚举上下行边界，把每列压成一个**列和**，二维塌缩为一维（引理 2）。
4. **classic problem solution（第一次：前缀和）** — 用前缀和把"区间和 $>0$"化为"$P_r>P_l$"，并把目标写成 $\max(r-l)$（引理 3）。
5. **classic problem solution（第二次：严格递减单调栈）** — 证明最优左端是**严格前缀最小**下标，且这些候选随下标递增而值严格递减（引理 4、5）。
6. **classic problem solution（第三次：二分）** — 在值严格递减的候选栈上二分，$O(\log M)$ 定位 $l^*(r)$（引理 6），把内层从 $O(M^2)$ 降到 $O(M\log M)$。
7. **boundary discipline** — 全程**严格**比较（$>0$、$<$），否则会把零和区间计入；海拔累加必须 `i64`。

**同族题**：最大子段和（Kadane）是其"$1$ 维、无长度最大化"的简化；"和最大子矩阵"（枚举行区间 + Kadane / 前缀最小）是同类降维套路；"最长子数组和 $\le K$ / $>K$"一类也常落到"前缀和 + 单调结构 + 二分"。

**一句话记忆**：固定上下边把二维压成一维 → 前缀和转成 $P_r>P_l$ → 用"严格递减前缀最小值栈 + 二分"求最远的一对。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $N,M$ / `n,m` | `int` | 行数、列数 | 读入 | 题面 |
| `a[i][j]` | `i64 [205][205]` | 第 $i$ 行第 $j$ 列海拔（0-based） | 读入 | 题面 |
| `c[j]` | `i64 [205]` | **当前行区间** [top,bot] 下第 $j$ 列的列和 | 每个 `top` 起重置为 $0$，随 `bot` 累加 | 引理 2 |
| `p[k]` | `i64 [205]` | `c` 的前缀和 $P_k=\sum_{j<k}c_j$（$0\le k\le M$） | `p[0]=0` | 引理 3 的 $P$ |
| `stk[tp]` / `tp` | `int [205]` / `int` | 严格递减前缀最小值的**下标**栈与栈顶指针 | `stk[0]=0, tp=1` | 引理 5 |
| `top,bot` | `int` | 枚举的行区间上下端（0-based，含端点） | — | 引理 2 |
| `h` | `int` | 行数 $=bot-top+1$ | — | 面积因子 |
| `best` | `int` | 当前行区间下的最长正和列区间长度 | $0$ | 引理 3 的 $\max(r-l)$ |
| `ans` | `int` | 最大面积 | $0$ | 答案 |

### 4.2 编号步骤

1. 读入 $n,m$ 与矩阵 `a`。
2. `ans=0`。
3. 外层枚举 `top=0..n-1`：
   3.1 把列和数组 `c[0..m-1]` 清零。
   3.2 内层枚举 `bot=top..n-1`：
      - 把第 `bot` 行累加进列和：对 `j=0..m-1` 执行 `c[j]+=a[bot][j]`。
      - 求 `c` 的前缀和：`p[0]=0`；对 `j=0..m-1`，`p[j+1]=p[j]+c[j]`。
      - 初始化单调栈：`tp=1, stk[0]=0`（值 $P_0=0$）；`best=0`。
      - 对 `r=1..m`：
        · 在栈 `stk[0..tp-1]` 上**二分**第一个满足 `p[stk[mid]]<p[r]` 的位置，取其下标 `pos`；若存在且 `r-pos>best` 则 `best=r-pos`（引理 6）。
        · 若 `p[r]<p[stk[tp-1]]`，则 `stk[tp++]=r`（维护严格递减，引理 5）。
      - `h=bot-top+1`；若 `best*h>ans` 则 `ans=best*h`。
4. 输出 `ans`（若从未出现正和矩形则为 $0$）。

> 二分的条件用**严格** `p[stk[mid]]<p[r]`：它对应"和 $>0$"（§2.5 失败 4）。栈的入栈条件同样用严格 `p[r]<p[stk[tp-1]]`，保证栈内值严格递减（引理 5），使二分单调性成立。

### 4.3 复杂度

- 时间：行区间共 $O(N^2)$ 对；每对做 $O(M)$ 累加/前缀 + 每个 $r$ 一次 $O(\log M)$ 二分，共 $O\!\big(N^2M\log M\big)$，最坏 $200^2\cdot200\cdot\log 200\approx3\times10^8$ 内的实际常数下耗时可接受。
- 空间：矩阵 `i64 a[205][205]` 约 $0.34$ MB，加列和/前缀/栈各 $O(M)$，总计约 $0.4$ MB。
- 实测（见 §4.5）：最坏 $N=M=200$ 耗时 $0.037$ s。

### 4.4 关键不变量

1. 进入二分前，`c[j]` 恰为 [top,bot] 的列和，`p` 为其前缀和（引理 2、3）。
2. 栈内 `stk` 的下标递增、对应 `p` 值**严格递减**，且恰为 $0..r-1$ 的全部严格前缀最小下标（引理 5）。
3. 二分得到的 `pos`（若存在）恰是 $l^*(r)$，故 `r-pos` 是固定右端 $r$ 时的最长正和长度（引理 3、4、6）。
4. 全程 `i64`，无溢出。

| 边界用例 | **通过**：全非正 → $0$；单格正数 → $1$；全正 $200\times200$ → 答案 $40000$ |
| 最坏规模计时 | $N=M=200$（随机大值）→ 输出 $0$，耗时 **$0.037$ s** |
| 残余风险 | ①把和条件写成 $\ge0$ 会把零和矩形计入（§2.5 失败 4）；②用双指针代替单调栈在含负数据上出错（§2.5 失败 2）；③海拔累加用 `int` 会溢出（§2.5 失败 5） |

## 5. 示例代码

### 5.1 主解：行区间枚举 + 前缀和 + 严格递减单调栈 + 二分

```cpp
//
// 题目：P1565 牛宫
// https://www.luogu.com.cn/problem/P1565
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{205};          // N,M<=200 (+5 松弛)

int n,m;
i64 a[mxn][mxn];                 // 海拔(可低至 -2e9,列和/前缀需 64 位)
i64 c[mxn];                      // 当前行区间各列的和(滚动复用)
i64 p[mxn];                      // c 的前缀和 p[0..m]
int stk[mxn];                    // 严格递减前缀最小值的下标单调栈

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			cin>>a[i][j];
	int ans=0;                   // 不存在正和子矩阵时输出 0
	for(int top=0;top<n;++top)
	{
		for(int j=0;j<m;++j)
			c[j]=0;
		for(int bot=top;bot<n;++bot)
		{
			for(int j=0;j<m;++j)
				c[j]+=a[bot][j];
			p[0]=0;
			for(int j=0;j<m;++j)
				p[j+1]=p[j]+c[j];
			int tp=0;            // 栈内值 p[stk[*]] 严格递减
			stk[tp++]=0;
			int best=0;          // 本行区间下最长正和子数组长度
			for(int r=1;r<=m;++r)
			{
				// 二分找栈中下标最小且 p[l]<p[r] 的 l
				int lo=0,hi=tp-1,pos=-1;
				while(lo<=hi)
				{
					int mid=(lo+hi)>>1;
					if(p[stk[mid]]<p[r])
					{
						pos=stk[mid];
						hi=mid-1;
					}
					else
						lo=mid+1;
				}
				if(pos!=-1&&r-pos>best)
					best=r-pos;
				if(p[r]<p[stk[tp-1]])
					stk[tp++]=r;
			}
			int h=bot-top+1;
			if(best*h>ans)
				ans=best*h;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

**代码结构对照**：`c` 是引理 2 的列和（随 `bot` 增量累加），`p` 是引理 3 的前缀和；`stk/tp` 是引理 5 的严格递减前缀最小值下标栈；`r` 循环内二分定位 $l^*(r)$（引理 6），`best` 累积当前行区间的最长正和宽度；`h*best` 与 `ans` 比较得到面积。所有比较均为**严格**，与海拔相关的量均为 `i64`。

### 5.2 对照实现：四重循环枚举子矩阵（仅用于小规模对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{205};

int n,m;
i64 s[mxn][mxn];                 // 二维前缀和(1-based)

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
		{
			i64 x;
			cin>>x;
			s[i+1][j+1]=s[i][j+1]+s[i+1][j]-s[i][j]+x;
		}
	int ans=0;
	for(int r1=0;r1<n;++r1)
		for(int r2=r1+1;r2<=n;++r2)
			for(int c1=0;c1<m;++c1)
				for(int c2=c1+1;c2<=m;++c2)
				{
					i64 sum=s[r2][c2]-s[r1][c2]-s[r2][c1]+s[r1][c1];
					if(sum>0)
						ans=max(ans,(r2-r1)*(c2-c1));
				}
	cout<<ans<<'\n';
	return 0;
}
```

两版输出逐字节相同（已用 $350$ 组随机数据确认）。这一版直接用二维前缀和枚举所有 $(\text{四边})$、按定义判"和 $>0$"取最大面积，完全不依赖单调栈与二分，可作为主解的独立交叉验证基准；代价 $O(N^2M^2)$，只有行列都很小时可跑。

### 5.3 易错点清单

- **把和条件写成 $\ge0$** $\Rightarrow$ 零和矩形被计入，面积偏大（§2.5 失败 4）。
- **一维里用双指针** $\Rightarrow$ 负数破坏窗口单调性，$[-1,3,-3]$ 反例（§2.5 失败 2）。
- **只取"最小前缀值"而不带下标 / 取栈底固定元素** $\Rightarrow$ 得不到"满足 $P_l<P_r$ 的最小下标 $l$"（§2.5 失败 3）。
- **栈用非严格递减** 虽不改变正确性，但会多存等值下标、浪费空间；保持严格 `<` 更整洁。
- **海拔/列和/前缀用 `int`** $\Rightarrow$ 溢出到 $\pm4\times10^{11}$ 量级时静默出错（§2.5 失败 5）。
- **四重循环** $\Rightarrow$ $O(N^2M^2)\approx1.6\times10^9$ 超时（§2.5 失败 1）。
- **用 `endl`** 违反本项目风格指南，一律用 `'\n'`。
