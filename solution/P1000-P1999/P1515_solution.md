# P1515 旅行

> 标签：搜索 / 贪心 / 递推 · 难度：普及-
> 本地题面：`P1515.md`（全程 $7000$ km，固定 $14$ 家旅馆，新增 $N\le 20$ 家；每日行程 $A\le d\le B$）。验证：`appendix/P1515/` 中 400 组随机对拍 + 3 组手工边界用例 + 最坏规模计时，std 与暴力逐字节一致。

## 1. 重新读题

**问题重述（人话版）**

有一条长 $7000$ 千米的直线公路，起点在 $0$ km、终点在 $7000$ km。沿途分布着若干**旅馆**，每家用"离起点距离"来标识：

- 固定的 $14$ 家：$[0,990,1010,1970,2030,2940,3060,3930,4060,4970,5030,5990,6010,7000]$；
- 出发前还可再**新增** $N$ 家（$0\le N\le 20$），新增旅馆位置 $m$ 满足 $0<m<7000$，且与任何既有旅馆都不重合。

旅行规则：**每天晚上必须停车住旅馆**，白天从一家旅馆开到下一家旅馆，每天行驶的距离必须落在区间 $[A,B]$ 内（下界 $A$ 来自"旅行社要求至少 $A$"，上界 $B$ 来自"国家要求最多 $B$"）。旅行从 $0$ 出发、最终停在 $7000$。问一共有多少种**不同的旅行方案**。

> 一句话版本：**在数轴上从 $0$ 走到 $7000$，每一步都落在旅馆点上、步长 $\in[A,B]$，数出这样的走法条数。**

**题面里容易漏掉的条款**

1. 「每天晚上都不开车，住在汽车旅馆」$\Rightarrow$ 每一天的落脚点**必须**是一个旅馆坐标，不能在任意位置过夜。于是每一段行程的两个端点都必须是旅馆。
2. 「每天至少行驶 $A$ 公里……每天最多只能行驶 $B$ 公里」$\Rightarrow$ 每段间隔 $d$ 必须同时满足 $A\le d\le B$。**下界 $A$ 与上界 $B$ 缺一不可**（见 §2.5 失败 1）。
3. 「$0<m<7000$」且「没有任意两个旅馆在同一位置」$\Rightarrow$ 所有旅馆坐标互不相同，且新增的不会落在 $0/7000$ 上，因此**不会出现零距离的相邻旅馆**（便于处理 $A=0$ 的退化情形）。
4. 题面没有说明 $A\le B$。若 $A>B$ 则区间为空、无任何可行的一日行程，此时答案应为 $0$（代码必须能正常给出 $0$，而不是崩溃或漏解）。
5. 输出的是**方案数**，可能是很大的整数，需留意是否会溢出 `int`（见 §2.6）。

**数据范围与规模感受**

$$0\le N\le 20,\qquad A,B\text{ 为行程上下界},\qquad \text{旅馆总数 }m\le 14+20=34 .$$

旅馆总数最多 $34$，是一个**极小**的规模。它提示的做法是 $O(m^2)$ 的朴素递推——连排序（$O(m\log m)$）都几乎可以忽略。任何指数级搜索（$2^{N}$）在 $N=20$ 时也不到 $10^6$，其实也能过，但递推更干净、更快。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"旅行"翻译成数轴上的路径

先问一个最朴素的问题：**一个"方案"到底是什么东西？**

旅行者从 $0$ 出发，每天停在某个旅馆，最后停在 $7000$。把途中停留过的旅馆按时间顺序串起来，就得到一串坐标

$$0=p_0\ <\ p_1\ <\ \dots\ <\ p_{t-1}\ <\ p_t=7000 ,$$

其中每个 $p_i$ 都是旅馆，相邻两者之差是当天的行程。**观察到位置是单调递增的**（因为车只会朝终点前进，题目没有掉头）。

**引理 1（方案 $\iff$ 一条合法路径）**

一个旅行方案与"从 $0$ 到 $7000$ 的一条路径"一一对应，其中"路径"指一个旅馆序列 $p_0,\dots,p_t$，满足 $p_0=0,\ p_t=7000$，且对每个 $i$ 有 $A\le p_{i+1}-p_i\le B$。

**证明**：
- （方案 $\Rightarrow$ 路径）给定一个方案，把它每天停留的旅馆坐标按时间顺序列出即得 $p_0=0,\dots,p_t=7000$。相邻两天的行程就是相邻坐标之差，由规则知它 $\in[A,B]$，故这是一条合法路径。
- （路径 $\Rightarrow$ 方案）给定一条合法路径，规定"第 $i$ 天从 $p_i$ 开到 $p_{i+1}$"。因为 $p_i$ 都是旅馆且差 $\in[A,B]$，这确实是一个合法的每日安排；又因为每晚都停在旅馆，满足"晚上住旅馆"的要求。两者互为逆映射。$\blacksquare$

> 这一步把"行程 / 旅馆 / 每天"这些叙事性的东西全部丢掉，只剩一个纯数学对象：**数轴上一张点集，求两条端点之间的合法路径数**。

### 2.2 考虑简化版：先只看上界 $B$

如果题目只给了上界 $B$（没有下界 $A$），问题变成"步长 $\le B$ 的路径计数"。加上下界 $A$ 之后，唯一的变化是**把可用的边构成一个子集**——凡是差 $<A$ 的相邻旅馆对不能再作为一天的行程。换句话说：

> $A$ 与 $B$ 只影响"哪些点对之间允许连边"，不改变问题的结构。

这告诉我们：一旦把"允许的边"确定下来，剩下的任务就是一个纯粹的**图上路径计数**，与 $A,B$ 的具体含义无关。这正是后面可以套用同一套模板的原因。

### 2.3 归约：按位置升序，边恒由左指向右

现在只关心"允许的边"。第 $j$ 家旅馆（坐标 $a_j$）与第 $i$ 家（坐标 $a_i$）之间连一条有向边 $j\to i$，当且仅当

$$A\ \le\ a_i-a_j\ \le\ B .$$

**引理 2（把坐标排序后，边与下标方向一致）**

设 $a_1<a_2<\dots<a_m$ 是把所有旅馆坐标**升序排列**后的结果。若存在边 $j\to i$，则必有 $j<i$。

**证明**：由边条件 $A\le a_i-a_j\le B$。若 $j\ge i$，则 $a_i-a_j\le 0$（升序性质，等号仅当 $i=j$ 而坐标互异故必 $<0$ 当 $j>i$）。又 $A\ge 0$（行程不为负），故 $A\le a_i-a_j\le0$ 迫使 $a_i-a_j=0$ 且 $A=0$，即 $j=i$，这是一条自环。但题面保证坐标互不相同，且自环（同一天从一家旅馆到它自己）不构成合法的"开出去"行程，故没有自环。于是必有 $j<i$。$\blacksquare$

> 引理 2 的直接好处：**升序下标本身就是这张有向图的一个拓扑序**。求路径数不需要拓扑排序、不需要 DFS，直接从 $i=1$ 到 $m$ 顺序扫即可。

### 2.4 经典技术：DAG 上的路径计数 DP

在拓扑序（下标序）上作线性 DP。定义

$$f_i=\text{“从起点 }\ 0\ \text{ 出发、最后停在旅馆 }\ a_i\ \text{ 的方案数''}.$$

**引理 3（DP 转移的正确性）**

设 $a_i$ 升序、$a_1=0$。令 $f_1=1$，并对 $i\ge 2$ 令

$$f_i=\sum_{j<i,\ A\le a_i-a_j\le B} f_j ,$$

则 $f_i$ 恰好等于从 $0$ 走到 $a_i$ 的合法路径数。

**证明**（对下标 $i$ 归纳，实质是"按最后一条边分类"）：
- **基例** $i=1$：坐标 $a_1=0$ 是起点，只有"尚未出发"这一种到达方式，故 $f_1=1$，与定义相符。
- **归纳步**：任取一条从 $0$ 到 $a_i$ 的合法路径。它的**最后一步**一定是从某个 $a_j$（$j<i$，由引理 2）跳到 $a_i$，且该步满足 $A\le a_i-a_j\le B$。把这条路径的前半段（$0\to a_j$）删去最后一步，得到一条从 $0$ 到 $a_j$ 的合法路径。按"最后一步的起跳点 $j$"对所有路径分类：每一类里的路径与"从 $0$ 到 $a_j$ 的合法路径"一一对应（同一前半段加同一最后一步唯一确定），故第 $j$ 类恰有 $f_j$ 条（归纳假设）。各类互不相交、且覆盖全部路径，于是总数 $=\sum_j f_j$，正是转移式。
- 归纳完成，$f_i$ 就是所求。$\blacksquare$

答案就是 $f$ 中对应终点 $7000$ 的那一项，即 $f_m$（$a_m=7000$）。

### 2.5 剖析几个失败思路（都给出具体反例）

**失败 1：忽略下界 $A$，只按"每天不超过 $B$"计数。**
反例：$A=B=500$，旅馆只有默认的 $14$ 家，$N=0$。真实的合法路径必须**每天恰好 $500$**：从 $0$ 只能到 $500$（不是任何一个默认旅馆），因此根本无路可走，答案 $\mathbf 0$。而只看上界 $B=500$ 的方案会把 $0\to990$ 之类也算进去（$990>500$ 其实仍被 $B$ 挡掉）……更贴近的反例是：把 $A$ 设成 $990$、$B$ 设成 $990$，则只有 $0\to990$、$990\to1980$ 这种步长恰 $990$ 的才合法，忽略 $A$ 会额外计入 $0\to1010$ 之类。$\Rightarrow$ **下界 $A$ 是硬约束，转移条件里必须同时写 $A\le a_i-a_j$ 与 $a_i-a_j\le B$。**

**失败 2：把"天数"也算进方案（即认为每天开多远不同是不同方案）。**
题面问的是**方案的条数**，而方案由"停在哪些旅馆"唯一决定；同一天内开 $500$ 还是 $501$ 由相邻旅馆决定，不存在额外自由度。$\Rightarrow$ 每一条路径恰好对应一种方案，引理 1 已封闭了对应关系，不要重复计数。

**失败 3：`f` 用 `int` 存储导致溢出。**
见 §2.6：答案可达 $2^{32}$，`int`（$2^{31}-1$）装不下。

### 2.6 答案上界与溢出（写代码前必须想清楚）

**引理 4（方案数不超过 $2^{m-2}$）**

设旅馆总数为 $m$（含端点 $0,7000$），则合法路径数 $\le 2^{m-2}$。

**证明**：每条路径都可以用一个"中间旅馆子集"来描述——它由 $0$、若干中间旅馆、$7000$ 组成，中间部分是从 $m-2$ 个中间旅馆里选出的任意子集（选了哪些就停哪些，顺序由坐标唯一确定，无需再选）。子集总数 $=2^{m-2}$，故路径条数是这些子集的一个子集（并非所有子集都合法，但合法的一定是子集之一），于是 $\le2^{m-2}$。$\blacksquare$

$m-2\le 34-2=32$，所以答案上界 $2^{32}=4294967296>2^{31}-1=2147483647$。**必须用 `long long`（`i64`）存放 `f`**，否则会静默溢出。这一条不是杞人忧天：验证脚本的最坏规模用例（$N=20$、$A=1$、$B=7000$，即全部子集都合法）实测答案正是 `4294967296`。

### 2.7 边界与状态体检

| 量 | 范围 | 上界 | 备注 |
|---|---|---|---|
| $A,B$ | 行程上下界 | 题面给定的整数 | 可能 $A>B$ |
| $N$ | 新增旅馆数 | $20$ | 可为 $0$ |
| 旅馆坐标 | $[0,7000]$ | $7000$ | 互不相同 |
| $m$ | 旅馆总数 | $34$ | 数组取 `mxn{45}`（$34+5$ 松弛） |
| $f_i$ | 方案数 | $2^{32}$ | **必须 64 位** |

要防的坑：

1. **`A > B` 时区间为空**，此时转移条件恒假，`f` 除起点外全为 $0$，答案自然为 $0$——循环写法天然处理，无需特判。
2. **去重**：题面保证无重复，但加一次 `sort + unique` 成本极低且更稳（即使数据意外重复也不会把"同一坐标"当成两站导致重复计数）。
3. **`f[0]=1` 的语义**：这是"站在起点、还没出发"的状态数，不是"已经住过一晚"。
4. **答案取值是 `f[m-1]`**：排序后 $7000$ 一定在最后（它是最大坐标），故终点就是末项。

## 3. 模式总结（Pattern Summary）

**模式名：数轴上的「合法性可分离 → DAG 路径计数」。**

**识别信号**：把"方案"翻译成一串有序的落脚点；每个落脚点来自一个给定点集；相邻落脚点的差受一个区间约束；问方案条数。

**可复用套路（按实际思考顺序）**：

- **explore its property** — 把叙事性的"旅行/每天/住店"翻译成数轴上的路径：方案 $\iff$ 起点到终点的点序列（引理 1）。
- **consider easier version** — 先摘掉下界 $A$，只剩上界 $B$；发现 $A,B$ 只决定"连哪些边"，不改变问题结构。
- **reduce to easier problem** — 按坐标升序给点编号，证明边恒由小下标指向大下标（引理 2），于是下标序即拓扑序，省掉拓扑排序。
- **classic problem solution** — 在拓扑序上做路径计数 DP：$f_i=\sum f_j$（引理 3）。
- **bound the growth** — 用"中间点任选"给出答案上界 $2^{m-2}$，据此选定 64 位整数（引理 4）。

**一句话记忆**：把"旅行方案"看成数轴上的路径，排序后就是一张 DAG，路径计数用一个递推即可，注意答案可能很大。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $A$ | `int` | 每日行程下界 | 读入 | 题面 |
| $B$ | `int` | 每日行程上界 | 读入 | 题面 |
| $N$ | `int` | 新增旅馆数 | 读入 | 题面 |
| `base[14]` | `int[14]` | 题目给定的 $14$ 家固定旅馆坐标 | 字面量 | 题面列表 |
| `a[mxn]` | `int[45]` | **全部**旅馆坐标，升序去重后 | 装入 base 后追加新增、再排序 | 位置数组 |
| $m$ | `int` | 旅馆总数 = `unique` 后的 `a` 长度 | 初为 $14$，每读一个新增 $+1$ | — |
| `f[mxn]` | `i64[45]` | `f[i]=` 从 $0$ 走到第 $i$ 家旅馆的方案数 | `f[0]=1`，其余 $0$ | 路径计数 DP（引理 3） |

### 4.2 编号步骤

1. 读入 $A,B,N$。
2. 把固定的 $14$ 家旅馆坐标写入 `a[0..13]`；再读入 $N$ 个新增坐标，依次写入 `a[14..]`，令 $m=14+N$。
3. `sort(a,a+m)` 升序；`m = unique(a,a+m)-a` 去重（题面保证无重复，此步为稳妥）。
4. `f[0]=1`；对 $i=1..m-1$，令 `f[i]=Σ_{j<i} f[j]`（仅当 `A<=a[i]-a[j]<=B`）。结束后 `f[i]` 即引理 3 所求。
5. 输出 `f[m-1]`（对应坐标 $7000$）。

### 4.3 复杂度

- 时间：排序 $O(m\log m)$ + 双层递推 $O(m^2)$，$m\le 34$，即约 $10^3$ 次运算，常数级。
- 空间：`int[45]` 一个、`i64[45]` 一个，约 $0.6$ KB。
- 实测（§4.5）：最坏规模 $N=20$、全部中间点合法时输出 `4294967296`，耗时远小于 $1$ ms。

### 4.4 关键不变量（值得写 `assert` 的地方）

1. `f[i]` 恰为到 `a[i]` 的方案数，且 `f[i]>=0`。
2. `a[0]==0` 且 `a[m-1]==7000`（端点固定）。
3. 若 `A>B`，则 `f` 除 `f[0]` 外全 $0$，答案 $0$。
4. `f` 用 `i64`；任何时刻不超过 $2^{32}$。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 随机对拍 | **通过**：$400$ 组随机用例（$N\in[0,8]$，$A\in[1,1200]$，$B\in[A,2200]$，位置随机且不与默认旅馆重合），递推 std 与"枚举所有路径"的暴力版输出**逐字节一致** |
| 手工边界用例 | **通过**：$A=1,B=7000,N=0\Rightarrow 4096=2^{12}$；$A=B=7000,N=0\Rightarrow 1$（仅 $0\to7000$ 直达）；$A>B\Rightarrow 0$ |
| 最坏规模计时 | $N=20$、$A=1$、$B=7000$（全部中间点合法）$\Rightarrow$ 输出 `4294967296`，耗时 **$0.0053$ s** |
| 残余风险 | 答案超出 $2^{32}$ 的情形不存在（中间点至多 $32$ 个）；若数据意外出现重复坐标，`unique` 已兜底 |

## 5. 示例代码

### 5.1 主解：排序 + DAG 路径计数 DP
```cpp
// 题目：P1515 旅行
// https://www.luogu.com.cn/problem/P1515
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{45};        // 固定 14 家 + 新增 <=20 (+5 松弛)

int a[mxn];                   // 所有旅馆位置(去重后升序)
i64 f[mxn];                   // f[i]=从起点走到第 i 家旅馆的方案数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int A,B,N;
	cin>>A>>B>>N;
	int base[14]={0,990,1010,1970,2030,2940,3060,3930,4060,4970,5030,5990,6010,7000};
	int m=14;
	for(int i=0;i<14;++i)
		a[i]=base[i];
	for(int i=0,x;i<N;++i)
	{
		cin>>x;
		a[m++]=x;
	}
	sort(a,a+m);
	m=unique(a,a+m)-a;        // 题面保证无重复;去重仅为稳妥
	f[0]=1;                   // 起点(0 km)只有"尚未出发"一种
	for(int i=1;i<m;++i)
		for(int j=0;j<i;++j)
			if(a[i]-a[j]>=A&&a[i]-a[j]<=B)
				f[i]+=f[j];   // 当天恰好从旅馆 j 开到旅馆 i
	cout<<f[m-1]<<'\n';       // a[m-1]=7000,即终点
	return 0;
}
```

### 5.2 对照实现：枚举所有路径（仅用于小规模对拍）
```cpp
// P1515 暴力基准：枚举所有合法旅行方案(小 N)
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{45};

int a[mxn],m,A,B;
i64 ans;

void dfs(int p)               // p=当前所在旅馆下标
{
	if(a[p]==7000)            // 到终点,记一种方案
	{
		++ans;
		return;
	}
	for(int j=p+1;j<m;++j)
		if(a[j]-a[p]>=A&&a[j]-a[p]<=B)
			dfs(j);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int N;
	cin>>A>>B>>N;
	int base[14]={0,990,1010,1970,2030,2940,3060,3930,4060,4970,5030,5990,6010,7000};
	m=14;
	for(int i=0;i<14;++i)
		a[i]=base[i];
	for(int i=0,x;i<N;++i)
	{
		cin>>x;
		a[m++]=x;
	}
	sort(a,a+m);
	m=unique(a,a+m)-a;
	dfs(0);
	cout<<ans<<'\n';
	return 0;
}
```

两版输出必须逐字节相同（已用 $400$ 组随机数据确认）。暴力版完全绕开 DP 递推，直接按定义穷举"每一站跳到哪"，因而是 §2.4 引理 3 的独立交叉验证基准。

### 5.3 易错点清单

- **`f` 开成 `int`** $\Rightarrow$ 答案可达 $2^{32}$ 时溢出，输出负数/错值。必须 `long long`。
- **转移漏掉下界** `A<=a[i]-a[j]` $\Rightarrow$ 把过短的行程也算进去，答案偏大（§2.5 失败 1）。
- **未排序就递推** $\Rightarrow$ 下标序不再是拓扑序，递推顺序错乱。
- **忘了把新增旅馆并入** $\Rightarrow$ 只用了 $14$ 家固定旅馆，方案数偏小。
- **`A>B` 时特判出错**（例如断言或死循环）$\Rightarrow$ 直接靠"区间为空 ⇒ 无边 ⇒ 答案 $0$"自然处理即可，无需特判。
