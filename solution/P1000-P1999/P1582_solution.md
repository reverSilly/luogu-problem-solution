# P1582 倒水

> 标签：枚举 · 进制 · 难度：普及-
> 本地题面：`P1582.md`（$1\le N\le2\times10^9$，$K\le1000$，单组询问）。验证：`appendix/P1582/` 官方样例 $3/3$；随机对拍 $3200$ 组 + 穷举 $5120$ 组（$N=1..128,\ K=1..40$）全部 `std==brute`（真·模拟暴力，不借用 popcount）；$2000$ 组大规模与两个独立参考实现一致；$N=2\times10^9$ 最坏规模 $0.0008\text{s}$/次。

## 1. 重新读题

**问题重述（人话版）**

CC 有 $N$ 个容量无限的瓶子，每个瓶子里初始有 $1$ 升水。他觉得瓶子太多，想**保留不超过 $K$ 个瓶子**。唯一允许的操作是：选两个**当前含水量相同**的瓶子，把一个瓶子的水全部倒进另一个，然后把空瓶丢弃（不能丢弃有水的瓶子）。如果靠合并减不到 $K$ 个以内，他可以**买新瓶子**（新瓶子同样容量无限、初始 $1$ 升水）。问最少需要买多少个新瓶子。

> 一句话版本：**总水量 $=N+$ 买入数；每一瓶的水量永远是 $2$ 的幂；合并两瓶等量的水就是二进制里的一次进位。问最少买入多少，才能使总量的二进制表示中 $1$ 的个数不超过 $K$。**

**题面里容易漏掉的条款**

1. 「两个当前含水量**相同**的瓶子」$\Rightarrow$ 只有等量才能合并：$1+1=2$、$2+2=4$、$4+4=8\ldots$ 于是任何时刻每瓶水量都是 $2$ 的幂（引理 1）。这是全题的数学入口。
2. 「**不能丢弃有水的瓶子**」$\Rightarrow$ 水一滴都少不了，总水量恒等于 $N+$ 买入瓶数，被丢掉的只有空瓶。总量守恒是后面一切推理的地基。
3. 新瓶子「开始时**有 $1$ 升水**」$\Rightarrow$ 买 $x$ 瓶就是加 $x$ 升水、加 $x$ 个 $1$ 升瓶，与初始状态完全同构；买瓶子不改变问题的结构，只改变总量。
4. 「保留**不超过** $K$ 个」$\Rightarrow$ 是 $\le$ 而不是 $=$。合并到越少越好，但下限被总水量卡死（引理 2），不是想减就能减。
5. 「比如 $N=3$、$K=1$」这个例子 $\Rightarrow$ 它想说的是"有时不买不行"；但只要买，就一定能行——买到总量变成 $2$ 的幂即可。**答案永远存在**（推论 5）。
6. $K\le1000$ 是个幌子：$N<2^{31}$，故 $\mathrm{pc}(N)\le31$，只要 $K\ge31$ 答案就是 $0$；真正需要算的只有 $K\le30$。
7. $N\le2\times10^9$ $\Rightarrow$ 不能逐瓶模拟（$20$ 亿个瓶子），必须整体做二进制抽象。

**数据范围与规模感受**

$$1\le N\le2\times10^9<2^{31},\qquad 1\le K\le1000,\qquad \text{单组询问、一行输入}.$$

瓶数高达 $2^{31}$ 量级，但"最少能剩几瓶"只由总量的二进制形态决定。整道题最后只需要看 $O(31)$ 个二进制位，连数组都不用开。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：一次合并到底改变了什么

先把操作翻译成数学语言。设某次合并前两瓶各有 $2^a$ 升，合并后得到一瓶 $2^{a+1}$ 升、丢掉一个空瓶。

**引理 1（形态与守恒）**

任意时刻：(a) 每个瓶子的水量都是 $2$ 的幂；(b) 总水量 $=N+x$，其中 $x$ 是买入瓶数。

**证明**：对合并/买入操作归纳。初始 $N$ 个瓶子各 $1=2^0$ 升、总量 $N$，(a)(b) 成立。假设某步之前成立，该步合并两瓶各 $2^a$ 升的水：新瓶 $2^{a+1}$ 仍是 $2$ 的幂；两瓶变一瓶，丢掉的空瓶水量为 $0$，总量不变。若买入 $x$ 瓶，则总量与瓶数各增加 $x$，且新瓶都是 $2^0$ 升。归纳成立。$\blacksquare$

> 这一步把"倒水"这个动作整个翻译掉了：题目剩下的全部数学内容就是——**一堆 $2$ 的幂，允许把两个相同的合成一个更大的，问最少能剩几项**。

### 2.2 考虑简化版：先斩掉"买入"，固定总水量 $T$

假设总共有 $T$ 升水（相当于 $T$ 个 $1$ 升瓶），先不问买入，只问一个子问题：**最少能剩几个瓶子？**

**引理 2（最少瓶数 $=\mathrm{pc}(T)$）**

$T$ 升水最少能剩 $\mathrm{pc}(T)$ 个瓶子，其中 $\mathrm{pc}(T)$ 是 $T$ 的二进制表示中 $1$ 的个数。

**证明**：

- **可达性（上界）**：只要还存在两瓶水量相同就合并它们。每次合并瓶数恰好减 $1$，过程必在有限步内终止。终止时任意两瓶水量都不同，即各瓶水量构成一组**互不相同**的 $2$ 的幂，而"一组互不相同的 $2$ 的幂之和"与 $T$ 的二进制展开一一对应，故此时恰好剩 $\mathrm{pc}(T)$ 瓶。
- **最优性（下界）**：任取一个终局（任意合并顺序、任意时刻停手），设剩 $m$ 瓶，水量为 $2^{b_1},\ldots,2^{b_m}$。把其中相同的继续合并——每次合并 $m$ 减 $1$、总和不变——直到无相同为止，此时必到达二进制展开，剩 $\mathrm{pc}(T)$ 瓶。因此 $m\ge\mathrm{pc}(T)$。

两方面合起来：最小值恰为 $\mathrm{pc}(T)$。$\blacksquare$

> 注意下界证明的套路：**不预设任何合并策略，而是说"任意终局都能被继续改造成二进制展开，且指标只会变好"**。这是交换论证的标准形态——不去比较两条路径谁更优，而是证明任意解都可以改造成目标形态。

### 2.3 归约：原题变成一个纯二进制问题

买入 $x$ 瓶后总量 $T=N+x$，由引理 2，能压到 $\le K$ 瓶当且仅当 $\mathrm{pc}(N+x)\le K$。

**引理 3（归约）**

$$\text{答案}=\min\bigl\{\,T-N\ :\ T\ge N,\ \mathrm{pc}(T)\le K\,\bigr\}.$$

**证明**：买入 $x$ 瓶 $\iff$ 总量 $T=N+x$；由引理 1、2，该 $x$ 可行当且仅当 $\mathrm{pc}(T)\le K$。可行 $x$ 与可行 $T$ 一一对应且 $x=T-N$，对可行 $x$ 取最小等价于对 $T-N$ 取最小。$\blacksquare$

### 2.4 失败思路 1：直接枚举买入数 $x$（定义级暴力）——太慢

顺着引理 3，最直白的做法是 $x=0,1,2,\ldots$ 逐个试 $\mathrm{pc}(N+x)\le K$。它是对的，但是慢：最坏要试到约 $2^{31}-N$ 次。反例规模：$N=2^{30}+1=1073741825$、$K=1$——只有总量恰为 $2$ 的幂时 $\mathrm{pc}=1$，而 $\ge N$ 的最小 $2$ 的幂是 $2^{31}$，答案 $1073741823$，线性扫描要跑十亿次。

$\Rightarrow$ **这个思路不枪毙，降级为暴力基准**：小规模下它绝对正确，正好给标程当对拍参照（见 §5.2）。

### 2.5 失败思路 2：对 $x$ 二分答案——谓词不单调

"$\mathrm{pc}(N+x)\le K$" 并不是 $x$ 的单调谓词，二分答案的前提直接崩掉。反例：$N=12$、$K=2$：

| $x$ | $0$ | $1$ | $2$ | $3$ | $4$ |
|---|---|---|---|---|---|
| $T=N+x$ | $12=\mathrm{0b1100}$ | $13=\mathrm{0b1101}$ | $14=\mathrm{0b1110}$ | $15=\mathrm{0b1111}$ | $16=\mathrm{0b10000}$ |
| $\mathrm{pc}(T)\le2?$ | ✓ | ✗ | ✗ | ✗ | ✓ |

真值序列是 `T,F,F,F,T`。二分赖以成立的"中点失败则一侧全失败"在此不成立，会锁死在错误的一侧。

### 2.6 失败思路 3：两个贪心，各配一个具体反例

- **贪心 A：一律凑到下一个 $2$ 的幂**（本质上只服务 $K=1$）。反例：$N=11$、$K=2$。下一个 $2$ 的幂是 $16$，要买 $5$ 瓶；但 $T=12=\mathrm{0b1100}$ 有 $\mathrm{pc}=2\le2$，买 $1$ 瓶就够。答案 $1\ne5$。原因：$K\ge2$ 时合法 $T$ 不必是 $2$ 的幂，可以是"两个 $1$"。
- **贪心 B：只盯着最低的 $0$ 位进位**。反例：$N=10=\mathrm{0b1010}$、$K=1$。最低的 $0$ 位是 bit $0$，进位得 $T=11=\mathrm{0b1011}$，$\mathrm{pc}=3>1$，不合法；必须继续往上进到 $16$，答案 $6$。原因：进一位只消掉最低的一个 $1$，高位的 $1$ 纹丝不动，$\mathrm{pc}$ 可能不降反升。

两个贪心共同死在同一个地方：**不知道该在哪儿停**。那就干脆把最优解的形状刻画出来。

### 2.7 关键结构：最优 $T$ 长什么样

**引理 4（最优 $T$ 的候选形态）**

设 $T^*>N$ 是满足 $\mathrm{pc}(T^*)\le K$ 的最小 $T$。记 $i$ 为 $T^*$ 与 $N$ 的二进制表示中**最高的不同位**，则：

(a) $N$ 的第 $i$ 位为 $0$、$T^*$ 的第 $i$ 位为 $1$；

(b) $T^*$ 的第 $i$ 位以下全为 $0$；

(c) $T^*$ 的第 $i$ 位以上与 $N$ 完全相同。

即

$$T^*=\bigl(N\gg(i+1)\ll(i+1)\bigr)\ \big|\ 2^i,\qquad\text{其中 }N\text{ 的第 }i\text{ 位为 }0.$$

**证明**：$T^*>N$，故在最高不同位 $i$ 上必须 $T^*$ 位 $1$、$N$ 位 $0$（若反过来则 $T^*<N$），即 (a)。假设 $T^*$ 在 $i$ 以下的某位 $j$ 上为 $1$，构造 $T'=T^*-2^j$（仅把这一位清 $0$）：$i$ 位以上不变、$i$ 位 $T'$ 仍为 $1>0$，故仍有 $T'>N$；且 $\mathrm{pc}(T')=\mathrm{pc}(T^*)-1\le K$。$T'<T^*$ 与 $T^*$ 的最小性矛盾。故 $i$ 以下全为 $0$，即 (b)；构造过程中 $i$ 以上未动，即 (c)。$\blacksquare$

**推论 5（候选集完备 + 答案必存在）**

$$\text{答案}=\min\Bigl(\ \bigl\{\,0\ \text{若}\ \mathrm{pc}(N)\le K\,\bigr\}\ \cup\ \bigl\{\,T_i-N\ :\ N\text{ 的第 }i\text{ 位为 }0,\ \mathrm{pc}(T_i)\le K\,\bigr\}\Bigr),$$

其中 $T_i=\bigl(N\gg(i+1)\ll(i+1)\bigr)|2^i$。并且只要 $K\ge1$，答案一定存在。

**证明**：若 $\mathrm{pc}(N)\le K$，则 $x=0$ 合法，$0$ 是一个候选。否则最优 $T^*>N$，由引理 4 它必是某个 $T_i$，已被枚举，故候选集含最优解、最小值就是答案。存在性：$N<2^{31}$，故 $N$ 的第 $31$ 位为 $0$，$T_{31}=2^{31}$，$\mathrm{pc}=1\le K$（题面说 $K$ 是正整数，$K\ge1$），$T_{31}-N$ 恒为合法候选。$\blacksquare$

> 推论 5 也连回了题面那句话："$N=3$、$K=1$ 时 CC 无法达到目标"——$\mathrm{pc}(3)=2>1$，$x=0$ 不行；但 $T_2=4$、$\mathrm{pc}=1$，**买 $1$ 瓶即可**。买到"总量变成 $2$ 的幂"永远是最保底的退路。

### 2.8 另一条同样正确的路（题外话）：逢 $1$ 进位

还有一个更有"操作感"的等价做法：从 $T=N$ 起，只要 $\mathrm{pc}(T)>K$ 就执行 $T\ +=$ `lowbit(T)`——即给最低位的 $1$ 进位，二进制里最低那一串 $1$ 当场塌缩成高一位的一个 $1$。

**引理 6（逢 $1$ 进位正确性）**

上述过程终止时，$T$ 就是满足 $\mathrm{pc}(T)\le K$ 的最小 $T\ge N$。

**证明**：设某一步当前值为 $T$，其最低置位为 $2^j$，且 $\mathrm{pc}(T)>K$。进位一步跳到 $T+2^j$，跳过区间 $(T,\,T+2^j)$ 内的所有值。任取其中 $T+d$（$0<d<2^j$）：$T$ 的低 $j$ 位全为 $0$，故 $T+d$ 的低 $(j+1)$ 位就是 $2^j+d$，其 popcount 为 $1+\mathrm{pc}(d)\ge2$，于是

$$\mathrm{pc}(T+d)=\mathrm{pc}\bigl(T\gg(j+1)\bigr)+1+\mathrm{pc}(d)\ \ge\ \mathrm{pc}(T)+1\ >\ K.$$

即被跳过的值全都不合法，不会漏掉解。每步 $T$ 严格增、$\mathrm{pc}(T)$ 不增，过程必终止；终止时 $\mathrm{pc}\le K$，而 $[N,\,$终止值$)$ 内的值要么是被跳过的（已证不合法）、要么是中间态（$\mathrm{pc}>K$），全不合法，故终止值就是最小合法 $T$。$\blacksquare$

实测该做法与候选枚举在 $20$ 万组全范围随机数据上零分歧（见 §4.5）。标程仍采用候选枚举：$32$ 个候选逐个验算的形式更贴近引理 4，写起来也更不容易错。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 把"合并两瓶等量的水"翻译成二进制进位，得到引理 1：每瓶水量恒为 $2$ 的幂、总水量守恒。
- **consider easier version** — 先斩掉"买入"，只问固定总量 $T$ 最少剩几瓶，得到引理 2：最少瓶数 $=\mathrm{pc}(T)$（交换论证：任意终局都能继续合并到二进制展开）。
- **reduce to easier problem** — 引理 3 把原题归约为纯二进制问题：求最小 $T\ge N$ 使 $\mathrm{pc}(T)\le K$。
- **classic problem solution（线性扫描）** — 定义级枚举 $x$ 正确但最坏 $10^9$ 次迭代，只配做暴力基准（失败 1）。
- **classic problem solution（二分答案）** — "$\mathrm{pc}(N+x)\le K$" 非单调，被 $N=12,K=2$ 的反例否决（失败 2）。
- **classic problem solution（贪心）** — "凑下一个 $2$ 的幂"（$N=11,K=2$）与"只进最低 $0$ 位"（$N=10,K=1$）各被一个具体反例否决（失败 3）。
- **classic problem solution（枚举候选）** — 引理 4 用"最高分歧位 $+$ 低位必须清 $0$"把最优 $T$ 锁死成 $O(32)$ 个候选，逐个验 $\mathrm{pc}$ 取最小差（主解）。
- **prove-by-contradiction / exchange** — 引理 2 的下界与引理 4 的低位清零都是反证/交换论证，全篇无"显然"。
- **count-the-candidates** — 候选只有 $32$ 个且 $i=31$ 恒合法，直接枚举即可，无需 DP、二分或数据结构。
- **verify against a simulation brute** — 暴力不借用 popcount，直接 DFS 模拟合并过程，独立复核整条推理链（§4.5）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `i64`（全局） | 原有瓶数 $=$ 初始总水量 | 读入 | 题面 $N$ |
| $k$ | `int`（全局） | 目标瓶数上界 | 读入 | 题面 $K$ |
| `mxb` | `constexpr int{37}` | 枚举位宽 $0..36$ | $37$ | $N<2^{31}$ 只需 $0..31$，$32..36$ 为 $+5$ 松弛冗余 |
| `pc(x)` | 函数 | $x$ 的二进制 $1$ 的个数 | — | popcount，`__builtin_popcountll` |
| `ans` | `i64`（main 局部） | 已发现的合法 $T$ 与 $N$ 的最小差 | `1145141919810` | 114514 家族哨兵；$K\ge1$ 时必被更新 |
| $i$ | `int`（循环） | 候选的最高分歧位 | $0$ | 引理 4 的 $i$ |
| $t$ | `i64`（循环局部） | 候选总水量 $T_i$ | `(n>>(i+1)<<(i+1))\|(1LL<<i)` | 高位保留、$i$ 位补 $1$、低位清零 |

### 4.2 编号步骤

1. 读入 $n,k$。
2. 若 $\mathrm{pc}(n)\le k$，令 `ans=0`（$T=N$ 本身合法，一瓶不买）。
3. 对 $i=0..\texttt{mxb}-1$：若 $n$ 的第 $i$ 位为 $1$ 则跳过（该位不可能是最高分歧位，引理 4(a)）；否则按引理 4 构造 $T_i$，若 $\mathrm{pc}(T_i)\le k$ 则 `ans=min(ans,T_i-n)`。
4. 输出 `ans`。

### 4.3 复杂度

- 时间：$O(\texttt{mxb})=37$ 次 popcount，与 $N$ 的大小无关。
- 空间：$O(1)$，仅几个标量。
- 实测（§4.5）：$N=2\times10^9$、$K=1$ 最坏规模 $0.0008\text{s}$/次（含进程启动；算法本身仅 $37$ 次内置 popcount，微秒级）。

### 4.4 关键不变量

1. 步骤 3 只枚举 $N$ 的第 $i$ 位为 $0$ 的 $i$，保证 $T_i>N$（$T_i-N=2^i-(N\bmod 2^i)>0$）。
2. `ans` 始终等于"已枚举合法候选与 $N$ 的最小差"；哨兵 $1145141919810>2^{31}>$ 任何真实答案。
3. $K\ge1$ 时 $i=31$ 的候选 $T=2^{31}$（$\mathrm{pc}=1$）必合法，故 `ans` 必被更新、哨兵不会存活；若题面放开 $K=0$（无解情形），哨兵会作为输出存活下来。
4. $\mathrm{pc}(n)\le31$（$N<2^{31}$），故 $K\ge31$ 时第 2 步必命中 $0$——$K\le1000$ 的上界是幌子。

## 5. 示例代码

### 5.1 主解：引理 4 的候选枚举

> 与 `appendix/P1582/P1582.cpp` **逐字节一致**。

```cpp
// 题目：P1582 倒水
// https://www.luogu.com.cn/problem/P1582
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxb{37};    // 枚举位宽 0..36:N<2^31 只需 0..31,32..36 为 +5 松弛冗余

i64 n;
int k;

int pc(i64 x){return __builtin_popcountll(x);}   // 二进制 1 的个数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>k;
	i64 ans{1145141919810};   // 114514 家族哨兵:K>=1 时必被更新(答案 < 2^31)
	if(pc(n)<=k)
		ans=0;               // 一瓶不买就已达标
	for(int i=0;i<mxb;++i)
	{
		if(n>>i&1)
			continue;        // 该位已是 1,不可能是最高分歧位
		i64 t=(n>>(i+1)<<(i+1))|(1LL<<i);   // 高位保留、第 i 位补 1、低位清零
		if(pc(t)<=k)
			ans=min(ans,t-n);
	}
	cout<<ans<<'\n';
	return 0;
}
```

**代码结构对照**：`pc` 是引理 2 的二进制 1 计数；`ans=0` 分支对应推论 5 中 $T=N$ 这个候选；循环体三行依次是引理 4 的 (a) 跳过置位、(b)(c) 构造 $T_i$、验 $\mathrm{pc}(T_i)\le k$ 并更新最小差。整个程序没有数组、没有递归，$37$ 次 popcount 结束战斗。

### 5.2 对照实现：真·模拟暴力（仅用于小规模对拍）

见 `appendix/P1582/P1582_brute.cpp`。它**不借用**"最小瓶数 $=\mathrm{pc}$"这一结论，而是把题意原样搬进代码：

- 状态 $=$ 各水位（$2$ 的幂）的瓶数分布 `c[]`；初始 $n+x$ 个 $1$ 升瓶即 `c[0]=n+x`；
- 操作 $=$ 任取一个 $j$ 若 `c[j]>=2` 则 `c[j]-=2, c[j+1]+=1`（两瓶 $2^j$ 合成一瓶 $2^{j+1}$）；
- `dfs(c)` 递归取所有合并选择的最小终局瓶数，`map` 记忆化（不同总量的状态空间不相交，可安全共享）；
- 外层 $x=0,1,2,\ldots$ 逐个试，第一个 `dfs(c)<=k` 的 $x$ 即答案。

```cpp
// 题目：P1582 倒水 —— 暴力基准(真·模拟,不借用 popcount)
// 状态=各水位(2 的幂)的瓶数分布;从 n+x 个 1 升瓶出发,
// DFS 枚举所有"两瓶等量合并"的顺序,取最少剩余瓶数。
// 仅适用于小规模(n+x<=1023),超出范围直接报错退出。
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int LV{10};    // 水位层数 2^0..2^9,故 n+x<=1023

i64 n;
int k;

map<array<int,LV>,int>memo;   // 瓶数分布 -> 从该分布出发的最少剩余瓶数

int dfs(array<int,LV>c)
{
	auto it=memo.find(c);
	if(it!=memo.end())
		return it->second;
	int ans=0;
	for(int j=0;j<LV;++j)
		ans+=c[j];            // 就地停手也是一种终局
	for(int j=0;j+1<LV;++j)
		if(c[j]>=2)           // 两瓶 2^j 合成一瓶 2^(j+1),瓶数 -1
		{
			auto d=c;
			d[j]-=2;
			++d[j+1];
			ans=min(ans,dfs(d));
		}
	memo[c]=ans;
	return ans;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>k;
	for(i64 x=0;;++x)         // 枚举买入瓶数:第一个达标的 x 即答案
	{
		if(n+x>(1<<LV)-1)
		{
			cerr<<"brute: n+x 超出小规模范围\n";
			return 1;
		}
		array<int,LV>c{};
		c[0]=(int)(n+x);      // 初始:n+x 个 1 升瓶
		if(dfs(c)<=k)
		{
			cout<<x<<'\n';
			return 0;
		}
	}
}
```

这一版与标程**零共享假设**：它模拟的是瓶子的真实合并过程，因此可以作为引理 2 的独立交叉验证基准——若引理 2 有漏洞、或标程的候选构造有误，这里会立刻暴露。$N\le128$ 时一次运行涉及的状态最多数十万量级（最坏的 $n=65,k=1$ 约 $6.6\times10^5$ 个分布），C++ 里依然是毫秒级；$N$ 再大状态数爆炸，所以只用于 §4.5 的小规模对拍。`P1582_check.py` 里还附了一个 Python 纯模拟版，用于把整条链（定义 $\to$ 引理 2 $\to$ 归约 $\to$ 答案）端到端复核。

### 5.3 易错点清单

- **漏掉 $T=N$ 这个候选**（$x=0$）：$\mathrm{pc}(N)\le K$ 时答案就是 $0$，忘了 `if(pc(n)<=k) ans=0;` 会给出偏大的错误答案。
- **把 $N$ 的第 $i$ 位为 $1$ 的 $i$ 也枚举进去**：此时"最高分歧位"不可能是 $i$（该位两边都是 $1$），算出的 $T_i<N$，差为负，直接污染 `min`。
- **构造 $T_i$ 时忘了清低位**：`(n>>(i+1)<<(i+1))|(1LL<<i)` 中左移右移就是把低位清零，只置 $i$ 位；若误写成 `n|(1LL<<i)`，得到的不是"最小候选"，答案会偏大。
- **用 `int` 存总量**：$N$ 可逼近 $2^{31}$，$T_i$ 最大到 $2^{31}$，超出 `int` 上限，必须 `i64`（差 $T_i-N$ 反而不炸，炸的是 $T_i$ 本身）。
- **以为 $K$ 大就要上复杂算法**：$\mathrm{pc}(N)\le31$，$K\ge31$ 时答案恒 $0$；$K\le1000$ 是幌子。
- **对 $x$ 二分**：谓词非单调（§2.5 反例），二分会锁死错误区间。
- **`cout<<...<<endl;`**：违反本项目风格指南，一律 `'\n'`；I/O 加速三行顺序固定 `cin.tie`、`cout.tie`、`sync_with_stdio`。
