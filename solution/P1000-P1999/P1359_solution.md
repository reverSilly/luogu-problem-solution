# P1359 租用游艇

> 标签：动态规划 DP / 图论 / 最短路 / Floyd 算法 · 难度：普及-

## 1. 重新读题

**大白话版本**

长江上按上游到下游排着 $n$ 个游艇出租站 $1,2,\dots,n$。在 $i$ 号站租一条船，只能归还到**它下游**的某个站 $j$，这一段租金 $r_{i,j}$；还船之后可以再重新租一条接着走。问从 $1$ 号站到 $n$ 号站**最少**要付多少租金。

**先把题面的坑钉死（都以题面为准）**

| 问的问题 | 题面结论 |
|---|---|
| 能不能"回头"往上游走（站号变小）？ | **不能**。题面两处同时锁死：①"并在下游的任何一个游艇出租站归还游艇"——每段行程的终点必须比起点更靠下游；②租金只定义了 $r_{i,j}$（$1\le i<j\le n$），反向段根本没有价格。⇒ 每一段都是 $i\to j$ 且 $i<j$。这是全文唯一承重前提，2.6 会给出"去掉它会怎样"的反例 |
| 站号顺序与上下游的关系？ | 站点沿长江按 $1,2,\dots,n$ 排列，"下游"= 下标更大。退一步说，即使不借助这个地理直觉也无碍：题面把"可租的一段"的集合**直接定义**为 $\{(i,j):1\le i<j\le n\}$（只有这些下标有租金 $r_{i,j}$），算法需要的全部信息就是"合法的段恰是 $i<j$"，不需要额外的几何性质 |
| 中途可以换船吗？ | 可以，每个站都能重新租。所以求的是**分段租金之和**的最小值，不必一次租到底 |
| $r$ 满足三角不等式吗？ | **不保证**。题面只保证"计算过程中任何时刻数值都不超过 $10^6$"，对大小关系没有任何约束。"两段比一段便宜"完全合法（见 4.3 例 1：$r_{1,3}=21>r_{1,2}+r_{2,3}=15$）⇒ 必须做换乘闭包 |
| 输入到底几个数、怎么排？ | "半矩阵"= 上三角不含对角线，共 $n-1$ 行：第 $i$ 行（$1\le i\le n-1$）依次给 $r_{i,i+1},r_{i,i+2},\dots,r_{i,n}$，共 $n-i$ 个数，合计 $\frac{n(n-1)}{2}$ 个 |
| 求什么、怎么输出？ | 只问 $1\to n$ 一个数，输出一个整数，无精度/前缀要求 |
| 有官方样例可对标吗？ | **本地题面文件 `P1359.md` 里没有样例**（只有描述、输入/输出格式与提示），所以无法对标官方样例；4.3 全部改为手算自造小例，并如实声明 |

**约束与暗示**

| 量 | 范围 | 暗示 |
|---|---|---|
| $n$ | $\le 200$ | $n^2=4\times10^4$、$n^3=8\times10^6$ 都远小于 $10^8$ ⇒ $O(n^2)$ 的 DP 和 $O(n^3)$ 的 Floyd **都能过**，选谁是"想清楚模型"的问题，不是"跑得动"的问题（2.6 给算式对比） |
| 数值 | 任何时刻 $\le 10^6$ | `int` 绰绰有余：$f[i]+a[i][j]\le 2\times10^6\ll 2.1\times10^9$，不必 `long long` |
| 边数 | $\frac{n(n-1)}{2}$，**完备** DAG | 图极稠密 ⇒ 堆优化 Dijkstra 无收益；而拓扑序递推连建图都省了，直接在矩阵上扫 |
| 下界 | $1\le n$ | $n=1$ 合法：人在终点，答案 $0$，且此时输入没有任何矩阵行（2.7） |

## 2. 思维链（Chain-of-thought）

### 2.1 第一步：把"只能向下游还船"这个机制压干净

几何语言（上游/下游）对我们没用，先把题面前提翻译成组合语言。

**引理 1（任一可行行程是严格递增的站号链）** 把一次"租—还"看作一段。由题面，每段形如 $i\to j$ 且 $i<j$。于是一整条从 $1$ 到 $n$ 的方案必为
$$1=v_0<v_1<\cdots<v_k=n,$$
其总租金为 $\sum_{t=1}^{k}a[v_{t-1}][v_t]$（下文用 $a[i][j]$ 表示题面 $r_{i,j}$）。特别地：站号**严格上升**、任何站至多经过一次、段数 $k\le n-1$。

**证明**：每段都要求起点下标小于终点下标（题面前提 ①②），故 $v_{t-1}<v_t$ 对每段成立，链起来得 $1=v_0<v_1<\cdots<v_k$；终点是 $n$，故 $v_k=n$。严格不等式传递后仍是严格不等式，所以序列不重复出现任何一个下标（若 $v_p=v_q$ 且 $p<q$，则由严格递增有 $v_p<v_q$，矛盾）。站号取自 $\{1,\dots,n\}$ 且互不相同，故 $k+1\le n$，即 $k\le n-1$。$\blacksquare$

> 引理 1 给了两件事，后面都要用：**无环**（不可能回到已走过的站，方案有限且只有至多 $n-1$ 段）与**拓扑序现成**（把站按 $1,2,\dots,n$ 排列就自动是拓扑序，不需要求、也不需要判环）。

**推论 1（自然序是拓扑序）** 把站当作点、每个合法的段 $i\to j$（$i<j$）当作一条有向边，得到图 $G$。$G$ 中没有环，且 $1,2,\dots,n$ 这个顺序是 $G$ 的一个拓扑序。

**证明**：任取一条边 $u\to v$，由前提 $u<v$，即每条边都从序列中较前的位置指向较后的位置，这正是拓扑序的定义。环的存在要求沿环走一圈回到起点、下标既严格增大又等于原值，矛盾，故无环。$\blacksquare$

### 2.2 最朴素的想法：一次租到底，以及它的破绽

最省事的"解法"是 $ans=a[1][n]$。但题面从未说"直达最便宜"。

**引理 2（输入矩阵一般不满足三角不等式，且题面不允许我们假设它满足）** 题面关于数值只有一句"保证计算过程中任何时刻数值都不超过 $10^6$"，没有任何形如 $a[i][k]\le a[i][j]+a[j][k]$ 的约束。因此"中途换乘更便宜"是合法数据。

**证明**：合法性由"未被禁止"给出——构造 $n=3$，输入
```
3
5 21
10
```
即 $a[1][2]=5,\ a[1][3]=21,\ a[2][3]=10$，三个数都不超过 $10^6$，符合输入格式（第 1 行 2 个数、第 2 行 1 个数）。此时 $a[1][3]=21>15=a[1][2]+a[2][3]$，三角不等式**反向**成立，直达方案被" $1\to2\to3$ "严格打败，$ans=a[1][n]$ 的算法在这组数据上输出 $21$ 而非正确的 $15$。$\blacksquare$

> 现实解释也支持这一点：$a[i][j]$ 是"在 $i$ 租一条船一路开到 $j$"的**一次**租赁定价，而 $a[i][k]+a[k][j]$ 是**两次**租赁的价格之和；两次租赁各自可能有各自的促销/短途价，二者没有必然大小关系。所以不能假设闭包已经做好，必须自己跑。

那就贪心？"每段都挑最便宜的下一站"。反例见 4.3 例 3（同一组数据手算：贪心 $101$，最优 $10$）。失败模式很清楚：**当下最便宜的那一段可能把你送到一个"去终点很贵"的站**，而代价是要在若干段之后才暴露。也就是说，"局部最优 + 后续随便"不成立，但"**局部最优性可以在固定终点上分解**"看起来还活着——这正是 DP 的信号。

### 2.3 正解雏形：按终点写 DP，升序一遍扫

**状态定义**：$f[j]= $ 从 $1$ 号站到 $j$ 号站的最少租金（$1\le j\le n$），$f[1]=0$。

**转移**：对 $j\ge2$，
$$f[j]=\min_{1\le i<j}\bigl(f[i]+a[i][j]\bigr).$$

**引理 3（递式的正确性）** 对每个 $j$，按上式算出的 $f[j]$ 等于"从 $1$ 到 $j$ 的所有可行行程"的最小租金。

**证明**（对 $j$ 归纳）：

- **基**：$j=1$。由引理 1，任何"$1$ 到 $1$"的行程都形如 $1=v_0<\cdots<v_k=1$；若 $k\ge1$ 则严格递增给出 $v_0<v_k$，即 $1<1$，矛盾，故只能 $k=0$——"一条都不租"是唯一方案，租金 $0$，于是 $OPT(1)=0=f[1]$，且 $j=1$ 处递式根本不需要枚举。
- **归纳方向一（$f[j]\le OPT(j)$，即递式不会低估）**：设 $j\ge2$，取 $1\to j$ 的一条最优行程 $1=v_0<\cdots<v_k=j$（因 $v_0=1<j=v_k$，严格递增迫使 $k\ge1$）。记倒数第二个站 $i=v_{k-1}$，由引理 1 有 $1\le i<j$。该行程去掉最后一段，剩下 $1\to i$ 的 $v_0<\cdots<v_{k-1}=i$ 仍是一段号严格递增的可行行程（引理 1；$k=1$ 时它就是"空行程 $1=i$"，费用 $0=f[1]$，同样适用归纳假设），其租金 $\ge f[i]$（归纳假设：$f[i]$ 已是 $1\to i$ 的最少租金）。于是
$$OPT(j)=\sum_{t=1}^{k-1}a[v_{t-1}][v_t]+a[i][j]\ \ge\ f[i]+a[i][j]\ \ge\ \min_{1\le i'<j}\bigl(f[i']+a[i'][j]\bigr)=f[j].$$
- **归纳方向二（$f[j]\ge OPT(j)$，即递式不会高估）**：递式取到最小值的那个 $i$ 满足 $i<j$，由归纳假设存在达到 $f[i]$ 的可行行程 $1=v_0<\cdots<v_m=i$。在它后面接一段 $i\to j$：因为 $i<j$，$j$ 在 $i$ 的下游，"在下游还船"合法，$a[i][j]$ 有定义；接完的站号序列 $v_0<\cdots<v_m=i<j$ 仍严格递增，故是一条合法的 $1\to j$ 行程（引理 1 的反向验证），租金恰为 $f[i]+a[i][j]=f[j]$。所以 $OPT(j)\le f[j]$。

两侧夹住得 $f[j]=OPT(j)$。归纳所需的"$f[i]$ 已算好"由 $i<j$ 与**按 $j$ 升序计算**保证（推论 1：自然序是拓扑序，所有入边都来自更早的 $i$）。$\blacksquare$

> 两处值得点名：**方向二才是"覆盖所有可行方案"的关键**——它说的是"任何一条由递式拼出来的候选都真的能开"，而 $i<j$ 恰好就是"下游"这一题面前提，所以无环前提在这里被用掉了；**方向一**只用"最优行程的前缀也必须最优"这一标准剪链论证（若前缀不是最优，换掉前缀可得更便宜的 $1\to j$，矛盾——上面用 $\ge f[i]$ 直接写了这个意思）。
> 另外注意：$f[i]$ 本身已经允许任意段数（归纳假设），所以 $f[j]=\min_i(f[i]+a[i][j])$ 一步就同时覆盖了"直达 / 两段 / 三段 / …"的全部方案，不需要在外层再枚举段数。这一点在 4.3 例 2 用三段最优的数据手算验证。

递式"覆盖所有可行方案"这件事还值得用组合语言独立说一遍，因为它才是 $O(n^2)$ 敢取代 $O(2^n)$ 的理由。

**引理 3'（按"最后一段起点"分桶，桶数 $j-1$ 却覆盖 $2^{j-2}$ 条链）** 固定 $j\ge2$，记 $\mathcal C_j$ 为全部链 $1=v_0<\cdots<v_k=j$（$k\ge1$）的集合。映射 $\varphi(c)=v_{k-1}$ 把 $\mathcal C_j$ **不重不漏**地划分进 $j-1$ 个桶 $\mathcal C_j^{(1)},\dots,\mathcal C_j^{(j-1)}$，并且 $\min_{c\in\mathcal C_j^{(i)}}\mathrm{cost}(c)=f[i]+a[i][j]$。

**证明**：

- **值域正确**：引理 1 给 $v_{k-1}<v_k=j$ 且 $v_{k-1}\ge v_0=1$，故 $\varphi(c)\in\{1,\dots,j-1\}$，桶号合法。
- **不漏**：任取 $i\in\{1,\dots,j-1\}$，链 $1\to i\to j$（当 $i=1$ 时即 $1\to j$，视 $1\to1$ 为空段）满足 $1\le i<j$，两段都向下游，故 $\mathcal C_j^{(i)}$ 非空，$j-1$ 个桶一个都不空。
- **不重**：一条链 $c$ 的最后一段由它的末两个顶点唯一决定（序列严格递增 ⇒ 末元素 $j$、倒数第二个元素 $\varphi(c)$ 都唯一），所以 $c$ 只属于一个桶。
- **桶内最优 = $f[i]+a[i][j]$**：构造双射 $\psi:\mathcal C_j^{(i)}\to\{$ $1\to i$ 的链 $\}\cup\{$空链（仅 $i=1$ 需要它，用来接 $1\to j$ 这条一段链）$\}$，$\psi(c)=$ 删去 $c$ 的最后一段。它可逆，逆映射写得出：对任一 $1\to i$ 的链 $c'$，接上段 $i\to j$ 得 $c'\oplus(i\to j)$ —— 因 $i<j$，这段"向下游还船"合法、$a[i][j]$ 有定义；又 $c'$ 自身严格递增，接上更大的 $j$ 后仍严格递增，故落在 $\mathcal C_j^{(i)}$ 内。两向互逆的理由：$\psi$ 删去的恰好就是最后添加的那一段（链的末两点由严格递增唯一确定，不存在"删哪一段"的歧义），而 $\oplus$ 接回的也恰好是 $\psi$ 删掉的那一段；于是 $\psi$ 是双射。再有 $\mathrm{cost}(c)=\mathrm{cost}(\psi(c))+a[i][j]$，其中 $a[i][j]$ 在桶内是**常数**。常数平移不改变谁最小，故 $\min_{c\in\mathcal C_j^{(i)}}\mathrm{cost}(c)=\bigl(\min_{c'}\mathrm{cost}(c')\bigr)+a[i][j]=f[i]+a[i][j]$（最后一步是归纳假设，$i<j$ 保证 $f[i]$ 已算好）。
- **合并**：$\mathcal C_j$ 是这 $j-1$ 个桶的不交并，故 $OPT(j)=\min_{1\le i<j}\bigl(f[i]+a[i][j]\bigr)$，与递式一字不差。$\blacksquare$

> **规模对照**（这才是要点）：$\mathcal C_j$ 的大小是 $2^{j-2}$ —— 中间站可任选 $\{2,\dots,j-1\}$ 的任意子集，而子集与链一一对应（选出的下标按递增排好就是一条链；反过来链的中间项集合就是原子集，两个方向互逆，严格递增保证"排好"的方式唯一）。$n=200$ 时链的总数天文数字，但引理 3' 说明**只需要 $j-1$ 次 $\min$**：指数级对象被压成了"前一站是谁"这一个 $n$ 值状态。这就是 DP 相对暴力枚举全部换乘方案的压缩比，也是 2.3 末尾那句"$f[i]$ 自带任意段数"的严格形态。

### 2.4 换个马甲：这就是最短路

**定理 1（模型等价）** 构造带权有向图 $G$：顶点 $\{1,\dots,n\}$，对每对 $i<j$ 连一条边 $i\to j$、权为 $a[i][j]$。则题面所求 $=$ $G$ 中从 $1$ 到 $n$ 的最短路长度。

**证明**：
- 任一可行行程 $1=v_0<\cdots<v_k=n$ 中每段都满足 $v_{t-1}<v_t$，恰是 $G$ 中一条有向路径，二者费用同为 $\sum_t a[v_{t-1}][v_t]$。故最短路长度 $\le$ 最优行程租金。
- 反之 $G$ 的任一路径 $u_0\to u_1\to\cdots\to u_\ell$ 的每条边都形如 $u_{t-1}<u_t$（$G$ 只有这种边），由严格递增的传递性得 $u_0<u_1<\cdots<u_\ell$，于是它对应一段号递增、每段都能"在下游还船"的可行行程，费用相同。故最优行程租金 $\le$ 最短路长度。

两个方向都是"同一批对象、同一个代价函数"，故两个最小值相等。$\blacksquare$

于是 2.3 的递式获得第二个身份：**在 DAG 上按拓扑序松弛**。标准 DAG 最短路定理说"按拓扑序处理每个顶点、对它的所有出边做松弛，结束后 $dis[\cdot]$ 即最短距离"；这里拓扑序就是 $1,2,\dots,n$，而"$u$ 的出边 $u\to v$ 松弛 $dis[v]\leftarrow dis[u]+a[u][v]$"重排成"处理 $v$ 时枚举所有入边 $i\to v$ 取 $\min$"，正是同一个 $\min$ 表达式，只是循环写法不同。

**引理 4（Floyd 同样给出正确答案，只是更贵）** 在这张图上跑 Floyd：初始化 $d[i][j]=a[i][j]$（$i<j$）、$d[i][i]=0$、其余视为不可达，三重循环 $k,i,j$ 做 $d[i][j]\leftarrow\min(d[i][j],d[i][k]+d[k][j])$，结束后 $d[1][n]$ 即所求。

**证明**：对 $k$ 归纳。记 $D_k[i][j]=$ 从 $i$ 到 $j$、**中间点**（不含端点）全部取自 $\{1,\dots,k\}$ 的路径的最小费用；无这样的路径时记 $+\infty$。最小值取得到（而非只是下确界）是因为由推论 1，这类路径的顶点序列严格递增、条数有限（$\le 2^{n}$），有限集合上必有最小元。
- $k=0$：不许有中间点，于是合法路径只能是"一条边 $i\to j$"（需 $i<j$，费用 $a[i][j]$）或"零条边 $i=j$"（费用 $0$）；$i>j$ 时两者都不存在，为 $+\infty$。与初始化（上三角取 $a$、对角线 $0$、**下三角与"反向"位置必须是 $+\infty$ 而不是 $0$**）逐条一致。
- $k-1\to k$：取达到 $D_k[i][j]$ 的一条路径 $P$，按它是否以 $k$ 为中间点分情形。
  - **不经过 $k$**：$P$ 的中间点 $\subseteq\{1,\dots,k-1\}$，所以 $P$ 同时是 $D_{k-1}[i][j]$ 的候选，$\mathrm{cost}(P)\ge D_{k-1}[i][j]$；反之 $D_{k-1}[i][j]$ 的候选许可集合更严，故这一类的最小值**恰**为 $D_{k-1}[i][j]$。
  - **经过 $k$**：由推论 1，$P$ 的顶点沿下标严格递增，故 $k$ **至多出现一次**，可在 $k$ 处**唯一**拆成前缀 $P_1:i\leadsto k$ 与后缀 $P_2:k\leadsto j$，且 $\mathrm{cost}(P)=\mathrm{cost}(P_1)+\mathrm{cost}(P_2)$。两段的中间点都是 $P$ 的中间点的子集，又都不含 $k$（$k$ 在 $P_1$ 里只是终点、在 $P_2$ 里只是起点），故都 $\subseteq\{1,\dots,k-1\}$，于是 $\mathrm{cost}(P)\ge D_{k-1}[i][k]+D_{k-1}[k][j]$。反向拼接同样可行：取分别达到 $D_{k-1}[i][k]$ 与 $D_{k-1}[k][j]$ 的两条路径（若任一为 $+\infty$，本情形直接不可行、不产生候选，$\min$ 自动忽略），它们顶点递增，拼起来是 $i<\cdots<k<\cdots<j$，相邻两点下标递增 ⇒ 每条边都存在于 $G$，且不重复任何顶点，因此确是 $D_k[i][j]$ 的合法候选、费用恰为两者之和，等号可达。故这一类的最小值**恰**为 $D_{k-1}[i][k]+D_{k-1}[k][j]$。
  - 两类取 $\min$ 即 $D_k[i][j]=\min\bigl(D_{k-1}[i][j],\;D_{k-1}[i][k]+D_{k-1}[k][j]\bigr)$，与 Floyd 的转移同式（Floyd 原地更新时同一轮 $k$ 里 $d[i][k]$、$d[k][j]$ 不会被本轮改动，因为要改它们需要以 $k$ 为**中间点**，而 $i\to k\to k$ 型转移要求 $k<k$，由严格递增不可能 —— 这也再次是无环前提在起作用）。
- $k=n$：所有顶点都允许作中间点，$D_n[i][j]$ 不再有任何限制，就是真正的最短路费用。$\blacksquare$

> Floyd 的常规前提"没有负环"在这里是**自动**满足的（图根本无环），所以它不会有"越绕越便宜"的隐患；而我们的 $a[i][j]\ge 0$ 也排除了负权。

### 2.5 闭包视角：为什么"必须跑闭包"，以及需要跑多少

**定义**：$a^*[i][j]=$ 所有满足 $i=v_0<\cdots<v_k=j$ 的链的租金最小值（$i<j$），$a^*[i][i]=0$。这就是将 $a$ 关于"$\min,+$"做**传递闭包**。

**引理 5（$a^*$ 满足三角不等式，$a$ 一般不满足）** 对任意 $i<j<k$ 有 $a^*[i][k]\le a^*[i][j]+a^*[j][k]$。

**证明**：取达到 $a^*[i][j]$ 的递增链 $i=u_0<\cdots<u_p=j$ 与达到 $a^*[j][k]$ 的递增链 $j=w_0<\cdots<w_q=k$（最小值能取到，因为 $n$ 有限、由引理 1 链数有限）。首尾相接得 $i=u_0<\cdots<u_p=j=w_0<\cdots<w_q=k$；拼接点 $j$ 只出现一次，其余部分各自严格递增，故整条仍是"站号严格递增"的合法链（引理 1 的反向验证），其租金为两链之和。而 $a^*[i][k]$ 是这类链租金的**最小值**（集合有限，最小一定能取到，见引理 4 开头那句"有限集合上必有最小元"），故 $a^*[i][k]\le$ 这条具体链的租金 $=a^*[i][j]+a^*[j][k]$。$\blacksquare$

> **反方向的断言也要有据**：引理标题里"$a$ 一般不满足"不是修辞——2.2 引理 2 的构造（$n=3$，$a[1][3]=21$、$a[1][2]+a[2][3]=15$）就是一组合法输入，它同时满足题面全部约束（格式对、数值 $\le10^6$），却使 $a^*[1][3]=15\ne21=a[1][3]$。所以闭包是**真的在改矩阵**，不是走过场；"直接把输入当度量用"是错解。

> 这条引理把 2.2 的教训说透了：**做完闭包才满足三角不等式，输入矩阵本身不满足**。所以"直接换乘费用是否满足三角不等式"的答案是"题面不保证、必须自己算"，反例形态就是 4.3 例 1（$a[i][k]>a[i][j]+a[j][k]$ 的那一组）。

**引理 6（我们只需要一列/一行，不需要全源）** 记 $OPT(i,j)$ 为 $i\to j$ 的最少租金，则 $a^*[i][j]=OPT(i,j)$，而题面只问 $OPT(1,n)=a^*[1][n]$。

**证明**：$a^*[i][j]$ 的定义与"$i\to j$ 的可行行程集合"完全一致（引理 1 与定理 1 的双向论证，把起点从 $1$ 换成 $i$、终点换成 $j$，论证逐字照搬）。故两者同为该集合上租金的最小值。$\blacksquare$

- 只求**单源** $1$ 到各点：$O(n^2)$ 递推（2.3）就够，因为拓扑序现成，不必枚举"中间点集合"。
- 要回答**任意** $(i,j)$ 的换乘价：才需要 $a^*$ 的全部 $\frac{n(n-1)}{2}$ 项，Floyd $O(n^3)$ 或"对每个源跑一遍 $O(n^2)$ 递推"（合计也是 $O(n^3)$）。
- 本题只问 $(1,n)$：Floyd 做的是**多余**的全源工作。

### 2.6 若题面允许"回头"会怎样（把前提的分量称出来）

假设把题面改成"任意两站间可往返"（把 $a$ 视为对称费用，$i>j$ 也允许）。此时：

1. **自然序不再是拓扑序**（存在从大到小的边），图有环，2.3 的升序一遍扫**不再正确**。
2. **反例形态**（$n=4$，对称费用 $a[1][2]=100,\ a[1][3]=1,\ a[1][4]=100,\ a[2][3]=1,\ a[2][4]=1,\ a[3][4]=100$；与 4.3 例 7 同一组数据）：
   - 只许递增：$f[2]=100$、$f[3]=\min(1,101)=1$、$f[4]=\min(100,101,101)=100$ ⇒ 答案 $100$；
   - 允许回头：$1\to3\to2\to4$ 花 $1+1+1=3$，远优。
   这说明"只能递增"不是打酱油的叙述，而是决定算法形态的前提。这种情况下必须上 **Dijkstra 或 Floyd**（费用非负 ⇒ 无负环，最短路良定义；且最优解必是简单路径，绕圈只会更贵，因为绕一圈至少多付非负费用）。
3. 反过来，**本题的正确前提**下，环不存在，所以既不需要判负环，也不需要 `vis`/堆，$O(n^2)$ 递推是最省的写法；Floyd（引理 4）与稠密 Dijkstra（$O(n^2)$）都是同解的替代品。

**复杂度算式对比**（$n\le200$）：

| 做法 | 松弛次数算式 | $n=200$ | 备注 |
|---|---|---|---|
| 拓扑序 DP（2.3） | $\sum_{j=2}^{n}(j-1)=\frac{n(n-1)}{2}$ | $19900$ | 最省，且只用上三角，无建图 |
| Floyd（引理 4） | $n^3$ | $8\times10^6$ | 算了全源，$400$ 倍冗余 |
| 稠密 Dijkstra | $n^2$ 找最小 + $n^2$ 松弛 | $\sim8\times10^4$ | 正确但代码最长，堆版在稠密图无收益 |

### 2.7 边界与实现细节（逐条过）

1. **$n=1$**：输入没有矩阵行（"接下来的 $n-1=0$ 行"），读入循环 $i=1..0$ 不执行；DP 循环 $j=2..1$ 不执行；$f[1]=0$ ⇒ 输出 $0$。语义上也对：已在终点，不必租船。
2. **$n=2$**：只有一个数 $a[1][2]$，$f[2]=f[1]+a[1][2]=a[1][2]$，与"只能直达"一致。
3. **对角线 $a[i][i]$**：题面无定义，代码里全局默认 $0$，但转移只在 $i<j$ 时读，永远取不到它，故 $0$ 无害（若把循环写成 $i\le j$ 才会中招）。
4. **$i>j$ 的上三角外区域**：同样默认 $0$、同样不被读取。这里要警惕"全局 `int` 数组默认 $0$"这个移植陷阱的反面版本：$0$ 一旦被当成"合法费用 $0$"读进 $\min$，答案会被错误压到 $0$。所以**内层循环上界必须是 $i<j$**，不能图省事写成 $i\le n$。
5. **$f$ 必须显式初始化**：$f[j]$ 在进入 $\min$ 之前必须置为一个大值（`inf`），否则全局默认的 $0$ 会一直赢过所有候选，答案恒为 $0$。代码里在每个 $j$ 的循环体开头写 `f[j]=inf;`，比 `fill_n` 更省，也更不容易漏。
6. **半矩阵读入**：用嵌套 `cin>>a[i][j]`（$i=1..n-1$，$j=i+1..n$）。`>>` 只按空白分隔，所以"每行恰好 $n-i$ 个数"这个换行约定不敏感——即使有人把整个上三角压成一行，也照样读对；但**顺序**必须是行优先 $r_{1,2},r_{1,3},\dots,r_{1,n},r_{2,3},\dots$，这与题面"第 $i$ 行是 $r_{i,j}$（$i<j$）"一致。
7. **数值上界**：题面保证计算中任何数值 $\le10^6$，`int` 加一次最多 $2\times10^6$，离 $2^{31}-1$ 很远；`inf=1145141919` 加 $a$ 也不溢出，但逻辑上 $f$ 里永不会带着 `inf` 去加（完备 DAG ⇒ 每个 $j$ 至少有 $i=1$ 这个入边，见下条）。
8. **无解性**：不存在。图是**完备**的：任意 $i<j$ 都有边，$1\to n$ 直达边一定存在，故 $f[n]$ 一定被某个有限值更新过，不需要判"不可达"。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 题面"在下游归还" + 只给 $i<j$ 的租金 ⇒ 每段站号严格增，行程是递增链，无环、段数 $\le n-1$、自然序即拓扑序（引理 1、推论 1）。
- **naive answer & its break** — $ans=a[1][n]$ 死在"两段比一段便宜"，而题面只限制数值大小、不限制三角不等式 ⇒ 必须自己算闭包（引理 2、引理 5）。
- **greedy attempt → dissect failure** — "下一段挑最便宜"被"到终点很贵的站"打穿（4.3 例 3 手算 $101$ vs $10$），失败在局部选择不具备可加的最优性。
- **classic problem solution（DP）** — 以终点为状态 $f[j]=\min_{i<j}(f[i]+a[i][j])$，双向夹逼归纳证明正确；$f[i]$ 自带任意段数，所以一遍升序即覆盖全部方案（引理 3）。
- **bucket by the last leg（计数 + 压缩）** — $2^{j-2}$ 条递增链按"最后一段起点"不重不漏地分成 $j-1$ 个桶，桶内只加常数 $a[i][j]$，于是指数级枚举压成 $j-1$ 次 $\min$（引理 3'）。
- **reduce to easier problem（图论）** — 完备 DAG 上的 $1\to n$ 最短路，与原题双向构造等价（定理 1）；DP 就是按拓扑序松弛。
- **consider alternative techniques** — Floyd 闭包（引理 4，归纳证明中间点集合递增）、稠密 Dijkstra；三者同解，只差冗余倍数。
- **cost accounting / scope cut** — 单源 $O(n^2)=19900$ 次 vs 全源 $O(n^3)=8\times10^6$ 次；题面只要 $(1,n)$，故取 $O(n^2)$（2.6 表）。
- **stress-test the premise** — 若允许回头，自然序不再是拓扑序，$O(n^2)$ 递推给出 $100$ 而真值 $3$，必须换成 Floyd/Dijkstra（2.6 反例、4.3 例 7）。
- **defer reconstruction** — 只要费用就不用存方案；想知道方案就在转移时记下取等的 $i$ 从 $n$ 回溯（4.3 例 5 手算回溯出 $1\to2\to3\to4\to5$）。
- **handle degeneracy** — $n=1$ 输出 $0$、$n=2$ 只有直达、$a[i][i]$ 与下三角不被读取、`f[j]=inf` 必须显式初始化、行优先读上三角（2.7）。

## 4. 真实解法（Real Solution）

### 4.1 符号表（Notation Glossary）

> 全文（公式与代码）**统一 1-based**，与题面 $1\le i<j\le n$ 一致，不做下标转换；这样输入循环的 $j=i+1..n$ 与题面"$j$ 比 $i$ 靠下游"逐字对应。

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n` | 出租站个数 | `int`，输入，$\le200$ | 站号 $1..n$ 即上游 $\to$ 下游 |
| `a[i][j]` | 题面 $r_{i,j}$：在 $i$ 租船、在下游 $j$ 归还的租金 | `int a[mxn][mxn]`，只写 $i<j$ 的上三角；$i\ge j$ 处保持 $0$ 且**永不被读** | "一段直达的价"，未必最便宜 |
| `f[j]` | 从 $1$ 到 $j$ 的最少租金（允许任意次换乘） | `int f[mxn]`；`f[1]=0`，每个 $j\ge2$ 进循环先置 `inf` | "$j$ 是终点"，升序算 ⇒ 拓扑序（引理 3） |
| `i` | 最后一次换乘/上船的起点，即 $j$ 的前一站 | 内层循环 $1\le i<j$ | 枚举"$j$ 前一站是谁" |
| `inf{1145141919}` | $\min$ 的空哨兵 | `constexpr int` | 114514 家族；远大于 $10^6$，加 $a$ 不溢 |
| `mxn{205}` | 数组尺寸 | $200+5$ | "+5 松弛" |

### 4.2 算法步骤

1. **读入**：`cin>>n`；行优先读上三角——$i=1..n-1$，$j=i+1..n$ 依次 `cin>>a[i][j]`（共 $\frac{n(n-1)}{2}$ 个数，2.7-6）。
2. **置初值**：`f[1]=0`（起点到自己，不花钱）。
3. **按拓扑序递推**：$j=2..n$：`f[j]=inf`，再对 $i=1..j-1$ 做 `f[j]=min(f[j],f[i]+a[i][j])`。这一步的正确性由引理 3（$i<j$ 保证 $f[i]$ 已算完且边合法），循环上界 $i<j$ 保证不读到 $a[i][i]$ 与下三角的 $0$（2.7-3、2.7-4）。
4. **输出** `cout<<f[n]<<'\n'`。完备 DAG 保证 `f[n]` 必为有限值（2.7-8）。

**复杂度**：时间 $\frac{n(n-1)}{2}=O(n^2)$（$n=200$ 时 $19900$ 次 $\min$），空间 $O(n^2)$（矩阵 $a$，$205^2\times4\approx168\,\mathrm{KB}$）。与 Floyd 的 $8\times10^6$ 相比是 $400$ 倍差距，但两者都远小于时限，选 $O(n^2)$ 的理由是**模型正确性的利用**，不是怕超时。

**验证状态**：本地题面无官方样例，故**无法对标**；4.3 给出 7 组手算，其中例 1、2、3、4、5 共 $5$ 组做了**全部递增链的穷举比对**（分别 $2,4,4,4,8$ 条链），例 1 另跑一遍 Floyd 逐步对照。**没有**编译、运行任何代码，**没有**生成数据文件或随机对拍。

### 4.3 验证（全部手工推演）

约定：每组先按 4.2 逐步填 $f$，再枚举**所有** $1\to n$ 的递增链（$n$ 个站时中间站可任选子集，共 $2^{n-2}$ 条）取最小，两值必须一致。

**例 1（题面格式的 $n=3$，"两段比一段便宜" ⇒ 必须闭包）**
```
3
5 21
10
```
读入检查：第 1 行 $n-1=2$ 个数 $a[1][2]=5,a[1][3]=21$；第 2 行 $1$ 个数 $a[2][3]=10$。

| $j$ | 候选 $f[i]+a[i][j]$ | $f[j]$ |
|---|---|---|
| 1 | —— | $0$ |
| 2 | $f[1]+a[1][2]=0+5=5$ | $5$ |
| 3 | $f[1]+a[1][3]=0+21=21$；$f[2]+a[2][3]=5+10=15$ | $\mathbf{15}$ |

全部递增链（$2^{3-2}=2$ 条）：$1\to3=21$，$1\to2\to3=5+10=15$；$\min=15$ ✔ 一致。
闭包对照：$a[1][3]=21>a[1][2]+a[2][3]=15$，三角不等式不成立 ⇒ 直接抄 $a[1][n]$ 会输出 $21$（错），跑闭包/DP 才得 $15$。
Floyd 交叉验证（引理 4）：初值 $d[1][2]=5,d[1][3]=21,d[2][3]=10$。$k=1$：无 $i<1$，$d$ 不变；$k=2$：$d[1][3]=\min(21,d[1][2]+d[2][3]=15)=15$；$k=3$：无 $j>3$，不变。$d[1][3]=15$ ✔ 与 DP 同值。

**例 2（$n=4$，最优是三段链 ⇒ 验证"一步递推覆盖任意段数"）**
```
4
3 10 20
3 10
3
```
即 $a[1][2]=3,a[1][3]=10,a[1][4]=20,a[2][3]=3,a[2][4]=10,a[3][4]=3$。

| $j$ | 候选 | $f[j]$ |
|---|---|---|
| 1 | —— | $0$ |
| 2 | $0+3=3$ | $3$ |
| 3 | $0+10=10$；$f[2]+3=6$ | $6$（来自 $1\to2\to3$） |
| 4 | $0+20=20$；$f[2]+10=13$；$f[3]+3=9$ | $\mathbf{9}$（来自 $1\to2\to3\to4$） |

全部链（$2^{2}=4$ 条）：$1\to4=20$；$1\to2\to4=3+10=13$；$1\to3\to4=10+3=13$；$1\to2\to3\to4=3+3+3=9$；$\min=9$ ✔。
关键点：$f[4]$ 只加了一段，但它用的 $f[3]=6$ 自己已经是两段的结果 ⇒ 递推把"段数"吃进了状态里，外层无需枚举 $k$。

**例 3（贪心"下段最便宜"被推翻 + DP 正确）**
```
4
1 5 100
100 100
5
```
即 $a[1][2]=1,a[1][3]=5,a[1][4]=100,a[2][3]=100,a[2][4]=100,a[3][4]=5$。

| $j$ | 候选 | $f[j]$ |
|---|---|---|
| 1 | —— | $0$ |
| 2 | $0+1=1$ | $1$ |
| 3 | $0+5=5$；$f[2]+100=101$ | $5$（直达，**不**经过看起来便宜的站 2） |
| 4 | $0+100=100$；$f[2]+100=101$；$f[3]+5=10$ | $\mathbf{10}$ |

全部链：$100$；$1\to2\to4=1+100=101$；$1\to3\to4=5+5=10$；$1\to2\to3\to4=1+100+5=106$；$\min=10$ ✔。
贪心对照：第一步挑最便宜的段 $1\to2$（价 $1$，比 $1\to3$ 的 $5$ 和 $1\to4$ 的 $100$ 都便宜）。此后站在 $2$，出发的两段都要价 $100$（$2\to4$ 与 $2\to3$ 并列），无论怎么破平局都不妙：直接 $2\to4$ 得 $1+100=101$；先 $2\to3$ 再 $3\to4$ 得 $1+100+5=106$。取较优者仍是 $101$，比最优的 $10$ 多花 $91$。失败原因：$2$ 是"进门便宜出门贵"的站，代价要等走进去之后才暴露，而贪心第一步已经收不回；对照 $f[3]=\min(5,101)=5$ —— DP 正是在这一步把"经过 $2$ 的 $101$"丢掉、保留了直达的 $5$。

**例 7（前提压力测试：若允许回头，$O(n^2)$ 递推失效）** 对称费用 $a[1][2]=100,a[1][3]=1,a[1][4]=100,a[2][3]=1,a[2][4]=1,a[3][4]=100$（本题格式只给上三角，即 $100\ 1\ 100\ /\ 1\ 1\ /\ 100$）。
- 递增递推：$f[2]=100$；$f[3]=\min(1,101)=1$；$f[4]=\min(100,101,101)=100$。
- 允许 $1\to3\to2\to4$（含回头段 $3\to2$）：$1+1+1=3$。

## 5. 示例代码（C++）

```cpp
// P1359 租用游艇
// 题面"只能在下游还船" => 每段 i->j 满足 i<j => 完备 DAG，自然序就是拓扑序
// 于是 f[j]=min_{i<j}(f[i]+a[i][j]) 升序扫一遍即得 1->n 最少租金（O(n^2)，Floyd 的 O(n^3) 也过）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{205};           //n<=200 +5
constexpr int inf{1145141919};

int n;
int a[mxn][mxn],f[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	//半矩阵（上三角）：第 i 行 n-i 个数 r_{i,i+1..n}，行优先；>> 不敏感于换行
	for(int i=1;i<n;++i)
		for(int j=i+1;j<=n;++j)
			cin>>a[i][j];

	f[1]=0;
	for(int j=2;j<=n;++j)   //拓扑序 = 站号升序
	{
		f[j]=inf;           //全局 int 默认 0，不先置 INF 则 min 恒等于 0
		for(int i=1;i<j;++i)    //只读上三角，i 必在 j 上游，a[i][j] 有定义
			f[j]=min(f[j],f[i]+a[i][j]);
	}

	cout<<f[n]<<'\n';   //n==1 时输出 0（已在终点）
	return 0;
}
```

### 代码说明

- **全文 1-based**：与题面 $1\le i<j\le n$ 逐字对应，避免"读入 $i+1$、内部 $i$"的两套下标在三角输入上出错；已在 4.1 声明并保持一致。
- **全局静态数组** `int a[mxn][mxn],f[mxn]`，`mxn{205}`=$200+5$，`constexpr` 花括号初始化；`inf` 用 114514 家族哨兵。
- **移植陷阱的正反两面**：$f[j]$ 在取 $\min$ 之前**必须**显式 `f[j]=inf`（否则默认 $0$ 恒赢）；而 $a$ 里 $i\ge j$ 的那半（含对角线）保持默认 $0$ 却**无害**，因为内层循环严格 $i<j$，永不读取——写成 `i<=n` 或 `i<=j` 就会把 $0$ 当合法租金，答案被错误压成 $0$。这两点分别对应 2.7-3/4 与 2.7-5。
- **输入循环范围**：外层 $i=1..n-1$、内层 $j=i+1..n$，合计 $\frac{n(n-1)}{2}$ 次读入，顺序为题面"半矩阵"的行优先顺序；用 `cin>>` 因而对每行实际个数不敏感（2.7-6）。
- **不需要判不可达**：任意 $i<j$ 都有边，$f[n]$ 一定被 $f[1]+a[1][n]$ 这类有限候选更新过（2.7-8）。
- **风格项**：`#include<bits/stdc++.h>` + `using namespace std;`；`cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);` 顺序固定；换行用 `'\n'` 不用 `endl`；运算符两侧无空格；Tab 缩进；无函数（逻辑短，直接写在 `main`），故无命名问题。
- **等价的 Floyd 写法**（引理 4，供对照，非本解）：把上三角读入后三重循环 `for(k)for(i)for(j)`，只在 $i<k<j$ 时做 `a[i][j]=min(a[i][j],a[i][k]+a[k][j])`，输出 `a[1][n]`；$n\le200$ 同样能过，但多算全源闭包，$8\times10^6$ 次操作对 $19900$ 次。若改成"不限下标"的通用 Floyd，则**必须先把 $i\ge j$（除对角线 $0$ 外）全部填 `inf`** 再跑——留默认 $0$ 等于宣称"反向/原地免费"，会沿着 $0$ 把 $\min$ 一路压成 $0$，正是引理 4 里 $k=0$ 那一步要求的初始化。
- **验证口径**：4.3 的 7 组手算（例 1、2、3、4、5 与"全部递增链"穷举逐条比对，链数分别 $2,4,4,4,8$；例 1 另跑 Floyd 逐步对照；例 5 还回溯了最优方案本身）；**未**编译运行、**未**随机对拍；本地题面无样例故无法对标官方样例。
