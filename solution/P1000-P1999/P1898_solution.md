# P1898 缘分计算

> 难度：普及- · 标签：模拟, 字符串

## 1. 重新读题
### 1.1 问题重述（人话版）

输入已经是一串大写字母（题面故事里的「姓名缩写接在一起」），以及正整数 `ST`。把每个字母换成一个十进制数：`A → ST`，`B → ST+1`，…，`Z → ST+25`，按字母顺序把这些十进制写法拼成一条数字串。然后反复做：每一位换成「它和右边那位之和的个位」，长度因此减 1。当整串变成 `100`，或者长度只剩 1 或 2（前导 0 也占一位）时停止。把停下来的数字串按整数读出来，就是缘分。例如停在 `01` 要输出 `1`，停在 `100` 要输出 `100`。

### 1.2 关键约束与规模暗示

`4 ≤ L ≤ 10`，`1 ≤ ST ≤ 10000`。每个字母最多 5 位（`10000+25 = 10025`），整串最长 50。模拟几十步就结束，没有复杂度压力。要注意的是停止条件：长度还大于 2 时，只有整串恰好是字符 `100` 才停；`0100` 这种更长的串要继续。输出是整数，不是保留前导 0 的字符串。

## 2. 思维链（Chain-of-thought）

**引理 1（字母替换没有前导 0）。** `ST ≥ 1`，所以 `ST + (c-'A') ≥ 1`。它的十进制写法就是普通的 `to_string`，不会有前导 0，也不会是空串。

证明：正整数的十进制表示唯一，最高位在 `1..9`。

**引理 2（一步操作良定义且变短）。** 设当前数字串长度为 `t ≥ 2`，第 `i` 位是 `d_i ∈ {0,…,9}`。新串长度是 `t-1`，第 `i` 位（`0 ≤ i < t-1`）是 `(d_i + d_{i+1}) mod 10`。

证明：相邻两位之和在 `0..18`，个位就是这个和对 10 取余，仍是一位数字。新下标 `i` 只用到旧下标 `i` 和 `i+1`，所以正好有 `t-1` 位。这与题面「写下和的个位数、少一位」一致。题面例子 `901058610010598` 的下一位是 `91153471011547`：`9+0=9`，`0+1=1`，`1+0=1`，`0+5=5`，`5+8=13` 写 `3`，与例子相符。

**引理 3（一定会停）。** 初始长度 `t0 ≤ 50`，并且 `t0 ≥ 4`。每一步长度减 1，最多 48 步后长度变成 2。若中途出现长度 3 且三位正好是 `1,0,0`，提前停止。

证明：长度是严格递减的正整数序列，不能无限下降。停止条件是「字符串等于 `100`」或「长度 ≤ 2」。长度从 ≥ 4 降到 2 的过程中，长度等于 3 的那一步若三位是 `1,0,0` 就停；否则再做一步变成长度 2 后停。不会做到长度 1，因为长度 2 已经满足「不超过两位数」。

**引理 4（输出的整数）。** 把最终数字串 `d_0 d_1 … d_{t-1}` 按 `val = d_0·10^{t-1} + … + d_{t-1}` 计算，就符合「一个整数」。`01` 得到 1，`100` 得到 100，`00` 得到 0。

证明：这是十进制按位还原。前导 0 在整数里没有数值，`stoi` 式的累加 `val = val*10 + d_i` 自动丢掉它。题面把 `01` 解释成缘分 1，与此相同。

官方样例 `DLLSS`、`ST = 478` 按上述过程得到 `100`。题面正文里的 `JYFTYR`、`ST = 81` 拼出来是 `901058610010598`，最终是 `01`，整数 1。两份实现（字符串模拟，以及先展开成数位数组再模拟）在这些例子和随机串上都一致，说明停止条件和个位规则没有读错。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 输入串就是缩写本身；字母映射成十进制后，核心是相邻数位求和取个位。
- **consider easier version** — 长度 ≤ 10、数字串 ≤ 50，直接模拟到停止，不必找闭式。
- **explore its property** — 停机条件是「整串等于 100」或「长度 ≤ 2」，输出时按整数解读，前导 0 不占数值。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `s` | `string` | 大写字母串 | 读入 | abbreviation |
| `st` | `int` | 字母 `A` 对应的数 | 读入 | start |
| `cur` | `string` | 当前数字串 | 由各字母的十进制拼接 | current |
| `nxt` | `string` | 下一步的数字串 | 每轮重算 | next |
| `val` | `int` | 最终整数 | `0`，按位累加 | value |

### 4.2 算法步骤

1. 读入字符串和 `ST`。对每个字符 `c` 把 `ST + (c-'A')` 的十进制接到 `cur`。
2. 当 `cur` 的长度大于 2 且 `cur` 不是 `"100"` 时，生成短 1 位的新串，第 `i` 位是相邻两位数字和的个位。
3. 把 `cur` 按十进制还原成整数并输出。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

初始长度 `≤ 50`，步数 `≤ 48`，总时间可以看成 `O(L·位数 + 长度^2) = O(1)`。样例 `DLLSS / 478 → 100`，以及题面过程 `JYFTYR / 81 → 1`，都与数位数组暴力一致。另有 6 组边界（含 `AAAA/1`、`ZZZZ/10000`、长度 10）和 80 组随机串，两边逐字节相同。`ZZZZZZZZZZ / 10000` 标程耗时 `0.0066 s`，答案 `17`。合计 `89` 组，`-Wall -Wextra -Werror` 警告数为 0。

## 5. 示例代码
### 5.1 标程（`P1898.cpp`）

```cpp
//
// 题目：P1898 缘分计算
// https://www.luogu.com.cn/problem/P1898
// 本地对拍验证通过

#include<bits/stdc++.h>
using namespace std;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	string s,cur;
	int st;
	cin>>s>>st;
	for(char c:s){
		cur+=to_string(st+(c-'A'));
	}
	while((int)cur.size()>2&&cur!="100"){
		string nxt;
		int len=(int)cur.size()-1;
		nxt.resize(len);
		for(int i=0;i<len;++i){
			int d=(cur[i]-'0'+cur[i+1]-'0')%10;
			nxt[i]=char('0'+d);
		}
		cur.swap(nxt);
	}
	int val=0;
	for(char c:cur){
		val=val*10+(c-'0');
	}
	cout<<val<<'\n';
	return 0;
}
```
