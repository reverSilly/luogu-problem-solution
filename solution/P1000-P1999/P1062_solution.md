# P1062 [NOIP 2006 普及组] 数列 题解

---

## 一、发现叙事

拿到这道题，第一反应是"把 $k$ 的方幂和它们的不重复和按从小到大排成序列，求第 $N$ 项"。题目给的例子 $k=3$ 时：

$$1,\ 3,\ 4,\ 9,\ 10,\ 12,\ 13,\ \ldots$$

对应的方幂组合为：

$$3^0,\ 3^1,\ 3^0+3^1,\ 3^2,\ 3^0+3^2,\ 3^1+3^2,\ 3^0+3^1+3^2,\ \ldots$$

观察这个序列的**序号 $N$** 与**项的值**之间的关系。我们先把 $N$ 写成二进制，看看会发生什么：

| $N$ | $N$ 的二进制 | 对应项的值（$k=3$）              | 计算               |
| --- | ------------ | -------------------------------- | ------------------ |
| 1   | `1`          | $3^0=1$                          | `1` 作为三进制 = 1  |
| 2   | `10`         | $3^1=3$                          | `10` 作为三进制 = 3 |
| 3   | `11`         | $3^0+3^1=4$                      | `11` 作为三进制 = 4 |
| 4   | `100`        | $3^2=9$                          | `100` 作为三进制 = 9 |
| 5   | `101`        | $3^0+3^2=10$                     | `101` 作为三进制 = 10 |
| 6   | `110`        | $3^1+3^2=12$                     | `110` 作为三进制 = 12 |
| 7   | `111`        | $3^0+3^1+3^2=13$                 | `111` 作为三进制 = 13 |

规律一目了然：**把 $N$ 的二进制表示直接当作 $k$ 进制数来解释，就得到了第 $N$ 项的值**。

验证题目给的样例：$k=3,\ N=100$。

$100$ 的二进制是 $1100100_2$。把这个二进制串当作三进制数：

$$1100100_{(3)} = 1\times 3^6 + 1\times 3^5 + 0\times 3^4 + 0\times 3^3 + 1\times 3^2 + 0\times 3^1 + 0\times 3^0$$

$$= 729 + 243 + 0 + 0 + 9 + 0 + 0 = 981$$

完全正确。

## 二、思维链与完整证明

### 2.1 问题的形式化

定义集合

$$S_k = \left\{ \sum_{i\in T} k^i \ \middle|\ T\subseteq \mathbb{N},\ |T|<\infty \right\}$$

即所有有限个互不相等的 $k$ 的方幂之和构成的集合。将 $S_k$ 中的元素从小到大排列，得到序列 $a_1 < a_2 < a_3 < \cdots$。求 $a_N$。

### 2.2 核心观察

**命题 1.** 集合 $S_k$ 中的每个元素，在 $k$ 进制表示下，每一位数字只能是 $0$ 或 $1$。

*证明*：设 $x = \sum_{i\in T} k^i$，其中 $T$ 是有限集且元素互异。那么 $x$ 的 $k$ 进制表示中，第 $i$ 位的系数恰好是 $[i\in T]$（$1$ 如果 $i\in T$，否则 $0$）。由 $T$ 中元素互异知每位系数至多为 $1$。$\square$

**命题 2.** 反之，任意一个 $k$ 进制下每位只含 $0$ 或 $1$ 的数都属于 $S_k$。

*证明*：若 $x$ 的 $k$ 进制表示为 $d_m d_{m-1}\ldots d_0$，其中 $d_i\in\{0,1\}$，则

$$x = \sum_{i=0}^m d_i\cdot k^i$$

取 $T = \{i\mid d_i = 1\}$，则 $x\in S_k$。$\square$

由命题 1 和 2，$S_k$ 与「$k$ 进制下每位为 $0$ 或 $1$ 的正整数」的集合一一对应。

### 2.3 排序与序数的关系

**命题 3.** 将 $S_k$ 中的元素按从小到大排序，得到的序列恰好对应：将正整数 $N$ 写成二进制，再把这个二进制串解释为 $k$ 进制数。

*证明*：考虑映射 $f: \mathbb{N}^+ \to S_k$，定义如下：
对于任意 $N\in\mathbb{N}^+$，写出 $N$ 的二进制表示

$$N = \sum_{i=0}^{m} b_i 2^i,\quad b_i\in\{0,1\}$$

令

$$f(N) = \sum_{i=0}^{m} b_i k^i$$

即把 $N$ 的二进制串当作 $k$ 进制数来解释。我们需要证明 $f$ 是保序双射。

**（a）$f$ 是单射**：若 $N_1 \neq N_2$，则它们的二进制表示不同，因此对应的 $k$ 进制数也不同（$k$ 进制表示唯一），故 $f(N_1)\neq f(N_2)$。

**（b）$f$ 是满射**：由命题 1 和 2，$S_k$ 中每个元素对应一个只含 $0/1$ 的 $k$ 进制串，而这个串恰好也是某个正整数的二进制表示（因为 $k$ 进制下的数字 $0/1$ 在二进制下同样合法）。因此每个 $S_k$ 中的元素都存在原像。

**（c）$f$ 保序**：对于正整数 $N_1 < N_2$，比较它们的二进制表示的最高位。设 $N_1$ 的最高位是 $2^p$，$N_2$ 的最高位是 $2^q$。有两种情况：
- 若 $p < q$，则 $f(N_1) < k^{p+1} \le k^q \le f(N_2)$（因为 $k\ge 3$，$k^{p+1} \le k^q$ 当 $p < q$），所以 $f(N_1) < f(N_2)$。
- 若 $p = q$，则从高位到低位逐位比较二进制串，第一次出现不同的位 $j$ 上 $N_1$ 为 $0$、$N_2$ 为 $1$。对应的 $k$ 进制数在相同位置也是 $N_1$ 为 $0$、$N_2$ 为 $1$，因此 $f(N_1) < f(N_2)$。

实际上更直接的论证：$f$ 可以看作是「把 $N$ 在二进制下的 $0/1$ 系数直接搬运到 $k$ 进制下」。由于两者都是按位权重递增的进制系统，且 $k>2$，二进制下的数值大小排序等价于 $k$ 进制下的数值大小排序（按字典序比较二进制串等价于按字典序比较 $k$ 进制串）。$\square$

### 2.4 举例验证

$k=3$ 时，$f(1)=1,\ f(2)=3,\ f(3)=4,\ f(4)=9,\ f(5)=10,\ldots$，与题目序列一致。

### 2.5 复杂度分析

$N\le 1000$，其二进制位数不超过 $10$ 位（因为 $2^{10}=1024>1000$）。每次只需逐个处理二进制位：提取最低位，乘上 $k$ 的对应次幂累加到答案。

- 时间复杂度：$O(\log N)$，即 $O(10)$。
- 空间复杂度：$O(1)$。

## 三、模式总结

**核心思想：进制映射**

这个问题的本质是「二进制到 $k$ 进制的位值映射」。

- 序列中的数在 $k$ 进制下每一位只能是 $0$ 或 $1$。
- 这就和二进制数一一对应：二进制数 $N$ 的第 $i$ 位 $b_i$ 决定是否取 $k^i$。
- 排序时，二进制的大小顺序和 $k$ 进制的大小顺序完全一致（因为 $k>1$，高位权重差异主导比较）。
- 因此直接把 $N$ 的二进制当作 $k$ 进制解释即可得到答案。

**一句话概括**：$a_N$ 等于将 $N$ 的二进制表示视为 $k$ 进制数所得到的值。

## 四、真实解法与符号表

### 符号表

| 符号 | 含义                                   |
| ---- | -------------------------------------- |
| $k$  | 给定的底数（$3\le k\le 15$）           |
| $N$  | 要求的项数序号（$10\le N\le 1000$）    |
| $b_i$ | $N$ 的二进制表示的第 $i$ 位（$0$ 或 $1$） |
| $p$  | 当前处理的二进制位的权重（$k^i$）        |
| $ans$ | 第 $N$ 项的值                          |

### 算法步骤

1. 读入 $k, N$。
2. 初始化 $p=1$（当前 $k^i$ 的值，从 $k^0$ 开始），$ans=0$。
3. 当 $N>0$ 时：
   - 如果 $N$ 的最低位是 $1$，则 $ans \gets ans + p$。
   - $N \gets N \gg 1$（右移一位，去掉最低位）。
   - $p \gets p \times k$（权重升到下一次幂）。
4. 输出 $ans$。

### 正确性

由第三部分的证明，这个算法等价于把 $N$ 的二进制串解释为 $k$ 进制数。正确。

## 五、C++ 代码

```cpp
// https://www.luogu.com.cn/problem/P1062

#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
    cin.tie(nullptr);
    ios::sync_with_stdio(false);

    int k,N;
    cin>>k>>N;

    i64 ans=0,p=1;
    while(N)
    {
        if(N&1)
            ans+=p;
        N>>=1;
        p*=k;
    }

    cout<<ans<<'\n';
    return 0;
}
```
