# P1563 [NOIP 2016 提高组] 玩具谜题

> 标签：模拟 · 难度：普及-
> 本地题面：`P1563.md`（$1\le n,m\le 10^5$，$s_i<n$，职业名字两两不同、长度 $\le10$）。验证：对拍脚本 `P1563_check.py` 实跑题面描述里的那组例子（据描述还原）得到 `writer`，与描述一致；$300$ 组随机用例中"取模跳步"标程与"逐格行走"暴力输出逐字节一致；最坏规模 $n=m=10^5$，耗时 $0.0204$ s。

## 1. 重新读题

**问题重述（人话版）**

有 $n$ 个玩具小人围成一圈，**按逆时针顺序**依次给出。每个小人有一个朝向 $f$（$0$ 表示面朝圈内，$1$ 表示面朝圈外）和一个职业名（两两不同）。现在从小人 $1$ 出发，依次执行 $m$ 条指令：

- 第 $i$ 条指令是「向左数 $s_i$ 个」或「向右数 $s_i$ 个」，用 $a_i$ 区分（$a_i=0$ 向左，$a_i=1$ 向右），$1\le s_i<n$。

关键在于：**"左"和"右"是相对当前小人本人的朝向而言的**——面朝圈内的小人，其左手方向是顺时针、右手方向是逆时针；面朝圈外的小人则相反。每执行一条指令，就从**当前所在小人**出发，朝对应方向数 $s_i$ 个小人，走到目标小人。

执行完 $m$ 条指令后，输出所在小人的职业。起点是第 $1$ 个读入的小人。

> 一句话版本：沿一个圈走动，每一步的"左右"要按当前点的朝向翻转，求 $m$ 步后落点。

**题面里容易漏掉的条款**

1. 「以逆时针为顺序给出每个玩具小人的朝向和职业」$\Rightarrow$ 输入顺序就是圈上的逆时针顺序，这是一条**坐标系约定**，决定了"下标增大 = 逆时针"，直接影响左右映射。
2. 「朝内 (0) 左边是顺时针，右边是逆时针；朝外 (1) 左边是逆时针，右边是顺时针」$\Rightarrow$ 左右方向随朝向翻转，这是本题唯一的难点，不能简单地"左就减、右就加"。
3. 「第 1 个玩具小人告诉小南」$\Rightarrow$ 起点固定为读入的第 $1$ 个小人（编号 $0$）。
4. 职业名两两不同，所以最终输出哪个名字就直接确定了落点，不存在歧义。
5. $1\le s_i<n$，即一步走不到"绕一整圈"的距离（但仍要取模）。

**数据范围与规模感受**

$$1\le n,m\le 10^5,\qquad 1\le s_i<n,\qquad \text{名字长度}\le10.$$

$10^5$ 级别提示 $O(n+m)$ 的**直接模拟**即可（甚至 $O(\sum s)$ 逐格走会达到 $10^{10}$，必须用取模一步到位）。名字用 `string` 存 $10^5$ 个、总长 $\le10^6$，空间无压力。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：先把"圈"的坐标系钉死

题面说输入按**逆时针**顺序给出。于是我们约定：

> **纸面约定**：给小人编号 $0,1,\dots,n-1$（第 $i$ 个读入的编号为 $i-1$）。规定**编号增大的方向 = 逆时针**（俯视地图时的逆时针）。

因此：
- "在圈上走 $s$ 步到达逆时针方向第 $s$ 个位置" $\Rightarrow$ 编号 $+s$（模 $n$）；
- "在圈上走 $s$ 步到达顺时针方向第 $s$ 个位置" $\Rightarrow$ 编号 $-s$（模 $n$）。

接下来只要搞清楚每条指令到底是"走逆时针"还是"走顺时针"。

### 2.2 几何事实：朝向如何翻转左右

**引理 1（朝内/朝外时左右对应的旋转方向）**

设小人面朝圈内（$f=0$）时，其**左**手方向对应地图上的**顺时针**、**右**手方向对应**逆时针**；面朝圈外（$f=1$）时则相反（左=逆时针、右=顺时针）。

**证明**（坐标法）：把圈放在 $xy$ 平面上，圆心在原点，俯视（从 $+z$ 方向往下看）。令角度 $\theta$ 随逆时针增加，小人位置为 $P(\theta)=(\cos\theta,\sin\theta)$。

- **朝内**：小人面朝圆心，即朝向向量 $\vec{in}=-P(\theta)$（由小人指向圆心）。取 $\theta=0$，则 $P=(1,0)$，朝内方向 $=(-1,0)$（朝西）。人面朝西站立时，其左手方向指向**南**，即 $(0,-1)$。而圈上的切向：逆时针切向为 $\frac{d}{d\theta}P=(0,1)$（朝北），顺时针切向为其相反 $(0,-1)$（朝南）。可见朝内时左手方向 = 顺时针切向。$\square$
- **朝外**：面朝方向 $\vec{out}=P(\theta)$（背离圆心）。取 $\theta=0$，面朝方向 $(1,0)$（朝东），其左手方向指向**北** $(0,1)$，恰是逆时针切向。故朝外时左手方向 = 逆时针切向。$\square$

（两种情形在任意 $\theta$ 都由旋转对称成立，因整幅图绕原点旋转 $\theta$ 不变。）$\blacksquare$

> **直观记忆**：想象你站在摩天轮的一个轿厢里——面朝圆心时，你的左手边就是"顺时钟针转下去"的那一侧；面朝外时反过来。

### 2.3 归约：把"左/右 + 朝向"合成一个方向符号

由引理 1，四种组合下的行走方向（用 $\pm1$ 表示编号变化方向，$+1$ 逆时针、$-1$ 顺时针）如下表：

| $a$（指令） | $f$（朝向） | 语义 | 地图方向 | 编号变化 |
|:---:|:---:|---|---|:---:|
| $0$ 左 | $0$ 内 | 朝内者的左 | 顺时针 | $-1$ |
| $1$ 右 | $0$ 内 | 朝内者的右 | 逆时针 | $+1$ |
| $0$ 左 | $1$ 外 | 朝外者的左 | 逆时针 | $+1$ |
| $1$ 右 | $1$ 外 | 朝外者的右 | 顺时针 | $-1$ |

**引理 2（方向符号 = $a\oplus f$）**

上表中"编号变化方向"为 $+1$ $\iff$ $a\oplus f=1$；为 $-1$ $\iff$ $a\oplus f=0$。于是每步

$$\text{pos}\leftarrow\begin{cases}\ (\text{pos}+s_i)\bmod n,& a_i\oplus f_{\text{pos}}=1\ (\text{逆时针})\\[2pt]\ (\text{pos}-s_i+n)\bmod n,& a_i\oplus f_{\text{pos}}=0\ (\text{顺时针})\end{cases}$$

**证明**：对照上表四种组合逐条核对：
- $(a,f)=(0,0)$：$a\oplus f=0$，方向 $-1$ ✓；
- $(1,0)$：$1\oplus0=1$，方向 $+1$ ✓；
- $(0,1)$：$0\oplus1=1$，方向 $+1$ ✓；
- $(1,1)$：$1\oplus1=0$，方向 $-1$ ✓。

四种组合全部吻合，故等价。$\blacksquare$

> **这一步的价值**：四个 case 被一个异或收成一个表达式，代码里不再需要写分支表。

### 2.4 用题面给的例子交叉验证

题面文字描述给出的那组例子（据描述还原）：$7$ 个小人按逆时针为 `0 singer / 0 reader / 0 mengbier / 1 thinker / 1 archer / 0 writer / 1 mogician`，指令为 `左3 / 右1 / 左2`（即 `0 3 / 1 1 / 0 2`）。

- 起点 `pos=0`（singer，$f=0$）。指令 $(a,f)=(0,0)$，$a\oplus f=0$ $\Rightarrow$ 顺时针，`pos=(0-3+7)%7=4` = `archer` ✓（描述说"左数第 3 个是 archer"）。
- `archer`（$f=1$），指令 $(1,1)$，$a\oplus f=0$ $\Rightarrow$ 顺时针，`pos=(4-1)%7=3` = `thinker` ✓（描述说"右数第 1 个是 thinker"）。
- `thinker`（$f=1$），指令 $(0,1)$，$a\oplus f=1$ $\Rightarrow$ 逆时针，`pos=(3+2)%7=5` = `writer` ✓（描述说"左数第 2 个是 writer"）。

三步全部命中描述中的 `singer→archer→thinker→writer`，验证了坐标系约定与引理 2。$\Rightarrow$ **答案 `writer`，与对拍脚本断言一致。**

### 2.5 复杂度

每步 $O(1)$（取模跳步），总共 $O(n+m)$，空间 $O(n\cdot\max|name|)$（用 `string` 数组）。完全满足 $10^5$。

## 3. 模式总结（Pattern Summary）

**模式名：环上游走模拟的「坐标系约定 + 朝向翻转归约」。**

**按实际思考顺序排列的可迁移标签：**

- `explore its property` — 先把题面给的输入顺序当作坐标系约定（"下标增大 = 逆时针"）钉死。
- `prove the geometry` — 用坐标法证明"朝内者的左 = 顺时针、朝外者的左 = 逆时针"（引理 1），而不是凭直觉。
- `discuss by category` — 把"左/右 × 朝内/朝外"四种组合列出真值表（引理 2 的表）。
- `reduce to easier problem` — 认出方向符号恰是 $a\oplus f$，把四分支合并成一个表达式。
- `classic problem solution` — 环上游走用 `(pos ± s) mod n`，一步到位（而非逐格）。
- `cross-validate with sample` — 用题面文字描述的例子逐步核对手算路径（§2.4）。

**识别信号：**

- 一个环形结构（人/格子/位置围成圈）；
- "左右"或"前后"这类相对方向依赖当前对象的朝向；
- 需要沿圈移动若干步。

**一句话记忆**：环形问题先定坐标系（哪个方向是下标增），相对方向再用"左右与朝向的异或"归约成 $+s/-s$。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `int` | 小人个数 | 读入 | 题面 |
| $m$ | `int` | 指令条数 | 读入 | 题面 |
| `fcg[i]` | `int [100005]` | 第 $i$ 个小人的朝向（$0$ 内/$1$ 外） | 读入 | facing 缩写 |
| `nm[i]` | `string [100005]` | 第 $i$ 个小人的职业名 | 读入 | name 缩写 |
| `pos` | `int` | 当前所在小人的编号（$0$-based） | `0` | 下标增大 = 逆时针 |
| $a,s$ | `int` | 当前指令的方向标记与步数 | 读入 | 题面 |

### 4.2 编号步骤

1. 读入 $n,m$。
2. 读入 $n$ 行 `朝向 职业名`，存入 `fcg[i]`、`nm[i]`。
3. 令 `pos=0`（起点为读入的第 $1$ 个小人）。
4. 循环 $i=0..m-1$：读入 $a,s$；
   - 若 `(a^fcg[pos])==1`，`pos=(pos+s)%n`（逆时针）；
   - 否则 `pos=(pos-s+n)%n`（顺时针）。
5. 输出 `nm[pos]` 与换行。

（引理 2 保证第 4 步的分支正确；`(pos-s+n)%n` 里的 `+n` 用于避免负数取模。）

### 4.3 复杂度

- 时间：$O(n+m)$，读入 $O(n+|名字|)+O(m)$，模拟 $O(m)$。
- 空间：两个大小 $10^5$ 的数组，名字总长 $\le10^6$。
- 实测：$n=m=10^5$，耗时 $0.0204$ s。

### 4.4 关键不变量

1. `pos` 始终是"当前所在小人"的编号。
2. 编号增大方向恒为逆时针（坐标系约定不变）。
3. `pos` 始终落在 $[0,n)$。

## 5. 示例代码

### 5.1 主解：异或归约 + 取模跳步

```cpp
//
// 题目：P1563 [NOIP 2016 提高组] 玩具谜题
// https://www.luogu.com.cn/problem/P1563
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};        // n,m<=1e5 (+5 松弛)

int n,m;
int fcg[mxn];                     // 朝向: 0 面朝圈内, 1 面朝圈外
string nm[mxn];                   // 职业名

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>fcg[i]>>nm[i];
	int pos{0};                   // 下标增大的方向 = 逆时针
	for(int i=0,a,s;i<m;++i)
	{
		cin>>a>>s;
		if((a^fcg[pos])==1)       // 左/右 与 朝向 异或为 1 => 逆时针(下标+)
			pos=(pos+s)%n;
		else
			pos=(pos-s+n)%n;
	}
	cout<<nm[pos]<<'\n';
	return 0;
}
```

**代码结构对照**：`pos` 是当前编号；`(a^fcg[pos])==1` 是引理 2 的判据（逆时针走 `+s`，顺时针走 `-s`）；`(pos-s+n)%n` 用 `+n` 兜住负数。`fcg`/`nm` 用全局数组，读入顺序即编号顺序，起点 `pos=0`。

### 5.2 对照实现：逐格行走（仅用于对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n,m;
int fcg[mxn];
string nm[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>fcg[i]>>nm[i];
	int pos=0;
	for(int i=0;i<m;++i)
	{
		int a,s;cin>>a>>s;
		int dir;                  // +1 逆时针(下标+), -1 顺时针(下标-)
		if(fcg[pos]==0)           // 面朝圈内: 左=顺时针, 右=逆时针
			dir=(a==0)?-1:1;
		else                      // 面朝圈外: 左=逆时针, 右=顺时针
			dir=(a==0)?1:-1;
		for(int k=0;k<s;++k)      // 一步一步走, 便于捕捉取模/方向的偏差
			pos=(pos+dir+n)%n;
	}
	cout<<nm[pos]<<'\n';
	return 0;
}
```

两版在 $300$ 组随机用例上**输出逐字节相同**。这一版把方向用显式 `if/else` 表写出，并**逐格移动** $s$ 次，与标程的"异或 + 一步取模"在实现路径上完全不同，可同时捕获"方向判据错"和"取模处理错"两类 bug。代价是 $O(\sum s)$，大输入会超时，仅用于小规模对拍。

### 5.3 易错点清单

- **坐标系约定搞反**：把"下标增大"当成顺时针，则左右全部颠倒，全盘错误（务必用引理 1 与题面例子锁定）。
- **`(pos-s+n)%n` 漏掉 `+n`**：C++ 负数取模得到负数，越界。
- **把起点设成第 $n$ 个或某个非第 $1$ 个**：题面明确起点是第 $1$ 个读入的小人。
- **用 `endl`**：违反本项目风格指南，用 `'\n'`。
