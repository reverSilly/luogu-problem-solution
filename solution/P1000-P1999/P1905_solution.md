# P1905 堆放货物

## 1. 重新读题

### 1.1 人话重述

有 $n$ 件货物，重量 $a_i\in\{1,2,3\}$。要把它们分成恰好 $p$ 堆（每件货物恰好属于一堆），并把每堆按“从下到上”的顺序排好，满足：

1. 同一堆内，从下到上重量**不增**（题面写“递减”，但 Special Judge 只禁止“把更重的放到更轻的上面”，即相等是允许的，见 1.3）；
2. 任意两堆的**总重量**之差不超过 $3$。

给出任意一种合法方案。$2\le n\le 10^3$，$1\le p\le \lfloor n/2\rfloor$。

### 1.2 关键约束与规模暗示

- 只有三种重量 $1,2,3$，且堆和之差允许到 $3$。这暗示“把每件货物丢到当前最轻的堆”这种负载均衡贪心很可能恰好把差控制在 $3$ 以内。
- $p\le n/2$ 保证每堆至少能分到一件货物，不需要处理空堆。
- 输出只需任意方案，因此不必求最优（例如最小化最大堆和），只要满足差值上界即可。

### 1.3 关于“递减”的歧义

若按**严格递减**理解，一堆中每种重量至多出现一次，堆最多 $3$ 件。取 $n=4,p=1$ 就无解（四件货物放进一堆必然有重复重量），与“$p\ge1$、数据保证有解”矛盾。再看 Special Judge 的报错文案：

```
score:qaq：你把重量为w1的货物放到了w2上面(w1>w2)
```

它只在 $w_1>w_2$ 时报错，相等不报错。因此正确理解是**非递增**（从下到上重量不增）。下文都按非递增处理。

## 2. 思维链（Chain-of-thought）

### 2.1 先解决“堆内顺序”

堆内顺序是局部的、与分配无关：只要确定了每堆包含哪些货物，把它们按重量从大到小排好，就满足“从下到上不增”。

所以问题只剩：**把 $n$ 件重量为 $1/2/3$ 的货物分成 $p$ 个非空组，使各组重量和的最大值减最小值不超过 $3$。**

### 2.2 尝试贪心：每件货物都放到当前最轻的堆

自然想法：维护每堆当前总重，每次取当前最轻的一堆，把下一件货物放进去。这相当于经典的 LPT（Longest Processing Time 的“最轻负载优先”变体）。

关键问题是：**这样做的最大堆与最小堆之差会不会超过 $3$？** 由于单件货物最大只有 $3$，答案是肯定的。下面给出严格的不变量证明。

**引理 1（不变量）**：在“每次把当前货物放到当前总重最小的一堆”的过程中的任意时刻，所有堆的总重的最大值 $M$ 与最小值 $m$ 满足
$$
M-m\le 3 .
$$

**证明**：对放入的货物件数归纳。

- 初始时所有堆总重为 $0$，$M=m=0$，成立。
- 设放入前不变量成立，最小值 $m$，最大值 $M$，且 $M-m\le3$。取一堆总重为 $m$ 的堆，放入重量 $w\le3$ 的货物。放入后：
  - 该堆总重变为 $m+w$；
  - 其余堆总重都 $\ge m$，所以新的最小值 $m'\ge m$；
  - 新的最大值 $M'=\max(M,m+w)$。

  分两种情况：
  1. 若 $M'=M$，则 $M'-m'\le M-m\le3$；
  2. 若 $M'=m+w$，则 $M'-m'\le (m+w)-m=w\le3$。

  两种情况下不变量都保持。$\blacksquare$

注意：若有多堆同时取到最小值 $m$，放入其中一堆后，其他堆仍是 $m$，故 $m'=m$，上述推导照常成立；若被放入的堆是唯一最小堆，则 $m'\ge m$，结论只会更宽松。

**引理 2（每堆非空）**：当 $n\ge p$ 时，上述贪心过程结束后每个堆都非空。

**证明**：初始 $p$ 个堆总重全为 $0$。只要还存在总重为 $0$ 的堆，最小值就是 $0$，贪心一定把当前货物放进某个空堆。因此前 $p$ 件货物会依次放入 $p$ 个不同的空堆，之后所有堆总重都 $>0$。由 $n\ge p$（题目给 $p\le\lfloor n/2\rfloor$），前 $p$ 件货物一定存在，故每堆非空。$\blacksquare$

**定理（贪心方案合法）**：把货物按上述贪心分配到 $p$ 堆，再把每堆内部按重量从大到小排列，得到的输出满足题目的两条规则。

**证明**：引理 2 保证 $p$ 堆都非空且所有货物恰好用一次；每堆内部按重量降序排列，满足“从下到上不增”；引理 1 保证任意两堆总重之差（即 $M-m$）不超过 $3$。$\blacksquare$

### 2.3 实现细节

- 用一个小根堆（优先队列）维护 `(当前总重, 堆编号)`；
- 依次取出总重最小的堆，放入当前货物，再把更新后的总重压回；
- 最后对每堆内部降序排序后输出。

因为只需输出方案，不必关心货物放入的先后对“堆内顺序”的影响——最后统一排序即可。

## 3. 模式总结（Pattern Summary）

- **separate local from global** — 堆内顺序只在每堆确定后排序即可，与分配解耦。
- **explore its property** — 单件重量上界为 $3$，猜测最大最小堆和之差也能被控制在 $3$。
- **greedy** — 每次把货物放到当前总重最小的堆。
- **invariant proof** — 用“新最大值只可能来自旧最大值或 $m+w$”证明 $M-m\le3$ 始终成立。
- **nonempty check** — 用“存在空堆时最小值为 $0$”证明前 $p$ 件货物铺满所有堆。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| $n$ | `int` | 货物数 | 读入 | 数量 |
| $p$ | `int` | 堆数 | 读入 | piles |
| `a[i]` | `int[mxn]` | 第 $i$ 件货物重量 | 读入 | array |
| `sum` | `int` | 某堆当前总重 | 堆中维护 | 负载 |
| `pile[i]` | `vector<int>[mxn]` | 第 $i$ 堆包含的货物重量 | 空 | 分组 |
| `Q` | 小根堆 | `(总重, 堆编号)` | 初始 $p$ 个 $(0,i)$ | priority queue |

### 4.2 算法步骤

1. 读入 $n,p$ 与 $n$ 件货物的重量。
2. 建立小根堆，把 $(0,i)$ 对每个 $i=0,\dots,p-1$ 入堆。
3. 对每件货物 $a_i$：
   - 弹出堆顶 $(s,id)$（当前最轻的堆）；
   - 把 $a_i$ 放进第 $id$ 堆；
   - 把 $(s+a_i,id)$ 压回堆中。
4. 对每个堆内部按重量降序排序。
5. 每堆输出一行，数字之间用空格分隔。

### 4.3 复杂度

- 时间：贪心 $O(n\log p)$，堆内排序总计 $O(n\log n)$；空间 $O(n+p)$。
- 本题 $n\le10^3$，任意实现都能轻松通过。

## 5. 示例代码

```cpp
//
// 题目：P1905 堆放货物
// https://www.luogu.com.cn/problem/P1905
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,p;
int a[mxn];
vector<int>pile[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>p;
	for(int i=0;i<n;++i)
		cin>>a[i];

	priority_queue<pair<int,int>,vector<pair<int,int>>,greater<>>Q;
	for(int i=0;i<p;++i)
		Q.push({0,i});

	for(int i=0;i<n;++i)
	{
		auto[sum,id]=Q.top();
		Q.pop();
		pile[id].push_back(a[i]);
		Q.push({sum+a[i],id});
	}

	for(int i=0;i<p;++i)
	{
		sort(pile[i].begin(),pile[i].end(),greater<>());
		for(int j=0;j<(int)pile[i].size();++j)
		{
			if(j)cout<<' ';
			cout<<pile[i][j];
		}
		cout<<'\n';
	}
	return 0;
}
```
