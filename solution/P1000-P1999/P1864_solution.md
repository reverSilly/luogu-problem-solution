# P1864 [NOI2009] 二叉查找树

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 个结点，每个结点有三个属性：

- 数据值 $d_i$（两两不同）；
- 权值 $w_i$（两两不同）；
- 访问频度 $f_i$。

要求构造一棵二叉查找树：按数据值满足 BST 性质（左子树所有数据值 $<$ 根 $<$ 右子树），同时按权值满足**小根堆**性质（每个结点的权值比它的两个儿子都小）。

可以修改某些结点的权值，每改一个付 $K$；改后的权值可以是**任意实数**，但所有结点的权值仍须两两不同。

代价 = 访问代价 + 修改代价，其中访问代价 $=\sum_i f_i\cdot\mathrm{depth}_i$，根深度为 $1$。求最小总代价。

### 1.2 关键约束与规模暗示

- $1\le n\le70$；$K\le3\times10^7$；数据值、权值、频度均 $\le4\times10^5$。
- 子任务：$40\%$ 数据 $n\le30$，$70\%$ 数据 $n\le50$，满分 $n\le70$。
- $n=70$ 意味着 $O(n^4)\approx2.4\times10^7$ 是舒适区，$O(n^5)\approx1.7\times10^9$ 需要常数优化，$O(2^n)$ 完全不可能。区间 DP 几乎是唯一出路。
- 注意"权值可以改成实数"这一条：它不是无关紧要的修辞，而是把问题从"排列"变成"稠密序"的关键，后面会反复用到。
- 代价量级：$\sum_i f_i\cdot\mathrm{depth}_i\le70\times70\times4\times10^5\approx2\times10^9$，再加上最多 $70\times3\times10^7=2.1\times10^9$ 的修改费，总和会超过 `int`，必须用 64 位。

## 2. 思维链（Chain-of-thought）

### 2.1 先把"数据值"这一维消掉

题面说得很清楚：给定所有数据值与权值后树的形态唯一。为什么？

BST 的中序遍历就是数据值的升序。所以把结点按**数据值排序**后，任何一个子树都对应排序数组上的一个**连续区间** $[l,r]$，而它的根 $k$ 把区间分成左子树 $[l,k-1]$ 与右子树 $[k+1,r]$。这一条立刻把"树"变成了"区间划分"。

于是问题可以完全改写成：

> 给定按数据值升序排列的 $n$ 个结点（属性为 $w_i,f_i$），选一棵以该顺序为叶子（更准确地说，以该顺序为中序）的二叉树，满足父权 $<$ 子权，最小化 $\sum h_i f_i+K\cdot\#\{\text{被修改的点}\}$。

### 2.2 简化版：不允许修改时会怎样

如果一次都不修改，那么"父权 $<$ 子权"就是全部约束。此时树是**被迫**的：

**观察**：在任何子树对应的区间 $[l,r]$ 中，权值最小的那个结点必须是这棵子树的根。

**证明**：设根为 $k$。若存在 $j\in[l,r]$ 且 $w_j<w_k$：$j$ 要么在左子树要么在右子树，于是它是 $k$ 的某个后代；沿着 $k\to j$ 的路径，每走一条边权值都严格增大，所以 $w_j>w_k$，矛盾。故根就是区间最小。递归到左右子区间，形态唯一。$\square$

这就是笛卡尔树。换句话说，"不修改"时没有任何决策空间；**全部自由度都来自修改**。这提示我们把问题理解成"花 $K$ 把一个点从权值序里'解放'出来"。

### 2.3 修改到底买到了什么

一个被修改的点，其权值可以取任意实数。它仍然要满足与父亲、儿子的大小关系，但由于实数稠密，只要两端之间"有空隙"，就总能塞进去。

反过来，一个**没有**被修改的点，它的权值被钉死在 $w_i$，它必须大于所有未修改的祖先、小于所有未修改的后代。

由此得到第一个关键刻画。

**引理 1（可行性）**：给定树形态 $T$ 与"未修改结点集合" $U$，该组合可行（存在一组实数权值实现 $T$ 且 $U$ 中的点保持原权值）当且仅当

$$\forall u,v\in U:\ u\text{ 是 }v\text{ 的祖先}\ \Longrightarrow\ w_u<w_v.$$

**证明**：

- 必要性：$u$ 是 $v$ 的祖先时，沿路径每一条边都有父权 $<$ 子权，严格不等式可传递，故 $w_u<w_v$。
- 充分性：按"从根到叶"的顺序给被修改的点赋值。设当前处理被修改点 $x$：
  - 它的父结点已经处理完（未修改的父权已知，修改的父权已赋好）；
  - 令 $B(x)=\min\{w_y: y\text{ 是 }x\text{ 的未修改真后代}\}$（若没有这样的后代则 $B(x)=+\infty$）。
  - 条件保证：父结点的值 $<$ $B(x)$。若父点未修改，父权 $w_p$ 与任一未修改后代 $y$ 都满足 $w_p<w_y$，故 $w_p<B(x)$；若父点已修改，其赋值 $<B(p)\le B(x)$（$x$ 的真后代集合是 $p$ 的真后代集合的子集，子集的最小值不小于全集的最小值），故也 $<B(x)$。
  - 于是开区间 $(\text{父值},B(x))$ 非空。全体原始权值和已经赋过的实数只有有限多个，而开区间中有不可数多个实数，因此可以选一个**不等于任何已用数值**的实数作为 $x$ 的权值。
  
  处理完所有点后，每条边的父权 $<$ 子权都成立：父修改、子未修改时，父值 $<B(\text{父})\le w_{\text{子}}$；父未修改、子修改时，子的赋值 $>$ 父值；两边都修改时由构造保证；两边都未修改时由条件保证。$\square$

引理 1 把"实数"这层复杂性彻底消掉了：以后只需追踪"哪些点未修改"以及它们的权值单调性。

### 2.4 第一次尝试：一个"看起来对"的 DP，以及它的反例

最朴素的想法是：区间 DP 带上深度。

$$f[l][r][h]=\text{区间 }[l,r]\text{ 构成深度为 }h\text{ 的子树的最小代价}.$$

转移枚举根 $k$，并规定：**若 $k$ 是区间内权值最小的点，可以不改；否则必须付 $K$ 改它**。理由是"若根不是最小，子树里一定有个更小的点，总得改一个"。

这个理由是错的。反例（$K=10$）：

| 结点 | 数据值 | 权值 | 频度 |
| :--- | :--- | :--- | :--- |
| A | 1 | 10 | 1000 |
| B | 2 | 15 | 100 |
| C | 3 | 5 | 1 |

真实最优：让 A 当根、B 当 A 的右儿子、C 当 B 的右儿子。A、B 都不改（$10<15$ 满足堆序），只把 C 改成 $16$，付一次 $K=10$。访问代价 $=1000\cdot1+100\cdot2+1\cdot3=1203$，总计 $1213$。

而"根非最小就收 $K$"的 DP 会这样算：$[1,3]$ 的根是 A，A 不是区间最小（最小是 C 的 $5$），收 $K$；$[2,3]$ 的根是 B，B 也不是最小（C 更小），再收 $K$。于是这条结构被估价 $1203+2K=1223$，比真实最优多算了一次 $K$。

错误根源：**收费点选错了**。这个结构里真正需要改的只有最深的 C；但 DP 在 A 处就已经看不到"C 会被单独改掉"这件事，只能保守地假设"根不能保持原权值"。更深层地说，DP 丢掉了**父结点权值给子树带来的下界**：一旦 A 以权值 $10$ 不动，B、C 的权值都必须 $>10$，而 $f[2,3]$ 这个子问题并不知道这个下界，就无法正确地判断"B 能不能不动"。

所以状态必须显式记住这个下界。

### 2.5 引入阈值：状态语义

把所有权值排序，记第 $i$ 小的权值为 $W_i$（$i$ 从 $0$ 起），并令 $\mathrm{rank}(x)$ 为结点 $x$ 的权值排名。

**定义（阈值）**：参数 $t\in[0,n]$ 表示"本子树中所有未修改结点的权值都要 $>$ 阈值 $\Theta_t$"，其中

$$\Theta_0=-\infty,\qquad \Theta_t=W_{t-1}\ (t\ge1).$$

也就是说 $t$ 的语义是"已有 $t$ 个原始权值不超过当前下界"。于是 $w_x>\Theta_t\iff \mathrm{rank}(x)\ge t$。

**状态**：$dp[l][r][h][t]$ = 在区间 $[l,r]$ 上造一棵根深度为 $h$ 的子树，且所有未修改结点的权值都 $>\Theta_t$ 时的最小代价。

整棵树的根没有父亲，阈值是 $-\infty$，即答案是 $dp[0][n-1][1][0]$。

### 2.6 转移：根改不改，是两个互斥的完整分支

**引理 2（转移）**：对 $[l,r]$ 枚举根 $k$，有

$$
dp[l][r][h][t]=\min_{k=l}^{r}\min\begin{cases}
K+h f_k+dp[l][k-1][h+1][t]+dp[k+1][r][h+1][t], & \text{(改 }k\text{)}\\[2mm]
h f_k+dp[l][k-1][h+1][\mathrm{rank}(k)+1]+dp[k+1][r][h+1][\mathrm{rank}(k)+1], & \text{(不改 }k,\ \mathrm{rank}(k)\ge t\text{)}
\end{cases}
$$

空区间的 $dp$ 值为 $0$。

**证明**：任取一个满足约束的子树方案，看根 $k$ 改没改，只有两种情况。

**情况一：$k$ 被修改。** 其新权值 $x$ 必须满足

$$\Theta_t<x<\min\{\text{子树中所有未修改结点的权值}\}$$

（若子树中没有其它未修改结点，则只需 $x>\Theta_t$）。注意这个区间非空：由约束，子树中未修改结点的权值都 $>\Theta_t$，所以它们的最小值 $>\Theta_t$，开区间非空。

现在关键的一点：**子女的阈值可以取回 $t$**。因为 $x$ 可以取得任意接近 $\Theta_t$（只需在 $(\Theta_t,\min)$ 中任意接近下端，同时避开有限个已用数值），而对任何一个**原始**权值 $w$，当 $x$ 足够接近 $\Theta_t$ 时，"$w>x$" 与 "$w>\Theta_t$" 等价。于是子女子树的约束恰好就是"未修改结点权值 $>\Theta_t$"，即同一个 $t$。又因为阈值只是用来筛选"哪些原始权值可用"，把 $x$ 换成足够接近 $\Theta_t$ 的值不会改变任何非修改点的可行性，故不损失一般性。

代价方面：$K$（修改费）$+h f_k$（根自身的访问代价）$+$ 两个子女区间的代价，两者独立可加。

**情况二：$k$ 不修改。** 要求 $w_k>\Theta_t$，即 $\mathrm{rank}(k)\ge t$。子女中未修改结点的权值必须 $>w_k$，所以子女阈值是 $\mathrm{rank}(k)+1$（即 $\Theta=w_k$）。代价为 $h f_k$ 加两个子女区间的代价。

每种可行方案恰好落入一种情况，两种情况的子问题又都精确刻画了剩余约束，故取 min 得到最优。$\square$

补充两点细节：

- $K$ 加在"改 $k$"分支上、$h f_k$ 两个分支都要加，因为访问代价只与深度有关、与改不改无关；
- 左右子树的约束互相独立（一个只受 $k$ 的下界约束，另一个也是），所以可以分别取各自的最优。

### 2.7 深度与阈值的取值范围

**深度**：$n$ 个点的树最大深度为 $n$（一条链），所以 $h\le n$；而一个长度 $m=r-l+1$ 的子树，根深度 $h$、最深处 $h+m-1$，必有 $h+m-1\le n$，即 $h\le n-m+1$。超过这个范围的 $dp$ 一律视为不可行（$\infty$）。

**阈值**：若 $t>\max_{i\in[l,r]}\mathrm{rank}(i)$，则区间内没有任何点能"不修改"，此时 $dp[l][r][h][t]$ 退化为"全部修改"的代价，记作 $G[l][r][h]$：

$$G[l][r][h]=\min_{k}\Bigl(K+h f_k+G[l][k-1][h+1]+G[k+1][r][h+1]\Bigr).$$

它是引理 2 中"改 $k$"分支在每个 $t$ 都成立的版本，可以单独算，省掉大量无意义的 $t$。

另外，若 $t\le\min_{i\in[l,r]}\mathrm{rank}(i)$，则区间内所有点都满足"可不动"，所有这样的 $t$ 取值相同，实现时可以把它夹到 $\min$ 上，减少枚举。

### 2.8 计算顺序与复杂度

- 深度 $h$ 从 $n$ 递减到 $1$ 计算（转移只依赖 $h+1$），只需滚动两层：空间 $O(n^3)$。
- 区间按任意顺序，因为同一层的 $dp[l][r][h][\cdot]$ 只依赖 $h+1$ 层。

状态数上界：区间 $O(n^2)$ × 深度 $O(n)$ × 阈值 $O(n)$ = $O(n^4)$，每次转移枚举 $O(n)$ 个根，总时间上界 $O(n^5)$。但深度受 $h\le n-m+1$、阈值只枚举到区间内最大 rank（$\le m$）约束，真实运算量约

$$\sum_{m=1}^{n}(n-m+1)^2m^2\approx\frac{n^5}{30}\approx5\times10^7\quad(n=70),$$

实测约 $0.7$ 秒，完全可接受。

### 2.9 边界清单

1. $n=1$：答案是 $f_1$（不用改，深度为 $1$），最外层查询会正确地取"不修改"分支。
2. $K$ 与 $f_i$ 相乘、$h f_k$ 都可能超过 `int`，所有 DP 值用 64 位，$\infty$ 取 `1145141919810`。
3. 空区间的代价恒为 $0$（深度再大也不需要放点）。
4. $t$ 可能等于 $n$（所有原始权值都不够大），此时只能全改。

## 3. 模式总结（Pattern Summary）

- **explore its property** — BST 中序 = 数据值升序 ⇒ 子树是排序数组的连续区间；堆性质 ⇒ 树是"权值的笛卡尔树"。
- **consider easier version** — 不允许修改时形态被唯一确定（区间最小值当根），说明全部自由度来自修改。
- **characterize feasibility** — 引理 1：只需检查未修改祖先的权值严格小于未修改后代，实数稠密保证其余可填。
- **failed attempt + counterexample** — "根不是区间最小就收 $K$"会重复收费，$A(10,1000),B(15,100),C(5,1)$ 反例。
- **add the missing dimension** — 引入"父权下界"阈值 $t$，状态 $dp[l][r][h][t]$。
- **case split** — 根改 / 不改是两个完整分支：改则子女阈值不变，不改则子女阈值变为根权值。
- **classic problem solution** — 区间 DP + 深度维度 + 滚动数组 + 阈值剪枝。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| $n$ | `int` | 结点数 | 读入 | $\le70$ |
| $K$ | `i64` | 单次修改费 | 读入 | — |
| `a[i].dt` | `int [75]` | 数据值 | 读入后按它排序 | data |
| `a[i].wt` | `int [75]` | 权值 | 读入 | weight |
| `a[i].fr` | `int [75]` | 访问频度 | 读入 | frequency |
| `a[i].rk` | `int [75]` | 权值的升序排名（$0$ 起） | 排序后填 | rank |
| `mnr[l][r],mxr[l][r]` | `int [75][75]` | 区间内最小 / 最大 rank | 预处理 | min/max rank |
| `D[2][l][r][t]` | `i64 [2][75][75][75]` | $dp[l][r][h][t]$（按 $h$ 奇偶滚动） | 见下 | DP |
| `G[2][l][r]` | `i64 [2][75][75]` | 全部修改时的代价 $G[l][r][h]$ | 见下 | all-modified |

DP 初值：$h=n+1$ 这一层对空区间为 $0$、非空区间为 $\infty$（因为不可能在深度 $n+1$ 放点还满足 $h\le n$）；之后 $h$ 从 $n$ 递减计算，每层只保留合法区间（$h\le n-m+1$），其余置 $\infty$。

### 4.2 算法步骤

1. 读入 $n,K$，以及 $n$ 个数据值、$n$ 个权值、$n$ 个频度。
2. 按数据值升序排序；再按权值升序求出每个结点的 `rk`；预处理区间内 rank 的 min/max。
3. 初始化 $h=n+1$ 图层：所有非空区间的 `G`、`D` 置 $\infty$（空区间由辅助函数直接返回 $0$）。
4. $h$ 从 $n$ 递减到 $1$：
   - 对每个区间 $[l,r]$（长度 $m$），若 $h>n-m+1$，整层置 $\infty$ 并跳过；
   - 计算 $G[l][r]$：枚举根 $k$，取 $K+h f_k+G[l][k-1]+G[k+1][r]$ 的最小值；
   - 对 $t=\mathrm{mnr}(l,r)\dots\mathrm{mxr}(l,r)$ 计算 $D[l][r][t]$：枚举根 $k$，分别尝试"改 $k$"（加 $K$，子女阈值仍为 $t$）与"不改 $k$"（条件 $\mathrm{rank}(k)\ge t$，子女阈值为 $\mathrm{rank}(k)+1$），取最小；
   - 查询辅助函数 `getD(lay,l,r,t)`：空区间返回 $0$；$t<\mathrm{mnr}$ 时夹到 $\mathrm{mnr}$；$t>\mathrm{mxr}$ 时返回 $G$；否则返回 $D$。
5. 输出 `getD(1,0,n-1,0)`（深度层 $h=1$、全区间、阈值为 $-\infty$）。

### 4.3 复杂度

- 时间：上界 $O(n^5)$，在 $n=70$ 的实际状态裁剪下约 $5\times10^7$ 次转移。
- 空间：$O(n^3)$（两层 $75\times75\times75$ 的 `i64` 表，约 $6.8$ MB）。

## 5. 示例代码

```cpp
//
// 题目：P1864 [NOI2009] 二叉查找树
// https://www.luogu.com.cn/problem/P1864
// 自测：n<=6 随机数据与暴力（枚举树形态+子集）对拍 400 组通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{75};
constexpr i64 inf{1145141919810LL};

int n;
i64 K;
struct node{int dt,wt,fr,rk;}a[mxn];
int mxr[mxn][mxn],mnr[mxn][mxn];
i64 G[2][mxn][mxn],D[2][mxn][mxn][mxn];

bool bydata(node x,node y)
{
	return x.dt<y.dt;
}
i64 getG(int lay,int l,int r)
{
	return l>r?0:G[lay][l][r];
}
i64 getD(int lay,int l,int r,int t)
{
	if(l>r)
		return 0;
	if(t<mnr[l][r])
		t=mnr[l][r];                 // t 更小时所有点都可不动，值相同
	return t>mxr[l][r]?G[lay][l][r]:D[lay][l][r][t];
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>K;
	for(int i=0;i<n;++i)
		cin>>a[i].dt;
	for(int i=0;i<n;++i)
		cin>>a[i].wt;
	for(int i=0;i<n;++i)
		cin>>a[i].fr;
	sort(a,a+n,bydata);              // 按数据值排序，子树即连续区间
	int id[mxn];
	iota(id,id+n,0);
	sort(id,id+n,[](int x,int y){return a[x].wt<a[y].wt;});
	for(int i=0;i<n;++i)
		a[id[i]].rk=i;
	for(int l=0;l<n;++l)
	{
		mxr[l][l]=mnr[l][l]=a[l].rk;
		for(int r=l+1;r<n;++r)
		{
			mxr[l][r]=max(mxr[l][r-1],a[r].rk);
			mnr[l][r]=min(mnr[l][r-1],a[r].rk);
		}
	}
	int nxt=(n+1)&1;                 // 第 n+1 层：非空区间不可行
	for(int l=0;l<n;++l)
		for(int r=l;r<n;++r)
		{
			G[nxt][l][r]=inf;
			for(int t=0;t<=n;++t)
				D[nxt][l][r][t]=inf;
		}
	for(int h=n;h>=1;--h)
	{
		int cu=h&1,nx=cu^1;
		for(int l=0;l<n;++l)
			for(int r=l;r<n;++r)
			{
				if(h>n-(r-l+1)+1)    // 深度 h 放不下这么多点
				{
					G[cu][l][r]=inf;
					for(int t=mnr[l][r];t<=mxr[l][r];++t)
						D[cu][l][r][t]=inf;
					continue;
				}
				i64 bg=inf;
				for(int k=l;k<=r;++k)
					bg=min(bg,K+h*a[k].fr+getG(nx,l,k-1)+getG(nx,k+1,r));
				G[cu][l][r]=bg;
				int mt=mxr[l][r];
				for(int t=mnr[l][r];t<=mt;++t)
				{
					i64 bd=inf;
					for(int k=l;k<=r;++k)
					{
						// 改根 k：子女阈值不变
						bd=min(bd,K+h*a[k].fr+getD(nx,l,k-1,t)+getD(nx,k+1,r,t));
						// 不改根 k：要求 w_k>阈值，子女阈值变为 rank(k)+1
						if(a[k].rk>=t)
						{
							int nt=a[k].rk+1;
							bd=min(bd,h*a[k].fr+getD(nx,l,k-1,nt)+getD(nx,k+1,r,nt));
						}
					}
					D[cu][l][r][t]=bd;
				}
			}
	}
	cout<<getD(1,0,n-1,0)<<'\n';
	return 0;
}
```
