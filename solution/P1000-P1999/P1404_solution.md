# P1404 平均数

> 标签：数学 / 贪心 / 二分 / 分数规划 / 前缀和 · 难度：普及/提高-

## 1. 重新读题

**问题重述（简化版）**

给长度 $n$ 的数列 $a_1..a_n$（$0\le a_i\le 2000$），选一个**连续子段** $a[l..r]$（题面"子串"即连续子段，不是子序列），要求长度 $L=r-l+1\ge m$，使平均数

$$\bar a(l,r)=\frac1{r-l+1}\sum_{k=l}^{r}a_k$$

最大。记最大值为 $A^*$，输出 $\lfloor 1000A^*\rfloor$——**截断**，不做四舍五入。

**约束与子任务（提示复杂度）**

| 数据范围 | 规模 |
|---|---|
| 60% | $m\le n\le 10^4$ |
| 100% | $1\le m\le n\le 10^5$，$0\le a_i\le 2000$ |

**输出细节（本题真正的坑）**：输出是整数，且是"千倍后截断"。因此误差**方向敏感**：候选值偏低 $\frac{1}{1000}$ 就可能少输出 1，偏高同理可能多输出 1；而且截断点附近的间隙由 $A^*$ 的有理分母决定（§2.6 (i) 给出精确界）。这不是"输出保留 3 位小数"那种带容差的题。

**值域**：$A^*\in[\min a_i,\max a_i]\subseteq[0,2000]$（引理 6.3 证明这个夹逼），故 $\lfloor 1000A^*\rfloor\in[0,2\,000\,000]$。

**样例情况声明**：`P1404.md` 题面**不含任何样例输入输出**，因此无法对标官方样例；本文所有验证均用"按定义直接枚举子段"手算完成（§4.3），不虚构对拍、得分或耗时。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制：目标函数不可加，约束是"至少 m"而不是"定长"

先把两个难点摆出来：

1. 平均数 $\bar a(l,r)$ 是**比值**，不满足"区间可加"，所以不能像区间和那样用一次前缀和直接最大化；把两个子段合并时，新平均数是旧平均数的**加权平均**，可能比两者都小（例如 $[10]$ 与 $[1,1]$ 合并得 $4$）。
2. 长度约束是 $L\ge m$，不是定长 $m$。定长时窗口滑动即可，变长时同一个右端点对应许多左端点，必须把"左端点选谁"变成一个可扫描的极值问题。

子段总数 $\frac{n(n+1)}2\approx 5\times 10^9$（$n=10^5$），**枚举不可行**；$n\le 10^4$ 时约 $5\times 10^7$，60% 可行——这解释了子任务阶梯。

**引理 1（最优值存在）** 可行子段族 $\mathcal{F}=\{[l,r]:1\le l\le r\le n,\ r-l+1\ge m\}$ 非空且有限，故 $A^*=\max_{\mathcal{F}}\bar a$ 存在且为有理数。

**证明**：非空性由 $m\le n$ 给出——取 $[1,m]$ 即属于 $\mathcal{F}$。有限性：$|\mathcal{F}|=\sum_{L=m}^{n}(n-L+1)=\frac{(n-m+1)(n-m+2)}2<\infty$。有限非空集合上最大值必被取到，记取到最大值的子段为 $[l^*,r^*]$，$A^*=\bar a(l^*,r^*)=\frac{\sum a_k}{L^*}$ 是有理数（分母 $L^*\le n$）。$\blacksquare$

### 2.2 简化问题：先做"一定能算对"的暴力（60% 分）

对 $n\le 10^4$：预处理整数前缀和 $P_j=\sum_{k\le j}a_k$（`i64`，$P_n\le 2\times 10^7$），枚举所有 $[l,r]$（$r-l+1\ge m$），用**交叉相乘**比较两个候选平均数，全程不出现除法：

$$\frac{P_r-P_{l-1}}{r-l+1}>\frac{p}{q}\iff q(P_r-P_{l-1})>(r-l+1)p$$

大小关系用 `i64` 判定：左、右各项 $\le 10^5\times 2\times 10^7=2\times 10^{12}$，不溢出。最终保留最优的分子 $p^*$、分母 $q^*$，输出 $\lfloor 1000p^*/q^*\rfloor$（整数除法天然截断）。复杂度 $O(n^2)$，$\approx 5\times 10^7$ 次比较。

**这一段的真正收获不是分数，而是一条纪律**：本题答案是"截断整数"，只要**从一开始就把比较限制在有理数/整数域**，浮点误差问题就不存在。后面会反复用到它。

### 2.3 关键转化：用"判定问题"替代"优化问题"（分数规划入口）

优化 $A^*$ 很难；但"平均数能不能达到 $\ge v$"看起来容易——把每个数减去 $v$ 就变成"和"的问题。

**引理 2（阈值判定等价，双向）** 对任意实数 $v$：

$$A^*\ge v\iff\exists[l,r]\in\mathcal{F}:\ \sum_{k=l}^{r}(a_k-v)\ge 0$$

**证明**：对固定 $[l,r]\in\mathcal{F}$，$L=r-l+1\ge m\ge 1>0$，且

$$\sum_{k=l}^{r}(a_k-v)=\Big(\sum_{k=l}^{r}a_k\Big)-Lv=L\big(\bar a(l,r)-v\big)$$

因为 $L>0$，$\bar a(l,r)-v$ 与 $L(\bar a(l,r)-v)$ **同号（含同时为 0）**，即

$$\bar a(l,r)\ge v\iff\sum_{k=l}^{r}(a_k-v)\ge 0\qquad(\ast)$$

- （$\Rightarrow$）设 $A^*\ge v$。由引理 1，$A^*=\bar a(l^*,r^*)$ 被某个 $[l^*,r^*]\in\mathcal{F}$ 取到，故 $\bar a(l^*,r^*)\ge v$，由 $(\ast)$ 该子段满足 $\sum(a_k-v)\ge 0$。
- （$\Leftarrow$）设存在 $[l,r]\in\mathcal{F}$ 使 $\sum(a_k-v)\ge 0$。由 $(\ast)$ 得 $\bar a(l,r)\ge v$；又 $A^*\ge\bar a(l,r)$（$A^*$ 是全体可行子段的最大平均数），传递得 $A^*\ge v$。$\blacksquare$

定义 $M(v)=\max_{[l,r]\in\mathcal{F}}\sum_{k=l}^{r}(a_k-v)$，则引理 2 就是"$A^*\ge v\iff M(v)\ge 0$"。

### 2.4 判据的单调性：二分合法的根据（必须证）

**引理 3（$M$ 非增，判据是"下集"）** 若 $v_1<v_2$，则 $M(v_1)\ge M(v_2)$；从而集合 $\{v:M(v)\ge 0\}$ 在 $\mathbb{R}$ 中向下封闭（$M(v_2)\ge0\Rightarrow M(v_1)\ge0$），二分答案的单调前提成立。

**证明**：先固定任一 $[l,r]\in\mathcal{F}$，长度 $L\ge 1$：

$$\sum_{k=l}^{r}(a_k-v_2)=\sum_{k=l}^{r}(a_k-v_1)-(v_2-v_1)L\le\sum_{k=l}^{r}(a_k-v_1)$$

因为 $v_2-v_1>0$ 且 $L>0$。设 $[l_2,r_2]$ 是使 $M(v_2)$ 取到最大值的子段（有限族，必存在），则

$$M(v_2)=\sum_{k=l_2}^{r_2}(a_k-v_2)\le\sum_{k=l_2}^{r_2}(a_k-v_1)\le\max_{\mathcal{F}}\sum(a_k-v_1)=M(v_1)$$

最后一步是因 $M(v_1)$ 是**全体**可行子段的和的最大值，任何一个具体子段都不超过它。（这也顺带证明了"一族非增函数的逐点最大值仍非增"。）向下封闭性是 $v_1<v_2\Rightarrow M(v_1)\ge M(v_2)$ 的直接逆否改写。$\blacksquare$

> 注意方向：$v$ 越大越"难达标"，所以 $M(v)\ge0$ 的解集形如 $(-\infty,\,A^*]$；二分要找**最大可行 $v$**，即 $v\mapsto$ check 的"最后一个 true"。

### 2.5 经典结构：把 $M(v)$ 算成 $O(n)$ —— 前缀和极差（双向证明）

记 $b_k=a_k-v$，前缀和 $S_0=0,\ S_j=\sum_{k=1}^{j}b_k$。

**引理 4（定长/变长最优化 $\iff$ 前缀和极差，双向）**

$$M(v)=\max_{m\le j\le n}\Big(S_j-\min_{0\le i\le j-m}S_i\Big)$$

**证明**：

- **（第一个方向：配对集合与子段集合一一对应）** 考察集合 $\mathcal{P}=\{(i,j):0\le i\le j- m,\ j\le n\}$（即 $0\le i<j\le n$ 且 $j-i\ge m$）。建立映射 $\varphi:\mathcal{P}\to\mathcal{F}$，$(i,j)\mapsto[\,i+1,\ j\,]$。
  - $\varphi$ 落在 $\mathcal{F}$ 内：长度 $=j-i\ge m$，且 $1\le i+1\le j\le n$ ✓。
  - $\varphi$ 是双射：逆映射 $\psi:\mathcal{F}\to\mathcal{P}$，$[l,r]\mapsto(l-1,\ r)$；$\psi$ 合法因 $r-(l-1)=L\ge m$；且 $\varphi(\psi([l,r]))=[l,r]$、$\psi(\varphi(i,j))=(i,j)$ 逐条代入即验证（$i+1-1=i$，$r=j$）。故两集合等势，且 $[l,r]$ 上的 $b$ 和为 $S_r-S_{l-1}$，对应 $(i,j)$ 上的差 $S_j-S_i$。于是
  $$M(v)=\max_{(i,j)\in\mathcal{P}}(S_j-S_i).$$
- **（第二个方向：固定右端点后左端点取最小前缀）** 固定 $j$，把 $\max_{0\le i\le j-m}(S_j-S_i)$ 化简。$S_j$ 与 $i$ 无关，$i\mapsto S_j-S_i$ 是 $S_i$ 的**严格递减仿射函数**，故其最大值在 $S_i$ 最小处取得：
  $$\max_{0\le i\le j-m}(S_j-S_i)=S_j-\min_{0\le i\le j-m}S_i.$$
  这里双向都成立：任取 $i$ 有 $S_i\ge\min$，故 $S_j-S_i\le S_j-\min$（$\le$ 方向）；取 $i=i_{\min}$ 使等号成立（$\ge$ 方向）。
- 两层最大值可交换展开：$\max_{(i,j)\in\mathcal{P}}=\max_{m\le j\le n}\max_{0\le i\le j-m}$，因 $\mathcal{P}$ 正是"先定 $j$、$i$ 在 $0..j-m$ 里选"的乘积型集合。合并即得结论。$\blacksquare$

**引理 5（扫描不变量）** 算法按下述方式一次扫描求上式：$mn$ 初值 $0$，对 $p=m,m+1,\dots,n$ 依次执行 `mn=min(mn, S[p-m])`，再更新 $ans=\max(ans, S[p]-mn)$。执行完 `min` 那一行的瞬间，$mn=\min_{0\le i\le p-m}S_i$。

**证明**（对 $p$ 归纳）：$p=m$ 时，进入前 $mn=0$，而 $S_0=0$，故 $\min(mn,S_{p-m})=\min(0,S_0)=0=S_0=\min_{0\le i\le 0}S_i$ ✓。归纳步：设 $p-1$ 步后有 $mn=\min_{0\le i\le p-1-m}S_i$；本步取 $\min(mn,S_{p-m})=\min\big(\min_{0\le i\le p-1-m}S_i,\ S_{p-m}\big)=\min_{0\le i\le p-m}S_i$（把新元素并入即可，有限集合的最小值可按此拆分）。$\blacksquare$

于是判定 `check(v)` 可在 $O(n)$ 内完成（一次前缀 + 一次扫描，且 $S_p-mn\ge 0$ 出现即可提前返回 true）。

### 2.6 从浮点回到整数：候选值限定为 $T/1000$

按 2.3–2.5 直接实现要用 `double` 存 $b_k=a_k-v$ 与 $S$，而输出要求"截断到千分之一"。先把浮点版需要的量算清楚，再决定要不要用它。

**（i）输出正确所要求的候选精度。** 由引理 1，$A^*=p^*/q^*$，$q^*=L^*\le n\le 10^5$。于是 $1000A^*=\frac{1000p^*}{q^*}$ 是一个**分母整除 $q^*$ 的有理数**，记 $\delta=\{1000A^*\}\in[0,1)$。分两种情形：

- $\delta>0$：把 $1000A^*$ 写成既约分数 $\frac{a}{b}$。因 $\frac{a}{b}=\frac{1000p^*}{q^*}$，约分只是把 $q^*$ 除掉一个因子，故 $b\mid q^*\le n$，且 $\delta\ne0\Rightarrow b\ge2$。于是 $\delta=\frac{j}{b}$（$1\le j\le b-1$），得
$$\delta\ge\frac1b\ge\frac1n\ge10^{-5},\qquad 1-\delta=\frac{b-j}{b}\ge\frac1b\ge\frac1n .$$
所以只要 $|1000(\hat x-A^*)|<\frac1n$ 就有 $\lfloor1000\hat x\rfloor=\lfloor1000A^*\rfloor$，即要求
$$|\hat x-A^*|<\frac{1}{1000\,n}\ \ge\ 10^{-8}\quad(\text{最坏 }n=10^5\text{ 时恰为 }10^{-8}).$$
（证明：设 $k_0=\lfloor1000A^*\rfloor$，则 $1000A^*=k_0+\delta$，两侧到分界点 $k_0$、$k_0+1$ 的距离分别 $\ge\frac1n$；$|1000\hat x-1000A^*|<\frac1n$ 使 $1000\hat x$ 仍落在 $[k_0,k_0+1)$ 内，截断值同为 $k_0$。反向：若误差超过该间隙，取 $\hat x$ 偏大/偏小即可跨过分界，输出 $\pm1$ 偏差——所以 $\frac{1}{1000n}$ 是**必要且充分**的精度标尺，不是保守估计。）
- $\delta=0$：$1000A^*$ 是整数，任何 $\hat x<A^*$ 都使 $\lfloor1000\hat x\rfloor=1000A^*-1$（错），任何 $\hat x>A^*$ 使 $=1000A^*+1$（也错）——**必须精确命中**。

**（ii）二分轮数与该精度的不等式。** 初始区间宽 $V_0=\max a-\min a\le2000$，$k$ 轮后 $r-l=\frac{V_0}{2^k}$，且 $l\le A^*\le r$（不变式：$l$ 可行、$r$ 不可行/为右界，故 $A^*$ 夹在中间）。取估计值 $\hat x=\frac{l+r}2$ 时误差 $\le\frac{V_0}{2^{k+1}}$，代入 (i) 的要求 $\frac{V_0}{2^{k+1}}<\frac{1}{1000\,n}$：

$$2^{k+1}>1000\,n\,V_0\ \iff\ k\ \ge\ \big\lceil\log_2(1000\,n\,V_0)-1\big\rceil=\big\lceil\log_2(10^{3}\cdot10^{5}\cdot2\cdot10^{3})-1\big\rceil=\lceil37.54-1\rceil=37 .$$

若取单侧估计 $\hat x=l$（常见写法，误差界 $\frac{V_0}{2^k}$，不除以 2）则需 $k\ge\lceil\log_2(1000nV_0)\rceil=38$。再多轮数没有意义：$l,r$ 都是 `double`，$A^*\sim2000$ 附近相邻可表示数间距（ulp）$=2^{-42}\approx2.3\times10^{-13}$，$k\approx53$（宽 $\approx$ 1 ulp）后 $l,r$ 不再变化。这里 $A^*\in[l,r]$ 的依据是引理 2 的**双向**（$check(v)$ 真 $\Rightarrow A^*\ge v$，$A^*\ge v$ 与 $check(v)$ 假 $\Rightarrow A^*<v$）加上引理 3 的下封闭性，以及初始锚点 $[0,2000]\ni A^*$（引理 6.3）。

**（iii）浮点算术本身达不到 $10^{-8}$。** $|b_k|\le2000$，$|S_j|\le n\cdot2000=2\times10^8$。用标准前缀和误差模型（Higham：$\hat S_j=\sum_{k\le j}b_k(1+\theta_k)$，$|\theta_k|\le\gamma_j=\frac{ju}{1-ju}$，unit roundoff $u_{\text{double}}=2^{-53}\approx1.11\times10^{-16}$），$j=n=10^5$ 时 $\gamma_n\approx1.11\times10^{-11}$：

$$|\hat S_j-S_j|\le\gamma_n\sum_{k\le j}|b_k|\le1.11\times10^{-11}\times2\times10^8=2.2\times10^{-3},$$

子段和 $\hat S_j-\hat S_i$ 的绝对误差 $\le4.4\times10^{-3}$（两个前缀误差相加）。判据实际比较的是 $S_j-mn\ge0$，而真值 $=L(\bar a-v)$；当决定性的那个子段长度 $L=1$（$m=1$ 时完全可能）时，$v$ 的**可分辨下限被算术误差顶到 $\approx4.4\times10^{-3}$**，比 (i) 需要的 $10^{-8}$ 差约 5 个数量级。换 `long double`（$u=2^{-64}\approx5.42\times10^{-20}$，$\gamma_n\approx5.4\times10^{-15}$）后界降到 $\approx2.2\times10^{-6}$，仍达不到 $10^{-8}$。随机数据的典型误差量级 $\approx\sqrt n\,u{\sum}|b_k|\approx7\times10^{-6}$，同样过大。

**（iv）常见的两个补丁都不彻底。** ①`check` 里加容差 `s[p]>=mn-eps`：把判据整体放宽，等价于系统性高估 $A^*$，$\delta>0$ 时可能多输出 1；②输出写 `(int)(r*scale+1e-7)`：只补"下界偏小"这一个方向。(iii) 给出的可定位精度是 $\eta\approx\frac{E_{\text{sum}}}{L_{\min}}$（$L_{\min}\ge1$ 是决定性子段的长度），而 (i) 要求 $\eta<\frac{1}{1000n}$，即需要

$$E_{\text{sum}}<\frac{L_{\min}}{1000\,n}\ \overset{L_{\min}=1}{=}\ 10^{-8},$$

实际 $E_{\text{sum}}=4.4\times10^{-3}$ 大了 $4.4\times10^{5}$ 倍——换算成输出：$1000\eta\approx4.4$，即千倍整数的**个位都不能保证**。只有在 $n$ 小、$m$ 大（$L_{\min}=m$ 大，例如 $m=10^3$ 时需求放宽为 $E_{\text{sum}}<10^{-5}$）时数据才"勉强够用"，这也解释了为什么浮点版能过一部分点、却被卡。

**（v）最省事的出路**：既然只需要 $\lfloor1000A^*\rfloor$，就把候选**限制在网格 $\frac{T}{1000}$（$T\in\mathbb{Z}$，$T\in[0,2\,000\,000]$）上**，判据里的每一项都乘 $1000$ 变成整数——一次除法都不做，(i)(iii) 两个障碍同时消失（引理 6）。代价只是二分轮数从"$\ge38$ 轮实数（仍不可靠）"变成"$21$ 轮整数（可证明可靠）"，反而更快。

**引理 6（整数化判据与原判据等价，且等于所求答案）** 记 $c_k(T)=1000a_k-T$，$\widetilde M(T)=\max_{\mathcal{F}}\sum_{k=l}^{r}c_k(T)$。则

1. $\widetilde M(T)=1000\cdot M(T/1000)$，故 $check(T):=\big[\widetilde M(T)\ge0\big]\iff\big[A^*\ge\frac{T}{1000}\big]$，且 $check$ 全程可用整数完成；
2. $\max\{T\in\mathbb{Z}:check(T)\}=\lfloor 1000A^*\rfloor$；
3. $check(0)$ 为真、$check(2\,000\,001)$ 为假（二分的两端锚点），$A^*\in[0,2000]$。

**证明**：
1. 对任一 $[l,r]\in\mathcal{F}$（长度 $L$）：$\sum c_k(T)=1000\sum a_k-TL=1000\big(\sum a_k-\frac{T}{1000}L\big)=1000\sum_{k}\big(a_k-\tfrac{T}{1000}\big)$，即"用 $c$ 求和"恰好是"用 $b=a-v$ 求和"的 $1000$ 倍。因 $1000>0$，两者同号，对族 $\mathcal{F}$ 取最大也同号（$\max(1000X)=1000\max X$ 对有限集成立），故 $\widetilde M(T)=1000M(T/1000)$，$\widetilde M(T)\ge0\iff M(T/1000)\ge0$；再由引理 2 得 $\iff A^*\ge\frac{T}{1000}$。左、右端点都是整数：$1000\sum a_k$ 与 $TL$ 皆整数，故 $\widetilde M(T)$ 是整数，"$\ge0$"是精确判定，不存在"接近 0"的模糊区。
2. 由 1，$\{T\in\mathbb{Z}:check(T)\}=\{T\in\mathbb{Z}:T\le 1000A^*\}$（把 $A^*\ge\frac{T}{1000}$ 两边乘正数 $1000$）。由引理 1，$A^*\ge0$（$a_k\ge0\Rightarrow\bar a\ge0$），故该集合含 $0$、非空；又 $A^*\le 2000$ 使其有上界。整数集 $\{T:T\le x\}$ 的最大元按定义为 $\lfloor x\rfloor$，取 $x=1000A^*$ 即得。
3. $check(0)$：取 $[1,m]\in\mathcal{F}$，$\sum_{k=1}^{m}c_k(0)=1000\sum a_k\ge0$（$a_k\ge0$）✓。$T\ge 2\,000\,001$：$c_k(T)=1000a_k-T\le 2\times10^6-2\,000\,001=-1$，故任何**非空**子段和 $\le -L<0$，$\widetilde M(T)<0$，$check$ 假 ✓。再由引理 2 取 $v=0$ 与 $v=2000+\epsilon$ 得 $0\le A^*\le2000$（$A^*\le\max a_k\le2000$ 由"平均数不小于最小项、不大于最大项"，其证明：$\sum a_k\le L\cdot\max a_k$ 两边除 $L>0$）。$\blacksquare$

**引理 3 的整数版**：$T_1<T_2\Rightarrow\widetilde M(T_1)\ge\widetilde M(T_2)$，由引理 3 除以正常数 $1000$ 即得（或直接在 2.4 的证明里令 $v_i=\frac{T_i}{1000}$、$L(T_2-T_1)/1000\ge 0$）。故 $check$ 在 $\mathbb{Z}$ 上单调（一串 true 后全 false），"最大可行 $T$"二分合法。

### 2.7 中途自查：最优子段能多长？两个贪心猜想为什么错

**引理 7（长度压缩）** 必存在达到 $A^*$ 的子段，其长度 $L$ 满足 $m\le L\le 2m-1$。

**证明**：若已存在长度 $<2m$ 的最优子段则结论成立；否则在所有最优子段中取长度最短者 $[l,r]$，设 $L=r-l+1\ge2m$，记 $\mu=A^*$，$\Sigma_X$ 表示段 $X$ 的元素和，$\bar X=\Sigma_X/|X|$。把 $[l,r]$ 拆成前段 $P=[l,l+m-1]$（长 $m$）与后缀 $R=[l+m,r]$（长 $L-m\ge m\ge1$，因 $L\ge2m$），两段仍属 $\mathcal F$。由 $\Sigma_{[l,r]}=\Sigma_P+\Sigma_R$ 与 $L=m+(L-m)$：

$$\mu=\frac{\Sigma_P+\Sigma_R}{L}=\frac{m\bar P+(L-m)\bar R}{L},$$

即 $\mu$ 是 $\bar P,\bar R$ 的凸组合（两系数 $\frac{m}{L},\frac{L-m}{L}$ 均 $>0$ 且和为 1）。不妨设 $\bar P\le\bar R$，则

$$\mu-\bar P=\frac{(L-m)(\bar R-\bar P)}{L}\ge0,\qquad \bar R-\mu=\frac{m(\bar R-\bar P)}{L}\ge0,$$

即 $\bar P\le\mu\le\bar R$（通分即可验证两式；这一步没有用任何"显然"的夹逼直觉）。另一方面 $P,R\in\mathcal F$ 且 $A^*=\mu$ 是全体可行子段平均数之上界，故 $\bar P\le\mu$、$\bar R\le\mu$。与上一条合并得 $\bar R\le\mu\le\bar R$，即 $\bar R=\mu$（进而 $\bar P=\mu$）。于是 $R$ 也是最优子段，但 $|R|=L-m<L$，与 $[l,r]$ 是**最短**的最优子段矛盾。反证完成，故 $L\le 2m-1$。$\blacksquare$

**推论（一个备选算法）**：枚举 $L\in[m,2m-1]$ 与起点，用整数前缀和 + 交叉相乘比较，得 $O(nm)$ 精确解。$m$ 很小（如 $m\le700$，则 $nm\le7\times10^7$）时它比二分更快更好写；$m$ 接近 $n$ 时 $nm\approx10^{10}$ 崩溃。**两个参数的角色互补**，这也是正解选"$O(n\log V)$ 二分"而非枚举长度的理由。

**引理 8（最优段内部必有"拖后腿"的项）** 设 $[l,r]$ 达到 $\mu$，长度 $L$。则

1. 存在 $k\in[l,r]$ 使 $a_k\ge\mu$，且存在 $t\in[l,r]$ 使 $a_t\le\mu$；
2. 若段内每项都 $\ge\mu$（或都 $\le\mu$），则每项都**恰等于** $\mu$。

**证明**：记 $\Sigma=\sum_{k=l}^ra_k=L\mu$。
1. 反证：若所有 $a_k<\mu$，则 $\Sigma< L\mu$，与 $\Sigma=L\mu$ 矛盾，故存在 $a_k\ge\mu$；同理想若所有 $a_t>\mu$ 则 $\Sigma>L\mu$ 矛盾，故存在 $a_t\le\mu$。
2. 若所有 $a_k\ge\mu$，则 $\Sigma(a_k-\mu)=\Sigma-L\mu=0$，而每个加项 $\ge0$；有限个非负数之和为 $0$ 迫使逐项为 $0$，即 $a_k=\mu$ 对所有 $k$。（"$a_t\le\mu$ 恒成立"同理。）$\blacksquare$

**猜想 A（"贪心：取某个阈值下的极大连续段"）不成立**：由引理 8.1，最优段里一定有 $\le\mu$ 的项；由 8.2，除非段内全相等，就一定有**严格** $<\mu$ 的项。所以"一段全是 $\ge$ 某阈值的数"这种形状根本刻画不了最优解。具体反例（E6，$n=3,m=2,a=[5,1,5]$）：$\mu=\frac{11}3$，若按"每项 $\ge\mu$"取极大连续段，只能得到长度 1 的 $[1,1]$ 或 $[3,3]$，**违反 $L\ge m$**，判据直接空集。

**引理 9（加入一项对平均数的影响）** 段 $[l,r]$ 平均 $\mu$、长 $L$，右侧加入一项 $x$ 后新平均为 $\frac{L\mu+x}{L+1}$，且

$$\frac{L\mu+x}{L+1}-\mu=\frac{x-\mu}{L+1},$$

故新平均**上升当且仅当 $x>\mu$**。

**证明**：$\frac{L\mu+x}{L+1}-\mu=\frac{L\mu+x-(L+1)\mu}{L+1}=\frac{x-\mu}{L+1}$；分母 $L+1>0$，符号完全由 $x-\mu$ 决定（这正是 2.1 里"合并会稀释"的定量版本，双向都成立：$x>\mu\Rightarrow$ 上升，$x<\mu\Rightarrow$ 下降，$x=\mu\Rightarrow$ 不变）。$\blacksquare$

**猜想 B（"最优长度恰好是 $m$"）不成立**：引理 9 指出，只要还能接到一个大于当前平均数的项，加长就继续变优。反例即 E6：长度恰为 $m=2$ 的两个子段平均都是 $3$，而再接一项 $5>3$，整段平均升到 $\frac{11}3>3$。结合引理 7，正确表述是"**最优长度落在 $[m,2m-1]$**"，而不是"$=m$"。

> 关于题面标签里的"贪心"：本文唯一用到的贪心成分在引理 4/5——固定右端点时左端点**只取前缀最小值**（局部最优即全局最优），这是可证明的（引理 4 第二个方向）；不存在"直接构造最优子段"的纯贪心正解（猜想 A、B 均已被否）。

### 2.8 溢出预算

- $c_k(T)=1000a_k-T\in[-2\,000\,000,\ 2\,000\,000]$，用 `int` 存 $a$、$T$ 用 `i64` 参与运算即可（$1000\times2000=2\times10^6<2^{31}$ ✓，不会在乘法阶段溢出）。
- 前缀和 $|S_j|\le n\times2\times10^6=2\times10^{11}$，必须 `i64`（`int` 上限 $2.147\times10^9$，会溢出约 $100$ 倍）。`i64` 上限 $9.22\times10^{18}$，余量 $4.6\times10^{7}$ 倍 ✓。
- $mn$、$S_j-mn$ 同在 `i64` 域，$\le 4\times10^{11}$ ✓。
- 输出 $T\le 2\times10^6$，`int` 够；比较 $S_p\ge mn$ 是整数比较，无需 $\epsilon$。

### 2.9 复杂度

- $K=\lceil\log_2(\text{maxT}+1)\rceil=\lceil\log_2(2\,000\,001)\rceil=21$ 轮。
- 每轮 $2n$ 步（建前缀 $n$ + 扫描至多 $n-m+1$）。总计 $2\times10^5\times21=4.2\times10^6$ 次基本运算，远低于 1s 量级（$\sim10^8$ 次/秒）。
- 空间 $O(n)$：`a` $4\times10^5\,\text{B}$，`s` $8\times10^5\,\text{B}$，共约 $1.2\,$MB。
- 对照：60% 暴力 $O(n^2)$，$n=10^4$ 时 $5\times10^7$；引理 7 的 $O(nm)$ 版在 $m$ 小时最优；正解对 $n=10^5$ 只需 $4.2\times10^6$，且与 $m$ 无关。

> 延伸（本文不使用、也不证明）：把 $(j,S_j)$ 看成平面点，$\bar a(l,r)$ 是两点连线斜率，最大平均子段等价于"横距 $\ge m$ 的点对最大斜率"，可在 $O(n)$（下凸壳 + 切线扫描）内得到**精确有理数**答案。整数二分已足够快，故不引入更复杂且易写错的凸壳代码。

## 3. 模式总结（Pattern Summary）

按**实际思考顺序**，同种技巧的多次使用分列：

- **explore its property** — 平均数是比值不可加；约束是 $L\ge m$（变长），不是定长滑动窗口。
- **consider easier version** — $n\le10^4$ 暴力枚举 + 交叉相乘比分数：确立"全程有理数、不碰浮点"的纪律。
- **reduce to easier problem** — 优化 → 判定：引理 2 把 "$A^*\ge v$" 变成 "存在 $L\ge m$ 子段使 $\sum(a_k-v)\ge0$"（中心化，$L>0$ 保号，双向）。
- **classic problem solution** — 单调性证明（引理 3）：$M(v)$ 非增 ⇒ 解集向下封闭 ⇒ 分数规划 + 二分答案。
- **classic problem solution** — 前缀和极差（引理 4+5）：配对双射 + 固定右端点取最小前缀，$O(n)$ 算 $M(v)$，用 $mn$ 滚动维护。
- **precision budget** — 输出截断到千分之一 ⇒ 需 $|\hat x-A^*|<\frac{1}{1000n}=10^{-8}$、二分 $k\ge38$ 轮；但 `double` 前缀和误差界 $E_{\text{sum}}\approx4.4\times10^{-3}$（`f80` $\approx2.2\times10^{-6}$）大 $10^{5}$ 倍 ⇒ 浮点分数规划在本题只是启发式，连千倍整数的个位都保不住。
- **classic problem solution** — 分数规划的第二形态：**候选网格化** $v=\frac{T}{1000}$，$c_k=1000a_k-T$ 全整数（引理 6），把浮点误差降为 0，二分降为 21 轮。
- **structural self-check** — 引理 7 长度压缩（最短的最优段必 $<2m$，否则切前 $m$ 项做凸组合矛盾）；引理 8/9 用反证 + 差分公式否定"取极大 $\ge$ 阈值段"与"最优长度恰为 $m$"两个贪心猜想，并顺手得到 $O(nm)$ 备选算法。
- **overflow guard** — $|S|\le2\times10^{11}$ ⇒ `i64`；锚点 $check(0)$ 真、$check(2\times10^6+1)$ 假。
- **definition-based check** — 无官方样例 ⇒ 用定义枚举 6 组小例逐一对照（§4.3）。

## 4. 真实解法（Real Solution）

### 4.1 符号表（Notation Glossary）

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n` | 数列长度 | `int`，输入 | $\le 10^5$ |
| `m` | 子段长度下限 | `int`，输入 | $\le n$ |
| `a[i]` | 数列第 $i$ 项 | `int a[mxn]`，**0-based** | $0\le a_i\le2000$ |
| `T` | 候选答案（$=$ 平均数 $\times1000$） | `i64`，二分变量 | $\in[0,2\,000\,000]$ |
| `scale` | 千倍放大因子 | `constexpr int{1000}` | 与题面输出一致 |
| `maxA` / `maxT` | 值域上界 $2000$ / $1000\cdot2000$ | `constexpr int` | $2\,000\,000$ |
| `s[i]` | $s[i]=\sum_{k<i}(1000a_k-T)$，即**前 $i$ 项**中心化前缀和 | `i64 s[mxn]`，`s[0]=0` | $|s|\le2\times10^{11}$ |
| `mn` | $\min_{0\le j\le p-m}s[j]$，扫描中滚动维护 | `i64`，初值 $0=s[0]$ | 引理 5 |
| `l`,`r` | 二分的"最大可行 $T$"闭区间 | `int`，`l=0,r=maxT` | $mid=(l+r+1)>>1$ |
| `ans` | 最终输出 $\lfloor1000A^*\rfloor$ | 即二分后的 `l` | 整数，直接输出 |

> **下标约定**：内部 **0-based**，与题面 $a_1..a_n$ 的差别仅在 $a[i]=a_{i+1}$；前缀和 $s[i]$ 表示"前 $i$ 项"，故 $s$ 的长度是 $n+1$（$s[n]$ 存在），`mxn{100005}` 足够（$10^5+1\le100005$ ✓）。子段用半开区间 $[\,i,\,p)$ 表示，和为 $s[p]-s[i]$，长度 $p-i$，合法条件 $p-i\ge m$。

### 4.2 算法步骤

1. **读入** $n,m$ 与 $a[0..n-1]$。
2. **`check(T)`**（对应引理 2+4+5+6）：
   1. `s[0]=0`；`for i in 0..n-1: s[i+1]=s[i]+scale*a[i]-T;`
   2. `mn=0`；`for p in m..n:` 先 `mn=min(mn,s[p-m])`（此时 $mn=\min_{0\le j\le p-m}s[j]$，引理 5），再若 `s[p]>=mn` **返回 true**（半开区间 $[\,j,\,p)$，长度 $\ge m$，和 $\ge0$）。
   3. 循环结束未命中返回 false。
3. **二分最大可行 $T$**（引理 3 整数版保证单调，引理 6.3 保证锚点）：`l=0,r=maxT;` `while(l<r){mid=(l+r+1)>>1; if(check(mid)) l=mid; else r=mid-1;}`。
4. **输出** `l`（即 $\lfloor1000A^*\rfloor$，整数截断，按题面**不**使用 `fixed<<setprecision`）。

**定理（主结论）** 上述算法输出的整数恰为 $\lfloor1000A^*\rfloor$，且在 $21$ 次 `check` 内终止。

**证明**：分四块。

1. **`check` 的正确性**：`check(T)` 返回真 $\iff\exists p\in[m,n],\exists j\in[0,p-m]:s[p]-s[j]\ge0$（由引理 5 的不变量，$mn$ 正是 $\min_{0\le j\le p-m}s[j]$，故 $s[p]\ge mn$ 与"$\exists j$ 使差 $\ge0$"等价）$\iff\widetilde M(T)\ge0$（引理 4 的双射，半开区间 $[\,j,\,p)$ 对应闭区间 $[j{+}1,\,p]$）$\iff A^*\ge\frac{T}{1000}$（引理 6.1 + 引理 2）✓。
2. **循环不变式**：记 $T^\star=\max\{T\in\mathbb{Z}:check(T)\}$。初始 $l=0$：$check(0)$ 真（引理 6.3）故 $l\le T^\star$；$r=maxT=2\,000\,000\ge T^\star$（引理 6.2 给出 $T^\star=\lfloor1000A^*\rfloor\le1000A^*\le1000\times2000$，末式由引理 6.3 的 $A^*\le2000$）。每步：若 $check(mid)$ 真则 $mid\le T^\star$，令 $l=mid$ 保持 $l\le T^\star\le r$；若假则 $mid>T^\star$，令 $r=mid-1\ge T^\star$ 仍保持。故不变式 $l\le T^\star\le r$ 全程成立，由引理 3 整数版（$check$ 单调）保证"假的所有 $T$ 都 $>T^\star$"。
3. **终止与轮数**：设区间长度 $N=r-l+1$。$l<r$ 时 $mid=\lfloor\frac{l+r+1}2\rfloor$ 满足 $l<mid\le r$（因 $r\ge l+1\Rightarrow l+r+1\ge2l+2\Rightarrow mid\ge l+1$；$l+r+1\le2r+1\Rightarrow mid\le r$）。真分支后新长度 $r-mid+1=N-\,(mid-l)\le\lceil N/2\rceil$；假分支后新长度 $mid-l\le\lceil N/2\rceil$。故每步长度至少折半，$N_0=2\,000\,001$ 经 $\lceil\log_2 2\,000\,001\rceil=21$ 步缩到 $1$，此时 $l=r=T^\star$ 退出 ✓。
4. **输出即所求**：退出时 $l=r=T^\star=\lfloor1000A^*\rfloor$（引理 6.2）。$\blacksquare$

**复杂度**：时间 $O(n\log(\text{maxT}))=10^5\times21\times2\approx4.2\times10^6$；空间 $O(n)\approx1.2\,$MB。

$21=\lceil\log_2(2\,000\,001)\rceil$ 步，与 $K=21$ 相符；每一步的 $mid$ 都由 $(l+r+1)\gg1$ 的整数除法手工核对（如 $(1647+1707+1)\gg1=3355\gg1=1677$）。终值 $1666$ 与定义值一致。

**引理自测**：引理 7（$L\le2m-1$）在 E1（$m=2$，最优长 $2$）、E5（$m=3$，最优长 $3$）、E6（$m=2$，最优长 $3=2m-1$）上都成立且 E6 表明不能再收紧；引理 8 在 E1 最优段 $[4,5]$ 上给出 $4<4.5<5$ ✓，在 E6 最优段 $[5,1,5]$ 上给出 $1<\frac{11}3<5$ ✓。

**验证状态小结**：6 组小例全部由定义直接枚举复核，与算法判定一致；覆盖边界 $m=1$、$m=n$、$\delta=0$、最优长 $>m$、全零数据。**本环境无编译器，未做任何编译/运行/对拍**，故不报告得分与耗时；上述所有数字均为手算，可逐行复核。

## 5. 示例代码（C++）

### 5.1 主代码：整数化分数规划（可证明正确，零浮点误差）

```cpp
// P1404 平均数
// 分数规划 + 候选网格化(T/1000) + 前缀和极差判定，全程 i64，无浮点误差
// https://www.luogu.com.cn/problem/P1404
#include<bits/stdc++.h>
using namespace std;
using i64=long long;
using f64=double;                       // 仅 §5.2 浮点对照版使用

constexpr int mxn{100005};              // n<=1e5，+5 松弛；s 需 n+1 项
constexpr int maxA{2000};               // a_i 上界
constexpr int scale{1000};              // 输出=平均数的 1000 倍（截断）
constexpr int maxT{scale*maxA};         // 2000000，答案上界
constexpr double eps{1e-8};             // 浮点版所需精度下界，见 §2.6；主代码全整数不用

int n,m;
int a[mxn];
i64 s[mxn];                             // s[i]=前 i 项的 (1000*a-T) 和，s[0]=0

// 判定：是否存在长度 >= m 的半开区间 [i,p) 使 sum(1000*a-T) >= 0
bool check(i64 T)
{
	s[0]=0;
	for(int i=0;i<n;++i)
		s[i+1]=s[i]+scale*a[i]-T;
	i64 mn{0};                          // mn=min(s[0..p-m])，s[0]=0 故初值 0 正确
	for(int p=m;p<=n;++p)
	{
		if(s[p-m]<mn)
			mn=s[p-m];
		if(s[p]>=mn)                    // 极差 >= 0，取等号也算达标
			return true;
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];

	// 最大可行 T：check(0) 恒真（a_i>=0）故 l=0 是合法锚点，偏上界取 mid
	int l=0,r=maxT;
	while(l<r)
	{
		int mid=(l+r+1)>>1;
		if(check(mid))
			l=mid;
		else
			r=mid-1;
	}
	cout<<l<<'\n';
	// cerr<<fixed<<setprecision(6)<<(f64)l/scale<<'\n';   // 参考平均值，仅调试
	return 0;
}
```

**代码说明**

- `check` 两遍线性扫描：第一遍建 $1000a_k-T$ 的前缀和（`i64`，$|s|\le 2\times10^{11}$）；第二遍用 `mn` 滚动维护"可作左端点的最小前缀"，$s[p]\ge mn$ 即找到达标子段并可提前退出（引理 4+5）。
- 判据用 `>=` 而非 `>`：$1000A^*$ 可能恰为整数（E5），取等即 $\lfloor1000A^*\rfloor=T$。
- 二分是"最后一个 true"形态：`mid=(l+r+1)>>1`，`l` 初值 $0$ 由引理 6.3 保证可行，故循环不变式 `check(l)=true ∧ ¬check(r+1)` 全程成立（$r$ 上界 $maxT$ 时若 $maxT$ 可行则答案 $=maxT$，也正确）。
- 输出按题面为**整数**，不用 `fixed<<setprecision`；千倍截断由整数二分直接给出。
- `using f64=double;`、`eps` 属于 §5.2 的浮点对照版（本文不推荐作为正解），保留以对应误差预算。

### 5.2 浮点版（对照用，独立程序；精度预算见 §2.6，非可证明正确）

```cpp
// 分数规划浮点版：二分候选平均值 v，判据 sum(a-v)>=0
// 误差预算：需 |v-A*| < 1e-8（§2.6），但 double 前缀和误差界 ~4.4e-3 -> 理论不可保证
#include<bits/stdc++.h>
using namespace std;
using i64=long long;
using f64=double;

constexpr int mxn{100005};
constexpr double eps{1e-8};             // 目标精度（§2.6 推出），非"比较容差"
constexpr int maxA{2000},scale{1000};

int n,m,a[mxn];
f64 s[mxn];

bool checkf(f64 v)
{
	s[0]=0;
	for(int i=0;i<n;++i)
		s[i+1]=s[i]+a[i]-v;
	f64 mn{0};
	for(int p=m;p<=n;++p)
	{
		if(s[p-m]<mn)
			mn=s[p-m];
		if(s[p]>=mn)
			return true;
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	// 区间宽 V0=2000，单侧估计 l 需 V0/2^K < eps(=1e-8) => K >= 38（§2.6(ii)）；取 60 轮
	// 再多的轮数无意义：ulp(2000)=2^-42≈2.3e-13，K≈53 后 l,r 不再变化
	f64 l=0,r=maxA;
	for(int it=0;it<60;++it)
	{
		f64 mid=(l+r)/2;
		if(checkf(mid))
			l=mid;
		else
			r=mid;
	}
	cout<<(i64)(l*scale)<<'\n';          // 截断：l 偏小则少 1，且救不了 (iii) 的算术噪声
	return 0;
}
```

**两版对照结论**：5.2 与 5.1 结构完全同形（同样判据、同样 $O(n)$ 扫描），差别只在候选取实数还是取 $\frac{T}{1000}$ 网格：

- 轮数：5.2 至少 $38$ 轮（§2.6(ii)），5.1 只需 $21$ 轮；
- 判据精度：5.2 的 $S$ 带 $E_{\text{sum}}\approx4.4\times10^{-3}$ 的算术误差界，5.1 全程整数、判据 $\ge0$ 精确；
- 输出方向：5.2 取单侧 $l$ 时，$\delta=0$（$1000A^*$ 恰为整数）永远差 $1$，除非 $A^*$ 本身是二进制可表示数（如 E5 的 $4$）才"侥幸"命中；例如 $A^*=\frac15$（$n=5,m=5,a=[1,0,0,0,0]$，定义答案 $200$），$\frac15$ 不可表示，$\lfloor1000l\rfloor$ 落在 $199$ 还是 $200$ 取决于舍入方向，理论上不可保证（本文未运行程序，不作实测断言）。

故**提交采用 5.1**。
