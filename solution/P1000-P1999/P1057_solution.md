# P1057 [NOIP 2008 普及组] 传球游戏 — 题解

---

## 一、发现叙事：从枚举到递推

### 1.1 问题的直觉

有 $n$ 个同学围成一圈，从 $1$ 号（小蛮）开始传球。每次传球，持球人可把球传给**左边或右边**的同学。传了 $m$ 次后，球回到小蛮手里。问有多少种不同的传球序列。

样例给了 $n=3,m=3$，答案是 $2$。手动枚举即可验证：

```
1 → 2 → 3 → 1
1 → 3 → 2 → 1
```

为什么只有两种？因为 $n=3$ 时，左右邻居实际上覆盖了整个环除了自己。传 $3$ 次恰好走完一圈回来只有这两个方向选择。

### 1.2 从暴力到记忆化

如果我们对 $n,m$ 做暴力枚举——每次有两种选择，总方案数是 $2^m$，当 $m\le 30$ 时 $2^{30}\approx 10^9$，不可接受。但状态空间其实很小：**传了 $i$ 次后球在谁手里**，这个二元组 $(i,j)$ 最多只有 $(m+1)\times n$ 种，在 $30\times 30=900$ 量级。

这就是动规的直觉来源：用状态压缩指数级枚举。

### 1.3 递推关系的发现

设 $f(i,j)$ 表示**传了 $i$ 次后球在 $j$ 号同学手里的方案数**。

考虑最后一次传球：第 $i$ 次时球到 $j$ 手里，那么第 $i-1$ 次时球必须在 $j$ 的左邻或右邻。左邻是 $(j-1)$，右邻是 $(j+1)$（模 $n$ 意义下）。所以：

$$
f(i,j)=f(i-1,j-1)+f(i-1,j+1)
$$

边界：$f(0,1)=1$（传 $0$ 次时球就在 $1$ 号手里），其他 $f(0,j)=0$。

答案就是 $f(m,1)$。

### 1.4 另一种视角：矩阵快速幂

如果觉得递推还不够过瘾，注意到递推是线性的，可以写成 $n\times n$ 的循环矩阵。但 $n,m\le 30$ 时递推已经足够，不必上矩阵。

## 二、推理链与完整证明

### 2.1 问题形式化

记同学编号为 $0,1,\dots ,n-1$（方便取模）。初始位置 $s=0$。每次传球，当前位置 $x$ 可转移到 $(x-1)\bmod n$ 或 $(x+1)\bmod n$。求 $m$ 步后回到 $0$ 的路径条数。

这是一个**无权有向图上的固定长度路径计数**问题。图是一个 $n$ 个点的环，每个点出度为 $2$（左右各一）。

### 2.2 状态定义与正确性

**定义** $dp[i][j]$：恰好传了 $i$ 次球后，球在 $j$ 号同学手里的方案数，其中 $0\le i\le m,\;0\le j<n$。

**正确性论证**：

1. **完备性**：任何一条长为 $i$ 的传球路径，走到第 $i$ 步时必然落在某个 $j$ 上，所以所有路径被这些状态不重不漏地划分。
2. **无后效性**：第 $i$ 步的状态只依赖于第 $i-1$ 步的状态，与更早的历史无关——马尔可夫性成立。
3. **递推正确性**：要到达 $j$，第 $i-1$ 步必须在 $j$ 的邻居处。两个邻居对应两类路径，互不相交（因为第 $i-1$ 步的位置不同），方案数相加即可。

### 2.3 边界与答案

- $dp[0][0]=1$，$dp[0][j]=0\;(j\neq 0)$。
- 递推 $i=1..m$：$dp[i][j]=dp[i-1][(j-1+n)\bmod n]+dp[i-1][(j+1)\bmod n]$。
- 答案 $ans=dp[m][0]$。

### 2.4 复杂度分析

$O(mn)$ 时间，$O(mn)$ 空间。由于 $m,n\le 30$，这是微不足道的。空间可以优化到 $O(n)$ 滚动数组，但没必要。

### 2.5 滚动数组优化证明

注意到 $dp[i]$ 只依赖 $dp[i-1]$，因此可以用两个长度为 $n$ 的数组滚动：

```
cur[0] = 1
for step = 1..m:
    for j = 0..n-1:
        nxt[j] = cur[(j-1+n)%n] + cur[(j+1)%n]
    swap(cur, nxt)
ans = cur[0]
```

正确性：每次迭代后 `cur` 等价于原来的 $dp[step][\cdot]$。这是正确的，因为递推只涉及前一层。

## 三、模式总结

| 观察点 | 结论 |
|---|---|
| 问题的核心结构 | 环上固定长度路径计数，每步两种选择 |
| 状态空间 | $(i,j)$ 二元组，$i$ 步数，$j$ 位置 |
| 递推形态 | $f(i,j)=f(i-1,j-1)+f(i-1,j+1)$ |
| 图论视角 | 环图邻接矩阵的 $m$ 次幂的 $(0,0)$ 元素 |
| 时空复杂度 | $O(mn)$ 时间，$O(n)$ 空间（滚动） |
| 同类问题 | 网格路径计数、爬楼梯变体、环上随机游走 |
| 关键技巧 | 模 $n$ 处理环形；滚动数组降维 |

本题是**线性递推在环结构上的经典应用**。当状态图是正则图（每点出度相同）且要求固定步数时，DP 总是可行的。

## 四、正式解法与符号表

### 4.1 符号表

| 符号 | 含义 |
|---|---|
| $n$ | 同学人数（环的大小） |
| $m$ | 传球次数 |
| $dp[i][j]$ | 传 $i$ 次后球在 $j$ 的方案数 |
| $(j-1)\bmod n$ | $j$ 的左邻居 |
| $(j+1)\bmod n$ | $j$ 的右邻居 |
| $ans$ | 最终答案，即 $dp[m][0]$ |

### 4.2 完整算法

```
输入 n, m
初始化 dp[0..m][0..n-1] 为 0
dp[0][0] = 1

for i = 1 to m:
    for j = 0 to n-1:
        dp[i][j] = dp[i-1][(j-1+n)%n] + dp[i-1][(j+1)%n]

输出 dp[m][0]
```

### 4.3 正确性说明

- **初始化正确**：传 $0$ 次球就在 $0$ 号位，仅此一种。
- **转移正确**：第 $i$ 步到 $j$，只能由第 $i-1$ 步在 $j$ 的左右邻居转移而来。
- **最终答案正确**：$dp[m][0]$ 即为传 $m$ 次回到起点的方案总数。

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int n,m;
int dp[2][35];

int main()
{
    cin.tie(nullptr);
    ios::sync_with_stdio(false);

    cin>>n>>m;
    dp[0][0]=1;
    for(int i=1;i<=m;++i)
    {
        int cur=i&1;
        int pre=cur^1;
        for(int j=0;j<n;++j)
        {
            dp[cur][j]=dp[pre][(j-1+n)%n]+dp[pre][(j+1)%n];
        }
    }
    cout<<dp[m&1][0]<<'\n';
    return 0;
}
```

### 代码要点

- **滚动数组**：`dp[2][35]` 仅两行，通过 `i&1` 和 `i&1^1` 切换当前层与前一层。
- **下标 $0$-based**：同学编号 $0..n-1$，与取模运算自然对齐。
- **环形取模**：`(j-1+n)%n` 处理 $j=0$ 时左邻为 $n-1$。
- **Allman 风格**：花括号换行，缩进使用 Tab（依编码规范）。
- **输入输出优化**：`cin.tie` 与 `ios::sync_with_stdio(false)` 按规范顺序书写。
- **简洁无冗余**：无多余头文件，无注释，无 `endl`。
