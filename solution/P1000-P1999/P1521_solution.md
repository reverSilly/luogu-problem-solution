# P1521 求逆序对

> 标签：动态规划 DP · 难度：普及/提高-
> 本地题面：`P1521.md`（$N\le100$，$K\le N(N-1)/2$；答案对 $10000$ 取模）。验证：本地对拍 300 组随机/边界用例 std==brute 全部通过；最坏 $N=100,K=4950$ 实测 **0.0078s**；样例 $N=5,K=3$ 输出 **15**（题面给出的 15 个排列吻合）。

## 1. 重新读题

**问题重述（人话版）**

给两个整数 $N,K$。把 $1,2,\dots,N$ 的每一种排列拿出来，数一数它里面有多少个逆序对（下标 $i<j$ 而 $a_i>a_j$ 的数对）。我们要统计"逆序对个数**恰好等于** $K$"的排列有多少种，把答案对 $10000$ 取模后输出。

一句话版本：**对全体 $N!$ 个排列按"逆序对数"分桶，输出桶 $K$ 的大小（模 $10000$）。**

**题面里容易漏掉的条款**

1. 计数对象是 $1,\dots,N$ 的**排列**，元素两两互异。这一点很关键：逆序对只取决于元素间的**大小次序**，与元素具体取什么数值无关，所以"$1..N$ 的排列"和"$N$ 个互异数的任意排列"在计数上是同一回事。
2. 模数是 **$10000$**（不是常见的 $10007$、$998244353$、$10^9+7$）。$10000$ 不是质数，不能做除法，但本题转移只有加法和减法，不需要逆元。
3. 问的是"**恰好为 $K$**"，不是"至少 $K$"、也不是"前 $K$ 小"。
4. $K\le N(N-1)/2$：$N$ 个元素最多 $N(N-1)/2$ 个逆序对（每一对下标最多贡献一个）。$N=100$ 时上限 $4950$。

**数据范围与规模感受**

$$N\le 100,\qquad K\le \frac{N(N-1)}2\le 4950 .$$

状态规模约 $N\times K\approx 5\times 10^{5}$。若单状态用 $O(N)$ 转移则 $O(N^2K)=5\times10^{7}$，勉强可行；用前缀和把转移降到 $O(1)$ 才是"标准答案"，$O(NK)=5\times10^{5}$。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：用"逐步插入"理解排列

暴力地枚举 $N!$ 个排列再数逆序对，$N=100$ 显然不可行。要计数，得找一个能把排列**增量式地**拼起来的结构。

**想法：从 $1,\dots,i-1$ 的排列构造 $1,\dots,i$ 的排列。** 每次新增的数是当前最大的 $i$，唯一自由度是"把它插在哪个位置"。直觉告诉我们，插入位置会以很规整的方式改变逆序对数，把这个规律精确写下来，就是一切。

**引理 1（插入 $i$ 的新增逆序对恰等于其右侧元素个数）**

把 $i$ 插入一个由 $1,\dots,i-1$ 组成的、长度为 $i-1$ 的排列，设插入后 $i$ **右侧**（位置上更靠后）的元素个数为 $t$（$0\le t\le i-1$）。则：

- $i$ 带来的**新增**逆序对恰好为 $t$ 个；
- 且 $t$ 可以取遍 $0,1,\dots,i-1$，每个 $t$ 恰好对应**一个**插入位置。

**证明**：
- 对任意一对下标，若两端都不是新插入的 $i$，则这对的逆序性完全没有变化；若一端是 $i$，只需看含 $i$ 的数对。
- 含 $i$ 且 $i$ 在**左**（即 $i$ 的下标较小）：另一端点在下标上更靠后，也就是 $i$ 的右侧元素，其值 $<i$，故 $a_i>a_{\text{右}}$ 成立，这是一个逆序对。右侧共有 $t$ 个元素，个数等于 $t$（每个右侧元素与 $i$ 恰好构成一个逆序对，不重不漏）。
- 含 $i$ 且 $i$ 在**右**：另一端点在 $i$ 左侧，其值同样 $<i$，于是 $a_{\text{左}}<a_i$，**不是**逆序对。
- 于是新增逆序对数 $=t$。又设 $i$ 插在第 $p$ 个位置（$p$ 表示它左边有 $p$ 个元素，$p=0..i-1$），则右侧元素个数 $t=(i-1)-p$。当 $p$ 从 $0$ 走到 $i-1$，$t$ 从 $i-1$ 走到 $0$，正好一次不重地覆盖 $0..i-1$，每个 $t$ 对应唯一的 $p=i-1-t$。$\blacksquare$

> 这条引理的价值在于：它把"排列计数"这个看上去要枚举 $N!$ 的东西，变成了"每一步只选一个 0..i-1 的增量"，从而天然适合 DP。

### 2.2 归约到 DP：按"长度 + 逆序对数"分桶

定义

$$dp[i][j]=\#\{\text{由 }1,\dots,i\text{ 组成的排列，其逆序对恰好为 }j\}.$$

**引理 2（DP 转移）**

$$dp[i][j]=\sum_{t=0}^{\min(j,\ i-1)} dp[i-1][j-t].$$

**证明**：
- **完备性**：任一 $1..i$ 的排列，删去元素 $i$ 后剩下一个 $1..i-1$ 的排列，逆序对数减少的量恰为引理 1 中的 $t$（删去 $i$ 不改变其余元素之间的顺序和大小关系，故其余逆序对不变）。所以该排列是被"某个 $1..i-1$ 排列 + 把 $i$ 放在第 $i-1-t$ 位"唯一生成的，$t$ 即其右侧元素个数。
- **计数的不重不漏**：由引理 1，固定一个 $1..i-1$ 的排列，对 $t=0..i-1$ 各取一次插入位置，得到 $i$ 个**互不相同**的 $1..i$ 排列（插入位置不同则结果序列不同），且新增逆序对数分别为 $t$。因此对每个 $t$，从"逆序对数 $j-t$"的短排列出发，恰好能生成一个"逆序对数 $j$"的长排列。
- 反过来，任何 $1..i$ 排列都对应唯一的 $(1..i-1\text{ 排列},\ t)$ 组合，"完备性"已证。
- 约束 $t\le i-1$（插入位置只有 $i$ 个）与 $t\le j$（逆序对数不能为负）给出求和上界 $\min(j,i-1)$。$\blacksquare$

基例：$dp[0][0]=1$（空排列逆序对为 $0$），其余 $dp[0][j>0]=0$。

### 2.3 经典技术：前缀和把 $O(N)$ 转移降到 $O(1)$

直接按引理 2 求和，单状态 $O(i)$，总计 $O(N^2K)=5\times10^{7}$。注意 $dp[i][j]$ 与 $dp[i][j-1]$ 的求和窗口**只差一个数**——这是标准的"滑动窗口求和"，可以差分。

**引理 3（线性递推式）**

对 $i\ge1$，令 $dp[i][-1]=0$，则

$$dp[i][j]=dp[i][j-1]+dp[i-1][j]-dp[i-1][j-i]\qquad(\text{其中 } j-i<0\text{ 时该项记 }0).$$

**证明**：由引理 2，把两个相邻状态作差：

$$
\begin{aligned}
dp[i][j]&=\sum_{t=0}^{i-1}dp[i-1][j-t]\quad(\text{越界项为 }0)\\
dp[i][j-1]&=\sum_{t=0}^{i-1}dp[i-1][j-1-t]=\sum_{u=1}^{i}dp[i-1][j-u] .
\end{aligned}
$$

两式相减，右端公共部分 $dp[i-1][j-1],\dots,dp[i-1][j-(i-1)]$ 抵消，只剩

$$dp[i][j]-dp[i][j-1]=dp[i-1][j]-dp[i-1][j-i].$$

移项即得。当 $j-i<0$ 时 $dp[i-1][j-i]$ 视为 $0$。$\blacksquare$

这一步只用到"相邻窗口差一项"这一个事实，是滑动窗口求和的通用手法（与背包的"$O(1)$ 差分转移"同源）。

### 2.4 取模与负数的处理

递推里出现**减法**，直接 `%10000` 在 C++ 里可能得到负数（C++ 的 `%` 向零取整，负数取模结果为负）。必须在取模后补一次 `+mod` 再取模，保证结果落在 $[0,10000)$。

### 2.5 剖析失败思路

**失败 1：直接枚举 $N!$ 个排列。** $N=100$ 时 $100!\approx9\times10^{157}$，秒杀任何机器 —— 只适合小数据的暴力基准（见 §5.2）。

**失败 2：漏掉 $\min(j,i-1)$ 上界，把 $t$ 求到 $j$。** 则相当于允许插到"末尾之外"，凭空多算。反例：$i=2,j=3$，正确 $t\le1$；若取到 $t=3$，会把不存在的"插入位置"算进去，计数偏大。

**失败 3：把模数写成 $10007$ 或 $10^9+7$。** 题面明文 $10000$，模数错了整体答案就错了（虽然对 `std==brute` 的对拍无法暴露它，因为两版若都用错模数会一起错；因此模数只能靠**读题**保证——本解已按 $10000$ 编写）。

**失败 4：一维滚动+正序递推。** 若把 $i$ 维压掉并正序扫 $j$，则 $dp[i][j-1]$ 读到的可能是**上一轮的旧值**，语义混乱。本解保留二维数组 $dp[i][j]$ 直接使用同行的 $dp[i][j-1]$，无需判断方向，规避了这一类错误（$N\times K$ 的二维数组约 $2$ MB，完全开得起）。

## 3. 模式总结（Pattern Summary）

**模式名：序列计数的「增量插入 DP + 滑动窗口差分」。**

**识别信号**：问"满足某个**可加统计量**等于定值的排列/序列有多少个"，且统计量能通过"逐步插入/逐步追加"来增量刻画。

**可复用套路（按真实思考顺序）**：

- **explore its property** — 把"数某个排列里的逆序对"翻译成"逐步插入时新元素带来的增量 $t$"，确认 $t$ 可枚举且与旧结构无关（引理 1）。
- **consider easier version** — 先用最朴素的"枚举第 $i$ 维的全部增量再求和"写出 $O(N)$ 转移的 DP（引理 2），保证正确性优先。
- **classic problem solution** — 识别出相邻状态的求和窗口只差一项，用**前缀和/滑动窗口差分**把 $O(N)$ 转移降到 $O(1)$（引理 3）。
- **classic problem solution(第二次，独立技巧)** — 减法型递推的**取模归一化**：`v%mod` 后补 `mod` 再取模，保证非负。
- **discuss by category** — 分类讨论边界：$j=0$（无逆序对，唯一升序排列）与 $j-i<0$（窗口未满，缺项记 $0$）。
- **maintain dimension, not rolling-array** — 为规避滚动数组方向错误，直接保留二维 $dp[i][j]$，用同行前一项做差分。

**同族题**：P1049 装箱（背包状差分）、"错排计数/随机排列统计量分布"、任何"排列按某统计量分桶"的经典 DP。

**一句话记忆**：排列计数分桶 = "长度×统计量"两维 DP；转移是"上一行一个滑动窗口之和"，用相邻差分变 $O(1)$。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $N$ | `int n` | 排列长度 | 读入 | 题面 |
| $K$ | `int k` | 目标逆序对数 | 读入 | 题面 |
| `mod` | `constexpr int` | 取模常数 | $10000$ | 题面明文 |
| $dp[i][j]$ | `int dp[105][5005]` | 由 $1..i$ 组成、逆序对恰为 $j$ 的排列数 | `dp[0][0]=1`，余 $0$ | 引理 2 的状态 |
| `mxn`/`mxk` | `constexpr int` | 两维上界（$+5$ 松弛） | $105$/$5005$ | $N\le100$、$K\le4950$ |
| `v` | `i64`（局部） | 转移的中间量（含减法，先 64 位防意外） | — | 引理 3 的右端 |

### 4.2 编号步骤

1. 读入 $N,K$；置 `dp[0][0]=1`（空排列）。
2. 对 $i=1..N$，对 $j=0..K$：
   - 取 $v\gets dp[i-1][j]$；
   - 若 $j>0$：$v\mathrel{+}=dp[i][j-1]$；
   - 若 $j\ge i$：$v\mathrel{-}=dp[i-1][j-i]$；
   - 归一化：`v%=mod; if(v<0)v+=mod;` 再写回 $dp[i][j]=v$。
3. 输出 $dp[N][K]$（即答案为 $0$ 时也正常输出 $0$；$K$ 超过最大逆序对数时自然为 $0$）。

### 4.3 复杂度

- 时间：$O(NK)\le100\times4950\approx 5\times10^{5}$ 次 $O(1)$ 递推。
- 空间：`int dp[105][5005]` $\approx2.1$ MB，远低于 125 MB。
- 实测：最坏 $N=100,K=4950$ 输出 `1`，耗时 **0.0078s**。

### 4.4 关键不变量

1. $dp[i][j]$ 只依赖 $dp[i-1][\cdot]$（上一行）与 $dp[i][j-1]$（同行左邻），故正序枚举 $j$ 时同行左邻已算好。
2. $dp[i][j]$ 恒 $\in[0,\text{mod})$（归一化保证）。
3. $dp[N][K]$ 为真答案模 $10000$ 的结果。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 题面样例回归 | **通过**：$N=5,K=3\to15$ |

## 5. 示例代码

### 5.1 主解：二维 DP + 滑窗差分（与 `appendix/P1521/P1521.cpp` 逐字节一致）

```cpp
//
// 题目：P1521 求逆序对
// https://www.luogu.com.cn/problem/P1521
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mod{10000};         // 题面要求对 10000 取模
constexpr int mxn{105};           // N<=100 (+5 松弛)
constexpr int mxk{5005};          // K <= 100*99/2 = 4950 (+5 松弛)

int n,k;
int dp[mxn][mxk];                 // dp[i][j]=1..i 的排列中逆序对恰为 j 的方案数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>k;
	dp[0][0]=1;                  // 空排列逆序对为 0,方案数 1
	for(int i=1;i<=n;++i)
		for(int j=0;j<=k;++j)
		{
			i64 v=dp[i-1][j];        // 未在末尾制造新逆序对
			if(j>0)
				v+=dp[i][j-1];       // 前缀和滑动:dp[i][j-1]
			if(j>=i)
				v-=dp[i-1][j-i];     // 滑出窗口的旧项
			v%=mod;
			if(v<0)
				v+=mod;
			dp[i][j]=int(v);
		}
	cout<<dp[n][k]<<'\n';
	return 0;
}
```

### 5.2 对照实现：枚举全排列（仅用于小规模对拍，与 `P1521_brute.cpp` 一致）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{5005};

int n,k;
int cnt[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>k;
	vector<int>a(n);
	iota(a.begin(),a.end(),1);
	do
	{
		int inv=0;
		for(int i=0;i<n;++i)
			for(int j=i+1;j<n;++j)
				if(a[i]>a[j])
					++inv;
		if(inv<mxn)
			++cnt[inv];
	}while(next_permutation(a.begin(),a.end()));
	cout<<(k<mxn?cnt[k]%10000:0)<<'\n';
	return 0;
}
```

### 5.3 易错点清单

- **模数写成 $10007$/$10^9+7$** ⇒ 答案整体错误（对拍抓不到，只能读题）。
- **漏掉 $\min(j,i-1)$ 上界** ⇒ 多算不存在的插入位置，计数偏大（引理 1）。
- **减法后忘记补正** ⇒ C++ 负数取模得到负数，输出为负。
- **用一维滚动且方向写反** ⇒ 掩蔽性错误；本解用二维数组规避。
