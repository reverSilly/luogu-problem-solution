# P1838 三子棋I

> 难度：入门 · 标签：模拟

## 1. 重新读题
### 1.1 问题重述（人话版）
九宫格里下三子棋。小 a 永远先手，uim 后手。输入是一串落子位置（格子编号 1 到 9），这盘棋已经结束。问结束时是小 a 赢、uim 赢，还是平局。

格子编号是

$$
\begin{array}{|c|c|c|}\hline
1 & 2 & 3 \\\hline
4 & 5 & 6 \\\hline
7 & 8 & 9 \\\hline
\end{array}
$$

谁先在同一行、同一列或同一条对角线上占满 3 格，谁就赢。输出必须带句点：`xiaoa wins.`、`uim wins.` 或 `drew.`。

### 1.2 关键约束与规模暗示
棋盘只有 9 个格子，一盘棋最多 9 步，而且题面保证输入的是已经结束的棋谱。不需要搜索最优着法，只要按记录重放。

## 2. 思维链（Chain-of-thought）
先把「赢」写成可以检查的条件。三子棋的胜利线一共 8 条：3 行、3 列、2 条对角线，也就是集合

$$
\{1,2,3\},\{4,5,6\},\{7,8,9\},\{1,4,7\},\{2,5,8\},\{3,6,9\},\{1,5,9\},\{3,5,7\}.
$$

**引理 1**：某一手落下之后，只有刚刚落子的那一方有可能在这一手新完成一条胜利线。

证明：设这一手之前双方都还没有胜利线（否则棋局更早已经结束，记录不会走到这一手）。这一手只把自己的一个空位改成己方棋子，对方的棋子集合完全没变。对方若此前没有胜利线，这一手之后仍然没有。己方集合变大，才可能第一次包含某条胜利线。$\square$

**引理 2**：从空盘开始按记录落子，第一次出现「某方拥有一条胜利线」的那一方，就是这盘棋的胜者；若直到记录结束都没有，则是平局。

证明：题面规定每份棋谱都是已经结束的对局，结束方式只有两种：一方先连成 3 个，或下满仍无人连成。由引理 1，胜利线第一次出现时，它一定属于刚刚落子的人，且此时对方还没有胜利线，所以胜者唯一。若全程没有胜利线，按题面这就是平局，应输出 `drew.`。$\square$

因此不能只在最后看终盘：若记录在某人已经三连之后仍继续（随机对拍会造出这种串），终盘上可能两个人都有线，字符串比较会和「先完成者」不一致。标程与暴力都在每一步之后立刻判定。

暴力不用二维棋盘，而用两个位掩码。格子 $p$（$1\le p\le 9$）对应第 $p-1$ 位。一条线被占满当且仅当 `(mask & line) == line`。这和逐格比较三元组是同一条件的两种写法，所以两边答案相同。

## 3. 模式总结（Pattern Summary）
- **explore its property** — 胜负只由 8 条三连线决定，且只可能在刚落子的一方身上新出现。
- **consider easier version** — 棋盘只有 9 格，不必博弈搜索，按记录重放即可。
- **classic problem solution** — 每步后扫描胜利线；位掩码是同一判定的另一实现，用来对拍。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `bd[1..9]` | `int[12]` | 格子归属，1 小 a，2 uim，0 空 | 全局 0 | board |
| `line[8][3]` | 常量 | 8 条胜利线的三个格子 | 题面列出的线 | line |
| `s` | `string` | 落子序列 | 读入 | string |
| `who` | `int` | 当前落子方 | 偶数步 1，奇数步 2 | who |

### 4.2 算法步骤
1. 读入落子串 `s`。
2. 对第 `i` 个字符（从 0 起），把格子 `s[i]-'0'` 标成 `who = i%2==0 ? 1 : 2`。
3. 若 `who` 占满某条 `line`，小 a 输出 `xiaoa wins.`，uim 输出 `uim wins.`，结束。
4. 全部落完仍无人三连，输出 `drew.`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）
时间 $O(|s|)$，空间 $O(1)$。`g++ -O2 -std=c++17 -Wall -Wextra -Werror` 无警告。对拍 196 组（含两份官方样例 `5237649 -> xiaoa wins.`、`539128647 -> drew.`，以及手造的 `142596 -> uim wins.`），标程与位掩码暴力一致，checker 墙钟 2.985s。

## 5. 示例代码
### 5.1 标程（`P1838.cpp`）

```cpp
//
// 题目：P1838 三子棋I
// https://www.luogu.com.cn/problem/P1838
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{12};
constexpr int line[8][3]{
	{1,2,3},{4,5,6},{7,8,9},
	{1,4,7},{2,5,8},{3,6,9},
	{1,5,9},{3,5,7}
};

int bd[mxn];

bool win(int who)
{
	for(int i=0;i<8;++i)
	{
		int a=line[i][0],b=line[i][1],c=line[i][2];
		if(bd[a]==who&&bd[b]==who&&bd[c]==who)
			return true;
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	string s;
	cin>>s;
	for(int i=0;i<(int)s.size();++i)
	{
		int p=s[i]-'0';
		int who=i%2==0?1:2;
		bd[p]=who;
		if(win(who))
		{
			if(who==1)
				cout<<"xiaoa wins.\n";
			else
				cout<<"uim wins.\n";
			return 0;
		}
	}
	cout<<"drew.\n";
	return 0;
}
```
