# P1866 编号

> 难度：普及- · 标签：数学, 递推, NOI 导刊, 排序

## 1. 重新读题
### 1.1 问题重述（人话版）

$N$ 只兔子要拿互不相同的正整数编号。第 $i$ 只只能拿 $[1,M_i]$ 里的整数。求方案数对 $10^9+7$ 取模。如果根本排不出，输出 $0$。

### 1.2 关键约束与规模暗示

$1\le N\le 50$，$1\le M_i\le 1000$。直接回溯是 $\prod M_i$ 级别，大的时候不行。先按 $M$ 排序，答案变成一个长度 $N$ 的连乘，中间任何一项非正就是 $0$。乘积会超过 32 位，用 64 位并每步取模。

## 2. 思维链（Chain-of-thought）

**引理 1（先满足更苛刻的兔子）。** 把兔子按 $M$ 升序重标为 $M_1\le M_2\le\cdots\le M_N$。合法编号的个数等于
$$
\prod_{i=1}^{N}\max(M_i-i+1,\ 0)
$$
再对 $10^9+7$ 取模；其中任一因子为 $0$ 则整个积为 $0$。这里 $i$ 从 $1$ 数。0-based 下第 $i$ 项（$i$ 从 $0$ 起）的因子是 $M-i$。

证明：按这个顺序一只一只选号。轮到第 $i$ 只时，前面 $i-1$ 只已经选了 $i-1$ 个互不相同的正整数，而且它们的上限都不超过 $M_{i-1}\le M_i$，所以这 $i-1$ 个数全部落在 $1..M_i$ 里。第 $i$ 只必须在 $1..M_i$ 里选一个还没被用过的数，剩下的个数恰好是 $M_i-(i-1)$，与前面具体选了哪些无关。若 $M_i-(i-1)\le 0$，连这一步都不可能，后面更不可能，方案数为 $0$。由乘法原理，总方案数是这些步数的乘积。

这个计数没有漏：任意合法分配里，上限更小的兔子拿到的号也一定 $\le$ 自己的 $M$，所以上述顺序能生成全部单射。$\blacksquare$

**交换说明。** 若不排序，先给上限大的兔子选号，它可能拿走一个小编号，后面苛刻的兔子剩下的个数就不再是「上限减已选人数」这么简单。排序后小上限的号全部被包进当前区间，才消掉这种依赖。

## 3. 模式总结（Pattern Summary）

- **sort tight constraints first** — 上限小的兔子先选
- **previous picks lie inside the current limit** — 所以只是少了 $i-1$ 个可选数
- **multiply step by step** — 每步 $M_i-i+1$
- **nonpositive factor means zero** — 出现 $\le 0$ 立刻答案为 $0$
- **mod after each multiply** — 模 $10^9+7$，中间用 64 位

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| --- | --- | --- | --- | --- |
| `n` | `int` | 兔子数 | 读入 | $N\le 50$ |
| `a[55]` | `int` | 每只的上限 | 读入后排序 | $M_i$ |
| `ans` | `i64` | 方案数模 $10^9+7$ | $1$ | 连乘 |
| `mod` | `constexpr int` | $1000000007$ | 常量 | |

### 4.2 算法步骤

1. 读入并升序排序。
2. 对 0-based 下标 $i$，若 `a[i]-i<=0` 则答案为 $0$ 并停止；否则 `ans = ans * (a[i]-i) % mod`。
3. 输出 `ans`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

时间 $O(N\log N)$，空间 $O(N)$。

`g++ -O2 -std=c++17 -Wall -Wextra` 无警告。暴力是逐只兔子回溯枚举没用过的编号，只在 $N\le 7$ 且上限很小的时候跑。对拍含官方样例（双方 `35`）、全是 $1$、上限恰好是 $1..N$ 的排列、以及 $50$ 组随机。结果：

- `57 tests OK`
- 最大数据 $N=50$、$M_i\in[1,1000]$ 随机，标程墙钟 `0.014144s`，输出 `511729904`

## 5. 示例代码
### 5.1 标程（`P1866.cpp`）

```cpp
//
// 题目：P1866 编号
// https://www.luogu.com.cn/problem/P1866
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{55};
constexpr int mod{1000000007};

int n;
int a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	sort(a,a+n);
	i64 ans=1;
	for(int i=0;i<n;++i)
	{
		int ways=a[i]-i;
		if(ways<=0)
		{
			ans=0;
			break;
		}
		ans=ans*ways%mod;
	}
	cout<<ans<<'\n';
	return 0;
}
```
