# P1542 包裹快递

> 标签：模拟 · 二分答案 · 难度：普及/提高-
> 本地题面：`P1542.md`（$0<n\le 2\times10^5$，$x_i\le y_i\le 10^8$，$s_i\le 10^7$，$x_i$ 严格递增，结果保留两位小数）。
> 验证：官方样例 `3 / 1 2 2 / 6 6 2 / 7 8 4 -> 2.00`；400 组随机对拍 std==brute；最坏规模 $n=2\times10^5$ 耗时 $0.089$ s。

## 1. 重新读题

**问题重述（人话版）**

一条**固定顺序**的路线，要依次到达 $n$ 个地点。第 $i$ 个地点的签收时间窗是 $[x_i,y_i]$（相对出发时刻），从第 $i-1$ 个地点到第 $i$ 个地点的路程是 $s_i$（$s_1$ 是从出发点出发到第 $1$ 个地点的路程）。车在 $t=0$ 从出发点出发。规则：

- 到达某地点若**早于** $x_i$，必须**原地等到** $x_i$ 才能签收；若**晚于** $y_i$，则该地点无法按时签收（方案失败）；
- 每段路可任选速度，但**全程任意一段的速度都不许超过一个上限** $v$。

要求：找一个最小的 $v$（"车的最大速度的最小值"），使得**存在**一种行使方案，按时签收全部 $n$ 个地点。输出 $v$，保留两位小数。

> 一句话版本：**二分枚举最大速度 $v$，判定"以速度 $v$ 是否能在各窗口内依次签收全部地点"，取最小可行 $v$**。

**题面里容易漏掉的条款**

1. 「若到达某一个地方的时间**早于**可以签收的时间段，则**必须停留**至可以签收」$\Rightarrow$ 早到是允许的（等待即可），但**等待会把后续到达时刻整体往后推**，这个"等待累积效应"是本题的核心（见 §2.4 失败 1）。
2. 「**不能晚于**签收的时间段」$\Rightarrow$ 到达时刻必须 $\le y_i$。
3. 「保证路线中 $x_i$ **递增**」$\Rightarrow$ 时间窗的起点单调右移，$x$ 是严格递增的正整数（该性质在证明上界时要用）。
4. 「车的**最大速度**越小越好」$\Rightarrow$ 每段速度可不同，只要都不超过 $v$；目标是最小化这个共同上限 $v$。
5. 「结果保留**两位小数**」$\Rightarrow$ 答案是实数，用浮点二分 + `fixed<<setprecision(2)`。

**数据范围与规模感受**

$$0<n\le 2\times10^5,\qquad x_i\le y_i\le 10^8,\qquad s_i\le 10^7 .$$

$n$ 高达 $2\times 10^5$，提示判定过程必须 $O(n)$；而"最小速度"是一个连续量、且越大的速度越容易达标（单调性），因此是典型的**二分答案**：判定 $O(n)$，二分约 $100$ 轮，合计 $O(100n)\approx2\times10^7$，稳过 $1$ s。逐个枚举候选速度、或 $O(n^2)$ 地联合搜索是绝不可行的。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：固定速度后，"动作"是确定的

固定一个上限速度 $v$（$v>0$）后，唯一还剩下、且**不能改慢**的自由度其实几乎没有价值：把某一段开得更慢只会让到达更晚、更危险。所以直觉上"以最大速度 $v$ 开、早到就等"就能得到**每个地点最早可能的到达时刻**。先把这句话严格化。

记 $D_i$ 为"按最大速度 $v$ 行驶、并在早到时等到 $x_i$ 之后离开第 $i$ 个地点"时的**离开时刻**，$D_0=0$（出发点 $t=0$ 出发，无窗口约束）；记 $A_i$ 为到达第 $i$ 个地点的**最早可能时刻**。

**引理 1（可行性 $\iff$ 最早到达不晚于窗口右端）**

对固定 $v$，存在合法方案 $\iff$ 对每个 $i$ 都有 $A_i\le y_i$。

**证明**：

- （必要性）任取一个合法方案：设它离开地点 $i$ 的时刻为 $d_i$（$d_0=0$），第 $i$ 段实际速度为 $u_i\le v$。归纳证明 $d_i\ge D_i$：
  - 基例 $d_0=0=D_0$。
  - 归纳步：到达地点 $i$ 的时刻 $=(d_{i-1}+\frac{s_i}{u_i})$，随后（若早到）等到 $x_i$ 才走，故 $d_i=\max\big(d_{i-1}+\tfrac{s_i}{u_i},\,x_i\big)$。由 $u_i\le v$ 得 $\tfrac{s_i}{u_i}\ge\tfrac{s_i}{v}$，又 $d_{i-1}\ge D_{i-1}$，故 $d_i\ge\max\big(D_{i-1}+\tfrac{s_i}{v},\,x_i\big)=D_i$。✓
  于是该方案到达地点 $i$ 的时刻 $\ge D_{i-1}+\tfrac{s_i}{v}=A_i$。若某 $A_i>y_i$，则任何方案在该点的到达都 $>y_i$，无法按时签收，矛盾。故必 $A_i\le y_i$。
- （充分性）若所有 $A_i\le y_i$：构造方案 = 每段都开速度 $v$，到达地点 $i$ 的时刻恰为 $A_i$；若 $A_i<x_i$ 则等到 $x_i$ 再走（签收时刻 $\max(A_i,x_i)\le y_i$，因为 $x_i\le y_i$ 且 $A_i\le y_i$）。此方案每个地点都在窗口内签收，合法。$\blacksquare$

> 该引理把"是否存在方案"这个 $\Omega(\text{指数})$ 的搜索问题，压缩成"算一条确定的时刻序列并逐点比较"，这是能上二分的前提。

### 2.2 一次归约：把最早到达时刻展开成"某个地点卡住"

递推 $A_i=D_{i-1}+\frac{s_i}{v},\,D_i=\max(A_i,x_i)$ 直接模拟是 $O(n)$，但为了**证明**与**求闭式**，把它展开：

记 $S_i=\sum_{k=1}^{i}s_k$（前 $i$ 段路程和，$S_0=0$），并约定 $x_0=0$。

**引理 2（最早到达时刻的展开式）**

$$A_i=\max_{0\le j<i}\Big(x_j+\frac{S_i-S_j}{v}\Big).$$

**证明**（对 $i$ 归纳）：

- **基例** $i=1$：$A_1=D_0+\frac{s_1}{v}=\frac{S_1-S_0}{v}=x_0+\frac{S_1-S_0}{v}$，而右边只有 $j=0$ 一项，相等。✓
- **归纳步**：设 $A_{i-1}=\max_{0\le j<i-1}(x_j+\frac{S_{i-1}-S_j}{v})$。则
  $$D_{i-1}=\max(A_{i-1},x_{i-1})=\max_{0\le j\le i-1}\Big(x_j+\frac{S_{i-1}-S_j}{v}\Big),$$
  这里恰好把 $x_{i-1}$ 写成 $x_{i-1}+\frac{S_{i-1}-S_{i-1}}{v}$ 对应的 $j=i-1$ 项。于是
  $$A_i=D_{i-1}+\frac{s_i}{v}=\max_{0\le j\le i-1}\Big(x_j+\frac{S_{i-1}-S_j+s_i}{v}\Big)=\max_{0\le j\le i-1}\Big(x_j+\frac{S_i-S_j}{v}\Big).\ \blacksquare$$

> 直觉：**$A_i$ 就是"到底在哪一个地点把时刻卡住了"的结果**——如果 $j$ 处（$x_j$ 或出发时刻 $0$）之后一直以最大速度行驶到 $i$，到达时刻就是 $x_j+\frac{S_i-S_j}{v}$；取所有 $j$ 的最大值，就是被最"卡"的那一站决定的最早到达时刻。

### 2.3 关键引理：答案的闭式与单调性

**引理 3（可行速度的下界逐一化为比率，最小值就是答案）**

令 $V^\*=\displaystyle\max_{0\le j<i\le n}\frac{S_i-S_j}{y_i-x_j}$（约定 $x_0=0,S_0=0$）。则：
1. 对所有 $i$，$y_i-x_j>0$（$j<i$），故 $V^\*>0$ 有定义；
2. 存在合法方案 $\iff v\ge V^\*$；
3. 故最小可行速度恰为 $V^\*$，即题目答案。

**证明**：

- (1) 对 $j<i$：$x_j<x_i$（$x$ 严格递增）且 $x_i\le y_i$，故 $x_j<x_i\le y_i\Rightarrow y_i-x_j>0$。特别地 $j=0$ 时 $y_i-x_0=y_i\ge x_i>0$。✓
- (2) 由引理 1，可行 $\iff$ 对所有 $i$ 有 $A_i\le y_i$。由引理 2，
  $$A_i\le y_i\iff \forall j<i:\ x_j+\frac{S_i-S_j}{v}\le y_i\iff \forall j<i:\ \frac{S_i-S_j}{v}\le y_i-x_j.$$
  由于 $y_i-x_j>0$，两边同号相乘（除以正数不改号）得等价于
  $$\forall j<i:\ v\ge\frac{S_i-S_j}{y_i-x_j}.$$
  对所有 $i$ 成立 $\iff v\ge\max_{j<i,i}\frac{S_i-S_j}{y_i-x_j}=V^\*$。✓ 这同时说明可行集合恰为 $[V^\*,\infty)$，**单调**，故可二分。
- (3) 可行集合 $[V^\*,\infty)$ 的最小元素就是 $V^\*$。$\blacksquare$

> **这一步是本题最漂亮的地方**：它把"二分 + 模拟"这一算法做法，背后的答案**精确**地写成了 $O(n^2)$ 个比率的最大值。这个闭式既是正确性证明，也直接充当**暴力基准**（§5.2）。

### 2.4 二分上界与失败思路

**引理 4（二分上界 $V^\*\le 10^7$）**

在本题数据范围（$s_i\le10^7$，$x_i$ 为严格递增正整数）下，$V^\*\le 10^7$。

**证明**：对任意一对 $j<i$：

- 分子 $S_i-S_j=\sum_{k=j+1}^{i}s_k\le(i-j)\cdot10^7$。
- 分母 $y_i-x_j\ge x_i-x_j$。由于 $x$ 是**严格递增的正整数**，$x_i-x_j\ge i-j$（相邻至少差 $1$）。$j=0$ 时 $y_i-x_0=y_i\ge x_i\ge i$（同样因 $x_i\ge x_1+(i-1)\ge i$）。
- 于是 $\dfrac{S_i-S_j}{y_i-x_j}\le\dfrac{(i-j)\cdot10^7}{i-j}=10^7$（$j=0$ 时 $\le\frac{i\cdot10^7}{i}=10^7$）。取遍所有对得 $V^\*\le10^7$。$\blacksquare$

所以二分区间取 $[0,2\times10^7]$（宽松包裹）即可。

**失败 1：判定时"忽略等待"，直接累加。** 若判定写成"$t{+}{=}\frac{s_i}{v}$，只比 $y_i$"，就漏掉了"早到要等到 $x_i$ 才能走"导致后续被整体推迟这件事，得到的是 $S_i/v\le y_i$ 这个**过宽**的条件，答案会偏小。

> **反例就是官方样例本身**：`3 / 1 2 2 / 6 6 2 / 7 8 4`。
> - 忽略等待：条件退化为 $\max_i \frac{S_i}{y_i}=\frac{8}{8}=1.00$，输出 **1.00**。
> - 正确的闭式：还需 $j=2,i=3$ 一项 $\frac{S_3-S_2}{y_3-x_2}=\frac{4}{8-6}=2.00$，答案 **2.00**。
>
> 差的这一项正来自"在第 2 个地点被 $x_2=6$ 卡住后，只剩 $10-6=2$ 的时间要赶 $4$ 的路程"。$\Rightarrow$ **判定必须带上 `t=max(t,x_i)` 的等待步骤**（引理 1 的 $D_i$）。

**失败 2：二分上界取太小（如 $10^6$）。** $V^\*$ 可达 $10^7$ 量级（见引理 4 的紧界构造），上界取小会把正确答案截断，直接判错。取 $2\times10^7$。

**失败 3：二分次数太少、精度不够。** 需要用两位小数，二分区间长 $2\times10^7$，$40$ 轮的区间宽 $2\times10^7/2^{40}\approx2\times10^{-5}$，勉强；取 $100$ 轮可把区间压到远小于 $10^{-3}$，绝对安全。干脆固定 $100$ 轮循环。

**失败 4：半分位舍入不稳定（浮点平局）。** 当精确答案恰为 $x.xx5$（半分位）时，二分从下方逼近得到的浮点数可能比精确值小一个 ULP，`printf("%.2f")` 就会舍入到偏低的那一档（如精确 $5.275$ 会打印成 $5.27$ 而非 $5.28$）。**处理**：对最终结果统一加一个远小于最小分度的平移量（如 $10^{-9}$）再做两位小数格式化，使"恰好落界"的平局稳定地向上取（§4.5 记录了实测）。

### 2.5 越界与状态体检

| 量 | 范围 | 上界 | 说明 |
|---|---|---|---|
| $x_i,y_i$ | $1\le\cdot\le10^8$ | $10^8$ | `int` 足够 |
| $s_i$ | $\le10^7$ | $10^7$ | `int` 足够 |
| $S_i$（前缀和，仅暴力用） | $\le n\cdot10^7$ | $2\times10^{12}$ | 需 `i64`（仅暴力用 $S$） |
| 判定中的累积时刻 $t$ | 最坏可达 $\approx10^8$ 及以上 | — | 用 `double`，须注意累计误差 |
| 答案 $V^\*$ | $\le10^7$ | $10^7$ | `double` 足够（$10^7$ 处 ULP $\approx2\times10^{-9}\ll 0.005$） |

结论：主解全程 `double`；暴力里的前缀和 `S` 用 `i64`。要防的是**判定漏掉等待**（失败 1）与**精度/舍入**（失败 3、4）。

## 3. 模式总结（Pattern Summary）

**模式名：二分答案 + 单调判定；判定背后是一个可展开的闭式。**

按真实思考顺序排列的可迁移标签：

- **explore its property** — 固定速度上限后澄清"越慢只会越晚"这一单调直觉，并用引理 1 严格证明"以最大速度行驶 + 早到等待"给出每个地点的最早到达。
- **explore its property（第二次）** — 用引理 2 把最早到达时刻展开成 $A_i=\max_j(x_j+\frac{S_i-S_j}{v})$，看清"是谁把时刻卡住"。
- **reduce to easier problem** — 用引理 3 把"存在方案"的判定，逐项化为对 $v$ 的下界不等式，得到一个**闭式** $\max\frac{S_i-S_j}{y_i-x_j}$。
- **prove monotonicity** — 由闭式立刻得到可行集恰为 $[V^\*,\infty)$，单调性成立 $\Rightarrow$ 可二分（引理 3 第 2 点）。
- **classic problem solution** — 二分答案 $v$，判定用 $O(n)$ 的引理 1 模拟（`t=max(t,x_i)` 不可省）。
- **bound the search range** — 用引理 4 把二分上界压到 $10^7$ 量级，避免取飞或截断。
- **stabilize float rounding** — 结果加 $10^{-9}$ 再两位小数，处理半分位平局（失败 4）。

**同族题 / 同源题**：

- **一类"最小化最大值"问题**（P1182 数列分段、P2678 跳石头、P1577 切绳子）：都是"答案单调 $\Rightarrow$ 二分 + $O(n)$ 判定"。
- **一类"时间窗调度/最早到达"问题**（会议安排、带 release 时刻的贪心）：判定式 $t=\max(t,x_i)+\cdots$ 是其通用骨架。
- **一分式闭式解**：若判定条件能写成 $v\ge$ 若干比率，则可直接 $O(n^2)$ 枚举得暴力基准（引理 3）。

**一句话记忆**：**"最小最大速度"= 二分速度 + 判定"t+=s/v，早到等到 x_i"；判定里千万别漏掉等待。**

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `int`（全局 `n`） | 地点数 | 读入 | 题面 |
| `x[i]`,`y[i]` | `int[mxn]` | 第 $i$ 个地点的签收窗口 $[x_i,y_i]$（读入即 0-based） | 读入 | 题面 |
| `s[i]` | `int[mxn]` | 从第 $i-1$ 个地点到第 $i$ 个地点的路程（0-based） | 读入 | 题面 |
| $v$ | `double`（判定参数） | 试用的最大速度 | 二分中点 | 判定函数的入参 |
| `t` | `double`（`ok` 内局部） | 当前"刚离开上一地点"的时刻（即 $D_{i-1}$） | $0$ | 引理 1 的递推 |
| `lo`,`hi` | `double` | 二分下/上界；始终有 $hi\ge V^\*$、$lo<V^\*$ | $lo=0,hi=2\times10^7$ | 引理 4 定的界 |

（暴力另加符号）

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `S[i]` | `i64[mxn]` | 前 $i$ 段路程和，$S_0=0$ | 递推 `S[i]=S[i-1]+s[i]` | 引理 2/3 的分子 |
| `best` | `double` | $\max_{j<i}\frac{S_i-S_j}{y_i-x_j}$ | $0$ | 引理 3 的闭式 |

### 4.2 编号步骤

1. 读入 $n$；读入 $n$ 行 $(x_i,y_i,s_i)$（0-based）。
2. `lo=0, hi=2e7;`（引理 4）。
3. 重复 $100$ 轮：
   - 3.1 `mid=(lo+hi)/2;`
   - 3.2 判定 `ok(mid)`：`t=0`；对 $i=0..n-1$：`t+=s[i]/mid;`（到达 $A_i$）；若 `t>y[i]` 返回 `false`；否则 `if(t<x[i]) t=x[i];`（等到窗口）。
   - 3.3 可行则 `hi=mid`，否则 `lo=mid`。
4. 输出 `fixed<<setprecision(2)<<hi+1e-9`（引理 3 得 `hi` 逼近 $V^\*$；§2.4 失败 4 的稳定平移）。

### 4.3 复杂度

- 时间：判定 $O(n)$，二分 $100$ 轮 $\Rightarrow O(100n)\approx2\times10^7$ 次浮点运算。
- 空间：三个 `int[mxn]` 约 $2.4$ MB。
- 实测（见 §4.5）：$n=2\times10^5$ 最坏实例 $0.089$ s。

### 4.4 关键不变量

1. 二分过程中恒有 `ok(hi)==true`、`ok(lo)==false`（初值由引理 4 保证 `hi` 可行）。
2. 判定中 `t` 恰为 $D_{i-1}$（已含等待），`t+=s[i]/v` 恰为 $A_i$。
3. 答案为 $V^\*=\inf\{v:\ ok(v)\}$，二分把它夹在最终 $[lo,hi]$ 内。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 官方样例回归 | **通过**：`3 / 1 2 2 / 6 6 2 / 7 8 4` $\to 2.00$ |
| 随机数据对拍 | **通过**：400 组随机（$n\in[1,20]$，$x$ 严格递增、$y\ge x$）二分版与 $O(n^2)$ 闭式版输出**逐字节一致** |
| 边界用例 | **通过**：$n=1,x=y=s=1\to1.00$；含一次「精确值 $5.275$ 的半分位」用例（修复舍弃入前会不一致，$5.27$ vs $5.28$，见下） |
| 最坏规模计时 | $n=2\times10^5$（$x_i=i,y_i=10^8,s_i=10^7$）$\to20000.00$，耗时 $0.089$ s |
| 坑点实录 | 对拍中出现精确答案 $633/120=5.275$（半分位）：标准二分从下方逼近得 `5.274999…` 打印成 $5.27$，而精确闭式得 $5.28$。已通过「两版结果统一 $+10^{-9}$ 再格式化」消除该平局；判定也从带 $10^{-6}$ 松弛改为严格 `t>y[i]` 以减少阈值漂移 |
| 残余风险 | 若判定漏写 `t=max(t,x_i)`，样例即会退化成 $1.00$（§2.4 失败 1）；若二分上界取小于 $10^7$，会截断答案 |

## 5. 示例代码

### 5.1 主解：二分答案 + 最早到达判定

```cpp
//
// 题目：P1542 包裹快递
// https://www.luogu.com.cn/problem/P1542
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{200005};        // n<=2e5 (+5 松弛)

int n;
int x[mxn],y[mxn],s[mxn];         // 签收区间 [x_i,y_i] 与第 i 段距离 s_i

bool ok(double v)                 // 以最大速度 v 能否全部准时签收
{
	double t=0;                   // 当前(刚离开上一地点)的时刻
	for(int i=0;i<n;++i)
	{
		t+=s[i]/v;                // 全程用最大速度 => 到达第 i 个地点最早时刻
		if(t>y[i])                // 晚于最晚签收时刻: 不可行 (严格比较, 见验证小结)
			return false;
		if(t<x[i])                // 早到: 原地停留至可以签收
			t=x[i];
	}
	return true;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>x[i]>>y[i]>>s[i];

	double lo=0,hi=2e7;           // 答案上界 1e7 (见题解引理), 取 2e7 宽松包裹
	for(int it=0;it<100;++it)     // 100 轮二分, 精度远优于两位小数
	{
		double mid=(lo+hi)/2;
		if(ok(mid))
			hi=mid;
		else
			lo=mid;
	}
	cout<<fixed<<setprecision(2)<<hi+1e-9<<'\n';   // 1e-9 远小于 0.005, 仅用于稳定半分位舍入
	return 0;
}
```

**代码结构对照**：`ok(v)` 就是引理 1 的判定（`t` 依次代表 $D_{i-1},A_i$，`if(t<x[i])t=x[i]` 是不可省的等待步）；`lo/hi` 的初值来自引理 4；结尾 $+10^{-9}$ 是 §2.4 失败 4 的舍入稳定项。答案即引理 3 的 $V^\*$。

### 5.2 对照实现：$O(n^2)$ 闭式枚举（仅用于对拍）

```cpp
// 暴力基准:直接枚举"到底是哪个签收点把时刻卡住"的 O(n^2) 精确公式
// 与二分版相互独立:这里完全不做模拟,只按 (S_i-S_j)/(y_i-x_j) 取最大
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{200005};

int n;
i64 x[mxn],y[mxn],s[mxn],S[mxn];  // S[i]=前 i 段距离和, x[0]=0,S[0]=0

int main()
{
	if(!(cin>>n))
		return 0;
	for(int i=1;i<=n;++i)
		cin>>x[i]>>y[i]>>s[i];

	S[0]=0;x[0]=0;
	for(int i=1;i<=n;++i)
		S[i]=S[i-1]+s[i];

	double best=0;                    // v 越大越容易达标, 取所有下界的最大值
	for(int i=1;i<=n;++i)
		for(int j=0;j<i;++j)          // j 为"上一个卡住时刻"的地点(0 表示出发地)
		{
			double r=(double)(S[i]-S[j])/(double)(y[i]-x[j]);
			if(r>best)
				best=r;
		}
	printf("%.2f\n",best+1e-9);       // 与标程同样加 1e-9, 保证半分位舍入一致
	return 0;
}
```

两版**输出必须逐字节相同**（已用 $400$ 组随机数据 + 样例 + 边界确认）。这一版完全不做二分、不做模拟，直接按引理 3 的闭式 $\max_{j<i}\frac{S_i-S_j}{y_i-x_j}$ 枚举所有 $O(n^2)$ 对，因而与二分版在方法上完全独立：若判定的递推、界或舍入有 bug，会立刻暴露。代价是 $O(n^2)$，仅小 $n$ 可跑。

### 5.3 易错点清单

- **判定漏掉 `t=max(t,x_i)`（等待步）**：条件退化为 $S_i/v\le y_i$，样例即出错（$1.00$ vs $2.00$）。
- **二分上界取太小**：$V^\*$ 可达 $10^7$ 量级，必须取 $2\times10^7$。
- **二分轮数太少**：至少数十轮；直接用 $100$ 轮最省心。
- **半分位舍入**：精确答案落 $x.xx5$ 时易偏小，统一 $+10^{-9}$ 后格式化。
- **`printf("%.2f\n")` 与 `cout<<fixed<<setprecision(2)`** 两种均可，但**必须**保留两位小数（题面要求）。
- **前缀和溢出**：只在暴力解里用到 $S_i$（可达 $2\times10^{12}$），须用 `i64`；主解不用 $S$。
