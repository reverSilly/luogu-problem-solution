# P1602 Sramoc 问题

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

定义 $\text{Sramoc}(k,m)$ 为：**十进制数字只允许取 $0,1,\dots,k-1$**、且能被 $m$ 整除的所有**正整数**中最小的一个。
给定 $k,m$，输出这个数。

注意这里 $k$ 限制的是"十进制表示中允许出现的数字种类"，不是进制。例如 $\text{Sramoc}(2,7)=1001$，因为 $1001$ 只含 $0,1$ 且 $1001=7\times143$。

### 输入输出格式

- **输入格式**：一行两个整数 $k,m$。
- **输出格式**：一行，即最小的那个数（可能长达上千位，只能按字符串输出）。
- **数据规模**：$2 \le k \le 10$，$1 \le m \le 1000$。

### 关键约束分析

1. **答案的位数可能很大**：$m \le 1000$ 意味着答案最多约 $m$ 位，$10^{1000}$ 量级，`long long`、`__int128` 全部失效，必须"边搜边拼字符串"。
2. **判定的是整除性**：只有余数影响后续的整除性，因此状态可以压缩成 $m$ 种余数，而不需要记住整个数。
3. **"最小"有两层含义**：先比位数（短的更小），位数相同再比字典序。这正好与 BFS 的分层顺序一致。
4. **首位不能是 $0$**：正整数不允许前导零，所以初始状态只能放 $1\dots k-1$；但扩展时可以放 $0$。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：暴力能做什么，卡在哪

最直接的暴力是"从 $1$ 开始逐个检查，数字每一位都 $<k$ 且能被 $m$ 整除"。它错在枚举顺序：
最小的解可能有上千位，逐个枚举根本走不到。

换一个暴力：按**长度**枚举所有合法数字（第 $L$ 层有 $(k-1)k^{L-1}$ 个），逐层检查。这样可以保证"先短后长"，
但第 $L$ 层的规模指数增长，$L$ 稍大就跑不动。卡点在于：**大量不同的数字其实"对 $m$ 而言完全一样"**。

### 第二步：把"数字"压成"余数"

**引理 1（追加一位的余数转移）**：若 $x \bmod m = r$，则在 $x$ 末尾追加数字 $d$ 得到的 $x'=10x+d$ 满足 $x' \bmod m = (10r+d)\bmod m$。

*证明*：$10x+d = 10(qm+r)+d = m(10q) + (10r+d)$，故 $x' \equiv 10r+d \pmod m$；再取模即得。$\square$

引理 1 说明：**要继续往下扩展，只需要知道当前余数**，不需要知道前面具体写了什么。于是把"余数"作为状态，
状态数只有 $m \le 1000$ 个，图是"每个状态 $r$ 向 $(10r+d)\bmod m$ 连 $k$ 条边"。

### 第三步：为什么 BFS 的第一次到达就是答案

在这张余数图上跑 BFS：第 $0$ 层是起点（空串，余数 $0$，但空串不是正整数，所以实际从第 $1$ 层开始），
第 $1$ 层是数字 $1,2,\dots,k-1$，第 $L$ 层是所有长度为 $L$ 的合法数字（按字典序）。

**引理 2（队列顺序 = 长度优先、字典序次之）**：按"初始按 $1,2,\dots,k-1$ 入队、每次弹出时按 $0,1,\dots,k-1$ 的顺序扩展"的规则做 BFS，
队列中元素的出队顺序恰好是它们对应数字按（长度，字典序）的全序。

*证明*：对层数归纳。第 $1$ 层入队顺序是 $1,2,\dots,k-1$，即字典序，成立。
设第 $L$ 层出队顺序为字典序 $x_1<x_2<\dots$，则第 $L+1$ 层按 $x_1 0, x_1 1,\dots,x_1(k-1), x_2 0,\dots$ 的顺序入队。
由于所有长度为 $L+1$ 的串都是"某个长度为 $L$ 的串 + 一位"，而字典序比较先比前 $L$ 位、再比第 $L+1$ 位，
故这个入队顺序正是长度为 $L+1$ 的串的字典序。归纳成立。$\square$

**引理 3（同余剪枝安全）**：若数字 $x$ 与 $y$ 满足 $x\equiv y \pmod m$ 且 $y$ 在（长度，字典序）意义下不优于 $x$，
则 $y$ 的任何延伸都不优于 $x$ 的对应延伸，因此 $y$ 被访问后可以不再扩展。

*证明*：设对 $y$ 追加同一个后缀 $w$（长度 $t$），得到 $y'=y\cdot10^t+w$，对 $x$ 做同样操作得 $x'=x\cdot10^t+w$。
由 $x\equiv y$ 得 $x'\equiv y'\pmod m$。又长度 $\text{len}(y')=\text{len}(y)+t \ge \text{len}(x)+t=\text{len}(x')$；
若长度相同，则 $y$ 与 $x$ 等长且 $x$ 字典序更小，前缀更小意味着 $x'$ 字典序更小。故 $y'$ 永远不可能是更优解。$\square$

由引理 3，每个余数只需保留"第一次到达"的那一个数，这正是 BFS 的 `vis` 数组。

### 第四步：答案一定存在，而且不会太长

**引理 4（存在性与长度上界）**：答案存在，且位数不超过 $m$。

*证明*：存在性：考虑 $m+1$ 个全由数字 $1$ 组成的数 $1,11,111,\dots,\underbrace{11\cdots1}_{m+1}$。
它们模 $m$ 的余数只有 $m$ 种取值，由鸽巢原理必有两个同余，
设为 $A$（$j$ 位）与 $B$（$i$ 位，$i<j$），则 $A-B=\underbrace{11\cdots1}_{j-i}\cdot 10^{i}$ 是 $m$ 的正倍数，
且它的十进制表示由若干个 $1$ 与若干个 $0$ 组成，数字全部 $<k$（$k\ge2$），故合法。
长度上界：余数图只有 $m$ 个结点，BFS 的最短路最多经过 $m-1$ 条边，故到达余数 $0$ 的数位数 $\le m$。$\square$

**定理**：BFS 第一次把余数 $0$ 入队时，沿前驱回溯拼出的数字就是 $\text{Sramoc}(k,m)$。

*证明*：由引理 2，队列顺序与（长度，字典序）一致，故第一次到达余数 $0$ 的数在所有"能被 $m$ 整除的合法数"中（长度，字典序）最小，
即数值最小；由引理 3，剪枝不会丢掉任何更优解；由引理 4 该数一定在 $m$ 层内出现。$\square$

### 第五步：怎么把数字"还原"出来

BFS 只记余数，但答案是具体数字。做法是给每个余数记两个值：`pre[r]`（它是从哪个余数扩展来的）与 `pd[r]`（扩展时追加的数字）。
到达余数 $0$ 后沿 `pre` 一路回溯即得数字的逆序，反转后输出。首位标记 `pre=-1`。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 追加一位只影响余数，于是"数"可压缩成"模 $m$ 的余数"。
- `consider easier version` — 先按长度分层枚举所有合法数（必然超时），明确卡点是"指数级的重复状态"。
- `classic problem solution` — 以余数为结点建图，BFS 求最短路，$\mathcal{O}(mk)$。
- `prove bfs order` — 证明队列顺序就是（长度，字典序），才能保证"第一次到达即最小"。
- `defer reconstruction` — 只存前驱余数与末位数字，最后回溯拼出答案，避免在队列里搬运整串数字。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $k$ | `k` | 允许出现的数字上界，可用数字为 $0..k-1$ |
| $m$ | `m` | 模数，状态数 |
| $r$ | `r` | 当前状态（余数），$0 \le r < m$ |
| $d$ | `d` | 本次追加的数字，$0 \le d < k$ |
| $pre_r$ | `pre[r]` | 余数 $r$ 的前驱余数；`-1` 表示 $r$ 由首位数字直接得到 |
| $pd_r$ | `pd[r]` | 生成余数 $r$ 时在末尾追加的数字（用于回溯） |
| $vis_r$ | `vis[r]` | 余数 $r$ 是否已被访问（BFS 剪枝标记），全局默认 `false` |
| $Q$ | `q[]`, `ql`, `qr` | 手写队列：`q[ql..qr-1]` 为队列内容，`ql` 为队头、`qr` 为队尾 |
| — | `nr` | 新余数 $(r\cdot10+d)\bmod m$ |
| — | `ans` | 回溯得到的答案串（此时是逆序，最后统一反转） |

### 算法步骤

1. 读入 $k,m$。
2. 初始化：对 $d=1..k-1$（首位非零），令 $r=d\bmod m$；若 `vis[r]` 为假则标记、`pre[r]=-1`、`pd[r]=d`、入队。
3. BFS：不断弹出队头 $r$；若 $r=0$ 立即停止（此时回溯即为答案）。否则对 $d=0..k-1$ 计算 `nr`，未被访问则标记、记录前驱与数字、入队。
4. 从余数 $0$ 沿 `pre` 回溯，把 `pd` 依次追加到 `ans`，反转后输出。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}(mk)$。每个余数最多入队一次，出队时扩展 $k$ 个数字；$m\le1000,k\le10$，约 $10^4$ 次转移。回溯 $\mathcal{O}(m)$。
- **空间复杂度**：$\mathcal{O}(m)$，三组长度 $m+5$ 的数组与一个队列；答案串长度 $\le m$。

### 正确性验证

引理 1 保证"只记余数"是充分的；引理 2 保证 BFS 顺序与数值大小的次序一致（先长度后字典序）；
引理 3 保证同余剪枝不丢最优解；引理 4 保证答案存在且规模可控；定理给出整体正确性。
数值范围：所有运算只涉及 $r<1000$ 与 $r\cdot10+d<10000$，`int` 足够；答案用 `string`，不存在溢出。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1602 Sramoc 问题
// https://www.luogu.com.cn/problem/P1602
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};          // m<=1000, 余数状态数 (+5 松弛)

int k,m;
int pre[mxn],pd[mxn];             // 余数 r 的前驱余数 / 末位数字
bool vis[mxn];
int q[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>k>>m;

	int ql=0,qr=0;
	for(int d=1;d<k;++d)          // 首位不能是 0
	{
		int r=d%m;
		if(vis[r])
			continue;
		vis[r]=true;
		pre[r]=-1;                // -1 表示这是首位
		pd[r]=d;
		q[qr++]=r;
	}

	while(ql<qr)
	{
		int r=q[ql++];
		if(r==0)
			break;                // 队首首次出现 0 余数即最短且字典序最小
		for(int d=0;d<k;++d)
		{
			int nr=(r*10+d)%m;
			if(vis[nr])
				continue;
			vis[nr]=true;
			pre[nr]=r;
			pd[nr]=d;
			q[qr++]=nr;
		}
	}

	string ans;
	for(int r=0;r!=-1;r=pre[r])   // 沿前驱回溯出整个数字
		ans+=char('0'+pd[r]);
	reverse(ans.begin(),ans.end());
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **首位放 $0$**：若初始把 $d=0$ 入队，会得到带前导零的"更短"答案，输出非法。
2. **用整数存答案**：答案可达 $m$ 位，必须 `string` + 回溯。
3. **忘记"每个余数只入队一次"**：不加 `vis` 会退化成指数级枚举。
4. **`m=1` 的特判**：此时任何数都被整除，答案是 `1`（首位最小的合法数字），代码中由 $d=1$ 直接得到，无需特判，但若首位从 $0$ 开始就会错。
5. **在同一余数的多个前驱里随便挑**：必须保留"第一次到达"，后续到达的（更长或字典序更大）不能覆盖 `pre`。
