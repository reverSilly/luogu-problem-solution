# P1609 最小回文数

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给定一个十进制正整数 $N$（无前导零，$N<10^{100}$），求**大于** $N$ 的最小回文数 $P$。
回文数指正着读、反着读相同的数，例如 $121,44,3$ 是回文数，而 $175,36$ 不是。

### 输入输出格式

- **输入格式**：一行一个正整数 $N$（$100$ 位以内，无前导零）。
- **输出格式**：一行，最小的满足 $P>N$ 的回文数。
- **数据规模**：$N<10^{100}$，即位数 $L\le100$；$50\%$ 数据 $N<10^9$。

### 关键约束分析

1. $L$ 最大 $100$，远超 `unsigned long long`（约 $1.8\times10^{19}$），必须**按字符串处理**，也就是手写"加一进位"。
2. 严格大于：$N$ 本身就是回文时（如 $121$），答案不能是它自己，必须是下一个（$131$）。
3. 位数的变化：$N=99\dots9$ 时答案比 $N$ 多一位（$999\to1001$）；其它情况答案与 $N$ 位数相同。
4. 不能忽略"最小的那类回文"：$N=9$ 时答案是 $11$ 而不是 $9$ 或 $10$。
5. 构造候选后要**做一次比较**：镜像出来的数可能恰好小于等于 $N$（如 $123\to121$），此时必须把左半段加一再镜像。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：从"枚举"到"构造"

最朴素的做法是从 $N+1$ 开始逐个试，判断是否回文。$L=100$ 时下一个回文可能离 $N$ 有 $10^{50}$ 那么远，暴力彻底不可行。

但"回文"这个约束非常强：一个 $L$ 位回文**完全由它的左半段决定**。这提示我们不去搜索数字，而是直接构造左半段。

### 第二步：回文与其左半段的对应

**引理 1（一一对应）**：设 $L$ 位数字串的左半段为前 $h=\lceil L/2\rceil$ 位（记为 $h$），定义
$$M(h)=\begin{cases}h+\operatorname{rev}(h),&L\text{ 为偶数}\\[2pt] h+\operatorname{rev}(h[0..h-2]),&L\text{ 为奇数}\end{cases}$$
其中 $\operatorname{rev}$ 表示反转。则 $M$ 是"$L$ 位左半段"到"$L$ 位回文"的双射（左半段首位非 $0$）。

*证明*：设 $P$ 是 $L$ 位回文，则对任意 $0\le j<L$ 有 $P[j]=P[L-1-j]$，所以 $P$ 由前 $\lceil L/2\rceil$ 位唯一确定，且把前 $\lceil L/2\rceil$ 位按上式镜像回去恰好还原 $P$（偶数长度时左右两半等长，直接反接；奇数长度时中间那位自成镜像，不能重复计入）。反之任一非零首位的 $h$ 按上式生成的串满足 $P[j]=P[L-1-j]$，是回文。两个方向互逆，故为双射。$\square$

### 第三步：$M$ 保序

**引理 2（保序性）**：对两个等长（长度都为 $\lceil L/2\rceil$）的左半段 $h_1<h_2$（字典序），有 $M(h_1)<M(h_2)$。

*证明*：设首个不同位置为 $p$，则 $h_1[p]<h_2[p]$，而 $M(h)$ 的前 $\lceil L/2\rceil$ 位就是 $h$ 本身，于是 $M(h_1)$ 与 $M(h_2)$ 的首个不同位置也是 $p$，且 $M(h_1)[p]<M(h_2)[p]$。等长数字串的字典序等于数值序，故 $M(h_1)<M(h_2)$。$\square$

于是"最小的 $L$ 位回文"就是 $M(10^{h-1})$，"左半段 $\ge h$ 的最小 $L$ 位回文"就是 $M(h)$。

### 第四步：三种情况

记 $h$ 为 $N$ 的左半段，$t=M(h)$。

**引理 3（构造的完备性）**：设 $N$ 不全为 $9$。
1. 若 $t>N$，则答案是 $t$；
2. 若 $t\le N$，则答案是 $M(h+1)$。

*证明*：
先看"$L$ 位回文"这一候选集合。由引理 1，任一 $L$ 位回文可写成 $M(h')$。
- 若 $h'<h$：因为 $N$ 的前 $\lceil L/2\rceil$ 位恰为 $h$，$M(h')$ 与 $N$ 的首个不同位置也在这个前缀内且更小，故 $M(h')<N$，不是答案。
- 若 $h'=h$：候选是 $t$（唯一）。
- 若 $h'>h$：由引理 2，候选 $>t$，其中最小的是 $M(h+1)$。

情况 1：$t>N$ 时，$t$ 是"左半段 $\ge h$"的最小回文，而左半段 $<h$ 的都 $<N$，故 $t$ 就是最小答案。
情况 2：$t\le N$ 时，$t$ 不满足 $>N$，唯一可能更小的一类（$h'<h$）也全都 $<N$，故答案只能是 $h'>h$ 中最小的 $M(h+1)$。
至于 $M(h+1)$ 一定是 $L$ 位：$N$ 不全为 $9$ 时，$h$ 全为 $9$ 会推出 $t=99\dots9\ge N$，与 $t\le N$ 且 $N$ 不全为 $9$ 矛盾，故 $h$ 不全为 $9$，$h+1$ 不发生位数变化。$\square$

**引理 4（全 $9$ 的情形）**：若 $N=99\dots9$（$L$ 位），则答案是 $10^L+1$，即 `1` + $(L-1)$ 个 `0` + `1`。

*证明*：任何 $>N$ 的数至少 $L$ 位；$L$ 位且回文的数最大就是 $99\dots9=N$ 本身，故答案至少 $L+1$ 位。$L+1$ 位回文的最小者是 $10^L+1$（首位只能 $\ge1$，取 $1$ 且其它位取 $0$ 得到回文 $10\dots01$）。$\square$

### 第五步：比较与进位

- 等长数字串的字典序 $=$ 数值序，所以 `t > s` 可以直接用 `std::string` 的比较。
- $h+1$ 用普通的字符串加一：从末位开始，遇到 `9` 变 `0` 继续左移，遇到非 `9` 加一并停止。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 回文数完全由左半段决定，问题从"搜索数字"变成"确定左半段"。
- `consider easier version` — 先解决固定位数 $L$ 的最小回文：它必然是 $10^{L-1}$ 的镜像 $M(10^{\lceil L/2\rceil-1})$。
- `reduce to easier problem` — 把"大于 $N$ 的最小回文"归约为"左半段等于 $h$ 或 $h+1$ 的两个候选"。
- `classify by cases` — 分"$M(h)>N$ / $M(h)\le N$ / 全 $9$"三类，第三类是唯一可能进位到更多位数的情况。
- `big integer by hand` — 位数到 $100$，用字符串模拟加一与镜像，避免高精度库。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $N$ | `s` | 输入的数字串（全程不转成整数） |
| $L$ | `L` | `s.size()`，位数 |
| — | `hl` | 左半段长度 $\lceil L/2\rceil$（变量名取 "half length"） |
| — | `odd` | $L$ 是否为奇数，决定镜像时中间位是否共用 |
| $h$（左半段） | `h` | `s.substr(0,hl)`；若需加一时就地修改 |
| $M(h)$ | `mk(h,odd)` 的返回值 / `t` | 由左半段镜像出的回文候选 |
| — | `r` | `mk` 内部的临时串：反转前先去掉中间位 |
| — | `ch` | 扫描 `s` 判断"是否全为 $9$"的临时字符 |
| — | `all9` | 全 $9$ 标记，为真时答案位数 $+1$ |
| — | `i` | 加一进位时的指针，从 `hl-1` 向左走 |

### 算法步骤

1. 读入字符串 `s`，取 `L=s.size()`。
2. 扫描 `s`：若全为 `9`，答案位数必为 $L+1$，输出 `'1' + string(L-1,'0') + '1'`，结束。
3. 取 `hl=(L+1)/2`、`h=s.substr(0,hl)`、`t=mk(h,odd)`。
4. 若 `t>s`，输出 `t`，结束。
5. 否则对 `h` 做十进制加一（`9` 变 `0` 左移，非 `9` 加一；若越界说明全是 $9$，用第 2 步的兜底输出），再输出 `mk(h,odd)`。

### 复杂度分析

- **时间复杂度**：判断全 $9$、截取、镜像、比较、进位各自 $\mathcal{O}(L)$，总计 $\mathcal{O}(L)\le\mathcal{O}(100)$。
- **空间复杂度**：$\mathcal{O}(L)$，只有几个长度 $L$ 的串。

### 正确性验证

- 引理 1 保证"镜像构造"不漏掉任何回文；引理 2 保证"左半段增大则回文增大"，从而"加一"是找下一个候选的正确方式。
- 引理 3 分情况给出答案，并证明了加一时不会发生位数变化；引理 4 处理唯一会变位数的情况。
- 边界检查：$N=9\to11$；$N=11\to22$；$N=99\to101$；$N=121\to131$；$N=10^{99}\to10^{99}+1$；$N=99\dots98$（$100$ 位）$\to99\dots9$（$100$ 位）。均已手算核对。
- 无整数运算，不存在溢出；字符串比较只在等长情形下使用，语义正确。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1609 最小回文数
// https://www.luogu.com.cn/problem/P1609
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

string s;

string mk(const string&h,bool odd)         // 由左半段 h 造出回文
{
	string r=h;
	if(odd)
		r.pop_back();                      // 奇数长度时中间那位被共用
	reverse(r.begin(),r.end());
	return h+r;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>s;
	int L=s.size();
	bool all9=true;
	for(char ch:s)
		if(ch!='9')
			all9=false;
	if(all9)
	{
		cout<<'1'<<string(L-1,'0')<<'1'<<'\n';
		return 0;
	}
	int hl=(L+1)/2;                        // 左半段长度
	bool odd=(L&1);
	string h=s.substr(0,hl);
	string t=mk(h,odd);
	if(t>s)                                // 等长数字串的字典序就是数值序
	{
		cout<<t<<'\n';
		return 0;
	}
	int i=hl-1;
	while(i>=0&&h[i]=='9')
	{
		h[i]='0';
		--i;
	}
	if(i<0)                                // 左半段全是 9, 位数要涨(上面已排除, 兜底)
	{
		cout<<'1'<<string(L-1,'0')<<'1'<<'\n';
		return 0;
	}
	++h[i];
	cout<<mk(h,odd)<<'\n';
	return 0;
}
```

### 易错点

1. **忘记"严格大于"**：$N=121$ 时镜像结果 $121$ 不等于答案，必须走加一分支；写成 `t>=s` 会死循环或错答。
2. **奇数长度镜像时重复中间位**：`L` 为奇数时中间那位只能出现一次，所以要 `pop_back()` 后再反转。$N=123\to131$ 就能暴露这个错。
3. **漏掉全 $9$**：$999$ 的答案是 $1001$（4 位），若不做特判，加一会让左半段变长，镜像长度就乱了。
4. **比较用数值**：$100$ 位无法存进 `long long`，只能用字符串比较；而且必须**等长**才能直接比字典序。
5. **输出多余的 $0$**：答案不含前导零，构造出的 `h` 首位来自 $N$ 的首位，天然非零（全 $9$ 分支的 `'1'` 也非零）。
