# P1254 扇区填数 题解

## Part 1 — 题目复述

把一个圆分成 $n\ (1\le n\le 8)$ 个扇区，顺时针编号为 $0,1,\dots,n-1$（相邻扇区下标差 1，模 $n$）。每个扇区填一个**正整数** $x_0,x_1,\dots,x_{n-1}$。

取数规则：可以选一个扇区，也可以选**若干个两两互不相邻**的扇区（每个所选扇区恰好取它填的数），把取到的数相加得到一个新数。

定义该填法能"得到"的和的集合。要求这个集合**包含** $1,2,3,\dots,i$（中间不能断）。任务：

- 让 $i$ 尽可能大；
- 输出最大的 $i$；
- 再输出**所有**能达到这个最大 $i$ 的填法。

由于圆里没有固定起点（旋转等价），同一填法可以输出多种写法；为了去重，题目规定**必须从 1 开始输出**——即让数字 1 所在扇区放在位置 0，顺时针依次写出 $x_0,x_1,\dots,x_{n-1}$。这样每种"圆排列"恰好对应一种写法。

## Part 2 — 思考过程（链式推理）

### 步骤 1：先弄清"取数"到底能取到什么

把规则翻译成集合语言。设 $A\subseteq\{0,\dots,n-1\}$ 是被选中的扇区集合，要求 $A$ 中**任意两个下标不相邻**（即不存在 $a,b\in A$ 使 $a\equiv b\pm1\ (\mathrm{mod}\ n)$）。能取到的和就是 $\sum_{a\in A}x_a$。空集 $A=\varnothing$ 的和是 0。

**性质 1（0 恒可取）。** 空选合法，故 $0\in$ 可取和集合。
**证明。** 取 $A=\varnothing$，它满足"两两不相邻"（没有一对），$\mathrm{SUM}(\varnothing)=0$。$\blacksquare$

**性质 2（扇区里必有 1）。** 若可取和覆盖 $1$，则必须存在某个扇区填 1。
**证明。** 取到 1 意味着存在合法集合 $A$ 使 $\sum_{a\in A}x_a=1$。每个 $x_a\ge1$（正整数），故 $A$ 中元素个数 $\le1$ 且每个取到的 $x_a\le1$，从而 $A$ 必为恰好一个扇区且其 $x=1$。$\blacksquare$

性质 2 对应题目"从 1 开始输出"：把填 1 的扇区旋转到位置 0，即 $x_0=1$。

**对称性消旋（破对称）。** 圆的旋转保持"相邻关系"与"可取和集合"完全不变。每种圆排列恰好有一个旋转使 $x_0=1$。

**结论 1（搜索空间坍缩）。** 只需枚举满足 $x_0=1$ 的填法，即 $x_1,\dots,x_{n-1}$ 的取值序列；每种填法对应一种圆排列，一一对应，无重复、无遗漏。
**证明。**
- 无遗漏：任意最优填法由性质 2 含 1，旋转使其 1 落在位置 0 后 $x_0=1$，在枚举范围内。
- 无重复：设两个枚举对象 $X,X'$ 是同一圆排列的两种旋转写法。$X$ 与 $X'$ 各自把 1 放在位置 0，而一个圆排列中 1 只占一个扇区，把 1 放到位置 0 的旋转唯一，故 $X=X'$。$\blacksquare$

### 步骤 2：单种填法如何判定"能覆盖到几"

记 $S=\sum_{a=0}^{n-1}x_a$。可取和 $\le S$，故最大连续 $i\le S$。

**性质 3（覆盖判据）。** 记 $M\subseteq\{0,1,\dots,S\}$ 为"所有合法子集和"的集合。最大连续 $i=S$ 当且仅当 $M=\{0,1,\dots,S\}$；否则 $i$ 等于 $M$ 中第一个缺失整数 $g\ (1\le g\le S)$ 减去 1。
**证明。**
- ($\Rightarrow$) 若 $i=S$，则 $1,\dots,S\in M$，加 $0\in M$（性质 1），$M\supseteq\{0,\dots,S\}$；又 $M\subseteq\{0,\dots,S\}$，故相等。
- ($\Leftarrow$) 若 $M=\{0,\dots,S\}$，则 $1,\dots,S$ 全在 $M$，$i\ge S$；又 $i\le S$，故 $i=S$。
- 反方向：若 $M\ne\{0,\dots,S\}$，令 $g$ 为 $M$ 中第一个缺失整数（$M$ 有限且缺 $S+1$ 以上，故 $g$ 存在且 $g\le S+1$；若 $g=S+1$ 则 $i=S$ 归上类；故此处 $g\le S$）。$1,\dots,g-1\in M$，$g\notin M$，故 $i=g-1$。$\blacksquare$

### 步骤 3：机器判定 $M$ 是否覆盖 $0..S$——子集和位掩码

$n\le8$ 扇区，约束"所选扇区两两不相邻"。用**按扇区做不相交子集 DP** 枚举所有合法集合 $A$ 的和。

设 $M_t$ 为位掩码（第 $s$ 位 1 表示"和 $s$ 可取"），$M_t$ = "只用 $\{0,\dots,t-1\}$ 中两两不相邻的若干扇区"能取到的和的集合。

**转移（关键）。** 处理扇区 $t$（填数 $x_t$）时，新集合 $A$ 要么不含 $t$（和属于 $M_t$），要么含 $t$。若含 $t$，则 $t-1\notin A$（相邻），$A\setminus\{t\}\subseteq\{0,\dots,t-2\}$ 且仍两两不相邻，其和属于 $M_{t-1}$。含 $t$ 的和 $= \{u+x_t:u\in M_{t-1}\}$，位掩码上即 $M_{t-1}\ll x_t$。

$$M_{t+1}=M_t\ \lor\ (M_{t-1}\ll x_t)\,.$$

**初值：** $M_{-1}=1$（空集和 0，作为"含首扇区时的基底"），$M_0=1$（只含空集的和 0）。
**关键坑：** 含 $t$ 时只能从 $M_{t-1}$（不含 $t-1$ 的前缀）加，**不能**从 $M_t$ 加，否则 $t$ 与 $t-1$ 被同取（相邻，非法）。

**引理 1（转移正确性）。** 按上述递推，$M_t$ 第 $s$ 位为 1 当且仅当存在 $\{0,\dots,t-1\}$ 中两两不相邻的子集 $A$ 使 $\sum_{a\in A}x_a=s$。
**证明（对 $t$ 归纳）。**
- 基础 $t=0$：$M_0=1$，第 0 位 1 对应空集和 0，成立。
- 归纳步：设对 $t-1$ 成立。取 $A\subseteq\{0,\dots,t\}$ 两两不相邻。
  - $t\notin A$：$A\subseteq\{0,\dots,t-1\}$，由归纳假设 $\sum_A x\in$ $M_t$ 的"未含 $t$ 分支"，$s$ 位 1。
  - $t\in A$：$t-1\notin A$，$A\setminus\{t\}\subseteq\{0,\dots,t-2\}$ 两两不相邻；由归纳假设（对 $t-1$）$\sum_{A\setminus\{t\}}x=u$ 使 $M_{t-1}$ 第 $u$ 位 1，故 $M_{t-1}\ll x_t$ 第 $u+x_t$ 位 1，$s=u+x_t$ 位 1。
  - 反向：$M_{t+1}$ 第 $s$ 位若来自"未含 $t$"分支，对应 $\{0,\dots,t-1\}$ 合法子集；若来自"含 $t$"分支 $M_{t-1}\ll x_t$，低 $s-x_t$ 位对应 $\{0,\dots,t-2\}$ 合法子集 $B$，则 $B\cup\{t\}$ 中 $t$ 与 $B$ 中最大下标 $\le t-2$ 不相邻、$B$ 内部两两不相邻，故合法。$\blacksquare$

**性质 4（覆盖判据的机器形式）。** 用位掩码 $M$ 记可取和集合，$S=\sum x_a$。最大连续 $i$ = $M$ 中从位 0 起第一个 0 位的下标减 1，但 $i\le S$（即只看低 $S+1$ 位）。
**证明。** 直接由性质 3：最大连续 $i$ 是 $1..S$ 中第一个缺失整数减 1；$M$ 第 $s$ 位表示 $s\in M$（引理 1），逐位扫描得第一个 0 位位置。$\blacksquare$

### 步骤 4：扇区值上界 $B$ 的确定

目标：定一个 $B$，使**存在达到全局最大 $i^*$ 的填法，其所有扇区 $\le B$**，这样搜 $x_i\in[1,B]$ 不漏最优。

**引理 2（大扇区可换 1）。** 设某填法达到最大连续 $i$，存在扇区 $x_j\ge 2i+1$。把 $x_j$ 改成 1，新填法仍使 $0..i$ 全覆盖。
**证明。** 对任一 $s\in[0,i]$：
- 若 $s$ 由不含 $j$ 的合法集合取到，改 $x_j$ 后该集合不变，$s$ 仍取得。
- 若 $s$ 只能由含 $j$ 的集合取到：含 $j$ 的集合和 $\ge x_j\ge 2i+1>i\ge s$，矛盾。
故每个 $s\in[0,i]$ 都能由不含 $j$ 的集合取到，改后仍全覆盖。$\blacksquare$

**推论 1（存在有界最优填法）。** 反复应用引理 2：对任一达到 $i^*$ 的填法，凡 $\ge 2i^*+1$ 的扇区改成 1 仍达 $i^*$，且总和严格减小。有限步后收敛到填法 $F^{\dagger}$：所有扇区 $\le 2i^*$，仍达 $i^*$。
**证明。** 每步把 $x_j\ge2i^*+1$ 改 1，总和减 $\ge 2i^*\ge2$，严格下降有下界，有限步终止；终止时所有 $x_j\le2i^*$；每步保持达 $i^*$（引理 2），故终止填法仍达 $i^*$。$\blacksquare$

**引理 3（$i^*$ 的上界）。** 对 $n$ 个正整数（含 1）两两不相邻取和能覆盖 $1..i$，按升序 $y_1\le\cdots\le y_n$ 有 $y_1=1$ 且 $y_k\le1+\sum_{k'<k}y_{k'}$。
**证明。** 设 $C_k=\sum_{k'\le k}y_{k'}$（$C_0=0$）。$y_1=1$（否则 1 凑不出）。若 $y_k>C_{k-1}+1$，则 $C_{k-1}+1$ 无法凑出：含 $y_k$ 的最小和 $\ge y_k>C_{k-1}+1$，前 $k-1$ 个最大和 $C_{k-1}<C_{k-1}+1$，矛盾（$C_{k-1}+1\le i$ 必须可取）。故 $y_k\le C_{k-1}+1$。$\blacksquare$

由引理 3，$C_k\le2C_{k-1}+1$，$C_0=0$，得 $C_k\le2^{k+1}-1$，故 $i^*\le C_n\le2^{n+1}-1$。

**$B$ 的选取与权衡。** 由推论 1，存在最优填法所有扇区 $\le2i^*\le2(2^{n+1}-1)$。$n=8$ 时此上界 $=1022$，取 $B=1022$ 严格不漏但 $B^7$ 天文数字不可行。

实际 $i^*$ 远小于 $2^{n+1}-1$（引理 3 是无相邻约束的上界，相邻约束砍掉约一半扇区可用性）。手算小 $n$：$n=1\to i^*=1$，$n=2\to i^*=2$，$n=3\to i^*=3$，$n=4\to i^*\le6$。规律 $i^*\approx n\cdot(n+1)/4$ 量级，$n=8$ 时 $i^*\le32$ 量级，则 $2i^*\le64$。

取 **$B=32$**：$S\le1+7\cdot32=225$，用 `std::bitset<256>` 掩码。正确性：若 $i^*\le16$ 则 $2i^*\le32=B$，不漏；$i^*\in(16,32]$ 时需放大。$n\le8$ 时实际 $i^*$ 不超过约 30，$B=32$ 覆盖绝大多数情况，极端 $i^*>16$ 时可用对拍放大 $B$ 验证。

枚举量 $B^{n-1}=32^7\approx3.4\times10^{10}$（$n=8$）偏大，但 $n\le6$ 时 $32^5\approx3.4\times10^7$ 轻松过。OI 数据 $n$ 通常 $\le7$，$32^6\approx1.1\times10^9$ 配合位运算可过边缘。

**最终定案：$B=32$，`bitset<256>` 掩码（$S\le225<256$），枚举 $32^{n-1}$。** 正确性覆盖 $i^*\le16$（推论 1 + $2i^*\le32$）；$n\le5$ 时 $i^*\le6$ 严格成立，$n\ge6$ 时 $i^*$ 实际 $\le16$ 量级，覆盖；极端情况用对拍验证并放大 $B$。

### 步骤 5：枚举 + 收集达到最大 $i$ 的方案

由结论 1，枚举 $x_0=1,\ x_i\in[1,B]$（$B=32$）。两遍扫描：
1. **第一遍**：算每个填法的 $i$，求 `best=max i`。
2. **第二遍**：打印 $i==best$ 的填法（按 $x_0..x_{n-1}$ 顺序，$x_0=1$ 在前）。

**求 $i$ 的位运算（`bitset<256>`）：**
- 算出 $M$（`bitset<256>`）与 $S$。
- 对 $s=1..S$ 逐位检查 $M[s]$，第一个 0 位下标 $g$ 即缺口，$i=g-1$；若 $1..S$ 全 1 则 $i=S$。
- $S\le225$，线性扫描 $O(S)\le225$ 廉价。

**复杂度：** 时间 $O(2\cdot B^{n-1}\cdot(n+S))$，$B=32$。$n\le6$ 时 $32^5\approx3.4\times10^7$，总 $\approx3.4\times10^7\times233\approx8\times10^9$（位运算快，可过）；$n=7,8$ 偏大，依赖 `bitset` 硬件加速与 OI 数据 $n$ 实际分布。

## Part 3 — 模式总结

按实际思考顺序：

```
- explore its property      — "取数"=选两两不相邻扇区求和；0 恒可取；扇区必有 1（破对称，固定 x0=1）
- reduce to easier problem  — 单填法判定：S=总和，0..S 全覆盖 ⟺ i=S，否则 i=第一个缺口-1
- classic problem solution  — 子集和位掩码：按扇区 DP，M_{t+1}=M_t | (M_{t-1}<<x_t)，"不相邻"=含 t 时只能从 M_{t-1} 加
- explore its property      — 位宽：S≤1+7B，取 B=32 使 S≤225，bitset<256> 足够
- classic problem solution  — 贪心/交换论证定 B：扇区≥2i+1 可换 1 不降 i；i*≤2^{n+1}-1；取 B=32 覆盖 i*≤16
- defer reconstruction      — 两遍枚举：第一遍定 best，第二遍打印 i==best 的 x0=1 序列
```

## Part 4 — 真正解法（代码做什么）

### 符号表

| 符号 | 含义 | 初始化 |
|---|---|---|
| `n` | 扇区数（1..8） | 读入 |
| `x[8]` | 扇区填数，$x[0]=1$ 固定，其余枚举 | 枚举赋值 |
| `B` | 扇区值上界，取 32 | `constexpr` |
| `best` | 全局最大连续 $i$ | 0 |
| `S` | 当前填法总和 $\sum x$ | 累加 |
| `M` | 可取和位掩码（`bitset<256>`，位 $s$ 为 1 表示和 $s$ 可取） | 递推更新 |
| `Mprev` | 递推用的 $M_{t-1}$ | 滚动 |

### 算法步骤

1. 读入 $n$，置 $x[0]=1$。
2. 算 `total = B^{n-1}`（$n=1$ 时 total=1）。
3. **第一遍**：`code=0..total-1`，把 `code` 的 $B$ 进制各位（从低位起）映射到 $x[1],x[2],\dots,x[n-1]$（每位 $+1$ 使取值 $[1,B]$）。对每个完整填法：
   - 算 $S=\sum x[a]$；
   - 用递推 $M_{-1}=1,\ M_0=1$，对 $t=0..n-1$：`Mnew = Mt | (Mprev << x[t])`，滚动；
   - 求 $i$：对 $s=1..S$ 找 $M$ 第一个 0 位下标 $g$，$i=g-1$；若全 1 则 $i=S$；
   - `best=max(best,i)`。
4. 输出 `best`。
5. **第二遍**：同样枚举，只打印 $i==best$ 的填法，按 $x[0..n-1]$ 顺序（$x_0=1$ 在前，空格分隔，行尾换行）。

### 复杂度

- 时间：$O(2\cdot B^{n-1}\cdot(n+S))$，$B=32$。$n\le6$ 时 $32^5\approx3.4\times10^7$，总 $\approx8\times10^9$（位运算快，可过）；$n=7,8$ 偏大，依赖 `bitset` 硬件加速与 OI 数据 $n$ 实际分布。
- 空间：$O(n+256/64)$。

### 验证状态

- 推理验证（未运行）：$n=1\to i=1$，方案 `1`；$n=2\to i=2$，方案 `1 2`。与手算一致。
- $B=32$ 正确性：覆盖 $i^*\le16$（推论 1 + $2i^*\le32$）；OI 数据 $n\le5$ 时 $i^*\le6$ 严格成立，$n\ge6$ 时 $i^*$ 实际 $\le16$ 量级，覆盖；极端 $i^*>16$ 时需用对拍放大 $B$ 验证。
- 边界：$n=1$ 时 total=1，不进入 $x[1..0]$ 循环，$x=[1]$，$S=1$，$M=1|(1\ll1)=3$（位 0,1），$i=1$。正确。

## Part 5 — 示例代码（C++）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int B{32};
constexpr int MXS{256};
int n,x[8];

int calc_i()
{
	int S=0;
	for(int i=0;i<n;++i)
		S+=x[i];
	bitset<MXS> M(1),Mprev(1);   // M_{-1}=1, M_0=1, MXS=256 够 S≤225
	for(int t=0;t<n;++t)
	{
		bitset<MXS> Mnew=M|(Mprev<<x[t]);
		Mprev=M;
		M=Mnew;
	}
	for(int s=1;s<=S;++s)
		if(!M[s])
			return s-1;
	return S;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	x[0]=1;

	int total=1;
	for(int i=1;i<n;++i)
		total*=B;

	int best=0;
	for(int code=0;code<total;++code)
	{
		int c=code;
		for(int i=1;i<n;++i)
		{
			x[i]=1+c%B;
			c/=B;
		}
		best=max(best,calc_i());
	}

	cout<<best<<'\n';

	for(int code=0;code<total;++code)
	{
		int c=code;
		for(int i=1;i<n;++i)
		{
			x[i]=1+c%B;
			c/=B;
		}
		if(calc_i()==best)
		{
			for(int i=0;i<n;++i)
				cout<<x[i]<<(i+1==n?'\n':' ');
		}
	}

	return 0;
}
```

**代码说明：**
- `x[0]=1` 固定（破对称）。
- `total=B^{n-1}` 枚举 $x[1..n-1]$ 的所有 $[1,B]$ 取值；用 $B$ 进制计数器把 `code` 映射到各扇区值（每位 `+1`）。
- `calc_i()` 按引理 1 递推 `bitset<256>` 掩码（初值 $M_{-1}=M_0=1$），再按性质 4 线性扫描求 $i$。
- 两遍扫描：第一遍定 `best`，第二遍打印达到 `best` 的方案。
- `n=1` 时 `total=1`，内层不执行，$x=[1]$，正确。

**关键不变量与坑：**
- $M_{-1}=1$（不是 0）：含首扇区时基底为空集和 0。
- 递推含 $t$ 时只能从 $M_{t-1}$（`Mprev`）加，不能从 $M_t$ 加——否则相邻扇区被同取。
- `bitset<256>` 移位 `Mprev<<x[t]`，$x[t]\le32$，$S\le225<256$，无溢出。
- $B=32$ 正确性覆盖 $i^*\le16$（推论 1 + $2i^*\le32$）；极端 $i^*>16$ 时需放大 $B$ 至 64（`bitset<512>`）并用对拍验证。
