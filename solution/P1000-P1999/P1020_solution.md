# P1020 [NOIP 1999 提高组] 导弹拦截 题解

## 一、发现叙事

打开题目，一个经典的拦截系统摆在面前：第一发任意高，之后每发不高于前一发。问两个问题——

> 一套系统最多拦几发？要拦完所有导弹最少要几套？

第一个问题很自然：一套系统拦截的导弹高度序列，必须是不上升的。那就是求**最长不上升子序列**（LNIS）。这是经典 DP。

但第二个问题就耐人寻味了：最少要几套？直觉上，如果有一串导弹高度是严格递增的，那它们谁都拦不了谁，一套系统只能拦一发，所以需要这么多套。但反过来想，是不是只要没有严格递增的"障碍"，一套系统总能想办法吃掉？这就引出了 Dilworth 定理的味道。

再看数据范围：n ≤ 10^5，O(n²) 只能拿一半分，必须上 O(n log n)。这提示我们——两个问题都可以用**二分 + 贪心**的 LIS 套路来解，只是比较符不同。

## 二、思维链与完整证明

### 2.1 问题一：最长不上升子序列

**定义.** 子序列 $a_{i_1},a_{i_2},\dots,a_{i_k}$（$i_1<i_2<\dots<i_k$）是不上升的，当且仅当 $a_{i_1}\ge a_{i_2}\ge\dots\ge a_{i_k}$。

**O(n²) 做法.** 设 $dp[i]$ 表示以 $i$ 结尾的最长不上升子序列长度。转移：
$$dp[i]=1+\max\{dp[j]\mid j<i,\;a_j\ge a_i\}$$
全局取 $\max dp$ 即可。复杂度 $O(n^2)$，应对 $n\le 10^4$ 的子任务。

**O(n log n) 做法——二分贪心.**

考虑维护一个数组 $d$，$d[k]$ 表示**长度为 $k$ 的不上升子序列中，最后一个元素的最大可能值**（为什么维护最大值？因为最后一个元素越大，越有利于后面接更小的元素）。

遍历每个 $a_i$：
- 在 $d$ 中**从左往右找到第一个 $< a_i$ 的位置**——因为 $d$ 本身是严格递减的（长度为 1 的末元素 ≥ 长度为 2 的末元素 ≥ ...），第一个 $< a_i$ 的位置意味着：前面那些 $\ge a_i$ 的末元素都可以接上 $a_i$ 形成更长的序列，但长度只能延伸到当前这个位置。把 $d$ 的这个位置替换为 $a_i$（因为 $a_i$ 比原来的值更小或相等，但作为末元素更"有潜力"）。
- 如果找不到 $< a_i$ 的元素（说明 $a_i$ 比所有末元素都小或相等），则在末尾追加。

这个二分查找可以用标准库的 `lower_bound` 配合自定义比较实现，也可以将序列取负后转为 LIS 问题。

**取负转化.** 令 $b_i=-a_i$，则原序列不上升等价于 $b$ 序列**不下降**（$a_i\ge a_j\iff -a_i\le -a_j$）。求 $b$ 的最长不下降子序列即可：使用 `upper_bound`（因为是不下降，允许相等，所以找第一个 $> b_i$ 的位置替换）。

### 2.2 问题二：最少拦截系统——Dilworth 定理

**定理（Dilworth, 1950）.** 在有限偏序集中，最小链覆盖数等于最大反链大小。

**建模.** 定义偏序关系：导弹 $i$ 可以在 $j$ 之前被同一系统拦截（即 $i$ 排在 $j$ 前面且 $a_i\ge a_j$）。那么：
- 一条链 = 一套系统拦截的导弹序列（不上升子序列）；
- 一个反链 = 任意两发导弹都不能被同一系统拦截，即对于任意 $i<j$，都有 $a_i<a_j$——这正是**严格递增子序列**。

因此，**最少系统数 = 最长严格递增子序列的长度**。

**O(n log n) 做法——标准 LIS.**

维护 $d$，$d[k]$ 表示长度为 $k$ 的递增子序列中最后一个元素的最小值。遍历 $a_i$：
- 在 $d$ 中找第一个 $\ge a_i$ 的位置（`lower_bound`），替换为 $a_i$；
- 如果都 $< a_i$，则追加。

最终 $d$ 的长度就是 LIS 的长度。

### 2.3 正确性证明摘要

**Q1 二分贪心的正确性.** $d$ 始终是递减的（非严格）。当处理 $a_i$ 时，设 $p$ 是第一个 $d[p] < a_i$ 的位置，这意味着 $d[0..p-1]\ge a_i$。因此 $a_i$ 可以接到任意一个长度为 $p-1$ 的不上升子序列后面，形成长度为 $p$ 的序列。同时 $a_i\le d[p-1]$，所以 $d[p]=a_i$ 不会破坏 $d$ 的单调性，而且 $a_i$ 比原来的 $d[p]$ 更大（或相等），作为末元素更优——因为更大的末元素更容易接上后面的元素。

**Q2 Dilworth 的直观.** 设 $L$ 为最长严格递增子序列的长度。由于这 $L$ 个导弹中任意两个都不能被同一系统拦截，至少需要 $L$ 套系统。同时可以构造性地证明 $L$ 套就够：每次从序列中贪心地取出以当前最小可能高度为起头的不上升子序列，恰好需要 $L$ 轮——与 LIS 的二分贪心本质上是对偶的。

### 2.4 复杂度

- 时间：$O(n\log n)$，两次二分贪心各需 $O(n\log n)$。
- 空间：$O(n)$，只需存储原数组和 $d$ 数组。

## 三、模式总结

| 问题 | 转化 | 二分查找方式 | $d$ 的单调性 |
|------|------|-------------|-------------|
| 最长不上升子序列 (LNIS) | 取负 → 最长不下降 | `upper_bound` | 不下降 |
| 最长递增子序列 (LIS) | 直接 | `lower_bound` | 递增 |
| 最少链覆盖 = 最长反链 | Dilworth | — | — |

**记忆口诀**：
- 上升用 `lower_bound`，不下降用 `upper_bound`；
- 取负反转比较符，不升转不降，不降转不升；
- 最少系统数 = 最长严格上升长度。

## 四、真实解法与符号约定

### 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 导弹个数 |
| $a[0..n-1]$ | 导弹高度，0-based |
| $d$ | 贪心维护的序列 |
| $b[0..n-1]$ | 取负后的高度 |

### 算法流程

```
Question 1:
  对每个 a[i]:
    b[i] = -a[i]
    在 d 中 upper_bound(b[i]) → pos
    if pos == d.size(): d.push_back(b[i])
    else: d[pos] = b[i]
  输出 d.size()

Question 2:
  清空 d
  对每个 a[i]:
    pos = lower_bound(d, a[i])
    if pos == d.size(): d.push_back(a[i])
    else: d[pos] = a[i]
  输出 d.size()
```

## 五、C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};
int n,a[mxn],b[mxn],d[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int x;
	while(cin>>x)
		a[n++]=x;

	// Q1: 最长不上升子序列 (取负 -> 最长不下降)
	for(int i=0;i<n;++i)
		b[i]=-a[i];
	int len1=0;
	for(int i=0;i<n;++i)
	{
		int pos=upper_bound(d,d+len1,b[i])-d;
		d[pos]=b[i];
		if(pos==len1)
			++len1;
	}
	cout<<len1<<'\n';

	// Q2: 最长严格递增子序列
	fill_n(d,n+1,0);
	int len2=0;
	for(int i=0;i<n;++i)
	{
		int pos=lower_bound(d,d+len2,a[i])-d;
		d[pos]=a[i];
		if(pos==len2)
			++len2;
	}
	cout<<len2<<'\n';

	return 0;
}
```

（说明：代码使用 `upper_bound` 求不下降子序列长度，对应取负后的 $b$ 数组；使用 `lower_bound` 求严格递增子序列长度，对应原 $a$ 数组。）
