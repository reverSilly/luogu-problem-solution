# P1861 星之器

## 1. 重新读题

### 1.1 问题重述（人话版）

有一个 $N$ 行 $M$ 列的格子，每格有若干颗“星”。一次操作：

- 在同一行或同一列的**两个不相邻**格子中各取走 $1$ 颗星；
- 让这两颗星各自向对方移动一格（即分别落到两个格子内侧相邻的格子里）。

操作获得的魔力等于两个格子之间**间隔的格子数**，也就是它们在行/列上下标之差减 $1$。

给定初态 $\mathit{Ini}$ 与终态 $\mathit{Fin}$（保证可达、且不完全相同），问从 $\mathit{Ini}$ 变到 $\mathit{Fin}$ 的过程中最多能获得多少魔力。操作过程中每格的星数不能为负。

### 1.2 关键约束与规模暗示

- $1\le N,M\le 200$，每格星数 $\le 1000$。
- 状态总量是 $N\times M$ 个格子的数表，规模上千，不可能对“状态”做搜索。
- “求所有合法操作序列中魔力的最大值”，而每个操作获得的魔力是确定的——这强烈暗示存在一个**势能函数**：它每次下降的量恰好等于获得的魔力。若如此，所有合法序列的总魔力都相同，最大值就是这个势差。

---

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：先看一次操作改变了什么

只考虑同一行上的操作。设两个格子列下标为 $j_1<j_2$（行下标同为 $i$）。操作后：

$$
a_{i,j_1}-=1,\quad a_{i,j_1+1}+=1,\quad
a_{i,j_2}-=1,\quad a_{i,j_2-1}+=1 .
$$

获得的魔力
$$
g=j_2-j_1-1 .
$$

四个被改动的格子是 $j_1,\ j_1+1,\ j_2-1,\ j_2$。操作把两端各一颗星向内推了一格。

竖直方向完全对称：把列下标换成行下标即可。

### 2.2 寻找势能：让“变化量”对上“魔力”

希望构造
$$
\Phi=\sum_{i,j} W(i,j)\,a_{i,j},
$$
使得每次操作满足 $\Delta\Phi=-g$（或 $=g$，取负号即可）。

先只看横向。既然操作只在同一行内发生，可以猜测 $W(i,j)=F(i)+F(j)$，横向操作时 $F(i)$ 部分因为该行星数总和不变而抵消，只需考察 $F(j)$ 部分。

设 $h(j)=F(j+1)-F(j)$。一次横向操作带来的势能变化为

$$
\Delta\Phi=\big(F(j_1+1)-F(j_1)\big)+\big(F(j_2-1)-F(j_2)\big)
=h(j_1)-h(j_2-1).
$$

希望它等于 $-(j_2-j_1-1)=j_1-(j_2-1)$。最简单的取法是

$$
h(j)=j \quad\Longrightarrow\quad F(j)=\frac{j(j-1)}{2}.
$$

（$F$ 加任意常数不影响 $\Delta\Phi$。）

**引理 1（势能恒等式，横向）**：取 $F(k)=\dfrac{k(k-1)}2$，则对任意 $j_1<j_2$ 的同行操作，
$$
\Delta\Phi = -\big(j_2-j_1-1\big).
$$

**证明**：把 $F(j)=\frac{j(j-1)}2$ 代入。直接计算
$$
F(j+1)-F(j)=\frac{(j+1)j-j(j-1)}2=j .
$$
于是
$$
\Delta\Phi=h(j_1)-h(j_2-1)=j_1-(j_2-1)=-(j_2-j_1-1),
$$
正是所需。$\blacksquare$

**引理 2（势能恒等式，纵向）**：同样的 $F(k)=\frac{k(k-1)}2$，对 $W(i,j)=F(i)+F(j)$，任意纵向操作也满足 $\Delta\Phi=-\big(i_2-i_1-1\big)$。

**证明**：纵向操作只改变同一列上的四个格子，$j$ 固定，行下标 $i_1,i_2$ 变化。由于 $W(i,j)=F(i)+F(j)$，其中 $F(j)$ 部分只依赖列，同一列内四个格子的 $F(j)$ 之和在操作前后不变，于是 $\Delta\Phi$ 中只剩 $F(i)$ 的贡献。对 $F(i)$ 套用引理 1 的推导（把 $j$ 换成 $i$）即得。$\blacksquare$

需要确认 $W(i,j)=F(i)+F(j)$ 的横向操作中 $F(i)$ 部分确实抵消：横向操作涉及同一行 $i$ 的四个格子，各取/加一颗，该行的 $\sum_j a_{i,j}$ 前后不变，故 $\sum_j F(i)a_{i,j}=F(i)\sum_j a_{i,j}$ 不变。同理纵向时 $F(j)$ 部分抵消。引理 1、2 合起来说明：

**定理（所有序列魔力相同）**：沿任意合法操作序列从 $\mathit{Ini}$ 到 $\mathit{Fin}$，总魔力和恒为
$$
\Phi(\mathit{Ini})-\Phi(\mathit{Fin}),\qquad
\Phi=\sum_{i,j}\left(F(i)+F(j)\right)a_{i,j}.
$$

**证明**：把序列中每一步的魔力 $g_t$ 与势能变化相加，由引理 1、2 得 $g_t=-\Delta\Phi_t$。对全部步骤求和，中间项望远镜相消：
$$
\sum_t g_t=\Phi(\mathit{Ini})-\Phi(\mathit{Fin}).
$$
与具体路径无关。$\blacksquare$

因此“最多”其实等于“唯一”：所有可达序列的魔力总和都相同，输出这个势差即可。题目保证可达且 $\mathit{Ini}\ne\mathit{Fin}$，所以答案为正。

### 2.3 为什么直觉上一定存在这种势能

一次操作把一个“有序对”的能量向内压缩：两颗星各自向中心移一格，系统的某种“惯量”下降。$F(k)=k(k-1)/2$ 是把坐标的“两两距离”累积起来的形式——一维上 $\sum k\cdot(\text{数量})$ 的差分正是位置。操作等价于把两点各向中间挪一格，因此距离平方和类量按固定量减少。这也解释了为什么魔力之和与操作顺序无关：它是一个守恒型的记账量。

### 2.4 实现

直接用 0-based 下标（题目输入从 1 开始也无所谓，$F(k)$ 加常数不影响差值，但为与公式一致，代码内部用 0-based）。注意空行分隔的两块输入：初态 $N$ 行，空行，终态 $N$ 行。用 `cin >>` 读入会自然跳过空白，不需要特殊处理空行。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 操作只改动同一行/列上的四个格子，获得的魔力是两端下标差减一。
- **construct potential** — 猜测可加势能 $W=F(i)+F(j)$，由一维差分方程 $F(j+1)-F(j)=j$ 解出 $F(k)=k(k-1)/2$。
- **telescoping** — 每一步魔力恰好等于势能下降量，整条序列望远镜相消，总魔力与路径无关。
- **reduce to easier problem** — “最大值”退化为一次 $O(NM)$ 的势差计算。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `N,M` | `int` | 行数、列数 | 读入 | 维度 |
| `ini[i][j]` | `int [205][205]` | 初态星数 | 读入 | Init |
| `fin[i][j]` | `int [205][205]` | 终态星数 | 读入 | Final |
| `ans` | `i64` | 势差，即最大魔力 | 0 | 输出 |
| `F(k)` | 函数 | $k(k-1)/2$ | —— | 一维权 |

### 4.2 算法步骤

1. 读入 $N,M$ 与初态 $N\times M$ 个数（`cin` 自动跨过空行）。
2. 读入终态 $N\times M$ 个数。
3. 对每个 $(i,j)$，令 $d=\mathit{Ini}_{i,j}-\mathit{Fin}_{i,j}$，累加
   $$d\cdot\left(\frac{i(i-1)}2+\frac{j(j-1)}2\right).$$
4. 输出累加值。

### 4.3 复杂度分析

- 时间 $O(NM)$。
- 空间 $O(NM)$（也可边读边算初态、读终态时直接做差，省掉一个数组）。

## 5. 示例代码

```cpp
//
// 题目：P1861 星之器
// https://www.luogu.com.cn/problem/P1861
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{205};

int N,M;
int ini[mxn][mxn];
int fin[mxn][mxn];

i64 f(int k)
{
	return 1LL*k*(k-1)/2;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>N>>M;
	for(int i=0;i<N;++i)
		for(int j=0;j<M;++j)
			cin>>ini[i][j];
	for(int i=0;i<N;++i)
		for(int j=0;j<M;++j)
			cin>>fin[i][j];

	i64 ans{0};
	for(int i=0;i<N;++i)
		for(int j=0;j<M;++j)
			ans+=(i64)(ini[i][j]-fin[i][j])*(f(i)+f(j));
	cout<<ans<<'\n';
	return 0;
}
```
