# P1169 [ZJOI2007] 棋盘制作

## 一、重新读题（先确保理解无误）

给一个 N×M 的 01 矩阵（N,M ≤ 2000，01 表示黑白）。我们要从中裁出**两个**棋盘：

1. **最大正方形棋盘**的面积（正方形子矩阵，内部相邻格子颜色互异）；
2. **最大矩形棋盘**的面积（矩形子矩阵，相邻格子颜色互异，不一定正方形）。

输出两行：第一行最大正方形面积，第二行最大矩形面积。

"黑白相间"即每个格子与其上下左右四个邻居颜色都不同。等价于：子矩阵内的颜色分布必须与国际象棋棋盘一致（两种颜色交替出现）。

---

## 二、思维链（完整推导 + 引理证明）

### 2.1 抓住交替结构的数学本质

棋盘交替色的核心规律是什么？如果固定左上角颜色为 C，那么对于位置 (i,j)，期望颜色可以唯一确定：

- 当 i+j 为偶数时，期望颜色 = C；
- 当 i+j 为奇数时，期望颜色 = 1−C。

反之，如果子矩阵中每个格子的实际颜色都等于按上述公式算出的期望颜色，则这个子矩阵就是合法的棋盘。

**定义（合法棋盘）**：一个子矩阵是**棋盘** ⟺ 存在一个颜色 C ∈ {0,1}，使得对于该子矩阵内的所有格子 (i,j)，有 A[i][j] = C ⊕ ((i+j) & 1)。

这里 ⊕ 是异或，((i+j) & 1) 就是 i+j 的奇偶性。也就是说，颜色由行号列号之和的奇偶性唯一决定，只是整体可能偏移（全是 C 对应的那种，或者全是 1−C 对应的那种）。

### 2.2 关键变换：棋盘子矩阵 → 全等子矩阵

我们不想同时考虑 0 和 1 的交替规则，能不能等价成更熟悉的问题？

构造变换矩阵 B：

```
B[i][j] = A[i][j] XOR ((i+j) & 1)
```

也就是：如果 i+j 是偶数，B[i][j] 保持原色；如果 i+j 是奇数，B[i][j] 翻转。

**引理 1**：A 中的一个子矩阵是合法棋盘 ⟺ B 中对应子矩阵的所有值相等（全 0 或全 1）。

**证明**：
设子矩阵的左上角为 (r,c)，固定期望颜色为 C。
对于子矩阵内任意格子 (i,j)：
- 期望颜色 = C ⊕ ((i+j) & 1)
- 实际颜色 = A[i][j]

合法棋盘要求 A[i][j] = C ⊕ ((i+j) & 1)。

而 B[i][j] = A[i][j] ⊕ ((i+j) & 1) = [C ⊕ ((i+j) & 1)] ⊕ ((i+j) & 1) = C。

所以 B[i][j] 恒等于 C，证毕。

**引理 2**：变换是可逆的。即如果在 B 中找到一个全等于 C 的子矩阵，则在 A 中对应的是一个合法棋盘（期望颜色 C）。

**证明**：B[i][j] = C ⟹ A[i][j] = C ⊕ ((i+j) & 1)，这正是棋盘定义。证毕。

因此，原问题等价于：

> 在 B 矩阵中找**最大的全等正方形子矩阵**（所有元素相同），和**最大的全等矩形子矩阵**。

由于全等于 0 和全等于 1 两者都要考虑，我们分别对 B 和 B 的补（1−B）做一次相同的算法，取最大值即可。

于是问题进一步简化为一个经典问题：

> 给定一个 01 矩阵，求**全 1 的最大正方形**和**全 1 的最大矩形**。

### 2.3 子问题 1：全 1 最大正方形（经典 DP）

定义 dp[i][j] = 以 (i,j) 为**右下角**的最大全 1 正方形的边长。

转移：

```
如果 B[i][j] == 0:  dp[i][j] = 0
如果 B[i][j] == 1:  dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
```

**正确性证明**：

要构造以 (i,j) 为右下角、边长为 k 的全 1 正方形，必须满足：
1. (i,j) 本身是 1；
2. 以 (i-1,j) 为右下角有一个边长 ≥ k−1 的正方形；
3. 以 (i,j-1) 为右下角有一个边长 ≥ k−1 的正方形；
4. 以 (i-1,j-1) 为右下角有一个边长 ≥ k−1 的正方形。

这是因为边长为 k 的正方形由三部分重叠组成：上方 k−1×k−1、左方 k−1×k−1、左上 k−1×k−1，加上第 k 行和第 k 列的边缘。这三者的交集恰好是 (i-1,j-1) 处的 k−1×k−1 子正方形。所以三个 dp 值的 min 就是最大的可行 k−1，加 1 得到 k。

边界：i=0 或 j=0 时，dp[i][j] = B[i][j]（边长至多为 1）。

答案取所有 dp[i][j] 中最大值的平方。

复杂度 O(NM)。

### 2.4 子问题 2：全 1 最大矩形（经典悬线法 / 直方图法）

#### 2.4.1 转化为直方图

对于每一行 i，定义 height[j] = 从 (i,j) 向上数连续 1 的个数（即以 (i,j) 为底、向上延伸到的最长全 1 竖直线段的长度）。

```
如果 B[i][j] == 0: height[j] = 0
如果 B[i][j] == 1: height[j] = height_prev[j] + 1    (上一行的 height)
```

那么第 i 行上，以这一行为底边的最大全 1 矩形，就是求直方图 height[0..M-1] 中的最大矩形面积。

#### 2.4.2 直方图最大矩形（单调栈）

直方图中每个柱子的高度为 height[j]。一个以 height[j] 为高的矩形，其左右边界由第一个高度小于 height[j] 的柱子位置决定。

用单调递增栈（严格递增）计算每个柱子 j 的**左边界 L[j]**：左边第一个高度 < height[j] 的柱子下标（如果不存在则为 −1），和**右边界 R[j]**：右边第一个高度 < height[j] 的柱子下标（如果不存在则为 M）。

```
栈初始为空。
从左到右遍历 j:
  当栈非空且 height[stack.top()] >= height[j]:
    弹出栈顶
  如果栈空: L[j] = -1
  否则: L[j] = stack.top()
  将 j 入栈

清空栈，再从右到左遍历 j 计算 R[j]:
  同理，R[j] = 右边第一个小于 height[j] 的位置
```

以 height[j] 为高的矩形的宽度 = R[j] − L[j] − 1，面积 = height[j] × (R[j] − L[j] − 1)。

取所有 j 的最大值，即为该行的最大矩形面积。

逐行做，取所有行的最大值即可。

**正确性证明**：

对于任何全 1 矩形，其底边在某一行 i。设其下边界为第 i 行，左右边界为 [l, r]，高度为 h。（h 即矩形内所有列的 height 的最小值。）

矩形面积 = h × (r − l + 1)。

如果固定底边行 i，那么每个候选矩形对应直方图中的一个区间，其高度等于该区间内 height 的最小值。而直方图最大矩形算法枚举每个柱子 j 作为"高度"（即该矩形的高度等于 height[j]），并找到左右第一个比它矮的柱子，这样 height[j] 就恰好是 [L[j]+1, R[j]−1] 这个区间内的最小高度。因此对于每个柱子 j，我们找到了以 height[j] 为高、且宽度尽可能大的矩形，这个矩形的面积就是 height[j] × (R[j] − L[j] − 1)。

既然每个矩形都有唯一一个"决定其高度"的最矮柱子，那么所有候选矩形都会被枚举到。取 max 即得该行上最大全 1 矩形面积。

复杂度 O(NM)（每行 O(M)）。

**注意**：N,M ≤ 2000，NM ≤ 4×10⁶，O(NM) 完全可行。

### 2.5 综合答案

我们在 B 上跑上述两个子问题，得到 ans1_sq, ans1_rec；
再在 B 的补矩阵 C[i][j] = 1 − B[i][j] 上跑一次，得到 ans2_sq, ans2_rec。

最终答案：
- 最大正方形面积 = max(ans1_sq², ans2_sq²)
- 最大矩形面积 = max(ans1_rec, ans2_rec)

## 三、模式总结（按思维顺序）

```
- 探索等价结构 —— 棋盘交替色 ↔ i+j 奇偶决定期望颜色
- 构造变换 —— B[i][j] = A[i][j] XOR ((i+j)&1)，将棋盘子矩阵等价为全等子矩阵
- 归约为经典问题 —— 求全 1 最大正方形 + 全 1 最大矩形
- 经典 DP —— 最大正方形：dp[i][j]=1+min(dp[i-1][j],dp[i][j-1],dp[i-1][j-1])
- 经典单调栈 —— 直方图最大矩形：每行做一次单调栈，栈维护严格递增的 height
- 对称处理 —— 对 B 和 1−B 各做一遍，取 max
```

## 四、真正的解题方案（含符号说明）

### 4.1 符号表

| 符号 | 含义 | 初始值 |
|------|------|--------|
| N,M | 矩阵行数、列数 | 读入 |
| A[N][M] | 原始 01 矩阵 | 读入 |
| B[N][M] | 变换矩阵：B[i][j] = A[i][j] XOR ((i+j)&1) | 由 A 计算 |
| h[M] | 当前行的直方图高度 | 全 0 |
| dp[N][M] | 最大正方形 DP 表 | 全 0 |
| L[M], R[M] | 单调栈得到的左右边界 | — |
| stk[M] | 单调栈（存下标） | — |
| ans_sq | 最大正方形面积 | 0 |
| ans_rec | 最大矩形面积 | 0 |

### 4.2 算法步骤

1. 读入 N, M 和 A 矩阵。
2. 构造变换矩阵 B：遍历每个格子，B[i][j] = A[i][j] ^ ((i+j) & 1)。
3. 定义函数 `solve(B)`，内部完成：
   - **最大正方形**：DP 扫描，dp[i][j] 按转移式计算，更新 ans_sq = max(ans_sq, dp[i][j]²)。
   - **最大矩形**：
     - 维护高度数组 h[M]（初始全 0）。
     - 逐行 i：
       - 更新 h[j]：若 B[i][j] == 0 则 h[j] = 0，否则 h[j]++。
       - 用单调栈求每个 j 的 L[j] 和 R[j]。
       - 对每个 j 计算 area = h[j] × (R[j]−L[j]−1)，更新 ans_rec = max(ans_rec, area)。
   - 返回 {ans_sq, ans_rec}。
4. 第一次调用 `solve(B)` 得到 {sq1, rec1}。
5. 对 B 取补：C[i][j] = 1 − B[i][j]。
6. 第二次调用 `solve(C)` 得到 {sq2, rec2}。
7. 输出 max(sq1, sq2) 和 max(rec1, rec2)。

### 4.3 复杂度与验证

- 时间复杂度：O(NM)。扫描两遍，每遍 O(NM) + 每行单调栈 O(M)，NM × 常数。
- 空间复杂度：O(NM) 存储矩阵。如果读入时直接变换可省去 A 数组，但不需要。
- N,M ≤ 2000，NM = 4×10⁶，运算量约 10⁷ 级别，C++ 轻松通过。

## 五、示例代码

```cpp
// https://www.luogu.com.cn/problem/P1169

#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2005};

int n,m,a[mxn][mxn],b[mxn][mxn];
int dp[mxn][mxn];
int h[mxn],L[mxn],R[mxn],stk[mxn];

int ans_sq,ans_rec;

void solve(int B[][mxn])
{
	// max square
	memset(dp,0,sizeof dp);
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			if(B[i][j])
			{
				int mn=min({i?dp[i-1][j]:0,j?dp[i][j-1]:0,i&&j?dp[i-1][j-1]:0});
				dp[i][j]=mn+1;
				ans_sq=max(ans_sq,dp[i][j]*dp[i][j]);
			}
	// max rectangle
	memset(h,0,sizeof h);
	for(int i=0;i<n;++i)
	{
		for(int j=0;j<m;++j)
			if(B[i][j])
				++h[j];
			else
				h[j]=0;
		// monotonic stack: left bound (first smaller to left)
		int top=0;
		for(int j=0;j<m;++j)
		{
			while(top&&h[stk[top-1]]>=h[j])
				--top;
			L[j]=top?stk[top-1]:-1;
			stk[top++]=j;
		}
		top=0;
		for(int j=m-1;j>=0;--j)
		{
			while(top&&h[stk[top-1]]>=h[j])
				--top;
			R[j]=top?stk[top-1]:m;
			stk[top++]=j;
		}
		for(int j=0;j<m;++j)
			ans_rec=max(ans_rec,h[j]*(R[j]-L[j]-1));
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			cin>>a[i][j];

	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			b[i][j]=a[i][j]^((i+j)&1);

	solve(b);
	for(int i=0;i<n;++i)
		for(int j=0;j<m;++j)
			b[i][j]^=1;
	solve(b);

	cout<<ans_sq<<'\n'<<ans_rec<<'\n';
	return 0;
}
```
