# P1803 凌乱的yyy / 线段覆盖

> 难度：普及- · 标签：贪心、排序、模拟

## 1. 重新读题
### 1.1 问题重述（人话版）

有 \(n\) 场比赛，第 \(i\) 场占用时间区间 \([a_i,b_i]\)，\(a_i<b_i\)。一场比赛一旦参加就必须从头到尾打完，同一时刻不能身处两场比赛。问最多能参加几场。

### 1.2 关键约束与规模暗示

- \(1\le n\le 10^6\)，\(0\le a_i<b_i\le 10^6\)。\(n=10^6\) 排除 \(O(n^2)\) 的区间 DP，只剩排序后线性扫描这一档。
- 样例 `0 2` 与 `2 4` 的答案是 2：结束时刻和下场开始时刻可以相同。相容条件是「下一场的开始 \(\ge\) 上一场的结束」，不是严格大于。
- 时间从 0 起，不能把「当前结束时刻」初值设成一个正数把第一场滤掉。

## 2. 思维链（Chain-of-thought）

把每场比赛看成闭区间。两场相容当且仅当一个的开始 \(\ge\) 另一个的结束（否则时间轴上有交）。

**引理 1（按结束时刻贪心不比任何方案差）**

把所有区间按结束时刻从早到晚排序，得到 \(g_1,g_2,\ldots\)。从左到右扫描：维护已经选定的最后一场的结束时刻 `cur`（一开始是 \(-1\)，因为最早的开始时刻是 0）。遇到 \(a\ge cur\) 就选它，并把 `cur` 改成它的结束时刻。设选出的集合为 \(G\)。则对任意相容集合 \(O\)，\(|G|\ge |O|\)。

**证明**（交换论证，归纳「贪心的结束时刻不晚于最优的结束时刻」）：

把 \(O\) 也按结束时刻排成 \(o_1,o_2,\ldots,o_t\)。它们两两相容，所以 \(a(o_{k+1})\ge b(o_k)\)。

断言：\(G\) 至少能选出 \(t\) 场，并且第 \(k\) 场 \(g^{(k)}\) 的结束时刻 \(b(g^{(k)})\le b(o_k)\)。

- \(k=1\)：\(g^{(1)}\) 是全体里结束最早的那场（排序后第一个被选中；它的开始 \(\ge -1\) 恒真，所以一定会被选）。因此 \(b(g^{(1)})\le b(o_1)\)。
- 若断言对 \(k\) 成立，则 \(a(o_{k+1})\ge b(o_k)\ge b(g^{(k)})\)。也就是说，在贪心刚刚选定第 \(k\) 场之后，\(o_{k+1}\) 仍然是一个合法候选。贪心下一步选的是「开始 \(\ge b(g^{(k)})\) 的区间里结束最早的那场」，它的结束时刻不会晚于这个候选 \(o_{k+1}\)。所以第 \(k+1\) 场存在，且 \(b(g^{(k+1)})\le b(o_{k+1})\)。

归纳走到 \(k=t\)，说明 \(|G|\ge t=|O|\)。\(O\) 任意，故 \(G\) 最优。\(\square\)

结束时刻相同的区间谁先谁后不影响证明：候选集合里「结束最早」可以任取一个，断言里用的是 \(\le\)，取等号照样传递。

**引理 2（扫描时用 \(\ge\) 而不是 \(>\)）**

相容的定义必须是 \(a_{next}\ge b_{prev}\)。

**证明**：样例区间 \([0,2]\) 与 \([2,4]\) 同时参加是唯一能得到 2 的方案（\([1,3]\) 与另外两场都相交）。若代码写成 `a>cur`，这两场会被判冲突，样例输出变成 1，与题面不符。引理 1 的证明里用的也是 \(a(o_{k+1})\ge b(o_k)\)，与这个边界一致。\(\square\)

## 3. 模式总结（Pattern Summary）

- **explore its property** — 结束越早，留给后面的时间轴越长。
- **exchange argument** — 最优解的第 \(k\) 场不会比贪心第 \(k\) 场更早结束，所以贪心场数够用。
- **classic problem solution** — 按右端点排序后线性选取，端点相接算相容。

## 4. 真实解法
### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| \(n\) | `int` | 比赛场数 | 读入 | \(\le 10^6\) |
| `a[i].l, a[i].r` | `seg[1000005]` | 开始、结束 | 读入 | `l<r` |
| `cur` | `int` | 已选最后一场的结束时刻 | \(-1\) | 比最小开始 0 还小 |
| `ans` | `int` | 已选场数 | 0 | 输出它 |

### 4.2 算法步骤

1. 读入 \(n\) 个区间。
2. 按 `r` 升序排序。
3. `cur=-1`，从左到右：若 `l>=cur` 则 `ans++`，`cur=r`。
4. 输出 `ans`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 时间 \(O(n\log n)\)（排序），扫描 \(O(n)\)。空间 \(O(n)\)。
- 编译 `g++ -O2 -std=c++17 -Wall -Wextra`，warn=0。
- 样例 3 场输出 `2`。另 8 组边界（单场、端点相接、完全包含、三条首尾相接、全部重叠）与 300 组随机（\(n\le 16\)，对 \(2^n\) 子集枚举）共 309 组，随机段 6.548s。
- 满数据计时：\(n=10^6\)、端点在 \([0,10^6]\) 随机，标程 0.217s，答案 `1551`。

## 5. 示例代码
### 5.1 标程（`P1803.cpp`）

```cpp
//
// 题目：P1803 凌乱的yyy / 线段覆盖
// https://www.luogu.com.cn/problem/P1803
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1000005};

struct seg
{
	int l,r;
};

int n;
seg a[mxn];

bool byend(seg x,seg y)
{
	return x.r<y.r;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i].l>>a[i].r;
	sort(a,a+n,byend);
	int cur{-1};
	int ans{0};
	for(int i=0;i<n;++i)
	{
		if(a[i].l>=cur)
		{
			++ans;
			cur=a[i].r;
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```
