# P1512 [ICPC 2001 Taejon R] 伊甸园日历游戏

> 标签：搜索 / 博弈论 / 记忆化搜索 / 动态规划 DP · 难度：提高/省选-
> 本地题面：`P1512.md`（日期范围 $1900.1.1$ 至 $2006.11.3$，目标日期 $2006.11.4$）。

## 1. 重新读题

**问题重述（人话版）**

给定一个在 $1900.1.1$ 到 $2006.11.3$ 之间的初始日期 $(Y,M,D)$，Adam（先手）与 Eve（后手）轮流操作。每次操作必须从以下两个动作中二选一：

1. **日期加 $1$ 天**：按格里高利历正常顺延到下一天（月底则进位到下月 $1$ 日，年末 $12.31$ 则进位到次年 $1.1$）。
2. **月份加 $1$ 月**：保持日号 $D$ 不变，只将月份变为下一月（$12$ 月则变为次年 $1$ 月）。**前提是目标月份确实存在第 $D$ 日**；若目标月份天数小于 $D$（例如从 $1.31$ 变到不存在的 $2.31$），则该操作**非法，禁止执行**。

谁先将日期变成 **$2006.11.4$** 谁直接获胜；**超越 $2006.11.4$ 的日期不算获胜**。双方均采取最优策略，判断先手 Adam 是否有必胜策略（输出 `YES` 或 `NO`）。

> 一句话版本：**在格里高利历构成的有向无环图（DAG）上，以 $2006.11.4$ 为唯一获胜终点，做双人完全信息有限无偏博弈（Impartial Game）的必胜/必败态判定。**

**题面里容易漏掉的条款**

1. **“如果超越了指定日期不算获胜”** $\Rightarrow$ 因为两种合法操作都会让日期严格往后推，一旦某个操作跳到了 $2006.11.5$ 及之后的日期，就再也回不到 $2006.11.4$ 了。因此任何落在 $2006.11.4$ 之后的转移都是无效/自杀步，建模时直接将 $>2006.11.4$ 的目标状态视为不可走（非法转移）。
2. **格里高利历的完整闰年规则** $\Rightarrow$ 年份 $Y$ 是闰年当且仅当 $(Y\bmod 400=0)\lor(Y\bmod 4=0\land Y\bmod 100\ne 0)$。特别注意：**$1900$ 年是平年**（$2$ 月只有 $28$ 天），而 **$2000$ 年是闰年**（$2$ 月有 $29$ 天）！
3. **原题年份与洛谷题面年份的差异（2024/1/31 Hack 数据根源之一）** $\Rightarrow$ ICPC 2001 Taejon 原题及样例的终点是 $2001.11.4$，而洛谷本题将终点改成了 **$2006.11.4$**。若照搬原题代码只把 DP 表开到 $2001$ 年，遇到 $2002\sim 2006$ 年的测试点会直接越界或错判。

**数据范围与规模感受**

从 $1900.1.1$ 到 $2006.11.4$ 一共只有 $107$ 年零 $10$ 个月，总天数仅

$$39,024\text{ 天} .$$

每个日期状态至多有 $2$ 条出边（加 $1$ 天、加 $1$ 月）。这意味着整张博弈图是一个仅有 **$3.9\times 10^4$ 个顶点、不足 $7.8\times 10^4$ 条边的极小 DAG**！在读入测试数据前，按日期从 $2006.11.4$ 倒推回 $1900.1.1$ 只需不到 $1\text{ ms}$，之后每组询问 $O(1)$ 查表即可。更奇妙的是，这张表背后还隐藏着一条贯穿全区间的奇偶不变量定理（见 §2.4），既能作数学证明，又能与 DAG 逆推实现 $39,023$ 个合法日期的全量交叉互验。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把这个游戏放进博弈论坐标系

先撇开复杂的大小月和闰年，看游戏的骨架：

- 每个合法日期 $u=(Y,M,D)\le 2006.11.4$ 是一个状态；
- 两种操作 $u\to v_1$（加 $1$ 天）和 $u\to v_2$（加 $1$ 月，若目标合法且 $\le 2006.11.4$）是有向边；
- 由于每次操作都使日期严格增大，图中**不存在环**，且从任意日期出发步数有限。

**引理 1（有限 DAG 上的 N/P 态递推刻画）**

定义状态 $u=(Y,M,D)\le 2006.11.4$ 为必胜态（$\mathrm{win}[u]=\mathrm{true}$，即 N-position）当且仅当从 $u$ 出发轮到行动的玩家有必胜策略；否则为必败态（$\mathrm{win}[u]=\mathrm{false}$，即 P-position）。则：

1. **终点基例**：$\mathrm{win}[2006.11.4]=\mathrm{false}$（上一步走出 $2006.11.4$ 的对手已经获胜，当前接手 $2006.11.4$ 的玩家已经输了）；
2. **逆推转移**：对任意 $u<2006.11.4$，
   $$\mathrm{win}[u]=\mathrm{true}\iff \exists v\in\mathrm{Next}(u)\text{ 使得 }v\le 2006.11.4\text{ 且 }\mathrm{win}[v]=\mathrm{false},$$
   其中 $\mathrm{Next}(u)$ 为从 $u$ 出发执行操作 1 或合法操作 2 得到的后继日期集合。

**证明**：

- 首先验证任何 $u<2006.11.4$ 都至少有一条合法转移：因为 $u<2006.11.4$，操作 1（日期加 $1$ 天）得到的下一天 $v_1$ 必然合法且满足 $v_1\le 2006.11.4$，故当前玩家永远不会“无路可走”，也不存在被迫超越 $2006.11.4$ 的情形（若操作 2 超越了 $2006.11.4$，选操作 1 即可，而主动超越 $2006.11.4$ 永远不可能到达 $2006.11.4$ 获胜）。
- 对距离终点的剩余天数做强归纳：
  - 若存在合法后继 $v\le 2006.11.4$ 使 $\mathrm{win}[v]=\mathrm{false}$，当前玩家直接走到 $v$（若 $v=2006.11.4$ 则当场获胜；若 $v<2006.11.4$，由归纳假设对手从 $v$ 出发必败），故当前玩家必胜，$\mathrm{win}[u]=\mathrm{true}$；
  - 若所有满足 $v\le 2006.11.4$ 的合法后继都有 $\mathrm{win}[v]=\mathrm{true}$（而超越 $2006.11.4$ 的后继永不可能获胜），则无论当前玩家怎么走，都会把一个必胜态交给对手，故当前玩家必败，$\mathrm{win}[u]=\mathrm{false}$。$\blacksquare$

> **引理 1 已经给出了 $100\%$ 严密的算法**：按时间从 $2006.11.3$ 倒着一天天枚举到 $1900.1.1$，因为计算 $u$ 时它的两个后继 $v_1,v_2>u$ 都已经算完了，直接查表求或即可！

### 2.2 子任务剖析：从终点 $2006.11.4$ 往回手推最后两个月

为了看清博弈的深层规律（也为了给 DP 提供独立的理论对拍基准），我们从终点 $2006.11.4$ 往回手推：

- **$2006.11.4$**：终点，$\mathrm{P}$ 态（`false`）。
- **$2006.11.3$**：加 $1$ 天即达 $2006.11.4$（$\mathrm{P}$），故为 $\mathrm{N}$ 态（`true`）。
- **$2006.10.5\sim 2006.11.3$（封锁区）**：在这一段里，“加 $1$ 月”会跳到 $2006.11.5\sim 2006.12.3$，全部超越了终点 $2006.11.4$，因此**操作 2 全部失效，双方只能单步“加 $1$ 天”**！
  于是从 $2006.11.4$（$\mathrm{P}$）往回，胜负态严格一替一个翻转：
  - $11$ 月：$11.4(\mathrm{P}),\,11.3(\mathrm{N}),\,11.2(\mathrm{P}),\,11.1(\mathrm{N})$ —— 注意在 $11$ 月里，$(M+D)$ 为**偶数**的全是 $\mathrm{N}$ 态，为**奇数**的全是 $\mathrm{P}$ 态！
  - 跨过月底到 $10.31$：$10.31$ 加 $1$ 天是 $11.1(\mathrm{N})$，加 $1$ 月（$11.31$）非法，故 $10.31$ 是 $\mathrm{P}$ 态！而 $10+31=41$ 恰好也是**奇数**！
  - 继续在 $10$ 月往回推 $10.30,10.29,\dots,10.5$：每退一天，$D$ 减 $1$，胜负翻转一次，所以整个 $10.5\sim 10.31$ 依然满足 **“$M+D$ 为偶 $\iff \mathrm{N}$ 态，$M+D$ 为奇 $\iff \mathrm{P}$ 态”**！
- **$2006.10.4$**：加 $1$ 月直达 $2006.11.4(\mathrm{P})$，加 $1$ 天也到 $2006.10.5(\mathrm{P})$，故 $2006.10.4$ 是 $\mathrm{N}$ 态，而 $10+4=14$ 依然是**偶数**！

这一段手推揭示了一个惊人的巧合：因为 $10$ 月恰好有 **$31$（奇数）**天，月底从 $10.31$ 跨到 $11.1$ 时，$(M+D)$ 从 $10+31=41$（奇）变成 $11+1=12$（偶），奇偶性没有断层！

### 2.3 反复碰壁：纯奇偶性猜想为什么会在小月月底翻车？

顺着 §2.2 的发现，最自然的猜想是：

> **失败猜想 1**：是不是所有日期都满足“$(M+D)$ 为偶数 $\iff$ 先手必胜”？

把规则放到一般月份检验：

- **月内加 $1$ 天** $(M,D)\to(M,D+1)$：$M+D$ 增加 $1$，奇偶必翻转。
- **跨月加 $1$ 月** $(M,D)\to(M',D)$：
  - 若 $M<12$，$M'=M+1$，$M+D$ 增加 $1$，奇偶必翻转；
  - 若 $M=12$，$M'=1$，$(1+D)-(12+D)=-11\equiv 1\pmod 2$，**跨年加 $1$ 月居然也翻转奇偶**！
- **大月（$31$ 天）月底加 $1$ 天** $(M,31)\to(M',1)$：
  - 若 $M<12$，$(M+1+1)-(M+31)=-29\equiv 1\pmod 2$，奇偶翻转；
  - 若 $M=12$，$(1+1)-(12+31)=-41\equiv 1\pmod 2$，奇偶也翻转！

那哪里**不翻转**？恰恰在**非 $31$ 天的月底**（即 $30$ 天的小月 $4,6,9,11$ 月，以及 $28/29$ 天的 $2$ 月）！

**反例击穿失败猜想 1：考察 $9$ 月 $30$ 日与 $11$ 月 $30$ 日**。

- 对 $(9,30)$：$9+30=39$ 是**奇数**。但从 $(9,30)$ 执行“加 $1$ 天”会跳到 $(10,1)$，而 $10+1=11$ **也是奇数**（必败态 $\mathrm{P}$）！既然 $(9,30)$ 能一步走到必败态 $(10,1)$，那么 $(9,30)$ 必然是**必胜态 $\mathrm{N}$**！
- 同理，对 $(11,30)$：$11+30=41$ 是**奇数**，但加 $1$ 天跳到 $(12,1)$（$12+1=13$，奇数必败态 $\mathrm{P}$），故 $(11,30)$ 也必然是**必胜态 $\mathrm{N}$**！
- 为什么同为小月的 $(4,30)$ 和 $(6,30)$ 没有反常？因为 $4+30=34$、$6+30=36$ 本来就是**偶数**！它们虽然加 $1$ 天跳到 $(5,1)$、$(7,1)$（偶数，$\mathrm{N}$ 态）不能赢，但它们可以改走**操作 2（加 $1$ 月）**跳到 $(5,30)$、$(7,30)$（$5+30=35$、$7+30=37$，奇数 $\mathrm{P}$ 态）获胜，所以 $(4,30)$ 和 $(6,30)$ 依然维持偶数必胜！

> **失败猜想 2**：既然 $(9,30)$ 和 $(11,30)$ 从必败变成了必胜，那它们的前驱（如 $9.29,8.30,11.29,10.30$）会不会因为“少了一个必败后继”而发生连锁雪崩？

我们逐个检查这四个前驱：
- $(9,29)$（$9+29=38$，偶）：加 $1$ 天到 $(9,30)$（现为 $\mathrm{N}$）走不通了，但它还有**加 $1$ 月**到 $(10,29)$（$10+29=39$，奇 $\mathrm{P}$ 态）！所以 $(9,29)$ 依然是 $\mathrm{N}$ 态！
- $(8,30)$（$8+30=38$，偶）：加 $1$ 月到 $(9,30)$（$\mathrm{N}$）走不通了，但它还有**加 $1$ 天**到 $(8,31)$（$8+31=39$，奇 $\mathrm{P}$ 态）！所以 $(8,30)$ 依然是 $\mathrm{N}$ 态！
- 完全对称地，$(11,29)$ 可加 $1$ 月去 $(12,29)(\mathrm{P})$，$(10,30)$ 可加 $1$ 天去 $(10,31)(\mathrm{P})$，**反常被这四个拥有双出边的偶数前驱彻底吸收，没有向前扩散半步！**

### 2.4 完整奇偶不变量定理与 $2$ 月平闰年统一证明

把 §2.2 与 §2.3 合起来，我们证明下面的全局定理（这也是 `P1512_brute.cpp` 的理论依据）：

**引理 2（伊甸园日历博弈的全局充要判据）**

在 $1900.1.1$ 至 $2006.11.3$ 的全部 $39,023$ 个合法日期中，日期 $(Y,M,D)$ 为先手必胜态（$\mathrm{N}$ 态）当且仅当

$$\Phi(M,D):\quad (M+D)\equiv 0\pmod 2\quad\lor\quad (M=9\land D=30)\quad\lor\quad (M=11\land D=30).$$

**证明**：

按引理 1 的二分定义，只需对每个 $u=(Y,M,D)\le 2006.11.3$ 验证：

- 若 $\Phi(M,D)$ 为真，则 $u$ 存在至少一个合法后继 $v\le 2006.11.4$ 满足 $\Phi(v)$ 为假（或 $v=2006.11.4$，注意 $\Phi(11,4)=(15\text{ 为偶})=\mathrm{false}$，终点本身也符合 $\Phi=\mathrm{false}$！）；
- 若 $\Phi(M,D)$ 为假，则 $u$ 的所有满足 $v\le 2006.11.4$ 的合法后继都有 $\Phi(v)$ 为真。

分情况逐一核验：

1. **封锁区 $2006.10.5\sim 2006.11.3$**：已在 §2.2 证明，此区间内操作 2 均超越 $2006.11.4$ 而非法，仅操作 1 合法；而区间内唯一的跨月发生在 $10.31\to 11.1$（$31$ 天大月），每步操作 1 严格翻转 $(M+D)\bmod 2$，且区间内不含 $9.30$ 与 $11.30$，故 $\Phi$ 严格成立。
2. **一般区 $u\le 2006.10.4$ 中满足 $\Phi(M,D)=\mathrm{false}$ 的点**（此时必有 $M+D$ 为奇数，且 $(M,D)\notin\{(9,30),(11,30)\}$）：
   - **考察操作 2（加 $1$ 月）**：若合法，到达 $(M',D)$，其中 $M'=(M\bmod 12)+1$。由 §2.3 知 $(M'+D)\equiv (M+D)+1\equiv 0\pmod 2$，故 $\Phi(M',D)=\mathrm{true}$。
   - **考察操作 1（加 $1$ 天）**：
     - 若 $D<\mathrm{dim}(Y,M)$（非月底），到达 $(M,D+1)$，$M+D+1$ 为偶数，故 $\Phi=\mathrm{true}$；
     - 若 $D=\mathrm{dim}(Y,M)$（月底），因为 $M+D$ 为奇数且已排除 $(9,30),(11,30)$：
       - 若为 $31$ 天大月（$D=31$，故 $M\in\{8,10,12\}$），下月 $1$ 日为 $M'\in\{9,11,1\},D'=1$，此时 $M'+D'$ 为偶数，故 $\Phi(M',1)=\mathrm{true}$；
       - 若为 $30$ 天小月（$D=30$），$M+30$ 为奇数要求 $M$ 为奇数，即 $M\in\{9,11\}$，但这正是已被单独划入 $\Phi=\mathrm{true}$ 的 $(9,30),(11,30)$，不在本分支内；
       - 若为 $2$ 月月底（$M=2$），$2+D$ 为奇数意味着 **$D=29$（闰年 $2$ 月 $29$ 日）**！此时加 $1$ 天到达 $(3,1)$（$3+1=4$，偶，$\Phi=\mathrm{true}$），加 $1$ 月到达 $(3,29)$（$3+29=32$，偶，$\Phi=\mathrm{true}$），两个后继全在 $\Phi=\mathrm{true}$ 中！
   - 因此，所有 $\Phi=\mathrm{false}$ 的状态，其全部合法后继均落在 $\Phi=\mathrm{true}$ 中。✓
3. **一般区 $u\le 2006.10.4$ 中满足 $\Phi(M,D)=\mathrm{true}$ 的点**：
   - **反常点 $(9,30)$ 与 $(11,30)$**：操作 1（加 $1$ 天）分别到达 $(10,1)$ 与 $(12,1)$，二者 $M'+D'$ 均为奇数且非月底，故 $\Phi=\mathrm{false}$。✓
   - **正常偶数点（$M+D$ 为偶数）**：
     - 若 $D<\mathrm{dim}(Y,M)$ 且 $(M,D+1)\notin\{(9,30),(11,30)\}$：直接走操作 1（加 $1$ 天）到 $(M,D+1)$，其 $M+D+1$ 为奇数且非反常点，故 $\Phi=\mathrm{false}$。✓
     - 若 $(M,D)\in\{(9,29),(11,29)\}$（即加 $1$ 天会撞上反常点）：改走**操作 2（加 $1$ 月）**，分别到达 $(10,29)$ 与 $(12,29)$（$10,12$ 月均有 $31\ge 29$ 天，操作 2 合法），其和为 $39,41$（奇，非反常点），故 $\Phi=\mathrm{false}$。✓
     - 若 $D=\mathrm{dim}(Y,M)$（偶数月底）：
       - 对 $31$ 天大月的偶数月底（$D=31$，故 $M\in\{1,3,5,7\}$）：走操作 1（加 $1$ 天）到 $(M+1,1)$，此时 $(M+1)+1=M+2$ 为奇数，且 $D'=1\ne 30$，故 $\Phi=\mathrm{false}$。✓
       - 对 $30$ 天小月的偶数月底（$D=30$，故 $M\in\{4,6\}$）：它们的下一月 $5$ 月、$7$ 月均为 $31$ 天大月，故**操作 2（加 $1$ 月）合法**，分别到达 $(5,30)$ 与 $(7,30)$，和为 $35,37$（奇，非反常点），故 $\Phi=\mathrm{false}$。✓
       - 对 $2$ 月的 $D=28$（$2+28=30$，偶）：无论平年还是闰年，$3$ 月都有 $31\ge 28$ 天，故**操作 2（加 $1$ 月）到 $(3,28)$ 恒合法**！而 $3+28=31$ 为奇数且非反常点，故 $\Phi(3,28)=\mathrm{false}$（闰年时走操作 1 到 $(2,29)$ 同样也是 $\Phi=\mathrm{false}$）。✓
- 全部情形闭合，归纳成立。$\blacksquare$

> **为什么我们标程仍然写 DAG 逆推 DP，而把引理 2 作为对拍基准？**
> 因为 DAG 逆推只需要 $39,024$ 步循环，既不需要手写任何特判，也能天然防御“终点日期如果被改动”或“输入刚好落在 $2006.11.4$ 当天”的边界情况；而引理 2 给出了极其深刻的结构解释，两者在全部 $39,023$ 个合法日期上 $100\%$ 吻合，形成了双保险！

## 3. 模式总结（Pattern Summary）

按实际思考顺序列出本题的可迁移模式：

- **explore its property（博弈图 DAG 化）** — 把日历操作翻译成有限有向无环图上的双人无偏博弈，确认状态总数仅 $3.9\times 10^4$、每个状态出度 $\le 2$（引理 1）。
- **classic problem solution（博弈态逆推 DP）** — 从终点 $2006.11.4$（必败态 $\mathrm{P}$）按日期倒序递推全表：存在一个必败后继即为必胜（$\mathrm{N}$），后继全必胜则为必败（$\mathrm{P}$）。
- **consider easier version（终点前单通道退化）** — 先分析 $2006.10.5\sim 2006.11.3$ 的单步退化区，发现 $(M+D)$ 奇偶交替规律，并注意到 $10$ 月有 $31$ 天恰好衔接了跨月奇偶性。
- **failed attempt（纯奇偶猜想）** — 试图直接用 $(M+D)\bmod 2=0$ 判胜，在小月月底 $9.30\to 10.1$ 与 $11.30\to 12.1$ 处因“加 $1$ 天不改变奇偶”而被击穿。
- **anomaly absorption（反常点吸收证明）** — 证明 $(9,30)$ 与 $(11,30)$ 翻转为必胜态后，其四个偶数前驱 $(9,29),(8,30),(11,29),(10,30)$ 均可借由另一条出边跳向必败态，且 $2.28$ 可借由 $+1$ 月跳向 $3.28$，从而严格证出全局不变量（引理 2）。

| `win[y][m][d]` | `bool [2010][15][35]` | 从日期 `y.m.d` 出发先手是否必胜 | 全 `false` | 引理 1 |
| `isLeap(y)` | 函数 `bool` | 判定年份 `y` 是否为格里高利历闰年 | — | 四年一闰，百年不闰，四百年再闰 |
| `dim(y,m)` | 函数 `int` | 返回 `y` 年 `m` 月的实际天数 | — | days in month |
| `validTarget(y,m,d)` | 函数 `bool` | 判定目标日期是否存在且 $\le 2006.11.4$ | — | 过滤非法日与超界日 |

### 4.2 编号步骤

1. **预处理 `ini()`**：
   - 1.1 置终点 `win[2006][11][4] = false`。
   - 1.2 令游标 `(y, m, d)` 从 `(2006, 11, 3)` 按日历逐日倒退至 `(1900, 1, 1)`：
     - 计算操作 1（加 $1$ 天）的后继 `(y1, m1, d1)`：若 `d + 1 > dim(y, m)` 则进位到下月 $1$ 日（$12$ 月则进位到次年 $1$ 月 $1$ 日）；若 `validTarget(y1, m1, d1) && !win[y1][m1][d1]`，标记当前状态 `w = true`。
     - 计算操作 2（加 $1$ 月）的后继 `(y2, m2, d2)`：`m2 = m + 1, d2 = d`（若 `m2 > 12` 则 `m2 = 1, y2 = y + 1`）；若 `validTarget(y2, m2, d2) && !win[y2][m2][d2]`，标记 `w = true`。
     - 写入 `win[y][m][d] = w`，然后将 `(y, m, d)` 向前退一天。
2. **处理询问**：读入组数 `t`，对每组 `(y, m, d)` 直接查表输出 `win[y][m][d] ? "YES\n" : "NO\n"`。

### 4.3 复杂度

- **时间**：预处理遍历 $39,023$ 个日期，每步 $O(1)$，耗时 $<0.5\text{ ms}$；单次查询 $O(1)$。总时间复杂度 $O(\text{总天数}+t)$。
- **空间**：`bool win[2010][15][35]` 仅占约 $1.05\text{ MB}$，远低于 $512\text{ MB}$ 限制。

## 5. 示例代码

### 5.1 主解：DAG 逆推博弈 DP

```cpp
//
// 题目：P1512 [ICPC 2001 Taejon R] 伊甸园日历游戏
// https://www.luogu.com.cn/problem/P1512
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxy{2010};          // 年份上界 2006 (+松弛)
constexpr int md[13]{0,31,28,31,30,31,30,31,31,30,31,30,31};

bool win[mxy][15][35];            // win[y][m][d]=从 y.m.d 出发先手是否必胜

bool isLeap(int y){return y%400==0||(y%4==0&&y%100!=0);}
int dim(int y,int m){return m==2?28+isLeap(y):md[m];}

// 判断日期是否在目标 2006.11.4 之前(含 2006.11.4)
bool validTarget(int y,int m,int d)
{
	if(d>dim(y,m))
		return false;
	return tie(y,m,d)<=make_tuple(2006,11,4);
}

void ini()
{
	// 终点 2006.11.4: 上一步走到的玩家已获胜, 当前轮到的玩家处于必败态(false)
	win[2006][11][4]=false;
	int y=2006,m=11,d=3;
	while(true)
	{
		bool w=false;
		// 操作 1: 天数 +1 (月底则进位到下月 1 日)
		int y1=y,m1=m,d1=d+1;
		if(d1>dim(y1,m1))
		{
			d1=1;
			if(++m1>12)
				m1=1,++y1;
		}
		if(validTarget(y1,m1,d1)&&!win[y1][m1][d1])
			w=true;

		// 操作 2: 月份 +1 (日号不变, 若目标月无该日或超界则非法)
		int y2=y,m2=m+1,d2=d;
		if(m2>12)
			m2=1,++y2;
		if(validTarget(y2,m2,d2)&&!win[y2][m2][d2])
			w=true;

		win[y][m][d]=w;
		if(y==1900&&m==1&&d==1)
			break;
		if(--d==0)
		{
			if(--m==0)
				m=12,--y;
			d=dim(y,m);
		}
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	ini();
	int t;
	if(!(cin>>t))
		return 0;
	for(int i=0,y,m,d;i<t;++i)
	{
		cin>>y>>m>>d;
		cout<<(win[y][m][d]?"YES\n":"NO\n");
	}
	return 0;
}
```
