# P1219 [USACO1.5] 八皇后 Checker Challenge 题解

## Part 1: 重述问题

给定一个 $n \times n$ 的棋盘（$6 \le n \le 13$），放置 $n$ 个棋子，使得：
- 每行恰好一个棋子
- 每列恰好一个棋子
- 每条对角线（两个方向的所有平行对角线）上至多一个棋子

用一个长度为 $n$ 的序列 $p_1 p_2 \cdots p_n$ 描述一个解：$p_i$ 表示第 $i$ 行棋子所在的列号（$1$-based）。

要求：输出前 $3$ 个解（按字典序排列），最后一行输出解的总个数。

**约束**：$6 \le n \le 13$。解的总数最多为 $n=13$ 时的 $73712$ 个，$n! = 13! \approx 6.2 \times 10^9$，因此不可能全排列枚举，需要剪枝。

## Part 2: 思考过程（链式推理）

### 2.1 探索性质：约束的代数化

首先把"每行恰好一个"这个约束吸收进表示中。既然每行恰好一个棋子，那么一个解完全由序列 $p_1, p_2, \ldots, p_n$ 确定，其中 $p_i \in \{1, 2, \ldots, n\}$ 表示第 $i$ 行的棋子放在第 $p_i$ 列。

"每列恰好一个"等价于 $p$ 是 $\{1, 2, \ldots, n\}$ 的一个**排列**。

"对角线上至多一个棋子"需要展开。棋盘上两条方向的斜对角线：
- 主对角线方向（左上到右下）：$(i, p_i)$ 在这条对角线上 $\iff i - p_i = \text{常数}$
- 副对角线方向（右上到左下）：$(i, p_i)$ 在这条对角线上 $\iff i + p_i = \text{常数}$

因此两个棋子 $(i, p_i)$ 和 $(j, p_j)$ 在同一条主对角线上 $\iff p_i - i = p_j - j$，在副对角线上 $\iff p_i + i = p_j + j$。

所以完整的约束是：$p$ 是 $[n]$ 的排列，且对所有 $i \ne j$，$p_i - i \ne p_j - j$ 且 $p_i + i \ne p_j + j$。

**引理 1**（对角线冲突的充要条件）。设 $1 \le i < j \le n$。棋子 $(i, p_i)$ 与 $(j, p_j)$ 在同一主对角线上当且仅当 $p_j - p_i = j - i$；在同一副对角线上当且仅当 $p_j - p_i = -(j - i)$。

**证明**：
- 主对角线：$p_i - i = p_j - j \iff p_j - p_i = j - i$。
- 副对角线：$p_i + i = p_j + j \iff p_j - p_i = -(j - i)$。
- 由于 $i \ne j$，$j - i \ne 0$，所以 $j - i \ne -(j - i)$，两种冲突不可能同时发生（除非 $i = j$，已被排除）。$\square$

引理 1 把"对角线不冲突"翻译成了逐对比较 $p_j - p_i$ 与 $j - i$ 的关系，非常适合在逐行放置时增量检查。

### 2.2 考虑更简单的版本：逐行放置 + 回溯

既然每行恰好一个棋子，我们可以按行号 $i = 1, 2, \ldots, n$ 的顺序依次决定 $p_i$。放置第 $i$ 行的棋子时，只需检查它与前面 $i - 1$ 个已放置棋子是否冲突。

**为什么逐行放置能产生字典序**：我们在第 $i$ 行按列号从小到大枚举 $p_i$，且先确定前面的行，所以 DFS 的叶子节点恰好按 $p_1, p_2, \ldots, p_n$ 的字典序产生。

**为什么逐行放置不会漏解**：每个解有唯一的 $p$ 序列，DFS 会枚举所有满足约束的 $p$ 序列。因为"每行一个"被吸收进了表示，"每列一个"被 $p$ 是排列这一条件保证，"对角线"被逐对检查保证，所以 DFS 的每个叶子恰好对应一个合法解，且每个合法解恰好被找到一次。

**引理 2**（剪枝的正确性）。在第 $i$ 行放置棋子于列 $c$ 时，若 $\exists\, j < i$ 使得 $|p_j - c| = |j - i|$，则该分支不可能延伸为合法解，应剪掉。

**证明**：若 $|p_j - c| = |j - i|$，则 $c - p_j = \pm(i - j)$，由引理 1，$(j, p_j)$ 与 $(i, c)$ 在同一斜对角线上，违反对角线约束。反之，若 $\forall\, j < i,\ |p_j - c| \ne |j - i|$，则 $(i, c)$ 与所有已放置棋子都不在同一对角线上，放置是合法的（列冲突由 $c$ 未出现在 $p_1, \ldots, p_{i-1}$ 中排除）。$\square$

### 2.3 经典问题方案：N  皇后 + 布尔标记数组加速

逐对检查需要 $O(i)$ 时间（检查前面 $i - 1$ 个棋子），总复杂度为 $O(n!) \cdot O(n) = O(n \cdot n!)$，对 $n = 13$ 来说 $13 \cdot 13! \approx 6 \times 10^{10}$ 太慢（实际上由于剪枝，远没有这么多节点，但我们可以做得更好）。

经典优化：用三个布尔数组分别标记"列被占""主对角线被占""副对角线被占"。

- 列 $c$ 被占：`col[c] = true`
- 主对角线 $d_1 = i - c$ 被占：范围 $[1-n, n-1]$，偏移 $n - 1$ 后范围 $[2 - n, 2n - 2]$ 不对，让我重算。$i \in [1, n]$，$c \in [1, n]$，$i - c \in [1 - n, n - 1]$，偏移 $(n - 1)$ 后范围 $[2 - n, 2n - 2]$……不对。$i - c$ 最小为 $1 - n$，最大为 $n - 1$。加上偏移 $n - 1$：最小为 $1 - n + (n - 1) = 0$，最大为 $n - 1 + (n - 1) = 2n - 2$。所以主对角线编号 $d_1 = i - c + n - 1 \in [0, 2n - 2]$。
- 副对角线 $d_2 = i + c$ 被占：范围 $[2, 2n]$，编号 $d_2 = i + c \in [2, 2n]$，直接用 $i + c$ 作下标。

检查与标记都是 $O(1)$，总复杂度降到 $O(n!)$（每个节点 $O(1)$ 工作，共 $O(n!)$ 个节点——实际上因剪枝远少于 $n!$）。

**引理 3**（标记数组的正确性）。在第 $i$ 行尝试列 $c$ 时，`col[c]`、`diag1[i - c + n - 1]`、`diag2[i + c]` 三个标记都为 `false` 当且仅当 $(i, c)$ 与所有已放置棋子不冲突。

**证明**：
- **充分性**：若三个标记都为 `false`，则列 $c$ 未被占（列不冲突），主对角线 $i - c$ 未被占（不存在 $j < i$ 使 $p_j - j = c - i$，即 $p_j - c \ne j - i$），副对角线 $i + c$ 未被占（不存在 $j < i$ 使 $p_j + j = c + i$，即 $p_j - c \ne -(j - i)$）。由引理 1，$(i, c)$ 与所有已放置棋子既不同列也不同对角线。
- **必要性**：若 $(i, c)$ 与某个已放置棋子 $(j, p_j)$ 冲突，则 $p_j = c$（列冲突，`col[c] = true`）或 $|p_j - c| = |j - i|$（对角线冲突，由引理 1 等价于 $p_j - j = c - i$ 即 `diag1[c - i + n - 1] = true`，或 $p_j + j = c + i$ 即 `diag2[c + i] = true`）。$\square$

### 2.4 复杂度分析

DFS 树的第 $i$ 层最多有 $P(n, i) = n!/(n - i)!$ 个节点（前 $i$ 行的排列数），但因对角线剪枝，实际远少于此。总节点数 $S(n) \le \sum_{i=0}^{n} P(n, i) < e \cdot n!$。

$n = 13$ 时 $e \cdot 13! \approx 2.7 \times 6.2 \times 10^9 \approx 1.7 \times 10^{10}$，但实际因剪枝 $S(13)$ 约为 $3 \times 10^8$ 量级，每个节点 $O(1)$ 工作，总时间 $O(S(n))$，在 1s 内可完成。

**验证**：$n = 8$ 时有 $92$ 个解，$n = 13$ 时有 $73712$ 个解。DFS 会遍历所有部分解（包括不完整的），总节点数约 $3 \times 10^8$，C++ 下每秒可处理约 $10^8$ 节点，因此 $n = 13$ 约 $0.3$ 秒。

## Part 3: 模式总结

```
- explore its property — 把"每行一个"吸收进序列表示，把对角线冲突翻译成 i±c 的等值
- consider easier version — 逐行 DFS 回溯，逐对检查冲突，正确但 O(n·n!)
- classic problem solution — N皇后经典三标记数组（列/主对角/副对角），检查降到 O(1)
- defer reconstruction — 解的序列在 DFS 栈中自然形成，无需额外重建
```

## Part 4: 真正解法

### 符号表

| 符号 | 含义 | 初始化 | 记忆 |
|------|------|--------|------|
| `n` | 棋盘大小 | 读入 | 行/列数 |
| `p[i]` | 第 $i$ 行棋子所在的列（$1$-based） | $0$ | 当前部分解 |
| `col[c]` | 列 $c$ 是否已被占 | `false` | C = column |
| `dg1[k]` | 主对角线 $k = i - c + n - 1$ 是否已被占 | `false` | 左上→右下 |
| `dg2[k]` | 副对角线 $k = i + c$ 是否已被占 | `false` | 右上→左下 |
| `cnt` | 已找到的解的总个数 | $0$ | 计数 |
| `top3[3][n+1]` | 前 $3$ 个解 | $0$ | 存前三解 |

**对角线编号约定**（$i, c$ 均为 $1$-based）：
- 主对角线：$i - c \in [1 - n, n - 1]$，加偏移 $n - 1$ 得 $[0, 2n - 2]$，数组大小 $2n$。
- 副对角线：$i + c \in [2, 2n]$，数组大小 $2n + 1$。

### 算法步骤

1. 读入 $n$。
2. 调用 `dfs(1)`，从第 $1$ 行开始逐行放置。
3. `dfs(i)`：
   - **若 $i > n$**：找到一个完整解。`cnt++`。若 `cnt ≤ 3`，把当前 `p[1..n]` 存入 `top3[cnt]`。返回。
   - **否则**：对 $c = 1, 2, \ldots, n$ 依次尝试：
     - 若 `col[c]` 或 `dg1[i - c + n - 1]` 或 `dg2[i + c]` 为 `true`，跳过。
     - 否则：`p[i] = c`；置 `col[c] = dg1[i - c + n - 1] = dg2[i + c] = true`；递归 `dfs(i + 1)`；回溯：置 `col[c] = dg1[i - c + n - 1] = dg2[i + c] = false`。
4. 输出 `top3[1]`、`top3[2]`、`top3[3]`（若 `cnt < 3` 则只输出实际有的）。
5. 输出 `cnt`。

### 复杂度

- 时间：$O(S(n))$，其中 $S(n)$ 为 DFS 访问的节点总数，$S(n) \le e \cdot n!$。$n = 13$ 时约 $3 \times 10^8$，约 $0.3$ 秒。
- 空间：$O(n)$（递归栈 + 三个标记数组 + 解数组）。

### 验证

- $n = 6$：解总数 $4$，前三解 `1 3 5 2 6 4` / `1 4 6 2 3 5` / `2 4 6 3 5 1`。
- $n = 8$：解总数 $92$（经典八皇后）。
- $n = 13$：解总数 $73712$。

## Part 5: C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int n;
int p[15];
bool col[15],dg1[30],dg2[30];
int cnt=0;
int top3[4][15];

void dfs(int r)
{
	if(r>n)
	{
		cnt++;
		if(cnt<=3)
			for(int i=1;i<=n;++i)
				top3[cnt][i]=p[i];
		return;
	}
	for(int c=1;c<=n;++c)
	{
		if(col[c]||dg1[r-c+n-1]||dg2[r+c])
			continue;
		p[r]=c;
		col[c]=dg1[r-c+n-1]=dg2[r+c]=true;
		dfs(r+1);
		col[c]=dg1[r-c+n-1]=dg2[r+c]=false;
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n;
	dfs(1);
	for(int i=1;i<=min(3,cnt);++i)
	{
		for(int j=1;j<=n;++j)
		{
			if(j>1)
				cout<<' ';
			cout<<top3[i][j];
		}
		cout<<'\n';
	}
	cout<<cnt<<'\n';
	return 0;
}
```
