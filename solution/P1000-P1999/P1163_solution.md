# P1163 银行贷款

---

## Part 1: 重新读题（简化版）

一个人从银行贷款 `w0` 元，之后每个月月底固定还 `w` 元，连续还 `m` 个月，**恰好**把本息全部还清。利率按月复利计算。求月利率，用百分数表示，四舍五入精确到 `0.1%`。

用简单的话说：

- 期初欠款 = `w0`
- 每个月：欠款先按"月利率"涨一次利息，再减掉这个月的还款 `w`
- `m` 个月之后，欠款刚好归零
- 求这个月利率

数据范围：

- `1 <= w0, w <= 2^31 - 1`
- `1 <= m <= 3000`
- 答案保证不超过 `300.0%`

---

## Part 2: 思维链（发现过程）

### 2.1 先把"模拟还款"翻译成数学

给定一个猜测的月利率 `x`（小数，比如 0.029 表示 2.9%），我们可以直接模拟：

```
bal = w0
重复 m 次:
    bal = bal * (1 + x) - w
```

- 如果最后 `bal <= 0`：说明这个利率下还得完（甚至多还了一点）。
- 如果最后 `bal > 0`：说明这个利率太高，还不起。

一开始我可能想直接解方程。把展开写一下：

```
bal(1) = w0(1+x) - w
bal(2) = w0(1+x)^2 - w(1+x) - w
...
bal(m) = w0(1+x)^m - w * ((1+x)^(m-1) + ... + 1)
```

这是一个关于 `(1+x)^m` 的表达式，而 `m` 最大是 3000，根本没办法直接求根。**这条路走不通。**

### 2.2 发现单调性 → 二分

注意一个直觉：**利率越高，欠款滚得越快，同样的月供最后剩下的欠款越多**，所以"最后余额"和利率是单调的，可以二分。

不过不能只凭直觉，需要严格证明。用"现值"来看就清楚了：每一期还的 `w` 元，折算到现在的价值是：

```
w/(1+x),  w/(1+x)^2,  ... ,  w/(1+x)^m
```

把这些加起来，应该恰好等于贷款总额 `w0`：

```
w0 = w/(1+x) + w/(1+x)^2 + ... + w/(1+x)^m
```

#### 引理 1：现值总和关于 `x` 严格递减

定义

```
f(x) = sum_{t=1}^{m} w/(1+x)^t - w0
```

因为 `x > -1` 时，`1+x > 0`，所以每一项 `w/(1+x)^t` 都随 `x` 增大而严格变小。有限个严格递减项之和还是严格递减，所以 `f(x)` 是**严格递减的连续函数**。

#### 引理 2：模拟判定的方向

把上面的模拟结果和 `f` 联系起来。等比数列求和再变形：

```
bal(m) = w0(1+x)^m - w * [(1+x)^m - 1] / x
```

而

```
f(x) = w * [1 - (1+x)^(-m)] / x - w0
     = -(1+x)^(-m) * [ w0(1+x)^m - w * ((1+x)^m - 1)/x ]
     = -(1+x)^(-m) * bal(m)
```

因为 `(1+x)^m > 0`，所以

```
bal(m) <= 0   ⇔   f(x) >= 0   ⇔   x 不大于真实利率
```

也就是说：**只要最后余额不为正，就说明这个利率可以接受（还清了），可以把利率再调大一点试试**。

### 2.3 二分怎么写

- 如果 `check(mid)` 为真（还得清），说明真实利率比 `mid` 大，答案在 `[mid, hi]`，把下界抬上去：`lo = mid`；
- 否则答案在 `[lo, mid]`，把上界拉下来：`hi = mid`。

区间上界取 `5`（500%）已经超过题目保证的 300%，足够安全。迭代固定次数（比如 100 次）得到任意足够精度。

### 2.4 复杂度

- `check`：模拟 `m` 次，`O(m)`。
- 二分 100 次。
- 总复杂度 `O(100 * m) <= 3 * 10^5`，随便过。

---

## Part 3: 模式总结

- 数学建模 —— 等额本息/复利还款 ⇒ 写成"每月 `bal = bal*(1+x) - w`"的递推
- 单调性 —— 抛出"能不能还清"这个判定，它关于利率单调 ⇒ 二分答案
- 浮点二分 —— 区间 `[0, 5]`，固定迭代 100 次，区间宽度 `5/2^100 ≈ 4e-30`，精度远超要求
- 输出格式 —— 百分数保留一位小数（`%.1f`）

## Part 4: 真实解法（含符号表）

### 符号表

| 符号 | 含义 |
|------|------|
| `w0` | 贷款原值（整数） |
| `w`  | 每月还款额（整数） |
| `m`  | 还款月数（整数） |
| `x`  | 二分中当前猜测的月利率（小数，1 = 100%） |
| `bal` | 模拟中的剩余欠款（double） |

### 算法步骤

1. 读入 `w0, w, m`。
2. 二分区间 `l = 0, r = 5`，迭代 100 次：
   - `mid = (l + r) / 2`
   - 用 `mid` 模拟 `m` 期：`bal = bal * (1 + mid) - w`
   - 若最后 `bal <= 0`，说明还得清，`l = mid`；否则 `r = mid`
3. 输出 `l * 100`，保留一位小数。

### 正确性说明（为什么二分最后输出的就是答案）

由引理 1、2，`check(mid)` 在 `mid <= 真实利率` 时恒为真，在 `mid > 真实利率` 时恒为假，所以 `l` 单调逼近真实利率，100 次迭代后误差小于 `5 * 2^-100`，四舍五入到 `0.1%` 稳定。

### 样例验证

输入 `1000 100 12`：

- 用 `x = 0.0291` 模拟 12 期：
  - 期初 1000
  - 每期 `bal = bal*1.0291 - 100`
  - 12 期后余额约为 `-1.04`（略小于 0，说明还得清）
- 用 `x = 0.0292` 模拟，余额约为 `+1.17`（还不起）

所以在 `[0.0291, 0.0292]` 之间，四舍五入到 `0.1%` 输出 `2.9`，与样例一致。✓

## Part 5: 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

i64 w0,w;
int m;

bool check(double x)
{
	double bal=w0;
	for(int i=0;i<m;++i)
		bal=bal*(1+x)-w;
	return bal<=0;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>w0>>w>>m;
	double l=0,r=5;
	for(int i=0;i<100;++i)
	{
		double mid=(l+r)/2;
		if(check(mid))
			l=mid;
		else
			r=mid;
	}
	printf("%.1f\n",l*100);
	return 0;
}
```
