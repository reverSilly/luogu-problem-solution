# P1965 [NOIP 2013 提高组] 转圈游戏

## 1. 重新读题

### 1.1 问题重述（人话版）

$n$ 个人编号 $0\sim n-1$，顺时针坐在编号 $0\sim n-1$ 的位置上，初始时「编号 $=$ 位置」。

每一轮，**所有位置上的人同时顺时针移动 $m$ 个位置**：位置 $p$ 上的人移动到 $(p+m)\bmod n$。因为这是一个整体平移，座位之间的相对顺序始终不变，变的只是「编号 $x$ 的人现在坐在哪个位置」。

游戏进行 $10^k$ 轮，问 $x$ 号最后所在的位置编号。

### 1.2 关键约束与规模暗示

- $1<n<10^6$，$0<m<n$，$0\le x\le n$，$0<k<10^9$。
- $30\%$ 数据 $k<7$：$10^k\le 10^6$，直接一轮一轮模拟即可。
- $80\%$ 数据 $k<10^7$：$10^k$ 根本不能模拟，但 $O(k)=10^7$ 的计算量刚好卡在及格线附近——说明正解要比 $O(k)$ 更快。
- $100\%$ 数据 $k<10^9$：必须做到 $O(\log k)$，也就是**快速幂**。
- $n$ 只有 $10^6$，所以中间乘法用 `long long` 就不会溢出；答案对 $n$ 取模。

---

## 2. 思维链（Chain-of-thought）

### 2.1 先搞清楚「一轮」到底做了什么

只看一个人。设他当前在位置 $p$。规则说「第 $p$ 号位置上的小伙伴顺时针走到第 $p+m$ 号位置」（超出 $n-1$ 就从 $0$ 绕回来），所以

$$
p\longmapsto (p+m)\bmod n .
$$

这个映射对**所有** $p$ 都一样，和这个人是谁、编号是多少完全无关。也就是说，每一轮都是把整圈人「旋转」$m$ 格。

**引理 1（$T$ 轮后的位置）**：经过 $T$ 轮，原来在位置 $x$ 的人到达位置

$$
(x+Tm)\bmod n .
$$

**证明**（对轮数归纳）：$T=0$ 时显然是 $x$。设 $T$ 轮后位置为 $(x+Tm)\bmod n$，则再走一轮：

$$
\big((x+Tm)\bmod n+m\big)\bmod n=(x+(T+1)m)\bmod n,
$$

最后一步用了「先取模再加再取模 $=$ 一起取模」这个恒等式。$\square$

于是本题就是求

$$
\big(x+10^k\cdot m\big)\bmod n .
$$

### 2.2 直接算 $10^k$ 会怎样

$10^k$ 有 $k+1$ 位十进制数，$k=10^9$ 时是十亿位数，任何整数类型都存不下，更别说做乘法。

第一反应是「边乘边取模」：让 $P=10^k\bmod n$，则 $(10^k m)\bmod n=(P\cdot m)\bmod n$。但把 $10$ 连乘 $k$ 次要 $10^9$ 次，仍然超时——$80\%$ 的 $k<10^7$ 或许能勉强跑，$100\%$ 不行。所以瓶颈从「数值太大」变成了「次数太多」。

### 2.3 快速幂：把 $10^9$ 次乘法压到 $30$ 次

$10^k$ 的本质是「$k$ 个 $10$ 相乘」。利用指数二进制拆分：

$$
10^k=\prod_{j:\ \text{第 }j\text{ 位为 }1} 10^{2^j}.
$$

于是从低位到高位扫描 $k$ 的二进制位，维护 $b_j=10^{2^j}\bmod n$（每步平方），遇到 $k$ 的当前位为 $1$ 就把答案乘上 $b_j$。循环次数是 $k$ 的二进制位数，即 $O(\log k)\le 30$。

**引理 2（模运算下平方/乘法合法）**：对任意整数 $a,b$，有

$$
(ab)\bmod n=\big((a\bmod n)(b\bmod n)\big)\bmod n .
$$

**证明**：设 $a=qn+r_a$，$b=pn+r_b$，$0\le r_a,r_b<n$。则 $ab=qpn^2+(qr_b+pr_a)n+r_ar_b$，前两项都被 $n$ 整除，所以 $ab\equiv r_ar_b\pmod n$，即 $(ab)\bmod n=(r_ar_b)\bmod n$。$\square$

由引理 2，快速幂中每一步都可以先取模，中间量始终 $<n^2\le 10^{12}$，`long long` 足够。

### 2.4 另一种想法：找循环节，为什么不如快速幂

映射 $p\mapsto(p+m)\bmod n$ 的周期是 $L=n/\gcd(n,m)$。理论上只要算出 $10^k\bmod L$，再走这么多轮即可。但：

1. 还是要算 $10^k\bmod L$，仍然要快速幂；
2. 多引入一个 $\gcd$，而且 $L$ 可能等于 $1$（$m$ 与 $n$ 不互质时），需要额外讨论。

所以直接对 $n$ 做快速幂更短、更不容易错。**注意**：不能对 $L$ 用「费马小定理」之类的做法，因为 $L$ 不一定是质数、$10$ 也未必与 $L$ 互质。

### 2.5 边界与坑点

- $k$ 用 `long long` 读（虽然 $<10^9$ 用 `int` 也够，但指数循环里 `b>>=1` 更自然）。
- $n>1$，所以 `10%n` 不是 $0$；若 $n=1$（本题不会出现），任何位置都是 $0$，需要特判。
- 最后答案再取一次模：$(x+m\cdot P)\bmod n$，其中 $P=10^k\bmod n$。
- 题面写 $0\le x\le n$，但位置编号只有 $0\sim n-1$；合法输入中 $x$ 实际是 $0\sim n-1$。即使读到 $x=n$，取模后也回到 $0$，不影响。

---

## 3. 模式总结（Pattern Summary）

- **explore its property** — 每一轮是同一个整体平移 $p\mapsto(p+m)\bmod n$，与人是谁无关。
- **reduce to easier problem** — $T$ 轮后位置为 $(x+Tm)\bmod n$，问题化成求 $10^k\bmod n$。
- **classic problem solution** — 模意义下快速幂，$O(\log k)$ 次乘法。
- **verify boundary** — 指数、模数都用 `long long` 中间量，最后统一取模。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `i64` | 人数 / 位置数 / 模数 | 读入 | 圆环长度 |
| `m` | `i64` | 每轮顺时针步数 | 读入 | move |
| `k` | `i64` | 轮数是 $10^k$ | 读入 | 指数 |
| `x` | `i64` | 被跟踪的人的初始位置 | 读入 | 起点 |
| `base` | `i64` | 当前 $10^{2^j}\bmod n$ | $10\bmod n$ | 快速幂的底 |
| `pw` | `i64` | 已累积的 $10^{\text{已处理位}}\bmod n$ | $1$ | power |
| `ans` | `i64` | 最终位置 | 计算 | 输出 |

### 4.2 算法步骤

1. 读入 $n,m,k,x$（全部用 `long long`）。
2. `pw=1`，`base=10%n`。对 `b=k` 做二进制快速幂：若 `b&1` 则 `pw=pw*base%n`；每轮 `base=base*base%n`，`b>>=1`。
3. 此时 `pw` $=10^k\bmod n$。
4. 输出 `(x+m*pw)%n`（$m<n$，`m*pw` 用 `long long` 不会溢出）。

### 4.3 复杂度分析

- **时间复杂度**：$O(\log k)$，$\log_2 10^9\approx 30$。
- **空间复杂度**：$O(1)$。

## 5. 示例代码

```cpp
//
// 题目：P1965 [NOIP 2013 提高组] 转圈游戏
// https://www.luogu.com.cn/problem/P1965
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	i64 n,m,k,x;
	cin>>n>>m>>k>>x;

	i64 base{10%n},pw{1};
	for(i64 b{k};b;b>>=1,base=base*base%n)
		if(b&1)
			pw=pw*base%n;

	cout<<(x+m*pw)%n<<'\n';
	return 0;
}
```
