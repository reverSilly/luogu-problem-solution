# P1818 电影投票

## 1. 重新读题

### 1.1 人话版

一个电影评分系统里，每张票只能投 $1\sim 10$ 的整数分。已知这部电影已经被投了 $N$ 票，且当前平均分**四舍五入保留一位小数**后显示为 $X$。XP 只能控制自己接下来投的票，他并不知道此前 $N$ 票的真实总分，只知道显示值 $X$。求：最坏情况下，XP 最少投多少票，才能保证新的平均分四舍五入保留一位小数后 $\le Y$。

### 1.2 关键约束与规模暗示

- 多组数据，读到文件尾；$1\le T\le 10^4$，$1\le N\le 10^6$，$X,Y\in[1,10]$ 且 $Y\le X$，均保留一位小数。
- 单组数据最好 $O(1)$。逐票模拟会被卡：当 $X=10.0,\ Y=1.0,\ N=10^6$ 时答案约为 $1.79\times 10^8$，乘以 $T=10^4$ 完全不可行。
- "四舍五入保留一位小数"是分段常函数，边界在 $x.x5$ 处。直接用浮点估算 $S\approx XN$ 会在边界上差一张票，必须精确化成整数不等式。

---

## 2. 思维链（Chain-of-thought）

### 2.1 explore its property：把"显示值"翻译成整数区间

设前 $N$ 票的总分为整数 $S$，显然 $N\le S\le 10N$。显示值写成 $k/10$，其中 $k=10X\in\{10,11,\dots,100\}$。

"$\frac SN$ 四舍五入保留一位小数等于 $\frac{k}{10}$" 等价于
$$
\frac{k}{10}-\frac{1}{20}\ \le\ \frac SN\ <\ \frac{k}{10}+\frac{1}{20},
$$
即
$$
\frac{2k-1}{20}\ \le\ \frac SN\ <\ \frac{2k+1}{20}.
$$

为什么左边闭、右边开？因为四舍五入是"遇到 $5$ 就进位"：

- 当 $\frac SN=\frac{k}{10}-\frac1{20}$ 时，恰好是 $\frac{k}{10}-0.05$，进位到 $\frac{k}{10}$，算显示 $\frac{k}{10}$；
- 当 $\frac SN=\frac{k}{10}+\frac1{20}$ 时，恰好是 $\frac{k}{10}+0.05$，进位到 $\frac{k+1}{10}$，**不**算显示 $\frac{k}{10}$。

于是所有与 $X$ 相容的总分构成一个整数的半开区间。

### 2.2 最坏情况：$S$ 取最大，XP 全投 $1$

**引理 1（最坏情况是 $S$ 取最大值）**
固定 XP 的票数为 $ans$、这些票的总分为 $v$。最终平均分
$$
g(S)=\frac{S+v}{N+ans}
$$
关于 $S$ 严格递增（分子分母都加同一个正数 $S$，而 $N+ans>0$ 固定），而"四舍五入"本身是单调不减函数。因此只要对区间内**最大**的 $S$ 都满足要求，对更小的 $S$ 就一定满足。

**证明**：设 $S_1<S_2$，则 $g(S_2)-g(S_1)=\frac{S_2-S_1}{N+ans}>0$。四舍五入映射 $r(x)$ 单调不减（它是阶梯函数，每一级只升不降），故 $r(g(S_2))\ge r(g(S_1))$。若 $r(g(S_{\max}))\le Y$，则所有 $S$ 都有 $r(g(S))\le r(g(S_{\max}))\le Y$。$\blacksquare$

**引理 2（XP 全投 $1$ 最优）**
固定 $ans$，XP 的票总分 $v$ 满足 $ans\le v\le 10ans$。最终平均分关于 $v$ 严格递增，所以使最终平均分最小（最有利）的取法是 $v=ans$，即每张都投 $1$。

**证明**：$g$ 对 $v$ 的偏导为 $\frac{1}{N+ans}>0$，故取 $v$ 的最小值 $ans$。因为 XP 面向的是"无论如何都成立"的保证，任何 $v>ans$ 都只会让结果更差，不可能更优。$\blacksquare$

结合两条引理：**答案就是把 $S$ 取到最大可行值 $S_{\max}$、XP 全投 $1$ 时，使最终显示 $\le Y$ 的最小票数**。

### 2.3 算出 $S_{\max}$

由 2.1，$S<\frac{(2k+1)N}{20}$，所以整数 $S$ 的最大值是
$$
S_{\max}=\left\lceil\frac{(2k+1)N}{20}\right\rceil-1
=\left\lfloor\frac{(2k+1)N-1}{20}\right\rfloor .
$$

**等式为什么成立**：对正整数 $a,b$，$\lceil a/b\rceil-1=\lfloor(a-1)/b\rfloor$。写法验证：设 $a=qb+r$，$0\le r<b$。若 $r=0$，左边 $q-1$，右边 $\lfloor(qb-1)/b\rfloor=q-1$；若 $r>0$，左边 $q$，右边 $\lfloor(qb+r-1)/b\rfloor=q$。$\blacksquare$

还要加上物理上界：$S\le 10N$。当 $X=10.0$（$k=100$）时，上式会算出略大于 $10N$ 的值（例如 $N=40$ 时为 $401$），但每票最多 $10$ 分，真实总分不可能超过 $10N$，必须取
$$
S_{\max}\leftarrow \min(S_{\max},\,10N).
$$

（不需要再和 $N$ 取 $\max$：$X\ge 1$ 时公式给出的值总不小于真实可行总分的最小值，且我们只关心最大值这一侧。）

### 2.4 把"最终显示 $\le Y$"写成严格不等式

设 $Y=l/10$。加 $ans$ 票后总分 $S_{\max}+ans$，票数 $N+ans$。最终显示 $\le Y$ 等价于
$$
\frac{S_{\max}+ans}{N+ans}<\frac{l}{10}+\frac1{20}=\frac{2l+1}{20}
\iff
20(S_{\max}+ans)<(2l+1)(N+ans).
$$

**为什么必须严格小于**：若取等号，值恰好是 $Y+0.05$，四舍五入会进位成 $Y+0.1$，不满足 $\le Y$。这正是 2.1 中"右端开"的同一回事。

### 2.5 解出 $ans$

展开 2.4 的不等式：
$$
20S_{\max}+20ans<(2l+1)N+(2l+1)ans
\iff
(19-2l)\,ans<(2l+1)N-20S_{\max}.
$$
因为 $l\ge 10$，有 $19-2l\le -1<0$，两边除以这个负数要变号：
$$
ans>\frac{20S_{\max}-(2l+1)N}{2l-19}=:q .
$$

**引理 3（可行票数构成一条上射线）**
记 $G(ans)=\frac{S_{\max}+ans}{N+ans}$，则 $G$ 关于 $ans$ 单调不增。

**证明**：
$$
G(ans+1)-G(ans)
=\frac{(S_{\max}+ans+1)(N+ans)-(S_{\max}+ans)(N+ans+1)}{(N+ans)(N+ans+1)}
=\frac{N-S_{\max}}{(N+ans)(N+ans+1)}\le0,
$$
因为 $S_{\max}\ge N$（平均分至少为 $1$）。$\blacksquare$

于是"满足要求"的 $ans$ 是 $ans>q$ 的所有正整数，最小值就是
$$
ans=\begin{cases}
1,&q<0,\\[2pt]
\lfloor q\rfloor+1,&q\ge0.
\end{cases}
$$
当 $q$ 恰为整数时也要 $+1$，因为不等式严格。实现时用整数除法实现 $\lfloor\cdot\rfloor$：`num=20*S-(2*l+1)*N`，`den=2*l-19`；若 `num<=0` 输出 $1$，否则输出 `num/den+1`。

### 2.6 精度

输入是"保留一位小数的实数"，读成 `double` 后乘 $10$ 再 `llround` 取整，就能得到 $k,l$。若用 `(int)(X*10)` 截断，$7.3$ 可能被存成 $7.2999\dots$ 而变成 $72$，答案就错了。题面也明确提醒"实数可能会有精度误差"。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 把"显示为 $k/10$"翻译成 $S$ 的半开区间，理解四舍五入在哪一侧闭合。
- **explore its property** — 最坏情况取区间内最大的 $S$；XP 全投 $1$ 使最终平均分最小。
- **reduce to easier problem** — 把"四舍五入 $\le Y$"化成一条严格线性不等式。
- **solve inequality** — 由单调性知可行解是上射线，直接得到阈值公式。
- **handle precision** — 读入乘 $10$ 后 `llround`，全程整数运算。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `X, Y` | `double` | 当前显示均分、目标均分（一位小数） | 输入 | 显示值 |
| `N` | `i64` | 已有票数 | 输入 | 张数 |
| `k, l` | `i64` | $10X$、$10Y$ | `llround` | 放大十倍的整数 |
| `S` | `i64` | 最坏情况下的已有总分 $S_{\max}$ | 公式 + `min(10N)` | sum |
| `den` | `i64` | $2l-19$（$l\ge10$ 故恒 $>0$） | $2l-19$ | 分母 |
| `num` | `i64` | $20S-(2l+1)N$ | 计算 | 分子 |
| `ans` | `i64` | 最少票数 | 阈值公式 | 输出 |

### 4.2 算法步骤

1. 读入 `X, Y, N`（循环到 EOF）。
2. `k=llround(X*10)`，`l=llround(Y*10)`。
3. 计算 `S=((2*k+1)*N-1)/20`，再取 `S=min(S,10*N)`。
4. 计算 `num=20*S-(2*l+1)*N`，`den=2*l-19`。
5. 若 `num<=0` 输出 `1`，否则输出 `num/den+1`。
6. 对下一组数据重复。

### 4.3 复杂度分析

- **时间复杂度**：每组 $O(1)$，共 $O(T)$。
- **空间复杂度**：$O(1)$。

## 5. 示例代码

```cpp
//
// 题目：P1818 电影投票
// https://www.luogu.com.cn/problem/P1818
// 与暴力枚举对拍通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	double X,Y;
	i64 N;
	while(cin>>X>>Y>>N)
	{
		i64 k=llround(X*10),l=llround(Y*10);
		// 显示值为 k/10 时，S < (2k+1)N/20；再截到物理上界 10N
		i64 S=((2*k+1)*N-1)/20;
		S=min(S,10*N);
		// 需 20(S+ans) < (2l+1)(N+ans)，整理得 ans > num/den
		i64 den=2*l-19,num=20*S-(2*l+1)*N;
		i64 ans=(num<=0?1:num/den+1);
		cout<<ans<<'\n';
	}
	return 0;
}
```
