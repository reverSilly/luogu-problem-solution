# P1824 [USACO05FEB] 进击的奶牛 Aggressive Cows G

> 难度：普及- · 标签：二分, 贪心, USACO

## 1. 重新读题

### 1.1 问题重述（人话版）

直线上有 $n$ 间牛舍，坐标 $x_i$（**不保证有序，也不保证互异**）。要放进 $m$ 头牛，一间至多一头。希望任意两头牛的距离的**最小值**尽量大。输出这个最大的最小距离。

### 1.2 关键约束与规模暗示

- $2\le m\le n\le 10^5$，$0\le x_i\le 10^9$。
- 坐标差到 $10^9$，答案仍放得进 32 位整数，但中间量不要用会溢出的写法去减。
- $n=10^5$ 排除「枚举所有选法」：$C(n,m)$ 不可行。单调性 + 排序后的线性判定是 $O(n\log A)$。
- 若有重复坐标，两头牛可以被迫距离为 $0$，答案合法地可以是 $0$。

## 2. 思维链（Chain-of-thought）

先排序，下面默认 $a_1\le a_2\le\dots\le a_n$。

**引理 1（可行性单调）**

若最小距离 $d$ 能放下 $m$ 头牛，则任意 $d'\le d$ 也能。

**证明**：拿出一组达到最小距离 $\ge d$ 的放置。同一组放置的最小距离也 $\ge d'$。所以可行解集合对 $d$ 是向下封闭的。$\blacksquare$

因此可以二分 $d$，左端 $0$（重复坐标或 $m$ 很大时的下界），右端 $a_n-a_1$（$m=2$ 时的上界，再大一定放不下）。

判定不能再二分牛舍子集，要一个线性贪心。

**引理 2（从左到右能放就放，是判定的充要条件）**

固定 $d$。第一头放在最左牛舍 $g_1=a_1$；之后每一头放在「与上一头距离至少 $d$ 的最左牛舍」。若这样能放下 $m$ 头，则 $d$ 可行；否则不可行。

**证明**：

（充分）构造本身给出了一组相邻差都 $\ge d$ 的 $m$ 个位置，可行。

（必要）设存在某组可行位置 $p_1<p_2<\dots<p_m$。对它们归纳 $g_i\le p_i$。

- $i=1$：任何放置的第一头都不能比全局最左更左，而贪心取的就是 $a_1$，故 $g_1=a_1\le p_1$。
- 若 $g_i\le p_i$，则 $p_{i+1}\ge p_i+d\ge g_i+d$。$p_{i+1}$ 是一个与 $g_i$ 距离至少 $d$ 的牛舍，贪心的 $g_{i+1}$ 是所有这种牛舍里最左的，所以 $g_{i+1}\le p_{i+1}$。

于是 $g_m\le p_m\le a_n$，贪心不会比一个已存在的可行解更早失败。反过来说，贪心失败就说明不存在可行解。$\blacksquare$

暴力对拍不走二分：在排序后的牛舍上直接 DFS 枚举组合，维护当前最小相邻差，取最大。$n\le 16$ 时 $C(16,8)=12870$ 量级，和二分贪心不是同一算法。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 「最大的最小距离」对阈值向下封闭（引理 1），先排序再二分。
- **classic problem solution** — 判定用从左到右的贪心放置，并用 $g_i\le p_i$ 的归纳证明它不漏可行解（引理 2）。
- **consider easier version** — $m=2$ 时答案就是极差；$m=n$ 时答案是排序后相邻差的最小值。二分贪心同时覆盖这两种，也对拍里单独点了。
- **boundary discipline** — 左端从 $0$ 起，允许答案为 $0$；中点写成 `l+(r-l)/2`，避免相加溢出。

## 4. 真实解法

### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `n,m` | `int` | 牛舍数、牛数 | 读入 | $m$ 头牛 |
| `a` | `int [100005]` | 牛舍坐标，排序后使用 | 读入后 `sort` | 从左到右 |
| `l,r` | `int` | 二分的距离区间 | `0` 与 `a[n-1]-a[0]` | 闭区间 |
| `ans` | `int` | 当前最大可行距离 | `0` | 最后输出 |
| `cnt,last` | `int`（`ok` 内） | 已放头数、上一头坐标 | `1, a[0]` | 贪心游标 |

### 4.2 算法步骤

1. 读入坐标并排序。
2. 二分 $d\in[0,a_{n-1}-a_0]$。`ok(d)` 从最左开始，每当 `a[i]-last>=d` 就再放一头。
3. 可行则把答案抬到 `mid` 并收左端，不可行则收右端。
4. 输出 `ans`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 时间 $O(n\log n+n\log A)$，$A\le 10^9$；空间 $O(n)$。
- 编译：`g++ -O2 -std=c++17 -Wall -Wextra -Werror`，无警告。
- 样例五间牛舍放 $3$ 头，标程与组合暴力都是 `3`。
- 随机 $2\le n\le 16$、含全相等与坐标到 $10^9$：300 组一致，耗时 $1.52$ s；另 5 组边界（全 $0$、极差 $10^9$、$m=n$、大量重复）一致。合计随机+边界 306 组。
- 最大规模 $n=10^5,m=5\cdot 10^4$、坐标在 $[0,10^9]$ 只跑标程：答案 `10084`，耗时 $0.0231$ s。
- 合计 `307 tests OK`。

## 5. 示例代码

### 5.1 标程（`P1824.cpp`）

```cpp
//
// 题目：P1824 [USACO05FEB] 进击的奶牛 Aggressive Cows G
// https://www.luogu.com.cn/problem/P1824
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{100005};

int n,m;
int a[mxn];

bool ok(int d)
{
	int cnt=1,last=a[0];
	for(int i=1;i<n;++i)
		if(a[i]-last>=d)
		{
			++cnt;
			last=a[i];
			if(cnt>=m)
				return true;
		}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	sort(a,a+n);
	int l=0,r=a[n-1]-a[0],ans=0;
	while(l<=r)
	{
		int mid=l+(r-l)/2;
		if(ok(mid))
		{
			ans=mid;
			l=mid+1;
		}
		else
			r=mid-1;
	}
	cout<<ans<<'\n';
	return 0;
}
```
