# P1548 [NOIP 1997 普及组] 棋盘问题

> 标签：1997 / NOIP 普及组 / 枚举 / 组合计数 · 难度：入门
> 本地题面：`P1548.md`（$1\le N,M\le 100$）。验证：300 组随机对拍（四重循环按定义枚举边界线暴力验证）+ 4 组手工用例全部通过，最坏规模 $100\times100$ 耗时 约 0.006 s。

## 1. 重新读题

**问题重述（人话版）**

有一个 $N\times M$ 的方格棋盘（$N$ 行 $M$ 列小方格）。统计棋盘里**所有**边与小方格边线对齐的矩形（含正方形），然后：

- 输出第一项 = 其中**正方形**的个数；
- 输出第二项 = 其中**长方形（题目明确说不包括正方形）**的个数。

> 一句话版本：**数出 $N\times M$ 网格里所有的子矩形，按"是不是正方形"分成两类，分别输出。** 两类的和 = 子矩形总数。

**题面里容易漏掉的条款**

1. 「长方形（不包括正方形）」$\Rightarrow$ 输出的第二个数是**非正方形**的矩形个数，正方形**不能**被重复计入长方形。于是最省事的做法是：先算全部矩形，再减去正方形，**恰好避免分类讨论与重复计数**。
2. 「边长为 $1$ 的正方形有 $6$ 个；边长为 $2$ 的正方形有 $2$ 个」（$N=2,M=3$ 的例子）$\Rightarrow$ 正方形按**边长**分类计数，边长范围 $1\le k\le\min(N,M)$。
3. 题的图中 $N=2,M=3$ 的长方形共 $10$ 个（$4+3+2+1$）$\Rightarrow$ 全部矩形 $= 8+10 = 18$。这是一个可用来校验公式的样例（本地题面未收录输入输出格式样例，此数据来自描述正文）。
4. 矩形的朝向：$N=2,M=3$ 时描述里出现过 $2\times1$、$1\times2$、$3\times1$、$3\times2$ 四种（把 $2$ 行 $3$ 列看成"行数 $\times$ 列数"的两种朝向都算）$\Rightarrow$ 子矩形可以横放也可以竖放，**行列不对称**，不能用交换的技巧偷懒，要分别用 $N,M$ 计数。

**数据范围与规模感受**

$$1\le N,M\le 100 .$$

两者都是 $10^2$ 级别。救场的是**答案有闭式公式**，可以做到 $O(\min(N,M))$（甚至 $O(1)$）；即便用朴素四重循环枚举边界也是 $O(N^2M^2)\le10^8$，尚能过，提示本题是"计数公式"入门题而非搜索题。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：一个子矩形到底由什么唯一确定

棋盘上有 $N+1$ 条横网格线（编号 $0,1,\dots,N$，把棋盘分成 $N$ 行）和 $M+1$ 条竖网格线（编号 $0,1,\dots,M$，分成 $M$ 列）。任何一个与小方格边对齐的子矩形，都是"选两条横线夹出上下、选两条竖线夹出左右"围成的。

**引理 1（子矩形与"两横线 + 两竖线"一一对应）**

记 $T$ 为上横线编号、$B$ 为下横线编号（$0\le T<B\le N$），$L$ 为左竖线、$R$ 为右竖线（$0\le L<R\le M$）。则四元组 $(T,B,L,R)$ 与棋盘中的子矩形构成**双射**：子矩形的高为 $B-T$，宽为 $R-L$。

**证明**：

- 一个四元组 $(T,B,L,R)$ 唯一确定一个矩形：上边界在 $T$、下边界在 $B$、左边界在 $L$、右边界在 $R$，四条边界都是网格线，故围成的小方格集合是确定的，且高 $=B-T$、宽 $=R-L$（相邻横线间距均为 $1$）。不同的四元组给出不同矩形（只要有一条边界不同，圈住的小方格集合就不同）。
- 反之，任一与小方格边对齐的矩形，其四条边必落在网格线上，设其上/下/左/右边界线编号为 $T,B,L,R$，因矩形非退化必有 $T<B,\ L<R$，且上界分别限制 $B\le N,\ R\le M$，故得到唯一合法的四元组。

两个方向互逆，双射成立。$\blacksquare$

> 这一步把"几何图形"彻底翻译成了"从若干条线里挑 2 条"的**组合选择问题**——几何被消掉了，只剩计数。

### 2.2 更简单的版本：先数"所有矩形"

**引理 2（矩形总数 $=\binom{N+1}{2}\binom{M+1}{2}$）**

棋盘内所有子矩形（正方形也算在内）的个数为
$$
\text{Tot}=\underbrace{\frac{N(N+1)}{2}}_{\binom{N+1}{2}}\cdot\underbrace{\frac{M(M+1)}{2}}_{\binom{M+1}{2}} .
$$

**证明**：由引理 1 的双射，矩形数 $=$ "从中选 2 条横线"的方案数 $\times$ "从中选 2 条竖线"的方案数（**乘法原理**：横线的选法与竖线的选法互相独立、可自由搭配，且每一对搭配恰对应一个矩形）。从 $N+1$ 条横线里选 2 条有 $\binom{N+1}{2}=\frac{N(N+1)}{2}$ 种（无序选择，因上下无序、只要 $T<B$ 即可，任意 2 条线总可规定编号小者为上）；竖线同理有 $\binom{M+1}{2}=\frac{M(M+1)}{2}$ 种。相乘即得。$\blacksquare$

> 这是本题第一个"归约"：**不要一开始就分正方形/长方形**，先把两类合起来一次数清。

### 2.3 数正方形：按边长分类

**引理 3（边长为 $k$ 的正方形有 $(N-k+1)(M-k+1)$ 个）**

对 $1\le k\le\min(N,M)$，边长（同时是高和宽）为 $k$ 的正方形个数为
$$
S_k=(N-k+1)(M-k+1).
$$

**证明**：一个 $k\times k$ 正方形由引理 1 表示为 $(T,B,L,R)$，其条件为高 $B-T=k$ 且宽 $R-L=k$。

- 满足 $B-T=k$ 的 $T$ 取值：$T$ 可取 $0,1,\dots,N-k$，共 $N-k+1$ 种（此时 $B=T+k\le N$ 自动满足）。
- 满足 $R-L=k$ 的 $L$ 取值：$L$ 可取 $0,1,\dots,M-k$，共 $M-k+1$ 种。

高度条件只约束横线、宽度条件只约束竖线，二者**互相独立**（横线选择与竖线选择是两组不相干的变量），由乘法原理，方案数为 $(N-k+1)(M-k+1)$。每个方案对应唯一的正方形，故正方形个数就是该乘积。$\blacksquare$

**引理 4（正方形总数）**

$$
\text{Sq}=\sum_{k=1}^{\min(N,M)}(N-k+1)(M-k+1).
$$

**证明**：任何正方形有且仅有一个确定的边长 $k$（$1\le k\le\min(N,M)$，因为高 $\le N$、宽 $\le M$），不同边长的正方形互不相同（边长不同则高不同），故按 $k$ 分类**不重不漏**；对每个 $k$ 用引理 3 的数目求和即得总数。$\blacksquare$

### 2.4 归约：长方形 = 总数 − 正方形

**引理 5（非正方形矩形个数 $=\text{Tot}-\text{Sq}$）**

**证明**：任一子矩形要么是正方形、要么不是，二者是互斥且穷尽的一对（"是不是正方形"是一个二分判定，无第三种可能），因此全体子矩形被划分为"正方形集合"与"非正方形集合"两个不相交的部分。由计数加法原理，两个部分大小之和等于总数，即 $\text{非正方形}=\text{Tot}-\text{Sq}$。$\blacksquare$

> 这正是题面"长方形（不包括正方形）"的精确翻译。**用"总数减去正方形"代替"逐个按行列分类数长方形"，既避免遗漏 $1\times2$、$2\times1$ 等各朝向，又杜绝了把正方形误算进长方形。**

### 2.5 剖析几个失败思路

**失败 1：分别数"长方形"时漏朝向 / 排错行列。**
例如只统计"宽 $>$ 高"的矩形当作长方形：会漏掉宽 $<$ 高的竖长方形；把 $N,M$ 互换套同一个公式：会算错（$N=2,M=3$ 的竖放与横放数量不同）。$\Rightarrow$ 正确做法是"总数 $-$ 正方形"，天然涵盖所有朝向。

**失败 2：把正方形公式写成 $\sum_k (N-k+1)^2$（误以为棋盘是方的）。**
反例：$N=2,M=3$。错版：$k=1:(2)^2=4$，$k=2:(1)^2=1$，得 $5$；正确：$6+2=8$。$\Rightarrow$ 正方形计数必须**横竖分别用 $N,M$ 的边界数** $(N-k+1)(M-k+1)$，不能平方。

**失败 3：把"长方形"理解为"周长/面积恰好某一固定值"。**
题面从未给此类约束，"长方形"只是"非正方形的矩形"的代名词。若自行加约束会全盘算错。$\Rightarrow$ 严格按"是不是正方形"二分。

**失败 4：整数溢出。**
$N=M=100$ 时 $\text{Tot}=\binom{101}{2}^2=5050^2=25\,502\,500$，仍在 `int` 内（$<2.1\times10^9$），但若把公式写成 $N(N+1)M(M+1)/2$ 这类不分组的形式，中间量 $100\times101\times100\times101\approx1.02\times10^8$ 尚可，而若更早地把 $\binom{101}{2}$ 误写为 $\binom{101}{2}\cdot\binom{101}{2}$ 的未除尽中间量则可能爆 `int`。$\Rightarrow$ 用 `long long` 或**先各自除以 2 再相乘**，稳妥。

### 2.6 越界与状态体检

| 量 | 范围 | 上界 | `int` 够？ |
|---|---|---|---|
| $N$ / $M$ | 题面 | $100$ | 是 |
| $\text{Sq}\le\sum_k k^2$（$N=M=100$） | — | $338\,350$ | 是 |
| $\text{Tot}=\binom{N+1}{2}\binom{M+1}{2}$ | — | $25\,502\,500$ | 是（但中间量用 `i64` 更稳） |
| $\text{Tot}-\text{Sq}$ | — | $\approx2.5\times10^7$ | 是 |

结论：结果都在 `int` 内；为求稳，累计与乘积用 `long long`（`i64`）。

## 3. 模式总结（Pattern Summary）

**模式名：矩形计数的「边界线双射 + 总数减特例」。**

**识别信号**：

- 题目要"数出网格/棋盘里所有子矩形 / 子正方形 / 特定形状"的个数。
- 形状由若干条"边线"围成，边界与网格对齐。
- 需要分类输出（正方形 vs 长方形），或要排除某类。

**可复用的思维轨迹（按实际思考顺序）**：

- explore its property — 把"子矩形"翻译成"选 2 条横线 + 2 条竖线"的四元组双射（引理 1），消掉几何、只剩组合选择。
- consider easier version — 先不分正方/长方，直接数**全部矩形** $\binom{N+1}{2}\binom{M+1}{2}$（引理 2）。
- exploit independence — 引用乘法原理：横线与竖线的选择互相独立，可自由搭配（引理 1、2、3 都用它）。
- consider easier version（第二处）— 正方形按**边长**分类，边长只约束高与宽，$S_k=(N-k+1)(M-k+1)$（引理 3）。
- reduce to easier problem — "长方形"（非正方形）$=$ 总数 $-$ 正方形，用互斥二分替代逐类枚举，天然避重漏（引理 5）。
- overflow guard — 乘积先除以 $2$ 或改用 `i64`，防止中间量溢出。

**同族题 / 同源题**：

- **LeetCode 1504 / 各类"数正方形"题**：$\sum_k(N-k+1)(M-k+1)$ 是同一公式。
- **P1009 阶乘之和 / 各类组合恒等式题**：$\binom{n}{2}=\frac{n(n+1)}{2}$ 的"边线配对数"是同一计数工具。
- **棋盘中的"最长公共子矩阵 / 计数子矩阵"**：起点都是"子矩形由两条横线两条竖线确定"这一双射。

**一句话记忆**：矩形 = 两组独立边界线的搭配；正方形按边长分类求和；长方形 = 总数减正方形。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $N$ | `int` | 棋盘行数（横线有 $N+1$ 条） | 读入 | 题面 |
| $M$ | `int` | 棋盘列数（竖线有 $M+1$ 条） | 读入 | 题面 |
| `sq` | `i64` | 正方形总数 $\text{Sq}$ | `0` | square，引理 4 累加 |
| `k` | `int` | 正方形边长，$1..\min(N,M)$ | 循环 | 引理 3 |
| `tot` | `i64` | 全部矩形总数 $\binom{N+1}{2}\binom{M+1}{2}$ | 计算 | total，引理 2 |

### 4.2 编号步骤

1. 读入 $N,M$。
2. `sq=0`；对 $k=1..\min(N,M)$ 累加 `sq += (i64)(N-k+1)*(M-k+1)`（引理 3、4）。
3. `tot = (i64)N*(N+1)/2 * (M*(M+1)/2)`（引理 2；先各自除 2 再相乘防溢出）。
4. 输出 `sq` 与 `tot-sq`（引理 5：长方形 = 总数 − 正方形）。

### 4.3 复杂度

- 时间：$O(\min(N,M))\le100$ 次迭代。
- 空间：$O(1)$，仅几个标量。
- 实测（见 §4.5）：$100\times100$ 耗时 **约 0.006 s**（其中含进程启动开销，真实计算开销可忽略）。

### 4.4 关键不变量（值得写 `assert` 的地方）

1. `sq <= tot`（正方形是矩形的一部分），故 `tot-sq >= 0`。
2. `k <= min(N,M)`：循环上界保证 $N-k+1\ge1$、$M-k+1\ge1$，不会出现负计数。
3. 当 $N=1$ 时 $\text{Sq}=M$、`tot=M(M+1)/2`，`tot-sq = M(M-1)/2`（$1\times M$ 棋盘里只有 $1\times1$ 是正方形）。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 描述样例回归 | **通过**：$N=2,M=3$ 输出 `8 10`（题面正文明确给出正方形 $8$、长方形 $10$） |
| 随机数据对拍 | **通过**：300 组随机用例，公式版与"四重循环枚举所有上下左右边界线、逐个判是否正方形"的暴力版输出**逐字节一致**（$N,M\in[1,10]$） |
| 手工边界用例 | **通过**：$1\times1\to$ `1 0`；$1\times100\to$ `100 4950`；$100\times100\to$ `338350 25164150` |
| 最坏规模计时 | $100\times100$ 输出 `338350 25164150`，耗时 **约 0.006 s** |
| 残余风险 | 若 $N,M>100$（超出题面），`int`/`i64` 仍安全（`i64` 可支撑到约 $10^9$ 量级），公式本身与范围无关，无风险 |

## 5. 示例代码

### 5.1 主解：组合公式（总数 − 正方形）

```cpp
// 题目：P1548 [NOIP 1997 普及组] 棋盘问题
// https://www.luogu.com.cn/problem/P1548
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m;
	cin>>n>>m;
	i64 sq=0;                                     // 正方形个数
	for(int k=1;k<=min(n,m);++k)                  // 边长为 k 的正方形
		sq+=(i64)(n-k+1)*(m-k+1);
	i64 tot=(i64)n*(n+1)/2*(m*(m+1)/2);           // 全部矩形 = C(n+1,2)*C(m+1,2)
	cout<<sq<<' '<<tot-sq<<'\n';                  // 长方形 = 矩形 - 正方形
	return 0;
}
```

**代码结构对照**：整个程序就是引理 2、3、4、5 的直译——`sq` 累加引理 4 的和式，`tot` 是引理 2 的乘积（`(i64)n*(n+1)/2*(m*(m+1)/2)` 先分别除 $2$），输出沿用引理 5 的减法。`using i64=long long` 用于压住乘积的中间量。

### 5.2 对照实现：四重循环枚举边界线（仅用于小规模对拍）

```cpp
// 题目：P1548 [NOIP 1997 普及组] 棋盘问题
// 暴力基准：枚举所有横向/纵向网格线选出的矩形,逐个判定是否正方形
// 仅用于小规模对拍,不能提交
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int n,m;
	cin>>n>>m;
	i64 sq=0,rect=0;
	for(int t=0;t<n;++t)                          // 上边界
		for(int b=t+1;b<=n;++b)                   // 下边界
			for(int l=0;l<m;++l)                  // 左边界
				for(int r=l+1;r<=m;++r)           // 右边界
				{
					int h=b-t,w=r-l;
					if(h==w)
						++sq;
					else
						++rect;
				}
	cout<<sq<<' '<<rect<<'\n';
	return 0;
}
```

两版**输出必须逐字节相同**（已用 300 组随机数据确认）。暴力版直接按引理 1 的**定义**枚举每一对横线、竖线并逐个数正方形，完全绕开组合公式，因此可作为引理 2、3 的独立交叉验证基准。代价是 $O(N^2M^2)$，$N=M=100$ 时约 $2.5\times10^7$ 次，仍可接受。

### 5.3 易错点清单

- **把正方形公式写成 $(N-k+1)^2$** $\Rightarrow$ 非方棋盘全错（§2.5 失败 2，$2\times3$ 得 $5$ 而非 $8$）。
- **"长方形"逐类枚举** $\Rightarrow$ 易漏朝向、易把正方形重复计入；改用 `tot-sq`（§2.5 失败 1）。
- **`(i64)n*(n+1)/2*(m*(m+1)/2)` 漏了整数除法次序**：若写成 `n*(n+1)*m*(m+1)/4`，对奇数乘积除以 $4$ 可能因除不尽而截断出错（$100\times101\times100\times101/4$ 恰为整数，但一般 $N,M$ 不保证）。$\Rightarrow$ 先分别 `/2` 再相乘。
- **`endl`** $\Rightarrow$ 违反风格指南，用 `'\n'`。
