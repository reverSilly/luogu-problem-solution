# P1396 营救

> 标签：图论 / 生成树 · 二分 + 并查集 · 难度：普及/提高-

## 1. 重新读题

**大白话版本**

$n$ 个区、$m$ 条**双向**大道，每条大道有一个"拥挤度"。给起点 $s$、终点 $t$，选一条 $s\to t$ 的路线，使得**这条路线上拥挤度的最大值尽量小**，输出这个最小能达到的最大值。

目标函数不是"求和"而是"取最大"：

$$b^*=\min_{P:\,s\to t}\ \max_{e\in P} w(e).$$

**先把题面的坑钉死（一律以本地题面 `P1396.md` 为准）**

| 问的问题 | 题面结论 / 说明 |

## 2. 思维链（Chain-of-thought）

### 2.1 先把"这题的机制"压干净

目标函数是 $\max$，不是 $\sum$。这带来三个立刻能用掉的性质：

1. **加长路径不会让 $\max$ 变大**（若不引入更大的边）：往路径上接一段全都不超过当前最大值的边，值不变。
2. **最优路线可以取成简单路径**：见引理 1。
3. **算法里根本不该出现加法**：只需要 $w(e)\le L$ 这种**比较**。于是"正权/负权"、"溢出"这两类经典麻烦同时消失（2.8、2.10-6）。

**引理 1（路线可取简单）** 任何 $s\to t$ 的行走 $W$ 都包含一条简单 $s\to t$ 路径 $P\subseteq W$，且 $\max_{e\in P}w(e)\le\max_{e\in W}w(e)$。

**证明**：$W$ 里若某个顶点出现两次 $v=s_i=s_j$（$i<j$），把 $i+1$ 到 $j$ 这段环路删掉，剩下仍是 $s\to t$ 的行走，且边集只减不增，故 $\max$ 不会变大。反复删环直到无重复顶点（每次顶点数严格减少 ⟹ 至多 $|W|$ 次内终止），得到简单路径 $P$。边集 $E(P)\subseteq E(W)$ ⟹ $\max_{E(P)}\le\max_{E(W)}$。$\blacksquare$

于是最小化可以只在所有简单路径上做，且最优值 $\le$ 任何一条具体路线的瓶颈，同时自环永远无用（2.10-2）。

### 2.2 陷阱：把"最短路"直接搬过来会错

**错法 A（求和）**：跑一遍 Dijkstra 把 $dis[t]$ 当答案。反例：

```
3 3 1 3
1 2 4
2 3 4
1 3 5
```

求和最短是直连边 $1\to3$（$5<8$），它的瓶颈是 $5$；而 $1\to2\to3$ 瓶颈只有 $\max(4,4)=4$ ⟹ 正确答案 $4$，求和版输出 $5$，**错**。

**错法 B（跳数）**：BFS 找最少跳数的路径再取 $\max$。上面例子最少跳数正是那条更差的直连边；把例子改成 `1 2 1 / 2 3 1 / 1 3 3`，最少跳数给 $3$，真答案 $1$。

**失败模式定位**：这两种做法比较的是"路径的**可加**总量"，而本题比较的是"路径的**最大**单项"。前者对拼接满足 $f(P\cdot Q)=f(P)+f(Q)$，后者满足 $f(P\cdot Q)=\max(f(P),f(Q))$——代数结构换了，"前缀最优 ⟹ 整体最优"的贪心依据也得换。这就把问题推向 2.3。

### 2.3 关键转化：把"最小化最大值"变成"判定 + 二分"

对门槛 $L$，记 $G_L=(V,\{e: w(e)\le L\})$，即**只保留不超过 $L$ 的边**；判定 $\text{check}(L)\equiv$ "$s,t$ 在 $G_L$ 中连通"。

**引理 2（瓶颈判据 ⟺ 阈值连通，双向）** 对任意整数 $L$：$\text{check}(L)$ 为真 $\Longleftrightarrow$ 存在 $s\to t$ 的行走 $W$ 使 $\max_{e\in W}w(e)\le L$（写成"路径"也对：路径是特殊的行走，两个方向的证明都不依赖 $W$ 是否简单，故两种口径等价）。

**证明**：
- ($\Longleftarrow$) 设这样的 $W$ 存在。$W$ 的每条边都满足 $w(e)\le\max_{e'\in W}w(e')\le L$，故 $E(W)$ 全部落在 $G_L$ 的边集里，$W$ 本身就是 $G_L$ 中一条 $s\to t$ 行走 ⟹ $s,t$ 在 $G_L$ 中连通。
- ($\Longrightarrow$) 设 $G_L$ 中 $s,t$ 连通，取 $G_L$ 里一条 $s\to t$ 路径 $P$。$P$ 的每条边都属于 $G_L$ 的边集，即 $w(e)\le L$ 对每条边成立，故 $\max_{e\in P}w(e)\le L$。$\blacksquare$

**引理 3（单调性）** $L_1\le L_2\implies(G_{L_1}\subseteq G_{L_2})\implies[\text{check}(L_1)\Rightarrow\text{check}(L_2)]$。

**证明**：$w(e)\le L_1\le L_2\Rightarrow w(e)\le L_2$，故 $E(G_{L_1})\subseteq E(G_{L_2})$，点集相同；"连通"就是存在路径，边集变大不会消灭已有路径（同一条路径在新图里仍然合法）。$\blacksquare$

**引理 4（门槛最小元存在、等于 $b^*$、且被某条输入边的权取到）** 记 $B=\{L\in\mathbb Z:\text{check}(L)\}$。当 $s\ne t$ 时 $B$ 非空、下有界，故 $\bar L=\min B$ 存在，且
$$\bar L\ =\ \min_{W:\,s\to t\text{ 行走}}\ \max_{e\in W}w(e)\ =\ b^*,$$
并且 $\bar L$ 等于某条输入边的权。

**证明**：令 $A=\{\beta(W): W \text{ 是 } s\to t \text{ 的行走}\}$，其中 $\beta(W)=\max_{e\in W}w(e)$（$s\ne t$ 保证 $W$ 至少一条边，$\beta$ 有定义）。
- $A$ 非空：题面承诺 $s\to t$ 可达 ⟹ 至少一条行走。$A$ 有限：$\beta(W)$ 必等于 $W$ 中**某个元素** $e$ 的权（有限边集的最大值一定在集合里取到），而 $W$ 的边都来自 $G$，故 $A\subseteq\{w(e):e\in E\}$，后者只有 $m$ 个元素 ⟹ $A$ 有限非空，$\min A$ 存在且被某条具体行走取到。
- $b^*=\min A$：$A$ 是"全体行走"上的值集，$b^*$ 的定义只跑简单路径，而简单路径是特殊的行走 ⟹ 行走集 $\supseteq$ 简单路径集 ⟹ $\min A\le b^*$。反向：$A$ 有限，取到 $\min A$ 的那条行走 $W^*$ 按引理 1 删环后得到简单路径 $P^*\subseteq W^*$，$\beta(P^*)\le\beta(W^*)=\min A$；而 $P^*$ 本身也是行走 ⟹ $\min A\le\beta(P^*)$，两式夹住得 $\beta(P^*)=\min A$，于是 $b^*\le\beta(P^*)=\min A$。两侧不等号即 $b^*=\min A$，并且 $b^*$ 也在简单路径上取到。
- $A\subseteq B$：对 $a=\beta(W)\in A$，$W$ 的每条边满足 $w(e)\le a$，引理 2 的 ($\Longleftarrow$) 给 $\text{check}(a)$ 为真 ⟹ $a\in B$。于是 $\min B\le\min A$。
- $\min A\le\min B$：$B$ 下有界（$L<\min_e w(e)$ 时 $G_L$ 一条边都没有，$s\ne t$ 的两点无法连通 ⟹ $\text{check}(L)$ 假），故 $\min B$ 存在；对 $L_0=\min B$ 用引理 2 的 ($\Longrightarrow$) 得到行走 $W_0$ 使 $\beta(W_0)\le L_0$，而 $\beta(W_0)\in A$ ⟹ $\min A\le\beta(W_0)\le L_0=\min B$。

后两条给 $\min A=\min B$，配上 $b^*=\min A$ 即 $\bar L=\min B=b^*$。最后 $\bar L\in A$（$A$ 有限，最小值被取到）⟹ $\bar L=\beta(W^*)$ 是 $W^*$ 里某条**输入边**的权（第一条已述 $A\subseteq\{w(e)\}$）⟹ $\bar L\le\max_e w(e)\le10^4$，`int` 绰绰有余（2.8）。$\blacksquare$

**$s=t$ 时引理 4 失效**，且失效得很有指导性：此时 $G_L$ 里 $s$ 与自己恒连通（长度为 $0$ 的路径），故 $\text{check}(L)$ 对**所有** $L$ 为真 ⟹ $B=\mathbb Z$ 无下界、$\min B$ 不存在，而 $A$ 也只含"空行走"这一个未定义量 ⟹ 必须像 2.10-4 那样单独约定答案（本解约定为 $0$）。三条实现里，只有"主解（Kruskal）"的口径是自然落到 $0$ 的（循环条件一开始就为假），另两条要显式特判。

**结论**：$s\ne t$ 时，答案 = "让 $s,t$ 首次连通的最小门槛"。怎么把这个门槛抬上去，有两条提速路线——二分门槛（配 BFS 判定，2.4）与按权加边（配并查集，2.5）；它们服务的都是同一个判据（引理 2），这正是题面标签里的"二分 / 搜索 / 并查集 / 生成树"。

### 2.4 退化版：枚举门槛 + BFS（子任务 $n\le100$ 的解）

既然 $\bar L$ 是某个输入边的权，最直接：把 $m$ 个不同权值逐个当门槛跑一遍 BFS ⟹ $O(m(n+m))=2\times10^4\times3\times10^4=6\times10^8$，太慢；改成**二分**（引理 3 保证单调，可二分）⟹ $O((n+m)\log W)$。完整代码见第 5 部分第二块，正确性由引理 2 + 引理 4。

### 2.5 经典化：Kruskal 过程里的"首次连通"就是答案

二分版要跑 14 遍 BFS。换个角度看引理 3：门槛从 $-\infty$ 往上涨，边**按权不降**一条条加入，$s,t$ 的状态只从"不连通"变"连通"一次。这恰好就是 **Kruskal 的过程**——它本来就按 $w$ 不降序处理边、用并查集维护连通分量。于是猜想：

**贪心（Kruskal 首连）** 边按 $w$ 不降排序，依次并查集合并，**第一次使 $s,t$ 同根**时那条边的权即答案。

先给出把猜想证死需要的桥：

**引理 5（并查集状态 $=$ 已处理边图的连通分量）** 设 Kruskal 已处理边的集合为 $F$（排序序列的某个**前缀**；特别地，"处理完所有权 $\le L$ 的边"时 $F=E(G_L)$），则 $u,v$ 在同一个并查集集合中 $\Longleftrightarrow$ $u,v$ 在图 $(V,F)$ 中连通。

**证明**：把"$u,v$ 同集合"记作 $\mathcal{R}$，"$u,v$ 在 $F$ 上连通"记作 $\sim_F$；$\sim_F$ 正是由边关系生成的等价闭包，所以两个关系都是 $V$ 上的等价关系。要证 $\mathcal{R}=\sim_F$，即双向包含，对"已处理边数 $k$"归纳（$k$ 从 $0$ 到 $|F|$，每次把两个关系同时往前推一步）。

- 归纳基 $k=0$：$F=\varnothing$。$\sim_\varnothing$ 只把每个点和自己相连 ⟹ 分量是 $n$ 个单点集；代码里 `iota(f,f+n,0)` 后每个点自己即根 ⟹ $\mathcal{R}$ 也是 $n$ 个单点集。一致。
- 归纳方向 $\mathcal{R}\subseteq\sim_F$（并查集绝不"凭空合并"）：只需证每一次 `union` 造出的新等同关系都能用 $F$ 中的边实现。代码里只有 `f[ru]=rv` 一处改变分区，且 $rv$ 是 $E_i=(x,y)$ 的一端 $y$ 的根、$ru$ 是另一端 $x$ 的根，即被合并的两个集合分别含 $x,y$；由归纳假设这两点与各自集合中的成员都已用 $F$ 中的边连通，于是"左侧点 $\leadsto x\xrightarrow{(x,y)}y\leadsto$ 右侧点"给出 $F$ 中一条路径 ⟹ 合并后的整个集合仍落在一个 $\sim$ 类里。自环、重边落入 `ru==rv` 分支、不改分区，不影响该方向。
- 归纳方向 $\sim_F\subseteq\mathcal{R}$（$F$ 中的每条边都被并查集认下来）：设 $u=v_0,v_1,\dots,v_p=v$ 是 $F$ 中的一条路径。逐条边 $(v_{j-1},v_j)$ 看：它在某步 $k_j\le k$ 被处理，处理那一刻要么把 $v_{j-1},v_j$ 所在的两个集合合并（此后二者同集合，且同集合是**单调**性质——代码里从不拆集合），要么二者已同集合。故对每个 $j$ 都有 $v_{j-1}\,\mathcal{R}\,v_j$，用 $\mathcal{R}$ 的传递性（等价关系）串起 $u\,\mathcal{R}\,v$。

两向合起来 $\mathcal{R}=\sim_F$。归纳的每一步只用到"分区单侧变粗、并查集只在真实边上合并"，因此结论对**同一批等权边内部的任意处理顺序**、以及对"前缀是否恰好切在整批之后"都成立（这正是下面推论 7 与定理 6 第一条的依据）。$\blacksquare$

**定理 6（Kruskal 首连值 $=b^*$，双向夹逼）** 设 $s\ne t$（$s=t$ 的情形由 2.10-4 单独约定，此时"$s,t$ 首次同根"根本不存在——它们一开始就同根）。Kruskal 按权不降序处理边，$L^*$ 定义为"第一次使 $s,t$ 落入同一并查集集合"时所处理那条边的权；则 $L^*$ 良定义且 $L^*=b^*$。

**先证 $L^*$ 存在**：由引理 4，$b^*$ 存在且有限，且引理 2 的反向给出 $\text{check}(b^*)$ 为真，即 $s,t$ 在 $G_{b^*}$ 中连通。$b^*\le\max_e w(e)$，故处理完全部 $m$ 条边后 $F=E(G_{\max_e w(e)})=E$，引理 5 说明此刻 $s,t$ 同集合 ⟹ "使 $s,t$ 同根"的边下标集合非空 ⟹ 其最小元存在（自然数集的非空子集必有最小元）⟹ 首次连通那一刻与 $L^*$ 唯一确定。

**证明**（两条不等式，各自都用一次引理 2 或引理 5）：
- $b^*\le L^*$：$L^*$ 那次合并完成后 $s,t$ 在同一并查集集合；此刻已处理的边全都满足 $w\le L^*$（排序不降），即已处理边集 $\subseteq E(G_{L^*})$。由引理 5 的方向 $\mathcal{R}\subseteq\sim$（同集合 ⟹ 用已处理边连通），$s,t$ 在 $G_{L^*}$ 中连通。引理 2 给出一条路径 $P$ 满足 $\max_{e\in P}w(e)\le L^*$，于是 $b^*=\min_{P'}\max w\le\max_{e\in P}w(e)\le L^*$。
- $L^*\le b^*$：反设 $b^*<L^*$。取达到 $b^*$ 的简单路径 $P$（引理 1、引理 4 保证存在），则 $P$ 的每条边 $w(e)\le b^*<L^*$。把边按权分成"批"：$B_c=\{e: w(e)=c\}$。因 $b^*<L^*$，凡是 $P$ 中的边都落在权 $\le b^*$ 的批里，而触发首次连通的那条边在权 $=L^*$ 的批里；排序不降 ⟹ **权 $\le b^*$ 的所有批整体排在权 $=L^*$ 的批之前**（不存在某条 $w=L^*$ 的边插在 $w\le b^*$ 的边前面，那会违反不降），故 $P$ 的全部边在"第一条权 $=L^*$ 的边被处理之前"就已全部处理完。此时已处理边集 $\supseteq E(G_{b^*})\supseteq E(P)$，由引理 5 的方向 $\sim\subseteq\mathcal{R}$（$P$ 是已处理边上的路径 ⟹ 两端同集合），$s,t$ 已经同根 ⟹ 首次连通发生在权 $<L^*$ 的时刻，与 $L^*$ 的最小性矛盾。故 $b^*\ge L^*$。

两侧夹住得 $b^*=L^*$。$\blacksquare$

（这段里两个方向的用词是有讲究的：第一条只要求"已处理边 $\subseteq G_{L^*}$"，第二条才需要"等权批整体在前"这一排序性质。少了第二条的批论证，遇到 $b^*$ 与 $L^*$ 之间夹着等权边时论证会失效——这也是为什么下面推论 7 要单独把并列权说清楚。顺带地，"第一次同根就 `break`"合法：定理 6 只关心首次时刻，其后处理的边权 $\ge L^*=b^*$，不可能再改变答案。）

**推论 7（并列权 / 重边 / 排序稳定性都不影响答案）** 若权相等的边之间用任意顺序处理，答案值仍为 $b^*$。

**证明**：设所有权 $=c$ 的边构成一批。引理 5 的结论"处理完权 $\le c$ 这批后 $s,t$ 是否同根"只依赖 $G_c$，与这批内部顺序无关；顺序只可能改变"这批内部哪一条边触发首次连通"，而触发时的 $L^*$ 恒等于这批的权 $c$。再由定理 6，$L^*=b^*$ 与实现无关。$\blacksquare$

（这也解释了为什么"重边"不需要去重：两条 $u\text{–}v$ 边按权排序后分别处理，第一次让 $u,v$ 同根的是较权小那条，另一次落入"已同根"分支被跳过，见 2.10-1。）

### 2.6 生成树视角：为什么"最小生成树上 $s$–$t$ 路径的最大边"也对

题面标签有"生成树"。把 Kruskal 跑完整张图（不在 $s,t$ 连通时停），得到一棵 MST $T$。

**定理 8（瓶颈路径性质）** 设 $T$ 是 $G$ 的一棵最小生成树（$G$ 不连通时取含 $s$ 的那个连通分量的生成树，题面的可达承诺保证 $t$ 也在其中），$P_T$ 为 $T$ 中唯一的 $s$–$t$ 路径，$e$ 为 $P_T$ 上权最大的一条边（若最大权出现多次，任取其一，下面证明不依赖选哪条），则 $w(e)=b^*$。

**证明**需要 MST 的割性质，先把割性质本身证了：

**引理 9（割性质）** 设 $e$ 是生成树 $T$ 的一条边，删去 $e$ 把 $T$ 分成两个点集 $X,V\setminus X$。则 $e$ 是横跨该割的所有边中权最小的之一：$\forall f\in\delta(X),\ w(e)\le w(f)$。

**证明**：反设存在跨割边 $f$ 满足 $w(f)<w(e)$。$T-e$ 是两个树 $T_X,T_Y$，$f$ 的两端分居两侧，故 $(T\setminus\{e\})\cup\{f\}$ 重新连通（同一侧内沿用原树路径，跨侧时走 $f$），且边数 $=(|V|-1)-1+1=|V|-1$，连通 + 边数 $=|V|-1\implies$ 树。其权比 $T$ 小 $w(e)-w(f)>0$，与 $T$ 是**最小**生成树矛盾。$\blacksquare$

**定理 8 的证明**：
- $b^*\le w(e)$：$P_T$ 本身就是一条 $s\to t$ 路径，$b^*$ 是所有路径瓶颈的最小值，故 $b^*\le\max_{e'\in P_T}w(e')=w(e)$。
- $w(e)\le b^*$：删去 $e$ 得割 $(X,V\setminus X)$，$s,t$ 分居两侧（因为 $e\in P_T$，删了它 $P_T$ 就断成分别含 $s$、含 $t$ 的两段）。任取达到 $b^*$ 的路径 $P$，它从含 $s$ 的一侧走到含 $t$ 的一侧，必有一条边 $f\in P$ 跨该割（把 $P$ 的顶点序列按所属侧写出来，第一次从一侧重到另一侧的那一步就是 $f$）。由引理 9，$w(e)\le w(f)\le\max_{e'\in P}w(e')=b^*$。

两式夹住得 $w(e)=b^*$。$\blacksquare$

有了定理 8，第三条路就通了：**先 Kruskal 建树，再在树上查 $s$–$t$ 路径最大边**。本题只有一组 $(s,t)$，一次树上 DFS 就够；若题目改成 $q$ 组询问，就需要"树上路径最大值"的 $\texttt{倍增}/\text{LCA}$（标签里"倍增 / 最近公共祖先"的由来），或 Kruskal 重构树（合并时新建父节点、权放在父上，答案即重构树上 $\text{LCA}(s,t)$ 的权）。**单次查询用它是杀鸡用牛刀**，本解不实现，只在 4.2 复杂度表里对比。

### 2.7 第三种判据：把 Dijkstra 的 $(\sum,\min)$ 换成 $(\max,\min)$

沿用 2.2 的代数观察，直接改松弛式（$d(v)\equiv\min_{P:s\to v}\max_{e\in P}w(e)$，于是答案 $=d(t)$）：

$$dis[v]\leftarrow\min\big(dis[v],\ \max(dis[u],\,w)\big),\qquad dis[s]=-INF,\ dis[v\ne s]=+INF .$$

**引理 10（该标签版 Dijkstra 正确，且不要求 $w\ge0$）** 用小根堆按上述规则松弛，$t$ **第一次出堆**那一刻的 $dis[t]=d(t)=b^*$。

先把三条支撑性事实写清楚（约定：路径的"前段" $P[0..i]$ 指从起点数到第 $i$ 条边为止的边集，它确实是 $s\to p_i$ 的一条路径）。

**不变量 I（标签 $\ge$ 真值）** 任意时刻，每个有限的 $dis[v]$ 都等于 $\beta(W)=\max_{e\in W}w(e)$，其中 $W$ 是某条真实的 $s\to v$ 行走；故 $dis[v]\ge d(v)$。

**证明**：初值 $dis[s]=-INF=\beta(\text{空行走})$（约定 $\max\varnothing=-INF$），$dis[v\ne s]=+INF$ 视作"尚无行走"不参与；每次赋值 $dis[v]\leftarrow\max(dis[u],w)$ 都是把 $u$ 的那条行走 $W_u$ 再接上边 $(u,v)$，新值恰为 $\beta(W_u\cdot(u,v))$（$\max$ 的定义就是如此），而 $dis$ 只在严格变小时被改写。对赋值次数归纳即得。$\blacksquare$

**引理 J（堆顶 $=$ 未定标点的最小标签）** 与 P1339 的引理 B 逐字同构，因为它的证明只用两件事：$dis$ 只减不增、每次严格改进都 `emplace` 一条新条目。堆里每个 $(d,x)$ 都是某次赋值时的历史值 ⟹ $d\ge dis[x]$；而每个未定标点 $v$ 的**最后一次**赋值条目必然还在堆里（被弹过就说明 $v$ 已定标），于是堆顶键 $=dis[u]\le dis[v]$ 对一切未定标 $v$ 成立。（注意这里**没有**用到任何算子性质，所以它同时服务于加法版和 $\max$ 版。）$\blacksquare$

**定理（定标即最优，对已定标点数归纳）** 归纳假设：已定标的每个 $x$ 满足 $dis[x]=d(x)$。设 $u$ 是下一个出堆的点。

**证明**：$dis[u]\ge d(u)$ 由不变量 I。反设 $dis[u]>d(u)$。取 $s\to u$ 的一条达到 $d(u)$ 的路径 $P:p_0=s\to p_1\to\cdots\to p_k=u$（引理 1 保证可取简单路径，故 $k\le n-1$，路径存在由 $d(u)<\infty$ 保证；$u=s$ 时 $dis[s]=-INF=d(s)$ 与反设矛盾，故 $u\ne s$、$k\ge1$）。令 $i$ 为 $P$ 上第一个未定标的下标：$p_0=s$ 在第一次出堆时就已定标（它的键 $-INF$ 全局最小，引理 J），故 $i\ge1$ 且 $p_{i-1}$ 已定标。

- $p_{i-1}$ 定标那一刻 $dis[p_{i-1}]=d(p_{i-1})$（归纳假设），且此后它不再变小（不变量 I 禁止任何标签跌到真值之下）⟹ 处理 $p_{i-1}$（扫它的全部邻接边，包含 $(p_{i-1},p_i)$）时执行过的赋值给出
$$dis[p_i]\ \le\ \max\big(d(p_{i-1}),\,w(p_{i-1},p_i)\big).$$
- 右边再往上界放：$d(p_{i-1})\le\beta(P[0..i-1])$（不变量 I 的"真值是所有路径的最小"这一侧：$P$ 的前段就是一条到 $p_{i-1}$ 的路径，故最小值不大于它），于是
$$\max\big(d(p_{i-1}),w_i\big)\ \le\ \max\big(\beta(P[0..i-1]),w_i\big)\ =\ \beta(P[0..i])\ \le\ \beta(P[0..k])\ =\ d(u).$$
  最后一个不等号"$\max$ 的前段 $\le$ 全长"是关键：$E(P[0..i])\subseteq E(P)$，一个集合的子集的最大值不超过全集最大值——**这对任意符号的权都成立**。加法版必须在 $w\ge0$ 时才有"前段和 $\le$ 全和"，这就是 $\max$ 版对负权免疫的确切原因（对比 P1339 的 2.5：那里断掉的正是这个不等号）。
- 于是 $dis[p_i]\le d(u)<dis[u]$，而 $p_i$ 未定标，与引理 J 的 $dis[u]=\min_{v\text{ 未定标}}dis[v]$ 矛盾。

反设不成立 ⟹ $dis[u]=d(u)$，归纳推进。有限性：每次出堆要么定标一个新点（至多 $n$ 次），要么跳过陈旧条目，条目数 $\le 1+2m$（同 P1339 引理 F/G 的论证，只用"每点只扫一次邻接"+"只在严格改进时 push"，与算子无关）。取 $u=t$ 的首次出堆即得 $dis[t]=d(t)=b^*$。$\blacksquare$

代码骨架只有松弛式与初值两处和 P1339 不同：

```cpp
fill_n(dis,mxn,INF);                 //全局 int 默认 0 会被当成"瓶颈已是 0"
dis[s]=-INF;Q.emplace(-INF,s);       //空路径口径：起点不带任何边
...
if(dis[v]>max(dis[u],w))             //把 dis[u]+w 换成 max(dis[u],w)
	dis[v]=max(dis[u],w),Q.emplace(dis[v],v);
```

**起点哨兵必须取 $-\infty$ 而不是 $0$**：取 $dis[s]=0$ 相当于偷偷往路径里塞一条"拥挤度 $0$ 的虚拟边"，于是算法算的是 $\max(0,\beta(P))$。题面只给 $w\le10^4$、没给 $w\ge1$（第 1 节表格），一旦真出现全负的数据（4.3 例 D），$0$ 版会输出 $0$ 而正确答案是负数 ⟹ **静默 WA**；取 $-INF$ 版输出 $-1$ 正确。$s=t$ 时 $-INF$ 版会输出 $-INF$，这是"空路径"的另一口径，需按 2.10-4 特判成 $0$。三条做法（Kruskal / 二分 + BFS / 半环 Dijkstra）由引理 2、定理 6、定理 8、引理 10 分别锁死，答案一致。

三种做法都能过本题，取哪一种看代码量与"要不要建树"：见 4.2 复杂度表。

### 2.8 溢出预算与资源算式

- **零加法 ⟹ 零溢出**：全代码只出现 $w\le L$、$a.w<b.w$、$f[x]==x$ 这类比较与赋值，**没有任何两个权值相加**，故权值参与运算的溢出可能性为 $0$。答案上界：$b^*\le\max_e w(e)\le10^4<2^{31}-1$（引理 4 已证 $b^*$ 取某条边的权）。
- **二分的 mid 相加**：备选代码里 `mid=(l+r)>>1`，$|l|,|r|\le10^4$ ⟹ $|l+r|\le2\times10^4$，`int`（上界 $2\,147\,483\,647$）余量 $\approx10^5$ 倍，安全。若把 $w$ 的上界改成 $2\times10^9$，则 $l+r$ 会溢出，必须换成 `l+((r-l)>>1)`——写清这条是为了说明"哪里才是真的预算口"。
- **尺寸**：`mxn{10005}`、`mxm{20005}`（$+5$）。主解边表 $20005\times12\,\mathrm{B}\approx240\,\mathrm{KB}$（`struct{int u,v,w;}`，$12\,\mathrm{B}$、$4$ 字节对齐无填充）+ `f[]` $10005\times4\approx40\,\mathrm{KB}$ ⟹ 静态部分合计 $\approx280\,\mathrm{KB}$。备选二分 BFS 版：弧表 $2m\le4\times10^4$ 条 $\times12\,\mathrm{B}\approx480\,\mathrm{KB}$，`H[]` $40\,\mathrm{KB}$ + `vis[]` $10\,\mathrm{KB}$ + 队列峰值 $n\times4\approx40\,\mathrm{KB}$ ⟹ 合计 $\approx570\,\mathrm{KB}$。题面**未给**内存限制，按常见 $128\,\mathrm{MiB}$ 口径毫无压力。
- **`getrt` 递归深度**：只做路径压缩、不按秩合并时，链状并查集的深度最坏可到 $n-1=9999$（本题排序后的合并顺序能构造出这种形状：让每条新边恰好接在已有链的根上），单次递归栈帧 $\approx32\,\mathrm{B}$ 量级 ⟹ 峰值 $\approx320\,\mathrm{KB}$，远小于常见 $8\,\mathrm{MiB}$ 栈；若嫌不稳可加 `sz[]` 按大小合并，深度立刻压到 $\lceil\log_2 n\rceil=14$，代价是多一个数组和两行代码。
- **时间算式**：主解 $=$ 排序 $m\lceil\log_2 m\rceil\approx2\times10^4\times15=3\times10^5$ 次比较 $+$ 并查集：循环条件每轮 $2$ 次 `getrt`、循环体 $2$ 次，共 $\le4m+2\approx8\times10^4$ 次调用，"只有路径压缩"的经典均摊上界为 $O(\log n)$/次（$\log_2 10^4\approx13.3$；按大小合并可到 $\alpha(n)\le4$）⟹ $\le8\times10^4\times13.3\approx1.1\times10^6$ 次基本操作，总计 $\approx1.4\times10^6$，比 $10^8$ 的常规时限预算低两个数量级。备选版 $=14\times(n+m)+14\times n\approx4.2\times10^5+1.4\times10^5\approx5.6\times10^5$（$14=\lceil\log_2(10^4+1)\rceil$ 次判定，每次 BFS 至多访问 $n$ 个点、扫至多 $2m$ 条弧），同量级。

### 2.9 与题面标签的对应

搜索/BFS（2.4 判定）、二分（2.4）、并查集（2.5 引理 5）、生成树（2.6 定理 8）、倍增/LCA（多询问版，2.6 末）、最短路（2.7 半环版）——标签里每个词都是这题的一条**合法**路线，不是冗余。

### 2.10 退化情形逐条过

1. **重边**：不去重。两条 $u\text{–}v$ 边权 $7,5$：排序后 $5$ 先处理 ⟹ 合并；$7$ 后处理 ⟹ `getrt(u)==getrt(v)` 命中"已同根"分支被跳过（第 5 部分代码里的 `continue`）。答案取 $\min$ 一侧，符合直觉且被推论 7 保证与顺序无关。
2. **自环 $u=v$**：$u,v$ 同根恒成立 ⟹ 恒被 `continue` 跳过，不进答案；这与引理 1"删环不增大 $\max$"一致。
3. **$s,t$ 不可达**：题面**承诺可达**，故主解不加防御。若去掉承诺：循环会自然跑完 $m$ 条边，`ans` 停在最后一条被合并的边权（**不是**合法答案，且不报错），必须改成事后 `if(getrt(s)!=getrt(t)) cout<<-1` 之类；题面未定义 $-1$ ⟹ 盲加反可能 WA，本解不加，只如实标注。
4. **$s=t$**：题面未禁止。循环条件里 `getrt(s)!=getrt(t)` 一开始就为假 ⟹ 一条边都不处理，`ans` 保持初值 $0$，即"待在自己区、不经过任何道路"的空路径口径。这在数学上是把 $\max\varnothing$ 约定为 $0$；题面没写清楚，列为**不确定点**（见 4.3 例 E）。备选二分版必须显式特判 `s==t`，否则会输出 $mw$（最小边权），两版口径不一致——这类"实现细节偷换语义"正是本题最容易静默 WA 的地方。
5. **$n=1,m\ge1$**：所有边都是自环，被第 2 条跳过；若 $s=t=1$ 同第 4 条，输出 $0$。
6. **$w\le0$**（题面只给上界，见第 1 节表格）：主解只用比较，结论定理 6 对任意实数权成立 ⟹ 无需改动；备选二分版**必须**把左端点设成最小边权 $mw$ 而不是 $0$，否则真实答案落在 $[mw,0)$ 时二分会停在 $0$（4.3 例 D 手算这一情形）。2.7 的半环 Dijkstra 还要注意起点标签不能取 $0$、必须取 $-\infty$ 哨兵（2.7 末段）。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 目标是 $\max$ 不是 $\sum$：不加权、只比权；最优路线可取简单（引理 1）。
- **dissect the failure** — 搬求和 Dijkstra / 搬跳数 BFS 都有具体反例（2.2），根因是"路径评价函数对拼接的合成律"变了：$+\to\max$。
- **threshold the objective** — 把"最小化最大值"改写成"判定 $G_L$ 是否连通"（引理 2，双向证明）；单调性（引理 3）+ 最小元存在且等于某条边权（引理 4）⟹ 答案 = 首次连通门槛。
- **consider easier version** — 枚举门槛跑 BFS（$6\times10^8$，超时）；二分门槛（$O((n+m)\log W)$，可过，也符合 $n\le100$ 子任务）。
- **classic problem solution** — Kruskal：边按权不降处理，并查集维护分量；引理 5（并查集分区 $=G_L$ 分量）+ 定理 6（双向夹逼 $L^*=b^*$）+ 推论 7（并列权/重边/顺序无关）。
- **reduce to a structure theorem** — 定理 8：MST 上 $s$–$t$ 路径的最大边 $=b^*$，靠引理 9 割性质的反证 + 交换；由此解释"生成树 / 倍增 / LCA"标签与多询问版。
- **classic problem solution (第二个)** — $(\max,\min)$ 半环上的 Dijkstra（引理 10：不变量 I + 引理 J 与算子无关，负权免疫的确切来源是"$E(P[0..i])\subseteq E(P)$ ⟹ 前段瓶颈 $\le$ 全长瓶颈"，它无条件成立，取代了加法版的 $w\ge0$）。
- **resource audit** — 无加法 ⟹ 无溢出；$b^*\le10^4$；`mxn{10005},mxm{20005}`；`getrt` 递归深度上界与是否加秩的取舍（2.8）。
- **handle degeneracy** — 重边跳同根、自环永跳、$s=t$ 空路径口径输出 $0$、可达性由题面承诺、$w\le0$ 时二分下界用 $mw$。
- **consider alternative techniques** — 完整 Kruskal + 树上查最大边 / Kruskal 重构树 + LCA（多询问才划算）、枚举门槛 BFS（只够 $n\le100$ 档）、求和 Dijkstra 与跳数 BFS（**结果错**）逐一比较（2.9、4.2 表）。

## 4. 真实解法（Real Solution）

### 4.1 符号表（Notation Glossary）

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n,m,s,t` | 区数、大道数、起点、终点（内部 0-based） | `int`，读入后 `--s;--t;` | $n\le10^4,m\le2\times10^4$ |
| `E[]` | 边表：`{u,v,w}` = 无向边的两端与拥挤度 | `struct{int u,v,w;}E[mxm]`，读入时 `--u;--v;` 后写入 | 不挂弧、不分方向，$m$ 个槽位够了 |
| `f[]` | 并查集父指针（根自己指自己） | `int f[mxn]`，**`iota(f,f+n,0)`** | 忘记初始化 ⟹ 全是 $0$，`getrt` 直接错 |
| `getrt(x)` | 找 $x$ 所在集合的根，路径压缩 | 递归，风格规范的 DSU 模板 | 返回根编号，不是权 |
| `ans` | 当前门槛：最后一次合并所用边的权 | `int`，初值 $0$（$s=t$ 口径） | 循环结束后 $=$ 首次让 $s,t$ 同根的边权（定理 6） |
| `ru,rv` | 本条边两端当前的根 | 局部 `int` | `ru==rv` ⟹ 这条边不改变连通关系，`continue` |
| `mxn{10005},mxm{20005}` | 数组尺寸 | `constexpr int` | 上界 $+5$ |

主解**不需要** `INF`：全程没有"未达/最远"的标签数组，只有比较。备选二分 BFS 版需要 `vis[]` 的显式 `fill_n(vis,mxn,false)`（每轮判定前重置，全局 `bool` 默认 $0$ 只在第一轮可信）。

### 4.2 算法步骤

1. 读 $n,m,s,t$，`--s;--t;`。
2. 读 $m$ 条边存进 `E[i]={u,v,w}`（`--u;--v;`）；重边、自环原样收下（2.10-1、2.10-2）。
3. `iota(f,f+n,0)`：每个点自成一个集合。
4. `sort(E,E+m,[](auto a,auto b){return a.w<b.w;});`：门槛从低到高。
5. 依次处理每条边：`ru=getrt(u),rv=getrt(v)`；`ru==rv` 就 `continue`；否则 `f[ru]=rv` 并令 `ans=E[i].w`；每轮开头用 `getrt(s)!=getrt(t)` 作循环条件，一旦 $s,t$ 同根立即停（定理 6 + 提前终止省掉后面的边）。
6. `cout<<ans<<'\n';`——输出的是**权值**，不是顶点编号，无需 $+1$ 还原。

**复杂度与对照**

| 做法 | 时间算式 | 本题评价 |
|---|---|---|
| Kruskal 首连（本解） | $O(m\log m+m\log n)\approx3\times10^5+1.1\times10^6$（若按大小合并，第二项降为 $O(m\alpha)$） | 最短码路、无 `INF`、对 $w\le0$ 天然安全 |
| 二分门槛 + BFS | $O((n+m)\log W)\approx5.6\times10^5$ | 与排序无关；需把下界设为 $mw$、特判 $s=t$ |
| $(\max,\min)$ Dijkstra | $O(m\log m)\approx3\times10^5$ | 需要 `fill_n(dis,mxn,INF)`、堆模板参数写全（默认大根堆会静默 WA） |
| 完整 Kruskal + 树上 DFS | $O(m\log m+n)$ | 多问一次询问，无收益；换成 $q$ 组询问时才有意义（配 LCA/倍增） |
| 枚举门槛 + BFS | $O(m(n+m))=6\times10^8$ | 淘汰，只够 $n\le100$ 档 |
| 求和 Dijkstra / 跳数 BFS | — | **结果错**（2.2 反例） |

## 5. 示例代码（C++）

### 5.1 主解：Kruskal + 并查集（首次连通即答案）

```cpp
// P1396 营救：路径最大边权最小 == 按权不降加边时 s,t 首次连通的门槛（定理 6）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};         //n<=1e4 +5
constexpr int mxm{20005};         //m<=2e4 +5

struct{int u,v,w;}E[mxm];
int n,m,s,t,f[mxn];
int ans{};                        //s==t 时按空路径口径输出 0（2.10-4）

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>s>>t;
	--s;--t;
	for(int i=0,u,v,w;i<m;++i)
	{
		cin>>u>>v>>w;--u;--v;
		E[i]={u,v,w};             //重边/自环照单全收，同根分支会跳过
	}

	iota(f,f+n,0);                //每个点自成集合，漏这行全错
	sort(E,E+m,[](auto a,auto b){return a.w<b.w;});   //门槛从低到高抬升
	for(int i=0;i<m && getrt(s)!=getrt(t);++i)
	{
		int ru=getrt(E[i].u),rv=getrt(E[i].v);
		if(ru==rv)
			continue;             //本条边不改变连通关系
		f[ru]=rv;
		ans=E[i].w;               //最后一次让 s,t 同根的权即答案
	}

	//输出的是权值，不是顶点编号，无需 +1 还原
	cout<<ans<<'\n';
	return 0;
}
```

- 全局静态数组、`mxn/mxm` 均 $+5$、`getrt` 用风格规范的递归模板；Tab 缩进、运算符无空格、`'\n'` 换行、`cin.tie/cout.tie/ios::sync_with_stdio` 顺序固定；内部 0-based（`--s;--t;--u;--v;`）。
- 本题主解**没有**"未达"数组，故不需要 `fill_n` 填 $INF$；但 `iota(f,f+n,0)` 就是这一族的等价物——全局 `int` 默认 $0$ 会让除 $0$ 号点外所有点的父指针都指向 $0$，`getrt` 立刻给出错误根，属于同类陷阱。
- 未运行验证；正确性来自引理 2、引理 5、定理 6、推论 7，数值行为来自 4.3 的六组手算。

### 5.2 备选：二分门槛 + BFS 判定（对应题面"二分 / 搜索"标签）

```cpp
// P1396 营救（二判版）：check(L)==="只走 w<=L 的边能否从 s 到 t"，单调可二分（引理 2、3）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{10005};
constexpr int mxm{20005};

struct{int v,w,nx;}E[mxm*2];      //无向 -> 2m 条弧
int H[mxn],cnt;
int n,m,s,t,mw{1145141919},mxw{-1145141919};   //权值域，二分的左右端点
bool vis[mxn];

void addedge(int u,int v,int w)
{
	E[cnt]={v,w,H[u]};H[u]=cnt++;
}

bool check(int lim)
{
	fill_n(vis,mxn,false);         //每轮判定必须重置，否则上一轮的 true 残留
	queue<int>Q;
	vis[s]=true;Q.push(s);
	while(!Q.empty())
	{
		int u=Q.front();Q.pop();
		if(u==t)
			return true;           //碰到即真，判定不需要最优性
		for(int i=H[u];~i;i=E[i].nx)
		{
			int v=E[i].v,w=E[i].w;
			if(w<=lim && !vis[v])
				vis[v]=true,Q.push(v);
		}
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m>>s>>t;
	--s;--t;
	fill_n(H,mxn,-1);             //前向星哨兵：默认 0 会把 0 号弧当成头
	for(int i=0,u,v,w;i<m;++i)
	{
		cin>>u>>v>>w;--u;--v;
		addedge(u,v,w);addedge(v,u,w);
		mw=min(mw,w),mxw=max(mxw,w);
	}
	if(s==t)
	{
		cout<<0<<'\n';            //与主解口径一致（2.10-4）
		return 0;
	}
	//check(mw) 不一定假、check(mxw) 一定真（题面承诺可达）
	for(int l=mw,r=mxw;l<r;)      //下界必须是 mw，不能写 0（例 D）
	{
		int mid=(l+r)>>1;
		if(check(mid))
			r=mid;
		else
			l=mid+1;
	}
	cout<<l<<'\n';
	return 0;
}
```

- `mw/mxw` 用 $\pm1145141919$ 哨兵起值（风格规范的哨兵家族），第一行读入后必被真实权值覆盖；题面保证 $m\ge1$，故循环结束时两个端点都已被更新，不会出现"左端点停在 $+\infty$"的空区间。
- 二分写法是风格规范的"闭区间、偏下界取 `mid=(l+r)>>1`"；终止时 $l=r$ 即 $\min\{L:\text{check}(L)\}=b^*$（引理 4）。
- 两版差异只在"判定的实现"（并查集 vs BFS）与"抬门槛的方式"（排序扫描 vs 二分），判据本身由引理 2 统一，故答案必然相同（$s=t$ 已特判对齐）。
