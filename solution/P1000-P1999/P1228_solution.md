# P1228 地毯填补问题 — 题解

## Part 1 — 重述题目

给定一个 $2^k \times 2^k$（$0<k\le 10$）的方格棋盘，其中恰好有一个格子是"公主"的格子，**不能**被地毯覆盖。地毯只能有一种形状：L 形三格毯（一个 $2\times 2$ 方块里去掉一格，剩 L 形的 3 格），它有 4 种朝向，分别记为 $c=1,2,3,4$（按官方图约定）：

- $c=1$：缺左上角 → 覆盖 $\{(x\!+\!1,y),\,(x,y\!+\!1),\,(x\!+\!1,y\!+\!1)\}$
- $c=2$：缺左下角 → 覆盖 $\{(x,y),\,(x,y\!+\!1),\,(x\!+\!1,y\!+\!1)\}$
- $c=3$：缺右下角 → 覆盖 $\{(x,y),\,(x\!+\!1,y),\,(x,y\!+\!1)\}$
- $c=4$：缺右上角 → 覆盖 $\{(x,y),\,(x\!+\!1,y),\,(x\!+\!1,y\!+\!1)\}$

每张毯子用一行 `x y c` 描述，其中 $(x,y)$ 是这张毯子**所属 $2\times 2$ 方块的左上角**坐标（行 $x$、列 $y$，1 起）。要求输出一种铺满方案：除公主格外，其余每个格子恰好被一层地毯覆盖。Special Judge 会校验：$c$ 不越界、$(x,y)$ 不越界、没有格子被重复覆盖、每个非公主格最终都被覆盖到。

**关键约束**：棋盘面积 $2^{2k}\le 2^{20}=1048576$，时间 1s。

---

## Part 2 — 思维链（完整推导）

### 2.1 先摸清"这个机制到底在干什么"

L 形毯恰好覆盖一个 $2\times 2$ 方块中的 3 格，留下 1 格。这暗示整个棋盘应该能按 $2\times 2$ 的块递归地"消解"。先算总面积：除公主格外共 $2^{2k}-1$ 格。每张毯盖 3 格，若 $2^{2k}-1$ 不能被 3 整除，则无解。验证：

> **断言**：对任意 $k\ge 1$，$2^{2k}-1\equiv 0\pmod 3$。
> **证明**：$2\equiv -1\pmod 3$，故 $2^{2k}=(-1)^{2k}=1\pmod 3$，于是 $2^{2k}-1\equiv 0\pmod 3$。$\blacksquare$

面积是必要条件，但"恰好整除"本身不保证能铺满，下面用归纳给出**存在性**和**构造法**。

### 2.2 考虑更小的版本（剥掉递归，看 $2\times 2$ 底步）

$k=1$ 时棋盘是 $2\times 2$，4 格里公主占 1 格，剩恰好 3 格——这 3 格**本身**就是一个 L 形毯。所以 $k=1$ 一定有解，只需输出一张毯：缺角就是公主所在的那一格。这就是递归的**底步**。

### 2.3 把 $2^k\times 2^k$ 切成四块，制造"恰好每块一个洞"的结构

这是整个算法的灵魂。把 $2^k\times 2^k$ 棋盘从正中心切成 4 个 $2^{k-1}\times 2^{k-1}$ 的象限，四个象限在**正中心**处共享同一个 $2\times 2$ 的"中心方块" $Q$。

> **关键观察**：公主 $(px,py)$ 必定落在 4 个象限中的某一个，记为 $Q_p$。其余三个象限各自都**没有**公主。
>
> 于是：$Q_p$ 里有 1 个洞（公主）；另外三个象限各有 0 个洞，**无法**直接递归（因为归纳假设要求"恰好 1 个洞"）。
>
> **修复手段**：在中心方块 $Q$ 里放一张 L 形毯，覆盖 $Q$ 中**不属于** $Q_p$ 的那 3 个格。这张毯在其余三个象限里各"挖出"1 个被覆盖格，使得**每个象限都恰好拥有 1 个不可铺的格子**（$Q_p$ 里是公主，另外三个是被这张中心毯占走的格）。

这一步把"只有一个洞的 $2^k$ 棋盘"化归成了"四个各自只有一个洞的 $2^{k-1}$ 棋盘"。

> **引理 A（修复毯的合法性）**：设中心方块 $Q$ 的行区间为 $\{r,\,r+1\}$、列区间为 $\{c,\,c+1\}$，公主在第 $a$ 行（$a\in\{r,r+1\}$）、第 $b$ 列（$b\in\{c,c+1\}$）。则存在且仅存在一张 L 形毯，覆盖 $Q$ 中除公主格之外的 3 格，且不覆盖公主格。
> **证明**：$Q$ 共 4 格，去掉公主格剩 3 格。这 3 格构成 $Q$ 去掉一个角后的形状，而"一个 $2\times 2$ 去掉一个角"恰好就是 L 形毯的定义（4 种朝向之一，缺角即公主所在角）。故这张毯合法，缺角由 $(a,b)$ 唯一确定，朝向 $c$ 由缺角在 $Q$ 中的位置唯一确定：缺左上→$c=1$、缺左下→$c=2$、缺右下→$c=3$、缺右上→$c=4$。$\blacksquare$
>
> **引理 B（修复毯落在正确的象限）**：上述修复毯覆盖的 3 个格中，恰好每个非公主象限各含 1 格。
> **证明**：$Q$ 的 4 格与 4 个象限一一对应（左上格∈左上象限、右上格∈右上象限、左下格∈左下象限、右下格∈右下象限）。去掉公主所在象限的那 1 格后，剩下的 3 格分别属于另外 3 个象限，且每象限恰 1 格（因为 $Q$ 里每个象限本来就只贡献 1 格）。$\blacksquare$

于是递归可以无矛盾地往下走：对每个象限，把它的"那个洞"（公主或修复毯占走的格）当作子问题的公主格，递归求解。

### 2.4 归纳证明正确性

> **定理**：对任意 $k\ge 1$ 及任意唯一公主格，存在一种 L 形毯铺满方案，使除公主格外每格恰被一层毯覆盖。
> **证明（对 $k$ 归纳）**：
> - **基**：$k=1$ 见 2.2，直接放一张缺角为公主的毯即可。
> - **步**：设对 $k-1$ 成立。对 $2^k\times 2^k$，按 2.3 切四块并放修复毯（引理 A、B）。此时每个象限都是 $2^{k-1}\times 2^{k-1}$ 且恰好含 1 个洞（公主或修复毯占格），由归纳假设各象限内部可被 L 形毯铺满。
>   **互不干扰性**：修复毯完全在中心方块 $Q$ 内；四个象限的内部（除去它们各自在 $Q$ 里的那 1 格）彼此不相交、也不含 $Q$ 的中心交叉点以外的格。各象限递归铺的毯都只覆盖该象限内部，故不同象限的毯、以及修复毯，三者覆盖的格子集合两两不相交，且并集恰为除公主格外的全部格子。$\blacksquare$

> **注（唯一性与 SPJ）**：本构造给出的是"确定性递归"的一种具体方案，并非唯一方案。题目用 Special Judge，只要满足覆盖条件即可，任意合法方案都被接受。因此我们不需要求"最优"，只求"合法 + 完整"。

### 2.5 复杂度

每层递归：棋盘被分成 4 块，每块处理常数工作（放 1 张中心毯 + 递归 4 次）。设 $T(n)$ 为 $2^n\times 2^n$ 的处理代价，则 $T(n)=4\,T(n-1)+O(1)$，$T(0)=O(1)$，解得 $T(n)=O(4^n)=O(N)$，$N=2^{2k}$。总毯数 $=\frac{2^{2k}-1}{3}$，与输出规模同阶，故算法是**输出敏感的最优**。

## Part 3 — 模式总结（按真实思考顺序）

- **explore its property** — L 形毯 = $2\times 2$ 缺一格；先验证面积 $2^{2k}-1$ 能被 3 整除（必要条件，恒成立）。
- **consider easier version** — $2\times 2$ 底步：4 格缺 1 格，剩 3 格天然就是一张毯（递归底）。
- **classic problem solution** — 分治（divide & conquer）：把 $2^k$ 板切 4 块 $2^{k-1}$ 子板，对子问题递归。
- **repair / reduce** — 关键修复：中心放一张"缺角=公主所在角"的 L 毯，使四个子板各恰好有一个洞，从而递归假设全部成立（这是把"单洞"还原成"四单洞"的化归步）。
- **prove every lemma** — 引理 A（修复毯合法且唯一）、引理 B（修复毯恰好占另外三象限各一格）、归纳定理（正确性）。
- **output-sensitive** — 总毯数 $\frac{2^{2k}-1}{3}$ 与输出同阶，算法 $O(N)$，无法更快（必须输出那么多行）。

## Part 4 — 正式解法（代码做了什么）

### 记号表（每个符号都定义清楚）

| 符号 | 含义 | 初始化 | 助记 |
|---|---|---|---|
| `k` | 输入，棋盘边长 $=2^k$ | 读入 | 边长指数 |
| `x1,y1` | 当前递归块的**左上角**（1 起） | 初值 `1,1` | 子问题定位 |
| `sz` | 当前递归块的边长 $=2^{d}$ | 初值 `1<<k` | 子块尺寸 |
| `px,py` | 当前块内**唯一洞**（公主）的 1 起坐标 | 初值读入 | 公主格 |
| `mid` | 当前块中线行/列 $=x_1+sz/2$（左上子块右下角 = $mid-1$，右上/左下子块起始 = $mid$） | 局部算 | 四象限分界 |
| `cx,cy` | 中心方块 $Q$ 的左上角 $=(mid, mid)$（$Q$ 占 $\{mid,mid\!+\!1\}\times\{mid,mid\!+\!1\}$） | 局部算 | 修复毯所属块 |
| `c` | 修复毯朝向 $1..4$（缺角：左上/左下/右下/右上） | 由公主所在角定 | 缺角编码 |
| `prx,pry` | 修复毯占走的格在**非公主象限**里的坐标（1 起），作为该子递归的公主格 | 局部算 | 子洞 |

### 算法步骤（`solve(x1,y1,sz,px,py)`）

1. **底步**：若 $sz=1$（即 $2^1\times 2^1$ 已不可能，实际底步是 $sz=2$ 且公主已知）——更准确地说，递归进行到"当前块只有 $2\times 2$ 且已知唯一公主格"时，直接输出这张毯：`cx=x1, cy=y1, c=` 公主所在角编码。
   - 等价实现：当 $sz=2$，$Q$ 就是当前块，修复毯 = 缺角为公主的毯，直接打印并返回。
2. **递归步**（$sz\ge 4$）：
   1. 计算 $mid=x_1+sz/2$，中心方块 $Q$ 左上角 $cx=cy=mid$。
   2. 由 $(px,py)$ 相对于 $mid$ 的上下/左右，判断公主落在哪个象限，并确定缺角编码 $c$：
      - $px<mid$（上）、$py<mid$（左）→ 公主在**左上**象限，缺左上 → $c=1$
      - $px<mid$（上）、$py\ge mid$（右）→ 公主在**右上**象限，缺右上 → $c=4$
      - $px\ge mid$（下）、$py<mid$（左）→ 公主在**左下**象限，缺左下 → $c=2$
      - $px\ge mid$（下）、$py\ge mid$（右）→ 公主在**右下**象限，缺右下 → $c=3$
   3. 输出中心修复毯：`mid mid c`。
   4. 对**其余三个**象限，分别算出修复毯占走格的 1 起坐标 $(prx,pry)$，并对该象限递归：
      - 若公主在左上 → 占走格在右上象限 $(mid, mid+1)$、左下 $(mid+1, mid)$、右下 $(mid+1,mid+1)$；
        对应三个子块左上角分别为 $(mid, mid+1)$ 右上、$(mid+1, mid)$ 左下、$(mid+1, mid+1)$ 右下，尺寸均 $sz/2$。
      - 其余三种公主位置对称处理（把公主所在象限跳过，只递归另外三个象限，子公主格 = 该象限在 $Q$ 里的那一格）。
   5. 对公主所在象限 $Q_p$，以原 $(px,py)$ 为子公主格递归（该象限内唯一的洞就是公主本身）。
   - 每个象限子问题尺寸 $sz/2$，递归直到 $sz=2$。

### 复杂度

- 时间 $O(4^{k})=O(N)$，$N=2^{2k}$（输出敏感最优，总毯数 $\frac{N-1}{3}$）。
- 空间：递归深度 $k\le 10$，栈 $O(k)$；无额外大数组。

### 校验状态

- 面积整除性：$2^{2k}-1\equiv 0\pmod 3$ 对一切 $k\ge 1$ 成立（2.1 已证），故毯数 $\frac{2^{2k}-1}{3}$ 为整数，输出行数精确。
- 正确性：由 2.4 归纳定理保证（每格恰一层、公主格不覆盖）。

## Part 5 — 示例代码（C++，按风格规范）

```cpp
// https://www.luogu.com.cn/problem/P1228
// L 形三格毯分治铺满；SPJ 校验合法性
#include<bits/stdc++.h>
using namespace std;

int k;
int px,py;        // 公主格，1 起

// 解一个左上角 (x1,y1)、边长 sz 的子块，块内唯一洞 (px,py)（均 1 起）
void solve(int x1,int y1,int sz,int px,int py)
{
	// 底步：2x2，整块就是一张缺角为公主的毯
	if(sz==2)
	{
		int c;
		if(px==x1&&py==y1)
			c=1;                       // 缺左上
		else if(px==x1&&py==y1+1)
			c=4;                       // 缺右上
		else if(px==x1+1&&py==y1)
			c=2;                       // 缺左下
		else
			c=3;                       // 缺右下
		cout<<x1<<' '<<y1<<' '<<c<<'\n';
		return;
	}

	int mid=x1+sz/2;                  // 中线：左上子块右下角=mid-1，右上/左下子块左上角=mid
	// 公主在哪个象限 -> 修复毯缺角 c 与三个子洞
	if(px<mid&&py<mid)                // 公主在左上象限，缺左上 c=1
	{
		cout<<mid<<' '<<mid<<' '<<1<<'\n';
		solve(mid,y1+sz/2,sz/2,mid,mid+1);          // 右上，洞( mid,mid+1 )
		solve(x1+sz/2,mid,sz/2,mid+1,mid);          // 左下，洞( mid+1,mid )
		solve(x1+sz/2,mid,sz/2,mid+1,mid+1);        // 右下，洞( mid+1,mid+1 )
		solve(x1,y1,sz/2,px,py);                    // 左上，洞=公主
	}
	else if(px<mid&&py>=mid)          // 公主在右上象限，缺右上 c=4
	{
		cout<<mid<<' '<<mid<<' '<<4<<'\n';
		solve(x1,y1+sz/2,sz/2,mid,mid);             // 左上，洞( mid,mid )
		solve(x1+sz/2,mid,sz/2,mid+1,mid);          // 左下，洞( mid+1,mid )
		solve(x1+sz/2,mid,sz/2,mid+1,mid+1);        // 右下，洞( mid+1,mid+1 )
		solve(mid,y1+sz/2,sz/2,px,py);              // 右上，洞=公主
	}
	else if(px>=mid&&py<mid)          // 公主在左下象限，缺左下 c=2
	{
		cout<<mid<<' '<<mid<<' '<<2<<'\n';
		solve(x1,y1+sz/2,sz/2,mid,mid);             // 左上，洞( mid,mid )
		solve(mid,y1+sz/2,sz/2,mid,mid+1);          // 右上，洞( mid,mid+1 )
		solve(x1+sz/2,mid,sz/2,mid+1,mid+1);        // 右下，洞( mid+1,mid+1 )
		solve(x1+sz/2,y1,sz/2,px,py);               // 左下，洞=公主
	}
	else                              // 公主在右下象限，缺右下 c=3
	{
		cout<<mid<<' '<<mid<<' '<<3<<'\n';
		solve(x1,y1+sz/2,sz/2,mid,mid);             // 左上，洞( mid,mid )
		solve(mid,y1+sz/2,sz/2,mid,mid+1);          // 右上，洞( mid,mid+1 )
		solve(x1+sz/2,mid,sz/2,mid+1,mid);          // 左下，洞( mid+1,mid )
		solve(x1+sz/2,mid,sz/2,px,py);              // 右下，洞=公主
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>k;
	cin>>px>>py;                     // 公主格，保持 1 起（与输出坐标一致，无需转换）
	solve(1,1,1<<k,px,py);
	return 0;
}
```

**坐标说明**：本题输入输出坐标均为 **1 起**，且输出要求就是毯子所属 $2\times 2$ 的左上角 $(x,y)$（1 起）。因此全程保持 1 起、不做 0-based 转换，避免引入边界偏移错误；`mid=x1+sz/2` 把块分成 $[x1,mid-1]$ 与 $[mid,x1+sz-1]$ 两半，中心方块 $Q$ 恰为 $\{mid,mid+1\}$，与四象限的共享关系一致。
