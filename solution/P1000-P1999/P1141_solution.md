# P1141 01迷宫 题解

---

## 1. 问题重述

给定一个 $n \times n$ 的 01 网格（$n \le 1000$，$m \le 10^5$ 次询问），移动规则是：

- 站在 `0` 格子上，只能走向相邻（上下左右）的 `1` 格子；
- 站在 `1` 格子上，只能走向相邻（上下左右）的 `0` 格子。

对于每次询问 $(i,j)$，输出从该格子出发，按照上述规则能到达的所有不同格子数（包含自身）。

---

## 2. 思路推导

### 2.1 把规则翻译成图

将每个格子看作一个节点。定义一条**无向边**：如果两个格子**相邻**且**数字不同**（一个是 0 另一个是 1），则它们之间可以互相移动。

> **为什么是无向边？**
>
> 假设格子 $u$ 是 `0`，格子 $v$ 是 `1`，它们相邻。从 $u$ 可以走到 $v$（因为 $u=0$ 且 $v=1$）；反过来从 $v$ 也可以走到 $u$（因为 $v=1$ 且 $u=0$）。条件只要求两格数字不同，不要求方向性，因此边是对称的。

于是原问题转化为：在一个 $n^2$ 个节点、最多约 $4n^2$ 条边的无向图中，对每个询问节点，求它所在连通分量的大小。

### 2.2 等价关系与连通分量

**引理 1**：图中的「可达性」是一个等价关系。

*证明*：

- **自反性**：每个格子到达自身，长度为 0 的路径，总是合法的。
- **对称性**：若存在一条路径 $u = v_0 \to v_1 \to \dots \to v_k = v$，其中每步 $v_t \to v_{t+1}$ 都满足数字不同。由于每一条边都是无向的，逆序路径 $v = v_k \to v_{k-1} \to \dots \to v_0 = u$ 的每步条件与原路径完全相同（数字不同与方向无关），因此也是合法路径。所以 $u$ 可达 $v$ 当且仅当 $v$ 可达 $u$。
- **传递性**：若 $u$ 可达 $v$，$v$ 可达 $w$，拼接两条路径即得 $u$ 可达 $w$。

因此节点被划分为若干个等价类，每个等价类对应图的一个连通分量。从类中任一节点出发能到达的节点集合就是整个等价类。

**推论**：对于同一连通分量内的任意两个格子，它们能到达的格子集合完全相同（就是整个分量本身）。

### 2.3 核心算法 — Flood-Fill / 连通分量染色

既然每个分量内的答案相同，我们只需：

1. 遍历所有尚未访问的格子，用 BFS（或 DFS）找出它所在的整个连通分量，同时给分量内每个格子标上**分量编号**，并记录该分量的大小。
2. 对于每次询问 $(i,j)$，直接输出该格子所在分量的大小。

这样预处理 $O(n^2)$，每次查询 $O(1)$，总复杂度 $O(n^2 + m)$，完全满足 $n \le 1000$（$n^2 = 10^6$）和 $m \le 10^5$ 的限制。

### 2.4 为什么不能对每个询问独立 BFS？

最坏情况下 $m = 10^5$，每次 BFS 最坏 $O(n^2)$，总复杂度 $O(m n^2) = 10^{11}$，不可接受。预处理的必要性由此而来。

## 3. 模式总结

| 关键观察 | 对应策略 |
|---|---|
| 移动规则只依赖两格数字不同，与方向无关 | 图是无向的，可达性是对称的 |
| 从同一连通分量任意点出发，答案相同 | 只需对每个分量预处理一次 |
| $n \le 1000$ 网格最多 $10^6$ 格 | BFS/DFS 预处理可行 |
| $m \le 10^5$ 查询量大 | 必须 $O(1)$ 回答每个查询 |

## 4. 正式解法

### 符号约定

- $n$：网格边长
- $g[i][j] \in \{0,1\}$：网格字符（已转为整数）
- $id[i][j]$：格子 $(i,j)$ 所属连通分量的编号（$-1$ 表示未访问）
- $sz[c]$：编号为 $c$ 的连通分量的大小
- 四个方向向量：$dx = \{-1,1,0,0\},\ dy = \{0,0,-1,1\}$

### 算法流程

```
预处理阶段：
  1. 初始化 id[][] = -1, 分量计数器 comp = 0
  2. 遍历 i = 0..n-1, j = 0..n-1:
       若 id[i][j] != -1，跳过
       否则：
         comp++
         以 (i,j) 为起点 BFS：
           - 队列初始放入 (i,j)
           - cnt = 0
           - 当队列非空：
               弹出 (x,y)，id[x][y] = comp，cnt++
               枚举四个邻居 (nx,ny)：
                 若越界或 id[nx][ny] != -1，跳过
                 若 g[x][y] == g[nx][ny]（数字相同），跳过
                 将 (nx,ny) 入队
           - sz[comp] = cnt

查询阶段：
  对每个询问 (x,y)：
    输出 sz[id[x-1][y-1]]   // 转换为 0 基
```

### 复杂度分析

- 时间：$O(n^2 + m)$。每个格子被 BFS 恰好访问一次（每条边至多检查两次）。
- 空间：$O(n^2)$。存储 $g$、$id$、$sz$ 数组。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};
int n,m;
char _g[mxn][mxn];
int g[mxn][mxn];
int id[mxn][mxn];
int sz[mxn*mxn];
int dx[4]{-1,1,0,0};
int dy[4]{0,0,-1,1};

void bfs(int sx,int sy,int comp)
{
	int cnt{0};
	queue<pair<int,int>> q;
	q.emplace(sx,sy);
	id[sx][sy]=comp;
	while(!q.empty())
	{
		auto[x,y]=q.front(); q.pop();
		++cnt;
		for(int d{0};d<4;++d)
		{
			int nx{x+dx[d]},ny{y+dy[d]};
			if(nx<0||nx>=n||ny<0||ny>=n)continue;
			if(id[nx][ny]!=-1)continue;
			if(g[nx][ny]==g[x][y])continue;
			id[nx][ny]=comp;
			q.emplace(nx,ny);
		}
	}
	sz[comp]=cnt;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>m;
	for(int i{0};i<n;++i)cin>>_g[i];
	for(int i{0};i<n;++i)
		for(int j{0};j<n;++j)
			g[i][j]=_g[i][j]-'0';
	fill_n(&id[0][0],mxn*mxn,-1);
	int comp{0};
	for(int i{0};i<n;++i)
	{
		for(int j{0};j<n;++j)
		{
			if(id[i][j]!=-1)continue;
			++comp;
			bfs(i,j,comp);
		}
	}
	while(m--)
	{
		int x,y;cin>>x>>y;
		--x;--y;
		cout<<sz[id[x][y]]<<'\n';
	}
	return 0;
}
```

### 代码说明

- `_g` 用于直接读入行的字符串，然后转为 `int` 数组 `g` 方便比较。
- `id` 使用 `fill_n` 全部初始化为 `-1` 表示未访问，注意大小是 `mxn*mxn`（约 $10^6$，在栈上静态分配可以，也可用 `memset`）。
- BFS 使用 `std::queue`，入队时立即标记 `id` 防止重复入队。
- 每条边条件 `g[nx][ny] == g[x][y]` 不满足时才走（即数字不同），恰好对应题目规则。
- 所有循环变量使用 `int d{0}` 的统一初始化风格。
- 查询时转为 0 基，直接查表输出 `sz[id[x][y]]`。
