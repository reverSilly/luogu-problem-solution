# P1960 [JOI 2007 Final] 郁闷的记者

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $N$ 支球队，编号 $1\sim N$，实力有严格的全序（没有平局、名次互不相同，且名次靠前的球队一定能赢名次靠后的球队）。现在只知道其中 $M$ 场比赛的结果：$X_i$ 能打败 $Y_i$。要求：

1. 给出一个 $1\sim N$ 的排列，作为满足这 $M$ 条结果的一种排名（若 $X$ 打败 $Y$，则 $X$ 排在 $Y$ 前面）；
2. 再判断：满足这些结果的排名是否**唯一**。唯一输出 `0`，否则输出 `1`。

### 1.2 关键约束与规模暗示

- $N\le 5000$，$M\le 10^5$。
- $30\%$：$N\le 7$，$M\le 15$，可以枚举全排列暴力检验。
- $60\%$：$N\le 100$，$M\le 2000$，$O(N^2)$ 级别的做法够用。
- $100\%$：$N\le 5000$，$M\le 10^5$，需要 $O(N+M)$ 或 $O((N+M)\log N)$ 的做法，正好是拓扑排序的复杂度。
- 题目有 Special Judge：任意合法排名都会被接受，只有“是否存在另一种排名”这个判断和排名的合法性会被检查。

**题意澄清**：题面第 3 条“对于所有 $1\le a<b\le N$，第 $a$ 名的球队一定可以打败第 $b$ 名的球队”描述的是隐藏的真实全序所具有的性质，而不是额外给出的输入。因此输入给的是一张有向图的部分边，我们要找的是与这些边相容的任意线性序。下文都按这个理解。

---

## 2. 思维链（Chain-of-thought）

### 2.1 把“排名”翻译成图论语言

对每条结果建有向边 $X\to Y$，含义是“$X$ 必须排在 $Y$ 前面”。一个排列 $p_1,\dots,p_N$（$p_k$ 是第 $k$ 名）合法，当且仅当对每条边 $X\to Y$，$X$ 在排列中的位置小于 $Y$ 的位置。

这正是**拓扑序**的定义。

**引理 1**：一个排列是合法排名，当且仅当它是这张有向图的一个拓扑序。

**证明**：

- （$\Rightarrow$）若排列合法，则每条边 $X\to Y$ 都有 $X$ 排在 $Y$ 前，按拓扑序定义（每条有向边都从较前指向较后）它就是一个拓扑序。
- （$\Leftarrow$）若排列是拓扑序，则每条边 $X\to Y$ 都满足 $X$ 在 $Y$ 前，即所有给定比赛结果都被满足，排列合法。$\square$

于是问题变成：**求一个拓扑序，并判断拓扑序是否唯一**。

### 2.2 求任意一个拓扑序：Kahn 算法

维护每个点的入度。初始把所有入度为 $0$ 的点入队；每次取出队首 $u$ 输出，并把 $u$ 的所有出边删掉（终点的入度减一），若某终点入度变成 $0$ 就入队。重复到队列为空。若输出的点数等于 $N$，就得到一个拓扑序。

正确性来自经典结论：DAG 中一定存在入度为 $0$ 的点；删去它不破坏“无环”。题目保证真实排名存在，所以这张图无环，Kahn 一定能输出全部 $N$ 个点。

### 2.3 判定唯一性

**引理 2（唯一性判据）**：这张图的拓扑序唯一，当且仅当 Kahn 算法执行的每一步中，队列里都恰好只有 $1$ 个点。

**证明**：

先证“若某一步队列中有至少 $2$ 个点，则拓扑序不唯一”。

设在某一步（已经输出了某个前缀 $P$）队列中有两个不同的点 $u,v$，它们的剩余入度都是 $0$。

- 首先，$u,v$ 之间不可能有边。否则若 $u\to v$，则此刻 $v$ 的剩余入度至少为 $1$，与 $v$ 入度为 $0$ 矛盾；$v\to u$ 同理。
- 因为剩下的图仍是 DAG（删点、删边不会造环），从“剩余图”出发分别以 $u$ 为第一个点、以 $v$ 为第一个点做 Kahn，都能把剩余点全部输出（每一步都至少有一个入度为 $0$ 的点，队列非空直到用完）。
- 于是得到两个排列：前缀都是 $P$，但下一个点一个是 $u$、一个是 $v$。它们不同，且都是合法拓扑序。

所以拓扑序不唯一。

再证“若每一步队列都只有 $1$ 个点，则拓扑序唯一”。

- 此时 Kahn 每一步的选择都被唯一确定（队列中只有那一个点），因此算法输出的排列是唯一的。
- 对任意一个拓扑序 $q$，它的第一个点必须是某个入度为 $0$ 的点。第一步队列只有 $1$ 个入度 $0$ 的点，所以 $q$ 的第一个点只能是它，与算法相同。删去该点后，对剩余图递归使用同样的论证（算法的后续每一步队列也都只有 $1$ 个点），可知 $q$ 与算法输出逐位相同。因此所有拓扑序都等于算法输出，拓扑序唯一。$\square$

注意：若图中存在环，则不存在拓扑序，也就谈不上唯一性；题目保证存在排名，故不会出现。实现时若输出点数 $<N$（有环），说明输入与题意矛盾，此时无论输出什么都不可能是合法排名，不过本题数据不会出现这种情况。

### 2.4 实现细节

- 队列里出现多个点只说明“当前有两个及以上可选的下一名”，并不需要知道具体有几个，只要用 `Q.size()>1` 标记即可。
- 输入边可能有重复（同一对 $(X,Y)$ 出现多次）。重复边在 Kahn 中会被删除多次、入度也相应加/减多次，最终仍然正确（每条重复边都被“删”一次），不影响拓扑序与唯一性判定。
- 输出需要 $N+1$ 行：前 $N$ 行每行一个球队编号（1-based），最后一行是 `0` 或 `1`。

## 3. 模式总结（Pattern Summary）

- **explore its property** — “排名合法”等价于“该排列是有向图的拓扑序”。
- **classic problem solution** — Kahn 求任意拓扑序，$O(N+M)$。
- **uniqueness by queue size** — 拓扑序唯一 $\iff$ 每一步入度为 $0$ 的点恰有一个。
- **prove both directions** — 多个零入度点可交换顺序；唯一时逐步强制。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 球队数 | 读入 | $\le 5000$ |
| `m` | `int` | 给出的比赛场数 | 读入 | $\le 10^5$ |
| `indeg[i]` | `int [5005]` | 点 $i$ 的入度 | 0 | in-degree |
| `g[i]` | `vector<int> [5005]` | $i$ 的出边终点 | 空 | graph |
| `Q` | `queue<int>` | 当前入度为 $0$ 的点 | 全部零入度点 | queue |
| `amb` | `bool` | 是否出现过多个零入度点 | false | ambiguous |
| `ord` | `vector<int>` | 输出的拓扑序 | 空 | order |

### 4.2 算法步骤

1. 读入 $N,M$ 与每条边 $X\to Y$（内部转 0-based）：`g[X].push_back(Y)`，`++indeg[Y]`。
2. 把所有 `indeg[i]==0` 的点压入队列。
3. 反复执行：若出队前 `Q.size()>1`，令 `amb=true`；取队首 $u$ 加入 `ord`；对 $u$ 的每个出边终点 $v$ 执行 `--indeg[v]`，若变成 $0$ 则入队。
4. 按 `ord` 输出每个点编号加一（每行一个），最后输出 `amb ? 1 : 0`。

### 4.3 复杂度分析

- 时间：每条边被处理一次，每个点入队出队一次，$O(N+M)$。
- 空间：$O(N+M)$（邻接表 + 入度 + 队列）。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{5005};

int n,m,indeg[mxn];
vector<int>g[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,x,y;i<m;++i)
	{
		cin>>x>>y;--x;--y;
		g[x].push_back(y);
		++indeg[y];
	}

	queue<int>Q;
	for(int i=0;i<n;++i)
		if(!indeg[i])
			Q.push(i);

	bool amb{false};
	vector<int>ord;
	while(!Q.empty())
	{
		if(Q.size()>1)
			amb=true;
		int u=Q.front();Q.pop();
		ord.push_back(u);
		for(int v:g[u])
			if(--indeg[v]==0)
				Q.push(v);
	}
	for(int u:ord)
		cout<<u+1<<'\n';
	cout<<(amb?'1':'0')<<'\n';
	return 0;
}
```
