# P1640 [SCOI2010] 连续攻击游戏 题解

> 标签：并查集 / 二分图匹配 / 图论建模 · 难度：提高/省选-

## 1. 重新读题

**问题重述（人话版）**

有 $N$ 件装备，第 $i$ 件装备有两个属性值 $(u_i, v_i)$，取值范围均为 $[1, 10000]$。每件装备最多只能使用一次，且使用时只能选择它的两个属性值之一。攻击必须从属性值 $1$ 开始连续递增进行（即依次需要属性值为 $1, 2, \dots, k$ 的不同装备）。求最多可以连续攻击多少次（即最大的 $k$）。

**约束与规模暗示**

- $30\%$ 数据：$N \le 10^3$；
- $100\%$ 数据：$1 \le N \le 10^6$，属性值 $\in [1, 10000]$。
- 规模暗示：装备数 $N = 10^6$ 很大，但属性值域上界 $V = 10000$ 很小。若建二分图跑匈牙利算法，最坏 $O(V \cdot N)$ 可能超时；而利用“每件装备恰好连接两个属性点”的图结构性质，可以用并查集做到线性复杂度 $O(N + V \alpha(V))$。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把“二选一装备”建模为无向图的边定向

把每个属性值 $x \in [1, 10000]$ 看作无向图中的一个顶点，把每件装备 $(u_i, v_i)$ 看作连接顶点 $u_i$ 与 $v_i$ 的一条无向边。“每件装备至多用一次，且选择其中一个属性被匹配”等价于：**给每条边至多指定一个端点作为它所覆盖的顶点，使得每个顶点至多被一条边覆盖**。

### 2.2 简化版：二分图最大匹配（$30\%$ 子任务）

左部为属性值 $1 \dots 10000$，右部为 $N$ 件装备。从属性 $1$ 开始依次尝试寻找增广路（匈牙利算法），一旦某个属性 $i$ 无法增广即停止，输出 $i - 1$。

### 2.3 归约到经典算法：连通块（树 vs 基环树/环图）的覆盖充要条件与并查集维护

**引理 1（连通块的顶点覆盖能力刻画）**

设无向图的一个连通块包含 $v$ 个顶点和 $e$ 条边：
1. 若 $e = v - 1$（该连通块是一棵树），则至多能同时覆盖其中的 $v - 1$ 个顶点，且**任意包含 $v - 1$ 个顶点的子集**都可以被同时覆盖；特别地，为了尽可能覆盖从 $1$ 开始的连续前缀，我们可以覆盖该树中**除最大编号顶点 $\max V_C$ 以外的所有 $v - 1$ 个顶点**。
2. 若 $e \ge v$（该连通块至少含有一个环），则该连通块中的**全部 $v$ 个顶点**都可以被同时覆盖。

**证明**：
1. 当 $e = v - 1$ 时，由于每条边至多覆盖 $1$ 个顶点，总覆盖顶点数不可能超过 $e = v - 1$。反之，任取连通块中不想覆盖的那个顶点 $r$（例如取 $r = \max V_C$）作为树根，将树中每条边定向为背离根 $r$（即每条边覆盖其子节点），则除根 $r$ 以外的 $v - 1$ 个顶点恰各有唯一的父边覆盖它。
2. 当 $e \ge v$ 时，连通块中存在一棵生成树 $T$ 以及至少一条非树边 $e_0 = (x, y)$。将 $x$ 作为生成树 $T$ 的根，树边全部定向为覆盖子节点，可覆盖 $V_C \setminus \{x\}$；再用非树边 $e_0$ 覆盖根节点 $x$，即实现了全部 $v$ 个顶点的完整覆盖。
此外，由于不同连通块之间的边集与点集互不相交，各连通块的覆盖方案完全独立。因此，从 $i = 1, 2, \dots, 10000$ 依次检查：属性 $i$ 能够被覆盖（在不牺牲任何 $< i$ 的同连通块顶点的前提下），当且仅当 $i$ 所在连通块满足 $e \ge v$，或者 $e = v - 1$ 且 $i < \max V_C$。$\blacksquare$

## 3. 模式总结（Pattern Summary）

- **explore its property** — 将“每件物品有两个候选属性、至多选一”转化为属性顶点集上的无向边定向覆盖问题。
- **consider easier version** — 建立属性与物品的二分图，从 $1$ 开始逐个跑匈牙利增广。
- **reduce to easier problem** — 证明树形连通块（$e=v-1$）恰能覆盖除最大顶点外的全部顶点，而含环连通块（$e \ge v$）能覆盖全部顶点（引理 1）。
- **classic problem solution** — 用并查集维护每个连通块的最大顶点编号 `mx[r]` 与含环标记 `cyc[r]`，随后单遍扫描 $1 \dots 10000$ 即得答案。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `n` | `int` | 装备数量 $N$ | 读入 | 边数 |
| `f[mxv]` | `int [10005]` | 并查集父节点数组 | `f[i] = i` | DSU 代表元 |
| `mx[mxv]` | `int [10005]` | 连通块内最大属性编号 | `mx[i] = i` | 树根放弃点 |
| `cyc[mxv]` | `bool [10005]` | 连通块是否满足 $e \ge v$（含环） | `false` | 满覆盖标记 |

### 4.2 算法步骤

1. 初始化 $i \in [1, 10000]$ 的并查集：`f[i] = i, mx[i] = i, cyc[i] = false`。
2. 读入 $N$ 条边 $(u, v)$：
   - 令 `ru = getrt(u), rv = getrt(v)`；
   - 若 `ru == rv`，令 `cyc[ru] = true`；
   - 否则合并 `f[ru] = rv`，更新 `mx[rv] = max(mx[rv], mx[ru])` 与 `cyc[rv] = cyc[rv] || cyc[ru]`。
3. 从 $i = 1$ 到 $10000$ 递增检查：设 `r = getrt(i)`，若 `cyc[r] || i < mx[r]` 则 `ans = i`，否则立即 `break`。输出 `ans`。

### 4.3 复杂度与验证报告

- **时间复杂度**：$O(N \alpha(V) + V)$，其中 $V = 10000$。
- **空间复杂度**：$O(V)$。
- **对拍验证**：`appendix/P1640/P1640_check.py` 中与匈牙利算法暴力基准完成 **500 组随机数据对拍**全部一致；$N = 200,000$ 规模实测耗时 **0.1153 s**。

## 5. 示例代码

```cpp
//
// 题目：P1640 [SCOI2010] 连续攻击游戏
// https://www.luogu.com.cn/problem/P1640
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxv{10005};

int n,f[mxv],mx[mxv];
bool cyc[mxv];

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	for(int i=1;i<mxv;++i)
	{
		f[i]=i;
		mx[i]=i;
		cyc[i]=false;
	}

	cin>>n;
	for(int i=0,u,v;i<n;++i)
	{
		cin>>u>>v;
		int ru=getrt(u),rv=getrt(v);
		if(ru==rv)
			cyc[ru]=true;
		else
		{
			f[ru]=rv;
			mx[rv]=max(mx[rv],mx[ru]);
			cyc[rv]=cyc[rv]||cyc[ru];
		}
	}

	int ans=0;
	for(int i=1;i<mxv;++i)
	{
		int r=getrt(i);
		if(cyc[r]||i<mx[r])
			ans=i;
		else
			break;
	}
	cout<<ans<<'\n';
	return 0;
}
```
