# P1143 进制转换

## 1. 重述问题

给定一个 n 进制数（n ≤ 16，数字 0-9 和 A-F），将它转换为 m 进制并输出。输入只有一行数，数据保证对应十进制不超过 10⁹。

## 2. 推理链

### 2.1 通用转换流程

进制转换最通用的做法是两步走：

1. **n 进制 → 十进制**：按位展开求和（秦九韶/霍纳加速，同时可避免大数溢出）。
2. **十进制 → m 进制**：不断除以 m 取余数，余数逆序输出。

### 2.2 为什么按这个方法

- 中间统一用十进制作为媒介，可以处理任意两个进制之间的转换，而不需要分别考虑 2 的幂关系等特殊情况。
- 题目保证十进制结果 ≤ 10⁹，所以 `int`（约 2×10⁹）足够，但用 `long long` 更稳妥。

### 2.3 字符 ↔ 数字映射

- 字符 '0'-'9' → 数字 0-9：`c - '0'`
- 字符 'A'-'F' → 数字 10-15：`c - 'A' + 10`
- 逆映射：0-9 → '0'+d，10-15 → 'A'+(d-10)

### 2.4 正确性证明概要

**引理**：十进制数 x 的 m 进制表示中，最低位是 x mod m，剩余高位是 ⌊x/m⌋ 的 m 进制表示。

证明：设 x = aₖ·mᵏ + aₖ₋₁·m^(k-1) + ... + a₁·m + a₀。则 x mod m = a₀，且 ⌊x/m⌋ = aₖ·m^(k-1) + ... + a₁，即其 m 进制表示为 aₖ...a₁。从低位到高位不断除以 m 取余即可。□

**引理**：n 进制数按位展开（x = x·n + digit 逐个迭代）得到正确的十进制值。

证明：这是秦九韶展开 x·n + digit，等价于 x = Σ digitᵢ·n^(len-1-i)，即 n 进制的定义。□

### 2.5 边界情况

- n = 进制数本身是 0 的情况：题目输入的是正整数，但转换结果可能为 0（如输入 "0" 转任意进制）。虽题目不保证，安全起见处理 x == 0 的情况输出 "0"。
- 除零：m ≥ 2，不影响。

## 3. 模式总结

- **两步转换法** — 任意进制 → 十进制 → 目标进制
- **霍纳展开** — 读入时直接累乘累加
- **短除法取余** — 除以目标进制取余数，逆序输出
- **字符映射** — 数字与字符互转

## 4. 真实解法

### 符号表

| 符号 | 含义 |
|------|------|
| `n` | 输入进制 |
| `s` | n 进制字符串 |
| `m` | 输出进制 |
| `x` | 中间十进制值（long long） |
| `c2v[c]` | 字符到数字的映射 |
| `v2c[v]` | 数字到字符的映射 |

### 算法步骤

1. 读入 n、字符串 s、m
2. 将 s 从高到低逐位转为数字，累乘累加得到十进制值 x：
   for each 字符 c in s: x = x * n + val(c)
3. 如果 x == 0，直接输出 "0"
4. 否则循环：
   - 记 d = x % m，把 v2c[d] 加入结果
   - x /= m
   - 直到 x == 0
5. 将结果逆序输出

### 复杂度

O(len + 位数)，len 为输入串长度。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int n,m;
string s;

int val(char c)
{
	if(c>='0'&&c<='9')
		return c-'0';
	return c-'A'+10;
}

char chr(int v)
{
	if(v<10)
		return char('0'+v);
	return char('A'+v-10);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>s>>m;
	i64 x=0;
	for(char c:s)
		x=x*n+val(c);
	if(x==0)
	{
		cout<<"0\n";
		return 0;
	}
	string ans;
	while(x)
	{
		ans+=chr((int)(x%m));
		x/=m;
	}
	reverse(ans.begin(),ans.end());
	cout<<ans<<'\n';
	return 0;
}
```
