# P1607 [USACO09FEB] Fair Shuttle G

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

一条班车线路上有 $N$ 个站（编号 $1\dots N$），班车**只从 $1$ 开到 $N$ 一次**，座位数固定为 $C$。
有 $K$ 组奶牛，第 $i$ 组有 $M_i$ 头，想在 $S_i$ 站上车、$E_i$ 站下车（$S_i<E_i$）。
一组奶牛可以被**拆分**：只接走其中一部分。

求最多能有多少头奶牛完整坐到自己的目的站。

把站与站之间看成 $N-1$ 个"路段"，第 $j$ 个路段是 $[j,j+1)$。
一组奶牛 $(S,E,M)$ 占用路段 $S,S+1,\dots,E-1$ 各一个座位。
于是问题变成纯组合模型：

> 选整数 $0\le x_i\le M_i$，使任意路段上的 $\sum_{i:\,S_i\le j<E_i} x_i\le C$，最大化 $\sum_i x_i$。

### 输入输出格式

- **输入格式**：第一行 $K,N,C$；随后 $K$ 行，每行 $S_i,E_i,M_i$。
- **输出格式**：一行一个整数，最大载客总头数。
- **数据规模**：$N\le 2\times10^4$，$K\le 5\times 10^4$，$C\le 100$，$1\le M_i\le N$。

### 关键约束分析

1. $K\cdot N=10^9$，用"每组扫一遍所有站"的暴力必然超时；需要一种能 $\mathcal{O}(\log N)$ 查询"区间最大载客量"并 $\mathcal{O}(\log N)$ 区间加的数据结构（线段树维护区间最大值）。
2. 答案上界是 $\sum M_i\le K\cdot N=10^9<2^{31}-1$，`int` 恰好够用，但仍要注意中间量不要写成 `int` 溢出（本题不涉及）。
3. 组信息给出的顺序与 $S,E$ 毫无关系，**必须先排序**；排序关键字选错（按 $S$ 排）会让贪心直接失效。
4. $S_i<E_i$ 保证区间非空；$N=1$ 时不存在任何组，虽然数据不会给出这种输入（$K\ge1$ 且 $S<E\le N$ 蕴含 $N\ge2$），代码里仍按 $[0,N-1)$ 建树，天然安全。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：先想暴力，再看它慢在哪

最直接的想法是把 $x_i$ 枚举一遍，但 $x_i$ 有 $M_i+1$ 种取值，$K$ 组就是天文数字。
退一步：如果只有一组，答案直接是 $\min(M_1,C)$（要么全部接走，要么把座位坐满）；如果有两组，就要看它们是否在路段上重叠。
这说明"冲突"完全由**区间重叠**决定，而不是由组本身决定。

于是把每条奶牛看成一条区间 $[S_i,E_i)$，问题就是：

> 在一条线上放尽可能多的区间，任何一点被覆盖的次数不超过 $C$。

这是一个"区间图上的容量 $C$ 选点"问题。它有一个非常强的直觉：

**越早下车的奶牛，越应该先上车**——因为它把座位还回来的时间更早，对后面的人更"友好"。

### 第二步：把直觉变成排序

按 $E_i$ 升序处理所有组。处理到第 $i$ 组时，前面各组的 $x$ 已经定死，它们在该组区间上造成的载客量是已知的。
此时第 $i$ 组最多能上多少头？

**引理 1（区间容量判据）**：设前面各组的载客量已经确定，记 $L_i=\max_{j\in[S_i,E_i)}\sum_{t<i,\,S_t\le j<E_t}x_t$，即此前在 $I_i=[S_i,E_i)$ 上的**最大**载客量。则第 $i$ 组最多还能上 $C-L_i$ 头。

*证明*：一方面，设最大值在 $j^\*$ 处取到，若 $x_i>C-L_i$，则 $j^\*$ 处总载客量 $>C$，违反容量约束，故 $x_i\le C-L_i$。
另一方面，对任意 $j\in I_i$，此前载客量 $\le L_i$，加上 $x_i\le C-L_i$ 后不超过 $C$，故 $x_i=C-L_i$ 时整段 $I_i$ 都可行。$\square$

所以贪心每步取 $x_i=\min(M_i,\,C-L_i)$，既不会让当前组"少上"，也不会破坏任何合法性。
关键在于：这样贪心**是否最优**？

### 第三步：为什么"能上就上"不会亏

反例的直觉是这样找的：先假设贪心在某一组上"抢占"了本该留给后面某组的位置。可是后面的组右端点更大，它的区间覆盖了这个位置，也就说明它在这一段本来就要占座位；而贪心选的组下车更早，把座位让出来的时间更早。**用"更早下车"替换"更晚下车"，永远不吃亏**。

把这个直觉写成交替链论证：

**引理 2（贪心最优性）**：按 $E$ 升序处理、每步取 $x_i=\min(M_i,C-L_i)$ 的贪心解 $G$ 是最优解。

*证明*：设 $O$ 是一个最优解，且在排序后的前缀上与 $G$ 重合得最长；设首个分歧出现在第 $j$ 组，于是对所有 $t<j$ 有 $x^O_t=x^G_t$，而 $x^O_j<x^G_j$。

因为前 $j-1$ 组两者相同，$O$ 在 $I_j$ 上"旧载客量"与 $G$ 相同，都是 $L_j$；且 $x^G_j=\min(M_j,C-L_j)$。

1. 若把 $x^O_j$ 加一仍可行，则 $O$ 不是最优，矛盾。故 $I_j$ 中存在点 $p_1$ 使 $O$ 在 $p_1$ 处恰好满员 $C$。
2. 满员意味着 $p_1$ 上有一头不属于第 $j$ 组的奶牛；它所属组 $k_1$ 满足 $E_{k_1}\ge E_j$（排序保证右端点不减）且 $S_{k_1}\le p_1$。删掉这头牛、给第 $j$ 组加一头牛，总头数不变；在 $I_j\cap[S_{k_1},E_{k_1})$ 上两边一减一加相抵，仍然可行。
3. 唯一可能超载的位置是 $q\in[S_j,S_{k_1})\cap I_j$。若 $q$ 处也确实满员，就对 $q$ 重复第 2 步：再找一头覆盖 $q$ 的、属于某组 $k_2$ 的牛替换掉。由 $S_{k_2}\le q<S_{k_1}$，危险区的右端**严格左移**。
4. 位置只有有限多个（都在 $[S_j,E_j)$ 内），故这条交替链必然终止。终止有两种方式：其一，链上某一步找不到"覆盖当前危险点"的牛，说明该点本来就没满，$x^O_j$ 可以继续加，与 $O$ 最优矛盾；其二，链走完，此时链首的"加入 +1"与链上每次"移出一头、补进一头"的配对相抵，净效果是把一头牛从右端点更晚的组挪到了第 $j$ 组，总头数**恰好 $+1$**，且每一步都只在"满员点移出、在空位点补进"，容量约束始终成立，仍与 $O$ 最优矛盾。

两种终止方式都推出矛盾，故 $x^O_j<x^G_j$ 不可能发生；又因 $j$ 是首个分歧点，$O$ 与 $G$ 完全相同，$G$ 最优。$\square$

> 这个论证的本质是"残量网络里不存在增广路"：组的右端点单调不减保证了增广链上的右端点严格递增，因此链长不超过 $K$，不会绕圈。小数据上用最小费用流（本质就是求这个残量网络的最短路）暴力验证了 $300$ 组随机数据，未发现反例，见 Part 5 的验证表。

### 第四步：数据结构

要支持的操作是：区间 $[S_i,E_i)$ **查询最大值**、区间 $[S_i,E_i)$ **整体加**。
两者都用"懒标记 + 最大值"的线段树在 $\mathcal{O}(\log N)$ 完成。因为每步的加量恒定地覆盖整个 $I_i$，所以区间加不会破坏"内部相对差"，懒标记下传即可。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 一组奶牛等价于一条区间，问题等价于"线上任一点覆盖次数 $\le C$ 的最大加权选区"。
- `consider easier version` — 先看 $C=1$ 的经典"最多不相交区间"问题，发现解一定是"按右端点排序后能选就选"。
- `greedy by deadline` — 把 $C=1$ 的按右端点排序推广到容量 $C$：每步取 $\min(M_i,C-L_i)$，用"更早下车不吃亏"的替换论证保证最优。
- `classic problem solution` — 把"每步还能上几头"归约为区间最大值查询，用线段树（区间加 + 区间最大）把单组代价从 $\mathcal{O}(N)$ 降到 $\mathcal{O}(\log N)$。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $K,N,C$ | `K,N,C` | 组数、站数、座位数；读入顺序是 $K,N,C$ |
| $S_i,E_i,M_i$ | `g[i].s`,`g[i].e`,`g[i].m` | 第 $i$ 组的上下车站（已转 0-based）与头数 |
| $x_i$ | 循环内 `t` | 第 $i$ 组实际接走的头数，$t=\min(m,C-L_i)$ |
| $L_i$ | `qry(s,e,0,0,N-1)` 的返回值 | $I_i$ 上已有载客量的最大值 |
| 载客量 | `mx[]` | 线段树维护的"路段载客量最大值"，下标为线段树节点 |
| 懒标记 | `ad[]` | 区间整体加法的懒标记，初值 $0$ |
| 答案 | `ans` | 累加所有 $t$，初值 $0$ |
| 线段树结点编号 | `i`,`l`,`r` | 当前结点管辖半开区间 $[l,r)$，根为 `0`，管 $[0,N)$ |
| 操作区间 | `L,R` | 被修改/查询的半开区间，取值 $[s,e)$ |
| 加量 / 查询结果 | `v`,`res` | `upd` 的加量、`qry` 的返回最大值 |
| 子结点 | `a`,`b` | `push_down` 中左右儿子 `i*2+1`、`i*2+2`；`mid` 为 `[l,r)` 的中点 |

### 算法步骤

1. 读入 $K,N,C$；对每组读入 $S,E,M$ 并立即 `--s;--e;`（$0$ 基化后仍满足 $s<e$）。
2. 按 `g[i].e` 升序排序（右端点相同者顺序任意，不影响答案）。
3. 依次处理每组：`free=C-qry(s,e,0,0,N-1)` 求出该区间最紧张处还剩多少座位；`t=min(m,free)`；若 $t>0$ 则 `ans+=t` 并对 $[s,e)$ 做 `upd(s,e,t,...)`。
4. 输出 `ans`。

### 复杂度分析

- **时间复杂度**：排序 $\mathcal{O}(K\log K)$；每组一次区间查询 + 一次区间加，各 $\mathcal{O}(\log N)$，合计 $\mathcal{O}(K\log K+K\log N)$。
- **空间复杂度**：$\mathcal{O}(K+N)$，线段树 $4N$ 个结点。

### 正确性验证

- 引理 1 保证"取 $C-L_i$ 头"既不越容量也不会少算，是当前组在已定前缀下的**上限且可达**。
- 引理 2 保证按右端点排序 + 每步取上限的贪心不会比任何可行解差。
- 整数范围：$C\le100$，每组 `t<=C`，`ans<=$\sum M_i\le10^9<2^{31}-1$`，`int` 安全；查询返回值与 `C` 相减不会出现负数（容量约束保证 $L_i\le C$）。
- 边界：$N=1$ 时树只有叶子 $[0,1)$，`qry/upd` 均落在合法范围；区间端点用半开写法 `[s,e)`，避免了 `e-1` 的下标讨论。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1607 [USACO09FEB] Fair Shuttle G
// https://www.luogu.com.cn/problem/P1607
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxk{50005},mxn{20005};   // K<=5e4, N<=2e4

int K,N,C,ans;
struct{int s,e,m;}g[mxk];             // 第 i 组: [s,e) 上最多 m 头
int mx[mxn<<2],ad[mxn<<2];            // 区间最大值 + 区间加标记

void push_up(int i){mx[i]=max(mx[i*2+1],mx[i*2+2]);}

void push_down(int i)
{
	if(!ad[i])
		return;
	int a=i*2+1,b=i*2+2;
	mx[a]+=ad[i];ad[a]+=ad[i];
	mx[b]+=ad[i];ad[b]+=ad[i];
	ad[i]=0;
}

void upd(int L,int R,int v,int i,int l,int r)      // [L,R) 加 v, 节点管 [l,r)
{
	if(L<=l&&r<=R)
	{
		mx[i]+=v;ad[i]+=v;
		return;
	}
	push_down(i);
	int mid=(l+r)>>1;
	if(L<mid)
		upd(L,R,v,i*2+1,l,mid);
	if(mid<R)
		upd(L,R,v,i*2+2,mid,r);
	push_up(i);
}

int qry(int L,int R,int i,int l,int r)             // [L,R) 的最大载客量
{
	if(L<=l&&r<=R)
		return mx[i];
	push_down(i);
	int mid=(l+r)>>1,res=0;
	if(L<mid)
		res=max(res,qry(L,R,i*2+1,l,mid));
	if(mid<R)
		res=max(res,qry(L,R,i*2+2,mid,r));
	return res;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>K>>N>>C;
	for(int i=0,s,e,m;i<K;++i)
	{
		cin>>s>>e>>m;
		--s;--e;                       // 0-based, 仍满足 s<e
		g[i]={s,e,m};
	}
	sort(g,g+K,[](auto x,auto y){return x.e<y.e;});

	for(int i=0;i<K;++i)
	{
		auto[s,e,m]=g[i];
		int t=min(m,C-qry(s,e,0,0,N-1));   // 全程最空处还能塞几头
		if(t>0)
		{
			ans+=t;
			upd(s,e,t,0,0,N-1);
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **按 $S$ 排序**：必须按右端点 $E$ 排序。按左端点排序时，"先上车的反而晚下车"的情形会让贪心把座位浪费掉。
2. **区间写成闭区间 $[S,E]$**：奶牛在 $E$ 站就下车，不占用 $[E,E+1)$ 路段。用 `[s,e)` 半开区间最不容易错。
3. **区间最大值查询写成"总和"**：容量约束是"每一点都 $\le C$"，要看的是区间**最大**值而不是平均值或总和。
4. **读入顺序**：第一行是 `K N C`，不是 `N K C`。
5. **线段树懒标记不清零**：`push_down` 后必须把 `ad[i]=0`，否则会重复下传导致答案偏大。
6. **单组 `t` 可能为 $0$**：此时不要做区间加，虽然加 $0$ 不影响正确性，但会浪费常数。
