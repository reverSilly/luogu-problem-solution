# P1508 Likecloud-吃、吃、吃

> 标签：动态规划 DP / 搜索 / 枚举 · 难度：普及/提高-
> 本地题面：`P1508.md`（$m,n\le 200$，$n$ 为奇数；能量绝对值 $\le 10^5$）。验证：官方样例 `41`；400 组随机对拍全过；最坏 $m=200,n=199$ 约 $0.01$ s。

## 1. 重新读题

**问题重述（人话版）**

餐桌是一个 $m$ 行 $n$ 列的网格（题面里写作 $m\times n$，但明文规定"矩阵共有 $m$ 行，每行 $n$ 个数字"），格 $(i,j)$ 里有能量 $a_{i,j}$。李大水牛一开始站在**最后一行（第 $m$ 行）的中间列正下方**；$n$ 为奇数，所以中间列唯一。

他只能朝"前方 / 左前方 / 右前方"吃——也就是**每吃一口都从当前行向上走一行**，下一口只落在正上方、左上、右上三格之一。他必须一路吃到**餐桌的另一侧（第 $1$ 行）**，沿途每一格"必须吃掉，不能不吃"。要求让沿途能量之和最大。

> 一句话版本：在网格上从"第 $m$ 行中间列的下方"出发，每步上移一行且列号最多变 $1$，一直走到第 $1$ 行，使途经格子的权值和最大。

**题面里容易漏掉的条款**

1. 「出发点都是最后一行的中间位置的**下方**」$\Rightarrow$ 起点在第 $m$ 行之外（虚拟位置），因此第一口只可能落在第 $m$ 行的 $mid-1,mid,mid+1$ 三列，不能离得更远。
2. 「$n$ 为奇数」$\Rightarrow$ 中间列唯一。把行列都取 0-based 时，中列下标是 `n>>1`。
3. 「只吃前方或左前方或右前方」$\Rightarrow$ 相邻两行所吃列号之差最多 $1$；不存在"跳过一行"的走法，所以**每条路径恰好吃掉 $m$ 个格子（每行一个）**。
4. 「途径的所有食物都必须吃掉，不能不吃」$\Rightarrow$ 负权也必须吃、不能绕开；答案可以是负数（例如整张表全负）。
5. 能量"绝对值不超过 $10^5$"$\Rightarrow$ 单条路径能量和的范围是 $\pm m\cdot10^5=\pm 2\times10^7$，因此必须用一个"负无穷"把"不可达"与"真的得到一个很小的可达值"区分开。

**数据范围与规模感受**

$$m,n\le 200,\qquad n\text{ 为奇数},\qquad \lvert a_{i,j}\rvert\le10^5 .$$

状态数 $m\times n\le 200\times199\approx4\times10^4$，每状态三次转移，合计 $\le1.2\times10^5$ 次加法——**$m\times n$ 级别的线性时间**，随手就有上万倍余量。而 $\Theta(3^m)$ 的路径枚举只在 $m\le 10$ 量级能跑动，提示正解必是"逐格递推"的动态规划。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"走"翻译成一个列序列

先把运动翻译成数学语言。把行自上而下编号 $1,\dots,m$（第 $1$ 行是"另一侧"，第 $m$ 行是他脚下那行），列编号 $1,\dots,n$，记中列 $mid=\frac{n+1}{2}$。

**引理 1（路径模型）**

一条合法路径与一个列序列 $(c_m,c_{m-1},\dots,c_1)\in[1,n]^m$ 一一对应，且满足

$$\lvert c_m-mid\rvert\le1,\qquad \lvert c_i-c_{i-1}\rvert\le1\quad(i=m,m-1,\dots,2).$$

路径的能量和恰为 $\sum_{i=1}^{m}a_{i,c_i}$。

**证明**：

- （路径 $\Rightarrow$ 序列）记他在第 $i$ 行吃到的格子列号为 $c_i$。起点在第 $m$ 行下方、中列，第一次移动只能朝前方/左前/右前，故 $c_m\in\{mid-1,mid,mid+1\}$，即 $\lvert c_m-mid\rvert\le1$。之后每吃一口都从第 $i$ 行移到第 $i-1$ 行、列号最多变 $1$，故 $\lvert c_i-c_{i-1}\rvert\le1$。"必须吃到另一侧"意味着序列含 $m$ 项并止于第 $1$ 行。能量按题面定义即经过格子求和，得 $\sum_i a_{i,c_i}$。
- （序列 $\Rightarrow$ 路径）给定满足上述不等式的序列，就按"第 $m$ 行取 $c_m$，再逐步移向第 $i-1$ 行的 $c_{i-1}$"行走：第一步合法（与中点差 $\le1$），其后每一步列号差 $\le1$（正前/左前/右前），终点在第 $1$ 行，符合"吃到另一侧"，能量和即该式。
- 两个方向互逆，故一一对应。$\blacksquare$

> 这一步把"吃的动作"彻底翻译掉了：唯一剩下的自由度就是每行选哪一列，唯一的输出量就是这些列的权值和。

### 2.2 考虑简化版：先看只有一行、只有一列

- $m=1$：他站在唯一一行下方，可以吃 $mid-1,mid,mid+1$ 三格之一，而"另一侧"就是这一行本身，故最优就是这三格的最大值——**只要走到顶就算到另一侧**。
- $n=1$：无左右可走，被迫竖直吃上去，答案就是该列的权值和。

这两个特例提示：**到达第 $1$ 行即可结束，且状态只需按列区分**——一个"沿行推进、按列分状态"的 DP 雏形已经浮现。

### 2.3 一次归约：从"枚举路径"降到"逐格递推"

直接枚举所有序列是 $\Theta(3^{m})$ 的，必须用**最优子结构**把它压下来。

**引理 2（最优子结构，交换论证）**

设 $f_{i,j}$ 表示"从起点走到格子 $(i,j)$ 且终点恰为 $(i,j)$"的最大能量和。则对 $i\ge2$：

$$f_{i,j}=a_{i,j}+\max\big(f_{i+1,j-1},\,f_{i+1,j},\,f_{i+1,j+1}\big),$$

其中越界邻居取 $-\infty$。

**证明**：考察一条通向 $(i,j)$ 的最优路径，它最后一步必来自第 $i+1$ 行的某列 $c\in\{j-1,j,j+1\}$。

- **上界**：该路径的前 $i+1$ 行部分是一条"起点 $\to (i+1,c)$"的合法路径，其能量 $\le f_{i+1,c}$；于是整条路径能量 $\le a_{i,j}+f_{i+1,c}\le a_{i,j}+\max_{c'\in\{j-1,j,j+1\}}f_{i+1,c'}$。
- **可达**：取 $c^\*$ 为取到上式最大值的邻居，把"起点 $\to(i+1,c^\*)$ 的最优路径"接上 $(i+1,c^\*)\to(i,j)$ 这一步（列差 $\le1$，合法），得到一条通向 $(i,j)$ 的合法路径，能量恰为 $a_{i,j}+f_{i+1,c^\*}$。
- 上界与可达相合；重叠处任取一个并列最大值的 $c^\*$ 都给出相同的和，故两边相等。$\blacksquare$

**引理 3（基例）**

$$f_{m,j}=\begin{cases}a_{m,j},& j\in\{mid-1,mid,mid+1\},\\ -\infty,&\text{otherwise.}\end{cases}$$

**证明**：第 $m$ 行是第一步，只有与中点列差 $\le1$ 的三列可达；其余列不存在任何合法路径，记 $-\infty$ 以与"可达但权值恰好很小"区分。$\blacksquare$

### 2.4 答案的落点：必须落在第 $1$ 行

**引理 4（答案 $=\max_j f_{1,j}$）**

$$\text{Ans}=\max_{1\le j\le n}f_{1,j}.$$

**证明**："吃到餐桌的另一侧（第 $1$ 行）"意味着路径终点行号为 $1$（引理 1 的序列止于第 $1$ 行）。于是每条合法路径的能量恰为某个 $f_{1,j}$；反之每个有限 $f_{1,j}$ 都对应一条合法路径。对全体终点列取最大即得答案；至少存在一条路径（序列 $c_i\equiv mid$ 合法），故最大值有限。$\blacksquare$

> **这里是最容易错的地方**：若把答案误写成"整张表所有 $f_{i,j}$ 的最大值"，当表格下半部有巨大正值、而通往上方的路径被迫吃掉负权时，就会把"半途放弃"当成合法方案，输出偏大。

### 2.5 统一边界：补一个虚拟起点行

引理 2 的递推对 $i=m$ 不方便直接套（第 $m$ 行没有"下一行"的已知值）。做法是**再补一行虚拟的第 $m+1$ 行**，只在中间列放 $f_{m+1,mid}=0$，其余 $-\infty$，这样引理 2 对 $i=m,m-1,\dots,1$ 一视同仁。

**引理 5（虚拟起点等价于基例）**

若令 $f_{m+1,mid}=0$、$f_{m+1,j}=-\infty\ (j\ne mid)$，并按引理 2 对 $i=m,m-1,\dots,1$ 递推，则所得 $f_{m,j}$ 恰等于引理 3 的基例。

**证明**：对 $i=m$，$(m,j)$ 的转移读的是 $\{f_{m+1,j-1},f_{m+1,j},f_{m+1,j+1}\}$。

- 若 $j=mid$：三者中恰有 $f_{m+1,mid}=0$（其余两侧为 $-\infty$），故 $f_{m,mid}=a_{m,mid}+0$。
- 若 $j=mid-1$：邻居集为 $\{mid-2,mid-1,mid\}$，恰含 $mid$ 且不含别的有限项，故 $f_{m,mid-1}=a_{m,mid-1}+0$；对称地 $f_{m,mid+1}=a_{m,mid+1}+0$。
- 其余 $j$：邻居集完全落在 $\{mid\}$ 外，全为 $-\infty$，得 $f_{m,j}=-\infty$。

逐一检查与引理 3 完全一致。$\blacksquare$

于是代码里根本不用写特判基例：初始化虚拟行后统一递推即可。

### 2.6 经典技术：数塔 / 数字三角形的线性 DP

至此本题就是经典的**数塔（数字三角形）**模型：状态 $O(mn)$、转移 $O(1)$、按行由下往上推。与标准数塔的唯一差别只是"起点被固定在中列下方"，用虚拟行 0 就抹平了。

**复杂度**：时间 $O(mn)$（每状态 $3$ 次比较），空间 $O(mn)$ 或滚动成 $O(n)$。

### 2.7 坑点与越界体检（写代码前的最后一次停顿）

| 量 | 范围 | 上界 | `int` 够？ |
|---|---|---|---|
| $m,n$ | 题面 | $200$ | 是 |
| $a_{i,j}$ | 题面 | $\pm10^5$ | 是 |
| 路径能量和 | $m\cdot\max\lvert a\rvert$ | $\pm2\times10^7$ | 是 |

结论：**全程 `int` 足够**，无乘积、无溢出。真正要防的是：

1. **"不可达"必须用 $-\infty$ 而不是 $0$**。全局 `int` 数组默认 $0$；若把不可达格子留成 $0$，会被当成"可达且能量为 $0$"，抬高答案。这里用 `-inf`（`inf=1145141919` 取负）显式填充，并在转移里跳过 `bst==-inf` 的情形。
2. **答案只取第 $1$ 行**（引理 4），别把整张表的 $\max$ 当作答案。
3. **虚拟行只有中列是有限项**，别把整行初始化成 $0$。

## 3. 模式总结（Pattern Summary）

按真实思考顺序排列，每条一行：

- explore its property — 把"走一步"翻译成列序列，得到"每行恰一列、相邻列差 $\le1$"的路径模型（引理 1）。
- consider easier version — 先做 $m=1$、$n=1$ 退化情形，确认"到第 $1$ 行即止"且状态只按列分。
- reduce to easier problem — 用交换论证证明最优子结构，把 $\Theta(3^m)$ 路径枚举降成逐格递推（引理 2）。
- classic problem solution — 识别为**数塔 / 数字三角形**的线性 DP，按行由下往上推。
- boundary unification — 补虚拟起点行 $f_{m+1,mid}=0$，把基例与一般转移统一（引理 5）。
- defer the terminal condition — 答案落在第 $1$ 行而非全表最大值（引理 4）。
- sentinel discipline — "不可达 $=-\infty$"，与"可达的极小值"严格区分。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $m$ | `int` | 行数 | 读入 | 题面 |
| $n$ | `int` | 列数（奇数） | 读入 | 题面 |
| `a[i][j]` | `int [205][205]` | 第 $i$ 行第 $j$ 列的能量（0-based） | 读入 | 题面 |
| `dp[i][j]` | `int [205][205]` | 走到 $(i,j)$ 的最大能量和 $f_{i,j}$ | 全 `-inf`，另置 `dp[m][mid]=0` | 数塔状态 |
| `mid` | `int` | 中间列下标 `n>>1`（0-based） | `n>>1` | 起点列 |
| `inf` | `constexpr int` | 哨兵 $1145141919$，取负作 $-\infty$ | — | 114514 家族 |
| `ans` | `int` | 答案 | `-inf`，取 $\max_j dp[0][j]$ | 引理 4 |

### 4.2 编号步骤

1. 读入 $m,n$ 与整张表 `a[0..m-1][0..n-1]`（0-based）。
2. `mid=n>>1`；把 `dp[0..m][*]` 全部置 `-inf`，再令 `dp[m][mid]=0`（虚拟第 $m$ 行只在中列可达，能量 $0$）。
3. 对 $i=m-1$ 递减到 $0$，对 $j=0..n-1$：
   3.1 `bst=max(dp[i+1][j-1],dp[i+1][j],dp[i+1][j+1])`，越界者跳过（等价于 $-\infty$）；
   3.2 若 `bst!=-inf` 则 `dp[i][j]=a[i][j]+bst`，否则保持 `-inf`（不可达）。
4. 答案 `ans=max_{j} dp[0][j]`，输出 `ans`。

### 4.3 复杂度

- 时间：$O(mn)$，最坏 $200\times199\approx4\times10^4$ 个状态，每状态 $3$ 次比较。
- 空间：两张 $205\times205$ 的 `int` 表，约 $0.34$ MB，远低于 $125$ MB。
- 实测（见 §4.5）：$m=200,n=199$ 约 $0.01$ s（含进程启动）。

### 4.4 关键不变量（值得写 `assert` 的地方）

1. `dp[i][j]!=-inf` $\iff$ 存在从起点到 $(i,j)$ 的合法路径。
2. `dp[i][j]=a[i][j]+max_{列差\le1}dp[i+1][*]`（引理 2）。
3. `dp[m][mid]=0` 且 `dp[m][j]=-inf (j\ne mid)`（引理 5）。
4. 答案 $=\max_j dp[0][j]$，且至少一个有限（引理 4）。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 官方样例回归 | **通过**：$6\times7$ 样例 $\to$ `41`（标程与暴力一致） |
| 随机数据对拍 | **通过**：$400$ 组随机小规模（$m\in[1,8]$、$n\in\{1,3,5,7,9\}$，约 $30\%$ 用例取 $\pm10^5$ 极端值），DP 与 $3^m$ 路径枚举**逐字节一致**；其中 $m=1$、$n=1$ 的退化情形由随机生成覆盖 |
| 边界用例 | **通过**：全 $1$ 大矩阵 $\to 200$（路径必吃 $m$ 格）；随机 $\pm10^5$ 矩阵得到有限值 $12834070$ |
| 最坏规模计时 | $m=200,n=199$：全 $1$ 输出 `200`；随机 $\pm10^5$ 最快约 **$0.01$ s**（多次测量 $0.007\sim0.012$，含进程启动） |
| 残余风险 | 若测试数据出现 $n$ 为偶数（违背题面"$n$ 为奇数"明文），`n>>1` 的取法会偏向右侧中点，非本题合法输入 |

## 5. 示例代码

### 5.1 主解：数塔 DP（与 `appendix/P1508/P1508.cpp` 逐字节一致）

```cpp
//
// 题目：P1508 Likecloud-吃、吃、吃
// https://www.luogu.com.cn/problem/P1508
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{205};        // 行数 m<=200 (+5 松弛)
constexpr int mxm{205};        // 列数 n<=200 (+5 松弛)
constexpr int inf{1145141919}; // 114514 家族哨兵, 取负当 -inf

int m,n;
int a[mxn][mxm];
int dp[mxn][mxm];              // dp[i][j]=从底部中点走到 (i,j) 的最大能量和

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n;
	for(int i=0;i<m;++i)
		for(int j=0;j<n;++j)
			cin>>a[i][j];

	for(int i=0;i<=m;++i)
		for(int j=0;j<n;++j)
			dp[i][j]=-inf;
	int mid=n>>1;              // n 为奇数, 0-based 的中间列
	dp[m][mid]=0;              // 虚拟第 m 行只在中点列可达, 能量 0

	for(int i=m-1;i>=0;--i)
		for(int j=0;j<n;++j)
		{
			int bst=-inf;
			for(int k=-1;k<=1;++k)
			{
				int c=j+k;
				if(c<0||c>=n)
					continue;
				bst=max(bst,dp[i+1][c]);
			}
			if(bst!=-inf)
				dp[i][j]=a[i][j]+bst;
		}

	int ans=-inf;
	for(int j=0;j<n;++j)
		ans=max(ans,dp[0][j]);
	cout<<ans<<'\n';
	return 0;
}
```

**代码结构对照**：`dp[m][mid]=0` 是引理 5 的虚拟起点，内层三方向取 $\max$ 是引理 2，答案对 `dp[0][*]` 取 $\max$ 是引理 4，`-inf` 区分不可达。三处对应三条引理，其余都是读入输出样板。

### 5.2 对照实现：$3^m$ 路径枚举（仅用于小规模对拍）

```cpp
//
// 题目：P1508 Likecloud-吃、吃、吃 (暴力基准)
// https://www.luogu.com.cn/problem/P1508
// 仅用于小规模对拍: 枚举全部 3^m 条路径取最大能量
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{25};
constexpr int inf{1145141919};

int m,n;
int a[mxn][mxn];
int ans;

void dfs(int i,int j,int sum)
{
	if(i==0)
	{
		ans=max(ans,sum);
		return;
	}
	for(int k=-1;k<=1;++k)
	{
		int c=j+k;
		if(c<0||c>=n)
			continue;
		dfs(i-1,c,sum+a[i-1][c]);
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>m>>n;
	for(int i=0;i<m;++i)
		for(int j=0;j<n;++j)
			cin>>a[i][j];

	ans=-inf;
	dfs(m,n>>1,0);
	cout<<ans<<'\n';
	return 0;
}
```

两版输出**逐字节相同**（已用 $400$ 组随机数据确认）。暴力完全绕过引理 2 的递推，直接按定义枚举每步的三个落点，可作为独立的交叉验证基准；代价是 $O(3^m)$，不能提交。

### 5.3 易错点清单

- **忘记把不可达格置 `-inf`** $\Rightarrow$ 全局默认 `0` 会被当成合法零能量，答案偏大。
- **把答案写成全表最大值** $\Rightarrow$ 允许"半途放弃"，答案偏大（应只取第 $1$ 行）。
- **虚拟行整行置 `0`** $\Rightarrow$ 起点可以落到任意列，答案偏大（应只在中列置 `0`）。
- **`cout<<...<<endl;`** 违反本项目风格指南，一律用 `'\n'`。
