# P1433 吃奶酪

> 标签：DP / 状压 DP / 搜索 / DFS / 剪枝 · 难度：提高/省选-

## 1. 重新读题

**问题重述（简化版）**

房间里 $n$ 块奶酪，第 $i$ 块在 $(x_i,y_i)$。老鼠从原点 $O=(0,0)$ 出发，必须把每块奶酪都吃到一次，求**最少跑过的总路程**。不需要回到原点，也不要求输出方案（只要一个实数）。

把一次完整吃法看成一个排列 $(p_1,p_2,\dots,p_n)$（$p_k$ 是第 $k$ 个吃到的奶酪编号），目标函数

$$L(p)=\sum_{k=1}^{n} d(p_{k-1},p_k),\qquad p_0=O,\quad d(a,b)=\sqrt{(x_a-x_b)^2+(y_a-y_b)^2}$$

求 $\min_{p} L(p)$，输出保留 2 位小数。这就是**开放路径版 TSP（哈密顿路径最短权）**，起点固定、终点自由。

**条件清单**

| 项目 | 内容 |
|---|---|
| 输入 | 一行 $n$；随后 $n$ 行，每行两个实数 $x_i,y_i$ |
| 输出 | 一行实数，2 位小数 |
| 起点 | 固定 $(0,0)$，且原点**不是**奶酪（除非某奶酪坐标恰为 $(0,0)$） |
| 覆盖要求 | 每块奶酪至少吃一次（多吃一次只会更长，见引理 1） |
| 规模 | $1\le n\le 15$，$\lvert x_i\rvert,\lvert y_i\rvert\le 200$，小数点后最多 3 位 |

**数据范围给出的复杂度提示**：$n\le15$ 不是"随便 $O(n^3)$ 过"的量级，而是刻意挑的"$2^n$ 与 $n!$ 分界点"——$2^{15}\cdot15^2\approx7.4\times10^6$ 可过，$15!\approx1.3\times10^{12}$ 不可过。这直接告诉我们：正解要么是 $O(2^n n^2)$ 的状压 DP，要么是"最坏 $n!$、实际被剪得很短"的分支限界搜索。

**陷阱与边界（先记下，后面逐条证明）**

1. **开放路径 ≠ 环**：终点不用回原点；若多加一条回边就变成了环 TSP，答案会偏大（见 2.6）。
2. **坐标可为负**：$|x_i|\le200$，两点最大距离 $\sqrt{400^2+400^2}=400\sqrt2\approx565.69$，全程上界 $15\times565.69\approx8485$。
3. **奶酪可与原点重合**，甚至 $n$ 块全重合；答案可为 $0.00$。距离公式对重合点给 $0$，DP 的 $0$ 转移与"不可达"必须区分开——这就是全局 $dp$ 数组必须显式 `fill` 成 $+\infty$ 的原因。
4. **不存在"位置权重"的交换视角**：本题每段系数都是 1，不能把答案写成 $\sum_k c_k\cdot(\text{第 }k\text{ 段长})$ 再用"重的段放后面/前面"的排序贪心（见引理 2、3）。
5. **贪心会错**：最近邻、按离原点距离排序都被小数据直接推翻（2.3 给全排列核对）；"每次取全局最短边"在手推的小数据上侥幸对，但**没有正确性保证**，同样不采用。
6. **剪枝下界必须"可采纳"**：把下界放大（例如每个未访问点算两条边）就会把最优解剪掉，这是本题 Hack 数据（2022.7.13）最容易踩的坑（2.5 给证明与小反例）。
7. **精度**：用 `double`（`f64`）而不是 `float`；输出用 `fixed<<setprecision(2)`，靠 `iostream` 的四舍五入。
8. **不能加"反转去半"的对称剪枝**：环 TSP 里正序逆序等价，路径里不等价（引理 3），去掉一半排列会真的去掉最优解（2.6 给数值）。

**样例情况**：本地题面文件 `P1433.md` **没有任何样例输入/输出**，因此**无法与官方答案对标**。本文所有验证都是手算：$n=4$ 实例做 $24$ 项全排列（2.3 反例一）、$n=3$ 实例做 $6$ 项全排列（2.3 反例二）、外加 $6$ 组自造边界用例（§4 表 A–H），以及一次完整的 DP 表格手推（§5 复核一）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索代价结构

先把"重复走同一块奶酪"和"走回头路"这些自由度的影响搞清楚，再看总路程到底由什么决定。

**引理 1（最优解是哈密顿路径：每个点恰好访问一次）**

存在一个最优吃法，其访问序列是 $n$ 块奶酪的一个排列（每块恰好一次）。

**证明**：任取一条访问序列 $q_1,\dots,q_m$（$m\ge n$，每块奶酪至少出现一次），构造新序列：只保留每块奶酪**第一次**出现的位置，其余删掉，得 $q_{t_1},q_{t_2},\dots,q_{t_n}$。

对删除掉的某一次出现 $q_t$（$t$ 不是该奶酪的首次出现），删除后原本相邻的两段 $d(q_{t-1},q_t)+d(q_t,q_{t+1})$ 被一段 $d(q_{t-1},q_{t+1})$ 取代（若 $t$ 是序列末端则直接少一段）。由三角不等式 $d(a,c)\le d(a,b)+d(b,c)$（欧氏距离满足，可由向量 $\vec{ac}=\vec{ab}+\vec{bc}$ 取模与 $|\vec u+\vec v|\le|\vec u|+|\vec v|$ 得到），总路程不减反可能变小。反复删除直到没有重复，得到排列 $p$，且 $L(p)\le L(q)$。$\blacksquare$

> 结论：搜索空间就是 $n!$ 个排列，且不必考虑"重访"。

**关键观察：代价只由"相邻点对"决定**

把 $L(p)$ 换一种写法。令路径的边集为 $E(p)=\{\{p_0,p_1\},\{p_1,p_2\},\dots,\{p_{n-1},p_n\}\}$，则

$$L(p)=\sum_{\{u,v\}\in E(p)} d(u,v)$$

即：**总路程 = 路径上 $n$ 条边的长度之和，每条边恰好计一次，系数全为 1。** 一个点在序列中的"位置编号" $k$ 本身不出现在公式里，它只通过"谁和谁相邻"间接影响代价。

**引理 2（不存在"位置权重"分解，因而加权交换视角在此失效）**
不存在常数 $c_1,\dots,c_n$ 与"只依赖单个点"的量 $a_P$，使得对一切 $n=2$ 的排列都有 $L(p_1,p_2)=c_1a_{p_1}+c_2a_{p_2}$。

**证明**（先推出必要条件，再用具体数据否证）：设分解存在。对任意三点 $P,Q,R$ 计算组合
$$\Phi=L(P,Q)+L(R,P)-L(R,Q).$$
代入分解式：$\Phi=(c_1a_P+c_2a_Q)+(c_1a_R+c_2a_P)-(c_1a_R+c_2a_Q)=(c_1+c_2)a_P$，**只与 $P$ 有关，与 $Q,R$ 无关**——这是分解存在的必要条件。
再用真实代价算同一个量。$L(x,y)=d(O,x)+d(x,y)$，故
$$\Phi=d(O,P)+d(P,Q)+d(R,P)-d(Q,R).$$
取 $O=(0,0)$，$P=(1,0)$，$Q=(2,0)$，$R=(1,1)$：$d(O,P)=1$，$d(P,Q)=1$，$d(P,R)=1$，$d(Q,R)=\sqrt{1+1}=\sqrt2\approx1.414214$，$\Phi=1+1+1-1.414214=1.585786$。
只把 $Q$ 改成 $Q'=(3,0)$：$d(P,Q')=2$，$d(Q',R)=\sqrt{4+1}=\sqrt5\approx2.236068$，$\Phi'=1+2+1-2.236068=1.763932\ne\Phi$。
必要条件被违反（同一 $P$ 得到不同的 $\Phi$），故分解不存在。$\blacksquare$

> **这条引理在防什么**：如果目标真是"路径距离加权求和" $\sum_k c_k\cdot(\text{第 }k\text{ 段})$，或能改写成"第 $k$ 个点被它后面的 $n-k$ 段各贡献一次"这类 $\sum_k c_k a_{p_k}$ 形式（典型如期望总停留时间、"每段长度乘以后面剩余点数"），就可以用交换论证把系数排好序后贪心。本题 $c_k\equiv1$，代价是**点对**（$d(P,Q)$）而不是**单点**的属性，上面证明的"跨 $Q,R$ 不变性"不成立，所以**交换视角不可用**；硬套它就产生 2.3 的两个错误贪心。

**引理 3（起点固定破坏反转对称性）**

$L(p_1,\dots,p_n)\ne L(p_n,\dots,p_1)$ 一般成立。

**证明**：反转后的第一条边是 $d(O,p_n)$ 而非 $d(O,p_1)$，其余边集合相同。故
$$L(p)-L(p^{\text{rev}})=d(O,p_1)-d(O,p_n).$$
取 $n=3$ 实例（2.3 反例二）：$O=(0,0),C=(1,0),B=(1,5),A=(0,5)$。$p=(C,B,A)$ 给出 $L=1+5+1=7$；反转 $p^{\text{rev}}=(A,B,C)$ 给出 $L=5+1+5=11$。差 $7-11=-4$，而公式给 $d(O,C)-d(O,A)=1-5=-4$，一致。$\blacksquare$

> 结论：不能像环 TSP 那样"固定任一点当起点、再把环向视为等价"来约掉一半分支；起点是**特殊点**，它只贡献 1 条边。

**为什么纯 DFS 不够**：由引理 1，暴力枚举就是 $n!$ 个排列。$n=15$ 时 $15!=1307674368000\approx1.3\times10^{12}$，即使每步只花 1 ns 也是 1300 秒量级，远超 1 s。要么把状态压缩成 $2^n\cdot n$（DP），要么在 DFS 里用**可采纳下界**大片剪掉子树。

### 2.2 简化版：把 $n$ 砍到 1、2、3、共线

先手工算最少的几种，目的是（a）确认目标函数没有理解错，（b）拿到几个"标准答案"用于日后自检，（c）看有没有隐藏结构（如"共线时按坐标序走"）。

**$n=1$**：只有一块奶酪 $A$，答案就是 $d(O,A)$。
- $A=(3,4)$：$\sqrt{9+16}=5\Rightarrow 5.00$。
- $A=(0,0)$：$0\Rightarrow 0.00$（合法，且这是"$dp$ 里出现 0 值转移"的最简例）。

**$n=2$**：两种顺序取小者，$\min\{d(O,A)+d(A,B),\ d(O,B)+d(B,A)\}=d(A,B)+\min\{d(O,A),d(O,B)\}$。
- $A=(0,3),B=(4,0)$：$d(A,B)=5$，$\min\{3,4\}=3\Rightarrow 8.00$。手算两序：$O\to A\to B=3+5=8$，$O\to B\to A=4+5=9$ ✓。
- $A=(-1,0),B=(-2,0)$：$1+1=2.00$（负坐标无特殊处理）。

**$n=3$**：$6$ 种排列，全部手算即可得最优——这给 2.3 的反例提供了"暴力核对"的手段。

**共线情形（$n$ 个点全在一条过原点的射线上）**

**引理 4**：若所有奶酪都在从原点出发的同一条射线上，则按到原点距离**递增**访问最优，最短路程 $=\max_i d(O,p_i)$。

**证明**：射线上两点距离等于它们到原点距离之差的绝对值。设访问顺序对应的距离序列为 $r_1,\dots,r_n$，记 $r_0=0$。因 $r_k\ge0$，有 $|r_k-r_{k-1}|\ge r_k-r_{k-1}$，把该不等式对"从 $0$ 走到 $\max_k r_k$ 再返回"的任意序列累加可得总路程 $\sum_k|r_k-r_{k-1}|\ge \max_k r_k$（形式化：取 $t$ 使 $r_t=\max_k r_k$，则 $\sum_{k=1}^{t}|r_k-r_{k-1}|\ge|r_t-r_0|=r_t$，去掉后面非负项即可）。另一方面，按 $r$ **递增**访问时 $r_k-r_{k-1}\ge0$，每段长 $r_k-r_{k-1}$，累加望远镜得 $L=\max_k r_k$，正好达到下界。$\blacksquare$

> 这条引理有两个用处：① 它给出一个**看起来很像正确答案**的贪心（"按离原点距离递增走"），2.3 反例二将证明它在非共线时错；② 它给出一个手算容易的边界用例：$n=15$，点 $(1,0),(2,0),\dots,(15,0)$，答案必为 $15.00$，可用来验证代码是否"多走回头路"。

**重合点情形**：$n$ 块奶酪全在同一位置 $P$ 时，答案 $=d(O,P)$（引理 1 说明重复访问不额外收费，距离为 0）。例如 3 块都在 $(1,1)$：答案 $\sqrt2\approx1.4142\Rightarrow1.41$。

### 2.3 贪心为什么失败（两个手算反例 + 边贪心的结构性分析）

有了 2.1 的"代价只由相邻点对决定"，第一反应自然是"每步选最短的那条边"。但 2.1 也提示了危险：**选了一条边，就同时决定了两个点的度数**，局部最优会破坏全局结构。下面先看两个被手算全排列直接推翻的贪心，再看第三种为什么"看似能用其实不能证明"。

**反例一：最近邻贪心（每次都走到最近的未访问点）**

数据（$n=4$）：
$$O=(0,0),\quad P_1=(2,0),\quad P_2=(3,0),\quad P_3=(4,0),\quad T=(2,1.6)$$

两两距离（手算）：

| 边 | 长度 |
|---|---|
| $O\!-\!P_1$ | $2$ |
| $O\!-\!P_2$ | $3$ |
| $O\!-\!P_3$ | $4$ |
| $O\!-\!T$ | $\sqrt{2^2+1.6^2}=\sqrt{6.56}\approx2.5613$ |
| $P_1\!-\!P_2$ | $1$ |
| $P_1\!-\!P_3$ | $2$ |
| $P_1\!-\!T$ | $1.6$ |
| $P_2\!-\!P_3$ | $1$ |
| $P_2\!-\!T$ | $\sqrt{1+2.56}=\sqrt{3.56}\approx1.8868$ |
| $P_3\!-\!T$ | $\sqrt{6.56}\approx2.5613$ |

贪心执行：$O$ 处最近是 $P_1$（$2<2.5613$）；$P_1$ 处未访问 $\{P_2,P_3,T\}$ 中最近是 $P_2$（$1<1.6<2$）；$P_2$ 处最近是 $P_3$（$1<1.8868$）；只剩 $T$：$+2.5613$。
$$L_{\text{贪心}}=2+1+1+2.5613=6.5613$$

全排列 $4!=24$ 手算枚举，按首点分 4 类、每类 6 个全部算过，表中给"该类最小"：

| 首点 | 该类最优序列 | 长度 |
|---|---|---|
| $P_1$ | $P_1,T,P_2,P_3$ | $2+1.6+1.8868+1=6.4868$ |
| $P_2$ | $P_2,P_3,P_1,T$ | $3+1+2+1.6=7.6$ |
| $P_3$ | $P_3,P_2,P_1,T$ | $4+1+1+1.6=7.6$ |
| $T$ | $T,P_1,P_2,P_3$ | $2.5613+1.6+1+1=\mathbf{6.1613}$ ← 全局最优 |

（贪心走的 $P_1,P_2,P_3,T=6.5613$ 也在 $P_1$ 类里，比该类最优 $6.4868$ 还差。）

$$L_{\text{最优}}=6.1613>L_{\text{贪心}}=6.5613\quad(\text{贪心错 }0.4)$$

**失败原因**：$P_1$ 离原点最近，贪心第一步就去它；但 $T$ 的"最经济的入边"只有 $1.6$（来自 $P_1$），一旦 $P_1$ 被消耗掉，$T$ 只能从 $P_3$ 用 $2.5613$ 进入。贪心把"便宜入边"和"便宜出边"绑在同一条边上，造成了不可逆的浪费。这正是引理 2 说的：决定代价的是**谁与谁相邻**，不是第几步。

**反例二：按到原点距离递增访问（引理 4 的诱惑）**

数据（$n=3$）：
$$O=(0,0),\ C=(1,0),\ B=(1,5),\ A=(0,5)$$
到原点距离：$d(O,C)=1$，$d(O,A)=5$，$d(O,B)=\sqrt{1+25}=\sqrt{26}\approx5.0990$。
点间距离：$d(C,B)=5$（同 $x$ 差 $5$），$d(A,B)=1$（同 $y$ 差 $1$），$d(C,A)=\sqrt{1+25}=\sqrt{26}\approx5.0990$。

贪心顺序（按距递增）$C,A,B$：$L=1+5.0990+1=7.0990$。
$6$ 个排列全部手算：

| 顺序 | 长度 |
|---|---|
| $C,A,B$ | $1+5.0990+1=7.0990$ |
| $C,B,A$ | $1+5+1=\mathbf{7.0000}$ ← 最优 |
| $A,B,C$ | $5+1+5=11.0000$ |
| $A,C,B$ | $5+5.0990+5=15.0990$ |
| $B,A,C$ | $5.0990+1+5.0990=11.1980$ |
| $B,C,A$ | $5.0990+5+5.0990=15.1980$ |

贪心差在把 $C$ 的**出边**接到了"距原点第二近"的 $A$，而正确做法是接到几何上更近的 $B$。

**引理 5（"按 $d(O,\cdot)$ 递增"策略的适用边界）**该策略在"所有点同处一条过原点的射线"时正确（引理 4），但**不是普适正确**：反例二给出一个 $n=3$ 的合法实例使它非最优。
**证明**：射线情形即引理 4 的结论。非普适性由反例二的枚举表（6 个排列逐个算出，最优 $7.0000$，该策略给 $7.0990$）直接得到。$\blacksquare$

**"取最短边"型贪心（类 Kruskal 构路）为什么也不能作为题解**

我把 $n=3,4$ 的几个小实例（含反例一）都按"边权升序、每点度数 $\le2$、原点度数 $\le1$、不成环"手推了一遍，在这些小数据上它**恰好**给出最优（例如反例一里它选出 $P_1P_2, P_2P_3, P_1T$ 后被迫放弃 $OP_1$，改用 $OT$，得到 $6.1613$）。但这只是小数据的运气，无法证明：

**引理 6（度数记账说明边贪心没有可靠的交换论证）**在任意一条从 $O$ 出发的哈密顿路径中，$O$ 的度数恰为 $1$；$n$ 块奶酪里恰有 **1** 块度数为 $1$（终点），其余 $n-1$ 块度数为 $2$。

**证明**：路径 $O,p_1,\dots,p_n$ 的边为 $\{O,p_1\},\{p_1,p_2\},\dots,\{p_{n-1},p_n\}$，共 $n$ 条。$O$ 只在第一条中出现 → 度 $1$。$p_1$ 出现在第 1、2 条 → 度 $2$（$n=1$ 时退化为度 1）；$p_k(1<k<n)$ 出现在第 $k,k+1$ 条 → 度 $2$；$p_n$ 只出现在第 $n$ 条 → 度 $1$。$\blacksquare$

由引理 6，"最便宜的 $n$ 条边"这种选择必须同时决定**谁是终点**（唯一度数 1 的点）。边贪心按权重独立排序，没有关于"终点身份"的信息；一旦两个便宜点都被填到度 2，就必须用一条贵边收尾，误差由此产生（构造更大实例即可放大，与最近邻失败机制同源）。因此放弃边贪心。

**关于"模拟退火 / 随机化贪心"（题目标签里有）**：这类方法**没有最优性保证**，只能"通常很接近"。本题 $2022.7.13$ 新增 Hack 数据，专门打的是不可证明最优的启发式；而输出要求精确到 2 位小数，差 $0.005$ 就错。所以本文只写两条**可证明正确**的路线：状压 DP（2.4）与"可采纳下界"分支限界（2.5）。

**小结（思维转折点）**：贪心的失败不是"差一点点"，而是结构性失败——代价定义在**相邻对**上，选一条边就锁定两个点的度，后面的选择相互耦合。耦合的选择问题需要**把耦合状态显式记录在 DP 里**（记录"已经访问过哪些点"+"现在站在哪"），这就是状压 DP；或者**显式搜索并给出可靠的下界**来剪掉不可能更优的子树，这就是分支限界。

### 2.4 经典解法：状压 DP（把"$n!$ 个排列"压成 "$2^n\cdot n$ 个状态"）

**想法来源**：2.1 说代价只由相邻点对决定；2.3 说"决定一条边就锁定两个点的度数"。既然未来的花费取决于"还有哪些点没被消耗"和"我现在站在哪"，那就把这两件事**原封不动地记进状态**——这正是 DP 处理耦合决策的标准手法。"没被消耗的点"是一个集合，$n\le15$ 可以用二进制掩码存，于是得到状压 DP。

**记号**
- 点编号约定：$0$ 号点 $=O=(0,0)$，奶酪编号 $1..n$（对应掩码位 $0..n-1$）。
- $dis[a][b]=\sqrt{(x_a-x_b)^2+(y_a-y_b)^2}$，$a,b\in\{0,\dots,n\}$。
- $S\subseteq\{0,\dots,n-1\}$ 用整数表示的"已吃过"集合；$i\in S$ 表示"当前站在奶酪 $i+1$"。
- $dp[S][i]=$ 从 $O$ 出发、**恰好**吃过 $S$ 中的奶酪、且此刻站在奶酪 $i+1$ 的所有走法中的最短路程。

**引理 7（状态是充分的：无后效性）**
给定 $(S,i)$，"吃完剩下奶酪的最小附加路程"只依赖 $(S,i)$，与到达该状态所走的具体顺序无关。

**证明**：由引理 1，可假定剩余走法不重访任何点。剩余部分的代价是若干条边的和，每条边连接"当前位置或某个未访问点"。任何只涉及 $\{i\}\cup([n]\setminus S)$ 中点的后续走法，其长度由这些点之间的 $dis$ 值唯一决定；已访问集合 $S\setminus\{i\}$ 中的点在后续不会再出现（否则可用引理 1 的删重复论证去掉，不会变差）。故后续最小代价 $g(S,i)$ 是 $(S,i)$ 的函数。$\blacksquare$

**引理 8（最优子结构 / cut-and-paste）**
设 $P$ 是从 $O$ 出发、吃完全部奶酪的最短走法，它在吃完集合 $S$ 后停在奶酪 $i+1$。则 $P$ 的前缀恰长 $dp[S][i]$，后缀恰长 $g(S,i)$，且 $L(P)=dp[S][i]+g(S,i)$。

**证明**：前缀是"恰好访问 $S$、终点 $i+1$"的一条走法，故长度 $\ge dp[S][i]$（$dp$ 的定义取下界）；后缀是"从 $i+1$ 出发吃完补集"的一条走法，故长度 $\ge g(S,i)$。于是 $L(P)\ge dp[S][i]+g(S,i)$。
反向：取达到 $dp[S][i]$ 的前缀 $A$ 与达到 $g(S,i)$ 的后缀 $B$。$A$ 经过的点集为 $S$，$B$ 经过的点集为 $\{i+1\}\cup([n]\setminus S)$（$i+1$ 只是起点，不再被吃），两者除 $i+1$ 外无公共点，故 $A$ 接 $B$ 是一条合法走法（每块奶酪恰好一次），长度 $=dp[S][i]+g(S,i)\le L(P)$。结合 $P$ 的最优性得等号。$\blacksquare$

**由引理 8 直接得到转移方程**（最后一步是谁）：对 $i\in S,\ i\ne j$，
$$dp[S][i]=\min_{j\in S\setminus\{i\}}\big(dp[S\setminus\{i\}][j]+dis[j+1][i+1]\big),\qquad dp[\{i\}][i]=dis[0][i+1]$$
代码里写成"正向松弛"（从 $S$ 推向 $S\cup\{j\}$），二者等价。**拓扑序检查**：$j\notin S\Rightarrow S\mid(1{\ll}j)=S+2^{j}>S$（该位原为 0，加法不进位），故 $S$ 从小到大一层循环即可，无需按 $|S|$ 分层。

**计数与复杂度**：转移三元组 $(S,i,j)$，$i\in S,j\notin S$。先选有序对 $(i,j)$：$n(n-1)$ 种；其余 $n-2$ 个点任意属于 $S$ 或不属：$2^{n-2}$ 种。故转移数 $=n(n-1)2^{n-2}=15\cdot14\cdot8192=1\,720\,320$。状态数 $n2^n=15\cdot32768=491\,520$，存 $double$ 约 $3.93\ \text{MB}$（代码开 $+5$ 松弛后 $32768\times20\times8\approx5.24\ \text{MB}$，全局静态数组安全）。

**答案**：$\displaystyle ans=\min_{0\le i<n}dp[(1{\ll}n)-1][i]$——终点自由，**不加回原点的那条边**（引理 3：本题是路径不是环）。

### 2.5 另一路：DFS + 可采纳下界剪枝（分支限界）

**想法来源**：$2^n n$ 的状态是"集合级"的，而 $n!$ 的排列里很多分支一开头就注定不可能更优。DFS 只要手里有一个**可靠的（不高估的）下界**，就能整片砍掉。关键是下界怎么造才不会把最优解砍掉。

**记号**
- $vis[i]$：奶酪 $i$（$1..n$）是否已吃；$u\in\{0,\dots,n\}$：当前位置（$0$ 为原点）；$cur$：已走路程；$dep$：已吃数量。
- $minn[i]=\min_{j\in\{0,\dots,n\},\,j\ne i}dis[i][j]$：奶酪 $i$ 到"其它任一顶点（含原点）"的最短距离，$i\ge1$。
- $lb=\sum_{i:\,vis[i]=0}minn[i]$：当前下界余量。

**引理 9（下界可采纳：$lb$ 不超过约去的最短附加路程）**
设当前站在 $u$，未吃集合为 $R$（$|R|=k$），则"从 $u$ 出发吃完 $R$"的最短附加路程 $g\ge\sum_{i\in R}minn[i]$。

**证明**：任一合法后续是一条路径 $u,q_1,q_2,\dots,q_k$，其中 $(q_1,\dots,q_k)$ 是 $R$ 的排列，附加路程 $=\sum_{t=1}^{k}dis(q_{t-1},q_t)$（记 $q_0=u$）。
给每条边一个**唯一归属**：把边 $(q_{t-1},q_t)$ 记为"$q_t$ 的入边"。因为 $q_1,\dots,q_k$ 互不相同且恰为 $R$ 的元素，$R$ 中每个点恰有一条入边，所以这 $k$ 条入边不重不漏地就是路径的全部 $k$ 条边，即附加路程 $=\sum_{i\in R}(\text{指向 }i\text{ 的那条边的长度})$。
对任意 $i\in R$，指向它的边来自某个 $j\ne i$（路径上不重访，前驱必然不是自己），故该边长 $\ge\min_{j\ne i}dis[i][j]=minn[i]$。逐项相加即得 $g\ge\sum_{i\in R}minn[i]=lb$。$\blacksquare$

> 数一遍"入边"就够了——这正是引理 6 的度数记账在用：路径中除起点 $u$ 外每个出现的点度数（作为**头**）恰为 1。**下界只数入边，不数出边。**

**引理 10（把下界翻倍一定错）**
若改用 $lb'=\sum_{i\in R}2\,minn[i]$（"每个点有两条边"），则存在合法数据使最优解被剪掉。

**证明 / 反例**：用 2.3 反例一的数据 $O,P_1,P_2,P_3,T$。$minn[P_1]=\min(2,1,2,1.6)=1$，$minn[P_2]=\min(3,1,1,1.8868)=1$，$minn[P_3]=\min(4,2,1,2.5613)=1$，$minn[T]=\min(2.5613,1.6,1.8868,2.5613)=1.6$。根节点 $R$ 为全体，$lb=1+1+1+1.6=4.6\le6.1613$（引理 9 成立，不剪）。而 $lb'=9.2$。
若先用最近邻贪心得到可行上界 $ans=6.5613$（这是真实走法长度，作为上界合法），则在**根节点**就有 $cur+lb'=0+9.2\ge6.5613=ans$，整棵树被剪光，程序输出 $6.56$；真最优是 $6.1613\to 6.16$。**结论：高估的下界会把最优解连同整棵子树一起误杀。**$\blacksquare$

原因很直白：路径只有 $k$ 条边却有 $2k$ 个"边端点槽"，最后一个点的出边不存在（它就是终点），所以"每个点两条边"多算了 $k$ 条不存在的边。

**剪枝的正确性**

**引理 11（$\ge$ 剪枝不丢最优值）**在状态 $(u,R)$ 处，若 $cur+lb\ge$ 当前已知的最好完整解 $ans$，则剪掉该分支不会使最终答案变大。

**证明**：该分支下任何完整走法的长度都 $\ge cur+g\ge cur+lb\ge ans$。而 $ans$ 已经由某条真实走法取得，故这些走法都不可能给出**严格小于** $ans$ 的值，剪掉后 $\min$ 不变。$\blacksquare$
（用 $>=$ 还是 $>$ 都可：相等时剪掉只丢掉"并列最优"，题目只要数值。浮点误差见 2.6。）

**代码要点**
1. $lb$ 增量维护：进入 $v$ 时传 $lb-minn[v]$（$v$ 的入边已被实际值取代），回溯时天然恢复。
2. $minn$ 必须排除 $j=i$；不排除则 $minn[i]=0$，下界退化为 $0$，剪枝失效（结果仍对，但会 TLE）。这是**慢**而不是**错**，与引理 10 的"错"要分清。
3. 先用一次最近邻贪心把 $ans$ 初始化成一个真实可行值，可大幅提前开始剪枝；贪心的输出本身就是一条合法走法（一个排列），长度 $\ge$ 最优值，所以作为**上界种子安全**，只影响速度不影响正确性（引理 11 只要求 $ans$ 是某条真实走法的长度）。
4. 分支顺序按"离当前点最近的未访问点优先"，能更快拿到好上界；顺序不影响正确性，只影响速度。
5. 最坏仍是 $O(n!)$，但引理 9 的下界在 $n\le15$、坐标随机时通常能砍掉绝大部分；DP 则是**无条件**$O(2^n n^2)$。**若只允许交一份，交状压 DP。**

### 2.6 归约到更简单的问题 + 精度/溢出防护

**归约**：把原点和 $n$ 块奶酪看成的完全图 $K_{n+1}$ 的 $n+1$ 个顶点，边权 $dis$。于是

$$\text{P1433} \;=\; \text{在 } K_{n+1} \text{ 上求"以 } O \text{ 为固定端点的最短哈密顿路径"}$$

- 与**最短哈密顿回路（经典 TSP）**同阶：状压 DP 都是 $O(2^n n^2)$，区别只在于回路要多一条回边、且可固定起点消掉一维对称；本题终点自由，**不能**固定终点。
- 与**最小生成树**不同：MST 允许分叉，本题要求路径（最大度 2 且连通）。但 MST 可以当**下界**用。

**引理 12（更强的可采纳下界：MST 版）**从 $u$ 出发吃完 $R$ 的最短附加路程 $\ge$ 点集 $\{u\}\cup R$ 在原完全图中的最小生成树权 $w(\mathrm{MST})$。

**证明**：任一后续走法 $u,q_1,\dots,q_k$ 的 $k$ 条边构成的图，顶点集为 $\{u\}\cup R$、边数 $k=|V|-1$、且沿路径连通无环，正是一棵生成树。MST 是所有生成树权的最小值，故 $w(\mathrm{MST})\le$ 该走法长度，对最优走法也成立。$\blacksquare$
（本文代码不用它：$O(k^2)$ 的 Prim 让每个分支变贵，$\sum minn_i$ 的 $O(1)$ 增量维护更划算。记着它可以在"下界太弱"时救场，取两者较大者仍由引理 9、12 保证可采纳。）

**环 vs 路径与对称剪枝**：回路满足 $L_{\text{环}}(p)=L_{\text{环}}(p^{\text{rev}})$（边集相同），可以只枚举一半；但由引理 3，本题路径**反转不等价**，所以搜索里**禁止**加"强制第一个点编号 $<$ 最后一个点编号"这类对称剪枝——用反例一数据看后果：
开环最优 $O\!\to\!T\!\to\!P_1\!\to\!P_2\!\to\!P_3=6.1613$；同一序列的反转 $O\!\to\!P_3\!\to\!P_2\!\to\!P_1\!\to\!T=4+1+1+1.6=7.6\ne6.1613$。若按对称剪枝丢掉其中一半，就可能丢掉真正最优的那一半。
另外"误加回原点"会得到 $9.1226$（枚举 $6$ 个不同环得最小值 $O\!-\!P_1\!-\!P_2\!-\!P_3\!-\!T\!-\!O$：$2+1+1+2.5613+2.5613$），比正解 $6.1613$ 大，且最优**顺序也变了**（$T$ 从第一位跑到第四位）——所以不能"先算环再减掉一条边"。

**精度与"溢出"防护**（本题没有整数溢出，风险全在浮点）

| 风险 | 定量分析 | 处置 |
|---|---|---|
| 数值大小 | $\max dis=\sqrt{400^2+400^2}=400\sqrt2\approx565.685$，$ans\le15\times565.685\approx8485.28$ | $double$（$1.2\times10^{-308}\sim1.8\times10^{308}$）绝对安全；`float` 也能表示，但精度不够（下一行） |
| 有效位数 | `double` 52 位尾数，相对精度 $\approx2.2\times10^{-16}$，$8485$ 量级下绝对误差 $\approx1.9\times10^{-12}$；累加 15 次、比较 $1.7\times10^6$ 次后误差仍 $\ll10^{-9}$ | 用 `f64=double`；**不要**用 `float`：其相对精度 $6\times10^{-8}$ 在 $8485$ 处给 $\approx5\times10^{-4}$ 的单值误差，累计可达 $10^{-3}$，足以把 $x.xx5$ 附近的结果舍入错 |
| 中间量 | $dx^2+dy^2\le 2\times400^2=320000$，不溢出 | `hypot(dx,dy)` 或 `sqrt` 皆可；`hypot` 顺带防一般性溢出/下溢 |
| 相等比较 | 浮点比较危险 | 只用 `<` / `>=`，绝不写 `==`；DP 的"不可达"用 `inf=1e18` 判定，**不能**依赖全局数组的默认 $0$（重合奶酪会产生真 $0$ 边） |
| 平方比较 | 常见技巧"比 $a^2$ 与 $b^2$" 在此**无效** | 目标是若干 $\sqrt{}$ 之和，不能整体平方比较大小 |
| 输出 | 要求 2 位小数 | `cout<<fixed<<setprecision(2)<<ans<<'\n'`，靠流舍入，不手写 `round` |
| 剪枝边界 | $cur+lb\ge ans$ 中的 $10^{-12}$ 级误差 | 误差远小于 $0.005$ 舍入粒度，剪枝方向不因它改变结论；仍可由引理 11 保证"至多丢掉并列最优" |

## 3. 模式总结（Pattern Summary）

按本文**实际思考顺序**列出的可复用标签（同一类步骤出现多次就拆成多条）：

- **explore its property — 把代价写成"边集之和"**：目标 $L=\sum_{\text{路径边}}dis$，系数全为 1，位置编号不出现 → 决定代价的是"谁与谁相邻"。
- **explore its property — 度数记账**：$O$ 度 1、恰一块奶酪度 1（终点）、其余度 2（引理 6）；后续路径的边数 $=|R|$，每条边归给它的**头**（引理 9 的根基）。
- **exchange-view check — 先确认加权交换视角是否可用**：只有目标形如 $\sum_k c_k\cdot(\text{第 }k\text{ 段})$ 才能"按后面贡献多少段"重分配后排序贪心；本题 $c_k\equiv1$，视角失效（引理 2 用 $n=2$ 双实例否证分解存在）。
- **reduce to easier problem — 删重复（三角不等式）**：证明最优解是排列，把搜索空间从"任意走法"缩到 $n!$（引理 1）。
- **consider easier version — $n=1,2,3$ + 共线 + 重合**：拿到可手算的标准答案，并暴露"按距排序在共线时对、一般时错"。
- **dissect greedy failure — 最近邻**：$n=4$ 反例，$6.5613$ vs 最优 $6.1613$；失败原因是"用掉便宜入边时同时烧掉便宜出边"。
- **dissect greedy failure — 按离原点距离排序**：$n=3$ 反例，$7.0990$ vs 最优 $7.0000$；失败原因是几何相邻 ≠ 到起点距离序。
- **dissect greedy failure — 边贪心（类 Kruskal）**：小数据上侥幸对，但缺"谁是终点"的信息，无交换论证 → 不采用。
- **classic problem solution — 状压 DP（第一遍）**：耦合决策 → 把"未消耗集合 + 当前位置"记进状态，$dp[S][i]$，$O(2^n n^2)=1.7\times10^6$ 次转移。
- **classic problem solution — 正向松弛 + 掩码拓扑序**：$j\notin S\Rightarrow S+2^j>S$，所以一层 $S$ 升序循环就够，不用按 $|S|$ 分层。
- **classic problem solution — 分支限界 DFS（第二遍，另一种技术）**：用可采纳下界 $lb=\sum_{i\in R}minn_i$ 砍子树，$O(1)$ 增量维护 $lb$。
- **admissible-bound discipline — 下界只数入边**：翻倍即错（引理 10 用同一组数据演示"整棵树被误杀"）。
- **admissible-bound discipline — 可行上界做种子**：贪心结果是**真实走法长度**，作为 $ans$ 初值只快不假。
- **strengthen the bound — MST 下界**：剩余路径本身是生成树，$w(\mathrm{MST})\le$ 附加路程（引理 12，本文不实现，留作救场）。
- **bound max — 两个下界取较大者仍可采纳**：$\max\!\big(\sum minn,\;w(\mathrm{MST})\big)\le g$，两者各自都是 $g$ 的下界。
- **symmetry trap — 路径不能反转去半**：环反转等价、路径不等价（引理 3），故不可加"首尾编号"类对称剪枝。
- **reduce to easier problem — 开放路径 TSP**：终点自由，答案 $\min_i dp[full][i]$，**不加回原点边**。
- **overflow/precision guard — `f64` + `hypot` + `fixed<<setprecision(2)`**：上界 $\approx8485$，`double` 误差 $\sim10^{-12}$，`float` 误差 $\sim10^{-3}$ 会毁掉两位小数。
- **porting pitfall — 全局数组必须 `fill_n` 成 `inf`**：重合奶酪给出真 $0$ 边，"默认 0"会把不可达状态当成 0 代价可达。
- **validation discipline — 无样例就全排列手算**：题面无样例，用 $24$ 项/ $6$ 项枚举当"人工对拍"。

| `x[],y[]` | 坐标；下标 $0$ 是原点，$1..n$ 是奶酪 | `x[0]=y[0]=0` | "0 号是老鼠的家" |
| `dis[a][b]` | 顶点间欧氏距离，$a,b\in[0,n]$ | 读入后 $O(n^2)$ 预处理，`hypot` | 距离表 |
| `dp[S][i]` | 已吃掩码 $S$（$0..n-1$ 位对应奶酪 $1..n$）、**当前站在奶酪 $i+1$** 时的最短路程 | 全填 `inf`，再置 `dp[1<<i][i]=dis[0][i+1]` | "集合 $S$ + 落脚点 $i$" |
| `S,j` | $S$：已吃集合；$j\notin S$：下一个要吃的奶酪下标 | — | — |
| `full` | $(1{\ll}n)-1$，全集掩码 | — | — |
| `ans` | $\min_i dp[full][i]$ | `inf` | 终点自由 |

注意下标换算：**DP 内层用 0-based 奶酪下标 $i$，距离表用 1-based 顶点编号**，所以转移里写 `dis[i+1][j+1]`，初值写 `dis[0][i]`（原点到奶酪 $i+1$）。

**步骤（代码一）**

1. 读 $n$，读 $n$ 个坐标到 `x[1..n]`，把 `x[0]=y[0]=0` 设成原点。
2. 双重循环算 `dis[i][j]=hypot(x[i]-x[j],y[i]-y[j])`，$0\le i,j\le n$（对称，全算不求巧）。
3. `fill_n(&dp[0][0], mxs*(mxn+5), inf)` —— 全局数组默认 $0$，不填就会把"不可达"当"0 代价可达"，答案直接变 $0.00$。
4. 置初值 `dp[1<<(i-1)][i-1]=dis[0][i]`，$i=1..n$：只吃一块奶酪，只能从原点直冲。
5. 三层循环：`S` 从 $1$ 到 $2^n-1$；`i` 枚举 $S$ 内的落脚点（`dp[S][i]>=inf` 则跳过）；`j` 枚举 $S$ 外的下一块，正向松弛 `dp[S|1<<j][j]=min(...,dp[S][i]+dis[i+1][j+1])`。合法性由 2.4 的 $S+2^j>S$ 保证。
6. `ans=min_i dp[full][i]`；`n=1` 时 `full=1`、循环只剩 `dp[1][0]`，正确退化。
7. `cout<<fixed<<setprecision(2)<<ans<<'\n'`。

**复杂度**：时间 $O(2^n n^2)$，实际转移数 $n(n-1)2^{n-2}=1\,720\,320$（$n=15$）；空间 $O(2^n n)$，`dp` 占 $32768\times20\times8\approx5.24\ \text{MB}$（全局静态区，安全）。运行时间与坐标分布**无关**，这是它优于搜索的原因。

**步骤（代码二，DFS + 剪枝）**：预处理同 1–2；额外算 `minn[i]`（$j$ 遍历 $0..n$ 且 $j\ne i$）与根下界 `sum=Σminn[i]`；`dfs(u,dep,cur,lb)`：`dep==n` 用 `cur` 更新 `ans` 并返回；否则 `cur+lb>=ans` 返回；否则枚举未访问 $v$，`dfs(v,dep+1,cur+dis[u][v],lb-minn[v])`，回溯清 `vis`。初始调用 `dfs(0,0,0,sum)`。复杂度：最坏 $O(n!\cdot n)$，实测依赖数据（本文**未运行**，见下）。

## 5. 示例代码

**代码一：状压 DP（推荐提交，无条件 $O(2^n n^2)$）**

```cpp
#include<bits/stdc++.h>
using namespace std;
using f64=double;

constexpr int mxn{15},mxs{1<<mxn};
constexpr f64 inf{1e18};

int n;
f64 x[mxn+5],y[mxn+5],dis[mxn+5][mxn+5];
f64 dp[mxs][mxn+5];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)
		cin>>x[i]>>y[i];
	x[0]=y[0]=0;                                  //0 号点是原点
	for(int i=0;i<=n;++i)
		for(int j=0;j<=n;++j)
			dis[i][j]=hypot(x[i]-x[j],y[i]-y[j]);

	fill_n(&dp[0][0],mxs*(mxn+5),inf);            //全局数组默认 0，必须显式填 inf
	for(int i=1;i<=n;++i)
		dp[1<<(i-1)][i-1]=dis[0][i];
	for(int S=1;S<(1<<n);++S)
		for(int i=0;i<n;++i)
		{
			if(!(S>>i&1)||dp[S][i]>=inf)
				continue;
			for(int j=0;j<n;++j)
				if(!(S>>j&1))
					dp[S|(1<<j)][j]=min(dp[S|(1<<j)][j],dp[S][i]+dis[i+1][j+1]);
		}

	f64 ans=inf;
	int full=(1<<n)-1;
	for(int i=0;i<n;++i)
		ans=min(ans,dp[full][i]);
	cout<<fixed<<setprecision(2)<<ans<<'\n';
	return 0;
}
```

**代码二：DFS + 可采纳下界剪枝（对照写法，验证"只数入边"的下界确实够用）**

```cpp
#include<bits/stdc++.h>
using namespace std;
using f64=double;

constexpr int mxn{15};
constexpr f64 inf{1e18};

int n;
f64 x[mxn+5],y[mxn+5],dis[mxn+5][mxn+5];
f64 minn[mxn+5],ans=inf;                //minn[i]:奶酪 i 到任一其它顶点的最短距离
bool vis[mxn+5];

void dfs(int u,int dep,f64 cur,f64 lb)
{
	if(dep==n)
	{
		if(cur<ans)
			ans=cur;                     //lb==0，无需再看
		return;
	}
	if(cur+lb>=ans)                      //可采纳下界：剪掉不可能更优的子树
		return;
	for(int v=1;v<=n;++v)
		if(!vis[v])
		{
			vis[v]=1;
			dfs(v,dep+1,cur+dis[u][v],lb-minn[v]);   //v 的入边由实际值接管
			vis[v]=0;
		}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=1;i<=n;++i)
		cin>>x[i]>>y[i];
	x[0]=y[0]=0;
	for(int i=0;i<=n;++i)
		for(int j=0;j<=n;++j)
			dis[i][j]=hypot(x[i]-x[j],y[i]-y[j]);

	f64 sum=0;
	for(int i=1;i<=n;++i)
	{
		minn[i]=inf;
		for(int j=0;j<=n;++j)
			if(j!=i)                     //必须含原点 0，且排除自身
				minn[i]=min(minn[i],dis[i][j]);
		sum+=minn[i];                    //根节点下界
	}

	dfs(0,0,0,sum);
	cout<<fixed<<setprecision(2)<<ans<<'\n';
	return 0;
}
```
