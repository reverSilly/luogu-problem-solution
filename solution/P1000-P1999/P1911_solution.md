# P1911 L 国的战斗之排兵布阵

## 1. 重新读题

有一个 $2^n\times 2^n$ 的方阵，以及编号 $1\sim\frac{4^n-1}{3}$ 的 L 形骨牌，每块恰好覆盖 $2\times2$ 方格中的 $3$ 格（少任意一格，方向可旋转）。给定一个格子 $(x,y)$，要求用骨牌覆盖**除它以外**的所有格子，且任意两骨牌不重叠。输出每个格子所属骨牌编号，$(x,y)$ 输出 $0$。

### 关键约束与规模暗示

- $1\le n\le10$，所以方阵最大 $1024\times1024$，骨牌数 $\frac{4^n-1}{3}\le349525$。
- 面积恰好对上：骨牌数 $\times3=4^n-1$，刚好是"除一格"的格子数。这暗示**只要构造不重叠，就自动铺满**，不需要额外的覆盖检查。
- 输出量本身是 $4^n\approx10^6$ 个数，允许 $O(4^n)$ 的构造；不可能对格子做多项式级以上的搜索。

## 2. 思维链（Chain-of-thought）

### 2.1 面积先对账

**引理 0（数量必然吻合）**：$3\mid(4^n-1)$，且 $\frac{4^n-1}{3}$ 块骨牌恰好覆盖 $4^n-1$ 个格子。

**证明**：$4\equiv1\pmod3$，故 $4^n\equiv1\pmod3$，$3\mid4^n-1$。块数乘以 $3$ 等于 $4^n-1$，正好等于要去掉的格子数。$\blacksquare$

所以**不会剩格子，也不会不够用**；构造只需保证不重叠、不盖洞。

### 2.2 从 $n=1$ 看结构

$n=1$ 时是 $2\times2$ 去掉一格，剩下的三格天然是一个 L 形——直接用一块骨牌解决。这是递归的底。

### 2.3 分治：把大问题拆成四个同型小问题

设当前方块边长 $sz=2^k\ge4$。把它切成四个 $sz/2$ 的子方块（左上、右上、左下、右下）。洞只落在其中一个子方块里。

如果能让"另外三个子方块"各缺一格、且缺的格子在**靠近整体中心**的那个角上，那么：

- 每个子方块都变成"$2^{k-1}\times2^{k-1}$ 缺一格"的**完全相同的小问题**，可以递归；
- 三个子方块各自缺的那一格，正好是中心 $2\times2$ 区域里互不相同的三格，可以再用**一块**骨牌补上！

具体地：在中心 $2\times2$ 区域放一块骨牌，盖住"不含洞的三个子方块各自靠近中心的那个角格"。中心 $2\times2$ 有一格属于洞所在的子方块，这块骨牌跳过它，于是它正好覆盖三格，形状是一个 L 形（$2\times2$ 去一格）。

**关键理解**：对递归到"不含洞子方块"时，那个被中心骨牌占住的角格不能、也不该再被覆盖，所以我们在子问题里把它**当作洞**。它不是真的窟窿，只是"已经铺过了"。这样递归的接口统一为"覆盖一个 $sz\times sz$ 方块，除指定的一格外"。

### 2.4 构造合法性（核心引理）

**引理 1（递归正确性）**：对任意 $n\ge1$、任意方块位置、任意洞位置，算法 `cover(r,c,sz,hr,hc)` 用互不重叠的 L 骨牌恰好覆盖方块内除 $(hr,hc)$ 外的所有格子，且骨牌编号互不相同。

**证明**：对 $k=\log_2 sz$ 归纳。

- 基础 $k=1$（$sz=2$）：除洞外恰有 $3$ 格，构成 $2\times2$ 减去一格，是一个 L 形；分配一个新编号即可。成立。
- 归纳步 $k\ge2$：令 $half=sz/2$，洞所在象限为 $Q$。中心 $2\times2$ 的四格按象限各归属一格。新骨牌覆盖除"$Q$ 的中心角格"外的三格：
  - 这三格分属三个不同象限，且都是对应象限靠近中心的角格；
  - 它们都在中心 $2\times2$ 内，形状为 $2\times2$ 去一格，是合法 L 形；
  - 均不是洞（洞在 $Q$ 内）。
  然后对四个子方块递归：
  - 对含洞象限 $Q$：洞仍是原洞，位于该子方块内；
  - 对其余三个象限：把"被新骨牌占用的那个中心角格"当作洞，它确实是该子方块的一个角格。

  由归纳假设，四个子问题的覆盖各自合法；四块区域两两不交；新骨牌只落在中心 4 格内且与子问题区域不重叠（子问题覆盖的是各自常规划分内的格子，中心角格在这些划分里恰好是"洞"，不会被覆盖）。所以并集恰好覆盖"大方块去掉洞"的所有格子，且无重叠。
  
  编号：中心骨牌取一个新编号，四个子问题各自使用独立递增的全局计数器，互不相撞。$\blacksquare$

**引理 2（编号范围）**：算法使用的编号总数恰为 $\frac{4^n-1}{3}$，全部落在 $1\sim\frac{4^n-1}{3}$。

**证明**：设 $T(n)$ 为边长 $2^n$ 时的骨牌数。$T(1)=1$。$n\ge2$ 时中心一块，四个 $2^{n-1}$ 子块各 $T(n-1)$ 块：

$$T(n)=1+4T(n-1).$$

解此递推：$T(n)=1+4+\dots+4^{n-1}=\frac{4^n-1}{3}$。又全局 `tile` 从 $0$ 起每次自增一后赋给一整块骨牌，故编号恰为 $1,\dots,T(n)$。$\blacksquare$

结合引理 0，全部格子（除洞）被覆盖且不越界。

### 2.5 实现要点与一个容易写错的地方

中心骨牌在四个象限中的位置必须**按象限分别计算**：对第 $(q_i,q_j)$ 象限（$0$ 上/左，$1$ 下/右），它靠近中心的角格是

$$\big(r+(q_i\,?\,0:half-1),\ c+(q_j\,?\,0:half-1)\big).$$

一开始我图省事，把所有子问题的"假洞"都写成 $(nr+half-1,nc+half-1)$，结果对右下/左下象限指到了该子块的**外角**，那里根本不该缺格，输出里出现了一片 $0$。改成上面的按象限公式后，用 checker 验证 $n=1\dots7$ 以及 $n=10$ 两端点均通过。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 面积对账：骨牌数乘 3 恰好等于 $4^n-1$（引理 0）。
- **consider easier version** — $n=1$ 的 $2\times2$ 去一格就是一块 L 骨牌。
- **divide and conquer** — 切成四块，洞只在一块的象限；中心放一块补齐另外三块的角。
- **reduce to easier problem** — 把"已被中心骨牌占用的角格"视为洞，四个子问题完全同型。
- **induction proof** — 对层数归纳证明覆盖合法、编号恰好用满。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 方阵边长指数，边长 $N=2^n$ | 读入 | $n\le10$ |
| `N` | `int` | 方阵边长 $2^n$ | `1<<n` | side |
| `x,y` | `int` | 洞的行列（读入为 1-based） | 读入后减一 | hole |
| `ans[i][j]` | `int[1030][1030]` | 格子 $(i,j)$ 所属骨牌编号，洞为 $0$ | 全 $0$ | grid |
| `tile` | `int` | 当前已分配的最大编号 | $0$ | 计数器 |
| `cover(r,c,sz,hr,hc)` | 函数 | 覆盖左上角 $(r,c)$、边长 $sz$ 的方块，洞在 $(hr,hc)$ | — | 分治 |

### 4.2 算法步骤

1. 读入 $n,x,y$，计算 $N=2^n$，并把 $x,y$ 转为 0-based。
2. 调用 `cover(0,0,N,x,y)`：
   - 若 $sz=1$：直接返回（只有 $n=0$ 才会出现，题面 $n\ge1$ 时用不到）；
   - 若 $sz=2$：`++tile`，把 $2\times2$ 中除洞外的三格标为 `tile`，返回；
   - 否则令 $half=sz/2$，算出洞所在象限 $(qr,qc)$；`++tile`，在中心 $2\times2$ 中把除 $(qr,qc)$ 对应的那一格之外的三个中心角格标为 `tile`；
   - 对四个象限递归：含洞象限传原洞；其余象限传"被中心骨牌占用的那个角格"作为洞。
3. 输出 $N$ 行，每行 $N$ 个数，洞位置自然为 $0$。

### 4.3 复杂度

- 时间：每个格子在递归树中只被处理常数次，总时间 $O(4^n)$；输出同样 $O(4^n)$。
- 空间：`ans` 占 $O(4^n)$，递归深度 $O(n)$。

## 5. 示例代码

```cpp
//
// 题目：P1911 L 国的战斗之排兵布阵
// https://www.luogu.com.cn/problem/P1911
// Special Judge：输出任意合法方案
//
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1030};

int n,N;
int ans[mxn][mxn];
int tile=0;

void cover(int r,int c,int sz,int hr,int hc)
{
	if(sz==1)
		return;
	if(sz==2)
	{
		++tile;
		for(int i=0;i<2;++i)
			for(int j=0;j<2;++j)
				if(!(r+i==hr&&c+j==hc))
					ans[r+i][c+j]=tile;
		return;
	}
	int half=sz>>1;
	int qr=(hr>=r+half),qc=(hc>=c+half); // 洞所在象限：0 上/左，1 下/右
	++tile;
	for(int i=0;i<2;++i)
		for(int j=0;j<2;++j)
		{
			if(i==qr&&j==qc)
				continue; // 洞所在象限的中心角格不铺
			ans[r+half-1+i][c+half-1+j]=tile;
		}
	for(int qi=0;qi<2;++qi)
		for(int qj=0;qj<2;++qj)
		{
			int nr=r+qi*half,nc=c+qj*half;
			if(qi==qr&&qj==qc)
				cover(nr,nc,half,hr,hc);
			else // 该象限靠近中心的角格已被中心骨牌占用，递归时视为洞
				cover(nr,nc,half,nr+(qi?0:half-1),nc+(qj?0:half-1));
		}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int x,y;
	cin>>n>>x>>y;
	N=1<<n;
	--x;--y;
	cover(0,0,N,x,y);
	for(int i=0;i<N;++i)
		for(int j=0;j<N;++j)
			cout<<ans[i][j]<<" \n"[j+1==N];
	return 0;
}
```
