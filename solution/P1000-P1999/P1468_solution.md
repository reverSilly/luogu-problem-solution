# P1468 [IOI 1998 / USACO 2.2] 派对灯 Party Lamps

> 标签：模拟 / 搜索 / 位运算 · 难度：提高/省选-

## 1. 重新读题

**问题重述（大白话版）**

一条线上有 $n$ 盏灯，编号 $1\sim n$，宴会开始时**全部亮着**。四个按钮各自固定翻转一批灯：

| 按钮 | 翻转的下标集合 $S_j\subseteq\{1,\dots,n\}$ | 用同余语言写 |
|---|---|---|
| 1 | $\{1,2,\dots,n\}$ | 全部 |
| 2 | $\{i: i\equiv 1\pmod 2\}$ | 奇数号 |
| 3 | $\{i: i\equiv 0\pmod 2\}$ | 偶数号 |
| 4 | $\{i: i\equiv 1\pmod 3\}$，即 $3k+1,\ k\ge 0$ | $1,4,7,10,\dots$ |

按一次按钮 = 对这个固定的 0/1 向量做一次"异或"。给定：

- 计数器读数 $c$：**实际按按钮的总次数**；
- 一批"末态必须亮"的灯号（第三行，`-1` 结尾）；
- 一批"末态必须灭"的灯号（第四行，`-1` 结尾）。

求：所有与这些信息相符、且互不重复的末态。

**数据范围（题面 100% 口径）**

| 量 | 范围 | 提示 |
|---|---|---|
| $n$ | $10\le n\le 100$ | 极小；一行最多 100 个字符 |
| $c$ | $0\le c\le 10^4$ | 比 $n$ 还大两个量级 ⇒ **绝不可能是"枚举按压序列"** |
| 约束灯号 | 保证同一盏灯不在输入中出现两次 | 不会出现"同一灯既要亮又要灭"的直接矛盾 |

$n,c$ 都这么小，说明考点不在"快"，而在**把指数级的按压序列空间压缩成常数级候选**。而 $c$ 的上界（$10^4$）远远超过按钮个数（4），这是最强的一道提示：**$c$ 只会以"奇偶 + 大小比较"的形式进入答案**，不会以"具体按了多久"的形式进入。

**输出的四条硬口径（逐字核对题面）**

1. 每行 $n$ 个字符，第 $i$ 个字符是灯 $i$ 的末态，`0` 灭 `1` 亮 —— **行长固定为 $n$**，不能省前导 `0`；
2. 行之间**没有重复**；
3. 行**从小到大排列（"看作是二进制数"）** —— 排序键是**数值序**；
4. 若一行都没有，输出单独一行 `IMPOSSIBLE`（全大写）。

**口径确认 ①：恰好 $c$ 次，而不是"至多 $c$ 次"**

题面原文："一个计数器 $c$ 记录按钮被按下的次数""第二行一个整数 $c$，表示最后计数器的数值"。计数器的值就是**已经发生的按压总数**，所以是**恰好 $c$ 次**。
注意：部分外部资料/译本把这里叙述成"不超过 $c$ 次操作"，**与本地题面冲突时按本地题面**（恰好 $c$ 次）。两种口径答案集合不同，例如 $c=2$、无约束时：恰好口径得 7 个状态（缺"只按按钮 4"），至多口径得 8 个。§2.6 把这个差别精确量化，并说明为什么"恰好"口径下反而**天然不会输出重复行**。

**口径确认 ②：本地题面没有样例输入/输出数据块**

本地 `P1468.md` 只有"【样例解释】"这段文字（说有三种可能末态：全灭；$1,4,7,10$ 灭而 $2,3,5,6,8,9$ 亮；$1,3,5,7,9$ 灭而 $2,4,6,8,10$ 亮），**没有给出样例输入与样例输出**，因此**无法与官方答案对标**。§4 的验证只能用"反推样例 + 自造边界用例"手算。
从解释反推：这三种末态恰好就是"只按 1""只按 2""只按 4"的效果，而"只按 3"（$1,3,5,7,9$ 亮）与"什么都不按"（全亮）都让 7 号灯亮着，被排除 —— 所以样例应是 $n=10,\ c=1$，"必须亮"列表为空，"必须灭"列表为 $\{7\}$。§4 以这组**反推数据**当主样例，并注明它是推断而非题面原文。

## 2. 思维链（Chain-of-thought）

### 2.1 探索特殊机制：按压的代数

**先把机制翻译成符号。** 用 $s\in\{0,1\}^n$ 表示灯的状态，$s_i=1$ 表示灯 $i$ 亮。初始 $s=(1,1,\dots,1)$。
每个按钮 $j\in\{1,2,3,4\}$ 对应一个固定的翻转向量 $b_j\in\{0,1\}^n$：$(b_j)_i=1\iff i\in S_j$。
按一次按钮 $j$ 就把状态变成 $s\oplus b_j$（$\oplus$ 表示逐位异或，即模 2 加）。

一个长度为 $L$ 的按压序列 $(a_1,\dots,a_L)$（每个 $a_t\in\{1,2,3,4\}$，$L$ 就是题面的计数器值 $c$）产生的效果是

$$b_{a_1}\oplus b_{a_2}\oplus\cdots\oplus b_{a_L}.$$

**引理 1（按压可交换、可对消：末态只取决于"每个按钮按了几次的奇偶"）**

设按钮 $j$ 在序列中出现了 $cnt_j$ 次，则末态只由奇偶向量 $x_j=cnt_j\bmod 2\ (j=1,2,3,4)$ 决定：

$$\text{末态}=(1,\dots,1)\oplus\bigoplus_{j=1}^{4}\,[x_j=1]\cdot b_j .$$

**证明**：异或是 $\mathbb{F}_2^n$ 上的加法，满足结合律与交换律，所以求和顺序无关，可把同一个按钮的贡献合并：

$$\bigoplus_{t=1}^{L} b_{a_t}=\bigoplus_{j=1}^{4}\underbrace{(b_j\oplus b_j\oplus\cdots\oplus b_j)}_{cnt_j\ \text{个}} .$$

再看括号内：$\mathbb{F}_2$ 中 $1+1=0$，故偶数个 $b_j$ 异或为全零向量，奇数个异或为 $b_j$ 本身（把前 $cnt_j-1$ 个两两配对归零，剩一个）。于是该值等于 $[x_j=1]\cdot b_j$，与 $cnt_j$ 的具体大小无关。四种按钮逐项代入即得所求。$\blacksquare$

> 这一步把"长度为 $c$ 的序列空间（$4^c$，天文数字）"直接压成 **16 个奇偶向量**。搜索空间一下子从指数级变成常数级——这就是 $c\le 10^4$ 那句提示的落地。

**但 16 个奇偶向量并不是都"合法"**：不是每个 $x$ 都能由**恰好 $c$ 次**按压实现。

**引理 2（可达性充要条件）**

记 $k(x)=x_1+x_2+x_3+x_4$（即 $x$ 中 1 的个数，等价于 $\operatorname{popcount}$）。则奇偶向量 $x$ 能由恰好 $c$ 次按压实现 $\iff$ $k(x)\le c$ 且 $c-k(x)$ 为偶数。

**证明（$\Rightarrow$）**：若存在非负整数 $cnt_1,\dots,cnt_4$ 满足 $\sum_j cnt_j=c$ 且 $cnt_j\equiv x_j\pmod 2$，则
（i）$cnt_j\ge x_j$（因为 $cnt_j\equiv 1\pmod 2\Rightarrow cnt_j\ge 1=x_j$；$cnt_j\equiv 0\pmod 2\Rightarrow cnt_j\ge 0=x_j$），求和得 $c=\sum_j cnt_j\ge\sum_j x_j=k(x)$；
（ii）$c=\sum_j cnt_j\equiv\sum_j x_j=k(x)\pmod 2$，即 $c-k(x)$ 为偶数。

**证明（$\Leftarrow$）**：设 $k(x)\le c$ 且 $c-k(x)=2t$（$t\ge 0$ 为整数）。构造 $cnt_j=x_j\ (j=2,3,4)$，$cnt_1=x_1+2t$。
则 $cnt_1\equiv x_1\pmod 2$（加了偶数），$cnt_j\equiv x_j\pmod 2\ (j\ge2)$，奇偶向量正是 $x$；
且 $\sum_j cnt_j=(x_1+2t)+x_2+x_3+x_4=k(x)+2t=c$。
所有 $cnt_j\ge 0$，故这是一个合法的按压次数分布（先把 $x$ 中标 1 的按钮各按一次，再把剩下的 $2t$ 次全部"成对"压在按钮 1 上，每对互相抵消）。$\blacksquare$

> **推论（考点定型）**：判定一个奇偶向量是否可用，只需两次 $O(1)$ 检查（大小 + 奇偶），完全不需要搜索按压序列。于是"枚举 16 个 $x$、逐个模拟、逐个判约束"就是一个**完备且无剪枝**的暴力——候选总数最多 16。
> 特例检查：$c=0$ 时只有 $k=0$ 即 $x=(0,0,0,0)$ 通过（$k\le 0$ 强制 $k=0$），末态只能是"全亮"，符合直觉。

### 2.2 简化版：把 $n$ 盏灯压缩成周期结构

16 个候选已经足够小，但如果继续问"这 16 个是否给出 16 种**不同**的末态"，就会挖出这题真正的结构（也是"输出不能重复"那句要求的来源）。

**引理 3（末态关于灯号以 6 为周期）**

对任意奇偶向量 $x$，灯 $i$ 的翻转次数（模 2）为

$$f_x(i)=x_1\oplus\big(x_2\cdot[i\text{ 奇}]\oplus x_3\cdot[i\text{ 偶}]\big)\oplus x_4\cdot[i\equiv 1\pmod 3],$$

故 $f_x(i)$ 只依赖 $(i\bmod 2,\ i\bmod 3)$，从而只依赖 $i\bmod 6$：只要 $i$ 与 $i+6$ 都不超过 $n$，就有 $f_x(i)=f_x(i+6)$。

**证明**：$f_x(i)$ 的四个加项分别是：常数 $x_1$；$[i\text{ 奇}]$ 与 $[i\text{ 偶}]$，只由 $i\bmod 2$ 决定；$[i\equiv 1\pmod 3]$，只由 $i\bmod 3$ 决定。而 $i\bmod 2$ 与 $i\bmod 3$ 由 $i\bmod 6$ 唯一决定（中国剩余定理：$\gcd(2,3)=1$，映射 $i\bmod 6\mapsto(i\bmod 2,i\bmod 3)$ 是双射）。因此 $i\equiv i+6\pmod 6$ 时两个坐标都不变，$f_x(i)=f_x(i+6)$。$\blacksquare$

> 直观记法：**一行只有 6 个本质不同的位置**，$n$ 再大也只是把这 6 位重复。$n\ge 10$ 保证 6 个剩余类全部出现（$1,\dots,6$ 都在），所以后面做的"剩余类互异性"计数不会因 $n$ 太小而失真。

**引理 4（按钮 1 是冗余的：$b_1=b_2\oplus b_3$）**

**证明**：逐坐标验证。任取 $i\in\{1,\dots,n\}$。
- 若 $i$ 为奇数：$(b_2)_i=1$，$(b_3)_i=0$，故 $(b_2\oplus b_3)_i=1=(b_1)_i$；
- 若 $i$ 为偶数：$(b_2)_i=0$，$(b_3)_i=1$，故 $(b_2\oplus b_3)_i=1=(b_1)_i$。
两种情形都等于 1，而 $b_1$ 恒为 1，所以两向量相等。$\blacksquare$

> 后果：按压 $(1,2,3)$ 三个按钮各一次（奇偶向量 $(1,1,1,0)$）**效果等于什么都不做**，即 $b_1\oplus b_2\oplus b_3=0$。所以 16 个奇偶向量最多给出 $16/2=8$ 种末态。

**引理 5（恰有 8 种不同末态；同一末态的两个原像恰相差 $(1,1,1,0)$）**

**证明**：由引理 4，$b_1=b_2\oplus b_3$，代入 $\varphi$ 的定义并按 $\mathbb{F}_2$ 合并同类项：

$$\varphi(x)=x_1(b_2\oplus b_3)\oplus x_2b_2\oplus x_3b_3\oplus x_4b_4=(x_1\oplus x_2)b_2\oplus(x_1\oplus x_3)b_3\oplus x_4b_4.$$

**第一步：像集大小 $=8$。** 只需证 $b_2,b_3,b_4$ 在 $\mathbb{F}_2^6$（前 6 个坐标，引理 3 说明看前 6 位足够）上线性无关。
设 $\alpha b_2\oplus\beta b_3\oplus\gamma b_4=0$，其中

$$b_2=(1,0,1,0,1,0),\quad b_3=(0,1,0,1,0,1),\quad b_4=(1,0,0,1,0,0)$$

（$b_4$ 恰在第 1、4 位为 1，因为前 6 个里只有 $1=3\cdot0+1$ 与 $4=3\cdot1+1$ 满足 $\equiv1\pmod 3$）。
- 取坐标 3：$\alpha\cdot1\oplus\beta\cdot0\oplus\gamma\cdot0=\alpha=0$；
- 取坐标 2：$\beta=0$；
- 取坐标 1：$\alpha\oplus\gamma=0$，结合 $\alpha=0$ 得 $\gamma=0$。
故只有零解，$\dim\operatorname{span}\{b_2,b_3,b_4\}=3$，其元素个数 $=2^3=8$。
又 $(x_1,x_2,x_3,x_4)\mapsto(x_1\oplus x_2,\ x_1\oplus x_3,\ x_4)$ 显然是满射（取 $x_1=0,x_2=u,x_3=v,x_4=w$ 即得任意 $(u,v,w)$），所以 $\varphi$ 的像恰为整个 $\operatorname{span}\{b_2,b_3,b_4\}$，**大小正好 8**。

**第二步：原像结构。** $\varphi(x)=\varphi(y)\iff$ 三个坐标相等：$x_1\oplus x_2=y_1\oplus y_2$，$x_1\oplus x_3=y_1\oplus y_3$，$x_4=y_4$。
记 $d=x\oplus y$，条件即 $d_1\oplus d_2=0,\ d_1\oplus d_3=0,\ d_4=0$，解为 $d=(t,t,t,0)$，$t\in\{0,1\}$。
故每个末态恰好被 2 个奇偶向量取到，它们相差 $(1,1,1,0)$（或相同）。结合第一步（16 个 $x$、8 个像、每个像 2 个原像，计数吻合）。$\blacksquare$

> 也就是说：**全世界只有 8 种不同的派对灯末态**（$n\ge 6$ 时，本题 $n\ge 10$ 满足）。
> 计数直觉：$b_1$ 完全冗余（"按 1"="按 2 再按 3"），有效自由度只有 3 个 $\Rightarrow 2^3=8$。这条是 §2.3 拆贪心失败的弹药。

### 2.3 剖析贪心失败："每个状态记最小按压数"

**贪心的诱惑。** 引理 2 给了"奇偶向量 $x$ 可用 $\iff k(x)\le c$ 且 $c-k(x)$ 为偶"。而引理 5 说"两个奇偶向量可能给同一个末态"。
于是很自然地想：**先把 16 个奇偶向量合并成 8 个真实状态，每个状态记一个"最小按压数" $m$，然后判 $m\le c$ 且 $c-m$ 为偶** —— 这样候选表只有 8 行，看着更"精简易写"。这个想法是**错的**，而且是这题最常见的错解。

**错在哪：引理 2 的条件是"点"层面的，不是"类"层面的。** 状态是一个等价类 $\{x,\,x\oplus(1,1,1,0)\}$，而奇偶约束 $k\equiv c\pmod 2$ 是**定义在类中元素上**的性质；取 $\min$ 会丢掉另一个元素。

**引理 6（同一状态两个代表元的 $k$ 之和为奇数）**

设 $x=(x_1,x_2,x_3,x_4)$，$x'=x\oplus(1,1,1,0)=(1-x_1,1-x_2,1-x_3,x_4)$，二者由引理 5 给出同一末态。记 $t=x_1+x_2+x_3$，则

$$k(x)=t+x_4,\qquad k(x')=(3-t)+x_4,\qquad k(x)+k(x')=3+2x_4\in\{3,5\}.$$

**证明**：$x'$ 的前三个坐标各取反，故其 1 的个数由 $t$ 变为 $3-t$；第四个坐标不变，故 $k(x')=(3-t)+x_4$。两式相加：$t+x_4+(3-t)+x_4=3+2x_4$，$x_4\in\{0,1\}$ 给出 3 或 5，两者都是奇数。$\blacksquare$

> **直接后果**：一个状态的两个代表元，一个 $k$ 为偶、一个 $k$ 为奇（且和为 3 或 5）。所以对固定的 $c$，**恰好其中一个**满足"$k\equiv c\pmod 2$"。这意味着
> - 判定"状态 $S$ 是否可达"必须**同时看两个代表元**，看那个"奇偶匹配 $c$"的代表元的 $k$ 是否 $\le c$；
> - 只存 $m=\min(k,k')$ 会把奇偶信息抹掉，从而错判（见下面两组具体数据）。

**反例 A（$c=3$，无任何约束，末态"全亮"）。** 全亮由 $x=(0,0,0,0)$（$k=0$）与 $x'=(1,1,1,0)$（$k=3$）给出，$m=0$。
- 错误规则：$m=0\le 3$ 但 $3-0=3$ 为奇 ⇒ 判"全亮不可达"。
- 事实：按按钮 1、2、3 各一次，共 3 次：按 1 → 全灭；按 2 → 奇数号翻回亮，偶数号仍灭；按 3 → 偶数号翻回亮 ⇒ **全亮**，正好 3 次。所以"全亮"必须输出。
  手算 $n=10$ 的逐位：$x'=(1,1,1,0)$，$f(i)=1\oplus(i\text{奇}?1:1)\oplus 0=1\oplus 1=0$（两种奇偶都算出 1），故所有位都不翻转 ⇒ `1111111111` ✓。

**反例 B（$c=2$，无任何约束）。** 用错误规则跑一遍 8 个状态（$m$ 值见 §2.5 的表）：

| 末态（$n=10$） | 两个代表元的 $k$ | $m$ | 错误规则（$m\le2$ 且 $2-m$ 偶） | 真实是否可达 |
|---|---|---|---|---|
| `1111111111` | 0 / 3 | 0 | 收 | 收（$k=0$） |
| `0000000000` | 1 / 2 | 1 | **弃**（$2-1$ 奇） | **收**（$k=2$，即按 2 和 3） |
| `0101010101` | 1 / 2 | 1 | **弃** | **收**（按 1 和 3） |
| `1010101010` | 1 / 2 | 1 | **弃** | **收**（按 1 和 2） |
| `0110110110` | 1 / 4 | 1 | **弃** | 弃 |
| `1001001001` | 2 / 3 | 2 | 收 | 收 |
| `1100011100` | 2 / 3 | 2 | 收 | 收 |
| `0011100011` | 2 / 3 | 2 | 收 | 收 |

错误规则输出 4 行，正确应有 7 行 —— **漏掉 3 行**。
（逐行核对"真实可达"：`0000000000` 用 $x=(0,1,1,0)$，即 $b_2\oplus b_3=b_1$，$k=2\le 2$ 且 $2-2=0$ 偶 ✓；`0101010101`（奇数号被翻）用 $x=(1,0,1,0)$，即 $b_1\oplus b_3=b_2$，$k=2$ ✓；`1010101010`（偶数号被翻）用 $x=(1,1,0,0)$，即 $b_1\oplus b_2=b_3$，$k=2$ ✓。`0110110110` 只有 $k=1,4$ 两个代表元，与 $c=2$ 奇偶都不匹配 ⇒ 确实不可达 ✓。）

**另一类坑（反过来：漏掉奇偶检查）。** 若只判 $k\le c$ 而不检查 $c-k$ 的奇偶（相当于偷偷用了"至多 $c$ 次"口径），会出现两种症状：
- **多余行**：$c=1$ 时 $x=(0,0,0,0)$ 满足 $0\le 1$，于是输出 `1111111111`，但 1 次按压不可能回到全亮；
- **重复行**：$c=4$ 时 $x=(0,0,0,0)$（$k=0$）与 $x=(1,1,1,0)$（$k=3$）都满足 $k\le4$，两者末态都是全亮 ⇒ 同一行输出两次，违反"没有重复"。

**教训**：奇偶向量层面（16 个）判定是**一对一**的，$k$ 与奇偶都精确；一旦压到状态层面（8 个）就必须显式携带"两个 $k$"，不能只留最小值。所以本解法选择**在 16 个奇偶向量上做判定，把去重推迟到最后**（defer reconstruction）。

### 2.4 经典解法：16 个奇偶向量全枚举

**结构盘点（到此为止得到的东西）**

- 候选末态总数 $\le 16$（引理 1、2：只需枚举奇偶向量 $x\in\{0,1\}^4$）；
- 其中真正互不相同的 $\le 8$（引理 5），所以**输出最多 8 行**；
- 判定一个候选是否"合法"分两小步：(a) 它能否由恰好 $c$ 次按压产生（引理 2）；(b) 它在所有被约束的灯上是否与输入一致。

**于是正解就是"枚举 + 模拟 + 收集"三段式，没有任何剪枝技巧：**

1. 用 $m=0..15$ 的二进制位当 $(x_1,x_2,x_3,x_4)$（$m$ 的第 $j-1$ 位就是 $x_j$）；
2. 先过引理 2 的两道门：`k<=c` 与 `(c-k)%2==0`，$k=$ popcount；
3. 活着下来的候选，逐灯 $i=1..n$ 算 $f_x(i)$（引理 3 的公式）得到末态位 $1\oplus f_x(i)$，边算边对照 `req[i]`；一旦某盏被约束的灯不符就整行弃掉；
4. 全程相符的候选，把长度 $n$ 的字符串丢进 `ans`；
5. 全部枚举完，`ans` 排序 + 去重后逐行输出；空集则 `IMPOSSIBLE`。

**为什么这样一定不漏（完备性证明）**

**引理 7（枚举完备性）**：对任意合法按压序列（长度恰为 $c$），其末态必出现在 `ans` 中；反之 `ans` 中每个串都存在一个长度恰为 $c$ 且满足全部约束的按压序列。

**证明**：
- （$\Rightarrow$）任取一个长度 $c$ 的按压序列，按引理 1 它有奇偶向量 $x$ 与按压次数分布 $cnt_j$。由引理 2 的正向部分，$k(x)\le c$ 且 $c-k(x)$ 为偶，所以第 2 步的门会放行 $x$。该序列末态满足全部输入约束（题设），而第 3 步用引理 3 的公式重算的就是同一个末态（引理 1 保证末态只由 $x$ 决定，与序列顺序无关），所以第 3 步的约束检查也全部通过，该串被收入 `ans`。
- （$\Leftarrow$）设某串在 `ans` 中，来自奇偶向量 $x$。由第 2 步，$k(x)\le c$ 且 $c-k(x)=2t$。取引理 2 反向构造的分布：$cnt_1=x_1+2t,\ cnt_j=x_j\ (j\ge2)$，$\sum_j cnt_j=c$，把按钮按此次数任意排成一个长度 $c$ 的序列（例如先按 $x$ 中标 1 的按钮各一次，再把按钮 1 连按 $2t$ 次）。由引理 1，该序列末态正是 $x$ 对应的末态，即 `ans` 里这个串；而第 3 步已经逐灯验证它满足所有约束。$\blacksquare$

**为什么这样一定不重（去重口径）**

`ans` 里可能同时出现"同一个末态的两个代表元"吗？不会 —— 引理 6 说两个代表元的 $k$ 一奇一偶，而第 2 步只放行与 $c$ 同奇偶的那个，所以**在"恰好 $c$ 次"口径下，`sort` 后的 `ans` 天然无重复**。（仍保留去重那两行代码，理由见 §2.6：一旦口径改成"至多 $c$ 次"或有人改用"8 状态表"直接生成候选，重复行就会出现；防御性写法的代价是 $O(1)$。）

**"排序键"与"相等"的口径（本题版的边界口径）**

- **相等判定（是否重复）= 长度 $n$ 的整串逐字符相等。** 不能只看前 6 位（虽然引理 3 说明前 6 位相同则整串相同，但反过来要成立必须依赖 $n\ge 6$；直接用整串比较则对任何 $n$ 都成立，不需要额外引理）。
- **排序键 = 整串字典序**，题面要求的是"看作二进制数从小到大"。二者是否等价必须证明，见引理 9（§2.6）。

### 2.5 归约：无约束上界随 $c$ 的分类表

**把 8 个状态连同"两个代表元"完整列出**（$n=10$，末态串按 $i=1..10$ 位；两个代表元按引理 5 必相差 $(1,1,1,0)$，$k,k'$ 就是各自数 1 的个数，可直接手核）：

| # | 翻转集合 | 代表元 $x$（$k$） | 代表元 $x'$（$k'$） | $n=10$ 末态 |
|---|---|---|---|---|
| 1 | $\varnothing$ | $(0,0,0,0)$，$k=0$ | $(1,1,1,0)$，$k=3$ | `1111111111` |
| 2 | 全部 | $(1,0,0,0)$，$1$ | $(0,1,1,0)$，$2$ | `0000000000` |
| 3 | 奇数号 | $(0,1,0,0)$，$1$ | $(1,0,1,0)$，$2$ | `0101010101` |
| 4 | 偶数号 | $(0,0,1,0)$，$1$ | $(1,1,0,0)$，$2$ | `1010101010` |
| 5 | $\{1,4,7,10\}$ | $(0,0,0,1)$，$1$ | $(1,1,1,1)$，$4$ | `0110110110` |
| 6 | 全部 $\Delta\{1,4,7,10\}$ | $(1,0,0,1)$，$2$ | $(0,1,1,1)$，$3$ | `1001001001` |
| 7 | 奇数号 $\Delta\{1,4,7,10\}$ | $(0,1,0,1)$，$2$ | $(1,0,1,1)$，$3$ | `1100011100` |
| 8 | 偶数号 $\Delta\{1,4,7,10\}$ | $(0,0,1,1)$，$2$ | $(1,1,0,1)$，$3$ | `0011100011` |

（$\Delta$ = 对称差，即两次翻转叠加后再消掉重合部分。例：#7 中 1 与 7 同时被"奇数号"和 $\{1,4,7,10\}$ 翻到，互相抵消 ⇒ 保持亮；翻转集实际是 $\{3,4,5,9,10\}$，对应串 `1100011100` ✓。）

**引理 8（无约束时可达状态数随 $c$ 的分类）**：$c=0,1,2,\ge3$ 分别给出 $1,4,7,8$ 个候选状态。

**证明**：由引理 6，每个状态的两个代表元 $k$ 一奇一偶，故对固定 $c$ 恰有一个代表元满足"$k\equiv c\pmod2$"；该状态可达 $\iff$ 这个"奇偶匹配代表元"的 $k\le c$。把上表按 $c$ 的奇偶分列：

- **$c$ 为奇**：匹配代表元为 #1$\to3$、#2$\to1$、#3$\to1$、#4$\to1$、#5$\to1$、#6$\to3$、#7$\to3$、#8$\to3$。
 $c=1$：只有 $k\le1$ 的 #2、#3、#4、#5 通过 ⇒ **4 个**。$c\ge3$（奇）：全部 $k\le3$ ⇒ **8 个**。
- **$c$ 为偶**：匹配代表元为 #1$\to0$、#2$\to2$、#3$\to2$、#4$\to2$、#5$\to4$、#6$\to2$、#7$\to2$、#8$\to2$。
 $c=0$：只有 #1（$k=0$）⇒ **1 个**。$c=2$：$k\le2$ 的是 #1、#2、#3、#4、#6、#7、#8 ⇒ **7 个**（缺 #5）。$c\ge4$（偶）：全部 $\le4$ ⇒ **8 个**。

合并：$1,4,7,8,8,8,\dots$，对 $c\ge 3$ 恒为 8。$\blacksquare$

> 检验引理 6 的威力：$c=3$ 与 $c=4$ 都能给出全部 8 个状态，但**给出每个状态所用的代表元完全不同**（$c=3$ 用 #1 的 $k=3$，$c=4$ 用 #1 的 $k=0$）。这正是"最小按压数 + 奇偶"式贪心注定失败的原因：状态集合相同，路径却不同。
> 有了这张表，就能秒判一些边界：$c=0$ 时若输入里有任何"必须灭"的灯 ⇒ 直接 `IMPOSSIBLE`；$c=1$ 时输出至多 4 行。

### 2.6 溢出防护与两处口径

**溢出防护 ①（本题真正的"大数"陷阱：别把行转成整数再排序）**

题面说"这些行必须从小到大排列（看作是二进制数）"。$n$ 最大 100，于是"二进制数"是 **100 位**，`long long` 只有 63 位可用正数值，`unsigned long long` 也才 64 位 —— **绝对不要把行转成整数再排**。正确做法：直接对长度相同的字符串做字典序排序，理由由下一条引理保证。

**引理 9（定长二进制串：字典序 = 数值序）**

设 $a,b$ 是两个长度同为 $n$ 的 0/1 串，$a\ne b$，对应数值 $A(a)=\sum_{i=1}^{n}a_i 2^{\,n-i}$（$a_1$ 是最高位）。则

$$A(a)<A(b)\iff a\ \text{字典序小于}\ b .$$

**证明**：设 $j$ 是第一个使 $a_j\ne b_j$ 的位置（因 $a\ne b$ 故存在）。对所有 $i<j$ 有 $a_i=b_i$，于是

$$A(a)-A(b)=\sum_{i=j}^{n}(a_i-b_i)2^{\,n-i}=(a_j-b_j)2^{\,n-j}+\sum_{i=j+1}^{n}(a_i-b_i)2^{\,n-i}.$$

**关键是把尾巴夹住**：$a_i-b_i\in\{-1,0,1\}$，故

$$\Big|\sum_{i=j+1}^{n}(a_i-b_i)2^{\,n-i}\Big|\le\sum_{i=j+1}^{n}2^{\,n-i}=2^{\,n-j-1}+2^{\,n-j-2}+\cdots+2^{0}=2^{\,n-j}-1<2^{\,n-j}.$$

即**首位差异的权重 $2^{\,n-j}$ 严格大于后面所有位的可能补偿 $2^{\,n-j}-1$**（等比数列求和，这正是"二进制没有相等的部分和"的体现）。
- 若 $a_j=0,b_j=1$：$A(a)-A(b)\le -2^{\,n-j}+(2^{\,n-j}-1)=-1<0$，即 $A(a)<A(b)$；
- 若 $a_j=1,b_j=0$：$A(a)-A(b)\ge 2^{\,n-j}-(2^{\,n-j}-1)=1>0$，即 $A(a)>A(b)$。
而字典序的定义正是"第一个不同位置上 $0<1$"，两种序的判别完全同步。$\blacksquare$

**口径被破坏时结论就不成立**（长度必须相等）：取 $a=$`100`（数值 4）、$b=$`11`（数值 3），字典序上 `100` < `11`（第 2 位 `0`<`1`），数值上却是 $4>3$。所以**每行必须老老实实输出 $n$ 个字符**，不能省前导 `0`、也不能只输出前 6 个字符，否则排序键与题面口径都对不上。

**溢出防护 ②（奇偶判断里的负数）**：`if(k>c||((c-k)&1))` 中，`||` 的短路保证只有 $k\le c$ 时才计算 `c-k`，于是被操作的数**非负**，`&1` 的结果就是通常意义的奇偶；若不写 $k>c$ 而直接判 `((c-k)&1)`，$c-k$ 为负时依赖补码语义（C++20 起标准才明确），是没必要踩的坑。$c\le10^4$、$k\le4$，全程 `int` 足够，无需 `i64`。

**下标口径（最容易写错的一处）**：按钮 4 作用的是 $3k+1\ (k\ge0)$，题面自己给了例子"1,4,7,10"。
- 于是判定式是 `i%3==1`（$1\%3=1$、$4\%3=1$、$7\%3=1$、$10\%3=1$ ✓）。
- **不是** `i%3==0`（那给出 $3,6,9$）；**也不是** `i%4==1`（那给出 $1,5,9$ —— 这是把"每隔三盏"和"模 4 余 1"混了的经典错法）。
- 自查手段：用 $n=10,c=1$ 跑一遍，若把按钮 4 写成 `i%4==1`，得到的串是 `0111011101`（灭在 $1,5,9$），与题面样例解释"$1,4,7,10$ 灭"不符，立刻能发现。
- 本题**刻意保持 1-based**（`req[1..n]`、循环 $i=1..n$），因为奇偶与模 3 条件都是按 1-based 叙述的；若改成 0-based，两个条件要重写成 `i%2==0`（奇数号）与 `(i+1)%3==1`，属于纯增风险的机械转换，不如不改。

**读入口径**：第三、四行各自以 `-1` 结束，用"无限循环 + 遇 `-1` 退出"最稳；`cin>>` 自动跨行，不需要 `getline`。题面保证同一盏灯不出现两次，故不会出现 `req[i]` 被先后写成 $1$ 和 $-1$ 的冲突。

## 3. 模式总结（Pattern Summary）

按真实思考顺序排列，一条一个技术点：

- **translate mechanic to algebra（把机制翻成 $\mathbb{F}_2$ 加法）** —— 按压 = 异或固定向量；对合 + 交换 ⇒ 末态只由 4 位奇偶向量决定，$4^c$ 的序列空间塌成 16 个候选。
- **read the bound as a hint（把 $c\le10^4$ 读成提示）** —— $c$ 远大于按钮数，说明它只以"大小 + 奇偶"进入判定；据此得到引理 2 的可达性充要条件（$k\le c$ 且 $c-k$ 偶）。
- **consider easier version（压缩周期）** —— 灯的状态只依赖 $(i\bmod2,i\bmod3)$，即周期 6 ⇒ 一行 100 个字符其实由前 6 位重复而成，"候选只有常数个"得到第二重保证。
- **reduce to easier problem（消掉冗余按钮）** —— $b_1=b_2\oplus b_3$ ⇒ 真实状态只有 $2^3=8$ 个，每个状态被 2 个奇偶向量取到（相差 $(1,1,1,0)$）。
- **dissect the failed shortcut（拆"最小按压数 + 奇偶"）** —— 奇偶约束活在"元素"上而不是"等价类"上；两代表元的 $k$ 之和为 $3$ 或 $5$（必为一奇一偶），取 $\min$ 必然抹掉正确的那一半（反例 $c=3$ 的全亮、$c=2$ 少 3 行）。
- **classic problem solution：tiny exhaustive enumeration** —— 不搜序列、不搜状态图，直接枚举全部 16 个奇偶向量，逐个模拟 + 逐个查约束；完备性由引理 7 双向构造证明。
- **defer reconstruction（先收集串，最后统一排序去重）** —— 判定用"元素级"的精确条件，重复与排序留到 `ans` 上一次性处理，避免在枚举阶段做容易出错的归约。
- **sort-key discipline（排序键口径）** —— 定长 0/1 串字典序 = 二进制数值序（引理 9，靠"首位权重 $>$ 尾部全部可能补偿"）；因此按字符串 `sort` 即可，且**绝不能**把 100 位串转成整数。
- **equality-key discipline（重复判定口径）** —— 用整串相等，不用"前 6 位相等"，从而不依赖 $n\ge 6$ 这一额外前提。
- **impossible-as-empty-set** —— 无解不是一个特判分支，而是"收集结果为空"的自然输出。

## 4. 真实解法

**符号表（代码里每个量存什么、初值、记忆口诀）**

| 符号 | 类型/尺寸 | 存什么 | 初值 | 一行口诀 |
|---|---|---|---|---|
| `n` | `int` | 灯数，$10\le n\le 100$ | 读入 | 行长就是 $n$ |
| `c` | `int` | 计数器读数＝**恰好**按压次数 | 读入 | 只看"够不够 + 奇偶" |
| `req[i]` | `int[mxn]`，`mxn=105` | 灯 $i$（**1-based**）的约束：`1` 必须亮，`-1` 必须灭，`0` 无约束 | 全局数组自动为 `0` | "要 1、要 -1、随便 0" |
| `m` | `int`（循环变量，$0..15$） | 奇偶向量 $x$ 的压缩形式：`m>>(j-1)&1 == x_j` | — | 16 个候选的编号 |
| `x1..x4` | `int` | 四个按钮各自的按压奇偶位 | 由 `m` 拆出 | $x_j=1$ ⇒ 按钮 $j$ 净翻转一次 |
| `k` | `int` | $x_1+x_2+x_3+x_4=\operatorname{popcount}(m)$ | 由 `m` 算 | 这个奇偶类的**最小**按压次数 |
| `lit(...,i)` | 函数，返回 `int` | $1\oplus f_x(i)$：第 $i$ 盏灯的末态位 | — | "初始全亮，翻奇数次就灭" |
| `f` | 函数内 `int` | 累计翻转次数模 2（$f_x(i)$） | `x1` | 先全按钮 1，再按奇偶/模 3 叠加 |
| `s` | `string` | 当前候选的完整末态串（长度 $n$） | 空串逐位 `+=` | 弃用时可半途废弃 |
| `ok` | `bool` | 当前候选是否仍满足全部约束 | `true` | 一旦 `false` 立刻 `break` |
| `ans` | `vector<string>` | 所有通过检查的末态串 | 空 | 先收集，最后统一排序+去重 |

**算法步骤（编号，与 §5 代码一一对应）**

1. 读 $n$、$c$。
2. 循环读第三行整数直到 $-1$，把 `req[x]` 置 `1`（必须亮）。
3. 循环读第四行整数直到 $-1$，把 `req[x]` 置 `-1`（必须灭）。
4. `for m=0..15`：拆出 `x1..x4`，算 `k`。
5. **可达门**（引理 2）：若 `k>c` 或 `(c-k)` 为奇数，`continue`。
6. **模拟 + 约束门**：`for i=1..n` 算 `v=lit(x1,x2,x3,x4,i)`；若 `req[i]==1 && v!=1` 或 `req[i]==-1 && v!=0`，置 `ok=false` 并 `break`；否则 `s+=(char)('0'+v)`。
7. `ok` 为真则 `ans.push_back(s)`。
8. 枚举结束后，若 `ans` 为空，输出 `IMPOSSIBLE\n` 并返回。
9. 否则 `sort(ans)`（引理 9：字典序即题面要求的二进制数值序），再**相邻比较去重**后逐行输出（口径见 §2.4/§2.6）。

**复杂度**：枚举 $16$ 个候选 × 每候选 $O(n)$ 模拟 $=O(16n)$，$n\le100$ 时约 $1.6\times10^3$ 次位运算；排序至多 $16$ 个长度 $100$ 的串，$O(16\log16\cdot n)$；空间 `req[105]` + 至多 16 个串。运行时间在任何 OJ 上都是"读入主导"，本题不卡复杂度。

**验证状态**（**按禁令未编译、未运行任何代码**；下列全部为逐位手算）

- **V1 反推主样例** $n=10,c=1$，必须亮 $=\varnothing$，必须灭 $=\{7\}$。
  可达门放行 $k=1$ 的 4 个候选：
  `m=1`(1,0,0,0)→`0000000000`，$v_7=0$ ✓ 收；
  `m=2`(0,1,0,0)→`0101010101`（奇数号灭），$v_7=0$ ✓ 收；
  `m=4`(0,0,1,0)→`1010101010`（偶数号灭），$7$ 为奇数号 ⇒ $v_7=1$ ✗ 弃；

  排序后输出 3 行：`0000000000` / `0101010101` / `0110110110`。

- **V3 贪心陷阱复现** $n=10,c=3$，无约束。放行 $k\in\{1,3\}$ 共 8 个候选：
  $k=1$：`m=1,2,4,8` → `0000000000`,`0101010101`,`1010101010`,`0110110110`；
  $k=3$：`m=7`(1,1,1,0)：$f(i)=1\oplus1=0$ ⇒ `1111111111`；`m=11`(1,1,0,1) ⇒ `0011100011`；`m=13`(1,0,1,1) ⇒ `1100011100`；`m=14`(0,1,1,1) ⇒ `1001001001`。
  排序输出 8 行：`0000000000`,`0011100011`,`0101010101`,`0110110110`,`1001001001`,`1010101010`,`1100011100`,`1111111111`。
  对照引理 8"$c\ge3$ 恒 8 个"✓；且**含 `1111111111`**，正是 §2.3 反例 A 中"最小按压数 + 奇偶"会漏掉的那一行 ✓；8 个候选产出 8 个互不相同的串，印证"恰好口径下天然无重复"。
- **V4 混合约束 + 大 $c$** $n=10,c=4$，必须亮 $=\{2\}$，必须灭 $=\{1\}$。放行 $k\in\{0,2,4\}$ 共 8 个候选，逐个查 $(v_1,v_2)$：
  `m=0`(0,0,0,0)→`1111111111`，$(1,1)$ ✗；`m=3`(1,1,0,0)$=b_1\oplus b_2=b_3$→`1010101010`，$(1,0)$ ✗；`m=5`(1,0,1,0)$=b_1\oplus b_3=b_2$→`0101010101`，$(0,1)$ ✓ 收；`m=6`(0,1,1,0)$=b_2\oplus b_3=b_1$→`0000000000`，$(0,0)$ ✗；`m=9`(1,0,0,1)$=b_1\oplus b_4$→`1001001001`，$(1,0)$ ✗；`m=10`(0,1,0,1)$=b_2\oplus b_4$→`1100011100`，$(1,1)$ ✗；`m=12`(0,0,1,1)$=b_3\oplus b_4$→`0011100011`，$(0,0)$ ✗；`m=15`(1,1,1,1)$=b_4$（因 $b_1\oplus b_2\oplus b_3=0$）→`0110110110`，$(0,1)$ ✓ 收。
  输出 2 行：`0101010101` / `0110110110` ✓（$(v_1,v_2)$ 与 §2.5 的 8 状态表逐位吻合；注意 $c=4$ 时 `0110110110` 是靠 $k=4$ 的代表元进来的，若按"最小按压数 $1$ 且 $4-1$ 为奇"就会把它误删 —— 与 §2.3 反例 A 同型的漏行）。
- **V5 周期外推（$n>10$）+ 双候选幸存** $n=12,c=2$，必须亮 $=\{3,9\}$，必须灭 $=\{6\}$。放行 $k\in\{0,2\}$ 共 7 个候选：
  `m=0`→`111111111111`，$v_6=1$ ✗；`m=3`($b_3$)→`101010101010`，$v_3=1,v_9=1,v_6=0$ ✓ 收；`m=5`($b_2$)→`010101010101`，$v_3=0$ ✗；`m=6`($b_1$)→`000000000000`，$v_3=0$ ✗；`m=9`→`100100100100`，$v_3=0$ ✗；`m=10`→`110001110001`，$v_3=0$ ✗；`m=12`→`001110001110`，$v_3=1,v_9=1,v_6=0$ ✓ 收。
  输出 2 行：`001110001110` / `101010101010`。
  交叉检查：两串都满足引理 3 的"第 $i$ 位 = 第 $i+6$ 位"（`001110|001110`、`101010|101010`）✓；与 V1 中 $n=10$ 的同状态前缀一致（`0011100011` 是 `001110001110` 的前 10 位）✓。

**未发现矛盾的其余检查**：引理 8 的 $1,4,7,8$ 计数由 V2/V3/V4 独立覆盖到 $c=0,3,4$；$c=1$ 由 V1 覆盖；$c=2$ 的"7 个状态"由 §2.3 反例 B 的整表覆盖。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{105};   // n<=100，+5 松弛

int n,c;
int req[mxn];             // req[i]: 0 无约束, 1 必须亮, -1 必须灭
vector<string>ans;

inline int bit(int x,int b){return x>>b&1;}

// 奇偶向量 (x1,x2,x3,x4) 下第 i 盏灯的末态；初始全亮，故为 1^flip
int lit(int x1,int x2,int x3,int x4,int i)
{
	int f=x1;
	if(i&1)
		f^=x2;              // 按钮 2：奇数号 1,3,5,...
	else
		f^=x3;              // 按钮 3：偶数号 2,4,6,...
	if(i%3==1)
		f^=x4;              // 按钮 4：3k+1 = 1,4,7,10,... 即 i≡1 (mod 3)
	return 1^f;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>c;
	for(int x;;)
	{
		cin>>x;
		if(x==-1)
			break;
		req[x]=1;
	}
	for(int x;;)
	{
		cin>>x;
		if(x==-1)
			break;
		req[x]=-1;
	}

	for(int m=0;m<16;++m)
	{
		int x1=bit(m,0),x2=bit(m,1),x3=bit(m,2),x4=bit(m,3);
		int k=x1+x2+x3+x4;                        // 汉明重量 = 该奇偶类的最小按压次数
		if(k>c||((c-k)&1))
			continue;                             // 引理 2：恰好 c 次的充要条件
		string s;
		bool ok=true;
		for(int i=1;i<=n;++i)
		{
			int v=lit(x1,x2,x3,x4,i);
			if((req[i]==1&&v!=1)||(req[i]==-1&&v!=0))
			{
				ok=false;
				break;
			}
			s+=(char)('0'+v);
		}
		if(ok)
			ans.push_back(s);
	}

	if(ans.empty())
	{
		cout<<"IMPOSSIBLE\n";
		return 0;
	}
	sort(ans.begin(),ans.end());                  // 定长串字典序 = 二进制数值序（引理 9）
	for(int i=0;i<(int)ans.size();++i)
		if(i==0||ans[i]!=ans[i-1])
			cout<<ans[i]<<'\n';                   // 去重：见 §2.6 的口径讨论
	return 0;
}
```

**代码与风格规范的对照说明（写代码时的取舍）**

| 规范要求 | 本代码的落点 |
|---|---|
| `#include<bits/stdc++.h>` 单一头 | 首行 |
| `using i64=long long;` 按需 | 保留别名；本题全程 `int`，`i64` 未使用（$c\le10^4$，见 §2.6 溢出防护 ②） |
| 全局数组 + `constexpr int mxn{...}`（+5 松弛） | `constexpr int mxn{105}`、`int req[mxn]`、`vector<string>ans` 全在全局 |
| `cin.tie(nullptr); cout.tie(nullptr); ios::sync_with_stdio(false);` 顺序 | `main` 开头三行，顺序照规范 |
| 换行只用 `'\n'` | 两处输出均是 `'\n'`，无 `endl` |
| 运算符两侧不加空格、缩进用 Tab | 全文照做 |
| 输出精度 | 本题**无浮点输出**，不需要 `fixed/setprecision`；输出为定长 0/1 串，逐字符精确 |
| 内部 0-based | **本题例外，刻意 1-based**：约束的下标口径（奇偶、$\bmod 3$）在题面里就是 1-based 叙述的，转 0-based 需把条件改成 `i%2==0` 与 `(i+1)%3==1`，纯增出错风险（§2.6 下标口径） |
| 一行小函数写单行 | `inline int bit(int x,int b){return x>>b&1;}` |

**等价可选写法（更快但更啰嗦，未采用）**：先用引理 3 只算前 6 位得到 6 位模板 $t[6]$，再 $s_i=t[(i-1)\%6]$ 拼出长度 $n$ 的串。它把每候选的 $O(n)$ 降成 $O(1)+O(n)$ 拼接，$n\le100$ 时毫无收益，且必须额外论证"$n\ge 6$ 时前 6 位相同 $\Leftrightarrow$ 整串相同"，故不进主线代码。
