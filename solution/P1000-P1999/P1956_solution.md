# P1956 Sum

## 1. 重新读题

### 1.1 问题重述（人话版）

给出长度为 $n$ 的正整数数列 $a_1,\dots,a_n$，以及正整数 $k,p$。对每个非空连续子段 $[i,j]$，记它的和为 $S_{i,j}=a_i+\dots+a_j$。在所有满足
$$
S_{i,j}\bmod p\ \ge\ k
$$
的子段中，求 $S_{i,j}\bmod p$ 的**最小值**。题面保证这样的子段存在。

> 注：题面把 $S_{i,j}$ 写成 $\sum_{k=i}^{j}a_k$，这里的 $k$ 只是求和哑变量，和输入的 $k$ 重名；不影响题意。

### 1.2 关键约束与规模暗示

- $1\le n\le10^5$，$1\le k,p,a_i\le10^{18}$。
- $n=10^5$ 排除 $O(n^2)$ 枚举所有子段（$10^{10}$），必须做到 $O(n\log n)$ 或 $O(n)$。
- $a_i,p$ 都到 $10^{18}$，前缀和最大可达 $10^{23}$，**会爆 `long long`**（甚至 `unsigned long long`）。这提示：我们只应该维护「前缀和模 $p$ 的余数」，而不是真前缀和。
- 题目只问「模 $p$ 后的余数」，值域 $[0,p)$ 却高达 $10^{18}$，不能开桶，只能用有序结构 / 平衡树。

---

## 2. 思维链（Chain-of-thought）

### 2.1 子段和转成前缀和之差

设
$$
P_0=0,\qquad P_i=a_1+\dots+a_i .
$$
则
$$
S_{i,j}=P_j-P_{i-1}.
$$
令 $R_i=P_i\bmod p\in[0,p)$。模运算对减法保持线性：
$$
S_{i,j}\bmod p=\bigl((P_j\bmod p)-(P_{i-1}\bmod p)\bigr)\bmod p=(R_j-R_{i-1})\bmod p .
$$
所以**真前缀和完全不需要算出来**，只保留 $R_0,R_1,\dots,R_n$ 就够了（这同时避免了 $10^{23}$ 溢出）。

问题变成：

> 对每个 $r=1,\dots,n$，在集合 $T=\{R_0,R_1,\dots,R_{r-1}\}$ 中选一个 $x$，令 $y=(R_r-x)\bmod p$，要求 $y\ge k$，求最小的 $y$。

这里的 $x=R_{l-1}$ 对应子段 $[l,r]$，用 $l-1<r$ 保证子段非空。

### 2.2 先看暴力，找瓶颈

暴力：枚举 $r$，再枚举 $r$ 个 $x$，$O(n^2)$。瓶颈是「对每个 $r$ 都要在一堆数里找一个最优的 $x$」。

把 $y=(R_r-x)\bmod p$ 按 $x$ 与 $R_r$ 的大小关系拆开：

- **不跨越** $x\le R_r$：$y=R_r-x$；
- **跨越** $x>R_r$：$y=R_r-x+p$。

两种情况下 $y$ 都是 $x$ 的**严格递减函数**。所以要最小化 $y$，就是要在每种情况里**把 $x$ 取到尽可能大**，同时满足 $y\ge k$。

### 2.3 把「$y\ge k$」翻译成对 $x$ 的上界

**情形 A（$x\le R_r$）**：
$$
y=R_r-x\ge k\iff x\le R_r-k .
$$
于是可行 $x$ 是集合中 $\le R_r-k$ 的部分；其中最大的那个给出最小的 $y$。

**情形 B（$x>R_r$）**：
$$
y=R_r-x+p\ge k\iff x\le R_r+p-k .
$$
于是可行 $x$ 是集合中满足 $R_r<x\le \min(p-1,\ R_r+p-k)$ 的部分；同样取最大的 $x$（$x$ 越大 $y$ 越小）。注意 $x$ 本身是余数，天然 $\le p-1$，所以上界写成 $\min(p-1,R_r+p-k)$。

**引理 1（两种情形各自的最优选择）**
在情形 A 中，若 $M_A=\max\{x\in T: x\le R_r-k\}$ 存在，则它是情形 A 中使 $y$ 最小的 $x$；在情形 B 中，若 $M_B=\max\{x\in T: R_r<x\le\min(p-1,R_r+p-k)\}$ 存在，则它是情形 B 中使 $y$ 最小的 $x$。

**证明**：在情形 A 上，$y(x)=R_r-x$ 严格递减，可行域 $\{x\le R_r-k\}$ 是一个「向下封闭」的集合；若 $x_1<x_2$ 且 $x_2$ 可行，则 $x_1$ 也可行且 $y(x_1)>y(x_2)$。因此最小值只能在可行域的最大元素处取得。情形 B 同理，$y(x)=R_r+p-x$ 也严格递减，而可行域 $\{R_r<x\le U\}$ 同样是向下封闭的（对 $x$ 而言），故最优在最大可行元素处。$\square$

**引理 2（合并两种情形得到全局最优）**
全局最优值等于
$$
\min\Bigl(\ \min_{x\le R_r,\ x\in T}y(x),\ \min_{x>R_r,\ x\in T}y(x)\ \Bigr),
$$
即两种情形的最优值取小；且只需检查引理 1 给出的两个候选 $M_A,M_B$。

**证明**：任意 $x\in T$ 必属于且仅属于 $x\le R_r$ 或 $x>R_r$ 之一，所以全局可行域是两情形可行域的不交并，全局最小值等于两边最小值取小。引理 1 说明每边的最小值只需看该边的最大可行元素。$\square$

### 2.4 数据结构：有序集合 + 前驱查询

需要支持：插入一个数、查询「$\le$ 某个上界 $U$ 的最大元素」。这正是 `std::set` 的 `upper_bound(U)` 再左移一格（`--it`）。

流程：

1. `set` 初始插入 $R_0=0$。
2. `r` 从 $1$ 到 $n$：
   1. 更新 $R_r=(R_{r-1}+a_r\bmod p)\bmod p$；
   2. 在**当前的** `set`（只含 $R_0,\dots,R_{r-1}$）里按 2.3 查两个候选，更新答案；
   3. 把 $R_r$ 插入 `set`。
3. 输出答案。

先查后插保证 $l-1\le r-1<r$，子段非空。

### 2.5 边界与坑

- **`k ≥ p`**：任何余数 $y\in[0,p-1]$ 都不满足 $y\ge k$，与「保证存在」矛盾，所以合法输入必有 $k<p$。代码里对情形 B 加了 `k<p` 的保护，避免 $R_r+p-k<R_r$ 造成误判。
- **`x = R_r`**：$y=0$，只有 $k=0$ 才可能可行；本题 $k\ge1$，所以它在情形 A 的查询条件 $x\le R_r-k$ 下自然被排除（$k\ge1\Rightarrow R_r-k<R_r$）。
- **答案初值**：用远大于 $p$ 的哨兵（如 `1145141919810LL`）。注意 $p$ 可到 $10^{18}$，哨兵必须 $\ge p$，`1e9` 不够。
- **溢出**：只存余数，$R_{r-1}<p\le10^{18}$，$a_r\bmod p\le10^{18}$，相加 $<2\times10^{18}<9.22\times10^{18}$，`long long` 安全；$R_r+p-k<2\times10^{18}$ 同样安全。全程不需要 `__int128`。
- **正数条件用不到**：推导只用到「子段和 = 前缀差」和模运算，$a_i\ge1$ 并非必要。题目给正数只是方便表述。
- 集合中可以有重复余数：我们只关心「是否存在某个 $x$」，重复无影响，`set` 足够（不需要 `multiset`）。

### 2.6 一个小例子

$p=10,k=3,a=[7,4]$。

- $R_0=0$，集合 $\{0\}$。
- $r=1$：$R_1=7$。情形 A：$U=R_1-k=4$，前驱是 $0$，$y=7$。情形 B：$U=\min(9,7+10-3=14)=9$，前驱 $0$ 不 $>7$，无候选。答案 $7$。插入 $7$，集合 $\{0,7\}$。
- $r=2$：$R_2=(7+4)\bmod10=1$。情形 A：$U=-2<0$，无。情形 B：$U=\min(9,1+10-3=8)=8$，前驱为 $7>1$，$y=1+10-7=4$。答案 $\min(7,4)=4$。插入 $1$。

输出 $4$。实际子段：$[7]$ 余 $7$，$[7,4]$ 余 $1$，$[4]$ 余 $4$；$\ge3$ 的最小余数是 $4$，正确。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 子段和 $=$ 前缀和之差，只需维护前缀和模 $p$ 的余数。
- **reduce to easier problem** — 固定右端点 $r$，问题变成在已出现余数集合里找一个 $x$ 使 $(R_r-x)\bmod p$ 最小且 $\ge k$。
- **discuss by category** — 按 $x\le R_r$ 与 $x>R_r$ 分两类（是否跨过模数回绕），两类都化为「取最大的可行 $x$」。
- **classic problem solution** — `set` + `upper_bound` 前驱查询，$O(n\log n)$。
- **overflow avoidance** — 不存真前缀和，只存余数，规避 $10^{23}$。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 数列长度 | 读入 | $\le10^5$ |
| `k` | `i64` | 余数下界 | 读入 | $\ge1$ |
| `p` | `i64` | 模数 | 读入 | $\le10^{18}$ |
| `a[i]` | `i64 [mxn]` | 原数列 | 读入 | — |
| `r` | `i64` | 当前前缀和模 $p$（即 $R_i$） | $0$ | residue |
| `S` | `set<i64>` | 已出现的所有 $R_0,\dots,R_{r-1}$ | `{0}` | set |
| `ans` | `i64` | 当前最优余数 | `1145141919810LL` | answer |
| `lim` | `i64` | 情形 A 的查询上界 $R_r-k$ | 每次算 | limit |
| `hi` | `i64` | 情形 B 的查询上界 $\min(p-1,R_r+p-k)$ | 每次算 | high |

### 4.2 算法步骤

1. 读入 $n,k,p$ 和 $a_1..a_n$。
2. `S.insert(0)`，`r=0`，`ans=1145141919810LL`。
3. 对 $i=0..n-1$（0-based）：
   1. `r=(r+a[i]%p)%p`，得到 $R_{i+1}$。
   2. **情形 A**：若 `lim=r-k>=0`，在 `S` 中 `upper_bound(lim)` 并左移一格得到 $x$（若存在），用 `y=r-x` 更新 `ans`。
   3. **情形 B**：若 `k<p`，令 `hi=min(p-1,r+p-k)`，在 `S` 中 `upper_bound(hi)` 左移一格得到 $x$；若 $x>r$，用 `y=r+p-x` 更新 `ans`。
   4. `S.insert(r)`。
4. 输出 `ans`。

### 4.3 复杂度分析

- 每次迭代做两次 `upper_bound` 加一次 `insert`，均为 $O(\log n)$。
- 时间 $O(n\log n)$；空间 $O(n)$。
- $n=10^5$ 时约 $3\times10^5$ 次平衡树操作，轻松通过。

## 5. 示例代码

```cpp
//
// 题目：P1956 Sum
// https://www.luogu.com.cn/problem/P1956
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};

int n;
i64 k,p,a[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>k>>p;
	for(int i=0;i<n;++i)
		cin>>a[i];

	set<i64>S;
	S.insert(0);
	i64 r{0},ans{1145141919810LL};
	for(int i=0;i<n;++i)
	{
		r=(r+a[i]%p)%p;
		//case1: x<=r, y=r-x
		i64 lim=r-k;
		if(lim>=0)
		{
			auto it=S.upper_bound(lim);
			if(it!=S.begin())
			{
				--it;
				i64 y=r-*it;
				if(y>=k)
					ans=min(ans,y);
			}
		}
		//case2: x>r, y=r+p-x
		if(k<p)
		{
			i64 hi=min(p-1,r+p-k);
			auto it=S.upper_bound(hi);
			if(it!=S.begin())
			{
				--it;
				if(*it>r)
				{
					i64 y=r+p-*it;
					if(y>=k)
						ans=min(ans,y);
				}
			}
		}
		S.insert(r);
	}
	cout<<ans<<'\n';
	return 0;
}
```
