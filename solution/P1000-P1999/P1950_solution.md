# P1950 长方形

## 1. 重新读题

### 1.1 问题重述（人话版）

有一张 $n\times m$ 的格子纸，每格是 `.`（没画过）或 `*`（画过）。只能沿着格子边剪，剪出的长方形**不能包含任何 `*`**。长方形的大小没有限制（$1\times1$ 也算）。问有多少种不同的剪法，也就是有多少个**全 `.` 子矩形**。

### 1.2 关键约束与规模暗示

- $n,m\le1000$。
- 直接的「枚举四条边界」是 $O(n^2m^2)=10^{12}$；「枚举上下边界 + 逐列处理」是 $O(n^2m)=10^9$。都不行。
- 只有 $O(nm)$（或 $O(nm\log m)$）能过，$10^6$ 量级。
- 答案量级：$1000\times1000$ 全 `.` 时的子矩形数为
  $$
  \binom{1001}{2}^2\approx 2.5\times10^{11}>2^{31},
  $$
  必须用 64 位整数。

---

## 2. 思维链（Chain-of-thought）

### 2.1 第一步：暴力枚举，看能不能砍掉一维

最直接：枚举上边界、下边界、左边界、右边界，检查内部是否全 `.`。$O(n^2m^2)$，$10^{12}$，不行。

优化一点：枚举上、下边界 $(t,b)$，那么每一列在 $[t,b]$ 内是否全 `.` 是已知的。把「整列都 `.`」的列标成 1，否则标成 0，问题变成「数有多少个全 1 的连续区间」，一遍扫描即可（遇到 0 就把连续段结算）。复杂度

$$
O\left(n^2m\right)=10^9,
$$

仍然太慢（$n=1000$ 时 $10^9$ 次操作，常数虽小也危险）。

瓶颈在「同时枚举上下两条边」。能不能只枚举一条边？

### 2.2 第二步：只固定底边，把「上边界」变成「高度」

固定底边为第 $i$ 行。对每个列 $j$ 定义

$$
h_j=\text{以 }(i,j)\text{ 结尾、向上连续 \texttt{.} 的格子数},
$$

即 $h_j=\max\{k:(i-k+1..i,j)\text{ 全为 \texttt{.}}\}$；若第 $i$ 行第 $j$ 列本身是 `*`，则 $h_j=0$。

**引理 1（矩形计数公式）**：固定底边 $i$、右边界 $j$、左边界 $l\le j$，则以这三条边为底、右、左的合法矩形个数恰好是

$$
\min_{l\le c\le j}h_c .
$$

**证明**：

- 设上边界为第 $t$ 行（$t\le i$），矩形高度为 $H=i-t+1$。矩形合法当且仅当对每个列 $c\in[l,j]$，格子 $(t..i,c)$ 全为 `.`。而 $(t..i,c)$ 全为 `.` 当且仅当 $h_c\ge H$（因为 $h_c$ 是从第 $i$ 行向上连续 `.` 的长度）。
- 所以合法当且仅当 $H\le\min_{c\in[l,j]}h_c$。高度 $H$ 可以取 $1,2,\dots,\min h$，共 $\min h$ 个取值，每个取值对应唯一的上边界 $t=i-H+1$，也就对应唯一一个矩形。
- 不同的 $H$ 给出不同上边界，故是 $\min h$ 个互不相同的矩形。$\square$

于是固定底边 $i$ 后，答案为

$$
\sum_{j=1}^{m}\sum_{l=1}^{j}\min_{l\le c\le j}h_c .
$$

这一步把「上边界」这一维消掉了：不再枚举 $t$，而是让 $h$ 自动统计所有可能的 $t$。

### 2.3 第三步：如何 $O(m)$ 求出这个双重和

定义

$$
\mathrm{cur}_j=\sum_{l=1}^{j}\min_{l\le c\le j}h_c ,
$$

它表示「以第 $j$ 列为右边界」的矩形数（底边固定）。答案就是 $\sum_j\mathrm{cur}_j$。这就是经典的「**所有子数组最小值之和**（以 $j$ 结尾）」问题。

从 $\mathrm{cur}_{j-1}$ 推到 $\mathrm{cur}_j$：

$$
\mathrm{cur}_j=\sum_{l=1}^{j-1}\min\bigl(\min_{l..j-1}h,\ h_j\bigr)+h_j
=\sum_{l=1}^{j-1}\min\bigl(\text{旧最小值},h_j\bigr)+h_j .
$$

也就是说：

1. 旧的每个左端点 $l$ 对应的最小值要和 $h_j$ 取 $\min$；
2. 新增左端点 $l=j$，贡献 $h_j$。

把「旧最小值」按大小分组，用单调栈维护。

**栈的定义**：栈中元素 $(v_1,c_1),(v_2,c_2),\dots,(v_k,c_k)$，满足

$$
v_1<v_2<\dots<v_k,
$$

且把左端点 $1..j-1$ 分成 $k$ 个连续段，第 $t$ 段有 $c_t$ 个左端点，它们当前的 $\min_{l..j-1}h$ 都等于 $v_t$。同时维护

$$
\mathrm{cur}=\sum_{t=1}^{k}v_tc_t=\sum_{l=1}^{j-1}\min_{l..j-1}h .
$$

**引理 2（不变式）**：上述「分组 + 严格递增 + `cur` 等于最小值之和」的不变式在每一步转移后仍成立。

**证明**（归纳）。初始 $j$ 之前（空）显然成立。设处理 $h=h_j$ 前不变式成立。

1. **弹栈**：当栈顶 $v_k\ge h$ 时，弹出 $(v_k,c_k)$。这一组的 $c_k$ 个左端点原本最小值 $v_k$，与 $h$ 取 $\min$ 后变成 $h$（因为 $v_k\ge h$）。所以 `cur` 减少 $(v_k-h)c_k$，这些左端点并入「待压入 $h$ 的那一组」。
2. **合并**：所有 $v\ge h$ 的组都被弹出并并入；剩下的栈顶 $v<h$，它们的左端点最小值本来就 $<h$，取 $\min$ 后不变，正确。
3. **新组**：被弹出的所有左端点（共 $1+\sum c$ 个，包含新增的 $l=j$）现在最小值都是 $h$，压入 $(h,\ 1+\sum c)$。此时 $v_{k'}=h$ 大于新的栈顶（若有），严格递增性保持。
4. **`cur` 更新**：被弹出的各组在 `cur` 中已经按新最小值 $h$ 计入（因为减去了 $(v-h)c$，该组剩下的贡献是 $h\cdot c$）；剩下的组不变。最后只需加上新增左端点 $l=j$ 的贡献 `cur += h`。此时 `cur` 精确等于 $\sum_{l=1}^{j}\min_{l..j}h$。

所有左端点恰好属于一个组（弹出与合并只是重新分组，数量守恒），所以不变式成立。$\square$

**引理 3（答案不重不漏）**：把底边固定为 $i$ 时，$\sum_j\mathrm{cur}_j$ 精确统计所有以第 $i$ 行为底边的合法矩形，且每个只算一次；再对 $i$ 求和即得全体合法矩形数。

**证明**：

- 每个合法矩形由（上边界 $t$、下边界 $i$、左边界 $l$、右边界 $j$）唯一确定。
- 在底边 $i$、右边界 $j$、左边界 $l$ 这一项里，合法上边界恰好有 $\min_{l..j}h$ 个（引理 1），每个上边界给出一个不同的矩形。因此该项的贡献等于「以 $(i,j,l)$ 为下、右、左的矩形个数」。
- 不同的 $(i,j,l)$ 三元组对应的矩形集合互不相交：任意两个不同三元组至少有一个边界不同，矩形必然不同。且每个合法矩形都能在自己的 $(i,j,l)$ 处被统计到。
- 所以并集不重不漏，求和即总方案数。$\square$

### 2.4 第四步：行与行之间的 $h$ 递推

$h_j$ 只依赖上一行的 $h_j$ 和当前格：

$$
h_j\leftarrow[h_{\text{当前格}}=\texttt{.}]\cdot(h_j+1).
$$

因为「向上连续 `.` 的长度」遇到 `*` 就断成 0，遇到 `.` 就在上一行同列的基础加一。每行只需 $O(m)$ 更新，不必每行重新扫描上方所有行。

### 2.5 复杂度

每行：列循环 $m$ 次，每个元素入栈、出栈各至多一次 $\Rightarrow O(m)$。总时间 $O(nm)$，空间 $O(n+m)$（其实只需要当前行的 $h$ 与栈）。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 固定底边后，每个合法矩形由「高度不超过该区间最小列高」决定，个数是区间最小值。
- **consider easier version** — 先砍掉上边界：固定底边，把上边界变成「向上连续 `.` 的列高」。
- **reduce to easier problem** — 问题化成「所有以 $j$ 结尾的子数组最小值之和」，逐列累加。
- **classic problem solution** — 单调栈维护（最小值，左端点数）分组，$O(1)$ 摊销更新 `cur`。
- **explore its property** — 每个矩形由 $(t,i,l,j)$ 唯一确定，保证不重不漏。
- **avoid overflow** — 答案 $2.5\times10^{11}$，用 `long long`。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n,m` | `int` | 行数、列数 | 读入 | 规模 |
| `grid[i]` | `char [1005]` | 第 $i$ 行的字符串 | 读入 | 图 |
| `h[j]` | `int [1005]` | 以当前行为底、第 $j$ 列向上连续 `.` 的长度 | 0 | height |
| `stkH[],stkC[]` | `int [1005]` | 单调栈：分组的最小值、该组左端点个数 | 每行清空 | stack |
| `top` | `int` | 栈内元素个数 | 0 | 栈顶 |
| `cur` | `i64` | 以当前列 $j$ 为右边界、当前行为底边的矩形数（即 $\sum_l\min h$） | 0 | current |
| `ans` | `i64` | 总方案数 | 0 | answer |
| `cnt` | `int` | 本轮被合并的组大小（含新左端点） | 1 | count |

### 4.2 算法步骤

1. 读入 $n,m$ 与 $n$ 行字符串。
2. `ans=0`，`h[*]=0`。
3. 对每一行 $i=0\dots n-1$：
   1. `top=0, cur=0`。
   2. 对每一列 $j=0\dots m-1$：
      1. 更新 `h[j]`：`grid[i][j]=='.' ? h[j]+1 : 0`。
      2. `cnt=1`；当栈非空且 `stkH[top-1]>=h[j]` 时：弹栈，`cur-=(stkH[top]-h[j])*stkC[top]`，`cnt+=stkC[top]`。
      3. 压入 `(h[j],cnt)`；`cur+=h[j]`；`ans+=cur`。
4. 输出 `ans`。

### 4.3 复杂度

- 时间：$O(nm)$（每个格子入栈、出栈各至多一次）。
- 空间：$O(n+m)$（主要由输入的网格决定，其余为 $O(m)$）。

## 5. 示例代码

```cpp
//
// 题目：P1950 长方形
// https://www.luogu.com.cn/problem/P1950
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};

int n,m;
char grid[mxn][mxn];
int h[mxn];
int stkH[mxn],stkC[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>grid[i];

	i64 ans{0};
	for(int i=0;i<n;++i)
	{
		int top{0};
		i64 cur{0};
		for(int j=0;j<m;++j)
		{
			h[j]=(grid[i][j]=='.')?h[j]+1:0;
			int cnt{1};
			while(top>0&&stkH[top-1]>=h[j])
			{
				--top;
				cur-=(i64)(stkH[top]-h[j])*stkC[top];
				cnt+=stkC[top];
			}
			stkH[top]=h[j];
			stkC[top]=cnt;
			++top;
			cur+=h[j];
			ans+=cur;	// 以 (i,j) 为右下角的全部矩形
		}
	}
	cout<<ans<<'\n';
	return 0;
}
```
