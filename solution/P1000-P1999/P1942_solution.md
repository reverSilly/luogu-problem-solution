# P1942 词编码

## 1. 重新读题

### 1.1 问题重述（人话版）

所有原始单词长度都是 $n$，且满足一个「校验性质」：把单词里每个 `1` 所在的位置（从 $1$ 开始数）加起来，这个和必须是 $n+1$ 的倍数（$0$ 也算）。

传输过程对每个单词**恰好**做下面四件事之一：

1. 把某个 `0` 改成 `1`（只有 $0\to1$，不会 $1\to0$）；
2. 删掉一个字符（长度变成 $n-1$）；
3. 在任意位置插入一个字符（长度变成 $n+1$）；
4. 什么都不做。

现在给你传输后的若干个单词（行数不一定是 $n$，读到文件末尾，最多 $2001$ 个），要求还原出唯一的原始单词；若有多解，按题目给定的偏好顺序选最优；无解输出 `-1`。

偏好顺序：先看操作 $4$，再看操作 $1$，再看操作 $2$，再看操作 $3$；同一操作中操作位置从左到右；对插入，同一位置插入 `0` 优于插入 `1`。

### 1.2 关键约束与规模暗示

- $4\le n\le 1000$，单词数 $W\le 2001$。
- $n$ 只有 $1000$，所以「枚举一个单词的所有单步逆操作」最多只有 $2n+O(1)\approx 2000$ 个候选，这个量级是被允许的。
- 校验性质把候选再砍掉一大截，是解题的关键筛子。
- 单词数 $W$ 可以比 $n$ 大，所以必须对每个候选去验证**全部**单词，不能只看一行。

---

## 2. 思维链（Chain-of-thought）

### 2.1 关键观察：候选只可能来自「第一个单词」的一次逆操作

**引理 1（候选的完备性）**：设原始单词为 $s$，第一个收到的单词为 $t_1$。则 $s$ 一定属于下面集合之一：

- 若 $|t_1|=n$：$s=t_1$，或 $s$ 是把 $t_1$ 中某个 `1` 改成 `0` 得到的串；
- 若 $|t_1|=n-1$：$s$ 是在 $t_1$ 的某个位置插入一个 `0` 或 `1` 得到的串；
- 若 $|t_1|=n+1$：$s$ 是删掉 $t_1$ 的某一个字符得到的串；
- 其他长度：无解。

**证明**：$t_1$ 是由 $s$ 经过四种操作之一得到的，把该操作反过来即可：

- 操作 $4$：$t_1=s$；
- 操作 $1$：$s$ 与 $t_1$ 只在被改的那一位不同，且 $s$ 该位是 `0`、$t_1$ 该位是 `1`，把该位改回 `0` 即得 $s$；
- 操作 $2$：$t_1$ 是 $s$ 删掉一个字符，故 $s$ 是 $t_1$ 插入一个字符，插入位置与插入的字符（`0` 或 `1`）均未知，需全部枚举；
- 操作 $3$：$t_1$ 是 $s$ 插入一个字符，故 $s$ 是 $t_1$ 删掉一个字符。

四种情况穷尽，且每种情况下我们枚举了所有可能的逆操作，故 $s$ 必在集合中。$\square$

于是我们只需要：从 $t_1$ 生成至多约 $2n+2$ 个候选，逐个用「校验性质 + 与所有单词相容」来筛选。

### 2.2 一个候选与一个单词是否相容

固定候选 $s$（长度 $n$），判断单词 $t$ 能否由 $s$ 经一次操作得到。

**引理 2（相容判定）**：

- $|t|=n$：相容当且仅当对每个 $i$ 都有 $s_i\le t_i$（把 `0` 看成 $0$、`1` 看成 $1$），且 $s_i\ne t_i$ 的位置至多一个。
- $|t|=n-1$：相容当且仅当存在唯一的「第一个失配位置」$i$，令 $s$ 跳过 $s_i$ 后与 $t$ 完全相等。
- $|t|=n+1$：相容当且仅当存在唯一的「第一个失配位置」$i$，令 $t$ 跳过 $t_i$ 后与 $s$ 完全相等。

**证明**：

- $|t|=n$：由引理 1 的逆过程，只可能是操作 $4$ 或操作 $1$。操作 $4$ 要求全等；操作 $1$ 要求恰有一位从 `0` 变 `1`，即 $s_i=0,t_i=1$，其余位相同。两种合并正是「$s_i\le t_i$ 且失配位至多一个」。
- $|t|=n-1$：只可能是操作 $2$，即删掉 $s$ 的一个字符。若 $s$ 删掉第 $i$ 个字符得到 $t$，则 $s_0=t_0,\dots,s_{i-1}=t_{i-1}$，且 $s_{i+1}=t_i,\dots$。从左往右找第一个失配位置 $i$（若前 $n-1$ 位全等则 $i=n-1$，表示删的是最后一个字符），此时只能删 $s_i$，再核对剩余部分即可。第一个失配位置唯一，所以判定是充要的。
- $|t|=n+1$：对偶，只可能是操作 $3$，删掉 $t$ 的一个字符得到 $s$，同样由第一个失配位置唯一确定删哪个字符。

$\square$

### 2.3 校验性质是必要的筛子

**引理 3**：任何原始单词 $s$ 必须满足 $\sum_{i:\,s_i=1}(i+1)\equiv 0\pmod{n+1}$。

**证明**：这是题面直接给出的原始单词性质，所有原始单词都满足。故候选不满足它时一定不是答案，可以直接丢弃。$\square$

先做这个 $O(n)$ 的检查，可以把候选数量大幅压低，尤其对「插入」类候选：插入 `0` 与插入 `1` 只差一个位置权重，而权重 $i+1\in[1,n]$ 模 $n+1$ 互不相同，所以同一插入位置上两种字符至多有一种能通过校验，位置 $i$ 也至多有一个可行。

**引理 4（校验筛选后每类候选的数量）**：

- 操作 $4$ 候选至多 $1$ 个；操作 $1$ 候选至多 $1$ 个（因为需要 $i+1\equiv S\pmod{n+1}$，而 $i+1\in[1,n]$ 至多一个解）；
- $|t_1|=n-1$ 时，每个插入位置 $0\le i\le n-1$ 至多一个字符可行，故至多 $n$ 个；
- $|t_1|=n+1$ 时，删每个字符至多得到 $n+1$ 个不同候选。

**证明**：操作 $1$：原和为 $S$，把位置 $p$ 的 `1` 改成 `0` 后和为 $S-p$，要求 $S-p\equiv0\pmod{n+1}$，即 $p\equiv S$。$p\in[1,n]$ 中至多一个。插入：在 $t_1$（长度 $n-1$）的位置 $i$（$0$ 基，插在它前面）插入字符后，新串中原来的后缀整体右移一位，和的变化量为「插入的字符权重 $i+1$（若插 `1`）」加上「后缀中 `1` 的个数」；固定 $i$ 时插 `0` 与插 `1` 的和相差 $i+1\not\equiv0\pmod{n+1}$，故至多一个字符满足校验。$\square$

结论：候选总数 $O(n)$。

### 2.4 偏好顺序 = 枚举顺序

**引理 5**：按「操作 $4$、操作 $1$、操作 $2$、操作 $3$」的顺序枚举 $t_1$ 的逆操作，同一操作内位置从左到右，插入时先 `0` 后 `1`；则第一个通过全部检查的候选就是题目意义下的最优解。

**证明**：每一个候选 $s$ 都对应至少一个「对 $t_1$ 的逆操作描述」（引理 1 的枚举），且描述到 $s$ 的映射是确定的：操作 $4$ 给唯一的 $s$；操作 $1$ 在位置 $p$ 给唯一的 $s$；操作 $2$（还原时插入）在位置 $i$、字符 $b$ 给唯一的 $s$；操作 $3$（还原时删除）在位置 $i$ 给唯一的 $s$。题目的偏好顺序正是这些描述的字典序，所以越早被枚举到的描述越优。若两个描述给出同一个 $s$，输出结果相同，顺序不影响答案。于是第一个合法候选就是最优解。$\square$

**注意一个题面细节**：$t_1$ 的长度已经把「正向操作是删还是插」钉死了——$|t_1|=n$ 只可能是操作 $4/1$，$|t_1|=n-1$ 只可能是操作 $2$，$|t_1|=n+1$ 只可能是操作 $3$。因此跨操作类别的先后（$2$ 与 $3$ 谁先）永远不会同时用到，真正需要落实的只有「$4$ 先于 $1$」「位置从左到右」「同位置插入 `0` 先于 `1`」这三条。

### 2.5 判定无解

**引理 6**：若按上述方法枚举完所有候选都没有一个同时满足校验与全部单词，则无解。

**证明**：任何合法原始单词都必须出现在候选集合中（引理 1），且必须满足校验（引理 3）并与每个收到的单词相容（否则该单词不可能由它一次操作得到，与题设「每个单词都由原始单词一次操作得到」矛盾）。故若候选全部失败，合法原始单词不存在。$\square$

### 2.6 复杂度

候选至多约 $2n+2$ 个；每个候选先花 $O(n)$ 做校验，再对每个单词花 $O(n)$ 判定相容（实现上找第一个失配位置，绝大多数候选会立刻失败）。最坏时间 $O(n^2W)$，但在校验筛选与提前退出后实际远小于该上界；空间 $O(nW)$ 存单词。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 收到的单词是原始单词「一次操作」的产物，故原始单词必是第一个单词的一次逆操作。
- **consider easier version** — 先只对一个单词：把四类逆操作全部枚举出来（至多 $O(n)$ 个候选）。
- **explore its property** — 校验和（`1` 的位置和模 $n+1$）是必要条件，能把候选砍到 $O(n)$。
- **classic problem solution** — 逐个候选与全部单词做 $O(n)$ 的「一次编辑」相容判定。
- **greedy by statement order** — 按题目给的偏好顺序枚举，第一个全部通过的候选即最优解。

## 4. 真实解法（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 原始单词长度 | 读入 | 规模 |
| `w` | `vector<string>` | 收到的全部单词（按首次出现顺序去重） | 读入到 EOF | words |
| `cand` | `vector<string>` | 由第一个单词逆操作得到的候选 | 空 | candidates |
| `seen` | `set<string>` | 候选去重（同一字符串只试一次） | 空 | 去重 |
| `sum` | `long long` | 某串中 `1` 的位置和 | 0 | 校验和 |

### 4.2 算法步骤

1. 读入 $n$；循环 `cin>>s` 把所有单词读入，并按首次出现顺序**去重**（同一个单词重复出现对「所有单词都相容」这一条件没有任何影响，去重只减少常数）。若读不到单词，输出 `-1`。
2. 设 `s0=w[0]`，按长度分类生成候选，保持偏好顺序：
   1. `|s0|=n`：先放 `s0`（操作 $4$）；再对 $i=0\to n-1$，若 `s0[i]=='1'`，把该位改成 `'0'` 得到一个操作 $1$ 候选。
   2. `|s0|=n-1`：对插入位置 $i=0\to n-1$，依次尝试插入 `'0'`、`'1'`。
   3. `|s0|=n+1`：对删除位置 $i=0\to n$，依次删除第 $i$ 个字符。
   4. 其他长度：输出 `-1`。
3. 依次遍历候选（用 `seen` 去重）：
   1. 计算校验和，若 `sum%(n+1)!=0` 跳过；
   2. 对 `w` 中每个单词调用相容判定（引理 2），全部通过则输出该候选并结束。
4. 所有候选都失败：输出 `-1`。

### 4.3 复杂度分析

- **时间**：候选 $O(n)$ 个，每个与 $W$ 个单词各做 $O(n)$ 判定，最坏 $O(n^2W)$；校验与提前退出使其远低于上界。
- **空间**：$O(nW)$ 存输入，$O(n^2)$ 存候选。

## 5. 示例代码

```cpp
//
// 题目：P1942 词编码
// https://www.luogu.com.cn/problem/P1942
#include<bits/stdc++.h>
using namespace std;

int n;
vector<string> w;
vector<string> cand;

bool checksum(const string&s)
{
	long long sum{0};
	for(int i=0;i<n;++i)
		if(s[i]=='1')
			sum+=i+1;
	return sum%(n+1)==0;
}

// 判断候选 s 能否在一步操作内变成 t
bool ok(const string&s,const string&t)
{
	int tn=t.size();
	if(tn==n)
	{
		int diff{0};
		for(int i=0;i<n;++i)
			if(s[i]!=t[i])
			{
				if(s[i]=='1')          // 只允许 0->1
					return false;
				if(++diff>1)
					return false;
			}
		return true;
	}
	if(tn==n+1)                        // s 是 t 删掉一个字符
	{
		int i{0};
		while(i<n&&s[i]==t[i])
			++i;
		for(int j=i;j<n;++j)
			if(s[j]!=t[j+1])
				return false;
		return true;
	}
	if(tn+1==n)                        // s 是 t 插入一个字符
	{
		int i{0};
		while(i<tn&&s[i]==t[i])
			++i;
		for(int j=i;j<tn;++j)
			if(s[j+1]!=t[j])
				return false;
		return true;
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	{
		string s;
		set<string> seenw;
		while(cin>>s)
			if(seenw.insert(s).second)
				w.push_back(s);
	}
	if(w.empty())
	{
		cout<<-1<<'\n';
		return 0;
	}

	string s0=w[0];
	if((int)s0.size()==n)
	{
		cand.push_back(s0);
		for(int i=0;i<n;++i)
			if(s0[i]=='1')
			{
				string t=s0;
				t[i]='0';
				cand.push_back(t);
			}
	}
	else if((int)s0.size()==n-1)
	{
		for(int i=0;i<n;++i)
			for(char b:{'0','1'})
			{
				string t=s0;
				t.insert(t.begin()+i,b);
				cand.push_back(t);
			}
	}
	else if((int)s0.size()==n+1)
	{
		for(int i=0;i<n+1;++i)
		{
			string t=s0;
			t.erase(t.begin()+i);
			cand.push_back(t);
		}
	}
	else
	{
		cout<<-1<<'\n';
		return 0;
	}

	set<string> seen;
	for(const string&s:cand)
	{
		if(!seen.insert(s).second)
			continue;
		if(!checksum(s))
			continue;
		bool good{true};
		for(const string&t:w)
			if(!ok(s,t))
			{
				good=false;
				break;
			}
		if(good)
		{
			cout<<s<<'\n';
			return 0;
		}
	}
	cout<<-1<<'\n';
	return 0;
}
```
