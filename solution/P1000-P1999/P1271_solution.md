# P1271 【深基9.例1】选举学生会

## Part 1 重新审题

有 $n$（$1 \le n \le 999$）名候选人，编号 $1$ 到 $n$。收到 $m$（$1 \le m \le 2000000$）张选票，第 $i$ 张选票上的数字为 $a_i$，保证 $1 \le a_i \le n$。要求把 $m$ 张选票按数字从小到大排序后输出。

关键观察：选票的数字只有 $1$ 到 $n$ 这 $n$ 种取值，而 $n \le 999$ 远小于 $m \le 2000000$。

---

## Part 2 思考过程（Chain of Thought）

### 第一步：探索题目特性

选票的值域 $[1,n]$ 很小（最多 999 种），而数据量 $m$ 很大（最多 200 万）。这提示我们：如果暴力排序 $m$ 个数，需要 $O(m \log m)$ 次比较，当 $m = 2000000$ 时约为 $2000000 \times 21 \approx 4.2 \times 10^7$ 次比较，可能卡常数。而值域只有 $n \le 999$，我们应该利用这个信息。

### 第二步：考虑更简单的版本

如果 $m = n$，每个候选人恰好得一票，那排序就是 $1,2,\ldots,n$，直接输出即可。但 $m$ 远大于 $n$，每个候选人可能得很多票，有些候选人可能得零票。

这提示我们：不需要逐张选票去排序，只需要统计每个候选人得了多少票，然后按候选人编号从小到大，把票数展开成选票序列即可。

### 第三步：经典技巧——计数排序（Counting Sort）

对于值域有限（$O(n)$）而数据量很大（$O(m)$）的排序问题，经典解法是计数排序：

1. 开一个计数数组 $cnt[1..n]$，初始化全为 0。
2. 遍历 $m$ 张选票，每读到一个值 $x$，令 $cnt[x]++$。
3. 按 $x = 1, 2, \ldots, n$ 的顺序，把值 $x$ 输出 $cnt[x]$ 次。

**为什么这样输出就是排序结果？**

**引理**：计数排序的输出序列等于原始序列的非降排序。

**证明**：设原始序列为 $a_1, a_2, \ldots, a_m$，每个 $a_i \in [1,n]$。记 $cnt[x] = |\{i : a_i = x\}|$ 为值 $x$ 在原始序列中出现的次数。

排序结果（非降序）$b_1 \le b_2 \le \cdots \le b_m$ 必须满足：对于任意 $t \in [1,n]$，$b$ 中值 $\le t$ 的元素个数为 $\sum_{x=1}^{t} cnt[x]$（因为原始序列中值 $\le t$ 的元素个数为 $\sum_{x=1}^{t} cnt[x]$，排序不改变各值的计数）。

计数排序的输出为：先输出 $cnt[1]$ 个 1，再输出 $cnt[2]$ 个 2，……，最后输出 $cnt[n]$ 个 $n$。

对于任意 $t$，输出序列中值 $\le t$ 的元素个数恰好为 $\sum_{x=1}^{t} cnt[x]$，与排序结果一致。

又因为输出序列是分段常数：前 $cnt[1]$ 个元素都是 1，接下来 $cnt[2]$ 个元素都是 2，……，天然满足非降序（$1 \le 1 \le \cdots \le 1 \le 2 \le 2 \le \cdots$）。

由以上两点，输出序列是满足"各值计数正确"且"非降"的唯一序列，即排序结果。$\blacksquare$

**复杂度分析**：
- 计数阶段：读入 $m$ 张选票，每张 $O(1)$ 更新计数，共 $O(m)$。
- 输出阶段：对 $x = 1$ 到 $n$，共输出 $m$ 个元素（$\sum_{x=1}^{n} cnt[x] = m$），每个元素 $O(1)$ 输出，共 $O(m)$。
- 空间：$cnt$ 数组大小 $O(n)$。
- 总时间 $O(m + n)$，总空间 $O(n)$。

对比暴力排序 $O(m \log m)$，当 $m = 2000000$ 时 $O(m \log m) \approx 4.2 \times 10^7$，而 $O(m + n) \approx 2.0 \times 10^6$，快了约 20 倍。

### 第四步：细节确认

- 输出格式：题目要求"求出排序后的选票编号"，一般 Luogu 排序题输出时每个数后跟一个空格，行末换行。
- 读入：$m$ 可达 200 万，需要 `ios::sync_with_stdio(false)` 加速。
- 下标：内部 0-based，$cnt$ 数组下标 0 到 $n-1$ 对应候选人 1 到 $n$。

---

## Part 3 模式总结

```
- explore its property — 值域 n ≤ 999 远小于 m ≤ 2000000，适合计数排序
- classic problem solution — 计数排序：统计频次 + 按值展开输出，O(m+n)
- prove correctness — 分段常数输出天然非降，各值计数与原始一致，故等于排序
```

## Part 4 正式解法

### 符号表

| 符号 | 含义 | 初始化 | 助记 |
|------|------|--------|------|
| $n$ | 候选人数 | 读入 | 值域上界 |
| $m$ | 选票张数 | 读入 | 数据量 |
| $cnt[i]$ | 候选人 $i+1$ 的得票数（0-based：$cnt[0]$ 存候选人 1 的票数） | 全 0（全局数组默认） | $C$ = count |

### 算法步骤

1. **读入** $n, m$。
2. **计数**：循环 $m$ 次，每次读入一个选票值 $x$（1-based），令 $cnt[x-1]++$（转为 0-based）。
3. **输出**：外层循环 $i = 0$ 到 $n-1$（对应候选人 $i+1$），内层循环 $j = 0$ 到 $cnt[i]-1$，每次输出 $i+1$ 后跟一个空格。
4. 末尾输出换行。

### 复杂度

- 时间：$O(m + n)$（计数 $O(m)$ + 输出 $O(m)$）。
- 空间：$O(n)$（$cnt$ 数组）。

### 验证状态

本题未编译运行。逻辑验证：对 $n=3, m=6, a = [3,1,2,3,1,1]$，计数得 $cnt = [3,1,2]$（0-based 对应候选人 1,2,3），输出 `1 1 1 2 3 3`，与原序列排序结果一致。

## Part 5 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1005};

int n,m,cnt[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,x;i<m;++i)
	{
		cin>>x;
		cnt[x-1]++;
	}
	for(int i=0;i<n;++i)
		for(int j=0;j<cnt[i];++j)
			cout<<i+1<<' ';
	cout<<'\n';
	return 0;
}
```

**代码说明**：
- `cnt[x-1]` 将 1-based 的候选人编号转为 0-based 下标。
- 输出时用 `i+1` 恢复为 1-based 编号。
- 全局数组 `cnt` 默认为 0，无需手动初始化。
- `mxn{1005}` 满足 $n \le 999$ 的 +5 松弛。
