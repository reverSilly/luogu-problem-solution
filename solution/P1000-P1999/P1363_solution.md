## 1. 重新读题

**问题重述（简化版）**

平面上每个整点格子 $(x,y)$ 的性状由 $n\times m$ 的模板周期决定：$(x\bmod n,\;y\bmod m)$ 是 `.` 或 `S` 则可走，是 `#` 则不可走。起点是模板里唯一的 `S`，把它当作**第 $0$ 个周期块**（即 $(0,0)$ 到 $(n-1,m-1)$ 那块）里那个 `S` 的实际位置。问：从起点出发，能否走到**与起点距离无界**的格子上（能即 `Yes`，否则 `No`）。

题面原文里 "$(x \bmod n,y \bmod m)$"、"$(0,0)$ 到 $(n-1,m-1)$ 这个矩阵单元"两处小写 $n,m$ 与输入形式里的大写 $N,M$ 混排，本文统一按输入记 $n,m$；含义不受影响。另外题面没有明说"模板里恰有一个 `S`"，只说"LHX 和 WD 所在的位置用 `S` 表示"（单数），代码据此取那唯一的 `S`（见 §2.9 对多 `S` 的讨论）。

抽象成图论语言：无限图 $G_\infty$（顶点 = 可走格，边 = 上下左右相邻可走格），起点 $s$。判定
$$\sup\{d(s,w): w\text{ 在 }s\text{ 的连通分量里}\}=+\infty\ \text{ 是否成立}.$$

**约束与暗示**

| 量 | 范围 | 推论 |
|---|---|---|
| $n,m$ | $1\le n,m\le 1500$ | 模类数 $nm\le 2.25\times 10^6$，$O(nm)$/组 是目标复杂度 |
| 组数 | 每个测试点 $\le 10$ 组，**以 EOF 结束**（没有 $T$） | 必须 `while(cin>>n>>m)`；每组重读 $n\times m$ |
| 状态空间 | 无限 | 不能直接在无限图上搜索，必须压到 $nm$ 个模类上 |
| 子任务 | $30\%$：$n,m\le20$；$50\%$：$n,m\le100$；$100\%$：$n,m\le1500$ | 分档按**线性倍数**而非平方递进（$20\to100\to1500$），说明标准解是 $O(nm)$/组 的**一次遍历**；而"$k\times k$ 份模板窗口"这类 $O(n^2m^2)$ 做法在 $n,m\le20$ 档能混分，正是它的诱惑所在（§2.4(b)） |
| 递归 | 路径长可达 $nm=2.25\times10^6$ | 深递归 DFS 有爆栈风险，用显式队列/栈 |

**下标约定**：题面自己就说"表示迷宫里 $(0,0)$ 到 $(n-1,m-1)$ 这个矩阵单元"，本来就是 0-based，与代码内部约定一致，无需读写入转换；唯一的坑是**无限图侧坐标可为负**，取模要处理负号（§2.6）。

**本地题面没有样例**：`P1363.md` 只有描述与数据范围，没有 Input/Output 样例，按纪律也不联网取样例，因此**无法与官方答案对标**；§4.3 全部是手算自造算例（含 $n=1$、$m=1$ 两个边界形状）。

## 2. 思维链（Chain-of-thought）

### 2.1 先把"无限"写成数学对象

定义模类映射 $\rho(x,y)=(x\bmod n,\;y\bmod m)$。模板给出环面图 $T$：顶点是 $nm$ 个模类中的可走者，模类 $u$ 向四个方向各有一条边到 $\rho(u+d_k)$（**允许 $v=u$**，例如 $n=1$ 时上、下两条边都回到自己），边的**标签**就是那一步的真实位移 $e(u,v)=d_k\in\{(\pm1,0),(0,\pm1)\}$。$G_\infty$ 是 $T$ 的铺叠（lift）：同一个模类对应**无穷多个**真实格子，彼此相差一个周期向量 $(an,bm)$；反过来说，$G_\infty$ 的一条边走到 $T$ 里就是一条边，$T$ 的一条闭合走法在 $G_\infty$ 里 lift 成一条路径，其端点差就是各边标签之和。

**约定** 下文"走法"指 $G_\infty$ 中顶点序列 $p_0,p_1,\dots,p_t$（相邻两点曼哈顿距离 $1$ 且都可走），净位移 $\operatorname{wind}(W)=p_t-p_0=\sum_{i=0}^{t-1}d_{k_i}$；"$s$ 的连通分量"指 $p_0=s$ 时所有可达 $p_t$ 的集合。

**$T$ 是带标签的*多重图*，不是简单图**：同一对模类之间可以有多条标签不同的边。$n=1$ 时上、下两条边都是从 $(0,y)$ 到自身的平行自环（标签 $(\pm1,0)$）；$m=2$ 时从 $(x,0)$ 出发的左边和右边都落在 $(x,1)$（标签 $(0,\pm1)$）。所以实现时必须**按四个方向各枚举一条出边**，不能按"去重后的邻居集合"枚举——定理 2.4 的 ($\ast$) 只对"被检查过的边"成立，$\square_3$ 的归纳在某一步恰好踩上没被检查的那条平行边时就断了。举例：$2\times2$ 模板 `S.` / `..`，从 $(0,0)$ 出发，"上"给出候选真实格 $(-1,0)$（模类 $(1,0)$），"下"给出 $(1,0)$（同一模类），两条边标签不同，正是它们直接制造冲突；若只登记"邻居 $(1,0)$"一条边，冲突就得指望在别处间接暴露，正确性不再有证明保障。

**引理 2.1（周期性）** 若 $v=(an,bm)$，则格 $c$ 可走 $\iff$ 格 $c+v$ 可走；且 $W$ 是 $G_\infty$ 中合法走法 $\iff$ $W+v$ 是合法走法。
**证明：** 可走性等价：$c=(x,y)$ 可走 $\iff$ 模板在 $\rho(x,y)$ 处非 `#`；而 $x+an\equiv x\pmod n$、$y+bm\equiv y\pmod m$，故 $\rho(c+v)=\rho(c)$，两边查同一格，得证。走法等价：设 $W=(p_0,\dots,p_t)$ 合法，即每 $p_i$ 可走且 $p_{i+1}-p_i=d_{k_i}$（四个单位向量之一）。取 $W+v=(p_0+v,\dots,p_t+v)$：每个 $p_i+v$ 由可走性一侧成立；相邻差 $(p_{i+1}+v)-(p_i+v)=d_{k_i}$ 仍是单位向量，故是合法走法。反向把 $v$ 换成 $-v$（仍是周期向量）即得。$\blacksquare$

于是"无限"这件事只剩一个来源：**走法的净位移**（winding，$\operatorname{wind}(W)=$ 终点 $-$ 起点）。

### 2.2 关键等价：能不能走 = 有没有"非零绕数的闭合走法"

**引理 2.2（非零绕数 $\Rightarrow$ Yes）** 若存在两条从 $s$ 出发的合法走法 $W_1,W_2$，终点 $p,q$ 满足 $\rho(p)=\rho(q)$ 但 $p\ne q$，则答案 Yes。
**证明：** 令 $v=p-q\ne0$。
- **$v$ 是周期向量**：$\rho(p)=\rho(q)$ 即 $p_x\equiv q_x\pmod n$ 且 $p_y\equiv q_y\pmod m$，故 $v=(an,bm)$，$a,b\in\mathbb Z$。
- **造一个"位移为 $v$ 的走法"**：由引理 2.1，把 $W_2$ 反着走再整体平移 $v$，记作 $\operatorname{rev}(W_2)+v$，是条从 $q+v=p$ 到 $s+v$ 的合法走法。拼接
$$U:=W_1\ \Vert\ \big(\operatorname{rev}(W_2)+v\big)$$
首段终点 $p$ 与次段起点 $p$ 相同，故 $U$ 是从 $s$ 到 $s+v$ 的合法走法（长度 $|U|=|W_1|+|W_2|$）。
- **重复它**：对 $j\ge0$，$U+jv$ 由引理 2.1 合法，起点 $s+jv$、终点 $s+(j+1)v$。对 $j$ 归纳：$j=0$ 时是空走法（终点 $s$）；设前 $j$ 段拼成一条从 $s$ 到 $s+jv$ 的合法走法 $U_j$，则 $U_j$ 末尾接 $U+jv$（其起点正是 $s+jv$）得到 $U_{j+1}$。于是对每个 $j$ 都存在从 $s$ 到 $s+jv$ 的合法走法。
- **无界**：$v\ne0$ 是整向量，其曼哈顿长度 $\|v\|_1\ge1$。图上距离不小于曼哈顿距离（每走一步只改变一个坐标、且改变量为 $1$，故 $|p_x-s_x|+|p_y-s_y|$ 每步至多减 $1$，从 $D$ 降到 $0$ 至少要 $D$ 步），于是
  $$d(s,\,s+jv)\;\ge\;\|jv\|_1\;=\;j\|v\|_1\;\ge\;j\xrightarrow[j\to\infty]{}\infty.$$
  按题面"能走到距离起点无限远处即认为能走出去"，答案为 Yes。$\blacksquare$

**引理 2.3（无反例 $\Rightarrow$ No）** 若每个模类在 $s$ 的连通分量里至多对应一个真实格子，则该连通分量顶点数 $\le nm$，有限即有界，答案 No。
**证明：** 假设即 $\rho$ 限制在分量上是单射，值域含于 $nm$ 个模类，故分量顶点数 $\le nm$（有限）。有限集上 $d(s,\cdot)$ 取到最大值 $M$，分量内任一点距离 $\le M$，与"存在任意远的可达点"矛盾，故答案 No。$\blacksquare$

**把两条合成判据**：$G_\infty$ 中从 $s$ 到某格的每条走法都按 $\rho$ 投影成 $T$ 中一条走法，而 $T$ 中一条走法的净位移只由边标签之和给出，所以"同一模类被两个不同真实格到达" 与 "$T$ 中存在净位移非零的闭合走法" 是同一件事的两个说法。于是
$$\text{Yes}\iff\exists\,p\ne q:\ p,q\text{ 均可从 }s\text{ 到达且 }\rho(p)=\rho(q)\tag{$\dagger$}$$
（$\Rightarrow$ 用引理 2.3 的逆否：若不存在这样的 $p,q$，分量有限故走不到无限远；$\Leftarrow$ 用引理 2.2：到 $p,q$ 的两条走法就是它的假设。）剩下的是怎么在 $O(nm)$ 里判定 $(\dagger)$——不能真的去枚举无限个格子，只要一条"标记 + 冲突"的判据（定理 2.4）。

### 2.3 特例先玩：什么都会发生

- $n=1$ 且某列可走 $\Rightarrow$ 该列每行都可走（$\rho$ 与行号无关）$\Rightarrow$ 竖直无限走廊 $\Rightarrow$ **必然 Yes**（§4.3 算例 4）。$m=1$ 同理（算例 5）。这说明"$v=u$ 的自环边"是真边，必须参与判据。
- 完全被墙围住的 $3\times2$ 方块（放在 $4\times4$ 模板里）$\Rightarrow$ No（§4.3 算例 2）：分量有限，无论怎么走都出不去那一块。
- 一条恰好绕环面一周的 $6$ 格闭合圈（$3\times3$ 模板，可走模类恰 $6$ 个）$\Rightarrow$ Yes，但**冲突只在最后一条边闭合时才出现**（§4.3 算例 3）。

### 2.4 被否掉的两条捷径

**(a) "在环面上判环"**：$T$ 只有 $nm$ 个点，任何长度 $>nm$ 的走法必重复模类（抽屉原理）。但"重复模类"太弱——算例 2 里有 $4$ 圈 $(1,1)\!-\!(1,2)\!-\!(2,2)\!-\!(2,1)\!-\!(1,1)$，四条边的标签逐条列出是 $(1,0),(0,1),(-1,0),(0,-1)$，相加恰为 $(0,0)$，绕数零，走多少遍都回到同一个真实格。**判据必须是净位移非零，而不是"是否成环"。**（形式化就是引理 2.2/2.3 的那对方向。）

**(b) "复制 $k\times k$ 份模板，看能否走到窗口边界"**：这条路要可靠，窗口必须装得下**第一处冲突的位置**。两个理由说明它不划算：
- **冲突可以很晚才出现**。算例 3 把 $6$ 个可走模类串成一条单圈，前 $4$ 次出队毫无异常，只有闭合那圈的最后一条边才报冲突。把"下–右阶梯"斜圈放到 $n\times m$ 模板上（行号 $+1$、列号也 $+1$ 地交替走，可走集取 $\{(a,b):a=b\ \text{或}\ a=b+1\}$ 那一类带状格），绕回同模类的另一份副本需要 $\Theta(\operatorname{lcm}(n,m))$ 步，$n,m$ 互素时就是 $\Theta(nm)$ 步——常数 $k$ 的窗口必然漏判（这里只用它作排除法的直观论证，不是形式化下界；真正的结论由 §2.5 的判据给出，不需要任何窗口）。
- **即使按 §2.7 的上界开窗口也太贵**。真实坐标绝对值的上界是 $nm+1500$，折算成周期块指标是行方向最多差 $nm/n=m$ 份、列方向最多差 $nm/m=n$ 份，窗口需 $\Theta(m)\times\Theta(n)$ 份模板 $=\Theta(m)\cdot\Theta(n)\cdot nm=\Theta(n^2m^2)$ 个格子；$n=m=1500$ 时是 $(2.25\times10^6)^2\approx5\times10^{12}$，比 $O(nm)$ 大六个数量级，连读入都不允许。

故放弃，改用"模类 + 绝对坐标标记"：**只在 $nm$ 个模类上走一遍，代价是每类多存两个 `int`**。（$30\%$ 档 $n,m\le20$ 时窗口法只要 $20^2\cdot20^2=1.6\times10^5$ 格，跑得动也常能对，这就是它 tempting 的地方；$50\%$、$100\%$ 两档按线性递进而非平方递进，本身就在提示正解是 $O(nm)$/组。）

### 2.5 判据的实现：给每个模类记一个"绝对坐标"

遍历 $T$（即只在 $nm$ 个模类上搜索），维护数组 $A[r]=(ax,ay)$：**第一次到达模类 $r$ 时我站在哪个真实格子上**。从 $u$（站在 $A[u]$）沿 $d_k$ 走一步，邻居模类 $v=\rho(A[u]+d_k)$、候选真实格 $w=A[u]+d_k$：

- $v$ 不可走（墙）：跳过；
- $v$ 未访问：$A[v]:=w$，入队；
- $v$ 已访问：若 $A[v]\ne w$ —— 同一模类两个不同真实格 —— 引理 2.2 **Yes**；若相等，说明这条边与标记一致，跳过。

**定理 2.4（充要性与顺序无关）** 上述遍历结束时，"从未报冲突" $\iff$ $s$ 的连通分量有限（即答案 No）。
**证明：** 分四步。先说清两条**构造规则**：(i) 只有当 $A[v]$ 还是哨兵 $inf$ 时才写入，写入后永不再改；(ii) 每个模类出队时把它的四条出边全部检查一遍。于是"每个模类至多赋值一次、至多入队一次、至多出队一次"。

- **(1) 每个被赋值的 $A[r]$ 都附带一条 $s\to A[r]$ 的合法走法**：按赋值发生的先后归纳。基例：$A[\rho(s)]=s$，配长度 $0$ 的空走法。归纳步：$A[v]=A[u]+d_k$ 这条赋值发生在 $u$ 出队时，$u$ 的赋值更早（$u$ 能出队说明它已被赋值），由归纳假设存在合法走法 $W$ 从 $s$ 到 $A[u]$；在末尾接一步 $d_k$，终点是 $A[u]+d_k=A[v]$，而该步的落点可走性正是这次赋值前检查过的 $v$（`g[v]!='#'`），且 $A[v]$ 的模类与 $A[u]+d_k$ 一致（§2.6 不变量），故 $W\Vert d_k$ 合法。$\square_1$
- **(2) "无冲突" $\Rightarrow$ 标记在每条被检查过的边上一致**：考察 $u$ 出队时对可走邻居 $v$ 的处理。若当时 $A[v]==inf$，则 $A[v]$ 被写成 $A[u]+d_k$，等式 $A[v]=A[u]+e(u,v)$ 由构造成立，且之后不再改写，故永久成立；若当时 $A[v]\ne inf$，则代码走到那条比较，"无冲突"意味着比较通过，等式成立。又因为每条以已访问模类为起点的边都会在该起点出队时被检查，所以
  $$\forall\ \text{已访问的 }u,\ \forall k:\quad A[\rho(A[u]+d_k)]=A[u]+d_k. \tag{$\ast$}$$
  可达模类全被访问：$T$ 中从 $\rho(s)$ 出发的任一路径，按节点序号归纳，父节点出队时会把子节点拉进队列。$\square_2$
- **(3) 用 ($\ast$) 把无限图上的任意走法压回 $\{A[r]\}$**：任取 $G_\infty$ 中从 $s$ 出发的走法 $p_0,\dots,p_t$，记 $r_i=\rho(p_i)$，$p_{i+1}=p_i+d_{k_i}$。$p_0=s=A[r_0]$（起点赋值就是 $s$ 本身）。设 $p_i=A[r_i]$：$r_i$ 可达故已访问，$r_{i+1}=\rho(p_i+d_{k_i})=\rho(A[r_i]+d_{k_i})$ 正是 ($\ast$) 左边的模类，于是 $p_{i+1}=p_i+d_{k_i}=A[r_i]+d_{k_i}=A[r_{i+1}]$。归纳完成，故**可达集 $\subseteq\{A[r]:r\text{ 已访问}\}$**，元素个数 $\le nm$，有限 $\Rightarrow$ 有界 $\Rightarrow$ No。$\square_3$
- **(4) 反向两个方向**：报冲突时，$A[r]$ 与候选 $w\ne A[r]$ 是同模类 $r$ 的两个不同真实格，且由 $\square_1$ 两者（$w=A[u]+d_k$，$u$ 已赋值）都各自附带一条从 $s$ 出发的合法走法 —— 注意 $w$ 的走法是"$u$ 的走法接一步"，这一步合法是因为代码已确认 $r$ 可走 —— 引理 2.2 给出 Yes。另一半："答案 Yes $\Rightarrow$ 必报冲突"是 $\square_3$ 的逆否：若不报冲突，可达集有限，就不可能走到无限远。$\square_4$$\blacksquare$

**推论 2.5（与遍历顺序无关）** 上面只用到"$A$ 一经赋值不再改"和"出队时枚举全部出边"这两条与次序无关的事实，$\square_3$ 的归纳也不依赖任何"最先到达/最短路径"性质：BFS 队列序、显式栈 DFS 序、甚至任意乱序访问都得出同样的 `Yes/No` 结论。$A$ 的**具体数值**依赖生成树（换一个顺序会记到同模类的另一个副本上），**结论不依赖**。这就是标签里 DFS、栈、BFS 都算正解的原因。

**另一个视角（也是它不需要"松弛"的原因）**：$A$ 满足的是环面图上的**位势方程** $A[v]-A[u]=e(u,v)$（取值在 $\mathbb Z^2$ 中）。普通最短路要把 $A$ 松弛到不动点，因为它的语义是"最小值"；而这里要求的只是**方程组可解**——一旦某点取值确定，沿任意边推出邻点取值，若两条路径推出不同值就矛盾，矛盾一旦出现就不会因"找到更好的值"而消失，所以首赋值即终赋值，一次遍历足够。于是既不需要 Dijkstra/SPFA，也不需要"距离"这个概念，只需要一个比较。

这一定理把"无限"彻底消掉了：**只在 $nm$ 个模类上做一次普通遍历 + 一次比较**。

### 2.6 负坐标取模（唯一容易写错的细节）

代码里同时维护"模类 $(x,y)$"和"绝对坐标 $(px,py)$"，靠一条不变量把两者缝起来：

**不变量** 对每个已赋值的模类 $r=(x,y)$：$ax[r]\equiv x\pmod n$ 且 $ay[r]\equiv y\pmod m$。
**证明：** 对赋值次序归纳。基例 $r=(s_x,s_y)$：$ax=s_x\equiv s_x$，$ay=s_y\equiv s_y$，自反成立。归纳步：$u=(x,y)$ 已成立，出队时写 $A[v]:=(px{+}d_k^x,\;py{+}d_k^y)$，其中 $v$ 的行模类按定义是 $x{+}d_k^x$ 再回绕一次（回绕加减的是 $n$，不改变模 $n$ 的余数），故
$$ax[v]=px+d_k^x\equiv x+d_k^x\equiv rx\pmod n,$$
列方向同理（加减 $m$ 不改模 $m$ 余数）。$A$ 之后不再改写，故 $v$ 处永久成立。$\blacksquare$

由它，邻居模类可以**只用 $x,y$ 算**，不必对可能为负的绝对坐标取模：
```
rx=x+dx; if(rx<0) rx+=n; else if(rx>=n) rx-=n;
```
**一次加减必够**：$x\in[0,n)$、$|dx|\le1\Rightarrow rx\in[-1,n]$。$rx=-1$ 时加 $n$ 得 $n-1\in[0,n)$（$n\ge1$）；$rx=n$ 时减 $n$ 得 $0$；其余不动。两个分支互斥（同一时刻 $rx$ 不能既 $-1$ 又 $n$，因 $n\ge1$），所以 `else if` 正确。这样写既避开 C++11 的截断取余让 $-1\bmod n=-1$（负数）的坑，又省掉除法指令。等价的稳妥写法是 $((t\bmod n)+n)\bmod n$（$t$ 为真实坐标），二者结果相同：$n=1$ 时都恒为 $0$，$t\ge0$ 时都是普通余数，$t<0$ 时后者把 $t\bmod n\in(-n,0]$ 平移回 $[0,n)$。算例 4、5 就是专门踩这条分支的。

### 2.7 溢出预算与复杂度算式

**坐标界**（这条界同时是 `int` 的依据和 §2.4(b) 里窗口法的代价依据）：$A[r]$ 是遍历树上路径 $s\to r$ 的终点。**树上路径不重复模类**：树路径的每个结点都是不同的模类（父结点唯一、沿父链严格变短、长度 $\le$ 已赋值模类数），故长度 $\le nm$；每步只把一个坐标改变 $1$，所以
$$|ax[r]|\le sx+\#\text{步}\le 1500+nm,\qquad |ay[r]|\le sy+\#\text{步}\le 1500+nm,$$
$$\max|a|\;\le\;1500+2.25\times10^6\;=\;2.2515\times10^6\;\ll\;2^{31}-1\approx2.147\times10^9,$$
余量约 $950\times$，`int` 足够，不需要 `i64`（也就不需要 `using i64=long long;`）。折算成周期块指标：$|ax|/n\le m+1$，即最远可站在第 $m$ 号周期块——这正是 §2.4(b) 中"$\Theta(m)$ 份窗口"的来源。
**哨兵不撞车**：`inf=1145141919` 比坐标界大两个数量级（$1.1\times10^9$ vs $2.3\times10^6$），所以 `ax==inf` 与"某合法绝对坐标"不可能混淆；且 $inf$ 只被读、被比较，从不参与 $+1$（写 $A$ 时用的是出队点的真实坐标 $px$，它必有限），不存在"无穷加一"溢出。
**下标**：$id=x\cdot m+y\le 1500\times1500<2.27\times10^6$，`int` 安全；数组永远按**模类**下标访问，回绕后恒在 $[0,n)\times[0,m)$ 内，$mxn,mxm=1505$ 只多不少，padding 行列既不读也不写（`fill_n` 只填 $m$ 个）。
**时间**：出队 $\le nm$（每模类至多入队一次，依据是定理 2.4 的构造规则 (i)"写入仅当 $A==inf$"），边检查 $\le 4nm$，重置 $2nm$，每组约 $6nm\le1.35\times10^7$ 次 $O(1)$ 操作；$10$ 组最坏 $\approx1.35\times10^8$，且内层没有除法/取模（§2.6 的回绕写法）。这就是题面规模暗示的 $O(nm)$/组。
**空间**：$ax,ay$ 各 $1505^2\times4\approx9.06$ MB，$g$ 约 $2.27$ MB，队列最坏 $nm$ 个 `int` 约 $9$ MB $\Rightarrow$ 合计 $\approx29.4$ MB。若内存吃紧，可改存周期块指标 $(bx,by)$（$|bx|\le m+1\le1501$，`short` 足够）省下一半多，但代价是比较时要乘回 $n,m$；本文按可读性用 `int`。

### 2.8 变式与别的做法

- **带权并查集**（题面标签里的"并查集"）：把 §2.5 末尾那组位势方程 $A[v]-A[u]=e(u,v)$（$u,v$ 均取可走模类，$u\to v$ 的四个方向各给一条方程）当作"带权合并"来做：每个结点存 $f[x]$ 与 $pot[x]=A[x]-A[\mathit{rt}(x)]$，`getrt` 时沿路径把 $pot$ 累加上去；合并一条新方程时，若 $u,v$ 不同块就按 $pot$ 之差挂接，若同块则检查 $pot[u]-pot[v]$ 是否等于 $e(u,v)$，不等就矛盾 $\Rightarrow$ Yes；全部方程无矛盾 $\Rightarrow$ No。
  **等价性证明**：并查集得到的赋值与 BFS 得到的 $A$ 都是同一方程组的解，而定理 2.4 的 $\square_2,\square_3$ 只用到"解存在则一切走法被压回 $\{A[r]\}$"、$\square_1$ 只用到"每条方程右边对应真实一步"，两条都不依赖赋值顺序。故两者给出同样的 Yes/No。缺点：要枚举全部 $4nm$ 条方程（含不可达部分，$O(nm\alpha)$ 次带路径查找，常数与代码量都比遍历大），而且不会顺便告诉你哪些模类可达；优点是不需要队列/栈容器。
- **栈版 DFS**（标签里的"栈"）：把队列换成栈即可，定理 2.4 与顺序无关；但必须**显式栈**或**手工改写为迭代**——遍历树深度可达 $nm=2.25\times10^6$，函数递归会爆栈。
- **变体：问"最少走多少步能逃出"**：本判据只回答可行性，不给出步数；若要步数，需在检测到冲突的那条边上回溯两条见证走法的长度（$O(nm)$ 存父指针），本文不涉及。
- **变体：模板旋转/镜像后是否等价**：与本判据无关，因为 $T$ 只由邻接关系与标签决定，旋转保持二者。

### 2.9 其它实现细节与题面空白处

- **多组、EOF**：题面"输入包含多组数据"但没给组数，也没有终止标记 $\Rightarrow$ 唯一正确写法是 `while(cin>>n>>m)`；写成 `for(t=1;t<=T;++t)` 会读不到数据。
- **`S` 的唯一性**：题面用单数描述"LHX 和 WD 所在的位置"，数据据此只含一个 `S`。代码取扫描到的那个 `S`（若一行里写成两个 `S` 则取最后一个）。更稳妥的改法是把所有 `S` 的模类都以第 $0$ 号周期块的真实坐标入队——等价于多源版的定理 2.4，$\square_1,\square_3$ 逐字可用，只是基例改为"每个源各配一条空走法"。这一分支本题用不到，写在这里是为了不掩盖假设。
- **`cin>>g[i]` 读字符串**：`char g[mxn][mxm]` 的每行是长度恰为 $m$、无空格的一串字符，`cin>>g[i]` 会在 $m$ 个字符后补 `\0`，故需要列宽 $>m+1$，$mxm=1505>1501$ 满足。行与行之间的换行被 `>>` 自动跳过。
- **提前 `return true` 的副作用**：本组 $A$ 表被留在半填充状态，靠"每组开头重新 `fill_n`"消化；$g$ 表整行重读、$Q$ 是函数内局部对象，都不需要额外清理。

## 3. 模式总结（按实际思考顺序）

- **translate the infinite into algebra** — 用 $\rho$ 把无限图写成"环面图 $T$ 的铺叠"，唯一自由的量是净位移（§2.1）。
- **explore its property** — 引理 2.1 周期性：平移周期向量把合法走法映成合法走法（§2.1）。
- **find the exact criterion** — 引理 2.2/2.3：Yes $\iff$ 同一模类被两个不同真实格到达（非零绕数闭合走法），并给出"重复拼接 $\Rightarrow$ 无界"的构造（§2.2）。
- **consider easier version** — $n=1$、$m=1$、孤岛、单圈四种极小形人手玩一遍，看到"自环边也算边"和"成环未必能走"（§2.3）。
- **kill two tempting shortcuts** — "判环"被零绕数圈否掉；"有限份窗口"被 $\Theta(nm)$ 的闭合深度与 $O(n^2m^2)$ 的窗口体积否掉（§2.4）。
- **classic problem solution（第 1 次：图遍历 + 位势标记）** — 给每个模类记一个绝对坐标 $A$，冲突即 Yes，一致即 No（§2.5）。
- **recognize it as a potential system, not a shortest path** — $A[v]-A[u]=e(u,v)$ 是 $\mathbb Z^2$ 上的位势方程组；只要求"可解/矛盾"，不要求最优，所以首赋值即终赋值、不需要松弛与优先队列（§2.5 末尾）。
- **prove the machinery** — 定理 2.4 四段：$\square_1$ 赋值附带真实走法 / $\square_2$ 无冲突 $\Rightarrow$ 每条边都不矛盾 / $\square_3$ 对步数归纳把所有无限走法压回 $\{A[r]\}$ / $\square_4$ 反向与逆否；顺带得到推论 2.5（与遍历顺序无关，故 DFS 也对）。
- **trap hunting** — 负坐标回绕用加减而不是 `%`（并证明 $ax\equiv x$ 不变量、一次加减够用）；$T$ 是多重图，必须按四个方向枚举**边**而不是去重邻居（§2.1）；EOF 多组、提前 `return` 后的脏表要靠每组开头 `fill_n` 清；显式队列避开 $2.25\times10^6$ 层深递归（§2.6、§2.9）。
- **budget before coding** — 坐标界 $2.26\times10^6$（含推导）、哨兵 $1.14\times10^9$ 不撞车、$6nm$/组、$\approx29$ MB 内存（§2.7）。

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n,m` | 模板行列数（= 周期） | `int`，每组输入 | 内部 0-based，与题面一致 |
| `g[][]` | 模板字符，仅 `#` 不可走（`.` 与 `S` 都可走） | `char[mxn][mxm]`，每组 `cin>>g[i]` | 行长 $m$，$mxm=1505>m+1$ 才放得下 `\0` |
| `sx,sy` | `S` 在模板里的位置，即起点 $s$ | `int`，读入时记录 | 起点的真实坐标就取 $(s_x,s_y)$（第 $0$ 号周期块里的那个） |
| `ax[x][y],ay[x][y]` | 模类 $(x,y)$ 首次到达时的真实坐标；`inf` = 未访问 | 两个 `int[mxn][mxm]`，逐行 `fill_n(...,m,inf)` | 位势/标记数组；一个值两用（可达 + 坐标） |
| `inf` | 未访问哨兵 | `constexpr int{1145141919}` | 绝对值远大于坐标界（§2.7），不会撞车 |
| `mxn,mxm` | 数组上界 | `constexpr int{1505}` | $1500+5$ |
| `dx[],dy[]` | 四个方向（上、下、右、左） | 全局 `constexpr int[4]` | 与 `Q` 顺序无关，结论与顺序无关 |
| `Q` | BFS 队列，元素 $id=x\cdot m+y$ | `queue<int>`，函数内 | 长度 $\le nm$（每模类至多入队一次） |

### 4.2 算法步骤

1. **读一组**：`while(cin>>n>>m)`；读 $n$ 行模板存入 `g`，遇到 `S` 记 `sx,sy`（题面保证恰有一个，§2.9）。
2. **重置位势表**：`for i<n { fill_n(ax[i],m,inf); fill_n(ay[i],m,inf); }`。一旦检测到 Yes 就提前 `return`，表是脏的，所以重置必须放在**每组开头**、`esc()` 之前。
3. **源**：`ax[sx][sy]=sx, ay[sx][sy]=sy`（第 $0$ 号周期块里的位置），`Q.push(sx*m+sy)`。这是定理 2.4 $\square_1$ 的基例（空走法）。
4. **弹 $u$**：解出模类 $(x,y)$ 与该模类记录的真实格 $(px,py)=(ax[x][y],ay[x][y])$；对四个方向 $k$（$d_k=(dx[k],dy[k])$）依次做：
   - 候选真实格 $(nx,ny)=(px{+}dx[k],\,py{+}dy[k])$；候选模类 $(rx,ry)$ 由 $(x{+}dx[k],\,y{+}dy[k])$ 各分量回绕一次得到（§2.6 不变量保证它等于 $\rho(nx,ny)$）；
   - `g[rx][ry]=='#'` → 跳过（不可走）；
   - `ax[rx][ry]==inf` → 写入 $ax[rx][ry]=nx,\;ay[rx][ry]=ny$ 并入队（$\square_1$ 的归纳步：给它接上真实走法）；
   - 否则比较：`ax[rx][ry]!=nx || ay[rx][ry]!=ny` → **`return true`（Yes）**，这就是 $(\dagger)$ 里的 $p,q$。
5. **队列自然空** $\Rightarrow$ `return false`（No）：$\square_2+\square_3$ 说明此时一切可达真实格都等于某个已记录的 $A[r]$，可达集 $\le nm$ 有限。
6. **输出** `cout<<(esc()?"Yes\n":"No\n");`。

**复杂度**：时间 $O(nm)$/组（出队 $\le nm$、边检 $\le 4nm$、重置 $2nm$，见 §2.7 的算式），空间 $O(nm)$。

**一句话记忆**：**在 $nm$ 个模类上做一次 BFS，每个模类记住"我第一次踩到它时站在哪个真实格"，第二次用另一个真实格踩到同一个模类就是绕数非零 = 能走无限远。**

- **算例 4（边界：$n=1$ 的自环边）** $1\times2$：`S#`。$A[(0,0)]=(0,0)$；出队后 $k=0$（上）：候选真实格 $(-1,0)$，行回绕 $-1+n=-1+1=0$，列回绕后仍是 $0$，模类还是 $(0,0)$，而 `g[0][0]=='S'` 可走；此时 $ax[0][0]=0\ne nx=-1$（比较第一项就失败）→ **冲突，`return true`，Yes**。独立核对：$n=1$ 时 $\rho$ 与行号无关，第 $0$ 列的每一行都可走，$(0,0),(1,0),(2,0),\dots$ 是竖直无限走廊，确实 Yes ✓。此例同时检验"行方向的 $v=u$ 自环边被当作真边参与判据"（若代码写成 `if(rx==x) continue` 之类的"原地边不算"就会漏判）。
- **算例 5（边界：$m=1$ + 列回绕）** $2\times1$：`S` / `#`。$A[(0,0)]=(0,0)$；$k=0$ 上：候选 $(-1,0)$，行回绕 $-1+2=1$，模类 $(1,0)$ 是 `#` → 跳过；$k=1$ 下：候选 $(1,0)$，模类 $(1,0)$ `#` → 跳过；$k=2$ 右：候选 $(0,1)$，列回绕 $1-m=0$，模类 $(0,0)$ 已访问且 $ay[0][0]=0\ne ny=1$ → **冲突，Yes**（$k=3$ 左不会走到）。独立核对：$m=1$ 时 $\rho$ 与列号无关，第 $0$ 行每一列都可走（都是 `S` 的副本），水平无限走廊，Yes ✓。注意此例的 $k=0$ 分支还顺带踩了一次"负数行号回绕"。
- **算例 6（Yes，绕数是 $(n,0)$ 即竖直一整块）** $3\times3$：`S#.` / `#..` / `##.`。可走模类 $(0,0),(0,2),(1,1),(1,2),(2,2)$。

  | 出队（模类，绝对） | 上 | 下 | 右 | 左 |
  |---|---|---|---|---|
  | $(0,0)_{(0,0)}$ | $(-1,0)$ 模类 $(2,0)$ `#` | $(1,0)$ 模类 $(1,0)$ `#` | $(0,1)$ `#` | $(0,-1)$ 模类 $(0,2){\to}A(0,-1)$ |
  | $(0,2)_{(0,-1)}$ | $(-1,-1)$ 模类 $(2,2){\to}A(-1,-1)$ | $(1,-1)$ 模类 $(1,2){\to}A(1,-1)$ | $(0,0)$ ✓ | $(0,-2)$ 模类 $(0,1)$ `#` |
  | $(2,2)_{(-1,-1)}$ | $(-2,-1)$ 模类 $(1,2)$，$A=(1,-1)\ne(-2,-1)$ **冲突** | — | — | — |

  第 $3$ 次出队的第 $1$ 条边即返回 `true` $\Rightarrow$ **Yes**。核对引理 2.2：模类 $(1,2)$ 被 $(1,-1)$ 与 $(-2,-1)$ 到达，$v=(3,0)=(n,0)$ 是竖直一整块的周期向量；两条见证走法 $s\to(0,-1)\to(1,-1)$ 与 $s\to(0,-1)\to(-1,-1)\to(-2,-1)$ 每步落点的模类分别查表为 `.`/`S`，逐格复核：$(0,-1)\bmod(3,3)=(0,2)$ ✓、$(1,-1)\to(1,2)$ ✓、$(-1,-1)\to(2,2)$ ✓、$(-2,-1)\to(1,2)$ ✓。此例与算例 3 的区别是绕数只有行分量非零，说明判据对"单方向绕"同样成立。
- **算例 7（No，竖直骨牌，检验 $n\ge3$ 时的回绕撞墙）** $3\times3$：`#S#` / `#.#` / `###`。可走模类 $(0,1),(1,1)$。$A[(0,1)]=(0,1)$；出队 $(0,1)$：上 $(-1,1)$ 回绕成 $(2,1)$ `#`、下 $(1,1)$ 未访问 $\to A=(1,1)$ 入队、右 $(0,2)$ `#`、左 $(0,0)$ `#`；出队 $(1,1)$：上 $(0,1)$ 一致 ✓、下 $(2,1)$ `#`、右 $(1,2)$ `#`、左 $(1,0)$ `#`。队列空 $\Rightarrow$ **No**。独立核对：$G_\infty$ 里 $s=(0,1)$ 的邻居是 $(\pm1,1),(0,0),(0,2)$，其中 $(1,1)$ 可走、其余查模板为 `#`；$(1,1)$ 的邻居 $(2,1),(0,1),(1,0),(1,2)$ 里只有 $(0,1)$ 可走，故分量恰 $\{(0,1),(1,1)\}$，$2$ 点有界 ✓。
- **两种独立方法互验**：上表每格都按代码语义（方法 A）模拟，随后再用与 A 完全无关的（方法 B）核对——B 对 Yes 用例是"显式写出引理 2.2 的两条见证走法，并逐格验证每步落点的模板字符"，对 No 用例是"在 $G_\infty$ 里逐点扩张分量直到无新格可加，数出分量大小"。$7$ 个用例两法结论一致：算例 1、2、7 判 No，B 给出分量大小 $1,6,2$；算例 3、4、5、6 判 Yes，B 给出的非零周期向量分别是 $v=(3,3)$、$(1,0)$、$(0,1)$、$(3,0)$。其中算例 4、5 的 $v$ 分量为 $\pm1$，恰因 $n=1$（或 $m=1$）使周期退化为 $1$，"$v$ 被 $(n,m)$ 整除"仍成立 ✓。
- **溢出/边界自检**：按 §2.7，$|ax|,|ay|\le1500+nm$；$7$ 个算例里出现的最大绝对坐标绝对值只有 $2$（算例 3 的 $(-2,-1)$、$(-1,-2)$ 一带），远未触及 `int`。$id=x\cdot m+y$ 在 $n=m=1500$ 时 $<2.25\times10^6$；`inf` 从未参与算术，不存在 $inf+1$；数组访问下标恒在 $[0,n)\times[0,m)$，$n=1$、$m=1$ 两种退化形状（算例 4、5）既不会算出负下标也不会算出 $n$。
- **坑自检**：(i) 漏 `fill_n` —— 全局 `int` 默认 $0$，未访问的模类会被当成"已访问且真实坐标 $(0,0)$"，算例 2 中 $A[(2,1)]$ 尚未被写入时若默认 $0$，则任何指向它的候选格都会与之比较并假报冲突，把 No 判成 Yes；(ii) 过早 `return true` 后本组剩余的入队状态必须靠**下一组开头的重置**清掉；(iii) 判界一律靠 `g[rx][ry]=='#'`（模类回绕后必然落在合法下标内），不需要也不应该用坐标边界判断。
- **溢出/边界自检**：按 §2.7，$|ax|,|ay|\le1500+nm$，$7$ 个算例里出现的最大绝对坐标绝对值是 $2$（算例 3 的 $(-2,-2)$ 之前一步），远未触及 `int`；$id=x\cdot m+y$ 在 $n=m=1500$ 时为 $2.25\times10^6$；`inf` 从未参与算术；数组访问下标恒 $\in[0,n)\times[0,m)$，$n=1$、$m=1$ 两种退化形状（算例 4、5）不会算出负下标或 $n$。

## 5. 示例代码（C++）

```cpp
// P1363 幻象迷宫
// 在 nm 个模类上做一次BFS，给每个模类记首次到达时的真实坐标；
// 同一模类被两个不同真实格到达 => 绕数非零 => 能走到无限远
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1505},mxm{1505};      //n,m<=1500 +5
constexpr int inf{1145141919};          //未访问哨兵，远大于任何真实坐标绝对值

int n,m,sx,sy;
char g[mxn][mxm];
int ax[mxn][mxm],ay[mxn][mxm];          //模类(x,y)首次到达的真实坐标(px,py)
constexpr int dx[4]{-1,1,0,0},dy[4]{0,0,1,-1};

bool esc()
{
	queue<int>Q;
	Q.push(sx*m+sy);
	ax[sx][sy]=sx;
	ay[sx][sy]=sy;                      //起点的真实坐标取第0号周期块里的位置
	while(!Q.empty())
	{
		int u=Q.front();
		Q.pop();
		int x=u/m,y=u%m,px=ax[x][y],py=ay[x][y];   //不变量：px≡x(mod n),py≡y(mod m)
		for(int k=0;k<4;++k)
		{
			int nx=px+dx[k],ny=py+dy[k];  //候选真实格，可负、可越出模板
			int rx=x+dx[k],ry=y+dy[k];    //候选模类，|增量|<=1故一次回绕就够
			if(rx<0)
				rx+=n;
			else if(rx>=n)
				rx-=n;
			if(ry<0)
				ry+=m;
			else if(ry>=m)
				ry-=m;
			if(g[rx][ry]=='#')
				continue;
			if(ax[rx][ry]==inf)
			{
				ax[rx][ry]=nx;
				ay[rx][ry]=ny;
				Q.push(rx*m+ry);          //每模类至多入队一次
			}
			else if(ax[rx][ry]!=nx||ay[rx][ry]!=ny)
				return true;              //同模类两个真实格：非零绕数，能走无限远
		}
	}
	return false;                         //标记处处自洽 => 可达集有限
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	while(cin>>n>>m)                  //多组数据以EOF结束，没有T
	{
		sx=sy=0;                      //题面保证模板内恰有一个S
		for(int i=0;i<n;++i)
		{
			cin>>g[i];
			for(int j=0;j<m;++j)
				if(g[i][j]=='S')
					sx=i,sy=j;
		}
		for(int i=0;i<n;++i)          //全局int默认0会被当成"已访问且坐标(0,0)"，必须显式填inf
		{
			fill_n(ax[i],m,inf);
			fill_n(ay[i],m,inf);
		}
		cout<<(esc()?"Yes\n":"No\n");
	}
	return 0;
}
```

### 代码说明

- **`fill_n` 不可省，且必须放在每组开头**：`ax==inf` 同时是"未访问"与"坐标"两个语义的开关；漏填则默认 $0$ 被当成"已访问、真实坐标 $(0,0)$"，任何指向该模类的候选格都会假报冲突（§4.3 坑自检 i）。又因为 `esc()` 可能提前 `return true`，表是脏的，重置只能靠下一组重跑。
- **模类回绕不用 `%`**：见 §2.6，一次加减足够且避开负数取模的符号坑、省掉除法指令；$n=1$ 或 $m=1$ 时同一条语句把自环边算成真边（算例 4、5）。
- **`id=x*m+y` 编解码**：$m$ 是运行时列数，与回绕后的 $ry\in[0,m)$ 一致；$m=1$ 时退化为 $id=x$，仍自洽。
- **早退安全**：读入已经全部完成，`return true` 不影响后续组的 `cin`。
- **不用递归**：树路径长可达 $nm=2.25\times10^6$，递归 DFS 会爆栈；换成显式栈也是对的（定理 2.4 与顺序无关），此处用队列。
