# P1832 A+B Problem（再升级）

> 难度：普及- · 标签：背包 DP, 素数, 递推

## 1. 重新读题

### 1.1 问题重述（人话版）

给定正整数 $n$，把它写成若干个素数相加，顺序不算（$2+5$ 和 $5+2$ 是同一种），素数可以重复（$2+2+3$ 算一种）。问有多少种写法。$n$ 本身如果是素数，单独一个数也算一种。

样例 $n=7$ 有三种：$7$、$2+5$、$2+2+3$。

### 1.2 关键约束与规模暗示

- $1\le n\le 10^3$。$30\%$ 的数据 $n\le 10$，可以搜索；全数据要用递推。
- $1$ 不是素数，也不能写成素数之和，答案是 $0$。
- 方案数增长不算慢：$n=20$ 时是 $26$，$n=1000$ 时是 $48278613741845757$，仍在有符号 $64$ 位以内（$2^{63}-1\approx 9.22\cdot 10^{18}$），用 `i64` 即可，不必高精度。
- 「不计顺序」决定了不能把素数当排列去转移，必须规定一个生成顺序。

## 2. 思维链（Chain-of-thought）

先把方案定义成多重集，再给每个多重集一个唯一的书写顺序。

**引理 1（每个方案对应唯一的非降素数序列）**

一种方案是一个元素全为素数的多重集。把它按从小到大排成 $p_1\le p_2\le\dots\le p_k$（$k\ge 1$），和为 $n$。不同多重集排出的序列不同，同一多重集只有一种非降排法。因此方案数等于这种序列的个数。

**证明**：排序存在，且非降序列由多重集唯一决定。反过来任何非降素数序列丢掉顺序就是一个多重集。这是双射。$k=0$ 的空和只对应 $n=0$，而 $n\ge 1$，所以不会把「什么都不选」算进答案。$\blacksquare$

**引理 2（素数从小到大做完全背包，计数不重不漏）**

设不超过 $n$ 的素数从小到大是 $q_1,q_2,\dots$。令 $dp[0]=1$，$dp[j]$ 表示数字 $j$ 的方案数。按 $i=1,2,\dots$ 的顺序，对每个 $q_i$ 做

$$dp[j]\mathrel{+}=dp[j-q_i]\qquad (j=q_i,q_i+1,\dots,n)$$

内层正序，表示 $q_i$ 可以用多次。结束后 $dp[n]$ 就是答案。

**证明**：断言在处理完前 $i$ 个素数之后，$dp[j]$ 等于「只使用 $q_1,\dots,q_i$、写成非降序列、和为 $j$」的个数。

$i=0$ 时只有 $dp[0]=1$，对应空序列，其余为 $0$。加入 $q_i$ 时，正序循环使得 $dp[j-q_i]$ 已经包含「在这一轮里先用过若干次 $q_i$」的方案，所以 $dp[j-q_i]$ 里的每种序列后面再加一个 $q_i$，得到以 $q_i$ 结尾、且前面的素数都不超过 $q_i$ 的非降序列。旧的 $dp[j]$（这一轮还没加当前项之前，完全不用 $q_i$）保留下来。两种情况互斥且覆盖全部非降序列：最后一个若小于 $q_i$，它已经在更早的素数轮次被计数；最后一个若等于 $q_i$，就由和为 $j-q_i$ 的序列唯一接出来。因此没有重复，也没有遗漏。$i$ 走完所有 $\le n$ 的素数后，$dp[n]$ 即所求。$\blacksquare$

若内层倒序，每个素数最多用一次，$2+2+3$ 会被丢掉，样例会得到 $2$ 而不是 $3$。若素数无序地反复使用，排列会被重复计数。所以上面的两层循环方向都不能反。

暴力是另一条路：只在非降下标上 DFS，`dfs(下一个素数至少从哪一个开始, 剩余)`，剩余为 $0$ 就记一种。它直接枚举引理 1 的序列，不走背包表。$n\le 45$ 时叶子数只有几百，可以对拍；$n=1000$ 的方案数是 $4.8\cdot 10^{16}$，DFS 不能跑，这一档只用标程对一份独立的 Python 背包。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 不计顺序的方案 = 非降素数序列，空和不是正整数的方案（引理 1）。
- **classic problem solution** — 素数从小到大、内层正序的完全背包计数（引理 2）。
- **consider easier version** — $n\le 10$ 甚至 $n\le 45$ 可以直接 DFS；$n=1,2,4,7,10,20$ 都有可以手算的答案。
- **boundary discipline** — `dp[0]=1` 但输出的是 `dp[n]`，$n=1$ 时答案 $0$；计数用 `i64`，线性筛的乘积先用 `1LL` 比较再写入。

## 4. 真实解法

### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `n` | `int` | 目标和 | 读入 | $\le 1000$ |
| `comp` | `bool [1005]` | 线性筛的合数标记 | 全局 `false` | composite |
| `pr,pc` | `int [1005]`、`int` | 素数表及个数 | `pc=0` | primes |
| `dp` | `i64 [1005]` | 和为 $j$ 的非降方案数 | `dp[0]=1`，其余 $0$ | 完全背包 |

### 4.2 算法步骤

1. 线性筛出 $2..n$ 的全部素数。
2. `dp[0]=1`。对每个素数 $p$，`j` 从 $p$ 到 $n$ 正序执行 `dp[j]+=dp[j-p]`。
3. 输出 `dp[n]`。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 筛 $O(n)$，背包 $O(\pi(n)\cdot n)$，空间 $O(n)$。
- 编译：`g++ -O2 -std=c++17 -Wall -Wextra -Werror`，无警告。
- 固定点：$7\to 3$，$20\to 26$，$1\to 0$，$2\to 1$，$4\to 1$，$10\to 5$。标程、DFS、Python 三者一致。
- 随机 $1\le n\le 45$ 共 $60$ 组，三者一致，随机部分耗时 $0.30$ s。
- 最大 $n=1000$：标程输出 `48278613741845757`，与独立 Python 背包相同，耗时 $0.0033$ s。
- 合计 `67 tests OK`。

## 5. 示例代码

### 5.1 标程（`P1832.cpp`）

```cpp
//
// 题目：P1832 A+B Problem（再升级）
// https://www.luogu.com.cn/problem/P1832
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};

int pr[mxn],pc;
bool comp[mxn];
i64 dp[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	int n;
	cin>>n;
	for(int i=2;i<=n;++i)
	{
		if(!comp[i])
			pr[pc++]=i;
		for(int j=0;j<pc&&i*1LL*pr[j]<=n;++j)
		{
			comp[i*pr[j]]=true;
			if(i%pr[j]==0)
				break;
		}
	}
	dp[0]=1;
	for(int i=0;i<pc;++i)
		for(int j=pr[i];j<=n;++j)
			dp[j]+=dp[j-pr[i]];
	cout<<dp[n]<<'\n';
	return 0;
}
```
