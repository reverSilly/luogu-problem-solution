# P1936 水晶灯火灵

## 1. 重新读题

### 1.1 问题重述（人话版）

给定整数 $k$，在 $1\le m,n\le k$ 中找整数对 $(m,n)$，满足
$$
(n^2-mn-m^2)^2=1,
$$
使 $m^2+n^2$ 最大。输出这个最大值对应的 $m$ 和 $n$（第一行 $m$，第二行 $n$）。

### 1.2 关键约束与规模暗示

- $k\le10^8$，而 $m,n$ 是整数。$10^8$ 排除了枚举 $m,n$ 的 $O(k^2)$，但只排除了“多项式于 $k$”的做法；真正的解只有 $O(\log k)$ 个。
- 条件里是一个二次型 $n^2-mn-m^2$ 的平方等于 $1$，这非常像 Fibonacci 数的恒等式，提示应当**先手算小解**找规律，再做数论证明。
- 只需要输出一对 $(m,n)$，不需要输出最大值本身。

## 2. 思维链（Chain-of-thought）

### 2.1 先手算，找规律

记
$$
E(m,n)=n^2-mn-m^2.
$$
从小到大试：

| $(m,n)$ | $E(m,n)$ | 是否满足 $E^2=1$ |
| :--- | :--- | :--- |
| $(1,1)$ | $1-1-1=-1$ | 是 |
| $(1,2)$ | $4-2-1=1$ | 是 |
| $(2,3)$ | $9-6-4=-1$ | 是 |
| $(3,5)$ | $25-15-9=1$ | 是 |
| $(5,8)$ | $64-40-25=-1$ | 是 |

全是相邻 Fibonacci 数！于是猜想：

> **猜想**：所有正整数解恰为 $(F_1,F_2)=(1,1)$、$(F_2,F_3)=(1,2)$、$(F_3,F_4)=(2,3)$、$(F_4,F_5)=(3,5)$、$\ldots$ 这一条链。

### 2.2 怎么证明“只有这些”？

直接解二次方程不好办，两个变量、还要整数。数论里处理这类“二元二次、右边是常数”的经典武器是**递降（Vieta jumping / descent）**：只要能从一个解造出一个更小的解，就能归纳。

观察相邻两组解之间的变换：$(1,2)\to(2,3)\to(3,5)$，看起来是 $(m,n)\mapsto(n,m+n)$。反过来就是 $(m,n)\mapsto(n-m,m)$。先验证这个逆变换确实保持“$E$ 的平方为 $1$”：

**引理 1（变换 $T(m,n)=(n-m,m)$ 只把 $E$ 变号）**
$$
E(n-m,m)=m^2-(n-m)m-(n-m)^2=-(n^2-mn-m^2)=-E(m,n).
$$

**证明**：展开
$$
\begin{aligned}
E(n-m,m)
&=m^2-(n-m)m-(n-m)^2\\
&=m^2-nm+m^2-(n^2-2nm+m^2)\\
&=m^2+nm-n^2\\
&=-(n^2-mn-m^2).
\end{aligned}
$$
$\blacksquare$

所以 $|E|=1$ 在 $T$ 下保持不变。接下来要保证 $T$ 把解送到“更小且仍为正”的解。

**引理 2（$m\ge2$ 时解必满足 $m<n<2m$）**

设 $m\ge2$ 且 $E(m,n)=\pm1$。

1. 若 $n\le m$，则 $n^2\le mn$，于是
   $$
   E(m,n)=n^2-mn-m^2\le -m^2\le -4,
   $$
   不可能等于 $\pm1$。故 $n>m$。
2. 若 $n\ge2m$，则
   $$
   E(m,n)=n^2-mn-m^2\ge4m^2-2m^2-m^2=m^2\ge4,
   $$
   也不可能等于 $\pm1$。故 $n<2m$。

**证明**：上面的不等式已经给出了两个方向的矛盾；注意 $E$ 在第二种情形下是正数且大于 $1$，也不可能等于 $-1$。$\blacksquare$

于是当 $m\ge2$ 时，$m'=n-m$ 满足
$$
1\le m'<m,
$$
而 $n'=m$ 显然满足 $n'<n$。也就是说：

**引理 3（递降终止）**：从任意解 $(m,n)$（$m\ge2$）出发，反复做 $T$，第二个坐标严格减小，故必在有限步后到达 $m=1$ 的解。

**证明**：每次 $T$ 后新的第二坐标等于旧的 $m$，而旧解满足 $n>m$，故新第二坐标 $<n$。正整数严格递减不可能无限进行。终止时只能是因为 $m=1$（$m\ge2$ 时引理 2 保证还能继续做 $T$）。$\blacksquare$

### 2.3 基例与完整分类

**引理 4（$m=1$ 的解只有 $(1,1)$ 与 $(1,2)$）**

$E(1,n)=n^2-n-1$。令其等于 $1$：
$$
n^2-n-2=0\Longrightarrow(n-2)(n+1)=0\Longrightarrow n=2.
$$
令其等于 $-1$：
$$
n^2-n=0\Longrightarrow n(n-1)=0\Longrightarrow n=1.
$$
正整数解恰为 $n=1,2$。$\blacksquare$

现在反向看递降链。$T^{-1}(m',n')=(n',m'+n')$。从基例出发：

$$
(1,1)\xrightarrow{T^{-1}}(1,2)\xrightarrow{T^{-1}}(2,3)\xrightarrow{T^{-1}}(3,5)\xrightarrow{T^{-1}}(5,8)\to\cdots
$$

这正是 Fibonacci 链。由引理 1，链上每个元素都满足 $|E|=1$；由引理 3，任何解递降后必落在基例上，而基例 $(1,2)$ 本身也在从 $(1,1)$ 出发的链上。因此：

**定理**：正整数解集恰为
$$
(m,n)=(F_i,F_{i+1}),\quad F_1=F_2=1,\ i\ge1.
$$

### 2.4 怎么选最大值

**引理 5（沿链 $m^2+n^2$ 严格递增）**

链的下一步是 $(n,m+n)$。由于链上恒有 $m\le n$，所以新坐标 $n\ge m$、$m+n\ge n$，两个坐标都不减且至少一个严格增，故
$$
n^2+(m+n)^2>m^2+n^2.
$$
$\blacksquare$

于是只需生成链，取**最后一个满足 $n\le k$ 的元素**。因为链上 $m\le n$，此时自动有 $m\le k$。

- 若 $k=1$：只有一个合法元素 $(1,1)$。
- 之后每次检查下一项的 $n$（即 $a+b$）是否仍 $\le k$，是则前进。

$F_{40}=102334155>10^8$，所以循环不超过 $40$ 次。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 手算小解，发现解恰为相邻 Fibonacci 数对。
- **prove by descent** — 用 $(m,n)\mapsto(n-m,m)$ 保持 $|E|=1$ 并把解变小，归纳到 $m=1$ 的基例。
- **classic problem solution** — 生成 Fibonacci 链，取满足上界的最后一项。
- **pitfall** — $k=1$ 时答案是 $(1,1)$；链上两个坐标同时不减，才能说“最后一对”就是最优。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `k` | `i64` | 上界 | 读入 | 约束 $10^8$ |
| `a` | `i64` | 当前对的 $m$ | $1$ | 链的前一项 |
| `b` | `i64` | 当前对的 $n$ | $1$ | 链的后一项 |

### 4.2 算法步骤

1. 读入 $k$。
2. 令 $a=1,b=1$。
3. 当 $a+b\le k$ 时，令 $(a,b)\leftarrow(b,a+b)$。
4. 输出 $a$，换行，输出 $b$。

### 4.3 复杂度分析

- 时间 $O(\log k)$（Fibonacci 增长，$\le40$ 轮）。
- 空间 $O(1)$。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	i64 k;
	cin>>k;
	i64 a=1,b=1;
	while(a+b<=k)
	{
		i64 c=a+b;
		a=b;
		b=c;
	}
	cout<<a<<'\n'<<b<<'\n';
	return 0;
}
```
