# P1122 最大子树和 — 题解报告

---

## 一、重新阅读问题（Re-read the problem）

**题目大意**：给定一棵 $n$ 个节点的无根树，每个节点 $i$ 有权值 $a_i$（可正可负，绝对值可达 $10^9$）。操作定义为：每次选择一条枝条（边）剪掉，植株分裂为两株，扔掉其中一株。可以反复进行任意次操作（也可以一次都不做），最终必须剩下恰好一株花（连通块，至少包含一朵花）。求最终剩下那株花上所有节点权值之和的最大值。

**输入**：$n$，$n$ 个权值 $a_1\cdots a_n$，$n-1$ 条边 $(a,b)$。

**输出**：一个整数，即最大可能和。保证答案绝对值不超过 $2^{31}-1$，但中间结果可能超过 32 位。

**数据范围**：$n\le 16000$，$|a_i|\le 10^9$。

**关键观察**：

1. 剪枝后剩下的部分一定是原树的一个 **连通子图**（连通导出子图）。因为每次剪掉一条边并丢弃一侧，保留的部分始终连通。
2. 反过来，**任意连通子图都可以通过若干次剪枝得到**：把子图内部边全部保留，把子图与外部相连的边全部剪断并丢弃外部即可。
3. 因此问题等价于：在树中找一个连通子图，最大化其点权和。

---

## 二、思维链与完整证明（Chain-of-thought with full proofs）

### 2.1 树形 DP 的动机

在树上找一个连通子图最大化点权和，是一个典型的「树上最大连通块」问题。树是分层结构，自然想到 **树形 DP**：将树无根化后任选一个根（不妨选节点 $1$），对每个子树递归求解。

### 2.2 DP 状态设计

对每个节点 $u$，定义：

$$
dp[u] = \text{在 } u \text{ 的子树中，包含 } u \text{ 的连通子图的最大点权和}
$$

为什么这样定义？因为我们关注的最终连通子图 $C$ 在固定根之后，一定有一个 **深度最小的节点**（即最靠近根的节点），记为 $u_0$。那么 $C$ 必然完全包含在 $u_0$ 的子树中，且包含 $u_0$ 本身。所以 $C$ 的权值和就是某个 $dp[u_0]$。全局最优解就是 $\max_u dp[u]$。

### 2.3 DP 转移方程

考虑节点 $u$ 和它的某个子节点 $v$（$v$ 在以 $u$ 为根的树中是 $u$ 的儿子）。

- 如果 $C$ 包含了 $u$，那么对于子节点 $v$ 的子树，$C$ **要么完全不取** $v$ 子树中的任何节点，**要么取一部分**。若取 $v$ 子树中的节点，由于 $C$ 要求连通且 $u$ 已在其中，进入 $v$ 子树的唯一路径是边 $(u,v)$，因此 $v$ 必须被包含。此时 $C$ 在 $v$ 子树中的部分，恰好是一个 **包含 $v$ 的连通子图** —— 这正是 $dp[v]$ 的定义。

- 于是，$C$ 包含 $u$ 时，对每个子节点 $v$，可获得的额外贡献为 $\max(0, dp[v])$。因为如果 $dp[v] \le 0$，加进来只会拉低总和，不如不取。

得到转移方程：

$$
dp[u] = a_u + \sum_{v \in \text{children}(u)} \max(0,\, dp[v])
$$

**叶子节点**：没有子节点，$dp[u] = a_u$。

### 2.4 正确性证明

**归纳基础**：对于叶子节点 $u$，子树中只含 $u$ 自己。包含 $u$ 的连通子图只有 $\{u\}$ 本身，最大和为 $a_u$，与 DP 一致。

**归纳步骤**：假设对于 $u$ 的所有子节点 $v$，$dp[v]$ 已正确计算。考虑任意一个在 $u$ 的子树中且包含 $u$ 的连通子图 $C$。对每个子节点 $v$：

- 若 $C \cap \text{subtree}(v) = \varnothing$，贡献为 $0$；
- 否则 $C \cap \text{subtree}(v)$ 是 $\text{subtree}(v)$ 中包含 $v$ 的连通子图，其最大可能和为 $dp[v]$（由归纳假设），而 $C$ 在 $\text{subtree}(v)$ 中的部分不可能超过 $dp[v]$。

由于各子树的决策互相独立（连通性唯一依赖 $u$ 作为枢纽），对每个子节点取 $\max(0, dp[v])$ 即得全局最优。故转移方程正确。

**全局最优性**：对根节点 $1$ 做完 DFS 后，任意连通子图 $C$ 的最高节点（深度最小）记作 $u$，则 $C$ 包含于 $\text{subtree}(u)$ 且包含 $u$，故 $C$ 的和 $\le dp[u] \le \max_i dp[i]$。反之，对使 $dp[u]$ 最大的 $u$，其 DP 值对应的子图即为一个合法连通子图。故答案为 $\max_u dp[u]$。

**时间复杂度**：$O(n)$，每个节点和每条边各访问一次。

**空间复杂度**：$O(n)$，存储邻接表和 DP 数组。

## 三、模式总结（Pattern summary）

| 模式 | 说明 |
|------|------|
| **树上最大连通权值和** | 任选根，树形 DP：$dp[u] = a_u + \sum_{v\in\text{children}(u)} \max(0, dp[v])$，答案是 $\max_u dp[u]$ |
| **核心思想** | 对每个子树，只保留对其父节点"有正贡献"的部分（$\max(0,\cdot)$ 裁剪负子树） |
| **拓展应用** | 类似地，树上最大权独立集、树上最大权路径等问题也常用 $\max(0,\cdot)$ 裁剪负贡献 |
| **复杂度记法** | $O(n)$ DFS 一遍即可，无额外开销 |

## 四、正式解法与符号表（Real solution with notation glossary）

### 4.1 算法流程

1. **建图**：读入 $n$，读入权值数组 $a[0..n-1]$。读入 $n-1$ 条边，建立邻接表。
2. **DFS**：任选根节点 $0$（或 $1$），进行 DFS，对每个节点 $u$：
   - 初始化 $dp[u] = a[u]$；
   - 遍历所有子节点 $v$（避开父节点 $p$），对每个子节点递归后：
     - 若 $dp[v] > 0$，则 $dp[u] \gets dp[u] + dp[v]$。
3. **求答案**：取 $\max_{0\le i<n} dp[i]$ 并输出。

### 4.2 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 节点数 |
| $a_u$ | 节点 $u$ 的美丽指数（权值） |
| $dp[u]$ | 在 $u$ 的子树中，包含 $u$ 的连通子图的最大点权和 |
| $\text{subtree}(u)$ | 以 $u$ 为根的子树 |
| $\text{children}(u)$ | $u$ 的子节点集合（DFS 树中） |
| $C$ | 最终保留的连通子图 |
| $p$ | DFS 过程中的父节点（用于防止往回走） |

### 4.3 边界与易错点

- 答案可以是负数（当所有 $a_i < 0$ 时，最优解是选一个最大的 $a_i$，即 $\max a_i$）。DP 会正确处理：所有 $dp[v] \le 0$ 时不加，$dp[u] = a_u$，最终 $\max dp[i] = \max a_i$。
- 必须用 $\text{long long}$（64 位整数）：$n\le 16000$，$|a_i|\le 10^9$，最坏情况 $16000\times 10^9 = 1.6\times 10^{13}$ 超出 32 位。
- 题目保证答案绝对值 $\le 2^{31}-1$，但 DP 中间结果可能更大（实际上如果所有值都为正，中间结果会很大）。
- 树是无向的，DFS 时需要传父节点参数防止死循环。

## 五、示例代码（Example code）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{16005};

int n;
i64 a[mxn];
i64 dp[mxn];
vector<int> g[mxn];

void dfs(int u,int p)
{
	dp[u]=a[u];
	for(int v:g[u])
	{
		if(v==p)
			continue;
		dfs(v,u);
		if(dp[v]>0)
			dp[u]+=dp[v];
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
		cin>>a[i];
	for(int i=1;i<n;++i)
	{
		int u,v;
		cin>>u>>v;
		--u;--v;
		g[u].push_back(v);
		g[v].push_back(u);
	}

	dfs(0,-1);

	i64 ans=dp[0];
	for(int i=1;i<n;++i)
		if(dp[i]>ans)
			ans=dp[i];

	cout<<ans<<'\n';

	return 0;
}
```

### 代码说明

| 部分 | 说明 |
|------|------|
| `mxn{16005}` | $n\le 16000$，$+5$ 安全余量，统一用花括号初始化 |
| `a[mxn]`, `dp[mxn]` | 全局数组，自动零初始化 |
| `vector<int> g[mxn]` | 邻接表，无向图存两次 |
| `dfs(0,-1)` | 以节点 $0$ 为根，父节点为 $-1$ |
| `--u;--v` | 输入转 0-based |
| `ans=dp[0]; ... ans=max(ans,dp[i])` | 取全局最大值 |
| `cout<<ans<<'\n'` | 用 `'\n'` 而非 `endl` |
