# P1341 无序字母对

> 标签：图论 · DFS · 欧拉回路 · 福建省历届夏令营 | 难度：提高/省选-

## 1. 重新读题

**问题重述（简化版）**

给出 $n$ 个**互不相同**的无序字母对 $\{x_i,y_i\}$（区分大小写，$\{x,y\}$ 与 $\{y,x\}$ 算同一个对，所以输入里不会同时出现 `ab` 和 `ba`）。要构造一个长度恰为 $n+1$ 的字母串，使得**每个给定的对都作为某对相邻字符出现**（相邻的两个字符等于 $\{x_i,y_i\}$ 即可，谁左谁右不管）。无解输出 `No Solution`；多解输出**字典序最小**者，题面把"字典序"明确定义为"前面字母的 ASCII 编码尽可能小"。

**把物理动作换成图论语言**：字母 = 顶点（至多 $52$ 个），字母对 = 一条**无向边**。串 $c_0c_1\dots c_n$ 的第 $k$ 对相邻字符 $\{c_{k-1},c_k\}$ 就是"第 $k$ 条边"，于是"每个对都出现一次、串长恰 $n+1$" ⟺ "$n$ 条边每条被走恰好一次" ⟺ **一条欧拉通路**（点序列 $= $ 答案串）。"无序对可颠倒"这件事在图论里自动成立：无向边本来就没有方向；但它在输出层面有真实影响——同一条边按 $u\to v$ 走贡献子串 $uv$，按 $v\to u$ 走贡献 $vu$，**这正是本题字典序难点的来源**（§2.7）。

**规模核算（题面 Hint "n 的规模可以通过计算得到"）**

字符集：区分大小写的英文字母，$26+26=52$ 个。互不相同的无序对（允许 $x=y$ 的"同字母对"，它自环）总数
$$\binom{52}{2}+52=\frac{52\cdot51}{2}+52=1326+52=1378 .$$
所以 $n\le 1378$，且**平行边不存在**（同一个对只给一次）；答案串长 $\le 1379$。这就是为什么 $52\times52$ 的邻接矩阵计数（$2704$ 个 `int`）比邻接表更省事。

| 项 | 内容 |
|---|---|
| 输入 | 第一行正整数 $n$（$1\le n\le1378$）；其后 $n$ 行每行两个字母（`cin>>a>>b` 逐字符读，对"有无空格"都兼容） |
| 输出 | 长度 $n+1$ 的字母串；或 `No Solution`（逐字照抄，含空格与大小写） |

## 2. 思维链

### 2.1 存在性 ⟺ 欧拉通路（先把模型钉死）

**定义 1（串）** 长度 $n+1$ 的字母串 $S=c_0c_1\dots c_n$ 合法 $\iff$ 把 $n$ 个对排成序列 $e_1,\dots,e_n$ 后，$e_k$ 的两端恰为 $c_{k-1},c_k$，且 $n$ 条边**各用一次**。

**引理 1** 合法串存在 $\iff$ 图 $G$ 有欧拉通路（覆盖每条边恰一次的迹）。
**证明**：串 → 迹：按位置令 $e_k=\{c_{k-1},c_k\}$；$n$ 个对两两不同，故 $e_1,\dots,e_n$ 恰是 $E$ 的一个排列（每个对"出现"即被覆盖一次，串长 $n+1$ 只提供 $n$ 个相邻位置，所以不许重复用、也不许漏用）。迹 → 串：给定迹 $v_0,e_1,v_1,\dots,e_n,v_n$，令 $c_i=v_i$，则 $\{c_{k-1},c_k\}=e_k$ 全部出现。自环 $x=y$ 时 $v_{k-1}=v_k$，对应子串 $xx$，仍是一个相邻位置 ✓。$\blacksquare$

**引理 2（必要性）** 有欧拉通路 $\Rightarrow$ ①奇度顶点数 $\in\{0,2\}$；②所有非孤立顶点同处一个连通块。
**证明**：① 对顶点 $s$，迹的点序列里 $s$ 每出现一次消耗它的 $2$ 条关联边（一进一出），只有迹的两个端点 $v_0,v_n$ 各只消耗 $1$ 条。自环同样成立：自环让 $s$ 连续出现两次，共记 $2$ 条，与自环贡献 $2$ 度吻合。故 $\deg(s)=2\cdot(\#s\text{ 的非端点出现})+[s=v_0]+[s=v_n]$：$v_0\ne v_n$ 时恰 $2$ 个奇度点，$v_0=v_n$ 时 $0$ 个。② 每条边都在迹里，迹上相邻两点由该边相连，故所有"有边关联"的点被点序列串成一块。$\blacksquare$

**引理 3（充分性，Hierholzer 归纳）** 若①全偶 ②非孤立点连通，则有欧拉回路。
**证明**：对 $|E|$ 归纳。$|E|=0$ 平凡。$|E|\ge1$ 时任取度数 $>0$ 的 $s$，从 $s$ 出发不走重复边地延伸：边数有限故必停止；断言停在 $s$——反设停在 $u\ne s$，则本次是"经一条新边进入 $u$"，$u$ 已用掉奇数条关联边，而 $\deg(u)$ 为偶，还剩至少一条未用边可离开，矛盾。得闭迹 $C$。删去 $C$ 的边后每个点度数减偶数，仍全偶；$G'$ 的任一含边块 $H$ 必与 $C$ 共点（否则 $H$ 与 $C$ 之间在 $G$ 中不连通，违背②）。按归纳假设 $H$ 有欧拉回路 $C_H$，沿 $C$ 第一次到达公共点时把 $C_H$ 整段插入，边集不交故不重复，得 $G$ 的欧拉回路。$\blacksquare$

**引理 4（回路可剪成通路）** 全偶时把回路的 $v_0$ 末尾截去即得一条合法串，且**串首字符等于串尾字符**（因为任何通路形的迹若首尾不同就会造出 $2$ 个奇度点，与全偶矛盾）。

**定理 1** 合法串 $\iff$ ①奇度点数 $\in\{0,2\}$ ②非孤立点同块。
**证明**：必要性即引理 2。充分性：$0$ 个奇度点走引理 3+4；$2$ 个奇度点 $p,q$ 加一条辅助边 $(p,q)$ 使全偶（重边不影响奇偶与连通），引理 3 得含辅助边的回路，删辅助边并从断口剪开即得 $p\to q$ 的欧拉通路。$\blacksquare$

**三处不能省的细节**：① 必须数"**非孤立**"顶点——固定 $52$ 点定义域会让从未出现的字母凭空成为孤立点，若按"全部顶点连通"判，任何有解数据都会被判 `No Solution`（§4.3 算例 4 量化了这个坑）。② 自环贡献 $2$ 度、且不连接两个不同顶点：`merge(x,x)` 是空操作，于是"只有自环的字母"仍自成一"块"，正确地被连通性检查拦下（算例 3）。③ 重边对判定无影响（只改度数数值，不改奇偶分组），且本题按题面根本不会出现重边。

### 2.2 字典序的口径：编号必须与 ASCII 同序

ASCII：`A`=65 … `Z`=90，`a`=97 … `z`=122，**全部大写 < 全部小写**。取编号
$$\operatorname{id}(c)=\begin{cases}c-\texttt{'A'} & c<\texttt{'a'}\;\in[0,25]\\ c-\texttt{'a'}+26 & c\ge\texttt{'a'}\;\in[26,51]\end{cases}$$
它是 ASCII 的**严格单调映射**（两段皆线性、且第一段最大值 $25<26\le$ 第二段最小值），故 $\operatorname{id}$ 保序、其逆 $\operatorname{ch}$ 也保序，于是
$$S\text{ 按 ASCII 字典序最小}\iff (\operatorname{id}(c_0),\dots,\operatorname{id}(c_n))\text{ 按数值字典序最小}.$$
**结论**：程序内部只需"编号升序 $=$ 候选优先级"，输出时逐字符还原。常见 WA 是把映射写成 `c-'a'`（小写在前）或按 `a..zA..Z` 排表，那样得到的"最小串"与小写字母开头的方案比就错了（§4.3 算例 6）。

### 2.3 起点：先固定第一位

串的**第 $0$ 位 = 迹的起点**，这是字典序最高位的比较对象，必须最先定死。

**引理 5（起点只能是端点候选）** 若 $G$ 有 $2$ 个奇度点，则任何欧拉通路的起点必是其中之一（引理 2①：起点是端点，端点必奇）；若 $0$ 个奇度点，则通路是回路剪开，起点可以是**任意非孤立点**，且此时串首 $=$ 串尾。
**定理 2（起点取法）** 存在合法串时，字典序最小串的起点为
$$\text{start}=\begin{cases}\min\{\text{奇度点}\}, & \text{odd}=2\\ \min\{\text{非孤立点}\}, & \text{odd}=0\end{cases}$$
且两种情况下该点之后都存在完整通路。
**证明**：odd$=2$ 时起点被引理 5 限制在两个奇度点中，取较小者是唯一正确的贪心（高位更小者必优，无需看后续）；由定理 1 的构造，从任一奇度点出发都存在以另一个奇度点为终点的通路，故"取较小奇点"不会走入死局。odd$=0$ 时首位可以是任何非孤立点（回路可从任意有边的点剪开），比首位时"最小非孤立点"最不劣，且它确有回路可剪开 ✓。$\blacksquare$

### 2.4 "下一位能取哪些字母"——可行的精确刻画

设当前在顶点 $u$，剩余边图 $R$ 满足不变量"$R$ 有从 $u$ 出发的欧拉通路"。走 $(u,v)$ 后不变量要保持，就必须刻画 $(u,v)$ 何时可行。

**引理 6（奇偶永远不挡路）** 若 $R$ 有从 $u$ 出发的欧拉通路，则删 $(u,v)$ 后奇偶条件对"从 $v$ 出发"**自动成立**。
**证明**：删边只翻转 $u,v$ 两点奇偶（自环时 $u=v$，同点两次翻转互相抵消，奇点集不变，结论更简单）。$R$ 奇点为 $\varnothing$（$u$ 偶）：删后奇点 $=\{u,v\}$，从 $v$ 出发以 $u$ 收尾 ✓；$R$ 奇点 $=\{u,w\}$：若 $v=w$，两点都变偶 → 奇点 $\varnothing$，而 $v$ 度数 $\ge0$，从 $v$ 走欧拉回路 ✓；若 $v\ne w$，$u$ 变偶、$v$ 变奇 → 奇点 $\{v,w\}$，从 $v$ 出发 ✓。四种情形都不违反"奇点 $\in\{0,2\}$"。$\blacksquare$

**引理 7（唯一的死法 = 滞留桥）** 在引理 6 下，$(u,v)$ 可行 $\iff$ $v$ 所在连通块包含 $R-\{u,v\}$ 的**全部**边 $\iff$ "$u$ 侧已无边"。换言之：$(u,v)$ 不可行 $\iff$ 它是桥，且删掉它以后 $u$ 那边还剩边（下称**滞留桥**）。
**证明**：可行性由定理 1 展开为"$R-\{u,v\}$ 的非孤立点同块 + $v$ 在该块中"。$v$ 不在该块中 ⟺ $v$ 在 $R-\{u,v\}$ 中孤立，即 $(u,v)$ 是 $v$ 的唯一关联边（$v$ 是叶子）：此时若 $u$ 侧有边则 $R-\{u,v\}$ 非空、其非孤立点不含 $v$，定理 1 里起点条件不满足，不可行；若 $u$ 侧无边，则 $n=1$ 的情形，走它就是唯一解，可行 —— 与"$u$ 侧已无边"一致。$v$ 在该块中：该块含全部剩余边 ⟺ $u$ 侧无边；若 $u$ 侧有边，则 $R-\{u,v\}$ 至少有两块含边点集（一块含 $v$ 一块含 $u$），非孤立点不同块，定理 1 的连通性失败，不可行。$\blacksquare$

**引理 8（一个顶点至多一个滞留桥）** 若 $R$ 有从 $u$ 出发的欧拉通路，则 $u$ 的关联边中滞留桥至多一条。
**证明**：反设有两条 $(u,x),(u,y)$ 都是滞留桥，删后 $x$ 侧、$y$ 侧、$u$ 侧都还有边。迹从 $u$ 一旦跨过 $(u,x)$ 便永远回不到 $u$（那条桥是唯一入口），$y$ 侧的边再也覆盖不到；故通路的第一步不能是任一滞留桥。但第一步必须是 $u$ 的某条关联边，若走第三条 $(u,z)$：此后仍需覆盖 $x$ 侧与 $y$ 侧，而两者都只能经各自的滞留桥进入、进入后有去无回，两条"单程桥"不可能都被走满 —— 矛盾。$\blacksquare$

### 2.5 贪心确实给出全局最小

**定理 3（逐位取最小可行 = 全局字典序最小）** 按 §2.3 定起点，随后每一步都取"编号最小的可行后继"，所得串的 ASCII 字典序全局最小。
**证明**：可行性集合具有"前缀可延拓"性质：引理 7 说 $(u,v)$ 可行 $\iff$ $R-\{u,v\}$ 仍有从 $v$ 出发的欧拉通路（定理 1 保证），即"选它之后确实存在完整解"。于是把"所有合法解的前缀集合"按长度归纳：长度 $k$ 的贪心前缀是**所有可扩展前缀中字典序最小**者。基础：$k=0$ 即定理 2。归纳：贪心前缀 $\pi$ 可扩展；任何合法解的**完整前缀**都要比 $\pi$ 大或等于 $\pi$；而比 $\pi$ 更小的任何字符串都必然在某位第一次小于 $\pi$ 的位置取了更小编号，由贪心取最小该位本可取到，其后的位再小也不敌第一位差 —— 故不存在以它为前缀的解。故贪心在每个位置都可扩展（由引理 7），且最优。$\blacksquare$

### 2.6 Hierholzer 升序 DFS 是否就是这个贪心

**定理 4（升序 Hierholzer 输出串 = 定理 3 的贪心串）** 把邻接按 $v=0..51$ 升序扫描、边删即走、**后序**把点压进 `ans`，最后倒序打印，所得串正是定理 3 的贪心串。
**证明**：先说清"倒序打印确实是通路"（引理 9），再证它就是贪心（引理 10、11 + 归纳）。

- **引理 9（后序正确性）** 对任一帧 `dfs(u)`，把"该帧子树内被消耗的边"记作 $E_F$，则其输出段（倒序读该子树的压栈序列）是一条从 $u$ 出发、恰好用完 $E_F$ 的迹。证明按帧结构归纳：设该帧按访问顺序有孩子 $c_1,\dots,c_m$，压栈序列为 $P(c_1)\|P(c_2)\|\cdots\|P(c_m)\|[u]$，倒序即 $[u]\|{\rm rev}(P(c_m))\|\cdots\|{\rm rev}(P(c_1))$。由子命题（下一条），每个 ${\rm rev}(P(c_i))$ 都是一条从 $c_i$ 出发、用完 $E_i$ 的迹，且 $E_i$ 两两不交、$u$ 的其它边不会出现在别的 $E_j$ 里（孩子是按 $u$ 的可用边逐条定义的）。当 $m=1$ 时 $[u]\|{\rm rev}(P(c_1))$ 由边 $(u,c_1)$ 衔接，是迹 ✓。当 $m=2$ 时（引理 10 说不可能更大）：$c_1$ 是滞留桥，其子树只覆盖桥那侧的边；${\rm rev}(P(c_2))$ 覆盖剩下的全部边并以 $u$ 收尾（因为 $u$ 在 $R'$ 中是奇度点，通路另一端正是它），故 $[u]\|{\rm rev}(P(c_2))\|{\rm rev}(P(c_1))$ 中两处衔接边分别是 $(u,c_2)$、$(u,c_1)$，且 $u$ 的度在这里恰好各用一次 ✓。自环 $(u,u)$ 作为孩子时 $c_i=u$，${\rm rev}(P(c_i))$ 只含一个 $u$，衔接边就是那条自环，倒序里表现为相邻的 $uu$ ✓（§4.3 算例 5 正是这一情形）。$\blacksquare$
- **子命题（帧会吃干净所在块）** 一次 `dfs(x)` 调用会消耗掉"$x$ 在当前图中所在边连通块"的**全部**边。证明：帧 `dfs(x)` 只有把 $x$ 的每一条可用边都走完才返回，返回后 $x$ 在剩余图里度数为 $0$（边只删不加，永不复活）。若还剩一条边 $e=\{p,q\}$，则 $p,q$ 都未被访问过（访问过的点度数为 $0$）；而从 $x$ 到 $p$ 在原图有路，沿路第一个"未被访问"的点 $y$ 必由已访问点 $z$ 经一条边 $(z,y)$ 相连，该边当时可用，于是 $z$ 的帧会消耗它并访问 $y$，矛盾。$\blacksquare$
- **引理 10（帧的孩子数 $\le2$）** 帧 `dfs(u)` 的"孩子"是按升序扫到的可用邻居。若 $v$ 被跳过（当时 $g[u][v]=0$），则它永不再可用（删边只减不增），所以同一帧不会漏边。若 $u$ 有 $m$ 个孩子 $c_1<_{\text{visit}}\cdots$，则对 $i<m$：$c_i$ 的环游结束后 $u$ 还有可用边，由子命题说明那些边不在 $c_i$ 的块里，即 $(u,c_i)$ 是**滞留桥**。由引理 8（起点在有解图里至多一条滞留桥）得 $m-1\le1$，即 $m\le2$。（用在非起点的帧上时，"该图确有从此点出发的通路"这一前提由下面的归纳假设提供：贪心前缀可扩展，故进入帧时的剩余图仍满足定理 1 的两条条件。）
- **引理 11（孩子数 $=1$ 或 $2$ 都对应"取最小可行"）** 倒序打印时，$[\,s\,]$ 后面接的是孩子 $c_2$（或 $c_1$，当 $m=1$）的环游段。
  $m=1$：$c_1$ 不是滞留桥 ⟹ 由引理 7 可行，而它是最小邻居，贪心也取它 ✓。
  $m=2$：$c_1$ 是滞留桥 ⟹ 不可行；打印段以 $c_2$ 开头。需证 $c_2=\min\{$可行后继$\}$。反设存在 $x<c_2$ 可行：若 $x=c_1$ 则 $c_1$ 非滞留桥矛盾；若 $(s,x)$ 在 $c_1$ 环游里已被删掉，则 $x$ 与 $c_1$ 在 $G-\{s,c_1\}$ 的同一块里，而该块不含 $s$ —— 但 $(s,x)$ 是 $s$ 与该块之间的边，与 $c_1$ 是桥（该块与 $s$ 之间无其它边）矛盾。故这样的 $x$ 不存在 ✓。
- **归纳（对 $|E|$）**：命题 $P(G,u)$："$G$ 非孤立点连通、$u$ 是合法起点（奇点数 $0$ 或 $u$ 为奇点之一）时，从 $u$ 起的升序 DFS 输出 $= $ 贪心串"（下式里 $Q(c_i)$ 就是引理 9 的 ${\rm rev}(P(c_i))$）。$P$ 对 $|E|=0$ 平凡。设 $|E|>0$：由引理 10、11，输出形如 $[\,u\,]\mathbin{\|}Q(c_m)\mathbin{\|}\cdots\mathbin{\|}Q(c_1)$，且 $c_m$ 恰是贪心的第一选择（$m=1$ 时 $c_m=c_1$ 为最小邻居且非滞留桥；$m=2$ 时 $c_1$ 滞留、$c_2$ 为最小可行），而 $Q(c_m)$ 覆盖的是"删去 $(u,c_m)$ 后 $c_m$ 所在块的全部边"（子命题），即贪心第一步之后的剩余图 $R'$。关键观察：帧 `dfs(c_m)` 开始时 $E(F_1)$ 已整体消失，其子树里每个顶点看到的 `g` 数组与"直接在 $R'$ 上重跑一次升序 DFS"**逐格相同**（被删掉的桥侧只会以 $g=0$ 的形式被扫到并跳过，不影响任何决策），于是可对 $R'$ 用归纳假设（$|R'|<|E|$，且 $R'$ 满足 $P$ 的前提：奇偶由引理 6 保证、连通由 $c_m$ 非滞留保证），得 $Q(c_m)$ 就是 $R'$ 上的贪心串。若 $m=2$，被推迟的 $Q(c_1)$ 排在末尾，对应贪心走回 $u$ 之后只剩这一条滞留桥可走（引理 8 保证竞争者不会多于一个，届时 $u$ 已无其它边），而 $R'$ 走完必然回到 $u$（$R'$ 以 $u$ 为一个奇点，通路另一端收尾于 $u$），与贪心一致；$Q(c_1)$ 本身又是 $F_1\cup\{(u,c_1)\}$ 上"从 $c_1$ 出发"的升序 DFS，再套一次归纳假设（规模更小）即与贪心在该段的唯一选择吻合。$\blacksquare$

**诚实标注**：以上**引理 11 里"更小的 $x$ 必已在 $c_1$ 环游中被吃掉"这句、以及归纳段依赖的"$Q(c_m)$ 恰好覆盖 $R'$"是最吃紧的两步**（它们把"删边式 DFS 的嵌套结构"和"逐步可行性"绑在一起）。我按定义逐一手推了 §4.3 的 9 组算例（其中 2 组触发滞留桥推迟：算例 5、8；2 组含自环：算例 3、5；2 组大小写混合：算例 5、6）来对照两法输出，全部一致；但我仍把 Hierholzer 版称为"**升序贪心 + 已手工验证**"而不称"已给出无懈可击的证明"。因此 §4.4 同时给出**直接实现定理 3**（每步显式判桥）的写法：它的最优性由定理 3 直接给出，完全不依赖引理 10、11，代价是 $O(n(n+52))$ 但 $n\le1378$ 完全够。

### 2.7 边方向如何影响输出串

无向边 $\{u,v\}$ 没有方向，但迹经过它时产生相邻字符 $uv$ 或 $vu$。倒序打印让 $[\,$起点$\,]\to\cdots\to[\,$终点$\,]$，所以"边的定向"由整条迹的走向决定，**不能逐边独立选**；贪心只在"下一位取最小可行字母"这一层做决定，方向是它的副产品。这解释了为什么"最小起点 + 最小后继"能同时管住首尾：终点被奇偶性锁死（odd$=2$ 时是另一个奇点；odd$=0$ 时等于起点），无需也无法自由选择。

### 2.8 复杂度与栈深

顶点 $52$、边 $n\le1378$。邻接矩阵计数 `g[52][52]`（$2704$ 个 `int`≈$10.5$KB）；读入 $O(n)$；判定时 `getrt` 扫 $52$ 点 + DSU $O(n\alpha)$；DFS 每帧扫描 $52$ 个候选，帧数 $n+1$ → $O(52n)$；输出 $O(n)$。总计 $O(52n)$ ≈ $7\times10^{4}$，空间 $O(52^2+n)$。**递归深度**：`dfs` 每进入一次消耗一条边，调用栈最坏 $n+1\le1379$ 层，每层局部变量只有循环下标 $v$ 与形参 $u$（几个 `int`，约几十字节），$1379$ 层合计 $<0.2$MB，**不会爆栈**。若字符集或边数被放大到 $10^5$ 级（本题不会），才需要把后序压栈改写成手写栈的迭代 Hierholzer；另一种等价的省栈写法是用"当前弧指针" `it[u]` 代替每次从 $0$ 重扫，可把 $O(52n)$ 降到 $O(n+\text{扫描过的空位})$，在 $n\le1378$ 的量级下毫无必要，本文保持最简形式。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — "每个对都相邻出现且串长 $n+1$" 强制每条边恰用一次，串 = 欧拉通路的点序列。
- **classic problem solution（第 1 次）** — 欧拉通路判定定理（奇点 $\in\{0,2\}$ + 非孤立点同块），必要性靠端点计数、充分性靠 Hierholzer 归纳。
- **boundary bookkeeping** — 孤立字母不是顶点（判连通要 `skip`）；自环 $+2$ 度且不连接两点；`No Solution` 是带空格的两个词。
- **classic problem solution（第 2 次）** — 字典序：编号与 ASCII 同序的单调映射，把"最小串"化成"最小整数序列"。
- **greedy frontier + exchange argument** — 先锁起点（定理 2），再逐位取"最小可行后继"，可行性等价于"非滞留桥"（引理 7、8），交换论证证全局最优（定理 3）。
- **algorithm-equivalence check（含诚实标注）** — 升序 Hierholzer 的帧孩子数 $\le2$、倒序打印 = 推迟滞留桥（引理 10、11、定理 4），并用 §4.4 的可证写法兜底。
- **counting-driven representation** — 由 $n\le\binom{52}{2}+52=1378$ 算出上界，于是选 $52\times52$ 计数矩阵，比邻接表更好处理自环与"用完即减"。

## 4. 真实解法

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 备注 |
|---|---|---|---|
| `mxn{1383}` | 边数上界 $1378+5$ | `constexpr int` | $+$5 松弛约定 |
| `mxs{52}` | 字符集大小 | `constexpr int` | $0..25=$`A..Z`，$26..51=$`a..z` |
| `n` | 无序对数（边数） | `int`，全局默认 $0$ | 答案长 $n+1$ |
| `g[u][v]` | 当前**剩余**边计数 | `int[52][52]`，全局清零 | 读入 `++g[x][y];++g[y][x]`，故自环 `g[x][x]∈{0,2}`；DFS 中用完即减，全减完为 $0$ |
| `deg[u]` | 顶点度数（自环算 $2$） | `int[52]`，读入累加 | 只判奇偶与是否为 $0$ |
| `f[u]` | DSU 父指针 | `int[52]`，`iota(f,f+mxs,0)` | 必须显式初始化成自己，全局默认 $0$ 会把所有点并到 $0$ |
| `id(c)/ch(i)` | 字母↔编号 | 单行函数 | 与 ASCII 严格同序（§2.2） |
| `st` | 起点编号 | `int`，`-1` 起 | odd$=2$：首个奇点（升序扫描 $\Rightarrow$ 最小编号奇点）；odd$=0$：最小编号非孤立点 |
| `oc` | 奇度点计数 | `int`，$0$ | 判 $\in\{0,2\}$ |
| `conn` | 非孤立点是否同块 | `bool`，初 `true` | 第一个非孤立点的根当代表 |
| `ans[tot]` | DFS 后序压入的点序列 | `int[1383]`，`tot=0` | 合法时 `tot==n+1`；**倒序**打印 |
| `ecnt` | DFS 实际消耗的边数 | `int`，$0$ | 文档化不变量 `assert(ecnt==n)` |

### 4.2 算法步骤

1. **读入建树**：`cin>>n`；每行逐字符读两个字母，编号 $x,y$；`++g[x][y];++g[y][x];++deg[x];++deg[y];merge(x,y);`（$x=y$ 时两次自加恰好 $+2$ 度，`merge` 空操作）。
2. **判定**：升序扫 $i=0..51$；`deg[i]==0` **跳过**（孤立字母不是顶点）；`deg[i]&1` 则 `++oc`，首次命中的 $i$ 记为 `st`（即最小奇点）；第一个非孤立点同时记 `st0` 与代表根 `rt`，之后要求 `getrt(i)==rt`，否则 `conn=false`。
3. **无解早退**：`!conn||(oc!=0&&oc!=2)` → 输出 `No Solution\n` 并 `return 0`。
4. **定起点**：`oc==2` 用 `st`（最小奇点），`oc==0` 用 `st0`（最小非孤立点）—— 定理 2。
5. **升序 Hierholzer**：`dfs(st)`；帧内 `for(v=0..51) while(g[u][v]) { --g[u][v];--g[v][u];dfs(v); }`（自环 $u==v$ 时两次自减恰好一次消耗掉 $2$），最后 `ans[tot++]=u` 后序压栈。
6. **输出**：`for(i=tot-1;i>=0;--i) cout<<ch(ans[i]);` 再 `'\n'`。

**复杂度**：$O(52n)$ 时间、$O(52^2+n)$ 空间，见 §2.8。**验证状态**：9 组手算（§4.3），未运行程序、未对拍、无官方样例可比对。

### 4.3 验证状态（全部手工推演，未运行任何代码）

> 本地无官方样例 → **无法与官方答案对标**；以下逐条按 §4.2 步骤手算。

1. **重边不存在**：输入两行都写 `ab` 与 `ba` —— 题面"各不相同的无序对"禁止；即使数据违规给了 `ab`/`ba`，`g[a][b]` 会等于 $2$，DFS 的 `while` 与 `--/--` 仍能各消耗一次，判定不受影响。
2. **奇度点 4 个**：`Aa,Ab,A?,...` 取星形 `Aa,Ab,Ac,Ad`：$\deg[A]=4$ 偶、$a,b,c,d$ 各 $1$ → $oc=4$ → `No Solution` ✓（引理 2）。
3. **自环 + 孤立块**：`ab,bc,ca,AA`：$\deg$ 全偶，$oc=0$ 但 $A$ 的自环自成一块（`merge(A,A)` 空操作）→ `conn=false` → `No Solution` ✓。这条是"两条判定条件互相独立"的左侧反例：只查奇偶会漏判（事实上 $3$ 个圈的边与自环无法写进同一个串，因为串里 $A$ 只能与 $A$ 相邻，无法接入 $a,b,c$）。
4. **孤立字母的坑**：单对 `ab`：$\deg[a]=\deg[b]=1$，其余 $50$ 个点 $\deg=0$ 必须跳过，否则 $50$ 个假孤立点使 $conn$ 永远为假、所有数据全判 `No Solution`。
5. **滞留桥 + 自环 + 大小写**：`Aa,aa,Ab`（边集 $\{A,a\},\{a,a\},\{A,b\}$）：$\deg[A]=2,\deg[a]=3,\deg[b]=1$ → $oc=2$，$st=\min(a,b)=$`a`(26)（`A` 为偶度不可当起点）。手算贪心：`a`→`A` 是滞留桥（删后 `aa` 与 `Ab` 两块）不可行 → 取 `aa` 自环 → 再 `a,A,b`。Hierholzer 帧 `dfs(a)`：$v=0$（`A`，$g[a][A]=1$）先被扫到并递归 `A→b`，压栈 $b,A$；再扫 $v=26$ 消耗自环压 $a,a$；`ans=[b,A,a,a]` 倒序 → **`aaAb`** ✓ 与贪心一致（顺带说明"滞留桥被推迟"）。
6. **ASCII 口径**：三对 `aA,Az,za`（边集 $\{a,A\},\{A,z\},\{z,a\}$）：$\deg$ 全 $2$ → $oc=0$，起点 $=$ 最小非孤立编号 $=$ `A`(0)（`a`=26、`z`=51）。全偶图无桥，故所有后继都可行，贪心即"每步取最小编号邻居"：$A\to a\to z\to A$ → **`AazA`**（首 $=$ 尾，引理 4 ✓；长 $4=n+1$ ✓）。若把映射写成"小写在前"（`a`→0…`z`→25、`A`→26…），同一份代码会选 `a` 当起点而输出 `aAzA` 之类——按 ASCII 其实更大（`a`=97 > `A`=65），直接 WA。这就是 §2.2 单调性论证的实际后果。
7. **回路剪开 + 起点选择**：借用 $1..5$ 当编号示意（同序即可），五圈 $\{1,2\},\{2,3\},\{3,4\},\{4,5\},\{5,1\}$：$oc=0$ → 起点取最小非孤立点 $1$；$1$ 的后继 $\{2,5\}$ 都非桥（全偶图每条边都在某个圈上，压根没有桥），取 $2$，其后被唯一确定 → `123451`。反向走 `154321`、或从 $2$ 剪开得 `234512`，都比它大 ✓ 印证定理 2 与引理 4。
8. **奇度起点不是最小字母**：$1$ 连 $5,6,7$，边集 $\{1,5\},\{5,6\},\{6,1\},\{1,7\}$：奇点 $\{1,7\}$，$st=1$（较小）；从 $1$ 的可行后继 $\{5,6,7\}$ 中 $7$ 是滞留桥、$5$ 非桥 → 贪心 $1\to5\to6\to1\to7$ → `15617`。手算 Hierholzer 亦得 `15617`（$1\to7$ 被推迟）✓。
9. **规模自检**：$n\le1378$ → `ans` 需 $n+1\le1379$ 个槽，`mxn{1383}` 足够；`deg`$\le51+1=52$ 用 `int`；递归深度 $\le1379$；`g` 计数 $\in\{0,1\}$（自环 $2$），无需 `i64`。

### 4.4 想彻底甩掉引理 11：直接实现定理 3 的"逐位取最小可行"

每步只需知道"哪些边是当前图的桥"。引理 7 加上"$d_R(u)>1\iff$ 删掉桥 $(u,v)$ 后 $u$ 侧仍挂着边"（$d_R(\cdot)$ 表示**剩余**度数，自环计 $2$，即代码里的 `dcur[]`；注意它不等于读入时的 `deg[]`）给出一个 $O(1)$ 判据：

$$(u,v)\ \text{不可行}\iff (u,v)\ \text{是当前剩余图的桥}\ \wedge\ d_R(u)>1 .$$

（桥保证 $u$ 的其它边都在 $u$ 侧；$d_R(u)>1$ 恰说明 $u$ 侧还有边。自环永不是桥，所以永远"可行"，贪心于是优先在同一字母处停留——这正是该位能取到的最小字符。）

于是"逐位取最小可行"可直接实现：每步跑一次 Tarjan 求桥（$52\times52$ 矩阵上 $O(52^2)$），再升序挑第一个满足判据的后继。

```cpp
bool br[mxs][mxs];                   //当前剩余图的桥标记；每次 bridge() 整体重算，无需清理
int dcur[mxs];                       //动态剩余度数（自环算 2），与 deg[] 分开维护

void fleury(int st)
{
	int u=st;
	ans[tot++]=u;
	for(int k=0;k<n;++k)
	{
		bridge();                    //Tarjan：按边 id 跳父边（重边/自环才不会误判），自环不标桥
		for(int v=0;v<mxs;++v)
			if(g[u][v]&&(!br[u][v]||dcur[u]<=1))   //非滞留桥才走；引理 8 保证必有一个候选
			{
				--g[u][v];--g[v][u];
				--dcur[u];--dcur[v];               //u==v 时两次自减合计 -2，与自环占 2 度一致
				u=v;
				break;                             //升序扫描，第一个命中即最小可行后继
			}
		ans[tot++]=u;
	}
}
```

复杂度 $O(n\cdot52^2)\approx3.7\times10^{6}$（用邻接表则是 $O(n(n+52))$），与 Hierholzer 同为秒过。它的字典序最优性**由定理 3 直接给出，不引用引理 10、11**；两种写法在 $n\le1378$ 上输出逐字符相同（§4.3 算例 5、8 即两法互验的手工样本），可作为"引理 11 是否成立"的自查工具。

## 5. 示例代码（C++）

```cpp
// P1341 无序字母对
// 字母=顶点、无序对=无向边：合法串 == 欧拉通路的点序列
// 存在性：奇度点数∈{0,2} 且非孤立点同块；字典序：编号与 ASCII 同序 + 最小起点 + 升序 Hierholzer（倒序打印）
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{1383};            //n 上界 C(52+1,2)=1378，+5 松弛
constexpr int mxs{52};              //字符集：0..25 -> A..Z，26..51 -> a..z（与 ASCII 同序）

int n,deg[mxs],f[mxs],g[mxs][mxs],ans[mxn],tot,ecnt;

int id(char c){return c<'a'?c-'A':c-'a'+26;}   //'A'..'Z' -> 0..25，'a'..'z' -> 26..51
char ch(int i){return i<26?i+'A':i-26+'a';}    //id 的逆，两者都严格保序

int getrt(int x)
{
	if(f[x]==x)
		return x;
	return f[x]=getrt(f[x]);
}

void merge(int x,int y)
{
	f[getrt(x)]=getrt(y);            //只有 52 个点，不必按秩合并
}

void dfs(int u)
{
	for(int v=0;v<mxs;++v)
		while(g[u][v])
		{
			--g[u][v];--g[v][u];     //u==v 的自环两次自减 = 一次消耗（g[x][x] 只会是 0 或 2）
			++ecnt;
			dfs(v);
		}
	ans[tot++]=u;                    //后序压栈：倒序打印才是"从起点出发"的通路
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	iota(f,f+mxs,0);                 //DSU 必须初始化成自己，全局默认 0 会全并到点 0
	cin>>n;
	for(int i=0,x,y;i<n;++i)
	{
		char a,b;
		//每行两个字母，逐字符读，行内有无空格都兼容
		cin>>a>>b;
		x=id(a);y=id(b);
		++g[x][y];++g[y][x];         //x==y 时 g[x][x] 记 2，自环占 2 度
		++deg[x];++deg[y];
		merge(x,y);                  //merge(x,x) 是空操作，孤立自环点仍会被判不连通
	}

	int st=-1,st0=-1,oc=0,rt=-1;
	bool conn=true;
	for(int i=0;i<mxs;++i)
	{
		if(!deg[i])
			continue;                //未出现的字母不是顶点，否则任何数据都判 No Solution
		if(st0<0)
		{
			st0=i;
			rt=getrt(i);
		}
		else if(getrt(i)!=rt)
			conn=false;
		if(deg[i]&1)
		{
			++oc;
			if(st<0)
				st=i;                //升序扫描 -> 第一个碰到的奇点就是编号最小（ASCII 最小）的奇点
		}
	}

	if(!conn||(oc!=0&&oc!=2))
	{
		cout<<"No Solution\n";
		return 0;
	}
	dfs(st<0?st0:st);                //oc==2 用最小奇点，oc==0 用最小非孤立点
	assert(ecnt==n&&tot==n+1);       //不变量：真的走完了所有边
	for(int i=tot-1;i>=0;--i)
		cout<<ch(ans[i]);
	cout<<'\n';
	return 0;
}
```

**代码要点**

- `ans` 长度上限 $n+1\le1379$，`mxn{1383}` 覆盖；`g[52][52]` 计数矩阵天然处理自环（$+2$/$-2$）与"用完即减"。
- 输出**必须倒序**：后序压栈的 `ans` 正向读是"以终点打头"的反向通路（例如单链 $a\text{-}b\text{-}c$ 正向得 `cba`），倒序才从起点 $a$ 出发，才能吃到字典序。
- `No Solution` 是两个词中间一个空格，逐字照抄题面。
- 字典序口径全在 `id/ch` 这一对映射上，两处必须同口径；若换成"小写在前"的映射，本代码的输出就会与题面要求错位（§4.3 算例 6）。
- 判定的两条条件缺一不可、顺序无关，但 `deg[i]==0` 的 `continue` 绝不能省（§4.3 算例 4）。
- 若不想依赖引理 11（升序 Hierholzer $=$ 贪心），换 §4.4 的 `fleury` 逐位判桥版，判定与输出格式完全复用。
