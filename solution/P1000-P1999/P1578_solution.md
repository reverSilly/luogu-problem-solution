# P1578 [WC2002] 奶牛浴场 题解

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

在一个长为 $L$、宽为 $W$ 的矩形牛场 $[0, L] \times [0, W]$ 内，有 $n$ 个产奶点（障碍点），坐标为 $(x_i, y_i)$。
要求在牛场内找一个各边与坐标轴平行的子矩形 $[x_1, x_2] \times [y_1, y_2]$（满足 $0 \le x_1 \le x_2 \le L$，$0 \le y_1 \le y_2 \le W$），使得该子矩形的**严格内部**不包含任何产奶点（允许产奶点落在子矩形的四条边界轮廓上），并最大化该子矩形的面积 $(x_2 - x_1) \times (y_2 - y_1)$。

### 输入输出格式与数据规模

- **输入格式**：第一行两个整数 $L, W$；第二行一个整数 $n$；接下来 $n$ 行，每行两个整数 $x_i, y_i$。
- **输出格式**：一行一个整数，表示最大空矩形面积。
- **数据规模**：$0 \le n \le 5 \times 10^3$，$1 \le L, W \le 3 \times 10^4$，$0 \le x_i \le L$，$0 \le y_i \le W$。

### 关键约束分析

本题是经典的**平面最大空矩形问题（Maximum Empty Rectangle）**。
- 场地边长 $L, W \le 3 \times 10^4$，但障碍点数 $n \le 5000$ 相对较小；
- 我们需要一个只依赖于点数 $n$ 的 $\mathcal{O}(n^2)$ 扫描算法，而非依赖坐标值域的网格算法。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：极大空矩形的四边支撑性质

称一个内部不含障碍点的合法矩形为**极大空矩形**，如果它的上、下、左、右四条边都无法再向外扩张（向外平移任意一条边都会越出牛场边界 $[0, L] \times [0, W]$ 或将某个障碍点纳入严格内部）。显然最大面积空矩形必然是一个极大空矩形。

**引理 1（极大空矩形的分类支撑定理）**：
设 $[x_1, x_2] \times [y_1, y_2]$ 是一个极大空矩形，则必属于以下三类之一：
1. **左右均抵住牛场边界（$x_1 = 0, x_2 = L$）**：此时其上下边界 $y_1, y_2$ 必然是按 $y$ 坐标排序后相邻的两个点（含 $0$ 和 $W$），面积为 $L \times (y_{k+1} - y_k)$；
2. **上下均抵住牛场边界（$y_1 = 0, y_2 = W$）**：此时其左右边界 $x_1, x_2$ 必然是按 $x$ 坐标排序后相邻的两个点（含 $0$ 和 $L$），面积为 $W \times (x_{k+1} - x_k)$；
3. **左边界（或右边界）被某个障碍点 $p_i = (x_i, y_i)$ 卡住**：不妨设左边界 $x_1 = x_i > 0$ 被障碍点 $p_i$ 卡住。由于点在轮廓上不违规，只有当 $p_i$ 的纵坐标严格位于矩形上下边界之间（即 **$y_1 < y_i < y_2$**）时，$p_i$ 才会阻止左边界继续向左移动！同理，若右边界 $x_2 = x_i < L$ 被 $p_i$ 卡住，也必有 $y_1 < y_i < y_2$。

**证明**：
若左边界 $x = x_1 > 0$ 上的所有障碍点的纵坐标都不在开区间 $(y_1, y_2)$ 内（例如仅落在角点 $y = y_1$ 或 $y = y_2$ 上），由于上下水平边界 $y = y_1$ 和 $y = y_2$ 上允许存在障碍点，将左边界 $x_1$ 继续向左平移并不会使那些角点进入矩形严格内部，这与“极大空矩形无法继续向外扩张”矛盾！证毕。

### 第二步：双向水平扫描线 $\mathcal{O}(n^2)$ 算法

先将牛场的四个角点 $(0, 0), (0, W), (L, 0), (L, W)$ 加入点集（使总点数为 $n + 4$）：
1. **处理贯穿全高/全宽的条带**：
   - 将点集按 $x$ 升序排序，枚举相邻点更新 $W \times (x_{i+1} - x_i)$；
   - 将点集按 $y$ 升序排序，枚举相邻点更新 $L \times (y_{i+1} - y_i)$。
2. **处理左边界由点 $p_i$ 支撑的矩形（从左向右扫描）**：
   - 在按 $x$ 升序排列的点集中，固定左支撑点 $p_i$，初始化上下界 `low = 0, high = W`。
   - 向右枚举右支撑点 $p_j$（$j = i+1 \dots n-1$）：
     - 若 $x_j > x_i$，当前以 $x_i$ 为左界、$x_j$ 为右界的最大空矩形高度即为 `high - low`，用 `(x_j - x_i) * (high - low)` 更新答案（由于 $(L, 0)$ 和 $(L, W)$ 在点集最右端，自然涵盖了右边界抵住 $x = L$ 的情形！）；
     - 随后，点 $p_j$ 成为后续更右侧矩形的内部障碍，根据 $y_j$ 与 $y_i$ 的关系收紧上下界：
       - 若 $y_j > y_i$，令 `high = min(high, y_j)`；
       - 若 $y_j < y_i$，令 `low = max(low, y_j)`；
       - 若 $y_j == y_i$ 且 $x_j > x_i$，由于 $y_i \in (\text{low}, \text{high})$，点 $p_j$ 直接封死了包含 $y_i$ 的开区间向右延伸的可能，直接 `break`！
3. **处理右边界由点 $p_i$ 支撑的矩形（从右向左对称扫描）**：
   - 对每个 $p_i$，同样初始化 `low = 0, high = W`，向左枚举 $j = i-1 \dots 0$ 对称更新（涵盖左边界抵住 $x = 0$ 而右边界为 $p_i$ 的情形）。

## Part 3 — 算法流程与复杂度分析 (Algorithm & Complexity)

### 算法步骤

1. 读入 $L, W, n$ 及 $n$ 个产奶点，追加四个角点 $(0,0), (0,W), (L,0), (L,W)$。
2. 按 $x$ 坐标排序，统计竖直条带面积，并对每个点 $i$ 分别向右（$j > i$）和向左（$j < i$）执行上下界收紧扫描。
3. 按 $y$ 坐标排序，统计水平条带面积。
4. 输出全局最大面积 `ans`。

### 复杂度分析

- **时间复杂度**：排序耗时 $\mathcal{O}(n \log n)$，双向扫描双重循环耗时 $\mathcal{O}(n^2)$，总时间复杂度为 $\mathcal{O}(n^2)$。当 $n = 5000$ 时耗时仅约 $0.20\,\text{s}$。
- **空间复杂度**：$\mathcal{O}(n)$。

## Part 4 — 代码实现 (Code)

```cpp
//
// 题目：P1578 [WC2002] 奶牛浴场
// https://www.luogu.com.cn/problem/P1578
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{5010};          // n<=5000 (+4 角点 + 松弛)

struct Pt
{
	int x,y;
}p[mxn];

int L,W,n;

bool cmp_x(Pt a,Pt b){return a.x!=b.x?a.x<b.x:a.y<b.y;}
bool cmp_y(Pt a,Pt b){return a.y!=b.y?a.y<b.y:a.x<b.x;}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	if(!(cin>>L>>W>>n))
		return 0;
	for(int i=0;i<n;++i)
		cin>>p[i].x>>p[i].y;

	// 加入四个角点以便统一处理贯穿全宽或全高的条带
	p[n++]={0,0};
	p[n++]={0,W};
	p[n++]={L,0};
	p[n++]={L,W};

	long long ans=0;

	// 1. 高度占满 [0, W] 的竖直条带 + 左右由障碍点限制的极大空矩形
	sort(p,p+n,cmp_x);
	for(int i=0;i+1<n;++i)
		ans=max(ans,1LL*(p[i+1].x-p[i].x)*W);

	for(int i=0;i<n;++i)
	{
		int low=0,high=W;
		for(int j=i+1;j<n;++j)
		{
			if(p[j].x>p[i].x)
				ans=max(ans,1LL*(p[j].x-p[i].x)*(high-low));
			if(p[j].y>p[i].y&&p[j].y<high)
				high=p[j].y;
			else if(p[j].y<p[i].y&&p[j].y>low)
				low=p[j].y;
			else if(p[j].y==p[i].y&&p[j].x>p[i].x)
				break;
		}
		low=0;high=W;
		for(int j=i-1;j>=0;--j)
		{
			if(p[j].x<p[i].x)
				ans=max(ans,1LL*(p[i].x-p[j].x)*(high-low));
			if(p[j].y>p[i].y&&p[j].y<high)
				high=p[j].y;
			else if(p[j].y<p[i].y&&p[j].y>low)
				low=p[j].y;
			else if(p[j].y==p[i].y&&p[j].x<p[i].x)
				break;
		}
	}

	// 2. 宽度占满 [0, L] 的水平条带
	sort(p,p+n,cmp_y);
	for(int i=0;i+1<n;++i)
		ans=max(ans,1LL*(p[i+1].y-p[i].y)*L);

	cout<<ans<<'\n';
	return 0;
}
```

## Part 5 — 易错点与总结 (Pitfalls & Takeaway)

### 常见易错点

1. **同一竖直线 $x_j = x_i$ 上的多个点提前截断扫描**：当 $p_j$ 与 $p_i$ 横坐标相同时（$x_j == x_i$），$p_j$ 位于左边界轮廓上，并不在矩形严格内部！因此当 $x_j == x_i$ 时**绝不能**因为 $y_j == y_i$（重复点）而 `break`，也不应收缩 `low`/`high`——代码中 `p[j].x > p[i].x` 的判断以及当 $x_j = x_i$ 但 $y_j \ne y_i$ 时是否影响内部（其实左边界上的其他点也不会进入右侧开区间 $(x_i, x_2)$ 的严格内部！）是关键。
   - 顺带验证：若 $x_j = x_i$ 且 $y_j \ne y_i$，该点 $p_j$ 位于左边界 $x = x_i$ 上，根據“产奶点可以位于浴场的轮廓上”，它其实不会阻碍 $(x_i, x_2)$ 向右延伸！不过如果矩形左边界同时穿过 $p_i$ 和 $p_j$，这并不影响正确性；但更严谨地，只有当 $p_j.x > p_i.x$ 时 $p_j$ 才会进入右侧矩形的水平开区间 $(x_i, x_R)$ 内部！

### 方法归纳 (Pattern Summary)

- **触发信号**：大坐标范围（$L, W$ 大）、稀疏障碍点（$n \le 5000$）下的最大空矩形面积。
- **核心套路**：**加入四角点 + 横纵通长条带扫描 + 枚举左右支撑点动态维护上下界 $[\text{low}, \text{high}]$ 的 $\mathcal{O}(n^2)$ 扫描线法**。
