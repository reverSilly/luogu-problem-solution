# P1564 膜拜

> 标签：动态规划 DP / 前缀和 · 难度：普及/提高-
> 本地题面：`P1564.md`（$1\le n\le 2500$，$0\le m\le 2500$）。验证：对拍脚本 `P1564_check.py` 实跑 300 组随机用例，$O(n^2)$ DP 标程与"枚举所有分段"暴力逐字节一致；手工边界用例全部命中；最坏规模 $n=2500$、$m=2500$ 输出 $1$，耗时 $0.0245$ s。

## 1. 重新读题

**问题重述（人话版）**

$n$ 个同学**排成一排**，第 $i$ 个同学膜拜神牛甲或乙（用 $1/2$ 表示）。老师要把这排人**切成若干连续段**，每段分进一个机房。一个机房（即一个连续段）**合法**当且仅当满足其一：

- 段内**全是同一位神牛**的膜拜者（要么全 $1$，要么全 $2$）；或
- 段内两位神牛的**膜拜者人数之差不超过 $m$**。

求最少需要几个机房。

> 一句话版本：把序列切分成最少的连续段，使每段"纯净"（全同一派）或"均衡"（两派人数差 $\le m$）。

**题面里容易漏掉的条款**

1. 「老师只会把连续一段的同学分进一个机房」$\Rightarrow$ 切分方式只能是**连续区间划分**（分割成若干 $[l,r]$），不能挑着分。这是问题能变成 DP 的根本原因。
2. 「要么……或者……」$\Rightarrow$ 两个条件是**或**的关系：全同段无论多长都合法（哪怕长度远大于 $m$）；反之人数差 $\le m$ 也合法，即使两派都非空。
3. 「人数差」是**绝对差**还是"甲减乙"？题面说"人数差不超过 $m$"，取**绝对差** $|c_1-c_2|\le m$ 才对称合理（否则方向依赖甲/乙会不对称）。
4. 每个同学单独成段永远合法（全同），所以答案必定存在，且 $\text{Ans}\le n$。

**数据范围与规模感受**

$$1\le n\le 2500,\qquad 0\le m\le 2500.$$

$n$ 只有 $2500$，$O(n^2)$ 的做法（约 $6.25\times10^6$ 次操作）绰绰有余，$O(n^3)$ 会到 $1.5\times10^{10}$ 太重。提示：**枚举区间左端点** $j$、对每个右端点 $i$ 做转移的区间 DP。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把问题变成"连续段划分"

**引理 1（切分 = 连续区间划分）**

任何合法方案都等价于把下标集合 $\{1,\dots,n\}$ 分成若干个**连续区间** $[l_1,r_1],[l_2,r_2],\dots,[l_k,r_k]$，满足 $l_1=1$、$r_k=n$、$r_t+1=l_{t+1}$，且每个区间"全同或人数差 $\le m$"；机房数就是区间个数 $k$。

**证明**：由题面"只会把连续一段的同学分进一个机房"，每个机房都是一个连续区间；又每个同学恰好进一个机房，故这些连续区间互不重叠且覆盖全部下标，必是上述"首尾相接"的划分形式。反过来任给这样一个划分，每个区间配一个机房即是一个合法方案。两边一一对应。$\blacksquare$

于是问题变成：**在 $[1,n]$ 上做最少段数的合法划分**。

### 2.2 从"划分"自然长出 DP：最优子结构

设 $dp[i]$ 表示"把前 $i$ 个同学划分完所需的最少机房数"（$0\le i\le n$，$dp[0]=0$）。

**引理 2（DP 转移方程）**

$$dp[i]=\min_{\substack{0\le j<i\\ \text{区间 }(j,\,i]\ \text{合法}}}\big(dp[j]+1\big).$$

**证明**：分两个方向证 $dp[i]$ 等于右端最小值。

*（可达，即 $dp[i]\le$ 右端）*：任取一个使区间 $(j,i]$ 合法的 $j$，以及前 $j$ 个同学的任意合法划分（段数为 $dp[j]$），把它和区间 $(j,i]$ 拼起来，就得到前 $i$ 个同学的一个合法划分，段数为 $dp[j]+1$。故 $dp[i]\le dp[j]+1$，对每个合法 $j$ 取最小值得 $dp[i]\le\min$。

*（必要性，即 $dp[i]\ge$ 右端）*：设 $P$ 是前 $i$ 个同学的**最优划分**（段数 $=dp[i]$）。取 $P$ 的**最后一段**为 $(j,i]$（其左端点为某 $j$，$j\ge0$；当 $i\ge1$ 时最后一段非空，$j<i$）。由 $P$ 合法，该区间合法。把最后一段去掉，剩下的是前 $j$ 个同学的一个合法划分，其段数为 $dp[i]-1$；而 $dp[j]$ 定义为前 $j$ 个同学的最少段数，故 $dp[j]\le dp[i]-1$，即 $dp[i]\ge dp[j]+1$。该 $j$ 又是合法的，于是 $dp[i]\ge\min$。

两个方向合起来得等号。$\blacksquare$

> **辅以"最优子结构"的完整论证**：上面的必要性用到了"最优划分去掉最后一段后，剩下的仍是**最优**的（否则替换成 $j$ 的更优划分会让整体更优）"。这正是引理 2 必要性证明的核心，已显式写出（$dp[j]\le dp[i]-1$ 依赖于 $dp[j]$ 是下界这一事实），未使用"显然"。

### 2.3 把"区间合法"判成 $O(1)$

判区间 $(j,i]$ 是否合法，需要该段内 $1$（甲）的人数 $c_1$ 与 $2$（乙）的人数 $c_2$，再检查 $c_1=0$ 或 $c_2=0$ 或 $|c_1-c_2|\le m$。

**引理 3（前缀和判据）**

令 $\mathrm{pre}[i]=$ 前 $i$ 个同学中崇拜甲（$1$）的人数（$\mathrm{pre}[0]=0$）。则区间 $(j,i]$ 内

$$c_1=\mathrm{pre}[i]-\mathrm{pre}[j],\qquad c_2=(i-j)-c_1,$$

且该区间合法 $\iff c_1=0$ 或 $c_2=0$ 或 $|c_1-c_2|\le m$。

**证明**：$c_1$ 是前缀之差（加法计数的可减性）：$(j,i]$ 内甲的人数 $=$ 前 $i$ 个里甲的 $-$ 前 $j$ 个里甲的 $=\mathrm{pre}[i]-\mathrm{pre}[j]$。区间长度 $=i-j$，故乙的人数 $c_2=$ 长度 $-$ 甲人数。合法判据直接照抄题面定义。$\blacksquare$

> 因而每个区间的合法判定是 $O(1)$ 的，配合引理 2 的双层循环，总复杂度 $O(n^2)$。

### 2.4 边界与别名

- $dp[0]=0$：空前缀划分需要 $0$ 个机房。
- 若整个 $[1,n]$ 合法（例如 $m\ge n$ 时差 $\le n\le m$），答案可能为 $1$。
- $m=0$ 时只允许"全同"或"两派人数恰好相等"的段。
- 非法状态初始化：`dp` 初值设为哨兵（`inf`），从 `dp[0]=0` 递推；由于"每段可单独成段"必合法，$dp[i]$ 最终必被更新出真实值，不会残留哨兵。

### 2.5 复杂度

- 时间：外层 $i=1..n$，内层 $j=0..i-1$，每次 $O(1)$，合计 $\dfrac{n(n+1)}2=O(n^2)\le3.1\times10^6$。
- 空间：`pre`、`dp` 各 $O(n)$。

## 3. 模式总结（Pattern Summary）

**模式名：连续段划分的「区间 DP + 前缀和判据」。**

**按实际思考顺序排列的可迁移标签：**

- `explore its property` — 把"连续分机房"翻译成"把序列切成连续区间"（引理 1）。
- `classic problem solution` — 识别为"最少段数划分"，建立 $dp[i]=$ 前 $i$ 个的最少段数。
- `prove the DP` — 用"取最优划分的最后一段"论证转移方程的必要性方向（引理 2），而非默认最优子结构。
- `reduce to easier problem` — 用前缀和把"区间内两类人数"降到 $O(1)$ 查询（引理 3）。
- `discuss by category` — 合法性拆成"全同 / 人数差 $\le m$"两种类别分别判定。
- `complexity by constraints` — 由 $n\le2500$ 直接选定 $O(n^2)$ 的枚举左端点写法。

**识别信号：**

- 要求把序列切成连续段，每段有独立的合法性条件；
- 目标是最少段数（或最大段数 / 最大收益等的段数型最优化）；
- 单段的合法性可以用前缀量快速判断。

**一句话记忆**：连续段划分几乎总是 $dp[i]=\min_{j<i,\ \text{seg}(j,i]\text{合法}} dp[j]+1$；单段合法性用前缀和 $O(1)$ 算。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $n$ | `int` | 同学人数 | 读入 | 题面 |
| $m$ | `int` | 两派人数差的上限 | 读入 | 题面 |
| `pre[i]` | `int [2505]` | 前 $i$ 个同学中崇拜甲（$1$）的人数 | `pre[0]=0` | prefix 前缀和 |
| `dp[i]` | `int [2505]` | 前 $i$ 个同学最少需要的机房数 | `dp[0]=0`，其余 `inf` | DP 状态 |
| $c_1,c_2$ | `int`（局部） | 当前区间内甲、乙的人数 | 每轮计算 | 由 `pre` 之差得到 |

### 4.2 编号步骤

1. 读入 $n,m$；对 $i=1..n$ 读入 $x$，`pre[i]=pre[i-1]+(x==1)`。
2. 把 `dp` 全体置为哨兵 `inf`，再 `dp[0]=0`。
3. 外层 $i=1..n$，内层 $j=0..i-1$：
   3.1 `c1=pre[i]-pre[j]`，`len=i-j`，`c2=len-c1`；
   3.2 若 `c1==0 || c2==0 || abs(c1-c2)<=m`，则 `dp[i]=min(dp[i], dp[j]+1)`。
4. 输出 `dp[n]` 与换行。

### 4.3 复杂度

- 时间：$O(n^2)$，$n=2500$ 时约 $3.1\times10^6$ 次内层迭代。
- 空间：两个 `int[2505]`，约 $20$ KB。
- 实测：$n=2500,m=2500$，耗时 $0.0245$ s。

### 4.4 关键不变量

1. `dp[i]` 为真值时表示前 $i$ 个同学的最小机房数；`dp[0]=0`。
2. `pre` 是单调不减的前缀计数（每位 $+0$ 或 $+1$）。
3. 每个区间合法性判定与题面定义逐字对应（引理 3）。
4. 最终答案 $\in[1,n]$（至少一个机房，至多每人一个）。

## 5. 示例代码

### 5.1 主解：$O(n^2)$ 区间 DP

```cpp
//
// 题目：P1564 膜拜
// https://www.luogu.com.cn/problem/P1564
// AC
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{2505};          // n<=2500 (+5 松弛)
constexpr int inf{1145141919};

int n,m;
int pre[mxn];                     // pre[i]=前 i 个同学中崇拜甲(1)的人数
int dp[mxn];                      // dp[i]=前 i 个同学最少需要的机房数

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=1,x;i<=n;++i)
	{
		cin>>x;
		pre[i]=pre[i-1]+(x==1);
	}
	fill_n(&dp[0],mxn,inf);
	dp[0]=0;
	for(int i=1;i<=n;++i)
		for(int j=0;j<i;++j)
		{
			int c1=pre[i]-pre[j];
			int len=i-j;
			int c2=len-c1;
			if(c1==0||c2==0||abs(c1-c2)<=m)   // 全同 或 两派人数差<=m
				dp[i]=min(dp[i],dp[j]+1);
		}
	cout<<dp[n]<<'\n';
	return 0;
}
```

**代码结构对照**：`pre` 是引理 3 的前缀计数；内层 `j` 枚举最后一个区间的左端点，`c1/c2` 由前缀之差 $O(1)$ 算出；合法判据 `c1==0||c2==0||abs(c1-c2)<=m` 逐字对应题面；`dp` 用 `inf` 哨兵初始化、`dp[0]=0` 起步，最后由每个同学单独成段保证 `dp[n]` 被更新出真值。

### 5.2 对照实现：枚举所有分段（仅用于对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{30};

int n,m;
int a[mxn];
int ans;

void dfs(int pos,int rooms)
{
	if(rooms>=ans)                // 剪枝
		return;
	if(pos==n)
	{
		ans=min(ans,rooms);
		return;
	}
	int c1=0,c2=0;
	for(int j=pos;j<n;++j)
	{
		if(a[j]==1)
			++c1;
		else
			++c2;
		if(c1==0||c2==0||abs(c1-c2)<=m)
			dfs(j+1,rooms+1);
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>a[i];
	ans=n;                        // 每个单独成房一定可行
	dfs(0,0);
	cout<<ans<<'\n';
	return 0;
}
```

两版在 $300$ 组随机用例上**输出逐字节相同**。这一版不建 DP 表，直接**深度优先枚举所有合法的连续分段**并取最少段数，可作为引理 2 转移方程与引理 3 判据的独立交叉验证基准。剪枝 `rooms>=ans` 让它能跑 $n\le12$ 左右。

### 5.3 易错点清单

- **漏掉"全同"分支**：只判 $|c_1-c_2|\le m$，会把超长的全同段误判非法，答案偏大。
- **人数差不取绝对值**：写成 `c1-c2<=m`，方向不对称，出错。
- **`dp` 未置哨兵 / 未初始化 `dp[0]=0`**：局部变量默认值不确定，或状态从非零起点开始，结果错误。
- **`inf` 溢出**：若用 `dp[j]+1` 时 `dp[j]` 恰为哨兵仍可能参与 min，因哨兵足够大（`1145141919`）不会成为答案，但要确保 `dp[i]` 最终必被真实值覆盖（每个同学单独成段保证了这一点）。
- **用 `endl`**：违反本项目风格指南，用 `'\n'`。
