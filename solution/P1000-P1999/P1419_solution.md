# P1419 寻找段落

> 标签：二分 / 单调队列 / 前缀和 · 难度：提高/省选-
> 注：**本地题面没有给出任何样例**，因此本文无法与官方答案对标，所有验证均为手算（见 §4.4）。

## 1. 重新读题

**问题重述（大白话版）**

给定长度为 $n$ 的序列 $a$。一个"段落"就是下标连续的一段 $a_l,a_{l+1},\dots,a_r$，它的**长度**是 $r-l+1$，**平均值**是 $\dfrac{1}{r-l+1}\sum_{i=l}^{r}a_i$。
要求：只允许选长度落在闭区间 $[S,T]$ 内的段落，在所有合法段落中让平均值最大，把这个最大的平均值以 3 位小数的实数输出。

**输入格式逐字核对**（一切以本地题面为准）

| 位置 | 内容 |
|---|---|
| 第 1 行 | $n$ |
| 第 2 行 | $S$ 和 $T$ |
| 第 $3$ 行 ~ 第 $n+2$ 行 | 每行一个整数 $a_i$ |

$a_i$ 是**每行一个**而不是排成一行——`cin>>a[i]` 循环读即可（`cin` 对空白不敏感），但不要按行解析。题面没有给样例数据。

**约束与子任务（提示复杂度）**

| 数据范围 | 规模 |
|---|---|
| 30% | $n\le 1000$ |
| 100% | $1\le n\le 10^5$，$1\le S\le T\le n$，$-10^4\le a_i\le 10^4$ |

- 合法段落数量级：长度有 $T-S+1$ 种取法，起点 $O(n)$ 个，共约 $\dfrac{(T-S+1)(2n-T-S+2)}{2}\le\Theta(n^2)\approx 5\times10^9$。$30\%$ 的 $n\le1000$ 正好对应"枚举两端点 $O(n^2)$ + $O(1)$ 求段和"的部分分，说明满分要把某个维度压成 $O(\log V)$ 次线性扫描。
- 值域含负数（$-10^4\le a_i$）——这是本题**最重要**的一条范围信息，直接决定二分下界不能取 $0$。

**目标函数形式**：$\max\limits_{S\le \mathrm{len}\le T}\dfrac{\sum a_i}{\mathrm{len}}$，分子分母同时变化，是**比值最大化**而不是和最大化。

**陷阱与边界（先列出来，后文逐条处理）**

1. **答案可负**：全负序列平均值必为负，若二分下界写成 `l=0` 则恒有 `check(0)=false`，最终输出 $0.000$ 或区间错乱。必须用 $\min a_i$ 级别的下界（见 §4.2 步骤 2）。
2. **$S=T$**：长度钉死，判定中窗口 $[i-T,i-S]$ 退化成单点，边界写错就整段漏判。
3. **$T=n$**：窗口左界 $i-T\le 0$，上界约束实际不起作用，出队条件必须写成下标比较（`q[h]<j-T`）而非法负数截断。
4. **$n=1$**：必有 $S=T=1$，答案是 $a_0$；前缀和数组需要 $n+1$ 个格子，`s[0]` 必须显式置 $0$。
5. **精度**：要 3 位小数，二分收敛半径须远小于 $5\times10^{-4}$，并评估浮点累加误差（§2.7）。
6. **循环写法**：实数二分用固定迭代次数，避免 `while(r-l>eps)` 的停滞与抖动。
7. **本地题面无样例**：无法与官方答案对标，验证只靠手算 + 自造边界用例（§4.4）。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：平均值这个目标函数到底有什么脾气

先把"平均值最大"这句话拆开，看看它到底允许我们做什么样的比较。**下面所有段落都默认指长度在 $[S,T]$ 内的合法段落。**

**引理 1（夹逼性）** 任意段落的平均值 $\mu$ 满足 $\min_{i\in[l,r]}a_i\le\mu\le\max_{i\in[l,r]}a_i$。

**证明**：记 $m=\min_{i\in[l,r]}a_i$，$M=\max_{i\in[l,r]}a_i$，段长 $L=r-l+1\ge S\ge1>0$。
由 $m$、$M$ 的定义，对每个 $i\in[l,r]$ 有 $m\le a_i\le M$。把 $L$ 个不等式分别相加（同向不等式可逐项相加）：
$Lm\le\sum_{i=l}^{r}a_i\le LM$。
再同除以正数 $L$（除以正数不改变不等号方向）即得 $m\le\mu\le M$。$\blacksquare$

**引理 2（答案的整体上下界 + 可取到）** 记 $A^\ast$ 为所求最大平均值，则 $\min_i a_i\le A^\ast\le\max_i a_i$，且存在某个合法段落恰好取到 $A^\ast$。

**证明**：
- 合法段落集合非空：由 $1\le S\le T\le n$，长度取 $S$ 时起点可以取 $1,\dots,n-S+1$，至少 $1$ 个（因为 $S\le n$），故集合非空。
- 段落总数不超过 $\sum_{L=S}^{T}(n-L+1)\le\dfrac{n(n+1)}{2}$，是**有限**集合；非空有限集合上最大值必被某个元素取到，故 $A^\ast$ 可达。
- 上界：取达到 $A^\ast$ 的段落，由引理 1 有 $A^\ast\le$ 该段最大值 $\le\max_i a_i$。
- 下界同理：$A^\ast\ge$ 该段最小值 $\ge\min_i a_i$。$\blacksquare$

> 这条引理后面有两个用途：① 它给出二分的初始区间；② 它说明"答案不会跑到 $[\min a,\max a]$ 外面"，所以不存在"需要更大的 $x$"的情况。

**引理 3（不可加 / 平均值的加权混合）** 设两段 $A,B$ 长度 $L_A,L_B$、平均值 $\mu_A,\mu_B$，拼接后的段平均值 $\mu=\dfrac{L_A\mu_A+L_B\mu_B}{L_A+L_B}$，于是 $\mu\in[\min(\mu_A,\mu_B),\max(\mu_A,\mu_B)]$。

**证明**：段和 $=\sum_{i\in A\cup B}a_i=L_A\mu_A+L_B\mu_B$（因为 $L_A\mu_A=\sum_{i\in A}a_i$ 由平均值定义直接移项得到）。拼接段长度 $L_A+L_B>0$，故 $\mu$ 如上式。
记 $w=\dfrac{L_A}{L_A+L_B}\in(0,1)$，则 $\mu=w\mu_A+(1-w)\mu_B$。
若 $\mu_A\le\mu_B$：$\mu\le w\mu_B+(1-w)\mu_B=\mu_B$ 且 $\mu\ge w\mu_A+(1-w)\mu_A=\mu_A$；$\mu_A>\mu_B$ 同理对称。$\blacksquare$

**这条引理的直接后果（也是本题的"机制"）**：
- 在一段后面追加一个元素/子段，平均值变不变好，取决于**新部分的平均值**是否比当前平均值更高——而新部分的平均值又依赖于它的长度。
- 所以"以位置 $i$ 结尾的最优段落"这个信息**不够**做 DP 转移：还需要知道它的**长度**（或**和**）。状态从 1 维变成 2 维，$O(nT)$ 太大。

**引理 4（几何改写：最大平均值 = 最大斜率）** 设原序列前缀和 $p_0=0,\ p_k=\sum_{i=1}^{k}a_i$，把每个 $k$ 看成平面点 $P_k=(k,p_k)$。则段落 $(j,i]$（即 $a_{j+1..i}$，长度 $i-j$）的平均值等于直线 $P_jP_i$ 的**斜率**。于是原问题等价于：

$$A^\ast=\max\{\ \mathrm{slope}(P_j,P_i)\ :\ 0\le j<i\le n,\ S\le i-j\le T\ \}$$

**证明**：$\mathrm{slope}(P_j,P_i)=\dfrac{p_i-p_j}{i-j}$。由前缀和定义，$p_i-p_j=\sum_{k=j+1}^{i}a_k$ 恰是段落 $a_{j+1},\dots,a_i$ 的段和，而 $i-j$ 恰是该段长度，两者之比即平均值。约束 $S\le i-j\le T$ 就是"长度在 $[S,T]$"。集合两边一一对应（每个合法段对应唯一点对，反之亦然），故最大值相等。$\blacksquare$

> **机制小结**：目标是"点对斜率最大"，是比值型而非可加型；比较两段好坏时要同时看 $\Delta p$ 与 $\Delta x$。这告诉我们两件事：(a) 直接 DP/贪心有困难；(b) 一旦把分母（斜率值）**猜**成一个数 $x$，比较就退化成"看 $\Delta p-x\Delta x$ 的符号"，分母消失，变成可加量——这正是二分答案的入口。

### 2.2 简化版 1：$S=1,\ T=n$（长度约束完全打开）—— 答案就是 $\max a_i$

**引理 5** 当 $S=1$ 时（此时无论 $T$ 取多少，只要 $T\ge1$），$A^\ast=\max_i a_i$。

**证明**：
- "$\le$"：由引理 2，$A^\ast\le\max_i a_i$。
- "$\ge$"：设 $t$ 是某个取到最大值的位置（有限集合必存在）。长度 $1$ 的段落 $[t,t]$ 合法（$S=1\le1\le T$），其平均值 $=\dfrac{a_t}{1}=\max_i a_i$，而 $A^\ast$ 是所有合法段平均值的最大值，故 $A^\ast\ge\max_i a_i$。
- 两式合并得 $A^\ast=\max_i a_i$。$\blacksquare$

> **这个特例教会我们的事**：一旦允许长度 $1$，任何"长段"都不可能有优势——引理 3 说明长段平均值被它内部元素平均值夹住，永远不超过 $\max a_i$。所以本题的**真正难度全部来自下界 $S\ge2$**：被迫把"差的元素"也吃进来。

### 2.3 简化版 2：定长 $S=T=L$ —— 分母相同，比较退化为比较"段和"

**引理 6** 若 $S=T=L$，则 $A^\ast=\dfrac{1}{L}\max\limits_{0\le i\le n-L}(p_{i+L}-p_i)$，可在 $O(n)$ 内算出。

**证明**：此时每个合法段长度都恰好是 $L$，平均值 $=\dfrac{\text{段和}}{L}$。因为 $L>0$ 是常数，映射 $x\mapsto x/L$ 严格单调递增，所以"平均值最大"与"段和最大"取到同一个段，即 $\max\dfrac{\text{段和}}{L}=\dfrac{1}{L}\max(\text{段和})$。
段和由前缀和表示为 $p_{i+L}-p_i$，$i$ 有 $n-L+1$ 个取值，每个 $O(1)$ 求出，故总 $O(n)$。$\blacksquare$

**回到原题，看简化版差在哪**：原题要在 $L\in[S,T]$ 上一共 $T-S+1$ 种长度里各做一次引理 6 的计算，朴素做法是
$$O\big(n\cdot(T-S+1)\big)\le O(n^2)$$
对 $n=10^5$ 完全不够（$\sim10^{10}$）。

**卡住的地方**：能不能对每个右端点 $i$ 只扫描一次、$O(1)$ 决策？我们希望找 $\arg\min\limits_{j}\dfrac{p_i-p_j}{i-j}$。麻烦在于 $j$ 同时出现在分子和分母里，**无法分离**：
- 使 $p_j$ 最小的 $j$ 不一定使比值最小；
- 使 $i-j$ 最大（即 $j$ 最小）的也不一定。

具体反例：$p=(0,\,5,\,4)$（对应 $a=[5,-1]$），考察右端点 $i=2$：
$j=0$ 给 $\dfrac{4-0}{2}=2$；$j=1$ 给 $\dfrac{4-5}{1}=-1$。
最小的是 $p_j$ **较大**的那个 $j=1$；而 $\arg\min p_j=0$ 给出的是最大值。可见"直接维护前缀最小值"在这一层是错的——必须先消掉分母。

> 于是自然产生一个念头：**先把比值猜成一个数**。如果猜 $x$，那么"$\dfrac{p_i-p_j}{i-j}\ge x$"由于 $i-j>0$ 等价于 $p_i-p_j\ge x(i-j)$，即 $(p_i-xi)-(p_j-xj)\ge 0$。分母消失了，而且新定义的 $q_k=p_k-xk$ 只和 $k$ 有关，比较 $q_i$ 与 $q_j$ 就能决策。这就是下一步的二分答案。

### 2.4 剖析贪心/DP 失败：四条看起来很对的直觉全部错

**(A) 贪心 1：最优段长度一定是 $S$ 或 $T$（"取端点"）。**
反例：$n=5,S=2,T=4$，$a=[10,-5,10,-5,10]$。把所有合法段穷举（合法长度只有 $2,3,4$）：

| 段（下标从 0） | 长度 | 段和 | 平均值 |
|---|---|---|---|
| $[0,1]$ | 2 | 5 | 2.5 |
| $[1,2]$ | 2 | 5 | 2.5 |
| $[2,3]$ | 2 | 5 | 2.5 |
| $[3,4]$ | 2 | 5 | 2.5 |
| $[0,2]$ | 3 | 15 | **5.0** |
| $[1,3]$ | 3 | 0 | 0.0 |
| $[2,4]$ | 3 | 15 | **5.0** |
| $[0,3]$ | 4 | 10 | 2.5 |
| $[1,4]$ | 4 | 10 | 2.5 |

答案 $A^\ast=5.000$ 出现在**内部长度 $3$**；长度 $S=2$ 最好只有 $2.5$，长度 $T=4$ 也只有 $2.5$。**"只查两个端点长度"错误**。
（表格是穷举，所以这是完整证明而不是举例。）

**(B) 贪心 2：最优段一定包含最大值元素。**
反例：$n=4,S=T=2$，$a=[100,-1000,50,50]$。合法段只有长度 $2$ 的三段（$n-L+1=3$）：
$[0,1]$：和 $-900$，均值 $-450$；$[1,2]$：和 $-950$，均值 $-475$；$[2,3]$：和 $100$，均值 $50$。
$A^\ast=50$，来自 $[2,3]$，**不含** $a_0=100$。原因即引理 3：平均值会被同段里的极端负值拖走，"含大值"不保证"均值大"。

**(C) 贪心 3：固定起点，"从长度 $S$ 开始往后扩，平均值一下降就停"。**
反例：$n=5,S=3,T=5$，$a=[4,3,-1,1,8]$。**穷举**全部 $6$ 个合法段（长度只可取 $3,4,5$）：

| 段 | 长度 | 和 | 平均值 |
|---|---|---|---|
| $[0,2]$ | 3 | 6 | 2.00 |
| $[1,3]$ | 3 | 3 | 1.00 |
| $[2,4]$ | 3 | 8 | 2.67 |
| $[0,3]$ | 4 | 7 | 1.75 |
| $[1,4]$ | 4 | 11 | 2.75 |
| $[0,4]$ | 5 | 15 | **3.00** |

$A^\ast=3.000$，且由唯一段 $[0,4]$ 取到（表已穷举）。现在跑该贪心：
- 起点 $0$：长度 $3$ 得 $2.00$ → 扩到长度 $4$ 得 $1.75$，**下降 → 停**，记录 $2.00$；
- 起点 $1$：$[1,3]$ 得 $1.00$ → $[1,4]$ 得 $2.75$，上升 → 记录 $2.75$；
- 起点 $2$：$[2,4]$ 得 $2.67$，已到数组末尾，记录 $2.67$。
贪心总输出 $\max(2.00,2.75,2.67)=2.75\ne 3.00$。**错**。
原因：$[0,4]$ 的前缀平均值序列 $2.00\to1.75\to3.00$ 不是单调的，中途的"下降"（被 $x_3=1$ 拉低）之后又被 $x_4=8$ 拉高；而最优段长 $5=2S-1$，它的后 $S=3$ 项 $[2,4]$ 均值 $2.67<3$，所以无法靠"换起点"绕过（这正是引理 7 里"$L\ge2S$ 才能切出两个都合法的子段"的边界情形）。

**(D) DP：只保留"以 $i$ 结尾的最优段"。**
反例：$n=4,S=2,T=3$，$a=[9,9,0,8]$。
- 以位置 $2$ 结尾的合法段：$[1,2]$ 和 $9$ 均值 $4.5$；$[0,2]$ 和 $18$ 均值 $6.0$ → 最优是 $[0,2]$（值 $6$）。
- 以位置 $3$ 结尾的合法段：$[2,3]$ 和 $8$ 均值 $4.0$；$[1,3]$ 和 $17$ 均值 $17/3\approx5.667$。
转移时，$[1,3]$ 是由 $[1,2]$（均值 $4.5$，**第二名**）扩展得到的；而"最优的 $[0,2]$"再加一个元素就变成长度 $4>T=3$，非法。
所以"只记住最优平均值"这条状态不够：扩展的可行性取决于**长度**，扩展后的好坏取决于**和**。要 2 维状态 $(\text{和},\text{长度})$，即 $O(nT)$，不可接受。

> **失败模式的共性**：比较两个段时要用到 $\Delta p/(i-j)$，分母随候选变化，局部最优不能传递。
> 由此得到一条**必须做对的事**：把分母固定住再比较。这有两种做法——枚举长度（$O(nT)$，见 (A) 的表）或者**猜一个斜率值 $x$ 并把所有候选拉平到同一个尺度**，后者就是二分答案。

### 2.4 延伸：结构性引理——长度上界 $T$ 很多时候是"多余"的

**引理 7（长度可压缩到 $[S,2S-1]$）** 设 $A^\ast(S,T)$ 为长度限制在 $[S,T]$ 时的最大平均值，则
$$A^\ast(S,T)=A^\ast\big(S,\min(T,2S-1)\big).$$

**证明**：只需证"$\le$"（反方向由 $\min(T,2S-1)\le T$、候选集变小即得 $A^\ast(S,\min(T,2S-1))\le A^\ast(S,T)$）。
取达到 $A^\ast(S,T)$ 的段 $[l,r]$，长度 $L=r-l+1$（由引理 2 这样的段存在）。
若 $L\le 2S-1$，压缩不动，已成立。若 $L\ge 2S$：把它切成前段 $X=[l,l+S-1]$（长 $S$）与后段 $Y=[l+S,r]$（长 $L-S\ge S$），平均值记 $\mu_X,\mu_Y$。
由引理 3 的拼接公式：$\mu=\dfrac{S\mu_X+(L-S)\mu_Y}{L}$。
若 $\mu_X<\mu$ 且 $\mu_Y<\mu$，则 $\mu=\dfrac{S\mu_X+(L-S)\mu_Y}{L}<\dfrac{S\mu+(L-S)\mu}{L}=\mu$，矛盾。故 $\max(\mu_X,\mu_Y)\ge\mu=A^\ast$。
- 若 $\mu_X\ge\mu$：$X$ 长 $S\in[S,2S-1]$，是一个不差的更短合法段。
- 若 $\mu_Y\ge\mu$：$Y$ 长 $L-S<L$ 且 $\ge S$，仍受 $T$ 约束（更短，故 $\le T$），对 $Y$ 递归使用本论证。
$L$ 每步严格减小，必在有限步内落入 $[S,2S-1]$，且沿途每段均值都 $\ge\mu=A^\ast$，由 $A^\ast$ 的最大性它们恰好等于 $A^\ast$。$\blacksquare$

**推论**：$T\ge 2S-1$ 时 $T$ 完全不起作用（答案只由 $S$ 决定上界）。
验证（用 (A) 的反例）：$S=2$ 时 $2S-1=3$，最优确实出现在长度 $3$；$T=4$ 多余。
验证（用 (C) 的反例）：$S=3$ 时 $2S-1=5=T$，最优段 $[0,4]$ 长 $5$ 恰在压缩界上，**已经压无可压**——这解释了 (C) 里"换个起点"也救不回来。
**但它只是把 $T$ 压到 $2S-1$，枚举长度仍需 $O(nS)$，$S\sim n/2$ 时照样 $O(n^2)$，所以这不足以满分。**

### 2.5 经典解法：二分答案 + 判定

由 §2.4 的失败模式，改成"**猜一个平均值 $x$，只判定 $x$ 能不能达到**"。定义

$$\mathrm{check}(x):\ \exists\ \text{合法段 } [l,r]\ \text{使}\ \sum_{i=l}^{r}(a_i-x)\ \ge\ 0 .$$

（本节沿用 §2.1 的 $1$-based 闭区间 $[l,r]$ 叙述；从引理 11 起换成与代码一致的 $0$-based 半开区间 $[i,j)$，两种写法描述的是同一批段。）

**引理 8（判定等价式 + 判定集的形状）** 对任意实数 $x$：$\mathrm{check}(x)$ 为真 $\iff x\le A^\ast$。

**证明**：设某合法段长度为 $L\ge S\ge1$、平均值为 $\mu$。则
$$\sum_{i=l}^{r}(a_i-x)=\Big(\sum_{i=l}^{r}a_i\Big)-xL=L\mu-xL=L(\mu-x).$$
因为 $L>0$，除以 $L$ 不改变不等号方向：$\sum_{i=l}^{r}(a_i-x)\ge 0\iff\mu-x\ge0\iff\mu\ge x$。
- ($\Leftarrow$) 若 $x\le A^\ast$：由引理 2，存在合法段取到 $\mu=A^\ast\ge x$，它的 $L(\mu-x)\ge0$，故 $\mathrm{check}(x)$ 真。
- ($\Rightarrow$) 若 $\mathrm{check}(x)$ 真：存在合法段 $\mu\ge x$，而 $A^\ast$ 是合法段均值上确界（这里是最大值），故 $A^\ast\ge\mu\ge x$。$\blacksquare$

**引理 9（$\mathrm{check}$ 单调，且不依赖引理 8 的直接证明）** 若 $y\le x$ 且 $\mathrm{check}(x)$ 为真，则 $\mathrm{check}(y)$ 为真。

**证明**：取见证段（$\mathrm{check}(x)$ 的 witness）$[l,r]$，长 $L$，$\sum_{i=l}^{r}(a_i-x)\ge0$。逐项改写
$$\sum_{i=l}^{r}(a_i-y)=\sum_{i=l}^{r}\big[(a_i-x)+(x-y)\big]=\sum_{i=l}^{r}(a_i-x)+(x-y)L\ \ge\ 0+0=0,$$
其中 $x-y\ge0$ 且 $L\ge1>0$，故第二项非负。于是 $\mathrm{check}(y)$ 真。$\blacksquare$
（这条不借助"$A^\ast$"的存在性，纯代数，说明判定过程本身对 $x$ 单调；引理 8 则告诉我们单调分界点恰好是答案。）

**于是可以二分**：$x$ 越大越难满足，真的区间是 $(-\infty,A^\ast]$。由引理 2，$A^\ast\in[\min a,\max a]$，取
$$l_0=\min_i a_i-1\ (\text{必真}),\qquad r_0=\max_i a_i+1\ (\text{必假})$$
（$l_0<\min a\le A^\ast$ 故真；$r_0>\max a\ge A^\ast$ 故假。）

**引理 10（二分收敛与误差）** 每步取 $mid=\frac{l+r}{2}$，真则 $l\leftarrow mid$ 否则 $r\leftarrow mid$，则不变量"$l\le A^\ast<r$ 且 $\mathrm{check}(l)$ 真、$\mathrm{check}(r)$ 假"始终保持，$k$ 步后 $r-l=\dfrac{r_0-l_0}{2^k}$，输出 $l$ 满足 $0\le A^\ast-l\le\dfrac{r_0-l_0}{2^k}$。

**证明**：归纳。基步即上面的选取。归纳步：设 $l\le A^\ast<r$。
- 若 $\mathrm{check}(mid)$ 真：由引理 8 得 $mid\le A^\ast$，令 $l'=mid$，则 $l'\le A^\ast<r$，且新区间长度减半。
- 若假：由引理 8 逆否得 $mid>A^\ast$（因为 $mid\le A^\ast\Rightarrow$ 真），令 $r'=mid$，则 $l\le A^\ast<r'$，长度减半。
$0\le A^\ast-l\le r-l$ 由 $l\le A^\ast\le r$ 得到。$\blacksquare$

代入数据：$r_0-l_0\le\max a-\min a+2\le 2\times10^4+2$。取 $k=60$：$\dfrac{2\times10^4+2}{2^{60}}\approx1.7\times10^{-14}$，远小于 $5\times10^{-4}$（3 位小数所需）。
**不用 `while(r-l>eps)`** 的理由：$l,r$ 都是 $\sim10^4$ 量级时，double 的 ulp 约 $2\times10^{-12}$，若把 eps 设得比 ulp 还小（例如 $10^{-15}$）则 `mid` 会反复等于端点导致长时间不推进；固定迭代次数把"是否终止"这件事变成与浮点无关。

### 2.6 归约到更简单问题：一次判定 = 滑动窗口最小值

现在只看 $\mathrm{check}(x)$ 怎么算快。$n=10^5$，枚举两段 $O(n^2)$ 显然还是太慢（$\times60$ 次更慢）。

**引理 11（把判定改写成窗口查询）** 记 $b_i=a_i-x\ (0\le i<n)$，$s_0=0,\ s_k=\sum_{i=0}^{k-1}b_i\ (1\le k\le n)$。则
$$\mathrm{check}(x)\iff\exists\, j\in[S,n],\ \ s_j\ \ge\ \min\{\,s_i:\ \max(0,\,j-T)\le i\le j-S\,\}.$$

**证明**：段落对应一对下标 $(i,j)$，含义是取 $a_i,\dots,a_{j-1}$，长 $j-i$。合法条件：
$\;0\le i<j\le n$，$S\le j-i\le T$ $\iff$ $S\le j\le n$ 且 $j-T\le i\le j-S$ 且 $i\ge0$，即 $i\in[\max(0,j-T),\,j-S]$（$j\ge S$ 时该区间非空，因为右端 $j-S\ge0\ge\max(0,j-T)$）。
段和 $\sum_{t=i}^{j-1}(a_t-x)=s_j-s_i$，条件 $\ge0$ 即 $s_i\le s_j$。
"区间内存在 $i$ 使 $s_i\le s_j$" $\iff$ "区间内最小的 $s_i\le s_j$"（区间非空且有限，最小值存在：有限集上取到）。$\blacksquare$

**关键观察**：当 $j$ 从 $S$ 变到 $n$ 时，窗口的左端 $\max(0,j-T)$ 与右端 $j-S$ **都恰好每次右移 $1$**（$j<T$ 时左端钉在 $0$，仍单调不减）。这正是"滑动窗口最小值"的标准形态，而窗口大小恒为 $T-S+1$（左端钉 $0$ 的暂态除外）。

**为什么不能用普通前缀最小值（扔掉上界）？** 若只要求 $i\le j-S$，判定就变成"$\exists$ 长度 $\ge S$ 的段达标"，算的是 $A^\ast(S,\infty)$。由引理 7，$A^\ast(S,\infty)=A^\ast(S,2S-1)$，于是：
- $T\ge 2S-1$ 时扔掉上界**判定的真假结果不变**（因为存在长度 $\le2S-1\le T$ 的等优段，弹不弹过期都不影响"$A^\ast$ 是否 $\ge x$"）；注意这**不等于**"队头弹出条件不会触发"，条件照样会触发，只是不影响最终答案；
- $T<2S-1$ 时会得到偏大的假答案。

**必须卡上界的反例**：$n=3,S=T=2$，$a=[10,-5,10]$。合法段只有长度 $2$ 的两个：$[0,1]$ 和 $5$ 均值 $2.5$，$[1,2]$ 和 $5$ 均值 $2.5$ → $A^\ast=2.5$。
取 $x=4$（正确判定应为**假**）：$b=[6,-9,6]$，$s=[0,6,-3,3]$。
- 带窗口版：$j=3$ 时窗口 $[\max(0,3-2),3-2]=[1,1]$，$\min=6$，$s_3-6=3-6=-3<0$；$j=2$ 时窗口 $[0,0]$，$s_2-s_0=-3<0$ → **判假** ✔。
- 无上界版：$j=3$ 时允许 $i\in[0,1]$，$\min(s_0,s_1)=0$，$s_3-0=3\ge0$ → **误判为真**，它偷偷用了 $i=0,j=3$ 即长度 $3$ 的段 $[0,2]$（和 $15$、均值 $5\ge4$，但 $3>T=2$ 非法）。✔

**引理 12（单调队列的正确性）** 代码中的 `q[]`（存下标，头尾指针 `h,t`，区间语义 $[h,t)$）在每次"插入 $k=j-S$ → 从队尾弹出 $s$ 值 $\ge s_k$ 者 → 从队头弹出下标 $<j-T$ 者"之后，恰好保存窗口 $[L_j,R_j]=[\max(0,j-T),\,j-S]$ 中所有"**后缀最小指标**"（即 $s_i$ 严格小于它右侧所有仍在窗口内的 $s$ 值），并按下标递增排列。故队头 $d_0$ 满足 $s_{d_0}=\min_{i\in[L_j,R_j]}s_i$。

**证明**：分三点。
1. **队内 $s$ 值随下标严格递增**：插入时先把队尾所有 $s\ge s_k$ 的弹出，剩下的队尾 $s<s_k$，故追加 $k$ 后性质保持；弹队尾/队头只删元素不影响相对顺序。归纳成立。
2. **被弹掉的元素永远不会再成为最小值**：设弹出 $d$（此刻 $d<k$，$s_d\ge s_k$）。此后任意一次循环的窗口右端 $R_{j'}\ge k$（右端只增），于是若 $d$ 仍在窗口内（即 $d\ge L_{j'}$），则 $k>d\ge L_{j'}$ 也在窗口内，而 $s_k\le s_d$：$\min$ 不需要 $d$。若 $d$ 已出窗口则无所谓。故删除 $d$ 不改变任何未来窗口的最小值。
3. **队头就是最小值**：窗口内每个下标 $i$ 要么在队里，要么在第 2 步的意义上被某个队里（或更晚入队、同样在窗口里）的下标支配；沿支配链走（下标严格增、$s$ 严格减、有限）必停在某个仍在队中的元素 $e$（窗口最右元素 $R_j$ 一定在队中，故链不会掉出队），有 $s_e\le s_i$。由第 1 点 $s_{d_0}\le s_e$；又 $d_0$ 在窗口内故 $s_{d_0}\ge\min$。综合 $s_{d_0}=\min_{[L_j,R_j]}s_i$。$\blacksquare$

**均摊 $O(1)$**：每个下标在整轮扫描中至多入队一次、出队一次（队尾弹或队头弹），故总操作 $\le 2n+2$，单次 $\mathrm{check}$ 为 $O(n)$。

**其它可选实现（比较）**：
- 线段树/稀疏表维护 $s$ 的区间最小值：每次判定 $O(n\log n)$（建表 $O(n\log n)$），总 $O(60n\log n)\approx10^8$，能过但明显更慢、代码更长。
- 优先队列 + 惰性删除：正确，但 $O(n\log n)$ 且要多存 $s$ 值比较。
- **结论**：窗口同步右移是"单调队列"的教科书触发条件，选它。

### 2.7 溢出与精度防护（写代码前必须算一遍量级）

**量级 1：前缀和会不会爆 `int`？**
$x\in[l_0,r_0]\subseteq[-10001,10001]$，故 $|b_i|=|a_i-x|\le 10^4+10^4+1=20001$，
$|s_k|\le n\cdot 20001=10^5\times20001=2.0001\times10^9$，而 $\mathrm{INT\_MAX}=2147483647\approx2.147\times10^9$。
→ **`int` 只差 $7\%$ 就爆了**，本文用 `double` 存 `s`（$2\times10^9$ 量级对 double 只是 1 个数量级的整数部分，精度绰绰有余）；
若想把"减 $x$"写成整数运算，必须用 `i64`。

**量级 2：整数化变体的溢出（如果这样写）** 把判定改成 $\sum(1000a_i-M)\ge0$（$M$ 是整数，见下面引理 13）：
单项 $|1000a_i-M|\le10^7+10^7=2\times10^7$，累加 $n$ 项 $\le 2\times10^{12}$ **远超 `int`**，必须 `i64`（$9.22\times10^{18}$，安全）。

**引理 13（整数化判定的等价性）** 对整数 $M$：$\exists$ 合法段使 $\mu\ge\dfrac{M}{1000}$ $\iff$ $\exists$ 合法段使 $\sum_{i}(1000a_i-M)\ge0$。

**证明**：设段长 $L$、和 $A=\sum a_i$，$\mu=A/L$。
$\sum_i(1000a_i-M)=1000A-ML=L(1000\mu-M)$。因 $L\ge1>0$，除以 $L$ 不改号：$\ge0\iff1000\mu-M\ge0\iff\mu\ge M/1000$。$\blacksquare$
整数化后二分区间 $M\in[1000(\min a-1),1000(\max a+1)]$，$\lceil\log_2(2\times10^7+1)\rceil=25$ 次判定，得到的 $M^\ast=\max\{M:\text{整数化判定为真}\}$ 满足
$\dfrac{M^\ast}{1000}\le A^\ast<\dfrac{M^\ast+1}{1000}$（左边：$M^\ast$ 达标 $\Rightarrow A^\ast\ge M^\ast/1000$；右边：$M^\ast+1$ 不达标 $\Rightarrow A^\ast<(M^\ast+1)/1000$）。
**但要注意输出的舍入方向**：直接打印 $M^\ast/1000$ 得到的是**截断**值，而题面"保留 3 位小数"通常按四舍五入理解；当 $A^\ast\times1000$ 的小数部分 $\ge0.5$（例如 $A^\ast=5.0007$，$M^\ast=5000$）时会差 $0.001$。
**正确用法**：把放大倍数取成 $10^4$（判 $\sum(10^4a_i-M)\ge0$），打印 $M^\ast/10^4$ 并交给 `setprecision(3)` 去四舍五入，误差上界 $10^{-4}\ll5\times10^{-4}$ 就安全了；代价是 $\lceil\log_2(2\times10^8)\rceil=28$ 次判定、单项 $|10^4a_i-M|\le2\times10^8$、累加 $\le2\times10^{13}$（**必须 `i64`**）。

**浮点误差评估（本文主代码用 `double`）**
`double` 的单元舍入误差 $u=2^{-53}\approx1.1\times10^{-16}$。经典最坏界
$$|E|\le (n-1)u\sum_i|b_i|\approx10^5\times1.1\times10^{-16}\times2\times10^9\approx2.2\times10^{-2}.$$
这是"每一步舍入都同向"的**极悲观**上界（实际部分和通常远小于 $2\times10^9$，误差近似随机游走，量级在 $10^{-9}\sim10^{-7}$）。
判定阈值是 $s_j-s_i\ge0$，而 $s_j-s_i=\sum a - xL$ 对 $x$ 的斜率是 $-L\le-1$，故绝对误差 $E$ 最多让二分边界移动 $E/L\le E$。
**加固选项**（若担心最坏界）：
1. 把 `s[]` 声明为 `long double`（$u=2^{-63}\approx1.08\times10^{-19}$，最坏界降到 $2.2\times10^{-5}$，比 $5\times10^{-4}$ 小 20 倍）；
2. 或直接改用引理 13 的整数化判定（零浮点误差）。
本文主代码保留 `double`（与最广泛接受的写法一致），并在此明确记号与风险，两个加固点都在一行改动之内。

**循环与终止**：固定 $60$ 次迭代（见引理 10 末尾），不写 `while(r-l>eps)`。

**输出**：`cout<<fixed<<setprecision(3)<<l<<'\n';`。打印 $l$（恒满足 $l\le A^\ast$）而不是 $(l+r)/2$，可保证输出值不会因抖动而**超过**真值；题面只写"保留 3 位小数"，未说明是否特殊判，本文按标准四舍五入输出。

**边界数组尺寸**：`s[]` 需要 $n+1$ 格（$s_0..s_n$），$n\le10^5\Rightarrow100001\le$ `mxn{100005}` ✔；`q[]` 至多 $n$ 个下标 ✔。`s[0]=0` 必须在每次 `check` 里显式赋值（全局数组只有第一次是 $0$）。

### 2.8 另一条路线（本文不实现，仅作归约收尾）

回到引理 4 的"最大斜率"视角：$A^\ast$ 是点集 $\{(k,p_k)\}$ 中横坐标差落在 $[S,T]$ 内的点对的最大斜率。
- 若无长度限制，最大斜率一定出现在**上凸壳**的相邻顶点之间（凸壳的边斜率单调递减；这是旋转卡壳的经典结论，本文不展开证明），可 $O(n\log n)$ 排序建壳 + $O(n)$ 扫描。
- 加上"$S\le i-j\le T$"后，扫描时要把滑出窗口的点从壳上删掉：**删的是凸壳中间的元素**，需要带"上下界"的可撤销单调栈（或分块/线段树维护壳），实现明显比二分复杂，出错的概率也高。
- 对比：二分答案把非线性的"比值"线性化成 $s_j-s_i\ge0$，剩下的只是滑动窗口最小值——**每步都是教科书组件**。在 $n=10^5$、精度只需 $10^{-3}$ 的设定下，$60n$ 的 $1.8\times10^7$ 次操作完全够用，因此选二分。
- 一句话总结这次归约：**"最大化比值" → （猜值线性化）→ "存在性判定" → （前缀和）→ "区间长度受限的差 $\ge0$" → （窗口同步平移）→ "滑动窗口最小值"**。

## 3. 模式总结（Pattern Summary）

按**真实思考顺序**列出，同一个大类里重复使用的技巧拆成独立条目。

- 探索性质 —— 先用夹逼（引理 1）与加权混合（引理 3）把"平均值"钉成**比值型**目标，判断它不是可加型 DP；再用引理 4 把它几何改写成"点对最大斜率"。
- 考虑简化版（1）—— 放开长度约束 $S=1$：答案退化成 $\max a_i$（引理 5），从而确认"难度全在下界 $S\ge2$"。
- 考虑简化版（2）—— 钉死长度 $S=T=L$：分母相同，比较退化为比较段和，$O(n)$ 前缀和可解（引理 6），并暴露出"分母随候选变化"是唯一障碍。
- 剖析贪心失败（A）—— "只试长度 $S$ 和 $T$"：被 $[10,-5,10,-5,10]$（最优在内部长度 $3$）穷举否证。
- 剖析贪心失败（B）—— "最优段含最大元素"：被 $[100,-1000,50,50]$（$S=T=2$，答案 $50$）否证。
- 剖析贪心失败（C）—— "平均值下降就停止扩展"：被 $S=3,T=5$、$a=[4,3,-1,1,8]$ 否证（$A^\ast=3.000$，贪心输出 $2.75$）；前缀平均值序列可以非单调。
- 剖析贪心失败（D）—— "只记以 $i$ 结尾的最优平均值"：被 $[9,9,0,8]$（$S=2,T=3$）否证；结论是状态必须同时含**和**与**长度**，$O(nT)$ 不可接受。
- 结构性引理 / 参数压缩 —— 引理 7 把长度上界压到 $\min(T,2S-1)$，既解释了 (A)(C) 为什么错，也界定了"上界约束何时真正生效"。
- 经典解法：二分答案 —— 猜斜率 $x$，用 $L(\mu-x)$ 消掉分母，把"最大化比值"换成单调判定（引理 8、9），并证明分界点就是答案（引理 10）。
- 归约到更简单问题 —— 判定 $\sum(a_i-x)\ge0$ 改写为"差分前缀和 $s$ 上，长度受限的点对比较"，即 $s_j\ge\min_{i\in[\max(0,j-T),\,j-S]}s_i$（引理 11）。
- 经典解法：单调队列 —— 窗口两端同步右移 $\Rightarrow$ 滑动窗口最小值，$O(n)$ 一次判定；正确性靠"被弹出者被更晚且更小的元素永久支配"（引理 12）。
- 归约到更简单问题（备选，未实现）—— 引理 4 的最大斜率视角可用"前缀点集上凸壳 + 旋转卡壳"做到 $O(n\log n)$，但长度上界 $T$ 需要动态删除壳上点，实现复杂度明显高于二分；本文不采用。
- 溢出与精度防护 —— 逐层估量级（$2\times10^9$ 临界 `int`、整数化变体 $2\times10^{12}$ 必须 `i64`），二分固定迭代次数、下界输出（§2.7、引理 13）。
- 手算验证 —— 小数据穷举所有合法段列表，与算法中间量（$s$、队列表）逐项对齐（§4.4）。

### 4.1 符号表（每个量存什么、怎么初始化、怎么记）

| 符号 | 类型/作用域 | 存什么 | 初始化 | 一行记忆 |
|---|---|---|---|---|
| `n,S,T` | `int`，全局 | 题面输入：序列长度、段长下界、段长上界 | 由 `cin` 读入 | $S\le\text{len}\le T$ |
| `a[]` | `int[mxn]`，全局 | $0$-based 的元素价值 $a_0..a_{n-1}$ | 逐行读入 | "价值" |
| `mn,mx` | `double`，`main` 局部 | 全局最小/最大值，用来定二分的初界 | `mn=1e9, mx=-1e9` 边读边 `min/max` | 答案被夹在 $[\min a,\max a]$（引理 2） |
| `l,r` | `double`，`main` 局部 | 二分区间端点 | `l=mn-1`（必真）、`r=mx+1`（必假） | **不变量：`check(l)` 真、`check(r)` 假、$l\le A^\ast<r$** |
| `x` | `double`，`check` 形参 | 被猜测的平均值（候选斜率） | 每轮传入 `(l+r)/2` | "能不能达到 $x$" |
| `s[]` | `double[mxn]`，全局 | **减过 $x$ 的前缀和**：`s[k]=Σ_{i<k}(a[i]-x)`，$0\le k\le n$ | 每次进 `check` **必须** `s[0]=0` 再递推（全局数组不会自动清） | s = "shifted prefix sum" |
| `q[]` | `int[mxn]`，全局 | 单调队列的**槽**，存的是 `s` 的**下标**（不是值） | 无需清空，靠 `h,t` 复位 | 队里是"候选左端点" |
| `h,t` | `int`，`check` 局部 | 队头/队尾指针，区间语义**半开** $[h,t)$ | `h=0,t=0`（空队） | `s[q[h]]` = 当前窗口最小值 |
| `j` | `int` | 段落**右端**（半开，段是 `a[i..j-1]`） | `for(j=1;j<=n;++j)` | 右端点扫描 |
| `k` | `int` | 本轮新进入窗口的**左端点** `k=j-S` | 每轮重算 | "刚好长度 $S$ 的那个左端" |

段落约定：代码里段记作 $0$-based **半开区间** $[i,j)$，即取 $a_i,\dots,a_{j-1}$，长 $j-i$；§2.1 引理 4 中的 $(j,i]$ 只是同一批段在 $1$-based 前缀和记号下的写法。全程不做 `--u` 式下标转换。

### 4.2 算法步骤（编号，带不变量）

1. **读入**：`cin>>n>>S>>T;` 然后循环读 `a[i]`，同时更新 `mn,mx`。
2. **定初界**：`l=mn-1`，`r=mx+1`。由引理 2 + 引理 8，`check(l)` 必真、`check(r)` 必假，不变量成立。
3. **二分 $60$ 轮**：`mid=(l+r)/2`；若 `check(mid)` 则 `l=mid`（$mid$ 可达，往上调），否则 `r=mid`。引理 10 保证不变量保持且 $r-l$ 每轮减半。
4. **`check(x)` 第一步：造差分前缀和**。`s[0]=0;` 然后 `s[i+1]=s[i]+a[i]-x`（$i=0..n-1$）。此时 $s_k$ 即 §2.6 引理 11 中的 $s$。
5. **`check(x)` 第二步：滑窗最小**。置 `h=0,t=0`（空队），$j$ 从 $1$ 扫到 $n$：
   1. `k=j-S`；若 `k>=0`，先把队尾所有满足 `s[q[t-1]]>=s[k]` 的下标弹出（`--t`），再 `q[t++]=k`。→ 队列右端（下标最大处）随之扩展，被弹者由引理 12 第 2 点说明永不可用。
   2. 循环弹出队头 `q[h]<j-T` 的下标（`++h`）。→ 这些下标会让段长超过 $T$，必须剔除。
   3. 若队列非空且 `s[j]>=s[q[h]]`，说明存在合法 $i$ 使 $s_j-s_i\ge0$，**立刻 `return true`**。
   （步骤 1 在 `k<0` 即 $j<S$ 时不插入，队列保持空，步骤 3 被 `h<t` 挡掉 → 自动实现"$j\ge S$"的要求。）
6. **`check(x)` 收尾**：扫完都没返回则 `return false`。
7. **输出**：`cout<<fixed<<setprecision(3)<<l<<'\n';`（取不变量给出的下界 $l\le A^\ast$）。

**顺序上的坑（真正的关键是"第 5.2 步必须在第 5.3 步之前"）**：
- 插入与过期的先后其实**无关**：新插入的 `k=j-S ≥ j-T`（因 $S\le T$），永远不会被同轮的过期步骤误删。
- 但**过期必须在查询之前**：否则队头可能是一个"太早的左端点"（对应长度 $>T$），把判定带偏。
  复现：$n=3,S=T=2$，$a=[10,-5,10]$，$x=4$，$s=[0,6,-3,3]$。若完全不执行过期步骤：
  $j=2$ 插入 $k=0$，队 $[0]$，$s_2-s_0=-3<0$ 不返回；$j=3$ 插入 $k=1$（$s_1=6$，队尾 $s_0=0<6$ 不弹），队 $[0,1]$，队头仍是**已越界的 $0$**，$s_3-s_0=3\ge0$ → 误报 `true`，而真实答案是 `false`（$A^\ast=2.5$）。
  执行过期步骤后，$j=3$ 时 $q[h]=0<3-2=1$ 被弹出，队只剩 $[1]$，$s_3-s_1=-3<0$ → 正确判假 ✔

### 4.3 复杂度

- 单次 `check`：造前缀 $n$ 步 + 扫描 $n$ 步；扫描中每个下标至多入队 $1$ 次、出队 $1$ 次 → 队列操作总数 $\le 2n$，故 $O(n)$。
- 总体：$60\times O(n)=O(60n)$，$n=10^5$ 时约 $60\times(10^5+2\cdot10^5)=1.8\times10^7$ 次基本操作（含浮点加减与比较）。
- 空间：`a[]`、`q[]`、`s[]` 各 $O(n)$ → $O(n)$（$\approx 100005\times(4+4+8)\,\text{B}\approx1.6\,\text{MB}$）。
- 对照 $30\%$ 的 $n\le1000$：$O(n^2)$ 枚举（$10^6$）也能过部分分，与 §1 的子任务阶梯一致。

**用例 2（$S=1$，测引理 5）** $n=5,S=1,T=3$，$a=[1,2,3,4,5]$。

```cpp
// P1419 寻找段落  二分答案 + 单调队列
// https://www.luogu.com.cn/problem/P1419
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005};                  // n<=1e5，+5 松弛；前缀和多用 1 格

int n,S,T,a[mxn],q[mxn];
double s[mxn];                              // 减过 x 的前缀和

// 判定：是否存在长度在 [S,T] 且平均值 >= x 的段落
bool check(double x)
{
	s[0]=0;                                 // 全局数组不会自动清，每轮必须显式置 0
	for(int i=0;i<n;++i)
		s[i+1]=s[i]+a[i]-x;
	int h=0,t=0;                            // 队列区间语义 [h,t)
	for(int j=1;j<=n;++j)
	{
		int k=j-S;                          // 随 j 右移，新加入窗口的左端点
		if(k>=0)
		{
			while(h<t&&s[q[t-1]]>=s[k])     // 被更晚、更小者永久支配
				--t;
			q[t++]=k;
		}
		while(h<t&&q[h]<j-T)                // 长度会超过 T，必须过期（顺序见 §4.2）
			++h;
		if(h<t&&s[j]>=s[q[h]])
			return true;
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>S>>T;
	double mn=1e9,mx=-1e9;
	for(int i=0;i<n;++i)
	{
		cin>>a[i];
		mn=min(mn,(double)a[i]);
		mx=max(mx,(double)a[i]);
	}
	double l=mn-1,r=mx+1;                   // 不变量：check(l) 真、check(r) 假
	for(int it=0;it<60;++it)
	{
		double mid=(l+r)/2;
		if(check(mid))
			l=mid;
		else
			r=mid;
	}
	cout<<fixed<<setprecision(3)<<l<<'\n';
	return 0;
}
```

### 代码说明

- **下标约定**：全程 $0$-based，段落写成半开区间 $[i,j)$（长 $j-i$），前缀和 `s` 的下标 $0..n$ 共 $n+1$ 个格子；不做 `--u` 式转换是因为输入本身就是序列本身。
- **`q[]` 存下标不存值**：比较用 `s[q[...]]`，这样过期判断（`q[h]<j-T`）与取最小值（`s[q[h]]`）都是 $O(1)$。
- **无需 `fill_n`**：本题没有"以 INF 表示不可达"的数组；`s[]` 每轮由 `s[0]=0` 起完整重算，`q[]` 靠局部 `h=0,t=0` 复位（风格规范里的 `fill_n` 只针对 INF 哨兵数组，此处无该语义）。
- **前向星 / `E[i^1]`**：本题不是图论题，不建图，故不涉及。
- **固定 $60$ 轮二分**：与 `while(r-l>eps)` 等价但必然终止（理由见 §2.5 末尾与引理 10）。
- **两段备用代码**以注释形式保留（风格规范的"考古层"），一是零浮点误差的整数化判定，二是 $O(n^2)$ 朴素枚举，供日后本地对拍时直接启用。
