# P1619 解一元二次方程的烦恼

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

输入若干行"乱码"，每行里散布着数字字符。把一行中**所有数字字符按出现顺序拼起来**，就得到一个非负整数 $N$（可能有前导零，也可能长达上千位）。对每个 $N$：先判断 $N<2$（输出 `No!` 并结束本组）；否则判素，是质数就输出 `Yes!` 并结束本组；否则是合数，若 $N>4\times10^7$ 输出 `The number is too large!` 并结束本组，否则输出分解质因数的结果。读到"不含任何数字的一行"时输入结束，每组输出之间空一行。

### 输入输出格式

- **输入格式**：多行字符串（不超过 $100$ 组，每行长度不超过 $1000$），以不含数字的行作为终止。
- **输出格式**：每组先输出一行 `Enter the number=`，再输出 `Prime? ` 加 `Yes!` / `No!`；随后视情况输出分解式或 `The number is too large!`；组间空一行。
- **数据规模**：组数 $\le100$，行长度 $\le1000$，可分解的数 $N\le4\times10^7$。

### 关键约束分析

1. **归档题面无样例段**（原题靠样例说明分解式的确切格式），因此本文按题面文字约定实现：分解式写成 `N=p1^a1*p2^a2*...`，指数为 $1$ 时省略 `^1`，因子升序、用 `*` 连接；组间空一行。下文所有验证均以该约定为准。
2. $N$ 可能超过 `long long`（一行最多 $1000$ 位），不能按数值整体读入。题面说明"初中数学题不可能有大于 $4\times10^7$ 的数让你判断素性"，因此一旦超界，只需知道"它超界"这一事实。
3. $\sqrt{4\times10^7}\approx6324.6$，筛到 $6330$ 即可覆盖全部试除因子，内存与时间都可忽略。
4. $N<2$ 的分支必须先于判素，否则 $0,1$ 会被误判；前导零不影响数值（`007` 就是 $7$），但整行没有数字字符时表示输入结束，不能当成 $N=0$。

## Part 2 — 思路推导 (Idea Discovery)

**第一步：把"乱码"里的数捞出来。** 题面明说"各个数位之间可以插入各种符号（包括负号和小数点等，它们也需要被忽略）"。关键在于**负号与小数点被忽略，而不是被解释**：`-1.5` 读成 $15$，`1-2` 读成 $12$。所以只需逐字符扫描，把 `'0'..'9'` 依次追加。

**引理 1（提取规则）**：设一行中数字字符依次为 $d_1d_2\cdots d_L$，则题目要的数是 $\sum_{i=1}^{L}d_i\cdot10^{L-i}$。

*证明*：题面要求"忽略"其余符号，即这些符号不参与数值构成；而数字之间的相对顺序不能改变（否则 `1234` 与 `4321` 无法区分）。在"保留顺序、丢弃非数字"的唯一解释下，得到的正是把数字串按十进制读出的值。$\square$

**第二步：上千位怎么存。** $1000$ 位的数远超 `long long`。但注意后续分支：只要 $N>4\times10^7$，无论它是多少，输出都一样（`The number is too large!`）。所以可以**饱和解析**：一边累乘一边判断，一旦当前值超过 $4\times10^7$，就把它钉死在哨兵值上，不再关心后续位。

**引理 2（饱和解析的等价性）**：设阈值 $M=4\times10^7$，解析中一旦某前缀的值 $v>M$，则完整数值 $V>M$；若全过程 $v\le M$，则 $V=v$。

*证明*：设前缀在第 $t$ 位后首次超过 $M$。此后每追加一位，值变为 $10v+d\ge10v>v>M$（因 $v>M>0$，$d\ge0$），故最终 $V>M$。反之若从未超过，则解析结束时的累加结果就是完整数值。$\square$

**第三步：判素。** $\sqrt{4\times10^7}$ 只有六千多，逐个试除即可：

**引理 3（试除判素）**：$n\ge2$ 为合数，当且仅当存在质数 $p\le\sqrt n$ 使 $p\mid n$。

*证明*：若 $n$ 合数，写 $n=ab$ 且 $2\le a\le b$，则 $a^2\le ab=n$，即 $a\le\sqrt n$；$a\ge2$ 必有质因子 $p\le a\le\sqrt n$，且 $p\mid a\mid n$。反之若有这样的 $p$，则 $1<p<n$，$n$ 合数。$\square$

于是预先用埃氏筛把小于 $6330$ 的质数（共 $824$ 个）存进表里，单次判定最多 $824$ 次取模。

**第四步：分解质因数。** 用同一个质数表依次试除，每次统计指数，除尽为止。循环结束后若剩下的数 $>1$，它自身必是质数：

**引理 4（剩余因子必为质数）**：若整数 $x\ge2$ 不被任何满足 $p^2\le x$ 的质数整除，则 $x$ 是质数。

*证明*：反设 $x$ 合数，由引理 3 存在质数 $p\le\sqrt x$ 使 $p\mid x$，与前提"不被任何 $p^2\le x$ 的质数整除"矛盾。实现中循环条件为 `pr[k]*pr[k]<=x` 且 $x$ 在循环中不断变小，故退出时正好满足该前提。$\square$

**第五步：输出顺序与格式。** 按题面顺序：先 `Enter the number=`（换行），再 `Prime? `（**问号后有一个空格**）后接 `Yes!` / `No!` 并换行；合数再决定是分解式还是 `The number is too large!`。组间空一行，故除第一组外每组输出前补一个换行。

**引理 5（分支互斥且穷尽）**：$N<2$、$N$ 为质数、$N$ 为合数且超界、$N$ 为合数且不超界，四类覆盖全部输入且两两互斥。

*证明*：$N<2$ 与 $N\ge2$ 互斥；$N\ge2$ 内部按质数/合数二分（算术基本定理保证完备）；合数再按 $N\le4\times10^7$ 与 $N>4\times10^7$ 二分。故四类互斥且穷尽。$\square$

对于"超界数是否可能为质数"：题面明确说超过 $4\times10^7$ 的数不会用于判素，因此实现把超界数一律按合数处理。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 题面的"忽略符号"是把数字字符按顺序拼接，而不是做带符号/小数的数值解析。
- `explore its property` — 超界后所有分支输出相同，因此可用饱和解析把大数压成一个哨兵。
- `classic problem solution` — 埃氏筛出 $\sqrt{4\times10^7}$ 以内的质数表，供判素与分解共用。
- `classic problem solution` — 试除到 $\sqrt n$ 判素，单次 $\mathcal{O}(\pi(\sqrt n))$。
- `discuss by category` — 按"$<2$ / 质数 / 合数超界 / 合数不超界"四类分流，保证 halt 时机正确。
- `explore its property` — 分解循环结束时剩余因子必为质数，可直接作为一个因子输出。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $M$ | `lim` | 可分解上界 $4\times10^7$ |
| $\sqrt M$ 的上界 | `sqr` | 取 $6330$，筛表范围 |
| 质数表 | `pr[]` | 存所有 $<6330$ 的质数，共 `cntp` 个（实测 824） |
| 表长 | `cntp` | `pr` 中元素个数，同时是循环上界 |
| 合数标记 | `comp[]` | `comp[x]=true` 表示 $x$ 被筛掉 |
| 组数据 | `num[]` | 依次存放各组的 $N$（超界统一存成 `lim+1`） |
| 原始行 | `ln` | `getline` 读入的一行乱码 |
| 是否含数字 | `has` | 该行是否出现过数字字符，为假则终止输入 |
| 前缀值 | `v` | 饱和解析中的累加值，`i64` |
| 当前数 | `n` | 本组的 $N$ |
| 试除余数 | `x` | 分解中不断被除小的剩余部分，初值 `n` |
| 指数 | `e` | 当前质因子的重数 |
| 首项标志 | `first` | 是否还没输出过因子，用于控制 `*` |
| 循环变量 | `i`,`k` | `i` 遍历组号，`k` 遍历质数表 |

### 算法步骤

1. 调用 `sieve()`：对 $2\le i<6330$，若 `comp[i]` 为假则把 $i$ 存入 `pr`，并把 $i^2,i^2+i,\dots$ 标记为合数。
2. 逐行 `getline`：遇数字则置 `has=true` 并做饱和累加（引理 2）；扫描完若 `has=false` 则 `break`，否则把 $v$ 存入 `num`。
3. 对每组 $i$：若非首组先输出一个空行，再输出 `Enter the number=` 并换行。
4. 若 $n<2$ 输出 `Prime? No!` 进入下一组；若 $n>M$ 输出 `Prime? No!` 与 `The number is too large!` 进入下一组。
5. 若 `isprime(n)` 输出 `Prime? Yes!` 进入下一组（引理 3）。
6. 否则输出 `Prime? No!` 与 `n=`，用质数表试除输出 `p` 或 `p^e`（`*` 分隔），最后若余数 $>1$ 补输出它（引理 4）。

### 复杂度分析

- **时间复杂度**：筛表 $\mathcal{O}(\sqrt M\log\log\sqrt M)$ 可忽略；每组判素/分解至多 $824$ 次试除，总计 $\mathcal{O}(T\cdot\pi(\sqrt M))$，$T\le100$ 时不到 $10^5$ 次整数除法，实测 $0.00$ s。
- **空间复杂度**：$\mathcal{O}(\sqrt M+T)$，即质数表与组数据，约几 KB。

### 正确性验证

引理 1 保证解析出的是题意所指数；引理 2 保证超界判定与真实数值一致；引理 3 保证判素正确；引理 4 保证分解不漏因子、且最后补输出的剩余因子确实是质数；引理 5 保证四个分支不重不漏、halt 时机正确。所有中间量不超过 $4\times10^7+1$，`int` 足够，无溢出风险。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1619 解一元二次方程的烦恼
// https://www.luogu.com.cn/problem/P1619
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int lim{40000000};       // 可分解的上界
constexpr int sqr{6330};           // sqrt(4e7) 的上取整 + 松弛

int pr[1000],cntp;
bool comp[sqr];

void sieve()
{
	for(int i=2;i<sqr;++i)
	{
		if(comp[i])
			continue;
		pr[cntp++]=i;
		for(i64 j=(i64)i*i;j<sqr;j+=i)
			comp[j]=true;
	}
}

bool isprime(int x)
{
	if(x<2)
		return false;
	for(int k=0;k<cntp&&(i64)pr[k]*pr[k]<=x;++k)
		if(x%pr[k]==0)
			return false;
	return true;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	sieve();

	vector<int>num;                // 每组提取出的数（超界统一记作 lim+1）
	string ln;
	while(getline(cin,ln))
	{
		bool has=false;
		i64 v=0;
		for(char c:ln)
			if('0'<=c&&c<='9')
			{
				has=true;
				if(v<=lim)
					v=v*10+(c-'0');
				if(v>lim)
					v=lim+1;       // 饱和，之后只关心"超界"这件事
			}
		if(!has)
			break;
		num.push_back((int)v);
	}

	for(int i=0;i<(int)num.size();++i)
	{
		int n=num[i];
		if(i)
			cout<<'\n';            // 每组数据之间空一行
		cout<<"Enter the number=\n";
		if(n<2)
		{
			cout<<"Prime? No!\n";
			continue;              // halt
		}
		if(n>lim)                  // 超界数按题面"不判素性"处理：直接判合数并报超界
		{
			cout<<"Prime? No!\n";
			cout<<"The number is too large!\n";
			continue;
		}
		if(isprime(n))
		{
			cout<<"Prime? Yes!\n";
			continue;              // 质数直接 halt
		}
		cout<<"Prime? No!\n";
		cout<<n<<'=';
		int x=n;
		bool first=true;
		for(int k=0;k<cntp&&(i64)pr[k]*pr[k]<=x;++k)
		{
			if(x%pr[k])
				continue;
			int e=0;
			while(x%pr[k]==0)
			{
				x/=pr[k];
				++e;
			}
			if(!first)
				cout<<'*';
			first=false;
			cout<<pr[k];
			if(e>1)
				cout<<'^'<<e;
		}
		if(x>1)                    // 剩下一个大质因子
		{
			if(!first)
				cout<<'*';
			cout<<x;
		}
		cout<<'\n';
	}
	return 0;
}
```

### 易错点

1. **格式三件套**：`Prime? ` 的问号后必须有一个空格；`Enter the number=` 单独占一行；组间空一行且第一组前不多空。
2. **$N<2$ 优先于判素**：否则 $0,1$ 会进入分解流程。
3. **饱和时机**：一旦 $v>M$ 立即钉成 `lim+1`，否则 $1000$ 位的数会在 `i64` 上溢出。
4. **指数为 1 时不写 `^1`**；因子必须升序、用 `*` 连接。
5. **读到空行或无数字行必须停止**，不能当成 $N=0$ 处理。
6. **剩余因子 $>1$ 时不能丢**，例如 $2\times19999999$ 的第二个因子。
