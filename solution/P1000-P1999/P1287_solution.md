# P1287 盒子与球

## 1. 重述题意

给定 $n$ 个**互不相同**的球和 $r$ 个**互不相同**的盒子，要求把 $n$ 个球全部放入 $r$ 个盒子中，且**不允许有空盒子**。问有多少种不同的放法。

两种放法不同，当且仅当存在某个球在两种放法中进入了不同的盒子。

数据范围：$0 \le r \le n \le 10$，答案小于 $2^{31}$。

> 注意：球是**有标号**的（球 1、球 2、…不同），盒子也**有标号**（盒子 1、盒子 2、…不同）。这是与"斯特林数（球无标号）"问题的关键区别。

---

## 2. 思维链

### 2.1 探索性质：到底在数什么？

先把"每个球放进哪个盒子"这件事拆开看。

- 球是有标号的：球 1 和球 2 是两个不同的对象。
- 盒子是有标号的：盒子 1 和盒子 2 是两个不同的对象。
- "放法"由"每个球被分配到了哪个盒子"唯一决定。

因此，一个放法本质上就是一个函数

$$f: \{1,2,\dots,n\} \to \{1,2,\dots,r\}$$

即"球 $i$ 放入盒子 $f(i)$"。

**没有任何空盒子限制**时，每个球有 $r$ 种选择，共 $r^n$ 种。

**加上"不允许有空盒子"**后，要求 $f$ 是**满射**（surjection）：每个盒子至少被分配到 1 个球。

> 性质总结：本题就是求**满射函数**的个数。

### 2.2 考虑简化版本：每个盒子恰好 1 个球

先做最简单的特例。如果 $n = r$，那"不允许空盒子"就意味着每个盒子恰好 1 个球。

此时放法 = 把 $n$ 个球分配给 $r$ 个盒子，每盒 1 个 = **排列** $n!$。

验证：$n = r = 1$ → $1! = 1$ ✓；$n = r = 2$ → $2! = 2$ ✓。

这个特例给了一个直觉：**答案和"分组 + 排列"有关**。

### 2.3 分类讨论：按"盒子里有多少个球"分类

回到一般情况。把"每个盒子分到几个球"看作一组**正整数** $a_1, a_2, \dots, a_r$，其中

$$a_i \ge 1, \quad \sum_{i=1}^{r} a_i = n$$

注意：这里 $a_i$ 对应的是**第 $i$ 个（有标号的）盒子**分到 $a_i$ 个球。

对于给定的 $(a_1, a_2, \dots, a_r)$，放法的计数分三步：

**第一步：把 $n$ 个有标号球分成 $r$ 组，大小分别为 $a_1, a_2, \dots, a_r$。**

这是多重组合数：

$$\binom{n}{a_1, a_2, \dots, a_r} = \frac{n!}{a_1!\,a_2!\cdots a_r!}$$

**证明**：从 $n$ 个球中先选 $a_1$ 个给盒子 1，再从剩下的选 $a_2$ 个给盒子 2，依此类推：

$$\binom{n}{a_1}\binom{n-a_1}{a_2}\binom{n-a_1-a_2}{a_3}\cdots = \frac{n!}{a_1!(n-a_1)!}\cdot\frac{(n-a_1)!}{a_2!(n-a_1-a_2)!}\cdots = \frac{n!}{a_1!a_2!\cdots a_r!}$$

中间的阶乘全部约掉，最终只剩 $\dfrac{n!}{a_1!a_2!\cdots a_r!}$。✓

**第二步：盒子已经标号了，所以分完组后，第 1 组进盒子 1，第 2 组进盒子 2，……，第 $r$ 组进盒子 $r$。不需要额外的排列。**

> 这一点很关键：如果盒子**没有**标号，还需要除以 $r!$（斯特林数的定义）。但本题盒子**有**标号，所以不需要。

**第三步：对所有的 $(a_1, a_2, \dots, a_r)$ 求和。**

因此答案为：

$$\text{ans} = \sum_{\substack{a_1+\cdots+a_r=n\\ a_i\ge 1}} \frac{n!}{a_1!\,a_2!\cdots a_r!}$$

### 2.4 证明这个公式等价于容斥原理

上面用的是"按盒子内球数分类"的方法。下面用**容斥原理**从另一个角度验证同一个答案，确保没有遗漏。

**容斥思路**：

- 总放法（不管是否空盒）：$r^n$
- 减去"至少 1 个盒子空"的放法
- 加上"至少 2 个盒子空"的放法（因为被多减了）
- ……

设 $A_i$ = "盒子 $i$ 为空"的事件。

$$\text{ans} = r^n - \sum_{|S|=1}|A_S| + \sum_{|S|=2}|A_S| - \cdots + (-1)^r\sum_{|S|=r}|A_S|$$

其中 $A_S$ 表示 $S$ 中的所有盒子都为空。若 $|S| = k$，则球只能放入剩下的 $r-k$ 个盒子，放法数 $= (r-k)^n$。

而从 $r$ 个盒子中选 $k$ 个为空的方式有 $\binom{r}{k}$ 种。

因此：

$$\text{ans} = \sum_{k=0}^{r}(-1)^k\binom{r}{k}(r-k)^n$$

**证明这个等式等价于分类求和公式**：

这是经典的**容斥恒等式**（也叫"满射计数"）。其正确性由容斥原理直接保证：

- 全集 $U$ = 所有 $r^n$ 个函数
- $A_i$ = "盒子 $i$ 为空"的函数集合
- 我们要求 $\left|U \setminus \bigcup_{i=1}^r A_i\right|$ = "没有任何盒子为空"的函数数
- 容斥原理给出：$\left|U \setminus \bigcup A_i\right| = \sum_{S \subseteq \{1..r\}}(-1)^{|S|}|A_S|$

而 $|A_S| = (r-|S|)^n$（球只能放 $r-|S|$ 个盒子），按 $|S|=k$ 分组求和得：

$$\sum_{k=0}^{r}\binom{r}{k}(-1)^k(r-k)^n$$

这与上面的分类求和公式给出**同一个数**（都是"满射函数个数"），只是两种不同的计数路径。

> 验证：$n=3, r=2$。
> - 分类法：$(a_1,a_2)$ 可以是 $(1,2)$ 或 $(2,1)$。
>   - $(1,2)$：$\frac{3!}{1!\,2!} = 3$
>   - $(2,1)$：$\frac{3!}{2!\,1!} = 3$
>   - 合计 $= 6$ ✓（与样例一致）
> - 容斥法：$\binom{2}{0}2^3 - \binom{2}{1}1^3 + \binom{2}{2}0^3 = 8 - 2 + 0 = 6$ ✓

### 2.5 与斯特林数的关系

第二类斯特林数 $S(n, r)$ 的定义是：把 $n$ 个**无标号**球分成 $r$ 个**无标号**非空集合的方案数。

本题中球和盒子**都有标号**，所以：

$$\text{ans} = r! \cdot S(n, r)$$

**证明**：

- $S(n, r)$ 把 $n$ 个球分成 $r$ 个非空**无标号**组（不关心哪组进哪个盒子）。
- 本题中，每组球必须分配给一个**特定的标号盒子**，$r$ 个组与 $r$ 个盒子一一对应，共有 $r!$ 种对应方式。
- 因此 $\text{ans} = r! \cdot S(n, r)$。

验证：$S(3,2) = 3$（{1,2,3} 分成 2 个非空无标号组：{1}{2,3}、{2}{1,3}、{3}{1,2}），$2! \times 3 = 6$ ✓。

### 2.6 最终选择：用哪种公式？

| 方法 | 公式 | 特点 |
|------|------|------|
| 分类求和 | $\sum \frac{n!}{a_1!\cdots a_r!}$ | 需要枚举所有正整数解，实现稍复杂 |
| 容斥原理 | $\sum_{k=0}^{r}(-1)^k\binom{r}{k}(r-k)^n$ | 直接 $O(r)$ 项，最简单 |
| 斯特林数 | $r! \cdot S(n,r)$ | 需要先 DP 算斯特林数 |

三种都可行。对于 $n, r \le 10$，**容斥公式**最简洁：只需算 $r+1 \le 11$ 项。

但本题的题目标签包含"Stirling 数"和"搜索/枚举"，说明出题人可能期望 DP 斯特林数。我选择**斯特林数 DP** 作为主解法，因为：

1. 它自然地处理了 $r = 0$ 的边界（$S(n,0) = [n=0]$）。
2. 它是经典的递推，便于理解和验证。
3. 与题目标签一致。

**斯特林数递推**（完整推导）：

$S(n, r)$ = 把 $n$ 个无标号球分成 $r$ 个非空无标号集合的方案数。

考虑**第 $n$ 个球**（把球标号为 $1, 2, \dots, n$ 后，看第 $n$ 个球）：

- **情况 A：第 $n$ 个球单独一组。** 则前 $n-1$ 个球要分成 $r-1$ 个非空组，方案数 $= S(n-1, r-1)$。
  - 为什么是 $r-1$ 组？因为第 $n$ 个球自占一组，剩下的 $n-1$ 个球要填满剩余的 $r-1$ 个组。
  
- **情况 B：第 $n$ 个球加入已有的一组。** 先让前 $n-1$ 个球分成 $r$ 个非空组（$S(n-1, r)$ 种分法），然后把第 $n$ 个球放入其中**任意一组**。有 $r$ 个组可选，所以方案数 $= r \cdot S(n-1, r)$。

两种情况互斥且穷尽（第 $n$ 个球要么独占一组，要么加入已有组），故：

$$S(n, r) = S(n-1, r-1) + r \cdot S(n-1, r)$$

**边界条件**：
- $S(0, 0) = 1$（0 个球 0 个组，空分划，1 种）
- $S(n, 0) = 0$（$n > 0$ 时无法分成 0 个非空组）
- $S(0, r) = 0$（$r > 0$ 时 0 个球无法填满 $r$ 个非空组）

**证明边界 $S(n,0) = 0$（$n > 0$）**：$n$ 个球（$n \ge 1$）要分成 0 个非空组，但至少有 1 个球必须放入某个组，矛盾，故 0 种。✓

**证明边界 $S(0,r) = 0$（$r > 0$）**：0 个球要分成 $r$ 个非空组（$r \ge 1$），但每组至少 1 个球，总共需要 $\ge 1$ 个球，矛盾，故 0 种。✓

最终答案：

$$\text{ans} = r! \cdot S(n, r)$$

> 边界处理：$r = 0$ 时，只有 $n = 0$ 才有解（$0! \cdot S(0,0) = 1$），$n > 0$ 时 $0! \cdot S(n,0) = 0$。
> 边界处理：$r > n$ 时，$S(n,r) = 0$（球不够填满盒子），答案 0。

## 3. 模式总结

按实际思考顺序：

```
- 探索性质 — 放法 = 有标号满射函数；核心约束是"每个盒子非空"
- 考虑简化版本 — n=r 时退为排列 n!，得到"分组 + 排列"的直觉
- 分类讨论 — 按盒子内球数 (a_1,...,a_r) 分类，得多重组合数求和
- 容斥验证 — 用容斥公式 sum (-1)^k C(r,k)(r-k)^n 交叉验证分类法
- 关联经典 — 答案为 r! * S(n,r)，第二类斯特林数（无标号分划）
- 经典递推 — S(n,r) = S(n-1,r-1) + r*S(n-1,r)，O(nr) DP 求解
```

## 4. 正式解法

### 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 球数（输入），$0 \le n \le 10$ |
| $r$ | 盒子数（输入），$0 \le r \le n$ |
| $S[i][j]$ | 第二类斯特林数：把 $i$ 个无标号球分成 $j$ 个非空无标号集合的方案数 |
| `fac[i]` | $i!$（阶乘），$0 \le i \le 10$ |
| `ans` | 最终答案 $= r! \cdot S(n, r)$ |

### 算法步骤

1. **读入** $n$ 和 $r$。

2. **预处理阶乘**：`fac[0]=1`；对 $i = 1, 2, \dots, 10$，`fac[i] = fac[i-1] * i`。

3. **初始化斯特林数 DP 表**：
   - `S[0][0] = 1`
   - 其余 `S[i][j] = 0`（全局数组默认 0，无需额外初始化）

4. **DP 填表**：对 $i = 1, 2, \dots, n$，对 $j = 1, 2, \dots, \min(i, r)$：
   $$S[i][j] = S[i-1][j-1] + j \times S[i-1][j]$$
   
   > 注意：$j$ 的上界是 $\min(i, r)$，因为 $S(i, j) = 0$ 当 $j > i$ 或 $j = 0$（且 $i > 0$）。

5. **计算答案**：`ans = fac[r] * S[n][r]`。

6. **输出** `ans`。

### 复杂度

- 时间：$O(n \cdot r) \le O(100)$，可忽略。
- 空间：$O(n \cdot r) \le O(100)$，可忽略。

### 验证状态

- 样例 $n=3, r=2$：$S[3][2] = S[2][1] + 2 \cdot S[2][2] = 1 + 2 \times 1 = 3$，$\text{ans} = 2! \times 3 = 6$ ✓
- $n=0, r=0$：$S[0][0] = 1$，$\text{ans} = 0! \times 1 = 1$ ✓
- $n=1, r=0$：$S[1][0] = 0$，$\text{ans} = 0$ ✓
- $n=5, r=3$：$S[5][3] = 25$，$\text{ans} = 6 \times 25 = 150$（可由容斥验证：$3^5 - 3 \cdot 2^5 + 3 \cdot 1^5 = 243 - 96 + 3 = 150$ ✓）

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{15};

int n,r,S[mxn][mxn],fac[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>r;
	fac[0]=1;
	for(int i=1;i<mxn;++i)
		fac[i]=fac[i-1]*i;
	S[0][0]=1;
	for(int i=1;i<=n;++i)
		for(int j=1;j<=r&&j<=i;++j)
			S[i][j]=S[i-1][j-1]+j*S[i-1][j];
	cout<<fac[r]*S[n][r]<<'\n';
	return 0;
}
```

**代码说明**：

- `S[i][j]` 为全局数组，默认初始化为 0，只需手动设 `S[0][0]=1`。
- `j` 的双重上界 `j<=r&&j<=i` 避免越界且跳过无用计算（$S(i,j)=0$ 当 $j>i$）。
- 答案直接 `fac[r]*S[n][r]`，无需单独变量。
