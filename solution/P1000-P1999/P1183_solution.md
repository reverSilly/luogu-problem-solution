# P1183 多边形的面积 — 题解

## Part 1 · 重述问题

平面上有一个简单多边形（无自交、无缺口），每条边都平行于 $x$ 轴或 $y$ 轴。顶点按**逆时针**顺序给出，共 $n$ 个，第 $i$ 个顶点坐标为 $(x_i, y_i)$。多边形由"从最后一个顶点画边回到第一个顶点"闭合。要求输出多边形面积（整数）。

约束：$1 \le n \le 100$，$-200 \le x,y \le 200$。注意可能存在连续三个顶点共线的情况（不影响面积公式）。

## Part 2 · 思考过程（Chain-of-Thought）

### 2.1 探索性质

多边形是正交的（边平行于坐标轴），这通常暗示可以用"扫描线 + 分治"或"水平/垂直边配对"的方法。但仔细想想：面积公式本身只依赖顶点的坐标和顺序，**不依赖边的方向**。一个任意多边形（只要不自交）的面积都可以由顶点坐标唯一确定。正交只是让坐标都是整数、面积也是整数，简化了输出格式（不用处理小数）。

所以关键不是"正交"，而是"给了有序顶点序列，求面积"。

### 2.2 考虑更简单的版本：三角形

最简单的多边形是三角形。设顶点为 $A(x_1,y_1)$, $B(x_2,y_2)$, $C(x_3,y_3)$。

三角形的面积可以用向量叉积表示。从原点 $O$ 到各顶点的向量为 $\vec{OA}$, $\vec{OB}$, $\vec{OC}$。

三角形 $OAB$ 的有向面积为：

$$[OAB] = \frac{1}{2}(x_1 y_2 - x_2 y_1)$$

这里 $(x_1 y_2 - x_2 y_1)$ 就是向量 $\vec{OA}$ 和 $\vec{OB}$ 的二维叉积。

**引理 1**：对于原点 $O$ 和两个向量 $\vec{u}=(u_x,u_y)$、$\vec{v}=(v_x,v_y)$，表达式 $u_x v_y - u_y v_x$ 等于以 $O$、$u$、$v$ 为顶点的三角形的**两倍有向面积**。

**证明**：

设 $\vec{u}$ 和 $\vec{v}$ 的夹角为 $\theta$（有向角）。二维叉积的几何定义为：

$$\vec{u} \times \vec{v} = u_x v_y - u_y v_x = |\vec{u}||\vec{v}|\sin\theta$$

（正号表示 $\vec{v}$ 在 $\vec{u}$ 的逆时针方向。）

而三角形 $Ouv$ 的（无符号）面积为 $\frac{1}{2}|\vec{u}||\vec{v}|\sin\theta$（当 $\sin\theta > 0$）。

所以 $u_x v_y - u_y v_x = 2 \cdot [Ouv]$（有向意义下，$\sin\theta$ 可正可负）。

当 $\sin\theta < 0$（即 $v$ 在 $u$ 的顺时针方向）时，$u_x v_y - u_y v_x$ 为负，对应"有向面积"为负——这正是我们需要的，因为逆时针绕行的多边形中，某些扇形贡献为正、某些为负，自动相消。$\blacksquare$

### 2.3 从三角形推广到任意多边形（扇形分解）

**引理 2（扇形分解 / 鞋带公式推导）**：

设简单多边形顶点按逆时针顺序为 $P_0, P_1, \dots, P_{n-1}$，$P_n = P_0$（闭合）。则多边形面积为：

$$A = \frac{1}{2} \sum_{i=0}^{n-1} (x_i y_{i+1} - x_{i+1} y_i)$$

**证明**：

以原点 $O$ 为参考点，把多边形分解为 $n$ 个"扇形三角形" $OP_iP_{i+1}$（$i = 0, 1, \dots, n-1$，其中 $P_n = P_0$）。

每个扇形 $OP_iP_{i+1}$ 的**两倍有向面积**为 $x_i y_{i+1} - x_{i+1} y_i$（由引理 1）。

**关键论断**：当原点 $O$ 在**多边形外部**时，这些扇形有向面积之和等于多边形面积的两倍。

**证明**（用有向面积的加法性）：

有向面积的一个重要性质：两个多边形的有向面积之和等于它们"拼接"后多边形的有向面积（共享边相互抵消）。

具体地，多边形 $P_0 P_1 \dots P_{n-1}$ 的有向面积可以写成：

$$2A = \sum_{i=0}^{n-1} [OP_iP_{i+1}]$$

其中 $[OP_iP_{i+1}]$ 表示有向三角形面积。

这个等式的直觉证明：从原点 $O$ 向每个顶点 $P_i$ 引射线，把多边形"扇形化"。逆时针绕行多边形时，每个扇形 $OP_iP_{i+1}$ 对总面积的贡献取决于它是"进入"还是"退出"多边形内部。

更严格的证明：考虑多边形边界的有向面积公式。多边形边界的有向面积可以用格林公式（Green's theorem）表达：

$$2A = \oint x\,dy - y\,dx = \sum_{i=0}^{n-1} (x_i y_{i+1} - x_{i+1} y_i)$$

这里 $\oint$ 沿多边形边界逆时针积分。将线积分离散化到每条边 $P_i \to P_{i+1}$（直线段）：

在边 $P_iP_{i+1}$ 上，$x$ 从 $x_i$ 线性变到 $x_{i+1}$，$y$ 从 $y_i$ 线性变到 $y_{i+1}$。参数化为 $x(t) = x_i + t(x_{i+1}-x_i)$, $y(t) = y_i + t(y_{i+1}-y_i)$, $t \in [0,1]$。

则：
$$\int_0^1 x\,\frac{dy}{dt}\,dt - \int_0^1 y\,\frac{dx}{dt}\,dt = \int_0^1 x(t)(y_{i+1}-y_i)\,dt - \int_0^1 y(t)(x_{i+1}-x_i)\,dt$$

第一个积分：
$$\int_0^1 [x_i + t(x_{i+1}-x_i)](y_{i+1}-y_i)\,dt = (y_{i+1}-y_i)\left[x_i + \frac{x_{i+1}-x_i}{2}\right] = \frac{(y_{i+1}-y_i)(x_i+x_{i+1})}{2}$$

第二个积分：
$$\int_0^1 [y_i + t(y_{i+1}-y_i)](x_{i+1}-x_i)\,dt = (x_{i+1}-x_i)\left[y_i + \frac{y_{i+1}-y_i}{2}\right] = \frac{(x_{i+1}-x_i)(y_i+y_{i+1})}{2}$$

相减：
$$\frac{(y_{i+1}-y_i)(x_i+x_{i+1}) - (x_{i+1}-x_i)(y_i+y_{i+1})}{2}$$

展开分子：
$$= \frac{x_i y_{i+1} + x_{i+1}y_{i+1} - x_i y_i - x_{i+1}y_i - x_{i+1}y_i - x_{i+1}y_{i+1} + x_i y_i + x_i y_{i+1}}{2}$$

逐项化简：
- $x_i y_{i+1} + x_i y_{i+1} = 2x_i y_{i+1}$
- $x_{i+1}y_{i+1} - x_{i+1}y_{i+1} = 0$
- $-x_i y_i + x_i y_i = 0$
- $-x_{i+1}y_i - x_{i+1}y_i = -2x_{i+1}y_i$

所以：
$$\frac{2x_i y_{i+1} - 2x_{i+1}y_i}{2} = x_i y_{i+1} - x_{i+1}y_i$$

对 $n$ 条边求和即得：

$$2A = \sum_{i=0}^{n-1}(x_i y_{i+1} - x_{i+1}y_i) \quad\blacksquare$$

**注**：这个证明对原点 $O$ 在多边形内部或外部都成立，因为格林公式不要求参考点（原点）在特定位置。有向面积的符号自动处理"内部/外部"的区别。

### 2.4 连续三顶点共线的处理

题目说"可能存在连续的三个顶点在一条直线上"。这会影响公式吗？

**不会。** 如果 $P_i, P_{i+1}, P_{i+2}$ 共线（在一条水平或垂直线上），那么边 $P_iP_{i+1}$ 和 $P_{i+1}P_{i+2}$ 在同一直线上。公式中这两条边的贡献是 $x_i y_{i+1} - x_{i+1}y_i$ 和 $x_{i+1}y_{i+2} - x_{i+2}y_{i+1}$。由于三点共线，$P_{i+1}$ 只是这条"直线边"上的一个中间点，把它分成两段不改变总面积——可以理解为：把 $P_i \to P_{i+1} \to P_{i+2}$ 合并为一条边 $P_i \to P_{i+2}$，面积公式的值不变（这是格林公式对折线分段积分的性质，与路径分段无关，只与起点终点和路径形状有关，而直线段合并后形状不变）。

所以无需特殊处理。

### 2.5 整数溢出检查

$x, y \in [-200, 200]$，$n \le 100$。

单项 $|x_i y_{i+1} - x_{i+1} y_i| \le |x_i y_{i+1}| + |x_{i+1} y_i| \le 200 \cdot 200 + 200 \cdot 200 = 80000$。

总和 $|\sum| \le 100 \cdot 80000 = 8 \times 10^6$。

$32$ 位 `int` 范围约 $2.1 \times 10^9$，远够。不需要 `long long`。

### 2.6 结论

直接用鞋带公式（Shoelace Formula）：

$$A = \frac{1}{2}\left|\sum_{i=0}^{n-1}(x_i y_{i+1} - x_{i+1}y_i)\right|$$

因为顶点是逆时针给出的，求和结果非负，所以绝对值可以去掉（但加上也无害）。最终面积 = `sum / 2`，其中 `sum` 是求和结果（偶数，因为面积是整数，`2A` 必为偶数）。

## Part 3 · 模式总结

- **探索性质** — 正交多边形只是保证坐标和面积都是整数；面积公式本身只依赖有序顶点序列，与边方向无关
- **考虑更简单版本** — 三角形面积 = 向量叉积 / 2（二维叉积的几何意义）
- **经典问题解法** — 鞋带公式（Shoelace Formula）：多边形面积 = $\frac{1}{2}\sum(x_i y_{i+1} - x_{i+1}y_i)$，源自格林公式的离散化
- **处理退化情况** — 连续三顶点共线不影响公式（折线分段积分与路径形状一致）
- **溢出检查** — 数据范围小，`int` 足够

## Part 4 · 正式解法

### 符号表

| 符号 | 含义 |
|------|------|
| $n$ | 多边形顶点数 |
| $x[i]$, $y[i]$ | 第 $i$ 个顶点的坐标（0-based 存储） |
| $S$ | $\sum_{i=0}^{n-1}(x[i] \cdot y[(i+1)\%n] - x[(i+1)\%n] \cdot y[i])$，即求和结果 |
| $A$ | 多边形面积 = $S/2$ |

### 算法步骤

1. 读入 $n$。
2. 读入 $n$ 个顶点的坐标，存入 `x[0..n-1]`, `y[0..n-1]`。
3. 计算 $S = \sum_{i=0}^{n-1}(x[i]\cdot y[(i+1)\bmod n] - x[(i+1)\bmod n]\cdot y[i])$，其中 $(i+1)\bmod n$ 即取模实现"从最后一个顶点回到第一个顶点"的闭合边。
4. 输出 $A = S/2$。

### 复杂度

- 时间：$O(n)$
- 空间：$O(n)$

### 正确性说明

- 逆时针给出的顶点保证 $S \ge 0$，所以 $A = S/2$ 为非负整数。
- 连续三顶点共线不影响结果（§2.4 已证）。
- 数据范围内无溢出风险（§2.5 已证）。

## Part 5 · 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{105};

int n,x[mxn],y[mxn];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	for(int i=0;i<n;++i)
	{
		cin>>x[i]>>y[i];
	}
	int S=0;
	for(int i=0;i<n;++i)
	{
		int j=(i+1)%n;
		S+=x[i]*y[j]-x[j]*y[i];
	}
	cout<<S/2<<'\n';
	return 0;
}
```

**说明**：

- 数组 `x`, `y` 存 0-based 顶点坐标，`mxn{105}` = 约束上界 100 + 5 松弛。
- 闭合边通过 `(i+1)%n` 取模处理（当 $i = n-1$ 时 $j = 0$，即从最后顶点回到第一个顶点）。
- $S$ 为逆时针求和结果，非负；面积 $= S/2$（整除，因为 $S$ 必为偶数）。
- `int` 足够，无溢出风险。
