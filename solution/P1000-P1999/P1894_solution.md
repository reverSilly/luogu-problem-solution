# P1894 [USACO4.2] 完美的牛栏 The Perfect Stall

## 1. 重新读题

### 1.1 问题重述（人话版）

有 $n$ 头奶牛、$m$ 个牛栏。每头奶牛给出自己愿意去的牛栏列表。一个牛栏最多容纳一头奶牛，一头奶牛最多进一个牛栏。问最多能让多少头奶牛分到它们愿意去的牛栏。

### 1.2 关键约束与规模暗示

- $0\le n,m\le 200$，$0\le s_i\le m$。
- 这是标准的**二分图最大匹配**：左部是奶牛（$n$ 个点），右部是牛栏（$m$ 个点），边表示「愿意」。
- 边数最多 $nm\le 4\times 10^4$。匈牙利算法 $O(n\cdot E)\le 8\times 10^6$，绰绰有余。
- 输入允许 $s_i=0$、允许 $n=0$ 或 $m=0$。此时答案为 $0$，代码不能因为 `fill_n` 长度为零或没有边而出错（实际实现中这些情况自然返回 $0$）。
- 同一行不会重复列出同一个牛栏，所以不用去重。

## 2. 思维链（Chain-of-thought）

### 2.1 建模：二分图

把奶牛和牛栏分别放在两侧，若奶牛 $i$ 愿意去牛栏 $j$，就连一条边。一个合法分配就是一组两两没有公共端点的边，即**匹配**。目标是边数最多的匹配。

### 2.2 先试简单贪心：为什么失败

最直接的想法：按奶牛顺序，每头奶牛随便挑一个「还空着」的、它喜欢的牛栏。

反例（$n=2,m=2$）：

- 奶牛 $1$ 只喜欢牛栏 $1$；
- 奶牛 $2$ 喜欢牛栏 $1,2$。

如果先处理奶牛 $2$、给它牛栏 $1$，轮到奶牛 $1$ 时它只喜欢牛栏 $1$，而牛栏 $1$ 已被占，于是只能放弃，得到 $1$。但最优是「奶牛 $2\to$ 牛栏 $2$、奶牛 $1\to$ 牛栏 $1$」，答案为 $2$。

失败的本质：**当前看起来可行的一次占用，可能堵死了后面唯一的出路**。解决它的经典手段不是推翻重来，而是允许「让已经匹配的奶牛挪一挪」——这就是增广路。

### 2.3 概念：交替路与增广路

给定匹配 $M$：

- **交替路**：路径上的边依次为「不在 $M$ 中、在 $M$ 中、不在 $M$ 中……」。由于 $M$ 是匹配，任意两条相邻边不可能都不在 $M$ 中，所以交替性是自然的。
- **增广路**：一条从**未匹配的左部点**出发、到**未匹配的右部点**结束的交替路。

沿增广路把边「翻转」（在 $M$ 中的删掉、不在 $M$ 中的加入），匹配大小恰好增加 $1$：路径有奇数条边，不在 $M$ 的边比在 $M$ 的边多一条。

### 2.4 引理 1（Berge 定理：最大匹配 $\iff$ 无增广路）

**引理 1.** 匹配 $M$ 是最大匹配，当且仅当不存在关于 $M$ 的增广路。

**证明.**

($\Leftarrow$) 若存在增广路 $P$，则对称差 $M\triangle P$ 仍是匹配：$P$ 的内部顶点在翻转前后都恰好关联 $P$ 中的一条边，端点则由未匹配变为匹配，其余点不受影响。同时 $|M\triangle P|=|M|+1$，故 $M$ 不是最大。

($\Rightarrow$) 设 $M$ 不是最大，取一个最大匹配 $M^*$，则 $|M^*|>|M|$。考虑对称差

$$
H=M\triangle M^*.
$$

在 $H$ 中，每个顶点至多关联一条 $M$ 的边和至多一条 $M^*$ 的边，所以度数不超过 $2$。因此 $H$ 的每个连通分量只能是：

- 一条交替路径（边在 $M,M^*$ 间交替）；
- 一个偶环（$M$ 与 $M^*$ 的边交替出现，数量相等）。

环对 $|M^*|-|M|$ 没有贡献。由于总和为正，$H$ 中必有一条路径分量满足「$M^*$ 的边比 $M$ 的边多一条」。这条路径以 $M^*$ 的边开始和结束，因此它的两个端点都不被 $M$ 匹配（否则该端点还要接一条 $M$ 的边），即它是一条关于 $M$ 的增广路。矛盾。

$\blacksquare$

### 2.5 引理 2（单次 DFS 的语义）

**引理 2.** 固定当前匹配 $M$，从某个未匹配的左部点 $u$ 出发，若存在增广路，则下面的 `dfs(u)` 返回 `true` 并完成翻转；否则返回 `false`。

```
dfs(u):
  for v in adj[u]:
    if vis[v]: continue
    vis[v] = true
    if mt[v] == -1 or dfs(mt[v]):
      mt[v] = u
      return true
  return false
```

其中 `mt[v]` 是当前匹配到右部点 $v$ 的左部点（没有则为 $-1$），`vis` 只标记右部点。

**证明.** 对递归深度（等价地，对还能访问的右部点数）归纳。

- 若 $u$ 有未匹配的邻居 $v$：$u\to v$ 本身就是增广路，代码在 `mt[v]==-1` 分支直接匹配并返回 `true`。
- 若 $u$ 的邻居 $v$ 已被 $u'=\text{mt}[v]$ 匹配：任何经过 $v$ 的增广路，下一步必须沿匹配边 $v\to u'$，然后从 $u'$ 继续找一条到未匹配右点的交替路。代码正是递归 `dfs(u')`；由归纳假设，若这样的路存在则递归成功，随后把 $v$ 改配给 $u$（原来的 $u'\to v$ 被替换），完成翻转。
- `vis[v]` 防止重复访问同一个右部点。在寻找增广路时，若某个右部点已被搜索过且失败，从别处再次到达它也不会有新结果；若已成功，搜索就会提前返回。所以跳过已访问点不影响完备性。
- 所有邻居都尝试失败，说明不存在从 $u$ 出发的增广路，返回 `false`。

$\blacksquare$

### 2.6 算法：逐点增广（Kuhn / 匈牙利）

对每个左部点 $u=0\dots n-1$：

1. 清空 `vis`；
2. 若 `dfs(u)` 成功，匹配数加一。

**正确性.** 做法是按左部点编号 $u_0,u_1,\dots,u_{n-1}$ 依次增广。记 $G_i$ 为「只保留前 $i$ 个左部点」得到的子图（右部点全部保留）。下面证明不变式：

> 处理完前 $i$ 个左部点后，当前匹配 $M_i$ 是 $G_i$ 的最大匹配。

对 $i$ 归纳。

- $i=0$：空匹配，成立。
- 设 $M_{i-1}$ 是 $G_{i-1}$ 的最大匹配。现在对 $u_i$ 运行 `dfs`。
  - **若成功**：由引理 2，沿找到的增广路翻转后匹配数加一，得到 $M_i$。因为 $G_i$ 比 $G_{i-1}$ 只多了左点 $u_i$，任何匹配最多比 $G_{i-1}$ 的最大匹配多一条边，即 $|M_i|\le|M_{i-1}|+1$；而 $|M_i|=|M_{i-1}|+1$，故 $M_i$ 是 $G_i$ 的最大匹配。
  - **若失败**：由引理 2，$G_i$ 中不存在从 $u_i$ 出发的增广路。假设 $G_i$ 存在比 $M_{i-1}$ 更大的匹配，则由引理 1 的证明，$M_{i-1}$ 在 $G_i$ 中存在一条增广路 $P$。$P$ 的起点是某个未匹配左点。由于 $M_{i-1}$ 已是 $G_{i-1}$ 的最大匹配，$G_{i-1}$ 内没有增广路，所以 $P$ 必须用到新左点 $u_i$。而 $u_i$ 在 $M_{i-1}$ 中未匹配，交替路的内部点必须关联一条匹配边（否则交替性被破坏），故 $u_i$ 只能是 $P$ 的起点。于是 $P$ 是一条从 $u_i$ 出发的增广路，与 `dfs` 失败矛盾。故 $M_i=M_{i-1}$ 仍是 $G_i$ 的最大匹配。

归纳完成。$G_n$ 就是原图，故算法结束时得到最大匹配。$\blacksquare$

### 2.7 失败尝试记录

1. **按顺序贪心占空牛栏**：如 2.2 的反例，得不到最大匹配。
2. **只做一次「让位」而不递归**：可能要让位一条链（奶牛 $a$ 让给 $b$，$b$ 再让给 $c$……），必须递归/迭代地找完整增广路。
3. **`vis` 标记左部点而不是右部点**：会把「同一个左点通过不同路径到达」误判为环；标记右部点才是标准写法。
4. **多组/多阶段忘记清空 `vis`**：每次对新的左点搜索前必须整体清零。
5. **`n=0` 或 `m=0`**：`fill_n(mt,m,-1)` 与循环都要能正常处理长度 $0$。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 问题就是二分图最大匹配。
- **consider easier version** — 贪心占空位会被「后来的唯一选择」反杀。
- **classic problem solution** — 用增广路而非重排：沿交替路翻转可使匹配数 $+1$。
- **prove a theorem** — Berge 定理：最大 $\iff$ 无增广路，用对称差分解证明。
- **classic problem solution** — Kuhn 算法：对每个左点 DFS 找增广路，右点打 `vis`。

## 4. 解法说明（The Real Solution）

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 / 来源 | 助记 |
| :--- | :--- | :--- | :--- | :--- |
| `n` | `int` | 奶牛数（左部点数） | 读入 | |
| `m` | `int` | 牛栏数（右部点数） | 读入 | |
| `graph[u]` | `vector<int> [205]` | 奶牛 $u$ 愿意去的牛栏（$0$-based） | 读入时 `--v` | adjacency |
| `mt[v]` | `int [205]` | 牛栏 $v$ 当前匹配的奶牛，未匹配为 $-1$ | `-1` | match |
| `vis[v]` | `bool [205]` | 本轮 DFS 中牛栏 $v$ 是否访问过 | 每轮清零 | visited |
| `ans` | `int` | 当前匹配大小 | $0$ | answer |

### 4.2 算法步骤

1. 读入 $n,m$。对每头奶牛 $i$ 读入 $s_i$ 及其后 $s_i$ 个牛栏编号，编号减一后加入 `graph[i]`。
2. `fill_n(mt,m,-1)`。
3. 对 $i=0\dots n-1$：`fill_n(vis,m,false)`；若 `dfs(i)` 为真，则 `++ans`。
4. `dfs(u)`：遍历 `graph[u]` 中的每个牛栏 $v$；若 `vis[v]` 跳过；否则标记访问，若 `mt[v]==-1` 或 `dfs(mt[v])` 为真，则令 `mt[v]=u` 并返回真；全部失败返回假。
5. 输出 `ans`。

### 4.3 复杂度分析

- **时间**：每轮 DFS 每条边至多被检查一次（`vis` 保证每个右点只进入一次，其邻接边也只展开一次），单轮 $O(E)$；共 $n$ 轮，总 $O(nE)\le O(n^2m)\approx 8\times 10^6$。
- **空间**：邻接表 $O(E)$，`mt/vis` $O(m)$。

## 5. 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;

constexpr int mxn{205};

int n,m;
vector<int>graph[mxn];
int mt[mxn];
bool vis[mxn];

bool dfs(int u)
{
	for(int v:graph[u])
	{
		if(vis[v])
			continue;
		vis[v]=true;
		if(mt[v]==-1||dfs(mt[v]))
		{
			mt[v]=u;
			return true;
		}
	}
	return false;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>m;
	for(int i=0,s;i<n;++i)
	{
		cin>>s;
		for(int j=0,v;j<s;++j)
		{
			cin>>v;--v;
			graph[i].push_back(v);
		}
	}
	fill_n(mt,m,-1);
	int ans=0;
	for(int i=0;i<n;++i)
	{
		fill_n(vis,m,false);
		if(dfs(i))
			++ans;
	}
	cout<<ans<<'\n';
	return 0;
}
```
