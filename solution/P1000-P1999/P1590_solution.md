# P1590 失踪的7

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

Pascal 人不使用数字 $7$。于是全体正整数被"跳过含 7 的那些"重新编号：$1,2,3,4,5,6,8,9,10,11,\dots$，其中 $8$ 是第 $7$ 个 Pascal 数，$18$ 是第 $16$ 个。给定一个 Pascal 数 $n$（保证 $n$ 的十进制表示中不含 $7$），求 $n$ 的排名，即 $1 \sim n$ 中共有多少个十进制不含 $7$ 的正整数。

### 输入输出格式

- **输入格式**：第一行 $t$；随后 $t$ 行每行一个正整数 $n$，保证 $n$ 是 Pascal 数。
- **输出格式**：每行一个整数，表示 $n$ 的排名。
- **数据规模**：$1 \le t \le 10^4$，$1 \le n \le 2^{32}-1$。

### 关键约束分析

1. $n$ 可达 $4.29\times 10^9$，$t$ 可达 $10^4$：逐个数枚举是 $4\times10^{13}$ 级别，必然超时；必须做到"按位"计算，单次 $O(\text{位数})$。
2. $n > 2^{31}-1$，`int` 存不下，读入用 `string`（同时方便逐位处理），答案用 `long long`。
3. 题目保证 $n$ 本身不含 $7$，因此不需要处理"上界含 7"的复杂情况。注意 $2^{32}-1=4294967295$ 本身含有数字 $7$，不是合法输入，所以真正能出现的最大值是不含 $7$ 的十位数。
4. 多组数据之间没有任何状态需要清空，逐组独立计算。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：暴力与它的瓶颈

最直白的做法：对每个 $n$ 从 $1$ 枚举到 $n$，逐位检查有没有 $7$。复杂度 $O(tn)$，$t=10^4,n=4\times10^9$ 时完全不可行。瓶颈在于"对每个数都重新检查一遍"，而相邻的整数在十进制表示上只有末尾几位不同，信息被大量重复计算。这提示我们：**不要按数值枚举，要按数位构造**。

### 第二步：看出这是"九进制"

不含 $7$ 的数字集合是 $D=\{0,1,2,3,4,5,6,8,9\}$，恰好 $9$ 个元素。把 $\{0,\dots,8\}$ 按顺序压到这 $9$ 个数字上：

$$\varphi(d)=\begin{cases}d,&d\le 6\\ d+1,&d\ge 7\end{cases}$$

也就是把九进制的 $7,8$ 显示成 $8,9$。由于 $\varphi(0)=0<\varphi(1)=1<\cdots<\varphi(8)=9$ 且九个取值两两不同，$\varphi$ 是 $\{0,\dots,8\}$ 到 $D$ 的双射。

### 第三步：逐位替换后按九进制读数

**引理 1（保序双射）**：对任意长度 $\ell$，$\varphi$ 逐位作用给出 $\{0,\dots,8\}^\ell \to D^\ell$ 的双射；并且两个 $\ell$ 位串的字典序关系在映射前后保持。

*证明*：每个坐标上 $\varphi$ 都是双射，笛卡尔积上的逐位映射因此是双射。$\varphi$ 在每个坐标上严格递增（$\varphi(0)<\varphi(1)<\dots<\varphi(8)$），若两串在第一个不同位置 $j$ 上 $a_j<b_j$，则 $\varphi(a_j)<\varphi(b_j)$，高位相同、位置 $j$ 处更小，故映射后字典序仍为 $a<b$。$\square$

**引理 2（排名公式）**：设 Pascal 数 $n$ 写成 $\ell$ 位字符串 $s_1s_2\dots s_\ell$（允许前导零补齐），令

$$V(n)=\sum_{i=1}^{\ell}\varphi^{-1}(s_i)\cdot 9^{\ell-i},\qquad \varphi^{-1}(s)=\begin{cases}s,&s\le 6\\ s-1,&s\ge 8\end{cases}$$

则 $V(n)$ 恰好等于 $1\sim n$ 中不含 $7$ 的正整数个数。

*证明*：在 $\ell$ 位（左侧补零）的视角下，"数值 $\le n$" 等价于"$\ell$ 位串字典序 $\le s$"。由引理 1，$\varphi$ 把 $\{0,\dots,8\}^\ell$ 与 $D^\ell$ 一一对应且保序，于是

$$\#\{x\in D^\ell: x\le s\}=\#\{y\in\{0,\dots,8\}^\ell: y\le \varphi^{-1}(s)\}.$$

右侧是九进制下不超过 $V(n)$ 的串个数，从 $0$ 数起恰有 $V(n)+1$ 个。左侧统计了 $[0,n]$ 中所有十进制不含 $7$ 的整数（含 $0$）。两边减去只多出来的那个 $0$，得到 $[1,n]$ 中不含 $7$ 的整数个数为 $V(n)$。$\square$

**定理（算法正确）**：把 $n$ 的每一位 $d$ 映射成 $d-[d>7]$，再按九进制读数（从左到右 `ans=ans*9+d'`），得到的就是答案。

*证明*：`ans=ans*9+d'` 正是 Horner 法则计算 $\sum d'_i9^{\ell-i}$，由引理 2 等于所求排名。$\square$

### 第四步：验证公式对边界成立

- $n=6$：$V=6$，$1\sim6$ 全是 Pascal 数，共 $6$ 个，一致。
- $n=8$：$8\to7$，$V=7$，$1\sim8$ 中除掉 $7$ 共 $7$ 个，与"$8$ 表示 $7$"一致。
- $n=18$：$1\to1,8\to7$，$V=1\cdot9+7=16$，与题面"$18$ 表示 $16$"一致。
- $n=9$：$9\to8$，$V=8$，$1\sim9$ 中除掉 $7$ 共 $8$ 个，一致。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 禁用数字 $7$ 后剩 $9$ 个可用数字，天然是"九进制"。
- `reduce to easier problem` — 排名问题转化为"逐位映射成九进制后读数",不再逐个枚举数值。
- `classic problem solution` — 数位替换（把 $d>7$ 减一）即"压缩映射",用 Horner 法 $O(\ell)$ 求值。
- `prove by bijection` — 用保序双射把"计数 $\le n$ 的合法数"变成"计数 $\le V(n)$ 的九进制串",避免容斥与数位 DP。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $t$ | `t` | 数据组数，`while(t--)` 控制循环 |
| $n$ | `s` | 以字符串读入的 $n$（可容 $2^{32}-1$，且便于逐位扫描） |
| $s_i$ | `c` | 当前正在处理的十进制字符 |
| $d$ | `d` | 当前位的数值 `c-'0'` |
| $d'=\varphi^{-1}(d)$ | `d`（就地修改） | 若 `d>7` 则 `--d`，得到九进制数字 |
| $V(n)$ | `ans` | 逐位累乘 $9$ 再加当前位，即排名；`i64` 存储 |

### 算法步骤

1. 读入 `t`。
2. 每组读入字符串 `s`，置 `ans=0`。
3. 从左到右扫 `s` 的每个字符：`d=c-'0'`；若 `d>7` 则 `--d`；`ans=ans*9+d`。
4. 输出 `ans`。

### 复杂度分析

- **时间复杂度**：单组 $O(\ell)$，$\ell\le 10$，总计 $O(t\ell)\le 10^5$ 次基本运算。
- **空间复杂度**：$O(\ell)$，即输入串本身。

### 正确性验证

引理 1 保证逐位映射是保序双射，引理 2 给出 $V(n)$ 就是排名，定理说明 Horner 法算的正是 $V(n)$。数值安全：最大合法 $n$ 为十位数，`ans` 上界小于 $9^{10}=3.49\times10^{9}$，`i64` 绰绰有余；字符串读入避免 `int` 溢出。输入保证不含 $7$，故不会出现"上界含 7 需要额外修正"的情形。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1590 失踪的7
// https://www.luogu.com.cn/problem/P1590
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

string s;

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int t;
	cin>>t;
	while(t--)
	{
		cin>>s;
		i64 ans=0;              // 九进制读数即排名
		for(char c:s)
		{
			int d=c-'0';
			if(d>7)
				--d;            // 跳过数字 7, 其后的数码整体前移一位
			ans=ans*9+d;
		}
		cout<<ans<<'\n';
	}
	return 0;
}
```

### 易错点

1. **用 `int` 读 $n$**：$n$ 可达 $2^{32}-1$，`int` 溢出成负数，读入即错。用 `string` 或 `unsigned int`。
2. **映射方向搞反**：是"把 $8$ 当成 $7$、$9$ 当成 $8$"，即 $d>7$ 时减一；写成 `d>=7` 会把 $7$ 也减一，虽然输入不含 $7$ 时不出错，但逻辑错误。
3. **答案用 `int`**：$t$ 组数据里排名最大可到 $1.6\times10^9$，接近 `int` 上界，仍建议 `i64`。
4. **误以为要处理 $n$ 含 $7$**：题面保证 $n$ 是 Pascal 数；若强行套用本题代码处理含 $7$ 的 $n$ 会得到错误结果（那些输入不在数据范围内）。
5. **多组数据忘记 `ans` 归零**：`ans` 定义在循环内即天然正确，若提到循环外必须每组清零。
