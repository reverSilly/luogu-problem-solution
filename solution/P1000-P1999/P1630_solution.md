# P1630 求和

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

多组数据。每组给定 $a,b$，求

$$\left(\sum_{i=1}^{a} i^{b}\right)\bmod 10^{4}.$$

### 输入输出格式

- **输入格式**：第一行 $N$（数据组数）；随后 $N$ 行，每行两个整数 $a,b$。
- **输出格式**：每组一行，一个 $[0,9999]$ 内的整数。
- **数据规模**：$N\le100$，$1\le a,b\le10^{9}$。

### 关键约束分析

1. $a$ 高达 $10^9$，逐项累加不可能；但模数只有 $10^4$，暗示**周期性**。
2. $b$ 也高达 $10^9$，求幂必须用快速幂（$\mathcal{O}(\log b)$），不能直接乘 $b$ 次。
3. $10^4=2^4\cdot5^4$ **不是素数**，所以不能用费马小定理把指数模 $p-1$ 降下来；快速幂本身不需要模数互素，可以放心使用。
4. 多组数据：每组都要重新计算，注意 $r=0$ 时前缀和为 $0$ 的边界。
5. 答案范围 $[0,9999]$，但中间量（整块和 $\times$ 块数）会到 $10^9$ 量级，用 `long long`。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：$a$ 太大，先看 $i^b \bmod 10^4$ 有没有周期

快速幂解决了 $b$ 大，但项数 $a$ 仍可达 $10^9$。一个自然的想法：$i^b \bmod 10^4$ 是不是随 $i$ 周期变化？

**引理 1（周期 $10^4$）**：对任意正整数 $i,b$，

$$(i+10^{4})^{b}\equiv i^{b}\pmod{10^{4}}.$$

*证明*：由二项式定理，

$$(i+10^4)^b=\sum_{k=0}^{b}\binom{b}{k}i^{b-k}(10^4)^{k}.$$

$k=0$ 项是 $i^b$；$k\ge1$ 的每一项都含有因子 $(10^4)^k$，因而被 $10^4$ 整除。故两者模 $10^4$ 同余。$\square$

于是 $f(i)=i^b\bmod10^4$ 是以 $10^4$ 为周期的序列（真实周期可能更小，这无关紧要）。

### 第二步：按块求和

**引理 2（分块公式）**：设 $a=10^4q+r$（$0\le r<10^4$），$T=\sum_{i=1}^{10^4} i^b \bmod 10^4$，则

$$\sum_{i=1}^{a}i^{b}\equiv q\,T+\sum_{i=1}^{r}i^{b}\pmod{10^{4}}.$$

*证明*：把 $1..a$ 分成 $q$ 个长度 $10^4$ 的整块加一个长度 $r$ 的残块。第 $t$ 个整块（$t=0..q-1$）是 $i=t\cdot10^4+j$（$1\le j\le10^4$），由引理 1，$(t\cdot10^4+j)^b\equiv j^b$，故每块之和都同余于 $T$；残块就是 $\sum_{i=1}^{r}i^b$。由同余的加法与数乘性质求和即得。$\square$

于是每组数据只需计算 $10^4$ 个 $i^b\bmod10^4$，加上快速幂的 $\mathcal{O}(\log b)$，单组 $\mathcal{O}(10^4\log b)$。

### 第三步：快速幂为什么对合数模数也正确

**引理 3（二进制快速幂）**：设 `r=1`，对指数 $b$ 的二进制位从低到高处理，遇到 $1$ 位就把 `r` 乘上当前的 $a^{2^k}$，每步都对 $M$ 取模，则最终 `r` $=a^b\bmod M$。

*证明*：对 $b$ 的二进制长度归纳。设已处理低 $k$ 位，`r` 等于 $a^{b\bmod 2^k}$（模 $M$），当前底数为 $a^{2^k}$。若第 $k$ 位为 $1$，新的 `r` $=a^{b\bmod2^k}\cdot a^{2^k}=a^{b\bmod2^{k+1}}$；为 $0$ 时不变，同样成立。模乘满足结合律与交换律，取模不改变同余类，故递推正确。$\square$

这里只用了"模乘可结合"这一条性质，没有要求 $M$ 是素数或与 $a$ 互素，因此对 $10^4$ 完全适用。

### 第四步：实现上的小优化

把 $T$ 与残块前缀和放在同一个 $i=1..10^4$ 的循环里：累加器 `blk` 一路加到 $10^4$ 就是 $T$，当 $i=r$ 时把 `blk` 记进 `pre`（$r=0$ 时 `pre` 保持初值 $0$）。这样每组数据只跑一遍 $10^4$ 次快速幂。

**定理**：程序输出等于题目所求的 $\left(\sum_{i=1}^a i^b\right)\bmod10^4$。

*证明*：由引理 2，答案 $\equiv qT+\sum_{i=1}^r i^b$；`blk` 按定义累加得到 $T$，`pre` 在 $i=r$ 时恰为残块和；引理 3 保证每个 $i^b\bmod10^4$ 正确。最后 $(q\bmod10^4)\cdot T+pre$ 再取模，同余意义下与 $qT+pre$ 一致。$\square$

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 模 $10^4$ 下 $i^b$ 以 $10^4$ 为周期（二项式展开）。
- `reduce to easier problem` — 把 $1..a$ 切成整块 + 残块，整块用同一个 $T$。
- `classic problem solution` — 二进制快速幂把 $\mathcal{O}(b)$ 降到 $\mathcal{O}(\log b)$，且不要求模数互素。
- `classic problem solution` — 一次循环同时求整块和与残块前缀和，避免重复计算。
- `explore its property` — $10^4$ 是合数，不能套费马小定理降指数，这是本题最容易踩的坑。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $N$ | `t` | 数据组数，`while(t--)` 循环 |
| $a$ | `a` | 求和上界，`i64` |
| $b$ | `b` | 指数，`i64`，传给 `qpow` 时转 `int` |
| $10^4$ | `MOD` | 模数 |
| $q$ | `q` | `a/MOD`，整块个数 |
| $r$ | `r` | `a%MOD`，残块长度 |
| $T$ | `blk` | 一整块 $1..10^4$ 的 $i^b$ 之和（模 $10^4$） |
| $\sum_{i=1}^{r}i^b$ | `pre` | 残块和，在 `i==r` 时从 `blk` 拷出，初值 $0$ |
| — | `x` | 当前项 `qpow(i%MOD,b)` |
| 答案 | `ans` | `q*blk+pre` 再取模 |

### 算法步骤

1. 读入 `t`，循环 `t` 次。
2. 每组读入 `a,b`，算 `q=a/MOD`、`r=a%MOD`。
3. 置 `blk=0,pre=0`，对 `i=1..MOD`：`x=qpow(i%MOD,b)`，`blk=(blk+x)%MOD`；若 `i==r` 则 `pre=blk`。
4. `ans=(q%MOD)*blk%MOD+pre`，再 `%MOD` 输出。

### 复杂度分析

- **时间复杂度**：每组 $\mathcal{O}(10^4\log b)$，$\log b\le30$，约 $3\times10^5$ 次乘法；$N=100$ 共 $3\times10^7$，实测约 $0.07$ s。
- **空间复杂度**：$\mathcal{O}(1)$，只有若干标量。

### 正确性验证

引理 1 给出周期性，引理 2 给出分块公式（含 $r=0$ 时残块为空的特例），引理 3 保证快速幂在合数模数下正确。数值上 `blk` 始终保持在 $[0,10^4)$，`(q%MOD)*blk` 不超过 $10^8$，`int` 即可，代码用 `i64` 承接 `q` 的中间乘法更保险。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1630 求和
// https://www.luogu.com.cn/problem/P1630
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int MOD{10000};

int qpow(int a,int b)
{
	int r=1%MOD;
	for(;b;b>>=1,a=a*a%MOD)
		if(b&1)
			r=r*a%MOD;
	return r;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	int t;
	cin>>t;
	while(t--)
	{
		i64 a,b;
		cin>>a>>b;
		i64 q=a/MOD;
		int r=a%MOD;
		int blk=0,pre=0;                // blk:一整块 1..10000 的和；pre:1..r 的和
		for(int i=1;i<=MOD;++i)
		{
			int x=qpow(i%MOD,(int)b);
			blk+=x;
			if(blk>=MOD)
				blk-=MOD;
			if(i==r)
				pre=blk;                // 此时 blk 恰为前 r 项之和
		}
		int ans=(int)((q%MOD)*blk%MOD+pre)%MOD;
		cout<<ans<<'\n';
	}
	return 0;
}
```

### 易错点

1. **套费马小定理**：$10^4$ 是合数，$\varphi(10^4)=4000$ 但 $a^{\varphi}\equiv1$ 只在 $\gcd(a,M)=1$ 时成立，直接降指数会错。快速幂不需要这个条件。
2. **周期性写错**：周期是 $10^4$ 而不是 $10^4-1$；用 $10^4-1$ 做块长会在 $i$ 为 $10^4$ 的倍数时出错。
3. **$r=0$ 时的前缀和**：`pre` 必须保持 $0$，若写成"循环结束后取 `blk`"会把整块和重复加一次。
4. **`b` 用 `int` 传参**：$b\le10^9$ 未超出 `int`，但读入用 `i64` 再显式转换更清楚；若把 `b` 直接当循环次数会 TLE。
5. **模运算顺序**：`(q%MOD)*blk%MOD` 先取模再相乘，避免 $q\cdot T$ 溢出；虽然 `i64` 也能承受 $10^{13}$，但先取模更稳。
6. **多组不清零**：`blk`、`pre` 必须在每组开头重新置 $0$。
