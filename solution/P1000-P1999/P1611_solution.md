# P1611 循环的数字

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

称两个**不同**的正整数 $(n,m)$ 是"循环的"，当且仅当把 $n$ 末尾的若干位（连续的一段，保持顺序）搬到最前面，恰好得到 $m$。
例如 $(12345,34512)$ 是一对循环的数字，$(12345,45123)$、$(12345,23451)$ 也是。
要求 $n,m$ 位数相同、都没有前导零。

给定 $A,B$（位数相同、无前导零），求满足 $A\le n\le m\le B$ 的循环数对 $(n,m)$ 的个数。

### 输入输出格式

- **输入格式**：一行两个正整数 $A,B$（$A,B$ 位数相同）。
- **输出格式**：一行一个整数，满足条件的数对个数。
- **数据规模**：$1\le A,B\le2\times10^6$，即位数 $L\le7$。

### 关键约束分析

1. $B\le2\times10^6$，值域很小，可以**枚举每个 $n$**；每个 $n$ 至多 $L-1\le6$ 个非平凡旋转，总量约 $1.2\times10^7$，完全可行。
2. "不同的整数对"：$n=m$ 不算（旋转后可能等于自身，例如 $n=1212$ 平移 $2$ 位仍是 $1212$），必须用严格 $m>n$ 过滤。
3. 旋转后可能出现前导零：例如 $n=1200$ 平移 $2$ 位得到 $0012$，这不是合法的 4 位数，必须跳过。
4. 计数不能重复：周期串（如 $1212$）的不同平移可能得到**相同**的 $m$，必须去重。
5. 答案规模：最坏约 $(B-A)\times6\approx1.2\times10^7$，`int` 够，但用 `long long` 更保险。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：暴力长什么样，慢在哪

最直接：枚举所有 $n\in[A,B]$ 与 $m\in[n,B]$，再判断 $m$ 是否是 $n$ 的循环移位，复杂度 $\mathcal{O}((B-A)^2)$，$B-A$ 达 $2\times10^6$ 时是 $4\times10^{12}$，不可行。

慢在"枚举 $m$"这一半。但注意：给定 $n$，$m$ **不是任意的**，它只能是 $n$ 的某次平移，最多 $L-1\le6$ 个。所以枚举 $m$ 这一维完全没必要。

### 第二步：枚举 $n$，生成它的平移

**引理 1（平移的刻画）**：设 $n$ 是 $L$ 位数。把末 $k$ 位（$1\le k<L$）搬到前面得到的数是
$$\mathrm{rot}_k(n)=\Big(n\bmod 10^k\Big)\cdot10^{L-k}+\Big\lfloor n/10^k\Big\rfloor .$$
且 $m$ 是 $n$ 的循环移位当且仅当存在 $k\in[1,L-1]$ 使 $m=\mathrm{rot}_k(n)$。

*证明*：把 $n$ 的十进制表示看成串 $s_0s_1\dots s_{L-1}$，末 $k$ 位就是 $s_{L-k}\dots s_{L-1}$。$n\bmod10^k$ 的数值正是这 $k$ 位（允许前导零），乘 $10^{L-k}$ 后它们占据高位；$\lfloor n/10^k\rfloor$ 是剩下的前 $L-k$ 位，放到低位。两者拼接即得平移结果。
反过来，"把末尾若干位搬到前面"的定义本身就限定为这种形式，故充要。$\square$

**引理 2（前导零的判别）**：$\mathrm{rot}_k(n)$ 仍是 $L$ 位数，当且仅当 $n\bmod10^k\ge10^{k-1}$。

*证明*：平移后最高位是原来的第 $L-k$ 位，即 $n\bmod10^k$ 的最高位。这个 $k$ 位块（允许前导零）的数值 $\ge10^{k-1}$ 等价于它的最高位非零，也就是平移结果没有前导零，位数仍为 $L$。$\square$

### 第三步：去重

**引理 3（周期串的重复）**：若字符串 $s$ 有周期 $d\mid L$，则 $\mathrm{rot}_d(n)=n$；更一般地，不同的 $k$ 可能给出同一个数。

*证明*：设有周期 $d$，即 $s_i=s_{i+d}$（下标模 $L$）。那么把末 $d$ 位搬到前面得到的串与原串逐位相同，故 $\mathrm{rot}_d(n)=n$。同理 $\mathrm{rot}_{d}(n)=\mathrm{rot}_{2d}(n)=\dots$，于是同一个数被多个 $k$ 生成。$\square$

所以对每个 $n$，要把生成的候选**去重**后再计数。每个 $n$ 的候选数不超过 $6$，用 $\mathcal{O}(L^2)$ 的暴力比较去重即可，总代价可以忽略。

**引理 4（不重不漏）**：枚举所有 $n\in[A,B]$，对每个 $n$ 统计"去重后、满足 $n<m\le B$ 的 $\mathrm{rot}_k(n)$ 个数"，求和即答案。

*证明*：
不漏：设 $(n_0,m_0)$ 是满足条件的一对，则 $n_0\le m_0$ 且二者不同故 $n_0<m_0$；枚举到 $n=n_0$ 时，由引理 1 存在 $k$ 使 $\mathrm{rot}_k(n_0)=m_0$，且 $m_0\le B$ 满足筛条件，被计入。
不重：每一对 $(n,m)$ 只在 $n$ 取"较小的那个数"时被枚举一次（因为要求 $m>n$）；同一 $n$ 下若多个 $k$ 给出同一个 $m$，由去重只算一次。$\square$

### 第四步：复杂度

对每个 $n$ 做 $L-1$ 次平移，每次 $\mathcal{O}(1)$ 取模/除法，再去重 $\mathcal{O}(L^2)$。总计 $\mathcal{O}((B-A)\cdot L^2)$，取 $B-A\le2\times10^6$、$L\le7$，约 $10^8$ 次基本运算中的绝大部分是 $L^2=49$ 里的小常数——实际只要 $1.2\times10^7$ 次平移，跑得飞快。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 给定 $n$ 时，它的循环移位只有 $L-1$ 个候选，值域极小。
- `reduce to easier problem` — 把"枚举数对"降成"枚举 $n$ + 生成常数个候选"，从 $\mathcal{O}(V^2)$ 变成 $\mathcal{O}(V\log V)$。
- `enumerate the smaller element` — 固定按"较小者"枚举，天然保证每对只数一次。
- `classic problem solution` — 用 $10^k$ 的整除/取模把字符串平移写成 $\mathcal{O}(1)$ 的算术平移。
- `deduplicate by period` — 周期串会产生重复候选，必须去重后才计数。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $A,B$ | `A`,`B` | 区间端点，均为 `int`（$\le2\times10^6$） |
| $n$ | `n` | 当前枚举的较小数，从 $A$ 到 $B$ |
| $L$ | `len` | $n$ 的位数，由循环除 $10$ 求得 |
| $10^k$ | `pw[k]` | 预处理好的 $10$ 的幂，`pw[0..9]` |
| $k$ | `k` | 本次搬到前面的末位位数，$1\le k<L$ |
| — | `hi` | $n/10^k$，即剩下的高位部分 |
| — | `lo` | $n\bmod10^k$，即被搬到前面的低位块 |
| $\mathrm{rot}_k(n)$ | `m` | 平移得到的候选数 |
| — | `rot[]`,`c` | 当前 $n$ 的候选缓存及其个数（去重后） |
| — | `dup` | 标记候选是否已出现过 |
| — | `t`,`j` | `t` 用于循环求位数，`j` 用于候选去重的线性扫描 |
| 答案 | `ans` | `i64` 累加计数 |

### 算法步骤

1. 读入 $A,B$，预处理 `pw[k]=10^k`。
2. 对 $n=A..B$：
   1. 用 `for(int t=n;t;t/=10)++len;` 求位数 $L$；
   2. 对 $k=1..L-1$：算 `hi=n/pw[k]`、`lo=n%pw[k]`；若 `lo<pw[k-1]` 则跳过（前导零）；否则 `m=lo*pw[len-k]+hi`；若 `n<m<=B` 则查重后放入 `rot[]`；
   3. `ans+=c`。
3. 输出 `ans`。

### 复杂度分析

- **时间复杂度**：$\mathcal{O}\big((B-A)\cdot L^2\big)$，其中 $L\le7$；主项是 $1.2\times10^7$ 次平移，远低于时限。
- **空间复杂度**：$\mathcal{O}(L)$，只有一个长度至多 $7$ 的候选数组。

### 正确性验证

- 引理 1 保证"生成平移"覆盖了全部可能的 $m$；引理 2 保证不会把带前导零的伪 $L$ 位数算进来。
- 引理 3 说明必须去重，代码用 $c$ 个已存候选逐个比较，恰好去掉重复。
- 引理 4 保证不重不漏（按较小者枚举 + 严格 $m>n$）。
- 数值范围：$n\le2\times10^6$，$L\le7$，$m<10^7$ 在 `int` 内；`pw[len-k]` 中 $len-k\le6$，`pw` 开到 $10$ 足够。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1611 循环的数字
// https://www.luogu.com.cn/problem/P1611
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

int A,B;
int pw[10]{1,10,100,1000,10000,100000,1000000,10000000,100000000,1000000000};

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>A>>B;
	i64 ans=0;
	for(int n=A;n<=B;++n)
	{
		int len=0;
		for(int t=n;t;t/=10)
			++len;
		int rot[10],c=0;
		for(int k=1;k<len;++k)             // 把末 k 位搬到前面
		{
			int hi=n/pw[k],lo=n%pw[k];
			if(lo<pw[k-1])
				continue;                  // 搬过去后首位是 0, 位数变了
			int m=lo*pw[len-k]+hi;
			if(m<=n||m>B)
				continue;
			bool dup=false;
			for(int j=0;j<c;++j)       // 周期串的不同旋转会重样, 去重
				if(rot[j]==m)
					dup=true;
			if(!dup)
				rot[c++]=m;
		}
		ans+=c;
	}
	cout<<ans<<'\n';
	return 0;
}
```

### 易错点

1. **不去重**：$n=1212$ 平移 $1$ 位与平移 $3$ 位都得到 $2121$，不去重就会算两遍。实测区间 $[1212,2122]$ 上，去重版答案是 $47$，去掉去重后变成 $48$。
2. **前导零判据写成 `lo==0`**：$n=1200$ 平移 $2$ 位得到 `0012`（此时 `lo=0`，两种写法都能排除），但 $n=1205$ 平移 $2$ 位得到 `0512`（`lo=5`，非零，却仍以 $0$ 开头）。正确判据只能看**最高位**：`lo>=pw[k-1]`。
3. **位数算成 $B$ 的位数**：必须对每个 $n$ 单独求位数（本题 $A,B$ 位数相同，可以只算一次，但逐个数求更稳）。
4. **计数上限**：答案可达 $1.2\times10^7$，`int` 也够，但 `i64` 更保险。
5. **把 $n=m$ 计入**：题面要求"两个不同的正整数"，必须严格 `m>n`。
