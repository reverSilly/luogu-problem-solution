# P1517 [ECNA 1988] 高精求小数幂

> 标签：数学 / 高精度 / ICPC · 难度：普及/提高-
> 本地题面：`P1517.md`（多组数据 $\le 11$ 组；$0<R\le 9999.9$，$1\le n\le 250$）。验证：`appendix/P1517/` 中 400 组随机对拍（std == 暴力 == Python 大整数 oracle）+ 7 组手工边界用例 + 最坏规模计时。

## 1. 重新读题

**问题重述（人话版）**

有多组数据（不超过 $11$ 组），读到文件末尾。每组给一个实数 $R$（$0<R\le 9999.9$，以十进制小数形式给出，例如 `95.123`、`0.4321`、`1.0100`、`.5`）和一个整数 $n$（$1\le n\le 250$），要求算出 $R^n$ 的**精确值**并按规定格式输出。

输出的三条硬性格式要求：

1. **不允许有前导 $0$**（整数部分不以 $0$ 开头）。
2. **小数部分末尾不能有 $0$**（要去掉无意义的尾随零）。
3. **结果是整数时不能输出小数点**。
4. 特别地，**当答案小于 $1$ 时省略整数部分的 $0$**，输出形如 `.25`。

> 一句话版本：**给定十进制小数 $R$ 与幂次 $n$，精确计算 $R^n$ 并按上面四条规则格式化输出。**

**题面里容易漏掉的条款**

1. 「精确值」$\Rightarrow$ 绝不能用 `double`/浮点（$9999.9^{250}$ 有上千位，浮点早溢出/丢精度），必须**整数运算**。
2. 输入里 $R$ 可能带**前导小数点**（如 `.5`）、也可能带**末尾多余的零**（如 `1.0100`），这两种都要正确解析与化简。
3. 「当答案小于 $1$ 时省略整数部分的 $0$」$\Rightarrow$ 输出可能是 `.000001` 这种没有整数部分的形式，不能顺手补一个 `0`。
4. 「保证每行包括空格在内恰好有 $9$ 个字符」$\Rightarrow$ 这是**输入格式的提示**，不用手写定长解析；用 `cin>>s>>n`（或 `scanf("%s%d",...)`）按空白切分即可自动兼容中间空格个数不等的情况。

**数据范围与规模感受**

$$0<R\le 9999.9,\qquad 1\le n\le 250 .$$

把 $R$ 写成 $P\cdot10^{-k}$（$P$ 为去掉小数点后的整数，$k$ 为小数位数）。由 $R\le9999.9$ 知 $P\le 99999$，即 $P$ 至多 $5$ 位。于是

$$\text{位数}(P^n)\ \le\ 5\cdot 250=1250 .$$

$1250$ 位十进制数远超 `long long`（约 $19$ 位）和 `__int128`（约 $39$ 位），所以**必须自写大整数**。好在只需要"逐次乘一个小整数"，每次 $O(\text{位数})$，总体 $250\times1250\approx3\times10^5$ 次基本运算，极其宽裕。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把实数写成"整数 / $10^k$"

第一步是给"十进制小数"找一个适合乘方的表示。把 $R$ 的数码串去掉小数点得到整数 $P$，并记小数点后面有 $k$ 位，则

$$R=P\cdot 10^{-k}.$$

例如 `95.123`：去掉小数点得 `95123`，$P=95123,\ k=3$；`.5`：$P=5,\ k=1$；`10`：$P=10,\ k=0$。

**引理 1（乘方的精确整数表示）**

对任意正整数 $n$，

$$R^n=P^n\cdot 10^{-kn}.$$

**证明**：由 $R=P\cdot 10^{-k}$，用乘法结合律与指数的乘法法则，

$$R^n=(P\cdot10^{-k})^n=\underbrace{(P\cdot10^{-k})\cdots(P\cdot10^{-k})}_{n\text{ 个}}=P^n\cdot 10^{-kn}. \blacksquare$$

> 这一步的意义：**乘方问题完全归约为"整数幂 $P^n$"加上"小数点位置 $kn$"**。前者是纯整数算术，后者只是一个记数法上的位移，两者互不干扰。

### 2.2 考虑简化版：$R$ 是整数（$k=0$）

若 $R$ 本身就是整数（$k=0$），则 $R^n=P^n$，输出 $P^n$ 的十进制串即可，不带小数点。这个简化版说明：**核心难点只有"如何算一个大整数的十进制"**，格式化是后加的。

### 2.3 归约：一般情形 = 整数幂的串 + 插入小数点

回到一般 $k>0$。已知 $R^n=P^n\cdot10^{-kn}$。设 $P^n$ 的十进制串为 $S$（长度 $L$，无前导零），令 $e=kn$（结果的小数位数）。

**引理 2（小数点插入法则）**

记 $R^n$ 的标准十进制表示为 $S$ 中从右往左数第 $e$ 位之前插入小数点，即：

- 若 $L>e$：整数部分是 $S$ 的前 $L-e$ 位，小数部分是后 $e$ 位；
- 若 $L\le e$：整数部分是 $0$，小数部分补 $(e-L)$ 个前导 $0$ 再接 $S$。

**证明**：十进制位置记数法下，$S$ 的各位权值是从右起 $10^0,10^1,\dots,10^{L-1}$。对 $S=P^n$ 整体除以 $10^e$，相当于把小数点左移 $e$ 位：右起第 $e$ 位与第 $e+1$ 位之间成为小数点。当 $L\le e$ 时小数点落在最左端之外，整数部分为 $0$，右侧（低位）自然补出 $e-L$ 个 $0$。这与 $S\cdot10^{-e}=P^n\cdot10^{-kn}=R^n$（引理 1）一致。$\blacksquare$

于是任务彻底分解为：**算 $S=P^n$ → 按引理 2 插点 → 按题目规则去零/去点**。

### 2.4 经典技术：十进制数码数组 + 逐次乘小整数

大整数用一个**小端的十进制数码数组**表示：`dig[0]` 是个位、`dig[1]` 是十位……`len` 记录当前位数。乘一个小整数 $m$ 的标准做法是从低位向高位逐位相乘、处理进位：

```cpp
carry = 0;
for i in [0, len):
    cur     = dig[i]*m + carry;
    dig[i]  = cur % 10;
    carry   = cur / 10;
while (carry) { dig[len++] = carry%10; carry/=10; }
```

**引理 3（`mul` 的正确性）**

上述过程结束后，数组所表示的值恰为原值 $\times m$。

**证明**（模拟竖式乘法）：设原数 $\sum_i d_i10^i$。乘 $m$ 后第 $i$ 位的"未进位和"为 $d_i\,m+c_i$，其中 $c_i$ 是第 $i-1$ 位产生的进位。循环按 $i=0,1,\dots$ 顺序处理，令 $d_i'\gets(d_i m+c_i)\bmod10$、$c_{i+1}\gets\lfloor(d_i m+c_i)/10\rfloor$，这正是每个十进制位"本位写 $d_i'$、向高位进 $c_{i+1}$"的竖式过程。循环结束再逐个把剩余进位压入更高位，直到进位为 $0$。由竖式乘法的唯一性，最终数码即为 $(m\sum_i d_i10^i)$ 的十进制表示。$\blacksquare$

每次相乘是 $O(\text{位数})$（外加进位的若干位），做 $n$ 次得 $O(n\cdot L)\le250\times1250\approx3\times10^5$。

> 为什么不做"快速幂 + 大数乘法"？因为 $n\le250$ 太小，逐次相乘已经足够快，且实现简单、不易错。**能用线性换两次方复杂度时，优先选简单的那个**。

### 2.5 格式化：按情形分类讨论

拿到 $S$ 与 $e$ 后，按情形分类输出。先做两件清理：把小数部分**末尾的 $0$ 去掉**，再把整数部分的**前导 $0$ 去掉**（本解中 $S$ 无前导零，故整数部分天然无前导零）。然后：

**引理 4（四种输出形态，覆盖所有情况）**

设清理后整数部分为 `ip`、小数部分为 `fp`：

- $e=0$：结果必为整数，直接输出 $S$（引理 2 的特例）。
- $e>0$ 且 `ip` 为空：结果 $<1$，输出 `'.'+fp`（对应题面"省略整数 $0$"）。
- $e>0$ 且 `fp` 为空：结果为整数，输出 `ip`（不带小数点）。
- 否则输出 `ip+'.'+fp`。

**证明**：$e>0$ 时 `ip` 为空当且仅当 $L\le e$（引理 2），此时数值 $<1$，依题目特例如 `.25` 形式输出。`fp` 为空当且仅当小数部分全为 $0$，说明数值实为整数，依题目要求不加小数点。四种情形互斥且穷尽（$e$ 是否为零 $\times$ 两部分的空否）。$\blacksquare$

以几组手推结果验证：`2.5^2=6.25`、`0.5^2=.25`、`1.0^3=1`、`0.01^3=.000001`、`.5^1=.5`，均落在上述四类中。

### 2.6 剖析几个失败思路

**失败 1：用 `double` 直接 `pow` 再格式化。**
$9999.9^{250}$ 约 $10^{1000}$，`double` 的有效位约 $15\sim16$ 位十进制，输出必然是垃圾。$\Rightarrow$ 必须整数大数。

**失败 2：把 `1.0100` 这类输入的小数位数 $k$ 数错。**
`1.0100` 的小数部分有 $4$ 位（含末尾两个 $0$），$k=4$。若程序"聪明"地先去掉末尾零再数 $k=2$，虽然数值等价，但**中间量 $P$ 与 $e$ 会改变**，容易与后续逻辑对不上。稳妥做法：**老老实实数小数点后的原始位数**，让引理 1 的 $P,k$ 与输入字面一致。

**失败 3：整数幂算出后忘了"去尾零"或"去前导零"。**
`1.0^3` 得 `S="1000"`，$e=3$，小数部分 `S.substr(1)="000"` 去尾零后为空 $\Rightarrow$ 应输出 `1`；若忘记去零会输出 `1.000`。$\Rightarrow$ 去零/去点是格式化的必要步骤。

## 3. 模式总结（Pattern Summary）

**模式名：十进制小数幂的「整数化 → 大数 → 定点格式化」。**

**识别信号**：要给实数（以十进制串给出）做整数次幂，且要求"精确、按十进制输出"，涉及大数与小数点位置。

**可复用套路（按实际思考顺序）**：

- **explore its property** — 把十进制小数写成 $P\cdot10^{-k}$，把乘方变成整数幂 + 指数（引理 1）。
- **consider easier version** — 先解"$R$ 是整数"的简化版，发现难点只有大整数乘法。
- **reduce to easier problem** — 一般情形 = 整数幂串 $S$ 按小数点位置插点（引理 2）。
- **classic problem solution** — 十进位数码数组大整数，逐次乘小整数并处理进位（引理 3）。
- **format by category** — 按"整数 / $<1$ / 有小数 / 无小数"分类输出并去零（引理 4）。
- **avoid floating point** — 全程整数运算，杜绝精度损失。

**一句话记忆**：实数幂 = 整数幂（大数）× $10^{-kn}$，先用大数算出整数幂，再按小数点位置分情况格式化。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| `s` | `string` | 当前组的 $R$ 字面串 | 每组读入 | 题面 |
| $n$ | `int` | 当前组的幂次 | 读入 | 题面 |
| $P$ | `int` | 去掉小数点后 $R$ 表示的整数 | $0$，逐字符累加 | $R=P\cdot10^{-k}$ |
| $k$ | `int` | $R$ 的小数位数（含末尾零） | $0$，见小数点后每位数 $+1$ | 引理 1 |
| `dig[mxn]` | `int[1505]` | 大整数数码，**小端**（`dig[0]` 为个位） | 每组重置为 `{1}`，`len=1` | 大数表示 |
| `len` | `int` | 大整数当前位数 | $1$ | — |
| $S$ | `string` | $P^n$ 的十进制串（正常序，无前导零） | 由 `dig` 倒序拼出 | 引理 2 |
| $e$ | `int` | 结果小数位数 $=k\cdot n$ | $kn$ | 引理 1 |

### 4.2 编号步骤

1. `while(cin>>s>>n)` 读到 EOF（多组）。
2. 扫描 `s`：遇 `.` 置标志；遇数字则 `P=P*10+该数字`，若已过小数点则 `++k`。
3. 令 `len=1;dig[0]=1`；重复 $n$ 次 `mul(P)`，得到 $P^n$（引理 3）。
4. 把 `dig` 倒序拼成串 $S$（即 $P^n$ 的十进制，无前导零）。
5. `e=k*n`：
   - `e==0`：输出 $S$，`continue`。
   - 否则按引理 2 切分为 `ip`（整数部分）与 `fp`（小数部分）；`L<=e` 时 `ip` 为空、`fp` 前置补零。
6. 去除 `fp` 末尾的 `0`（`while(!fp.empty()&&fp.back()=='0') fp.pop_back();`）。
7. 按引理 4 的四类输出：`ip` 为空 $\to$ `'.'+fp`；`fp` 为空 $\to$ `ip`；否则 `ip+'.'+fp`。

### 4.3 复杂度

- 时间：每组 $O(n\cdot L)$，$L\le1250$、$n\le250$，即 $\le3\times10^5$ 次位运算；$11$ 组共 $\le3.4\times10^6$。
- 空间：两个 `string` + 一个 `int[1505]`，约 $6$ KB。
- 实测（§4.5）：最坏 $R=9999.9,\ n=250$ 输出 $1251$ 位，耗时 **$0.0051$ s**。

### 4.4 关键不变量（值得写 `assert` 的地方）

1. 任意时刻 `dig[len-1]!=0`（无前导零）且 `P>0`（$R>0$）。
2. $S$ 的每位是 $P^n$ 十进制位，`len==S.size()`。
3. $e=kn\ge0$；`ip`、`fp` 拼接（去零）后数值仍等于 $R^n$。
4. 只用整数运算，无浮点参与。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 随机对拍 | **通过**：$400$ 组随机 $(R,n)$（$R$ 随机整数/小数且 $\le9999.9$，$n\in[1,250]$），`std == 暴力(字符串大数) == Python 原生大整数 oracle` **三者逐行一致** |
| 手工边界用例 | **通过**：`2.5^2=6.25`、`0.5^2=.25`、`1.0^3=1`、`10^2=100`、`0.01^3=.000001`、`.5^1=.5`、`9999.9^1=9999.9` |
| 最坏规模计时 | $R=9999.9,\ n=250$ $\Rightarrow$ 输出 $1251$ 位，耗时 **$0.0051$ s**（std 与暴力、oracle 一致） |
| 残余风险 | 若输入 $R$ 超过题面 $9999.9$ 上限（如 $6$ 位数整数），`mxn{1505}` 可能不足；按题面不会 |

## 5. 示例代码

### 5.1 主解：十进位数码数组 + 逐次乘小整数 + 定点格式化
```cpp
// 题目：P1517 [ECNA 1988] 高精求小数幂
// https://www.luogu.com.cn/problem/P1517
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1505};      // P^n 位数 <= 5*250=1250 (+5 松弛)

int dig[mxn];                 // 大数(十进制小端;dig[0] 为个位)
int len;                      // 当前位数

void mul(int m)               // 大数 *= 小整数 m
{
	int carry=0;
	for(int i=0;i<len;++i)
	{
		i64 cur=1ll*dig[i]*m+carry;
		dig[i]=cur%10;
		carry=cur/10;
	}
	while(carry)
	{
		dig[len++]=carry%10;
		carry/=10;
	}
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	string s;
	int n;
	while(cin>>s>>n)                    // 读到文件末尾(多组数据)
	{
		int P=0,k=0;                    // P=去掉小数点后的整数, k=小数位数
		bool dot=false;
		for(char c:s)
		{
			if(c=='.')
				dot=true;
			else if(c>='0'&&c<='9')
			{
				P=P*10+(c-'0');
				if(dot)
					++k;                // 只统计小数点之后的位数
			}
		}
		len=1;dig[0]=1;
		for(int i=0;i<n;++i)
			mul(P);                     // R^n = P^n / 10^(k*n)
		string S;
		for(int i=len-1;i>=0;--i)
			S.push_back(char('0'+dig[i]));
		int e=k*n;                      // 结果的小数位数
		if(e==0)                        // 整数,不带小数点
		{
			cout<<S<<'\n';
			continue;
		}
		string ip,fp;
		if(len<=e)
			fp=string(e-len,'0')+S;     // 整数部分为 0(结果<1),省略
		else
		{
			ip=S.substr(0,len-e);
			fp=S.substr(len-e);
		}
		while(!fp.empty()&&fp.back()=='0')
			fp.pop_back();              // 小数末尾去 0
		if(ip.empty())                  // 结果 <1 时省略整数 0
			cout<<'.'<<fp<<'\n';
		else if(fp.empty())
			cout<<ip<<'\n';
		else
			cout<<ip<<'.'<<fp<<'\n';
	}
	return 0;
}
```

### 5.2 对照实现：字符串大数逐次乘（仅用于对拍）
```cpp
// P1517 暴力基准：用字符串大数逐次乘以 P
#include<bits/stdc++.h>
using namespace std;

string mul(string s,int m)            // 十进制字符串 *= 小整数
{
	int carry=0;
	for(int i=s.size()-1;i>=0;--i)
	{
		int cur=(s[i]-'0')*m+carry;
		s[i]=char('0'+cur%10);
		carry=cur/10;
	}
	while(carry)
	{
		s.insert(s.begin(),char('0'+carry%10));
		carry/=10;
	}
	return s;
}

string fmt(string s,int e)            // 按规则插入小数点并去零
{
	if(e==0)
		return s;
	if((int)s.size()<=e)
		s=string(e-s.size(),'0')+s;
	int pos=s.size()-e;
	string ip=s.substr(0,pos),fp=s.substr(pos);
	while(!fp.empty()&&fp.back()=='0')
		fp.pop_back();
	int i=0;
	while(i<(int)ip.size()&&ip[i]=='0')
		++i;
	ip=ip.substr(i);
	if(ip.empty())
		return fp.empty()?"0":"."+fp;
	if(fp.empty())
		return ip;
	return ip+"."+fp;
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	string s;
	int n;
	while(cin>>s>>n)
	{
		int P=0,k=0;
		bool dot=false;
		for(char c:s)
		{
			if(c=='.')
				dot=true;
			else if(c>='0'&&c<='9')
			{
				P=P*10+(c-'0');
				if(dot)
					++k;
			}
		}
		string num="1";
		for(int i=0;i<n;++i)
			num=mul(num,P);
		cout<<fmt(num,k*n)<<'\n';
	}
	return 0;
}
```

两版输出必须逐字节相同（已用 $400$ 组随机数据 + Python 原生大整数三方确认）。暴力版用**字符串**存大数、并以完全独立的代码路径做格式化，正因如此能暴露主解里方向写反、切点算错等掩蔽性 bug。

### 5.3 易错点清单

- **用 `double`/`pow`** $\Rightarrow$ 大幂必然丢精度甚至溢出，必须整数大数。
- **`k` 数错**（例如先去掉末尾零再数）$\Rightarrow$ 与引理 1 的 $P,k$ 不一致，切点错位。
- **忘记去小数末尾 $0$** $\Rightarrow$ 输出 `1.000` 之类，违反格式要求。
- **忘记"结果 $<1$ 时省略整数 $0$"** $\Rightarrow$ 输出 `0.25` 而非 `.25`。
- **整数结果仍输出小数点** $\Rightarrow$ 例 `1.0^3` 若不去点会输出 `1.000`。
- **`mul` 的进位处理不完整**（只处理一次进位而非 `while`）$\Rightarrow$ 当 $P$ 较大时高位进位丢失，结果偏小。
