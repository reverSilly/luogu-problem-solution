# P1568 赛跑

> 标签：模拟 / 洛谷原创 · 难度：普及-
> 本地题面：`P1568.md`（输入全为 $\le1000$ 的非负整数）。
> 验证：`appendix/P1568/P1568_check.py` —— 官方样例输出 `2` 通过；500 组随机小规模用例标程与暴力逐字节一致；最坏 $N=M=1000$、总时间 $10^6$ 耗时 $0.013$ s。

## 1. 重新读题

**问题重述（人话版）**

SH 与 KC 同时从同一起点沿同一方向跑，比赛总时间相同。两人的运动被分成若干段，段内速度恒定：

- SH 有 $N$ 段，第 $i$ 段是"以速度 $v_i$ 跑 $d_i$ 个时间单位"；
- KC 有 $M$ 段，第 $j$ 段是"以速度 $u_j$ 跑 $e_j$ 个时间单位"。

把时间按单位切成 $T$ 个时刻（$T=$ 两人总时间），在每个整数时刻比较两人的累计位置。要求统计**领先顺序的变化次数**。

> 一句话版本：**把两人的位置随时间的走势展开，数一数"领头的人"换了多少次。**

**题面里容易漏掉的条款**

1. 「领先顺序的变化」的定义包含**经过平局的情况**：题面原文说"某个时刻 SH 领先，接下来 KC 赶上来并和 SH 齐头并进，但最终还是超过了 SH，这也是一次领先顺序的变化"。也就是说，**平局本身不算一次变化，但它不打断"领先者是否换人"的判断**——比较的是平局前后那次"非平局领先者"。
2. 「比赛**开始后**」$\Rightarrow$ **开局第一次确立领先者不算变化**。样例中 KC 一开始就领先，这一次不计入；随后 SH 反超（第 1 次），再被 KC 反超（第 2 次），答案 $2$。
3. 速度、时长都是**非负整数**，允许为 $0$（站着不动）。因此**可能出现时长为 $0$ 的段**（该段无时间片、直接跳过），也允许速度为 $0$。
4. 「所有数字均不大于 $1000$」$\Rightarrow$ $N,M\le1000$、$d_i,e_j\le1000$，故**总时间 $T\le1000\times1000=10^6$**，可以放心按单位时间逐格模拟。
5. 两人**总时间相同**（$T=\sum d_i=\sum e_j$）。

**数据范围与规模感受**

$$N,M\le1000,\qquad v_i,u_j,d_i,e_j\le1000,\qquad T\le 10^6 .$$

$T\le10^6$，提示"把时间展开成逐单位数组再线性扫描"的 $O(T)$ 做法完全可行（$10^6$ 次比较在 $1$ s 内轻松完成）。任何 $O(T^2)$ 的做法都会爆。

## 2. 思维链（Chain-of-thought）

### 2.1 探索性质：把"领先顺序"翻译成符号序列

设 $S(t)$、$K(t)$ 分别为两人在第 $t$ 个单位时间末的累计位置（$t=1..T$）。定义**领先符号**

$$\sigma_t=\operatorname{sgn}\big(S(t)-K(t)\big)\in\{+1,0,-1\},$$

其中 $+1$ 表示 SH 领先，$-1$ 表示 KC 领先，$0$ 表示并头齐进（平局）。

记 $\sigma=(\sigma_1,\sigma_2,\dots,\sigma_T)$ 为整条符号序列。现在把题面那句口语化的定义精确化：

- 从 $\sigma$ 里**删掉所有 $0$**（平局时刻不贡献"谁领先"的信息）；
- 再把**相邻相同的符号合并**（同一人连续领先只是"一段领先"，不是多次变化）。

**引理 1（领先顺序变化次数 = 压缩后序列的"相邻不同"对数）**

设删零去重后得到序列 $\tau=(\tau_1,\dots,\tau_m)$（每个 $\tau_k\ne0$ 且相邻两项不同），则领先顺序的变化次数为

$$\text{Ans}=\max(m-1,\,0).$$

**证明**：把变化定义为"领头者（忽略平局）从一个人换成另一个人"。走一遍 $\tau$：
- 序列开头 $\tau_1$ 是**比赛开始后第一个确立的领先者**，题面明确"开始后"不算一次变化，故以它为基准，$0$ 次变化；
- 每遇到 $\tau_{k}\ne\tau_{k-1}$（相邻不同），说明领先者由 $\tau_{k-1}$ 变成了 $\tau_k$，计入一次变化；
- 反过来，任何一次"领先者换人"都必然在 $\tau$ 中留下相邻不同的一对（因为删零去重只保留"谁在领先"的信息，领先者换人当且仅当压缩后的相邻值不同）。
因此变化次数恰为相邻不同对的数目 $=m-1$。当 $m=0$（全程平局）时为 $0$。$\blacksquare$

> 这条引理把口语定义变成了一个**纯序列操作**：删零、去重、数相邻不同。下面的失败分析会说明，凭直觉随手写的计数很容易漏掉其中任一步。

### 2.2 得到位置序列：把时间展开

要拿到 $\sigma$ 或 $\tau$，先得有两人的位置序列 $S(t),K(t)$。由于段内速度恒定，直接**按单位时间累加**即可。

**引理 2（逐单位累加得到的位置是正确的时刻位置）**

设某人的分段为 $(v_1,d_1),\dots,(v_p,d_p)$。令 $P(0)=0$，并按时间顺序把每一段重复 $d$ 次地执行 $P(t)=P(t-1)+v_{\text{该时刻所属段}}$，则 $P(t)$ 恰为其在第 $t$ 个单位时间末的累计位置（位移）。

**证明**：在第 $t$ 个单位时间（区间 $(t-1,t]$）内，该人的速度由"$t-1$ 落在哪一段"决定，是**常数**；匀速直线运动的位移 = 速度 × 时间，一个单位时间即速度 × 1。累加 $\sum_{s=1}^{t}\big(\text{第 }s\text{ 单位时间的速度}\big)$ 就是这段总位移。由段划分的定义，第 $s$ 单位时间的速度就是覆盖时刻 $(s-1,s]$ 的那一段的 $v$；逐单位展开的累加正实现了这件事。故 $P(t)$ 是正确的累计位移。$\blacksquare$

**关键实现细节（本人在写标程时踩过的坑）**：段不急，可以先把每段"摊平"成逐单位的数组：

```cpp
for(int i=0;i<n;++i)
	for(int e=0;e<st[i];++e)
	{
		++ts;
		ps[ts]=ps[ts-1]+sv[i];   // 必须先 ++ts 再读 ps[ts-1]
	}
```

**千万不要把自增和下标塞进同一个表达式**，例如 `ps[++ts]=ps[ts-1]+sv[i]`。C++17 规定简单赋值的**右操作数先于左操作数求值**，于是右侧的 `ts-1` 用的是**自增前**的 `ts`：第一次迭代时 `ts` 还是 $0$、`ts-1=-1`，越界读到垃圾，整条位置序列全错（本人在样例上曾得到 $6$ 而非 $2$）。把自增拆成独立语句即可规避。

### 2.3 剖析失败思路

**失败 1：把"开局第一次领先"也算作变化。**
这样样例会得 $3$（KC 领先算 1，SH 反超算 1，KC 反超算 1）。题面"比赛开始后"四个字排除了它。$\Rightarrow$ 首个领先者**不计数**。

**失败 2：把平局时刻当成"变化"或当成"新的一人领先"。**
若每次 $\sigma_t$ 与 $\sigma_{t-1}$ 不同就 `cnt++`（不处理 $0$），则样例中 $t=3,4,6$ 的平局会各自记一次，答案远超 $2$。$\Rightarrow$ 必须先**删零**，只在"非平局"的相邻处比较。

**失败 3：不合并连续相同符号。**
若不合并，则 SH 连续领先 5 个时刻会被算成 4 次变化。$\Rightarrow$ 相邻相同必须**合并**（等价于只在符号真正跳变时 `++cnt`）。

**失败 4：把两人总时间当成 `min` 之外的东西 / 越界。**
两人时间由题面保证相等，但稳妥起见取 `T=min(ts,tk)`；数组开到 $T_{\max}+5$ 以防越界。

**失败 5：相等位置用 `>` 直接判负 / 用浮点比较。**
位置是整数累加（速度、时长均为整数），**精确相等就是 `S(t)==K(t)`**，无需任何浮点或 eps。用 `>` 和 `<` 两个整数比较即可得到 $\operatorname{sgn}$。

### 2.4 复杂度与溢出体检

| 量 | 范围 | 上界 | `int` 够？ |
|---|---|---|---|
| $T$ | $\sum d_i$ | $10^6$ | 是 |
| 位置 $S(t),K(t)$ | 速度 $\times$ 时间 | $1000\times10^6=10^9$ | 是（`int` 上限约 $2.1\times10^9$） |
| 位置数组尺寸 | $T_{\max}+5$ | `mxt{1000005}` | — |

位置最大约 $10^9$，`int` 刚好够但**贴近上限**，稳妥用 `i64`（`long long`）。逐单位模拟 $O(T)=10^6$，空间两个 `i64[T]` 约 $16$ MB，均远低于 $1$ s / $125$ MB 限制。

## 3. 模式总结（Pattern Summary）

**模式名：分段匀速运动 → 逐时刻位置序列 → 符号序列的「删零 + 去重 + 数跳变」。**

**识别信号**：题目给"每人若干匀速段"，要求比较两人"随时间的领先关系变化"；所有量是整数、时长有限。

1. **explore its property** — 把"领先顺序变化"精确化成符号序列操作：删平局、合并连续相同、数相邻不同（引理 1）。
2. **reduce to easier problem** — 把"分段速度"摊平成逐单位位置数组（引理 2），运动问题退化为数组比较问题。
3. **classic problem solution** — 线性扫描维护"上一次确立的领先者" `prv`，非平局且与 `prv` 不同则计数，得到 $O(T)$。
4. **boundary discipline（边界纪律）** — 开局首个领先者不计数；平局跳过但保留 `prv`；允许时长为 $0$ 的段（摊平时自动跳过）。
5. **explore its property（第二次：数制与求值顺序）** — 位置可达 $10^9$ 用 `i64`；摊平循环里把自增与下标拆成两条语句，避免 C++ 求值顺序陷阱。

**同族题**：各种"速度-时间折线比较先后"、"两人追赶谁先到"的模拟题，骨架都是"逐时刻算位置再用符号压缩比较"。

**一句话记忆**：先摊平出逐时刻位置，再过一遍符号序列：删平局、合并连续、数跳变。

## 4. 真实解法

### 4.1 符号表

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 / 来源 |
|---|---|---|---|---|
| $N,M$ / `n,m` | `int` | SH / KC 的段数 | 读入 | 题面 |
| `sv[i],st[i]` | `int [1005]` | SH 第 $i$ 段的速度、时长 | 读入 | 题面 |
| `kv[i],kt[i]` | `int [1005]` | KC 第 $i$ 段的速度、时长 | 读入 | 题面 |
| `ps[t],pk[t]` | `i64 [1000005]` | SH / KC 在第 $t$ 单位时间末的位置 | `ps[0]=pk[0]=0`，逐段累加 | 引理 2 |
| `ts,tk` | `int` | 两人摊平后的总时间 | $0$ | 累加变量 |
| `T` | `int` | 比赛总时间 $=\min(ts,tk)$ | — | 题面保证相等 |
| `prv` | `int` | 上一次**已确立**的领先者（$+1$ SH / $-1$ KC / $0$ 尚无） | $0$ | 引理 1 |
| `cnt` | `int` | 领先顺序变化次数 | $0$ | 答案 |
| `lead` | `int` | 当前时刻领先者符号 $\operatorname{sgn}(ps-pk)$ | — | 引理 1 的 $\sigma_t$ |

### 4.2 编号步骤

1. 读入 $n,m$，再读入 SH 的 $N$ 段与 KC 的 $M$ 段。
2. 摊平 SH：`ts=0, ps[0]=0`；对每段、每个时间片执行 `++ts; ps[ts]=ps[ts-1]+sv[i];`（引理 2；自增与下标分开写）。
3. 摊平 KC：同理得 `tk, pk[]`。
4. 取 `T=min(ts,tk)`；`cnt=0,prv=0`。
5. 对 $t=1..T$：
   5.1 算 `lead=(ps[t]>pk[t])-(ps[t]<pk[t])`；
   5.2 若 `lead!=0`（非平局）：若 `prv!=0 && prv!=lead` 则 `++cnt`；随后 `prv=lead`（平局时 $prv$ 不变，实现引理 1 的"删零且不打断"）。
6. 输出 `cnt`。

### 4.3 复杂度

- 时间：摊平 $O(T)$ + 扫描 $O(T)$，$T\le10^6$。
- 空间：`i64 ps/pk` 各约 $8$ MB，合计约 $16$ MB（< 125 MB）。
- 实测（见 §4.5）：最坏 $N=M=1000$、总时间 $10^6$ 耗时 $0.013$ s。

### 4.4 关键不变量

1. `ps[t]`（`pk[t]`）等于对应选手在第 $t$ 单位时间末的精确累计位置（引理 2）。
2. `prv` 只记录**非平局**时刻最近一次的领先者；平局不改变它。
3. `cnt` 恒等于引理 1 中 $\tau$ 的相邻不同对数；开局首次领先者不计入。
4. `lead` 由整数比较直接得到，无浮点误差。

### 4.5 验证状态小结

| 项目 | 状态 |
|---|---|
| 官方样例回归 | **通过**：`4 3` / `1 2`,`4 1`,`1 1`,`2 10` / `2 3`,`1 2`,`3 9` → `2` |
| 随机数据对拍 | **通过**：$500$ 组随机用例（两侧总时间强制相同、段时长含 $0$、速度含 $0$），`prv` 扫描版与"符号序列删零+去重后数相邻不同"版逐字节一致 |
| 最坏规模计时 | $N=M=1000$、每段时长 $1000$（总时间 $10^6$）→ 输出 $0$（该构造下 SH 始终领先），耗时 **$0.013$ s** |

## 5. 示例代码

### 5.1 主解：逐时刻摊平 + 符号扫描

```cpp
//
// 题目：P1568 赛跑
// https://www.luogu.com.cn/problem/P1568
// AC
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{1005};          // N,M<=1000 (+5 松弛)
constexpr int mxt{1000005};       // 总时间上界 1000*1000 (+5 松弛)

int n,m;
int sv[mxn],st[mxn],kv[mxn],kt[mxn];
i64 ps[mxt],pk[mxt];              // ps[t]/pk[t]=第 t 个单位时间末的位置

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>m;
	for(int i=0;i<n;++i)
		cin>>sv[i]>>st[i];
	for(int i=0;i<m;++i)
		cin>>kv[i]>>kt[i];
	int ts=0,tk=0;
	ps[0]=0;
	for(int i=0;i<n;++i)
		for(int e=0;e<st[i];++e)
		{
			++ts;                 // 先自增再读 ps[ts-1],避免 ++ 与索引的求值顺序陷阱
			ps[ts]=ps[ts-1]+sv[i];
		}
	pk[0]=0;
	for(int i=0;i<m;++i)
		for(int e=0;e<kt[i];++e)
		{
			++tk;
			pk[tk]=pk[tk-1]+kv[i];
		}
	int T=min(ts,tk);
	int cnt=0,prv=0;              // prv=上一次已确立的领先者(+1 SH / -1 KC)
	for(int t=1;t<=T;++t)
	{
		int lead=(ps[t]>pk[t])-(ps[t]<pk[t]);
		if(lead!=0)               // 平局不改变领先者,直接跳过
		{
			if(prv!=0&&prv!=lead)
				++cnt;
			prv=lead;
		}
	}
	cout<<cnt<<'\n';
	return 0;
}
```

**代码结构对照**：`ps/pk` 是引理 2 的逐时刻位置；`lead` 用整数比较构造 $\operatorname{sgn}$；`prv` 与"`lead!=0` 才更新"共同实现了引理 1 的"删零去重数跳变"，`prv=0` 的初值保证开局首个领先者不计入。

### 5.2 对照实现：符号序列删零 + 去重（仅用于对拍）

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxt{1000005};

int n,m;
i64 ps[mxt],pk[mxt];

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	cin>>n>>m;
	int ts=0,tk=0;
	ps[0]=0;
	for(int i=0,v,d;i<n;++i){cin>>v>>d; for(int e=0;e<d;++e){++ts;ps[ts]=ps[ts-1]+v;}}
	pk[0]=0;
	for(int i=0,v,d;i<m;++i){cin>>v>>d; for(int e=0;e<d;++e){++tk;pk[tk]=pk[tk-1]+v;}}
	int T=min(ts,tk);
	vector<int> seq;             // 依次记录非平局时刻的领先者符号
	for(int t=1;t<=T;++t)
	{
		i64 d=ps[t]-pk[t];
		if(d>0)
			seq.push_back(1);
		else
			if(d<0)
				seq.push_back(-1);
	}
	vector<int> c;               // 合并连续相同领先者
	for(int v:seq)
		if(c.empty()||c.back()!=v)
			c.push_back(v);
	int ans=c.empty()?0:(int)c.size()-1;   // 相邻不同即一次领先顺序变化
	cout<<ans<<'\n';
	return 0;
}
```

两版输出逐字节相同（已用 $500$ 组随机数据确认）。这一版**显式建出**符号序列，再按引理 1 的字面步骤"删零、去重、数相邻不同"，与主解"边扫边维护 `prv`"是两条不同的代码路径，可交叉验证计数规则的正确性。

### 5.3 易错点清单

- **把自增与下标写在同一表达式**（如 `ps[++ts]=ps[ts-1]+v`）$\Rightarrow$ C++17 下右侧先求值，`ts-1` 用旧值、越界读（§2.2，本人实测样例错成 $6$）。
- **把平局当变化** $\Rightarrow$ 答案偏大（§2.3 失败 2）。
- **不合并连续相同领先** $\Rightarrow$ 每次时刻比较都计一次，答案偏大（§2.3 失败 3）。
- **把开局首次领先计入变化** $\Rightarrow$ 多 $1$（§2.3 失败 1）。
- **位置用 `int`** 在极端数据下贴近上限，稳妥用 `i64`。
- **用 `endl`** 违反本项目风格指南，一律用 `'\n'`。
