# P1612 [yLOI2018] 树上的链

## Part 1 — 题目理解 (Problem Comprehension)

### 题意简述

给一棵以 $1$ 为根的有根树，点 $i$ 有权 $w_i$ 与参数 $c_i$。
对每个点 $u$，求最长的"向上链" $v_1=u,\,v_2=\text{fa}(u),\,v_3=\text{fa}^2(u),\dots,v_m$ 的长度 $m$，使得
$$\sum_{j=1}^{m} w_{v_j}\le c_u .$$
也就是从 $u$ 出发，不断地往父亲走，在权值和不超过 $c_u$ 的前提下最多能连续走几个点（$u$ 自己算一个）。

### 输入输出格式

- **输入格式**：第一行 $n$；第二行 $n-1$ 个数 $p_2,\dots,p_n$（$p_i$ 是 $i$ 的父亲）；第三行 $n$ 个 $w_i$；第四行 $n$ 个 $c_i$。
- **输出格式**：一行 $n$ 个数，第 $i$ 个是节点 $i$ 的答案，空格分隔。
- **数据规模**：$n\le10^5$，$1\le p_i<i$，$1\le w_i\le c_i\le10^9$。

### 关键约束分析

1. $1\le p_i<i$ 意味着**父节点编号一定更小**，可以按编号 $1,2,\dots,n$ 直接递推出深度与前缀和，完全不需要建图或 DFS。
2. $w_i\le c_i$ 保证答案至少为 $1$，所以不会出现"一个点都放不下"的退化情况——这让二分/倍增不需要处理"无解"。
3. $n=10^5$ 且权值可达 $10^9$，一条长链的和可达 $10^{14}$，**必须用 `long long`**。
4. 若对每个点暴力向上走，链形态下是 $\mathcal{O}(n^2)$（$10^{10}$），必须加速到 $\mathcal{O}(\log n)$ 每点。
5. 深链上递归 DFS 会爆栈（虽然本题可以完全不 DFS，但若用 DFS 求深度需注意）。

## Part 2 — 思路推导 (Idea Discovery)

### 第一步：暴力与它的瓶颈

对每个 $u$，从 $u$ 沿父亲指针往上走，累加权值，超过 $c_u$ 就停。
单点代价 $\mathcal{O}(\text{答案})$，最坏 $10^5$；总共 $10^{10}$，超时。

瓶颈在于"重复计算路径上的和"。把"路径和"换成"两点前缀和之差"，就能把"求一段和"降成 $\mathcal{O}(1)$。

### 第二步：前缀和改写条件

定义 $s_u$ 为根到 $u$（含）的点权和。

**引理 1（链和的差分形式）**：设 $a$ 是 $u$ 的某个祖先（$a$ 可以为 $u$ 自己），则链 $u\to a$ 的点权和为
$$s_u-s_{\text{fa}(a)},$$
其中约定 $s_{\text{fa}(\text{root})}=0$。

*证明*：$s_u$ 是根到 $u$ 的和，$s_{\text{fa}(a)}$ 是根到 $a$ 的父亲的和。两段都在同一条根路径上，后者是前者的前缀，相减正好剩下 $a$ 到 $u$（含两端）这一段。$a$ 为根时，减数取 $0$，整条根路径都算进去。$\square$

于是"链 $u\to a$ 的和 $\le c_u$"等价于
$$s_{\text{fa}(a)}\ \ge\ s_u-c_u .$$
把右边记作阈值 $\theta_u=s_u-c_u$，条件就只和"$a$ 的父亲的前缀和"有关。

### 第三步：单调性——为什么能二分/倍增

记 $\mathrm{up}(a)=s_{\text{fa}(a)}$（根记 $0$）。

**引理 2（单调性）**：沿根到叶的方向，$\mathrm{up}(\cdot)$ 严格递增。

*证明*：设 $x$ 是 $y$ 的父亲。$\mathrm{up}(y)=s_x$，$\mathrm{up}(x)=s_{\text{fa}(x)}=s_x-w_x$（$x$ 非根时），故 $\mathrm{up}(y)-\mathrm{up}(x)=w_x\ge1>0$；$x$ 为根时 $\mathrm{up}(x)=0\le s_x=\mathrm{up}(y)$，且 $s_x=w_{\text{root}}\ge1$ 使不等式仍严格。$\square$

**引理 3（合法祖先集合的形状）**：对固定的 $u$，满足 $\mathrm{up}(a)\ge\theta_u$ 的祖先 $a$ 恰好是根路径上**从某个深度开始往下的一段连续后缀**。

*证明*：由引理 2，$\mathrm{up}$ 沿路径严格递增，故满足 $\ge\theta_u$ 的位置必然构成"越深越容易满足"的后缀形；即存在唯一的临界深度 $D$，使 $\mathrm{deep}(a)\ge D$ 时合法。$\square$

我们要的是**最浅的**合法祖先 $a^\*$（链最长）。

### 第四步：倍增上跳

朴素二分需要把路径存下来（可以做到，但要开栈）。倍增更直接：预处理 $2^k$ 级祖先 `up[k][v]`，然后从 $u$ 出发，从大到小尝试"跳 $2^k$ 步"：

> 若跳过去之后的那个祖先仍然合法（$\mathrm{up}(\text{祖先})\ge\theta_u$），就跳。

**引理 4（倍增正确性）**：上述过程结束时的 $a$ 就是最浅的合法祖先。

*证明*：设 $a^\*$ 为最浅合法祖先。过程维持"$a$ 合法"这一不变量（初始 $a=u$ 合法，因为 $\mathrm{up}(u)=s_{\text{fa}(u)}\ge s_u-c_u=\theta_u$ 由 $w_u\le c_u$ 得到）。每次跳跃都把 $a$ 往上移，故终止时 $a$ 是合法祖先。
另一方面，任何时刻若 $a$ 的某个祖先不合法，则 $a$ 与 $a^\*$ 之间的所有点都不合法（引理 3 的后缀形），所以"能跳就跳"不会越过 $a^\*$：标准倍增的不变量是"最终 $a$ 的父节点不合法"，从而 $\text{dep}(a)=\text{dep}(a^\*)$，即 $a=a^\*$。$\square$

**引理 5（答案公式）**：答案为 $\text{dep}(u)-\text{dep}(a^\*)+1$。

*证明*：链 $u\to a^\*$ 上的点数就是深度差加一。$\square$

### 第五步：实现细节

- `p[i]<i` 让我们按 $i=0,1,\dots,n-1$ 的顺序递推 `dep[i]`、`s[i]`、`up[0][i]`，无需求树。
- 根的父亲约定为它自己（`p[0]=0`），这样 `up[k][0]=0` 恒成立，跳飞了也只会停在根。
- $\mathrm{up}(x)$ 用一个小函数 `above(x)` 表达：`x? s[p[x]] : 0`。

## Part 3 — 模式总结 (Pattern Summary)

- `explore its property` — 向上链的和 = 前缀和之差，把"路径和"变成 $\mathcal{O}(1)$ 的减法。
- `reduce to easier problem` — 原问题化为"在根路径上找最浅的、满足 $\mathrm{up}(a)\ge\theta_u$ 的点"，是一维单调查找。
- `classic problem solution` — 单调性 + 倍增上跳，$\mathcal{O}(\log n)$ 求每个点的最浅合法祖先。
- `exploit the input order` — $p_i<i$ 使深度/前缀和/倍增表都能按编号顺序递推，省掉建图与 DFS。

## Part 4 — 真正的解法 (The Real Solution)

### 符号表 (Notation Glossary)

| 数学符号 | 代码变量 | 含义说明 |
| :--- | :--- | :--- |
| $n$ | `n` | 点数 |
| $\text{fa}(i)$ | `p[i]` | 父亲（0-based）；`p[0]=0`（根的父亲约定为自己） |
| $w_i$ | `w[i]` | 点权 |
| $c_i$ | `c[i]` | 参数（链和上限） |
| $s_u$ | `s[i]` | 根到 $i$ 的点权和（`i64`），`s[0]=w[0]` |
| $\text{dep}(u)$ | `dep[i]` | 深度，根为 $0$ |
| $2^k$ 级祖先 | `up[k][i]` | 倍增表，`up[0][i]=p[i]`，`up[k][i]=up[k-1][up[k-1][i]]` |
| $\mathrm{up}(x)$ | `above(x)` | $x$ 的父亲的前缀和，根返回 $0$ |
| $\theta_u$ | `thr` | 阈值 $s_u-c_u$ |
| $a^\*$ | `a` | 当前找到的最浅合法祖先，初值 $u$ |

### 算法步骤

1. 读入 $n$；读 $p_1..p_{n-1}$ 并 `--p[i]`，`p[0]=0`；读 $w,c$。
2. 递推：`dep[i]=dep[p[i]]+1`，`s[i]=s[p[i]]+w[i]`，`up[0][i]=p[i]`（$i=1..n-1$；$i=0$ 时 `dep[0]=0,s[0]=w[0],up[0][0]=0`）。
3. 对 $k=1..\lfloor\log_2 n\rfloor$：`up[k][i]=up[k-1][up[k-1][i]]`。
4. 对每个 $u$：令 `thr=s[u]-c[u]`、`a=u`；`k` 从大到小，若 `above(up[k][a])>=thr` 则 `a=up[k][a]`；输出 `dep[u]-dep[a]+1`。
5. 空格分隔输出，末尾换行。

### 复杂度分析

- **时间复杂度**：递推与倍增表 $\mathcal{O}(n\log n)$，每个点 $\mathcal{O}(\log n)$ 上跳，总计 $\mathcal{O}(n\log n)$。
- **空间复杂度**：$\mathcal{O}(n\log n)$（$\text{up}$ 表约 $18\times10^5$ 个 `int`，约 $7$ MB）。

### 正确性验证

- 引理 1 把"链和"改写为前缀和之差；引理 2 给出单调性，引理 3 说明合法祖先成后缀形，于是"最浅合法祖先"唯一存在。
- 引理 4 是标准的倍增"能跳就跳"归纳：不变量"$a$ 合法 + 最终 $a$ 的父亲不合法"，由单调性保证不会跳过头。
- 引理 5 给出长度公式。
- 数值范围：$s$ 最大 $10^5\times10^9=10^{14}$，`i64` 安全；$\theta_u$ 可能为负，`above` 返回非负，比较用 `i64`。
- 边界：$n=1$ 时输出 `1`；根节点 $\theta\le0$，`above(0)=0\ge\theta` 成立但 `a` 停在根，长度 $1$。

## Part 5 — 示例代码 (Example Code)

```cpp
//
// 题目：P1612 [yLOI2018] 树上的链
// https://www.luogu.com.cn/problem/P1612
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;
using i64=long long;

constexpr int mxn{100005},lg{18};    // n<=1e5, 2^17>1e5

int n;
int p[mxn],w[mxn],c[mxn],dep[mxn],up[lg][mxn];
i64 s[mxn];                          // 根到该点的点权和

i64 above(int x){return x?s[p[x]]:0;}  // x 的父节点的前缀和(根记 0)

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n;
	p[0]=0;
	for(int i=1;i<n;++i)
	{
		cin>>p[i];
		--p[i];
	}
	for(int i=0;i<n;++i)
		cin>>w[i];
	for(int i=0;i<n;++i)
		cin>>c[i];

	dep[0]=0;
	s[0]=w[0];
	up[0][0]=0;
	for(int i=1;i<n;++i)             // p[i]<i, 直接按编号递推
	{
		dep[i]=dep[p[i]]+1;
		s[i]=s[p[i]]+w[i];
		up[0][i]=p[i];
	}
	for(int k=1;k<lg;++k)
		for(int i=0;i<n;++i)
			up[k][i]=up[k-1][up[k-1][i]];

	for(int u=0;u<n;++u)
	{
		i64 thr=s[u]-c[u];           // 需要 父(a) 的前缀和 >= thr
		int a=u;
		for(int k=lg-1;k>=0;--k)     // 越往上 above 越小, 二分式上跳
			if(above(up[k][a])>=thr)
				a=up[k][a];
		cout<<dep[u]-dep[a]+1<<(u+1==n?'\n':' ');
	}
	return 0;
}
```

### 易错点

1. **比较对象搞错**：条件里的前缀和是 $a$ 的**父亲**的前缀和，不是 $a$ 自己的。写成 `s[a]>=thr` 会少算一层，答案整体偏小 $1$。
2. **`s` 用 `int`**：$10^{14}$ 会溢出，必须 `long long`。
3. **根的父亲不设成自己**：`up[0][0]` 若是随机值，倍增跳飞后会越界；设成 $0$ 并让 `above(0)=0` 最省事。
4. **`lg` 取太小**：$n=10^5$ 需要 $\lceil\log_2 10^5\rceil=17$，取 `lg=18` 留一位余量；取 $16$ 时链底部的点跳不到根。
5. **阈值算成 $c_u-s_u$**：符号反了会导致所有点都只能取自己。
6. **输出格式**：$n$ 个数空格分隔，最后一个后面直接换行。
