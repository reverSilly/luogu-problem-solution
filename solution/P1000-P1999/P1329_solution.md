# P1329 数列

> 标签：数学 / 福建省历届夏令营 / Special Judge / O2优化 · 难度：提高/省选-

## 1. 重新读题

**问题重述（简化版）**

从 $a_0=0$ 出发走 $n-1$ 步，每步 $\pm1$（即 $|a_{i}-a_{i+1}|=1$，$a_i$ **可取负数**，题面没有非负限制，且 $s$ 允许为负，故不能加"非负"约束）。把所有 $n$ 个位置的值加起来要求恰为 $s$。**下标说明**：题面是 $a_1=0$ 的 1-based 写法，本文一律换成 0-based（$a_0=0,\dots,a_{n-1}$），只是编号平移、值与项数都不变，和 $s$ 也不变。要输出两样东西：

1. 满足条件的数列**总数对 $2^{64}$ 取模**的值 $t$（第一行）；
2. 满足条件的数列，**最多 $100$ 条**；若真实总数不足 $100$ 就**全部**输出。

**约束与暗示**

| 量 | 范围 |
|---|---|
| 数列长度 $n$ | $1\le n\le 100$ |
| 和 $s$ | $-2^{63}\le s<2^{63}$（有符号 64 位全区间） |
| 方案总数 | $\le 2^{n-1}=2^{99}\approx 6.3\times10^{29}\gg 2^{64}$ |

总数会超过 $2^{64}$，这就是"对 $2^{64}$ 取模"的由来（不是出题人懒得给模数，而是 $2^{64}$ 让 `unsigned long long` 自然溢出即为答案）。`O2优化` 标签暗示状态数不小；`Special Judge` 暗示第二问只验合法不验顺序。

**计数口径（必须先钉死）**

1. 第一行的 $t$ 是**真实总数** $N$ 在 $\mathbb Z/2^{64}\mathbb Z$ 中的代表元，取 $[0,2^{64}-1]$ 按无符号十进制输出，**不是** $\min(N,100)$。
2. 输出的数列必须**两两不同**且逐条合法（$a_0=0$、相邻差 $\pm1$、和恰为 $s$）。
3. **行数 $=\min(N,100)$**。注意 $N\bmod 2^{64}$ 无法反推 $N$ 是否 $\ge100$（真值 $>0$ 而余数 $=0$ 完全可能），所以第二问必须**另算一张饱和表** $\min(N,100)$，不能用 $f$ 表判断"还剩几个"。
4. 本地题面**未附样例**（文件里没有 Sample/样例段），所以第 4 节的验证全部是自造小例的**手算穷举**。

## 2. 思维链（Chain-of-thought）

### 2.1 探索机制 —— 数列被"步序"唯一决定

令 $d_t=a_{t+1}-a_t\in\{+1,-1\}$，$t=0..n-2$。因为 $a_0=0$，有 $a_k=\sum_{t<k}d_t$。

**引理 A（双射）**：$\{$合法数列$\}\;\leftrightarrow\;\{+1,-1\}^{n-1}$，$a\mapsto(d_0,\dots,d_{n-2})$ 是双射。

**证明**：正向即上式；反向由 $a_0=0,\ a_{k+1}=a_k+d_k$ 唯一重建，两个复合都是恒等：数列 → 步序 → 数列，因为 $d_t$ 本来就是相邻差；步序 → 数列 → 步序，因为按递推得到的数列相邻差恰是 $d_t$。故一一对应，方案数 $=2^{n-1}$（不加和约束时）。$\blacksquare$

### 2.2 第一次尝试 —— 三维 DP 直接爆炸

最朴素的想法：$f[i][v][\sigma]$ = 走到第 $i$ 位、当前值 $v$、累计和 $\sigma$ 的方案数。$i\le100$，$v\in[-99,99]$（$199$ 个），$|\sigma|\le W=\frac{n(n-1)}2=4950$（$9901$ 个）。状态数 $101\times199\times9901\approx2.0\times10^{8}$，`u64` 存要 $1.6\,\mathrm{GB}$；滚动掉 $i$ 也要 $199\times9901\times8\approx15.8\,\mathrm{MB}$ 一层，而且**重建方案需要整张表**，滚动数组直接废掉。此路不通 ⇒ 一定有个维度是多余的。

### 2.3 关键发现 —— 和 $s$ 只依赖步序的**加权和**

多余的正是"当前值 $v$"：$v$ 由步序前缀和决定，而 $s$ 也直接由步序决定，中间变量 $a_i$ 根本不必进状态。交换求和次序：

$$s=\sum_{k=0}^{n-1}a_k=\sum_{k=0}^{n-1}\sum_{t=0}^{k-1}d_t=\sum_{t=0}^{n-2}(n-1-t)\,d_t.$$

**推导细节**：固定的 $d_t$ 出现在 $a_k$ 中当且仅当 $t\le k-1$，即 $k\in\{t+1,\dots,n-1\}$，共 $(n-1)-t$ 个 $k$，故 $d_t$ 的系数恰为 $n-1-t$。$\blacksquare$

记**权重** $w=n-1-t\in\{1,2,\dots,n-1\}$：步 $t$ 的权重是 $w$，不同的 $t$ 给出**互不相同**的权重，且 $\{1,\dots,n-1\}$ 每个权重恰好用一次。于是

$$s=\sum_{w=1}^{n-1}w\,\varepsilon_w,\qquad \varepsilon_w\in\{+1,-1\}.$$

### 2.4 归约到子集和

设 $P=\sum_{\varepsilon_w=+1}w$，$Neg=\sum_{\varepsilon_w=-1}w$，$W=\sum_{w=1}^{n-1}w=\frac{n(n-1)}2$。则 $P+Neg=W,\ P-Neg=s$，两式相减得

$$\boxed{P=\frac{W+s}{2}}$$

**引理 B（判据）**：存在满足条件的数列 $\iff |s|\le W$ 且 $s\equiv W\pmod 2$。

**证明**：
- *必要性*：$|s|=|P-Neg|\le P+Neg=W$；又 $+1\equiv-1\equiv1\pmod2$，故 $s=\sum w\varepsilon_w\equiv\sum w=W\pmod2$。
- *充分性*：只需证"$W+s$ 为偶数且 $0\le t_0:=\frac{W+s}{2}\le W$ 时，$\{1,\dots,n-1\}$ 有子集和为 $t_0$"——这正是下面的引理 C；取该子集为 $\{\varepsilon_w=+1\}$，其余 $-1$，即得 $s=2t_0-W$。（$n=1$ 时 $W=0$，判据只剩 $s=0$，唯一解就是单元素数列 $(0)$，对应空子集；引理 C 用于 $n\ge2$ 即 $m=n-1\ge1$。）$\blacksquare$

**引理 C（连续整数的前缀集合是"完备"的）**：对任意 $m\ge1$ 与任意整数 $t\in[0,\frac{m(m+1)}2]$，存在 $T\subseteq\{1,\dots,m\}$ 使 $\sum_{x\in T}x=t$。

**证明（对 $m$ 归纳）**：$m=1$：$t\in\{0,1\}$，取 $T=\varnothing$ 或 $\{1\}$。$m=2$：$\tfrac{m(m+1)}2=3$，$t=0,1,2,3$ 分别取 $\varnothing,\{1\},\{2\},\{1,2\}$。设 $m\ge3$ 且结论对 $m-1$ 成立，记 $W_{m}=\frac{m(m+1)}2$。给定 $t\le W_m$：
- 若 $t\le W_{m-1}$，由归纳假设在 $\{1..m-1\}$ 中取子集即可（不含 $m$）。
- 若 $t>W_{m-1}$：因 $m\ge3$ 有 $W_{m-1}=\frac{(m-1)m}2\ge m$（等价于 $m-1\ge2$），故 $t\ge W_{m-1}+1>m$，即 $t-m\ge1\ge0$；又 $t\le W_m=W_{m-1}+m$ 给出 $t-m\le W_{m-1}$。于是 $t-m\in[0,W_{m-1}]$，用归纳假设取 $T'\subseteq\{1..m-1\}$ 和为 $t-m$，令 $T=T'\cup\{m\}$。$\blacksquare$

> 引理 B 也顺带说明：**无解当且仅当 $|s|>W$ 或奇偶不符**，此时第一行输出 `0` 且**不输出任何数列**。

### 2.5 计数：二维子集和 DP + `u64` 自然溢出

$f[i][t]$ = $\{1,2,\dots,i\}$ 中子集和恰为 $t$ 的个数。

**引理 D（递推正确性）**：$f[0][0]=1,\ f[0][t>0]=0$；$i\ge1$ 时 $f[i][t]=f[i-1][t]+f[i-1][t-i]$（$t<i$ 时第二项视为 $0$）。

**证明**：按"$i$ 是否属于子集"分类，两类互斥且穷尽（子集要么含 $i$ 要么不含）。不含 $i$ 且和为 $t$ 的子集就是 $\{1..i-1\}$ 的和为 $t$ 的子集，$f[i-1][t]$ 个；含 $i$ 的子集与 $\{1..i-1\}$ 的和为 $t-i$ 的子集通过 $T'\mapsto T'\cup\{i\}$ 双射（和恰差 $i$），$f[i-1][t-i]$ 个。$i=0$ 时只有空集，和为 $0$，故 $f[0][0]=1$。由 $(i,t)$ 的字典序递推即覆盖全部状态。$\blacksquare$

答案 $N\bmod 2^{64}=f[n-1][t_0]$。**实现零成本**：`unsigned long long` 的加法在 C++ 里定义为模 $2^{64}$（无符号溢出有定义），不必手写任何取模。

**先猜"$a_i\ge0$（Dyck 型）"——被题面否决**。若真要求非负，就会是卡特兰/$|a_i|$ 那一类"带壁折返"计数（用反射原理可得闭式 $\binom{\cdot}{\cdot}-\binom{\cdot}{\cdot}$）。但题面只写了 $|a_i-a_{i+1}|=1$ 与 $a_1=0$，**没有任何非负约束**，而且 $s$ 的下界是 $-2^{63}$（负和必须能出现，否则给出负区间毫无意义），故不能自作主张加壁。这个判断很重要：加了壁就是另一道题，DP 也做不对。

**再猜"能不能像走格子那样直接给组合数闭式"——也失败**。若所有步的权重都相等（例如只数 $+1$ 的个数），则 $N$ 会是某个 $\binom{n-1}{k}$；但这里权重 $1,2,\dots,n-1$ **互不相同**，"和为 $t_0$ 的子集个数"正是**互异分拆数** $q(t_0)$ 的截断版，其母函数 $\prod_{w=1}^{n-1}(1+y x^{w})$ 中 $y$ 只用来记项数；对固定的 $n$ 它等于 Gauss 二项式系数的系数展开，**没有关于 $t_0$ 的初等闭式**。⇒ 计数只能 DP，这正是 $n\le100,\ W\le4950$ 这组范围想要的量级。

**对称自检**：$s\mapsto-s$ 对应 $t_0\mapsto W-t_0$，而 $T\mapsto\{1..n-1\}\setminus T$ 是"和为 $t_0$ 的子集"到"和为 $W-t_0$ 的子集"的双射，故 $N(n,s)=N(n,-s)$（也就是"整体取相反数"的双射，两回事互相印证）。

### 2.6 输出方案：饱和表 + 带回溯的字典序枚举

用 $f$ 表剪枝不安全（模 $2^{64}$ 后可能假零），所以并行维护

$$cap[i][t]=\min\bigl(\text{真实方案数},\,100\bigr)$$

加法改为饱和加法 $x\mathbin{\dot{+}}y=\min(100,x+y)$。

**引理 E（饱和运算保真）**：对非负整数 $x,y$，$\min(x+y,100)=\min\bigl(\min(x,100)+\min(y,100),\,100\bigr)$。

**证明**：若 $x+y\le100$，则 $x\le100,\ y\le100$，右端 $=\min(x+y,100)=x+y$，等于左端。若 $x+y>100$：左端 $=100$；右端中若 $x,y$ 都 $\le100$ 则两项和为 $x+y>100$，若某个（不妨 $x$）$>100$ 则 $\min(x,100)=100$ 且另一项 $\ge0$，两种情况下右端括号内 $\ge100$，取 $\min$ 后仍为 $100$。故两端都等于 $100$。$\blacksquare$

由引理 E 对引理 D 的分类逐项归纳，得 $cap[i][t]=\min(f^{\text{true}}[i][t],100)$ **恒成立**，特别地 $cap[i][t]=0\iff$ 真实方案数为 $0$。

**枚举**：$dfs(i,r)$ 表示"权重 $i,i-1,\dots,1$ 尚未决定，还需凑出 $r$"。先走"选 $i$"（当 $r\ge i$ 且 $cap[i-1][r-i]>0$），再走"不选 $i$"（当 $cap[i-1][r]>0$）；$i=0$ 且 $r=0$ 时得到一个子集，还原成数列输出，$cnt{++}$，$cnt\ge100$ 立即逐层返回。分支顺序只影响打印顺序，**不影响合法性**（SPJ 逐行校验，不验顺序），所以随意。

**引理 F（不重不漏）**：该 DFS 恰好输出 $\min(N,100)$ 条互不相同的合法数列。

**证明**：DFS 的每个结点唯一对应一个"对权重 $i..n-1$ 的 $\pm1$ 指派"（部分指派），路径到叶子即完整指派；由引理 A 的逆映射，完整指派 ↔ 数列，且不同叶子给出不同指派 ⇒ 不同数列，**不重**。剪枝只拒绝 $cap=0$ 的子树，由引理 E 这些子树真实方案数为 $0$，故任何解的整条路径都不会被剪，**不漏**。终止只有两种：解已取完（此时输出数 $=N<100$）或 $cnt=100$（此时 $N\ge100$）。综上输出数 $=\min(N,100)$。$\blacksquare$

**结点数量（显式上界）**：因只进入含解子树，被访问结点 $\subseteq$ "根到各已输出叶子的路径并集" $\cup$ 最后被 $cnt\ge100$ 截断的那一条下降路径。前者在深度 $n-1$ 的二叉树里 $\le 100(n-1)$ 个，后者 $\le n$ 个，故访问结点 $\le 100(n-1)+n+1<1.02\times10^{4}$，每结点 $O(1)$ 判断；输出 $\le100\times n=10^{4}$ 个整数。与解空间 $2^{99}$ 无关。

还原：$sel[w]=1$ 表示权重 $w$ 取 $+1$，权重 $w$ 对应步 $t=n-1-w$，故 $a_{t+1}=a_t+(sel[n-1-t]?1:-1)$，$a_0=0$。其和为 $2\sum_{sel}w-W=2t_0-W=s$，**天然合法**（无需事后校验，但第 4 节仍手算核对）。

### 2.7 其它视角（同一结论）

- **生成函数**：$\sum_{d}x^{\sum w\varepsilon_w}=\prod_{w=1}^{n-1}(x^{w}+x^{-w})=x^{-W}\prod_{w=1}^{n-1}(1+x^{2w})$，故 $N(n,s)=[x^{W+s}]\prod_w(1+x^{2w})$，即"从 $\{2,4,\dots,2(n-1)\}$ 中选出若干使其和恰为 $W+s$"；两边同除 $2$，就是 $\{1..n-1\}$ 的子集和 $=t_0$ —— 与引理 D 的 DP 完全同构，且奇偶性（$x$ 的指数只能取 $W+2t$ 这一族）、对称性一眼可见（标签"数学"的出处）。
- **3D 滚动 + 记忆化重建**：能过 $n\le100$，但要 $16\,\mathrm{MB}$/层且重建需另存整表，常数与内存都远差于二维，被 2.2 否决。

### 2.8 枚举上界与"是否要求输出方案"的确认（动手前必答）

- **是否要求输出方案**：题面第二条要求"输出满足条件的 $100$ 个数列（不满 $100$ 全部输出）"，输出格式也写了"接下来若干行，每行 $n$ 个整数"。**要方案** ⇒ 计数表不能滚动，必须留整张二维表（$6.3\,\mathrm{MB}$，可接受），并额外留一张饱和表用于剪枝。
- **枚举上界**：解空间 $\le 2^{99}$ 条，**绝不能**暴力枚举全部再筛。合法上界来自两处：①和约束把候选压成"子集和 $=t_0$"，②只要前 $100$ 条。DFS 每步先查 $cap$，只有"子树里确实还有解"才往下走，所以访问结点数 $\le100(n-1)+n+1<1.02\times10^{4}$（见 §2.6"结点数量"），与 $2^{99}$ 无关。
- **第二问的"上界"还要防反向情形**：$N$ 本身可能 $<100$（如 V1 只有 2 条），此时必须**全打印**，不能只打印"看起来够"的条数；$cap$ 表恰好给出 $\min(N,100)$，两分支都剪光即自然结束。
- **第一问的上界**：$N\bmod 2^{64}\in[0,2^{64}-1]$，$2^{64}-1=18446744073709551615$（20 位十进制），必须用无符号类型输出，`long long` 会打印成负数——这是本题最容易写错的一行。

## 3. 模式总结（按实际思考顺序）

- **explore its property** — 数列被步序 $d\in\{\pm1\}^{n-1}$ 唯一决定（引理 A），先换自变量。
- **read the statement literally** — 题面无 $a_i\ge0$、且 $s$ 可为负 ⇒ 不是 Dyck/反射原理那一类，不能自作加壁（否则整题变形）。
- **first naive DP / 撞墙** — (位置,当前值,累计和) 三维 $2\times10^8$ 状态、$1.6\,\mathrm{GB}$，且滚动数组毁掉重建。
- **algebraic collapse（关键恒等式）** — 交换求和次序得 $s=\sum_t(n-1-t)d_t$：权重恰为 $1..n-1$ 各一次，"当前值"维度冗余。
- **reduce to easier problem** — 拆成正负两部分 $\Rightarrow P=\frac{W+s}{2}$，化为"连续整数集合的子集和"计数。
- **existence criterion + full proof** — 归纳证 $\{1..m\}$ 能表出 $[0,W_m]$ 中每个整数（引理 C），得到无解判据 $|s|\le W\wedge s\equiv W\pmod2$。
- **try a closed form, fail** — 权重互异 ⇒ 计数是互异分拆数 / Gauss 二项式系数，无初等闭式，坐实"只能 DP"。
- **classic problem solution** — 子集和 DP $f[i][t]=f[i-1][t]+f[i-1][t-i]$；模 $2^{64}$ 靠 `unsigned long long` 自然溢出（**by design**，不是疏忽），零额外代码。
- **second table for reconstruction（饱和计数）** — $cap=\min(\text{真值},100)$，证明饱和加法保真（引理 E），同时用于"够不够 100 个"与"子树剪枝"；$f$ 表会假零，**绝不能**拿它剪枝。
- **defer reconstruction** — 字典序 DFS 枚举子集，叶子处由 $sel$ 反推 $a$，和自动为 $2t_0-W=s$（引理 F），无需事后校验。
- **口径先于代码** — 动手前钉死：要输出方案 ⇒ 不能滚动；枚举上界来自 $cap$ 剪枝而非解空间大小；第一行是无符号 20 位十进制。
- **sanity via symmetry** — $N(n,s)=N(n,-s)$ 有两个独立证明（补集双射 / 取相反数双射），用来校 DP。

## 4. 真实解法（Real Solution）

### 4.1 符号表

| 符号 | 含义 | 类型 / 初始化 | 记忆点 |
|---|---|---|---|
| `n`,`s` | 长度、目标和 | `int`、`i64`，输入 | $n\le100$，$s\in[-2^{63},2^{63})$ |
| `W` | $\frac{n(n-1)}2$，权重总和 | `int`，$n\le100\Rightarrow W\le4950$ | "$s$ 的最大可能值" |
| `t0` | $\frac{W+s}{2}$，目标子集和 | `int`，判据通过后才计算 | $0\le t_0\le W$ |
| `f[i][t]` | $\{1..i\}$ 中和为 $t$ 的子集数 $\bmod 2^{64}$ | `u64 f[mxn][mxs]`，`f[0][0]=1` | 答案 $=f[n-1][t_0]$ |
| `cap[i][t]` | $\min($真实子集数$,100)$ | `int cap[mxn][mxs]`，`cap[0][0]=1` | 剪枝 + "是否满 100" |
| `sel[w]` | 权重 $w$ 那一步取 $+1$？ | `int`，全局 0 起 | DFS 路径 = 部分子集 |
| `a[k]` | 还原出的数列 | `int a[mxn]`，`a[0]=0` | 值域 $[-99,99]$，和为 $2t_0-W$ |
| `cnt` | 已输出方案数 | `int`，0 | $\ge100$ 即回溯停止 |

> **下标约定**：内部 0-based，$a_0..a_{n-1}$，步 $t=0..n-2$ 的权重为 $n-1-t$。

### 4.2 步骤

1. 读入 $n,s$，算 $W$。
2. **无解判定**：若 $s>W\ \|\ s<-W\ \|\ (W+s)$ 为奇数，直接输出 `0` 并结束（先比范围再做加法，避免 $s=-2^{63}$ 取负溢出）。
3. $t_0=(W+s)/2$。
4. **建两张表**：$i=1..n-1$，$t=0..W$：`f[i][t]=f[i-1][t]+(t>=i?f[i-1][t-i]:0)`（`u64` 溢出即模 $2^{64}$）；`cap[i][t]=min(100, 同式)`。
5. 第一行输出 `f[n-1][t0]`（无符号十进制）。
6. `dfs(n-1,t0)`：$cnt\ge100$ 或 $r<0$ 立即返回；$i=0$ 时若 $r=0$ 就 `out()`（还原 $a$、打印一行、$cnt{++}$）；否则按"选 $i$"→"不选 $i$"两分支递归，分支前查 $cap$ 非零。
7. 结束（$cap$ 已保证行数 $=\min(N,100)$）。

### 4.3 复杂度（显式上界，与数据范围比对）

- DP：$\sum_{i=1}^{n-1}(W+1)\le99\times4951=4.90\times10^{5}$ 次循环、每次 2 张表各一次加法 $\Rightarrow\le10^6$ 次整数运算。
- 枚举：DFS 只进入含解子树，访问结点 $\le100(n-1)+n+1<1.02\times10^{4}$（§2.6 核算）；输出 $\le100\times n=10^{4}$ 个整数。
- 合计时间 $\le1.1\times10^{6}$ 次基本操作 + $10^4$ 次输出，远低于 $10^8$ 量级时限门槛（`O2优化` 标签在此其实不卡）。
- 空间：`f` $105\times5005\times8\approx4.20\,\mathrm{MB}$，`cap` $\approx2.10\,\mathrm{MB}$，共 $\approx6.3\,\mathrm{MB}$，$<128\,\mathrm{MB}$。对比 2.2 的 $1.6\,\mathrm{GB}$，降维是**必需**的。

## 5. 示例代码（C++）

```cpp
// P1329 数列
// s = sum_{w=1}^{n-1} w*eps_w (eps=+-1)  ->  {1..n-1} 的子集和计数, 目标 t0=(W+s)/2
#include<bits/stdc++.h>
using namespace std;
using i64=long long;
using u64=unsigned long long;

constexpr int mxn{105};            // n<=100 +5
constexpr int mxs{5005};           // W=n(n-1)/2<=4950 +5
constexpr int lim{100};            // 第二问要输出的条数

int n;
i64 s;
int W,t0;
u64 f[mxn][mxs];                    // f[i][t]: {1..i} 中和为 t 的子集数(mod 2^64)
int cap[mxn][mxs];                  // 饱和版 min(真值,100), 用于剪枝与"够不够100"
int sel[mxn],a[mxn];                // sel[w]: 权重w那一步取+1; a: 还原的数列
int cnt;                            // 已输出条数

void out()
{
	a[0]=0;
	for(int t=0;t<n-1;++t)          // 步t 的权重 = n-1-t
		a[t+1]=a[t]+(sel[n-1-t]?1:-1);
	for(int i=0;i<n;++i)
	{
		if(i)
			cout<<' ';
		cout<<a[i];
	}
	cout<<'\n';
	++cnt;
}

void dfs(int i,int r)               // 待定权重 i..1, 还需凑 r
{
	if(cnt>=lim||r<0)
		return;
	if(i==0)
	{
		if(r==0)
			out();
		return;
	}
	if(r>=i&&cap[i-1][r-i])         // 分支一: 选权重 i
	{
		sel[i]=1;
		dfs(i-1,r-i);
		sel[i]=0;
	}
	if(cap[i-1][r])                 // 分支二: 不选权重 i
		dfs(i-1,r);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);

	cin>>n>>s;
	W=n*(n-1)/2;
	if(s>W||s<-W||((W+s)&1))        // 先判范围再做加法: s=-2^63 时取负会溢出
	{
		cout<<0<<'\n';
		return 0;
	}
	t0=int((W+s)/2);
	f[0][0]=cap[0][0]=1;
	for(int i=1;i<n;++i)
		for(int t=0;t<=W;++t)
		{
			f[i][t]=f[i-1][t]+(t>=i?f[i-1][t-i]:0);   //u64自然溢出即mod 2^64
			cap[i][t]=min(lim,cap[i-1][t]+(t>=i?cap[i-1][t-i]:0));
		}
	cout<<f[n-1][t0]<<'\n';
	dfs(n-1,t0);
	// cerr<<W<<' '<<t0<<' '<<cnt<<'\n';
	return 0;
}
```

### 代码说明

- **全局静态数组** + `constexpr` 尺寸（上界 +5）：`mxn{105}`、`mxs{5005}`；两张 $105\times5005$ 表约 $6.3\,\mathrm{MB}$。
- **无需 `fill_n`**：这里"不可达"的正确值就是 $0$（子集数个数为 0），全局数组默认 0 恰好符合 $f[0][t>0]=0$ 与 $t<i$ 的缺项，不存在"0 被误当有效值"的移植陷阱；只需显式写 $f[0][0]=cap[0][0]=1$。
- **模 $2^{64}$**：`u64` 加法天然回绕，`cout` 对 `unsigned long long` 输出无符号十进制，正是题面要的剩余类。
- **两分支剪枝用 `cap` 不用 `f`**：$f$ 可能因回绕出现假零，$cap$ 由引理 E 保证 $0\iff$ 真的无解。
- **0-based**：$a[0..n-1]$，步 $t$ 权重 $n-1-t$；`sel` 按权重编号 $1..n-1$。
- **输出**：`'\n'`、无 `endl`；`for` 头内声明循环变量；运算符两侧不加空格、Tab 缩进；`main` 里"读入 → 判无解 → 建表 → 输出"顺序固定。
