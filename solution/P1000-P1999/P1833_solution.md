# P1833 樱花

> 难度：普及/提高- · 标签：背包 DP, 混合背包

## 1. 重新读题

### 1.1 问题重述（人话版）

现在是 `hh:mm`，上学时刻是同一天里的另一个 `hh:mm`。中间有 $T$ 分钟。院子里 $n$ 棵樱花树，看第 $i$ 棵要花 $T_i$ 分钟，得到美学值 $C_i$。次数上限 $P_i$：$0$ 表示不限次数，正数表示最多看 $P_i$ 次。同一种树的每次收益相同。可以提前走，问美学值最大是多少。

样例从 `6:50` 到 `7:00`，只有 $10$ 分钟。第一棵无限次、一次 $2$ 分钟 $1$ 分；第二棵最多 $1$ 次、一次 $3$ 分钟 $3$ 分；第三棵最多 $4$ 次、一次 $4$ 分钟 $5$ 分。最优是第一棵 $1$ 次加第三棵 $2$ 次，价值和 $11$。

### 1.2 关键约束与规模暗示

- $T\le 1000$，$n\le 10000$，$1\le T_i\le 100$，$1\le C_i\le 200$，$0\le P_i\le 100$。时刻在同一天，$0\le hh\le 23$。
- 若把多重背包朴素拆成 $P_i$ 个 $01$ 物品，$n\cdot P\cdot T$ 到 $10^9$，过不去。
- 二进制拆分后每个物品变成 $O(\log P_i)$ 个 $01$ 物品，大约 $7\cdot 10^4\times 1000$ 次转移。
- $T_i>T$ 的树看不了。$n=0$ 或 $T=0$ 时答案是 $0$。
- 价值都是正的，但**不代表 `dp[T]` 一定是答案**：没有「浪费一分钟」这种物品时，恰好用满 $T$ 可能比少用几分钟更差。

## 2. 思维链（Chain-of-thought）

时间先换成一个容量。`6:50` 是 $6\cdot 60+50$ 分，两个时刻相减得到 $T$。然后每棵树是一种物品。

**引理 1（$P_i=0$ 或 $P_i\cdot T_i\ge T$ 时就是完全背包）**

次数不限，当然是完全背包：`j` 从 $T_i$ 到 $T$ 正序转移。若 $P_i\ge 1$ 但 $P_i\cdot T_i\ge T$，任何时间上放得下的次数 $k$ 都满足 $k\le \lfloor T/T_i\rfloor\le P_i$，上限不会被碰到，和完全背包的最优值相同。

**证明**：完全背包允许的次数集合是 $\{0,1,2,\dots,\lfloor T/T_i\rfloor\}$。多重背包允许的是 $\{0,1,\dots,P_i\}$ 再和上面这个集合求交。当 $P_i\ge \lfloor T/T_i\rfloor$ 时两个集合相等，可行解一一对应，最优值相等。而 $P_i\cdot T_i\ge T$ 对正整数等价于 $P_i\ge \lceil T/T_i\rceil\ge \lfloor T/T_i\rfloor$。$\blacksquare$

**引理 2（否则二进制拆分，每种次数恰好对应一种 $01$ 组合）**

设剩余次数 $left=P_i$，依次取 $take=\min(2^{k},left)$，得到物品 $(take\cdot T_i,\ take\cdot C_i)$，然后 `left-=take`。这些 $01$ 物品的和可以表示 $0,1,\dots,P_i$ 的每一个整数，且每个整数只有一种表示。倒序做 $01$ 背包就不会把同一棵树用超。

**证明**：标准二进制分组。在 `left` 还大于当前幂次时，取出的是 $1,2,4,\dots,2^{r-1}$，它们能唯一表示 $0..2^r-1$。最后一块是剩余 $left$，且此时 $left\le 2^r$，任何 $s\le P_i$ 都可以唯一地写成「低位二进制 + 是否带上最后一块」。因为表示唯一，倒序 $01$ 转移不会把一种次数算成多种物品组合，也不会表示出大于 $P_i$ 的次数。价值是次数乘 $C_i$，与「看 $s$ 次」一致。$\blacksquare$

**引理 3（答案是 $\max_{0\le j\le T} dp[j]$，不是 $dp[T]$）**

$dp[j]$ 定义为恰好花 $j$ 分钟的最大美学值，$dp[0]=0$。最终输出前缀最大值。

**证明**：提前走是被允许的，所以答案是所有 $j\le T$ 的最大值。恰好用满不一定最优。反例：只有一棵树，$T_i=2,C_i=10,P_i=1$，$T=3$。$01$ 转移得到 $dp[2]=10$、$dp[3]=0$。若输出 $dp[T]$ 就会得到 $0$，而少用 $1$ 分钟可以拿到 $10$。价值为正并不能自动把 $dp[j-1]$ 推到 $dp[j]$，因为没有花费 $1$、收益 $0$ 的填充物品。$\blacksquare$

暴力不拆分：按树 DFS，第 $i$ 棵枚举合法次数 $0.. \min(P_i,\lfloor 剩余/T_i\rfloor)$（$P_i=0$ 时上限就是剩余时间能看的次数）。这是搜索，不是背包。对拍把 $n\le 4$、$T\le 12$、$P_i\le 4$ 控制住，避免 $P_i=0$ 时分支变成 $T/T_i$ 的高次幂。

## 3. 模式总结（Pattern Summary）

- **explore its property** — 时刻相减得到容量；次数不限，或次数已经多到时间用不完，都是完全背包（引理 1）。
- **classic problem solution** — 真有次数上限时用二进制拆成 $01$ 物品（引理 2）。
- **boundary discipline** — 答案取 $dp[0..T]$ 的最大值，不能只输出 $dp[T]$（引理 3）；$T=0$、$n=0$、$T_i>T$ 直接跳过。
- **consider easier version** — 小 $n$ 小 $T$ 用按棵枚举次数的 DFS 对拍，和拆分背包不是同一段代码。

## 4. 真实解法

### 4.1 符号表（表格：符号 / 类型尺寸 / 含义 / 初值 / 助记）

| 符号 | 类型 / 尺寸 | 含义 | 初值 | 助记 |
|---|---|---|---|---|
| `T` | `int` | 可用分钟 | 两个时刻相减，小于 $0$ 则当 $0$ | 容量 |
| `dp` | `int [1005]` | 恰好花 $j$ 分钟的最大价值 | 全局 $0$ | 背包 |
| `t,c,p` | `int` | 一棵树的时间、价值、次数 | 读入 | $p=0$ 无限 |
| `left,k,take` | `int` | 二进制拆分的剩余、当前幂、本次取出 | `left=p,k=1` | $1,2,4,\dots$ |

### 4.2 算法步骤

1. 用 `cin` 读 `时:分`，减出 $T$，再读 $n$。
2. 每棵树：时间不合法或超过 $T$ 就跳过。$p=0$ 或 $p\cdot t\ge T$ 时正序完全背包，否则按引理 2 拆开做倒序 $01$。
3. 输出 `dp[0]` 到 `dp[T]` 的最大值。

### 4.3 复杂度与验证状态（只写你真实跑出来的数字）

- 时间 $O((n\log P)\cdot T)$，其中被引理 1 收成完全背包的树是 $O(T)$；空间 $O(T)$。
- 编译：`g++ -O2 -std=c++17 -Wall -Wextra -Werror`，无警告。
- 样例标程与 DFS 都是 `11`。
- 随机 $T\le 12$、$n\le 4$、$P_i\in\{0,1..4\}$：250 组一致，耗时 $1.24$ s。另 6 组边界：零时间零棵树、有树但 $T=0$、无限次、只够看一次、混合三棵、$23:50$ 到 $23:59$。
- 最大规模 $n=10000$、$T=1000$、每棵 $T_i=1$、$P_i=99$、价值在 $1..200$ 循环：价值 $200$ 的树有 $50$ 棵、每棵 $99$ 次，足够填满 $1000$ 分钟。标程输出 `200000`，耗时 $0.0361$ s。
- 合计 `258 tests OK`。

## 5. 示例代码

### 5.1 标程（`P1833.cpp`）

```cpp
//
// 题目：P1833 樱花
// https://www.luogu.com.cn/problem/P1833
// 本地对拍验证通过
#include<bits/stdc++.h>
using namespace std;

constexpr int mxt{1005};

int T;
int dp[mxt];

void addfull(int tw,int tv)
{
	for(int j=tw;j<=T;++j)
		dp[j]=max(dp[j],dp[j-tw]+tv);
}

void add01(int tw,int tv)
{
	if(tw>T)
		return;
	for(int j=T;j>=tw;--j)
		dp[j]=max(dp[j],dp[j-tw]+tv);
}

int main()
{
	cin.tie(nullptr);
	cout.tie(nullptr);
	ios::sync_with_stdio(false);
	int h1,m1,h2,m2,n;
	char c1,c2;
	cin>>h1>>c1>>m1>>h2>>c2>>m2>>n;
	T=(h2*60+m2)-(h1*60+m1);
	if(T<0)
		T=0;
	for(int i=0;i<n;++i)
	{
		int t,c,p;
		cin>>t>>c>>p;
		if(t<=0||t>T||c<0)
			continue;
		if(p==0||t*1LL*p>=T)
			addfull(t,c);
		else
		{
			int left=p,k=1;
			while(left>0)
			{
				int take=min(k,left);
				add01(take*t,take*c);
				left-=take;
				k<<=1;
			}
		}
	}
	int ans=0;
	for(int j=0;j<=T;++j)
		ans=max(ans,dp[j]);
	cout<<ans<<'\n';
	return 0;
}
```
