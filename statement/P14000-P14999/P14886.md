# P14886 Left and Right

## Difficulty

普及/提高-

## Tags

数学, 数论

## Problem Description

### Description

Yuki 有两个整数 $l$ 和 $r$。她希望你求解一个巨大的不定方程，可是那实在是太巨大了！因此，Yuki 转而想要考你：有多少个正整数 $x$ 不能被表示为若干个在 $[l, r]$ 内的正整数和？特殊地，如果答案有无穷多个，输出 `infty`。

### Input Format

**本题单个测试点内有多组测试数据**。

第一行，一个整数 $t$（$1 \leq t \leq 10^5$），描述数据组数。对于每组数据：

- 仅一行，两个整数 $l,r$（$1 \leq l \leq r \leq 10^9$）。

### Output Format

对于每组数据：如果答案是有限的，输出仅一行一个整数，表示答案；否则仅输出一个字符串 `infty` 即可。

### Hint

#### 样例解释

对于第一组样例，只有 $x$ 取 $1, 2, 5$ 时不能被表示。

对于第三组样例，显然只要 $7 \nmid x$，就无法被表示。
