### Description

给出长为 $n$ 的序列 $a$ 和 $q$ 次询问，每次给定区间 $[l,r]$，查询 $\left|\left\{x\left | \exists l \le i , j \le r,x=\left\lfloor\dfrac{a_i}{a_j}\right.\right\rfloor\right\}\right|$。

### Input Format

第一行两个正整数 $n,q$。

接下来一行 $n$ 个正整数，第 $i$ 个表示 $a_i$。

接下来 $q$ 行，每行包含两个整数 $l,r$。

### Output Format

对于每个询问输出一行表示答案。

### Hint

所有数据满足 $1 \le n,q,a_i\le 4 \times 10^5$，$1 \le l \le r \le n$。

本题采用捆绑测试，你需要通过一个子任务的所有测试点才能得到该子任务的分数。

|子任务编号|  $n,q\le$ | $a_i\le$  |  特殊性质 |  分值 |
|:---:|:-:|:-:|:-:|:-:|
|  $1$   | $5\times10^2$  | $4\times10^5$  | 无  |  $10$ |
|   $2$  |  $10^5$ | $10^2$  | 无  | $20$  |
|  $3$   |  $10^5$ | $10^5$  | A  | $20$  |
|  $4$   |  $10^5$ | $10^5$  | 无  | $20$  |
|  $5$   |  $4\times10^5$ | $4 \times 10^5$  | 无  | $30$  |

特殊性质 A：保证 $l=1$。
