## Problem Description

### Description

给定两个数字串 $A$ 和 $B$，通过将 $A$ 和 $B$ 进行二路归并得到一个新的数字串 $T$，请找到字典序最小的 $T$。

### Input Format

第一行，一个整数 $n$，表示 $A$ 的长度；

第二行，$n$ 个整数，表示 $A$；

第三行，一个整数 $m$，表示 $B$ 的长度；

第四行，$m$ 个整数，表示 $B$；

### Output Format

一行，$n + m$ 个正整数，表示字典序最小的 $T$。

### Hint

对于 $100\%$ 的数据，$1 \leq n, m \leq 2 \times 10^5$，组成 $A, B$ 的每个数字为不超过 $10^3$ 的正整数。
