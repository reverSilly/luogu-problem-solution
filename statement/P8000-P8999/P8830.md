# P8830 [传智杯 #3 练习赛] 评委打分

## Difficulty

普及-

## Tags

Special Judge, 枚举, 传智杯

## Problem Description

### Description

小 A 参加一个综艺节目。一共有 $n(3 \le n \le 10^6)$ 名评委参与打分（分数范围是 0 到 100 的整数），每个评委依次亮出自己的得分。

为了节目效果，要求从第三个评委开始，每当第 $i$ 个评委给出打分后，立刻计算出出这个选手在前 $i$ 名评委的打分中，去掉一个最高分和一个最低分，剩下 $i-2$ 个评委的平均分，保留不少于 $2$ 位小数。

### Input Format

第一行输入一个整数 $n$，表示评委人数。

第二行输出 $n$ 个整数，表示各个评委的打分。

### Output Format

输出共 $n-2$ 行，每行表示对应的答案。
