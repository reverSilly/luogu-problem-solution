## Difficulty

## Tags

## Problem Description

### Description

考虑一种简单的正则表达式：

只由 `x` `(` `)` `|` 组成的正则表达式。

小明想求出这个正则表达式能接受的最长字符串的长度。  

例如 `((xx|xxx)x|(x|xx))xx` 能接受的最长字符串是： `xxxxxx`，长度是 $6$。


### Input Format

一个由 `x()|` 组成的正则表达式。输入长度不超过 $100$，保证合法。

### Output Format

这个正则表达式能接受的最长字符串的长度。
