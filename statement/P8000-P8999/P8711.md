# P8711 [蓝桥杯 2020 省 B1] 整除序列

## Difficulty

入门

## Tags

模拟, 2020, 蓝桥杯省赛

## Problem Description

### Description

有一个序列，序列的第一个数是 $n$，后面的每个数是前一个数整除 $2$，请输出这个序列中值为正数的项。

### Input Format

输入一行包含一个整数 $n$。

### Output Format

输出一行，包含多个整数，相邻的整数之间用一个空格分隔，表示答案。

### Hint

对于 $80\%$ 的评测用例，$1\le n\le10^9$。

对于所有评测用例，$1\le n\le10^{18}$。

蓝桥杯 2020 第一轮省赛 B 组 F 题。
