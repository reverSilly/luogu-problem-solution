# P8707 [蓝桥杯 2020 省 AB1] 走方格

## Difficulty

普及-

## Tags

动态规划 DP, 2020, 蓝桥杯省赛

## Problem Description

### Description

在平面上有一些二维的点阵。

这些点的编号就像二维数组的编号一样，从上到下依次为第 $1$ 至第 $n$ 行，从左到右依次为第 $1$ 至第 $m$ 列，每一个点可以用行号和列号来表示。

现在有个人站在第 $1$ 行第 $1$ 列，要走到第 $n$ 行第 $m$ 列。只能向右或者向下走。

注意，如果行号和列数都是偶数，不能走入这一格中。

问有多少种方案。

### Input Format

输入一行包含两个整数 $n$，$m$。

### Output Format

输出一个整数，表示答案。

### Hint

$1\le n,m\le30$。

蓝桥杯 2020 第一轮省赛 A 组 G 题（B 组 H 题）。
