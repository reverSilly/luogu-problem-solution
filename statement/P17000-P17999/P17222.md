# P17222 [ICPC 2017 Nanning R] Twice Equation

## Difficulty

提高/省选-

## Tags

数学, 高精度, 2017, 二分, ICPC

## Problem Description

### Description

给定 $L$，求最小的 $n$（$n \ge L$），使得存在一个正整数 $m$ 满足 $2m(m + 1) = n(n + 1)$。


### Input Format

本题包含多组测试数据。多组输入的第一行是一个整数 $T$ ($1 \le T < 1000$)，接下来是 $T$ 行输入。每行包含一个整数 $L$ ($1 \le L < 10^{190}$)。


### Output Format

对于每个给定的 $L$，输出最小的 $n$。若不存在这样的 $n$，则输出 $-1$。
