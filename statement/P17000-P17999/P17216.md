## Problem Description

### Description

欢迎来到 2017 年 ACM-ICPC 亚洲南宁区域赛。

这是一则重磅消息：现在你有机会通过一个游戏与亚洲区总监单独会面。

所有追逐梦想的男孩和女孩必须站成一排。他们按照站位顺序被赋予从 $1$ 开始的编号。

接着，主持人将进行若干轮操作，每轮移除所有站在奇数位置的男孩和女孩。

例如，假设总共有 $n = 8$ 人。初始站位者的编号依次为 $1, 2, 3, 4, 5, 6, 7$ 和 $8$。第一轮过后，剩下的人是 $2, 4, 6$ 和 $8$。第二轮过后，只剩下两人：$4$ 和 $8$。

一直留到最后的那个人就是被选中的幸运儿。

我知道你想成为那个幸运儿，与你的偶像单独会面。给定总人数，你能否找到最佳的排队位置，从而使自己成为那个被选中的人？

### Input Format

第一行包含一个整数 $t$ ($1 \le t \le 1000$)，表示测试数据的组数。

接下来的 $t$ 行，每行包含一个整数 $n$，表示男孩和女孩的总人数，其中 $2 \le n \le 10^{50}$。


### Output Format

输出共 $t$ 行，每行一个整数，表示为了赢得这次机会你应该站的位置。
