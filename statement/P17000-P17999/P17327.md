## Problem Description

### Description

给定一个由 $n$ 个整数构成的序列 $a_i$。

令 $\text{mul}(l, r) = \prod_{i = l}^{r} a_i$，并令 $\text{fac}(l, r)$ 表示 $\text{mul}(l, r)$ 的不同质因子的个数。

请计算 $\sum_{i = 1}^{n}\sum_{j = i}^{n}\text{fac}(i, j)$。

### Input Format

第一行包含一个整数 $n$ ($1 \le n \le 10^6$) —— 序列的长度。

第二行包含 $n$ 个整数 $a_i$ ($1 \le i \le n, 1 \le a_i \le 10^6$) —— 该序列。


### Output Format

输出该式的计算结果。
