# P17326 [ICPC 2018 Nanjing R] Magic Potion

## Difficulty

NOI/NOI+

## Tags

2018, 网络流, 图论建模, ICPC, 南京

## Problem Description

### Description

一座岛上住着 $n$ 位英雄和 $m$ 只怪物。近来怪物变得异常凶残，因此英雄们决定消灭岛上的怪物。然而，第 $i$ 位英雄只能杀死属于集合 $M_i$ 中的恰好一只怪物。军师 Joe 拥有 $k$ 瓶魔法药水，每瓶药水可以强化一位英雄的力量，使其能够多杀死一只怪物。由于药水的效力非常强大，每位英雄最多只能服用一瓶药水。

请你帮助 Joe 找出在采取最优策略的情况下，英雄们最多能杀死多少只怪物。

### Input Format

第一行包含三个整数 $n, m, k$ ($1 \le n, m, k \le 500$) —— 英雄的数量、怪物的数量以及魔法药水的瓶数。

接下来的 $n$ 行，每行描述一位英雄的能力：首先是一个整数 $t_i$，表示集合 $M_i$ 的大小；接下来是 $t_i$ 个整数 $M_{i, j}$ ($1 \le j \le t_i$)，表示第 $i$ 位英雄能够杀死的怪物的编号（下标从 $1$ 开始）。数据满足 $1 \le t_i \le m$，$1 \le M_{i, j} \le m$。

### Output Format

输出一个整数，表示英雄们最多能杀死的怪物数量。
