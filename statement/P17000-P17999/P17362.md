# P17362 [ECNA 2024] Oooh I See

## Difficulty

普及-

## Tags

模拟, 2024, ICPC

## Problem Description

### Description

O'Capten 船长藏起了一批宝藏，并画了一张地图标记埋藏位置。他没有用 `X` 标出地点，而是决定用一个由大写字母 `O` 和数字 `0` 组成的网格来混淆位置。

宝藏位于一个数字 `0` 所在的位置，并且这个 `0` 的八个方向都紧邻字母 `O`：正上、正下、正左、正右、左上、右上、左下和右下。

O'Capten 船长想找回宝藏，却发现自己的地图很难阅读——真让人意外。请帮助他找到宝藏位置；如果地图上没有这样的标记，或者这样的标记不止一个，则按要求惊呼 `Oh no!`。

### Input Format

第一行包含两个整数 $r,c$（$1\le r,c\le 50$），分别表示地图字符网格的行数和列数。行从上到下编号为 $1$ 到 $r$，列从左到右编号为 $1$ 到 $c$。

接下来的 $r$ 行中，每行包含 $c$ 个字符，每个字符为 `O` 或 `0`。

### Output Format

- 如果不存在八个方向均由 `O` 包围的 `0`，输出一行 `Oh no!`；
- 如果这样的 `0` 不止一个，输出一行 `Oh no! N locations`，其中 `N` 替换为位置数量；
- 如果恰好存在一个这样的 `0`，输出两个整数，第一个是它的行号，第二个是它的列号。
