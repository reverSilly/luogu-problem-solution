## Problem Description

### Description

Cliff Valley 地区因包围一连串山谷与丘陵的陡峭垂直悬崖而得名。除了独特地貌，这里还以在风景秀丽的山丘上筑巢的蓝喉山鸥闻名；同样出名的还有雨——大量的雨。上涨的洪水经常迫使蓝喉山鸥放弃巢穴，令它们的生活十分艰难。这种鸟以独特的美丽外形和令人难忘的鸣叫闻名，但在选择筑巢地点方面并不算聪明。

环保人士 Audrey Bond 负责建立山谷洪水模型，评估洪水对海鸥的威胁。为了简化问题，她决定用山谷的二维切片进行建模。她掌握的地形信息有限，只有此前测量得到的一小组高程点可用，其中第一个和最后一个点位于两侧悬崖壁上，如图 1(a) 所示。她还知道这些测量点处没有巢穴，因为测量员靠近蓝喉山鸥的巢时，它们会变得相当难以控制。

给定这些点，Audrey 打算用分段一次插值曲线模拟每个山谷切片；换言之，她会用直线连接每一对相邻测量点，如图 1(b) 所示。

对于给定降雨速率，Audrey 原以为很容易算出洪水需要多久才会到达山谷中任意一个蓝喉山鸥巢穴。结果事实证明，即使只用直线建模也比她想象的困难。你能帮帮这些海鸥吗？

### Input Format

第一行包含三个量 $p,r,m$。其中 $p$（$2\le p\le 50$）是测量点数量；$r$（$0<r\le 3.0$）是每小时以英尺计的降雨速率；$m$（$1\le m\le 100$）是巢穴数量。$r$ 的小数点后至多有两位。

第二行包含 $p$ 对整数 $x_i,y_i$（$0\le x_i\le 5000$，$-1000\le y_i\le 1000$），表示以英尺为单位的 $p$ 个测量点。任意两个测量点的 $x$ 坐标不同，$y$ 坐标也不同；$x$ 坐标按递增顺序给出，且任意连续三个点不共线。第一个和最后一个 $x$ 坐标对应两侧悬崖的位置，可以认为悬崖壁高度高于所有测量点的 $y$ 坐标。

最后一行包含 $m$ 个整数 $n_1,n_2,\ldots,n_m$，满足 $x_1<n_1<n_2<\cdots<n_m<x_p$，表示 $m$ 个巢穴的 $x$ 坐标。各巢穴在插值曲线上的对应 $y$ 坐标均不等于任何测量点的 $y$ 坐标。


### Output Format

输出 $m$ 行，依次表示洪水到达各巢穴所需的小时数。假设降雨从 $t=0$ 开始，并始终以速率 $r$ 持续。

若答案的绝对误差或相对误差不超过 $10^{-5}$，则认为正确。
