# P17095 [ICPC 2017 Qingdao R] Enclosure of Land and Water

## Difficulty

Level 8

## Tags

计算几何, 2017, ICPC, 青岛, 平面几何

## Problem Description

### Description

推罗国王穆顿有一位聪慧美丽的公主，名叫狄多。狄多在王国中过着快乐自由的生活，但好景不长，她的丈夫被她的兄弟——塞浦路斯国王杀害。随后，狄多逃往非洲西海岸，希望在那里定居。于是，她拿出自己的珠宝、玉石和黄金，向当地酋长贾尔巴斯购买土地和水域。贾尔巴斯说：“现在你可以去任何你想去的地方。你移动所围成的曲线内部的土地和水域，就是你能得到的。你必须在日落之前完成围圈。”

海岸是一条直线，起点到海岸的距离为 $d$ 单位距离。如下图所示。

:::align{center}
![](https://cdn.luogu.com.cn/upload/image_hosting/xnrr6a1s.png)
:::

在陆地（或水域）上移动的速度为 $v$（或 $w$）单位距离每单位时间，陆地（或水域）每单位面积的价值为 $V$（或 $W$）单位价值。日落前剩余的时间为 $t$ 单位时间。狄多必须在日落之前回到起点。她将获得她移动曲线所围出的陆地和水域。她希望最大化所围陆地与水域的价值总和。

你的任务是找出最佳的移动曲线，并计算狄多能获得的最大价值总和。

### Input Format

第一行是测试用例的数量，最多不超过 100。对于每个测试用例，给出 6 个实数 $d$、$v$、$w$、$V$、$W$ 和 $t$，它们的取值范围均在 0.1 到 10 之间。

### Output Format

对于每个测试用例，输出狄多能获得的最大价值总和，结果精确到小数点后 3 位。
