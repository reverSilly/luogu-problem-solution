# P17388 [PNW 2025] Server Room

## Difficulty

NOI/NOI+

## Tags

2025, ICPC

## Problem Description

### Description

Audrey 是米哈游的系统管理员！她的职责是管理服务器机房，保证自己最喜欢的电子游戏《崩坏：星穹铁道》持续运行。

Audrey 的服务器机房是一个矩形房间，被划分成若干行和若干列。房间中的某些区域安装了服务器，其中一些服务器已经开启。

Audrey 急需开启更多服务器。然而机房通风很差：如果两台处于同一行且列相邻、或者处于同一列且行相邻的服务器同时开启，机房就会过热，所有服务器都会停机。Audrey 不能关闭已经开启的服务器。

请计算在不使机房过热的前提下，Audrey 最多能从当前关闭的服务器中再开启多少台；并计算达到这一最大数量的不同开启方案数。

### Input Format

第一行包含两个正整数 $r,c$，满足 $1\le r\cdot c\le400$。

接下来 $r$ 行，每行包含一个长度为 $c$、仅由 `0`、`1`、`2` 组成的字符串。其中：

- `0` 表示该区域没有服务器；
- `1` 表示该区域有一台关闭的服务器；
- `2` 表示该区域有一台已经开启的服务器。

保证初始状态下，不存在两台相邻服务器同时开启的情况。

### Output Format

令 $s$ 表示 Audrey 最多能够新开启的服务器数量，$w$ 表示达到这一数量的方案数。输出两个整数：$s$，以及 $w$ 除以 $998244353$ 的余数。
