### Description

有 $n$ 个房间，编号 $1 \sim n$。你初始位于房间 $1$，目标是房间 $n$。每次移动可以选择：

- 行走：从 $i$ 移动到 $i+1$，代价 $c$。
- 冲刺：从 $i$ 移动到 $j$（必须满足 $j \ge i+2$），代价 $(j-i)^2$。

冲刺之后的下一次移动必须是行走，且最多只能冲刺 $k$ 次。

求从 $1$ 到 $n$ 的最小总代价。

### Input Format

第一行输入 $t$，表示 $t$ 组数据。

接下来每一行输入三个整数 $n, c, k$。

### Output Format

对于每个询问输出一行，每行包含一个整数，表示最小总代价。
