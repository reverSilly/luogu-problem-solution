# P10982 Connected Graph

## Difficulty

省选/NOI-

## Tags

组合数学, 容斥原理

## Problem Description

### Background

本题是 P4841 [集训队作业2013] 城市规划 的弱化版，去除了原题中的多项式部分。

### Description

求 $n$ 个结点的有标号无向连通图个数。

### Input Format

输入一个正整数 $n$。

### Output Format

输出答案对 $1004535809$ ( $479 \times 2 ^{21} + 1$ ) 取模的值。

### Hint

数据保证 $1\leq n \leq 1000$。
