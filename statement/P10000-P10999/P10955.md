# P10955 正整数拆分

## Difficulty

普及-

## Tags

动态规划 DP, 背包 DP

## Problem Description

### Description

给定一个正整数 $N$，要求把 $N$ 拆分成若干个正整数相加的形式，参与加法运算的数可以重复。

**注意**:

  * 拆分方案不考虑顺序；
  * 至少拆分成 $2$ 个数的和。

求拆分的方案数 $\bmod 2147483648$ 的结果。

### Input Format

一个正整数 $N$。

### Output Format

输出一个整数，表示结果。

### Hint

$1 \le N \le 4000$
