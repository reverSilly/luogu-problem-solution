## Problem Description

### Background

小 Z 要卷 whk。

### Description

小 Z 一共要卷 $n$ 门科目，第 $i$ 门科目他有且只有 $a_i$ 道题。有无数天时间，每天小 Z 可以做无数道题。

如果小 Z 认为一天是有趣的，仅当他在这一天**至少**做了 $t$ 门科目的题。

小 Z 想知道最多有多少天是有趣的。

### Input Format

第一行，$2$ 个正整数 $n,t$。

接下来一行，有 $n$ 个整数，分别 $a_1,a_2,a_3,\dots,a_{n-1},a_n$。


### Output Format

一个整数，输出小 Z 认为有趣的天数的最大值。
