# P10471 最大异或对 The XOR Largest Pair

## Difficulty

普及/提高-

## Tags

字典树 Trie

## Problem Description

### Description

给定 $N$ 个整数 $A_1,A_2, \cdots, A_N$ 中选出两个进行异或计算，得到的结果最大是多少？

### Input Format

第一行一个整数 $N$，第二行 $N$ 个整数 $A_1,A_2, \cdots, A_N$。

### Output Format

一个整数表示答案。

### Hint

对于所有测试数据，$2 \le N \le 10^5$，保证 $0\le A_i<2^{31}$。
