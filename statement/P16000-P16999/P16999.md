# P16999 [NWERC 2019] 平均排名 / Average Rank

## Difficulty

提高/省选-

## Tags

## Problem Description

### Background

译自 [Northwestern Europe Regional Contest (NWERC) 2019](http://2019.nwerc.eu)。


### Description

National Weekly Escape Room Challenge（NWERC）是一项在埃因霍温长期举办的比赛。每周都会推出一个新的密室，任何在第一次尝试中完成该密室的人都会得到 $1$ 分。

每周结束时，参赛者按照当前累计分数从高到低排名。若多人分数相同，则他们并列同一名。换句话说，一名参赛者的排名等于“分数严格大于他的人数”再加 $1$。

:::align{center}

![](https://cdn.luogu.com.cn/upload/image_hosting/15aufvlw.png)

:::

一共有 $n$ 名参赛者，比赛已经持续了 $w$ 周。对于每一周，给出这一周获得 $1$ 分的参赛者列表。你的任务是计算每名参赛者在这 $w$ 周比赛中的平均排名。

上图展示了样例 $3$ 中分数变化过程的示意。

### Input Format

输入包含：

- 第一行包含两个整数 $n$ 和 $w$ ($1 \le n,w \le 3\cdot 10^5$)，分别表示参赛者数量和周数。参赛者编号为 $1$ 到 $n$。
- 接下来 $w$ 行，每行对应一周。每行先包含一个整数 $k$ ($0 \le k \le n$)，随后是 $k$ 个互不相同的整数 $c_1,\ldots,c_k$ ($1 \le c_i \le n$)，表示这些参赛者在该周各获得了 $1$ 分。

保证总共发出的分数不超过 $1$ 百万。

### Output Format

输出 $n$ 行，第 $i$ 行输出第 $i$ 名参赛者在 $w$ 周比赛中的平均排名。

你的答案的绝对误差或相对误差不超过 $10^{-6}$ 即可。

### Hint

【数据规模与约定】

- $1 \le n,w \le 3\cdot 10^5$。
- 每周获胜人数 $0 \le k \le n$。
- 参赛者编号满足 $1 \le c_i \le n$，且同一周内互不相同。
- 总共发出的分数不超过 $10^6$。
- 输出平均排名时，允许绝对误差或相对误差不超过 $10^{-6}$。
