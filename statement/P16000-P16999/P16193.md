## Problem Description

### Description

众所周知，现代显卡绘制图像时都是靠三角形拼出来的。POBEDA-2014 显卡也不落后，它只能显示四种方向的等腰直角三角形，具体形状见下图。显卡不能改变这些三角形的朝向。


![](https://cdn.luogu.com.cn/upload/image_hosting/ub3oluze.png)

每个三角形的直角边长都是 $1$ 厘米。显卡每个时钟周期最多能显示 $a_i$ 个第 $i$ 种类型的三角形。

你的任务是算出显卡在一个时钟周期内，能绘制出的最大正方形边长。注意，这个正方形的边必须和显示器的边平行。

请写程序解决这个问题。

### Input Format

输入文件第一行包含四个用空格分隔的整数：$a_1, a_2, a_3, a_4\ (0 \le a_i \le 10^{18})$。注意，输入数值可能超过 $32$ 位整数范围。

下面是第一个样例的示意图，供参考。

对于 $50$ 分的数据，有 $a_1,a_2,a_3,a_4\le100\,000$。
