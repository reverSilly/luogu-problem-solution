### Description

给定一个 $n$ 个点 $m$ 条边的有向图 $G$，每条边有边权，保证整张图弱连通（即将图中的所有有向边替换为无向边，所得到的图是连通的），不存在自环、重边。

给出一个长度为 $n$ 的数组 $\{b_1,b_2,\cdots,b_n\}$。

有 $q$ 次询问，每次询问给定一个整数 $x$。我们将要你解决一个问题。

定义一个变量 $y$ 初始为 $0$，我们允许你进行如下操作任意次（可以是 $0$ 次）：

- 选择一条边 $e\in G$，设这条边是从 $u$ 连向 $v$，边权为 $w$ 的一条边。
- 将 $b_u\gets b_u-1,b_v\gets b_v+1,y\gets y+w$，或将 $b_u\gets b_u+1,b_v\gets b_v-1,y\gets y-w$。

我们希望进行若干次操作后，**最终**满足 $\max_{i=1}^n|b_i|\le x$（「最终」意味着你可以在操作过程中不满足这个限制，但是进行完所有操作后必须要满足这个限制）。

对于每一次询问，你需要求出如果能满足上述要求，$y$ 最大能是多少。如果没有一种操作方案能够使得最终局面满足要求，输出 `-1`；如果 $y$ 能是无穷大，输出 `inf`；否则输出 $y$ 的最大值。

每次询问都不会对 $b$ 产生任何实质性修改，也就是每次询问的 $b$ 都是相同的。

### Input Format

**本题有多组测试数据。**

输入的第一行包含一个整数 $T\ (1 \leq T \leq 10)$，表示测试数据的组数。

接下来包含 $T$ 组数据，每组数据的格式如下：

第一行输入三个整数 $n,m,q\ (3 \leq n \leq 10^5;3 \leq m \leq 2\times 10^5;0 \leq q \leq 10^5)$ 代表图的节点数、边数和询问次数。

保证 $T$ 组测试数据的 $n$ 的和不超过 $4\times 10^5$，$m$ 的和不超过 $8\times 10^5$，$q$ 的和不超过 $4\times 10^5$。

第二行输入 $n$ 个整数 $b_1,b_2,\cdots,b_n\ (-10^5 \leq b_i \leq 10^5)$ 表示图的初始点权。

接下来 $m$ 行，每行三个整数 $u,v,w\ (1 \leq u,v\leq n;-10^5\leq w\leq 10^5)$，表示 $G$ 中一条从 $u$ 指向 $v$，边权为 $w$ 的有向边。保证 $G$ 是一个弱连通图，不存在自环、重边。

接下来 $q$ 行，每行描述一个询问。每行输入一个整数 $x\ (0 \leq x \leq 10^5)$，表示询问的参数。

### Output Format

对于每组测试数据，输出 $q$ 行，每行输出一个整数或字符串 `inf`，表示对应询问中 $y$ 最大能是多少。

- 如果没有一种操作方案能够使得最终局面满足要求，输出一行 `-1`；
- 如果 $y$ 能是无穷大，输出一行 `inf`；
- 否则输出一行 $y$ 的最大值。

### Hint

**样例 1 解释**

选择 $3\to 1$ 这条边，令 $b_3\gets b_3-1$，$b_1\gets b_1+1$，$y$ 则为 $2$。可以证明不存在 $y$ 更大的方案。
