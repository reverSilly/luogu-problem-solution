# P16197 [ROIR 2014 Day 2] Lights 红绿灯

## Difficulty

普及-

## Tags

数学, 2014, Special Judge, ROIR（俄罗斯）

## Problem Description

### Description

在电脑夏令营的场地里铺设了一条电动车行驶路线。由于电动车能直达 ICT 中心，学生帕霍姆决定试试这条路。沿着路线，电动车以恒定速度依次通过了两个绿灯的红绿灯。已知这两个红绿灯相距 $x$ 米，并且它们的灯光切换完全同步：绿灯亮 $a$ 分钟，然后红灯亮 $b$ 分钟，接着又切换回绿灯，循环往复。红绿灯中间没有黄灯。电动车的速度不会超过 $1000$ 米/分钟。电动车可以在红绿灯切换瞬间通过路口。

到达 ICT 中心后，帕霍姆好奇自己在两红绿灯之间的最大恒定速度是多少。

请你写个程序，帮帕霍姆算出这个最大速度。

### Input Format

输入文件第一行包含三个整数：$a$、$b$ 和 $x$，满足 $1 \le a \le 100$，$1 \le b \le 100$，$1 \le x \le 100\,000$。



### Output Format

输出文件只需包含一个数字——电动车在两红绿灯之间可能达到的最大速度。答案与正确值的误差不能超过 $10^{-9}$。



### Hint

### 评分
对于 $50$ 分的数据，答案为整数。
