入门

## Tags

## Problem Description

### Description

Isyana 得到了当地主题公园连续 $N$ 天的游客数量。第 $i$ 天的游客数量为 $V_i$。如果某一天同时满足以下两个条件，则称这一天为**破纪录日**：

- 当天的游客数量严格大于之前每一天的游客数量。
- 要么是最后一天，要么当天的游客数量严格大于下一天的游客数量。

注意，第一天也可能是破纪录日！

请帮助 Isyana 找出破纪录日的数量。

### Input Format

输入的第一行给出测试用例的数量 $T$。接下来有 $T$ 个测试用例。每个测试用例的第一行包含一个整数 $N$。第二行包含 $N$ 个整数，其中第 $i$ 个整数为 $V_i$。

### Output Format

对于每个测试用例，输出一行，格式为 `Case #x: y`，其中 $x$ 是测试用例编号（从 $1$ 开始），$y$ 是破纪录日的数量。

### Hint

在样例 #1 中，以下用粗体并加下划线的数字表示破纪录日：1 **2** 0 **7** 2 0 2 0。

在样例 #2 中，只有最后一天是破纪录日。

在样例 #3 中，第一天、第三天和第六天是破纪录日。

在样例 #4 中，没有破纪录日。

### 限制条件

$1 \le T \le 100$。  

$0 \le V_i \le 2 \times 10^5$。

**测试集 1**

$1 \le N \le 1000$。

**测试集 2**

最多 $10$ 个测试用例满足 $1 \le N \le 2 \times 10^5$。  

其余测试用例满足 $1 \le N \le 1000$。
