# P16948 「LAOI-18」Two Tree Triples

## Difficulty

Level 8

## Tags

网络流, Special Judge, O2优化, 构造

## Problem Description

### Background

Cybher 喜欢两棵树的问题和三元组的问题。

### Description

有两棵包含 $3n$ 个节点的树 $T_1$ 和 $T_2$，每棵树的节点均编号为 $1,2,\dots,3n$。

你需要帮助 Cybher 将全体节点恰好划分成 $n$ 个三元组，记第 $i$ 个三元组为 $(u_i,v_i,w_i)$。要求满足：

- 所有 $3n$ 个节点在 $n$ 个三元组中各出现恰好一次。
- 对于树 $T_1$，考虑每个三元组中节点 $u_i$ 与 $v_i$ 之间的唯一简单路径。这 $n$ 条路径两两之间没有公共边。
- 对于树 $T_2$，考虑每个三元组中节点 $v_i$ 与 $w_i$ 之间的唯一简单路径。这 $n$ 条路径两两之间没有公共边。

请你判断是否存在这样的划分，如果存在，输出任意一组解。

### Input Format

**本题包含多组测试数据。**

第一行一个整数 $T\ (1 \le T \le 10)$，表示测试数据组数。

对于每组数据，第一行输入一个正整数 $n\ (1 \le n \le 10^5)$。注意此时树的总节点数为 $3n$。

保证 $T$ 组测试数据的 $n$ 的和不超过 $10^5$。

接下来 $3n-1$ 行，每行两个整数 $x_i, y_i$，表示树 $T_1$ 中的一条边，连接节点 $x_i$ 与 $y_i$。

再接下来 $3n-1$ 行，每行两个整数 $x'_i, y'_i$，表示树 $T_2$ 中的一条边，连接节点 $x'_i$ 与 $y'_i$。

输入保证给出的边构成两棵树，且节点编号均为 $1$ 到 $3n$ 的整数。

### Output Format

对于每组数据，如果存在满足条件的划分，第一行输出 `YES`（大小写不敏感，例如 `YES`、`Yes`、`yes` 等均视为正确），接下来 $n$ 行每行输出三个整数 $u_i, v_i, w_i$，表示一组三元组。输出顺序任意，每个节点必须恰好出现一次。

如果不存在，仅输出一行 `NO`（同样大小写不敏感）。
