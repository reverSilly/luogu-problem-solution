# P16856 [GKS 2021 #E] Increasing Sequence Card Game

## Difficulty

提高/省选-

## Tags

2021, Special Judge, 期望, 调和级数, Google Kick Start

## Problem Description

### Description

你正在玩一个单人卡牌游戏。

有 $N$ 张牌，第 $i$ 张牌上写着整数 $i$。

你首先将 $N$ 张牌随机洗牌，并叠成一堆。取出堆顶的牌放入手中。然后重复以下过程，直到牌堆为空：

1. 查看牌堆顶的牌。
2. 如果这张牌上的数字大于你上一次拿走的牌上的数字，则取走这张牌。
3. 否则，弃掉这张牌。

游戏的得分是最终手中牌的数量。给定牌的张数 $N$，求游戏的期望得分。

### Input Format

输入的第一行包含测试用例的数量 $T$。接下来有 $T$ 行，每行包含一个整数 $N$，表示牌堆中牌的张数。


### Output Format

对于每个测试用例，输出一行，格式为 `Case #x: y`，其中 $x$ 是测试用例编号（从 $1$ 开始），$y$ 是游戏结束时的期望得分。

若 $y$ 与正确答案的绝对误差或相对误差在 $10^{-6}$ 以内，则认为正确。

### Hint

### 限制条件

$1 \le T \le 100$。

**测试集 1**

$1 \le N \le 10$。

**测试集 2**

$1 \le N \le 10^6$。

**测试集 3**

$1 \le N \le 10^{18}$。
