## Problem Description

### Description

有一个数字 $n$ 和一个参数 $k$，你需要对这个数字进行 $m$ 次操作，对于每次操作，你可以做以下两种操作中的一种：

- 将这个数字加上 $1$，即 $n \gets n + 1$。
- 将这个数字对 $k$ 取模，即 $n \gets n \bmod k$。

求在 $m$ 次操作后 $n$ 的最小值。

### Input Format

本题共有 $T$ 组测试数据，第一行输入一行一个正整数 $T$ 表示数据组数。

对于每组测试数据：

- 第一行输入三个非负整数 $n,m,k$。

### Output Format

对于每组测试数据：

- 输出一行一个非负整数表示你的答案。

### Hint

**【样例解释】**

该样例共有 $7$ 组测试数据。

对于第一组测试数据：
- 第一次操作将 $n \gets n + 1$，此时 $n = 2$。
- 第二次操作将 $n \gets n \bmod k$，此时 $n = 0$。

对于第二组测试数据：
- 第一次操作将 $n \gets n \bmod k$，此时 $n = 3$。

可以证明这两个样例的操作方案可以均使得 $n$ 最终变为最小值。

**【数据范围】**

对于 $100\%$ 的数据，$1 \le T \le 2 \times 10^5$，$0 \le n,m,k < 2^{30}$，$k \ge 1$。
