## Problem Description

### Background

Kipfel 和 Zn 在玩一个名叫“树上的树”的游戏。

### Description

游戏的具体流程如下：
1. Zn 给 Kipfel 一共 $k$ 颗**无标号有根有序树** $\bm{^\dagger}$，分别为 $X_1 \sim X_k$，这 $k$ 颗无标号有根有序树的第 $i$ 颗由 $m_i$ 个节点组成，且拥有一个属性 $C_i$。

2. Kipfel 造出一颗有 $n$ 个节点的无标号有根有序树 $Y$，并将 $Y$ 再交给 Zn。
3. Zn 从 $Y$ 中选择一个打上标记的节点集合 $S$，使得 $S$ 中任意两个节点互不相同（$S$ 可以为空集）。游戏结束。

Kipfel 是只笨猫，所以它会从所有可能的无标号有根有序树 $Y$ 中**等概率地**选出一棵作为第二步的结果。同理，Zn 也会从第三步中所有可能选择的 $S$ 中**等概率地**选出一个作为第三步的结果。

规定 Zn 在第三步中选择的 $S$ 是“好的方案”，当且仅当对于 $Y$ 中每个子树 $T$，满足下列的**至少一个**条件：
- $T$ 不与 $X_1\sim X_k$ 中任何一颗无标号有根有序树同构。
- 若 $T$ 与 $X_i$ 同构，则需满足 $|V_T\cap S|\ge C_i$（即 $T$ 中至少有 $C_i$ 个节点被标记）。其中 $V_T$ 表示 $T$ 的节点集合。

Zn 已经完成了游戏的第一步，但是游戏的第二步和第三步仍未进行。你需要求出第三步中 Zn 选择了 $\bm{|S|}$ **最小的**“好的方案”的概率，**并将答案对 $\bm{998244353}$ 取模**。注意“$|S|$ 最小”的条件是对于第二步选择的 $Y$ 而言的，不是对于所有可能的 $Y$ 而言的。

::::info[$\dagger$ 无标号有根有序树]
- 无标号有根有序树：**无标号的**、每个节点的每个儿子间**有顺序**的**有根**树。
- 令 $|T|$ 表示无标号有根有序树 $T$ 的节点个数；$son_T$ 表示无标号有根有序树 $T$ 的**根的儿子个数**；$\operatorname{Sub}(T,i)$ 表示以无标号有根有序树 $T$ 的根的第 $i$ 个儿子为根的子树。
- 判断两颗无标号有根有序树 $A,B$ 是否同构的方法为：
  - 若 $|A|=|B|=1$，则 $A$ 与 $B$ 同构。
  - 否则，若 $son_A=son_B$ 且对于任何 $1 \le i \le son_A$ 都满足 $\operatorname{Sub}(A,i)$ 与 $\operatorname{Sub}(B,i)$ 同构，则 $A$ 与 $B$ 同构。
::::

**为了方便描述，我们在输入格式、样例解释中给每个节点赋予了一个编号，并钦定编号为 $\bm{1}$ 的节点为根。实际无标号有根有序树的节点是没有编号的。**

### Input Format

第一行包含两个非负整数 $n,k$，分别表示 $Y$ 的节点数、Zn 给出的无标号有根有序树的个数。

接下来对于 Zn 给出的每一颗无标号有根有序树 $X_i$：
- 第一行包含两个正整数 $m_i,C_i$。
- 接下来的 $m_i$ 行：
	- 假设当前行是这 $m_i$ 行中的第 $j$ 行。首先输入一个非负整数 $s_j$ 表示无标号有根有序树 $X_i$ 中节点 $j$ 的儿子个数。
   - 紧接着在同一行输入 $s_j$ 个正整数，其中第 $x$ 个正整数表示节点 $j$ 的第 $x$ 个儿子的编号。

### Output Format

第一行包含一个非负整数，表示第三步中 Zn 选择了 $\bm{|S|}$ **最小的**“好的方案”的概率。**注意将答案对 $\bm{998244353}$ 取模**。
