# P16522 自破碎的天空坠落

## Difficulty

提高/省选-

## Tags

## Problem Description

### Background

![](https://cdn.luogu.com.cn/upload/image_hosting/e0z1tro4.png)
>自破碎的天空坠落，   
>沉睡在静默的星河。   
>自无梦的长夜亮起，  
>绽放在终竟的明天。

### Description

有 $n$ 条直线在一个平面直角坐标系中，第 $i$ 条直线表示为 $y=k_ix+b_i$。你需要处理 $Q$ 次询问。每次询问的形式为 `x y`，含义是求有多少条直线过点 $(x,y)$。

### Input Format

第一行一个整数 $n$ 表示直线的条数。

接下来 $n$ 行，每行两个整数 $k_i$ 和 $b_i$，表示一条直线。

接下来一行一个整数 $Q$，表示询问次数。

最后 $Q$ 行，每行两个整数 $x,y$，表示一次询问。

### Output Format

共 $Q$ 行，对于每个询问，依次输出相应的答案。
