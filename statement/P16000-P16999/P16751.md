# P16751 [GKS 2020 #B] Bike Tour

入门

## Tags

## Problem Description

### Description

Li 计划在瑞士山区进行一场自行车旅行。他的旅行包括 $N$ 个检查点，按照他将访问的顺序编号为 $1$ 到 $N$。第 $i$ 个检查点的高度为 $H_i$。

如果满足以下条件，则一个检查点被称为**山峰**：

*   它不是第 $1$ 个或第 $N$ 个检查点，并且
*   该检查点的高度**严格大于**它前一个和后一个检查点的高度。

请帮助 Li 找出山峰的数量。


### Input Format

输入的第一行给出测试用例的数量 $T$。接下来有 $T$ 个测试用例。每个测试用例的第一行包含一个整数 $N$。第二行包含 $N$ 个整数，其中第 $i$ 个整数为 $H_i$。

### Output Format

对于每个测试用例，输出一行，格式为 `Case #x: y`，其中 $x$ 是测试用例编号（从 $1$ 开始），$y$ 是 Li 自行车旅行中山峰的数量。

### Hint

*   在样例 #1 中，第 2 个检查点是山峰。
*   在样例 #2 中，没有山峰。
*   在样例 #3 中，第 2 个和第 4 个检查点是山峰。
*   在样例 #4 中，没有山峰。

### 限制条件

$1 \le T \le 100$。

$1 \le H_i \le 100$。

**测试集 1**

$3 \le N \le 5$。

**测试集 2**

$3 \le N \le 100$。
