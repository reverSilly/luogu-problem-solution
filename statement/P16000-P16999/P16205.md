### Description

对于每一个 $0\le k\le27$，你需要在坐标 $x,y,z\in[0,n+1]$ 的立方体上放置尽可能少的雷，使得对于任意 $x,y,z\in[1,n]$，若 $(x,y,z)$ 不是雷，则与它相邻的 $26$ 个位置上恰有 $k$ 个雷。

这里称两个坐标“相邻”，若其每个坐标的差都不超过 $1$。**保证 $\bm{n=55}$。**

在本题中，你需要直接用一份代码依次输出包含 $k=0$ 至 $k=27$ 的构造。详见【输出格式】。

### Input Format

输入一个 $n$，保证 $n=55$。

### Output Format

依次输出 $k=0,\cdots,27$ 的构造。

对于每个 $k$，输出 $(n+2)$ 个 $(n+2)$ 行 $(n+2)$ 列的方阵，自上而下表示你的构造中雷的排布，`*` 是雷，`.` 是空地。不要输出多余的换行。

### Hint

### 样例解释

样例输出中所有位置都是雷，是一种合法输出。

根据评分细则，$p_i$ 为空地个数，即为 $0$。

总得分为 $0$。 

### 评分细则

定义 $p_i(0\le i\le27)$ 为：

- 若你 $k=i$ 的构造合法，则 $p_i$ 为空地个数。

- 若你 $k=i$ 的构造不合法，则 $p_i=0$。

你的得分为 $\sum_{i=0}^{27}p_i$。

如果你不会某个 $k$ 的构造，你也要按照格式输出任意一种排布。

你需要在本题中获得总共不低于 $2970000$ 分，才能被视作通过本题。

赛场上的最高分为 $2938095$，目前各点最高分之和为 $2978155$。
