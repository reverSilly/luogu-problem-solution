# P16781 ⌈Xzy OI R1 T3⌋ 穿穿表

## Difficulty

省选/NOI-

## Tags

## Problem Description

### Description

呲牙球有一个放置在平面直角坐标系第四象限的杨辉三角，三角内 $\binom{i}{j}$ 被放置于坐标 $(j,-i)$ 上。如图所示：

![](https://cdn.luogu.com.cn/upload/image_hosting/e7yxfbcn.png)

呲牙球有两个非负整数 $k,b$，他想要用直线 $y=kx-b$ 穿过这个杨辉三角，请你告诉他这条线上所有的数之和对 $1145141$ 取模后的结果。$1145141$ 是一个质数，呲牙球不知道为什么他要使用它。

### Input Format

一行两个非负整数 $k,b$。

### Output Format

一行一个非负整数表示答案。
