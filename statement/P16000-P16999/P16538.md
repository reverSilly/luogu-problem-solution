## Problem Description

### Background

来自 2026 清华大学学生程序设计竞赛暨高校邀请赛（THUPC2026）决赛。

### Description

至此，THUPC 十周年庆典即将结束。小 T 和小 S 站在主会场的出口处，为每一位满载而归的同学们准备了精美的留念礼品。

十年的岁月沉淀了无数闪光的瞬间，而今晚的相聚同样令人难忘。经历了这一系列智力与欢乐的碰撞，大家心中想必都有了自己最钟意的活动。为此，小 T 和小 S 将根据大家的不同选择，分别赠上对应主题的十周年定制纪念品。

请你从本次庆典的所有活动项目中，挑选出你最喜欢的一个，从而获取这份专属的纪念品吧！

### Input Format

本题没有输入。

### Output Format

输出一行一个仅包含英文字母（不区分大小写）的字符串，表示你最喜欢的活动项目。
