### Description

给定正整数 $n$，请构造一个仅包含 $0$ 和 $1$ 的序列 $A$ 使得 $\displaystyle \sum_{i=2}^{n-1}[\text{mex}\{A_{i-1},A_i,A_{i+1}\}=0]=\sum_{i=2}^{n-1}[\text{mex}\{A_{i-1},A_i,A_{i+1}\}=1]=\sum_{i=2}^{n-1}[\text{mex}\{A_{i-1},A_i,A_{i+1}\}=2]$ 成立。你需要最小化这个序列 $1$ 的个数，无解输出 $\texttt{-1}$。

### Input Format

**本题有多组测试数据。**

第一行一个正整数 $T\ (1\le T \le 10^4)$，表示数据组数。

接下来 $T$ 行，每行一个正整数 $n\ (3\le  n \le 10^6)$，表示序列长度。

保证所有测试数据的 $n$ 的总和不超过 $10^6$。

### Output Format

共 $T$ 行，每行 $n$ 个非负整数表示序列 $A$，若无解则输出 $\texttt{-1}$。

### Hint

**样例 1 解释**

对于 $n=8$，可以构造序列 $0\ 0\ 0\ 0\ 1\ 1\ 1\ 1$。其中 $\text{mex}$ 值为 $0,1,2$ 的长度为 $3$ 的区间各有 $2$ 个，满足条件。且可以证明 $1$ 的个数 $4$ 是最小的。

**样例 2 解释**

对于 $n=4$，可以证明不存在满足条件的序列，故输出 `-1`。

**样例 3 解释**

对于 $n=5$，也不存在满足条件的序列，故输出 `-1`。
