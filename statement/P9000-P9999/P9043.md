# P9043 [PA 2021] Zbalansowane słowa

## Difficulty

提高/省选-

## Tags

2021, PA（波兰）

## Problem Description

### Description

定义一个字符串 $s$ 是好的，当且仅当它包含的所有字符出现次数相同。

好的字符串例如：`mama`、`aabbcbcccbaa`。

不好的字符串例如：`ovo`。

给定一个字符串 $s$，求出 $s$ 好的**子串**数量。

### Input Format

一行，一个字符串 $s$。

### Output Format

一行，一个整数，表示所求的值。

### Hint

对于 $100\%$ 的数据，$1 \leq |s| \leq 3 \times 10^5$，$s$ 中只含 `a`、`b`、`c` 三个小写字母。
