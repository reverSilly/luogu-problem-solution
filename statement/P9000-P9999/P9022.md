# P9022 [CCC 2021 J3] Secret Instructions

## Difficulty

入门

## Tags

模拟, 2021, ﻿基础算法, CCC（加拿大）

## Problem Description

### Description

多组数据。

对于每组数据读入 $5$ 个数字字符。

- 如果前两个之和为奇数，输出 `left`；
- 如果前两个之和为非零偶数，输出 `right`；
- 如果前两个之和为零，输出 `left` 或 `right` 取决于上组数据。

然后输出一个空格与后三个数字字符。

### Input Format

多组数据。

每行 $5$ 个数字字符。

读入直到 `99999`。

### Output Format

每行一个字符串与 $3$ 个数字字符，空格隔开。

### Hint

读入的第三个字符不会为 $0$。

第一组数据不会以 $00$ 开头。
