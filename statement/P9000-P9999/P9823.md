## Problem Description

### Description

给定 $1 \le k \le 10^7$，我们规定满足以下性质的 $1\sim n$（其中 $ 1\le n \le 10^7$） 的排列为“好排列”：

$$\forall k<i \le n,~a_i > \min\{a_{i-k},a_{i-k+1},...,a_{i-1}\}$$

求好排列的个数。对 $998244353$ 取模。

### Input Format

一行，两个整数 $n,k$。

### Output Format

一行，为好排列的个数对 $998244353$ 取模的值。
