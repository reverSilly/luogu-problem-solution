# P9502 『MGOI』Simple Round I | A. 魔法数字

## Difficulty

入门

## Tags

数学, 洛谷原创, O2优化, 枚举

## Problem Description

### Background

> 目标越坚定的魔法士，越幸运。——殿堂魔法士 S

### Description

初级魔法士小 M 的魔法数字是 $2$。

给定一个正整数 $n$，小 M 需要找到最大的 **偶数** $m$，使得 $2^m<n$。

请你帮帮他。

### Input Format

一行一个正整数 $n$。

### Output Format

一行一个 **偶数** $m$，表示答案。

### Hint

**【数据范围】**

对于前 $20\%$ 的数据，$n = 2$。

对于前 $60\%$ 的数据，$n$ 为 $2$ 的幂次。

对于 $100\%$ 的数据，$2 \le n \le 10^9$。
