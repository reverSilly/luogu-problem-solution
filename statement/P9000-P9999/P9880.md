## Problem Description

### Description

共 $T(1 \leq T \leq 10^6)$ 组数据，每组给出一个数 $n(1 \leq n \leq 10^6)$ 和 $n$ 个数 $a_1,a_2,...,a_n(-10^9 \leq a_i \leq 10^9)$，求有多少个二元组 $(a_i,a_j)$ 满足 $a_ia_j<a_i+a_j$。

### Input Format

第一行为一个数 $T$。

接下来 $T$ 组数据，每组数据第一行为一个数 $n$，第二行为 $n$ 个数 $a_1,a_2,...,a_n$。

保证所有测试用例的 $n$ 之和不超过 $ 10^6 $。

### Output Format

$T$ 行，为满足 $a_ia_j<a_i+a_j$ 的二元组 $(a_i,a_j)$ 的组数。
