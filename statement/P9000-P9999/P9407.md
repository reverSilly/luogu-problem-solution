### Description

给你一个数字 $n$，求 $l,r$，使 $[l,r]$ 区间内的所有质数之和等于 $n$。

如果有多解，任意一组均可；无解输出 `NIE`。

### Input Format

一行一个正整数 $n$。

### Output Format

如果有解，一行两个正整数 $l,r$，**其中要求** $1 \le l \le r \le n$，表示你的答案。

如果无解，输出 `NIE`。

### Hint

对于所有数据，$1\leq n\leq 10^{11}$。
