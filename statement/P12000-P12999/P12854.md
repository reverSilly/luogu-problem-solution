## Problem Description

### Description

Edward 需要测量两个水泵的抽水速率。为此，他使用这两个水泵向水箱中注水，并记录在特定时间内注入水箱的水量。

他发现第一个水泵在 $b$ 秒内抽了 $a$ 升水，第二个水泵在 $d$ 秒内抽了 $c$ 升水。他还发现当两个水泵同时工作时，它们一起在 $d$ 秒内抽了 $b$ 升水。

不幸的是，Edward 的记录被水浸湿了，导致他无法恢复 $a$ 和 $c$ 的具体数值。但他记得这两个值都是正整数。现在他想知道有多少种选择 $a$ 和 $c$ 的方式符合他的测量结果。


### Input Format

第一行包含一个整数 $n$（$1 \le n \le 1000$）——测试用例的数量。

接下来的 $n$ 行，每行包含两个整数 $b$ 和 $d$（$1 \le b, d \le 10^9$）。


### Output Format

对于每个测试用例，输出一个整数——表示选择 $a$ 和 $c$ 的方式数量。每个答案单独占一行。


### Hint

在第一个测试用例中，可能的取值组合为 $a=3$, $c=7$；$a=6$, $c=5$；$a=9$, $c=3$；以及 $a=12$, $c=1$。
