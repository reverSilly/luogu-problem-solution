# P1409 骰子

## Difficulty

省选/NOI-

## Tags

动态规划 DP, 数学, 递推, 福建省历届夏令营

## Problem Description

### Description

$n$ 个人排成一排，你排在第 $m$ 个。

每轮队首的人投一次骰子。

- 若掷到 $1$，则队首的人获胜。
- 若掷到 $2,4,6$，则队首的人排到队尾。
- 若掷到 $3,5$，则队首的人出队。

若队列中仅剩一人，则该人获胜，求你获胜的概率。

### Input Format

一行两个整数 $n,m$。


### Output Format

一个实数表示获胜概率，精确到小数点后 $9$ 位。


### Hint

- 对于 $30\%$ 的数据，$0<m\le n\le 10$。
- 对于 $100\%$ 的数据，$0<m\le n\le 1000$。
