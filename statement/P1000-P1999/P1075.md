# P1075 [NOIP 2012 普及组] 质因数分解

## Difficulty

普及-

## Tags

数学, 2012, NOIP 普及组, 素数判断

## Problem Description

### Description

已知正整数 $n$ 是两个不同的质数的乘积，试求出两者中较大的那个质数。

### Input Format

输入一个正整数 $n$。

### Output Format

输出一个正整数 $p$，即较大的那个质数。

### Hint

$1 \le n\le 2\times 10^9$。
