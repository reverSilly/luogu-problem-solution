# P1888 三角函数

## Difficulty

入门

## Tags

数学, 排序, 最大公约数 gcd

## Problem Description

### Description

输入一组勾股数 $a,b,c(a\neq b\neq c)$，用分数格式输出其较小锐角的正弦值（要求约分）。

### Input Format

一行，包含三个正整数，即勾股数 $a,b,c$（无大小顺序）。

### Output Format

一行，包含一个分数，即较小锐角的正弦值。

### Hint

对于 $100\%$ 的数据，$a,b,c$ 为正整数且 $\in [1,10^9]$。
