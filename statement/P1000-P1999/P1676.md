$\small\color{white}/35^{\text{th}}\text{Problem by AtC}.$

### Description

求与原点距离不超过 $n(1\leq n\leq 10^{12})$ 的整点个数。

### Input Format

一行一个正整数 $n$。

### Output Format

一行一个正整数，即答案。注意它可能大于 $2^{64}$。

### Hint

### 样例 $1$ 解释

符合条件的 $5$ 个点是 $(0,0),(1,0),(0,1),(0,-1),(-1,0)$。
