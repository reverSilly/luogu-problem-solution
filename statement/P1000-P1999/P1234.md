# P1234 小 A 的口头禅

## Difficulty

普及-

## Tags

搜索

## Problem Description

### Description

小 A 最近有了一个口头禅 “呵呵”，于是他给出了一个矩形，让你求出里面有几个 “$\verb!hehe!$”（方向可以是向上、向下、向左、向右的直线）。


### Input Format

第一行两个数 $n, m$，表示这个矩形的大小。

接下来 $n$ 行，每行 $m$ 个字符，表示这个矩形。


### Output Format

一行一个数，表示有几个 “$\verb!hehe!$”。


### Hint

$1 \leq n,m \leq1000$。
