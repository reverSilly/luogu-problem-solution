# P1480 A/B Problem（高精度除法Ⅰ）

## Difficulty

普及-

## Tags

模拟, 高精度

## Problem Description

### Description

输入两个整数 $a,b$，输出它们的商。


### Input Format

两行，第一行是被除数，第二行是除数。


### Output Format

一行，商的整数部分。


### Hint

$0\le a\le 10^{5000}$，$1\le b\le 10^9$。
