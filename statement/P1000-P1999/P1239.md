# P1239 计数器

## Difficulty

提高/省选-

## Tags

动态规划 DP, 递推, 深度优先搜索 DFS, 数位 DP

## Problem Description

### Description

一本书的页数为 $n$，页码从 $1$ 开始编起，请你求出全部页码中，用了多少个 $0,1,2\cdots 9$。每个页码不含前导 $0$，如 $n=1234$ 时第 $5$ 页不是 $0005$，只是 $5$。


### Input Format

一个正整数 $n$，表示总的页码。


### Output Format

输出共十行，其中第 $k$ 行为数字 $k-1$ 的个数。


### Hint

对于 $100\%$ 数据，满足 $1\le n\le 10^9$。
