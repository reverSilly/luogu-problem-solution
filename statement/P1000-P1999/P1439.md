# P1439 两个排列的最长公共子序列

## Difficulty

提高/省选-

## Tags

动态规划 DP, 二分, 树状数组

## Problem Description

### Description

给出 $1,2,\ldots,n$ 的两个排列 $P_1$ 和 $P_2$，求它们的最长公共子序列。

### Input Format

第一行是一个数 $n$。

接下来两行，每行为 $n$ 个数，为自然数 $1,2,\ldots,n$ 的一个排列。

### Output Format

一个数，即最长公共子序列的长度。

### Hint

- 对于 $50\%$ 的数据， $n \le 10^3$；
- 对于 $100\%$ 的数据， $n \le 10^5$。
