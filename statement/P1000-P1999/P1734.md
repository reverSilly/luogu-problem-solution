# P1734 最大约数和

## Difficulty

普及-

## Tags

动态规划 DP, 背包 DP

## Problem Description

### Description

选取和不超过 $S$ 的若干个不同的正整数，使得所有数的约数（不含它本身）之和最大。

### Input Format

输入一个正整数 $S$。

### Output Format

输出最大的约数之和。


### Hint

**【样例说明】**

取数字 $4$ 和 $6$，可以得到最大值 $(1+2)+(1+2+3)=9$。

**【数据规模】**

对于 $100 \%$ 的数据，$1 \le S \le 1000$。
