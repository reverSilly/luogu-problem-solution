# P1932 A+B  A-B  A*B  A/B A%B Problem

## Difficulty

提高/省选-

## Tags

数学, 高精度, 洛谷原创

## Problem Description

### Background

这个题目很新颖吧！！！

### Description

求 $A$ 与 $B$ 的和、差、积、商、余。

**由于数据有修改，减法运算结果可能带负号。**

### Input Format

两行，每行一个数，为参与运算的两个数。

### Output Format

五行，每行一个数，分别为 $A$ 与 $B$ 的和、差、积、商、余。

### Hint

$|A|,|B| \leq 2 \times 10^4$，这里表示数字的位数而不是绝对值。

$ A,B > 0 $。
