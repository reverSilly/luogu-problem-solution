# P1049 [NOIP 2001 普及组] 装箱问题

## Difficulty

普及-

## Tags

动态规划 DP, 2001, 递归, NOIP 普及组, 深度优先搜索 DFS, 背包 DP

## Problem Description

### Description

有一个箱子容量为 $V$，同时有 $n$ 个物品，每个物品有一个体积。


现在从 $n$ 个物品中，任取若干个装入箱内（也可以不取），使箱子的剩余空间最小。输出这个最小值。

### Input Format

第一行共一个整数 $V$，表示箱子容量。

第二行共一个整数 $n$，表示物品总数。

接下来 $n$ 行，每行有一个正整数，表示第 $i$ 个物品的体积。

### Output Format

- 共一行一个整数，表示箱子最小剩余空间。


### Hint

对于 $100\%$ 数据，满足 $0<n \le 30$，$1 \le V \le 20000$。
