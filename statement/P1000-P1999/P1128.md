# P1128 [HNOI2001] 求正整数

## Difficulty

省选/NOI-

## Tags

动态规划 DP, 数学, 高精度, 2001, 各省省选, 湖南, 深度优先搜索 DFS

## Problem Description

### Description

对于任意输入的正整数 $n$，请求出具有 $n$ 个不同因子的最小正整数 $m$。

例如：$n=4$，则 $m=6$，因为 $6$ 有 $4$ 个不同整数因子 $1,2,3,6$；而且是最小的有 $4$ 个因子的整数。

### Input Format

输入有且仅有一行一个整数，代表 $n$。


### Output Format

输出一行一个整数，代表符合条件的最小正整数 $m$。

### Hint

#### 数据规模与约定

对于 $100\%$ 的数据，保证 $1 \leq n \leq 5 \times 10^4$。
