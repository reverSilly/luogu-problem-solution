# P1441 砝码称重

## Difficulty

提高/省选-

## Tags

动态规划 DP, 搜索, 福建省历届夏令营, 随机化, 状压 DP, bitset

## Problem Description

### Description

现有 $n$ 个砝码，重量分别为 $a_i$，在去掉 $m$ 个砝码后，问最多能称量出多少不同的重量（不包括 $0$）。

请注意，砝码只能放在其中一边。

### Input Format

第 $1$ 行为有两个整数 $n$ 和 $m$，用空格分隔。

第 $2$ 行有 $n$ 个正整数 $a_1, a_2, a_3,\ldots , a_n$，表示每个砝码的重量。

### Output Format

仅包括 $1$ 个整数，为最多能称量出的重量数量。

### Hint

【样例说明】

在去掉一个重量为 $2$ 的砝码后，能称量出 $1, 2, 3$ 共 $3$ 种重量。


【数据规模】

对于 $20\%$ 的数据，$m=0$。

对于 $50\%$ 的数据，$0 \leq m\leq 1$。

对于 $50\%$ 的数据，$1 \leq n\leq 10$。

对于 $100\%$ 的数据，$1 \leq n\leq 20$， $0 \leq m\leq 4$，$m < n$，$a_i\leq 100$。
