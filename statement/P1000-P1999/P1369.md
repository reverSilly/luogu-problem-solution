# P1369 矩形

## Difficulty

普及/提高-

## Tags

贪心, 前缀和

## Problem Description

### Description

给出平面上的 $n$ 个点，请找出一个边与坐标轴平行的矩形，使得它的边界上有尽量多的点。


### Input Format

第一行一个整数 $n$，为平面内点的个数。

第 $2\sim n+1$ 行每行两个整数，为点的横、纵坐标。


### Output Format

只有一个数，为所取矩形边界上能包含尽量多的点的个数。


### Hint

### 数据范围及约定

- 对于 $40\%$ 的数据，$1\le n\le 30$；
- 对于 $100\%$ 的数据，$1\le n\le 300$，各点的横、纵坐标在 $[1,100]$ 范围内。
