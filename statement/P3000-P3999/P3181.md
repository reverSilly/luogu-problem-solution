# P3181 [HAOI2016] 找相同字符

## Difficulty

NOI+

## Tags

字符串, 2016, 河南, 并查集, 各省省选, 后缀自动机 SAM, 后缀数组 SA, 单调栈

## Problem Description

### Description

给定两个字符串，求出在两个字符串中各取出一个子串使得这两个子串相同的方案数。两个方案不同当且仅当这两个子串中至少有一个位置不同。

### Input Format

共两行，每行两个字符串 $s_1,s_2$，长度分别为 $n_1,n_2$。

### Output Format

输出一个整数表示答案。

### Hint

$1\le n_1,n_2\le 2\times 10^5$，字符串中只有小写字母。
