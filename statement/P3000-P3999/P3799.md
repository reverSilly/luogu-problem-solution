# P3799 小 Y 拼木棒

## Difficulty

普及/提高-

## Tags

洛谷原创, 枚举, 组合数学, 洛谷比赛

## Problem Description

### Background

上道题中，小 Y 斩了一地的木棒，现在她想要将木棒拼起来。

### Description

有 $n$ 根木棒，现在从中选 $4$ 根，想要组成一个正三角形，问有几种选法？

答案对 $10^9+7$ 取模。

### Input Format

第一行一个整数 $n$。

第二行往下 $n$ 行，每行 $1$ 个整数，第 $i$ 个整数 $a_i$ 代表第 $i$ 根木棒的长度。

### Output Format

一行一个整数代表答案。


### Hint

#### 数据规模与约定

- 对于 $30\%$ 的数据，保证 $n \le 5 \times 10^3$。
- 对于 $100\%$ 的数据，保证 $1 \leq n \le 10^5$，$1 \le a_i \le 5 \times 10^3$。
