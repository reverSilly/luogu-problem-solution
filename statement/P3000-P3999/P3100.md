# P3100 [USACO14JAN] Building a Ski Course G

## Difficulty

省选/NOI-

## Tags

递推, 2014, USACO, 枚举

## Problem Description

### Description

FJ 的滑雪场是一个 $M\times N$ 的矩阵，初始时矩阵是空的。FJ 有一张 $M\times N$ 矩阵的设计图，每一格是 `R`（粗糙）或 `S`（平整）中的一种，代表他期望滑雪场的最终状态。例如：

```
RSRSSS
RSRSSS
RSRSSS
```

FJ 每次操作可以将滑雪场上一块 $B\times B$（$B\le M,B\le N$）的正方形全部变成 `R` 或 `S` 中的一种，每次操作可以覆盖前面的结果。要使得通过若干次操作后可以将滑雪场由空矩阵变成 FJ 所期望的状态，求 $B$ 的最大值。

### Input Format

第一行输入两个整数 $M$ 和 $N$。

第二到 $M+1$ 行，每行输入 $N$ 个字符 `R` 或 `S`，代表滑雪场的最终状态。

### Output Format

一行一个整数，代表 $B$ 的最大值。

### Hint

#### 样例解释

FJ 可以先将第 $1$ 到 $3$ 列变成 `R`，再将第 $2$ 到 $4$ 列变成 `S`，再将 $3$ 到 $5$ 列变成 `R`，最后将 $4$ 到 $6$ 列变成 `S`。

#### 数据范围

对于 $100\%$ 的数据，$1\le N,M\le 100$。
