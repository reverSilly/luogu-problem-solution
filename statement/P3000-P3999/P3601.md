# P3601 签到题

## Difficulty

省选/NOI-

## Tags

数学, 洛谷原创, O2优化, 洛谷月赛, 欧拉函数

## Problem Description

### Background

这是一道签到题！

**建议做题之前仔细阅读数据范围！**

### Description

我们定义一个函数：$\operatorname{qiandao}(x)$ 为小于等于 $x$ 的数中，与 $x$ **不互质**的数的个数。

这题作为签到题，给出 $l$ 和 $r$，求出：

$$\left(\sum_{i=l}^r \operatorname{qiandao}(i) \right) \bmod 666623333$$

### Input Format

一行两个整数，$l$、$r$。

### Output Format

一行一个整数表示答案。

### Hint

- 对于 $30\%$ 的数据，$l,r\leq 10^3$。
- 对于 $60\%$ 的数据，$l,r\leq 10^7$。
- 对于 $100\%$ 的数据，$1 \leq l \leq r \leq 10^{12}$，$r-l \leq 10^6$。
