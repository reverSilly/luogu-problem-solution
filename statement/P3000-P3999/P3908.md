# P3908 数列之异或

## Difficulty

普及/提高-

## Tags

数学, 递归, 进制

## Problem Description

### Description

求 $1 \oplus 2 \oplus\cdots\oplus N$ 的值。

$A \oplus B$ 即为 $A,B$ 按位异或后的值。

### Input Format

一行一个整数 $N$。

### Output Format

一个整数，表示所求的值。

### Hint

- 对于 $50\%$ 的数据，$1 \le N \le 10^6$；

- 对于 $100\%$ 的数据，$1 \le N \le 10^{18}$。
