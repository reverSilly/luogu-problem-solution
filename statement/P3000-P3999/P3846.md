## Problem Description

### Description

给定一个质数 $p$，以及一个整数 $b$，一个整数 $n$，现在要求你计算一个最小的非负整数 $l$，满足 $b^l \equiv n \pmod p$。

### Input Format

仅一行，有 $3$ 个整数，依次代表 $p, b, n$。

### Output Format

仅一行，如果有 $l$ 满足该要求，输出最小的 $l$，否则输出 `no solution`。

### Hint

#### 数据规模与约定

- 对于所有的测试点，保证 $2\le b < p<2^{31}$，$1\leq n<p$。
