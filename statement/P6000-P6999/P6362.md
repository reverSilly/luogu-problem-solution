# P6362 平面欧几里得最小生成树

## Difficulty

Level 8

## Tags

计算几何, Special Judge, O2优化, 分治, 生成树, 凸包

## Problem Description

### Background

2025/06/13 @[ケロシ](https://www.luogu.com.cn/user/511639) 加入十组 hack 数据，位于 Subtask 1。

### Description

平面上有 $n$ 个点，第 $i$ 个点坐标为 $(x_i, y_i)$。连接 $i, j$ 两点的边权为 $\sqrt{(x_i - x_j) ^ 2 + (y_i - y_j) ^ 2}$。求最小生成树的边权之和。

### Input Format

第一行一个整数 $n$。

接下来 $n$ 行，每行输入两个整数 $x_i, y_i$。

### Output Format

输出一行一个实数，表示答案。

当你的答案与标准输出的绝对误差或相对误差在 $10^{-6}$  内时，就会被视为正确。
