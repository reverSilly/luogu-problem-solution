# P6875 [COCI 2013/2014 #6] KRUŽNICE

## Difficulty

省选/NOI-

## Tags

2013, COCI（克罗地亚）

## Problem Description

### Description

现在有 $N$ 个以 $x$ 轴为中心的互不相交的圆，但圆周可以接触。请问这些圆把平面分成多少块？

### Input Format

输入的第一行包含整数 $N$，即圆的数目。

下列n行中的每一个包含两个整数 $x_i$ 和 $r_i$， $x_i$ 表示第 $i$ 个圆的 $x$ 坐标，$r_i$ 表示第 $i$ 个圆的半径。

输入中的所有圆保证都是唯一的。

### Output Format

输出这些圆把平面分成多少区域。
