# P6316 [COCI 2006/2007 #3] TROJKE

## Difficulty

普及/提高-

## Tags

2006, 枚举, COCI（克罗地亚）

## Problem Description

### Description

给定一个 $n\times n$ 的方格纸，每个格子可能有一个大写字母，也可能为空。不会有同一个字母在方格纸中出现两次。

你在方格纸中找到三个字母，使得存在一条线穿过这三个字母所在的格子的中心。

请你求出方格纸上还有多少组这样的三个字母。

### Input Format

输入第一行为一个整数 $n$，表示方格纸的边长。

接下来的 $n$ 行，每行 $n$ 个字符，每个字符可能为一个大写字母或 `.`（空）。

### Output Format

输出一行一个整数，表示方格纸上符合要求的三个字母的组数。

### Hint

#### 样例 1 解释

注意在第一个样例中，任意三个字母都处在同一条线上，这时的答案相当于 $C^{3}_{4}=4$，即 $(A,B,C)$，$(A,B,D)$，$(A,C,D)$，$(B,C,D)$ 四组。

----

#### 数据规模与约定

对于 $100\%$ 的数据，保证 $3\le n\le 100$，不会有同一个字母在方格纸中出现两次。
