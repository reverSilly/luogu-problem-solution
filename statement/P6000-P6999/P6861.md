## Problem Description

### Description

求两个整数 $a,b$ $(1\le a,b\le n)$，使 $(a\ \mathrm{or}\ b)+(a\ \mathrm{xor}\ b)$ 最大。只需输出这个最大值。

### Input Format

一个正整数 $n$。

### Output Format

一个正整数，为答案。

### Hint

样例说明：$(5\ \mathrm{or}\ 2)+(5\ \mathrm{xor}\ 2)=14$。

对于 $80\%$ 的数据，$n\le 1000$。

对于 $100\%$ 的数据，$2\le n\le 10^{18}$。
