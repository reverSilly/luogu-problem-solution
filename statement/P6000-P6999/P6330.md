# P6330 [COCI 2007/2008 #1]  CETVRTA

## Difficulty

入门

## Tags

2007, COCI（克罗地亚）

## Problem Description

### Description

给出坐标系中一个矩形的三个顶点的坐标，请你确定第四个顶点的坐标并输出。

保证矩形的边与坐标轴平行。

### Input Format

共 $3$ 行，每行两个 $1\sim 1000$ 之间的整数（含端点），表示这个矩形一个顶点的坐标。

### Output Format

输出一行两个整数，表示第四个顶点的坐标。
