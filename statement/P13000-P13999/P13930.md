# P13930 [蓝桥杯 2022 省 Java B] 字符统计

## Difficulty

普及-

## Tags

2022, 排序, 蓝桥杯省赛

## Problem Description

### Description

给定一个只包含大写字母的字符串 $S$，请你输出其中出现次数最多的字母。

如果有多个字母均出现了最多次，按字母表顺序依次输出所有这些字母。

### Input Format

一个只包含大写字母的字符串 $S$.

### Output Format

若干个大写字母，代表答案。

### Hint

对于 $100\%$ 的评测用例，$1 \leq |S| \leq 10^6$.
