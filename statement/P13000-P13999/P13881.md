# P13881 [蓝桥杯 2023 省 Java/Python A] 阶乘的和

## Difficulty

提高/省选-

## Tags

2023, 数论, 蓝桥杯省赛

## Problem Description

### Description

给定 $n$ 个数 $A_i$，问能满足 $m!$ 为 $\sum \limits_{i=1}^{n}(A_i!)$ 的因数的最大的 $m$ 是多少。其中 $m!$ 表示 $m$ 的阶乘，即 $1 \times 2 \times 3 \times \cdots \times m$。


### Input Format

输入的第一行包含一个整数 $n$。

第二行包含 $n$ 个整数，分别表示 $A_i$，相邻整数之间使用一个空格分隔。


### Output Format

输出一行包含一个整数表示答案。

### Hint

**【评测用例规模与约定】**

对于 $40\%$ 的评测用例，$n \leq 5000$；

对于所有评测用例，$1 \leq n \leq 10^5$，$1 \leq A_i \leq 10^9$。
