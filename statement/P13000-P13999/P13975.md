## Problem Description

### Description

Katya 知道从家到地铁站骑滑板车需要 $t$ 秒。

公司 $\texttt{W}$ 的滑板车费用计算方式如下：首先确定本次行程所用的完整分钟数，然后将该分钟数乘以 60，按每秒 $c_1$ 分的费率计算费用。

公司 $\texttt{Y}$ 的滑板车费用计算方式不同：首先按每秒 $c_2$ 分的费率计算本次行程的费用，然后将该金额向上取整到最接近的整欧元。

请帮助 Katya 计算，她选择这两家公司中哪一家，能以最低的费用骑滑板车到地铁站。

注意：1 欧元等于 100 分。

### Input Format

第一行包含三个整数 $t$、$c_1$ 和 $c_2$，分别表示骑行时间（秒）、公司 $\texttt{W}$ 的每秒费用（分）、公司 $\texttt{Y}$ 的每秒费用（分）$(1 \le t \le 1000, 10 \le c_1, c_2 \le 20)$。

### Output Format

输出骑行所需的最小费用（单位：分）。
