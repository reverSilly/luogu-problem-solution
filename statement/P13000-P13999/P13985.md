# P13985 [PO Final 2023] 通胀 / Inflation

## Difficulty

入门

## Tags

2023, Special Judge, PO（瑞典）

## Problem Description

### Background

1s, 1G, inflation3

### Description


经济的很大一部分受到当前通胀的影响，即社会中商品价格上涨的速度。例如，通胀水平会影响瑞典央行（Riksbank）如何设定其政策利率，而这又会影响股市、房贷利率等。通胀以百分比计量，表示与去年同一时间相比，价格上涨了多少。

在瑞典，瑞典统计局（SCB）负责测量社会中的通胀率。它们通过在每个月中测量通胀率 **每天如何变化**，然后将全月的每日涨幅相加来计算每月的通胀率。你希望利用这些数据，在 SCB 正式发布数据之前判断是否应该买入或卖出你全部的股票。幸运的是，你有一位朋友愿意把这些数据泄露给你。

问题在于，你的朋友记笔记相当不统一。有时他用 **百分点** 记录每日通胀率的变化，有时又用 **百分比**。如果通胀率是 $20\%$，而记录的涨幅是 “50”，你就不清楚新的通胀率是 $70\%$（上升 50 个百分点）还是 $30\%$（上升 50%）。

至少，你可以计算通胀率的一个上界，这对你的股票交易或许有所帮助。给定你朋友的数据，通胀率的最高可能值是多少？

### Input Format


输入的第一行包含一个小数 $I$，表示月初的通胀率（以百分比计）。接下来一行包含 30 个新的小数，表示你朋友记录的该月中每日通胀率的变化。

所有数字都在 0 到 1000 之间，且最多有 2 位小数。


### Output Format


输出一个小数：通胀率的最高可能值。若你的答案的相对或绝对误差不超过 $10^{-6}$，则视为正确。
