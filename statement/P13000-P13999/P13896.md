# P13896 [蓝桥杯 2023 省 C] 公因数匹配

## Difficulty

提高/省选-

## Tags

2023, 数论, 素数判断, 蓝桥杯省赛

## Problem Description

### Description

给定 $n$ 个正整数 $A_i$，请找出两个数 $i, j$ 使得 $i < j$ 且 $A_i$ 和 $A_j$ 存在大于 $1$ 的公因数。

如果存在多组 $i, j$，请输出 $i$ 最小的那组。如果仍然存在多组 $i, j$，请输出 $i$ 最小的所有方案中 $j$ 最小的那组。

### Input Format

输入的第一行包含一个整数 $n$。

第二行包含 $n$ 个整数分别表示 $A_1, A_2, \cdots, A_n$，相邻整数之间使用一个空格分隔。

### Output Format

输出一行包含两个整数分别表示题目要求的 $i, j$，用一个空格分隔。

### Hint

**【评测用例规模与约定】**

对于 $40\%$ 的评测用例，$n \leq 5000$；

对于所有评测用例，$1 \leq n \leq 10^5$，$1 \leq A_i \leq 10^6$。数据保证至少存在一组符合题目要求的 $\langle i,j\rangle$。
