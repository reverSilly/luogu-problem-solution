# P2383 狗哥玩木棒

## Difficulty

普及/提高-

## Tags

搜索, 剪枝

## Problem Description

### Background

狗哥又趁着语文课干些无聊的事了……

### Description

现给出一些木棒长度，那么狗哥能否用给出的木棒（木棒全用完）组成一个正方形呢？

### Input Format

输入文件中的第一行是一个整数 $n(1\le n\le 10)$ 表示测试的组数，接下来 $n$ 行表示每组的测试数据。每行的第一个数为 $m(4\le m\le 20)$，接下来 $m$ 个数 $a_i(1\le a_i\le 2000)$ 表示木棒的长度。

### Output Format

对于每组测试数据，如果可以组成正方形输出 `yes`，否则输出 `no`。

### Hint

狗哥快抓狂了。
