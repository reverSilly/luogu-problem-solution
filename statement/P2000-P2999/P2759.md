# P2759 奇怪的函数

## Difficulty

普及/提高-

## Tags

数学, 二分, 洛谷原创

## Problem Description

### Description

使得 $x^x$ 达到或超过 $n$ 位数字的最小正整数 $x$ 是多少？


### Input Format

一个正整数 $n$。


### Output Format

使得 $x^x$ 达到 $n$ 位数字的最小正整数 $x$。


### Hint

对于全部数据，$1\le n\le 2\times 10^9$。
