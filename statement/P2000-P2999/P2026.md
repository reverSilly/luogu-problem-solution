# P2026 求一次函数解析式

## Difficulty

普及-

## Tags

数学, 洛谷原创

## Problem Description

### Background

做数学寒假作业的怨念……

### Description

给定两个整点的坐标，求它们所在直线的函数解析式（一次函数）。

### Input Format

第一行有两个整数 $x_1,y_1$，表示第一个整点的坐标为 $(x_1,y_1)$。

第二行有两个整数 $x_2,y_2$，表示第二个整点的坐标为 $(x_2,y_2)$。

### Output Format

输出共一行，即这个函数解析式。

### Hint

$2 x$ 表示为 `2x`。

$\frac{1}{2}x$ 表示为 `1/2*x`。
