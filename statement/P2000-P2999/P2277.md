# P2277 [HNOI2003] 24点游戏

## Difficulty

提高/省选-

## Tags

搜索, 2003, 各省省选, 湖南

## Problem Description

### Description

为了培养小孩的计算能力，大人们经常给小孩玩这样的游戏：从一副扑克牌中任意抽出 $4$ 张扑克，要小孩用 `+`、`-`、`*`、`/` 和括号组成一个合法的表达式，并使表达式的值为 $24$ 点。这种游戏就是所谓的“$24$ 点游戏”。

对于给出的任意 $4$ 个非负整数 $a$、$b$、$c$、$d$，我们不希望表达式过于冗杂，即只在必要的时候加括号，请你编程求出这 $4$ 个整数能组成多少个值为 $24$ 的不同表达式。

### Input Format

输入文件共一行，为四个非负整数 $a$、$b$、$c$、$d$。（$0 \le a, b, c, d \le 100$）

### Output Format

输出文件为由 $a$、$b$、$c$、$d$ 组成的值为 $24$ 的表达式个数，如没有，输出 $0$。

### Hint

只有一个表达式符合要求：
$$
5\times 5-5\div 5=24
$$

注意，以下表达式被认为是“过于冗杂”的：
$$
(5\times 5)-5\div 5=24\\
5\times 5-(5\div 5)=24
$$

因为乘除法的运算律高于加减法，所以在这些地方加括号是非必要的。
