# P2630 图像变换

## Difficulty

普及/提高-

## Tags

模拟, 贪心

## Problem Description

### Description

给定 $3$ 行 $3$ 列的图像各像素点灰度值，给定最终图像，求最短、字典序最小的**非空**操作序列。

其中，可能的操作及对应字符有如下四种：

`A`：顺时针旋转 $90$ 度；

`B`：逆时针旋转 $90$ 度；

`C`：左右翻转；

`D`：上下翻转。

### Input Format

一个矩阵，表示初始的图像。

一个矩阵，表示最终的图像。

### Output Format

最短、字典序最小的**非空**操作序列，保证长度不超过 $10^8$，不保证有解。

若长度超过 $10^8$ 无解则输出 `Poland cannot into space!!!` 。

### Hint

字符串长度不超过 $10^8$。
