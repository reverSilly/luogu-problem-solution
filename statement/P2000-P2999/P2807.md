# P2807 三角形计数

## Difficulty

普及-

## Tags

递推

## Problem Description

### Background

三角形计数(triangle) 递推


### Description

把大三角形的每条边 $n$ 等分，将对应的等分点连接起来（连接线分别平行于三条边），这样一共会有多少三角形呢？编程来解决这个问题。


### Input Format

第一行为整数 $t(t≤100)$，表示测试数据组数；接下来 $t$ 行，每行一个正整数 $n(n≤500)$。


### Output Format

对于每个 $n$，输出一个正整数，表示三角形个数。
