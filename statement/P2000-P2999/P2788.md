## Problem Description

### Background

蒟蒻HansBug 在数学考场上，挠了无数次的头，可脑子里还是一片空白。


### Description

好不容易啊，HansBug 终于熬到了做到数学最后一题的时刻了，眼前是一堆杂乱的加减算式。显然成功就在眼前了。可是他脑细胞和RP已经消耗殆尽，所以这个重要的任务就交给你们啦。


### Input Format

一行，包含一个字符串形式的加减法多项式（每一项数字范围为$0\sim 32767$）。


### Output Format

一个整数，为计算所得的结果（保证计算结果不会超过长整型范围）。


### Hint

数据保证字符串长度不超过 $60000$。
