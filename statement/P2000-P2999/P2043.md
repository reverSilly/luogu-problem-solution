# P2043 质因子分解

## Difficulty

普及-

## Tags

数学

## Problem Description

### Description

对 $N!$ 进行质因子分解。

### Input Format

输入数据仅有一行包含一个正整数 $N$，$N \leq 10000$。

### Output Format

输出数据包含若干行，每行两个正整数 $p,a$，中间用一个空格隔开。表示 $N!$ 包含 $a$ 个质因子 $p$，要求按 $p$ 的值从小到大输出。

### Hint

$10! = 3628800 = (2^8) \times (3^4) \times (5^2) \times 7$。
