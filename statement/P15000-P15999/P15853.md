# P15853 [蓝桥杯第二届国际赛] 特殊日期

## Difficulty

普及-

## Tags

字符串, 2018, 枚举, 蓝桥杯国赛

## Problem Description

### Description

一个日期由年、月、日组成，年份为四位数，月不超过两位，日期为不超过两位，小明喜欢把年月日连起来写，当月或日期的长度为一位时在前面补 $0$，这样形成一个八位数。

例如，$2018$ 年 $1$ 月 $3$ 日写成 $20180103$，而 $2018$ 年 $11$ 月 $15$ 日写成 $20181115$。

小明发现，这样写好，有些日期中出现了 $3$ 位连续的数字，小明称之为特殊日期。例如，$20181115$ 就是这样一个数，中间出现了连续的 $3$ 个 $1$。当然，$2011$ 年 $11$ 月 $11$ 日也是这样一个日期。

给定一个起始日期和一个结束日期，请计算这两个日期之间（包含这两个日期）有多少个特殊日期。

### Input Format

输入两行，第一行包含一个八位数字，表示起始日期，第二行包含一个八位数字，表示结束日期。


### Output Format

输出一行包含一个整数，表示有多少个特殊日期。

### Hint

给定的日期一定是一个合法的日期，其中年份的范围为 $1900$ 至 $9999$。结束日期不会在起始日期之前。
