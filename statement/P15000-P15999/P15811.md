# P15811 [JOI 2014 Final] JOI 徽章 / JOI Emblem

## Difficulty

普及/提高-

## Tags

2014, 枚举, JOI（日本）

## Problem Description

### Description

国际信息学奥林匹克日本委员会为了给参加台湾大赛的选手加油，决定制作一面新的 **JOI** 旗。

**JOI** 旗的形状是正方形纵向排列 $M$ 行、横向排列 $N$ 列，每个正方形上写有 **J**, **O**, **I** 中的一个字符。

:::align{center}
![](https://cdn.luogu.com.cn/upload/image_hosting/hvhyxado.png)

JOI 旗示例
:::

国际信息学奥林匹克日本委员会除了 **JOI** 旗之外，还规定了一种 **JOI 纹章**。**JOI 纹章** 的形状是正方形纵向排列 $2$ 行、横向排列 $2$ 列，每个正方形上写有 **J**, **O**, **I** 中的一个字符。

:::align{center}
![](https://cdn.luogu.com.cn/upload/image_hosting/7gbxptrq.png)

JOI 纹章示例
:::

**JOI** 旗中包含的 **JOI 纹章** 的数量，是指 **JOI** 旗中包含的纵向 $2$ 行、横向 $2$ 列的区域中，该区域内 **J**, **O**, **I** 的布局与 **JOI 纹章**（不经过旋转或翻转）一致的区域的个数。即使满足条件的纵向 $2$ 行、横向 $2$ 列区域相互重叠，也应分别计数。

国际信息学奥林匹克日本委员会有一面旧的 **JOI** 旗和一张白纸。白纸的大小与构成 **JOI** 旗的一个正方形相同，可以在上面写下 **J**, **O**, **I** 中的任意一个字符。国际信息学奥林匹克日本委员会决定通过以下两种操作之一来制作新的 **JOI** 旗：

- 不对旧的 **JOI** 旗进行任何操作，直接将其作为新的 **JOI** 旗。不使用白纸。
- 在白纸上写下一个字符，然后将其覆盖粘贴到旧的 **JOI** 旗的任意一个正方形上，从而更改旧的 **JOI** 旗中的一个位置。将更改后的 **JOI** 旗作为新的 **JOI** 旗。

国际信息学奥林匹克日本委员会希望新的 **JOI** 旗中包含的 **JOI 纹章** 的数量尽可能多。你需要求出新的 **JOI** 旗中包含的 **JOI 纹章** 的最大数量。

### 任务

给定旧的 **JOI** 旗和 **JOI 纹章** 的信息，编写一个程序，求出新的 **JOI** 旗中包含的 **JOI 纹章** 的最大数量。


### Input Format

从标准输入读取以下数据。

- 第一行包含两个用空格分隔的整数 $M, N$。这表示 **JOI** 旗是正方形纵向排列 $M$ 行、横向排列 $N$ 列的形状。
- 接下来的 $M$ 行，每行包含一个长度为 $N$ 的字符串。每个字符是 **J**, **O**, **I** 中的一个，$M$ 行中从上数第 $i$ 行 ($1 \le i \le M$) 的字符串从左数第 $j$ 个字符 ($1 \le j \le N$) 表示旧的 **JOI** 旗中从上数第 $i$ 行、从左数第 $j$ 列的正方形上写的字符。
- 接下来的 $2$ 行，每行包含一个长度为 $2$ 的字符串。每个字符是 **J**, **O**, **I** 中的一个，$2$ 行中从上数第 $i$ 行 ($1 \le i \le 2$) 的字符串从左数第 $j$ 个字符 ($1 \le j \le 2$) 表示 **JOI 纹章** 中从上数第 $i$ 行、从左数第 $j$ 列的正方形上写的字符。


### Output Format

向标准输出输出一行，包含一个整数，表示新的 **JOI** 旗中包含的 **JOI 纹章** 的最大数量。


### Hint

### 样例解释 1

旧的 **JOI** 旗和 **JOI 纹章** 与题目描述中的示例相同。如果使用白纸将从上数第 $2$ 行、从左数第 $4$ 列的正方形更改为 **J**，则会变成如下形状：

:::align{center}
![](https://cdn.luogu.com.cn/upload/image_hosting/dyuwx47c.png)

更改 JOI 旗一处位置的示例
:::

这样更改后的 **JOI 旗** 中，有以下 $3$ 处区域与 **JOI 纹章** 的布局相同：

:::align{center}
![](https://cdn.luogu.com.cn/upload/image_hosting/0pc40swh.png)

与 JOI 纹章布局相同的区域
:::

不存在包含 $4$ 处或以上与 **JOI 纹章** 布局相同的区域的新 **JOI** 旗，因此新的 **JOI** 旗中包含的 **JOI 纹章** 的最大数量是 $3$。

### 样例解释 2

请注意，有时不使用白纸也能得到最大值。

### 样例解释 3

对于此样例，在任何可能的新 **JOI 旗** 中，都不包含任何 **JOI 纹章**。

### 限制

所有输入数据满足以下条件：

- $2 \le M \le 1000$
- $2 \le N \le 1000$

### 子任务

#### 子任务 1 [30 分]

满足以下条件：

- $M \le 50$
- $N \le 50$

#### 子任务 2 [70 分]

无额外限制。
