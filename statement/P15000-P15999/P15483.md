## Problem Description

### Description

考虑一个向靶盘投掷飞镖的游戏。靶盘由 10 个圆心在原点、半径分别为 20、40、60、80、100、120、140、160、180 和 200（单位：毫米）的同心圆组成。每次投掷根据飞镖击中靶盘的位置进行评分。如果包含或穿过命中点的最小圆的半径为 $20\cdot(11-p)$，则得分为 $p$ 分（$p\in\{1,2,\dots,10\}$）。未命中最大圆的投掷不得分。你的任务是计算 $n$ 次投掷的总得分。

### Input Format

输入的第一行包含测试用例的数量 $T$。随后是每个测试用例的描述：

每个测试用例以一行包含投掷次数 $n$（$1\le n\le 10^6$）开始。接下来的 $n$ 行每行包含两个由空格分隔的整数 $x$ 和 $y$（$-200\le x,y\le 200$），表示一次投掷命中点的坐标。


### Output Format

按照输入中出现的顺序输出每个测试用例的答案。对于每个测试用例，输出一行，包含一个整数——所有 $n$ 次投掷的得分总和。
