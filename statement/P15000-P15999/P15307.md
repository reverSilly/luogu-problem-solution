## Problem Description

### Description

在一个居住着神奇生物的遥远国度，遗传学家们发现了一个独特的现象：后代的眼色直接取决于他们父母的眼色。在这个世界里，只有三种眼色：**棕色**、**绿色**和**蓝色**。

遗传学家们制定了若干规则，用于确定孩子可能拥有的眼色：
- 如果父母中至少有一人拥有棕色眼睛，那么孩子一定拥有棕色眼睛。
- 否则，如果父母中有一人拥有绿色眼睛，那么孩子也拥有绿色眼睛。
- 如果父母双方拥有相同的眼色，那么孩子也将拥有相同的眼色。

遗传学家们有一本古老的书籍，其中记录了父母和后代眼色的统计数据。然而，书中可能包含错误的条目，或者包含符号 `.`，这表示该眼色未被记录下来，可以是三种眼色中的任意一种。

你的任务是帮助遗传学家们验证关于眼色记录的正确性。你将获得父母双方及其后代的眼色。你需要按字典序找出所有可能的、正确的父母及后代的眼色组合。如果这样的组合不存在，则输出单词 "Incorrect"。

### Input Format

输入包含三个以空格分隔的眼色：两个父母的眼色和后代的眼色。眼色可以是**棕色**（`brown`）、**绿色**（`green`）、**蓝色**（`blue`）或 `.`。

### Output Format

按字典序输出所有可能的正确父母及后代的眼色组合，组合中的三个眼色以空格分隔，每个组合占一行。如果组合不可实现，则输出单词 "Incorrect"。
