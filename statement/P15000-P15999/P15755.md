## Problem Description

### Description

JAG Box 是一种目前在全世界流行的普通长方体盒子。共有 $N$ 个 JAG Box。对于每个 $i = 1, 2, \ldots, N$，第 $i$ 个盒子有一个整数重量 $A_i$。

你将通过重复选择一个剩余的盒子并将其插入当前堆叠的最底部来建造一个垂直堆叠。当一个重量为 $w$ 的盒子被插入到总重量为 $x$ 的现有堆叠底部时，该盒子承受的负载等于 $\left\lfloor \frac{x}{w} \right\rfloor$。

确定所有盒子可能承受的最小总负载。

### Input Format

输入格式如下：

$$\begin{aligned} &N \\ &A_1 \ A_2 \ \ldots \ A_N \end{aligned}$$

- $2 \leq N \leq 200\,000$
- $1 \leq A_i \leq 10^9$ ($1 \leq i \leq N$)
- 所有输入值均为整数。

### Output Format

在一行中输出答案。
