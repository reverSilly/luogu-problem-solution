## Tags

## Problem Description

### Description

锦标赛中，每位选手需进行六场比赛。比赛无平局。锦标赛负责人将根据选手的比赛结果按以下规则分组：  

- 若选手赢 $5$ 场或 $6$ 场，则分入第 $1$ 组；

- 若选手赢 $3$ 场或 $4$ 场，则分入第 $2$ 组；
  
- 若选手赢 $1$ 场或 $2$ 场，则分入第 $3$ 组；
   
- 若选手未赢任何一场比赛，则被淘汰出锦标赛。  

请编写一个程序，以确定某位选手被分入的组别。 

### Input Format

输入共有六行，每行包含一个英文大写字母 `W`（表示胜利）或 `L`（表示失败）。  

### Output Format

输出共有一行，表示该选手应被分入的组别。

若该选手已被淘汰，输出 $-1$。
