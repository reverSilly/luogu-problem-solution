## Problem Description

### Description

你面对一个谜题。给定一个 $n$ 行 $m$ 列、由 0 和 1 填充的表格。

只允许一种操作：在任意一列内，你可以自由地重新排列该列的元素，以任意方式改变该列中行的顺序。每一列中 0 和 1 的数量保持不变。

你可以进行任意多次这样的操作。谜题的目标是让尽可能多的行变得完全相同。

请确定通过使用所描述的操作，最多可以让多少行变得完全相同。

### Input Format

第一行包含两个整数 $n$ 和 $m$ （$1 \le n, m \le 10^5$； $nm \le 2 \cdot 10^5$）—— 分别表示行数和列数。

接下来的 $n$ 行，每行包含 $m$ 个字符 $\tt{0}$ 或 $\tt{1}$ —— 初始表格中的元素。


### Output Format

输出一个整数 —— 最多可以获得完全相同的行的数量。
