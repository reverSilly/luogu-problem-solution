## Problem Description

### Description

魔方阵是一种数字方阵，其有趣的特性在于：每一列和每一行的数字之和均相等。

给定一个 $4 \times 4$ 的数字方阵，判断它是否为魔方阵。

### Input Format

输入共有四行，每行包含 $4$ 个以空格分隔的整数。 

### Output Format

输出一行。

输出应为 `magic`（若输入是魔方阵）或 `not magic`（若输入不是魔方阵）。

### Hint

### 样例解释 $1$

每一行之和均为 $34$，每一列之和也均为 $34$。

故输出 `magic`。

### 样例解释 $2$

最上面一行之和为 $19$，但最右边一列之和为 $11$。

故输出 `not magic`。
