# P15479 [CERC2012] Non-boring sequences

## Difficulty

省选/NOI-

## Tags

## Problem Description

### Background

我们担心把题目描述搞得太无聊，所以决定写得简短些。

### Description

如果一个序列的每一个连续子序列都包含一个独一无二的元素，即在该子序列中没有其他元素与其值相同，则称该序列是 **non-boring** 的。

给定一个整数序列，判断它是否是 **non-boring** 的。

### Input Format

输入的第一行包含测试用例的数量 $T$。随后是每个测试用例的描述：

每个测试用例以一个整数 $n$（$1\le n\le 200000$）开头，表示序列的长度。接下来一行包含 $n$ 个由空格分隔的序列元素。这些元素是非负整数，小于 $10^9$。

### Output Format

按照输入中出现的顺序输出每个测试用例的答案。对于每个测试用例，输出一行，包含单词 `non-boring` 或 `boring`。
