# P15670 [ICPC 2024 Jakarta R] Saraga

## Difficulty

普及/提高-

## Tags

2024, Special Judge, ICPC

## Problem Description

### Description

单词 **saraga** 是 **sarana olahraga** 的缩写，后者是印尼语中“体育设施”的意思。它由单词 **sarana** 的前缀 **sara** 和单词 **olahraga** 的后缀 **ga** 组合而成。有趣的是，它也可以由单词 **sarana** 的前缀 **sa** 和单词 **olahraga** 的后缀 **raga** 组合而成。

对于两个字符串 $S$ 和 $T$，一个缩写被称为**有趣的**，如果存在至少两种不同的方式将该缩写分割成两个非空子串，使得第一个子串是 $S$ 的一个前缀，而第二个子串是 $T$ 的一个后缀。

给定两个字符串 $S$ 和 $T$。你需要构造一个长度最短的、关于字符串 $S$ 和 $T$ 的有趣缩写，或者判断不可能构造出这样的缩写。


### Input Format

第一行包含一个字符串 $S$（$1 \leq |S| \leq 200\,000$）。

第二行包含一个字符串 $T$（$1 \leq |T| \leq 200\,000$）。

两个字符串 $S$ 和 $T$ 都仅由小写英文字母组成。

### Output Format

如果无法构造出有趣的缩写，输出 -1。

否则，在一行中输出一个字符串，表示一个长度最短的、关于字符串 $S$ 和 $T$ 的有趣缩写。如果有多个解，输出其中任意一个即可。


### Hint

**样例输入/输出 #1 的解释**

你可以将 **saga** 分割为 **s** 和 **aga**，或者 **sa** 和 **ga**。缩写 **saraga** 也是有趣的，但 **saga** 的长度更短。

**样例输入/输出 #2 的解释**

缩写 **belhijau** 也是长度最短的有趣缩写，因此它是另一个有效的解。
