## Problem Description

### Description

大学毕业后，Anton 决定开始找工作。

他立刻访问了 $\tt{ConnectedIn}$ 网站。当他打开“职位”标签时，看到了很多工作机会。然而，网站上并未明确标注职位的具体数量。他知道每页最多显示 $20$ 个职位，且职位总共占据 $n$ 页。

你非常了解该网站的工作原理。当新增一个职位时，它会被添加到最后一页。如果在添加新职位之前，最后一页已经包含了 $20$ 个职位，则会创建一个新页，并将该职位添加到新页中。

根据这些信息，请确定职位数量的最小值和最大值。

### Input Format

输入的第一行包含一个整数 $n$（$1 \le n \le 100$）——显示职位的页面数。


### Output Format

输出两个整数——网站可能拥有的职位数量的最小值和最大值。
