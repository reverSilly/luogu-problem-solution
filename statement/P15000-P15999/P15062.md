## Problem Description

### Description

今天是星期五。Anton 终于有两天的学校假期了！Anton 回家有两条路可走：
- 走第一条路，Anton 可以经过 $a$ 家商店；
- 走第二条路，Anton 可以经过 $b$ 家商店。

Anton 还知道有 $c$ 家商店同时出现在两条路上（两处都有）。Anton 好奇他所在的城市总共有多少家商店？我们假设除了这些商店外，城市里没有其他商店。

请帮助他回答这个问题。

### Input Format

第一行包含三个整数 $a$、$b$、$c$（$0 \le c \le a, b \le 100$）——分别表示第一条路上的商店数、第二条路上的商店数以及两条路共有的商店数。

### Output Format

输出一个整数——城市中商店的总数。
