## Tags

## Problem Description

### Description

杰瑞在竞争激烈的国际大学生程序设计竞赛（ICPC）领域中，凭借其独特的执教方法，赢得了著名教练的美誉。他通过利用在该领域鲜少使用的编程语言 Java 来训练学生，使他们在 ICPC 竞赛中脱颖而出。因此，杰瑞的团队已成为卓越的代名词，并被亲切地称为“Java 勇士”。

杰瑞带领 $n$ 支队伍参加 2023 年 ICPC 桃园区域赛。每支队伍的报名费为 $4000$ 美元，而杰瑞没有足够的资金为所有 Java 勇士支付费用。面对带队参加 2023 年 ICPC 桃园区域赛的财务挑战，杰瑞怀着诚挚与恳切的心情向上帝祈祷。

“亲爱的上帝，

我今天怀着谦卑的心和深深的渴望来到你面前，希望能帮助我的队伍参加国际大学生程序设计竞赛。报名费是一个巨大的障碍，我发现自己缺乏支持所有队伍所需的资金。

我祈求你的指引和帮助，不仅为我自己，也为那些信任我作为他们教练的优秀学生们。请赐予我们必要的资源，以支付这些队伍的报名费用。

我明白这次竞赛不仅关乎胜利，更在于培养这些年轻人的学习能力、团队合作精神和成长。请帮助我们克服这个财务障碍，让我们能够继续培养他们的技能和志向。

我也祈求智慧，让我能做出最好的决定，并有决心探索所有可能的途径来获得所需的资金。如果这是你的旨意，请为我们打开大门，让我们结识愿意支持我们事业的人或组织，或者启发我们找到创造性的解决方案来满足我们的财务需求。

感谢你，上帝，垂听了我的祈祷，成为我们力量和指引的源泉。我将信任交托于你，相信在你的帮助下，我们能够克服这一挑战。

奉你圣洁而慈爱的名祈祷，

阿门。”

听到他真挚的祈祷，被他的真诚和奉献深深打动，你决定伸出援手，为 Java 勇士支付报名费用。现在问题来了：你需要捐赠多少钱，才能使杰瑞的队伍能够参加 2023 年 ICPC 桃园区域赛？

### Input Format

输入包含一个正整数 $n$，表示杰瑞的 Java 勇士报名参加 2023 年 ICPC 桃园区域赛的队伍数量。


### Output Format

输出报名费的总金额。

### Hint

$n$ 不超过 $20$。
