## Problem Description

### Description

在 JAG 国，共有 $m$ 所大学，我们计划邀请 $2n$ 名学生参加一个训练营。每名学生隶属于这 $m$ 所大学中的一所。在训练营期间，学生们将被安排入住 $n$ 个双人间，这意味着每个房间将被分配给恰好两名学生。

为了促进学生之间的多样化交流，我们的目标是实现一个“良好的房间分配”。一个房间分配被认为是良好的，当且仅当共享同一房间的两名学生来自不同的大学。

这里，我们想知道良好的房间分配在多大程度上是可行的。总共有 $m^{2n}$ 种可能的学生所属大学序列，请计算其中有多少种序列存在一种良好的房间分配。

实际上，我们尚不知道可以提供多少个房间。因此，对于每个 $n = 1, 2, \ldots, m$，请计算有多少种大学序列存在一种良好的房间分配。

由于答案可能非常大，请输出答案对 $998,244,353$ 取模的结果。

### Input Format

输入为一行，包含一个介于 $1$ 到 $200,000$ 之间（含）的整数 $m$。


### Output Format

输出 $m$ 行。在第 $i$ 行，输出 $n = i$ 时的答案。
