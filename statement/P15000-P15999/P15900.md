# P15900 [TOPC 2025] Chopsticks

## Problem Description

### Description

千纱在一家传统的日本餐厅工作，店里刚刚收到一批精美的手工筷子。共有 $m$ 种不同类型的筷子，对于每种类型 $i$（$1 \le i \le m$），恰好有 $k_i$ 根筷子。

今晚有 $n$ 位客人到来，每位客人需要恰好一双筷子。由于没有任何一种筷子的数量达到 $2n$ 根，千纱决定从总共 $s = \sum_{i=1}^{m} k_i$ 根筷子中，随机选取 $2n$ 根筷子。

选取 $2n$ 根筷子后，千纱会尽量分配，使拿到相同类型配对（即两根同一类型的筷子）的客人数量最大化。如果无法让所有客人都拿到相同类型的配对，那么部分客人将拿到不匹配的配对。

你的任务是计算在这种策略下，拿到不匹配配对的客人数的期望值。

### Input Format

第一行包含两个整数 $n$ 和 $m$，分别表示人数和筷子类型数。

第二行包含 $m$ 个整数，其中第 $i$ 个整数 $k_i$ 表示第 $i$ 种筷子的根数。

### Output Format

输出一个整数，表示无法拿到相同类型配对的客人数的期望值乘以 $\binom{s}{2n}$ 的结果（其中 $s = \sum_{i=1}^{m} k_i$）。可以证明该乘积是一个整数。输出结果对 $998244353$ 取模。

### Hint

- $1 \le n \le 2.5 \times 10^5$
- $1 \le m \le 5 \times 10^5$
- $1 \le k_i < 2 \times n$
- $2 \times n \le s$
