## Problem Description

### Description

在动物庄园中，动物们反抗了它们的人类主人，接管了农场的管理工作。为了确保所有动物之间的平等与公平，它们决定制定一套新的规则。然而，作为新的领导者，猪开始修改规则以偏袒自己。

农场根据物种维护着动物的等级制度，每只动物都被分配了一个特定的影响力等级。这个影响力等级用正整数表示，决定了动物在决策中的优先级。在一个群体内，某只动物如果拥有群体中最高的影响力等级，就可以做出决策。

猪计划通过选择特定的动物群体来最大化它们在领导委员会中的集体影响力。给定一系列动物及其物种和影响力等级，你的任务是组成最具影响力的领导委员会，同时遵守以下规则：

1. 委员会中只允许出现一种猪，以避免猪之间的权力冲突。
2. 委员会中所有非猪物种的成员，其影响力等级必须低于委员会中唯一那只猪的影响力等级。

请确定在遵守这些规则的前提下，委员会能够达到的最大总影响力值。

### Input Format

第一行包含一个整数 $n$，表示动物的数量。接下来的 $n$ 行，每行包含一个字符串 `species` 和一个正整数 `influence`：

- `species` 是一个表示动物物种的字符串，例如 “pig”、“horse”、“cow” 等。
- `influence` 是一个整数，表示该动物的影响力等级。

### Output Format

输出一个整数，表示在遵守规则的情况下，能够组成的领导委员会的最大总影响力值。


### Hint

- $1 \le n \le 10^5$
- `species` 的长度不超过 $10$
- `species` 仅由英文小写字母组成
- 至少有一只动物的物种为 pig
- `influence` 不超过 $10^8$
