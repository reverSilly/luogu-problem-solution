# P15638 [ICPC 2022 Tehran R] Final Price

入门

## Tags

## Problem Description

### Description

梦幻岛（Neverland）最近经历了通货膨胀率的快速上升。货币价值持续下降，公民的购买力每天都在降低。政$ $府正试图通过测试各种方法来控制通货膨胀率，例如通过提高利率来减少经济中的货币量，并鼓励投资，甚至鼓励购买那些在不可预见的未来才会交付的汽车。

尽管做出了这些努力，通货膨胀率仍然高于 $50\%$，并且物价时不时地剧烈上下波动。梦幻岛统计中心提供了关于通货膨胀率以及一篮子家庭常用商品平均价格随时间变化的详细信息。然而，利用这些信息很难计算出特定商品在给定时间点的实际价格。

国际价格变化中心（ICPC）请你帮助梦幻岛的公民计算他们想要的商品在经过特定时间段后的价格。提供给你的信息是商品在一个时间段开始时的初始价格，以及该商品在观察时间段内的每日价格变化。

### Input Format

输入的第一行包含一个整数 $n(1 \leq n \leq 1000)$，表示观察价格的天数。

第二行包含一个正整数，表示第 $1$ 天所需商品的初始价格。

接下来的 $n−1$ 行包含 $n−1$ 个整数，按顺序显示从第 $2$ 天到第 $n$ 天该商品的每日价格变化。你可以假设在观察期间，商品的价格始终为正数且从不超过 $1000000$。


### Output Format

在输出中，打印第 $n$ 天商品的最终价格。
