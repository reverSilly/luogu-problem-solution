# P15040 [UOI 2022 II Stage] 竞赛

## Difficulty

入门

## Tags

模拟, 数学, 2022, UOI（乌克兰）

## Problem Description

### Description

克索尼亚和她的班级在竞赛开始前 $t$ 分钟到达。由于防疫限制，组织者允许学生每 $w$ 分钟以 $m$ 人为一组进入考场。

换句话说，第一批 $m$ 名学生将在竞赛开始前 $t$ 分钟进入考场。下一批 $m$ 名学生将在开始前 $t-w$ 分钟进入。再下一批 $m$ 名学生将在开始前 $t-2w$ 分钟进入，依此类推。学生甚至可以在开始前 $0$ 分钟（即竞赛开始时）进入。但是，学生不能在竞赛开始后进入。

班级总共有 $n$ 名学生（包括克索尼亚）。有多少学生能在竞赛开始前进入考场？

### Input Format

第一行包含四个整数 $n$、$m$、$w$、$t$ ($1 \leq n, m, w, t \leq 1\,000$)。

### Output Format

输出一个数字 —— 能及时参加竞赛的学生数量。

### Hint

### 样例说明

第一个样例的说明：

-   开始前 $4$ 分钟，一组两名学生进入考场。
-   开始前 $3$ 分钟，剩余三名学生等待。
-   开始前 $2$ 分钟，剩余三名学生等待。
-   开始前 $1$ 分钟，又有两名学生进入考场。
-   开始前 $0$ 分钟，剩余一名学生等待。由于时间已到，只有四名学生成功进入。

第二个样例的说明：

-   开始前 $4$ 分钟，一组三名学生进入考场。
-   开始前 $3$ 分钟，剩余三名学生等待。
-   开始前 $2$ 分钟，又有一组三名学生可以进入考场。由于没有更多学生，因此所有 $6$ 名学生都成功进入。

第三个样例的说明：

-   开始前 $6$ 分钟，一组三名学生进入考场。
-   开始前 $4$ 分钟，剩余的七名学生等待。
-   开始前 $3$ 分钟，又有一组三名学生可以进入考场。
-   开始前 $1$ 分钟，剩余的四名学生等待。
-   开始前 $0$ 分钟，一组三名学生进入考场。
-   时间耗尽，因此共有 $9$ 名学生进入。
