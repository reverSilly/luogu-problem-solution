# P15711 [JAG 2023 Summer Camp #2] Tea time in the grand garden

## Difficulty

Level 8

## Tags

2023, LGV 引理, 容斥原理, ICPC

## Problem Description

### Description

适宜的温度变化对于冲泡美味的茶至关重要。Noli 被传授了一个美味茶的配方。

该配方由一个长度为 $N+2$ 的非负整数序列 $A = a_0, a_1, a_2, \ldots, a_N, a_{N+1}$ 表示。她必须相应地改变温度。

升高温度是项艰苦的工作。配方 $A$ 的成本由以下 $f(A)$ 定义。

$$
f(A) = \sum_{i=0}^{N} \max(0, a_{i+1} - a_i)
$$

Noli 忘记了她被传授的配方。她只记得 $a_0 = a_{N+1} = 0$，并且成本是 $K$。

有多少种可能的配方可以考虑？请找出可能的配方数量除以 $998244353$ 的余数。

注意，当对于任意 $i (0 \leq i \leq N+1)$，$a_i$ 的值不同时，两个配方被认为是不同的。


### Input Format

$N \ K$

输入满足以下约束：

- 所有输入均为整数。
- $1 \leq N \leq 2 \times 10^5$
- $0 \leq K \leq 2 \times 10^5$

### Output Format

输出可能的配方数量除以 $998244353$ 的余数。请在输出末尾添加换行符。


### Hint

在样例输入 1 中，有五种可能的序列 $A$：

- $\{0,2,0,0\}$
- $\{0,0,2,0\}$
- $\{0,1,2,0\}$
- $\{0,2,1,0\}$
- $\{0,2,2,0\}$
