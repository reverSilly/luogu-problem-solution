# P7629 [COCI 2011/2012 #1] SORT

## Difficulty

提高/省选-

## Tags

2011, 线段树, 树状数组, COCI（克罗地亚）

## Problem Description

### Description

考虑如下的排序算法：

```
reverse-sort(序列 a)
    当 (a 未按非递减顺序排列时)
        将 a 划分为最少个数的斜率段
        对于每一个长度大于 1 的斜率段
            反转(该斜率段)
```

定义 `slope` 为 `a` 的递减子串，`reverse()` 将翻转一段序列。

给定一个 $1 \sim N$ 的排列，保证在第一次划分时每个 `slope` 的长度都为偶数，求如果使用这种排序算法对给定的排列进行排序，需要调用多少次 `reverse(slope)`。

### Input Format

输入的第一行包含一个正整数 $N$。

第二行包含 $N$ 个互不相同的的正整数，代表待排序的排列。

### Output Format

输出一行一个整数，表示 `reverse(slope)` 需要被调用的次数。

### Hint

#### 【数据范围】

对于 $100\%$ 的数据，$2 \le N \le 10^5$。
