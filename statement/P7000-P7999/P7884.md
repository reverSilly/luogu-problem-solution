# P7884 【模板】Meissel-Lehmer

## Difficulty

NOI+

## Tags

数论, 线性筛法, 模板题

## Problem Description

### Description

给定整数 $n$，求出 $\pi(n)$ 的值。

$\pi(n)$ 表示 $1 \sim n$ 的整数中质数的个数。

### Input Format

一行，一个整数 $n$。

### Output Format

一行，一个整数，表示所求的值。

### Hint

对于 $100\%$ 的数据，$1 \leq n \leq 10^{13}$。
