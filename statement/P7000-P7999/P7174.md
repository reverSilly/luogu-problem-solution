# P7174 [COCI 2014/2015 #4] CESTA

## Difficulty

入门

## Tags

## Problem Description

### Description

Mirko 发现了一个正整数 $n$，由于 Mirko 喜欢数字 $30$，他想知道用 $n$ 的每位数字所组成的数中 $30$ 的最大倍数。

写一个计算这个数字的程序（如果不存在，则输出 `-1`）。

### Input Format

一个数 $n$。

### Output Format

仅一行，即题中所求。

### Hint

#### 数据规模与约定

对于 $100\%$ 的数据，$n$ 的位数不超过 $10^5$。
