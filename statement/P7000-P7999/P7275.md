# P7275 计树

## Difficulty

Level 8

## Tags

O2优化, 组合数学, 容斥原理, 生成函数, 线性递推

## Problem Description

### Description

求有多少不同的包含 $n$ 个点的有标号无根树，满足：对于任何一个点 $x$，都存在点 $y$ 使得 $x$ 和 $y$ 之间有一条边且 $|x - y| = 1$。答案对 $998244353$ 取模。

### Input Format

一行一个正整数 $n$。

### Output Format

一行一个整数，所求答案。

**【数据范围】**

本题包含 $20$ 个测试点，每个测试点 $5$ 分。

| 测试点编号 | $n$ 的范围  |
| :--------: | :---------: |
|  $1 \sim 2$  |  $\leq 7$   |
|  $3 \sim 4$  |  $\leq 14$  |
|  $5 \sim 8$  |  $\leq 30$  |
|  $9 \sim 12$ | $\leq 10^3$ |
| $13 \sim 20$ | $\leq 10^5$ |

对于所有测试点满足 $n$ 为正整数且 $2 \leq n \leq {10}^5$。
