# P4780 Phi 的反函数

## Difficulty

省选/NOI-

## Tags

搜索, 枚举, 素数判断

## Problem Description

### Description

求最小的正整数 $x$，使得 $\varphi(x)=n$。

### Input Format

输入正整数 $n$（$n<2^{31}$）。

### Output Format

输出 $x$，如果 $x>2^{31}$ 或者不存在，则输出 $-1$。
