### Description

## 题目大意

一共有 $T$ 组数据，每组数据给定一个数 $N$，请将 $N$ 分解为几个连续正整数的和，如果有多种情况，请输出最小数最大的情况。

### Input Format

第一行，一个整数 $T$，表示数据组数。

第 $2$ 行至第 $T+1$ 行，每行一个整数 $N$（$1\le N\le 10^9$），表示要拆分的数字。

### Output Format

$T$ 行，每行一个式子，表示拆分结果。

如果无解，请输出 `IMPOSSIBLE`。
