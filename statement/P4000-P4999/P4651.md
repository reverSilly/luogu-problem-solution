# P4651 [BalticOI 2005] Maze (Day1)

## Difficulty

提高/省选-

## Tags

图论, 2005, 最短路, BalticOI（波罗的海）

## Problem Description

### Description

给出一个平行四边形的长与高。给出入口与出口，对于四边形的每条边都有三种可能：黑色、白色、无色。你要找出一条路径，走过的边黑白交替，且长度最短。

### Input Format

第一行给出平行四边形的长与高，且值在 $[1,500]$。

第二行给出入口，出口坐标。

下面的字符矩阵代表这个平行四边形每条边的颜色，`n` 表示无色，`w` 表示白色，`b` 表示黑色。

### Output Format

输出路径的最短长度。

### Hint

$(0, 0) \rightarrow (1, 0) \rightarrow (0, 1) \rightarrow (1, 1) \rightarrow (1, 0) \rightarrow(2, 0) \rightarrow (2, 1)$
