# P4763 [CERC2014] Bricks

## Difficulty

提高/省选-

## Tags

2014, ICPC, CERC

## Problem Description

### Description

给你一个由 'B' 和 'W' 组成的序列，将其按分成最多的区间且每个区间的 'B':'W' 的值相等。

### Input Format

多组数据，第一行一个整数 $T$ 表示数据组数。
每组数据的第一行为一个整数 $n$，接下来 $n$ 行，每行一个整数 $k$ 和一个字符（'B' 或 'W'）表示在上一个序列后有一个长度为 $k$ 的 'B' 或 'W' 的序列，序列的总长度不超过 $10^9$。

### Output Format

共 $T$ 行，每行一个整数，表示能分成的最多的区间数。
