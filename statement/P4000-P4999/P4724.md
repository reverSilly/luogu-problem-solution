# P4724 【模板】三维凸包

## Difficulty

Level 8

## Tags

计算几何, 三维计算几何, 模板题

## Problem Description

### Description

给出空间中 $n$ 个点，求凸包表面积。

### Input Format

第一行一个整数 $n$，表示点数。

接下来 $n$ 行，每行三个实数 $x, y, z$ 描述坐标。


### Output Format

输出凸包表面积，保留 $3$ 位小数。

### Hint

$4 \le n \le 2000$
