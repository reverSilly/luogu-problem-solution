# P4857 [PA 2013] Konduktorzy

## Difficulty

提高/省选-

## Tags

2013, 二分, 堆, PA（波兰）

## Problem Description

### Description

一辆无限长的列车，有 $k$ 个检票员。每个检票员一次检验 $a_i$ 个车厢，初始时所有检票员在 $0$ 号车厢。

列车长每次命令最靠左的编号最小的检票员向右走 $a_i$ 步，一共发出 $n$ 个命令，输出每个检票员走的最后一步是列车长的第几次命令。保证 $a_i$ 互不相同。

### Input Format

第一行两个数 $n,k$。

第二行 $k$ 个数，表示每个检票员一次检验的长度 $a_i$。

### Output Format

一行 $k$ 个整数，每个整数表示这个检票员走到最后一步是列车长的第几次命令。

### Hint

对于 $100\%$ 的数据，$1\le n\le 2\times 10^{13}$，$1\le k\le 10^5$，$k\le n$，$1\le a_i\le 10^5$，保证不存在 $1\le i<j\le n$ 满足 $a_i=a_j$。
