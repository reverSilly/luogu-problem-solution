# P4127 [AHOI2009] 同类分布

## Difficulty

省选/NOI-

## Tags

动态规划 DP, 搜索, 递推, 2009, 各省省选, 安徽, 枚举, 数位 DP

## Problem Description

### Description

给出两个数 $a,b$，求出 $[a,b]$ 中各位数字之和能整除原数的数的个数。

### Input Format

一行，两个整数 $a$ 和 $b$。

### Output Format

一个整数，表示答案。

### Hint

对于所有的数据，$1 \le a \le b \le 10^{18}$。
