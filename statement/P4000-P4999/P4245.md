# P4245 【模板】任意模数多项式乘法

## Difficulty

NOI+

## Tags

数学, 多项式, O2优化, 中国剩余定理 CRT, 快速傅里叶变换 FFT, 快速数论变换 NTT, 模板题

## Problem Description

### Background

模板题，无背景

### Description

给定 $2$ 个多项式 $F(x), G(x)$ ，请求出 $F(x) \times G(x)$。    

**系数对 $p$ 取模**，且**不保证** $p$ 可以分解成 $p = a \cdot 2^k + 1$ 之形式。

### Input Format

输入共 $3$ 行。   

第一行 $3$ 个整数 $n, m, p$，分别表示 $F(x), G(x)$ 的次数以及模数 $p$ 。

第二行为 $n+1$ 个整数，第 $i$ 个整数 $a_i$ 表示 $F(x)$ 的 $i-1$ 次项的系数。  

第三行为 $m+1$ 个整数，第 $i$ 个整数 $b_i$ 表示 $G(x)$ 的 $i-1$ 次项的系数。

### Output Format

输出 $n+m+1$ 个整数， 第 $i$ 个整数 $c_i$ 表示 $F(x) \times G(x)$ 的 $i-1$ 次项的系数。

### Hint

对于 $100 \%$ 的数据，$1 \leq n, m \leq 10^5$，$0 \leq a_i, b_i \leq 10^9$，$2 \leq p \leq 10^9 + 9$。
