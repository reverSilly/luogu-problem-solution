# P4464 [国家集训队] JZPKIL

## Difficulty

Level 8

## Tags

数学, 2012, 集训队互测, 素数判断, 莫比乌斯反演

## Problem Description

### Description

给定$ n, x, y$，求

$$\sum_{i=1}^{n}\mathrm{gcd}(i,n)^x \mathrm{lcm}(i,n)^y \bmod (10^9+7)$$



### Input Format

第一行，询问个数 $T$。

下面 $T$ 行，每行三个整数 $n, x, y$。

### Output Format

$T$ 行，每行一个整数，表示相应的询问的答案

### Hint

30%的数据，$x=y$

另30%的数据，$n \le 10^9, x, y \le 100$

100%的数据，$T \le 100, 1 \le n \le 10^{18}, 0 \le x, y \le 3000$
