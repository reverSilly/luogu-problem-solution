# P4597 序列 sequence

## Difficulty

NOI/NOI+

## Tags

贪心, O2优化, 优先队列, 整体二分, 斜率维护技巧 slope trick

## Problem Description

### Background

原题 CF13C 数据加强版

### Description

给定一个序列，每次操作可以把某个数 $+1$ 或 $-1$。要求把序列变成非降数列。

### Input Format

第一行，输入一个整数 $n$（$n \leq 5 \times 10^5$），表示有 $n$ 个数字。  
第二行输入 $n$ 个整数，整数的绝对值不超过 $10^9$。

### Output Format

输出一个数，表示最少的操作次数。

### Hint

对于 $100 \%$ 的数据，$1 \le n \le 5 \times {10}^5$。
