# P4781 【模板】拉格朗日插值

## Difficulty

省选/NOI-

## Tags

O2优化, 拉格朗日插值法, 模板题

## Problem Description

### Background

这是一道模板题。

### Description

对于 $n$ 个点 $(x_i,y_i)$，如果满足 $\forall i\neq j, x_i\neq x_j$，那么经过这 $n$ 个点可以唯一地确定一个次数不超过 $n-1$ 的多项式 $y = f(x)$。

现在，给定这样 $n$ 个点，请你确定这个多项式，并求出 $f(k) \bmod 998244353$ 的值。

### Input Format

第一行两个整数 $n,k$。

接下来 $n$ 行，第 $i$ 行两个整数 $x_i,y_i$。

### Output Format

一行一个整数，表示 $f(k) \bmod 998244353$ 的值。

### Hint

样例一中的多项式为 $f(x)=x^2+2x+1$，$f(100) = 10201$。

样例二中的多项式为 $f(x)=x$，$f(100) = 100$。

---

$1 \le n \leq 2\times 10^3$，$1 \le x_i,y_i,k < 998244353$，$x_i$ 两两不同。
