# P4526 【模板】自适应辛普森法 2

## Difficulty

NOI+

## Tags

数学, 积分, 定积分, 模板题

## Problem Description

### Description

试计算积分

$$\displaystyle{\int_0^\infty x^{\frac{a}{x}-x}\mathrm{d}x}$$

保留至小数点后 $5$ 位。若积分发散，请输出 $\text{orz} $。

### Input Format

一行，包含一个实数，为 $a$ 的值。

### Output Format

一行，积分值或 $\text{orz}$。

### Hint

$|a|\le50$。

请注意时空限制。
