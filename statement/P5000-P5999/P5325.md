# P5325 【模板】Min_25 筛

## Difficulty

NOI+

## Tags

递推, 数论, 杜教筛, 线性筛法, 模板题, 亚线性快速求和算法

## Problem Description

### Background

模板题，无背景。

### Description

定义积性函数 $f(x)$，且 $f(p ^ k) = p ^ k(p ^ k - 1)$（$p$ 是一个质数），求

$$\sum_{i = 1} ^ n f(i)$$

对 $10 ^ 9 + 7$ 取模。

### Input Format

一行一个整数 $n$。

### Output Format

一个整数表示答案。

### Hint

$f(1)=1$，$f(2)=2$，$f(3)=6$，$f(4)=12$，$f(5)=20$；  
$f(6)=12$，$f(7)=42$，$f(8)=56$，$f(9)=72$，$f(10)=40$。

对于 $30\%$ 的数据，保证 $1\le n\le 10^6$。

对于 $100\%$ 的数据，保证 $1\le n\le 10^{10}$。
