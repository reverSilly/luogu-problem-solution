# P5153 简单的函数

## Difficulty

提高/省选-

## Tags

数学

## Problem Description

### Background

此题为改编题，特别鸣谢吴作凡同学。


### Description

HKE 有一次发现了一个很有趣的函数。

定义 $f(2)=1$。对于 $n\geq3$，设 $t$ 为最小的使得 $n$ 不能被 $t$ 整除的正整数，则 $f(n)=f(t)+1$。

举个栗子。比如 $n=6$，此时 $t=4$，$f(6)=f(4)+1=f(3)+2=f(2)+3=4$。

现在，HKE 想知道 $f(2)\times f(3)\times\cdots\times f(n)$ 是多少？答案可能很大，请对 $10^9+7$ 取模。


### Input Format

一行一个正整数 $n$。


### Output Format

一行为所求的结果。


### Hint

对于 $30\%$ 的数据，$n\leq1000$；

对于 $50\%$ 的数据，$n\leq1000000$；

对于 $100\%$ 的数据，$2\leq n\leq10^{18}$。
