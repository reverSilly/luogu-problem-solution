# P5703 【深基2.例5】苹果采购

## Difficulty

入门

## Tags

数学

## Problem Description

### Description

现在需要采购一些苹果，每名同学都可以分到固定数量的苹果，并且已经知道了同学的数量，请问需要采购多少个苹果？

### Input Format

输入两个不超过 $10^9$ 正整数，分别表示每人分到的数量和同学的人数。

### Output Format

一个整数，表示答案。保证输入和答案都在 int 范围内的非负整数。
