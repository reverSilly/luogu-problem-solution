# P5900 无标号无根树计数

## Difficulty

Level 8

## Tags

数学, O2优化, Pólya 定理, 组合数学, 生成函数, 快速傅里叶变换 FFT

## Problem Description

### Background

考虑到你谷还没有这类题，于是就放了这么个水题。 


### Description

求 $n$ 个点的无标号无根树数量，答案对 $998244353$ 取模。

### Input Format

输入一行一个正整数 $n$。

### Output Format

输出一行一个整数表示答案。

### Hint

【数据范围】   
对于 $30\%$ 的数据，$1\le n \le 1000$；   
对于 $100\%$ 的数据，$1\le n \le 2\times 10^5$。  

虽然 $\Theta(n \log^2 n)$ 也能过，但是没什么意义，建议写一下 $\Theta(n \log n)$ 的做法。
