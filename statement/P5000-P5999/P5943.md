# P5943 [POI 2002 R2] 最大的园地

## Difficulty

提高/省选-

## Tags

2002, POI（波兰）

## Problem Description

### Description

在一个 $n\times n$ 的正方形内找到最大的由 `0` 组成的矩形，输出它的面积。

### Input Format

输入的第一行为一个整数 $n$。

接下来的 $n$ 行，每行 $n$ 个数，描述这个正方形。

### Output Format

输出其中最大的由 `0` 组成的矩形的面积。

### Hint

对于 $100\%$ 的数据，$1\le n\le 2000$。
