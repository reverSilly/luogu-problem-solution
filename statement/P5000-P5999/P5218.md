# P5218 无聊的水题 II

## Difficulty

NOI+

## Tags

莫比乌斯反演, 整除分块, Bézout 定理, 杜教筛

## Problem Description

### Background

出题人过菜，只会出这种题。

### Description

DLS 是一个喜欢玩游戏的男生。

今天他从朋友那里看到了 $N$ 件武器，其中第 $i$ 件武器的威力值为$i$。

他观察了这 $N$ 件武器许久，打算买下其中若干件武器，但他想用买下的武器的威力值组合出任意威力值，其中每一件武器已经的威力值可以叠加，甚至可以减去。  
例如一个威力值为 $3$ 的武器，可以组合成的威力值为 $\dots,-6,-3,0,3,6,\dots$。

他想找出所有满足以上条件的买下装备的方案，但方案数量实在太多了。你能帮他计算一下吗？    
答案对 $10^9+7$ 取模。

### Input Format

一行一个整数 $N$。

### Output Format

一行一个整数表示答案。

### Hint

|数据百分比|限制|
|-|-|
|$10\%$|$N \le 20$|
|$30\%$|$N \le 2000$|
|$60\%$|$N \le 10^7$|
|$100\%$|$N \le 10^{11}$|
