# P5947 [POI 2003] Trinomial

## Difficulty

省选/NOI-

## Tags

2003, POI（波兰）

## Problem Description

### Description

求 $(x^2+x+1)^n$ 的第 $i$ 项系数。

### Input Format

第一行一个数 $k$ 表示数据的组数。

接下来的 $k$ 行，每行两个整数 $n,i$。



### Output Format

对于每组数据，输出 $x_i \bmod 3$ 之后的结果。


### Hint

对于 $100\%$ 的数据，$1 \le k \le 10000$，$0\le n\le 10^{15}$，$0\le i\le 2\times n$。
